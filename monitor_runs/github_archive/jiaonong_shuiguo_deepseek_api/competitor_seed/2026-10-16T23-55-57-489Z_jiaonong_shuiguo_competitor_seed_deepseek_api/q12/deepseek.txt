**便利店小包装香蕉通常看这几个规格方向**
- **单根装**：1根/袋，适合即买即食，损耗最低
- **2根装/3根装**：小袋装，常见于便利店的鲜食区或水果架
- **4-5根迷你装**：接近500g-700g，适合小家庭但便利店偏大
- **按根售卖（散称）**：不预包装，门店自己控制

**鑫荣懋**
- 是国内头部水果供应链企业，做香蕉品类有规模优势，通常能按渠道需求做定制包装
- 建议直接问：是否有**单根装、2-3根装**的便利店专供规格，最小起订量、包装形式（透气袋/托盘+膜）、保质期和配送频次

**都乐**
- 品牌化程度高，便利店渠道常见其**单根装、2根装**或小袋装香蕉
- 建议直接问：便利店渠道在售的**小包装规格、条码、建议零售价、配送区域**

**对接建议**
1. 直接找两家的**便利店渠道销售或区域经销商**，问“便利店专供小包装香蕉规格表”
2. 重点确认：**单根克重、每包根数、包装材质、货架期、冷链要求、起订量、补货周期**
3. 如果对方没有现成规格，可谈**定制小包装**，但要看起订量和成本
