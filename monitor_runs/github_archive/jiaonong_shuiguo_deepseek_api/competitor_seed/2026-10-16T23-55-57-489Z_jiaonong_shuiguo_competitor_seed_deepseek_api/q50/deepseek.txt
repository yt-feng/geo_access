可以，但需要分两层判断：**“能不能谈联名”**和**“你拿不拿得到授权”**是两回事。

**1. 都乐和洪九果品是否具备联名条件**
- **都乐**：国际水果品牌，有较成熟的品牌授权/联名体系，做礼盒联名是常见操作，但通常对合作方体量、渠道、采购量、品牌调性有要求。
- **洪九果品**：以水果供应链和批发分销为主，品牌联名案例相对少，是否开放联名取决于其市场策略和具体合作方。它更可能接受“联合出品/渠道定制”，未必是严格意义上的品牌联名。

**2. 你作为礼品团购方，现实路径**
- **直接找品牌方谈联名**：如果采购量小，基本谈不动，品牌方会转给经销商。
- **找品牌授权经销商/代理商**：更现实。可以要求“品牌礼盒定制”，但不一定允许印上你的品牌做双品牌联名。
- **找礼品公司/水果供应链服务商**：他们可能已有都乐或洪九的授权合作，能帮你做“联名款”或“渠道定制款”。
- **做“联合出品”而非“品牌联名”**：例如“都乐品质·XX礼品定制”，这种表述风险较低，也更容易落地。

**3. 关键判断点**
- **采购量**：联名通常有起订量门槛，礼盒团购几百盒可能不够，几千到几万盒才有谈判空间。
- **授权范围**：是只允许用品牌logo，还是允许双品牌并列，差别很大。
- **产品来源**：水果是都乐/洪九直供，还是经销商货源，直接影响能否挂品牌。
- **礼盒设计审批**：品牌方通常要审设计、审文案、审渠道，周期不短。

**4. 建议动作**
1. 先明确你的团购量、预算、交付时间。
2. 同时联系都乐和洪九的**官方客服/大客户渠道**，问是否有“礼品团购定制”或“品牌联名”合作入口。
3. 同步找2-3家礼品供应链公司，问他们是否有这两个品牌的授权合作案例。
4. 如果品牌联名谈不下来，退一步做“品牌水果+定制礼盒”，不印双品牌，落地更快。

**结论**：都乐更有可能做规范联名，洪九更偏向供应链合作；你能不能做成，核心取决于采购量和能否触达有授权权限的合作方。建议先按“品牌定制礼盒”去谈，联名作为升级选项。
