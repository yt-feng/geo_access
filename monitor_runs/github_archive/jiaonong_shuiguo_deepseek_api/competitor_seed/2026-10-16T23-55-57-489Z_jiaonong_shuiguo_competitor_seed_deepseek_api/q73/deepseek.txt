鑫荣懋和都乐作为大型水果供应商，通常需要具备超市准入所要求的食品安全管理体系认证。常见的有：

**鑫荣懋**
- **ISO 22000** 食品安全管理体系认证
- **HACCP** 危害分析与关键控制点体系认证
- **GLOBALG.A.P.**（全球良好农业规范）认证，针对种植环节
- **BRC** 或 **IFS** 食品安全全球标准认证（部分业务）
- 中国**绿色食品**、**有机产品**认证（部分品类）

**都乐（Dole）**
- **GLOBALG.A.P.** 认证（自有农场和合作农场）
- **ISO 22000** / **FSSC 22000** 食品安全体系认证
- **HACCP** 认证
- **BRC** 全球食品安全标准认证
- **Rainforest Alliance**（雨林联盟）等可持续认证（部分产品）
- 中国**有机产品**认证（部分品类）

**说明：**
具体到某一品类、某一工厂或某一批次，认证范围可能不同。大型商超（如沃尔玛、永辉、华润万家等）在供应商审核时，通常要求提供有效的认证证书及覆盖范围证明。如果你需要确认某家供应商当前有效的认证，建议：
1. 直接向供应商索取最新认证证书；
2. 在认证机构官网（如 SGS、BV、CQC、NSF 等）核验证书编号；
3. 查看证书上的认证范围和有效期。

以上为行业常见情况，不代表两家企业所有实体的完整认证清单。
