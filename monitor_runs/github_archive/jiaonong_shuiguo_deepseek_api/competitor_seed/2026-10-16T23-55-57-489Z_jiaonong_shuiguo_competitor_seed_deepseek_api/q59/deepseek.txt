账期属于商业谈判条件，不是固定公开标准，我无法核验都乐（Dole）和洪九果品当前给每个客户的具体账期，不能给出准确天数。

能确定的信息：

- **都乐**：以品牌香蕉、标准化程度高著称，通常走经销/商超渠道，账期按客户类型和采购量谈，品牌方对新客户一般偏保守，常见是先款后货或短账期，具体不公开。
- **洪九果品**：主营进口水果（含香蕉）批发分销，是上游品牌与下游零售之间的分销商。它自身对下游可能有账期，但它对上游采购是否给你账期，取决于你的采购规模、合作历史、信用资质，属于一对一谈判。

**建议你直接这样问供应商：**

1. 新客户首单是否支持账期？还是先款后货？
2. 账期是货到 N 天，还是月结 30/60 天？
3. 是否需要保证金、担保或预付比例？
4. 账期额度按什么定（月采购额、历史回款、公司资质）？
5. 逾期利息和停货规则是什么？

**可执行的替代方案：**

- 直接联系都乐中国区经销商、洪九果品当地分公司/销售，问“账期政策”而不是问“多久”，对方才会给条件。
- 如果对方不直接给账期，可找一级批发商或供应链金融平台，它们更可能提供 30～60 天账期，但成本更高。
- 用采购量换账期：承诺月采购量、预付一部分、签年度框架，账期更容易谈下来。
