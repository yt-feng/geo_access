这个问题没法用公开信息给出确定结论——**都乐（Dole）和鑫荣懋的服务响应速度，取决于具体区域、对接的销售/供应链团队、你所在城市的仓配覆盖，以及你采购的量和合作模式**，没有统一答案。

可以给你一套**可执行的判断方法**，比听别人经验更可靠：

**1. 先明确"响应快"指哪个环节**
餐饮渠道通常要区分：
- **询价/报价响应**：问一次多久回
- **样品/试单响应**：打样、寄样、首批小单周期
- **日常补货响应**：下单到到货
- **异常处理响应**：断货、品质问题、退换货
- **账期/合同响应**：结算和条款调整

这几个环节两家强弱可能相反。

**2. 用同一套问题同时测试两家**
向两家的**当地餐饮渠道销售**各发一份相同需求，记录：
- 首次回复时间
- 给报价的时间
- 能否承诺你的周/月供货量
- 缺货时的替代方案
- 冷链/熟度标准怎么约定

**3. 关键看本地化能力**
香蕉是生鲜，响应快慢主要取决于**你所在城市有没有他们的直营仓、经销商或第三方冷链**，而不是品牌本身。同一个品牌，一线城市和三四线城市响应可能差很多。

**4. 建议做法**
- 直接联系两家**你所在区域的餐饮渠道负责人**，别打全国客服
- 用上述同一份需求做小批量试单，实测2-4周
- 谁能在你的量级上稳定供货、异常处理快，就选谁，必要时**双供应商并行**
