关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法给出可靠的具体数字。这类商务条款通常不会公开披露，而且会随品类（鲜菠萝/菠萝制品）、季节、采购量、合同类型和谈判结果而变，同一家公司对不同客户也可能给不同条件。

可以明确的是：

- **没有公开、可核验的“都乐菠萝锁价周期X周/X月”资料**，如果我给你一个具体天数，很可能是不准确的。
- 洪九果品作为国内水果供应链企业，通常按订单/框架协议商谈价格，锁价周期需要向其销售或大客户部门确认。

**建议这样推进：**

1. **直接向两家的大客户/餐饮渠道销售询价**，明确问：锁价有效期、锁价对应的最小起订量、是否含运费、超期后调价规则、违约/保证金条款。
2. **要求书面报价单或框架协议草案**，重点看“价格有效期”和“调价触发条件”（如产地价、汇率、海运费波动）。
3. **同时找2–3家替代供应商比价**，例如佳农、鑫荣懋、百果园供应链，以及产地型贸易商，避免只依赖一两家。
4. **如果用量大**，可谈“阶梯锁价”：部分量锁固定价，部分量随行就市，降低双方风险。
