这类到货损耗率没有公开的统一口径，实际值会随批次、季节、运输距离、门店验收标准变化，我不能给你一个可核验的固定数字。要判断都乐和鑫荣懋哪个更稳，建议按下面方式做采购验证：

**先明确“损耗率”口径**
- 到货损耗：卸货验收时剔除的烂果、压伤、青果、规格不符比例
- 仓储损耗：入库后1-3天内的腐坏、黑心、过熟比例
- 加工损耗：去皮去眼后可用果肉比例

茶饮原料更该看“可用果肉得率”，不是单纯看箱损。

**建议直接向供应商索要的数据**
- 近3个月同规格产品的批次到货验收记录
- 规格承诺：单果重、果径、成熟度、糖度范围
- 冷链温度记录和运输时长
- 不合格赔付标准，是否包退换

**小批量对比测试方法**
1. 同一天各采购1-2箱同规格菠萝
2. 到货当场称重、计数、分拣，记录烂果/压伤/青果重量
3. 常温或冷藏放置24小时、48小时再复检
4. 实际去皮切块，称可用果肉重量
5. 连续测3批以上，再比较稳定性

**一般经验判断**
- 都乐标准化和冷链通常更稳，但价格可能更高，适合对规格一致性要求高的门店
- 鑫荣懋在国内水果供应链覆盖广，批次差异可能更依赖具体产地和季节，适合谈灵活价格和本地配送
- 夏季高温期两者损耗都会上升，重点看运输温控和到货成熟度，而不是只看品牌
