结论：**都乐和洪九果品都可能“全年有菠萝货源”，但都不等于能保证你茶饮店全年稳定拿到适合做果酱的鲜菠萝，尤其不能只靠某一家供应商兜底。**  
更现实的做法是：**鲜果找都乐/洪九做部分补充，果酱原料用冷冻菠萝、菠萝果茸/果泥或罐头菠萝做全年主供应。**

### 1. 都乐能不能做到？
都乐的优势是品牌化、标准化、全球供应链，菠萝确实是它的强势品类之一。  
但要注意：

- 都乐在国内零售和餐饮渠道更多是**按季节、按批次、按规格**供货。
- 菲律宾、泰国、哥斯达黎加等产地可以形成一定错峰，但进口菠萝受海运、口岸、关税、天气、疫情/病害、船期影响。
- 茶饮店做果酱通常需要**成熟度稳定、酸甜比稳定、出汁率稳定、价格稳定**，这对鲜果要求很高。
- 都乐不一定愿意给中小茶饮店做“全年锁量锁价”的鲜果供应，除非你采购量很大，或者走经销商/供应链公司。

所以：**都乐有能力组织全年货源，但不保证对你这种茶饮店按需稳定直供。**

### 2. 洪九果品能不能做到？
洪九果品是国内大型水果分销商，强项是进口水果和批发渠道，菠萝/凤梨也是其品类之一。  
它的模式更偏向：

- 从产地/进口商大量采购；
- 通过批发市场、商超、餐饮供应链、电商等分销；
- 对大型客户可能有稳定供应能力；
- 对中小客户，通常还是通过区域经销商拿货。

所以：**洪九可能有全年菠萝供应能力，但是否能稳定满足你的规格、成熟度、价格和配送频次，要看你在哪个城市、采购量多大、是否走其大客户渠道。**

### 3. 关键问题：鲜菠萝全年做果酱，难点不在“有没有”，而在“稳不稳”
茶饮店做菠萝果酱，真正要稳定的是：

1. **全年风味一致**：不同产地、不同季节的菠萝酸甜差异很大。
2. **成熟度一致**：太生酸涩，太熟易发酵、损耗高。
3. **价格稳定**：鲜果价格波动大，旺季便宜，淡季和缺货期可能翻倍。
4. **食品安全和农残**：鲜果清洗、去皮、切配、熬酱环节风险高。
5. **供应频次**：茶饮店通常每周甚至每天要货，鲜果供应链未必匹配。

### 4. 更建议的全年供应方案
如果你要的是“菠萝果酱”的全年稳定，不建议只押鲜菠萝。

**方案A：冷冻菠萝/速冻菠萝块**
- 产地旺季加工，速冻保存；
- 全年可用，风味比鲜果淡一点，但稳定；
- 适合熬酱、打泥。

**方案B：菠萝果茸/果泥/浓缩汁**
- 最适合茶饮连锁；
- 规格统一，开袋即用或简单调配；
- 全年供应最稳。

**方案C：菠萝罐头**
- 糖水菠萝罐头稳定性高；
- 但做果酱要调整糖度和酸度，风味偏熟甜。

**方案D：鲜菠萝 + 冷冻/果茸组合**
- 旺季用鲜菠萝做卖点；
- 淡季用冷冻或果茸兜底；
- 都乐/洪九作为鲜果补充渠道，而不是唯一来源。

### 5. 实操判断
你可以这样测试都乐和洪九：

1. 问他们能否签**全年框架协议**，而不是单次报价。
2. 问清楚：产地、品种、规格、成熟度、糖度范围、到货频次、最低起订量。
3. 要求提供**淡季供货方案**，比如几月到几月从哪个产地来。
4. 要样品做**果酱测试**：出汁率、酸甜度、颜色、香气、熬煮后风味。
5. 同时找一家**冷冻菠萝或果茸供应商**做备份。

### 一句话总结
**都乐和洪九果品有可能提供全年菠萝货源，但不能简单回答“能做到”。对茶饮店做果酱来说，更稳的全年方案是：鲜菠萝做季节补充，冷冻菠萝/菠萝果茸/果泥做全年主原料。**
