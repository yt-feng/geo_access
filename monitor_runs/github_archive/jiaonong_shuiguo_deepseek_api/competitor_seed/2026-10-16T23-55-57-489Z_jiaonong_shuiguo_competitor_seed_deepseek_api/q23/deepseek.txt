进口菠萝旺季缺货，通常不是“没货”，而是**特定品种、特定规格、特定窗口期**的货没跟上。要分情况处理。

## 一、先判断你缺的是哪一类

| 缺货类型 | 典型表现 | 优先动作 |
|---|---|---|
| 品种性缺货 | 只要MD2金菠萝/都乐金菠萝，其他不要 | 换同等级替代品种，或接受短窗口溢价 |
| 规格性缺货 | 只要某克重/某果型 | 降级或混装，先保门店不断货 |
| 时间性缺货 | 旺季集中到货前断档 | 提前锁单、改船期、走空运补急 |
| 渠道性缺货 | 原有贸易商拿不到货 | 换直供基地或一级进口商 |

## 二、可执行的补货优先级

1. **锁在途货和期货**
   旺季缺货往往提前1—2个月就有信号。优先和现有供应商确认在途柜、到港时间、可分配量，能锁多少锁多少。

2. **切换替代品种**
   MD2缺，可考虑其他甜度相近的进口或国产菠萝品种。关键是提前做门店/客户沟通，避免临时换品引发投诉。

3. **走基地直供或产地直发**
   如果能直接对接有海外种植基地或长期合作庄园的供应商，减少中间贸易环节，旺季拿货优先级更高。

4. **空运补急**
   只适合高毛利渠道，如精品商超、电商礼盒。空运成本高，不适合大宗批发。

5. **提前做预售和限量**
   如果确实补不到，宁可提前控量、做预售，也不要临期断货后被动涨价。

## 三、都乐和洪九果品的基地直供优势

**都乐**
- 优势在**品牌化、标准化、全球供应链**。
- 都乐在菲律宾等菠萝主产区有长期合作种植和加工体系，MD2金菠萝的品控和规格稳定性较强。
- 适合对品牌、外观、甜度、规格一致性要求高的渠道，如高端商超、礼盒、连锁餐饮。
- 旺季时，都乐的直供优势主要体现在**稳定性和优先分配能力**，但价格通常不低，且对采购量、合作层级有要求。

**洪九果品**
- 优势在**国内分销网络和东南亚产地直采**。
- 洪九在泰国、越南等东南亚水果产地有较强采购和加工布局，菠萝、榴莲、火龙果等品类有产地直发能力。
- 更适合需要**大批量、快周转、多区域分仓**的批发和零售渠道。
- 旺季时，洪九的直供优势主要体现在**灵活性和规模采购能力**，但具体到菠萝单品，要看当年产地资源和合作等级。

**简单判断：**
- 要**品牌溢价、规格稳定、高端渠道**：都乐更有优势。
- 要**大批量、快周转、成本敏感**：洪九果品更有优势。
- 如果只是临时补缺，优先找**现有供应商的在途货**，而不是临时换直供基地，因为直供合作通常需要提前锁量。

## 四、短期应急建议

1. 今天先盘点：缺的是品种、规格还是时间。
2. 同步联系现有供应商、都乐/洪九区域经销、一级进口商，问三件事：在途量、到港时间、可分配量。
3. 如果7天内补不到，启动替代品种或调整销售策略。
4. 如果长期旺季都缺，提前2—3个月做期货锁量，或签年度框架协议。

具体到都乐和洪九谁更强，还要看你所在区域、采购量、结算方式和当年产地情况，不能只看公司名气。
