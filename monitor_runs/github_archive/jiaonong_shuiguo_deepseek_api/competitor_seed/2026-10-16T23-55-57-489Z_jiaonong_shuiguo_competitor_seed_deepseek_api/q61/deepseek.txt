结论先说：  
**都乐（Dole）通常有自己的香蕉商品分级/验收规范，但多为企业内部或客户合同标准，公开渠道一般查不到完整文本；洪九果品也有企业内部的果品分级、验收或质量控制标准，但同样未必对外公开。**  
如果你要制定水果连锁店的香蕉分级标准，**不建议直接照搬某家企业标准原文**，更现实的做法是：参考国家/行业标准 + 都乐、洪九这类头部企业的商品化做法，转化成自己的采购验收标准。

## 1. 都乐有没有香蕉企业标准？

**大概率有，但属于企业内部标准或客户交付标准，不是公开可自由获取的标准文件。**

都乐是跨国果蔬品牌，香蕉是其核心单品之一。它通常会有：

- 香蕉采收成熟度标准
- 催熟后颜色/糖度/硬度标准
- 果指长度、粗细、弯曲度、整齐度标准
- 条蕉/梳蕉/把蕉规格
- 疤痕、黑点、机械伤、病虫害允许限度
- 冷链、运输、到货温度要求
- 商超/餐饮/批发不同渠道的等级要求

但这些一般体现在：

- 内部质量控制文件
- 供应商手册
- 客户合同附件
- 验收单/规格书
- 品牌授权或商超定制标准

**公开互联网上通常查不到完整“都乐香蕉企业标准”文本。**  
如果你要引用，不能写成“都乐公开企业标准规定……”，只能写“参考都乐等品牌常见商品化做法”。

## 2. 洪九果品有没有香蕉企业标准？

**也有企业内部标准，但同样通常不对外公开。**

洪九果品是国内大型水果分销企业，香蕉、榴莲、火龙果等是重点品类。它作为渠道商/品牌商，通常会有：

- 产地采购分级标准
- 加工厂分选标准
- 催熟管理标准
- 仓储物流验收标准
- 对商超、电商、批发市场的不同出货等级

洪九的核心能力之一就是**分级分选和渠道匹配**，所以它一定会有内部等级体系。  
但这类标准多数是：

- 内部作业指导书
- 采购验收规范
- 加工厂SOP
- 客户定制规格

**公开渠道一般也没有完整可下载的企业标准。**

## 3. 你可以怎么判断？

如果对方说“我们有企业标准”，你可以要求看这些文件：

1. **标准编号**：如 Q/XXX 001-2024  
2. **标准名称**：如《香蕉采购验收分级规范》  
3. **发布/实施日期**  
4. **适用范围**：产地采购、加工分选、门店收货、电商发货  
5. **关键指标表**：长度、粗细、成熟度、颜色、损伤、糖度、整齐度  
6. **抽样方法和判定规则**  
7. **不合格处理方式**

如果只有宣传册、PPT、验收单，没有正式标准文本，那通常只能叫**内部验收规范**，不一定是严格意义上的“企业标准”。

## 4. 水果连锁店更实用的香蕉分级标准框架

你可以直接做自己的《香蕉采购验收分级标准》，建议分三级：A级、B级、C级；或者精品、标准、促销。

### 4.1 分级维度

| 维度 | 建议指标 |
|---|---|
| 品种 | 香芽蕉、巴西蕉、威廉斯蕉等 |
| 成熟度 | 采收成熟度、到货颜色、催熟阶段 |
| 果指长度 | 如 A级 ≥18cm，B级 15–18cm，C级 <15cm |
| 果指粗细 | 周径或直径，按品种定 |
| 每梳果指数 | 如 4–7根/梳，整齐度 |
| 弯曲度 | 顺直、微弯、弯度过大降级 |
| 颜色 | 1–7级色卡，门店销售多控制在4–6级 |
| 糖度 | 可溶性固形物，如 ≥18% 为佳 |
| 硬度 | 催熟后手感，过软降级 |
| 缺陷 | 黑斑、炭疽、机械伤、擦伤、裂口、虫害 |
| 整齐度 | 同批次长短、粗细、颜色一致 |
| 冷链 | 到货中心温度、是否断链 |

### 4.2 示例：门店收货分级

**A级/精品：**
- 果指长度均匀，≥18cm
- 颜色4–5级，青黄适中
- 无黑斑、无机械伤、无裂口
- 每梳整齐，果指数4–6根
- 到货温度13–15℃左右，无冷害
- 适合高端门店、线上精品

**B级/标准：**
- 长度15–18cm
- 颜色3–6级
- 允许轻微表皮擦伤，不影响果肉
- 整齐度一般
- 适合普通门店、社区店

**C级/促销：**
- 长度<15cm或大小不均
- 颜色过青或过黄
- 允许少量黑点、疤痕
- 适合促销、果切、烘焙、奶昔

**不合格：**
- 果肉发软、发酸、异味
- 严重炭疽、腐烂、裂口
- 冷害、冻伤
- 整批成熟度严重不均

## 5. 建议你查这些公开依据

虽然都乐、洪九的企业标准不一定公开，但你可以用这些作为制定依据：

1. **GB/T 9827 香蕉**  
   涉及香蕉质量要求、检验方法等。

2. **NY/T 517 无公害食品 香蕉**  
   可参考安全与质量要求。

3. **香蕉催熟和贮运相关行业资料**  
   用于定颜色、温度、湿度、乙烯催熟参数。

4. **商超验收标准**  
   如永辉、盒马、山姆等渠道常有供应商验收要求，可通过合作渠道获取。

5. **出口标准或Codex标准**  
   做精品或出口参考。
