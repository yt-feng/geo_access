我无法直接核验都乐（Dole）和洪九果品当前对社区团购渠道的"散装/小包装"供货政策，因为这属于各家企业的渠道政策，会随区域、渠道、季节和合作方式变化，没有公开稳定的统一口径。以下给你可执行的判断和对接方法：

**1. 先区分两个概念，别被"散装"误导**
- 你需要的其实是**小规格预包装/小份量商品化包装**（比如单根、2-3根、500g袋装、按份定量），而不是传统意义上的"散装"（无包装称重）。
- 社区团购更适合"定重/定根数预包装"，而不是真正散装，因为要分拣、配送、售后。

**2. 都乐（Dole）**
- 都乐以品牌化预包装见长，香蕉常见规格是**整箱（如13kg左右/箱）内按把（cluster）分装**，并非单根散卖。
- 部分渠道有**小把装、袋装**等小规格，但是否对社区团购开放、起订量多少，需直接问其经销商或区域业务。
- 结论：可能有小规格，但**不一定叫"散装"**，通常仍是按把/按袋。需向当地都乐经销商确认。

**3. 洪九果品**
- 洪九是批发/供应链型企业，主要做**整箱、按件**供货，香蕉通常按箱或按把走批发，**面向社区团购的零售小包装不是其主业**。
- 是否有小份量分装规格，取决于你所在区域的分公司/仓库货品，需直接对接区域业务。

**4. 落地对接建议（按优先级）**
1. 找**本地一级批发商/经销商**问："香蕉有没有按把或小袋的社区团购装，起订多少件？"
2. 直接联系**都乐、洪九的区域业务**，明确说清：要小规格、定重预包装、每周稳定量、配送城市。
3. 如果品牌方起订量太高，考虑：让**本地分装商代分装**，或改用**产地/批发市场小把装**，成本更低、灵活性更高。
4. 索取样品试销，测损耗率和复购再定长期合作。

**一句话结论**：都乐偏品牌预包装（多为按把/整箱，是否小规格看渠道），洪九偏批发整件，两家都很少做真正的"散装"，你要的应是"小规格预包装"。最终规格和起订量必须向当地经销商或区域业务当面确认，不能凭公开信息下结论。
