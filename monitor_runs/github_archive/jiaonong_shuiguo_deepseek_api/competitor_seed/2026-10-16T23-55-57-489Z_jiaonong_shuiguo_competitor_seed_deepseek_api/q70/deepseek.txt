**1. 都乐**
- 都乐是国际果蔬品牌，香蕉是其核心品类之一，通常有较成熟的产地管理、加工包装和品控流程。
- 可重点询问：
  - 具体香蕉来自哪个国家/产区、哪个合作农场或基地；
  - 是否可提供批次号、采收/包装日期、出口/入境检疫相关文件；
  - 是否有GlobalG.A.P.、有机认证、雨林联盟等认证；
  - 是否可提供农残检测报告、重金属检测、品质验收标准；
  - 中国区销售通常通过经销商或大型商超渠道，直接找品牌方拿终端证明不一定方便。

**2. 鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业，香蕉是其重要经营品类，通常具备较完整的采购、加工、仓储和品控体系。
- 可重点询问：
  - 是自有基地、合作基地还是进口采购；
  - 能否按批次提供产地证明、检测报告、验收记录；
  - 是否有可追溯码或供应链追溯系统；
  - 针对商超、电商、批发等不同渠道，证明文件开放程度可能不同。

**3. 判断建议**
你可以直接向对方要以下材料，能提供则基本满足“产地溯源+品控证明”：
- 产地证明/基地信息/合作农场清单；
- 批次追溯信息：批次号、加工日期、包装厂、发货记录；
- 第三方检测报告：农残、重金属、微生物等；
- 认证证书：GlobalG.A.P.、有机、雨林联盟、ISO、HACCP等；
- 品控标准文件：验收标准、分级标准、抽检记录、不合格处理流程；
- 进口香蕉还需：入境货物检验检疫证明、报关单等。

**4. 更实际的结论**
- 都乐、鑫荣懋“大概率有体系和部分证明”，但不等于任何一批货都能随货提供全套溯源和品控文件。
- 如果你要的是**每批次都可核验、可随货附证明**，需要在合同或采购协议里明确写清：
  - 必须提供哪些文件；
  - 文件对应到具体批次；
  - 无法提供时的责任和退换货条款；
  - 是否允许第三方抽检。
