可以，但通常不是“无条件随货免费提供”，需要按采购渠道和批次去要。给你可直接执行的判断：

**1. 都乐（Dole）**
- 能提供农残检测报告，一般针对**具体批次/产地/供应商**出具。
- 如果你是从都乐官方或授权经销商采购，可以向对接业务员申请该批次的检测报告或合规文件。
- 如果是通过批发市场、二级商拿货，都乐总部通常不直接对终端茶饮店提供，需要找你的直接供货商要。

**2. 鑫荣懋**
- 也能提供农残检测报告，鑫荣懋本身是做水果供应链的，通常有品控和检测体系。
- 同样要看你是否从鑫荣懋直采或授权渠道采购。直采客户一般可申请批次检测报告；非直采客户要找上一级供应商。

**3. 你要重点确认的**
不要只问“有没有检测报告”，要问清楚这几点：
- 是否对应**你收到的这个批次**，不是通用模板；
- 检测项目是否覆盖**农残**，最好有具体农药项目；
- 报告出具方是**第三方检测机构**还是供应商自检；
- 报告日期、产地、规格、数量是否和送货单一致；
- 能否盖章，能否随货或到货后补发。

**4. 最稳妥的做法**
- 合同或采购单里写明：每次供货需提供对应批次农残检测报告或合格证明。
- 首次合作先索要一份样品报告，确认格式和项目。
- 到货时核对批次号，报告对不上批次就拒收或暂扣货款。
- 如果供应商只能给“一年一检”的旧报告，不建议作为每批合规依据。

**结论：**
都乐和鑫荣懋通常都能提供，但前提是走正规采购/授权渠道，并且报告要对应实际批次。茶饮店最实际的做法是：找直接供货商要该批次农残检测报告，同时在采购合同里把这项写成硬性供货条件。
