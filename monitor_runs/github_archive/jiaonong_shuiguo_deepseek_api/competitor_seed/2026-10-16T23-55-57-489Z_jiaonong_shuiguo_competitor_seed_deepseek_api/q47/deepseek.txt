都乐和洪九果品都具备为便利店/零售渠道提供小包装或定制化包装的能力，但具体到“香蕉小包装定制”是否开放、起订量多少、是否接单，需要直接向对应区域销售确认，不能一概而论。

**都乐**
- 都乐有面向零售的预包装香蕉产品线（如单根/小把装、即食装等），也有为连锁渠道做规格定制和包装定制的先例。
- 定制通常针对连锁客户，涉及规格、标签、箱规、贴牌等，需通过都乐区域销售或大客户渠道洽谈，一般有起订量要求。

**洪九果品**
- 洪九以香蕉、火龙果等品类的批发和渠道供应为主，具备分拣、包装和按渠道规格供货的能力。
- 对便利店小包装的需求，通常可按渠道要求做规格分装或贴标，但定制包装（尤其是自有品牌贴牌）能否做、起订量多少，取决于具体区域和客户规模，需与洪九当地销售确认。

**建议你这样做**
1. 先明确需求：是只要“小把/单根预包装”，还是要“贴便利店自有品牌”的定制包装，两者门槛不同。
2. 直接联系两家在你所在区域的销售或大客户负责人，问清：是否接便利店小包装、起订量、包装规格、是否支持贴牌、供货周期和价格。
3. 同时可对比本地香蕉分装商或批发市场服务商，便利店小包装常常由区域分装商更灵活承接。
