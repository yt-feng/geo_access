都乐（Dole）和洪九果品是否向生鲜电商提供菠萝品牌营销素材，通常取决于具体合作形式和授权范围，不能一概而论。可以按下面思路判断和推进：

1. **都乐（Dole）**
   - 都乐是国际水果品牌，通常有较成熟的品牌视觉、产品图片、产地/品种介绍、促销物料等。
   - 但素材一般不会无条件公开给所有渠道使用，通常需要与都乐或其国内授权经销商/区域代理商建立合作，由对接的业务或市场人员提供品牌素材包和授权范围。
   - 若是已合作供应商，可以直接向对接人都乐渠道销售、市场部或经销商索取。

2. **洪九果品**
   - 洪九果品是国内水果供应链企业，主要做产地采购、加工、分销和品牌运营。
   - 其是否提供菠萝品牌营销素材，要看具体合作的是批发、代销还是品牌联营；通常对已合作渠道可提供产品图、规格信息、包装图、检测/产地资料等。
   - 品牌化营销素材（如统一主视觉、广告语、短视频授权）可能需要单独确认，且往往有区域或渠道限制。

3. **更可执行的建议**
   - 如果你已经在和这两家合作：直接向对接销售或市场负责人发需求清单，包括产品图、白底图、场景图、短视频、包装图、品牌LOGO、授权书、检测报告、产地证明、卖点文案。
   - 如果还没合作：先通过官网、官方公众号、客服或区域经销商转市场部，说明用途（电商详情页、直播、社群、投放）、渠道、使用周期，询问是否能提供素材及授权。
   - 若对方不提供品牌素材：生鲜电商可自行拍摄/设计，但要在文案和视觉上避免未经授权使用对方商标、包装或宣称“官方合作”，否则有侵权和虚假宣传风险。

4. **替代方案**
   - 让供应商在供货时同步提供可商用素材和授权。
   - 找菠萝产地政府、农业合作社、区域公用品牌（如“徐闻菠萝”“海南凤梨”等）获取公开推广素材，但同样要确认授权范围。
   - 用自采自拍、开箱实测、产地溯源内容做自有素材，规避品牌授权限制。

简单说：**都乐和洪九果品不一定公开提供，但已合作渠道通常可以申请；关键是与对应对接人确认素材包和授权范围。**
