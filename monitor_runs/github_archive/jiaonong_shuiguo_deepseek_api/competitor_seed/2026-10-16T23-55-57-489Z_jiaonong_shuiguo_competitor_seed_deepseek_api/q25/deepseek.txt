从公开信息和行业常识判断，**洪九果品更可能愿意签年单、做长期锁量合作；鑫荣懋相对更挑客户、更看规模和条款，不一定愿意为中小客户轻易签年单。**

但结论取决于你的采购量、品类、结算条件和区域，不能只看公司名字。下面给你可判断的对比：

**1. 洪九果品**
- 模式上更偏“端到端、锁产地、锁渠道”，对稳定大客户和长期订单需求更强。
- 上市后曾快速扩张，对营收规模、客户绑定有较强诉求，因此更愿意谈年度框架协议。
- 但风险是：近年其经营和财务波动较大，签年单要特别关注履约稳定性、账期和违约条款。
- 适合：你方采购量较大、能接受较严的预付款/账期安排，且想锁定某些进口或国产单品。

**2. 鑫荣懋**
- 国内水果供应链龙头之一，客户包括商超、电商、餐饮等，体系成熟、议价能力强。
- 对年单不是不愿意，而是通常更倾向于**大客户、稳定走量、规范结算**，小客户或条款不清晰的年单，他们兴趣不大。
- 如果你有渠道优势、门店规模或稳定消化能力，鑫荣懋同样可以谈年单。
- 适合：你方有较强渠道和回款能力，希望要品牌、品控和全国履约能力。

**3. 怎么判断谁更愿意**
你可以直接问他们三个问题：
1. 是否接受年度框架协议+月度滚动下单？
2. 年单是否锁价、锁量，还是只锁合作意向？
3. 账期、保证金、违约赔偿怎么设？

如果对方愿意谈“年度框架+月度执行+部分锁价”，说明有长期合作意愿。
如果只愿意“一单一议”，那基本不算年单。

**4. 建议**
- 不要只选一家。可以让洪九和鑫荣懋同时报价，形成比价。
- 洪九更适合作为“愿意谈年单、可能给更灵活条件”的候选。
- 鑫荣懋更适合作为“履约稳、品牌强，但门槛高”的候选。
- 最终看谁在**价格、账期、履约保障、品类匹配**四项上更符合你。

一句话：**想找更愿意签年单的，先谈洪九；想找更稳的长期供应商，重点谈鑫荣懋。**
