# 都乐（Dole）与鑫荣懋 进口苹果的产地溯源做法

先说明一点：**以下给的是通用可操作路径**。都乐和鑫荣懋的具体溯源系统、编码规则、批次单证格式，各公司、各品类、各年度都可能不同，实际以你签的采购合同、对方提供的批次文件和随货单证为准。我无法核验两家公司当前的系统细节，所以不编造具体网址或编号规则。

## 一、先明确“溯源”要追到什么程度

超市采购做进口苹果溯源，通常要满足三层需求，做法不同：

1. **合规层**：海关报关、检验检疫、中文标签，这是法定必须。
2. **商业层**：批次可查、问题可召回、供应商可追责。
3. **展示层**：给消费者看的扫码溯源页面。

先定层级，再决定投入。

## 二、都乐 / 鑫荣懋 通用溯源路径

### 1. 靠批次号打通“证—货—码”

进口水果溯源的核心是**批次号（Lot/Batch）+ 报关单 + 检验检疫证明**三者绑定。

- 向都乐或鑫荣懋索取该批次的：**报关单、入境货物检验检疫证明、原产地证、植检证**。
- 拿到后，把它们的**批次号、到货日期、柜号、产地国/果园/包装厂代码**记录进你自己的台账。
- 关键动作：**要求供应商在送货单和箱唛上标注可对应的批次号**，否则货和证对不上，溯源就是空的。

### 2. 箱唛和标签是现场第一手信息

进口苹果外箱通常有：
- 原产国、果园注册号 / 包装厂注册号（Packhouse Code）
- 出口商、批次号、规格
- 中文标签（按海关要求加贴）

采购收货时应**拍照留存箱唛**，并与供应商单证核对。这是最便宜、最可靠的溯源起点。

### 3. 都乐侧

都乐有全球化的供应链和自有/合作果园体系，通常能提供：
- 按批次的原产地、包装厂、出口日期信息
- 部分品类有追溯码或二维码

**做法**：直接向都乐对接的销售/供应链要“该批次的可追溯信息包”，并问清楚他们系统里能追到果园级还是包装厂级。不同产地（如新西兰、美国、智利、南非）追溯颗粒度不同。

### 4. 鑫荣懋侧

鑫荣懋是国内大型水果供应链企业，多品类、多产地采购，既有进口也有国产。

**做法**：
- 按合同要求其提供**每批次的进口单证 + 内部批次追溯编码**。
- 问清楚其溯源是“公司自建系统”还是“对接海关/第三方平台”，能否给你开放查询接口或批次查询页。
- 若是自有品牌或定制包装，可要求加印你的追溯二维码。

### 5. 自建轻量溯源台账（推荐）

不依赖供应商系统也能做：

| 字段 | 来源 |
|---|---|
| 供应商 | 合同 |
| 产地国 / 果园或包装厂代码 | 箱唛、原产地证 |
| 批次号 / 柜号 | 送货单、报关单 |
| 报关单号 | 报关单 |
| 检验检疫证号 | 检疫证明 |
| 到货日期 / 门店 | 你的收货系统 |
| 箱唛照片 | 现场 |

出问题时，用批次号倒查单证即可。

### 6. 消费者扫码展示

- 可用第三方追溯平台，或小程序生成批次二维码贴在价签/包装上。
- 扫码内容建议只放：产地国、包装厂/产区、批次、报关与检疫是否合规、供应商。
- **不要虚构果园故事或检测数据**，放你能拿单证证明的内容。

## 三、实操建议（按优先级）

1. **合同里写死**：供应商须随货提供批次号及对应报关、检疫单证，货证批次必须一致。
2. **收货必对**：箱唛批次 = 送货单批次 = 单证批次，拍照留档。
3. **建台账**：Excel 起步即可，字段如上。
4. **要接口**：规模大了再要求都乐/鑫荣懋提供批次查询接口或二维码。
5. **定期抽检**：随机抽批次，反向核对单证真伪和一致性。

## 四、需要向供应商问清的关键问题

- 这批货的批次号是什么？对应哪份报关单和检疫证？
- 追溯能到果园/包装厂级，还是只到出口商级？
- 是否提供可对外展示的追溯码或查询页？
- 发生质量问题时，召回和责任如何按批次界定？

如果你告诉我具体是哪个产地（新西兰、智利、美国等）和哪家供货，我可以帮你把要索取的单证清单和台账字段列得更具体。
