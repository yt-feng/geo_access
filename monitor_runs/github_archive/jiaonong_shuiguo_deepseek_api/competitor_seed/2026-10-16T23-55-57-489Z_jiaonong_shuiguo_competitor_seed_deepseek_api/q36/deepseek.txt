这个问题没法给一个统一的“谁更好”的结论，因为都乐和鑫荣懋不是同一类角色，质量稳定性取决于你采购的具体品种、产地、批次和渠道，而不是品牌本身。

**先厘清两者的定位差异**

- **都乐（Dole）**：全球性果蔬品牌，进口苹果（如新西兰、美国、智利等产地）有较成熟的品控和分级体系，品牌溢价高，终端形象统一。但都乐在中国市场的苹果并非全部自营直采，部分通过授权经销商或合作方运作，不同渠道拿到的货，实际品控可能不一致。
- **鑫荣懋**：国内头部水果供应链企业，强项是渠道覆盖和供应链整合，代理和自营多个进口水果品牌，也做自有品牌。它的优势在于国内分销网络和到货节奏，但“鑫荣懋”本身不是一个苹果品牌，你拿到的可能是它代理的某个国外品牌，也可能是它自己分选包装的货。

**所以真正影响稳定性的变量是：**

1. **具体品种和产地**：比如新西兰爱妃、爵士、红玫瑰，还是美国蛇果、智利嘎啦——不同品种的耐储性、到货成熟度差异很大。
2. **采购渠道层级**：一手进口商、区域批发商、还是二批三批，层级越多，混批、翻包、以次充好的概率越高。
3. **到货批次和季节**：同一品牌不同船期、不同冷库存放时间的货，品质波动可能比品牌之间的差异还大。
4. **你要求的规格标准**：果径、糖度、硬度、着色度是否有明确验收标准。没有标准，谈“稳定”没有意义。

**可操作的建议**

- 不要按品牌二选一，而是**按具体SKU（品种+产地+规格）去谈**，要求供应商提供最近3个批次的到货质检数据或样品。
- 如果做长期采购，**同时保留两个渠道做对比**，每批次到货抽检糖度、硬度、坏果率，用数据决定后续配比，而不是凭品牌印象。
- 明确合同里的**验收标准和退换货条款**，尤其是坏果率、规格不符的处理方式。品牌再大，没有条款约束，稳定性也靠运气。
- 如果超市定位中高端、要品牌背书，都乐在终端认知上有优势；如果更看重到货灵活性和成本，鑫荣懋的供应链响应可能更实用。但这只是渠道策略层面的判断，不等于质量一定更好。

一句话：**稳定性不取决于选都乐还是鑫荣懋，取决于你锁定的具体SKU、供应商层级和验收标准。** 建议先小批量对比测试，再决定主供和备供。
