我不能直接给出“都乐一定更便宜”或“鑫荣懋一定更便宜”的结论，因为进口苹果的到货价受**产地、品种、规格、包装、季节、汇率、关税/增值税、港口、促销政策、账期和返利**影响很大，同一家公司不同月份、不同单品价格都会反转。

但可以给你一个可执行的判断框架，按这个去比，基本不会被“表面报价”误导：

**1. 先锁定可比单品**
不要只问“进口苹果多少钱”。要统一到：
- 品种：如新西兰爱妃、索尼娅、红玫瑰；美国蛇果；智利嘎啦等
- 规格：果径/克重/个数
- 包装：原箱、礼盒、托盘、单层/双层
- 等级：一级、二级、成品率
- 到货港/到货地
- 是否贴标、是否可换箱、是否带品牌授权

**2. 比“落地综合成本”，不是比报价**
让两家按同一口径报：
- 裸果价/箱
- 关税、增值税、港杂、冷链、运费谁承担
- 损耗率、次果率、可退换比例
- 账期：现款、30天、60天
- 返利、陈列费、促销支持、损耗补贴
- 起订量、拼柜要求、锁价周期

**3. 都乐和鑫荣懋的典型差异**
- **都乐**：品牌力强，终端认知高，适合做礼盒、精品超市、线上品牌专区；但通常品牌溢价更明显，条款可能更严，适合走量+品牌溢价的渠道。
- **鑫荣懋**：供应链和进口水果操作能力强，很多连锁水果店会把它作为重要进口果供应商；价格弹性、单品组合、区域服务可能更灵活，但具体也要看你在哪个区域、采购量多大。
- 简单说：**都乐不一定更便宜，但品牌溢价可能更好卖；鑫荣懋不一定最低，但综合服务和供货稳定性可能更有优势。** 最终要按你的门店定位算毛利。

**5. 结论建议**
如果你要的是**品牌溢价和礼盒场景**，优先测都乐；如果你要的是**连锁门店日常走量、综合成本低、供应灵活**，优先测鑫荣懋。最稳的做法是：
- 选2-3个同规格单品
- 各拿1-2板/1柜试销
- 按“实际售罄率、损耗、毛利额”而不是“进货价”决定主供
- 主供+辅供并行，避免被单一供应商锁死价格
