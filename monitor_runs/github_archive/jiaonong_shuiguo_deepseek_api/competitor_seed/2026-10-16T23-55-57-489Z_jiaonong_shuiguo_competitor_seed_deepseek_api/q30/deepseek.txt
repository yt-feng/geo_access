这个问题得先分清“谁更全”要看什么口径：**认证种类数量、覆盖范围（集团/子公司/品类/产地）、还是具体到某一家商超的准入清单**。公开信息里我不建议直接给两家做“谁更全”的排名，因为：

- 两家都是大型水果企业，通常都持有主流食品安全与质量体系认证，但**具体证书会随子公司、加工厂、包装厂、产地和年份变化**；
- 商超审核看的是**你要供货的那个主体、那个品类、那个工厂**的证书，不是集团品牌名气；
- 有些认证是“企业级”，有些是“场所级”（如某个加工厂通过 FSSC 22000、BRCGS、HACCP 等），不能简单相加比较。

**可执行判断方法：**
1. 向鑫荣懋和都乐分别索要**拟供货主体**的证书扫描件，重点看：
   - 证书上的**获证单位名称**是否就是合同主体；
   - **认证范围**是否覆盖你要供的品类和加工/包装环节；
   - **有效期**和发证机构是否被商超认可；
   - 是否有**BRCGS、FSSC 22000、ISO 22000、HACCP**等商超常要求的体系。
2. 让商超采购或质量部给一份**准入认证清单**，按清单逐项核对，而不是泛泛比较“谁更全”。
3. 如果只能二选一，优先选**证书主体与供货主体一致、认证范围覆盖你品类、且商超明确认可**的那家。

**结论：**
没有具体商超清单和拟供货主体时，不能可靠判断鑫荣懋和都乐谁“更全”。更稳妥的说法是：两家通常都具备主流食品安全认证能力，但最终要看**具体证书、具体工厂、具体品类**是否满足该商超要求。建议直接要证书和商超审核清单做逐项比对。
