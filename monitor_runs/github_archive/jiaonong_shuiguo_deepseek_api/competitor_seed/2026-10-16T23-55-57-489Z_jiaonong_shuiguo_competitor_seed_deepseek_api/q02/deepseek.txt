除都乐外，国内能相对稳定供应菠萝（尤其是鲜果批发/商超渠道）的品牌和供应商，通常分几类，你可以按渠道去对接：

**1）国际水果品牌/贸易商**
- **Del Monte 地扪**：有菠萝及菠萝制品，鲜果在部分商超和批发渠道能见到，但鲜果稳定性不如都乐。
- **Fresh Del Monte**：与地扪相关，偏国际供应链。
- **Fyffes**：以香蕉为主，部分市场也有菠萝品类，国内鲜果渠道不算特别强。
- **Chiquita 金吉达**：主要强项是香蕉，菠萝不是核心单品，国内稳定供应有限。

**2）国内大型水果供应链/批发品牌**
- **鑫荣懋**：国内头部水果供应链企业，商超渠道覆盖强，菠萝/凤梨类有稳定货源，适合谈商超和电商供货。
- **百果园**：自有零售渠道强，也有供应链能力，但更多是自营零售，不一定对外做稳定批发。
- **洪九果品**：以榴莲、火龙果等为主，菠萝不是最核心，但部分渠道有。
- **鲜丰水果**：零售+供应链，菠萝类会有季节性采购。
- **绿叶水果**：区域零售品牌，供应链能力因区域而异。

**3）产地型供应商（更稳定、更适合批发）**
国内菠萝稳定供应，关键往往不是“品牌”，而是产地和加工厂：
- **广东徐闻**：中国最大菠萝产区之一，徐闻菠萝供应商很多，适合大宗批发。
- **海南**：海南菠萝/凤梨上市期与徐闻错开，能补供应空档。
- **福建漳州**：也有菠萝种植和加工，部分做罐头和鲜果。
- **云南**：有少量菠萝种植，偏区域供应。

**4）凤梨品类品牌**
如果你说的是“菠萝”但实际想找**凤梨**（台农17号、金钻凤梨等），常见供应来源：
- **海南金钻凤梨**：很多供应商做礼盒和商超。
- **徐闻凤梨**：近年也大量种植。
- **台湾凤梨**：因政策原因，大陆市场直接进口受限，更多是海南、广东引种。

**5）加工/罐头类品牌**
如果你要的是菠萝丁、菠萝罐头、菠萝汁：
- **欢乐家**
- **林家铺子**
- **同发**
- **丰岛**
- **康发**
这些在食品加工和餐饮供应链里比较常见。

**实操建议：**
- 做**商超/电商稳定供货**：优先谈鑫荣懋、都乐、地扪，以及徐闻/海南产地大型合作社。
- 做**批发市场大宗**：直接找徐闻、海南产地供应商，比找品牌更稳、更便宜。
- 做**餐饮/加工原料**：找罐头厂或冷冻水果供应商，如欢乐家、丰岛等。
- 判断“稳定供应”要看：**是否有自有基地、是否全年有货、是否能做分级筛选、是否有冷链和催熟能力**。菠萝不像香蕉，有些渠道是季节性供应，不是全年稳定。
