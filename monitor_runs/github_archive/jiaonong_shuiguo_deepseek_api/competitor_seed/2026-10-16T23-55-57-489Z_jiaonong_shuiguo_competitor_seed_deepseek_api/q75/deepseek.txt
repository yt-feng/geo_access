到货损耗率没有公开统一口径，且会随季节、产地、运输距离、冷链、批发市场卸货与分货方式变化。不能直接给出“洪九果品 vs 都乐香蕉”的固定损耗率对比数字；如果有人给出精确百分比，通常只是某批次或某区域的样本，不适合当通用结论。

可以按可操作方式判断：

1. **品牌差异不是主因**
   - 都乐香蕉通常是品牌化、标准化程度较高的香蕉供应链，催熟、分级、包装、冷链更稳定。
   - 洪九果品是国内大型水果分销商，香蕉是其重要品类之一，但洪九更多是渠道/分销平台属性，具体到货品质取决于批次、产地、催熟厂和承运商。
   - 因此对比时不能只比“品牌”，要比同一市场、同一季节、同一产地/催熟批次。

2. **香蕉到货损耗主要看这些环节**
   - 青蕉采收成熟度
   - 催熟程度和催熟均匀性
   - 冷链断链次数
   - 运输时长与装卸碰撞
   - 批发市场开箱、分拣、翻箱次数
   - 档口温度与销售速度

3. **批发市场常见损耗范围**
   - 管理较好、冷链完整、周转快：到货后分拣损耗通常较低，很多档口可控制在个位数百分比。
   - 普通常温运输、多次装卸、催熟偏熟：损耗会明显上升，擦伤、压伤、落梳、黑斑、软腐都会增加。
   - 夏季高温或压车销售时，损耗通常高于冬季。
   - 具体到“洪九”或“都乐”，必须看当批次，不能跨批次直接比较。

4. **建议你这样实测对比**
   - 同一天、同一市场，各拿洪九和都乐同规格香蕉若干箱。
   - 记录：到货总重、开箱时间、箱内温度、青熟度、外观。
   - 分拣后记录：可售重量、次品重量、损耗重量。
   - 公式：  
     **到货损耗率 = 不可售/降级处理重量 ÷ 到货总重量 × 100%**
   - 连续跟 3—5 批，才能看出稳定差异。

5. **拿货判断建议**
   - 如果你做高端稳定客群：优先看都乐这类标准化程度高的货，但也要确认当地经销商冷链和周转。
   - 如果你做价格敏感、走量：洪九或其他大型渠道可谈，但必须每批验货，重点看催熟一致性和压伤。
   - 无论哪个品牌，先小批量试单，再谈账期和售后扣损。  
   - 合同里最好写清：到货损耗超过多少可扣款/补货/退货，以及验收时限。

结论：**不能可靠地说洪九果品和都乐香蕉谁的到货损耗率固定更低。** 都乐通常在标准化和品控稳定性上有优势，洪九的优势更多在渠道覆盖和批量供应；实际损耗取决于具体批次和流通条件。最靠谱的方法是按你所在批发市场做同批次实测。
