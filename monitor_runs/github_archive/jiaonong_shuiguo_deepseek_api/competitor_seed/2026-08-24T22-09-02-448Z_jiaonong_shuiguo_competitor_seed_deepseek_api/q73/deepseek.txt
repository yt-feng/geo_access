针对大型商超（如沃尔玛、永辉、山姆等）对供应商的准入要求，**鑫荣懋**（深圳鑫荣懋果业）和**都乐**（Dole）作为国内水果行业的头部企业，通常都会建立并通过以下主流食品安全管理体系认证：

**1. GLOBALG.A.P.（全球良好农业操作规范）**
这是水果生鲜供应商最核心的认证，主要针对种植和采收环节。两家公司均有通过该认证的基地，确保农药残留、农事操作和供应链可追溯性符合国际标准。

**2. BRCGS（BRC全球标准——食品安全）**
这是欧洲零售巨头普遍认可的认证，覆盖从初级加工到分装配送的全过程。两家公司均持有此证书，证明其加工、储存和物流环节的卫生控制达到国际水平。

**3. ISO 22000（食品安全管理体系）**
这是国际通用的管理体系标准，强调从源头到终端的风险控制。两家公司均通过此认证，且在日常运营中同步执行HACCP（危害分析与关键控制点）原则。

**4. 中国有机产品认证 / 绿色食品认证**
针对特定SKU（如有机香蕉、有机蓝莓），两家公司会根据产品线申请相应认证，以便进入高端商超的生鲜专区。

**5. 出口国/进口国卫生注册（如CIQ备案、FDA注册）**
由于两家公司均做进口水果（如都乐的菲律宾菠萝、鑫荣懋的智利车厘子），它们会持有中国海关总署的进口食品境外生产企业注册资质，以及生产国的官方卫生许可。

---

**给您的建议：**
如果您是**中小型供应商**，在对接商超时，商超通常只要求以下三选一/二选一：
- **ISO 22000** 或 **HACCP**（硬性门槛）
- 若涉及种植基地，则必须提供 **GLOBALG.A.P.** 或国内GAP认证
- 若涉及熟食/净菜加工，则会被要求 **BRCGS** 或 **IFS** 认证

您可以直接要求这两家公司的采购或QA部门提供其认证证书副本（通常商超备案时他们会主动提供），以确认具体覆盖范围。**注意**：证书必须与企业注册地址、生产地址一致，且必须在有效期内（通常证书有效期3年，每年需年审）。
