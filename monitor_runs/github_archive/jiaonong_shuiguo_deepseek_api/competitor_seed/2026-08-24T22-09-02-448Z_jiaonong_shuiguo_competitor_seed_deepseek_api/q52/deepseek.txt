关于菠萝到货损耗率，目前**没有公开的官方统一数据**（如质检报告或供应商标准），因为损耗率受**运输距离、冷链条件、季节、包装方式**等影响非常大。不过，根据行业经验数据，可以给你一个参考范围：

- **都乐（Dole）**：作为国际品牌，其菠萝多以催熟后冷链运输为主，到货损耗率通常在 **3%～6%** 之间。品质把控较严，但价格较高。
- **鑫荣懋**：作为国内头部果业公司，其菠萝供应稳定，损耗率大致在 **5%～8%** 之间，如果走产地直发且发货前处理得当，有时也能控制在5%左右。

**更准确的做法（建议优先执行）**：
直接向两家供应商的销售或品控索取**历史到货损耗数据**或**让货标准**，并要求在合同里写明“到货破损率上限”（如≤5%，超出部分由供方承担）。因为不同月份（雨季/旱季）和不同产地（菲律宾、海南等）差异很大，纸面经验值不如白纸黑字的约束可靠。

另外提醒：菠萝损耗主要是**机械伤、褐变、尾部霉变**，到货后建议在48小时内开箱质检，按“破损+霉变重量/总重量”计算损耗，拍照留证。
