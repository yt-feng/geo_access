**结论：基本可以，但两家模式不同，需要根据你的门店定位和预算做取舍。**

---

### 一、都乐（Dole）

- **能力**：**全球性供应链**，是大型餐饮/工业客户的长期供应商。
- **供应稳定性**：顶级。都乐在南美（菲律宾、泰国、哥斯达黎加等）有多处种植基地和冷链网络，可以实现**常年的鲜果/冷冻菠萝**供应。
- **适合场景**：如果你做的是**中高端品牌**、对果酱风味一致性要求极高，且愿意接受**相对更高的采购价**和**最低起订量**，都乐是稳妥选择。
- **注意**：都乐更偏向于"标准品"（如去皮切块冷冻块），可能不适合做小众或特殊风味果酱。

---

### 二、洪九果品

- **能力**：**中国本土龙头**，擅长"产地直采+快速分销"，在东南亚和中国云南、海南等地有深度合作基地。
- **供应稳定性**：较强，但**受季节和产地天气影响比都乐略大**。洪九的优势是**灵活**，可以按需采购不同成熟度的菠萝。
- **适合场景**：如果你追求**成本控制**、需要**小批量多批次**到货（降低库存压力），洪九性价比通常更高。
- **注意**：需要你**提前锁定产区**（比如每年4-10月云南/海南，11-3月菲律宾/泰国轮换），并签好框架合同。

---

### 三、给你的落地建议

1. **验证供应能力的关键不是"能不能"，而是"签约后能不能"**：直接要求两家提供**连续12个月的菠萝采购报价单和历史供货记录**，看重叠月份的报价波动。
2. **先做小批量测试**：分别采购少量新鲜菠萝和冷冻菠萝块，测试果酱熬制后的**出胶率、酸度稳定性和褐变情况**。菠萝成熟度波动会直接影响果酱口感。
3. **考虑混合方案**：旺季（4-8月）用国产鲜果（成本低），淡季（11-3月）用都乐/洪九的冷冻菠萝或进口鲜果，以平衡成本和供应。
4. **合同关键条款**：务必写入**最低采购量、提前备货周期（至少7-15天）、天气/封港违约免责条款**，以及**到货质检标准**（糖度/成熟度/无黑心）。

---

**最终建议**：**两家都能做到全年供应**。如果预算充足，选都乐保稳定；如果预算敏感，选洪九配合你自建冻库。最稳妥的做法是**两家都建立年度框架合同**，同时采购，形成双供应商保险。
