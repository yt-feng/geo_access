目前市场上除了都乐（Dole），菠萝的供应品牌和渠道确实比较丰富。根据国内水果市场的实际情况，以下几个品牌和供应渠道比较稳定，您可以参考：

1. **佳沃（Joyvio）**：联想控股旗下的农业品牌，主要做高端水果，有稳定的供应链，菠萝品质也不错，常见于大型商超和生鲜电商。
2. **百果园（Pagoda）**：虽然是零售连锁，但自有基地和供应链体系比较完善，其自有品牌菠萝（如台湾金钻、菲律宾菠萝）供应比较稳定。
3. **鑫荣懋（Joy Wing Mau）**：国内水果流通龙头企业，与全球多个产区合作，菠萝（如泰国、菲律宾、马来西亚）货源较稳，供货给批发市场和商超。
4. **快乐恰（Happy Elephant）**：泰国品牌，主打进口菠萝，主要供应高端超市。
5. **佳沛（Zespri）**：虽然以奇异果出名，但部分区域也供应菠萝，品质有保证，但供应范围可能不如前几个广。
6. **本地或区域品牌**：例如海南、广东、云南等产地的本地品牌（如海南菠萝、徐闻菠萝），如果从事批发，直接对接产地合作社或农户，供应更稳定，价格也更有优势。

**建议优先选择**：如果您是批发或大宗采购，可以接触鑫荣懋或直接联系海南、徐闻产区的农业合作社；如果是零售或电商，佳沃和百果园的供应链更规范。另外，建议关注季节性——菲律宾、泰国菠萝全年有货，而国内菠萝（如徐闻）主要集中在3-5月。
