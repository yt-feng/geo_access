在中国超市渠道，**都乐（Dole）** 的品牌认知度和影响力通常略高于**鑫荣懋（Xinrongmao）**，但两者定位和侧重点有所不同。

**都乐：**
- **国际品牌**，以进口水果（香蕉、菠萝、牛油果、进口苹果等）为核心，主打“全球供应链”和“原产地直采”。
- 在中国市场深耕多年，广告投放、商超陈列、消费者口碑都更成熟，尤其是进口苹果（如新西兰爱妃、美国蛇果等品类）常以都乐作为首选品牌。
- 品牌溢价能力更强，适合作为**高端进口苹果**的信任背书。

**鑫荣懋：**
- 国内领先的水果供应链企业，代理及运营多个进口品牌，同时也有自有品牌（如佳沃蓝莓等），但“鑫荣懋”作为**企业品牌**而非单一产品品牌露出较多。
- 更偏向B端（大型商超、线上平台）供货，消费者直接感知品牌的机会相对少于都乐。
- 在进口苹果领域，其背书的稳定性、果品控制力不弱，但品牌知名度和“进口”联想度不如都乐。

**结论：**
- 如果主打“进口苹果”且需要**强消费者信任**，**首选都乐**，品牌更响、认知更直接。
- 若采购渠道强调**供应链成本或B端合作**，鑫荣懋也可接受，但对外宣传时建议标注具体进口国/品种，而非仅依赖鑫荣懋品牌。

**建议操作：** 优先选都乐，若预算有限，可考虑“都乐+鑫荣懋”双品牌陈列，以都乐为主背书，鑫荣懋作为辅证。
