关于茶饮店采购菠萝原料时，都乐（Dole）和鑫荣懋（Xinrongmao）能否提供农残检测报告，**通常情况下，正规大型供应商都能提供，但具体能否提供、以及报告的形式和覆盖范围，需要你与供应商采购或品控部门直接确认**。

以下是具体分析和建议：

1. **都乐（Dole）**  
   作为全球知名果蔬品牌，其供应链通常遵循严格的质量体系，一般会配备第三方检测报告（如SGS、华测等），且会覆盖常见农残项目。**对接其中国区销售或品控时，直接索要当批次或近期批次的检测报告即可**。如果是大客户（茶饮连锁），多数情况下他们能提供。

2. **鑫荣懋（Xinrongmao）**  
   中国大型水果供应链企业，同样具备质量检测能力。对于企业客户采购，通常可提供产品的农残检测报告，但需要注意：  
   - 报告可能是“供应商自检报告”，也可能是“第三方检测报告”，需确认是哪种。  
   - 如果采购量小（如少量批发），可能不主动提供，需主动询问。

3. **关键操作建议**  
   - **直接索要**：联系对应业务员，明确要求提供“本批次”或“最近连续批次的农残检测报告（含检测项目、限值、结论）”，并确认报告是否在有效期内。  
   - **核对报告内容**：重点看检测项目是否覆盖茶饮业常用关注的农残（如毒死蜱、吡虫啉、阿维菌素等），以及是否符合国家标准GB 2763。  
   - **补充手段**：如果对方无法提供或报告不全，建议你自行委托第三方检测（如SGS、CTI）抽检，或要求供应商指定检测机构复检。

4. **替代方案**  
   如果两家均无法提供，可考虑其他大型供应商（如佳沃、百果园/果品批发的B端渠道），或要求对方在合同中承诺“提供符合国标的农残报告”作为履约条款。

**请不要依赖口头承诺，务必拿到纸质或电子版报告原件，并注意报告上的委托单位、样品名称、生产日期是否与采购批次一致。** 如果对方说“有但暂时拿不出来”，需明确时间节点，并索取样品留底备查。
