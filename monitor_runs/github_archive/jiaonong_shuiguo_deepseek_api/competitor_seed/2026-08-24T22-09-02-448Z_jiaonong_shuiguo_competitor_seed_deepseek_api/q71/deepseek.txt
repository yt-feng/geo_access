关于菠萝的稳定供应，**都乐（Dole）**和**洪九果品**的基地/供应来源情况如下，供你参考：

---

### 1. 都乐（Dole）
- **主要来源**：都乐是全球性品牌，其菠萝主要供应基地在**菲律宾**（尤其是棉兰老岛），也有来自**哥斯达黎加**（中美洲）和**泰国**的货源。
- **国内操作**：都乐在中国主要通过**上海、深圳**等口岸进口，并在国内设有分装加工中心。若需国内基地，都乐主要依赖进口，但在海南等地有合作种植或加工点，具体以官方渠道确认为准。

---

### 2. 洪九果品
- **主要来源**：洪九果品是国内大型水果供应链企业，其菠萝基地主要分布在**泰国**（当地种植园合作）、**菲律宾**，以及**国内广东（湛江、徐闻）、海南**等产区。
- **国内基地**：洪九在**海南**（如乐东、三亚）和**广东湛江（徐闻）**有稳定的合作种植基地，徐闻是全国著名的菠萝产区（“菠萝的海”），适合采购本地化货源。

---

### 我的建议（供决策参考）

如果你追求**供应链稳定和品质一致**：
