除了都乐（Dole）和佳沛（Zespri），礼品团购市场上常见的进口水果品牌还有以下几类，供你参考：

**1. 美国品牌（主打车厘子、苹果等）**

-   **新奇士（Sunkist）**：美国老牌柑橘和柠檬品牌，橙子、葡萄柚礼盒很经典，包装辨识度高。
-   **华盛顿苹果（Washington Apples）**：虽然不算单一公司，但很多高端礼盒会标注“华盛顿州产”，品质稳定，尤其是红地厘蛇果。

**2. 新西兰品牌（主打奇异果、苹果）**

-   **爱妃（Envy）**：新西兰顶级苹果品牌，由佳沛关联公司推出（但独立运营），果肉紧实、甜度高，适合高端馈赠。
-   **爵士（Jazz）**：同样是新西兰苹果品牌，口感脆酸，适合喜欢酸甜口味的客户。

**3. 南美/欧洲品牌**

-   **智利车厘子（如吉制（Garces Fruit）等）**：智利车厘子在冬季是礼品主力，注意看具体庄园品牌，如祥瑞（Riipen）等，通常带独立认证。
-   **西班牙/秘鲁蓝莓（如Camposol、Naturipe等）**：蓝莓礼盒常见，但单盒价值较低，通常和混合水果组合。

**4. 其他热带水果**

-   **菲律宾都乐**（已在列表中，但注意区分）：都乐菠萝是经典。
-   **越南/泰国榴莲（如KPY、B&V等）**：高端金枕或猫山王榴莲礼盒，适合特定客户，注意冷链资质。

---

**建议（针对团购）：**

1.  **核验资质**：进口水果礼盒涉及检疫和原产地证明，团购量大时，务必要求供应商提供《入境货物检验检疫证明》和《原产地证书》复印件，避免假冒。
2.  **季节匹配**：南半球水果（智利、新西兰）在北半球冬春季节供应，而美国车厘子在夏季，选品时优先选择当季能稳定供货的品牌，避免断货。
3.  **混合策略**：单一的佳沛或都乐价格透明利润低，建议搭配新奇士橙子+智利车厘子+新西兰爱妃苹果的混搭礼盒，成本可控且显档次。
4.  **定制贴标**：进口品牌通常不允许随意加贴中方定制标签，但可以在包装外增加手提袋或腰封，建议先和供应商确认“二次包装”的允许范围。
