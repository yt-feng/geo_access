大型商超（如沃尔玛、永辉、盒马等）通常要求生鲜/水果供应商具备**食品安全管理体系认证**，常见认可项包括 ISO 22000、FSSC 22000、HACCP、BRCGS、GLOBALG.A.P. 等。关于**鑫荣懋**和**都乐（Dole）**具体通过了哪些认证，我无法在无实时核验的情况下给出确定清单，避免虚构。

可执行的判断与建议如下：

1. **获取官方凭证**：要求两家供应商提供有效期内的认证证书扫描件，核对认证机构、证书编号、覆盖范围（是否覆盖供货品类/加工厂/包装厂）及有效期。
2. **官网/公开渠道自查**：鑫荣懋官网“质量与安全/资质荣誉”栏目、都乐中国官网及都乐全球官网的食品安全/可持续发展报告中，通常会披露体系认证信息；也可在认证机构官网用证书编号反查。
3. **向商超索要准入清单**：直接问商超品控部门其《供应商食品安全准入标准》认可哪些认证及等级要求，再对照供应商证书。
4. **常见行业实践（仅作参考，不等于两家均已取得）**：大型水果供应商通常涉及 GLOBALG.A.P.（种植端）、ISO 22000 或 FSSC 22000（加工/仓储端）、HACCP；出口导向企业还常见 BRCGS。具体以证书为准。
