都乐（Dole）和鑫荣懋（Joyvio）都是国内生鲜供应链里做进口/国产水果比较成熟的玩家，但“菠萝产地直发”的物流时效不能一概而论，要看**产地、发货仓、目的地、是否走他们的直发专线**。可判断的建议如下：

1. **先确认“产地直发”的实际起运点**
   - 都乐：常见是进口菠萝（如菲律宾）到港后分拨，或国内合作基地直发；真正“产地直发”要看是否从广东徐闻、海南等基地仓起运。
   - 鑫荣懋：国产水果供应链较强，菠萝可能从广东/海南产地仓或区域中心仓发；进口菠萝则看港口分拨。
   - 直接问对方：**起运仓地址、是否产地仓直发、截单时间、发什么快递/冷链、到您城市的标准时效和承诺时效**。

2. **时效判断维度**
   - **同省/邻近省**：通常次日达或隔日达较常见。
   - **跨省中长途**：普通快递2–4天，冷链专线可能2–3天；偏远地区加1–2天。
   - **整柜/大货直发**：走冷链整车，时效取决于排车和线路，通常按“发货后N小时/天”约定，不适合按快递时效判断。
   - **菠萝特性**：常温耐运但怕闷热和挤压，夏季建议确认是否控温、通风、防压；冷链并非必须，但高温长途要问清楚。

3. **让供应商给出可核验的承诺**
   - 要求提供：**近30天到您所在区域/类似城市的实际签收时效样本**，而不是口头“次日达”。
   - 合同里写清：**截单时间、起运时间、承诺时效、超时赔付、坏果率标准**。
   - 先小批量试单：同一目的地发2–3票，记录“下单—出库—中转—签收”节点，再决定主供。

4. **两家怎么选**
   - 如果您做**进口菠萝**且看重品牌标准化，都乐的系统化程度通常较高，但要确认是国内分拨还是真产地直发。
   - 如果您做**国产菠萝（徐闻/海南）**且看重产地资源和灵活拼柜，鑫荣懋的产地供应链可能更贴近；同样要确认起运仓和专线。
   - 最终不看品牌，看**具体起运仓到您仓的线路时效和履约数据**。

**结论：** 无法直接给出两家统一的“时效几天”，因为都乐和鑫荣懋的菠萝直发时效取决于起运仓和线路。建议您向两家分别索取“起运仓—您收货城市”的**承诺时效+近30天实际签收数据**，并用小批量试单核验；同省/邻省一般次日到隔日，跨省普通2–4天、冷链专线2–3天，偏远加1–2天。
