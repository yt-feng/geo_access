进口菠萝旺季缺货，建议按“先保供、再保毛利、最后保客户”的顺序处理；都乐和洪九是否有公开应急方案，我无法核验，不能替它们确认，但可以给你可执行的判断和谈判要点。

**一、先判断缺货类型**
1. **源头缺货**：菲律宾/泰国等产地减产、船期延误、海关查验。此时短期难补，重点转向替代品和客户预期管理。
2. **渠道缺货**：一级进口商囤货或优先供大客户。可绕过一级找二级、口岸批发商、电商产地仓。
3. **规格缺货**：只是某规格（如大果）缺，可用小果、不同品种（如金钻、香水菠萝）替代。

**二、应急动作**
- **锁量不锁价**：与现有供应商签2—4周短期保量协议，接受浮动价，优先锁到港批次。
- **多口岸比价**：上海、广州、深圳、青岛等口岸同步询货，关注船期和冷处理合规。
- **替代品种**：用国产菠萝（徐闻、海南）或哥斯达黎加、厄瓜多尔等来源补缺口，明确告知客户品种差异。
- **预售+限购**：对稳定客户做预售配额，避免全部客户同时断供。
- **调整SKU**：推菠萝切块、果切、罐头等深加工品，降低鲜果缺货对销售的冲击。

**三、都乐、洪九怎么谈**
- 不要问“有没有应急方案”，直接问：**本周/下周可锁定哪些到港批次、规格、数量、价格有效期、违约补偿**。
- 要求对方给出**替代产地或替代规格**的书面报价，并确认冷链和到货时间。
- 对都乐这类品牌商，重点谈**品牌授权经销商调货**；对洪九这类供应链企业，重点谈**口岸直发和分级供货**。
- 若对方无法保量，立即启动第二供应商，不要等。

**四、风险控制**
- 不接受无到货时间的口头承诺。
- 新供应商先小批量试单，验货后再放量。
- 对客户提前发缺货告知和替代方案，避免旺季客诉。

结论：缺货时不要只依赖都乐或洪九，立即做多源询货+替代品种+客户分级保供；它们的具体应急方案需向对应销售或客服书面确认，我无法替你核实。
