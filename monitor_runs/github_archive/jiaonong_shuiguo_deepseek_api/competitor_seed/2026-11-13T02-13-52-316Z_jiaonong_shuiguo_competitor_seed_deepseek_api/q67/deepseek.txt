能提供，但“提供素材”通常要按品牌授权和联名流程走，不能默认可商用。可执行判断如下：

1. **都乐（Dole）**：有成熟品牌素材体系，通常可提供产品图、品牌Logo、产地/品种卖点、营养知识、部分营销文案参考；但用于生鲜电商详情页、海报、短视频、直播贴片等，一般需通过其销售/市场对接人申请素材包和商用授权，联名或定制包装另走审批。
2. **洪九果品**：作为水果供应链和品牌运营方，通常可提供菠萝相关产品资料、规格分级、产地信息、包装/品牌图、部分检测或品控资料；同样需对接其销售或市场团队确认可对外使用的素材范围和授权。
3. **实际操作建议**：
   - 先向两家对接人发“素材需求清单”：用途（详情页/海报/短视频/直播）、渠道、使用期限、是否改图、是否带Logo、是否联名。
   - 要求提供“可商用素材包+授权确认邮件/函件”，避免直接抓官网或电商图。
   - 若做对比营销，避免未经授权使用对方商标做贬损或暗示背书。
   - 若对方不提供成品素材，可退而求其次：用其提供的产品参数和卖点自拍自剪，品牌Logo使用需单独确认。

结论：**两家一般都能提供营销支持素材，但都乐更偏品牌化素材包，洪九更偏产品与供应链资料；是否可用取决于对接和授权，先要授权再落地。**
