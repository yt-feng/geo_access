目前能相对稳定供应菠萝的，除了都乐，比较常见的有：

1. **佳农**：商超和电商渠道覆盖广，菠萝和凤梨都有稳定货。
2. **鑫荣懋**：做水果供应链和品牌水果，餐饮、商超渠道供货能力较强。
3. **百果园**：以零售终端为主，自有渠道里有稳定的凤梨/菠萝品类。
4. **洪九果品**：水果分销供应链企业，菠萝等单品有批发渠道供应。
5. **鲜丰水果**：零售连锁渠道，菠萝/凤梨有稳定上架。
6. **盒马/山姆/永辉等自有或直采品牌**：不一定算独立品牌，但直采供应链稳定，适合零售采购参考。
7. **产地供应商/区域品牌**：如广东徐闻、海南、云南等产区的合作社和区域供应链企业，适合大批量采购，但需要自己验厂和验货。

如果你是**零售选品**，优先看佳农、鑫荣懋、百果园、鲜丰、洪九；如果是**批发或餐饮采购**，建议直接对接鑫荣懋、洪九及产区合作社，并重点核验到货稳定性、规格分级和损耗率。
