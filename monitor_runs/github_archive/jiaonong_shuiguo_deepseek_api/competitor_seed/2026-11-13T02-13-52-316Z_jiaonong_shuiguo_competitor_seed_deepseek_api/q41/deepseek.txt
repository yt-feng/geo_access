结论：从“锁价灵活性”这个维度，通常都乐会更灵活一些，但我们无法核验两家当前的具体报价政策，所以你最终应以书面报价条款为准，不宜只凭品牌印象定供应商。

建议按以下方式判断和推进：

1. **先明确“锁价”具体指什么**
   - 锁采购价还是锁销售价？
   - 锁多久：1周、1个月、一季度？
   - 是否含运费、关税、损耗、催熟费？
   - 价格波动超过多少可调价？

2. **向两家同时发同一份询价表**
   让都乐和鑫荣懋按同一口径报价，重点看：
   - 可锁价的最长期限
   - 锁价保证金/预付款比例
   - 超量、减量是否罚则
   - 汇率、海运费、产地涨价时是否可重谈
   - 违约和不可抗力条款

3. **一般经验判断**
   - **都乐**：品牌和全球供应链强，标准合同体系较成熟，但大公司流程可能更规范、议价空间未必大；“灵活”可能体现在多产地组合和长期协议设计上。
   - **鑫荣懋**：国内渠道和客户响应通常更快，定制化、区域配送、账期和促销协同上可能更灵活；但锁价能力取决于其上游产地和资金安排。

4. **可执行的谈判策略**
   - 不要问“你们能不能锁价”，直接给场景：例如“未来3个月每月200吨，锁价比例70%，剩余30%随行就市，能否做？”
   - 要求两家分别给出“固定价+浮动价”组合方案。
   - 先小批量试单，验证履约、品质和调价沟通效率。

**一句话建议**：如果要快速响应和定制条款，优先深谈鑫荣懋；如果要全球产地组合和标准化合约，优先深谈都乐。但“哪家更灵活”必须用同一份锁价条款去比，不能只看品牌。
