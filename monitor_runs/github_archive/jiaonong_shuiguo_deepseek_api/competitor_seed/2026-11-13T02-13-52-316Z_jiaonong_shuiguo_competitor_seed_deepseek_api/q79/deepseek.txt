从供应能力看，**都乐更可能做到全年稳定供应，洪九果品也有条件做，但需要按你的门店规模和采购方式具体确认**。不能直接下结论说两家都“保证全年不断供”，因为菠萝全年供应取决于品种、产区轮换、加工形态和你的采购合同。

### 都乐
- 都乐是全球性水果企业，有跨国产地和供应链体系，理论上具备通过不同产区轮换实现菠萝全年供应的能力。
- 但都乐在中国市场更偏向鲜果品牌和商超渠道，**是否给你这类茶饮店稳定供应适合做果酱的菠萝原料/果肉/果泥，要看当地经销体系和最小起订量**。
- 建议直接问都乐当地经销商或大客户渠道：能否签年度框架、每月固定量、指定品种和规格、异常月份如何替代。

### 洪九果品
- 洪九果品是国内较大的水果供应链企业，菠萝是其经营品类之一，具备产地采购和全国分销能力。
- 但洪九的核心模式是水果分销，**能否全年稳定供你一个茶饮品牌，取决于你的采购量、所在城市和是否走其B端客户渠道**。小门店直接找洪九不一定好对接，可能需要通过区域经销商。
- 同样要确认：全年各月货源产区、规格等级、到货价波动、最小起订量和账期。

### 更可执行的建议
1. **不要只依赖一家**：茶饮店做果酱，建议“都乐/洪九之一做主供 + 一家区域水果供应链或本地加工厂做备供”。
2. **优先考虑菠萝果泥/冷冻果肉**：全年鲜果供应受季节和产区影响，做果酱用冷冻果肉或果泥更稳定，也减少门店处理损耗。
3. **签合同前要样品和月度排产表**：让供应商提供未来12个月产区来源、规格、参考价和替代方案。
4. **小批量试供3个月**：重点看糖度/酸度稳定性、纤维粗细、出酱率、冷冻解冻表现。
5. **问清最小起订量和配送频次**：茶饮店用量不大时，大供应商可能不直供，需接受经销商加价。

结论：**都乐全年供应能力更强，洪九可以作为国内供应链备选或主供之一，但两家都需要你以B端采购身份去核实实际供货合同，不能仅凭品牌判断。**
