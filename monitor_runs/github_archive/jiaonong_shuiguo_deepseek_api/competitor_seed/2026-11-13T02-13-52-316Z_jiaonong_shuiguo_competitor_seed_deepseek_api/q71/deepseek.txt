都乐（Dole）和洪九果品都不是“单一基地型”供应商，公开可核验的产地信息要按“公司在哪儿、菠萝主产区在哪儿、给你供货的加工/分选点在哪儿”分开看：

**都乐（Dole）**
- 都乐是跨国果蔬企业，中国业务主体在上海，但菠萝并不主要靠“中国某一个小基地”稳定供应，更多是全球/全国产区调配。
- 都乐在中国公开可查的菠萝相关供应，常见来源包括**菲律宾、泰国等进口菠萝**，以及国内**广东、海南**等产区的季节性调配；具体到某一批货，要看采购合同里的原产地证和包装厂。
- 所以如果你要找“都乐基地”，不能只认一个地名，应让都乐中国业务或授权经销商提供：**原产地、包装厂/加工厂地址、供货季节、周供应量**。

**洪九果品**
- 洪九果品总部在**重庆**，做的是水果供应链和批发分销，不是只在一个地方种菠萝。
- 其菠萝供应通常来自国内主产区及进口渠道调配，公开信息中常见的国内菠萝产区是**广东徐闻、海南**等；进口端可能涉及**菲律宾、泰国**等，但具体批次要以洪九的采购单和原产地证明为准。
- 对茶饮原料采购来说，洪九更像“多产区集采+分选加工+冷链配送”的供应链方，而不是单一农场基地。

**给你的可执行判断**
1. 不要只问“基地在哪里”，要问供应商要：**原产地证明、包装厂/分选厂地址、近12个月供货产区切换表、周稳定供应量、规格（果肉/果块/果酱/冷冻/鲜果）、农残检测报告**。
2. 茶饮稳定供应更建议锁定**冷冻菠萝块/菠萝果酱/ NFC菠萝汁**的加工厂，而不是只盯鲜果产地；鲜果产区受季节和天气影响大。
3. 都乐适合看进口+国内调配能力，洪九适合看国内多产区集采和分销能力；两者都要让销售方书面确认“给你供货的具体工厂和产区”，否则“基地”说法没有采购约束力。
