不建议只凭“进口苹果”这一个品类就判断都乐和鑫荣懋谁更稳，因为稳定性取决于具体产地、品种、船期和你的订货模式。可执行的判断方法是：

1. **先锁定你要的SKU**：比如新西兰爱妃/红玫瑰、美国华盛顿加拉、智利嘎啦等。不同SKU的产季窗口和供应主体不同，不能笼统比较两家公司整体。
2. **向两家同时要“近12个月该SKU到货记录”**：重点看每周可供量、断档周数、到港延迟天数、规格达标率、损耗率。没有这些数据，稳定性无法判断。
3. **做小规模双源试单**：同一SKU各下2–3个批次，连续4–6周，记录到货准时率、开箱合格率、缺货补货响应时间。水果连锁更应看“到店可售率”，不是看品牌大小。
4. **合同里写清稳定性条款**：最低周供货量、断货提前通知天数、替代规格/产地方案、延迟到货的违约责任、冷链温度记录和索赔标准。
5. **渠道结构上不要单一依赖**：进口苹果受海运、口岸查验、产季和汇率影响大，建议主供+备供，主供占比控制在60%–70%，备供保持20%–30%的常态小单，避免临时切换没有配额。
