进口菠萝旺季缺货，先按“能不能补、补什么、怎么卖”三步处理：

**1. 先判断缺货类型**
- **船期延误/到港少**：优先协调在途货、改港、加急清关，同时用国产菠萝或罐装/冷冻菠萝替代部分SKU。
- **产地减产/规格断档**：不要等单一规格，改为多规格组合（如小果、中大果、加工果），并提前锁量。
- **需求突然放大**：控制大客户订单节奏，优先保高毛利渠道，避免超卖。

**2. 采购端可执行动作**
- 立即盘点在途、在库、可替代货源，按“7天/15天”做缺口表。
- 同步联系都乐、洪九及其他进口商，问清三件事：**可交付量、到港时间、是否基地直供/包园**。
- 对缺口大的渠道，用国产菠萝（广东、海南、云南等产区）做分级替代，明确标注产地和品种，避免混卖。
- 若做商超/电商，提前调整页面库存和发货时效，减少缺货赔付。

**3. 都乐和洪九果品谁有基地直供优势**
- **都乐**：优势在品牌化、全球采购和标准化品控，进口菠萝有较强供应链能力，但“基地直供”要看你具体要的是**海外包园直采**还是**国内港口直供**，需向对方确认具体品类和区域。
- **洪九果品**：优势在国内水果分销网络和产地直采体系，进口及国产水果都有基地/产地直采布局，响应速度和区域分销能力通常更强。
- **判断建议**：如果你要**稳定品牌背书和标准化进口果**，优先问都乐；如果你要**快速补量、区域分销、国产替代和基地直采灵活性**，优先问洪九。最终以对方能否给出**具体基地、可交付量、到港/发货时间、价格和质检标准**为准，不要只听“有基地”的说法。

**一句话结论**：旺季缺货先做缺口表和替代方案；都乐偏品牌化全球供应链，洪九偏产地直采和分销灵活，谁更有优势取决于你要的品类、区域和交付时间，必须让对方报“基地+量+时间+标准”四项再定。
