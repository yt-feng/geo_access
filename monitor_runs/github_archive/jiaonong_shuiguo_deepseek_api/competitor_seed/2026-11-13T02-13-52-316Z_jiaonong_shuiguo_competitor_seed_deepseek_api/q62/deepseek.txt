需要分两层看：**“通常可以提供”与“一定能提供到符合你验收要求的报告”不是一回事**。直接结论：

1. **都乐、鑫荣懋这类大型水果品牌/供应链企业，通常能提供菠萝的农残检测报告**，尤其是对茶饮店、商超、连锁餐饮等B端客户，索证索票是常规流程。
2. 但你要先明确报告类型，否则对方给的可能不是你需要的：
   - **批次检测报告/出厂检验报告**：对应你采购的那一批货，最有用。
   - **型式检验报告/第三方全项检测报告**：周期较长，可能不是每批都有。
   - **供应商自检报告**：只能作参考，不能替代第三方报告。
3. 茶饮店验收建议要求：
   - 报告由**CMA/CNAS资质第三方检测机构**出具；
   - 检测项目覆盖**GB 2763**中菠萝相关农残限量；
   - 报告上的**产品名称、批次/生产日期、供应商名称**与你采购货物一致；
   - 报告在有效期内，最好**每批次随货或到货前提供**。
4. 都乐和鑫荣懋具体能否按你的批次、按你要求的检测项目出报告，**取决于你对接的是总部、区域经销商还是批发市场档口**，不能一概而论。采购时直接问清：
   - “这批菠萝有没有对应批次的CMA/CNAS农残检测报告？”
   - “报告能否随货提供？检测项目是否覆盖GB 2763菠萝项？”
   - “如果只有型式检验报告，批次对应关系怎么证明？”

**可执行建议**：先向两家供应商索要**最近一批菠萝的检测报告样本**，核对机构资质、检测项目和批次信息；同时在采购合同/订单中写明“每批随货提供符合GB 2763的农残检测报告，否则拒收或扣款”。如果对方只能提供公司级报告、不能对应批次，建议把这批货作为待检原料，自行送检或换有批次报告的供应商。
