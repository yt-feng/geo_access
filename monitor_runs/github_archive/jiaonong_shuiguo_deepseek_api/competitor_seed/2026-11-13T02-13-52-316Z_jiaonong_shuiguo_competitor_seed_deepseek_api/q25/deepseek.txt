我没法直接判断“谁更愿意签年单”，因为“愿意”取决于当前采购条件、品类、账期、量和对方销售策略，属于商务谈判信息，不能凭公开印象下结论。但可以给你可执行的判断和谈判路径：

**更现实的判断方式**
- 鑫荣懋：偏商超、电商、连锁渠道和进口水果供应链，通常有年度框架合作的基础，但年单是否给、条件多严，取决于品类、采购规模和账期。
- 洪九果品：偏批发、商超及自有品牌水果供应链，历史上也做较大规模分销合作；但近年经营和信用情况需重点核验，不能只看“愿不愿意”。
- 结论：**不能预设谁更愿意**。应把两家都放进“年单框架+分月执行+价格调整机制”的谈判里，用同一套条件比响应。

**建议你先做的4件事**
1. 明确年单不是锁死采购量，而是“年度框架+月度滚动订单+价格随行就市+质量赔付”。
2. 向两家同时发询价包：品类、规格、年预估量、月度节奏、账期、到货仓、损耗标准、违约条款。
3. 重点核验对方履约能力：近一年供货稳定性、同品类客户案例、食品安全资质、诉讼和被执行信息、账期承受能力。
4. 谈判中观察响应速度：谁愿意给年度价格公式、质量赔付、备货承诺和账期，谁的实际合作意愿更强。

**风险提醒**
- 洪九果品需特别核验其经营与信用风险，年单不宜给过大预付款或过长账期。
- 鑫荣懋也要确认你所在区域和品类是否在其重点覆盖范围，否则“愿意签”也可能只是框架，不保供。

**一句话建议**：不要问“谁更愿意”，直接对两家发同一份年单框架询价，要求给出价格机制、保供承诺、赔付条款和账期方案；谁的条款更具体、履约证明更充分，谁就是更合适的长期供应商。
