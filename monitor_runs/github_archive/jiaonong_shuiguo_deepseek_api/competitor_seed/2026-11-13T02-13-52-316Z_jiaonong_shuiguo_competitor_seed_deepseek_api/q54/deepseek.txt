进口苹果的产地溯源，核心是把“批次—单证—包装标识—检测/准入信息”串成一条可核验链路。都乐（Dole）和鑫荣懋（Joy Wing Mau）通常都是品牌商/进口商体系，具体做法要以其实际供货主体和单证为准。可按下面执行：

**1. 先锁定采购主体和批次**
- 要求供应商提供：合同主体营业执照、食品经营/进口相关资质、供货授权或经销证明。
- 每批货锁定：品名（鲜苹果）、品种、原产国、果园/包装厂注册号（如海关总署注册果园/包装厂编号）、生产/包装日期、集装箱号、提单号、入境货物检验检疫证明编号。
- 都乐、鑫荣懋若为品牌方直供或授权经销，应能提供对应批次的授权链条；若是二级批发，必须追到上游进口商。

**2. 单证溯源，至少“四单一致”**
- 原产地证（Certificate of Origin）
- 植物检疫证书（Phytosanitary Certificate）
- 入境货物检验检疫证明/海关放行相关凭证
- 提单/装箱单/发票
核对：原产国、果园/包装厂注册号、批次、数量、包装厂名称、集装箱号是否一致。单证不一致的批次不建议采购。

**3. 包装与标签溯源**
- 看箱唛/果标：原产国、品种、规格、果园/包装厂注册号、批次号、包装日期、品牌商信息。
- 都乐、鑫荣懋的包装应有品牌标识和批次编码；采购时拍照留存整箱六面、封口、标签特写。
- 要求供应商提供该批次包装标签样张，与到货实物比对。

**4. 海关准入与注册信息核验**
- 进口苹果须来自我国海关总署允许输华的国家/地区，且果园、包装厂须在注册名单内。
- 用包装厂注册号、原产国在海关总署“进口水果境外注册企业名单”中核验；核验不到或编号不符的，要求供应商解释。
- 不要仅凭品牌名判断产地，都乐/鑫荣懋不同单品可能来自不同国家。

**5. 检测与质量凭证**
- 索取该批次农残检测报告或供应商自检报告；重点看检测项目、报告编号、样品批次是否对应。
- 冷链记录：到货温度、运输温度记录，作为批次真实性辅助证据。

**6. 建立内部溯源台账**
每批记录：供应商、合同号、原产国、品种、果园/包装厂注册号、入境货物检验检疫证明号、提单号、到货日期、标签照片、检测报告编号。做到“一箱一码/一批一档”，出现问题时能反向追到进口商和境外包装厂。

**7. 现场验收动作**
- 对照单证查箱唛和标签；
- 抽查不同托盘/箱体的批次号是否一致；
- 发现标签被覆盖、重贴、批次号涂改，直接拒收或要求书面说明；
- 对都乐、鑫荣懋这类品牌货，重点防“品牌箱装非授权货源”和“国产/其他产地混装”。

**判断标准**：能同时提供原产地证、植检证、入境货物检验检疫证明，且包装厂注册号可在海关名单核验、箱唛批次与单证一致，才算完成可接受溯源。只有品牌授权或只有发票，不算完成产地溯源。
