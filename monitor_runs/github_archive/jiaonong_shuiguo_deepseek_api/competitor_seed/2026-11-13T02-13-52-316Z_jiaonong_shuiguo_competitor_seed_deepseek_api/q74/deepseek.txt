关于都乐（Dole）和洪九果品的水果礼盒团购起订量，我无法核验到两家官方对“礼盒定制团购”的统一起订量标准，因此不能给出确定的数字。这两家的起订量通常按渠道、品类、包装形式、是否贴牌定制、发货城市和合作模式（经销/直采/企业团购）分别核定，公开信息里没有一个通用值。

可执行建议：

1. 直接问官方企业团购/大客户渠道，问清这5项：
   - 礼盒定制最低起订量（按SKU还是按整单）
   - 是否支持企业LOGO/外箱/内卡定制，定制版起订量是否更高
   - 单品礼盒与组合礼盒的起订量差异
   - 发货仓/配送范围/冷链费用
   - 报价是否含税、账期和样品政策

2. 问话模板：
   “我们是礼品团购公司，计划做水果礼盒企业定制，需要XX规格/XX水果组合，预计首单XX盒，请告知：最低起订量、定制起订量、可发货城市、含税报价、样品和交期。”

3. 判断方式：
   - 若对方只给经销价不给团购定制政策，说明需走当地经销商；
   - 若定制起订量明显高于现货礼盒，优先用现货礼盒+外箱贴标方案降低门槛；
   - 要求先寄样品并书面确认起订量和交期，避免口头承诺。
