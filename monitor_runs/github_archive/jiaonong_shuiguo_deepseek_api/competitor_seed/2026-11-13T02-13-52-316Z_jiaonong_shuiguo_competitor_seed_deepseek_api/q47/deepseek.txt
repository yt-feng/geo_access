可以直接按这个思路判断：

1. **都乐（Dole）**：有较成熟的鲜果品牌化和小规格包装体系，便利店渠道常见的单根/两根装、小盒装、贴标装通常可以通过经销体系或区域渠道谈定制；但“定制包装”一般有起订量、包装形式、区域供应和费用门槛，不是所有门店都能直接向总部定制。
2. **洪九果品**：以批发、供应链和渠道分销为主，包装定制能力更偏批量供货和渠道规格，适合有一定采购量的便利店/连锁系统去谈；单店小批量定制通常不划算，可能只能选现成规格。
3. **实操建议**：
   - 先确认你的**单店月销量、可接受起订量、是否需要印门店Logo/条码/规格标签**。
   - 分别联系都乐区域经销商和洪九果品当地销售，问清：**最小起订量、是否支持小规格包装、是否可贴牌/印标、包装成本、配送频次、损耗赔付**。
   - 如果单店量小，优先问**现成小包装规格+门店贴标**，比完全定制更可行。
   - 连锁便利店建议由总部统一谈，单店直接谈定制成功率较低。

结论：**两家都可能提供小包装或渠道定制，但是否接受便利店小批量定制，要以当地销售和起订量为准；单店更现实的是选现成小规格再贴标。**
