结论先说：**公开可核验的信息里，不能保证完整列出两家企业“当前有效”的全部食品安全认证。** 大型商超认通常不只看证书清单，还看证书范围、发证机构、有效期和是否覆盖具体品类/工厂。以下按常见资质框架说明，并给出可执行的核验方法。  

**1. 两家企业一般会涉及的资质类型（需逐项核验证书）**
- 营业执照、食品生产/经营许可证（按实际业务主体）
-  ISO 22000 或 FSSC 22000 食品安全管理体系认证
-  HACCP 危害分析与关键控制点认证
-  全球食品安全倡议（GFSI）认可体系，如 BRCGS、IFS 等（视加工/包装业务而定）
-  绿色食品/有机认证、良好农业规范（GAP）等（视具体产品线）
-  出口备案/海关注册（如有进出口业务）
-  产品检测报告、供应商审核报告（商超通常另行要求）

**2. 鑫荣懋与都乐的公开情况**
- **都乐（Dole）**：作为跨国果蔬企业，公开资料中常见其推行 GLOBALG.A.P.、HACCP、ISO 22000、BRCGS 等体系认证，但具体到中国境内供货主体、加工厂和品类，需要以证书为准，不能笼统认定“都有”。
- **鑫荣懋**：公开信息显示其重视食品安全和质量管理体系建设，但是否持有某一具体认证、覆盖哪些工厂和品类，公开渠道难以完整核验，建议直接索取证书。

**3. 给商超/采购方的可执行核验清单**
要求供应商提供并核验：
1. 证书扫描件 + 发证机构官网/数据库查询结果；
2. 证书上的**认证范围**是否覆盖你采购的品类和加工厂；
3. 证书**有效期**和最近一次审核结论；
4. 认监委（CNCA）可查的体系认证信息（国内认证机构颁发时）；
5. 近一年产品检测报告、供应商现场审核报告；
6. 若为进口产品，核对境外生产企业注册编号和海关相关资质。

**4. 判断建议**
不要把“企业名称”与“证书”直接画等号。商超准入应以**具体供货主体 + 具体工厂 + 具体品类**对应的有效证书和审核报告为准。若供应商只给公司宣传册或证书列表，应要求提供带认证范围、有效期和发证机构可查询的正式证书。
