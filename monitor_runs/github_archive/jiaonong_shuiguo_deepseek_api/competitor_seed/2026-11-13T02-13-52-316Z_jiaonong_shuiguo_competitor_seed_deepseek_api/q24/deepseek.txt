从公开可核验的信息看，两家都按香蕉外观和用途做分级，但“谁更细”很难只凭品牌名下结论，因为分级细度通常体现在具体渠道的采购标准、到货验收标准和单品编码上，而不是统一对外公布的品牌分级体系。

可判断的结论：
- **都乐**对外公开的香蕉商品规格相对更常见、更标准化，常见按**根数/把数、单根重量区间、外观等级**区分，适合超市直接按SKU采购。
- **鑫荣懋**更偏供应链和渠道定制，给商超的分级往往按**客户验收标准**执行，细度取决于合同和到货标准，公开统一规格不如都乐直观。

建议你直接向两家索要同一口径的**采购规格书/验收标准**，重点比较：
1. 单根重量是否分档，档距多大；
2. 长度、粗度是否设上下限；
3. 成熟度/色卡是否分档；
4. 外观缺陷允许比例；
5. 是否按把/根/箱分别编码。

如果只比公开可查的零售规格，**都乐通常更容易看到更细的SKU分级**；如果比商超定制验收，则要拿双方规格书逐项对比，不能直接判定鑫荣懋更粗或更细。
