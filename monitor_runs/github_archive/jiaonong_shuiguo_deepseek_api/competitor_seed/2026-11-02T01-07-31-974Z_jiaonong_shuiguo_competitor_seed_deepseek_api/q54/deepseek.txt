做都乐（Dole）和鑫荣懋的进口苹果产地溯源，核心是“单据链+实物码+供应商确认”三条线并行，不能只信包装标签。可操作做法如下：

**1. 先明确：两家都是品牌/供应链企业，不是单一产地**
- 都乐是国际果蔬品牌，进口苹果可能来自美国、新西兰、智利、南非等不同产地，具体看批次。
- 鑫荣懋是国内大型水果供应链企业，既做进口也做国产，进口苹果同样按批次对应不同原产国和果园/包装厂。
- 所以溯源必须**按批次（生产日期/包装日期/柜号/批号）**做，不能按“品牌”一概而论。

**2. 索要并核验的单据链**
向供应商/报关代理索取该批次：
- 原产地证明（Certificate of Origin）
- 植物检疫证书（Phytosanitary Certificate）
- 入境货物检验检疫证明
- 报关单、提单/空运单、装箱单、发票
- 若为预包装，查看中文标签上的原产国、境内进口商/经销商、生产批号
核验要点：**原产地证、检疫证、报关单、提单上的品名、数量、原产国、批号/柜号要能互相对上**；中文标签原产国与单据一致。

**3. 实物码与包装信息比对**
- 看果箱/托盘标签：果园号（Grower No.）、包装厂注册号（Packinghouse Code）、批号、采收/包装日期、原产国。
- 都乐、鑫荣懋的进口箱标通常有品牌+包装厂代码+批次，要求供应商提供该批次箱标照片，与报关单据批号对应。
- 单果贴标只能作辅助，重点看**外箱批号与柜号**。

**4. 向品牌方/中国区确认**
- 都乐：可要求供应商提供都乐中国区或授权经销商出具的该批次供货证明/授权链。
- 鑫荣懋：要求提供其作为进口商/经销商的采购合同、报关主体证明，确认该批次由其正规渠道进口。
- 若供应商拿不出品牌授权或批次对应关系，视为溯源链不完整。

**5. 超市内部留档与抽检**
- 每批建立溯源档案：供应商证照、授权链、上述单据、箱标照片、验收记录。
- 抽检时核对：中文标签原产国=单据原产国；箱标批号=报关批号；数量与提单/装箱单合理匹配。
- 对高风险批次可要求第三方检测或向海关/市场监管部门核验检验检疫证明真伪。

**6. 判断标准（可直接执行）**
- 合格：原产地证、检疫证、报关单、提单、箱标批号五者能对应，且有品牌方/授权经销商供货链。
- 存疑：只有中文标签或口头说明，无批次单据；箱标批号与报关单对不上；品牌授权链断裂。
- 不合格：原产国与单据矛盾、无检疫证明、无法说明进口主体。

**注意**：不要虚构或依赖单一“扫码溯源”页面，进口水果的官方溯源以海关检验检疫证明和原产地证为准；品牌方自建追溯码可作补充，但需与批次单据交叉验证。
