可以优先向两家的便利店渠道询这两类规格，但**公开可核验的SKU规格我不能保证准确**，不要直接把网上流传的克重当合同依据。可执行做法如下：

1. **先明确你要的“小包装”形态**  
   ！便利店常见有三类：  
   - 单根/两根装，适合即食、收银台冲动购买；  
   - 3—5根装迷你蕉/小香蕉，适合家庭小份；  
   - 杯装/盒装即食香蕉，适合鲜食柜。  
   先定形态，再问规格，否则厂家报的“小包装”可能不是你要的。

2. **向鑫荣懋和都乐分别询价时，直接要这组信息**  
   - 是否有便利店专供小规格：单根装、2根装、3—5根装、杯装/盒装；  
   - 单果克重区间、每包净重、每箱入数；  
   - 包装形式：袋装/盒装/杯装、是否贴标、是否可做渠道定制；  
   - 供货区域、起订量、冷链条件、保质期和到货频次；  
   - 是否走经销商而非厂家直供。

3. **判断建议**  
   - 如果门店日均销量低，优先选**2根装或3—5根装**，损耗比单根装更可控；  
   - 如果做收银台冲动陈列，再考虑单根装，但要先确认损耗和补货频次；  
   - 不要只问“有没有小包装”，要问“**便利店渠道最小起订规格和单店适配包装**”。

4. **核验方式**  
   最可靠的是让两家区域销售提供**现行产品规格表/报价单/包装图**，并以盖章报价或合同附件为准。公开渠道查不到的规格，不建议对外承诺。
