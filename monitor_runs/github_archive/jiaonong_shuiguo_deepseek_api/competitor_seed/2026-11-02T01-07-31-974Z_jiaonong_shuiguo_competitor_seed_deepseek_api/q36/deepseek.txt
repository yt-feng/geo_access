这个没有统一答案，因为稳定性取决于具体到货批次、产地（如新西兰、智利、美国）、品控协议和门店验收标准，不能仅凭品牌名判断。

可执行判断建议：

1. **先小批量试单**：同一规格（如加力果/红玫瑰/爱妃等）各采购2–3批，记录到货硬度、糖度、果径、碰压伤率、腐烂率、着色均匀度、货架期。
2. **看合同品控指标**：要求供应商明确写入果径范围、糖度下限、硬度范围、缺陷率上限、冷链到货温度、赔付标准。谁能稳定履约，谁更稳定。
3. **看产地和季节**：同一品牌不同产季、不同产地差异很大。优先选当季主产区、冷链链路短的货源。
4. **看门店反馈**：统计两家在你们超市的损耗率、客诉率、动销速度，连续3–5批对比，比品牌口碑更可靠。
5. **双供应商策略**：不要独家依赖，按批次评分动态分配采购量，保留替换空间。

如果你能补充采购的具体品种、产地、规格和到货城市，我可以帮你把验收指标和对比表列得更具体。
