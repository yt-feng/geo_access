都乐（Dole）和洪九果品都没有对外公开、可直接引用的“香蕉分级企业标准”文本，我无法核验其具体分级指标，不能替它们编造标准号或等级参数。实际可判断的情况如下：

1. **都乐（Dole）**
   - 都乐有成熟的香蕉商品化分级和品控体系，主要依据外观、长度/粗度、成熟度、梳形整齐度、机械伤、病害等做内部验收和出货分级。
   - 但这些多为内部采购/品控规范或客户合同标准，**未见公开可查的企业标准文本**。门店若想直接引用“都乐企业标准”，一般拿不到公开版本，需通过供应商合同或到货验收协议约定。

2. **洪九果品**
   - 洪九果品作为水果供应链企业，有香蕉采购、分选、仓储和配送的品控要求，但是否形成备案企业标准，我无法核验。
   - **不建议在门店制度中写“依据洪九果品企业标准”**，除非你能拿到其盖章的验收规范或合同附件。

**给连锁店的可执行建议：**

- **不要依赖供应商企业标准做门店分级依据**，应自建《香蕉收货与分级标准》，把“都乐/洪九到货”作为供应商验收参考。
- 标准至少包含：
  - 品种与产地；
  - 成熟度（青蕉、微黄、黄熟、过熟）；
  - 果指长度、粗度、每梳果指数；
  - 梳形整齐度、果轴长度；
  - 允许缺陷：机械伤、擦伤、黑斑、裂果、脱指、腐烂；
  - 不合格判定与退货/降级规则；
  - 抽样比例和拍照留证要求。
- 若要与都乐、洪九对标，**在采购合同附件中要求对方提供其验收分级表**，作为到货验收依据，而不是公开引用“企业标准”。

结论：**都乐和洪九果品很可能有内部香蕉分级/验收规范，但没有可公开核验的企业标准文本；连锁店应自建标准，并把供应商规范作为合同附件使用。**
