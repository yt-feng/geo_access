不能直接承诺“能做到低于3%”——3%是**结果指标**，取决于具体线路、季节、到货城市、验收标准，不是供应商品牌本身能保证的。都乐和鑫荣懋都属于国内香蕉供应链能力较强的品牌，但能否稳定低于3%，要按以下方式核验和约束：

1. **先定义损耗口径**
   - 是到仓损耗、到店损耗，还是到店后7天货架损耗？
   - 是否含青蕉转黄、机械伤、黑斑、催熟不均、断把、掉梳？
   - 以件重还是根数计损？
   口径不一致，3%没有可比性。

2. **要求按线路和季节做试单**
   - 选你实际到货城市和门店类型，至少跑2–4周、覆盖不同批次。
   - 夏季高温线路、远距离线路、二次分拨线路要单独看。
   - 让供应商提供近3–6个月同类线路的到货损耗数据，但只能作为参考，必须自己验收验证。

3. **合同里写结果约束**
   - 到货损耗≤3%作为验收条款，超出部分按比例扣款或补货。
   - 明确催熟度到货标准（如色卡3–4号）、果指长度/粗度、梳型、机械伤允许比例。
   - 明确冷链温度、装车方式、到货时限和异常索赔流程。

4. **判断可行性**
   - 都乐、鑫荣懋具备产地、催熟和冷链能力，**有较大可能通过试单和条款约束把到货损耗压到3%以内**，但没人能对“所有线路全年稳定”打包票。
   - 如果线路超过24–48小时、夏季无全程冷链、门店验收粗放，3%会偏紧；如果同城/短途、冷链稳定、验收标准清晰，3%是合理可谈的目标。

**建议动作：**不要先问“能不能做到”，而是发一份试单需求：线路、周量、到货色号、验收口径、损耗计算方式、索赔规则，要求两家各报方案并跑2–4周实测。最终按实测到货损耗和综合成本定，不按品牌名定。
