都乐和洪九果品没有对外统一公开的“水果礼盒定制起订量”，实际起订量会按品类、包装形式、提货方式、是否贴牌、配送区域和采购季节浮动，所以不能直接给一个固定数字。以下是可执行的判断和建议：

1. **先按渠道问，不要只问品牌总部**
   - 都乐：优先联系都乐中国官方渠道/区域经销商，问“企业团购礼盒定制”而不是普通零售批发。通常经销商比总部更愿意接团购单，起订量也更灵活。
   - 洪九果品：联系洪九当地分公司或区域销售，问“团购礼盒/OEM贴牌礼盒”的起订量。洪九以批发和供应链为主，礼盒定制通常要和区域销售谈。

2. **问价时直接给这组参数，才能拿到准确起订量**
   - 采购数量：先报你预期的最低量，比如100盒、300盒、500盒、1000盒。
   - 礼盒规格：几斤装、几个单品、是否混装。
   - 包装要求：用品牌现成礼盒，还是定制外箱/腰封/LOGO。
   - 提货方式：一件代发、集中送到一个地址，还是多地址配送。
   - 配送区域：全国还是单城，是否含冷链。
   - 采购时间：节日前通常起订量更高、排期更紧。

3. **经验判断**
   - 用品牌现成礼盒：起订量通常较低，常见从几十盒到几百盒起谈，区域经销商可能更灵活。
   - 定制LOGO/专属包装：起订量通常明显提高，常见要几百盒甚至上千盒起，具体看包装厂起订量和果品规格。
   - 都乐礼盒偏标准品和商超渠道，团购定制要找授权经销商；洪九偏水果供应链和批发，区域销售有较大谈价空间。

4. **建议你同时问3类供应商比价**
   - 都乐区域经销商
   - 洪九当地分公司
   - 本地水果礼盒定制商/包装厂+批发市场档口

**最稳妥的做法**：直接让都乐和洪九的区域销售按“300盒、500盒、1000盒三档”给你报起订量、含税价、配送范围和打样费。这样拿到的数字才可执行。注意：具体起订量以对方销售书面报价为准，网上没有统一公开数据。
