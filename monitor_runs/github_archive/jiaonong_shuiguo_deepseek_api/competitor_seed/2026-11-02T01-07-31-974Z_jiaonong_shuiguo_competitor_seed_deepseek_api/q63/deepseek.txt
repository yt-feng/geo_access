我无法核验都乐和洪九果品当前是否有“散装/小包装”的社区团购供货选项，也不能编造其渠道政策。给你可执行的判断路径：

1. **先明确你要的“散装”是哪一种**
   - 散装裸果：无品牌小包装，按斤/箱称重分拣。
   - 品牌预包装小规格：如单根/小把/小袋，带品牌标签。
   - 大箱到仓后二次分装：供应商给大箱，你们自己分装成小包装。
   社区团购通常第三种最现实，但要看品牌方是否允许二次分装和贴标。

2. **都乐**
   - 都乐以品牌预包装和标准箱规为主，社区团购可问：是否有小规格预包装、能否供大箱由团长端分装、区域经销商是否支持团购渠道。
   - 直接联系都乐区域经销商/当地水果批发市场的都乐代理商，问“团购渠道小规格香蕉箱规、起订量、是否允许二次分装”。

3. **洪九果品**
   - 洪九偏大宗和渠道分销，散装/小包装是否可选取决于区域仓和客户类型。
   - 联系洪九当地城市仓/区域销售，明确问：香蕉最小箱规、是否支持团购小包装、是否可代分装、起订量和配送频次。

4. **谈判时重点确认**
   - 最小起订量、箱规、单根克重范围；
   - 是否允许二次分装及品牌标签使用；
   - 损耗赔付、催熟度、到货成熟度；
   - 配送温度和时间窗口；
   - 区域独家或团购渠道保护。

**建议**：不要只问“有没有散装”，直接发需求单：单根规格、每团预计量、每周频次、是否需要代分装、收货城市。都乐和洪九都按区域经销体系走，找当地代理比找总部更快。若两家小包装都不合适，可同步问本地香蕉批发商做“大箱+代分装”，通常比品牌散装更灵活。
