这个问题我没法给你一个可靠的“对比数字”。洪九果品和都乐的到货损耗率都不是公开披露的稳定指标，会随批次、季节、运输距离、温控和你的验收标准大幅波动；我若给具体百分比就是编造。下面给你可执行的判断和做法。

**1. 先明确“损耗率”口径**
批发拿货建议分三段统计，否则数字没有可比性：
- 运输损耗：发货重量 vs 到货重量
- 验收损耗：到货后挑出的坏果、青果、机械伤
- 上架/催熟损耗：香蕉催熟后报废和失水

**2. 两家品牌的现实差异（定性，不给假数字）**
- 都乐：标准化程度高，香蕉多为品牌催熟/冷链体系，批次一致性通常更好，但价格和起订门槛更高；损耗更多取决于你拿的是“已催熟即卖”还是“青蕉自催”。
- 洪九果品：品类宽、渠道覆盖广，香蕉批次差异可能更大，价格弹性也更大；到货损耗高度依赖具体产区、季节和承运方式。
- 结论：不能笼统说谁损耗低，必须按“同一季节、同一规格、同一运输方式、同一验收标准”做批次对比。

**3. 你直接可做的对比方法**
连续拿 3–5 批，每批记录：
- 发货净重、到货净重、验收合格净重
- 坏果率、青果率、机械伤率、催熟后报废率
- 到货温度记录、运输时长
- 单价 + 损耗折算后的“可售成本/斤”

公式：可售成本/斤 = 拿货单价 ÷（1 − 综合损耗率）。用这个比价格才有意义。

**4. 谈判和验收建议**
- 合同写明到货验收标准、允许损耗上限、超标扣款或补货
- 到货当场抽箱称重并拍照留证
- 香蕉重点看：果指饱满度、条蕉整齐度、机械伤、催熟均匀度
- 先小批量试单，不要一次压大货
