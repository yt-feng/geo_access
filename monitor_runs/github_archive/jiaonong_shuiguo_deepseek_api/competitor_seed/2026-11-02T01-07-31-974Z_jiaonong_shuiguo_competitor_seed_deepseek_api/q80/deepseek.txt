结论先说：**在中国超市渠道做“进口苹果”的品牌背书，都乐（Dole）的品牌知名度更高、消费者认知更广；鑫荣懋（Joy Wing Mau）更强在供应链和渠道能力，但作为“面向消费者的品牌”声量不如都乐。**

可判断的依据：

1. **都乐是全球化水果品牌**
   - 都乐是国际水果品牌，长期做香蕉、菠萝、苹果等品类的消费者品牌建设，包装和终端识别度高。
   - 对超市采购来说，都乐更容易直接用作“进口水果品牌背书”，消费者看到品牌名有感知。

2. **鑫荣懋是供应链/渠道型龙头**
   - 鑫荣懋是国内大型水果供应链企业，渠道覆盖和进口运作能力强，旗下也有佳沃等品牌体系。
   - 但“鑫荣懋”本身更偏 B 端企业品牌，普通消费者在苹果包装上不一定有强品牌认知。

3. **采购建议**
   - 如果你要的是**终端消费者一眼认品牌、降低解释成本**：优先选都乐。
   - 如果你要的是**稳定供货、进口操作能力、渠道配合**：鑫荣懋很强，可以合作，但最好搭配具体产品品牌或产地卖点，而不是只靠“鑫荣懋”三个字做消费者背书。
   - 实际采购可做双轨：**都乐做品牌引流款，鑫荣懋做供应链/性价比款**，比单押一个更稳。

简单说：**品牌响度选都乐，供应链能力看鑫荣懋。**
