关于都乐和洪九果品的菠萝锁价周期，我无法核验到公开、可引用的官方数据，不能给出具体天数，避免误导。可以给你可执行的判断和谈法：

1. **锁价周期通常不是公开标准品参数**  
   菠萝锁价多出现在大客户/商超/餐饮供应链合同里，周期按品类、产地、季节、采购量、付款方式单独谈，公开渠道一般查不到统一“X天/月”政策。

2. **向供应商确认时直接问这4个字段**  
   - 锁价基准：以哪个市场/产地/规格的报价为基准  
   - 锁价时长：7天、15天、30天还是按季度  
   - 触发调整条件：产地价涨跌幅超过多少可调价  
   - 锁量义务：锁价是否绑定最低采购量、违约处理

3. **都乐/洪九的核实路径**  
   - 都乐：联系都乐中国官方销售/大客户渠道，问“菠萝大客户锁价协议政策”，要求书面报价条款。  
   - 洪九果品：联系其区域销售或供应链商务，问“菠萝单品锁价周期及调价机制”，同样要书面确认。  
   不要依赖经销商口头承诺，锁价必须写进合同附件。

4. **替代供应商建议**  
   可同时找产地一级批发商、大型果蔬供应链公司、连锁商超供应商询价，通常比品牌方更灵活；锁价周期常见谈判区间可从7—30天起谈，但具体以对方书面报价为准。

**结论：都乐和洪九果品菠萝锁价周期没有可核验的公开统一数据，需向官方大客户渠道索取书面锁价条款；谈判时重点锁定基准价、周期、调价触发条件和最低采购量。**
