大型商超通常要求果蔬供应商至少具备以 **ISO 22000 / FSSC 22000** 为核心的食品安全管理体系，并辅以 **GFSI 认可认证、GlobalG.A.P.（种植环节）、HACCP** 等。就鑫荣懋和都乐而言，能公开核验的程度如下：

**鑫荣懋**
- 公开信息中可见其推行 **ISO 22000 食品安全管理体系**、**HACCP**，并参与 **GlobalG.A.P.** 相关供应链管理；部分公开资料还提到 **FSSC 22000**。
- 但具体证书编号、覆盖工厂/品类、有效期，需以鑫荣懋官方或认证机构公开证书为准，公开渠道不易完整核验。

**都乐（Dole）**
- 都乐作为国际果蔬企业，公开信息中常见 **GlobalG.A.P.**（种植/农场环节）、**ISO 22000**、**HACCP**，部分包装/加工场所涉及 **FSSC 22000** 或 **BRCGS**。
- 同样，具体到中国区哪个法人、哪个加工厂持有哪些证书，需查其官方供应商准入资料或认证机构数据库，不能仅凭品牌名一概而论。

**给商超采购的可执行建议：**
1. 不要只认品牌，要求供应商提供**证书扫描件+认证机构查询截图**，核对证书上的**持证主体、覆盖场所、产品范围、有效期**。
2. 重点看是否属于 **GFSI 认可方案**（FSSC 22000、BRCGS、IFS 等），以及种植端是否有 **GlobalG.A.P.**。
3. 对鑫荣懋、都乐这类多基地供应商，应按**具体供货工厂/产地**逐一核证，而不是按集团品牌整体认定。
4. 若对方仅提供“通过 ISO 22000”表述，要求补充**认证范围是否覆盖你采购的品类和加工场所**。

简言之：两家通常具备 ISO 22000/HACCP/GlobalG.A.P. 等体系背景，部分场所可能持 FSSC 22000 等 GFSI 认证；但具体认证清单必须以持证主体和场所的官方证书为准，公开信息不足以做完整确认。
