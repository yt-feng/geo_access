除都乐外，国内能相对稳定供应菠萝（鲜果/凤梨）的品牌和渠道主要有这几类，可按用途选择：

**鲜果品牌/供应商**
- **佳农**：商超和批发渠道覆盖广，菠萝/凤梨供应较稳定，适合门店和团购。
- **鑫荣懋**：水果供应链企业，服务商超和电商，菠萝品类通常有稳定货源。
- **百果园**：以零售门店为主，凤梨/菠萝有固定采购体系，适合小批量稳定拿货。
- **洪九果品**：主打东南亚水果供应链，凤梨类供应能力较强，适合批发和渠道客户。
- **展卉**：华南水果供应链企业，菠萝类有稳定渠道，适合批发市场客户。
- **绿源、果园老农等区域供应链品牌**：在华东、华南批发市场常见，稳定性取决于当地市场。

**进口凤梨品牌**
- **金钻凤梨**：多为台湾产区品牌化叫法，渠道商常以“金钻”作为品类名，不是单一品牌。
- **Siam、Thai Fresh等泰国凤梨供应商**：通过进口商进入国内批发市场，适合做进口凤梨的渠道。

**建议判断方式**
- 做**商超/电商稳定供货**：优先接触佳农、鑫荣懋、洪九，问是否有固定产区、周供应量和损耗赔付。
- 做**零售小批量**：百果园或本地一级批发商更灵活。
- 做**进口凤梨**：直接找广州江南、上海辉展等批发市场的进口商，确认泰国/菲律宾产季和船期。
