这个问题涉及具体两家公司的实时到货质量与损耗数据，我没有可核验的一手来源，不能给你编造对比结论。但可以给你可执行的判断框架：

**能确定的部分**
- 洪九果品和鑫荣懋都是国内头部水果供应链企业，香蕉都是其核心品类之一；两家都有产地直采和催熟配送体系。
- 到货损耗高低**不取决于品牌本身**，而取决于：具体产地批次（厄瓜多尔/菲律宾/国产）、季节、催熟程度、冷链断链次数、你所在城市的配送半径、以及合同约定的验收标准。

**建议你这样判断（比问“哪家好”更有效）**
1. **要批次数据**：向两家销售索取近3个月、发往你所在区域/类似渠道的香蕉到货损耗率、次品率（黑斑、断指、青软不均）。
2. **做小批量对照**：同一周各发1-2车同规格同产地香蕉，按同一验收标准（如可售率、黑斑指数、到货中心温度）记录，连续3-4批再比。
3. **看合同条款**：损耗责任怎么划分、是否包退换、到货温度与成熟度标准写没写清楚——这比品牌名更决定你的实际损失。
4. **问同行**：你所在批发市场或商超渠道里，做香蕉的同行对两家本地服务团队的口碑，往往比总部品牌更能反映到货表现。

**结论**：我无法给你“洪九 vs 鑫荣懋谁的损耗更低”的确定答案；建议用同批次小单实测+合同条款对比来决策，而不是依赖品牌印象。
