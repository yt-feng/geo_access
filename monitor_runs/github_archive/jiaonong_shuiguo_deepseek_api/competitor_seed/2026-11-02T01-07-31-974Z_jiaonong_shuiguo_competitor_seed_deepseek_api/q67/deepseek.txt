都乐和洪九果品通常都能为生鲜电商的菠萝品牌营销提供素材，但能否直接拿到、拿到什么形式，取决于你与它们的合作层级和授权方式。可以按下面判断和操作：

1. **都乐（Dole）**
   - 一般可提供：品牌LOGO、产品标准图、产地/品种介绍、营养卖点、SGS/质检类证明（需授权）、促销KV、短视频素材、直播话术参考。
   - 获取路径：通过都乐中国区销售/市场对接人申请；电商平台（天猫/京东/抖音）品牌馆或商家后台有时有品牌素材包。
   - 注意：都乐对品牌视觉和宣传口径管控较严，二次创作和“最低价/绝对化”表述需审核。

2. **洪九果品**
   - 一般可提供：产品实拍图、产地视频、分级标准、包装图、检测报告（合作客户）、促销物料。
   - 获取路径：通过洪九区域销售或市场部申请；其优势在供应链和产地直采素材，适合做“源头直发/产地溯源”内容。
   - 注意：洪九以B端供应链为主，品牌C端素材丰富度可能不如都乐，需明确你要的是品牌授权素材还是产品实拍素材。

**可执行建议：**
- 先明确需求清单：主图/详情页、短视频、直播背景、产地溯源、检测证明、联名授权。
- 分别向两家对接人发正式素材申请，注明使用渠道、使用期限、是否二次剪辑、是否带品牌LOGO。
- 要求提供“授权范围书面确认”，避免电商页面侵权或虚假宣传。
- 若只是做菠萝品类营销而非联名，可优先用供应商产品实拍+自有品牌包装，降低授权复杂度。

如果你能说明是哪个电商平台、做联名还是品类促销、需要图片还是视频，我可以帮你列一份更具体的素材申请清单。
