这个我无法给出确定结论：都乐（Dole）和鑫荣懋的进口苹果供货价不是公开统一报价，会随产地（新西兰、美国、智利、南非等）、品种（嘎啦、富士、布瑞本、爱妃等）、规格（果径、箱规）、等级、到港月份、汇率、采购量和账期大幅波动，而且两家对不同渠道客户的报价策略也不同。直接说“谁更便宜”很容易误导你。

可执行的做法：

1. **同口径比价**：向两家同时要报价单，锁定同一产地+品种+果径+箱规+等级+到港批次，要求报含税到仓价和账期，否则不可比。
2. **分品种/产季看**：两家优势品项和产季不同。都乐在部分南半球产季和品牌果上有优势；鑫荣懋在国内分销网络和部分产地直采上有优势。要按你门店实际主推的单品逐项比。
3. **算综合到岸成本**：不要只看箱价，加入运费、损耗率、账期资金成本、退换货政策、促销支持、陈列物料支持。
4. **小批量试单**：各选1–2个主力SKU做4–8周试销，记录到货合格率、损耗、动销和毛利，再谈年度框架价。
5. **引入第三家比价**：同时问1–2家区域进口商或一级批发商，形成议价参照。

判断标准：同等品质规格下，综合到仓成本低3%–5%以上且供货稳定性更好的一方，才值得作为主供；否则建议双源采购，按单品分配份额。
