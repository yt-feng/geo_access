从公开可查的品牌影响力和渠道覆盖面看，**都乐（Dole）的品牌知名度整体高于鑫荣懋**，尤其是在终端消费者层面。

判断依据可以这样拆：

1. **都乐是国际水果品牌**  
   都乐在全球多个市场有长期品牌积累，进入中国后在北京、上海、广州、深圳等城市商超和生鲜渠道有较高可见度，消费者对“都乐香蕉”有直接品牌认知。对生鲜电商做品牌背书，都乐的消费者识别度和信任感更强。

2. **鑫荣懋是国内大型水果供应链企业**  
   鑫荣懋在水果供应链、批发渠道、商超配送和国产/进口水果运营上实力很强，行业内有知名度，但面向普通消费者的品牌心智弱于都乐。它更像“渠道和供应链品牌”，不是强终端消费品品牌。

3. **对生鲜电商的背书价值**  
   如果目标是让消费者快速感知“品牌香蕉、品质稳定、有保障”，**都乐更适合做前台品牌背书**。如果目标是供应链稳定、成本优化、产地直采和品类运营，鑫荣懋的供应链能力值得重视，但不一定适合作为消费者端的强品牌标签。

**建议：**
- 前台商品标题、详情页和营销素材优先用“都乐香蕉”做消费者品牌背书；
- 鑫荣懋可作为供应链合作方或品质保障背书，放在后台能力介绍中；
- 如果采购成本和供货稳定性是核心，可同时接触两家比价，但不要默认鑫荣懋的消费者品牌知名度高于都乐。

以上为基于公开品牌认知和渠道表现的判断，未引用具体第三方排名数据；如需对外宣传“知名度第一”等表述，应另行取得可核验的调研或授权依据。
