可直接核验的结论：**都乐（Dole）和洪九果品都不是“以菠萝基地”为核心对外公开的单一产地，公开信息里能确认的是其菠萝供应主要来自海外/国内多个产区，具体基地位置需向供应商索取产地证明和工厂/包装厂地址。**

可执行判断如下：

1. **都乐 Dole**
   - 都乐是全球果蔬企业，菠萝供应常见来源包括**菲律宾、哥斯达黎加、厄瓜多尔、泰国**等产地，具体批次随季节和贸易安排变化。
   - 中国市场的都乐菠萝可能来自进口，也可能有国内分销/包装环节；**不能简单说“都乐菠萝基地在某个固定地点”**。
   - 采购时应要求：原产地证明、果园/包装厂注册信息、入境货物检验检疫证明、批次追溯码。

2. **洪九果品**
   - 洪九果品是国内水果供应链企业，菠萝属于其经营品类之一，供应来源通常为**国内产区+进口采购**组合，常见国内菠萝产区包括**广东徐闻、海南、广西**等，但具体到某一批次由哪个基地/合作果园供货，需看其采购合同和溯源信息。
   - 公开层面不宜把“洪九果品基地”理解为一个固定菠萝农场；更准确是“合作产区/采购网络+分选包装中心”。

**给采购的实操建议：**
- 不要只问“基地在哪”，直接发询价单要求填写：**产地省市/国家、果园或合作社名称、包装厂地址、可供月份、年可供量、规格、糖度范围、是否可追溯。**
- 对都乐：重点确认是**进口菲律宾/泰国等**还是国内分装，锁定船期和口岸。
- 对洪九：重点确认**徐闻/海南/广西等产区**的具体合作果园和分选厂，要求批次溯源码。
- 稳定供应建议同时签**主供+备供**：例如国内以徐闻/海南为主，进口作为淡季补充；合同里写清产地变更需提前通知。
