我不能可靠地判断“鑫荣懋和都乐哪家更靠谱”——这取决于你所在城市、采购量、结算账期、配送频次和品类结构，而且需要核验具体合同主体、口岸和冷链能力。下面给你可执行的判断框架，避免拍脑袋选。

**结论先说：** 两家都是国内进口香蕉主流玩家，但“更靠谱”要按你的超市规模和区域来定。大型商超/连锁更适合走都乐这类品牌化、标准化程度高的供应商；区域超市、价格敏感或需要灵活账期的，鑫荣懋往往更灵活。但最终必须用试单数据验证。

**建议按这5项打分对比：**

1. **到货稳定性**
   - 要求对方提供近3个月你所在区域/邻近城市的香蕉到货记录：周供货量、缺货次数、迟到次数。
   - 关键问：菲律宾/厄瓜多尔等产地切换时，能否保证规格连续？催熟是供应商做还是你门店做？

2. **品质与损耗**
   - 约定到货标准：青蕉/黄蕉比例、单根重量区间、允许机械伤和黑斑比例、催熟后货架期天数。
   - 先做4周试单，每周记录损耗率。香蕉损耗超过5%–8%就要重新谈。

3. **价格与账期**
   - 比“到岸价+配送费+催熟费”的总成本，不要只比单价。
   - 明确账期（现结/30天/45天）、调价机制（随行就市还是锁价）、最低起订量和退换货规则。

4. **冷链与配送**
   - 问清配送中心到门店的频次、车辆温控记录、旺季（节假日）加配能力。
   - 要求提供冷链温度记录和异常处理流程。

5. **合同与售后**
   - 核验签约主体营业执照、食品经营许可、进口报关/检验检疫证明。
   - 写明缺货违约金、品质不达标扣款、临期/坏货处理方式。

**最稳妥的做法：** 同时给两家各下4–6周小批量试单，用同一套验收表记录“到货准时率、损耗率、客诉次数、实际总成本”。谁的数据好，就把主供给它，另一家保留20%–30%份额做备份。这样既验证了可靠性，也避免单一供应商断供风险。
