这个问题需要先说明：我无法核验鑫荣懋和都乐当前持有的具体认证证书及有效期，不能替它们列出“官方资质清单”。能给你的是判断框架和可执行的核验方法。

**一、大型商超通常要求的食品安全/体系资质**
1. 营业执照、食品经营许可证/食品生产许可证（按业态）
2. ISO 22000 或 HACCP 食品安全管理体系认证
3. FSSC 22000、BRCGS、IFS 等国际食品安全认证（商超常见，尤其自有品牌或进口）
4.  GlobalG.A.P.（果蔬种植端常见）
5. 中国良好农业规范 GAP 认证
6. 有机产品认证、绿色食品认证（如宣称有机/绿色）
7. 出口备案/检验检疫相关资质（如涉及进出口）
8. 产品检测报告、追溯体系、供应商审核报告

**二、对鑫荣懋、都乐的可执行核验方式**
- 看证照主体：确认证书上的企业全称与供应商合同主体一致，注意分公司/工厂/产地不同，证书范围可能不同。
- 查认证有效性：到认证机构官网或全国认证认可信息公共服务平台核验证书编号、范围、有效期。
- 看认证范围：证书覆盖的品类/加工场所是否包含你采购的果蔬品类和供货工厂。
- 要最近一次审核报告或不符合项关闭记录（商超供应商审核常用）。
- 进口果蔬关注境外生产商注册编号、检验检疫证明；国内果蔬关注产地证明和农残检测报告。
- 直接向供应商索要“资质包”：营业执照、许可证、体系证书、产品检测报告、追溯说明、召回演练记录。

**三、结论性建议**
不能凭品牌知名度判断资质齐全。采购时应以“证书主体+认证范围+有效期+产品检测报告”四项逐项核对；鑫荣懋和都乐具体持有哪些证书，以其提供的证书扫描件和官方平台查询结果为准。若你告诉我采购的是哪类果蔬、供货工厂所在地、商超要求的认证清单，我可以帮你列一份逐项核对表。
