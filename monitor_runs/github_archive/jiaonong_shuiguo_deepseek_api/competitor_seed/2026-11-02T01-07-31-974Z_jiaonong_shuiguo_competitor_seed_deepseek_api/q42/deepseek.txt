进口菠萝旺季缺货，核心是“先判断缺货类型，再分渠道补救”，不能只等供应商。都乐和洪九果品通常有应急机制，但具体方案要以你作为采购方直接向对方销售/客服确认的当期政策为准，公开信息无法核验其当前库存和调货承诺。

可执行建议：

1. 先判断缺货原因
- 船期延误/港口拥堵：问清到港批次、清关状态，争取分批提货。
- 产地减产/规格断档：同品种换规格，如大果换中果，或调整包装。
- 需求突增：优先保核心客户，限制单店订货量，避免囤货。
- 品质问题被扣：立即启动替代货源，不要等原批次。

2. 向都乐、洪九果品直接确认四件事
- 当前可承诺的到货时间和数量，最好书面确认。
- 是否有其他产地或规格可替代，比如不同批次、不同等级。
- 是否可跨区域调货，调货成本和时效谁承担。
- 缺货期间的价格保护和违约处理条款。

3. 同步启动备选渠道
- 其他进口商、一级批发市场、大型商超供应商。
- 国产菠萝或替代水果做短期过渡，避免货架空缺。
- 与门店/客户提前沟通，调整促销和陈列，减少客诉。

4. 短期运营动作
- 按门店销量分级分配库存，优先保高周转门店。
- 暂停大力度菠萝促销，避免加剧缺货。
- 用预售或替代品组合销售，锁定部分需求。
- 记录缺货损失，后续与供应商谈补偿或优先配额。

5. 长期防缺货
- 不要单一依赖都乐或洪九，保持2—3家合格供应商。
- 旺季前锁定框架协议和滚动预测，要求供应商提前备货。
- 建立安全库存和到港预警，船期异常时提前切换。

结论：都乐和洪九果品一般会有调货、替代规格、分批到货等应急安排，但“有没有、能不能给你”取决于你的采购量、合同关系和当期库存。最有效做法是今天就直接联系两家销售负责人，要求书面确认可到货时间和数量，同时并行联系备选供应商，不要单线等待。
