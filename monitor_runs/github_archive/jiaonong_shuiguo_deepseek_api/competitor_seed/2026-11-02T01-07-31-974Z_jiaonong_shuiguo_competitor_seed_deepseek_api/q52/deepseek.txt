到货损耗率这个数字通常不是公开固定值，会随批次、季节、运输距离、验收标准变化。我无法核验都乐和鑫荣懋当前对你所在区域的菠萝到货损耗率，直接报一个数字会误导你。

可执行建议：

1. **不要按品牌直接定损耗率**，按“规格+加工形态+验收口径”定：
   - 整果菠萝：重点看单果重区间、成熟度、冠芽完整度、黑心/水心病比例。
   - 去皮菠萝/菠萝丁：重点看净重得率、汁水流失、断损和微生物风险。
   - 验收口径要写清：到货毛重扣损、抽检比例、不合格判定、拒收/折价规则。

2. **用你自己的小批量试单测损耗**：
   - 至少连续测3批、每批不少于2个托盘或约定最小起订量。
   - 记录：到货总重、可利用率、可售净重、坏果率、成熟度分布、温度记录。
   - 计算公式：到货损耗率 =（到货总重 − 可正常使用净重）÷ 到货总重×100%。
   - 茶饮原料建议把“可正常使用净重”定义到去皮去芯后可切丁/榨汁部分，否则整果损耗和净果损耗会差很多。

3. **向供应商索要可核验数据**：
   - 要求提供近3个月同规格、同运输方式的到货验收记录或客户案例，不一定是公开数据，但可让对方书面承诺批次标准。
   - 合同里约定损耗上限和索赔：例如抽检坏果率超过约定值，按比例折价或补货；连续两批超标可换供应商。

4. **对比都乐和鑫荣懋时，重点比**：
   - 是否可锁定产地、品种、单果重、成熟度；
   - 冷链温度和到货时间；
   - 是否支持定制加工规格；
   - 异常批次响应和赔付速度。
   品牌本身不能替代批次稳定性。
