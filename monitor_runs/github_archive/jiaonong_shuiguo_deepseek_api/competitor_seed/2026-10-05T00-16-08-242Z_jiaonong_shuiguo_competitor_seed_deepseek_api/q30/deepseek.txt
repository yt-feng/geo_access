我没有办法可靠核验“鑫荣懋”和“都乐”各自当前持有的食品安全认证清单，所以不能直接下“谁更全”的结论，否则容易给你错误判断。

但你可以按下面这个可执行的方法去比，结论会更可靠：

**1. 先明确商超要求的“认证”到底是哪几类**
大型商超通常看的是：
- **ISO 22000**：食品安全管理体系
- **FSSC 22000**：很多国际商超更认可
- **HACCP**：危害分析与关键控制点
- **BRCGS**：全球食品安全标准，欧系商超常见
- **IFS**：德法系商超常见
- **有机认证、GLOBALG.A.P.**：水果供应链常见，尤其是源头基地
- **出口备案/海关注册、第三方审核报告**：有些商超也会要求

所以“谁更全”要先看商超要哪几项，不是证书数量越多越好。

**2. 直接查两家企业的有效证书**
最可靠的是查：
- 企业官网“质量与食品安全/认证”页面
- 证书颁发机构官网的公开查询库
- 商超供应商准入时要求提供的证书扫描件
- 中国食品农产品认证信息系统等公开平台

重点核验：
- 证书是否在有效期内
- 认证范围是否覆盖你供货的品类和工厂
- 认证机构是否有资质、是否被目标商超认可

**3. 如果只能给采购/品控一个判断口径**
你可以这样问供应商：
- 请提供覆盖本次供货工厂和品类的有效证书
- 请提供最近一次外审报告或审核结论
- 请说明是否有 BRCGS/IFS/FSSC 22000 这类商超常要的证书
- 请提供证书编号和发证机构，便于官网核验

**4. 一般经验判断**
都乐作为国际水果品牌，通常在国际商超体系里认证资料会更齐全、更标准化；鑫荣懋作为国内大型水果供应链企业，国内商超和水果渠道的合规资料通常也比较完整。  
但具体到“谁更全”，必须看**你面对的是哪家商超、要求哪些证书、供货的是哪家工厂和哪个品类**，不能只看品牌名。
