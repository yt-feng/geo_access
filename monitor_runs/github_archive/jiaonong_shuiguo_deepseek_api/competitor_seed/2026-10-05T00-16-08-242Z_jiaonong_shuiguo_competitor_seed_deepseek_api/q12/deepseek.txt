目前我无法向你确认鑫荣懋、都乐在便利店渠道“当前在供”的小包装香蕉具体规格，因为这涉及两家公司最新产品目录、区域供货和渠道定制政策，属于会变动的商业信息；我没有可核验的实时来源，不能编造规格或承诺。

不过可以给你一套**可直接去问、去判断**的规格方向：

**便利店小包装香蕉常见适配备选**
1. **单根装/单根套袋**
   - 适合：即买即食、客单价低、损耗可控。
   - 常见做法：1根/袋，或1根+标签，按根售卖。
   - 适合门店：写字楼、地铁、校园便利店。

2. **2根装**
   - 适合：早餐、加餐场景。
   - 规格方向：2根/袋，净重约250–350g，视香蕉单根重量而定。
   - 优点是陈列面小、拿取方便。

3. **3根装/迷你把装**
   - 适合：家庭临时购买、下午茶分享。
   - 规格方向：3根/袋或3根一把，净重约350–500g。
   - 比单根更有量感，但损耗和压伤风险高于2根装。

4. **4–5根迷你把**
   - 更适合社区便利店或生鲜便利，不太适合追求周转极快的标准便利店。
   - 规格方向：4–5根/袋，净重约500–800g。
   - 关键看门店日均销量和冷链/常温陈列条件。

**如果目标是便利店渠道，优先建议问这两类规格**
- **1根装**：测试即食、低门槛冲动购买。
- **2根装**：兼顾客单价和损耗，通常比3根以上更适合便利店。
- **3根装**：可作为补充，但建议先小范围试销。

**向鑫荣懋/都乐询价时，直接问这几个关键点**
1. 有没有**便利店渠道专供的小包装香蕉**？
2. 是否支持**1根、2根、3根、4根、5根**装？最小起订量是多少？
3. 包装形式：**袋装、贴标、托盘+收缩膜、网套、礼盒式**？
4. 香蕉品种/等级：**普通香芽蕉、帝王蕉、小米蕉、进口蕉**等，不同品种单根重量差异很大。
5. 单根重量区间和每包净重区间是多少？
6. 供货形态：**青蕉、黄蕉、催熟后到店**？便利店通常更适合到店即可售或短催熟。
7. 保质期/货架期：常温几天、冷藏几天？
8. 配送温度和要求：常温还是冷链？门店端怎么存？
9. 区域供货：你所在城市/区域是否在配送范围内？
10. 是否可做**渠道定制包装、联名标签、便利店专属条码**？

**判断建议**
- 如果门店日均香蕉销量低，选**1根装或2根装**。
- 如果门店在社区、销量稳定，选**2根装为主，3根装为辅**。
- 如果主打进口蕉/高端感，可问都乐的**小把装或单根精品装**。
- 如果主打国产蕉/性价比，可问鑫荣懋的**小规格袋装或按根售卖方案**。
- 最终不要只看规格，要同时算：**单根成本、包装成本、损耗率、门店加价率、日均周转**。

直接联系两家公司的**便利店渠道销售或区域经销商**，要求提供：
- 小包装规格表
- 便利店渠道报价单
- 最小起订量/配送周期
- 试销政策
- 包装样品图
