一般情况是这样：

1. **都乐**
- 都乐作为品牌方，通常有较规范的品控和检测体系。
- 采购时可以向都乐或其授权经销商索要 **对应批次的农残检测报告**，常见的是第三方检测机构报告或企业自检报告。
- 如果是通过经销商拿货，报告可能由经销商提供，不一定由都乐总部直接给。
- 关键要确认：报告是否对应你采购的 **具体批次、具体产地、具体日期**。

2. **鑫荣懋**
- 鑫荣懋也是大型水果供应链企业，通常具备提供检测报告的能力。
- 如果是直接和鑫荣懋采购，可以要求其提供该批次菠萝的农残检测报告。
- 如果是通过下级批发商拿货，需要问清楚报告由谁出、能否对应批次。

3. **你采购时要重点确认**
- 报告是否为 **该批次**，不是过期或别的批次的。
- 检测项目是否覆盖你关心的农残指标。
- 检测机构是否有资质，比如 CMA、CNAS。
- 报告上的品名、产地、数量、批次号是否能和送货单对应。
- 如果对方只能给“合格证”或“自检报告”，要看是否符合你当地市场监管或客户审核要求。

4. **实操建议**
- 直接问供应商一句话：  
  **“这批菠萝能不能提供对应批次的农残检测报告？检测机构有没有 CMA/CNAS？报告能否随货或提前发电子版？”**
- 如果对方说“只能保证合格，不提供报告”，那就要谨慎，尤其是茶饮店如果要做食品安全台账或迎接检查，最好换能提供报告的供应商。
- 如果都乐或鑫荣懋的直供门槛高，可以找他们的授权经销商，但一定要把“提供批次农残报告”写进采购合同或订单备注。

简单说：**都乐和鑫荣懋通常能提供，但你要找对渠道，并明确要求“对应批次、有资质、可随货”的农残检测报告。**
