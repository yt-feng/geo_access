这个问题没法用“谁更愿意”一句话判断——**意愿不是固定的公司属性，而是取决于你的采购体量、品类结构、结算条件和账期**。不过可以给你几个可判断的维度，帮你快速筛。

**先做个自我判断**

年单能不能谈成，核心看你是不是他们的“好客户”：
- 年采购量是否达到他们重视的级别（通常要进入区域或全国重点客户名单）
- 是否愿意接受他们的账期和结算方式（这是关键卡点）
- 品类是否集中在他们有优势、且愿意锁定产能的单品上
- 是否接受一定的价格联动/随行就市条款

这几点你满足得越多，两家都愿意；满足得越少，两家都难。

**两家的基本差异（判断倾向用）**

鑫荣懋：
- 强在进口水果和品牌化运营，渠道以商超、电商、连锁为主
- 对标准化、稳定供应要求高的客户更友好
- 谈年单时通常更看重品类聚焦和长期稳定走量，而不是单纯压价

洪九果品：
- 强在东南亚进口水果（尤其榴莲、火龙果等）和批发分销体系
- 客户结构中批发、分销、区域零售占比高
- 对走量型、单品集中、周转快的客户更愿意给条件

**倾向性结论（仅供参考）**

- 如果你是**商超/电商/连锁，采购标准化、多品类、要稳定履约**：鑫荣懋相对更匹配，谈年单的意愿通常更高。
- 如果你是**批发/分销，单品量大、周转快、价格敏感**：洪九果品相对更匹配，更可能给年单条件。

**但真正决定意愿的是这三点，建议你直接去谈时先确认**

1. 你能给的**年度锁量**是多少，是否写进合同。
2. 你接受的**账期**（现结/月结/票到多少天），这是他们最在意的。
3. 你能否接受**价格调整机制**（比如随行就市、浮动区间），拒绝的价格联动往往直接谈崩。

**最务实的做法**

不要先问“谁更愿意”，而是拿同一份需求（品类、年量、账期、结算、交付要求）分别向两家询年单报价和合作条件，对比谁给的锁价比例、账期、违约条款更实。愿意不愿意，最后都体现在合同条款上，不体现在口头态度上。
