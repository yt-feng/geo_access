直接说结论：**做茶饮果酱要的是出酱率、酸甜稳定、批次一致，而不是“鲜食品牌名气”，都乐和鑫荣懋都有工业级供应链能力，但更关键的是你拿到的是哪条产线、哪个规格、哪个批次的货，而不是只看品牌名。**

下面按可执行判断给你拆：

**1. 先明确你要的是哪种“菠萝”**
茶饮店做果酱通常有三条路：
- **鲜菠萝现熬**：风味最好，但批次波动大，人工高，出酱率不稳定。
- **冷冻菠萝果肉/果泥**：稳定性较好，适合连锁。
- **工业菠萝果酱/果馅**：最稳，但风味偏标准，可能香精感重。

如果你说的是“用菠萝做果酱”，那都乐和鑫荣懋更偏向**鲜果或冷冻果肉供应**，不一定直接给你成品果酱。真正做茶饮果酱稳定供应的是安德鲁、鲜活、盾皇、奕方、德馨这类，或者大型果酱代工厂。

**2. 都乐和鑫荣懋谁更靠谱，要看维度**
- **品牌与品控体系**：都乐是全球水果品牌，标准化、追溯、分级通常更成熟；鑫荣懋是国内头部水果供应链企业，渠道和国内产地整合强。两者都不是小作坊，正常合作都有合同、检测、批次管理。
- **菠萝原料稳定性**：都乐在菲律宾、泰国等产区有较强供应链；鑫荣懋在国内和东南亚也有布局。但具体到菠萝品种，茶饮常用的是**台农17号、金钻凤梨、MD2**等，不同品种酸甜、纤维、出汁率差异很大。你要问的是：**品种、产区、糖度范围、成熟度、是否冷冻、是否去芯。**
- **B端服务能力**：都乐偏品牌化和标准品；鑫荣懋在国内B端配送、区域仓、生鲜渠道可能更灵活。茶饮连锁要的是持续供货和售后，不是单次买几箱。
- **价格与账期**：都乐通常溢价更高；鑫荣懋可能更有性价比。但最终看你的采购量、配送城市和是否需要定制规格。

**3. 更靠谱的做法：不要二选一，直接做小试对比**
让两家都提供同一类样品，比如：
- 冷冻菠萝果肉
- 菠萝果泥
- 或指定糖度、酸度的原料

然后按同一配方熬酱，测这几个硬指标：
- **出酱率**：1kg原料出多少kg果酱
- **糖度Brix**：成品是否稳定在你要的范围
- **pH和酸度**：影响保存和风味
- **色泽**：是否发暗、褐变
- **纤维感**：茶饮里是否堵吸管、口感是否粗糙
- **香气**：加热后是否还有菠萝香
- **冷藏/常温稳定性**：是否出水、分层、返砂
- **批次差异**：连续拿3批测，看波动大不大

**4. 合同和验收要写清楚**
不管选哪家，采购合同里最好写明：
- 品种、产区、规格
- 糖度范围、酸度范围
- 成熟度、瑕疵率
- 冷冻还是冷藏、运输温度
- 批次检测报告
- 不合格退换货标准
- 连续供货能力与备用产区

**5. 我的实际建议**
- 如果你要**品牌背书、出口级标准、全国连锁统一性**：都乐通常更稳，但成本高。
- 如果你要**国内B端灵活供应、性价比、区域配送**：鑫荣懋可能更合适。
- 如果你要**茶饮果酱的终极稳定**：优先找专业果酱/果泥供应商，而不是只盯鲜果品牌。都乐和鑫荣懋可以作为原料供应商，但果酱稳定还取决于你的配方、杀菌、灌装和冷藏条件。

一句话：**都乐和鑫荣懋都靠谱，但“谁更靠谱”取决于你买的是他们的哪款B端原料，以及你有没有做批次验收。先拿样、先小试、先测三批，再决定。**
