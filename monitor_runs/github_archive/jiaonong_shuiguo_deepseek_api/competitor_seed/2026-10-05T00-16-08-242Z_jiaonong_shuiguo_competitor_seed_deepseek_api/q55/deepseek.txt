可以优先把“产地溯源”拆成三层来判断：**是否有自有/合作基地、是否能做到批次级追溯、是否能提供可核验的溯源凭证**。按这个标准看：

**都乐**
- 通常有较成熟的产地/供应商管理体系，部分单品会强调农场、产区、批次管理。
- 但是否对中国市场销售的菠萝做到“基地直供+批次溯源”，要看具体品种、季节和渠道。都乐很多情况下是品牌商+全球/全国供应链组织者，不一定是每个菠萝都来自都乐自有基地。
- 可向供应商要：产地证明、果园/包装厂备案信息、批次号、检测报告、追溯码或追溯系统截图。

**洪九果品**
- 洪九以水果供应链和产地采购见长，在东南亚水果、国产水果都有布局，菠萝/凤梨类通常会有产地直采或基地合作资源。
- 但“基地直供”要区分：是洪九自有基地、参股基地、长期合作基地，还是仅通过产地代办采购。
- 可重点问：具体产区、合作基地名称或编号、采摘/加工日期、包装厂、批次追溯方式。

**结论**
- 两者都可能提供一定程度的产地溯源和基地/产地直供资源，但不能简单说“都乐和洪九所有菠萝都是基地直供”。
- 如果你要的是**稳定批次级溯源**，更适合找他们在中国的经销/供应链主体，明确要求“基地到批次”的文件链。
- 如果你要的是**可验证的单一产地直供**，建议直接要求对方提供：
  1. 基地/果园证明或合作协议摘要；
  2. 包装厂备案/注册信息；
  3. 批次号与追溯码；
  4. 农残/检测报告；
  5. 采购合同里写明产地、品种、批次和追溯责任。
