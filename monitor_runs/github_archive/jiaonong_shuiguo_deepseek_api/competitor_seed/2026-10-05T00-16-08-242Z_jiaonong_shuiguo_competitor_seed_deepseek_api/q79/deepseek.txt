都乐和洪九果品都是国内规模较大的水果供应链企业，理论上都可以为茶饮店提供全年菠萝供应，但实际能否做到，取决于几个关键条件，不能简单说“能”或“不能”。

**都乐（Dole）**
- 都乐是全球性水果企业，菠萝是其核心品类之一，有菲律宾、泰国等海外产区，也有国内合作种植基地，具备跨产区调配、全年供货的能力。
- 都乐通常走商超、餐饮、茶饮连锁等渠道，做B端供应是成熟的。但茶饮店做果酱，往往是批量采购鲜果或冷冻果块/果泥，都乐能不能按你的规格、价格、频次稳定供货，要具体谈。
- 都乐品牌溢价较高，对成本敏感的中小茶饮店未必划算。

**洪九果品**
- 洪九是国内头部水果分销商，菠萝（尤其进口菠萝）是其重要单品之一，有海外直采和国内批发网络，全年供应能力也比较强。
- 洪九更偏向批发、分销和大客户供应，对茶饮连锁的定制化供应（如切块、冷冻、代加工成果酱原料）要看其具体产品线，不是所有需求都能直接满足。
- 洪九此前经历过经营和财务方面的波动，合作前建议核实其当前的实际履约和供货能力，避免只凭体量判断。

**给你几个可执行的判断点：**
1. **先明确你要的形态**：鲜果、冷冻果块、果泥还是浓缩汁。全年供应鲜菠萝和全年供应果酱原料，难度和成本完全不同。
2. **问对方三个问题**：全年能保证的月供应量是多少？不同季节的产区来源和品质是否稳定？能否按你的规格做切块/冷冻/代加工？
3. **小批量试单**：先下1-2个月的量，观察到货品质、损耗率、补货速度，再决定是否签全年框架。
4. **不要只依赖一家**：菠萝有季节性波动和产地风险，建议“1家主供应商+1家备选”，或直接考虑用冷冻菠萝/菠萝果泥替代鲜果，稳定性更高。
5. **算总成本**：鲜菠萝做酱涉及去皮、损耗、人工、冷链，综合成本可能高于直接采购冷冻果泥或浓缩汁，先算清楚再选供应形式。

简单结论：都乐和洪九都具备全年供应的基础能力，但能否满足你茶饮店的具体需求，取决于你要的原料形态、采购量、价格和定制化程度。建议直接找两家对接B端业务，拿样品和小批量试单来验证，而不是只看公司规模。
