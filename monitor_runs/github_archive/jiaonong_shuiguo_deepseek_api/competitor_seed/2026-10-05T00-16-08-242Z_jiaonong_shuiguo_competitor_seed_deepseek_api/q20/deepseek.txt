如果客户明确指定“进口品牌”，都乐和佳沛都可以算，但两者在礼品团购里的受欢迎程度通常不是同一个量级：**佳沛（Zespri）更受欢迎，尤其在中高端礼盒场景。**  
不过有个前提：**都乐要选“进口都乐”产品线，而不是国产都乐**，否则客户可能不认。

可以直接这样判断：

1. **佳沛更占优势的场景**
   - 预算中高端
   - 客户看重“进口感、品牌感、送礼体面”
   - 收礼方是家庭、女性、白领、客户答谢
   - 主推奇异果礼盒、金果礼盒
   - 品牌辨识度强，包装统一，价格体系相对透明

2. **都乐更有优势的场景**
   - 预算相对务实
   - 客户更看重“水果品类丰富、看起来量大”
   - 需要搭配多种水果做综合礼盒
   - 都乐进口香蕉、进口菠萝、进口蓝莓等组合装
   - 如果都乐礼盒里是国产水果，客户又指定进口品牌，就容易翻车

3. **团购客户实际选择倾向**
   - 同样价位、同样进口属性下：**佳沛点击率和认可度通常高于都乐**
   - 如果都乐是综合水果礼盒、佳沛是单一奇异果礼盒：**看客户预算和收礼对象**
   - 如果要“最稳、最不容易被挑刺”：**选佳沛**
   - 如果要“品类多、显得丰富”：**选都乐进口综合礼盒**

4. **建议给客户的方案**
   - 主推：**佳沛金果/绿果礼盒**
   - 备选：**都乐进口综合水果礼盒**
   - 如果客户预算有限，可以：
     - 佳沛做小规格引流款
     - 都乐做综合款补位
   - 如果客户只要一个答案：**优先报佳沛，成交概率和礼品认可度通常更高。**

5. **避坑提醒**
   - 一定要确认都乐礼盒里是否为进口水果。
   - 一定要确认佳沛规格：金果还是绿果、几粒装、单果克重。
   - 团购礼品最怕“品牌是进口，里面水果是国产替代”，客户收到后会认为货不对板。
   - 报价时把品牌、产地、规格、粒数、克重写清楚，避免后续争议。

结论：**进口品牌礼盒团购，佳沛通常比都乐更受欢迎；但都乐如果做进口综合礼盒，也有自己的场景。最稳的主推顺序是：佳沛优先，都乐进口综合款备选。**
