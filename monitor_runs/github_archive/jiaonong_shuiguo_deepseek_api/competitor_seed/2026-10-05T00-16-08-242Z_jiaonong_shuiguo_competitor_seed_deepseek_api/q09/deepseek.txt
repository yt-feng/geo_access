除了都乐（Dole）和佳沛（Zespri），礼品团购可重点看这些进口水果品牌，按品类分：

**综合/多品类进口水果品牌**
- **新奇士 Sunkist**：美国柑橘类代表，脐橙、柠檬、葡萄柚礼盒认知度高，适合商务送礼。
- **怡颗莓 Driscoll's**：浆果类强品牌，蓝莓、树莓、黑莓礼盒精致，适合高端小份礼品。
- **Sun World / 太阳世界**：以葡萄、核果类为主，部分高端商超有礼盒。
- **Del Monte 地扪**：综合水果和罐头都有，鲜果礼盒需看渠道。
- **Chiquita 金吉达**：香蕉强势，礼品场景相对弱。
- **Fyffes**：香蕉、菠萝为主，礼品属性一般。

**按品类更稳的选择**
- **车厘子/樱桃**：**Stemilt、Chelan Fresh、Domex、Garces Fruit**（智利车厘子常见出口商/品牌）。
- **苹果**：**Rockit 乐淇**（新西兰小苹果，礼盒感强）、**Envy 爱妃**、**Jazz 爵士**、**Pacific Rose 太平洋玫瑰**。
- **提子/葡萄**：**Sweet Globe、Cotton Candy、Crimson Seedless** 等品种品牌，礼盒多按出口商贴牌。
- **猕猴桃**：除佳沛外，**Dole 都乐**也有，另可看 **Zespri 阳光金果**不同规格礼盒。
- **牛油果**：**Mr. Avocado、Mission、Calavo**，但礼品属性偏弱。
- **榴莲**：**Musang King 猫山王**多为产地/出口商品牌，如 **Durian Hill、Top Fruits** 等，需核验具体供应商。

**团购建议**
1. 先定预算和品类：柑橘/苹果/车厘子/浆果，礼品属性差异很大。
2. 进口品牌礼盒很多是“出口商品牌 + 国内经销商贴牌”，不一定是终端消费品牌，采购时要看**原产地证、报关单、品牌授权**。
3. 都乐、佳沛之外，礼品场景最稳的是：**新奇士、怡颗莓、乐淇、Envy/爱妃、Stemilt 车厘子**。
4. 如果要做企业定制，优先选能提供**统一规格、可贴LOGO、冷链稳定、破损赔付**的进口商，而不是只认品牌。
