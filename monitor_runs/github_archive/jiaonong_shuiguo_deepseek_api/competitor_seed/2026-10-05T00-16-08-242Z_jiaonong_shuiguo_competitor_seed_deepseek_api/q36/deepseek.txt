这个问题没有绝对答案，因为**质量稳定性更多取决于具体批次、产地、季节和到货渠道，而不是品牌本身**。但可以给你一个可判断的框架：

**1. 品牌定位差异**
- **都乐**：国际品牌，供应链标准化程度高，品控体系成熟，尤其在高档商超渠道的到货一致性通常较好。但都乐很多产品是授权/贴牌运作，不同单品差异大。
- **鑫荣懋**：国内头部水果供应链企业，代理和自营多个进口水果品牌，渠道覆盖广，性价比通常更好。但因为它同时运作很多品牌和产地，**同一品牌名下的批次差异可能比都乐更明显**。

**2. 真正决定稳定性的因素**
- **产地**：新西兰、美国、智利、南非等不同产季，口感硬度差异很大。
- **品种**：嘎啦、红玫瑰、爱妃、富士等，耐储性完全不同。
- **到货批次**：同一品牌不同柜次，成熟度、糖度、硬度都可能不一样。
- **冷链和周转**：超市收货后的储存温度、上架时间，比品牌影响更直接。

**3. 采购建议**
- 如果是**长期稳定供货**，优先看供应商能否提供**固定产地+固定品种+定期质检报告**，而不是只看品牌。
- 可以要求**先试销2-3个批次**，记录硬度、糖度、坏果率，再决定主推哪个。
- 都乐适合对**外观一致性和品牌背书**要求高的场景；鑫荣懋适合对**成本和渠道灵活性**要求高的场景。
- 最稳的做法：**同时保留两个供应商**，按批次抽检，谁稳定就加大采购比例。

**一句话结论**：单看品牌，都乐的标准化程度通常更高；但实际采购中，**批次和供应链管理能力比品牌名字更重要**。建议用“小批量试单+批次抽检”来验证，而不是直接押注某一个品牌。
