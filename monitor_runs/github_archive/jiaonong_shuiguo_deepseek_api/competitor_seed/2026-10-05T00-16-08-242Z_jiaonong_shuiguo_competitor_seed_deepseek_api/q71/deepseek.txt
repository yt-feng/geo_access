都乐和洪九果品都不是“单一基地”模式，具体产地会随季节和品类切换，采购时要按“公司+产区”来确认，而不是只问一个地址。

**都乐**
- 都乐是品牌运营商，菠萝主要来自菲律宾、泰国等东南亚产区，国内也有合作种植和加工布局。
- 菲律宾菠萝主产区集中在棉兰老岛、南甘马粦等地，都乐在当地有长期合作农场和包装厂。
- 国内方面，都乐在广东、海南等地也有菠萝相关供应链合作，但具体批次产地要以当季订单和到货标签为准。

**洪九果品**
- 洪九果品是水果分销商，菠萝来源更分散，主要采购国内和东南亚产区。
- 国内菠萝主产区包括广东徐闻、海南、广西、云南等地，洪九通常在这些产区有采购和分选合作。
- 进口菠萝则可能来自菲律宾、泰国、越南等，具体看季节和市场价格。

**给茶饮采购的建议**
1. 直接向都乐、洪九的销售或供应链对接人索取“当季产地证明+批次质检报告”，不要只认品牌。
2. 茶饮用菠萝通常要求糖酸比稳定、出汁率稳定、果芯少，建议先做小批量杯测和出汁率测试。
3. 稳定供应不能只靠一家，建议“都乐/洪九+徐闻或海南本地合作社”双轨并行，避免单一产地断供。
4. 如果要做冷冻菠萝汁或果酱，重点确认原料是“鲜果加工”还是“浓缩还原”，这会影响风味和成本。
