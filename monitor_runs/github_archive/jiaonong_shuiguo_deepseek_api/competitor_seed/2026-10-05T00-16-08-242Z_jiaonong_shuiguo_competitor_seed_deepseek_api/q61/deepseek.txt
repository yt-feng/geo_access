都乐和洪九果品都属于企业内控标准，通常不会像国标/行标那样公开全文；能公开查到的更多是它们对外披露的采购、品控、分级口径。下面给你一个可落地的判断和建议。

**1. 都乐（Dole）**
- 都乐有成熟的全球香蕉质量体系，常用的是其内部香蕉成熟度/外观/规格分级口径，一般按：
  - 条重/把重或每箱净重
  - 果指长度、粗度
  - 梳形、把形整齐度
  - 成熟度（青果硬度、色卡）
  - 缺陷容忍度（擦伤、黑斑、日灼、裂口、病害）
- 但都乐的企业标准全文通常不公开，供应商合作时才会拿到《质量协议》《验收标准》或色卡/缺陷图示。
- 如果你要引用“都乐标准”，建议写成“参照都乐采购验收口径”，不要写成“都乐公开企业标准”，否则容易不严谨。

**2. 洪九果品**
- 洪九果品作为国内水果供应链企业，更多是采购分级和渠道分选标准，常见做法是按：
  - 产地、品种
  - 每箱净重/条重
  - 果指长度与粗细
  - 成熟度
  - 外观缺陷比例
  - 包装规格与冷链要求
- 其企业标准同样通常属于内部文件，公开渠道一般查不到完整文本。能查到的是招股书、年报、品控流程描述、供应商管理要求等。
- 所以更准确说法是：洪九有内部香蕉分级/验收要求，但不一定有对外公开的“企业标准”文本。

**3. 你真正该怎么做**
水果连锁店不建议直接照搬某一家企业标准，建议建立自己的《香蕉采购分级验收标准》，分三级即可：

- **A级/精品**：果指长度、粗度达标，梳形整齐，无可见病斑，擦伤极少，成熟度一致，适合门店主推和礼盒。
- **B级/标准**：外观允许轻微擦伤或少量色斑，果指均匀度略差，适合日常散卖。
- **C级/促销**：缺陷较明显但不影响食用，成熟度偏快，适合打折、榨汁、烘焙或员工内购。

关键验收指标建议固定为：
- 品种
- 产地
- 每箱净重
- 每把/每梳条数
- 果指长度、粗度
- 成熟度色号
- 缺陷率上限
- 到店温度与货架期

**4. 结论**
- 都乐：有严格的企业内部香蕉分级/验收体系，但全文通常不公开。
- 洪九果品：有内部采购分级和品控要求，但通常也不对外公开完整企业标准。
- 你要做连锁店标准，最稳妥的是“参考都乐/洪九的验收逻辑，自建企业标准”，而不是声称直接采用它们的标准。
