可以，但要分清楚“有没有”和“能不能给到你要的层级”。

**结论：**
- **都乐（Dole）**：通常有较成熟的产地溯源和品控体系，尤其是自有或合作蕉园、加工包装环节。一般能提供产地证明、植保/农残检测、质量体系文件等，但具体到“每一批货”的追溯码、检测报告、品控记录，要看你采购量、渠道和合同约定。
- **鑫荣懋**：作为国内大型水果供应链企业，通常也有产地采购、分级包装和品控流程，能提供部分产地证明、检测报告或供应商审核资料。但它更多是供应链整合商，具体证明取决于上游蕉园和批次，不一定像都乐那样统一标准。

**你可以直接这样判断和要资料：**
1. **要“批次级”溯源**：问能否提供每批货的追溯码/批次号，能对应到具体蕉园、采摘日期、包装厂。
2. **要“品控证明”**：至少要有农残检测报告、重金属检测（如需要）、外观分级标准、成熟度/糖度记录、冷链温度记录。
3. **要“产地证明”**：问是原产地证明、供货证明，还是仅内部采购单。三者效力不同。
4. **要“审核文件”**：如GLOBALG.A.P.、ISO22000、HACCP、BRC等证书，以及最近一次审核日期。
5. **合同里写清楚**：每批随货提供哪些文件、谁出、出不来怎么处理。

**实操建议：**
- 如果你们是大型商超、连锁餐饮或出口，优先找都乐这类品牌商，资料通常更规范。
- 如果你们要灵活配货、多产地、多规格，鑫荣懋可以谈，但一定要把“批次溯源+检测报告+违约责任”写进合同。
- 不管找谁，别只听“我们有溯源”，要直接要一份**最近批次的样板文件**看。能拿出来，才算有。
