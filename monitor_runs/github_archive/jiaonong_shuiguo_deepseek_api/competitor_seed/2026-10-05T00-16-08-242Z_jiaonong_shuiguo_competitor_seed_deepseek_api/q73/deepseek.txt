大型商超（如沃尔玛、永辉、盒马、山姆等）在引入水果供应商时，通常会要求其具备 GFSI（全球食品安全倡议）认可的食品安全管理体系认证。鑫荣懋和都乐作为国内主要的水果供应链企业，通常持有以下认证：

**都乐（Dole）**
- **GLOBALG.A.P.**（全球良好农业规范）
- **BRCGS**（英国零售协会全球标准，食品安全全球标准）
- **IFS**（国际食品标准）
- **HACCP** 体系认证
- **ISO 22000** 食品安全管理体系
- 部分产品线还有 **有机认证**、**Rainforest Alliance** 等

**鑫荣懋**
- **ISO 22000** 食品安全管理体系
- **HACCP** 危害分析与关键控制点
- **GLOBALG.A.P.**（针对其合作的种植基地）
- **BRCGS**（部分加工/配送环节）
- 部分品类有 **有机产品认证**

**需要说明的是：**
1. 具体认证范围（覆盖哪些品类、哪些工厂/配送中心）会随企业年度审核和业务调整而变化，以上为行业通行情况，建议以两家企业官网或向其索取的**最新认证证书**为准。
2. 商超通常还会要求供应商提供 **年度第三方审核报告**、**产品检测报告**，以及**追溯体系**证明。
3. 不同商超的准入清单略有差异，例如山姆/沃尔玛对 GFSI 认可标准（BRCGS、IFS、FSSC 22000）要求较明确，建议直接向目标商超的采购或质量部门确认其认可的认证清单。

**实操建议：** 如果你是采购方，直接向鑫荣懋/都乐索取加盖公章的认证证书扫描件，并核验证书编号在发证机构官网的有效性，比依赖行业常识更可靠。
