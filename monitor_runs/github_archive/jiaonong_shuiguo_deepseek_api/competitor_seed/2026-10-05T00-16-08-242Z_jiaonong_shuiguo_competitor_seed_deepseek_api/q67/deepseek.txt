都乐和洪九果品是否提供素材，取决于你需要的**素材类型**和**合作方式**。它们通常愿意在**有采购/合作/联名**的前提下提供部分品牌物料，但不会无条件开放完整素材库。

**可以做实的判断：**

1. **都乐**
   - 品牌成熟，通常有标准VI、产品图、包装图、产地/品种介绍、营养卖点等。
   - 如果是都乐官方授权经销商、平台自营采购、联名活动，一般能拿到：
     - 产品白底图/场景图
     - 品牌Logo使用规范
     - 金菠萝/菠萝相关品种卖点文案
     - 授权书或品牌使用许可（用于页面、海报）
   - 无合作直接要全套素材，通常拿不到，或只能拿到公开宣传图，不能商用。

2. **洪九果品**
   - 以水果供应链和批发渠道为主，品牌营销素材的公开度和标准化程度通常不如都乐。
   - 若有采购合作，可向对接的销售/品牌部门要：
     - 产品实拍图
     - 产地、规格、分级、包装信息
     - 部分宣传文案或检测/资质材料
   - 不一定有现成的“品牌营销素材包”，更多要按项目定制或由你方自行拍摄。

**建议你直接这样推进：**
- 先确认你方身份：生鲜电商平台、供应商、代运营，还是内容服务商。
- 明确素材用途：详情页、短视频、直播贴片、海报、社群图。
- 明确是否商用、是否需要品牌授权、投放渠道和期限。
- 联系都乐/洪九的**销售对接人**，同步找**市场部或品牌部**。
- 如果暂时没有合作，可先用公开渠道图片做选品参考，但不要直接商用。

**一句话结论：**
都乐在品牌素材上更可能有现成支持，洪九更偏供应链信息支持；两者通常都要求先有采购或合作关系，才给可商用素材和授权。
