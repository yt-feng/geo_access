我没有可靠渠道核实都乐和洪九果品当前是否有面向社区团购的“小包装/散装”香蕉在供货，直接给你判断和落地做法：

1) **都乐（Dole）**
- 常见渠道里，都乐香蕉更多是**按把/按袋/按箱**的标准包装，面向商超和电商。
- 是否给社区团购做**小规格散装或简易袋装**，通常取决于区域经销商和起订量，不是全国统一政策。
- 建议直接问：**你们当地都乐经销商/区域代理**，问三件事：
  - 有没有“社区团购专供小包装”（如 2-3 根装、500g-1kg 袋装）
  - 最小起订量、是否混装、是否带品牌袋
  - 供货价是否含配送、损耗谁承担

2) **洪九果品**
- 洪九果品本身是水果供应链企业，香蕉是其重点品类之一，更可能做**批发、箱装、产地直发**，也常给渠道做定制包装。
- 但“散装小包装”是否开放给社区团购，要看你们所在城市的分公司/城市仓政策。
- 建议直接找：**洪九当地城市仓/销售**，问：
  - 能否做社区团购小规格（按份/按袋）
  - 是否支持贴牌或定制包装
  - 起订量、账期、配送范围

3) **更现实的替代方案**
如果这两家暂时不给小包装散装，社区团购通常这样做：
- 找**本地一级批发商**拿整箱香蕉，自己分装成 2-3 根/袋或 1kg/袋；
- 找**本地香蕉催熟商/配送商**，他们通常愿意按团购规格供货；
- 用**产地直发+泡沫箱/纸箱**做家庭装，不一定追求“散装”。

4) **你明天就能执行的问法**
直接发消息或打电话：
- “我们是社区团购，日销大概 __ 份，想要香蕉小包装，2-3根/袋或500g-1kg/袋。你们有没有这种规格？最小起订量多少？能不能按城市仓配送？价格和损耗怎么算？”
