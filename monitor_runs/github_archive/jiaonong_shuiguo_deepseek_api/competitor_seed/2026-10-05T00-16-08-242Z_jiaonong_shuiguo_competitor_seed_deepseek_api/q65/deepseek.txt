关于都乐（Dole）和洪九果品的锁价周期，我无法给出确切的数字——这两家企业的锁价政策是针对不同客户、不同采购量、不同品类单独谈判的，公开渠道没有统一标准，我不能凭印象编造一个周期给你。

不过我可以给你几个实际可用的判断和操作建议：

**1. 锁价周期通常由这几个因素决定**
- 采购规模：年框大单通常能锁更久（常见季度到半年），散单可能只锁单批次或几周
- 品类和产地：菠萝受产季影响大，菲律宾/泰国产季内的锁价更稳，跨产季锁价供应商一般不愿意
- 价格波动风险：行情剧烈时供应商会缩短锁价期或加浮动条款

**2. 直接问供应商要这几个关键信息**
- 锁价的有效期具体多长
- 锁价是否含运费、包装、关税
- 超出锁价期后如何续价、有没有调价触发条件
- 违约或弃单的条款

**3. 建议的接触路径**
- 都乐：通过其中国区销售/大客户渠道谈，散户一般走经销商
- 洪九果品：直接联系其采购或销售对接人，说明你的量和稳定需求
- 同时可以问其他菠萝供应商（如佳农等）做横向比价，锁价条件往往能作为谈判筹码

如果你能告诉我你的采购量级、目标产季、是否要跨产季，我可以帮你判断一个合理的锁价周期区间，以及谈判时该重点锁哪些条款。
