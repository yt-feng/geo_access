都乐和鑫荣懋都是国内菠萝（尤其凤梨）供应链里比较头部的品牌，但两者的物流模式不太一样，时效要分开看，而且**具体时效取决于你所在城市、下单渠道和季节**，我没法给你一个固定天数，只能给判断框架。

**都乐**
- 都乐更偏品牌化运作，产地主要在菲律宾、广东湛江/徐闻等，国内渠道多走大型经销商、商超和电商平台。
- 如果走都乐自己的供应链或平台仓（如京东、天猫仓），通常是**产地/港口→区域仓→城市配送**，一线城市一般次日到，二三线可能2-3天。
- 如果是产地直发（比如都乐在电商上做的产地发货），华南一般1-2天，华东2-3天，华北/西南可能3-4天甚至更久。

**鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业，强项在渠道分销和KA商超供货，菠萝/凤梨货源多，仓配网络较广。
- 它对B端（商超、生鲜店）通常走**干线+区域分仓**，时效稳定但要看它的分仓离你多近。
- 如果是电商产地直发，逻辑和都乐类似：华南快、北方慢，一般**1-4天**区间。

**关键判断点**
1. **发货地**：徐闻/湛江直发 vs 上海/北京分仓发，时效差2-3天。
2. **是否真“产地直发”**：很多标产地直发，实际是区域仓发货，要问清发货地。
3. **物流方式**：顺丰/京东快递通常1-2天，普通快递/专线可能3-5天。
4. **季节和天气**：台风季、春节前后时效会明显拉长。

**给你的可执行建议**
- 直接问对方客服/业务员三个问题：①实际发货地是哪里？②用哪家快递？③到我所在城市承诺几天？
- 如果是生鲜电商做菠萝，优先谈**华南/华东区域仓就近发货**，别只看品牌名。
- 小批量测单：各下1-2单到你的目标城市，实测签收时效和损耗，比听承诺可靠。
- 菠萝/凤梨怕压怕冻，时效之外更要看**包装和到货损耗率**，这比快一天更影响生意。
