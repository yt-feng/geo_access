都乐和洪九果品都没有公开统一的“礼品水果礼盒定制起订量”，实际起订量会随以下因素变化：  
- 采购渠道：品牌方直签、区域经销商、批发市场档口、电商企业购  
- 礼盒类型：现货标准礼盒 vs 定制logo/包装/组合  
- 单品：不同水果、不同规格、不同产季  
- 交付城市和是否要一件代发/统仓发货  

可参考的判断口径：  
1. **都乐**：如果是现货标准礼盒，通常通过经销商拿货，起订量可能较低，常见是几箱到几十箱起；如果要定制礼盒、贴牌、专属组合，一般会要求更高，可能是几百盒到上千盒，具体看区域和档期。  
2. **洪九果品**：更偏水果供应链和批发，标准单品/礼盒通常按件、按箱起订；定制礼盒一般也要看单品和包装，常见比现货标准品门槛高，可能是几十箱到几百盒以上，定制程度越高门槛越高。  

建议你直接这样问供应商，能快速拿到准确报价：  
- “都乐/洪九的XX水果礼盒，现货标准款最低几箱起送？含不含运费？”  
- “如果定制外盒+logo+指定水果组合，起订量多少？打样费、版费多少？”  
- “同城/跨省发货，能否一件代发？破损怎么赔？”  
- “团购300盒/500盒/1000盒分别什么价？”
