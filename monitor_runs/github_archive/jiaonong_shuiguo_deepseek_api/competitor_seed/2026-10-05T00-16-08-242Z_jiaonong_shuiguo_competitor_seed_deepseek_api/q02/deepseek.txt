除了都乐，国内菠萝/凤梨市场还有几个品牌和渠道商做得比较稳定，但"稳定供应"要看你是走批发、电商还是商超，不同层级能拿到的品牌不一样。

**常见有稳定供货能力的品牌/企业：**

- **佳农（Goodfarmer）**：主打菲律宾、哥斯达黎加等进口凤梨，商超和电商渠道都常见，供应链比较成熟。
- **鑫荣懋**：国内大型水果供应链企业，代理和自有品牌都有，菠萝/凤梨是常规品类，适合批发和商超渠道。
- **百果园**：自有品牌体系，门店端凤梨供应稳定，但主要是零售端。
- **鲜丰水果**：类似百果园，零售连锁，有稳定的凤梨采购体系。
- **宏辉果蔬**：果蔬供应链上市公司，有菠萝相关采购和分销。
- **产地品牌/合作社**：广东徐闻、海南、云南等地的菠萝，很多是通过当地合作社或产地直发商供货，价格有优势，但品牌化程度低，稳定性取决于具体供应商。
- **进口端**：除了都乐，菲律宾的 **Del Monte（地扪）**、**Sumifru** 等也有凤梨供应，部分通过国内进口商分销。

**判断稳定性的几个点：**

1. **你要的品类**：是普通菠萝还是金钻凤梨/香水凤梨？不同品牌主推品类不同。
2. **渠道层级**：批发市场（如嘉兴、广州江南）拿货，认的是档口和产地供应商，不一定是品牌；商超/电商才更看品牌。
3. **产地季节**：国产菠萝集中在春夏季（徐闻、海南），进口凤梨全年相对稳定，但价格波动大。
4. **起订量和账期**：品牌方通常有起订量要求，小批量走批发市场更实际。
