目前没有可核验的公开资料能直接支持“鑫荣懋和都乐谁的分级更细”的确定结论。两者的香蕉分级通常不是面向消费者公开的统一标准，而是按**渠道、客户订单、产地和批次**执行企业内控规格，所以很难仅凭品牌名做稳定对比。

可以这样判断和落地：

1. **先看你要的分级维度**
   - 按根数/把数：如每把几根、单根重量区间。
   - 按单根重量：如 120–150g、150–180g、180g+。
   - 按长度/粗度：如长度、周径/果指粗细。
   - 按成熟度：如青蕉、微黄、黄熟。
   - 按外观：条蕉、把蕉、有无黑斑、擦伤、断指率。
   - 按装箱规格：每箱净重、每箱把数、每把根数。

2. **不要只比品牌，直接比“规格书”**
   向两家供应商要同一套资料：
   - 香蕉规格分级表
   - 各等级单根重量/长度/根数/把数区间
   - 允收标准：青度、黑斑、机械伤、断指、掉把
   - 装箱标准：净重、毛重、箱规、码放方式
   - 到货验收标准和赔付规则

3. **现场用同一批货做对比**
   同一时间、同一产地、同一成熟度，各抽 3–5 箱：
   - 每箱称净重
   - 数每箱把数、每把根数
   - 抽 30–50 根称单根重量
   - 量长度和粗度
   - 记录黑斑、擦伤、断指、掉把比例
   最后看谁的**区间更窄、等级更多、验收更稳定**，而不是看品牌宣传。

4. **更实际的结论**
   - 如果你要的是**零售小包装或电商精细化分级**，都乐在部分零售渠道的规格呈现可能更标准化，但这不等于其所有渠道都比鑫荣懋细。
   - 如果你要的是**批发、商超配送、定制化分级**，鑫荣懋在国内渠道覆盖和客户定制方面可能更灵活，但同样要看具体区域和采购合同。
   - 真正决定“谁更细”的，是你拿到的**报价单和验收标准**，不是品牌本身。

建议你直接向两家索要同版本规格书，并让采购按“单根重量、每把根数、装箱净重、外观允收率”四项做盲测。这样得到的结论比问品牌谁更细更可靠。
