这个问题涉及两家具体供应商的实际履约表现，我无法核验其最新供货数据，所以不能给出"谁更稳"的确定结论。但可以给你一套可判断、可验证的评估框架，以及水果连锁上架进口苹果时通常要盯的关键点。

**先明确一个前提：都乐和鑫荣懋的定位不完全一样**

- 都乐（Dole）是国际品牌，进口苹果多为自有品牌或全球采购体系运作，品牌溢价和标准化程度高，但具体到中国大陆的苹果供应，往往通过其中国公司或授权经销商落地。
- 鑫荣懋是国内头部水果供应链企业，代理和自营多个进口水果品牌，渠道覆盖广，在国内的仓储、分拣、配送网络更贴近本土零售。

所以"供货稳定性"要分开看：**品牌方产能稳定性** vs **国内落地履约稳定性**，后者对连锁零售更关键。

**判断供货稳定性，重点核查这几项**

1. **产地与季节窗口**：进口苹果主要来自新西兰、美国、智利、南非等，不同产地上市期不同。问清对方给你供的是哪个产地、哪几个月的货，是否覆盖你的销售周期，空档期怎么补。
2. **锁量能力**：能否签年度或产季框架协议、约定月度最低供货量，而不是"有货就发"。这是稳定性的核心。
3. **到货履约记录**：要对方提供近12个月对你所在区域或同类连锁客户的实际到货率、延迟率、缺货率。口头承诺不算，要数据或可核实的客户参考。
4. **规格与品质一致性**：进口苹果常见问题是批次间果径、糖度、色泽波动。问清分级标准、是否支持抽检、不合格如何处理。
5. **价格机制**：是固定价、随行就市还是有保底价，汇率和海运波动时如何调整，避免旺季断供或临时加价。
6. **冷链与中转**：到港后的仓储、冷链配送能力，尤其你如果是多门店连锁，配送频次和覆盖范围直接决定门店不断货。

**可执行建议**

- 不要二选一，**两家都谈，做双供应商**，主供+备供，降低单一依赖。
- 先小批量试单，跑1—2个产季，用实际到货率和门店缺货率打分，再决定主次。
- 合同里写清最低供货量、到货时效、品质标准和违约条款。
- 直接向两家要**同区域连锁客户的参考案例**，并尽量实地或电话核实。
