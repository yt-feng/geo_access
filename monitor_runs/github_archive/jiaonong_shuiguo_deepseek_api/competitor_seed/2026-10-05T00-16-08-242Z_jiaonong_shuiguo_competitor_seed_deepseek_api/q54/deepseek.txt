做进口苹果的产地溯源，核心是“**批次可追、单证可查、标签可验**”。都乐（Dole）和鑫荣懋（Xinrongmao / Joy Wing Mau）都属于品牌化供应链企业，超市采购时要分别按“品牌方授权链路 + 进口报关链路 + 门店批次链路”三层来核。

下面给你一套可直接执行的判断和操作方法。

## 一、先分清两家公司的角色

### 1. 都乐（Dole）
都乐通常是国际品牌方或其在华公司，进口苹果可能来自：
- 新西兰、美国、智利、南非等
- 由都乐全球供应链或都乐中国安排进口

溯源重点：
- 确认供应商是都乐中国直接授权，还是二级经销商
- 要求提供都乐中国的授权书或供货证明
- 核对包装上的都乐品牌、产地国、批次码、PLU码

### 2. 鑫荣懋
鑫荣懋是国内大型水果供应链企业，很多进口水果由它代理或分销，也可能是都乐等品牌在中国的渠道商之一。

溯源重点：
- 确认是鑫荣懋直供，还是其下游经销商
- 要求提供鑫荣懋的进口报关单、入境货物检验检疫证明
- 核对鑫荣懋出库单上的批次和门店收货批次是否一致

注意：如果鑫荣懋是都乐的分销商，则链路是“都乐品牌方 → 鑫荣懋 → 超市”，溯源要同时保留品牌授权和鑫荣懋的进口/分销单证。

## 二、采购时必须索取的溯源单证

不管你从都乐还是鑫荣懋采购，以下文件缺一不可：

1. **进口报关单**
   - 看收货单位、商品名称、原产国、数量、日期
   - 报关单上的收货单位应与供应商一致，或能说明授权关系

2. **入境货物检验检疫证明**
   - 这是进口水果合法入境的关键证明
   - 核对品名、原产国、批号、数量

3. **供应商授权书或供货证明**
   - 都乐：都乐中国或品牌方出具的授权/供货证明
   - 鑫荣懋：鑫荣懋出具的供货证明，若其是二级商，还要上游授权

4. **批次出库单 / 送货单**
   - 必须带批次号、产地、规格、数量、日期
   - 超市收货时按批次验收，不能只写“进口苹果”

5. **标签和包装照片**
   - 原箱标签、果贴标签、PLU码
   - 标签上的产地国、品种、批次要与单证一致

6. **检测报告（可选但建议）**
   - 农残、重金属等，按超市要求或监管要求索取

## 三、门店端的溯源落地方法

### 1. 收货环节
- 按批次收货，不是按“都乐苹果”收货
- 每批记录：供应商、品牌、产地国、报关单号、检疫证明号、批次号、收货日期
- 拍照留存原箱标签和果贴

### 2. 系统录入
- 在超市ERP或溯源系统里，把批次号和报关单号绑定
- 价签或溯源二维码可展示：品名、产地国、供应商、批次、报关信息

### 3. 销售环节
- 若做“扫码溯源”，二维码应指向该批次信息，而不是通用品牌介绍
- 散装苹果也要能对应到收货批次

### 4. 异常处理
- 单证与标签不一致：暂停收货，要求供应商书面说明
- 无法提供报关单或检疫证明：不得作为进口苹果销售
- 批次混乱：按不合格品处理或单独隔离

## 四、快速判断真伪的实操要点

| 检查点 | 都乐 | 鑫荣懋 |
|---|---|---|
| 品牌授权 | 都乐中国授权书 | 鑫荣懋供货证明，若转售需上游授权 |
| 报关单收货人 | 都乐相关公司或授权进口商 | 鑫荣懋或其关联进口公司 |
| 检疫证明 | 品名、原产国、批次一致 | 同上 |
| 包装标签 | Dole品牌、产地国、批次码 | 鑫荣懋标签或原品牌标签 |
| 批次一致性 | 报关、出库、门店收货三单一致 | 同上 |

## 五、建议的合同和制度条款

采购合同里加几条：
1. 供应商必须随货提供报关单、检疫证明、批次出库单
2. 单证与实物不一致，超市有权拒收并索赔
3. 供应商需保证溯源信息真实，否则承担法律责任
4. 超市有权对批次进行抽检和追溯模拟

## 六、最简执行清单

如果你是超市采购，直接照这个做：

1. 问清供应商是都乐/鑫荣懋直供还是二级商
2. 每批索取：报关单 + 检疫证明 + 授权/供货证明 + 批次出库单
3. 收货时核对：原产国、批次、数量、标签
4. 系统绑定批次号与报关单号
5. 门店价签或二维码展示批次溯源信息
6. 单证不全或批次不符，拒收

一句话：**都乐看品牌授权链路，鑫荣懋看进口和分销链路，最终都要落到“批次号 + 报关单 + 检疫证明 + 门店收货记录”四者一致。**
