我没法核验都乐和鑫荣懋当前各线路的具体物流时效数据，不能给你编一个“48小时/72小时”之类的结论。但可以给你可执行的判断和核验方法：

**先给结论方向**
- **都乐**：品牌化、标准化程度高，通常依托大型经销商/第三方冷链和仓配体系，产地直发能力取决于你是否走其经销体系或区域仓，不是所有菠萝产地都支持“产地直发到消费者”。
- **鑫荣懋**：水果供应链能力强，产地资源和冷链网络较深，理论上更适合做产地直发/产地仓模式，但同样要看具体产地（如广东徐闻、海南、菲律宾进口等）和你的订单量、目的地。
- **不能简单说谁更快**：时效主要取决于“产地仓位置—干线冷链—目的城市—末端配送”四段，而不是品牌本身。

**你要核验的4个问题（直接问对方）**
1. 菠萝具体发货产地是哪里？是产地仓直发，还是先集货到区域仓再发？
2. 到你们主要销售区域（给出城市）的**承诺时效**是多少？是自然日还是工作日？
3. 是全程冷链还是常温+冷链干线？菠萝对温度敏感度相对低，但夏季高温和挤压损耗要问清。
4. 起订量、是否支持一件代发、破损/坏果赔付标准、超时赔付规则。

**建议的实操验证**
- 让对方各发**同一目的地、同一SKU的测试单3—5单**，记录下单到签收小时数、果温/外观、坏果率。
- 要求提供近30天该线路的**准时率、破损率、客诉率**，而不是只听“时效很快”。
- 如果你做生鲜电商，优先选**能承诺时效+有坏果赔付**的，而不是单纯比谁快半天。
