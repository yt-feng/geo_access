关于都乐和洪九果品的具体账期，我无法核验到公开、准确的数字，不能给你编一个“多久”。可以确认的是：两家都不是公开挂牌“账期政策”的供应商，账期通常按采购量、合作年限、结算方式、是否直签/经销、品类和区域单独谈，不能当成统一标准。

可执行建议：

1. **都乐（Dole）**  
   - 走**都乐中国/区域经销商**两条线分别问，不要只问一个销售。  
   - 重点确认：是**直营直签**还是**经销供货**；香蕉是**进口菲蕉/厄瓜多尔蕉**还是国产分装；结算是否支持**月结、票到付款、货到付款**。  
   - 首次合作大概率难直接给长账期，可谈**首单现结/短账期，连续稳定采购后转月结**。

2. **洪九果品**  
   - 洪九以水果分销为主，账期更可能和**区域分公司、品类采购量、是否走其供应链平台**有关。  
   - 直接问区域销售：**月结周期、起订量、是否收保证金、逾期计息、发票类型**。  
   - 不要只问“账期多久”，要问“**在什么采购条件下能给到什么账期**”。

3. **谈判时让对方书面确认**  
   至少写清：结算周期（如货到30/45/60天）、对账日、开票日、付款日、逾期条款、是否可分批结算。口头“可以月结”不等于合同账期。

4. **备选供应商**  
   如果这两家账期不理想，可同步找**一级香蕉进口商、区域批发市场大户、连锁商超水果供应链服务商**，这类供应商更可能给**7—30天试合作账期**，但通常要求保证金或首单现结。

结论：**都乐和洪九的具体账期没有可核验的公开统一标准，必须按你的采购规模向对应区域销售书面询价确认。** 建议你同时向两家要“账期报价单”，用同一采购量对比。
