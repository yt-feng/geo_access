大型商超通常会要求生鲜/食品供应商具备可核验的食品安全与质量体系认证。就鑫荣懋和都乐而言，能明确说的是：

- **都乐（Dole）**：作为跨国果蔬企业，公开可查的体系通常涉及 **GFSI 认可的食品安全认证**（如 BRCGS、IFS、FSSC 22000 等，具体到某个法人/包装厂需看证书）、**ISO 9001 质量管理体系**、**ISO 22000 食品安全管理体系**，以及农业端的 **GlobalG.A.P.** 等。具体哪些工厂/品类持证，要以证书编号和认证范围为准。
- **鑫荣懋**：公开信息常见其具备 **ISO 9001、ISO 22000/HACCP** 等体系认证，并在部分品类/基地涉及 **GlobalG.A.P.** 等农业规范。具体到供货主体、加工厂和品类，同样需以有效证书为准。

**可执行建议**：不要只问“有没有认证”，而应要求供应商提供与本次供货主体、工厂、品类一致的有效证书（含证书编号、认证范围、有效期、发证机构），并在认监委/认证机构官网或 GFSI 数据库核验；商超审核时重点看认证范围是否覆盖实际生产场所和产品。由于我无法在此核验两家企业当前具体证书清单，以上不构成对其现时持证情况的保证。
