1. **都乐（Dole）**：作为大型果蔬品牌，一般有批次农残检测/质量检测体系，但门店或小批量采购通常通过经销商拿货。能否给报告取决于你从品牌直供还是经销商采购。直采可向都乐区域销售申请；经销采购要让经销商提供该批次检测报告或厂家报告复印件。

2. **鑫荣懋**：同样属于大型水果供应链企业，通常可提供批次质检/农残检测报告，但也多通过其销售或经销渠道对接。需要在订单合同中写明“随货提供该批次农残检测报告（或复印件/电子版）”，并约定报告项目、检测机构、批次对应关系。

3. **关键可执行建议**：
   - 下单前书面确认：**是否提供、报告类型（农残检测/出厂检验/第三方检测）、是否对应到货批次、电子版是否可用**。
   - 要求报告上的**样品批次/生产日期/供货商名称**与到货批次一致，避免“一份报告长期通用”。
   - 若对方只给“合格证”或“型式检验报告”，要区分：型式检验不等于每批次农残检测。
   - 茶饮店自检/抽检需求高时，可在合同里约定**每季度或每批次第三方检测**，费用和责任写清。

结论：**都乐和鑫荣懋大概率能提供，但必须采购前约定到批次，不能默认随货就有。** 建议你直接向对接销售问一句：“这批菠萝能否随货提供对应批次的农残检测报告电子版？检测项目和检测机构是什么？”
