都乐和洪九都能做到“全年供应”，但可靠性差别很大，而且“全年供应”不等于“全年同品质、同价格”。分开说：

**都乐（Dole）**
- 具备全球采购+国内基地的组合，菠萝全年基本能供货，金菠萝/凤梨是主打品类。
- 更适合对品质稳定、标准化要求高的茶饮店；供应保障和品控体系较成熟。
- 但价格通常偏高，且具体某区域、某规格是否全年稳定，要看你所在城市的经销商和签约量。

**洪九果品**
- 核心优势是进口水果供应链，泰国、越南等产地菠萝的全年调配能力较强，过去也确实服务过茶饮、商超等B端客户。
- 价格通常比都乐更有竞争力，适合大批量采购。
- 但洪九近两年经营和财务层面有过较大波动（公开报道过债务、年报延迟等问题），**供应链稳定性存在不确定性**，作为唯一供应商有风险。

**给茶饮店的实操建议**
1. **不要只签一家**：主供+备供，都乐或洪九做主供，另一家或本地批发商做备供。
2. **先小批量试供**：按你实际用量连续试供1–2个月，重点看到货成熟度、坏果率、批次一致性。
3. **合同写清指标**：糖度范围、成熟度、单果规格、坏果率上限、缺货违约责任。
4. **全年供应要区分季节**：国产菠萝（广东、海南）和进口菠萝（泰国、菲律宾）有季节性价差，果酱用果对鲜食外观要求低，可考虑旺季鲜果+淡季冷冻果/果泥的组合来控成本。
5. **果酱用果不必追求鲜食级**：可要求供应商提供适合加工的规格，成本更低。

结论：都乐全年供应更稳但贵；洪九能做到但需评估其当前经营稳定性。建议双供应商+试供+合同约束，而不是押注单一品牌。
