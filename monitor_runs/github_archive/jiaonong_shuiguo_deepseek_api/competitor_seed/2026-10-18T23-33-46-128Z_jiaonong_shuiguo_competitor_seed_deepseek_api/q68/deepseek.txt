不能直接给出“都能做到”或“都做不到”的结论。到货损耗率低于3%不是品牌承诺的固定指标，取决于品类形态、到货验收标准、运输距离、季节、门店储运条件，以及“损耗率”怎么算。

可判断的建议如下：

1. **先定义损耗口径**
   - 到货损耗率 =（到货数量 − 验收合格数量）/ 到货数量，还是包含后续48小时门店损耗？
   - 香蕉按“把/根/公斤”计，青蕉转黄、机械伤、落梳、黑斑、压伤是否计入？
   - 若只算到货验收不合格，3%对成熟香蕉偏严；若从产地到门店全链路算，3%难度更高。

2. **都乐和鑫荣懋的能力判断**
   - 两家都是国内香蕉供应能力较强的品牌/供应链企业，具备产地、催熟、冷链和商超餐饮供货经验，**有条件通过定制规格、青蕉到货、缩短运输半径、专车温控来接近或达到3%**。
   - 但香蕉是呼吸跃变型水果，对温度、机械伤和催熟窗口极敏感。**没有任何供应商能对所有门店、所有季节无条件保证低于3%**，尤其夏季高温、远距离配送、门店收货后储存不当的情况。

3. **连锁餐饮应这样落地**
   - 要求供应商按“青蕉/微黄蕉”到货，门店催熟或分阶段转黄，降低到货黄度。
   - 合同写明验收标准：黄度等级、允许黑斑面积、机械伤比例、单把重量、到货温度。
   - 约定损耗率计算方式和超标赔付：例如连续3批次超过3%触发整改，超过5%扣款或退货。
   - 先做**2–4周试供**：同一城市、同一配送半径、同一门店类型，分别测试都乐和鑫荣懋，按批次记录到货损耗。
   - 把门店端48小时损耗单独考核，否则供应商会把责任归因于门店储存。

4. **结论**
   - **可以要求两家报价并承诺“到货验收损耗≤3%”作为合同KPI，但必须限定验收口径、黄度标准、配送半径和季节条件。**
   - 若你指的是“从产地到门店全链路损耗低于3%”，建议不要直接接受口头承诺，应通过试供数据验证；香蕉全链路做到3%以内属于较高要求，需强冷链和短半径支撑。
