我不能核验都乐（Dole）和洪九果品是否公开了“企业标准”文本，所以不能直接断言“有”或“没有”。可判断的是：两家企业都会有内部香蕉商品分级/验收规范，但不等于公开可查的企业标准。都乐作为国际果蔬品牌，通常以全球/区域产品规格、客户合同规格和内部质量手册控制香蕉等级；洪九果品作为国内水果供应链企业，通常以采购验收标准、客户交付规格和内部品控文件执行分级。这些多为非公开文件，公开渠道未必能检索到“企业标准”编号。

给你的可执行建议：
1. 先去“企业标准信息公共服务平台”按企业名称检索，看是否有已自我声明公开的香蕉相关标准；这是判断“公开企业标准”的最直接依据。
2. 向都乐/洪九的业务或品控部门索取“香蕉产品规格书/验收标准”，比问“有没有企业标准”更实际；连锁店采购可直接把对方规格书作为对标依据。
3. 若用于门店分级，不要依赖对方企业标准，建议自建“可执行分级卡”：按品种（如巴西蕉、皇帝蕉）、等级（特级/一级/二级）、果指长度、单果重、条数/箱、成熟度（色卡1-7）、果面缺陷、机械伤、青软/黄熟比例、到货温度、允许损耗率设定验收阈值。
4. 合同里写明“以双方确认的规格书为验收依据”，并保留到货抽检记录；这样即使对方企业标准不公开，也能形成可执行标准。
