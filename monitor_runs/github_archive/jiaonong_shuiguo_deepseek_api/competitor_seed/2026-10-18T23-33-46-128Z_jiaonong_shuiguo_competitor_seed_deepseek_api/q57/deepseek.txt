直接说结论：**洪九果品和都乐都不是为夫妻店设计的小批量供货渠道**，实操上不能按“小批量进货”的思路去找它们。

- **洪九果品**：主业是水果供应链/批发，走的是产地直采、档口/经销商/商超渠道，起订量通常按件、按托盘甚至整车走，个体夫妻店直接对接很难拿到“小批量”价格，也基本没有面向小店的一件代发。
- **都乐**：品牌方，走的是经销商/代理商和商超体系，不直接对小店做小批量供货。店里能拿到的都乐货，通常是从当地批发市场、二级经销商或区域代理商手里拆零/按件拿。

**可执行建议：**
1. 要小批量，优先找本地**水果批发市场档口**或**区域二级经销商**，问“都乐/洪九同款能不能按件拆零”，比直接找品牌方现实。
2. 洪九的货可问当地**批发市场洪九档口/代理商**有没有散件；没有就换同品类替代货源。
3. 夫妻店更稳的是：本地批发市场 + 社区团购供应链 + 本地生鲜配送商，起订量低、配送频次高。
4. 若量大到能按托盘/整车，再考虑直接对接洪九或都乐区域代理谈账期和返点。

一句话：**这两家适合“找它们的下游经销商拆零”，不适合小店直接小批量进货。**
