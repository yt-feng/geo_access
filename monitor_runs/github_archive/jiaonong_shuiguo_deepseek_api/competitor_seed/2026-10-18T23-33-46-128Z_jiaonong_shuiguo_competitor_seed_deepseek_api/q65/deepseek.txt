关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法给出确切的官方数字：这两家企业的锁价安排通常属于**按客户、按品类、按年度合同/框架协议单独谈判**的商业条款，公开渠道一般不会披露统一“锁价周期”，我也不应虚构具体天数。

可以明确判断和执行的建议如下：

1. **不要按“公司统一锁价周期”去问**  
   都乐、洪九这类水果供应链企业，菠萝锁价通常取决于：
   - 品种（如金钻凤梨、巴厘菠萝等）
   - 产地/产季（国产或进口）
   - 采购量级与合作年限
   - 是否签年度框架协议
   - 是否接受预付款/保证金
   - 市场价格波动区间与调价触发条件

2. **直接向对方索要“锁价条款样本”**  
   可要求供应商提供：
   - 锁价有效期（例如按周、按月、按产季）
   - 锁价适用数量上限
   - 超出数量后的计价方式
   - 调价触发条件（如产地价涨跌幅超过X%）
   - 违约与保证金条款

3. **谈判时可参考的锁价周期区间**  
   生鲜水果行业常见做法是：
   - 短期锁价：7–15天
   - 中期锁价：1个月
   - 产季锁价：按单个产季或3个月左右  
   但这只是行业常见区间，**不能视为都乐或洪九的官方政策**。

4. **建议的询价话术**  
   “请确认贵司菠萝产品是否支持锁价，锁价周期最短/最长分别是多少，对应最小起订量和保证金要求，并请提供锁价合同条款样本。”
