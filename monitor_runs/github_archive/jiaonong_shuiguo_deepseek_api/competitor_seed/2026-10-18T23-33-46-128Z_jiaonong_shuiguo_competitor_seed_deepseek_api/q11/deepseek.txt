都乐和洪九果品的菠萝“性价比”不能一概而论，关键看你门店的**定位、客群价格敏感度、损耗控制能力**。给你一套可落地的判断方法：

## 先明确“性价比”对水果连锁店意味着什么
不是单纯比进货价，而是比：
**单只到手成本 → 出品率（去皮后可用果肉比例）→ 损耗率 → 动销速度 → 毛利额**

## 两个品牌的一般特点（需你自行向供应商核实当前批次）
- **都乐**：品牌力强、标准化程度高、包装和品控稳定，适合做中高端陈列和礼盒/单只零售；通常采购价偏高，但客诉率和损耗相对可控，适合对“稳定出品”要求高的门店。
- **洪九果品**：国内果品供应链企业，品类覆盖广、价格通常更有弹性，适合做走量、促销和散称；但不同批次、不同产区的品质一致性需要你重点验货，损耗管理要求更高。

## 建议你按这5步实测再定
1. **同规格对比进货价**：按“每斤/每只”折算，不要只看箱价，注意箱规、净重、大小等级。
2. **算出品率**：各拿10只去皮称重，算果肉得率。菠萝品种（如金钻、普通菠萝）和成熟度差异很大，出品率能直接拉开成本。
3. **测损耗**：常温/冷藏各放3–5天，看黑心、烂心、出水比例。菠萝损耗是性价比的核心变量。
4. **看动销**：同一门店做3天AB测试，看单只零售、切块、促销三种卖法的销量和毛利额。
5. **算综合毛利额**：`（售价×出品率－进货成本－损耗成本）÷售价`，比毛利率更真实。

## 直接可执行的结论框架
- 门店偏**中高端、社区精品、礼盒/单只零售**：优先试**都乐**，用稳定性换低客诉和低损耗。
- 门店偏**走量、促销、切块散称、价格敏感客群**：优先试**洪九**，但必须建立到货验货和先进先出制度。
- **最优做法不是二选一**：都乐做形象款/单只，洪九做走量款/切块促销，用价格带分层覆盖客群，同时对比两者的综合毛利额再调整采购比例。

## 需要你向供应商核实的硬信息
当前批次产地、品种、等级、箱规净重、到店价、账期、退换货政策、是否支持小批量试销。这些确认后，上面的AB测试才有意义。
