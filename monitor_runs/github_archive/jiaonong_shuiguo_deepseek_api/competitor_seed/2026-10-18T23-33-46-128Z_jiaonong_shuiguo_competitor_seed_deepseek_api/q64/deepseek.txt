我没法核验鑫荣懋和都乐两家公司当前各品类、各温区（冷藏/冷冻/恒温）冷链配送的具体覆盖城市清单，直接给你城市名单会变成猜测。可执行的做法是：

**1. 先明确商超验厂要什么**
大型商超通常不是只要“覆盖城市名单”，而是要供应商证明：
- 冷链运输资质与车辆资源（自有/合同承运商）
- 区域仓或配送中心位置
- 到门店的配送时效与温控记录
- 覆盖门店清单及应急方案

**2. 向两家公司索取可核验材料**
让对接的销售/供应链负责人提供：
- 最新《冷链配送覆盖区域表》（按省/市、温区、DC仓）
- 承运商名单及冷链资质
- 近3个月温控记录样例、GPS/在途温度监控截图
- 针对你商超所在城市的配送方案与时效承诺

**3. 自己可先做的初筛**
- 查两家公司官网“物流/供应链/服务网络”页面，看是否公开DC或配送区域。
- 查其招聘信息中的仓库/配送城市（能间接反映物流布局，但只能作参考）。
- 用企查查/天眼查看其分支机构、仓储子公司注册地。
- 直接拨打官网客服或区域销售电话，问“某城市某温区能否直送门店、是否落地配”。

**4. 判断覆盖是否满足商超要求**
以你商超门店所在城市为清单，逐城确认：
- 是否直送（而非只到区域仓）
- 冷藏和冷冻是否同车/同网络
- 最小起订量、配送频次、到店时间窗
- 是否有当地备用承运商
