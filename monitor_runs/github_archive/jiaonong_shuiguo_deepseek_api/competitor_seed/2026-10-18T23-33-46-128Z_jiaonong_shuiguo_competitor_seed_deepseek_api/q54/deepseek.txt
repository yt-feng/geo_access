都乐和鑫荣懋的进口苹果溯源，核心是“单证链 + 批次码 + 现场核验”三件事，分开说：

## 一、都乐（Dole）
都乐进口苹果通常走品牌自有供应链，溯源抓手主要是：
1. **箱标批次码**：都乐外箱一般有生产批次/包装日期/原产国/果园或包装厂注册号（如 Pack House Code），采购时要求供应商提供与到货批次一致的箱标照片。
2. **原产地证明**：要求提供出口国官方植物检疫证书（Phytosanitary Certificate），证书上的原产国、果园/包装厂注册号应与箱标一致。
3. **都乐授权链**：确认供应商是都乐授权进口商/经销商，可要求出示授权书或采购合同链，避免“贴牌都乐”。
4. **可追溯系统**：都乐部分市场有批次追溯查询，可让供应商提供其内部追溯单号，核对发货批次与到货批次是否对应。

## 二、鑫荣懋
鑫荣懋是国内大型水果进口商，多为代理多个产地品牌，溯源要点：
1. **报关单 + 入境货物检验检疫证明**：这是最硬的单证，核对品名、原产国、数量、生产日期/批次与实物是否一致。
2. **供应商授权/购销合同链**：鑫荣懋出货通常有销售单，单上应有批次号，要求逐级提供从鑫荣懋到你供应商的购销凭证。
3. **箱标与标签**：进口苹果中文标签应含原产国、境内经销商/进口商、保质期等；箱标果园/包装厂代码与检疫证书对应。
4. **产地证书核验**：通过海关或单一窗口可核验报关单真伪（供应商配合提供报关单号），重点看原产国与证书是否匹配。

## 三、通用可执行动作
- **到货前**：要求供应商提供“一批一档”：检疫证书、报关单、箱标照片、购销合同/发票，四者批次号必须能串起来。
- **到货时**：抽箱核对箱标批次号与单证一致，拍视频留证；中文标签与箱标原产国一致。
- **异常判断**：单证批次与实物对不上、箱标无包装厂代码、授权链断档，直接拒收或要求补证。
- **留档**：每批建立溯源档案，保存至少2年，便于市场监管抽查和客诉追溯。

一句话：都乐看“品牌授权+箱标批次”，鑫荣懋看“报关单+检疫证+购销链”，两者都要做到单证批次与实物箱标三码合一。
