可以，但“提供素材”要分两层看：**品牌方可提供官方素材/授权素材**，**平台或营销服务商也可提供通用素材**。就都乐和洪九果品而言：

1. **都乐（Dole）**
   - 通常有较成熟的品牌视觉体系，可能提供：品牌Logo、产品图、产地/品种介绍、营养卖点、包装图、部分宣传视频或社媒素材。
   - 但正式商用通常需要走**品牌授权/素材使用确认**，尤其是电商详情页、直播切片、达人二创。
   - 建议联系都乐中国区市场部/电商渠道负责人，或通过其经销商/代理索取“品牌素材包+使用规范”。

2. **洪九果品**
   - 作为水果供应链企业，通常能提供：产品实拍图、规格分级、产地信息、包装与物流卖点、部分检测/资质材料。
   - 品牌营销素材的标准化程度可能不如都乐，更多依赖**销售对接人提供实拍和产品资料**。
   - 建议联系洪九果品对应品类销售/市场对接人，明确用途（详情页、短视频、直播背景、达人brief）后索取。

**可执行建议：**
- 先列素材清单：Logo、产品图、产地证明、检测报告、包装图、卖点文案、视频、达人授权范围。
- 向两家分别发正式需求邮件，写明：使用渠道、使用期限、是否二次剪辑、是否付费投放、是否需要授权书。
- 若对方不直接提供，可要求其**经销商/一级代理**提供，并在合同中约定素材授权。
- 不要默认“拿到图就能商用”，生鲜品牌对Logo、包装、产地宣称较敏感，需留存书面授权。

**判断标准：** 能拿到“官方素材包+使用规范+书面授权”即可推进；只有销售发的零散图片，建议仅内部参考，不直接用于公开投放。
