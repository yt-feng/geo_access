可以直接按“企业+产区”来判断，但注意：**都乐（Dole）和洪九果品都不是只靠一个“基地”供菠萝**，而是多产区、多加工厂组织供应链。采购时不要只问“基地在哪”，要问“具体供货工厂/包装厂+产区+季节窗口+规格”。

### 1）都乐（Dole）
都乐在中国菠萝供应主要以**菲律宾进口**和**国内产区组织**为主，公开可核验的信息应以其官方渠道为准。采购上可这样判断：
- **进口菠萝**：主要看菲律宾产区（如棉兰老岛等菠萝主产区），到港口岸常见为上海、深圳、广州等，具体批次需向供应商索取**原产地证、植物检疫证、港口/报关信息**。
- **国内供应**：都乐在中国有合作种植/加工与配送体系，但“基地”通常不是单一自有农场，需让供应商提供**包装厂地址、备案果园/合作农场证明**。
- **采购建议**：要求都乐经销/直供方提供当季**供货产区+包装厂+到货港/仓**，并锁定规格（如金菠萝/MD2、单果重、糖度、黑心控制标准）。

### 2）洪九果品
洪九果品是水果供应链企业，菠萝供应同样以**多产区采购+分选加工+冷链配送**为主，不是单一基地。可核验的采购判断点：
- **国内产区**：广东（徐闻/雷州等）、海南、广西、云南等菠萝/凤梨产区按其季节组织货源；具体批次产区要问供应商。
- **进口补充**：菲律宾、泰国等进口菠萝/凤梨也可能按其客户订单组织。
- **加工/分选**：重点索取**分选包装厂地址、备案资质、农残检测报告、冷链记录**，而不是只问“基地在哪”。
- **采购建议**：要求洪九业务提供当季**主供产区、替代产区、周供应量、规格分级、损耗与赔付条款**。

### 给采购的可执行动作
1. 向两家供应商发同一张表：**产区/包装厂地址、季节窗口、周供量、规格、糖度/黑心率、农残检测、报价条款、断供应急产区**。
2. 要求提供**果园备案/合作证明、包装厂资质、检测报告、原产地证（进口时）**。
3. 不要只锁定一个“基地”，至少配置**主供产区+备用产区**，并做小批量到货验收后再放量。
