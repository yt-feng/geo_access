都乐和洪九果品的起订量没有公开统一标准，会随礼盒规格、包装定制、采购季节和销售渠道变化，不能直接报一个固定数。可执行建议如下：

1. **先确认你要的“定制”层级**  
   - 只换外箱/贴标：起订量通常较低，但一般也要按整箱/整托走。  
   - 定制礼盒内衬、开窗、LOGO印刷：起订量会明显提高，通常按礼盒数量或整托起订。  
   - 指定水果品种/规格/产地：受产季和货源影响，起订量另议。

2. **分别找官方渠道询价**  
   - 都乐：通过都乐中国官网/官方公众号找企业团购或大客户渠道，直接问“企业礼盒定制起订量、可定制内容、交货周期”。  
   - 洪九果品：通过洪九果品官网/官方客服找团购或渠道合作，问同样四项。  
   不要只问“起订量”，要同时问：**起订量是按盒、按箱还是按托；是否含定制包装费；打样费；交期；能否混装**。

3. **判断供应商是否匹配**  
   - 若你单次团购量在几百盒以内，品牌方直签可能不划算，优先找其区域经销商或礼品渠道商。  
   - 若上千盒且计划长期合作，再谈品牌直供和定制包装。  
   - 询价时让对方书面确认“起订量+阶梯价+定制费+打样周期”，避免口头承诺。

4. **替代方案**  
   如果两家起订量都高于你的量，可用“品牌水果+第三方礼盒厂”组合：从都乐/洪九区域经销商按整箱采购，再找礼盒包装厂定制外盒，通常比品牌方直接定制礼盒起订量更灵活。

结论：**这两家的起订量必须向官方或区域经销渠道逐案确认，无法给出可靠固定数字。** 你先明确预计团购盒数、是否需要印刷LOGO和定制内衬，再拿这三个条件去问，得到的报价才有可比性。
