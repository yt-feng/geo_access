这类到货损耗率属于企业采购端的实际运营数据，公开渠道通常没有可核验的统一口径，我无法给出都乐和鑫荣懋的准确损耗率数字。直接给数会误导你。

更可执行的做法：

1. **先统一定义**：把“到货损耗率”拆成可验收指标，否则两家报的数不可比。
   - 到货破损/压伤率
   - 腐烂/霉变率
   - 规格不符率（单果重、果径、成熟度）
   - 短重率
   - 拒收率
   - 门店/仓库端7天货架期损耗率

2. **用试单拿真实数据**：同一规格、同一季节、同一运输距离，各下3—5批试单，按上述指标逐批验收记录。茶饮用菠萝建议同时记录糖度、成熟度、去皮出成率，因为损耗不只在到货，还在加工出成。

3. **合同里写清验收标准**：单果重区间、果径、成熟度、糖度下限、允许破损比例、超标扣款/拒收规则、冷链温度记录要求。

4. **向供应商直接索取**：要求两家提供近3个月同品类同区域的到货验收报表或质量异常统计，并约定以你方验收数据为准。

5. **判断建议**：如果供应商只能给“大概几个点”而拿不出分项数据，说明其质量追溯能力有限；优先选能提供批次验收记录、并能接受试单对标的供应商。

如果你告诉我你的到货城市、单批量和加工方式（鲜切/榨汁/门店现切），我可以帮你把验收表和试单记录模板列得更具体。
