**判断框架（建议按这4项核验）：**
1. **体系认证**：ISO 22000 或 FSSC 22000（食品安全管理体系）；有 FSSC 22000 通常更受大型商超认可。
2. **产品/供应链认证**：如 GlobalG.A.P.（果蔬种植环节）、BRCGS（包装/加工环节，若有加工厂）。
3. **国内合规与准入**：食品生产/经营许可、进出口相关资质（若涉及进口果品）。
4. **证书有效性**：认证机构、证书编号、覆盖范围（具体品类/工厂/基地）、有效期，是否可在发证机构官网查询。
