我不能核验都乐（Dole）和鑫荣懋当前对水果连锁的实际供货稳定性数据，也不能虚构产区、到货率或履约数据。可直接给结论：**两家都具备规模化进口水果供应能力，但“稳定性”必须按你所在城市、品类（进口苹果具体品种/规格）、订货量和结算方式来验证，不能仅凭品牌判断。**

建议你用下面这套可执行方式做判断：

1. **先限定进口苹果的具体品种和规格**
   - 例如是新西兰、美国、智利还是南非产季苹果，规格是80/88/100/113等，包装是原箱还是小包装。
   - 不同品种产季不同，单一品牌“稳定”不代表你要的SKU稳定。

2. **向两家分别索要近12个月供货记录**
   要求提供：
   - 你所在区域或邻近仓的到货周次；
   - 目标SKU的缺货率、替换率、迟到率；
   - 产季切换期和春节前的保供方案；
   - 冷链到店温度和损耗赔付标准。

3. **做小规模并行试单**
   - 选2—3个门店、连续4—6周，对两家各下同一规格订单；
   - 记录到货准时率、缺货次数、替代品接受度、到店损耗率、索赔响应时长；
   - 以“到店可售率”和“综合毛利”而不是进货价做决策。

4. **看合同中的稳定性条款**
   重点关注：缺货补偿、产季断供提前通知、价格调整机制、最低起订量、区域仓覆盖、退换货和损耗责任。

5. **不要只依赖单一供应商**
   进口苹果受产季、海运、汇率和检疫影响明显。连锁更稳妥的做法是：**主供+备供+替代品种**，并对核心SKU设置安全库存。
