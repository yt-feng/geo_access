从“产地溯源透明度”这个单一维度看，**都乐（Dole）通常比洪九果品更容易查到公开、可核验的溯源信息**，但“谁更透明”不能只看品牌名气，要看你需要的溯源颗粒度。建议按下面标准判断并直接向供应商索取材料。

**1. 都乐的优势：品牌化和国际溯源体系更成熟**
- 都乐有全球化的种植、包装和供应链体系，公开披露的产地、品种、包装厂信息相对更多。
- 进口菠萝常可通过包装标签、批次号、原产地标识追溯到国家/产区/包装厂。
- 适合需要**进口菠萝、标准化包装、批次追溯**的采购方。
- 注意：都乐中国市场的具体批次能否追溯到“单个果园”，仍要以供应商提供的批次证明为准，不能仅凭品牌判断。

**2. 洪九果品的优势：国内渠道和产地资源强，但公开溯源信息颗粒度不一**
- 洪九果品以国内水果分销和产地采购见长，菠萝等单品可能来自国内或进口产区。
- 其优势在渠道覆盖和产地采购能力，但公开可查的逐批溯源信息不如都乐标准化。
- 如果你要的是**国内产区直采、灵活定制包装、陪同验厂**，洪九可能更配合；但需要合同里明确溯源要求。

**3. 直接可执行的判断方法**
向两家同时发一份《溯源信息需求表》，要求提供：
- 本批菠萝的产地（国家/省/县/果园或合作社）
- 包装厂名称及注册号
- 采摘日期、包装日期、批次号
- 农残检测报告和出口/入境检验检疫证明（进口则要）
- 是否支持包装箱二维码或批次查询
- 是否接受第三方验厂/飞行检查

**结论：**
- 要**公开可查、标准化批次追溯、进口菠萝**：优先接触都乐。
- 要**国内产地直采、渠道灵活、可谈深度验厂**：可重点谈洪九，但必须把溯源条款写进合同。
- 单看“透明度”，都乐更占优；但最终选谁，取决于你能否拿到上述可核验文件。谁愿意提供**批次级、可验证、可追责**的材料，谁就更透明。
