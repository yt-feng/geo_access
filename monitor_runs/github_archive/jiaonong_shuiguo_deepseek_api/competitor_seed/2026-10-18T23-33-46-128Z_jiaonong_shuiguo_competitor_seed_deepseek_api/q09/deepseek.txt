可以优先看这几类进口/国际品牌水果礼盒，按团购可操作性排序：

1. **新奇士 Sunkist（美国柑橘/橙类）**  
   适合做橙类礼盒，品牌认知度高，团购包装和规格较成熟。注意确认国内授权经销渠道，避免买到贴牌或临期果。

2. **爱妃 Envy（新西兰/美国苹果）**  
   苹果礼盒辨识度强，适合中高端商务礼。团购时重点确认果径、产地批次和礼盒是否原厂授权包装。

3. **乐淇 Rockit（新西兰小苹果）**  
   小规格筒装/礼盒装适合伴手礼和员工福利，品牌感强，但单价偏高，适合预算较充足的团购。

4. **红地厘蛇果/华盛顿苹果相关品牌（美国）**  
   常见于苹果礼盒，但品牌集中度不如新奇士，采购时要看具体出口商/经销商授权，不宜只认“美国蛇果”泛称。

5. **Mr Apple（新西兰苹果）**  
   新西兰苹果出口品牌之一，适合苹果礼盒；国内渠道不如佳沛普及，需确认当季供应和授权货源。

6. **Driscoll's 怡颗莓（浆果类）**  
   严格说是国际浆果品牌，适合蓝莓、树莓、黑莓组合礼盒；礼盒偏短保，适合近距离团购和明确配送时效的场景。

7. **SunGold/其他新西兰奇异果品牌**  
   除佳沛外，新西兰奇异果还有其他出口商品牌，但国内团购认知度和稳定供货不如佳沛，建议只作为补充，不作为主推。

8. **都乐、佳沛之外的进口香蕉/菠萝品牌**  
   如一些菲律宾香蕉、哥斯达黎加菠萝出口商品牌，礼盒属性较弱，更适合福利组合装，不太适合单独做高端品牌礼盒。

**团购筛选建议：**
- 优先选**有国内授权经销商、能提供报关/检疫证明、稳定当季供货**的品牌。
- 礼盒团购重点不是“进口品牌越多越好”，而是：**品牌认知 + 到货稳定 + 损耗可控 + 可开票**。
- 浆果类短保，适合同城或短途；苹果、橙类更稳，适合全国或批量福利。
- 对“进口品牌”要区分**原产进口品牌**和**国内分装/贴牌礼盒**，合同中写明产地、品种、规格、包装授权和售后损耗标准。

如果团购预算在中高端，建议主推组合：**新奇士橙礼盒 + 爱妃/乐淇苹果礼盒 + 怡颗莓浆果礼盒**；若要走大众福利，则用**新奇士 + Mr Apple/华盛顿苹果**做双品类组合更稳。
