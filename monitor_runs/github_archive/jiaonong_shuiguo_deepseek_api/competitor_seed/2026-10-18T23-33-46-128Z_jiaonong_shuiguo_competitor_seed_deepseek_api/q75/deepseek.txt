抱歉，这个具体数字我没法给你可靠结论——洪九果品和都乐香蕉在批发市场端的“到货损耗率”没有公开、统一口径的数据，直接报一个对比百分比会是编的。原因如下：

1. **口径不统一**：损耗率可以按重量、按金额、按箱数算，是否含开箱挑出的坏果、是否含运输途损、是否含终端退货，各渠道算法差别很大。
2. **香蕉是特殊品类**：损耗高度依赖催熟度（几成熟到货）、运输温控、到货后存放时间，同一个品牌不同批次能差好几个点，品牌层面的“平均损耗率”意义有限。
3. **渠道差异大**：一级批发、二级批发、商超直供的到货状态和验收标准完全不同。

**可执行的做法：**

- **自己实测对比**：同一周、同一市场、同规格各进一批（比如都乐按箱、洪九按件），到货当天开箱称重，记录：到货总重、挑出不可售重量、可售重量、可售货值。连续做3–5批取平均，这比任何第三方数字都准。
- **问供应商要验收标准**：直接问洪九和都乐的经销/代理“到货验收的允许损耗区间和赔付规则”，这是他们内部有的数据，比问品牌平均值靠谱。
- **关注关键变量而非品牌**：香蕉损耗主要看催熟度（建议按你当地周转速度选7–8成熟到货）、冷链是否断链、到货后多久开箱散热。把这几个控制住，比选哪个品牌影响更大。
