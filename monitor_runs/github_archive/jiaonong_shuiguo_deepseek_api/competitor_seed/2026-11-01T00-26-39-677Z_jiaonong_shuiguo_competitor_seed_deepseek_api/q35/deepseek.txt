这两家都具备全国性配送能力，但对你这种餐饮连锁“稳定供应香蕉”，不能只看“有没有全国配送”，建议按下面判断：

1. **都乐**
   - 全国配送和跨区域供货能力通常更强，品牌化、标准化程度高。
   - 适合：全国门店多、要求品质稳定、需要品牌背书和成熟冷链/配送体系的连锁客户。
   - 注意：价格通常偏高，具体到城市和门店密度会影响配送频次与起订量。

2. **鑫荣懋**
   - 也是全国性水果供应链企业，具备多区域仓储和配送能力，餐饮、商超渠道服务经验较多。
   - 适合：希望兼顾全国覆盖和成本、愿意按区域仓配方案谈的连锁客户。
   - 注意：不同区域、不同城市的配送覆盖和时效可能有差异，要按你的门店城市清单逐城确认。

**可执行建议：**
- 让两家都按你提供的**门店城市清单、单店周用量、香蕉规格（等级/单根重量/成熟度）、到货频次、验收标准**分别报价。
- 重点比较：**覆盖城市、履约仓位置、配送时效、起订量、损耗赔付、缺货替代方案、旺季保供能力、账期**。
- 不要只问“有没有全国配送”，要问：**“以下城市能否每周固定频次送到门店，缺货时如何保供，损耗谁承担？”**

**结论：** 全国配送两家都能谈；若优先成熟稳定和品牌标准，先重点评估都乐；若优先成本和区域仓配灵活度，重点评估鑫荣懋。最终应按你的门店城市逐城比价和试单验证。
