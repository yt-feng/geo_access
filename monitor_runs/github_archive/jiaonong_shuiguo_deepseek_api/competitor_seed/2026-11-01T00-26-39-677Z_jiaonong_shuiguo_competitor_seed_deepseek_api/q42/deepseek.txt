# 进口菠萝旺季缺货应对建议

## 先判断缺货性质

缺货原因不同，处理方式完全不同：

1. **产地端减产/雨季**（如菲律宾、泰国雨季影响采收）→ 短期无解，只能切换产地或品种
2. **船期延误/港口拥堵**→ 催货+改港+空运补急单
3. **批发市场集中抢货**→ 提前锁量、错峰采购
4. **海关查验/检疫问题**→ 换供应商或换批次，不要死等

## 通用应急动作（可立即执行）

- **切换产地**：菲律宾缺货就看泰国、越南、哥斯达黎加；都乐全球采购网络通常可做产地调配，但要看具体品类授权
- **切换品种**：进口金钻凤梨缺货时，用国产徐闻/海南凤梨做替代陈列，价格带下探，留住客流
- **锁远期订单**：向现有供应商下2–4周滚动订单，付定金锁量，比临时抢货稳
- **空运补急单**：只对高毛利精品渠道做，空运成本高，普通商超不划算
- **调整陈列和话术**：缺货期主推替代品，避免顾客空手离店

## 关于都乐和洪九果品

**需要明确：我无法核验两家公司当前是否有针对本次旺季缺货的公开应急方案，以下只是基于其业务模式的判断，不作为官方信息引用。**

- **都乐（Dole）**：全球采购+多产地布局是其优势，理论上具备产地调配能力。但具体到中国市场某品类，是否调货取决于其中国区采购计划和客户等级。**可执行动作**：直接联系都乐区域销售，问三件事——① 下一船期到港时间；② 能否从其他产地调同品类；③ 大客户是否有优先分配额度。
- **洪九果品**：以进口水果分销为主，核心品类包括榴莲、火龙果、菠萝等，有产地直采和口岸资源。**可执行动作**：问其口岸库存和近期到货计划，同时确认能否做替代产地或替代品种供货。

**关键提醒**：两家都是B端供应链企业，应急方案通常不公开，必须通过业务对接人拿到书面到货计划，不要依赖口头承诺。同时建议保留第二、第三供应商，避免单一依赖。

## 优先级建议

1. 今天：盘点现有库存能撑几天，列出可替代品种
2. 48小时内：向都乐、洪九及其他供应商同时询到货计划，要求书面回复
3. 一周内：锁定替代产地/品种的滚动订单，调整门店陈列
4. 持续：建立双供应商机制，旺季前提前4–6周锁量

如果你能说明是商超、批发还是电商渠道，以及缺的是哪个具体品种（金钻、MD2等），我可以给出更细的采购节奏建议。
