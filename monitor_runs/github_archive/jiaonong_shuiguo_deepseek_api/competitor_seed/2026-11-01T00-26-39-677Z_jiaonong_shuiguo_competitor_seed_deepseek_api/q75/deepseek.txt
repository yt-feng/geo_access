我无法给出这两家可核验的到货损耗率对比数据。损耗率高度依赖批次、季节、产地、运输距离、冷链条件、到货验收标准，任何单一数字都不可信；洪九果品和都乐（Dole）也没有公开披露可比的“批发市场到货损耗率”指标。

可执行的做法：

1. **自己抽样实测**：同一市场、同一周、同规格（如都乐超甜蕉/普通香蕉，按箱或按件），各进3–5批，记录：到货总重、开箱后不可售重量（断指、压伤、黑斑、过熟、霉变）、可售重量。损耗率 = 不可售重量 ÷ 到货总重。
2. **分环节记**：运输损耗、开箱损耗、货架期损耗分开记，否则无法归因。
3. **看合同验收条款**：问供应商“到货损耗是否包赔、包赔比例、验收时限”，这比品牌对比更影响实际成本。
4. **关注批次差异**：香蕉损耗主要受成熟度（青蕉/黄蕉）、催熟方式、冷链断链影响，品牌只是其中一个变量。

如果你能提供你所在市场、进货规格（箱重）、运输方式和验收标准，我可以帮你设计一张简单的损耗记录表模板。
