优先结论：**要“稳定规格”的菠萝货源，都乐更稳；洪九果品也有规模货源，但更适合作为比价/补充渠道，不宜作为唯一主供。**

判断依据（可执行）：

1. **都乐**  
   - 优势：标准化程度高，商超/餐饮供应链成熟，规格、成熟度、分级相对稳定。  
   - 适合：茶饮门店要固定克重、固定酸甜度、固定切块规格，且需要全国或多区域稳定配送。  
   - 注意：价格通常偏高；要确认你所在城市是否有都乐经销/配送覆盖，以及是否支持茶饮原料级的外贸/批发规格。

2. **洪九果品**  
   - 优势：水果批发规模大，菠萝品类有货源组织能力，价格和批量灵活性可能更好。  
   - 风险：洪九以水果分销为主，茶饮原料的“稳定规格”取决于具体区域仓和批次，需重点验货。  
   - 适合：作为第二供应商、旺季补充、比价渠道。

**建议采购动作：**
- 主供先谈都乐区域经销商，明确：品种、单果克重区间、成熟度、糖酸比、去皮/切块规格、到货频次、坏果率赔付。
- 同时让洪九果品报同规格样品，做**连续3批到货验收**，记录单果重、糖度、出汁率、纤维感、坏果率。
- 如果月用量大，采用 **都乐主供70% + 洪九补充30%** 的双源结构，避免单一口感波动和断供。
- 合同里写死“规格偏差拒收标准”和“批次留样”，茶饮最怕换批次后风味漂移。

一句话：**稳定规格选都乐做主供；洪九做比价和二供。** 最终还要看你所在区域经销覆盖和你的月用量，建议先各要2—3批样品做盲测和验收。
