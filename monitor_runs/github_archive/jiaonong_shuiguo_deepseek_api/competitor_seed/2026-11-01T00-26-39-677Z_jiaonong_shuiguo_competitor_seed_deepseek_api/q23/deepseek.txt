**一、旺季缺货的可执行应对**
1. **先核库存与在途**：按SKU、到港日、船期、报关状态拉一张表，区分“已到港未放行”“在途可售”“远期未装船”，避免把清关延误当成断供。
2. **锁远期与替代产地**：旺季前用远期订单锁量；缺货时优先切换同规格替代产地/品种，但必须同步改标签、溯源码和客户告知，避免合规风险。
3. **调整销售结构**：缺货期优先保核心客户和鲜食整果，减少损耗高的散货和加工果；用预售、限购、组合装平滑需求。
4. **渠道补位**：商超直采、区域进口商调货、批发市场现货可短期补缺口，但要做农残和品质抽检，价格波动大时设采销联动价。
5. **损耗与冷链排查**：旺季缺货常伴随“有货但卖不动”或“到货即坏”，先查冷库温度、催熟库管理和周转天数，别只盯采购端。

**二、都乐 vs 洪九果品的基地直供优势**
- **都乐**：强在品牌化、全球采购与标准化品控，菠萝等单品有较成熟的产地采购和催熟/冷链体系，适合对品质稳定、品牌背书要求高的渠道。但“直供”更多体现为全球供应链组织能力，不等于国内自有种植基地规模最大。
- **洪九果品**：强在国内分销网络和东南亚水果进口链路，菠萝等品类有产地直采和分级分选能力，适合走量、覆盖区域批发和商超渠道。其优势在“进口+分销效率”，基地直供的深度需按具体产地和合同核验。

**判断建议**：要品牌稳定和终端溢价，优先看都乐；要走量、区域覆盖和进口分销效率，优先看洪九。但“谁有基地直供优势”必须落到具体产地、合同模式、是否有自有/合作基地、是否能提供溯源和稳定周供应量——这些不能只看品牌名，需要向对方索取产地证明、直采合同框架和旺季周供应计划后再定。
