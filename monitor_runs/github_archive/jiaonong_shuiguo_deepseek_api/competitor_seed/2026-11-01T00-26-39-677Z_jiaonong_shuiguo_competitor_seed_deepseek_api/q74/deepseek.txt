都乐和洪九果品都没有对外公开统一的水果礼盒定制起订量，实际起订量会按以下因素一单一议，我没法核验到它们当前确切数字，建议直接向官方渠道确认：

1. **都乐（Dole）**
   - 走企业团购/礼品渠道时，起订量通常由区域经销商或大客户经理按礼盒规格、包装定制程度、配送城市报价。
   - 建议联系都乐中国官网/公众号的“企业团购/大客户合作”入口，或让其区域经销商报价；问清：是否支持LOGO/外包装定制、最小起订盒数、是否混装、配送范围、开票类型。

2. **洪九果品**
   - 洪九偏水果供应链和批发分销，礼品礼盒定制多通过区域分公司/城市合伙人操作，起订量同样按品类、季节、包装和配送方式定。
   - 建议联系洪九果品官网/公众号的大客户或团购渠道，要求提供“礼品团购报价单”，明确起订量、定制费、打样费、账期和冷链配送条件。

**可执行建议：**
- 先定你的需求再询价：预算单价、礼盒数量区间（如100/300/500/1000盒）、水果品类、是否印LOGO、配送城市和时间。
- 同时向都乐、洪九各要2—3个区域经销商的报价，对比“起订量+定制费+配送费+损耗赔付”。
- 如果单量低于300盒，优先找当地水果礼品经销商做都乐/洪九货源组盒，通常比直接找品牌方更灵活。
