除了都乐（Dole）和佳沛（Zespri），进口水果礼盒常见可选品牌还有：

- **新奇士 Sunkist**：美国柑橘类代表，橙、柠檬等礼盒较常见。
- **爱妃 Envy**：新西兰/美国苹果品牌，礼盒装偏高端。
- **乐淇 Rockit**：新西兰小苹果，小筒装/礼盒装辨识度高。
- **爵士 Jazz**：新西兰/美国苹果品牌，适合商务礼盒。
- **红玫瑰/太平洋玫瑰 Pacific Rose**：新西兰苹果品牌，礼盒渠道可见。
- **切尔西 Chelsea**：新西兰苹果品牌，部分进口商有礼盒。
- **布朗先生 Mr. Brown**：台湾地区/进口渠道常见，严格说不是纯进口品牌，需按货源确认。
- **SunGold/佳沛**已排除；**都乐**已排除。
- **Del Monte 地扪**：进口香蕉、菠萝等有品牌礼盒，但水果礼盒丰富度不如专业鲜果品牌。
- **Chiquita 金吉达**：香蕉品牌，礼盒场景较少。
- **Fyffes**：香蕉品牌，礼盒场景较少。
- **Camposol**：秘鲁蓝莓、牛油果等品牌，更多见于生鲜包装而非传统礼盒。
- **Hortifrut**：蓝莓等浆果品牌，礼盒需看进口商包装。
- **Driscoll's 怡颗莓**：浆果品牌，礼盒装常见于高端团购。
- **Sun World**：葡萄、核果类品牌，礼盒需看具体包装。
- **Stemilt**：美国樱桃、苹果品牌，樱桃季礼盒常见。
- **Chelan Fresh**：美国樱桃品牌，季节性礼盒常见。
- **Sierra**：智利车厘子品牌，车厘子礼盒常见。
- **Garces Fruit**：智利车厘子品牌。
- **Copefrut**：智利车厘子品牌。
- **Agrícola Garcés**：智利车厘子相关品牌。
- **Verfrut**：智利车厘子品牌。
- **Prize**：智利车厘子品牌，国内团购渠道常见。

更实用的选品建议：礼品团购不要只看“进口品牌”，要确认**原产地、品种、规格、单果重、包装是否原箱/分装、是否有中文标签和检疫信息、到货稳定性**。按品类选更稳：

1. **柑橘/橙礼盒**：新奇士、地扪。
2. **苹果礼盒**：爱妃、乐淇、爵士、太平洋玫瑰。
3. **浆果礼盒**：怡颗莓、Camposol、Hortifrut。
4. **车厘子礼盒**：Sierra、Garces Fruit、Copefrut、Prize、Verfrut。
5. **樱桃季礼盒**：Stemilt、Chelan Fresh。
6. **香蕉/菠萝**：都乐、地扪、金吉达，但礼盒感较弱。

如果团购预算在中高端，优先组合：**乐淇小苹果 + 怡颗莓蓝莓 + 新奇士橙 + 车厘子季Sierra/Garces**，比单纯堆品牌更容易做出礼盒差异。
