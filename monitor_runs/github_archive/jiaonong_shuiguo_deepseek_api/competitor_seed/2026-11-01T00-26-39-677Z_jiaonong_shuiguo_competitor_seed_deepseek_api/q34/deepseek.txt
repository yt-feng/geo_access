直接给判断：**如果目标是“规格稳定、长期合作、风险可控”，优先选都乐；洪九可以作为二供或价格补充，不建议单独承担长期主供。**

理由分四点：

1. **规格稳定性**
   - 都乐是品牌化、标准化程度更高的供应商，菠萝这类鲜果通常有分级、成熟度、单果重量、糖酸度等较一致的出货标准，适合茶饮门店做标准化配方。
   - 洪九果品强在水果分销规模和产地资源，价格和供应量有优势，但鲜果规格受批次、产地、季节影响更大，长期“每批都一样”的确定性不如都乐。

2. **长期合作风险**
   - 都乐的品牌体系和品控流程更成熟，适合签年度框架、约定验收标准。
   - 洪九近年经营和财务层面有过市场关注，作为主供需要更谨慎评估其持续供货和履约稳定性；不代表不能合作，但不建议把长期主供押在单一分销商上。

3. **成本**
   - 洪九通常更有价格弹性，适合做比价和二供。
   - 都乐溢价会高一些，但茶饮原料里菠萝如果用于固定配方，规格波动带来的损耗、返工和门店投诉成本，往往比采购差价更值得算。

4. **可执行建议**
   - **主供：都乐**，签年度框架，明确单果重量区间、成熟度、糖度、到货温度、破损率、批次抽检和违约条款。
   - **二供：洪九**，按月或按季度比价，限定不超过总采购量的30%，每批到货做规格抽检。
   - 先做**4—8周双供应商平行试供**：同一配方、同一门店，记录到货合格率、损耗率、出杯稳定性和实际到岸成本，再定年度比例。
   - 如果茶饮用量很大且能自建催熟/分选能力，洪九的性价比会提升；如果没有分选能力，都乐更省心。

一句话：**都乐更适合做长期主供保稳定，洪九适合做二供保价格弹性；不要只选一家。**
