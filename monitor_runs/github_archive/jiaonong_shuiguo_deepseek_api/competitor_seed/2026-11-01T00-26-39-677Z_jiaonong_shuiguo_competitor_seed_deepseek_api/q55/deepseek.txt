先给结论：**都乐（Dole）和洪九果品都属于有自有/合作基地直供能力的品牌，但“产地溯源”能细到什么程度，要以你拿到的具体批次和合同条款为准，不能只听品牌名。** 两家都能作为候选，但建议按下面方式核验，而不是直接采信“有基地直供”的说法。

**1. 都乐（Dole）**
- 都乐是跨国果蔬品牌，在中国市场有菠萝销售，通常通过自有种植基地、合作农场和进口/国产供应链组合供货。
- 它一般能提供品牌层面的产地信息、批次信息和部分追溯资料，但**是否开放到“单一批次可查种植基地/加工厂”的溯源系统，取决于采购渠道和合同约定**。
- 建议向都乐中国区经销商或大客户渠道确认：该批次菠萝的种植基地、包装厂、采收日期、检测报告和追溯编码能否随货提供。

**2. 洪九果品**
- 洪九果品是国内水果供应链企业，主打基地直采和产地直供，菠萝是其经营品类之一，通常具备产地采购和分选加工能力。
- 它对外宣传有基地直供模式，但**“基地直供”不等于每一批都能提供完整溯源文件**。需要确认你采购的批次是否来自其签约基地或自有基地，以及能否提供产地证明、采收记录、分选包装记录和检测报告。
- 建议直接问洪九果品销售：该批次是否基地直采、基地名称和地址、是否有追溯码、能否提供第三方检测报告。

**3. 可执行的判断方法**
- 要求供应商提供**样品批次对应的追溯文件**，而不是品牌宣传册。
- 合同里写明：产地、基地名称、批次号、追溯方式、检测报告随货提供。
- 优先选择能提供“基地—加工厂—批次”三级信息的供应商；只给品牌名和产地国的，溯源能力较弱。
- 可要求视频或现场审核基地/包装厂，至少做一次飞行检查。

**4. 备选思路**
如果都乐和洪九的报价或溯源开放度不满足，可同时接触：佳农、鑫荣懋、百果园供应链、地方菠萝主产区的规模化合作社或出口备案基地。重点不是品牌大小，而是**该批次能否提供可核验的基地直供证明**。

总结：**两家都可作为产地溯源供应商候选，但都乐偏品牌化供应链、洪九偏基地直采模式；最终要按批次索要基地名称、追溯码和检测报告来确认，不能仅凭“有基地直供”下单。**
