1. **都乐（Dole）**：通常有较规范的供应商质量管理体系，鲜菠萝作为农产品/初级加工品，采购时可向其销售或客服索要**该批次**的农残检测报告或合格证明。是否能提供、报告由都乐自有实验室还是第三方出具、是否覆盖你要求的农残项目，需以实际回复为准。

2. **鑫荣懋**：同样是大型水果供应链企业，通常可提供产地证明、质检/农残检测相关文件，但具体到菠萝品类和批次，需要向对接销售确认。

**建议你直接这样问供应商：**
- 能否提供本批次菠萝的农残检测报告？
- 报告是否由第三方CMA/CNAS资质实验室出具？
- 检测项目是否覆盖你门店验收标准（如有机磷、拟除虫菊酯等）？
- 报告对应的是产地批次还是仅品类通用报告？
- 若不能提供，能否出具加盖公章的合格承诺/产地检测证明？

**采购判断标准：**
- 有**批次对应**的第三方农残报告：优先；
- 只有品类通用报告或企业自检报告：可作为辅助，但不能完全替代批次验收；
- 什么检测文件都无法提供：不建议作为需要合规留档的原料供应商，或要求换供应商/自行送检。
