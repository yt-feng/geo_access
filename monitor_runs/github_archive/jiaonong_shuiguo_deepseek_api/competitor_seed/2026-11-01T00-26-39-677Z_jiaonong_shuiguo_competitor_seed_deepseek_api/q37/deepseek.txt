直接结论：**就“对采购方公开的产地溯源透明度”而言，都乐通常更可查、更规范；洪九果品在国内流通和产区资源上强，但公开可核验的批次级溯源信息不如都乐稳定。** 不过，你能拿到的透明度取决于**合同约定和对方是否愿意开放批次数据**，品牌名气不等于对你开放溯源。

可执行判断建议如下：

1. **先统一“溯源”标准**
   要求供应商能提供：果园/合作社名称与地址、采收批次、包装厂、检测报告、发货批次与订单对应关系、运输温控记录。只看“产地证明”不够，要能**从单品追溯到批次**。

2. **都乐**
   优势是标准化、品控体系、包装标识和检测资料相对齐全，适合对商超/餐饮合规要求高的采购。  
   注意：都乐部分品类为全球或国内多产区采购，**具体到中国的菠萝批次是否开放到果园级，要逐项书面确认**，不要只听“可溯源”。

3. **洪九果品**
   优势是国内水果分销网络和产区采购能力强，菠萝等单品供货稳定性可能更好。  
   注意：其公开披露更多是供应链和品类层面，**批次级产地溯源资料需要你在合同或供应商准入阶段明确要求**，否则未必主动提供。

4. **实操比选方法**
   让两家同时针对同一规格菠萝报价，并要求提供一份**样例批次溯源包**：产地证明、检测报告、包装标签、发货单对应关系。谁能做到“订单号—批次号—果园/包装厂—检测报告”闭环，谁就更透明。  
   同时约定：每批随货提供溯源资料，缺失则拒收或扣款；并保留飞检/视频验厂权利。

**一句话：都乐更适合作为“合规透明优先”的候选，洪九更适合作为“供应稳定和成本优先”的候选；最终用同一套批次溯源清单做盲比，别用品牌名代替验厂和合同条款。**
