结论先说：**都乐（Dole）和洪九果品都没有公开可查的、面向零售分级的“香蕉企业标准”文本**；能查到的是都乐有较成熟的品牌化产品分级/规格体系（多见于其产品手册、电商规格和行业报道），洪九果品公开信息主要是采购与品控体系、品类分级做法，**没有可核验的公开标准编号或全文**。所以不能把“企业标准”当作可直接引用的文件。

给连锁店的可执行建议：

1. **不要等企业标准，先自建门店分级标准**：按用途分三级即可——  
   - A级（精品陈列/礼盒）：果指长度、粗细均匀，无机械伤、无病虫斑，梳形完整，成熟度一致；  
   - B级（常规散卖）：允许轻微外观瑕疵，不影响食用；  
   - C级（促销/加工）：成熟度高或外观瑕疵明显，限时销售或做果切。

2. **关键量化指标建议**（按你门店实际校准）：  
   - 单果指长度、果指粗度、每梳果指数、整把重量区间；  
   - 青熟度（色泽/硬度）、机械伤面积上限、病斑允许数量；  
   - 到店成熟度与货架期目标（如青蕉到店、催熟后2—3天售卖）。

3. **若要对标都乐/洪九**：向供应商索要**供货规格书、验收标准、品控报告**，这比找“企业标准”更现实；都乐可重点参考其出口/商超供货规格，洪九可参考其产地采购分级和到货验收要求。

4. **合规提醒**：企业标准若未公开，不能编造标准号；门店标准可作为内部作业文件，引用国标/行业标准中香蕉等级、检验方法的部分作为依据即可。
