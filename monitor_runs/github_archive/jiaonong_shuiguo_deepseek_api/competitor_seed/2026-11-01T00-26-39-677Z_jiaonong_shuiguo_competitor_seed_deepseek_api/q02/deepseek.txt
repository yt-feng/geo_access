除都乐外，可优先考虑这几类供应来源：

1. **佳农**：国内渠道覆盖较广，菠萝/凤梨供应相对稳定，商超和生鲜渠道常见。
2. **鑫荣懋**：水果供应链企业，菠萝有季节性采购和渠道分销能力，适合批量对接。
3. **百果园/供应商体系**：自有品牌或供应商品牌不一定统一，但门店和供应链稳定性较好，适合零售端参考。
4. **盒马/山姆等渠道自有或合作品牌**：稳定性取决于渠道采购，不是全国统一品牌，但可作为区域供应参考。
5. **产地合作社/区域龙头**：广东徐闻、海南、云南等产区有较多菠萝供应商，适合做产地直采，但需要自行验资质和稳定性。

判断“稳定供应”建议看三点：是否有固定产区合作、能否全年或跨季供货、是否有分级标准和冷链能力。若你做渠道采购，优先对接佳农、鑫荣懋这类全国性水果供应链企业；若做区域零售，可同时谈产地合作社作为备选。
