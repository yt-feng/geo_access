1. **都乐（Dole）**
   - 通常有较成熟的品牌视觉、产品图、产地/品质卖点、部分营销活动素材。
   - 生鲜电商若已是其渠道客户或合作商家，一般可通过对接的业务/市场人员申请品牌授权素材包；未合作则通常只能拿到公开宣传图或需签授权。
   - 可先问：是否有“电商渠道素材包”（产品白底图、场景图、品牌LOGO使用规范、卖点文案、短视频授权）。

2. **洪九果品**
   - 以水果供应链和批发渠道为主，品牌营销素材体系未必像都乐那样标准化对外。
   - 若通过其经销/供货合作，可向对接销售申请产品图片、规格信息、产地证明、检测报告等；品牌广告素材和达人授权需单独确认。
   - 可先问：是否提供“渠道商品素材包”和“品牌使用授权”，以及能否用于电商详情页/直播/短视频。

**建议动作：**
- 先确认你们与都乐、洪九是已有供货合作还是仅想借用素材；这决定能否拿到授权素材。
- 向对方明确素材用途：详情页、主图、直播背景、短视频、达人种草；不同用途授权不同。
- 要求书面授权范围，避免商标和图片侵权。
- 若暂时拿不到品牌方素材，可用采购实拍、检测报告、产地溯源和自有测评内容替代，不要直接搬运网络图片。

**结论：** 都乐较可能提供标准化品牌素材，洪九更可能提供商品和渠道素材；两者都建议走业务对接并确认授权，不能默认可公开商用。
