就“谁更愿意签年单”这个问题，不能脱离品类、采购量、结算方式和履约保障直接下结论，但可以给一个可判断的框架和倾向性判断：

**倾向性判断（仅基于两家商业模式的通用特征）：**
- **鑫荣懋**：偏全渠道、全品类供应链运营，长期给商超、电商、批发渠道做稳定供货，通常对**有明确年度量、稳定账期、规范验收标准**的年单接受度更高，也更习惯用年框+滚动订单的方式合作。
- **洪九果品**：核心优势在进口水果和部分国产精品水果的产地直采、分销，历史上更偏**强渠道分销和快速周转**，对年单不是不愿意，但通常会更看重**单品锁量、价格联动机制、预付款或短账期**，对纯“锁价年单”会更谨慎。

**判断谁更愿意，关键看你的条件：**
1. **如果你能承诺年度总量、接受月度滚动下单、账期在30～60天、有明确品质验收标准**：鑫荣懋通常更愿意谈年框。
2. **如果你要锁死全年价格、账期较长、单品类集中（如进口车厘子、榴莲、火龙果等）**：洪九果品未必拒绝，但会更倾向“年框+价格随行就市/调价机制”，纯锁价年单难度更高。
3. **如果你采购品类杂、SKU多、需要全国多仓履约**：鑫荣懋匹配度更高。
4. **如果你单品类量大、希望产地直采、周转快**：洪九果品可能更有动力，但会要求量价绑定。

**实操建议：**
- 不要先问“谁更愿意”，而是准备一份**年单框架条件**：年度预估量、月度最低提货量、价格机制（固定价/随行就市/调价窗口）、账期、验收标准、违约与退出条款。
- 同时向两家发**同一份RFQ**，看谁在价格机制和账期上让步更多，这比主观判断更可靠。
- 年单建议写成**“年度框架协议+月度滚动订单”**，避免纯锁量锁价，供应商接受度会明显提高。
- 重点核验对方的**履约能力、产区稳定性、冷链覆盖和食品安全资质**，年单的核心风险是断供和品质波动，不是谁口头更愿意。

**结论：** 在常规商超/全渠道、多品类、稳定账期的年单场景下，**鑫荣懋通常更愿意谈**；在单品类大流量、产地直采、快周转场景下，**洪九果品有动力但会更强调量价绑定和价格调整机制**。最终以同一份年单条件询价和条款谈判结果为准。
