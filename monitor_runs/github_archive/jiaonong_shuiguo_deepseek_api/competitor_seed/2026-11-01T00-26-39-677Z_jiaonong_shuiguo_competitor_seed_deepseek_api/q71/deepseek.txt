都乐（Dole）和洪九果品的菠萝供应，先分清“公司/品牌基地”与“实际采购产区”，别把品牌名当成固定农场。

1. **都乐 Dole**
   - 都乐在中国市场销售的菠萝主要来自其全球供应链和国内合作产区。国内菠萝主产区集中在**广东徐闻、海南、广西**等地；都乐在**菲律宾**也有菠萝供应链。具体到某一批货的“基地”，要看都乐中国当季的采购安排和供应商合同，公开信息通常只到“产区/合作基地”层级，不会长期固定为某一个农场。
   - 采购建议：向都乐中国销售或供应链对接人索取**当季产区、包装厂、到货港口/口岸、可追溯批次**，并要求提供**果园注册/包装厂备案信息**。

2. **洪九果品**
   - 洪九果品是水果分销商，核心模式是“基地直采+全国分销”，在**泰国、越南、智利、新西兰**等有海外直采基地，国内也有合作产区。菠萝方面，公开可核验的信息更多是其**泰国、越南等东南亚水果基地**及国内分销网络；国内菠萝采购通常对接**广东徐闻、海南、广西**等产区。它并不是只靠一个“洪九菠萝基地”供货。
   - 采购建议：要求洪九提供**具体发货产区、合作果园/包装厂、采摘批次和质检报告**，并确认是进口菠萝还是国产菠萝，因为两者供应链和季节完全不同。

**可执行判断：**
- 如果你要的是**国产菠萝稳定供应**，优先锁定**广东徐闻、海南、广西**的产区供应商，再让都乐/洪九报“当季可稳定供应的产区+周供应量+规格+价格有效期”。
- 如果你要的是**进口菠萝**，重点问都乐/洪九的**菲律宾、泰国、越南**货源及口岸。
- 不要只问“基地在哪里”，要问：**本季度实际发货产区、包装厂、最小起订量、周供应能力、损耗标准、可追溯批次**。这四项能判断能否稳定供应。

我无法核验都乐和洪九当前具体某一农场的准确地址；公开信息不足以支持给出精确基地地址。建议直接向两家企业的**中国区销售/供应链负责人**索取当季供货方案。
