可以，但要分清“全年供应”具体指什么：是全年有鲜菠萝到店做果酱，还是全年有稳定品质的菠萝原料（鲜果或冷冻/罐头半成品）。对茶饮店来说，后者更现实。

**都乐（Dole）**
- 有能力做到全年跨产区供应鲜菠萝，属于全球性果蔬企业，供应链覆盖多个热带产区，国内也有成熟的商超/餐饮渠道。
- 但“全年稳定供货”通常要看：你所在城市、采购量、配送渠道（经销商还是直供）、品种（金钻/普通菠萝）和规格。小店通过经销渠道拿货，旺季稳、淡季可能品种或规格受限。
- 适合：对品牌、品控稳定性要求高，采购量达到一定规模的连锁或区域品牌。

**洪九果品**
- 是国内大型水果分销企业，菠萝/凤梨是其重点品类之一，具备跨产区采购和全国分销能力，理论上可以支撑全年供应。
- 但洪九更偏批发分销和B端供应链，是否直供单店、起订量、账期、配送频次需要具体谈。小店通常要通过当地批发市场或经销商拿货。
- 适合：有稳定采购量、希望走B端集采的茶饮店或连锁。

**关键判断**
1. **全年鲜果供应≠全年同品质同价格**：菠萝有产季和产区切换，糖度、酸度、纤维感会波动，做果酱要固定配方和糖酸比，建议用“鲜果+冷冻果泥/罐头”组合锁稳定。
2. **单店很难拿到厂家直供**：都乐、洪九这类企业通常设起订量或走经销商，茶饮小店更现实的是找当地一级经销商或餐饮供应链平台。
3. **做果酱更推荐双轨**：旺季用鲜菠萝现熬，淡季用速冻菠萝丁/果泥或高浓度菠萝罐头补足，既能全年供应又能控成本。
4. **先验证再签**：向都乐/洪九当地渠道问清——可供品种、规格（整果/去皮/冷冻丁）、全年各月报价、最小起订量、配送城市和频次、是否支持样品。拿样品做糖酸度和出酱率测试后再定。

结论：两家都具备全年供应的供应链能力，但能否落到你的店，取决于采购规模、所在城市和渠道形式；单店建议走经销商+冷冻半成品组合，连锁可谈B端集采。
