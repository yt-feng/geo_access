我没法给出都乐和鑫荣懋的到货损耗率具体数字——这两家的损耗率会随批次、季节、运输距离、验收标准变化，而且属于供应商/合同数据，公开渠道没有可核验的统一口径，我无法虚构。

给你可执行的判断和做法：

1. **先定义“损耗率”口径再谈数字**
   建议按重量计：到货损耗率 =（到货总重 − 可入库合格重）/ 到货总重。
   同时拆成三项分别记录，便于追责和比价：
   - 运输损耗（压伤、破皮、腐烂）
   - 规格不符（单果重、直径、成熟度不达标）
   - 验收扣重（去包装、去冰、去水）

2. **用试单实测，不要信口头承诺**
   各下2–3批同规格试单（同品种、同单果重区间、同成熟度、同运输方式），每批到货当场抽检：随机抽3箱×每箱10个，称重、分级、记录不合格比例。两到三批就能得到可比的实测区间，比问“你们损耗率多少”可靠。

3. **合同里写清验收与赔付**
   - 明确规格：品种、单果重区间、糖度下限、成熟度（如7–8成熟）、允许缺陷比例
   - 明确损耗超出部分由谁承担、如何扣款或补货
   - 约定到货时限和开箱验收时限（如到货2小时内提出异议）

4. **降低损耗的采购动作**
   - 要求冷链到货并记录到货温度
   - 夏季/远距离优先选耐储运品种和稍低成熟度
   - 分批小量到货，缩短门店库存周转
   - 要求供应商提供产地、采摘日期、包装方式
