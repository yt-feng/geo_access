结论先说：**洪九果品和都乐都不是为“夫妻店小批量进货”设计的渠道，常规一件起批/混装小单基本没有；能拿到小批量现货，通常要走它们的一级批发商、区域经销商或二级批发市场，而不是直接找厂家/品牌方。** 具体分两家说：

**1）洪九果品**
- 洪九主要是产地直采、大宗分销，客户以商超、连锁水果店、区域批发商、电商平台为主。
- 对夫妻店直接开户、一件起送的支持很少；很多区域是**经销商/批发市场档口**在出货。
- 实操：找当地**一级水果批发市场里挂洪九货的档口**，按箱/件拿，少量混装可谈；或问区域业务员“最近有没有小规格箱/尾货/拼车单”。
- 注意：洪九部分品类走品牌箱，小批量往往只能拿**整箱**，不是按斤散批。

**2）都乐**
- 都乐是品牌化运营，商超和连锁渠道为主，也有区域经销商。
- 夫妻店直接小批量从都乐拿货一般不现实；可通过**当地都乐经销商、批发市场代理档口**拿货。
- 实操：问经销商有没有**小规格箱、临期促销箱、混搭拼箱**；香蕉、菠萝等品类在批发市场更容易小批量拿。

**给夫妻店的建议：**
- 不要执着“品牌方直供”，优先找**区域经销商/批发市场同品牌档口**，小批量、混装、账期都更好谈。
- 首次合作先拿**1–2箱试销**，确认损耗、周转和毛利再放量。
- 问清三件事：**起批量、是否可混装、破损/售后怎么算**。
- 如果当地没有洪九/都乐经销资源，可以用**本地批发商+少量品牌箱**组合，别为单一品牌压库存。

一句话：**直接小批量供货基本没有，但通过经销商/批发档口可以小批量拿到货。**
