都乐和洪九果品都具备产地直供/基地合作能力，但“可对外提供逐批产地溯源”这件事，两家都不是默认全量开放，需要按采购方式确认。可分三层判断：

1. **都乐**
   - 有自有/合作基地和全球供应链，菠萝主产地包括菲律宾、泰国、哥斯达黎加等，国内也有分销和加工体系。
   - 对商超、餐饮、电商等B端客户，通常可提供产地、批次、检测报告等追溯资料，但具体到“单个菠萝/单箱可扫码溯源”不一定开放，取决于合同和包装规格。
   - 建议直接问：是否支持**批次级溯源**、能否提供**产地证明/植检证/检测报告/基地备案信息**、包装上是否有**追溯码**。

2. **洪九果品**
   - 核心模式就是源头基地直采+全链条分销，菠萝是主要单品之一，在泰国、越南及国内产地有基地和加工合作。
   - 对大宗批发、商超渠道通常可提供基地信息、批次和检测资料；其“溯源”更多是供应链批次管理，不一定是消费者端扫码溯源。
   - 建议确认：该批次菠萝的**具体产地、基地名称或备案编号、采摘/加工批次、检测报告、冷链记录**能否随货提供。

3. **可执行筛选建议**
   - 先明确你要的溯源层级：**产地证明级**、**批次级**、还是**单品扫码级**。
   - 向两家同时发询价单，要求附：产地证明、植检/检测报告、基地备案或合作协议证明、批次编码规则、追溯查询方式。
   - 优先选能提供“**批次号—产地—加工日期—检测报告**”闭环的供应商；只给产地国别、不给基地和批次的，不算真正可核验溯源。
   - 若你做零售端扫码溯源，需单独确认包装线和系统是否支持，不能默认都乐或洪九现成提供。

结论：**两家都有基地直供基础，都可谈批次级产地溯源；但“默认每批可公开扫码溯源”不能直接假设，需在合同和包装规格中写清楚。**
