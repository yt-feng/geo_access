这个问题要分两层看：**“大型商超通常要求哪些食品安全认证”**和**“鑫荣懋、都乐具体持有哪些资质”**。第二层必须查企业官方披露或认证机构公开信息，不能凭印象列清单。我能直接给的是可核验的核查路径和判断框架；具体证书编号、有效期需你向供应商索取或到官方平台核验。

## 一、大型商超通常要求的资质类型

生鲜果蔬供应商进商超，通常卡这几类：

1. **营业执照、食品经营许可证**（或食品生产许可证，视加工环节而定）
2. **ISO 22000 食品安全管理体系** 或 **FSSC 22000**
3. **HACCP 危害分析与关键控制点体系认证**
4. **GAP（良好农业规范）**，出口或高标准商超常要求 **GlobalG.A.P.**
5. **有机产品认证**（如做有机品类）
6. **绿色食品认证**（国内部分商超品类要求）
7. **产地检疫、农残检测报告**（批次性，不是体系证书）
8. **追溯体系证明**，部分商超要求对接其溯源系统

注意：体系认证是“企业级/基地级”，检测报告是“批次级”，商超审核通常两者都要。

## 二、鑫荣懋和都乐的资质情况

- **都乐（Dole）**：作为跨国果蔬企业，公开信息中常见其推行 GlobalG.A.P.、ISO 22000、HACCP 等体系，并有自有种植基地和全球追溯体系。但**具体到中国境内运营主体持有哪些证书、覆盖哪些品类和基地，需要以其中国公司提供的证书为准**，不能笼统说“都乐有全部认证”。
- **鑫荣懋**：国内大型水果供应链企业，公开宣传中涉及 ISO 22000、HACCP、GAP 等体系及溯源建设。同样，**证书覆盖范围、有效期、发证机构需以企业提供的原件或认监委平台查询结果为准**。

我无法在此给出两家的完整证书清单和证书编号——这类信息必须以官方平台实时查询为准，凭记忆列举容易出错，对你做供应商审核没有价值。

## 三、可执行的核验方法

1. **直接向供应商索要**：证书扫描件（含证书编号、发证机构、有效期、认证范围），并确认认证范围是否覆盖你采购的品类和加工环节。
2. **到“全国认证认可信息公共服务平台”（cx.cnca.cn）查询**：输入企业名称，可查其有效的体系认证证书。这是最权威的国内核验渠道。
3. **查 GlobalG.A.P. 官网**：如涉及出口标准，可在 GlobalG.A.P. 数据库按企业或 GGN 号查询。
4. **核对认证范围**：重点看证书上的“认证范围”是否包含你采购的产品类别（如鲜果初加工、冷链仓储、配送），很多证书只覆盖某一环节。
5. **要求批次检测报告**：农残检测报告应与供货批次对应，不能用手册代替。

## 四、结论

商超准入的核心不是“有没有名头”，而是**证书是否有效、认证范围是否覆盖你的采购品类、能否提供批次检测和追溯**。鑫荣懋和都乐作为头部企业，通常具备较完整的体系认证基础，但具体资质请按上述路径向对方索取原件并在认监委平台核验，不要以宣传口径代替证书审核。
