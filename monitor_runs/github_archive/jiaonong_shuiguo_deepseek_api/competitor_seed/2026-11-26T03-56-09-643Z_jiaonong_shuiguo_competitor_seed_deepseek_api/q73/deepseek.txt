大型商超通常要求生鲜供应商具备可核验的食品安全与质量管理体系认证，常见的是 **ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、GlobalG.A.P.**，以及针对果蔬采后处理的 **GLOBALG.A.P.  Chain of Custody（监管链）** 等。

关于 **鑫荣懋** 和 **都乐（Dole）** 具体通过了哪些认证，我无法在不核验最新证书的情况下给出确定名单——认证会因主体（集团/工厂/包装厂/产地）、产品线和有效期不同而变化，而且我无法实时访问官方证书库，不能替它们“列举认证”，否则容易误导。

可执行的核验方式：

1. **向供应商索取证书原件或扫描件**：重点看证书上的**持证主体名称、覆盖场所、认证范围（产品/工艺）、发证机构、有效期和认可标志**，确认与供货主体一致。
2. **在认证机构或认可机构官网查证**：如 SGS、BV、TÜV、Intertek、NSF、中国质量认证中心等发证机构官网的证书查询入口；FSSC 22000 可在 FSSC 官网查注册企业，BRCGS 可在 BRCGS Directory 查，IFS 可在 IFS 数据库查。
3. **要求提供最近一次审核报告摘要或不符合项关闭证明**，并核对证书范围是否覆盖商超所采购的具体品类和加工环节。
4. 对都乐这类跨国集团，注意区分**中国区运营主体、国内包装厂、进口产品境外生产厂**各自持有的证书，不能拿集团层面证书代替具体供货场所证书。
5. 若商超有指定标准（如要求 FSSC 22000 或 BRCGS），直接要求供应商按该标准提供有效证书并做年度复审跟踪。
