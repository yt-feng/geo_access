不能直接给出“能做到/不能做到”的确定结论，因为到货损耗率取决于具体品类（国产蕉/进口蕉）、成熟度、运输半径、季节、验收标准、门店收货条件和合同中的损耗责任划分。都乐和鑫荣懋都是规模化香蕉供应商，具备较强的产地、催熟和冷链能力，但“低于3%到货损耗”属于较严的指标，需要按实际业务验证。

可执行判断建议：

1. **先定义“到货损耗率”**
   - 是否只算腐烂、压伤、断裂、青软不均？
   - 是否包含重量失水、果指脱落、拒收部分？
   - 以门店收货称重为准，还是配送中心验收为准？
   - 3%是单批次、月度还是年度平均？不同定义会直接决定供应商能否承诺。

2. **要求供应商做试单验证**
   - 选2—3个代表性城市/门店，连续跑4—8周，每周至少2—3车。
   - 固定品种、规格、成熟度（如催熟到几号色）、包装方式、运输时长。
   - 到货即抽检，记录损耗类型和比例，不要只看供应商自报数据。

3. **合同里写清验收与赔付**
   - 明确抽检比例、判定标准、照片留证、复检时限。
   - 约定超过3%的扣款/补货/退货机制。
   - 区分“运输责任”和“门店储存责任”，避免到货后扯皮。

4. **关注香蕉特有的风险点**
   - 夏季高温、冬季冻伤、催熟度偏高、周转慢都会推高损耗。
   - 连锁门店若收货后不能及时入冷藏/催熟库，3%很难稳定达成。
   - 建议要求供应商提供到店成熟度窗口和温湿度要求。

5. **商务上不要只压指标**
   - 低于3%通常需要更好的包装（如纸箱+内衬）、更短运输半径、更精准的催熟批次和更高的采购价。
   - 可先谈“3%以内不扣款、3%—5%按比例扣款、超过5%退货或重发”，比直接要求供应商硬承诺更可落地。

结论：两家都“有能力接近或达到”，但是否能稳定做到低于3%，必须用你方实际线路和验收标准试单验证；在合同未明确损耗定义和赔付机制前，不建议直接采信供应商的口头承诺。
