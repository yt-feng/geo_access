结论先说：两家都能做菠萝产地直发，但公开可核验的“菠萝单品产地到仓/到消费者”时效数据很少，不能可靠给出具体小时/天数。采购判断应看**产区仓网 + 直发模式 + 目的地**，而不是只看品牌。都乐和鑫荣懋都属于全国性水果供应链企业，通常具备产地仓/区域仓和冷链干线能力；菠萝这类耐储运水果，直发时效更多取决于起运地（广东徐闻、海南、云南等）、目的地城市和是否整车/零担。

可执行判定建议：
1. **必须让两家按你的实际场景报价并承诺时效**：给出起运产区、目的仓/城市、日均单量、整车或零担、是否要求冷链、到仓还是到家。
2. **重点核验四项**：产地仓是否在菠萝主产区周边；干线是直发还是经区域仓中转；到货温控记录和破损赔付；旺季（3—5月）排车与压车情况。
3. **用试单验证**：同一产区、同一目的地各发1—2车或一批电商件，记录“采摘/装车—干线—到仓/末端”的分段时效和破损率，再定主供。
4. **合同写清**：起运地、目的地、时限口径（到仓/到家）、冷链温度、延误与损耗赔付、旺季运力保障。
