可以，但要先确认“报告类型”和“批次对应关系”，不能只听供应商口头说有。给你可直接执行的判断：

1. **都乐（Dole）**  
   通常能提供农残检测报告，但多为**企业自检/第三方检测报告**，且常见是**按品类或基地/批次**出具。采购时要明确：
   - 要**该批次菠萝**对应的报告，不接受“同品类通用报告”糊弄；
   - 要**第三方 CMA/CNAS 检测报告**优先；
   - 确认检测项目是否覆盖你客户/平台要求的农残项（如 GB 2763 对应项目）；
   - 报告上的**生产日期/批次号/供应商名称**要与送货单、发票一致。

2. **鑫荣懋**  
   作为大型水果供应链企业，一般也能提供农残检测报告，同样通常是**批次检测或基地检测报告**。重点确认：
   - 是否支持**按送货批次提供报告**；
   - 报告是否由**具备资质的第三方检测机构**出具；
   - 能否提供**承诺书+批次检测**组合，若你只需要门店索证索票，通常企业自检报告也可用；若进商超/平台，往往要第三方报告。

3. **直接问供应商的话术**  
   “请提供本批次菠萝的农残检测报告，要求报告编号、检测机构、检测日期、批次号与送货单一致；检测项目按 GB 2763 执行。若为第三方报告，请确认具备 CMA/CNAS 资质。没有本批次报告的话，请书面说明可提供的替代文件（企业自检报告/基地检测/承诺书）及出报告周期。”

4. **判断建议**  
   - 只是茶饮门店日常索证：都乐、鑫荣懋通常能配合，企业自检报告+批次信息一般可接受。  
   - 进商超、外卖平台或大客户审核：优先要**本批次第三方 CMA/CNAS 报告**，并在采购合同里写明“随货提供批次检测报告，缺报告可拒收”。  
   - 若对方只能给“年度报告”或“品类报告”，要求补**批次检测**或换供应商，不要仅凭口头保证。

结论：**两家大概率都能提供，但能否提供“你需要的本批次、符合资质要求的农残报告”必须在下单前书面确认。**
