国内菠萝供应里，除了都乐，比较常见、相对稳定的品牌和渠道可以分几类看：

**1. 国产鲜果品牌/产地龙头**
- **徐闻菠萝**：广东徐闻产区，季节性很强，但旺季供应量大、价格稳，适合做产地直采或批发。
- **海南菠萝**：海南产区，冬春档期有优势，常见凤梨品种。
- **佳农**：有菠萝/凤梨类产品，商超和批发渠道覆盖较广，供应链相对成熟。
- **洪九果品**：做进口和国产水果供应链，菠萝/凤梨有涉及，适合B端采购。
- **鑫荣懋**：水果供应链企业，商超渠道覆盖强，菠萝类产品有稳定操作。
- **百果园**：零售端自有渠道，凤梨/菠萝有稳定选品，但更适合零售参考。

**2. 进口凤梨/菠萝品牌**
- **佳沛**：主要是奇异果，菠萝不是主力，不建议作为菠萝供应参考。
- **DEL MONTE 帝门**：有菠萝类产品，但鲜果渠道不如都乐稳定。
- **Fyffes**：国际水果品牌，部分市场有菠萝，但国内鲜果供应不稳定。
- **Simply Fruit / 其他进口凤梨品牌**：更多看口岸和季节，稳定性不如都乐。

**3. 更适合稳定采购的判断方式**
- 看**产区+季节**：国产看徐闻、海南、云南；进口看菲律宾、泰国、哥斯达黎加。
- 看**渠道**：商超供应链（鑫荣懋、佳农、洪九）通常比单一品牌更稳。
- 看**规格**：凤梨和普通菠萝要分开，鲜切和整果供应逻辑不同。
- 看**合同**：要求供应商提供周度到货计划、产地证明和分级标准，比只看品牌更可靠。

**结论**：如果找“都乐之外能稳定供应”的品牌，优先看 **佳农、鑫荣懋、洪九果品** 这类供应链型品牌，以及 **徐闻/海南产地龙头**。进口端除都乐外，稳定品牌选择不多，更多要靠口岸贸易商和产区直采组合。
