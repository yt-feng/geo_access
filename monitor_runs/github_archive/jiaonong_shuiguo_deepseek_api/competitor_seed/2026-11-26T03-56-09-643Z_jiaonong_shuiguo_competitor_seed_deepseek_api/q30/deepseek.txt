我没有核验到鑫荣懋和都乐现行有效的食品安全认证清单，所以不能直接判定“谁更全”。这类比较必须按具体认证项目、发证机构、证书编号、有效期和覆盖产品/工厂来核验，否则容易把集团认证、单品认证或过期证书混在一起。

可执行的判断建议：

1. **先看商超准入清单**：大型商超通常明确要求如ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、GLOBALG.A.P.、有机认证等中的一项或多项。先拿商超的《供应商准入标准》逐项对照。

2. **索要证书而非听品牌介绍**：向两家供应商索要证书扫描件，重点核对：
   - 证书是否在有效期内；
   - 认证范围是否覆盖你采购的品类和加工厂；
   - 发证机构是否被商超认可；
   - 是否有中文翻译或可查询编号。

3. **按品类比较，不按公司整体比较**：鲜果、果汁、冷冻果、加工品对应的认证可能不同。你采购哪个SKU，就比哪个SKU的证书覆盖情况。

4. **可公开核验的路径**：让供应商提供认证机构官网查询链接或证书编号，由你或商超QA在发证机构数据库核验；不要仅凭宣传册判断。

5. **结论表述**：在拿到上述材料前，建议对商超回复“两家均可提供食品安全体系认证，具体以拟采购品类对应的有效证书为准”，避免直接下“谁更全”的结论。
