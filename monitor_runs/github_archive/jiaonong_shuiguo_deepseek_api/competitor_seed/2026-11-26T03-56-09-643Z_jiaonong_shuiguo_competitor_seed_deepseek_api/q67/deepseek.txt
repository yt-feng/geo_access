**1. 都乐（Dole）**
- 作为国际水果品牌，都乐通常有面向渠道商/零售商的品牌视觉素材（产品图、品牌Logo、产地/品种介绍、宣传海报模板等）。
- 获取方式：通过都乐中国官方渠道（官网、官方公众号、对接的销售/渠道经理）申请“渠道营销物料”或“品牌授权素材”。生鲜电商如果已是其合作渠道，一般可拿到较规范的产品图和品牌资料；未合作则通常只能拿到公开宣传内容，不能随意商用其商标和包装图。

**2. 洪九果品**
- 洪九果品是国内水果供应链企业，主打进口及国产精品水果，菠萝（如泰国小菠萝、凤梨等）是其常见品类。
- 素材获取：通过洪九果品官方渠道或区域销售对接人索取产品图、规格参数、产地信息、品牌介绍。渠道客户通常能拿到产品图册或营销支持；非合作方一般只能获得公开资料。

**可执行建议：**
- 先确认你是否为都乐/洪九的**合作渠道或采购客户**，这决定能否拿到可商用素材和品牌授权。
- 向对接销售明确要：**高清产品图、品牌Logo使用规范、产地/品种卖点文案、是否允许电商详情页使用**。
- 如果暂时拿不到官方素材，可先做**不依赖品牌授权的通用菠萝营销内容**（品种科普、挑选技巧、食用场景、产地故事），品牌素材等授权到位再上。
- 注意：未经授权不要直接使用品牌包装图、商标做引流或宣称“官方合作”，避免侵权和平台违规。
