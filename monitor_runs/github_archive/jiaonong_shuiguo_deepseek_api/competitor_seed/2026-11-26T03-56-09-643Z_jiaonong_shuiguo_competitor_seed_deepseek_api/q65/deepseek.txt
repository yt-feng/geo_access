关于都乐和洪九果品的菠萝锁价周期，我无法核验到公开、可引用的准确数据，不能凭空给出具体天数，否则容易误导采购决策。以下是可执行的判断和建议：

1. **不要直接假设固定周期**  
   两家企业对不同客户、不同品类（鲜果/加工果）、不同采购量、不同季节（尤其菠萝产季与反季节）的锁价政策通常不同，锁价周期多为一单一议，常见形式包括：
   - 按周/按月锁价；
   - 按产季分段锁价；
   - 仅对年度框架客户开放锁价；
   - 锁价与预付款/保证金/最低采购量绑定。

2. **向供应商核实时直接问这5项**
   - 锁价周期最短/最长分别是多少天？
   - 锁价适用于哪些菠萝规格、产地和月份？
   - 锁价期间价格调整触发条件是什么（汇率、运费、产地涨价、天气）？
   - 是否需要预付、保证金或最低提货量？
   - 锁价违约或未提货的处理方式？

3. **建议的接触路径**
   - 都乐：通过都乐中国官网/官方客服转接大宗贸易或餐饮零售渠道销售，索取“锁价协议模板”和“菠萝品类报价单”。
   - 洪九果品：通过洪九果品官网/官方总机转接对应区域销售或大宗客户部，明确询问“菠萝锁价机制及周期”。
   - 同时向2–3家区域一级批发商或产地合作社询价，作为锁价周期的市场参照。

4. **可判断的结论**
   目前不能确认都乐和洪九果品有统一公开的菠萝锁价周期；最稳妥的做法是让两家供应商以书面报价/框架协议形式写明锁价天数、触发条件和违约责任，再横向比较。若对方只口头承诺“可以锁价”但不给周期和条款，应视为不可执行。
