都乐和洪九果品都没有公开、稳定的“水果礼盒定制起订量”标准，具体要看城市、渠道、礼盒类型和当季货源，直接给固定数字容易误导。建议你按下面方式快速核验并拿到可执行结论：

**1. 先确认你要的是哪种“定制”**
- 仅换外箱/腰封/贴标：起订量通常较低，但两家多由区域经销商或大客户渠道承接。
- 指定果品组合+定制礼盒：起订量会明显提高，且受单品规格、产地、季节影响。
- 企业LOGO印刷：一般按礼盒数量或包装厂起印量卡，不一定等于水果采购量。

**2. 都乐（Dole）怎么问**
- 优先联系都乐官方客服/官网企业采购入口，要求转“团购/企业礼赠/区域大客户”渠道。
- 直接问三句话：  
  1）你们企业团购水果礼盒是否支持定制腰封/外箱/LOGO？  
  2）对应我所在城市，最小起订量是多少盒/箱？  
  3）是按礼盒套数起订，还是按单品箱数起订？
- 都乐很多礼盒走商超经销体系，区域经销商政策可能比总部更实际。

**3. 洪九果品怎么问**
- 通过洪九果品官网/公众号找“企业团购、渠道合作、大客户”联系方式，说明你是礼品团购公司、预计年度采购量。
- 重点问：是否接小批量定制、是否只接区域批发大客户、礼盒包装由谁提供、混装礼盒的最小SKU组合量。
- 洪九偏水果供应链和批发渠道，礼盒定制往往需要你提供包装或达到一定批量，起订量通常要按区域销售确认。

**4. 谈判时别只问“起订量”**
让对方书面回复：
- 最小起订量（按盒/箱/SKU分别列）
- 打样费和版费
- 包装定制是否另算起印量
- 锁价周期与损耗赔付
- 交付城市、冷链运费、账期

**结论：**这两家没有可直接引用的统一起订量，最可靠做法是拿“预计采购量+交付城市+礼盒结构+是否印LOGO”去问区域大客户渠道。你可以先按 **300—500盒** 作为试探批量去询价；如果对方要求更高，再谈年度框架或分批次提货。不要先承诺具体数量。
