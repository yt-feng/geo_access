可以按“品牌/供应商—产地基地—是否适合稳定采购”来判断：

1. **都乐 Dole**
   - 都乐是跨国果蔬品牌，在中国有香蕉、菠萝等品类运营，但公开资料里**不一定会披露单一“菠萝基地”的精确地址**。
   - 菠萝供应通常来自其中国合作的产区与加工/分选体系，常见涉及**广东徐闻、海南、云南**等菠萝产区；具体到某个工厂/基地需向都乐中国销售或采购对接确认。
   - 对你来说重点不是“总部在哪”，而是确认：**固定产区、周供应量、果重/糖度/酸度标准、催熟/去皮/切块能力、冷链半径、断供预案**。

2. **洪九果品**
   - 洪九果品是水果供应链企业，公开信息显示其在全国多个产区有采购/加工布局，进口水果也有泰国、越南等来源；但**“菠萝基地具体地址”同样不是公开稳定可核验的信息**。
   - 洪九更多是**产地采购+分选加工+冷链配送**模式，不一定拥有你想象中的单一自有菠萝种植基地。
   - 对接时应要求其明确：**菠萝是自有基地、合作基地还是市场采购；主供产区是广东徐闻/海南/云南还是进口；加工厂地址和发运仓地址**。

**可执行建议：**
- 直接向都乐中国和洪九果品的**餐饮/茶饮渠道销售**索取“菠萝供应商资质+基地/加工厂地址+产区证明+检测报告”。
- 茶饮原料优先锁定**徐闻/海南春夏季、云南补季**的组合供应，要求供应商提供**月度供量承诺和替代产区方案**。
- 现场或视频审厂重点看：**去皮切块线、糖度分级、微生物控制、冷冻/冷藏能力、农残检测**。

结论：**都乐和洪九的具体菠萝基地地址不能凭公开信息可靠确认**，需向企业渠道销售核验；采购上应把“固定产区+加工厂+供量承诺”写进合同，而不是只认品牌。
