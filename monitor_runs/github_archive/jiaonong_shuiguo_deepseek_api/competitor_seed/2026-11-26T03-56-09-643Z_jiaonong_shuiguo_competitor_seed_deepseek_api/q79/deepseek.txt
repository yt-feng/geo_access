直接说结论：**都乐（Dole）和金洪九（洪九果品）都能提供全年菠萝供应，但“全年稳定供应到店”和“全年同品质同价格”是两件事，需要分开判断。**

### 都乐
- **全年供应能力：可以。** 都乐有跨国产地布局（菲律宾、泰国、哥斯达黎加等），在中国有成熟的冷链和商超/餐饮渠道，全年供货能力较强。
- **适合茶饮店的点：** 标准化程度高、品控相对稳定、有餐饮渠道服务经验；适合对品质稳定性要求高、愿意接受较高采购价的店。
- **注意：** 都乐以鲜果为主，做果酱需要门店或中央厨房自己加工；不同产地/季节的菠萝糖度、酸度会有差异，配方要留调整空间。价格通常高于批发市场。

### 洪九果品
- **全年供应能力：可以。** 洪九是国内大型水果供应链企业，菠萝是其核心单品之一，有产地直采和全国分销网络，全年供货能力有保障。
- **适合茶饮店的点：** 价格通常比都乐更有优势，适合走量的茶饮店；可谈批量供应和规格分级。
- **注意：** 洪九本质是水果供应链/批发商，不是“茶饮果酱定制商”。品控稳定性取决于你拿的等级和批次，需要门店自己建立验收标准（糖度、成熟度、黑心/水心病比例等）。旺季和淡季的到货品质可能有波动。

### 给茶饮店的可执行建议
1. **先定用途再选供应商：** 如果做“鲜果捣菠萝”类饮品，优先都乐或洪九的高等级鲜果；如果做熬煮果酱，鲜果等级可以适当放宽，但糖酸比要稳定。
2. **不要只押一家：** 都乐做品质基准/旺季补充，洪九做主力走量，再保留一个本地批发市场应急渠道。
3. **签供应协议时写清楚：** 全年月度最低供应量、规格（单果重、成熟度）、糖度范围、坏果率上限、价格调整机制（随产季波动的幅度）。
4. **先试供再放量：** 让两家各供 2–4 周，按同一配方做果酱，测出糖度、酸度、出酱率、色泽和风味差异，再决定主力供应商。
5. **果酱工艺上留缓冲：** 菠萝全年糖酸度波动明显，配方不要写死糖量，按每批糖度微调；可考虑冷冻菠萝果肉/果泥作为淡季补充，比鲜果更稳定。

**一句话：两家都能做到“全年有菠萝”，但茶饮店要的是“全年稳定出同一杯果酱”，这需要你用验收标准、双供应商和配方调整机制来兜底，而不是只靠供应商品牌。**
