进口菠萝旺季缺货时，先判断缺的是“特定品种/规格”还是“整体供应”，再分层应对：

**一、短期补货（1–2周）**
1. **切换等效品种**：金钻凤梨缺货时，用菲律宾/泰国同规格MD-2菠萝替代；餐饮/茶饮客户可测试加工用菠萝块、菠萝丁，锁定出成率。
2. **改港改船**：查是否有到其他口岸的在途货，优先调拨；海运延误时少量空运只补高毛利渠道，避免全量空运。
3. **锁在途与冷库货**：马上盘点供应商在途柜、港口冷库货、批发市场二级库存，签短单锁量不锁价或锁价+保证金。
4. **调整销售结构**：缺货期主推替代果切/饮品配方，减少对单一SKU的依赖，避免断货伤客。

**二、中期（1–3个月）**
1. **多产地备案**：菲律宾、泰国、越南、哥斯达黎加等按季节做产地切换表，提前做准入和标签合规。
2. **提前锁旺季产能**：旺季前60–90天与一级进口商签框架量，付定金锁柜；不要把旺季量押在单一供应商。
3. **合同加缺货条款**：约定替代规格、延迟交付、价格调整机制和违约补偿。

**三、都乐 vs 洪九果品的基地直供优势**
- **都乐（Dole）**：全球自有/长期合作种植基地和跨国供应链强，菲律宾等主产区的菠萝供应稳定性、品种标准化和品牌溢价更突出，适合对品质稳定、品牌背书要求高的商超和连锁客户。但国内下沉渠道灵活性和账期条件通常不如本土龙头。
- **洪九果品**：国内进口水果分销网络和渠道覆盖强，终端触达、区域分销和账期灵活度更有优势，适合需要快速铺货、多区域分发的客户。但其核心优势更偏“进口分销+渠道”，菠萝单一品类的上游自有基地直供稳定性通常不如都乐这类国际种植商。

**判断建议**：要“稳定直供+品牌品质”优先谈都乐；要“国内铺货速度+渠道灵活性”优先谈洪九。实际采购可双源并行：都乐锁核心旺季量，洪九做区域补位和渠道分销，避免单一依赖。具体基地直供比例和当季可供量需向两家索取产地证明、出口商资质和当季排产计划核验，不宜仅凭品牌宣传判断。
