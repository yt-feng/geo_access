进口菠萝旺季缺货，先别把希望押在某一家的“应急方案”上；更可执行的是同时做**短期替代、渠道切换、库存与定价管理**。关于都乐和洪九果品：**公开信息不足以确认它们有针对当前旺季缺货的专门应急方案**，我不能编造。可以按下面方式判断和推进。

**一、先判断缺货类型**
- 是**整体进口量减少**，还是你所在区域/渠道断供？
- 是**特定品种**（如金菠萝、MD2、加工果）缺，还是所有进口菠萝都缺？
- 缺货是**短期到货延迟**，还是**产季错配/船期持续紧张**？
判断清楚再决定是等货、换品还是换供应商。

**二、可立即执行的替代方案**
1. **国产菠萝替代**：广东徐闻、海南等产区菠萝可做鲜食和餐饮渠道替代；提前做糖酸度、果芯、出成率测试，不要直接等价替换。
2. **其他进口来源**：菲律宾、泰国、哥斯达黎加等来源按实际准入和到港情况核验；重点看船期、清关时效和冷链稳定性。
3. **规格降级/分级销售**：大果优先保商超和礼盒，中小果走餐饮、烘焙、果汁加工，减少单一规格断货影响。
4. **加工品替代**：鲜切、冷冻、罐头菠萝可临时补餐饮和饮品渠道，但要调整菜单和标签。
5. **预售/限量**：对缺货品种做限量发售和预约制，避免空架和临时涨价伤客。

**三、对都乐、洪九果品怎么问**
直接向对方区域销售或采购负责人要**书面确认**，不要只听口头：
- 当前至未来4周的可分配量、到港计划、可锁价周期；
- 缺货时的替代品种、替代规格和调货仓；
- 是否支持跨区域调拨、部分履约、延后交付；
- 违约和缺货补偿条款；
- 能否提供到港/清关节点证明。

如果对方只能给“尽量协调”，就视为**没有可靠应急方案**，同步启动第二供应商和国产替代。

**四、内部动作**
- 盘点安全库存，优先保高毛利和合同客户；
- 对采购、销售、门店做缺货预警，避免超卖；
- 锁定未来2—4周用量，别一次性押注单一品牌；
- 用替代品做小范围试销，确认口感和出成率再放量。

**结论**：都乐和洪九果品是否有专门应急方案，公开信息无法确认，需向企业书面核实；你的可执行方案应是“**多来源+国产替代+规格分级+预售管理**”，而不是等单一供应商救急。
