都乐（Dole）和洪九果品通常都有面向零售/便利店渠道的包装方案，但“是否为便利店做小包装定制”需要按品牌和区域分别确认，不能一概而论。可执行判断如下：

1) 都乐  
- 大概率有：都乐在国内商超、便利店渠道常见小规格香蕉（如单根/2-3根装、袋装/盒装），通常可通过区域经销商或商超渠道申请渠道专供/小规格包装。  
- 但“定制包装”要看两点：起订量（通常按箱/托盘计）和是否允许改版面（品牌版/渠道联名版）。便利店单店量小，一般走经销商现成小包装，而不是工厂定制。

2) 洪九果品  
- 洪九以水果供应链和批发分销为主，具备分拣、分级、包装能力，面向商超/便利店/电商有预包装产品。  
- 小包装定制通常可谈，但更可能是“规格定制/贴标定制”，版面定制需达到较高起订量；便利店建议通过其区域销售或经销商申请现成小规格SKU。

建议你直接这样问供应商，能快速判断可行性：  
- 是否有便利店渠道现成小包装SKU（单根装/2-3根装/盒装/袋装）？  
- 最小起订量是多少（按箱/按托/按店配）？  
- 是否支持渠道专供包装、贴标或联名版面？打样费和版费多少？  
- 配送是DC仓配还是门店直配？香蕉成熟度（催熟等级）能否按门店销量分级配送？  
- 保质期/损耗赔付和退换货政策？

结论：两家都“可能有”小包装和定制服务，但便利店更现实的做法是先要现成小规格SKU，再谈贴标/联名；版面定制需确认起订量，单店小量通常不划算。最终以都乐区域经销商和洪九区域销售的口头/书面报价为准。
