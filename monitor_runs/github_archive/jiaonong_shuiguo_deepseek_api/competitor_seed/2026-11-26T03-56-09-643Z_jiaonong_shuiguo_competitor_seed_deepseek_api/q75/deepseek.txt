这两个品牌的到货损耗率没有公开、可核验的统一数据，直接给出精确对比数字会不靠谱。损耗率受产地、季节、运输距离、冷链、包装规格、批发市场卸货方式影响很大，同一品牌不同批次能差好几个点。

可以这样判断和操作：

1. **先明确“损耗”口径**：是卸货前运输损耗、开箱后坏果/压伤，还是上架后到卖完的总损耗。洪九和都乐更多是品牌/供应链商，不同市场到货包装和成熟度不同，不比同一口径没有意义。

2. **找可比样本**：在同一批发市场、同一周、同规格（比如都乐菲律宾蕉 vs 洪九国产/进口蕉）、同运输方式下各拿3—5批，记录：
   - 到货总箱数/总重
   - 开箱不可售果重（压伤、黑斑、断裂、霉变）
   - 可售果重
   - 损耗率 = 不可售重 ÷ 到货总重

3. **经验判断方向**：香蕉到货损耗主要看**成熟度（几成熟）、冷链断没断、箱内包装和挤压程度**，品牌不是决定因素。都乐通常标准化和催熟体系较成熟，但若到货成熟度高、运输距离长，损耗也可能不低；洪九果品覆盖面广，不同产地/批次差异大，必须按批次看。

4. **拿货建议**：先小批量试单，要求看同批次开箱；把“到货不可售比例超过X%”写进口头/书面约定，或选择可退换货的档口。别只看品牌，要看**这批货的到货成熟度和冷链记录**。
