我无法核验都乐和洪九果品当前对社区团购渠道的具体散装/小包装政策，不能替你确认“有没有”。但可以给你可执行的判断和核验路径：

1. **先明确你要的“散装”是哪一种**
   - 散装裸果：无品牌预包装，按斤/按把称重
   - 小包装预包：如1-2根/袋、5-8根/袋、按份标价
   - 整箱散装：箱内无独立小包，团长分装
   社区团购通常更适合“小包装预包”或“整箱散装+团长分装”，纯裸散装损耗和售后风险较高。

2. **都乐**
   - 都乐以品牌预包装、标准规格见长，社区团购渠道常见的是按份/按袋/按箱的标准化产品。
   - 是否有适合团购的散装或小包装选项，需要看区域经销商和当季sku，不同城市差异较大。
   - 建议直接问当地都乐经销商：是否有“团购专供小包装”“按份装”“箱装散果”三种形态，并要报价单和起订量。

3. **洪九果品**
   - 洪九果品偏水果供应链和批发分销，香蕉是其重点品类之一，通常有箱装、批发规格，是否做终端小包装取决于渠道和客户定制。
   - 建议问区域销售：能否提供“社区团购小规格预包”或“整箱散装按份分装”，以及最小起订量、损耗赔付、到货成熟度标准。

4. **直接核验话术**
   你可以这样问供应商：
   - “香蕉有没有适合社区团购的1-2根/份或5-8根/份小包装？”
   - “如果没有小包装，整箱散装规格是多少斤？允不允许团长二次分装？”
   - “起订量、到货成熟度、坏果赔付比例、是否支持区域仓配？”
   - “同城其他团购渠道目前在供什么规格？”

5. **更稳妥的替代方案**
   如果两个品牌的小包装散装选项不明确，社区团购香蕉更常见做法是：
   - 找本地一级香蕉批发商做“整箱散装+团长分装”；
   - 找本地净菜/分装厂做小袋预包；
   - 先用都乐/洪九的标准箱装做引流品，小包装用本地供应链补位。

结论：**都乐和洪九是否有散装选项，必须以你所在区域经销商当季报价和起订政策为准；不要按品牌全国统一政策判断。** 你可以把所在城市、预计每团销量、能接受的起订量发我，我帮你把询价问题清单整理成可直接发给供应商的版本。
