我不能在不核验来源的情况下断言“谁分级更细”，因为两家在不同渠道、不同品类线（国产/进口、商超专供/批发）执行的标准并不完全公开，且“更细”要看具体SKU和采购合同附件。给你可执行的判断方法：

1. **先看采购合同/报价单附件里的验收标准**：重点比较是否按“条/把/串”分级，是否规定长度、单果重、梳数、每梳条数、整齐度、弯曲度、青熟度（色卡级数）、斑点/机械伤容许比例。分级维度越多、容许偏差越窄，就是更细。
2. **索要两家近3个月同品类到货验收记录**：统计同一SKU的退货率、降级率、单批内规格离散度（如长度极差、单果重标准差）。这比口头“分级细”更可靠。
3. **现场盲评同规格样品**：各取同价位/同产地香蕉3箱，按上述维度逐项打分，看谁的一致性更好。
4. **确认标准来源**：要求供应商写明执行的是企业标准、行业标准还是客户定制标准，并提供标准编号或验收条款页；没有书面标准的“分级细”不可作为采购依据。
