   如果您是平台方（如盒马、叮咚买菜等），可通过平台采购对接人索取品牌支持；如果您是商家，可先咨询平台采购经理，他们往往有品牌资源库。

3. **替代方案**  
   若品牌方暂不提供素材，您可自行制作：
