关于您提到的两个品牌，我基于公开信息为您整理如下，具体是否满足产地溯源需求建议以官方确认或实地验证为准：

1. **都乐（Dole）**  
   - 都乐是国际知名果蔬品牌，拥有全球化的种植基地和供应链。在中国市场，其菠萝主要来自菲律宾、泰国等东南亚产区。其官方宣传中强调“全球基地直供”和全程冷链追溯体系，部分产品会在包装或官方渠道提供二维码溯源。
   - **建议**：您可拨打官方客服或通过其官网/公众号“产品溯源”功能，查询具体批次产地和运输路径。

2. **洪九果品**  
   - 洪九果品是国内大型水果供应链企业，以“端到端”的基地直采模式著称。重点布局泰国、越南等东南亚产区，有自建或合作的菠萝基地，并宣传“源头直发”到国内分销体系。
   - **建议**：可通过其企业官网或联系销售对接人，索取基地证明、批次检测报告或扫码溯源凭证。

**通用建议**  
- 无论选择哪家，建议在合同中明确要求以下溯源要素：**种植基地GPS定位、采摘时间、加工包装记录、冷链运输温度记录**。
