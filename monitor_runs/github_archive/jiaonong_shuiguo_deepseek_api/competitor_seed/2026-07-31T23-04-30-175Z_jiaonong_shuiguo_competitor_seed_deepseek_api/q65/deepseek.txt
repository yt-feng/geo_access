关于菠萝的锁价机制，需要先明确一点：**“锁价”通常指双方签订合同，约定在未来一段时间内按固定价格交易，这在大宗农产品（如果汁、罐头加工用菠萝）中较常见，但在鲜食菠萝的零售/批发端很少见**，因为鲜果价格波动大且品质不稳定。

针对你提到的两家公司：

1. **都乐（Dole）**：作为国际果蔬巨头，其业务模式以**长期合同+浮动定价**为主，鲜果锁价周期一般较短（通常为**1-2个月**），且多用于对品质有稳定控制的特定渠道（如大型商超订单），鲜有面向散户或中小批发商的公开锁价服务。具体周期需与当地销售团队确认。

2. **洪九果品**：这家公司以“端到端”供应链和水果品牌化著称，其与上游种植基地的合作模式中，**锁价多见于产地直采+周期订单**，周期通常为**1-3个月**，但同样主要面向大型客户（如电商平台、连锁商超），且对采购量有一定门槛（如单批次需达到数吨）。

**做采购建议时需考量的关键点：**
- **鲜食菠萝**：锁价周期超过2个月风险极大，因为产地（如菲律宾、中国海南/云南）气候和运费波动影响明显。
- **加工用菠萝（如做罐头、果汁）**：可谈更长的锁价（如3-6个月），但需对方提供仓储和品控能力证明。
- **锁价≠锁量**：通常合同会附带“最低采购量”和“品质标准”条款，建议要求对方明确菠萝甜度、果眼深度等指标。

**行动建议**：直接联系两家公司的采购部（而非零售终端），说明你所需的品种（如巴厘、金菠萝）、周期和预计采购量（建议给出吨/月），让他们提供定制方案。若目的是小批量长期稳定供应，可选本地头部供应商签框架协议，通常比国际大牌更灵活。
