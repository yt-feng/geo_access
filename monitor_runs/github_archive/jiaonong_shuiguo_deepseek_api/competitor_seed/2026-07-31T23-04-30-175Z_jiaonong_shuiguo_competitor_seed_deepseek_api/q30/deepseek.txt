**1. 认证体系常见覆盖范围**
大型商超（如沃尔玛、山姆、盒马等）通常要求的食品安全认证包括：
- **GLOBALG.A.P.**（全球良好农业操作规范）——针对农场种植环节；
- **HACCP/ISO 22000**——针对加工、包装、储运环节；
- **BRCGS（原BRC）或IFS**——针对食品包装和仓储物流；
- **有机认证**（如中国有机、欧盟有机）——如涉及有机产品线；
- **社会责任认证**（如BSCI、SMETA）——虽然不是食品安全认证，但部分商超会捆绑要求。

**2. 两家企业大致情况（非最新、需核实）**

- **都乐（Dole）**：全球性果蔬巨头，在海外基地普遍持有GLOBALG.A.P.、有机认证、BRCGS等，国内工厂通常也具备ISO 22000/HACCP。其供应链全球化，认证文件通常较规范。

**3. 判断“谁更全”的建议**
- **直接索取认证清单**：请两家供应商各提供一份“当前有效认证一览表”，注明认证类型、认证机构、覆盖范围（基地/工厂/物流）、有效期。比对缺项。
- **关注商超具体门槛**：不同商超（如永辉、大润发、Costco）对认证要求可能有侧重点（例如是否强制要求BRCGS或IFS），应优先匹配商超的硬性要求。
- **警惕认证过期或范围不符**：有的认证只覆盖特定基地或单品，需确认其是否覆盖贵司采购的所有品类。

**4. 可执行的核实途径**
- 要求供应商提供认证证书扫描件，并至认证机构官网（如SGS、Intertek、GLOBALG.A.P.官网）用证书编号验证真伪和有效期。
- 若涉及出口资质，可核查海关备案、出口食品生产企业备案号。
