关于菠萝的到货损耗率，**建议以实际到货验收为准**，因为损耗率受季节、产地、运输方式、仓储条件影响极大，行业内不会有固定数值。

不过，可以参考以下一般行业经验（非官方数据）：

1. **都乐（Dole）**：作为国际品牌，其标准化程度较高，通常采用冷链运输，成熟度控制较严。在正常冷链条件下，菠萝到货损耗率一般在 **3%-5%** 左右（包括轻微机械伤、腐烂果、过熟果）。
2. **鑫荣懋（Joyvio）**：作为国内头部水果供应链企业，其合作基地和分级标准较稳定。到货损耗率通常与都乐接近，常规在 **3%-6%** 之间；若夏季高温或运输延误，损耗可能上升到 **8%-10%**。

**给您的实操建议：**
- 签订采购合同时，**明确约定到货损耗率上限**（如超过5%部分由供应商承担），并要求供应商提供损耗赔付标准。
- 每次到货后立即抽检（开箱检查底部、果柄、表皮），记录实际损耗，作为后续议价或更换供应商的依据。
- 根据您门店的日均用量，预留5%-10%的安全库存缓冲，避免断货。

如果您需要更精确的数据，建议向两家供应商的销售代表索取近3个月的**物流损耗实绩报表**，或要求他们提供“同城同规格”的案例数据。
