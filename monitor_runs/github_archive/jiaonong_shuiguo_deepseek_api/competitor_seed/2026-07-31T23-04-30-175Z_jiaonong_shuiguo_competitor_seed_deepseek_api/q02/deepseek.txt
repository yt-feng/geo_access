除了都乐（Dole），目前市场上还能稳定供应菠萝的品牌主要有以下几个，它们在规模化种植、冷链物流和季节供应上相对成熟：

1. **佳沛（Zespri）**——虽然以奇异果闻名，但近年也开始供应菠萝，主要来自东南亚产地，品控稳定。
2. **新奇士（Sunkist）**——美国品牌，主要供应菲律宾和哥斯达黎加的菠萝，渠道覆盖面广，尤其在商超渠道。
3. **金菠萝（Gold Pineapple，如Doña Rafaela）**——菲律宾品牌，尤其是“黄金菠萝”系列，甜度高、纤维少，在高端超市和电商平台有持续供应。
4. **乐淇（Rockit）**——新西兰品牌，主打迷你菠萝，供应稳定但定位偏高端小包装。
5. **玺赞（Zespri的竞品，如“甜蜜蜜”品牌）**——国内一些大型水果企业（如百果园、鑫荣懋）自有品牌菠萝，通过基地直采保证供应。
6. **泰国皇家（Royal Project）**——泰国品牌，常见于进口超市，供应期集中在每年3-6月，但常与电商渠道合作维持年度供应。

**建议**：
- 如果您是B端采购，优先考虑**佳沛、新奇士、金菠萝**，这三大品牌在供应链上最稳。
- 如果是零售终端，可同时搭配**菲律宾和哥斯达黎加产地的“黄金菠萝”**，口感好且货源足。
- 观察季节性：菠萝有主产期（春季至夏初），但大型品牌通常有南半球/北半球轮换产地，可全年供应。

如果您的渠道对价格敏感，建议直接联系**国内头部水果批发商（如鑫荣懋）**，他们代理多个稳定品牌，并可协调产地直供。
