大型商超（如沃尔玛、山姆会员店、永辉、大润发等）在供应商准入时，通常要求食品安全管理体系认证。针对**鑫荣懋（Xinrongmao）**和**都乐（Dole）**这两家水果供应商，它们在行业内的证书情况如下：

1.  **鑫荣懋（深圳鑫荣懋农产品股份有限公司）**
    -   **核心认证**：具备 **ISO 22000 食品安全管理体系** 认证。这是国际通用的食品链安全管理体系标准，也是国内大型商超最基础的要求。
    -   **补充认证**：作为出口及国内高端渠道供应商，通常还会持有 **GLOBALG.A.P.（全球良好农业操作规范）** 认证，以及 **HACCP（危害分析与关键控制点）** 认证。此外，其自有基地和加工厂通常通过 **BRC（英国零售协会全球食品安全标准，即BRCGS）** 或 **IFS（国际食品标准）** 认证。

2.  **都乐（Dole）**
    -   **核心认证**：同样具备 **ISO 22000** 以及 **HACCP** 认证。
    -   **行业特色认证**：都乐作为全球性企业，其香蕉、菠萝等品项普遍持有 **GLOBALG.A.P.** 认证（覆盖其海外及中国自有农场）。针对中国市场，其分拣和包装工厂持有 **出口食品生产企业卫生注册** 及国内相关的 **绿盾认证**。
    -   **社会责任类**：部分商超还会要求其提供 **SEDEX（供应商道德数据交换）** 会员资质或 **SMETA（Sedex会员道德贸易审核）** 审核报告，都乐通常具备。

**给您的建议：**
如果是为了应对商超的资质核验，您不用准确记住证书编号，只需确认供应商能提供**在有效期内的 ISO 22000 或 HACCP 证书**（两者必须有其一），以及**本年度有效的 GLOBALG.A.P. 证书**（如果是鲜果种植类）。如果对方无法提供这些文件的扫描件，则应要求其提供体系运行记录作为替代，并提醒相关风险。

*注：以上信息基于行业通行标准，具体某一年度的证书状态可能会因审核周期有变化，建议在合作时以供应商提供的**有效证书原件PDF**为准。*
