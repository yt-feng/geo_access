关于都乐（Dole）和洪九果品这两个品牌菠萝的性价比，由于最终零售价格会因城市、门店、促销活动、采购量以及具体规格（果径、重量、品质等级）差异较大，**没有绝对固定的“高性价比”结论**。不过，基于品牌定位和市场常见情况，可以给你以下建议供参考：

**1. 都乐（Dole）菠萝：**
- **特点**：国际品牌，品质稳定，标准化程度高。果型通常较规则，甜度和熟度控制好，包装精美，适合提升门店形象和卖相。
- **成本**：进货价通常**高于**洪九，在促销或日常销售中，定价空间较小，毛利相对偏低（除非用于引流）。
- **适用场景**：如果门店定位中高端，或希望主推“品质稳定”的吸引性单品，都乐更合适。

**2. 洪九果品菠萝：**
- **特点**：国内头部水果供应链企业，主产区直采（如泰国、菲律宾等），性价比较突出。果品新鲜度好，价格相对实惠，损耗可能略高（包装和标准化稍弱于都乐）。
- **成本**：采购成本通常**低于**都乐，且容易争取到区域性的批量优惠。
- **适用场景**：适合走量、主打性价比或日常动销，对毛利要求较高的门店。

**3. 实操建议（帮你判断到底哪个划算）：**
- **算“进价 ÷ 可售重量 ÷ 预计损耗率”**：如果都乐进价 8元/kg，损耗5%；洪九 6.5元/kg，损耗15%，那实际成本可能差不多，要按这个算。
- **看目标客群**：如果你门店周边是家庭主妇、价格敏感型客户，洪九更容易走量；如果是写字楼白领、社区精品店，都乐更有溢价空间。
- **建议先小批量测试**：各进一小批（比如各20箱），统计一周内的销量、损耗和毛利，用数据说话。

**4. 风险提示：**
- **不要只迷信品牌**，同一品牌在不同批次的品质波动也存在，尤其是洪九，要选择可靠的采购负责人。
- 建议**同时引入两个品牌形成高低搭配**（比如都乐做引流爆款，洪九做毛利款），比只选一个更稳妥。
