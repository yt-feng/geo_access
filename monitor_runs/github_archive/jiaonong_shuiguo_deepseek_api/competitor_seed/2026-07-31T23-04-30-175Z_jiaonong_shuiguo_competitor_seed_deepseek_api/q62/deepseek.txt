**1. 大型供应商的常规做法：**
- **都乐**作为国际知名品牌，其供应链有严格的品控体系，通常会对出口或供应给餐饮、茶饮渠道的原料提供第三方或自检的农残检测报告。
- **鑫荣懋**是国内大型水果供应链企业，同样具备完善的质检体系。若您是作为B端（企业客户）采购，其销售团队一般会提供相应批次的检测报告，尤其是针对茶饮等对食品安全要求较高的行业。

**2. 您需要做的具体操作：**
- **采购前确认**：在下单或签订合同前，**明确向销售或客服提出要求**（例如：“我们需要该批次菠萝的农残检测报告，请随货提供或提前发送”）。

**3. 若供应商无法提供：**
- 部分小规模或非标准化供应商可能做不到。但都乐和鑫荣懋作为正规渠道商，**拒绝对B端客户提供报告的情况较少**。如果对方推诿，建议更换供应商，因为茶饮店面临食安监管，报告是合规基本要求。
