### 一、品牌背景差异（影响定价策略）

| 维度 | 都乐（Dole） | 鑫荣懋（Golden Wing Mau） |
|------|-------------|---------------------------|
| 定位 | 全球知名水果品牌，主打高端、标准化、品牌溢价 | 国内头部水果供应链企业，兼营代理国际品牌+自有产地，渠道分销能力强 |
| 进口苹果主要来源 | 美国（华盛顿州）、新西兰、智利等，多走高端渠道（商超、精品店） | 新西兰、南非、智利等，覆盖中端及大众渠道，价格带更宽 |
| 价格特点 | 通常**单价偏高**，但品质标准化高、损耗低、卖相好 | **同等品质下往往更便宜**，因为有产地直采和规模采购优势，且促销灵活性高 |

### 二、决定竞争力的关键因素（建议你直接对比）

1. **具体品种和规格**  
   - 进口苹果常见品种：红玫瑰（Pink Lady）、富士（Fuji）、爵士（Jazz）、嘎啦（Gala）、青森等。高等级（如直径80mm+）的价位差异大，必须同规格比价。
   
2. **价格体系与账期**  
   - 都乐偏向品牌直供，价格坚挺，但给商超的返点、促销支持较标准化。  
   - 鑫荣懋更灵活，可能给出批量折扣、临期处理价、账期支持，**在毛利和现金流上更有竞争力**。

3. **采购数量**  
   - 如果单次采购量大（如整柜），鑫荣懋的源头集采优势会更明显；如果小批量多频次，都乐的稳定供应和品质一致性可能弥补价格差。

4. **当地市场行情**  
   - 进口苹果价格每周浮动，建议你分别向两家要**本周现货报价单**（含到岸价、仓储费、配送费），并要求标明产地和等级。

5. **隐性成本**  
   - 都乐的品牌溢价带来的终端售价更高，可能更适合高端客户；如果你们定位偏社区或大众消费，鑫荣懋更容易跑量。

### 三、可落地的操作建议

1. **立即询价对比**：  
   向两家同时索取：同一品种（如新西兰爵士苹果，80果）、同一规格、同一到货城市的价格（元/斤或元/箱），并要求拆分**成本（到岸+包装+配送）**。

2. **小批量试单**：  
   各下一小批试单（如各50箱），实测损耗率、口感稳定性、消费者反馈，再定主供应商。

3. **谈合作条件**：  
   如果你有3家以上门店，可以拿都乐的报价去压鑫荣懋，反之亦然；重点谈判“坏果赔付率”和“空档期补货”条款。

4. **关注季节性**：  
   南半球（智利、南非）苹果在北半球淡季（3-8月）有价格优势，北半球（美国、新西兰）在9-次年2月供应充足。此时**鑫荣懋的南半球货源定价通常更低**；都乐在美国产区有强势合作，但溢价依旧。

### 四、我的初步判断（供参考）

- **如果只论单品定价**：大概率是 **鑫荣懋更便宜**，尤其是智利、南非等非高档产区，价格竞争力明显。
- **如果论综合价值**：都乐在高端果品、损耗控制、品牌背书上有优势，适合做精品线或礼品单；鑫荣懋则更适合“日常走量”和活动促销。
