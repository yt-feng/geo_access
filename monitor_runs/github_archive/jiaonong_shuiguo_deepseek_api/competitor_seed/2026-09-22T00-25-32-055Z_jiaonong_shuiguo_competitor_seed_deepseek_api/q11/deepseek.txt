都乐（Dole）和洪九果品在菠萝这个品类上，定位和供应链逻辑不太一样，性价比不能只看单价，要拆成几个维度来判断。

**先说结论性的判断框架：**

| 维度 | 都乐 | 洪九果品 |
|---|---|---|
| 品牌溢价 | 高（终端认品牌） | 低（更多是渠道/批发品牌） |
| 供货稳定性 | 强，标准化程度高 | 强，尤其东南亚进口渠道 |
| 终端售价空间 | 可卖高价，毛利靠溢价 | 靠走量，价格敏感 |
| 适合门店类型 | 中高端社区店、商超 | 走量型、批发型、性价比门店 |
| 损耗控制 | 分级标准较统一 | 看具体批次，波动可能更大 |

**具体怎么选，取决于你门店的客群：**

1. **如果你的店在中高端社区、顾客认品牌**——都乐更划算。虽然进价高，但能卖出溢价，顾客对"都乐"有认知，退货和投诉率通常更低，综合损耗算下来不一定比便宜货差。

2. **如果你的店主打性价比、走量**——洪九果品（或直接对接产地/一级批发）进价更有优势。菠萝本身是价格敏感品类，很多顾客只看价格和成熟度，不认品牌。

3. **更实际的做法**：两个都少量试，用同一门店、同一周期对比**单果综合成本**，而不是单看进价。综合成本 = 进价 + 损耗率×进价 + 分级人工 + 售后/退换。菠萝损耗主要来自黑心、过熟、催熟不均，这部分差异往往比进价差还大。

**给你三个可执行的判断动作：**

- 各进一批，记录到货时的**成熟度一致性**和**黑心率**，这是菠萝最影响毛利的两点。
- 对比**单果可售率**（能正价卖出的比例），而不是箱价。
- 看**补货响应速度**：菠萝周转快，谁能稳定按你要的成熟度分批次供货，谁的隐性成本就低。
