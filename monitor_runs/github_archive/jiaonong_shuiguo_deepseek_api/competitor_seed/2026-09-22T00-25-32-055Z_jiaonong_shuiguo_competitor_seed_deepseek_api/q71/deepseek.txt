你提到的两家公司情况不一样，需要分开看：

**都乐（Dole）**
- 都乐不是自有单一基地型供应商，而是全球采购+区域配送模式。在中国市场，都乐菠萝的主要来源包括：
  - 菲律宾（都乐在菲律宾有长期种植和合作基地，是国内都乐菠萝的主要进口来源）
  - 哥斯达黎加等中南美产地
  - 国内部分合作种植基地（如广东、海南等地有合作果园，但并非都乐全资自有）
- 都乐在中国的运营主体是都乐食品（上海）等，走的是品牌化分选、催熟、配送体系。

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，核心模式是“基地直采+全国分销”，在多个东南亚产地有布局：
  - 泰国：龙眼、榴莲等核心产地有长期合作基地和工厂
  - 越南：火龙果、菠萝蜜等
  - 菲律宾：菠萝等
  - 国内：在重庆、四川、云南、海南等地有分选加工中心和合作基地
- 洪九的菠萝供应主要依赖东南亚直采（菲律宾、泰国等），国内基地更多是分选、催熟、配送节点，不是大规模种植基地。

**对你做茶饮原料采购的实际建议：**
1. 如果你要的是**稳定、标准化、可追溯**的菠萝原料（果肉/果浆/冷冻块），直接找都乐或洪九的**B2B供应链部门**，而不是零售渠道。
2. 问清楚三个关键点：产地是否固定、是否有催熟和糖度分级、最小起订量和锁价周期。
3. 茶饮用量大且要求稳定，通常更建议走**冷冻菠萝块/菠萝果浆**而非鲜果，供应链波动小很多。
4. 如果都乐和洪九的起订量或价格不合适，可以同时对比：佳农、鑫荣懋、鲜丰水果的B2B板块，以及广东、海南本地的菠萝加工厂（做冷冻块和果浆）。
