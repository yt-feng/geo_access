如果客户明确要“进口品牌”，**都乐（Dole）和佳沛（Zespri）里，通常佳沛礼盒更受欢迎，尤其在中高端企业团购和节庆送礼场景**。但结论要看具体用途，不能一概而论。

**简要判断：**

- **佳沛更占优势的场景**  
  - 预算中高端，送礼对象偏商务、客户、领导  
  - 看重“进口感、品牌感、健康感”  
  - 主推奇异果礼盒，认知度高，包装和规格容易做出档次  
  - 节庆送礼时，佳沛金果、绿果礼盒通常比都乐水果礼盒更有“专门礼盒”的心智

- **都乐也有优势的场景**  
  - 预算相对可控，但又要进口品牌背书  
  - 客户想要水果品类更丰富，比如香蕉、菠萝、车厘子、蓝莓等组合  
  - 需要走商超、员工福利、大批量稳定供货  
  - 都乐品类广，做混合水果礼盒更灵活

**实际团购里常见的结论：**
1. **单一水果礼盒、偏送礼：佳沛更容易被选中。**  
   尤其是佳沛金果礼盒，认知度强，客户接受度高。
2. **混合水果礼盒、偏员工福利：都乐更灵活。**  
   都乐能组合更多品类，价格带也更好做。
3. **如果客户只说“进口品牌”，没指定水果：**  
   优先推荐佳沛奇异果礼盒，其次再配都乐组合装作为备选。

**给客户的推荐话术可以这样：**
> 如果偏商务送礼、要品牌感和进口感，建议主推佳沛金果/绿果礼盒；如果偏员工福利、预算要灵活、还想水果种类丰富，可以选都乐组合礼盒。两者都是进口品牌，但佳沛在“礼盒送礼”场景通常更受欢迎。

**最终建议：**
- 商务送礼、节庆客户礼：**选佳沛**
- 员工福利、混合水果、控预算：**选都乐**
- 不确定时：**佳沛做主推，都乐做备选**，这样成交率通常更高。
