就公开可核实的信息来看：

1. **都乐（Dole）**：有面向零售/便利渠道的小包装香蕉产品（如单根、2-3根装、小把装），也做品牌化预包装。但是否给便利店做“定制包装”（印客户logo、指定规格/克重/文案）通常属于**渠道定制或OEM合作**，不是标准公开服务。一般需要通过都乐的区域销售/大客户渠道谈，是否接单取决于起订量、区域和产品线。

2. **洪九果品**：主营业务是水果供应链和批发分销，香蕉是其重要品类之一。它更偏**供应链/渠道供货**，可以为商超、便利店、电商等提供分级、分装、贴标等流通加工服务。是否支持“便利店定制小包装”同样要看具体区域分公司和合作规模，公开信息里没有统一标准化的定制包装服务说明。

**判断建议：**
- 如果只是要“小包装香蕉”（1-2根装、3根装、小把装），两家大概率都能通过渠道供货，但不一定是印你便利店logo的定制包装。
- 如果要“定制包装”（印logo、指定设计、指定规格），需要直接联系区域销售，问清：
  - 最小起订量
  - 是否支持贴牌/联名/专版
  - 包装规格和克重
  - 供货区域和冷链条件
  - 价格是否含包装和配送

**更实际的做法：**
- 都乐：找当地经销商或区域大客户经理，问“便利店渠道小包装香蕉能不能做专版”。
- 洪九：找当地分公司或供应链销售，问“能否做便利店小包装分装和贴标”。
- 如果两家都不接小批量定制，可以考虑本地香蕉分装厂/净菜果切供应商做贴牌小包装，成本通常更低、起订量也更灵活。
