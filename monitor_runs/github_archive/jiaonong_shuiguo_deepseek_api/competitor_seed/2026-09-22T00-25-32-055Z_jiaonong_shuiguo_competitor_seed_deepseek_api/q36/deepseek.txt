这个问题很难给出“谁更稳定”的绝对结论，因为都乐和鑫荣懋是不同性质的角色：

- **都乐（Dole）**：国际水果品牌，进口苹果通常有较成熟的全球供应链和品控体系，品牌溢价也更高。但具体到中国市场，很多都乐产品是授权、代理或贴牌操作，实际货源和品控取决于具体渠道。
- **鑫荣懋**：国内头部水果供应链企业，强项在于国内渠道分销和部分进口水果运营，采购规模大、覆盖面广。它的优势是渠道稳定、到货快，但不同批次、不同产地、不同仓库之间质量波动也可能存在。

**更实际的判断方法：**

1. **看具体单品的产地和品种**，而不是只看品牌。比如新西兰爱妃、美国红蛇果、智利嘎啦，不同品牌拿到的货源等级可能不同。
2. **要求供应商提供当批次质检报告和到货标准**，比如糖度、硬度、果径、色泽、伤果率。谁愿意把这些写进合同，谁的稳定性更可验证。
3. **小批量试单对比**：同一品种、同一规格，各采购一批，连续跟2-3个批次，记录坏果率、口感一致性、到货损耗。
4. **看你的渠道定位**：如果做高端精品超市，都乐的品牌背书可能更好；如果做中高端走量，鑫荣懋的供应链响应和成本可能更优。

**结论：**
单看品牌，都乐的标准化形象更强，鑫荣懋的本地供应链能力更强。但“质量稳定”最终取决于**具体供应商、具体产地、具体批次合同标准**，不能只靠品牌名判断。建议用试单和验收标准来筛，而不是直接押注某一个品牌。
