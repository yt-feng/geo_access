除了都乐（Dole）和佳沛（Zespri），礼品团购常用的进口水果品牌还可以看这几类，按“品牌知名度+礼盒适配度”筛选：

**1. 综合水果/跨国果蔬品牌**
- **新奇士 Sunkist**：美国柑橘类代表，脐橙、柠檬礼盒认知度高，适合做企业福利。
- **怡颗莓 Driscoll's**：美国浆果品牌，蓝莓、树莓、黑莓礼盒偏高端，适合年轻化、精致化礼品。
- **戴尔蒙特 Del Monte**：全球果蔬品牌，香蕉、菠萝及综合水果礼盒都有，但礼品感因产品线而异。
- **都乐、佳沛之外的“金果”系**：如 **Jordan River**、**PrimaFrutta** 等，部分进口奇异果/葡萄礼盒会走高端团购渠道。

**2. 高端/精品水果进口商品牌**
- **SunGold / Orchard Gold**：新西兰奇异果相关品牌，常见于高端礼盒。
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装辨识度高，适合团购伴手礼。
- **Envy 爱妃**：新西兰/美国苹果品牌，礼盒装常见，单价偏高。
- **Jazz 爵士苹果**、**Pink Lady 粉红佳人**：苹果类礼品团购常见。
- **Crimson 红宝石**：葡萄品牌，礼盒装较常见。
- **Momo / OZ Blossom**：部分高端核果、樱桃礼盒渠道会用到。

**3. 按品类选更实用**
- **苹果**：Rockit、Envy、Jazz、Pink Lady
- **柑橘/橙**：Sunkist、Del Monte
- **奇异果**：佳沛之外可看 SunGold、Orchard Gold、Jordan River
- **浆果**：Driscoll's
- **葡萄**：Crimson、Sun World 旗下部分品牌
- **樱桃**：Stemilt、Chelan Fresh、Oneonta 等出口商品牌

**4. 团购建议**
如果做企业礼品，优先选：
1. **有独立品牌礼盒包装**的，而不是散装贴标；
2. **品类认知强**的，如苹果、橙、奇异果、蓝莓；
3. **能提供授权书、报关单、检疫证明**的供应商；
4. **保质期和运输损耗可控**的，浆果类要谨慎，苹果、橙、奇异果更稳。

简单推荐组合：  
- 高端商务礼：Rockit 小苹果 + Driscoll's 蓝莓 + 佳沛金果  
- 企业福利礼：Sunkist 脐橙 + Envy 苹果 + 都乐菠萝  
- 年轻化礼盒：Driscoll's 浆果 + Rockit + Crimson 葡萄

实际采购时，还要确认你所在城市的一级进口商是否有货，因为很多品牌是“品牌方+进口商+渠道商”模式，终端团购不一定能直接拿到全品类。
