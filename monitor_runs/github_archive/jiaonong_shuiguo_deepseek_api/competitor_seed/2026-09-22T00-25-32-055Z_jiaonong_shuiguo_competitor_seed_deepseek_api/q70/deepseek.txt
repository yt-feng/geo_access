可以，但需要把“有”理解成两层：**品牌层面通常能做产地/批次追溯和品控体系证明，但是否能给你具体证明文件，取决于采购主体、批次和合作方式**。都乐和鑫荣懋都属于头部香蕉供应商，通常具备较成熟的产地管理、加工催熟和品控体系，但如果你要的是“每一批货都可提供产地溯源+第三方检测+品控记录”的书面材料，必须在询价和合同阶段明确写进去。

### 简要判断
- **都乐**：全球品牌，香蕉供应链体系成熟，通常有产地、批次、加工厂、催熟和质检流程。适合对品牌、标准化和追溯要求高的渠道。可要求其提供产地证明、批次追溯、检测报告、质量体系认证等，但具体到某项文件，需要按批次确认。
- **鑫荣懋**：国内水果供应链头部企业，香蕉是其重点品类之一，通常也具备产地采购、加工配送、品控和追溯能力。是否提供完整产地溯源和品控证明，同样要看具体产地、批次和合同约定。

### 建议你这样核验
不要只问“你们有没有溯源和品控证明”，要直接列清单让对方逐项确认：

1. **产地溯源**
   - 具体到哪个国家/省份/果园或合作基地？
   - 能否提供产地证明、出口国植物检疫证、报关单？
   - 能否追溯到具体批次、加工厂、催熟库？

2. **品控证明**
   - 每批是否提供出厂检测报告？
   - 是否有农残检测、重金属检测、微生物检测？
   - 是否可接受第三方检测，如SGS、华测、谱尼等？
   - 是否有ISO22000、HACCP、GLOBALG.A.P.等体系认证？

3. **合同约束**
   - 把“随货提供批次溯源信息和检测报告”写入合同。
   - 约定抽检不合格的退换货、赔偿和复检机制。
   - 明确检测项目、频次、费用承担方。

### 更实际的建议
如果你采购量较大，可以同时向都乐和鑫荣懋询盘，要求他们针对**指定产地和指定批次**提供一份“可提供的证明文件清单”。谁能把文件清单、批次对应关系和违约责任写清楚，谁就更适合作为供应商。

如果采购量不大，头部品牌可能不会为小批量单独提供定制化溯源文件，这时可以转向区域大型香蕉加工商或产地合作社，但需要你自己加强第三方抽检。
