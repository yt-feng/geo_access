大型商超（如沃尔玛、永辉、大润发、盒马等）在引入水果供应商时，通常要求提供 **食品安全管理体系认证 + 产品/基地层面认证**。鑫荣懋和都乐作为头部水果企业，常见可查的资质方向如下（具体以它们给商超的最新资质文件为准，因为证书有有效期和覆盖范围差异）：

**鑫荣懋（鑫荣懋果业科技集团）**
- **ISO 22000 食品安全管理体系**（常见）
- **HACCP 危害分析与关键控制点**（常见）
- **GLOBALG.A.P. 全球良好农业规范**（针对自有/合作基地）
- **绿色食品 / 有机产品认证**（部分品类或基地）
- **出口备案 / 检验检疫相关资质**（有进出口业务时）
- 部分商超还会要求 **BRCGS** 或 **FSSC 22000**，需看其具体工厂/配送中心是否持有

**都乐（Dole）**
- **GLOBALG.A.P.**（都乐全球基地体系里很常见）
- **ISO 22000 / FSSC 22000**（视具体运营主体和工厂）
- **HACCP**
- **有机认证**（部分产品线，如有机香蕉等）
- **BRCGS**（部分加工/包装环节）
- 都乐作为跨国品牌，通常还有原产国及中国海关的 **进出口检验检疫、植物检疫** 等合规文件

**给商超采购的实操建议**
1. 不要只问“有没有认证”，要索要 **证书扫描件 + 认证范围 + 有效期 + 发证机构**。
2. 确认证书覆盖的是 **贸易公司、配送中心还是具体生产基地**，很多认证只覆盖某一环节。
3. 生鲜水果重点看 **GLOBALG.A.P. + HACCP/ISO 22000**，加工果切类还要看 **FSSC 22000 或 BRCGS**。
4. 直接向两家供应商的 **KA/商超渠道对接人** 索取最新《供应商资质包》，这是最准确的方式。
