关于都乐和洪九果品的具体锁价周期，我无法给出经核实的准确数字，公开渠道也没有稳定、可引用的统一口径。这类锁价条款通常是按客户、采购量、品类（鲜果/冻果/罐头原料）、季节和合同类型单独谈的，不同客户拿到的周期可能差别很大。

可以给你一些可判断的参考：

**都乐（Dole）**
- 作为跨国水果企业，通常对大型商超、连锁餐饮、加工客户会做阶段性报价或短期锁价，常见是按月、按季或按单个产季来谈，而不是公开的固定周期。
- 对中小采购方，锁价周期一般更短，甚至只锁单批或几周。

**洪九果品**
- 国内水果分销为主，锁价更多体现在产地采购和分销合同中，周期往往和水果产季、到货批次绑定。
- 对下游客户，可能是按批次、按月或按产季锁价，具体要看品类和谈判结果。

**建议你直接这样核实**
1. 找都乐、洪九的B2B销售或大客户渠道，直接问：某品类（如菠萝/凤梨）在你们采购量下，最长能锁多久、锁价是否含运费和损耗。
2. 要求书面报价单或框架协议里写明：锁价起止日、锁价数量、超量/不足量怎么处理、是否可调价。
3. 同时对比其他供应商，比如佳农、鑫荣懋，以及产地合作社/大型加工厂，通常锁价灵活度更高。
