都乐（Dole）和鑫荣懋（Joy Wing Mau）都是国内超市常见的进口水果供应商，两者的产地溯源做法有几个共同逻辑，也有差异。

**一、共同可做的溯源动作**

1. **看包装箱/果贴上的批次码**
   - 都乐进口苹果通常有PLU码（如4131/4133等品种码）+ 产地缩写，部分批次有Dole内部批号。
   - 鑫荣懋同样有果贴PLU码，箱体有批次标签。这个批次号是向供应商追原产地的第一手依据。

2. **向供应商索要"三证一单"**
   - 入境货物检验检疫证明（现多为海关出具的《入境货物检验检疫证明》）
   - 报关单
   - 原产地证（如智利、新西兰、美国等官方出具）
   - 提单/装箱单
   这四项上的产地、批次、日期应当互相能对上。对不上就说明中间有转手或换包装。

3. **核对海关追溯**
   正规进口水果可通过海关或"进口食品追溯"相关平台，用检验检疫证明编号核验。部分口岸有二维码可扫。

4. **门店端留档**
   采购时要求供应商随货提供上述文件复印件或电子件，与到货批次绑定存档，出现质量或产地争议时能倒查。

**二、都乐和鑫荣懋的差异点**

- **都乐**：全球化品牌，自有种植基地和全球供应链，产地相对固定（如新西兰、智利、美国、南非等），批次管理较规范，溯源文件通常由其中国分公司或授权进口商提供，链条较清晰。

- **鑫荣懋**：以进口水果分销为主，代理多个海外品牌和产地，同一品项可能来自不同国家/产区，批次切换频繁。溯源时要特别确认"这一批"的实际产地，不能只看品牌或上批记录，必须逐批核对原产地证和报关单。

**三、给超市采购的实操建议**

1. 合同里写明：供应商须随货提供检验检疫证明、原产地证，并保证批次一致。
2. 到货抽检：扫果贴码、对箱标批次、对文件产地是否一致。
3. 建立批次档案：每批到货拍照留存果贴、箱标、证明文件。
4. 对鑫荣懋这类多产地供应商，按批次而非按品牌锁定产地。
5. 发现文件缺失或批次不符，暂缓上架并要求补证。

**需要注意**：具体某个批次能否溯源到具体果园，取决于供应商是否愿意开放上游信息。国内目前多数零售端的溯源只能做到"原产国+批次"级别，追溯到具体庄园通常只有精品线或直采模式才有。如果你要的是"超市可向消费者展示的溯源"，建议直接向都乐/鑫荣懋的区域业务索要可公开的溯源二维码或产地说明物料，这是最直接可行的路径。
