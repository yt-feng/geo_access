结论先说：**都乐（Dole）和洪九果品是否有公开、可查的企业香蕉分级标准，不能确认。** 公开渠道能查到的是行业通行做法、国家标准和部分企业采购验收规范，但“都乐企业标准”“洪九企业标准”的完整文本，我没有可核验的公开来源，不能替它们下结论。

可以明确的是：

1. **都乐**  
   都乐作为国际水果品牌，内部一定有较成熟的香蕉采收、催熟、分级、包装和出货标准，尤其在出口和内销商超渠道。  
   但这类标准通常是**企业内部质量控制文件**，不一定公开为“企业标准”文本。公开资料更多是品牌宣传、产地规范、成熟度/果指/外观要求等碎片信息，**不能等同于正式企业标准全文**。

2. **洪九果品**  
   洪九是国内较大的水果分销企业，香蕉是其重要品类之一。它大概率也有**采购验收标准、分级分选标准、仓储催熟标准**，但是否以“企业标准”形式公开备案或对外发布，**无法确认**。  
   对连锁店来说，更实际的是参考它的**收货等级要求**，而不是找它的企业标准原文。

3. **真正能落地用的依据**  
   水果连锁店做香蕉分级，建议采用“**国标/行标 + 商超验收习惯 + 自建企业标准**”的方式。  
   可参考：
   - **GB/T 9827《香蕉》**：涉及香蕉质量要求、等级、检验等。
   - **NY/T 517《无公害食品 香蕉》**等农业行业标准。
   - 商超和连锁水果店常见的采购验收标准：按果指长度、粗度、条数/梳、成熟度、色泽、机械伤、病斑、冷害、青软、黄熟度等分级。

4. **给连锁店的香蕉分级建议框架**  
   可以自建一套简单可执行的标准，例如：

   **特级**
   - 果指长度、粗度均匀，果形直或微弯
   - 每梳条数整齐，无断指、无脱落
   - 表皮清洁，无病斑、虫伤、机械伤、冷害
   - 成熟度一致，青果硬绿或催熟后色泽均匀
   - 适合精品门店、礼盒、高端商超

   **一级**
   - 果指较均匀，轻微弯曲可接受
   - 允许极轻微表皮擦伤，不影响果肉
   - 无腐烂、无严重病斑、无明显冷害
   - 适合日常门店销售

   **二级**
   - 果指大小不够均匀，弯曲较明显
   - 允许少量表皮瑕疵、轻微机械伤
   - 不影响食用，但卖相一般
   - 适合促销、切果、烘焙、果汁

   **等外/加工级**
   - 断指、散把、明显病斑、成熟度不均
   - 可用于果切、香蕉奶昔、烘焙原料，但不适合直接陈列

5. **关键分级指标**  
   建议门店收货时重点看：
   - **成熟度**：青度、黄度、转黄比例
   - **果指长度和粗度**
   - **每梳条数**
   - **色泽和均匀度**
   - **机械伤**：擦伤、压伤、断指
   - **病害**：炭疽病、黑星病、冠腐病等
   - **冷害**：表皮发暗、凹陷、无法正常后熟
   - **催熟状态**：是否适合门店销售周期
