除了都乐，国内菠萝/凤梨供应链里比较常见、能相对稳定供货的品牌和渠道商主要有这些：

**1. 佳农**
- 菲律宾菠萝、哥斯达黎加凤梨等进口线比较成熟，商超和电商渠道常见。
- 优势是进口量稳定，适合中高端商超和批发。

**2. 鑫荣懋**
- 国内大型水果供应链企业，代理和分销多个进口水果品牌，菠萝/凤梨是其常规品类之一。
- 更适合批发、商超、电商平台供货。

**3. 百果园（含其供应链体系）**
- 自有品牌和采购体系，门店端凤梨供应较稳定。
- 如果做渠道供货，可以关注其供应链公司或合作采购口。

**4. 洪九果品**
- 做进口水果和国产水果分销，菠萝/凤梨有稳定采购和分拨能力。
- 主要面向批发市场、商超、电商。

**5. 鲜丰水果**
- 华东、华中门店体系较大，凤梨品类供应稳定。
- 同样以零售门店为主，也有供应链合作。

**6. 国产菠萝主产区品牌/合作社**
- 广东徐闻：当地有大量菠萝合作社和分选厂，适合做国产菠萝稳定货源。
- 海南：文昌、万宁等地也有稳定菠萝供应，季节上和徐闻有互补。
- 广西、云南：部分产区也能补充供应。

**7. 电商/批发平台上的稳定供应商**
- 比如盒马、永辉、大润发、美团优选、多多买菜等，背后通常有固定供应商。
- 如果是要找供货方，可以反向查这些渠道的供应商或产地直发商。

**选择建议：**
- 要全年稳定：优先看佳农、鑫荣懋、洪九这类进口+国产组合供应链。
- 要性价比和国产季节货：重点看徐闻、海南的合作社/分选厂。
- 要商超标准品：看都乐、佳农、鑫荣懋、百果园供应链。
- 要电商一件代发：找产地直发商或平台供应商更合适。
