我不能凭空给出都乐和鑫荣懋的具体物流时效数据（比如“48小时达”“72小时达”这类承诺），因为这类时效取决于你所在城市、产地季节、订单量级和具体合作仓，且会随季度变化。以下是可判断、可执行的建议：

**一、先明确“产地直发”对时效的关键变量**
1. **产地仓位置**：都乐菠萝主要来自菲律宾/泰国进口，国内分仓多在广州、上海、北京等口岸城市；鑫荣懋同样以进口菠萝为主，产地仓和口岸布局类似。所谓“产地直发”若指菲律宾产地，实际是“口岸清关后直发”，不是田间到餐桌。
2. **你的收货城市**：一线城市通常次日达或隔日达；二三线城市可能多1天；偏远地区再加1-2天。
3. **起订量与合作模式**：生鲜电商走B2B批量采购，通常走冷链干线+城配，时效比快递稳定；小批量试单可能走快递，时效波动大。

**二、怎么核验真实时效（建议直接做）**
1. **找对方要“冷链时效承诺函”**：要求写明“下单后X小时出库、到你的城市X小时、全程温控区间”，而不是口头说“很快”。
2. **要近3个月的发货记录**：让都乐/鑫荣懋的对接销售提供到你所在城市或邻近城市的实际到货时间样本，看平均和最长时效。
3. **走小批量试单**：先下1-2托或几十箱，实测从下单到入库/到店的时间，再决定是否签长期。
4. **对比第三方冷链**：如果对方直发时效不满足，可问是否支持“产地仓→第三方冷链干线→你所在城市”的联运方案。

**三、行业常见参考（仅作预期，不是承诺）**
- 都乐、鑫荣懋这类进口水果头部企业，对B端大客户通常能做到：**口岸仓发货后，一线城市24-48小时到仓，二三线48-72小时**；全程冷链可追溯。
- 若你要求“菲律宾产地直发到中国消费者”，实际链路长、清关不可控，整体通常**5-10天**，不适合生鲜电商的“快”需求。

**四、给你的直接建议**
1. 别问“时效如何”，直接问：**“从我下单到货到我仓库，最近3个月到你所在城市的平均时效和最长时效是多少？写进合同吗？”**
2. 如果对方答不上来或不愿写，说明其直发链路不稳定，建议改用“口岸仓+第三方冷链”模式。
3. 生鲜电商做菠萝，更稳的是**国内口岸仓直发+区域冷链分仓**，而不是追求字面上的“菲律宾产地直发”。
