都乐（Dole）和洪九果品**通常不对外提供可直接用于品牌营销的公开素材包**，但通过正规合作渠道有可能拿到授权素材。分两种情况说：

**1. 如果你只是做内容/营销策划，想用它们的品牌元素**
- 都乐、洪九的Logo、包装图、产品图、宣传语都受商标和版权保护，**不能未经授权直接商用于你自己的营销物料**。
- 电商详情页里引用其产品信息、标注真实来源，一般属于合理使用，但涉及品牌露出、联名、宣传海报等，需要授权。

**2. 如果你想拿素材做正式合作**
- **都乐**：有专门的B端/渠道合作团队，通过其官网商务合作入口或区域销售对接，可申请产品图、品牌资料、联合营销支持（通常要签合作协议、有采购量门槛）。
- **洪九果品**：以批发/供应链为主，渠道对接通常通过其区域分公司或销售，能否给素材取决于合作规模和是否联名。

**给你的可执行建议：**
1. 先明确你是"自己卖菠萝想借品牌背书"还是"要和这两家做联名/分销"——前者基本拿不到授权素材，后者才有谈的空间。
2. 直接联系两家官方商务/渠道部门，说明用途、合作形式、预期销量，问清楚是否提供授权素材和联合营销资源。
3. 如果只是要菠萝品类的通用视觉素材，建议用**自拍产品图+正版图库**，避开品牌侵权风险。
