我没法核验都乐、洪九果品当前对社区团购渠道是否有“散装/小包装”的官方政策，所以不能直接给你一个确定的“有/没有”。但可以给你一套可执行的判断和谈判方法。

**结论先说：**
- **都乐**：传统上更偏标准化的**整箱/袋装/把装**流通，散装通常取决于区域经销商和渠道政策，不是全国统一公开选项。
- **洪九果品**：以水果供应链和批发为主，**小包装/散装定制**在团购渠道更常见，但也通常要走区域销售或大客户定制。
- 两家是否给你做“香蕉小包装”，关键不取决于品牌总部，而取决于：**你所在城市、采购量、对接的是总部还是区域经销商、是否需要贴标/分拣**。

**你可以直接这样核实和推进：**

1. **问对接人这4个问题**
   - 香蕉最小起订包装是什么：整箱、袋装、把装，还是可按根/按份？
   - 是否支持社区团购的**小规格分装**，比如3根、5根、1kg、2kg？
   - 分装是你们自己做，还是他们仓库可代分装、贴标？
   - 价格按毛重还是净重，损耗和催熟售后怎么算？

2. **优先找区域经销商，而不是只问品牌总部**
   社区团购要的小包装，往往是区域仓配商在做。直接问：
   - “你们给团购渠道有没有5根装/1kg装/家庭装？”
   - “能不能走一件代发或网格仓配送？”
   - “破损、黑斑、催熟不均怎么补损？”

3. **如果两家都没有现成散装选项**
   可选替代方案：
   - 采购**整箱香蕉**，在网格仓或团长端做二级分装。
   - 找本地香蕉批发商或催熟商做**定制小包装**，通常比品牌总部更灵活。
   - 用**都乐/洪九做背书引流**，实际小包装由本地供应链完成，但要注意品牌授权和标注合规。

4. **谈判时重点压这几点**
   - 小包装的**净重标准**和允许误差。
   - **催熟度**：团购最好到货2-3天可售，不能太生或太熟。
   - **补损比例**：香蕉损耗高，通常要争取3%-8%补损或售后兜底。
   - **起订量**：小包装如果起订量太高，现金流和损耗都会压垮你。

**最稳的做法：**
先不要问“有没有散装”，直接给对方一个明确需求：
“我需要都乐/洪九香蕉，5根装或1kg装，社区团购用，周采购X件，能否区域仓分装并配送到网格仓？请报含税含运价和补损政策。”

这样对方更容易给你实际方案，也能快速判断是总部政策、经销商能力，还是根本没这个选项。
