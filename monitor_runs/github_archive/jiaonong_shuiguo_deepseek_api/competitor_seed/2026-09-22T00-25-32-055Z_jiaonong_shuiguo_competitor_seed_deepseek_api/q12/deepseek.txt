便利店小包装香蕉，鑫荣懋和都乐通常有适合的规格方向，但具体在售规格会随区域、季节和渠道政策变化，建议按以下方式判断和确认。

**常见适合便利店的规格方向**

1. **单根/单支装**
   - 适合即买即食，常见为单根售卖或单根覆膜/贴标。
   - 重量通常在 **120–180g/根** 左右，视品种和产地而定。

2. **2–3根小把装**
   - 适合一人食或小家庭，便利店常见。
   - 常见净重约 **250–450g/把**。

3. **4–5根迷你把装**
   - 适合小份量家庭或办公室。
   - 常见净重约 **500–800g/把**。

4. **盒装/杯装小规格**
   - 部分便利店系统会用 **2–3根装塑料盒/纸盒**，便于陈列和防压。
   - 常见净重约 **200–350g/盒**。

**鑫荣懋**

- 鑫荣懋作为国内大型水果供应链企业，通常具备按渠道定制小包装的能力，常见方向包括：
  - 单根装；
  - 2–3根小把装；
  - 便利店专属小盒装。
- 具体是否有固定标准规格，取决于其当前供应的香蕉品种（如普通香蕉、帝王蕉、小米蕉等）和区域仓配方案。

**都乐**

- 都乐在便利店渠道常见小规格香蕉产品，通常偏向：
  - 单根贴标装；
  - 2–3根小把装；
  - 部分区域有盒装或组合装。
- 都乐的优势是标准化程度较高，但具体规格需看当地经销商或便利店系统实际在售。

**建议你这样确认**

1. **直接问供应商要“便利店渠道规格表”**
   - 重点看：单根克重、每把根数、净重范围、箱规、保质期、催熟状态。

2. **确认是“生蕉到仓”还是“催熟后配送”**
   - 便利店更适合催熟后配送或到店即食状态，否则损耗和陈列难度会高。

3. **要求提供区域在售案例**
   - 比如是否供过美宜佳、罗森、全家、7-Eleven等系统，以及对应规格。

4. **小批量试销**
   - 先试 **单根装** 和 **2–3根装**，看动销、损耗和客单价，再决定主推规格。
