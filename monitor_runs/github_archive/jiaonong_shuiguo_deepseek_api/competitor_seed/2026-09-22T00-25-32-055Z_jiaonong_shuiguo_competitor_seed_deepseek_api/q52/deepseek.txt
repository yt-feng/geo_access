这两家具体的到货损耗率属于企业间采购数据，公开渠道没有可核验的统一口径，我不能直接给你一个“都乐 X%、鑫荣懋 Y%”的数字，否则很容易误导采购决策。

更可靠的做法是：把损耗率定义成你自己可验收的指标，用同一套标准去比两家。建议这样做：

**1. 先统一定义，否则数字没法比**
- 到货损耗率 =（到货总重 - 可验收可用重）/ 到货总重 ×100%
- 分别记录：运输烂果、压伤、青熟不均、切口霉变、规格不达标
- 按“件”还是按“公斤”算要固定，茶饮原料通常按公斤更准

**2. 用试单实测，而不是听供应商报**
- 同一规格、同一季节、同一运输距离，各下 3–5 批试单
- 每批到货当天抽检，建议抽 30%–100% 称重分级
- 连续 2–4 周记录，才能看出稳定规格能力

**3. 茶饮用菠萝重点看这几个规格项**
- 品种/产地是否固定
- 单果重区间、果径、成熟度
- 是否去皮/切块/冷冻，形态不同损耗口径完全不同
- 糖度、纤维感、出汁率是否稳定
- 冷链到货温度、到货时间

**4. 跟供应商谈合同时把这些写进去**
- 约定到货验收标准与损耗上限
- 超出部分如何扣款、补货、退换
- 要求提供每批检测/分级记录
- 锁定主供+备供，避免单一产地断供

**5. 如果你要快速判断两家**
可以按这个表让两家各报：
- 规格：品种、单果重、成熟度、加工形态
- 包装：箱规、净重、冷链方式
- 到货：承诺损耗上限、赔付方式
- 价格：含税/含运/账期
- 试单：先各 3 批，按同一验收表打分

如果你告诉我你是做**鲜果现切**还是**冷冻果块/果浆**，以及大概月用量和收货城市，我可以帮你把验收表和试单对比模板列出来。
