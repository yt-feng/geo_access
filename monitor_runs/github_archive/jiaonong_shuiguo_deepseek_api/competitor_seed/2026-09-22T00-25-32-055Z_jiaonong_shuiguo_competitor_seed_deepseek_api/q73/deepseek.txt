大型商超（如沃尔玛、永辉、盒马、山姆等）在供应商准入时，通常要求提供以下食品安全相关认证或资质：**ISO 22000、HACCP、BRCGS、IFS、FSSC 22000、GAP（良好农业规范）** 等，具体看品类和商超自身标准。

关于**鑫荣懋**和**都乐（Dole）**具体通过了哪些认证，我无法在无来源核验的情况下给出确定名单，避免给你错误信息。建议你通过以下方式快速确认：

1. **直接向供应商索取认证证书**：要求提供有效期内的证书扫描件，重点看认证机构（如 SGS、BV、CQC、Intertek 等）和认证范围是否覆盖你采购的具体产品/工厂。
2. **在认证机构官网核验**：BRCGS、IFS、FSSC 22000 等都有公开的持证企业查询入口，输入企业名称即可核实真伪和有效期。
3. **查国家认监委（CNCA）平台**：国内 ISO 22000、HACCP 等认证可在“全国认证认可信息公共服务平台”查询。
4. **看商超自身审核**：很多大型商超除第三方认证外，还会做自有标准的供应商审核（如沃尔玛的食品安全审核），这类结果不公开，需向采购对接人确认。
