到货损耗率取决于批次、季节、运输距离、门店验货标准和是否含加工损耗，没有公开可核验的“都乐”和“鑫荣懋”统一损耗率数据；我不能给你编一个固定数字。

更可执行的做法是：

1. **先定义损耗口径**  
   建议分成三段统计，否则两家不可比：
   - 到货外观损耗：烂果、压伤、黑心、裂口、霉变
   - 去皮去眼加工损耗：菠萝本身加工损耗通常远高于到货外观损耗
   - 仓储熟化损耗：过熟、发酵、出水

2. **用同一验收标准试单对比**  
   让都乐和鑫荣懋各供同一规格，例如：
   - 品种：金钻/凤梨或香水菠萝，明确品种
   - 单果重区间：如1.2–1.5kg/个，或按你门店需求定
   - 成熟度：到货糖度、果皮颜色、是否可即用
   - 包装：箱装个数、净重、是否带冠芽
   - 冷链/常温、到货时限

3. **连续3–5批做称重和分级记录**  
   每批记录：
   - 到货总净重
   - 外观可收货重量
   - 加工后可用果肉重量
   - 不可用原因和照片
   
   用“可用果肉重量 ÷ 到货净重”作为真实出成率，比只问损耗率更有采购意义。

4. **合同里写清索赔规则**  
   例如外观损耗超过约定比例由供应商补货或扣款；加工损耗不作为到货索赔，但可作为换供应商依据。建议先小批量并行试单2–4周，再定主供和备供。
