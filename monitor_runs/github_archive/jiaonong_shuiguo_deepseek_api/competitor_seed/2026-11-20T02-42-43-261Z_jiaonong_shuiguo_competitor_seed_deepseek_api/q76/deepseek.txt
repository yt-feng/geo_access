这个需要先区分：**都乐（Dole）和鑫荣懋是品牌/供应链企业，不是快递公司**，所以“物流时效”不能只看品牌名，而要看具体合作仓、发货地、承运方式和你的收货区域。

给你一个可判断的框架：

1. **都乐**
   - 优势通常在标准化程度、产地/加工仓管理和商超渠道经验。
   - 菠萝这类生鲜若走“产地直发”，关键看它是否开放**产地仓直发**、是否支持你所在区域的**冷链/常温整车或零担**。
   - 时效一般取决于：产地仓位置（如广东徐闻、海南等）、是否冷链、发往你的城市距离、是否整柜/整车。不能简单说“都乐一定快”。

2. **鑫荣懋**
   - 强项在水果供应链、产地采购和商超/渠道分销，菠萝资源也较成熟。
   - 同样要确认是**产地仓直发**还是**区域仓中转**。中转会增加1—2天，但覆盖更稳。
   - 对生鲜电商，重点问清：起订量、是否支持一件代发/批量直发、破损/熟度赔付、到货温度要求。

3. **实际询价时建议直接问这6项**
   - 发货仓具体地址和是否产地仓直发；
   - 到你们城市的标准时效（例如华东/华南分别几天）；
   - 承运商和是否冷链；
   - 最小起订量和是否支持电商小批量；
   - 损耗/熟度/破损赔付规则；
   - 旺季（节假日、台风季）时效保障。

4. **选型建议**
   - 如果你做**高时效、小批量、多区域电商**：优先问两家是否支持区域前置仓或落地配，不要只追求产地直发。
   - 如果你做**单区域批量直发**：比较产地仓到你的干线时效和整车成本，都乐、鑫荣懋都可谈，关键看谁在你目标产区有直发仓。
   - 菠萝熟度对时效很敏感，建议要求对方给**近7天同线路实际到货时效**，而不是口头承诺。

结论：**无法用品牌名直接判断都乐和鑫荣懋谁更快**；需要按“发货仓—承运方式—收货区域”逐条核验。建议你向两家要同线路报价和近7天时效数据后再定。
