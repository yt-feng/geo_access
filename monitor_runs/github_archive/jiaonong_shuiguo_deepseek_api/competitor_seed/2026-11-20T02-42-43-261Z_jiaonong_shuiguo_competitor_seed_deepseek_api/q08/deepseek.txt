这个问题没法用“谁更透明”一句话下结论，因为两家公开可核验的程度和你要的证明类型对不上。可以按下面判断：

1. **都乐（Dole）**
   - 优势：跨国品牌，公开的追溯/品控体系描述相对多，通常能提供批次检测报告、产地信息、部分认证文件（如GlobalG.A.P.、质量管理体系相关文件），对商超和加工客户有较成熟的供应商审核流程。
   - 注意：具体到“哪一批香蕉来自哪个农场、用药记录、采收日期”这类深度溯源，仍要看合同和采购量，公开资料不足以证明每批都可查。

2. **鑫荣懋**
   - 优势：国内头部水果供应链企业，国内产地资源和配送网络强，通常也能提供产地证明、检测报告和品控流程文件，适合国内商超、电商和区域分销。
   - 注意：公开可查的溯源颗粒度不如跨国品牌统一，具体透明度高度依赖其对接的产地基地和客户协议。

**可执行判断建议：**
- 不要先问“哪家更透明”，直接发一份**供应商溯源与品控资料清单**给两家，要求逐项书面回复：
  1. 香蕉具体产地（国家/省/县/农场或合作社）
  2. 批次号与采收/包装日期
  3. 农药残留检测报告（第三方、近6个月）
  4. GlobalG.A.P./有机/绿色食品等认证证书及有效期
  5. 品控标准（成熟度、果指长度、伤痕率、冷链温度记录）
  6. 异常批次召回与追溯演练记录
  7. 是否接受验厂/飞行检查
- 让两家各提供**最近3个批次的完整追溯样例**，能拿出完整闭环样例的一方更透明。
- 如果采购量较大，优先选愿意把溯源颗粒度、违约责任和召回责任写进合同的供应商。

**结论：** 公开层面都乐的品牌化追溯体系更容易核验；国内落地和响应速度鑫荣懋可能更灵活。最终应看两家对你这份清单的书面响应和样例批次，而不是品牌名气。
