旺季缺货时，建议按“先保供、再分流、后锁定”三步处理：

1. **立即保供（1–2周）**
   - 先盘现有库存和在途订单，按SKU/渠道分级，优先保核心客户和高毛利渠道。
   - 启动替代产地/替代品种：菲律宾缺货时看泰国、越南、哥斯达黎加等，但要注意品种口感、规格和关税/检疫要求差异。
   - 与现有供应商谈短期调拨、加急船期、空运补少量高价值订单；空运只适合应急，成本高。
   - 调整销售策略：预售、限购、组合装、替代品种推荐，避免硬缺货导致客户流失。

2. **分流与替代**
   - 餐饮/加工渠道可转用冷冻菠萝、罐头或浓缩汁，鲜果零售渠道则用其他产地鲜果替代。
   - 对价格敏感渠道做规格调整（如小果、散装），对高端渠道保品牌果。
   - 提前跟客户沟通到货节奏，避免临时违约。

3. **锁定中期供应**
   - 与供应商签短期框架协议，锁定未来4–8周的量价。
   - 分散采购，不把单一大单品压在一个产地或一个供应商上。
   - 建立安全库存和到货预警，旺季前提前备货。

关于都乐和洪九果品的基地直供优势：

- **都乐**：全球化采购和品牌化运营强，在菲律宾、泰国等菠萝主产区有长期合作和自有/合作基地资源，适合需要稳定品牌果、标准化程度高的渠道。它的优势在“全球产地调配+品牌溢价”，但具体直供比例和国内基地布局需以官方披露为准。
- **洪九果品**：核心优势是国内分销网络和产地直采模式，在泰国、越南等东南亚水果上有较强直采和供应链能力，菠萝品类也有布局。它的优势在“直采+分销效率”，适合走量、控成本的渠道。但菠萝是否为其最强单品、基地直供的具体规模，需看其公开财报和官方信息。

**判断建议**：要品牌稳定和全球调配，优先看都乐；要直采走量和国内分销效率，优先看洪九。但两家具体菠萝基地直供能力，建议直接向供应商索要产地证明、直采合同、到货周期和旺季保供方案，不要只凭品牌印象判断。缺货应急时，也可以同时接触两家做短期比价和保供测试。
