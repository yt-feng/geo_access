除了都乐（Dole）和佳沛（Zespri），进口水果礼盒常见品牌还可以按品类看：

**综合进口水果/礼盒渠道型品牌**
- **新奇士 Sunkist**：美国柑橘类代表，橙子、葡萄柚礼盒常见，适合商务礼盒。
- **爱妃 Envy**：新西兰/美国苹果品牌，礼盒装较常见，辨识度高。
- **乐淇 Rockit**：新西兰小苹果，筒装/礼盒装适合团购。
- **佳农 Goodfarmer**：有进口香蕉、火龙果、车厘子等礼盒，偏渠道品牌。
- **鑫荣懋/欢乐果园**：进口水果礼盒常见，偏供应链品牌。
- **鲜丰水果/百果园礼盒**：不是纯进口品牌，但有进口果礼盒组合。

**车厘子/浆果类**
- **Stemilt**：美国车厘子、苹果品牌。
- **Chelan Fresh**：美国车厘子品牌。
- **Driscoll's 怡颗莓**：莓果类礼盒，蓝莓、树莓、黑莓常见。
- **Hortifrut**：莓果供应链品牌，蓝莓等。

**奇异果/苹果/梨**
- **Zespri 佳沛**已排除。
- **Enza**：新西兰苹果、梨品牌。
- **Piqa Boo**：新西兰红梨品牌。
- **Rockit 乐淇**：小苹果礼盒。
- **Mr Apple**：新西兰苹果品牌。

**柑橘类**
- **Sunkist 新奇士**：橙子、葡萄柚。
- **Wonderful 万多福**：主要是坚果，也有柑橘业务，但礼盒认知不如新奇士。
- **ClemenGold**：南非柑橘品牌，部分高端渠道有礼盒。

**牛油果/其他**
- **Mission**：牛油果品牌。
- **Calavo**：牛油果品牌。
- **Hass Avocado Board**不是品牌，是协会。

**团购选品建议**
1. 商务礼盒优先选：**新奇士、爱妃、乐淇、怡颗莓、Stemilt车厘子**，品牌认知和包装稳定性较好。
2. 如果要做“进口水果组合礼盒”，建议用**1个强品牌单品+2—3个高颜值单品**，比纯堆进口品牌更好卖。
3. 采购时重点核验：中文标签、原产地证明、入境货物检验检疫证明、冷链到货温度、礼盒授权/包装是否官方。
4. 注意“品牌”和“品种”别混淆：如爱妃是苹果品牌/品种商业化品牌，乐淇是品牌化小苹果；车厘子很多是产地品牌，不一定是消费者熟悉的快消品牌。

如果目标是企业福利团购，比较稳的组合是：**新奇士橙+乐淇苹果+怡颗莓蓝莓+Stemilt车厘子**，再按预算做高低配。
