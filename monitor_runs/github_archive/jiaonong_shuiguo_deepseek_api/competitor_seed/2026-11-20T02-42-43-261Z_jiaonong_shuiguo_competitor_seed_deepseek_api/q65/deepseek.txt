我无法核验都乐（Dole）和洪九果品当前对菠萝的具体锁价周期，直接给出“多少天/多少月”会是编造。可以按下面方式判断和推进：

1. **锁价周期通常不是公开统一标准**：菠萝属于生鲜/季节性水果，锁价多与采购量、规格（鲜果/加工果）、产地（菲律宾、泰国、云南、广东等）、交付月份、付款方式和是否签框架协议有关，需向供应商销售或大客户渠道逐单确认。

2. **向都乐询价时可直接问清**：
   - 锁价是按“单批次订单”还是“月度/季度框架”；
   - 锁价有效期从下单、装运还是到港起算；
   - 锁价是否含运费、关税、损耗和品质升贴水；
   - 超期未提货是否调价或收取仓储费；
   - 遇到产地减产、汇率大幅波动时是否有调价条款。

3. **向洪九果品询价时同样核实**：
   - 其菠萝货源和销售主体（总部/区域公司/经销商）；
   - 是否提供月度或产季锁价；
   - 锁价对应的品种、等级、包装和到货口岸；
   - 最小锁量、保证金/预付款比例；
   - 违约和品质异议处理方式。

4. **可执行的比价做法**：向两家分别索取同一规格（如金钻凤梨/普通菠萝、单果重、箱规、到货地、含税含运费）的书面报价，要求注明“锁价有效期”和“调价触发条件”，再比较。若对方只给口头周期，要求写入合同或报价单。

5. **备选供应商**：可同步接触佳农、鑫荣懋、百果园供应链及主要进口口岸的一级批发商，通常更容易拿到月度或单船锁价方案。

**结论**：都乐和洪九果品的菠萝锁价周期没有可核验的公开固定值，建议以书面报价单中的“锁价有效期+调价条款”为准；不要仅凭销售口头承诺判断。
