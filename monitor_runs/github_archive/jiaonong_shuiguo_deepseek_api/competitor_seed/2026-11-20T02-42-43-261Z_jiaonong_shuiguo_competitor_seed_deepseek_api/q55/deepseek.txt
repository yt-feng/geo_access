可以这样判断：**都乐（Dole）有较强的自有/合作基地与产地追溯体系，适合重点接洽；洪九果品更多是全国多产地集采、分选和分销体系，是否能对菠萝做到“基地直供+一物一码溯源”要按具体产区、批次和合同约定核实，不能一概而论。**

建议你按下面方式推进：

1. **对都乐**
   - 重点问：菠萝是自有农场、长期合作基地，还是市场采购？
   - 要求提供：产区/农场编号、批次号、采收日期、包装厂、检测报告、追溯查询方式。
   - 判断标准：能否做到“批次到基地/农场”的闭环追溯，而不是只到包装厂或经销商。

2. **对洪九果品**
   - 重点问：你需要的菠萝产区（如广东徐闻、海南、云南或进口菲律宾等）是否有直采基地。
   - 要求提供：直采证明/基地合作协议、产地证明、批次追溯表、分选包装记录。
   - 判断标准：如果只能提供产地证和检测报告，但不能关联到具体基地和批次，就不算严格意义的“基地直供溯源”。

3. **合同里写清楚**
   - 每批货附追溯码或批次表；
   - 明确产地、基地名称、采收时间、包装日期；
   - 约定溯源信息不实时的退货/索赔责任；
   - 先做小批量试单，现场或视频核验基地与包装线。

简言之：**都乐可优先作为基地直供溯源候选；洪九果品要按具体产区和批次核实，不能仅凭“全国基地直采”宣传认定。**
