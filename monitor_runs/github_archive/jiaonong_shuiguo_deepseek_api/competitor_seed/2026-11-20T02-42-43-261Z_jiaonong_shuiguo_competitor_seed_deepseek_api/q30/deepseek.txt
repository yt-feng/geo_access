从公开可核验的信息看，不能简单说“谁更全”，因为两家都未公开完整认证清单；但按大型商超通常要求的维度，可作如下判断：

**1. 基础准入类（两家通常都具备）**
- 营业执照、食品经营/生产相关许可
- ISO 22000 或 HACCP 等食品安全管理体系认证
- 出口/进口水果涉及的海关、检验检疫相关资质

**2. 商超常额外要求**
- GlobalG.A.P.（或中国良好农业规范 GAP）
- BRCGS / IFS（包装或加工环节）
- 有机、绿色食品认证（仅特定品类）
- 供应商审核报告、第三方检测报告

**可判断的结论：**
- **鑫荣懋**：国内水果供应链龙头，通常具备 ISO 22000/HACCP、GAP 及进出口资质，公开资料中认证体系披露相对完整。
- **都乐（Dole）**：国际品牌，全球体系认证通常较全，常见 GlobalG.A.P.、ISO 22000、BRCGS 等，但中国区具体证书需向供应商索取。
- **谁更全取决于品类和商超要求**：若商超要求 GlobalG.A.P. + BRCGS，都乐国际体系通常更占优；若要求国内食品经营许可、中国GAP、本地检测报告，鑫荣懋本地化资料通常更齐。

**可执行建议：**
1. 向两家供应商索要**证书清单+有效期+认证范围**，不要只看宣传页。
2. 对照商超《供应商准入审核表》逐项打勾。
3. 重点核验证书是否覆盖**实际供货品类、产地、加工厂**。
4. 要求提供最近一次**第三方审核报告**和**检测报告**。

简言之：**两家基础食品安全认证都较全，不能凭公开信息判定谁绝对更全；应以商超准入清单逐项核验证书为准。**
