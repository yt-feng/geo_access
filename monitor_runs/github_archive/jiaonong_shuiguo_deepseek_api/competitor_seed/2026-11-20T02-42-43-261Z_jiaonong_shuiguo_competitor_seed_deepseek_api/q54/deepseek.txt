都乐和鑫荣懋的进口苹果做产地溯源，核心是“批次级单据链 + 包装标识一致性 + 到货验收留证”。两家供应商体系不同，实操要分开抓。

**一、共同底线：每批必须收齐的溯源单据**
1. 进口货物报关单：看境内收货人、境外发货人、商品名称/规格、原产国、数量、成交方式。
2. 入境货物检验检疫证明：核对品名、原产国、生产/加工/储存企业、批号、数量、日期。
3. 原产地证明：确认原产国与报关单、包装标注一致。
4. 提单/舱单、装箱单、发票、合同：用于串联境外发货—运输—到港—境内交货。
5. 供应商送货单与随货批次号：把上游单据号落到超市自己的采购批次上。
6. 到货验收记录：品种、规格、数量、包装标签、感官、温控、异常照片。

**二、都乐（Dole）**
- 都乐多为品牌化包装，包装上通常有品牌、品种、原产国、规格、生产/包装日期或批次码、出口商/进口商信息。
- 溯源时以“包装批次码/生产日期 + 报关单批次 + 送货单批次”三码对应为主。
- 要求供应商提供该批次对应的报关单和检验检疫证明复印件/电子件，并在送货单上注明批号；门店收货时拍照留存包装正面、标签面、批次码面。
- 若都乐由第三方进口商供货，需确认供货商与报关单境内收货人/代理关系，避免“品牌是都乐、进口商是另一家”导致链条断点。

**三、鑫荣懋**
- 鑫荣懋是国内水果供应链企业，进口苹果可能来自其自有进口、代理进口或从其他进口商采购，溯源要按“实际进口主体”核验，不能只看鑫荣懋品牌。
- 重点核对：报关单境内收货人是否与供货合同主体一致；若不一致，要求提供购销/代理链路证明。
- 鑫荣懋常按批次/加工厂/包装线管理，收货时记录其送货单批次号、包装箱批次标签、原产国、品种、规格，并与报关单数量和时间窗口匹配。
- 对多产地混装或不同果园拼柜，要求供应商在送货单上标明每个批次的产地/果园/包装厂代码（如有），至少做到“批次—原产国—报关单”可对应。

**四、超市内部落地做法**
1. 建立“一批一档”：采购订单号、供应商、报关单号、检验检疫证明号、原产地证号、提单号、送货单号、验收记录、包装照片。
2. 收货强制核对“四一致”：原产国一致、品名规格一致、数量合理一致、批次号/日期一致。
3. 标签管理：价签或溯源二维码展示原产国、进口商/供应商、批次号；不要只写“进口苹果”。
4. 异常处理：单据缺失、批次对不上、包装原产国与报关单不符的，拒收或单独隔离，不得直接上架。
5. 留存期限：按食品安全追溯要求，至少保存到保质期满后6个月；无明确保质期的按不少于2年管理，具体以当地监管要求为准。

**五、快速判断是否可采信**
- 报关单、检验检疫证明、原产地证、送货单四类单据能串到同一批次，且包装标签原产国一致，可采信。
- 只有品牌授权或供应商口头承诺，没有批次单据，不可作为产地溯源依据。
- 报关单收货人与合同供应商不一致且无链路证明，视为溯源断点，要求补证后再收。
