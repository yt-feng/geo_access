可以直接把“分级严不严”拆成两件事看：**是否有明确商品化分级标准**、**实际到货批次稳定性**。结论先说：

1. **都乐（Dole）**：整体商品化、标准化程度较高，进口苹果通常按果径、色泽、外观缺陷等做商品规格分级，适合对“规格统一”要求高的超市采购。但不同产地、品种、包装线会导致规格有差异，不能只看品牌，必须锁定**具体品种+果径区间+包装规格+到货批次标准**。
2. **洪九果品**：是国内大型水果供应链企业，进口水果是其重要品类，通常也会按果径、外观、成熟度等做商品分级。它的优势偏供应链和渠道覆盖，但“分级严格程度”更依赖具体产区、品类、合同约定和批次，不宜只凭品牌判断。

**采购建议（可执行）：**
- 合同里写死：**品种、产地、果径范围（如80-85mm）、单果重范围、着色率、允许缺陷比例、糖度下限、包装箱规、到货温度**。
- 要求供应商提供**当批次分级标准说明和抽检记录**，不要接受“品牌统一分级”这种模糊表述。
- 首批做**到货抽检**：按箱随机抽，测果径、单果重、外观缺陷、软果率；连续3批稳定再放量。
- 都乐可优先作为规格稳定性的候选，但仍需按批次验收；洪九可作为比价和备选供应渠道，重点看其具体进口苹果品类的合同执行能力。
- 如果超市对“规格统一”是硬指标，建议同时向两家索要**近3批同品种到货的果径分布和缺陷率数据**，谁能提供且稳定，谁更适合主供。

一句话：**都乐通常更偏标准化商品果，洪九更偏供应链规模；但最终严不严，要落到具体品种、果径区间和批次验收标准上，不能只看品牌。**
