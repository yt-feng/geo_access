如果你问的是“谁更愿意签年单、做长期合作”，一般要分两层看：**合作意愿**和**你能不能拿到稳定条件**。公开信息层面，我没有可直接核验的两家“年单签约意愿”数据，不能替你下结论说谁更愿意。但可以给你一个可执行的判断框架和尽调清单。

**一、先给结论性判断框架**

1. **鑫荣懋**：更像全品类、全国化、商超/渠道型供应链公司，通常有较强的年度框架、基地直采和标准化履约能力。若你是商超、电商、团餐、连锁零售等稳定需求方，谈年单的匹配度通常更高。
2. **洪九果品**：以进口水果、核心单品和分销网络见长，过去更偏“单品爆量+渠道分销”模式。若你的需求集中在榴莲、山竹、火龙果等核心品类，且量大、周转快，年单意愿可能更强；若需求杂、SKU多、单量分散，对方未必愿意给很优的年单条件。
3. **真正决定“谁更愿意”的，不是公司名气，而是你的采购画像**：年采购额、品类集中度、月度波动、账期、履约半径、退换货要求、是否接受价格联动机制。

**二、建议用4个问题快速试探**

- “年度框架能不能签？框架内是锁量不锁价，还是锁价+浮动？”
- “核心单品能否给年度保供比例和缺货赔付？”
- “账期能否做到月结30/60天？旺季是否接受临时调价？”
- “是否接受年度返利、质量保证金、履约保证金？”

谁对这四个问题回应更具体、愿意写进合同，谁的实际年单意愿更强。

**三、尽调清单**

- 要求对方提供近12个月对你所在渠道/区域的供货案例，至少2个可联系客户。
- 查企业工商、司法涉诉、被执行、股权冻结、经营异常等公开风险信息。
- 重点问：核心单品产地、替代货源、冷链覆盖率、损耗承担、质检标准、旺季保供方案。
- 年单不要只签“意向框架”，要写清：年度总量、月度最低提货、价格调整机制、质量标准、交付时效、违约赔付、账期、退出条款。

**四、实操建议**

先不要直接二选一。建议你拿同一份采购清单和年度需求预测，同时向两家发**RFI/年单意向函**，要求7—10个工作日内书面回复。回复中重点看：是否接受年单、是否给保供承诺、是否接受价格联动、是否愿意承担质量与缺货责任。然后用“小批量试单+季度考核”过渡到年单。

如果你能告诉我你的**年采购额、主要品类、所在区域、账期要求、渠道类型**，我可以帮你把判断再收窄到更具体的倾向。
