目前没有可核验的公开信息能证明都乐或鑫荣懋谁在“香蕉锁价”上更灵活，我不能凭印象给你下结论。但可以给你一套可执行的判断和谈判方法：

1. **先明确锁价标的**：锁的是产地采购价、到岸成本、还是给你们的批发价；是否含关税、运费、损耗、催熟费。不同口径下“灵活”含义完全不同。
2. **向两家同时发同一份询价单**，要求逐项回复：
   - 锁价周期（周/月/季）
   - 锁价比例（全部/部分）
   - 保证金或预付款比例
   - 触发调价的阈值与条件（汇率、海运费、产地天气）
   - 违约与差额结算方式
   - 最小起订量和履约区域
3. **重点看三项灵活性**：锁价期限能否按月滚动、能否部分锁量、能否设置价格区间而非单一固定价。能接受“部分锁量+区间价”的通常更灵活。
4. **用小单试单**：先做1—2柜或一个月的锁价试单，观察对方在行情波动时是否按约执行、调价沟通是否及时。
5. **要求书面条款**：把“锁价期间不因市场上涨单方调价”“超阈值如何分摊”写进合同，口头承诺不算。

如果你们能提供采购规模、港口/区域、锁价周期和结算方式，我可以帮你把询价单和评分表列得更具体。
