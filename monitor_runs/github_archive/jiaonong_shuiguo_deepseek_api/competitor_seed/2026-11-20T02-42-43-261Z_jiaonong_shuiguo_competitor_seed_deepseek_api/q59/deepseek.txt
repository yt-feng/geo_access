都乐（Dole）和洪九果品这类企业的具体账期属于商务谈判条款，公开渠道通常不会披露，且会随客户规模、采购量、合作年限、结算方式（月结/票到付款/预付比例）不同而变化，无法给出确定天数。

可判断的信息：

- **都乐（Dole）**：大型外资果蔬品牌，对商超、餐饮、批发客户一般走合同账期，常见框架是先款后货或短账期（如月结30天左右）起步，大客户可谈更长，但没有公开统一标准。
- **洪九果品**：以水果分销为主，客户结构包括商超、电商、批发等，账期同样按客户分级谈，通常新客户偏向现款或短账期，稳定大客户才可能给到月结。

3. 新供应商首次合作可先争取“部分预付+月结”过渡，避免只口头承诺账期。
