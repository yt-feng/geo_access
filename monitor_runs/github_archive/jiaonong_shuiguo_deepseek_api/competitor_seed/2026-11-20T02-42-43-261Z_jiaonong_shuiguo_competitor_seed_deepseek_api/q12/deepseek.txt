### 可执行判断
便利店小包装香蕉通常看这几类规格：
1. **单根/两根装**：适合即食、早餐、搭配酸奶；常见以“根”计价或贴标销售。
2. **3—5根小把装**：适合家庭临时购买，货架占用小。
3. **迷你香蕉/小米蕉小盒装**：更适合便利店冷柜旁或收银台冲动购买。
4. **按重量分装**：如300g、500g左右的小袋/小盒，适合标准化陈列。

### 对鑫荣懋和都乐的建议问法
不要只问“有没有小包装”，直接向区域销售要：
- 便利店渠道**现有小规格SKU清单**：单根装、2根装、3—5根把装、迷你蕉盒装；
- **最小起订量、供货频次、冷链/常温条件**；
- **单根克重范围**和**每箱根数/袋数**；
- 是否支持**贴标、定重、定根数分装**；
- 区域仓是否常备，断货替代规格是什么。

### 判断标准
优先选：
- 单根约**100—130g**、2—3根一包，适合即食；
- 到店成熟度可控，最好有**催熟/色卡分级**；
- 包装能立住、透气，避免挤压黑斑；
- 供货稳定，能按门店销量拆分配送。
