可以，但要注意“能提供”不等于“每批次随货都能给”。按可执行判断：

1. **都乐（Dole）**：通常有较完善的质量管理体系，供应商/大客户渠道一般可提供农残检测报告或符合性声明，但具体到菠萝原料，要看你是从都乐直采、经销商还是批发市场拿货。直采和正式供应商合作更容易拿到**批次检测报告**；零售/批发渠道通常只能给通用报告或合格证明。

2. **鑫荣懋**：作为大型水果供应链企业，通常也能提供农残检测报告，尤其是对商超、餐饮、茶饮等B端客户。实际能否随批提供，取决于合同约定、采购量和具体发货仓。

采购时建议直接这样确认，避免扯皮：

- 问清楚：**“能否提供该批次菠萝的农残检测报告？报告是第三方检测机构出具的吗？检测项目是否覆盖GB 2763常见农残项？”**
- 要求：**报告上的品名、批次/生产日期、供应商名称与到货批次对应**，不能只给一份过期通用报告。
- 合同写明：**每批随货提供检测报告或合格证明；如抽检不合格，退换货及检测费用由供方承担。**
- 首次合作先要**样品批次报告**，到货后再核对报告与实物批次是否一致。

结论：**都乐和鑫荣懋一般都能提供，但茶饮店应把“批次对应、第三方报告、随货提供”写进采购要求**，不要只接受口头承诺或通用报告。
