可以做，但要把“全年稳定供应”拆成两件事看：**鲜果全年供应能力**和**适合做果酱的稳定品质/成本**。都乐和洪九果品都属于国内大型水果供应链企业，具备跨产区、跨季节组织菠萝货源的能力，但仅凭公开信息无法确认它们能对茶饮店做“全年同规格、同价格、稳定批量”的承诺，需要你按采购条件逐项核验。

**判断要点：**

1. **都乐**
   - 品牌化、标准化程度较高，商超和餐饮供应链经验较强，适合对品质稳定、规格统一要求高的客户。
   - 菠萝供应通常依赖多产区切换和进口补充，全年“有货”一般能做到，但具体到某个品种、甜度、成熟度、切块/果酱用规格，需要问清产季切换方案。
   - 价格通常偏高，适合中高端茶饮或对品牌背书有需求的店。

2. **洪九果品**
   - 以水果分销和产地直采见长，菠萝是其重要品类之一，跨区域调货能力强，批量供应和成本方面可能更有优势。
   - 但洪九的产品更多面向批发分销，餐饮客户的小批量、高频次、定制化服务能力要具体核实；果酱用菠萝对成熟度、纤维、酸度要求与鲜食不同，需要确认能否稳定分级。

**建议你直接向供应商核验这5项：**
- 能否承诺**全年12个月供货**，并给出各月主供产区/品种；
- 果酱用菠萝的**固定规格标准**：品种、单果重、成熟度、糖酸比、是否允许冻果/罐头替代；
- **月度最低起订量、锁价周期、调价机制**；
- **跨产区切换时的品质波动控制**和不合格赔付条款；
- 是否支持**代加工成果酱/果泥**，还是只供鲜果。

**更稳妥的采购策略：**
不要只押一家。茶饮店做果酱，建议“**鲜果+冷冻果/果泥**”组合：旺季用鲜果降低成本，淡季用速冻菠萝或菠萝果泥保稳定；同时让都乐、洪九及本地一级批发商分别报价，按“全年综合成本+品质稳定性”比选，而不是只看单月价格。若门店规模不大，直接找菠萝果酱/果泥加工厂做定制可能比鲜果自加工更稳定。
