**鑫荣懋（鑫荣懋果业科技集团股份有限公司等）**
常见/可能持有的资质方向：
- **ISO 22000 食品安全管理体系**（果蔬供应链相关范围）
- **HACCP 危害分析与关键控制点体系**
- **ISO 9001 质量管理体系**
- **GLOBALG.A.P.（全球良好农业规范）**：通常由其合作的种植基地/供应商持有，需看具体基地证书

- **食品经营许可证/食品生产许可证**（按实际经营主体和业态）

**都乐（Dole，在华主体如都乐（上海）水果蔬菜贸易有限公司等）**
常见/可能持有的资质方向：
- **ISO 22000 / HACCP / ISO 9001**（按其中国运营主体及配送/加工场地）
- **GLOBALG.A.P.**：都乐自有或合作农场常见，需按具体产地/产品核验
- **BRCGS**（如涉及加工、包装场地）
- **食品经营许可证**（贸易/流通主体）
- 进口水果相关：**海关进出口收发货人备案、入境货物检验检疫证明**（按批次）
- 有机认证等（按具体产品/产地）

**给商超采购的可执行核验建议**
1. 要求供应商提供**证书扫描件+发证机构官网查询截图**，核对证书编号、有效期、认证范围是否覆盖“供货产品/场地”。
2. 区分**企业总部证书**与**具体加工厂/配送中心/种植基地证书**，商超审核通常要看实际供货场地。
3. 进口水果额外核验**入境货物检验检疫证明**和批次追溯；国产水果核验**产地证明/检测报告**。
4. 把**GLOBALG.A.P.、有机、绿色食品**按单品/基地核验，不要按企业品牌笼统认可。
5. 在合同中约定**证书到期前更新义务**和**飞行检查/抽检**条款。
