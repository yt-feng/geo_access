进口菠萝旺季缺货时，先判断缺货属于哪一类，再决定是“补货”还是“换品”：

**1. 先做可执行判断**
- **短期断货（1–2周）**：优先做替代规格和替代品种，不要死等单一产地。常见替代顺序：同品种不同规格（如大果换中果/小果）→ 邻近产地（菲律宾/泰国/哥斯达黎加等按实际可采情况）→ 国产菠萝（徐闻、海南等）做短期过渡。
- **中期缺货（3–6周）**：锁定在途和期货，和供应商签“保量不保价”或“保价不保量”的框架，明确到港时间、违约条款。
- **长期缺货**：调整菜单/货架结构，把菠萝从“主推单品”降为“搭配单品”，用菠萝罐头、冷冻菠萝块、菠萝汁做B端替代，减少鲜果依赖。

**2. 对都乐、洪九果品应急方案的判断**
我无法核验两家企业当前的具体应急方案和内部政策，不能虚构其承诺。可执行的做法是：
- **对都乐**：直接问区域销售要“在途船期表+可分配量+替代规格清单”，要求书面确认到货窗口；都乐通常有全球采购和多产地布局，但具体到旺季缺货时能否调货，取决于你所在区域和合同等级。
- **对洪九果品**：重点问“国产替代+进口补位”的组合方案，要求给出可替代品种、起订量、到货周期和价格保护期；洪九的渠道优势在国产果和分销网络，进口菠萝的应急调货能力需以对方书面回复为准。
- **通用谈判点**：要求供应商提供“缺货预警机制”（提前多少天通知）、“替代品优先分配权”、“逾期违约金或补偿货补”。

**3. 门店/渠道端立刻能做的**
- 把菠萝陈列从“整果主推”改为“切块/果切+果汁”组合，降低整果缺货的感知。
- 设置替代品推荐牌，引导顾客接受国产菠萝或同价位热带水果。
- 对B端客户提前发缺货告知和替代方案，避免临时断供违约。

**结论**：不要等供应商给“应急方案”，要主动要三样东西：**在途船期、可分配量、书面替代清单**。都乐和洪九具体方案无法替你核验，但按上述问法去要，能快速判断他们有没有真实调货能力。
