**都乐（Dole）菠萝**
- 都乐是跨国果蔬企业，菠萝供应以“全球产地+中国销售”为主，不是单一国内基地。
- 国内采购常见来源包括广东、海南、广西、云南等热带/亚热带产区；进口端常见菲律宾、泰国、哥斯达黎加等。
- 你要稳定供应，建议不去追“都乐基地在哪”，而是让都乐中国区销售提供：**中国境内合作农场/包装厂清单、进口口岸、可签年度框架协议的SKU和规格**。都乐更多是品牌商+供应链组织者，不一定所有货源都来自自有基地。

**洪九果品**
- 洪九果品是国内水果供应链企业，核心模式是“基地采购+产地加工+全国分销”，在东南亚水果和国内产区都有布局。
- 公开信息中，洪九在泰国、越南等东南亚产区有榴莲、火龙果等品类布局；菠萝方面需向其对接口径确认是**国内基地直采**还是**进口+国内产区组合**。
- 采购时重点问：菠萝主供产区、是否有自有/合作包装厂、月度可供量、规格分级、到岸/到仓价、账期和品质赔付条款。

**给你的实操建议**
1. 不要只锁定“都乐/洪九基地”，茶饮菠萝需求通常是**全年稳定+规格统一+出成率稳定**，应要求供应商提供近12个月供货产区切换表。
