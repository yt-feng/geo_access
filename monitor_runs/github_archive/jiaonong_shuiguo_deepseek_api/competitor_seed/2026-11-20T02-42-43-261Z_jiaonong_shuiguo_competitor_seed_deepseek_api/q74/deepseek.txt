都乐和洪九果品都没有公开、统一的礼盒定制起订量标准，需按**品类、包装形式、是否贴牌/定制箱、发货仓和结算方式**逐单确认。以下是可执行判断：

1. **都乐**
   - 常规水果礼盒通常是按整箱/整托起订，团购定制常见门槛在**几十箱到数百箱**区间，具体随单品和季节波动很大。
   - 若要做企业LOGO、专属箱型、卡片/腰封等定制，一般会高于现货礼盒起订量，且可能另收版费或包装费。
   - 建议直接找都乐官方团购/企业客户渠道或授权经销商询价，要求书面给出：起订量、箱规、可定制项、打样周期、冷链到货范围。

2. **洪九果品**
   - 洪九以批发和渠道分销为主，礼盒定制起订量同样取决于单品和区域仓，常见也是**整箱起订、批量定制**，没有对外统一数字。
   - 企业定制通常需要通过其区域销售或经销商确认，部分单品可小批量试单，但专属包装往往有更高门槛。
   - 建议同时问：是否支持混拼礼盒、是否可贴企业标、最小生产批量、交货仓和账期。

**可判断建议：**
- 不要按“品牌统一起订量”做预算，先锁定3—5个水果单品，分别向都乐和洪九的**企业团购/区域经销**询“现货礼盒”和“定制礼盒”两套报价。
- 询价时明确：团购数量、预算单价、是否需要LOGO、交货城市、交货时间、是否要一件代发。
- 若单次量低于100盒，优先找品牌授权经销商做现货+贴标；若高于300—500盒，再谈专属箱型和直供。
- 要求对方把起订量写进报价单，避免口头“可以少量做”但后续加收版费。

我无法核验两家当前具体起订量数字，建议以官方渠道或授权经销商书面报价为准。
