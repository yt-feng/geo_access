结论先说：**没有可靠公开信息能证明“都乐（Dole）”和“洪九果品”有对外公开、可查的香蕉分级企业标准文本。** 能确认的是：都乐有成熟的内部商品化分级/规格体系，洪九果品作为水果供应链企业也有自己的收货与品控分级做法，但这些通常是**企业内部标准或客户合同标准，不对外公开**，不能当作“公开企业标准”引用。

对水果连锁店，建议不要等这两家的企业标准，直接做一套可执行的**门店/采购共用香蕉分级标准**，可按下面落地：

### 一、先定用途
香蕉分级必须分场景，否则标准会打架：
1. **采购收货级**：看产地、条蕉/梳蕉、青度、伤损。
2. **仓储催熟级**：看青果硬度、催熟阶段。
3. **门店陈列销售级**：看成熟度、外观、货架期。
4. **加工/折价级**：碰伤、过熟、断把、单根。

### 二、建议分级维度
用“**品种+规格+成熟度+外观+损伤+农残/合规**”六维，不要只看大小。

**1. 品种**
- 主销：香芽蕉/巴西蕉等。
- 高端：皇帝蕉、小米蕉等单独设标准，不混级。

**2. 规格**
按每梳/每把重量或每根长度粗度分：
- 大果：单根长度、粗度、单把重量设上限下限。
- 中果：门店主销规格。
- 小果：促销/儿童装/散称。

**3. 成熟度（最关键）**
用色卡或催熟阶段，建议设：
- 1级：全青硬果，适合长途/催熟库。
- 2级：青带微黄，适合配送。
- 3级：黄绿相间，适合门店次日主推。
- 4级：大部分黄、果尖微绿，适合当日主推。
- 5级：全黄带糖斑，适合即时促销。
- 6级：过熟/软果，只能折价或加工。

门店收货建议只收**2—3级**；陈列主推**3—4级**；5级进折扣区；6级不进正常货架。

**4. 外观**
- 果形端正、弯曲正常。
- 无严重机械伤、无裂果、无黑腐、无霉点。
- 梳蕉整齐，断把率设上限。
- 允许少量自然果斑，但设面积/数量上限。

**5. 损伤与缺陷**
建议设“允许轻微缺陷比例”和“拒收项”：
- 拒收：霉变、腐烂、异味、严重压伤、果柄黑腐、农残超标、冷链失温。
- 可折价：轻微擦伤、少量断根、果指不齐、轻微日灼。

**6. 合规**
- 农残检测/承诺达标合格证。
- 产地证明、进货查验记录。
- 冷链温度记录。

### 三、给门店用的简版分级表
可以做成三档：

| 等级 | 用途 | 成熟度 | 外观 | 处理 |
|---|---|---|---|---|
| A级 | 主推/礼盒 | 3—4级 | 果形整齐、无明显伤、断把少 | 正常陈列 |
| B级 | 散称/促销 | 4—5级 | 轻微果斑/轻微擦伤 | 折扣区或当日促销 |
| C级 | 加工/折价 | 5—6级 | 明显碰伤、过软、断把多 | 折价、加工、限时清货 |

再配一张**拒收清单**，收货员按清单执行即可。

### 四、关于都乐和洪九的正确用法
- 可以把都乐、洪九的**到货实物**作为对标样品，反推自己的收货标准。
- 可以在采购合同里要求供应商按你的分级标准供货，而不是引用对方企业标准。
- 若确实需要“企业标准”文本，只能向对方业务/品控部门索取**合同附件或供货规格书**，并在合同中约定验收依据；公开渠道不要虚构标准号。

### 五、建议下一步
1. 先拍一套门店在售香蕉的成熟度色卡照片，做1—6级。
2. 定A/B/C三档和拒收清单。
3. 连续7天记录到货等级、损耗、售价，再调阈值。
4. 把标准写进采购合同附件，作为收货和扣款依据。
