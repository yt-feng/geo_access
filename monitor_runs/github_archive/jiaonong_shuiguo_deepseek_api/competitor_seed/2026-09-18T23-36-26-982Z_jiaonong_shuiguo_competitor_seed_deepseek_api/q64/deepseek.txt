结论先说：**公开资料里通常查不到鑫荣懋和都乐“商超冷链配送覆盖城市”的完整、实时清单**。这类信息属于企业物流能力明细，往往只在招标文件、客户合同、官网服务网络或销售口中给出，且会随仓库、经销商和季节变化。  
所以更稳妥的判断方式是：**不要只看“覆盖多少城市”，要看它能否覆盖你门店所在城市、是否全程冷链、到店频次和温控证据**。

### 1. 一般能确认的情况
- **鑫荣懋**：国内大型水果供应链企业，服务过商超、电商、批发等渠道，通常具备多区域仓配和冷链能力。覆盖范围一般是**全国主要一二线城市和部分重点地级市**，但具体到某个城市是否直配，需要按其当地仓网确认。
- **都乐**：国际水果品牌，在国内有较大分销体系，商超配送往往通过**自身配送体系+区域经销商/第三方冷链**完成。覆盖通常也是**全国主要城市和重点商超系统**，但未必每个城市都“厂家直配”。

### 2. 对商超供应商审核更实用的核验清单
让这两家或任何供应商提供以下材料，比问“覆盖哪些城市”更有效：

1. **拟配送城市清单**：明确到“XX市XX区/门店”，不要只写“华东、华南”。
2. **冷链仓位置**：距你门店多少公里，是否自有或外包。
3. **运输温控**：冷藏车/保温箱类型，是否有GPS和温度记录。
4. **到店频次**：每周几配，能否拆零，最小起订量。
5. **温控记录**：提供近3个月同类商超客户的温度曲线样例。
6. **应急方案**：车辆故障、节假日、极端天气如何补配。
7. **资质文件**：道路运输许可、冷链验证报告、保险、食品安全相关资质。
8. **试配安排**：先选1—2家门店试配1个月，考核到货温度、准时率、损耗率。

### 3. 如果你要快速判断
可以这样问供应商：
> “请提供贵司对我司XX城市XX门店的冷链直配能力证明：最近仓地址、车型、温控记录、每周配送频次、是否可拆零、应急补货时限。”

如果对方只能给全国品牌介绍，给不出**具体城市+仓+温控记录**，就不能视为满足大型商超的冷链物流要求。

### 4. 建议
- 若你门店在**一线/新一线/省会城市**：鑫荣懋、都乐大概率有覆盖或可通过区域经销商覆盖，但仍需逐店确认。
- 若在**普通地级市、县级市**：要重点确认是否直配，很多情况是经销商配送，冷链完整性要单独审计。
- 最终以**供应商盖章的配送范围承诺+试配结果**为准，不要仅凭口头或宣传资料。
