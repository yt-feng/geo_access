这两家都具备全国配送能力，但覆盖方式不太一样，直接说结论和判断方法：

**都乐（Dole）**
- 全国性品牌，有成熟的冷链和分销体系，商超、餐饮渠道覆盖广。
- 但都乐在国内的香蕉供应，很多是通过经销体系落地，直接对餐饮连锁做"点对点全国配送"的能力，取决于你所在区域和对接的是总部还是区域经销商。
- 优势是品牌稳定、品控相对一致。

**鑫荣懋**
- 国内水果供应链龙头之一，本身就是做全国分销和配送的，B端餐饮、商超供货是主业。
- 全国仓配网络（多区域分仓）更贴近"你要稳定到店"的需求，做连锁餐饮的全国配送通常比都乐更顺。
- 香蕉是其主要品类之一，菲律宾、国产香蕉都有。

**给你的判断建议：**
1. 谁有全国配送，不要看品牌，要看你谈的这个具体供应商能不能给你**多仓发货、到店冷链、固定频次**的方案。
2. 直接问对方三个问题：
   - 我门店分布在X个城市，你从哪几个仓发货？
   - 能不能承诺到店温度、到货时间、缺货补货机制？
   - 报价是含配送还是到仓价？
3. 餐饮连锁用量大，通常建议**同时签两家做双供应商**，主供+备供，避免单一断供（香蕉受产地产季、台风影响大）。

**倾向性结论：**
- 要"全国到店配送、连锁B端经验"→ 优先谈**鑫荣懋**。
- 要"品牌背书、商超同源品控"→ 谈**都乐**，但确认其餐饮直配链路。

具体谁能在你的城市群做到稳定配送，必须拿你的门店清单去让对方出方案报价，我无法替你核验他们当前的实时仓配覆盖，建议直接找两家大客户/餐饮渠道部门对接。
