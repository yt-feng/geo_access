都乐和洪九果品对“水果礼盒定制”的起订量并没有一个全国统一、公开固定的标准，通常会按以下因素变化：礼盒类型、单品/混装、包装是否定制、提货方式、配送区域、是否走企业团购/员工福利通道。所以不能直接给一个确定数字，最稳妥是走官方渠道确认。

可执行的判断和建议如下：

1. **都乐**
   - 都乐在国内更多是品牌水果供应和部分礼盒产品，企业团购一般通过区域经销商、电商企业购渠道或都乐官方合作渠道对接。
   - 常见情况：标准礼盒起订量可能较低，但“定制包装/定制组合”通常要更高，很多区域会要求 **几十箱到上百箱** 起。
   - 如果只是贴企业logo或贺卡，起订量可能低于完全定制外箱。

2. **洪九果品**
   - 洪九更偏水果供应链和批发流通，企业团购/礼盒定制通常按区域、品类和采购规模谈。
   - 常见情况：定制礼盒往往要求 **上百盒起**，部分区域或特殊水果可能更高；如果是标准礼盒现货，起订量可能低一些。
   - 洪九不同区域分公司政策可能不一致，需要找对应区域销售确认。

3. **建议你直接这样问对方**
   - 我们要做企业水果礼盒定制，预计采购 ___ 盒，是否需要定制外箱/logo/贺卡？
   - 这个数量你们接不接？起订量是多少？
   - 含不含运费、能否分地址发货、能否开票？
   - 礼盒内容能不能自选？换品要不要加价？
   - 最晚下单时间和到货周期是多少？

4. **更实际的采购建议**
   - 如果采购量在 **50～100盒**：优先问区域经销商和本地水果供应链，不一定能拿到都乐/洪九直接定制。
   - 如果采购量在 **100～300盒**：可以同时问都乐、洪九区域销售，以及本地精品水果商。
   - 如果采购量在 **300盒以上**：再重点谈品牌方或大经销商定制，价格和起订政策会更好谈。

5. **注意**
   - 我没有都乐和洪九当前官方公开的固定起订量数据，不能给你编一个确定数字。
   - 最可靠方式是：找都乐企业购/区域经销商、洪九当地分公司销售，直接报你的采购量和定制需求，让对方给书面报价和起订量。
