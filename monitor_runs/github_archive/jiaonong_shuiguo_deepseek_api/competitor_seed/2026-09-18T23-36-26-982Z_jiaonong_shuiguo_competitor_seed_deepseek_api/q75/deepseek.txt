直接说结论：**公开渠道几乎查不到洪九果品和都乐香蕉在同一批发市场的“到货损耗率”可核验对比数据**。损耗率受季节、产地、运输距离、冷链、到货成熟度、批发市场装卸条件影响极大，同一品牌不同批次能差几个百分点。任何给你一个精确百分比的说法，基本都不可靠。

下面是可判断的经验性对比和操作建议：

## 品牌定位差异
- **都乐（Dole）**：国际品牌，主打标准化、催熟和冷链管理，通常到货成熟度控制更稳定，香蕉品相一致性较好。
- **洪九果品**：国内头部水果供应链企业，规模大、渠道广，香蕉是其重要品类之一，但产品线杂，批次间稳定性取决于具体产地、季节和承运方式。

## 损耗率的实际差异
- 如果都是**同一季节、同一产地、同等冷链条件**到货，都乐因标准化程度高，损耗通常**略低或持平**，差距一般在**1~3个百分点**量级，而不是几倍差距。
- 如果是**国产蕉 vs 进口蕉**、**夏秋高温季 vs 冬春**、**长途 vs 短途**，这些因素对损耗的影响**远大于品牌差异**。
- 关键变量：到货时的**成熟度（几成熟）**、**是否冷链断链**、**装卸是否磕碰**、**市场内是否及时开箱散热**。

## 给你的可执行建议
1. **别信品牌标签，做批次测试**：同一市场、同一周，各进1~2箱，记录到货重量、坏果重量，算实际损耗。
2. **看合同条款**：损耗责任怎么划分，是否包损耗、是否可退换，比品牌本身更影响你的实际成本。
3. **问同市场档口**：问3~5个做香蕉的档口老板，他们对同一批货的实际损耗最清楚，比任何公开数据准。
4. **要产地和到货成熟度**：同样是都乐，菲律宾蕉和厄瓜多尔蕉、3成熟和5成熟到货，损耗完全不同。
5. **算综合成本**：损耗率 × 单价 + 运费 + 退换成本，才是真实拿货成本。
