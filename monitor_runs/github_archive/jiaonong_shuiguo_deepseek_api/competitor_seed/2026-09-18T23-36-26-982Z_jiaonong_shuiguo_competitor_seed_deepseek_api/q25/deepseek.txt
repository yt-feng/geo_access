这个没有公开、可核验的信息能直接判断“谁更愿意签年单”，两家都是大型水果供应链企业，是否接受年单取决于品类、采购量、结算条件、履约周期和你的渠道稳定性，不能简单按公司名比较。

可以按下面几个可执行维度去谈和判断：

1. **看品类匹配**
   - 鑫荣懋偏进口水果、商超渠道、品牌化供应较强。
   - 洪九果品偏东南亚水果、批发分销、全国网络较强。
   - 你要的品项如果正好是对方核心优势品类，签年单的意愿通常更高。

2. **看你的采购确定性**
   供应商愿不愿意签年单，关键不是“你是谁”，而是：
   - 年度采购量是否明确
   - 是否能按月/按周给滚动预测
   - 是否接受最低采购量
   - 是否接受价格联动机制
   - 账期是否可接受
   这些条件越清楚，越容易谈到年单。

3. **看价格和风险分担**
   水果价格波动大，长期年单一般不会签死一个固定价，更常见的是：
   - 框架协议 + 定期议价
   - 保底量 + 浮动价
   - 锁量不锁价
   - 按规格、等级、产季分阶段定价
   如果你要求全年一口价，两家都大概率会谨慎。

4. **看结算方式**
   能接受预付、短账期、保证金或稳定回款，供应商签年单意愿会明显提高。反之，长账期、低首付、高退货要求，会让年单很难落地。

5. **最有效的判断方式**
   不要先猜谁更愿意，直接同时向两家发起同一份询价和年单框架需求，让对方报价和反馈：
   - 是否接受年度框架协议
   - 是否接受保底采购量
   - 价格调整机制
   - 账期和履约保证金
   - 违约和品质赔付条款
   谁的回复更积极、条款更接近你的需求，谁就是更愿意合作的一方。

**结论：**
没有可靠公开依据能判断鑫荣懋和洪九果品谁更愿意签年单。更实际的做法是：拿你的具体品类、年采购量、结算条件和交付要求，同时找两家谈年度框架协议，用对方的条款反馈来判断意愿。通常，采购量稳定、账期好、品类匹配的一方，更容易谈成年单。
