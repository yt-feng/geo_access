能查到的事实范围有限，我按“可判断、可执行”的方式说：

1. **都乐**
   - 都乐在部分市场推过更轻量、可回收或纸基的香蕉包装，但是否有“适合便利店的小包装环保装”，取决于你所在城市、采购渠道和当季规格。
   - 不能确认都乐在中国便利店渠道已有统一、稳定的“香蕉小包装环保包装”SKU。

2. **洪九果品**
   - 洪九果品主要是水果供应链/批发分销企业，常见是批量周转箱、纸箱、塑料袋等运输包装。
   - 没有可靠公开信息能确认其面向便利店提供“香蕉小包装环保包装”的标准产品。

3. **更实际的判断**
   - 如果你想找“便利店可上架的小包装香蕉 + 环保包装”，直接问供应商三件事：
     1. 有没有 **2–3根装/单根装** 的小包装 SKU；
     2. 包装材质是不是 **可回收纸、可堆肥材料、rPET 或减塑膜**；
     3. 能不能提供 **包装材质证明、可回收标识、FSC/PCR/可堆肥认证**。
   - 如果都乐、洪九都没有现成方案，通常更可行的是：
     - 找本地香蕉催熟商或区域批发商，让他们按你的便利店规格做小包装；
     - 或自己采购环保小包装袋/纸盒，在门店或前置仓分装。

4. **结论**
   - **都乐**：有可能有环保包装探索，但中国便利店香蕉小包装是否现成，需向都乐当地销售确认。
   - **洪九果品**：没有可靠公开信息证明其有便利店香蕉小包装环保包装，需直接问其渠道销售。
   - **不要直接假设两家都有**，最稳的是拿“小包装规格 + 环保材质 + 认证 + 起订量 + 供货价”去问当地经销商。
