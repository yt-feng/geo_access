大型商超（如沃尔玛、永辉、盒马、大润发等）在供应商准入时，通常会要求提供 **GFSI（全球食品安全倡议）认可的食品安全认证**，常见的就是 **FSSC 22000、BRCGS、IFS、SQF** 这几类，以及 ISO 22000、HACCP 等。

关于 **鑫荣懋** 和 **都乐（Dole）** 具体通过了哪些认证，我无法在当前对话中核验其最新、完整的认证清单，因此不能给出确定性的逐项名单，避免给你错误信息。

可以确认的通用情况是：

- **都乐（Dole）** 作为跨国果蔬企业，其部分运营主体和加工/包装场所通常持有 **GFSI 认可的认证**（如 BRCGS、FSSC 22000 等），但具体到某个工厂、某个国家或某一年度，认证情况会不同。
- **鑫荣懋** 作为国内大型水果供应链企业，其部分仓储、加工、配送主体通常也会按商超要求取得 **ISO 22000、HACCP 或 FSSC 22000** 等认证，但同样需要按具体主体和场所核实。

**建议你这样做，才能拿到可判断的结果：**

1. **直接向对方索取认证证书扫描件**，重点看：
   - 认证标准（如 FSSC 22000、BRCGS）
   - 认证覆盖场所（具体工厂/仓库地址）
   - 证书有效期
   - 发证机构（是否 GFSI 认可）
2. **在 GFSI 官网或认证机构官网核验证书编号**，确认不是过期或超范围证书。
3. **按商超准入要求比对**：如果商超明确要求 GFSI 认可认证，仅有 ISO 22000 或 HACCP 可能不够，需要看商超的具体标准。
4. **注意主体区分**：集团公司有认证，不等于每个子公司、每个仓库、每个加工点都覆盖，商超审核通常看实际供货主体和场所。
