### 一、先明确：进口苹果"供货稳定性"看什么
不是看品牌大小，而是看这几个硬指标：
1. **产区与季节覆盖**：是否能全年连续供应（南半球+北半球拼货），还是只做某几个月。
2. **自有/合作果园与锁量能力**：能否提前锁量、锁价，还是临时市场调货。
3. **冷链与到港节奏**：船期是否稳定、清关是否顺畅、到港后分拨速度。
4. **你所在区域的仓储/配送**：有没有本地仓或区域分仓，缺货补货响应多快。
5. **规格与等级稳定性**：同一SKU的果径、糖度、色差是否批次间波动大。

### 二、要求两家提供这些"可验证材料"
让业务员给书面/系统数据，而不是口头承诺：
- 近12个月**分月供货记录**：到货批次、数量、准时率、缺货次数。
- 主推品种的**产区切换表**（如新西兰→智利→美国等），标明空档期。
- **合同履约条款**：最低保供量、断货赔付、临期/质量问题的处理。
- 你所在城市的**仓储位置与配送时效**。
- 可参观的**已合作水果连锁客户案例**（同区域最佳）。

### 四、更稳的做法：不要二选一
