进口香蕉这块，佳沛确实基本可以排除——它的主营业务是奇异果，香蕉不是强项。

如果你要做进口香蕉，建议按“品牌/产地”两条线来看：

**1. 都乐**
- 全球果蔬巨头，香蕉是其核心单品之一，供应链稳定，国内渠道认知度高。
- 适合走商超、水果连锁、电商标准品。
- 优点是品控和货源相对稳，缺点是价格通常不是最低，利润空间要看你的渠道。

**2. 金吉达**
- 老牌香蕉巨头，历史上在香蕉领域非常强，全球香蕉供应链有基础。
- 国内部分渠道仍有货，但要看具体进口商和区域供货情况。
- 如果做中高端或稳定供货，可以重点问。

**3. 地扪**
- 也是国际果蔬品牌，香蕉有业务，但国内香蕉存在感不如都乐、金吉达。
- 可以作为补充品牌去问，不一定作为主力。

**4. 菲律宾产地品牌/进口商品牌**
- 国内很多进口香蕉其实是“产地+进口商”在卖，不一定是终端消费品牌。
- 菲律宾、厄瓜多尔、越南等产地都有货。
- 如果品牌溢价不重要，重点看进口商：货源稳定性、催熟能力、损耗率、到货周期。

**5. 佳农**
- 国产香蕉龙头之一，也做进口香蕉和果蔬供应链。
- 如果你要的是“稳定供货+国内渠道服务”，佳农值得问，不一定算纯进口品牌，但实操上很多渠道会把它作为香蕉主力供应商。

**实操建议：**
- 先明确你要的是**品牌溢价**还是**稳定走量**。
- 走量：优先问都乐、金吉达、佳农的进口/供应链线。
- 做中高端：都乐、金吉达更合适。
- 做性价比：直接找菲律宾、越南、厄瓜多尔产地的进口商，不一定追品牌。
- 关键指标别只看品牌：**催熟配套、到货损耗、单箱成本、供货周期**比牌子更重要。
