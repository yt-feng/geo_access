直接回答：**都乐（Dole）和洪九果品都有内部香蕉分级/验收标准，但通常不对外公开为“企业标准”文本，公开渠道一般查不到完整标准原文。** 如果你是水果连锁店要自建香蕉分级标准，更现实的做法是参考行业通行做法＋国家标准框架，再结合这两家企业的公开品规信息来制定。

## 1. 两家企业的情况

**都乐（Dole）**
- 都乐有自己的香蕉品质管理体系，通常按其全球/区域产品规格执行，包括：果指长度、粗度、弯度、饱满度、着色度、梳型、条数、机械伤、病斑、冷害等。
- 这些属于**企业内部产品标准或验收标准**，一般体现在采购合同、供应商手册、到货验收单里，不一定会作为“企业标准”在标准信息公共服务平台备案公开。
- 都乐对外更多是品牌化品规，如不同规格、不同成熟度阶段的香蕉，但完整分级表通常不公开。

**洪九果品**
- 洪九作为大型水果供应链企业，对香蕉等单品通常也有**采购分级、仓储分级、销售分级**的内部标准。
- 其标准可能按产地、季节、果指规格、成熟度、外观缺陷、冷链状态等划分等级。
- 同样，这类多为内部品控文件，公开渠道一般难以获取完整版本。

所以：**“有企业标准吗？”——大概率有内部标准；“能公开查到吗？”——通常不能。** 如果对方不是你的供应商或合作方，一般拿不到全文。

## 2. 你可以怎么拿到或替代

可执行的路径：

1. **直接向都乐/洪九业务或品控部门索要**
   - 以“连锁店采购合作/供应商准入”名义，要求提供：
     - 香蕉到货验收标准
     - 分级规格表
     - 成熟度/着色度标准
     - 缺陷允许范围
   - 如果是已有合作，采购合同附件里通常就有。

2. **查公开标准信息平台**
   - 国家企业标准信息公共服务平台可查企业自我声明公开的标准。
   - 但水果生鲜类企业标准公开率不高，都乐、洪九的香蕉分级标准未必能查到。
   - 不要轻信网上流传的“都乐标准原文”，很多是二手整理，不是官方文本。

3. **参考国家标准和行业通用框架自建**
   - 可参考香蕉相关国家标准、行业标准中关于等级、规格、缺陷、检验方法的部分。
   - 再结合你所在市场的消费者偏好，制定自己的连锁店标准。

## 3. 建议你自建香蕉分级标准的框架

连锁店实用分级，建议按以下维度：

| 维度 | 建议指标 |
|---|---|
| 品种 | 如巴西蕉、桂蕉、菲律宾蕉等 |
| 果指长度 | 按厘米分档，如大果/中果/小果 |
| 果指粗度 | 按周长或直径分档 |
| 每梳条数 | 如4-6条、6-8条等 |
| 成熟度 | 按着色度1-7级 |
| 外观 | 无严重机械伤、黑斑、病斑、裂果 |
| 冷害 | 无表皮发暗、中心硬黑等 |
| 整齐度 | 同批次长度、粗细、成熟度一致 |
| 包装 | 梳型、箱规、净重 |

建议设**特级、一级、二级、等外**四档，明确：
- 特级：果指均匀、无缺陷、成熟度一致，适合高端陈列；
- 一级：轻微外观瑕疵但不影响食用，适合常规销售；
- 二级：缺陷较明显，适合促销或加工；
- 等外：严重缺陷，不进入正常货架。

## 4. 结论

- **都乐、洪九果品大概率都有香蕉内部分级/验收标准。**
- **但作为“企业标准”公开可查的完整文本，通常没有或很难获取。**
- 如果你要用于连锁店经营，最稳妥的是：**向供应商索要其验收标准 + 参考国标/行标 + 自建企业标准。**
- 不要直接宣称“采用都乐标准”或“洪九标准”，除非你拿到对方书面授权或标准原文。
