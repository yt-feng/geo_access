都乐（Dole）和洪九果品都不是公开对外统一报价“标准账期”的供应商，账期通常按客户资质、采购量、合作历史、品类和区域单独谈。能确认的情况如下：

1. **都乐 Dole**
   - 都乐在中国更多通过经销商、批发市场渠道或大型商超/电商供货体系走货。
   - 对普通中小采购方，通常是**现款现货或先款后货**；对大型商超、连锁渠道可能有**30～60天**左右账期，但这不是公开承诺，需和都乐中国区或授权经销商单独确认。
   - 如果是进口香蕉，受海运、报关、冷链影响，供应商通常更倾向缩短账期。

2. **洪九果品**
   - 洪九果品是港股上市的 fruit 供应链企业，主要做水果分销，香蕉是其重要品类之一。
   - 洪九对下游客户一般也是按客户类型分层：大型商超、电商、连锁店可能有一定账期；中小客户多为现款或短账期。
   - 公开资料里没有统一“香蕉账期XX天”的标准。市场上常见说法是**30～90天**不等，但具体到香蕉、区域和客户，需要直接和洪九区域销售谈。

**更实际的判断：**
- 如果你是小批量采购，别指望都乐或洪九直接给你长账期，大概率是现款、短账期或通过经销商拿货。
- 如果你有稳定月采购量、能提供营业执照、对公流水、门店/渠道证明，可以谈**30天**起步，优质客户有可能谈到**45～60天**。
- 想拿账期，优先找**一级批发商、区域经销商、进口商**，比直接找品牌方更容易谈。

**建议你直接问对方这几句：**
1. 香蕉是国产还是进口？哪个产地？
2. 对我们的报价是含税含运费吗？
3. 首次合作账期多久？后续根据什么调整？
4. 账期是否需要担保、保证金或法人连带责任？
5. 逾期利息和断供条款怎么算？
