两家都是国内进口水果头部**供应链/品牌运营方**，价格谁更有竞争力，不能直接一句“谁更低”下结论，要分场景看。给你一个可执行的判断框架：

**1. 先明确你比的是哪类“价格”**
- **品牌方直供价**：都乐（Dole）偏品牌化运营，部分单品有品牌溢价，适合做礼盒、精品门店、线上品牌专区。
- **渠道批发价**：鑫荣懋（Joy Wing Mau）渠道覆盖广、批发流通能力强，在部分进口苹果单品上更容易拿到有竞争力的流通价。
- **实际到手价**：还要算上配送、账期、损耗、返利、促销支持，不能只看报价单。

**2. 进口苹果要分开看产地和品种**
- 新西兰爱妃、红玫瑰、爵士等：都乐和鑫荣懋都有操作，具体看当季船期和库存。
- 美国、智利、南非等产地苹果：鑫荣懋在部分批发渠道的流通效率可能更占优。
- 都乐的优势通常在**品牌认知、包装标准化、终端动销支持**，不是单纯最低价。

**3. 更建议你这样比价**
让两家按同一规格报价，至少包含：
- 品种、产地、果径/等级、包装规格
- 起订量、含税/不含税
- 到仓价还是门店配送价
- 账期、返利、损耗赔付
- 当季促销和陈列支持

然后按**“单箱综合成本 = 采购价 + 物流 + 损耗 + 资金占用 - 返利”**来比，而不是只看单价。

**4. 结论性建议**
- 如果你做**精品店、礼盒、品牌专区**：都乐可能更合适，价格未必最低，但品牌和标准化更强。
- 如果你做**大众门店、走量、批发流通**：鑫荣懋在部分进口苹果单品上通常更有价格竞争力。
- 最稳的做法：**同一单品、同一规格、同一交付条件，让两家同时报价**，再按综合成本定。通常不建议只签一家，可以主供+辅供，用竞争压价并保证旺季不断货。
