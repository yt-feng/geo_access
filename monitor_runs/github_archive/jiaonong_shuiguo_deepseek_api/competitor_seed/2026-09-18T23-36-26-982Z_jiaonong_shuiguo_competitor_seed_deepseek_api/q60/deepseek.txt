进口菠萝（主要是菲律宾、泰国、哥斯达黎加等产地的MD-2金菠萝、小菠萝）到货损耗高，核心矛盾是**冷链断链 + 成熟度控制 + 到货后催熟/分选节奏**。都乐、鑫荣懋这类头部玩家的做法，本质是把"损耗"从到货环节前移到产地和运输环节去解决。下面拆开讲。

## 一、产地端：从源头锁定成熟度

菠萝是呼吸跃变型水果，采后仍在成熟，所以**采收成熟度直接决定到货损耗**。

- **按糖度/成熟度分级采收**：都乐通常要求产地按可溶性固形物（糖度）和果眼饱满度分批采收，而不是一次性全园采摘。过早采→到货后酸、催不熟；过晚采→运输途中就烂。
- **采后快速预冷**：采收后要在产地短时间内（通常几小时内）做强制风冷或水冷，把果心温度快速降到适宜区间，抑制呼吸热。这一步做不好，集装箱里就是"闷熟+腐烂"。
- **杀菌处理**：采后做防腐/杀菌处理（如针对黑腐病、果腐病的处理），并对果柄切口做处理，因为切口是主要侵染入口。

## 二、冷链运输：全程温控是损耗的分水岭

菠萝海运通常走冷藏集装箱，温度控制是核心。

- **恒温而非"到港才降温"**：全程维持菠萝适宜储运温度（一般在7–10℃区间，具体看品种和成熟度），温度波动比低温本身更致命——反复回温会让果实出水、加速腐烂。
- **气调/通风管理**：部分高值批次会用气调（调节O₂/CO₂）延缓成熟，同时保证通风排走乙烯，避免自催熟。
- **运输时长控制**：航程越长、损耗风险越高，所以头部企业会优先选稳定船期、减少中转，缩短在途时间。

## 三、到港后：分选 + 催熟节奏管理

这是国内进口商损耗最容易失控的环节。

- **到港即检、即分选**：到港后快速做品质检验，按成熟度、硬度、有无病斑分级。**把不同成熟度的货分开处理**，而不是混在一起等统一催熟。
- **催熟分批、按需催熟**：菠萝到货后往往需要催熟到可售状态。都乐、鑫荣懋的做法是按销售节奏分批催熟，卖多少催多少，避免一次性催熟导致集中过熟、卖不完就烂。
- **催熟环境控制**：温度、湿度、乙烯浓度精确控制，催熟后及时降温"锁熟"，防止过熟。
- **缩短库内停留**：到货→分选→催熟→发货的链条越短越好，减少中间仓储时间。

## 四、渠道端：以销定采 + 快速周转

- **订单农业/以销定采**：根据销售预测反向安排产地发货，减少到货后压库。
- **分级销售**：一级果走商超/精品渠道，次级果及时走加工或低价渠道，不让次级货拖累整体损耗。
- **数据复盘**：每批次的产地、船期、温度记录、损耗率做归因，找出是采收问题、运输问题还是到货催熟问题，逐批优化。

## 五、给你可落地的判断/动作

如果你是进口商或经销商，想对标头部做法，优先抓这三件事：

1. **把温度记录要过来**：让货代/船公司提供全程冷链温度曲线，看有没有断链、回温。这是损耗归因的第一步。
2. **到货后先分级再催熟**：不要整柜统一催熟，按成熟度分批次，能显著降损耗。
3. **压缩到货到发货的停留时间**：损耗大头往往在"到货后等销售"这段时间，以销定采、快进快出最有效。

一句话总结：都乐、鑫荣懋控损耗的逻辑不是"到货后补救"，而是**产地控成熟度 → 全程控温不断链 → 到货分批催熟快周转**，把损耗消灭在链条前端。
