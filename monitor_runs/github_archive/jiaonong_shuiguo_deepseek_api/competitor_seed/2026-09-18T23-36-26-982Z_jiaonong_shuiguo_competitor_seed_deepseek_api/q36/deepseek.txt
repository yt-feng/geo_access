这个问题没有统一答案，因为“质量更稳定”取决于具体品类、产地、季节和批次，而不是品牌本身。不过可以给你一套可判断的框架：

**1. 两个品牌的定位差异**
- **都乐**：全球性水果品牌，供应链标准化程度高，进口苹果（如新西兰、美国、智利等产地）通常有较统一的分级、包装和品控流程，走量大的商超渠道多。
- **鑫荣懋**：国内头部水果供应链企业，代理和运作多个进口水果品牌（包括佳沛等），自身也做进口苹果，强项在渠道分销和国内落地，不同产季/产地的品控波动可能比都乐更依赖具体供应商。

**2. 稳定性不能只看品牌，要看这几项**
- **产地和品种是否固定**：同一产地、同一品种连续供货，稳定性通常更好。
- **到货批次的新旧**：冷库果和当季新果差异很大。
- **分级标准**：是否明确标注规格（如70#、80#、85#）、糖度、硬度要求。
- **供应商是否可追溯**：能否提供果园/包装厂信息。

**3. 实操建议**
- 先小批量试单，分别采购都乐和鑫荣懋同一品种、同一规格的苹果，连续跟踪2-3个批次，记录：到货损耗率、硬度、糖度、外观均匀度、货架期。
- 要求供应商提供每批次的产地证明、检测报告和分级标准。
- 如果超市定位中高端且要求标准化，都乐通常更省心；如果追求成本灵活、本地化响应快，鑫荣懋可能更有优势，但需要你加强批次验收。
- 最好同时保留两个供应商，按批次质量动态调整采购比例，而不是二选一。

**结论**：无法直接说谁更稳定。建议用“同品种同规格、连续3批、损耗率和货架期”作为判断依据，用数据决定。
