都乐（Dole）和洪九果品通常都有面向渠道的分级包装，但“散装”是否可做，取决于你指的是哪种：

1) 都乐
- 常见渠道货：整箱（如 12kg、13kg 左右）、单把/单根预包装、商超用袋装。
- 社区团购小包装：一般不是“散装称重”，而是按把/按份预包装（如 2-3 根、4-5 根、500g/1kg 袋装）。
- 能否做小包装：多数要通过经销商或区域批发商谈，品牌方直供门槛较高。可问“能否做社区团购专供小规格”，但通常有起订量。

2) 洪九果品
- 以批发、渠道分销为主，香蕉常见整箱、整件、催熟后按件出货。
- 小包装/散装：部分区域经销商可做分装或按把出货，但要看当地仓配能力。
- 社区团购小包装：更可能通过区域经销商做“按份分装”，而不是品牌统一散装。

给你的判断建议：
- 如果你要的是“消费者到手即食小份”：优先找区域香蕉批发商/催熟商做 500g、1kg、2-3 根装，而不是直接找都乐/洪九总部。
- 如果你要的是“散装称重”：都乐和洪九体系内都不算标准选项，通常需要经销商二次分装。
- 谈判时直接问三件事：能否按份预包装、起订量多少、是否支持代贴标签/定制袋。

更可执行的路径：
1. 先联系你所在城市的都乐、洪九区域经销商，问“社区团购小包装香蕉能否做、起订量、到仓价”。
2. 同时找本地催熟商，问“500g/1kg 分装、贴标、次日配”。
3. 如果量不大，先用经销商现有小规格，别一开始要求品牌直供定制。
