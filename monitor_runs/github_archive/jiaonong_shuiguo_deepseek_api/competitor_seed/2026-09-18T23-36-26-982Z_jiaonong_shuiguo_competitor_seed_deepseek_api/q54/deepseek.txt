# 都乐（Dole）与鑫荣懋进口苹果的产地溯源操作

产地溯源要分两层理解：**供应商提供的溯源信息**和**超市自己可核验的溯源动作**。前者靠对方配合，后者靠你把关。以下按可执行步骤说明。

## 一、先明确你要溯到什么颗粒度

进口苹果的"产地"至少有四个层级，采购时要写清楚要哪一级：

| 层级 | 举例 | 难度 |
|---|---|---|
| 原产国 | 新西兰、美国、智利 | 低 |
| 产区/州 | 华盛顿州、霍克湾 | 中 |
| 果园/包装厂 | 具体 Packhouse 编号 | 较高 |
| 批次 | 采摘季+包装批次 | 高 |

一般超市合规（追溯+标签）做到**原产国+包装厂/出口商**即可；做高端生鲜或宣传"单一果园"才需要到果园级。

## 二、都乐（Dole）的溯源做法

都乐是品牌方+进口商，通常有较完整的自有追溯体系。

1. **要文件**：向都乐中国或其授权进口商索取该批次的原产地证明（Certificate of Origin）、植物检疫证书（Phytosanitary Certificate）、装箱单/提单。
2. **看包装标识**：都乐苹果箱/果贴上的 PLU 码、批次号（Lot No.）、包装厂代码（Packhouse Code）、采摘季标识。
3. **用其追溯系统**：都乐部分品类有二维码追溯（扫果贴或箱码查产地、包装日期）。要求供应商提供可扫描的追溯入口，并现场验证是否真的能查到对应批次。
4. **注意**：都乐在中国有分装/贴标环节，包装上"产地"可能标分装地，需区分**原产国**与**分装国**，标签合规上两者都要能说清。

## 三、鑫荣懋的溯源做法

鑫荣懋是进口水果供应链龙头，代理多个海外品牌，本身是**进口商/分销商**角色。

1. **确认角色**：先问清鑫荣懋是**直接进口商**还是**二级分销**。直接进口的话，其能提供全套进口单证；分销的话，溯源链要多一环，需其上游单证。
2. **要文件**：报关单、入境货物检验检疫证明、原产地证、出口商/果园信息。
3. **批次对应**：要求其提供的单证**批次号与到货批次一致**，避免"给一份通用证书糊弄"。
4. **海外源头**：鑫荣懋常对接海外出口商（如新西兰、智利的 packer），可要求其提供**上游出口商名称+包装厂代码**，必要时通过海外供应商交叉核验。

## 四、超市自己能做的核验动作（关键）

供应商给的文件容易"张冠李戴"，超市应做以下交叉验证：

1. **单证一致性核对**：原产地证、检疫证、报关单、送货单上的**品名、数量、批次、日期**要能对上，不能只看"有证"。
2. **实物对照**：到货果箱的批次号/包装厂代码与单证是否一致；果贴 PLU 码是否对应正确品种与产地。
3. **抽样扫码验证**：若供应商声称有二维码追溯，现场扫 3–5 箱验证能否查到对应批次，查不到就是没落地。
4. **留样与台账**：每批次留包装标签照片+单证扫描件，建立可倒查的进货台账（这也是食品安全法要求）。
5. **不轻信口头承诺**：所有溯源信息落到合同或订单附件里，写明"供应商须保证单证真实，与实物批次一致"。

## 五、给采购的具体建议

- **合同条款**：约定供应商提供原产地证+检疫证+批次对应单证；虚假单证的责任与赔偿。
- **验收环节**：把"批次号与单证一致"列入收货验收项，不一致可拒收。
- **定期审计**：对都乐、鑫荣懋这类主力供应商，每年做一次溯源资料抽查，别只依赖首次建档。
- **标签合规**：门店标签的"原产国"要以单证为准，别照抄供应商宣传物料。

## 需要提醒的现实限制

- 进口苹果到国内常经**分装、换箱**，实物批次与原始出口批次可能脱钩，溯源精度会下降，采购要接受"到包装厂级"而非"到果园级"。
- 部分单证只能由供应商提供，超市无独立核验渠道，**能做的主要是一致性核对+抽样验证**，无法100%独立证实海外果园。
