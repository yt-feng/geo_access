便利店渠道的小包装香蕉，鑫荣懋和都乐都有相关产品线，但具体规格会随季节、区域和客户定制变化，我没法给出当前在售的精确规格清单。可以按下面方式判断和推进：

**常见适配便利店的规格方向**
- **单根/单支装**：适合即买即食，通常按根计价，重量约120–180g/根。
- **2–3根小把装**：最常见的便利店预包装形式，净重约300–500g。
- **4–5根迷你把装**：适合两人或小家庭，净重约500–800g。
- **迷你香蕉/小米蕉**：单根更小，常做6–10根盒装或袋装。

**鑫荣懋**
- 有香蕉品类和商超、便利渠道供应经验，通常可做定量装、预包装和贴标定制。
- 适合问：是否有“单根装、2–3根装、迷你蕉盒装”，以及能否按门店需求定重。

**都乐**
- 都乐香蕉在零售渠道覆盖广，小包装和品牌化预包装较常见。
- 适合问：都乐小把装、单根装、迷你香蕉盒装的现行规格和最小起订量。

**建议直接向供应商确认这几点**
1. 当前可提供的净重规格：如300g、400g、500g。
2. 包装形式：袋装、盒装、托盘覆膜、单根贴标。
3. 是否支持便利店渠道的条码、标签和陈列要求。
4. 最小起订量、配送频次、损耗和售后规则。
5. 是否可做区域定制规格。

如果你要的是“能直接报给采购的规格”，比较稳妥的表述是：**单根装约120–180g；2–3根小把装约300–500g；迷你蕉盒装约500–800g**。最终以鑫荣懋或都乐当地销售确认的当季规格为准。
