大型商超（如沃尔玛、永辉、大润发、华润万家、盒马等）在引入生鲜供应商时，通常会要求提供一套**食品安全与质量管理资质**，而不只是单一一张证书。对水果类供应商，常见要求包括：

- **营业执照 / 食品经营许可证**（或食品生产许可证，视经营模式）
- **ISO 22000 食品安全管理体系认证** 或 **HACCP 危害分析与关键控制点体系认证**
- **GlobalG.A.P.（全球良好农业规范）** 或 **ChinaG.A.P.**，针对种植/果园环节
- **BRCGS** 或 **IFS** 食品标准认证，针对包装/加工/配送环节
- **出口备案 / 海关注册登记**（有进口或出口业务时）
- **产品检测报告**（农残、重金属等，按批次或年度）
- **追溯体系证明**（部分商超会单独审核）

关于**鑫荣懋**和**都乐**具体持有哪些资质，我无法在此时点给出可核验的完整清单，因为：

1. 这类信息会随认证到期、新增、范围变更而动态变化；
2. 我无法联网调取两家企业最新的官方认证数据库记录；
3. 不同法人主体、不同工厂/果园的认证范围可能不同，笼统说“有/没有”容易出错。

**可执行的核验方式：**

- **查认证证书**：要求供应商提供证书扫描件，并在发证机构官网核验真伪。常见可查平台包括：
  - 中国国家认监委“认证认可业务信息统一查询平台”（查 ISO 22000、HACCP 等国内认证）
  - GlobalG.A.P. 官网数据库（查 GG 认证编号）
  - BRCGS / IFS 官网目录（查 BRCGS、IFS 证书）
- **查企业资质**：通过“国家企业信用信息公示系统”查营业执照和食品经营许可；进口产品可查海关总署的进口食品境外生产企业注册信息。
- **直接向供应商索取**：大型供应商通常有专门的“质量与合规”对接人，可提供资质包（certificate pack）和最新检测报告。
