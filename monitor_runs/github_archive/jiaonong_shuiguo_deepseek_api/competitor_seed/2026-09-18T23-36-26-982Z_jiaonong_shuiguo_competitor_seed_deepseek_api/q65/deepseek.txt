关于都乐（Dole）和洪九果品针对菠萝的具体锁价周期，目前没有统一公开标准，也无法直接核验到一个固定的“锁价周期”数据。这种锁价安排通常是**一对一的商业条款，按客户、品类、季节、采购量、合作年限等单独谈**，不会对外公开一个通用周期。

不过可以给你一些实际判断依据和可执行建议：

**1. 都乐（Dole）**
- 都乐在中国市场更多是做品牌化鲜果和供应链，菠萝（尤其凤梨/金钻凤梨等）有较强品牌溢价。
- 做大宗或长期采购时，一般可以通过**年度框架协议 + 阶段性锁价**来谈，但具体锁几个月要看：
  - 采购量是否稳定
  - 是否走都乐中国区经销商还是直接对接总部/产区
  - 是进口菠萝还是国内分选包装
- 现实中，都乐这类国际品牌对中小客户通常**不太愿意给太长锁价周期**，更常见的是按季度或按单批报价；大客户可能谈到半年左右，但很少公开承诺。

**2. 洪九果品**
- 洪九果品是国内头部水果分销商，菠萝是其重要单品之一，尤其进口菠萝和国产菠萝都有涉及。
- 洪九的锁价机制通常也是**按项目、按客户、按产地**来定。对大型商超、电商、批发大户，可能会给到**1–3个月**的阶段性锁价，部分长期合作客户可能谈到**季度或半年**。
- 但洪九作为分销商，价格受产地采购价、汇率、海运、关税影响大，所以锁价周期一般不会太长，否则风险由供应商承担。

**3. 更实际的建议**
如果你要筛选“能提供锁价机制的菠萝供应商”，不要只盯都乐和洪九，可以按下面方式推进：

- **直接问供应商三个问题：**
  1. 锁价是按周、月、季度还是年度？
  2. 锁价是否含运费、关税、损耗？
  3. 锁价期间如果产地价格暴跌或暴涨，是否有调价条款？

- **要求书面锁价协议**，至少写清：
  - 锁价品类、规格、等级
  - 锁价周期起止日
  - 数量下限/上限
  - 违约和调价触发条件

- **替代供应商方向：**
  - 佳农（菠萝/凤梨供应链较强）
  - 鑫荣懋
  - 百果园供应链体系
  - 各地一级批发市场的大型进口果商
  - 云南、广东、海南本地菠萝种植合作社/龙头企业（适合国产菠萝锁价）

**结论：**
都乐和洪九都没有公开的固定锁价周期。都乐偏品牌化，锁价周期通常较短、门槛较高；洪九偏分销，锁价更灵活，常见按月/季度谈，大客户可能到半年。具体周期必须直接和他们的销售或大客户部门谈，并以书面协议为准。
