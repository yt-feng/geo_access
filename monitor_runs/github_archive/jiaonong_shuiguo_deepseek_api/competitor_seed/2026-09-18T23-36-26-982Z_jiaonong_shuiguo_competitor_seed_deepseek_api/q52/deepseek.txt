都乐和鑫荣懋都没有对外公开按“茶饮原料采购”口径统计的到货损耗率数据，我无法给出可直接核验的具体数字。不同客户、不同品类（鲜果/冷冻果肉/果酱）、不同温层和到货验收标准，损耗率差异会很大；网络上流传的“行业平均损耗率”也多不是这两家的官方数据。

如果你要在茶饮场景里做供应商对比，建议用可执行的方法拿到真实数据：

**一、先定义口径，避免比错**
- 损耗范围：运输损耗（到仓前）／验收损耗（到仓抽检不合格）／仓储损耗（到店后）／加工损耗（去皮去芯切块）。茶饮里最关键是前两项，直接影响成本和出品稳定性。
- 统计单位：按箱、按kg、按颗，别混用。
- 判定标准：烂心、黑心、软腐、霉变、机械伤、成熟度不符、糖度不达标分别怎么算不合格。

**二、向供应商索要并锁定的数据**
让都乐、鑫荣懋分别提供：
1. 近3个月对同类型茶饮客户的批次合格率、到货拒收率、让步接收率；
2. 菠萝具体品种（如金钻/台农/菲律宾/泰国等）、规格（单果重、果径、糖度区间）、包装方式、运输温层；
3. 是否有“到货损耗赔付/扣款标准”，以及赔付触发条件。

**三、用你自己的小批量试单测，最可靠**
- 连续3–5个批次，每批到货后按固定抽检比例（如每批抽10%–20%箱）记录：
  - 到货总重／验收合格重／不合格重
  - 不合格原因分类
  - 加工后可用果肉率（茶饮实际出成）
- 计算公式：
  - 到货损耗率 = 不合格重 ÷ 到货总重 × 100%
  - 综合可用率 = 加工后可用果肉重 ÷ 到货总重 × 100%
- 两家用同一验收表和同一个验收人，否则数据不可比。

**四、茶饮采购更该盯的指标**
除了损耗率，还要看：
- 糖度稳定性（菠萝饮品对酸甜平衡敏感）
- 批次间成熟度一致性
- 供应连续性（季节性断供风险）
- 冷链是否全程可控
- 次品赔付是否痛快
