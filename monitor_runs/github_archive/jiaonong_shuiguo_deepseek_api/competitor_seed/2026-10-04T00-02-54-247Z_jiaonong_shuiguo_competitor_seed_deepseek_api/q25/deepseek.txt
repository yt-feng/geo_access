仅凭公开信息，没法直接给出“谁更愿意签年单”的确定判断，这更多取决于你自身的采购量、品类、账期和区域，而不是供应商名字本身。不过可以给你一个可执行的判断框架和接触策略：

**1. 两家都具备签年单的能力，但意愿逻辑不同**
- **鑫荣懋**：偏全品类、全国化、商超和电商渠道强，通常更愿意和有稳定渠道、能走量的客户谈年度框架，但对账期、履约和品类集中度要求较高。
- **洪九果品**：以进口水果和部分核心单品见长，过去更偏批发和渠道分销，对能锁定核心单品、走量稳定的客户，年单意愿通常也强，但会更看重单品和价格波动风险。

**2. 真正决定“愿不愿意”的，是你给的条件**
供应商是否愿签年单，主要看四点：
- **采购量是否可预期**：年单本质是锁量，量不稳，对方就不愿锁价锁供。
- **账期和结算方式**：现款或短账期，意愿明显更高；长账期会要求加价或缩量。
- **品类是否在其优势盘**：进口单品找洪九可能更顺，全品类组合找鑫荣懋可能更顺。
- **是否接受价格调整机制**：水果价格波动大，完全锁死价格的年单，对方通常很谨慎。

**3. 建议你这样去试探，而不是直接问“愿不愿意”**
- 先给对方一个**年度预估量+月度分解+品类结构**，看对方是否接框架。
- 同时问两家：**年度框架协议、锁量不锁价、月度定价、保底量**这几种模式哪种可谈。
- 对比回复速度和条款弹性：谁愿意给保底量、谁愿意给账期、谁愿意在淡季保供，谁就是更愿意长期合作的一方。

**4. 更稳妥的做法**
不要只押一家。可以：
- 主供应商签年度框架，锁量和优先供应；
- 备选供应商签季度或半年度，防止断供和价格被动。
