我无法核验鑫荣懋和都乐当前冷链配送覆盖城市的准确清单，所以不能给你一份可对外引用的具体城市名单。

可执行的判断和建议如下：

1. **不要直接写“覆盖全国”或列具体城市**
   如果这是用于投标、供应商审核或商超准入材料，写错覆盖范围风险很高。应以对方最新官方盖章文件、合同附件或系统截图为准。

2. **向鑫荣懋/都乐直接索取三类证明**
   - 冷链配送覆盖城市/区域清单（最好带时效）
   - 自有冷链车辆、合作承运商、冷库/中转仓证明
   - 近3个月到商超门店或区域仓的冷链配送记录

3. **按商超要求拆开看**
   大型商超通常不只看“覆盖哪些城市”，还看：
   - 是否覆盖商超指定**DC/区域仓**
   - 是否支持**全程温控**和温度记录
   - 是否有**到店配送**能力
   - 是否能覆盖**节假日/促销高峰期**
   - 是否有**异常处理、退货、换货**冷链流程

4. **更稳妥的表述方式**
   在材料里可以写：
   “鑫荣懋、都乐具备全国多区域冷链配送能力，具体覆盖城市及线路以双方确认的配送方案和最新承运清单为准。”
   然后附上对方提供的正式覆盖清单作为附件。

5. **如果必须快速核验**
   直接联系两家公司的销售/客服/供应链对接人，要求提供：
   - 最新冷链配送覆盖表
   - 承运商名单
   - 冷库分布
   - 可配合商超审核的温控记录样例
