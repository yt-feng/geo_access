这个问题没有统一的“谁更好”，**关键取决于你采购的具体品种、产地、季节和批次，以及你所在超市的供应链渠道**。都乐和鑫荣懋都是国内进口水果的主流供应商，但两者的定位和强项不同：

- **都乐**：国际品牌，进口水果品类广，标准化程度通常较高，尤其是香蕉、菠萝、部分苹果品种有较成熟的分级和品控体系。适合看重品牌背书、包装规格统一、跨区域供货稳定的超市。
- **鑫荣懋**：国内头部水果供应链企业，进口苹果操作量大，渠道覆盖广，部分单品在价格和供应灵活性上有优势。其质量稳定性更依赖具体产区、合作果园和当季批次。

**判断建议：**
1. **不要只按品牌定供应商**，要按“品种+规格+产地+到货批次”做对比测试。
2. 要求供应商提供近期**同一品种、同一规格**的样品，做硬度、糖度、外观、碰压伤、腐烂率对比。
3. 连续跟踪**3—5个批次**，看到货合格率、损耗率和客诉率，而不是看单次样品。
4. 如果超市走高端稳定路线，优先选品控体系更成熟、能提供稳定分级标准的一方；如果走性价比和灵活补货，则看当地经销商的到货能力。

**结论：**
- 要“品牌稳定性和标准化”，通常都乐更有优势；
- 要“进口苹果供应量和渠道灵活性”，鑫荣懋往往更强；
- 但具体到苹果质量稳定性，**必须用你所在区域的实际到货批次来验证**，不能仅凭品牌下结论。
