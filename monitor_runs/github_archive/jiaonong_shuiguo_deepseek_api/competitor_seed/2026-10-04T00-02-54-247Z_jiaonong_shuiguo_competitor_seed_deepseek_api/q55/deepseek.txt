可以先给结论：**都乐和洪九果品都不是典型的“单一产地、基地直供、可开放溯源”的菠萝供应商模式，能否满足你要的产地溯源，要看具体品类、批次和采购渠道。**

分开说：

**1. 都乐**
- 都乐有全球化种植、采购和供应链体系，部分水果会强调自有农场、合作基地、标准化分选和追溯体系。
- 但都乐在国内水果业务更多是品牌化、多渠道分销，不一定对普通采购商开放“某个菠萝批次对应某个基地”的完整溯源数据。
- 如果你要的是“基地直供”，通常需要通过都乐官方渠道、区域经销商或大型商超供应链去谈，而不是默认所有都乐菠萝都能做到基地直发。

**2. 洪九果品**
- 洪九果品是国内较大的水果分销和供应链企业，核心优势在采购、分选、冷链和渠道分销，不是完全等同于“自有基地直供”。
- 它会有产地采购和合作基地资源，部分单品可能能提供产地证明、批次信息或检测报告。
- 但能否提供你要的“产地溯源”，同样要看具体菠萝品种、季节、采购规模和合同要求。

**判断建议：**
- 如果只要求“能说明产地”，都乐、洪九这类大供应链企业通常比普通批发商更规范。
- 如果要求“基地直供 + 一物一码/批次可追溯 + 可实地验厂”，需要直接问对方要：
  1. 具体菠萝品种和产区；
  2. 是否自有基地，还是合作基地/产地直采；
  3. 能否提供批次号、产地证明、检测报告；
  4. 是否支持验厂或视频看基地；
  5. 最小起订量和直发条件。

**更实际的建议：**
不要只问“你们有没有基地直供”，而要问：
> “这批菠萝具体来自哪个县/哪个基地？能不能提供该批次产地证明和追溯编码？是否支持验厂？”

如果对方只能给“产地：菲律宾/广东/海南”这种大范围信息，那不算真正溯源。  
如果对方能精确到基地、批次、采摘时间、检测报告，才更接近你要的产地溯源供应。

另外，如果你们采购量稳定，也可以同时看：
- 产地合作社或种植基地直采；
- 大型批发市场中的品牌供应链商；
- 地方农业农村部门推荐的追溯示范企业。
