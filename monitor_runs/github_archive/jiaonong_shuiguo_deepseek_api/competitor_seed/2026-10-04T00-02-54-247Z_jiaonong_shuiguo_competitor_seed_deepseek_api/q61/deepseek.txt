结论先说：**都乐（Dole）和洪九果品都没有公开可查的、针对香蕉分级的“企业标准”文本对外发布**。你在公开渠道（企业标准信息公共服务平台、公司官网、行业媒体）基本查不到这两家以“企业标准”形式备案的香蕉分级文件。下面是可执行的判断和替代方案。

## 一、两家企业的实际情况

**都乐（Dole）**
- 都乐有成熟的**内部香蕉品质规格体系**，通常按产地、品种、条数/梳数、长度、粗度（周径）、色泽、成熟度、机械伤、病斑等维度分级。
- 但这些属于**内部采购/品控规格（Spec）**，不是向市场监管部门备案的“企业标准”，一般不公开。
- 都乐对外的产品分级更多体现在**品牌等级（如 Dole Premium 等）和商超供货规格**上，而非标准文本。

**洪九果品**
- 洪九是水果供应链/批发型企业，香蕉是其核心单品之一，内部有**收货分级和品控规则**。
- 同样，这些是**内部作业标准**，未见公开备案的企业标准文本。
- 洪九更常见的是按**等级/规格报价**（如按条重、条数、外观），但不成文对外发布。

> 关键区别：企业**内部有分级规则** ≠ 有**备案的“企业标准”**。前者几乎每家规模企业都有，后者需要主动声明公开。

## 二、为什么查不到

1. 企业标准备案是**自愿公开**的，多数生鲜企业不备案，直接用国标/行标或自定内控规格。
2. 香蕉是**非加工农产品**，分级更常依据**国家标准、行业标准或采购合同规格**，而非企业标准。
3. 头部企业的分级规格属于**商业信息**，公开会削弱议价和供应链优势，所以不对外。

## 三、你可以直接用的替代依据

做水果连锁店分级，优先用这些**公开、可引用**的标准：

| 标准 | 说明 |
|---|---|
| **GB/T 9827《香蕉》** | 国家标准，含香蕉等级（优等品、一等品、合格品）和规格指标 |
| **NY/T 517《香蕉》** | 农业行业标准，常被采购参考 |
| **GB/T 33129《新鲜水果、蔬菜包装和冷链运输通用操作规程》** | 包装运输环节参考 |
| 出口参考 | **Codex Stan 205**（国际食品法典香蕉标准） |

**GB/T 9827 的分级维度**（可直接落到你店里）：
- 外观：果形、色泽、成熟度一致
- 缺陷：机械伤、病虫害、日灼、裂果
- 规格：按**每梳条数、单果长度、周径**分档
- 允许缺陷限度：按等级递减

## 四、给你店里的可执行建议

1. **以 GB/T 9827 为骨架**，做一份《门店香蕉收货分级卡》，分 A/B/C 三级。
2. **向都乐/洪九要“供货规格书”**：不叫企业标准，叫 **Product Spec / 收货标准 / 规格确认单**，这是你能拿到的真实分级依据，写进采购合同即可。
3. **自建内控标准**：把你店实际能卖动的规格固化成表，例如：
   - A级：长度≥18cm，周径≥3.5cm，无可见病斑，成熟度7成
   - B级：长度15–18cm，轻微机械伤
   - C级：做促销/加工
4. **要求供应商按你的等级报价和验收**，比纠结“有没有企业标准”更实用。

## 一句话总结

都乐和洪九**有内部香蕉分级规格，但没有公开备案的企业标准文本**。你要做分级，直接用 **GB/T 9827** 打底，再向供应商索要**供货规格书**写进合同，是更可靠、可落地的路径。
