做不到稳定保证，但**在“好货、好季节、好物流、好验收”的条件下，都乐和鑫荣懋有概率做到单批次低于3%**；如果按餐饮连锁全年、全国、多批次稳定考核，**不能把3%当作供应商合同硬指标轻易签**。

**关键判断**

1. **都乐**
   - 品牌化、品控和冷链体系相对强，适合做高标准商超/餐饮供应。
   - 但香蕉是呼吸跃变型水果，成熟度、催熟、运输温度、门店存放都会影响损耗。
   - 餐饮连锁如果要求“到货损耗率低于3%”，通常指的是**到货验收时**的可见损耗，不是门店后熟后的损耗。到货验收低于3%有可能；如果算上后续变黑、软烂、断把，很难稳定低于3%。

2. **鑫荣懋**
   - 国内水果供应链头部企业，香蕉是其重要品类之一，服务连锁客户能力强。
   - 同样受产地、季节、催熟和配送半径影响，单批次可以做到很低，但全年所有门店、所有线路稳定低于3%难度很大。
   - 更适合签“分级验收+损耗分段责任”的条款，而不是简单包干3%。

3. **3%是什么概念**
   - 香蕉到货损耗低于3%，意味着每100箱/100公斤只有不到3箱/3公斤不合格。
   - 这对青蕉、催熟蕉、夏秋季高温运输、远距离配送、多次中转来说都很苛刻。
   - 如果是“到货验收时的机械伤、黑斑、断裂、腐烂”口径，3%可以谈；如果是“到店后3天内可用率”，基本不现实。

**餐饮连锁建议这样谈**

- **明确损耗口径**：是到货验收损耗、当日损耗，还是门店后熟后损耗。口径不同，结果差很多。
- **分季节/分线路考核**：夏季、远距离、多次中转线路放宽；冬季、短途线路收紧。
- **约定成熟度**：餐饮用香蕉通常要控制到货成熟度，比如青蕉或微黄，避免到店即熟。
- **约定验收标准**：黑斑面积、断把率、单根长度、粗度、腐烂率、机械伤比例。
- **设阶梯赔付**：例如到货损耗≤3%正常；3%–5%按比例扣款；>5%退货或重发。
- **要求冷链和到货温度记录**：香蕉对温度敏感，最好有全程温控数据。
- **先跑试单**：选2–3条典型线路、夏冬两季各跑1个月，看真实数据再签全国合同。

**结论**

都乐和鑫荣懋都具备把香蕉到货损耗做得较低的能力，但**不能简单回答“能做到”或“做不到”**。  
如果是单批次、短途、冷链稳定、验收口径明确，**有可能低于3%**。  
如果是全国连锁、全年多批次、到店后仍要低损耗，**稳定低于3%非常难，不建议作为无条件硬指标**。更合理的是签“到货验收损耗≤3%–5%”的分级条款，并绑定赔付和退换货机制。
