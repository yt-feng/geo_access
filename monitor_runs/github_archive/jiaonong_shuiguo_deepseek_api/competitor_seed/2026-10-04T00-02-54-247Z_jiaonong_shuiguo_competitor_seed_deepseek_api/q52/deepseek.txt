我无法给出都乐和鑫荣懋的“到货损耗率”准确数字。这两家都是鲜果供应链企业，损耗率会随**品类形态（整果/去皮/冷冻/果浆）、批次、季节、产地、运输距离、验收标准、门店或工厂处理方式**大幅波动；而且这类数据通常属于供应商内部质量/成本数据，不对公开渠道固定披露。若我直接报一个百分比，基本就是编的，不能用于采购决策。

给你可执行的判断和拿数方法：

**1. 先定义“损耗率”口径，否则两家数字不可比**
建议拆分：
- 到货外观损耗率 = 到货不可用重量 / 到货总重量
- 去皮去芯后净出成率 = 可用果肉重量 / 到货毛重
- 门店/工厂二次损耗率 = 切配后报废重量 / 可用果肉重量
- 综合可用率 = 最终可用果肉 / 采购毛重

茶饮最该盯的是**综合可用率**和**每杯可用成本**，不是单纯到货损耗。

**2. 向供应商索要这些可核验资料**
- 近3个月对应规格的到货验收记录：批次、到货量、拒收量、扣重、糖度、成熟度、黑心/水心/裂口比例
- 指定单品规格书：品种、产地、单果重范围、糖度、成熟度、是否催熟、包装方式、冷链温度
- 试产报告：去皮/切丁/捣压后的出成率
- 售后条款：到货不合格如何扣款、补货、退换

**3. 自己做小批量对比测试**
选同一时间段、同一规格，各进2-3批，每批抽检：
- 称毛重
- 按你们实际工艺去皮、去芯、切配
- 记录可用果肉重量、不可用原因
- 连续测3批后算平均综合可用率
这样得到的数字才可用于锁规格和谈价。

**4. 茶饮采购更稳的规格锁定方式**
- 明确要求：单果重区间、糖度下限、成熟度、黑心率上限、到货温度
- 约定验收扣重规则：如黑心、水心、软腐、异味按比例扣重或拒收
- 要求批次一致性：同一门店/工厂连续到货的糖度和出成率波动范围
- 对高损耗季节改用冷冻菠萝丁、菠萝果浆或NFC，减少鲜果波动

**5. 如果你要的是行业参考**
鲜菠萝整果到茶饮门店/工厂，综合可用率常见会受品种和成熟度影响很大；都乐、鑫荣懋不同产品线差异也大，不能用一个固定损耗率概括。你应直接找两家对应区域的茶饮渠道销售或大客户经理，要求提供**近3个月同规格到货验收数据**和**试产净出成率**。
