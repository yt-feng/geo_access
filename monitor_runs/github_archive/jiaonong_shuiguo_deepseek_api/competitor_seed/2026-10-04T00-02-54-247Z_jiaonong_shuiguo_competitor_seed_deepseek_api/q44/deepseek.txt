进口水果的供货稳定性没有绝对答案，主要取决于品类、季节、口岸和你的采购量级。就都乐和鑫荣懋这两家来说，可以给你几个判断维度，但具体到苹果这个单品，我无法凭空给出准确结论，需要你用下面的方法去核验。

**先说结论性判断：**

- **都乐**：品牌化程度高，全球供应链成熟，进口苹果（如新西兰爱妃、美国红蛇果/青苹果等）通常有稳定的品牌货源。但都乐很多品类走的是"品牌授权+国内进口商/经销商"模式，实际供货稳定性取决于你对接的是都乐直营还是其区域经销商。
- **鑫荣懋**：国内头部水果供应链企业，进口能力强，口岸资源多，苹果品类覆盖面广（新西兰、美国、智利等）。作为国内供应链方，对中小连锁的响应通常比纯外资品牌更灵活。

**你要重点核验的几件事：**

1. **问清楚是"直供"还是"经经销商转手"**
   - 直供稳定性高，但通常有起订量门槛。
   - 经经销商则多一层，旺季可能被截货源。

2. **确认具体品种和产季**
   - 进口苹果有明显产季（新西兰苹果大致上半年，美国苹果秋冬，智利苹果南半球反季）。产季内稳定，产季外依赖冷库或换产地，稳定性和价格都会波动。
   - 让对方给出"全年供应计划表"，而不是笼统说"稳定"。

3. **问断货率和替代方案**
   - 直接问：过去一年该单品对连锁客户的断货频次？断货时有无替代产地/品种？
   - 这比听"我们供应很稳定"有用得多。

4. **小批量试单验证**
   - 先下2-3个月的小单，观察到货准时率、品质一致性、缺货补货速度，再决定是否放量或签年框。

5. **对比两家在同一单品上的报价、账期、损耗赔付条款**
   - 稳定性也体现在售后：到货烂果率谁承担、缺货怎么补偿，这些直接决定你的实际经营风险。

**实操建议：**
不要只在两家之间二选一。可以同时接洽，各拿一份"品种+产季+起订量+账期+断货赔付"的书面方案，用小单跑3个月数据，再定主供和备供。进口苹果这种单品，**主供+备供双渠道**通常比押注一家更稳。
