都乐和洪九的具体账期属于商务谈判条款，没有统一公开标准，我不能给出准确数字，只能给你判断和建议方向：

**都乐（Dole）**
- 都乐在中国以品牌授权、进口分销、商超直供为主，账期通常按渠道和采购量谈。
- 对大型商超/连锁，行业常见是月结30～60天；对中小批发客户，往往现款或短账期。
- 都乐本身对下游一般不会给很长的账期，具体要问对接的销售或区域经销商。

**洪九果品**
- 洪九是水果分销商，主要做批发市场和商超渠道，账期同样因客户类型差异很大。
- 对大型商超、电商平台，行业常见月结30～90天不等；对批发客户多为现款或7～30天。
- 洪九作为上市公司，财报里会披露应收账款周转情况，但不会公开单个客户的账期。

**能落地的做法**
1. 直接找区域销售或经销商，明确问：首单是否现款、后续月结多少天、是否需要保证金/担保。
2. 要求对方给书面账期政策，不要只听口头承诺。
3. 如果你们采购量稳定，可以用年度框架协议换更长账期。
4. 同时对比其他香蕉供应商：如佳农、鑫荣懋、百果园供应链、各地一级批发商，账期往往更灵活。

**提醒**：账期越长，单价通常越高，或隐含资金成本。建议把“价格+账期+违约金+断供风险”一起算综合成本，而不是只看账期。
