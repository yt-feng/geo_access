目前没有可靠、可核验的公开资料，能直接比较“鑫荣懋”和“都乐”在香蕉规格分级上的细度，所以我不能给出确定结论。

不过可以给你一个可操作的判断框架，去现场或向供应商确认：

**1. 先看分级维度**
两家都可能按以下维度分级，但细度不同：
- 单根重量/克重区间
- 每箱根数
- 果指长度
- 果指粗度/周径
- 成熟度/催熟阶段
- 条形、弯曲度、外观瑕疵
- 产地、季节、品种

**2. 判断“谁更细”的方法**
向两家分别要同一采购场景下的规格表，重点对比：
- 同一等级内，重量区间跨度是多少
- 是否区分长度、粗度、根数、成熟度
- 是否允许混装、串数差异
- 到货验收标准是否量化

例如同样叫“一级蕉”：
- A家只写“单根120–160g”，那就是粗分。
- B家写“单根135–150g、果指长18–20cm、每箱5–7串、催熟度3.5–4.0”，那就是更细。

**3. 采购建议**
- 如果超市要做**标准货架陈列**，优先选规格表更量化、批次稳定性更高的一家。
- 如果要做**高端精品/小规格**，重点问是否有小果、中果、大果的细分，以及单根克重和长度标准。
- 如果要做**促销堆头**，可接受略粗分级，重点看价格和到货稳定。
- 不要只看品牌，直接要求两家提供**最近3批到货验收记录**，比较规格达标率和波动范围。

**4. 结论**
仅凭品牌名，无法判断鑫荣懋和都乐哪家香蕉分级更细。实际采购中，应以供应商最新规格书、验收标准和历史到货数据为准。通常国际品牌（如都乐）在标准化文件上可能更成熟，但具体到某个区域、某个产地和某个采购渠道，鑫荣懋也可能给到更细的定制分级。最终要拿两家的书面规格表逐项对比。
