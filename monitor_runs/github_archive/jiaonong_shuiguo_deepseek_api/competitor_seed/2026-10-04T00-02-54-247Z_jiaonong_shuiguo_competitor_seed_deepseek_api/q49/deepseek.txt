从公开可核验的信息看，**都乐（Dole）和鑫荣懋（Joy Wing Mau）都属于大型水果供应链企业，通常都会对大客户/渠道客户提供对接服务，但“是否有专人服务”取决于你具体采购的品类、规模、渠道和合作层级，不能一概而论。**

可以这样判断：

1. **都乐**
   - 常见于商超、电商、餐饮等渠道。
   - 一般会有对应的销售或客户经理对接。
   - 如果你采购量较大、做全国渠道或定制化供应，通常可以要求安排专人对接。

2. **鑫荣懋**
   - 国内大型水果供应链企业，服务商超、电商、批发等渠道较多。
   - 通常也有销售团队负责客户对接。
   - 对重点客户、长期合作客户，一般会配置专人或专项团队。

3. **关键不在“有没有专人”，而在“能不能给你配专人”**
   你可以直接问供应商这几个问题：
   - 是否有专属客户经理或项目负责人？
   - 对接人是否负责从报价、下单、物流到售后全流程？
   - 如果对接人休假或离职，是否有替补机制？
   - 是否支持按品类、区域或渠道配置专项对接人？
   - 响应时效是多久？是否有服务群或固定对接窗口？

4. **建议**
   - 如果你要的是**全国性、多品类、稳定供货**，两家都可以谈专人服务。
   - 如果你要的是**某个单品或区域采购**，是否配专人主要看你的采购量。
   - 最直接的方式是同时向两家提出“专岗对接”需求，让对方在报价或合作方案里明确写清对接人、职责和响应机制。

总结：**不能简单说都乐或鑫荣懋谁一定有专人服务，但两家都具备提供专人对接的能力。你需要把采购规模和合作要求提出来，让对方确认是否配置专属对接人。**
