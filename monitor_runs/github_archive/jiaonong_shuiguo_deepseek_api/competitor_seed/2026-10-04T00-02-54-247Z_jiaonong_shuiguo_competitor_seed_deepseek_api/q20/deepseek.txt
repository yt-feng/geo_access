如果礼品团购客户明确要“进口品牌”，**都乐（Dole）和佳沛（Zespri）不能简单说谁绝对更受欢迎，要看礼品场景、预算和收礼人群**。但按国内礼品团购市场的普遍认知，可以这样判断：

**1. 品牌认知和礼品属性**
- **佳沛**：奇异果领域的高认知进口水果品牌，尤其是金果、绿果、阳光金果。包装规格成熟，礼盒感强，适合中高端礼品、员工福利、客户答谢。
- **都乐**：综合水果品牌，进口香蕉、菠萝、奇异果、牛油果等都有，品牌知名度也高，但礼品心智不如佳沛聚焦。都乐更像“日常高品质水果品牌”。

**2. 礼盒受欢迎程度**
- **中高端客户送礼、商务答谢**：通常**佳沛更受欢迎**，因为奇异果礼盒辨识度高，价格带清晰，收礼人容易感知价值。
- **员工福利、预算适中、量大**：都乐也有优势，尤其是都乐金菠萝、香蕉、混合水果礼盒，性价比和供应稳定性可能更好。
- **如果客户指定“进口品牌”但不指定品类**：佳沛在“进口水果礼盒”里更容易被接受，尤其是金果礼盒；都乐则更适合做组合装或走量福利。

**3. 采购时建议这样判断**
- 预算高、要面子、送重要客户：优先**佳沛金果/阳光金果礼盒**。
- 预算中等、要覆盖人数多：可考虑**都乐进口水果礼盒**或都乐+佳沛组合。
- 客户有明确品类偏好：按品类选，不要只看品牌。比如要奇异果就佳沛更强，要菠萝/香蕉组合都乐更强。
- 注意规格和产地：佳沛通常按“粒数/规格”计价，都乐产品线更杂，礼盒内容差异大，必须确认单果规格、净重、箱规和到货稳定性。

**结论：**
如果只问“礼品团购客户指定进口品牌，哪个礼盒更受欢迎”，**多数中高端礼品场景下佳沛更占优势；都乐在综合水果、福利走量和性价比场景更有竞争力**。最稳妥的做法是：给客户报两个方案——佳沛金果礼盒作为主推高端方案，都乐进口水果礼盒作为性价比/组合方案，让客户按预算和收礼对象定。
