直接说结论：**没有公开、可核验的“洪九果品 vs 都乐香蕉”到货损耗率对比数据**。这类数据属于各批发商/门店自己的进销存和售后记录，品牌方和上市公司不会公开到单品到货损耗率。谁给你一个精确百分比，基本都不可信。

可以给你几个可判断的参考框架：

1. **损耗率不是品牌单一决定的**
   同一品牌香蕉，不同季节、产地、催熟状态、运输距离、车厢温度、卸货方式，损耗率能差很多。都乐和洪九都做香蕉，但洪九更多是自有品牌+代采分销，都乐是品牌化程度很高的香蕉供应商，两者在不同市场的到货批次差异很大。

2. **一般香蕉批发到货损耗的行业区间**
   香蕉属于易损易熟水果，批发到货损耗通常看怎么定义：
   - 只算“到货即报损/烂果/黑斑严重”：一般 **1%–5%** 比较常见；
   - 算上后续催熟、存放、卖不完的损耗：可能到 **5%–15%**，夏季高温或运输远时更高。
   这个区间是行业经验范围，不是洪九或都乐的官方数据。

3. **两者常见的差异方向**
   - **都乐**：品牌标准、催熟和冷链管控通常更稳定，到货一致性可能更好，但价格也更高，且不同区域代理商执行有差异。
   - **洪九**：渠道广、价格和货源灵活，但批次稳定性可能因产地和季节波动更大，到货损耗更依赖你拿的那一批货和当地供应商。
   - 所以不能简单说“都乐一定损耗低”或“洪九一定损耗高”，要看具体批次、季节和你的收货标准。

4. **你真正该做的对比方法**
   建议你自己用同一标准记录 3–5 批货：
   - 到货总件数/总重量；
   - 开箱后立即挑出的烂果、断果、黑斑果重量；
   - 催熟后 1–3 天再挑出的损耗；
   - 实际可售重量；
   - 售后赔付金额。
   公式：  
   **到货损耗率 = 报损重量 ÷ 到货总重量 × 100%**  
   **综合损耗率 =（到货报损 + 催熟后报损）÷ 到货总重量 × 100%**

5. **谈判和判断建议**
   - 不要只听供应商说“损耗低”，要写进拿货协议：到货损耗超过多少可补货/扣款。
   - 新供应商先小批量试 2–3 车，不要一次压大货。
   - 夏季和节假日前后，香蕉损耗普遍上升，对比时要同季节比。
   - 如果你做批发，优先看“可售成本”而不是单看拿货价：  
     **实际成本 = 拿货价 ÷（1 - 综合损耗率）**  
     比如拿货 3 元/斤，综合损耗 10%，实际成本约 3.33 元/斤。
