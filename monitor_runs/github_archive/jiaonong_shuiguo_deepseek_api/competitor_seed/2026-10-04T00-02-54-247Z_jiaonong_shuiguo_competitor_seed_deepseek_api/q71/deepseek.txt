都乐（Dole）和洪九果品都是国内茶饮行业常见的菠萝/凤梨供应商，但两者的基地布局逻辑不太一样。

**都乐（Dole）**
都乐是全球性果蔬企业，在中国市场的菠萝供应主要来自其在菲律宾、泰国等东南亚的自有或合作种植基地，国内则通过上海、东莞等口岸进口分销。都乐在国内也有部分合作种植和加工基地，集中在广东、海南一带，但核心菠萝货源仍以菲律宾进口为主。如果你要找的是"都乐中国菠萝基地"，更准确的说法是：海外基地为主，国内口岸和加工点负责分拨。

**洪九果品**
洪九果品是国内水果供应链企业，菠萝/凤梨采购主要来自国内产区加东南亚进口两条线：
- 国内产区：广东湛江（徐闻是我国菠萝主产区）、海南、云南河口等；
- 进口来源：泰国、菲律宾、越南等地的合作果园和加工厂。
洪九在重庆、广州、上海等地有分拣加工和仓储节点，但菠萝种植基地本身多为"合作基地"而非完全自有。

**给你的实操建议：**
1. 直接联系都乐中国（上海总部）和洪九果品（重庆总部）的B端销售，要求提供当季可供货的产区清单和产地证明，这比查公开资料更准。
2. 茶饮用的菠萝通常要求品种稳定（如金钻凤梨、台农系列）、糖度一致、果肉规格统一，签约时把品种、糖度区间、单果克重、到货半径写进合同。
3. 不要只依赖单一供应商，建议都乐+洪九+一个国内徐闻产区的直采渠道做组合，避免进口口岸或单一产区出问题时断供。
4. 如果你要的是"稳定供应"，核心不是基地在哪，而是锁定年度框架协议+分批到货节奏，并约定替代产区条款。

具体基地地址和当季供货量属于动态商业信息，建议直接向两家公司的B端渠道索取最新资料，我无法保证公开信息的实时准确性。
