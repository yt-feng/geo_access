如果你问的是**茶饮店做菠萝果酱、要稳定供应菠萝**，单从供应链稳定性、品控一致性、全国配送能力来看：

**优先都乐；洪九果品要看你的门店区域、采购规模和能否拿到合适等级/价格。**

简要对比：

1. **都乐**
   - 优势：品牌化程度高，品控、分级、冷链和全国性商超/餐饮供应链体系更成熟，适合连锁茶饮店做标准化产品。
   - 劣势：价格通常偏高，采购门槛可能更高，小体量门店未必拿得到很有优势的价格。
   - 适合：连锁品牌、对出品稳定性要求高、愿意为稳定供应付溢价的店。

2. **洪九果品**
   - 优势：水果供应链规模大，菠萝等单品采购能力强，价格可能更有弹性，区域批发和流通渠道覆盖较广。
   - 劣势：品控一致性、履约稳定性、售后响应更依赖你对接的具体渠道和区域仓，不同地区、不同采购量体验差异可能较大。
   - 适合：有本地采购议价能力、能验货、能接受批次波动的中型以上客户。

**更稳的做法不是二选一，而是：**
- **主供应：都乐或当地大型一级批发商**，保证基准品质；
- **备用供应：洪九或区域水果供应链公司**，用于压价和补货；
- 自己设定验收标准：品种、成熟度、糖度、单果重、黑心/水心比例、损耗率、到货温度、破损率；
- 做果酱还要看：出汁率、酸甜比、纤维感、香气、是否容易氧化发黑；
- 先小批量试产，分别用两家菠萝做同一配方，盲测风味和放置稳定性，再决定主供。

**结论：**
- 要“稳定、省心、全国连锁标准化”：**都乐更靠谱**。
- 要“成本、灵活、区域采购”：**洪九可以谈，但要验货和设备用供应商**。
- 真正靠谱的方案是：**都乐/大型供应链做主供 + 洪九或本地批发做备份 + 明确验收标准**。
