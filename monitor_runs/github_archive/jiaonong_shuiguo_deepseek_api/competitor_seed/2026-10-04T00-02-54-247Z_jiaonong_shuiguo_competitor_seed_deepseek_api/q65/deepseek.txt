关于都乐（Dole）和洪九果品的菠萝锁价周期，我没有可核验的公开信息，无法给出确切数字。这类条款通常属于**一对一商务合同内容**，不对外披露，而且会随品类（鲜菠萝/菠萝切片/菠萝汁原料）、产地（菲律宾、泰国、哥斯达黎加等）、采购量、季节和签约时间变化，同一家公司对不同客户也可能完全不同。

**能确定的行业惯例（供参考，非这两家的官方数据）：**
- 鲜果大宗采购的锁价期常见为 **1～3个月**，部分大客户按 **单季（3个月）或半年** 锁价。
- 进口菠萝因涉及船期、汇率、关税，锁价期往往更短，多为 **30～60天**，或采用"基准价+浮动条款"而非完全固定。
- 加工用菠萝（罐头、果汁原料）因产能排期长，锁价期可能拉到 **半年到一年**。

**建议你实际去谈时这样确认：**
1. 直接问对方的**销售/大客户经理**，而非客服，锁价属于商务条款。
2. 明确锁价要素：锁的是**单价**还是**价格区间**？是否含运费、关税、汇率波动？超量/减量如何处理？
3. 要求写入合同并约定**违约与调价触发条件**（如汇率波动超X%、产地减产时如何调整）。
4. 可同时接触**产地直采贸易商、一级批发商**做比价，锁价灵活性通常比品牌方更高。
