结论先说：**两家都做分级，但“严格程度”不能用一句话统一比较**，而且进口超市采购里，真正决定规格是否统一的往往不是品牌本身，而是**具体品类、产地、加工厂、批次和采购合同里的验收标准**。

分开看：

**都乐（Dole）**
- 优势在于标准化体系成熟，尤其香蕉、菠萝这类核心品项，分级、催熟、包装、冷链管理比较规范。
- 苹果方面，都乐更多是品牌+供应链整合，具体到某个进口苹果品种，要看它由哪个产地/包装厂供货。
- 如果是都乐自有或深度管控的产线，规格一致性通常较有保障；如果是贴牌或贸易商供货，稳定性会受批次影响。

**洪九果品**
- 强项是进口水果供应链，尤其是东南亚水果，做批发渠道多，分级和分选能力在进口果品里算比较强的。
- 苹果不是它最核心的标签品类，但仍会按果径、颜色、果面、成熟度等做商品化分级。
- 洪九的优势更多体现在大规模集采和分销，是否能做到“每批都高度统一”，取决于你采购的具体等级和合同约束。

**超市采购更该关注这些：**
1. **合同写死验收标准**：果径范围（如80#、85#）、单果重范围、色泽、果面瑕疵比例、糖度、硬度。
2. **要求看实物样或到货批次照片**，不要只看品牌。
3. **约定允差范围**：比如同一箱内果径偏差不超过多少毫米，次果率不超过多少。
4. **看加工厂和产地**：同一品牌不同产地/包装厂，稳定性可能差很多。
5. **试单再放量**：先小批量验三批，看规格、损耗、到货一致性，再决定主供。

**简单判断：**
- 要“品牌背书+成熟标准化”：都乐通常更稳。
- 要“进口果品集采+批发供应链能力”：洪九通常更有优势。
- 但如果你要的是**超市货架规格统一**，最终应靠**采购合同+验收标准+批次抽检**来保证，而不是只依赖品牌分级严不严。
