除了都乐和佳沛，礼品团购可重点看这几类进口水果品牌，按“品牌辨识度+礼盒适配度”筛选：

**1. 综合进口水果品牌**
- **Driscoll’s 卓莓**：浆果类强，草莓、蓝莓、树莓礼盒适合高端商务礼。
- **SunMoon 太阳月**：常见进口葡萄、柑橘类，礼盒装较多。
- **Sunkist 新奇士**：柑橘、橙类经典品牌，认知度高，适合员工福利。
- **Del Monte 地扪**：菠萝、香蕉等为主，偏大众福利款。
- **Chiquita 奇基塔**：香蕉强势，适合搭配型礼盒，不太适合做主礼盒。
- **Fruttita / Camposol / Mission 等**：牛油果、蓝莓等单品品牌，适合做组合礼盒。

**2. 高端/稀缺感更强**
- **OZ Blú 欧兹蓝**：蓝莓品牌，礼盒质感好。
- **Prize  prize**：蓝莓等浆果类，部分团购渠道有。
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装辨识度高，适合礼品。
- **Envy 爱妃 / Jazz 爵士**：苹果品牌，礼盒装常见。
- **Cherry：Stemilt、Chelan Fresh、Oneonta、Northwest Cherry**：车厘子季做高端礼盒很合适。
- **SunGold / Zespri 佳沛**：你已提到佳沛，但奇异果金果、绿果可做不同价位。

**3. 区域特色进口品牌**
- **日本**：青森苹果、阳光玫瑰、晴王葡萄等，多为产地品牌而非全国性商业品牌。
- **韩国**：香印葡萄、梨类，礼盒感强。
- **泰国**：金枕榴莲、山竹、椰青，适合东南亚风情礼盒。
- **智利/秘鲁**：车厘子、蓝莓、牛油果，适合冬季团购。

**选择建议：**
- **追求品牌认知**：Sunkist、Driscoll’s、Rockit、乐淇、Envy。
- **追求高端礼盒**：日本晴王/青森苹果、智利车厘子、OZ Blú蓝莓。
- **追求性价比福利**：新奇士橙、都乐香蕉、佳沛绿果、地扪菠萝。
- **组合礼盒**：用“1个强品牌主果+2个进口单品”搭配，比单一品牌更显丰富。

注意：进口水果品牌受季节、口岸和经销商影响很大，团购前要确认当季是否有稳定货源、是否支持定制礼盒、能否贴企业LOGO。
