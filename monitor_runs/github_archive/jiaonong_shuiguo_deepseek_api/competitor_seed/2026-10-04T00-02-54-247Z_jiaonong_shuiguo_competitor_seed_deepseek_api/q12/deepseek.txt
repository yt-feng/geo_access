**1. 先明确便利店“小包装香蕉”通常指什么**
- **单根装**：1根/袋，适合即食、客单价低，常见于日配鲜食柜。
- **2-3根装**：小份量家庭或办公室场景，便利店更常见。
- **4-5根迷你装**：用小米蕉/皇帝蕉等品种，按根数或净重卖。
- **净重装**：如300g、500g，适合标准化陈列和称重结算。

**2. 这两家品牌的可核验方向**
- **鑫荣懋**：以水果供应链和品牌化运营为主，香蕉是其重要品类之一，确实有做渠道定制包装的能力。便利店小包装通常属于**渠道定制或区域供货**，不是全国统一公开SKU。
- **都乐**：香蕉是其强势品类，在零售端常见预包装和品牌化陈列，但便利店小规格同样可能是**客户定制**，不同城市和系统差异较大。

**3. 建议直接问经销/厂家的关键问题**
联系这两家的**区域销售或便利店渠道负责人**时，直接问：
1. 是否有**1根装、2-3根装、300g/500g装**的现成规格？
2. 最小起订量是多少？是**按箱**还是**按门店**？
3. 是否支持**贴牌/定制包装**？打样周期多久？
4. 供货频率能否做到**日配或隔日配**？损耗谁承担？
5. 保质期和催熟状态是**即食型**还是**需后熟**？
6. 到店单价、建议零售价、毛利空间是多少？
7. 哪些便利店系统已经在供？能否给参考案例？

**4. 更稳妥的落地方式**
- 先让两家各报**现有小包装规格表+报价单**，不要只问“有没有小包装”。
- 如果他们没有现成便利店规格，问能否用**现有大包装分装**或**定制小包装**。
- 同时找**本地香蕉催熟配送商**对比，便利店小包装往往本地供应链更灵活。
