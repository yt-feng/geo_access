这个问题没法直接给一个“谁更快”的固定答案，因为都乐和鑫荣懋都是品牌/供应链方，实际履约快慢取决于你走哪个产地、哪个仓、哪家承运商、以及你签的是哪种合作模式。脱离具体线路谈快慢，容易踩坑。

给你一个可判断的框架，以及怎么在 1-2 天内自己测出结论：

**1. 先明确“快”指哪一段**
- 产地到你的前置仓/分拣中心
- 到消费者手里的“最后一公里”
- 从下单到签收的全链路

生鲜香蕉产地直发，真正卡时效的通常是：产地装车→干线→你所在区域分拨。都乐、鑫荣懋这类更多是供应链组织方。

**2. 直接影响快慢的变量**
- 产地：菲律宾、厄瓜多尔进口 vs 云南、广西、海南国产，线路完全不同
- 合作模式：一件代发 / 整车 / 干支线 / 云仓
- 是否用他们的仓配网络，还是只买货、物流自己找
- 你所在城市是一线还是下沉市场
- 香蕉催熟和温控要求，会决定能不能走普通快递

**3. 建议你这样对比**
向两家各要同一条件的报价和时效承诺：
- 同产地、同规格、同起订量
- 写明：发货仓、承运商、预计揽收时间、干线时长、到你城市的时效、破损/催熟责任
- 要求给最近 1 个月同线路的真实签收时效数据

**4. 大方向上的经验判断**
- 都乐品牌和供应链体系成熟，标准化程度高，进口香蕉链条通常更稳
- 鑫荣懋在国内水果供应链、尤其是国产水果和区域分拨上覆盖较广
- 但“更快”往往取决于他们在你目标城市的仓配布局，而不是品牌本身

**5. 最稳的做法**
先小批量测单：同一产地、同一目的地，各发 2-3 批，记录装车到签收的小时数。生鲜电商别只看报价，腐损率和实际签收时效才是利润线。

如果你告诉我：**你在哪个城市、走国产还是进口、日单量大概多少、是整车还是快递**，我可以帮你把对比维度收窄，给一个更具体的判断。
