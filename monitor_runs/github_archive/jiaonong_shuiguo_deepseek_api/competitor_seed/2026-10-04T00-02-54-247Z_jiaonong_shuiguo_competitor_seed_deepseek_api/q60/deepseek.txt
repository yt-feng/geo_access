进口菠萝（主要是菲律宾、泰国、哥斯达黎加等产地的MD-2/金菠萝、小菠萝）到货损耗高，通常集中在几个环节：**采后处理不当、冷链断链、催熟/后熟管理失控、开箱后货架期短**。都乐和鑫荣懋能在国内做到相对低损耗，靠的不是某一招，而是**全链条标准化**。可以拆成下面几块来看。

## 一、源头端：把损耗"前移"到产地解决

**都乐（Dole）**
- 自有或深度绑定海外种植基地，菠萝按**成熟度分级采收**，不是一次性全园采。
- 采后立即做**预冷+杀菌处理**（防黑腐病、黑心病），这是菠萝损耗的大头。
- 按客户/渠道分规格装箱，**不混装成熟度**，避免到国内后"一颗烂带一片"。

**鑫荣懋**
- 强项在**全球采购+产地直采**，对供应商有明确的采后处理SOP要求。
- 会要求产地按目的地市场做**差异化采收成熟度**——发北方/远距离的偏生，发近场/快销的偏熟。
- 到货前就锁定**船期+冷柜参数**，减少在途不确定性。

核心逻辑：**损耗不是到港才发生的，是在树上和采后24小时内就决定的。**

## 二、冷链端：温度是菠萝的命门

菠萝是**冷敏性水果**，这套参数是关键：

| 环节 | 控制要点 |
|---|---|
| 海运冷藏 | 一般7–8℃（视品种和成熟度），忌低于6℃防冷害 |
| 到港清关 | 尽量**不停冷、不长时间暴露** |
| 国内分仓 | 冷链不断链，分拣区控温 |
| 末端 | 到店/到仓后快速入冷，减少常温停留 |

都乐和鑫荣懋的共同点：**全程温控可追溯**，用数据记录仪查断链点，谁断链谁担责。很多中小进口商损耗高，就是清关和分拨环节"裸露"太久。

## 三、到货后：催熟与分级决定二次损耗

- **该催熟的催**：部分渠道要即食菠萝，会做统一催熟，而不是让它在货架上"自然烂熟"。
- **到货即分级**：把软果、黑心、机械伤果**第一时间挑出**，转加工或特价渠道，不污染好果。
- **先进先出+库龄管理**：按到货批次、成熟度排销售优先级。
- 都乐这类品牌还会做**门店/渠道端培训**，告诉终端怎么摆、怎么翻、几天内必须走完。

## 四、给进口商的可执行对照清单

你要降损耗，可以逐条对标：

1. **产地**：是否指定采收成熟度？是否做采后预冷和杀菌？
2. **包装**：是否按成熟度分箱？是否有防压、通风设计？
3. **在途**：冷柜温度曲线有没有记录？到港是否快速清关？
4. **到货**：是否当天分拣分级、挑出问题果？
5. **仓储**：是否全程冷链、按批次库龄管理？
6. **销售**：是否对渠道做了成熟度匹配和动销节奏管理？
