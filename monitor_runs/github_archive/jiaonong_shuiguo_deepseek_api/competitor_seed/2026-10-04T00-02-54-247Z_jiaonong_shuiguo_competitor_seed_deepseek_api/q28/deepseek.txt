这个没法直接给一个“谁更便宜”的结论，因为两家都是大型进口水果供应链，具体到苹果这个单品，价格差距主要取决于几个变量：

**影响价格的关键变量**
1. **品种和产地**：都乐主推的进口苹果常见有新西兰爱妃/爵士、美国红玫瑰等；鑫荣懋也做新西兰、美国、智利等产地的苹果，且它本身是多个品牌的代理/渠道商。同是“进口苹果”，品种不同价格差一倍都正常。
2. **合作量级和账期**：你如果是总部统采、量大、现款，价格会比门店零散进货好很多。两家对大连锁和小连锁的报价体系不一样。
3. **到货批次和季节**：进口苹果受船期、汇率、当季产量影响大，同一个供应商不同月份报价可能差20%以上。
4. **规格和包装**：果径、等级、箱规、是否贴标，直接决定单价。

**两家的一般性特点（供参考，不是绝对结论）**
- **都乐**：品牌溢价较高，终端认知度强，适合做引流和高毛利礼盒，但采购成本通常不低，议价空间相对小。
- **鑫荣懋**：供应链能力强，代理品牌多，走量和渠道分销是强项，对连锁客户通常有更灵活的报价和返利方案，性价比可能更好。

**建议的做法**
1. 直接找两家区域销售**同时报同一规格**：写清楚品种、产地、果径、等级、箱规、到货城市、月采购量、账期，拿到可比的报价单。
2. 要求**样品试销**：价格竞争力不只看进货价，还要看损耗率、终端动销和退换货政策。都乐可能卖得贵但好卖，鑫荣懋可能进价低但需要你推。
3. 询价时问清**是否含税、含运费、有无返利/账期**，这些对实际成本影响很大。
4. 可以引入**第三家**（如佳沃、百果园供应链等）做比价，避免被单一渠道绑定。

一句话：单看报价没有意义，**同规格、同账期、同量级下的综合到货成本**才能判断谁更有竞争力。建议你按上面清单让两家各报一次，我可以帮你分析怎么对比。
