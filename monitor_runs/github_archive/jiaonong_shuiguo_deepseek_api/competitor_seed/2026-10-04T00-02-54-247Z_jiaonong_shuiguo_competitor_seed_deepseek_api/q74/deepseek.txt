关于都乐和洪九果品的礼品团购起订量，我无法给出准确数字，因为这两家的团购/定制政策会随季节、品类、区域经销体系变化，而且通常不是全国统一一个标准，而是由各地经销商或大客户渠道单独谈。

可以明确的是：

**都乐（Dole）**
- 都乐在中国更多是通过授权经销商、区域代理做团购和企业客户。
- 起订量一般不是品牌总部统一规定，而是看具体城市、具体品类（如蓝莓、车厘子、猕猴桃、菠萝等）和礼盒形式。
- 常见做法：几十箱起谈，量越大越有价格优势；热门单品或进口水果可能要求更高。
- 如果你要定制礼盒（印logo、指定组合），通常需要达到一定箱数，且要提前锁货。

**洪九果品**
- 洪九果品主要是水果供应链和批发分销，团购礼盒多走大客户或渠道合作。
- 起订量同样不统一，取决于品类、包装、是否贴牌、配送区域。
- 一般也是按箱/按件起订，量小可能只能走现成礼盒，量大有定制空间。

**建议你直接这样问，最快拿到准确答复：**
1. 说明城市和配送范围。
2. 说明需要的品类和预算区间。
3. 说明预计采购箱数。
4. 问清楚：是否含定制包装、是否含运费、能否开票、多久交货。

**更实际的做法：**
- 找都乐、洪九在你所在城市的经销商或大区团购负责人，而不是只问总部客服。
- 同时问2-3家本地水果供应链公司比价，因为礼盒定制往往本地供应链更灵活。
- 如果量在100箱以内，优先选当地经销商或专业礼品水果商；量在几百箱以上，再直接找品牌大客户渠道谈。
