如果你说的“都乐”和“鑫荣懋”是水果/生鲜供应链领域的那两家公司，先给结论：

**两家都属于行业里规模大、渠道能力强的供应商，但“专岗对接”和“售后服务”不能只看品牌，必须按你的业务类型、采购规模、合作模式去谈，并在合同里写死。** 单凭公司名气，无法直接判断它们对你这类客户的服务水平。

具体判断建议如下：

**1. 都乐**
- 优势通常在品牌、标准化程度、商超/餐饮渠道经验、部分品类的稳定供应能力。
- 如果你要的是品牌背书、标准化产品、全国性或区域性稳定供货，都乐通常更有吸引力。
- 但“专岗对接”是否给到，取决于你的采购量、合作层级和签约主体。大客户通常有专属团队，中小客户可能走渠道商或区域销售，售后响应不一定是一对一。

**2. 鑫荣懋**
- 优势通常在水果供应链、品类整合、渠道覆盖、仓储配送和部分进口/国产水果资源。
- 如果你要的是多品类水果集采、区域配送、商超或电商供货，鑫荣懋的供应链能力通常比较强。
- 同样，专岗和售后要看具体区域、品类和合同条款。大区/渠道体系下，实际对接人可能是区域销售或经销商，不一定是总部专属客服。

**3. 真正要核验的点**
不管选哪家，建议你要求对方书面确认：
- 是否指定**固定对接人**，姓名、职务、响应时间、备份人是谁；
- 售后问题谁负责：质量异议、短少、破损、退换货、补货、冷链温控、临期处理；
- 响应时效：比如几小时内回复、几小时内给方案、几天内完成退换/赔付；
- 责任边界：是供应商责任、物流责任还是你方收货后责任；
- 是否有**服务考核**：月度复盘、投诉率、到货合格率、缺货率、赔付标准；
- 合同里写清违约和赔偿，不要只听口头承诺。

**4. 更稳妥的做法**
- 同时让都乐、鑫荣懋以及1-2家区域型供应商报价和出服务方案；
- 用同一套问题去问，比较“专岗是谁、售后多久响应、出问题怎么赔”；
- 先小批量试单，重点测：到货品质、异常响应、退换货速度、对接人是否稳定；
- 如果你采购量不大，直接找它们的区域经销商或一级代理，可能比找总部更容易拿到实际对接服务。
