直接说结论：**没有绝对“谁更靠谱”，要看你店里的用法和采购渠道。** 但在茶饮店做菠萝果酱这个场景里，两者定位不太一样：

- **都乐（Dole）**：品牌标准化更强，全球供应链，凤梨/菠萝品种和成熟度相对稳定，适合对**风味一致性和品牌背书**要求高的店。缺点是价格通常更高，而且不是所有城市都好拿到稳定批发价。
- **鑫荣懋**：国内龙头水果供应链企业，渠道覆盖广，餐饮/茶饮供货经验多，性价比和本地化服务通常更好。缺点是不同批次、不同产区、不同品种可能波动比进口大牌更明显，需要你锁规格。

**建议按这几点判断：**

1. **先定品种和规格**  
   做果酱不要只说“菠萝”，要定：  
   - 品种：金钻凤梨、台农、巴厘菠萝等  
   - 状态：鲜果、冷冻果肉、果泥、糖水菠萝  
   - 规格：糖度、酸度、纤维感、出肉率  
   茶饮店更建议用**冷冻菠萝果肉/果泥**，比鲜果削皮更稳定。

2. **要样品做盲测**  
   同一配方分别用两家原料做3批：  
   - 第1天、第3天、第7天测风味  
   - 看是否发苦、变色、出水、香气衰减  
   茶饮最怕的不是不好喝，而是**每批不一样**。

3. **看供货稳定性**  
   问清楚：  
   - 是固定产区还是随季节换产区？  
   - 断货时有没有替代规格？  
   - 最小起订量、冷链、到货周期、破损赔付？

4. **算综合成本**  
   都乐可能单价高，但损耗低、人工少、品控省心。  
   鑫荣懋可能单价低，但如果批次波动大，你每批都要调糖调酸，隐性成本更高。

**实操建议：**
- 如果你做**连锁、标准化要求高、预算够**：优先试都乐，或都乐+本地供应商双源。
- 如果你做**单店/区域小店、追求性价比**：优先试鑫荣懋，但必须锁规格、签品质标准。
- 最稳的做法：**两家都拿样，做盲测和7天稳定性测试，再决定主供应商和备选供应商。**

一句话：**要品牌稳定选都乐，要渠道性价比选鑫荣懋；但茶饮店真正该选的是“能长期稳定供货且批次差异小”的那家。**
