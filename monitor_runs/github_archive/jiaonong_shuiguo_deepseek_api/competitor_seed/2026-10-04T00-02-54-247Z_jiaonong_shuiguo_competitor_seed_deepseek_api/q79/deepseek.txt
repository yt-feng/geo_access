直接说结论：**都乐基本能，洪九果品不一定能稳定满足“全年菠萝供应”这种需求，而且两家都不是最适合茶饮店做果酱原料的采购对象。**

分开看：

**1. 都乐**
都乐是全球水果品牌，供应链能力强，菠萝是它的核心品类之一。它在中国市场有鲜菠萝、菠萝切块/冷冻菠萝等相关产品。
- 如果你要的是**鲜菠萝全年稳定供货**：都乐能做到，但受产地轮换影响，不同季节可能来自菲律宾、泰国、哥斯达黎加等不同产区，风味、糖酸比会有波动。
- 如果你要的是**标准化果酱原料**：都乐更偏鲜果和鲜切，不一定直接给你茶饮店用的果酱/果泥/冷冻果肉方案，通常要通过经销商或加工厂。
- 价格上，都乐品牌溢价明显，茶饮店做果酱原料成本会偏高。

**2. 洪九果品**
洪九是国内大型水果分销商，强项是榴莲、火龙果、车厘子等品类的批发分销，菠萝也有做，但不像都乐那样把菠萝作为全球核心单品。
- 它能不能全年供菠萝，取决于当年它的产地采购和渠道安排，**不是像都乐那样有全球多产区轮换的确定性**。
- 洪九主要是**分销商角色**，不是专门做茶饮果酱原料的供应商。你要的是稳定规格、稳定糖度、稳定价格的工业原料，它不一定能长期匹配。
- 如果只是要鲜菠萝，它可以阶段性供货；如果要签全年框架、锁定品质和价格，风险较高。

**更实际的做法：**
茶饮店做菠萝果酱，通常不需要执着于“都乐或洪九供鲜菠萝”，而应该找：
1. **冷冻菠萝果肉/菠萝果泥供应商**：全年供应最稳，规格统一，适合做酱。
2. **果酱代工厂或浓缩果浆厂**：直接采购菠萝果酱半成品，省去自己熬酱的品控麻烦。
3. **大型水果加工厂**：比如做速冻果蔬、果肉果浆的企业，按糖度、酸度、出成率定标准。
4. 如果坚持用鲜菠萝，可以“都乐保底 + 国内产区补充”，但必须接受季节风味差异，并做配方调整。

**判断建议：**
- 要品牌稳定、全球供应链：选都乐体系，但成本高，且要确认是鲜果还是加工原料。
- 要低价、灵活采购：洪九可以问，但别指望它像专业果酱原料商那样全年稳定。
- 要真正适合茶饮店全年做酱：优先找**冷冻菠萝果肉/果泥/果酱代工**，而不是鲜果品牌。
