大型商超（如沃尔玛、山姆、永辉、盒马等）通常要求生鲜/食品供应商具备**GFSI（全球食品安全倡议）认可的认证**作为准入基础。

关于**鑫荣懋**和**都乐（Dole）**具体通过了哪些认证，我无法给出可核验的完整清单，因为：

**1. 认证信息是动态的**
企业的认证会随年度审核、工厂/基地增减而变化，且不同子公司、不同加工厂可能持有不同认证。

**2. 我无法核实当前有效的证书**
我手里没有这两家企业最新的认证数据库，凭记忆列举具体证书编号或认证机构名容易出错，也可能误导你的准入判断。

---

**可靠的核实途径（建议直接操作）：**

1. **直接向供应商索取证书原件/扫描件**
   - 要求提供认证证书（含认证机构、证书编号、有效期、覆盖范围/场所）。
   - GFSI认可的主流认证包括：BRCGS、IFS、FSSC 22000、SQF、GlobalG.A.P.（针对种植端）等。

2. **在认证机构官网核验**
   - 拿到证书编号后，到对应认证机构（如 SGS、BV、Intertek、TÜV、NSF 等）官网查询真伪和有效性。

3. **在 GFSI 官网核对认可方案**
   - GFSI 官网列有认可的认证方案清单，可比对证书类型是否符合商超要求。

4. **通过天眼查/企查查等查企业资质**
   - 部分平台会收录企业的体系认证（ISO 22000、HACCP 等），但更新可能滞后，仅供参考，不能替代原件核验。

---

**给你的建议：**
- 不要依赖第三方转述的具体认证名称，**以供应商提供的有效证书原件为准**。
- 明确商超准入标准到底是要求 GFSI 认可认证，还是接受 HACCP/ISO 22000，两者门槛不同。
- 如果涉及具体工厂，要确认证书**覆盖范围是否包含供应给你的那个加工厂/包装厂**，否则可能不满足要求。
