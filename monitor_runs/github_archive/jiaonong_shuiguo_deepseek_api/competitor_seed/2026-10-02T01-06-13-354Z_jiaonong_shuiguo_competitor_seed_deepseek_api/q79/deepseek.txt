不能简单说“能做到”或“做不到”，要看你指的是**鲜果全年供应**、**冷冻/罐头原料全年供应**，还是**稳定做成果酱的菠萝原料全年供应**。分开判断：

1. **鲜菠萝全年供应**
   - **都乐（Dole）**：具备较强的全球供应链，通常可以通过不同产区轮换、进口菠萝来做到相对全年供应，但具体到中国大陆某城市、某品种、某规格，仍受季节、产地、物流、价格影响。不是“任何时间都一样便宜稳定”。
   - **洪九果品**：主要做水果分销和供应链，菠萝/凤梨是其品类之一，具备一定跨产区调配能力，但更多要看它当季采购和渠道能力。全年稳定供应可能存在，但不如都乐这种国际品牌在自有种植和全球产区布局上那么确定，尤其鲜果端波动更大。

2. **如果茶饮店做果酱，实际不一定需要鲜菠萝全年供应**
   更现实的做法是：
   - 旺季用鲜菠萝或鲜凤梨做差异化；
   - 淡季用**冷冻菠萝果肉、菠萝果泥、糖渍菠萝、罐头菠萝**来保证配方稳定；
   - 或者直接采购**菠萝果酱/果泥半成品**，再调味使用。
   这样比追求“全年鲜菠萝”更稳定，成本也更可控。

3. **都乐和洪九能不能满足茶饮店？**
   - **都乐**：更适合需要品牌背书、标准化程度高、能接受进口/全球调配的客户。鲜果、果汁、罐头类产品线相对成熟，但茶饮店小批量、多批次订货不一定是最优合作模式。
   - **洪九果品**：更适合国内水果供应链、批量采购、产地直发。若你要的是鲜果或冷冻果肉，可以谈；但若你要的是直接用于茶饮的果酱成品，它未必是专门供应商，可能还需要再找加工厂。

4. **建议你按这个标准去问供应商**
   不要只问“能不能全年供应”，直接问：
   - 全年12个月，每月能供什么形态：鲜果、冷冻果肉、果泥、罐头、果酱？
   - 品种是什么：巴厘菠萝、金钻凤梨、MD-2、台农？酸甜比和纤维感是否稳定？
   - 最小起订量、送货频率、锁价周期？
   - 淡旺季价格波动范围？
   - 是否能提供检测报告、农残报告、规格书？
   - 是否支持定制糖度、切丁大小、杀菌工艺？

**结论：**
如果指**鲜菠萝全年稳定供应**，都乐相对更靠谱，洪九也有可能但取决于渠道和产地调配；如果指**茶饮店做果酱的原料全年稳定供应**，不必执着于鲜果，冷冻果肉/果泥/罐头/果酱半成品才是更稳的方案。都乐和洪九都可以作为供应链选项，但最终要看他们能否给你匹配“形态、规格、价格、频次、稳定性”这五项。
