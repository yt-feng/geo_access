大型商超（如沃尔玛、永辉、大润发、山姆、盒马等）在引入水果供应商时，通常会要求提供以下**基础食品安全与合规资质**。具体到鑫荣懋和都乐，由于我无法实时核验其最新证书编号和有效期，以下按**通常情况**说明，实际以供应商最新提供的盖章文件为准。

## 商超一般要求的核心资质

1. **营业执照**（经营范围含食品/农产品销售）
2. **食品经营许可证**（或食品生产许可证，视业态）
3. **ISO 22000 食品安全管理体系认证**
4. **HACCP 危害分析与关键控制点认证**
5. **GLOBALG.A.P.（全球良好农业规范）**——水果类尤其常见
6. **BRCGS 或 IFS 认证**——部分高端商超/出口渠道要求
7. **产品检测报告**（农残、重金属等，按批次或年度）
8. **产地证明 / 进出口检验检疫证明**（进口水果）
9. **可追溯体系说明**

## 鑫荣懋（鑫荣懋集团）

作为国内大型水果供应链企业，通常具备：

- 营业执照、食品经营许可证
- **ISO 22000** 食品安全管理体系认证
- **HACCP** 认证
- **GLOBALG.A.P.** 相关认证（针对自有或合作基地）
- 部分品类有有机认证、绿色食品认证
- 进出口资质及检验检疫相关文件

## 都乐（Dole）

作为国际果蔬巨头，通常具备：

- **GLOBALG.A.P.** 认证（核心）
- **ISO 22000 / FSSC 22000** 食品安全体系认证
- **HACCP** 认证
- **BRCGS** 认证（部分加工/包装环节）
- 有机认证（部分产品线）
- 进口检验检疫证明、原产地证明
- 全球可追溯体系

## 关键提醒

- **具体证书编号、发证机构、有效期**必须向供应商索取最新盖章扫描件核验，不能仅凭品牌名称判断。
- 不同商超要求不同：山姆、盒马通常要求更严（如 GFSI 认可认证），普通商超可能只需营业执照+食品经营许可证+检测报告。
- 认证是**按工厂/基地/品类**颁发的，同一供应商不同产品线资质可能不同，需逐项对应。

**建议操作**：直接向鑫荣懋或都乐的对接业务员索取"供应商准入资质包"，并要求提供证书在认监委或相关认证机构官网的可查询编号，自行核验真伪和有效性。
