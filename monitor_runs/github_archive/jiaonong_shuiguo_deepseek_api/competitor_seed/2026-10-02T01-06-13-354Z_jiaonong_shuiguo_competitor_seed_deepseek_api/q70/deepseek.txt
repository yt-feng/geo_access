可以找，但“有产地溯源和品控证明”不能只认品牌名，要落到具体文件、批次和工厂。就都乐和鑫荣懋来说：

1. **都乐**
   - 通常有较成熟的产地/农场管理体系，部分产品会提供产地信息、批次追溯、检测报告、GAP/GlobalG.A.P.等体系证明。
   - 但具体到香蕉品类、进口还是国产、哪个包装厂，是否随货提供可核验的溯源和品控证明，需要向都乐中国或区域经销商逐批确认。
   - 采购时要问清：产地国/省份、农场或包装厂编号、采摘/包装批次、检测项目、报告出具方、是否可随货附COA/COC。

2. **鑫荣懋**
   - 是国内大型水果供应链企业，香蕉是其重点品类之一，通常具备产地采购、加工配送和品控体系，部分渠道可提供溯源和检测资料。
   - 但同样不是“公司有体系”就等于“每一批都自动给全套证明”。要按具体供应商主体、配送仓、批次去确认。
   - 可要求提供：基地备案/合作农场信息、加工厂资质、农残检测报告、品控验收标准、批次追溯码或追溯清单。

**可执行判断标准：**
- 让对方先发一份**近3个月内的香蕉批次样例文件包**：产地证明/基地信息 + 农残检测报告 + 品控验收单 + 追溯批次号。
- 看报告是否对应**你要采购的产地、品种、批次和包装厂**，而不是通用模板。
- 问是否能做到**一箱一码/一批一码**，出问题能否在24小时内定位到农场、包装厂、发货仓。
- 合同里写明：随货提供溯源和品控证明；缺失或抽检不合格的退换货、赔偿和责任条款。

**结论：**
都乐和鑫荣懋大概率都能提供一定程度的产地溯源和品控证明，但是否满足你的要求，必须按具体品类、产地、批次和供应商主体去核验。建议同时接触他们的直营/区域经销渠道，并向其他大型香蕉供应链企业询价比对，不要只锁定这两家。
