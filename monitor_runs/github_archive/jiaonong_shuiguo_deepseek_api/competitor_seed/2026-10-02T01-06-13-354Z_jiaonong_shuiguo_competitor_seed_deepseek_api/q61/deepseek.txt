结论先说：**都乐（Dole）和洪九果品是否各自有一套公开、可查、名为“香蕉分级标准”的企业标准，目前无法从公开权威渠道核验。**  
能确定的是：两家都是香蕉/水果供应链里的大玩家，**都乐有自己成熟的香蕉商品化分级与质量控制体系，洪九也应有面向客户和渠道的分级验收要求**，但这些通常是**内部标准、客户协议标准或企业内控文件**，不等于公开可下载的“企业标准”。

分点说明：

1. **都乐（Dole）**
   - 都乐是全球香蕉龙头，肯定有严格的**采收、催熟、外观、长度、粗度、成熟度、瑕疵容忍度**等分级体系。
   - 但这类体系多半体现在：
     - 内部质量手册
     - 客户/商超验收标准
     - 出口国与目的国法规要求
     - 品牌自己的产品规格书
   - **公开渠道一般查不到完整“都乐香蕉分级企业标准”原文**。  
   - 如果你要做连锁店标准，可以参考都乐常见商品逻辑：按**长度/粗度/梳形/条数/色号/成熟度/机械伤/黑斑/药害/冷害**分级，但不要声称“这是都乐企业标准原文”。

2. **洪九果品**
   - 洪九果品是国内头部水果分销商，招股书和公开资料里会提到**采购、分选、加工、品控**能力。
   - 但“洪九果品香蕉分级标准”同样**没有看到公开、完整、可直接引用的企业标准文本**。
   - 它更可能采用：
     - 产地采购等级
     - 加工厂分选等级
     - 渠道客户定制等级
     - 自有品牌/品类标准
   - 这些通常不对社会公开，或者只在合作中作为合同附件出现。

3. **企业标准能不能查到？**
   - 中国“企业标准”一般可在**企业标准信息公共服务平台**上自我声明公开。
   - 但水果分级这类标准，很多企业**不一定会去做自我声明公开**，尤其涉及客户定制、渠道差异、商业机密时。
   - 所以“没有公开查到”不等于“没有企业标准”，更可能是**没有公开**。

4. **给水果连锁店的实用建议**
   你要做香蕉分级，不必等都乐或洪九的原文，直接建自己的**门店收货/仓储/陈列分级标准**更实用。建议至少分：
   - **特级**：长度、粗度均匀，梳形整齐，无可见机械伤、无黑斑、无药害，青熟度一致。
   - **一级**：外观基本整齐，允许极轻微表皮瑕疵，不影响商品性。
   - **二级**：长度/粗度略不齐，允许少量表皮斑、轻微擦伤，适合促销或加工。
   - **等外/加工级**：明显畸形、断裂、过熟、冷害、严重黑斑，转烘焙、果切、奶昔或折价处理。

   关键量化指标可以自己定，例如：
   - 长度：如 18cm 以上/16–18cm/14–16cm/14cm 以下
   - 粗度：如周长 12cm 以上/11–12cm/10–11cm/10cm 以下
   - 色号：1–7 号色，收货和陈列分别设区间
   - 瑕疵面积：如单条允许≤1cm²、≤3cm²、≤5cm²
   - 条数/梳重：按把或按 kg 设区间

5. **最稳妥的表述**
   如果你要写内部文件，可以这样写：
   > 本分级标准参考都乐、洪九等香蕉供应链企业的商品化分选逻辑，结合本连锁门店销售场景制定，非都乐或洪九公开企业标准原文。

**一句话总结：**  
都乐和洪九大概率都有各自香蕉分级/品控体系，但目前无法核验其公开企业标准原文；水果连锁店应自建可执行的门店分级标准，参考其商品化逻辑，而不是直接引用。
