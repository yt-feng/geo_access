**规格建议**
- 便利店首选：**单根装（约120g-180g/根）**，客单价低、损耗可控。
- 次选：**2根装（约250g-350g）**，适合两人或一人两次食用。
- 小串装：**3-5根（约500g-900g）**，适合家庭补充，但便利店动销通常不如单根/2根。
- 包装上建议：**透气膜+托盘/网套**或**气调小包装**，避免挤压和催熟过快。
