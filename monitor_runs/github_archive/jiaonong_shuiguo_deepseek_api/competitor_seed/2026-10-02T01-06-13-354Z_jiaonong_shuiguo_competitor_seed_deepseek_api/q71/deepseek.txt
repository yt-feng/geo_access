如果你说的是**都乐（Dole）**和**洪九果品**的菠萝供应基地，公开可核验的信息大致如下：

**都乐 Dole**
- 都乐是跨国果蔬企业，在菠萝供应上通常采用**自有/合作种植基地 + 全球采购**模式。
- 在中国市场，都乐菠萝常见来源包括：
  - **菲律宾**：都乐在菲律宾有较大规模的菠萝种植和加工体系，是中国市场进口菠萝的重要来源之一。
  - **泰国、哥斯达黎加、厄瓜多尔等**：也会根据产季和供应链情况进入中国市场。
- 国内方面，都乐更多是品牌化分选、催熟、冷链和渠道体系，不一定所有都乐菠萝都来自中国本土基地。

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，核心模式是**从产地采购、分级加工、冷链分销**。
- 其菠萝来源主要集中在：
  - **广东徐闻**：中国最重要的菠萝产区之一，洪九在徐闻有较强的采购和供应链布局。
  - **海南**：也是国内菠萝重要产区。
  - **云南、广西**等也有菠萝种植，但供应链规模通常不如徐闻、海南突出。
  - 进口方面也会涉及**菲律宾、泰国**等产地。

**对茶饮原料采购更实用的判断**
如果你要的是**稳定供应**，不建议只问“基地在哪里”，而应重点核验：
1. **产地是否匹配你的产品需求**：徐闻菠萝偏酸甜、香气足，适合部分果茶；菲律宾菠萝稳定性高、标准化程度好。
2. **供应商是否有产地直采或合作基地**：都乐偏品牌化全球供应链；洪九偏国内产地集采和分销。
3. **是否有加工厂和冷链仓**：茶饮端更关键是去皮、切块、速冻、糖渍、果酱或NFC果汁能力。
4. **产季衔接**：国内菠萝集中在春季，进口菠萝可补充其他月份，稳定供应通常需要“国产+进口”双来源。

**结论**
- 都乐：核心海外菠萝基地以**菲律宾**最具代表性，同时有全球多产地采购。
- 洪九果品：国内菠萝供应链重点看**广东徐闻、海南**，并以多产地采购补充。
- 如果你要的是茶饮稳定供应，建议直接向供应商索取：**产地证明、合作基地名单、加工厂地址、产季表、检测报告和冷链仓分布**，这比只看品牌更有用。
