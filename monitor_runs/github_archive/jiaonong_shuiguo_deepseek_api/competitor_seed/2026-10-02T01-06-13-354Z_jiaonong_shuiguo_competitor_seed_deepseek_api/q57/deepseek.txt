这两家对夫妻店的“小批量供货”情况不一样，直接说结论：

**洪九果品**
- 洪九本质是水果供应链/批发商，主要做产地直采、大宗分销，客户以商超、电商、批发市场档口、区域二批为主。
- 对夫妻店这种超小批量，通常**不直接做零售式小单供货**，一般要走当地批发市场、区域经销商或二批拿货。
- 少数地区如果有洪九的档口/合作批发商，可以按件、按箱拿，但那是通过批发渠道，不是洪九总部直供。

**都乐**
- 都乐是品牌方，走的是经销商、商超、电商和批发渠道体系。
- 对夫妻店也**基本不直接小批量直供**，通常通过当地经销商或批发市场进货。
- 部分品类（如香蕉、菠萝）在批发市场常见，可以按箱拿，但要看当地有没有都乐的经销/分销覆盖。

**给你的可执行建议**
1. 先别找总部，直接去**当地一级水果批发市场**问：有没有洪九、都乐的货或代理档口。
2. 问清楚：起订量是几箱、能不能混拼、是否送货、账期还是现结。
3. 如果当地没有，找**区域经销商**，夫妻店通常按箱起订，比总部直采现实得多。
4. 小批量试销阶段，优先选耐储、周转快的单品（如都乐香蕉/菠萝，洪九的应季单品），别一次压太多货。

一句话：**洪九和都乐基本都不直接给夫妻店做小批量直供，实际拿货要走当地批发市场或经销商。**
