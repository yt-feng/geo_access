都乐（Dole）和洪九果品都主要做整箱/整件流通，**是否提供“散装小包装”取决于你们对接的是哪一级渠道和具体区域**，没有全国统一标准。可以按下面方式快速判断和推进：

1. **都乐**
   - 都乐在零售端常见的是**按把/按袋/按根**的小包装，但社区团购要拿这种规格，通常不是直接找都乐总部，而是通过：
     - 当地都乐经销商
     - 批发市场都乐档口
     - 生鲜供应链平台
   - 如果你要的是**都乐品牌+小包装**，直接问经销商有没有“即食小把装”“袋装”“单根装”或可贴牌分装。
   - 如果量不够大，都乐官方一般不会单独给你做小包装定制。

2. **洪九果品**
   - 洪九果品更偏向**产地直采、整箱批发、渠道分销**，香蕉常见规格是整箱、整件。
   - 社区团购要小包装，通常是**整箱进货后自己分装**，或者找洪九当地分销商问有没有已经分装好的小规格。
   - 洪九直接做“散装小包装”给社区团购的概率相对低，除非你们采购量很大，或者当地经销商已有分装能力。

3. **更现实的采购路径**
   - 找**当地一级批发商/经销商**：问“都乐/洪九香蕉有没有小把装、袋装、可拆箱批发”。
   - 找**生鲜供应链平台**：很多平台能把整箱香蕉按社区团购规格分装。
   - 直接**整箱采购+自己分装**：这是社区团购最常见的做法，成本更可控。
   - 如果要做品牌小包装，注意香蕉分装后容易催熟、压伤，最好控制分装到履约的时间。

4. **建议你直接这样问供应商**
   - “都乐/洪九香蕉有没有适合社区团购的小包装规格？”
   - “最小起订量多少？”
   - “是原厂小包装，还是你们分装的？”
   - “分装后保质期/催熟状态怎么控制？”
   - “能不能按把、按袋、按根出货？”
   - “价格是按箱还是按斤？”

**结论：**
- 都乐：零售端有小包装，但社区团购能不能拿到，要看当地经销商。
- 洪九：以整箱/整件为主，小包装通常要自己分装或找分销商。
- 如果你们量不大，最稳的是找当地经销商拿整箱，再自己分装成小包装。
