关于鑫荣懋和都乐在冷链物流方面的具体覆盖城市，我无法给出完整、准确的清单。这类信息属于企业具体的物流网络数据，不同品类、不同客户项目下覆盖范围也可能不同，而且会随年份调整，公开渠道很难核实到权威且完整的口径，我不能凭印象列城市名单。

不过可以给你几个可执行的做法：

1. **直接向对方索要冷链网络资料**
   让鑫荣懋或都乐的对接销售/商务提供：
   - 冷链配送覆盖城市清单（区分常温/冷藏/冷冻）
   - 是否有自建冷链或外包承运商
   - 各地仓配中心位置
   - 能否满足你商超系统的到店/到仓时效

2. **按你的实际门店城市去问，而不是要全景清单**
   把你商超的门店城市或DC地址列出来，让对方逐城确认“能不能冷链直送、时效几天、温度区间”。这比问“覆盖哪些城市”更可验证。

3. **核验冷链资质**
   可要求提供：
   - 冷链运输车辆/温控设备证明
   - 仓储温区证明
   - 第三方物流承运合同或合作证明
   - 过往同类商超客户的配送案例

4. **做小范围试配**
   选1-2个城市或1个DC先试运行，看温度记录、到货时效、损耗率，再决定是否全面合作。
