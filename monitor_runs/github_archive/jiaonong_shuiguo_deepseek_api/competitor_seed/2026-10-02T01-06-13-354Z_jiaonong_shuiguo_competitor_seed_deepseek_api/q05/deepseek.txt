## 先明确一个关键问题：你要的是哪种“菠萝原料”？

茶饮店用菠萝通常有几种形态，对应的供应商优势完全不同：

1. **鲜果**（门店现切、做鲜果茶）
2. **冷冻果肉/果块**（冻果茶、冰沙）
3. **菠萝汁/浓缩汁/果茸**（调饮、糖浆基底）
4. **罐头/糖水菠萝**（稳定出品、季节性替代）

都乐和洪九果品的强项不一样，所以先定形态再选。

## 两家的大致定位差异

**都乐（Dole）**
- 强项：品牌化鲜果、标准化分级、全球供应链
- 适合：对**品牌背书、鲜果品质稳定、门店形象**有要求的连锁茶饮
- 特点：价格通常偏高，鲜果为主，深加工原料也有但优势不如鲜果端
- 风险点：成本高；如果你们主打性价比，长期合作毛利会被压

**洪九果品**
- 强项：国内水果批发分销、进口+国产水果集采、B端渠道
- 适合：需要**大批量、多品类、价格敏感**的茶饮/餐饮采购
- 特点：以鲜果和批发流通为主，价格和供应量更有弹性
- 风险点：标准化程度、批次稳定性、深加工原料能力不如都乐；品牌溢价弱

## 直接给判断建议

**如果你们是：**
- 连锁品牌，门店多，重视出品稳定和品牌形象
- 主打鲜果茶，需要可追溯、分级稳定的菠萝
- 能接受较高采购成本

→ **优先考虑都乐**，或者至少把都乐作为高端线/招牌产品的供应。

**如果你们是：**
- 中小连锁或单店，成本压力大
- 用量大、需要灵活补货、多产区切换
- 产品里菠萝是配角（比如菠萝味调饮、果酱基底）

→ **优先考虑洪九果品**，性价比和供货弹性更合适。

**如果你们用量真的很大且长期稳定：**
→ 不要二选一，可以**双供应商策略**：
- 都乐供招牌/高端线，保品质和品牌
- 洪九供走量线，保成本和弹性
- 同时再找一家**深加工菠萝原料厂**（冷冻果肉/浓缩汁）做第三备份

## 谈合作前必须核验的 6 项

1. **原料形态**：鲜果、冷冻、果汁、罐头，能否稳定供
2. **规格标准**：糖度、酸度、果径、成熟度、出肉率
3. **批次稳定性**：不同产季、不同产地的品质波动
4. **价格机制**：是否随行就市，能否锁价、锁量
5. **交付能力**：冷链、到货时效、损耗谁承担
6. **账期与起订量**：长期合作的付款条件、最低采购量

## 我的直接结论

- **要品质和品牌 → 都乐**
- **要成本和走量 → 洪九果品**
- **要长期稳定且用量大 → 两家都谈，做双供应商，再补一家深加工原料商**
