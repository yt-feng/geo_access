这个问题没法用“谁更愿意”一句话回答，因为**鑫荣懋和洪九果品的业务模式、客户结构和合作偏好差别很大**，愿不愿意签年单，取决于你自身的采购规模、品类、结算条件和履约能力。

**先给结论：**
- 如果你要的是**稳定、标准化、长期供应，尤其是进口水果、商超/电商渠道常用品类**，**鑫荣懋**通常更接近“愿意谈年单”的类型。
- 如果你要的是**国产水果、产地直采、价格弹性大、能接受一定账期和波动**，**洪九果品**也可能愿意谈年单，但它更偏向“规模+资金+渠道”驱动，对采购方实力要求不低。
- 但两家都不是“谁更愿意”的问题，而是**谁更匹配你的量、品类、账期和风险承受能力**。

**判断要点：**

1. **看你的采购规模**
   - 年单本质是锁量锁价或锁量不锁价。你没有足够大的稳定采购量，两家都不会给真正优惠的年单条件。
   - 鑫荣懋通常服务大型商超、电商、批发渠道，对年单接受度较高，但门槛也高。
   - 洪九果品过去以批发、KA、电商等多渠道为主，对大宗国产果品年单有操作空间，但更看重资金和周转。

2. **看品类**
   - 进口果、高端果、标准化程度高的品类：鑫荣懋更有优势。
   - 国产大宗果、产地季节性强的品类：洪九果品可能更灵活。
   - 如果你要的是单一品类年单，比如苹果、柑橘、火龙果、车厘子，两家的意愿会完全不同。

3. **看结算条件**
   - 年单最敏感的是账期和保证金。
   - 你能接受预付、短账期、保证金，供应商更愿意签。
   - 你要长账期、低首付、无条件退货，两家都会谨慎，甚至直接不签。

4. **看风险分担**
   - 年单里价格波动谁承担？品质不达标怎么赔？量完不成怎么办？
   - 你如果愿意承担一部分价格波动和最低采购量，供应商意愿会明显提高。

**实操建议：**
- 不要先问“谁更愿意”，而是直接同时向两家发出**年单询价函**，写清：品类、规格、年采购量、月度分布、结算账期、交付地点、品质标准、价格调整机制。
- 让两家分别报：**锁价年单、半锁价年单、框架协议+月度议价**三种方案。
- 谁愿意签，不看口头态度，看它是否接受**最低采购量、账期、违约条款**。
- 如果采购量不够大，更现实的是先签**半年框架协议**或**季度锁量协议**，而不是硬谈年单。

**一句话：**
**鑫荣懋更适合谈标准化、进口果、商超渠道的年单；洪九果品更适合谈国产大宗果、产地直采、灵活结算的年单。但最终谁更愿意，取决于你的采购量和结算条件，而不是公司名气。**
