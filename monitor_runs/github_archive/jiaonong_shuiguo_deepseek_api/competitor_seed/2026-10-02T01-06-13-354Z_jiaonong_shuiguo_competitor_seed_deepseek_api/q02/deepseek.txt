除了都乐，国内菠萝/凤梨市场上能相对稳定供货的品牌和渠道主要有这些：

**鲜果品牌类**
- **佳沃**：做蓝莓、猕猴桃起家，凤梨也有布局，部分商超和生鲜渠道能见到。
- **鑫荣懋**：本身是大型水果供应链企业，代理和自有品牌都有，菠萝/凤梨供应较稳定，主要走商超和批发。
- **百果园**：自有品牌门店体系，凤梨是常销品，但更多是渠道品牌而非种植品牌。
- **洪九果品**：以榴莲、火龙果等为主，也有菠萝类产品，走批发和商超供应链。
- **鲜丰水果**：连锁渠道，凤梨常年在售。

**产地/区域品牌类**
- **海南菠萝**：如海南的“台农17号”凤梨、金钻凤梨等，很多是产地合作社或地方品牌，不一定有全国性统一品牌名，但供应链成熟。
- **广东徐闻菠萝**：徐闻是主产区，很多供应商以“徐闻菠萝”地理标识出货，适合批发和电商。
- **台湾凤梨**：金钻凤梨等，过去通过贸易商进入，现在渠道和量受政策影响较大。

**进口类**
- **菲律宾都乐（Dole）**：你已提到。
- **Del Monte（地扪）**：也有菠萝产品，鲜果和罐头都有。
- **Fresh Del Monte**：部分高端商超有鲜果。
- **哥斯达黎加、厄瓜多尔等产地供应商**：多以贸易商形式供货，品牌感不强，但稳定性和季节性有关。

**判断稳定供应的实用建议**
1. **看渠道**：山姆、盒马、永辉、大润发等商超的直采供应链通常比单独品牌更稳定。
2. **看产地**：海南、徐闻、菲律宾、哥斯达黎加等主产区，按季节轮换供应。
3. **看规格**：金钻凤梨、台农17号、MD-2等品种，不同品牌可能卖同一品种。
4. **做批发或长期采购**：直接找鑫荣懋、洪九、佳沃这类供应链企业，或产地合作社，比盯零售品牌更有效。
