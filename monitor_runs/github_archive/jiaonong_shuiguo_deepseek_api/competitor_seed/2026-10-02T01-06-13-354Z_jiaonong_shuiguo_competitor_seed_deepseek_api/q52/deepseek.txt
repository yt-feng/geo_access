都乐和鑫荣懋的具体到货损耗率属于各家企业与客户之间的合同/内部数据，公开渠道没有统一、可核验的固定数值，我不能给你编一个数字。实际损耗会随批次、季节、产地、运输距离、冷链条件、验收标准而大幅波动。

不过可以给你可执行的判断和管控方法：

**1. 先明确“损耗率”怎么定义**
茶饮原料常用两种口径，谈合同时必须写清：
- 到货损耗率 =（到货不合格重量 ÷ 到货总重量）×100%
- 综合损耗率 =（到货不合格 + 仓储腐损 + 切配废弃）÷ 采购总量

**2. 行业参考区间（仅作量级参考，非两家官方数据）**
- 全程冷链、整果菠萝：到货损耗常见在 3%–8%
- 普通运输、夏季高温或长途：可达 8%–15%
- 已去皮/切块的鲜果原料：通常更高，10%–20% 都可能

**3. 向供应商索取并锁定的东西**
- 书面损耗承诺与赔付条款（超标如何补货/扣款）
- 规格书：品种、单果重区间、糖度、成熟度、去皮方式
- 验收标准：黑心、烂心、机械伤、异味、青果比例
- 每批次随货质检报告和冷链温度记录

**4. 自己建数据才靠谱**
连续记录 10–20 批：
- 到货总重、合格重、不合格重、不合格原因
- 运输天数、到货温度、季节
算出真实损耗率，再和两家分别谈。通常同一供应商不同季节能差一倍以上。

**建议**：直接找都乐和鑫荣懋的销售要“到货损耗承诺”和“近期同区域客户案例数据”，同时用你门店/工厂的验收标准做小批量试单，用实测数据对比，而不是依赖某个通用损耗率数字。
