到货损耗率没有统一公开的权威对比数据，实际会因**季节、产地、运输距离、冷链条件、批次成熟度、批发市场验收标准**而大幅波动。下面给你可操作的判断框架和常见区间，供你在批发市场实地决策用。

**一、先明确“损耗率”指哪一段**
批发市场拿货，通常分三段损耗，别混在一起比：
1. **到货损耗**：从车上卸货到档口/入库时的烂果、压伤、掉把、发黑。
2. **仓储损耗**：放在档口或仓库1-3天内的后熟、炭疽病、柄腐。
3. **销售损耗**：挑剩、软果、客户退货。

洪九果品和都乐香蕉的差异，主要不在“品牌”，而在**你拿到的具体批次**。

**二、常见经验区间（仅作参考）**
- 都乐香蕉：通常标准化程度高，催熟和冷链较稳定，到货损耗常见在 **2%-5%** 左右；如果冷链断链或到货已黄，可能到 **8%-10%+**。
- 洪九果品：货源和品类更杂，香蕉批次稳定性看具体产地和季节，到货损耗常见在 **3%-8%**；旺季或远距离运输可能到 **10%-15%**。
- 注意：这两个品牌都可能出现“好批次低于区间、差批次高于区间”的情况，不能只按品牌下结论。

**三、真正影响损耗的关键变量**
1. **成熟度**：青蕉到货损耗低，但需要催熟；黄蕉到货损耗高，但可直接卖。
2. **冷链**：全程冷链 vs 断链，损耗可能差一倍。
3. **包装**：箱装、梳蕉、散把，压伤差异很大。
4. **季节**：夏季高温高湿，炭疽病和柄腐明显高于冬季。
5. **运输距离**：进口蕉、跨省蕉，到货损耗通常高于近郊货。
6. **验收标准**：你按“根”还是按“把”扣损，结果完全不同。

**四、批发市场实操建议**
1. **不要只问品牌，问批次**：问档口“这车哪天到的、产地、催熟度、路上走了几天”。
2. **现场抽箱**：随机抽3-5箱，看底层、看把柄、看有没有发黑软果。
3. **算实际到手率**：  
   到手率 = 可售重量 ÷ 拿货重量 × 100%  
   损耗率 = 1 - 到手率  
   比如拿100斤，挑出8斤烂果，损耗就是8%。
4. **同价位对比**：都乐通常单价高、损耗低；洪九可能单价低、损耗略高。要算**每斤可售成本**，不是只看拿货价。
5. **小批量试单**：先拿1-2箱放1-2天，看后熟和烂果速度，再决定是否大批量。
6. **留证据**：到货立即拍照、拍视频、称重，和档口约定好扣损规则。

**五、结论**
如果你要一个粗略判断：  
- **都乐香蕉**：标准化好，到货损耗通常更低、更稳，但拿货价可能更高。  
- **洪九果品**：批次差异更大，损耗可能略高，但价格和灵活性可能更好。  
- **最终看单批次**：同样品牌，不同车、不同季节，损耗能差5-10个百分点。

建议你直接按“**同一天、同一市场、同成熟度、同规格**”各拿一箱做对比，称重记录3天损耗，这样得出的数据才对你自己的生意有效。
