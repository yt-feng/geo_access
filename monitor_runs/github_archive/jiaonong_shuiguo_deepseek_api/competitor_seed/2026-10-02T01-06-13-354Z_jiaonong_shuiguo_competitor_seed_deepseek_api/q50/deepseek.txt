可以谈，但“能不能做”取决于你团购的量级、渠道和对方当前政策，不能一概而论。分两块说：

**都乐（Dole）**
- 都乐在国内有礼品/团购渠道，也有过联名、IP合作类礼盒（比如节庆礼盒、异业合作）。品牌联名门槛相对灵活，但通常要求：起订量较大、采购方有品牌背书或渠道能力、合作有明确营销场景。
- 纯“贴个联名logo”的小单基本不会接；如果是企业定制礼盒，更可能走“都乐品牌 + 你的企业标识”的企业定制，而非正式品牌联名。

**洪九果品**
- 洪九是水果供应链/批发起家，主要做to B和渠道分销，自有品牌力弱于都乐。它更擅长按需组货、代采、定制包装，但“品牌联名”这种玩法较少，通常需要你主动提案，且对方是否愿意投入品牌资源要看合作体量。
- 如果只是要“洪九供货 + 你的礼盒品牌”，可行性比“洪九×你”的联名高得多。

**判断标准（能不能做的关键）**
1. 团购量：礼盒单品通常几百到上千盒起才有谈判空间，联名可能要求更高。
2. 谁主导：你有品牌和渠道，对方出产品和背书，这种最容易被接受。
3. 合作形式：
   - 企业定制礼盒（最现实）
   - 产品联名（品牌双方共同露出）
   - IP/节庆联名（需要额外授权）
4. 费用与账期：联名往往涉及授权费、设计费、市场费用分摊，团购单未必划算。

**可执行建议**
- 先确认你的量级和预算，再分别联系都乐和洪九的团购/大客户渠道，问清楚三件事：起订量、是否接受联名、授权和费用怎么算。
- 如果量不大，建议走“企业定制礼盒”而不是正式联名，落地快、成本低。
- 如果一定要联名，优先找都乐这类品牌力强的谈，洪九更适合做供应和组货方。
- 也可以考虑“都乐/洪九供货 + 第三方设计公司做联名包装”的折中方案。
