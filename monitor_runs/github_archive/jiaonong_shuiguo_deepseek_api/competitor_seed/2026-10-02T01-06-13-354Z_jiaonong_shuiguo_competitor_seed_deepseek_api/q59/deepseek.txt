都乐（Dole）和洪九果品都是大型香蕉供应商，但两者的合作模式和账期政策差异较大，需要分开说明：

**都乐（Dole）**
- 都乐在中国的业务以品牌授权、直营和经销商体系为主，通常不对中小客户直接提供账期，多为现款现货或预付。
- 对大型商超、连锁渠道，账期一般通过年度框架合同约定，常见在 **30～60 天** 左右，具体取决于采购量、合作年限和渠道类型。
- 中小批发商、电商客户基本拿不到账期，需要现结。

**洪九果品**
- 洪九果品是国内较大的水果供应链企业，香蕉是其核心品类之一，客户包括商超、电商、批发市场等。
- 对稳定合作的大客户，账期通常在 **15～45 天**，部分核心客户可谈到 **60 天**。
- 对新客户或中小客户，一般要求现款或短账期（7～15 天），部分情况需要保证金。

**实际建议：**
1. 账期不是公开统一标准，而是**一客一议**，取决于采购量、合作稳定性、结算方式和信用评估。
2. 想拿账期，最好直接联系两家公司的**大客户部或供应链金融部门**，而不是普通销售。
3. 如果你们采购量不大，建议优先找**一级批发商或区域代理商**，他们比品牌方更灵活，可能给到 15～30 天账期。
4. 注意：水果行业账期通常伴随**价格上浮**或**保证金要求**，谈账期时要同时确认单价和违约责任。
