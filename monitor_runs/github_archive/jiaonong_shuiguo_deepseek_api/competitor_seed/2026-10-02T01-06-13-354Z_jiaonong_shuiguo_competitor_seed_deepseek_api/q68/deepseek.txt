直接结论：**不能简单说“都乐”或“鑫荣懋”一定能做到，也不能说一定做不到。香蕉到货损耗率能否低于3%，主要取决于你们的验收标准、运输半径、冷链条件、季节和采购合同，而不是只看品牌。**

先说行业实际水平：

- 香蕉是呼吸跃变型水果，对温度、乙烯、机械伤非常敏感。
- 到货损耗率低于3%，在餐饮连锁里属于**偏严**的指标。
- 如果是**同城/短途、全程冷链、青蕉到货、门店或中央厨房验收**，3%以内是有可能做到的。
- 如果是**跨省长途、常温运输、黄蕉到货、多次装卸**，3%以内难度很大，行业里更常见的是3%到8%，夏季或管理不好会更高。

关于都乐和鑫荣懋：

- **都乐**：品牌化、标准化程度高，部分品类和渠道有较强冷链和品控能力，但香蕉业务在不同区域可能由不同经销商或配送商执行，实际到货损耗要看具体承接方。
- **鑫荣懋**：国内水果供应链头部企业，香蕉是其重要品类之一，仓储、催熟、配送能力较强，但同样要看具体区域、仓配模式和合同约定。
- 两家都能在**特定条件下**承诺或接近3%，但通常不会无条件对所有客户、所有区域承诺“到货损耗低于3%”。

建议你们这样判断和落地：

1. **先定义清楚“到货损耗率”**
   - 是按重量算，还是按箱数/条数算？
   - 是否包含压伤、断裂、黑斑、青软、霉变？
   - 验收时点是在卸货前、卸货后，还是门店上架前？
   - 定义不清，3%没有可比性。

2. **要求供应商提供近3到6个月数据**
   - 同区域、同运输距离、同季节的到货损耗记录。
   - 不要只看全国平均值，要看你们所在城市和配送仓的数据。

3. **用试单验证**
   - 先做1到2个月、多批次试单。
   - 每批记录：发货成熟度、运输温度、到货温度、损耗重量、损耗原因。
   - 连续10批以上，才能判断是否稳定低于3%。

4. **合同里写清责任和赔付**
   - 到货损耗超过3%的部分如何扣款、补货或退款。
   - 因催熟度、冷链断链、压伤导致的损耗由谁承担。
   - 是否允许供应商用“自然失水”排除部分重量。

5. **考虑调整采购策略**
   - 如果3%是硬指标，建议采购**青蕉或微黄蕉**，到店后再催熟。
   - 缩短配送半径，减少装卸次数。
   - 要求全程冷链，尤其夏季。
   - 中央厨房统一验收，比分散到门店验收更容易控制。

一句话：**都乐和鑫荣懋具备做到低于3%的能力，但能否对你们稳定做到，取决于区域、链路、季节和合同条款。最稳妥的方式不是听承诺，而是让他们拿同区域历史数据，再用试单和赔付条款锁定。**
