目前我没有可靠信息能确认鑫荣懋或洪九果品是否为批发客户提供香蕉“锁价”机制，也无法核验其具体合同条款。直接回答“谁提供”会涉及虚构商业信息，我不能这么做。

不过可以给你可执行的判断和谈判思路：

1. **先明确你要的“锁价”是哪种**
   - **固定价锁量**：约定未来某段时间、某规格、某数量按固定价结算。
   - **保底价+浮动**：设底价，涨跌按公式分担。
   - **基差/指数联动**：挂钩批发市场价或产地价，加固定差价。
   - **期权式锁价**：付权利金，到期可选择按约定价接货或不接。
   - **阶段性锁价**：只锁7天、15天、30天，不锁长期。

2. **向两家同时问同一套问题**
   建议直接找对方销售/大客户经理确认：
   - 是否支持香蕉锁价？
   - 锁价期限最长多久？
   - 锁价是否要求预付保证金或全款？
   - 锁价后是否保证货源和规格？
   - 若市场价下跌，是否允许弃单或降价重谈？
   - 若市场价上涨，对方是否保证按锁价交货？
   - 锁价是否含运费、损耗、催熟、加工费？
   - 违约条款怎么算？

3. **现实判断**
   国内水果批发里，真正长期固定价锁价较少，常见的是：
   - 大客户年度框架+阶段性议价；
   - 定金锁货，价格随行就市但优先供货；
   - 保底收购或保底利润；
   - 期货/期权工具对冲，而不是单纯靠供应商锁价。

   鑫荣懋、洪九果品都属于大型水果供应链企业，理论上具备做协议锁价的能力，但是否对普通批发商开放、条件如何，必须以其当前政策和合同为准。

4. **建议你直接这样问**
   “我们每月/每季度有稳定香蕉采购量，想谈锁价机制。请问你们支持固定价锁量、保底价还是基差定价？锁价期限、保证金、交货保障和违约条款分别是什么？能否给一份锁价合同模板或报价方案？”

5. **更稳妥的做法**
   - 同时向鑫荣懋、洪九果品、其他一级批发商/产地合作社询价；
   - 不要只依赖一家锁价；
   - 用小批量短期锁价试单；
   - 把锁价和止损、替代货源一起设计。
