除了都乐和佳沛，进口水果礼盒常见可选品牌主要集中在这几类，按团购场景比较实用：

**1. 综合进口水果品牌**
- **新奇士/Sunkist**：美国柑橘类代表，脐橙、夏橙等礼盒较常见，适合企业福利。
- **爱妃/Envy**：新西兰苹果品牌，礼盒装辨识度高，适合中高端团购。
- **爵士/Jazz**：新西兰苹果品牌，口感脆甜，常和爱妃一起出现在高端礼盒里。
- **红玫瑰/Queen Rose**：苹果类进口品牌，部分渠道有礼盒。
- **Mr. Apple**：新西兰苹果品牌，部分精品渠道有售。

**2. 高端葡萄/提子类**
- **Driscoll's 怡颗莓**：虽然以浆果出名，但蓝莓、树莓、黑莓礼盒在团购中很常见，品牌认知度高。
- **Sun World**：专利葡萄品种品牌，如秋脆等，部分进口提子礼盒会标注。
- **IFG**：葡萄品种品牌，如甜蜜蓝宝石等，礼盒端有出现。

**3. 车厘子/樱桃类**
- **Stemilt**：美国车厘子品牌，季节性强，礼盒常见。
- **Chelan Fresh**：美国车厘子品牌。
- **Rainier**：雷尼尔樱桃品牌/品种，高端礼盒常见。
- **Cherry Burst**：部分车厘子礼盒品牌。

**4. 奇异果/其他**
- **佳沛/Zespri**：你已提到，仍是奇异果礼盒主力。
- **都乐/Dole**：你已提到，综合性强。
- **SanLucar**：欧洲果蔬品牌，部分精品超市有进口礼盒。
- **Del Monte 地扪**：综合水果品牌，部分礼盒渠道有。

**5. 精品渠道常见但偏“品牌+品种”**
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装很适合团购。
- **Pink Lady 粉红佳人**：苹果品牌，礼盒有辨识度。
- **Aomori 青森**：日本苹果产区品牌，高端礼盒常见。
- **Sekai Ichi 世界一**：日本苹果，高端团购偶尔用。

**团购选品建议：**
- 预算中等、走量：新奇士、都乐、佳沛、怡颗莓。
- 中高端福利：爱妃、乐淇、爵士、粉红佳人。
- 高端商务：青森苹果、雷尼尔樱桃、精品提子礼盒。
- 注意季节：车厘子、提子、柑橘类季节性强，团购前要确认产季和到货稳定性。

另外，很多所谓“进口品牌”实际是品种品牌或产区品牌，不一定有统一礼盒。团购时重点看：原产地证明、品牌授权、规格一致性、损耗赔付和冷链时效。
