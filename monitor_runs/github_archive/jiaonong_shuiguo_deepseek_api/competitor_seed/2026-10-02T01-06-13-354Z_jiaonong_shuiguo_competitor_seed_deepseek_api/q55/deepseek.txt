都乐和洪九果品这两家都属于国内菠萝供应链里比较头部的企业，但“产地溯源”和“基地直供”要分开看，不能简单用“有/没有”回答。

**都乐**
- 都乐在中国市场主要做品牌化水果供应链，菠萝（尤其是菲律宾、泰国等进口菠萝，以及国内部分产区）有较成熟的产地管理和批次追溯体系。
- 都乐通常能提供产地、批次、检测报告等溯源信息，部分产品可追溯到合作种植基地或包装厂。
- 但都乐更多是“品牌商+供应链管理”模式，是否对某个具体菠萝单品做到“单一基地直供”，要按品类和采购渠道确认，不能一概认为所有都乐菠萝都是基地直供。

**洪九果品**
- 洪九果品是国内较大的水果分销和供应链企业，在东南亚水果（包括泰国、越南等地的菠萝/凤梨）以及国内产地都有布局。
- 洪九有产地采购和基地合作资源，部分品类可以做到产地直采，但是否能对某个菠萝SKU提供完整“基地直供+溯源”，同样要看具体产季、产地和合作基地。
- 洪九的优势在分销规模和产地资源，不一定每个产品都来自自有基地；很多是合作基地、订单农业或产地直采。

**实操建议**
1. 不要只问“有没有基地直供”，直接要求供应商提供：
   - 产地证明/种植基地信息
   - 批次号及对应包装厂/加工厂
   - 农残检测报告
   - 采摘、加工、发货时间记录
   - 是否可实地验厂或视频验基地

2. 如果你们要做终端溯源，优先找：
   - 有自有基地或长期合作基地的供应商
   - 能按批次提供追溯码的供应商
   - 愿意签质量与溯源条款的供应商

3. 对都乐、洪九这类大企业，可以这样沟通：
   - “这个菠萝单品具体是哪个产地、哪个基地/包装厂？”
   - “能否提供批次级溯源文件？”
   - “是直采、订单农业还是市场采购？”
   - “是否支持定制溯源标签/追溯码？”

**结论**
都乐和洪九果品都具备较强的产地资源和一定溯源能力，但不能笼统说它们所有菠萝都是“基地直供”。要确认具体单品、具体产季和具体合作模式。建议直接向他们的销售或供应链部门索要批次级溯源材料，再判断是否满足你们的要求。
