如果客户明确指定“进口品牌”，**都乐和佳沛都算常见进口水果品牌，但礼品团购场景里通常佳沛更受欢迎、更容易被认可**，尤其是预算中等偏上、送客户/员工福利时。

可以这样判断：

1. **品牌认知**
   - **佳沛**：奇异果领域的进口品牌心智很强，很多人默认“佳沛=进口奇异果”，礼盒看起来更专业、更统一。
   - **都乐**：品牌也强，但产品线更宽，有菠萝、香蕉、柑橘、苹果等，礼盒容易显得偏综合水果，不一定有佳沛那么强的“进口高端感”。

2. **礼品团购受欢迎度**
   - 如果客户要的是**进口水果礼盒、送人体面、认知度高**：优先选**佳沛**。
   - 如果客户要的是**预算更灵活、品类丰富、众口好调**：都乐也可以，但要注意都乐有些产品是国内分装或国产基地，不一定是纯进口。

3. **实际采购要注意**
   - 佳沛常见规格：22粒、25粒、30粒、33粒等，礼盒装和原箱装差异大。
   - 都乐礼盒可能混装，采购前要确认：**是否整盒进口、产地、规格、是否贴牌分装**。
   - 团购客户如果指定“进口品牌”，最好让供应商提供：**报关单、产地证明、品牌授权或采购凭证**。

4. **建议**
   - **送重要客户/领导/高端福利**：选**佳沛金果或绿果礼盒**，更稳。
   - **普通员工福利/预算控制**：都乐可以，但建议选明确标注进口产地的单品礼盒，不要混装太杂。
   - **不确定客户偏好时**：佳沛认知度更高，出错概率更低。

结论：**礼品团购客户指定进口品牌时，佳沛通常比都乐更受欢迎，尤其在中高端礼盒场景。** 但最终要看预算、规格和是否要求纯进口。
