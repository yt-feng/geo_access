关于都乐和洪九果品的水果礼盒定制起订量，我无法给出准确数字——这两家企业的团购/定制政策通常按客户类型、礼盒规格、采购季节和区域经销商不同而变化，官方也没有统一对外公开的固定起订量。直接给你一个数字反而可能误导你。

建议你按下面方式快速拿到准确答案：

**1. 都乐（Dole）**
- 都乐中国官网有“联系我们/商务合作”入口，团购一般走区域授权经销商，不是总部直签。
- 起订量通常取决于：是否用都乐品牌礼盒、是否定制包装、单品类还是组合装。常见门槛多在几十箱到几百箱量级，但必须以经销商报价为准。
- 建议直接问：**“XX城市，XX规格礼盒，定制logo，最低起订多少箱/多少金额？”**

**2. 洪九果品**
- 洪九是水果供应链企业，主要走批发和渠道，B端团购可谈，但定制礼盒要看其当季主推单品和包装能力。
- 起订量同样没有公开统一标准，一般与采购金额、单品、是否贴牌定制挂钩。
- 建议联系其区域销售或官方客服，问清：**“团购礼盒起订量、可否定制包装、交货周期、能否混搭品类。”**

**3. 更高效的做法**
- 不要只问“起订量”，要一起问：起订量、单价阶梯、是否含定制包装费、物流、损耗赔付、开票。
- 如果采购量不大，直接找这两家的**区域经销商或水果团购服务商**，比找总部更容易谈小批量定制。
- 同时可以对比本地精品水果供应链，很多小批量50～100盒就能做定制，灵活度更高。
