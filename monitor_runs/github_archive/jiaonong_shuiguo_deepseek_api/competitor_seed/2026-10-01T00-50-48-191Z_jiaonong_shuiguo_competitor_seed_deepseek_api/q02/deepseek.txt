国内菠萝/凤梨供应链里，除了都乐（Dole），以下品牌或产地供应商通常能较稳定供货，具体取决于你要的是鲜果批发、商超渠道还是电商一件代发：

**国际品牌/大型果蔬商**
- **佳农（Goodfarmer）**：国内菠萝进口和国产凤梨供应量很大，商超、电商都常见，稳定性较强。
- **鑫荣懋（Joyvio）**：水果供应链头部企业，做进口菠萝和国产精品凤梨，B端供货能力较强。
- **百果园**：自有渠道品牌，也有产地直采的凤梨/菠萝，主要走门店和线上。
- **鲜丰水果**：类似百果园，区域性供应稳定，但更偏零售端。
- **洪九果品**：以东南亚水果见长，菠萝/凤梨有进口和分销能力。
- **佳沃（Joyvio旗下）**：部分水果品类有布局，菠萝不是其最核心单品，但可关注。

**国产凤梨/菠萝主产区品牌或供应商**
- **海南**：澄迈、万宁、陵水、乐东等地的凤梨/菠萝供应商，常见品种有“台农17号”（金钻凤梨）、“台农16号”（甜蜜蜜）、“香水菠萝”等。海南货期集中在每年2—6月。
- **广东**：徐闻菠萝最有名，主产“巴厘菠萝”，也有台农系列。徐闻县内有不少合作社和农业公司可稳定供货。
- **云南**：西双版纳、河口等地有反季节或早春菠萝，可补充海南货期空档。
- **福建**：漳州等地也有菠萝种植，但规模和品牌化程度不如海南、广东。
- **广西**：部分区域有菠萝种植，更多作为补充产地。

**如果按渠道选**
- **商超/连锁水果店**：佳农、鑫荣懋、百果园、鲜丰、洪九较常见。
- **电商一件代发**：可找海南、徐闻产地合作社或供应链公司，如“徐闻菠萝”“海南金钻凤梨”产地直发商家。
- **批发市场**：北京新发地、上海辉展、广州江南市场等，常见佳农、鑫荣懋及产地直供档口。
- **深加工/餐饮原料**：可找罐头或速冻菠萝供应商，如欢乐家、林家铺子等，但这是加工品，不是鲜果。

**判断“稳定供应”的关键**
1. **货期**：海南、广东、云南、进口菲律宾/泰国菠萝的上市时间不同，单一产地很难全年稳定。
2. **品种**：都乐常见的是金菠萝/MD-2；国产稳定替代可看金钻凤梨、甜蜜蜜、徐闻巴厘。
3. **规格**：按果重、糖度、是否去眼、是否即食分等级。
4. **合作方式**：产地合作社适合量大直采；供应链公司适合多品种拼柜、商超配送。

如果你是要做批发或电商，建议优先对接：**佳农、鑫荣懋、洪九**这类供应链商，再搭配**海南/徐闻产地合作社**做季节补充。这样比只依赖单一品牌更容易全年稳定。
