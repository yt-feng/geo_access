直接给结论：**都乐（Dole）更可能有现成的香蕉小包装方案；洪九果品更偏大宗批发和渠道分销，便利店小包装的标准化零售产品相对少。** 但这两家是否在你所在区域、以什么规格供货，取决于当地经销体系，需要具体问。

判断依据：

- **都乐**：做品牌化零售水果，香蕉有按根、按把、小包装的零售规格，在便利店、商超渠道铺得比较成熟。你找它更像找“现成的零售商品”，可以直接问区域经销商有没有便利店渠道的香蕉小包装 SKU。
- **洪九果品**：强项是水果供应链、批发和产地直采，给商超、电商、批发市场供货多。它可能有小规格或定制包装能力，但未必有面向便利店即拿即卖的标准化小包装成品，更可能是按箱、按件供货，需要你或门店自己分装。

建议你这样落地核实：

1. **先明确你要的“小包装”形态**  
   - 单根独立包装  
   - 2–3 根一袋  
   - 一盒/一袋固定克重  
   - 是否要贴条码、价签、品牌露出  
   这决定对方是按标准 SKU 供货，还是要给你定制。

2. **问都乐区域经销商的几句话**  
   - “有没有面向便利店的香蕉小包装 SKU？”  
   - “最小起订量、箱规、单根/单袋成本是多少？”  
   - “能不能贴门店条码？供货频次怎样？”  
   - “保质期和配送温层要求是什么？”

3. **问洪九果品时换个问法**  
   - “能不能做便利店小包装定制？”  
   - “是你们工厂分装，还是需要我们门店自己分装？”  
   - “起订量、包装材料、损耗和退货怎么算？”

4. **便利店实际选型时重点看**  
   - 损耗率：香蕉熟得快，小包装反而可能增加损耗。  
   - 配送频次：最好能一周多次配。  
   - 成本：小包装会增加包材和人工，单价通常高于散卖。  
   - 陈列：小包装要能立在冷柜或常温货架，不能太软塌。

一句话：**要现成便利店小包装，先找都乐；要大批量、定制或供应链价格，问洪九。** 但最终都得落到你所在城市的经销商库存和起订条件上，不能只看品牌总部。
