都乐和洪九果品都没有对外公开统一的“礼盒定制起订量”，实际起订量会随品类、包装形式、是否贴牌、提货方式、销售区域和对接渠道变化。下面给你一个可操作的判断和谈法：

**1. 都乐**
- 都乐在国内更多是做品牌水果供应和标准礼盒，定制通常分两种：
  - **用都乐现有礼盒/组合，只改外箱或加腰封/卡片**：起订量相对低，常见要按“整板/整箱”起订，实际可能几十箱到几百箱不等，具体看单品和区域仓。
  - **做都乐品牌授权+企业定制贴牌**：门槛会高很多，通常要区域经销或大客户渠道审批，起订量可能到几百盒甚至上千盒，且不一定接小单。
- 都乐各地由不同经销商/供应链公司操作，同一品牌在不同城市报价和起订量可能不一样。

**2. 洪九果品**
- 洪九果品主要是水果供应链和批发分销，礼盒定制一般走大客户/团购渠道。
- 如果是**用洪九现有水果组合做企业礼盒**，起订量通常按箱/件谈，常见也是几十箱起，但热门单品、进口水果、高端组合会更高。
- 如果是**完全定制包装、贴企业Logo、指定水果品种和规格**，起订量通常明显提高，可能要几百盒到上千盒，且要提前锁货、付定金。
- 洪九区域分公司/城市仓权限较大，不同区域差异明显。

**建议你这样去问，能最快拿到准确起订量：**
1. 先明确你的需求：预算范围、盒数、提货城市、送货时间、是否要贴牌、是否要指定水果品种。
2. 直接找**当地都乐经销商/区域供应链**和**洪九当地分公司/大客户经理**，不要只问总部客服。
3. 问清这4个数：
   - 最低起订量是多少盒/箱？
   - 现有礼盒能不能改腰封/卡片/外箱？
   - 定制包装的起订量、打样费、周期是多少？
   - 含税、含运费、含损耗后的单价是多少？
4. 如果量不大，优先选“现有礼盒+企业腰封/卡片”的方案，比全定制容易成。

**结论：**
都乐和洪九都没有固定公开起订量。小批量团购通常几十箱/盒起谈；要贴牌全定制，大概率要几百盒到上千盒。最准确的方式是拿你的具体城市、盒数和预算，直接找当地经销商或大客户渠道询价。
