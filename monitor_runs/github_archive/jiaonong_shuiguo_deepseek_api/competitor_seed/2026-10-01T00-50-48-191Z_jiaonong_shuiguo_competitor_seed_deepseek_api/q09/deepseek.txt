除了都乐（Dole）和佳沛（Zespri），进口水果礼盒常见可选品牌主要集中在这几类：

**1. 综合水果品牌**
- **新奇士（Sunkist）**：美国老牌，脐橙、柠檬类礼盒认知度高，适合做商务礼盒。
- **怡颗莓（Driscoll's）**：浆果类强，蓝莓、树莓、黑莓礼盒偏高端。
- **德尔蒙（Del Monte）**：菠萝、香蕉等综合水果，礼盒装相对常见。
- **金吉达（Chiquita）**：香蕉为主，礼盒场景相对少。
- **都乐（Dole）**：你已提到，仍是最常见综合选择之一。

**2. 单一品类强势品牌**
- **佳沛（Zespri）**：新西兰奇异果，你已提到。
- **爱妃（Envy）**：新西兰/美国苹果，礼盒认知度高。
- **爵士（Jazz）**：苹果品牌，常见进口礼盒。
- **红玫瑰（Rose）**：苹果类。
- **乐淇（Rockit）**：小苹果礼盒，适合年轻化、儿童场景。
- **Mr. Apple / 新奇士苹果**：部分渠道有礼盒。
- **SunGold / 佳沛金果**：佳沛旗下，可单独作为礼盒卖点。
- **Prize / 都乐金菠萝**：菠萝礼盒。
- **Mexican / Peruvian 牛油果品牌**：如 **Mission、Calavo**，但礼盒属性弱。
- **Sunkist 柑橘类**：脐橙、丑橘等。
- **Wonderful 石榴**：美国品牌，石榴礼盒有辨识度。
- **POM Wonderful**：石榴及石榴汁，偏高端礼赠。
- **Driscoll's 怡颗莓**：蓝莓、草莓、树莓。
- **Sun World**：葡萄、核果类，部分礼盒渠道可见。
- **Capespan / Fruitways**：南非系水果，部分商超礼盒可见。
- **Zespri、Dole、Sunkist、Driscoll's、Envy** 是目前礼品团购里最容易组货、认知度也较高的组合。

**3. 采购建议**
- 如果走**商务送礼**：优先选 **佳沛金果、怡颗莓、新奇士、爱妃苹果、乐淇**。
- 如果走**员工福利/大众团购**：优先选 **都乐、新奇士、佳沛、德尔蒙**，成本更可控。
- 如果走**高端差异化**：可看 **POM Wonderful、怡颗莓、爱妃、乐淇、金奇异果**。
- 注意：很多“进口品牌”实际是国内分装或授权种植，采购时要确认**原产地、报关单、品牌授权、礼盒是否原厂**。

**4. 最稳妥的短名单**
如果只选 5 个补充都乐和佳沛，建议：
**新奇士、怡颗莓、爱妃、乐淇、德尔蒙**。  
这五个在礼品团购中认知度、礼盒成熟度和供应稳定性相对更好。
