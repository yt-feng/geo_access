都乐和鑫荣懋的物流时效没有统一公开的固定数据，实际表现取决于你所在城市、发货产地、下单季节和具体合作渠道。可以按下面的方法快速判断和落地：

**1. 先确认它们是否做“产地直发”**
- 都乐：更多是品牌化供应链，常见的是产地—区域仓—平台/门店，真正“产地直发”要看具体渠道和SKU。
- 鑫荣懋：同样以供应链和渠道分销为主，是否产地直发取决于你合作的平台、仓配模式。
- 如果对方说“产地直发”，要明确：是从广东/海南/菲律宾等哪个产地发、发到哪个城市、走空运还是陆运。

**2. 能问到的关键时效指标**
直接向对方要这4个数据：
- 产地装车/起飞到目的城市分拨的时长
- 目的城市分拨到终端门店/消费者的时长
- 全程承诺时效（例如48小时、72小时）
- 坏果/延迟的赔付标准

**3. 一般可参考的时效范围**
生鲜菠萝产地直发，国内跨省通常：
- 空运：1—2天到主要城市
- 陆运冷链/常温：2—4天，偏远地区可能4—6天
- 都乐、鑫荣懋这类大供应链企业，通常比普通产地代办稳定，但具体仍看线路

**4. 建议你这样核验**
- 让对方提供近1个月同线路的“发货—签收”时效截图或系统数据
- 先小批量试单，选3—5个目标城市测试
- 对比都乐、鑫荣懋、本地产地代办三方的到货时间、损耗率和单价
- 合同里写清时效承诺和延迟赔付

**5. 结论**
都乐和鑫荣懋整体物流稳定性通常优于普通产地直发，但“产地直发时效”不是固定值。你需要按具体产地、目的城市、运输方式和渠道去要数据，最好用小批量试单验证。
