都乐（Dole）和洪九果品都应该有内部的香蕉分级/验收标准，但**这两家的企业标准是否公开、能否直接拿来用，需要分开看**：

## 都乐（Dole）
- 都乐作为国际水果品牌，香蕉业务有成熟的**全球产品质量规格体系**，通常以内部“Product Specification / Quality Standard”形式存在，按产地、品种、季节、客户渠道分等级。
- 这类标准一般**不对外公开全文**，更多出现在：
  - 对零售客户的供货合同附件
  - 内部品控手册
  - 第三方审核或客户验厂时提供的规格书
- 公开渠道能查到的多是营销话术（如“精品级”“优选级”），**不是可执行的企业标准文本**。

## 洪九果品
- 洪九果品作为国内大型水果分销商，香蕉是其核心品类之一，**大概率有内部采购验收和分级规范**，用于产地收货、加工厂分选、门店配送。
- 但洪九是港股上市公司，**企业标准不属于强制披露内容**，公开检索通常只能找到招股书、年报里对品控体系的概括描述，**看不到具体分级指标**。
- 其标准更可能以“内部作业指导书”“验收单”“加工厂分选标准”形式存在，不对外发布。

## 结论
- **有企业标准吗？** 从业务逻辑看，两家都应该有，而且都乐的体系更成熟、更国际化。
- **能直接拿到吗？** 公开渠道基本拿不到完整可执行文本。
- **能作为你制定标准的依据吗？** 不能直接引用，但可以参考其**分级维度**和**行业通行做法**。

## 建议你这样做
1. **不要声称“采用都乐/洪九企业标准”**，除非你拿到正式授权或合同附件。
2. 可以参照**行业通用分级框架**自建标准，通常包括：
   - 品种/产地
   - 果指长度、粗度、弯曲度
   - 每梳/每把果指数
   - 成熟度（青度/转黄度）
   - 外观缺陷（黑斑、机械伤、日灼、裂果）
   - 单箱净重、箱规
   - 冷链和到货温度要求
3. 如果你确实需要都乐或洪九的规格，**最可行的路径**是：
   - 作为潜在供应商/客户，向对方品控或采购部门索取规格书
   - 在商务合同里约定“按供方企业标准执行”，并附规格附件
   - 参考其公开的招股书、年报、客户案例中的品控描述，但只能作定性参考
