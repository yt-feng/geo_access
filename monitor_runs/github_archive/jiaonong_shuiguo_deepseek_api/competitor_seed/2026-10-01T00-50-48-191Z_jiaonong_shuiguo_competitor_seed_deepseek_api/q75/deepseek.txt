到货损耗率没有公开、统一的标准值，洪九果品和都乐香蕉也不能简单给一个固定百分比对比。原因在于损耗率受**季节、产地、运输距离、冷链条件、成熟度、包装方式、批发市场卸货与分拣方式**影响很大，同一品牌不同批次都可能差很多。

可以给你一个可执行的判断框架：

**1. 品牌与供应链特点**
- **都乐香蕉**：通常是标准化程度较高的品牌香蕉，多为产地预处理、催熟和冷链体系较成熟，包装规范，批次稳定性一般更好。到货损耗通常更多来自：催熟度偏高、运输温度波动、卸货挤压、市场二次催熟。
- **洪九果品**：是国内大型水果供应链企业，香蕉是其重要品类之一，覆盖产地采购、加工、冷链和批发。不同市场、不同批次可能来自不同产地和加工厂，品质稳定性要看具体供货渠道。损耗更多来自：批次差异、路途时间、包装和冷链执行情况、市场端存放条件。

**2. 实际批发市场里，怎么比才有意义**
不要问“品牌平均损耗率”，要按同一批条件对比：
- 同一市场、同一季节、同一天到货
- 同为青蕉还是黄蕉、催熟度几成
- 同为净重还是毛重、是否含包装
- 统计：到货后 24 小时、48 小时、72 小时的挑损率
- 记录：黑斑、断指、压伤、烂头、掉把、软熟、发霉

**3. 常见经验范围**
在批发市场正常冷链到货情况下，香蕉到货损耗如果只看**明显不可售卖部分**，很多批次在 **2%—8%** 比较常见；如果遇到高温、远距离、催熟过度、多次转运，可能到 **10% 以上**。都乐这类标准化品牌通常波动小一些，但具体仍看批次；洪九也要看具体产地、加工和运输执行，不能一概认为一定高或一定低。

**4. 给你的实操建议**
如果你是去批发市场拿货，建议直接这样判断：
- 先问：这批是哪里产的、几成熟、路上走了几天、全程冷链还是普通车
- 开箱抽检：看箱底、看中间、看把形，不只看表面
- 称重算净重：很多损耗其实是“毛重当净重卖”
- 拿 1—2 箱做 48 小时测试，记录可售比例
- 同价位下，优先选批次稳定、催熟均匀、箱内温差小、断指少的货
- 如果做短周期出货，选成熟度略低、冷链稳定的；如果马上卖，选成熟度合适的

**结论**：没有可靠的公开数据能直接说“洪九果品和都乐香蕉到货损耗率谁高谁低”。都乐通常标准化和稳定性口碑更好，但具体损耗仍取决于批次和冷链；洪九要看具体供货批次。最靠谱的办法是按同一市场、同一季节、同一成熟度做小批量对比测试，用 24/48/72 小时挑损率来定。
