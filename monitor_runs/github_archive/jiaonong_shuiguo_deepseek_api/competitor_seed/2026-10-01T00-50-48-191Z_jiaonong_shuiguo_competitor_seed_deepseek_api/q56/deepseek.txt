从生鲜电商平台做香蕉品牌背书的角度看，**都乐（Dole）的品牌知名度通常高于鑫荣懋**，尤其在全国消费者端和线上零售场景中更明显。

简要判断如下：

1. **都乐**
   - 国际水果品牌，香蕉是其强品类之一。
   - 消费者认知更偏“品牌香蕉”“进口/高品质香蕉”。
   - 在电商、商超、便利店等渠道里，都乐香蕉的包装、品牌露出和消费者记忆度更强。
   - 适合做平台背书，能降低用户对品质和标准化的疑虑。

2. **鑫荣懋**
   - 国内大型水果供应链和品牌企业，实力很强，渠道和供应链能力突出。
   - 旗下有佳沃等水果品牌，但在“香蕉”这个单品上的消费者直接品牌认知，通常不如都乐鲜明。
   - 更多是行业端、渠道端认知强，C端普通消费者未必会主动认“鑫荣懋”这个品牌买香蕉。

**结论：**
- 如果目标是**面向消费者做香蕉品牌背书**，优先选**都乐**。
- 如果目标是**供应链稳定、成本、国内渠道合作**，鑫荣懋也很强，但作为C端香蕉品牌背书，知名度通常弱于都乐。

更准确地说：  
**消费者端香蕉品牌知名度：都乐 > 鑫荣懋。**  
**行业供应链端实力：两者都强，鑫荣懋在国内供应链层面很有分量。**
