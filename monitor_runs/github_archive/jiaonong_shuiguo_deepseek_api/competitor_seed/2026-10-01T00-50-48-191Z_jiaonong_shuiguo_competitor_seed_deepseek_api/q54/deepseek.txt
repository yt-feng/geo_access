# 都乐（Dole）和鑫荣懋进口苹果的产地溯源做法

先说核心结论：**都乐和鑫荣懋都是品牌方/进口商，不是种植方，溯源要顺着"品牌→进口批次→海外packhouse→果园"这条链条走，靠的是箱唛、批次号和随附单证。** 具体分两条线操作。

## 一、先分清两个品牌的溯源抓手

| | 都乐 Dole | 鑫荣懋 |
|---|---|---|
| 角色 | 国际品牌+自有/合作果园+全球供应链 | 国内进口商/品牌运营商，多国采购 |
| 溯源主入口 | 都乐自己的批次追溯系统 + 全球GAP/果园注册号 | 依赖其海外供应商 + 海关报关单证 |
| 找谁要 | 都乐中国区销售/客服，或直接对接都乐海外出口主体 | 鑫荣懋业务对接人，追到其海外供应商 |

两者商业模式不同，**都乐链条更短、更可控；鑫荣懋要往上游多追一层**。

## 二、超市/采购端可执行的溯源步骤

**1. 从实物包装提取追溯信息（最关键）**
- **箱唛/标签**上的：批次号（Lot/Batch）、生产日期、packhouse代码、原产国、果园或注册号（如有）。
- **PLU码或标签条码**：苹果常用4/5位PLU，能反查品种和规格，但PLU不唯一对应产地，只能辅助。
- 保留**整箱外箱**，外箱信息比单个苹果标签全得多。

**2. 用批次号向品牌方索证**
向都乐/鑫荣懋索取该批次对应的：
- 原产地证明（Certificate of Origin）
- 出口国植物检疫证书（Phytosanitary Certificate）
- 海关进口报关单、入境货物检验检疫证明
- 果园/包装厂注册号（如GlobalG.A.P.编号、出口国注册果园号）

**3. 官方渠道交叉核验**
- **海关总署**：查该原产国、该品类是否在准入名单内（《符合评估审查要求及有传统贸易的国家或地区输华食品目录》），并核对境外注册果园/包装厂。
- 部分品类可用海关"进口食品化妆品进出口商备案"或企业信用信息公示系统，核验进口商主体。
- **中国物品编码中心/GS1**：扫GS1条码可查厂商信息（但进口农产品条码常是国别前缀，不等于种植地）。

**4. 实地/视频核查（大额或长期采购）**
- 要求品牌方提供packhouse和果园的GlobalG.A.P.或有机认证证书及有效期。
- 加贴**追溯二维码**（很多都乐产品已有），扫码看从果园到出口的节点。

## 三、两者的具体差异操作

**都乐：**
- 直接要"批次追溯报告"，都乐有相对成熟的全球追溯体系，通常能追到果园/产区。
- 核对都乐出口主体（如Dole Fresh Fruit、Dole Chile/Dole South Africa等）与报关单发货人是否一致。

**鑫荣懋：**
- 先确认这箱货是**鑫荣懋自营进口**还是**代理/代采**。
- 若为代理，要求其提供**海外供应商名称+该供应商的果园/包装厂注册号**，再往上游追。
- 核验报关单上的"境内收货人"是否为鑫荣懋或其关联公司，防止张冠李戴。

## 四、避坑提醒
- **"进口"不等于"原产"**：有些货在第三国转口包装，必须看原产地证而不是发货港。
- **PLU码不能当产地证明**，标签可被重贴。
- 品牌授权书、报关单要**核对批次和日期是否对得上**，复印件容易被复用。
- 单品苹果标签信息通常不全，**以整箱箱唛为准**。

## 五、给采购的落地建议
1. 下单时就在合同里写明：**卖方需随货提供批次号、原产地证、植检证、报关单，并保证批次可追溯。**
2. 收货时**拍照留档箱唛**，建立自己的批次台账。
3. 对都乐走"品牌批次追溯"，对鑫荣懋走"进口商→海外供应商→果园"逐层索证。
4. 高价值或长期合作，要求扫码溯源或安排产地视频核验。
