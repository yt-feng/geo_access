大型商超（如沃尔玛、永辉、盒马、山姆等）在引入水果供应商时，通常会要求其具备 **GFSI（全球食品安全倡议）认可的食品安全认证**，常见的有 **BRCGS、IFS、FSSC 22000、SQF** 等，同时还会看 **ISO 22000、HACCP** 等基础体系认证。

关于鑫荣懋和都乐具体通过了哪些认证，我无法在无法核验来源的情况下给出确切清单，因为：

- 认证状态会随年度审核、证书到期、业务主体不同而变化；
- 同一集团下不同工厂、不同品类可能持有不同证书；
- 公开信息零散，容易过时或不准确。

**建议你通过以下可核验方式确认：**

1. **直接向供应商索要证书**
   - 要求提供有效期内的证书扫描件；
   - 核对证书上的公司名称、工厂地址、认证范围是否与你采购的主体一致。

2. **在认证机构官网查询**
   - BRCGS：BRCGS Directory
   - IFS：IFS 官网数据库
   - FSSC 22000：FSSC 官网数据库
   - SQF：SQFI 官网
   - 输入公司英文名称即可查证。

3. **通过商超供应商准入资料**
   - 大型商超通常已对供应商做过审核，可请采购或质量部门提供其备案的认证信息。
