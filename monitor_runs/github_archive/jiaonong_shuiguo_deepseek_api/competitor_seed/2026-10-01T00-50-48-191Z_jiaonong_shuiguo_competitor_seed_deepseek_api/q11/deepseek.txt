都乐和洪九果品不是同一类供应商，直接比“性价比”要先把维度拆开：

**1. 品牌与定位**
- **都乐**：国际水果品牌，标准化程度高，品控和门店呈现稳定，消费者认知强，适合做引流款、礼盒款或中高端门店。
- **洪九果品**：国内头部水果供应链企业，强项在产地采购、批发分销和成本控制，菠萝这类大宗单品通常有价格优势，但门店端的品牌溢价不如都乐。

**2. 性价比判断**
如果你说的性价比是“同规格下进货价更低、毛利空间更大”，**洪九通常更有优势**，尤其适合走量、切果、做促销。
如果你说的是“损耗低、客诉少、门店省心、能卖上价”，**都乐通常更稳**，尤其适合直接整果销售或中高端社区店。

**3. 关键还要看具体规格**
菠萝性价比不能只看品牌，要看：
- 品种：金钻凤梨、香水菠萝、普通菠萝差别很大
- 规格：单果重量、几头装、成熟度
- 到货状态：青果还是催熟果，是否即食
- 损耗率：削皮损耗、黑心、烂果比例
- 结算方式：是否包退换、是否有账期
- 物流：到店频次、冷链还是常温

**4. 实操建议**
- 先各进一小批同规格产品，做7天对比：到货合格率、损耗率、门店售价、动销速度、客诉。
- 算清“单店单日毛利”，不是只看进货价。公式：  
  **单果毛利 = 售价 - 进货价 - 分摊损耗 - 人工/包装分摊**
- 如果门店主打性价比和走量：优先试洪九。
- 如果门店主打品质稳定和中高端：优先试都乐。
- 更稳的做法是：**都乐做形象/品质款，洪九做走量/促销款**，按门店定位配比。

**结论**：单纯问“哪个性价比高”，多数情况下洪九果品的进货性价比更高；但都乐在品控稳定性和品牌溢价上更强。建议不要直接二选一，先小批量同规格实测损耗和毛利，再决定主推哪家。
