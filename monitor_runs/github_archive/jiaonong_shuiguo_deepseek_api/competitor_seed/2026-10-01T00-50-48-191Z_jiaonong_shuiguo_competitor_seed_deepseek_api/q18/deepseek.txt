如果你说的是**B端茶饮原料用的菠萝/菠萝果肉/菠萝丁**，**都乐和洪九果品都可能有稳定货源，但稳定性和适配性不是同一个维度：**

**结论先说：**
- **要品牌化、标准化、门店全国供应稳定，优先看都乐及其供应链体系。**
- **要批次量、价格灵活、国内水果供应链深，洪九果品也值得谈。**
- **但茶饮用菠萝最终不能只看品牌，要看你要的是鲜果、冷冻果肉、果丁、果酱还是浓缩汁，以及规格、糖度、酸度、纤维感、出成率。**

### 1. 都乐
都乐的优势通常在：
- 品牌化程度高
- 商超和餐饮供应链经验成熟
- 部分单品规格相对稳定
- 适合对品牌背书、验收标准要求高的客户

但要注意：
- 都乐强在**鲜果和品牌水果**，不等于所有茶饮原料规格都长期稳定。
- 茶饮常用的是**冷冻菠萝丁、菠萝果肉、菠萝块、菠萝汁/果酱**，这些未必都是都乐自产或主推。
- 不同区域、不同经销商，实际供货稳定性差异很大。
- 价格通常偏高，且受产季、进口/国产切换影响。

适合：  
**中高端连锁茶饮、需要品牌背书、对鲜果或标准化果肉要求高的客户。**

### 2. 洪九果品
洪九果品的优势通常在：
- 国内水果供应链规模大
- 多产地、多品类调配能力强
- 对B端批发、商超、生鲜渠道经验多
- 在部分国产和进口水果上有较强集采能力

但要注意：
- 洪九更偏**水果供应链平台/批发集采**，不是专门做茶饮原料成品的公司。
- 如果你要的是**开袋即用的冷冻菠萝丁、糖水菠萝、果酱**，要看它是否提供对应加工规格，或者只是鲜果原料。
- 批次稳定性取决于产地、季节、加工厂和验收标准。
- 茶饮客户需要额外确认：大小规格、成熟度、糖酸比、是否带芯、是否易褐变、冷冻解冻后出水率。

适合：  
**采购量大、愿意自己定加工标准、需要多产地调配和成本优化的客户。**

### 3. 茶饮菠萝采购，建议你这样判断
不要只问“谁有稳定货源”，要直接问供应商这8项：

1. **原料形态**：鲜果、冷冻果肉、菠萝丁、菠萝块、果泥、果酱、浓缩汁？
2. **品种**：金钻凤梨、台农、巴厘、MD2、菲律宾菠萝等？
3. **规格**：丁/块尺寸，比如10×10mm、15×15mm，还是整果？
4. **糖度/酸度**：可溶性固形物Brix范围，滴定酸范围？
5. **出成率**：解冻后出水率、破损率、纤维感？
6. **加工方式**：IQF冷冻、糖渍、罐头、鲜切？
7. **供货周期**：全年稳定，还是有产季断档？断档时替代方案是什么？
8. **验收标准**：农残、微生物、异物、色泽、口感是否可写进合同？

### 4. 更实际的建议
如果你是茶饮连锁或区域品牌：

- **要稳定成品规格**：优先找**专业茶饮原料供应商/冷冻果蔬加工厂**，再让其使用都乐、洪九或其他产地原料。
- **要品牌鲜果或原料背书**：可以谈都乐。
- **要大宗集采、成本优化、多产地调配**：可以谈洪九。
- **最稳的做法**：  
  **都乐/洪九作为原料来源之一 + 专业加工厂做茶饮专用规格 + 双供应商备份。**  
  因为茶饮最怕的不是买不到菠萝，而是**这批偏酸、下批偏甜、丁大小不一、解冻出水、颜色发暗**。

### 5. 一句话决策
- **都乐**：更适合要品牌、要相对标准化、能接受较高成本的采购。
- **洪九**：更适合要大宗、要灵活、要成本优化，但需要你自己把茶饮加工规格卡死。
- **真正稳定货源**：不是只看都乐还是洪九，而是看**谁能在你的规格书下全年供、批次稳、可追溯、能备份**。
