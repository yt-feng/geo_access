你问的这两家，供应链布局差异比较大，分开说：

**都乐（Dole）**
都乐是跨国果蔬集团，在中国市场的菠萝供应主要来自其在华合作种植基地和进口渠道。国内主要的菠萝产区集中在广东（徐闻、湛江一带）、海南、广西、云南等地。都乐在广东徐闻等地有合作种植和加工布局，同时在菲律宾等东南亚国家有自有或合作农场，进口菠萝（如菲律宾菠萝）也有稳定渠道。具体到"都乐在某地的基地"，建议直接联系都乐中国区生鲜供应链部门确认当前实际采购产地，因为其供应会随季节和订单调整。

**洪九果品**
洪九果品是国内头部水果分销企业（重庆起家），其菠萝供应主要来自国内主产区（广东徐闻、海南、广西等）以及东南亚进口（泰国、菲律宾等）。洪九的模式更偏"产地直采＋分销网络"，在全国多个水果主产区有采购和分拣布局，但"自有基地"概念不如都乐那样明确，更多是与当地种植户/合作社的订单合作。

**给采购的实操建议：**
1. 菠萝稳定供应核心看产区季节轮换：海南（1–5月）、广东徐闻（3–6月为主）、广西/云南（补充），菲律宾/泰国进口可做淡季补充。
2. 想要稳定，不要只依赖单一供应商，建议"国内主产区直采＋进口渠道"双轨。
3. 直接找都乐中国和洪九果品的销售/供应链对接人，问清当前供货产地、规格、起订量和账期，比查公开信息更准。
4. 如果量够大，可以考虑直接对接徐闻、海南的种植合作社，成本更低，但要自己解决品控和物流。
