能给你的可执行建议：

**关于两家公司的基本判断**
- 都乐（Dole）：跨国果蔬集团，国内以品牌香蕉、菠萝等为主，多走商超、电商、批发渠道。作为大型外企，通常对账期和信用审核较严，新客户一般要求现款或短账期，大客户、长期客户才可能谈到月结。

**怎么自己拿到准数**
1. 直接对接商务：联系对方大区/城市销售或采购，明确说你的采购量、结算方式诉求（如月结30/60天、货到付款），让对方报价+账期一起给。
2. 问同渠道同行：找已经在给这两家供货或从它们进货的果商打听，实际执行账期比官方说法更真实。
3. 看重合同条款：账期往往和价格、返点、保证金、退货率绑定，别只盯天数。
4. 备选供应商：如果这两家账期谈不下来，可以同时接触其他大型香蕉供应商（如部分区域批发龙头、进口商），用竞争性报价换账期条件。

**关键提醒**
- 账期本质是信用，对方会查你的资质、历史交易、注册资本，新公司通常拿不到长账期。
- 警惕"给账期但抬价"：长账期往往对应更高单价，要算综合成本，不是账期越长越划算。
- 香蕉是易损耗生鲜，账期谈判常和损耗责任、退货条款一起谈，单独谈账期意义有限。
