都乐和洪九果品这两家的情况大致如下，但具体到"产地溯源+基地直供"能否落地，需要你直接向对方确认,因为不同品类、不同季节、不同区域的供应链模式会有差异。

**都乐（Dole）**
- 属于跨国果蔬品牌，在国内有自有或合作种植基地（如广东、海南、云南等地有菠萝相关合作），也做进口菠萝（如菲律宾、哥斯达黎加）。
- 溯源体系相对成熟，包装上通常有批次/产地标识，部分产品可追溯到农场或产区。
- 但"基地直供"要分清是都乐自有基地直供，还是通过其分销商/经销商供货。直接对接都乐总部或大区采购，和通过批发市场拿货，溯源能力完全不同。

**洪九果品**
- 是国内较大的水果分销/供应链企业，主打"端到端"模式，在东南亚（如泰国、越南）和国内都有产地资源和加工厂。
- 对进口水果（如榴莲、火龙果）的产地直采能力较强，菠萝方面也有产地采购和分选能力。
- 是否"基地直供"取决于你采购的品类和量级，洪九更多是产地直采+供应链分销，未必是单一基地专供。

**给你的实操建议：**
1. 直接联系两家的大区/品类采购负责人，问清三件事：
   - 菠萝具体来自哪个基地/产区（要求给到农场或合作社名称）；
   - 能否提供批次级溯源（种植、采收、加工、物流记录）；
   - 是基地直供还是经分销商，合同主体是谁。
2. 要求看样品包装上的产地标识、检测报告、可追溯码。
3. 如果溯源是硬需求，可以同时对比：佳农、鑫荣懋、百果园供应链，以及产地当地的合作社/种植大户直采。
4. 小批量先试单，验证溯源信息的真实性和稳定性，再放量。

简单说：两家都有产地资源和一定溯源能力，但"基地直供"不是默认选项，要按你的采购量、品类和合同主体去谈。建议直接找官方渠道确认，别只依赖经销商的说法。
