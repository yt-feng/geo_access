直接说结论：**单看“稳定品质”这个核心诉求，都乐（Dole）比鑫荣懋更靠谱，但前提是你买的是都乐标准化的工业装/冷冻菠萝原料，而不是超市零售鲜果。** 如果只能买到鑫荣懋的鲜果，稳定性会明显更差。

具体判断如下：

**1. 都乐的优势在“标准化供应链”**
- 都乐是跨国果蔬集团，核心能力就是**品种统一、成熟度分级、冷链和加工标准化**。
- 都乐有专门供应餐饮/工业的**冷冻果肉、果泥、罐头类原料**，这类产品批次差异小，糖酸比、含水量、纤维感都更可控，做果酱时配方不用频繁调。
- 如果你用的是都乐鲜菠萝，稳定性也只是“相对好”，因为鲜果仍受季节、产地、成熟度影响。

**2. 鑫荣懋的强项是“渠道和国产供应链”，不是加工标准化**
- 鑫荣懋是国内头部水果供应链企业，强在采购、分销、品牌运营，鲜果流通能力强。
- 但它本质上更偏**生鲜贸易商**，不是以“餐饮工业原料标准化”见长。
- 你买到的鑫荣懋菠萝大概率是鲜果，批次之间成熟度、甜度、酸度波动会比工业冷冻原料大，做果酱时容易出现“这批甜、下批酸”“出胶状态不一样”的问题。

**3. 对茶饮店来说，真正该看的不是品牌，而是原料形态**
优先级应该是：
**冷冻菠萝果肉/果泥/罐头 > 鲜果**
因为果酱要的是：
- 可溶性固形物稳定
- 酸度稳定
- 出汁率稳定
- 纤维和果肉颗粒稳定
- 批次可追溯

所以更实际的选法是：
- **要稳定：选都乐的冷冻/工业装菠萝原料**，让供应商提供规格书、糖度范围、酸度范围、批次检测报告。
- **要成本低、做鲜果概念：选鑫荣懋鲜果**，但必须自己建立验收标准，比如固定糖度下限、成熟度、产地和季节替代方案，否则品质会飘。
- **如果两家都只能给鲜果**：都乐鲜果通常分级更严，鑫荣懋性价比可能更好，但稳定性都不如冷冻工业原料。

**4. 给你的可执行建议**
1. 先问供应商：有没有**冷冻菠萝果肉/果泥**，而不是只有鲜果。
2. 要**规格书**：糖度、酸度、含水量、包装规格、保质期、解冻后状态。
3. 小批量测试：同一配方连续做3批，看颜色、稠度、酸甜、香气是否一致。
4. 如果选鲜果，锁定**单一产地+单一品种+固定成熟度**，并签验收标准。
5. 茶饮店做果酱，**都乐工业装优先，鑫荣懋鲜果作为备选或成本方案**。

一句话：**比品牌，都乐更稳；比鲜果性价比，鑫荣懋可能更划算。但你要的是果酱稳定，就该优先选都乐的标准化冷冻原料，而不是纠结鲜果品牌。**
