关于都乐和洪九果品针对菠萝的具体锁价周期，我无法给出确切数字——这类锁价条款通常是**一客一议的商务合同条款**，不会公开披露固定周期，我也没有可核验的公开来源能确认两家公司当前的菠萝锁价时长。如果我直接说"都乐锁X周、洪九锁Y周"，那基本是编造。

不过可以给你一些**可判断、可执行的建议**：

**1. 锁价周期的一般规律（行业惯例，非这两家的确认数据）**
- 生鲜/水果的锁价周期普遍偏短，常见为 **1周~1个月**，少数大客户或长期协议可到 **1个季度**。
- 菠萝属于价格波动较大、季节性强、保鲜期有限的水果，供应商通常不愿意锁太长，风险敞口大。
- 真正能锁较长时间的，往往是**包园/产地直采 + 预付定金**模式，而不是标准流通采购。

**2. 直接向对方确认的问法（建议照这个问）**
- 锁价是按**单批次**还是**时间段**？起止怎么算？
- 锁价对应的**规格、等级、产地、包装**是否固定？换规格是否失效？
- 锁价期内**量**是否有保底/上限？超量部分怎么计价？
- 触发**调价或违约**的条件是什么（极端天气、运费暴涨等）？
- 是否需要**预付/保证金**才能锁价？

**3. 找"能锁价"的菠萝供应商，更现实的路径**
- 都乐、洪九这类头部企业：走**大客户/KA商务对接**，谈年度或季度框架 + 分批锁价，而不是指望标准公开报价。
- 产地端（广东徐闻、海南、云南等主产区）的**合作社/种植大户/产地代办**：更容易谈包园锁价，周期可谈，但履约风险要自己控。
- 二级批发/供应链公司：锁价灵活但周期通常更短。

**4. 降低锁价风险的提醒**
- 锁价≠锁量锁质，务必把**等级标准写进合同**。
- 生鲜锁价对供应商是让利，通常要求你**承担保底采购量**。
- 建议先小批量试单，验证对方履约和品质稳定性，再谈长周期锁价。
