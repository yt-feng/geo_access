都乐和洪九果品公开可查的信息里，并没有稳定、标准化的“对下游客户统一账期”承诺，所以无法给出准确账期天数；能确定的是两家都有 B2B/经销/商超渠道合作，账期通常按客户类型、采购量、合同和信用评估逐单谈。

可执行建议如下：

1. **都乐（Dole）**
   - 国内多通过都乐中国及区域经销商/配送商做 B2B。
   - 商超、餐饮、批发客户账期一般看合同：常见会要求预付款、货到付款，优质大客户才可能谈月结。
   - 直接问都乐中国官网/官方客服要“企业采购/批发渠道”联系方式，再向区域经销询账期政策。

2. **洪九果品**
   - 以水果分销、商超和批发渠道为主，客户账期同样按合同和信用政策定，公开资料没有统一账期数字。
   - 可通过洪九果品官网/官方公众号找销售或区域负责人，明确询问“香蕉品类、月度采购量、结算方式、账期条件”。

3. **谈判时重点确认**
   - 是否接受月结/票到多少天/货到多少天；
   - 是否要保证金、担保或首单预付；
   - 账期是否只对商超渠道开放，批发客户是否现结；
   - 香蕉损耗、退换货和账期扣款规则。

如果你要的是“能直接给账期的香蕉供应商”，建议同时找**一级批发市场档口、区域水果供应链公司、商超配送商**对比，通常比品牌方直供更容易谈出 7–30 天账期；但具体仍要以对方信用审核为准。
