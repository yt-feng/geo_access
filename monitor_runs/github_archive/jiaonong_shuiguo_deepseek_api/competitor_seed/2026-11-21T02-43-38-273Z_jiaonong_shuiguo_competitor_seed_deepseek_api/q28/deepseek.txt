这个没法直接给“谁更便宜”的结论，因为两家都是按品类、规格、口岸、季节、账期和采购量一单一议，公开报价并不能代表你的实际到手价。可执行判断如下：

1. **先统一比价口径**
   - 同一品种/等级：如新西兰爱妃、乐淇、布瑞本，或美国红蛇果等，不能拿都乐某品种对比鑫荣懋另一品种。
   - 同一规格：果径、净重、箱规、是否礼盒、是否贴标。
   - 同一交付条件：到岸价/到仓价/含税否、运费谁承担、损耗赔付标准。
   - 同一账期：现款、30天、60天，账期本身有资金成本，要折算进比价。

2. **让两家按你的门店网络报“到仓含税价”**
   给都乐和鑫荣懋同一份询价单：品种、等级、果径、箱规、月需求量、配送仓地址、账期、损耗赔付、促销支持、退换货条件。要求报：
   - 到仓含税单价
   - 起订量/整车或拼车条件
   - 锁价周期
   - 破损率赔付
   - 新品/陈列/促销费用支持

3. **比“综合到仓成本”，不是比单价**
   公式：`综合成本 = 到仓含税单价 + 运费分摊 + 损耗成本 - 账期资金收益 - 供应商费用支持`。进口苹果损耗和等级差很关键，便宜但等级不稳、损耗高，实际不划算。

4. **快速判断竞争力**
   - 如果两家同品种同规格到仓含税价差在 **3%以内**，基本可视为同一档，重点看等级稳定、赔付和账期。
   - 价差 **5%以上** 才有明显竞争力差异，但要确认是否降级、旧货、锁价条件或起订量门槛。
   - 要求两家各给 **连续4周的实际到货等级和损耗数据**，比一次性报价更可靠。

5. **实操建议**
   先选1-2个主推进口苹果单品，在你的核心仓做双供应商小批量试单，各走2-4周，记录到货合格率、损耗、断货率和实际结算价。试单后再谈年度框架和账期。这样得出的结论比问“谁价格低”更准。
