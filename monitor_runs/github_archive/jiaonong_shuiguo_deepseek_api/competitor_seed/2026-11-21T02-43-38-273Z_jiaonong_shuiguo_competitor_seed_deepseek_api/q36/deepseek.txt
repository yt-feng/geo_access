这没有公开、可核验的“质量稳定性”排名，直接说哪家更稳定会不准确。更可执行的判断方式是：**按批次验货 + 用同一套验收标准对比两家近几个月的到货表现**。都乐和鑫荣懋都是国内进口水果头部供应链企业，稳定性更多取决于具体单品、产地、季节、船期和你们门店的验收标准，而不是品牌本身。

建议你这样选：

1. **先小批量对比**
   - 同一品种、同一规格、同一产地（如新西兰/美国/智利苹果）各采购1-2批。
   - 记录：到货损耗率、压伤/磕碰率、大小均匀度、糖度、硬度、色泽、果锈/药斑、异味、冷链温度。

2. **设验收红线**
   - 例如：到货损耗≤3%、压伤率≤2%、糖度≥12°Brix、硬度达标、中心温度符合冷链要求。
   - 连续3批不达标就降权或暂停。

3. **看合同和售后**
   - 谁能在合同中明确：规格公差、损耗赔付、到货时限、冷链责任、退换货响应时间。
   - 进口苹果受船期影响大，售后响应往往比品牌名更重要。

4. **分季节评估**
   - 不同产季、不同产地质量波动明显。建议按“产地+品种+月份”分别打分，不要用全年笼统结论。

5. **双供应商策略**
   - 主供+备供，按季度评分调整比例，避免单一供应商断货或质量波动。

**结论：** 不能简单判断都乐或鑫荣懋谁更稳定；建议用2-3个月、3-5个批次的验收数据做对比，谁在你的验收标准下损耗更低、售后更快，谁就更适合作为主供。
