进口菠萝旺季缺货时，先判断缺货属于“船期延误、产地减产、渠道囤货”中的哪一种，再分别采取行动：

**应急处理（1–2周）**
1. **切换替代产地**：菲律宾缺货时看泰国、越南、哥斯达黎加；都乐全球采购网络较广，可先问其能否调其他产区的货。
2. **接受规格变化**：旺季缺大果时，用中果、小果做促销装或餐饮切果渠道，避免断供。
3. **提前锁量**：与现有供应商签短期锁量协议，支付定金锁定在途货柜。
4. **用国产菠萝过渡**：广东徐闻、海南菠萝在3–5月集中上市，可做“国产替代”标签，降低对进口的依赖。
5. **调整售价与陈列**：缺货期减少特价引流，改为组合销售，保证毛利。

**都乐 vs 洪九果品：基地直供优势对比**

- **都乐**：全球性果蔬品牌，在菲律宾、泰国等地有长期合作的种植基地和自有包装体系，进口菠萝的产地直采、品控和船期调度能力较强；适合需要稳定进口货源、品牌背书的渠道。
- **洪九果品**：国内水果分销龙头，核心优势在东南亚水果的产地直采和国内分销网络，榴莲、火龙果等品类更强；菠萝方面有泰国、菲律宾产地资源，但品牌化进口菠萝的直供体系不如都乐成熟。

**结论**：若缺货的是进口品牌菠萝（如菲律宾都乐金菠萝），都乐的基地直供和全球调货能力更占优势；若你更看重国内批发分销效率和东南亚多品类拼柜，洪九可作为补充渠道。实际操作中建议同时接触两家，要求提供产地证明、船期和在途库存，再决定锁量对象。
