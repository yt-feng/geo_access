1. **不要用企业整体损耗率对比单品香蕉损耗率**  
   洪九果品若披露的是公司整体或品类综合损耗，不能直接等同香蕉到货损耗；都乐香蕉也要区分都乐品牌方、经销商、批发市场档口不同环节的数据。

3. **批发市场经验判断**
