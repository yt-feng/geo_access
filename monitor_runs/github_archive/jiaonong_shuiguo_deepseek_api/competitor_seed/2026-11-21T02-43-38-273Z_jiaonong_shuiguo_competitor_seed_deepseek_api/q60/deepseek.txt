进口菠萝损耗高，核心通常不在“到货那几天”，而在**到货前的成熟度窗口 + 到货后的温湿度与周转速度**。都乐、鑫荣懋这类头部进口商的做法，本质是把品控前移、把损耗拆段管理。可参考的逻辑如下：

**1. 产地端：按“到货后销售节奏”定采收成熟度**
- 菠萝是后熟/易感病水果，不能等全黄再采。头部企业通常按季节、船期、目标市场距离，约定不同成熟度标准（如底色、糖度、果心状态），避免“到港即过熟”。
- 对黑心病、水心病、内部褐变等高发问题，靠产区分选和抽检前置，而不是到港后挑。

**2. 冷链：全程温度连续，不只看柜温**
- 菠萝对低温敏感，长期低于适宜温度易冷害，温度波动又会加重黑心。关键是**全程记录+到港复核**，看运输途中是否有断链、开关门、堆码堵风。
- 到港后快速卸柜、快速分拨，减少在码头和月台暴露时间。

**3. 到货验收：按“批次+成熟度+病害”分级，不混装**
- 到货即做抽样，按成熟度分档、按病害风险隔离，成熟度高的优先出库或转短保渠道。
- 对高损耗批次不进入正常商超链路，避免“一颗坏果拖累整箱”。

**4. 仓储与周转：先进先出 + 按成熟度分库**
- 不同成熟度分温区/分库管理，控制堆码高度和通风，避免挤压和局部积热。
- 以销定进，缩短库内停留；对菠萝这种周转敏感品，**库存天数比采购价格更影响损耗率**。

**5. 渠道匹配：成熟度与渠道绑定**
- 高成熟度走即时零售、水果店、餐饮切果；中低成熟度走商超和二级批发。渠道错配是损耗放大的常见原因。

**6. 数据闭环：按批次复盘损耗**
- 把损耗拆成产地、运输、到货验收、仓储、门店/客户五段，按供应商和船期复盘，倒推采收标准和物流责任。头部企业的优势往往在“每批可追溯、每段有责任人”。

**可执行建议：**
- 先统计你现有损耗发生在哪一段：到货即坏、库内坏、门店坏，三类原因不同。
- 与供应商约定**成熟度区间和到货验收标准**，而不是只约定规格等级。
- 到货后24小时内完成分档，成熟度高的先走。
- 控制单批库存周转天数，宁可小批量高频补货。
- 对黑心/冷害做切开抽检，不要只看外观。
