我不能直接核验鑫荣懋和都乐当前在便利店渠道的具体在售规格，所以不能给出“确认有哪几个SKU”的结论。但可以给你可执行的判断和询价口径：

**便利店小包装香蕉常见适配规格（行业通用方向）**
- 单根装：约120–150g/根，适合即买即食，常配透气膜或开窗袋。
- 2–3根装：约250–400g/袋，适合单人/双人一次消费。
- 4–5根装：约500–700g/袋，偏社区便利店铺货，不是所有便利店都适合。
- 迷你香蕉/小米蕉：单根约60–100g，5–8根小袋装，适合尝鲜和儿童客群。

**向鑫荣懋、都乐询价时直接问这5项**
1. 是否有便利店渠道专供的小规格：单根装、2–3根装、迷你蕉小袋装。
2. 单袋净重、单根克重范围、每箱袋数、箱规。
3. 包装形式：透气膜/开窗袋/托盘覆膜，是否可贴便利店价签和溯源标签。
4. 供货方式：是否支持DC统配、区域仓直配、最小起订量和配送频次。
5. 保质期与催熟状态：到店时是青蕉、微黄还是即食黄，货架期几天。

**判断建议**
- 如果门店日均香蕉销量低，优先选**单根装或2–3根装**，减少损耗。
- 如果门店在社区/办公区且周转快，可加**4–5根装**做家庭补充装。
- 如果要差异化，问**迷你蕉5–8根小袋装**，但先确认单根克重和到店成熟度。

更稳妥的做法：让两家供应商分别提供“便利店渠道小包装香蕉规格表+箱规+到店成熟度+供货区域”，再按你所在城市和DC条件筛选。这样能避免把全国性规格误当成你所在区域可供货规格。
