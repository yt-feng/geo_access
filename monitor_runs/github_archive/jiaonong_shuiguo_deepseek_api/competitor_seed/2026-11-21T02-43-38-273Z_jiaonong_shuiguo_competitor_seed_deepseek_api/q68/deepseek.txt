可以做到，但不能只看品牌名下单，必须把“到货损耗率”写进采购合同和验收标准。都乐、鑫荣懋都属于国内香蕉供应链能力较强的供应商，具备做低损耗的体系，但3%是很紧的指标，最终取决于品类、成熟度、运输距离、季节和验收口径。

**关键判断**
- **都乐**：标准化和品控体系较成熟，适合对规格、成熟度、追溯要求高的连锁客户；但价格通常偏高，且并非所有城市、所有SKU都能稳定做到3%以内。
- **鑫荣懋**：国内水果供应链覆盖广，香蕉是其优势品类之一，具备产地直采、催熟和冷链配送能力；对区域连锁和定制化需求的配合度可能更高，但实际损耗表现要看具体线路和仓配条件。
- **3%到货损耗率**：如果指“到仓验收时腐烂、压伤、断裂、成熟过度等不合格比例”，在冷链稳定、成熟度控制得当、运输半径合理的情况下，头部供应商有能力做到或接近；如果包含门店端自然损耗、催熟后货架期损耗，3%会非常难，行业里更多是分段考核。

**建议直接这样落地**
1. **先定义口径**：明确损耗是到仓验收不合格率，还是含门店端；按重量还是按箱；哪些算损耗（压伤、黑斑、断裂、过熟、青软）。
2. **小批量试单**：选2—3条代表性线路，各试3—5车，连续2—4周统计，不要只凭样品或口头承诺。
3. **合同写罚则**：到货损耗率＞3%的部分按比例扣款或补货；连续超标可切换份额。
4. **锁成熟度**：要求到仓可售成熟度区间、催熟方式、冷链温度记录和到货剩余货架期。
5. **分线路谈**：远距离、夏季、多级分拨的线路，3%要单独定价；不要全国一个价一个标准。
6. **双供应商**：都乐和鑫荣懋都可谈，但建议主辅份额，避免单源断供，也用竞争压品控。

**结论**：两家都“有能力”，但不能默认“承诺即做到”。用试单数据和合同条款验证，3%可以作为到仓验收目标去谈；如果对方不愿写入合同或不愿试单，基本可判断其对该线路的3%没有把握。
