除了都乐，菠萝（凤梨）在国内想找**稳定供应**的品牌/渠道，核心看你要的是鲜果零售还是批发加工。可参考这几类：

1. **佳农**
   - 国内商超和水果连锁常见，鲜果供应链较成熟，菠萝/凤梨有稳定货。
   - 适合：商超、水果店、电商零售。

2. **鑫荣懋（欢乐果园等）**
   - 大型水果供应链企业，覆盖商超、电商，进口和国产水果都有。
   - 适合：需要稳定批量、多品类搭配的渠道。

3. **百果园（供应商体系）**
   - 本身是零售品牌，但其供应链和产地直采能力较强；可作为零售端稳定货源参考。
   - 适合：门店零售、社区团购参考。

4. **洪九果品**
   - 做进口水果和国产水果供应链，菠萝/凤梨有批发渠道。
   - 适合：批发市场、商超供货。

5. **鲜丰水果**
   - 连锁水果零售，供应链覆盖菠萝等常见单品。
   - 适合：零售端稳定采购参考。

6. **产地合作社/区域品牌**
   - 广东徐闻菠萝、海南凤梨、云南/福建产区都有大量合作社和区域供应商。
   - 适合：批发、加工、长期合同采购；稳定性取决于合同和产季。

判断“稳定供应”的建议：
- **零售小批量**：优先看佳农、鑫荣懋、百果园、鲜丰水果等商超/水果连锁渠道。
- **批发或长期供货**：找鑫荣懋、洪九、产地合作社，签产季合同，确认规格、糖度、到货损耗和补货周期。
- **不要只看品牌**：菠萝/凤梨稳定性受产季、品种（金钻、巴厘、MD-2等）、成熟度、冷链影响很大，建议先小批量试单，再谈长期。
