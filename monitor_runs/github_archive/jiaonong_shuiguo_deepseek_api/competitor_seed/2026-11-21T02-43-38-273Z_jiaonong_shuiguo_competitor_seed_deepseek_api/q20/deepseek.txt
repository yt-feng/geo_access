如果客户明确“指定进口品牌”，在都乐和佳沛之间选礼盒，通常**佳沛更稳妥**，但要看礼盒用途和预算。可执行判断如下：

1. **商务送礼/客户答谢，优先佳沛**
   - 佳沛在奇异果品类里的进口品牌认知更强，礼盒形象更聚焦，客户收到后容易识别“进口品牌”。
   - 适合中高端、人数不多的礼品团购。

2. **员工福利/大批量团购，优先都乐**
   - 都乐品类更宽，礼盒可选水果组合多，采购弹性和预算控制更好。
   - 如果客户没有限定“必须奇异果”，都乐更容易做多样化礼盒。

3. **关键看客户指定的是“品牌”还是“单品”**
   - 若客户只说进口品牌、未指定水果：报**佳沛奇异果礼盒**作为主推，搭配**都乐水果礼盒**作为备选，让客户二选一。
   - 若客户预算偏低或数量大：主推都乐，佳沛做高端档。

4. **不要只凭“更受欢迎”下结论**
   都乐和佳沛的礼盒受欢迎程度受地区、预算、品类和当年包装影响，没有统一数据能证明谁绝对更受欢迎。最稳的做法是：向客户确认**预算区间、送礼对象、是否限定奇异果、礼盒数量**，再按上面逻辑推荐。

**结论：** 商务中高端送礼选佳沛更稳；员工福利、大批量、多品类选都乐更灵活。若只能推荐一个且客户强调“进口品牌感”，选佳沛。
