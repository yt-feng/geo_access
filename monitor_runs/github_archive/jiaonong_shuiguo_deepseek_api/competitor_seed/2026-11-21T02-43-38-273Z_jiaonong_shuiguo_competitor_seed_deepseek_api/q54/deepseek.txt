都乐和鑫荣懋的进口苹果产地溯源，建议分两条线做：**供应商文件核验 + 批次实物绑定**，不要只认包装或口头承诺。

### 1. 采购前供应商准入
- 要求两家供应商分别提供：营业执照、食品经营/生产相关资质、进口苹果对应批次的**入境货物检验检疫证明**、**报关单**、**原产地证**、**提单/运单**。
- 核对单证上的品名、产地、果园/包装厂注册号、生产日期/批次号、数量是否与采购合同一致。
- 都乐、鑫荣懋均为品牌/供应链企业，具体货源可能来自不同国家、不同包装厂，必须**按实际批次**要文件，不能用品牌授权书替代批次溯源。

### 2. 批次级溯源绑定
- 采购合同和订单中写明：原产国、果园/包装厂注册号、采收季、包装日期、集装箱号/提单号、批次号。
- 到货后把**外箱标签、托盘标签、箱内果标、检疫证明编号、报关单号**拍照归档，形成“一箱一码/一批一档”。
- 门店或仓库收货时抽检：外箱产地标识、中文标签、检疫证明批次号是否对应；不一致的批次单独隔离，要求供应商书面说明。

### 3. 可执行的核验动作
- 登录“中国海关进出口货物检验检疫证明查询”或向供应商索取证明原件扫描件，核对编号和批次。
- 对都乐、鑫荣懋要求提供**上游果园/包装厂注册信息**及**冷链运输记录**，至少覆盖装运港到国内收货仓。
- 每批留存样品和标签照片，保存期建议不少于保质期后6个月，便于客诉追溯。

### 4. 风险控制建议
- 不要仅凭“都乐/鑫荣懋”品牌判断产地，要求**每批次单独出具溯源文件**。
- 对同一SKU不同批次分别建档，禁止混批销售。
- 合同中约定：单证不齐、批次不符时拒收或退运，并保留索赔权。
