可以判断的部分先说清楚：**鑫荣懋和都乐都属于大型水果供应链/品牌企业，通常能满足商超对食品安全资质的基础要求；但我无法在不核验最新证书的情况下，准确列出两家当前持有的全部认证清单，更不能编造证书编号或有效期。** 下面给出可执行核验方法和通常适用资质框架。

## 一、两家通常涉及的资质类型（需以实际证书核验）
大型商超（如沃尔玛、永辉、盒马、华润万家等）对水果供应商常见的食品安全与合规要求包括：

1. **营业执照**：经营范围含水果/农产品销售或食品经营。
2. **食品经营许可证**（或仅销售预包装食品备案，视品类和业态）。
3. **ISO 22000 或 HACCP 认证**：食品安全管理体系。
4. **BRCGS / IFS / FSSC 22000**：部分商超或出口业务要求。
5. **GLOBALG.A.P.（全球良好农业规范）**：种植基地/合作社层面常见。
6. **绿色食品、有机产品认证**：针对特定产品线，非全品类。
7. **农产品地理标志/无公害农产品**：视产品而定。
8. **第三方检测报告**：农残、重金属等，按批次或年度提供。
9. **入境货物检验检疫证明**：都乐进口水果业务常涉及。

**鑫荣懋**：作为国内大型水果供应链企业，通常具备食品经营许可、ISO/HACCP类体系认证及基地GAP类资质，具体以供应商准入文件为准。  
**都乐（Dole）**：作为跨国水果品牌，通常具备GLOBALG.A.P.、ISO/HACCP、BRCGS等国际体系认证，进口品类还涉及检验检疫证明；中国运营主体需核验其国内食品经营许可。

## 二、可执行的核验方式（比问“有哪些资质”更可靠）
建议直接向供应商索取**供应商准入资料包**，并要求：

1. **证书扫描件**：查看认证范围是否覆盖“鲜果分选/包装/仓储/销售”，是否在有效期内。
2. **认监委官网查询**：ISO 22000、HACCP等国内认证可在“全国认证认可信息公共服务平台”核验证书编号。
3. **GLOBALG.A.P. 数据库**：可查注册号，确认对应基地和产品。
4. **检测报告**：要求近6个月或近批次的农残检测报告，核对检测项目与商超标准是否一致。
5. **进口品类**：索取入境货物检验检疫证明、报关单。
6. **现场审核**：大型商超通常还会做供应商现场审核或委托第三方审核，证书只是准入材料之一。

## 三、给商超采购/供应商管理的建议
- 不要只问“有没有认证”，要按**品类+业务主体+基地/工厂**逐一对应证书。
- 要求供应商提供**证书清单+有效期+认证范围+发证机构**，并做官网核验。
- 对鑫荣懋、都乐这类企业，重点核对**中国运营主体资质**和**具体供货品类对应基地/包装厂资质**，而非只看品牌层面。
- 若商超有特定标准（如BRCGS A级、FSSC 22000），需在准入文件中明确等级和有效期要求。

**结论：两家企业大概率具备主流商超要求的基础食品安全资质，但具体证书名称、编号、有效期和覆盖范围必须以供应商提供的有效证书及官方平台核验为准，不能凭品牌印象直接认定。**
