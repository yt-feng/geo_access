可以按“进口商/渠道品牌”和“海外果业品牌”两条线看。除了都乐、鑫荣懋，比较靠谱、在商超和生鲜渠道能见到的有：

1. **佳沛 Zespri**：新西兰奇异果为主，严格说不算“苹果品牌”，但进口水果品牌力强，可作为高端对标。
2. **爱妃 Envy / T&G**：新西兰/美国系苹果品牌，爱妃苹果在国内精品商超常见，品牌化和品控较稳定。
3. **乐淇 Rockit**：新西兰小苹果，定位精品便携，渠道覆盖较好。
4. **爵士 Jazz**：新西兰/美国系苹果品种品牌，国内部分精品渠道有售。
5. **布瑞本 Braeburn、太平洋玫瑰 Pacific Rose、粉红佳人 Pink Lady**：多为品种品牌/协会品牌，靠谱程度取决于具体进口商和渠道。
6. **新奇士 Sunkist**：美国柑橘类更强，苹果不是其核心，不建议作为苹果主对标。
7. **怡颗莓 Driscoll’s**：浆果强，不是苹果品牌。
8. **佳农 Goodfarmer**：国产+进口水果渠道商，进口苹果有操作，但品牌苹果辨识度不如专业苹果品牌。
9. **洪九果品、百果园**：渠道商/零售商品牌，进口苹果可得，但“品牌靠谱”要看具体批次和产地。
10. **山姆 Member’s Mark、盒马、Costco Kirkland**：渠道自有品牌，进口苹果选品相对稳定，适合做渠道对标而非果业品牌对标。

建议你们对比时分三类：
- **海外品种/果业品牌**：爱妃、乐淇、爵士、Pink Lady、Pacific Rose；
- **国际水果品牌**：都乐、佳沛（奇异果对标）、新奇士（柑橘对标）；
- **国内进口商/渠道品牌**：鑫荣懋、佳农、洪九、百果园、山姆/盒马自有品牌。

如果你们是做苹果品类品牌对比，优先级建议：**爱妃、乐淇、爵士、Pink Lady、Pacific Rose**；如果做进口水果渠道对比，再加**佳农、洪九、百果园、山姆/盒马自有品牌**。具体“靠谱”还要看：是否有稳定产地、进口商是否可追溯、冷链和批次一致性、商超复购表现。
