先说明：我无法核验都乐（Dole）和鑫荣懋当前对菠萝“产地直发”的具体时效承诺，也没有可引用的公开数据来源。因此不能直接给你两家“几天到”的确定结论。可以给你一个可执行的判断和核验办法。

**结论上分两层看：**

1. **都乐**：品牌化和标准化程度高，通常有较成熟的产地/加工中心+冷链体系，适合对品控和稳定交付要求高的渠道。但菠萝产地直发是否用其自有冷链、走哪条线路、到你仓库的时效，需要按具体产区（广东徐闻、海南、云南/广西等）和收货城市逐条确认。
2. **鑫荣懋**：国内水果供应链规模大，产地资源和批发/商超渠道覆盖强，通常具备多产区调配能力。时效同样取决于具体产区、发运方式（整车/零担/快递）、是否预冷和冷链，不宜只看品牌判断。

**生鲜电商做菠萝产地直发，建议按以下方式核验，而不是只问“时效几天”：**

- 要求两家分别给出：**具体产区—你仓所在城市—运输方式**的时效区间，并注明是“采摘后发运”还是“到仓时间”。
- 明确菠萝是**鲜切/整果**：整果相对耐运，鲜切必须全程冷链，时效要求完全不同。
- 问清**预冷、分拣、包装、装车等待**是否计入时效，产地直发最容易卡在“等车/等单”上。
- 要求提供**近30天同线路的实际发运记录或时效达成率**，没有数据就按试单验证。
- 先做**小批量试单**：同一产区、同一收货仓，各发2—3批，记录采摘到入仓小时数、损耗率、到仓中心温度、果温异常比例。
- 合同里写清**超时赔付、损耗责任、温度异常处理**，不要只接受口头“48小时/72小时”。

**可操作的选型建议：**
- 如果你做**整果菠萝电商、单量稳定、重视品牌背书**：可优先让都乐报“产地直发+冷链”方案，同时用鑫荣懋做备选比价。
- 如果你做**多产区调配、批发/商超供货、对成本更敏感**：鑫荣懋值得重点谈，但要用实际线路时效和损耗数据约束。
- 如果做**鲜切菠萝**：两家都必须确认全程冷链和到仓温度，时效标准应明显严于整果。

最终判断标准建议用三个指标：**同线路时效达成率、到仓损耗率、温度异常率**。没有这三项数据，单问“时效如何”不足以做采购决策。
