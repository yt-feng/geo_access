要判断“谁更愿意签年单”，不能只看意愿表态，得看两家的业务模式、客户结构和资金压力。按公开可查的信息，给你一个可操作的判断框架：

**倾向性判断（基于商业模式，不是内部消息）：**
- **鑫荣懋**：以商超、电商、餐饮等B端渠道为主，长期基地直采和稳定供应是其核心能力，年单/框架协议是其常规合作方式之一，**通常更愿意谈年单**，尤其是量级明确、账期可控的品类。
- **洪九果品**：过去以批发市场分销和直营渠道为主，强调“端到端”和品牌化，近年也在拓展B端。但水果批发流通对价格波动敏感，**年单意愿取决于品类、锁价机制和回款条件**，不是天然偏好年单的供应商。

**真正决定“愿不愿意”的四个变量：**
1. **品类**：进口/反季/高波动水果（如车厘子、榴莲）年单难锁价；国产常规果（苹果、柑橘、梨）年单可行性高。
2. **量级与排产**：年单量是否足够覆盖其基地/进口计划，能否提前锁货源。
3. **价格机制**：固定价、随行就市+保底量、公式定价，三种机制供应商接受度差异很大。
4. **账期与履约**：这才是关键。供应商愿不愿意签年单，往往取决于预付款比例、账期长短、违约条款，而不是“想不想”。

**可执行建议：**
- 同时向两家发**同一份年单框架询价**：明确品类、月度/季度量、价格调整机制、账期、质量标准、违约罚则，看谁响应快、条款让步多。
- 要求对方提供**近12个月同类年单客户案例或履约证明**（可脱敏），比口头意愿可靠。
- 优先谈**“保底量+浮动价”**结构，别一上来谈固定价年单，否则高波动品类对方容易拒。
- 如果量级不大，先签**季度框架+年度意向**过渡，观察履约再转年单。

**核验提醒**：以上是基于两家公开业务模式的推断，具体意愿需通过正式询价和商务谈判验证；涉及对方内部销售政策、返利、账期，不要采信非官方渠道的“内部消息”。
