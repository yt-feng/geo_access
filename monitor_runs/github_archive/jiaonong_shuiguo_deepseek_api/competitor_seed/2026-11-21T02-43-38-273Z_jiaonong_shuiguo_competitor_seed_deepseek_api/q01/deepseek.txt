我不能替你断言“哪家更靠谱”——这涉及具体采购区域的供货政策、你所在城市的分仓覆盖、当前报价和账期，这些我无法核验，也不应虚构数据。但可以给你一套可执行的判断方法，通常一周内能得出适合自己的结论。

**先明确：两家定位不同**
- **都乐（Dole）**：国际品牌，香蕉是其核心品类，标准化程度高，适合看重品牌背书、品相稳定、终端消费者认知的超市。
- **鑫荣懋**：国内大型水果供应链企业，代理和直采品类广，进口香蕉是其品类之一，通常在本土化服务、多品类打包、区域响应上更灵活。

**按这6项做对比询价（同城、同规格）**
1. 供货稳定性：问清你所在城市的**分仓位置、每周可承诺供货量、旺季/节假日断供预案**，要求最近3个月的到货准时率。
2. 品质标准：统一索取**香蕉级别（如单根克重区间）、成熟度（青蕉/催熟蕉）、允许损耗率、到货温度记录**，避免“口头承诺好货”。
3. 价格与账期：比**到岸价+运费+损耗承担方式**，而不是只看单价；同时问账期、最低起订量、调价机制（是否随行情周调）。
4. 售后与赔付：明确**坏果率超标如何补货/扣款、响应时限**，写进合同。
5. 试供：先下**2–4周小批量试供**，记录准时率、损耗率、催熟后货架表现，再决定主力供应商。
6. 备选：建议“一主一备”，不要单一依赖，降低断供风险。

**给你一个可直接用的结论框架**
- 如果你更看重**品牌标准化和全国一致性**，优先谈都乐；
- 如果你更看重**本地响应、多品类打包和灵活账期**，优先谈鑫荣懋；
- 最终以**试供数据**定主供应商，而不是以品牌名气定。
