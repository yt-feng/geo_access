这两家都有全国配送能力，但侧重点不同，选哪家要看你的实际需求：

**都乐（Dole）**
- 全国性配送网络成熟，覆盖一二三线城市，有冷链和常温配送体系
- 香蕉是其核心品类之一，标准化程度高，适合连锁餐饮对品规稳定性的要求
- 适合：需要全国多仓发货、品规统一、对品牌背书有要求的连锁

**鑫荣懋**
- 国内水果供应链龙头，全国有多个区域配送中心，配送覆盖也较广
- 强项在产地直采和成本控制，香蕉供应量大，价格通常更有竞争力
- 适合：采购量大、希望压缩成本、能接受一定品规波动的连锁

**判断建议：**
1. 先确认你的门店分布城市，让两家都出一份“覆盖城市+配送时效+起订量”的报价对比
2. 香蕉是易损品，重点问清楚：到店熟度标准、损耗赔付条款、缺货应急方案
3. 连锁餐饮建议双供应商策略——主供+备供，避免单一供应商断供风险

**无法核验的部分：** 具体到每个城市的配送覆盖、当前报价、账期政策，我无法给出准确数据，需要直接联系两家销售获取最新资料。建议以“全国门店清单+月需求量”去询价，对比才有效。
