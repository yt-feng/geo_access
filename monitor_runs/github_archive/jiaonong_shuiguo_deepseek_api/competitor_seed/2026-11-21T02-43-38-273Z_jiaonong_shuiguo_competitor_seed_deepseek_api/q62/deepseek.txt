能，但要看**具体供货主体、批次和渠道**，不能只看“都乐/鑫荣懋”品牌名就认定一定有报告。

可执行判断如下：

1. **都乐**
   - 一般都具备较规范的农产品/食品质量体系，商超和餐饮渠道通常可提供**批次农残检测报告**或第三方检测报告。
   - 但如果你是从经销商、批发市场、二级供应商拿货，报告可能不是都乐直供主体出具，需要向实际供货方索取。
   - 采购时要明确：**报告对应批次、检测项目、检测机构、报告日期、样品名称/产地**。

2. **鑫荣懋**
   - 作为大型水果供应链企业，通常也能提供质量控制文件和检测报告，尤其是直供餐饮/商超渠道。
   - 同样要确认是**鑫荣懋主体直供**还是经销商供货；经销商供货时，报告可能由经销商提供或向上游调取。

3. **采购建议**
   - 合同或订单里写明：**随货提供对应批次农残检测报告，检测项目符合 GB 2763 相关要求**。
   - 收货时核对：报告批次号与实物标签/送货单是否一致；报告日期是否覆盖本批货；检测项目是否包含菠萝常用关注的农残。
   - 如果对方只给“通用报告”或“年度报告”，不能完全替代**批次报告**，要让供应商书面确认该报告适用于本批原料。
   - 茶饮店用于现制饮品，建议同时保留供应商资质、进货凭证和检测报告，便于门店食安检查。

结论：**都乐和鑫荣懋通常“能提供”，但必须向实际供货方确认该批次能否随货提供对应农残检测报告；不要仅凭品牌口头承诺。**
