除都乐（Dole）和佳沛（Zespri）外，进口水果礼盒可优先考虑以下品牌，按品类列举：

**综合/多品类水果品牌**
- **新奇士 Sunkist**：美国柑橘类代表，脐橙、葡萄柚礼盒常见，品牌认知度高。
- **怡颗莓 Driscoll's**：浆果类强势品牌，蓝莓、树莓、黑莓礼盒适合中高端团购。
- **佳沃 Joyvio**：有进口与国产混合水果线，礼盒包装较成熟（注意区分进口/国产批次）。
- **鲜丰水果/百果园企业团购线**：不是纯进口品牌，但可整合多国进口水果做定制礼盒，适合需要“一站式组盒”的团购。

**单品强势品牌**
- **爱妃 Envy**：新西兰/美国苹果，礼盒溢价能力强，适合高端商务礼品。
- **火箭果 Rockit**：新西兰小苹果，便携装礼盒有记忆点。
- **乐淇/佳沛之外的新西兰奇异果**：如 **Oravida** 等小众品牌，但渠道稳定性不如佳沛。
- **SunGold 以外的葡萄品牌**：如 **Sable & Co**、**M&G** 等，需核实当季货源。
- **秘鲁/智利蓝莓品牌**：如 **Hortifrut**、**Camposol**，多以原料或简装出现，礼盒化程度不如怡颗莓。
- **泰国/越南水果**：如 **K-Fresh**（泰国椰青、榴莲等），礼盒需渠道定制。

**实用建议**
1. 团购礼盒优先选“品牌单品+定制外盒”，比直接采购品牌成品礼盒更灵活、毛利更可控。
2. 进口水果受季节和口岸影响大，锁定品牌前先确认当季到货规格、糖度标准和损耗赔付条款。
3. 若客户看重“进口品牌背书”，组合建议：新奇士橙 + 怡颗莓蓝莓 + 爱妃苹果，覆盖大众到高端价位。
4. 小众进口品牌礼盒渠道不稳定，建议要求供应商提供报关单、产地证和当批次质检，避免“贴牌进口”。
