进口菠萝旺季缺货，先分清楚是**短期断供**还是**结构性缺货**，再决定动作。都乐、洪九果品这类企业通常有应急机制，但具体方案属于企业商业信息，外部无法核验，不能替它们背书；下面给可执行判断和向供应商要方案的话术。

**一、先判断缺货类型**
1. **船期/口岸问题**：到港延迟、通关慢、冷链拥堵。通常2–4周可缓解，优先做替代规格和预售。
2. **产地季节性断档**：菲律宾、泰国、哥斯达黎加等产区交替期。需切换产地或品种，不能只等原产地。
3. **需求突增或渠道囤货**：终端加价、限购、锁库存，防止恐慌性断货。
4. **品质/规格缺口**：大果缺、小果多，或反之。用规格替换和分级销售解决。

**二、立即执行的应急动作**
- **锁在途和在库**：盘点已下单未到港、在港未提、在库可售库存，按SKU和到货日排序。
- **切换产地与品种**：菲律宾缺货时评估泰国、哥斯达黎加、厄瓜多尔等替代来源；同时用凤梨、金钻菠萝等品种补位。
- **规格替代**：大果缺用中果做促销装，小果缺用大果做分级定价，避免一刀切缺货。
- **预售+限购**：对稳定客群做预售锁客，对散客限购，防止渠道囤货。
- **合同条款核查**：检查供应商的不可抗力、延迟交付、替代供货条款，明确索赔和补货优先级。
- **B端客户提前沟通**：餐饮、商超客户给替代方案和到货时间表，避免临时违约。

**三、向都乐/洪九果品要应急方案的话术**
直接问对方区域销售或大客户经理，要求书面回复：
1. 当前缺货涉及哪些SKU、预计恢复时间；
2. 是否有替代产地/品种/规格的可用库存；
3. 已签合同订单的交付优先级和延迟补偿；
4. 能否锁量锁价、支持预售或分批到货；
5. 冷链和口岸异常时的转港、改港方案。

**四、判断建议**
- 如果缺货预计**2周内缓解**：以锁库存、规格替代、限购为主，不轻易换供应商。
- 如果**超过1个月**：必须启动第二产地和第二供应商，不能依赖单一品牌。
- 都乐、洪九作为头部企业通常有产地多元化和冷链调度能力，但**具体应急方案需其书面确认**，不要仅凭口头承诺做采购决策。
