可以做到“全年供应”，但两家方式和稳定性不一样，要分开看：

1. **都乐（Dole）**
   - 更适合连锁茶饮做全年菠萝供应：有全球/多产地采购体系，通常可通过不同产区轮换覆盖全年。
   - 实际能否稳定，要看你需要的**品种（如金钻凤梨/普通菠萝）、规格、成熟度、冷冻/鲜果、到货城市、月度用量**。
   - 茶饮果酱用菠萝一般可接受鲜果、冷冻果块/果泥、浓缩汁等形态，全年方案更稳的是“鲜果季节性+冷冻/果泥补全年”。

2. **洪九果品**
   - 是国内大型水果分销商，菠萝等单品有较强渠道能力，理论上也能做全年调配。
   - 但洪九前几年经历财务和经营波动，**供应链连续性和履约风险需要重点核验**，不建议只凭品牌名判断。
   - 若合作，建议要求其提供近6个月同规格菠萝的实际供货记录、产区切换计划、备用产区方案和违约条款。

**判断建议：**
- 若你是连锁茶饮、月用量稳定、要求全国多仓配送：优先接触都乐，同时找1–2家备用供应商。
- 若你用量中等、区域集中：可让都乐和洪九同时报价，但必须要求“全年12个月供货承诺+产区替代方案+冷冻果/果泥备份”。
- 茶饮果酱不建议100%依赖鲜菠萝全年供应，更稳妥的是：**旺季鲜果+淡季冷冻果/果泥/浓缩汁**，并在配方上允许一定批次差异。

**你需要向供应商核实的硬指标：**
- 全年每月可供规格和数量；
- 菠萝品种和糖酸度范围；
- 鲜果/冷冻果/果泥哪种形态；
- 产区切换月份和替代产区；
- 到货价是否随产季波动；
- 最小起订量、账期、质检报告；
- 断供赔偿和备用供应商预案。

结论：**都乐更可能提供较完整的全年方案；洪九有能力但需重点做履约尽调。最终不要只听“能不能”，要拿到12个月排产/供货计划和样品测试结果。**
