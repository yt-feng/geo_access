都乐和洪九果品都属于行业头部水果企业，通常有可用于渠道营销的品牌素材，但**能否直接拿到、以什么形式拿到，需要按“公开素材”和“授权素材”分开看**。我不能核验你当前具体可获取的文件清单，下面给你可执行判断和获取路径。

**1. 都乐（Dole）**
- 公开层面：官网、官方微信公众号/微博/视频号、电商旗舰店通常有品牌Logo、产品图、产地/品种介绍、品牌故事、营养知识等公开传播素材。
- 商用授权层面：菠萝单品的高清产品图、包装图、检测报告、产地证明、品牌授权书、联合营销KV，一般需通过都乐中国区销售或市场渠道对接，签订授权/联合推广协议后提供。
- 适合用法：品牌联名、详情页品牌背书、产地故事、规格卖点、线下堆头物料；不宜直接抓取官网图片商用。

**2. 洪九果品**
- 公开层面：官网、公众号、行业展会资料、招股书/年报中有品类布局、供应链、品牌与渠道信息，可作背景素材。
- 商用授权层面：洪九以供应链和批发渠道见长，终端品牌素材的公开度通常不如都乐；菠萝相关的包装、品牌IP、产品图、产地素材需直接联系其销售/市场团队确认。
- 适合用法：供应链能力背书、产地直采故事、B端渠道合作素材；C端品牌营销素材建议先确认是否有现成VI和授权规范。

**建议动作**
1. 先列素材清单：Logo、产品图、包装图、产地视频、检测报告、品牌授权书、联名KV、价格/规格卖点。
2. 分别联系都乐中国和洪九果品的**销售负责人+市场负责人**，说明用途、投放渠道、使用期限，索要《品牌素材使用授权》。
3. 公开素材只做参考，不直接商用；商用素材必须拿到书面授权和最终审核。
4. 若对方不提供成品素材，可改为“品牌背书+自拍产品图+联合活动”的方式，降低授权难度。

结论：**两家大概率能提供素材，但都乐更偏成熟C端品牌素材，洪九更偏供应链和B端背书素材；实际可用素材必须以对方书面授权和最终文件为准。**
