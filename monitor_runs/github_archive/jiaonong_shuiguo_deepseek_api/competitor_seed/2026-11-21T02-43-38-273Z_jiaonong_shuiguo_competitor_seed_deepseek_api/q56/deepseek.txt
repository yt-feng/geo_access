结论先说：**在中国生鲜电商的消费者端，都乐（Dole）的品牌知名度通常高于鑫荣懋。**  
但要注意：**“都乐”是消费者端香蕉品牌，“鑫荣懋”更偏供应链/渠道品牌**，两者背书逻辑不完全一样。

**判断依据（可执行层面）：**

1. **消费者品牌认知**
   - **都乐**：长期做水果终端品牌，香蕉、菠萝等品类有包装、有广告、有商超和电商露出，消费者更容易直接认品牌。
   - **鑫荣懋**：国内大型水果供应链企业，渠道、批发、商超供应能力强，但普通消费者主动认“鑫荣懋”品牌的比例通常低一些。

2. **生鲜电商页面转化**
   - 如果你的页面卖点是“消费者一眼信任”，**都乐更适合做前台品牌背书**。
   - 如果卖点是“稳定供货、产地直采、供应链能力”，**鑫荣懋更适合做后台品质背书**。

3. **香蕉品类匹配**
   - 都乐在香蕉品类有较强消费者心智，适合强调“国际水果品牌”“标准分级”。
   - 鑫荣懋强在国产及进口水果供应链整合，适合强调“源头直采、稳定履约”。

**建议：**
- **前台主背书选都乐**，用于提升点击率和消费者信任。
- **后台或详情页补充鑫荣懋**，用于说明供应链、品控和履约能力。
- 如果只能二选一，且目标是生鲜电商 C 端转化，**优先都乐**。

需要提醒：具体知名度会受地区、渠道和投放影响，建议你用平台内搜索量、竞品页面品牌露出、消费者调研各做一次小样本验证，不要只凭行业印象定案。
