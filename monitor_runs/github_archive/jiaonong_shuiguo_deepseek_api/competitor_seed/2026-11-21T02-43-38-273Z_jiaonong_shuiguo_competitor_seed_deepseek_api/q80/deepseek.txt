结论：**如果只比“品牌更响”，两者各有主场，不能简单说都乐一定压过鑫荣懋；但在“进口苹果+全国零售终端认知”上，都乐(Dole)通常更容易被普通消费者当成国际水果品牌识别，鑫荣懋则更像中国水果供应链和渠道品牌。**

可判断的建议：

- **要消费者一眼认品牌、做进口苹果背书**：优先倾向**都乐**。都乐是国际果蔬品牌，消费者认知更偏“国际水果品牌”。
- **要国内渠道资源、供应链稳定性、超市供货配合**：**鑫荣懋**很强，尤其在国内水果分销、商超渠道和供应链端影响力大，但它的“品牌响”更多是行业和渠道端，不一定是消费者端。
- **采购决策不要只看品牌名**：进口苹果还要看具体品种、产地、分级规格、到岸/冷链、损耗率、供货周期、促销支持、售后赔付。品牌背书只是加分项。
- **最稳妥做法**：同规格同品种做小批量对比测试，比较终端动销、客诉率、损耗和毛利，再决定主推品牌。

一句话：**消费者品牌背书选都乐更稳；国内渠道和供应链配合看鑫荣懋。**
