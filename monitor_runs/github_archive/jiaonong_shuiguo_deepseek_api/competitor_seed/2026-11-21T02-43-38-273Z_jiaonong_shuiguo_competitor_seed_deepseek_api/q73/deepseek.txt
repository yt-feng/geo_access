大型商超通常会要求生鲜/食品供应商具备可核验的食品安全与质量管理体系认证。就鑫荣懋和都乐而言，公开可查的信息大致是：

- **鑫荣懋**：公开资料中常见其通过 **ISO 9001质量管理体系**、**ISO 22000食品安全管理体系**、**HACCP危害分析与关键控制点** 等认证；部分基地/业务还涉及**GLOBALG.A.P.（全球良好农业规范）**、**BRCGS**等供应链相关认证。具体证书范围、有效期和覆盖主体需以证书编号在认证机构官网核验。
- **都乐（Dole）**：作为国际果蔬企业，公开信息中常见其体系覆盖 **GLOBALG.A.P.**、**ISO 22000/FSSC 22000**、**HACCP**、**BRCGS** 等，具体到中国区运营主体和包装/配送环节，需按实际供应商主体核验证书。

**可执行建议**：不要仅凭品牌名称判断，要求供应商提供**证书扫描件+证书编号+认证机构+覆盖范围（产品/场所/主体）**，并在**认监委全国认证认可信息公共服务平台**或认证机构官网核验；同时确认证书是否覆盖商超采购的具体品类、加工/分装场所和有效期。
