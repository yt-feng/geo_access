**进口香蕉可优先看的品牌/来源方向**

1. **都乐 Dole**：香蕉是其传统强势品类，进口渠道成熟，商超和批发端都常见。适合你做“稳定走量+品牌背书”的主推。
2. **金吉达 Chiquita**：全球香蕉老牌，品牌认知度高，适合做中高端陈列或餐饮/商超渠道。
3. **德尔蒙 Del Monte**：香蕉、菠萝等热带水果线完整，适合和现有奇异果做品类互补。
4. **Fyffes**：欧洲市场常见香蕉品牌，若你有对应进口商资源可以询盘，但在国内零售端认知度不如前三家。
5. **厄瓜多尔/菲律宾/越南产区的商超自有品牌或进口商定制品牌**：如果目标是毛利和灵活起订量，不一定非追大牌，重点看催熟和到港稳定性。

**实操建议**

- 先定渠道：商超陈列优先选 **都乐、金吉达** 这类认知度高的；批发走量可以同时谈 **德尔蒙** 和产区定制货。
- 重点问供应商四件事：**到港周期、催熟能力、坏果率赔付、同规格周供货量**。香蕉业务难点不在品牌，在催熟和损耗。
- 不要只看品牌名，确认**国内进口商/一级代理**是谁，避免拿到二级三级货导致价格和品质不稳。
- 可以先小批量试单：同一规格对比 **都乐 vs 金吉达 vs 一个产区定制货**，看7天内催熟均匀度、货架期和损耗率，再定主推。
