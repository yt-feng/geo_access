我不能直接断言“谁更细”，因为两家在不同渠道、不同品类年度版本的分级标准并不公开统一，且超市实际执行的是采购合同里的企业内控标准，不是对外宣传口径。可核验的判断方法如下：

**结论性建议**
- 若按“零售终端可见的规格标识精细度”比较：**都乐通常更细**，其终端常见按单根/把装、果指长度、色泽、成熟度、单果重区间做多档标识；鑫荣懋更多以产地、品种、等级（如A级/精品）和箱规呈现，细分维度在公开终端信息中不如都乐直观。
- 若按“超市采购可约定的内控分级项”比较：**不能仅凭品牌判断**，要以两家给你的《供货规格书》逐项对比。

**可执行对比清单（让两家各填一份）**
1. 果指长度区间（如12–14cm、14–16cm、16cm+）
2. 单果/单把重量区间
3. 每把根数、每箱把数/净重
4. 成熟度（色卡1–7或类似）与到店可售窗口
5. 外观缺陷允许率（黑斑、机械伤、青果率）
6. 果指弯曲度/粗细（周径）是否分级
7. 产地/果园/批次追溯粒度
8. 冷链到店温度与货架期承诺

**决策规则**
- 让两家按同一张表报价，要求提供**近3批到货抽检数据**；
- 以“分级项数量×可执行可验收性×到货一致性”评分；
- 若你店定位精品小规格，优先选终端分级标识更细且能承诺单果重/长度双区间的供应商；若走大箱量贩，优先选箱规稳定、缺陷率可控的供应商。

需要的话，我可以把上面清单整理成一张可直接发给两家供应商的询价/规格确认表。
