如果在推进菠萝品牌营销，通常可以按“品牌方是否提供素材”分别看：

- **都乐（Dole）**：通常有较成熟的水果品牌营销素材体系，但菠萝相关的具体素材是否对生鲜电商开放，需要直接对接都乐中国区的市场/渠道负责人确认。可优先问：品牌授权、产品图/视频、包装图、产地故事、营养卖点、检测报告、联合活动权限。
- **洪九果品**：以水果供应链和渠道分销为主，是否提供终端品牌营销素材取决于合作层级和具体单品。需要对接其对应品类销售或市场人员，确认是否有菠萝单品素材、包装/箱规图、产地与品控资料、授权范围。
- **更稳妥的做法**：不要假设两家都会提供完整素材。先列出你需要的素材清单，分别向两家发正式需求，明确用途（电商详情页/直播/短视频/线下物料）、使用期限、是否可二次剪辑、是否允许露出品牌Logo。
- **可执行的判断标准**：如果对方能提供“品牌授权+产品图/视频+卖点文案+检测/品控资料”，就可支撑品牌营销；如果只给产品图和报价，则只能做渠道促销，不适合做品牌化内容。
