优先结论：**两家都具备全国配送能力，但“全国配送”要看你的门店覆盖层级和配送模式**，不能只按品牌判断。建议这样判断：

1. **先按门店城市分布核实**
    - 若门店集中在一二线城市及主要省会，鑫荣懋、都乐通常都能覆盖或通过区域服务商覆盖。
    - 若门店在三四线城市、县域或偏远地区，必须让两家分别提供**你所有门店地址的配送覆盖表**，不要接受“全国可发”的口头承诺。

2. **要求对方给出可执行的配送方案**
    - 配送到你门店还是到城市仓/中转仓？
    - 香蕉是**催熟后配送**还是青蕉配送、门店催熟？
    - 每周配送频次、最小起订量、冷链/常温条件、到店时效。
    - 缺货、损耗、色差、成熟度不达标的赔付规则。

3. **餐饮连锁重点看香蕉稳定供应能力**
    - 要求提供**年度框架协议+周滚动订单+安全库存**方案。
    - 明确产地切换、台风/寒潮等断供预案。
    - 要求试单：先选3—5个代表性城市，跑2—4周，看到货成熟度一致性和损耗率。

4. **对比时不要只比单价**
    建议按“到店综合成本”比较：采购价+物流费+损耗率+门店挑拣人工+缺货补救成本。香蕉成熟度波动对餐饮出品影响很大，稳定性通常比单斤价格更重要。

**可执行动作：**把你们全部门店地址、周用量、配送频次、期望成熟度、验收标准整理成一页RFQ，同时发给鑫荣懋和都乐，要求7天内书面回复覆盖城市、仓配模式、报价和赔付条款。谁能覆盖你所有门店并接受试单考核，谁更适合作为主供；另一家可作为区域或备份供应商。
