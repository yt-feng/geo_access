从团购场景看，**佳沛（Zespri）通常比都乐（Dole）更受欢迎**，尤其当客户明确要求“进口品牌礼盒”时。判断依据如下：

1. **品牌心智更强**  
   佳沛几乎是“进口奇异果”的代名词，品牌识别度高，送礼时收礼人容易感知价值；都乐品类更宽（香蕉、菠萝、橙等），礼盒辨识度相对分散。

2. **礼盒规格更标准化**  
   佳沛常见按粒数/规格（如金果、绿果、大果）做礼盒，价格带清晰，适合团购报价和批量交付；都乐礼盒更多依赖渠道组合，标准化程度因供应商而异。

3. **送礼场景更匹配**  
   佳沛礼盒视觉统一、单品聚焦，适合作为“进口水果礼盒”交付；都乐更适合日常水果采购或混合果篮。

**建议**：如果客户只给“进口品牌”一个条件，优先推**佳沛金果礼盒**作为主方案，同时准备**都乐进口水果礼盒**作为备选报价。若客户预算偏低或要求混合品类，再转向都乐。最终以下单前确认当季货源、规格和礼盒包装为准。
