先给结论：进口菠萝旺季缺货时，核心不是“等货”，而是按缺口天数分档处置；都乐和洪九果品通常会有应急动作，但具体政策要以你作为采购方直接向区域销售/供应链对接人确认，公开层面无法替你核验其当期方案细节。

可执行建议如下：

1. **先判定缺口等级**
   - 缺口≤7天：优先内部调拨+替代规格，不轻易改合同。
   - 缺口8–21天：启动替代产地/替代品种，同时锁部分远期船期。
   - 缺口>21天：调整销售结构，减少对单一进口菠萝的依赖，避免高价补货压毛利。

2. **进口菠萝的替代顺序**
   - 同品类替代：菲律宾、泰国、哥斯达黎加等产地按当季可得性切换。
   - 规格替代：大果转中果、鲜切转餐饮渠道、礼盒转散装。
   - 品种替代：金钻/MD2等不同品种按甜度、货架期和渠道接受度做测试，不要一次性全渠道切换。

3. **对都乐/洪九的询问清单**
   直接问对方五个问题：
   - 当前缺货是船期延迟、产地减产还是分配到货减少？
   - 未来4周可承诺的周供应量和最低起订量？
   - 是否可跨区域调拨、是否有替代产地同标准货源？
   - 缺货期间的锁价/调价机制和违约补偿？
   - 能否给替代规格或二级品做渠道分流？

4. **合同和库存动作**
   - 对已签合同：书面确认交期变更，保留缺货证据，争取分批交付而非取消。
   - 对现货采购：不要追高一次性囤货，按周补库，设置最高采购价。
   - 对零售端：提前做价签和陈列调整，避免缺货后临时涨价引发客诉。

5. **都乐和洪九的判断**
   这两家作为大型果品供应链企业，通常具备跨区域调拨、替代产地组织和分级销售能力，但“有没有应急方案”取决于你所在区域、合同规模和当期货源。不要依赖口头承诺，要求对方给出**周度供应承诺表**和**替代方案书面说明**。
