这个问题涉及具体批次和渠道，公开信息不足以给出确定的损耗对比。可以给你一个可判断的框架：

**洪九果品香蕉质量的一般判断**
- 洪九果品以香蕉、火龙果等进口水果为主营品类之一，香蕉是其传统优势品类，通常走产地直采+催熟加工模式。
- 质量表现高度依赖：到货批次、催熟成熟度控制、冷链和门店周转速度。同一供应商不同批次差异可能很大。
- 公开渠道缺乏可核验的系统性质量数据，不宜仅凭品牌下结论。

**和鑫荣懋比到货损耗**
- 鑫荣懋是大型水果供应链企业，香蕉也是其重要品类，供应链和冷链体系较成熟。
- “到货损耗更低”没有公开可核验的统一数据，取决于：产地、季节、运输距离、催熟库水平、到货验收标准、门店销量周转。

**可执行建议**
1. 用同一品类、同一季节、同一运输距离做对照测试：各进3—5批，记录到货成熟度、青软比例、机械伤、黑斑、掉把率、货架期损耗率。
2. 统一验收标准（如按成熟度分级、允许损耗率），否则对比无意义。
3. 向供应商索取：产地批次、催熟日期、冷链温度记录、到货合格率历史数据。
4. 小批量试单再放量，优先看**批次稳定性**而非单批最好表现。
