**直接结论**
- 两家公开资料中通常不会披露“菠萝单品锁价周期”这一细项，锁价一般按客户、品类、季节、采购量和合同类型单独谈，不能用一个固定周期概括。
- 都乐属于品牌鲜果供应商，锁价更可能出现在年度/季度框架协议或大客户合同中；洪九果品以批发分销和基地采购为主，锁价更可能按批次或短期窗口谈。以上是业务模式推断，不是两家官方政策。

**建议这样核实**
1. 向两家销售/大客户部门直接询问三个问题：  
   - 菠萝锁价是按周、按月还是按产季？  
   - 锁价是否含运费、损耗和等级差价？  
   - 违约或行情大幅波动时如何调价？
2. 要求书面报价单或框架合同条款，重点看“价格调整机制”“有效期”“最小起订量”。
3. 同时找2—3家区域一级批发商或产地合作社做对比，锁价周期通常比品牌商更灵活。

**谈判时可参考的合理区间（仅供议价，不是两家官方数据）**
- 短期锁价：7—15天，适合小批量试单。
- 月度锁价：30天左右，适合稳定门店供货。
- 产季锁价：按菠萝产季分段锁定，适合大客户，但通常附带采购量承诺。
