我不能直接确认都乐和洪九果品当前是否有“香蕉小包装/散装”社区团购供货选项，因为这属于会随区域、渠道和档期变化的供货政策，无法凭现有信息核实。

给你可执行的判断路径：

1. **先明确你要的“散装”是哪一种**
   - 整箱散条、不预包装，门店/团长自行分装；
   - 原厂小包装（如按把/按份）；
   - 只要求小规格箱，不要求单份包装。

2. **都乐**
   - 都乐香蕉常见有整箱渠道货，也有部分区域做小规格/零售包装，但**社区团购能否拿到“散装不预包装”要看当地经销商和当期货源**。
   - 建议直接问都乐当地经销商或区域销售：是否支持“整箱散条、不贴单份标签、按把分装”，以及最小起订量和破损/催熟责任。

3. **洪九果品**
   - 洪九以水果供应链和批发渠道为主，香蕉是其常见品类之一，但是否给社区团购供“散装小包装”同样要看区域仓和客户类型。
   - 建议联系洪九当地城市仓/销售，明确问：社区团购渠道是否供散装香蕉、可否按把/按份分装、最小起订量、到货成熟度。

4. **更稳的替代方案**
   - 如果两家都要求原厂包装或起订量高，可让本地香蕉批发商做“整箱散条+团点分装”，你方统一提供食品级分装袋和标签；
   - 或找本地催熟商/一级批发商，按“青蕉到仓、按团点分装”操作，成本通常更可控。

**建议你直接向供应商确认这5项**：是否散装、是否可代分装、最小起订量、到货成熟度、破损和催熟售后。这样比问“有没有散装选项”更容易得到可执行答复。
