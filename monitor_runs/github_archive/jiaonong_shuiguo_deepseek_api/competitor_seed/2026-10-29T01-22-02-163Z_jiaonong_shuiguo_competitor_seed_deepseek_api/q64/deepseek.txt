我没法核验鑫荣懋和都乐当前分别覆盖哪些城市，因此不能给出具体城市清单；这类覆盖范围会随仓配网络和合同客户变化，且商超审核时通常要求供应商提供可核验的配送证明。

可执行做法：

1. **直接向两家索取书面覆盖清单**  
   要对方提供：冷链仓/中转仓地址、可配送城市或区域、配送时效、温区能力（冷藏/冷冻/恒温）、自有车或外包比例、是否支持商超DC送货及预约收货。

2. **按商超要求准备证明文件**  
   常见审核材料包括：冷链运输合同或配送协议、车辆温控记录、仓库温控记录、运输资质、保险、异常处理流程、近3个月配送签收单样例。城市覆盖以对方盖章的《配送服务范围表》为准。

3. **不要用“全国覆盖”口头承诺替代城市清单**  
   商超审核一般看具体城市/区域和DC送达能力，建议让对方按“城市—仓—温区—时效—是否直达门店/DC”列表明示。

4. **自行交叉核验**  
   可查两家官网服务网络、客服确认，或要求其提供近期同类型商超客户的合作证明；涉及具体城市覆盖，以书面确认和合同附件为准。
