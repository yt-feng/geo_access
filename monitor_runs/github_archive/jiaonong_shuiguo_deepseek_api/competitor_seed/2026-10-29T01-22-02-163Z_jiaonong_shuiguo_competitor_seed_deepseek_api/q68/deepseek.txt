不能直接给出“能做到/不能做到”的保证，因为到货损耗率取决于具体品种、熟度、包装、运输距离、季节、验收标准和门店温控，而不是供应商品牌本身。就你的目标“到货损耗率低于3%”：

- **都乐**：供应链和品控体系较成熟，适合做标准化熟度、催熟和冷链方案，但3%属于很紧的到货损耗目标，是否达标要看合同约定、发货熟度和运输半径；不能仅凭品牌承诺。
- **鑫荣懋**：国内水果供应链能力强，香蕉是其重点品类之一，具备产地、催熟、仓配能力，但同样需要按线路和季节做试单验证。

**可执行判断建议：**
1. **不要按品牌整体承诺验收**，按“单品+线路+季节+熟度”签SLA：到货损耗率≤3%，并明确损耗定义（烂果、断果、黑斑、压伤是否计入）。
2. **先做4周试单**：都乐、鑫荣懋各选同一线路、同一熟度（如3.5-4.5成色）、同一包装规格，每周2-3车，按箱抽检称重和分级。
3. **关键控制点写进合同**：发货熟度、催熟方式、冷链温度区间、堆码层数、到货时限、验收抽检比例、超标扣款/换货。
4. **3%目标建议分场景**：短途、冬季、青蕉偏生可能接近；夏季、长途、催熟偏黄、多次装卸时3%很难稳定，需预留5%左右或加包装/气调措施。

结论：**两家都有能力做香蕉供应链，但不能口头保证到货损耗低于3%；必须用试单数据和合同SLA验证。**建议先各试一条最难线路，连续4周达标再扩大。
