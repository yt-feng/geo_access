大型商超通常要求生鲜/食品供应商具备可核验的食品安全管理体系认证。就这两家企业而言，公开可查的常见认证信息如下（具体以企业最新公示和证书为准）：

- **鑫荣懋**：公开资料中常见其通过 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系** 等认证；部分基地/产品还涉及 **GLOBALG.A.P.（全球良好农业规范）**、**绿色食品** 等农产品相关认证。不同法人主体、基地和品类证书可能不同。
- **都乐（Dole）**：作为跨国果蔬企业，公开信息中常见其体系包括 **ISO 22000**、**HACCP**，以及面向初级农产品/种植环节的 **GLOBALG.A.P.**；部分加工/配送环节还会有 **BRCGS** 等零售商常认可的食品安全标准认证。具体到中国境内运营主体和单品，需看对应证书。

**给商超采购的可执行判断建议：**
1. 不要只看企业品牌，要索取**拟供货主体**的证书复印件/扫描件，核对证书上的**企业名称、地址、认证范围、有效期、认证机构**。
2. 重点核验：**ISO 22000 或 HACCP**（加工/流通环节）、**GLOBALG.A.P.**（种植/基地环节）；若为预包装或加工品，可关注 **BRCGS/FSSC 22000**。
3. 到 **全国认证认可信息公共服务平台**（认监委）核验 ISO 22000、HACCP 等证书真伪；GLOBALG.A.P. 可在其官方数据库核验。
4. 要求供应商提供**最近一次审核报告/不符合项关闭情况**，并与商超自身供应商准入标准逐项对照。

由于我无法实时核验这两家企业当前具体证书编号和有效期，建议以供应商提供的证书原件及官方平台查询结果为准，不要仅凭品牌宣传页认定。
