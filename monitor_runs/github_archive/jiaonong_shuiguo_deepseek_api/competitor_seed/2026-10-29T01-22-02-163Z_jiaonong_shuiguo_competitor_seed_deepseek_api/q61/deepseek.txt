结论先说：**都乐（Dole）和洪九果品都没有公开可查的、面向门店使用的香蕉分级企业标准文本**。公开渠道能查到的，是都乐的产品规格/品质描述，以及洪九的行业标准参与情况和内部品控做法，但都不是可直接引用的“企业标准”文件。下面分开说明，并给你一套可直接落地的门店分级标准。

## 一、两家企业的实际情况

**都乐（Dole）**
- 都乐有较成熟的全球产品规格体系（如香蕉按把/梳、长度、粗度、成熟度分档），但公开可查的是产品描述和商品规格，不是标准编号形式的企业标准。
- 都乐中国的公开信息以产品介绍、追溯体系为主，未见公开发布的香蕉分级企业标准文本。
- 判断：**有内部规格体系，但无公开可查证的企业标准**。

**洪九果品**
- 洪九是国内香蕉、火龙果等品类的主要进口/分销商，公开报道提及其参与行业标准、有内部品控分级流程（如按果指长度、色泽、成熟度分拣），但公开渠道查不到其企业标准全文或标准编号。
- 判断：**有内部品控分级，但无公开可查证的企业标准文本**。

> 提示：企业标准若已在“企业标准信息公共服务平台”备案，可自行检索标准编号核实；上述两家未检索到公开备案的香蕉分级标准，故不下“有/无”的绝对结论，只说明“公开不可查证”。

## 二、可直接落地的门店香蕉分级标准（建议采用）

按**外观、果指规格、成熟度、机械伤**四项分级，分特级/一级/二级/等外四个等级：

| 项目 | 特级 | 一级 | 二级 | 等外（折价/加工） |
|---|---|---|---|---|
| 果指长度 | ≥20cm | 17–20cm | 14–17cm | <14cm 或长短混杂 |
| 果指粗度（中段周长） | ≥12cm | 10.5–12cm | 9–10.5cm | <9cm |
| 色泽/成熟度 | 青绿至微黄，均匀 | 微黄，允许轻微色差 | 黄熟，色差可接受 | 过熟/青硬不均 |
| 机械伤 | 无擦伤、无压伤 | 允许≤5%果指轻微擦伤 | 允许≤10%轻微伤 | 明显伤痕、断指 |
| 果形 | 弯曲均匀、无畸形 | 基本均匀 | 允许轻度畸形 | 畸形、双生果多 |
| 梳/把整齐度 | 整齐 | 基本整齐 | 可不齐 | 散果为主 |
| 腐烂/病害 | 无 | 无 | 无 | 有即剔除 |

**门店执行要点：**
1. **到货验收按一级为基准**，特级单独上架做精品陈列，二级走促销或切果/加工。
2. **成熟度按销售节奏分档**：即售区用黄熟（4–5级），周转区用微黄（3级），避免全店同熟度造成损耗。
3. **每批次抽检**：按到货箱数抽5%–10%，记录长度、粗度、伤果率，超阈值整批降级。
4. **等外果不二次上架**，直接转加工或报损，防止拖累整体毛利。
