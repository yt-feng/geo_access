直接结论：**没有公开的、可核验的第三方数据能证明“都乐”或“鑫荣懋”谁的进口苹果质量更稳定**；稳定性更多取决于具体单品、产地/批次、到货季节和你们超市的验收标准，而不是只看品牌。采购决策建议按“可验证指标+试销对比”来做，而不是选一个品牌名就定。

可执行判断方式：

1. **先限定品类再比**
   - 进口苹果要区分：如新西兰爱妃/爵士、美国红蛇果、智利嘎啦等。
   - 同一品牌不同单品、不同产季，稳定性差异可能大于两个品牌之间的差异。

2. **用 3—4 周到货数据打分**
   对每个品牌/单品记录：
   - 到货合格率（外观、果径、糖度、硬度、碰压伤、烂果率）
   - 批次间波动（同一规格连续 3 批的糖度/硬度/果径标准差）
   - 货架期（到店后 5—7 天损耗率）
   - 缺货/断供次数、冷链到货温度记录
   - 售后赔付响应速度

3. **小批量并行试销**
   - 同规格、同产地、同等级各进 1—2 板，连续 3 批对比。
   - 以“烂果率+碰压伤率+7 天损耗率+顾客投诉”做加权评分，谁稳定一目了然。

4. **合同里写死验收标准**
   - 果径、糖度下限、硬度范围、允许缺陷比例、烂果赔付、批次追溯。
   - 稳定性靠验收条款和赔付机制约束，比口头问“谁更稳定”更可靠。

5. **向供应商要可核验材料**
   - 近 3 批次的第三方检测/出厂检验报告、产地证明、冷链记录、同区域商超供货案例。
   - 拿不到连续批次数据的，先不要给大单。

**采购建议**：如果必须二选一，先各给一个小陈列位并行试销 3 批，用上述损耗和合格率数据决定主供；同时保留第二供应商，避免单一品牌批次波动影响门店。品牌层面无法直接判定谁更稳定，批次数据才能判定。
