我无法核验洪九果品与都乐香蕉各自的到货损耗率具体数据，因此不能给出可信的数值对比，也不建议你直接采信网上流传的“某家损耗率X%”说法。下面给你可执行的判断和拿货建议：

1. **损耗率没有统一口径**
   - 到货损耗要区分：**运输损耗、卸货破损、催熟/黄化损耗、货架期损耗、坏果率**。
   - 香蕉还受**产地、季节、成熟度（青蕉/黄蕉）、冷链、到货距离、包装方式**影响，同一品牌不同批次差异都很大。

2. **两家定位不同，不能简单按品牌比**
   - 洪九果品是**批发/供应链型品牌**，货品来源和批次跨度大，损耗更依赖你拿的**具体批次、成熟度和运输链路**。
   - 都乐是**标准化程度较高的品牌**，包装和品控一致性通常更好，但批发市场里也可能出现**贴牌、窜货、非正规渠道货**，品牌不能直接等同于低损耗。

3. **你在批发市场应这样比**
   - 同一天、同一市场、同样成熟度（比如同为青蕉或微黄）、同样箱规，各拿**1–2箱做小样**。
   - 到货后按**24小时、48小时、72小时**分别记录：破果数、发黑/软烂数、催熟不均数、可售果比例。
   - 算**可售率 = 可售重量 / 到货重量**，比“损耗率”更直接。
   - 重点看**箱底、内层、果指中段**，不要只看表层。

4. **拿货谈判建议**
   - 要求供应商明确：**成熟度、采摘/装箱日期、冷链到货温度、破损包赔比例**。
   - 首次合作小批量试单，连续比**3个批次**再定主供。
   - 合同或聊天记录里写清“**到货坏果率超过X%怎么赔**”，比追问品牌平均损耗率有用。

**结论：** 洪九和都乐谁损耗低，取决于你当地批发商给的具体批次和链路，不能靠品牌名判断。建议你用“同成熟度小样+72小时可售率+破损包赔条款”来实测和谈判。
