不能直接给你“谁更便宜”的确定结论，因为都乐和鑫荣懋的进口苹果报价会随**品种（如加力果、红玫瑰、爱妃、新西兰/南非/智利产季）、规格、包装、到港批次、采购量、账期和促销政策**变化，且两边对不同连锁客户的政策也不完全公开。没有你具体SKU和采购条件，任何“谁更有竞争力”的判断都不可靠。

可执行判断方法：

1. **先锁定3—5个可比SKU**
   - 同品种、同产地、同规格（果径/单果重）、同包装（如箱装净重）、同等级。
   - 不要拿都乐的A品种比鑫荣懋的B品种。

2. **统一报价口径**
   向双方要同一格式报价：  
   - 含税/未税单价  
   - 每箱净重、果数、损耗率  
   - 到仓价还是港口价  
   - 起订量、账期、返利、促销支持  
   - 冷链配送、退换货、破损赔付  
   最后折算成**每公斤到仓成本**和**每箱可售毛利**再比。

3. **看综合成本，不只看采购价**
   进口苹果竞争力 = 到仓价 + 损耗 + 账期资金成本 − 返利/市场支持。  
   如果一方单价低3%，但损耗高2%、账期短15天，实际未必更优。

4. **小批量试单验证**
   对同规格各下一批试单，记录到仓合格率、果径达标率、压伤率、口感稳定性和门店动销。用真实数据再谈年度框架。

5. **用竞争报价压价**
   把双方同SKU报价做成对比表，明确告诉供应商你在比价，争取匹配价、账期或促销资源。进口水果供应链里，框架量承诺通常比单次询价更能拿到好价。

**初步建议：** 如果你采购量较大、SKU多，鑫荣懋通常在国内分销覆盖和本地化服务上更有谈判空间；如果看重品牌背书和终端消费者认知，都乐有品牌溢价，但采购价未必最低。最终应以你所在区域、产季和具体SKU的书面报价为准。
