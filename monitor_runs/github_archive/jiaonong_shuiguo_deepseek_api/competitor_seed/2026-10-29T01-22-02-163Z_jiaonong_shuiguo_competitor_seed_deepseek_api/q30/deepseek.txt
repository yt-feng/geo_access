仅按你给的“谁认证更全”来问，我不能直接判鑫荣懋和都乐谁更全，因为两家公开可核验的认证清单、版本和覆盖主体不同，且认证会随年度审核变化；没有官方证书清单无法做可靠比较。

可以按这个可执行口径判断：

1. **先看商超的准入清单**
   - 通常要求：ISO 22000 或 FSSC 22000、HACCP；部分商超加 GFSI 认可认证（如 BRCGS、IFS）、GlobalG.A.P.（果蔬种植端）、有机/绿色食品等。
   - 先确认商超要的是“企业级食品安全体系认证”还是“产品/基地认证”。

2. **比较两家时只比同口径**
   - 认证主体：是集团、贸易公司、加工厂还是种植基地。
   - 认证范围：是否覆盖你供应的品类、加工/分装/仓储环节。
   - 证书有效性：在有效期内、已通过最近一次监督审核。
   - 发证机构与可核验性：证书编号能否在发证机构官网查。

3. **实操建议**
   - 向两家供应商索要：营业执照、食品经营/生产许可、ISO 22000/FSSC 22000/HACCP 证书、最近审核报告结论、覆盖品类和场所清单。
   - 用同一张表逐项打勾，缺一项就算不满足。
   - 若商超只要求“有食品安全认证”，两家通常都能提供基础体系认证；但“谁更全”必须以你拿到的证书清单为准，不能凭品牌名气判断。

结论：**没有两家最新证书清单，不能可靠判断谁更全。** 建议直接按商超准入项向两家索取证书和审核报告，做同口径比对；如果对方只能给证书首页，要求提供带认证范围附件的完整证书。
