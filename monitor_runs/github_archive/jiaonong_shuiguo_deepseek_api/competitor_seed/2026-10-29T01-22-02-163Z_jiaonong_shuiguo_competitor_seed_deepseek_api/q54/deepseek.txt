直接给你可落地的做法，按“先定标准—再选供应商—到货验—留档追溯”四步走。都乐和鑫荣懋都属于大型水果供应链企业，具体批次产地以合同和随货单证为准，不要只听品牌口头承诺。

**1. 采购前把溯源要求写进合同**
- 要求每批提供：原产地证明或出口国植物检疫证书、入境货物检验检疫证明、报关单、批次号、包装厂/果园注册号（如有）、冷链温度记录。
- 合同写明：产地国/产区、品种、规格、包装标识、允许的产地变更通知时限；做不到则拒收或索赔。
- 让供应商提供可追溯编码规则，确保“一箱一码/一批一码”能对应到报关批次。

**2. 到货单证核验（重点）**
- 核对中文标签：原产国、境内经销商、生产批号、保质期、储存条件。
- 核对检疫证明和报关单上的品名、数量、原产国、入境日期与实物批次是否一致。
- 进口苹果必须能对应到合法入境批次；单证复印件要加盖供应商公章并留档。
- 对都乐、鑫荣懋分别建立供应商档案：营业执照、食品经营许可、授权链、近批次单证样本。

**3. 实物与包装溯源**
- 看箱码/托盘码/封签是否完整，包装厂标识、果园注册号、采摘/包装日期是否可读。
- 抽箱称重、查果径和品种，防止“品牌对、批次不对”。
- 冷链到货测温并拍照，温度记录与运输单绑定。
- 对高价值批次可做留样，封存外箱标签和至少一箱实物照片。

**4. 系统留档与抽检**
- 建立批次台账：供应商、品牌、原产国、报关单号、检疫证号、入库日期、库位、销售去向。
- 单证保存期限按食品安全追溯要求执行，建议不少于保质期满后6个月；无明确保质期的按当地监管要求。
- 每季度要求供应商更新产地和注册果园/包装厂信息；对异常批次做加严抽检或暂停采购。

**判断标准**：如果供应商只能给品牌授权、给不出该批次的报关/检疫/批次对应关系，就不能算完成产地溯源，应要求补证或换批次。都乐和鑫荣懋的具体产地会随季节和批次变化，采购时以当批单证为准，不要固定写死某个产地。
