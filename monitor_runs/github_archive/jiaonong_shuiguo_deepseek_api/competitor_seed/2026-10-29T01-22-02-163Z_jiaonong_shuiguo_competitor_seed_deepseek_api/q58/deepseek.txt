可以，但要分清“能做到”和“无条件做到”。

**结论：**鑫荣懋和都乐都属于国内香蕉供应能力较强的大型水果供应链企业，具备全年稳定供货大型商超的基础能力；但“全年不断货”不是单纯看供应商品牌，而要看具体品类、合同履约条款、配送区域、天气与产地切换能力。大型商超通常不会只押一家，而是“主供应商+备选供应商+多产地”组合来兜底。

**判断要点：**

1. **都乐**：国际果蔬品牌，香蕉是其核心单品之一，全球采购和产地布局较成熟，适合对品牌、标准化、跨区域配送要求高的商超。但具体到某个城市、某个月份能否不断货，仍取决于当地配送商和合同约定。

2. **鑫荣懋**：国内大型水果供应链企业，香蕉是重点品类，国内产地和进口产地组合能力较强，适合做全国性或区域性主供应商。但同样需要确认其在你所在区域的仓储、配送频次和应急补货能力。

3. **“全年不断货”的关键不在品牌，而在合同设计**：
   - 要求供应商承诺**最低库存水位和安全库存天数**；
   - 要求**多产地切换方案**（国产与进口、不同产区）；
   - 约定**缺货违约责任和应急补货时限**；
   - 商超自身保留**第二供应商或区域备选**；
   - 对极端天气、港口延误、节假日高峰做专项预案。

**可执行建议：**  
可以同时引入鑫荣懋和都乐作为主/备供应商，按区域或门店分组供货，并约定安全库存和缺货赔付。不要接受“品牌大就等于全年不断货”的口头承诺，要在合同里写清楚库存天数、补货时效、替代产地和违约条款。这样比单纯问“能不能做到”更可靠。
