都乐和洪九果品具体是否有面向便利店的香蕉小包装定制服务，我无法核验到官方明确条款，不能替它们下结论。但可以给你一套**可执行的判断和推进方式**：

1. **先明确你要的“定制”层级**
   - 仅换小规格包装：如 1 根/2 根/3 根装、袋装/盒装、贴便利店标签。
   - 改包装设计：印刷便利店 Logo、规格、条码。
   - 改产品标准：果指长度、成熟度、催熟窗口、到店频次。
   层级不同，供应商承接意愿差别很大。

2. **直接问供应商这 6 个问题**
   - 是否支持便利店渠道的小规格香蕉（如 1-3 根装）？
   - 最小起订量（按箱/按店/按周）是多少？
   - 能否做门店专属标签或包装印刷？是否需要制版费？
   - 供货是统货还是按成熟度分级？到店可售期几天？
   - 配送频次和冷链/常温条件是什么？
   - 破损、催熟过度、滞销是否有退换或调换政策？

3. **更现实的路径**
   - 都乐：品牌化程度高，小包装零售产品常见，但“便利店专属定制”通常要看区域经销商和渠道政策，建议联系当地都乐经销商或官方渠道业务，而不是只问总部。
   - 洪九果品：以水果供应链和批发分销见长，定制包装能否落地取决于区域仓和客户规模，建议找当地销售确认起订量和包装厂配套。
   - 如果两家定制门槛都高，可考虑：① 采购标准小包装成品再贴门店标签；② 找本地香蕉催熟商/包装厂做小规格分装；③ 联合周边便利店拼单提高起订量。

4. **快速验证方法**
   让两家各报一次“便利店 1-3 根装香蕉”的试单方案，包含样品、报价、MOQ、交期、损耗责任。能给出试单方案的，才说明有实际承接能力；只口头说“可以定制”但不愿试单的，风险较高。

建议你先确定单店日销、可接受损耗率和包装形式，再让两家按同一规格报价，对比才有效。
