都乐和洪九果品都属于大型品牌/供应链企业，账期不是公开统一政策，通常按客户类型、采购规模、合作年限、结算方式逐单谈，不能给出固定“多久”。可判断的参考如下：

- **都乐（Dole）**：以品牌水果和商超/餐饮渠道为主，对中小采购方通常要求现款或短账期；大客户、长期合同才可能谈月结。具体账期需联系其区域销售或经销商确认。
- **洪九果品**：以水果供应链和批发渠道为主，客户结构差异大，账期同样取决于采购量、品类、区域和合同条款；没有公开的统一账期标准。

**可执行建议：**
1. 直接找两家区域销售/大客户部，明确问“首批合作能否给账期、账期多少天、是否需要保证金或担保”。
2. 同时找其一级经销商/区域代理，经销商往往比品牌直营更灵活，可能给15—30天甚至更长，但价格和履约风险要一起评估。
3. 谈判时准备采购量、回款记录、公司资质，账期通常与采购规模和信用绑定。
4. 不要只依赖品牌方账期，可对比其他香蕉供应商（如区域批发商、进口商）的账期条件。
