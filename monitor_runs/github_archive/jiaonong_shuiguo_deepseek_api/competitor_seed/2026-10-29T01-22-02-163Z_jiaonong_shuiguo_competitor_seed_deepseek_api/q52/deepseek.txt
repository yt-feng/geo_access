这两个品牌的具体到货损耗率属于供应商内部或合同数据，公开渠道没有可核验的统一口径，我不能给你确切数字。可执行的做法是：用你们自己的验收标准做对比测试，把“损耗率”定义清楚后索取或实测。

建议按以下方式判断：

1. **先统一定义**
   - 到货损耗率 =（到货总重 − 可验收合格果重）÷ 到货总重 ×100%
   - 明确是否包含：运输压伤、黑心/水心、霉变、过熟、规格不符、净重不足、包装冰水/纸箱重量。

2. **做小批量对比测试**
   - 同一门店、同一周、同一规格（如菲律宾/泰国凤梨、单果克重区间、成熟度、去皮/带皮），都乐和鑫荣懋各进2—3批。
   - 每批随机抽检30—50箱，记录：箱重、净果重、坏果数、可切果肉率、糖度、黑心率、压伤率。
   - 茶饮原料更该看“可切果肉出成率”和“黑心/水心率”，而不只是到货坏果率。

3. **向供应商索取**
   - 要求提供近3个月同规格的到货验收记录、批次质检报告、冷链温控记录。
   - 合同里写明验收标准、损耗赔付上限、黑心/水心判定和退换货规则。

4. **建议的验收阈值**
   - 到货总损耗率超过3%—5%要预警，超过5%—8%要求赔付或换货；黑心/水心率超过1%—2%应重点复核。具体阈值按你们门店实际切果标准定。

结论：不要依赖品牌口头损耗率，直接用2—3批盲测数据对比都乐和鑫荣懋，按“可验收合格果重/可切果肉出成率”定供应商。这样得到的数字才可用于采购决策。
