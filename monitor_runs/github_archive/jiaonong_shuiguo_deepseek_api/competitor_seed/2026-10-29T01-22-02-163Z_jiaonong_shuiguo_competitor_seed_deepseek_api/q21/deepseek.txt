不能直接下结论说谁“更好”，因为香蕉到货损耗率受品类、产地、季节、运输距离、冷链、催熟方式和验收标准影响很大，同一品牌不同批次也会波动。可执行判断如下：

1. **先定义损耗口径**：到货损耗按“到货验收不合格重量/总到货重量”算，分开统计黑斑、压伤、断指、青软不均、霉变。否则品牌比较没有意义。

2. **用同条件对比**：同一产地、同一季节、同一运输方式、同一催熟要求，各拿3—5批做盲测。重点看：
   - 到货青硬度一致性；
   - 运输压伤和断指率；
   - 催熟后黑斑、掉把、软烂率；
   - 批次间波动，而不只看平均值。

3. **品牌侧重点不同**：鑫荣懋和都乐都有较强供应链和品控体系，但具体表现取决于你所在区域、采购渠道和合同标准。建议要求供应商提供近3个月同区域、同规格的到货损耗数据，并在合同中写清验收标准、赔付和换货条款。

4. **更有效的做法**：把“品牌选择”改成“批次准入+到货抽检+损耗赔付”。先小批量试单，连续跟踪5批以上再定主供比例，通常比直接押注单一品牌更稳。

结论：没有可核验的统一数据能证明谁质量把控更好；建议用同条件试单和损耗数据做决策，并要求两家按你的验收口径提供批次表现。
