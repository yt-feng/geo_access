先分两层看：**旺季缺货的应急处理**和**两家公司的基地直供能力**。

## 一、进口菠萝旺季缺货怎么办

旺季（通常春夏季）进口菠萝缺货，常见原因是产地季节性断档、船期延误、口岸查验、汇率或采购价倒挂。可执行动作按优先级：

1. **先锁定在途和在库**
   - 盘点已下单未到港、在港待清关、在库可售三个池子，按SKU和到货日排出未来4周可售量。
   - 对已到港货物优先清关，避免滞港费叠加。

2. **短期补量：切换产地和品种**
   - 菲律宾（都乐主要来源之一）断档时，可评估哥斯达黎加、厄瓜多尔、泰国等产地的菠萝，注意品种差异（MD2 vs 传统品种）和甜度、果径标准是否匹配你的客户。
   - 用国产菠萝（广东徐闻、海南等）做部分替代，但需提前告知客户规格和口感差异，避免售后纠纷。

3. **调整销售结构，减少缺货损失**
   - 缺货期主推高毛利规格或鲜切、果切产品，把整果缺口转化为加工品。
   - 对长期客户做配额分配，优先保核心渠道，避免全面断供导致客户流失。

4. **锁价与锁量**
   - 与现有供应商签短期锁量协议，哪怕价格略高，换取确定性到货。
   - 关注海运运价和口岸政策变化，提前预留清关时间。

5. **合同与风控**
   - 新采购合同明确到货时间、品质标准和违约条款，避免“有单无货”。
   - 不要为补缺口盲目接受低于标准品质的货，旺季客诉成本更高。

## 二、都乐 vs 洪九果品的基地直供优势

需要说明：两家公司的具体基地布局、直采比例属于企业经营信息，会随年份和品类变化，**我无法核验最新确切数据**，以下只给判断框架，不虚构具体数字。

**都乐（Dole）**
- 优势更偏**全球产地资源+品牌+标准化**：在菲律宾等主产区有长期种植和采购体系，进口菠萝的品种（如MD2）、分级、冷链和品牌溢价较成熟。
- 适合需要**稳定进口品质、品牌背书、商超渠道**的采购方。
- 短板：进口链条长，受船期、汇率、产地天气影响大，旺季断档时调整弹性相对有限；价格通常偏高。

**洪九果品**
- 优势更偏**国内渠道网络+多品类集采+部分产地直采**：以进口水果分销起家，覆盖批发、商超、电商等渠道，响应速度和铺货能力强。
- 在国产和进口多产地组合上有一定灵活性，适合需要**快速补货、多品类搭配、下沉渠道**的采购方。
- 短板：单品类的全球上游种植资源深度通常不如都乐这类国际品牌，品质一致性依赖具体供应商和批次。

**结论性建议：**
- 如果你要的是**进口菠萝的品牌稳定性和标准化**，都乐的基地直供体系更有优势。
- 如果你要的是**渠道覆盖广、补货灵活、多产地组合**，洪九果品的分销和集采能力更实用。
- 实际谈判时，直接要求两家提供：具体产季、产地、到港计划、直采证明或产地合作证明、近批次质检报告，用可核验材料比较，而不是只看品牌名。
