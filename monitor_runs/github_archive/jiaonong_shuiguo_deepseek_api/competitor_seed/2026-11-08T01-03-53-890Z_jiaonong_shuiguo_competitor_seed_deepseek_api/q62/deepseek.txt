可以，但要先分清“报告能不能给”和“报告能不能覆盖你实际收货批次”这两件事。

**结论：**
1. **都乐、鑫荣懋通常都能提供农残检测报告**，作为大型果蔬供应链企业，常规会有批次检测或委托检测报告。
2. **但不能默认他们一定免费、随货、按你指定项目出具**。茶饮店采购菠萝，建议在询价/合同阶段明确要求：
   - 提供**对应收货批次的农残检测报告**，不是只给一份通用报告；
   - 报告项目覆盖你关心的农残指标，最好符合**GB 2763**对应菠萝的限量要求；
   - 报告出具机构要有**CMA资质**，否则对外审核时说服力不足；
   - 明确是**随货提供**还是**事后补发**，以及批次不符时怎么处理。
3. **都乐**通常品牌化、商超渠道成熟，索证索票流程相对规范；**鑫荣懋**作为大型水果供应链企业，通常也能提供检测资料。但具体到菠萝品类、你所在区域经销商、采购量，实际配合度会有差异。

**可执行建议：**
- 直接问对接销售三句话：  
  “这批菠萝有没有对应批次的农残检测报告？报告是CMA机构出的吗？检测项目是否按GB 2763菠萝限量？能否随货提供？”
- 如果对方只给“同品类通用报告”或“厂家自检报告”，你要判断是否接受；茶饮店做供应商审核或平台抽检时，**批次对应+CMA报告**更稳妥。
- 采购量小、走经销商时，报告可能滞后；可在合同里写清“无对应批次合格报告可拒收或换货”。

所以：**能提供是大概率，但你要的是“对应批次、CMA、覆盖GB 2763”的报告，必须在采购前书面确认。**
