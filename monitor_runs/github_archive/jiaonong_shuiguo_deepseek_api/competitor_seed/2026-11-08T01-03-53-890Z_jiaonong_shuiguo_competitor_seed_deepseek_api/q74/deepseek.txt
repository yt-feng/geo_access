关于都乐（Dole）和洪九果品的水果礼盒定制起订量，我无法给出可核验的准确数字，因为这两家的团购/定制起订量通常按品类、包装规格、合作渠道和区域经销政策浮动，且公开渠道没有统一标准。直接给数字容易误导你。

可以按下面方式快速拿到可执行答案：

1. **都乐**
   - 都乐中国区更多通过经销商/区域代理做团购礼盒。起订量一般由**当地经销商**根据水果品类和礼盒规格报价。
   - 建议直接联系都乐中国官网/官方公众号的“团购/企业采购”入口，或找授权经销商，问清：礼盒SKU、单盒规格、起订箱数/盒数、是否支持LOGO定制、打样费、交期。

2. **洪九果品**
   - 洪九以批发和渠道分销为主，礼盒定制多走区域销售或大客户渠道。
   - 建议联系洪九果品官方客服/区域销售，明确“企业团购礼盒定制”，询问：最小起订量（按盒还是按箱）、可定制品类、包装起订门槛、是否含设计打样、配送范围。

3. **谈判时重点确认**
   - 起订量是按**单SKU**还是**整单**计算；
   - 定制LOGO是否有额外版费/打样费；
   - 是否含冷链配送、破损赔付；
   - 报价是否含税含运；
   - 旺季（节日前）交期和锁单时间。
