大型商超一般会要求水果供应商具备可核验的食品安全与质量管理体系认证。就这两家企业而言：

**鑫荣懋**
- 通常可查到的体系认证包括 **ISO 9001 质量管理体系**、**ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系**，部分业务/基地还涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 等供应链或农产品相关认证。
- 具体证书范围（覆盖哪些品类、加工厂或配送中心）需以其最新证书为准。

**都乐（Dole）**
- 都乐作为跨国果蔬企业，常见体系包括 **ISO 9001**、**ISO 22000 / FSSC 22000**、**HACCP**，以及 **GLOBALG.A.P.**、**BRCGS** 等农业与食品供应链认证；不同国家、品类和加工环节适用的认证不同。

**建议的核验方式（商超准入可执行）**
1. 要求供应商提供**证书扫描件**，核对：证书编号、认证范围、有效期、发证机构（需为 CNCA 批准或 IAF 认可机构）。
2. 在**全国认证认可信息公共服务平台**查询 ISO 9001、ISO 22000、HACCP 等证书有效性。
3. 对 GLOBALG.A.P.、BRCGS 等，核对证书编号及认证机构官网。
4. 确认认证覆盖**实际供货品类和加工/配送场所**，而不是仅覆盖集团其他主体。

由于我无法在此核验两家企业当前最新证书清单，上述为常见认证类型，具体以供应商提供的最新有效证书为准。
