我不能给出都乐和洪九果品确切的锁价周期——这类商务条款通常按客户、品类、季节、采购量和合同类型单独谈，公开渠道没有可核验的统一标准，硬报“几个月”容易误导。

可执行的做法：

1. **先定义你要的锁价机制**  
   - 锁单价：合同期内单价固定  
   - 锁价+锁量：价格和供货量都锁定  
   - 锁价上限/保底价：价格在区间内浮动  
   - 锁价窗口：按周/月/产季报价，过期重议

2. **向都乐和洪九分别询价时直接问这5项**  
   - 锁价周期最短/最长分别是多少  
   - 锁价对应的最小采购量或年度框架量  
   - 锁价是否含运费、包装、损耗和等级标准  
   - 超出锁价周期后如何续价，是否可分批提货  
   - 违约、延期、品质不达标时价格如何调整

3. **别只问总部，要问到具体渠道**  
   都乐可通过其中国区销售/经销商询；洪九果品可通过其区域销售或供应链业务对接人询。不同区域、不同客户等级政策可能不同。

4. **建议的询价话术**  
   “我们计划年度采购菠萝X吨，等级X，提货区域X，希望采用月度/季度锁价，请提供可锁价周期、对应采购量门槛、报价有效期和超期续价规则。”

如果你告诉我采购量、提货城市、菠萝品种/等级和期望锁价时长，我可以帮你把询价清单和对比表模板整理出来。
