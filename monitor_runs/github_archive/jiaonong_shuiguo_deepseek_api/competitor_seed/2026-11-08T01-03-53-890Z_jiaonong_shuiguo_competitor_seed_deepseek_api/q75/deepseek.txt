这个对比没法给出可靠数字：**洪九果品和都乐香蕉的“到货损耗率”没有公开、可核验的统一口径数据**。批发市场的到货损耗受产地、季节、成熟度、冷链距离、包装规格、卸货方式、档口存放条件影响极大，同一品牌不同批次能差好几个点。直接说“A比B低/高几个百分点”基本是拍脑袋。

可执行的判断方法：

1. **先统一损耗口径**  
   按“到货拆箱后到可售状态”计算：  
   到货损耗率 =（到货总件数×标准净重 − 可售合格净重）÷（到货总件数×标准净重）×100%。  
   同时分开记：机械伤、压伤、青黑/黄黑、断指/脱梳、霉变、重量短缺。

2. **用同批次小样对比**  
   同一市场、同一周、同一运输距离，各拿3—5箱做样本，到货当天和放置24/48小时各称一次、分拣一次。至少连续比3个批次，才有参考意义。

3. **关注品牌差异的实际来源**  
   - 都乐香蕉通常标准化程度高、催熟和冷链体系较成熟，但不同进口/国产批次、不同熟度到货差异仍大；  
   - 洪九果品品类多、香蕉为其重点品类之一，但不同产区、不同包装规格和档口操作差异也大。  
   品牌不能替代批次管理，批发市场里“同品牌不同柜”损耗差别往往比“品牌之间”更大。

4. **谈判和采购时看合同指标**  
   让供应商书面注明：到货成熟度、允许青黑/机械伤比例、单箱净重下限、冷链到货温度、破损赔付标准。比问“损耗率多少”更能落地。

结论：**没有可核验的公开对比数据，不建议用固定损耗率做决策；用你自己的档口连续3批同口径实测，才是可判断的依据。**
