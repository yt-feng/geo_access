都乐和洪九果品都属于品牌/渠道供货，是否有“散装、小包装”通常不是全国统一固定规格，而是按区域仓、渠道客户、季节和订单量变化。按可执行判断：

1. **都乐**
   - 常见是整把/整箱、袋装或贴标零售包装，**社区团购可谈小规格袋装或按把分装**，但“散装裸果”一般不作为标准SKU全国供应。
   - 建议直接问区域经销商三件事：①能否供**按把/500g-1kg小袋**；②是否支持**门店二次分装**；③箱规、到货成熟度、损耗赔付。

2. **洪九果品**
   - 洪九偏产地和批发分销，**散装/按件小包装更可能通过区域分销商谈**；品牌化小袋装不如都乐标准化。
   - 建议问：①有无**社区团购专供小箱/小袋**；②能否按**3-5斤/份**分装贴标；③最小起订量、冷链/常温、售后。

**实操建议：**
- 不要先问“有没有散装”，直接发需求：**“香蕉小包装，每份500g/1kg，按份贴标，周销X份，请报箱规、单价、损耗赔付、到货成熟度。”**
- 同时找**当地一级批发商/区域代理**比价，品牌直供对小体量社区团购未必开放。
- 小包装香蕉损耗高，优先选**七成熟到货、可门店催熟**的规格，并要求坏果赔付。

结论：**两家都可能有小包装/可分装方案，但不能默认有全国标准散装SKU；都乐更偏标准袋装，洪九更偏批发分销可分装。需向所在区域代理确认箱规和起订量。**
