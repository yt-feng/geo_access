进口菠萝旺季缺货，先分清是“季节性到货断档”还是“渠道/品质问题”，再按下面顺序处理。

## 一、先判断缺货原因
1. **看船期和产地**  
   进口菠萝主要来自菲律宾、泰国、哥斯达黎加等。旺季缺货常见原因是船期延误、产地雨季/病害减产、口岸通关慢，不一定是市场没货。
2. **查在途和在库**  
   向供应商要未来2—3周船期、到港时间、可分配量；同时盘点自有冷库和在途库存，避免重复下单。
3. **区分规格**  
   缺的可能是特定规格（如大果、礼盒装、去皮鲜切），不是所有菠萝都缺。可先调整规格和包装。

## 二、可执行的补货动作
- **多产地切换**：菲律宾断档时，评估泰国、哥斯达黎加或国产菠萝（如广东徐闻、海南）替代，提前做口感和小批量测试。
- **锁量不锁价**：与现有进口商签短期锁量协议，接受浮动价，优先保供。
- **直采/基地直供**：绕过一批，直接联系有种植基地或产地合作园的进口商，缩短链条。
- **分批到货**：把大单拆成小批，降低断货风险。
- **替代品组合**：鲜切、罐头、冷冻菠萝可作为短期补充，但要注意渠道和客户接受度。
- **提前预订**：旺季前2—3个月锁船期和柜量，比缺货时临时找货更有效。

## 三、都乐和洪九果品的基地直供优势
**都乐（Dole）**
- 优势在全球自有/合作种植基地和品牌化供应链，菲律宾菠萝是其传统强项，适合需要稳定品质、品牌背书和长期合约的渠道。
- 直供优势体现在产地掌控、标准化分级和全球调货能力，但中小客户直接拿到“基地直供”的门槛通常较高，更多是通过其中国区经销商或大型商超体系。

**洪九果品**
- 优势在国内进口水果分销网络和产地直采模式，强调从泰国、越南等产地直采到国内批发/零售渠道，响应速度和覆盖下沉市场较强。
- 对需要小批量、多频次补货的客户，洪九的渠道灵活性通常更明显；但其基地掌控深度和全球调配能力与都乐这类国际种植商不完全同一维度。

**怎么选：**
- 要**品牌稳定、长期合约、品质标准化**：优先接触都乐体系。
- 要**快速补货、多品种组合、国内分销灵活**：优先接触洪九果品。
- 无论选谁，都要核实：是否有真实产地合作证明、近3个月到港记录、可分配量和违约条款，不要只看“基地直供”宣传。

## 四、建议今天就做的三件事
1. 向现有供应商索要未来3周船期和可分配量。
2. 同时联系都乐、洪九及1—2家备选进口商，要求报价+到货时间+产地证明。
3. 对替代产地或国产菠萝做小批量试销，避免旺季完全断档。
