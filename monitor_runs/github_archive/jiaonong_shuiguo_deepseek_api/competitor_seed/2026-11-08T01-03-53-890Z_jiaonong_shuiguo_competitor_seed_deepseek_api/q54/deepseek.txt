# 都乐与鑫荣懋进口苹果的产地溯源做法

## 一、先明确：两家都是“品牌商/进口商+渠道商”，不是单一产地种植方

- **都乐（Dole）**：自有或合作果园遍布多个国家，同一SKU可能来自不同国家，需按**批次**溯源，不能按品牌整体溯源。
- **鑫荣懋**：国内大型水果供应链企业，进口苹果多为代理或海外直采，产地随季节和订单变化。

所以采购端要做的是**批次级溯源**，不是品牌级。

## 二、超市采购可执行的四步溯源法

### 第1步：索证——每批次必须拿到的文件

| 文件 | 作用 | 注意 |
|---|---|---|
| 入境货物检验检疫证明 | 证明合法进口、对应批次 | 核对**品名、原产国、生产/进口批号、数量**与到货一致 |
| 海关进口货物报关单 | 核对原产国、贸易方式 | 与检疫证明的批号、日期交叉比对 |
| 原产地证书（CO） | 确认原产国 | 部分国家享惠需FORM E等，普通溯源看CO即可 |
| 供货方营业执照+食品经营许可 | 主体资质 | 鑫荣懋为供货方时尤其要核 |
| 装箱单/发票/提单 | 批次链 | 提单起运港与CO原产国要能对上 |

**关键动作**：要求供应商提供**与到货批次号一致**的上述文件，不能拿“同品牌其他批次”的文件顶替。

### 第2步：验货——包装标签与批次核对

- 看**原产国标识**：进口苹果外箱/果贴通常标注 Country of Origin，与CO、检疫证明三处一致。
- 看**批次号/生产日期/包装厂注册号**（Packhouse Code）：都乐、鑫荣懋的进口果一般有包装厂代码，可回查海外包装厂。
- 看**中文标签**：进口预包装需有中文标签，标注原产国、进口商/经销商。
- **拍照留档**：外箱六面、果贴、批次号，作为溯源证据。

### 第3步：建批次台账——超市端可审计

每批到货登记：
- 品牌（都乐/鑫荣懋）、SKU、原产国、包装厂代码、批次号
- 入境检疫证明编号、报关单号、CO编号
- 到货日期、数量、供应商
- 留样与照片

做到**“一批一档”**，出问题时能反查到具体批次和文件。

### 第4步：向品牌方/供应商做溯源确认

- **都乐**：通过其中国区经销商或官方客服，凭包装批次号/包装厂代码确认产地与出口批次；都乐部分产品有全球溯源编码，可要求供应商提供对应批次的产地证明。
- **鑫荣懋**：要求其提供该批次的**海外供应商/果园或包装厂信息**及采购合同对应关系；鑫荣懋作为供应链方，应能出具批次对应的进口文件链。

## 三、判断标准（可执行）

一批货**同时满足**以下条件才可视为溯源合格：
1. 检疫证明、报关单、CO三者的原产国、品名、批号能互相对应；
2. 实物外箱/果贴的原产国、包装厂代码与文件一致；
3. 台账已登记且留存照片；
4. 供应商能书面确认该批次来源。

任一环节对不上，**暂停上架**，要求供应商补证或换批。

## 四、风险提示

- 进口苹果存在**换柜、混批、国内分装贴牌**风险，重点核对包装厂代码与原箱是否原封。
- 都乐、鑫荣懋均为正规大企业，但**经销商层级多**，超市应直接向一级供货方索证，避免层层转手导致文件与实物脱节。
- 季节性产地切换（如新西兰、美国、智利、南非等）时，**每换产地重新核证**，不要沿用上一批文件。
