可以明确回答：**都乐（Dole）和鑫荣懋都能提供产地溯源和品控证明，但两家能提供的证明类型、颗粒度和获取难度不同，需要你在询价时把要求写进合同或采购条款里。**

**都乐（Dole）**
- 有较成熟的全球溯源体系，菲律宾、厄瓜多尔等主产区可提供产地证明、果园/包装厂注册信息，以及GlobalG.A.P.等认证。
- 品控方面通常可提供批次检测报告、农残检测报告、到货质量标准。
- 注意：具体到“某一柜/某一批次”的溯源文件，需要在下单时明确要求，不是默认每单都随附全套。多为进口蕉，文件偏国际认证体系。

**鑫荣懋**
- 国内龙头水果供应链企业，国产蕉和进口蕉都做，国内产区（如云南、广西、海南）溯源和品控文件相对容易配合。
- 可提供产地证明、基地/合作社信息、农残检测报告、分拣包装记录等，部分基地有GAP或绿色食品认证。
- 注意：鑫荣懋体系大、供应商多，溯源颗粒度取决于具体供货基地，需确认是“公司级证明”还是“批次级证明”。

**给你的可执行建议**
1. 询价时直接发一份《供应商文件要求清单》，写清：产地证明、批次农残检测报告（第三方CMA/CNAS优先）、GAP/绿色食品等认证、包装厂注册号、到货验收标准。
2. 明确要求“**批次级**”而非“公司级”文件，并约定随货或到货后几个工作日内提供。
3. 合同里写违约条款：文件缺失或与批次不符时的退换货/扣款责任。
4. 首次合作先小批量试单，验证对方文件是否真实、可对应到具体批次。

两家都具备能力，关键不在“有没有”，而在“你要求的颗粒度和是否写进采购条件”。
