除了都乐和佳沛，礼品团购场景可以重点看这几类进口/外资品牌水果礼盒：

1. **新奇士 Sunkist**  
   美国柑橘类代表品牌，脐橙、夏橙、柠檬礼盒认知度高，适合做节庆果礼。注意国内授权包装和分装渠道较杂，团购要确认授权与到货批次。

2. **爱妃 Envy**  
   新西兰/美国体系的高端苹果品牌，礼盒定位偏中高端，适合商务礼赠。采购时重点确认产地、规格和是否原箱原标。

3. **乐淇 Rockit**  
   新西兰小苹果品牌，筒装/礼盒装辨识度高，适合员工福利和小型伴手礼，但客单价和规格要提前核算。

4. **红地厘蛇果/华盛顿苹果体系**  
   美国苹果在中国礼品市场有一定认知，常见“华盛顿苹果”礼盒。品牌集中度不如佳沛，采购时要看具体包装商和授权标识。

5. **Pink Lady 粉红佳人**  
   国际苹果品牌，礼盒调性较好，适合中高端团购；国内供应稳定性和授权包装需逐批确认。

6. **Zespri 佳沛之外的奇异果品牌**  
   可关注 **Oscar** 等新西兰奇异果品牌，但国内礼品渠道认知度和供应稳定性弱于佳沛，适合作为差异化补充。

7. **SunGold/意大利猕猴桃、智利车厘子品牌礼盒**  
   车厘子礼盒本身是团购刚需，但“品牌”多集中在出口商/包装商层面，如智利车厘子出口品牌礼盒。采购时应看出口商品牌、品种、J级/XL级规格和原箱标签，不宜只看国家名。

8. **日本高端水果品牌**  
   如 **千疋屋、果道** 等更多是高端零售/礼赠概念，国内正规团购供应不稳定、价格高，不适合作为常规团购主力。

**建议的团购品牌组合：**
- 高端商务礼：爱妃苹果、Pink Lady、新奇士高端橙礼盒、佳沛金果礼盒
- 员工福利：乐淇小苹果、新奇士橙、都乐香蕉/果切类组合
- 节庆刚需：智利车厘子品牌礼盒 + 佳沛/新奇士做搭配

**采购判断要点：**
优先要求供应商提供：品牌授权或进口报关信息、原箱/原标证明、到货批次、规格等级、坏果赔付标准。进口水果礼盒团购最大的风险不是品牌不够，而是“贴牌礼盒”和规格虚标，建议先小批量验货再锁大货。
