我没法核验鑫荣懋和都乐当前在便利店渠道的具体在售规格，直接报“他们有哪些规格”容易给你错误信息。可以按下面方式判断和落地：

**先明确你要的“小包装”是哪一种**
- 单根/2根装：适合即食、客单价低、损耗控制要求高
- 3-5根装：适合家庭补货，但便利店动销偏慢
- 果切/盒装香蕉段：适合鲜食柜，保质期短、冷链要求高
- 迷你蕉/小米蕉小袋装：更适合便利店尝鲜型消费

**对鑫荣懋、都乐的可执行核验方式**
1. 直接问区域销售或经销商要“便利店渠道SKU清单”，重点看：单果重、每袋根数、袋型（网袋/贴体/盒装）、保质期、起订量、配送频次。
2. 要求提供近3个月便利店渠道实际供货规格和包装图，不接受只给“有零售小包装”的模糊说法。
3. 确认是否支持小批量混配、门店直配、临期退换和损耗分担。
4. 对比同一规格的到岸价/供货价、建议零售价和毛利空间。

**便利店选品建议**
优先测试 **2根装或3根装、单果重约110-130g、网袋或可呼吸膜包装** 的规格；如果门店有鲜食柜，再考虑盒装香蕉段。先小范围试销2-4周，看日均销量、损耗率和复购，再决定是否扩SKU。
