这个问题不能直接下结论说“都乐更便宜”或“鑫荣懋更便宜”，因为进口苹果的到店价受品牌、品种、规格、口岸、汇率、船期、采购量和促销政策影响很大，两家在不同品类和区域上各有优势。给你一个可执行的判断框架：

**1. 先锁定可比标的**
不要拿“都乐苹果”对“鑫荣懋苹果”泛比，要统一到具体品种和规格，例如：
- 品种：新西兰爱妃/爵士/布瑞本、美国红蛇果、智利嘎啦等
- 规格：单果克重、箱规、果径、等级
- 包装：原箱/贴标/分装
- 到货口岸和交货方式：到岸价、到仓价、含税与否

**2. 问两家要同一口径报价**
让两家按同一张询价单报价，至少包含：出厂/采购价、箱规、单果成本、到仓运费、损耗率、账期、返利/促销支持、最小起订量、换货政策。只比“每箱价”容易失真，建议折算成**每公斤到仓成本**和**每颗门店成本**。

**3. 用门店真实数据算竞争力**
竞争力不只看进货价，建议算：
- 到仓成本 = 采购价 + 运费 + 关税/增值税影响 + 损耗分摊
- 毛利率 =（门店售价 - 到仓成本）/ 门店售价
- 周转与损耗：进口苹果损耗和周转差异可能吞掉几个点的价差
- 促销资源：堆头费、试吃、返利、账期，折算成每箱净成本

**4. 分区域、分品种小批量试单**
水果连锁最稳妥的做法是：选2-3个核心门店、2-3个SKU，各下一小批同规格订单，跑一个完整销售周期，对比**净毛利、损耗率、动销速度、顾客反馈**。这比口头比价可靠。

**5. 谈判策略**
可以明确告诉两家你在做同规格比价，要求给出“季度锁价+返利”或“首单促销价”，并关注账期和退换货。进口苹果价格波动大，锁价和账期有时比单箱便宜几毛更重要。

**结论**：没有统一答案。建议你先用同一询价单让都乐和鑫荣懋报同品种同规格的到仓净成本，再结合损耗和促销资源做小批量试单。若你告诉我具体品种、规格、口岸和月采购量，我可以帮你把比价表的口径列得更细。
