结论先说：**这两家大概率都没有公开可查的“香蕉企业分级标准”文本**。都乐（Dole）有全球香蕉质量规范，洪九果品有内部商品分级/验收体系，但都不以“企业标准”公开文本形式对外发布，我无法核验到具体编号或全文，因此不能当作可引用的标准来源。

可判断的情况：

1. **都乐（Dole）**
   - 有成熟的香蕉质量分级体系，用于全球供应链，按品种、产地、果指长度/粗度、梳/把规格、成熟度（色卡）、机械伤、病害等分级。
   - 但多为**内部质量规范/采购验收规范**，不是中国“企业标准信息公共服务平台”上公开备案的企业标准。
   - 建议：不要引用“都乐企业标准”，可写“参照都乐香蕉商品质量规范（内部）”，或直接自建标准。

2. **洪九果品**
   - 作为水果供应链企业，有内部采购、分级、品控流程，香蕉按产地、等级、果指规格、成熟度、外观等分档。
   - 同样未核验到公开的企业标准编号或全文。
   - 建议：可参考其商品等级命名和包装规格习惯，但不宜称为“洪九企业标准”。

**给水果连锁店的可执行建议：**
- 不依赖这两家的“企业标准”，自己制定《香蕉采购分级与验收标准》，内部发布即可。
- 标准至少包含：品种/产地、果指长度与粗度、每梳果指数、把型、成熟度色卡（1–7级）、青熟/黄熟阶段、机械伤允许度、病斑/黑星病/炭疽病允许度、冷害/药害、单箱净重、包装规格、抽检比例、判定规则。
- 若想找公开依据，可查：**GB/T 9827《香蕉》**、**NY/T 517《无公害食品 香蕉》**相关农业行业标准、**GB 2762/GB 2763**（污染物/农残），以及中国物品编码/生鲜分级类团体标准；企业标准可在“企业标准信息公共服务平台”按企业名称检索，但我未核验到都乐、洪九的香蕉分级企标公开文本。
