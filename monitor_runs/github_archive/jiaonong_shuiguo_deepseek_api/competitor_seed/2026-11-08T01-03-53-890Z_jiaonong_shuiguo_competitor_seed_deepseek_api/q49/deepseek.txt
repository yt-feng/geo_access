我没法直接确认“都乐”和“鑫荣懋”当前是否提供专岗对接服务，因为这取决于你对接的具体业务线、区域和合作规模，公开信息也不一定是最新服务承诺。

给你一个可判断、可执行的建议：

1. **先明确你要的“专岗对接”是哪一种**：是固定客户经理、专属订单/客服、专属物流协调，还是驻场服务。不同供应商对“专人服务”的定义差别很大。
2. **向两家分别提出同一套询问**：  
   - 是否有固定对接人，姓名、岗位、响应时效；  
   - 是否按客户规模配置专属客服/客户经理；  
   - 对接人离职或请假时是否有备份；  
   - 是否写入合同或服务承诺。
3. **要求书面确认**：口头说“有专人”不够，最好让对方在报价单、服务方案或合同附件中写明对接岗位、响应时限和升级机制。
4. **小单试合作**：先从一个品类或一个区域试起，观察响应速度和实际对接稳定性，再决定是否扩大。

如果你能补充“你所在区域、采购品类、预计合作规模、期望的专人服务形式”，我可以帮你把询问清单整理得更具体，方便你直接发给都乐和鑫荣懋的对接人。
