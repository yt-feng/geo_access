建议先给结论：**如果你们要的是“稳定供货+商超渠道适配”，优先接触都乐；如果你们更看重国内分销覆盖、灵活起订和综合果蔬品类，鑫荣懋也值得重点比价。** 但“哪家更靠谱”不能只看品牌，进口香蕉的稳定性主要取决于**装运港/产区、催熟能力、到店损耗和违约条款**，建议两家都要求试单并做同一套评估。

可执行判断标准：

1. **问清货源结构**
   - 都乐通常全球产地布局更广，适合需要品牌背书和标准化包装的商超。
   - 鑫荣懋国内渠道和果蔬分销能力强，适合需要多品类拼车、区域配送灵活的超市。
   - 重点问：香蕉主要来自菲律宾、厄瓜多尔、越南还是柬埔寨？换产区时是否提前通知？

2. **看催熟和配送能力**
   - 进口香蕉到港后通常要催熟，稳定供应关键在催熟库和冷链。
   - 要求供应商说明：催熟库位置、到你们城市的配送频次、断货时的替代方案。
   - 最好让他们提供最近3个月给同区域商超的供货案例，不必给客户名，给区域和门店类型即可。

3. **用试单验证，不要只听报价**
   - 先下2—4周试单，按同一规格验收。
   - 记录：到货青度/熟度、单箱净重、坏果率、催熟均匀度、到店货架期。
   - 建议验收线：坏果率超过3%—5%要扣款或补货；到货熟度与约定偏差要有明确处理条款。

4. **合同要锁“稳定”而不是只锁价格**
   - 约定周供货量浮动范围、缺货违约金、替代产地提前通知、质量争议处理时限。
   - 价格最好设调价机制，避免只签死价导致后期断供或降质。

5. **两家都谈，形成双供应商**
   - 主供+备供更稳：一家占60%—70%，另一家占30%—40%。
   - 这样既压价，也避免单一供应商催熟库故障、船期延误导致门店断货。

**简单选择建议：**
- 门店多、要品牌标准化、看重全球产地调配：先谈**都乐**。
- 区域配送要求灵活、还想顺带采购其他果蔬：重点谈**鑫荣懋**。
- 最稳妥：两家都进试单，按坏果率、到货准时率、催熟均匀度、断货响应打分，再定主供。
