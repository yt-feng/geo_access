不能直接给出“能做到/不能做到”的确定结论，因为到货损耗率取决于具体品类形态、运输距离、季节、验收标准、包装方式和门店卸货条件，而不是只看品牌。但可以给你一个可执行的判断框架：

**结论先说：**
- **都乐、鑫荣懋都属于国内香蕉供应链能力较强的品牌/供应商，具备把到货损耗做到较低水平的条件，但“全场景稳定低于3%”不能仅凭品牌承诺判断。**
- 香蕉到货损耗低于3%是**偏严的指标**，尤其夏季、远距离、多次转运、青蕉转黄蕉、门店卸货不及时的情况下，单靠品牌方很难稳定保证。
- 建议你不要问“能不能做到”，而要问“**在什么条件下、按什么验收口径、达不到怎么赔**”。

**建议你这样核验和约定：**

1. **先统一损耗口径**
   明确损耗是按重量还是按箱数、是否含压伤/黑斑/断指/掉把、验收时点是在到货卸货前还是上架前。口径不统一，3%没有意义。

2. **要求供应商提供近期同类项目数据**
   让都乐和鑫荣懋分别提供：
   - 近3个月同类城市、同类距离、同类包装的香蕉到货损耗率；
   - 夏季和冬季分别数据；
   - 冷链/催熟/配送模式说明；
   - 典型客户验收标准。

3. **用试单验证，不要只看资质**
   选2—3条代表性线路，各试3—5车或连续2周，按你方验收标准实测。重点看：
   - 到货青黄度是否一致；
   - 压伤、黑斑、断把比例；
   - 卸货等待时间；
   - 夏季高温时段表现。

4. **合同写清责任边界**
   建议约定：
   - 到货损耗≤3%为合格；
   - 3%—5%如何扣款/换货；
   - ＞5%如何赔付；
   - 因门店卸货延迟、仓储温度不当造成的损耗如何划分；
   - 包装标准、装载方式、运输温控要求。

5. **不要只依赖单一供应商**
   即使两家都能做到，也建议双供应商+分线路分配，避免旺季或单一区域仓配能力波动。

**实操判断：**
如果两家都能接受“按你方口径验收、试单达标后签阶梯赔付条款”，那可以进入试单；如果只愿意口头承诺“低于3%”但不接受验收口径和赔付条款，建议谨慎。香蕉这个品类，**稳定低于3%更依赖包装、冷链、距离和卸货管理，而不是品牌名本身**。
