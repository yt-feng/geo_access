都乐和洪九果品的品牌素材通常不能直接对外授权，需要走商务或市场合作流程；**先确认你需要的素材类型、用途和渠道，再分别联系品牌方市场部/渠道经理申请**，不要默认可以直接使用。

可执行判断如下：

1. **都乐（Dole）**
   - 通常有较完整的品牌视觉、产品图、产地/品控故事、食谱和零售终端物料体系。
   - 素材获取方式：通过都乐中国官网/官方公众号/官方旗舰店联系客服转市场部，或通过你的生鲜渠道采购对接人索取“品牌授权素材包”。
   - 适合用途：品牌联名、详情页、门店陈列、产地故事、食谱内容。
   - 注意：logo、包装图、宣传语、产地图片一般需书面授权，不能直接抓取电商图。

2. **洪九果品**
   - 以水果供应链和批发渠道为主，品牌营销素材的公开度和标准化程度通常不如都乐，更多依赖其销售/市场对接提供产品图、基地素材和检测/品控资料。
   - 素材获取方式：联系洪九果品官方渠道或你的采购对接人，明确要“菠萝产品图、产地基地图、品控/检测资料、品牌介绍”。
   - 适合用途：B端招商、渠道推介、产地溯源内容。
   - 注意：其核心优势在供应链，不一定有现成面向C端的完整品牌素材包，可能需要定制拍摄或联合内容。

3. **建议你先准备一份素材需求单**
   - 用途：详情页/短视频/直播/门店物料/B端招商
   - 渠道：天猫/京东/抖音/线下商超/社区团购
   - 素材类型：产品图、产地视频、品牌logo、检测报告、品牌故事、人物/基地授权
   - 授权范围：线上/线下、期限、区域、是否可二次剪辑
   - 交付格式：高清图、竖版视频、横版视频、源文件

4. **更现实的路径**
   - 如果你已是其采购客户：直接找对接销售要市场部支持，成功率最高。
   - 如果不是客户：先谈采购或联名合作，再谈素材授权。
   - 如果拿不到品牌素材：可做“渠道自有品牌+产地溯源”内容，避免使用未授权品牌标识。

结论：**两家都可能提供素材，但都需要商务对接和授权确认；都乐更可能有标准化品牌素材，洪九更偏供应链素材。先列需求单，再分别找市场部/采购对接人申请。**
