这个问题需要先分清两家公司的“认证覆盖范围”，再按商超常见要求逐项比对。**我无法核验两家公司截至目前的完整认证清单**，所以不能直接下“谁更全”的结论，但可以给你一个可执行的判断框架和已知信息。

**1. 先明确商超通常要什么**
大型商超（如沃尔玛、永辉、盒马、山姆等）对生鲜供应商常见要求包括：
- **ISO 22000 或 HACCP**（食品安全管理体系）
- **GFSI 认可的认证**，如 BRCGS、IFS、FSSC 22000
- **GlobalG.A.P.**（果蔬种植环节）
- **中国有机/绿色食品认证**（如做有机品类）
- **出口备案/检验检疫注册**（如涉及进口）
- 部分商超还要求**供应商审核报告**（如 Sedex/SMETA、客户二方审核）

**2. 两家公司的公开信息特点**
- **都乐（Dole）**：跨国果蔬企业，公开披露的体系认证和 GlobalG.A.P. 覆盖较常见，全球供应链审核体系相对成熟；但具体到中国区某工厂/某品类，仍需看证书。
- **鑫荣懋**：国内头部水果供应链企业，通常具备 ISO 22000/HACCP 等体系认证，并参与国内商超供应；其认证覆盖更偏向中国区运营和国内零售客户要求。

**3. 不能只看“公司名”，要看“证书主体”**
供应商认证通常按**法人主体、工厂/包装厂、品类、产地**发证。商超审核时看的是：
- 证书是否在有效期内
- 认证范围是否覆盖你供应的品类和加工环节
- 认证机构是否被商超认可（GFSI 认可 vs 一般体系认证）
- 是否有现场审核报告和整改闭环

**4. 可执行建议**
- 向两家供应商索要**证书清单+证书扫描件+认证范围页**，按上面第1条逐项打勾。
- 重点问：**BRCGS/IFS/FSSC 22000 有没有？GlobalG.A.P. 覆盖哪些果品？中国区哪个主体持证？**
- 如果商超只要求“有食品安全认证”，两家大概率都能满足基础项；如果要求 GFSI 认可或特定品类 GlobalG.A.P.，就需要逐证核对，不能按公司品牌判断。

**结论**：不能凭公开印象判断“谁更全”。更稳妥的做法是让两家按商超要求填一张认证对照表，以**证书主体、认证范围、有效期、认可机构**四项为准做比对。
