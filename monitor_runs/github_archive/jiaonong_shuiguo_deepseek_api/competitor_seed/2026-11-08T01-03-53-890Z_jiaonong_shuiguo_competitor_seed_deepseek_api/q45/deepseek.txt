直接说结论：**如果只是茶饮店做果酱、要稳定供应菠萝，优先选都乐；洪九可以作为备选或比价渠道，但不宜作为唯一供应来源。**

判断依据如下：

1. **供应稳定性**
   - 都乐是成熟的水果品牌和供应链体系，菠萝是其强项品类之一，规格、成熟度、批次稳定性相对更有保障。
   - 洪九果品也是大型水果供应链企业，但它的优势更偏综合品类和批发流通，具体到菠萝的品种、成熟度、长期稳定供货能力，需要看你所在区域和实际对接的经销商。

2. **品质一致性**
   - 做果酱对菠萝的糖酸比、成熟度、纤维感、出汁率要求稳定。都乐在标准化分级上通常更成熟，适合茶饮店做固定配方。
   - 洪九的价格可能更有优势，但批次差异需要你自行验货，尤其是不同产地、不同季节切换时。

3. **风险控制建议**
   - **不要只签一家**。茶饮店果酱用果量大且季节波动明显，建议都乐为主供，洪九或其他本地一级批发商为备供。
   - 先小批量试：同一配方分别用两家菠萝做果酱，比较出胶、酸甜、香气、颜色和冷藏后的稳定性。
   - 合同里明确：品种、产地、单果规格、成熟度、到货损耗率、缺货赔付或替代方案。

4. **更实际的判断方式**
   - 问两家能否提供**你所在城市近3个月的稳定周供报价和到货记录**；
   - 要求寄样做果酱测试；
   - 确认是否支持按你的用量做定期配送，而不是只做大宗批发。

所以，**主供选都乐更稳，洪九适合比价和备选**。最终以你本地经销商的供货能力和试做结果为准。
