可以按“是否有基地直供/能否做产地溯源”两个层面来判断，但直接回答“都乐和洪九果品有没有基地直供”需要分情况，不能一概而论。

**都乐**
- 都乐是有全球供应链和自有/合作种植基地体系的果蔬品牌，菠萝是其重要品类之一，尤其菲律宾菠萝等进口菠萝较常见。
- 但“基地直供”通常要看你采购的是哪类都乐产品、通过哪个渠道、哪个区域仓配货。都乐中国更多是通过品牌方、进口商、经销商、商超/生鲜渠道分销，未必能对每一个采购客户都做到“从具体基地直接发你”。
- 产地溯源方面，都乐一般具备较强的批次和产地管理能力，正规渠道通常可提供产地、批次、进口/检疫等信息，但能否开放到“单个果园/基地级”溯源，要看具体品类和合作规模。

**洪九果品**
- 洪九果品是国内大型水果分销企业，核心优势在榴莲、火龙果、车厘子、菠萝等品类的产地采购和分销网络，在泰国、越南等产地有布局和合作基地/工厂。
- 它更接近“产地直采+分级分选+分销”的模式，部分品类可以做到基地/工厂直供或产地直发。
- 菠萝方面，是否能对你做基地直供，取决于你采购的品种、产地、起订量、是否走批发市场/商超/电商仓，以及你能否接受其经销体系而不是品牌方直签。溯源信息通常可以做到批次、产地、供应商/工厂级别，但能否给到具体种植基地，也要看合同和品类。

**给你的可执行判断建议**
1. **先明确你要哪种“直供”**
   - 品牌方/产地工厂直接和你签合同并发货；
   - 还是通过其经销商/区域仓供货，但能提供产地证明和批次溯源。
   这两者差别很大。

2. **向对方要这4类文件**
   - 产地证明/出口国官方或产地机构证明；
   - 批次号及对应基地/工厂信息；
   - 检验检疫、农残检测报告；
   - 供货合同里写明“产地可追溯、批次可查询、异常可追责”。

3. **直接问都乐/洪九的对接人这几个问题**
   - 这个菠萝是哪个国家/产区/基地？
   - 是基地直发，还是区域仓/经销商发货？
   - 能否提供到批次级的溯源文件？
   - 最小起订量、供货稳定性、损耗和售后怎么算？

4. **如果你要的是强溯源基地直供**
   - 都乐：更适合找其品牌方或授权进口商，确认具体品类和渠道政策。
   - 洪九：更适合谈产地直采/工厂直供，尤其是你有一定采购量时。
   - 如果量不大，通常很难拿到真正“基地直供”，更多是经销商供货+批次溯源。

简单说：**都乐有强供应链和产地管理能力，但不一定对中小客户做基地直供；洪九更偏产地直采和分销，部分品类可做基地/工厂直供，但要按品类和采购量谈。** 最终不要只听“有基地”，要让他们在合同和批次文件里落到具体产地、工厂和溯源责任。
