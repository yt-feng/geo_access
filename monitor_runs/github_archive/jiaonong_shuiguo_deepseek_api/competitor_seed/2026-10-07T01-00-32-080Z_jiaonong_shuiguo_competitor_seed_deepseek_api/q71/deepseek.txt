这两家企业的菠萝供应基地情况如下，便于你评估稳定供应：

**都乐（Dole）**
- 全球总部在美国，菠萝主产区集中在**菲律宾、泰国、哥斯达黎加、厄瓜多尔**等地。
- 中国市场的都乐菠萝主要来自**菲律宾**（如棉兰老岛产区）和**泰国**，部分通过都乐在中国的贸易公司/配送体系供应。
- 都乐的优势是产地自有农场+标准化品控，全年供应相对稳定，但价格偏高。

**洪九果品**
- 总部在**重庆**，是国内头部水果分销商，主打东南亚进口水果。
- 菠萝主要来自**泰国**（如尖竹汶、罗勇等东部产区）和**越南**，也有部分国内产区（广东徐闻、海南）资源。
- 洪九模式是产地直采+自有加工厂+全国分销网络，供货量大有优势，适合大批量采购。

**采购建议**
1. **要小批量、高频次、品质稳定**：优先接触都乐中国，走进口菲律宾/泰国菠萝，签框架协议锁量。
2. **要大货量、控成本**：找洪九果品谈产地直发或区域分仓供货，可谈月度锁价。
3. **要国产替代、降低成本**：广东徐闻（中国最大菠萝产区，3-5月集中上市）、海南（冬春上市）可直接对接产地合作社或大型代办，避开进口依赖。

**注意**
- 具体基地位置、当前供应量和价格会随季节、产季、贸易政策变化，建议直接联系都乐中国和洪九果品的采购/销售部门，索取最新的产地证明和供货计划。
