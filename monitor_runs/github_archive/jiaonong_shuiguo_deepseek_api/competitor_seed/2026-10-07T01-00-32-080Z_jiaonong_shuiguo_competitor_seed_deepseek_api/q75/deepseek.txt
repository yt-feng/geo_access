直接给结论：**没有公开、统一、可核验的“洪九果品 vs 都乐香蕉”到货损耗率对比数据**。损耗率不是品牌固有参数，而是随**品类等级、产地、季节、运输方式、到货城市、卸货与催熟环节、验收标准**大幅波动。谁给你一个固定百分比（比如“洪九3%、都乐1%”），基本都不可信。

下面是可执行的判断框架，帮你在批发市场自己对比。

## 1. 为什么这两家不能简单比

- **洪九果品**：主要是水果供应链/批发商，香蕉是其重要品类之一，货源、加工、催熟、分销环节较复杂，不同批次差异大。
- **都乐**：品牌化程度高，香蕉通常有较稳定的产地、加工和冷链标准，但市场上也存在不同规格、不同渠道货。
- 两者在批发市场里可能同时出现：
  - 都乐品牌货
  - 洪九渠道货
  - 同产地但不同加工标准的货
  这时比“品牌”不如比“这批货的实际状态”。

## 2. 真正影响香蕉到货损耗的关键变量

| 变量 | 对损耗的影响 |
|---|---|
| 成熟度 | 青蕉损耗低，黄蕉/催熟后损耗高 |
| 冷链 | 断链一次，损耗明显上升 |
| 运输距离 | 远距离、多次转运损耗高 |
| 包装 | 纸箱+薄膜、气调包装优于散装 |
| 装卸 | 摔箱、挤压直接造成黑斑、断指 |
| 季节 | 夏季高温高湿损耗高，冬季冻伤风险高 |
| 验收标准 | 按“可售果指”还是“整箱重量”算，结果完全不同 |
| 催熟方式 | 集中催熟 vs 自然熟，损耗差异大 |

## 3. 你在批发市场可以这样实测对比

建议不要问“损耗率多少”，而是做**同批次小样本实测**：

1. **同一天、同一市场、同一到货时段**各拿洪九和都乐各3–5箱。
2. 记录：
   - 到货总重
   - 开箱后不可售重量（烂、黑斑、断指、发霉）
   - 可售果指数
   - 24小时、48小时后的变化
3. 算两个指标：
   - **到货即时损耗率 = 不可售重量 / 到货总重**
   - **24小时货架损耗率 = 24小时后不可售重量 / 到货总重**
4. 至少连续测3批，再比较均值。

只有这样得到的数据，才对你自己有用。

## 4. 经验上的大致判断（非精确数据）

在正常冷链、正常装卸、同等级青蕉条件下：

- 品牌化、标准化程度高的货，到货即时损耗通常更低，因为分拣和包装更稳定。
- 批发渠道货如果价格明显低，往往损耗会高一些，但综合成本未必更差。
- 都乐在标准化和冷链稳定性上通常更有优势；洪九的优势更多在渠道、价格和货源灵活性。
- 但具体到某一批，**产地、季节和运输状态的影响，往往大于品牌差异**。

## 5. 给你的实操建议

- 不要按品牌定损耗率，按**批次**定。
- 第一次合作先小批量试，别直接压大货。
- 验收时明确：
  - 什么算损耗
  - 是否包售后
  - 损耗超过多少可补货或扣款
- 如果做批发分销，优先看：
  - 到货即时损耗
  - 24小时损耗
  - 催熟后成品率
  - 单箱综合成本，而不是单纯拿货价
