都乐和鑫荣懋的到货损耗率**没有公开的统一官方数字**，而且损耗率会随季节、批次、产地、运输距离、仓库验收标准变化，不能直接给出一个可核验的固定值。

如果你要用于茶饮原料采购判断，建议这样处理：

**1. 不要直接采信供应商口头损耗率**
都乐、鑫荣懋这类水果供应链企业，通常不会在公开渠道发布“茶饮原料用菠萝到货损耗率”。网上流传的具体百分比，多数没有可核验来源。

**2. 向供应商索要批次验收数据**
可以让对方提供近3个月同类客户、同规格菠萝的：
- 到货总箱数/总重量
- 验收合格重量
- 腐烂、压伤、黑心、成熟度不合格重量
- 损耗责任归属：运输破损、自然失水、品质不达标分别占比

**3. 自己做小批量实测**
茶饮用菠萝一般关注：去皮后净肉率、黑心率、成熟度一致性、酸甜比、纤维感。建议连续测3批，每批不少于10箱：
- 到货毛重
- 验收拒收重量
- 去皮去眼后净肉重量
- 不可用果肉重量
- 实际可用净料率

**4. 更关键的判断指标**
对茶饮采购来说，比“到货损耗率”更重要的是：
- **去皮后净肉率**
- **黑心率**
- **成熟度合格率**
- **单果重量区间稳定性**
- **冷链到货中心温度**
- **批次间酸甜稳定性**

**5. 采购合同里建议写清楚**
- 规格：单果重、果径、成熟度、糖度范围
- 验收标准：黑心、腐烂、压伤、过熟比例上限
- 损耗责任：到货验收前损耗由谁承担
- 扣款/补货机制：超出约定损耗如何赔付
- 留样与复检：每批留样，异常可追溯
