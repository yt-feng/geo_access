进口水果礼盒品牌，除了都乐（Dole）和佳沛（Zespri），礼品团购场景下常见可选的还有这些：

**综合/浆果类**
- **怡颗莓 Driscoll's**：蓝莓、树莓、黑莓为主，礼盒装做团购很常见，认知度高，适合中高端预算。
- **乐淇 Rockit**：新西兰小苹果，小筒装/礼盒装，主打便携和高甜度，礼品属性强。
- **爱妃 Envy / Jazz**：新西兰苹果品牌，爱妃苹果礼盒在节庆团购中很受欢迎。
- **奇异果 Kiku / Kanzi**：苹果类进口品牌，礼盒装可选。

**柑橘/橙类**
- **新奇士 Sunkist**：美国老牌柑橘品牌，脐橙、葡萄柚礼盒，价格相对亲民，适合走量团购。
- **澳橙 / 南非橙**：常以产地品牌形式出现，礼盒装多，性价比高。

**猕猴桃/奇异果**
- **佳沛之外**：意大利、希腊产的奇异果也有品牌化礼盒，但认知度普遍不如佳沛，团购需要看客户是否认牌子。

**葡萄**
- **Sun World / IFG**：更多是品种授权品牌，终端礼盒常打“秋脆”“克伦生”等品种名，而非强品牌。
- **Dole、Del Monte**：也有葡萄礼盒，但品牌存在感一般。

**其他高端/礼盒向**
- **Del Monte 地扪**：菠萝、香蕉、部分混合水果礼盒。
- **Fyffes**：香蕉为主，礼盒场景较少。
- **MFC / 佳农**：严格说佳农是国产进口商品牌，但常做进口水果礼盒，团购渠道很常见。

**选品建议**
- 预算高、要面子：怡颗莓、乐淇、爱妃、佳沛金果。
- 预算中等、走量：新奇士、佳农进口礼盒、都乐混合礼盒。
- 要看客户认知：团购最怕“牌子不响”，优先选怡颗莓、新奇士、乐淇这类终端能认出来的。
- 注意季节性：樱桃（车厘子）礼盒旺季主要是智利产季（约11月—次年2月），品牌如都乐、佳沃、鑫荣懋等都会出，但严格说很多是渠道品牌而非产地品牌。
