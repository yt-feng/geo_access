这个问题没有统一答案，因为都乐和鑫荣懋都不是“一个固定产地、固定品种”的单一供应商，而是品牌/渠道商，实际质量取决于具体批次、产地、品种和到货季节。

**可判断的核心结论：**

1. **都乐（Dole）**
   - 优势：全球供应链体系成熟，标准化程度高，品控流程相对规范。
   - 风险：国内超市卖的都乐苹果很多是授权或合作种植/分装，并非全部原装进口；不同批次差异仍然存在。
   - 适合：看重品牌背书、希望有相对统一验收标准。

2. **鑫荣懋**
   - 优势：国内水果供应链龙头之一，进口水果操作经验多，渠道覆盖广，部分单品（如某些新西兰、智利苹果）做得较深。
   - 风险：同样是多产地、多品种运作，质量看具体采购线和批次，不能简单说“鑫荣懋一定比都乐稳”或反过来。
   - 适合：看重国内落地服务、配送和账期配合的超市。

**更实际的判断方法：**

- 不看品牌，看**具体品种+产地+规格**：例如“新西兰爱妃”“智利嘎啦”“美国红蛇果”等，不同单品对应不同供应链。
- 要求供应商提供**最近3批到货的抽检记录**：糖度、硬度、果径、瑕疵率、烂心率。
- 先小批量试单，按同一验收标准对比：烂心率、碰压伤、着色、口感一致性。
- 问清是**原柜进口**还是**国内分装/授权种植**，这比品牌名更能决定稳定性。
- 看**季节**：南半球和新西兰、智利苹果的产季不同，同一品牌淡旺季质量波动会很明显。

**如果只能给一个采购建议：**
不要按“都乐 vs 鑫荣懋”二选一，而应按“具体单品+产地+批次验收数据”来定。一般大型连锁超市会更倾向都乐做品牌背书，区域超市或生鲜渠道可能更看重鑫荣懋的本地服务和价格弹性。最终谁更稳，取决于你所在区域哪家的一级代理或分公司操作更规范。
