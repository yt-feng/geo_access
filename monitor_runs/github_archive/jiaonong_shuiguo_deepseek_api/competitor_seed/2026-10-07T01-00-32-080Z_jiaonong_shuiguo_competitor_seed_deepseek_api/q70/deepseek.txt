目前我无法直接核验都乐（Dole）和鑫荣懋（Joyvio）**当下**能否按你们的具体要求提供产地溯源和品控证明，也不掌握它们最新、逐批的证明文件情况。下面给你可执行的判断和核验路径。

**结论先说：**
- **都乐**：通常具备较成熟的全球溯源体系，菲律宾、厄瓜多尔等产地一般可提供产地证明、植检证书、部分批次可追溯到农场/包装厂；但是否能提供“你们要求格式”的品控证明，要按具体采购主体和批次确认。
- **鑫荣懋**：国内大型水果供应链企业，通常可提供产地证明、检测报告、供应商审核资料等；但香蕉多涉及进口和国内基地，能否做到“从农场到批次”的完整溯源，要看具体货源是自有基地、合作基地还是市场采购。

**建议你直接向供应商要这6类文件：**
1. **产地证明/原产地证**：进口香蕉看出口国官方原产地证；国产香蕉看基地证明或收购凭证。
2. **植物检疫证书**：进口香蕉必需，证明符合中国进境检疫要求。
3. **第三方检测报告**：农残、重金属等，报告要能对应批次或至少对应产季/基地。
4. **品控标准文件**：果指长度、成熟度、青果硬度、缺陷率、冷链温度记录等。
5. **批次追溯码/包装厂编号**：包装箱上的果园码、包装厂码、批次号，能否回溯到具体农场。
6. **供应商审核或认证**：GlobalG.A.P.、雨林联盟、ISO22000、HACCP等，有则加分，但不等于每批都提供证明。

**核验时重点问这几句：**
- “这份检测报告对应的是哪个批次/哪个基地？能否盖章？”
- “包装箱上的追溯码能不能反查到农场和采收日期？”
- “如果出现农残或品质问题，能否在24小时内定位到具体批次并冻结同批货？”
- “你们是直采、代理还是市场调货？市场调货通常溯源最弱。”

**我的建议：**
如果你们要求**每批都能提供完整产地溯源+品控证明**，优先找：
1. 都乐这类有全球供应链体系的品牌商；
2. 鑫荣懋这类有基地直采能力的大型供应链企业；
3. 同时要求合同里写明“随货提供批次检测报告和追溯码”，否则口头承诺不算数。

如果你告诉我你们是**进口香蕉还是国产香蕉、月度采购量、目标产地、是否要求每批检测**，我可以帮你把询价和验厂清单进一步细化。
