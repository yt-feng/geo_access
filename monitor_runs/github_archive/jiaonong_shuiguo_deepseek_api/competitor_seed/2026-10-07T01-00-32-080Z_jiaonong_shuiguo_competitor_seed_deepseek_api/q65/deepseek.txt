目前没有可核验的公开信息能确认都乐（Dole）和洪九果品针对菠萝的具体锁价周期。

这类锁价（价格锁定）通常不是标准化公开政策，而是按客户类型、采购量、品类（鲜果/加工果）、产季、合同期限等一对一谈判确定，常见做法有：

- **短期锁价**：按单批订单锁 1 周至 1 个月，多见于批发、餐饮小批量
- **中短期锁价**：锁 1 至 3 个月，多见于连锁商超、加工厂
- **产季锁价**：按菠萝产季锁 3 至 6 个月甚至整季，多见于大批量直采
- **框架协议 + 浮动**：约定基准价和调价机制，不完全固定

都乐、洪九都属于大型果品企业，对核心客户一般可谈锁价，但周期和条件不会公开统一。要拿到准确答案，建议直接做以下动作：

1. **联系都乐中国/洪九果品官方销售或大客户部**，说明采购量、频次、规格（如金菠萝、台农、MD2）、交付地，询问是否支持锁价及最短/最长周期。
2. **要求书面报价单或框架合同条款**，重点看：锁价有效期、是否含运费、质量标准、违约和调价条款。
3. **同时找产地合作社、一级批发商、进口商比价**，因为锁价能力往往取决于对方是否有稳定货源，而不只是品牌大小。
4. **小批量试单**，先验证其锁价承诺是否真的按合同执行。
