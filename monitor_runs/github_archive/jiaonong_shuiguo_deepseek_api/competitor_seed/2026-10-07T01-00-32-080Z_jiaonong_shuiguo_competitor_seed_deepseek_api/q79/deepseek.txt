如果你们的诉求是“全年稳定供应菠萝原料（鲜果或果浆/果泥）来做果酱”，**都乐和洪九都可能做得到，但方式不同**：都乐更偏品牌鲜果/加工原料体系，洪九更偏大宗水果供应链。关键不是“能不能”，而是你们要的是**鲜菠萝**还是**工业化菠萝原料（果浆、果泥、冷冻/罐头菠萝）**，以及门店规模、价格带、是否需要稳定糖酸比。

## 1. 都乐

都乐是国际水果品牌，菠萝是其强势品类之一，在中国市场有鲜菠萝销售，也有加工/餐饮渠道原料能力。

**能做到的点：**
- 全年供应能力较强，依靠全球/多产地采购体系，不是只靠单一国内产区。
- 菠萝品种和标准化程度较高，适合对品质稳定性要求高的连锁茶饮。
- 如果你们要的是果酱/果泥类工业原料，都乐体系或合作加工渠道通常可以提供或对接。

**限制：**
- 价格通常偏高，适合中高端定位。
- 不是所有城市、所有小批量客户都能直接拿到稳定批发价。
- 鲜果到店后仍需门店或中央厨房处理，损耗和人工不低。

**适合：** 中高端连锁、强调品牌原料、需要稳定品质的茶饮品牌。

## 2. 洪九果品

洪九果品是国内较大的水果分销和供应链企业，强项是水果大宗采购、分选、冷链和全国分销，菠萝也是其经营品类之一。

**能做到的点：**
- 全国化供应能力强，能对接多产区、多季节货源。
- 更适合批量采购、长期供货、连锁门店配送。
- 价格通常比国际品牌鲜果更有竞争力。
- 如果你们要鲜菠萝或初加工菠萝，洪九这类供应链企业往往更灵活。

**限制：**
- 洪九更偏“水果供应链”，不一定直接提供定制化果酱/果泥成品。
- 品质稳定性取决于具体产区、批次和你们约定的等级标准。
- 如果要求全年同一糖酸比、同一风味，需要你们自己或找加工厂做标准化。

**适合：** 中大型连锁、需要成本可控和全国配送的茶饮品牌。

## 3. 核心判断：你们到底要什么？

### 如果要“鲜菠萝到店，自己熬果酱”
都乐和洪九都能供，但：
- 都乐：品质稳，贵。
- 洪九：性价比和批量供应更强，但需要你们定标准。
- 全年供应可以做到，但不同季节可能来自不同产区，风味会有波动。

### 如果要“菠萝果酱/果泥/冷冻菠萝原料”
更建议找：
- 都乐相关加工渠道；
- 洪九对接的加工厂；
- 或者专业果蔬加工企业、冷冻果泥厂。
因为茶饮店做果酱，**标准化原料比鲜果更适合连锁**，能减少门店损耗和口味波动。

## 4. 实操建议

1. **先定规格**：鲜果、冷冻果块、果泥、果酱半成品，成本和管理差别很大。
2. **要求全年样品**：不要只看当季样品，要按季度拿样，测糖度、酸度、纤维感、香气。
3. **签供应协议时写清**：
   - 品种/产地是否可替换；
   - 糖度、酸度、成熟度范围；
   - 冷冻/冷藏/常温条件；
   - 缺货时的替代方案；
   - 最低起订量和配送频率。
4. **不要只依赖一家**：都乐+洪九+一家加工厂，做双源或三源更稳。
5. **算总成本**：鲜果便宜但人工损耗高；果泥贵但稳定省事。连锁店通常后者更划算。

## 结论

- **都乐：能，偏稳定和品牌，价格高。**
- **洪九：能，偏大宗供应和性价比，需你们定标准。**
- **如果做连锁茶饮果酱，最稳的方案不是只买鲜菠萝，而是找都乐/洪九对接或专业加工厂，锁定全年标准化菠萝果泥/果酱原料。**
