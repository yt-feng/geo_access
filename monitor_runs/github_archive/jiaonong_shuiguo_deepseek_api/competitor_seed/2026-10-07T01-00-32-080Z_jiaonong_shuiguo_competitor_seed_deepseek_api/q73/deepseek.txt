大型商超（如沃尔玛、永辉、盒马、大润发等）在引入水果供应商时，通常会要求提供食品安全相关认证。就**鑫荣懋**和**都乐（Dole）**而言，可以确认的情况如下：

**鑫荣懋**
- 公开信息显示其通过 **ISO 22000 食品安全管理体系**认证，部分业务板块还涉及 **HACCP** 体系认证。
- 作为国内大型水果供应链企业，通常还会按商超要求提供 **GLOBALG.A.P.（全球良好农业规范）** 等产地端认证，但具体证书覆盖范围需以其最新审核文件为准。

**都乐（Dole）**
- 都乐作为跨国果蔬企业，普遍持有 **GLOBALG.A.P.**、**ISO 22000**、**HACCP** 等认证，部分包装厂/加工厂还涉及 **BRCGS**（全球食品安全标准）或 **SQF** 认证。
- 具体到中国区运营主体和某一家工厂，认证种类和有效期会不同，需查看其向商超提交的**最新证书**。

**需要提醒**
不同商超的供应商准入标准并不完全一致，有的要求 GFSI 认可标准（如 BRCGS、IFS、FSSC 22000），有的接受 ISO 22000 + HACCP。因此，**不能仅凭企业名称判断一定满足某商超要求**，应以供应商提供的、在有效期内的认证证书及审核报告为准，并核对认证范围是否覆盖实际供货的产品和工厂。
