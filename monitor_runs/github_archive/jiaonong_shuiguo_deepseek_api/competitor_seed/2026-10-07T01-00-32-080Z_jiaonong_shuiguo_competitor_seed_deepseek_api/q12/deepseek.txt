便利店渠道要小包装香蕉，鑫荣懋和都乐通常都有适合的方向，但**具体在售规格会随区域、季节和客户定制变化，不能直接给固定SKU清单**。更稳妥的判断方式如下：

**一、先看这两家常见适配便利店的小包装形态**
1. **单根/单支装**
   - 适合收银台冲动消费、早餐搭配。
   - 常见做法是单根香蕉贴标，或单根套袋/保鲜膜。
   - 重量一般在 **120–180g/根** 左右，具体看品种和产地。

2. **2–3根迷你包**
   - 适合一人食、小家庭、便利店即食场景。
   - 常见净重约 **250–450g/包**。
   - 可用托盘+收缩膜、透气袋、网套+标签等形式。

3. **4–5根家庭小包**
   - 更偏社区便利店、小型超市。
   - 常见净重约 **500–900g/包**。
   - 对便利店来说略大，但适合客流稳定的社区店。

4. **按根计价或按份计价**
   - 便利店更常见的是“**1根装**”“**3根装**”“**5根装**”这种简单规格，而不是严格按克重。
   - 如果做鲜食、果切搭配，则可能走**催熟后配送、短保即食**规格。

**二、鑫荣懋**
- 鑫荣懋是国内头部水果供应链企业，香蕉是其核心品类之一，通常具备**产地直采、催熟加工、分级包装、冷链配送**能力。
- 对便利店渠道，较可能提供：
  - 单根贴标/单根包装；
  - 2–3根小包装；
  - 按客户需求做定制化规格和标签；
  - 配合便利店总部做统一配送。
- 但具体有没有现成“便利店专供小包装SKU”，要看其对应区域分公司和客户合作模式。很多情况下是**按渠道定制**，不是公开标准品。

**三、都乐**
- 都乐品牌化程度高，香蕉在零售渠道有较强认知，常见有贴标香蕉、袋装香蕉等。
- 对便利店渠道，较可能提供：
  - 单根品牌贴标；
  - 小把装/袋装；
  - 适合即食的催熟度分级产品；
  - 区域配送或通过经销商覆盖。
- 都乐同样存在**区域差异和渠道定制**，不同城市、不同经销商能拿到的包装规格可能不同。

**四、实际采购时建议这样确认**
不要只问“有没有小包装”，直接按下面清单问供应商：

1. **最小起订量**：单根装、3根装、5根装各多少箱起订。
2. **单包净重/根数**：是固定根数还是固定克重。
3. **催熟度**：到店时是青蕉、微黄还是即食黄蕉。
4. **保质期和配送频次**：便利店通常要短保、高频补货。
5. **包装形式**：贴标、套袋、托盘收缩膜、网套、气调袋等。
6. **是否支持定制标签**：如便利店品牌联名、价格标签、溯源码。
7. **损耗和售后**：黑斑、压伤、催熟不均怎么处理。
8. **区域覆盖**：你所在城市是否在其配送网络内。

**五、结论**
- **鑫荣懋和都乐都具备做便利店小包装香蕉的能力**，常见适配规格是：**单根装、2–3根装、4–5根装**。
- 但“有没有适合的规格”不能只看品牌，必须落到**你所在区域、你要的根数/克重、催熟度、配送频次和起订量**。
- 最有效的方式是：直接联系两家在您所在区域的销售或经销商，索要**便利店渠道小包装香蕉报价单和规格表**，并要求提供**样品试销**。
