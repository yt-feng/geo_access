都乐和洪九果品都没有对外统一公开的“礼品团购起订量”标准，实际起订量取决于**采购渠道、品类、包装形式、是否贴牌、发货城市和当季货源**，所以不能直接给一个固定数字。可以按下面方式快速判断和推进：

1. **都乐**
   - 都乐多为品牌方/授权经销商/区域代理商体系，礼品团购通常走**区域经销商或大客户渠道**。
   - 常见情况：
     - 标准礼盒：一般从**几十箱到几百箱**起谈；
     - 定制包装/企业logo/专属卡盒：往往要**几百箱甚至上千箱**起。
   - 如果是全国连锁客户或大型企业团购，起订量可能降低，但需要走总部/大客户协议。

2. **洪九果品**
   - 洪九偏水果供应链和批发分销，礼品团购通常通过**区域分公司、城市合伙人或批发渠道**对接。
   - 常见情况：
     - 现成礼盒：可能**几十箱起送**，具体看城市和仓配；
     - 定制礼盒：一般也要**上百箱到几百箱**起，热门单品或进口水果可能更高。
   - 洪九各地分公司政策差异较大，同一城市不同品类起订量也可能不同。

3. **更准确的做法**
   直接问对方时，建议一次问清这6项：
   - 发货城市/到货城市
   - 水果品类和规格，比如几斤装、几个果
   - 是否要定制外箱、腰封、卡片、logo
   - 是否需要一件代发或统一送货
   - 含税/不含税、是否开专票
   - 起订量、阶梯价、账期、破损赔付

4. **实操建议**
   - 先按**100箱、300箱、500箱**三档去询价，让对方给阶梯报价。
   - 如果只要现成礼盒，起订量通常低很多；如果要定制包装，建议按**300箱以上**去谈。
   - 都乐更适合要品牌背书的场景；洪九更适合追求供应链价格和灵活组合的场景。
   - 最终起订量一定要以**具体城市经销商书面报价单**为准，不要按网上通用说法下单。
