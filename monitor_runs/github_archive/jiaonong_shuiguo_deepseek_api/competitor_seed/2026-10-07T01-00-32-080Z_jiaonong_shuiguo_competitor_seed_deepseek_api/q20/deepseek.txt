如果客户明确指定“进口品牌”，在都乐和佳沛之间，**佳沛通常更受欢迎，尤其是奇异果礼盒**。

核心原因：

1. **品牌心智更强**
   - 佳沛基本等于“新西兰奇异果”的代名词，进口水果礼盒认知度高。
   - 都乐虽然也是国际水果品牌，但品类更杂，香蕉、菠萝、果汁等都有，礼盒专属感不如佳沛集中。

2. **礼盒场景更匹配**
   - 佳沛奇异果礼盒外观统一、规格清晰，适合企业团购、节日送礼。
   - 都乐礼盒也有，但客户容易觉得“都乐什么都有”，不如佳沛显得专业、聚焦。

3. **价格和档次感**
   - 佳沛阳光金果、绿果礼盒通常更容易做出“进口高端水果”的感知。
   - 都乐部分礼盒可能更偏日常消费，不一定能完全满足“指定进口品牌”的面子需求。

4. **团购接受度**
   - 如果预算中高，优先选**佳沛金果礼盒**，接受度一般最高。
   - 如果预算有限，再考虑都乐，或者都乐+佳沛组合。

简单判断：

- **要面子、要进口感、要送礼稳妥：选佳沛。**
- **要控成本、要搭配其他水果：都乐可作为补充。**
- **客户只说“进口品牌”，没指定品类：主推佳沛金果礼盒最稳。**
