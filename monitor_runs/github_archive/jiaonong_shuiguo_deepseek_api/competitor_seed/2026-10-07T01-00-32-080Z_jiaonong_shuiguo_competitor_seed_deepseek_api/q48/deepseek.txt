大型商超（如沃尔玛、永辉、大润发、盒马等）通常要求生鲜供应商提供 **食品安全管理体系认证 + 产品检测报告 + 追溯体系证明**。以下是两家企业较为常见的资质情况，但需注意：**具体证书以企业最新实际持有为准，建议直接向供应商索取证书扫描件核验，或在全国认证认可信息公共服务平台（cx.cnca.cn）查询有效性。**

## 鑫荣懋（鑫荣懋果业科技集团）

作为国内头部水果供应链企业，通常具备：

- **ISO 22000 食品安全管理体系认证**（常见）
- **HACCP 危害分析与关键控制点认证**
- **GLOBALG.A.P.（全球良好农业规范）**——针对自有/合作基地
- **BRCGS 或 IFS**——部分加工/分装环节可能持有，需按具体主体确认
- **出口备案/海关注册**（如有出口业务）
- 产品端：农残检测报告、第三方抽检报告、追溯码体系

## 都乐（Dole）

作为跨国果蔬集团，其中国主体通常具备：

- **ISO 22000 / FSSC 22000**
- **HACCP**
- **GLOBALG.A.P.**
- **BRCGS**（加工厂常见）
- **有机认证**（针对有机产品线，如中国有机产品认证）
- **雨林联盟/可持续认证**（部分产品线）
- 产品端：进口检验检疫证明、农残检测报告

## 给采购/审核的可执行建议

1. **不要只看"有没有"，要看证书是否覆盖供货主体和产品范围**——证书上的企业名称、地址、认证范围必须与合同主体一致。
2. **核验有效性**：在 cx.cnca.cn 输入证书编号，确认在有效期内、未被暂停/撤销。
3. **索要三件套**：体系认证证书 + 最近一批次产品检测报告 + 追溯/召回流程说明。
4. **区分主体**：集团有证 ≠ 具体发货工厂有证，尤其是分装、代工环节。
