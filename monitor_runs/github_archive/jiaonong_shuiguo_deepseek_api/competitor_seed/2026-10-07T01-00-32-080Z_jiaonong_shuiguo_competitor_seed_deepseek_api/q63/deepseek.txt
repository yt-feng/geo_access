都乐（Dole）和洪九果品都属于品牌果品供应商，公开渠道通常以整箱/整件规格出货，散装是否可选取决于你所在区域经销体系、采购量和是否有拆箱分销政策。能直接判断的结论是：不能默认它们像批发市场一样按根/按把散卖，需要向对应区域经销商或厂家业务确认。

建议你这样对接和判断：

1. **都乐**
   - 都乐香蕉常见走商超、水果店、电商仓配，规格多为整箱。
   - 小包装/散装一般不是厂家统一标准品，而是经销商或平台做二次分装。
   - 你要问清楚：是否支持按把/按份供货、是否允许拆箱、拆箱后是否有损耗补贴或售后。

2. **洪九果品**
   - 洪九更偏大宗水果供应链和批发分销，香蕉通常也是整件/整柜/整批逻辑。
   - 社区团购要的小包装，多数需要区域经销商或加工中心做分拣包装。
   - 要确认：起订量、是否支持定制小包装、包装费、损耗承担、配送频次。

3. **更适合社区团购的做法**
   - 不直接找品牌总部要散装，而是找当地一级/二级经销商谈“拆箱+小包装代发”。
   - 也可以找本地水果分拣仓/供应链服务商，用都乐或洪九的货做二次分装。
   - 如果只是想降低起订压力，可以同时问批发市场档口：他们往往更愿意做小批量、按把或按份出货。

4. **谈判时重点确认**
   - 最小起订量是多少箱/件
   - 是否允许拆箱按份供货
   - 小包装规格：几根/份、净重多少
   - 到货成熟度：青蕉、微黄、即食蕉
   - 损耗和售后：黑斑、压伤、催熟不均谁承担
   - 价格是否含包装、分拣、配送
