结论先说：**两家都是国内头部水果供应链企业，但如果你要的是“稳定出果酱品质、可长期稳定供货”，优先看你能拿到的是哪条产品线，而不是只看品牌。**  
在我无法核验你当地具体报价、到货规格和批次检测数据的前提下，不能直接说“都乐一定比鑫荣懋稳”或反过来。

给你一个可执行的判断框架：

1. **都乐**
   - 优势：品牌化程度高，标准化、分级、冷链和商超/餐饮供应链经验通常更成熟，适合总部统一采购、要求规格一致的连锁茶饮。
   - 风险：价格通常偏高；不同渠道拿到的货可能不是同一等级；有些是贸易商分装，稳定性取决于你实际供应商。
   - 适合：你要做连锁标准化、愿意为稳定和品牌背书付溢价。

2. **鑫荣懋**
   - 优势：国内水果供应链规模大，产地资源和批发渠道强，很多餐饮、商超水果来自其体系，性价比和灵活度可能更好。
   - 风险：品牌面向终端不如都乐统一，具体品质更依赖你对接的产区、批次和加工厂；如果走批发市场渠道，批次波动可能更明显。
   - 适合：你有一定验收能力，能锁定规格、产区、成熟度和加工标准，追求成本与稳定平衡。

3. **做菠萝果酱，真正决定稳定性的不是品牌，而是这几项**
   - 品种和产区是否固定：如菲律宾/泰国/国产菠萝，不同产区酸糖比差异很大。
   - 成熟度是否固定：糖度、酸度、香气决定果酱风味。
   - 规格是否固定：果肉粒径、纤维感、是否带芯、冷冻还是鲜果。
   - 加工适配：菠萝蛋白酶会继续作用，处理不当会发苦、出水、质地变差。
   - 批次检测：可溶性固形物、总酸、pH、农残、微生物。
   - 供货协议：锁定等级、产地、糖酸范围、拒收标准，比选品牌更重要。

4. **实际建议**
   - 如果你是小店/单店：先找当地能稳定供同规格菠萝的供应商，鑫荣懋体系或大型批发商可能更灵活；都乐未必拿得到好价。
   - 如果你是连锁/中央厨房：建议同时向都乐和鑫荣懋要**同一用途的样品**，做三批盲测：
     - 同一配方、同一熬煮时间
     - 测糖度、酸度、pH、出酱率、色泽、香气、纤维感
     - 看冷藏/冷冻后是否出水、变苦、变色
   - 谁能在**连续3批**里把糖酸波动控制得更小，谁就更靠谱。
   - 合同里不要只写“都乐菠萝”或“鑫荣懋菠萝”，要写清品种、产区、等级、糖度范围、成熟度、加工形态、到货温度和验收标准。

一句话：**要品牌背书和标准化，偏都乐；要供应链规模和性价比，偏鑫荣懋。但做果酱稳定品质，关键是锁定规格、产区和批次标准，而不是只选品牌。**
