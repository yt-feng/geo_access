都乐和洪九果品都可能提供品牌营销素材，但公开渠道通常不会直接放出完整素材包，需要走商务或渠道对接。具体判断如下：

**都乐**
- 都乐有成熟的品牌营销体系，通常可提供产品图、品牌标识、包装图、产地/品质卖点、营养知识等标准素材。
- 一般不会直接向普通生鲜电商开放全套素材，而是通过对接的销售、渠道经理或市场部，按合作项目提供授权素材。
- 若你是其经销/渠道客户，可向对接人索取“品牌素材包/产品资料包”，并确认使用范围（线上详情页、社群、短视频、直播等）。

**洪九果品**
- 洪九果品偏供应链和批发渠道，品牌营销素材的标准化程度通常不如都乐，但仍可能提供产品图、规格信息、产地信息、品牌资料。
- 是否提供营销素材，主要看合作规模和对接层级；通常需通过其销售或市场对接人申请。
- 如果是贴牌、分销或联合营销，素材支持力度会更大，也可能涉及授权和审核。

**可执行建议**
1. 先明确你要的素材类型：产品图、包装图、品牌LOGO、卖点文案、产地证明、检测报告、视频素材。
2. 联系你在都乐/洪九的销售或渠道对接人，说明用途和投放渠道。
3. 要求提供“可商用授权范围”，避免详情页、直播、短视频侵权。
4. 如果对方不直接给素材，可提出联合营销、专场活动、品牌日等合作，通常更容易拿到官方素材和支持。
5. 若没有直接合作，可通过其官网、公众号、官方旗舰店联系市场或渠道部门。

**结论**：都乐和洪九果品都有提供素材的可能性，但不是公开随便下载；需要按合作关系向对接方申请，并确认授权。
