关于都乐（Dole）和鑫荣懋（Xinrongmao）进口苹果的价格竞争力，**目前我无法提供实时、具体的批发价或报价**，因为这两家公司的价格会随产地、季节、汇率、采购量、包装规格（如箱装克重、果径）以及具体的苹果品种（如红玫瑰、青苹果、富士等）而动态变化。

不过，基于行业惯例和公开信息，我可以给你一些判断和决策的参考建议：

**1. 价格竞争力的基本判断维度：**

-   **都乐（Dole）：** 全球知名品牌，品牌溢价通常较高。他们的产品更多主打高端市场，包装、品控标准非常严格。因此，**如果追求“品牌效应”和“稳定品质”，都乐的单价通常会略高于鑫荣懋**。
-   **鑫荣懋（Xinrongmao）：** 是国内大型水果供应链企业，采购量大，且更熟悉国内终端渠道。**在同等品质条件下，鑫荣懋的供货价往往更具灵活性，尤其是针对连锁门店的大批量采购，谈判空间更大**，其性价比通常更占优势。

**2. 你需要做的实际比价动作（建议）：**

-   **索取“全项报价单”：** 要求两家供应商提供**同一品种、同一产地、同一果径（例如70mm vs 75mm）、同一包装规格（例如10kg/箱）**的报价。没有统一基准，价格没有可比性。
-   **关注“到仓价”**：不要只看裸价，要问清楚是否包含运费、冷链、损耗补贴。部分品牌报价低但运费高，综合到仓成本可能反而更高。
-   **洽谈“返利或账期”**：连锁门店通常有规模优势。你可以直接向采购经理提出“竞品询价”作为谈判筹码，要求鑫荣懋或其代理商在同等条件下给出更低的折扣价或年返利政策。

**3. 额外的核心建议（“便宜”不等于“竞争力”）：**

-   **看损耗率：** 进口苹果在长途运输后，果蒂是否脱落、内部是否褐变是关键。都乐的标准化分选通常能保证较低的开箱损耗（通常控制在3%-5%以内）。如果鑫荣懋的供货损耗率高于这个水平，即使单价低5%，你的综合毛利也可能更低。
-   **看动销速度：** 你的连锁店客群更认哪个品牌？如果都乐的品牌认知度高，能在你门店实现快速周转，那么“高一点的价格”可能反而是更低的综合成本。反之，如果鑫荣懋在当地有更紧密的配送体系，补货更及时，那它的价格优势就更有价值。

**结论：**
在目前的市场环境下，**大概率是鑫荣懋的硬性批发价更有竞争力，但都乐在品质稳定性上更有保障。** 建议你不要只盯价格，直接让两家按你门店的分级标准（如一级果）报“整柜到仓价”，争取一周内拿到含税的书面报价对比，并加上5%预算作为损耗预备金来测算最终毛利。
