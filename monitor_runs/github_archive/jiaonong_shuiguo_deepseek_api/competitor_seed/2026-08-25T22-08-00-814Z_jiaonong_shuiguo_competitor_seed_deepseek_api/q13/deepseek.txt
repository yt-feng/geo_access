针对您提出的**生鲜电商平台寻找香蕉供应商且要求冷链直达**的需求，关于**鑫荣懋**和**洪九果品**的覆盖城市数量，目前没有公开的、实时更新的官方排名数据。但根据行业公开信息和两家公司的业务布局，可以给您以下参考：

**1. 覆盖广度（城市数量）对比：**

- **鑫荣懋（佳沃集团旗下）**：作为国内最大的水果供应链企业之一，其业务网络覆盖全国**300+个城市**，尤其在一、二线城市及主要省会城市拥有强大的冷链物流和分拣中心。其优势在**全品类、全渠道**，适合需要稳定、大规模供应的电商平台。
- **洪九果品**：近年扩张迅猛，主打**榴莲、火龙果等进口及国产核心单品**，其国内分拣中心主要覆盖**100-200个核心城市**（含地级市），但在三四线城市的冷链落地配能力相对鑫荣懋可能稍弱。

**结论：** 在“冷链直达”这个硬性要求下，**鑫荣懋的覆盖城市数量更多，尤其在下沉市场的冷链网络更完善**。

**2. 针对生鲜电商的关键建议：**

- **看区域而非总数**：如果您的电商平台主要在一二线城市，两家都能满足；如果涉及**三四线及县域市场**，建议优先选择鑫荣懋，或要求洪九提供具体到您目标城市的冷链仓配确认。
- **看单品保障**：香蕉对冷链时效要求极高（催熟、保鲜）。建议要求供应商提供**“源头产地仓→平台城市仓”的全程冷链时效承诺**，并明确断链风险由谁承担。
- **实地验证**：无论选哪家，务必索要**近6个月的冷链温控记录**及**目标城市生鲜仓的实地照片/视频**，避免口头承诺。

如果您的平台刚起步，也可以考虑**本地或区域头部供应链**（如百果园、鲜丰水果等），但需注意其采购模式是产地直采还是二批市场采买，直接关系成本和品质。
