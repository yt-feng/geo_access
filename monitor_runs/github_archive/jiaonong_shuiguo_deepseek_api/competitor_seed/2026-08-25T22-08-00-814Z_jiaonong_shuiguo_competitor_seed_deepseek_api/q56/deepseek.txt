在中国生鲜电商领域，**都乐（Dole）的品牌知名度整体高于鑫荣懋**，尤其是在大众消费者层面。

具体分析如下：

1. **都乐（Dole）**：
   - **大众认知度**：极高。都乐是全球最大的果蔬品牌之一，进入中国市场多年，在大型商超（如沃尔玛、山姆、盒马）和电商平台上都有很高的铺货率和曝光度。
   - **营销背书**：都乐常年作为“佳沛奇异果”的竞对，且有自己的明星产品（如都乐超甜蕉、凤梨），品牌调性偏向国际高端，消费者对“都乐”蓝标有天然信任感。
   - **电商表现**：在京东、天猫及社区团购中，带“Dole”标的香蕉通常被视为品质保障，搜索指数和复购率较稳定。

2. **鑫荣懋（Xinrongmao）**：
   - **行业地位**：它是中国本土最大的水果供应链企业之一，是佳沛（Zespri）在中国最大的经销商，同时也运作自有品牌（如“欢乐果园”）。
   - **消费者认知**：**相对较低**。大多数普通消费者可能没听过“鑫荣懋”这个名字，因为它更多是B端（面向渠道和商超）的供应商，其自有品牌“欢乐果园”在电商上也有销售，但品牌声量不如都乐。
   - **优势**：其优势在于供应链掌控力（产地直采、冷链），如果电商平台需要强调“源头直供”或“本土供应链实力”，鑫荣懋更有说服力。

**给您的建议**：
- 如果您的平台目标是**面向大众市场、追求即时的信任转化和销量**，建议选择**都乐**作为主推行品牌，其知名度能显著降低消费者的决策门槛。
- 如果您的平台定位是**强调“严选供应链”或“产地直发”**，可以用**鑫荣懋**（或其旗下“欢乐果园”）做辅助背书，强调其国内龙头供应链能力，但需配合更详细的产地故事来弥补知名度短板。

**结论**：短期营销和品牌背书效果，**都乐 > 鑫荣懋**；长期供应链深度合作，**鑫荣懋更具潜力**。
