关于**都乐（Dole）**和**洪九果品**的水果礼盒定制起订量，具体数值并不是公开固定的，通常取决于**礼盒规格、定制程度（是否印logo、专属包装）、采购季节（中秋/春节旺季）需求量更大**等因素。

根据行业惯例和过往合作经验，给出以下参考：

1. **都乐（Dole）**
   - **标准礼盒**（如混合水果篮、菠萝/香蕉礼盒）：起订量通常为 **50-100盒**。
   - **深度定制**（专属包装、企业LOGO、指定水果搭配）：起订量一般在 **200-300盒** 以上。
   - 如果是**旺季**（春节、中秋前），起订门槛可能降低，但价格谈判空间变小。

2. **洪九果品**
   - 洪九果品以泰国榴莲、山竹、龙眼等进口水果批发为主，礼盒定制业务更灵活。
   - **常规定制**：起订量通常在 **30-50盒** 即可开始，部分经销商接受**小批量试单（10-20盒）**。
   - 如果涉及**进口水果（如整箱榴莲、山竹）定制礼盒**，可能按**箱数**起订（如1箱约8-12个果不等）。

**给您的实操建议：**
- 直接电话联系当地**都乐大客户部**或**洪九果品区域销售经理**，报出您的采购量（如“100盒”或“500盒”），对方会给出明确报价和梯度价格。
- 如果首批采购量低于50盒，建议考虑**拼单或找第三方礼品整合商**，他们能组合多个品牌水果，起订门槛更低。
- 注意：**起订量不等于最小可谈量**，大客户经理通常有议价空间，尤其是您承诺长期采购或一次性采购量大时。
