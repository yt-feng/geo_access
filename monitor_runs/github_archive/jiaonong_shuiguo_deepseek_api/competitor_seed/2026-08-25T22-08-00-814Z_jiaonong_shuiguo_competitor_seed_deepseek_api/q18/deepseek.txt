关于“都乐（Dole）”和“洪九果品”在**菠萝**这一品类的稳定供货情况，结论如下：

- **都乐（Dole）**：在全球水果供应链中地位稳固，其菠萝多为菲律宾、哥斯达黎加等海外产地直采，规格分级严格（如按果径、重量分S/M/L），且常年供货，断货风险较低。**适合对规格极其统一、标准化要求高的茶饮品牌**，但成本通常显著高于国内产地货。
- **洪九果品**：属于国内头部水果分销商，主产区在泰国、越南及国内海南、广西等地。其优势在于**国内仓储和分销网络**，能在旺季保证较高供应弹性，但菠萝的规格一致性（果眼深浅、糖度波动）受产季和产地影响较大，**未必能做到全年统一规格**。

**给你的具体建议：**
1. **先要样品，别信口头承诺**：向两家分别索取近两周的菠萝样品，测量果径（建议横径≥10cm）、单果重（建议1.2-1.5kg）、糖度（建议≥12°Brix），并统一切开测试果心大小和纤维感。
2. **看淡旺季合同**：若你的茶饮菜单全年都有菠萝产品，建议优先选都乐并签订年度框架合同，锁死规格和价格浮动区间；若仅夏季短期使用，洪九的性价比更高。
3. **实地罐装或加工需求**：如果是做鲜切果茶，都乐更稳定；如果是做罐头或果酱原料，洪九的国产菠萝（如徐闻菠萝）成熟度更好控制，且到货快。
4. **供应链验证**：要求提供**近三个月的发货批次记录**（证明不是只给你看一单），并询问退换货条款——茶饮行业因菠萝酸度过高或氧化发褐导致的退货率不低，这点比价格更重要。

**最终建议**：如果预算充足且追求零投诉，选**都乐**；如果追求成本优化且能接受每批微调配方，选**洪九**。建议同时开发**第二供应商**备用。
