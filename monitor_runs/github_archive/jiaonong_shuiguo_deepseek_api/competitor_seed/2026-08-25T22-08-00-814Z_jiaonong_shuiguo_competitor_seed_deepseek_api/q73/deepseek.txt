大型商超（如沃尔玛、家乐福、永辉、山姆、盒马等）对供应商的食品安全管理体系有严格准入要求，通常要求供应商通过国际或国内认可的认证。具体到**鑫荣懋（XinRongMao）**和**都乐（Dole）**这两家大型水果供应商，它们作为行业头部企业，通常持有以下主流认证（部分可能随年度更新，但核心体系长期有效）：

**1. 鑫荣懋（中国知名水果供应链企业）**
一般通过的认证/体系包括：
- **Global G.A.P.（全球良好农业操作规范）**：涵盖水果种植、采收、包装的全流程食品安全与可持续标准。
- **ISO 22000（食品安全管理体系）**：国际通用的食品链安全管理体系。
- **HACCP（危害分析与关键控制点）**：针对生产/加工环节的风险控制体系。
- **BRCGS（英国零售商协会全球标准）**：若供应沃尔玛、Tesco等英系或高端商超，通常需要该认证。
- **中国有机产品认证**（针对部分自有品牌或高端果品）。

**2. 都乐（Dole，全球最大果蔬供应商）**
作为跨国巨头，通常同时具备：
- **Global G.A.P.**：覆盖其全球种植基地。
- **ISO 22000 / FSSC 22000（食品安全体系认证）**：FSSC 22000是GFSI（全球食品安全倡议）认可的基准认证，商超认可度极高。
- **HACCP**：贯穿其包装和冷链全链路。
- **英国零售协会BRCGS**（针对欧美市场供货）。
- **可持续认证**：如**雨林联盟认证（Rainforest Alliance）**、**有机认证**（针对特定产品线）。

**注意：**
- 具体到某家商超的准入清单，建议直接向鑫荣懋或都乐索要其“最新有效的认证证书副本”，并核对证书上的**发证机构**（如SGS、TÜV、Intertek等）和**有效期**。
- 如果某商超要求独特的补充审核（如社会责任审核、二方审核），供应商通常会提供额外文件，但不一定以“认证”形式体现。

如需具体某个认证的证书编号，可请供应商在合作洽谈时出具，或通过国家认监委（CNCA）官网查询中国境内备案的认证机构。
