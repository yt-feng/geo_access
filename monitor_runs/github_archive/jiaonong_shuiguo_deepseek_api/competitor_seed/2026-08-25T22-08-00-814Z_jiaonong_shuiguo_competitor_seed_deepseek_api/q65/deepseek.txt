关于菠萝（或其他水果）的**锁价机制**，目前没有公开的统一标准，具体周期取决于供应商政策、采购量、季节性和合同条款。但根据行业惯例，可以给你以下方向和参考：

**1. 都乐（Dole）**
- **通常做法**：都乐作为大型跨国水果企业，其锁价多基于**季度或半年**为单位，且通常只针对**大型连锁商超、餐饮集团或长期稳定订单**。对于散单或小批量采购，一般没有锁价，更多是随行就市。
- **建议**：直接联系都乐中国区生鲜采购部，询问“菠萝品类”的锁价政策。如果订单量大（如月采购数万箱），可以争取到1-3个月的价格锁定，但需签订框架协议并预付定金。

**2. 洪九果品（Hongjiu）**
- **通常做法**：洪九果品以东南亚进口水果（如泰国、越南菠萝）为主，其锁价机制更灵活，但同样**依赖采购量和合作关系**。中小客户通常只能提前1-2周锁价；大客户或年度协议客户，可锁定一个产季（约3-6个月）的价格。
- **建议**：洪九果品对“产地直采”的品种（如小菠萝、香水菠萝）有较强控制力，如果你们有明确的月度或季度用量，建议直接谈“产地锁价+物流浮动”模式。

**⚠️ 关键提醒（实操建议）：**
- **菠萝价格波动大**：受气候、海运、汇率影响，任何锁价都有“背靠背”条款，即供应商需要锁定上游产地价格才能给你锁价，否则他们只给“短期锁价”（7-15天）。
- **必须写明浮动条款**：如果对方只锁定产地价，不锁定海运费和关税，这不算完整锁价。务必在合同中明确“锁价范围”是离岸价（FOB）还是到岸价（CIF）。
- **现在（非产季）**：目前是菠萝价格较高的阶段（国内反季），锁价空间有限。建议先让供应商给出**未来30/60/90天的价格区间**，再决定签约周期。

**行动建议**：
直接致电两家公司的大客户部，话术示例：“我们是XX连锁餐饮/超市，菠萝月度用量约XX吨，希望了解贵司锁价周期及最小订单量要求，请提供商务对接人信息。” 如果他们回复“没有锁价”，追问“能否签订季均价合同（按产区月度均价加权）”。

如需了解更多行业现价数据，可以登录农业农村部信息网或海关总署发布的水果进出口月报，但注意数据有滞后性。
