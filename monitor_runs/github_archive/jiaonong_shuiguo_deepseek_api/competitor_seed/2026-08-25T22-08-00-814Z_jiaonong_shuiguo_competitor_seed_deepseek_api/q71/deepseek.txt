关于茶饮原料采购中菠萝的稳定供应，您提到的**都乐（Dole）** 和**洪九果品** 是国内菠萝供应链中较知名的企业。以下是基于公开信息的回答：

---

### 1. **都乐（Dole）**
- **基地分布**：都乐是全球化企业，其菠萝种植基地主要位于**菲律宾（棉兰老岛）**、**泰国**、**哥斯达黎加**等地。在中国市场，都乐通过进口+本地合作模式供应，国内暂无大规模自建菠萝基地，但会与**海南、广东**的菠萝产区签订采购协议（如海南文昌、广东湛江徐闻）来补充供应。
- **采购建议**：如需与都乐合作，建议直接联系其中国区总部（上海），确认其当季供应基地和物流仓储节点。

---

### 2. **洪九果品**
- **基地分布**：洪九果品是国内头部水果供应链企业，其菠萝基地主要集中在**海南（特别是文昌、琼海）** 和**广东（湛江徐闻）**。此外，洪九在**泰国、越南**也有进口菠萝采购渠道，用于反季节补充。
- **特点**：洪九与海南、广东多个合作社有长期订单，能实现从田间到分选、冷链的一体化运作，适合茶饮企业大批量、稳定采购。

---

### 3. **稳定供应建议（针对茶饮门店）**
- **主产地周期**：  
  - **海南菠萝**：3-5月是高峰（如“台农17号”）。  
  - **广东徐闻菠萝**：4-6月为主。  
  - **泰国菠萝**：全年可供应，但价格波动大。  
- **双渠道备份**：建议同时对接**洪九果品（国内基地直采）** 和**都乐（进口+海南补充）**，避免单一产地受天气或物流影响。
- **验收标准**：茶饮用菠萝建议要求糖度≥12°、无黑心、成熟度8-9成，并要求供应商提供农残检测报告。

---

### 4. **注意事项**
- **核实时效性**：水果基地合作会随季节调整，建议直接致电两家公司销售部门，索取最新基地备案清单（而非依赖网络信息）。
- **冷链物流**：若门店不在产区，务必确认供应商是否支持“产地-前置仓-门店”的全程冷链（最佳成本价为陆运+冷柜）。
