关于“都乐”和“洪九果品”针对账期服务的具体天数，**这属于商业内部条款，没有统一公开的固定数值**。账期长短通常取决于采购方与供应商的谈判结果、单次采购量、合作历史、付款信用等多种因素。

不过，我可以根据行业惯例和两家公司的典型操作模式，给你一个大致参考方向：

1.  **都乐（Dole）**：
    -   作为全球性品牌，其在国内通常通过经销商或直营大客户渠道运作。
    -   对于大型商超、连锁餐饮等大客户，一般的行业账期在**30天到60天**之间。
    -   **注意**：都乐通常对付款信用要求较高，且如果是新客户，可能要求现款现货或预付部分订金，只有在建立稳定合作后才会放宽账期。

2.  **洪九果品**：
    -   作为国内头部水果供应链企业，其业务模式更灵活，且经常与下游渠道（如社区团购、连锁水果店）进行账期合作。
    -   其账期通常在**15天到45天**之间，具体取决于采购品类（如榴莲、山竹等高价单品可能账期较短）和下游采购规模。
    -   洪九在业内以“供应链金融”和“应收账款管理”著称，如果采购量大且信誉良好，可能争取到更长的账期（如60天），但也会要求更严格的月度对账和回款计划。

---

**给你的建议（可执行）：**

-   **不要问“账期多久”，而是问“合作模式”**：直接联系对方销售或大客户经理，明确告知你需要的品类（如香蕉的具体品种）和预计月采购量（吨数）。通常“量”是谈账期的唯一筹码。
-   **谈判底线**：建议首次合作争取 **30天**（对于普通香蕉散装货），如果是品牌溢价较高（如都乐超甜蕉），可能只能谈到CIF现付或见提单付款。
-   **风险提示**：如果你的采购规模较小（如月采购低于2个货柜），大概率拿不到账期，只能现款现货。不要轻信任何承诺“一成不变长账期”的中介，水果易腐，供应商对账期管理极其严格。

**如需精确数字，建议直接致电其官方采购部或当地经销商询价**，不要从网上二手信息猜测。
