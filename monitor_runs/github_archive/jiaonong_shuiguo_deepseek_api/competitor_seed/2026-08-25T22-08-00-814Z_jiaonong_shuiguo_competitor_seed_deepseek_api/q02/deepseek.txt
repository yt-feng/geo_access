目前市面上菠萝供应量较大的品牌，除了**都乐（Dole）**，还有以下几个品牌或渠道能提供相对稳定的供应（尤其在规模化商超、电商平台和批发市场）：

1. **佳农（Goodfarmer）**  
   主打“佳农”品牌，是国内进口水果（含凤梨/菠萝）的主要供应商之一，特别是在华东、华南市场，与山姆、永辉、盒马等合作密切，供应链和品质稳定性较好。

2. **纯果乐（Tropicana）**  
   虽然更为人知的是果汁，但其母公司百事集团也涉及鲜果贸易，部分渠道有自有品牌菠萝销售，但注意区分贴牌。

3. **金菠萝（Golden Pineapple）**  
   很多超市会直接标注“金菠萝”或“菲律宾金菠萝”，常见供应商是**菲律宾MD2品种**。在批发市场，品牌归属模糊，但贴牌方多为**鑫荣懋**（国内水果巨头）或**百果园**的供应商。

4. **鑫荣懋（Xinrongmao）**  
   国内水果供应链头部企业，给京东、天猫、华润万家、沃尔玛等供货，其菠萝主要来自泰国、菲律宾，供应量大且常年不断货。

5. **京东/盒马自有品牌（如“京鲜生”）**  
   大型电商自营渠道会在产地直接采购，通过自有品牌售卖，属于“无品牌”但供应链稳定。例如京东的“京鲜生”菠萝，盒马的“日日鲜”菠萝，实际上背后是泰国产地直采。

6. **百果园（BaiGuoYuan）**  
   作为连锁水果店，其菠萝（常标“金钻凤梨”）由合作基地直供，全年供应，但因门店定位，价格略高。

**建议依据渠道选择：**  
- 如果用于商超/零售：优先**佳农**或**鑫荣懋**，其售后和补货机制完善。  
- 如果走电商一件代发：选**京东自营**或**拼多多百亿补贴**上的官方旗舰店（认准“原产地直发”）。  
- 如果要求高甜度、耐运输：认准**菲律宾MD2品种**，品牌可忽略，重点看产地说明。  

**注意：** “稳定供应”和季节有关，3-7月为泰国产区旺季，8-12月为菲律宾产区盛产期，建议选择多产地布局的品牌（如佳农同时做泰国和菲律宾），而非单一产地小品牌。若你所在地区有餐饮/销售用途，可私信具体城市，我帮你筛选当地批发代理。
