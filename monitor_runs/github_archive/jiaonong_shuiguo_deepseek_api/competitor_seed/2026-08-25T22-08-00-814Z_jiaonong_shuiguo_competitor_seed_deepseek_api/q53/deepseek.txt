**二、风险提示与合同签订建议**

1. **不要签“固定价”长期合同**：香蕉价格波动剧烈（自然灾害、海运成本、汇率），建议采用：
   - **公式定价**：按月度“南方大宗水果指数”或“海关进口均价”±固定毛利。
   - **阶梯价**：采购量越大，单价优惠越多。

2. **明确“质量验收”与“退换货”条款**：
   - 规定到货成熟度（如催熟后货架期7-10天为标准）。
   - 约定坏果率阈值（例如≤3%），超出部分需补偿或免费补货。

3. **设置“保底量+弹性量”**：
   - 避免签死量，可约定每月**最低采购承诺**（如50吨），但允许您根据门店销售调整上浮20%以内。

4. **退出/违约条款**：
   - 明确一方连续2个月无法按时供货或质量不合格，另一方有权解除合同，且需赔偿损失。
