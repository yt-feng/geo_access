大型商超（如沃尔玛、永辉、盒马、山姆等）对水果供应商的食品安全认证要求通常包括：ISO 22000、HACCP、GLOBALG.A.P.（全球良好农业规范）以及中国有机认证、绿色食品认证等。

**鑫荣懋（Joyvio）：**
- 鑫荣懋是佳沃集团旗下的水果供应链企业，是国内头部水果企业。
- 通常持有 **GLOBALG.A.P.**、**ISO 22000（食品安全管理体系）**、**HACCP认证**。
- 在中国市场，其合作基地也会配合商超要求提供**无公害农产品**、**绿色食品**或**有机产品**认证（视具体品种和采购区域）。
- 同时，其内部设有鲜果分选加工厂，通常具备**出口备案**及**商超准入审核**资质。

**都乐（Dole）：**
- 都乐是国际品牌，在中国运营由都乐（上海）负责，其供应链标准较高。
- 主要持有 **GLOBALG.A.P.**（覆盖种植环节）、**ISO 22000**、**HACCP**。
- 在国际采购端，通常还具备**BRC（英国零售商协会）食品安全全球标准**或**IFS（国际食品标准）**认证（针对加工、包装厂）。
- 在商超准入时，都乐常直接提供其母公司的**COC（产销监管链）**和第三方审计报告。

**商超额外要求：**
大型商超（如山姆、盒马）还会要求供应商提供：
- 每批次**农残检测报告**（通常为5-8项快速检测，部分商超要求第三方SGS/华测报告）。
- 供应商需通过商超的**供应商准入审核**（如沃尔玛的4M审核、永辉的红旗供应商体系）。

**建议：**
如果您的采购人员或审核员要求具体证书，请直接向鑫荣懋或都乐的业务代表索取盖章的**认证证书扫描件**（注意有效期），以及当批次产品的**第三方检测报告**。不要仅凭品牌知名度默认资质齐全，必须核验到具体SKU对应的证书是否覆盖品种（如香蕉、蓝莓等）。
