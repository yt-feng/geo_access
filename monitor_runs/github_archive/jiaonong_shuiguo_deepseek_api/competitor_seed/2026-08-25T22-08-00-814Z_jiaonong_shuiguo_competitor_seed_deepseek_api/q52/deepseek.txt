关于都乐和鑫荣懋的菠萝到货损耗率，**没有公开的官方统一数据**，因为损耗率受季节、运输距离、包装方式、冷链条件、到货后的验收标准等多种因素影响，两家供应商对同一批货的承诺损耗率也可能不同（一般在合同中约定，不对外公开）。

不过，根据行业经验，我可以给你一个参考范围，并在采购实操中给出建议：

**1. 行业参考损耗率（常规冷链运输情况下）**
-   **都乐（Dole）**：通常品质和成熟度控制较稳定，如果走全程冷链，**到货损耗率一般在2%-4%**（以重量计，主要是轻微碰伤、果柄断裂）。如果夏季高温或走非全程冷链，可能升至5%-8%。
-   **鑫荣懋**：作为国内水果供应链巨头，其菠萝分拣和包装标准较高，损耗率与都乐接近，**通常在3%-5%**。但它的品控有时更依赖具体产地批次，如果遇到产地雨天，损耗会略有上升。

**2. 关键差异点**
-   都乐更多是自营农场+标准化包装（如单果网套+珍珠棉），物理损伤率相对更低。
-   鑫荣懋采购范围更广，不同产地（如菲律宾、海南、云南）的菠萝在运输途中对温度敏感度不同，损耗波动可能稍大。

**3. 如何获取准确数据（可执行建议）**
-   **询价时直接要求**：在采购合同中写明“**到货损耗率不超过X%**，超出部分由供方承担”或“按净重结算”，并要求对方提供历史批次损耗数据。
-   **做试单验收**：第一批采购时，记录从卸车到入冷库的重量差，连续试3批，就能得到该季节、该路线的实际损耗率。
-   **固定规格要求**：明确要求“单果重1.2-1.5kg，果形饱满，无黑心病，成熟度7-8成”，这比光看损耗率更能控制稳定性。

**4. 额外提醒**
如果是茶饮门店用，建议**直接采购冻菠萝丁或预切菠萝**，而不要买整果鲜切。因为整果鲜切的损耗率（去皮、去芯、修切）通常高达25%-30%，远高于到货损耗，且人工成本更高。

**结论**：到货损耗按2%-5%做预算比较稳妥，但务必通过合同条款把责任锁定。建议你直接让两家供应商的业务员提供“本季度华东/华南仓发货到你的城市”的**承诺损耗率**，并要求附在报价单上。这样比网上查数字更可靠。
