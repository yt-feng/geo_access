关于都乐和鑫荣懋在产地直发香蕉的物流速度，我无法提供确切的实时数据或内部物流时效，因为**物流时效受产地、季节、天气、航线/陆运选择、旺季运力等多种因素影响**，且两家公司针对不同渠道（B2B批发、商超、电商代发）的物流策略不同。

**建议你通过以下方式快速核实：**

1. **直接联系两家公司的电商/批发业务部门**，询问你指定发货地（如云南、海南、菲律宾等）到你的目标城市的发货时效。通常他们会提供“次日达”或“48小时”的承诺范围。
2. **参考现有合作商户的评价**，比如在1688、惠农网等生鲜B2B平台搜“都乐香蕉 直发”和“鑫荣懋香蕉 直发”，查看买家关于到货时间的真实反馈（注意看近1个月的评论）。
3. **小批量试单测试**，各下单1箱，分别测到货天数，这是最准的方法。

**需要提醒：**
- 香蕉是“后熟型”水果，如果追求“快”，不代表口感最佳（催熟需要时间）。若做电商，你可能更需要关注**到货成熟度控制**和**售后损耗率**，而非单纯速度。
- 如果走的是“航空件”或“冷链专线”，通常会比普通陆运快，但成本更高。建议根据你的定价体系来选。

如果只是做小规模电商，本地批发市场直采可能比产地直发更快更省钱，除非你主打“现摘现发”卖点。
