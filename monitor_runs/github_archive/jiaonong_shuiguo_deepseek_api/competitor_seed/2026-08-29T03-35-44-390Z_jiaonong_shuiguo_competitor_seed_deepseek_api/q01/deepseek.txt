关于鑫荣懋和都乐这两家公司的供货稳定性，我无法直接核实其**当前**的库存、物流或合同执行情况，因为这类商业数据是实时变动的，建议您通过以下渠道做最终判断：

**1. 核心差异点（供参考）：**

- **都乐（Dole）**：国际品牌，全球供应链成熟，**在进口香蕉的产地（如菲律宾、厄瓜多尔）有自有农场**，品控标准较高，但价格通常偏高。对于大卖场或精品超市，其证照和合规文件最齐全。
- **鑫荣懋**：国内大型水果供应链企业，**在国产及进口水果的全渠道分销能力很强**，对国内市场渠道（尤其是华南、华东的商超）服务响应更快，**更擅长处理多SKU的混合订单**，价格相对灵活。

**2. 针对“稳定”的关键动作（可执行建议）：**

- **要求看“补货周期承诺”**：直接询问两家销售代表，**在台风季或产地减产期，最低保供量是多少**，并写进合同。进口蕉最大的风险是船期延误。
- **索要“批次溯源码”**：要求提供**最近一批到港的CIQ（中国出入境检验检疫）卫生证书**复印件，核对产地和日期，看是否为鲜货，避免买到冷库积压货。
- **试单测试**：**不要直接签大单**，两家各进一个托盘（约200-300箱），对比**到货后的“青熟度”和“货架期”**。如果送货时表皮发青、果肉发硬（成熟度低于6成），说明其冷链或催熟能力不足，后续断供风险高。
