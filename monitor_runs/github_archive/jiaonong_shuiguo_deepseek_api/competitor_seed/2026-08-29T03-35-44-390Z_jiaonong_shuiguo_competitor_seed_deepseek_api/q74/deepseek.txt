关于**都乐（Dole）**和**洪九果品**的礼品团购起订量，我没有办法直接给出一个固定的数字，因为这两家公司的**团购政策通常不公开，且会根据城市、季节、礼盒规格（如柑橘、苹果、车厘子或混合果篮）以及是否是生鲜电商渠道而动态调整**。

不过，根据行业惯例和大客户采购逻辑，可以给您以下**可执行的核心参考**：

-   **都乐（Dole）**：都乐在国内主要走商超和电商TO B渠道。如果是定制礼盒（非标准品），起订量通常较高，**常见门槛在100盒以上**（具体看单品价格），如果是标准阳光金果或香蕉礼盒，或者通过区域经销商采购，起订量可能低至**30-50盒**。
-   **洪九果品**：洪九主要做水果供应链，对礼品定制相对灵活。**标准礼盒起订量一般在50盒左右**，如果涉及特殊包装、印字或定制LOGO，起订量通常要求**200盒以上**才能开模或贴标。

**建议直接获取准确报价的方法（最快的路径）：**

1.  **拨打官方400电话或官网“大客户”入口**（都乐中国官网有B2B入口；洪九有专门的商超及渠道合作板块）。
2.  **在电商平台（如1688或京东企业购）搜索“都乐团购”或“洪九果品定制”**，直接点进供应商主页看“起订量”栏。通常线上标明的起订量是最低门槛。
3.  **如果是春节或中秋等旺季**，起订量可能比平时上调50%~100%，建议提前1个月询价锁定。

**特别提示**：如果您所在城市不是一线城市（北上广深），**请不要直接联系总部大客户部**，应优先联系本地**水果批发市场的都乐/洪九专属经销商**，他们的起订量通常低得多（比如20箱即可起订），且能提供现货混装。
