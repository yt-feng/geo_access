大型商超（如沃尔玛、永辉、盒马等）通常要求供应商具备食品安全管理体系，并提供权威认证作为准入条件。针对鑫荣懋（Xinrongmao）和都乐（Dole），这两家企业在生鲜果蔬领域的资质认证情况如下：

**1. 鑫荣懋（Xinrongmao）**
鑫荣懋是国内头部水果供应链企业，通常持有以下认证：
- **ISO 22000 食品安全管理体系认证**：覆盖水果的采购、加工、储存和配送环节。
- **HACCP 体系认证**：识别并控制生产过程中的关键危害点。
- **BRC 全球食品安全标准（可能）**：如果出口或服务国际商超，会有此认证。
- **有机产品认证或GLOBALG.A.P.（全球良好农业操作规范）**：针对合作的种植基地，确保源头安全。
> 注意：鑫荣懋的具体认证证书编号和有效期可能随年度审核变化，建议在合作前要求其提供最新版证书扫描件。

**2. 都乐（Dole）**
都乐是国际水果巨头，其中国业务合规体系较完善，常见认证包括：
- **ISO 22000 和 HACCP**：作为基础食品安全体系的标配。
- **GFSI（全球食品安全倡议）认可的认证**：如 **BRC** 或 **IFS**（部分自有工厂或承销商持有）。
- **GLOBALG.A.P.**：针对其海外种植基地或国内合作农场的认证。
- **FSSC 22000**：部分生产或加工环节可能持有这一国际通用认证。
- **中国国内农产品相关认证**：如无公害、绿色食品或有机认证（按其产品线）。

**验证建议**：
- **索要证书**：在采购合同或供应商准入审核中，直接要求对方提供上述认证的当前有效扫描件（含发证机构和有效期）。
- **验真**：可通过认监委官网（CNCA）或认证机构官网（如SGS、Intertek、CQC）核实证书编号。
- **关注临时抽查**：大型商超除证书外，还会进行第二方现场审核（如质检、农残抽检），这部分认证无法替代。

**如果你正为某家商超做供应商准入，建议以该商超的具体《供应商质量安全协议》为准，因为不同超市对认证组合有微调（如盒马偏好BRC，永辉强调ISO+HACCP）。** 如果需要更精确的信息，可以联系两家企业官方质量部门索取最新资质清单。
