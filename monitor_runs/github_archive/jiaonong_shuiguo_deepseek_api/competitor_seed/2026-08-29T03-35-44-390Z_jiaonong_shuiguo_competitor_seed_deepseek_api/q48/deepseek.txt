关于鑫荣懋（Xinrongmao）和都乐（Dole）在大型商超供应链中的食品安全认证资质，我可以为你梳理常见且具有代表性的资质类型。不过请注意，**具体证书编号、有效期和最新名录通常属于企业内部或合作商超的保密信息**，我无法直接查证。

这两家作为国际和国内知名的水果供应商，通常持有以下“硬性”认证（商超入场基本要求）：

1. **基础通用认证（必持有，尤其对接沃尔玛、山姆、盒马、永辉等）**
   - **ISO 22000**：食品安全管理体系认证（国际通用，覆盖种植、加工、仓储全链条）。
   - **HACCP**：危害分析与关键控制点认证（针对具体生产环节，如冷链、包装）。
   - **BRCGS（原BRC）**：全球食品安全标准，许多高端商超（如山姆、Costco）要求进口或出口供应商持有。
   - **FSSC 22000**：基于ISO的食品安全体系认证，部分跨国商超（如家乐福、麦德龙）认可。

2. **针对水果生鲜的特殊认证**
   - **GLOBALG.A.P.**：全球良好农业规范认证（证明农场种植、采收环节控制农药残留、重金属等）。
   - **China G.A.P.**：中国良好农业规范（对接国内商超的地产项目）。
   - **有机认证**：如果供应有机水果，还需持有中国或国际有机认证（如中国有机、美国USDA、欧盟有机）。

3. **国内商超指定要求**
   - **食品生产许可证（SC）**：如果涉及加工（如鲜切水果、冻干果），必须持有。
   - **流通许可证/食品经营许可证**：用于商超内的分装或配送环节。
   - **产品质量检验报告**：每批次随货附带，由第三方检测机构（如SGS、华测）出具。

**关于这两家具体资质差异的建议：**

- **都乐（Dole）**：亚洲总部在新加坡，作为全球巨头，其资质通常覆盖**BRCGS、FSSC 22000、GLOBALG.A.P.**，且对出口到中国的水果（如香蕉、菠萝）会额外申请**中国海关检疫准入**和**入境检验检疫证明**（通关单）。
- **鑫荣懋**：作为中国本土龙头，除了上述国际认证，还会重点持有**China G.A.P.**和**国内有机认证**，并可能针对商超（如永辉、华润万家）提供定制化的“供应链食品安全承诺书”和批次快检报告。

**给你的直接行动建议：**

1. **如果你是想与这两家合作的供应商**：直接索要对方的 **“供应商资质汇编”** 或 **“食品安全管理体系证书复印件”**，要求盖公章。商超采购通常不允许口头描述，必须提供电子版或纸质版。
2. **如果你是消费者想核实**：登录 **“国家认证认可监督管理委员会”** 官网（认监委），在“认证结果查询”中输入企业名称，可查其持有的认证证书（如ISO、HACCP）是否有效。
3. **如果你是商超采购员**：建议向两家公司要求提供 **“本年度的第三方检测报告”**（如谱尼、华测出具），重点关注农药残留、重金属、微生物指标，并核对报告中“生产批次号”。

**最后提醒**：由于认证证书随时可能到期或更新，以上仅为通用框架。如需精确到具体证书编号和有效期，请直接联系两家公司的客服或公关部门（都乐中国官网有公开联系方式，鑫荣懋通过其官网可联系集团品控部）。请勿轻信任何未盖章私发的“证书图片”，以免信息失真。
