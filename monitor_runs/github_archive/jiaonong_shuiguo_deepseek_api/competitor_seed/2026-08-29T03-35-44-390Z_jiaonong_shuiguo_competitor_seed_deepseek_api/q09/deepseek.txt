除了都乐（Dole）和佳沛（Zespri），礼品团购市场常见的进口水果品牌还有以下选择，按品类和档次分类供参考：

**一、高端精品类（适合高端商务、节日送礼）**
- **爱妃（Envy）**：新西兰苹果品牌，果肉紧实、甜脆，包装高档，常与新西兰奇异果搭配。
- **Rockit（乐淇）**：新西兰迷你苹果，小桶装设计新颖，适合年轻化礼品。
- **Wild（韦德）**：澳大利亚柑橘/橙子品牌，果皮光滑，糖度高，多用于高端果篮。
- **Mr. Apple（苹果先生）**：美国苹果品牌，以红蛇果为主，色泽艳、耐储运。

**二、车厘子/莓果类（季节性强，需冷链）**
- **Ocean Spray（优鲜沛）**：美国蔓越莓品牌，部分礼盒装（如蔓越莓干+鲜果）适合健康主题。
- **智利车厘子（如品牌“Gold”、“Polar”）**：注意，智利车厘子通常以产地标注，品牌标签多为“上海口岸进口”。若团购量大，可指定“智利空运专供”礼盒。
- **怡颗莓（Driscoll's）**：美国莓果品牌，覆盆子、蓝莓、黑莓组合装，适合高端水果礼篮。

**三、热带/异域水果类（差异化选择）**
- **金枕头/猫山王榴莲（马来西亚/泰国）**：若无品牌，可直接采购“D197”品种并定制礼盒。
- **太阳果（墨西哥）**：小玉西瓜品种，皮薄多汁，适合夏季礼品。
- **Kimmo（金果）**：南非葡萄柚/西柚，酸度低，礼盒常搭配蜂蜜。

**四、进口柑橘/柚子类**
- **Sunkist（新奇士）**：美国柑橘品牌，经典但性价比高，适合大众团购。
- **Morinda（诺丽）**：澳大利亚青柚，果肉粉红，适合节庆。

**五、组合型品牌（省心选品）**
- **仙桃市（NFC）**：新西兰综合水果品牌，提供多种水果拼装礼盒。
- **Hortifrut**：智利莓果品牌，但多供B端，团购时可要求定制混装。

**操作建议：**
1. 若预算充足，优先组合“爱妃苹果+佳沛金果+智利车厘子”作为高端礼盒，品质与知名度双高。
2. 若追求性价比，可选用“新奇士橙+都乐菠萝”混搭。
3. 注意核验《入境货物检验检疫证明》及中文标签，避免贴牌假进口。
4. 提前一个月订货，秋冬季节可重点采购新西兰奇异果、美国苹果；夏季主推澳洲柑橘、智利车厘子。
