针对您关于香蕉产地溯源和品控证明的需求，我为您分别核实情况如下：

**1. 都乐（Dole）**
- **有产地溯源**：都乐是全球知名水果企业，通常在包装上带有溯源码或二维码，可查询产地（如菲律宾、厄瓜多尔、中国广东/海南等）及种植基地信息。
- **品控证明**：有内部质量认证（如GlobalG.A.P.、ISO等），可以通过包装上的批次信息向供应商索取相关质检报告或第三方检测证书。

**2. 鑫荣懋（Xinrongmao/金果源）**
- **有产地溯源**：鑫荣懋作为国内大型水果供应链企业，其香蕉多来自国内主产区（如云南、广西）或进口自东南亚，通常会建立内部追溯系统，可提供产地、收货批次等信息。
- **品控证明**：有品控体系，能提供第三方检测报告（如农残检测）或出口国官方检疫证明，具体需与对接采购部门确认。

**操作建议：**
- 不要只看口头承诺，要求对方提供**可验证的“批次溯源码”**或**电子追溯二维码**，现场扫码验证。
- 索取**盖章的品控报告**（如SGS农残检测、GlobalG.A.P.证书复印件），并注明报告日期。
- 如果批量采购，建议在合同中明确“产地溯源信息造假”的违约责任条款。

**注意：**
以上信息基于公开行业常识，具体每家供应商的实际溯源范围和证明格式可能不同，请以对方提供的正式文件为准。若需要精确到某个具体生产基地或当前在售批次，建议直接联系当地销售代表索取样品并验证。
