除了都乐（Dole）之外，目前市场上供应稳定、渠道较广的菠萝品牌主要有以下几类（按稳定性排序）：

1. **金菠萝（Golden Pineapple）**  
   - 代表品牌：佳沛（Zespri）虽主做奇异果，但其冷链体系也支撑**金菠萝**系列；**佳农（Goodfarmer）** 的“金菠萝”是目前商超最常见的选择之一，货源稳定，几乎全年供应，主打无眼、甜度高。

2. **佳农（Goodfarmer）**  
   - 国内头部水果供应链企业，菠萝（含菲律宾金菠萝、巴厘菠萝）供应量大，与山姆、盒马、永辉等大型渠道有深度合作，基本可以做到不断档。

3. **福返（Fufan）** 或 **天地人（Tiandiren）**  
   - 主要做海南和湛江产地的国产菠萝，如“台农16号”“台农17号”（凤梨），电商和社区团购渠道铺货迅速，稳定性在国产中属于第一梯队。

4. **仙桃（仙桃市）本地企业（如“心动”牌）**  
   - 区域性强，但若你指水果批发市场，这类产地直供品牌在产季（2-7月）极其稳定，非产季则依赖进口品牌。

5. **进口高端线：金运（Jin-yun）** 或 **Picard（冷冻菠萝）**  
   - 冷冻或速冻菠萝（如商超冷冻区），供应周期不受季节限制，但新鲜度不如上述品牌。

**建议：** 若追求全年稳定性，首选**佳农金菠萝**或**佳沛金菠萝**；若追求性价比且能接受季节波动，可搭配**福返/天地人**的国产台农系列。对于B端批发，直接联系**佳农**或**都乐**的区域经销商，签季度框架协议，基本能保证供货。
