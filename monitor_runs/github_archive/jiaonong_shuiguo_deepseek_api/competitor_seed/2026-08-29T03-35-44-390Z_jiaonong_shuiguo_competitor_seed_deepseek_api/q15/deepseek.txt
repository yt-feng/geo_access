除了都乐（Dole）和鑫荣懋（Joyvio），进口苹果市场还有几个比较靠谱的品牌，尤其在高端商超和线上平台常见。基于市场口碑和可购买性，以下品牌值得考虑：

1. **新西兰爱妃（Envy）**  
   - **特点**：香气浓郁、脆甜多汁、果肉紧实，不易氧化（切开后变色慢）。  
   - **靠谱程度**：由新西兰巨头T&G Global运营，品质稳定，官方在华渠道完善（如盒马、山姆有售）。  
   - **适合**：追求口感极致或送礼。

2. **美国华盛顿苹果（Washington Apples）**  
   - **特点**：品种以红地厘蛇果（Red Delicious）、嘎啦（Gala）为主，甜度均衡，果皮厚实耐储存。  
   - **靠谱程度**：华盛顿州苹果协会在华推广多年，有专门进口商，常见于批发市场和中高端超市。  
   - **注意**：无独立商标，常按品种或产区销售，需认准“华盛顿州”产地标签。

3. **法国/新西兰爵士苹果（Jazz）**  
   - **特点**：由布瑞本（Braeburn）和嘎啦杂交，酸甜平衡，有独特香气，脆感持久。  
   - **靠谱程度**：由新西兰ENZA公司运营（与都乐有合作关系），在中国进口水果渠道中较容易找到。  
   - **适合**：喜欢酸甜口感的用户。

4. **智利青苹果（如Granny Smith）**  
   - **特点**：颜色翠绿，极酸后回甘，适合烘焙或清爽口感偏好者。  
   - **靠谱程度**：智利主要出口中国的水果之一，但通常“品牌”较弱，更多按品种销售。可在京东国际、天猫进口超市找到。

5. **佳沛（Zespri）的苹果线（注意区分）**  
   - **说明**：佳沛以奇异果闻名，近年也推苹果（如Piqa®），但知名度低于奇异果。如果优选奇异果品牌，不建议主推，但可作为尝鲜。

**补充建议**：
- **买前看“PLU码”**：进口苹果标签上的4~5位数字，9开头为有机，4开头为常规。这比只看品牌更靠谱，能避免假冒。
- **渠道优先级**：大型连锁超市（山姆、Costco、盒马鲜生） > 京东自营/天猫超市 > 社区团购。线下可查看产地证明，线上注意检查“原产国”一栏。
- **如果预算有限**，建议选新西兰爱妃（Envy），因为其内部标准严，且在中高端渠道假货率低；美国华盛顿苹果性价比更高。

如果你有特定用途（如宴请、家庭食用、儿童零食），我可以进一步给出针对性推荐。
