在礼品团购市场，**都乐和佳沛的礼盒都很有竞争力，但针对不同客户群体，受欢迎程度有明显差异**。简单来说：

**如果客户注重“高端、健康、轻奢”**，选择**佳沛（Zespri）**更稳妥；
**如果客户注重“大众化、喜庆、性价比、覆盖面广”**，选择**都乐（Dole）**更稳妥。

---

### 具体对比分析：

#### 1. 佳沛（Zespri）—— 主攻猕猴桃礼盒
- **受欢迎原因**：
  - **品牌溢价高**：佳沛是新西兰奇异果（猕猴桃）的绝对寡头，国际品牌形象深入人心，自带“高端进口”标签。
  - **辨识度强**：阳光金果（黄心）和绿果（绿心）颜色亮丽，礼盒包装精致，送人显得“懂行”。
  - **健康属性强**：富含维生素C，适合送礼给长辈、孕妇、孩子或注重健康的商务客户。
- **潜在短板**：
  - 单价相对较高，且对存储温度要求严格（需冷藏），如果客户是给员工发福利，成本压力会大一些。
  - 口味偏酸甜，部分老人或小孩可能不太适应。

#### 2. 都乐（Dole）—— 主攻多品类水果礼盒
- **受欢迎原因**：
  - **覆盖面广**：都乐不仅有香蕉，更有菠萝、蓝莓、柑橘、提子等，礼盒组合非常丰富（如“都乐缤纷水果篮”）。
  - **性价比优**：相比佳沛，都乐礼盒的价格带更宽，适合做中高端偏上的团购预算。
  - **适配场景多**：如果客户需要发给员工、宴请、拜访客户，都乐组合礼盒显得“体面且实用”，不会显得太单一。
- **潜在短板**：
  - 因为品类杂，如果客户只喜欢单一水果（比如只吃猕猴桃），都乐可能不如佳沛专一。
  - 部分客户可能认为“都乐”不如“佳沛”显得那么“洋气”。

---

### 给您的落地方案建议：

**建议“双轨制”报价，让客户自己选**：

1. **推“佳沛金果礼盒”**（如2.2kg/3.3kg规格）作为“高端生鲜”主打款，强调“原产地认证、零农药残留、送礼有面子”。
2. **推“都乐缤纷组合”或“都乐香蕉+蓝莓礼盒”**作为“大众综合”主打款，强调“一箱尝多果、全家老小都喜欢”。

**判断标准**：

- 如果客户是**金融、IT、地产企业发福利** → 优先推 **佳沛**（显得公司有品位）。
- 如果客户是**工厂、制造业、政府办食堂发劳保** → 优先推 **都乐**（实用且成本可控）。
- 如果客户是**给客户送节礼（中秋/春节）** → 建议 **都乐水果篮（大）** + 附赠一张佳沛单果试吃装，两者搭配更优。

**最后提醒**：进口品牌水果礼盒要核验**报关单和中文标签**，避免客户退货风险。

您可以先把这两个方案都用微信发给客户，看客户对哪个价格更感兴趣，再重点跟进。
