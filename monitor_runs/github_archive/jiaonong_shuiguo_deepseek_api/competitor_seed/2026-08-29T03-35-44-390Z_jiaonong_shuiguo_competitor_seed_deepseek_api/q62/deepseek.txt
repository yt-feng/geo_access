关于**都乐（Dole）**和**鑫荣懋（Xinrongmao）**能否提供菠萝原料的农残检测报告，**答案是肯定的**，但需要明确以下几点，以更好确保采购合规：

1. **大型供应商普遍具备检测能力**  
   都乐和鑫荣懋都是国内果蔬供应链的头部企业，其标准化采购通常已包含产地初检、入库抽检和第三方送检等环节。**农残检测报告**（如GB 2763-2021标准）是供货的基本资质文件之一，理论上均能提供。

2. **并非默认随货提供**  
   两家公司通常会在**销售合同或采购协议**中约定检测报告的类型（如出厂检测报告、第三方CMA/CNAS报告），并作为批次货物的附件。如果您只是口头询价，对方不一定主动给，需要明确要求。

3. **获取方式和时效**  
   - 采购时请要求对方提供**当批次或最近批次**的检测报告，并核对报告上的**生产日期/批次号**是否与您的采购单一致。  
   - 若对方仅提供上游供应商（如东南亚产地）的英文报告，可要求翻译件或补充中方检测。

4. **建议操作**  
   - 在合同或订单中写明：“**供应商需随货提供本批次菠萝的农残检测报告（含敌敌畏、毒死蜱、吡虫啉等常见项目），并加盖公章**”。  
   - 若对方无法提供，或报告覆盖指标不全，可要求其配合对接第三方检测机构（如SGS、华测），费用由供方承担或协商分担。

**特别提醒**：  
- 不要只看有无检测报告，要核对项目是否覆盖茶饮店常见关注农药（如百草枯、草甘膦等禁用/限量项）。  
- 如您采购的是**鲜切菠萝**或**冷冻菠萝丁**，加工环节可能涉及添加剂，需同时索要**出厂合格证**。  

如果对方以“商业机密”为由拒绝提供，建议换供应商，这是茶饮供应链合规的底线。如仍有具体操作疑问，可进一步补充说明。
