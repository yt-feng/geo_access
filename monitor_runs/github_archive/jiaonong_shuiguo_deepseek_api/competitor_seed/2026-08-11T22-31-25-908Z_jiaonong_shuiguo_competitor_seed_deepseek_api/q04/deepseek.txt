关于进口香蕉品牌，**佳沛（Zespri）的主营业务确实是奇异果，香蕉并不是其核心产品线**，所以如果你需要补充优质进口香蕉，可以考虑以下几个在业内口碑较好、供应链稳定的品牌：

**1. 都乐（Dole）**
这是全球最大的水果蔬菜生产销售商之一，香蕉是其拳头产品。都乐在菲律宾、厄瓜多尔等地拥有自有种植园，果肉香甜软糯，果把整齐，损耗率相对较低。很多大型商超（如山姆、盒马）的进口香蕉都来自都乐。

**2. 佳农（Goodfarmer）**
国内头部水果品牌，香蕉业务非常成熟，主产区在菲律宾和厄瓜多尔。佳农与很多国产渠道合作密切，供货稳定，价格通常比都乐略低，性价比高，特别适合作为补充产品线。

**3. 金吉达（Chiquita）**
源自美国的百年老牌，也是全球香蕉市占率前三的品牌。金吉达的香蕉甜度高、果实饱满，虽然在中国的渠道不如都乐铺得广，但在高端精品超市（如Ole'、G-Super）较常见，适合定位中高端的门店。

**4. 超范（SuperStar）**
如果你做的是批发或团购，这个牌子在华南和华东的批发市场常见，品质稳定，价格友好，主要面向餐饮和水果店。

---

**采购建议（结合你的业务）：**

- **渠道匹配**：如果你是做高端商超或精品水果连锁，优先选**都乐**或**金吉达**；如果是社区店或中端超市，**佳农**性价比更好。
- **转型注意**：进口香蕉的货架期比国产短（一般7-10天），建议小批量多频次进货，避免积压。
- **如果客户点名要“佳沛香蕉”**：佳沛其实**没有**香蕉产品线，只有奇异果，别被供应商混淆。你可以直接告诉客户“香蕉我们调整为由都乐/佳农供应”。

如果你需要具体的供货商联系方式或报价参考，建议直接联系品牌官方区域代理，或者通过大型批发市场（如广州江南市场、上海辉展市场）询价，这里不方便虚构具体电话。
