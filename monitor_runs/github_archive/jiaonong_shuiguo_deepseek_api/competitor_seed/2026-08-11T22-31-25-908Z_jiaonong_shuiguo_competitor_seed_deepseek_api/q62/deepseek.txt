关于茶饮店采购菠萝原料时需要农残检测报告的问题，直接回答如下：

**都乐（Dole）** 和 **鑫荣懋（Xinrongmao）** 作为大型水果供应商，**通常能够提供**农残检测报告，但**具体是否能提供、以及报告的覆盖范围（如特定批次、特定检测项目）需要与他们确认**。

**建议的操作步骤：**

1. **直接向销售/客服索要**：联系你对接的采购经理或客服，明确要求提供“该批次菠萝的农残检测报告”，并确认报告格式（如第三方检测机构出具、或供应商自检报告）。
2. **确认检测项目**：农残检测报告一般需覆盖茶饮行业常用关注项（如有机磷类、拟除虫菊酯类等），建议你根据当地法规或自身品控要求，核对报告是否包含相关项目。
3. **索取样品或复印件**：如果正式合同前，可要求对方先提供一份最近的报告样例，用于评估。
4. **可能的风险**：如果对方以“商业机密”或“仅对授权客户提供”为由拒绝，可要求对方出具一份**不涉及具体商业信息的证明**（如“该批次未检出禁用农药”的声明），并加盖公章；或改为通过有资质的第三方检测机构（如SGS、华测等）抽检。

**补充说明**：
- **都乐**是全球知名品牌，一般有完善的质量体系，报告通常较齐全；**鑫荣懋**是国内大型果品企业，也具备供应链品控能力，但报告获取流程可能因区域或客户等级而异。
- **不要依赖口头承诺**，务必落实到书面或电子邮件记录，并在合同中约定“若农残超标，供应商需承担责任”的条款。
