关于水果连锁店香蕉分级标准的问题，以下基于公开信息和行业常识进行回答，无法核验具体企业内部文件，请以实际采购条款为准：

1. **都乐（Dole）**：  
   都乐作为国际果蔬巨头，确实有内部严格的香蕉分级标准，但其标准通常不对外完全公开。其分级主要参照国际通行标准（如长度、直径、成熟度、外观瑕疵）并结合销售区域需求制定。公开资料显示，都乐会按“果指长度、弯曲度、表皮损伤程度”等维度分级，但具体数值属于商业机密，采购时通常通过其供货合同或产品规格书确认。

2. **洪九果品**：  
   洪九果品（重庆洪九果品股份有限公司）在香蕉业务上有自己的采购和品控体系，其标准多见于其招股书或官方宣传中提及 “分拣分级、色泽、成熟度”等，但同样没有公开的量化分级文件。其运营模式强调产地直采和标准化分选，但具体分级阈值需咨询其销售团队。

**行业通用建议**：  
如果贵连锁店需要制定香蕉分级标准，建议参考以下公开框架（非特定企业标准）：
- **长度分级**：常见商业等级为“大果”（≥19cm）、“中果”（16-19cm）、“小果”（<16cm），但不同市场有差异。
- **外观要求**：无严重压伤、黑斑、果柄断裂，弯曲度自然，允许轻微花皮（花皮面积≤10%）。
- **成熟度指标**：按果皮颜色分为青熟、黄熟、黄带绿等，运输和销售阶段要求不同。
- **重量/梳数**：按整梳净重或每箱数量分等。

**建议操作**：
- 直接联系都乐、洪九的采购负责人，索取其《产品规格书》或《验收标准》（通常供应商愿意提供给客户）。
- 若是自有品牌，可参照国家标准GB/T 25037-2010《香蕉 购销等级》或行业标准SB/T 10894-2012（如有），结合本地消费者偏好细化。
- 对供应商进行验厂时，可以要求其提供内部质检记录作为参考。
