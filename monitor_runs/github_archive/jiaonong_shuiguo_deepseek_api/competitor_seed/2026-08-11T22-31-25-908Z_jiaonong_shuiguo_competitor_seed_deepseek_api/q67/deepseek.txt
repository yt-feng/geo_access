关于生鲜电商与菠萝品牌营销，具体情况如下：

1. **都乐（Dole）**：都乐是全球知名的水果品牌，在菠萝品类上有成熟的品牌体系和营销素材（如产品图片、宣传视频、营养资料、品牌授权等）。生鲜电商若与其合作，通常可通过官方渠道（商务合作、市场部）申请品牌素材，或通过其官方授权的经销商获取。合作形式一般包括联合营销、买赠活动、品牌专区等。

2. **洪九果品**：洪九是国内大型水果供应链企业，主要业务偏向B端批发和分销，其品牌营销素材（尤其是面向终端消费者的）相对较少，但可提供产品规格、产地信息、质量认证等基础资料。若电商平台希望做产地溯源或品质背书，洪九可配合提供。

**建议行动路径**：
- **直接联系**：拨打都乐或洪九的官方客服电话，或在其官网找到“商务合作”入口，说明是生鲜电商平台，提出品牌素材授权及联合营销需求。
- **平台采购渠道**：如果你是通过批发市场或供应商拿货，可让供应商转达需求，或由你方平台采购部门对接其区域销售负责人。
- **素材使用注意**：商标、图片、视频等需获得书面授权，避免侵权风险。若仅用于平台内部展示（非公开广告），也建议先确认使用范围。

总结：都乐通常更愿意提供完整品牌素材（因其重视C端品牌形象），洪九则更多提供产品相关信息，两者都可通过商务渠道对接。如果联系不上，可尝试通过生鲜展会或行业对接平台寻找其营销负责人。
