关于洪九果品和鑫荣懋的香蕉批发价，我无法实时获取市场报价，且价格会因产地、品种（如国产/进口）、季节、批发市场（如江南市场、嘉兴市场）和拿货量浮动。**建议通过以下方式比较：**

1. **直接询价**：联系两家公司当地的销售代表或拨打客服电话，要求按“单箱净重、规格（如36支/42支）、熟度”报价，并明确“整车价”和“散货价”。
2. **对比规格**：同等级（如一级、二级）的香蕉才有可比性，洪九在国产蕉（如云南蕉）流通上常见优势，鑫荣懋在进口蕉（如菲律宾、厄瓜多尔）供应链上更成熟，问清产地即可判断。
3. **关注损耗率**：批发价低但生熟度不均匀可能导致损耗高，综合核算成本（单价+损耗+退换政策）而非只看裸价。
4. **参考行情平台**：水果批发市场内的电子大屏幕（如广州江南市场）或“全国农产品商务信息公共服务平台”，可查询每日参考价，但需注意是“参考价”而非成交价。

**具体操作**：直接给两家销售打电话，要求按同规格报价，并询问对大批量（如100箱以上）的阶梯优惠。提醒：网络上流传的“底价”多为营销话术，务必以书面报价为准。如果拿货量小（10箱以内），建议直接去档口谈，洪九和鑫荣懋的批发档口有时对散客报价高于市场价，可以多问几家周边档口对比。
