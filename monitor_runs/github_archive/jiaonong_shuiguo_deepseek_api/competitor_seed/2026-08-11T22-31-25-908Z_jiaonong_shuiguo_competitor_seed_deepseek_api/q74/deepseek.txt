关于都乐（Dole）和洪九果品的水果礼盒定制起订量，由于这两家公司主要面向B端（商超、批发市场、企业采购），且起订量会根据**礼盒规格、水果品类、定制包装复杂度（如印logo、特殊礼盒）**以及**当年采购淡旺季**有所不同，无法给出固定数字。

但根据行业惯例，给你以下**可操作建议**：

**1. 行业普遍门槛参考（非官方，但常见）**
- **都乐（Dole）**：主要做高端香蕉、菠萝、牛油果等，如果是标准礼盒（如香蕉装），起订量通常在 **50-100箱** 左右；如果是特殊定制（如混装车厘子、定制腰封/彩盒），起订量可能需要 **200-500箱** 起。
- **洪九果品**：主打榴莲、火龙果、进口提子等，走量较大。如果是常规单品礼盒，起订量一般在 **100箱** 上下；定制Logo或混装礼盒，通常在 **500箱** 左右起（因为他们更倾向批发分销渠道）。

**2. 建议的获取方式（更靠谱）**
- **直接联系当地经销商/销售经理**：都乐在中国各区域有代理，洪九有分公司。在官网“联系我们”或拨打400电话，说明“礼品团购，需定制水果礼盒”，销售会按你的具体需求（如**总采购量、单盒预算、是否需要贴标/烫金**）给出明确起订量。这比网上搜索任何模糊数字都准确。
- **如果量小（如100盒以内）**：不建议直接对接厂家，建议通过**当地水果批发市场的头部档口**或**京东企业购/美菜网**等中间商拼单，他们通常可接受50盒起做，且起订门槛更低。

**3. 提醒风险**
- 起订量不是唯一成本，**定制版费和包装费**（通常几百到几千元）可能另收。
- 水果是期货属性，价格波动大，起订价通常按**提货日当天行情**锁定。
