关于**洪九果品**和**都乐（Dole）**的香蕉在批发市场的到货损耗率，目前没有一个公开的、统一的官方统计数字。因为损耗率受**运输距离、包装方式、季节温度、批发市场管理水平**以及**具体批次**影响极大。

不过，基于行业常识和水果批发市场的普遍经验，可以给出以下**对比参考和判断维度**：

**1. 品牌定位与包装标准（核心差异）**

-   **都乐（Dole）**：作为国际品牌，其香蕉通常有成熟度分级标准（色卡）、标准化的纸箱+薄膜包装，且多采用冷链运输。在**源头品质控制和包装标准化**上更严格，磕碰伤和压伤通常更少，到货的“外观损耗”（黑斑、压烂）通常较低。
-   **洪九果品**：作为国内头部进口+分销商，其水果主要走量，主打性价比。其香蕉包装规格和冷链程度可能根据不同采购渠道（如不同产地如菲律宾、厄瓜多尔）有差异，**批量大、周转快**，但标准化程度和保鲜精细度通常略逊于国际品牌。

**2. 粗略的经验损耗率参考（供谈判和预算用）**

-   **都乐**：如果走**全程冷链**且批发市场管理水平正常，到货后的**“霉变/严重软烂”损耗率**通常在 **1% - 3%** 之间。若市场行情不好、堆放时间过长，可能上升至5%左右。
-   **洪九**：由于出货量大、流通速度快，且部分非高端线可能采用常温车运输，到货时出现**表皮擦伤、个别断裂、柄部腐烂**的情况会略多。如果非指定高标准控温，**“严重损耗”通常在3% - 5%**，加上当天卖不完的后续损耗，可能达到5% - 8%。

**3. 关键区别：损耗类型**

-   **都乐损耗少但贵**：它的优势在于**货架期长**，只要到手没坏，能多卖1-2天，这能抵消部分价格差。
-   **洪九损耗略高但便宜**：它的优势是**采购价低**，如果周转快（比如一天内清完），即使损耗多点，利润也可能更优。

**4. 实操建议（如何精确判断）**

由于没有固定比率，你在拿货时建议做以下动作：

1.  **现场开箱抽检**：批发市场拿货时，**务必随机抽2-3箱**（分别抽箱底和箱顶），现场按重量和外观估算“可售率”。
2.  **询问到货时间**：问档口老板“这批货是几天前到港/到库的？” 存放时间超过3天的都乐，损耗率也会上升；洪九则要问“冷链还是常温”过来的。
3.  **关注“级差”**：通常批发市场报价中，**“原箱损耗”**（即正常情况下挑出的烂果）占比例，档口老板心里有数，你可以直接问：“这批货拿回去一般能挑出几个烂的？” 一般他们给的回答就是真实损耗参考。

**总结结论：**
在同等批发市场、当天到家的情况下，**都乐的到货损耗率通常显著低于洪九**（可能低2-4个百分点），但单价更高。**洪九赢在采购成本低**，适合**快进快出**的摊位；如果你做的是对鲜度要求高的高端社区店，**都乐更稳妥**。

最终建议：拿货前分别拿洪九的便宜货和都乐的贵货**各进一小批试卖**，根据你那边的实际销售速度（比如一天卖完 vs 两天卖完）来定夺哪个更划算，因为损耗率最终由“到你店里的销售周期”决定。
