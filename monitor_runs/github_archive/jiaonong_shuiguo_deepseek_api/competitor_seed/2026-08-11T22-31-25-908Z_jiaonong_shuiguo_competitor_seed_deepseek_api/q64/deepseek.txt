不过，我可以给出基于公开行业信息的**常规覆盖范围判断**，供你参考：

1.  **鑫荣懋**：作为国内头部水果供应链企业，其冷链物流网络通常覆盖**全国主要一二线城市及重点省会城市**，尤其在其核心水果产区（如华南、华东、西南）和重点销售区域（北上广深、成都、武汉、西安等）配送能力较强。其服务对象多为全国性大型商超（如永辉、盒马等），因此其配送网络多为“干线+城配”模式，覆盖**直辖市、副省级城市及经济发达地级市**概率较高。

2.  **都乐（Dole）**：作为国际品牌，在中国主要依托第三方冷链物流或与大型商超共建配送体系。其配送网络通常集中在**沿海及一线城市**（如上海、北京、广州、深圳、杭州、南京、厦门等），以及其进口水果主要港口城市（如上海、广州、天津、大连）周边区域。对于内陆三四线城市，可能依赖经销商的二次配送。
