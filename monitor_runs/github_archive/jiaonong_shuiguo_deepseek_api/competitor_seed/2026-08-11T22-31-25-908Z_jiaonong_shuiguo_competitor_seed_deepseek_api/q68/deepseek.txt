关于“香蕉到货损耗率低于3%”这一指标，**都乐和鑫荣懋作为国内头部香蕉供应链企业，通常情况下可以做到，但这取决于具体的合作模式、配送距离、验收标准和季节。**

**核心结论：**
- **能做到**：对于标准规格（如整箱、特定成熟度）的香蕉，在稳定的冷链运输和短途配送（如产地到区域仓）下，这两家头部企业的到货损耗率通常可以控制在2%-3%之间，甚至更低（1%左右）。
- **有前提**：如果要求“全程到门店”而非“到中央仓”，或采购非常规成熟度（如极青蕉）进行催熟，损耗率会显著上升，3%的承诺难以保证。

---

**关键影响因素（请对照您的合同条款）：**

1. **验收节点定义**  
   - 如果损耗率是指在**收货方仓库**开箱验收时，剔除腐烂、严重压伤后的批次损耗，这两家能做到。  
   - 如果是指**门店上架后**（经历再次搬运、顾客翻动）的损耗，则超出供应商可控范围，3%几乎不可能。

2. **成熟度等级**  
   - 都乐和鑫荣懋通常供应“绿熟”或“半熟”果（需催熟房处理），到货时果皮完整、无黑斑，损耗低。  
   - 若采购高成熟度（可直接售卖）的香蕉，运输中极易碰撞发黑，损耗大概率突破3%。

3. **配送距离与季节**  
   - 冷链车控温（13-15℃）且配送半径在500公里内，损耗可控。  
   - 夏季高温或多雨季节，若中途多次卸货、周转，损耗会显著增加，供应商一般会在合同中免责。

4. **包装与托盘标准**  
   - 头部供应商采用标准纸箱+双层珍珠棉隔层，抗压能力强。若您要求额外加固或改托盘化运输，损耗会更低，但单价会上浮。

---

**建议执行动作：**

1. **合同明确验收标准**：写明“到仓验收损耗率≤3%”，并约定**损耗剔除方式**（按箱重/按根数计数），避免后期扯皮。  
2. **要求提供分拣数据**：让供应商提供每批次到货的“自然损耗+机械伤损耗”分析表，作为评价依据。  
3. **小批量试单验证**：先按您实际配送路径发1-2车试货，实测到货损耗，再签订长期框架协议。  
4. **备选方案**：若您门店分散且配送距离超过800公里，可考虑与供应商协商**到仓净重结算**，损耗风险由您自担部分，价格上争取优惠。

---

**补充说明**：  
- 都乐（Dole）和鑫荣懋在中国主要做基地直采和催熟配送，对损耗控制有成熟SOP；但**没有任何供应商会书面承诺“门店端损耗低于3%”**，因为这涉及零售环节的人为损耗。  
- 如果您需要更精确的报价或试单方案，建议直接联系两家公司的餐饮大客户部，提供您的城市和月均用量，他们会给出可行性评估。
