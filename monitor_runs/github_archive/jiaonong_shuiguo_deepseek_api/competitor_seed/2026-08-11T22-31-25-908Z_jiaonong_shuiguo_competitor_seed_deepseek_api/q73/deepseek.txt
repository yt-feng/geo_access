对于大型商超（如沃尔玛、山姆、永辉等）的供应商，食品安全管理体系认证是硬性准入门槛。鑫荣懋（XinRongMao）和都乐（Dole）作为国内头部水果供应链企业，通常持有以下国际及国内主流认证，但具体证书版本和覆盖范围以采购方最新验厂报告为准，建议在合作时要求对方提供有效证书扫描件。

以下是这两类企业普遍具备且商超最看重的认证：

**1. 核心食品安全管理体系认证（必查项）**

-   **ISO 22000（食品安全管理体系）**：最基础的全球性认证，涵盖从农田到餐桌的全链条。
-   **HACCP（危害分析与关键控制点）**：针对生产/加工环节的预防性体系，几乎所有生鲜供应商必备。
-   **GLOBALG.A.P.（全球良好农业规范）**：针对农业种植端，证明其种植、采摘、农药残留控制符合国际标准。鑫荣懋和都乐在自有或核心合作基地通常持有此证。

**2. 行业专属及出口资质认证（加分项）**

-   **BRCGS（原BRC全球标准）**：英国零售协会标准，是进入欧洲及高端商超（如山姆、Costco）的重要门槛。大型供应商通常持有此证。
-   **IFS Food（国际食品标准）**：法国和德国零售协会制定，与BRC齐名，通常二选一或均有。
-   **自有基地/加工厂认证**：可能还有有机产品认证（如中国有机、美国USDA有机）、良好农业操作规范（CHINAGAP）等。

**3. 特别针对进口水果的认证**

-   **检疫类证书**：如植物检疫证书（国家海关出具），这个是临时性的，但属于必要文件。
-   **国际供应链安全**：可能涉及AEO（海关高级认证）或TAPA（运输资产保护协会）认证（针对物流环节）。
