除了都乐（Dole）之外，目前在中国市场能做到**稳定供应（尤其是全年供应或季中不断供）**的菠萝品牌和供应商，主要分为以下几类。请注意，以下建议基于市场常见情况，具体供货稳定性会受季节、进口政策影响，建议直接联系品牌区域代理或批发市场确认，我无法捏造具体库存数据。

**1. 高端进口/全年供货品牌（以菲律宾、哥斯达黎加、泰国为主）**

- **金菠萝（MD-2品种）**：这是目前最主流的稳定供应品种，果眼浅、甜度高。
- **佳沛（Zespri）**：虽然是猕猴桃巨头，但旗下也有菠萝线，主要通过新西兰和东南亚采购，供应稳定但价格较高。
- **新奇士（Sunkist）**：美国品牌，在中国主要供应橙类，但菠萝（多来自哥斯达黎加）也是其业务线，适合对品牌知名度有要求的渠道。
- **Fresh Del Monte（德尔蒙）**：全球果蔬巨头，与都乐并列，在菲律宾和哥斯达黎加有大型种植基地，供应期长，终端零售常见。

**2. 国内产地稳定品牌（产量大、价格亲民、季节性强）**

- **神湾菠萝（广东中山）**：小果型，香气浓，但产量有限，主要供应当地高端水果店，不适合大渠道全年供货。
- **徐闻菠萝（广东湛江）**：全国最大的菠萝产区，有“中国菠萝之乡”之称。虽然季节性明显（春季集中上市），但近年有深加工和冷库延贮，**能稳定供应3-8个月**，品牌如“徐闻菠萝”地理标志产品，或当地龙头企业（如湛江农垦集团）。
- **四季菠萝（云南西双版纳、海南）**：海南和西双版纳有大棚或反季节种植，可实现**有限全年供应**，代表有“海南金钻菠萝”或“香水菠萝”。

**3. 整颗果或即食果切品牌（供应链解决方案商）**

- **百果园、鲜丰水果**：不是自有品牌，但作为渠道商有稳定合作的产地基地，适合你“渠道拿货”的需求。
- **盒马、叮咚等生鲜电商**：有自有品牌（如盒马“日日鲜”菠萝），供应链稳定，但仅限其自有平台售卖。

**4. 建议的供应链备选策略**

- **春秋季优先选**：菲律宾进口“金菠萝”（如德尔蒙或金果源品牌）。
- **夏季优先选**：海南/广西本地菠萝（如“海阳”或“徐闻金菠萝”）。
- **冬季优先选**：哥斯达黎加或厄瓜多尔进口菠萝（供应期长于泰国）。

**怎么验证“稳定供应”？**
建议直接到当地最大批发市场（如广州江南市场、嘉兴水果市场）向档口询问“有哪几家常驻菠萝货”，同时要求对方提供**海关进口检疫单（进口果）**或**产地溯源二维码（国产果）**。不要依赖单一品牌，备两到三个品牌轮流补货最稳妥。
