目前没有可核验的公开信息能确认都乐（Dole）和洪九果品针对菠萝的“锁价周期”具体多长。这类锁价安排通常属于**一客一议的商务合同条款**，不对外统一公布，且会随品类（鲜菠萝/菠萝制品）、规格、采购量、季节、产地、交付方式和合同期限变化。

可以给出的判断和建议如下：

1. **都乐**
   - 都乐在中国市场更多以品牌鲜果、商超供应、餐饮供应链等形式出现。
   - 是否提供锁价、锁价多久，通常要看具体采购主体、区域经销商或直供合同。
   - 公开渠道一般查不到统一“菠萝锁价周期”。

2. **洪九果品**
   - 洪九果品做水果供应链和批发分销，菠萝是其可能涉及的品类之一。
   - 锁价机制更可能体现在年度/季度框架协议、单品采购合同或大客户定制条款中。
   - 公开信息同样难以确认固定锁价周期。

3. **行业常见做法**
   - 鲜果锁价周期常见为：**1周、2周、1个月、1个季度**，少数大客户可谈**半年或年度框架+定期调价**。
   - 菠萝受产季、产地天气、运输成本、汇率和市场需求影响大，供应商通常不愿长期固定价格。
   - 更常见的是：**短期锁价 + 浮动调整机制**，例如设定基准价、涨跌触发幅度、月度复盘。

4. **建议你直接这样问供应商**
   - 是否支持锁价？锁价适用于鲜果还是加工果？
   - 锁价周期最短/最长分别是多少？
   - 锁价是否含运费、关税、包装、损耗？
   - 超量或减量时价格怎么调整？
   - 原料涨价超过多少比例可以调价？
   - 锁价是否要预付、保证金或最低采购量？
   - 报价对应哪个产地、规格、等级和交付地？

5. **更稳妥的询价路径**
   - 找都乐中国区官方渠道或其大型经销商；
   - 找洪九果品对应区域销售/供应链负责人；
   - 同时询价3—5家产地供应商或一级批发商做对比；
   - 要求书面报价单和合同条款，不要只依赖口头承诺。
