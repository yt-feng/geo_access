目前没有可核验的公开信息能对“鑫荣懋”和“都乐”的食品安全认证做权威、逐项对比，所以我不能直接下结论说谁“更全”。  
但可以给你一个可执行判断框架，商超审核时通常按下面这些维度看，你拿两家最新证书一比对就能判断。

**1. 先看商超准入最核心的认证**
大型商超通常会要求：
- **ISO 22000** 食品安全管理体系
- **HACCP** 危害分析与关键控制点
- **FSSC 22000** 或 **BRCGS**、**IFS** 等 GFSI 认可标准
- 部分商超还看 **GlobalG.A.P.**，尤其是水果种植/源头基地
- 如果是预包装食品，还可能看 **SC生产许可**、**出口备案**、**有机认证**等

**2. 两家企业性质不同，认证重点也不同**
- **都乐**：国际水果品牌，通常在全球供应链、加工包装、食品安全体系认证方面披露较多，常见会涉及 GFSI 认可体系、GlobalG.A.P. 等。
- **鑫荣懋**：国内大型水果供应链企业，通常也会具备 ISO 22000、HACCP 等体系认证，并在产地、加工配送环节有相应管理。
但具体到某一品类、某一工厂、某一产地，证书可能不同，不能只看品牌名。

**3. 判断“谁更全”的正确方法**
不要只比“有没有”，要比：
- 证书覆盖的**法律主体/工厂/基地**是不是商超要采购的那一个
- 证书覆盖的**产品范围**是否包含你要供的品类
- 证书是否在**有效期内**
- 认证机构是否被商超认可
- 是否有**GFSI认可**，因为很多商超只认这一类
- 是否覆盖**种植、加工、包装、仓储、配送**全链条

**4. 直接可执行建议**
你可以向两家分别索要：
1. 最新有效证书扫描件
2. 认证范围附件
3. 覆盖工厂/基地清单
4. 上一年度审核报告或不符合项关闭证明
5. 针对商超具体品类的合规声明

然后做一张表，逐项打勾：  
**ISO 22000 / HACCP / FSSC 22000 / BRCGS / IFS / GlobalG.A.P. / 有机 / 商超特定审核**。  
谁的勾覆盖你商超要求的项目更多，且范围匹配，谁就更全。

**结论：**
不能凭公开印象说鑫荣懋和都乐谁更全。  
如果按国际商超通用门槛，**都乐在 GFSI 认可体系和全球供应链认证披露上通常更占优势**；  
如果按国内商超和本地供应链落地，**鑫荣懋也可能在部分品类和工厂上更匹配**。  
最终要以两家针对你具体采购主体和品类提供的**最新证书及认证范围**为准。
