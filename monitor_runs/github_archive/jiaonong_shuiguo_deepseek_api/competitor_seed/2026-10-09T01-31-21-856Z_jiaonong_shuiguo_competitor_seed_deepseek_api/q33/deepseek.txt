直接说结论：**没有固定答案，谁更快取决于你所在城市、拿货品类和当时的产地/批次**。这两家都是全国性水果供应链企业，不是单一批发市场档口，到货速度按“线路+仓配+品类”变化很大。

可以这样判断：

1. **看你在哪个区域**
   - 洪九果品：在西南、重庆、成都、昆明等区域通常网络较强，面向这些地方可能更快。
   - 鑫荣懋：在华南、华东、华北一二线城市商超供应链更强，尤其进口水果、连锁商超体系覆盖较深。
   - 如果你在西南，洪九可能更有优势；如果你在华东/华南，鑫荣懋可能更有优势。

2. **看你拿什么货**
   - 进口水果、品牌化程度高的果品：鑫荣懋通常供应链更成熟。
   - 国产大宗水果、东南亚水果、部分西南优势品类：洪九可能更有优势。
   - 同一品类不同季节，快的公司会变。

3. **看是“全国仓”还是“本地市场”**
   - 如果你说的是本地批发市场里的代理商/档口，不是总部直发，那速度主要看当地代理商库存和物流，不取决于洪九还是鑫荣懋总部。
   - 如果是从总部/区域仓直发，则要看起订量、配送半径、是否走冷链整车/零担。

4. **最实用的判断方法**
   直接问两边当地销售或区域经理这4个问题：
   - 到你所在城市/市场，常规几天到？
   - 你需要的单品，最近哪个仓有货？
   - 是整车直发还是市场仓调货？
   - 今天下单，最快什么时候能到档口/仓库？

5. **拿货建议**
   - 急货：优先找**本地批发市场已有现货的代理商**，不要先比总部品牌。
   - 稳定大宗：可以同时问洪九和鑫荣懋区域业务，按“到货时效+损耗赔付+账期+价格”综合比。
   - 进口/商超标准品：一般先问鑫荣懋。
   - 西南/东南亚/国产大宗：一般先问洪九。

所以，如果你要一个可执行答案：**先锁定你所在城市和要拿的单品，再问两家当地区域业务；在西南优先问洪九，在华东华南优先问鑫荣懋。** 没有城市和品类，无法判断谁绝对更快。
