都乐和鑫荣懋都属于国内香蕉供应链里比较头部、品控相对成熟的玩家，但**“到货损耗率低于3%”能不能做到，不能只按品牌名字判断**，关键要看：**采购规格、运输方式、到货验收标准、门店接货后的处理、以及你定义的损耗口径**。

直接说结论：

1. **如果“到货损耗率”只看外箱到店验收环节的黑斑、断指、压伤、烂果、重量短少等，且全程冷链、整箱周转、成熟度控制得当，都乐和鑫荣懋都有能力做到接近或低于3%。**
2. **如果“损耗率”包含门店催熟后报废、发黑、软烂、切果损耗、当日未售完丢弃，那低于3%非常难，任何品牌都不能单方面保证。**
3. **如果是常温车、多次中转、门店乱堆乱放、验收标准宽松，3%以内基本不现实。**

具体判断方式如下：

| 判断维度 | 能做到低于3%的条件 | 很难低于3%的情况 |
|---|---|---|
| 采购成熟度 | 青蕉或微黄，按门店催熟计划到货 | 到货已熟、黄蕉、 ready-to-eat |
| 运输 | 全程冷链或控温车，少中转 | 常温车、多级批发、反复装卸 |
| 包装 | 整箱、气调/保鲜包装、托盘化 | 散装、纸箱软、堆压严重 |
| 验收口径 | 只算到货可见坏果/压伤/短重 | 算催熟后报废、门店损耗 |
| 门店处理 | 有催熟房、先进先出、温湿度管理 | 后厨常温堆放、挤压、不及时处理 |
| 采购量 | 稳定大批量、单店周转快 | 小批量、多频次、长距离配送 |

都乐的优势通常在**标准化、品牌品控、商超和连锁餐饮经验**；鑫荣懋的优势通常在**国内水果供应链覆盖、渠道和成本控制**。但香蕉是后熟型水果，损耗高度依赖**到店后的成熟度管理和周转速度**，不是签了品牌就自动低于3%。

如果你要和供应商谈，建议直接这样约束：

1. **明确损耗定义**  
   写清楚：是到货验收损耗，还是包含催熟后、货架期、门店报废的综合损耗。  
   建议拆成：
   - 到货验收损耗率 ≤3%
   - 到货后24小时坏果率 ≤1%
   - 催熟后可用率 ≥97%

2. **明确验收标准**  
   例如：
   - 青蕉到货，成熟度按约定色卡；
   - 单箱断指、压伤、发黑、烂果超过约定比例即扣款；
   - 到货中心温度、品温有记录；
   - 箱重、净重、支数抽检。

3. **要求试配和分阶段承诺**  
   先跑1-2条线路、3-5家门店、2-4周，按实际数据谈。  
   不要一上来让供应商承诺全国全门店低于3%，对方通常不会接。

4. **把赔付写进合同**  
   例如：
   - 到货验收损耗＞3%，超出部分按货值扣款或补货；
   - 连续两周超标，调整线路或更换供应商；
   - 因成熟度不符导致的门店报废，按约定比例承担。

5. **门店端也要配合**  
   香蕉低于3%到货损耗，门店必须做到：
   - 到货立即开箱散热；
   - 按成熟度分库/分区；
   - 先进先出；
   - 催熟房温湿度记录；
   - 不挤压、不常温过夜。

所以，**都乐和鑫荣懋在合适条件下可以做到到货损耗低于3%，但不能简单回答“能”或“不能”**。  
更准确的说法是：**头部供应商有能力在明确标准、冷链、稳定量和门店配合下做到；如果只靠品牌背书、没有验收和赔付条款，3%不能保证。**
