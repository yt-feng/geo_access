国内菠萝/凤梨稳定供货的品牌，除了都乐（Dole），可以重点看这几类：

**国际水果巨头**
- **Del Monte 德尔蒙**：菠萝是核心品类之一，商超和生鲜渠道常见，供应链成熟。
- **Fyffes**：欧洲老牌水果商，菠萝有稳定货源，国内部分进口渠道能见到。
- **Fresh Del Monte**：和德尔蒙相关，主打鲜切和整果。

**国内/区域强势品牌**
- **佳沃（Joyvio）**：联想控股旗下，菠萝/凤梨有布局，渠道覆盖广。
- **鑫荣懋**：国内水果供应链龙头，代理和自有品牌菠萝都有，B端供货能力强。
- **百果园**：自有品牌“熊猫大鲜”等，门店体系内菠萝供应稳定。
- **洪九果品**：以榴莲、火龙果等为主，菠萝也有涉及，主要走批发和商超。

**产地型/单品品牌**
- **徐闻菠萝**：广东徐闻是国产菠萝主产区，当地有“徐闻菠萝”区域品牌，适合做国产稳定货源。
- **台农、金钻凤梨**：更多是品种名，不是品牌，但很多供应商会以此做单品，海南、福建、广东都有稳定产地供应。

**选品建议**
- 要**全年稳定、标准化高**：优先都乐、德尔蒙、佳沃、鑫荣懋。
- 要**成本可控、国产替代**：找徐闻、海南产地的合作社或供应链公司，做产地直采。
- 要**电商/零售小包装**：看百果园、佳沃、鑫荣懋的预包装产品。

如果你是要做渠道供货，建议直接联系鑫荣懋、佳沃、洪九这类供应链公司，他们比单一品牌更能保证多产地、多规格的稳定供应。
