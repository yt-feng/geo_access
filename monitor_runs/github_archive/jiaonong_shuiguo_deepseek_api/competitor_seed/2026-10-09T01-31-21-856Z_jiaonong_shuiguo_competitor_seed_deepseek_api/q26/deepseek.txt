没法直接说谁“更靠谱”——品质稳不稳定，关键不在品牌本身，而在你具体采购的**品种、等级、成熟度、到货批次和供应链条件**。都乐和鑫荣懋体量都大、供应链能力都不弱，但茶饮店做果酱的逻辑和买鲜果吃是两回事。

给你几个可判断的维度：

**1. 先明确你要的是什么**
- 做果酱通常需要**糖酸比稳定、出汁/出肉率稳定、香气稳定**，对“甜不甜”“香不香”反而不是唯一标准。
- 都乐强在品牌标准化和终端渠道覆盖，鑫荣懋强在国内水果供应链和产地资源，两者都可能给你合适或翻车的货，取决于你订的规格。

**2. 关键看合同里能不能锁这些**
- **品种**：菠萝品种不同，酸度和香气差异大，菲莉欣、金钻、普通巴厘等做酱表现不一样。
- **成熟度/糖度**：要求供应商给每批的糖度范围（比如可溶性固形物≥某值）和酸度范围。
- **规格等级**：鲜果还是冷冻果肉/果泥/浓缩汁？做稳定品质的果酱，**冷冻果肉或标准化果泥往往比鲜果更稳**。
- **批次一致性**：要求提供近3-5批的检测数据，看波动大不大。

**3. 实操建议**
- **不要只看品牌**：先让两家各寄**同规格样品**，你做小试，测出肉率、糖度、酸度、香气、褐变情况。
- **优先谈冷冻/加工专用原料**：如果都乐或鑫荣懋能供**冷冻菠萝果肉、果泥、果酱半成品**，稳定性通常优于鲜果。
- **小批量试产**：同一配方做3批，看颜色、口感、出酱率是否一致，再决定。
- **合同锁指标**：糖度、酸度、成熟度、异物控制、农残、可追溯批次，写进验收标准。
- **备份供应商**：茶饮店最怕断供或批次漂移，最好主供+备供，别把稳定性押在一家品牌上。

**结论**：  
都乐和鑫荣懋都可以谈，但“谁更靠谱”取决于你买的是**鲜果还是加工原料**、**有没有锁规格和检测指标**、**到货批次稳不稳**。如果你要的是做果酱的稳定品质，优先找能提供**标准化冷冻果肉/果泥**并愿意签质量指标的那家，而不是单纯比品牌。
