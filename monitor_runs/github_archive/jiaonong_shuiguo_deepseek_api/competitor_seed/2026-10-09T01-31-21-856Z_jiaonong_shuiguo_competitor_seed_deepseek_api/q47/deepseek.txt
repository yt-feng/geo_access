都乐和洪九果品这类水果供应链企业通常可以谈定制包装，但“是否有现成的便利店香蕉小包装定制服务”要看合作模式和起订量，不能一概而论。可以按下面方式判断和推进：

**1. 都乐**
- 都乐有面向零售/便利店渠道的预包装香蕉产品，比如按根、按份、小把装等规格。
- 是否能做便利店专属定制包装（印便利店LOGO、指定规格、指定克重/根数），一般属于**大客户定制或渠道专供**，需要联系都乐当地销售/经销商，通常有起订量要求。
- 如果只是采购现有小包装香蕉，可直接问区域经销商是否有便利店适配规格。

**2. 洪九果品**
- 洪九果品主要做水果供应链和批发分销，香蕉是其重要品类之一。
- 定制包装服务更可能针对连锁商超、便利店、电商等B端客户，能否做小包装定制取决于采购量、区域仓配能力和是否走直供。
- 建议直接联系洪九果品当地分公司或销售，询问：能否做便利店小包装、是否支持贴牌/定制、最小起订量、配送范围。

**3. 建议你这样问供应商**
直接问这5个问题，基本就能判断能不能做：
1. 有没有适合便利店的香蕉小包装现成规格？  
2. 支持不支持定制包装？比如印LOGO、改克重、改根数、改包装形式？  
3. 最小起订量是多少？  
4. 是产地直发还是区域仓配？配送频率和损耗怎么算？  
5. 包装成本和单品报价分别是多少？

**4. 现实建议**
- 如果你门店数量少、单店采购量小，都乐和洪九不一定愿意单独给你开定制包装，更现实的是采购他们的标准小包装，或找当地水果配送商做贴标分装。
- 如果你有连锁便利店规模，可以直接谈渠道定制，通常更容易拿到支持。
- 也可以同步问本地香蕉催熟/配送商，他们往往比品牌方更灵活，能做小批量便利店小包装。

**结论：**
都乐和洪九“有可能”提供便利店香蕉小包装定制，但通常不是标准零售服务，而是B端渠道定制，需要联系当地销售确认起订量和合作条件。门店少的话，优先找区域经销商或本地水果配送商更实际。
