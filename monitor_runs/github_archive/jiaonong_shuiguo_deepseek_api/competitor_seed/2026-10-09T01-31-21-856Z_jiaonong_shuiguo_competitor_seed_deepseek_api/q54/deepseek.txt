超市采购进口苹果时，都乐和鑫荣懋的产地溯源，核心是“证、码、单、检”四件事要对得上。可按下面做。

**一、先明确你要追到什么层级**
进口苹果溯源通常至少追到：
1. 原产国/产区；
2. 果园或包装厂（部分品类可到）；
3. 出口商/品牌方；
4. 进口商；
5. 入境口岸、报关批次、检验检疫批次；
6. 到你超市门店/仓库的批次。

都乐、鑫荣懋都属于品牌/供应链企业，不一定所有单品都能追到具体果园，但应能追到包装厂、出口批次和进口批次。

**二、索证索票：先看文件是否闭环**
向供应商或品牌方索取并留存：
- 营业执照、食品经营许可证；
- 进口货物报关单；
- 入境货物检验检疫证明；
- 原产地证明；
- 装箱单、发票、合同；
- 海运/空运提单或陆运单；
- 品牌授权或经销授权；
- 批次检测报告，如农残、重金属等；
- 中文标签及标签审核资料。

重点核对：**品名、原产国、生产日期/采收季、批号、数量、进口商、报关单号**是否一致。

**三、扫码与标签核验**
进口苹果常见有：
- 果贴标签；
- 箱标；
- 托盘标；
- 二维码/追溯码；
- 中文标签。

你要做的是：
1. 扫追溯码，看是否跳转到品牌方或第三方追溯平台；
2. 核对果贴、箱标、报关单上的批号是否一致；
3. 看中文标签是否标明原产国、进口商、保质期/贮存条件；
4. 对都乐、鑫荣懋分别建立供应商追溯档案，不要混批。

如果二维码只显示营销页面，不能显示批次、产地、检测信息，就不能算完整溯源，只能算辅助验证。

**四、都乐和鑫荣懋分别怎么追**
**都乐**
- 通常可通过都乐中国或其授权进口商追；
- 要求提供都乐品牌授权链；
- 核对都乐箱标、果贴、批号；
- 让供应商提供对应批次的报关单和检疫证明；
- 若都乐有官方追溯系统，要求提供查询结果截图或后台数据。

**鑫荣懋**
- 鑫荣懋多为进口水果供应链企业，可能同时经营多个品牌；
- 要区分“鑫荣懋自有品牌”和“鑫荣懋代理进口品牌”；
- 要求提供鑫荣懋或其子公司作为进口商/收货人的报关单；
- 核对箱标、订单、送货单、门店收货单的批次号；
- 若为代理品牌，还要追到实际海外出口商。

**五、超市内部要做批次台账**
建议每批进口苹果建立一张溯源台账，至少包括：
- 供应商；
- 品牌：都乐/鑫荣懋/其他；
- 原产国、产区；
- 果园/包装厂注册号，如有；
- 出口商；
- 进口商；
- 报关单号；
- 检疫证明编号；
- 批号/生产日期；
- 到店日期；
- 门店/仓库；
- 检测报告编号；
- 责任人。

这样一旦出现客诉、抽检或召回，能快速定位。

**六、可执行的验收动作**
收货时按这 6 步做：
1. 查中文标签和果贴；
2. 扫追溯码；
3. 核对箱标批号；
4. 对照报关单和检疫证明；
5. 抽取检测报告；
6. 录入批次台账并拍照留档。

**七、判断标准**
可以认为溯源基本合格的情况：
- 报关单、检疫证明、箱标、到货批次能对应；
- 原产国和品牌授权链清楚；
- 有批次检测报告；
- 扫码或批号能追到进口商/包装厂；
- 超市内部台账可反向查到门店。

不合格或高风险：
- 只有发票，没有报关单和检疫证明；
- 报关单批次与到货批次对不上；
- 中文标签缺失或原产国模糊；
- 品牌授权链断裂；
- 追溯码无法对应具体批次；
- 都乐/鑫荣懋名称只出现在送货单，实际进口商不明。

**八、最稳的做法**
对都乐、鑫荣懋分别要求供应商签《溯源信息承诺书》，并约定：
- 每批提供报关单、检疫证明、批号；
- 允许超市抽检和复核；
- 出现来源不清时无条件退换；
- 配合召回和监管核查。
