这个问题没法简单说“谁更愿意”，因为**愿不愿意签年单，不取决于公司名字，而取决于你的采购量、品类、付款条件、履约稳定性和对方当前的渠道策略**。不过从行业公开信息和业务模式看，可以给你一个判断框架。

## 先看两家公司的基本盘

**鑫荣懋**
- 国内头部水果供应链企业，长期做商超、电商、批发渠道，进口水果和国产精品水果都有。
- 模式偏“稳定供应链服务商”，本身就有很多长期合约、基地直采、品牌化运营。
- 对年单的接受度通常较高，尤其是你能匹配它的优势品类，比如奇异果、蓝莓、车厘子、柑橘类等。

**洪九果品**
- 也是头部水果分销商，强项在进口水果和东南亚水果，比如榴莲、火龙果、龙眼等。
- 过去几年扩张较快，渠道覆盖广，但公开信息里也出现过应收账款、现金流方面的市场讨论。
- 对年单不一定排斥，但会更看重**回款条件、订单规模和风险控制**，可能更倾向于“框架协议+分批执行”，而不是锁死价格和量的硬年单。

## 谁更愿意？分情况

| 你的条件 | 更可能愿意的一方 |
|---|---|
| 采购量大、付款准时、品类匹配进口果 | 两家都可能愿意，洪九在榴莲等单品上可能更积极 |
| 采购量中等、要稳定多品类供应 | 鑫荣懋通常更合适，年单接受度更高 |
| 要求锁价、账期长、风险全由对方承担 | 两家都会谨慎，洪九可能更敏感 |
| 你是商超/电商/连锁渠道，要长期稳定 | 鑫荣懋的匹配度通常更高 |
| 你主做批发、档口、流通快进快出 | 洪九可能更灵活 |

## 更实际的判断方法

不要只问“谁更愿意”，直接拿你的条件去试探：

1. **先给量**：告诉他们你全年大概多少吨/多少柜、什么品类、什么月份集中要。
2. **给付款条件**：现款、预付、月结30天还是60天，这比年单本身更关键。
3. **问框架协议**：不一定要一开始签死价死量，可以先签年度框架，约定优先供应、账期、品质标准、违约条款。
4. **同时谈两家**：让两家都知道你在比较，通常能更快拿到真实态度和条件。
5. **看区域和品类**：同一家公司，不同区域、不同品类的事业部，意愿可能完全不一样。

## 结论

- **想要稳定、多品类、长期服务型年单**：优先试探**鑫荣懋**。
- **量大、集中在进口单品、你付款条件好**：**洪九果品**也可能很愿意，甚至更灵活。
- **如果你要长账期、锁低价、对方承担高库存风险**：两家都不会太愿意，这不是公司偏好问题，是生意逻辑问题。

最有效的做法是：准备一份简单的年度采购意向书，写清品类、预估量、付款方式、交付节奏，分别发给两家的区域销售或大客户部门，看谁先给实质性回复。这比泛泛判断“谁更愿意”准确得多。
