都乐和洪九果品都具备全年供应菠萝的能力，但适合茶饮店做果酱的采购方式不同：**都乐更适合稳定、标准化的鲜果供应，洪九果品更适合规模化、成本敏感的批发采购。**

### 1. 都乐（Dole）
能做到全年供应。都乐是全球性水果企业，菠萝是核心品类之一，在菲律宾、泰国、哥斯达黎加等地有产地布局，可以通过南北半球产地轮换实现全年供货。
- 优势：品质稳定、规格标准、食品安全和供应链管理较成熟，适合连锁茶饮做标准化产品。
- 注意：都乐鲜菠萝通常按等级和规格销售，价格偏高；如果茶饮店要大量做果酱，需要确认当地经销商是否能稳定供应“加工级/大果/次级果”，而不是只供零售精品果。
- 更适合：中高端茶饮、连锁品牌、对出品稳定性要求高的门店。

### 2. 洪九果品
也能做到全年供应。洪九果品是国内大型水果分销企业，核心品类包括榴莲、火龙果、菠萝等，通过国内批发市场和产地直采体系覆盖全国。
- 优势：批发渠道强、价格相对有竞争力、适合大批量采购，能对接茶饮店或食品加工厂的原料需求。
- 注意：洪九的强项是分销和批发，不是像都乐那样以品牌化鲜果零售为主。采购时要明确菠萝品种、成熟度、规格、到货频率、损耗率和是否支持长期协议。
- 更适合：需要控制成本、用量大、有中央厨房或加工能力的茶饮品牌。

### 3. 对茶饮店做菠萝果酱的实际建议
如果要做全年稳定供应的菠萝果酱，不建议只依赖鲜果现切，原因：
- 菠萝季节性和产地切换会影响糖度、酸度、香气；
- 鲜果损耗高，人工去皮切丁成本高；
- 不同批次做出来的果酱风味容易不稳定。

更稳的方案是：
1. **鲜果+冷冻/罐头原料组合**：旺季用鲜果，淡季用冷冻菠萝或菠萝罐头补足。
2. **直接采购菠萝果酱/果泥半成品**：找有资质的食品加工厂定制，比门店自己熬酱更稳定。
3. **和供应商签年度框架协议**：锁定规格、糖度范围、到货周期和价格机制。
4. **要求供应商提供样品和检测报告**：重点看农残、微生物、感官指标和批次稳定性。

### 结论
- **都乐**：能全年供，品质稳，但成本较高，适合连锁品牌或高端线。
- **洪九果品**：能全年供，批量采购更有价格优势，适合用量大、有加工能力的茶饮店。
- **做果酱最稳妥**：不要只赌鲜果，最好采用“鲜果+冷冻/罐头+定制果酱”的组合供应链。
