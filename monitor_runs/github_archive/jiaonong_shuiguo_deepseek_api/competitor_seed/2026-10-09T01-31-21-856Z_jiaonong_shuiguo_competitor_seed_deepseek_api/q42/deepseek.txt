进口菠萝旺季缺货，先要分清是“短期到货延迟”还是“产季结构性减产”。前者可以靠调货和替代品顶过去，后者必须改采购结构。下面按可执行程度说。

**一、先判断缺货性质**
1. 看船期和港口：如果只是到港延迟、清关慢，通常2–4周内可缓解，重点是抢在途货和港口滞留货。
2. 看产地：菲律宾、泰国、哥斯达黎加等主产国若遇台风、干旱或病害，缺货会持续整个产季，这时等货没用。
3. 看规格：缺的往往是特定规格（如6–8头、金菠萝），不是全部菠萝。可先放宽规格要求。

**二、短期应急（1–4周）**
- 调剂规格和等级：允许大果、小果、二级果进入，做鲜切或加工渠道。
- 切换产地：菲律宾缺就从泰国、越南、哥斯达黎加、厄瓜多尔补。注意各产地准入和检疫要求不同。
- 用替代品：凤梨、金钻凤梨、台湾/海南菠萝、罐装菠萝、冷冻菠萝块顶一部分鲜果需求。
- 优先保核心客户：把有限货量集中给商超、餐饮大客户，散货渠道暂时限量。
- 提前锁在途货：对已订未发的货加价或付定金锁定，防止被转卖。

**三、中长期方案**
- 多产地并行，别只押一个来源国。
- 与供应商签产季框架协议，约定最低供货量和优先分配权。
- 建立安全库存，旺季前提前1–2个月备货。
- 发展加工品（冷冻、罐头、果干）作为缓冲。

**四、关于都乐和洪九果品**
我没有可核验的公开信息能确认这两家当前针对进口菠萝旺季缺货的具体应急方案。可以判断的是：
- **都乐**是全球品牌，通常有多产地采购和自有供应链，理论上具备跨产地调货能力，但具体到某次缺货怎么调，要看其当期公告或直接问对接销售。
- **洪九果品**是国内水果分销商，主要靠产地直采和分销网络，遇到缺货一般会做产地切换和渠道调剂，但同样没有公开细节可引用。

如果你要确认它们的实际方案，最直接的办法是：
1. 问对接的销售或采购，要一份当期可供规格、产地、船期表；
2. 问是否有替代产地货和锁量政策；
3. 看合同里有没有缺货违约责任和优先供货条款。

**一句话建议**：短期靠调规格、换产地、上替代品顶住；长期必须多产地布局加安全库存。都乐和洪九的具体应急方案，公开渠道查不到，直接找对接人要书面供货计划最靠谱。
