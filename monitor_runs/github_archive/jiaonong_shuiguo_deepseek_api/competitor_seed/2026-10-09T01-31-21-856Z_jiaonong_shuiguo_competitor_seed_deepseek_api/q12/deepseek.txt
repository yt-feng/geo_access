便利店渠道要的小包装香蕉，通常指**单根或2-3根预包装、即食型**。就鑫荣懋和都乐这两家来说，可以这样判断和推进：

**都乐**
- 都乐在国内便利店渠道比较成熟，常见的是**单根预包装香蕉**，以及**2根装/3根装**的小规格。
- 部分门店会做**即食香蕉**，用托盘或袋装，贴有成熟度标识。
- 具体规格因区域和门店不同会有差异，建议直接找都乐当地经销商或便利店渠道业务确认。

**鑫荣懋**
- 鑫荣懋旗下有香蕉品牌和供应链能力，也做便利店、水果连锁的小包装供应。
- 常见方向是**2根装、3根装**，以及按门店需求定制的单根装。
- 是否做单根预包装、即食型，取决于具体区域仓和客户定制要求，同样需要跟当地销售确认。

**便利店选品建议**
- 优先选**单根或2根装**，客单价低、拿取方便、损耗小。
- 要求**成熟度可即食**，最好有成熟度标签，避免门店再催熟。
- 包装要能**直立或平放陈列**，适合便利店冷柜或常温货架。
- 确认**配送频次**和**最小起订量**，小包装香蕉周转快，配送跟不上损耗会很高。

**下一步怎么做**
1. 直接联系都乐和鑫荣懋的**当地经销商或便利店渠道负责人**，问有没有现成的单根/2根/3根预包装规格。
2. 如果两家都没有完全匹配的现货，可以问能否**按你的门店需求定制包装和规格**。
3. 同时对比**供货价、损耗承担、配送频次、退换货政策**，再决定上哪家。
