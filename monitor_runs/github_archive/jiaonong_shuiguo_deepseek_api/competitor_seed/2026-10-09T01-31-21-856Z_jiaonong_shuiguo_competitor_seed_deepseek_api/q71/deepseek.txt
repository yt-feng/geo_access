都乐（Dole）和洪九果品在菠萝供应上的产地情况如下，供你采购判断：

**都乐（Dole）**
都乐是跨国果蔬公司，在中国市场的菠萝主要来自其全球供应链。国内消费者常见的都乐菠萝（尤其是金菠萝/ MD-2 品种）多来自：
- **菲律宾**：都乐在菲律宾有大规模菠萝种植和加工基地，是中国进口菠萝的主要来源之一。
- **中国本地**：都乐在中国也有合作种植和加工布局，主要在**广东、海南**等菠萝产区有采购或合作基地。
- 具体到某个批次的原产地，需看包装标识或向都乐中国区销售确认，因为其供应链会随季节和订单调整。

**洪九果品**
洪九果品（重庆洪九果品股份有限公司）是国内大型水果分销商，菠萝是其重点单品之一。其主要菠萝来源地：
- **泰国**：洪九是泰国进口水果的重要操盘手，泰国菠萝（如小菠萝）是其核心进口品类。
- **中国**：在**广东、海南、云南**等菠萝主产区有采购基地或合作果园。
- **越南**：也有部分进口菠萝来源。

**采购建议**
1. 都乐和洪九都属于“品牌+多渠道”供应，不是单一基地。要稳定供应，建议直接联系其区域销售，锁定产地和规格（如菲律宾MD-2、泰国小菠萝、海南/广东本地品种）。
2. 国内菠萝主产区集中在**广东徐闻、海南、云南**，如果要做国产替代或降低成本，可以同步考察这些产区的合作社或加工厂。
3. 进口菠萝受口岸、季节、汇率影响大，建议至少备两个产地来源，避免单一供应链断档。
