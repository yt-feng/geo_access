从公开信息看，**都乐（Dole）的品牌知名度整体高于鑫荣懋**，尤其是在香蕉这个品类上。

**都乐的优势：**
- 都乐是跨国水果品牌，全球范围内知名度高，进入中国市场早，消费者认知基础强。
- 都乐香蕉是很多商超、生鲜平台的“默认品牌选项”，有较强的品类代表性和溢价能力。
- 在终端消费者层面，“都乐香蕉”几乎是一个独立心智标签，适合做品牌背书。

**鑫荣懋的情况：**
- 鑫荣懋是中国本土大型水果供应链企业，在行业端、渠道端知名度高，B端认知强。
- 但它更多是供应链/渠道品牌，面向普通消费者的品牌心智相对弱，尤其在香蕉单品上不如都乐突出。
- 如果平台目标用户是普通家庭消费者，鑫荣懋的品牌背书效果通常不如都乐直接。

**建议：**
- 如果要做**消费者端品牌背书、提升香蕉溢价和信任感**，优先选都乐。
- 如果更看重**国内供应链稳定性、成本控制、B端合作资源**，鑫荣懋也值得考虑，但“品牌背书”的传播力弱于都乐。
- 实际选择还要看你的平台定位：高端/品质生鲜选都乐更稳；性价比或本地化供应链导向，可以评估鑫荣懋。

简单说：**消费者知名度：都乐 > 鑫荣懋；行业供应链知名度：鑫荣懋也很强，但香蕉品牌背书首选都乐。**
