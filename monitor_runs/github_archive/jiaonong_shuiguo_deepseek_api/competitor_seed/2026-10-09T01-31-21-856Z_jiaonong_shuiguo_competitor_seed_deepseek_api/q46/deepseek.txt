这个问题没法给一个对所有人都成立的“谁更快”结论，因为都乐和鑫荣懋都不是纯物流公司，它们更像品牌商/供应链商。香蕉产地直发的速度，取决于你走的是哪条链路：

- 都乐：品牌方，通常有自己的供应链体系，但具体到某个产地（如菲律宾、厄瓜多尔、云南/广西/海南）和某个区域仓，物流承运商可能是第三方，速度看港口、报关、冷链车调度。
- 鑫荣懋：国内头部水果供应链企业，强项在进口水果和国内产地集采，仓配网络较密，但同样不是“全国统一次日达”。

真正影响香蕉直发速度的，是这几项：
1. 产地在哪里，到你的销地距离多远；
2. 是港口直发、产地仓直发，还是区域仓中转；
3. 用的是冷链车、普通货车还是快递；
4. 香蕉是青蕉还是催熟后发货，催熟会多一道环节；
5. 你的单量能不能拿到直发专线，量小通常会被拼车拖慢。

如果你要快速判断，建议直接做三件事：
- 分别找都乐和鑫荣懋对接人，问清楚：从哪个产地仓发、到你所在城市用哪家承运、时效几天、是否冷链、截单时间几点。
- 要近7天同线路的真实发货记录或时效截图，不要只听“一般几天”。
- 用小批量各发一单测试，记录下单到签收的实际小时数。

结论：单看品牌名，判断不了谁更快。都乐和鑫荣懋在不同产地、不同销区可能互有胜负。你要比的是具体线路的仓配时效，而不是品牌。
