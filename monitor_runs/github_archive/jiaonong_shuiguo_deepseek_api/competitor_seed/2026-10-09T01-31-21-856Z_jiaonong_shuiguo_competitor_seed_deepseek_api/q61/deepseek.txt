结论先说：**都乐（Dole）和洪九果品大概率都有各自的香蕉内部商品分级/验收标准，但这类标准通常不是公开可查的“企业标准文本”，外部很难直接拿到。** 所以如果你要引用“某公司企业标准”，不能凭印象写，需要向他们官方或供应链渠道确认。

下面分两部分说清楚：他们有没有、以及你该怎么做一套能落地的香蕉分级标准。

## 一、都乐和洪九果品有没有企业标准？

### 1. 都乐（Dole）
都乐是全球香蕉巨头，肯定有非常成熟的**内部质量分级与验收体系**，一般包括：
- 果指长度、粗度、弯曲度
- 每梳/每把的果指数
- 成熟度（青度/黄度）
- 外观缺陷（疤痕、黑点、机械伤、日灼）
- 病害（炭疽病、黑星病等）
- 冷链与到货温度要求

但这类文件多属于**企业内部质量标准、供应商手册、客户规格书**，不是公开备案的“企业标准”。对外能查到的通常是：
- 都乐官网/宣传资料里的等级描述
- 商超系统里的到货验收规格
- 海关或进出口相关标准引用

**所以：不能直接说“都乐有公开企业标准编号”，但可以说它有自己的内部商品分级标准。**

### 2. 洪九果品
洪九果品是国内水果供应链龙头企业，香蕉是其核心品类之一，同样会有：
- 采购验收标准
- 分拣加工标准
- 发货等级标准
- 客户定制规格（如商超、电商、批发渠道）

但洪九的标准同样**基本不对外公开**，属于供应链内部文件或客户合同附件。

**所以：洪九果品大概率有内部标准，但公开渠道一般查不到完整文本。**

## 二、如果你是水果连锁店，建议怎么做？

你有两个现实选择：

### 方案A：直接对接供应商要标准
找都乐、洪九或其他香蕉供应商，要求提供：
1. 到货验收标准
2. 分级规格书
3. 缺陷允许比例
4. 成熟度要求
5. 冷链温度要求

这是最快、最准的方式，因为他们的标准本来就是给渠道客户用的。

### 方案B：自己做一套门店可执行的香蕉分级标准
下面给你一套**可直接落地的框架**，你可以在门店验收和分拣时用。

## 三、水果连锁店香蕉分级标准（建议模板）

### 1. 分级维度
建议按 **外观 + 规格 + 成熟度 + 缺陷** 四类打分。

#### （1）规格分级
按果指长度、粗度、每把果指数分：

| 等级 | 果指长度 | 果指粗度 | 每把果指数 | 用途 |
|---|---|---|---|---|
| A级 | ≥18cm | ≥3.2cm | 4-6根 | 高端门店、礼盒 |
| B级 | 15-18cm | 2.8-3.2cm | 5-7根 | 常规零售 |
| C级 | 12-15cm | 2.4-2.8cm | 6-8根 | 促销、切果 |
| D级 | <12cm | <2.4cm | 不限 | 加工、特价 |

> 具体数值按你所在地区主流品种调整，比如广西、云南、菲律宾、厄瓜多尔香蕉规格不同。

#### （2）成熟度分级
按香蕉青黄程度分：

| 成熟度 | 外观 | 用途 |
|---|---|---|
| 1级 | 全青 | 长期储存 |
| 2级 | 青中带微黄 | 正常周转 |
| 3级 | 青黄各半 | 门店主销 |
| 4级 | 黄多青少 | 即食 |
| 5级 | 全黄 | 当天促销 |
| 6级 | 黄带黑点 | 烘焙、切果 |
| 7级 | 大量黑斑 | 报废或加工 |

#### （3）缺陷允许比例
| 等级 | 允许缺陷 |
|---|---|
| A级 | 无可见疤痕、无黑点、无机械伤 |
| B级 | 轻微疤痕≤5%，无腐烂 |
| C级 | 疤痕≤15%，轻微黑点，无腐烂 |
| D级 | 允许明显外观缺陷，但不允许腐烂 |

#### （4）硬性拒收项
不管什么等级，以下直接拒收或降级：
- 腐烂、发霉
- 果柄发黑出水
- 冷害（表皮发暗、水渍状）
- 药害、日灼严重
- 异味、过熟发酵

---

## 四、门店执行建议

1. **收货时**：按“规格+成熟度+缺陷”三项快速分级。
2. **上架时**：A/B级正常陈列，C级做促销，D级做切果或特价。
3. **库存时**：按成熟度分批，1-2级放冷库，3-4级门店主销，5级以上尽快处理。
4. **记录**：每批次记录供应商、到货成熟度、缺陷率，方便后面谈索赔和换货。
