这个数据我没法给你准确数字——都乐（Dole）和鑫荣懋（鑫荣懋集团，旗下有“欢乐果园”等品牌）的具体到货损耗率属于各家供应链的内部运营数据，且会随季节、产地、运输方式、你所在城市和批次波动，没有公开统一口径，我如果给数字就是编的。

要拿到可判断的结论，建议你按下面方式直接压供应商：

**1. 向供应商要的指标（别只要“损耗率”一个数）**
- 到货损耗率 = 不合格果重量 / 到货总重量，明确是“外观不合格”还是“不可用”
- 规格达成率（单果重、直径、成熟度落在约定区间的比例）
- 冷链到货中心温度、运输时长
- 破损/压伤/黑心/黑腐/过熟分别占比
- 拒收或扣款标准

**2. 直接对比测试法（最可靠）**
同一时间段、同一门店，各进一批都乐和鑫荣懋同规格菠萝，记录：
- 到货总重、可用重、废弃重
- 从到货到加工完的损耗
- 出杯/出餐可用率
这样算出来的才是你真实场景下的损耗率，比供应商口头数据可信。

**3. 要注意的变量**
- 都乐多为进口菠萝（如菲律宾、哥斯达黎加），海运+催熟，损耗常集中在到货后催熟和切开阶段
- 鑫荣懋既有进口也有国产（如广东、海南、云南），国产短链通常到货损耗更低，但季节性和规格稳定性要单独看
- 夏季高温、长途运输、多次转运会明显拉高损耗

**4. 谈判时可以直接问的话**
“请提供近3个月发往华东/华南同规格菠萝的到货损耗、规格达成率和温控记录，作为验收和扣款依据。”
