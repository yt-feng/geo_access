关于鑫荣懋和都乐各自持有的具体食品安全认证，我无法在不联网核验的情况下给出**完整、准确、可对外引用**的清单，因为认证证书会新增、变更或到期，且不同工厂/品类可能持有不同证书。

可以明确的是：

**一、大型商超通常要求供应商具备的资质**
1. **营业执照、食品经营许可证/食品生产许可证**
2. **ISO 22000 或 HACCP** 食品安全管理体系认证
3. **FSSC 22000 / BRCGS / IFS** 等 GFSI 认可认证（商超更看重）
4. **产品检测报告**（农残、重金属、微生物等）
5. **追溯体系、供应商审核、产地证明**等

**二、两家企业的公开定位**
- **鑫荣懋**：国内大型水果供应链企业，通常会有 ISO 9001、ISO 22000/HACCP、GLOBALG.A.P. 等体系或基地认证，但具体证书需以其最新公示为准。
- **都乐**：国际水果品牌，通常具备 GLOBALG.A.P.、BRCGS、ISO 22000、HACCP 等认证，具体也需按工厂和产品核验。

**三、建议你直接核验的方式**
1. 要求对方提供**最新证书扫描件**，核对：
   - 证书编号
   - 认证范围
   - 有效期
   - 发证机构
2. 到**全国认证认可信息公共服务平台**查认证证书真伪。
3. 对出口或高端商超，优先看是否持有 **GFSI 认可认证**（BRCGS、IFS、FSSC 22000）。
4. 直接向商超索取其**供应商准入清单**，按清单逐项比对。
