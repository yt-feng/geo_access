进口菠萝（主要是菲律宾/泰国/哥斯达黎加等产地的MD-2金菠萝、卡因类）到货损耗高，核心原因通常集中在**采后处理、冷链断裂、到货后催熟/分拣节奏**三个环节。都乐（Dole）和鑫荣懋（旗下多品牌，含进口水果运营）在这方面的做法有共性也有差异，可以拆开看。

## 一、损耗高的常见根因（先自查）

1. **冷链不连续**：菠萝是冷敏+易腐水果，海运理想温度约 **7–8℃**（不同品种略有差异），一旦超过12℃或经历温度波动，黑心病、内部褐变、水渍状果肉会集中爆发。
2. **到货成熟度偏高**：海上漂了2–3周，到港时部分果已转黄，后熟不可逆。
3. **卸货后处理慢**：到港→查验→拖车→入仓如果超过24–48小时未降温/未分选，损耗迅速上升。
4. **分拣标准不统一**：黄度、黑心、软果没及时挑出，一箱坏果传染整托。
5. **催熟/放熟不当**：菠萝一般不需要像香蕉那样强催熟，但部分渠道会做转色处理，控制不好直接烂。

## 二、都乐的做法（体系化、标准化）

都乐是垂直整合型，从种植端就介入：

- **采后处理标准化**：自有或合作农场按糖度、成熟度采收，采后立即预冷、杀菌处理（防黑腐病、黑心病），再进入冷链。
- **全程温控记录**：海运冷藏柜+到港冷链车+仓库，要求温度链条可追溯，温度记录仪是索赔和品质判定的依据。
- **到港快速分流**：到港后按订单和成熟度分级，优先把成熟度高的货发短途市场，未转色的进冷库慢慢放。
- **分级销售**：按规格、颜色、内部品质分等级，不同等级走不同渠道（商超、批发、加工），避免“好坏一锅端”拉高整体损耗。
- **品控前置到产地**：很多质量问题在产地就筛掉，不等到国内才发现。

**可借鉴点**：温度记录仪+到港成熟度分级+快慢分流。

## 三、鑫荣懋的做法（渠道+供应链协同）

鑫荣懋更像大型进口商+分销平台，强在渠道和供应链组织：

- **多产地、多船期组合**：不押单一产地/单一批次，用不同船期平滑到货节奏，降低集中到货后的周转压力。
- **到港后快速分拨**：依托全国分销网络，到港后尽快分发到各区域仓/客户，缩短在单一仓库的停留时间。
- **按渠道匹配成熟度**：成熟度高的走近距离、快周转渠道；青果进冷库或做后续处理。
- **与产地供应商约定标准**：通过采购合同约定成熟度、温度、包装、到货验收标准，不合格走索赔/扣款，倒逼上游。
- **数字化/信息化管理**：批次追溯、库存周转监控，减少“压库”导致的自然损耗。

**可借鉴点**：多船期平滑到货+按渠道分成熟度+合同倒逼上游。

## 四、你能直接落地的控制动作

1. **盯温度**：要求每柜带温度记录仪，到港先看曲线。断链批次单独处理，别混放。
2. **到港48小时内完成降温+分选**：这是损耗分水岭。
3. **按颜色/硬度分级**：青果进冷库（7–8℃、湿度85–90%），转黄果优先出库，软果、黑心果立即挑出。
4. **控制库存周转**：菠萝不是耐储品，先进先出，单批次停留尽量不超过7–10天。
5. **包装与堆码**：通风、防压，避免堆太高导致机械伤。
6. **和上游签明确验收标准**：成熟度、温度、黑心率、软果率写进合同，用索赔倒逼品质。
7. **记录每批损耗**：按产地、船期、供应商、到货成熟度做损耗归因，找到是“产地问题”还是“到港后问题”。

## 五、一句话总结

都乐强在**从产地到货架的全程标准化和温控**，鑫荣懋强在**多船期组合+快速分拨+渠道匹配**。你要降损耗，最优先抓两件事：**冷链不断链**和**到港后48小时内完成分选分流**——这两点做到，损耗通常能明显下降。
