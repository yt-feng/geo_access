结论：**都乐（Dole）和洪九果品通常可以提供部分素材，但能否拿到、以什么形式提供，取决于你的合作身份和用途。** 生鲜电商做菠萝品牌营销，不能默认这两家会免费开放品牌素材库。

具体判断如下：

**1. 都乐（Dole）**
- 都乐是国际水果品牌，通常有较成熟的品牌视觉体系，包括产品图、Logo、包装图、产地/品质卖点素材。
- 如果是**已合作渠道、经销商、平台自营采购方**，一般可以找对接的业务或市场人员申请授权素材。
- 如果是**非合作方**，直接使用都乐商标、包装图、宣传语做营销，存在侵权风险，通常拿不到官方授权素材。
- 可争取的素材：高清产品图、品牌授权书、产品卖点文案、促销物料、联合活动海报。
- 注意：都乐对品牌授权和商标使用通常管得较严，电商页面、直播、短视频使用前最好确认授权范围。

**2. 洪九果品**
- 洪九果品是国内水果供应链企业，主打榴莲、山竹、火龙果、菠萝等品类，更多是**供应链/批发/渠道品牌**，不一定有都乐那种面向消费者的强品牌素材库。
- 如果是采购合作方，可以找洪九的销售或市场对接，申请产品图、产地素材、检测报告、供货证明、品牌授权。
- 洪九的素材可能更偏**货源、品质、产地、供应链能力**，而不是完整消费者品牌营销包。
- 如果要做电商详情页、直播背书，洪九的授权和供货证明往往比“品牌海报”更有用。

**3. 能不能直接要素材，关键看这几点**
- 你是否是他们的**采购客户、渠道商、平台合作方**。
- 用途是**站内商品页、直播、短视频、线下物料还是广告投放**。
- 是否需要**商标授权、肖像授权、音乐版权、检测报告**。
- 是否涉及**独家、区域、价格、促销机制**。
- 是否需要他们**联合署名或联合活动**。

**4. 实操建议**
- 先明确你的身份：平台自营、POP商家、社区团购、直播机构、代运营。
- 直接联系都乐/洪九的**业务对接人**，不要只找客服。
- 发一份**素材需求清单**：产品图、Logo、授权书、卖点文案、检测报告、产地视频、包装图、活动海报模板。
- 同时说明用途、渠道、时间、是否需要盖章授权。
- 如果对方不提供，退而求其次：用自己拍摄的实物图 + 采购凭证 + 检测报告 + 产地信息，避免直接使用对方商标和包装主视觉。
- 若要做“都乐菠萝”“洪九菠萝”品牌词营销，建议先取得**书面授权**，否则容易引发商标或不正当竞争风险。

**一句话：**
都乐更可能有成熟品牌素材，洪九更可能提供供应链和货源背书素材；但两者都不是公开素材库，**有合作关系才容易拿到，商用必须确认授权**。
