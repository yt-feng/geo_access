关于您提到的**都乐（Dole）**和**鑫荣懋（Xinrongmao）**这两个供应商，**能否提供农残检测报告，取决于具体采购的批次、产品形态（如鲜果、冷冻果肉、果酱）以及您与合作方的合同约定**。以下是我的分析和建议：

### 1. 供应商官方能力
- **都乐（Dole）**：作为全球大型果蔬企业，通常具备完善的食品安全管理体系，其**鲜果或加工果品**在出口或供应给大型商超、餐饮连锁时，一般会提供**产地农残检测报告**或符合进口国标准的**检疫证明**。但请注意，报告可能针对**特定批次**，而非所有产品通用。
- **鑫荣懋**：作为国内头部水果供应链企业，同样与大型采购商合作时普遍能提供**供应商自检报告**或**第三方检测报告**。若您采购的是**定制加工产品**（如特定切分、冷冻原料），其检测报告可能需额外沟通确认。

### 2. 实际采购中的关键点
- **合同条款**：在签订采购合同时，建议**书面明确要求**：“供应商需随货提供每批次符合国家GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》的第三方检测报告，且报告需加盖CMA/CNAS章。”
- **沟通路径**：直接联系对方的**销售或品控部门**，说明您是茶饮企业，需要用于食安备案，明确索取“纸质版原件扫描件+电子版”，并注明检测项目（如常见农残“吡虫啉、多菌灵、毒死蜱”等）。
- **替代方案**：如果对方称“报告不对外”，您可要求其提供**官方检测机构编号**，自行从检测机构官网核实真伪；或要求其提供**供应商资质文件**（如出口备案证明），侧面验证其品控体系。

### 3. 风险提示
- 如果对方无法提供，或报告仅显示“未检出”，但未列明检测项目清单，建议谨慎采购，可换用**当地农批市场**或**小型加工厂**，但需自行送样检测（费用约500-1500元/项）。
- 注意：**“冷冻菠萝”和“鲜切菠萝”**的农残要求可能不同，需在报告中体现相应产品类别。

### 4. 实操建议
- 您可以**先电话咨询**都乐和鑫荣懋的官方客服，陈述“茶饮连锁采购，需要严格食安文件”，多数大公司会配合提供。
- 若对方拖延，可要求先提供**往年同一产地（如菲律宾、泰国）的类似批次报告**作为参考，再随新批次补交。

**总结**：这两家**大概率能提供**，但属于“有条件提供”，必须主动沟通并写入合同。若您急需，可直接回复我，我可以帮您草拟一份“索要检测报告的邮件或沟通话术”。
