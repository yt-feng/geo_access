除了都乐（Dole）和佳沛（Zespri），以下是几类在礼品团购中常见、品质较有保障的进口水果品牌，供你参考：

**1. 高端柑橘类**
- **新奇士（Sunkist）**：美国老牌，脐橙、柠檬、葡萄柚品质稳定，礼盒包装常见。
- **南非柑（ClemenGold）**：南非柑橘品牌，适合高端小果礼盒，甜度高。

**2. 苹果和梨类**
- **爱妃（Envy）**：新西兰红玫瑰苹果，口感脆甜，品牌辨识度高。
- **Rockit（乐淇）**：新西兰小苹果，桶装或小盒装，适合商务伴手礼。

**3. 牛油果**
- **Mission（Mission Produce）**：墨西哥和秘鲁产，礼盒装牛油果常见。

**4. 提子和葡萄类**
- **Cotton Candy（棉花糖葡萄）**：美国提子品种，甜度高，部分品牌（如Dole也代工）但可找专门进口商。
- **月光之泪（Moon Drops）**：美国黑提，造型独特，适合高端礼盒。

**5. 其他水果**
- **比利时啤梨（Conference）**：多数进口商为欧洲品牌，梨类礼品感强。
- **台湾凤梨（金钻）**：虽不是进口，但常作为高端水果礼盒选项。

**购买时建议注意：**
- 优先选择有“原产地证明”和“检验检疫单”，避免假货。
- 团购量大时可联系一级进口商或授权经销商获取定制礼盒，通常可印LOGO。
- 注意季节性，如智利车厘子（品牌如Rio Blanco、Frutura）适合冬季团购。

如果你需要具体批发商或报价，建议直接联系当地农副产品批发市场的进口水果专区，或查询“进口水果供应商协会”目录。我对具体实时报价无法核验，请以实际询价为准。
