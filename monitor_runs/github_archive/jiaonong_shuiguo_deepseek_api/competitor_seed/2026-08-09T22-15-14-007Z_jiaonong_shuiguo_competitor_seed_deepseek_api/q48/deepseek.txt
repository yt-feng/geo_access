### 一、大型商超对食品供应商的通用硬性要求
商超验厂（供应商审核）时，通常会要求提供以下证书或文件，且**必须在有效期内**：
1.  **营业执照**（含食品经营范围）。
2.  **食品生产许可证（SC）** 或 **食品经营许可证**（依据加工/分装/流通环节而定）。
3.  **质量管理体系认证**：如 **ISO 9001**。
4.  **食品安全管理体系认证**：最核心的是 **ISO 22000** 或 **HACCP（危害分析与关键控制点）认证**。
5.  **出口资质**（如涉及进出口业务）：**海关进出口收发货人备案**、**出口食品生产企业备案**。
6.  **产品检测报告**：每批次或定期送检的 **第三方检测报告**（如SGS、Intertek、华测等）。
7.  **特殊品类要求**：如涉及生鲜，可能需要 **卫生许可证**、**无公害/绿色/有机认证**（非强制，但加分）。

### 二、鑫荣懋（Xinrongmao）—— 国内果业巨头
鑫荣懋是国内最大的水果供应链企业之一，主要业务覆盖水果种植、采购、分选、仓储、配送。

其常见资质通常包括（**以下为公开信息推测，非官方实时数据**）：
- **ISO 9001质量管理体系认证**：普遍持有。
- **ISO 22000食品安全管理体系认证**：或其认证的子公司持有。
- **HACCP认证**：针对其分拣、包装、冷链储存环节。
- **Global G.A.P.（全球良好农业规范）认证**：若其自有或合作农场出口，通常会持有。
- **BRC（英国零售商协会）认证**：若服务国际商超（如沃尔玛全球采购），可能持有。
- **海关相关备案**：作为大型进出口企业，必然具备。

**注意**：鑫荣懋在全国多地设有分公司或加工中心，**资质可能挂在集团或特定子公司名下**，审查时需要求对方提供注册地址与实际供应工厂一致的文件。

### 三、都乐（Dole）—— 全球果蔬巨头
都乐为全球性企业，在中国主要通过子公司、合资公司运营。其资质更强调全球化标准。

其常见资质包括：
- **ISO 22000 / HACCP**：基本标配。
- **Global G.A.P.**：因其拥有全球多个产地（菲律宾、泰国、中国等）的农场，这是其核心资质。
- **MSC（海洋管理委员会）** 或类似可持续认证（如涉及海产品，但水果业务较少见）。
- **BRC / IFS（国际食品标准）**：因其供应欧洲商超，可能持有。
- **中国食品生产许可证（SC）**：若其在中国境内进行包装、分装，必须持有。
- **有机认证**（部分高端产品线）：如中国有机产品认证或美国USDA有机认证。

**特别提示**：都乐的资质文件编号常以其国内子公司（如“都乐（中国）水果商贸有限公司”）为主体，需确认其在中国商超供货时使用的是哪一家法人抬头。

### 四、给您的实操建议
1.  **要求对方提供证书原件扫描件**，并核对：
    - 证书上的**公司名称**与供货合同主体是否一致。
    - **有效期**是否覆盖合同期间（通常需覆盖至合同结束）。
    - 认证范围是否覆盖您采购的**具体品类**（例如：只认证了苹果，就不能覆盖香蕉）。
2.  **要求提供最近3个月的第三方检测报告**，特别是农残、重金属项目（商超抽检频率高）。
3.  **登录国家市场监督管理总局官网**（或“全国认证认可信息公共服务平台”）可查询部分认证真伪。
4.  **直接向商超采购部索取其供应商准入清单**，但通常商超不会透露，您可通过同行业渠道了解其是否已“验厂通过”。
