1. **都乐（Dole）**：作为国际知名水果企业，都乐确实有内部的企业分级标准，但其具体分级细则（如重量、长度、成熟度、外观缺陷等参数）通常属于商业机密，不会对外完全公开。都乐的香蕉分级主要参考国际通行标准（如美国农业部的分级体系）并结合中国市场终端需求（如对果指长度、弯曲度、表皮光洁度、糖度等）进行内部品控。

2. **洪九果品**：作为国内头部水果供应链企业，洪九也有自身的企业标准，但同样不对外公布详细分级手册。其香蕉分级一般围绕产地（如菲律宾、厄瓜多尔等）、单串重量、果指长度/直径、成熟度（如7成熟/8成熟发货）、瑕疵率（黑斑、擦伤、腐烂）、糖度等进行内部划分，主要用于供应链分拣和门店上架。

**对你有用的建议：**
如果你需要搭建自己的香蕉分级标准，可以基于以下公开可行的维度设计，不必依赖外部企业机密：

- **果指长度**：通常分为A级（22cm以上）、B级（18-22cm）、C级（15-18cm）；
- **单串重量**：如25kg/箱，按串重分大串（3.5kg以上）、中串（2.5-3.5kg）、小串；
- **成熟度**：按色卡分（如全绿→黄绿→全黄→有斑点），到店收货建议为“黄绿”或“半黄”，避免过熟损耗；
- **外观缺陷**：黑斑、压伤、断指、虫眼等按面积或数量限值划分；
- **糖度**：一般Brix≥18为优（可用手持糖度计抽检）。

你可以参考**《香蕉国家标准》（GB/T 39723-2020）**（国内现行），并结合门店客单价定位，把标准写成内部SOP。注意，公开可查的国家标准有法效性，而企业标准只需自家执行即可，不需要公开。
