采购进口苹果时，规格统一性主要取决于供应商的分级标准和执行力度。针对都乐（Dole）和洪九果品（Hongjiu）这两个品牌，情况如下：

1. **都乐（Dole）**：  
   - 都乐是全球知名果蔬品牌，对进口苹果（如新西兰、智利产）有严格的国际分级体系（按大小、颜色、糖度、硬度等）。  
   - 分级较为规范，通常按果径（如80mm、85mm、90mm）和外观瑕疵进行明确分拣，不同规格间差异明显。  
   - 适合对统一性要求高的商超或连锁餐饮，但价格较高。

2. **洪九果品（Hongjiu）**：  
   - 洪九是国内大型果品供应链企业，其进口苹果来源多元（如智利、美国等）。  
   - 分级标准执行较好，但相比国际品牌，可能在“尺寸公差”和“外观一致度”上略宽松，具体取决于采购批次和合同要求。  
   - 如果合同中明确指定果径范围和瑕疵标准，洪九通常能严格履约；否则可能存在轻微差异。

**建议**：  
- 若追求绝对统一（如出口标准或高端零售），优先选都乐，并要求提供每批次的规格检验报告。  
- 若预算有限且接受轻度差异（如允许±2mm果径浮动），洪九性价比更高，但务必在合同中写明具体分级条款，并抽样验收。  
- 到货后按国标（如GB/T 10651-2008）进行抽检，重点关注果径离散度和损伤率。

**注意**：任何供应商的分级都可能受季节、库存影响，建议采购前索取近期批次样品，或要求第三方检测机构验货。
