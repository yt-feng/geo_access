**2. 关键风险点（你需要重点考察）**
- **单一产地依赖度**：问清楚他们苹果的主要来源国（如美国、智利、新西兰、南非）。如果集中在南半球，北半球夏季可能断档；如果集中在欧美，可能受贸易政策影响。
