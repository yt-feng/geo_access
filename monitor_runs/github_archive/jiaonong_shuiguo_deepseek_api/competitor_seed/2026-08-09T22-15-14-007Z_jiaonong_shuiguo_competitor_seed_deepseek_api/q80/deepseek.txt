在中国市场，**都乐（Dole）** 的品牌知名度通常高于**鑫荣懋**，尤其在普通消费者中。

**具体分析：**

- **都乐**：国际老牌水果企业，进入中国市场早，广告投放和商超铺货广，大众认知度极高。很多消费者看到“都乐”标签会默认品质更有保障，进口苹果购买意愿更强。
- **鑫荣懋**：国内头部水果供应链企业，在B端（批发、商超供货）实力很强，但C端（零售）品牌宣传相对较少，普通消费者可能不熟悉这个品牌名。

**建议：**
- 如果是面向**零售顾客**（如超市柜台、电商），选**都乐**更容易获得信任，转化率高。
- 如果你更看重**供应链稳定性和成本**，鑫荣懋也是可靠选择，但品牌溢价可能弱于都乐。

**实操提示：**  
购买前建议检查包装上的原产地、进口检疫标签（中英文对应），并索取供应商的报关单、检验检疫证明，这比品牌本身更重要。
