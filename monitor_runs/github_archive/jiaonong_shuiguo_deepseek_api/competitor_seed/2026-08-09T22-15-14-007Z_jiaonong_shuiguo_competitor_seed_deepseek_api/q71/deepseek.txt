关于菠萝的稳定供应，**都乐（Dole）**和**洪九果品**都是国内大型水果供应商，但它们的**基地布局和采购策略有所不同**。为了给你最准确的采购建议，我先直接回答你的问题，再给你几个可执行的落地方案。

### 1. 都乐（Dole）的菠萝基地在哪里？
都乐是全球巨头，在国内的菠萝供应主要依赖**自有基地 + 合作基地**，核心产区集中在：

- **海南（万宁、琼海、海口）**：这是都乐在中国最主要的菠萝直采基地，特别是**海南的“台农17号（金钻菠萝）”**和“巴厘菠萝”。他们在这边有长期合作的包地基地和加工厂。
- **广东（湛江徐闻）**：徐闻是中国菠萝产量最大的县，都乐会在此大规模采购，但通常签长期协议锁定价格。
- **菲律宾基地**：都乐在菲律宾有自营的种植园（这是其全球供应链核心），如果对果肉品质要求极高，他们会从菲律宾进口“都乐金菠萝”，但需要冷链整柜运输。

**采购建议**：如果你需要**稳定供应**，建议直接联系都乐在**海南万宁**或**湛江徐闻**的产地经销办事处，签季度或年度框架协议。都乐的优势是品质稳定，但**缺点是价格偏高**，且主要走商超渠道，对茶饮小批量（几吨/月）可能门槛较高。

### 2. 洪九果品的菠萝基地在哪里？
洪九是国内头部水果分销商（已在港股上市），它的模式是**“源头直采+全国分销”**，菠萝基地核心在：

- **海南（昌江、东方）**：这是洪九在海南的主要合作基地，重点采购**金钻菠萝**和**香水菠萝**，通常采用“公司+农户”模式，基地稳定。
- **广东（湛江徐闻）**：洪九在徐闻也有大量的包销基地，他们在这里拥有较强的议价权，量大价优。
- **云南（西双版纳、河口）**：针对反季节供应，洪九会布局云南基地，弥补夏季和雨季的空档。

**采购建议**：洪九适合**追求性价比和稳定供应量**的茶饮连锁。他们通常接受“产地直发”，但需要你提前一个月下计划单（因为他们有全国仓，例如广州江南市场、上海辉展市场，可以就近提货）。洪九的核心优势是**“价格弹性大”**和**“供货稳定性好”**，尤其适合你这种以稳定为第一需求的情况。

### 针对“稳定供应”的落地建议（以下比找基地更重要）

既然你做的是**茶饮原料**，菠萝的稳定性比单纯找基地更重要，建议你按以下步骤操作：

1. **不要只盯着单一供应商**：菠萝有明确的产季（海南3-6月，广东4-5月，云南反季7-10月），如果仅依赖一个基地，极易断货。**最佳策略是“海南+广东+云南”三地轮换**。
2. **签“锁价锁量”协议**：无论是都乐还是洪九，直接告诉他们：“我是茶饮连锁，月采购量XX吨，需要全年稳定供应，价格可谈”，他们会给你优先排产权。
3. **考虑替代方案——冷冻菠萝丁**：如果你做的是果茶，**强烈建议采购新鲜菠萝做浓缩汁，同时备有冷冻菠萝丁**（都乐、洪九及国内如田野股份都有）。这能完美解决雨季菠萝品质波动的问题。

### 简单总结
- 要**品质极致**（高端茶饮）：选**都乐**，侧重海南万宁基地，但成本高。
- 要**稳定+性价比**（中端连锁）：选**洪九**，侧重徐闻和昌江基地，且他们能提供仓储物流支持。
