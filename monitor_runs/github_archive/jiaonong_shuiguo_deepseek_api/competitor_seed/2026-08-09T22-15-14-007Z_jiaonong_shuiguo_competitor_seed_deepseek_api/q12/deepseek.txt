针对便利店渠道，**鑫荣懋（XinRongMao）**和**都乐（Dole）**都有小包装香蕉产品，但具体规格和铺货情况会因地区、季节和合作门店不同而有差异。以下是常见规格及建议：

**1. 鑫荣懋（国内品牌）**
- **常规小把装**：通常为**2-3根/把**，整把净重约**400g-500g**，适合便利店单次购买。
- **精品果盒/袋装**：部分渠道有**独立小盒装（约300g）**或**透明膜预包装**，便于陈列和扫码结算。
- **对接方式**：鑫荣懋与国内多家连锁便利店（如全家、7-11、罗森）有长期合作，可直接联系其**华南/华东**大区销售，按便利店单店日销量定制**每日鲜配**。

**2. 都乐（Dole，进口/合资）**
- **标准小把装**：主要为 **“DOLE迷你香蕉”** 或 **“小果”** 系列，通常**2-4根/把**，净重约**450g-550g**，特点是果实较细、甜度高。
- **即食水果杯/袋**：部分地区有**盒装切片香蕉（如120g-150g）**，适合加工型便利店（如鲜食柜），但需冷链物流。
