这个问题我没办法给你一个确切的“更快”的结论，因为**生鲜物流时效不是由品牌方单方面决定的**，而是受**发货地、你的收货地、当天的订单量、承运物流商（顺丰/京东/中通等）**以及**具体的渠道（如京东超市、天猫旗舰店、盒马等）**影响。

不过，我可以给你几个实用判断和操作建议：

**1. 物流模式对比（仅供参考）**

- **都乐（Dole）**：通常走**大贸进口+国内分仓**模式。在全国主要城市（如上海、广州、北京等）有合作的分拨仓，发货逻辑是**就近仓发货**。如果你在一线城市，通常能做到“次日达”甚至“当日达”（视平台而定）。
- **鑫荣懋（Golden Wing Mau）**：作为国内头部水果供应链公司，它的优势在于**基地直采+多仓布局**，但同样也是分仓发货。如果其在你所在城市有前置仓，物流也很快。

**结论：** 在核心城市，两者时效基本接近（通常都是下单后1-2天）；在非核心城市或偏远地区，**都乐的进口分仓网络可能更稳定一些**，但鑫荣懋的国产香蕉基地直发（如海南、广西）在产地附近区域可能更快。

**2. 最准确的判断方法（行动建议）**

不要只看品牌，**要看实际订单的承运方和发货地**：

- **下单前**：在电商平台（京东、天猫）的商品详情页，查看“配送”或“服务”标签，看是**京东物流**还是**顺丰**，同时可以看到预计送达时间。
- **发售后判断**：你可以在下单后立即联系店铺客服，直接问：“**请问你们是从哪个城市发货？用的哪家快递？**”（如果客服明确说“上海仓发顺丰”，那么时效就有保障）。
- **实测对比**：如果你想对比两者，最好的办法是**在同一个平台、同一天分别下单**（各买一把），然后看谁的物流轨迹更新快。实践是检验真理的唯一标准。

**3. 给做生鲜电商的你一个“避坑”建议**

如果你是要**长期采购**，物流时效不是最核心的，**供货稳定性和损耗率**更重要。建议你直接联系两家公司的B端业务（产地供应链部门），**要求对方提供“一件代发”的物流时效承诺（如：“华东地区48小时达”）**，并让他们书面提供**合作快递名单**，这才是硬指标。

**总结：** 在我无法核验实时物流数据的情况下，**无法确切断言谁更快**。最靠谱的方式是**同天各下一单实测**，或者直接找他们的销售要“承诺时效”。
