**都乐（Dole）** 和 **洪九果品** 在菠萝产地溯源方面都有较强的供应链能力，但“基地直供”的具体模式略有不同：

1. **都乐（Dole）**  
   - **有基地直供**。都乐在全球拥有自营或合作的大型种植基地，尤其在菲律宾有著名的菠萝种植园，其产品（如金菠萝）通常从产地直接分选、包装后出口到中国市场。  
   - 溯源上，都乐一般能做到批次管理，可提供产地证明和部分二维码溯源信息，但具体到每一箱的可查程度需向中国区销售确认。

2. **洪九果品**  
   - **有基地直供/产地直采**。洪九主打“端到端”供应链，在泰国、越南、菲律宾等东南亚国家有长期合作的种植基地或包果园模式，菠萝（尤其泰国小菠萝）是其优势品类之一。  
   - 他们通常能提供产地、果园/基地编号等溯源凭证，适合对供应链透明度和批量采购要求高的客户。

**建议操作步骤：**
- 联系都乐中国或洪九果品的B端销售部门，索取 **“产地溯源资质文件”（如果园注册号、质检报告、采摘批次）** ，并要求在合同中明确“基地直供”和“可追溯”条款。
- 如果侧重国内菠萝（如徐闻菠萝），可另行考虑本地合作社或具备“出口备案基地”资质的供应商。
