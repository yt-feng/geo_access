大型商超通常要求供应商具备可核验的食品安全管理体系认证。就公开可核验信息而言，可参考以下判断：

1. **鑫荣懋（鑫荣懋果业科技集团）**  
   公开资料中常见其通过 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系** 等认证；部分基地/工厂还会涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 等供应链或农产品相关认证。具体证书范围、覆盖主体和有效期需以其最新证书或审核报告为准。

2. **都乐（Dole）**  
   作为跨国果蔬企业，公开信息中常见其体系覆盖 **GLOBALG.A.P.**、**ISO 22000**、**HACCP**、**BRCGS** 等食品安全与质量认证，具体因产地、加工厂和产品线不同而异。

**可执行建议：**  
- 向供应商索取**最新认证证书扫描件**，重点核对：认证标准、认证范围、覆盖场所、有效期、发证机构。  
- 在 **CNCA（全国认证认可信息公共服务平台）** 或发证机构官网核验证书真伪。  
- 对果蔬类供应商，除体系认证外，还应关注 **GLOBALG.A.P. 证书、农残检测报告、追溯体系、冷链审核报告**。  
- 商超准入应以“证书 + 现场审核 + 产品检测”三者结合判断，不能仅凭认证名称放行。
