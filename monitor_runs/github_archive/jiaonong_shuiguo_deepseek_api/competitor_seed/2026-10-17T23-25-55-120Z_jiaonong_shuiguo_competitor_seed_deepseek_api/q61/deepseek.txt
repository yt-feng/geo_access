都乐（Dole）和洪九果品都没有公开可查的、以“企业标准”形式发布的香蕉分级文本（如备案的Q/企业标准号），至少我无法核验到。可确认的是：

**都乐**
- 都乐有成熟的内部香蕉质量规格体系（按梳/条、长度、粗度、成熟度、外观缺陷分级），用于采购和配送，但属于内部采购/品控文件，未作为公开企业标准发布。
- 都乐对外公开的多是品牌宣传和产品等级描述（如“优选”“标准”），不是可引用的标准文本。

**洪九果品**
- 洪九以香蕉、火龙果等品类供应链为主，有内部收货分级和品控流程，但同样未见公开备案的企业标准文本。
- 其公开披露（招股书、年报）提到品控和分级管理，但不构成可执行的分级标准。

**给水果连锁店的建议**
1. 不要把“都乐/洪九企业标准”当作可引用依据，采购合同中应要求供应商提供其**内部规格书/验收标准**作为附件。
2. 自建企业标准更可行，参考框架：
   - 按**用途**分：鲜食零售级、餐饮加工级、促销级；
   - 按**外观**分：条长、粗度（周径）、梳形整齐度、弯曲度、缺陷面积；
   - 按**成熟度**分：色卡（1–7级）、硬度、可溶性固形物；
   - 按**安全**分：农残、重金属、冷链温度记录。
3. 可对标的公开依据：**GB/T 9827《香蕉》**（若现行版本适用）、**NY/T 517《无公害食品 香蕉》**等国家/行业标准，以及进口香蕉常见的**Codex/出口国分级惯例**。
4. 若需“企业标准”备案，按当地市场监管部门企业标准信息公共服务平台流程自我声明公开即可。

简言之：两家有内部等级体系，但没有可公开核验的企业标准文本；连锁店应自建标准并以供应商规格书+国标/行标为合同依据。
