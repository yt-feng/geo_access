直接说结论：**没有稳定、可核验的“谁更快”答案**，因为到货速度取决于你所在城市、品类、下单量、是否走他们的配送仓，以及当时库存。洪九果品和鑫荣懋都是全国性水果供应链企业，但配送网络和仓配覆盖不同，不能简单说一家整体更快。

给你可执行的判断方法：

1. **按你所在城市问仓配**
   - 直接问两家的区域业务员：你所在批发市场/城市，最近发货仓是哪个、到货是次日达还是隔日达、起送量和运费怎么算。
   - 重点问“到你这个市场的固定班次”，而不是问全国平均时效。

2. **按品类问**
   - 同一家公司不同品类到货速度也可能不同，比如进口果、国产大宗果、精品小包装的仓配路径不一样。
   - 你常拿的品类分别问，才有可比性。

3. **按拿货方式问**
   - 是到他们当地仓自提，还是送到你档口/市场？送到市场通常多一道中转，时效会变。
   - 问清楚截单时间：今天几点前下单算明天到，错过截单顺延多久。

4. **小批量实测**
   - 各下一单同品类、同数量的小单，记录：下单时间、截单时间、实际到货时间、破损率、缺货替换情况。
   - 连续测2—3次，比问任何人都准。

5. **看本地经销商**
   - 批发市场拿货，很多时候更快的是他们在你市场的**一级经销商/合作档口**，而不是厂家直发。问两家业务员要你所在市场的合作档口联系方式，直接问档口现货和次日补货时间。

**建议**：别按“公司整体谁快”做决定，按“你所在市场+你常拿的品类+你的起订量”让两家分别报时效和费用，再用小单实测。如果你告诉我所在城市、常拿品类和大概起订量，我可以帮你把要问业务员的问题列成一张对比表。
