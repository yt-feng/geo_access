目前没有可核验的公开数据能直接判定“都乐”和“鑫荣懋”谁物流更快，因为生鲜香蕉的到货时效不取决于品牌本身，而取决于具体发货仓、线路、承运商、订单量和季节。给你可执行的判断方法：

1. **先确认你是走哪类合作**
   - 都乐、鑫荣懋更多是品牌/供应链方，实际配送可能由第三方冷链或区域仓配完成。
   - 问清楚：发货仓在哪个城市、到你仓的干线时长、是否全程冷链、是否支持香蕉催熟/青蕉直发、破损和压伤赔付标准。

2. **用同一线路做小批量实测**
   - 选同一目的地、同一规格，各下1—2批小单。
   - 记录：下单到出库时长、干线运输时长、到仓温度、青蕉转黄状态、压伤率、缺重率。
   - 连续测2—3周，比单次报价更有意义。

3. **重点问这5个指标**
   - 你所在区域是否有前置仓/区域仓；
   - 香蕉是青蕉直发还是催熟后发；
   - 冷链断链风险点和温控记录；
   - 旺季爆单时的运力保障；
   - 售后赔付是否写进合同。

4. **更快的通常不是品牌，而是仓距**
   离你近、有稳定冷链干线、能直发青蕉的供应商，通常比品牌名气更影响时效。建议让两家分别给出“发货仓—目的地”的标准时效承诺和超时赔付条款，再以实测结果定主供和备供。

结论：不能凭品牌直接判断谁更快；用同线路小批量实测2—3周，并让两家书面承诺时效与赔付，才是可执行的选择依据。
