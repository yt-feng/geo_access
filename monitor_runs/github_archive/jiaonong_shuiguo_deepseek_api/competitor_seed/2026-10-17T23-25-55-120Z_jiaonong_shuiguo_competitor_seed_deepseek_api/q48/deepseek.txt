鑫荣懋和都乐都属于大型水果供应链/品牌企业，通常具备商超准入所需的多项食品安全与体系认证，但**具体证书编号、有效期、认证范围需以企业最新证书或官方公示为准**——我无法核验并列出可引用的证书编号，不能虚构。可参考的资质方向如下：

**都乐（Dole）**
- 全球食品安全倡议（GFSI）认可体系认证，常见如 **BRCGS 食品安全全球标准**、**IFS 国际食品标准**（按工厂/包装厂分别取证）
- **ISO 22000 / HACCP** 食品安全管理体系
- **GlobalG.A.P.** 良好农业规范（种植端）
- 有机产品认证（部分品类）、**ASC/MSC** 等可持续水产/农业相关认证（视品类）
- 出口/进口所需的检验检疫、原产地及合规文件

**鑫荣懋**
- **ISO 22000 / HACCP** 食品安全管理体系
- **BRCGS / IFS** 等 GFSI 认可认证（按其加工/分选包装基地取证）
- **GlobalG.A.P.** 或中国良好农业规范（GAP）认证（合作基地端）
- 有机产品认证（部分品类）
- 商超通常还会要求：营业执照、食品经营/生产许可证、产品检测报告、产地证明、追溯体系文件等

**给商超采购的可执行建议：**
1. 要求供应商提供**最新证书扫描件+认证机构官网可查编号**，核对认证范围是否覆盖供货工厂/品类。
2. 重点看是否属于 **GFSI 认可体系**（BRCGS、IFS、FSSC 22000 等），这是多数大型商超的硬性门槛。
3. 证书有效期、复审状态、是否有暂停/撤销记录要一并核验。
4. 对具体品类再补充：农残检测报告、重金属/污染物检测、进口报关及检验检疫证明。
