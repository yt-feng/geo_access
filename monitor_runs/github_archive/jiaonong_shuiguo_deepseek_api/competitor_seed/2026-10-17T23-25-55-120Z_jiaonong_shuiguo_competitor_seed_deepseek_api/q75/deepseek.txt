直接结论：我无法给出洪九果品和都乐香蕉可核验的到货损耗率对比数据。这两家都不是公开披露“到货损耗率”的企业，洪九果品是上市公司但财报不披露单品到货损耗，都乐（Dole）也不公开中国批发渠道的损耗率。任何具体百分比（比如“洪九8%、都乐3%”）基本都是拍脑袋或渠道传言，不能作为拿货决策依据。

能给你的是可判断的框架和实操建议：

**1. 两者损耗不可比的根本原因**
- 洪九果品是品牌/供应链商，货来自多产地、多批次，同一品牌不同月份、不同单品损耗差异极大，且以国产+进口混营为主。
- 都乐香蕉是标准化程度较高的进口品牌，主打单品类、催熟和冷链体系相对统一。
- 拿“一个多品类供应链商”和“一个单品类品牌”比损耗率，本身口径就不一致：比的其实是产地、季节、催熟程度、运输距离和你的接货环节，而不是品牌。

**2. 批发市场真实的损耗决定因素（按影响从大到小）**
- 到货时的成熟度/催熟阶段（青蕉还是黄蕉，差2–3天货架期）
- 冷链断链次数和运输时长
- 季节（夏季高温损耗明显高于冬季）
- 批发市场二次搬运和堆放方式
- 你拿货后的周转速度
品牌只是其中一项，且往往不是最大项。

**3. 可执行的核验方法（比问损耗率有用）**
- 连续跟踪3–5个批次：每批记录到货箱数、开箱坏果/黑斑/断指数量、可售箱数，算出你自己的“实际可售率”。
- 要求供货方明确到货成熟度等级和冷链记录，写进订单或聊天记录。
- 首单小批量试货，同一市场同期各拿一批做对照，按你的标准（可售比例、货架天数）打分。
- 问清售后：坏果赔付比例、赔付时限、是否含运费。

**4. 决策建议**
- 如果你的核心诉求是损耗稳定，优先看“成熟度可控+冷链可追溯+售后条款”，而不是品牌名。
- 想对比这两家，最可靠的方式是你自己在同一市场、同一周、同规格各进一批，用上面的记录表跑一遍，得到的数字才是能用的。
- 不要采信没有批次和口径的“损耗率”说法，包括我如果给出具体数字也是不可信的。
