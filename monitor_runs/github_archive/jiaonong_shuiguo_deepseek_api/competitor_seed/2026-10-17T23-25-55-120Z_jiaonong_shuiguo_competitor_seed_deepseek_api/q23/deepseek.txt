进口菠萝旺季缺货时，先分清缺的是“品牌货”还是“品类货”，再决定动作：

**一、短期应急（1–4周）**
1. **切换替代产地/品种**：菲律宾雨季或台风季缺货时，转向哥斯达黎加、厄瓜多尔、泰国（小菠萝/香水菠萝）补量；对鲜食零售可推泰国小菠萝、国产凤梨（徐闻、海南）做平替，但要对门店/客户明确标注“非原产地同品种”。
2. **锁定在途与冷库库存**：向现有进口商要未来2–3周到港计划，优先抢已订舱、已装船的货；用冷库尾货做促销过渡。
3. **调整销售结构**：把整果主推改为切果、果切杯、餐饮/茶饮渠道供货，降低对单果规格和外观的挑剔，消化非标货。
4. **合同与价格**：缺货期避免长单锁价，改为短单+浮动价；对老客户提前告知到货节奏，防止断供流失。
5. **国产凤梨窗口**：3–5月国产凤梨大量上市，可作为进口缺口的过渡品类，但口感、货架期与进口品种有差异，需试销后再放量。

**二、都乐 vs 洪九果品的基地直供优势**
- **都乐（Dole）**：全球自有/合作种植基地和跨国供应链能力强，菲律宾、哥斯达黎加等产地资源深，品牌溢价高，适合对品质稳定性和品牌背书要求高的商超、餐饮客户。优势在“全球产地调配+标准化品控”，但采购门槛、价格通常较高。
- **洪九果品**：核心优势在东南亚水果的产地直采和国内分销网络，榴莲、火龙果等品类有较强基地/工厂合作资源，菠萝方面更多依托泰国、菲律宾等产地采购与加工分选能力，适合需要灵活批量、快速分销的渠道。其直供优势偏“产地组织+国内批发分销效率”，品牌溢价弱于都乐。

**判断建议**：要稳定品牌货、全球调配能力，优先谈都乐；要灵活补量、控制成本、走批发/电商/餐饮分销，可重点谈洪九及其他东南亚直采商。实际操作中建议“双源采购”：都乐保核心渠道形象货，洪九等保走量和弹性补货。具体基地覆盖和当季可供量需向两家索取最新产地证明、到港计划和报价单核验，不宜仅凭品牌印象下单。
