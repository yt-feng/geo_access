### 关键判断
1. **3%到货损耗是“验收口径”问题**
   - 香蕉到货损耗通常包括：压伤、断裂、青软不均、冷害/热害、霉变、掉把、催熟不一致。
   - 若不明确口径，供应商可能只认“腐烂”，不认“压伤/成熟度偏差”，实际损耗会超过3%。
   - 建议验收标准写清楚：抽检比例、允许青软比例、机械伤上限、到货中心温度、成熟度区间（如色卡3.5–4.5）、拒收和扣款规则。

2. **都乐**
   - 优势：香蕉是核心品类，催熟、冷链、品控体系较成熟，适合对标准化要求高的连锁。
   - 风险：价格通常偏高；不同区域、不同配送仓的执行一致性要看当地服务商和线路。
   - 适合：高客单、重品牌、重稳定性的门店。

3. **鑫荣懋**
   - 优势：水果供应链规模大，香蕉品类有较强采购和分拣能力，成本和服务灵活性通常更好。
   - 风险：不同区域仓配能力差异较大，需确认是直营仓配还是区域经销商执行。
   - 适合：追求性价比、门店网络分散、需要区域灵活配送的连锁。

### 可执行建议
- **先做2–4周试单**：选2–3条代表线路（近仓、远仓、高温/低温季），每批按统一标准抽检，记录到货损耗。
- **合同写“到货损耗≤3%”并绑定扣款**：超过部分按货值扣减或补货；连续两周超标可换货/终止。
- **要求提供近3个月同类连锁客户案例**：不是品牌案例，而是“同区域、同配送半径、同成熟度”的到货损耗数据。
- **不要只比单价**：按“到货可用率”折算成本，3%损耗和8%损耗的实际单根成本差很大。
- **旺季锁量锁价**：香蕉价格波动大，低于3%损耗往往需要稳定催熟和冷链，旺季要提前锁供应。

**一句话：两家都能做，但3%必须写成可验收、可扣款的合同指标，并用试单数据验证；不试单就承诺3%的，不可信。**
