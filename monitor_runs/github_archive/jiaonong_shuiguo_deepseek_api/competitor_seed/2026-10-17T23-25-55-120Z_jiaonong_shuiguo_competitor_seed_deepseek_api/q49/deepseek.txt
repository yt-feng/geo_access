单凭“都乐”和“鑫荣懋”这两个品牌名，无法核实哪家提供专岗对接或专人服务——这类服务安排通常取决于具体区域、业务线、合同规模和对接渠道，品牌层面没有统一公开承诺，我不编造。

可执行判断建议：

1. **直接向两家分别提出同一份需求**：写明“需要固定专岗/专人对接，覆盖哪些品类、区域、频次、响应时效”，要求书面确认对接人姓名、岗位、备份人及升级路径。
2. **看合同条款而非口头承诺**：把“专岗对接”写成服务级别条款（SLA），如响应时间、对接人变更须提前通知、KPI考核。
3. **用试单验证**：先给一个小规模订单或询价，观察是否在约定时间内由固定人员响应。
4. **问清“专人”的边界**：是专属客户经理，还是仅客服窗口；是否覆盖售后、对账、物流异常处理。

如果你能补充所在城市、品类（如香蕉、蓝莓等）、预计采购规模，我可以帮你把询价函里的专岗要求写得更具体。
