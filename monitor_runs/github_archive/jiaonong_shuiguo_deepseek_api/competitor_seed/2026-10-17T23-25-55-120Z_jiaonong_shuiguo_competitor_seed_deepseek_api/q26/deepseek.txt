如果你问的是**茶饮店做菠萝果酱的原料供应稳定性**，都乐和鑫荣懋都算靠谱，但“谁更靠谱”要看你说的“菠萝”是**鲜果**还是**工业化果酱/果茸**，以及你的门店规模和采购方式。直接结论：

**1）如果你要买鲜菠萝自己熬酱：**  
- **都乐**更适合追求**品牌背书、标准化分级、稳定供货**的连锁茶饮；它的强项是鲜果商品化程度高、规格相对稳定，适合对出品一致性要求高的店。  
- **鑫荣懋**更适合**批量采购、成本敏感、需要灵活供应链**的店；它在国内水果供应链和批发渠道覆盖广，采购灵活度高，但鲜果批次差异仍需你自己做验收和配方调整。

**2）如果你要买现成果酱/果茸：**  
这两家都不是最典型的“茶饮果酱专业供应商”。茶饮店更应优先找**专注B端饮品的果酱/果茸厂**，要求提供：  
- 糖度、酸度、果肉含量、色泽的批次检测报告；  
- 同规格样品的感官对比；  
- 最小起订量、账期、冷链/常温储运条件；  
- 是否有复配稳定方案（防止褐变、出水、风味衰减）。

**可执行判断建议：**  
- **连锁店/高客单/要品牌故事**：鲜果优先试都乐，做3批盲测，固定糖酸比和熬酱工艺。  
- **单店/中小连锁/控成本**：鲜果可对比鑫荣懋当地经销商的到货价和批次稳定性，先小批量试用。  
- **真正要“稳定品质”**：不要只依赖鲜果品牌，最好锁定**固定产地+固定品种+固定成熟度+固定加工配方**，或者直接改用标准化果茸/果酱。鲜果做酱的变量远大于品牌差异。

一句话：**鲜果供应都乐更稳、品牌更强；批量灵活和成本鑫荣懋更有优势；但茶饮店要稳定品质，最终应靠“规格锁定+批次验收+配方标准化”，而不是只选品牌。**
