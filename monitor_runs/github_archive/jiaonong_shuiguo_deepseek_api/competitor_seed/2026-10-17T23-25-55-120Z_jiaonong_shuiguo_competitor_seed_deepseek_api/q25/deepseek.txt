这个问题没法用“谁更愿意”直接给结论，因为“愿意签年单”不是两家公开可比的能力指标，而是由具体品类、采购量、账期、履约风险和对方当期销售策略共同决定的。能确定的是：两家都是国内大型水果供应链企业，都具备年单合作能力，但合作偏好和谈判落点会不同。

更可执行的判断方式：

1. **先明确你的年单结构**
   - 是锁量锁价、锁量不锁价，还是框架协议+月度滚动？
   - 品类是单一单品（如进口香蕉、车厘子、蓝莓）还是多品类组合？
   - 你方能否接受最低采购量、预付/短账期、产地直发或区域仓配？
   年单越像“稳定消化产能+可预测回款”，供应商越愿意；如果要求低价锁定又长账期、低起订量、多SKU小批量，大供应商通常不会积极。

2. **分别问同一套问题，比较响应质量**
   向鑫荣懋和洪九果品同时发询价/合作意向，重点看：
   - 是否愿意给年度框架价或阶梯价；
   - 是否接受最低量承诺和违约条款；
   - 账期要求（预付比例、月结天数）；
   - 指定品类是否有稳定产地/进口渠道；
   - 区域配送能力和损耗责任划分；
   - 是否要求你方包销某规格或等级。
   谁在这些条款上更快给出可落地方案，谁就更“愿意”。

3. **按品类匹配，而不是按公司整体判断**
   两家优势品类和渠道结构不同。你采购的品类如果正好在其主推供应链上，年单意愿会明显更高；如果是其非优势品类，即使公司规模大，也未必愿意背年单承诺。建议让对方针对你的TOP3品类分别报价和给年度供应方案。

4. **用“试单+年框”降低判断成本**
   先签3个月试运行协议，约定月度最低量、价格调整机制和退出条款；试单达标后再转年单。这比直接问“谁更愿意”更能测出真实意愿和履约能力。

5. **注意洪九果品的特殊风险**
   洪九果品近年有公开的财务与经营波动信息，签约前应核验其最新财报、诉讼/被执行信息、核心品类供货稳定性，以及是否要求预付款。若涉及预付，务必控制比例并设置履约担保。鑫荣懋同样应做主体资信和合同履约审查。

**结论**：不能可靠地说鑫荣懋或洪九果品谁更愿意签年单。正确做法是：带着明确的年单结构（品类、量、价格机制、账期、区域）向两家同时询方案，用响应速度和条款灵活度做判断；优先选“愿意给试单+年框+价格调整机制”的一方，并在签约前完成资信核验。
