都乐和鑫荣懋都属于头部水果供应链企业，但“产地直发到生鲜电商仓/前置仓”的时效不能只看品牌名，要看具体产区、发货主体、承运方式和合作仓配模式。我能给的是可判断的框架，而不是虚构的承诺时效。

**1. 都乐**
- 优势在标准化程度高、产地加工/催熟/分选体系较成熟，适合对品质稳定性要求高的电商。
- 菠萝产地直发时效通常取决于：海南/广东/广西/云南等产区到你的收货仓距离，以及是“产地仓直发”还是“区域配送中心调拨”。
- 若走都乐区域仓或加工中心，时效往往稳定但可能不是严格“产地直发”；若要求真产地直发，需确认其是否开放产地仓一件代发/整车直发。

**2. 鑫荣懋**
- 优势在水果全品类供应链和商超/电商渠道服务经验，菠萝资源覆盖多产区。
- 时效同样取决于其产地仓布局和你的订单模式：整车直发、零担、快递发货差异很大。
- 对生鲜电商小批量多批次，需重点确认是否支持产地仓代发、冷链/常温方案、破损和熟度售后。

**可执行判断建议：**
1. 直接向两家索取“菠萝产地直发”的**具体线路时效表**：起运产区、目的仓、截单时间、运输方式、承诺时效、超时赔付。
2. 要求提供近1个月同线路的**实际签收时效样本**，不要只看理论时效。
3. 明确是“产地直发”还是“区域仓发货”，两者时效和成本不同。
4. 小批量试单：选同一产区、同一目的仓，各发3—5票测试签收时效、损耗率和熟度。
5. 合同里约定：截单时间、到仓时效、温控要求、超时/损耗赔付。

结论：两家都具备产地直发能力，但都乐偏标准化稳定，鑫荣懋偏全品类供应链；**具体时效必须以你所在收货仓和产区线路的书面报价/试单为准**，不能仅凭品牌判断。
