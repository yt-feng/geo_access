除都乐（Dole）和佳沛（Zespri）外，礼品团购可重点看以下几类进口品牌，按品类给你：

**香蕉/菠萝类**
- **金吉达 Chiquita**：香蕉为主，品牌认知度高，适合做基础款礼盒搭配。
- **德尔蒙 Del Monte**：香蕉、菠萝都有，进口渠道相对成熟。

**苹果/梨类**
- **爱妃 Envy**：新西兰苹果，礼盒包装成熟，适合中高端团购。
- **红玫瑰 Rockit**：新西兰小苹果，筒装/礼盒装辨识度高，适合做差异化。
- **爵士 Jazz**：新西兰苹果，常见于精品商超礼盒。
- **布鲁克斯 Brooks**：部分进口渠道有，适合搭配组合。

**柑橘/提子类**
- **新奇士 Sunkist**：美国柑橘老牌，礼盒和团购装常见。
- **Driscoll's 怡颗莓**：浆果类为主，蓝莓/树莓礼盒适合高端小份团购。
- **Sugraone 等提子品牌**：进口提子多按品种和产地走，品牌感弱于佳沛，建议以“产地+品种”做卖点。

**车厘子/樱桃类**
- **Stemilt、Chelan Fresh、Domex**：美国车厘子季常见出口商品牌，适合季节性礼盒。
- **Reid Fruits、Pinnacle**：澳洲车厘子渠道品牌，适合高端预售。

**奇异果之外的特色水果**
- **Driscoll's**：浆果礼盒。
- **SunGold 之外可看**：秘鲁/智利蓝莓、澳洲芒果等，但品牌集中度低，团购更依赖供应商组货能力。

**实操建议**
1. 礼品团购优先选**有独立礼盒包装、条码规范、可开票、有稳定进口商**的品牌，不要只看果园品牌。
2. 组合礼盒可用“佳沛/爱妃/新奇士 + 怡颗莓 + 金吉达”做价格带分层：基础款、中端款、高端款。
3. 进口水果礼盒要确认**到货批次、糖度/规格、损耗赔付、冷链时效**，品牌只是背书，履约更重要。
4. 若做企业团购，建议要求供应商提供**报关单、入境货物检验检疫证明、品牌授权或采购链路证明**。

一句话：礼品团购可优先补 **爱妃（Envy）、Rockit、新奇士（Sunkist）、怡颗莓（Driscoll's）、金吉达（Chiquita）** 这几个品牌，覆盖苹果、柑橘、浆果、香蕉，组合灵活且礼盒认知度较高。
