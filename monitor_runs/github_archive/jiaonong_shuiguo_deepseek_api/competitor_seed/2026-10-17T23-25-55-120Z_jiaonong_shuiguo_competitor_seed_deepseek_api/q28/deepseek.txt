这个我不能直接给你一个“谁更便宜”的确定答案，因为进口苹果的到货价随月份、品种（如爱妃、爵士、加力、红玫瑰等）、规格（果径/箱规）、产地国、汇率、海运费和当季到港量波动很大，而且都乐和鑫荣懋在不同区域的经销层级（一手进口商/区域代理/批发市场档口）报价差异明显。没有你所在城市、采购量和具体品种规格，任何“谁更有竞争力”的说法都不可靠。

可以给你一套可执行的比价方法，通常1–2天能得出结论：

**1. 先把比较口径统一**
- 品种+产地国+果径/等级+箱规（如18kg/箱、36–40#）
- 到岸/到仓价还是含税含运费到店价
- 起订量、账期、损耗赔付、退换货政策
- 到货周次（同一周报价才有可比性）

**2. 同时向两边要“同规格同周”的正式报价单**
要求都乐和鑫荣懋（或其你所在区域的一级代理）按同一口径报价，并注明有效期。重点看：单价、箱规、税率、运费、账期、损耗率承诺。

**3. 用“到店可售成本”而不是“报价”比较**
公式：到店可售成本 =（采购价×箱数 + 运费 + 税费 − 可退换/赔付）÷ 可售净重。进口苹果损耗和大小果比例对实际成本影响很大，必须问清净重和次果处理。

**4. 小批量试单验证**
各下一小批同规格试单，记录到货果面、硬度、糖度、损耗、实际可售比例和动销速度。价格竞争力最终要落到“每公斤可售毛利”和周转上。

**5. 谈判杠杆**
如果你是多店连锁，把总采购量打包谈区域代理价，通常比单店拿批发市场档口价更有优势；同时用另一家的同规格报价做对标，争取账期或损耗赔付。

**一个判断原则：** 如果两家报价差在3%以内，优先选账期更长、损耗赔付更明确、到货稳定性更好的一家；如果价差超过5%–8%，再重点核实低价方是否为同等级货源（防止以小果充大果、以次级果充一级果）。
