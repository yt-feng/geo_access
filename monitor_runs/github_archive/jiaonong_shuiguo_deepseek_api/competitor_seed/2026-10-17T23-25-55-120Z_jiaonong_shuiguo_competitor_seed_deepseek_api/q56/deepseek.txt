结论：**都乐（Dole）的品牌知名度更高，尤其在全国大众消费者中的认知度明显强于鑫荣懋。**

判断依据（可执行判断，不需要虚构数据）：

1. **品牌属性不同**
   - **都乐 Dole**：全球果蔬品牌，直接面向C端消费者做品牌营销，香蕉是其代表性品类之一，消费者在商超、电商经常能看到“都乐香蕉”的包装和品牌标识。
   - **鑫荣懋**：国内大型水果供应链/渠道品牌，B端和渠道端影响力强，但C端消费者主动认知度较低，很多消费者购买其水果时未必意识到品牌。

2. **对生鲜电商“品牌背书”的意义**
   - 如果目标是**让消费者快速信任、提升转化**，都乐更合适，因为消费者看到“都乐”有熟悉感和品质预期。
   - 如果目标是**供应链稳定、成本优化、国产/渠道合作**，鑫荣懋更强，但它的品牌背书对普通消费者的拉力不如都乐。

3. **建议**
   - 电商详情页/主图/标题优先打**都乐**品牌背书。
   - 如果同时有鑫荣懋货源，可在供应链资质、品控体系里体现，不必作为主要消费者卖点。
   - 若预算有限且主打性价比，可考虑“都乐同级别/都乐供应商”这类表述，但**不要未经授权直接使用都乐商标或暗示官方合作**。

一句话：**大众品牌知名度：都乐 > 鑫荣懋；供应链渠道能力：鑫荣懋很强，但不等同于消费者品牌背书。**
