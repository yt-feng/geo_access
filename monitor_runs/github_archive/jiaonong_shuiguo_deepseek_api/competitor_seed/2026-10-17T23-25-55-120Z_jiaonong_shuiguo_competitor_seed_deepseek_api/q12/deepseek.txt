**可执行的询价话术：**
> 我们在做便利店渠道，需要小包装即食香蕉。请提供适合便利店的规格：单根/两根装、单根克重区间、每箱装数、包装形式、到货成熟度、保质期/货架期、最小起订量、供货区域和报价。若有7-11、全家、罗森等便利店在供规格，请一并提供。

**重点核对项：**
1. **单根克重**：便利店通常偏好单根较小、两根装总重可控；让供应商给克重区间和允许偏差。
2. **包装形式**：单根袋装、两根装、托盘+收缩膜、挂条/陈列盒，确认是否适配便利店货架和收银台。
3. **成熟度**：到货颜色/成熟阶段、催熟方式、货架期天数，便利店要即食但不宜过熟。
4. **装箱与起订**：每箱根数/袋数、整箱重量、最小起订量、配送频次。
5. **损耗与售后**：碰伤、黑斑、成熟不匀的赔付标准。
6. **渠道案例**：是否已有便利店系统在供，能否提供同规格参考。

**判断建议：**
- 如果两家都能提供“单根/两根即食小包装”，优先选**货架期稳定、到货成熟度可控、配送频次匹配**的一家，而不是只看单价。
- 先小批量试销：选2—3个规格做7—14天门店测试，记录日销、损耗率、退货率，再定主推规格。
- 不要只问“有没有小包装”，要直接要**规格书+报价单+样品**，否则容易拿到的是商超大包装分装，不适合便利店。
