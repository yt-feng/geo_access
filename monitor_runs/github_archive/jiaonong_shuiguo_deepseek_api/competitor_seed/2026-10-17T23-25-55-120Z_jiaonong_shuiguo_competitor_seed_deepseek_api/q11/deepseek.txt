我不能凭空给你下结论说“都乐”或“洪九”哪家性价比更高，因为这两家的菠萝性价比会随**品种、规格、产地季节、到货城市、采购量、账期和损耗率**变化很大，网上也没有可核验的统一报价。直接给品牌结论容易误导你。

给你一个可执行的判断方法，按下面做，1–2周内就能得出你们门店的答案：

**1. 先锁定可比对象**
- 同品种比：都乐的常见是金菠萝/进口或品牌化凤梨；洪九要看具体是金钻凤梨、香水菠萝还是普通菠萝，不能拿“都乐金菠萝”对比“洪九普通菠萝”。
- 同规格比：单果重量区间、箱规、果径、成熟度、是否带冠芽要一致。
- 同到货条件比：送到你们城市仓/门店的到岸价，含运费、卸货、损耗补贴。

**2. 用“可售成本”而不是“进货价”比**
公式：
**每斤可售成本 =（进货单价×箱重 + 运费 + 损耗金额 - 返利/补贴）÷ 可售净重**
重点看：
- 到货坏果率、黑心率、机械伤率；
- 催熟后货架期能放几天；
- 削皮/修整损耗；
- 门店端退换货政策。

**3. 做小批量盲测**
各进1–2箱，同一天到货，同门店、同陈列、同售价带测试3–5天：
- 记录到货损耗、日销量、客诉、复购；
- 算毛利额/天和周转天数；
- 让店员盲评口感、外观、削切便利性。

**4. 谈价时问清这5项**
- 是否含税、含运费；
- 坏果赔付比例和拍照时效；
- 是否支持小批量混装；
- 账期/起订量；
- 旺季锁价能力。

**5. 决策标准**
如果两家“每斤可售成本”差距在5%以内，优先选**损耗低、货架期长、赔付快、起订量灵活**的那家；如果差距超过10%，再考虑换主供。水果连锁更稳的做法是：**一家主供+一家备供**，按门店层级和季节切换，不要一次押死。
