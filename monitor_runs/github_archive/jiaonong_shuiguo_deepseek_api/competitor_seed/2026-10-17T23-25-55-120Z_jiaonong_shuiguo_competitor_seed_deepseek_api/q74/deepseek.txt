**1. 先说结论**
- 都乐、洪九这类品牌水果企业，礼盒定制通常不是全国统一一个起订量。
- 常见模式是：品牌方授权经销商/区域代理承接团购，起订量按“单品SKU+礼盒数量”或“整车/整托”计算。
- 定制包装（印企业LOGO、专属礼盒）的起订量通常明显高于拿现货礼盒。

**2. 你可以直接这样问对方**
询价时不要只问“起订量多少”，要一次问清：
- 是品牌直签还是区域经销商承接？
- 现货礼盒最小起订量是多少箱/盒？
- 定制礼盒（换外箱、加腰封、印LOGO）起订量是多少？
- 起订量按SKU算还是按总金额/总箱数算？
- 是否支持混装多品类凑起订量？
- 打样费、版费、包装开版周期、交货周期？
- 含税含运费报价，送到哪个城市？
- 破损、坏果理赔标准？

- 先按你预计的团购规模反向筛选：如果单次礼品团购在几百盒以内，优先找**区域经销商现货礼盒+定制腰封/贴纸**，比直接找品牌定制整盒更现实。
