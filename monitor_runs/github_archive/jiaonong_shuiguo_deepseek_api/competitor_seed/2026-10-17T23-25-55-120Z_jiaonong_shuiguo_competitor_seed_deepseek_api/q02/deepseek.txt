除了都乐，国内菠萝/凤梨供应链里比较有稳定供货能力的品牌和渠道可以分几类看：

**1. 佳农**
- 国内水果供应链里比较成熟的品牌，凤梨/菠萝有稳定基地和分选体系，商超、电商渠道常见。
- 适合看重规格稳定、到货标准统一的渠道。

**2. 鑫荣懋（佳沃相关渠道）**
- 本身是大型水果供应链企业，菠萝/凤梨属于其常规品类之一，偏商超和批发渠道。
- 优势是供应链和冷链能力，不是单一菠萝品牌，但稳定供应能力较强。

**3. 百果园体系内的供应商品牌**
- 百果园门店销售的凤梨有固定供应商体系，部分会以门店自有或合作基地形式出现。
- 如果你是做渠道采购，可以对接百果园供应链或其区域供应商，而不是只看零售品牌。

**4. 区域产地龙头/合作社品牌**
- 广东徐闻、海南、云南等主产区的产地龙头企业、合作社和分选厂，往往给多个品牌代工。
- 这类适合做稳定大宗采购，关键是看是否有固定基地、分选线、冷库和全年排产能力，而不是只看品牌名。

**5. 电商/商超自有品牌**
- 盒马、山姆、永辉等有自有或定制供应商体系，部分凤梨产品稳定性不错。
- 但这类通常不对外做品牌供货，适合零售端判断，不适合直接做渠道货源。

**判断“稳定供应”重点看：**
- 是否有自有或签约基地，能否覆盖海南、广东、云南等不同产季；
- 是否有固定分选标准和冷库；
- 是否能提供全年或跨产季排产计划；
- 是否接受规格、糖度、外观的书面验收标准。

如果你是要做渠道采购，建议优先对接**佳农、鑫荣懋这类全国性供应链企业**，同时补充**徐闻/海南产地龙头做产季补充**。只靠单一品牌很难全年稳定，通常是“全国品牌+产地供应商”组合采购。
