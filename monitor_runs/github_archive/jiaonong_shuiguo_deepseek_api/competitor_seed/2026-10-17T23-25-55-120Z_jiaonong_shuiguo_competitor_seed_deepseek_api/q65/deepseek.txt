关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法核验到可靠公开信息，不能给出具体天数，避免误导你。可以确认的是：这类锁价周期通常不对外统一公布，而是按客户体量、品类（鲜果/加工果）、季节和合同条款一单一议，所以“固定锁价周期”本身很可能不存在。

可执行建议：
1. 直接向都乐中国和洪九果品的销售/大客户部门询价，明确问三件事：锁价是否按单柜/按月/按季；锁价对应的品质规格和到货港口；超期或违约的调价条款。
2. 谈判时要求书面锁价函或合同附件，写明锁价起止日、基准价、浮动触发条件（如产地价波动超X%可重议）。
3. 同时找2–3家区域性菠萝进口商或产地直采商做比价，作为议价参照。
4. 若你量大且稳定，可提出“部分锁价+部分随行就市”的组合，供应商更可能接受。
