我没法核验都乐和洪九果品当前对小包装/散装的具体供货政策，不能给你确定的“有/没有”结论。可执行的做法是直接向渠道确认，并按下面问法一次问清：

1. **都乐（Dole）**：问当地经销商或区域销售  
   - “香蕉是否有适合社区团购的**小包装/散装称重**规格？最小起订量、每箱净重、是否可混装？”
   - “能否提供**按根/按把/按小袋**的预包装？包装克重范围？”
   - “社区团购渠道是否开放？是否需要企业资质、冷链自提点要求？”

2. **洪九果品**：问区域业务或官方客服/经销渠道  
   - “香蕉有没有**散装称重**或**小规格箱装**？最小起订量和配送频次？”
   - “是否支持社区团购的**小包装代包**或**预包装贴标**？”
   - “到货成熟度、损耗赔付和售后标准是什么？”

3. **判断建议**  
   - 若对方只给大箱：可让本地供应商做**分装代包**，但需确认香蕉催熟度、分装损耗和食品安全责任。  
   - 优先选**预包装小规格**，比散装称重更适合团购履约，减少称重和损耗争议。  
   - 要求先拿**样品箱**测损耗、成熟度和复购，再定长期供货。
