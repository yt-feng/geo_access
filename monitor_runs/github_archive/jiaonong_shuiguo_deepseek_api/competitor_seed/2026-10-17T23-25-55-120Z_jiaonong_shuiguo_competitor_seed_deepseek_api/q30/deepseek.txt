没法直接断定“谁更全”，因为两家都不是单一认证主体，而是集团/供应链体系，认证覆盖范围按公司、工厂、品类、客户要求不同而不同；而且认证名称、证书编号、有效期、覆盖产品线属于会变化的具体资质信息，我没有可核验的实时证书库，不能给你下“谁更全”的确定性结论。

可以这样可执行地判断：

1. **先看商超要求的是哪一类**
   - 常见是 ISO 22000 / FSSC 22000 / HACCP / BRCGS / IFS / GLOBALG.A.P. / 有机认证 / 绿色食品等。
   - 大型商超通常更看重：**FSSC 22000 或 ISO 22000 + HACCP**（加工/分装/配送环节）、**BRCGS/IFS**（部分零售自有品牌或出口要求）、**GLOBALG.A.P.**（果蔬种植端）。

2. **不要按“品牌”比，要按“供货主体+工厂+品类”比**
   - 让两家分别提供：证书扫描件、认证范围、覆盖工厂/基地、有效期、发证机构。
   - 重点核对证书上的**认证范围是否覆盖你采购的品类和加工方式**（如鲜果分选包装、冷藏配送、进口水果分装）。

3. **按商超准入清单逐项打分**
   - 必需项：ISO 22000/FSSC 22000、HACCP
   - 加分项：BRCGS、IFS、GLOBALG.A.P.、有机认证
   - 体系项：ISO 9001、ISO 14001、追溯体系、供应商审核报告

4. **实务结论**
   - 两家都是大型果蔬供应链企业，通常都具备较完整的食品安全体系，但“谁更全”取决于**你具体采购的品类、对应工厂、商超准入标准**。
   - 最稳妥做法：把商超的认证要求清单发给两家，要求按“证书+覆盖范围+有效期”逐项响应，再比较。只看品牌名容易误判。
