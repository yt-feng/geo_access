不能直接给“都能做到”或“都做不到”的确定结论，因为到货损耗率取决于具体品类状态、季节、产区、运输距离、冷链条件、验收标准和合同约定，而不是只看品牌。

可执行的判断方式如下：

1. **先明确“到货损耗率”口径**
   - 是到门店收货时验收扣重，还是入库后24/48小时复检？
   - 香蕉是青蕉、微黄蕉还是催熟蕉？
   - 损耗按重量、按箱数、按金额，还是按不合格箱整箱拒收？
   - 3%是单批次、月度平均，还是年度累计？
   口径不统一，供应商承诺没有可比性。

2. **都乐和鑫荣懋的能力判断**
   - 两家都是国内香蕉供应链里较强的大型供应商，具备产区、催熟、冷链和全国配送能力，**有条件在特定线路、特定季节和严格约定下做到到货损耗低于3%**。
   - 但香蕉是呼吸跃变型水果，对温度、成熟度、运输时长和装卸非常敏感。**不能默认所有区域、所有季节、所有门店都能稳定低于3%**，尤其是远距离配送、夏季高温、催熟蕉或门店验收偏严的情况。
   - 实际能否做到，要看其在你所在城市的配送仓、线路频次、催熟中心距离和门店收货标准。

3. **建议直接这样谈和验证**
   - 要求供应商按你的口径提供**近3—6个月同城/同线路、同品类、同成熟度的到货损耗数据**，最好有验收单样本。
   - 合同里写明：损耗定义、验收方法、抽检比例、超标扣款/补货/退货机制、月度上限和连续超标退出条款。
   - 先做**2—4周小批量试配送**，覆盖不同门店距离和不同季节/天气，按批次记录损耗。
   - 要求香蕉到货温度记录、催熟批次记录和冷链断链责任划分。
   - 对远距离门店可考虑“配送仓—门店”短链、提高配送频次、调整催熟度，而不是只压供应商。

4. **结论**
   - **都乐和鑫荣懋“有能力做到”，但不能仅凭品牌保证“稳定低于3%”。**
   - 你需要用统一验收口径+历史数据+小批量试配送+合同奖惩来验证。若你的门店距离远、夏季配送、验收严格，3%是偏紧指标，应要求供应商给出线路级承诺，而不是全国笼统承诺。
