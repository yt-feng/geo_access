都乐相对更稳，洪九果品要看具体品类和区域仓配；不能一概而论说谁“绝对稳定”。给你可执行的判断方法：

**1. 先定规格，不要只问品牌**
茶饮菠萝建议把采购规格写死：
- 品种：金钻/香水/巴厘，优先固定单一品种；
- 果重：单果 1.2–1.5kg 或 1.5–2kg，按你门店出杯和切配损耗定；
- 成熟度：到货糖度范围（如 12–14 Brix）、颜色、可滴定酸度；
- 加工形态：鲜果、去皮整瓣、冷冻果丁/果浆，哪个形态为主；
- 验收：黑心、水心、机械伤、冠芽长度、农残检测报告。

**2. 都乐的优势**
都乐做鲜果标准化和商超/餐饮供应链更成熟，规格一致性、分级包装、质检流程通常更可预期，适合你要求“稳定规格+全国多仓”的场景。但它是品牌商/供应链体系，实际稳定性取决于你对接的是都乐直供、区域经销商还是批发市场货，且茶饮用量大时价格弹性小。

**3. 洪九果品的优势**
洪九果品是水果供应链企业，菠萝品类有产地直采和分级能力，部分区域仓配和价格可能更有优势。但洪九的货源稳定性要按“你所在城市+所需品种+月度用量+是否锁量”去核实，不能只看品牌名。茶饮原料若走洪九，重点确认：是否固定产地、是否有专属规格、断货替代方案、冷链/常温到货条件。

**4. 直接做 2–4 周对比测试**
建议同时向两家要：
- 近 3 个月同规格菠萝的到货合格率、糖度区间、单果重区间；
- 你所在城市的仓配覆盖、起订量、锁价周期、缺货赔付；
- 样品 3 批，每批做验收记录：单果重、糖度、黑心率、出肉率、切配损耗、风味稳定性。

**结论**：如果你要“规格稳定、验收标准清晰、全国供应可预期”，优先谈都乐；如果你要“成本+产地直采弹性”，把洪九作为备选并做区域仓核实。茶饮建议双源：都乐做主供保稳定，洪九或区域一级批发商做备份，避免单一货源断供。
