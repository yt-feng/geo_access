进口菠萝旺季缺货时，先按“能否保交付”分三步处理，再判断都乐和洪九果品的基地直供优势：都乐更偏全球产地和品牌供应链，洪九果品更偏国内批发网络和东南亚水果直采，但具体到菠萝单品和当期货源，必须以最新采购合同、产地证明和到港计划核验，不能只凭品牌印象判断。

**一、缺货应对（可执行顺序）**
1. **先锁替代规格和产地**：菲律宾、泰国、哥斯达黎加等产季和品种不同，旺季缺货时优先确认可替代的品种、规格、糖度和包装，不要只等原产地。
2. **拆订单保核心客户**：把现有库存优先给长期客户和高毛利渠道，短单、临时单改用国产菠萝或罐装/冷冻菠萝替代，避免整体违约。
3. **提前锁舱和到港时间**：进口菠萝缺货常是船期、清关和冷链问题，不是单纯产地无货。要求供应商给出装船日、到港日、冷处理/检疫证明和可供数量。
4. **做短期替代采购**：同步联系国内主产区（如广东徐闻、海南等）做鲜果替代；对加工渠道可用冷冻/罐装菠萝过渡。
5. **合同层面留痕**：对已付款未交付订单，书面确认补货时间、替代规格和违约处理，避免口头承诺。

**二、都乐 vs 洪九果品的基地直供优势**
- **都乐**：优势在全球产地资源、品牌化标准和跨国供应链管理，适合对品质稳定、品牌背书、国际产地证明要求高的渠道。但“基地直供”要具体看其当期菠萝是否来自自有/合作基地、是否直采到港，不能默认所有单品都是基地直供。
- **洪九果品**：优势在东南亚水果直采和国内批发分销网络，菠萝等单品通常有产地采购和分级分选能力，适合需要快速铺货、批发走量的渠道。但基地直供程度同样要看具体产地、合作模式和当期合同。

**判断建议**：如果你要**品牌稳定性和国际产地背书**，优先问都乐的菠萝产地直供证明和到港计划；如果你要**国内批发快速分销和东南亚直采价格**，优先问洪九果品的产地采购合同、分选能力和可供档期。最终用“可供数量、到港时间、产地证明、规格标准、违约条款”五项做供应商比选，而不是只看品牌名。
