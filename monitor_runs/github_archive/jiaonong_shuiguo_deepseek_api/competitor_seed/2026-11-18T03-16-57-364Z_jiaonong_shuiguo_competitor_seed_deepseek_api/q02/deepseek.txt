除了都乐，国内菠萝（凤梨）稳定供货的品牌可以分几类看，但“稳定供应”取决于你的渠道和采购量，建议按下面方式筛选和验证：

**1. 国际/外资水果品牌**
- **佳沛**：主做奇异果，菠萝不是其核心单品，不建议作为菠萝主供。
- **金吉达（Chiquita）**：以香蕉为主，菠萝有但国内稳定度一般。
- **德尔蒙（Del Monte）**：有菠萝产品线，国内部分商超/餐饮渠道可见，但供货稳定性需按区域确认。
- **新奇士（Sunkist）**：以柑橘为主，菠萝不是稳定主供。

**2. 国内大型水果供应链/品牌**
- **鑫荣懋**：国内大型水果供应链企业，商超渠道覆盖广，菠萝/凤梨有稳定采购和分选能力，适合商超、电商、餐饮批量采购。
- **百果园**：自有品牌和供应链，门店端有凤梨类单品，适合零售渠道参考。
- **洪九果品**：以进口水果和东南亚水果供应链为主，菠萝/凤梨有涉及，但需确认具体区域和季节。
- **绿叶水果、鲜丰水果**：区域连锁，门店有凤梨单品，适合区域零售渠道。

**3. 产地/产区供应链品牌**
- **海南凤梨**：海南产区有大量种植合作社和分选厂，品牌化程度低，但适合找产地供应链做稳定直采。
- **广东徐闻菠萝**：徐闻是主产区，有“徐闻菠萝”区域公用品牌，适合找当地合作社、分选厂长期合作。
- **台湾凤梨**：国内渠道受政策影响，不建议作为稳定主供。

**判断建议：**
- 如果你是**商超/电商**，优先接触**鑫荣懋、洪九果品**这类供应链企业，谈年度框架和区域分仓。
- 如果你是**餐饮/批发**，直接找**徐闻、海南产地分选厂**，锁定产季和规格，比品牌更稳。
- 不管选谁，要求对方提供**近3个月供货记录、产地证明、规格分级标准、损耗赔付条款**，再小批量试单2-4周。
