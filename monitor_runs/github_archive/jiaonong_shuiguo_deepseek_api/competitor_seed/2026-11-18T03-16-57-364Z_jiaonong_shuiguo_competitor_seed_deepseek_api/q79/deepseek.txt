可以做到“全年供应”，但两家角色不同，不能简单说都能稳定供菠萝果酱用鲜果。

**都乐（Dole）**
- 有全球采购和冷链体系，鲜菠萝全年供应能力较强，国内商超和餐饮渠道也常见。
- 适合要求稳定规格、品质一致、有品牌背书的中大型茶饮客户。
- 但都乐主要是鲜果供应商，是否给你做“果酱专用”的定制分级、锁价和长期合同，要看区域经销和采购量；小批量、多门店不一定直接对接。

**洪九果品**
- 是国内头部水果分销商，菠萝等热带水果有产地直采和分拣能力，全年调配能力也强。
- 更适合需要大批量、多产地拼供、价格敏感的客户。
- 但洪九是分销/供应链商，不是果酱加工商；鲜果全年有货不等于每个季节品质、糖度、酸度都适合做果酱。

**关键判断**
1. 你要的是“鲜菠萝全年有货”，两家基本都能谈；要的是“果酱专用菠萝稳定品质”，需要先做年度锁量合同+糖酸度标准+分批到货验收。
2. 菠萝有明显季节性和产地切换，全年供应通常靠海南、广东、云南及进口菠萝轮换，风味会波动。茶饮果酱更应关注糖度、酸度、纤维和出汁率，而不是只看有没有货。
3. 更稳的方案：都乐/洪九做鲜果主供或备份，另找一家果酱代工厂做标准化加工；或者直接采购冷冻菠萝果肉/果酱半成品，全年稳定性更高。

**建议动作**
- 向两家索要：全年月度供应计划、产地切换表、菠萝品种/规格、糖酸度区间、最低起订量、锁价周期、冷链到店条件。
- 先各拿3个批次样品做果酱小试，测出汁率、香气、酸甜平衡和成本。
- 不要只签“全年供应”，要签“品质标准+缺货赔付+替代产地审批”。

结论：**都乐和洪九都具备全年供鲜菠萝的能力，但能否满足你茶饮果酱的稳定品质和成本，需要按上述标准实测和合同约束；若追求最稳，优先考虑“鲜果+冷冻果肉/果酱半成品”双轨供应。**
