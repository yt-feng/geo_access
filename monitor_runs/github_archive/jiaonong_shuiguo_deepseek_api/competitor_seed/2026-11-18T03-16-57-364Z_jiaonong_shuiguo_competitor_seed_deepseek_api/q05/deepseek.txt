这个选择不能只看“谁名气大”，要按你们茶饮店的长期合作条件来判断。结论先说：**如果你们要的是全国稳定供应、标准化和食品安全体系，偏都乐；如果要的是更灵活的价格、账期和重服务，洪九可以重点谈，但必须把品控和违约条款写死。** 对茶饮店“大量菠萝原料”这个场景，通常都乐的风险更低，洪九的商务弹性可能更大，需要实地比价和试单。

建议按下面几项做判断：

1. **供应稳定性**
   - 都乐：品牌化、供应链体系成熟，适合门店多、要求批次稳定的连锁茶饮。
   - 洪九果品：国内水果分销规模大，菠萝是重要单品之一，但具体到你们城市的到货频次、规格稳定性要问清楚。
   - 可执行动作：要求双方提供过去6个月同规格菠萝的月度供货记录、产地切换方案、缺货替代方案。

2. **规格和出成率**
   茶饮店大量用菠萝，核心不是“到货价”，而是**每公斤出成率**。要统一问：
   - 单果重量区间、糖度范围、成熟度、黑心/水心比例；
   - 去皮去芯后出成率；
   - 是否可做鲜切、冷冻果块、果茸或NFC果汁；
   - 次果率和赔付标准。
   让两家各报“到货价+出成率+损耗赔付”，再折算成**每杯可用原料成本**，这比单价比价更准。

3. **食品安全和资质**
   都乐在标准化和追溯上通常更占优；洪九要看具体供应商和批次管理。必须核验：
   - 营业执照、食品经营/生产相关许可；
   - 农残检测报告、批次检测频率；
   - 冷链温度记录；
   - 追溯码或批次追溯能力；
   - 是否接受第三方抽检。

4. **价格与账期**
   - 都乐通常价格体系更规范，议价空间可能小；
   - 洪九在商务政策、账期、返利上可能更灵活；
   - 但茶饮店长期合作最怕“低价切入、后期降质”。合同里要约定价格调整机制、质量不达标扣款、断供赔偿。

5. **合同关键条款**
   建议无论选谁，都写清：
   - 月度最低供货量和最高锁价量；
   - 规格、糖度、成熟度、次果率上限；
   - 到货时限和冷链要求；
   - 质量不合格的退换货、扣款和赔偿；
   - 产地/品种变更需提前通知并重新确认；
   - 价格随行就市时，设置涨跌幅上限和提前报价周期。

**实操建议：**不要直接二选一签长期。先让都乐和洪九各供**2—4周试单**，用同一套验收表记录到货合格率、出成率、损耗、售后响应和实际每杯成本。若你们是跨区域连锁、对食安和稳定最敏感，优先都乐做主供；若单城门店、追求成本和账期，可让洪九做主供或备供，但必须保留第二供应商。长期合作更稳妥的结构是：**一家主供+一家备供**，避免单一供应商断供或坐地起价。
