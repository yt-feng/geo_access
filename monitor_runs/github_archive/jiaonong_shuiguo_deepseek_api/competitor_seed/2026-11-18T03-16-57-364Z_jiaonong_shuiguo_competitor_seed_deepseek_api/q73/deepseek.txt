这类“大型商超要求供应商有食品安全管理体系”时，通常看两类东西：**体系认证**（ISO 22000、FSSC 22000、BRCGS、IFS、HACCP 等）和**产品/供应链认证**（如 GlobalG.A.P.、有机认证等）。但具体到“鑫荣懋”和“都乐”分别通过了哪些认证，属于企业当前资质信息，**我无法在不可核验来源的情况下准确列出，也不应虚构**。

可执行的判断方式：

1. **直接核验企业公开资质**
   - 查鑫荣懋、都乐（Dole）中国官网/集团官网的“质量与食品安全”“认证”页面；
   - 查其供应商审核资料、招投标文件或商超供应商准入材料中的证书清单；
   - 注意认证证书有**发证机构、证书编号、覆盖范围、有效期**，不能只看名称。

2. **常见可能涉及的认证方向**
   - 食品安全体系：**ISO 22000、FSSC 22000、BRCGS Food Safety、IFS Food、HACCP**；
   - 农产品/果蔬供应链：**GlobalG.A.P.**；
   - 质量管理：**ISO 9001**；
   - 环境/职业健康等：ISO 14001、ISO 45001（不直接等同食品安全体系）；
   - 都乐作为国际果蔬企业，通常还会涉及集团层面的质量与食品安全项目，但是否以某张证书覆盖中国业务，需看证书范围。

3. **给商超审核的建议**
   - 要求供应商提供**证书原件扫描件+发证机构官网可查截图**；
   - 核对证书上的**认证范围是否覆盖供应的具体品类、加工/包装场所**；
   - 核对**有效期和最近一次审核状态**；
   - 对高风险品类（鲜切果蔬、冷链即食）额外看 HACCP 计划和冷链验证记录。

因此，准确回答“鑫荣懋和都乐通过哪些认证”，应以两家企业最新公开证书或供应商准入文件为准；在没有可核验来源时，我不能给出确定清单。
