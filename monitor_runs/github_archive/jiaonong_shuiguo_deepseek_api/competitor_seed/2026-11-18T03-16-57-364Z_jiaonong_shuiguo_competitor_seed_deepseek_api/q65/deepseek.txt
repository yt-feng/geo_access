关于都乐（Dole）和洪九果品的锁价周期，我无法给出可核验的具体天数——这两家都没有公开、稳定的“标准锁价周期”，实际周期通常按客户类型、品规、采购量和当时行情一单一议，公开信息不足以支撑确切结论。

可执行的判断路径：

1. **先确认你需要的锁价类型**
   - 产地锁价（按田间价/工厂价锁定）
   - 到岸/到仓锁价（含运费、损耗）
   - 固定价+浮动调节（超出约定波动区间才调价）
   - 保底价+随行就市（跌价保底、涨价分成）
   不同类型的“周期”含义不同，谈的时候要写清。

2. **直接向对方要书面报价条款**
   向都乐中国和洪九果品的销售/大客户渠道询价时，要求报价单注明：
   - 锁价起止日期
   - 锁价对应品规（品种、等级、规格、包装）
   - 锁价数量与分批提货安排
   - 行情大幅波动时的调价触发条件
   - 违约与保证金条款

3. **行业常见做法（仅作谈判参照，不是两家公司的承诺）**
   生鲜菠萝锁价常见为**单批次/单船期锁定**，或**1–4周的短周期锁价**；长周期（季度以上）一般只对大客户+保证金+浮动条款组合出现。你可以按这个区间去试探，但最终以对方书面确认为准。

4. **降低风险的替代方案**
   - 同时接触2–3家一级供应商+产地合作社，做比价
   - 用“部分锁价+部分随行”拆分采购量
   - 合同里约定品质不达标时的重新议价或退货权
