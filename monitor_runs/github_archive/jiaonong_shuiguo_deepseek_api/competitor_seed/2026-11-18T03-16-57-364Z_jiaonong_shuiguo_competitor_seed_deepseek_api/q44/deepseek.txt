我不能核验都乐和鑫荣懋当前的供货稳定性数据，所以不能给你“谁更稳”的确定结论。但可以给你一套水果连锁可执行的判断方法，避免拍脑袋上架。

**结论先说：**  
都乐和鑫荣懋都是国内进口水果头部供应链企业，整体履约能力通常强于普通贸易商；但“供货稳定性”要按**单品、产地、季节、你所在城市、你的采购量级**分别看，不能按品牌一概而论。建议你先小批量双供应商并行，用4—8周实际到货数据再定主供。

**可执行的评估清单：**

1. **问清具体单品和产地**
   - 进口苹果要明确：是新西兰、美国、智利、南非还是其他产地；品种是嘎啦、富士、爱妃、布瑞本等。
   - 不同产地有淡旺季和船期波动，稳定性的答案完全不同。

2. **要求对方提供近3个月履约数据**
   - 可订货率、准时到货率、缺货提前通知天数、到货合格率、损耗率。
   - 不要只看“有没有货”，要看**缺货时提前多久通知**和**替代方案**。

3. **确认你所在区域的仓配能力**
   - 问清楚服务你门店的是哪个区域仓、配送频次、最小起订量、冷链覆盖范围。
   - 同一供应商在不同城市的稳定性差异可能很大。

4. **做双供应商并行测试**
   - 建议主供60%—70%，备供30%—40%，跑4—8周。
   - 记录：到货准时率、缺货次数、规格达标率、坏果率、售后响应时长。

5. **合同里写死关键条款**
   - 缺货提前通知时限、替代品规则、品质不达标退换货、损耗赔付、价格调整机制。
   - 对进口苹果尤其要约定规格、糖度、果径、色泽和包装标准。

6. **关注港口和船期风险**
   - 进口苹果受海运、清关、港口拥堵影响。问对方是否有多港口、多产地备货能力。
   - 单一产地依赖度高的供应商，旺季稳定性风险更大。

**给你的建议：**  
先不要直接定“都乐还是鑫荣懋”，而是让两家都针对你计划上架的**具体苹果单品**报价并提交履约方案，选2—3个门店做4周试销。用数据打分：准时到货率40%、品质合格率30%、缺货通知与替代能力20%、售后响应10%。谁的综合得分高，谁做主供。这样比问“哪家稳定”更可靠。
