都乐和洪九果品的礼盒定制起订量没有公开统一标准，会随品类、包装形式、区域仓、是否贴牌、采购季节和对接渠道变化。直接给具体数字容易误导你。可执行判断如下：

1. **都乐**
   - 常规礼盒：通常以“整箱/整托”起订，零售散装礼盒少量可谈，但定制企业Logo、专属卡纸/腰封、指定果径和混装组合，一般需要较大批量。
   - 定制贴牌：通常要求按单品或组合装达到一定箱数，且很多区域只接企业团购/渠道客户，不接极小批量。
   - 建议直接问：①常规现货礼盒最小起订箱数；②企业Logo定制最小量；③混装礼盒每SKU最小量；④是否含设计打样费；⑤到货仓和账期。

2. **洪九果品**
   - 以批发和渠道分销为主，礼盒定制通常按整件/整托起订，企业专属包装一般要求更高起订量。
   - 单品礼盒和混装礼盒的起订规则可能不同，进口果、国产果、反季果差异大。
   - 建议直接问：①团购礼盒最小起订量；②可否混装及每款最低数量；③定制腰封/外箱的最低量；④打样周期和打样费；⑤区域配送门槛。

**谈判建议：**
- 先报你的真实需求：预计总盒数、单盒预算、果品组合、交付城市、交付时间、是否需要LOGO和专属包装。
- 不要只问“起订量多少”，要问“**常规现货最小量**”和“**定制包装最小量**”两套数字。
- 如果单量小，可先做“现货礼盒+定制腰封/贴纸/手提袋”，通常比全定制外箱门槛低。
- 同时找都乐、洪九的当地经销商/区域团购负责人询价，同一品牌不同经销商起订量可能不同。

由于我无法核验这两家当前具体政策，不能给你确定的箱数；建议以你所在城市对应销售人员的书面报价为准。
