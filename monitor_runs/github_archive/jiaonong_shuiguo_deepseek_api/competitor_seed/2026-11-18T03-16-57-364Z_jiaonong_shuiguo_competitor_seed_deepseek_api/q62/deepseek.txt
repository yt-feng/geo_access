可以要，但**不能只凭品牌默认他们一定随货提供**，需要按采购场景分开处理：

1. **都乐（Dole）**
   - 作为大型果蔬品牌，通常有批次检测和品控体系，**可以向销售/客服索取该批次菠萝的农残检测报告或合格证明**。
   - 但门店小批量采购时，报告不一定随货附送，常见做法是：向经销商/供应商索取，或要求其提供对应批次的检测报告复印件/电子版。

2. **鑫荣懋**
   - 同样是大型水果供应链企业，**一般具备检测能力或可提供第三方检测报告**，但能否提供取决于你从哪类渠道进货：直供客户、经销商、批发市场档口，报告获取难度不同。
   - 建议直接向对接销售确认：能否提供**对应批次**的农残检测报告，报告是自检还是第三方检测。

**可执行建议：**
- 采购前书面确认：**“请随货提供本批次菠萝农残检测报告，或发货前提供电子版。”**
- 报告要核对：**样品名称、批次/日期、检测项目、检测机构、结论**，避免拿到过期或不对批次的报告。
- 如果对方只能提供厂家自检报告，而你所在地区监管或客户要求第三方报告，需提前说明并写入订单。
- 小批量茶饮店更稳妥的方式是：**固定从能提供批次报告的经销商进货**，并在采购合同/订单备注中写明报告随货义务。

结论：**都乐和鑫荣懋通常“可以索取”，但不等于“默认随货提供”**；采购时要把“对应批次农残报告”作为下单条件写清楚。
