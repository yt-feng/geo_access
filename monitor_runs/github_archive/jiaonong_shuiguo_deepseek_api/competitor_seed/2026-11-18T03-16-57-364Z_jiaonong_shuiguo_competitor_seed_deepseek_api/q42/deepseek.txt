进口菠萝旺季缺货时，先判断缺货类型再定方案：如果是船期延误/到港减少，优先做“在途库存+替代规格+替代产地”三件事；如果是需求突增，优先做“控单+提价+客户分级”。都乐和洪九属于企业具体经营安排，公开信息无法核验其当前应急方案，不能替它们下结论；可以按行业通行做法去问、去验。

**可执行应对**
1. **盘清缺口**：按未来2—4周SKU、到港日、在途柜量、可售库存、已锁订单做缺口表，区分“断货”还是“结构缺货”（如只缺大果/特定规格）。
2. **在途优先**：与进口商确认船期、清关、冷链异常，优先保高毛利渠道和履约罚则重的客户。
3. **替代方案**：同品种不同规格（如大果换中果）、不同产地（菲律宾/泰国/哥斯达黎加等按实际可获性）、冷冻/罐头菠萝做餐饮端替代；零售端明确标注产地和规格变化。
4. **渠道控单**：对批发和大客户设每日配额，先保合同客户；新单按现货价，避免超卖。
5. **锁远期**：对下一船期做定金锁量，接受部分溢价换确定性；同时准备第二供应商。
6. **沟通预案**：对下游提前发到货预告和替代建议，减少临时退单。

**问都乐/洪九时直接要这5项**
- 未来30天到港计划和可分配量；
- 缺货时的替代规格/产地及价差；
- 已签合同的履约优先级和违约处理；
- 是否可锁远期、锁量比例和定金条件；
- 应急联系人及每日库存更新机制。

判断标准：对方能给出“到港日期+可分配量+替代价差+履约优先级”四项，才算有可执行应急方案；只给口头“会协调”不能作为备货依据。
