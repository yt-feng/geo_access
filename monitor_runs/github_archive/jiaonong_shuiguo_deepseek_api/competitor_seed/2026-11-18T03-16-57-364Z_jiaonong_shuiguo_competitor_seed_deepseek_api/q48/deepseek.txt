**1. 先明确商超通常认哪些资质**
大型商超对果蔬供应商通常关注：
- 营业执照、食品经营/生产相关许可（按业务模式）
- 食品安全管理体系认证，如 **ISO 22000** 或 **FSSC 22000**
- **HACCP** 体系认证
- 农产品/食品相关认证，如 **绿色食品、有机认证、GAP/GlobalG.A.P.**（看品类和商超要求）
- 出口或特定客户要求的 **BRCGS、IFS** 等
- 检测报告、产地证明、合格供应商审核资料

不同商超、不同品类、不同门店系统要求不一样，不能只看“有没有证”，还要看认证范围是否覆盖供货产品、证书是否在有效期内、认证机构是否被认可。
