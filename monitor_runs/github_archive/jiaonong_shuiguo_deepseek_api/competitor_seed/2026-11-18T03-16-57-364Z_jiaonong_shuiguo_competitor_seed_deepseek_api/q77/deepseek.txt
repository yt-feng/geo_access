都乐和洪九果品都**没有公开、可核验的“便利店香蕉小包装”专用环保包装方案**，不能直接说“有”。可执行判断如下：

1. **都乐**
   - 都乐有香蕉小包装产品，也有可持续包装/减塑方向的公开表述，但是否用于便利店渠道的单根/小把香蕉包装，需要向都乐区域销售或经销商确认。
   - 可重点问：是否提供无塑纸标签、FSC认证纸带、可堆肥膜、减薄PE膜、可回收单一材质膜；起订量、加价、是否支持门店品牌联名。

2. **洪九果品**
   - 洪九以水果供应链和批发分销为主，公开信息中未见其香蕉小包装环保包装的明确方案。
   - 便利店采购应直接向其渠道销售确认：是否有单根/小把香蕉的纸带捆扎、纸浆模塑托、可回收膜或可堆肥袋方案；是否只做散装/大箱。

3. **便利店可落地做法**
   - 优先选**纸带捆扎+纸质标签**，减塑最直接；
   - 若需保鲜膜，要求**单一材质可回收PE/PP膜**，避免PVC；
   - 小包装用**FSC认证纸托/纸浆模塑托**；
   - 合同里写明包装材质、可回收标识、供应商需提供检测报告或材质声明。

**结论：** 两家都需向供应商逐项确认，不能默认有现成环保小包装。建议先让都乐和洪九各报“单根/3根/5根”便利店规格及包装材质方案，再对比起订量和加价。
