结论：在中国市场做生鲜电商平台品牌背书，**都乐（Dole）的品牌知名度更高，更适合作为面向消费者的“品牌背书”**；鑫荣懋是强势的**供应链/渠道品牌**，但在普通消费者端的品牌心智明显弱于都乐。

判断依据（可执行口径）：
- **消费者认知**：都乐是全球化果蔬品牌，香蕉、菠萝等品类有长期零售曝光和包装识别度，消费者在货架/页面看到“都乐”更容易形成品质联想。鑫荣懋更多被B端、零售采购和行业认知为供应链与渠道品牌，C端品牌露出和记忆点较弱。
- **背书场景**：如果背书用于商品详情页、主图、搜索词、直播话术，优先用“都乐香蕉/都乐品牌授权或直采”这类消费者能秒懂的表达。鑫荣懋更适合放在“供应商实力、产地直采、品控体系”模块，而不是作为主要消费者背书。
- **风险提示**：品牌知名度不等于你一定拿到授权。是否能用都乐做背书，取决于平台是否有**品牌授权、直采合同或官方合作证明**；没有授权不要在主图/标题写“都乐”，可写“都乐同产区/同品种”也需谨慎，避免侵权和虚假宣传。

建议落地：
1. 主背书选**都乐**，用于前台转化；鑫荣懋放后台或详情页“供应链实力”部分。
2. 先确认授权链路：有授权则打“都乐官方合作/授权直采”；无授权则不打品牌名，改打“菲律宾/厄瓜多尔等产区+AAA级/单根果指规格+催熟标准”。
3. 如果平台定位偏B端或强调稳定供应，可双品牌表达：前台都乐背书，详情页写“鑫荣懋供应链/品控支持”（前提是合作真实可证）。

简言之：**C端背书选都乐，供应链背书可提鑫荣懋；没有授权就不要把品牌名当背书使用。**
