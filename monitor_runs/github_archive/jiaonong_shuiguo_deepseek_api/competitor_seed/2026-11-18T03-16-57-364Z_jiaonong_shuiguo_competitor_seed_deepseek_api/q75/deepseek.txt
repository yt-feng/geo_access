到货损耗率没有公开、可核验的统一数据，**不能直接给出“洪九 vs 都乐”的准确对比数字**。批发市场拿货时，损耗率受批次、季节、产地、运输距离、冷链、包装、到货成熟度、验收标准影响很大，同一品牌不同批次也可能差很多。

可执行的判断方式：

1. **按“同一市场、同一周、同规格”做小批量对比**
   - 各拿 3～5 箱，记录：到货总重、开箱烂果/压伤/青硬/过熟重量、可售重量。
   - 到货损耗率 =（不可售重量 ÷ 到货总重）× 100%。
   - 连续做 3 批以上再比较，单批没有代表性。

2. **重点看香蕉的“到货成熟度”而非只看品牌**
   - 都乐通常标准化和冷链管理较成熟，但批发市场到货批次差异仍大。
   - 洪九果品品类多、渠道广，香蕉批次之间稳定性要看具体产地、催熟和运输链路。
   - 若到货青硬，短期损耗低但后熟风险高；若到货偏黄，即时损耗高但周转快。

3. **验收时分开记录损耗类型**
   - 压伤、黑斑、断把、掉把、霉变、过熟、青硬不熟。
   - 压伤和断把通常与包装/装卸关系大；霉变与冷链和箱内湿度关系大；过熟与催熟和运输时间关系大。

4. **批发拿货建议**
   - 先小批量试单，不要一次压大货。
   - 要求看同批次开箱样，记录箱内上下层差异。
   - 谈清楚“到货损耗谁承担、多少比例内可换货”。
   - 同一供应商连续跟踪 3～5 批，建立自己的损耗台账，比问品牌平均值更可靠。

结论：**没有可公开核验的洪九果品与都乐香蕉到货损耗率对比数据；建议用同批次小批量实测建立自己的损耗率，通常都乐标准化程度较高，但具体仍以你所在市场和当批到货为准。**
