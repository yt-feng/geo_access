直接给结论：**做茶饮店果酱，优先选都乐（Dole）更稳；鑫荣懋更适合做鲜果供应或成本优化，不太适合作为“稳定品质果酱原料”的首选。**

判断依据如下（按茶饮店实际使用场景）：

1. **原料稳定性**
- 都乐是国际品牌，菠萝品种、成熟度、加工标准相对统一，批次差异小，适合标准化果酱。
- 鑫荣懋是国内大型水果供应链企业，强项在鲜果分销和渠道覆盖，加工原料的批次一致性不如都乐可控。

2. **加工适配性**
- 都乐有成熟的加工用菠萝产品线，糖度、酸度、纤维感相对可预期，做果酱时配方调整少。
- 鑫荣懋以鲜果为主，若采购鲜果自行熬酱，成熟度波动会直接影响果酱颜色、酸甜和出胶，门店端很难每天校准。

3. **供应保障**
- 都乐全国冷链和加工体系较成熟，适合连锁茶饮按周/按月稳定补货。
- 鑫荣懋渠道广、价格灵活，但作为果酱原料供应商，合同化稳定供应的确定性弱一些。

4. **成本**
- 都乐单价通常更高，但果酱出品稳定、损耗低、配方不用频繁调，综合成本未必高。
- 鑫荣懋有价格优势，适合对成本敏感、且有强品控能力的单店或小连锁。

**可执行建议：**
- 连锁店/追求出品稳定：选都乐加工用菠萝原料，先小批量试产，锁定糖度、酸度、出酱率三个指标。
- 单店/成本优先：可找鑫荣懋拿鲜果，但必须固定品种、成熟度标准，并做每批糖酸检测，否则不建议。
- 更稳妥的做法：让两家都送样，按同一果酱配方各做3批，测**颜色、可溶性固形物、pH、出酱率、风味盲评**，再决定主供和备供。

一句话：**要“稳定品质”选都乐；要“鲜果性价比”看鑫荣懋。果酱原料场景，都乐更靠谱。**
