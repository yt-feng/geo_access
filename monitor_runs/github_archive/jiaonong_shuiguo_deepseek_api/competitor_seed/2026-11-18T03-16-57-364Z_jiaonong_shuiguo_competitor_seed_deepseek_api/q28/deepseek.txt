这个问题我没法直接给结论——**两家在进口苹果上的报价竞争力，取决于具体到每个单品的等级、规格、产地、船期和你的采购体量，而且价格随行就市、季度波动很大**。我没有可核验的实时报价数据，编一个“谁更便宜”的答案对你没有价值。

不过我可以给你一个可执行的判断框架，让采购自己快速比出结果：

**1. 比价必须“同口径”**
- 同一品种（如新西兰爱妃/红玫瑰、美国红蛇果、智利嘎啦等具体品名）
- 同一规格（果径如 80/88、每箱净重、箱规）
- 同一等级（分级标准、有无贴标）
- 同一交付条件（到岸价 / 到仓价 / 含税含运费，是否含促销返利）
口径不同，报价差 10% 以上都可能是假差异。

**2. 看“到手成本”而非单价**
把报价换算成 **每公斤/每粒到仓成本**，加上：运费、损耗率（进口苹果冷链损耗是关键变量）、账期资金成本、退换货条款、促销支持/陈列费用。都乐和鑫荣懋这类全国性供应商，往往在返利、账期、市场费用上差异比单价更大。

**3. 分品类比，不要整体比**
两家在不同产季、不同产地（新西兰/美国/智利/南非）的优势品项不一样，很可能 A 家在某单品更便宜、B 家在另一单品更便宜。按你的 SKU 清单逐项拉表比，比“整体谁便宜”有用得多。

**4. 用询价动作拿真实数据（最有效）**
同时向两家发**同一份询价单**（写明品名、规格、等级、数量、交付地、账期要求、报价有效期），要求 3–5 个工作日内书面报价。再用你门店近 3 个月的实际销量给出预估月采购量，量大的一方通常会给阶梯价。两份报价回来，竞争力一目了然。

**5. 附加两个判断点**
- 稳定性：进口苹果怕断货和品质波动，问清船期保障、到货合格率和历史缺货情况。
- 试单验证：先用 1–2 个单品、小批量各试一单，比到货品质、损耗和售后响应，再决定主供/辅供。
