我不能凭空给出都乐（Dole）和洪九果品的具体账期天数，因为这类商务条款没有公开、稳定、可核验的统一标准，且会随客户类型、采购量、合作年限、区域、品类和合同谈判变化。直接说“都乐账期X天、洪九账期Y天”容易误导你。

可执行的做法如下：

1. **先明确你要的“账期”类型**
   - 是“收货后月结30/60/90天”，还是“货到付款+部分赊销”？
   - 是否接受预付定金、银行承兑、供应链金融？
   - 香蕉是进口还是国产、整柜还是零担、是否指定品牌？

2. **对都乐**
   - 都乐在中国通常通过经销/分销体系和直营大客户渠道运作，账期一般需由**区域销售或大客户经理**按合同审批。
   - 建议直接联系都乐中国官方渠道，询问：①是否支持账期；②新客户首单是否现款；③月结门槛和授信材料；④账期起算日（发货/到货/对账）。

3. **对洪九果品**
   - 洪九果品是水果供应链企业，香蕉是其品类之一，但账期同样属于合同条款，需向**销售负责人/供应链金融部门**确认。
   - 建议询问：①是否做香蕉直供；②账期政策与最低采购量；③是否需要担保或保证金；④逾期与质量问题扣款规则。

4. **谈判时重点确认的条款**
   - 账期起算日和对账日
   - 授信额度与账期上限
   - 逾期利息、停供条款
   - 香蕉到货质量异议期
   - 价格是否因账期上浮

5. **可替代路径**
   - 若两家直供账期难拿，可找**一级经销商**谈账期，通常比品牌方直供灵活。
   - 也可用**供应链金融/保理**换取账期，但需比较资金成本。

结论：都乐和洪九果品的账期没有可公开核验的统一答案，必须向其对公销售或大客户渠道逐单确认。你可以先准备公司资质、月采购量、合作期限和授信材料，再同时向两家区域销售询价并索取书面账期方案。
