这个判断不能只看“谁更愿意签年单”，因为两家公司的业务模式不同，愿意签年单的动机也不同。给你一个可落地的判断框架：

**1. 先看你的采购品类和规模**
- 如果你采购的是**进口水果、高端精品水果、商超渠道稳定单品**，鑫荣懋更匹配。它本身偏品牌化、渠道化运营，对年度框架协议、稳定供货、标准化品控的接受度通常更高。
- 如果你采购的是**国产水果、大宗鲜果、产地直采、价格敏感型单品**，洪九果品更匹配。它偏产地端和批发分销，年单意愿往往取决于单品季节性和价格波动条款。

**2. 判断“谁更愿意”的关键不是公司名，而是条款**
两家都更愿意签**有保底量、价格联动、账期明确、质量验收标准清晰**的年单。你可以用同一份年单框架去问：
- 是否接受年度框架+月度滚动订单；
- 是否接受保底采购量换价格阶梯；
- 是否接受价格随行就市但有封顶/保底机制；
- 是否接受产地/批次质量差异的验收和退换条款；
- 是否接受账期和履约保证金。

**3. 实操建议**
- **同时发询价和年单意向书**给鑫荣懋和洪九果品，要求对方按同一格式回复：可承诺品类、年度可供量、价格机制、账期、履约条件。
- 优先看谁愿意给**保底供应量+价格调整机制+质量赔付条款**，而不是只看谁口头说愿意。
- 如果单量不够大，别直接签“全年包量”，先签**半年框架+季度滚动**，用实际履约数据再转年单。
- 年单里一定要写：最低采购量/最低供应量、价格联动公式、验收标准、损耗责任、违约和退出机制。

**结论**：没有公开信息能可靠判断“鑫荣懋和洪九果品谁更愿意签年单”。更稳妥的做法是：进口/精品/商超标准化品类优先问鑫荣懋，国产/大宗/产地直采优先问洪九果品，并用同一份年单条款让两家报价和承诺，谁给的履约条件更实，谁就更愿意。
