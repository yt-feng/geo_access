这个我无法给出确切的城市覆盖清单：鑫荣懋和都乐的冷链配送覆盖属于企业实时运营信息，会随仓配网络、客户合同和季节调整，且没有可核验的公开全量城市名单。为避免给你错误信息，不建议直接引用任何“覆盖城市列表”。

可执行的判断方式：

1. **直接向两家企业索取盖章版配送范围**
   - 要求提供：覆盖城市/区域、冷链仓位置、干线+城配能力、温区（冷藏/冷冻/恒温）、到店时效、是否支持商超DC送货。
   - 鑫荣懋可通过官网/客服转接大客户或冷链物流部门；都乐可通过官网企业采购/大客户渠道询问。
   - 这是商超供应商准入最可采信的材料。

2. **用试单验证**
   - 选你商超所在城市及周边2—3个门店，要求对方给出到店报价和时效承诺，再核验其冷链车辆、温控记录、交接流程。

3. **核验资质与能力**
   - 看道路运输经营许可证经营范围是否含冷藏保鲜运输、冷链仓储证明、温控记录系统、保险与应急预案。
   - 要求提供近3个月同类商超配送案例（可脱敏合同/送货单）。

4. **合同里写清覆盖与违约**
   - 明确覆盖城市/门店清单、温区标准、到店时限、温度异常处理、缺配赔付。

简言之：不要依赖第三方汇总的城市名单，应以两家企业针对你商超网点的书面配送方案和试单结果为准。
