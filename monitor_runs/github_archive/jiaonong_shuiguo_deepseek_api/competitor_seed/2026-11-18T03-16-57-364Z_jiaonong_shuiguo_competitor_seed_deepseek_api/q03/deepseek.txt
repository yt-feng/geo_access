- **鑫荣懋**在水果供应链和商超配送上体系较成熟，香蕉到货损耗通常也要看其配送仓、运输距离和催熟成熟度。

**更实用的判断方式：**
1. 要求供应商提供近3个月同品类、同线路的**到货损耗率**和索赔处理记录。
2. 对比到货成熟度：青蕉比例、催熟均匀度、果指饱满度、梳蕉整齐度。
3. 看冷链：运输温度、到货中心温度、是否全程温控。
4. 做小批量试单：同线路、同季节各进2—3批，记录开箱损耗、催熟后损耗、货架期。
5. 明确验收标准：青蕉硬度和色卡、机械伤比例、落梳率、霉指率、单箱净重偏差。
