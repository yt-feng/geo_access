结论先说：**如果只看“菠萝规格稳定 + 长期供应可预期”，都乐更适合做长期主供应商；洪九果品更适合作为补充或短中期备选。**  
但两家都不是“签了就稳”，菠萝原料长期合作的关键不在品牌，而在于**规格书 + 分级验收 + 锁价/调价机制 + 备选产区**。建议采用“都乐主供 + 洪九/区域果商备供”的双源结构。

### 对比判断

| 维度 | 都乐 | 洪九果品 |
|---|---|---|
| 品牌与标准化 | 强，适合连锁茶饮做稳定规格和品牌背书 | 国内水果供应链规模大，品类广，价格和区域灵活 |
| 菠萝供应稳定性 | 进口菠萝体系成熟，规格和成熟度相对可控 | 国内及进口水果分销能力强，但菠萝不是其唯一核心单品，长期专供稳定性需看具体区域和季节 |
| 规格一致性 | 更偏标准化分级，适合写进验收标准 | 需更细的到货抽检和批次管理，不同产区/批次差异要盯 |
| 价格 | 通常偏高，品牌和稳定性的溢价 | 价格弹性更大，适合比价和补充 |
| 长期合作风险 | 成本较高；进口受汇率、海运、产地天气影响 | 批次波动、区域调货依赖较强，需明确违约和替换条款 |
| 适合角色 | 主供，尤其对门店多、SOP要求高的茶饮品牌 | 备供/比价/区域补货 |

### 建议的合作结构

1. **都乐做主供**：锁定核心规格，如品种、单果重量区间、成熟度、糖度、果肉色泽、出成率、农残标准、到货温度、破损率上限。
2. **洪九做备供**：约定同规格书报价，季度比价，主供断货时48—72小时内补位。
3. **不要只按品牌采购**：茶饮用的菠萝要看出汁率、纤维感、酸甜比、去皮损耗。先做小批量盲测和出成率测试，再谈年度框架。
4. **合同写死四件事**：规格验收标准、批次抽检比例、不合格退换货时限、价格调整触发条件（产地价/汇率/运费波动超过多少可调）。
5. **保留第三备选**：广东徐闻、海南等国产菠萝产区可作为季节性补充，降低单一进口依赖。

### 直接决策

- **门店多、追求出品稳定、愿意付溢价**：选都乐主供。
- **成本敏感、采购团队强、能自己做验货**：洪九可给更高份额，但必须加严验收。
- **最稳妥**：都乐60%—70% + 洪九20%—30% + 国产产区10%左右做弹性补充。

不建议只签一家。菠萝受季节和产地波动影响大，长期合作的核心是**双源+规格书+抽检机制**，而不是单纯选品牌。
