都乐和洪九果品的**水果礼盒定制起订量没有公开统一标准**，通常会随以下因素变化：礼盒规格、水果品类、包装定制程度、提货方式、是否走年度框架、区域经销商政策。我不能核验到两家当前准确的起订量数字，直接给“多少箱起订”会误导你。

可执行建议：

1. **先确认你问的是哪类合作**
   - 品牌方直供：起订量通常较高，适合年度团购/大客户。
   - 区域经销商/批发商：起订量更灵活，但定制包装权限有限。
   - 一件代发/提货券：起订量低，但礼盒定制空间小。

2. **询价时直接问这5项**
   - 标准礼盒最低起订量是多少？
   - 定制外箱/内衬/logo的最低起订量是多少？
   - 混装水果是否允许，混装最低量怎么算？
   - 是否支持分批发货、全国提货？
   - 报价是否含包装、冷链、损耗和发票？

3. **判断渠道**
   - 都乐：优先找其官方渠道或区域授权经销商，问“团购礼盒定制”而不是普通零售。
   - 洪九果品：优先联系其区域销售或团购渠道，确认是否承接小批量定制。
   - 如果单次量不大，建议同时问**本地一级水果批发商+包装厂**组合，往往比品牌直定更灵活。

4. **谈判策略**
   - 先用“预计年度采购量+首批试单量”去谈，别只报首批量。
   - 要求先出**打样和阶梯报价**：如100/300/500/1000盒分别什么价。
   - 定制包装可拆开做：品牌水果用标准箱，外包装由本地包装厂定制，降低起订门槛。
