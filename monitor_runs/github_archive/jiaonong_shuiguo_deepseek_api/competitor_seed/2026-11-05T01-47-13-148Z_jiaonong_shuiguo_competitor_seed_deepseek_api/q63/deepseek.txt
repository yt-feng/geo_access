这个我没法替你确认到“当前是否有散装/小包装现货和起订量”这种会随渠道和档期变化的信息，也不能编造都乐、洪九的具体包装规格。给你可执行的核验和替代方案：

**1）先按包装形态向供应商问清这4项**
- 是否有“散装称重”或“小包装固定规格”（如按根/按把/净重袋装）
- 最小起订量、是否支持混装、是否按箱结算
- 到货形态：整箱散装、预包装袋装、还是气调/催熟后分装
- 损耗与售后：青蕉/熟蕉比例、压伤赔付规则

**2）都乐**
都乐在零售端常见预包装香蕉，但社区团购是否能拿到“散装称重”或小规格，取决于当地经销商/批发渠道，不取决于品牌统一政策。建议直接联系都乐当地经销或一级批发商，问“社区团购小包装/散装称重是否有专供规格”。

**3）洪九果品**
洪九以水果供应链和批发分销为主，是否有散装或小包装要看具体城市仓和客户类型。建议向洪九当地销售确认“团购渠道最小包装单元”和“是否可做门店分装”。

**4）更稳的落地做法**
- 若两家都要求整箱起订：让本地批发商做“二次分装”，你按净重袋/把装售卖，注意标注净重和保存条件。
- 找本地香蕉催熟商或批发市场档口做小规格代分装，通常比品牌直供更灵活。
- 先小批量测试2-3种包装：散装称重、净重袋装、按把装，看损耗和复购再定。

**判断标准**：能拿到“固定净重小包装+明确损耗赔付+稳定周供”的渠道优先；只有整箱散装且无赔付的，不建议直接做团购小包装。
