大型商超通常要求供应商具备食品安全管理体系认证，**鑫荣懋和都乐（Dole）的官方认证清单需要以各企业最新公开披露或审核时提供的证书为准**，我不能凭印象虚构具体证书编号或认证范围。可判断与可执行的建议如下：

1. **鑫荣懋**
   - 公开信息中，鑫荣懋作为水果供应链企业，通常会被商超要求具备 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点** 等体系认证；部分生鲜/果蔬供应商还会涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 或 **FSSC 22000** 等。
   - 但具体“通过哪些认证”应以鑫荣懋提供的有效证书、认监委/认证机构查询结果，或商超供应商准入审核材料为准。

2. **都乐（Dole）**
   - 都乐作为跨国果蔬企业，常见食品安全与质量体系包括 **GLOBALG.A.P.**、**HACCP**、**ISO 22000**、**BRCGS** 等；不同产地、品类、加工厂可能认证不同。
   - 同样不能笼统说“都乐整体通过了某认证”，因为认证通常按法人、工厂、产品范围或基地签发，需看具体证书范围。

**建议你直接这样核验：**
- 要求供应商提供**有效认证证书扫描件**，重点看：认证标准、认证范围、覆盖产品/工厂、有效期、认证机构。
- 到**全国认证认可信息公共服务平台**（国内认证）或认证机构官网核验证书真伪。
- 对进口果蔬，核对 **GLOBALG.A.P. 注册号**、**BRCGS 目录**等可公开查询信息。
- 在商超供应商准入表中，把“食品安全管理体系认证”列为必填并附证书，而不是只接受企业口头说明。
