这个我不能给你“拍脑袋”的稳定性结论，因为两家在不同口岸、不同品类、不同季节的到货表现差异很大，且我没有可核验的实时履约数据。直接说谁更稳，容易误导你。

但可以给你一套可执行的判断方法，一周内能拿到结论：

**1. 先明确“稳定性”指什么**
对进口苹果门店端，稳定性主要看四项，谈的时候分开要数据：
- 到货准时率：约定周几到、实际偏差几天
- 到货合格率：烂果率、规格偏差、糖度/硬度抽检
- 缺货替代方案：断货时能否同价换规格/品种
- 旺季保供：春节前、9-11月新果季的锁量能力

**2. 对两家做同一口径的试单对比**
不要只谈框架协议，直接下 2-3 个 SKU、连续 4 周的小批量订单，按同一张表打分。重点看：
- 首单到货偏差天数
- 每批抽检烂果率（建议抽 3 箱/批）
- 临时加单 20% 的响应时间
- 缺货通知提前量（提前 3 天以上才算合格）

**3. 问清供货模式，这决定稳定性**
- 是产地直采锁量，还是口岸现货调货？现货调货在旺季波动大。
- 进口苹果主要看新西兰、南非、智利等产季衔接，问清“青黄不接”月份从哪国补。
- 是否自有冷库/口岸仓，还是第三方代发。

**4. 合同里写死稳定性条款**
- 准时率低于约定值（比如 95%）的违约金或补货义务
- 烂果率超标整批退换，运费谁承担
- 旺季月度锁量数字，写进附件
- 断货提前通知时限

**5. 别只押一家**
水果连锁更稳的做法是“主供+备份”：都乐、鑫荣懋可一主一备，按区域或 SKU 分配，保留 20%-30% 份额给备选。这样单家出问题时门店不断货。
