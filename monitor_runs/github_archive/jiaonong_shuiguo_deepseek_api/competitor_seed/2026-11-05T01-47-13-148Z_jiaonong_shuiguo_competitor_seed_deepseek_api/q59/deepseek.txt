我不能确认都乐（Dole）和洪九果品当前对外提供的账期天数。这类条件通常按客户规模、采购量、合作年限、结算方式、是否直采/经销、区域和合同条款单独谈，公开信息往往不写具体账期，直接给数字容易误导。

可执行的判断和建议：

1. **不要按“行业通用账期”报价**
   - 香蕉属于生鲜，损耗和价格波动大，供应商对新客户通常更谨慎。
   - 常见做法是先款后货、预付部分+到货结清，稳定合作后再谈月结，但具体天数必须由对方书面确认。

2. **向都乐和洪九分别问清以下条款**
   - 账期起算日：发货日、到货日、验收日还是对账日
   - 账期天数：Net 15/30/45/60 等
   - 是否有最低采购量、保证金、授信额度
   - 逾期利息、断供条款、质量异议扣款规则
   - 是否含税、运费、损耗承担
   - 是否要求先试单或现金结算若干周期

3. **核验路径**
   - 都乐：通过其中国区官方渠道或当地经销商询价，确认是直营还是经销体系。
   - 洪九果品：通过其官方销售渠道或区域分公司询价；上市公司公开披露通常不包含单个客户账期。
   - 要求对方提供盖章报价单/框架合同，账期以书面为准，不接受口头承诺。

4. **替代方案**
   - 同时询价大型批发市场一级香蕉经销商、产地合作社、区域供应链公司。
   - 可要求“部分账期+保证金”或“银行/供应链金融授信”模式，降低对方风险。
   - 新供应商先做小批量试单，稳定后再争取账期。
