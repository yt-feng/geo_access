可以要求，但不能默认一定有、更不能默认“给了报告就等于合格”。采购时建议这样判断：

1. **都乐、鑫荣懋通常能提供农残检测报告**
   - 两家都是大型水果供应链企业，一般会有批次检测或委托检测报告。
   - 但报告通常是**按批次/产地/供应商**出具，不是“品牌一份报告全年通用”。
   - 茶饮店采购的是菠萝原料，需确认是**鲜果**还是**鲜切/冷冻/果酱/果汁**，不同形态报告不同。

2. **签约前必须书面确认**
   - 要求供应商在报价单或合同里写明：**随货提供该批次农残检测报告**。
   - 明确报告类型：第三方 CMA/CNAS 检测报告，或供应商自检报告。
   - 明确检测项目：至少覆盖菠萝常见农残，如有机磷、拟除虫菊酯类等；具体项目按你所在地区监管和客户审核要求确定。
   - 明确报告与**到货批次号/生产日期/产地**对应。

3. **到货验收要核对**
   - 报告上的品名、批次、生产/采摘日期、供应商名称要与实物一致。
   - 报告不能是过期、无盖章、无检测机构资质、项目不全的“复印通用版”。
   - 鲜切菠萝还要关注加工环节的微生物和冷链记录，不只看农残。

4. **可执行的采购话术**
   - “请确认贵司菠萝原料可随货提供与到货批次对应的农残检测报告，报告需有检测机构盖章/资质标识；如为自检报告，请说明检测项目和频次。”
   - “请在合同中约定：无法提供对应批次报告时，我方有权拒收或要求换货。”

**结论：** 都乐和鑫荣懋大概率能提供，但你要按“批次对应、第三方优先、合同约定、到货核验”来落实。不要只问“能不能提供”，要问“能否随每批货提供对应报告”。
