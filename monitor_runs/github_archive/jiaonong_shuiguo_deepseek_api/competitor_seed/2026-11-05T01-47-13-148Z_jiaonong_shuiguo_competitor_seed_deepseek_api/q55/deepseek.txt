可以，但要把“能做产地溯源”和“有基地直供”分开判断，不能仅凭品牌知名度下结论。

**结论先说：**
- **都乐（Dole）**：通常有较成熟的产地/批次追溯体系，部分品类可做到基地或产区直供，但是否对中国市场菠萝做到“单一基地直供+可开放溯源查询”，要以具体SKU、采购合同和当季产区为准；不能一概认为所有都乐菠萝都是基地直供。
- **洪九果品**：以水果供应链和产区采购见长，具备产地直采/基地合作能力，但“基地直供”是否覆盖菠萝、能否提供可核验的溯源凭证，同样要看具体产区、批次和合作模式。
- 两家都**可能有**基地或产区直采资源，但“有基地直供”不等于“对任意采购商开放溯源”。建议按供应商准入方式核验。

**可执行的核验清单：**
1. 要求供应商提供**具体菠萝SKU的产地证明**：产区、果园/包装厂名称、采收批次、包装日期。
2. 要求提供**追溯链条**：果园/合作社→分选包装厂→冷链运输→到货批次，能否做到批次级对应。
3. 询问**直供模式**：是自有基地、合作基地、订单农业，还是产区经纪人采购；四种模式的溯源强度不同。
4. 要求**现场或视频验厂/验基地**，并核对包装厂备案号、出口/商超供货资质。
5. 在合同中写明**溯源违约责任**：批次不符、产地不符时的退换货和赔偿条款。
6. 先做**小批量试单**，随机抽批次反查溯源信息是否闭合。

**建议提问话术：**
“请提供本季度菠萝具体产区的基地名称、包装厂名称、批次追溯编号，以及从基地到我们仓库的完整流转记录；并说明是自有基地、合作基地还是产区直采。”

如果你们要的是**稳定商超级溯源+基地直供**，优先找都乐这类有体系化品控的供应商谈具体SKU；如果更看重**产区直采价格和灵活性**，可同步接触洪九果品及产区头部合作社，但必须把批次溯源写进合同。最终以对方能否提供**可核验的批次级凭证**为准，而不是只看品牌。
