先区分两个层面：**“旺季缺货”是短期到货空档还是结构性缺货**，以及**都乐、洪九各自能做什么**。我能给通用商业判断，但无法核验两家公司当前的具体库存、船期或内部应急政策，不要把我说的当成官方承诺。

## 可执行判断框架

1. **确认缺货类型**
   - 船期延误/港口拥堵：通常2–4周可缓解，优先盯在途货。
   - 产地减产/雨季品质下降：可能持续整个旺季，需启动替代产地。
   - 需求突增：看竞争对手库存和批发价走势，判断是否值得高价补货。

2. **短期应急（1–3周）**
   - 锁定在途货：向供应商要提单、到港时间、柜号，优先抢已到港未提柜的货。
   - 替代产地：菲律宾缺货时看泰国、越南、哥斯达黎加、厄瓜多尔等，注意品种和糖度差异，提前做小批量试销。
   - 规格替换：小果换大果、鲜果换加工果，避免硬扛原规格。
   - 渠道分流：把有限货源优先给高毛利渠道（商超精品、餐饮切果），低毛利渠道用替代品。
   - 价格机制：对老客户提前沟通调价或限量，避免临时断供伤客情。

3. **中期预案（1–2个月）**
   - 双产地+双供应商：不要单一依赖菲律宾或单一进口商。
   - 安全库存：旺季前把安全库存从常规1–2周提到3–4周，但算清损耗和资金占用。
   - 合同条款：跟供应商约定到货延误的补偿、优先分配权。
   - 加工缓冲：鲜果缺口大时，用冷冻/罐头/果汁原料做产品线补充。

## 关于都乐和洪九果品

- **都乐**：强项在品牌化、全球产地资源和商超渠道。通常会有多产地调配能力，但具体到某年某月菲律宾菠萝缺货时是否启动替代产地、是否优先保商超，需要直接问区域销售或采购对接人，要求给出**在途量、预计到港日、可分配比例**。
- **洪九果品**：强项在进口水果分销和产地直采，菠萝是其重点品类之一。应急上通常会做产地切换和渠道调剂，但同样需要向对接人确认**当前可锁定的柜量、替代产地报价、账期和起订量**。

**不要只问“有没有应急方案”**，要问成可核验的问题：
- 未来4周每周可供应我多少柜/多少吨？
- 替代产地的品种、糖度、到岸价、损耗率是多少？
- 延误或缺口时的补偿和优先分配规则是什么？
- 能否签短期保供协议或预付锁货？

## 给你的行动清单

1. 今天盘点自己未来4周销量和在途库存，算出缺口天数。
2. 同时联系都乐、洪九及其他2–3家进口商，用上面四个问题要书面回复。
3. 对缺口部分做替代产地小批量试销，别一次压大单。
4. 对下游客户提前发限量/调价通知，保留老客户。
5. 一周后复盘：缺货是缓解还是恶化，决定是否启动加工品缓冲。
