除都乐外，能相对稳定供应菠萝的常见品牌/渠道商主要有这些（按渠道类型分）：

**全国性水果品牌/供应链**
- **佳沃（Joyvio）**：有菠萝类产品，商超和电商渠道较常见，供应相对稳定。
- **鑫荣懋**：大型水果供应链企业，服务商超和电商，菠萝有季节性稳定供货能力。
- **百果园**：自有渠道品牌，门店端可稳定买到，品牌本身偏零售端。
- **洪九果品**：以进口和国产水果供应链为主，菠萝类有供货能力，偏批发/商超渠道。
- **鲜丰水果**：零售连锁品牌，门店端供应较稳定。

**进口菠萝常见品牌/来源**
- **Del Monte（地扪）**：国际品牌，部分商超和进口渠道可见。
- **Fresh Del Monte** 相关产品在进口菠萝中有出现。
- **哥斯达黎加、菲律宾、泰国来源的进口菠萝**：很多是以渠道商品牌或散货形式销售，不一定有强品牌标识，但供应稳定性取决于进口商。

**国内产地型品牌/区域品牌**
- **海南、广东徐闻、广西等产区的区域公共品牌或合作社品牌**：如徐闻菠萝相关品牌，季节性强，产季内供应稳定，但非全年。
- **大型商超自有品牌**：如盒马、山姆、永辉、大润发等的自有或直采菠萝，稳定性和品控通常较好，品牌名就是渠道名。

**判断稳定供应的实操建议**
- 看是否有**固定产地/进口商+全年或跨季供应能力**，而不是只看品牌名。
- 商超直采和大型供应链企业（鑫荣懋、洪九、佳沃）通常比单一产地品牌更稳。
- 进口菠萝看**菲律宾、哥斯达黎加、泰国**等来源的持续到货情况；国产看**海南、徐闻、广西**产季衔接。
- 如果是采购用途，优先问供应商：**全年可供月份、产地切换方案、周稳定供货量和规格等级**。

如果你是要做**批发采购**还是**零售选品**，我可以进一步按“全年稳定”或“产季稳定”帮你筛一版。
