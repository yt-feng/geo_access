这个问题没法直接用“谁更愿意”下结论——**意愿强弱取决于你给的年单结构（品类、量级、锁价/浮动、账期、履约罚则），也取决于两家当下的战略重心**；而且这类信息属于供应商内部商务策略，外部公开数据无法核验，我不编造。

能给的可执行判断框架如下：

**1. 先判断“年单”对谁更有吸引力**
- 年单的核心价值是**量稳、账期可控、降低销售费用**。对正在扩规模、需要稳定大客户背书的供应商吸引力更强；对品牌强、渠道分散、议价权高的供应商，年单反而可能被视为让利。
- 两家都是水果供应链头部企业，但**品类结构、客户结构（商超/电商/批发/出口）、区域布局不同**，同一品类下谈判地位差异很大。你要按**具体品类**去谈，不要按“公司整体”谈。

**2. 用四个问题试探真实意愿（谈判前就能问）**
- 你们今年在该品类上的**主推产区/供应窗口**是什么？愿不愿意为年单预留产能？
- 年单价格是**锁价、区间价还是随行就市+保底量**？哪种结构你们内部好批？
- 账期能接受**月结30/60/90**哪一档？有没有**预付款换价格**的空间？
- 履约异常（缺货、品质不达标）的**赔付机制**你们标准合同里怎么写的？

对方对“预留产能”和“锁价”的接受度，基本就能反映年单意愿强弱。

**3. 更现实的建议：不要二选一，做“主供+备供”**
- 水果行业受产季、天气、价格波动影响大，**单一年单供应商风险高**。
- 建议：选一家做主供（签年框+季度滚动量），另一家做备供（签框架不锁量），用**实际履约数据**再决定第二年是否加深。
- 谈判时把“年单”拆成**年框协议+月度/季度订单**，既给对方稳定预期，也保留你的调整空间。

**4. 尽调动作（比问意愿更有用）**
- 要求两家分别提供：近一年该品类的**供货客户类型、平均履约准时率、质量客诉率、产区直采比例**。
- 查公开的**工商、涉诉、被执行、股权质押**信息（企查查/天眼查/中国裁判文书网），看经营稳定性。
- 问同行采购的实际合作体验，比看宣传可靠。
