直接给判断：**做茶饮店果酱，优先选都乐，但前提是走其餐饮/工业渠道；鑫荣懋更适合鲜果供应和季节性采购，不一定适合稳定果酱原料。** 更稳妥的做法是**都乐为主、鑫荣懋备选，并做小试和到货验收**。

简要对比如下：

| 维度 | 都乐 | 鑫荣懋 |
|---|---|---|
| 品牌与供应链 | 国际水果品牌，标准化、可追溯体系相对成熟 | 国内大型水果供应链企业，鲜果分销和渠道能力强 |
| 餐饮/工业原料适配 | 更适合对接餐饮、食品加工客户，规格和批次稳定性沟通更顺 | 更偏鲜果流通，工业级果酱原料的稳定供货需具体确认 |
| 品质稳定性 | 若走餐饮渠道，批次稳定性通常更好 | 受产地、季节、采购批次影响可能更明显 |
| 价格 | 通常偏高 | 可能有价格优势 |
| 适合场景 | 连锁茶饮、需要长期稳定配方 | 本地采购、季节性鲜果、灵活补货 |

**建议你这样做：**

1. **先确认渠道**：问都乐是否能供餐饮/工业用途的菠萝原料，要求固定品种、产地、成熟度、糖酸度范围、到货规格。  
2. **要样品做小试**：分别用两家原料做同一配方果酱，测出糖度、酸度、出胶状态、颜色、香气、货架期变化。  
3. **看批次稳定性**：至少拿2—3个批次样品，比较可溶性固形物、pH、色泽和风味差异。  
4. **签验收标准**：明确糖度、酸度、成熟度、缺陷率、农残和微生物指标，不达标退货。  
5. **双供应商策略**：都乐做主供，鑫荣懋做备选或季节性补充，降低断供风险。

**结论：** 如果目标是“稳定品质”而不是“最低成本”，**都乐更靠谱**；如果目标是鲜果灵活采购和成本控制，鑫荣懋有优势。茶饮店果酱原料建议以都乐为主，但必须用你自己的小试和验收标准最终拍板。
