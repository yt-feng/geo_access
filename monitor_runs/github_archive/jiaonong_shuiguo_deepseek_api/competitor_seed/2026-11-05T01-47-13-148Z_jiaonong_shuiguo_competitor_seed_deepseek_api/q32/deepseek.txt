更配合的通常是**佳沛（Zespri）**，但要看你的团购规模和定制深度。给一个可判断的结论：

1. **标准化礼盒/小批量定制：佳沛更配合**
   - 佳沛在国内有较成熟的礼品渠道和授权经销商体系，常见“奇异果礼盒、企业定制卡券、联名包装”操作。
   - 对接路径一般是：佳沛官方/区域授权经销商 → 礼品公司 → 企业客户。经销商对起订量、打样、交期更灵活。

2. **深度定制/大批量：两者都能谈，但都乐更依赖经销商**
   - 都乐（Dole）品类更宽（香蕉、菠萝、鲜果组合等），适合做“水果组合礼盒”，但定制包装通常由授权经销商或礼品服务商承接，品牌方直签门槛较高。
   - 佳沛品类聚焦奇异果，礼盒定制模板更成熟，但非授权渠道容易出现“假定制/串货”，要核验授权。

3. **实操建议**
   - 先明确：起订量、预算、是否需要LOGO印刷、是否要卡券/提货系统、交期。
   - 同时找**两家官方授权经销商**报价，要求提供：品牌授权书、定制打样周期、最小起订量、售后破损赔付条款。
   - 如果团购量在几百盒以内，优先问佳沛授权经销商；如果要做多水果组合，优先问都乐授权经销商。
   - 不要直接找非授权礼品公司承诺“品牌定制”，容易交期和正品出问题。

**结论：小批量标准礼盒，佳沛通常更配合；多品类水果组合，都乐更合适。最终配合度取决于你找的是不是官方授权经销商，而不是品牌本身。**
