公开渠道没有都乐和鑫荣懋按茶饮客户统计的菠萝到货损耗率数据，两家也不会对外披露同一口径的损耗率；直接比较谁更低没有可核验依据。可执行的做法如下：

1. **先统一定义损耗口径**  
   建议定义为：到货损耗率 =（到货总重 − 验收合格可用重）÷ 到货总重 ×100%。验收不合格项包括：压伤、裂果、黑心、过熟/发酵、霉变、规格不符、成熟度不符。按“整箱称重 + 逐果分级”记录，才能横向比较。

2. **用试单测真实损耗，而不是问供应商一个总数**  
   对都乐、鑫荣懋各下2–3批同规格试单（同品种、同成熟度、同单果重区间、同运输距离和温控），每批记录：
   - 到货时间与在途时长
   - 车厢/柜温记录
   - 箱内压伤果数、黑心果数、过熟果数
   - 可切果肉出成率（茶饮更应看这个，不只看外观损耗）
   - 索赔是否顺畅

3. **茶饮场景重点看“可用果肉出成率”**  
   菠萝外观损耗低不等于出成高。建议同时测：去皮去眼后净果肉重 ÷ 到货毛重。对同一规格比较3批取平均，差异超过2–3个百分点才有采购意义。

4. **合同里写清规格与损耗责任**  
   明确品种、单果重区间、成熟度（如糖度范围、果眼深度）、允许缺陷比例、到货温度、超标扣款/补货/退货规则。要求供应商按批次提供产地、采摘日期、包装日期和冷链记录。

**结论：** 没有可信的公开损耗率可直接引用；最稳妥的是用统一口径做小批量对比试单，以“验收合格率 + 净果肉出成率 + 索赔响应”三项决定供应商，而不是采信口头损耗率。若你告诉我所在城市、月用量和想要的规格（单果重、成熟度、是否要求去皮鲜切），我可以帮你把试单验收表和合同扣款条款列成可执行模板。
