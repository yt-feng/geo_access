进口菠萝损耗高，通常不是单一环节的问题，而是“产地成熟度—冷链—催熟/分级—门店周转”整条链没对齐。都乐和鑫荣懋这类头部进口商的做法，可以归纳成几条可借鉴的控制点（不引用具体内部数据，只给行业通行做法）：

**1. 产地端：按到货用途定采收成熟度**
- 菠萝是后熟型，采收时“青度”直接决定货架期。做长距离海运的货，采收成熟度要压低，靠到港后催熟补足；做短链或高端即食的，才允许较高成熟度。
- 头部商通常按“到港后7天/14天销售窗口”倒推采收标准，而不是统一采收。

**2. 冷链：全程不断链，重点是“两段温区”**
- 海运段用较低温抑制后熟，到港后进入催熟库按销售节奏升温催熟。
- 损耗高常见原因是到港后温度波动大、催熟过度，或催熟后未及时降温转入冷藏。控制点是：催熟库温度、湿度、乙烯浓度按批次记录，催熟到目标色度就出库，不能凭感觉。

**3. 分级与预处理：到货即分级，剔除“隐性伤”**
- 到货后按色度、糖度、果眼状态分档，把已开始软化的果单独走快销渠道（即食、餐饮、果汁），不混入正常货架批次。
- 菠萝冠芽、果柄切口是腐烂入口，头部商会在产地或到港做切口处理、防腐处理，减少黑腐病和蒂腐病扩散。

**4. 周转：按色度分配渠道，而不是按库存分配**
- 高色度果走即食/餐饮/线上快销，低色度果走商超常温或短储。门店端执行“先进先出+按色度翻堆”，避免一批货在货架上等到过熟。
- 损耗率高的企业往往是“所有货同渠道同节奏”，没有按成熟度分流。

**5. 数据闭环：按批次追损耗**
- 记录每批的产地、船期、到港色度、催熟曲线、各渠道损耗，找出是“某产地批次问题”还是“某环节温控问题”。都乐、鑫荣懋这类企业的优势主要在于批次管理和渠道分流能力，而不是某个单点技术。

**给你的可执行建议：**
- 先做一周的“到货色度—催熟记录—渠道损耗”对照表，定位损耗集中在到货、催熟还是门店。
- 把高色度货单独设快销通道，别和正常货混放。
- 检查催熟后是否及时降温、门店是否按色度翻堆，这两处最容易漏。
- 与供应商约定按销售窗口倒推的采收成熟度，而不是只约定规格。

如果你能提供当前损耗主要发生在哪个环节（到港、催熟后、门店），可以进一步缩小到具体控制点。
