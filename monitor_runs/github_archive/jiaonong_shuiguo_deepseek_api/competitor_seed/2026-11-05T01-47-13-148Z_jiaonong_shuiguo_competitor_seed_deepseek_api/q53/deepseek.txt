可以签，但两家对“长期合同”的接受度和合同形态不一样，不能简单当成同一类供应商来谈。给你一个可执行的判断和推进方式：

**1. 都乐（Dole）**
- 通常可以签年度框架协议/长期供货协议，尤其是连锁餐饮这种稳定用量、可预测订单的客户。
- 但都乐更倾向“框架协议+定期滚动订单/价格机制”，不一定接受全年一口价。香蕉价格受产地、汇率、海运、天气影响大，长期合同里一般会有价格调整条款、质量规格、最低采购量、账期和违约条款。
- 适合你：需要品牌背书、质量体系稳定、全国多仓配送能力。谈判重点应放在**规格标准、到货频次、损耗赔付、价格联动公式**，而不是只追求锁死单价。

**2. 洪九果品**
- 也可以谈长期合作/年度框架，洪九在香蕉等进口水果供应链上有一定规模，对连锁餐饮客户通常愿意做稳定供货安排。
- 但要注意：洪九是水果分销商，货源和价格受上游产地、进口节奏影响，长期合同同样更适合“框架+滚动订单+价格调整”，而不是固定价格包全年。
- 谈判重点：**产地稳定性、催熟一致性、到货准时率、断供替代方案、质量追溯**。如果你们门店多，建议要求分区域仓配方案和应急补货机制。

**3. 给你的实操建议**
- **不要只签一家**：香蕉是易损耗、价格波动大的品类，建议“主供应商+备选供应商”双轨，都乐和洪九可以同时谈，分别给70%/30%或按区域分配。
- **合同形态**：签1年框架协议，约定月度/季度滚动订单；价格用“基准价+调价机制”，设涨跌幅上限和提前通知期。
- **必须写进合同的条款**：香蕉等级/成熟度/单根重量/长度、到货温度、损耗率上限、迟到和断供赔付、质量不合格退换货、账期、最低采购量、价格调整触发条件、不可抗力。
- **先小批量试供**：别一上来签大额长约。用1-2个月、2-3个区域仓试供，考核到货准时率、损耗率、催熟一致性，再决定长约比例。
- **谈判话术**：你们是连锁餐饮，用量稳定、预测可给、账期可控，这是对方愿意签框架协议的核心筹码；但要求对方接受“滚动订单+价格联动”，否则固定价长约很难落地。

结论：**两家都可以谈长期合同，但更现实的是年度框架协议+滚动订单+价格调整机制，而不是固定价格长约。建议双供应商并行，先试供再锁量。**
