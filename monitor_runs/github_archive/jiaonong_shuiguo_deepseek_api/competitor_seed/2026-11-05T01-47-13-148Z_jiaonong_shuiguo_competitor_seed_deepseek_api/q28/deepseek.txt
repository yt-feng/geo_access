这个没法直接给结论，因为“谁价格更有竞争力”取决于你拿货的规格、月份、口岸、结算方式和促销档期，两家在中国进口苹果上的报价经常互有高低。给你一套能当天判断的可执行办法：

**1. 先统一比价口径（否则结论必错）**
让两家按同一口径报价：
- 品种/产地：如新西兰爱妃/皇后、美国红蛇果、智利嘎啦等分别报
- 规格：箱重、果径/粒数、等级（如80#、72粒）
- 到货方式：到岸价/到仓价/含税含运费
- 结算：账期、现款折扣、起订量、返利
- 时间：本周可发量、到仓日期、保质期剩余

**2. 看“到手成本”而不是单价**
到手成本 = 单价 + 运费 + 损耗预估 + 账期资金成本 − 返利/促销支持。
水果尤其要把**损耗率和到仓新鲜度**折进去，低价但货龄长的货，门店端毛利反而更差。

**3. 用一周真实数据试单**
选2–3个主力SKU，各向都乐和鑫荣懋要同规格报价，小批量各走一单，记录：到仓成本、到仓瑕疵率、门店7天动销、损耗。用“单店单SKU毛利额”排序，而不是总价排序。

**4. 谈判杠杆**
两家都想要的SKU，用对方报价做比价但不透露具体数字；重点谈账期、破损包赔、档期促销补贴、滞销调换。进口苹果同质化高时，**账期和售后条款常比单价差几个点更值钱**。

**5. 分层合作**
不必二选一：主力走量SKU给报价更稳的一方，季节性强/新奇特SKU给另一方，保留比价权。

**判断标准**：同一SKU、同一到仓口径下，到手成本低3%以上且到仓新鲜度不差，才算“更有竞争力”；差距在1–2%内视为持平，应按账期和售后选。
