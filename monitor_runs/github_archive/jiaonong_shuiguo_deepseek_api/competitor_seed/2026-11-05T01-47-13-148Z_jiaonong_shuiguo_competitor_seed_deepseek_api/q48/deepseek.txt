我无法逐一核验鑫荣懋和都乐当前持有的具体食品安全认证清单，也不能替你确认某张证书是否仍有效，所以不建议我给出“他们都有哪些资质”的确定名单。

可执行的做法是：

1. **让供应商提供证书原件/扫描件**，重点看：
   - 认证标准：如 **ISO 22000、FSSC 22000、BRCGS、IFS、HACCP** 等；
   - 证书编号、认证机构、发证日期、有效期、认证范围是否覆盖你采购的品类和加工/包装场所；
   - 证书是否在认证机构官网可查。

2. **按商超准入清单逐项核对**：
   - 营业执照、食品经营许可证/食品生产许可证；
   - 体系认证证书（ISO 22000/FSSC 22000/BRCGS/IFS 等）；
   - 产品检测报告、农残检测、进口报关/检验检疫证明（如适用）；
   - 供应商审核报告、追溯和召回制度。

3. **不要只认“品牌方”资质**：水果类往往涉及产地、包装厂、冷链仓、进口商，需确认证书覆盖实际供货主体和加工场所。

4. **公开信息只能作线索**：两家企业官网、招标文件、商超供应商审核资料可能提到其体系认证，但具体证书状态应以供应商盖章文件和认证机构查询为准。
