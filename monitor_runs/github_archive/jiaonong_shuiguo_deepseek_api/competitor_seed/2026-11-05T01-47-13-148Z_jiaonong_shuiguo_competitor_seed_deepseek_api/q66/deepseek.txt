## 一、关于都乐和鑫荣懋的“保价服务”

- **都乐（Dole）**：公开信息更多是其品牌、供应链和经销体系，未见可核验的、面向批发商的标准化“香蕉保价服务”条款。是否存在区域性的价格保护、返利或滞销补贴，通常取决于**年度经销协议、区域代理合同、促销政策**，需要向对接的都乐区域销售/经销商确认。
- **鑫荣懋**：同样属于水果供应链企业，公开层面无法确认其提供标准化香蕉保价服务。是否有“保底价、跌价补差、调价补差、滞销处理”等安排，要以**合同条款**为准。
- **判断标准**：让对方书面明确四点——①保价标的（哪个规格/等级）；②保价周期；③触发条件（市场价跌多少、以什么价格指数为准）；④补差方式和上限。**口头承诺不算。**

## 二、批发商可执行的香蕉价格波动应对方案

### 1. 采购端：锁价不锁量，分批建仓
- 与供应商谈**分批定价**：每周或每旬按约定基准价（如产地价+固定服务费）结算，避免一次性锁死。
- 合同里争取**跌价补差条款**：约定参考第三方价格（如产地批发价、行业指数），跌幅超过约定比例时补差，设补差上限。
- 保持**2—3家供应商**并行，避免单一品牌断供或价格绑架。

### 2. 库存端：快周转，控熟度
- 香蕉是后熟品，价格波动最怕压库。按**销售速度倒推采购量**，库存周转控制在3—5天以内（视冷链和催熟能力）。
- 分级销售：熟度高的走促销/加工渠道，减少损耗折价。

### 3. 销售端：提前锁量，价格联动
- 对商超、水果店客户签**短期框架价+调价机制**，比如每周调价一次，避免单边承担跌价。
- 对团购、餐饮、果汁加工渠道做**尾货分流**，降低跌价损失。

### 4. 金融与风险工具
- 关注是否有**农产品价格保险、订单农业保底收购**等地方政策工具，部分产区有香蕉价格指数保险试点，可向当地农业农村部门咨询。
- 现金流上预留**价格下跌准备金**，不要用高杠杆囤货。

### 5. 合同必须写清的条款
- 基准价定义和来源；
- 调价频率和通知期；
- 跌价补差触发条件和上限；
- 质量争议与退货责任；
- 保价是否含运费、损耗。
