可以找，但要先区分“有相关体系”与“能对你这一批货出具你要求的证明”。都乐和鑫荣懋都属于大型果蔬企业，通常具备产地管理、供应商审核和品控体系；但是否能提供**可核验的产地溯源证明、批次检测报告、品控流程文件**，取决于具体品类、产地、采购主体和批次，不能仅凭品牌名确认。

建议你按下面方式核验：

1. **都乐**
   - 可向都乐中国官方渠道或区域销售确认：香蕉的产地、包装厂、批次号是否可追溯。
   - 要求提供：本批次农残检测报告、产地证明或采收/包装记录、质量管理体系认证证书、追溯编码规则。
   - 注意：都乐品牌授权和直营渠道要分清，避免从二级经销拿货却拿不到原厂批次证明。

2. **鑫荣懋**
   - 同样向鑫荣懋官方销售确认其香蕉业务能否提供批次溯源和品控文件。
   - 要求提供：供应商审核记录、采收批次与发货批次对应关系、第三方检测报告、冷链温控记录（如适用）。
   - 若为进口香蕉，还要确认报关单、入境货物检验检疫证明与销售批次能否对应。

3. **谈判时直接问这5项**
   - 能否按“发货批次”提供检测报告，而不是通用模板报告？
   - 追溯码能否从成品箱追溯到产地果园/包装厂？
   - 品控证明具体包括哪些文件，是否盖章？
   - 出现农残或品质争议时，能否配合第三方复检？
   - 是否接受验厂或提供年度审核报告？

结论：**都乐和鑫荣懋大概率有品控和溯源管理能力，但你必须要求其官方渠道对具体香蕉批次出具书面证明并核验一致性。** 如果对方只能给品牌宣传资料、不能给批次文件，就不应视为满足“产地溯源和品控证明”要求。
