都乐（Dole）和洪九果品都面向零售/B端客户，但“香蕉小包装定制”能否做、怎么做，通常要先区分两件事：**品牌方标准小包装** vs **渠道专供/定制包装**。

**1）都乐**
- 都乐有面向便利店、商超的小规格香蕉/单根或小把预包装产品，也做渠道专供规格，但通常以**现有标准规格+渠道贴标/陈列方案**为主。
- 真正“完全按你便利店需求定制包装”（尺寸、材质、印刷、克重、起订量）一般需要走**都乐B2B/大客户或经销商**，且有较高起订量门槛；小连锁便利店单店很难直接开定制。
- 可行路径：联系都乐当地经销商或区域B2B销售，问三件事：①是否有便利店小规格标准品；②能否做渠道专供贴标；③定制起订量和账期。

**2）洪九果品**
- 洪九果品以水果供应链和B端分销为主，香蕉是其重点品类之一，具备**分拣、分级、预包装**能力，理论上可谈小包装/渠道专供。
- 但是否开放“便利店小包装定制”取决于区域分公司和客户体量；通常更愿意服务连锁便利店、区域零售客户，起订量按件/箱/批次谈。
- 可行路径：联系洪九当地分公司/城市负责人，明确你的**门店数、日销量、包装规格（如单根/2-3根/袋装/盒装）、是否需要印刷LOGO、配送频次**，让对方报价并确认最小起订量。

**判断建议**
- 如果你是**单店或几家店**：优先找当地水果批发商/经销商拿都乐或洪九的**标准小包装**，不要一开始谈完全定制，成本高且起订量难达标。
- 如果你是**连锁便利店（十几家以上、有稳定销量）**：可以直接找都乐区域B2B和洪九分公司谈**渠道专供小包装**，重点谈：规格、保鲜期、损耗赔付、配送频次、起订量、是否允许贴便利店品牌标签。
- 谈判时别只问“有没有定制”，要直接给对方一张需求表：**包装形式、每包重量/根数、预计月采购量、配送城市、是否要印LOGO、可接受单价**。这样对方才能快速判断能否接。

**结论**：两家都具备B端小包装/渠道专供的谈判基础，但“完全定制包装”通常有起订量门槛；便利店更现实的做法是先拿标准小规格，再逐步谈渠道专供贴标。具体政策需以你所在城市对应经销商/分公司答复为准。
