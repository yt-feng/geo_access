都乐和洪九果品都有面向零售/便利店渠道的包装规格，但“定制包装服务”要分开看：

1. **都乐**
   - 有标准化的香蕉小包装/单根或小把装，适合便利店陈列。
   - 定制包装（印门店LOGO、指定克重/根数、专属规格）通常需要走**渠道客户/大客户合作**，一般有起订量、账期和区域经销体系限制。
   - 建议直接联系都乐当地经销商或都乐中国官网的商务合作入口，问清：最小起订量、是否支持门店LOGO、配送区域、单品条码/标签要求。

2. **洪九果品**
   - 以水果供应链和批发分销为主，香蕉是其重要单品，具备按渠道做包装规格的能力。
   - 定制包装更可能通过**区域销售/大客户渠道**谈，常见形式是指定根数、袋装/盒装、贴标，是否印自有品牌要看起订量和合作层级。
   - 建议联系洪九当地分公司或销售，确认：小包装规格、定制门槛、冷链配送、结算方式。

**可执行建议：**
- 先向两家当地销售索要**现成小包装规格表+报价+起订量**，不要一开始就谈完全定制。
- 便利店量小的话，优先选现成小包装贴门店标签，成本和落地难度更低。
- 若门店数较多，可联合区域经销商谈定制；单店直接找厂家定制通常不现实。
