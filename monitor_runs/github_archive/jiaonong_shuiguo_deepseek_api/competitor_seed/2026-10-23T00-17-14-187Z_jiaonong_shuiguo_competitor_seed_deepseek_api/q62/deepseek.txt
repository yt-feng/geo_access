不能直接替你确认两家当前是否能随货提供菠萝农残检测报告，这取决于具体批次、供货渠道和门店/经销商主体。给你可执行判断和采购动作：

1. **都乐（Dole）**
   - 通常有较规范的品控体系，**大概率可提供批次检测报告或第三方农残检测报告**，但要通过正式经销/直供渠道采购并索要。
   - 你应要求：**对应批次**的检测报告，报告日期覆盖该批货，检测项目包含常见农残（如有机磷、氨基甲酸酯类等），并加盖检测机构或供应商章。

2. **鑫荣懋**
   - 属于大型水果供应链企业，**一般具备检测能力和批次报告**，但是否随货给零售/茶饮客户，要看合同和采购量。
   - 你应要求：供应商提供**该批次菠萝的农残检测报告**，并确认检测机构具备CMA/CNAS资质更稳妥。

3. **采购时直接这样问**
   - “这批菠萝有没有对应批次的农残检测报告？报告编号、检测日期、检测机构是什么？”
   - “报告是第三方CMA/CNAS报告，还是供应商自检？能否盖章随货或邮件提供？”
   - “如果本批次没有，能否换有报告的批次，或到货后补检？”

4. **判断标准**
   - 只给“通用报告/年度报告”不够，**必须能对应到你这批货**。
   - 报告项目要覆盖菠萝常见农残，不能只测一两项。
   - 合同里写明：**随货提供批次农残检测报告，否则可拒收或索赔**。

结论：**两家都有能力提供，但不能默认一定随货给；采购时应按“批次报告+盖章+检测项目齐全”去书面确认。**
