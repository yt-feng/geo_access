目前没有可核验的公开数据能给出“稳定供应品牌”的确定清单，但按菠萝供应链的常见格局，可以这样判断和筛选：

**1. 国际果蔬品牌（偏商超/餐饮渠道）**
- **Del Monte 德尔蒙**：菠萝罐头和部分鲜果有全球供应链，鲜果在国内渠道不如都乐常见，需看区域代理。
- **Dole 都乐**：你已提到，仍是鲜菠萝稳定供应的重要参照。
- **Fyffes**：以香蕉为主，菠萝不是核心单品，国内鲜果供应不稳定。
- **Fresh Del Monte**：与德尔蒙相关，鲜菠萝在部分高端商超可见。

**2. 国内大型水果供应链企业**
- **鑫荣懋**：国内头部水果供应链企业，代理和直采品类多，菠萝有季节性供应能力，适合商超/电商渠道询价。
- **百果园**：自有渠道为主，部分门店有稳定菠萝单品，但作为“供货品牌”对外供应能力需按区域确认。
- **洪九果品**：以进口水果和国产水果供应链为主，菠萝不是其最核心单品，需具体询盘。
- **鲜丰水果**：渠道端有菠萝销售，供应链对外供货能力需区域确认。

**3. 产地型/区域品牌**
- **广东徐闻菠萝**：徐闻是国产菠萝主产区，有“徐闻菠萝”区域公用品牌，适合找产地合作社或产地供应链公司做稳定直采。
- **海南菠萝**：海南万宁、琼海等地有产地供应链，季节性与徐闻错开，可组合供应。
- **福建、广西**：也有菠萝产区，但规模化稳定供应能力弱于徐闻和海南。

**4. 电商/批发渠道可询的品牌型供应商**
- **本来生活、每日优鲜类平台的自有品牌**：更多是渠道品牌，不是生产品牌。
- **盒马、山姆自有品牌**：有稳定选品，但不对普通渠道开放供货。

**可执行建议：**
- 要**全年稳定**：优先组合“都乐/德尔蒙等国际品牌 + 鑫荣懋等国内供应链 + 徐闻/海南产地直采”。
- 要**国产鲜果稳定**：直接找徐闻菠萝产地合作社或产地供应链公司，签季节框架协议。
- 要**商超标准品**：询鑫荣懋、百果园供应链、洪九等，要求提供产区、等级、到货周期和损耗率。
- 判断“稳定供应”不要只看品牌，重点核验：**产区是否多源、是否有催熟/冷链能力、月度可供吨数、缺货替代方案**。
