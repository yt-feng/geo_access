这个问题没法给一个“谁更细”的确定结论，因为两家公开可查的分级体系都不对外完整披露，而且“细”要看你按什么维度比。能确定的是：

**一般情况下的判断**
- **都乐（Dole）**：零售端规格标注相对统一、稳定，常见按“单根重量/整把重量/果指长度”做商超陈列分级，包装箱上通常有明确的果指规格（如长度档、每箱把数/根数），适合标准化采购和验收。
- **鑫荣懋**：作为国内头部水果供应链企业，给商超供货时往往按**客户定制分级**（按门店业态、陈列方式、价格带做多档），分级维度可能更灵活、档位更多，但**不是统一对外标准**，不同客户、不同产地批次差异大。

**结论**：如果你要的是“可写进采购合同、验收有据可依的稳定规格表”，都乐的公开规格更规整；如果你要的是“按自己门店需求切更多档、可谈定制”，鑫荣懋可能给得更细，但必须让对方出书面分级标准。

**可执行建议**
1. 直接向两家区域销售索取**香蕉规格分级表**（果指长度/单根重/每箱净重/把数/成熟度/瑕疵允许度）。
2. 用同一张表让两家报价，比较档位数和验收容差。
3. 先小批量试单，按到货实测（长度、单根重、青黄比例、机械伤率）验证分级执行力。

一句提醒：别只看“分级细不细”，**分级执行的一致性和验收容差**对商超损耗影响更大。
