结论先说：**不能对“所有批次稳定低于3%”打包票；这两家都具备把香蕉到货损耗压到3%左右甚至更低的能力，但是否≤3%取决于合同标准、运输距离/季节、到货验收口径和门店操作，必须用试单数据验证，不能仅凭品牌承诺判断。**

## 判断要点

1. **先定义“到货损耗率”**
   - 分子是否包含：断果、压伤、黑斑、青硬不熟、过熟、果柄脱落、单根失重？
   - 分母按到货总重还是总箱数？
   - 验收时点：卸货即刻、到店后24小时、催熟后？
   - 口径不统一，3%这个数字没有可比性。香蕉是呼吸跃变型水果，到店后熟度变化很快，按“到店后24小时”算损耗通常明显高于“卸货即刻”。

2. **都乐（Dole）**
   - 供应链和催熟体系成熟，适合对品质稳定性、标准化要求高的连锁客户。
   - 但香蕉到货损耗受产地季节、船期、港口拥堵、冷链断链影响很大，**没有供应商能承诺全年所有批次≤3%**。
   - 更现实的做法是要求其按**批次/季节/线路**给出历史损耗区间，并写入验收扣罚条款。

3. **鑫荣懋**
   - 国内分销网络和终端服务能力强，灵活性通常优于国际品牌直供，适合多区域门店配送。
   - 其损耗表现同样取决于具体仓配线路和催熟管理，**不能默认全区域≤3%**。
   - 若你有多区域门店，重点考察其**区域仓到店冷链**和**催熟批次一致性**。

## 可执行建议

- **先做4–8周试单**：选2–3条代表性线路（近仓/远仓、夏季/雨季），同规格同熟度，按统一验收口径记录每批损耗。
- **合同写清**：验收标准（熟度、色卡、机械伤允许比例）、损耗计算口径、超标扣款/补货/退货机制、到店时效和冷链温度记录。
- **分线路定指标**：近仓线路可争≤3%，远距离或高温季节建议设3%–5%的阶梯标准，避免供应商为达标发偏生香蕉，反而造成门店催熟损耗。
- **看催熟责任归属**：若由供应商催熟后配送，3%到货损耗相对可谈；若门店自行催熟，到货损耗和催熟损耗要分开考核，否则责任说不清。
- **要求数据透明**：让两家分别提供近6–12个月同类客户、同类线路的损耗数据（可脱敏），并允许你到其区域仓看香蕉到货和催熟流程。

**一句话：都乐和鑫荣懋“有能力做到”，但“能不能稳定≤3%”要用你的线路和验收口径试出来，合同里按线路和季节设阶梯指标比一刀切更可靠。**
