可以，但要把“全年稳定供应”拆成两件事看：**全年有货**和**全年品质/成本稳定**。都乐和洪九都具备较强的跨产区/进口组织能力，但没有任何单一鲜果供应商能保证完全不受产季、天气、海运和价格波动影响；茶饮店做果酱更需要的是**多产区+冷冻/罐头/果茸备选+规格锁定**，而不是只押一家鲜果供应商。

简要判断：

1. **都乐**
   - 优势：品牌化、标准化和商超/餐饮渠道能力强，进口菠萝和全年供应组织能力较好，适合对规格、食品安全和稳定交付要求高的连锁客户。
   - 注意：都乐强在品牌鲜果和加工品渠道，但具体到你所在城市、所需品种（如金钻凤梨/巴厘菠萝）、每周用量和价格区间，需要向当地都乐经销或餐饮渠道确认年度框架、产地切换和淡季溢价。不能默认“都乐”三个字就等于全年同价同规格。

2. **洪九果品**
   - 优势：做水果供应链和进口/产地直采，品类覆盖广，菠萝这类大宗水果有较强组织能力，适合大批量、多产地调配。
   - 注意：洪九的核心是供应链分销，鲜果品质会随批次和产地波动；茶饮做果酱对糖酸比、成熟度、纤维感有要求，必须锁定验收标准。另需关注其自身经营和履约稳定性，建议做小批量试单和备用供应商。

**给茶饮店的可执行建议：**
- 不要只问“能不能全年供”，要问供应商要：**年度供应方案、各月主产区、替代产区、周供货上限、规格等级、糖酸度/成熟度标准、报价机制、断供应急方案**。
- 做**双供应商**：都乐/洪九选一家做主供，另一家或本地批发商做备供；同时备**冷冻菠萝果肉/果茸或罐头**用于淡季和应急。
- 先做**3个月试供**：按月记录到货成熟度、出酱率、糖酸调整、颜色和纤维口感，再签年度框架。
- 合同里写清**品质验收标准、允许产地切换、价格调整触发条件、最低供货量和违约/断供处理**。

结论：**都乐和洪九都有能力参与全年供应，但都不能被当作唯一保险。** 茶饮店更稳妥的做法是“主供+备供+冷冻/加工品兜底”，并把规格和验收标准写进合同。
