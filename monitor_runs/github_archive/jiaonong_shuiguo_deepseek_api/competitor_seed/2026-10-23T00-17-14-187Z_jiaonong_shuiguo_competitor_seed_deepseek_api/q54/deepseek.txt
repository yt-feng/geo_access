做进口苹果产地溯源，核心是把“批次—产地—报关/检疫—仓储流向”串成一条可核验的链。都乐和鑫荣懋都属于品牌/供应链商，不是单一产地，实操上按下面做即可。

## 一、先分清溯源对象
- **都乐**：多为品牌运营+全球采购，进口苹果可能来自新西兰、美国、智利、南非等，具体看包装批次和报关单。
- **鑫荣懋**：国内大型水果供应链企业，既有进口也有国产，进口苹果同样要看具体批次原产地。
- 所以不能用“都乐/鑫荣懋”作为产地铁证，**必须以批次为单位溯源**。

## 二、超市端可执行的溯源动作
1. **收货时索证索票**
   - 每批次索取：入境货物检验检疫证明、报关单、供货商营业执照、食品经营许可证。
   - 核对：品名、原产国、生产/包装日期、批次号、数量与到货是否一致。
   - 进口苹果应有中文标签，标明原产国、境内责任人/进口商、批次等信息。

2. **建立批次档案**
   - 以“供应商+品牌+原产国+批次号+到货日期”为唯一追溯键。
   - 保存报关单、检疫证明、送货单、验收记录、照片（外箱标签、中文标签、果贴）。
   - 建议纸质+电子双存档，至少保存至保质期后6个月，常规按2年管理。

3. **门店/仓库标识**
   - 价签或溯源牌标注：原产国、品牌/供应商、批次或到货日期。
   - 有条件可在价签放二维码，链接到该批次证照摘要，不公开展示完整报关单敏感信息。

4. **抽检与异常处理**
   - 到货抽检外箱标签与中文标签是否一致，果贴是否与箱标一致。
   - 发现标签缺失、批次对不上、检疫证明与货物不符，先隔离再联系供应商补证，不能直接上架。

## 三、向供应商提出的溯源要求
采购合同或年度协议中明确：
- 每批提供报关单和入境货物检验检疫证明复印件/电子件；
- 外箱标注批次号，中文标签可追溯到进口商；
- 发生召回或食安事件时，供应商能在约定时限内提供流向和处置配合；
- 都乐、鑫荣懋分别指定对接人和证照提供流程。

## 四、给消费者的可核验信息
超市对外展示不必放完整报关单，可展示：
- 原产国；
- 进口商/境内责任人；
- 批次或到货日期；
- 检验检疫证明编号或摘要；
- 门店可查证照的说明。

## 五、判断是否做到位的标准
同时满足以下四条，才算溯源闭环：
1. 货架商品能对应到具体批次；
2. 该批次有报关单和检疫证明；
3. 外箱标签、中文标签、果贴信息一致；
4. 门店能说清该批从哪个供应商、何时到店、存于何处。

**注意**：都乐和鑫荣懋的具体产地随批次变化，不要按品牌固定认定产地；一切以该批次报关单、检疫证明和中文标签为准。
