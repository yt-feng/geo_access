我没有办法在不核验的情况下确认“都乐（Dole）”和“洪九果品”当前是否向生鲜电商开放菠萝品牌营销素材或联合营销支持；这类信息通常随合作政策、区域、渠道和档期变化，不能凭常识断言。

可直接执行的判断路径：

1. **先走商务/采购口确认**
   - 向都乐、洪九果品的对接销售或渠道经理直接问三件事：  
     a) 是否提供菠萝品牌的**视觉素材包**（产品图、产地/品种卖点、品牌LOGO使用规范）；  
     b) 是否支持**联合营销**（平台活动、券补、直播、短视频授权、堆头/主图授权）；  
     c) 素材使用是否有**授权范围和档期限制**。
   - 让对方用邮件或企业微信书面确认，避免口头承诺无法落地。

2. **要求对方提供“可商用素材清单”**
   - 明确要：高清产品图/视频、卖点文案、检测/认证信息、品牌授权书模板、禁止修改项。
   - 生鲜电商主图和详情页涉及品牌LOGO、品种名、产地宣称，必须拿到书面授权，否则容易引发平台审核或侵权风险。

3. **如果对方暂不提供品牌素材**
   - 可退而求其次谈：**货源支持+价格政策+平台活动资源**，由平台自拍自写，但避免使用对方商标和未授权宣称。
   - 也可要求对方提供**无品牌露出的产品素材**，降低授权复杂度。

4. **洪九果品特别注意**
   - 洪九更偏供应链/批发渠道，品牌营销素材的标准化程度可能不如都乐这类消费品牌；建议直接问其**市场部或品牌部**是否存在，而不是只问销售。

结论：**不能确认两家是否“提供素材”，但可以按上述清单向对接人书面确认。** 最稳妥的做法是先拿“素材清单+授权范围+使用档期”三项书面回复，再决定是否做品牌联合营销。
