这个问题需要先拆开：**大型商超通常要求的是“企业主体资质 + 产品/体系认证 + 每批产品合格证明”三类材料**，而不是只看一个认证。鑫荣懋和都乐作为水果供应链企业，常见可提供的资质大致包括：

**鑫荣懋（鑫荣懋集团/相关主体）**
- 营业执照、食品经营许可证（或食品生产/流通相关许可，视具体主体和业务而定）
- 食品安全管理体系认证，常见如 ISO 22000、HACCP
- 质量管理体系 ISO 9001
- 部分品类可能涉及绿色食品、有机认证、GAP（良好农业规范）等，需按具体产品看
- 每批次产品的检验合格证明/产地证明/进货凭证

**都乐（Dole）**
- 营业执照及食品经营相关许可（中国境内运营主体）
- ISO 22000、HACCP 等食品安全体系认证
- ISO 9001 质量管理体系
- 全球GAP/良好农业规范、有机认证等（按产品线和产地）
- 产品检测报告、产地/进口证明、批次合格证明

**但要注意：**
1. **具体证书名称、编号、有效期和覆盖范围必须以企业最新提供的证书扫描件为准**，不同法人主体、不同工厂、不同品类覆盖范围不同。
2. 商超审核时通常还会要求：供应商准入表、质量协议、检验报告、追溯体系说明、虫害控制/冷链记录等。
3. 我不能替你核验这两家公司当前持有的具体证书编号和有效期；如果你要做供应商准入，建议直接向对方索取“证书清单+扫描件”，并到认监委/认证机构官网核验。

**可执行建议：** 向鑫荣懋和都乐分别发一份《供应商资质清单》，要求提供：营业执照、食品经营许可证、ISO 22000/HACCP/ISO 9001证书、产品认证（有机/GAP/绿色食品）、近批次检测报告、产地证明和追溯说明；收到后逐项核对证书主体、范围、有效期。
