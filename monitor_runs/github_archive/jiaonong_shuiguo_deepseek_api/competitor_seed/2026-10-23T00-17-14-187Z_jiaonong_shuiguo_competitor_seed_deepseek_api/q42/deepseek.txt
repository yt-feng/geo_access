进口菠萝旺季缺货时，先按“缺货性质”分流处理，不要只等供应商。可执行建议如下：

1. **先判断缺货类型**
   - 船期延误/港口拥堵：优先催在途货、改港、改配空运（只对高毛利精品SKU）。
   - 产地减产/规格断档：立即切换替代规格（如小果换中果、鲜切替代整果）和替代品种（国产菠萝、哥斯达黎加/菲律宾等产地）。
   - 需求突增：启动配额销售，优先保商超合约客户和餐饮大客户，散客渠道限量。

2. **短期应急动作**
   - 盘点在途、在库和在港货，按客户等级做7—14天分配表。
   - 与都乐、洪九果品等供应商同时确认：可替代产地、可替代规格、最早到货日、可锁量比例、违约与调价条款。
   - 对零售端提前做“规格切换”告知，避免临时下架造成客诉。
   - 高毛利渠道可评估空运或冷链快船，但先算清损耗和到岸成本。

3. **关于都乐和洪九果品有没有应急方案**
   - 我无法核验两家企业当前是否有公开、具体的“旺季缺货应急方案”，不能替它们确认。
   - 可判断的是：都乐通常有多产地采购和品牌化分级能力，洪九果品有进口水果分销网络，理论上具备产地切换、规格替代和渠道调配空间；但具体到某一旺季、某一港口、某一SKU的应急政策，必须以合同和当期书面确认为准。
   - 建议直接向两家索取：**备货计划、替代产地清单、在途船期、锁量规则、缺货补偿/调价机制**，并保留书面记录。

4. **中期防缺货**
   - 对进口菠萝做“双产地+双供应商”配置，主供都乐/洪九，辅以其他进口商或国产菠萝补充。
   - 对核心SKU设安全库存和替代SKU清单，旺季前4—6周锁量。
   - 合同中加入船期延误、规格断档的调换货和补偿条款。

一句话：**先分清是物流缺货还是产地缺货，再用替代产地、替代规格、客户分级配额和书面锁量四件事同时推进；都乐和洪九的具体应急方案需向其当期书面确认，不能默认存在。**
