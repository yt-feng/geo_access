可以，两家都能提供，但形式不完全一样，需要按“你要什么证明”去对接。结论先说：

**都乐（Dole）**
- 有较成熟的产地/农场信息、批次管理和品控体系，通常可提供：产地/农场或包装厂信息、批次号、采收/包装日期、质量检测或内部品控记录、部分产品的可追溯信息。
- 但“产地溯源证明”和“品控证明”不是标准统一的一份文件，往往要通过销售或质量部门按批次申请，可能是追溯表、检测报告、合规声明或供应商审核资料。
- 适合：连锁商超、餐饮、电商等对品牌和稳定供货要求高的客户。

**鑫荣懋**
- 也有产地直采、基地管理和品控体系，香蕉是其重点品类之一，通常可提供产地/基地信息、批次追溯、检测报告和内部品控记录。
- 同样不是“一份万能证明”，需要明确你要的是：产地证明、检测报告、农残报告、品控流程文件、批次追溯记录，还是供应商审核表。
- 适合：商超、批发、加工和团购等渠道，定制化对接空间较大。

**建议你这样问供应商，最容易拿到可核验材料：**
1. 请提供本批次香蕉的产地/基地名称、包装厂编号、批次号、采收和包装日期。
2. 请提供该批次农残检测报告或第三方检测报告（注明检测机构、日期、批次对应关系）。
3. 请提供品控流程文件：验收标准、分级标准、成熟度/糖度控制、冷链温度记录、异常处理流程。
4. 请说明追溯粒度：能否追溯到具体基地/包装厂/批次，而不是只给公司级声明。
5. 请提供供应商审核表、营业执照、食品相关许可或体系认证（如ISO22000/HACCP等，按其实际持有情况）。

**注意：** 不要只接受“我们有溯源体系”的口头说法，要拿到**与本批次挂钩**的批次号、检测报告和追溯记录；公司级宣传册不能替代批次证明。具体能否提供、提供到什么粒度，需向都乐和鑫荣懋的当地销售或质量负责人确认。
