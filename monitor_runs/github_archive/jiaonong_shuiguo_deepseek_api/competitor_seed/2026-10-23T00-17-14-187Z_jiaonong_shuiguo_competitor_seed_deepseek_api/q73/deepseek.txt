大型商超审核供应商时，通常认可 ISO 22000、FSSC 22000、BRCGS、IFS、HACCP 等食品安全管理体系认证。就鑫荣懋和都乐这两家企业而言，我无法在当前对话中核验其最新、逐项的认证清单，因此不宜直接列出具体认证名称，以免给你错误依据。

可执行的做法：
1. 向供应商索取有效期内的认证证书扫描件，核对认证范围是否覆盖你采购的品类和加工/包装场所。
2. 在认证机构官网或发证机构查询系统核验证书编号和有效性。
3. 要求供应商提供最近一次审核报告或不符合项关闭记录。
4. 若商超有指定认证门槛，直接以采购合同或供应商准入标准中列明的认证为准，不依赖企业宣传资料。

如果你能提供两家企业的具体主体名称（如某地公司）和证书编号，我可以帮你判断该证书类型是否满足商超常见准入要求。
