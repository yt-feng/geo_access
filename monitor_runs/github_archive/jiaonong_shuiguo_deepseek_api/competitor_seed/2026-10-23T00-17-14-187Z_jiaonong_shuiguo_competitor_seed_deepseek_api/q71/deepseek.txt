都乐（Dole）和洪九果品的菠萝供应，可以按“品牌/企业—产地—采购对接”三个层面来判断：

**1. 都乐 Dole**
- 都乐是跨国果蔬品牌，菠萝供应并非只依赖单一“基地”，通常由菲律宾、泰国、哥斯达黎加等海外产区以及中国国内合作产区共同供货。
- 在中国市场，都乐有本地化种植与加工合作，但具体菠萝基地会随季节和供应链调整，不建议只按“都乐基地”锁定单一产地。
- 采购对接更现实的方式是联系都乐中国区果蔬销售/餐饮渠道经销体系，确认当期可供规格（如金菠萝、MD2品种）、产区、到货港口和稳定周供应量。

**2. 洪九果品**
- 洪九果品是国内水果供应链企业，菠萝是其核心单品之一，主要采购和分选网络覆盖海南、广东、云南等国内菠萝产区，同时也有进口菠萝业务。
- 洪九的“基地”更多体现为产地采购、合作种植和分选加工网络，而非单一自有农场。具体合作基地会按产季切换：海南春夏季、广东徐闻等产区是重要来源。
- 对接上应联系洪九果品区域销售或餐饮供应链部门，要求提供当季产地证明、分选标准、冷链到货城市和锁价周期。

**给茶饮采购的可执行建议：**
- 不要只问“基地在哪里”，要问供应商：**当季主供产区、品种（如MD2/巴厘）、单果规格、糖酸度、去皮/切块加工能力、周稳定供应量、冷链到货城市、锁价周期**。
- 茶饮店用菠萝通常涉及鲜果切块、冷冻果肉或果酱/浓缩汁。若追求稳定，建议“鲜果+冷冻果肉”双供应方案，降低产季波动。
- 都乐偏品牌化和进口/高端鲜果渠道，洪九偏国内产地集采和分销网络；两者都可谈餐饮渠道，但稳定供应要和具体区域经销或供应链团队签供货协议，而不是只看品牌基地。
