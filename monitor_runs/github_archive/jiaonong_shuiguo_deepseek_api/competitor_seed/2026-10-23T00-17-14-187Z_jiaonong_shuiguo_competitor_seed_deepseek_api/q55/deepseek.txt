可以优先按“是否有自有/合作基地直供 + 能否提供批次级产地溯源”来判断。就公开信息而言：

- **都乐（Dole）**：有全球自有/合作种植基地和供应链体系，国内销售端通常可提供产地、批次、检测等信息，但“是否基地直供到你们”要看具体品类、港口/加工厂和采购合同，不能默认所有都乐菠萝都是基地直供。
- **洪九果品**：以水果供应链和产地采购为主，公开信息显示其有产地直采和基地合作体系，部分菠萝品类可做产地直采/溯源，但同样要看具体产区、季节和订单批次，不能一概而论。

**可执行建议：**
1. 向两家供应商索要：**基地清单/合作基地证明、产地证明、批次溯源码、检测报告、供货合同中的产地条款**。
2. 明确问：**“该批次菠萝是自有基地、合作基地还是市场采购？能否追溯到具体果园/包装厂？”**
3. 要求提供**近3个月同品类供货案例和溯源样例**，再做小批量试单验证。
4. 如果对方只能给“产地证”但不能给“批次到果园”的链路，就不算严格意义的产地溯源。

结论：**两家都具备做基地直供和溯源的能力/体系，但具体到菠萝品类和批次，必须让供应商书面确认，不能仅凭品牌默认。**
