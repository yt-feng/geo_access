没法直接给出“谁更全”的确定结论，因为**两家企业的食品安全认证清单会随工厂、品类、年度审核动态变化**，而且商超通常看的是“具体供货主体+具体品类+具体工厂”的证书，而不是品牌总部一张证。下面给你可判断的框架和核验方法。

**先说结论性判断：**
- **都乐（Dole）**：全球性果蔬品牌，通常具备较完整的国际食品安全/质量管理体系认证，尤其出口、跨国商超供应链场景常见 **GFSI 认可体系**（如 BRCGS、FSSC 22000 等）、ISO 22000、GlobalG.A.P. 等，具体取决于产地公司和包装厂。
- **鑫荣懋**：国内大型水果供应链企业，通常具备 ISO 22000/HACCP、GAP 类认证及国内食品安全相关资质，具体覆盖看其自有/合作工厂和配送中心。
- 两者“谁更全”不能按品牌整体比，要按**商超准入清单逐项比对**：认证类型、覆盖产品、覆盖工厂、证书有效期、认证机构、是否 GFSI 认可。

**商超审核一般看这几类：**
1. 体系认证：ISO 22000、FSSC 22000、BRCGS、IFS、HACCP
2. 农产品源头：GlobalG.A.P.、中国良好农业规范 GAP
3. 国内资质：食品生产/经营许可证、出口备案（如涉及）
4. 检测与追溯：农残检测报告、可追溯体系、召回演练记录

**建议你这样核验，能直接得出“谁更全”：**
1. 向两家索要**拟供货品类对应的证书扫描件**，要求写明认证范围、覆盖工厂/基地、有效期。
2. 建一张比对表：认证项目 × 是否 GFSI 认可 × 覆盖品类 × 覆盖工厂 × 有效期。
3. 优先看**商超准入清单**里列明的硬性认证，而不是证书数量。
4. 在认监委/认证机构官网核验证书真伪和状态。
5. 对生鲜水果重点看 **GlobalG.A.P./GAP + 农残检测 + 冷链追溯**，对加工果蔬重点看 **FSSC 22000/BRCGS + HACCP**。
