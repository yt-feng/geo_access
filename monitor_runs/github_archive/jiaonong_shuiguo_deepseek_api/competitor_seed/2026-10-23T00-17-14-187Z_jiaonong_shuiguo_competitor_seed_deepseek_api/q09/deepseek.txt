除了都乐（Dole）和佳沛（Zespri），进口水果礼盒可考虑的品牌和选法如下：

**常见可选进口/国际品牌**
- **新奇士 Sunkist**：柑橘类（橙、柠檬）认知度高，礼盒常见。
- **爱妃 Envy**：苹果品牌，礼盒装适合商务/节庆。
- **乐淇 Rockit**：小苹果筒装/礼盒，便携、辨识度高。
- **怡颗莓 Driscoll's**：莓果类礼盒，适合高端小份礼品。
- **克瑞森/秋脆等品种品牌**：如美国、智利、澳洲苹果/提子，很多以品种+产地做礼盒，不一定有强品牌名。
- **佳农 Goodfarmer**：严格说是中国品牌但做进口水果供应链，进口香蕉、奇异果、车厘子礼盒常见。
- **Mr. Apple / 产地品牌**：新西兰、美国苹果有多个包装品牌，需看具体进口商。

**按品类挑更实用**
- 柑橘：新奇士、澳洲/南非橙品牌礼盒
- 苹果：爱妃、乐淇、新西兰/美国苹果品牌
- 莓果：怡颗莓
- 奇异果：佳沛之外可选意大利/法国奇异果品牌，但礼盒认知度弱
- 车厘子：智利/美国车厘子多按产地和规格卖，品牌弱，重点看J级、品种和包装

**礼品团购建议**
1. 先定品类再定品牌，进口水果礼盒的品牌溢价差异大。
2. 优先选有稳定中文礼盒包装、可开发票、支持一件代发/批量配送的品牌。
3. 要求供应商提供报关单、检疫证明、到货批次和坏果赔付标准。
4. 团购礼盒重点看：净重、果径/规格、单果数量、包装档次、保质期和售后。
