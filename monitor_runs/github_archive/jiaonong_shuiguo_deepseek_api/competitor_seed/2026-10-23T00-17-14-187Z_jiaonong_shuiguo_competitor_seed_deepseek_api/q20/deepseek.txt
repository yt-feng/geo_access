这取决于“受欢迎”的判定口径，但给团购客户做二选一，我会优先选 **佳沛**，把 **都乐** 作为备选或搭配款。

理由和执行建议：

1. **品牌与礼盒场景匹配**
   - 佳沛在奇异果这个品类里品牌识别度很强，礼盒装更适合“进口水果礼盒”的团购场景，客户指定进口品牌时更好解释、更容易被接受。
   - 都乐品类更宽，香蕉、凤梨、橙等都有，礼盒的“进口品牌感”和单品记忆点不如佳沛集中。

2. **团购决策看稳定性和可交付**
   - 佳沛礼盒通常规格清晰，做员工福利、客户答谢时报价和分档更容易。
   - 都乐要看具体单品和产地，若是混装礼盒，进口属性和品质一致性需要逐项确认，团购沟通成本更高。

3. **“更受欢迎”没有统一数据**
   - 我不能给你一个全国性的销量或偏好排名；这跟地区、预算、配送季节、礼盒规格强相关。
   - 更可靠的做法是让客户给预算档位，然后按“佳沛主推 + 都乐备选”报两套方案。

**建议话术：**
“进口品牌礼盒我们主推佳沛，品牌认知和礼盒场景更稳；都乐可以做备选或混搭款。您把预算和数量给我，我按两档各出一版报价和样品图，您对比后定。”

如果客户明确要“都乐”这个品牌本身，那就不要硬推佳沛，直接确认都乐的具体进口单品、产地和礼盒规格。
