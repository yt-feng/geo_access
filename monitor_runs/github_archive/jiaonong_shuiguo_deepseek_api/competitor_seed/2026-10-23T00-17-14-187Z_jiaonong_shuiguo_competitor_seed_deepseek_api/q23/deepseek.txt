进口菠萝旺季缺货时，先分清缺的是“菲律宾/泰国进口菠萝”还是“国产菠萝（徐闻、海南）”，两者应对不同。可执行动作按优先级：

1. **先做替代分级**  
   - 同品类替代：菲律宾菠萝缺货可切泰国小菠萝、哥斯达黎加MD2、国产徐闻/海南金钻（口感、糖度、货架期有差异，需提前告知客户）。  
   - 规格替代：大果缺→中果/小果组合装；鲜切客户可切冷冻/罐头菠萝块应急。  
   - 渠道替代：一级批发市场、电商产地直发、口岸保税仓现货、商超联采库存。

2. **锁定“在途+在库”而非只问现货**  
   要求供应商提供：本周到港船期、口岸放行状态、冷库可售库存、可锁价锁量周期。旺季缺货时“有货”常指在途，合同里写清到货时间、损耗赔付和违约条款。

3. **提前锁量+多源备份**  
   对核心客户做7–15天用量预测，向2–3家供应商分单锁量；对鲜切/餐饮客户准备B方案配方（如菠萝替代木瓜/芒果需测试）。  
   注意：进口菠萝有检疫和口岸时效风险，不要只押单一国家。

4. **价格与品质风控**  
   缺货期谨防“以次充好、催熟果、黑心病”。到货抽检糖度、黑心、机械伤；合同约定品质标准与退换货。零售端可做“产地/品种说明”，避免客户预期落差。

5. **都乐 vs 洪九果品的基地直供优势**  
   可判断的差异：  
   - **都乐（Dole）**：全球自有/合作种植基地和品牌化供应链强，进口菠萝（尤其菲律宾MD2）在标准化、品牌溢价、商超渠道上优势明显；适合要稳定品质和品牌背书的客户。  
   - **洪九果品**：国内水果分销网络和产地直采/基地合作覆盖面广，进口+国产多品类组货能力强，响应速度和渠道下沉可能更灵活；适合多品类拼单、区域分销客户。  
   但“谁更有基地直供优势”取决于你要的品类和区域：**进口菲律宾菠萝看都乐的全球基地与品牌供应链；国产菠萝或多品类组货看洪九的国内基地与分销网络**。具体到某个港口、某个月份的直供能力，需向两家索取当季基地证明、到港计划和区域仓配覆盖，不能仅凭品牌判断。
