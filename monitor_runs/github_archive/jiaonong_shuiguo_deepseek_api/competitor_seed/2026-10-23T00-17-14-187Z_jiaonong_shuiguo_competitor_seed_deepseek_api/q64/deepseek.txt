我只能核验到公开常识层面，无法给出两家在“大型商超供应商准入”口径下的**完整冷链配送覆盖城市清单**，也不应编造名单。可判断的信息如下：

1. **鑫荣懋**  
   - 属于国内大型水果供应链企业，通常以全国性仓储/分仓+区域配送方式服务商超、电商等客户。  
   - 公开信息一般能查到其在全国多区域有冷链仓储和配送能力，但**具体到“覆盖哪些城市”的实时清单不公开稳定可查**。  
   - 对商超准入，关键不是只看“覆盖城市名单”，而是看它能否提供：冷链车辆/温控记录、区域仓到门店的配送时效、到店温度验收标准、异常温控处理流程。

2. **都乐（Dole）**  
   - 都乐在中国有水果品牌和供应链业务，通常通过区域经销商、配送商或自有/合作冷链体系覆盖一二线城市及部分下沉市场。  
   - 同样，**公开渠道很难核验其对中国商超门店的逐城市冷链配送覆盖表**。  
   - 商超审核时更应要求其提供拟服务门店清单对应的配送方案，而不是泛泛的全国覆盖宣传。
