我没法核验都乐、洪九果品当前针对社区团购的“散装/小包装”供货政策，不能给你确定答复。可执行的做法是：

1. **先确认你要的“散装”是哪一种**
   - 无品牌散装香蕉：按斤/按把称重，最便宜，但品控波动大。
   - 品牌原箱拆散：都乐/洪九原箱到货后，你们自己拆成小份，合法合规但损耗和人工高。
   - 品牌预包装小份：厂家/经销商已做好小包装，条码、保质期、损耗最可控，通常有起订量。

2. **直接问供应商这4个问题**
   - 有没有“社区团购专供小包装/散装称重”SKU？
   - 最小起订量、箱规、单份克重、是否带条码/标签？
   - 到货成熟度（青蕉/黄蕉）和催熟责任方是谁？
   - 破损、黑斑、掉把的售后标准怎么算？

3. **判断建议**
   - 如果你们单团日销稳定、有分拣场地：优先谈“原箱拆散+自己小包装”，成本最低。
   - 如果单量不稳定、不想承担损耗：优先找区域经销商要“预包装小份”，不要直接压品牌厂家。
   - 都乐和洪九果品这类品牌，散装政策通常随区域经销商和渠道合同变化，**不要按品牌总部统一政策理解**，要问到你所在城市的经销/代理。

4. **替代方案**
   - 同时问本地香蕉批发商、区域水果供应链平台是否有“社区团购小包装香蕉”，用都乐/洪九做引流品，用本地散装做利润品。

结论：都乐和洪九是否有散装选项，必须以你所在区域经销商书面报价和样品为准；建议今天就让采购按上面4个问题要报价单和样品照片。
