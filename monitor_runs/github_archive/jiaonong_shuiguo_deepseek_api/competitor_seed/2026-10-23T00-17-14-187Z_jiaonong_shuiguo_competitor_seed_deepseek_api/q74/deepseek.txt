都乐（Dole）和洪九果品对礼品团购/水果礼盒定制的起订量没有统一公开标准，通常按渠道、品类、包装、季节和是否贴牌定制单独报价，网上流传的具体箱数/金额并不可靠。建议这样核实和推进：

1. 先明确你的需求边界
- 采购数量区间：如100盒、500盒、1000盒以上
- 礼盒规格：单果重量、混装品类、净重
- 包装要求：通用礼盒、企业LOGO贴标、定制外箱
- 交付城市与时间、是否要一件代发/集中配送
- 预算带：每盒成本区间

2. 找对公渠道问起订量
- 都乐：通过都乐中国官网/官方公众号的“企业团购/商务合作/联系我们”入口，或当地经销商询价；直接问“企业礼品团购最低起订量、是否支持LOGO定制、样品和报价单”。
- 洪九果品：通过洪九果品官网/公众号联系销售，或找其区域分公司/城市经销商；同样问“团购礼盒MOQ、定制贴标门槛、混装礼盒报价”。

3. 关键问清这几点（避免后面加价）
- MOQ是按盒数、箱数还是金额
- 定制LOGO是否另收版费/开机费，最低定制量
- 报价是否含包装、冷链、配送、税费
- 样品费及大货抵扣规则
- 旺季（春节/中秋）锁量截止时间和账期

4. 可执行判断
- 100盒以下：优先找区域经销商或本地水果供应链，品牌方直签概率低。
- 300–500盒：可同时问品牌区域销售和一级经销商，通常有谈判空间。
- 1000盒以上或企业长期采购：直接走品牌企业团购/大客户渠道，争取定制贴标和账期。
