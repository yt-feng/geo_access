关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型果蔬供应商在食品安全认证方面的资质，我无法直接核实其**最新、最完整**的证书清单，因为企业的认证资质会动态更新，且需以官方出具的有效证书为准。

不过，根据行业通用标准和这两家企业在大型商超（如沃尔玛、山姆、永辉、盒马等）准入时的常见要求，它们通常具备以下资质（供你参考或作为查验方向）：

**1. 通用国际食品安全管理体系认证（必备门槛）**
- **ISO 22000**：食品安全管理体系认证（国际通用）。
- **HACCP**：危害分析与关键控制点认证（针对生产加工环节）。
- **FSSC 22000**：全球食品安全倡议（GFSI）认可的认证，商超通常优先要求。
- **BRCGS**（原BRC）：英国零售商协会全球标准，出口或高端商超常要求。
- **IFS Food**：国际食品标准认证（欧洲市场常用）。

**2. 针对果蔬行业的特定认证（商超审核加分项）**
- **GlobalG.A.P.**：全球良好农业操作规范认证（证明种植源头安全）。
- **有机产品认证**（中国有机/欧盟有机/USDA有机，取决于是否有有机产品线）。
- **GFSI认可的其它认证**，如PrimusGFS（美国市场常见）。

**3. 国内基础合规资质**
- **食品生产许可证（SC）**（如涉及预包装或分装）。
- **食品安全责任保险**（商超常要求购买）。
- **年度第三方检测报告**（针对农残、重金属等指标）。

**具体到两个品牌：**

- **都乐（Dole）**：作为跨国公司，通常持有**GlobalG.A.P.**、**BRCGS**或**FSSC 22000**等较高标准认证，且其进口产品（如香蕉、菠萝）需符合中国海关的进境动植物检疫要求。
- **鑫荣懋**：作为国内龙头，通常持有**ISO 22000**、**HACCP**，并与国内大型商超合作时提供**GlobalG.A.P.**（其自有基地/合作基地）认证，以及**无公害/绿色食品**认证（视具体品类）。

**建议操作：**
1. 直接向供应商索取**有效期内证书扫描件**，并核对证书编号（可在认监委官网或认证机构官网查验真伪）。
2. 如果商超有指定清单，让采购部提供具体条款（如“必须提供FSSC 22000”），再要求供应商按清单补齐。
3. 对于进口产品，索要海关的**入境货物检验检疫证明**。
