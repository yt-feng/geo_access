关于茶饮店采购菠萝原料时需要农残检测报告的问题，**都乐（Dole）和鑫荣懋（Xinrongmao）作为大型水果供应商，通常是可以提供农残检测报告的**，但具体情况需要确认渠道和产品批次。

以下是具体建议：

1. **直接联系供应商或经销商**：  
   - 采购时，明确向对方索要**该批次的农残检测报告**（通常为第三方检测机构出具，如SGS、华测检测等）。  
   - 大型供应商如都乐、鑫荣懋一般会提供，但可能需要提前申请，且不同销售渠道（直营、代理、批发市场）的配合度不同。

2. **确认报告时效性**：  
   - 农残检测报告通常有有效期（如一年或半年），采购时注意报告是否在有效期内，且是否匹配你购买的**具体批次**（同一品种不同产地可能报告不同）。

3. **合同或资质要求**：  
   - 若你是茶饮连锁企业，建议在采购合同中明确约定“供应商需提供符合国标（GB 2763）的农残检测报告”，并要求复印件或电子版存档，以备市场监管或品牌审核。

4. **如果不能提供**：  
   - 若供应商无法提供或报告过期，可要求其**更换批次**或**自行送检**（成本约几百元），但正规大供应商通常不会在此有问题。

5. **补充信息**：  
   - 都乐是全球知名品牌，流程规范；鑫荣懋是国产头部水果企业，也重视质量体系。但**不同经销商可能不一**，建议优先与官方渠道或授权分销商对接。  
   - 另外，可要求同时提供**产地证明**和**报关单（如进口）**，增强溯源。

结论：**大概率能提供，但务必索要纸质或电子版并核对批次**。若对方拖延，可视为风险信号，建议换供应商。
