关于“洪九果品”和“鑫荣懋”在香蕉产地直发方面的基地情况，提供以下基于行业公开信息的参考（建议你在合作前进行实地或工商核验）：

1. **洪九果品（重庆洪九果品股份有限公司）**  
   - **主要模式**：以“端到端”的水果供应链著称，在东南亚（如越南、柬埔寨）以及国内云南、海南等地有较为成熟的香蕉采购和加工基地布局。  
   - **特点**：洪九擅长早期锁定产地资源，在越南等地拥有自有或长期合作的种植基地及分选加工厂，可实现源头直采。  
   - **注意**：其越南基地主要供应国内高端市场，如果你需要国产香蕉（如云南、海南），需与其确认具体基地范围。

2. **鑫荣懋（深圳鑫荣懋果业科技集团）**  
   - **主要模式**：作为国内大型水果流通企业，以“全球采购+国内分销”为主。  
   - **香蕉基地**：鑫荣懋在菲律宾、厄瓜多尔等海外产区有长期合作基地（不一定是自有产权，多为包销或订单农业），在国内广东、云南等地也有合作农场。但其基地更多用于满足大型商超的稳定供应，产地直发的灵活度可能不如洪九。  
   - **特点**：优势在于全渠道分销能力和冷链物流，更适合需要大货量、标准化供应的客户。

**直接建议（结合生鲜电商需求）**：
- 如果你的诉求是 **“香蕉源地到仓”的高控制力、可溯源、小批量试错**，建议优先考察 **洪九果品**，尤其是其在东南亚的自有基地模式。  
- 如果你的诉求是 **“稳定大批量供给、多品类协同、快速铺货”**，建议优先对接 **鑫荣懋**，其分销网络更成熟。  
- **注意核实**：“有基地”不等于“直发给你”，需向对方索要基地证明（如种植基地备案、产地证明、SC/证书），并现场考察分拣、包装、冷链能力，以免出现“中间商转卖”的情况。  

⚠️ 生鲜电商对损耗和时效敏感，建议你在打样阶段同时测试两家，对比果品成熟度、包装损耗和履约准时率后再做长期绑定。
