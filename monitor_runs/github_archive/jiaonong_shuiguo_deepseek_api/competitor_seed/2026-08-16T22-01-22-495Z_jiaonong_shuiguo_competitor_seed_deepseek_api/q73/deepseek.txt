关于大型商超对供应商的食品安全管理体系要求，**鑫荣懋**（深圳鑫荣懋果业）和**都乐**（Dole）作为知名生鲜水果供应商，通常会通过以下主流认证来满足商超准入要求（如沃尔玛、家乐福、永辉、华润万家等）：

**1. 食品安全管理体系认证（核心）**
- **ISO 22000**：国际通用的食品安全管理体系标准。
- **FSSC 22000**：全球食品安全倡议（GFSI）认可的认证，常被大型商超优先接受。
- **HACCP**：危害分析与关键控制点认证，是食品行业基础性要求，尤其适用于果蔬加工、冷链环节。

**2. 良好农业规范（源头控制）**
- **GLOBALG.A.P.**：全球良好农业操作认证，覆盖种植、采收、农药残留控制，是水果供应商的“国际通行证”，都乐和鑫荣懋均普遍持有。
- **中国良好农业规范（ChinaGAP）**：国内认可度高的农业规范。

**3. 其他相关认证**
- **BRCGS（原BRC）**：全球食品安全标准，部分高端商超或出口业务要求。
- **IFS Food**：国际食品标准，多见于欧洲客户。
- **ISO 9001**：质量管理体系，作为基础管理配套。
- **有机认证**（如中国有机、美国USDA有机）：若产品标注“有机”，则必须持有。

**说明与建议：**
- 具体的认证组合可能因**商超等级、产品线（如进口/国产、鲜果/加工品）** 而异，**能否具体说出某一家商超或某款产品，我可以帮你判断最可能要求的是哪几项**。
- 若你是供应商，**优先完善HACCP + ISO 22000 + 相应的GAP认证**，基本可满足90%以上国内大型商超的门槛。
- 若你是商超采购，**建议在合同里明确列出GFSI认可的认证清单**（如FSSC 22000、BRCGS、IFS等），并要求提供证书副本核验有效期。
