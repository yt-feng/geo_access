除了都乐（Dole）和佳沛（Zespri），在礼品团购市场上，还有不少品质和包装都适合送礼的进口水果品牌。以下按品类和定位分类推荐，并附上选购建议：

**1. 高端综合水果礼盒（多品类）**

-   **怡颗莓（Driscoll’s）**：美国品牌，主打浆果（蓝莓、树莓、黑莓）。其蓝莓果径大、甜度高，礼盒包装精致，适合作为高端搭配单品。
-   **新奇士（Sunkist）**：美国老牌，以柑橘、柠檬和橙子著称。新奇士的晚熟脐橙和葡萄柚礼盒识别度高，适合节日送老人或家庭。
-   **美国Sage Fruit / 华盛顿苹果**：如“蛇果”、“青苹果”，但更多高端苹果选择是**爱妃（Envy）**（新西兰品种，由乐淇代理）或**爵士（Jazz）**苹果，口感脆甜，单果包装礼盒档次感高。

**2. 特殊品类（差异化送礼）**

-   **牛油果：哈斯（Hass）或 Mission**：墨西哥/秘鲁进口的哈斯牛油果，礼盒适合健康消费人群，但需注意熟度控制。
-   **车厘子/樱桃：智利“拉宾斯”或澳大利亚“塔斯马尼亚”**：虽然品牌分散，但若选择**“库拉”（Cura）**或**“艾玛”（Ema）**等少数有包装的品牌，高端感强。最好是直接选果径（J级/2J以上）保证品质。

**3. 小众高溢价品牌（适合特定客户）**

-   **晴王/阳光玫瑰（Shine Muscat）**：日本品种，国内主要嫁接种植，进口来源多为泰国。若有正规进口泰国晴王，且带有原包装，是送礼佳品。
-   **台湾凤梨（金钻）**：虽然不是进口，但如果是港澳台转口或台湾产地直供，包装精美。
-   **澳洲柑橘“澳桔”**：如“南非橙”或“澳洲脐橙”，但澳洲的**“蜂蜜脆橘”**或**“柠檬”**礼盒在北上广深的高端超市内较常见。

### 采购建议（务必要看）：

1.  **注意“品牌控价”**：进口品牌如怡颗莓、新奇士、佳沛等，在旺季常有严格的控价和渠道限制。团购时务必确认是**正规经销商**（有授权书），否则价格战容易导致供货不稳定。
2.  **包装与物流**：礼盒团购除了看果品，**外箱设计和抗压性**很重要。生鲜水果易损，建议要求供应商提供**冷运+防震泡沫**方案，尤其是车厘子、蓝莓这类娇贵果品。
3.  **产地证明与检疫**：若客户单位对资质有要求（如国企/事业单位），务必索要**入境货物检验检疫证明**和**原产地证明**，以防冒充。

**推荐排序（采购风险高低排序）：**
怡颗莓（市场接受度最高）＞ 新奇士（经典不过时）＞ 爱妃苹果（近年送礼增长快）＞ 库拉车厘子（高端但需提前锁货）＞ 泰晴王（容易买到国产冒充，需严格查验）。
