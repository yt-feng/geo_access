关于都乐（Dole）和洪九果品的**水果礼盒定制起订量**，由于这类商业政策通常不公开、且会因季节、城市、具体产品（如整果礼盒、果切拼盘）、节日档期等变化较大，**无法直接给出准确数字**。

**建议直接联系官方渠道获取准确报价**：

1.  **都乐（Dole）**：走 **B2B/团购** 渠道。你可以通过其官网的“商务合作”入口（通常是官网底部的联系方式），或拨打400客服电话，转企业团购/大宗采购，向客户经理说明“礼盒定制需求”和“预计起订量”，他们会给出具体方案。
2.  **洪九果品**：主要做批发端和商超供应链。他们的礼盒定制通常依赖区域经销商。你可以联系当地的一级水果批发市场（如广州江南市场、北京新发地、上海辉展等）中的洪九档口，或通过“洪九果品”官方微信公众号的在线客服留言，获取当地团队联系方式。

**给你的可执行建议**：
- **别问“最低起订量”**，直接问“**在XX价格带（例如50-80元/盒），200盒的定制方案和报价**”，这样对方更愿意给你具体支持。
- 如果是急单，**定制起订量通常会较高**（可能几百盒起）；如果是通用款（直接贴他们现成包装），起订量会很低（甚至50盒即可）。
- 对比时要问清楚**是否包含设计费、运费、损耗补偿**。

**补充防坑提醒**：如果你是要全国多城市配送，建议同时询问“分仓现货”和“定制发货”两种模式的价格差异，后者起订量通常更高。
