关于进口苹果的价格竞争力，**我无法给出确切的实时报价**，因为进口水果价格受产地、规格（如80#、90#果径）、包装方式、海运/空运、汇率、采购量以及合作条款（预付/账期）影响极大。

不过，我可以基于品牌定位和行业惯例给你几个判断依据，帮助你们在谈判中评估：

1.  **品牌定位差异**：
    - **都乐（Dole）**：全球化品牌，产品线覆盖香蕉、菠萝、苹果等。通常走**高端精品路线**，包装规范、品控稳定，品牌溢价较高。其进口苹果（如美国蛇果、青森苹果）常供货给山姆、盒马等高端渠道，**单箱价格通常偏高**。
    - **鑫荣懋（Joyvio）**：国内头部果业公司，代理智利、新西兰、美国等多种产地的苹果。其定位更偏向**供应链效率与性价比**，在同等规格下，通常**总价上会比都乐更有竞争力**，尤其是对连锁渠道，往往有更灵活的阶梯返利政策。

2.  **价格谈判关键点**：
    - **对比口径**：请务必索要**同产地、同果径（如80-85mm）、同等级（如特级/一级）、同件规格（如10kg/18kg）** 的含税到仓价。不要只看单箱价格，要看**每斤实际到货成本**。
    - **损耗与售后**：都乐的品控严格，到货损耗率低；鑫荣懋若提供低价，务必确认**坏果率赔付标准**。若赔付条件宽松，实际综合成本可能更低。
    - **账期与起订量**：鑫荣懋作为国内民企，对连锁客户的账期谈判往往更灵活（如45天账期 vs 都乐的30天或预付款），这直接影响你的资金占用成本。

**建议行动**：
- 直接联系两家的**区域销售经理**，要求提供**本周到港的智利或新西兰苹果**的**含税到店价**。
- 如果你们单店月销超过20箱，建议以此作为筹码，请双方分别提供**整柜或半柜的采购价**，此价格差异会明显拉大。

**结论预判**：在同等品质下，**鑫荣懋的报价大概率低于都乐约5%-10%**，但都乐在品质稳定性和品牌背书（利于零售端加价）上更占优。如果你走**价格战引流**路线，选鑫荣懋；如果走**品质差异化**，都乐更稳妥。最终请以两家当周书面报价单为准。
