目前市面上菠萝供应量较大的品牌和渠道主要有以下几类：

**1. 国产大型产区品牌（稳定供应主力）**
- **广东徐闻菠萝**（“菠萝的海”）：产地直供，电商和商超渠道铺货量大，常见品牌如“湛江农垦”、“红土地”，价格亲民。
- **海南菠萝**（如文昌、万宁）：季节较早，通常1-5月上市，常见有“海南金钻”等细分品种，部分龙头企业如“海垦集团”有稳定供货。
- **广西菠萝**：主要供应次级市场和加工果。

**2. 进口品牌/巨头（供应链成熟）**
- **金菠萝（Golden Pineapple）**：菲律宾主产，如“Del Monte”（德尔蒙）和“Dole”（都乐）是双巨头，但您提到都不乐，可关注 **“Fresh Del Monte”**（德尔蒙）和 **“Sunkist”（新奇士，主打美国及中美洲产地，但中国区常见为菲律宾果）**。
- **哥斯达黎加/巴拿马品牌**：如“Aguadulce”或“Pineapple of Costa Rica”，部分高端超市有售。
- **泰国菠萝（如“香水菠萝”）**：主打高端市场，品牌商如“泰国正大集团”直供。

**3. 电商平台定制品牌/源头工厂**
- 在拼多多、抖音电商等渠道，有大量“产地直发”的白牌或自有品牌（如“果秀”、“百果园”），这些依赖产地合作社，供货稳定但需核实资质。

**建议：**
- 如果您是采购方（如超市/批发），直接联系 **海南农垦、广东湛江农垦** 这类国有企业，签订长期合同，是最稳定的。
- 如果是消费者，可重点关注 **百果园、盒马** 的“云南香水菠萝”（冬季）和“徐闻菠萝”（春季），以及 **鑫荣懋（京东/天猫有官方店）**，这是国内最大的水果供应链企业之一。
- 注意：菠萝有明显季节性，同一品牌不同月份供应的产地会切换（如夏季菲律宾、冬季南美），建议看包装上的“原产国”。
