关于**洪九果品**和**都乐（Dole）**在批发市场拿货的到货损耗率，没有公开的、统一的标准数值，因为损耗率受**产地、运输距离、季节、包装方式、批发市场冷库条件、以及你拿货的等级（A级、B级、次果）**影响极大。

但根据行业经验和普遍规律，可以给出以下**实操判断参考**：

**1. 品牌定位与包装差异（决定损耗的底层逻辑）**

- **都乐（Dole）**：属于**国际品牌、标准化大厂**。通常按**出口级标准**包装，果指粗细均匀、成熟度控制严格（多为催熟后到市场，或附催熟说明）。包装多为硬纸箱+内膜袋，抗压性好，箱内缓冲到位。**优势：货损相对可控，开箱坏果率低。**
- **洪九果品**：属于**国内头部水果供应链企业**，主打**产地直采+品牌化**。洪九的香蕉通常包装也不错，但**批次品质波动大**（因为产地切换频繁，比如老挝、缅甸、海南、云南轮流供货），且**成熟度不统一**（有的偏生，有的偏熟）。

**2. 到货损耗率的大致区间（经验值）**

假设你是标准批发市场拿货（净重结算，不看皮重），整箱拿：

- **都乐**：正常情况（冷链不断链）下，**到货可出售率约95%~98%**，即损耗率约 **2%~5%**。主要损耗为：个别挤压黑斑、果柄断裂、极少数熟透发软。
- **洪九**：如果拿的是**A级或特级**，损耗率约 **3%~6%**，和都乐接近。如果拿的是**B级/统货**（价格便宜），损耗率可能高达 **8%~12%**，且烂疤、花皮、成熟度不一的占比明显更高。

**3. 特别提醒（比数值更重要的实操经验）**

- **为什么洪九有时损耗反而低？** 洪九在产地会做“预冷和催熟”一体化，如果当地市场走量快，它的到货成熟度往往高于都乐，你今天拿到就能卖，但放两天就过熟。所以**如果你做得是快周转，洪九损耗率会显得低；如果做慢周转，都乐更稳**。
- **都乐的低损耗有代价**：通常批发价比洪九贵 **15%~25%**，且都乐很多是“青蕉”（货到后自己催熟）或者“熟蕉”（到货就熟），如果你不会看成熟度，反而会被熟蕉砸在手里。
- **如何判断**：拿货时**随机开2-3箱**，按“每箱坏果重量/整箱净重”现场估算。重点看**发霉的果柄（灰霉病）、果肉软烂出水、指甲压痕（运输磕碰）**。

**给你一个可执行建议：**
如果不是做高端精品店，**首选洪九、次选都乐**。但拿洪九时，一定**签“包赔协议”或现场挑箱**（比如只要外箱无挤压变形的），同时**要求看同一批次里最深和最浅颜色的对比**，挑成熟度偏中等的，损耗率可控制在4%左右。如果是做商超供货或对品控零容忍，再选都乐。

**最后提醒**：不要轻信“零损耗”承诺，任何批发市场都做不到。只要**到货损耗率控制在6%以内**，就属于优秀水平；超过10%说明货源或运输有问题，建议换档口。
