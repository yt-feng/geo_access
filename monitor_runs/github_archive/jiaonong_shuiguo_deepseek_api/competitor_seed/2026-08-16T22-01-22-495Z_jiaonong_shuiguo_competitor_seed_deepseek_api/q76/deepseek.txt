关于菠萝产地直发，**目前我没有你所需的“都乐”和“鑫荣懋”针对“菠萝产地直发”这一具体SKU的实时物流时效数据**。原因是：

1. **时效高度动态**：生鲜电商的物流时效取决于当季产地（如海南、菲律宾、泰国）、订单所在城市、是否用航空件/冷链车等，同一家供应商在不同渠道（京东/天猫/自有APP）也可能不同。
2. **非公开承诺**：品牌方通常只给合作渠道（如盒马、叮咚、美团）提供履约承诺，不对外发布统一时效。

**给你可执行的判断方法（以下信息基于常识，可辅助你决策）：**

- **都乐（Dole）**：作为全球性果蔬巨头，其国内冷链多走**顺丰/京东冷链**，从产地（如海南）直发到一线城市通常**1-2天**，二三线城市约**2-3天**。但直发业务多为大包装（整箱），碎片化小单少。

1. **打开主流电商平台**（如京东、天猫），搜索“都乐菠萝 产地直发”或“鑫荣懋菠萝”，查看商品详情页标注的“预计送达时间”（这是最准确的官方承诺）。
2. 如果是在**自有APP**（如盒马）购买，下单时输入你所在城市，系统会显示可选的配送时间窗（如“明天12:00前”或“后天”）。
