我无法核验都乐和鑫荣懋针对茶饮渠道的到货损耗率具体数据，也没有可引用的公开统计口径。直接给结论：**这两家的“到货损耗率”不存在统一对外披露值，不能拿一个固定百分比做采购判断**；它取决于品类形态（鲜果/冷冻果肉/果酱/果茸）、规格等级、运输距离、验收标准和季节批次，同一供应商不同月份也可能差很多。

可执行建议如下：

1. **先明确你采购的是哪种形态**
   - 鲜菠萝：损耗主要来自机械伤、黑心、熟度不均、冠芽/果柄修剪失重。
   - 冷冻菠萝块/果肉：损耗主要是解冻失水、冰霜、破碎率、净含量不足。
   - 果酱/果茸：损耗主要是包装破损、净重偏差、批次色差。
   不同形态的“到货损耗率”不能跨品类比较。

2. **向供应商索要同口径数据**
   要求都乐和鑫荣懋分别提供：
   - 近3—6个月你所在区域、同规格产品的到货验收记录；
   - 损耗定义（按重量、件数还是金额）；
   - 是否含运输破损、成熟度不符、黑心、净重不足；
   - 抽样比例和验收标准。
   没有同口径数据的“损耗率”没有决策价值。

3. **自己做小批量对比测试**
   建议各下1—2个批次、同规格同路线，按统一验收表记录：
   - 到货总重/件数；
   - 不合格重量（机械伤、黑心、过熟、霉变、净重不足分开记）；
   - 可利用率；
   - 货架期第2/3/5天损耗变化。
   茶饮原料更应看“可利用率”和“货架期损耗”，而不是单次到货损耗。

4. **合同里写清验收和赔付**
   约定规格（单果重/果径/熟度/糖酸度）、允许缺陷率、抽检比例、超标扣款或退换货、到货温度和时间窗口。鲜果建议把黑心、机械伤、过熟单列。

5. **采购判断**
   如果两家都能稳定供货，优先比“同规格同路线同验收口径下的可利用率+批次稳定性+赔付条款”，不要只比报价或口头损耗率。茶饮端建议先小批量并行测试2—4周再定主供。
