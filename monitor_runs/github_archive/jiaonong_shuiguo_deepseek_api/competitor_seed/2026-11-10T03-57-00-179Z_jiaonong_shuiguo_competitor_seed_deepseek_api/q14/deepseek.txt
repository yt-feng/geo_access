从公开信息看，我只能给你**可判断的维度**，不能替你断言“谁更快”，因为服务响应速度高度依赖区域仓、对接销售、订单量和当地配送商，而且我没有可核验的实时对比数据。

可执行判断建议：

1. **先按你所在城市问区域仓，而不是问总部品牌**
   - 都乐、鑫荣懋在餐饮渠道通常都是总部品牌 + 区域经销商/配送商体系。响应快慢主要看**当地服务商**。
   - 直接问两家：你所在城市是否有餐饮渠道专属仓？餐饮客户平均下单到到货几小时/几天？缺货时是否有替代仓？

2. **用同一张测试单对比**
   - 同一天、同一时段，向两家当地销售发同样的需求：  
     “餐饮渠道，香蕉，周用量X箱，要求成熟度X，配送到X地址，请报：可稳定周供应量、报价、起订量、下单截止时间、最快到货时间、缺货处理方案、售后赔付规则。”
   - 记录：**首次回复时间、报价完整度、可承诺周供应量、缺货替代方案、异常处理时效**。这比品牌名气更能判断服务。

3. **餐饮渠道重点看“稳定性”而非“首次回复快”**
   - 香蕉成熟度波动大，餐饮最怕断供和熟度不稳。优先问：
     - 是否可锁定周供应量？
     - 是否有催熟/分级能力？
     - 断货时能否调货或替代？
     - 质量问题多久内响应、怎么赔？
   - 如果一家首次回复快但周供应量不能锁定、缺货无预案，不适合餐饮稳定供货。

4. **可参考的结论框架**
   - 若你在一线城市且两家都有直营/专属餐饮配送：**用试单和区域仓承诺来定**。
   - 若在二三线城市：大概率取决于当地经销商，**不要只看都乐/鑫荣懋品牌**，要看具体服务商仓储和配送能力。
   - 建议同时保留两家作为主供+备供，餐饮渠道香蕉供应更稳妥。
