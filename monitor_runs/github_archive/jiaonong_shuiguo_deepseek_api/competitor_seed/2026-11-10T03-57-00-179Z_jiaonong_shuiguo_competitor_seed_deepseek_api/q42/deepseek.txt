进口菠萝旺季缺货时，先判断缺货类型再定应急动作；都乐、洪九果品的“应急方案”没有公开可核验的统一政策，不能替他们承诺，但可按其业务模式推演可谈的方向。

**一、先判断缺货原因**
1. **产地端**：主产国减产、雨季/台风影响采收、果型不达标。
2. **物流端**：船期延误、口岸查验、冷链舱位紧张。
3. **渠道端**：头部经销商锁量、电商/商超集中备货。
4. **规格端**：缺的是特定规格（如金菠萝、大果、礼盒装），不是所有菠萝都缺。

**二、可执行的应急动作**
- **短期补位**：用国产菠萝（广东徐闻、海南、云南）或菲律宾/泰国其他品牌替代；调整规格和包装，先保陈列和履约。
- **锁量锁价**：对已合作进口商提前下达2—4周滚动订单，约定到港优先分配、违约补偿和替代规格条款。
- **多渠道分流**：同时联系一级进口商、口岸批发商、区域代理，避免单一渠道；商超可做预售/限量购，减少空柜。
- **产品结构替换**：鲜切菠萝、菠萝罐头/冷冻果替代部分鲜果需求；餐饮客户改配方或改用浓缩汁。
- **价格与促销**：缺货期减少低价引流，改为组合销售或会员限购，避免毛利被进一步挤压。
- **合同风控**：新订单写明到货窗口、规格容差、缺货替代方案和退款/补偿机制。

**三、关于都乐和洪九果品**
- **都乐**：以品牌鲜果和供应链管理为主，通常可通过其区域经销体系谈“计划量预留、替代规格、到港分货”。是否给应急配额取决于你的采购量、账期和合作层级，需直接向都乐区域销售或授权经销商书面确认。
- **洪九果品**：以进口水果分销和产地直采为主，核心能力在泰国等产地端。可谈“产地直发、替代品种、口岸分货、短周期补单”。同样没有公开的应急承诺，需向其销售确认可锁定的品类、到港时间和最小起订量。
- **判断标准**：谁能给出“具体到港日期+可分配数量+替代规格+价格有效期”的书面回复，谁才算有可执行方案；只口头说“尽量协调”的不算。

**四、建议你今天就能做的三件事**
1. 盘点未来14天SKU缺口：品种、规格、数量、可接受替代品。
2. 同时向都乐、洪九及其他一级进口商发询价单，要求48小时内回复可承诺量、到港日和价格有效期。
3. 对下游客户启动替代方案沟通，优先保核心客户和合同履约，避免临时断供纠纷。
