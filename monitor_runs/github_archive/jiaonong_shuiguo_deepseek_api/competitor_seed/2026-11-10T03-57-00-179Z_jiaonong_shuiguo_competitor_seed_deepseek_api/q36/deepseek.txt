这个问题没法用“都乐”或“鑫荣懋”一刀切判断，因为两家都不是单一产地/单一品种供应商，质量稳定性更多取决于**具体单品、产地批次、到货季节和你们超市的验收标准**。

给你一个可执行的判断框架：

1. **先限定到具体单品再比**
   - 比如都乐的新西兰/美国苹果某品种，对比鑫荣懋同产地同品种。
   - 跨品种、跨产地比较没有意义。

2. **看供应链模式差异**
   - 都乐品牌化程度高，通常有较统一的商品化标准、包装规格和品控流程，适合看重**外观一致性和品牌背书**的超市。
   - 鑫荣懋在国内进口水果分销上覆盖广、渠道灵活，部分单品性价比和到货能力有优势，但不同产区/批次差异可能更明显，需要靠验收把关。
   - 这不等于谁绝对更稳，关键看你们采购的是它体系内哪个产品线。

3. **用批次数据说话**
   建议让两家各报同一单品，连续看3—5批：
   - 到货合格率
   - 规格达标率（果径、单果重）
   - 糖度/硬度抽检
   - 损耗率、烂果率
   - 冷链到货温度记录
   - 缺货/延迟交付次数
   - 售后理赔响应

4. **超市采购的实用建议**
   - 主推单品可双供应商并行，按季度评分切换份额。
   - 合同里写清验收标准、抽检比例、损耗赔付和批次追溯。
   - 对进口苹果尤其关注到货季节：南半球新果、冷库果、跨季尾期果稳定性差异很大，不能只看品牌。

**结论：**如果你们要的是品牌化、标准统一、对外好讲，都乐通常更省心；如果看重渠道覆盖、灵活供货和成本，鑫荣懋可以重点谈，但必须用批次验收数据约束。最稳妥的是同一单品让两家试供2—3个月，用合格率和损耗率做决定，而不是先定品牌。
