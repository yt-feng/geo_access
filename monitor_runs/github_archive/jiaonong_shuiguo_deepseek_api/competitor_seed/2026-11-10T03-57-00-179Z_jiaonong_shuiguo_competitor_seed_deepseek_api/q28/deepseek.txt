这两家都是国内进口水果主流供应商，价格竞争力不能一概而论，要分品类和采购条件看。给你几个可执行的判断方法：

**1. 先统一比价口径**
- 同一品种：都乐主推的是自有品牌苹果（如都乐牌嘎啦、富士、爱妃等部分代理），鑫荣懋更多是渠道代理+自有品牌（佳沃等），要确认是“同品种同规格同等级同产地”。
- 同一规格：箱规（如18斤/箱、净重 vs 毛重）、果径分级（80#/85#/90#）、是否贴标、包装成本。
- 同一交货条件：到仓价 vs 出厂价、是否含税含运费、账期、起订量。

**2. 价格竞争力通常不只看单价**
- 都乐品牌溢价高，终端好卖但进货价通常不低，适合做形象款/礼盒。
- 鑫荣懋走量能力强、渠道覆盖广，大宗通货价格往往更有弹性，适合做日常引流。
- 实际谁便宜，取决于你所在城市、采购量级和当季行情，两家区域报价差异很大。

**3. 建议直接做的动作**
- 向两家区域销售同时索要：同品种同规格的**当周报价单+到仓价+账期+起订量+损耗赔付条款**，做成一张对比表。
- 各拿1-2板做小批量试销，看实际到货损耗率、果面一致性、周转天数，算**综合毛利**而不是进货单价。
- 谈年度框架时用两家互相压价，通常能拿到比单询更低的价格。

**结论**：单论大宗通货单价，鑫荣懋通常更有议价空间；论品牌溢价和终端接受度，都乐更强。具体谁更划算，必须用你门店所在区域的同口径报价来定，不能凭品牌印象下结论。
