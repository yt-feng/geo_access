不能仅凭品牌名直接给出“能做到/做不到”的确定结论，因为这取决于具体品类、规格、产地、运输距离、到货验收标准和季节。更可执行的判断方式如下：

1. **先明确“到货损耗率”口径**
   - 是卸货验收时损耗，还是到门店后24/48小时损耗？
   - 统计的是重量损耗、数量损耗，还是不合格品率？
   - 香蕉成熟度到货要求是几号色（如3-4号色）？
   口径不同，3%的难度差异很大。

2. **都乐和鑫荣懋通常具备较强供应链能力**
   - 都乐：品牌化、标准化程度高，香蕉催熟和冷链体系较成熟，适合对规格和稳定性要求高的连锁客户。
   - 鑫荣懋：水果供应链规模大，香蕉品类有产地和配送网络优势，适合多区域、多门店配送。
   但“品牌能力强”不等于“每个区域、每条线路都能稳定低于3%”，尤其夏季高温、远距离配送、门店收货不及时时会明显波动。

3. **建议用试单和合同条款验证**
   - 要求供应商按你的门店城市和到货频次报价，并提供近3个月同类客户/同类线路的香蕉到货损耗数据（要求可核验，不接受口头承诺）。
   - 先做2-4周试单，按统一验收标准逐批记录损耗。
   - 合同约定：到货损耗率≤3%，超出部分按比例扣款、补货或退货；明确成熟度、温度、包装、卸货时限责任。
   - 要求供应商承担“到货前损耗”，门店承担“收货后因存放不当造成的损耗”，责任边界写清。

4. **结论**
   - 都乐和鑫荣懋“有能力做到”低于3%，但是否“对你的具体线路和门店稳定做到”需要试单验证。
   - 如果门店分散、配送距离长、夏季高温或收货不及时，3%是偏紧指标，建议同时引入第三家区域供应商做比价和备份。
   - 不要只看品牌，重点看：产地到仓冷链、催熟控制、配送频次、门店收货SOP和损耗责任条款。
