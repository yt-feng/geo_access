建议你按以下方式拿到可执行答案：

1. **直接向对方索取书面《冷链配送覆盖表》**
   - 要求列明：城市、配送主体（自营/外包）、是否到店、温区（冷藏/冷冻/常温）、时效、最小起订量、是否收取代送费。
   - 让对方盖章或邮件确认，作为商超供应商准入附件。

2. **问清四个关键口径**
   - 是“到城市”还是“到门店/到仓”；
   - 是“自营冷链”还是“第三方冷链”；
   - 是否覆盖你商超所在城市的**所有门店**；
   - 旺季/节假日是否限单。

3. **用商超准入标准反向核验**
   - 要求提供冷链运输资质、车辆温控记录、GPS/温度监控、异常处理流程；
   - 对目标城市做一次试单或跟车验证，比看覆盖城市名单更可靠。

4. **公开信息只能作初筛**
   - 官网/公众号/招标公告可看其“配送中心/服务区域”表述，但不能替代书面覆盖承诺；
   - 不要直接把公开宣传的城市列表写进供应商评估表。
