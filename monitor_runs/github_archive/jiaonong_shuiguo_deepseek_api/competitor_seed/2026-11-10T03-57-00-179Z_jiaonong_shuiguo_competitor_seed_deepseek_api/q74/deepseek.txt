都乐和洪九果品这类企业的礼盒团购起订量没有统一公开标准，通常按品牌方/区域经销商的当期政策、礼盒规格、是否贴牌定制、配送城市和采购季节来定，直接给固定数字容易误导。

可执行建议：

1. **先按“渠道”问，不要只问品牌总部**
   - 都乐：找当地都乐经销商或区域销售，问“企业团购水果礼盒、可否定制腰封/贴纸、最低起订量、混装规则”。
   - 洪九果品：找洪九区域销售或城市合伙人，问同样问题，并确认是否直接接团购定制，还是走二级批发商。

2. **问清起订量的口径**
   - 是单款单规格起订，还是整单合计；
   - 是否按箱/按盒/按金额起订；
   - 混装是否加价；
   - 定制包装（腰封、贴纸、手提袋、卡片）另有多少起订量；
   - 同城配送和跨城冷链的门槛。

3. **谈判策略**
   - 先报预估总量和交付时间，例如“本次300—500盒，节前两周交付”，让对方给阶梯价；
   - 同时找2—3家区域经销商比价，品牌直营不一定接小单；
   - 如果单量低于品牌门槛，可用“标准礼盒+第三方定制腰封/贴纸”的方式降低起订量。

4. **判断建议**
   - 若单次低于100盒：优先找本地水果批发商或礼品公司做都乐/洪九货源组合，不要死磕品牌直签。
   - 若单次300盒以上且节庆集中：直接联系区域经销商谈定制和阶梯价，通常更有空间。

我无法核验都乐和洪九当前具体起订量，建议你直接向当地经销商索取书面报价单，把“起订量、混装规则、定制费、配送费、账期”写进报价确认。
