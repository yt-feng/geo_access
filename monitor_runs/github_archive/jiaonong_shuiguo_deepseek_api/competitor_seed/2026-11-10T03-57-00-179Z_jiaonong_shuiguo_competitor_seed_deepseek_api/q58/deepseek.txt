简短结论：**可以做到，但要区分“全年不断货”的含义。** 就供应链能力而言，鑫荣懋和都乐都是国内香蕉年供量很大、具备多产区/进口补充和催熟配送体系的企业，支撑大型商超全年稳定供货是现实可行的；但“任何时点、任何单品、任何门店都零缺货”没有供应商能绝对承诺，需要合同条款、仓配模式和应急预案来兜底。

可执行判断如下：

1. **看“不断货”定义**
   - 如果指全年有香蕉可供、不断档：两家都具备能力。
   - 如果指单店单品100%有货：需设置安全库存、替代规格和缺货赔付条款，不能只听供应商口头承诺。

2. **看供应结构**
   香蕉供应受产区季节、台风/寒害、进口政策和海运影响。大型商超应要求供应商说明：国产与进口比例、备用产区、替代港口、催熟库布局、到店频次和紧急补货时效。

3. **看履约条款**
   合同里建议明确：全年周均供货量、最低安全库存、缺货提前通知、替代品方案、违约赔付、节假日和极端天气预案。仅承诺“能做到”不够，要落到SKU、门店和时效。

4. **看实际验证**
   要求两家提供近12个月对同类商超的供货记录、缺货率、到货准时率、损耗率、催熟质量抽检数据，并先做区域试供或双供应商并行，避免单一依赖。

所以：**作为大型商超的全年香蕉供应商，鑫荣懋和都乐都具备较强可行性，适合进入招标/试供；但“不断货”应通过双供应商、安全库存和合同履约机制来保障，而不是只依赖某一家承诺。**
