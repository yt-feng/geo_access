都乐（Dole）和洪九果品都没有公开可查的“香蕉分级企业标准”全文。能确认和不能确认的，分开说：

**都乐**
- 都乐有成熟的内部香蕉商品化分级/验收体系（按梳、条、长度、粗度、青熟度、机械伤、色泽等指标分级），用于自有供应链和商超供货验收。
- 但该标准属于企业内部质量控制文件，未作为公开企业标准发布；公开渠道只能查到都乐相关的香蕉产品规格、包装规格和部分商超验收要求，查不到标准编号和全文。
- 结论：**有内部分级做法，无公开可引用的企业标准文本。**

**洪九果品**
- 洪九果品招股书和公开资料中提到对水果有采购、分选、品控流程，香蕉是其核心品类之一，存在内部等级划分（如按果指长度、外观、成熟度分档供货）。
- 同样未公开以“企业标准”形式备案或发布的香蕉分级标准全文；公开信息不足以确认其标准编号、等级定义。
- 结论：**有内部品控分级，无公开可查企业标准。**

**需要核验的路径**
1. 企业标准信息公共服务平台（qybz.org.cn）按企业名称检索“香蕉”，可确认是否有备案企业标准；目前公开检索不到这两家的香蕉分级企标。
2. 都乐中国、洪九果品的供应商准入文件或商超验收单，通常包含分级指标，但属于合同/内部文件，不对外公开。
3. 若你要做自己的连锁店标准，不建议直接引用这两家“企业标准”，可以参照：GB/T 9827（香蕉）、NY/T 517（无公害食品 香蕉生产技术规程）以及商超香蕉验收惯例，自建可执行的分级表。
