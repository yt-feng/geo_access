都乐和洪九果品公开渠道通常以整箱/整件流通为主，是否提供“散装、按根/按小包”的社区团购规格，需要分别向对应区域经销商确认，不能一概而论。给你可执行的判断和问法：

1. **都乐**
- 常见流通形态：按箱（如整箱香蕉/小把装），部分区域会有小把或单根预包装，但属于区域/渠道定制，不是全国统一散装选项。
- 你要问经销商的原话：
  - “有没有适合社区团购的**小把装/单根预包装**？每箱多少把、每把几根、单把克重范围？”
  - “是**原厂预包装**还是你们仓库二次分装？二次分装能否贴标、控熟度？”
  - “最小起订量、混装政策、损耗和催熟售后怎么算？”

2. **洪九果品**
- 公开流通更多是整箱批发、按件走货；小包装/散装往往依赖区域仓或团长渠道做二次分装。
- 你要问的原话：
  - “有没有**社区团购专供小规格**：如5-6根装、1kg内小把装？”
  - “是否支持**按把/按份**发货，还是只能整箱？整箱规格和单根成本怎么算？”
  - “能否提供**催熟到可售状态**的货，还是青蕉到仓后自行催熟？”

3. **实操建议**
- 社区团购香蕉不建议真“散装裸发”，损耗和压伤高。优先选：**小把预包装（5-6根/把）或单根套袋**。
- 先各要一份**小包装报价单+箱规+克重+熟度标准+破损赔付**，用同一口径比价。
- 如果品牌方没有小包装，就让本地批发商做**二次分装**，但必须确认：分装后保质期、催熟责任、破损谁承担。
- 香蕉团购关键不是“有没有散装”，而是**熟度分级和到货时间**：建议要求“到货即售”的熟度，避免青蕉或过熟。

结论：**都乐和洪九是否有散装/小包装，取决于你所在区域经销商和渠道政策，需按上述问题直接确认；社区团购更建议要小把预包装，而不是裸散装。**
