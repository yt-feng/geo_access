做这两家进口苹果的产地溯源，建议按“到货前资料核验—到货时批次绑定—到货后可追溯”三步执行，关键是把**批次号/箱码和报关单、原产地证明、检测报告绑定**，而不是只留一张供应商说明。

## 1. 到货前：核验供应商与单证
- **供应商资质**：都乐、鑫荣懋（或其授权经销商）的营业执照、食品经营许可证、授权经销/供货证明。
- **进口单证**：每批货对应报关单、入境货物检验检疫证明（或海关相关合格证明）、原产地证明。核对品名、产地国、规格、生产/包装日期、批次号。
- **检测与标签**：农残检测报告或供应商合格证明；中文标签是否标明原产国、境内责任人/经销商、生产日期/保质期等。
- **供应链追溯信息**：要求供应商提供果园/包装厂注册号、包装日期、集装箱号或提单号、海运/空运批次信息。能做到“果园—包装厂—出口商—进口商—超市”链条的可优先采购。

## 2. 到货时：批次绑定与留证
- **按批次收货**：同一报关单/同一包装批次作为一个收货批次，不要混批。
- **拍照留档**：外箱标签、箱码/批次号、中文标签、托盘标签、封条号。
- **抽样制度**：每批抽检外观、成熟度、有无腐烂，并记录抽样比例；检测报告与批次号对应归档。
- **系统录入**：在采购/仓储系统中录入供应商、原产国、果园/包装厂注册号（如有）、报关单号、入境货物检验检疫证明编号、到货日期、箱码区间。
- **异常处理**：单证批次与实物标签不一致、无中文标签、无法提供报关或检疫证明的，暂缓上架并退货/换货。

## 3. 到货后：可追溯与日常管理
- **一物一码或箱码追溯**：保留箱码区间与货架/门店的对应关系，至少能追溯到“哪一批、哪个报关单、哪个供应商”。
- **留样与台账**：每批留样并保存单证复印件/电子件，台账保存期限按当地监管要求执行（通常不少于保质期满后6个月，具体以当地规定为准）。
- **供应商考核**：把单证齐全率、批次一致率、检测合格率纳入月度考核；对都乐、鑫荣懋分别建立供应商档案。
- **消费者展示**：可在价签或小程序展示原产国、进口商、报关批次等可公开信息，但不要展示完整报关单等敏感单证。

## 4. 判断标准（可直接执行）
- 能提供**报关单+入境货物检验检疫证明+原产地证明**，且三者产地、品名、批次能对应：可收货。
- 只有供应商口头说明或普通送货单：不收或降级为待验区。
- 箱码/批次号无法与单证对应：按混批风险处理，要求供应商补证或退货。
