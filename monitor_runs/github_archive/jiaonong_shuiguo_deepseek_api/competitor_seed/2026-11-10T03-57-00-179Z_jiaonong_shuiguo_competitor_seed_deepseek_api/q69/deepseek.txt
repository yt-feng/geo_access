结论先说：**都乐的分级和规格统一性通常更稳、更适合超市按标准采购；洪九果品也有分级体系，但更偏大宗流通和国产/进口混合供应，进口苹果的“到店一致性”要更依赖具体批次和供应商执行。**

简要判断：

- **都乐**：品牌化程度高，进口水果供应链成熟，通常按果径、外观、色泽、包装规格做较严格分档，适合超市做标准陈列和稳定定价。但也要注意：都乐不同品类、不同产地、不同包装线会有差异，采购时仍要锁定“果径区间、单果重、着色标准、允许瑕疵率、箱规”。
- **洪九果品**：强项在大宗水果分销和国产精品水果，进口苹果也有做，但分级严格程度更取决于具体产地、加工厂和批次。它适合价格和供应量有优势的采购，但超市如果要求“规格高度统一”，建议先小批量验货，不要只看品牌名。

可执行建议：

1. **先定采购标准**：写明果径mm区间、单果重、着色面积、果形、硬度、糖度下限、碰压伤/虫眼/裂口允许比例、箱装净重和颗数。
2. **要求提供分级样表**：让两家都提供本批次验收标准和大货实拍，不接受只用“一级/特级”这种模糊说法。
3. **到货抽检**：每箱随机抽若干颗测果径和单果重，统计不符合规格比例；超过约定比例就扣款或退货。
4. **小批量试单**：同规格各试1—2批，比较到店后7天内的外观稳定性和损耗。
5. **合同锁定批次标准**：进口苹果受产地和季节影响大，合同里要写明“以封样为准”，并约定换批需重新确认样品。

所以，若你优先要**规格统一、陈列稳定、减少验收争议**，优先谈都乐并封样；若你优先要**成本和大货供应弹性**，可以谈洪九，但必须用封样和抽检条款把一致性管住。
