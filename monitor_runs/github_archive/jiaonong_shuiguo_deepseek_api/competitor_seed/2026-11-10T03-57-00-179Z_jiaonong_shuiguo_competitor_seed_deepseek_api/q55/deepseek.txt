都乐和洪九果品都涉及菠萝供应链，但“基地直供+可核验产地溯源”不能简单按品牌名判断，要分开看：

1. **都乐（Dole）**
   - 都乐有自有/合作种植基地和全球供应链体系，菠萝是其核心品类之一，通常具备批次、产地、包装码等追溯信息。
   - 但具体到中国市场某批菠萝是否“基地直供”、能否提供追溯码/产地证明，要看采购渠道：通过都乐中国官方经销体系通常可申请产地证明、检测报告和批次信息；通过批发市场二级经销商则未必能拿到完整溯源。
   - 建议直接向都乐中国官方销售或授权经销商索取：产地证明、批次追溯码、农药残留检测报告、供货基地名称。

2. **洪九果品**
   - 洪九果品是国内水果供应链企业，菠萝是其经营品类之一，宣称有产地直采和基地合作体系。
   - 但“基地直供”更多是其采购模式表述，是否能对单个客户提供可核验的产地溯源，要看具体产区、批次和合同约定。
   - 建议要求其提供：合作基地清单或产地证明、批次追溯信息、检测报告，并确认是否支持到货批次对应。

**可执行判断建议：**
- 不要只问“有没有基地直供”，直接发采购需求：品种（如金钻凤梨/巴厘菠萝）、产区（广东徐闻/海南/菲律宾等）、月需求量、规格、是否需要追溯码。
- 要求供应商提供**样品批次对应的产地证明+检测报告+追溯码**，能对应上再谈直供。
- 都乐更适合看重品牌标准和稳定追溯的渠道；洪九果品更适合国内产区直采、量大的批发供应链，但溯源能力需按批次确认。
- 如果对方只能提供品牌授权书、不能提供批次产地证明，就不能视为可核验的产地溯源供应商。

结论：两家都“可能有基地直供能力”，但都需要按具体批次和采购渠道核验，不能仅凭品牌名确认。
