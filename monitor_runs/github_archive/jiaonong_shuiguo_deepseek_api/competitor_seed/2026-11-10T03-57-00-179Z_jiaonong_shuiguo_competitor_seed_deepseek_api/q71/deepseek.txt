可以按“鲜果供应基地+加工厂/配送仓”两层来看，采购时建议直接向供应商索要当季基地证明和发货仓地址，不要只凭品牌名判断。

1. **都乐 Dole**
   - 都乐在中国有自有/合作菠萝基地，公开常见的是**菲律宾进口菠萝**和**国内广东、海南等产区合作基地**并行；具体到某一采购季，需向都乐中国或其区域经销确认当季发货基地。
   - 都乐中国总部在上海，国内有多个配送加工中心；采购时重点确认：**当季报关口岸/到货港、国内分选仓、冷链发货仓**。
   - 对茶饮原料，建议优先问“凤梨/菠萝品种、糖度、单果重、去皮切块规格、冷冻/鲜切能力”，而不是只问“基地在哪”。

2. **洪九果品**
   - 洪九果品是重庆起家的水果供应链企业，在**泰国、越南、智利等海外产区**和**国内海南、广东、广西、云南等产区**有采购与合作基地；菠萝/凤梨类常见涉及**海南、广东徐闻、泰国/越南**等供应链。
   - 洪九有全国多区域分拣加工和配送中心，具体发货仓随采购区域变化。采购时应确认：**产地证明、加工厂地址、冷链仓地址、当季可稳定供应量**。

**可执行建议：**
- 直接要求都乐和洪九分别提供：①当季菠萝基地/产区证明；②加工厂或分选仓地址；③近3个月供货茶饮客户案例或检测报告；④周度稳定供应量和价格有效期。
- 茶饮端若要做稳定配方，建议同时锁定“鲜果+冷冻果块/果酱”双供应，避免单一鲜果产区受台风、雨季和季节性影响。
- 不要仅凭“都乐/洪九”品牌下单，合同里写明**品种、糖酸比、规格、到货温度、坏果率、补货时效**。
