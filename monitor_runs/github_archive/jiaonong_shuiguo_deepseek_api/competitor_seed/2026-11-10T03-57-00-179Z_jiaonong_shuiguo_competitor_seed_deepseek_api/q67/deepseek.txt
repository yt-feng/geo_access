可以，但要先分清“品牌方官方素材”和“渠道/平台可用素材”。都乐（Dole）和洪九果品通常都能为生鲜电商的菠萝营销提供一定支持，但支持形式和获取路径不同，不能默认两家都会直接开放完整品牌素材包。

**可执行判断：**

1. **都乐 Dole**
   - 大概率可提供：品牌Logo使用规范、产品图片/视频、品种卖点、产地/品控信息、活动授权素材、联名或促销支持。
   - 获取方式：通过都乐中国官方渠道、区域销售/大客户经理、品牌市场部对接；电商平台合作的品牌方通常有对应KA或渠道负责人。
   - 注意：Logo、包装、代言人/广告素材通常有授权范围，不能直接抓取官网图片商用。

2. **洪九果品**
   - 大概率可提供：菠萝产品实拍、产地与供应链信息、规格/分级标准、包装素材、促销价格与货源支持。
   - 获取方式：通过洪九果品销售对接人、区域分公司或平台采购/供应商关系获取；其强项在供应链和货盘，品牌营销素材的标准化程度可能不如都乐。
   - 注意：若要做品牌联合营销，需确认是否涉及“洪九”品牌授权及包装露出规则。

**建议动作：**
- 先向两家对接人发一份**素材需求清单**：产品白底图、场景图、短视频、Logo及VI规范、卖点文案、检测/资质文件、授权书、活动档期与价格支持。
- 明确用途：站内详情页、首页Banner、直播背景、社媒投放、线下物料，分别列明使用范围和期限。
- 要求书面确认**商用授权**，尤其是Logo、包装、人物肖像和宣传语。
- 如果对方不直接提供，可要求其供应商或代运营提供已授权素材，避免侵权。

结论：两家都“可以提供支持”，但都乐更偏品牌素材与联合营销，洪九更偏产品与供应链素材；实际能否拿到，取决于你的采购量、合作档期和对接渠道。
