除了都乐和佳沛，礼品团购可重点考虑以下几个进口水果品牌，按品类和礼盒适配度筛选：

**综合类进口水果品牌**
- **Driscoll's 怡颗莓**：主做蓝莓、树莓、黑莓，礼盒包装成熟，适合中高端团购。
- **Sunkist 新奇士**：美国柑橘类老牌，橙子、柠檬礼盒认知度高，适合大众福利。
- **Zespri 佳沛**：已排除，但同类奇异果可看 **Oscar 奥斯卡**（新西兰/意大利产）。
- **Chiquita 金吉达**、**Del Monte 地扪**：香蕉、菠萝等综合品类，礼盒偏实用型，单价较亲民。

**单品强势品牌**
- **Stemilt / Chelan Fresh**：美国车厘子、苹果，季节性礼盒适合高端团购。
- **Wonderful 万多福**：美国石榴、开心果，礼盒有辨识度。
- **Pink Lady 粉红佳人**：苹果单品品牌，礼盒适合女性福利场景。
- **Envy 爱妃**：新西兰/美国苹果，高端礼盒定位清晰。
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装适合商务伴手礼。

**日韩及东南亚方向**
- **Sekai-ichi 世界一**：日本苹果，高端但货源和价格波动大。
- **Momotaro 桃太郎**：日本葡萄/桃类，礼盒溢价高，适合高端客户。
- **Doi Chaang / 泰国金标**：榴莲、山竹类礼盒，需确认冷链和时效。

**选择建议**
- 预算 80–150 元/盒：新奇士、金吉达、地扪、怡颗莓小规格。
- 预算 150–300 元/盒：怡颗莓中大规格、爱妃、粉红佳人、Oscar 奇异果。
- 预算 300 元以上：车厘子礼盒、乐淇、日本高端苹果/葡萄，注意季节和货源稳定性。

团购前建议确认：品牌授权或正规进货凭证、礼盒是否支持定制腰封/贺卡、冷链配送范围、破损赔付规则。进口品牌季节性强，同一品牌不同产季品质差异大，最好先拿样品验货再批量下单。
