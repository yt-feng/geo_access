这个问题没法用“谁更愿意”直接下结论——两家都是大型水果供应链企业，签年单的意愿不取决于企业性格，而取决于**品类、体量、账期和你的渠道稳定性**。从公开可核验的信息看，可以给你一个判断框架：

**1. 两家业务模式不同，对年单的接受度场景不同**
- **鑫荣懋**：以进口水果和全品类供应链为主，客户结构里商超、电商、餐饮大客户占比较大，本身就有较强的年度框架协议合作经验。如果你的采购量稳定、品类集中在进口/高端果品、结算规范，它对年单的接受度通常较高。
- **洪九果品**：核心优势在自有品牌和产地直采（尤其东南亚进口水果、榴莲等），过去几年扩张快，对大宗稳定订单有需求，但更看重单品的走量和回款效率。如果年单品类窄、量大、账期短，谈判空间会更大。

**2. 真正决定“愿不愿意”的四个变量**
- **年采购额**：低于对方大客户门槛，年单很难谈到好条件，对方也不一定愿意锁量。
- **品类集中度**：单一爆品年单（如榴莲、车厘子）比全品类年单更容易谈。
- **账期与履约保障**：水果行业价格波动大，供应商对长账期年单普遍谨慎；你能给预付款或短账期，意愿会明显上升。
- **你的渠道稳定性**：有稳定下游（商超、电商、批发档口）比纯贸易转手更容易拿到年单。

**3. 可执行建议**
- 不要先问“谁愿意”，而是准备一份**年度采购计划书**：预估年量、月度分布、品类结构、结算方式、违约条款，同时发给两家询价。
- 分别约谈，重点问：年单是否锁价、锁量比例、调价机制、账期要求、最低起订量。
- 用两家的报价和条款互相参照，但注意水果年单通常不是固定价，而是**框架量+浮动定价**，重点谈调价触发条件。
