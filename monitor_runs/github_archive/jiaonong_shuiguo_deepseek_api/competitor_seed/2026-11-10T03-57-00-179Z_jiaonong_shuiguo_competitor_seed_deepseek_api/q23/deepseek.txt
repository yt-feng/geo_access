进口菠萝旺季缺货时，可以按“先保供、再锁价、后替换”的顺序处理，同时两家公司的“基地直供优势”要分开看：都乐强在全球产地和品牌化供应链，洪九果品强在国内分销网络和东南亚水果集采，但是否“基地直供”要以当期合同和产地证明为准，不能仅凭品牌名判断。

**一、旺季缺货的可执行应对**

1. **立刻做缺口测算**：按未来4周销量、在途量、库存、合同锁量算出周度缺口，区分鲜切/餐饮客户和零售整果客户，优先保高毛利和长约客户。
2. **切换产地**：菲律宾台风季或船期延误时，可询泰国、越南、哥斯达黎加等替代产地，但需确认品种、甜度、规格和准入要求是否匹配。
3. **锁在途与舱位**：对已下单未发运的货，要求供应商提供装船证明和到港时间；对缺口部分优先买“在途货”或“港口现货”，比重新排产快。
4. **短保替代**：零售端可用国产菠萝或菠萝罐头/冷冻果块做过渡，餐饮端可调整菜单或做限时替代，避免断货投诉。
5. **价格与合同**：缺货期避免全量追高，采用“部分锁价+部分现货”组合；对长期客户提前沟通调价或减量，防止履约纠纷。
6. **验货前置**：旺季抢货容易混级，到港前要求第三方或自检青果成熟度、黑心、冠芽和箱规，减少到仓后损耗。

**二、都乐和洪九果品的直供优势对比**

| 维度 | 都乐 | 洪九果品 |
|---|---|---|
| 核心优势 | 全球产地资源、品牌化标准、商超和餐饮渠道成熟 | 国内分销网络广、东南亚水果集采和分拣能力强 |
| 直供能力 | 更偏向全球采购+自有/合作基地+标准化供应链，适合对品质稳定和品牌背书要求高的客户 | 更偏向产地集采+国内分拨，适合需要快速铺货、多SKU组合和区域分销的客户 |
| 风险点 | 进口依赖度高，旺季同样受船期和产地天气影响 | 直供深度和自有基地比例需按品类和合同核实，不能一概而论 |

**结论**：如果缺货发生在进口旺季，优先用都乐这类全球供应链做品质和品牌保供；如果缺口需要快速覆盖区域门店和多渠道分销，洪九果品的集采和分拨效率可能更实用。签约前要明确三件事：产地证明、是否自有/合作基地直采、缺货时的替代和赔付条款。
