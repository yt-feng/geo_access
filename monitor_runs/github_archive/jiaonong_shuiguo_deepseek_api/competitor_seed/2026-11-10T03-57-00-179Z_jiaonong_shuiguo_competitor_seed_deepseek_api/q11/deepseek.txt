我没法核验两家当前的具体报价、规格、促销政策和到货品质，所以不能直接给出“谁性价比更高”的结论。但可以给你一套门店可执行的判断方法，按下面4步比，基本能选出适合你门店的菠萝。

**1. 先统一口径，别只比“每箱价格”**
按同一个可比单位算：
- 到手成本/斤 =（箱价 + 运费 + 损耗分摊）÷ 实际净重
- 真实毛利率 =（门店售价 - 到手成本/斤）÷ 门店售价
- 单箱可售毛利 = 实际可售斤数 × 单斤毛利
- 损耗率 =（到货重 - 可售重）÷ 到货重

都乐通常品牌溢价高、标准化程度可能更好；洪九果品是水果供应链企业，渠道和批次差异可能更明显。**最终要看同一批次、同一规格的实际到货表现。**

**2. 用同一门店做7天小规模对比测试**
建议各进1—2箱，同店同期上架，记录：
- 到货成熟度：青果比例、熟果比例、坏果率
- 可售率：削皮/去眼后的净果重
- 货架期：第1、3、5天可售比例
- 口感稳定性：甜度、纤维感、酸度
- 顾客反馈：复购、投诉、试吃转化

**3. 算“综合性价比”，不是“进货价低”**
综合性价比 = 可售率 × 口感稳定 × 货架期 × 供应稳定性 ÷ 到手成本。
如果都乐贵10%但可售率高、损耗低、投诉少，可能更划算；如果洪九便宜20%但坏果多、成熟度不齐，门店实际毛利可能更低。

**4. 采购谈判时重点问清**
- 是否可固定规格、固定成熟度发货
- 坏果/烂果赔付标准
- 最小起订量和配送频次
- 促销支持、陈列物料
- 同批次质检报告和产地信息

**给你的直接建议：**
