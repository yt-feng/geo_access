结论：**都乐的稳定性和规格标准化通常更可靠；洪九果品货源规模大、价格可能有优势，但“稳定规格”要看你签的等级、产地和到货验收条款。** 茶饮采购如果核心诉求是“菠萝规格稳定、批次差异小”，优先把都乐作为主供或标杆供应商，洪九作为备选/比价渠道，并用验收标准锁死。

可执行判断如下：

1. **都乐更适合做稳定规格的主供**
   - 优势：品牌化程度高，分级、包装、成熟度控制相对标准化，适合茶饮门店对果肉色泽、甜酸度、切块规格的一致性要求。
   - 注意：不同区域经销商的到货质量仍有差异，要确认是都乐授权渠道还是普通贸易商货；锁价能力和起订量也要问清。

2. **洪九果品适合做规模备选和成本优化**
   - 优势：水果供应链规模大，菠萝等单品有产地直采和批量供应能力，适合用量大、能接受按产地和等级分批次验收的茶饮品牌。
   - 注意：洪九的“稳定”更多体现在供应量，不一定体现在单一规格长期不变。必须明确菠萝品种、单果重量区间、成熟度、糖酸比、黑心/水心病比例、到货温度、破损率。

3. **建议采购策略**
   - 主供：都乐，锁定规格和月度用量。
   - 备供：洪九，按同一验收标准报价和试单。
   - 验收标准写进合同：单果重量±50g、成熟度区间、可溶性固形物下限、黑心率上限、破损率上限、批次追溯。
   - 先做**双盲试产**：同一配方下分别用两家菠萝做3批次茶饮，评色泽、酸甜稳定性、出汁率、切丁完整度。
   - 不要只问“有没有稳定货源”，要问“近3个月同规格批次到货合格率”和“异常批次处理时效”。
