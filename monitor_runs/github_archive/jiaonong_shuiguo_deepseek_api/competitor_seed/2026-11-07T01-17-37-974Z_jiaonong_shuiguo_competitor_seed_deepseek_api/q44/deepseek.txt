我不能核验这两家具体到“进口苹果对水果连锁供货稳定性”的实时数据，所以不做谁更稳的结论。可直接按下面方法判断和决策：

**1. 先定义“稳定”的考核口径**
对连锁门店，建议看四项：
- 周度可承诺SKU数/品规数（如嘎啦、富士、爱妃等分开）
- 订单满足率（按门店/仓，周维度）
- 到货准时率与冷链到店温度合格率
- 缺货补货响应时间（报缺后48/72小时）

**2. 向两家要同一套试单数据**
让都乐和鑫荣懋各报：
- 未来8周进口苹果可供品规、产地、到港周次、每周可锁量
- 锁价/浮动价规则、最小起订量、账期
- 区域仓到你们门店的配送时效和冷链责任
- 缺货替代方案（同品种不同规格/产地）

**3. 做4—6周双源试单**
选10—20家代表性门店，两家各占一部分量，按同一口径记录订单满足率、准时率、损耗率、客诉率。不要只看采购报价，算“到店可售成本”。

**4. 合同层面锁稳定性**
- 周度锁量而非仅年度框架
- 订单满足率低于约定值的补偿/替代条款
- 到货质量标准、温控和退货责任
- 旺季优先供应条款

**结论建议：** 先不要二选一。用4—6周双源试单，以订单满足率、准时率、损耗率三项做主评分，再决定主供/备供比例。若你们门店集中在某一区域，还要优先问两家在该区域是否有进口苹果专用仓和固定冷链线路，这通常比品牌本身更影响稳定性。
