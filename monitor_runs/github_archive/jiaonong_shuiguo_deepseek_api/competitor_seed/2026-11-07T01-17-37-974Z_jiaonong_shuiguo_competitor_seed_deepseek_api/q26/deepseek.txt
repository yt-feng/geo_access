结论先说：**单看“稳定品质”这个核心诉求，都乐通常更稳妥；鑫荣懋不是不靠谱，而是更依赖你所在区域的实际到货批次和对接的供应商层级。** 两家都不是专门做茶饮果酱的供应商，本质是鲜果供应链公司，所以“谁更靠谱”不能只看品牌，要看你拿到的是哪条产品线、什么规格、哪个产季、谁给你做售后。

**判断建议：**

- **要省心、标准化、跨区域门店一致**：优先选都乐。它的品牌化程度高，鲜果分级和品控体系相对成熟，适合连锁茶饮对“每批菠萝酸甜度、成熟度、纤维感”要求一致的情况。
- **要成本、本地化服务、灵活供货**：可以重点谈鑫荣懋。它在国内水果分销网络强，区域响应可能更快，但不同区域、不同经销商拿到的货差异会更大，必须锁死规格和验收标准。
- **做果酱不看品牌看指标**：不管选谁，都要明确菠萝品种、成熟度、糖度范围、酸度、纤维粗细、是否带芯、冷冻还是鲜果、到货温度、批次允许偏差。茶饮果酱的稳定性，70%取决于你的验收标准和工艺，不是供应商品牌。
- **先小批量盲测**：让两家各供2到3个批次，同一配方做果酱，测出成率、颜色、香气、酸甜平衡、纤维口感、冷藏/冷冻后析水情况，再决定主供和备供。
- **不要单一供应商**：建议一家主供、一家备供，合同里写清批次不合格的退换和赔偿条款。茶饮店最怕的是旺季断供或批次波动。

简单说：**都乐偏“稳”，鑫荣懋偏“灵活和成本”，但最终靠你的验收标准和盲测数据定。** 如果你告诉我门店所在城市、用量规模、用鲜果还是冷冻果，我可以帮你把询价和验收指标列得更具体。
