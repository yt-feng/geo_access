都乐（Dole）和洪九果品的菠萝供应基地，公开可查的信息如下，采购时建议以对方销售确认的“备案果园/包装厂”为准：

**都乐 Dole**
- 都乐在中国市场的菠萝以进口为主，主要来源是菲律宾和泰国。都乐在菲律宾有自有/合作菠萝种植基地（棉兰老岛等产区），在中国国内主要是分选、包装和冷链配送，不是国内大规模种植基地。
- 国内采购对接时，应要求供应商提供具体批次的原产地证明、果园/包装厂注册信息，而不是只看“都乐”品牌。

**洪九果品**
- 洪九果品是水果供应链企业，菠萝来源以海外采购+国内产区采购为主，海外包括泰国、菲律宾等，国内在海南、广东徐闻等菠萝产区有采购或合作基地。
- 洪九的“基地”更多是合作果园/产地直采模式，具体基地位置随季节和批次变化，需向洪九销售确认当季备案产地。

**给采购的可执行建议**
1. 不要只问“基地在哪”，要问：当季可供货产地、果园注册号/包装厂号、可提供的检测报告和追溯码。
2. 菠萝稳定供应建议双源：海外（菲律宾/泰国）补淡季，国内（海南、广东徐闻）补旺季，避免单一产地断供。
3. 要求供应商提供近3批到货的糖度、成熟度、黑心病抽检数据，作为稳定供应评估依据。
4. 都乐和洪九的具体基地属商业信息，公开资料有限，签约前让对方书面确认产地和换产预案。
