都乐（Dole）和鑫荣懋都可以提供产地溯源和品控证明，但需要你主动在合同/订单环节明确要求，并确认具体证明的颗粒度和出具主体。

**都乐（Dole）**
- 通常具备较完整的自有或合作种植园管理体系，可提供产地信息（国家/产区/农场或包装厂编号）、批次号、采收与包装日期。
- 品控方面一般有内部质量标准、农残检测报告、第三方检测（如SGS、华测等）可按批次提供，部分客户可拿到GlobalG.A.P.等认证复印件。
- 注意：追溯通常到“包装厂/批次”层级，不一定能逐箱追溯到具体农户地块；第三方检测报告需要提前约定由谁承担费用、按什么频次抽检。

**鑫荣懋**
- 国内水果供应链企业，香蕉有国产和进口来源，能提供产地证明、批次追溯、检测报告和品控记录，具体取决于其供货的是自有基地、合作基地还是进口代理货。
- 对国产香蕉可谈“基地直采+批次追溯”；对进口香蕉通常追溯至进口批次和境外包装厂。
- 注意：其证明能力因品类和区域分公司而异，需要在询价时明确到“哪一批货、哪个基地/包装厂、哪份检测报告”。

**可执行的核验建议**
1. 报价阶段就发一份《溯源与品控资料清单》，要求逐项填写：产地（国/省/县/基地或包装厂）、批次号规则、采收/包装日期、农残检测项目与检出限、检测机构、报告有效期、认证证书编号。
2. 要求提供近3个月同品类批次的样例报告和追溯记录，先验证格式和可核验性，再谈合同。
3. 合同里写明：每批随货提供追溯单和检测报告；抽检不合格的处理与赔付；报告造假或溯源断链的违约责任。
4. 对“可追溯”定义达成书面一致：是追溯到包装厂、基地，还是地块/农户；避免口头承诺。

总体判断：两家都“有”，但都乐的体系化程度通常更稳定，鑫荣懋的灵活性更强、需按具体货源确认。建议同时向两家索要同品类样例资料做对比，再决定是否进入样品和验厂环节。
