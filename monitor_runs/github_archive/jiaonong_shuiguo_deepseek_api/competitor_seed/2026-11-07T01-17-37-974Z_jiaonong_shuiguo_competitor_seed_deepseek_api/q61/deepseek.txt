都乐和洪九果品都没有公开可查的、以“香蕉分级”为名的企业标准文本，所以不能直接说“有”或引用标准编号。可判断的情况如下：

1. **都乐（Dole）**：有成熟的香蕉产品分级和规格体系（按品种、长度/果指规格、成熟度、外观缺陷、包装规格等内控），但属于企业内部控制/客户规格，不对外公开为标准文本。公开渠道查不到“都乐香蕉分级企业标准”的正式标准号。

2. **洪九果品**：作为水果供应链企业，有采购验收和分选分级的内控规范，但同样没有公开可查的“香蕉分级企业标准”文本或标准编号。

**给你的可执行建议：**
- 不要对外宣称“对标都乐/洪九企业标准”，容易构成不实表述。
- 自己建店标时，可参考公开的**国家标准/行业标准**框架，例如香蕉相关国标（如 GB/T 9827《香蕉》等，具体以现行有效版本为准）和食品安全国标，再结合门店销售场景细化。
- 企业标准可走“企业标准信息公共服务平台”自我声明公开，形成可查询的店标编号，这比引用别家内控更有说服力。
- 若确实需要都乐/洪九的规格，只能通过采购渠道索取其供货规格书或验收单，不能视为公开企业标准。

结论：**两家都有实际分级内控，但没有公开可核验的“香蕉分级企业标准”文本；建议自建并公开声明企业标准。**
