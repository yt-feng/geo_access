都乐和洪九果品的礼盒定制起订量没有公开统一标准，实际取决于采购渠道、礼盒规格、包装定制程度和是否走企业团购/经销体系，不能直接给一个固定数字。可执行判断如下：

1. **都乐**：零售端以标准礼盒为主，企业团购定制通常要通过都乐官方企业团购、区域经销商或授权渠道谈。起订量常见会按“整箱/整托/整车”或“定制包装最低印量”核算，包装越定制、SKU越分散，起订量越高。建议直接问：①是否支持企业LOGO/外箱定制；②是按礼盒数还是整箱数起订；③同城配送和全国仓配的门槛。
2. **洪九果品**：更偏批发和渠道分销，礼盒定制一般走区域销售或经销体系，起订量往往与单品采购量、包装印量和配送区域绑定。建议直接问：①定制礼盒最低起订盒数；②是否接受多品类混装；③包装打样费和版费；④是否含冷链/落地配。
3. **询价时统一让对方书面确认**：起订量、是否含包装设计打样、版费、样品费、交货周期、破损赔付、发票税率、配送范围。不要只问“起订量多少”，要问“按我们这款礼盒和定制要求，最低起订量多少”。
