不能直接给出“谁更愿意”的确定结论：这取决于品类、区域、采购量、账期和你方的渠道能力，而且两家公开信息里并没有“年单意愿”这种可直接比较的指标。可执行的判断方法是：**先按品类匹配度筛选，再用账期和采购承诺做试探性询价，看谁愿意进入框架协议谈判。**

**两家特点（供你判断，不替代尽调）：**
- **鑫荣懋**：以水果供应链、商超/零售渠道配送见长，通常更看重稳定渠道和标准化供货能力。若你方有稳定零售或团购出货、能接受规范账期和品控流程，谈年度框架的可能性相对更顺。
- **洪九果品**：以进口水果、自有品牌和批发分销为主，历史上对大宗、单品爆量的合作更敏感。若你方采购集中在几个进口单品、量大且回款快，洪九可能更有动力谈年单；但其经营和财务波动需重点做供应商风险审查。

**建议你按这四步判断：**
1. **列SKU清单**：把年采购量、单品集中度、目标价、账期写清楚，分别发给两家。
2. **问框架条件**：直接问“年度框架协议的最低采购承诺、返利阶梯、账期、调价机制、违约条款”，看谁愿意给书面条款。
3. **看响应质量**：谁愿意派业务负责人对接、给样品和报价、接受小批量试单，谁的年单意愿更真实。
4. **做风险审查**：查两家近一年财报/公告、诉讼和供应链纠纷，尤其洪九的现金流和债务情况；年单供应商不宜只看意愿。

**结论**：若你方是商超/零售稳定渠道，鑫荣懋更可能愿意谈规范年单；若你方是进口单品大宗批发、回款快，洪九可能更积极，但必须加风险条款。最终以两家书面框架报价和试单结果为准，不要只凭“意愿”签约。
