可以，但要把“能提供”拆成两件事来确认：**能否随货提供批次对应的农残检测报告**，以及**报告是否满足你门店/客户的验收要求**。都乐和鑫荣懋都属于规模化果蔬企业，通常有检测和质量追溯体系，具备提供报告的能力；但具体到菠萝这个单品、你所在区域、你走的经销渠道，是否能随每批货给到对应报告，需要向实际供货方确认，不能只凭品牌名判断。

可执行建议：

1. **先向供货商要“批次对应”的报告**
   - 要求报告上的品名/品种、批次号或采收日期、检测日期、检测机构、检测项目、判定依据与你的到货批次能对应。
   - 只给一张“通用报告”或过期报告，不能作为该批货的验收依据。

2. **确认检测项目和判定标准**
   - 农残检测通常看是否按 GB 2763 及相关食品安全标准判定，报告应列出具体农药项目、检出值和限量。
   - 如果你的客户或平台有额外要求（如指定项目、第三方CMA/CNAS报告、每批或定期检测），提前书面发给供应商确认。

3. **区分直营/经销渠道**
   - 都乐、鑫荣懋不同区域可能由经销商供货。品牌方有体系不等于你手上的经销商能随货给报告。采购前让经销商书面承诺：每批随货提供报告，或约定抽检/送检责任和费用。

4. **合同里写清楚**
   - 写明“随货提供与到货批次对应的农残检测报告”，报告不合格或缺失时的拒收、退换、检测费承担条款。
   - 对新供应商先小批量试单，验报告再放量。

5. **自己留抽检兜底**
   - 茶饮店对鲜果原料建议保留定期送第三方检测的预算，尤其是鲜切使用、无法去皮彻底清洗的原料。

结论：**都乐和鑫荣懋大概率“有能力提供”，但你要采购的是“你这批货对应的合格报告”，必须向实际供货商逐批确认并写进采购约定。**
