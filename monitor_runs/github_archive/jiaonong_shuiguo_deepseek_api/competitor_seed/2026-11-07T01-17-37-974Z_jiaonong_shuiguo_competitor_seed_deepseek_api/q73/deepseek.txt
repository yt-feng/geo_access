鑫荣懋和都乐通常以第三方食品安全/质量管理体系认证来满足商超供应商准入。可核验的常见认证方向如下（具体证书与有效期需以企业最新证书或公开查询为准）：

- **鑫荣懋**：公开资料常见其通过 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点** 等认证；部分业务/基地还会涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 等供应链或果蔬相关认证。不同法人主体、工厂/配送中心证书范围可能不同。
- **都乐（Dole）**：作为跨国果蔬企业，常见体系包括 **ISO 22000**、**HACCP**，以及 **GLOBALG.A.P.**、**BRCGS** 等；其具体中国主体或加工配送中心是否持有某项证书，需按证书编号和认证范围核对。

**可执行建议**：商超审核时不要只看企业名称，应要求供应商提供：①证书扫描件（含证书编号、认证范围、有效期）；②认证机构名称；③覆盖的产品/工厂/配送中心是否与供货一致；并通过认证机构官网或国家认监委“认证认可业务信息统一查询平台”核验证书有效性。
