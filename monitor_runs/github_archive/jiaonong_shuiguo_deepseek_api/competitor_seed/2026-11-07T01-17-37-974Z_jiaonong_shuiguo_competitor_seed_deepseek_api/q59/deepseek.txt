账期属于具体商务条款，通常不公开且会随客户规模、采购量、合作阶段、品类和区域变化，不能给出都乐或洪九果品的固定账期天数。可执行判断如下：

1. **都乐（Dole）**：多为品牌化、标准化供应链体系，账期一般由经销/直供合同约定；大客户、长期合同才更可能谈到账期，中小采购通常现款或短账期。建议直接联系都乐中国区销售/经销商，询问“直供还是经销、账期起算点、结算周期、是否收保证金”。

2. **洪九果品**：属于水果供应链企业，客户结构里有商超、电商、批发等，账期更可能按客户类型和单品分别谈；不能按公开信息推断统一账期。建议联系其区域销售，明确“香蕉单品、月度采购量、配送区域、对账周期、承兑或电汇”。

**谈判时重点确认：**
- 账期是“货到验收后N天”还是“月结N天”；
- 是否要求预付款/保证金；
- 逾期是否停供、有无违约金；
- 香蕉损耗和退换货如何计入对账；
- 是否含税含运费。

**建议话术**：“我们计划月度采购香蕉约X吨，配送到X区域，希望申请货到验收后30天账期；请确认贵司对新增客户的最短合作周期和授信条件。”

如果是要做供应商比选，可以同时向都乐经销商、洪九区域销售、本地一级批发商各要一份书面报价，统一按“账期+单价+损耗承担+配送”四项比较。
