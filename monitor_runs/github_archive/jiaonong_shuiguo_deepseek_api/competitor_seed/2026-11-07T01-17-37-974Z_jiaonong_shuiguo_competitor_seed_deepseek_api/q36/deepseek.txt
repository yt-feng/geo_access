我没有可核验的批次抽检数据，不能直接给出“谁更稳定”的定论；按可操作判断，**都乐更偏标准化、稳定，鑫荣懋更偏区域/季节采购灵活，稳定性更依赖具体产区、批次和到货链路**。超市采购建议这样选：

1. **先看货源结构**  
   - 都乐：进口苹果多来自其全球供应链，等级、包装、成熟度标准通常更统一，适合做长期稳定陈列和促销品。  
   - 鑫荣懋：国内果业供应链强，进口苹果常随产季和渠道变化，可能同规格下不同批次差异更明显，但采购灵活、成本空间可能更大。

2. **不要按品牌一刀切，按“单品+产区+批次”定**  
   重点比较：同品种（如嘎啦、富士、加力果）、同规格、同产季、同到货港。要求供应商提供近3批到货的糖度、硬度、果径、瑕疵率、损耗率记录。

3. **超市实操测试**  
   先各做2—3批小批量试销，记录：到货损耗、7天货架期损耗、顾客投诉、外观一致性、口感稳定性。连续3批稳定再签长期。

4. **合同里锁稳定性指标**  
   约定果径合格率、瑕疵率上限、糖度下限、硬度范围、到货温度、冷链时长、批次追溯和退换货条款。谁能在合同里稳定承诺这些，谁更适合你。

**结论：** 若你追求陈列标准和长期省心，优先试都乐；若你追求成本和本地响应，可重点试鑫荣懋，但必须用连续批次数据验证。最终以你所在区域实际到货批次为准，品牌名不能替代批次管理。
