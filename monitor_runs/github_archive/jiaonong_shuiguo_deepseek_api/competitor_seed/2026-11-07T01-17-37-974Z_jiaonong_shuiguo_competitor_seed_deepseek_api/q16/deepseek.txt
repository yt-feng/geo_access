从公开可核验的信息看，无法直接给出“洪九果品一定比鑫荣懋便宜”的结论；两家对夫妻老婆店的到货价，取决于你所在区域、品类、起订量、账期和是否是本地经销商拿货。

可判断的结论如下：

1. **洪九果品**更偏水果供应链和批发分销，核心优势在部分进口/国产单品（如榴莲、火龙果、车厘子等）的产地直采和批发流通；对下沉市场小店，实际价格往往由当地一批/二批或区域经销商决定，不一定能直接拿到“总部低价”。
2. **鑫荣懋**偏品牌化水果供应链和商超/渠道分销，终端品牌和标准化程度更强，通常更适合有陈列、动销要求的门店；对小店单店小批量，价格未必有优势。
3. **价格敏感的小店**，不能只看进货单价，要看：  
   - 同规格同等级到店价（含运费、损耗）  
   - 起订量门槛  
   - 退换/损耗赔付  
   - 账期或现结折扣  
   - 是否强制搭售  
4. **实操建议**：选3—5个你常卖的单品（如苹果、香蕉、橙子、火龙果、榴莲），分别向当地洪九和鑫荣懋经销商索要**同等级、同规格、到店含运价**，按“每斤到店成本+预估损耗”比价。通常本地批发市场一批的价格会比品牌供应链单店报价更灵活。  
5. **如果只能二选一且单店量小**：优先问本地经销商谁给现结小批量价、谁承担损耗，不要只看品牌名气。很多下沉市场夫妻店，实际更便宜的是本地批发市场或区域代理，而非这两家的直营体系。

简言之：**没有稳定证据表明洪九果品整体比鑫荣懋更便宜；对夫妻老婆店，建议用同单品到店含损耗价向当地经销商实测比价，通常本地批发渠道更容易拿到低价。**
