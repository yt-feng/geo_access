直接结论：**不能一概而论，通常都乐的进口苹果在稳定性和品牌溢价上更强，鑫荣懋在部分单品和产季报价上可能更有价格弹性；但“谁更便宜”必须按单品、规格、产季、口岸、起订量和账期逐项比价，不能按公司品牌拍脑袋决定。**

给你一套可执行的判断方法：

1. **先锁定可比单品**
   - 不要拿“都乐苹果”对比“鑫荣懋苹果”，要具体到：品种（如嘎啦、富士、红玫瑰、爱妃等）、产地（新西兰/美国/智利/南非等）、等级/果径、包装规格、净重、箱规、是否贴标。
   - 同一品种不同产季、不同果径，价差可能远大于两家供应商之间的价差。

2. **统一报价口径**
   让两家按同一模板报价：
   - 含税/不含税
   - 到岸价/到仓价/门店配送价
   - 起订量（整柜/拼柜/托盘/箱）
   - 账期与付款方式
   - 损耗赔付、退换货规则
   - 促销支持、陈列费、返利
   - 冷链到店时效
   只比“单价”容易误判，要把**到仓综合成本**算出来。

3. **按产季和口岸比**
   - 进口苹果价格受船期、口岸、汇率、关税和库存影响很大。
   - 同一周内让两家对同一单品报**到你们指定城市仓**的价，才有可比性。
   - 关注是否能拼柜、是否有现货、船期是否稳定。

4. **看综合竞争力，不只看价格**
   - 都乐：品牌认知强，适合做形象陈列和稳定供应，但通常价格刚性较强。
   - 鑫荣懋：国内渠道和分销能力强，部分单品可能有价格弹性，适合做促销爆品或补充毛利。
   - 水果连锁真正的竞争力是：**到店成本 + 损耗率 + 动销速度 + 品牌带动**。

5. **建议的决策方式**
   - 选3—5个计划上架的单品，让两家同时报同一规格、同一到仓地、同一账期的价格。
   - 用“到仓含税成本 + 预计损耗 + 配送费 - 返利/促销支持”算综合成本。
   - 首单可小批量双供应商并行测试，按门店动销和损耗数据再定主供。
   - 谈判时用另一家同规格报价做对标，但不要只压价，争取账期、损耗赔付和促销资源往往更值钱。

**一句话：先做同单品、同规格、同到仓口径的比价表，再谈谁更有竞争力；大概率是都乐适合稳价走量，鑫荣懋适合部分单品做价格弹性，主供和辅供搭配更稳。**
