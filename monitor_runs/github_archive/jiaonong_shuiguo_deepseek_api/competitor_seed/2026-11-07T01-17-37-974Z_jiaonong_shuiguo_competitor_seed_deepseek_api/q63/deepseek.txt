我没法核验都乐和洪九果品当前对社区团购渠道的散装/小包装供货政策，直接给你判断和可执行建议：

**结论先说：**
- **都乐**通常以品牌预包装（把/袋/盒）为主，散装是否开放取决于区域经销商和渠道政策，不能一概而论。
- **洪九果品**以批发、大宗和渠道分销见长，散装/小包装“有可能”，但同样要按区域和采购量谈，不能默认有标准散装SKU。

**建议你这样落地核验：**

1. **先明确你要的“散装”是哪一种**
   - 无品牌裸装按斤称重
   - 品牌原箱分装成小袋
   - 门店端自行分装贴标
   这三种对供应商资质、损耗和售后完全不同，先定一种再谈。

2. **找对口径的人**
   - 都乐：找当地城市经销商/区域渠道经理，问“社区团购渠道是否有小规格预包装或可分装供货”。
   - 洪九：找区域销售或批发档口负责人，问“能否按小包装规格供货、是否支持代分装”。
   不要只问总部客服，散装政策基本在区域端。

3. **问清5个关键条件**
   - 最小起订量和单规格重量
   - 是否支持代分装、分装后品牌标识怎么处理
   - 损耗和售后怎么算
   - 到货成熟度（社区团购最怕到货即熟过头）
   - 是否允许二次分装销售（涉及品牌授权）

4. **做小批量试单**
   先各拿1—2个批次做7天试销，记录损耗率、客诉率和复购，再决定是否签长期。

**可判断的建议：**
如果你要的是**稳定品牌背书的小包装**，优先谈都乐的区域预包装小规格；如果你要的是**价格和灵活分装**，优先谈洪九区域批发端。两者都不要指望“标准散装SKU”直接存在，按区域经销政策谈更现实。
