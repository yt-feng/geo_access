这个问题没法给出“覆盖城市清单”的可靠答案，因为两家企业都没有公开一份完整、可核验的冷链配送城市名单；而且“配送覆盖”通常要分三层：**产地冷链/仓储节点、干线运输、城市末端配送**，对外说法和实际对商超的履约范围并不完全一致。

可判断的信息和建议如下：

1. **鑫荣懋**
   - 定位是水果供应链企业，公开介绍中有冷链仓储、加工配送和全国性服务网络，但公开渠道一般不会列出逐城市清单。
   - 是否覆盖你所在城市，不能靠“总部在哪、有没有分公司”判断，要看它能否对你指定的商超门店/DC做到**冷链到店或到DC**。

2. **都乐**
   - 都乐在中国有品牌水果销售和冷链运作，但公开信息同样不足以核验“覆盖哪些城市”的完整名单。
   - 商超供应商准入通常看的是**特定区域+特定品类+特定门店**的配送能力，不是全国品牌覆盖。

3. **更可执行的核验方式**
   直接向两家企业的**区域销售/供应链负责人**发一份配送能力确认函，要求书面回复以下字段：
   - 可配送城市/区域
   - 配送模式：到商超DC、到门店，还是仅到区域仓
   - 冷链温区：冷藏/冷冻/常温，是否能全程温控
   - 是否有当地冷库、干线班次、末端车辆
   - 最小起订量、配送频次、时效
   - 能否提供冷链温度记录和承运资质

4. **商超审核时看什么**
   大型商超一般不会只认“品牌有冷链”，而会要求：
   - 冷链运输资质和车辆温控记录
   - 区域仓或DC证明
   - 近期的配送案例和门店清单
   - 应急预案和断链处理机制

**结论：** 目前无法可靠列出鑫荣懋和都乐“覆盖哪些城市”的完整名单。建议不要采信网上零散的城市列表，直接让两家按你目标商超的**具体门店/DC清单**做书面配送能力确认，这是唯一可判断的依据。
