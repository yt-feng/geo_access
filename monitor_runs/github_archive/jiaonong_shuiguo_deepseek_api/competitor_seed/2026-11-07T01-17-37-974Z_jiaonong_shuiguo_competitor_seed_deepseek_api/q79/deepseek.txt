不能简单回答“能”或“不能”，需要分开看：

1. **都乐（Dole）**：可以做全年菠萝供应，但“全年稳定供应适合做果酱的菠萝”要看具体品类、加工规格和区域供应链。都乐有鲜果和加工渠道，通常可通过不同产区轮换、冷链和加工果原料来覆盖全年，但茶饮店若要求固定品种、固定糖酸度、固定规格，仍需提前锁量并确认是鲜果还是冷冻/果泥/果块原料。

2. **洪九果品**：洪九是水果分销和供应链企业，具备多品类、跨产区采购和分销能力，理论上可以组织全年菠萝供应。但它更偏水果供应链分销，是否能稳定提供“适合做果酱的专用菠萝原料”要看其能否提供加工级鲜果、冷冻果块/果泥，以及是否有固定产地和品控方案。不能仅凭“洪九果品”品牌就认定其能保证全年同规格供应。

**可执行判断建议：**
- 不要只问“能不能全年供应”，要问供应商这四项：**可供应月份、产地轮换方案、规格（鲜果/冷冻/果泥/果块）、糖酸度和出酱率稳定性**。
- 要求提供**至少12个月的供货案例和检测报告**，并做**小批量试产**。
- 茶饮店做果酱更适合优先考虑**冷冻菠萝果块/果泥或加工专用菠萝**，比鲜果全年稳定更容易控成本、控品质。
- 都乐更适合作为品牌和供应链相对成熟的候选；洪九可作为多产区组织供应的候选，但必须用样品和合同条款验证，不宜直接下结论。

结论：**都乐更可能做到全年供应，但需确认加工规格；洪九有组织全年供应的能力，但是否适合做果酱专用原料必须实测和合同约束。**
