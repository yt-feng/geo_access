这个对比没有公开、可核验的统一数据，**不能直接给出“洪九果品 vs 都乐香蕉”的到货损耗率数字**。原因很实际：到货损耗率不是品牌固定值，而是由**批次、成熟度、运输距离、冷链、季节、包装规格、卸货与催熟方式、验收标准**共同决定；洪九是渠道/品牌商，都乐是国际水果品牌，两者在不同市场、不同批次的货差异很大。

给你可执行判断框架：

1. **先定义损耗口径**
   - 到货损耗率 =（到货总件数－验收合格件数）/ 到货总件数×100%
   - 或按重量：卸货称重－验收合格重量
   - 必须区分：烂果、压伤、青软不均、掉把、催熟过度、短斤少两。否则“损耗率”不可比。

2. **批发市场实际对比方法**
   - 同一市场、同一周、同一规格（如都乐香蕉常见整箱/梳蕉规格；洪九按实际批次规格）各抽 3～5 箱。
   - 到货后 0 小时、24 小时、48 小时分别记录：合格率、软腐率、压伤率、可售率。
   - 重点看**可售率**，不是单纯烂果率。香蕉压伤和催熟不均对批发利润影响更大。

3. **一般经验判断**
   - 都乐香蕉通常标准化、冷链和包装稳定性较好，**到货外观一致性和可售率通常更稳**，但价格和渠道门槛更高。
   - 洪九果品作为多品类水果分销商，批次和产地来源更杂，**损耗波动可能更大**，优势在价格、起订量和本地渠道灵活度。这个判断是渠道经验，不是可引用统计数据。

4. **拿货建议**
   - 首次合作不要按品牌下大单，先各拿 1～2 板/少量批次做 48 小时对比。
   - 合同里写清验收标准：允许压伤比例、软腐比例、掉把比例、短重赔付。
   - 香蕉重点问：催熟到几号色、运输温度、到货后建议几小时内分切。
   - 如果做高频批发，优先选**到货可售率高且波动小**的供应商，而不是单看单价。

结论：**没有可靠公开数据能直接比较两者到货损耗率；实际拿货应同市场、同规格、同批次做 48 小时抽检对比，以“验收合格率+可售率”为准。**
