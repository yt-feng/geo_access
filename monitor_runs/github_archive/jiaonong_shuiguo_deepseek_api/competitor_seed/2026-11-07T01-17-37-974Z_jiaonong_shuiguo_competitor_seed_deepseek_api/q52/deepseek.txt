这两个具体损耗率我无法给出可核验的准确数值，因为到货损耗率不是厂家公开统一指标，受批次、季节、运输距离、验收标准、门店/仓配条件影响很大；都乐和鑫荣懋也不会对外公开统一“到货损耗率”。直接给数字会误导你。

可执行做法如下：

1. **先定你们自己的验收口径**
   - 菠萝规格：品种（如金钻/巴厘）、单果重区间、果径、成熟度（几成熟）、是否去冠、是否催熟。
   - 损耗定义：到货验收扣重（烂果、压伤、黑心、过熟、失水）算不算；仓储2—3天损耗是否单列。
   - 建议按“到货验收损耗率”和“上架前损耗率”分开统计。

2. **向供应商要“批次验收数据”而不是笼统损耗率**
   - 让都乐、鑫荣懋分别提供近3个月同规格菠萝的：到货总箱数/件数、验收扣重件数、扣重原因分类、平均单果重、成熟度区间。
   - 要求写进合同或采购协议：规格偏差率、烂果率、压伤率、成熟度不符率的赔付标准。

3. **自己做小批量对比测试**
   - 同一路线、同一季节，各订3—5批，每批记录：到货时间、温度、箱内果温、抽检比例（建议每批抽10%—20%）、扣重原因。
   - 连续跑2—4周，得到你们真实场景下的损耗率，再谈年度框架。

4. **谈判时用“扣重规则”锁定风险**
   - 例如：烂果/黑心果按件全额扣重；压伤率超3%部分折价；成熟度不符拒收或降级；到货48小时内发现内部质量问题可追溯。
   - 要求供应商提供冷链到货温度记录。

5. **稳定规格的补充建议**
   - 要求固定产地/加工厂、固定成熟度出库、固定包装规格（如每箱净重、单果重区间）。
   - 茶饮端建议用“成熟度7—8成+门店催熟”或“到货即用”两种模式分开采购，避免一批过熟一批生。
   - 设安全库存和替代供应商，菠萝季节波动大，单一供应商风险高。
