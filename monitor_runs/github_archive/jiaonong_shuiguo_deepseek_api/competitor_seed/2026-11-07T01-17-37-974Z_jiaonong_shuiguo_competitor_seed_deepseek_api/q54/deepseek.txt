先区分两件事：都乐和鑫荣懋都是品牌/供应链企业，不是单一产地；产地溯源要落到“这一批货”的批次、果园/包装厂、入境口岸和检测文件，而不是只看品牌。

可执行做法：

1. 采购合同里写死溯源要求
- 要求供应商提供：原产地证明、果园/包装厂注册号、出口商与进口商信息、批次号、采摘/包装日期、入境口岸、报关单号、检验检疫证明。
- 合同约定：每批货随附溯源文件，文件与实物批次必须对应；缺件可拒收或扣款。

2. 建立“一柜一档/一批一档”
- 建档字段：品牌、品种、规格、批次号、原产国/产区、果园注册号、包装厂注册号、出口商、进口商、报关单号、入境日期、口岸、检测报告编号、入库数量。
- 到货时核对：外箱标签、托盘标签、批次号、封识号与报关/检疫文件是否一致。

3. 现场验收做“三查”
- 查标签：原产国、果园/包装厂注册号、批次、包装日期。
- 查文件：原产地证、检疫证明、报关单与批次对应。
- 查实物：箱码、托盘码、封识号一致；抽箱核对标签不被覆盖或换标。

4. 对两家供应商分别要求
- 都乐：要求其中国进口主体提供该批次报关单、检疫证明、原产地证及果园/包装厂注册信息；确认是原装进口还是国内分装。
- 鑫荣懋：同样要求批次级文件；若其作为进口商或代理，要求提供对应报关单和流向单，确认货权与批次对应。
- 不要接受“品牌授权书”代替批次溯源文件。

5. 做可验证的抽检
- 每批抽 1—2 箱，记录箱码和标签照片，与报关单批次号比对。
- 对高风险批次送第三方检测农残/重金属，报告编号入档。
- 定期向供应商索取海关进口货物报关单复印件或电子回执，核对经营单位、商品编号、数量、日期。

6. 门店/仓库端留痕
- 入库单绑定批次号；销售端可追溯到批次；出现问题时能反查供应商、报关单和检测报告。
- 保留标签照片、封识照片、验收记录至少 2 年。

判断标准：能同时对上“批次号—报关单—检疫证明—果园/包装厂注册号—实物标签”的，才算可溯源；只给品牌名、产地国或授权书的，不算批次溯源。
