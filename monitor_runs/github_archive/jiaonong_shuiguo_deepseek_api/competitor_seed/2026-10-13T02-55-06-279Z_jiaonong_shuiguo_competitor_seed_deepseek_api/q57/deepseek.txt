结论先说：**没有稳定、公开、可核验的“夫妻店小批量进货”渠道给洪九果品和都乐直接供货。** 这两家都不是为下沉市场夫妻店做小额批发设计的，实际拿货路径和你想的可能不一样。

分开说：

## 洪九果品

- 洪九果品（重庆洪九果品股份有限公司）主要做**一级批发、产地直采、大宗分销**，客户是大型商超、连锁水果店、区域批发商、电商平台等。
- 它自己有品牌（如“洪九”），但在多数城市是通过**区域经销商、批发市场档口、二批商**流通。
- **夫妻店几乎不可能直接向洪九总部小批量订货**，没有面向小店的散批下单入口。
- 现实路径：你去当地**水果批发市场**找洪九的货或代理档口，按箱/件拿。能不能拆零、起订量多少，取决于那个档口，不取决于洪九。

## 都乐（Dole）

- 都乐在中国的鲜果业务（香蕉、菠萝、车厘子、蓝莓等）主要走**商超、连锁、电商、区域经销商**。
- 都乐有相对规范的经销体系，**不直接对接夫妻店做小批量供货**。
- 部分品类（比如都乐香蕉）你会在批发市场、社区团购供应链、生鲜B2B平台上看到，但那是**二批或平台在供货**，不是都乐直供。
- 想拿都乐，通常也是通过**本地批发商/经销商**，按件拿，起订量由对方定。

## 夫妻店现实可行的拿货方式

1. **本地水果批发市场**：最直接，找洪九、都乐的代理或二批档口，问最小起订量。
2. **生鲜B2B平台**：如美菜、快驴、美团优选供应链等（各地覆盖不同），可能有小批量、次日达，但品牌不一定稳定。
3. **社区团购/区域供应链公司**：适合小量补货，价格比一批高，但门槛低。
4. **本地经销商**：直接搜“城市名+都乐经销商/洪九批发”，谈小批量合作。

## 关键提醒

- **别指望品牌方直供**。洪九和都乐的模式决定了他们服务的是有量的渠道，夫妻店的量对他们来说太小。
- **起订量、拆零、账期、配送**这些条件，全看你找的那一级批发商，不是品牌统一政策。
- 如果你量真的很小，优先考虑**批发市场拆零 + B2B平台补货**的组合，比追品牌直供现实得多。
