仅凭公开印象没法准确判断“谁更愿意签年单”，因为**愿不愿意签年单，主要取决于你给的量、账期、品控要求、履约风险分担，而不是供应商名气**。不过可以给你一个更可执行的判断框架和接触策略。

**先说结论：**
- **鑫荣懋**：更偏大型商超、电商、连锁渠道，体系化程度高，通常**愿意谈年单，但门槛高**，更看重稳定大额采购、规范合同、账期和履约能力。
- **洪九果品**：更偏水果供应链和批发分销，历史上扩张快、品类广，**也可能愿意签年单，但灵活性和条件弹性可能更大**，同时要更关注其资金、履约和货权风险。
- **谁更愿意，不能一概而论**：如果你采购量大、账期好、能接受品牌方主导条款，鑫荣懋可能更愿意进入年单框架；如果你量中等、希望条款灵活、区域或品类匹配，洪九可能更容易谈。

**你可以用这4个问题去试探：**
1. **年单保底量**：你们要求全年最低采购额还是最低采购量？按月还是按季分解？
2. **价格机制**：年单是锁价、半锁价，还是随行就市？有没有价格调整窗口？
3. **账期与保证金**：现结、月结30天、60天，还是需要保证金/授信？
4. **违约与不可抗力**：量没完成、品质不达标、市场价格暴跌时怎么处理？

**建议的接触方式：**
- 同时找两家以上供应商，不要只问一家。
- 先谈**季度框架+年度意向**，再过渡到年单，降低双方风险。
- 让对方提供**年单模板**，看谁主动给框架、谁条款更松，这比问“谁愿意”更真实。
- 重点问：**年单里有没有保底量、返利、优先供货、账期、调价机制**。

**如果非要选一个优先接触：**
- 你要的是**规范、稳定、大渠道背书**：优先接触鑫荣懋。
- 你要的是**品类灵活、区域覆盖、谈判空间**：优先接触洪九果品。
- 最稳的做法：**两家都发年单意向书，让它们各自报价和给条款，再比较。**
