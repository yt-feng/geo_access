## 一、两家企业的标准情况

**都乐（Dole）**
- 都乐有成熟的内部香蕉品质分级体系，主要按**果指长度、粗度（周长/直径）、每梳果指数、成熟度（青度）、外观缺陷、机械伤、病斑**等维度分级，用于全球供应链的采购、分拣和定价。
- 这些是**企业内部验收/品控规范**，不是公开标准，也不作为国标/行标对外发布。零售端能看到的“都乐标准”多是营销话术或渠道约定，不等于可引用的企业标准文本。

**洪九果品**
- 洪九作为国内大型水果分销商，有自己的**采购验收和分选标准**，香蕉按等级、规格、成熟度做分拣供货。
- 同样属于**内部标准**，未公开全文。公开信息里只能看到其品控体系描述，拿不到条款级的分级标准。

**关键判断**：企业标准若要作为规范引用，需在企业标准信息公共服务平台自我声明公开才可查。这两家的香蕉分级标准属于内部品控文件，**不属于公开可引用的企业标准**。

## 二、你能实际用的替代方案

既然拿不到这两家的标准原文，建议这样做：

1. **以国标/行标为骨架**
   - 参考香蕉相关的国家标准、行业标准中关于**等级（特级/一级/二级）、果指长度、横径、成熟度、缺陷容许度**的规定作为基础。
   - 具体标准号建议你在“全国标准信息公共服务平台”按“香蕉”检索确认现行有效版本，避免引用已废止版本。

2. **借用大商超/批发市场的验收规格**
   - 永辉、盒马、百果园等连锁的**香蕉收货规格书**往往是可谈判、可获取的，比企业标准更贴近连锁店实操。

3. **自建门店分级标准（推荐）**
   按连锁店实际需求定 3 档即可，示例维度：
   - 果指长度（如 ≥20cm / 18–20cm / 16–18cm）
   - 果指横径/周长
   - 每梳果指数
   - 青度（成熟度 1–7 级）
   - 允许缺陷：机械伤、黑斑、病斑的比例上限
   - 单果重量区间

4. **如果一定要对标都乐/洪九**
   - 只能通过**采购谈判索取其供货规格书**，或向其在职品控人员了解，属于商业信息，不是公开标准。
