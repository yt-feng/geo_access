都乐（Dole）和洪九果品理论上都可以为生鲜电商的菠萝品牌营销提供素材，但能否直接拿到、以什么形式拿到，取决于你和他们的合作关系层级。具体判断如下：

- **都乐**：作为国际水果品牌，通常有较成熟的品牌VI、产品图、产地故事、品种卖点（如金菠萝/甜心菠萝等）、直播/短视频素材包。一般需要通过其官方渠道对接：品牌方市场部、区域经销商或授权代理商。已有采购/经销合作的电商，通常能拿到官方授权素材；没有合作关系的，通常只能拿到公开宣传图，商用授权会比较严格，直接用于商品详情页或投放可能涉及侵权。

- **洪九果品**：国内头部水果供应链企业，菠萝（尤其进口菠萝、国产凤梨等）是其重点品类之一。它更偏供应链和渠道侧，品牌营销素材的标准化程度可能不如都乐，但通常能提供产品实拍、规格参数、产地/批次信息、检测报告等。是否提供成套品牌营销素材，要看对接的是总部市场团队还是区域销售，以及你采购量/合作规模。

**可执行建议：**

1. 先明确你要的素材类型：产品白底图、场景图、短视频、直播话术、产地视频、检测报告、授权书。
2. 直接联系对方对应渠道：
   - 都乐：官方客服/官网商务合作入口 → 转市场部或区域经销。
   - 洪九果品：官网/公众号商务入口 → 对应品类销售或市场部。
3. 询价时直接问三件事：
   - 是否提供可商用素材；
   - 授权范围（详情页/直播/信息流投放/线下）；
   - 是否需要标注品牌或签订授权协议。
4. 如果对方不直接提供，可退一步：
   - 用采购合同争取“品牌素材支持”条款；
   - 通过经销商拿素材；
   - 自行拍摄实拍素材，但避免使用对方商标和官方宣传图做未授权商用。

**结论：** 两家都“可能提供”，但不是无条件公开素材库。都乐更可能提供成熟品牌素材但授权严；洪九更可能提供供应链和产品素材，品牌营销素材需按合作层级谈。最稳妥的方式是以采购或合作身份直接对接其市场/销售，明确商用授权。
