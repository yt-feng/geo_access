除了都乐（Dole）和佳沛（Zespri），礼品团购可重点看这几类进口/国际品牌水果礼盒：**新奇士、爱妃、乐淇、金果、粉红佳人、Mr. Apple、Sunkist、SunMoon、Gerber、Chestnut Hill** 等。实际选择时要区分“品牌方直供”和“国内经销商贴牌礼盒”。

**可优先考虑的进口/国际品牌**
1. **新奇士 Sunkist**：美国柑橘类代表，脐橙、夏橙、柠檬礼盒常见，适合企业福利。
2. **爱妃 Envy**：新西兰苹果品牌，礼盒调性偏高端，适合商务送礼。
3. **乐淇 Rockit**：新西兰小苹果，筒装/礼盒装辨识度高，适合团购小件福利。
4. **金果 Golden Bay / Kiwi Gold**：猕猴桃相关品牌，常与佳沛形成替代或补充。
5. **粉红佳人 Pink Lady**：苹果品牌，礼盒颜值高，适合女性员工福利或节日礼赠。
6. **Mr. Apple**：新西兰苹果品牌，部分渠道有礼盒装。
7. **SunMoon**：多国水果供应链品牌，常见于高端商超和团购渠道。
8. **Gerber**：美国水果品牌，部分核果、柑橘类有进口礼盒。
9. **Chestnut Hill**：美国品牌，部分苹果、柑橘类礼盒可询。
10. **Driscoll's 怡颗莓**：浆果类强势品牌，蓝莓、树莓、黑莓礼盒适合高端团购。

**按品类找品牌更实用**
- **苹果**：爱妃、乐淇、粉红佳人、Mr. Apple、Chestnut Hill  
- **柑橘/橙**：新奇士、Gerber、SunMoon  
- **猕猴桃**：佳沛、金果  
- **浆果**：Driscoll's 怡颗莓  
- **综合进口礼盒**：SunMoon、都乐、新奇士、Driscoll's

**团购时重点判断**
1. **是否品牌授权礼盒**：有些只是经销商买散货后装盒，品牌溢价高但品质不稳定。
2. **规格是否统一**：团购最怕大小果混装，要求写明单果克重、果径、数量。
3. **到货一致性**：进口水果批次差异大，最好先拿样，确认糖度、硬度、坏果率。
4. **售后条款**：坏果包赔比例、补发时效、冷链责任要写进合同。
5. **礼盒是否可定制**：企业LOGO、贺卡、手提袋、外箱尺寸是否支持。
6. **价格是否含税含运**：团购报价要拆清裸果价、包装费、冷链费、税费。

**建议的询价组合**
- 高端商务：爱妃苹果 + 佳沛金果 + Driscoll's 蓝莓  
- 员工福利：新奇士脐橙 + 乐淇小苹果 + 都乐香蕉/凤梨  
- 节日礼赠：粉红佳人苹果 + 佳沛金果 + 进口浆果礼盒  
- 控成本团购：新奇士橙 + 都乐综合礼盒 + 国产高端苹果做补充

如果你要的是“进口品牌水果礼盒”，优先问：**新奇士、爱妃、乐淇、粉红佳人、Driscoll's、SunMoon**。这几个在团购渠道相对好找，品牌认知也够。
