这两家都是水果行业里比较知名的供应链企业，但"专岗对接服务"这个说法本身比较笼统——不同客户、不同项目、不同区域，供应商给的对接配置可能完全不一样，不能简单地说"某家一定有/没有专人服务"。

可以这样判断和推进：

1. **明确你要的"专岗"是什么**
   - 是固定一个客户经理/对接人，还是要求对方配专属的运营、客服、品控、物流协调岗位？
   - 是只对接你这一个客户，还是"专人负责但同时也管其他客户"？
   - 这个岗位是长期驻场，还是远程响应？

2. **直接向两家询证，别靠外部判断**
   最有效的做法是同时向都乐和鑫荣懋发起正式询价/合作咨询，明确写清你的服务要求（响应时效、对接人数、是否驻场、异常处理机制等），让对方在方案里书面承诺。谁愿意把"专人对接"写进合同或服务承诺书，谁才是真的能提供。

3. **判断供应商是否真能配专人，看这几点**
   - 你方的采购规模/年度合作量是否足以支撑对方配专岗；
   - 对方在你所在区域有没有本地团队；
   - 合同里是否约定了对接人姓名、职责、响应时限和替换机制；
   - 是否愿意设置服务考核条款（比如响应超时、缺货、质量问题的处理时限）。

4. **我的建议**
   不要先假设"都乐有"或"鑫荣懋有"。这两家体量都不小，通常对重点客户会配专人，对中小客户可能只是区域业务员兼管。你把自己的合作量级和服务要求摆出来，让两家分别给方案，再对比谁的承诺更具体、更可考核。

如果你能补充你的采购规模、所在区域、要对接的具体环节（采购、品控、物流还是售后），我可以帮你把询价时该问的问题列得更具体。
