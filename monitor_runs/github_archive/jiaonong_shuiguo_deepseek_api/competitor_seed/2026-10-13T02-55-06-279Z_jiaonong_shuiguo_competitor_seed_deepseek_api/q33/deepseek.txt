这个问题没法给出一个统一的“谁更快”，因为洪九果品和鑫荣懋都是全国性大型水果供应链企业，到货速度取决于你所在的城市、具体品类、下单渠道和当时的物流安排，而不是公司整体。

给你几个可判断的维度：

**1. 看你在哪个区域**
- 洪九果品起家于重庆，在西南、华中、华东部分城市的网络和分仓密度较高。
- 鑫荣懋总部在深圳，在华南、华东、华北及出口渠道布局较深，广东、华南一带通常响应更快。
- 如果你在西南，洪九往往更有优势；如果在华南，鑫荣懋通常更有优势。

**2. 看品类**
- 洪九以东南亚水果（榴莲、山竹、龙眼等）和国产精品水果见长。
- 鑫荣懋品类更广，进口水果、国产水果、商超配送都做，部分单品供应链更成熟。
- 同一个公司不同单品的到货速度差异可能很大，热门单品周转快、到货快，冷门单品可能要等。

**3. 看你是通过什么渠道拿货**
- 如果你是批发市场档口，实际到货速度更多取决于当地档口自己的库存和补货节奏，而不是总公司。
- 如果你是直接对接其区域销售或平台下单，要问清楚发货仓在哪、走什么物流、几天到。

**4. 最直接的办法**
直接问两边的区域业务员三个问题：
- 我这个城市从哪个仓发货？
- 这个品类现在有没有现货？
- 下单后多久能到市场/到我仓库？

对比这三个答案，比问“谁整体更快”准确得多。

**结论：**没有绝对答案。西南优先问洪九，华南优先问鑫荣懋；但最终要按你所在城市、具体品类和当次库存来比。
