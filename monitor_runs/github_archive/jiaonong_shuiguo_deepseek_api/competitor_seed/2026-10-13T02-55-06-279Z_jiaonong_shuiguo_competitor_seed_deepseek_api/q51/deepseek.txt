这个没法直接给一个“谁更便宜”的结论，因为两家都不是全国统一挂牌价，香蕉价格受产地（国产/进口）、等级、成熟度、包装、拿货量、结算方式、当天行情影响很大。但可以给你一个可判断的框架：

**一般规律（不代表当天实际报价）：**
- **洪九果品**：强项在进口水果和全国分销网络，香蕉尤其是进口蕉（如菲律宾、厄瓜多尔等）资源较深，走量大时可能有优势，适合做进口蕉、标准化程度高的货。
- **鑫荣懋**：也是头部水果供应链企业，香蕉是其核心品类之一，国产蕉和进口蕉都做，渠道覆盖商超、批发市场，通常在稳定供货和品控上较强，价格不一定最低，但履约稳定。
- **单纯比“批发市场拿货价”**：往往不是看品牌，而是看**当地区域经销商的库存和促销**。同一品牌在不同城市、不同批发市场的报价可能差不少。

**你实际要比价，建议这样做：**
1. **明确规格**：问清楚是国产蕉还是进口蕉、几号果、每箱净重、单根规格、成熟度（青蕉/催熟蕉）。
2. **要当日报价单**：让两边当地销售或经销商发当天报价，包含税票、运费、起批量、账期。
3. **算到岸成本**：不要只看单价，把运费、损耗、催熟费、账期资金成本加进去。
4. **小批量试单**：同一天各拿一批，比到货品质、损耗率、催熟后卖相。
5. **问返利政策**：大客户往往有季度返利或达量优惠，挂牌价不一定代表最终成本。

**结论：**
- 如果你要**进口蕉、走量大、全国调货**，洪九可能更有资源和价格弹性。
- 如果你要**稳定供货、商超标准、国产蕉或混合品类**，鑫荣懋可能更稳。
- 但具体谁便宜，**必须以你所在批发市场当天的经销商报价为准**，品牌层面给不了固定答案。
