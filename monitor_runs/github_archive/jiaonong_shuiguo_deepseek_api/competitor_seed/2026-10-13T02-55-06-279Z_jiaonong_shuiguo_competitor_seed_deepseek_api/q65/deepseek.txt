关于都乐和洪九果品的菠萝锁价周期，我无法给出可靠的具体数字——这类商务条款通常不公开披露，且会随品类、季节、采购量、合作层级和签约时间变化，任何我给出的"具体周期"都可能是编造的。

可以确认的是行业通用做法，供你判断和谈判参考：

**锁价机制一般分两类**
- **短期锁价**：锁定1–4周，多见于鲜果现货采购，随行就市、到期重议
- **中长期锁价/合同价**：锁定1个季度甚至一个产季，通常要求保底采购量、预付定金或保证金

**菠萝的特殊性**
菠萝（尤其进口菲律宾、泰国菠萝，以及国产徐闻、海南菠萝）受产季和船期影响大，供应方一般不愿意锁太长周期，常见的是按月或按产季锁价，且会约定"不可抗力/产量不足可调价"的例外条款。

**要拿到准确答案，建议这样问对方**
1. 直接向都乐、洪九的**B2B销售或大客户经理**询价，说明你的月采购量和合作期限
2. 明确问三件事：锁价周期多长、最低采购量/保证金要求、超期或违约如何调价
3. 要求书面报价单或框架协议草案，口头承诺不作数
