可以，但要以“批次”为准，不是品牌层面永久有效。都乐、鑫荣懋这类大型水果供应链企业通常能提供菠萝的农残检测报告，但你采购时要确认三点：

1. **报告对应你要采购的批次**
   - 农残检测报告一般按批次、产地、加工厂出具。
   - 供应商给你一份旧报告或别的产地报告，不能覆盖你实际收到的货。

2. **报告项目要符合你的验收要求**
   - 常见要看法检项目：有机磷、氨基甲酸酯、拟除虫菊酯、杀菌剂等。
   - 茶饮店至少应关注：**毒死蜱、克百威、氧乐果、水胺硫磷、敌敌畏、多菌灵、吡虫啉、苯醚甲环唑、氯氰菊酯**等常见高风险项。
   - 如果是鲜菠萝/冷冻菠萝/菠萝果浆，检测项目可能不同。

3. **报告形式**
   - 最好要：**CMA/CNAS资质检测报告**。
   - 报告上应有：样品名称、批次号/生产日期、检测机构、检测项目、限量标准、结论。
   - 如果供应商只有“出厂检验报告”或“自检报告”，强度较低，不一定满足市场监管或大客户审核。

**实际操作建议：**
- 向都乐或鑫荣懋的销售/客服直接问：  
  “请提供我拟采购批次菠萝的农残检测报告，要求CMA/CNAS，报告批次号能对应送货批次。”
- 如果对方说“品牌统一报告”或“年度报告”，你要追问：  
  “这份报告能否对应我这次订单的生产日期/批次号？”
- 若他们不能提供，可要求：
  1. 每批随货附检测报告；
  2. 或你自行送检，费用谈判分摊；
  3. 或在合同里写明“每批提供符合GB 2763的农残检测报告，否则退货”。

**结论：**
都乐和鑫荣懋大概率能提供，但能不能满足你，关键看**是否按你采购批次出报告、是否有CMA/CNAS、检测项目是否覆盖你的验收标准**。不要只认品牌，要认“批次报告”。
