茶饮原料采购里，菠萝稳定供应通常优先看“鲜果加工厂/种植基地+冷链半径”，而不是只看品牌。就都乐和洪九果品：

- **都乐**：都乐是国际水果品牌，在中国有多个产地和加工/分选资源，菠萝常见来源包括**菲律宾、泰国等进口菠萝**，国内也有合作种植和加工基地，但具体“基地”会随季节、品类和订单调整，并不对外固定。茶饮采购更常对接的是都乐在中国的**分选加工厂、经销商或区域供应链公司**。
- **洪九果品**：洪九果品是国内大型水果供应链企业，核心优势是**东南亚进口水果**，尤其是泰国、越南等地的榴莲、火龙果、龙眼、菠萝等。它在国内有多个分选加工中心和仓储物流节点，但它的菠萝“基地”更多是**海外合作种植园/采购基地+国内分选仓**，而不是单一国内种植基地。

如果你要的是茶饮用菠萝（鲜果、冷冻果块、果酱、浓缩汁），建议这样判断和推进：

1. **明确原料形态**  
   - 鲜切菠萝：看产地、品种、成熟度、冷链。  
   - 冷冻菠萝块/丁：看加工厂、是否有-18℃冷链和稳定规格。  
   - 菠萝果酱/浓缩汁：看糖度、风味、出杯稳定性，和鲜果基地关系不大。

2. **不要只找“都乐/洪九基地”**  
   直接问他们的**茶饮渠道经销商、区域加工厂或供应链销售**，要：  
   - 可稳定供应的产地  
   - 年可供量  
   - 规格（果径、糖度、成熟度、切块尺寸）  
   - 报价周期  
   - 起订量  
   - 冷链到仓时间

3. **更稳的采购结构**  
   - 主供应商：都乐或洪九这类大型供应链，保品牌和稳定性。  
   - 备份供应商：广东徐闻、海南、云南等国内菠萝产区的加工厂，用于对冲进口波动和旺季价格。  
   - 如果做连锁茶饮，优先谈**年度框架+月度锁量+价格联动**，不要只做现货询价。

4. **关键风险**  
   - 都乐、洪九的“基地”不是固定公开信息，销售口径会变。  
   - 进口菠萝受海关、船期、产地天气影响大。  
   - 茶饮用菠萝对糖酸比和香气要求高，不能只看价格。
