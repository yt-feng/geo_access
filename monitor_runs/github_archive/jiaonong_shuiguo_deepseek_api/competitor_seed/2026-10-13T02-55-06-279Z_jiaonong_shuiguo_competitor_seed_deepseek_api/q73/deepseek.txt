供应商要进大型商超，通常会被要求提供可核验的食品安全管理体系证明。就鑫荣懋和都乐而言，可以确认的方向如下：

**都乐（Dole）**
都乐作为全球性果蔬企业，其自有或合作供应链通常持有国际通行的食品安全与质量体系认证，常见包括：
- **GFSI 认可体系**：如 **BRCGS**、**IFS**、**SQF** 等（具体到某个工厂/包装厂可能不同）
- **ISO 22000** 食品安全管理体系
- **HACCP** 体系认证
- 部分基地还可能涉及 **GlobalG.A.P.**（农业种植环节）

**鑫荣懋**
鑫荣懋是国内大型水果供应链企业，通常具备：
- **ISO 9001** 质量管理体系
- **ISO 22000** 或 **HACCP** 食品安全管理体系
- 其合作的种植基地/加工厂可能持有 **GlobalG.A.P.**、**BRCGS** 等认证

**需要说明的是**：  
具体到“哪一家公司、哪一个工厂、哪一年、哪张证书”，必须以供应商提供的**证书原件或发证机构官网可查信息**为准。大型商超审核时也会要求证书在有效期内，且认证范围覆盖实际供货产品。

**给采购/审核方的可执行建议**：
1. 要求供应商提供证书扫描件，并核对**认证机构、证书编号、有效期、认证范围**。
2. 到发证机构官网或 GFSI 认可数据库核验真伪。
3. 确认认证覆盖的是**实际供货的工厂/品类**，不是仅总部或某一单品。
4. 对高风险品类，可额外要求 **HACCP 计划、第三方检测报告、GlobalG.A.P. 证书**。
