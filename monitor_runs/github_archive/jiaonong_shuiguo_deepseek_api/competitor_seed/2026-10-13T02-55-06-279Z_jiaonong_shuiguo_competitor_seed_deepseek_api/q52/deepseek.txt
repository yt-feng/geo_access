这两家的菠萝到货损耗率,公开渠道没有统一的官方数字,而且损耗率会随**批次、季节、产地、运输方式、验收标准**大幅波动,所以直接给一个"某家是X%"的数字并不可靠。下面给你可判断的框架和获取方法。

## 为什么不能直接给数字

- 都乐(Dole)和鑫荣懋都是大型果品供应链企业,主要做一级批发/连锁餐饮供货,损耗率通常写在**合同或供应商SLA**里,不对外公开。
- 菠萝损耗分几段:运输损耗、到仓验收扣重、加工去皮损耗、存放腐损。你问的"到货损耗率"如果不定义是哪一段,数字没有可比性。
- 不同规格(如4-6头、7-9头)、不同季节(春夏vs冬季)、不同产地(菲律宾、泰国、国产徐闻/海南),损耗差异很大。

## 建议你这样定义和测量

把"到货损耗率"拆成可量化的口径:

1. **到货验收损耗率** =（到货总重 − 验收合格入库重）/ 到货总重 ×100%
2. **加工出成率** = 去皮去眼后净果肉重 / 毛重,这个对茶饮更关键(菠萝丁/菠萝酱用途不同)
3. **暂存腐损率** = 入库后48/72小时报废重 / 入库重

## 怎么拿到真实数字

- 直接向两家销售要**近3个月同规格的供货质检报告 + 到货验收记录**,让他们给"平均损耗区间"而不是单点值。
- 做**小批量盲测**:同一周各进2-3批,按上面口径自己称重记录,通常2周就能出可对比的平均值。
- 合同里写入**损耗上限和超标扣款条款**,把风险转移给对方,比事先问一个数字更有效。

## 一般经验范围(仅供参考,需自行验证)

- 全程冷链、成熟度控制好的情况下,菠萝到货验收损耗常在**3%-8%**区间;
- 加工去皮损耗(人工/机器)通常**35%-50%**,这取决于品种和成熟度,不取决于供应商品牌;
- 夏季高温、长途运输时,到货损耗可能翻倍。
