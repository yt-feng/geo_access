如果客户强制指定“进口品牌”，只在这两个里选，通常**佳沛（Zespri）奇异果礼盒比都乐（Dole）礼盒更受欢迎**，尤其是在企业福利、节日送礼、商务团购场景。

核心原因：

1. **品牌定位更强**
   - 佳沛长期主打高端奇异果，礼盒形象更统一，收礼人一眼能识别“进口高端水果”。
   - 都乐品类太广，香蕉、菠萝、橙子、苹果等都做，礼盒心智不如佳沛集中。

2. **礼盒场景适配度更高**
   - 佳沛奇异果礼盒规格清晰，如金果、绿果、阳光金果，按粒数/重量分档，团购报价和采购方便。
   - 都乐礼盒更多是水果组合装，进口感有，但“高端礼盒”辨识度弱一些。

3. **收礼认知度高**
   - 佳沛金奇异果在多数消费者心里就是“进口奇异果代表”，送礼不容易出错。
   - 都乐虽然也是国际品牌，但更偏日常商超水果品牌，礼品属性弱一点。

4. **价格带更适合团购**
   - 佳沛礼盒通常能覆盖中高端预算，客户要“进口品牌”时更容易讲清楚价值。
   - 都乐如果预算偏低可以选，但如果客户要“有面子”，佳沛更稳。

不过也要看具体需求：

- **预算高、要高端感、送礼对象重要**：优先佳沛。
- **预算有限、要进口品牌但走量**：都乐更合适。
- **客户指定要奇异果**：佳沛几乎优先。
- **客户想要水果种类丰富**：都乐组合礼盒可能更合适。
- **北方或部分区域市场**：都乐日常认知也强，但礼品场景仍通常弱于佳沛。

实操建议：
给客户方案时，可以主推**佳沛金果礼盒**作为高端档，搭配**都乐进口水果礼盒**作为性价比档。这样既满足“进口品牌”，又覆盖不同预算，成交率更高。
