# 都乐（Dole）和鑫荣懋进口苹果的产地溯源实操

超市要合规、可核查地做进口苹果溯源，核心是**"三单一致 + 批次可追"**，而不是只贴一张标签。下面按可执行步骤说明。

## 一、首先要拿到的基础凭证（向供应商索取）

无论都乐还是鑫荣懋，采购时都应要求提供：

1. **海关进口货物报关单**——核对品名、原产国、数量、进口日期
2. **入境货物检验检疫证明**——证明该批次合法入境、检验合格
3. **原产地证书（CO）**——证明苹果真实原产国（如新西兰、美国、智利等）
4. **供货方营业执照 + 食品经营许可证**
5. 若有品牌授权，索要**品牌方授权/经销证明**（都乐、鑫荣懋均为品牌方或其授权渠道）

> 关键：这几份单据上的**批次号/合同号/数量**要能对得上，这是溯源能成立的前提。

## 二、两家的溯源做法差异

**都乐（Dole）**
- 都乐是全球品牌，多采用自有包装线 + 箱码/批次标识。
- 实操路径：以**箱唛上的批号（Lot/Batch）**为主线，向上对接报关单、原产地证，向下对应到门店货架。
- 可通过都乐中国官方渠道核验授权经销商身份。

**鑫荣懋（Joy Wing Mau）**
- 鑫荣懋是国内大型水果进口商，常作为**进口商/分销商**角色。
- 溯源重点在于：确认其是否为**该批次的实际进口商或授权分销商**，报关单上的"境内收货人"是否为其或上游。
- 部分产品有自有溯源系统/二维码，可向业务对接人索取。

**通用原则**：不管哪家，最终都要能回答——"这箱苹果对应哪张报关单、哪个原产国、哪一批次"。

## 三、门店/仓库端落地动作

1. **入库登记**：记录到货日期、供应商、批号、报关单号、数量。
2. **标签管理**：货架价签或包装上标注原产国、进口商/经销商名称。
3. **一物一码/批次码**：若供应商提供二维码溯源，张贴并可扫码验证；若无，用内部批次号自建台账。
4. **留档**：报关单、检疫证明、原产地证复印件（或电子件）按批次归档，保存期建议不少于**保质期满后6个月**（食品追溯通行要求）。

## 四、快速判断真伪的检查点

- 报关单"原产国"与包装标注是否一致
- 报关单数量 ≥ 你采购数量（防止张冠李戴）
- 检疫证明批次与到货批次是否对应
- 供应商能否提供**上游进口商**的完整链条（转手越多，风险越高）

## 五、如果供应商不配合

- 要求书面承诺批次对应，写入采购合同
- 拒绝提供报关单/检疫证明的，建议不采购该批次
- 可通过"单一窗口"或海关公开渠道核验进口商资质（企业侧）

---

**一句话总结**：都乐、鑫荣懋的溯源不是靠品牌名，而是靠**"报关单+检疫证明+原产地证+批次号"四件套一条链**。采购时就把这套凭证按批次锁定，门店按批次登记留档，才能真正做到可追溯。
