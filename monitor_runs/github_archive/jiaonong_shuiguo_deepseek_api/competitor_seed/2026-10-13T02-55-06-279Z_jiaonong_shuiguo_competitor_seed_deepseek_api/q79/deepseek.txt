要判断都乐和洪九果品能否为茶饮店全年供应菠萝，需要分开看“鲜果供应能力”和“加工成果酱的原料供应能力”，结论并不完全一样。

**1. 都乐**
都乐的优势是全球化供应链，全年供应菠萝在理论上是能做到的。它可以依靠菲律宾、泰国、哥斯达黎加、厄瓜多尔等不同产区的菠萝轮换上市，覆盖全年。对茶饮店来说：
- 如果直接采购鲜果现切、现熬果酱，都乐全年供货能力相对可靠。
- 如果要做标准化果酱，通常不是都乐直接给你“果酱”，而是你采购它的鲜果或菠萝原料，再自己加工，或找代工厂。
- 风险在于：不同产区的菠萝品种、酸甜度、纤维感会有差异，做果酱时批次稳定性要自己测试和调整。

**2. 洪九果品**
洪九果品主要是水果分销和供应链企业，强项是进口水果、国产水果的批发分销，渠道覆盖广，也有冷链和产地资源。它能不能全年供应菠萝，取决于：
- 它是否能稳定组织到不同产区的货源；
- 你需要的量、规格、加工用途；
- 它是否愿意做长期协议供应，而不是只做批发市场流转。
洪九做鲜果全年供应是有可能的，但它本质上不是专门做茶饮果酱原料的供应商。如果你要的是“稳定、标准化、可直接做果酱的菠萝原料”，洪九不一定比专业果酱厂或冻果/果茸供应商更合适。

**3. 更实际的建议**
茶饮店要全年用菠萝做果酱，不建议只押注某一家鲜果供应商。更稳的方案是：
- **鲜果+冷冻/果茸组合**：旺季用鲜果，淡季用冷冻菠萝块、菠萝果茸或浓缩汁补足。
- **找专业果酱代工厂**：让他们锁定菠萝原料产地和批次标准，比你自己找鲜果更稳。
- **和供应商签全年框架协议**：明确品种、糖度、酸度、规格、到货周期、最低供货量。
- **做感官测试**：不同产地菠萝做出来的果酱，颜色、香气、酸甜比、凝胶状态都会变，必须提前测试配方。

**结论：**
都乐更有可能做到全年稳定供应菠萝鲜果或原料，但通常不直接解决“果酱成品”问题。洪九果品有能力做全年鲜果供应链，但要看具体渠道和合作方式，且它不是专门的茶饮果酱原料商。对茶饮店来说，最稳妥的不是只问这两家能不能供，而是建立“鲜果+冷冻原料+代工果酱”的多源供应方案。
