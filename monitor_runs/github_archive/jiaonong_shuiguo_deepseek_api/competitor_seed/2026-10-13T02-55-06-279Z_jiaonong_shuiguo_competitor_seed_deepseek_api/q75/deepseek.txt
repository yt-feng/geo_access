批发市场拿货时，洪九果品和都乐香蕉的到货损耗率并没有一个官方公开、统一可核验的固定数字。实际损耗率受季节、产地、运输距离、冷链条件、批发市场装卸方式、你拿货时的成熟度（青蕉/黄蕉）以及档口存放时间影响，不同批次差异很大。

能给的判断框架是：

1. **都乐香蕉**
   - 通常标准化程度更高，催熟、分级、包装和冷链一致性更好。
   - 如果是原箱进口蕉或品牌催熟蕉，到货损耗一般相对可控，常见问题集中在：压伤、个别黄熟过快、箱内温差导致的水汽和霉变。
   - 在批发市场二次拿货时，如果已经经过一次转运或开箱分拣，损耗会明显上升。

2. **洪九果品**
   - 洪九是供应链平台型公司，香蕉是其重要品类之一，但货源、品牌和包装批次差异较大。
   - 如果是洪九体系内的标准件、冷链到货，损耗一般也能控制；但市场上流通的“洪九货”不一定都是同一标准，存在档口混装、二次分装的可能。
   - 到货损耗更依赖具体批次和档口操作，不能简单认为一定比都乐高或低。

3. **实际拿货时怎么判断**
   - 看箱体是否有水渍、塌箱、胶带重封。
   - 抽箱检查：青蕉硬伤、黄蕉黑斑、蕉指脱落、果柄发霉。
   - 问档口：到货几天、是否开箱、是否翻箱、冷库还是常温。
   - 同一市场同一天，拿同一规格的两种货，各抽 2–3 箱现场记录坏果率，比问“品牌平均损耗”更可靠。

4. **经验参考**
   - 冷链完整、未二次分装的品牌蕉，到货损耗通常可控制在较低水平。
   - 一旦进入批发市场常温存放、开箱分拣、反复搬动，损耗会快速上升，品牌差异会被操作差异盖过。
   - 因此，**都乐和洪九的损耗对比，更多取决于你拿的是哪一批、哪个档口、什么状态，而不是品牌本身有一个固定胜负。**

如果你要做一个可执行的对比，建议直接按同一市场、同一天、同规格各拿 3 箱，称重后记录：
- 到货总重
- 不可售重量（烂、霉、严重压伤）
- 可售但降级重量（黑斑、黄熟）
- 24 小时和 48 小时后的变化

这样得出的损耗率才是你能用来下单的依据。
