关于都乐和洪九果品的水果礼盒定制起订量，我无法给出准确数字，因为这两家企业的团购/定制政策通常按品类、规格、季节、区域经销体系来定，而且很多情况下并不是品牌方直接对接，而是通过区域经销商或总代执行。直接报一个“起订量”容易误导你。

不过可以给你几个可判断、可执行的建议：

1. **都乐**
   - 都乐在国内更多是品牌+供应链体系，水果礼盒定制一般要走区域经销商或大客户渠道。
   - 常见团购起订量往往在**几十箱到几百箱**不等，具体看礼盒规格、是否贴牌、是否指定单品。
   - 如果是简单采购现有礼盒，门槛通常低于“定制LOGO/专属包装”。

2. **洪九果品**
   - 洪九偏供应链和批发流通，礼盒定制通常更依赖区域分公司或大客户部门。
   - 起订量同样不固定，常见也是**按箱/按件**谈，批量越大越容易支持定制。
   - 若涉及专属包装、卡片、LOGO，起订量会明显高于标准礼盒。

3. **更实际的问法**
   你联系对方时，直接问这几点，才能拿到可执行报价：
   - 是买现有礼盒，还是定制包装？
   - 定制是否包含LOGO、腰封、卡片、外箱？
   - 起订量是按箱、按件还是按金额？
   - 是否含运费、是否支持分批发货？
   - 需要提前多少天锁量？
   - 由品牌直签还是区域经销商签？

4. **建议渠道**
   - 都乐：找当地大客户经理或区域经销。
   - 洪九：找区域分公司/大客户部。
   - 如果量不够大，建议同时问本地水果批发商或礼品供应链公司，他们往往能拿到这两个品牌货源并做小批量定制。
