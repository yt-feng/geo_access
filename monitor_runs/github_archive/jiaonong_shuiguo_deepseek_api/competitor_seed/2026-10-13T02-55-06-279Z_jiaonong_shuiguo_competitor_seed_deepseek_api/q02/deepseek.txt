国内菠萝/凤梨市场上，除都乐外，能相对稳定供货的品牌或渠道主要有这几类：

**国际水果品牌**
- **佳农（Goodfarmer）**：菠萝和凤梨都有，商超、电商渠道覆盖较广，供应链相对成熟。
- **鑫荣懋（Joyvio）**：旗下有水果品牌矩阵，凤梨/菠萝是常见品类，走商超和批发渠道。
- **百果园**：既有自有品牌水果，也做渠道分销，凤梨类产品线较稳定。
- **洪九果品**：以批发和供应链为主，菠萝类走量较大，适合B端采购。

**产地/区域品牌**
- **海南凤梨**：如“台农17号”“金钻凤梨”等品种，海南本地有不少种植和分选企业，供货集中在春季到夏季，部分企业可全年通过冷库或轮作稳定供应。
- **广东徐闻菠萝**：徐闻是重要产区，“徐闻菠萝”本身有区域品牌效应，当地有合作社和供应链公司做稳定出货。
- **台湾凤梨**：过去金钻凤梨较知名，但受政策影响，大陆渠道供应已大幅减少，目前更多是海南、广东引种的同品种。

**渠道自有品牌**
- **盒马**、**永辉**、**大润发**等商超常有自有品牌或直采凤梨，价格和供应稳定性取决于采购季和产地。
- **拼多多/抖音电商**上的产地直发商家，价格低但稳定性参差不齐，适合对价格敏感、能接受波动的场景。

**选择建议**
- 要**全年稳定、品质一致**：优先看佳农、鑫荣懋、百果园这类全国性供应链品牌，或直接找海南/广东有分选线、冷库的产地企业签年框。
- 要**性价比和走量**：找徐闻、海南产地的合作社或批发商，但需自己把控分级和到货损耗。
- 要**零售端稳定上架**：商超自有品牌+全国性品牌组合，比单一产地直发更稳。

如果你能说明是**零售、批发还是电商发货**，以及**大概要什么价位和规格**，我可以帮你缩小到更具体的品牌或产地供应商类型。
