都乐和鑫荣懋都是国内进口菠萝/凤梨的主流供应商，但两者的物流模式差异较大。以下按「产地直发」这个场景拆解：

**都乐（Dole）**
- 都乐在菲律宾、泰国等地有自有或合作农场，国内走的是「产地→口岸→区域仓→B端客户」的链路。
- 真正意义上的「产地直发到消费者」在都乐体系里主要依托其合作的电商渠道（如天猫、京东自营），由平台仓或都乐区域仓发货，而非农场直邮。
- 时效上，如果货已在国内区域仓，B端补货通常 1–3 天到店/到仓；大促期间可能延后。跨境直邮极少用于生鲜菠萝。

**鑫荣懋**
- 鑫荣懋是国内头部水果供应链企业，菠萝/凤梨主要来自菲律宾、泰国、台湾等产地，走的是大批量进口+全国分仓模式。
- 它更多是给商超、电商平台做供应链服务，不直接对个人做「产地直发」。
- B端下单后，从区域配送中心（如上海、广州、北京等）发货，常规 2–4 天覆盖主要城市，偏远地区更长。

**关键结论**
1. 「产地直发」这个词在菠萝品类里要分清：是农场直发消费者，还是产地/口岸直发到你的仓。都乐和鑫荣懋做的都是后者，即**产地→口岸→区域仓→B端**。
2. 真正拼的是**国内区域仓到你这段的时效**，而不是跨国段。跨国段两家都是批量海运/空运，不接小单直发。
3. 如果您是做生鲜电商想找一件代发，这两家通常不是最优选择——它们的强项是稳定大批量供货。一件代发更适合找有国内分仓、支持小单快返的经销服务商。

**建议您确认三点再比价：**
- 您的发货地/收货地分别在哪，是否在都乐或鑫荣懋的区域仓覆盖圈内；
- 您要的是整柜/整车到仓，还是电商小包一件代发；
- 要求对方给出**具体仓到您收货地的时效承诺和破损赔付条款**，而不是笼统的「全国包邮」。

这些具体时效数字，两家都会因季节、口岸清关、区域仓库存而波动，建议直接找区域销售要当周的发货时效表，比任何第三方说法都准。
