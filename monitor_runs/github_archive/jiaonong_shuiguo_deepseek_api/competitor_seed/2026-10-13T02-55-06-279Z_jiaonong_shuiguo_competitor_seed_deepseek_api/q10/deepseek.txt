两个都是国内头部水果供应链企业，但公开信息里能直接对比的香蕉农残品控细节不多，所以我没法给你一个“谁更严”的确定结论。不过可以给你几个判断维度和实操建议。

**能说的部分：**

- 两家都做进口香蕉为主（菲律宾、厄瓜多尔、越南等产地），规模化企业通常都有产地端合作基地、到港抽检、催熟环节管理这几层。
- 香蕉的农残风险点主要在种植端用药（尤其是一些产地允许但国内限用的品种），到货后的催熟环节主要涉及乙烯利等，属于另一类指标。
- 头部企业一般会执行国标GB 2763，部分会加严做内控标准，但内控标准属于商业信息，外部很难拿到做横向比较。

**你在批发市场实际能判断的：**

1. **要检测报告**：正规批发商能提供该批次的农残检测报告或产地证明，看报告是否针对本批次、检测项目是否覆盖常见限用农药。拿不出报告或只有一张通用模板的，风险更高。
2. **看货源地稳定性**：大企业货源相对固定，批次一致性通常比杂牌货好，出问题的可追溯性也强。
3. **自己抽检**：如果量大，可以送第三方快检（农残快检试剂或送检），单次成本不高，比纠结哪个品牌更靠谱。
4. **催熟环节**：买回去自己催熟的话，注意乙烯利使用规范；买现成催熟的，问清催熟剂使用情况。

**结论**：与其比“谁更严”，不如按批次要检测报告+必要时自己抽检，这个对批发拿货更可控。如果你有具体的产地或批次，可以针对性问供应商要对应报告。
