关于洪九果品（重庆洪九果品股份有限公司）和都乐（Dole）对下沉市场夫妻店的**小批量供货**情况，直接回答是：**基本没有，且不适合作为你们的主要进货渠道。**

具体分析如下，供你决策：

**1. 洪九果品：**
- **模式**：洪九的核心是“端到端”大宗水果贸易，主要服务**大型商超（如永辉、盒马等）、批发市场二级经销商**以及电商平台的大仓。其业务逻辑是整车发运，计算的是规模利润。
- **小批量现实**：洪九极少直接对接夫妻店。对于夫妻店，如果需要它的货源，通常只能通过**当地农贸批发市场**进货——那些档口老板可能从洪九或其他产地采购，然后拆散零售给你，但这不是“洪九小批量供货”，而是二级批发。
- **建议**：如果你所在城市有大型水果批发市场（比如广州江南市场、北京新发地），档口老板的报价可能比直接对接原产地或者大厂更低，且灵活（一箱起拿）。洪九不会给你开小单。

**2. 都乐（Dole）：**
- **模式**：都乐是国际品牌，在中国主要深耕**精品商超（如山姆、开市客）、高端水果连锁、以及线上中高端生鲜**（如每日优鲜、叮咚买菜等）。其产品多为品牌香蕉、菠萝、牛油果等标准化包装。
- **小批量现实**：都乐有严格的渠道管理，为保证价格体系和品牌形象，**不会向夫妻店供货**。即使你打电话过去，通常也会被转介给当地的经销商。而经销商通常有批量门槛（比如整板或整柜），对夫妻店来说库存压力太大。
- **建议**：如果你要卖都乐品牌水果撑门面，建议去当地的水果批发市场找代理都乐的档口，他们允许你拿小几箱货。但请注意，都乐产品溢价较高，在下沉市场**由于品牌溢价不一定卖得动**，且损耗风险大，需谨慎。

---

**给下沉市场夫妻店的实操建议（避免踩坑）：**

1. **主渠道**：找离你最近的**一级或二级农批市场**。早上5-6点去进货，小批量（几箱起）没问题。重点看当天物流到货的“新货”和“处理货”（尾货价格低，但损耗加快）。
2. **供货稳定性**：夫妻店资金有限，建议不要囤货。每天根据昨日销量决定进货量，主打“勤进快出”。
3. **品类选择**：下沉市场消费者对价格敏感度高。**建议主攻当季大众水果**（如西瓜、苹果、柑橘），少碰“新奇贵”的进口果（如牛油果、蓝莓）——除非你地处县城中心且有特定客群。
4. **替代品牌参考**：如果确实想找稳定且有品牌的供货，可以考虑**国产头部如百果园的B端分销（但门槛也不低）**，或者直接去寻找**当地产业带合作社**（如陕西苹果、广西砂糖桔产区的货源），比国际大牌更合适。

最后提醒：**千万不要为了“品牌”去签任何月结协议或大量囤货**。水果是易损耗品，最忌讳压货。小批量、多频次是你利润的护身符。
