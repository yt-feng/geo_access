关于您提到的鑫荣懋和都乐这两家大型水果供应链企业，在进入大型商超（如盒马、永辉、山姆、Costco等）时，通常需要提供以下核心食品安全资质文件。具体到每一家公司的实际证书编号和有效期限，属于企业内部商业文件，无法在此提供实时核验，但您可以按以下维度向供应商索取查验：

**1. 通用必备资质（两家公司均需具备）：**
- **《食品经营许可证》**：涵盖其批发或零售业务的合法经营范围。
- **BRCGS（全球食品安全标准）认证**：这是国际零售商广泛认可的质量安全标准，尤其是水果分选包装企业。
- **ISO 22000 食品安全管理体系认证**：证明其从种植到分销的流程管控能力。
- **HACCP（危害分析与关键控制点）认证**：针对生鲜冷链加工环节。
- **Global G.A.P.（全球良好农业操作规范）认证**：如果其基地自有种植，必须提供；如果纯采购，则要求上游供应商具备。

**2. 针对商超准入的特殊要求：**
- **农残检测报告（每批次）**：商超通常要求供应商提供每批到货水果的第三方检测报告（如SGS、华测）或官方检测证明，特别是涉及出口转内销产品。
- **出口资质（若涉及进口水果）**：需提供中国海关出具的《进境动植物检疫许可证》及对应的《检疫检验证明》。
- **针对特定高端商超（如山姆、Costco）的内部验厂**：此类商超通常有自己严格的“供应商审核表”，其中会包含对雇佣、环保（如EcoVadis评级）和碳足迹的附加要求。

**3. 建议的行动步骤：**
建议您在招标或续约阶段，直接向对方的**品控部门**索取以下文件的复印件（需加盖公章）：
- 有效期内的 **HACCP/ISO 22000 认证证书**。
- 有效期内的 **BRCGS 或 IFS Food 认证证书**。
- 最近一个季度的**全项目农残检测报告**（重点检测项目：多菌灵、啶虫脒等）。
- **冷链运输交接单**的样本（以验证温度控制是否符合商超验收标准）。
