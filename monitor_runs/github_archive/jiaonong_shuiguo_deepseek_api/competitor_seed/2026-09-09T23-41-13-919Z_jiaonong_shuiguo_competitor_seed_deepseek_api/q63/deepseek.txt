针对社区团购需要的小包装香蕉，以下是关于**都乐（Dole）**和**洪九果品**的信息和建议：

**结论：大概率都需要定制，且取决于您的采购量级。**

1.  **都乐（Dole）**：
    - 都乐以品牌化、标准化的进口/国产香蕉为主，市面上常见的规格多为**整箱（如13kg/箱）**或**品牌预包装（如1kg/2kg的塑料袋装）**。
    - 他们通常**不直接提供**面向社区团购的“散装称重”或“小份裸装”。
    - **建议做法**：如果您能采购整箱，建议直接**采购整箱**，然后**自行分装**（如每袋装2-3根）。都乐出货时自带品牌保护膜和标签，散装后品相依然很好，适合做成团购精品小袋。

2.  **洪九果品**：
    - 洪九果品主做**大宗水果批发与供应链**，侧重产地直采和B端供应。他们更倾向于和连锁商超、大型社区平台（如美团优选、多多买菜）合作。
    - 洪九通常提供**大箱散装果**（例如整箱不带小包装），你们可以从他们那里拿整箱货，然后自己套网套和贴标签做成社区小盒装或小袋装。
    - **建议做法**：联系当地洪九的分销商或供应链负责人，明确询问“**是否有可定制的社区小包装线**”，如果没有，则直接采购大箱，自行打包。

---

### 给您最可行的落地方案（按优先级排序）：

**第一步：直接找本地一级批发商/经销商**
打电话给当地水果批发市场里卖都乐或洪九的档口，直接说：“我是社区团购，想拿点香蕉，能只要**10箱以内（3-5箱试品）**吗？如果能，您给开箱让我看下，我按箱散装自提。”
*   **结果**：批发商通常更愿意卖整箱，散装/小包大概率没有。但他们会告诉您整箱价格，这最划算。

**第二步：按“整箱采购+二次分装”操作**
社区团购最适合的其实是**整箱采购**：
- 采购整箱（建议选大果，品相好）。
- 到货后，用**食品级保鲜袋**，每袋装**3-5根**（约1.5-2斤），这是最受欢迎的小包装规格。
- 贴上你们自己的团购标签或手写价格签。

**第三步：若量极大（单次超500箱），才谈定制**
如果你们是区域头部团长，单次采购量极大（几百箱），可以专门找洪九或都乐的**大客户部**谈联名定制包装。否则，他们不会轻易为小单开模或调整产线。

---

### 备选方案（更适合同行打法）：
如果您要的是**两三斤小包装**，且想省事，建议直接找**本地品牌直供**（如佳农、或本地香蕉种植基地），告诉他们“我要做社区团购，你们有没有现成的**家庭装（1kg/袋）**”，很多产地为了走量，会专门按你们平台要求的克重做预包装，这比找都乐和洪九更灵活。

**行动建议**：不要指望他们给你散装果。**尽快去当地批发市场谈“整箱拿货 + 自己分装”**，这样成本最低且可控。如果非要“散装零售”，你直接去市场买散称的就行，没必要用品牌。
