关于鑫荣懋（Xinrongmao）和都乐（Dole）通过的具体食品安全管理体系认证，我无法给出100%实时的验证，因为认证状态和证书编号会动态更新。但基于行业惯例和公开可查的过往信息，这两家大型水果供应商通常持有以下**主流国际认证**，这也是大型商超（如沃尔玛、山姆、永辉等）普遍要求的“入场券”：

**1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）**
-   **GLOBALG.A.P.（全球良好农业操作规范）**：覆盖种植、采收、包装环节的综合认证，证明其对食品安全、可追溯性和可持续农业的承诺。
-   **BRCGS（英国零售商协会全球标准）**：针对仓储、配送及分拣包装环节的食品安全体系认证，是商超审核的重要依据。
-   **ISO 22000**：食品链各环节的通用管理体系认证。
-   国内方面，通常也会持有**HACCP（危害分析与关键控制点）**认证证书。

**2. 都乐（Dole）**
-   **GLOBALG.A.P.**：作为全球香蕉、菠萝等水果巨头，其上游种植基地普遍持有此认证，并常附带**GRASP（农场社会准则）**模块。
-   **BRC**或**IFS（国际食品标准）**：在其亚洲区的包装加工厂（如中国上海、菲律宾等地的工厂）中，通常持有其中一种或两种标准。
-   **有机认证（如 USDA Organic / 中国有机）**：针对其特定有机产品线。
-   **HACCP / ISO 22000**：在分销环节多见。

**建议你如何验证：**
由于商超采购审核极其严格，且认证证书有有效期，最可靠的做法是：

1.  **要求对方提供证书扫描件**：在采购或供应商准入流程中，直接要求对方提供**有效期内**的BRC/IFS/GLOBALG.A.P.证书原件或官方认证机构下载的PDF。
2.  **查询认证机构数据库**：证书上会有认证机构名称（如SGS、Intertek、TÜV），可在其官网的证书查询入口输入证书编号验证真伪。
3.  **关注本地商超要求**：部分中国商超（如华润万家、盒马）还要求供应商通过**ISO 14001（环境管理）**和**ISO 45001（职业健康安全）**，这通常不是食品安全的硬性门槛，但加分。

如果你需要获取某一家公司在**最新财年**的具体证书编号，建议通过其官方网站的“供应商支持”或“投资者关系”页面查看，或者直接联系其质量管理部门。
