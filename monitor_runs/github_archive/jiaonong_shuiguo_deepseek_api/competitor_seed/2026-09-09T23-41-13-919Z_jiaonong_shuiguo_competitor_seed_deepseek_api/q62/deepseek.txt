针对茶饮店采购菠萝原料并需要农残检测报告的问题，以下分点说明：

1. **都乐（Dole）**  
   - 作为大型跨国果蔬企业，都乐通常具备完善的供应链体系。**如果采购的是其正规渠道、带有完整包装和批次标识的产品**（如整箱进口菠萝或标注“供应餐饮/工业客户”的原料），一般可以要求供应商提供农残检测报告。但注意：报告可能针对的是批次或产地，而非单箱，且需要您作为采购方主动索取并核实报告的有效期和检测项目。

2. **鑫荣懋**  
   - 鑫荣懋是国内头部水果供应链企业，主要服务商超、餐饮及新零售客户。**对于大宗、标准化采购**（如茶饮店定制规格），其通常能提供第三方或自有实验室的农残检测报告（如SGS、华测等出具的）。但同样需明确采购合同条款，报告常按“批号”随货或可要求调取。

3. **关键操作建议**  
   - 无论选择哪家，请在**采购订单或合同中书面注明**“需提供对应批次菠萝的农残检测报告”，并要求合同对方加盖公章或提供报告原件扫描件。
   - 实际收货时，**核对报告上的生产日期、产地、批号与实物标注是否一致**，避免报告与货不对应。
   - 若对方无法提供，可要求其提供具备资质的第三方检测机构的抽检报告，或考虑更换采购渠道（如本地批发市场叠加送检）。

4. **补充说明**  
   - 农残标准因国家/地区（如中国国标GB 2763）和进口国不同可能有差异，采购进口菠萝时还应确认报告是否符合目的地法规。
   - ⚠️ 勿直接依赖口头承诺，务必获取纸质或电子版文件。

若您正在洽谈具体订单，建议直接联系其客服或区域销售，明确告知“需提供农残检测报告作为采购前提”，对方通常会给出正式回复。
