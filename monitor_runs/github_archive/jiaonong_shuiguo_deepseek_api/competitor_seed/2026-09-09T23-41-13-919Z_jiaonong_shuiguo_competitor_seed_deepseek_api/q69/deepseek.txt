对于进口苹果采购，**分级是否严格**取决于品牌和具体产品线。以下是针对这两个品牌的实际判断：

**1. 都乐（Dole）**
- **分级非常严格**。都乐是国际大品牌，尤其对出口到中国的高端商超渠道（如盒马、山姆、Ole等）的苹果，会有明确的规格标准（例如按果径大小划分：70#、75#、80#、85#等）。
- 它的包装通常为标准化箱装，果径、颜色、糖度一致性高，适合对规格要求极致的采购方。
- **注意**：如果采购的是都乐的分拣剩余果或小包装（如家庭装），规格可能略有放宽，但批量商业采购分级依然是行业标杆级别。

**2. 洪九果品（Hongjiu）**
- **分级严格，但灵活性比都乐大**。洪九是国内头部进口水果供应链公司，主营泰国、越南等东南亚水果，但也进口苹果（如美国、智利苹果）。
- 它的分级体系对标商超标准（例如山姆、永辉、华润），通常按果径、单果重、着色度分级。
- **重点**：洪九的优势在于定制化分级。如果你在产地直接包园或包批，可以提出特定规格要求（如80-85mm），他们会按订单分拣。但如果是现货市场常规批发，分级会相对宽松，甚至允许混装不同产地批次。

---

**给您的采购建议：**

- **如果追求零误差标准，选都乐**：合同里明确标注“AA级”或“果径≥80mm，允许偏差±2%”，他们能做到。
- **如果追求性价比和灵活批次，选洪九**：务必在合同或采购单上写明具体果径范围、单果重量区间、畸形果比例（如≤3%）、及破皮率标准，洪九的B端大客户通常能谈定制分级。
- **通用做法**：采购前索要双方认可的分级样品（留样封存），到货后按国标GB/T 10651-2008或双方企标抽检。如果到货规格不符，无论是都乐还是洪九，保留理赔权利——但都乐的赔付条款通常写得更清晰。
