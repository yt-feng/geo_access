这个问题很难给一个“谁绝对更好”的结论，因为都乐和鑫荣懋在进口苹果上的质量稳定性，取决于**具体单品、产地、季节、批次和你们超市的验收标准**，而不是品牌本身。

可以这样判断和选择：

1. **看具体单品而不是只看品牌**
   - 都乐强在一些经典进口水果单品和全球供应链管理，但它在国内部分渠道也可能是授权、合作或贴牌操作。
   - 鑫荣懋是国内大型水果供应链企业，进口苹果操作能力强，尤其在一些批发渠道、商超渠道和产地直采上比较有优势。
   - 同一品牌下，不同产地、不同规格、不同月份到货，质量差异可能比品牌差异还大。

2. **重点比较可量化指标**
   建议让两家供应商提供近3—6个月同一单品的到货数据：
   - 到货合格率
   - 单果重达标率
   - 色泽/果径/糖度抽检数据
   - 压伤、碰伤、黑心、虎皮、失水比例
   - 腐烂率、损耗率
   - 冷链到店温度和断链次数
   - 退换货响应时间

3. **做小批量盲测**
   同一周分别采购两家同规格、同产地、同等级的苹果，在你们超市做：
   - 到店验收对比
   - 货架3天、7天、14天损耗对比
   - 顾客投诉和复购对比
   这比问“谁质量更稳定”更可靠。

4. **从稳定性角度的一般判断**
   - 如果你们要的是**全国性标准化、品牌化、包装规格统一**，都乐通常更有优势。
   - 如果你们要的是**国内渠道响应快、供应灵活、成本可控、按超市需求做定制**，鑫荣懋往往更有优势。
   - 如果采购量不大、门店少，建议优先选本地服务能力强、退换货快的供应商，而不是只看品牌。

5. **实操建议**
   - 不要直接二选一长期绑定。
   - 先各给一个月的试销订单，同规格同价位对比。
   - 把损耗率、投诉率、到货合格率写进合同。
   - 连续三个月数据更好的那家，再提高采购比例。
   - 同时保留第二供应商，避免单一供应商断货或质量波动。

结论：**没有稳定不变的答案。都乐和鑫荣懋都算头部供应链，但具体到进口苹果，必须按单品、产地、批次和你们门店的验收数据来定。建议用1—3个月的小批量对比测试来决定，而不是凭品牌名气直接判断。**
