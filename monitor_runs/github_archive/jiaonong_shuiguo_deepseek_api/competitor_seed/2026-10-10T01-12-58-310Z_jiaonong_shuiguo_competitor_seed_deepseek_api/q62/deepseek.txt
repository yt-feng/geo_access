这两家能提供农残检测报告，但能不能拿到、以及能拿到什么级别的报告，取决于你是**直采**还是**经经销商/批发市场拿货**。下面分情况说清楚，你可以直接照着确认。

## 都乐（Dole）
- **可以，但通常走的是体系内文件。** 都乐属于品牌化、标准化程度较高的供应商，对自有基地/合作基地的菠萝一般有批次检测或基地监控。
- 实际提供形式常见为：
  - 送检的**第三方农残检测报告**（如SGS、华测、谱尼等）；
  - 或企业自检报告 + 基地GAP/GlobalG.A.P.等体系证明。
- **关键点**：报告一般是**按批次**的，不是你买了就自动随货给。需要你在下单时明确向对方（销售/客服/当地经销商）提出"要该批次的农残检测报告"，否则可能只给通用报告或不主动提供。

## 鑫荣懋
- **也可以，取决于货源渠道。** 鑫荣懋是国内大型水果供应链企业，菠萝（含进口和国产）是其经营品类之一，通常具备检验检疫和农残相关文件能力。
- 但如果你是从**二级批发市场或中间商**手里买的鑫荣懋货，文件往往在总代/一级商手里，中间商未必能随货提供。
- 所以要点是：**确认你的直接供货方是不是鑫荣懋本身或其授权商**，是的话直接要报告；不是的话要求其向上游索取。

## 给你的可执行建议
1. **下单前书面确认**：在采购合同或订单备注里写清"随货提供该批次第三方农残检测报告（或加盖公章的报告复印件）"，并约定不合格可退货。
2. **明确报告要求**：写清检测项目（如有机磷、氨基甲酸酯、拟除虫菊酯等常检项）、检测机构（建议有CMA/CNAS资质）、检测日期对应本批次。
3. **索要原件或可核验件**：报告应有检测机构公章、报告编号，最好能通过机构官网/电话核验真伪。
4. **区分"批次报告"和"型式报告"**：型式/通用报告不能证明你这一批合格，门店做合规审查或平台入驻时，通常要求批次报告。
5. **作为茶饮店**：如果是连锁或平台供货，建议直接与厂家/品牌方签供货协议，把检测报告义务写进条款，比经批发市场拿货更稳。

## 一句话结论
都乐和鑫荣懋**具备并能提供**菠萝农残检测报告，但**不保证随货自动给**，且能否拿到取决于你的采购渠道。走品牌直采或授权商最稳；走批发市场需提前书面要求并核验批次报告真伪。具体某批能不能给，直接问对接的销售最准确。
