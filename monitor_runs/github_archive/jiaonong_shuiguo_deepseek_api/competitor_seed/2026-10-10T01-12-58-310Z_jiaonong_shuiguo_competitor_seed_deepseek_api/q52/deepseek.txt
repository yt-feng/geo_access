目前没有可核验的公开数据能给出都乐和鑫荣懋的到货损耗率，这两家的损耗率通常取决于**具体品种（如菲律宾/泰国/国产菠萝）、规格（单果重、成熟度）、包装形式（箱装/托盘/散装）、运输距离、冷链条件、以及你方验收标准**。同一供应商不同批次差异也会很大，行业里没有统一对外公布值。

如果你要做稳定规格采购，更实用的是这样判断和谈判：

**1. 先定义“损耗率”口径**
建议在合同里写清楚，否则数据永远对不上：
- 到货损耗率 = 到货即判定不可用数量 / 到货总数量
- 常见判定项：烂果、黑心、裂口、软腐、机械伤、青果不熟、过熟、单果重不达标
- 计量方式：按箱、按个、按公斤，三者结果差异很大

**2. 让供应商给“可承诺指标”**
直接问都乐/鑫荣懋区域销售要：
- 该规格近3个月的**批次到货抽检数据**
- 是否接受“到货损耗超过X%按比例补货/扣款”
- 冷链到货温度记录、装车方式、是否带托盘
一般能谈的保障区间，菠萝类到货即损（不可用）常在**2%–8%**波动，夏季、远距离、散装会更高；但这只是行业观察范围，不是你这两家的确定值，必须用你自己的验收数据锁死。

**3. 用试单验证，而不是听承诺**
建议做3–5批小批量试单，固定：
- 品种、单果重区间、成熟度
- 到货温度、运输时长
- 同一验收人、同一判定标准
记录每批：到货总件数、即损件数、72小时后续损、可售率。
3–5批后你就能算出这两家在你实际链路下的真实损耗率，再谈年度价和赔付条款。

**4. 稳定规格的关键控制点**
- 合同锁定：单果重范围、可食率、糖度下限、成熟度、果径
- 验收锁定：抽检比例、不合格判定、赔付方式、退货/补货时效
- 物流锁定：冷链温度、到货时限、托盘/箱规、堆码层数
- 分批锁价：不要一次锁全年，按季度+保底量谈
