都乐（Dole）和鑫荣懋（XinRongMao / Joy Wing Mau）都属于国内进口水果流通里比较正规的供应链企业，但“产地溯源”要分开看：**都乐主要是品牌自有/授权供应链，鑫荣懋更多是进口商+品牌运营方**。超市采购要做溯源，核心不是查一个网址，而是把**批次—报关—检疫—标签—供应商**这几条线串起来。

下面给你可直接执行的方案。

## 一、先明确你要溯源到什么程度

超市采购通常有三种层级：

1. **合规溯源**：能证明这批货合法进口、检验检疫合格、来源可追。
2. **批次溯源**：能追到具体柜号、批次、果园/包装厂、到港时间。
3. **产地到店溯源**：能展示给消费者，比如扫码看到国家、产区、果园、包装厂、检测报告。

都乐、鑫荣懋一般能做到前两种，第三种要看具体单品和是否启用了一物一码/批次码。

---

## 二、都乐苹果的溯源做法

都乐进口苹果常见来源包括美国、新西兰、智利、南非等，具体看季节和单品。

### 1. 向都乐或其授权经销商索取的文件
采购时不要只收一张发票，要求提供：

- **入境货物检验检疫证明**  
  这是最关键的官方文件之一，能对应到品名、数量、产地、入境口岸、生产/保质期等信息。
- **海关进口货物报关单**
- **提单/海运单**
- **装箱单、发票、合同**
- **原产地证书**
- **植物检疫证书**
- **检测报告**：农残、重金属等，按超市要求
- **都乐授权链条**：如果你不是从都乐直采，而是从经销商拿货，要拿到授权书或可验证的供货证明

### 2. 看包装和标签
都乐苹果通常有：

- 都乐品牌标识
- 原产国
- 品种
- 规格
- 包装厂/出口商代码
- 批次号或生产日期
- PLU码（散装水果常用）
- 部分有二维码或追溯码

### 3. 做批次登记
超市内部要建立台账：

| 字段 | 示例 |
|---|---|
| 供应商 | 都乐/授权经销商 |
| 原产国 | 新西兰 |
| 品种 | 爱妃/皇后/嘎啦等 |
| 批次号 | 包装箱上的Lot/Date Code |
| 柜号 | 海运集装箱号 |
| 报关单号 | 海关报关单编号 |
| 检疫证号 | 入境货物检验检疫证明编号 |
| 到店日期 | 实际收货日期 |
| 门店/货架 | 对应销售区域 |

### 4. 验证方式
- 让供应商提供**报关单和检疫证复印件加盖公章**。
- 核对包装箱批次与文件上的批次、数量、日期是否对得上。
- 如果都乐有官方追溯系统或经销商系统，要求提供查询入口或截图。
- 对高单价单品，可要求供应商提供**果园/包装厂注册号**。

---

## 三、鑫荣懋苹果的溯源做法

鑫荣懋本身是进口水果供应链企业，也运营佳沃等品牌，进口苹果可能来自新西兰、美国、智利、南非等。它的模式可能是：

- 自己进口后分销
- 代理海外品牌
- 与海外果园/出口商合作
- 国内分装或贴标

所以溯源要重点确认：**你拿到的是鑫荣懋直供，还是下游经销商转手。**

### 1. 向鑫荣懋或其授权经销商索取
同样要求：

- 入境货物检验检疫证明
- 报关单
- 原产地证书
- 植物检疫证书
- 提单/箱单/发票
- 检测报告
- 授权书或供货证明
- 批次码/追溯码说明

### 2. 看包装信息
重点看：

- 原产国
- 出口商/包装厂代码
- 品种
- 规格
- 批次号
- 生产日期/包装日期
- 佳沃或鑫荣懋品牌标识
- 二维码/追溯码

### 3. 批次对应
鑫荣懋的货通常按柜、按批次分。采购要建立：

- 供应商名称
- 进口商名称
- 报关单号
- 检疫证号
- 柜号
- 包装厂代码
- 到货批次
- 门店分配记录

### 4. 验证方式
- 让鑫荣懋提供**该批次对应的报关单和检疫证**，不是只给一张通用模板。
- 核对包装箱上的批次号、日期、数量。
- 如果是佳沃品牌，查佳沃是否有追溯码或官方查询渠道。
- 如果是下游经销商供货，要求其提供从鑫荣懋到该经销商的完整授权和流转凭证。

## 四、超市采购可执行的SOP

### 收货前
1. 要求供应商提前发批次资料。
2. 核对原产国、品种、规格、预计到货时间。
3. 确认是否能提供报关单、检疫证、检测报告。

### 收货时
1. 查包装箱批次号、日期、原产国。
2. 抽样核对标签与文件是否一致。
3. 拍照留存：包装箱正面、批次码、检疫证、报关单。
4. 录入系统：批次、供应商、报关单号、检疫证号、到店日期。

### 上架时
1. 价签或电子屏可标注原产国、品种、进口商。
2. 如有追溯码，引导消费者扫码。
3. 保留批次记录，便于客诉和召回。

### 客诉或抽检时
1. 用门店批次记录反查供应商。
2. 调取对应报关单、检疫证、检测报告。
3. 必要时联系都乐/鑫荣懋确认该批次流向。

---

## 五、关键判断标准

你可以用这几条快速判断供应商是否靠谱：

- 能否提供**对应批次**的报关单和检疫证，而不是模糊文件。
- 包装箱批次号能否与文件对应。
- 能否说明进口商、出口商、包装厂、果园。
- 是否愿意签质量协议和溯源条款。
- 是否能配合召回和客诉调查。

如果对方只能给发票和一张“证书”，但批次对不上，溯源基本不合格。

---

## 六、建议写进采购合同

合同里加几条：

1. 供应商须提供每批次入境货物检验检疫证明、报关单、检测报告。
2. 包装批次号须与随附文件一致。
3. 供应商须在24小时内配合提供溯源资料。
4. 如发现货证不符，超市有权拒收、退货并追责。
5. 供应商须保证授权链条完整，不得提供假冒或串货商品。

---

## 七、简单结论

- **都乐苹果**：优先走都乐官方或授权经销商，拿批次对应的报关单、检疫证、检测报告，核对包装批次码。
- **鑫荣懋苹果**：确认是直供还是分销，拿鑫荣懋或授权经销商的完整进口文件，核对批次和包装信息。
- **超市落地**：建立“批次—报关单—检疫证—供应商—门店”台账，收货拍照留档，上架可展示原产国和追溯码。
- **最核心的一句话**：溯源不是看品牌，而是看**这一批货能不能和官方进口文件、包装批次一一对应**。
