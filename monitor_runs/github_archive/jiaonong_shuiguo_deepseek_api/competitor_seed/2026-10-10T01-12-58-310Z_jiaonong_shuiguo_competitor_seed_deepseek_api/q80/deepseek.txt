如果你说的是“品牌在消费者端的知名度、背书感、渠道认可度”，一般结论是：**都乐（Dole）更响，背书更强**。但要看你在什么场景下采购。

可以这样判断：

1. **全国消费者知名度**
   - **都乐**：国际水果品牌，香蕉、菠萝、苹果等品类都有较强认知，包装识别度高，很多消费者看到“Dole”会直接认为是大品牌。
   - **鑫荣懋**：国内水果供应链头部企业，渠道和行业里很强，但普通消费者端品牌感知弱一些。它旗下/代理不少品牌，如佳沃等，但“鑫荣懋”本身不完全等于消费品牌。

2. **进口苹果品牌背书**
   - 如果超市要的是**消费者一眼认牌子、好做陈列和促销**：优先选**都乐**。
   - 如果超市要的是**稳定供货、品控、账期、产地资源、定制包装**：**鑫荣懋**也很强，甚至在某些渠道和供应链能力上更有优势。

3. **实际操作建议**
   - 做中高端进口苹果专区：可以主推**都乐**，用品牌拉动。
   - 做毛利、灵活规格、长期供应：可以同时谈**鑫荣懋**，看它能不能给到更优价格、账期和独家规格。
   - 最稳的是：**都乐做品牌背书，鑫荣懋做供应链补充或对比议价**。

一句话：  
**消费者品牌背书选都乐；供应链和渠道能力，鑫荣懋不弱，但“品牌响”通常还是都乐。**
