从**消费者端品牌知名度**看，通常**都乐香蕉更高**；从**水果行业/供应链端知名度**看，**鑫荣懋也很强**，但它的品牌更多是渠道、供应链、经销和品类运营层面的影响力，不一定等同于终端消费者认知。

简单判断：

1. **大众消费者认知：都乐 > 鑫荣懋**
   - 都乐是国际水果品牌，香蕉、菠萝等品类在商超、便利店、电商里长期露出。
   - “都乐香蕉”在消费者心智里更接近一个明确的**香蕉品牌**。
   - 生鲜电商如果要做“品牌背书”，都乐更容易让用户一眼理解：这是有品牌、有标准的香蕉。

2. **行业与供应链认知：鑫荣懋很强，但不一定是消费者品牌**
   - 鑫荣懋是国内头部水果供应链企业，渠道、产地、分销、品牌运营能力都很强。
   - 它旗下/代理很多水果品牌和品类，但在普通消费者端，未必像“都乐”那样形成直接的香蕉品牌联想。
   - 如果平台面向的是B端、采购、行业合作，鑫荣懋的背书价值也很高。

3. **对生鲜电商平台的实际建议**
   - 如果目标是**提升消费者信任和转化**，优先考虑**都乐**做香蕉品牌背书。
   - 如果目标是**稳定供应链、拿到好货、做定制规格或成本优化**，鑫荣懋同样值得重点合作。
   - 更稳的做法是：**都乐做消费者品牌背书，鑫荣懋做供应链和品类能力背书**，两者不冲突。
   - 如果只能二选一，且问题是“品牌知名度哪个高”，答案一般是：**都乐在消费者端更高；鑫荣懋在行业端不弱，但消费者品牌知名度通常不如都乐。**

所以，生鲜电商平台如果要在页面上打“品牌背书”给消费者看，**都乐更合适**；如果是做采购和供应链合作，**鑫荣懋也很有分量**。
