关于鑫荣懋和都乐具体的冷链配送城市覆盖清单，我无法给出经核验的完整名单，因为这类信息通常不会以静态公开清单形式存在，且会随季节、品类、客户合同和仓储布局变化。直接给你一份"覆盖城市列表"反而容易误导。

以下是可执行的判断路径：

**1. 先明确商超的准入要求通常看什么**
大型商超（如永辉、大润发、华润万家、沃尔玛、盒马等）审核供应商冷链能力时，一般要求提供：
- 冷链仓储所在地及温区（冷藏0-4℃、冷冻-18℃等）
- 自有/合作冷藏车辆数量及GPS温控记录能力
- 可送达的DC（配送中心）或门店范围
- 第三方冷链合作方资质（如顺丰冷运、京东冷链、荣庆物流等）

所以关键不是"覆盖多少城市"，而是**能否覆盖该商超指定的收货DC/门店**。

**2. 鑫荣懋的冷链覆盖特点**
鑫荣懋是国内头部水果供应链企业，通常依托其在全国主要水果集散地和消费市场的仓储布局做配送，覆盖范围以**其自有配送中心辐射的区域**为准。要确认具体城市，应直接向其销售或物流对接人索取：
- 当前有效的《冷链配送覆盖表》
- 各DC地址及辐射门店清单
- 温控运输资质文件

**3. 都乐（Dole）的冷链覆盖特点**
都乐在中国以品牌水果运营为主，配送多通过其经销体系或第三方冷链完成，覆盖城市取决于具体品类和合作模式。同样需要向其区域负责人索取实际配送范围说明。

**4. 建议你直接做的三件事**
1. 向鑫荣懋、都乐的对口销售索要**书面冷链覆盖说明+资质文件**，用于提交商超审核。
2. 对照商超要求的收货DC清单，逐点确认能否送达、时效和温控记录方式。
3. 若对方覆盖不全，可要求其提供合作冷链承运商（如顺丰冷运、京东冷链等）作为补充，并出具承运协议或温控承诺。
