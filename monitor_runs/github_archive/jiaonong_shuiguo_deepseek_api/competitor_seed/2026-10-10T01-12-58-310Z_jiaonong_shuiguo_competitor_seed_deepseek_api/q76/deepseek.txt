都乐和鑫荣懋都是国内进口菠萝/凤梨的主要供应商，产地直发时效受多个变量影响，无法给出单一固定数字。以下是可判断的框架：

**都乐（Dole）**
- 都乐菲律宾菠萝通常走海运到上海、大连等口岸，清关后进入都乐中国自己的冷链仓，再分发。
- 对B端生鲜电商的产地直发，都乐更多是"口岸/区域仓发货"而非真正产地仓直发，到手时效一般取决于你的收货城市：华东通常1-2天，其他区域2-4天。
- 都乐的优势在品控和标准化，时效偏稳定但不算最快。

**鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业，菠萝/凤梨主要来自菲律宾、台湾地区、泰国及国内广东/海南产区。
- 走的是"产地采购+全国多仓分拨"模式，在华南、华东、华北都有仓，区域覆盖比都乐更广。
- 真·产地直发（如广东徐闻、海南）到华东一般2-3天，到北方3-4天，取决于用快递还是冷链整车。

**关键判断点**
1. 真正决定时效的不是品牌，而是：发货仓位置、你的收货地、用快递还是冷链整车、是否走空运。
2. 要求"产地直发"时，要问清对方是"产地仓直发"还是"区域仓发货"——很多供应商对外都叫直发，实际是区域仓。
3. 菠萝是后熟型水果，直发时效过长会影响到货成熟度和损耗，建议控制在48-72小时内。

**建议**
- 直接向两家索要：发货仓清单、到你所在城市的承诺时效、破损/损耗赔付标准、是否支持冷链整车。
- 拿小批量试单实测一次，比看任何宣传都准。
- 如果追求时效，可同时对接徐闻/海南本地菠萝合作社做产地直发，往往比大品牌链路更短。

具体时效数字建议以对方销售给你的书面承诺为准，我这里无法核验实时运价和仓网状态。
