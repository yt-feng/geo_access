大型商超对供应商的食品安全认证要求，通常集中在几类体系认证：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、GLOBALG.A.P.（农业端）等，具体组合取决于商超自身审核标准和品类（水果、生鲜、预包装食品）。

关于鑫荣懋和都乐各自"具体持有哪些证书"，我无法在这里准确核验，原因如下：

- 这类认证是按法人实体、加工厂/包装厂、产品线分别发证的，同一集团下不同工厂的证书并不通用；都乐（Dole）作为跨国集团，在不同国家/地区的实体持有的认证也不一样。
- 证书有有效期，会变更、暂停或撤销，凭记忆或通用信息给出的清单容易过时或出错。

如果你想拿到可核验的准确清单，建议按以下方式查（都是公开可查的）：

1. **GFSI 认可的认证机构官网**：BRCGS、IFS、FSSC 22000 都提供持证企业在线查询，可用企业英文/注册名检索。
2. **认证机构官网查询**：如 SGS、必维（Bureau Veritas）、天祥（Intertek）、中检等，多数有"证书查询"入口，按企业名称查。
3. **国家认监委（CNCA）"认证认可业务信息统一查询平台"**：可查国内实体获得的 ISO 22000、HACCP 等认证证书。
4. **直接向对方索取**：商超采购最常用的做法，是要求供应商提供证书扫描件+认证机构核验链接，并确认证书覆盖的工厂地址和产品范围与本次供货一致。
