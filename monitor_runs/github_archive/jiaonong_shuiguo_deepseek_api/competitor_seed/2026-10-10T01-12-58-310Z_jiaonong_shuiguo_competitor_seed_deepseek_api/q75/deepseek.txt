到货损耗率没有统一的公开固定值，主要取决于**批次成熟度、运输距离/冷链、季节、包装方式、批发市场卸货与暂存条件**。洪九果品和都乐香蕉不能简单用一个固定百分比对比。下面给你可判断的参考区间和拿货决策方法。

**一、一般参考区间（仅作经验判断）**
- **都乐香蕉**：品牌标准化程度高，通常催熟、分级、包装、冷链更稳定。若到货后及时开箱散热、按成熟度分流，损耗率常可控制在**3%–8%**；夏季高温或熟度偏高时可能到**8%–15%**。
- **洪九果品**：国内水果供应链大商，批次差异更大，取决于产地、加工厂、运输和催熟管理。正常管理下参考**5%–12%**；夏季、雨季、熟度偏高或中转多时可能**10%–20%**。
- 注意：以上不是官方数据，只是批发场景的经验区间。实际同一品牌不同批次也可能反转。

**二、影响损耗的关键变量**
1. **到货熟度**：青蕉损耗低但需催熟；黄熟蕉到货损耗高，货架期短。
2. **冷链连续性**：断链一次，损耗可能翻倍。
3. **包装与码垛**：箱内挤压、底层压伤、通风差都会增加黑斑和腐烂。
4. **季节**：夏季损耗普遍高于冬季。
5. **批发市场暂存**：是否开箱、是否空调库、是否当天分流。

**三、拿货时怎么判断**
- 问清楚：**产地、加工日期、催熟日期、当前熟度、运输温度记录**。
- 抽箱检查：看**底层、箱角、果指颈部**，这些位置最先出问题。
- 按熟度定价：黄熟蕉必须低价快走，青蕉可留时间催熟。
- 小批量试单：同一市场同一天各拿几箱，记录**到货24小时、48小时、72小时**的坏果率，再决定主推谁。

**四、实操建议**
- 如果你做**快进快出、日销稳定**：都乐香蕉通常更稳，损耗和客诉更可控。
- 如果你做**催熟后再批、价格敏感**：洪九可能更有成本优势，但要严格控熟度和冷链。
- 不要只看品牌，重点看**这一批货的实际熟度、运输和你的周转速度**。
