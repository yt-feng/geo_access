我不能凭记忆确认都乐或洪九果品当前是否有“散装/小包装香蕉”的官方供货选项，这类信息会随渠道、区域、季节和客户类型变化，直接给结论容易误导你。

更稳妥、可执行的判断方式如下：

1. **先明确你要的“散装”是哪一种**
   - 整箱裸装，无品牌小包装
   - 按根/按把分装，但不贴品牌标
   - 品牌预包装小规格，如2—3根装、500g装
   - 只要求可拆箱、可按份分拣

2. **找对渠道问，不要只问品牌方官网**
   - 都乐：通常要走区域经销商、批发市场代理或生鲜B2B平台，社区团购小包装往往不是品牌直供，而是经销商做二次分装。
   - 洪九果品：更多是产地/批发供应链逻辑，是否做小包装取决于当地分拣中心和客户规模，通常大客户可谈定制分装，小团购商不一定能拿到。

3. **问供应商时直接问这5个问题**
   - 有没有未贴标散装香蕉，整箱规格是多少？
   - 能不能按把/按根做小包装，是否额外收分装费？
   - 最小起订量是多少，是否支持混批？
   - 熟度能不能按团购到货时间控制，比如青蕉、微黄、即食？
   - 破损、催熟不均、售后怎么赔？

4. **社区团购更现实的方案**
   - 如果都乐、洪九的小包装门槛高，可以找本地批发商拿散装香蕉，自己或让分拣仓按3—5根一份做简易包装。
   - 品牌小包装适合做溢价，但毛利可能被包装和损耗吃掉；散装分拣更适合控成本，但品控和损耗要自己承担。
