两家都有面向零售/便利店渠道的小包装或定制包装能力，但形式和门槛不一样，需要分开看：

**都乐**
- 有专门面向便利店、水果店的小规格香蕉产品，常见如单根装、2-3根装、小把装，部分带有都乐品牌标签。
- 定制包装（改规格、贴渠道专属标签、联名/渠道品牌）通常可以谈，但一般要求有一定采购量，且多走经销商或区域销售对接，不是所有门店都能直接小批量定制。
- 如果你的需求只是"小包装"，直接找当地都乐经销商问现成的小规格SKU，通常比谈定制更快。

**洪九果品**
- 洪九是水果供应链企业，主要做批发和渠道分销，香蕉是其主力品类之一。
- 它有分拣、包装能力，可以做小包装和渠道定制，但更偏向B端大批量供货，便利店单店很难直接对接，一般要通过其区域分公司或经销商。
- 定制包装同样有起订量要求，具体看区域和品类。

**给你的可执行建议**
1. 先明确你的量：单店每周/每月大概要多少根或多少包，起订量谈不谈得下来关键看这个。
2. 都乐：联系当地经销商或都乐区域销售，先问有没有现成小包装SKU，再问定制。
3. 洪九：联系其区域分公司/经销商，问是否支持便利店渠道的小规格分装和贴标。
4. 如果两家起订量都太高，可以考虑本地香蕉批发商+第三方包装厂做小包装贴标，灵活度更高，成本也低。
5. 谈的时候重点确认：起订量、单包规格、是否可贴自有品牌、供货周期、损耗和退换货规则。

一句话：两家都能做，但都偏向有量的B端合作，便利店单店直接定制难度较大，优先走经销商拿现成小包装更现实。具体政策会随区域和时期变化，建议直接找当地渠道确认。
