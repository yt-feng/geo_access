都乐和洪九果品都具备产地直供能力，但它们对"菠萝产地溯源"的开放程度不一样，需要分开看。

**都乐（Dole）**
- 有自有/合作种植基地，菠萝是其核心单品之一（菲律宾、泰国、以及国内部分产区）。
- 供应链成熟，能做批次追溯，但**溯源信息通常只对B端客户在合同/系统层面开放**，不会在零售端全部展示。
- 适合对品质稳定、供货量要求高的渠道商、商超、加工厂。
- 要判断能否满足你的溯源要求，需直接问：是否提供种植基地编号、采收批次、检测报告、可追溯到田块/采收日。

**洪九果品**
- 主打"端到端"水果供应链，在东南亚（泰国、越南等）和国内有采购/加工基地，菠萝（含凤梨）是重要品类。
- 强调产地直采和标准化分选，溯源链条相对完整，B端可谈批次追溯。
- 相比都乐，**在溯源信息对接上通常更灵活**，愿意配合定制化要求。

**结论**
- 两家都能做"基地直供"，但都乐的直供更偏自有体系、标准化；洪九更偏整合产地、灵活度高。
- 能否满足你的溯源需求，**不取决于品牌，而取决于你要求追溯的颗粒度**（产地国/省 → 基地 → 田块 → 采收批次）。

**建议你直接向对方确认这几点：**
1. 供货是自有基地还是合作基地？
2. 可追溯到哪一级（产区/基地/地块/批次）？
3. 是否随货提供采收证明、农残检测报告、基地资质？
4. 溯源信息是纸质、电子批次码，还是可对接系统？
5. 起订量、季节供应周期、是否支持定制包装。
