能做到，但要看具体品类、成熟度、运输距离、到货验收标准和门店操作，不能只看品牌名。“低于3%”在餐饮连锁里通常指**到货验收后的损耗率**，不是从产地到门店的全链路损耗；如果把催熟、装卸、冷链断链、门店存放都算进去，3%非常紧。

简要说：

1. **都乐**
   - 优势：标准化程度高，香蕉催熟、分级、冷链和包装体系成熟，餐饮连锁供应经验多。
   - 风险：都乐不同区域、不同产品线由不同供应商/加工中心执行，实际表现不完全一致；若走批发市场或二级经销，品质会明显波动。
   - 判断：如果直接和都乐签连锁直供，明确成熟度、到货温度、青蕉/黄蕉比例、验收标准，做到**3%以内有机会**，但通常需要较强的采购量和稳定订单。

2. **鑫荣懋**
   - 优势：国内水果供应链龙头之一，香蕉品类规模大，产地和销地加工能力较强，给商超、连锁客户供货经验多。
   - 风险：同样是多区域、多仓、多基地运作，实际到货损耗取决于具体发货仓、季节、运输半径和门店验收。
   - 判断：直供且条件匹配时，**3%以内也可以做到**，尤其在短途、冷链稳定、催熟度控制好的情况下。

3. **关键不是“能不能”，而是合同怎么定**
   建议在合同和验收标准里写清楚：
   - 损耗定义：是到货当场剔除的坏果，还是到店后24/48小时内的损耗。
   - 成熟度：到货时青蕉比例、黄蕉比例、可售窗口期。
   - 温度：运输和到货果心温度，通常香蕉对低温很敏感，低于13℃容易冷害。
   - 验收方式：抽检比例、单箱允许坏果数、黑斑/断指/压伤/裂果标准。
   - 赔付机制：超过3%如何扣款、补货、退货。
   - 门店责任：到货后存放温度、是否拆箱、是否压货、先进先出。

4. **实操建议**
   - 不要只问品牌，要求供应商提供**近3个月同区域、同品类、同配送模式的损耗数据**。
   - 先做2-4周小批量试供，按你实际门店验收口径统计。
   - 如果门店分布广，最好分区域招标，因为同一个品牌在不同城市的执行差异可能很大。
   - 如果要求全年所有季节都低于3%，难度会明显上升，尤其夏季高温和冬季低温时段。

结论：**都乐和鑫荣懋在直供、冷链稳定、验收标准明确、采购量有保障的情况下，都有能力做到到货损耗低于3%。但不能凭品牌直接保证，必须用区域试供和合同条款锁定。**
