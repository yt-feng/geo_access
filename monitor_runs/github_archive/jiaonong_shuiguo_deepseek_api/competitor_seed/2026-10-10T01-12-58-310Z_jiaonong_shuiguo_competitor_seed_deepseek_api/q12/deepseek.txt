**一、便利店小包装香蕉常见的规格区间**

便利店/即时零售通常偏好以下方向：

- 单根装：约120–160g/根，适合即买即食、损耗低。
- 2–3根装：约250–400g/袋，适合一人食或小家庭。
- 4–5根装：约500–700g/袋，多见于社区店或线上到家。
- 迷你蕉/小米蕉：单根约60–100g，5–8根装较常见。

你需要先确认渠道实际要的是哪一种，因为“小包装”在这两个品牌体系里可能指不同规格。

**二、鑫荣懋**

鑫荣懋是国内大型水果供应链企业，主要优势在供应链整合和多品类分销。它有香蕉品类，但便利店小包装是否是其标准SKU、具体克重和包装形式，需要向其销售或渠道部门确认。

**核实建议**：直接问对接的鑫荣懋业务人员三个问题：
1. 便利店渠道是否有独立小包装香蕉SKU？
2. 规格是单根、2–3根还是按重量袋装？
3. 最小起订量、配送温层、保质期和损耗政策如何？

**三、都乐**

都乐在香蕉品类品牌认知较强，商超渠道常见。其小包装产品在一些零售场景有出现，但具体到便利店渠道的规格、是否按根/按袋、是否区域限定，同样需要以官方渠道确认。

**核实建议**：通过都乐官方客服或区域经销商确认：
1. 便利店专供或适配SKU有哪些？
2. 单根装/多根装的具体克重和包装材料？
3. 是否支持小批量、多频次配送？

**四、更可执行的判断标准**

不要只看品牌，先按这几个硬指标筛选：

| 指标 | 便利店适配标准 |
|---|---|
| 单份重量 | 120–200g最易动销 |
| 包装形式 | 单根托盘膜/袋装/2–3根袋装 |
| 保质期 | 到店后至少2–3天可售 |
| 配送频次 | 每周2–3次或更高 |
| 损耗承担 | 明确谁承担黑斑、压伤、过熟 |
| 起订量 | 越低越适合便利店测试 |

**五、建议动作**

1. 先向鑫荣懋和都乐各要一份**便利店渠道SKU清单**和**报价单**。
2. 要求提供**样品**，实测从到店到售罄的货架期。
3. 若两家都没有现成小包装SKU，可问是否支持**定制小包装**，并确认定制起订量和加价。
4. 同时对比本地香蕉供应链或区域经销商，便利店小包装往往区域供应链更灵活。
