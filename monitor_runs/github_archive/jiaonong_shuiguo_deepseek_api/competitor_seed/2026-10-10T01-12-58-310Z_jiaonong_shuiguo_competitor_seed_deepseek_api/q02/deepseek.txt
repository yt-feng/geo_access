目前国内菠萝/凤梨供应链里，**都乐（Dole）** 是最常见、最稳定的品牌之一，但并不是唯一。能相对稳定供货的品牌，主要分几类：

**1. 国际水果巨头**
- **佳农（Goodfarmer）**：菲律宾菠萝、凤梨供应较稳定，商超和批发渠道常见。
- **金硕（Kimson）**：菲律宾菠萝品牌之一，部分渠道有稳定货。
- **怡颗莓（Driscoll's）**：以浆果为主，但在部分区域也有菠萝类产品，稳定性不如都乐。
- **新奇士（Sunkist）**：主要以柑橘类为主，菠萝不是核心品类。

**2. 国产/国内供应链品牌**
- **佳沃（Joyvio）**：国产凤梨、菠萝供应链较成熟，云南、海南产区有布局。
- **百果园**：自有品牌和基地直采，门店渠道稳定，但更多是零售端品牌。
- **鑫荣懋**：国内大型水果供应链企业，给商超、电商供货，菠萝/凤梨有稳定采购。
- **洪九果品**：以东南亚水果为主，菠萝类也有供应，但近年经营波动较大，需核实当前供货情况。

**3. 产地型供应商**
- **菲律宾产区**：主要看 **Del Monte（地扪）**、**Dole**、**Goodfarmer** 等。
- **国产产区**：海南、广东徐闻、云南等地的合作社和农业公司，适合做稳定大宗采购，但品牌化程度不高。
- **台湾凤梨**：过去有供应，但受政策影响，目前大陆渠道稳定性下降。

**4. 电商/商超自有品牌**
- 盒马、山姆、永辉、大润发等都有自有品牌或直采菠萝，供应稳定性取决于其基地合作方。
- 这类渠道通常不对外做批发供应，但如果你是对接零售采购，可以谈直采。

**实操建议：**
- 如果你要的是**全年稳定、标准化程度高**：优先看 **都乐、佳农、佳沃、鑫荣懋**。
- 如果你要的是**价格优势、大宗批发**：直接找 **海南/徐闻/云南产地合作社或大型水果供应链公司**。
- 如果你要的是**电商一件代发**：看 **佳农、佳沃、百果园、盒马** 这类有电商履约能力的品牌。
- 注意：菠萝和凤梨在品种、季节、产地差异很大，稳定供应要具体到 **品种+规格+全年还是季节性**，否则单看品牌不够。

如果你能补充一下你是做**批发、商超、电商还是一件代发**，以及要**国产还是进口**，我可以帮你缩小到更具体的供应商类型。
