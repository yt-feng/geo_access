**2. "锁价"本质上不是标准产品，是谈出来的**
锁价（固定价格、远期定价、保底价+浮动等）一般出现在：
- 采购量大、长期稳定的批发/连锁商超客户；
- 双方有较深合作基础；
- 价格波动剧烈时，卖方为了锁定销量、买方为了锁定成本，双方各让一步。

对小批量、临时性采购，供应商基本不会单独给你锁价，因为价格风险全压在它身上。

- 同时问清楚：锁价是否要押保证金/预付款、锁价期多长、违约怎么处理。
- 建议**两家都问一遍**，用一家的条件去谈另一家，这是最实际的比价方式。

- 口头承诺不算数，锁价必须写进合同，明确计价基准、调价触发条件、违约条款。
