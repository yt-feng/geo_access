就**公开、稳定可查的香蕉商品规格分级**而言，通常 **都乐（Dole）的分级更细、更标准化**，但“谁更细”要看你说的“分级”指哪一层：

1. **零售端商品规格**
   - **都乐**：常见会按“单根重量/整把重量/果指长度/成熟度/包装规格”做较清晰标注，例如不同克重区间、不同把型、不同熟度。
   - **鑫荣懋**：也有分级，但更多体现在渠道供货标准、客户定制标准里，公开零售端不一定像都乐那样统一展示得很细。

2. **供应链/采购端分级**
   - 两家都会按**果指长度、粗度、每梳果指数、整串重量、色泽、成熟度、机械伤、病斑、青黄比例**等做分级。
   - 如果是对接商超、电商、批发市场，**鑫荣懋往往可按渠道要求做定制化分级**，实际执行细则可能不比都乐少，甚至更贴合国内渠道。
   - 但如果是看**公开可复制的标准体系**，都乐通常更统一、更容易按规格采购。

3. **采购判断建议**
   - 你要做超市采购，不要只问“谁分得更细”，而要看：
     - 是否能提供**书面分级标准**；
     - 是否能按**单根重、果指长、每把根数、成熟度**分档；
     - 是否能稳定供货同一规格；
     - 是否接受**到货抽检和退换货标准**。
   - 如果超市面向高端客群，倾向选**都乐体系**，规格一致性更强。
   - 如果面向国内大众商超、需要灵活定制，**鑫荣懋**可能更适配，但必须把分级标准写进采购合同。

**结论**：  
**看公开标准，都乐更细、更统一；看国内渠道定制，鑫荣懋可以做到很细，甚至更灵活。**  
如果你是超市采购，建议让两家分别提供“香蕉规格分级表+到货验收标准”，再比谁更适合你的货架和客群。
