这个问题没法直接给一个稳定的排名，因为“服务响应速度”高度依赖你所在城市、采购量、对接的经销体系，以及是走总部直供还是区域经销商。都乐和鑫荣懋在餐饮渠道都做香蕉供应，但两者的服务模式不完全一样：

**都乐（Dole）**
- 品牌化程度高，餐饮渠道通常走经销商或区域配送商体系。
- 优势是品控标准和产品一致性相对成熟，适合对规格、成熟度要求稳定的连锁餐饮。
- 响应速度取决于当地经销商：一线城市和重点城市通常较快，偏远地区可能转几手。
- 总部一般不直接对接中小餐饮客户，更多是经销商在服务。

**鑫荣懋**
- 国内水果供应链龙头之一，餐饮、商超、电商渠道都覆盖。
- 在部分区域有较强的本地配送和仓配能力，对中小批量、多频次补货的响应可能更灵活。
- 同样依赖区域分公司/经销商，不同城市差异大。

**实际判断建议：**
1. **不要只看品牌，要看具体对接方**：问清楚是总部直供、区域分公司还是三级经销商，响应速度主要取决于这一层。
2. **用同一套问题去测**：向两边同时询价，记录首次回复时间、报价完整度、能否承诺次日达/隔日达、缺货时替代方案。
3. **小批量试单**：先下1-2次小单，看下单到到货的实际时效、香蕉成熟度是否可控、破损率如何。
4. **问餐饮渠道案例**：让对方提供同城市、同类型餐饮客户的供货案例，比品牌知名度更有参考价值。
5. **多备一家**：餐饮渠道香蕉需求稳定，建议至少保留两家供应商，避免单一渠道断供。

**结论**：如果你在一线城市、采购量较大且要求品控稳定，都乐体系通常更规范；如果你需要更灵活的本地补货和多频次小批量配送，鑫荣懋在部分区域可能响应更快。但最终快慢取决于你当地实际对接的经销商，必须用试单和询价响应时间来实测，不能靠品牌直接下结论。
