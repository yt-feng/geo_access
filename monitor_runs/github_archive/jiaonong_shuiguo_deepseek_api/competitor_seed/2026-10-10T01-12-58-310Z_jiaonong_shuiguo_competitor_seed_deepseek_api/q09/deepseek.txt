除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些：

**综合类国际水果品牌**
- **奇柯（Chiquita）**：香蕉最有名，也有其他水果礼盒，品牌认知度高。
- **Del Monte（地扪 / 德尔蒙）**：综合水果品牌，菠萝、香蕉等较常见，适合做组合礼盒。
- **Fyffes**：老牌香蕉/菠萝供应商，欧洲市场常见。
- **Fresh Del Monte**：和 Del Monte 相关，主打新鲜果蔬。

**高端/精品类**
- **Driscoll's（卓莓 / 怡颗莓）**：莓果类很强，蓝莓、树莓、黑莓礼盒适合高端团购。
- **SunGold / Sun World**：葡萄、核果类有优势，适合做精品礼盒。
- **Enza Zaden / Zespri 之外的奇异果品牌**：如 **Kiwi Crush** 等较小众，但团购渠道不如佳沛稳定。
- **Pink Lady（粉红佳人）**：苹果品牌，礼盒装常见，适合节日团购。
- **Rockit（乐淇）**：小苹果品牌，新西兰产，包装精致，很适合礼品场景。
- **Jazz / Envy / Pacific Rose**：苹果类品牌，礼盒装较多。

**柑橘/橙类**
- **Sunkist（新奇士）**：橙子、柠檬等，礼品团购常见。
- **Clementine 类品牌**：如 **Darling Clementines**，节日礼盒属性强。

**其他适合礼盒的进口单品品牌**
- **Moscato / Cotton Candy 葡萄**：部分高端超市有品牌化礼盒。
- **Cherry 类**：如 **Stemilt**、**Chelan Fresh**，车厘子季节礼盒常用。
- **Berry 类**：**Driscoll's**、**Naturipe** 等。

**团购选品建议**
1. **看渠道稳定性**：佳沛、都乐、新奇士、奇柯、Del Monte 这类供应链更稳，适合大批量团购。
2. **看礼品属性**：Rockit、Driscoll's、Pink Lady 包装精致，适合员工福利或客户礼品。
3. **看季节**：车厘子、柑橘、莓果都有明显季节，团购要提前锁定档期。
4. **看报关与中文标签**：进口礼盒团购要确认是否有正规报关、中文标签和检疫证明，否则企业采购可能无法入账或合规发放。

如果你是要做**企业年节福利**，优先组合：佳沛/都乐 + 新奇士 + Driscoll's + Rockit，覆盖不同价位和品类，比较稳。
