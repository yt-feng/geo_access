关于都乐和洪九果品的菠萝供应基地，可以按以下实际情况判断：

**都乐**
都乐在菠萝领域的主要优势是菲律宾都乐（Dole Philippines）自有/合作农场，产地集中在菲律宾南部棉兰老岛一带（如南达沃、北哥打巴托等区域），品种以MD-2金菠萝为主。国内销售的都乐菠萝不少来自菲律宾进口，也有部分国内合作基地，但都乐在中国本土并没有像“自建万亩菠萝园”那样广为人知的单一基地。做茶饮原料，重点应确认：是菲律宾进口果还是国内分装/催熟，规格、糖度、到货稳定性差异较大。

**洪九果品**
洪九果品是做进口水果和国产水果分销的供应链企业，菠萝/凤梨主要来自：
- 菲律宾进口：与都乐类似，走进口渠道；
- 国内产地：广东徐闻、海南、云南等地也有布局或采购。
洪九的优势在分销网络和渠道整合，不一定是单一自有种植基地。茶饮采购若找洪九，通常谈的是稳定代采、分选、仓配和跨区域调货能力。

**给茶饮采购的可执行建议**
1. 先明确要的是“菠萝果肉/果块/果酱/冷冻果泥”哪种原料，不同形态对应不同供应链。
2. 要稳定供应，优先找：菲律宾进口商 + 国内徐闻/海南产地商双渠道备份，避免单一产地季节断供。
3. 直接向都乐、洪九索要：
   - 产地证明/报关单；
   - 近3个月到货批次和糖度检测；
   - 最小起订量、锁价周期、账期；
   - 是否支持定制规格（切块、冷冻、糖度分级）。
4. 如果用量大，建议同时接触徐闻本地菠萝合作社和冷冻果泥厂，成本通常比品牌果商更低，但需要自己控品控。

简单说：都乐基地核心在菲律宾棉兰老岛；洪九更多是渠道商，菠萝来源包括菲律宾和国内徐闻、海南等产地，不宜简单理解为单一自有基地。
