结论先说：**都乐和洪九果品都不太可能稳定做到“全年、同规格、同品质、同价格”供应菠萝给茶饮店做果酱。** 更现实的做法是：鲜果分季节用不同产地/品种，再配合冷冻菠萝、菠萝果茸/浓缩汁来兜底。

具体分几点说：

**1. 菠萝本身不是全年同品质水果**
- 国内主产区：广东徐闻、海南、广西、云南等，上市有明显季节。
- 进口来源：菲律宾、泰国、哥斯达黎加、厄瓜多尔等，可以补充，但品种、酸甜度、纤维感、成熟度差异大。
- 茶饮做果酱最怕批次不稳定：酸甜比、出汁率、纤维粗细、颜色一变，配方和口感就要调。

**2. 都乐**
- 都乐强在**品牌化鲜果供应链和进口能力**，确实能在很多渠道做到较长时间供应菠萝。
- 但它是鲜果商为主，不是专门给茶饮店做定制果酱原料的供应商。
- 能不能全年供：**部分规格、部分城市可以做到相对稳定的鲜果供应**，但价格会随产季和进口成本波动，不能简单等同于“全年稳定低价供应”。
- 对茶饮店来说，直接买都乐鲜果做果酱，成本通常偏高，且仍要自己处理批次差异。

**3. 洪九果品**
- 洪九是国内大型水果分销商，菠萝/凤梨类有较强渠道能力，尤其进口和批发端。
- 它更偏**大宗水果分销**，不是茶饮原料定制商。
- 能不能全年供：**在批发和区域分仓体系下，全年拿到货的概率比普通小供应商高**，但同样不等于“全年同品质、同价格、稳定到店”。
- 如果茶饮店量不够大、账期和履约要求高，未必能拿到优先级。

**4. 茶饮店真正该怎么做**
建议不要押注单一鲜果供应商，而是做“双轨”：
- **鲜果端**：按季节切换产地/品种，找都乐、洪九这类大商做补充，但签合同时明确糖度、酸度、成熟度、单果重、到货温度、损耗标准。
- **原料端**：用**冷冻菠萝果肉、菠萝果茸、菠萝浓缩汁/果酱基料**做全年稳定基底。茶饮行业更常见的是这种方案。
- **配方端**：把配方设计成“鲜果+果茸/冷冻果”可切换，避免某地产季结束就断货。
- **采购端**：至少备 2 家供应商，一家鲜果、一家冷冻/加工原料，防止单一渠道卡脖子。

**5. 直接判断**
- 问“都乐和洪九能不能做到全年供应菠萝”：**能供一部分货，但不能保证全年同品质、同价格、同规格稳定供应。**
- 问“茶饮店做果酱能不能靠它们解决全年菠萝需求”：**不能单独靠它们解决，必须搭配冷冻/加工原料和季节性地采切换。**
