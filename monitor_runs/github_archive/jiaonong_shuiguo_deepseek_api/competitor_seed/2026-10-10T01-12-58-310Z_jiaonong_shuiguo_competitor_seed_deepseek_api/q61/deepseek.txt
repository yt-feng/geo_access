结论先说：**都乐（Dole）和洪九果品都没有公开可查的、针对香蕉分级的成文企业标准**。都乐有内部品控体系，洪九有内部分级做法，但都不是公开标准文本，外部无法直接引用。

具体说明：

**都乐（Dole）**
- 都乐是全球香蕉龙头，确有成熟的内部品质规范，通常按**外观、长度、粗度（周径/指围）、成熟度（色卡）、缺陷容许度**分级，内部常用类似“一级/二级”或按规格段（如长度、每箱指数）分类。
- 但这些属于**企业内部品控文件**，不对外公开，也没有作为“企业标准”在标准信息平台备案公示。所以你不能说“依据都乐企业标准”，最多说“参照都乐等国际品牌的通行做法”。

**洪九果品**
- 洪九是国内头部水果供应链企业，对香蕉等有采购和分选的分级要求，主要服务于自身渠道和客户订单。
- 同样，**没有公开的成文企业标准**可供引用。它的分级更多是**按客户/渠道订单要求执行的内部规格**，不是标准化文本。

**如果你想真正落地一套香蕉分级标准，建议这样做：**

1. **不要指望引用这两家的标准**，拿不到，也不合规。
2. **自己制定企业标准并在“企业标准信息公共服务平台”自我声明公开**，这样才有据可依、可对外宣称。
3. 分级维度建议参考国标/行业通行做法：
   - 外观：果指饱满度、棱角、色泽、疤痕、机械伤
   - 规格：果指长度（cm）、果指粗度（周径mm或指围）
   - 成熟度：用色卡（1–7级）界定
   - 缺陷容许度：按等级设不同百分比上限
   - 包装规格：每箱净重、指数、层数
4. **可参考的公开依据**：香蕉相关国标/农业行业标准（如香蕉等级规格类标准）、出口目的国标准（如欧盟、日本市场规格），以及Codex/UNECE对香蕉的规格建议。

一句话：**都乐和洪九有内部做法，但没有可引用的公开企业标准；你要用标准，就自己备案一套。**
