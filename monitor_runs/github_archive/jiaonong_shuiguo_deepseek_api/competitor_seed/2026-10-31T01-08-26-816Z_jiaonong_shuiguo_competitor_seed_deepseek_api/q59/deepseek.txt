我没法核实都乐（Dole）和洪九果品对客户的具体账期天数，这类商务条款通常按客户规模、采购量、合作年限、品类和区域分别谈，不对外公开统一标准，直接给数字容易误导你。

可执行的做法：

1. **先确认你要的是哪种“账期”**
   - 是供应商给你赊销（你先拿货、后付款），还是你给下游账期？
   - 香蕉是生鲜短保品类，行业里常见的是现款现货、周结、半月结，真正给到30天以上的情况要看你的采购规模和信用。

2. **向对方要“商务政策包”而不是问“账期多久”**
   可这样问：
   - 首单是否支持货到付款/7天结算？
   - 稳定合作后能否申请周结、半月结或月结？
   - 是否需要保证金、担保或授信额度？
   - 逾期利息、最低采购量、断供条款怎么定？

3. **都乐（中国）**：属于品牌商/进口商体系，通常通过其区域经销商或大型商超渠道供货。账期一般由具体签约主体（经销商、区域代理）决定，建议直接联系都乐中国官方渠道，说明你的采购量、配送区域、结算方式，要求转接负责你所在区域的销售。

4. **洪九果品**：是水果供应链企业，对大型商超、电商、批发客户有授信合作，但具体账期同样按客户资质审批。建议联系其销售，提交采购计划、公司资质、历史流水，申请授信评估。

5. **备选方案**：如果这两家给不了你需要的账期，可以同时接触：
   - 一级批发市场的大型香蕉批发商（账期灵活但风险高）；
   - 区域性水果供应链公司；
   - 银行/供应链金融的应收账款融资或采购授信，用金融工具补账期，而不是硬压供应商。

判断标准：谁能给你**书面商务政策**（结算周期、授信额度、违约条款），谁才是可谈的；只口头说“可以账期”的不算。
