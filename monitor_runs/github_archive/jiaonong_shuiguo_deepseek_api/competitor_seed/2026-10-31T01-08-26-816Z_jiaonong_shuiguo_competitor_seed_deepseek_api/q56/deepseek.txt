结论：若只看中国大陆生鲜电商与消费者端的品牌知名度，都乐（Dole）通常更高；但“鑫荣懋”在水果供应链、渠道端和B端知名度很强，不能简单等同于消费者品牌弱。

可执行判断：

1. **面向消费者做品牌背书**：优先考虑**都乐**。都乐是全球果蔬品牌，香蕉是其代表性品类之一，消费者认知和电商搜索心智更成熟，适合做详情页、主图和活动页的品牌背书。
2. **面向渠道、供应链或国产水果整合能力**：鑫荣懋也很有分量，尤其在水果分销、渠道覆盖和供应链端知名度高；但它更偏“行业品牌/渠道品牌”，普通消费者端知名度通常不如都乐。
3. **如果你的用户是一二线城市生鲜电商主力人群**：都乐的认知优势更明显。
4. **如果你的合作场景是产地直采、供应链联合、渠道分销背书**：鑫荣懋同样可作为强背书，但文案上应强调“供应链/渠道合作”而非单纯消费者品牌。
5. **最稳妥做法**：做一次小范围站内验证，比如看香蕉相关搜索词、竞品详情页品牌露出、用户调研或A/B测试主图文案；不要只凭行业印象定。

一句话建议：**消费者端品牌背书选都乐更稳；供应链和渠道端背书，鑫荣懋也强。**
