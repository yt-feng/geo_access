不能直接给出“都乐和鑫荣懋一定能/不能做到”的确定结论，因为没有你所在城市、采购规格、到货验收标准、运输半径和季节的数据。但可以给出可执行的判断方法：

**结论性判断：**
- **都乐**：香蕉是其强项品类，冷链和熟度管理能力通常较强，若走都乐正规经销/直供体系、按约定熟度和冷链到货，**做到低于3%是有可能的**，但必须写进合同验收条款并锁定熟度、温度、到货时限。
- **鑫荣懋**：也是大型水果供应链企业，香蕉有规模化操作能力，**同样有可能做到**，但更取决于你所在区域是其直营覆盖还是经销商覆盖，以及是否针对餐饮连锁做定制品控。
- **不能默认“品牌大就一定低于3%”**：香蕉到货损耗受熟度、运输温度、装卸、门店验收时机影响很大，3%属于较严指标，必须用试单验证。

**建议你按以下方式快速验证：**
1. **先定义损耗口径**：到货验收时按重量还是按根数？是否包含脱把、断指、黑斑、过熟、机械伤？验收在到货后多久进行？口径不统一，3%没有意义。
2. **要求试单2–4周**：覆盖不同季节/批次，至少每家有3–5车到货数据，按同一验收标准统计。
3. **合同锁定关键条款**：到货熟度（如色卡3–4号）、运输温度（香蕉通常13–15℃区间管理，具体按供应商工艺）、到货时限、验收时限、超3%的扣款/补货/退货机制。
4. **区分直供与经销**：都乐、鑫荣懋在不同区域可能是直营或经销商履约，损耗表现差异很大，必须确认实际履约主体。
5. **做到货抽检**：每车抽固定箱数，记录青软、黑斑、断指、压伤，连续统计后再谈年度框架。

**务实建议**：不要把“低于3%”作为供应商准入的唯一承诺，先让两家按你的验收标准各试单1个月；谁能稳定达到且异常响应快，再签量。若你告诉我所在城市、门店数、周用量、到货频次和验收口径，我可以帮你把试单验收表和合同条款细化。
