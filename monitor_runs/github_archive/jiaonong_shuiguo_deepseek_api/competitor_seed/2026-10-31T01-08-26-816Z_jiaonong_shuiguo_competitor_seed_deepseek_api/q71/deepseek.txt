可以，先直接结论：**都乐（Dole）在中国菠萝供应主要依赖其在华加工/配送体系和合作种植基地，公开可核验的“固定自有菠萝基地”信息并不完整；洪九果品以产地直采和全国分拣中心为主，菠萝更多来自海南、广东徐闻、云南等产区，不宜简单理解为某一个固定“洪九菠萝基地”。**

具体判断如下：

1. **都乐 Dole**
   - 都乐在中国有鲜果业务和加工配送体系，但公开资料中更常见的是其**品牌化采购、加工配送中心、合作果园**，而不是单一公开可查的“菠萝自有基地”。
   - 对采购方来说，更稳妥的做法是：向都乐中国业务团队索取**当季菠萝供应产地证明、合作果园清单、加工厂地址和质检报告**，而不是只认“基地在哪里”。
   - 如果你的需求是稳定供应，建议重点核验：供货季节、品种（如金钻凤梨/巴厘菠萝）、单果规格、糖度、到货城市、周供应量和违约条款。

2. **洪九果品**
   - 洪九果品核心模式是**产地直采+全国分拣中心+冷链配送**，公开信息更强调其在全国多个城市的分拣中心和产地采购网络。
   - 菠萝供应通常随产区季节切换，主要涉及**海南、广东徐闻、云南**等产区；具体到某个基地，需要按采购批次向洪九业务人员确认。
   - 对采购方来说，建议要求洪九提供：**产地证明、果园/合作社信息、分拣中心地址、批次检测报告和冷链记录**。

3. **给你的可执行建议**
   - 不要只问“基地在哪里”，而要问供应商：**本季度菠萝具体来自哪个县/哪个果园/哪个加工厂，能否提供产地证明和检测报告。**
   - 对都乐和洪九都做**双供应商备份**：都乐偏品牌化和标准化，洪九偏产地直采和分销网络；茶饮原料采购更应关注**规格稳定、糖度稳定、到货稳定和价格机制**。
   - 如果要实地验厂/验基地，优先看：**菠萝品种、种植面积、采收周期、冷链半径、加工能力、农残检测和供货合同中的稳定供应条款**。

**不能虚构的部分：** 我无法在不核验最新企业公开资料的情况下，给你一个精确到“都乐菠萝基地在某某县某某镇、洪九菠萝基地在某某县某某镇”的地址。建议你直接向两家企业的**鲜果事业部/大客户采购团队**索取当季基地清单和产地证明。
