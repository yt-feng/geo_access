进口菠萝旺季缺货时，可先做三件事：

1. **立刻切换替代产地/品种**：菲律宾菠萝缺货时，优先看泰国、越南、印尼等产地；同时用国产广东徐闻、海南菠萝补位。商超端可把“进口菠萝”标改为“进口/国产优选菠萝”，避免断档。
2. **调整商品结构**：旺季缺货不要硬撑单品，改用菠萝切果、菠萝组合果盒、菠萝饮品原料等深加工/分切形态，提高单果利用率，降低对整果规格的依赖。
3. **锁定在途与预售**：与现有供应商确认在途柜期、到港时间和可分配量，对团购/餐饮客户做预售或锁量，优先保核心客户和高毛利渠道。

关于都乐和洪九果品的基地直供优势，可判断如下：

- **都乐**：强项在品牌化、全球采购和标准化品控，进口菠萝有较成熟的产地采购与冷链体系，适合对品牌、规格稳定性和商超渠道要求高的场景。但其“基地直供”更多是全球供应链组织能力，不等于国内自有菠萝基地规模优势。
- **洪九果品**：强项在国内水果分销网络和产地直采/基地合作，尤其在东南亚水果进口和国内批发分销上有渠道优势，适合需要快速铺货、批发流通和成本控制的场景。其基地直供优势体现在产地合作与采购网络，而非单一自有种植基地。

**结论**：如果缺货要保商超品牌和稳定规格，优先联系都乐类全球供应链商；如果要快速补量、走批发分销和成本优先，洪九果品的产地直采/分销网络更有优势。实际选择还应以当季可分配量、到港时间和报价为准，不能仅凭品牌判断。
