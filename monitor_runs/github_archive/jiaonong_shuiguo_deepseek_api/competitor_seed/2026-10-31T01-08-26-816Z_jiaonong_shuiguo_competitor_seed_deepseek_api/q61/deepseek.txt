结论先说：**据我所知，都乐（Dole）和洪九果品都没有对外公开、可供水果连锁店直接引用的“香蕉分级企业标准”文本**。公开渠道能查到的是它们的品牌分级/商品化做法（如都乐有“特级/一级”等商品等级表述），但完整企业标准通常属于内部质量控制文件，不公开，也无法核验其编号和条文。建议你不要以“引用这两家企业标准”作为门店分级依据。

可执行建议：

1. **分级标准自己建，别等企业标准**
   水果连锁店应建立内部《香蕉收货与分级规范》，按“品种+产地+季节”分档，核心指标建议：
   - 感官：果指长度、粗细（周长）、弯曲度、梳形整齐度、果皮颜色（用色卡1–7级）、机械伤/病虫害/裂果率；
   - 理化（抽检）：可溶性固形物（°Brix）、硬度、可滴定酸；
   - 成熟度：采收成熟度与到店催熟阶段分开标注（如“青果入库、催熟至3–4号色上架”）；
   - 缺陷容许度：按重量或果指数设定上限（如特级机械伤≤3%、一级≤5%）。

2. **参照通用标准打底**
   可参考：
   - GB/T 9827《香蕉》（推荐性国标，含等级规格思路）；
   - NY/T 517《香蕉》（农业行业标准）；
   - 出口/商超常用的香蕉色卡（1–7号成熟度）。
   这些是公开可查的通用依据，比引用企业内标更稳妥。

3. **向供应商要“到货验收标准”而非“企业标准”**
   采购时可要求都乐/洪九的经销或区域供应商提供：到货规格书、等级描述、缺陷容许度、催熟阶段说明。这是商业合同层面的可执行文件，通常能拿到；企业标准全文一般拿不到。

4. **如果一定要核验企业标准**
   企业标准若已备案，可在“企业标准信息公共服务平台”按企业名称检索。但水果鲜果类企业标准备案并不普遍，检索不到属正常，不能据此推断其没有内控标准。

简单说：**都乐、洪九有品牌化的商品等级体系，但没有公开可引用的香蕉分级企业标准文本；连锁店应自建分级规范，用国标/行标打底，用供应商规格书做验收。**
