直接结论：如果做菠萝产地直发，都乐和鑫荣懋都具备全国化冷链能力，但“谁更快”取决于你指的发货地、目的城市、是否走其仓配体系，以及是用他们的标准物流还是你自提/自配送。没有实时线路报价和仓网路由表，不能可靠地给出具体时效小时数或“几天达”的硬结论。

可执行的判断方法：

1. 先锁定产地与销地
   - 菠萝主产区常见广东徐闻、海南、广西等；产地直发时效受“产地仓→干线→销地分拨→末端”影响，不同线路差异很大。
   - 让两家分别报：发货地、目的城市、起订量、整车/零担、温层要求、是否含末端配送。

2. 用同一口径向两家要时效承诺
   让都乐和鑫荣懋分别提供：
   - 产地装车到销地分拨的干线时效；
   - 分拨到门店/前置仓的支线时效；
   - 截单时间、每日发车频次；
   - 是否全程冷链、温度记录是否可追溯；
   - 破损/延迟赔付标准。
   要求按你实际的目的城市给“承诺时效+历史履约率”，不要只看宣传口径。

3. 小批量试单验证
   选一个目的城市，各发1—2车或1—2批零担，记录：装车时间、到达分拨时间、末端签收时间、温差记录、破损率。连续跑2—3周再比较，比问“时效如何”更可靠。

4. 注意两家模式差异
   - 都乐：品牌方+冷链体系较成熟，适合对品牌、品质稳定性和全国商超渠道有要求的订单；但产地直发的具体线路仍要按其仓网确认。
   - 鑫荣懋：水果供应链规模大、产地和销地网络较广，适合多产地、多品类组合；同样要以实际线路和仓配合同为准。
   - 两者都可能存在“自有冷链+外协承运”混合，实际时效取决于具体承运商和季节运力。

5. 菠萝品类的特殊要求
   菠萝对温度、挤压和成熟度敏感，产地直发重点不是单纯“快”，而是：
   - 采摘成熟度与预冷；
   - 装车温度与通风；
   - 是否混装、堆码方式；
   - 销地是否具备快速分拨能力。
   建议合同里写明“到货温度、最长在途时间、压伤/黑心赔付”。

简要建议：不要只问两家“物流时效如何”，而是拿你确定的产地—目的城市—批量—温层，向都乐和鑫荣懋索要线路时效承诺和近3个月履约数据，再用小批量试单验证。若你提供具体发货地、目的城市、批量（整车/零担）和是否要末端配送，我可以帮你列一份可直接发给两家的询价/时效对比表。
