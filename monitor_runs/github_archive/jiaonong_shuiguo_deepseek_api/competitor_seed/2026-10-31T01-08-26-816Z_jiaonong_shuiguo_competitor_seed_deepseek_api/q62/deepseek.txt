可以要，但不要默认“品牌方一定直接给零售采购方出报告”，要按供应商类型核实。可执行判断如下：

1. **都乐（Dole）**
   - 通常有较完善的质量与农残控制体系，但是否能给你**针对具体批次菠萝的农残检测报告**，取决于你从都乐直采、经销商还是批发市场拿货。
   - 直采/大客户渠道：可向对接销售申请**批次检测报告/COA或农残检测报告**。
   - 经销渠道：报告一般由经销商协调提供，且可能只提供**该批次或近期批次**报告，不一定能覆盖你实际收货批次。

2. **鑫荣懋**
   - 属于大型水果供应链企业，通常具备检测和品控能力，但同样要看是否直采及具体品类/批次。
   - 可要求其提供**对应批次农残检测报告**；若无法提供，至少要求**同产地、同品种、近期批次的检测报告+承诺书**，并自行抽检。

3. **采购时务必确认**
   - 报告是否**对应你收货的批次/产地/品种**；
   - 检测项目是否覆盖常见农残，检测机构是否有资质（CMA/CNAS）；
   - 报告日期是否在合理周期内；
   - 合同里写明：**随货提供批次检测报告，抽检不合格退换并承担检测费/损失**。

**结论：**都乐和鑫荣懋通常“可以谈、可以要”，但不保证任何零售/小批量采购都直接提供对应批次报告。建议下单前让两家销售书面确认：能否随货提供**该批次菠萝农残检测报告**；不能的话，要求经销商提供并约定自行送检条款。
