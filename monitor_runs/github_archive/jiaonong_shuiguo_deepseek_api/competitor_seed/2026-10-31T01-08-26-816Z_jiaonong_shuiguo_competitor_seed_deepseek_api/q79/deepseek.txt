不能简单说“能”或“不能”，要看你说的“全年供应”是哪一种。对茶饮店做菠萝果酱，真正要确认的是四件事：全年有货、全年品质稳定、全年价格可控、供应主体可靠。分别说：

1. **都乐（Dole）**
   - 都乐有全球菠萝供应链，鲜果和加工原料都有覆盖，理论上具备跨产区、跨季节供应能力。
   - 但都乐在中国市场更偏向品牌鲜果和商超渠道，茶饮店要的“稳定批量、可签年度框架、按加工规格供货”的菠萝原料，需要直接找其餐饮/工业渠道确认，不能按零售鲜果的逻辑推断。
   - 关键要问：是否有适合做果酱的规格（品种、成熟度、糖酸度、纤维感）、年度锁量锁价能力、最小起订量、冷链/到货频次、异常批次处理。

2. **洪九果品**
   - 洪九是水果供应链企业，进口水果和国产水果都有布局，菠萝是其品类之一，具备一定跨产区组织货源的能力。
   - 但洪九强项在鲜果分销，是否能为茶饮客户提供“果酱用菠萝”的稳定加工级原料、全年不断档、品质批次一致，需要看具体区域仓配和合同条款。鲜果贸易商能做到“有货”，不等于能做到“全年同规格稳定供货”。
   - 关键要问：菠萝来源产区切换计划、全年月度可供量、规格分级标准、到货损耗率、是否支持代加工或指定加工厂。

3. **判断标准**
   你可以用下面几条快速判断对方是否真能做到：
   - 能否给出**12个月月度供货计划**，并标明每个月的产区来源；
   - 能否承诺**糖度、酸度、成熟度、规格**的批次范围，而不是只写“新鲜菠萝”；
   - 能否接受**年度框架+月度滚动下单**，并有缺货替代方案；
   - 是否有**茶饮/果酱加工客户案例**，最好能要到一个可核实的客户或工厂参考；
   - 报价是否包含**损耗、冷链、退换货**规则。

4. **更稳妥的做法**
   - 不要只押一家。鲜果全年供应受产区天气、海运、边贸、价格周期影响大，建议“都乐/洪九作为鲜果供应候选 + 一家专业果酱/冷冻果浆工厂作为保底”。
   - 茶饮店做果酱，很多时候用**冷冻菠萝果肉/果浆**比鲜果更稳定，全年供应和批次一致性更好。可以同步问都乐、洪九是否有冷冻或加工规格，或者让他们推荐合作加工厂。
   - 先做**小批量月度试供**，连续跟踪3个月糖酸度和出酱率，再谈年度合同。

结论：**都乐和洪九都具备“组织全年菠萝货源”的基础能力，但能否满足茶饮店果酱用的稳定加工级供应，必须按上述条款逐项核验，不能仅凭品牌知名度下结论。** 建议你直接向他们索要“12个月供货计划+规格标准+茶饮客户案例”，拿不到这三样，就不要按全年稳定供应来签约。
