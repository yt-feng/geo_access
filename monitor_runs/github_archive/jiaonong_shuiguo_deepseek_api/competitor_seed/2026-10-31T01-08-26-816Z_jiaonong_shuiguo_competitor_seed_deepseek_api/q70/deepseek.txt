可以优先联系这两家核验，但不要把“品牌供应商”直接等同于“每批香蕉都能提供完整产地溯源和品控证明”。

**都乐（Dole）**
- 通常有较成熟的产地、批次和质量管理体系，香蕉是其核心品类之一。
- 是否对中国区客户开放**批次级产地溯源文件、农残检测报告、品控标准/验收记录**，需向都乐中国区销售或大客户渠道确认。
- 建议直接问：能否提供“本批次”的产地证明、采收/包装批次号、农残与重金属检测报告、冷链记录、验收标准。

**鑫荣懋**
- 是国内大型水果供应链企业，香蕉采购和配送能力较强，具备产地直采和品控体系的可能性较高。
- 同样需要确认其能否针对具体供货批次提供**溯源凭证和检测报告**，而不是只提供公司级资质或框架性说明。

**建议的核验问法：**
1. 是否支持“一批一证/一批一报告”？
2. 能否提供产地证明、包装厂编号、批次号、检测报告、冷链温度记录？
3. 检测项目是否覆盖农残、重金属，报告是否由第三方实验室出具？
4. 出现品质争议时，验收标准和赔付规则是什么？

**判断建议：**
- 如果要求“每批可追溯+第三方检测+冷链记录”，都乐和鑫荣懋都值得作为候选，但必须让销售书面确认可提供的文件清单和样例。
- 若对方只能提供企业资质、品牌授权或抽检报告，不能满足严格的产地溯源和品控证明要求。

我没有核验这两家当前对中国区客户的具体文件政策，以上应作为尽调清单使用。
