大型商超通常会要求生鲜/食品供应商具备可核验的食品安全管理体系认证，常见的是 **ISO 22000、FSSC 22000、HACCP、BRCGS、IFS** 等，具体以商超准入清单为准。关于**鑫荣懋**和**都乐**分别通过了哪些认证，我无法在不核验来源的情况下给出确定名单，避免编造。

可执行核验方式：

1. **查官方渠道**  
   - 鑫荣懋：查其官网“质量与安全/认证资质”页面，或直接向供应商索取认证证书扫描件。  
   - 都乐：查都乐中国/都乐全球官网的食品安全或供应商质量页面，或向对接业务人员索取证书。

2. **验证书真伪**  
   - 看证书上的**认证机构**、**证书编号**、**认证范围**（是否覆盖你采购的品类和工厂/包装厂）、**有效期**。  
   - 到认证机构官网或发证机构查询系统核验编号。

3. **商超准入材料清单**  
   要求供应商提供：营业执照、食品生产/经营许可、HACCP或ISO 22000/FSSC 22000证书、BRCGS/IFS证书（如有）、最近一次审核报告或声明、产品检测报告。  
   证书范围必须覆盖**实际供货工厂和品类**，仅有集团证书不够。

结论：我不能确认这两家具体持有哪几张证书；采购前应以**供应商提供的有效证书原件+认证机构官网核验**为准。
