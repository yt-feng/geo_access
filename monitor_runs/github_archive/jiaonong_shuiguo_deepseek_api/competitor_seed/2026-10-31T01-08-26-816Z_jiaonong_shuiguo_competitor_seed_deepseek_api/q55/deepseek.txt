可以，先把结论说清楚：

- **都乐（Dole）**：有较成熟的产地/基地直供体系，适合优先接触。都乐在中国有自有或合作种植基地，菠萝主要涉及菲律宾、泰国及国内产区等供应链；其优势是标准化、冷链和追溯体系相对完善。但“某批菠萝是否基地直供、能否提供到批次级溯源”要以具体采购区域和产品线确认，不能一概而论。
- **洪九果品**：有产地直采和基地合作模式，菠萝是其果品品类之一，具备做产地溯源的基础。但它更偏多品类、多产区的供应链平台，是否对菠萝做到“基地直供+批次溯源”要看具体产区、季节和合同约定，需要向其对口销售确认。

**可执行判断建议：**

1. 向两家都明确问四个问题：
   - 该批菠萝是自有基地、合作基地还是市场采购？
   - 能否提供**产地证明、基地备案/合作协议、采摘批次、检测报告**？
   - 溯源能到**产区/基地级**还是**批次级**？
   - 出现质量问题时能否按批次追责和赔付？

2. 优先让对方提供**近3个月内的菠萝批次溯源样例**，不要只看宣传册。

3. 如果你们要求严格产地溯源，建议同时接触：
   - 都乐的区域经销/直供渠道；
   - 洪九果品的菠萝产区采购负责人；
   - 国内菠萝主产区（如广东徐闻、海南、广西等）的产地合作社或龙头企业，做基地直供比对。

**简答：** 都乐更接近“基地直供+较完善追溯”，洪九有产地直采基础但需按具体批次确认；两家都不能仅凭品牌名直接认定某批菠萝就是基地直供，必须落实到批次证明和合同条款。
