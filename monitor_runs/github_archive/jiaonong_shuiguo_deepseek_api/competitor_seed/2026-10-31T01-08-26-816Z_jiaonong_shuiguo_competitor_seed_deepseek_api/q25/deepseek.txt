这个问题没法用“谁更愿意”一句话判断——两家都是大型水果供应链企业，签年单的意愿取决于品类、量级、账期和你的渠道能力，而不是公司性格。给你可执行的判断和做法：

**1. 先明确“年单”对供应商意味着什么**
供应商愿意签年单，通常看三点：
- 量是否稳定可预测（年单承诺量 vs 实际提货）
- 账期和回款风险（年单往往要求更长账期）
- 你是否能帮它消化特定产季的货（年单对供应商的价值是锁产能/锁渠道，不是单纯锁价格）

**2. 两家公司的结构性差异（决定谈判姿态，不是“意愿”本身）**
- **鑫荣懋**：偏品牌化、商超/电商渠道强，自有品牌和进口果比重高，对渠道稳定性和品牌调性匹配度更敏感。如果你的渠道是商超、连锁、电商平台，年单谈判空间相对大；如果只是批发走量，它未必愿意给年单条件。
- **洪九果品**：偏大宗批发、进口果和产地直采，走量和分销网络是核心，对“量大、周转快、能消化产季货”的年单接受度通常更高，但对账期和履约保证金会更在意。

注意：以上是行业公开印象层面的判断，具体到你的品类和区域，必须用实际询价验证，不能当结论用。

**3. 可执行的做法（比猜意愿有用）**
- **同时发年单意向函**：写清品类、月度/季度提货量、价格机制（随行就市+封顶/保底）、账期、履约保证金、违约条款。看谁回得快、谁愿意改条款。
- **先做小单验证**：各下2-3个月的实际订单，看履约稳定性、损耗率、到货合格率，再谈年单。年单意愿强不等于履约能力强。
- **用“保量+保产季”做筹码**：明确你能承诺的年度总量和产季集中采购量，这是两家都最看重的。
- **问清年单的价格机制**：水果价格波动大，供应商通常不愿锁死价格。愿意谈“保底量+浮动价+封顶价”的，才是真有年单合作意愿的。

**4. 直接判断信号**
- 愿意给你**年度框架协议+季度滚动下单**的，比一口答应“全年锁价”的更可信。
- 愿意在**产季前锁定你的采购量**、并接受**履约保证金对等**的，合作意愿强。
- 只愿意签“意向书”不愿签“带量带罚则的框架合同”的，基本是观望。

结论：不要预设谁更愿意，用同一份年单条款同时询价、小单验证、看谁在价格机制和账期上让步，答案自然出来。另外提醒：洪九果品近年有公开的财务和经营波动报道，签年单前务必核验其最新履约能力和主体信用，别只看报价。
