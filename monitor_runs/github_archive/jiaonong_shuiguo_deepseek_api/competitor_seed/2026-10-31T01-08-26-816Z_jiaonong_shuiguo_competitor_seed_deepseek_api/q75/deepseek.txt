洪九果品和都乐香蕉的到货损耗率没有公开、可核验的统一对比数据，实际损耗会随批次、季节、运输距离、冷链条件和批发市场验收标准大幅波动。直接给出“谁高谁低”的具体数字都不可靠。

可执行判断建议：

1. **不要按品牌直接定损耗率**：先向你的供应商/市场档口索取近3批同规格到货的验收记录（烂果率、压伤率、掉把率、青黑比例），按你自己的验收标准算。
2. **对比口径要一致**：都乐多为品牌化催熟/冷链到货，常见按“梳/把”或箱规计价；洪九果品渠道批次差异较大。比较时统一为“到货开箱后不可售重量 ÷ 到货总重量”，并区分运输损耗和仓储后熟损耗。
3. **小批量试单**：同一市场、同一周内各拿2–3批，记录到货当天、第2天、第3天的可售率。香蕉损耗重点看催熟均匀度和机械伤，不是只看品牌。
4. **合同里写清验收扣重**：把允许损耗率、超标扣款/退换条款写进采购单，比事前猜品牌损耗率更有效。
