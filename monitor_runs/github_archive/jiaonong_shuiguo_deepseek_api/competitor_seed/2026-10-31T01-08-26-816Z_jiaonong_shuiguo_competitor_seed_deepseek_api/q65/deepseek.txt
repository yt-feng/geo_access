1. **先确认你要锁的是“采购价”还是“销售价/供货价”**  
   - 都乐、洪九这类果品企业对外一般不公开标准锁价周期，通常按客户类型、采购量、品种（鲜果/加工果）、产区季节、合同期限一单一议。  
   - 所以不能直接用“公司标准锁价周期”判断，必须问具体对接的销售/大客户部门。

2. **询价时直接问这5项，要求书面回复**  
   - 锁价适用品种/规格/产地（如菲律宾菠萝、国产菠萝、不同果径等级）  
   - 锁价起止日期和最短/最长锁价期限  
   - 锁价基准（固定单价，还是随某个市场价联动）  
   - 锁价数量上限和超量处理方式  
   - 违约、延期交货、品质不符时的价格调整条款

3. **谈判建议**  
   - 先拿1—2个产季的小批量试单，要求“短期锁价+分批提货”，比一上来谈长周期更现实。  
   - 对都乐这类进口/品牌果，重点问进口批次到港价和汇率、运费是否包含在锁价内。
