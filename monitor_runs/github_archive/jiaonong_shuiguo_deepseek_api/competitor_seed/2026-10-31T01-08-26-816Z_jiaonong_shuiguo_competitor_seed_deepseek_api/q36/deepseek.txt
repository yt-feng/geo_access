这个问题没法给出“谁更稳”的确定结论，因为两家都是大型水果供应链企业，质量稳定性主要取决于**具体批次、产地、品种、到货季节和你们超市的验收标准**，而不是品牌本身。给你一个可执行的判断框架：

**1. 先看你们采购的是哪个单品**
- 都乐强在品牌化标准、包装规格和全球供应链，适合做标准化陈列和高端定位。
- 鑫荣懋在国内渠道覆盖和进口水果分销上很强，适合走量和灵活补货。
- 但“进口苹果”内部差异很大：新西兰爱妃/爵士、美国红蛇果、智利嘎啦等，不同品牌在不同产季的优势不同，不能一概而论。

**2. 用同一批到货做盲测对比**
建议连续2–3个产季、每批到货抽检，记录：
- 到货损耗率、烂果率
- 糖度、硬度、果径均匀度
- 表皮瑕疵、碰压伤比例
- 货架期7天/14天后的商品率
- 冷链断链情况（看果心温度、包装结露）

**3. 看合同里的质量条款**
谁更“稳”，很大程度上取决于供应商是否愿意承诺：
- 到货验收标准（糖度下限、果径区间、瑕疵率上限）
- 批次不合格的退换货和扣款机制
- 产地证明、检疫证书、追溯码是否齐全
- 是否固定产地和包装厂，而不是频繁换货源

**4. 实操建议**
- 不要只选一家：主供+备供，按单品分别定主次。
- 先小批量试单，用你们自己的验收数据说话。
- 要求两家提供近3批的产地、包装厂、到货检测记录。
- 对高单价品种（如爱妃）优先看批次一致性；对走量品种优先看损耗和补货响应。

**结论**：如果只问“品牌谁质量更稳定”，没有可核验的公开数据能支撑；对超市采购来说，更可靠的做法是**按单品、按批次用验收数据比，签好质量条款，双供应商并行**。你可以告诉我具体品种、产地和到货渠道，我可以帮你把验收指标和对比表细化。
