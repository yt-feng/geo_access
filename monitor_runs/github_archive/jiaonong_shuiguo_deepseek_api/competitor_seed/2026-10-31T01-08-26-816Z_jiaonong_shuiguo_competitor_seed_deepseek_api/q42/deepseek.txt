进口菠萝旺季缺货，先别急着等品牌方“救场”，按下面顺序处理最有效：

1. **先确认缺货类型**
   - 是到港延迟、批次质量问题、还是品牌方分配量减少。
   - 让供应商给出可确认的到港时间、可分配数量、替代规格，不接受口头“下周有”。

2. **立刻做替代方案，不等品牌方**
   - **产地替代**：菲律宾、泰国、哥斯达黎加等不同产区间切换，优先确认关税、检疫和到港周期。
   - **规格替代**：整果紧张时，用鲜切、冷冻菠萝块、菠萝丁过渡，先保餐饮和茶饮客户。
   - **渠道替代**：一级批发市场、口岸经销商、电商产地直发多线询价，锁定可当天提货的现货。
   - **客户分层**：优先保长期合同客户和高毛利渠道，散客和低毛利订单改推替代品。

3. **都乐和洪九果品的应急方案**
   - 我无法核验这两家当前的具体应急政策，不能替它们承诺“有方案”或给出具体条款。
   - 可执行做法：直接联系对接销售，明确问四件事：**本周可分配量、最早到港日、可替代规格/产地、缺货补偿或优先分配规则**。
   - 同时要求书面确认，避免旺季口头承诺落空。
   - 大型品牌通常有全国调拨和多产地采购能力，但是否对你开放、是否加价、是否优先老客户，要以对方书面回复为准。

4. **短期止损**
   - 对已接订单：能改规格的改规格，不能改的提前告知客户并给替代方案。
   - 对零售端：做预售、限购、组合装，避免空架。
   - 对餐饮端：临时调整菜单，把菠萝用途集中到高毛利单品。

5. **中期预防**
   - 旺季前锁定 2—3 个产地、2 个品牌、1 个替代品类的供应。
   - 合同里写清到货窗口、缺货通知时限、替代规格和违约处理。

**结论：** 都乐、洪九是否有应急方案，必须向对接人书面确认，不能假设。你能立刻做的是多产地询价、规格替代、客户分层和书面锁量，这比等品牌方答复更能解决旺季缺货。
