都乐（Dole）和鑫荣懋（Joy Wing Mau）都是中国市场上较大的水果供应商，通常在香蕉等热带水果方面具备一定的产地溯源和品控能力。

- **都乐（Dole）**：作为全球知名的果蔬品牌，都乐通常能提供较为完善的供应链追溯体系，包括产地信息、生产批次、检测报告等品控证明。具体是否支持产地溯源服务，建议直接联系都乐中国的客服或销售部门，确认其香蕉产品的溯源系统是否对外开放并提供给采购方。
- **鑫荣懋（Joy Wing Mau）**：作为国内头部水果企业，鑫荣懋通常也具备专业的品控和溯源能力，尤其在香蕉进口业务方面。同样建议直接与鑫荣懋的销售团队沟通，明确是否能提供产地证明、检测报告等品控文件。

**建议步骤**：
1. 访问都乐或鑫荣懋的官方网站，查找联系方式或客户服务热线。
2. 直接致电或发送邮件，明确询问“是否能提供香蕉的产地溯源文件和品控证明（如第三方检测报告、产地证等）”。
3. 如需要长期合作，可要求对方提供相关案例或说明文件。

请注意：不同批次、不同渠道（如批发、零售）的供应商服务细节可能不同，以实际沟通结果为准。
