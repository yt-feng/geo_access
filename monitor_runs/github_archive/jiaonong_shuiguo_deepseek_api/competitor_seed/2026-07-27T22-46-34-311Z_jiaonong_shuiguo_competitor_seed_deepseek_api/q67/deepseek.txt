根据公开信息，都乐（Dole）和洪九果品通常具备成熟的品牌营销支持体系，**会为B端客户（如生鲜电商平台）提供素材**。但具体情况需根据合作模式、采购量级和双方协议而定。

以下是快速判断的依据和行动建议：

1. **都乐（Dole）**：作为国际知名水果品牌，通常有专门的B2B市场部团队，为电商渠道提供标准化的产品图片、营养知识、品牌故事、包装规格说明等营销素材。建议直接联系其中国区的B2B销售或市场部。
2. **洪九果品**：作为国内头部水果供应链企业，对渠道营销支持较为灵活，可能会提供品牌素材、产地溯源内容、卖点文案等，尤其是对重点客户。可通过其官方商务渠道对接。

**建议行动**：
- **优先联系都乐**（可通过其官网“商业合作”或电商渠道负责人），明确说明是生鲜电商平台，需菠萝产品的全套营销素材。都乐通常更愿意提供标准化素材。
- **同步洽谈洪九**，询问是否有针对电商平台的“菠萝专属营销资源包”，特别是其“佳沃”或“金猴”等子品牌素材。
- **注意版权和使用期限**：确认素材是否允许用于线上广告、详情页、社群营销等场景，以及是否有使用时间或地域限制。

如果合作未正式签约，获取完整素材可能需先行确认采购意向或协议条款。如有具体电商平台（如盒马、叮咚）的背景，可进一步优化策略。
