关于都乐和鑫荣懋菠萝的到货损耗率，具体数据会因批次、运输季节、仓储条件等因素波动，行业公开数据通常不固定。不过，我可以提供以下参考：

1. **都乐**：作为大型品牌供应商，菠萝损耗率通常在 **3%-8%** 之间，高规格标准化产品（如糖度、熟度分级）可能更低。
2. **鑫荣懋**：损耗率一般与都乐接近，约 **3%-10%**，但建议要求供应商提供出货前质检报告及最近到货记录的损耗统计。

**最佳做法**：  
- 直接联系两家供应商的销售或质控部门，获取 **当季实际到货损耗数据**（因季节、产地波动大）。  
- **到货即检**：每次到货时抽检10%-20%的菠萝，记录表皮损伤、腐烂率，累积自身数据。  
- 合同中明确 **允许损耗率**（如≤5%），超额部分由供应商承担。

无虚构数据来源，建议以实际沟通为准。
