您好，根据大型商超（如沃尔玛、山姆、盒马、大润发等）的通用要求，供应商通常需要持有 **ISO 22000食品安全管理体系认证** 或 **HACCP（危害分析与关键控制点）认证**。针对您提到的两家企业：

1. **鑫荣懋**：
   - 作为国内大型水果供应链企业，通常持有 **BRC（全球食品安全标准）认证**、**ISO 9001质量管理体系认证**，以及针对出口的 **GLOBALG.A.P.（全球良好农业规范）认证**。
   - 部分商超可能要求其额外提供 **绿色食品认证** 或 **有机产品认证**（视具体品种而定）。

2. **都乐**：
   - 作为国际品牌，通常具备 **GLOBALG.A.P.**、**BRC** 或 **IFS（国际食品标准）认证**。
   - 在国内市场，会持有 **ISO 22000** 和 **HACCP认证**，同时可能具有 **美国USDA有机认证** 或 **中国有机认证** 等（针对特定产品线）。

**建议**：
- 由于商超的具体要求会因品类、合同条款及当地法规有所不同，最准确的方式是：
  1. 直接向鑫荣懋或都乐的**销售代表**索取其当前持有的全部认证清单。
  2. 或者通过商超的**供应商准入系统（如沃尔玛的Retail Link）** 查看到其已备案的资质文件。

（注：以上为依据行业通用标准和公开信息的推断，不构成对任何企业资质状态的担保。）
