目前都乐和洪九果品均提供香蕉小包装产品，但环保包装的具体情况需结合实际产品批次和区域政策确认。以下为已知信息：

1. **都乐**：都乐已推出部分环保包装方案，如使用可回收纸板或符合FSC认证的纸箱包装香蕉，部分小包装可能采用可降解塑料或简化设计以减少塑料使用。需查看具体包装标识或联系当地经销商确认。

2. **洪九果品**：洪九在部分产品线尝试环保包装，例如采用再生材料或可重复使用的周转箱，但小包装的环保属性可能因合作供应商而异。建议直接询问供应商是否符合您的环保标准（如可降解、可回收、减量设计等）。

**建议**：  
- 要求供应商提供包装的环保认证（如FSC、可降解标识、GRS认证等）。

- 可要求供应商提供包装材质说明和环保测试报告。

如需更具体信息，建议直接联系两家公司的销售部门或查看产品包装标签。
