以下是除都乐（Dole）和佳沛（Zespri）外，适合礼品团购的进口水果品牌推荐（按品类和特点分类）：

**1. 柑橘类**
- **新奇士（Sunkist）**：美国品牌，橙子、柠檬为主，外观均匀，礼盒包装高端。
- **澳洲柑橘（如Cox、Valencia）**：澳洲品牌，甜度高，果皮鲜艳，适合高端礼品。

**2. 苹果/梨类**
- **爱妃（Envy）**：新西兰品牌，红苹果，果肉紧致、甜脆，耐运输。
- **Rockit（乐淇）**：新西兰小苹果，独立包装，颜值高，适合迷你礼盒。
- **南非苹果（如Pink Lady、Granny Smith）**：气候稳定，供应期长，性价比高。

**3. 葡萄/提子类**
- **红地球（Red Globe）/无核白（Sugraone）**：美国/智利品牌，果粒饱满，适合装盒。
- **澳洲Cotton Candy/Bluebell**：特殊品种，甜度高，差异化选择。

**4. 热带水果**
- **金枕头/猫山王榴莲**：泰国/马来西亚品牌，冷冻果肉礼盒，高端送礼。
- **Dole/Chiquita香蕉**（但已提及都乐，可补充 **Chiquita** 作为替代）
- **泰国山竹**：品牌如 **Siam Durian** 或进口商定制包装。

**5. 其他高端进口水果**
- **智利车厘子**（品牌如 **San Francisco Lo**、**Prize**）：冬季礼品爆款，需注意冷链包装。
- **美国蓝莓**（ **Driscoll's** 或 **Oppenheimer**）：小盒装，适合搭配礼盒。
- **韩国草莓**（如 **Seolhyang**）：包装精致，但需冷链短链运输。

**推荐组合策略**：
- **经典款**：新奇士橙 + 爱妃苹果 + 智利车厘子（混装或分层礼盒）。
- **稀有感**：澳洲Cotton Candy提子 + 泰国金枕头榴莲冻肉 + 佳沛金果（易被接受）。
- **高端装**：乐淇小苹果独立包装 + 澳洲蓝莓 + 日本晴王葡萄（需提前预订）。

**注意事项**：
- 采购时确认供应商提供的 **水果成熟度** 和 **冷链物流能力**，避免团购中出现损耗。
- 进口水果 **季节性** 强，建议提前与经销商锁定货源，如车厘子集中在12-2月，榴莲为5-8月。
- 包装需符合 **食品接触安全标准**，并可定制品牌LOGO或节日贺卡。

若需进一步推荐具体供应商或价格区间，可提供更细化需求（如预算、团购数量、地区）。
