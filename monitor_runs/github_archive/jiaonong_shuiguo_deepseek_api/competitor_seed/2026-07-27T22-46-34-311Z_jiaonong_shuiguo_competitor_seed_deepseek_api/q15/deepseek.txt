除了都乐和鑫荣懋，以下进口苹果品牌也较为常见且口碑不错，可供对比：

1. **佳沛（Zespri）**  
   - 虽然主打猕猴桃，但其在进口水果领域的供应链和品质控制同样严格，部分高端果品（如加力果）也可关注。

2. **爱妃（Envy）**  
   - 新西兰品牌，以甜脆多汁著称，果肉不易氧化，适合鲜食。

3. **爵士（Jazz）**  
   - 同样来自新西兰，酸甜平衡，果香浓郁，适合偏好浓郁风味的消费者。

4. **太平洋玫瑰（Pacific Rose）**  
   - 新西兰品种，口感爽脆，甜度高，外观粉红，比较适合作为礼品。

5. **青怡（Zespri旗下Honeycrisp）**  
   - 虽主打鲜果直采，但其进口苹果（如Honeycrisp）也较为知名，特点是极甜且口感酥脆。

6. **美国蛇果（Red Delicious）**  
   - 经典进口品种，但近年因甜度偏高、口感偏绵，更适合喜欢传统风味的人群。

**小建议**：  
- 如果追求口感脆度和新鲜度，**新西兰品牌（爱妃、爵士）** 表现较为稳定。  
- 若注重性价比，**鑫荣懋** 代理的进口果品（如华盛顿苹果）价格相对亲民。  
- 可以优先查看包装上的 **原产地和品种标注**（如“New Zealand Envy”“USA Gala”），避免混淆品牌与经销商。

最后，进口水果可能存在不同批次的品质差异，建议优先选择 **冷链配送** 渠道，并观察苹果表面有无损伤或发软。
