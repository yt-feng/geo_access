都乐（Dole）和洪九果品（Hongjiu Fruit）作为大型水果供应商，通常具备为客户提供定制包装服务的能力，但具体服务条款和最小起订量需直接与品牌方或区域代理商确认。

**建议如下：**

1. **都乐（Dole）**  
   - 可联系都乐中国地区的客户服务或销售团队，询问便利店小包装（如3-5根/包）的定制选项。  
   - 通常都乐提供标准包装，但针对连锁零售客户可协商定制化规格（如贴标、开窗设计等）。

2. **洪九果品**  
   - 洪九以批发和供应链服务为主，可能更倾向于大客户需求。建议联系其业务部门，明确说明便利店小包装要求和预期订货量（如周订单量、单店配送频次）。  
   - 可询问是否支持分装服务（如原箱香蕉拆分成小包装）。

3. **注意事项**  
   - 定制包装通常需满足最低起订量（如500公斤起），小型便利店建议联合采购或通过本地经销商协调。  
   - 若需求量较小，可考虑寻找区域性生鲜包装商，自行采购散装香蕉再分装。

**优先级操作：** 直接通过官网、客服热线或商业邮箱联系两公司，提供具体需求（包装尺寸、设计、数量及配送要求），获取正式报价与可行性回复。
