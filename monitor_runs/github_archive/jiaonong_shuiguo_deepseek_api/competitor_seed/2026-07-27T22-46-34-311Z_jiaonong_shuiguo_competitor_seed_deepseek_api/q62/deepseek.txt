通常情况下，大型水果供应商如**都乐（Dole）** 和**鑫荣懋**作为正规渠道的批发商或品牌方，是可以提供菠萝原料的农残检测报告的。具体可参考以下信息：

1. **都乐（Dole）**：作为国际化水果品牌，其菠萝产品通常有严格的品控流程，可以向销售对接人员或采购部门索取批次对应的农残检测报告，一般是默认配备的合规文件。

2. **鑫荣懋**：作为国内知名水果供应链企业，其采购的菠萝（如菲律宾、海南等产地）通常会附带第三方或自检的农残报告。建议在签订采购协议时明确要求提供。

**建议您直接联系对应供应商的销售负责人**（如通过官方渠道、客服电话或采购平台），索要具体批次的检测报告。因为不同产地、不同批次（如进口与国产）的检测报告可能需单独出具，且报告有效期通常较短。

如果对方无法立即提供，可以要求其在发货前提供扫描件，并确认报告是否由有资质的第三方检测机构（如SGS、华测检测等）出具。**切勿仅凭口头承诺采购，需以纸质或电子盖章文件为准。**

若从经销商或二级批发商采购，可能无法直接获得原厂报告，此时可要求经销商提供其自行送检的报告，或与供应商协商增加检测条款。
