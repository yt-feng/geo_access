都乐（Dole）和洪九果品（Hongjiu Fruit）是知名的水果供应商。关于菠萝的种植基地，以下是两大公司的主要产区信息：

1. **都乐（Dole）**：
   - 国内产地：主要在海南、广东、广西等热带及亚热带地区建有合作种植基地。都乐在海南有自有或合作的菠萝种植基地，例如在海南的一些农场。
   - 国外产地：都乐在全球多地（如菲律宾、哥斯达黎加、厄瓜多尔等）拥有大型菠萝种植园，但国内采购通常以国产为主，进口渠道可能涉及菲律宾（如都乐金菠萝）。

2. **洪九果品（Hongjiu Fruit）**：
   - 洪九果品是国内大型水果供应链企业，其菠萝采购主要来自国内主产区，如**海南省**（尤其是万宁、琼海、文昌等市县）和**广东省**（如徐闻、湛江等地）。洪九通常通过订单农业或与产地合作社合作来保障供应。
   - 此外，洪九也可能采购进口菠萝（如菲律宾、泰国等），但以国产为主。

**建议**：若您需要稳定供应，可直接联系都乐或洪九果品的采购部门，确认其当前菠萝基地的具体位置、合作模式（自有基地或长期订单）、供应周期和品控标准。建议关注季节性因素（如海南菠萝主产期为3-5月，广东徐闻菠萝为3-4月），并考虑备选产地以应对波动。
