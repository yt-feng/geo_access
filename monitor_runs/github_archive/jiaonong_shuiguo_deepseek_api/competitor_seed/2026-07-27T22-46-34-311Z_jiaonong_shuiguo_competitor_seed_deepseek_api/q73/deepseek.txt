大型商超通常要求供应商通过以下食品安全管理体系认证，鑫荣懋（Xinrongmao）和都乐（Dole）作为国际知名果蔬供应商，一般持有以下认证：

1. **BRCGS Food**（食品安全全球标准）：  
   都乐作为全球品牌，其多家工厂持有BRCGS认证；鑫荣懋出口业务中也可能具备此认证。

2. **FSSC 22000**（食品安全管理体系）：  
   这是大型商超（如沃尔玛、家乐福）常见要求，两家公司均通过此类认证。

3. **ISO 22000**（食品安全管理体系）：  
   面向国内供应体系的常见认证，两家公司均应持有。

4. **GlobalG.A.P.**（全球良好农业规范）：  
   针对水果种植环节，都乐广泛持有；鑫荣懋的基地级供应商通常也具备。

5. **HACCP**（危害分析与关键控制点）或 **ISO 28000**（供应链安全管理）：  
   部分商超（如麦德龙）额外要求，两家企业均具备。

**建议**：  
- 如需对接具体商超（如永辉、山姆），可直接要求供应商提供**认证证书复印件**，通常会在合同附件中注明。  
- 都乐官网（dole.com）和鑫荣懋官方渠道（如官网或年报）可查询认证范围，但具体到每个工厂可能不同。  

**注意**：不同商超门槛有差异（如Costco可能要求有机认证），请以实际采购合同为准。
