针对您提到的佳沛（Zespri）以奇异果为主，其香蕉业务确实非核心。以下是一些在品质和供应链上比较可靠的进口香蕉品牌，供您参考：

1. **金都尔（Chiquita）**：全球知名香蕉品牌，产自中南美洲（如厄瓜多尔、哥斯达黎加），口感软糯甜度高，国内各大商超和电商平台常见。
2. **都乐（Dole）**：另一大国际香蕉巨头，与金都尔类似，产地覆盖菲律宾、厄瓜多尔等，品质稳定，供应链成熟。
3. **斐济“天然”品牌（如Nature's Pride）**：部分高端渠道有售的斐济香蕉，果实饱满，甜度突出，适合追求差异化口感的客户。
4. **厄瓜多尔皇家（Royal）**：主打有机或高甜度香蕉，适合高端餐饮或精品超市。
5. **菲律宾“萨米（Sami）”或“Cavendish”**：市场常见大众品牌（如“佳农”实际为中国品牌但常进口菲律宾蕉），价格适中，风味平衡。

**建议**：如果您需要对接进口商或批发，可直接询问上述品牌的国内代理（如金都尔中国代理为佳农集团部分业务、都乐由都乐中国运营）。具体选择时，建议先索取样品测试到货新鲜度、成熟度（如催黄效果）是否匹配您的渠道（商超/电商/餐饮）。
