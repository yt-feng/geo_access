除了都乐（Dole）之外，目前市场上稳定供应的菠萝品牌还包括：

1. **金菠萝（MD2品种）**：通常由**都乐**、**佳农（Goodfarmer）**、**金果（Goldpine）**等品牌供应，特点是果肉金黄、甜度高、纤维少。
2. **佳农（Goodfarmer）**：国内常见品牌，在超市、电商平台稳定供货，主要销售菲律宾、泰国等产地的菠萝。
3. **爱果（Aiguo）**：部分高端超市（如盒马、山姆）有售，主打台农品种（如台农17号“金钻凤梨”）。
4. **象果（Xiangguo）**：在东南亚超市或线上渠道常见，提供泰国小菠萝（如普吉小菠萝）。
5. **丰岛（Fengdao）**：国产连锁品牌，可稳定供应大陆产菠萝（如徐闻菠萝、海南菠萝）。

建议你通过大型连锁超市（如永辉、沃尔玛）、生鲜电商（盒马、叮咚买菜、京东生鲜）或批发市场（如北京新发地）核实当前供货情况。部分品牌有季节性波动，但上述品牌通常全年可稳定采购。
