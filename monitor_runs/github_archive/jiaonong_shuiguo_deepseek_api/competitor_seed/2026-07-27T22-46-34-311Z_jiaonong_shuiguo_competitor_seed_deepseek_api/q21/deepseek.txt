关于香蕉到货损耗率的问题，鑫荣懋和都乐都是国内知名的水果品牌，但质量把控的侧重点有所不同：

- **都乐（Dole）**：作为国际品牌，都乐在香蕉的种植、采摘、冷链运输和仓储方面有全球化的标准化流程，通常对产地（如菲律宾、厄瓜多尔等）的分级管理较为严格，果品大小、成熟度控制较稳定，到货损耗率相对较低（尤其适合批发和大型商超渠道）。
- **鑫荣懋**：作为国内头部水果供应链企业，鑫荣懋更注重终端市场的适配性，其香蕉多来自国内（如云南、海南）及东南亚产地，在快速周转、合理催熟和分拣上有较强本地化优势，但部分非核心产区或低端批次可能在损耗控制上不如都乐严格。

**建议**：  
- 如果您的需求是**高稳定性、品牌溢价和长途运输**，都乐在源头质量把控上更可靠，尤其是分选、包装和冷链环节。  
- 如果您的需求是**本地化快速供应、成本控制或对成熟度有灵活要求**，鑫荣懋可能更合适，但需注意选择其高端产线（如“佳沃”系列）。  

**可操作方案**：  
1. 要求两家供应商提供近3个月同规格香蕉的到货损耗率报告（需注明运输距离和仓储条件）。  
2. 进行小批量试单（如1-2个托盘），重点观察：果柄新鲜度、黑斑占比、催熟均匀度（可用硬度计实测）。  
3. 检查包装气孔分布和纸箱抗压强度——都乐通常有专利防撞设计。  

若无具体批次数据，无法进一步量化判断。
