都乐和洪九果品这两家我没有可核验的实时产品目录，无法确认它们当前是否有“散装/小包装”的香蕉 SKU，也无法给你具体规格或价格。

不过从实操角度看，可以这样判断和推进：

**1. 都乐（Dole）**
- 都乐在零售端常见的是**整把/整袋预包装**，尤其是商超和电商渠道。
- 社区团购要的“小包装”通常不是都乐标准流通货，而是需要渠道商做**二次分装**，或走**定制规格**。
- 建议直接问区域经销或大客户渠道：有没有“单根/2-3根装”“小把装”“按份分装”的方案，起订量和分装责任归谁。

**2. 洪九果品**
- 洪九更多是**水果供应链/批发**逻辑，香蕉是重要品类，但常见是**整箱、整件、按重量**走货。
- 能否做小包装，取决于你对接的是总部、区域仓还是当地批发商，很多情况下是**可谈定制分装**，但要满足起订量。
- 建议问清楚：是否支持社区团购规格、是否代分装、包装耗材谁出、损耗怎么算。

**3. 更现实的判断**
- 这两家不一定有现成的“散装小包装香蕉”标准品。
- 社区团购要的小包装，通常有三条路：
  1. 找品牌区域经销商做**定制分装**；
  2. 自己或找加工点做**二次分装**；
  3. 直接找本地香蕉批发商/催熟商，按你需要的份量供货。

**4. 你可以直接这样问供应商**
- 有没有适合社区团购的**小规格香蕉**：单根装、2-3根装、500g/份、1kg/份？
- 是**原厂预包装**还是**渠道二次分装**？
- 起订量、供货价、损耗率、售后怎么算？
- 是否支持**按周稳定供货**和**催熟度可控**？
- 包装上能否贴团购平台的标签/条码？

**5. 建议**
如果你量不大，优先找**本地批发商或催熟商**做小包装，比直接找都乐、洪九总部更灵活。  
如果你量稳定且大，再去谈都乐/洪九的区域渠道做定制分装，才有可能拿到合适的小包装方案。
