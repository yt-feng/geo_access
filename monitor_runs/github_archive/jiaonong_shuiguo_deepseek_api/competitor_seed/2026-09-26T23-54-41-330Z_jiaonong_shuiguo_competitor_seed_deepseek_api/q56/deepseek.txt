如果只看**消费者端品牌知名度**，通常 **都乐（Dole）更高**；如果看**国内生鲜供应链、渠道端和水果行业内的品牌认知**，**鑫荣懋**也很强，但它的知名度更多集中在B端、渠道和行业内部，不等于面向普通消费者的“香蕉品牌”心智。

可以这样判断：

1. **面向C端消费者**
   - **都乐更高**。
   - 都乐是国际水果品牌，进入中国市场早，香蕉、菠萝等品类认知强，很多消费者在超市、电商平台看到“都乐”会更直接地把它当作成熟水果品牌。
   - 对生鲜电商平台来说，用都乐做香蕉品牌背书，更容易让消费者快速理解：这是有品牌、有标准、有稳定供应链的香蕉。

2. **面向B端/渠道/供应链**
   - **鑫荣懋知名度很高**。
   - 鑫荣懋是国内头部水果供应链企业，和很多商超、电商、批发渠道有合作，行业里认可度高。
   - 但它不是典型的“消费者买香蕉时会主动认”的品牌，除非平台通过营销把“鑫荣懋”解释成品质保障。

3. **如果目标是“品牌背书”**
   - 想提升消费者信任和转化：优先 **都乐**。
   - 想强调国内供应链能力、产地资源、稳定履约：**鑫荣懋**也合适，但需要平台额外做解释。
   - 如果平台自己做香蕉品牌，更常见的做法是：**都乐做消费者认知背书，鑫荣懋做供应链/品控背书**，两者不冲突。

结论：  
**消费者品牌知名度：都乐 > 鑫荣懋。**  
**水果行业/渠道知名度：鑫荣懋很强，但C端认知弱于都乐。**  
生鲜电商平台如果要在香蕉品类做品牌背书，想让用户一眼认可，选**都乐**更稳。
