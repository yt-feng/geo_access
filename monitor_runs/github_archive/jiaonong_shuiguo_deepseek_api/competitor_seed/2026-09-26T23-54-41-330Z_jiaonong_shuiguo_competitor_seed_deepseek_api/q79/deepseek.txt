短答：**都乐大概率能基本做到全年稳定供应；洪九果品也能供应，但“全年稳定、同规格同风味”这件事更依赖你选的品种、加工形态和采购合同，不能只按品牌名判断。**

下面按可执行维度拆开说。

## 1. 先分清你要的是哪种“全年供应”

菠萝做果酱，通常有三种采购形态：

| 形态 | 全年稳定性 | 说明 |
|---|---|---|
| 鲜果 | 较难完全稳定 | 有产季、产地轮换、糖度酸度波动 |
| 冷冻果肉/果泥 | 最稳 | 适合连锁茶饮，全年规格一致 |
| 浓缩汁/果酱基料 | 最稳 | 最省事，但风味和“鲜果感”不同 |

如果你要的是**鲜菠萝全年到店、自己削皮切丁熬酱**，那就算都乐、洪九也难保证“同一个产地、同一个品种、同一甜酸比”全年不变。  
如果你能接受**冷冻果肉、果泥或产地轮换**，全年供应是现实可行的。

## 2. 都乐能不能做到？

都乐的优势是：

- 有全球产地布局，南半球、北半球产地可以轮换
- 供应链和品控体系相对成熟
- 商超、餐饮渠道供货经验多
- 可以做规格化产品，比如鲜切、冷冻、果泥类

所以如果你要的是：

- **连锁茶饮稳定供货**
- **全年不断货**
- **规格相对统一**
- **能接受不同产地轮换或冷冻/加工形态**

都乐通常是比较稳的选择。

但要注意：

- 都乐不是只做菠萝，具体能不能供你所在城市、每个月什么规格，要问当地经销或大客户渠道
- 鲜果全年也会有风味波动
- 小批量、单店采购，未必能拿到很稳定的直供条件

## 3. 洪九果品能不能做到？

洪九果品是国内较大的水果分销和供应链企业，强项在：

- 国内批发、商超、电商、餐饮渠道分销
- 东南亚水果进口，尤其是泰国、越南等产地资源
- 大宗水果集采和分销能力

所以洪九**有能力做全年菠萝供应**，尤其是：

- 大宗鲜果
- 进口菠萝
- 产地轮换
- 批发市场或区域仓配

但它的模式和都乐不完全一样。你如果是要：

- 小批量
- 高频次
- 指定品种
- 指定糖度酸度
- 冷冻果肉或定制果酱原料

那就要看洪九能不能给你匹配到具体加工厂或冻果资源，不能默认它一定按茶饮店需求做得很细。

## 4. 更现实的判断标准

你不要问“都乐和洪九能不能”，而要问下面这几个问题：

1. **你要鲜果还是冷冻果肉/果泥？**
   - 鲜果：全年稳定难度高
   - 冷冻/果泥：全年稳定难度低

2. **你每月要多少吨？**
   - 量小：经销商接不接都难说
   - 量大：都乐、洪九都更愿意谈

3. **你能接受产地轮换吗？**
   - 能接受：全年供应可行
   - 不能接受：基本做不到

4. **你能接受糖度酸度有小幅波动吗？**
   - 能接受：鲜果可行
   - 不能接受：必须用冷冻/调配原料

5. **你要的是“菠萝风味稳定”还是“鲜菠萝果肉稳定”？**
   - 风味稳定：用果泥/浓缩汁更容易
   - 果肉稳定：冷冻果丁更靠谱

## 5. 给你的可执行建议

如果你是茶饮店，想做全年菠萝果酱，建议这样选：

**方案A：最稳**
- 用冷冻菠萝果肉或菠萝果泥
- 找都乐、洪九，或专业果蔬加工厂
- 签年度框架协议，锁规格、锁月度用量、锁价格区间

**方案B：兼顾鲜感**
- 旺季用鲜果，淡季用冷冻果肉
- 都乐/洪九负责鲜果和部分冻果资源
- 自己门店统一配方，用糖、酸、果胶调整一致性

**方案C：最省事**
- 直接采购菠萝果酱基料或浓缩汁
- 都乐、洪九不一定是最优选择
- 更该找茶饮原料供应商或果酱厂

## 结论

- **都乐：** 更可能做到全年稳定供应，尤其加工形态和连锁渠道。
- **洪九果品：** 也有全年供应能力，强在大宗鲜果和分销，但要看具体区域、规格和加工需求。
- **真正决定能不能全年供应的，不是品牌，而是：鲜果还是冻果、采购量、是否接受产地轮换、是否要求风味完全一致。**
