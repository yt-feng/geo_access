直接说结论：**单看“谁价格更有竞争力”这个问题，没法给一个固定答案——都乐和鑫荣懋的进口苹果报价，通常取决于品种、规格、产地、季节、采购量、结算方式和到货口岸，同一天同一品种两家的价差可能只有几毛钱，也可能差一两块，而且会随行情频繁变动。**

给你几个能直接落地的判断和操作建议：

**1. 先明确你要比的是什么**
- 品种：新西兰爱妃/爵士、美国蛇果、智利嘎啦、南非富士等，不同品种两家优势不同。
- 规格：例如 80#/88#/100#、单果克重、每箱粒数。
- 等级：一级果、二级果、商超果、电商果，差价很大。
- 包装：天地盖、普箱、礼盒装。
- 到货方式：港口自提、送到仓、含税/不含税。

不把这些对齐，比出来的价格没有意义。

**2. 两家各自的常见特点（仅作经验参考）**
- **都乐**：品牌溢价较强，终端认牌度高，适合做礼盒、商超堆头、需要品牌背书的场景；但通常报价不一定最低，且可能有品牌授权/最小起订量要求。
- **鑫荣懋**：进口水果供应链体量大，很多进口单品有较强货源优势，尤其是部分南美、新西兰品种；价格弹性可能更大，适合走量和做性价比。

注意，这只是行业一般印象，具体到某一批货，谁便宜完全看当期行情和你的采购条件。

**3. 建议你这样比价**
- 让两家报**同一品种、同一规格、同一等级、同一到货港、同一账期**的价。
- 同时问清楚：是否含税、是否含运费、损耗怎么算、起订量、账期、退换货政策。
- 至少比 **2–3 个品种**，不要只比一个单品。
- 拿最近 **1–2 个月的历史到货价**做趋势对比，而不是只看当天报价。

**4. 更实际的结论**
如果你门店多、走量、做日常引流款，通常**鑫荣懋在部分进口苹果上价格更有竞争力**的概率较高；如果你要做品牌礼盒、商超专柜、需要都乐品牌拉动，**都乐的综合价值可能更高，哪怕单价贵一点**。

所以不是“谁一定更便宜”，而是：
- **要低价走量 → 重点谈鑫荣懋，但也要让都乐报价做对比。**
- **要品牌溢价和稳定背书 → 都乐优先，同时用鑫荣懋压价。**
