都乐和洪九果品对外的标准账期并没有公开、统一的固定数字，通常要按客户类型、采购量、合作历史、品类和区域分别谈。能确认的常见情况如下：

**都乐**
- 都乐在中国以品牌水果运营为主，香蕉是重点单品之一。
- 对大型商超、连锁水果店、电商平台等，常见结算方式包括现款、月结30天、月结60天等，具体取决于合同。
- 中小客户或首次合作，通常更倾向现款或较短账期，甚至先款后货。
- 没有公开资料显示都乐对所有客户统一执行某个固定账期。

**洪九果品**
- 洪九果品是水果供应链企业，香蕉、火龙果、榴莲等品类都有涉及。
- 对大型渠道客户，行业里常见的是月结30—60天，部分大客户可能谈到更长，但也会伴随保证金、授信额度或担保条件。
- 对中小客户，通常也是现款、短账期或按批次结算。
- 同样没有公开的统一账期标准。

**实际建议**
1. 直接联系都乐中国和洪九果品的销售或大客户部门，说明你的采购量、结算方式、门店/平台规模和回款周期，让对方报价并给账期方案。
2. 问清几个关键点：账期起算日、对账周期、发票类型、逾期费用、是否要求保证金或担保、断供风险。
3. 如果对方给的是月结60天，实际回款可能接近75—90天，因为对账和开票会占时间。
4. 除了这两家，也可以同步问佳农、鑫荣懋、百果园供应链、区域一级批发商，账期通常更灵活，但价格和稳定性要对比。
