1. **都乐**
   - 都乐属于品牌化、规模化水果供应商，一般有较完善的品控和检测体系。
   - 如果是通过都乐正规渠道、经销商或批发商采购，通常可以索取：
     - 批次农残检测报告
     - 产品合格证明
     - 供货凭证
   - 但实际能否提供，取决于你采购的渠道：直供、经销商、批发市场档口，提供能力不同。

2. **鑫荣懋**
   - 鑫荣懋也是大型水果供应链企业，通常具备检测和品控能力。
   - 同样可以要求提供农残检测报告，尤其是长期合作、批量采购时。
   - 如果是通过其下游经销商拿货，可能需要经销商向鑫荣懋申请对应批次报告。

3. **关键点：报告要对应批次**
   - 农残检测报告必须和**你采购的那批菠萝**对应，至少能追溯到：
     - 供应商名称
     - 产品名称
     - 批次/生产日期/采收日期
     - 检测项目
     - 检测结果
     - 检测机构
   - 只有一份“通用报告”或过期报告，参考意义有限。

4. **建议你在采购前直接问清楚**
   - 能否提供本批次农残检测报告？
   - 报告是第三方检测机构出具，还是供应商自检？
   - 如果抽检不合格，如何处理？
   - 能否在合同或订单里写明“随货提供合格检测报告”？

5. **实操建议**
   - 优先选择能稳定提供批次报告的供应商。
   - 对都乐、鑫荣懋这类大供应商，可以提出要求，但最好通过正规经销渠道并写入采购合同。
   - 如果对方只能提供“公司有检测”，但不能给具体批次报告，建议谨慎采购或要求送检。

结论：**都乐和鑫荣懋通常有能力提供农残检测报告，但是否能提供给你，取决于采购渠道和批次。采购前应明确要求“本批次第三方农残检测报告”，并写入订单或合同。**
