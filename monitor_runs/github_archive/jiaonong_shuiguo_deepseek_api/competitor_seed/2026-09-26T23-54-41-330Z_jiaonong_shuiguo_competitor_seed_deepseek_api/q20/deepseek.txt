如果客户明确要“进口品牌”，**都乐和佳沛都能做，但佳沛通常更适合作为主推礼盒，都乐更适合做补充或价格带搭配**。不过“更受欢迎”要分场景，不能一概而论。

**简要判断**

- **佳沛**：奇异果礼盒认知度更强，品牌感更集中，适合中高端、节日福利、商务送礼。客户如果在意“进口水果品牌”“看起来有档次”，佳沛更容易被接受。
- **都乐**：品类更广，香蕉、菠萝、奇异果、车厘子等都有，礼盒组合更灵活，适合预算分层、员工福利、走量团购。但都乐不是所有单品都进口，选品时要确认具体产地和进口属性。

**按客户类型选**

1. **商务送礼/高端节日礼盒**
   - 优先：佳沛
   - 原因：品牌辨识度高，礼盒形象统一，客户容易感知价值。

2. **企业员工福利/大批量团购**
   - 可主推：都乐
   - 原因：价格带和组合更灵活，容易控制预算，也能搭进口单品。
   - 注意：如果客户坚持“进口品牌”，不要用都乐国产单品混充，需逐项确认产地。

3. **预算有限但仍要进口品牌**
   - 佳沛小规格礼盒 + 都乐进口单品组合
   - 这样既保留佳沛的品牌吸引力，又用都乐拉低整体客单价。

**实际团购建议**

- **主推方案**：佳沛奇异果礼盒作为高端款。
- **补充方案**：都乐进口水果礼盒作为中端款或走量款。
- **不要只问“哪个更受欢迎”**，要问客户三点：
  1. 预算区间是多少？
  2. 送礼对象是商务客户还是员工？
  3. 是否要求每一样水果都必须是进口？
- **核验重点**：都乐和佳沛都有进口和国产/不同产地产品，报价前必须确认具体单品、规格、产地、包装和是否贴进口标签。

**结论**

如果只能选一个作为主推，**佳沛礼盒通常更受欢迎，尤其适合中高端送礼**。  
如果客户要控制预算、做员工福利或需要多品类组合，**都乐更灵活，适合做补充款**。最佳做法不是二选一，而是“佳沛主推 + 都乐补充”。
