大型商超（如沃尔玛、永辉、大润发、Costco、山姆等）在引入水果供应商时，通常要求提供以下核心食品安全与体系资质。下面分别说明鑫荣懋和都乐（Dole）通常具备的资质类型。需要说明：具体证书编号和有效期属于企业动态信息，我无法在此核验，建议直接向供应商索取或在全国认证认可信息公共服务平台查询。

## 一、商超通常要求的资质清单

1. **营业执照 / 食品经营许可证**（必备）
2. **ISO 22000 食品安全管理体系认证** 或 **FSSC 22000**
3. **HACCP 危害分析与关键控制点体系认证**
4. **GLOBALG.A.P.（全球良好农业规范）** —— 针对种植源头
5. **BRCGS 全球食品安全标准认证** —— 部分高端商超（如山姆、Costco）要求
6. **有机产品认证**（如供应有机品类）
7. **绿色食品认证 / 无公害农产品认证**（国内品类）
8. **出入境检验检疫 / 海关出口备案**（进口水果相关）
9. **可追溯体系证明**

## 二、鑫荣懋（深圳鑫荣懋果业科技集团）

鑫荣懋是国内头部水果供应链企业，通常具备：

- **ISO 9001 质量管理体系**
- **ISO 22000 / HACCP 食品安全体系**
- **GLOBALG.A.P. 认证**（其合作的种植基地）
- **食品经营许可证**
- 部分品类有**有机认证、绿色食品认证**
- 作为进口商，具备**海关进出口相关备案**

具体证书以其实际提供为准。

## 三、都乐（Dole）

都乐是全球性果蔬集团，通常具备：

- **GLOBALG.A.P.**（全球种植基地普遍认证）
- **ISO 22000 / FSSC 22000**
- **HACCP**
- **BRCGS**（部分加工/包装环节）
- 部分产品线有**有机认证**（如 USDA Organic、EU Organic）
- 跨国供应链的**可追溯与质量体系**

## 四、建议的可执行做法

1. **直接索证**：要求两家供应商提供最新证书扫描件（含证书编号、有效期、认证机构）。
2. **官方核验**：
   - 国内体系认证：在全国认证认可信息公共服务平台（cx.cnca.cn）查询。
   - GLOBALG.A.P.：在 GLOBALG.A.P. 官网数据库按 GGN 号查询。
3. **按商超标准比对**：确认目标商超的具体要求清单（不同商超门槛不同），逐项核对。
4. **注意区分主体**：集团、分公司、种植基地、加工厂的认证主体可能不同，需确认认证覆盖你采购的具体产品和工厂。
