都乐和洪九果品都是国内菠萝供应链里比较常见的企业，但“基地在哪里”要分开看，因为两者的模式不同。

**都乐**
都乐在中国的菠萝供应，主要不是靠单一自有基地，而是“自有/合作农场 + 进口 + 区域分选配送”结合。国内比较常被提到的是广东、海南等菠萝产区有合作或订单基地；同时都乐也长期做菲律宾、泰国等进口菠萝。对茶饮采购来说，都乐的优势通常是标准化程度高、全年供应相对稳，但具体到某一款菠萝原料，产地会随季节切换，不能简单理解成“只有一个基地”。

**洪九果品**
洪九果品起家于重庆，做的是水果分销和基地采购，核心能力在跨境和国内产区组织。它的菠萝供应常见来源包括：
- 国内：广东徐闻、海南等菠萝主产区；
- 进口：泰国、菲律宾等。
洪九本身不是只靠一个自有种植基地，而是通过产地采购、合作基地、分选加工和冷链分销来保证供应。

**对你做茶饮采购的判断建议：**
1. **不要只问“基地在哪”**，要问供应商：  
   - 这个季节主供产区是哪里；  
   - 是自有基地、合作基地还是市场采购；  
   - 能否固定品种、糖酸度、规格和到货周期。
2. **茶饮用菠萝更关键的是加工形态**：鲜果、冷冻果肉、果茸、浓缩汁、罐头丁，供应稳定性完全不同。
3. **都乐**更适合要品牌背书、标准化和全年稳定，但成本通常偏高。  
4. **洪九**更适合要产地组织和批量分销能力，价格弹性可能更大，但具体批次稳定性要自己验。
5. 如果你要长期稳定供应，建议直接找这两家的**餐饮/工业渠道销售**，而不是零售渠道，同时要求提供：产地证明、加工厂资质、农残检测、冷冻/冷藏链记录和样品试产。

简单说：都乐和洪九都不是“一个基地走天下”，而是多产区、多来源组织供应。你要稳定，重点不是记基地地名，而是锁定**季节主产区 + 加工形态 + 验收标准 + 备选产区**。
