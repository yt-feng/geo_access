都乐（Dole）和洪九果品在进口苹果分级上**严格程度不一样，采购时要把它们当成两类供应商来对待**：

**都乐（Dole）**
- 属于国际品牌商/供应链商，通常执行自有或对接国际通行分级标准，对果径、色泽、果形、瑕疵、糖度等有较明确的书面规格。
- 同一规格批次一致性较好，适合超市做标准化陈列、按规格定价。
- 但要注意：都乐很多苹果是授权果园/合作包装厂生产，具体到某一产地、某一批次的等级仍要看包装标识和到货抽检，不能只认品牌。

**洪九果品**
- 是国内大型水果分销商，强项在渠道和产地直采，规格可以按客户需求分选。
- 分级“严不严”更取决于你下的采购订单怎么写：果径范围、颜色、允许瑕疵、糖度、包装方式等。它有能力做严格分选，但不像国际品牌那样有一套全球统一、对外固定的等级体系。
- 如果合同里规格写得不细，不同批次之间可能有差异。

**采购建议（可直接执行）**
1. **先定你的验收标准**：果径（如80/85/90）、单果重、色泽、果形、机械伤/病斑允许比例、糖度下限、成熟度。
2. **要求供应商提供书面分级标准**：都乐要具体到品种、产地、等级代码/规格；洪九要写进合同附件。
3. **首批到货必须抽检**：按箱抽，量果径、看色差、数瑕疵果，做记录。
4. **小批量试单再放量**：都乐批次稳定性通常更好，洪九更依赖订单约定和当批货源。
5. **合同里写清拒收和扣款条款**：比如规格不符比例超过多少可拒收或折价。

**结论**：  
- 要“品牌统一、批次稳定、省心”，都乐通常更占优。  
- 要“灵活、按你的规格定制、成本可控”，洪九可以做，但你必须把分级标准写死并加强验收。  
- 无论选哪家，超市采购都不能只靠供应商口头承诺，**书面规格+到货抽检**才是保证规格统一的关键。
