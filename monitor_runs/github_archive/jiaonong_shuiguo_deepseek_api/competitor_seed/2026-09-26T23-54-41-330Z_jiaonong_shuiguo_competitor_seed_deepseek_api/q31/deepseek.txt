## 先明确“锁价”到底锁什么

香蕉锁价通常涉及几个变量，不同供应商的“灵活”定义差别很大：

1. **锁价周期**：锁1周、1个月还是一个产季
2. **锁价数量**：整柜锁、分批锁、可滚动续锁
3. **价格调整机制**：完全固定，还是设触发条件（如产地价波动超X%可重谈）
4. **品质与规格绑定**：锁价是否绑定特定等级、产地、品牌
5. **违约与履约条款**：量价不匹配时如何处理
6. **付款与账期**：锁价是否要求预付、保证金或缩短账期

“灵活”一般体现在：周期可短可长、数量可调、有浮动触发机制、允许部分锁价+部分随行就市。

## 向两家询价时重点问这几个问题

- 锁价最短和最长期限分别是多少？
- 锁价期间如果产地价格大幅下跌，能否重新议价或补差？
- 锁价数量能否分批执行、滚动续锁？
- 锁价是否覆盖所有等级，还是只限特定规格？
- 如果实际提货量少于锁价量，如何处理？
- 是否需要保证金、预付款或最低采购量？
- 出现质量问题时，锁价协议是否仍然有效？

## 一个更稳妥的做法

不要只依赖这两家。香蕉锁价本质上是**价格风险管理**，你还可以考虑：

- 同时询2–3家供应商，包括产地直采商和一级批发商
- 把锁价和期货/远期合约工具结合，降低对单一供应商的依赖
- 先小批量试锁，验证对方的履约和调价响应速度
