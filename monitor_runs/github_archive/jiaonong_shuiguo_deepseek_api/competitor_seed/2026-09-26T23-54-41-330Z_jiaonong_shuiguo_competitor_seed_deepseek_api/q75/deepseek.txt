直接说结论：**公开渠道查不到“洪九果品 vs 都乐香蕉”可核验的官方到货损耗率对比数据**。这类损耗率属于企业内部经营数据，通常只在年报、招股书、投资者交流或内部品控文件里才会出现，且口径（产地损耗/冷链损耗/到货损耗/门店损耗）差异很大，不能直接横向比。

能确定的是逻辑上的差异，而不是具体数字：

1. **都乐（Dole）香蕉**
   - 优势：品牌方自有/合作种植园、采后处理标准化、催熟和冷链体系成熟，到货一致性通常更好。
   - 到货损耗通常体现在：机械伤、催熟不均、青黄比例、仓储温控波动。
   - 如果你是批发市场拿货，损耗更多取决于**你拿的是几级货、是否经过二次分拣、运输距离和卸货方式**，而不是“都乐”三个字本身。

2. **洪九果品**
   - 优势：国内水果分销规模大，香蕉是其核心品类之一，渠道覆盖广，价格和货源稳定。
   - 但洪九本质是**分销/供应链平台**，不同批次可能来自不同产地、不同加工厂，品控一致性不如都乐这种品牌化程度高的单品。
   - 到货损耗更依赖：你拿的批次、等级、包装规格、是否打冷、运输时效、市场端存放条件。

3. **实操判断建议**
   - 不要只看品牌，先看**批次和等级**：同品牌不同批次损耗可能差一倍。
   - 到货当天做抽检：随机开3-5箱，统计：
     - 机械伤/压伤比例
     - 霉变/黑星/炭疽比例
     - 青果、黄果、过熟果比例
     - 单箱净重是否达标
   - 连续记录3-5车，算你自己的**实际到货损耗率**，比任何品牌宣传都准。
   - 如果做批发，优先谈**到货验收标准、扣重规则、售后理赔**，这比纠结品牌损耗率更有用。

4. **如果你要的是行业参考值**
   - 香蕉批发环节到货损耗，行业里常见区间大约是 **3%-8%**，冷链好、等级高、距离短可做到 **2%-5%**；管理差、二次转运多、天气热可到 **8%-15%**。
   - 但这个区间不能直接套到洪九或都乐某一个品牌上，只能作为你验货时的参照。
