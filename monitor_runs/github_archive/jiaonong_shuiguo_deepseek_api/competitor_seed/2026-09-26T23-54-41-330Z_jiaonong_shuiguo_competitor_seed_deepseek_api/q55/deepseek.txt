都乐（Dole）和洪九果品都属于有自有/合作种植基地、能做产地溯源的水果供应链企业，但两家模式不同，是否“基地直供”要分开看。

**都乐Dole**
- 有自有农场和长期合作种植基地，主要菠萝产区包括菲律宾、泰国、哥斯达黎加等，国内也有合作基地。
- 通常能提供批次、产地、加工厂信息，部分产品可做到包装码/批次溯源。
- 适合对品牌、标准化、出口级品质要求高的渠道。
- 但“直供”一般指通过其中国公司或授权经销商体系供货，不是农场直接对你发货，中间仍有分选、加工、冷链环节。

**洪九果品**
- 是国内头部水果分销商，核心模式是“基地+加工厂+批发市场/商超/电商”供应链。
- 在泰国、越南、菲律宾等有合作或自建基地，菠萝是其重点单品之一。
- 溯源能力通常体现在批次、产地、报关、检测报告等环节。
- 更适合大批量、多品类、稳定走货的采购方，但直供也多是经过其加工分选中心。

**判断建议**
1. 如果你要的是“农场到仓”的短链直供，都乐和洪九都不算严格意义上的农场直发，更多是基地直采+加工分选后供货。
2. 如果你要的是“可溯源、有基地证明、批次可查”，两家都能谈，但需要具体到单品、产区、季节和采购量。
3. 真正要核实，建议直接要求供应商提供：
   - 基地证明或合作基地协议
   - 出口/报关或产地证明
   - 批次检测报告
   - 包装追溯码或批次号规则
   - 加工厂和冷链节点信息

**更实际的采购路径**
- 要品牌化和稳定标准：优先问都乐中国及其授权经销商。
- 要大批量、多产地、价格弹性：优先问洪九果品及其区域供应链公司。
- 要更短链、更低价：可以同时找海南、广东、云南、福建等国内菠萝主产区的合作社或种植基地，但溯源体系通常不如都乐、洪九完整。
