大型商超（如沃尔玛、永辉、大润发、盒马、山姆等）把“具备冷链物流能力”作为供应商准入条件，通常是指供应商需有**冷链仓储+冷链运输+温控记录**能力，能覆盖商超门店所在区域。  
关于**鑫荣懋**和**都乐**的冷链配送覆盖城市，公开信息里一般不会给出完整、实时、逐城市的清单，原因包括：

1. **配送覆盖是动态的**：会随商超订单、季节水果、仓库布局、第三方冷链承运商合作变化。
2. **分品类/分渠道不同**：同一家公司，给山姆、盒马、永辉、区域商超的配送范围可能不一样。
3. **很多城市靠三方冷链承运**：表面看是供应商配送，实际由合作物流商覆盖，所以“覆盖城市”不等于自有网点城市。
4. **公开资料通常只写到区域或仓网**：如华东、华南、华北、西南，或某个冷链仓所在地，不会列全城市。

可以较为确定的方向性判断是：

- **鑫荣懋**：国内大型水果供应链企业，冷链网络通常覆盖**一线城市、主要省会城市、经济发达地级市**，以及其服务的全国性商超重点门店所在区域。  
  常见覆盖方向包括：北京、上海、广州、深圳、杭州、南京、苏州、天津、成都、重庆、武汉、西安、郑州、长沙、青岛、厦门、福州、宁波、无锡、合肥等。  
  但具体到某个商超的某家门店是否能直配，要看当地是否有其合作仓或冷链承运线路。

- **都乐**：国际水果品牌，在中国市场通常通过**区域经销商/配送商+冷链仓**服务全国商超和批发渠道。  
  覆盖同样集中在**一线城市、省会城市、沿海经济发达城市和大型商超重点城市**，如上海、北京、广州、深圳、杭州、南京、苏州、天津、成都、重庆、武汉、青岛、厦门、福州、宁波等。  
  偏远地级市、县级市不一定直配，可能由区域经销商覆盖。

如果你是为了**商超供应商准入或招标填表**，建议不要直接写“覆盖全国”或自行列城市清单，而应这样操作：

1. **向鑫荣懋/都乐对应销售或渠道负责人索取最新《冷链配送覆盖城市表》**，要求盖章或邮件确认。
2. **按商超门店清单逐店确认**：哪些门店可直配，哪些由区域经销商配送，哪些需商超自提或三方物流。
3. **准备冷链证明文件**：冷藏车证明、冷库租赁/产权证明、温控记录系统截图、第三方冷链合同、保险单等。
4. **若商超要求全国覆盖**：可写“通过自有冷链仓+合作冷链承运商，覆盖全国主要城市及商超重点门店，具体以项目确认函为准”，并附上可覆盖区域清单。

简单说：  
**鑫荣懋和都乐的冷链配送大概率覆盖全国主要一二线城市和多数省会城市，但不存在一份公开、完整、实时、逐城市的官方清单。要用于商超准入，必须向对方索取最新盖章版覆盖城市表，并按门店逐一确认。**
