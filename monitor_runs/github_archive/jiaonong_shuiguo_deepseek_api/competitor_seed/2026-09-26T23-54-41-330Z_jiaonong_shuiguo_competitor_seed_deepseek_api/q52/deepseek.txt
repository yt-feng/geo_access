都乐和鑫荣懋的到货损耗率没有公开的官方统一数据，实际会随**批次、产季、运输方式、到货城市、验收标准、加工方式（鲜切/去皮/整果）**波动。茶饮采购里更可靠的做法是：拿你自己的验收口径做同批次对比测试，再写进采购标准。

可以按下面框架快速判断和落地：

**1. 先定义“损耗率”口径**
建议至少分三档统计，否则不同供应商数字不可比：
- 到货损耗率＝（到货总重－验收合格重）/到货总重
- 仓储损耗率＝（入库合格重－出库可用重）/入库合格重
- 加工损耗率＝（出库可用重－实际入杯/入桶净料重）/出库可用重
茶饮菠萝常见问题：青皮、黑心、水心病、果眼深、大小不均、成熟度不齐、压伤、霉变。

**2. 都乐和鑫荣懋的通常差异**
- 都乐：标准化、分级和冷链通常更稳，适合对规格一致性要求高的门店；但价格通常更高，不同批次仍会有成熟度和压伤波动。
- 鑫荣懋：渠道覆盖广、性价比通常更好，适合做多产地调配；但规格稳定性更依赖具体产地、批次和合同等级。
所以不能简单说“谁损耗一定低”，要看你采购的是**鲜果整果、去皮果、冷冻果块还是果浆**。

**3. 建议的实测方法**
选同一到货日、同一规格、同一运输条件的各3批：
- 每批抽检不少于30kg或30个果
- 记录：到货总重、合格重、坏果重、需催熟重、加工后净重
- 连续做2–4周，按周算加权平均
- 同时记录到货温度、运输时长、产地、采摘/加工日期

**4. 采购合同里建议写死的指标**
- 品种/产地/规格：如单果重、果径、成熟度、糖度范围
- 验收标准：黑心、水心、霉变、压伤、青果比例上限
- 损耗责任：到货损耗超过约定比例如何扣款、补货或退货
- 加工出成率：去皮去眼后净料率下限
- 批次一致性：允许的成熟度/糖度/大小波动范围

**5. 实操结论**
如果你要“稳定规格优先”，先小批量对比都乐与鑫荣懋同一规格，连续测2–4周，按“到货损耗率＋加工出成率＋单价折算净料成本”一起算，而不是只看采购单价。净料成本＝采购单价÷（1－到货损耗率）÷（1－加工损耗率），这个数字才直接决定茶饮毛利。
