这个问题没有统一答案，因为“质量更稳定”取决于**具体批次、产地、品种和到货渠道**，不能简单说都乐或鑫荣懋哪家绝对更好。可以给你一个可执行的判断框架：

**1. 先看品牌定位和常见表现**
- **都乐**：国际水果品牌，标准化、分级、包装和冷链体系通常较成熟，适合对规格一致性、外观和货架期要求高的超市。但不同产地和季节差异也很大。
- **鑫荣懋**：国内大型水果供应链企业，进口水果操作能力强，渠道覆盖广，部分单品如苹果、奇异果等有较强供应链。稳定性更多取决于它给你供的是哪个产区、哪条线。

**2. 真正决定稳定性的不是品牌名，而是这几点**
- **产地**：新西兰、美国、智利、南非等不同产区，硬度和酸甜比差异明显。
- **品种**：富士、嘎啦、红玫瑰、爱妃等耐储性不同。
- **批次**：同一品牌不同船期、不同冷库，质量可能波动。
- **冷链**：到店后是否有断链，比品牌本身更影响货架期。
- **等级规格**：是否统一果径、着色度、糖度、硬度标准。

**3. 超市采购建议这样比**
- 要求两家各提供**同一品种、同一产区、同一规格**的样品。
- 连续拿**3个批次**做对比，而不是只看一次。
- 重点测：糖度、硬度、果径均匀度、着色、碰伤率、烂心率、货架期。
- 看**到店验收合格率**和**售后赔付响应**。
- 如果做长期稳定供货，优先选能固定产区、固定包装线、能提供质检报告的供应商。

**4. 简单结论**
- 如果追求**标准化和品牌背书**，都乐通常更稳。
- 如果追求**国内渠道响应、成本控制和灵活供货**，鑫荣懋可能更有优势。
- 但最终谁更稳，必须用**你所在超市的实际到货批次数据**来判断。
