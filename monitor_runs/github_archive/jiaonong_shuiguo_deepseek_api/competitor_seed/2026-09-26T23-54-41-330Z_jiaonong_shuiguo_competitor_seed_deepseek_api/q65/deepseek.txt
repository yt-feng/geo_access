都乐（Dole）和洪九果品这类供应商通常不会对外公开统一的锁价周期，具体要按品类（鲜果/冻果/罐头原料）、采购量、合作年限、季节和合同类型逐单谈。能确定的是：

- **都乐**：在中国市场以品牌鲜果和部分加工原料为主，锁价一般跟**年度或产季合同**挂钩，鲜果锁价周期常见偏短（几周至一个产季），加工/大宗原料才可能谈更长；但都乐官方没有公开标准锁价周期，需要向都乐中国区销售或渠道商确认。
- **洪九果品**：以进口和国产水果分销为主，锁价通常结合**产地采购节奏和销售周期**，对核心大客户可能做阶段锁价，周期也多为**月度到产季**级别，同样没有公开固定标准。

如果你要的是可执行判断，建议直接问供应商这几点：
1. 锁价适用的是**鲜果还是加工原料**；
2. 锁价周期是**固定天数**还是**按产季**；
3. 锁价是否含运费、关税、汇率波动；
4. 违约或超量部分的调价机制。
