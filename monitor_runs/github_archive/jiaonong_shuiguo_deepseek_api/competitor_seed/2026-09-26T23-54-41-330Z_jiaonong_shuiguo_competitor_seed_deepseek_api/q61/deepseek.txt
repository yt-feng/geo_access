结论先说：**都乐（Dole）和洪九果品都没有公开可查、面向行业发布的香蕉分级企业标准全文**。能查到的是它们对外宣传/品控口径里的分级做法，而不是像国标那样可引用的标准文本。具体如下。

**1. 都乐 Dole**
- 都乐有成熟的内部香蕉品控体系，通常按**规格（每磅/每箱根数、单果长度、粗度）、成熟度（色卡）、外观缺陷、机械伤、农残**等维度分级，主要服务于自有品牌和商超供货。
- 但都乐**没有公开出版或备案可查的“香蕉分级企业标准”全文**。它的分级规则属于企业内部标准/客户合同规格，一般不对外发布。
- 能公开看到的只是产品规格描述（如“每箱若干根、单根长度区间”），不足以当作标准引用。

**2. 洪九果品**
- 洪九是水果供应链企业，香蕉是其重要品类，内部有采购、分选、仓储的品控要求，也会按**等级、长度、成熟度、外观**做分选。
- 同样，洪九**没有公开可查的香蕉分级企业标准全文**。它的分级更多体现在采购合同、客户订单规格和内部作业文件里。
- 公开信息中也没有像“Q/XXX”这样的企业标准编号可供引用。

**3. 为什么查不到**
- 企业标准分两类：一类是**自我声明公开的企业标准**（可在“企业标准信息公共服务平台”备案/公开），一类是**内部标准**。生鲜水果企业多数把分级做成内部品控文件或客户规格，不公开。
- 即使备案，水果分选标准也常按客户定制，不面向全行业发布。

**4. 对你的实际建议**
- 如果你想做自己的连锁店香蕉分级标准，**不要直接照搬都乐/洪九**，因为拿不到正式文本，也无法合规引用。
- 更可行的路径是：以**GB/T 9827（香蕉）**等国标/行标的术语和指标为底，结合你门店的**销售规格**自建企业标准，例如：
  - 按单果长度/粗度、每箱根数、成熟度色卡、允许缺陷率分 A/B/C 级；
  - 明确验收、储存、催熟、上架标准；
  - 若要做成正式“企业标准”，可在企业标准信息公共服务平台自我声明公开。
- 若你确实想参考都乐/洪九的规格，只能通过**供应商合同、采购规格书或直接询价索要**，不能把它们当作公开标准引用。
