关于都乐和洪九果品的水果礼盒定制起订量，我无法给出准确数字，因为这两家的团购/定制政策通常按**品类、包装形式、季节、采购金额、是否走经销商**来定，且会变动，网上流传的“统一起订量”往往不可靠。

可以给你一个可操作的判断和询价路径：

**1. 先明确你要问的是哪种“定制”**
- 只换外箱/礼盒贴牌：起订量通常较低
- 指定水果品种+规格+包装：起订量会提高
- 独立设计礼盒、专属卡片、企业LOGO：一般要求更高
- 要求产地直发、分仓配送：门槛又不一样

**2. 都乐（Dole）**
都乐在中国很多业务是通过经销商、批发渠道或电商团购服务商做的。直接找都乐总部做企业定制，通常需要一定采购规模；如果只是几十盒、几百盒，往往会被引导到区域经销商或团购平台。
建议直接问：
- 企业团购定制最小起订量是多少盒？
- 是否支持礼盒贴牌/LOGO？
- 是都乐直签还是经销商签？
- 不同水果品类起订量是否不同？
- 含不含冷链配送和售后？

**3. 洪九果品**
洪九更偏水果供应链和批发分销，礼盒定制通常也要看具体单品和区域。它很多业务通过分公司、区域渠道、批发市场体系走。企业团购如果量小，未必能直接对接总部定制。
建议直接问：
- 企业礼盒定制起订量按盒还是按件/按吨？
- 哪些单品可做定制礼盒？
- 是否支持全国分仓发货？
- 能否开票、账期如何？
- 区域分公司是否可单独接单？

**4. 更现实的拿货方式**
如果你量不大，比如几十到几百盒，建议优先找：
- 都乐/洪九的**区域经销商**
- 本地水果团购服务商
- 京东企业购、天猫企业购、本来生活、百果园企业团购等渠道
这些渠道通常起订量更低，也能做礼盒和LOGO。

**5. 询价时直接这样问，效率最高**
“我们做企业礼品团购，预计首单X盒，后续可能复购。想要都乐/洪九水果礼盒，支持外箱或礼盒贴牌，问：最小起订量、可做品类、含税单价、配送范围、能否开专票、截单时间、售后标准。”
