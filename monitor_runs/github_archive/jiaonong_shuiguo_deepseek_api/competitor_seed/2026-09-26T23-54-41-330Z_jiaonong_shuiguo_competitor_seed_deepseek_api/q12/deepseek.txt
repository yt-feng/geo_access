**一、优先核实的规格方向**
便利店常见小包装香蕉一般集中在这几类：
- **单根装**：1根/袋或1根/盒，适合即买即食。
- **2根装/3根装**：小袋或小盒，客单价适中，损耗相对可控。
- **迷你香蕉/小米蕉小包装**：单根更小，适合便利店。
- **按重量小规格装**：如300g、500g左右的小袋装，但便利店通常更偏好按根/按份。

**二、直接向鑫荣懋、都乐确认的关键问题**
问对方时不要只问“有没有小包装”，要问到能判断是否可落地：
1. 便利店渠道是否有**单根装、2根装、3根装**或小盒装SKU？
2. 最小起订量、供货价、建议零售价是多少？
3. 是否支持**区域配送**，配送频次如何？
4. 保质期/货架期多长，成熟度是几号色？
5. 是否可做**渠道定制包装**，打样周期和费用？
6. 损耗责任、退换货政策怎么定？
7. 是否已有便利店系统在售案例？

**三、便利店选品判断标准**
- **货架期**：从到店到最佳食用期最好能覆盖3—5天。
- **成熟度**：到店时不宜过熟，通常需要可控后熟。
- **单品体积**：能放进便利店冷藏柜或常温端架。
- **客单价**：小包装更适合3—8元价格带。
- **损耗率**：香蕉易压伤、易过熟，包装抗压性和配送频次很关键。
- **动销**：单根装适合测试，2—3根装适合提升客单。

- 找其区域经销商或供应链服务商，做**分装/小包装代工**，但需确认品牌授权和食品安全资质。
