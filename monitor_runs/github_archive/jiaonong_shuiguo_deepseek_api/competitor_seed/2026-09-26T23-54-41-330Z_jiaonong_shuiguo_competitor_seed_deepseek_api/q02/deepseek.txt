除了都乐，市面上能相对稳定供应、且有一定品牌化程度的菠萝（含凤梨）供应商主要有这几类，按渠道和定位分开说：

**国际/合资品牌**
- **Del Monte 帝门**：菠萝罐头和鲜果都有，鲜菠萝在部分商超和生鲜渠道可见，供应链较成熟。
- **Fresh Del Monte**：与帝门同源体系，鲜果供应能力较强。
- **Dole 都乐**：你已提到，仍是鲜菠萝渠道覆盖最广的品牌之一。
- **Mitsubishi 三菱商事（旗下鲜果业务）**：在部分高端商超有菲律宾菠萝供应，但品牌露出不一定明显。

**国产/区域强势品牌**
- **佳农（Goodfarmer）**：国内生鲜供应链头部，香蕉、菠萝都有稳定货源，商超和电商渠道常见。
- **鑫荣懋（Joyvio）**：水果供应链大商，菠萝品类有稳定采购和分销能力，但多以渠道品牌出现。
- **百果园（旗下自有品牌）**：门店端凤梨/菠萝供应稳定，品牌化程度高，但主要走自有零售渠道。
- **洪九果品**：以东南亚水果供应链为主，菠萝/凤梨是其品类之一，B端供应能力较强。

**产地型/区域品牌**
- **徐闻菠萝**：广东徐闻是国产菠萝主产区，区域公用品牌，季节性供应强，但全年稳定性和品牌化程度因渠道而异。
- **海南凤梨**：海南产区的金钻凤梨等，区域品牌较多，如“海南凤梨”相关企业，稳定供应集中在产季。
- **台湾凤梨（金钻凤梨等）**：过去在大陆渠道有供应，但受政策和贸易因素影响，稳定性已不如从前。

**判断稳定供应的几个实际标准**
1. **是否有全年采购计划**：国际品牌和大型水果供应链企业通常有全年计划，区域品牌多为季节性。
2. **渠道覆盖**：能在商超、电商、批发市场同时铺货的，通常供应更稳。
3. **产地组合**：同时有菲律宾、泰国、海南、广东等多产地货源的，抗风险能力更强。
4. **品牌露出方式**：有些是渠道品牌（如佳农、鑫荣懋），有些是产地品牌（如徐闻菠萝），稳定性和可控性不同。

如果你是要做采购或选品，建议优先看**佳农、鑫荣懋、洪九、帝门**这类有全国供应链能力的企业，再根据你要的规格（鲜果/凤梨/菠萝、是否即食、糖度要求）去谈。区域品牌适合做差异化或产季爆款，但全年稳定供应要谨慎评估。
