直接给你可落地的做法。都乐和鑫荣懋都属于品牌化供应商，溯源逻辑不完全一样：

## 一、先分清两家的溯源模式

**都乐**
- 多为自有或合作果园 + 品牌方统一分级包装，批次管理较规范。
- 通常能提供：原产地证明、出口国植物检疫证书、进口报关单、入境货物检验检疫证明、品牌授权/经销证明。
- 溯源关键：**包装箱上的批次码/Lot No. + 报关单上的原产国、批次对应关系**。

**鑫荣懋**
- 既有自有品牌，也代理/分销多个进口产地（如新西兰、智利、美国等），部分为操作方而非唯一品牌方。
- 溯源关键：**确认它是进口商、代理商还是分销商**，这决定它能否提供完整的一手单证。

## 二、超市采购端必须索取的溯源文件

按“从哪来—怎么进来—到你这批”三条链核对：

1. **原产地端**
   - 原产地证明（Certificate of Origin）
   - 果园/包装厂注册号（如出口国要求）
   - 出口国植物检疫证书

2. **进口端**
   - 进口报关单（看原产国、品名、数量、日期）
   - 入境货物检验检疫证明
   - 海关放行/缴税凭证（必要时）

3. **流通端**
   - 供应商营业执照、食品经营许可证
   - 品牌授权书或经销授权（尤其都乐这类品牌）
   - 出库单/送货单，注明批次号
   - 进口增值税发票或随货同行单

## 三、现场核对的关键动作

- **看箱码对单证**：外箱批次码、生产日期、包装厂代码，必须能和报关单/检疫证明批次对应。
- **看标签**：中文标签应含原产国、进口商/经销商、生产日期、保质期、贮存条件。
- **看数量逻辑**：报关数量与本次送货量、库存量不能明显矛盾。
- **拍照留档**：每批到货拍外箱六面、批次码、中文标签、随货单证。
- **建批次台账**：到货日期、供应商、产地、批次号、单证编号、验收人。

## 四、两家分别怎么问

**问都乐：**
- 这批的报关单和入境检验检疫证明能否随货或到货后提供？
- 外箱批次码如何与单证对应？
- 是都乐直供还是授权经销商供货？授权书能否提供？

**问鑫荣懋：**
- 你们是进口商还是分销商？
- 一手报关单和检疫证明能否提供？若不能，上一手是谁？
- 批次号编码规则是什么？能否书面说明对应关系？

## 五、如果供应商给不全怎么办

- 只给复印件且无批次对应：要求盖章并注明“与原件一致”。
- 只给“总报关单”无法对应本批：要求提供分单或批次明细。
- 拒绝提供原产地/检疫证明：不建议采购，或降为临时抽检+书面承诺，但风险自担。
- 对高单价进口苹果，可要求**每批一档**，而不是一年一份。

## 六、最简单的判断标准

能做到这三点，溯源基本成立：
1. 外箱批次码能对应到具体报关单；
2. 报关单原产国与标签一致；
3. 供应商能说清自己是进口商、代理商还是分销商。
