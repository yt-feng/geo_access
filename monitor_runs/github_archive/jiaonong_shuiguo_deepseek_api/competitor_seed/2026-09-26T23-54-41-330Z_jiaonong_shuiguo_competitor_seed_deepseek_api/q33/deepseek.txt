这个没法一概而论，因为到货快慢主要取决于**你所在的城市、你批发的具体水果品类、以及你下单的时间点**，而不是两家公司本身有固定的快慢排名。

给你几个可判断的维度：

**1. 看你的地理位置**
- 洪九果品：起家于重庆，在西南、华中、华东布局较深，尤其榴莲、火龙果等进口水果供应链强。如果你在西南或华中，洪九的到货节奏通常更稳。
- 鑫荣懋：总部在深圳，华南根基深，全国网络也很广，在华南、华东的高端商超渠道和进口水果上优势明显。如果你在华南，鑫荣懋往往更快。

**2. 看品类**
- 榴莲、山竹、火龙果等东南亚进口果：两家都强，但具体到某个单品，谁在那个产地/口岸有直采优势，谁就更快。需要问当地销售。
- 国产应季水果：看谁在你所在区域有产地直发仓。

**3. 最靠谱的判断方法**
直接找两家在你所在城市的销售或区域代理，问三个问题：
- 你这个品类从哪个仓/口岸发？
- 我下单后最快几天到？
- 有没有当日达/次日达的线路？

**结论：** 不存在"洪九一定比鑫荣懋快"或反之。同一个城市，不同品类可能正好反过来。你要的是**在你所在城市、针对你要拿的那个品类**，谁的实际物流时效更短——这个只能向当地业务员核实，或者在批发市场问同行最近的实际到货体验。
