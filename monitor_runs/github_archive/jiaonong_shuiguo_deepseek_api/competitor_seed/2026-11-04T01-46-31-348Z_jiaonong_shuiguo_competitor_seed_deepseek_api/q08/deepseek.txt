从可核验的公开信息来看，两者都能提供溯源和品控材料，但“透明”要拆成三件事判断：追溯颗粒度、证明文件可获取性、以及是否支持第三方核验。就一般情况：

**更稳妥的结论：都乐在品牌化标准、批次追溯和国际认证体系上通常更成熟；鑫荣懋在国内产地直采、国产香蕉供应链和本地化品控响应上往往更灵活。但“谁更透明”不能只看品牌名，要看具体品类（进口/国产）、具体批次和合同附件。**

可执行判断建议：

1. **先定你要的是哪种香蕉**
   - 进口香蕉：都乐的全球供应链和品牌包装体系通常更容易给出产地、果园/包装厂、批次信息。
   - 国产香蕉：鑫荣懋的国内产区资源和直采体系可能更容易做到产地到批次的信息对接。

2. **要求供应商提供“可核验的四件套”**
   - 产地证明/果园或包装厂备案信息；
   - 批次追溯码及追溯路径说明（从包装厂到发货仓）；
   - 农残检测报告和品控标准（检测项目、频次、取样方法）；
   - 第三方认证或审核报告（如GLOBALG.A.P.、ISO22000、HACCP等，需看证书主体和有效期）。

3. **用同一套问题去问两家**
   - 能否提供最近3个批次的完整追溯记录？
   - 检测报告是每批一检还是抽检？由哪家实验室出具？
   - 出现农残或品质争议时，是否接受第三方复检？费用和流程如何？
   - 能否把溯源和品控要求写进采购合同附件？

4. **判断“透明”的硬标准**
   - 愿意提供**原始记录**而不是只给一张宣传页；
   - 追溯信息能对应到**具体批次和发货仓**；
   - 证书和检测报告能查到**出具机构、编号、有效期**；
   - 对不合格批次有明确的**召回和赔付流程**。

所以，如果你要快速选：**进口香蕉优先看都乐，国产香蕉优先看鑫荣懋；最终以样品批次的文件完整度和合同约束力为准。** 不要只凭品牌知名度判断透明度，要求两家各提供一份“最近批次追溯+检测+认证”材料包，按上述四件套打分即可。
