都乐（Dole）和洪九果品的菠萝供应基地，公开信息可以这样看：

**都乐（Dole）**
- 都乐在中国市场的菠萝主要来自自有/合作种植基地，公开可查的核心产区包括：**菲律宾**（都乐全球重要菠萝产地，进口至中国）、**中国广东徐闻**（都乐在徐闻有合作/订单农业基地，徐闻是中国最大菠萝产区之一）、以及**海南**等产区。
- 都乐在**广东湛江徐闻**有菠萝采购/合作基地布局，这是国内菠萝稳定供应的重要来源。
- 具体基地地址和产能属于商业信息，建议直接联系都乐中国（上海都乐食品有限公司）采购部门确认当季供应量和产地。

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，其菠萝来源以**泰国**（如小菠萝/香水菠萝）和**中国海南、广东**为主，通过“基地直采+口岸通关”模式供应。
- 洪九在**泰国**有榴莲、山竹、菠萝等东南亚水果的采购基地和加工厂；国内在**海南、广东**有菠萝采购网络。
- 洪九果品近年经营出现较大波动（2023年后财报延迟、停牌等），**供应稳定性需重点核实**，建议确认其当前是否正常履约。

**给采购的可执行建议：**
1. 都乐：联系都乐中国官方采购/销售渠道，索取当季菠萝产地证明和供应计划；徐闻基地可实地或委托验厂。
2. 洪九：先核实其当前经营和履约能力（是否正常发货、账期），不宜作为单一稳定来源。
3. 备选稳定来源：**广东徐闻**（国内最大菠萝产区，3-5月旺季）、**海南万宁/琼海**、**菲律宾进口**（都乐、Del Monte等）；可同时对接徐闻本地大型合作社或加工厂做第二供应商，降低单一供应商风险。
4. 要求供应商提供：产地证明、农残检测报告、冷库/加工能力、月度可供量承诺。

具体基地地址和实时产能，公开资料难以精确核验，建议以供应商书面确认为准。
