都乐（Dole）和洪九果品的账期没有公开统一标准，通常按客户类型、采购量、合作年限、合同条款逐单谈，不能直接给出固定天数。可判断的参考如下：

1. **都乐（Dole）**  
   - 属于国际品牌商/大型水果企业，国内多为经销、直供商超或餐饮客户。  
   - 对新客户一般要求现款现货或预付；稳定大客户才可能给账期，常见方向是月结，但是否给、给多少天取决于合同和信用审核。  
   - 不建议按“品牌统一账期”去谈，应直接找区域销售或大客户渠道询价并申请信用账期。

2. **洪九果品**  
   - 以水果分销、批发和供应链为主，客户包括商超、电商、批发商等。  
   - 账期同样不是公开固定政策，通常与采购规模、合作稳定性、品类和回款风险有关；新客户多为现款或短账期，大客户可谈月结。  
   - 应联系其销售/供应链业务人员，明确采购量、结算周期、保证金或担保条件。

**可执行建议：**
- 向两家供应商分别索要《客户信用申请表》或《账期政策说明》，重点问：新客户是否可给账期、最长多少天、是否收保证金、逾期利息、是否要求担保。
- 谈判时准备：营业执照、近半年采购/销售流水、下游客户合同、可接受的预付款比例。
- 不要只问“账期多久”，要问清结算起算点：发货日、到货日、对账日还是开票日；这直接决定实际资金占用。
- 如果对方不给账期，可谈“部分预付+尾款月结”或“首单现款、连续合作3个月后申请账期”。

如需精确天数，只能以两家供应商当前区域销售给出的书面报价/合同为准，公开信息无法核验固定账期。
