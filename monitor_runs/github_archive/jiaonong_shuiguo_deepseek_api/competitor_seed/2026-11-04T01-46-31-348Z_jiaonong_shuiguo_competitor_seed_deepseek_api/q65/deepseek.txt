我不能可靠核验都乐和洪九果品当前的锁价周期，直接给具体天数会是猜测。可执行判断如下：

1. **都乐（Dole）**：锁价通常不是公开标准政策，多按客户规模、年度框架协议、品类和产季单独谈；菠萝这类鲜果受产季和海运影响，锁价周期往往较短，常见做法是月度/产季分段锁价，但需向都乐中国区B2B销售或大客户渠道确认。
2. **洪九果品**：同样以框架协议和订单协商为主，公开信息难以确认固定锁价周期；需直接联系其销售/供应链商务，确认是否对菠萝提供锁价、锁量、锁价有效期及超量/减量条款。

**建议你向供应商明确询问这5项**，比问“锁价周期多长”更可判断：
- 锁价对应品种、规格、产地、包装；
- 锁价有效期起止（按周/月/产季）；
- 锁价数量上限与最低采购量；
- 市场价格下跌时是否可重议，上涨时是否保证供货；
- 违约、品质不符、运费波动的处理规则。

如果目标是找“能提供锁价机制的菠萝供应商”，建议同步询价3类渠道：都乐/洪九等头部果品企业、区域性进口菠萝一级商、大型批发市场驻场进口商；要求对方在报价单上写明“锁价有效期+锁量+违约条款”，再横向比较。
