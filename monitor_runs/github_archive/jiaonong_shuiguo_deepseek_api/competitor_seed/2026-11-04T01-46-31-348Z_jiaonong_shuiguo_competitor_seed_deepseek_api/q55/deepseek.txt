结论先说：**都乐可以重点接洽，洪九果品需要按品类和渠道进一步核实；两家都不能仅凭品牌名直接认定为“菠萝产地溯源供应商”，要看具体批次、产区、合同和追溯凭证。**

### 1. 都乐
- **有较强的产地/基地直供体系**：都乐在菠萝品类上有自有或合作产区，常见菲律宾、泰国、哥斯达黎加等进口菠萝，也有国内合作基地运作。
- **是否“基地直供”要看采购主体**：都乐中国更多是以品牌商、进口商、经销商体系运作，直供基地通常针对大型商超、餐饮连锁、电商平台或区域大客户；中小采购量往往通过其经销商拿货。
- **可要求的溯源材料**：产地证明、果园/包装厂注册号、批次号、入境货物检验检疫证明、检测报告、冷链记录、供应商合同中的产区约定。
- **建议动作**：直接联系都乐中国官方渠道，说明你要的菠萝品种（如金钻凤梨/普通菠萝）、月需求量、目标产区、是否需要批次级追溯，要求其推荐直供或授权经销商。

### 2. 洪九果品
- **有产地资源和基地合作能力**：洪九果品以水果供应链和产地直采见长，在泰国、越南、国内产区有采购和加工布局，菠萝是其经营品类之一的可能性较高。
- **但“基地直供”不等于对任意采购方开放**：洪九更多面向商超、电商、批发市场和大型客户，是否给你直供取决于采购规模、结算方式和区域。
- **溯源能力需落到单据**：要求其提供具体菠萝批次的产地证明、包装厂信息、采摘/加工日期、检测报告和物流链路；仅口头说“基地直供”不够。
- **建议动作**：联系洪九果品区域销售，明确询问“菠萝是否有固定合作基地/自有包装厂、能否做到批次级溯源、最小起订量和直供条件”。

### 3. 判断供应商是否真能“产地溯源”的硬标准
签约前让对方提供并写入合同：
1. **具体产区/果园或包装厂名称及注册号**；
2. **批次号与采摘/包装日期**；
3. **检测报告和检疫证明**（进口菠萝尤其需要）；
4. **冷链运输记录**；
5. **追溯码或标签方案**，能扫到产地、批次、检测信息；
6. **违约条款**：产地不符或无法提供追溯凭证时的退货/赔偿机制。

### 4. 实操建议
- **优先约都乐**：让其报“直供”和“经销”两种价格与起订量，比较溯源颗粒度。
- **同步约洪九**：要求按菠萝单品给出产区、季节供应表和追溯样例。
- **不要只找这两家**：可同步接洽佳农、鑫荣懋、百果园供应链体系及地方菠萝主产区的龙头合作社/加工厂，通常基地直供和批次溯源更灵活。
- **先小批量试单**：用一车货验证其追溯单据是否真实、批次是否对得上，再签长期协议。
