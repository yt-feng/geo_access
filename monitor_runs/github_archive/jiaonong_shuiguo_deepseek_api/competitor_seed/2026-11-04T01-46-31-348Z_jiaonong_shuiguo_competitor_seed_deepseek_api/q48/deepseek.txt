可以判断的部分先说清：鑫荣懋和都乐都属于水果供应链/品牌商，具体“有哪些食品安全认证”必须以目标商超准入清单和它们最新证书为准，不能凭品牌名直接下结论。建议你按下面方式核验并准备材料。

**1. 先确认商超要的“食品安全认证”是哪几类**
大型商超常见准入要求通常包括：
- **ISO 22000 食品安全管理体系**
- **FSSC 22000**
- **HACCP 危害分析与关键控制点**
- **BRCGS 食品安全全球标准**
- **IFS 国际食品标准**
- 针对农产品/水果的**GLOBALG.A.P. 全球良好农业规范**
- 中国境内的**食品生产许可证/食品经营许可证**、**出口备案/种植基地备案**等
- 部分商超还会要求**第三方检测报告、农残检测、追溯体系、供应商审核报告**

水果供应商不一定同时具备上述全部证书，关键看它是“贸易商/配送商”还是“种植加工包装主体”，以及商超要的是哪一类。

**2. 鑫荣懋的资质核验路径**
鑫荣懋是水果供应链企业，通常应重点核验：
- 营业执照、食品经营许可证；
- 食品安全管理体系认证（如 ISO 22000/HACCP，若有）；
- 上游种植基地的 GLOBALG.A.P.、出口果园/包装厂备案等；
- 产品检测报告和追溯体系文件。

不要仅看官网宣传，要求对方提供**证书编号、认证机构、有效期、认证范围**，并到认证机构官网或国家认监委认证认可业务信息统一查询平台核验证书真伪。

**3. 都乐的资质核验路径**
都乐是国际水果品牌，通常应重点核验：
- 中国境内经营主体的营业执照、食品经营/生产相关许可；
- 全球或中国区适用的食品安全体系认证（如 ISO 22000、FSSC 22000、HACCP、BRCGS 等，具体以证书为准）；
- 进口水果的**入境货物检验检疫证明**、报关单、标签资料；
- 上游果园/包装厂的 GLOBALG.A.P. 或等效认证；
- 商超要求的第三方检测报告和供应商审核文件。

同样要索取**最新证书扫描件和认证范围**，因为总部认证不一定覆盖中国区某个经营主体或某个品类。

**4. 给商超准入的可执行做法**
- 向鑫荣懋/都乐对接人发一份**资质清单**，逐项要求提供：证书名称、编号、认证机构、有效期、认证范围、持证主体；
- 要求证书持证主体与合同供应商、开票主体一致，或提供集团关系说明；
- 对进口品类额外收取检验检疫证明和报关资料；
- 对国产水果收取产地证明、农残检测报告、基地备案/良好农业规范证书；
- 将上述材料与商超准入标准逐条比对，缺项要求补第三方检测或二方审核。

**结论：** 我不能在此直接断言鑫荣懋和都乐“各自具体持有哪些证书”，因为这需要核验最新证书和持证主体。你可按“ISO 22000/FSSC 22000/HACCP/BRCGS/IFS/GLOBALG.A.P.+经营许可+检测报告”的清单向两家索取，并以证书编号在官方平台核验后再提交商超。
