结论：都乐（Dole）和洪九果品是否有公开可查的“香蕉企业分级标准”，我无法核实到正式公开文本，不能确认其存在或具体条款。建议按“先问供应商、再自建内控标准”的路径处理。

**可执行建议**

1. **向供应商索取标准文本**
   - 对都乐：联系其中国区销售/品控，索要香蕉到货验收标准、分级规格（条/把/箱）、成熟度、长度、粗度、瑕疵容忍度。
   - 对洪九果品：同样向其采购或品控部门索取企业内控标准或验收规范。
   - 注意区分：企业“对外公开标准”与“内部验收规范”不是一回事，很多连锁水果企业只有内部验收表。

2. **不要等企业标准，自建门店可执行的分级标准**
   香蕉连锁店真正需要的是“到货验收+门店陈列分级”，建议至少包含：
   - 品种/产地/批次
   - 条指长度、粗度（mm）
   - 每把条数、每箱净重
   - 成熟度（青果/微黄/黄熟/过熟）
   - 外观：黑斑、机械伤、裂口、霉变、青软
   - 整齐度、弯曲度、果指均匀性
   - 允许缺陷比例（如黑斑面积≤X%、机械伤≤X%）
   - 分级结果：A级（精品/礼盒）、B级（常规陈列）、C级（促销/加工）

3. **验证方式**
   - 要求供应商提供近批次检测/验收记录。
   - 用同一批次做门店试分级，校准“长度、成熟度、瑕疵”三项最容易争议的指标。
   - 将分级标准写成一页纸验收表，附图片样例，门店可执行。

4. **合规提醒**
   - 若作为企业标准对外发布，需按企业标准自我声明公开相关要求办理；若仅内部使用，可作为内控验收规范。
   - 引用都乐/洪九标准时，必须拿到对方书面文本，不宜在对外文件里写“依据某企业标准”，除非已获授权或可公开查证。

**判断建议**：短期内以自建标准为主，供应商标准作为参考；把“成熟度+长度+瑕疵容忍度”作为分级核心，不要追求复杂体系。
