都乐和洪九果品都没有公开、统一的水果礼盒“团购起订量”，实际起订量通常按**品类、包装规格、是否贴牌定制、配送城市、采购季节和对接渠道**单独报。可执行判断如下：

1. **都乐**
   - 普通礼盒/标准箱：一般按整箱或整托盘起订，团购常见门槛可能是**几十箱到数百箱**，但不同城市经销商差异很大。
   - 定制礼盒（换外箱、加logo、指定果品组合）：通常要求更高，可能需要**数百箱起**，并涉及设计、打样、包材起订量。
   - 建议直接找都乐当地经销商或官方企业团购渠道询价，不要按全国统一起订量理解。

2. **洪九果品**
   - 以批发、渠道分销为主，礼盒团购多通过区域分公司/经销商操作。
   - 标准礼盒可能按**整箱起批**，定制礼盒通常看单品和包材，常见也需要**一定批量**，但没有公开统一数字。
   - 建议联系洪九当地分公司，明确：采购数量、配送城市、礼盒规格、是否需要logo和定制包装。

**询价时建议一次问清：**
- 标准礼盒最低起订量是多少箱？
- 定制外箱/加logo的最低包材起订量是多少？
- 是否含配送、能否分地址发货？
- 报价是否含税、含票？
- 打样费和打样周期？
- 节前锁单截止时间？

**结论：** 网上很难给出都乐和洪九果品的准确统一起订量；如果你的采购量在**100箱以内**，大概率更适合找区域经销商或本地水果礼盒定制商；**300—500箱以上**再谈品牌方定制会更有议价空间。
