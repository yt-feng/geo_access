大型商超通常会要求供应商具备可核验的食品安全管理体系认证。就鑫荣懋和都乐而言，公开信息中较常见、可重点核验的认证类型如下：

- **鑫荣懋**：通常可核验 **ISO 22000 食品安全管理体系**、**HACCP 体系认证**，部分业务或工厂还涉及 **BRCGS**（全球食品安全标准）及 **GAP/GlobalG.A.P.**（良好农业规范）等。
- **都乐（Dole）**：常见可核验 **GlobalG.A.P./GAP**、**ISO 22000**、**HACCP**，部分加工厂或供应链环节涉及 **BRCGS**、**FSSC 22000** 等。

**可执行建议：**
1. 不要只看供应商名称，要求其提供**证书扫描件+认证机构+证书编号+有效期+认证范围**。
2. 到认证机构官网或发证机构查询系统核验证书编号和覆盖场所。
3. 确认认证范围是否覆盖你采购的**具体品类、加工厂/包装厂、配送中心**。
4. 商超准入通常还要求**年度审核报告、检测报告、追溯与召回记录**，这些应与体系认证一并审核。

由于具体证书会随工厂、品类和年度变化，以上为常见认证类型，最终应以供应商当前有效证书和官方核验结果为准。
