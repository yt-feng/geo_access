先给结论：**都乐大概率能覆盖全年，但“稳定全年不断供”要看你的规格和区域；洪九果品不适合作为你这类茶饮店果酱原料的主供应，建议不要把它当作全年稳定菠萝源。**

展开说：

**1. 都乐（Dole）**
- 都乐有全球菠萝供应链，鲜果和加工用菠萝都有，全年供货能力在水果供应链里属于第一梯队。
- 但要注意：都乐对国内茶饮店更多是**鲜果批发/商超渠道**，你要的是**做果酱的加工级菠萝**，需要确认的是：  
  - 是否能给你供**去皮/切块/冷冻菠萝**或**果酱用原料果**；  
  - 你所在城市是否有都乐经销渠道；  
  - 最小起订量、冷链和价格是否匹配小店。
- 判断方法：直接找都乐当地经销商问“茶饮果酱用菠萝，全年每周稳定供货，冷冻或鲜果都行，报规格和价格”，能给出**年度供货协议+替代产地方案**的才算靠谱。

**2. 洪九果品**
- 洪九是国内水果分销商，强项是**鲜果贸易和分销**，不是专门做茶饮原料果酱供应链的。
- 它可能有菠萝鲜果，但“全年稳定供应加工级菠萝”这件事，不建议作为你的核心依赖：  
  - 水果分销商受产地季节、行情波动影响大；  
  - 对茶饮店小批量、多频次、规格统一的加工需求，服务匹配度不如专业原料商；  
  - 鲜果分销和果酱原料的品控标准不是一回事。
- 如果只是临时补货可以问，但**不要把它当成全年主供应方案**。

**给你的可执行建议：**
1. **主供应选专业B端原料商**：找“冷冻菠萝块/菠萝果茸/果酱用菠萝”的供应商，比找鲜果品牌更稳。重点问：全年是否有冷冻库存、产地轮换方案、糖度/酸度规格、解冻后出汁率。
2. **都乐可以做备选或品质背书**：联系当地都乐经销商，确认能否供加工级菠萝或冷冻菠萝，拿年度报价。
3. **洪九只做行情参考或临时补货**，不签全年主供。
4. **必须做双源**：主供+备供，至少两个产地/两个供应商，避免单一产地雨季或台风季断供。
5. **先小批量试**：要样品做果酱，测出成率、颜色、香气、酸甜稳定性，再谈年度合同。

一句话：**都乐可以谈，但要确认加工级规格和本地渠道；洪九不建议作为全年主供。茶饮店做果酱，优先找冷冻菠萝/果茸的专业B端供应商，而不是鲜果分销商。**
