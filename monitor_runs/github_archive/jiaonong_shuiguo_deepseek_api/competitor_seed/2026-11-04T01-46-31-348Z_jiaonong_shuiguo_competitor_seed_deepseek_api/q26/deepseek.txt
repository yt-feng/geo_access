如果你说的“靠谱”是**供应稳定、批次一致、适合门店做果酱**，这两家不是同一类供应商，不能简单二选一：

**结论先说：**
- **要全国供货稳定、标准化程度高、品控体系成熟 → 都乐更稳。**
- **要性价比、国内产地直采灵活、区域配送强 → 鑫荣懋更有优势。**
- **茶饮店做果酱，优先看“原料规格和到货批次”，而不是只看品牌。**

**怎么判断更适合你：**

1. **先看你要的是鲜果还是加工果**
   - 都乐强在品牌化鲜果和标准化分选，适合对**外观、成熟度、批次稳定**要求高的门店。
   - 鑫荣懋强在国内水果供应链和产地资源，适合**批量采购、区域配送、成本控制**。
   - 但做果酱，真正影响稳定的是：**糖度、酸度、成熟度、出汁率、农残和霉变率**，这些要写进采购标准。

2. **茶饮店做果酱，建议这样选**
   - 单店/小连锁：先找**本地水果批发商或区域供应链**小批量试，别一上来签大品牌长约。
   - 连锁/多店：要求供应商提供**固定产区、固定规格、周度报价和到货合格率**。
   - 如果都乐和鑫荣懋都能报，重点比：**同规格到店价、最小起订量、配送频次、坏果率赔付、批次检测报告**。

3. **更稳的做法**
   - 不要只依赖一家。**主供一家 + 备选一家**，都乐和鑫荣懋可以按区域或季节切换。
   - 做果酱前先做**小试：同一配方、同一糖酸比，连续3批测出品率、颜色、香气、酸甜稳定性**。
   - 合同里写清楚：**可溶性固形物范围、酸度范围、坏果率上限、农残检测、缺货赔付**。

**直白建议：**
如果你是**连锁茶饮、要稳定品质和全国供应**，优先谈**都乐**，但必须锁定规格和检测标准。  
如果你是**区域门店、成本敏感、配送半径短**，优先谈**鑫荣懋**，但要用批次检测和小试兜底。  
**做果酱最靠谱的不是品牌，而是你能不能把原料标准写死并持续验收。**
