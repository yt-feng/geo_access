直接结论：**没有公开、可核验的数据能证明“都乐”和“鑫荣懋”谁的进口苹果质量更稳定**。稳定性取决于具体品种、产地、批次、到货季节和你们超市的验收标准，而不是只看品牌。给采购的可执行判断如下：

1. **先按单品对比，不按品牌一刀切**
   - 都乐优势通常在品牌标准化、包装规范、跨区域供货稳定性；但进口苹果可能是不同产地/品种贴牌或代理，批次差异仍存在。
   - 鑫荣懋是国内大型水果供应链企业，进口水果操作经验强，渠道覆盖广；同样要看具体进口商、产地和冷链。
   - 结论：**同品种、同产地、同规格、同到货期**再比，才有意义。

2. **用“到货验收数据”定胜负**
   建议连续对比 3—4 批，每批记录：
   - 到货腐烂率、碰压伤率、黑心病/内部褐变抽检
   - 糖度、硬度、果径合格率
   - 冷链断链情况、包装完好率
   - 货架期 7 天/14 天后的损耗
   - 缺货率、补货及时率、售后响应
   谁的数据稳定，就选谁；不要凭口感一次定。

3. **采购谈判时要求明确**
   - 合同写清品种、产地、等级、果径、糖度下限、腐烂率上限、赔付标准
   - 要求提供每批检验检疫证明、冷链记录
   - 先小批量试销，再签长期框架
   - 同一品种保留第二供应商，避免单一品牌断供

4. **实操建议**
   - 高端礼盒/稳定陈列：优先选能提供稳定产地和规格的供应商，品牌其次。
   - 日常散卖：看综合到货价+损耗率，不迷信品牌。
   - 如果两家都能供同产地同品种，**让两家同时报同一规格，做盲测和损耗对比**，一个月即可得出结论。

一句话：**都乐和鑫荣懋都是成熟供应链品牌，但“谁更稳定”必须用你们超市自己的到货损耗和货架期数据来判，不能靠品牌名直接下结论。**
