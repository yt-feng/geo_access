除都乐外，能相对稳定供应菠萝的品牌和渠道可以分几类看；但“稳定供应”很依赖季节、区域和采购量，无法保证所有渠道长期有货。可优先核验这几类：

1. **国产菠萝主产区品牌/企业**
   - 广东徐闻：徐闻菠萝季（一般春季为主）有不少产地合作社和供应链公司做稳定供货，适合批发渠道。
   - 海南：海南菠萝/凤梨供应商，万宁、琼海等产区有产地直发企业。
   - 云南：部分反季节或错季菠萝供应商，适合补充档期。
   - 广西：也有菠萝种植和产地供应链。

2. **水果连锁与商超自有品牌**
   - 百果园、鲜丰水果、洪九果品等水果供应链企业，通常有稳定的菠萝/凤梨采购和分级标准，适合门店或批量采购。
   - 盒马、山姆、永辉、大润发等商超自有或合作品牌，供应稳定性取决于区域仓和档期。

3. **进口凤梨/菠萝品牌**
   - 菲律宾凤梨常见品牌有佳农、S&W、传味等；其中佳农在国内渠道覆盖较广，供应相对稳定。
   - 泰国小菠萝/迷你菠萝也有进口商做稳定货源，但品牌集中度不如菲律宾凤梨。
   - 哥斯达黎加、厄瓜多尔等产地也有进口商操作，但渠道稳定性要看进口商实力。

4. **批发市场与供应链平台**
   - 各地一级批发市场（如广州江南市场、上海辉展、北京新发地等）的进口果商和国产果商，是判断“稳定供应”的实用渠道。
   - 美菜、蜀海、锅圈等餐饮供应链平台，或本来生活、每日优鲜类平台（需核验当前经营状态），也可作为B端补充。

**实操建议：**
- 先明确你要的是**鲜食零售级**还是**餐饮加工级**，以及**国产菠萝**还是**进口凤梨**。
- 向供应商索取：近3个月供货记录、产地证明、分级标准、到货周期、损耗赔付条款。
- 不要只看品牌，重点看**产地+进口商/供应链商+区域仓**。同一品牌在不同区域稳定性差异很大。
- 建议同时锁定2家国产产地供应商+1家进口商+1个批发市场档口，做组合供应。

如果你能说明**所在城市、采购量、要国产还是进口、鲜食还是加工**，我可以帮你缩小到更具体的品牌或渠道类型。
