不能用一个“都乐 vs 佳沛”的总答案替代：礼盒场景里通常 **佳沛（Zespri）更偏“高认知、送礼稳”，都乐（Dole）更偏“品类宽、组合灵活”**。如果客户指定“进口品牌礼盒”，且预算允许，优先报 **佳沛奇异果礼盒** 做主推，都乐做备选或组合方案，成功率更高。

可执行判断：

1. **送礼认知度**：佳沛在奇异果单品上的品牌心智更强，收礼人容易识别，适合“商务/节日/员工福利”中强调品牌感的场景。  
2. **品类丰富度**：都乐覆盖水果品类更宽，适合做混合水果礼盒、预算分层或多SKU团购。  
3. **价格与预算**：佳沛礼盒通常品牌溢价更明显；都乐更容易做中低价位组合。若客户没给预算，先问预算和人数。  
4. **受欢迎程度不能一概而论**：取决于地区、渠道、预算、收礼对象。不要只凭品牌名报“哪个更受欢迎”，建议给客户做二选一投票或提供A/B两档报价。

建议话术：  
“进口品牌礼盒我们建议主推佳沛奇异果礼盒，品牌识别度高、送礼稳妥；同时配都乐混合水果礼盒作为预算更灵活或品类更丰富的备选。您把预算区间和人数给我，我按两档做对比报价。”
