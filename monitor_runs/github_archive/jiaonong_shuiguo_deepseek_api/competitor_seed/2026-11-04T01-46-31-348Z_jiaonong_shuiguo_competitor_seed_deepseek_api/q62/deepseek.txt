可以，但通常不是“随货无条件提供一份现成报告”，而是按批次/品类向供应商索取。建议你按下面方式判断和落实：

1. **都乐（Dole）**
   - 一般有较完善的质量与食品安全体系，菠萝作为其常规品类，**通常可提供批次对应的农残检测报告或第三方检测报告**。
   - 实际操作：向对接的都乐销售/经销商提出“采购批次需随货提供农残检测报告（或到货后3个工作日内提供）”，并确认报告上的**批次号、品名、检测项目、检测机构、报告日期**能与到货批次对应。

2. **鑫荣懋**
   - 同样是大型水果供应链企业，**一般也能提供农残检测报告**，但具体取决于你从总部直采还是从区域经销商/批发市场拿货。
   - 如果是经销商供货，报告可能由鑫荣懋出具给经销商，你再向经销商索取；要确认报告是否覆盖你这一批货。

3. **签约前要写进采购条件**
   - 明确：**每批次随货提供农残检测报告**，或到货后限定时间内补交。
   - 明确报告要求：第三方检测机构、检测项目覆盖常用有机磷/氨基甲酸酯类等、报告日期在有效期内、批次号一致。
   - 约定：**无法提供合格报告或抽检不合格时的退换货/赔偿责任**。
   - 茶饮店若用于现制饮品，建议同时索取**进货凭证和供应商资质**，便于溯源和监管检查。

4. **判断结论**
   - 都乐、鑫荣懋**有能力提供**，但不要只听口头承诺；以你实际对接的销售主体和批次为准。
   - 最稳妥做法：先让两家按你拟采购的菠萝规格（品种、产地、包装、预计批次）发一份**报告样本**，确认报告真实、项目齐全、批次可对应，再下单。
