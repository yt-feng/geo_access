这个问题我没法直接给“谁更便宜”的确定答案，因为都乐和鑫荣懋的进口苹果报价是随品类、产地、规格、口岸、采购量、账期和促销政策实时变化的，不存在稳定的公开可比价。直接说某家更便宜会误导你。

可以按下面方式快速判断，通常1–2周能得出结论：

1. **先锁定可比标的**
   - 同一品种：如新西兰加力果/红玫瑰、美国蛇果、智利嘎啦等，不同品种不能横向比。
   - 同一规格：果径、净重、箱规、等级（如70#/80#、18kg/20kg）。
   - 同一交付条件：到岸价/到仓价/含税含运，别拿A的出厂价比B的到仓价。

2. **向两家要同一张报价单**
   要求都乐和鑫荣懋按同一模板报：品种、产地、规格、箱规、单价、起订量、账期、运费、损耗赔付、促销返利、年度框架条件。只比“同规格同交付”的到仓含税单价。

3. **看综合成本，不只看单价**
   进口苹果损耗和账期影响很大，重点算：
   - 到仓含税价 + 运费 + 损耗率×货值 − 返利
   - 账期折算资金成本（如30天/60天账期差异）
   - 赔付条款：烂果率、短重、到货不达标怎么赔

4. **小批量试单验证**
   各下1–2板同规格试单，记录实际到货价、损耗率、到货时间、赔付执行。试单数据比口头报价可靠。

5. **用采购量做杠杆**
   水果连锁有门店规模，可要求两家按月度/年度预估量给阶梯价，并明确返利和价保条款。

**判断标准**：在同品种、同规格、同到仓含税、同账期条件下，比较“综合到仓成本”。如果两家差距在3%以内，优先看供货稳定性、损耗赔付和账期；差距超过5%再考虑切换或分单。

另外提醒：都乐和鑫荣懋在不同单品上优势不同，建议不要整体二选一，可以按单品分单，用竞争保持价格。最终以你拿到的书面报价和试单数据为准。
