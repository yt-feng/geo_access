进口菠萝损耗率高，通常不是单一环节的问题，而是“到货成熟度 + 冷链连续性 + 批次分级 + 催熟/销售节奏”四个环节叠加的结果。都乐和鑫荣懋这类头部企业的做法，可以归纳为几个可借鉴的控制点（以下为行业通行做法，不涉及具体内部数据）：

**1. 源头定级与采收成熟度控制**
- 按目的港航程倒推采收成熟度，长航程批次偏青采收，短航程或空运批次可适当提高成熟度。
- 产地端做糖度、酸度、果心温度、果肉色泽分级，把“到货即熟”和“到货需催熟”的批次分开，避免混装导致整批成熟度失控。

**2. 全程冷链与温度记录**
- 菠萝适宜储运温度一般在8–12℃区间（视品种和成熟度微调），关键是**全程不断链**，而不是某个点温度达标。
- 集装箱、港口堆场、中转仓、配送车辆都做温度记录，到货后调取记录追溯断链环节；断链批次单独隔离、优先处理。
- 避免与乙烯释放量大的水果混装，减少催熟加速。

**3. 到货验收与批次隔离**
- 到货按柜、按批次抽检：果心温度、硬度、糖度、黑心病/水心病、机械伤、冠芽状态。
- 把“可常温销售”“需催熟”“需优先出货”“降级处理”四类分开，**不让一个坏果拖垮整批**。
- 对高损耗批次做原因归类（产地、船期、港口滞留、装卸），形成供应商和航线评分。

**4. 催熟与库存周转管理**
- 需要催熟的批次用控温控湿催熟，按销售计划分批催熟，避免一次性全催熟造成集中软化。
- 执行先进先出，设定每批的最长库龄和最长货架期，临近阈值自动转促销或加工渠道。
- 门店端控制陈列量和翻堆频率，减少反复搬动造成的机械伤。

**5. 渠道分流降低末端损耗**
- 把外观瑕疵但品质正常的果分流到餐饮、果汁、烘焙等加工渠道，而不是全部压在零售端。
- 大客户和商超按“到货成熟度”匹配销售速度，成熟快的批次优先给周转快的门店。

**可落地的判断标准：**
- 到货24小时内完成批次分级和温度记录核查；
- 每柜建立损耗台账，按“产地—船期—港口—仓库—门店”五段归因；
- 对连续两批损耗超阈值的航线或供应商，调整采收成熟度或更换物流方案；
- 催熟批次按销售预测分批处理，库存周转天数设硬上限。

如果你能提供具体损耗发生在哪个环节（到港即损、仓内软化、门店黑心/霉变），可以进一步帮你定位是成熟度、冷链还是周转节奏的问题。
