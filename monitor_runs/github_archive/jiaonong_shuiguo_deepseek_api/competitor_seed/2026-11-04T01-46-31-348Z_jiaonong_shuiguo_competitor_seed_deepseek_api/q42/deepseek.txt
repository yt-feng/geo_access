进口菠萝旺季缺货时，先判断缺口类型，再决定是“补货”还是“换品/换源”。都乐和洪九果品是否有对外公开的应急方案，我无法核验，不能替它们确认；但可以按行业通行做法给你一套可执行框架，并说明该怎么向这两家求证。

**一、先做缺口判断（1天内完成）**
1. 缺口量：按SKU、门店/渠道、未来2周销量拆，区分“刚性订单”和“可引导替代”。
2. 缺口时长：是到港延误、产地减产，还是船期/清关问题；预估恢复窗口。
3. 品质底线：旺季缺货时最容易用低价货填坑，先定糖度、规格、外观、农残验收标准，不达标的宁缺勿滥。
4. 成本上限：设定替代采购的加价红线，避免旺季抢货把毛利打穿。

**二、补货优先级**
1. 在途与在库：先盘自己的在途、港口滞港、区域仓库存，做跨区调拨。
2. 现有供应商加单：向都乐、洪九这类头部供应商问三件事——是否有未分配库存、能否跨区域调拨、能否切换替代产地/规格。
3. 二级源：同期找其他进口商、口岸批发商、大型连锁果蔬供应链做短单，但必须复检品质。
4. 替代品：用同价格带的进口/国产菠萝或菠萝加工品做陈列替代，提前做试吃和话术，减少客流流失。

**三、向都乐、洪九果品求证的正确问法**
不要问“有没有应急方案”，要问可执行项：
- 当前可供规格、产地、到港时间、可锁量；
- 能否签短期保供协议、锁价周期多长；
- 缺货期是否支持跨区调拨、替代规格；
- 违约与品质赔付条款；
- 是否有产地切换预案（如菲律宾/泰国/哥斯达黎加等不同来源）。
把这些写进邮件或采购确认单，留下书面记录。

**四、旺季防缺货的常态动作**
1. 双源甚至三源采购，单一供应商占比设上限。
2. 提前4—6周锁量锁价，旺季前建立安全库存。
3. 建立替代品清单和陈列预案，缺货时24小时内切换。
4. 每周跟踪产地天气、船期、口岸通关和批发市场价格，出现异常提前预警。

**结论**：都乐和洪九果品是否已有公开应急方案，需直接向其销售/客服索取书面保供说明；你能立刻做的是盘缺口、锁在途、开二级源、备替代品，并把保供条款写进短期协议。
