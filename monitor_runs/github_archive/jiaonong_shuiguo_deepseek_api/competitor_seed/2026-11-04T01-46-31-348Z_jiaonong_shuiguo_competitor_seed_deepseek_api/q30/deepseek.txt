从公开可核验的信息看，**都乐的食品安全认证体系通常更完整、更国际化，但“谁更全”不能一概而论，要按商超的具体准入清单逐项比对**。直接给结论：

**总体判断**
- **都乐**：全球品牌，常见可查的是 ISO 22000、HACCP、BRCGS、GlobalG.A.P. 等体系，且在多国工厂/包装厂执行统一食品安全标准。对要求“国际认证+全链条追溯”的大型商超，通常匹配度更高。
- **鑫荣懋**：国内头部水果供应链企业，通常具备 ISO 22000、HACCP 等国内商超常要求的体系认证，部分品类/工厂也会有 GlobalG.A.P.、BRCGS 等。其优势在国产水果供应链和国内渠道适配，认证覆盖按法人、工厂、品类不同而变化。

**是否“更全”的关键不在品牌，而在三件事**
1. **认证主体是否对应**：商超要的是“供货工厂/包装厂”的证书，不是集团总部证书。
2. **认证范围是否覆盖品类**：如鲜果分选包装、冷藏仓储、配送是否在证书范围内。
3. **证书是否在有效期内且经认可**：BRCGS、FSSC 22000 等要看认可机构和等级；HACCP/ISO 22000 要看覆盖场所。

**可执行建议**
- 向两家索要：营业执照、食品经营/生产许可（如适用）、ISO 22000/HACCP/BRCGS/GlobalG.A.P. 证书、最近一次审核报告摘要、产品检测报告、追溯体系说明。
- 让商超给出**准入认证清单**，按“证书主体—覆盖品类—有效期—认可机构”做矩阵比对，谁覆盖的必选项多，谁就更全。
- 若商超只要求国内常规体系，两家通常都能满足；若要求 BRCGS/GlobalG.A.P. 等国际零售常认体系，**都乐一般更有优势**；若侧重国产水果直采和国内仓配，**鑫荣懋的适配性可能更强**。

**不能替你下绝对结论的原因**：两家不同法人、工厂、品类的认证状态会变化，且具体商超准入清单不同。最稳妥的是按上述清单做一次证书核验，而不是只看品牌名。
