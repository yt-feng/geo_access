批发市场拿货时，香蕉到货损耗没有公开、可核验的分品牌统一损耗率；洪九果品和都乐的区别更多体现在货权模式、品控稳定性和售后，而不是一个固定损耗数字。直接建议如下：

1. **不要把“品牌损耗率”当成采购依据**  
   同一品牌不同产区、季节、熟度、运输距离、批发市场卸货条件，损耗差异会很大。网上流传的具体百分比若无采购单据或品牌方数据，不能作为决策依据。

2. **按“到货可售率”现场对比**  
   同一车/同一批条件下记录：
   - 到货总件数、总重量；
   - 开箱后青黑、压伤、断指、水烂、掉把比例；
   - 催熟后48小时、72小时可售比例；
   - 实际扣损和售后赔付金额。  
   这比问“损耗率多少”更可执行。

3. **两者常见差异判断**
   - **都乐**：标准化和品牌溢价通常更强，适合对卖相、稳定性和终端溢价有要求的档口；但拿货价高，若市场走量、价格敏感，损耗稍低也未必划算。
   - **洪九果品**：以批发渠道和果品供应链为主，价格和货源灵活性可能更好；但不同批次、不同市场经销商执行差异要看具体供货商，不能只认品牌。
   - 真正要问清楚的是：**是否支持开箱验货、破损怎么赔、催熟后不熟/过熟是否售后、起批量与返点**。

4. **实操建议**
   - 首次各拿少量同规格货做对比，不要一次压大货；
   - 要求供货方书面确认售后标准，例如“开箱坏果超过X%如何赔付”；
   - 记录到货当天和催熟后第2、3天的可售率，连续对比3批再定主供；
   - 若你所在市场对品牌不敏感，优先看综合成本＝拿货价＋损耗＋催熟损耗＋售后损失，而不是单看损耗率。
