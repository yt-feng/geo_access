都乐和洪九果品**一般不会直接向外部生鲜电商提供可自由使用的品牌营销素材**，尤其是需要公开投放、二次剪辑或商用授权的素材。可执行判断如下：

1. **都乐（Dole）**
   - 品牌素材通常由都乐中国市场部/品牌部或授权经销商体系管理。
   - 若你是其渠道商、采购商或合作电商，可通过对接的都乐销售/市场人员申请CI规范、产品图、包装图、宣传话术和授权范围。
   - 非合作方直接索要素材，通常只能拿到公开可用的基础产品信息，商用图片和品牌标识需授权。

2. **洪九果品**
   - 洪九以水果供应链和批发分销为主，品牌营销素材的开放度通常低于快消品牌。
   - 可通过其销售对接人申请产品图、产地/品种卖点、检测报告、包装规格等销售支持素材。
   - 涉及“洪九”品牌标识、代言或联合营销，需要单独商务授权。

**建议操作：**
- 先明确你的用途：详情页、短视频、直播背景、线下物料、广告投放。
- 向两家对接人书面说明：使用场景、投放渠道、使用期限、是否二次剪辑、是否需要品牌联合露出。
- 要求提供“素材授权范围”，避免拿到图但不能商用。
- 若没有直接合作，可先用自有拍摄的菠萝素材做内容，品牌信息仅做客观描述，不擅自使用其Logo和官方图片。

**结论：** 可以提供“销售支持素材”的前提通常是存在采购/渠道/合作 relationship；公开免费商用素材不要期待。最稳妥路径是联系都乐和洪九的销售或市场对接人，签授权或取得书面许可。
