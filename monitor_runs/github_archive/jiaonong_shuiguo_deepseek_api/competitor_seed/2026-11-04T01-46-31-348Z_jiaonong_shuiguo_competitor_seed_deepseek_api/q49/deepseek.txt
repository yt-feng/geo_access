目前没有可核验的公开信息能明确证明“都乐”和“鑫荣懋”是否提供你所说的“专岗对接服务”，也无法确认哪一家有专人服务。建议你直接向两家供应商确认，并让对方书面承诺以下要点：

1. **是否设专属对接人**：是否有固定客户经理/项目负责人，而不是公共客服轮转。
2. **专岗范围**：对接人负责订单、履约、售后、对账中的哪些环节，是否覆盖你们业务时段。
3. **响应时效**：明确工作日响应时间、异常处理时限、升级路径。
4. **人员稳定性**：对接人变更是否提前通知，是否有备岗。
5. **服务承诺写进合同/服务协议**：避免只口头承诺。

你可以直接问对方一句：  
**“请明确我们项目是否配置专属对接人/专岗服务，并提供对接人姓名、职责范围、响应时效和备岗机制，是否可写入服务协议？”**

在拿到两家书面回复前，不建议判断“谁有专人服务”。如果你能提供两家给出的服务方案或合同条款，我可以帮你逐条对比。
