菠萝作为茶饮原料，判断“更适合长期合作”不能只看品牌名气，要按你实际用果形态来分。先给结论，再给判断方法：

**结论：**
- **如果你用的是鲜切菠萝/菠萝块，且门店对出品稳定性、损耗控制要求高：优先测都乐。** 都乐的鲜果标准化、冷链和商超/连锁供应体系更成熟，规格一致性风险相对低。
- **如果你用量大、以菠萝果肉/果酱/冷冻果肉等加工形态为主，或需要更强价格弹性和定制：洪九果品值得重点谈。** 洪九强在水果供应链和产地资源，量大时有议价和定制空间，但鲜果规格稳定性更依赖具体批次和你的验收标准。
- **不建议直接二选一签长期。** 茶饮菠萝的稳定规格核心不在“品牌选谁”，而在“你定义什么规格+怎么验收”。

**关键判断维度：**
1. **你用果形态**：鲜切果块、冷冻果肉、果酱/浓缩汁，供应商适配完全不同。
2. **规格定义**：品种（如金钻/巴厘）、单果重区间、糖度、成熟度、切块尺寸、纤维感、出汁率、色泽。
3. **批次稳定性**：连续3–5批的糖度、酸度、成熟度、损耗率波动。
4. **供应半径与冷链**：你所在城市到供应商仓配的距离，决定鲜果到店品质。
5. **价格机制**：长期合作是锁价、随行就市还是保底量返利，菠萝季节波动大，必须写清。
6. **售后与替换**：坏果率、规格不符的赔付和补货时效。

**可执行建议：**
- 先做**双供应商并行测试**：都乐、洪九各供2–3批，用同一套验收表打分。
- 验收表至少包含：单果重合格率、糖度区间合格率、坏果率、切块出品率、门店投诉数。
- 测试期建议**1个月或3个订货周期**，再决定主供+备供，而不是独家长期。
- 长期合同里写清：规格区间、批次抽检、价格调整触发条件、最低供货保障、赔付条款。

简单说：**鲜切稳定优先都乐，量大加工和价格弹性优先洪九；最终用你的验收数据决定主备供关系。**
