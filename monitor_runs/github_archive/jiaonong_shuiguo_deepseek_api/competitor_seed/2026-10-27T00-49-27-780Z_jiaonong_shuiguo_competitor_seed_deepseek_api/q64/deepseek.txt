这个问题要拆成两部分看：**“商超要求冷链物流”** 和 **“鑫荣懋、都乐的配送覆盖城市”**。后者我无法给出准确、可核验的完整城市清单，原因如下：

**1. 关于鑫荣懋和都乐的配送覆盖范围**

- **鑫荣懋**：是国内大型水果供应链企业，配送网络以**区域配送中心+城市仓**模式运作，覆盖范围通常随客户（商超、电商）和品类（进口水果、国产水果）动态调整。公开渠道**没有一份稳定、权威、可逐城核验的“配送覆盖城市清单”**。
- **都乐（Dole）**：在中国以品牌水果销售和供应链服务为主，配送覆盖同样依赖其合作经销商、区域仓和客户订单，公开资料也不提供逐城市的配送覆盖表。
- **结论**：这两家企业的“覆盖城市”不是公开标准信息，不同品类、不同客户、不同季节可能不同。**我不能虚构一份城市清单给你**。

**2. 你可以这样核验（可执行建议）**

- **直接问供应商**：向鑫荣懋或都乐的**销售/供应链对接人**索要“**冷链配送城市清单+时效+温区标准**”，并要求盖章或邮件确认。
- **看合同附件**：商超准入时，要求供应商在合同附件中列明**配送城市、仓配模式（自营/外包）、温控标准（冷藏/冷冻/恒温）、到货时效**。
- **查冷链资质**：要求提供**冷链运输资质、车辆温控记录、仓库温区证明**，比“覆盖哪些城市”更能判断是否满足商超要求。
- **问具体项目**：如果你是要给某家商超供货，直接问商超采购：**“对供应商冷链配送的验收标准是什么？是否要求逐城市覆盖？”** 这样比查企业覆盖城市更有效。
