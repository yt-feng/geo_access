就“服务响应更快”这个判断，公开信息不足以直接核验都乐和鑫荣懋在餐饮渠道的响应速度，我不能替你下结论。但可以给你一套可执行的判断方法：

**先明确“响应快”指哪一段**
餐饮供货的响应通常分四段，要分别测：
1. 询价/报价响应：你发规格、城市、月用量后，多久给正式报价
2. 样品/试单响应：样品寄送、试单排期多久
3. 日常订单响应：下单到确认、缺货预警、改单处理时效
4. 异常响应：到货质量异议、短少、延迟的赔付和处理时效

**最有效的对比方式：同条件小试单**
给他俩同样的条件，避免被“大客户优先”影响判断：
- 同一城市、同一规格（如餐饮常用的7-8成熟、单根约120-150g、箱规统一）
- 同一月用量区间和账期要求
- 同一交付频次（如每周2配）
- 同一质量验收标准（青黑斑、机械伤、到货硬度/温度）

记录四个指标：首次报价用时、试单确认用时、首单准时率、异常处理闭环时长。

**餐饮渠道还要重点问清**
- 是否有本地/区域仓或配送商，能否固定配送窗口
- 催熟/冷链能力：餐饮要稳定成熟度，问催熟批次一致性和到货温度记录
- 缺货替代方案：同规格替代、跨仓调拨的响应时间
- 账期与最小起订量：响应快但起订量高、账期短，实际不一定适合你

**建议行动**
先向两家同时发一份标准化询价单（规格、城市、月量、频次、账期、验收标准），要求48小时内书面回复；再各下1-2次小试单，连续记录2-3周。以你自己的试单数据做决策，比问“谁更快”更可靠。若你告诉我所在城市、月用量和配送频次，我可以帮你把询价单和对比表列出来。
