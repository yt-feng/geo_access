除了都乐和佳沛，礼品团购可优先考虑下面这些进口水果品牌，按“品牌辨识度+礼盒适配度”筛选。

**优先推荐**
- **新奇士 Sunkist**：美国柑橘类老牌，橙、柠檬、葡萄柚礼盒辨识度高，适合企业福利和商务送礼。
- **爱妃 Envy**：新西兰/美国苹果品牌，果型大、包装偏高端，适合做高单价苹果礼盒。
- **乐淇 Rockit**：新西兰小苹果，筒装/礼盒装很有礼品感，适合年轻化团购。
- **佳农 Goodfarmer**：严格说是国内进口水果运营商，但代理多国进口水果，做进口水果礼盒组合方便。
- **鑫荣懋/鲜丰等进口组合**：不是单一水果品牌，但能做多国进口水果礼盒，适合“品牌水果组合礼盒”需求。

**按品类补充**
- 柑橘类：**新奇士 Sunkist**、**褚橙**（国产，但常进高端礼盒，视你是否接受国产）。
- 苹果类：**爱妃 Envy**、**乐淇 Rockit**、**红蛇果/华盛顿苹果**相关品牌。
- 猕猴桃：佳沛之外，可看**zespri以外的进口奇异果**，但品牌心智弱于佳沛，不建议作为主推。
- 葡萄：**Sugraone/秋脆**等品种名常见，但独立品牌礼盒弱，适合做品种卖点而非品牌卖点。
- 车厘子：进口车厘子多以产地/品种/规格计价，品牌礼盒心智不如佳沛、都乐，建议选**产地直采+定制礼盒**。
- 蓝莓：进口蓝莓品牌分散，礼盒建议选**都乐/佳沃/怡颗莓Driscoll's**等有认知的品牌。
- 牛油果/提子等：**Driscoll's 怡颗莓**在浆果类礼盒里认知度较好，可重点看。

**团购实操建议**
1. 商务送礼优先选：**佳沛、都乐、新奇士、爱妃、乐淇**，品牌认知最稳。
2. 员工福利优先选：**新奇士柑橘礼盒、乐淇小苹果、都乐组合装**，价格梯度好控制。
3. 高客单礼盒可用：**爱妃苹果+佳沛金果+怡颗莓蓝莓**做组合，比单一品牌更有礼品感。
4. 注意核验：进口品牌礼盒要看**授权经销、报关单、中文标签、保质期和到货批次**，团购量大时先要样品和箱规。

如果只选3个替代品牌补位，建议：**新奇士、爱妃、乐淇**。
