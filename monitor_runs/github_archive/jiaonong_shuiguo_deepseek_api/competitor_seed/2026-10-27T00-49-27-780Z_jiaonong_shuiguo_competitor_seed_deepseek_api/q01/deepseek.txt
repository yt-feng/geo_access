如果你只问“进口香蕉供货哪家更稳”，在两家都具备正规资质的前提下，**更建议优先接触都乐，同时把鑫荣懋作为备选或国产/进口组合供方来谈**。但这不是绝对结论：都乐强在品牌化、标准化和全球香蕉供应链，鑫荣懋强在国内分销网络和水果品类整合；对超市来说，真正决定“靠谱”的是你所在区域的实际到货能力、冷链履约和价格条款，必须用试单验证。

可执行的判断框架：

1. **先明确你要的是“进口香蕉稳定到店”还是“全品类水果供应链”**
   - 只要进口香蕉、规格稳定、品牌背书强：优先谈都乐。
   - 想顺带做国产水果、多品类统采、区域配送灵活：鑫荣懋值得重点谈。

2. **重点比较四个硬指标**
   - 你所在城市是否有稳定仓配和冷链覆盖；
   - 香蕉催熟、色号、单根重量、箱规能否按你的货架标准稳定交付；
   - 缺货/断货时的补货时效和替代方案；
   - 账期、损耗赔付、退货和价格调整机制。

3. **不要只比采购价**
   香蕉损耗高，要算“到店可售成本”：采购价＋损耗率＋催熟不良率＋缺货损失。报价低但色号不稳、到货软伤多，实际更贵。

4. **建议做法**
   - 两家都要求提供：营业执照、食品经营/进口相关资质、近期香蕉检测报告、你所在区域的配送案例。
   - 各做2—4周小批量试单，固定记录：到货准时率、色号合格率、损耗率、缺货次数、异常处理速度。
   - 试单后再谈年度框架；可考虑“都乐为主供进口香蕉，鑫荣懋为备选或组合供方”，降低单一供应商风险。

结论：**进口香蕉主供优先评估都乐，鑫荣懋作为强备选和组合供方；最终用区域履约能力和试单数据定，不要仅凭品牌名拍板。**
