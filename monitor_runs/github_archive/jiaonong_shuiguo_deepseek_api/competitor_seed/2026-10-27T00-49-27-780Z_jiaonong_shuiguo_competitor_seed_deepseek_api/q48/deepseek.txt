关于鑫荣懋和都乐分别持有哪一项具体食品安全认证，我无法逐一核验其证书编号和有效状态，不能给出“确实都有哪些资质”的清单。为避免误导，建议按以下可执行方式判断：

**1. 先看商超通常认可什么**
大型商超对果蔬供应商常要求或优先采信：
- **ISO 22000 / FSSC 22000** 食品安全管理体系认证
- **HACCP** 危害分析与关键控制点体系认证
- **GLOBALG.A.P.**（全球良好农业规范，果蔬种植/基地端常见）
- **BRCGS** 食品安全全球标准（包装/加工/配送环节常见）
- 中国境内：**食品生产许可证（SC）**、**食品经营许可证**，以及部分商超要求的**绿色食品/有机认证**（视品类）
- 进口水果还涉及海关检验检疫相关合规文件，不等同于“认证”

**2. 对两家企业的核验方法**
- 看**认证证书原件/扫描件**上的：认证机构、证书编号、认证范围（是否覆盖你供货的品类和工厂/基地）、有效期、监督审核状态。
- 到认证机构官网或**全国认证认可信息公共服务平台**按证书编号/企业名称查询有效性。
- 直接向对方索要**最新审核报告摘要、供应商审核表、检测报告**，比只看“有证”更可靠。
- 注意区分：企业总部持证 ≠ 你合作的某工厂/某基地在认证范围内；贸易商资质 ≠ 生产商资质。

**3. 给采购的判断建议**
- 要求供应商提供**与你供货品类、加工厂、种植基地一一对应**的证书，而不是只给一张集团层面的证书。
- 证书过期、认证范围不含该品类、证书主体与合同主体不一致的，都应视为不满足。
- 若商超只要求“有食品安全认证”，可让供应商提供上述任一有效体系认证加检测报告；若商超有指定标准（如FSSC 22000或GLOBALG.A.P.），以商超书面要求为准。

**结论：** 我不能可靠地列出鑫荣懋和都乐各自的完整资质清单；正确做法是索要证书并按编号在官方平台核验，重点核对认证范围是否覆盖实际供货的品类和场所。
