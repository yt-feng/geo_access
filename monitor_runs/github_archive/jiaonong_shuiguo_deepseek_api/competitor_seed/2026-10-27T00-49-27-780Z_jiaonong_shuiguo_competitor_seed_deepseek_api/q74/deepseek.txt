建议你按下面方式快速拿到可执行答案：

1. **先明确你的需求再问**
   - 礼盒预算档位：如50/80/120/200元
   - 单品还是混合果品
   - 是否需要贴牌/定制外箱/贺卡
   - 预计总采购量、单次下单量、是否分批发货
   - 收货城市和是否需要冷链落地配

2. **问都乐**
   - 找都乐官方渠道：都乐中国官网/官方公众号的“商务合作/团购”入口，或当地水果批发市场的都乐经销商。
   - 直接问话术：  
     “我们是礼品团购公司，计划做都乐水果礼盒定制，需要贴牌/定制外箱，预计首单X盒、年度X盒，收货在X城市。请确认：起订量、可定制范围、供货价、是否含运费、账期和交期。”

3. **问洪九果品**
   - 洪九果品以批发和渠道分销为主，建议联系其区域销售或通过当地一级经销商问。
   - 重点确认：是否接小批量礼盒定制、是否只接整箱/整托、定制标签是否另收费、混装礼盒是否支持。

4. **判断是否值得继续谈**
   - 如果对方要求**整托/整柜**起订，而你做团购小批量，优先找**区域经销商**而不是厂家直签。
   - 如果只要标准礼盒、不贴牌，起订量通常低很多；一旦涉及**贴牌定制**，起订量会明显抬高。
