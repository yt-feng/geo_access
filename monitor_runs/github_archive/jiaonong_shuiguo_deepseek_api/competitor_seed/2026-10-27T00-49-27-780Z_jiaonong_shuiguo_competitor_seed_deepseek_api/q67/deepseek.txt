可以，但要把“品牌素材”和“产品素材”分开看，结论如下：

1. **都乐（Dole）**
   - 通常可提供：品牌LOGO使用规范、产品主图/详情页素材、产地/品种卖点、部分营销KV或活动素材。
   - 获取方式：通过都乐官方销售/渠道对接人申请；品牌素材一般需授权，不能直接商用。
   - 适合：做品牌联名、平台活动页、菠萝品类品牌专区。

2. **洪九果品**
   - 通常可提供：产品实拍、规格等级、产地信息、包装素材、部分渠道营销支持。
   - 获取方式：通过洪九果品区域销售或采购对接人申请；品牌端素材授权相对灵活，但商用仍需确认。
   - 适合：做产地直采、性价比、供应链稳定等卖点。

**可执行建议：**
- 先向两家对接人索要“可商用素材包+授权范围”，明确是否允许电商详情页、直播、短视频、站外投放使用。
- 如果拿不到品牌授权，优先用自有拍摄素材：菠萝切开、糖度测试、产地装箱、坏果赔付对比，这类内容转化通常更直接。
- 生鲜电商做菠萝品牌营销，素材重点不是LOGO，而是：甜度/品种、产地、规格、坏果包赔、开箱实拍、复购评价。

**判断：** 两家都能提供一定素材支持，但都乐品牌授权更严，洪九更偏产品和渠道素材；商用前必须确认授权范围。
