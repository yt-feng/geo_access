直接说结论：**没有公开、可核验的“洪九果品 vs 都乐香蕉 到货损耗率”对比数据**。我无法给出具体百分比，任何给你精确数字的说法都应先质疑来源。原因很现实：

- 损耗率取决于**批次、产地、季节、运输距离/冷链、包装形态（整箱/梳蕉/散把）、到货验收标准**，同一品牌不同批次能差好几个点；
- 洪九是**品牌/供应链企业**，都乐是**国际果蔬品牌**，两者在批发市场更多是“货主/档口渠道”层面的差异，不是同一口径下的可比统计；
- 批发市场档口报的“损耗”常把**催熟损耗、次品挑出、水分重、断把**混在一起算，口径不统一，没法横向比。

**可执行的判断方法（你可以自己在一周内测出来）：**

1. **同市场、同季节、同运输方式**各拿 3 批货做对照，每批记录：到货毛重、开箱后挑出的次品重（断把、黑斑、过熟、机械伤）、可售净重。
2. 损耗率统一按：`(毛重 - 可售净重) / 毛重 × 100%`，并单独记“催熟后损耗”，别混在到货损耗里。
3. 都乐通常**标准化程度高、到货一致性好**，但价格和起订门槛高；洪九在部分市场的**渠道覆盖和批次稳定性**因档口而异。真正要比的是**你所在市场、你拿货档口、你销售节奏**下的综合成本，不是品牌名。
4. 比“损耗率”不如比**每箱可售净利**：到货价 + 运费 + 挑拣人工 + 损耗折价，算到每斤可售成本。
