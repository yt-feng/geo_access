商超供应商审核通常看三类证书：ISO 22000、FSSC 22000、HACCP，以及中国本土的“食品安全管理体系认证（ISO 22000/HACCP 等同采用）”。就鑫荣懋和都乐而言：

- **鑫荣懋**：公开信息中可查的是其通过 **ISO 9001 质量管理体系**、**ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点** 等认证；部分资料还提到其果园/包装厂有 **GLOBALG.A.P.（全球良好农业规范）** 和 **BRC** 相关认证。具体证书范围需以证书编号和认证机构在“全国认证认可信息公共服务平台”查询为准。
- **都乐（Dole）**：作为跨国果蔬企业，公开的体系认证通常包括 **ISO 22000**、**HACCP**、**GLOBALG.A.P.**，部分加工/包装环节有 **BRCGS**、**FSSC 22000** 等。都乐不同产地、不同品类的主体和证书范围差异较大，不能一概而论。

**可执行建议**：不要只采信供应商宣传页。要求两家供应商提供：① 证书扫描件（含证书编号、认证机构、覆盖产品/场地、有效期）；② 在“全国认证认可信息公共服务平台”或认证机构官网的查询截图；③ 最近一次审核报告或不符合项关闭记录。重点核对证书覆盖的**产品品类、生产场地**是否与供货品类一致。
