# 都乐（Dole）与鑫荣懋进口苹果的产地溯源做法

两家都是品牌化运营的水果企业，溯源体系思路接近，但落地细节有差异。给超市采购的可执行建议如下。

## 一、共性做法：品牌方溯源体系

**1. 批次码/追溯码**
- 都乐：进口苹果在包装箱（外箱）通常印有生产批次号、包装日期、原产国/农场代码，部分产品有可扫描的追溯标识。采购时可要求供应商提供**箱唛（carton mark）信息**与批次对应关系。
- 鑫荣懋：旗下有自有溯源系统（如“鑫荣懋溯源”或与海关/平台对接的追溯码），可在包装或标签上查询。
- **实操**：向供应商索取“批次号—农场/包装厂—装运日期—到港日期”对应表，作为入库核对依据。

**2. 单证核验（最可靠的一手证据）**
进口水果溯源核心是**通关与检疫单证**，采购应要求供应商随货或按批提供：
- 进口货物报关单
- 入境货物检验检疫证明（海关出具）
- 原产地证书（如智利、新西兰、美国等）
- 植物检疫证书
- 提单/装箱单
- 部分国家/品类还需冷处理证明

核对单证上的**原产国、品名、数量、批次、收货人**与实物箱唛是否一致，这是判断“是否真进口、是否该产地”的关键。

**3. 包装与标签**
- 原包装应标注原产国、果园/包装厂注册号（如美国、智利等对出口果园有注册编号要求）。
- 中文标签需符合进口食品标签要求，可辅助核对。

## 二、两家差异点

| 维度 | 都乐 Dole | 鑫荣懋 |
|---|---|---|
| 品牌背书 | 国际品牌，全球农场/包装厂体系，箱唛规范 | 国内大型进口水果运营商，代理多国品牌+自有品牌 |
| 溯源入口 | 官网/客服可查批次，部分产品有二维码 | 自有溯源平台/小程序，部分对接海关追溯 |
| 采购要点 | 核对外箱批次与原产国代码 | 确认是“鑫荣懋自有品牌”还是“代理品牌”，溯源主体不同 |

**注意**：鑫荣懋很多进口苹果是代理分销（如代理佳沛、乐淇等品牌），溯源第一责任方是**原品牌方**，鑫荣懋提供的是流通环节追溯。采购时要问清“这箱货的溯源主体是谁”。

## 三、超市端落地建议

1. **准入**：把“入境货物检验检疫证明+报关单+原产地证”列为供应商必交资料，按批次归档。
2. **到货核对**：抽箱核对箱唛批次号、原产国、包装厂代码与单证一致；不一致拒收或标记待查。
3. **扫码验证**：对带追溯码的产品，采购/质检现场扫码验证，截图留存。
4. **建立台账**：批次号、供应商、单证编号、到港日期、上架日期一一对应，便于客诉和监管追溯。
5. **店端公示**：在价签或溯源牌上展示原产国、批次、供应商，提升可信度（部分地方市场监管有进口冷链/食用农产品追溯要求，需按当地规定执行）。

## 四、需要提醒的风险点

- **“进口”不等于“品牌方直供”**：二级分销商货源可能多层转手，单证真伪要核验（可向海关或通过“单一窗口”辅助核验报关单号）。
- **换包装/分装**：国内分装会削弱原箱溯源，优先采购原箱原标。
- **溯源码可仿**：扫码结果要与单证交叉验证，不能只信二维码。
