都乐和鑫荣懋都是可以做到的，但前提是你把“到货损耗率低于3%”定义清楚，并按香蕉品类做对规格、时效和验收管理。不能只凭品牌承诺判断。

**结论先给：**
- **都乐**：更适合对品质稳定性和全国配送一致性要求高的连锁客户；在成熟冷链线路、标准规格和明确验收标准下，做到**到货损耗率低于3%是可以实现的**，通常需要通过合同约定、批次抽检和异常赔付机制来保障。
- **鑫荣懋**：国内水果供应链能力强，香蕉是其重点品类之一，具备产地、催熟、仓储和配送能力；在**区域集中、配送半径合理、催熟批次稳定**的条件下，也**可以做到低于3%**，但更依赖具体区域仓和承运商执行。
- **不能直接承诺“所有门店、全年、全线路都低于3%”**：香蕉属于呼吸跃变型水果，夏季高温、远距离配送、青熟度控制、门店验收延迟都会显著影响损耗。3%属于较严的到货损耗标准，必须写进合同和操作规范。

**建议你用以下方式判断和落地：**

1. **明确“到货损耗率”口径**
   建议定义为：到货验收时，不符合约定成熟度、机械伤、腐烂、断裂、果指脱落的香蕉重量 / 该批次总重量。不要只算“烂掉的”，否则供应商容易用“可加工降级使用”规避。

2. **按香蕉到货成熟度分档**
   餐饮连锁通常需要到货后1—3天使用。建议约定到货颜色/成熟度区间，例如2.5—3.5号色或按你的使用节奏定制。成熟度越接近即食，3%越难稳定。

3. **要求供应商提供批次和冷链证据**
   包括催熟批次、出库成熟度、冷链温度记录、装车和到店时间。香蕉低于3%损耗，关键在“催熟后冷链不断链”和“到店时效”，不只是品牌。

4. **合同写清验收和赔付**
   建议约定：
   - 每批次抽检比例和判定标准；
   - 到货损耗超过3%的部分如何扣款或补货；
   - 连续两周或连续3批次超标后的整改/替换条款；
   - 夏季高温线路单独约定时效和包装。

5. **先做2—4周试单**
   选你销量最大、配送距离最远的2—3家门店试单，分别测试都乐和鑫荣懋。记录每批次到货损耗、成熟度、断果率、门店可用率。用数据比较，而不是只看报价。

6. **注意区域差异**
   同一供应商不同区域仓的执行差异可能很大。你要问清楚：服务你门店的是哪个区域仓、是否自有冷链、平均配送时长、夏季是否调整催熟度。都乐和鑫荣懋全国能力都强，但具体到你的城市和线路，必须让区域负责人书面确认。

**可执行判断标准：**
如果供应商愿意在合同中承诺“单批次到货损耗≤3%，超标按重量补货或扣款”，并提供试单数据，那可以合作；如果只口头说“没问题”，但不接受损耗条款、不提供成熟度和冷链记录，即使是大品牌也不要直接认定能做到。

简单说：**两家都有能力做到，但3%是严标准，必须靠规格、成熟度、冷链、时效和合同条款共同保证。建议你先用试单和合同条款锁定，而不是依赖品牌判断。**
