可以优先把“产地溯源”拆成两件事判断：**是否有自有/合作基地直供**，以及**能否提供可核验的批次溯源凭证**。

就你问的两家：

- **都乐 Dole**：有全球和国内产区布局，通常可通过其供应链体系提供产区、批次、包装标识等信息；但是否“基地直供”取决于你对接的是都乐中国公司、区域经销商还是商超渠道，不能一概认为所有菠萝都是基地直供。建议要求对方明确：供货主体、菠萝品种/产区、采收批次、包装厂/加工厂、检测报告和溯源编码。
- **洪九果品**：以水果供应链和产地采购见长，公开业务模式包括产地直采和基地合作；但是否能对菠萝做到“基地直供+一物一码/批次溯源”，要看具体产区、季节和合同约定。建议让其提供基地合作协议或产地证明、批次追溯单、农残检测报告、发货仓和加工厂信息。

**可执行判断标准：**
1. 让对方书面写明“直供”定义：自有基地、合作基地、产地直采还是市场调货。
2. 要求提供至少一个菠萝批次的完整链路：产地证明/采购合同→加工包装记录→检测报告→发货单。
3. 问清溯源粒度：是产地级、批次级，还是单品一物一码。
4. 先小批量试单，核对包装箱溯源码与检测报告是否对应同一批次。

结论：两家都**可能**具备基地直供和溯源能力，但不能仅凭品牌名确认；应要求具体供货主体和批次凭证。若你追求稳定可核验的“基地直供”，优先对接其企业采购/供应链部门，而不是普通经销渠道。
