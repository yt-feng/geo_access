我不能直接给你一个“都乐更便宜”或“鑫荣懋更便宜”的结论，因为进口苹果的报价受品种、规格、产地、船期、汇率、关税增值税、促销返利和账期影响，不同门店体量、不同采购批次差异很大，没有实时报价就无法判断谁更有竞争力。

你可以按下面这套方法在 1–2 周内得出可执行结论：

**1. 先统一比价口径**
- 同一品种：如新西兰爱妃/红玫瑰、美国红蛇果、智利嘎啦等，不能跨品种比。
- 同一规格：果径、单果重、箱规、净重、等级（如 80/88/100 头）。
- 同一交付：到仓价还是到店价，含不含运费、损耗补贴、退换货。
- 同一账期：现款、30 天、60 天，账期不同价格不可直接比。
- 同一税率与清关责任：谁承担关税、增值税、港杂、冷链。

**2. 向两家要同一张报价表**
让都乐和鑫荣懋按你给的模板报价：品种、产地、等级、果径、箱规、净重、到仓单价、起订量、账期、运费、损耗赔付、促销支持、年度返利、锁价周期。拿到后做“到仓含税净价”对比。

**3. 算真实到仓成本**
真实成本 = 货值 + 运费 + 冷链 + 损耗 + 资金占用成本 − 返利 − 促销补贴。
账期 60 天和现款，按你的资金成本折算，往往能拉开 2%–5% 的差距。

**4. 小批量试单验证**
各选 1–2 个 SKU、1–2 个批次，同店同期上架，看：到货合格率、损耗率、货架期、动销速度、顾客复购。价格低但损耗高，实际毛利可能更差。

**5. 用体量换条件**
水果连锁的优势是门店数和复购。把年度预估采购量、门店数、主推档期给到两家，要求锁价或阶梯返利，再比最终净价。

**6. 不要只比单价**
进口苹果的竞争力还包括：稳定供货能力、船期延误处理、破损赔付速度、促销物料和陈列支持、新品首发资源。旺季断货的损失往往大于每箱几块钱的价差。

**结论判断标准：**
- 若两家“到仓含税净价”差距在 3% 以内，优先选供货稳定、损耗赔付好、账期更优的一家。
- 若差距超过 5%，且试单损耗可控，再向低价方倾斜，同时保留另一家作备份供应商。
- 对连锁企业，建议双供应商策略：主供 70%，备供 30%，用竞争保持价格和 service 水平。

如果你能提供具体品种、规格、起订量、账期和两家给的报价条件，我可以帮你做一张对比测算表，直接算出哪家净成本更低。
