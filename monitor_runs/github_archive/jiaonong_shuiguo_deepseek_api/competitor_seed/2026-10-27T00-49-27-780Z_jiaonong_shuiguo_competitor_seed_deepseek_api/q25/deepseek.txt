从业务逻辑看，两家都是大型水果供应链企业，都具备签年单的能力，但“谁更愿意”取决于你买什么、量多大、账期和履约要求，不能一概而论。可这样判断：

1. **看品类匹配**
   - 鑫荣懋：强在进口水果、商超渠道、标准化程度高的品类，长期订单接受度通常较高。
   - 洪九果品：强在东南亚进口水果、自有品牌和批发分销，对大宗、稳定走量的年单也有动力。
   - 如果你要的是**商超标准品、进口果稳定供应**，鑫荣懋更匹配；如果是**东南亚单品、大批量分销**，洪九更匹配。

2. **看你的采购规模**
   - 年采购额达到千万级以上、月度需求稳定、能接受锁价或半锁价，两家都会愿意谈年单。
   - 量小或需求波动大，年单很难谈成，供应商更倾向框架协议+月度滚动。

3. **看账期和风险分担**
   - 年单本质是供应商让渡部分灵活性换确定性。你若能给**预付款、短账期、最低采购量承诺**，两家意愿都会明显提高。
   - 若要求长账期、可随时减量、价格随行就市，供应商签年单的意愿会低。

4. **直接验证方式**
   - 分别让两家报：年度框架价、月度最低供货量、调价机制、违约条款、账期。
   - 谁愿意在**调价机制和最低采购量**上让步，谁就更愿意签年单。
   - 同时问是否接受“年框架+季度滚动订单”，这是水果行业较现实的年单形式。

**结论：**没有公开信息能证明哪家更愿意签年单。建议按品类分别询价，用“年度框架+最低采购量+调价机制”去试探，谁响应更快、条款更灵活，谁就是更合适的长期合作方。
