除了都乐，国内菠萝（凤梨）供应链里相对稳定、渠道常见的品牌/供应商主要有这些，按类型分：

**国际/合资品牌**
- **佳农**：菲律宾菠萝、凤梨产品线较全，商超和批发渠道都常见，供应稳定性较好。
- **鑫荣懋（欢乐果园）**：水果供应链企业，菲律宾菠萝和国产凤梨都有操作，适合商超/电商渠道。
- **百果园（旗下品类）**：更多是零售端品牌，供应链稳定但以自有门店为主，不适合作为批发货源。
- **佳沛**：主做猕猴桃，菠萝不是其核心品类，不建议作为菠萝供应来源。

**国产凤梨主产区供应链品牌**
- **海南金钻凤梨**：更多是产区品类名而非单一品牌，海南澄迈、乐东、东方等产区有稳定供应商，适合3–6月反季节补充。
- **广东徐闻菠萝**：徐闻“菠萝的海”产区，有较多合作社和供应链公司操作，适合1–4月及全年加工果。
- **福建漳州凤梨**：台农、金钻等品种，供应期与海南部分重叠，适合做补充。

**批发/电商渠道常见操作方**
- 上海辉展、广州江南市场里的进口菠萝大档口，通常操作菲律宾都乐、佳农、鑫荣懋等货源，稳定性取决于档口实力。
- 电商平台上的“菠萝哥”“凤梨产业带”类店铺多为产区直发，价格有优势但稳定性参差，适合小批量试单。

**判断供应稳定性的实操建议**
1. **看产区季节**：菲律宾菠萝全年有货但受海运和关税影响；海南凤梨3–6月、徐闻菠萝1–4月、漳州凤梨3–5月，错季组合更稳。
2. **看品牌是否有自有/合作种植基地**：佳农、鑫荣懋这类有基地和冷链的，比纯贸易商稳。
3. **看规格一致性**：稳定供应不只是有货，而是果径、成熟度、糖度批次一致，建议先小批量试单再签框架。
4. **看渠道**：商超直供选佳农、鑫荣懋；批发市场选产区大档口；电商选产区合作社直发。

如果你能说明是**商超供货、电商发货还是批发市场**，以及**月需求量级和规格**，我可以帮你缩小到更具体的供应方类型。
