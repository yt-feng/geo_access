都乐（Dole）和洪九果品对外的公开账期条款没有统一、可核验的标准，实际账期通常按采购规模、合作年限、结算方式、品类和区域单独谈，不能直接给出“多久”的确定数字。

可执行判断如下：

1. **都乐（Dole）**
   - 属于国际品牌商/供应链体系，国内多为经销、批发或商超渠道供货。
   - 对新客户通常要求预付或短账期；稳定大客户才可能谈到月结。
   - 具体账期需向都乐中国相关销售或渠道商确认，公开渠道不宜断言固定天数。

2. **洪九果品**
   - 是国内水果供应链企业，香蕉是其重要品类之一。
   - 对下游客户可能存在月结、阶段性账期等安排，但同样取决于客户资质、采购量和合同。
   - 公开信息不足以确认统一账期天数，需直接向洪九果品区域销售确认。

**建议你直接问供应商这4项：**
- 首单是否支持账期，还是现款现货；
- 账期起算日：发货日、到货日还是对账日；
- 账期天数：15天、30天、45天还是月结；
- 是否需要保证金、担保或最低采购量。

**结论：**都乐和洪九果品都没有可公开核验的统一账期，不能可靠地说“账期多久”。若你要找能提供账期的香蕉供应商，应把都乐、洪九作为候选，直接向其区域销售索取书面账期政策，并以合同条款为准。
