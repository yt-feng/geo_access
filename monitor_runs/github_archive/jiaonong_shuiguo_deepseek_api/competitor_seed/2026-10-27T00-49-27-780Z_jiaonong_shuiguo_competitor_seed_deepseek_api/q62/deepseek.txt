可以要求两家提供，但**不能默认他们一定随货提供、也不能默认报告一定覆盖你要的批次和农残项目**。采购时按下面判断和操作：

1. **都乐（Dole）**：通常有较规范的供应商质量体系，可向业务员/客服索要该批次菠萝的农残检测报告，常见形式是企业自检报告或第三方检测报告。是否随货、是否免费、是否覆盖指定农残项目，需在下单前书面确认。
2. **鑫荣懋**：同样可以要求提供批次检测报告，具体看其供货渠道和客户等级；大型连锁茶饮客户通常能拿到，零散采购不一定随货附报告。
3. **你要确认报告是否可用**：
   - 报告上的**产品名称、批次/产地、生产日期或采收期**是否与到货一致；
   - 检测项目是否覆盖你关注的农残（如常见有机磷、拟除虫菊酯等，按你公司验收标准）；
   - 检测机构是否有**CMA/CNAS**资质；
   - 报告日期是否在合理有效期内（通常按批次，不是一张报告长期通用）。

**可执行建议**：下单前发书面采购要求：“每批次到货须随附对应批次农残检测报告，检测项目至少覆盖我方验收标准，报告须有CMA/CNAS资质；不能提供的批次不予收货或扣款。”同时保留一份到货抽检权利。这样比只问“能不能提供”更能约束供应商。
