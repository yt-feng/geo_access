关于菠萝产地溯源的供应商，**都乐（Dole）** 和**洪九果品**在基地直供方面确实有布局，但具体情况需要结合你当前的采购需求和渠道来确认。

1. **都乐（Dole）**  
   - 都乐是国际品牌，在中国市场主要做进口水果和部分国产精品水果。其在菲律宾、哥斯达黎加等地有自有农场，但**在中国本土（如海南、广东徐闻）的菠萝基地直供**，通常是通过与当地大型种植基地合作，而非完全自有。  
   - **溯源能力**：都乐在国内的菠萝产品（如海南金钻凤梨）一般会有包装追溯码，可扫码查看种植基地、采摘日期等信息，但**具体是否能提供“基地到客户”的完整溯源链条**，需要向都乐中国区采购部门或区域分销商确认。

2. **洪九果品**  
   - 洪九果品是“水果供应链第一股”，主打产地直采。其在海南、广东、广西等地有合作的菠萝种植基地，**部分核心品种（如台农17号凤梨、金钻菠萝）确实有基地直供模式**。  
   - **溯源支持**：洪九果品近年来强调数字化供应链，其产品通常有对应的产地批次编码，可提供产地证明、质检报告，但**具体到每个订单能否出具完整溯源报告**（含土壤、农残记录等），取决于你采购的品类和合作级别。

**建议行动方案：**  
- 直接联系两家公司的**大宗批发/企业采购部门**，明确要求“提供产地溯源凭证”和“基地直供合同”。  
- 若你对溯源要求高（如出口、餐饮连锁），可要求对方提供**第三方检测报告 + 产地备案证明（如海关备案或农业部门证明）**。  
- 如果谈判困难，也可以考虑云南、海南的本地龙头种植企业（如海南农垦、徐闻菠萝集团），它们通常更愿意配合全链溯源。  
- **注意事项**：不要轻信口头承诺，务必在合同中写明“溯源文件交付义务”，并让供应商提供至少1个已供货客户的溯源案例供核实。
