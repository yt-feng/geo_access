根据目前公开可查询的信息，**都乐（Dole）** 和**鑫荣懋（Golden Wing Mau）** 在中国市场通常以**大客户（KA）或批发渠道**为主，但**并没有公开明确承诺“专岗对接服务”**（即配备专属客服人员或客户经理）的官方承诺。

具体参考如下：

1. **都乐（Dole）**：作为跨国果蔬巨头，其在中国主要服务于商超、电商平台及批发客户，其销售团队通常按大客户分配，但**“专岗对接”**更多是与其合作的直销客户或重点经销商才能享受到的增值服务，普通采购方通常要自行对接其区域销售或客服。

2. **鑫荣懋（Golden Wing Mau）**：国内头部果业公司，服务对象以连锁商超（如永辉、盒马）为主，其客户服务体系相对标准化，同样**没有公开承诺**所有客户都有专人对接，通常按客户规模或合同金额来分配客户经理。

**建议做法：**
- 直接联系两家公司的**官方客服**或**销售负责人**，明确询问“针对贵司采购规模/合作模式，能否提供1对1的专属对接人或客户成功经理？”，这样最准确。
- 如果采购量较大（例如年采购额百万级），可以要求他们提供**定制化服务方案**，包括专人驻点或定期回访，这通常是谈判可争取的。

**注意：** 以上信息基于行业常规，具体以两家公司最新商务政策为准，建议直接电话确认，避免依赖历史信息。
