关于菠萝供应商的锁价机制，**都乐（Dole）**和**洪九果品**的具体锁价周期**并无公开固定标准**，且不同客户（商超、餐饮、批发商）、采购量、季节及市场行情会有显著差异。

以下是根据行业惯例和两家公司通常操作模式的**参考信息**，供你在商务洽谈时直接向对方销售/大客户部门核实：

**1. 都乐（Dole）**
- **一般做法**：都乐通常采用“**周度或月度**”定价模式。对于长期大客户（如连锁超市、烘焙连锁），普遍提供**30天**的锁价周期；若市场波动剧烈，可能缩短至**7-15天**；对于特殊定制规格或预付款订单，可协商长达**60天**锁价。
- **建议**：直接联系国内都乐（上海）生鲜公司的大客户销售，明确告知“我司希望将菠萝价格锁定N周”，他们会根据菲律宾/泰国产地到岸价及汇率调整报价。

**2. 洪九果品**
- **一般做法**：洪九作为“端到端”供应链企业，其锁价灵活度更高。通常针对**有稳定月度采购计划**的渠道客户，提供**月度锁价**（30天）；如果采购量达到整车或整柜级别，可争取**季度锁价**（约90天），但合同中会附带“仅当产地价格波动超过5%-8%时，双方协商补差”的条款。
- **建议**：洪九的销售策略偏向“量价挂钩”，建议以连续多月采购量为依托谈判锁价周期。
