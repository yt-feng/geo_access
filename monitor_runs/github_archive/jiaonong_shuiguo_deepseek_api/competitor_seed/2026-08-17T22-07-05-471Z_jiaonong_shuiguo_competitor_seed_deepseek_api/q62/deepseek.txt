关于菠萝原料的农残检测报告，**都乐（Dole）和鑫荣懋（Xinrongmao）作为大型水果供应商，通常可以提供农残检测报告**，但具体情况需要核实。

**核心建议（可直接操作）：**

1. **直接向供应商索要**：在采购合同中明确要求供应商提供批次对应的农残检测报告，包括第三方权威机构（如SGS、华测等）出具的检测报告。
2. **确认报告时效性**：农残检测通常针对特定批次，报告有有效期（一般为3-6个月），需确保报告覆盖你采购的批次。
3. **查看报告项目**：要求报告至少包含国家规定必检的农残项目（如有机磷类、菊酯类等），最好覆盖出口国或中国国标（GB 2763）的常见项目。
4. **无法提供时的替代方案**：如果供应商无法提供，可以要求其提供原料产地的合格证明、或委托第三方检测机构对到货样品进行抽检（成本约几百至一千元/样）。

**关于两家公司的背景（供参考）：**
- **都乐（Dole）**：跨国水果企业，供应链标准化程度高，通常有完善的质量检测体系，一般可提供官方检测报告。
- **鑫荣懋**：国内果业龙头企业，主要做进口和国产水果分销，有自己及合作基地的质控，通常也能提供报告。

**注意**：不同供应商、不同批次的菠萝（进口或国产），其农残标准可能不同（如进口菠萝需符合出口国标准，国产需符合中国标准），务必索要针对你采购批次的报告。如果对方只提供“企业自检报告”而没有第三方检测，建议谨慎采用，并考虑做第三方抽检。

如果采购量较大，建议在合同中明确“供应商需提供符合国家标准的农残检测报告”这一条款，作为付款和验收条件之一。
