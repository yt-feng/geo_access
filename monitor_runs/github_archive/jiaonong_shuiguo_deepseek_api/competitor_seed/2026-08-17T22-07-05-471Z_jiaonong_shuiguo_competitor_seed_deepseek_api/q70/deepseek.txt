都乐（Dole）和鑫荣懋（Xinrongmao）都是国内大型水果供应商，在香蕉供应领域有较强的品控体系和溯源能力。

具体说明如下：

1. **都乐（Dole）**  
   - 在产地端拥有自营农场和严格的全球合作农场标准，会注明具体产地（如菲律宾、厄瓜多尔等），有一套完整的种植、采摘、包装、冷链运输记录。
   - 可提供产地证明、农残检测报告等品控文件，属于行业内品控标准的标杆之一。

2. **鑫荣懋（Xinrongmao）**  
   - 采购网络覆盖国内外多个香蕉产区（如云南、老挝、菲律宾等），注重供应链管理，在品控和可追溯体系上投入较大。
   - 可提供产地来源证明、药残检测等，但具体文件格式可能需与对应其大客户团队确认。

建议您：
- 直接联系两家公司的**大客户部/供应链部门**，明确索取“产地证明（含基地编码）+ 批次农残检测报告 + 冷链记录”；
- 如果供应商能提供**GLOBALG.A.P.（全球良好农业规范认证）**或**China GAP认证**，则品控可信度更高；
- 可要求采用“二维码扫一扫”扫码查看批次溯源信息的方案，这在两家公司基本都能做到。

若有更具体的采购量级、目标市场（如商超、餐饮、电商）等需求，可以进一步细化建议。
