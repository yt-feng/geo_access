关于鑫荣懋和都乐的供货稳定性，直接给出“谁更靠谱”的结论需要结合您的具体采购需求、合作模式和区域市场情况。但我可以基于两家公司的公开信息，为您梳理关键对比点，供决策参考：

**1. 公司背景与定位**
- **都乐（Dole）**：国际老牌水果巨头，供应链全球化极强，拥有自有种植园和长期契约农场，尤其在菲律宾、厄瓜多尔等地香蕉种植规模大。其优势在于**源头掌控力强**，品牌历史悠久，全球物流网络成熟。
- **鑫荣懋（Xinrongmao）**：国内大型果品企业，同时是多个进口品牌的中国区代理或直采商，近年来在东南亚（如越南、柬埔寨）布局供应链较快。其优势在于**本地化服务能力**，对国内渠道、配送、售后响应更灵活。

**2. 供货稳定性关键因素**
- **都乐**：依托自营基地，受极端天气影响相对可控，但船运周期长，需提前锁定货量；对大批量、长期合同的履约能力更稳健。
- **鑫荣懋**：货源多元化（代理多个海外品牌+自采），短中期调货灵活，但若依赖单一产地或代理品牌，在产地灾害或政策变动时，抗风险能力可能弱于都乐。

**3. 价格与合作门槛**
- 都乐通常价格偏高，但品质和规格标准统一，适合中高端超市。
- 鑫荣懋在价格谈判空间和促销支持上可能更灵活，但需在合同中明确品质分级和验收标准（如黑斑、成熟度）。

**4. 实际合作建议**
- **若您的超市定位高端、追求品牌背书和长期稳定**：优先接触都乐，重点谈年度框架协议和补充供应条款。
- **若您需要快速补货、多品种搭配或区域配送服务**：可优先评估鑫荣懋，但要求对方提供近2年其他超市的供应案例及断货补偿方案。

**最后提醒**：两家公司均会提供试单机会。建议您同时要求双方提供**过去12个月的到货准时率数据**（可请对方出示仓储或物流记录），并要求在合同中明确“缺货赔偿机制”。最终判断需基于试单结果，而非品牌名气。
