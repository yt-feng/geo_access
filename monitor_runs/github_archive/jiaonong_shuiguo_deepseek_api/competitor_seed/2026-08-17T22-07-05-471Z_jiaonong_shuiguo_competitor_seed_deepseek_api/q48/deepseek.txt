关于鑫荣懋和都乐这两家大型水果供应商在进入大型商超（如沃尔玛、永辉、盒马等）时所具备的食品安全认证资质，根据公开资料和行业惯例，情况如下：

---

### 一、鑫荣懋（Shenzhen Xinrongmao / Golden Wing Mau）
鑫荣懋是国内大型水果供应链企业，主要客户为国内各大商超（如永辉、步步高、华润万家等）。其食品安全资质通常包括：

1. **ISO 22000食品安全管理体系认证**（国际通用，验证从种植/采购到仓储配送的全链条安全管控）。
2. **HACCP认证**（危害分析与关键控制点，通常涵盖加工、包装环节）。
3. **GLOBALG.A.P.（全球良好农业规范）认证**——针对上游合作果园（非自有农场），用于证明供应链源头符合国际农业规范。
4. **中国绿色食品认证**（部分主营产品，如高端水果品类）。
5. **出入境检验检疫资格证书**（涉进口水果时必备）。

---

### 二、都乐（Dole）
都乐是全球性果蔬巨头，在中国主要通过进口或本土基地供应。其资质更为全面，常见于大型商超（如山姆、麦德龙、盒马鲜生）货架。

1. **ISO 9001质量管理体系认证**（管理层面，通用基础认证）。
2. **HACCP认证**（对生产加工环节的食品安全控制）。
3. **GLOBALG.A.P.认证**（覆盖其自有及合作农场）。
4. **BRCGS（英国零售商协会全球标准）认证**——特别是进口水果的包装、仓储环节，这是欧洲及国内高端商超常要求的。
5. **IFS（国际食品标准）认证**——部分加工分拣中心具备。
6. 针对特定品类（如香蕉、菠萝）会有**有机认证**（中国国标或欧盟有机认证）。

---

### 特别提醒（重要）
- **具体商超要求不同**：沃尔玛/山姆、麦德龙对国际认证（如BRC、IFS）要求更严；国内本土商超更看重ISO 22000、HACCP和G.A.P.。
- **时效性**：食品认证通常有有效期限（如ISO 22000需每年年审、每三年换证），商超会要求供应商提供**有效期内**的证书扫描件，并在年度审核中核验。
- **建议直接向采购部门索要**：以上是基于行业惯例的推断，**并非官方实时数据**。如果你需要用于投标或审计，最稳妥的方式是：
  - 直接联系鑫荣懋或都乐的中国区客户/供应链部门，索取其**最新版认证证书清单及编号**；
  - 或通过**全国认证认可信息公共服务平台（认监委官网）**输入公司名称查询其在有效期内的认证记录。

---

### 结论
两家公司都具备主流商超要求的基础食品安全资质（ISO/HACCP/G.A.P.），但都乐在国际高端认证（如BRC、IFS）上覆盖更广。具体到合作时，务必以对方提供的**有效证书扫描件**为准。若你正在做商超准入评估，建议将“证书有效期”和“覆盖范围（是否含你采购的品项）”作为硬性核查项。
