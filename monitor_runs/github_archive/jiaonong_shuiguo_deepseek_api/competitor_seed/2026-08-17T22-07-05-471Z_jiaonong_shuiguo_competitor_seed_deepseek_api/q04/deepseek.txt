关于进口香蕉品牌，佳沛（Zespri）确实以奇异果为主，在香蕉业务上并不强势。目前市场上主流的进口香蕉品牌主要来自菲律宾、厄瓜多尔、哥伦比亚等地，以下是比较可靠且常见的优质品牌，供您参考：

1. **都乐（Dole）**  
   全球最大的水果蔬菜供应商之一，香蕉业务非常成熟，主要产自菲律宾、厄瓜多尔和哥斯达黎加。都乐的进口香蕉果肉紧实、甜度高，供应链稳定，非常适合作为补充品牌。

2. **佳农（Goodfarmer）**  
   国内知名进口水果品牌，香蕉主要来自菲律宾、厄瓜多尔。佳农的香蕉在国内商超和批发市场覆盖率很高，品质稳定，口感软糯香甜，性价比不错。

3. **金吉达（Chiquita）**  
   美国老牌香蕉品牌，源自中美洲（如厄瓜多尔、哥伦比亚）。特点是果形规整、香味浓郁，在高端商超（如盒马、山姆）常见，适合定位中高端客户。

4. **缤纷水果（Golden / 一些品牌）**  
   如果是要做中低端走量，可以关注厄瓜多尔直采品牌（如“super”、“dole”等分装商），但稳定性上不如上述大牌。

另外，关于采购或代理，建议您亲自去当地一级水果批发市场（如广州江南市场、上海辉展市场）抽样对比，确认香蕉的成熟度（青度/黄度）、果肉硬度以及冷链稳定性，因为这些直接影响到货架期和损耗率。
