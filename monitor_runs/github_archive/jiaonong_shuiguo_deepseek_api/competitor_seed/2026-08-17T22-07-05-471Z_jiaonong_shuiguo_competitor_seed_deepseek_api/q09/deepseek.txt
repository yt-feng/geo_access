除了都乐（Dole）和佳沛（Zespri），以下是一些适合礼品团购的进口水果品牌，它们品质稳定、包装精美，适合中高端送礼场景：

### 1. **凤梨 / 菠萝类**
- **金菠萝（Golden Pineapple）—— 哥斯达黎加/菲律宾产**  
  常见品牌如 **“Diva”** 或 **“Goldpine”**，果肉金黄、甜度高，礼盒包装大气。

### 2. **樱桃 / 车厘子**
- **智利车厘子**：目前进口量最大，常见优质品牌有 **“Sunkist”**（也做橙子）、**“Prize”**、**“Goldsun”**。  
  按规格（如JJ、JJJ）分级，礼盒通常10斤装或5斤装，适合冬季团购。

### 3. **葡萄 / 提子**
- **美国红提/青提**：品牌如 **“Delano”**、**“Sun World”**（主打无籽红提和青提），果实紧实、甜脆。
- **澳大利亚甜心青提**：品牌 **“Mayfair”** 或 **“Auspic”**，皮薄无籽，礼盒精致。

### 4. **牛油果**
- **智利/秘鲁牛油果**：品牌如 **“Avocados from Peru”** 或 **“Mission”**（美国品牌，全球采购）。  
  注意选择果熟度一致的，适合做成商务礼盒（搭配其他水果）。

### 5. **柑橘 / 橙子**
- **美国新奇士（Sunkist）**：经典品牌，血橙、脐橙和夏橙，适合大众送礼，性价比高。
- **南非橙（Valencia）**：品牌如 **“Outspan”**，果香浓，适合团购预算中等的情况。

### 6. **梨 / 苹果**
- **新西兰爱妃（Envy）苹果**：品牌授权种植，果肉脆甜，无氧化变黄，适合高端礼盒。
- **韩国新高梨**：品牌如 **“Golden Pears”**，水分大、甜度高，包装多为金属色礼盒。

### 7. **奇异果 / 猕猴桃（除佳沛外）**
- **意大利金色猕猴桃**：品牌如 **“Jingold”**，品质与佳沛接近，但价格略低，适合差异化的团购需求。

### 8. **椰子 / 椰青**
- **泰国椰青**：品牌如 **“Amru”** 或 **“Chokchai”**，带有切顶包装，适合夏季礼品，与高端水饮搭配。

---

### 团购选购建议（重要）：
- **看产地与季节**：如车厘子冬季选智利、夏季选美国或澳洲；牛油果优先墨西哥/秘鲁。
- **确认单果重与规格**：礼盒要标注“xx个装/xx斤”，避免装数差异引发售后。
- **包装与授权**：要求供应商提供品牌授权书（尤其出口品牌），防止窜货或贴牌。
- **组合搭配**：可考虑“2-3款进口水果+1款国产高端水果（如丹东草莓）”混搭，控制成本且更显丰富。
