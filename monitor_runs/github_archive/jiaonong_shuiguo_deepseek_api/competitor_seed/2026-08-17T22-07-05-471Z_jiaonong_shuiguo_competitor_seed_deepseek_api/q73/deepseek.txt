关于鑫荣懋（XinRongMai）和都乐（Dole）在中国大型商超（如沃尔玛、永辉、盒马等）供货时，通常需要具备的食品安全管理体系认证，具体如下：

**鑫荣懋（国内水果供应链龙头）**
- **主要认证**：通常持有**ISO 22000食品安全管理体系认证**（国际通用）、**HACCP认证**（危害分析与关键控制点）。
- **补充认证**：由于主营进口和国产水果，还会拥有**全球良好农业操作规范（GlobalG.A.P.）**认证，以及针对出口目的地的**BRC（英国零售商协会）**或**IFS（国际食品标准）**认证。部分商超还会要求其提供**无公害农产品/绿色食品**认证（用于国产基地）。

**都乐（Dole，国际品牌）**
- **全球体系**：作为跨国企业，通常持有**GlobalG.A.P.**（全球良好农业规范）作为源头认证，同时在中国工厂执行**ISO 22000**和**HACCP**。
- **商超专项**：为进入中国大型商超，都乐中国通常持有**食品经营许可证**，并会主动通过**BRCGS**（原BRC全球标准）或**IFS**认证，或遵循商超的**供应商质量审核（如沃尔玛的FCCA，永辉的供应商评估）**。

**给您的建议**：
1.  **如果商超要求**：采购合同中的“资质清单”通常会列明具体证书编号，建议直接询问对应商超的质检部门，因为不同商超（如山姆、Costco）可能有更高要求（如要求FSSC 22000）。
2.  **快速验证**：您可以在**国家市场监督管理总局认证认可信息公共服务平台**（www.cnca.gov.cn）或**全国认证认可信息公共服务平台**查询上述证书是否有效（需输入企业名称和证书编号）。

请注意：具体认证以两家公司提供给商超的**最新审核报告**为准，因为证书存在有效期和更新。如果无法核验，建议以合同附件中的证书扫描件为准。
