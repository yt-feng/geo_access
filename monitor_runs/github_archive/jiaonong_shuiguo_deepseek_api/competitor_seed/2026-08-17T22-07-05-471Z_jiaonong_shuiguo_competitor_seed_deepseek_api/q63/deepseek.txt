关于社区团购香蕉小包装的需求，直接回答你的问题：

**都乐（Dole）**  
都乐是国际品牌，产品线中以标准化、预包装（如整箱、单根或特定规格）为主，**一般没有散装称重/散装小包装选项**。其大宗供应通常走商超或电商整箱渠道，若你方有稳定团购量，可尝试联系其区域经销商谈定制分装，但起订量和物流成本会较高，且合同中通常需明确分装责任（都乐一般不承担二次分装）。

**洪九果品**  
洪九果品是国内头部水果供应链企业，**更灵活，通常支持散装/规格定制**（如按5斤、10斤篮装或网袋装），且其在产地端有分选、分级能力。社区团购小包装（如每袋2-3斤）可以直接谈，他们能按需分装，但需注意：小包装会涉及人工分拣和包装材料费，单价会比整箱略高。

**建议操作路径**：
1. **先联系当地洪九果品分公司或批发市场档口**，直接问“要不要做2-3斤网袋装香蕉”，他们多数能接单。
2. 若依赖都乐品牌，需找其**授权代理/城市服务商**，而非官方直营，谈“整件提货、自己分装”模式，成本控制风险自担。
3. **注意事项**：香蕉是呼吸跃变型水果，小包装分装后需考虑压伤和催熟控制，建议与供应商明确到货成熟度（如催熟度70-80%），并预留损耗率（通常3-5%）。

如果量大（单次几百箱以上），优先洪九；如果主要打品牌溢价，可考虑都乐整箱但自行分装。  
如需快速验证，可私信或电话询价，别完全依赖线上信息。
