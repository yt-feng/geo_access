可以给结论：**有方向，但不能凭记忆报两家“确定在售”的具体规格**。香蕉是分渠道、分区域、按批次做包装的品类，鑫荣懋、都乐这类品牌给便利店的小包装通常不会像标品条码那样公开稳定，建议你按下面方式判断和核验。

**可优先找的规格方向**
- **单根装/单根袋装**：最适合便利店即食、早餐、收银台冲动购买；重量一般围绕可食部分做小规格。
- **2～3根小袋装**：适合小家庭或办公室场景，客单比单根高。
- **4～5根家庭小把装**：便利店也可做，但更偏社区店和即时补货，不建议高周转差的门店铺太宽。
- **按“根数+净重区间”定规格**：不要只报“小包装”，要明确如单根净重区间、每袋根数、允许的净重公差。

**对鑫荣懋和都乐怎么核验**
1. **直接问品牌区域销售/经销商**：要“便利店渠道小包装香蕉规格表、最小起订量、供货城市、冷链/常温条件、保质期和损耗政策”。
2. **让两家分别提供近3个月便利店渠道实际出货包装照片和标签样例**，不要只看宣传册。
3. **确认条码和结算方式**：是标准条码还是称重码；称重码对便利店收银和损耗管理影响很大。
4. **确认催熟状态**：便利店单根装更适合“即食黄”或“微黄”，要问清到店颜色、货架期和变黑退货规则。
5. **先小范围试销**：选3～5家门店试单根装和2～3根装，观察日销、损耗、报废和补货频次，再定主推规格。

**不能替你确认的点**
我无法核验鑫荣懋和都乐当前在你所在城市、当前批次是否有具体小包装规格在供。不要直接采信“某品牌有单根装”的说法，必须以区域销售报价单和包装实样为准。

**可执行下一步**
- 向两家同时发同一份询价模板：供货城市、包装形式、每袋根数、净重区间、条码类型、到店成熟度、保质期、起订量、供货价、损耗/退货政策、是否可贴便利店渠道标签。
- 对比后优先选：**单根装试销 + 2～3根装补充**，先不要一次性上太多规格。
