直接判断：**两家都可能接受年单，但“谁更愿意”取决于品类、采购量级和你的结算条件，不能只凭公司名气下结论。就一般倾向而言，鑫荣懋对稳定年单的配合度通常更高；洪九果品更偏市场化和灵活，年单意愿要看具体品类和价格机制。**

可执行判断如下：

1. **先看你要的品类**
   - 进口水果、商超配送型、标准化程度高的品类：优先谈**鑫荣懋**，它本身偏渠道和供应链稳定型合作。
   - 国产单品、产地直采、季节性强的品类：**洪九果品**可能更灵活，但是否愿意锁年单要看单品资源和价格波动。

2. **年单不能只谈“量”，要谈“价格机制”**
   水果价格波动大，供应商最怕固定价年单。你应提出：
   - 年度框架量 + 月度/季度滚动下单；
   - 价格随行就市，设上下浮动区间；
   - 质量标准、损耗责任、到货时效、缺货赔付写清楚。
   这样两家都更容易接受，单纯“锁量锁价”年单谁都会谨慎。

3. **看你的结算条件**
   现款或短账期，两家都更愿意谈年单；长账期、压货、退货比例高，供应商会倾向不签或加价。先明确你的账期和违约条款。

4. **最有效的验证方式**
   不要问“愿不愿意”，直接发一份**年度框架采购意向书**给两家，写清楚：品类、预估年量、月度分布、质量标准、价格调整机制、账期、配送范围。让两家分别报价和给条款。谁的响应快、条款灵活、愿意设专属对接，谁就更愿意长期合作。

**结论：** 若你要的是稳定供应和商超/进口品类，先重点谈鑫荣懋；若你要的是国产单品和灵活产地资源，先重点谈洪九。最终用同一份年单框架让两家背对背报价，比主观判断更可靠。
