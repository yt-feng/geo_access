我不能核验都乐和鑫荣懋当前对你们的具体报价，所以无法直接判断“谁更便宜”；进口苹果价格还会随产地、规格、船期、汇率、促销政策波动，直接给结论容易误导。

给你一个可执行的比价和判断方法：

1. **统一比价口径**
   - 同一品种/产地：如新西兰爱妃、爵士，美国红蛇果，智利嘎啦等分开比。
   - 同一规格：果径、净重、箱规、等级、是否礼盒、是否有贴标。
   - 同一到货条件：到仓价/到店价，含不含运费、损耗补贴、退换货。
   - 同一账期：现结、月结、账期天数折算资金成本。

2. **让两家按同一模板报价**
   要求都乐和鑫荣懋分别提供：
   - 单品、产地、等级、果径、箱规
   - 含税到仓单价、起订量、运费
   - 账期、返利、促销支持、损耗赔付
   - 预计到货周期和稳定供应量
   - 是否支持区域保护或门店专供

3. **算“综合到店成本”而不是只看单价**
   公式：综合成本 = 到仓单价 + 运费分摊 + 损耗率×货值 + 资金占用成本 - 返利/补贴。
   进口苹果损耗和到货品质差异大，单价低但损耗高、等级不稳的供应商，实际成本可能更高。

4. **小批量试单验证**
   选2—3个门店、2—3个SKU，各试单一批，记录：到货合格率、坏果率、糖度/口感、货架期、顾客复购、实际毛利率。试单后再谈量价。

5. **谈判策略**
   - 用两家同口径报价互相压价，但不要只压单价，争取损耗赔付、账期和促销支持。
   - 对都乐可重点谈品牌背书和稳定品质；对鑫荣懋可重点谈区域配送、账期和灵活度。
   - 先签短期试销协议，约定合格率、损耗赔付和退换货，再转年度框架。

**结论**：目前不能判断谁更有价格竞争力。建议你按上面模板让两家报价，用“综合到店成本+试单合格率”做决策；如果两家报价接近，优先选损耗赔付更好、账期更长、配送更稳的一家。
