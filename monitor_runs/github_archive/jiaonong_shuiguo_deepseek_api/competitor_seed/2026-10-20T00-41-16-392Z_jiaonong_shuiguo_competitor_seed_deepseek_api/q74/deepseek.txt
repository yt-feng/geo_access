都乐和洪九果品都没公开统一的水果礼盒定制起订量，实际以区域经销/项目制报价为准，不能直接给准确数字。可按下面方式快速判断和询价：

1. **都乐（Dole）**
   - 团购礼盒通常走区域经销商或企业团购渠道，起订量因城市、礼盒规格、是否贴牌而变。
   - 一般企业团购礼盒常见门槛在**几十箱到几百箱**量级，贴牌/定制包装往往更高。
   - 建议直接问：①当地都乐经销商企业团购负责人；②都乐官方客服转团购渠道。询价时明确“数量、预算、交付城市、是否要定制LOGO/包装、是否要一件代发”。

2. **洪九果品**
   - 洪九偏批发和渠道分销，礼盒定制多按项目谈，起订量取决于品类、产地、包装和配送方式。
   - 同样没有公开统一起订量，常见也是**按箱/按托盘/按整车**分级报价，定制包装门槛通常高于标准礼盒。
   - 建议联系洪九当地分公司或大客户/团购渠道，问“标准礼盒起订量”和“定制礼盒起订量”两档。

**可执行建议：**
- 先定3个参数再询价：采购总量（如100/300/500箱）、单盒预算、是否定制包装和LOGO。
- 同时找都乐、洪九各2个渠道（官方+当地经销商）比价，要求书面报“起订量、阶梯价、打样费、交期、损耗赔付”。
- 如果首批量小，优先选标准礼盒贴标，不要直接开定制包装，门槛会低很多。
