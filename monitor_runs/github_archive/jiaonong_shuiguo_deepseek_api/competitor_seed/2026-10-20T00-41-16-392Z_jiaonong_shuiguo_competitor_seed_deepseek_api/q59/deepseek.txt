账期通常不是品牌方统一对外公布的固定政策，而是按采购规模、合作年限、结算方式、区域经销/直供关系逐单谈。因此“都乐账期多久”“洪九果品账期多久”没有可核验的公开统一答案；我不能给你编一个确定天数。

可执行建议：

1. **先确认合作主体和渠道**
   - 都乐在中国涉及不同运营主体和经销体系，直接找对应区域销售/大客户渠道问结算政策。
   - 洪九果品是上市公司，但具体客户账期属于商业条款，需对接其销售或供应链金融部门确认。

2. **询价时直接问这4项**
   - 首单是否支持账期，还是现款/预付；
   - 标准账期天数及起算日（发货日、到货日、对账日还是开票日）；
   - 是否需要保证金、担保或供应链金融；
   - 逾期利率、返利与账期是否绑定。

3. **判断对方能否给账期的信号**
   - 有稳定月度采购量和历史合作，才更可能给30—60天；
   - 新客户通常先款后货或短账期试单；
   - 大品牌直供账期往往比区域经销商更严，经销商反而可能更灵活。

4. **谈判策略**
   - 先争取“首单现款、次单15天、稳定后30天”的阶梯；
   - 用预付款换价格，或用保证金换账期；
   - 要求书面写明账期起算和对账流程，避免口头承诺。
