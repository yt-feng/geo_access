可以，但需要把“基地直供”和“产地溯源”分开看：

1. **都乐（Dole）**
   - 有自有/合作种植基地和较成熟的产区供应体系，菠萝是其常规品类之一。
   - 是否能做到“基地直供到你方”，取决于你采购的是鲜果批发、商超配送还是加工原料，以及所在区域由哪个配送中心/代理商供货。
   - 溯源方面通常可提供产区、批次、包装标识等信息，但具体到“单批次可查种植基地”的程度，需要向都乐中国区销售或当地经销商书面确认。

2. **洪九果品**
   - 以水果供应链和产地采购为主，菠萝属于其经营品类范围，具备产区采购和分选包装能力。
   - “基地直供”更可能是产地直采+配送中心分拨模式，不等于每个批次都来自单一自有基地。
   - 可要求其提供产地证明、批次号、检测报告和供货基地/合作社信息，确认能否做到批次级溯源。

**可执行判断建议：**
- 向两家分别索要：①菠萝供货产区清单；②近3个月批次溯源样例；③基地/合作社名称及合作协议证明；④检测报告；⑤是否支持到厂验厂或视频验基地。
- 如果对方只能提供“产地省份”而不能提供“基地/合作社+批次对应关系”，就不算严格意义的产地溯源。
- 若你要的是稳定大宗供应，建议同时询价都乐区域经销体系和洪九当地分公司，并对比“直供价、起订量、损耗赔付、溯源文件完整性”。

结论：**两家都有产地供应和一定溯源能力，但“是否基地直供”不能一概而论，必须以具体产区、品类、批次和供货区域书面确认。**
