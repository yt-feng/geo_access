可以支持，但需要区分“能提供”和“需授权确认”两类：

1. **都乐（Dole）**：通常有较成熟的品牌素材体系，包括产品图、品牌Logo、包装图、产地/品种介绍、营养卖点、宣传视频等。生鲜电商做菠萝品牌营销时，可以向都乐对接的销售/市场人员申请授权素材包。**不能默认可公开商用**，需确认使用范围（站内详情页、短视频、直播、社群、线下物料）和期限。

2. **洪九果品**：作为水果供应链企业，通常能提供菠萝品类相关的产品图、规格信息、产地/分级标准、包装和部分品牌宣传资料。但其品牌素材的公开营销授权同样需要向对接业务或市场部门确认，尤其是涉及“洪九”品牌标识、检测报告、产地证明等。

**可执行建议：**
- 分别向都乐和洪九果品的对接销售提出“素材授权申请清单”：产品白底图、场景图、品牌Logo、包装图、短视频、卖点文案、检测/产地证明。
- 明确用途：电商详情页、直播切片、短视频投放、社群海报、线下堆头。
- 要求书面授权或邮件确认，避免侵权风险。
- 如果对方不提供公开授权素材，可改用自拍商品图+平台自有品牌文案，仅客观描述品种、规格、产地，不突出对方品牌标识。

**判断：** 两家大概率能提供营销素材，但都需走授权确认；不能直接假设素材可公开商用。
