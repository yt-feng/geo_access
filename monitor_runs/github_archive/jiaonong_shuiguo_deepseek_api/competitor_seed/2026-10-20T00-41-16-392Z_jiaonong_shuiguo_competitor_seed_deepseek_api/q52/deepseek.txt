我无法核验都乐和鑫荣懋针对茶饮渠道的到货损耗率，不能给出两家公司的具体损耗数据；这类数据通常随批次、季节、运输距离、验收标准和冷链条件变化，公开渠道也没有统一口径。

可以按下面方式做出可执行判断：

1. **不要直接问“损耗率是多少”**  
   要求供应商提供近3个月、同品类（如菠萝/凤梨）、同规格、同运输方式的到货验收记录，按“到货总箱数/件数”和“可验收合格数”计算：
   - 到货损耗率 =（到货总件数 − 验收合格件数）÷ 到货总件数 × 100%
   - 同时区分：外观损伤、压伤、腐烂、成熟度不符、重量短缺、温度异常。

2. **用试单对比两家**  
   各下2–3批同规格试单，统一验收标准（糖度、单果重、果径、成熟度、允许缺陷比例），记录每批损耗。连续3批以上再比较，单批数据不能代表稳定水平。

3. **合同里锁定规格和赔付**  
   明确品种、单果重/果径、成熟度、糖度下限、允许缺陷比例、冷链温度、到货时限，以及超出约定损耗的补货或扣款规则。

4. **茶饮原料更应关注“可用出成率”**  
   对菠萝而言，到货损耗之外还要看去皮去芯后的果肉出成率、糖度和酸度稳定性。建议让两家按你的加工方式提供样品，做小批量出成测试。

如果你能提供所在城市、月用量、规格要求（如单果重、糖度、是否鲜切）和验收标准，我可以帮你把试单验收表和损耗计算口径整理成可直接使用的版本。
