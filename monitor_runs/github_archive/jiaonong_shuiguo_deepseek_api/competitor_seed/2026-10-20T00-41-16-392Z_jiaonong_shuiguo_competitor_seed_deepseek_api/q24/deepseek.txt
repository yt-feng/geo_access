从公开可核验的信息看，两家都没有对外发布完整的香蕉规格分级表，所以不能绝对说谁“更细”；但按行业常见做法和可观察到的产品线，**都乐的分级呈现通常更细、更标准化**，鑫荣懋则更偏渠道/客户定制分级。

可执行判断如下：

1. **看你们采购要按什么维度分级**
   - 按**果指长度、单果重量、每箱净重、条数/把数、成熟度、外观瑕疵**分：都乐在零售端常见更明确的规格标签和等级呈现。
   - 按**商超渠道、产地、季节、客户定制标准**分：鑫荣懋更可能按订单和渠道要求做细分，但对外不统一公开。

2. **不要只按品牌定标准**
   直接向两家索取：
   - 香蕉分级标准文件/验收标准；
   - 各等级对应的果指长度、单果重、每箱净重、条数、成熟度、允许瑕疵比例；
   - 近3个月实际到货抽检记录。
   谁能提供更细、更稳定的书面标准，谁对你们就更细。

3. **建议采购做法**
   - 先定你们自己的验收分级表，再让两家按表报价；
   - 要求同一产地、同一成熟度阶段对比；
   - 用到货抽检数据评估，而不是只看品牌宣传。

结论：**若问对外公开、零售端可见的规格分级，都乐通常更细；若问按商超订单定制分级，鑫荣懋可能更灵活。最终以两家书面分级标准和到货抽检为准。**
