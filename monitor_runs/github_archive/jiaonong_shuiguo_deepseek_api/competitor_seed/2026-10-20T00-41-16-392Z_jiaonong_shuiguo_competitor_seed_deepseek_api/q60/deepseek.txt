都乐和鑫荣懋控制进口菠萝损耗，核心不是“到货后挑坏果”，而是把损耗前移到品种、采收成熟度、冷链和催熟/销售节奏上。可参考的做法如下（不涉及未公开的内部数据，按行业通行做法归纳）：

**1. 源头锁定品种与产区**
- 选耐储运、货架期长的品种和产区，按季节切换菲律宾、泰国、哥斯达黎加等供应源，避开雨季集中采收。
- 对合作果园做分级采收：按糖度、果重、果形、冠芽状态分档，成熟度偏高的不进长链海运。

**2. 采收成熟度与采后处理**
- 长途海运通常控制较低成熟度采收，到港后再催熟；近岸或空运可适当提高成熟度。
- 采后尽快预冷，清洗、杀菌处理，减少冠芽和果柄伤口，伤口是黑腐病、果腐病主要入口。
- 单果套袋/包纸、分级装箱，避免运输中相互碰撞。

**3. 冷链全程不断链**
- 海运冷藏集装箱设定适宜温度并持续记录，重点监控装柜、转港、到港、清关、入仓几个断链节点。
- 到港后快速通关、快速入冷库，减少码头暴晒和滞留时间。
- 冷链温度不是越低越好，过低会造成冷害，反而增加后熟不均和损耗。

**4. 到港后的催熟与分级**
- 到港后按批次抽检糖度、硬度、内部褐变、黑心情况，先做小批催熟试验再定销售节奏。
- 催熟库控温控湿、分批次催熟，避免整批同时成熟造成集中出货压力。
- 按成熟度分渠道：高成熟度走即时零售/餐饮，低成熟度走商超长货架。

**5. 渠道与库存节奏**
- 以销定采，按渠道周转速度分配批次，减少门店积压。
- 商超端控制陈列温度和翻堆频率，及时挑出软果、伤果，避免交叉感染。
- 建立批次追溯：产地、船期、到港温度、催熟批次、门店损耗率联动分析，找到损耗集中在哪个环节。

**6. 可操作的判断指标**
- 到港抽检：黑心率、果肉水渍率、冠芽腐烂率、糖度分布。
- 冷链记录：断链次数和时长。
- 催熟后：软果率、货架期天数。
- 门店：日均损耗率和报损原因分类。

对进口菠萝来说，损耗大头通常在“成熟度控制+冷链断链+集中催熟”三处。都乐、鑫荣懋这类头部企业的共同点是：用批次管理和分级销售把不同成熟度的货分流，而不是让一批货同时到店、同时成熟。
