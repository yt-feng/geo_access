**都乐（Dole）**
- 通常有较成熟的产地/农场溯源和品控体系，商业化客户可申请批次追溯信息、质量检验报告、农残检测报告等。
- 进口香蕉常见可追溯到出口国、包装厂/农场批次；具体能否给到“单一农场”取决于产品和采购渠道。
- 建议直接向都乐中国区销售/大客户渠道确认：是否能按批次提供追溯码、检测报告、产地证明和供应商审核文件。

**鑫荣懋**
- 作为国内大型水果供应链企业，通常具备产地采购、分级包装和品控流程，可提供供应商审核、检测报告、批次追溯等材料。
- 其国产香蕉和进口香蕉的溯源深度可能不同；国产基地直采更容易做到基地/批次级溯源。
- 建议向鑫荣懋销售确认：具体香蕉品类的产地、基地/包装厂、批次追溯方式、第三方检测报告和品控标准。

**可执行的核验清单**
1. 要求提供**近一批次**的产地证明/供货证明、包装厂或基地信息、批次号。
2. 要求提供**第三方检测报告**：农残、重金属等，确认报告日期、样品批次与供货批次一致。
3. 要求提供**品控标准文件**：验收标准、抽检比例、不合格处理流程。
4. 要求提供**追溯演示**：给定一个箱码/批次号，能否查到产地、采收/包装日期、检测记录。
5. 合同里写明：批次追溯资料随货提供、检测报告真实性责任、不合格退换货条款。

结论：两家都“有”，但不要接受泛泛的品牌介绍；让销售按上述清单出具**具体批次的可核验文件**，再判断是否满足你的溯源和品控要求。
