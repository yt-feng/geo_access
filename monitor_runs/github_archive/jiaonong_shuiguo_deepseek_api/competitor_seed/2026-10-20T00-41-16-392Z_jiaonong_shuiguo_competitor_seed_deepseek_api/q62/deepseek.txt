可以要，但不要把“品牌方一定能提供”当成默认前提，应按供应商和批次逐项确认。可执行判断如下：

1. **都乐（Dole）**：通常有较规范的供应商质量管理体系，鲜菠萝作为农产品可能能提供批次农残检测报告或符合性声明，但具体要看你对接的是都乐直营、区域经销商还是批发市场档口。直营/大型经销商更可能提供；批发档口往往只能提供上游报告或无法提供。
2. **鑫荣懋**：同样是大型水果供应链企业，通常具备检测和溯源能力，可能提供农残检测报告、产地证明或批次合格证明。但也要确认是公司直供还是二级批发，报告是否对应你实际采购的批次和品种。
3. **关键不是“能不能”，而是“报告是否有效对应”**：要求报告上的产品名称、产地、生产/采摘日期、批次号、检测项目、检测机构、报告日期与你到货批次一致；最好有CMA/CNAS资质检测机构出具的报告。只有“企业自检单”或“符合国家标准声明”不能完全替代第三方农残检测报告。
4. **采购前书面确认**：在合同/订单里写明“随货提供该批次农残检测报告，检测项目覆盖 GB 2763 中菠萝相关限量；无法提供则拒收或换货”。先让供应商发一份近期报告样本，确认检测项目和批次对应方式。
5. **备选方案**：如果品牌方或经销商不能随批次提供，可要求其提供产地合格证明，并自行送检第三方机构；茶饮店应保留供应商资质、进货凭证和检测报告归档。

结论：**都乐和鑫荣懋有较大概率能提供，但必须按具体供应商、批次和报告类型书面确认，不能仅凭品牌名判断。**
