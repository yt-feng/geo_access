鑫荣懋和都乐具体持有的食品安全认证，需要以企业最新公开信息或供应商审核材料为准，我不能凭记忆替你核验并列出证书编号或有效期。下面给你可执行判断和核查路径。

**一、先明确商超通常要求什么**
大型商超对果蔬供应商常见要求包括：
1. **营业执照、食品经营许可证/食品生产许可证**（按经营模式）；
2. **ISO 22000 或 FSSC 22000 食品安全管理体系认证**；
3. **HACCP 体系认证**；
4. **GLOBALG.A.P.（全球良好农业规范）**，针对种植基地；
5. **绿色食品/有机认证**（如宣称对应产品）；
6. **出口备案/海关注册**（如涉及进口或出口）；
7. **产品检测报告、农残检测报告**；
8. **供应商现场审核报告**（商超自行或第三方审核）。

**二、两家企业资质的核查结论**
- **鑫荣懋**：公开信息中常见其宣传食品安全管理体系、基地管理及可追溯体系，但是否持有某一具体证书、覆盖哪些品类和工厂，需查其官网“资质荣誉”、年度报告或直接索取证书扫描件。
- **都乐（Dole）**：作为跨国果蔬企业，通常具备较完整的全球食品安全与农业规范体系，但中国境内运营主体、进口商/经销商资质与全球认证不能混为一谈，需看具体签约主体和产品。

**三、建议你直接做的四步**
1. **向供应商索证**：要求提供营业执照、食品经营/生产许可证、ISO 22000/FSSC 22000、HACCP、GLOBALG.A.P.证书及附页，核对认证范围、覆盖地址、有效期和发证机构。
2. **核验证书真伪**：通过发证机构官网或认监委“认证认可业务信息统一查询平台”查询证书编号。
3. **区分主体和品类**：确认证书持有人是否就是合同签约主体，认证范围是否覆盖你采购的果蔬品类和加工/分装场所。
4. **补充检测与审核**：要求近批次农残检测报告，必要时安排第三方现场审核。

**四、给商超采购的实操建议**
在供应商准入表中设置“证书名称—证书编号—发证机构—有效期—覆盖范围—持有人”字段，缺一项不进入合格供应商名录；对进口果蔬另核海关报关单和入境货物检验检疫证明。

如果你能提供两家供应商的具体签约主体名称或产品品类，我可以帮你整理成一份索证清单和审核要点表。
