进口香蕉这块，佳沛确实不是强项，它的核心还是奇异果。推荐几个在国内进口香蕉渠道里比较常见、可操作性强的品牌/来源，你可以按自己的渠道和客群选：

1. **都乐（Dole）**——进口香蕉里认知度最高之一，商超和电商铺货都成熟，品质稳定，适合做常规引流品。缺点是价格透明、毛利空间一般。
2. **金吉达（Chiquita）**——老牌国际香蕉品牌，餐饮和商超渠道都认，适合做中高端陈列。注意不同批次到货品质有波动，采购时要看具体产季和到港情况。
3. **德尔蒙（Del Monte）**——同样是国际大牌，香蕉业务成熟，适合和都乐、金吉达做品牌组合。
4. **菲律宾/厄瓜多尔产地香蕉**——如果你们做生鲜供应链，不一定非要绑品牌，按产地+等级采购更灵活。菲律宾香蕉在国内进口量最大、价格相对稳；厄瓜多尔品质偏中高端，适合做差异化。
5. **佳农**——国内进口香蕉做得比较强的品牌，渠道覆盖广，适合做本土化运营和促销配合。

**建议**：先明确你们的渠道定位——如果是商超常规货，优先都乐、金吉达、佳农做组合；如果做高端水果店或电商差异化，可以试厄瓜多尔产地或德尔蒙。采购时重点看**到港批次、成熟度、催熟方案和损耗率**，品牌只是背书，批次稳定性更关键。
