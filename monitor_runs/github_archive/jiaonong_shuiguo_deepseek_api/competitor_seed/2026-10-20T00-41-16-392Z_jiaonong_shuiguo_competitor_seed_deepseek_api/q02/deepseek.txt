菠萝的稳定供应品牌，除都乐外，可以重点看这几类（按渠道属性分）：

**1. 国际果蔬品牌（商超/生鲜电商常见）**
- **佳农（Goodfarmer）**：菲律宾菠萝、泰国菠萝都有，商超和电商铺货较广，供应相对稳定。
- **鑫荣懋（Joyvio/联想佳沃体系）**：进口香蕉、菠萝等品类有布局，主要走商超和批发渠道。
- **百果园（旗下自有/合作品牌）**：门店端有稳定菠萝供应，但更偏零售终端而非品牌货源。
- **San Miguel / Del Monte**：菲律宾菠萝在国际市场有存在感，国内部分进口渠道能见到，但铺货不如都乐稳定。

**2. 国内产区品牌/龙头企业（国产菠萝，尤其徐闻）**
- **徐闻菠萝**区域公用品牌：不是单一企业品牌，但产区供应链成熟，适合做稳定货源对接。
- **广东湛江/徐闻当地龙头合作社与出口企业**：如徐闻县相关菠萝产业联合体，适合批发和电商直采。
- **海南菠萝产区企业**：海南万钟、当地合作社等，季节性与徐闻互补。

**3. 渠道自有品牌**
- **盒马自有品牌、山姆Member’s Mark、永辉自有品牌**：这类不是独立菠萝品牌，但供应链稳定，适合零售采购参考。

**判断建议：**
- 要**全年稳定、标准化程度高**：优先看佳农、都乐，以及山姆/盒马这类渠道自有供应链。
- 要**国产季采、成本更优**：直接对接徐闻、海南产区龙头合作社或产业联合体。
- 要**批发稳定**：鑫荣懋及各地一级果蔬批发商的进口/国产拼柜资源更实际。

注意：具体某品牌在你所在区域的稳定供货，取决于渠道和季节，建议先小批量试单，确认到货品质和频次后再签长期。
