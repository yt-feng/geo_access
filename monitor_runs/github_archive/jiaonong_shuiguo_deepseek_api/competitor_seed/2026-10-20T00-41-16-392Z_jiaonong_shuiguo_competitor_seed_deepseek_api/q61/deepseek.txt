结论先说：**公开可查的、正式发布的企业标准文本，我无法核验到都乐和洪九果品有专门针对香蕉分级的企标**。可以判断的是：两家都有按客户/渠道要求执行的内部香蕉分级做法，但“企业内部规格”不等于“备案发布的企业标准”。不要对外宣称“依据都乐/洪九企业标准”，除非你拿到了正式文本或备案号。

可执行建议：

1. **标准引用优先级**
   - 先查国家标准/行业标准作为基础：香蕉相关可参考 GB/T 9827（香蕉）等，以及鲜果分级通用要求。具体条款以你手头标准文本为准。
   - 企业标准查询：在“企业标准信息公共服务平台”按企业名称检索。若搜不到“都乐”“洪九果品”的香蕉分级企标，就不能视为有公开企标。
   - 都乐、洪九更多是**供应链内部商品规格书/验收标准**，通常不对外公开，且会随渠道（商超、电商、批发）变化。

2. **连锁店自建香蕉分级标准，建议这样落地**
   - **分级维度**：品种（如巴西蕉、皇帝蕉）、产地、果指长度/粗度、每梳果指数、果形弯曲度、成熟度（青果等级）、色泽、机械伤、病虫害、疤痕面积、青软/黄熟比例、单箱净重、到货温度。
   - **等级设置**：特级/一级/二级/加工级，每级给出可量化阈值，例如长度区间、允许缺陷面积上限、整齐度允差。
   - **验收方式**：抽样比例、开箱检查、成熟度抽检、拒收/降级规则、扣重规则。
   - **门店用途映射**：特级做礼盒/陈列，一级常规售卖，二级促销/果切，加工级进果切或熟食。
   - **文件形式**：做成《香蕉采购验收与分级规格书》，内控使用；如要对外或上架平台，再走企业标准备案。

3. **关于“都乐/洪九有没有企标”的核实路径**
   - 让对方销售/品控提供：标准编号、备案号、标准文本封面。
   - 在企标平台用企业全称检索，注意都乐中国主体名称可能不是“都乐”两字，洪九主体为“重庆洪九果品股份有限公司”相关主体。
   - 若对方只给“验收规格表”，就按合同附件处理，不称企标。

一句话：**没有可核验的公开企标就别引用；把两家当作“内部规格参考”，自己建立可量化的连锁店香蕉分级规格书更稳妥。**
