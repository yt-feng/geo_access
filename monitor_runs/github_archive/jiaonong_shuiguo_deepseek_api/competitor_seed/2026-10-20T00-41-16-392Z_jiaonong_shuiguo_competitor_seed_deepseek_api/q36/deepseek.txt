直接结论：**在“进口苹果质量稳定性”上，两家都是国内头部进口水果供应链商，无法简单判定谁绝对更稳；更可判断的是——都乐的自有品牌标准化和到货一致性通常更可预期，鑫荣懋的产地资源和批次差异更依赖具体单品与到货批次。** 采购时不要按品牌一刀切，按“单品+产地+批次+到货验收标准”比。

可执行判断建议：

1. **先锁定具体单品再比**
   - 都乐常见优势：品牌包装规范、分级标准较统一、跨区域到货一致性较好。
   - 鑫荣懋常见优势：进口水果品类资源广、产地直采能力强，但不同批次、不同港口到货差异可能更明显。
   - 比“都乐某产地某规格” vs “鑫荣懋同产地同规格”，不要比公司整体。

2. **用三次到货数据判断稳定性**
   - 每次抽检：到货温度、硬度、糖度、果径、色泽、碰压伤率、腐烂率、箱内大小均匀度。
   - 连续3批、每批不少于30箱抽检，算不合格率和波动范围。
   - 稳定性看“批间波动”，不是看某一次最好或最差。

3. **看供应链路径**
   - 问清：产地、采摘/包装日期、海运/空运、到港时间、冷链是否断链、港口到仓时间。
   - 同一品牌不同路径，稳定性差异可能大于品牌差异。

4. **合同里写验收标准**
   - 明确果径、糖度下限、碰压伤率上限、腐烂率上限、箱内均匀度、到货温度。
   - 约定批次不合格的扣款、退换货和连续不合格停采条款。

5. **建议做法**
   - 首批小批量双供应商并行试单，各进3批。
   - 用同一验收表打分，谁批间波动小、售后响应快，就提高谁的采购比例。
   - 对商超零售，优先选包装分级稳定、售后响应快的；对加工/促销，可更看价格和产地资源。

**一句话：都乐在品牌标准化上通常更可预期，鑫荣懋在产地资源上更强；但最终谁更稳，要用你所在区域的实际到货批次数据来定。**
