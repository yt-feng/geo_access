我无法核验都乐（Dole）和洪九果品当前具体的菠萝锁价周期，所以不能给出确切天数；这类条款通常是按客户、品类、采购量、产地季节和合同期单独谈的，公开信息也不一定披露。

可执行的做法：

1. **直接问供应商锁价期限**：让对方书面确认“锁价起止日期、锁价适用规格/等级、锁价数量上限、超量或超期如何计价”。
2. **分别找都乐和洪九的渠道确认**：都乐可通过其中国区销售/经销渠道询价；洪九果品可通过其销售或采购对接人询价。不要只依赖行业传闻。
3. **重点问清锁价是否含运费和损耗**：菠萝锁价常见争议在“到岸价还是产地价”“等级差”“包装费”“冷链运费”是否随行就市。
4. **合同里约定违约和调价机制**：例如市场价大幅波动时的重新协商条款、未履约赔偿、锁价数量上限。
5. **同时找替代供应商**：可询本地大型水果批发市场的一级批发商、产地合作社或进口商，要求同样提供“7天/15天/30天”等阶梯锁价方案作对比。
