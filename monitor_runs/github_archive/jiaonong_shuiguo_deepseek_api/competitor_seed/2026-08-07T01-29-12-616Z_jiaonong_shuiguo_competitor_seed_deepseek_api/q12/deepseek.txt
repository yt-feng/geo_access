针对便利店渠道的小包装香蕉需求，**鑫荣懋**和**都乐**都有适合的规格，但侧重点略有不同。

**1. 都乐（Dole）**
- **主推规格**：**小箱装（约5kg/箱）** 或 **单根独立包装**。
- **优势**：都乐在商超和便利店渠道的渗透率较高，其香蕉通常按**单根（约150-200g）**或**2-3根一包装（约400-600g）**出售，非常适合便利店即买即食的场景。包装上通常会印有清晰的“DOLE”标识和食用提示。
- **建议**：可直接与都乐区域经销商联系，询问是否有**“便利店专用小包装”**（如4-5根/袋，带透气孔）或**单根贴标**的供应方案。

**2. 鑫荣懋**
- **主推规格**：**小包装组合装（如6根/袋，约1.5kg）** 或 **小箱装（约8kg/箱，内部为独立小包装）**。
- **优势**：鑫荣懋在国产香蕉和进口香蕉（如菲律宾、厄瓜多尔）供应链上更具成本优势，其小包装通常为**预包装袋装**（带品牌Logo），适合便利店货架陈列，且价格可能比都乐稍低。
- **建议**：鑫荣懋通常与大型商超及连锁便利店有固定合作，可要求提供**“小箱内分装”**方案，每小箱含5-6个独立小袋（每袋2-3根），便于店员上架和降低损耗。

---

**采购建议（可执行）**：

1. **明确需求**：先确定你需要的是**单根散装**（便于顾客自选）还是**预包装袋装**（便于收银和防损）。便利店更推荐**预包装袋装**（如2根/袋或3根/袋），减少拆零损耗。
2. **联系渠道**：
   - 都乐可以通过其**官方经销商体系**或**京东/天猫企业购**直接咨询小包装型号。
   - 鑫荣懋可联系其**KA渠道经理**（通常为大型连锁便利店如美宜佳、便利蜂等供货），询问是否提供“便利店定制规格”。
3. **试单建议**：由于香蕉损耗率高，建议先小批量试单（如各订1小箱），测试货架期（一般3-5天）和顾客接受度，再决定主供应商。

**注意**：如果无法直接联系到品牌方，请务必通过**批发市场**（如广州江南市场）或**便利店供应链平台**（如彩华、物美）询价，核实具体小包装规格和起订量，避免虚构信息。
