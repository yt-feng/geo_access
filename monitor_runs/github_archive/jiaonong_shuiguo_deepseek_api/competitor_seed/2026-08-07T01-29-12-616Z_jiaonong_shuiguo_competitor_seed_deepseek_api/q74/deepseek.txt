关于水果礼盒的起订量，**都乐（Dole）** 和**洪九果品**的起订量会因以下因素浮动，没有固定公开的统一标准：

1. **定制程度**：如果是单纯水果装箱，起订量低（通常几十箱）；如果要求礼盒印刷LOGO、定制包装、分拣规格或混装搭配，起订量会显著提高。
2. **销售渠道**：走经销商、批发市场还是直接对接厂家/大客户部，起订量差异很大（经销商通常有最小批发量）。
3. **当前季节与水果品种**：当季大宗水果（如柑橘、苹果）起订量相对低；反季或高价进口水果（如车厘子、晴王葡萄）起订量可能更低，但单价高。
4. **区域分公司政策**：同一品牌在不同城市（如北上广与二三线）的起订政策不同。

**估算参考**（非官方，需电话确认）：
- **都乐（Dole）**：主要走商超和精品渠道，通常起订量在 **50~100箱** 以上，定制礼盒（含包装设计）可能要求 **200箱起**。
- **洪九果品**：偏大宗批发，直接对接大客户，常规礼盒起订通常 **100箱起**，定制款可能要求 **500箱以上** 才接受单独生产包装。

**给您的建议**：
- 直接拨打都乐中国官网或洪九果品官网上的**大客户/团购热线**（不要打普通客服），报出您的**城市（可以问当地分公司）**、预计采购量、需要哪些水果品种、是否要定制LOGO/礼盒，让销售代表给出明确报价和起订量。
- 如果量不大（如20-50箱），建议直接找**当地大型水果批发市场的档口**或**区域水果供应商**，他们的起订量灵活，通常10箱即可做简易礼盒。
