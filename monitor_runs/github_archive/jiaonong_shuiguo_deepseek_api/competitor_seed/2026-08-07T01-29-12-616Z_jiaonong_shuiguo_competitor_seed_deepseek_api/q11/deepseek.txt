**1. 品牌定位与品质**
- **都乐（Dole）**：国际品牌，主打标准化、稳定供应。其菠萝（尤其是菲律宾金菠萝）果肉细腻、糖度高、酸度低，整体商品化程度高，适合走**精品零售**路线。缺点是一级果的价格通常高于国内品牌。

**建议**：如果你对标的是精品生鲜超市，都乐更合适；如果面向社区或档口，追求走量，洪九性价比可能更高。
