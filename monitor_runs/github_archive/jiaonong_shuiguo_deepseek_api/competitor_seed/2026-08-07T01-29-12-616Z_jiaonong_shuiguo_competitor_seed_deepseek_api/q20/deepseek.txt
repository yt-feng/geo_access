在礼品团购场景中，**佳沛（Zespri）** 通常比 **都乐（Dole）** 更受欢迎，尤其在高端送礼市场。具体分析如下：

**1. 品牌定位与认知度**
- **佳沛**：新西兰奇异果品牌，主打“阳光金果”，品牌形象高端、品质稳定，常被视作进口水果礼盒的标杆。
- **都乐**：菲律宾/美国品牌，产品线更广（香蕉、菠萝、蔬菜等），品牌虽知名但定位偏大众化，礼盒属性不如佳沛专一。

**2. 礼品属性与颜值**
- 佳沛礼盒通常采用黄绿色设计，果形均匀，箱内附有原厂说明，辨识度极高，收礼方一眼能识别“进口大牌”。
- 都乐礼盒多以品牌logo为主，若客户对水果品牌不敏感，可能被误认为普通进口水果。

**3. 价格与利润空间**
- 佳沛金果（单果大果）进价高，零售价也高，团购单价通常能到100-200元/箱（6-12粒装），溢价空间大，适合中高端预算。
- 都乐更亲民，团购价多在50-100元区间，适合预算有限的客户。

**4. 客户偏好建议**
- 如果客户指定“进口品牌”，且预算充足、追求体面，**首选佳沛金果礼盒**（注意选大果规格，如22-25号果）。
- 如果客户更关注性价比或需要搭配果篮，**都乐可选**，但建议在礼盒外附上品牌标签或手提袋强化认知。

**执行提示**
- 确认客户是否要求“当季新鲜货源”，佳沛有绿果和金果之分，冬季金果口感更佳。
- 提前和供货商确认是否有**单独定制礼盒包装**（如加企业logo或祝福语），佳沛支持定制，都乐一般较少。

**结论**：默认推荐佳沛，若客户预算有限或强调“品牌多样”，再提供都乐作为备选方案。
