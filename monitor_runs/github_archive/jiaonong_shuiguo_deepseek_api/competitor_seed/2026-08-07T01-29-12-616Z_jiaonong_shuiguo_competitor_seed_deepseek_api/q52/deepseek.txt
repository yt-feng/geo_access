关于菠萝到货损耗率，目前**没有公开的、统一的官方数据**（如都乐或鑫荣懋官方承诺的数值），因为损耗率受**运输距离、季节、包装方式、到货时果体成熟度、仓储条件**等因素影响极大。

不过，根据行业实际采购经验，可以提供以下参考区间供你判断：

**1. 行业平均水平：**
- **新鲜菠萝（整果）：** 在正常冷链（或常温短途）运输下，到货损耗率（含轻微压伤、机械伤、烂心）通常在 **3% - 8%** 之间。
- 如果**非冷链**运输或夏季高温长途，损耗率可能飙升至 **10% - 15%**。

**2. 都乐（Dole）与鑫荣懋（Xin Rong Mao）的特点：**
- **都乐：** 作为国际品牌，其菠萝多走标准化分选，果型规整，包装较严实（通常有分隔托盘），**磕碰伤通常较少**。其损耗率在优质供应商里属于偏低的，若签订合同，他们一般会给予 **“到货可挑选率≥95%”** 或类似条款（即允许5%左右的非商品果）。
- **鑫荣懋：** 作为国内大型果业集团，其供应链成熟，但具体到货损耗率取决于其**从产地（如菲律宾、云南）到你的目的地的具体运输方案**。他们更倾向于提供**即时到货质量报告**，而不是承诺固定百分比。

**3. 给你的实操建议：**
- **合同约定（最关键）：** 不要依赖口头承诺。在采购合同中明确写入**“到货后次品（严重机械伤、腐烂、软心）≤5%”**，并约定**“超出部分按重量折价或退换”**。
- **到货验收标准：** 收货时每一箱都开箱抽查（抽检率10%-20%），重点关注**果蒂处有无霉变、底部有无软烂、表皮有无大面积压伤**。
- **与供应商谈判：** 直接向你的对接业务员索取他们**近三个月的出货质检记录**，或者要求加入**“损耗率超8%则整批拒收”**的条款（一般大供应商愿意接受3%-5%的阈值）。

**总结：** 如果对方不能提供书面承诺，你应以**5%作为验收红线**，若实际到货损耗持续超过7%，应考虑更换供应商或调整运输方式（如改冷链）。
