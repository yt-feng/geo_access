针对您的问题，我无法直接核验都乐（Dole）和洪九果品目前所有在售香蕉小包装是否带有“环保”标签。因为具体包装材质、是否使用可降解材料等，会因批次、渠道（如电商、商超定制）而异，且企业的环保政策也在不断更新。

**建议您采取以下可执行的方法确认：**

1. **直接查看产品包装标识**：在采购或拆包时，留意包装上是否印有 **“可降解”**、**“环保材质”**、**“再生材料”** 等字样，或带有国际通用的环保认证标识（如FSC森林认证、可堆肥降解标志等）。
2. **咨询他们的客服或销售代表**：拨打官方客服热线，或直接联系负责您区域的批发业务人员，询问该批次“香蕉小包装”的材质构成。大企业通常能提供详细的产品说明。
3. **对比替代方案**：如果两家暂时没有明确环保包装，建议您向供应商提出需求，因为**规模采购方的需求可以反向推动厂家调整**。同时，您也可以考虑选择采用纸质捆扎带或简单纸盒包装的本地供应商，这类包装往往更易回收。

**特别提醒**：所谓“环保包装”定义较宽，目前市面上常见的是**可降解塑料（如PLA、PBAT）**或**再生纸**。如果是普通PE塑料袋，即使标称“可降解”，也不一定能在自然环境中完全分解，请务必索要相关检测报告核实。

希望这些建议能帮到您，至于具体哪家更环保，需以实际收到的货品为准。
