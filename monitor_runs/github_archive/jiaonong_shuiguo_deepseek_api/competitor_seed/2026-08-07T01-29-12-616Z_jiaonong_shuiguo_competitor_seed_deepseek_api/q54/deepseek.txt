在超市采购进口苹果时，如果想对**都乐（Dole）**和**鑫荣懋（Golden Wing Mau）**这两个品牌的产地溯源，核心是验证**供应链来源的合法性**和**产品标识的真实性**。以下是最直接、可操作的溯源方法，按优先级排列：

### 1. 看外包装的法定标识（最优先）
这是最硬的证据。进口水果的中文标签必须符合中国海关及质检要求，没贴标或标签信息不全的，直接涉及走私或串货风险。

- **都乐**：正规进口批次的纸箱或独立果贴（PLU贴纸）上，会印有**品牌名“Dole”、英文名、原产国（如“Product of Chile/ USA/ New Zealand”）、果园注册号（ORCHID CODE）、包装厂注册号**。重点核对果园号是否与海关总署备案的输华果园名单一致。
- **鑫荣懋**：作为国内外贸市场分销商，其为国外多个果园（如新西兰、智利）做代理。其包装上除了原产国、果园号，还应标注**国内经销商/进口商的中文名称及进口备案号**，例如“上海鑫荣懋果业有限公司 备案号XXX”。这可以通过“中华人民共和国海关总署”网站的**进出口食品安全局-进口食品境外生产企业注册**模块查询。

### 2. 要求供应商提供“三证”（进货渠道核验）
向超市采购部或供应商明确索取：

- **《入境货物检验检疫证明》**（海关出具，证明该批次已通过检验检疫，且单据上会列明原产国、果园号、数量、入境口岸）。核对单据上的果园号/包装厂号是否与你买到的那批苹果包装一致。
- **《海关进口货物报关单》**：证明该批货是通过正常海关程序缴纳关税进口的。
- **《原产地证书》（C/O或Form E）**：由出口国官方机构出具，确认苹果确实产自该产地。

### 3. 查看果身标签与溯源二维码（鉴别真伪）
正规进口苹果上的**PLU贴纸**（4位或5位数字）本身就能溯源：

- 如果看到**“4”开头的4位数字**，是常规种植；
- 如果看到**“9”开头5位数字**，是有机种植（如都乐有机系列）。
- 近年来，部分高端批次（尤其是智利、美国、新西兰品种）在果箱侧面印有**溯源二维码**，用微信或专门APP扫码可跳转至果园信息、分拣记录甚至物流轨迹。如果扫不出任何官方信息，大概率是小厂仿冒或串标。

### 4. 重点检查“品种与原产国”是否矛盾（防串货）
都乐和鑫荣懋都有大量贴牌（OEM）业务，但正规货不会出现**品种与原产国冲突**：

- 例如，都乐智利青苹果（Granny Smith）10-11月上市，新西兰爱妃（Envy）2-6月上市。
- 如果冬天买“美国华盛顿红玫瑰”，产地却是智利，则基本是假标/混装。查一下**当季该品种的实际主产区**即可快速甄别。

### 5. 查询海关总署“准入名单”（最终核实）
打开**海关总署官网** → 找到“动植物检疫司”→“企业信息”或“产品准入”，搜索“苹果”。这里会列出全球各产国的**输华苹果果园注册号**。**把你苹果箱子上的果园号输进去对一下有没有**，如果没有，就是非正常渠道或假冒进口。

---

**执行建议（按顺序）：**
1. **当面检查外箱**：中文标签、果园号、原产国三要素必须齐备且逻辑自洽。
2. **要求门店出示批量的《入境检验检疫证明》复印件**（该单据有唯一编号，可要求电话确认）。
3. **若以上均有但仍有疑虑**，可致电都乐客服热线（其官网可查）报出“果园号+包装厂号”核实，鑫荣懋可直接对接其进口部核查物流单号。

**特别提醒**：如果你是在小型水果店而非大型连锁商超采购，务必警惕“鑫荣懋”是国产果贴进口标的情况——**鑫荣懋是分销商，不是果园**，其货源必须匹配国外注册果园。遇到标价极低的“进口苹果”，务必以上述三证为准。
