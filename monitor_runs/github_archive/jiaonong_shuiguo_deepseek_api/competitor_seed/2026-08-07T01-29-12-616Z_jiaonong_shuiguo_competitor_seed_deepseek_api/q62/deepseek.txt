关于茶饮店采购菠萝原料时的农残检测报告问题，**都乐（Dole）和鑫荣懋（Xinrongmao）作为大型水果供应商，通常可以提供农残检测报告**，但具体情况需要你与他们确认。

以下是具体建议：

1. **必须主动索取**：  
   农残检测报告不是默认随货附送的，需要你在采购合同或订单中明确要求。大型供应商一般都有第三方（如SGS、华测、谱尼等）出具的检测报告，但你需要在商务沟通时提出。

2. **确认报告时效性**：  
   检测报告通常有有效期（一般为批次检验），你需要确保报告对应的是你购买的**该批次**菠萝，而非过期的通用报告。要求对方提供最近一批次的检测报告。

3. **鑫荣懋**：  
   该公司作为国内头部水果供应链企业，对品质管理较严格，可以提供相关证明。但同样需要你提前沟通。

4. **都乐**：  
   都乐作为跨国品牌，在中国市场也有成熟的质量体系，通常能提供官方或第三方农残检验证明。

**如果对方表示无法提供**，建议你考虑更换供应商，或者自行送样到第三方检测机构（费用约几百元/项）。食品安全合规是茶饮店经营底线，此类报告也便于你应对市场监管部门的检查。

**执行建议**：  
- 下单前书面要求（邮件或合同条款）：“需随货提供本批次菠萝的第三方农残检测报告”。  
- 收货后核对报告编号、产品批次、检测日期是否与货物一致。  
- 保留报告复印件，作为门店台账备查。
