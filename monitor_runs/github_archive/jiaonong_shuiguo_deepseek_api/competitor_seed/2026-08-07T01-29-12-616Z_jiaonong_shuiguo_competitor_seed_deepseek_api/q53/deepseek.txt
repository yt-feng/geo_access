对于餐饮连锁企业而言，稳定供货是生命线。**都乐（Dole）和洪九果品都可以签订长期供货合同，但合作模式、合同主体和风险点区别很大。**

建议你从以下三个维度进行判断和决策：

### 1. 都乐（Dole）——适合标准化连锁、重品质
- **合作方式**：都乐作为全球头部生鲜品牌，主要走**大贸批发（一级市场）**或**商超直供**。如果你的门店数量多（如50家以上）、月度需求量大（单品类），可以谈**年度框架协议**。
- **合同性质**：可以签年度供货合同，但**通常不接受“保量锁价”**，多采用“随行就市 + 保底供应”。他们会保证货源稳定，但价格会随国际产地（菲律宾、厄瓜多尔等）行情波动。
- **优势**：品控严格（标准化程度高），有完善冷链和追溯体系，适合对食品安全要求极高的全国连锁。
- **劣势**：起订量要求高，小批量价格不占优。

### 2. 洪九果品——适合锁量锁价、下沉市场
- **合作方式**：洪九是产业链一体化公司（自有种植基地+泰国、越南等产地直采）。他们的商业模式正好是**“端到端”**，非常愿意和餐饮连锁签**长期保供协议**。
- **合同性质**：可以签**中长期（半年/一年）锁价锁量合同**，特别是针对帝王蕉、苹果蕉、国产香蕉（如云南蕉）等特定品种。他们更灵活，支持前置仓周转、按周配送。
- **优势**：愿意承接中小连锁，且能提供产地直发成本优势；合同中可以约定淡旺季调整机制。
- **劣势**：相对都乐，其标准化品控能力稍弱，**强烈建议在合同中明确“糖度、把型、催熟程度”的验货标准**，并设置拒收条款。

### 3. 签订长期合同前的关键风控建议（务必执行）

无论选哪家，必须在签约前落实以下几点，否则合同签了也是隐患：

- **明确“数量弹性条款”**：餐饮经营波动大，合同中要约定“最低采购量”和“最高采购量”。例如：保证月采购满20吨，低于则需付违约金；但超过约定上限，供应商有权调价或延迟发货。
- **价格联动机制**：因为香蕉是期货属性较强的农产品，不能一价锁定一年。建议写明：**“基础价锁定3个月，之后按产地收购价指数浮动（如以海南/云南产地批发价加权）调整。”**
- **检验与拒收标准**：香蕉催熟度直接决定损耗。合同中必须写明色泽、单把重量、断裂率、冻伤率等可量化指标，并约定“到货后24小时内验货，不合格可拒收退货”。
- **违约赔付**：既要约束对方断供（罚没保证金），也要约束自己。长期合同建议**互缴履约保证金（通常为月度货款的10%-15%）**。

### 4. 给你的实操建议（分两步走）

1. **先做“3个月试单”**：和洪九果品先签3个月短期合同，测试其香蕉的到货损耗率和配送时效；同时让都乐报年度框架价作为对标。
2. **首年合同期限定在1年以内**：不要一次签3年。生鲜市场的产地气候、汇率浮动影响极大，首年合同控制在1年，并附“合同到期前60天双方可协商续签或终止”的条款。

**一句话结论**：**洪九更适合锁量锁价长期合作，都乐适合保证品质但不锁价。** 如果你们是标准化中高端品牌，优先选都乐；如果追求成本优势且愿意做品控管理，选洪九。
