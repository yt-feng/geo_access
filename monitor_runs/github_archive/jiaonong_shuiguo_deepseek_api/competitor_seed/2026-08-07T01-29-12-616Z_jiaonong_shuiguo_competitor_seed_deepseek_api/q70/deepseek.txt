**都乐（Dole）和鑫荣懋（XinRongMao，即金果园 Joyvio 旗下）都有产地溯源和品控证明体系，但具体到每一批货，需要你向他们索取对应的纸质或电子版证明。**

具体来说：

**1. 都乐（Dole）**
- **有**。都乐是全球性品牌，其供应链有严格的果园备案和品控标准。
- 他们在国内外的种植基地（如菲律宾、厄瓜多尔、国内云南等）均有对应的质检报告（如农残检测、重金属检测）和产地证明。
- 通常，都乐会随货附带**CIQ（中国检验检疫）证明**或**供货商自检报告**。
- **建议动作**：联系都乐华南或华东大客户销售，明确要求提供**“基地备案号+批次农残报告+产地证明原件”**。

**2. 鑫荣懋（Joyvio）**
- **有**。鑫荣懋是国内头部水果供应链企业，主营进口及国产香蕉，其品控体系较完善。
- 鑫荣懋对国产（如广西、云南）基地和进口（如菲律宾）基地均实行果园分级和采后检测。
- 他们可以提供**基地备案扫描件**、**批次检验报告**（农残、水分、糖度等）以及**供货证明**。
- **建议动作**：向其采购部门索取**《供应商质量保证书》**和**具体批次的出厂/入场检验记录**。

**给你的可执行建议（按优先级）：**

1. **直接联系两家公司的企业销售/大客户部**，并明确说：“我们需要用于B2B采购的产地溯源证明和品控检测报告，建议包含农残和重金属项。”
2. **索要电子版文件**：正规供应商通常可提供PDF版盖章证明，要求对方在邮件中注明**对应批号**。
3. **自行复核**：收到证明后，可要求对方提供“果园备案号”在海关/农业农村部官网的可查询路径（如有）。

**警惕点**：如果对方只口头承诺“有品控”但无法给出具体批次文件，或拒绝提供盖章PDF，则属于严重不合规，建议换供应商。
