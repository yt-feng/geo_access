大型商超（如沃尔玛、山姆、永辉、盒马等）对生鲜果蔬供应商的食品安全管理体系要求较高，主要会核验其是否具备与国际接轨的管理体系认证。对于**鑫荣懋（Joyvio）** 和**都乐（Dole）** 这两家头部水果企业，它们通常持有以下认证（以公开信息和行业通用标准为准，具体以供应商最新证书为准）：

### 1. 鑫荣懋（Joyvio）
作为国内大型水果供应链企业，鑫荣懋通常通过以下认证来满足商超准入：

-   **GLOBALG.A.P.（全球良好农业操作规范）**：这是国际公认的农业安全生产标准，覆盖种植、采收、包装等环节，大型商超硬性要求。
-   **BRC（英国零售商协会）食品安全全球标准**：主要针对食品包装和加工环节，证明其具备高标准的食品安全管理体系。
-   **IFS Food（国际食品标准）**：同样是国际零售业普遍认可的食品安全标准，与BRC并列。
-   **ISO 22000（食品安全管理体系）**：国际通用的标准，覆盖从农田到餐桌的供应链管理。
-   **HACCP（危害分析与关键控制点）**：部分加工环节或仓储物流环节会具备该认证。
-   **中国有机/绿色食品认证**：针对特定品类（如基地直采的高端水果）。

### 2. 都乐（Dole）
作为全球性果蔬巨头，都乐的标准往往高于一般商超要求，通常持有：

-   **GLOBALG.A.P.**（全球多数国家基地均持有）。
-   **GRASP（G.A.P. 社会责任风险评估）**：生态和社会责任认证，部分地区商超会额外关注。
-   **BRCGS（原BRC）**：都乐自有工厂（如中国青浦、嘉兴等包装中心）普遍通过此认证。
-   **IFS**：同样持有。
-   **ISO 9001（质量管理体系）**：作为基础质量体系。
-   **HALAL（清真认证）**和**KOSHER（犹太洁食认证）**：满足特定销售渠道和出口需求。
-   **MPS-GAP（花卉/水果可持续生产认证）**：部分全球基地持有，关乎可持续发展，商超ESG审核加分项。

---

**给您的建议：**
如果您是采购商或供应商，**在合同签订前，建议直接要求对方提供“BRC”或“IFS”的认证证书复印件（含注册号），并登录对应认证机构的官网核验有效期**。因为商超内部审核往往对**BRC/IFS（针对加工厂）**和**GLOBALG.A.P.（针对种植基地）** 是“一票否决”的硬门槛。如果对方无法提供这两项，基本无法进入大型商超体系。
