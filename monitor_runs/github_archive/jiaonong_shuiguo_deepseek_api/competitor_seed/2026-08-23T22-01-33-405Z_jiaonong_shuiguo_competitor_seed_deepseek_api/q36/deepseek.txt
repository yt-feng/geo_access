这两家都是国内水果市场的主要进口商/品牌，但**质量稳定性没有绝对的“谁更好”**，更多取决于你想买哪种苹果、以及具体批次。以下是根据常见市场情况的客观参考：

**一、核心定位差异**
1. **都乐（Dole）**：全球老牌水果品牌，主打高端商超（如盒马、ole'、山姆等），对品控要求极严格。它的进口苹果以**美国蛇果、智利青苹果/红玫瑰、新西兰爱妃**等高品质品种为主，标准化程度高，外观糖度比较统一，极少出现腐烂或黄心。
2. **鑫荣懋（Golden Wing Mau）**：国内大型水果供应链企业，代理多个进口品牌，同时也做自有品牌。线下铺货更广（社区超市、普通生鲜店都有），价格区间宽。质量稳定性**因渠道和单品而异**——如果是它主推的进口品牌（如新西兰皇后、智利嘎啦），稳定性不错；但如果部分走量区的低价小果，批次波动就可能大一些。

**二、实际购买建议**
- 如果**预算充足且追求省心**，优先选都乐。它的分级筛选流程更成熟，坏果率低，尤其适合送人或家庭采摘。
- 如果**追求性价比或常买日常口粮**，鑫荣懋更合适。建议认准包装上的**“进口”标签和具体产地（如“新西兰产”“智利产”）**，尽量选大果（果径80mm以上），并避开临期特价区。
- **关键动作**：无论买哪个，开箱后先检查是否有碰伤或酒精味。进口苹果运输周期长，有时候品牌好但某个船期湿度大，也会有个别问题。如果发现坏果，两家售后都支持按个数赔付，但需保留购物小票或订单截图。

**三、特别提醒**
没有绝对“稳定”的品牌，水果是农产品，受气候和海运影响大。建议在靠谱渠道（山姆/盒马买都乐，永辉/百果园买鑫荣懋）时，当场看外观：**均匀红、果柄鲜绿、无皱皮**的批次通常更稳定。

如果要挑特定品种（比如嘎啦、红玫瑰），我可以再给你推荐具体哪家更擅长。
