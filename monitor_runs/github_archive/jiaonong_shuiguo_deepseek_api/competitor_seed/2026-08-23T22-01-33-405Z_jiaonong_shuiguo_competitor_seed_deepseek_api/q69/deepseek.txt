关于都乐（Dole）和洪九果品在进口苹果分级方面的严格程度，我可以根据行业常识给出以下分析，但**无法提供实时监管数据或内部品控报告**，建议你以实际到货样品及合同条款为准。

**结论先放：两者都执行分级标准，但侧重点和严格程度不同，**洪九果品在进口苹果上通常比都乐更依赖订单化、可定制的分级，而都乐更偏向品牌化、标准化包装。**

具体如下：

1. **都乐（Dole）**  
   - **品牌定位**：全球性大品牌，主要面向商超、精品店，走的是“稳定供货”路线。  
   - **分级标准**：执行国际通行标准（如美国USDA或智利、新西兰出口标准），常见按**果径（如80#、85#、90#）和外观（色泽、无瑕疵）**分拣。其分级严格，但相对**固定单一**，不做过多碎片化细分，包装规格（如5kg/10kg）通常固定。  
   - **优点**：统一性好，果径均匀度较高，不容易出现大小混装。  
   - **注意点**：如果你需要特别细的等级（如“特级果”和“一级果”有明显价格差），都乐可能不如专业进口商灵活。

2. **洪九果品**  
   - **品牌定位**：专注于鲜果供应链，尤其在东南亚（如泰国、越南）和智利、新西兰进口果上有较强渠道，服务大型批发市场、社区团购和连锁超市。  
   - **分级标准**：更强调**按客户订单需求做定制分级**，通常分为“精选果”“标准果”等，可以按果径、糖度、硬度甚至色泽做更精细的筛选。  
   - **优点**：灵活性高，如果你对规格有明确要求（比如只要75-80mm，且糖度≥14），他们可以按需分捡；但**品控波动可能比都乐稍大**，因为其产地分散，不同批次需当面验货。

**给你的实操建议：**

- **如果你要“绝对统一、零瑕疵”**：优先选都乐，但需提前确认具体品种（如红玫瑰、加力果）的到货级别，并要求提供“同批次果径公差证明”（如±2mm）。  
- **如果你要“大批量、可定制”**：选洪九，但必须在合同里写清楚：  
  - 果径公差范围（如85mm果，允许80-90mm的比例≤5%）；  
  - 抽样标准（每箱抽查几个）和退换条款（如混级超过10%可拒收）。  
- **无论选哪家，建议**：  
  - 到货后**当场开箱抽检**，用游标卡尺量20个以上果径，计算标准差；  
  - 要求对方提供**产地海关检疫证明和品控单**（避免以次充好）；  
  - 如果单次采购超10吨，可考虑请第三方检测机构（如SGS）做抽检。

**最后提醒**：进口苹果的分级严格程度还受季节（如早期果和尾期货差异大）影响，以上信息基于行业通行做法，具体以你的采购合同和打板样品为准。
