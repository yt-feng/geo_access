针对菠萝采购的长期合作，建议优先考虑**都乐（Dole）**，但需要结合你的具体业务量、价格敏感度和品控要求来最终决策。

以下是详细对比和建议，供你参考：

**1. 规格稳定性（核心指标）**
- **都乐**：作为全球一线品牌，其规模化种植基地和分选标准极为严格。无论是菲律宾、泰国还是国内基地，菠萝的个头、成熟度、糖度通常有严格的分级标准（如按直径、重量分选），**批次间一致性最强**，适合对出品标准要求极高、走连锁门店或高端渠道的茶饮品牌。
- **洪九果品**：作为国内头部水果供应链企业，其优势在于**产地直采和整合能力**，但不同产季、不同产地（如海南、云南、东南亚）的货源切换时，规格波动性相对更大。如果你是走性价比路线、对规格有一定弹性接受度，洪九可选。

**2. 价格与供货弹性**
- **洪九**：通常价格更有竞争力，尤其在国产菠萝产季（3-6月），可以拿到产地一手价。且其国内网络发达，小批量、多频次送货灵活。
- **都乐**：价格通常高于国产供应链5%-15%，但胜在**全年供货稳定**，且受台风、病虫害等影响时，其全球调货能力强，断供风险低。

**3. 品控与售后**
- **都乐**：有完善的冷链和售后服务，若到货出现腐烂、规格不符，理赔流程规范且快速，适合将“客诉率”放在首位的品牌。
- **洪九**：近年品控提升显著，但售后服务有时依赖区域经理的个人执行力，建议在合同中写明**规格误差阈值（如重量±5%、单果重600g以上）**和**坏果率赔付标准**。

**4. 明确你的优先级**
- **选都乐的情况**：你品牌有标准化茶饮SOP（如“水果茶必须用1.2斤以上菠萝”）、对出杯颜值有硬性要求、且能接受略高的原料成本。
- **选洪九的情况**：你门店多、走量快、需要灵活调货，且你的茶饮类型（如菠萝切粒放入奶茶）对“大果小果”不那么敏感。

**5. 实操建议（关键一步）**
- **盲测对比**：同一天向两家各采购100斤“同一成熟度（如8-9成熟）”的菠萝，让店长和门店伙伴做**去皮出肉率、甜度、纤维粗度、杯测风味**的盲测。
- **看合同细节**：重点看“规格不符时是换货还是扣款”、“价格调整机制（如遇极端天气怎么算）”、“账期（30/45/60天）”。

**最终建议**：如果预算允许、且你的茶饮对菠萝外观和风味一致性要求高（比如整块菠萝做装饰），**首选都乐**。如果更看重**性价比和灵活补货**，可以先和洪九签**6个月**短约，设立“阶梯式考核”（如抽检合格率低于95%自动切换都乐）。
