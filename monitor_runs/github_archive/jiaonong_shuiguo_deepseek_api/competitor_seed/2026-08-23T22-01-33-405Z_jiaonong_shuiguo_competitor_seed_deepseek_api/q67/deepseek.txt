关于生鲜电商平台与菠萝品牌（如都乐、洪九果品）的合作：

**1. 都乐（Dole）**  
都乐是全球知名的果蔬品牌，在国内与多家生鲜电商（如盒马、京东生鲜、美团买菜等）有长期合作，通常会提供**官方品牌素材**（产品图、宣传视频、品牌故事等）。具体是否提供素材，取决于电商平台是否与都乐有直接合作或授权，**建议直接联系都乐中国区市场部或电商对接人**，或通过其官方微信公众号/官网获取联系方式。

**2. 洪九果品**  
洪九果品是国内头部水果供应链企业，在菠萝品类上主要供应“海南金钻凤梨”等，面向B端（电商、商超）提供稳定货源。**其素材提供情况需看具体电商合作项目**，一般大宗供应渠道更侧重**产品规格、质检报告、产地证明**，而营销素材（如海报、短视频）可能需通过其市场部定制或申请。

**建议操作：**  
- 优先查询你所运营的电商平台后台（如商家后台的“品牌素材库”），看是否有官方已授权的品牌内容。  
- 若平台无现成素材，可直接联系两家公司的**大客户/电商渠道负责人**（可通过官网、展会、行业通讯录获取），说明需求（如“菠萝专题推广”），通常对方会提供标准化素材包。  
- 部分中小规模电商可能需**签订授权协议**后才能使用品牌LOGO、图片，注意版权合规。

**如果无法获取官方素材**，可考虑：  
- 使用**自行拍摄的实物图**（如有自有渠道），但需避免使用品牌logo或误导性宣传。  
- 与供应商协商**定制化营销支持**（如提供产地采风视频、联合促销活动）。  

最终能否提供，取决于合同约定和品牌策略，建议以**官方回复为准**。
