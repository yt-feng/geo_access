在超市采购进口苹果时，针对“都乐（Dole）”和“鑫荣懋（Golden Wing Mau）”这两个品牌，产地溯源的核心在于**看包装、扫溯源码、核验官方文件和查海关信息**。以下是具体可执行的操作步骤：

**一、针对“都乐（Dole）”品牌溯源**
都乐是全球知名品牌，其进口苹果（如红蛇果、青苹果、加力果等）多产自**美国（华盛顿州）、智利、南非**等。

1. **看包装标签**：正规都乐进口苹果，外箱或果贴（小标签）上会明确标注英文原产地，如“Product of USA”、 “Product of Chile”等。果贴上的数字是PLU码（如4132是红蛇果代码）。
2. **扫描二维码**：都乐在中国销售的进口产品，包装上通常有官方溯源码（或“啄木鸟”防伪标签）。用微信扫一扫，页面会显示该批次的**果园注册号、包装厂编号、出口国家**。
3. **索要质检报告**：向超市采购部或供应商索要该批次的**《入境货物检验检疫证明》**，上面会明确写有“原产国/地区”及“进境口岸”。这是海关出具的官方凭证，是法律效力的核心依据。

**二、针对“鑫荣懋”品牌溯源**
鑫荣懋是中国本土的果业巨头，其进口苹果（如新西兰爱妃、美国红玫瑰、智利青苹果等）采购自全球。

1. **中文标签比对**：由于是跨境采购，鑫荣懋的进口苹果**必须**有中文标签（国标规定）。标签上会印有“原产国”和“经销商/进口商”是“鑫荣懋（或其子公司）”。注意看原产国是否与你了解的一致。
2. **利用“数字身份证”**：鑫荣懋近年来推行“一果一码”或“一批一码”。刮开果贴上的涂层或扫描箱体二维码，进入其官方溯源平台，可看到**果园GPS坐标、采收日期、海运船号、报关单号**。
3. **报关单核对**：向鑫荣懋索要供应商提供的**《海关进口货物报关单》**，注意核对品名、启运地、境外发货人。如果申报原产地为“智利”，但标签写“美国”，即为严重违规。

**三、通用避坑与验证技巧（超市采购员必看）**

1. **认准国家质检总局准入**：进口苹果必须是海关总署《获得我国检验检疫准入的新鲜水果种类及输出国家/地区名录》内的。例如**美国产蛇果是准入的，但美国产某些梨不一定**。在中国海关官网（gov.cn）可查询。
2. **“四证”缺一不可**：正规进口设备必有的四证，缺一不可：
   - 《入境货物检验检疫证明》（最重要）
   - 《海关进口货物报关单》
   - 《植物检疫证书》（国外出具）
   - 《原产地证书》（国外出具，证明产自该国）
3. **避免“只认品牌不认产地”**：例如都乐也卖智利苹果，鑫荣懋也卖新西兰苹果，且同一品牌不同月份产地不同（南半球、北半球轮换）。**溯源核心是产地，品牌只是包装商**。
4. **查外箱批次号**：外箱侧面通常有喷码或印章，记录“果园代码+包装厂代码+生产日期”。可要求供应商出示这些代码在国际组织的注册证明（如智利出口商需在SAG注册）。

**四、实操建议**
- **要求供应商提供“产地承诺函”**：在采购合同中写明“若原产地与申报不符，供应商承担全部退货及赔偿责任”。
- **使用“掌上海关”APP**：可扫描报关单上的二维码实时核验真伪，防止供应商PS造假。
- **现场试杀**（如果允许）：苹果不是高溢价炒作品，产地真实性主要靠文件而非口感，但可切开对比果皮厚度、果肉紧实度辅助判断（如美国蛇果偏脆口，智利带青）。

**总结**：最权威的途径是向超市供应商索要《入境货物检验检疫证明》并核对“原产国”，同时用微信扫描品牌官方溯源码。若两者不一致，或文件缺失，则极有可能是“国产冒充进口”或“转口贸易伪造产地”，建议终止采购。
