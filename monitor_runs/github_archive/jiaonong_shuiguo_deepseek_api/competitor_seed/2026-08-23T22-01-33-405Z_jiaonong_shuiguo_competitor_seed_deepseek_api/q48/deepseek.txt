关于鑫荣懋（Xinrongmao）和都乐（Dole）在大型商超（如沃尔玛、山姆、盒马、大润发等）的供应商准入资质，由于这类认证信息属于企业商业资料，具体证书编号和时间通常不公开，且商超会根据自身的合规清单（如“BSCI”“SMETA”或“道德采购”要求）进行审核，我无法提供实时、具体的证书清单。

但根据行业标准和两家公司公开的供应链管理信息，**通常这些大型果业供应商会持有以下资质**（供你参考，具体以商超邀约或合作时提供的文件为准）：

### 1. 食品安全管理体系认证（通用）
- **BRCGS（食品安全全球标准）**（原BRC）：若供应自有品牌或出口商超，通常必备。
- **IFS Food（国际食品标准）**：欧洲及高端商超常用。
- **ISO 22000（食品安全管理体系）**：基础认证。
- **HACCP（危害分析与关键控制点）**：几乎所有商超的最低要求（通常以体系文件中体现）。

### 2. 农产品质量与安全认证（国内）
- **GAP（良好农业规范）**（尤其China GAP或Global G.A.P.）：在源头种植环节必备。
- **绿色食品认证**：若标注“绿色食品”则必须持有。
- **有机产品认证（中国有机/欧盟有机/USDA有机）**：涉有机产品线时持有。
- **无公害农产品认证**（部分省份或商超要求）。

### 3. 国际贸易与合规类（若涉及进口或出口）
- **植物检疫证书**（出入境检验检疫局出具，每批次）。
- **符合美国FSMA（食品安全现代化法）规则**（供美国市场）。
- **欧盟符合性声明（CE/REACH等）**（供欧洲市场）。

### 4. 社会责任与道德采购（大型商超“非食品”红线）
- **BSCI（倡议商界遵守社会责任组织）**或 **Sedex/SMETA** 认证：大型零售采购时的常见要求。
- **FSC（森林管理委员会认证）**（若涉及木材/纸制品包装）。

### 5. 两家公司的差异（仅基于公开信息）
- **鑫荣懋**：国内供应链强，主要持有国内GAP（China GAP）、ISO22000、HACCP，以及进口水果必备的检验检疫证明。同时其自有品牌“佳沃”等有绿色食品认证。
- **都乐（Dole）**：作为全球化企业，通常持有Global G.A.P.、BRC、IFS，以及美国FSMA相关合规文件。在中国市场销售时，也要有中国检疫入境证明及国内分装厂的食品生产许可证（SC）。

**给您的实操建议：**
1. **最准确方式**：在洽谈合同时，直接向对方的 **“食品安全或质量合规部门”** 索取《供应商资质证书扫描件》（要求加盖公章）以及每批次的《出厂检验报告》和《第三方检测报告》（最近6个月内的）。
2. **核对“有效期”和“供应商名称”**：确保证书上的公司名称与**签订合同的主体名称一致**，别名或集团子公司不通用。
3. **关注商超内部清单**：每家商超有独特的“供应商标准”，比如山姆会额外要求“国际认证”，盒马则对“可追溯性”要求严格。所以即使两家都有上述证书，也可能因商超不同而要求补交其他材料。
