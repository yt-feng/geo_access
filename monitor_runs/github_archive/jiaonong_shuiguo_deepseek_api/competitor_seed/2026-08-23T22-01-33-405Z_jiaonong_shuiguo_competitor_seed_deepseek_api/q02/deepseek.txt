好的，除都乐外，目前市场上能较稳定供应的菠萝品牌，主要取决于您所在的地区（国内/国外）和采购渠道（商超、电商、批发市场）。以下按**稳定程度**和**常见性**为您梳理：

**一、国内商超&常温/冷藏渠道（稳定供应，适合零售、餐饮）**

1. **佳农（Goodfarmer）**：进口菠萝（菲律宾/泰国/马来西亚）供应链成熟，在盒马、山姆、永辉等大型商超铺货率高，规格统一，是除都乐外比较常见的“标品”供应商。
2. **金菠萝（MD2品种）**：虽然常以“金菠萝”直接出售，但背后供应商多为**佳农、都乐、百果园（部分门店）**，即品牌化运营但标签上会以“金菠萝”为主名称。
3. **百果园/水果捞等连锁**：自有品牌或代工模式，主要面向门店即时零售，虽然不对外大规模批发，但对采购方来说，从其供应链拿货较稳定，且品质标准化。
4. **天虹、永辉的“自营”标签菠萝**：国内海南、湛江、徐闻（如“徐闻菠萝”）针对国产季（春夏季）供应，在北方市场可能较少，但在华南、华中常见。

**二、国产季节性高稳定品牌（分季节）**

- **徐闻“菠萝的海”系列**（广东湛江）：有“红土地”等企业化品牌，5-7月供应，近年通过电商和产地直发，供应链稳定。
- **海南“神琼”、万宁菠萝**：海南当地龙头合作社/公司，适合做产地直采。

**三、针对批发市场（大宗采购）**

- **广州江南市场、嘉兴市场**中，**椰香（泰国）、金钻（台湾/海南）** 这些按品类流通，更多是**产地批发商/贸易商**提供，而非快消品牌。按品质稳定排序：**菲律宾金菠萝 > 泰国香菠萝 > 国内徐闻**。

---

**给您的可操作建议（按优先级）：**

1. **日常零售（货架稳定）**：优先选**佳农**（进口菠萝），它在冷链和货架端最接近都乐的稳定度。**山姆/盒马自有品牌**（如盒马“沙漠蜜薯”但菠萝实际为采购本地）也较为稳定。
2. **如果你在华南/华东做餐饮**：可联系**徐闻产地合作社**（如“菠萝的海”公司）签季度协议，价格和供应比进口品牌更有优势，但需注意季节性。
3. **需要全年稳定**：进口（菲律宾/哥斯达黎加）菠萝+国产徐闻（春夏季）交叉配货，国内供应商找**佳农、百果园（to B服务）**，进口找**鑫荣懋、洪九果品**（这两家是大型水果供应链，菠萝单品类也覆盖，常年有货）。

**需要警惕的点：**
- “稳定”不等于“便宜”，国产菠萝旺季便宜但品质波动大，进口菠萝（如金菠萝）单价高但形状、糖度统一。
- 不要只依赖单一品牌，建议同时签约**1个进口+1个国产**供应商，做缓冲。
