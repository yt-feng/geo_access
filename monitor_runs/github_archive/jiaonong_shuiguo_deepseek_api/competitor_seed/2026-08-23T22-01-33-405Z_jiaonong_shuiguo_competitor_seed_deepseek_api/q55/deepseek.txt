关于您提到的两个品牌，我根据公开信息为您整理如下，但**建议您直接联系供应商确认最新基地和溯源情况**，避免依赖过时信息：

1. **都乐（Dole）**  
   - 都乐在中国市场确实有**自有/合作基地**，主要在海南、广东、云南等地（如海南澄迈、广东徐闻），并有“基地直供”的宣传。  
   - 其商品通常带有二维码或标签，扫码可查看产地、采摘/加工信息。  
   - 您可以拨打其官方客服或联系区域销售，要求提供**批次溯源凭证**（如基地备案号、检疫证明）。

2. **洪九果品**  
   - 洪九是大型水果供应链企业，以“全球基地+国内分销”模式为主，但**其直供基地主要覆盖进口水果（如泰国榴莲、山竹）**，菠萝业务更可能依赖国内产区（如湛江、海南）的采购合作，不一定有自有基地。  
   - 建议您联系其大客户部，询问能否提供**产地证明材料**（如收购协议、产地证明书）。

**补充建议**：  
- 如果您需要严格、可追溯的产地信息，可以优先考虑**大型连锁商超的直采项目**（如盒马、永辉自有品牌），或直接联系海南、广东当地的**省级农业合作社**，他们通常能提供更透明的产地认证和质检报告。  
- 溯源无统一标准，签订采购协议时，可要求供应商明确“产地+批号+质检”三项内容并写入合同。
