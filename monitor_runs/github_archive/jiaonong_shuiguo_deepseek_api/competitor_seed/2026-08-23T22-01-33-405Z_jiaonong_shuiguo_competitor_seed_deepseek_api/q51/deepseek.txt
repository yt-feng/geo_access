关于洪九果品和鑫荣懋的香蕉批发价格，**我无法提供具体实时报价**，因为水果批发价格波动大（受产地、季节、品质、采购量、地区市场供需等影响），且两家公司的报价需以当天批发市场实际成交为准。

但可以给你以下**分析和判断依据**，帮你评估哪家更有价格优势：

**1. 品牌定位与渠道差异**
- **洪九果品**：以“产地直采+全产业链”著称，在东南亚（如越南、老挝）和国内主产区有较强控制力，通常**量大价优**，适合大批量采购，议价空间大。
- **鑫荣懋**：国内头部果业公司，品牌溢价较高，常规批发报价可能略高，但胜在**品质更稳定**、包装和售后规范。

**2. 采购策略建议**
- **直接询价**：建议直接联系**当地一级批发市场**（如广州江南市场、北京新发地、上海辉展等）的**档口**，报出你预计的采购量（如多少箱/吨），请他们分别报**当日现价**。
- **对比含运费价**：问清楚是否含包装、冷链运输和送货上门费用，有的报价低但物流费高。
- **关注品级**：确认是“统货”还是“一级果”，统货价格更低但损耗可能大。

**3. 成本核算要点**
- 香蕉批发价通常按**箱**计（每箱约13-15公斤），不同规格价格差异大。
- 建议以**每公斤到手价**比较，同时计入**损耗率**（高品质香蕉损耗低，长期看可能更划算）。

**4. 注意事项**
- 避免只比单价，要考察：**成熟度**（青皮还是黄熟）、**果把大小**、**有无冻伤/黑斑**、**产地**（海南蕉与进口蕉价格差明显）。
- 若采购量小（少量几百斤），两者都没优势，直接找本地二等批发商或零售渠道更优。

**推荐做法**：  
直接给两家公司当地销售经理或市场档口打电话，说“我要长期采购，日订货量XX箱”，他会直接给你一个**底价**。如果你能亮出长期合作意向，洪九通常比鑫荣懋更灵活。
