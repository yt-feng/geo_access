关于都乐（Dole）和鑫荣懋（Golden wing Mau）的进口苹果价格竞争力，我无法直接提供实时报价，因为价格会随产地、品种（如红玫瑰、嘎啦、富士等）、规格、运输成本、季节和采购量显著波动。

**为你提供可执行的决策建议：**

1. **直接询价对比：** 这是最准确的方式。建议你联系两家公司的区域销售或总代理，提供你计划采购的品种（如加力果、红玫瑰等）、规格（如80#、90#）、采购量（箱数或吨位）和交货地，要求他们给出含税到岸或到仓价。
2. **关注市场行情：** 可以通过中国果品流通协会官网、海关数据（如中国海关总署发布的进出口数据）或上海辉展、广州江南市场等一级批发市场的每日价格行情，了解当前智利、美国、新西兰等主要产区的进口苹果批发价，作为谈判基准。
3. **考虑综合成本：** 价格不仅看单价，还要看：
   - **产地与关税**：比如智利苹果通常比美国苹果关税低，价格可能更低。
   - **到货稳定性**：鑫荣懋作为国内企业，在分销网络和本地服务上可能有优势；都乐全球供应链更强，但价格可能包含品牌溢价。
   - **品质损耗率**：低价格但运输损耗大可能反而增加总成本。
4. **小批量试单：** 建议先各采购一小批（如各2-5吨）试卖，对比实际销售速度、消费者反馈和损耗率，再决定长期供应商。

**一句话结论：** 建议你直接向两家索取带规格的报价单，并参考产地行情判断——通常**智利货源的鑫荣懋可能更有价格优势**，而**美国/新西兰货源的都乐可能因品牌和供应链稳定而单价略高**，但最终以你拿到的报价为准。
