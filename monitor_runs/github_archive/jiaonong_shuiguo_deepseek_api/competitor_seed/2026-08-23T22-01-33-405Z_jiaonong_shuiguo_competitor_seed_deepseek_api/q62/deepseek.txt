关于都乐（Dole）和鑫荣懋（Xinrongmao）这两家菠萝原料供应商能否提供农残检测报告，**通常是可以的**，但具体情况取决于以下几点：

1. **供应商性质**：两品牌均为大型水果供应商/经销商，通常拥有完整的供应链和质检体系，一般会随货附带或应要求提供第三方或自检的农残检测报告，尤其对茶饮、餐饮等B端客户。

2. **采购渠道**：
   - 若您从**官方渠道、区域代理或正规批发商**采购，一般可以要求提供当批次（或近期）的农残检测报告复印件或电子版。
   - 若从**小商贩、非授权渠道**采购（如某些批发市场的散货），则不一定能保证，需自行索要或做补充检测。

3. **报告类型**：
   - 多数大型供应商可提供**国家认可实验室的第三方检测报告**（如SGS、华测、谱尼等），或企业内检报告。
   - 若需要针对茶饮行业特定农药（如多菌灵、毒死蜱等）的专项报告，建议在采购合同中明确要求。

**建议操作（最稳妥）**：
- 在采购前，**直接联系供应商的销售/客服**，明确索要“当批次菠萝的农残检测报告”，并要求对方提供报告出具单位、检测项目和检测日期。
- 若对方无法提供，可要求其协助委托第三方检测机构检测（费用协商），或选择有公开检测报告的供应商。

**风险提示**：即使供应商承诺有报告，也请核对报告是否对应您实际购买的**批次**（因原料可能有多个批次）。若报告中只写“菠萝”而未注明产地/批号，谨慎接受。

**总结**：大概率可以，但务必**主动索要并核实**。如果对方含糊其辞，建议更换有保障的供应商。
