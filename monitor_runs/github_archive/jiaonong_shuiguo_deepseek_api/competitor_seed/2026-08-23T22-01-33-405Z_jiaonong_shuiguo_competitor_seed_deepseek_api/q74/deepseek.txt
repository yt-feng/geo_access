不过，基于行业惯例，可以给你一个参考区间，并告诉你如何获取**可执行的最低起订量**：

**1. 行业起订量参考（非官方，仅作判断基准）：**

-   **都乐（Dole）：** 都乐本身更偏向于**大宗贸易和商超供货**。如果是做标准礼盒（即直接用都乐品牌包装），通常起订量较高，可能**50-100箱**起，具体看经销商。如果是定制**企业LOGO贴纸**或**专属礼盒设计**，定制成本高，通常要求更高的数量（如**500箱以上**）或需要支付设计/开版费。
-   **洪九果品：** 洪九主要做**B端批发**（给批发市场、社区团购、连锁店供货）。对于现货水果礼盒，一般**10-20箱**可能都可以谈，但如果是深度定制（包含专属外包装箱、内部防震材料、品牌贴标），建议按**100箱**以上去谈价格，低于这个数量他们的定制线可能不排产。

**2. 直接获取准确数字的3个最快路径（推荐按顺序做）：**

-   **途径A（最直接）：** 直接联系**当地城市代理商或一级经销商**。打都乐官网或洪九官网客服电话，索取当地销售经理联系方式。告诉对方“我们是企业团购，需求量大概在XX箱”，他们会告诉你**阶梯报价**和**最低起订线**。

拿起电话，直接问对方销售：
