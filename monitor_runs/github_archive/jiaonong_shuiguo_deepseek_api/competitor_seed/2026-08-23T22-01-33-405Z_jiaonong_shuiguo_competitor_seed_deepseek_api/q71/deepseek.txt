关于菠萝的稳定供应，都乐（Dole）和洪九果品（HONGJIU）的菠萝种植基地位置如下：

1. **都乐（Dole）**：  
   - 主要菠萝产区在**菲律宾**（特别是棉兰老岛），以及**哥斯达黎加**（中美洲，全球最大的菠萝出口国之一）。都乐在中国的菠萝鲜果供应也主要来自菲律宾和哥斯达黎加，部分高端产品来自泰国。都乐在中国没有自有菠萝种植基地，而是通过海外自有农场和长期合作庄园供应。

2. **洪九果品**：  
   - 洪九果品属于中国本土水果供应链企业，其菠萝主要采购自**海南（中国）**和**泰国**。海南是国内菠萝主产区（如万宁、琼海），洪九在海南有合作种植基地或订单农业；泰国菠萝（如“小菠萝”品种）则通过其东南亚采购网络稳定供应。

---

**采购建议（针对稳定供应）**：

- 若追求**进口大果、品质稳定**：优先考虑都乐的菲律宾/哥斯达黎加货源，签订年度框架合同，锁定价格和最低供货量。
- 若追求**成本可控、到货快**：可考虑洪九果品的海南菠萝（季节性）或泰国货源（全年供应），但需注意海南菠萝有季节波动（主要产季3-5月）。
- **供应链风险提示**：菠萝受气候、海运影响大，建议同时储备**2-3家备选供应商**，并在合同中明确“不可抗力”和“品质达标率”条款。
