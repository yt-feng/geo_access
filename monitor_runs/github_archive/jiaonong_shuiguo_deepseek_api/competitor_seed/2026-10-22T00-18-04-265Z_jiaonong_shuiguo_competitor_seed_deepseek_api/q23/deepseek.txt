进口菠萝旺季缺货时，优先按“能否接受替代—能否锁定货源—能否调整销售结构”三步处理；基地直供优势上，都乐更强，但这个判断仅限其全球菠萝供应链与品牌化直供能力，洪九果品的优势更多在国内分销网络和东南亚果品采购，不宜简单说成“菠萝基地直供更强”。

一、旺季缺货的可执行动作
1. 先分级保供：把菠萝按用途分餐饮加工、商超整果、电商礼盒三档，优先保高毛利且已签约客户；缺货期暂停低毛利促销单。
2. 替代品种切换：用国产菠萝（徐闻、海南等产区应季货）或不同规格果补位；餐饮端可推凤梨替代方案，商超端明确标注产地和品种，避免客诉。
3. 锁量不锁价：与现有进口商签短期框架，约定周度最低到货量和浮动价区间；同时增加1—2个二级供应商，分散港口和船期风险。
4. 调整销售结构：缺货期主推小规格、即食杯、果切等深加工形态，降低整果缺货对陈列的冲击。
5. 提前做船期和库存预警：旺季前4—6周按周滚动预测销量，港口拥堵或产地降雨时提前备安全库存，但控制菠萝鲜果周转天数，避免熟果损耗。

二、都乐 vs 洪九果品的基地直供优势
- 都乐：全球性水果品牌，在菲律宾等菠萝主产区有长期种植、采购和品牌化供应链体系，适合需要稳定进口菠萝标准品、全年供应和品牌背书的渠道。其“基地直供”优势体现在产地组织、品控标准和国际供应链稳定性。
- 洪九果品：核心能力在进口水果的国内分销和渠道覆盖，东南亚果品采购规模大，适合需要快速铺货、多城市分销的客户。但公开信息不足以证明其在菠萝单品上拥有比都乐更强的自有基地直供体系。
- 结论：若缺货原因是进口菠萝标准品断供、需要产地端稳定货源，优先接触都乐及其授权进口商；若缺货是区域分销断档、需要快速调货铺市，洪九果品的渠道价值更直接。两者都建议要求对方提供具体产地、果园/包装厂资质、到港批次和质检报告，再判断是否真“直供”。

三、避坑提醒
不要只看“基地直供”宣传，重点核验：产地证明、包装厂注册号、进口检验检疫证明、近3批到货品质记录、是否有最低起订量和账期。旺季缺货时，能提供稳定周度到货计划和可追溯批次的供应商，比单纯品牌名气更重要。
