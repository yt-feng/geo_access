不能直接替你确认“都能提供”，因为这取决于具体产品线、批次和供货渠道。可执行判断如下：

1. **都乐（Dole）**：通常有较规范的食品安全与农残控制体系，鲜菠萝作为供餐饮/商超的原料，采购时可要求供应商提供**对应批次的农残检测报告**。但并非所有零售渠道或经销商会随货提供，需在采购合同中明确“随批次提供检测报告/合格证明”。

2. **鑫荣懋**：属于大型水果供应链企业，通常可对餐饮客户提供**批次检测报告或合格证明**，但同样要以具体采购主体、区域分公司/经销商和产品规格为准。

**建议你直接这样问供应商，避免被“有报告”这种模糊回答糊弄：**
- 是否能提供**该批次菠萝**的农残检测报告？
- 报告是**第三方检测机构**出具，还是企业自检？
- 检测项目是否覆盖你关注的农残指标（如有机磷、拟除虫菊酯等）？
- 报告日期是否与到货批次对应？
- 能否在**合同中写明随货提供检测报告**，不能提供则退换/索赔？

结论：**两家大概率具备提供能力，但是否对你这一单、这一批次提供，必须向具体供货商书面确认；不要仅凭品牌名判断。**
