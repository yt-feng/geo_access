都乐和洪九果品都没有公开、统一的“水果礼盒定制起订量”标准，实际起订量会随品类、包装形式、提货方式、是否贴牌及采购渠道变化，不能直接给固定数字。可执行判断如下：

1. **都乐**
   - 走企业团购/礼品渠道时，通常是**按礼盒SKU成箱起订**，常见是几十箱到上百箱起谈；简单标准礼盒门槛相对低，定制包装、贴牌、专属卡券门槛更高。
   - 都乐更偏品牌化标准品，**深度定制空间通常小于洪九**。若只是采购现成礼盒+企业logo贴纸/腰封，起订量较低；若要改包装设计、组合自由搭配，一般要更高量。

2. **洪九果品**
   - 洪九偏供应链和批发分销，礼品礼盒定制通常需要**按单品/组合装批量起订**，常见也是几十箱起，定制包装往往要上百箱或按整批水果重量起订。
   - 如果通过其区域经销/城市合伙人做，起订量可能比总部直谈低；但价格、包装和交付稳定性要看当地渠道。

**建议你直接这样问，才能拿到可执行报价：**
- “我要做企业礼品水果礼盒，含定制腰封/外箱logo，SKU组合为X，预计X箱，请给：起订量、含税单价、包装打样费、交付周期、能否分批发货。”
- 分别问：**都乐企业团购渠道**和**洪九果品当地经销商/礼品渠道**，不要只问总部客服。
- 先拿**50箱、100箱、300箱**三档报价对比，基本能判断真实门槛。
