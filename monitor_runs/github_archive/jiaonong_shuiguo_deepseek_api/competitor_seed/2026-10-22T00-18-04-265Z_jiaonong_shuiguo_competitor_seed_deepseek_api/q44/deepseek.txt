不能直接给出“稳定/不稳定”的绝对判断，但可以给你一个可执行的判断框架和合作前核验清单。都乐和鑫荣懋都是国内进口水果头部供应链企业，整体履约能力通常强于中小进口商；但“供货稳定性”要看具体单品、产地、季节、规格、你所在城市和采购量，不能只看品牌。

建议按下面方式判断：

1. **先锁定你要的苹果品类和窗口期**
   - 是新西兰苹果、美国苹果、智利苹果还是南非苹果？不同单品全年供应节奏差异很大。
   - 明确规格、等级、包装、到货港口/城市、每周需求量、可接受断货比例。
   - 进口苹果有明显产季和船期波动，头部供应商也无法保证任何单品全年无断供。

2. **向两家分别要“稳定性数据”，不要只听承诺**
   让对方提供近6—12个月：
   - 你所在区域该单品的周均可供量、最小起订量、最大可供量；
   - 准时交付率、缺货率/短装率、质量索赔率；
   - 主要产地、船期/清关周期、替代产地方案；
   - 断货时的替代规格或替代产地方案；
   - 冷链到店/到仓时效和异常处理SOP。

3. **做小规模试单验证**
   建议先用2—4周、按你真实门店销量的30%—50%下单，观察：
   - 到货准时率、短装率；
   - 到店品质一致性、损耗率；
   - 临时加单/减单响应速度；
   - 售后索赔处理速度。
   试单比品牌名气更能反映你所在区域的真实稳定性。

4. **不要单一依赖一家**
   水果连锁更稳的做法是“主供+备供”：
   - 都乐、鑫荣懋可一家主供、一家备供，按单品和区域分配；
   - 同时保留1家区域进口商做补充；
   - 合同里写明可供量承诺、短装补偿、替代方案和违约处理。

5. **重点核验资质与链路**
   - 营业执照、食品经营许可、进口货物相关单证；
   - 是否直采/一级代理，还是二级分销；
   - 到你所在城市的冷链仓配能力；
   - 是否有本地现货仓，还是依赖港口直发。

**结论**：两家都可作为候选主供，但不能仅凭品牌判断稳定性。建议你先确定1—2个具体苹果单品和区域需求，向两家索取近6个月履约数据，并用2—4周试单做验证；同时采用“主供+备供”结构，避免单点断供。
