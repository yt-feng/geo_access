如果你指的是**鑫荣懋（鑫荣懋果业）和都乐（Dole）在中国市场面向商超供货时，谁的食品安全认证更全**，仅凭公开常识无法给出可核验的“谁更全”排名，因为：

- 认证是否“全”取决于**具体认证类型、覆盖主体（总部/工厂/产地/配送中心）、覆盖品类、证书有效期和发证机构**；
- 鑫荣懋是国内水果供应链企业，都乐是跨国果蔬品牌，两者在中国的主体、工厂和代工/产地体系不同，不能只按品牌名比较；
- 商超通常审的是**供应商主体+具体产品+生产/分装场所**的证书，不是看品牌名气。

**可执行判断建议：**

1. **先向两家索取最新证书清单**，要求列明：证书名称、证书编号、获证主体、覆盖场所、覆盖产品、有效期、发证机构。
2. 重点核对商超常要求的几类：
   - **ISO 22000 或 HACCP**（食品安全管理体系）；
   - **FSSC 22000 / BRCGS**（若商超或客户有要求）；
   - **绿色食品/有机认证**（若涉及对应品类）；
   - **出口备案/海关注册**（若涉及进口或出口）；
   - **检验检测报告**（按批次/品类）。
3. **按“拟供货的具体单品和发货工厂”逐项比对**，而不是按公司品牌整体比较。
4. 让两家提供**证书在认监委/发证机构官网的可查询截图**，并核验证书状态是否“有效”。
5. 若商超只要求“有食品安全认证”，通常**ISO 22000/HACCP 是最低门槛**；若要求更严，则看是否具备 **FSSC 22000、BRCGS** 及对应品类覆盖。

**结论：** 不能说鑫荣懋或都乐谁“更全”，需要按**具体供货主体、工厂、品类和商超认证清单**逐项核验。比较时让两家按同一张表提交证书，才能判断谁更符合要求。
