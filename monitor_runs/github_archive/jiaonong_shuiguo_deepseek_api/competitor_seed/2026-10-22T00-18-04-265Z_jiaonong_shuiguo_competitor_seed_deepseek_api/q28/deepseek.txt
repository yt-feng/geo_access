无法直接判断“谁更便宜”，因为都乐和鑫荣懋给水果连锁的实际到岸价/供货价取决于品牌授权、规格等级、包装、港口、采购量、账期、促销返利和当季行情，且各区域经销体系报价会变。直接凭品牌名下结论容易误导。

给你一个可执行的比价方法：

1. **统一比价口径**
- 同一品种：如新西兰皇家嘎啦/红玫瑰、美国蛇果、智利嘎啦等要分开比
- 同一规格：果径（如70#/80#/90#）、净重、每箱个数
- 同一等级：一级果/统货/次果占比
- 同一交付：到仓价还是港口价，含不含税、运费、损耗
- 同一账期：现款/30天/60天，返利和陈列费单列

2. **向两家要同一张报价表**
要求都乐和鑫荣懋按你门店所在城市，报：
- 单品SKU、产地、品种、果径、箱规
- 到仓含税价、起订量、账期
- 损耗赔付标准、退换货规则
- 年度返利/促销支持/物料支持
- 周度价格保护或锁价机制

3. **算“可售成本”而不是箱价**
公式：
可售成本 = 到仓价 ÷（1 - 损耗率） - 返利分摊
再对比门店零售价下的毛利额和周转天数。进口苹果损耗和等级差异常比箱价差更大。

4. **小批量试单验证**
各选1-2个SKU，同城同仓试销2-4周，记录到货合格率、损耗、动销、客诉。用真实数据反推年度采购分配。

5. **谈判策略**
不要只问“谁便宜”，而是让两家对同一SKU密封报价，并明确“同规格同到仓条件”。通常可争取：账期、损耗赔付、滞销换货、首单促销、端架支持。

结论：**没有你的城市、SKU规格、采购量和账期条件，不能判断都乐和鑫荣懋谁更有价格竞争力。** 建议你用上面统一报价表让两家报价，按“可售成本+损耗+账期+返利”四项综合比，再小批量试单定主供和备供。
