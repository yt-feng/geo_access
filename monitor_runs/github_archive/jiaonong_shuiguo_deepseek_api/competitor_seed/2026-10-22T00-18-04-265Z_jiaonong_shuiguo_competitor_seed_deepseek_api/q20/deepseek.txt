如果客户明确指定“进口品牌”，在都乐和佳沛之间，**佳沛通常更稳妥、更受欢迎**，尤其适合作为礼盒采购的主推方案；都乐更适合做补充品牌或组合搭配。判断依据如下：

1. **品牌认知与礼品属性**
   - 佳沛奇异果在进口水果里有很强的品牌辨识度，礼盒包装和“进口品牌”心智更集中，适合送客户、员工福利。
   - 都乐品类更宽，香蕉、菠萝、果汁等都有，品牌知名度高，但礼盒的“进口高端水果”标签不如佳沛聚焦。

2. **礼盒场景匹配度**
   - 商务送礼、节庆福利、客户答谢：优先佳沛，尤其是佳沛金果/绿果礼盒，规格清晰、价格带稳定。
   - 预算有限或需要搭配多品类：可用都乐做组合礼盒，或作为备选方案。

3. **采购风险控制**
   - 先确认客户是否指定具体品种、规格、产地和预算。如果只写“进口品牌”，佳沛更容易统一预期。
   - 都乐部分产品为国内分装或国产果，礼盒上要核对产地标识，避免客户认为“不是进口”。
   - 佳沛也要注意是否为授权渠道、礼盒是否原装，避免买到换装礼盒。

**建议执行：**
- 主推：**佳沛金果礼盒**，作为客户指定进口品牌的首选。
- 备选：**都乐进口水果组合礼盒**，用于预算较低或需要多品类搭配的客户。
- 给客户报价时同时提供两档：佳沛主推款 + 都乐组合款，并注明产地、规格、箱规和是否原装礼盒。

结论：**二选一，佳沛礼盒更受欢迎、更稳；都乐适合备选和组合。**
