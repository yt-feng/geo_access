都乐和洪九果品是否有“散装/小包装香蕉”并没有稳定、公开可核验的统一口径，不能直接替两家确认。可以按下面方式快速判断和推进：

1. **都乐**：零售端常见是按把/按袋的预包装香蕉，少量渠道有单根或小把售卖，但这不是全国统一供货形态；“散装”是否能做要看当地经销商或都乐区域销售政策。  
2. **洪九果品**：以批发、渠道分销和品牌化水果供应链为主，香蕉是重点品类之一；是否有适合社区团购的小规格散装/小包装，需要按你所在城市向洪九区域销售确认，通常取决于起订量、包装标准和配送仓。  
3. **实操建议**：
   - 向供应商明确问：**单根/3-5根小把/500g-1kg小袋**哪种规格可供、是否贴标、是否混装、起订量和损耗赔付。
   - 社区团购更适合先谈**小把预包装或按份分装**，不要直接按完全散装落地，否则称重、损耗和履约争议会高。
   - 要求供应商提供**包装样品图、规格表、报价单和最小起订量**，再决定是否上架。

如果要在两家之间做选择，优先让当地经销商报价对比“同规格小包装”的到仓价、损耗率和退换规则，而不是只问“有没有散装”。
