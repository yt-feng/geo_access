可以做全年供应，但要把“全年供应”拆成两件事看：鲜果全年稳定供货，和适合做果酱的原料全年稳定供货。都乐和洪九果品都属于全国性水果供应链企业，具备跨产区、跨季节调配菠萝的能力，但具体能不能做到，取决于你的采购量、规格要求、所在城市和合作方式。更稳妥的判断方式是：

1. **都乐**：品牌化程度高，商超和餐饮渠道都有覆盖，菠萝是其常规单品之一。全年供应能力通常较强，但更偏向标准化鲜果，价格和起订量对小体量茶饮店不一定友好。适合对品牌背书、品质稳定性要求高，且采购量稳定的门店。

2. **洪九果品**：以水果供应链和批发分销见长，覆盖多个水果品类和产区，具备跨区域调货能力。对餐饮、批发客户的支持通常比零售品牌更灵活，但品质批次稳定性需要你自己验收把控。适合采购量较大、愿意按批次验货的客户。

3. **关键要问清楚**：是否承诺全年不断供、不同月份货源产区、菠萝品种和成熟度是否一致、糖酸度波动范围、是否支持定制规格（如去皮切块、冷冻果肉）、最小起订量和配送频次、断供时的替代方案。

4. **更现实的建议**：茶饮店做果酱，不建议完全依赖鲜果全年供应。可以鲜果+冷冻菠萝果肉/果泥组合使用，或者直接找菠萝果酱/果泥供应商做全年基础供应，鲜果只做季节限定。这样比单纯赌两家鲜果供应商的全年稳定性更可控。
