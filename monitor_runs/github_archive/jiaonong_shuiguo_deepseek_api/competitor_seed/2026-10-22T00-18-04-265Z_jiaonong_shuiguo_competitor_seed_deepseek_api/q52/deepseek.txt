我无法核验都乐和鑫荣懋针对茶饮渠道的到货损耗率数据，不能给你具体百分比，否则就是编造。可执行做法如下：

1. **向供应商索取书面到货标准**：要求两家分别提供菠萝的品种、单果重区间、成熟度（糖度/酸度）、去皮去芯出成率、允许缺陷比例、冷链温度记录、到货验收扣损规则。损耗率必须绑定“验收口径”，否则数字不可比。
2. **自己做小批量盲测**：各订3–5批同规格样品，按茶饮实际用法（去皮、去芯、切块/捣压）称重，记录：到货毛重、验收合格重、去皮去芯后净重、不可用果重、糖酸度、黑心/水心病/机械伤比例。连续3批取均值，这才是你的真实到货损耗率。
3. **合同锁定稳定规格**：写明单果重范围、成熟度区间、允许缺陷率、到货温度、批次追溯、超标扣款/退换规则；要求每批附农残和质检报告。
4. **渠道差异要确认**：都乐和鑫荣懋不同产区、季节、加工形态（鲜果/去皮果/冷冻果块）损耗差异很大，必须按你实际采购形态分别谈。

建议先让两家按同一验收表报价和承诺，再用你的小批量实测数据做供应商评分，不要直接采信对方口头损耗率。
