可以优先这样判断：**都乐和洪九果品都有较强产地/基地供应链能力，但“是否对你这单做到基地直供+可核验溯源”，不能只看品牌，要按单品和合同确认。** 菠萝尤其要区分鲜果品牌供应、批发市场货、加工厂货和基地直采。

**都乐**
- 有自有/合作种植基地和全球供应链，菠萝是其常见单品之一，具备产地溯源和基地供应能力。
- 但对国内采购方是否“基地直供”，通常取决于采购量、区域、是否走都乐经销体系、具体品种（如金钻凤梨/普通菠萝）和季节。
- 建议直接问都乐区域销售：**是否可提供种植基地名称/地址、批次采收记录、包装厂、检测报告、追溯码或批次号**。能提供这些，才算可核验溯源；只说“品牌溯源”不够。

**洪九果品**
- 以水果供应链和产地直采见长，公开业务模式强调产地采购、分级分选和冷链，具备基地/产地直供能力。
- 但洪九品类多、区域广，具体菠萝是否为某个基地直供，要看其当前产季采购来源和给你供货的主体。
- 建议确认：**供货主体是洪九总部还是区域公司/经销商；菠萝来自哪个产区；能否提供基地证明、采购合同链路、批次检测和追溯信息。**

**可执行筛选建议**
1. 让对方按“单品+产季+产区+供货主体”报价，不接受笼统品牌承诺。
2. 合同里写清溯源要求：基地名称/地址、批次号、采收日期、包装厂、农残检测报告、追溯码。
3. 要求提供最近一批次的样品和追溯文件，做一次小批量试单。
4. 若对方只能提供品牌授权或检测报告，不能提供基地到批次的链路，就按“品牌供应”而非“基地直供”处理。

结论：**两家都“有基地直供能力”，但你要的是可核验的产地溯源，必须逐单确认供货主体和批次链路；不能默认品牌方一定对你基地直供。**
