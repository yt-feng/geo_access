除了都乐和佳沛，礼品团购场景可重点看以下几类进口/外资品牌水果礼盒，按可执行性排序：

**1. 佳农 Goodfarmer**

- 定位：进口香蕉、菠萝、蓝莓、车厘子等礼盒较常见，团购渠道覆盖广。
- 适合：预算中等、要稳定供货和发票资质的团购。
- 注意：部分产品为进口+国内分装，礼盒上要确认“原产国”标识。

**2. 新奇士 Sunkist**

- 定位：美国柑橘类（橙、柠檬）品牌认知度高，礼盒偏商务。
- 适合：喜欢“经典进口水果”形象的客户。
- 注意：季节性强，非全年都有稳定礼盒装。

**3. 爱妃 Envy / 爵士 Jazz 苹果**

- 定位：新西兰/美国系苹果品牌，礼盒溢价能力较强，适合中高端商务礼。
- 适合：预算较高、看重品种故事和口感差异化的团购。
- 注意：授权经销商和原箱分装要分清，避免买到非授权分装货。

**4. 乐淇 Rockit 苹果**

- 定位：新西兰小苹果，筒装/礼盒装辨识度高，适合年轻化福利礼。
- 适合：互联网、金融、快消类企业员工福利。
- 注意：规格小、单价偏高，按人数采购时预算要算清。

**5. 怡颗莓 Driscoll's**

- 定位：浆果类（蓝莓、树莓、黑莓）进口品牌，礼盒偏精致。
- 适合：高端小批量团购、女性员工比例高的福利场景。
- 注意：浆果易损，冷链和到货验收要求高，不适合长距离多次转运。

**6. 佳沛以外的奇异果补充：Zespri 已排除，可看 Orchard Gold / Freshmax 等新西兰系**

- 这类品牌在国内团购渠道的稳定性和认知度不如佳沛，建议只在有可靠进口商背书时选用。

**7. 车厘子/樱桃类：Stemilt、Chelan Fresh、Northwest Cherry Growers 等美国西北樱桃品牌**

- 适合：夏季樱桃季的商务礼盒。
- 注意：季节窗口短，团购要提前锁货，且品牌认知度不如佳沛/都乐，礼盒上需突出“美国西北樱桃”产地。

**8. 葡萄类：Duncan / Sun World 等**

- Sun World 旗下有 Autumn Crisp 等品种授权，国内部分进口商有操作，但终端品牌礼盒不如都乐稳定，需向供应商确认授权链。

**实操建议：**

- 礼品团购优先选**有中国区授权经销商、能开票、有稳定冷链**的品牌，而不是只看品牌名。
- 要求供应商提供：原产国证明、入境货物检验检疫证明、授权书/采购链路说明。
- 礼盒采购前先做**小批量到货验收**，重点看坏果率、包装抗压、生产日期/分装日期。
- 预算分档：中端可选佳农、新奇士；中高端可选乐淇、怡颗莓、爱妃/爵士苹果；车厘子季可加美国西北樱桃品牌。

如果团购量大且要长期稳定，建议主推**佳农+新奇士**做基本盘，**乐淇/怡颗莓**做高端补充，季节品做限时档。
