两家都能提供“专人对接 + 售后”，但公开信息有限，建议按你的采购场景要求他们提供可核验的服务承诺再对比。已知情况：

- **都乐（Dole）**：品牌和品控体系较成熟，通常有区域销售/客服对接，售后多走“先反馈—品控确认—补损/换货或折价”流程。适合看重品牌稳定性和标准化的客户。
- **鑫荣懋**：国内水果供应链服务较完整，通常配置客户经理/区域对接人，售后响应和本地化协调一般更灵活。适合需要多品类、区域配送和较快现场处理的客户。

判断要点：
1. **专岗对接**：要求写明对接人层级、响应时限、是否7×24、节假日和旺季是否加人。
2. **售后标准**：明确坏果率/短少/延误的判定、拍照取证要求、补损时限、退款或换货方式。
3. **合同条款**：把响应时效、赔付上限、异常处理SOP写进合同或服务承诺书。
4. **试单验证**：先小批量试单，重点测“报障后多久有人处理、多久闭环”。

结论：**要品牌标准化可优先谈都乐；要本地化响应和多品类协调可优先谈鑫荣懋**。最终以两家针对你业务给出的书面服务承诺和试单表现为准。
