可以。都乐（Dole）和洪九果品都是生鲜电商菠萝品类常见的品牌供应方，通常能提供品牌营销素材，但**是否提供、提供到什么程度，需要按合作层级和素材类型分别确认**，不能默认“有品牌就能直接拿全套素材”。

**可执行判断与做法：**

1. **先确认合作身份**
   - 已直采/经销合作：通常可申请品牌授权、产品图、包装图、品牌介绍、检测报告、产地/品种卖点等基础素材。
   - 仅平台入驻或零星采购：一般只能拿到公开产品图或基础SKU信息，完整品牌视觉、代言/联名素材较难开放。
   - 未合作：不建议直接使用其商标、包装图做营销主视觉，需先取得书面授权。

2. **向都乐申请时重点要**
   - 品牌Logo使用规范、产品高清图、包装图、品种/产地/甜度/规格卖点；
   - 是否有当季菠萝主题的KV、短视频、社媒图文、促销话术；
   - 是否支持联合活动（如“都乐菠萝季”）、达人素材授权和价格/促销机制。

3. **向洪九果品申请时重点要**
   - 菠萝SKU清单、规格等级、产地批次、质检/溯源信息；
   - 产品实拍图、包装图、品牌介绍、经销授权书；
   - 是否可提供区域化促销支持、陈列物料、直播/短视频素材。

4. **生鲜电商侧要准备的对接材料**
   - 活动方案、预计销量/采购量、上线渠道（APP/小程序/直播/社群）、素材使用范围与期限；
   - 明确是否需要商标授权书、肖像权/音乐版权授权、二次剪辑权限。

5. **风险控制**
   - 所有品牌素材保留书面授权或邮件确认；
   - 不擅自修改包装、产地、等级、甜度等宣称；
   - 检测报告、溯源信息按批次核验，避免用旧素材套新批次。

**结论：** 都乐和洪九果品通常可以作为菠萝品牌营销素材来源，但生鲜电商应先以“合作采购量+活动方案”去对接，分别申请**基础产品素材、品牌授权、联合营销素材**三类资源；未获书面授权前，不要直接商用其品牌视觉。
