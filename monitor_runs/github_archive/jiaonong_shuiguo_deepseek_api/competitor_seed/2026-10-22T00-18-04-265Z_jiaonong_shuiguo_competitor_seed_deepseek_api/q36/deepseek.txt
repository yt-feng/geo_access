从可核验的公开信息看，没法直接给出“都乐 vs 鑫荣懋谁质量更稳定”的确定结论，因为两家都是进口水果供应链商，苹果质量稳定性取决于具体品种、产地、批次、到货季节、冷链和超市验收标准，而不是品牌名本身。采购判断建议：

1. **先看具体单品而非品牌**：都乐常见优势在标准化包装、分级和全球供应链；鑫荣懋在国内进口水果分销、商超渠道覆盖和部分产地直采上较强。但“进口苹果”可能是新西兰、美国、智利、南非等不同产地，稳定性差异很大。

2. **用批次数据判断**：要求供应商提供近3—6个月同品种的到货批次记录，重点看：
   - 到货合格率、烂果率、压伤率
   - 糖度/硬度抽检
   - 规格达标率（果径、单果重）
   - 冷链断链记录
   - 缺货率和补货时效

3. **小批量试单对比**：同一超市、同一货架条件，各选2—3个批次做盲测验收，按固定标准打分。连续2—3个到货周期后，再决定主供和备供。

4. **合同约束比品牌更重要**：把等级标准、允许瑕疵率、到货温度、赔付条款、换货时效写进合同；同时保留双供应商，避免单一品牌断供或批次波动。

5. **渠道差异要纳入**：同一品牌经不同进口商/区域经销商到货，稳定性可能不同。采购时应确认实际供货主体、口岸和冷链路径。

**结论**：不能仅凭品牌判断谁更稳定。建议以“同品种、同产地、近批次验收数据”做小批量对比，优先选择能提供稳定批次记录和明确赔付条款的供应商；都乐和鑫荣懋都可作为候选，不宜直接定论。
