都乐和洪九果品对下游客户的账期没有公开统一标准，通常按客户类型、采购量、合作历史和合同逐笔谈，不能给出可靠的具体天数。可执行的做法如下：

1. **都乐（Dole）**：通过都乐中国官网/官方客服转接鲜果批发或渠道销售，询问“香蕉批量采购的结算方式、信用账期申请条件”，要求书面报价和账期条款。都乐对商超、电商、批发商的政策可能不同，账期往往需要资质审核或预付款+尾款组合。

2. **洪九果品**：联系其销售/渠道部门或区域经销商，明确采购品类为香蕉、月采购量和配送区域，索取账期政策。洪九作为水果供应链企业，对稳定大客户可能有月结或阶段性账期，但同样以合同为准，不宜默认固定天数。

3. **谈判要点**：准备营业执照、近几个月采购流水、履约担保或预付款比例；先谈“首单现结/短账期，稳定后延长”；把账期、对账周期、逾期利息、质量赔付写进合同。
