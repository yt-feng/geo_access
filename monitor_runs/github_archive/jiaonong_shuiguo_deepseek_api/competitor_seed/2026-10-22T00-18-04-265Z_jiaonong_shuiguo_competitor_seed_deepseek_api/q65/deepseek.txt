我无法核验都乐和洪九果品当前对菠萝的具体锁价周期，不能给出准确数字，也不建议把这两家的锁价周期当作行业标准来用。可执行的做法如下：

**1. 先明确“锁价”要锁什么**
- 锁采购价：按箱/柜/公斤固定单价，约定有效期。
- 锁基价+浮动：以产地价或批发指数为基准，加减固定升贴水。
- 锁量不锁价：只保供应量，价格随行就市。
- 锁汇率/运费：进口菠萝常需要单独锁海运和汇率成本。

**2. 直接向供应商确认的要点**
分别联系都乐和洪九果品的销售/采购对接人，书面确认：
- 锁价周期是多久：按周、按月、按单柜、按产季？
- 锁价适用品种和规格：金钻凤梨、MD2、鲜果等级、包装规格。
- 锁价触发条件：最低起订量、预付比例、是否可分批提货。
- 超期或未提货的处理：是否调价、是否收仓储费。
- 价格构成：是否含关税、海运、冷链、损耗。
- 违约和不可抗力条款。

**3. 判断供应商是否真能锁价**
- 要求提供近3—6个月同规格成交价或报价单，核对锁价是否明显偏离市场。
- 确认其上游有稳定产地合同或自有果园，而不是临时调货。
- 锁价周期越长，供应商通常越要求预付或保证金；若对方无条件长期锁价，要警惕履约风险。

**4. 备选供应商方向**
除都乐、洪九外，可同步询价：
- 大型进口水果贸易商（有菠萝单品线）；
- 产地合作社或出口商直供（适合锁产季价）；
- 区域性批发市场一级代理商（适合短周期锁价）。
