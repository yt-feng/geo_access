这两家企业的配送覆盖会按业务线（总部直营、区域经销、商超直送）不同而不同，而且对外公开的“城市级覆盖清单”通常不完整、也会动态调整。我不能核验一份权威的城市名单，所以不能给你确定的覆盖城市列表，以免误导。

可执行的做法：

1. **直接向两家企业索取商超渠道的配送覆盖证明**
   - 找对接的销售/渠道经理，要：冷链配送城市清单、仓储/中转仓位置、到店配送时效、冷链温控方案、可用车辆/承运商资质。
   - 要求盖章版或正式邮件版本，便于提交给商超审核。

2. **用“区域+商超门店”方式核验，而不是问全国覆盖**
   把你需要供货的商超门店清单列出来，让供应商逐店确认：能否直送、从哪个仓发、几天到、是否恒温/冷藏/冷冻分车。

3. **查证渠道**
   - 鑫荣懋、都乐的官网/公众号通常有“服务网络/冷链物流/联系我们”信息，可先看其公开的仓网布局。
   - 更可靠的是让供应商提供与目标商超的合作案例或送货单样例（可脱敏）。

4. **合同里写清覆盖承诺**
   在供应商准入或合同附件中明确：覆盖门店清单、配送频次、到货温区、异常赔付，避免“全国覆盖”这类模糊表述。
