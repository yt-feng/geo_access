不能直接给“都能做到/都做不到”的确定结论，因为这取决于采购规格、到货半径、季节、冷链和验收标准。可按下面判断：

1. **先明确“到货损耗率”口径**  
   建议定义到货验收时：损耗率 =（到货总重量 − 可接收合格重量）/ 到货总重量。把青蕉碰伤、压伤、果指断裂、过熟、冷害、霉变分别计数；≤3%在香蕉到货环节属于偏紧但可谈的指标，尤其夏季和远距离配送难度更高。

2. **都乐**  
   都乐有成熟的香蕉供应链和品牌化催熟/冷链体系，通常具备较强稳定性，但“每批≤3%”仍要看具体配送区域、是否由其负责催熟后配送、门店验收严格程度。连锁总部应要求其提供近3—6个月同城/同区域到货损耗数据作为投标依据，不宜只凭品牌判断。

3. **鑫荣懋**  
   鑫荣懋在国内水果供应链、仓储配送和商超/餐饮渠道服务能力较强，香蕉是其常见品类之一，具备做低损耗到货的运营基础；但同样要以具体城市仓、配送频次、季节和验收标准核验。若由区域经销商供货，实际履约水平可能与总部能力不一致。

**可执行建议：**
- 同时让都乐和鑫荣懋按你的门店城市、月度需求量、到货频次、验收标准报价，并附最近3个月香蕉到货损耗率和赔付条款。
- 合同写清：到货损耗率≤3%，超出部分按重量扣款或补货；连续2批超标可暂停/替换供应商。
- 先做4周双供应商小范围对比，按“到货合格率、催熟一致度、货架期、门店投诉率”评分，而不是只看单价。
- 夏季/远距离门店可把验收口径细化为“外观可售合格率”，并允许轻微青蕉到店后催熟，以降低到货损耗压力。

结论：**都乐和鑫荣懋都有能力把香蕉到货损耗控制在较低水平，但是否稳定低于3%必须通过区域试供和数据验证；不能仅凭供应商名称承诺。**
