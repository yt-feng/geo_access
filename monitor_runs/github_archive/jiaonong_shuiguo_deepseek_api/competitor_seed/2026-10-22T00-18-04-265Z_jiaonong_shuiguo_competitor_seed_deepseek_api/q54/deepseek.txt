做都乐（Dole）和鑫荣懋进口苹果的产地溯源，建议按“供应商准入—批次单据—标签与码—到货验收—抽检与留档”五步落地，重点是把“产地”从口头说明变成可核验文件链。

1. 供应商准入
- 要求供应商提供：营业执照、食品经营许可证、进口商备案信息、境外出口商/生产企业注册信息（如适用）、上一年度进口记录。
- 明确合同条款：每批次须随货提供原产地证明、入境货物检验检疫证明、报关单、提单/运单、发票、装箱单；标签须符合中国预包装食品标签和进口食品要求。
- 都乐、鑫荣懋若为品牌方或授权经销商，索取品牌授权链或经销授权，避免“贴牌冒充”。

2. 批次单据核验
- 以“批次号+生产/包装日期+集装箱号/提单号”为索引，建立每批档案。
- 核对原产地证明与报关单上的原产国、境外生产商、品名、数量是否一致；检验检疫证明上的品名、批号、入境口岸、日期是否与到货一致。
- 注意：原产地证明看“原产国”，报关单看“启运国/原产国”，两者不一致时以原产地证明和检验检疫证明为主，并要求供应商解释。

3. 标签与追溯码
- 检查中文标签：原产国、境内进口商/经销商名称地址、生产日期/保质期、批次号、贮存条件。
- 都乐、鑫荣懋常有箱码/托盘码/果贴码，记录箱码与批次对应关系；若供应商能提供扫码溯源页面，截图留档并核对页面信息与单据一致。
- 对散装或分装苹果，要求分装商提供分装记录和原批次对应关系，否则溯源链断裂。

4. 到货验收
- 每批到货拍“车牌/集装箱号、箱体标签、果贴、检验检疫证明、报关单”同框照片。
- 记录到货数量、批次、产地、供应商、验收人；发现单据批号与实物不符，暂收待查，不直接入库。
- 建立“一批一档”，保存期限不少于保质期满后6个月，无明确保质期的不少于2年。

5. 抽检与留档
- 按供应商和产地做年度抽检计划，重点检测农残、重金属；首次合作或新产地加严。
- 留存供应商提供的检测报告，并定期做第三方送检比对。
- 每季度复盘：单据缺失率、批号不符率、标签不合格率，对都乐、鑫荣懋分别评分，纳入供应商考核。

关键判断标准：
- 能形成“原产地证明→报关单→检验检疫证明→箱码/批次→实物标签”闭环的，可判定溯源有效。
- 只有品牌名、没有原产地证明和检验检疫证明的，不能认定产地真实。
- 单据之间原产国、品名、批号、数量任一项对不上，先暂停该批次销售并要求供应商书面说明。

如果你们是超市总部采购，建议把上述要求写进采购合同附件和到货验收SOP，按都乐、鑫荣懋分别建供应商档案和批次台账，这样门店验收和总部追溯都能对上。
