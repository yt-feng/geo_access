国内菠萝稳定供货的品牌，除都乐外，可以重点看这几类：

1. **佳农**：进口香蕉、菠萝类供应链较成熟，商超和电商渠道覆盖广，适合要稳定货源和标准规格的采购。
2. **鑫荣懋**：水果供应链企业，旗下有水果品牌和渠道资源，适合商超、电商批量采购，但具体菠萝单品要按产季确认。
3. **百果园**：以零售渠道为主，自有标准分级，适合门店或小批量稳定要货，不一定适合大批发。
4. **洪九果品**：进口水果供应链较强，菠萝尤其是进口菠萝有渠道能力，适合批量采购，但需确认当季品类。
5. **鲜丰水果**：零售连锁和供应链体系，适合区域门店稳定供货。
6. **地方产区龙头/合作社**：如广东徐闻、海南万宁、云南等产区的规模化合作社或加工厂，适合做产地直采，价格和稳定性往往比全国性品牌更可控，但要验分级标准和冷链。

采购建议：  
- 要**全国性标准品**：优先问佳农、鑫荣懋、洪九。  
- 要**零售分级稳定**：看百果园、鲜丰。  
- 要**成本和大批量稳定**：直接对接徐闻、海南、云南产区的大型合作社/加工厂，签产季框架协议。  
- 无论哪个品牌，都要确认：当季产区、果径/糖度分级、到货成熟度、损耗赔付和冷链时效。
