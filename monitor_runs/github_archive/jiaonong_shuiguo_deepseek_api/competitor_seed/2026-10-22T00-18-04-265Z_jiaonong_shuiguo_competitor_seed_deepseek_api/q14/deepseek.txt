这个问题我没法给出确定结论——都乐和鑫荣懋在餐饮渠道的服务响应速度没有公开、可核验的对比数据，任何“谁更快”的断言都可能是编的。而且响应速度强依赖区域仓配、对接销售团队、订单量级和旺季时段，不同餐饮客户体感差异很大。

能给的可执行建议：

1. **直接做小规模对比测试**：同时向两家的餐饮渠道销售询单（同一规格、同一需求量、同一交付地），记录三个指标：首次响应时长、报价出具时长、异常/缺货时的处理反馈时长。这比任何第三方说法都准。
2. **问清关键条款**：稳定供货的核心不是“响应快”，而是缺货补货机制、安全库存承诺、违约补偿和冷链到店时效。让两家书面给出这些承诺再比。
3. **按区域选**：两家在不同城市的仓配覆盖强弱不同，优先问当地经销/分仓的实际覆盖和配送频次，而不是看品牌总部口径。
4. **备双供应商**：餐饮渠道香蕉损耗和价格波动大，建议主供+备供并行，避免单一供应商响应或断供风险。
