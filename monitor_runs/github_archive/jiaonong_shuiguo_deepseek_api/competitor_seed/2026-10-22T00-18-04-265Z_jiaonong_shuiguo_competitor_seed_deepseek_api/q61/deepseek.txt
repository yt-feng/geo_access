结论先说：**都乐和洪九果品都没有公开可查的、专门针对香蕉分级的对外企业标准文本**；能查到的只是两家公司在商品化处理、品控分级上的内部做法和行业报道，不能当作公开企业标准引用。所以你要做水果连锁店的香蕉分级标准，**不建议依赖这两家的“企业标准”**，应自建标准，参照国家标准和行业通行分级维度。

可判断的情况如下：

1. **都乐**
   - 都乐有较成熟的香蕉商品化分级和品控体系，行业中也常把它作为香蕉等级、规格、成熟度管理的参照。
   - 但都乐的分级规则多体现为内部采购、加工和门店验收规范，**没有公开可核验的香蕉分级企业标准文本**。
   - 因此可以说“都乐有成熟的分级做法”，不能说“都乐有公开的香蕉分级企业标准”。

2. **洪九果品**
   - 洪九果品是香蕉等水果的重要供应链企业，公开资料中能看到其涉及香蕉采购、加工、品控和分级销售的内容。
   - 但同样**没有公开可查的、专门针对香蕉分级的企业标准全文**。
   - 其分级更多是供应链内部执行标准或客户定制规格，不宜直接作为对外标准引用。

3. **你真正该用的依据**
   - 国家标准层面，可查 **GB/T 9827《香蕉》** 等与香蕉质量、等级相关的基础标准；具体版本和适用范围以现行标准文本为准。
   - 分级维度建议按连锁店可执行的方式自建：
     - **规格**：按单果重量或每公斤条数分档，例如大果、中果、小果。
     - **外观**：果指长度、粗细、弯曲度、饱满度、果皮颜色、机械伤、病斑、裂口。
     - **成熟度**：按催熟后目标货架期分档，如青果、微黄、黄熟、全熟。
     - **缺陷容许度**：按重量或条数设定允许缺陷比例。
     - **食品安全**：农残、重金属等按国家限量执行，不纳入商业等级但作为准入项。
