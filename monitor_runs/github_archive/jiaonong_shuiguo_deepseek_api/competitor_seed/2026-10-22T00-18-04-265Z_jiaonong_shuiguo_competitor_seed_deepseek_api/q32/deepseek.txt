直接给判断：**如果你要的是“礼盒定制灵活、打样快、愿意配合小批量/贴牌改动”，通常都乐（Dole）更配合；如果你要的是“品牌力强、包装规范、适合高端水果礼盒”，佳沛（Zespri）更稳，但定制自由度一般更紧。**

不过这两家都不是按“团购定制礼盒”作为主业务来灵活接单的，实际配合度更多取决于：**你的采购量、是否走授权经销商、是否只做外盒定制还是改内包装、是否要印企业LOGO、交付周期**。不能简单说谁一定更配合。

可执行建议：

1. **先明确你要的“定制”是哪一种**
   - 只换外礼盒/加腰封/贴企业标：两家经销商通常都能谈，都乐相对更容易。
   - 改内袋、改果品规格、混装、小批量打样：都乐体系通常更灵活。
   - 用佳沛品牌做深度联名或改包装：审批更严，周期更长，通常需要较大采购量。

2. **询价时直接问这5个问题**
   - 最小起订量是多少？
   - 能否只定制外盒，内包装保留原厂？
   - 能否加企业LOGO/腰封/贺卡？
   - 打样费、打样周期、是否可退？
   - 团购价是否含礼盒、物流、破损补发？

3. **更现实的采购路径**
   - 找**都乐/佳沛的区域授权经销商或水果团购服务商**，不要只找品牌总部。
   - 同时让2—3家经销商按同一需求报价，比较“配合度”比比较品牌更有意义。
   - 如果采购量不大，优先选**都乐+经销商外盒定制**；如果是高端商务送礼、品牌背书优先，选**佳沛标准礼盒+外部腰封/手提袋定制**。

4. **合同里写清楚**
   - 打样确认后大货色差范围；
   - 礼盒承重和冷链/常温运输适配；
   - 破损补发比例和时效；
   - 品牌授权使用范围，避免未经许可印佳沛/都乐商标。

结论：**要定制灵活度，优先问都乐；要品牌调性，优先问佳沛。最终看经销商，不看品牌口号。** 你先确定采购箱数、预算和定制深度，我可以帮你列一份给经销商的需求清单。
