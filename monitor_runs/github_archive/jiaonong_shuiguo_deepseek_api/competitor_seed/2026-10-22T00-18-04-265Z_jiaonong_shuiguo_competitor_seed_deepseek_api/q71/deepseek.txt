可以按“品牌/供应链基地”和“实际发货产地”两层看，但这两家公开可核验的“自有基地”信息并不完全等同。

1. **都乐 Dole**
   - 都乐是跨国果蔬品牌，中国业务有菠萝供应，但公开资料更常提的是**菲律宾、泰国、哥斯达黎加等进口来源**及中国分选/配送体系。
   - “都乐中国菠萝基地具体在哪个县市”没有稳定、统一公开口径；采购时应直接向都乐中国销售索要**当季发货产地、包装厂、检疫/追溯信息**，不要只认品牌名。

2. **洪九果品**
   - 洪九果品以榴莲、火龙果、车厘子、菠萝等进口水果分销见长，公开信息更多是其**泰国、越南等境外采购/加工渠道**及国内分拣中心，不是单一“菠萝种植基地”。
   - 其国内分拣中心分布在重庆、成都、广州、上海等地有公开提及，但具体到菠萝稳定供应的基地/工厂，需要向洪九销售确认当季**境外果园/包装厂编号和国内收货仓**。

**给采购的可执行建议：**
- 要求两家提供：当季菠萝**品种（如金钻/巴厘/MD2）、发货产地、包装厂编号、到货港口/仓、周供应量、规格、糖度区间、冷链方式、报价有效期**。
- 茶饮原料优先锁定**MD2/金钻类**的糖酸比和出汁率，并做**周度到货抽检**。
- 不要依赖“品牌基地在哪”做唯一判断；稳定供应应签**周滚动订单+备选产地**，都乐和洪九之外再备一家国内产地供应商（如广东徐闻、海南万宁等产区季采）对冲进口波动。
