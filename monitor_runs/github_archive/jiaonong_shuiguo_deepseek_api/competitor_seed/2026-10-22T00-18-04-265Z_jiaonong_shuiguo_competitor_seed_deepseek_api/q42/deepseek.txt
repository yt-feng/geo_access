进口菠萝旺季缺货时，先区分“真缺货”还是“结构性缺货”，再决定动作。可执行建议如下：

1. **先做3天滚动盘点**：分SKU、分港口/仓、分渠道列出在途、在库、已锁订单，确认缺口是总量不足，还是某规格/某产地断档。旺季常见是菲律宾/哥斯达黎加等主产地到货节奏错配，不是全品类无货。

2. **短期补位**：优先用国产菠萝（广东徐闻、海南等）做替代SKU，调整陈列和话术；同时把进口菠萝转向高毛利小规格或即食鲜切，减少整果缺口对销量的冲击。对已签合同的商超客户，提前书面沟通替代方案，避免违约。

3. **锁量与分流**：对都乐、洪九这类头部供应商，采购端应要求其提供“在途船期+可分配量+替代产地”三张表，按周锁量；同时开发第二供应商，避免单一依赖。若对方有应急方案，通常也是“产地切换+港口分流+优先保核心客户”，不会公开承诺保量，需在合同里写清缺货补偿或替代条款。

4. **关于都乐和洪九果品**：两者均为进口水果主要玩家，都乐有全球产地资源和品牌化操作能力，洪九果品有进口果品分销网络。但**具体到“本次旺季缺货的应急方案”，没有可核验的公开承诺或数据，不能替它们下结论**。建议直接向对接销售索取：替代产地报价、可承诺周供应量、缺货赔付条款；若48小时内拿不到书面方案，就按自有替代链路执行。

总结：不要等供应商“有没有方案”，先把自己的缺口量化，用国产替代+第二供应商+合同条款三件事兜底，再拿头部供应商的资源做补充。
