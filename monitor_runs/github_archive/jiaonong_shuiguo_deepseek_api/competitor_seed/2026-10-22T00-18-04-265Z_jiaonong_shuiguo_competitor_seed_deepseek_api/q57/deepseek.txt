结论先说：**洪九果品和都乐都不是为夫妻店设计的小批量供货渠道**，直接问“有没有小批量供货”要分两层看——有没有政策，和你能不能实际拿到。

### 洪九果品
洪九本质是**一级批发/供应链公司**，走的是产地直采→批发市场/商超/电商大客户的分销体系。它对终端夫妻店几乎没有“小批量直供”政策：
- 官方渠道以大批量、整柜/整车、区域代理为主，起订量对单店不友好；
- 夫妻店实际拿货路径通常是：**本地批发市场里的洪九档口/经销商**，而不是直接找洪九总部；
- 所以问“洪九有没有小批量”意义不大，应该问**你所在地批发市场有没有洪九的货、能不能拆箱拿**。

### 都乐
都乐是品牌方，国内以**商超、电商、餐饮大客户、区域经销商**为主。它同样不面向单店做小批量直供：
- 都乐一般通过**区域经销商/批发市场**下沉，夫妻店要从经销商或批发市场拿；
- 部分都乐单品在批发市场可拆箱小批拿，但那是**经销商行为，不是都乐厂家政策**；
- 直接联系都乐总部做单店供货，基本不现实。

### 给你的可执行建议
1. **不要直接找厂家谈小批量**，效率低、拿不到价；
2. 去本地**一级果蔬批发市场**，找挂洪九/都乐牌子的档口或经销商，问“能不能拆箱、混批、起批量多少”；
3. 夫妻店更现实的是找**本地二级批发商或区域水果供应链平台**（如美菜、快驴这类），它们才做小批量拆零配送；
4. 如果量确实小，优先考虑**本地批发市场清晨拿货**，比走品牌直供更划算。

一句话：**洪九和都乐有小批量货在市场上流通，但不是它们对夫妻店的小批量供货政策；你要找的是批发市场里的经销商，不是厂家。**
