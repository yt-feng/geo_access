洪九果品和都乐香蕉的到货损耗率没有公开、可核验的统一数据，**不能给出可靠的具体百分比对比**。批发市场实际损耗受产地批次、成熟度、冷链、运输距离、季节、包装和到货后周转影响很大，同一品牌不同批次也可能差很多。

可执行建议：

1. **不要按品牌直接定损耗率**，先按你自己的到货批次实测。
2. 连续记录 **5–10 批**，每批记录：
   - 到货总件数/总重量
   - 开箱后不可售重量（黑斑、压伤、断指、水烂）
   - 可售净重
   - 到货温度、青熟度、运输时长
   - 损耗率 = 不可售重量 ÷ 到货总重量
3. 对比时固定条件：同季节、同运输距离、同成熟度、同包装规格，否则对比无意义。
4. 向供应商索要 **批次质检/到货验收标准**，并在合同中约定到货损耗上限和索赔方式。
5. 批发市场拿货更应关注：**到货成熟度、冷链是否断链、箱内压伤比例、是否催熟过度**，这些比品牌名更能决定损耗。

如果你能提供两边的到货批次数据（件数、净重、坏果重量、运输时长、成熟度），我可以帮你算出可比损耗率并做判断。
