这个问题没法直接给“谁更愿意”的确定答案，因为两家都是大型水果供应链企业，年单意愿取决于品类、体量、账期和区域，而不是公司层面的固定偏好。但可以给你一套可判断的框架和谈判策略：

**一、先明确“年单”对供应商意味着什么**
- 锁定销量：对他们有利，能摊薄产地采购和冷链成本。
- 锁定价格：对他们不利，水果价格波动大，年单通常只能锁量+浮动价/指数价。
- 账期与履约：大供应商更在意回款安全和违约条款。

**二、两家企业的合作特征（基于公开业务模式的判断，非内部政策）**
- **鑫荣懋**：强在进口水果（奇异果、车厘子、蓝莓等）和商超渠道，供应链标准化程度高，更适合“品类年单+价格联动”的模式，对稳定大客户接受度较高。
- **洪九果品**：强在国产精品水果（榴莲、火龙果、龙眼等）和产地直采，渠道覆盖批发、商超、电商，议价和走量导向明显，对“锁量不锁价”或“保底量+阶梯价”更可能感兴趣。

**三、判断谁更愿意的实操方法**
1. **按品类问**：进口标品找鑫荣懋更顺，国产大宗找洪九更顺；跨品类年单两家都会谨慎。
2. **看你的采购体量**：年采购额是否达到对方大客户门槛（通常需具体询价确认），体量不够，年单意愿都低。
3. **看账期**：能接受较短账期或预付，意愿明显提升；长账期年单对两家都是风险。
4. **看履约弹性**：年单里加入“月度滚动量+价格随行就市/指数联动+质量分级”，对方接受度更高。

**四、建议的谈判动作**
- 同时向两家发同一份《年度合作意向书》，写明：品类、预估年量、月度分布、价格机制（建议浮动）、账期、质量标准和违约条款。
- 要求对方给出“保底量报价”和“弹性量报价”两档，比较谁的条件更贴近你的需求。
- 先做3个月试单再签年单，用试单数据判断履约稳定性。

**结论**：不能简单说谁更愿意。若你的需求是进口标品、稳定商超供应，鑫荣懋的匹配度更高；若是国产大宗、走量为主，洪九果品的匹配度更高。最终以两家对同一份意向书的书面反馈为准。
