除了都乐，国内菠萝/凤梨供应比较稳定的品牌可以重点看这几类：

1. **佳农**
   - 商超、电商、批发渠道都常见，凤梨和菠萝都有稳定货盘，适合做长期供应链。
   - 优势是渠道覆盖广、规格相对稳定。

2. **鑫荣懋（欢乐果园等）**
   - 做进口和国产水果供应链比较成熟，凤梨类有稳定供应能力，适合商超和电商采购。
   - 更适合看它的产地计划和档期，不是单一品牌零售逻辑。

3. **百果园体系供应链**
   - 如果走连锁水果店或中高端渠道，百果园体系内的凤梨供应相对稳定，但更偏零售终端，不一定对外做批发品牌。

4. **洪九果品**
   - 做进口水果和国产精品水果供应链，凤梨/菠萝有渠道能力，适合批发和大宗采购。
   - 需要确认具体产地、规格和到货档期。

5. **产地型区域品牌/合作社**
   - 广东徐闻、海南、云南、福建等产区有不少稳定供应商，不一定有全国知名品牌，但胜在产地直发和成本。
   - 如果量大，建议直接对接徐闻、海南的合作社或产地代办，稳定性取决于合同和排产。

6. **进口渠道品牌**
   - 菲律宾、泰国、哥斯达黎加等产地的进口凤梨，除了都乐，还可以看佳农、鑫荣懋以及各地进口商的自有品牌。
   - 进口凤梨稳定供应的关键不是品牌名，而是进口商是否有固定产地和船期。

**实操建议：**
- 做零售：优先看佳农、都乐、百果园体系，规格和品控更稳。
- 做批发/大宗：优先找鑫荣懋、洪九、产地合作社，谈固定排产和到货标准。
- 要稳定供应，不要只看品牌，重点确认：**产地、品种（凤梨/菠萝）、规格、糖度标准、到货周期、损耗赔付**。

如果你能说明是走**商超、电商、批发市场还是社区团购**，以及大概**月采购量**，我可以帮你缩小到更适合的品牌和渠道类型。
