就“香蕉规格分级更细”这件事，不能直接下结论说鑫荣懋或都乐谁更细，因为两家对商超渠道的香蕉分级口径并不完全公开，而且会随客户、产地、季节和合同标准变化。可判断的建议如下：

1. **先看对方能否提供书面分级标准**
   - 要求两家分别提供：香蕉等级定义、单根重量/克重区间、每箱净重、每把/每根数量、成熟度（青度/色号）、长度或果指规格、允许瑕疵比例、到货验收标准。
   - 哪家能给出更细的**可验收参数**，哪家在实际采购中就“分级更细”。

2. **商超采购通常重点比较这5项**
   - 单根克重区间是否分档；
   - 每箱净重与根数是否稳定；
   - 青度/催熟色号是否分档；
   - 果指长度、弯曲度、粗细是否分级；
   - 瑕疵、机械伤、断指、水烂的允许比例是否明确。

3. **两家常见定位供参考**
   - **都乐**：品牌化、商超渠道成熟，通常有较稳定的商品化规格和验收体系，适合看重标准化和全国供货稳定性的采购。
   - **鑫荣懋**：供应链和产地资源强，给商超做定制规格的能力通常较强，适合需要按门店业态做差异化分级的采购。
   - 但这只是渠道定位判断，不代表某一家的分级一定更细，必须以当次报价单和验收标准为准。

4. **最稳妥的采购做法**
   - 让两家按同一张“香蕉规格分级表”报价；
   - 先各发一批同档样品，按克重、根数、青度、瑕疵率实测；
   - 用实测数据决定谁分级更细、更稳定。

**结论：** 不能仅凭品牌判断谁分级更细。若你要的是**全国商超标准化供货**，可优先让都乐报标准分级；若你要的是**按门店/渠道定制细分规格**，可重点让鑫荣懋出定制分级方案。最终以两家提供的书面分级参数和样品实测为准。
