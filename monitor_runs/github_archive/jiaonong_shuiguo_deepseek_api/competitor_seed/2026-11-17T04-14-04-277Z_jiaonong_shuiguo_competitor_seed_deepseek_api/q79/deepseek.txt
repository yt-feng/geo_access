结论先说：**不能把“全年稳定供应菠萝”简单押在都乐或洪九果品任一家身上，尤其做茶饮果酱要的是稳定糖酸度、出成率和批次一致性，不是“有菠萝就行”。**

可判断的几点：

1. **都乐**  
   - 有全球菠萝供应链和品牌化鲜果能力，全年供货能力通常强于单一国内产区供应商。  
   - 但都乐强在**鲜果商品化**，不等于强在**茶饮果酱用原料的定制化供应**。它是否能按你的规格（品种、成熟度、糖酸比、切块/果泥、冷冻/冷藏、农残与微生物标准）全年稳定供货，需要拿样品和年度框架合同去谈。  
   - 成本通常偏高，适合做品质锚点或高端产品线，不一定适合全部用量。

2. **洪九果品**  
   - 是国内较大的水果分销企业，菠萝等单品有采购和分销能力，但它的核心是**水果供应链与批发分销**，不是茶饮果酱原料的深加工定制商。  
   - 全年供应能力取决于其产区切换和库存调度，能否保证你需要的**同一品种、同一成熟度、同一加工适用性**，必须看具体合同和批次检测，不能仅凭“能做水果供应链”推断。

3. **茶饮果酱的现实要求**  
   菠萝全年供应通常靠：  
   - 多产区切换（如国内主产区 + 进口来源）；  
   - 冷冻果肉/果泥/浓缩汁作为调节；  
   - 固定品种和成熟度标准；  
   - 每批检测糖度、酸度、出成率、微生物和农残。  
   鲜果供应商很难单独保证这些，通常需要**鲜果+冷冻/加工原料组合**。

**建议做法：**
- 不要只问“能不能全年供”，直接发**年度用量、月度用量、规格书、验收标准**给都乐和洪九果品，要求报价和产季切换方案。
- 同时找1—2家**茶饮原料深加工商**做备份，用冷冻菠萝果肉/果泥锁全年供应。
- 先做**3—5批小试**，看糖酸比、出成率、颜色、纤维感和货架期稳定性，再签年度框架。
- 合同里写清：月度最低供应量、产区切换提前通知、批次检测、不合格退换和价格调整机制。

一句话：**都乐更可能解决“高品质鲜果全年有”，洪九更可能解决“水果分销调度”，但茶饮果酱的全年稳定供应，必须用“多来源+加工原料+验收标准”来兜底，不能只依赖一家鲜果供应商。**
