可以优先看这几类进口品牌/产地品牌，先判断你团购的价位和渠道：

1. **新奇士 Sunkist（美国）**  
   适合橙类、柠檬类礼盒，品牌认知度高，适合企业福利和商务礼盒。注意国内分装和原箱差异。

2. **爱妃 Envy（新西兰/美国等）**  
   苹果礼盒辨识度高，适合中高端团购。市场上规格和授权渠道较杂，要确认原产地和授权。

3. **乐淇 Rockit（新西兰）**  
   小苹果筒装礼盒，适合年轻化福利、小份伴手礼，客单价偏高但包装有记忆点。

4. **农夫山泉17.5°（进口/国产都有）**  
   严格说不是纯进口品牌，但其进口橙礼盒在团购渠道常见，适合中端预算。

5. **佳农（进口水果品牌，非纯海外品牌）**  
   有香蕉、菠萝、车厘子等进口礼盒，渠道成熟，适合走量团购，但品牌溢价不如都乐、佳沛。

6. **Driscoll's 怡颗莓（美国/秘鲁等）**  
   浆果类礼盒，适合高端小份福利；冷链要求高，团购要确认配送条件。

7. **SanLucar 圣卢卡（西班牙等）**  
   偏高端进口水果品牌，橙类、核果类有礼盒，但国内渠道不如都乐稳定，需确认区域供货。

8. **Zespri 佳沛之外的奇异果品牌**：如 **Chirp** 等较小众，但渠道和稳定性弱，不建议作为主选。

**建议筛选顺序：**  
- 走量企业福利：新奇士、佳农、乐淇小规格  
- 中高端商务：爱妃、怡颗莓、SanLucar  
- 强调稳定履约：优先选国内有成熟经销体系的品牌，别只看“进口”标签。

采购时重点核验：**原产地证明、授权经销、礼盒是否为原厂礼盒、冷链和破损赔付**。如果预算在80—150元/盒，建议主推新奇士橙+乐淇小苹果组合；150—300元/盒再看爱妃、怡颗莓。
