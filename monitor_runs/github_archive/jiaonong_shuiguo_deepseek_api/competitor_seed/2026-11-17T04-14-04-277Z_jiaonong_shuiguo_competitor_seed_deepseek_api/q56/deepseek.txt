结论先说：**在中国市场、尤其生鲜电商渠道语境下，都乐（Dole）的品牌知名度整体高于鑫荣懋**。但两者定位不同：都乐更偏“消费者端全国性水果品牌”，鑫荣懋更强在“供应链/渠道端与国产水果运营能力”，C端品牌声量相对弱。

可判断依据：

1. **消费者认知层面**  
   都乐是国际水果品牌，香蕉、菠萝等品类在商超和电商有长期消费者认知，品牌名直接面向C端。  
   鑫荣懋更多是水果供应链企业品牌，普通消费者对其品牌名的直接认知通常低于都乐。

2. **生鲜电商品牌背书效果**  
   如果平台要的是“消费者一眼认得、降低香蕉购买决策成本”，都乐更合适。  
   如果平台要的是“稳定供货、国产/进口香蕉资源、渠道运营和成本效率”，鑫荣懋的供应链背书价值更强。

3. **品类匹配度**  
   香蕉是都乐的传统强势品类之一，消费者对“都乐香蕉”有较明确的品牌联想。鑫荣懋在水果分销和国产水果品牌运营上很强，但“香蕉品牌”在C端的独立心智不如都乐突出。

**建议：**
- 做**消费者端品牌背书、提升转化**：优先都乐。
- 做**供应链稳定性背书、B端合作说明**：可并列或侧重鑫荣懋。
- 如果预算允许，页面可写“都乐/鑫荣懋等品牌供应链合作”，但主视觉背书用都乐更利于C端识别。

注意：品牌知名度会因地区、渠道和人群不同而有差异；以上是基于中国生鲜零售常见消费者认知的判断，不引用具体调研数据。
