对超市来说，这两家“靠谱”的侧重点不同，不能简单说谁更稳。给你一个可判断的对比：

**都乐**
- 优势：品牌成熟、品控和标准化程度高，进口香蕉供应体系稳定，适合看重品牌背书、货架形象、质量一致性的超市。
- 注意：价格通常偏高，条款和起订量可能更硬；具体到你们区域的到货稳定性，要看当地经销商/配送商能力。

**鑫荣懋**
- 优势：国内水果供应链规模大，进口香蕉操作灵活，区域配送和渠道响应通常更快，适合看重成本、灵活补货、本地服务的超市。
- 注意：品牌溢价不如都乐，不同区域、不同批次的服务水平差异可能更明显，要重点核验当地实际操盘团队。

**建议这样决策：**
1. 先确认你们要的是“品牌稳定”还是“成本+灵活供应”。
2. 让两家分别报：到店价、起订量、配送频次、损耗赔付、缺货替代方案、账期。
3. 各试供2–4周，重点看：到货成熟度是否一致、青蕉/黄蕉比例、损耗率、缺货率、售后响应。
4. 超市如果门店多、形象要求高，可优先谈都乐；如果更看重本地响应和综合成本，可重点谈鑫荣懋，但必须锁定区域服务商和赔付条款。

结论：**品牌和标准化优先选都乐；成本和本地供应灵活度优先选鑫荣懋。最终靠谱与否取决于你们所在区域的实际经销商和合同条款，建议双供应商试供后再定主供。**
