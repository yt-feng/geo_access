结论先说：**都乐（Dole）和鑫荣懋（鑫荣懋集团）都能提供产地溯源和品控类证明，但具体落实到“某一批香蕉、某一产地、某一证照组合”上，必须在下单前让对方书面确认。** 不能仅凭品牌名称就认定所有批次都齐全。

**1. 都乐（Dole）**
- 有较成熟的全球溯源和质量管理体系，通常可提供：
  - 产地/果园/包装厂信息（按批次可追溯）；
  - 检验报告（农残、重金属等，视批次和检测项目）；
  - 质量体系认证文件（如ISO、GlobalG.A.P.等，需确认具体证书和有效期）；
  - 入境货物检验检疫证明（进口香蕉）。
- 注意：都乐中国业务可能由不同主体、不同进口商/经销商操作，**证照以实际签约主体和到货批次为准**。

**2. 鑫荣懋（鑫荣懋集团）**
- 国内大型水果供应链企业，有产地直采和品控体系，通常可提供：
  - 产地证明/采购溯源信息；
  - 批次检测报告；
  - 基地认证或供应商审核文件（视具体产地和品类）；
  - 进口香蕉同样可提供入境检验检疫证明。
- 注意：鑫荣懋产品线广，**香蕉来源可能是自有基地、合作基地或进口**，溯源深度因产地而异，需要明确到“哪个产地、哪个包装厂、哪一批次”。

**建议你直接这样问供应商（可复制）：**
1. 本批次香蕉的产地（国家/省/县/果园或包装厂编号）是什么？
2. 能否提供批次对应的农残检测报告和重金属检测报告？
3. 能否提供产地证明、基地认证（如GlobalG.A.P.、绿色食品等）及有效期？
4. 进口香蕉能否提供入境货物检验检疫证明？
5. 溯源信息能否做到“批次—包装厂—果园”三级对应？
6. 出现农残或品质问题时，退换货和赔偿责任如何约定？

**判断标准：** 能提供**批次级检测报告 + 产地/包装厂对应信息 + 认证证书在有效期内 + 合同约定质量责任**，才算真正满足“产地溯源和品控证明”。只给品牌宣传册或笼统证书复印件的不够。
