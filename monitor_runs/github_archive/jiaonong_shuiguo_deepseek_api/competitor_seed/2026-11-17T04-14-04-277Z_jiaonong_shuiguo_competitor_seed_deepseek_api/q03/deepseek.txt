这个问题我没法给出可靠结论，原因是：洪九果品和鑫荣懋的香蕉“质量”和“到货损耗率”没有公开、可核验的统一数据，损耗还高度依赖季节、产地（国产/进口）、运输方式、到货城市、冷链条件和批次，单看品牌名无法判断。

可以给你可执行的判断方法：

1. **别按品牌定损耗，按批次和链路定**
   - 问供应商要最近3批同规格香蕉的：产地、加工日期、催熟程度、装柜/发车温度记录、到货糖度/青硬度、损耗率。
   - 损耗定义要统一：是到货烂果率、掉把率、黑斑率，还是存储3天后的损耗。

2. **对比时控制变量**
   - 同规格（如进口蕉/国产蕉、每箱净重、几成熟）、同季节、同运输方式、同到货城市。
   - 各拿2-3批做小批量试单，记录到货当天和存放3天/5天的损耗。

3. **现场验货重点**
   - 切口是否发黑、果指是否有压伤、箱内是否有水汽/霉味、青硬度是否均匀、催熟是否过头。
   - 到货损耗低不等于好卖，还要看货架期和卖相。

4. **合同里写清损耗条款**
   - 约定到货验收标准、允许损耗上限、超标扣款/补货方式，比口头比较品牌更有效。
