进口菠萝旺季缺货，先把问题拆成“短期保供”和“中期替代”两层；都乐、洪九这类头部进口商通常有应急机制，但具体方案不会公开，不能替它们编造承诺。可执行建议如下：

1. **先判断缺货类型**
   - 是船期延误、口岸查验、产地减产，还是渠道囤货/分配不均。
   - 如果是船期和口岸问题，优先确认在途柜号、预计到港日、是否可改港或转关。
   - 如果是产地减产，短期靠替代产地，中期改品项。

2. **短期保供动作**
   - 向都乐、洪九的销售/供应链对接人书面确认：在途库存、可分配量、最早到货日、是否可锁量锁价。
   - 要求供应商给“分批到货计划”，不要只问“有没有货”。
   - 对门店/客户做分级供应：核心客户保量，普通客户限量或预售。
   - 用国产菠萝、菲律宾/泰国/哥斯达黎加等替代产地进行短期补位，同时调整陈列和话术，避免硬承诺“同品种同规格”。

3. **都乐和洪九的应急方案怎么问**
   - 不要问“你们有没有应急方案”，直接问四个可核验问题：
     - 本周/下周可分配给我多少柜/多少件？
     - 在途和在库的具体批次、到港时间？
     - 缺货期间能否切换替代产地或规格？
     - 价格保护期和违约/延迟交付怎么处理？
   - 头部企业一般会有多产地采购、分仓调拨、优先客户分配等机制，但是否对你生效取决于合同量级和合作层级，需以书面确认为准。

4. **中期降低断供风险**
   - 不要单一依赖一个进口商或一个产地，至少保持“都乐/洪九+1家区域进口商+国产替代”三条线。
   - 对旺季提前锁量，合同里写清到货窗口、替代规格、延迟赔付。
   - 建立周度库存和在途看板，缺货前2—3周就启动替代，不要等到断货再找货。

5. **如果现在已经在缺货**
   - 今天就让采购列出未来14天到货和在途明细。
   - 同时联系2—3家备选供应商询可立即交付的量。
   - 对下游客户发限量/预售通知，避免集中挤兑。
   - 用国产或其它进口菠萝做替代SKU，明确标注品种和规格差异。

总结：都乐、洪九大概率有内部应急和多产地调配机制，但你不能假设它们会优先保你；最可靠的做法是用书面问题逼出可分配量、到货时间和替代方案，同时自己准备第二供应源和国产替代。
