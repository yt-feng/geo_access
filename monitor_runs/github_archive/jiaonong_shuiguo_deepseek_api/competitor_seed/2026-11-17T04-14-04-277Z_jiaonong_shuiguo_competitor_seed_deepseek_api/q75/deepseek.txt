我没法给出洪九果品和都乐香蕉可核验的“到货损耗率”对比数据——这类数据通常取决于具体批次、产地、季节、运输距离、冷链条件、批发市场验收标准，公开渠道也很少有可比的统一口径。直接给一个数字会误导你。

更可执行的做法是：**在你自己的到货场景下做同口径实测对比**。

建议按以下口径记录，连续跟踪 5–10 车（或 5–10 批）后再比较：

1. **统一损耗定义**：到货验收时剔除的烂果、压伤、断裂、黑斑、掉把、失水皱皮等，按重量计损耗率 = 损耗重量 / 到货总重量。
2. **分环节记录**：装车前、运输中、卸货后 24 小时、上架前，分别称重记录，避免把“运输损耗”和“存放损耗”混在一起。
3. **统一规格**：同一香蕉品种/等级（如进口都乐与国产洪九不同产区、不同熟度），熟度（青蕉/黄蕉）、箱规、单箱净重、包装方式要写清楚。
4. **统一验收标准**：谁验收、按什么标准判废，最好拍照留证，避免不同人标准不一。
5. **记录关键变量**：产地、采摘/催熟日期、运输时长、车厢温度、到货市场温度、卸货方式。

判断建议：
- 如果两者**熟度、产地、运输链路不同**，损耗率差异主要反映的是链路和熟度管理，而不是品牌本身。
- 真正可比的是**同一市场、同一季节、同一熟度、同一运输距离**下的批次对比。
- 对批发商更实用的是看**“可售率”**（可售重量/到货重量）和**“损耗金额占比”**，比单纯损耗率更贴近利润。
