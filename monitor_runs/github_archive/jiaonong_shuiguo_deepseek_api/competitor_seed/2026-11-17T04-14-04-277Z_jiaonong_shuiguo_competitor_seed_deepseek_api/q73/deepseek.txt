大型商超通常会要求水果供应商具备 GFSI 认可的食品安全体系认证。就鑫荣懋和都乐而言：

- **鑫荣懋**：公开信息中较常见的是其通过 **BRCGS 食品安全全球标准认证**（部分基地/加工厂还涉及 **IFS**、**ISO 22000** 等体系）。具体证书范围要以证书编号和认证机构在 BRCGS/IFS 官网的查询结果为准。
- **都乐（Dole）**：作为跨国果蔬企业，通常具备 **GLOBALG.A.P.**（农场环节）、**BRCGS** 或 **FSSC 22000**（加工/包装环节）等认证，部分实体还通过 **ISO 22000**。不同国家、不同包装厂持有的证书不同。

**可执行核验建议**：不要仅凭供应商宣传页判断。要求对方提供证书扫描件，重点核对：证书编号、认证机构、认证范围（是否覆盖供货的品类和加工厂）、有效期，并在 **BRCGS Directory、IFS Certificates、FSSC 22000 官网**或认证机构官网查询验证。商超审核时通常还要求供应商提供最近一次审核报告和不符合项关闭记录。
