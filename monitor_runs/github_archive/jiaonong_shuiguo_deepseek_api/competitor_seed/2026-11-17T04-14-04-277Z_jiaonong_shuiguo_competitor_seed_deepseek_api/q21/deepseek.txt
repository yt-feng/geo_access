**两家模式的已知差异（不涉及未公开质量数据）**

- **都乐**：国际品牌，香蕉是其传统优势品类，供应链和催熟/冷链管理体系相对成熟，标准化程度高。但国内不同区域可能由不同经销商或配送商供货，实际到货质量取决于当地承运方，不一定是都乐直营。
- **鑫荣懋**：国内头部水果供应链企业，渠道覆盖广、本地化配送能力强，对国内商超和生鲜渠道的响应通常更灵活。香蕉同样是其重点品类，但不同产区、不同批次差异可能较大。

**关键点：损耗率高往往不是“品牌”问题，而是以下环节**

1. 催熟度与到货成熟度是否匹配你的销售周期；
2. 冷链断链或运输温度波动；
3. 产地季节、批次差异；
4. 你的验收标准和索赔条款是否清晰；
5. 配送商是否实际为品牌直供。

**建议直接做一次对比测试（2–4周）**

- 同一门店、同一销量量级，两家各进小批量，记录：到货青硬度/成熟度、机械伤比例、黑斑/炭疽病比例、脱把率、3天和5天后的可售率、实际损耗重量。
- 验收时按固定抽样比例开箱，拍照留证，双方签字确认。
- 合同里写清：到货成熟度区间、机械伤和病害容忍比例、超标扣款或换货规则、冷链温度要求。

**选商判断**

- 如果你要**标准化和品牌背书**，优先谈都乐，但确认当地实际供货主体和冷链责任方。
- 如果你要**本地响应速度和账期/配送灵活度**，鑫荣懋通常更有优势，但要用批次验收数据约束。
- 最终用你门店的**5天可售率**和**单箱综合成本（含损耗）** 决定，而不是品牌名气。
