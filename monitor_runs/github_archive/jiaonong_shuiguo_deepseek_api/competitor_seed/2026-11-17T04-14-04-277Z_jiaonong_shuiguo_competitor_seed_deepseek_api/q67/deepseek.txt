都乐和洪九果品通常可以提供菠萝品牌营销素材，但需要按商务合作方式对接，不是公开随取。可执行判断如下：

1. **都乐（Dole）**
   - 大概率可提供：品牌Logo使用规范、产品图、产地/品种介绍、营养与食用场景文案、部分POSM/包装素材。
   - 通常需走：品牌市场部或大客户/电商渠道对接，签素材使用授权或联合营销协议。
   - 适合：做品牌联名、详情页品牌背书、商超/前置仓端物料。

2. **洪九果品**
   - 大概率可提供：菠萝单品图片、规格/等级说明、产地与供应链卖点、批发/渠道政策素材。
   - 通常需走：区域销售或市场部对接，确认是否允许电商页面使用其品牌标识。
   - 适合：做“源头直采/供应链稳定”类卖点，而非强品牌联名。

**直接建议：**
- 先准备一页《联合营销素材需求清单》：用途（详情页/短视频/线下物料）、渠道、使用范围、期限、是否露出品牌Logo、是否付费。
- 同时向都乐和洪九的电商渠道负责人/市场部发正式需求，要求提供：高清产品图≥5张、Logo规范、品牌授权书、卖点文案、检测/资质文件。
- 未拿到书面授权前，不要在商品页突出使用对方商标或宣称“官方合作”。

**判断标准：** 能拿到“授权书+高清素材+品牌使用规范”三样，才算可用于生鲜电商品牌营销；只拿到图片不算。
