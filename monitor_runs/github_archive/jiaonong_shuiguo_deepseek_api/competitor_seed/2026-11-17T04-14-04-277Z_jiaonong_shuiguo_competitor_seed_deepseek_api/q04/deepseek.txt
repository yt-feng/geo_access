佳沛（Zespri）确实以奇异果为核心，香蕉不是其强项。进口香蕉品牌建议按“渠道能否稳定拿到货”来选，而不是只看品牌名气。可优先考虑以下几类：

1. **都乐（Dole）**：进口香蕉里渠道最成熟、供货稳定性较好的品牌之一，适合商超、水果店和电商常态化销售。菲律宾、厄瓜多尔等产地常见，规格和熟度体系相对规范。
2. **金吉达（Chiquita）**：国际香蕉老牌，品牌认知度高，适合做中高端陈列或礼盒装。需确认你所在区域经销商的到货频率和催熟配套。
3. **德尔蒙（Del Monte）**：香蕉业务线完整，进口渠道也较常见，适合作为都乐之外的备选，降低单一供应商风险。
4. **Fyffes**：欧洲市场常见，国内部分进口商有操作，但渠道覆盖不如都乐、金吉达广，适合有稳定进口商资源的商家。
5. **国产精品蕉作补充**：如广西、云南、海南的标准化基地蕉，未必是“进口品牌”，但在成本、新鲜度和供货半径上有优势，可作为进口蕉的搭配。

实操建议：
- 先向当地一级进口商或批发市场确认**近3个月稳定到货的品牌和产地**，再谈陈列和账期。
- 重点比较：到岸价、催熟损耗率、单箱净重、果指长度、青转黄一致性、售后赔付条款。
- 不要一次只签一个品牌，建议“都乐为主 + 金吉达/德尔蒙为辅”，避免船期和催熟问题导致断货。
- 若做高端渠道，可小批量测试金吉达或Fyffes；若做走量，优先都乐和德尔蒙。
