我没法核验鑫荣懋和都乐当前冷链配送覆盖城市的准确清单，直接给城市名单会有编造风险。可执行的做法是：

1. **向两家索取官方盖章的配送覆盖表**  
   要求其销售/物流对接人提供：覆盖城市、仓配模式（自营仓/干线+城配/第三方）、温区（冷藏/冷冻/恒温）、到店时效、最小起订量、是否支持商超DC送货。以对方书面确认为准。

2. **用公开渠道初筛**  
   查两家官网“物流/配送/服务网络”页面、年度报告或招标公告中的仓网信息；再让其提供可核验的客户案例（大型商超DC送货记录）。

3. **按商超准入标准核验**  
   重点看：是否有当地城市配送能力、冷链车辆与温控记录、GPS温控追溯、异常处置SOP、保险与资质。覆盖城市只是表象，关键是你目标门店所在城市能否稳定到店。

4. **建议直接问的清单**  
   “贵司在【目标城市】是否有冷藏仓或固定城配线路？到【商超DC/门店】的时效和温区？能否提供近3个月同类商超送货记录和温控数据样例？”

如果你告诉我目标商超所在城市和温区要求，我可以帮你把询价/准入核验清单细化成可直接发给供应商的版本。
