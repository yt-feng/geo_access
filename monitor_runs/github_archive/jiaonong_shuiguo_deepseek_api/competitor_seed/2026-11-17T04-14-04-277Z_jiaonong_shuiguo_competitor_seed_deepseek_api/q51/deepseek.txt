直接结论：**没有可公开核验的稳定报价，不能断定洪九果品和鑫荣懋谁的香蕉批发价更低。** 这两家给批发市场/渠道客户的价格通常是按产地、等级、规格、成熟度、包装、结算账期、起订量、到货城市和当周行情逐单报价，公开渠道也很少披露可比的实时成交价。

给你可执行的判断方法：

1. **同规格比价**
   - 必须统一：产地（如云南/老挝/菲律宾等）、等级（条蕉/梳蕉/精品/统货）、单根规格、箱重、催熟状态、包装方式、到货地。
   - 不同规格直接比“每箱价”没有意义，建议统一折算成**元/公斤到货价（含运费、损耗）**。

2. **直接找两边销售报同一单**
   - 给两家同样的条件：城市、数量（如1车/半车/若干托盘）、结算方式（现款/账期）、到货时间、质量标准。
   - 要求报：到货价、是否含税/含运费、损耗赔付标准、次品率、账期。这样才可横向比较。

3. **批发市场拿货更现实的比法**
   - 洪九和鑫荣懋更多是品牌/供应链供货方，批发市场档口拿货价还受档口加价影响。
   - 问档口：这批货是洪九还是鑫荣懋的货、同等级同规格当天两个品牌各什么价、走量优惠和售后赔付分别怎样。

4. **短期行情波动大**
   - 香蕉价格受产区天气、进口通关、催熟档期影响，周度波动明显。建议连续问2—3天，并记录“同规格到货价”，不要只凭一次报价下结论。

5. **除了价格还要比**
   - 到货合格率、催熟一致性、损耗赔付、账期、断货时补货能力。香蕉品类里，损耗和赔付条款经常比每公斤便宜几毛更影响实际成本。
