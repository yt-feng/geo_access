可以，但先把品牌口径说清：进口苹果在中国市场有“全球果蔬品牌”和“国内进口商/渠道品牌”两类，不能只看名字。

除了都乐、鑫荣懋，比较常见且相对靠谱的可以按这几类看：

1. **全球果蔬品牌**
   - **SanLucar 圣卢卡**：欧洲果蔬品牌，苹果有进口线，品牌化程度较高。
   - **Fyffes**：老牌果蔬商，以香蕉知名，也有苹果等品类，需看具体到货批次。
   - **Del Monte 德尔蒙**：全球果蔬品牌，苹果不是核心单品，但渠道正规。
   - **Frusan / Unifrutti 等欧洲果蔬商**：在进口苹果中常见，偏供应链品牌，零售端辨识度不如都乐。

2. **国内进口水果运营/渠道品牌**
   - **佳沃 Joyvio**：有进口水果业务，品牌和品控体系相对成熟。
   - **百果园**：偏零售渠道品牌，进口苹果选品较稳，但本质是渠道背书。
   - **洪九果品**：进口水果供应链规模大，苹果有涉及，偏B端和渠道。
   - **鲜丰水果**：渠道品牌，进口苹果可作为比价参考。

3. **产地/协会品牌**
   - **新西兰苹果**：常见 **Mr Apple、Rockit 乐淇、Jazz、Envy 爱妃** 等，严格说是品种/产地品牌，不是综合果蔬品牌，但靠谱度通常看产地和品种更直接。
   - **美国苹果**：如 **Stemilt、Chelan Fresh、Rainier Fruit** 等，偏产地供应商品牌。
   - **智利/南非苹果**：多为产地供应商，零售端品牌弱，重点看进口商和批次。

**实操建议：**
- 做品牌对比时，建议分两栏：**“品牌方”** 和 **“中国进口商/经销商”**。进口苹果的稳定性很大程度取决于后者。
- 优先选有稳定产地直采、冷链记录、检疫证和批次追溯的供应商。
- 如果用于零售选品，建议对比：都乐、鑫荣懋、SanLucar、佳沃，再加一个产地品种品牌如 Mr Apple/Rockit/Envy 做差异。
- 不要只看“进口品牌名”，要核对：原产国、品种、果园/包装厂注册号、入境货物检验检疫证明、到港批次。
