可以要求提供，但**不能默认两家一定都能随货提供**，需要按供应商和批次确认。可执行判断如下：

1. **都乐（Dole）**
   - 通常有较完善的质量管理体系，可向对接销售/客服申请**该批次菠萝的农残检测报告**。
   - 常见形式：第三方检测报告、企业自检报告、基地/工厂质量控制文件。
   - 注意：报告必须对应**具体品种、产地、批次/生产日期**，不能只要一份通用报告。

2. **鑫荣懋**
   - 作为大型水果供应链企业，通常也可提供或协调提供**批次农残检测报告/合格证明**。
   - 需确认是**供应商自检**还是**第三方CMA/CNAS检测**；茶饮店若用于验厂/合规，建议优先要第三方报告。

3. **采购时直接这样问**
   - “请提供本批次菠萝的农残检测报告，报告编号、检测机构、检测项目、检测日期、对应批次号请一并提供。”
   - “是否支持到货随批提供？如不能，最快几个工作日可补？”
   - “检测项目是否覆盖常用农残指标？是否可由你们承担送检费用？”
   - “若报告不是本批次，能否出具批次合格承诺或补检？”

4. **合同/订单建议写明**
   - 每批随货提供农残检测报告或合格证明；
   - 报告须与批次对应；
   - 抽检不合格的退换货及违约责任；
   - 茶饮店有权不定期送第三方复检。

结论：**都乐和鑫荣懋一般都有能力提供，但是否能按你的批次、时间、报告类型提供，必须让销售书面确认。** 采购前不要只听“能提供”，要拿到**报告样本和批次对应承诺**再下单。
