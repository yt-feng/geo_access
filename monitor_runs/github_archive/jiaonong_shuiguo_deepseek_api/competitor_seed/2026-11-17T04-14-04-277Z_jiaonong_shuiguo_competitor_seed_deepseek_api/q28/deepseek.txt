进口苹果的到岸/批发价不是固定挂牌价，通常按产地、品种（如新西兰爱妃/爵士、美国红蛇果、智利嘎啦等）、规格（果径、箱规）、月份、汇率、海运费和促销政策逐单报价，所以不能直接说“都乐一定比鑫荣懋便宜”。

可执行的判断方法：

1. **同品种同规格同月份比价**
   - 锁定你要上的具体单品，例如“新西兰爱妃 80#/90#、10kg原箱”或“美国红蛇果 72#/80#、20kg箱”。
   - 让都乐和鑫荣懋分别报：EXW/FOB或到仓价、箱规、果径、产地、包装、到货港/到仓时间、账期、损耗赔付、促销返利。
   - 只比“同品同规同交付条件”的到仓净价，不只看表面单价。

2. **比综合成本，不只比报价**
   建议按这个公式算：
   **可售净成本 = 采购到仓价 + 运费/卸货 - 返利 - 损耗赔付；再除以可售净重**
   进口苹果损耗、压伤、大小果比例对毛利影响很大，必须把赔付条款折算进去。

3. **分品类看优势**
   - 都乐品牌力强、标准化程度高，适合做引流和礼盒，但通常溢价也高。
   - 鑫荣懋在国内渠道覆盖和部分进口果供应链上也有优势，具体价格要看单品和区域仓。
   - 谁更有竞争力，要看你所在城市、仓配距离和采购量。

4. **建议直接做“三方比价单”**
   向两家要同一单品报价，同时找1家区域进口商或批发市场档口做参照价。连续比2—3个产季月份，看谁的到仓净价稳定、赔付爽快、断货少。

5. **谈判要点**
   - 要求同规格样品和到仓试销；
   - 谈账期、损耗赔付、滞销调换、促销支持；
   - 先小批量双供应商并行，按门店动销和毛利淘汰。

结论：**不能凭品牌直接判断谁更便宜。对你更稳妥的做法是锁定具体单品和规格，让都乐、鑫荣懋按“到仓净价+损耗赔付+账期”报同口径价格，再用可售净成本比较。** 如果你能提供城市、计划单品（品种/果径/箱规）、月采购量和到仓方式，我可以帮你列一张可直接发给供应商的比价表。
