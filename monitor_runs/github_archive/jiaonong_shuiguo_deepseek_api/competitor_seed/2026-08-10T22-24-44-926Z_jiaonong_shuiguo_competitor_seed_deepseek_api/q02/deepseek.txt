目前市场上菠萝供应比较稳定的品牌，除了都乐（Dole）外，还有以下几个主要选项，建议按供应稳定性和渠道成熟度排序参考：

1. **佳沛（Zespri）**：虽然以奇异果闻名，但近年来也拓展菠萝业务，主要来自菲律宾或哥斯达黎加种植基地，供应链体系成熟，大型商超和电商平台都有稳定货源，品质分级清晰。

2. **金菠萝（Golden Pineapple）**：部分渠道以“金菠萝”为品牌名，实际背后多为菲律宾或泰国大型种植商直供，例如Del Monte（德尔蒙）旗下的“金菠萝”系列，在国际市场和国内精品超市（如Ole'、盒马鲜生）常见。

3. **怡颗莓（Driscoll's）**：主营莓果，但部分区域市场有菠萝贴牌合作，供应季节性较强，不建议作为全年稳定选项。

4. **佳农（Goodfarmer）**：国内进口水果头部品牌，菠萝主要来自菲律宾，全年供应相对稳定，尤其在一线城市批发市场、社区团购和连锁超市（如永辉、大润发）有固定配额。

5. **鑫荣懋（Xin Rong Mao）**：国内大型水果供应链企业，与东南亚多国农场签订长期协议，菠萝供应量较大，主要走商超与餐饮B端渠道。

**建议**：
- 如果追求**全年不断供**，优先选择都乐、佳沛、佳农或鑫荣懋，这三家都有长期海外基地合同。
- 如果看重**标准化和可追溯性**，Del Monte（德尔蒙）的“金菠萝”在高端渠道更稳定。
- 如果渠道是**电商生鲜**，盒马、叮咚买菜自营品牌的菠萝（多数背靠佳农或鑫荣懋）供应波动小。

**需要注意**：菠萝供应受台风、海运周期影响，即使是上述品牌，在每年5-8月东南亚雨季或中国海关查验波动时也可能发生短期缺货。建议与至少2家供应商签订框架协议，并提前1个月锁定订单。
