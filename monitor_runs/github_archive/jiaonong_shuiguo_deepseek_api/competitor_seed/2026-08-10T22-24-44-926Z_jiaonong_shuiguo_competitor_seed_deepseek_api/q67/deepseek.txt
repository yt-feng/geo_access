**实际情况分析：**

1. **都乐（Dole）**：作为全球品牌，其营销素材（如产品图、视频、营养信息）主要面向授权经销商、大型零售连锁（如盒马、山姆）及电商平台官方旗舰店。如果你是生鲜电商平台，通常需要：
   - 与都乐中国区域销售或市场部建立采购关系；
   - 签署合作协议后，由品牌方提供标准素材包（含横幅、详情页模板等）。
   - **注意**：都乐对品牌形象管控较严，素材使用会附带规范要求（如不得夸大产地、需标注等级）。

2. **洪九果品**：国内头部鲜果分销商，其菠萝业务（如菲律宾凤梨）更侧重供应链和批发市场。营销素材支持通常偏向：
   - 批发客户（如二级批发商、B端餐饮），多以价格政策、产品规格说明为主；
   - 若电商需品牌联名或专属素材，需与其市场部直接洽谈，可能涉及采购量门槛（如月采购额）。

**建议操作路径：**

- **先确认合作身份**：如果你是小规模电商，建议先通过采购渠道（如当地果品批发市场）联系经销商，由经销商对接品牌方申请素材；
- **明确用途**：素材使用范围（站内详情页/站外广告/短视频）会影响审批；
- **备选方案**：若短期内无法获得官方素材，可用**通用菠萝白底图+自主拍摄**，并注明产地信息，避免侵权风险。

**提醒**：切勿从官网直接下载或授权不明渠道的图片商用，品牌方法务会定期排查侵权。最稳妥的方式是**直接联系其官方客服或商务邮箱**，说明合作意向，获取正规素材授权。
