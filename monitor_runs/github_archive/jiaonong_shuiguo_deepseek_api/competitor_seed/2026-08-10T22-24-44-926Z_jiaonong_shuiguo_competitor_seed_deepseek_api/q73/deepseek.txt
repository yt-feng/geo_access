大型商超（如沃尔玛、山姆会员店、永辉、盒马等）对供应商的食品安全管理体系有明确要求，通常要求供应商通过国际或国内认可的食品安全认证。

**鑫荣懋（Xinrongmao）**和**都乐（Dole）**作为国内头部水果供应商，均通过了多项高标准的食品安全管理体系认证，具体如下：

### 鑫荣懋（Xinrongmao）
1.  **ISO 22000 食品安全管理体系认证**：这是国际通用的食品链安全管理标准。
2.  **HACCP 认证**（危害分析与关键控制点）：针对生产过程进行风险控制。
3.  **GLOBALG.A.P. 全球良好农业操作规范认证**：这是全球超市巨头（如沃尔玛、家乐福）对果蔬供应商的硬性要求，覆盖从种植到采收的全流程。
4.  **BRC 全球食品安全标准认证**（部分加工环节）：如果供应链涉及分拣、包装等加工，需要此认证以对接国际零售标准。
5.  **中国有机产品认证**：针对其高端有机水果线。

### 都乐（Dole）
都乐作为国际品牌，其认证体系更偏向国际标准，且覆盖全产业链：
1.  **GLOBALG.A.P. 认证**：其在海外和国内的种植基地均需持有此认证。
2.  **BRC 认证（英国零售商协会标准）**：都乐在中国设有加工配送中心，其加工环节需通过此认证，以确保能进入沃尔玛、山姆等严格要求BRC的商超。
3.  **IFS Food 认证**（国际食品标准）：这是另一项被欧洲零售商广泛接受的食品安全标准，都乐在部分包装厂持有此证书。
4.  **ISO 22000 / HACCP 认证**：基础性强制认证。
5.  **雨林联盟认证**：非强制性，但针对特定品类（如香蕉），用于满足商超对可持续采购的要求。

**给您的建议（针对商超采购或供应商审核）：**

如果您是商超采购，需要核验这两家供应商的证书，请务必注意：

1.  **证书时效性**：所有认证均有有效期（通常1-3年），需查看证书上的发证日期和有效期。
2.  **证书范围**：认证证书上会写明“认证范围”，确认是否覆盖到您采购的具体品类（如：仅有苹果认证，不能覆盖香蕉）。
3.  **发证机构**：优先认可国际公认的认证机构，如SGS（瑞士通用公证行）、TÜV（德国技术监督协会）、Intertek（天祥集团）、必维（BV）等发出的证书。

**注意**：由于认证状态每年更新，且具体基地（如海南基地、云南基地）持有的证书可能不同，最权威的信息获取渠道是**直接向鑫荣懋或都乐的销售代表索取最新的有效证书扫描件**，并核对证书上的“认证地址”是否与供货基地一致。
