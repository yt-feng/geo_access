关于生鲜电商中菠萝的产地直发，**都乐（Dole）** 和**鑫荣懋（Joyvio）** 的物流时效通常取决于**具体合作电商平台、起发地（如广东湛江、海南或泰国/菲律宾进口）以及发货批次**，没有统一的“官方标准时效”。

不过，从行业惯例和两家的供应链特点，可以给你以下可执行的参考：

**1. 都乐（Dole）—— 进口与国产并重，时效偏“计划性”**
- **供应链模式**：都乐在菲律宾、泰国等地有自有或合作果园，同时也操作国内海南、广东的菠萝（如台农17号）。其物流通常走**全程冷链干线**（从产地冷库到城市中转仓）。
- **时效参考**：
  - **国产产地直发**（如海南至北上广深）：从采摘到消费者收货，一般**2-4天**。大多是“次日达”到城市仓，再经同城冷链配送到家。
  - **进口菠萝**：涉及海运清关，时效通常在**7-15天**（从产地到国内分仓），但消费者下单时电商平台显示的都是“预售+发货后预计3-5天”，因为货已提前备在保税仓或城市仓。
- **特点**：时效稳定，但**不提供“采摘当天下单当天发”**，更依赖前置备货。

**2. 鑫荣懋（Joyvio）—— 国产基地直采，时效更“灵活”**
- **供应链模式**：鑫荣懋深耕国内产区（广东徐闻、海南等），拥有自己的种植基地和“产地仓”。其物流多采用**产地直发+顺丰/京东冷链**，或者“产地仓-销地仓”的二级分拨。
- **时效参考**：
  - **核心城市（一线及新一线）**：从下单到发货，通常**48小时内**完成发出（如遇暴雨台风等天气影响采摘会延迟）。运输全程冷链，到货约**2-3天**。
  - **偏远地区（如新疆、西藏）**：时效会延长至**4-6天**，且可能改为“冰袋+泡沫箱”非全程冷链，需留意损耗。
- **特点**：对**生鲜损耗控制**要求高，如果电商页面标注“产地直发”，通常当天或次日凌晨采摘，下午装车。

---

**给你的实用建议（避免踩坑）：**

1. **看电商平台履约承诺**：不要只问品牌，直接看**京东超市/天猫超市/美团优选/朴朴**等平台商品页的“预计送达时间”。生鲜电商的物流是**平台主导**的，都乐和鑫荣懋大多只是供货方。
   - 例如：**京东自营**上标注“次日达”的都乐菠萝，实际是京东冷链从本地仓发，而非产地直发；只有标“产地直采”的才是你想要的。

2. **批量采购（B端）直接问销售**：如果你是做社区团购、连锁水果店，直接联系都乐/鑫荣懋的区域销售经理，要求提供**“SOP时效承诺书”**，通常包括：
   - 采摘节点（如凌晨4点前）
   - 干线运输时长（如广州到上海 26小时）
   - 到货损耗率（一般承诺低于5%）

3. **小批量试单测试**：建议先各下一单**最小订货量**，实测两家在公司或店铺所在地址的**真实配送时长**。因为时效受高温天气、节假日爆仓影响极大，数据远比宣传更可信。

**结论：**
- 日常电商零售，**鑫荣懋**的国产直发在“下单到收货”的短时效上通常略优于都乐（尤其南方市场）。
- 追求**品质稳定和全程冷链标准化**，选**都乐**，但需预留更长的运输时间。
- **如果页面明确写“产地直发”，鑫荣懋更契合；如果写“冷链仓储”，两家都差不多，主要看平台仓库位置**。
