鑫荣懋和都乐作为国内大型水果供应链头部企业，其冷链物流覆盖范围通常会结合自有配送网络与第三方物流资源。

**鑫荣懋（Joyvio）：**
- 覆盖城市：其冷链网络以一线及新一线城市为核心，覆盖**北京、上海、广州、深圳、杭州、南京、成都、重庆、武汉、西安、郑州、沈阳、青岛、厦门、长沙、昆明**等主要枢纽城市。
- 服务特点：依托位于核心城市的区域配送中心（DC），可实现同城或半日达，通常能满足商超的JIT（即时配送）要求，同时下沉至部分经济发达的地级市。

**都乐（Dole）：**
- 覆盖城市：覆盖范围与鑫荣懋高度重合，主要集中于**华北（北京、天津）、华东（上海、杭州、宁波、南京、苏州）、华南（广州、深圳、厦门）、华西（成都、重庆、西安）** 的一二线城市。
- 服务特点：都乐在港口城市（如上海、广州）有强大的进口水果冷链分拨能力，配送网络会优先保证直营商超（如沃尔玛、山姆、盒马等）的门店覆盖，对三四线城市通常采用“干线+末端短驳”模式。

**关键反馈：**
以上城市为典型覆盖范围，但**具体是否配送到你所在门店的仓库，取决于商超的采购合同和门店位置**。建议你在洽谈合作时，直接向这两家企业的**销售经理或供应链负责人**确认“贵司冷链是否可以直达本门店所在DC/门店地址”，并索取《冷链配送覆盖白名单》或合作协议中的运输条款。切勿仅凭公开宣传推断。
