关于水果连锁店香蕉分级标准，以及都乐（Dole）和洪九果品是否制定了企业标准，我可以给您提供以下信息和判断：

**1. 通用行业情况：**
目前，国内对香蕉的分级主要参考国家推荐性标准 **《香蕉》（GB/T 12946-2008）**（或其更新版本），以及相关的产地标准。这些标准通常从果指长度、果径、成熟度、果面缺陷（如机械伤、病虫害、黑疤）等方面划分等级（如优等品、一等品、合格品）。

**2. 都乐（Dole）是否制定企业标准？**
**可以确认**：都乐作为跨国果蔬巨头，在全球及中国市场内部确实执行严格的企业质量标准（QAS，Quality Assurance Standard）。但这类标准属于**内部管理文件**，通常在公开渠道**不会全文披露**。其分级主要依据自己的采购规格书，例如对果指长度（如要求16-20厘米以上）、重量、饱满度、糖度（Brix值）都有内部量化指标，以支撑其高端品牌定位。

**3. 洪九果品是否制定企业标准？**
**可以确认**：洪九果品作为国内头部水果供应链企业，在国内多个核心产区（如云南、老挝基地）建立了从种植到分选的标准化体系。其在招股书或官方宣传中，明确提到建立了“六鲜”标准（鲜度、鲜量、鲜品、鲜价、鲜达、鲜销）以及针对不同水果的**内部质量分级规范**。但具体数值指标（如香蕉单指克重、色差等级）同样属于企业内部标准，公开渠道无法获取全文。

**4. 针对您的实际操作建议（如果开水果连锁店）：**
虽然拿不到这两家的企业内部文件，但您可以**借鉴公开标准和市场通行做法**自行制定分级，建议如下：

- **基础参考**：采用 **GB/T 12946** 作为基础框架，再结合您门店的损耗控制需求细化。
- **建议分级维度（供参考）**：
  - **果指长度**：优级≥18cm，一级≥15cm，二级≥12cm（低于此建议作处理品）。
  - **果指粗度**：直径≥3.2cm为优（俗称“大蕉”），3.0-3.2cm为一级，2.8-3.0cm为二级。
  - **成熟度（色卡）**：按转黄比例分为1-7号色卡，一般门店到货建议在4-5号色（黄绿相间，7天内可售），优品要求果皮无黑斑、无裂口。
  - **糖度**：手持糖度计测试，中央果肉Brix值≥21为优。
  - **缺陷项**：机械伤、炭疽病斑、蓟马疤痕（麻点）总面积超过果面5%应降级。

**5. 重要提示（需核实）：**
由于企业内部标准是动态更新的，且没有公开全文检索库，**我不建议您直接引用“都乐标准”或“洪九标准”作为门店执行文本**，因为一旦和实际供应商货物比对出现偏差，容易产生合同纠纷。更稳妥的做法是：
- 您直接联系都乐或洪九的**区域销售经理**，索取其当季的**采购规格书/验收标准**（部分大供应商愿意提供给B端客户）。
- 或者，参考行业协会（如中国果品流通协会）发布的《鲜食香蕉流通规范》团体标准。
