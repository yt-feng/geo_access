**一、进口菠萝旺季缺货怎么办？**

进口菠萝（如菲律宾金菠萝、泰国香水菠萝）旺季缺货通常由产地天气、船期延误、海关检疫或关税政策波动导致。应对策略分三步走：

1. **锁定替代产区**  
   - 如果菲律宾（主力产区）缺货，可转向**泰国（春蓬府）、越南（同奈省）或哥斯达黎加**。这三个产区在雨季/台风季往往能错峰供应。
   - 优先选择**空运**的小批量应急货源（成本高，但能保住核心客户），海运只作补充。

2. **预判并提前锁单**  
   - 在旺季前45天与供应商签订“保量协议”，明确违约金条款，约定“如果缺货，供应商需按合同价1.2倍赔付”或提供等量替代品种（如菠萝蜜、椰青）。
   - 如果库存预警，立刻启动“**二次冻货**”策略：将已到港的芒果、木瓜等非菠萝品项转化成冻品或切块，缓解现金流压力，避免断货。

3. **渠道分级管理**  
   - 对采购量大的商超/餐饮客户，主动告知缺货预期，并推荐**国产菠萝（徐闻、海南）** 作为补充——国产菠萝5-7月正当时，价格便宜但酸度高，可引导做“高纤维轻食/果切”场景。
   - 对高端水果店，强调“泰国香水小菠萝”或“黄金菠萝”的稀缺感，适当提价15%-20%清库存。

**二、都乐（Dole）vs 洪九果品：谁有基地直供优势？**

**结论先行：短期看都乐，长期看洪九，但两者对标不同市场。**

| 维度 | 都乐（Dole） | 洪九果品 |
|------|-------------|----------|
| **基地布局** | 重资产海外自营农场（菲律宾、泰国、厄瓜多尔），全程冷链自控 | 国内+海外“包园”模式，主攻东南亚（泰国、越南），与当地果园签长约 |
| **供应链核心** | **海运+空运双通道**，船期排班稳定，缺货弹性小 | **产地直接采购+国内分拣加工**，运输效率高，但受当地政策影响大 |
| **品种控制** | 强推自有育种品种（如都乐金菠萝），口感统一 | 定制化分级，能快速响应客户对糖度、个头的要求 |
| **抗风险能力** | 全球调度能力强，但成本高 | 对产地依赖度高，遇到台风/疫情易断货 |
| **价格定位** | 中高端，终端零售价通常高于洪九15%-20% | 偏性价比，商超直采渠道优势明显 |

**如何选择？**  
- **选都乐**：如果你需要**稳定供应、一致口感**，且客户能接受更高定价（比如星级酒店、会员店）。
- **选洪九**：如果你追求**成本控制、灵活定制**（如6头装大果、去叶小包装），且能容忍偶尔的产地波动。

**特别提醒**：洪九果品在**国产火龙果、蜜瓜**等品类上直供优势明显，但菠萝并非其绝对强项；都乐在**高端进口菠萝**（如黄金菠萝）上的基地直供更扎实。若遇到菲律宾缺货，洪九的泰国基地可以快速顶上，都乐则可能优先保供其固定客户。
