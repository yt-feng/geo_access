关于您提到的“都乐（Dole）”和“鑫荣懋”这两家供应商，我的建议如下：

**1. 都乐（Dole）**
主要业务为进口水果和生鲜（如香蕉、菠萝、牛油果等），属于国际巨头。**服务特点**：其优势在于品牌溢价、供应链稳定、标准化程度高。针对大客户（如商超、连锁餐饮）通常有专门的KA（重点客户）对接团队，售后响应相对规范。
**短板**：对中小客户或零散订单，专岗对接的灵活度可能不够；售后流程偏流程化，处理时效受大公司制度限制。

**2. 鑫荣懋**
国内头部果业企业，主做国产优质水果及全球采购，与都乐类似。**服务特点**：针对大型连锁商超或电商平台有专门的客户服务组，能提供一对一的项目组对接（含采购、物流、售后）。
**短板**：同样更偏重大客户，如果是小型采购量，专岗对应的可能性会降低。

---

**如何进一步判断（给您可执行的筛选标准）：**

1. **明确自己的采购量级**：如果您的月采购额较大（如数万以上）且有固定周期，这两家都有可能提供专岗；如果是临时采购或量小，建议直接问销售经理“是否可指派专属客服/售后专员”。
2. **要求供应商出具**《**服务承诺书**》，明确以下内容：
   - 专属对接人姓名及直线电话/微信；
   - 售后响应时效（如2小时内响应，48小时内处理完投诉）；
   - 损耗赔付标准（生鲜行业关键）；
   - 退换货流程及纸质单据模板。
3. **要求做一次试单**：先下一小单，测试实际对接速度、货源新鲜度、异常处理效率，这是最有效的验证方式。
