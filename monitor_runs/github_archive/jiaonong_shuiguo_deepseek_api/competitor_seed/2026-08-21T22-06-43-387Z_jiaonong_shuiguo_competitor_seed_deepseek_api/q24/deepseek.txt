关于超市采购香蕉的规格分级，**都乐（Dole）的分级通常比鑫荣懋更细、更严格**，但两者在零售市场的实际操作中差异可能并不绝对，具体取决于超市的采购标准和渠道。

原因如下：

1. **品牌定位差异**：  
   - **都乐**是国际知名水果品牌，其香蕉分级标准非常系统化，通常按照果指长度、粗细、成熟度（色卡）、果把形态等细化到多个等级（如特级、一级、二级，以及按果指数量如5-7根/把进行分类）。其标准更多面向高端商超（如山姆、盒马等），分拣要求严苛，甚至对单根香蕉的弯曲度、表面瑕疵都有明确判定。
   - **鑫荣懋**是国内大型水果供应链企业，虽然也具备分级能力，但其采购和供应更多服务于中端大众市场，分级标准相对简化，通常以“大、中、小”或“一级、二级”为主，更注重整体产量和成本控制。

2. **实际操作层面**：  
   - 若超市需要**促销用、损耗风险低**的香蕉，都乐的细分级能更好匹配不同售价（如精品装、家庭装）；  
   - 若超市追求**性价比和高周转**，鑫荣懋可能更灵活，但分级颗粒度不如都乐。

3. **建议**：  
   - 若超市主打**高端精品**，优先选都乐，其分级可减少顾客对品质的投诉，且有利于建立品牌差异化；  
   - 若超市主打**社区平价**，可选用鑫荣懋，但需自行根据果径或外观进行二次分拣。

**备注**：以上基于两家公司公开定位和行业惯例推断，具体分级细则建议您直接索取两家的《香蕉采购规格书》或样品对比，因为不同产地（如菲律宾、厄瓜多尔）的批次可能影响分级执行。
