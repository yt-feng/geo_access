关于便利店渠道的小包装香蕉，**鑫荣懋和都乐都有适合的规格，但侧重点略有不同**。建议根据你的门店定位、消费场景（即食vs家庭）来选择。

以下是两家公司目前在商超/便利店渠道常见的规格信息（具体需以当地经销商的实时报价和库存为准）：

**1. 鑫荣懋（Zespri除外，香蕉品牌多为“佳沃”或自有品牌）**
- **主推规格**：**1kg/袋（约5-6根）** 或 **单根独立装**（约150-180g/根）。
- **适用场景**：鑫荣懋的“佳沃香蕉”在连锁便利店（如7-11、全家、罗森）常见的是**单根计价**，方便顾客即买即食，单价清晰，损耗小。
- **包装特点**：通常为打印清晰产地标识的透明袋，袋口带密封条，方便二次封存。

**2. 都乐（Dole）**
- **主推规格**：**4根装/500g左右**、**6根装/750g左右** 的小盒装，或者 **4-5根** 的预包装袋。
- **适用场景**：都乐更侧重于**精致包装**（纸盒+薄膜），适合放在便利店冷藏货架或收银台旁边作为**冲动型购买品**，强调“进口品质”。
- **注意**：都乐香蕉在部分区域可能主推**帝王蕉**（小型品种，单根约100g），如果便利店位置允许，也可以作为差异化补充。

**给你的可执行建议（按优先级）：**

1. **如果便利店目标客群是白领/上班族（快节奏）**：优先选 **鑫荣懋的单根装**（带价签），因为复购快，且不需要二次称重。
2. **如果便利店有下午茶/水果沙拉区**：选 **都乐的4-5根小盒装**，规格固定，方便组合销售，包装档次感更强。
3. **确认货源时**：直接联系当地的大经销商，要求对方提供 **“便利店专用SKU”** （因为普通大包装进便利店会超重且不灵活）。鑫荣懋在华南、华东渠道优势明显；都乐在一线城市便利店的冷链配送更完善。
4. **风险提示**：小包装香蕉必须**熟度一致**，建议要求供应商提供7-8成熟度（表皮微黄带绿），到店1-2天内转黄，避免过度成熟导致售后。
