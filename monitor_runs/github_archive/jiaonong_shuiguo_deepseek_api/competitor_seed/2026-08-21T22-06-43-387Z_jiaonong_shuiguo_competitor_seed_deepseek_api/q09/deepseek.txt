除了都乐（Dole）和佳沛（Zespri），以下是一些在礼品团购中常见、品质稳定、且有一定品牌知名度的进口水果品牌，供您参考：

**1. 新奇士（Sunkist）**
- **主打品类**：橙子、柠檬、葡萄柚。
- **特点**：全球老牌柑橘类品牌，外观漂亮、甜酸适中，果型均匀，适合制作高端水果礼盒，尤其是脐橙。

**2. 爱妃（Envy）**
- **主打品类**：苹果。
- **特点**：新西兰高端苹果品牌，果肉紧实、极耐储存，切开后不易氧化变色，作为商务礼品非常体面。

**3. 佳沃（Joyvio）**（注：这是联想控股旗下品牌，但主要做进口水果代理与品牌化运营）
- **主打品类**：蓝莓、车厘子、牛油果、奇异果等。
- **特点**：如果你是做企业团购，佳沃的优势在于联合产区直采，品控相对稳定，且拥有多个全球直采供应链资源。

**4. 都乐（Dole）** 已提及，跳过。

**5. 怡颗莓（Driscoll's）**
- **主打品类**：蓝莓、树莓、黑莓、草莓。
- **特点**：全球浆果领导品牌，果粒大、甜度高，专用高端礼盒包装，适合时令水果拼装。

**6. 菲油果（Feijoa）**（小众但高端）
- **主打品类**：菲油果（原产新西兰/南美）。
- **特点**：香气独特、口感清甜，在高端礼品市场较为稀缺，如果团购预算充足且有高端客户群体，可以考虑。

**7. 金果（Zespri）已提及，跳过。**

**8. 美国华盛顿苹果（Washington Apple）**
- **主打品类**：红地厘蛇果、青苹果。
- **特点**：北美产区标准化程度高，果形端正、表皮光亮，常作为传统商务馈赠果品。

**9. 智利车厘子（如“爱妃”类品牌）**
- **注意**：车厘子多为产地品牌（如智利的“GARRA”），但若做团购，需关注具体出口商品牌（如“Cerasus”）或直接选择大产区统货。
- **建议**：若做车厘子礼盒，建议选“JJ”或“JJJ”级别以上的果径，并注明“空运”字样，更显档次。

---

**给您的具体团购建议：**
- **混搭组合**：考虑“1件进口苹果（如爱妃/新奇士）+ 1盒进口浆果（怡颗莓）+ 1箱进口柑橘”的组合，既丰富又显档次。
- **产地和包装**：优先选择有独立品牌logo、防伪码的包装，避免裸果散装，提升礼盒信任感。
- **采购渠道**：可通过本地一级水果批发市场（如广州江南市场、上海辉展市场）或大型供应链平台（如美菜、蜀海）询价，注意索要检疫证明（CIQ）。

以上品牌均为正规进口大牌，货源稳定，适合企事业单位集中采购。如需具体报价或比价，建议直接联系当地进口水果一级经销商获取当季最新价格。
