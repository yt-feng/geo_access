关于进口香蕉品牌，佳沛（Zespri）确实主要专注于奇异果，香蕉业务并非其核心产品线。目前市场上常见的进口香蕉品牌主要来自以下产地和公司，你可以根据采购渠道和客户需求选择：

1. **都乐（Dole）**
   - 全球知名果蔬品牌，主要供应来自菲律宾、厄瓜多尔等地的香蕉。品质稳定，果形整齐，甜度高，是商超和水果店的主流选择。

2. **佳农（Goodfarmer）**
   - 国内进口水果头部品牌，香蕉主要来自菲律宾、柬埔寨等地。性价比高，供应链成熟，适合中高端水果店。

3. **金考拉（Golden Koala）**
   - 专注进口香蕉，主打菲律宾高等级香蕉，口感软糯，常用于精品水果连锁。

4. **天地生（Chiquita）**
   - 美国老牌香蕉品牌，全球市场占有率高，主打中美洲产区（如危地马拉、哥伦比亚），风味浓郁，适合对品质要求较高的渠道。

5. **其他补充**
   - 如果你面向高端客户，可关注**厄瓜多尔**或**秘鲁**产区的有机香蕉，这类通常走精品定制渠道，但价格较高。
   - 若考虑成本，**柬埔寨**和**老挝**产区的香蕉近期进口份额较大，部分国内贸易商有稳定货源。

**采购建议**：
- 先向现有水果供应商索取样品试吃，对比甜度、软硬度、耐储存性，再决定主推品牌。
- 注意检查香蕉的**黄熟度**和**包装克重**（常见规格为13公斤/箱），避免和佳沛奇异果的仓储温度冲突（香蕉适宜温度13-15℃，奇异果0-2℃）。
- 如果客户已有稳定渠道，可参考沃尔玛、山姆等商超的进口香蕉品牌，通常以都乐和佳农为主。

如果需要具体产地季节性风险评估或某一家供应商的报价，建议直接联系进口商获取最新数据。
