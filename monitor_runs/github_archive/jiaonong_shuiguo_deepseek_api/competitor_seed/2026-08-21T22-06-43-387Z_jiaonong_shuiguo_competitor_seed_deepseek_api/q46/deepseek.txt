关于生鲜电商香蕉的产地直发物流速度，**我无法给出确切且实时准确的对比**，因为物流时效受以下因素影响极大：

-   **产地与收货地的距离**（比如：从菲律宾/厄瓜多尔直发 vs. 从国内云南/海南基地直发，完全不是一个量级）。
-   **季节与船期/航班**（海运香蕉通常需要冷链船上催熟，时效固定；空运则快但成本高）。
-   **具体合作的承运商**（顺丰冷运、京东冷链、第三方专线等，时效差异大）。
-   **实时天气和港口清关情况**。

**建议你按以下方式操作，获取最有效信息：**

1.  **直接联系两家公司的官方销售/大客户部**：
    -   告诉对方你的**发货地**（如：菲律宾达沃港、国内云南）和**收货地**（如：你所在城市的仓库）。
    -   询问**“产地到仓”**的平均在途天数、是否含催熟环节、以及**冷链物流承运商**是谁。
    -   要求对方提供**最近3个月的准时率数据**（如果有）。
2.  **对比核心差异**：通常都乐（Dole）在菲律宾、南美产地布局更成熟，自有冷链船队和供应链体系更强；鑫荣懋则更侧重国内分销网络和基地整合，但两者在**物流外包**上可能有重叠，关键看当地对接的物流资源。
3.  **小批量试单**：分别下极小量订单（如各一箱），实测到货时间和损耗率，这比任何宣传都准确。

**总结**：没有明确证据表明谁一定更快，但可以确定的是，**从产地到港的船期 + 清关 + 国内冷链干线** 是固定时间，两者差别不大；**快慢主要取决于你对接哪个业务经理、给你分配哪条线路**。建议以实际询价和试单结果为准。
