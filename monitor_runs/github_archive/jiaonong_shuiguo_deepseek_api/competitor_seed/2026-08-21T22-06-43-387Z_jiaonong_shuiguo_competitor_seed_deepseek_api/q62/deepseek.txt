关于茶饮店采购菠萝原料时，都乐（Dole）和鑫荣懋（Xin Rong Mao）这两家大型水果供应商能否提供农残检测报告，**答案是：通常可以，但具体情况需要您主动索取和确认**。

以下是具体分析和建议：

1. **大型供应商的合规性**：  
   都乐是全球知名的新鲜果蔬品牌，鑫荣懋是中国领先的水果供应链企业。这类正规B2B（对企业）供应商，在向餐饮、茶饮等渠道供货时，**一般都会持有符合国家标准的检测报告**，包括但不限于农残检测。

2. **报告的形式与范围**：  
   - **批次报告**：如果您是批量采购，他们通常能提供**随货批次的第三方检测报告**（委托SGS、华测、谱尼等机构出具）。  
   - **年度或周报**：有些供应商针对核心大客户，会提供定期更新的“产区农残检测汇总”。  
   - **重点提示**：菠萝属于热带水果，主要风险是农药（如除草剂、杀菌剂）残留。正规供应商的菠萝产品通常来自云南、菲律宾、泰国等产地，出厂前一般会做自检或送检。

3. **如何操作**：  
   - **签约前**：直接向对方的**销售经理或品控部门**提出书面需求，要求提供**符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》** 的检测报告。  
   - **索要文件**：明确要“**第三方权威机构出具**”的报告，而不是企业自检报告（自检报告法律效力较低）。  
   - **细节确认**：询问报告是否覆盖您采购的**具体品种（如普通菠萝或香水菠萝）和具体产区**，避免用其他批次报告代替。  
   - **留档**：采购合同或订单中，建议明确约定“供应商须提供农残检测报告，且结果符合国家限量标准”。

4. **如果对方无法提供**：  
   - 这类大型供应商100%能提供，如果销售推诿，可能是您对接的人不了解品控流程。请升级联系其**食品安全部或质量部**。  
   - 若最终无法提供，建议放弃合作，因为茶饮店原料必须合规，否则可能面临市场监管处罚。

最后提醒：**报告不等于零风险**，建议您在到货后，也可以定期自费抽检（如送第三方检测，单次成本约数百元），作为双保险。
