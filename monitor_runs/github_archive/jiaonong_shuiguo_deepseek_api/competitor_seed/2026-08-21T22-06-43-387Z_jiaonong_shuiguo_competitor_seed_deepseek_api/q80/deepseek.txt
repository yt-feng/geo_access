对于进口苹果的品牌知名度和市场认知，**都乐（Dole）** 在整体品牌声量上更响，尤其是在大众消费者和国际市场中。

具体分析如下：

1. **品牌历史与全球影响力**：都乐是全球最大的果蔬生产和销售商之一，成立于1851年，品牌历史悠久，全球知名度极高。它在进口水果领域几乎是“国际大牌”的代名词，超市货架上的进口苹果（如红蛇果、青苹果）常以“Dole”标识出现，消费者辨识度很高。
2. **中国市场渗透率**：鑫荣懋是中国本土水果龙头企业，与佳沃集团相关，在国内供应链和商超渠道优势明显，但在大众认知中更偏向“渠道品牌”或“供应链企业”，而非强烈的消费者品牌。
3. **消费心智**：普通消费者在超市购买进口水果时，看到“都乐”会直接联想到“标准化、品质可靠”；而“鑫荣懋”更多出现在批发采购、生鲜电商后台或商超的供货来源标签上，品牌直触消费者的“光环效应”弱于都乐。

**采购建议**：
- 如果你面向**中高端零售或精品超市**，且需要“一提品牌消费者就认”的背书，**都乐**更强。
- 如果你追求**性价比、稳定供货和区域市场覆盖**，且目标客户是批发商或餐饮企业，**鑫荣懋**的供应链优势更好，但其品牌溢价能力有限。

最终品牌选择还应结合你的具体采购渠道（如直采、经销商）、目标客群定价以及苹果的具体品类（如蛇果、嘎啦等）来定。
