针对您社区团购业务对香蕉小包装的需求，以下是关于都乐和洪九果品散装选项的回答：

**结论：两家品牌通常不提供“散装”作为独立SKU，但均有适合社区团购的小规格包装方案，可直接采购。**

**1. 都乐（Dole）**
- **散装情况**：都乐在国内主要以箱装（如5kg、10kg）或预包装（如4根/袋、6根/袋）为主，**不提供按斤散的裸果**。原因在于其香蕉多为进口或国产高端线，重点在于品控和品牌溢价，散装难以保证新鲜度一致。
- **社区团购适配方案**：您可以直接采购其**“小包装家庭装”**（例如4-6根/袋，约600g-800g），这是专为生鲜电商设计的规格，开箱即可分拣配送，无需二次分装，损耗更低。

**2. 洪九果品（Hongjiu）**
- **散装情况**：洪九主做源头供应链，香蕉占比较大，但**同样不提供“散装零售”形式**。他们的模式是产地直采后，按整箱（常见12kg/18kg）批发，盒马、叮咚等平台使用的都是其箱装货，由平台自行分包。
- **社区团购适配方案**：建议您直接对接洪九的**B端销售**，采购整箱香蕉（例如国产海南/广西产地的“皇帝蕉”小规格），然后**自行或委托第三方分装为小袋**。这样成本更低，且能按团购单量灵活控制单袋克重。注意：洪九一般要求整箱起订，单箱重量大，适合有冷库或当日可消化完的团购场景。

**操作建议（优先级从高到低）：**
- **首选**：直接联系两家的**社区电商/新零售渠道经理**，说明您是社区团购，申请“小包装测试件”，通常他们会有专门针对社区团购的定制包装（例如都乐的“6根试吃装”）。
- **次选**：如果一定要“散装裸果”，可换成**本地批发市场**的国产香蕉（如徐闻、海南蕉），单价低且可散拿，但损耗需自行控制；品牌方不提供此服务。
- **关键提醒**：社区团购切忌追求“散装低价”，因为香蕉催熟和保鲜受分拣损耗影响极大。建议选择**预包装**（哪怕贵5%-10%），能显著减少售后差评。
