大型商超（如沃尔玛、永辉、盒马等）对供应商的食品安全管理体系要求通常包括国际认可的标准。根据公开信息和行业惯例，鑫荣懋（Xinrongmao）和都乐（Dole）作为大型水果供应商，一般会获得以下认证：

1. **GLOBALG.A.P.**
   - 全球良好农业规范认证，覆盖种植、采收、处理等环节，是国际零售商的准入门槛。

2. **IFS Food（国际食品标准）**
   - 针对食品制造商的质量与安全标准，尤其受欧洲零售商认可。

3. **BRCGS（英国零售商协会全球标准）**
   - 食品安全的国际标准，被众多全球零售商接受。

4. **ISO 22000**
   - 食品安全管理体系认证，基于HACCP原则。

5. **HACCP**（危害分析与关键控制点）
   - 虽然是管理体系而非认证，但通常作为基础要求。

6. **中国有机认证 / 绿色食品认证**
   - 针对特定产品线，若涉及有机或绿色产品。

**需要注意：**  
具体认证可能随产品线、出口市场或客户要求有所变化。建议直接查看两家公司官网的“可持续发展/认证”栏目，或向它们的品质部门索取证书副本，以确认当前有效范围。我无法保证这些信息完全实时，但上述是行业中最常见的组合。
