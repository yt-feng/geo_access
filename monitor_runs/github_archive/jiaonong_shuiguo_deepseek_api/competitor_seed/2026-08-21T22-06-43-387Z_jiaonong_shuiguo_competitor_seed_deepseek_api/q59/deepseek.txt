关于都乐（Dole）和洪九果品这两家公司对下游客户（如超市、批发商）的**具体账期政策**，属于企业内部商业条款，**公开渠道没有统一的标准答案**，且会根据合作规模、采购量、信用评级、季节行情等因素动态调整。

不过，根据行业惯例和公开财报信息，可以给你以下参考判断：

**1. 都乐（Dole）**
- **背景**：全球性果蔬巨头，主要服务大型商超、餐饮连锁及批发市场。
- **账期惯例**：作为外资企业，其账期管理通常较为规范严格。面向大型连锁客户（如沃尔玛、永辉等），账期通常在 **30-60天**；面向中小批发商，往往要求现款现货或预付定金，有账期的比例较低。
- **提点**：都乐更注重品牌溢价和品质稳定性，对资金回笼要求高，一般不会给到超长账期（如90天以上），除非是战略合作大客户。

**2. 洪九果品**
- **背景**：国内头部水果供应链企业，专注榴莲、山竹等高单价进口水果，B端客户覆盖全国批发市场及新零售渠道。
- **账期惯例**：洪九以“端到端”模式著称，对下游经销商和商超通常提供 **15-45天** 的信用账期，部分核心客户可达60天。但因其高周转特性，绝大多数分销会采用“预付款+尾款”或“周结/半月结”方式，纯赊销比例不高。
- **提示**：洪九近两年（2023-2025）处于降杠杆周期，若合作方是中小客户，更可能要求先款后货。

**建议：**
- 如果你是**连锁商超或大型餐饮**，可直接联系两家公司的销售或KA大客户部门，提交公司资质和采购意向书，他们会给出书面账期方案（通常需要提供财务报表或担保）。
- 如果你是**中小批发商**，建议优先考虑本地一级代理或产地合作社，他们更灵活，账期可能给到7-15天，但风险较高。

**风险提醒**：果品生鲜易腐，账期长意味着对方可能以“坏果损耗”为由克扣货款。若对方承诺超过60天账期，务必谨慎核查其偿付能力，并签订正式购销合同。
