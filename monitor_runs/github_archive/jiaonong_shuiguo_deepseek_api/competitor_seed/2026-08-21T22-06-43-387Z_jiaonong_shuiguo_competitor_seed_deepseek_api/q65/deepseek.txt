关于菠萝的锁价机制，**都乐（Dole）** 和**洪九果品**目前在公开渠道均未公布统一的、标准化的锁价周期，因为水果批发锁价高度依赖**采购量、合作模式、物流时效和车厘子/菠萝等生鲜商品的行情波动**。

**针对这两个品牌的具体情况，建议如下：**

1. **都乐（Dole）**：作为国际品牌，其国内供应链通常采用“基地直采+远期合约”模式。锁价周期一般较短，**常见为7~30天**，且通常需要提前支付一定比例的预付款。实际锁价期限取决于您采购的规格（如整柜海运 vs 空运）和当前产地（如菲律宾、泰国）的收货价。
2. **洪九果品**：作为国内头部进口商，对大宗客户（如连锁商超、批发市场大户）可提供“**以到港日或提货日为基准**”的阶梯式锁价。锁价周期通常与船期挂钩，**常见为15~45天**，但需要单个业务员进行谈判。

**行动建议：**
- 请直接致电都乐或洪九的**大客户部/水果事业部**，明确告知您需要的**月采购量（吨/柜）**，他们才能给出有效的锁价周期报价。
- 如果您的采购量较小（例如单次不足一柜），通常**不提供锁价**，而是按当天的市场部指导价结算，避免承担库存风险。

**注意**：由于菠萝价格受台风、产地雨季等影响极大，正规供应商通常只提供**短期锁价**（以货物在途或在库为准），很少提供超过1个月的锁价，这属于行业通行做法。建议您同时询价圣桃（Sunkist）、佳沃等其他中型供应商以作对比。
