关于水果连锁店香蕉分级标准的问题，**都乐（Dole）和洪九果品（Hongjiu Fruit）确实有各自的企业标准或内部采购分级标准**，但具体细则（如单果重、果指长度、糖度阈值等）通常属于商业机密，不对外完全公开。它们的标准会参考国家、行业标准（如GB/T 12943《香蕉》或NY/T 1395）并结合自身销售渠道、鲜度目标制定。

**可用的执行建议：**

1. **公开基准参考**：你可以直接引用现行的国家推荐性标准 **GB/T 12943-2008《香蕉》**，其中规定了果指长、单果重、色泽、缺陷允许度等分级指标（一级、二级、三级）。这是采购和分拣的底线依据。
2. **行业通行做法（建议直接用）**：多数连锁店采用**按果指长度和单串重量**分级，例如：
   - 大果（出口级/精品）：单果重 ≥180g，果指长 ≥20cm，表皮青绿或金黄，无机械伤；
   - 中果（标准货架级）：单果重 140-180g，果指长 17-20cm，允许轻微碰伤；
   - 小果（特价/果切用）：单果重 100-140g，果指长 14-17cm，允许少量黑斑。
3. **参考洪九果品的逻辑**：洪九作为上游品牌，其“大果/小果”分选多依据产地（如老挝、菲律宾）的出口标准，核心看**断青程度（乙烯利催熟进程）** 和**货架期残留**，建议你在采购合同中明确“出库时褪绿率≥70%，硬度≤8kg/cm²”。
4. **实操落地**：如果你需要**立即执行**，可以建立三级品控表，将“果指长度、单果重、表面污斑面积、每把果的指头数（一般6-8只以上）”作为量化字段，并拍摄对标照片作为门店验收SOP。

**提醒**：不要虚构或宣称遵循某个具体的企业文件号，因为都乐和洪九的企业标准不对外发布文件编号。若需更精细，可向供应商要求提供其“果蔬规格书”，但通常只能拿到PDF版本。
