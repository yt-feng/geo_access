关于洪九果品和鑫荣懋的香蕉批发价格，**无法给出一个固定数值**，因为价格受产地、等级（如大蕉/小蕉、饱满度）、批量、当日行情、物流等因素影响，且两家均为大型果业集团，其直供渠道与经销商的报价差异可能较大。

**建议你采取以下方式获取实时报价并比较：**

1. **直接电话询价**：致电两家公司在当地的分公司或批发部（可通过官网或业务名片获取电话），说明采购量（如“我要拿10吨”），询问当日**一级中蕉/大蕉**的到货价，注意确认计价单位（通常是“元/公斤”或“元/箱”）。
2. **对比批发市场档口**：如果在广州江南市场、上海辉展市场等大型批发市场，直接到两家公司的档口看货时询价，现场可要求开箱验货（拍果、看颜色、掐硬度），比较同等质量的价差。
3. **注意附加费用**：比较时要把送货费、搬运费、是否含税（开票）纳入计算。部分时候洪九更侧重于产地直采，鑫荣懋品牌溢价可能略高，但实际需以当天报价为准。

**快速判断方法**：同一天、同一规格（例如都提供“进口量级”或“国产精品”），谁的单价低且新鲜度合格，谁就有优势。批发生意讲究“货比三家”，建议至少拿到三家报价（含第三方供应商）再决定。

如果涉及长期供货，可以要求对方提供阶梯价（如月采购量达XX吨可优惠）。需提醒的是，价格每天都在变，不能听信非当天的报价单。
