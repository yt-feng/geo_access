除了都乐（Dole）和佳沛（Zespri）之外，以下是一些适合礼品团购的进口水果品牌，按品类区分：

**1. 柑橘/橙类**
- **新奇士（Sunkist）**：美国老牌，主打脐橙、柠檬，礼盒包装经典，知名度高。
- **澳柑（澳洲蜜柑）**：如“塔斯马尼亚”“澳洲甜橙”，强调阳光产地。

**2. 提子/葡萄**
- **阳光玫瑰（日本/云南产地）**：但进口常指“晴王”（日本冈山），价格较高，适合高端礼盒。
- **美国红提/青提**：如“Dole红提”（已有）以外，可找“Costa”“Naturipe”等出口商，但实际零售少见。

**3. 苹果/梨**
- **爱妃（Envy）**：新西兰品牌，脆甜多汁，包装精致。
- **青怡（Granny Smith）**：澳洲青苹果，酸度低，适合送礼。
- **新西兰玫瑰苹果（JAZZ）**：口感紧实。

**4. 猕猴桃（奇异果）**
- 除佳沛外，**意大利、希腊**产猕猴桃（如“Zespri”是新西兰，但意大利也有“Vital”品牌），但品牌力弱。

**5. 梨/牛油果等**
- **牛油果**：墨西哥、智利，常见品牌“Mission”（Mission Produce），但礼盒少见。
- **进口梨**：如“台湾凤梨”（实为菠萝）、“日本水蜜桃”，但价格波动大。

**6. 综合礼盒品牌**
- **鑫荣懋（Happy&Fresh）**：虽是国内公司，但运营进口品类多（如智利车厘子、蓝莓），可定制礼盒。
- **佳沃（Joyvio）**：联想旗下，进口蓝莓、奇异果、苹果等，有企业团购渠道。

**7. 高端小众品牌**
- **美国蓝莓**：如“Driscoll’s”（怡颗莓），以浆果为主，有礼盒装。
- **智利车厘子**：常见“Ocean Spray”（但非专一品牌），多按产地（如“Bing”品种）卖。

**建议**：
- 如果走**企业团购**，优先选**新奇士（Sunkist）**、**爱妃（Envy）**，品牌辨识度高且品质稳定。
- 如果追求**差异化**，可选**澳洲蜜柑**、**智利蓝莓（Driscoll’s）**，注意冷链和季节供应。
- 采购时确认是否有**官方授权经销商**，避免买到假货，并索取原产地证明（如澳洲检疫证、智利植物检疫证）。

最后提醒：进口品牌的实际货源可能受季节、检疫政策影响，建议提前2-4周联系供应商询价和预定。
