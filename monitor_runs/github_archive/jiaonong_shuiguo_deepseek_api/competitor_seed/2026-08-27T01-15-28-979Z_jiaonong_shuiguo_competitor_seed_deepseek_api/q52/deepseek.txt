关于菠萝到货损耗率，**没有统一的固定数值**，实际损耗主要取决于运输距离、冷链管理、到货季节以及仓库的验收标准。但根据行业经验，我可以给你一个参考范围，并结合两家供应商的定位做分析：

**1. 行业默认参考值（以新鲜菠萝为例）**

- **常规冷链运输（整车/整柜）**：在正常采摘成熟度（约7-8成熟）且冷链不断的情况下，到货损耗一般控制在 **3%~8%** 之间。
- **如果遇到天气骤变、装卸粗暴、或未充分预冷**，损耗可能飙升至 **10%~15%**。

**2. 都乐（Dole）**

- **定位**：全球品牌，主打标准化程度高，果品分级严格，通常在产地（如菲律宾、哥斯达黎加）进行标准化清洗、打蜡、包装。
- **损耗特点**：都乐的菠萝一般自带包装（纸箱+网套或泡沫），防撞防压能力强。在标准冷链下，**到货损耗率通常偏低，约在 3%~5%**。
- **注意点**：因为通常走海运，到港后可能面临“过渡成熟”风险。若在货架期末端收货，实际可售卖损耗（如内部褐变、酸味增加）可能达到 **5%~6%**。

**3. 鑫荣懋（Xinrongmao）**

- **定位**：国内龙头果品供应链企业，主要对接国内产地（如海南、广东徐闻）及部分进口货源，周转快，灵活性高。
- **损耗特点**：如果采购的是**国产菠萝**（如徐闻菠萝，采摘期集中），容易受产地天气影响（如连续降雨导致水分大、易烂心），运输周期短（一般1-2天直达），到货损耗率**在 4%~7% 浮动**。如果采购的是进口菠萝（如菲律宾都乐同源但经销商不同），损耗与都乐接近。
- **特别注意**：鑫荣懋在生鲜电商及商超渠道供货较多，如果采购时要求其按“净重结算”或提供“损耗补贴”条款，可大幅降低实际损失。

**建议你按以下方式与供应商锁定损耗标准：**

- 在采购合同中明确写入 **“到货损耗率上限（如≤5%）”**，超出部分由供应商承担或补货；
- 到货后**当天开箱抽检**（抽样比例不低于10%），重点检查底部挤压伤、果眼褐变、果肉水渍状；
- 要求供应商提供**到货温度记录仪数据**（尤其夏季），确保冷链在0-4℃。

如果你需要更精确的数据，建议直接让都乐和鑫荣懋的业务员提供**近三个月同规格产品的平均到货损耗统计报告**（他们内部一般有，但需主动索要）。若无法提供，可要求按上述标准写入合同。
