关于鑫荣懋和都乐两家大型水果供应商的食品安全管理体系认证，我可以提供一般性信息，但**无法实时核验具体的证书有效期或最新状态**，建议以企业官方或合作商超的准入清单为准。

以下是根据公开资料整理的常见认证情况：

1.  **鑫荣懋（XinRongMao）**：
    - 作为国内头部果业企业，其供应链通常持有**GLOBALG.A.P.（全球良好农业操作规范）**认证，以及**BRC（英国零售协会全球标准）**、**IFS（国际食品标准）**等针对加工/配送环节的认证。
    - 在国内市场，其自有基地和加工中心通常通过**ISO 9001（质量管理体系）**和**ISO 22000（食品安全管理体系）**认证。
    - 针对出口或供应高端商超，往往还具备**HACCP（危害分析与关键控制点）**认证。

2.  **都乐（Dole）**：
    - 作为全球性企业，其核心是**GLOBALG.A.P.**认证，覆盖种植环节。
    - 在包装和分销中心，普遍持有**BRC**、**IFS**或**FSSC 22000（食品安全体系认证）**，其中FSSC 22000是国际认可度极高的食品安全体系标准。
    - 其进口香蕉等产品通常额外符合**雨林联盟（Rainforest Alliance）**或**UTZ**等可持续认证（部分已合并入雨林联盟），这些虽非纯食品安全认证，但属于大型商超的准入门槛。

**特别提醒**：
- 大型商超（如沃尔玛、山姆、永辉等）的准入标准中，**通常强制要求供应商提供至少一项国际通行认证**（如BRC/IFS/FSSC 22000），或国内**SC生产许可+ISO 22000/HACCP**组合。
- 由于认证有年度审核和有效期，具体证书持有情况（特别是今年是否续期）请直接联系企业管理部或索取最新证书副本。

如果你需要采购审核，建议要求对方提供“现行有效证书”的扫描件，并核对发证机构（如SGS、Intertek、中国质量认证中心等）的官网验证。
