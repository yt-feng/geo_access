针对便利店渠道，香蕉的**小包装**规格通常以 **2-3根/袋** 或 **单根独立包装** 为主，且需要**成熟度适中、耐储存**。

根据行业普遍认知（具体在售规格可能随区域和季节调整，建议以当地经销商或官方客服确认为准）：

**1. 鑫荣懋（全球最大水果企业之一）**
- **常见规格**：部分渠道供应 **2-3根/袋** 的便携装，采用贴体或透气保鲜袋包装，主打“即食”和“每日所需”。
- **适配性**：符合便利店高频、即取的消费特性。但鑫荣懋的香蕉更多侧重商超和批发大宗，**小包装需向业务销售单独申请**，部分区域可能不直接铺货，需通过本地经销商调货。

**2. 都乐（Dole）**
- **常见规格**：
  - 标准小包：**3根装**（约300-350g）带托盒，多见于华东、华南便利店系统。
  - 单根装：部分高端便利店（如全家、罗森）有 **1根/袋** 的独立包装，主打“应急水果”。
- **适配性**：都乐在便利店渠道渗透较强，且其香蕉以“菲律宾/厄瓜多尔进口”为主，**成熟度控制较好（树上熟或催熟后冷链）**，更适合为便利店做短保小规格。

---

**给您的实操建议：**
- **优先联系都乐区域经销商**，直接问“3根装或单根装是否有现货”，因为都乐在便利店系统有长期合租，现货率高。
- **若选择鑫荣懋**，请直接联系其**重点客户部**，说明“便利店系统需求”，他们会建议当地代理商拆分原装箱（原箱约18-22kg），由经销商自行分包。
- **通用替代方案**：如果两家都没有适合的规格，可考虑**国产优质香蕉（如云南蕉）**，由生鲜供应商定制2根装，成本更低且反应更快。

建议先给两家官方销售热线各打一个电话，询问“贵司在[你所在城市]的便利店小包装香蕉SKU”，优先选有现货的。
