大型商超（如沃尔玛、山姆、盒马、永辉等）通常要求供应商具备食品安全管理体系认证、产品检测报告以及必要的生产许可。针对**鑫荣懋**和**都乐（Dole）**，这两家都是国内头部的水果供应链企业，资质通常非常齐全，基本能满足所有大型商超的入场门槛。

具体资质情况如下（由于企业资质会动态更新，以下为基础框架，最新清单以供应商提供的年度证书为准）：

### 1. 基础必备资质
- **营业执照**：均具备，且经营范围包含水果种植、加工、销售。
- **食品经营许可证/食品生产许可证**：
  - 鑫荣懋：作为国内供应链巨头，通常持有全国多地分公司的食品经营许可证；若涉及自有工厂加工（如鲜切水果、果汁），则持有SC（食品生产许可）证。
  - 都乐：其中国区运营主体持有食品经营许可证；其在华设有的加工配送中心通常持有SC证及出口食品生产企业备案。

### 2. 食品安全管理体系认证（商超重点核查项）
- **HACCP认证（危害分析与关键控制点）**：两者均有。这是商超最看重的，表明从源头到终端的关键环节受控。
- **ISO 22000食品安全管理体系**：两者通常均有。都乐作为国际品牌，其中国供应链企业一般持有；鑫荣懋也在全国主要基地/仓配中心推进该认证。
- **ISO 9001质量管理体系**：两者基本都有，作为管理基础。

### 3. 产品专项认证（行业特色）
- **GLOBALG.A.P.（全球良好农业操作规范）**：都乐认可度极高，其海外基地和部分国内合作农场持有；鑫荣懋对自有和合作基地也推广该项认证。
- **绿色食品/有机食品认证**：两者均有部分单品取得，具体取决于超市采购的特定SKU。
- **无公害农产品认证**：部分国内基地有，属于基础门槛。

### 4. 检测与追溯类资质（商超质检必查）
- **每批次第三方检测报告（CMA/CNAS）**：两者均能提供，重点检测农残（如GB 2763）、重金属、微生物。
- **追溯体系证明**：两者均建立从产地到门店的信息化追溯平台，可提供进货查验记录。

---

**给采购/供应商的建议（可执行性）：**

如果你是在**投标或进系统前的资质审核**：

1. **直接索要证书原件扫描件**，并核对有效期。重点看：营业执照经营范围是否含“新鲜水果批发零售”；食品经营许可证的“经营项目”是否涵盖“预包装食品销售（含冷藏冷冻）”及“散装食品”。
2. **要求提供最近3个月的第三方抽检报告**（商超一般要90天内的）。
3. **询问是否有安全责任险（产品责任险）**，这也是大型商超（如山姆、麦德龙）很看重的一项隐性资质。
