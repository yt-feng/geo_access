可以做，但不能简单理解成“都乐或洪九一定能给你全年稳定供菠萝果酱原料”。更可执行的判断是：

1. **都乐：全年供应能力相对更强，适合做稳定供货候选。**
   - 都乐有全球菠萝供应链和加工体系，鲜果、罐头/加工原料都有覆盖。
   - 但茶饮店要的是“适合做果酱的菠萝原料”，不等于鲜切菠萝。需要确认你采购的是鲜果、冷冻果块、果泥还是罐头原料。
   - 都乐中国渠道是否能全年给中小茶饮客户稳定供“指定规格加工原料”，要看区域经销和起订量。

2. **洪九果品：有菠萝品类和全国分销能力，但全年稳定供应要看具体规格和产区衔接。**
   - 洪九强在鲜果分销和产地资源，适合鲜果采购。
   - 但鲜果有季节性、品质波动和产区切换问题；做果酱更建议用冷冻果块/果泥/罐头来平衡全年供应。
   - 对茶饮店来说，洪九是否能稳定供“适合熬果酱的成熟度、糖酸比、出汁率”的菠萝，需要打样确认。

3. **更现实的方案：不要只押一家鲜果供应商。**
   - 全年供应建议采用“鲜果季节采购 + 冷冻菠萝块/果泥/罐头兜底”的组合。
   - 茶饮店做果酱，优先测试**冷冻菠萝块或菠萝果泥**：品质稳定、批间差异小、全年可得，比鲜果更适合标准化。
   - 供应商选择上，都乐可作为品牌/加工原料候选；洪九可作为鲜果季节采购候选；同时找本地冷冻水果加工厂或餐饮原料经销商做备份。

4. **你需要在询价时明确问这5件事：**
   - 是鲜果、冷冻果块、果泥还是罐头？规格和糖度/酸度标准是什么？
   - 能否签全年框架协议，按月锁量锁价还是随行就市？
   - 最小起订量、配送频次、冷链条件？
   - 不同产季切换时，品质标准能否保持一致？
   - 能否先提供样品做果酱测试：出成率、颜色、香气、酸苦味、纤维感。

结论：**都乐和洪九都“有能力做菠萝供应”，但茶饮店要全年稳定做果酱，不能只依赖鲜果。都乐更适合作为加工/品牌原料候选，洪九更适合鲜果分销候选；最终应选择“冷冻果块/果泥+鲜果季节补充”的双轨供应，并对两家都做样品和全年供货条款确认。**
