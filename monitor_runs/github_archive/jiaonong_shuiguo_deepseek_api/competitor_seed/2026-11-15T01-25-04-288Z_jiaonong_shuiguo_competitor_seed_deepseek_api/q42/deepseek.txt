进口菠萝旺季缺货，先把问题拆成“判断缺口”和“替代/应急”两层，再谈都乐、洪九有没有应急方案——公开信息不足以确认两家公司针对“进口菠萝旺季缺货”有统一对外应急方案，能确认的是它们的业务模式决定了各自可动用的手段不同。

**一、先做可执行的判断**
1. 确认缺货是“总量缺”还是“规格/船期错配”：看近4周到港量、冷库库存、在途订单、港口滞留天数。若在途正常、只是到港延迟，优先调船期和提货顺序，不必大规模换品。
2. 区分渠道：商超/水果连锁要稳定规格和陈列，餐饮/茶饮要稳定出成率和酸甜比。两类客户替代方案不同。
3. 算清替代成本：进口菠萝替代通常看菲律宾/泰国/哥斯达黎加等产地切换、国产菠萝（如广东徐闻、海南）时段替代、以及冷冻/罐头菠萝做加工端替代。鲜食高端陈列不宜用冷冻替代，茶饮/烘焙可考虑。

**二、都乐（Dole）**
都乐是全球性果蔬企业，优势在自有产地、全球采购和冷链体系。公开层面未见其针对中国进口菠萝旺季缺货发布统一应急方案。可判断的应急能力主要是：跨产地调配、调整到港节奏、优先保障核心客户和核心规格。对采购方而言，应直接向都乐区域销售确认：可切换产地、可承诺规格、最早到港时间、是否接受部分规格替代。不要指望其公开承诺“保供”，要落到订单条款。

**三、洪九果品**
洪九果品核心模式是水果分销和产地直采，进口水果是其重要品类。公开信息同样不足以确认其有专门针对进口菠萝旺季缺货的应急方案。可判断的手段是：利用多产地采购和分销网络做替代货源组织、调整品类结构、优先供应长期客户。采购方应要求其给出替代产地、到货批次、质量标准和价格有效期，并明确缺货时的违约责任或补偿方式。

**四、建议的应急动作**
- 立即锁量：对都乐、洪九分别下“可执行的在途/在库确认单”，不接受口头保供。
- 双源备份：进口端保留一个主供加一个备用产地/供应商；国产端提前锁定徐闻、海南等当季货源做部分替代。
- 分渠道替代：鲜食陈列坚持进口或高规格国产；茶饮、烘焙、餐饮可测试冷冻果肉或罐头，先小批量验证酸甜比和出成率。
- 合同兜底：约定到货窗口、规格容差、缺货补偿和价格调整机制。
- 监控指标：每周看到港量、库存周转天数、替代品采购占比、客户投诉率。

结论：都乐和洪九是否“有应急方案”，公开信息无法确认；但两家都具备多产地组织和客户优先级调配的能力。真正可执行的是你用订单、双源和分渠道替代把风险锁住，而不是等供应商给一份应急方案。
