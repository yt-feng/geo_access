都乐（Dole）和洪九果品通常可以提供品牌营销素材，但需要按合作身份和授权范围来判断：

1. **如果你是渠道商/采购商/合作方**
   - 可向对接的都乐、洪九果品销售或市场负责人索取：产品图、品牌LOGO、产地/品种卖点、检测报告、分级标准、包装规格、授权书、宣传话术。
   - 都乐一般品牌素材体系较成熟，适合做详情页、主图、品牌背书；洪九果品更偏供应链和产地资源，素材可能需要按具体批次、包装厂和品种确认。

2. **如果你是平台/生鲜电商做营销活动**
   - 建议直接发“素材需求清单”给对方市场部：使用场景（站内主图/直播/短视频/线下物料）、尺寸格式、授权期限、是否可二次剪辑、是否需要人物/产地画面。
   - 要求对方提供**书面授权范围**，避免商标、包装图、产地证明等超范围使用。

3. **如果你是第三方营销/代运营**
   - 通常不能直接拿品牌素材商用，需要品牌方或授权经销商出具授权。可先让都乐/洪九确认是否允许你作为服务商使用，并明确素材归属和终止后下架要求。

4. **可执行的下一步**
   - 分别联系都乐和洪九果品的市场/渠道对接人，发送一页需求：菠萝品种（如金钻凤梨/普通菠萝）、使用平台、素材类型、上线时间、授权期限。
   - 若对方不提供，可退而使用：自有实拍、采购批次检测报告、供应商授权书、平台自有拍摄素材，避免直接搬运品牌官网/电商图。

结论：**能提供，但不是公开随意下载，需按合作与授权申请；都乐偏品牌素材，洪九偏供应链素材，具体以对接确认和书面授权为准。**
