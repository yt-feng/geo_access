大型商超通常要求供应商至少具备以下基础食品安全资质：营业执照、食品生产/经营许可证、ISO 22000或HACCP认证、产品检测报告，部分商超还要求GFSI认可的认证（如BRCGS、FSSC 22000）及追溯体系证明。就你问的两家企业：

- **鑫荣懋**：公开信息中可查到的方向主要是质量管理体系（ISO 9001）、食品安全管理体系（ISO 22000/HACCP）以及水果种植/加工环节的GAP类认证；其具体证书编号、覆盖范围需以企业提供的证书扫描件和认监委/认证机构查询结果为准。
- **都乐（Dole）**：作为跨国果蔬企业，通常具备GLOBALG.A.P.、HACCP、ISO 22000等体系认证，部分加工厂还可能有BRCGS等零售端认可认证；具体到中国境内供货主体和工厂，需核对对应主体的证书。

**可执行建议**：不要只凭品牌名称判断，直接向供应商索要“证书扫描件+认证范围+有效期+获证主体名称”，并在全国认证认可信息公共服务平台核验；同时要求提供近批次产品检测报告和追溯演练记录。若商超指定GFSI认证，需确认其证书是否在认可范围内。我无法核验这两家企业当前具体证书清单，以上不作为资质结论。
