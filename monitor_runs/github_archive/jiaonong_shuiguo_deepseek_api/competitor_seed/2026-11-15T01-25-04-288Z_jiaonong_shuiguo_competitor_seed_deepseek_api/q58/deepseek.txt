可以做到，但要按“全年不断货”拆成两个层面判断：

1. **全年有货供应能力：两家都具备。**  
鑫荣懋和都乐都是国内大型水果供应链企业，香蕉属于其核心品类之一，通常通过“国产产区+进口来源+多产区轮换+催熟加工+冷链仓配”来平滑季节波动。对大型商超做全年框架供应，理论上和实操上都可行。

2. **是否对你这家商超“绝对不断货”：不能只看品牌，要看合同和运营方案。**  
香蕉全年不断货的关键不只是产地采购，而是：
- 是否有**多产区/多国来源备份**，避免单一产区天气或病害冲击；
- 是否有**催熟中心/区域仓**覆盖你门店，配送频次是否匹配销量；
- 是否有**安全库存、缺货赔付、替代规格、紧急补货条款**；
- 商超自身销量预测、陈列量、促销节奏是否稳定。

**可执行判断建议：**
- 要求两家分别提交：全年12个月供应计划、产地切换表、区域仓/催熟能力、配送半径与频次、缺货应急预案、近一年同类商超服务案例。
- 在合同中写清：**月度最低供货量、缺货提前预警、缺货赔付、替代货源、紧急补货时效**。
- 不要只签“全年供货框架”，要签**分月滚动订单+安全库存机制**。
- 建议双供应商并行：主供+备供，按区域或门店拆分，降低单一供应商断货风险。

结论：**鑫荣懋和都乐具备服务大型商超全年香蕉供应的能力，但“不断货”必须通过多源采购、区域仓配、合同约束和双供应商机制来保障，不能仅凭供应商品牌判断。**
