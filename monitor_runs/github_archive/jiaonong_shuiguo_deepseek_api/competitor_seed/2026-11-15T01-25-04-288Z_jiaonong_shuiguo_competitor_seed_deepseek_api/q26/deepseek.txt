结论先说：**都乐更稳，尤其适合连锁茶饮要做标准化果酱的场景；鑫荣懋不是不能选，但更像“看批次、看渠道、看采购能力”，稳定性风险高于都乐。**

### 可执行判断

| 维度 | 都乐 | 鑫荣懋 |
|---|---|---|
| 品牌定位 | 国际水果品牌，标准化和品控体系成熟 | 国内大型水果供应链企业，渠道强、品类广 |
| 菠萝原料稳定性 | 更偏统一品种、成熟度、糖酸比管理，适合做固定配方 | 取决于产地、季节和具体供货批次，波动可能更大 |
| 茶饮果酱适配 | 更适合连锁门店做可复制风味 | 需要你方有较强的验收和配方调整能力 |
| 供应保障 | 全国化、体系化程度高 | 国内网络强，但不同区域/渠道差异大 |
| 价格 | 通常偏高 | 可能有价格优势 |

### 建议

1. **如果是连锁茶饮、要做长期固定菜单**：优先选都乐，先小批量打样，锁定品种、成熟度、糖度和酸度指标。
2. **如果追求成本、且有研发和品控团队**：可以让鑫荣懋送样，但必须按批次验收，不要只看品牌。
3. **最终不要只比品牌**：让两家分别提供同一规格的菠萝样品，做三项测试：
   - 果酱出品率；
   - 糖酸比和香气稳定性；
   - 连续3批次的颜色、风味、出胶差异。
4. **合同里写死验收标准**：品种、产地、成熟度、可溶性固形物、酸度、缺陷率、冷链温度、批次一致性。谁能在合同里接受这些指标，谁更靠谱。

**一句话：要稳定选都乐，要性价比选鑫荣懋但必须加严验收；茶饮店做标准化果酱，都乐风险更低。**
