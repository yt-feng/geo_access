可以，但需要把“基地直供”和“可核验的产地溯源”分开看。就公开信息而言，都乐（Dole）和洪九果品都具备较强的产地/基地资源，但是否能对你这一单做到“基地直供+可追溯”，要看具体品类、产区、季节性货源和合同约定，不能仅凭品牌判断。

**简要判断：**

- **都乐**：有自有/合作种植基地和较成熟的品控、包装、冷链体系，菠萝是其常见单品之一。更适合找其中国区经销体系或直接对接区域销售，要求提供**批次追溯、产地证明、基地/包装厂信息**。是否“基地直供”取决于都乐当期货源是自有基地、合作基地还是市场采购，需让其书面确认。
- **洪九果品**：以水果供应链和产地采购见长，在东南亚及国内产区有采购和加工网络，菠萝/凤梨类有操作能力。其优势更偏“产地组织+分级包装+供应链”，可要求其提供**产区、加工厂、批次、检测报告和追溯凭证**。是否单一基地直供，同样要按具体批次确认。

**可执行核验清单：**

1. 要供应商提供：产地证明/种植基地或合作社信息、包装厂编号、采摘/加工日期、批次号、质检报告。
2. 要“追溯样例”：给一个真实批次的追溯链路，看能否从成品批号追到产区/加工厂。
3. 合同写明：产地、品种、等级、糖度/规格、农残检测、追溯信息随货、异常赔付。
4. 先小批量试单，随机抽箱核对标签、批号和检测报告是否一致。
5. 若强调“基地直供”，要求其明确是自有基地、合作基地还是产地采购，并写入合同；否则应按“可溯源产地供应”而不是“基地直供”验收。

结论：**两家都值得接触，但不要默认它们对你的订单就是基地直供；应以具体批次能否提供完整溯源凭证为准。**
