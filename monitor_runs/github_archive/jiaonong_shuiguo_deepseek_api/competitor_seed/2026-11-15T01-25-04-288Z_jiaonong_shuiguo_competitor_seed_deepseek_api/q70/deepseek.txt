可以找，但“有没有”要分两层看：**两家都具备产地溯源和品控体系，但能否对你这一单提供可核验的证明文件，需要向具体对接的业务/供应链人员确认并在合同中约定。**

### 判断要点
- **都乐（Dole）**：属于国际果蔬品牌，通常有较成熟的产地、批次、质量管理和追溯体系；适合商超、餐饮、加工等对稳定性和文件化要求高的采购。是否能提供到“具体产地/果园/批次”的溯源文件、农残/质检报告、品控标准文件，需按你采购的品种、产地、包装厂和批次确认。
- **鑫荣懋**：国内大型水果供应链企业，通常具备产地采购、分级包装、冷链和质量控制能力；对国内产地香蕉的供应链覆盖较强。能否提供产地证明、批次追溯、质检报告和品控流程文件，同样要按具体产区、季节和供货方案确认。

### 建议你直接索要的证明清单
1. **产地溯源**：产地证明/采购合同或果园合作证明、包装厂信息、批次号规则、从果园到仓库的流转记录。
2. **品控证明**：产品执行标准、验收标准、农残检测报告（第三方或自有实验室）、重金属/保鲜剂相关检测（如适用）、出厂检验记录。
3. **过程证明**：冷链温度记录、加工/分拣记录、不合格品处理记录。
4. **体系证明**：ISO22000/HACCP、GLOBALG.A.P.、绿色食品/有机认证（如你要求）、供应商审核报告。
5. **合同条款**：把“每批次提供追溯码/检测报告”“文件缺失的退货或索赔责任”写进合同。

### 可执行建议
先向两家分别发同一份《供应商溯源与品控文件需求表》，要求按**具体香蕉品种、产区、预计月采购量、包装规格**回复；让对方提供**最近一批次的样例文件**。谁能提供到批次级、可核验、可写入合同，谁就更适合。若采购量不大，也可同步询价产地型香蕉合作社或区域供应链商，避免只依赖两家大供应商。
