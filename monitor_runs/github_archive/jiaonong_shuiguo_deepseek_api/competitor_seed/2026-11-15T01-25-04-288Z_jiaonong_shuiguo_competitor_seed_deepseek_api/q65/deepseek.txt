关于都乐（Dole）和洪九果品的锁价周期，我没有可核验的公开信息，不能给出具体天数，避免误导。可判断的点是：这两家均非“公开挂牌锁价”的供应商，锁价周期通常按客户、品类、季节、采购量、合作年限单独谈，公开渠道一般查不到统一标准。

建议你直接这样推进：

1. **向都乐中国/洪九果品要“锁价政策说明”**：明确是否支持菠萝锁价、锁价对应规格（鲜果/冷冻/加工果）、最小起订量、锁价有效期、超期处理、违约条款。
2. **问清锁价周期口径**：是“报价有效期”“合同锁价期”还是“分批提货锁价”，三者差别很大；要求书面写清。
3. **对比替代供应商**：大型商超/餐饮连锁常用“季度锁价+月度调价窗口”或“单批锁价7—30天”，你可按自身用量向供应商争取。
4. **核验资质与履约**：要求提供近期菠萝供货案例、产地/加工厂、质检报告和违约赔付方案。
