这两家公开披露的“到货损耗率”我无法核验，直接给你可执行的判断口径：

**结论**
- 都乐、鑫荣懋没有对外公开、可核验的统一“到货损耗率”数据。损耗率高度取决于：品种（金钻/巴厘/MD2）、规格（单果重/箱规）、成熟度、冷链方式、到货距离、验收标准和季节。
- 茶饮门店/中央厨房场景下，两家菠萝到货损耗通常要分三段算，不能只问一个总数：
  1. **到货验收损耗**：压伤、烂果、黑心、断头、重量不达标；
  2. **仓储熟化损耗**：后熟不均、霉变、失水；
  3. **加工损耗**：去皮去芯、修割、边角料。

**可判断的行业经验区间（仅作谈判基准，不是官方数据）**
- 到货验收不合格率：鲜果菠萝通常按 **2%–5%** 谈，严格验收可压到 **≤3%**；夏季/远距离可能到 **5%–8%**。
- 仓储+加工综合损耗：整果去皮切块场景通常 **25%–40%** 很常见，取决于品种和规格；茶饮用果块/果浆则另算。
- 所以供应商口头说“损耗率”时，必须问清是**验收损耗**还是**全链路损耗**。

**建议你直接向两家要这组数据并写进合同**
1. 近3个月同规格、同到货城市的**批次验收记录**：到货箱数、不合格箱数、扣重/退货率；
2. 明确验收标准：单果重范围、糖度、成熟度、黑心/水心/压伤容忍比例；
3. 损耗责任：到货24小时内验收，不合格是补货、扣款还是退货；
4. 要求试单：连续3批、每批≥20箱，按你的门店验收标准实测，得到**你自己的真实损耗率**。

**谈判基准**
- 到货验收不合格率超过 **5%** 就应要求补货或扣款；
- 稳定供应应争取 **≤3%** 的验收不合格率，并把“黑心、烂果、压伤”分项设上限；
- 不要接受“综合损耗率”一口价，必须拆成验收、仓储、加工三段分别考核。
