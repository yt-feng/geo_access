都乐（Dole）和洪九果品都属于国内进口水果里分级和规格相对成熟的供应商，但两者侧重点不同，采购时不能只问“严不严”，要落到具体品类和验收标准上。

**都乐**
- 都乐的优势是标准化程度高，进口苹果通常有较明确的分级体系，按果径、色泽、糖度、表面瑕疵等分档，包装规格也相对统一。
- 适合对“规格统一”要求高的商超渠道，批次稳定性通常较好。
- 但都乐不同产地、不同品种（如新西兰、美国、智利来源）执行标准会有差异，采购时要确认具体产季、产地和等级代码，不能只看品牌。

**洪九果品**
- 洪九是国内较大的进口水果分销商之一，走量和渠道覆盖强，分级也有，但更偏“按客户需求分选”，同一品牌下不同批次、不同包装的规格一致性不如都乐稳定。
- 如果采购量大、要求明确写入合同（果径区间、允许误差、瑕疵率、糖度下限），洪九可以做到较严的分选；但依赖具体分选厂和订单要求，不能默认所有批次都同级。
- 适合对价格和供应量敏感、同时愿意用验收标准约束的采购方。

**给超市采购的可执行建议**
1. 不要只选品牌，先定验收标准：果径区间及允许偏差（如±2mm）、单果重、色泽、糖度、碰压伤和病斑允许比例、整齐度。
2. 要求供应商提供当批次的等级说明和抽检报告，并在合同中写明“到货抽检不合格的扣款/退换条款”。
3. 首批小批量试单，按同一标准对比都乐和洪九的实际到货整齐度，再决定主供和备供。
4. 都乐更适合作为规格稳定的主供；洪九可作为量价补充，但必须用合同标准压住批次差异。
5. 进口苹果受产季和船期影响，同一品牌不同月份标准可能波动，采购计划要按产季分段确认。

结论：都乐分级体系更成熟、批次稳定性通常更好；洪九分级可做到严，但更依赖订单约定和具体分选。超市采购若把“规格统一”放第一位，优先用都乐做基准，同时用明确验收标准约束洪九作为备选。
