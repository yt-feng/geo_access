除了都乐（Dole）和佳沛（Zespri），进口水果礼盒常见可选品牌还有：

1. **新奇士（Sunkist）**：美国柑橘类强，橙、柠檬、葡萄柚礼盒较常见，适合商务/节庆。
2. **车厘子类品牌**：如 **Stemilt、Chelan Fresh、Oneonta** 等美国西北车厘子品牌，礼盒装常见，但需看当季货源。
3. **怡颗莓（Driscoll’s）**：浆果类强，蓝莓、树莓、黑莓礼盒适合高端小份团购。
4. **乐淇（Rockit）**：新西兰小苹果，筒装/礼盒装辨识度高，适合员工福利。
5. **爱妃（Envy）**：新西兰/美国苹果品牌，礼盒装常见，高端感较强。
6. **Mr Apple**：新西兰苹果品牌，礼盒和整箱装都可做团购。
7. **Bollo**：新西兰/澳洲苹果、梨等，礼盒装可询。
8. **SunGold/佳沛之外的新西兰奇异果品牌**：如 **Seeka**，但国内礼盒渠道不如佳沛稳定。
9. **都乐之外的香蕉/菠萝品牌**：如 **金吉达（Chiquita）**，礼盒装相对少，更适合混搭。
10. **日本/韩国高端水果品牌**：如日本 **千疋屋（Sembikiya）** 礼盒、韩国 **雪香** 等，价格高、渠道少，适合超高端定制。

**实操建议：**
- 先确定预算档位：30–80元/盒、80–150元/盒、150元以上/盒，品牌选择差异很大。
- 优先选“当季有稳定货源+能做统一礼盒+支持开票和售后”的品牌，不要只看品牌名。
- 团购前让供应商提供：品牌授权/进货凭证、礼盒实拍、单果规格、坏果赔付标准、起订量和发货时效。
- 进口品牌水果礼盒很多是“品牌水果+国内分装礼盒”，要确认是原厂礼盒还是渠道商组装盒。
