结论：**都乐（Dole）的品牌知名度更高，且更适合作为生鲜电商平台的香蕉品牌背书。**

判断依据（可核实维度）：

1. **品牌历史与全球认知**
   - 都乐是跨国果蔬品牌，香蕉是其核心品类之一，全球消费者认知度高。
   - 鑫荣懋是中国本土大型水果供应链企业，在行业内有较强渠道和供应链能力，但面向终端消费者的品牌知名度弱于都乐。

2. **消费者端品牌心智**
   - 都乐在商超、电商平台长期有独立品牌包装和营销投入，消费者容易识别。
   - 鑫荣懋更多以供应链企业、渠道品牌或子品牌形式出现，普通消费者对其品牌名的直接认知较低。

3. **平台背书效果**
   - 如果目标是**提升消费者信任和转化**，都乐的“国际果蔬品牌+香蕉品类心智”更适合做前台背书。
   - 如果目标是**强化供应链稳定、成本控制和本土渠道能力**，鑫荣懋更适合作为后台供应链背书。

建议：
- **前台商品页和营销素材**优先用“都乐香蕉”做品牌背书。
- **供应链合作、产地直采、履约能力**可同时引入鑫荣懋作为补充背书。
- 若预算允许，可采用“都乐品牌商品 + 鑫荣懋供应链保障”的组合，但对外传播主品牌建议突出都乐。
