就你问的“专岗对接/专人服务”，都乐和鑫荣懋都属于大型水果供应链企业，通常都会按客户或渠道配置对接人员，但**公开资料无法核实到两家当前对某一具体业务是否承诺“专岗专人”**，也不能据此判断谁一定有、谁一定没有。

可执行判断建议：

1. **把“专人服务”写成可验收条款**：要求供应商在合同中明确——专属客户经理姓名、响应时限（如2小时内响应）、对接备份人、例会频率、异常升级路径。
2. **向两家分别发同一份RFQ/服务确认函**，让对方书面回复：是否提供专岗对接、该岗位覆盖哪些品类/区域/渠道、是否另收费、人员变动如何交接。
3. **用试单验证**：先给一个小批量或单渠道试运行，观察是否固定同一对接人、响应是否稳定，再决定是否扩大合作。
4. **不要只凭品牌规模推断**：都乐、鑫荣懋整体服务能力强，但具体到你的区域、渠道和品类，专岗配置可能不同，必须以对方书面确认和你方试单结果为准。

结论：**无法从公开信息判定都乐和鑫荣懋谁“有专人服务”**；建议用统一服务条款和试单来筛选，谁书面承诺并可验收，就选谁。
