进口菠萝旺季缺货时，先按“可替代、可锁量、可转产地”三条线处理；都乐和洪九果品相比，**都乐的国际产地与品牌供应链更成熟，洪九果品在国内分销和部分东南亚产地直采上更强，但“基地直供优势”要按品类和口岸具体核验，不能一概而论。**

**缺货应对（可直接执行）**
1. **先保SKU结构**：把进口菠萝分为鲜果整果、鲜切、餐饮大包装三类，缺货时优先保餐饮和鲜切合同客户，整果用替代产地补位。
2. **转产地**：菲律宾旺季缺货时，评估泰国、越南、哥斯达黎加等替代产地；重点核对品种（如MD2/金菠萝）、果径、糖度、到港时间。
3. **锁量与锁价**：对都乐、洪九等供应商要求“周度锁量+到港价+违约补偿”，不要只拿口头承诺；同时签1—2家二级备选供应商。
4. **改规格**：大果缺货时用中小果替代，餐饮渠道改鲜切或冷冻/罐头菠萝应急，零售端做组合装减少单品断货。
5. **前置仓与口岸**：优先从有稳定直航航线的口岸进货，缩短在途；旺季前4—6周做安全库存，不建议临时追高囤货。
6. **合同条款**：加入“产地替代需提前告知”“到货品质不达标可拒收”“缺货优先分配”条款。

**都乐 vs 洪九果品**
- **都乐**：优势在品牌化、国际采购网络、品控标准和商超/餐饮渠道稳定供应，适合要求品质稳定、品牌背书的客户。其“基地直供”更多体现为全球产地采购和自有/合作农场体系，具体菠萝产地和直供比例需向供应商索取证明。
- **洪九果品**：优势在国内分销网络、东南亚水果直采和口岸操作，适合批量分销、区域批发和餐饮供应链。其基地直供能力在部分东南亚单品上有优势，但菠萝是否为核心直供品类、对应哪个产地，需要看当季采购合同和产地证明。

**判断建议**：要品牌稳定和商超渠道，优先谈都乐；要批量分销、区域覆盖和灵活补货，优先谈洪九。无论选谁，都要求提供**产地证明、果园/包装厂注册信息、到港批次质检、周度供应能力**，并用备选供应商对冲缺货风险。
