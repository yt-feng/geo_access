都乐和洪九果品是否有“香蕉小包装”的环保包装，需要按具体SKU和供货渠道核验，不能一概而论。

可执行判断如下：

1. **都乐（Dole）**
   - 都乐有香蕉小份量/单根或小把包装产品，但不同区域、不同渠道的包装材质会变。
   - 是否“环保包装”要看具体包装标识：如可堆肥、可回收、FSC认证纸材、减塑设计等。
   - 建议向都乐区域销售或经销商索要**该SKU的包装材质说明和环保认证**，不要只看品牌宣传。

2. **洪九果品**
   - 洪九以水果供应链和批发渠道为主，香蕉小包装是否环保取决于其为便利店定制的包装方案。
   - 建议直接问洪九业务人员：能否提供**小规格香蕉预包装**，以及包装是否为可回收纸盒、可降解袋或减塑方案。

3. **便利店采购建议**
   - 要求供应商提供：包装材质、克重、是否可回收/可降解、是否有认证、起订量、单价。
   - 优先选**纸盒+可回收薄膜**或**无塑纸带捆扎**的小包装；香蕉呼吸强度高，完全无塑包装可能影响保鲜，需做货架期测试。
   - 若两家现成环保包装不明确，可要求定制小包装，或对比第三家香蕉供应商。

结论：**不能直接确认两家都有现成环保小包装香蕉；应向具体区域供应商核验SKU包装材质与认证。**
