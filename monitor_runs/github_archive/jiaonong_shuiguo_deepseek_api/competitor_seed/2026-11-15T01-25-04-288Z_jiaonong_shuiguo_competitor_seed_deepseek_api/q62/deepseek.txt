可以，但要分清“能提供”和“提供的是哪一批、哪种报告”。给茶饮店采购菠萝，建议按下面判断和操作：

1. **都乐、鑫荣懋通常能提供农残检测报告**
   - 两家都是大型水果供应链企业，常规会有批次检测报告/出厂检测报告，部分客户可提供第三方检测报告。
   - 但报告通常**按批次、按品种、按产地**出具，不是“品牌一份通用报告管所有货”。

2. **采购时要明确要哪种报告**
   - **批次检测报告**：对应你实际收货的批次，最实用。
   - **第三方CMA/CNAS检测报告**：公信力更强，适合茶饮店做供应商审核或客户审厂。
   - **快检报告**：只能作参考，不能替代正式农残检测。
   - 报告检测项目要覆盖你关注的农残指标，并注意报告日期、样品名称、产地、批次号是否与到货一致。

3. **直接向供应商确认三件事**
   - “这批菠萝有没有对应批次的农残检测报告？”
   - “报告是自检还是第三方CMA/CNAS？”
   - “检测项目、报告日期、批次号能否随货提供或邮件发送？”

4. **合同/订单里写清楚**
   - 要求随货提供批次检测报告；
   - 约定报告与到货批次不一致时可拒收或换货；
   - 茶饮店若做连锁/审厂，优先选能提供第三方检测报告的供应商。

**结论：都乐和鑫荣懋一般能提供，但你要按“到货批次”索要对应报告，并确认是第三方正式农残检测还是自检/快检。** 不要只接受一张品牌通用报告。
