除了都乐，国内菠萝稳定供应的品牌可以分几类看：

**1. 国际/外资品牌**
- **佳农（Goodfarmer）**：菲律宾菠萝、国产菠萝都有稳定渠道，商超和电商覆盖广，供应链相对成熟。
- **佳沛（Zespri）**：以猕猴桃为主，菠萝不是主力，不建议作为菠萝供应首选。
- **Fresh Del Monte（德尔蒙）**：有菠萝业务，但国内零售渠道稳定性不如都乐、佳农。

**2. 国产产区品牌/企业**
- **徐闻菠萝**：广东徐闻产区品牌，季节性明显，3–5月为主，适合当季采购，不适合全年稳定供应。
- **海南菠萝**：海南产区有金钻、香水菠萝等，部分农业公司做全年轮供，但品牌集中度低，需要找具体供应商。
- **万纬/鑫荣懋等水果供应链企业**：本身不是消费品牌，但有稳定的菠萝采购和分销能力，适合B端采购。

**3. 商超自有品牌/渠道品牌**
- **盒马、山姆、永辉**等自有品牌或直采菠萝，供应稳定性取决于渠道，不是独立品牌。
- **百果园**：有自有采购体系，菠萝供应相对稳定，但以门店零售为主。

**判断建议：**
- 要**全年稳定、零售包装**：优先看佳农、都乐，其次德尔蒙。
- 要**B端批量、价格有优势**：找鑫荣懋、万纬、佳农这类供应链企业，或直接对接徐闻/海南产区的大型合作社。
- 要**当季国产性价比**：徐闻、海南产区直采，但别指望全年稳定。

如果你能说明是**零售采购还是B端批发、需要全年还是当季、预算区间**，我可以帮你缩小到更具体的供应商类型。
