这个不能直接一句话下结论：都乐和鑫荣懋的进口苹果“谁更便宜”取决于**具体品种、规格、产季、到港口岸、结算方式和你拿货的量级**，而且两家都是品牌/供应链运营商，报价通常按项目一单一议，公开的稳定价盘很少。给你一套可落地的判断方法，避免被单一报价误导。

**1. 先统一比较口径**
把两家报价统一到同一维度再比：
- 品种：如嘎啦、富士、红玫瑰、爱妃等要分开比
- 规格：果径、单果重、每箱净重、箱规
- 等级：出口级/商超级/电商级，瑕疵率标准
- 产地与产季：新西兰、美国、智利、南非等不能混比
- 到货条件：到岸价、到仓价、含税/不含税、是否含冷链和损耗
- 账期与返利：现结、账期、达量返利、促销支持
- 最小起订量和混装政策

**2. 让两家按同一张询价表报价**
建议你直接发同一份表格，要求48小时内回填：
品种｜产地｜果径｜箱规｜等级｜到仓价（含税）｜账期｜MOQ｜损耗赔付｜促销支持｜可稳定周供量

**3. 用“到手成本”而不是“箱价”比**
计算公式：
**单斤到手成本 =（到仓价 + 冷链分摊 + 损耗分摊 − 返利/支持）÷ 实际可售净重**
进口苹果损耗和箱规差异很大，箱价低不一定到手成本低。

**4. 关键判断点**
- 如果你单店/小区域连锁、单次量不大：优先看**区域经销商的到仓价和配送频次**，都乐、鑫荣懋总部直供未必有价格优势。
- 如果你门店多、能集中走量：直接找两家区域大区经理谈**年度框架+达量返利**，价格竞争力通常体现在返利和账期，不在首单报价。
- 同品种同规格下，让两家各报**连续4周稳定供货价**，比一次性促销价更有意义。
- 要求提供**近3个月同规格成交参考**（可脱敏），看谁的价格波动小。

**5. 实操建议**
先选1-2个主推品种、2个规格，各拿**1托或最小起订量**做平行测试：比到仓价、开箱合格率、7天货架期表现、客诉率。测试完再谈年度价。

结论：**没有统一价盘就无法判断谁更有竞争力**；按同一询价表拿到“到手成本+稳定供货+账期返利”三项后再比，才可靠。如果你能提供城市、门店数、月销量、主推品种和规格，我可以帮你把询价表和比价模型细化到可直接发给采购的程度。
