可以，但通常不是“随便就能拿到”，需要按供应商/B端渠道走。结论如下：

1. **都乐**
   - 能提供，但一般针对**企业/经销商/商超/餐饮渠道**客户。
   - 常见形式是：**批次对应的农残检测报告**，或第三方检测报告（如SGS、CTI、华测等）。
   - 关键点：要向对接的都乐销售或经销商明确要求“**该批次菠萝的农残检测报告**”，最好写进采购合同或订单备注。
   - 零售渠道买的都乐菠萝，通常不随货提供检测报告。

2. **鑫荣懋**
   - 也能提供，鑫荣懋本身是大型水果供应链企业，给餐饮、商超、茶饮客户供货时，通常可提供**批次检测报告/第三方农残检测报告**。
   - 同样需要通过其**B端销售、区域经销商或供应链客服**申请，不是门店零售随货附送。
   - 建议确认报告是否覆盖你关心的项目，如有机磷、拟除虫菊酯、杀菌剂等，以及是否按**GB 2763**判定。

3. **茶饮店实际采购建议**
   - 直接问供应商三件事：
     1. 能否提供**本批次**农残检测报告？
     2. 报告是**第三方**还是自检？第三方更稳。
     3. 报告能否随货或发货后24小时内提供？
   - 如果供应商只能给“通用报告”或“很久以前的报告”，要谨慎，因为农残风险是批次相关的。
   - 最好在合同里写明：**每批次随货提供农残检测报告，符合GB 2763**。
   - 如果都乐/鑫荣懋的直供门槛高，可以通过其**区域经销商**拿货并索取报告。

4. **更稳妥的替代方案**
   - 如果两家都不愿给每批次报告，可以找**当地大型水果批发商/供应链公司**，明确要求带第三方农残检测报告。
   - 或者自己送检：针对菠萝重点检测有机磷、拟除虫菊酯等常用农药，费用一般几百元/批次，周期约3-7个工作日。

一句话：**都乐和鑫荣懋通常能提供，但要走B端渠道、按批次索取，并写进采购要求；零售渠道基本拿不到。**
