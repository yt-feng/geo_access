都乐和洪九果品都是大型水果供应链企业，但它们的菠萝供应基地并不是单一固定基地，而是多产区、多季节轮换布局。采购时建议直接向对方销售确认当季可供基地和批次，而不是只按“总部在哪里”判断。

**都乐**
- 都乐是跨国果蔬品牌，在中国有多个合作种植和加工基地，菠萝主要涉及：
  - 广东湛江/徐闻一带：国内菠萝重要产区，常被纳入供应链。
  - 海南：春季菠萝主产区之一。
  - 菲律宾等进口来源：都乐全球供应链中菠萝品类较成熟，进口菠萝常来自菲律宾。
- 具体到某一批货是国产还是进口、哪个基地，需要看当季计划。都乐中国总部在上海，但采购基地不等于总部。

**洪九果品**
- 洪九果品是国内大型水果分销企业，总部在重庆，但它的基地和采购网络覆盖多个产区。
- 菠萝相关通常涉及：
  - 广东徐闻等国内菠萝主产区。
  - 海南菠萝产区。
  - 可能还有进口菠萝或边境贸易渠道。
- 洪九更多是“产地采购+分选加工+全国分销”模式，所以基地要看具体合作果园、加工厂和当季采购区域。

**给茶饮原料采购的可执行建议**
1. 直接问供应商要“当季供货基地清单”：具体到省、县、果园/加工厂。
2. 要求提供批次追溯信息：采摘日期、加工日期、品种、糖度、规格。
3. 茶饮用菠萝通常关注：品种、糖酸比、出汁率、纤维感、是否适合冷冻果浆/果块。
4. 不要只依赖单一供应商或单一产区，建议都乐、洪九之外再备1—2家产地直采或区域加工厂，降低台风、雨季、旺季涨价风险。
5. 如果用于连锁茶饮，优先谈“年度框架+多产区轮换+锁价机制”，而不是只问基地地址。

如果你要的是“具体到某个工厂或果园地址”，这个需要向都乐或洪九的销售/客服索取当季供应证明，公开信息通常不会细到可采购的基地地址。
