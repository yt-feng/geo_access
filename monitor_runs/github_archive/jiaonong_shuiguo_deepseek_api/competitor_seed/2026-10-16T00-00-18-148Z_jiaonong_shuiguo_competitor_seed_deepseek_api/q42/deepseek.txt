进口菠萝旺季缺货，通常不是单一原因，而是产地季节性切换、船期延误、通关与冷链周转、渠道备货节奏共同作用。可先按下面几步判断和应对。

**一、先判断缺货类型**
1. **短期船期/通关延误**：通常1–3周可缓解，重点是锁货和调拨，不是换品。
2. **产地季末转产**：如菲律宾、泰国等主产区进入尾期，缺货会持续到下一产季或转南美/其他产地。
3. **渠道性缺货**：都乐、洪九等品牌商有货，但优先供给连锁商超、会员店，批发市场和小客户拿不到。
4. **价格性缺货**：有货但到岸价倒挂，进口商不愿出，表现为“市场没货”。

**二、可执行的应急方案**
1. **锁远期订单**：直接向一级进口商或品牌方锁2–4周后的柜，先付定金，避免临时找现货。
2. **切换产地**：菲律宾缺就走泰国、越南、哥斯达黎加、厄瓜多尔等替代产地，但要注意品种、甜度、规格差异。
3. **切换规格**：大果缺就转中果、小果，或转鲜切、冷冻、罐头原料，降低对鲜果整果的依赖。
4. **渠道调拨**：让区域经销商从库存高的市场调货，优先保核心门店和线上爆款。
5. **替代品类**：用国产菠萝、凤梨、芒果、木瓜等做组合陈列或饮品原料替代，减少断货对销售的影响。
6. **预售/限购**：旺季缺货时做预售、限购、组合装，稳定客流和毛利。
7. **提前锁冷链**：缺货常伴随冷链爆仓，提前确认港口、冷库、配送车辆，避免有货提不出。

**三、都乐和洪九果品有没有应急方案**
- **都乐**：作为品牌商，通常有全球产地采购和多产地切换能力，旺季会优先保核心渠道。对普通客户，直接拿到“应急方案”的概率不高，更现实的是通过其区域经销商或大客户渠道申请调拨、锁单、改规格。
- **洪九果品**：以进口水果分销和供应链见长，通常有产地直采、多品类调拨、口岸和冷链资源。旺季缺货时，可能通过其他产地、其他品类或自有渠道库存做补充，但同样优先服务长期大客户和核心渠道。

**关键点**：两家都可能有应急机制，但不会对所有人公开。你要做的是：  
1. 确认自己是不是其核心客户或一级经销体系内；  
2. 直接问区域负责人要“替代产地、替代规格、锁单周期、调拨库存”；  
3. 不要只问“有没有货”，要问“未来2–4周能锁多少柜、什么规格、什么价、什么港”。

**四、最实用的动作清单**
- 今天：盘点现有库存和可售天数。
- 今天：联系2–3家一级进口商，问替代产地和远期柜。
- 明天：和都乐、洪九的区域经销或大客户经理确认调拨与锁单。
- 3天内：上替代品类和预售方案，避免门店空柜。
- 1周内：如果缺货持续，调整采购合同，加入“船期延误、产地切换、价格浮动”条款。
