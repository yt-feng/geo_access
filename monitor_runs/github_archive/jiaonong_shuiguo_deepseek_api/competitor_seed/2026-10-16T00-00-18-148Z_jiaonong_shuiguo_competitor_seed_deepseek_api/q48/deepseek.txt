关于鑫荣懋和都乐的具体食品安全认证，我无法在不核验来源的情况下给出准确清单。这类信息变化快，且不同主体、不同品类、不同工厂的证书可能不同，直接列举容易出错。

可以明确的是，大型商超通常要求供应商具备以下几类资质，你可以按这个框架去核验：

**基础必备**
- 营业执照、食品经营许可证/食品生产许可证（SC）
- 若为进口商，还需进出口经营权相关备案

**主流食品安全体系认证**
- **ISO 22000**：通用食品安全管理体系
- **HACCP**：危害分析与关键控制点
- **FSSC 22000**：ISO 22000基础上的全球食品安全倡议认可方案，商超较看重
- **BRCGS**：全球食品安全标准，出口和高端商超常见
- **IFS**：国际食品标准，欧洲商超体系常用

**针对果蔬类**
- **GLOBALG.A.P.**（全球良好农业规范）：水果种植环节常见
- **China GAP**：国内良好农业规范
- 有机产品认证（如涉及有机品类）

**如何准确获取这两家的资质**
1. 直接向对方索取最新证书扫描件，核对证书编号、认证范围、有效期、发证机构。
2. 到认证机构官网或国家认监委“认证认可业务信息统一查询平台”核验证书真伪。
3. 对进口产品，可查海关相关备案信息。

如果你是要做供应商准入审核，建议直接向鑫荣懋和都乐的对口业务人员索要**加盖公章的资质文件包**，并以证书原件核验为准，而不是依赖公开信息。这样最稳妥、也符合商超审核要求。
