都乐（Dole）和洪九果品对下游客户的具体账期，通常不会公开统一标准，而是**按客户类型、采购量、合作年限、信用评级、品类和区域分别谈**。公开渠道一般查不到“固定账期天数”，所以不能直接给你一个准确数字。

可以判断的是：

1. **都乐（Dole）**
   - 属于国际品牌水果供应商，体系较规范。
   - 对大型商超、电商、连锁餐饮等大客户，可能有月结或一定账期；对中小客户通常偏预付款、款到发货或短账期。
   - 具体账期要联系都乐中国区销售或区域经销商，按你的采购规模和资质审批。

2. **洪九果品**
   - 是国内大型水果分销商，做香蕉等品类较多。
   - 对下游一般也是按客户资质给账期，常见会是现款、短账期或月结，但不同区域、不同子公司/办事处政策可能不一样。
   - 洪九曾出现财务和经营波动，合作前要特别关注其供货稳定性、履约能力和自身回款风险。

如果你要找“能提供账期服务的香蕉供应商”，建议直接这样筛选和谈判：

- 先明确你的采购量：每月多少车/多少吨/多少箱。
- 要求对方报价时同时给：**账期天数、起算方式、结算方式、逾期费用、是否要保证金/担保**。
- 优先找：一级批发商、大型水果供应链公司、区域总代、进口蕉一级货主。
- 常见账期谈判区间：
  - 新客户：现款、7天、15天较多；
  - 稳定大客户：30天常见；
  - 强势渠道或超大采购：可能谈到30—60天，但通常需要合同、担保或历史交易记录。

更实际的做法：
- 直接联系都乐中国和洪九果品当地销售，问“针对我们这种采购规模，能否做30天账期，需要什么条件”。
- 同时找2—3家区域香蕉供应链商比价，把账期作为核心条款谈。
- 不要只问“账期多久”，要问“账期怎么算、从哪一天起算、超过怎么处理”。
