菠萝的供应品牌比较分散，跟产地、季节和渠道关系很大。除了都乐（Dole），下面这些是市场上比较常见、供应相对稳定的品牌或来源，可以按你的渠道类型参考：

**国际品牌/大型果蔬商**
- **Del Monte（地扪）**：有菠萝及相关产品，鲜果在部分商超和进出口渠道能见到。
- **Fresh Del Monte**：与地扪相关，鲜菠萝在部分高端商超有稳定供应。
- **Fyffes**：主要做香蕉，也有菠萝等热带水果，欧洲渠道较多。
- **Chiquita（金吉达）**：以香蕉为主，部分市场有菠萝。
- **Total Produce / Dole 以外的欧美果蔬集团**：通过进口商进入国内，但品牌辨识度不如都乐。

**国内产地型供应商（更稳、更便宜）**
国内鲜菠萝其实主要看产地，不一定看品牌：
- **广东徐闻**：中国最大菠萝产区之一，徐闻菠萝供应商很多，适合走批发市场、电商、社区团购。
- **海南**：文昌、万宁、琼海等地菠萝，季节性强，冬春供应较好。
- **广西**：南宁、崇左等地也有菠萝，部分作为补充货源。
- **云南**：河口、西双版纳等地有少量菠萝，季节错峰。

**渠道品牌/自有品牌**
- **盒马**：有自有品牌或产地直采菠萝，供应相对稳定。
- **永辉**、**大润发**、**华润万家**：多有产地直采或合作供应商。
- **百果园**：门店有固定菠萝单品，供应链较稳定。
- **叮咚买菜**、**美团买菜**：有产地直采或合作基地，适合零售端。

**加工/罐头类品牌（如果你要的是加工品）**
- **欢乐家**
- **林家铺子**
- **真心**
- **果秀**
- **Dole、Del Monte** 也有罐头线

**怎么判断能不能稳定供应**
1. **看你是要鲜果还是加工品**：鲜果看产地和季节，加工品看品牌和工厂。
2. **看规格**：凤梨（金钻、台农）、普通菠萝、香水菠萝，供应逻辑不同。
3. **看渠道**：批发市场走产地供应商，商超走直采或经销商，电商走基地或代发。
4. **问清楚**：产地、品种、等级、全年还是季节性、起订量、冷链还是常温。
