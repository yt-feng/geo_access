都乐和鑫荣懋的**实际到货损耗率没有公开的权威统一数据**，我不能给你编一个具体百分比。原因：

- 损耗率不是品牌固定指标，而是按**批次、产地、季节、运输距离、到货城市、验收标准（成熟度/糖度/单果重/黑心/烂心/机械伤）**波动的。
- 都乐、鑫荣懋多为渠道供货，实际执行方可能是批发商、区域代理或加工厂，同一品牌不同供应商差异很大。
- 茶饮端通常用的是**菠萝果块/菠萝丁/冷冻菠萝/菠萝汁/果酱**，不同形态损耗口径完全不同：鲜果去皮损耗、解冻失水、汁损、过期报废，不能混着比。

**可执行的判断办法**

1. **先定验收规格**
   - 品种：如金钻凤梨/台农/巴厘
   - 单果重：如 1.2–1.5kg
   - 成熟度：几成熟到货
   - 缺陷容忍：黑心、烂心、裂口、机械伤各允许百分比
   - 形态：鲜果、去皮果块、冷冻果丁、果酱

2. **按“到货净可用率”算，而不是只听损耗率**
   - 到货总重
   - 扣包装、烂果、不可用果
   - 去皮去眼后净果肉重
   - 净可用率 = 净果肉重 ÷ 到货总重
   茶饮出杯更该看：**每公斤原料能出多少杯/多少毫升**。

3. **让供应商书面承诺并留样**
   - 要求提供近 1–3 个月到货验收记录
   - 约定超标扣款/退换
   - 首次合作先小批量试单，连续 3 批统计

4. **对比时统一口径**
   同一城市、同一季节、同一规格、同一验收人、同一称重方式。否则都乐和鑫荣懋的“损耗率”没有可比性。

**经验参考范围（仅作管理预期，不是品牌数据）**
- 鲜菠萝到货，整果不可用/严重损耗常见约 **2%–8%**，看运输和季节。
- 去皮去眼后净果肉率常见约 **45%–60%**，品种、成熟度、人工影响很大。
- 冷冻菠萝丁解冻损耗通常低于鲜果，但会有汁液流失，常见约 **3%–10%**。
