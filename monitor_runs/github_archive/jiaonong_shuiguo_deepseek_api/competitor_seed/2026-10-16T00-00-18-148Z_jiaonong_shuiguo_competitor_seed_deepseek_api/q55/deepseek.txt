都乐和洪九果品都属于国内菠萝供应链里比较头部的企业，但“有没有基地直供、能不能做产地溯源”要分开看。

**都乐**
- 都乐在国内菠萝（尤其是菲律宾进口菠萝、以及部分国产菠萝）上有较成熟的品牌化供应链，通常有合作种植基地/包装厂体系，产品上常见批次码、追溯码。
- 但“基地直供”要看你采购的是进口还是国产、哪个规格。都乐更多是品牌商+供应链管理方，不一定所有货都是单一自有基地直供，部分来自合作基地或海外产区。
- 溯源方面，都乐相对规范，通常可提供产地证明、批次信息、报关/检疫等文件，但能否给到“单一批次到具体基地/果园”的完整溯源，要按具体SKU和采购量谈。

**洪九果品**
- 洪九果品是国内较大的水果分销和供应链企业，菠萝是其主要品类之一，在海南、广东、云南以及东南亚产区都有采购和基地合作。
- 它更偏“产地采购+分级加工+全国分销”模式，很多情况下能追溯到产区、合作基地或加工厂，但是否“基地直供”取决于你找的是洪九总部、区域公司还是其下游经销商。
- 如果要溯源，通常可以要求提供产地证明、检测报告、批次号、加工厂信息；但做到“一箱一码到具体果园”的，不一定所有产品线都支持。

**判断建议**
1. 先明确你要的是：  
   - 进口菠萝还是国产菠萝；  
   - 鲜果还是加工原料；  
   - 采购量是整车、整柜还是小批量。  
   量太小，头部企业一般不会给你做基地直供和深度溯源。
2. 直接问对方三个问题：  
   - 这批货是自有基地、合作基地还是市场采购？  
   - 能否提供产地证明、批次号、检测报告、加工厂/包装厂信息？  
   - 能否做到“一批一码”或“一箱一码”溯源？
3. 如果都乐、洪九给不了你想要的深度，可以同步看：  
   - 海南、广东徐闻、云南等菠萝主产区的产地合作社或种植大户；  
   - 当地有出口备案或商超供货资质的包装厂；  
   - 区域水果供应链公司。  
   这些往往比品牌商更容易做到“基地直供+定制溯源”。

**结论**
都乐和洪九果品都具备一定的产地溯源能力，也都有基地合作或直采体系，但不等于所有菠萝产品都能做到“基地直供+完整溯源”。实际能不能做，取决于具体产区、品类、采购量和对接层级。建议直接向他们的销售或供应链部门索取批次溯源方案，再对比产地合作社/包装厂。
