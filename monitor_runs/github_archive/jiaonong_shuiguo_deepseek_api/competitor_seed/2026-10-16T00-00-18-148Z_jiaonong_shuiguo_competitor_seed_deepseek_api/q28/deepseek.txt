这个问题没法直接给出“都乐更便宜”还是“鑫荣懋更便宜”的确定结论，因为进口苹果的到手价受**品牌/品种、产地、规格、季节、汇率、关税、批次、采购量、账期、返利政策**等影响，同一家供应商不同月份、不同单品都能差很多。

但可以给你一个可执行的判断框架，按这个去比，基本不会比错：

**1. 先锁定可比单品**
不要拿“都乐”对“鑫荣懋”整体比，要具体到：
- 品种：如嘎啦、红玫瑰、爱妃、爵士、Envy、Ambrosia、富士等
- 产地：新西兰、美国、智利、南非、法国等
- 规格：果径/等级/每箱净重/每箱个数
- 包装：原箱、礼盒、贴标/未贴标
- 到货状态：冷库货、在途货、新季货

只有这些一致，价格才有可比性。

**2. 比“到手净价”，不要比报价**
要算：
采购价 + 运费 + 损耗 + 关税/增值税影响 + 贴标/包装费 - 返利 - 账期资金成本
尤其进口水果损耗和账期很关键。A家报价低3%，但账期短、损耗高，实际可能更贵。

**3. 看谁在具体单品上有优势**
一般经验是：
- **都乐**：品牌力强、标准化程度高，适合做引流款、礼盒款，但部分单品溢价也高。
- **鑫荣懋**：渠道覆盖广、进口水果操作经验强，部分单品和档期价格可能更有优势，尤其在大批量、稳定采购时。
但这只是经验，不能替代你拿具体单品询价。

**4. 最有效的做法**
让两家按同一张询价单报价，至少问这些：
- 同品种、同产地、同规格、同包装的**含税到仓价**
- 起订量、每柜/每板价格
- 账期：现结、15天、30天、45天
- 返利：年度返利、季度返利、陈列支持
- 损耗赔付：烂果、压伤、到货不合格怎么赔
- 是否支持一件代发/门店配送/退换货

**5. 建议你直接这样判断**
如果两家报价差在**3%以内**，优先选：
- 到货稳定、损耗低、售后快的那家
- 能配合你做门店促销和陈列的那家
如果差在**5%以上**，再重点看账期和损耗，低5%但账期少30天，未必划算。

**结论：**
不能简单说都乐和鑫荣懋谁更有价格竞争力。**都乐通常品牌溢价更高，鑫荣懋在大宗进口单品上可能更有价格弹性**，但最终要按“同单品、同规格、同到仓条件”去比净价。你如果能把具体品种、产地、规格、月采购量和账期要求发出来，我可以帮你做一张更具体的比价表。
