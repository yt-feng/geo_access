都乐和洪九果品对菠萝的锁价周期，公开渠道没有统一、稳定的官方披露，通常要按具体品类（鲜果/冻果/罐头原料）、产地（菲律宾、泰国、海南、广东等）、采购量、合同期限和当时行情一事一议。不能直接给出一个固定天数。

可判断的建议：

1. **都乐**
   - 都乐更多是品牌商/供应链方，鲜菠萝以进口菲律宾、泰国等为主。
   - 锁价一般不会面向所有客户公开标准，常见做法是：
     - 零售/商超渠道：按季度或按档期谈，可能有 1—3 个月的价格有效期。
     - 餐饮/工业客户：可能按月、按季度或按产季锁，具体看采购量。
   - 如果是冻菠萝、菠萝丁、菠萝汁等加工品，锁价周期可能更长，常见按季度或半年，但同样取决于工厂和订单量。

2. **洪九果品**
   - 洪九果品以水果分销为主，菠萝是其部分品类之一，但不同区域、不同基地和不同客户政策差异较大。
   - 对批发/渠道客户，常见是短期锁价，比如按周、按月，或按单批到货锁价。
   - 对大型商超、电商、餐饮连锁，可能谈到月度、季度框架价，但往往会带量、带保证金或浮动调整条款。

3. **实际怎么确认**
   - 直接找都乐和洪九果品的**区域销售或大客户经理**，问清楚：
     - 是鲜果还是加工品；
     - 锁价对应哪个产地和规格；
     - 锁价有效期；
     - 是否含运费、损耗、税率；
     - 超量/减量怎么调价；
     - 行情大幅波动时是否有重谈条款。
   - 如果对方只给口头锁价，建议写进合同：锁价周期、触发调价条件、违约处理。

4. **替代思路**
   - 如果都乐、洪九的锁价周期不够长，可以同时找：
     - 一级进口商/产地直采商；
     - 大型批发市场头部档口；
     - 菠萝加工厂（冻果、罐头原料）做季度/半年锁价；
     - 海南、广东徐闻、福建等国产菠萝产季供应商做产季锁价。
   - 国产菠萝通常更容易按产季锁价，进口菠萝受汇率、海运和产地天气影响，锁价周期往往更短。

结论：都乐和洪九果品没有公开统一的菠萝锁价周期，不能准确说“多少天”。一般鲜果偏短，按月或按季度；加工品偏长，可能按季度或半年。要拿到确定周期，必须向具体销售主体询价并写进合同。
