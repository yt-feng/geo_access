目前没有可核验的“认证清单”直接对比，所以不能简单说鑫荣懋和都乐谁“更全”。但可以给你一个可判断的框架：

**结论：两家都是大型商超常见的合格供应商，通常都能满足商超准入的食品安全认证要求；差异不在“谁更全”，而在你具体要进哪家商超、卖什么品类、走什么渠道。**

### 1. 商超通常要求哪些食品安全认证？
大型商超一般会分层次要求：

- **基础准入**：营业执照、食品经营许可证/食品生产许可证、产品检测报告、SC证、进口报关/检验检疫证明（进口品）。
- **体系认证**：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、GLOBALG.A.P.（农产品/果蔬常见）。
- **供应链与追溯**：可追溯体系、供应商审核、冷链记录、农残检测报告。
- **特定渠道**：山姆、Costco、盒马、永辉、华润万家、沃尔玛等，往往还会加验厂、飞行检查、年度审核。

### 2. 鑫荣懋和都乐的大致情况
- **都乐（Dole）**：国际水果品牌，全球供应链体系成熟，通常具备较完整的国际食品安全和农业规范认证，尤其适合进口水果、品牌化果蔬。
- **鑫荣懋**：国内头部水果供应链企业，服务国内大型商超和电商渠道经验丰富，通常也具备商超准入所需的食品安全、质量管理和追溯体系认证。

所以，**如果只是判断“能不能进大型商超”，两家一般都不是问题**。  
真正要比的是：

1. **你要进的具体商超**：不同商超认可证书不同。
2. **品类**：鲜果、鲜切、果汁、预包装食品，要求完全不同。
3. **认证范围**：证书是否覆盖你供货的工厂、产地、品类。
4. **证书有效性**：是否在有效期内、是否被商超列入认可清单。
5. **审核结果**：商超更看重现场审核、抽检合格率和历史质量记录。

### 3. 直接判断建议
你可以这样判断谁“更全”：

- 让两家提供**最新认证证书清单**；
- 对照目标商超的**供应商准入标准**逐项打勾；
- 重点看：**FSSC 22000 / BRCGS / HACCP / GLOBALG.A.P. / ISO 22000** 是否覆盖你的品类和工厂；
- 再看：**近一年第三方检测报告、商超审核记录、客诉和召回记录**。

### 4. 一句话建议
**不要问“谁更全”，要问“谁更匹配你要进的商超和品类”。**  
如果做进口高端水果，都乐的国际认证体系通常更占优势；如果做国内商超综合水果供应链，鑫荣懋的国内渠道适配和响应速度可能更强。最终以目标商超的准入清单和两家实际证书为准。
