都乐和洪九果品不是同一类供应商，直接比“性价比”要看你门店的定位和走量方式。可以这样判断：

**1. 都乐**
- 优势：品牌认知强、品控和标准化较好，消费者认这个牌子，适合做中高端陈列、礼盒、即食鲜切。
- 劣势：进货价通常更高，毛利空间相对小，更像“品牌引流/品质背书”品类。
- 适合：门店客单价较高、位置好、顾客对品牌敏感，或者你想用都乐做品质标杆。

**2. 洪九果品**
- 优势：以批发和供应链走量为主，价格通常更有竞争力，适合做促销、堆头、社群团购。
- 劣势：品牌终端认知不如都乐，不同批次、不同产区的品质稳定性要你自己盯，门店需要做分级销售。
- 适合：社区店、走量店、团购渠道，或者你想把菠萝做成高毛利引流单品。

**更实用的选法：**
- **想引流、做活动、拼价格**：优先看洪九，但必须验货、定标准。
- **想做品牌、鲜切、礼盒、稳定复购**：优先看都乐，但要把损耗和售价算清楚。
- **最稳的做法**：两家都少量试销 1—2 周，对比四个指标：
  1. 到店合格率
  2. 损耗率
  3. 实际到手单价（含运费、损耗）
  4. 顾客复购和投诉

**结论：**
如果只问“哪个性价比高”，通常**洪九果品在进货价和走量上性价比更高；都乐在品牌溢价和品质稳定上更值钱**。水果连锁店不建议二选一，更建议：
- 都乐做品质款/品牌款；
- 洪九做促销款/走量款；
- 按门店类型分配，而不是全店统一。

另外，这两家的具体报价、规格、起订量、区域配送政策会变，最好直接向当地经销商或采购平台询价，拿同规格同等级做对比，才能算出真实性价比。
