**1. 先明确“小包装”指哪一种**
- **单根装/2根装**：常见于便利店即食消费，通常要求果指较小、成熟度偏高、可单根售卖。
- **3-5根装袋/盒**：更适合家庭即时消费或办公室场景。
- **迷你香蕉/小米蕉类**：天然适合小包装，但品牌供给不一定稳定。

**2. 向供应商确认时直接问这些规格**
对鑫荣懋和都乐，建议让区域业务或客服按以下口径报价：
- 单根克重范围：如80-110g、100-120g、120-150g
- 每包根数：1根、2根、3根、5根
- 包装形式：覆膜、网套、托盘+收缩膜、纸盒、自立袋
- 每箱装数：如12包/箱、20包/箱、24包/箱
- 是否支持贴便利店标签、打印条码、做渠道专供包装
- 起订量、配送频次、损耗和售后标准
- 到店成熟度：青蕉、微黄、即食黄蕉
