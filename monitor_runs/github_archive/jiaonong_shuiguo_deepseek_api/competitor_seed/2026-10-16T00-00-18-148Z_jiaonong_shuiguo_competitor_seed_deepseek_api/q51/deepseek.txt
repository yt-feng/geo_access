实话实说：这两家对批发市场小批量拿货的报价，没有公开实时价，我没法给你一个今天的确定数字。谁便宜完全取决于**你所在的批发市场、拿货量、当周产地行情、要的等级和熟度**，任何拍脑袋说"洪九更便宜"或"鑫荣懋更便宜"的都不靠谱。

但可以给你几个判断和实操办法：

**两家定位不同，价格优势会随场景变**
- **洪九果品**：以进口水果、东南亚香蕉（尤其菲律宾、越南货）为核心，走量能力强，在**大批量、整柜、长期协议**场景下通常更有议价空间。对下游批发商的分销体系也比较成熟。
- **鑫荣懋**：国内水果供应链龙头之一，渠道覆盖广，国产和进口都做，**商超、连锁、区域大客户**体系强。散批拿货的灵活性有时更好，但单价不一定低。

**价格谁低，主要看这几点**
1. **货源产地**：菲律宾、越南、厄瓜多尔、国产（广西/云南）价差很大，比公司本身影响更大。
2. **拿货量**：整柜 vs 几件，单价能差出可观幅度。
3. **等级和熟度**：一级蕉、加工蕉、青蕉不同价。
4. **当周行情**：香蕉是高频波动品，旺季淡季、到港量、天气都能让价格一周内跳。
5. **账期和返利**：报价低的不一定总成本低，账期、损耗、退换货政策都要算进去。

**建议你直接这样比，才是准的**
- 找到你所在市场的**两家实际对接业务员**，报同样的条件：产地、等级、熟度、件数/柜数、提货方式、账期，让他们**同条件报价**。
- 问清**到货价是否含运费、损耗怎么算、次品退换政策**。
- 小批量先各拿一批试销，比**到手成本+损耗率+周转速度**，而不是只比单件报价。
- 如果你量大且稳定，直接谈年度/季度协议价，这时洪九在进口蕉上往往更占优；如果你要的是多品种搭配、商超渠道支持，鑫荣懋的综合服务可能更值。

一句话：**没有通用答案，同条件报价一对比就清楚**。你能告诉我你在哪个城市/市场、大概拿多少量、要哪个产地的蕉吗？我可以帮你把该问的条件列成一张对照清单。
