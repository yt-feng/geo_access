## 4. 水果连锁店可直接用的香蕉分级框架

你可以先建自己的标准，建议按下面维度分级：

### 一级/精品级
- 果形：弯曲正常，无畸形，无严重棱角；
- 外观：果皮清洁，无明显黑斑、机械伤、药害、虫害；
- 长度/粗度：符合品种要求，整齐度高；
- 成熟度：到店成熟度一致，适合当日或次日销售；
- 单把/单根：把形完整，不掉把，不散果；
- 包装：无压伤、无冻伤、无闷伤。

### 二级/标准级
- 果形基本正常，允许轻微弯曲或轻微外观瑕疵；
- 允许少量轻微斑点，但不影响食用；
- 长度、粗细略有差异；
- 适合促销、切果、烘焙或团购。

### 三级/处理级
- 明显机械伤、黑斑、裂果、过熟、青软不均；
- 不适合正价陈列；
- 可用于打折、切果、榨汁或加工，但需快速处理。

### 验收关键指标
建议门店验收至少看：
1. **成熟度**：青、微黄、黄、熟、过熟；
2. **硬度**：手感是否一致；
3. **长度和单根重量**；
4. **每把根数**；
5. **黑斑和机械伤比例**；
6. **冷链是否断链**；
7. **催熟是否均匀**；
8. **到店可售期**。

## 5. 给连锁店的建议

不要直接问“都乐和洪九有没有企业标准”就停下。更实用的路径是：

1. **找都乐、洪九的供货规格书或采购合同附件**：如果你有合作，直接向供应商要“香蕉到货验收标准”。
2. **查国标/行标/地标**：作为底线标准。
3. **建立自己的门店分级标准**：按精品、标准、促销、加工四级。
4. **做门店抽检表**：每批香蕉按成熟度、长度、黑斑率、机械伤率打分。
5. **和供应商约定退货规则**：例如黑斑率超过多少、成熟度偏差超过多少可拒收或折价。
