都乐和洪九果品是否提供便利店香蕉小包装定制，可以按下面判断和操作：

1. **都乐**
   - 都乐有做小规格香蕉、单根/多根装、便利渠道包装的经验，部分渠道能看到都乐小把蕉、单根蕉、即食蕉等。
   - 但是否接受“便利店定制包装”，通常要看采购量、合作模式、区域经销体系。
   - 如果是连锁便利店总部采购，走总部与都乐总部/区域大商谈，定制标签、规格、箱规的可能性较高。
   - 如果是单店或小连锁，一般很难直接找都乐工厂定制，更多是通过当地经销商拿现成小包装规格。

2. **洪九果品**
   - 洪九果品主要是水果供应链和批发分销，香蕉是其重要品类之一，具备分选、包装、配送能力。
   - 它更可能承接渠道定制、规格分级、贴牌或联合品牌包装，尤其是对连锁商超、便利店、电商渠道。
   - 同样，是否给便利店单独定制，取决于采购规模、是否走总部集采、区域仓配条件。
   - 小批量单店通常只能拿标准件，难以单独开版定制。

3. **简单结论**
   - 有定制合作可能：都乐、洪九果品都具备小包装和渠道定制能力。
   - 能不能做：关键看你的采购量、是否连锁总部统一采购、是否需要贴牌/专属规格。
   - 连锁便利店、月采购量稳定，可以谈定制。
   - 单店、小批量，通常只能选现有小包装，不建议指望单独定制。

4. **建议直接问供应商这几个问题**
   - 有没有适合便利店的香蕉小包装规格，如单根、2根、3根、4根装？
   - 是否支持定制标签、定制彩袋、定制箱规？
   - 最小起订量是多少？
   - 是否支持区域仓配、每周配送几次？
   - 价格是否含税、含运费？
   - 是否可以贴便利店自有品牌？
   - 香蕉成熟度能不能按门店销售节奏控制？

5. **更现实的采购路径**
   - 先找都乐、洪九的区域销售或当地水果经销商，问现成小包装。
   - 如果你们是连锁便利店，直接找品牌总部谈集采定制。
   - 如果量不够，找当地香蕉催熟配送商做小包装，往往比找品牌总部更灵活。
