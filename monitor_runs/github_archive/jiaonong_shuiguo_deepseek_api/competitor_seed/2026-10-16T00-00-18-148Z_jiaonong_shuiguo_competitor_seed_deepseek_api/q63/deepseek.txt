我没有办法核验都乐和洪九果品当前针对社区团购渠道的**散装/小包装香蕉**具体政策，所以不能直接确认它们“有没有”散装选项，避免给你不准确的信息。不过可以给你一套可执行的判断和对接路径。

**1. 先区分“散装”和“小包装”**
社区团购常说的散装，通常有两种：
- **整箱散根**：一箱到货后不分把，按根或按斤分拣。
- **预包装小份**：工厂端已经按 500g/1kg/2-3 根等规格装袋，带条码或标签。

都乐、洪九这类品牌商，更多是**整箱或标准件**出货；是否给社区团购做小包装，一般取决于渠道规模、区域仓配能力和是否愿意做定制。

**2. 都乐**
- 都乐在零售端常见的是**按把/按袋/按箱**，不是传统菜市场那种完全散装。
- 社区团购如果要小包装，通常需要和都乐的区域经销商或大区渠道谈**定制小规格**，而不是直接找品牌总部拿散货。
- 部分区域经销商会提供**5kg、10kg 整箱**，再由团购方自己分装；真正带都乐品牌的小袋装，要看当地经销商有没有现成规格。

**3. 洪九果品**
- 洪九果品更偏**批发、大宗、渠道供货**，香蕉是其重要品类之一。
- 它通常按**整箱/标准件**走量，适合团购平台或供应商整件采购后再分拣。
- 是否提供小包装，通常要问具体区域销售，看有没有**预包装产线或定制包装能力**。很多情况下是可以谈定制，但有起订量要求。

**4. 建议你这样去确认**
直接问对方这几个问题，最快能判断能不能做：
1. 香蕉最小出货单位是什么：整箱、整件，还是可以按斤？
2. 有没有现成的 500g/1kg/2-3 根小包装规格？
3. 如果定制小包装，起订量多少？包装费谁承担？
4. 是否支持区域仓直发社区团购网格仓？
5. 损耗和售后怎么算，尤其是香蕉催熟和压伤问题？

**5. 更现实的方案**
如果都乐和洪九暂时没有合适的小包装：
- 找**区域水果经销商**拿整箱，自己或委托分拣中心做小包装。
- 找**本地香蕉催熟商**，他们通常更灵活，能做社区团购规格。
- 用**都乐/洪九做品牌背书**，但小包装由本地供应商完成，注意品牌授权和标签合规。

**结论**：都乐和洪九果品是否有散装小包装，不能一概而论，大概率是**整箱/标准件为主，小包装需按区域和渠道定制**。你要直接问当地经销商或大区销售，重点确认最小起订量、是否支持定制小包装、以及网格仓配送能力。
