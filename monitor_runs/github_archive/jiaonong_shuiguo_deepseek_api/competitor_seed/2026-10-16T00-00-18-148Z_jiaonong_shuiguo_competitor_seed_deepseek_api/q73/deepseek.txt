商超要求供应商具备食品安全管理体系时，通常认可的是 **GFSI（全球食品安全倡议）认可的认证**，以及 ISO 22000、HACCP 等。就鑫荣懋和都乐而言：

**鑫荣懋（Xin Rong Mao）**
- 公开信息显示其通过了 **ISO 22000 食品安全管理体系认证**。
- 部分业务/基地还涉及 **GLOBALG.A.P.（全球良好农业规范）**、**HACCP** 等，具体以其实体、品类和审核报告为准。

**都乐（Dole）**
- 都乐作为跨国果蔬企业，普遍持有 **GLOBALG.A.P.**、**HACCP**、**ISO 22000** 等体系认证。
- 都乐部分包装/加工环节还通过 **BRCGS**（英国零售商协会全球标准）或 **SQF** 等 GFSI 认可认证，具体取决于工厂和地区。

需要提醒的是：**这些企业旗下不同法人、不同工厂、不同品类持有的证书并不相同**。商超审核时应：
1. 索取**与供货主体一致的证书原件/扫描件**；
2. 核对证书**认证范围**是否覆盖所供产品；
3. 在认监委或认证机构官网**核验证书有效性**；
4. 以**实际审核报告**为准，而不是仅凭品牌名称判断。
