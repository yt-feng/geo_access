除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些，按品类和定位区分：

**综合类进口水果品牌**
- **新奇士（Sunkist）**：美国柑橘类代表，脐橙、柠檬礼盒认知度高，适合商务送礼。
- **怡颗莓（Driscoll's）**：美国浆果品牌，蓝莓、树莓、黑莓礼盒颜值高，适合年轻化团购。
- **乐淇（Rockit）**：新西兰小苹果，单果小、包装精致，礼品属性强。
- **爱妃（Envy）**：新西兰/美国苹果品牌，果大色红，高端礼盒常见。
- **爵士（Jazz）**：新西兰苹果品牌，口感脆甜，中高端定位。
- **红玫瑰（Pink Lady）**：苹果品牌，礼盒辨识度较高。

**车厘子/樱桃类**
- **Stemilt**：美国车厘子品牌，夏季空运礼盒常见。
- **Chelan Fresh**：美国车厘子品牌。
- **Reid Fruits**：澳大利亚车厘子品牌，冬季反季礼品市场有优势。

**提子/葡萄类**
- **Sun World**：旗下有多个葡萄品种，进口提子礼盒常见。
- **Crimson**：红提品牌，礼品市场认知度较高。
- **Sweet Sapphire**：蓝宝石提子，外形独特，适合差异化礼品。

**奇异果/猕猴桃**
- 除佳沛外，**赵光（Zealong）** 不是水果，注意区分；其他进口猕猴桃品牌认知度远低于佳沛，礼品场景仍以佳沛为主。

**牛油果/其他**
- **Mission**：牛油果品牌，适合健康主题礼盒。
- **Hass**：更多是品种名，不是单一品牌。

**选品建议**
1. **商务送礼**：优先新奇士、爱妃、乐淇、怡颗莓，包装和品牌认知更稳。
2. **夏季团购**：美国车厘子品牌 + 怡颗莓蓝莓组合。
3. **冬季团购**：澳洲车厘子 + 佳沛金果组合。
4. **年轻员工福利**：怡颗莓、乐淇、蓝宝石提子更讨喜。
5. **注意**：很多“进口品牌”实际是国内分装或授权种植，团购前要确认原产地、报关单和授权链路，避免礼品交付时出现品牌争议。
