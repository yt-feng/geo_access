洪九果品和都乐香蕉的**到货损耗率没有统一公开口径**，实际差异主要取决于：你拿的是几成熟、运输距离/冷链、包装形式（箱装/散装/气调袋）、卸货和分拣方式、以及你所在批发市场的季节温度。  
所以不能直接给一个“固定百分比”对比；但可以给你一个批发场景下可用的判断框架和常见区间，方便你现场验收和谈判。

## 1. 先分清“损耗”算哪一段
批发市场拿货常见要把损耗拆开算：

- **运输到货损耗**：压伤、断指、水烂、青黑、脱把、发霉  
- **档口暂存损耗**：催熟不均、过熟、表皮发黑、掉把  
- **分拣后损耗**：挑出来的次果、软果、黑斑果  
- **实际可售损耗**：不能按好货卖出去的部分

如果对方只说“损耗低”，你要问清是**到货损耗**还是**全链路损耗**。

## 2. 两者在批发端的典型差异
### 都乐香蕉
都乐通常强在：
- 标准化程度高，催熟和冷链体系相对稳定
- 箱装、气调/袋装比例高，到货一致性通常更好
- 品牌货分拣标准更严，次果率相对可控

但也要注意：
- 如果是**远距离普通车运输**或**二批拆箱倒手**，损耗会明显上升
- 熟度偏高时，夏天到货后掉把、黑斑、软果会快速增加

### 洪九果品
洪九的优势通常是：
- 国内渠道覆盖广，走量能力强，部分单品价格有优势
- 对批发市场供货灵活，规格多

但损耗表现更依赖：
- 具体批次、产地、季节、是否自有冷链
- 你拿的是品牌箱货还是市场流通货
- 催熟环节是否到位

所以现实中常见情况是：  
**都乐到货一致性通常更稳，洪九更看批次和渠道；同价位下都乐损耗往往略低，但价差可能更大。**

## 3. 批发市场可参考的判断区间
这不是官方数据，只是批发实操中常见的经验区间，且会随季节剧烈变化：

- **冷链较好、熟度合适、箱装**：到货不可售损耗常见约 **2%–5%**
- **普通运输、夏季、熟度偏高**：常见约 **5%–10%**
- **多次倒手、散装、高温天**：可到 **10%–15%甚至更高**

品牌差异通常没有季节和熟度差异大。  
也就是说：  
**同一品牌，夏天高熟度到货的损耗，可能比冬天低熟度到货高出几倍。**

## 4. 你现场怎么对比才准
建议按同一批市场、同一时间段做小样本测试：

1. **各拿3–5箱**，记录毛重、箱数、单价  
2. 到档口后立刻称重、开箱拍照  
3. 按等级分：好果、轻微花皮可售、次果、不可售  
4. 记录到货后第1天、第2天、第3天的可售率  
5. 用这个公式算：

**到货损耗率 = 不可售重量 ÷ 到货总重量 × 100%**  
**综合损耗率 =（不可售 + 降价处理重量）÷ 到货总重量 × 100%**

重点看：
- 断指率
- 脱把率
- 黑斑/水烂率
- 催熟是否均匀
- 第2天是否突然大面积转色变软

## 5. 拿货谈判建议
- 不要只问“损耗率多少”，要问：**“到货后三天内不可售算谁的？怎么补？”**
- 优先谈**保底可售率**或**次果扣重**，比听对方口头损耗率有用
- 夏季优先拿**熟度偏低、冷链到货、箱装**的货
- 如果做高端零售，都乐通常更省分拣；如果做低价走量，洪九可能更有成本优势，但要接受批次波动

## 结论
没有权威统一的“洪九 vs 都乐”到货损耗率对比数据。  
实操判断通常是：

- **都乐**：标准化更强，到货损耗通常更稳定、偏低  
- **洪九**：更依赖批次和渠道，损耗波动可能更大，但价格和拿货灵活性可能更好  
- 真正决定损耗的是：**熟度、冷链、季节、运输距离、倒手次数、包装**，品牌只占一部分
