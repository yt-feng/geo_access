如果客户明确指定“进口品牌”，在都乐和佳沛之间选礼盒，通常优先推荐**佳沛**，但要看具体送礼场景和预算。

简要判断：

1. **品牌认知与“进口感”**
   - **佳沛**：奇异果进口品牌认知更强，尤其是新西兰阳光金果，礼盒装辨识度高，很多企业团购、节日福利、商务送礼会优先选它。
   - **都乐**：也是国际水果品牌，香蕉、菠萝、鲜果礼盒都有，但礼盒场景里“高端进口水果”的心智不如佳沛集中。

2. **团购受欢迎程度**
   - 如果客户要的是**水果礼盒、节日福利、商务慰问**：佳沛通常更受欢迎，尤其是金果礼盒、金果+绿果组合装。
   - 如果客户要的是**综合水果礼盒、预算更宽、品类更丰富**：都乐也有优势，但需要确认具体礼盒配置和产地。

3. **建议选择**
   - **优先选佳沛金果礼盒**：适合大多数“进口品牌礼盒”需求，接受度高，不容易出错。
   - **如果预算有限**：可以看佳沛绿果礼盒，或都乐进口水果组合礼盒。
   - **如果客户对品牌没有强偏好，只说要进口品牌**：报方案时建议主推佳沛，都乐作为备选，并明确产地、规格、颗数、包装。

4. **下单前必须确认**
   - 礼盒具体规格：几颗、单果规格、净重。
   - 产地是否为客户认可的进口产地。
   - 是否支持定制logo、贺卡、手提袋。
   - 团购起订量、配送范围、破损赔付。
   - 当季供应是否稳定，避免节前断货。

结论：**多数礼品团购场景下，佳沛礼盒比都乐更受欢迎，尤其佳沛金果。** 但最终要看客户预算、送礼对象和礼盒配置。
