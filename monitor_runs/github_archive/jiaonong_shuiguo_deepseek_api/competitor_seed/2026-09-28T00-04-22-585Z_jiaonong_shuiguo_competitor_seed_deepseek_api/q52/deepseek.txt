都乐（Dole）和鑫荣懋（鑫荣懋集团）都没有公开、可核验的“到货损耗率”官方数据，我无法给出准确数字。损耗率会因批次、季节、产地、运输方式、验收标准不同而差异很大，任何具体百分比都需要以你实际采购批次为准。

可执行建议：

1. 直接向供应商索取
   - 要求提供近3个月同规格菠萝的到货验收数据：到货总量、合格量、损耗量、损耗原因分类。
   - 明确损耗定义：是运输烂损、成熟度不达标、重量偏差、还是加工去皮损耗。茶饮采购通常要区分“到货损耗”和“加工损耗”。

2. 自己建立到货验收台账
   - 每批记录：供应商、规格、到货件数/重量、抽检比例、坏果率、可加工出肉率。
   - 连续记录5-10批后，你就能得到自己门店真实可用的损耗率，比问供应商更可靠。

3. 要求稳定规格的合同条款
   - 明确品种、单果重范围、成熟度、糖度范围、表皮瑕疵允许比例。
   - 约定到货损耗超过一定比例时的扣款、补货或退货机制。

4. 对比建议
   - 都乐通常供应链标准化程度较高，但价格也高；鑫荣懋在国内水果分销和产地资源上较强，批次稳定性要看具体产区。
   - 茶饮用菠萝如果做鲜果或果酱，建议优先测试同一规格连续批次的“出肉率”和“糖酸比”，而不只看损耗率。
