## 两家菠萝的基本差异（方向性判断）

**都乐（Dole）**
- 定位偏中高端，主打标准化、品牌溢价，常见“金菠萝/甜心菠萝”等。
- 优点：品控稳定、成熟度一致、损耗相对可控、消费者认知度高，摆出来好卖。
- 缺点：进货价通常更高，毛利空间被压缩，更适合走“品质+品牌”路线。

**洪九果品**
- 国内头部水果供应链企业，东南亚水果（含菠萝）是其强项之一，走量能力大。
- 优点：供应链规模大，价格通常更有竞争力，适合走量和做促销。
- 缺点：不同批次稳定性可能不如都乐这种强品牌标准，需要你自己把好验收关。

> 注意：具体价格、规格（如几头/箱、单果重）、产地（泰国/菲律宾/国产）、季节波动，都会让结论反转，必须按你实际拿到的报价单比。

## 判断性价比的实操方法

别只看“每箱单价”，要算**可售毛利**：

1. **折算到每斤可售成本**
   - 用：进货总价 ÷ 实际可售净重（去掉烂果、损耗）
   - 品牌果损耗低，可能反而更划算。

2. **算单果毛利**
   - 单果售价 − 单果分摊成本 = 单果毛利
   - 都乐可能售价高、销量好；洪九可能成本低、走量大。看哪个总毛利高。

3. **看损耗率**
   - 菠萝易损耗，建议各进一小批试销，记录7天内的损耗率。

4. **看动销和复购**
   - 品牌果可能“好卖但赚得少”，洪九可能“赚得多但需要你推”。

## 给你的建议

- **如果你门店偏社区、走量、价格敏感**：优先试**洪九**，用低价做引流和促销。
- **如果你门店偏精品、客单价高、注重口碑**：优先试**都乐**，用稳定品质换复购。
- **最稳妥**：两家各进一小批，同店同期对比2周，看**单果毛利、损耗率、动销速度**三个指标，再定主推和备选。
