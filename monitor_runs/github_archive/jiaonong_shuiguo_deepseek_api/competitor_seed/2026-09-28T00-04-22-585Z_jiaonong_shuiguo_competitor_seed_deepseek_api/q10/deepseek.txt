这个问题没法直接给一个"谁更严"的确定结论,原因和可判断的做法如下。

**先说结论**
- 两家都是国内头部水果供应链企业,香蕉都是核心品类,品控体系都比较成熟,但"谁更严"没有公开、可比的权威数据支撑(比如各自的农残检测批次合格率、检测项数量、抽检标准),所以我不能替你拍板。
- 更实际的做法:不看品牌名气,看**你能拿到手的检测凭证和验收标准**。

**判断依据(采购时可以直接要的)**
1. **检测报告**:要求提供该批次香蕉的农残检测报告(第三方或自检),看检测项目数、是否覆盖常用农药、报告日期是否对应本批货。
2. **溯源能力**:能否提供产地、基地、采摘/加工日期。溯源越细,出问题越好追责。
3. **验收标准**:问清楚对方对农残的自我控制线(是卡国标还是更严)、不合格怎么赔付。
4. **实际货损和退换**:农残问题往往和整体品质管理绑定,看对方对不合格批次的处理态度。

**给你的落地建议**
- 别只认品牌,同一品牌不同批次、不同产地差异也很大。
- 建立自己的抽检习惯:新供应商前几批货送第三方快检,合格再放量。
- 把"每批提供检测报告+不合格退赔"写进采购约定,比纠结哪家更严更能保护自己。
