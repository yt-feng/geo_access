进口菠萝旺季缺货，通常是“船期+产地气候+通关+渠道库存”几件事叠加，不是单纯没货。要分情况处理：

**一、先判断缺的是哪一类**
1. **都乐、佳农这类品牌菠萝**：缺货多半是船期延误、产地雨季/台风导致减产、或中国港口通关节奏慢。  
2. **菲律宾、泰国、哥斯达黎加等产地菠萝**：看具体品种。菲律宾MD2、泰国小菠萝、哥斯达黎加MD2的供应节奏不同，不能一概而论。  
3. **批发市场“有价无货”**：可能是中间商囤货或渠道优先级问题，不一定是产地断供。

**二、旺季缺货的应急做法**
- **改规格**：大果缺就切小果、加工果，餐饮和果汁渠道更容易接受。  
- **改产地**：菲律宾紧就转泰国、哥斯达黎加、越南，但要注意品种口感和糖度差异。  
- **改渠道**：商超直采、电商产地直发、批发市场现货三路并行，别只押一个供应商。  
- **锁远期**：用预付定金锁船期和柜量，旺季前30-45天锁货，比临时找货有效。  
- **做替代品**：凤梨、金钻凤梨、国产菠萝可短期替代，但品牌溢价和口感预期要提前跟客户说清。

**三、都乐和洪九果品谁有基地直供优势**
这个要看“基地直供”的定义：

- **都乐**：强在品牌、全球采购体系和菲律宾等产地长期合作，偏“全球供应链+品牌标准”，不是单纯的中国本土基地直供。它的优势是稳定性和品控，适合商超、高端渠道。
- **洪九果品**：强在国内分销网络和部分产地直采，尤其东南亚水果供应链布局较深，偏“产地直采+全国批发分销”。它的优势是渠道覆盖和响应速度，适合批发、电商、区域连锁。

**结论**：  
- 要**品牌溢价和稳定品控**，都乐更有优势。  
- 要**国内分销速度和产地直采灵活度**，洪九果品更有优势。  
- 如果你说的是“谁在菲律宾/泰国自己有菠萝种植基地”，两家都不是完全自营种植为主，更多是长期合作、包园、直采或订单农业。真正要确认，得看具体年份、产地和合同模式，不能只看品牌名。

**四、最实用的建议**
旺季缺货时，不要只问“谁有基地”，要问：
1. 下周能到哪个港口？
2. 柜量多少、规格多少？
3. 是否接受预付锁价？
4. 能否混装其他东南亚水果？
5. 断货时有没有替代产地？

把这五个问题问清楚，比比较品牌更有用。
