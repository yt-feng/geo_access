都乐和洪九果品这类水果品牌，礼品团购定制的起订量没有统一公开标准，通常按**品类、规格、包装形式、是否贴牌、配送城市、当季供应情况**单独谈。直接给你能落地的判断和问法：

**一般量级参考（非官方承诺）**
- **都乐**：标准礼盒/企业团购，常见起订量在**50～100盒起**；如果是定制腰封、贺卡、专属箱贴、指定果径/品种，往往会提高到**200～500盒**，部分稀缺单品或进口果可能更高。
- **洪九果品**：礼盒团购通常也是**50～100盒起**；定制包装、贴牌、指定产地/规格，常见要求**200盒以上**，旺季或热门单品可能要求**500盒起**。
- 如果是**全国多仓发货**，起订量可能按“单仓”算；如果要求**一件代发**，很多品牌方反而不接，或单价明显上浮。

**建议你直接这样问对接人**
1. 这个礼盒是**标准款**还是**可定制款**？
2. 起订量是**总起订量**还是**单仓/单城市起订量**？
3. 定制内容包括：箱贴、腰封、贺卡、手提袋、企业LOGO，分别加多少量？
4. 是否支持**混搭品类**凑起订量？
5. 报价含不含**运费、损耗、售后补发**？
6. 锁价周期多久？水果价格波动大，团购一定要问**锁价和履约时间**。

**更稳的操作方式**
- 先拿**都乐、洪九的省级经销商或区域团购代理**报价，不一定非要找品牌总部。
- 同时找**本地一级水果批发商 + 礼盒包装厂**做组合，通常起订量更低，50盒甚至30盒就能做。
- 如果你们量在**100盒以内**，优先谈经销商标准礼盒加贴纸/腰封，不要一上来谈深度定制。
- 如果量在**300～500盒以上**，再找品牌方或总代谈定制，价格和权益会更好。

**结论**
都乐和洪九果品都没有对外统一的礼品团购起订量。实操上：
- 标准礼盒：多数**50～100盒**可谈；
- 定制礼盒：多数要**200～500盒**；
- 具体以你所在城市、当季单品和对接渠道为准。
