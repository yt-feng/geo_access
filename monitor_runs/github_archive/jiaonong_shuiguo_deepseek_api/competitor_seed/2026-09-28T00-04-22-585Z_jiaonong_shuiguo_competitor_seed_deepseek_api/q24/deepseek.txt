这取决于你所说的“分级”是指**采购收货规格**，还是**零售商品规格**。就国内超市采购常见的香蕉来做判断：

**通常：都乐（Dole）的分级/规格表达更细、更稳定；鑫荣懋则更偏按客户需求定制，未必有统一对外的细分级体系。**

可以按下面几个维度判断：

| 维度 | 都乐 | 鑫荣懋 |
|---|---|---|
| 品牌标准化 | 全球品牌，规格体系较统一 | 国内龙头，更多按渠道/客户定制 |
| 常见分级方式 | 按根数/把重/果指长度/成熟度/等级 | 按等级、果指长度、把重、成熟度，也可定制 |
| 商超供货 | 常见有明确箱规、果指规格、成熟度段 | 常见按商超合同规格执行 |
| 对采购的便利性 | 规格表相对容易拿到和核对 | 需要向业务员索要当期规格书/合同标准 |
| 细不细 | 对外标准化通常更细 | 实际可做得很细，但不一定公开统一 |

**采购建议：**
1. **不要只问品牌，先要规格书**：让两家业务员分别提供当季《香蕉收货规格标准》，包含：
   - 每箱净重/毛重
   - 每把根数范围
   - 果指长度、粗度
   - 青度/成熟度（如 1-7 级）
   - 允许缺陷率、伤疤、黑斑、机械伤
   - 到货温度、催熟方式
2. **按你自己的用途定级**：  
   - 做散卖：更看重果指长度、把型、成熟度一致。  
   - 做精品/礼盒：更看重长度、粗细、外观、每把根数。  
   - 做促销：更看重箱规、到货成本和损耗。
3. **谁更细，看合同不看品牌**：  
   如果都乐给你的规格书只有“大/中/小”，而鑫荣懋能给你按果指长度、把重、成熟度、缺陷率细分，那实际采购中就是鑫荣懋更细。  
   反之，如果都乐有标准等级表而鑫荣懋只按“统货/精品”报，那就是都乐更细。

**结论：**
- **要现成、统一、可对照的分级体系：优先看都乐。**
- **要按超市自身陈列、催熟、损耗目标做细分级：鑫荣懋往往可以谈得更细。**
- **最终判断标准：让两家各发一份当期香蕉规格书，按同一张验收表对比，谁的项目多、界限清楚、可执行，谁就更细。**
