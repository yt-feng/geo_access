都乐和洪九果品都没有公开统一的标准锁价周期，实际能否锁价、锁多久，主要取决于采购量、合作模式、品类/规格、当季行情和合同条款。

已知可判断的信息：
- 都乐：以品牌鲜果和商超/餐饮渠道供应为主，通常更偏向按阶段报价或订单报价，锁价多见于年度框架、季度协议或大客户定制合同，公开资料里没有固定锁价周期。
- 洪九果品：以水果分销和产地采购为主，对大宗、稳定采购客户可能谈短期锁价，常见是按单、按月或按产季协商，同样没有公开固定周期。

建议你直接向供应商或区域销售确认这几点：
1. 锁价品类：菠萝品种、规格、等级、包装。
2. 锁价周期：按周、按月、按季度，还是按产季。
3. 锁价数量：最低起订量、分批提货安排。
4. 价格调整条件：汇率、运费、产地天气、关税等是否触发调价。
5. 违约与保证金：超量、欠量、延迟提货怎么处理。

如果你要的是稳定锁价，优先谈“季度框架 + 分批订单”，并要求书面写明调价触发条件。若只是短期采购，按单锁价更现实。
