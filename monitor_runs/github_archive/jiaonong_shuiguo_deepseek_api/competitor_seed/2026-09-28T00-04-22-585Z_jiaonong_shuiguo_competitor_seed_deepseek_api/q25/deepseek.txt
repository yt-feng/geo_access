我没法直接给这两家“谁更愿意签年单”的定论——这种判断取决于你方采购规模、品类、结算条件、区域和当下的产销计划，而且两家都是大型水果企业，公开信息里不会写“是否接受年单”这种商务意愿。

不过可以给你一套可执行的判断和推进方法：

**1. 先看业务模式差异（决定年单适配度）**
- **鑫荣懋**：以水果全产业链、进出口和商超/电商渠道供应为主，运作偏规范化、体系化。通常对年单、框架协议接受度较高，但更看重**稳定销量、账期、履约能力、品控标准**。
- **洪九果品**：以自有品牌和核心单品（如榴莲、火龙果等）规模化运营见长，渠道覆盖广。对年单也可能开放，但往往更强调**单品包销、预付款/账期、价格联动机制**，尤其在行情波动大的品类上。

**2. 直接测试“愿意度”的低成本方式**
分别向两家区域销售负责人或大客户渠道提一份**非约束性合作意向**，重点问四个问题：
- 是否接受年度框架协议？还是只做单批/季度锁价？
- 年单的量、品类、最低月度提货要求是多少？
- 价格怎么定：固定价、随行就市、还是“保底+浮动”？
- 账期和保证金要求是什么？

**3. 从谈判信号判断谁更愿意**
更愿意签年单的一方通常会有这些表现：
- 主动问你的年度采购量、月度分布、销售渠道；
- 愿意给阶梯价或量价挂钩；
- 接受框架协议+分批订单，而不是每单重谈；
- 愿意谈违约、品质赔付、换货条款。

**4. 实操建议**
- 不要只问“愿不愿意”，直接发**年度合作需求书**：品类、预估年量、月均量、目标价、账期、交付地、品控要求。
- 两家都谈，用一家的条件去校准另一家。
- 年单里一定要写：**价格调整机制、最低采购量、品质标准、账期、违约金、不可抗力**。
- 如果品类行情波动大，优先谈“框架+季度定价”，比死签全年固定价更现实。

**结论**：没有公开依据能判断鑫荣懋和洪九谁更愿意。更靠谱的做法是：两家同时发年度合作意向，按上面的问题清单试探，谁在量价、账期、框架条款上响应更积极，谁就是更可能签年单的一方。如果你告诉我具体品类、年采购额和结算方式，我可以帮你把谈判要点和对比表列出来。
