结论先说：**都乐（Dole）和洪九果品都没有公开可查、可直接引用的香蕉分级“企业标准”文本**。这类标准通常属于企业内部品控文件，不对外公开，所以网上很难找到正式编号（如 Q/XXX）或全文。你如果需要落地执行的标准，建议**自建一套，参考国标+行业惯例+两家企业的公开分级做法**。

下面分三块说明，方便你判断和操作。

## 一、都乐和洪九的实际情况

**都乐 Dole**
- 都乐有全球统一的香蕉品质规格体系，主要按**果指长度、粗度、成熟度、外观缺陷、串型**分级，出口和内销常分为 Premium / Class I / Class II 等等级思路。
- 但这是**企业内部规格（spec）**，不是公开备案的企业标准，公开渠道查不到标准编号和全文。
- 它的分级逻辑可以参考，但不能直接说“都乐企业标准是XXX”。

**洪九果品**
- 洪九是国内香蕉、榴莲等水果的头部供应链企业，内部有分拣、品控和等级划分流程，通常按**长度、条重、外观、成熟度、产地**做商品等级（如一级、二级）。
- 同样属于**内部品控/商品标准**，没有公开可查的正式企业标准文本。
- 公开信息里更多是财务、供应链、渠道内容，几乎没有完整分级标准。

所以：**能参考它们的公开做法和行业惯例，但不能直接引用它们的“企业标准”。**

## 二、你可以直接落地的香蕉分级框架

水果连锁店自用，建议按 **外观 + 规格 + 成熟度** 三维分级，简单可执行：

**1. 按果指长度（最直观）**
- 特级：≥ 20 cm
- 一级：18–20 cm
- 二级：16–18 cm
- 三级：14–16 cm
- 等外：< 14 cm

（不同品种如巴西蕉、桂蕉、菲律宾蕉长度基准不同，需按你主销品种微调）

**2. 按外观缺陷**
- 特级：无黑斑、无机械伤、无病虫、果指饱满、串型整齐
- 一级：允许极轻微瑕疵，不影响观感
- 二级：允许少量黑斑、轻微擦伤
- 三级：明显瑕疵，适合促销或加工

**3. 按成熟度**
- 1–2 号色：青硬，适合长途/久放
- 3–4 号色：转黄初期，适合门店陈列
- 5–6 号色：黄熟，适合即食
- 7 号色以上：过熟，适合打折/加工

**4. 按条重/把重（连锁店常用）**
- 单果重：特级 ≥ 180g，一级 150–180g，二级 120–150g
- 每把/每串重量也可设区间，方便定价和陈列

## 三、推荐做法

1. **不要等“都乐/洪九标准”**，直接自建《香蕉商品分级验收标准》，写成内部文件即可。
2. **参考国标和行业标准**：如 GB/T 主要水果等级相关标准、香蕉 NY/T 或 SB/T 相关标准（具体编号以现行有效版本为准，建议在“全国标准信息公共服务平台”核对）。
3. **结合门店实际**：按你卖的品种、产地、客单价、损耗率，把上面框架调成 3–4 个等级。
4. **做成验收表**：长度、重量、成熟度色号、缺陷比例、抽检数量、判定结果，采购和门店都能直接用。
5. **如需对外宣称**：只能写“参照都乐/洪九公开分级惯例制定”，不能写“执行都乐企业标准”。
