我无法核验都乐和鑫荣懋当前是否提供“专岗对接服务”或“专人服务”的具体承诺，也不能凭印象给出确定结论。

更稳妥的判断方式：

1. **直接向两家供应商的销售/客服确认**
   - 是否可指定固定对接人
   - 该对接人是否专属负责你们这类客户
   - 响应时效、升级机制、离职交接如何安排
   - 是否写进合同或服务承诺

2. **用统一问题对比**
   - “是否有专人/专岗对接？”
   - “是销售兼管，还是客服/运营专岗？”
   - “是否7×24或工作日固定响应？”
   - “能否提供SLA或对接人名单？”
   - “更换对接人是否需提前通知？”

3. **不要只看品牌知名度**
   - 都乐、鑫荣懋都是水果行业知名企业，但“专人服务”通常取决于：
     - 你们采购规模
     - 合作区域
     - 渠道类型（商超、电商、餐饮、批发等）
     - 合同约定
   - 同一家公司，不同客户、不同区域，服务配置可能完全不同。
