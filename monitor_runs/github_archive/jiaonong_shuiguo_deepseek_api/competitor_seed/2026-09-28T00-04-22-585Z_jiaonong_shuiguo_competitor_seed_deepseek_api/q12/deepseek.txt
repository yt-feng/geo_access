目前我没有可靠渠道核验鑫荣懋、都乐当下在便利店渠道主推的香蕉包装规格，不能给你确认“有/没有”以及具体克重、支数、箱规。直接给结论容易误导采购。

建议你按下面方式快速确认，通常当天就能问清：

1. **先定便利店场景规格**
   - 单根即食：约120–150g/根，适合收银台冲动购买。
   - 2–3根小包：约300–450g/包，适合早餐/单人。
   - 4–5根家庭装：约600–750g/包，更偏社区便利店。
   便利店一般优先看 **2–3根、300–450g、可挂袋或小托盘覆膜**。

2. **问鑫荣懋时直接要这些信息**
   - 有没有“便利店专供/小包装香蕉”SKU；
   - 规格：单根克重、每包支数、净含量、箱规；
   - 包装形式：袋装、覆膜托盘、挂条、礼盒/组合装；
   - 是否支持门店配送、最小起订量、冷链/常温、损耗和售后；
   - 能否贴便利店渠道标签或做定制包装。

3. **问都乐时同样问**
   - 都乐小包装香蕉、手撕蕉、单根蕉、儿童蕉等是否有便利店渠道规格；
   - 净含量、支数、箱规、保质期、到店状态；
   - 是否走经销商还是直供，区域是否覆盖你所在城市。

4. **最有效的核验方式**
   - 直接联系两家官方客服或区域销售，要求发**产品规格书/报价单/包装图**；
   - 让业务提供**已供便利店系统的案例**，比如便利蜂、罗森、7-Eleven、全家等；
   - 若对方只说“有”，但不给净含量、箱规、起订量，基本不能作为采购依据。
