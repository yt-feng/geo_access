在中国大型商超（如沃尔玛、永辉、大润发、华润万家、盒马等）的供应商准入中，通常要求提供以下几类食品安全与质量体系认证。就两家企业而言，可以分两个层面来看：

**一、商超通常要求的通用资质/认证**
1. **营业执照、食品经营许可证/食品生产许可证**（SC证，按品类）
2. **ISO 22000 食品安全管理体系认证** 或 **HACCP 危害分析与关键控制点体系认证**
3. **GFSI 认可的食品安全认证**，常见如：
   - **BRCGS**（英国零售商协会全球标准）
   - **IFS**（国际食品标准）
   - **FSSC 22000**
   - **SQF**
4. **GlobalG.A.P.**（针对种植/水果供应链，尤其生鲜果蔬类供应商常被要求）
5. **出口备案/海关注册**（如涉及进口水果）
6. **产品检测报告、农残检测、追溯体系文件**

**二、鑫荣懋与都乐的情况**
- **都乐（Dole）**：作为跨国果蔬企业，通常持有较完整的国际认证体系，常见包括 GlobalG.A.P.、ISO 22000、HACCP、BRCGS 等，具体以各产地、加工厂和品类的证书为准。都乐在不同国家和工厂的认证并不完全一致。
- **鑫荣懋**：作为国内大型水果供应链企业，通常具备 ISO 22000、HACCP 等体系认证，并在部分品类/基地具备 GlobalG.A.P. 等认证。具体证书范围需按其子公司、加工厂和品类分别核对。

**重要提醒**：我无法在此提供两家企业当前有效的证书编号、发证机构和有效期，因为这些信息会随审核周期更新，且同一集团下不同法人、不同工厂的资质不同。**准确做法是**：
1. 向对方索要**最新证书扫描件**（含证书编号、认证范围、有效期、发证机构）；
2. 到 **全国认证认可信息公共服务平台（cx.cnca.cn）** 或认证机构官网核验；
3. 确认证书覆盖的**产品类别、加工场所**是否与供货一致；
4. 商超通常还会要求供应商通过其**自有审核**（如沃尔玛的验厂、永辉的供应商审核），这不等同于第三方认证。
