这个问题没有统一答案，因为都乐和鑫荣懋都不是“种植商”，而是**品牌/供应链商**，苹果质量稳不稳定，主要取决于**具体产地、批次、品种和到货季节**，而不是单看品牌名字。

但可以给你一个可执行的判断框架：

**1. 都乐（Dole）**
- 优势：全球供应链体系成熟，标准化程度较高，尤其在一些固定产地和固定品种上，分级、包装、冷链相对规范。
- 风险：都乐苹果很多是贴牌或代理采购，不同批次可能来自不同国家/产区，口感一致性不一定比国产头部供应链更强。
- 适合：看重品牌背书、包装规范、超市验收流程相对省心的采购。

**2. 鑫荣懋**
- 优势：国内水果供应链龙头之一，进口水果操作经验多，和很多商超、渠道合作深，部分单品（如某些新西兰、智利苹果）在到货稳定性和成本控制上有优势。
- 风险：同样是多产地、多品种运营，不同批次差异也可能明显，尤其受海运、清关、仓储影响。
- 适合：看重国内渠道响应速度、账期和本地化服务的采购。

**3. 真正决定“质量稳定”的关键**
- **产地是否固定**：比如新西兰、智利、美国、南非，不同国家差异很大。
- **品种是否固定**：嘎啦、富士、红玫瑰、Envy、爵士等，耐储和口感差异明显。
- **到货批次**：同一品牌不同船期、不同冷库，质量可能完全不同。
- **验收标准**：糖度、硬度、果径、色差、碰压伤比例，你有没有统一标准。
- **冷链和周转**：超市端如果堆头时间长、温度不稳，再好的货也会快速变差。

**4. 建议你这样做**
- 不要只问“谁更稳定”，而是要求两家分别提供：
  - 最近3批到货的**产地、品种、船期/批次**
  - **糖度、硬度、果径、损耗率**数据
  - 试销样品，做**盲测和货架期测试**
- 同一品种、同一产地、同一规格下对比，才有意义。
- 如果非要二选一：  
  - 更看重**国际品牌标准化和商超接受度**，可优先试都乐；  
  - 更看重**国内供应链响应、成本和渠道配合**，可优先试鑫荣懋。  
  - 但最终应以**你所在区域的实际到货批次**为准，而不是品牌名气。

简单说：**都乐和鑫荣懋谁更稳，取决于你采购的具体单品和批次。先锁定产地+品种+规格，再让两家报价和送样对比，才是可判断的做法。**
