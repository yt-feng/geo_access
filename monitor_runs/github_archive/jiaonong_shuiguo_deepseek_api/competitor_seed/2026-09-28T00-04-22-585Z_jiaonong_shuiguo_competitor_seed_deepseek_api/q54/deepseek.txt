# 都乐（Dole）和鑫荣懋进口苹果的产地溯源做法

两者模式不同，溯源路径也不同，分开说。

## 一、都乐（Dole）

都乐是自有品牌+全球供应链模式，苹果多来自其海外合作果园/自有农场。溯源主要靠**都乐自己的批次体系**：

1. **看包装箱标签**：都乐进口苹果外箱通常印有：
   - 原产国（如美国、新西兰、智利、南非等）
   - 果园/种植者编号（Grower No. / Orchard ID）
   - 包装厂编号（Packing House No.）
   - 批次号（Lot / Batch）
   - 采摘或包装日期
2. **凭批次号向都乐中国查询**：联系都乐中国（上海都乐食品有限公司）或其区域经销商，提供批次号，可反查对应果园、包装厂、装运信息。
3. **海关报关单/检验检疫证明**：进口时每批都有《入境货物检验检疫证明》，上面有原产国、境外注册果园/包装厂编号。这是最硬的官方凭证。
4. **都乐溯源系统**：部分批次支持扫码查询，但覆盖程度视品类和批次而定，不是所有货都有。

**关键点**：都乐的溯源以“批次→果园+包装厂”为主，官方背书是海关检验检疫证明。

## 二、鑫荣懋

鑫荣懋是**进口水果分销/供应链企业**，本身不一定是种植方，苹果来自多个海外产区（新西兰、智利、美国等），可能同时代理多个品牌（如新西兰Mr Apple、Envy、Jazz等）。溯源逻辑是：

1. **实际品牌方才是源头**：鑫荣懋卖的苹果，包装上往往还有真正的海外品牌（如新西兰Mr Apple、T&G的Envy/Jazz）。溯源要追到这个品牌方。
2. **看包装标签**：原产国、品牌、果园/包装厂注册号、批次号、出口商。
3. **向鑫荣懋要报关和检疫资料**：作为进口商/经销商，鑫荣懋持有该批次的：
   - 入境货物检验检疫证明
   - 海关报关单
   - 原产地证（如适用）
   - 出口方提供的果园/包装厂信息
4. **通过鑫荣懋追溯上游**：它作为供应链方，能对接海外出口商/品牌方，可要求提供果园级信息。

**关键点**：鑫荣懋是渠道方，溯源要穿透到它背后的品牌方和海外出口商，官方凭证同样是海关检疫证明+原产地证。

## 三、超市采购实操建议

| 环节 | 做法 |
|---|---|
| 收货时 | 留存每批外箱标签照片、批次号 |
| 索证 | 向供应商索取当批《入境货物检验检疫证明》+报关单 |
| 合同 | 约定供应商须提供可追溯至果园/包装厂的信息，出问题可追责 |
| 抽检 | 核对标签批次与检疫证明是否一致 |
| 门店 | 张贴/扫码展示溯源信息，提升可信度 |

## 四、注意

- 国内目前对进口水果的强制溯源主要靠**海关检验检疫证明**，不是每个品牌都有面向消费者的扫码溯源系统。
- 若供应商只能给“原产国”而给不出果园/包装厂/批次，说明溯源链不完整，采购时要警惕。
- 具体批次能否查到果园级信息，取决于该供应商的上游数据能力，需实际向都乐中国或鑫荣懋业务对接人确认，我无法替你核验其当前系统覆盖情况。

**一句话**：都乐靠自身批次+果园体系，鑫荣懋靠穿透到海外品牌方；两者最硬的共同凭证都是海关《入境货物检验检疫证明》和报关单，采购时务必逐批索取并留存。
