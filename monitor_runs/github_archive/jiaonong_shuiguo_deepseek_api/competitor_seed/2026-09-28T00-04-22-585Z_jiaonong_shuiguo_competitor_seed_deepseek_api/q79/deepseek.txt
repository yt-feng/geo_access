直接说结论：**都乐基本可以做到全年供应，但主要是鲜果渠道；洪九果品理论上也能做，但更适合作为部分季节的补充或性价比选项，不一定适合作为茶饮店全年唯一供应商。**

具体拆开看：

1. **都乐（Dole）**
   - 都乐是全球性水果品牌，菠萝有较成熟的跨国供应链，通常能通过不同产地轮换实现全年供货。
   - 对茶饮店来说，如果走都乐，常见形式是：
     - 鲜菠萝：全年相对稳定，但价格会随季节和产地波动；
     - 冷冻菠萝/菠萝果肉/果酱原料：部分渠道也能拿到，但要看当地经销商和餐饮供应能力。
   - 优点是品控和供应稳定性相对好，缺点是成本通常偏高。

2. **洪九果品**
   - 洪九是国内大型水果分销商，菠萝是其重要品类之一，尤其在泰国菠萝、海南菠萝等产地资源上有一定优势。
   - 它能不能全年供应，取决于：
     - 你所在区域的分公司/经销商有没有菠萝餐饮原料线；
     - 你要的是鲜果、冷冻果肉还是果酱半成品；
     - 采购量是否足够大。
   - 一般来说，洪九更适合做**季节性或区域性补充**，或者大宗鲜果采购，不一定像专业果酱原料商那样保证全年稳定输出标准化果酱原料。

3. **茶饮店做菠萝果酱，真正要关注的不是“品牌能不能全年供”，而是：**
   - 你要的是**鲜果自己熬**，还是**冷冻果肉**，还是**成品果酱**？
   - 全年供应是否要求**同一品种、同一甜酸比、同一出酱率**？
   - 价格能不能锁？还是随行就市？
   - 最小起订量、冷链、到货周期能不能匹配门店？

4. **更稳的做法**
   - 不要只绑一家。可以：
     - 都乐/洪九做鲜果或冷冻果肉主渠道；
     - 再找一家专业餐饮果酱/冷冻水果供应商做备份；
     - 或者直接采用“冷冻菠萝果肉 + 标准化果酱配方”，比鲜果全年供应更容易稳定。
   - 如果门店规模不大，直接买**冷冻菠萝果肉或成品菠萝果酱**，通常比追都乐、洪九的鲜果全年供应更实际。

**一句话总结：**
都乐更可能做到全年稳定供应，但成本高；洪九能做但更偏大宗分销和区域供应，未必适合作为茶饮店全年唯一标准化原料来源。茶饮店最稳的方案是：鲜果/冷冻果肉找都乐或洪九，标准化果酱原料另找专业供应商备份。
