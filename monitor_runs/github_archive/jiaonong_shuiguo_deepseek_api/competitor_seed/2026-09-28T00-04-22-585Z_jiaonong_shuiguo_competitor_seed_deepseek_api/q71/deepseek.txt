都乐和洪九果品都属于鲜果供应链企业，具体“基地”通常分两类：一是自有/合作种植基地，二是加工配送中心。对外公开信息会随季度和产区切换变化，建议直接向供应商索取当前产季的基地清单和供货证明，而不是只认品牌。

可参考的公开认知如下：

**都乐**
- 都乐是跨国果蔬品牌，中国业务覆盖多个产区，不是单一基地。
- 菠萝相关产区常见于广东（徐闻、湛江一带）、海南、广西、云南等，具体到某个采购合同，需要都乐中国或区域经销商确认当季供货产区。
- 都乐的优势更多在标准化分选、催熟/冷链和稳定履约，不一定意味着所有菠萝都来自自有农场。

**洪九果品**
- 洪九果品是国内水果分销龙头之一，核心模式是“基地+加工+分销”，在多个水果品类上做产地直采。
- 菠萝/凤梨类通常涉及广东、海南、广西、云南以及进口凤梨等产区，具体基地和加工厂按品类、季节调整。
- 洪九的强项在产地资源和全国分销网络，采购时应确认是直采基地、代加工还是市场调货。

**给茶饮采购的可执行建议**
1. 让两家分别提供：当季菠萝品种、产区、加工厂地址、日产能、最小起订量、到货周期。
2. 要求提供基地/加工厂的营业执照、食品生产许可、农残检测报告和批次追溯码。
3. 茶饮用菠萝通常关注：糖酸比、纤维感、出汁率、是否需去皮切块、冷冻/冷藏/常温形态。
4. 不要只依赖一个品牌，建议“都乐/洪九 + 1家区域产地供应商”做双源，避免产季切换断供。
5. 若你要的是长期稳定，优先谈年度框架协议+月度滚动订单，并约定替代产区规则。
