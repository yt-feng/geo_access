国内菠萝/凤梨市场，除都乐外，能稳定供货的常见品牌大致分几类：

**国际/合资品牌**
- **佳农**：菲律宾菠萝、凤梨类目供应较成熟，商超和电商渠道常见，走量稳定。
- **旺旺**：部分鲜果渠道有菠萝供应，但不算绝对主力，稳定性看季节和区域。
- **百果园**：自有品牌和合作基地菠萝，门店渠道较稳，但更多是零售端。
- **鑫荣懋**：水果供应链企业，给商超供货，菠萝/凤梨有稳定货源。

**国内产地品牌/基地**
- **徐闻菠萝**：广东徐闻产区，品牌化程度逐年提升，多个合作社和供应链公司做稳定供应，如“徐闻菠萝”区域品牌下的企业。
- **海南凤梨**：海南产区，金钻凤梨等品种，产地供应链公司较多，适合做稳定采购。
- **台农/金钻凤梨**：不少国内基地在做，品牌分散但供应量足。

**渠道自有品牌**
- **盒马、山姆、永辉、大润发**等自有品牌或直采菠萝，往往由产地供应链公司供货，稳定性取决于其采购体系。

**判断稳定供应的几个实操点**
1. **看产地**：徐闻、海南、菲律宾是主要稳定产区。
2. **看供应链公司**：鑫荣懋、佳农这类全国性水果供应链，通常比单一品牌更稳。
3. **看季节**：国内菠萝旺季在3-6月，菲律宾等进口全年相对稳。
4. **看渠道**：商超直采和大型供应链公司，比零散批发商更稳。

如果你是要做采购或分销，建议直接对接**佳农、鑫荣懋**这类供应链公司，以及**徐闻、海南**的产地合作社/基地，比只盯品牌更实际。需要的话我可以帮你按“进口/国产、鲜果/加工、大宗/零售”再细分。
