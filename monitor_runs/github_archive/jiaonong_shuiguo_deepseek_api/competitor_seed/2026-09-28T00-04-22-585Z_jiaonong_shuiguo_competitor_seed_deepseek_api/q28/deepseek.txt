这个问题没有一个固定的“谁更便宜”的答案，因为两家都是国内头部水果供应链企业，价格取决于品类、规格、产地、季节、采购量、结算方式和区域。直接说“都乐更便宜”或“鑫荣懋更便宜”都不严谨。

但可以给你一个可判断的框架，帮你快速比出谁更有竞争力：

**1. 先看你们要比的具体是什么**
进口苹果不是一个单品，至少要锁定：
- 品种：如新西兰爱妃、红玫瑰、爵士，美国蛇果，智利嘎啦等
- 规格：果径、单果重、每箱粒数
- 包装：原箱、礼盒、电商装
- 产地和船期：新季/旧季、空运/海运
- 到货口岸和交货地

不锁定这些，报价没有可比性。

**2. 都乐和鑫荣懋的定位差异**
- **都乐**：品牌化强，终端认知度高，适合做礼盒、精品商超、线上品牌款。通常品牌溢价更明显，但部分单品在促销期或大客户协议下也有价格空间。
- **鑫荣懋**：供应链规模大，渠道覆盖广，很多商超和水果连锁的进口水果来自它。它的优势常在稳定供货、多产地调配和综合成本，不一定每个单品都最低，但整体供应链能力强。

所以：
- 如果你要**品牌背书和礼盒溢价**，都乐可能更好卖。
- 如果你要**稳定走量和综合采购成本**，鑫荣懋往往更值得重点谈。

**3. 比价时不要只比“每箱价”**
要算到岸综合成本：
- 裸果价
- 运费、冷链、装卸
- 损耗率
- 账期
- 返利/搭赠
- 退换货政策
- 最小起订量和补货频率

同样一箱便宜5元，如果损耗高3%，账期短15天，实际可能更贵。

**4. 最有效的做法**
找两家同时要同一规格的报价，做一张对比表：
- 同一品种、规格、产地、到货时间
- 报“到仓价”而不是“出厂价”
- 问清账期和损耗承担
- 各拿一柜或一批做小范围试销
- 看终端动销、毛利、损耗、顾客反馈

**5. 实操建议**
- 不要只选一家，建议**双供应商**：都乐做品牌款和礼盒，鑫荣懋做走量款和稳定补货。
- 用一家的报价去压另一家的同规格价格，但不要只压价，要谈账期和损耗。
- 如果你们门店多、采购量大，直接找两家的区域负责人谈年度框架，价格通常比单次询价好很多。
- 如果量不大，可以优先找当地一级批发商或鑫荣懋/都乐的经销商，拿货灵活，但价格未必最优。

**结论**：
单看“谁价格更有竞争力”，通常**鑫荣懋在综合供应链成本和走量单品上更容易有优势，都乐在品牌溢价和精品单品上更强**。但具体到你们要上的进口苹果，必须拿同规格、同到仓条件的报价单来比。最稳的策略是两家都谈，分角色使用，而不是二选一。
