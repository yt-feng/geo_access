大型商超通常要求供应商具备权威的食品安全管理体系认证。鑫荣懋和都乐作为知名的水果和农产品供应商，一般通过以下认证：

- **鑫荣懋**：通常持有**BRCGS（全球食品安全标准）**、**ISO 22000（食品安全管理体系）**、**GLOBALG.A.P.（全球良好农业规范）** 以及**HACCP（危害分析与关键控制点）** 认证。具体认证可能因产品线和客户要求有所差异。
- **都乐**：通常持有**GLOBALG.A.P.**、**ISO 22000**、**HACCP**，以及特定市场的**有机认证**或**雨林联盟认证**。都乐还强调**SCS（可持续农业标准）** 或**SQF（安全质量食品）** 认证。

建议直接联系鑫荣懋或都乐的官方客服或查询其官网公布的认证文件，以获取最新、最准确的清单。商超审核时一般会要求提供有效证书原件或扫描件。
