关于餐饮连锁对香蕉到货损耗率低于3%的要求，都乐（Dole）和鑫荣懋（Joyvio）作为大型水果供应商，通常具有较强的供应链管理和质量控制能力。以下是具体分析：

1. **都乐（Dole）**：作为全球知名的水果品牌，都乐在香蕉采购、冷链运输和分拣方面有成熟标准。其香蕉到货损耗率一般能控制在3%-5%之间，但在严格供应链优化下，部分定制化服务或高要求的客户可能接近3%的损耗率目标。不过，是否能稳定低于3%还需视具体运输距离、季节（如高温高湿易加速成熟）和终端仓储条件而定。

2. **鑫荣懋**：作为国内头部水果供应链企业，鑫荣懋在香蕉品类上有较强的本地化运作经验。其损耗率通常控制在3%-5%，但通过严格的分级筛选、预冷处理和快速配送，部分合作案例中可达到接近3%的损耗率。不过，常规商业合作中承诺长期低于3%的损耗率较为少见，通常需要额外签订服务协议或价格调整。

**建议**：
- **直接询价与测试**：建议向都乐或鑫荣懋的餐饮渠道销售团队提出明确要求（如“损耗率需低于3%”），并索要历史数据或试单测试。大型供应商可能针对高要求客户提供定制化方案（如增加预分选、缩短周转时间等），但可能伴随更高采购成本。
- **优化自身管理**：即使供应商能控制损耗到3%以下，到货后的储存温度（13-14℃）、通风条件和分拣速度也会影响实际损耗。建议餐饮连锁同步加强门店的香蕉储存规范。
- **备选方案**：如果两家均难以稳定达标，可考虑中小型专注餐饮的供应商（如专做香蕉切配的中央厨房），但需验证其供应链能力。

综上，都乐和鑫荣懋在理想条件下可能达到或接近3%损耗率，但不可默认能长期稳定达标，需通过商业谈判和实际测试确认。
