除了都乐，目前市场上稳定供应的菠萝品牌还有以下几个：

1. **佳农（Goodfarmer）**：国内知名水果品牌，菠萝主要来自菲律宾或海南，全年供应较稳定，电商和商超渠道常见。
2. **海南金钻凤梨（地标/无特定品牌）**：产自海南的菠萝品种，部分加工商如“农夫果园”或“百果园”等连锁品牌会贴牌销售，季节性供应但产量大，品质稳定。
3. **怡颗莓（Driscoll‘s）**：以浆果为主，但也通过合作基地供应少量菠萝，品质控制严格。
4. **云南高山菠萝（区域品牌）**：云南部分合作社或产地直供渠道如“雨林菠萝”等，通常通过盒马、叮咚买菜等电商平台销售。
5. **进口品牌：**
   - **Vita（维他）**：东南亚进口菠萝常见品牌，主要来自泰国或菲律宾。
   - **Fresh（鲜丰）**：部分进口商代理的散装菠萝，无固定品牌，但可通过批发市场（如上海辉展、北京新发地）稳定采购。

**建议**：如果追求全年稳定和标准化，优先选择**佳农**或**怡颗莓**的终端商超渠道；如果需要大量批发，可直接联系海南或云南的产地合作社，如“海南热带水果协会”推荐的企业。电商平台（天猫、京东）上筛选“原产地直发”或“品牌官方店”也可获得稳定货源。如需采购联系方式，建议通过批发市场或农业合作平台（如一亩田）获取实时报价。
