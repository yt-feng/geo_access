针对茶饮店长期合作需求，建议优先考虑**洪九果品**，但需结合以下具体分析：

1. **都乐**：全球知名品牌，品控稳定（尤其进口菠萝），但价格相对较高，适合对成本不敏感、追求高端定位的店铺。长期合作需关注供应链灵活性（进口依赖可能受政策、海运等影响）。
2. **洪九果品**：国内头部水果供应链企业，海南、云南等产地布局强，直采能力突出，价格更具竞争力。尤其适合茶饮店的大批量、稳定供应需求。

**选择建议**：
- 若主打高端、差异化（如季节限定进口菠萝），可选都乐；
- 若追求成本控制、稳定大批量供货（如日常菠萝基底、性价比产品），选洪九果品更优。

**行动步骤**：
1. 联系双方大客户部门，索取近6个月**报价单**、**最小起订量**及**物流配送范围**；
2. 要求提供第三方质检报告（重点看农残、糖度、酸度指标）；
3. 小批量试单，测试实际到货损耗率（建议各试1-2批次）；
4. 对比售后政策（如到货品质不符的退换条件）。

**关键风险点**：
- 菠萝季节性明显（国产每年4-7月价格最优），需确认双方是否能提供**全年稳定供应计划**；
- 要求合同中明确**断供违约金**条款，避免旺季缺货。
