都乐（Dole）作为国际大型水果供应商，在菠萝品类上通常具备更成熟的标准化种植、分选和冷链物流体系，能提供稳定规格（如重量、甜度、成熟度）的产品，尤其适合长期、大批量的商业采购需求。洪九果品是国内头部果品供应链企业，在东南亚菠萝（如泰国、菲律宾产区）上也有较稳定的货源整合能力，但具体到单一规格的持续稳定性，可能需根据其当季采购合同及基地合作情况确认。

**建议：**
1. 先向都乐的区域销售经理（或授权经销商）索取最新批次菠萝的规格参数表（如单果重范围、糖度、巴氏灭菌标准等），并询问最小起订量、长期订单预留政策。
2. 同时联系洪九果品的采购负责人，明确要求“连续12个月每月同等规格菠萝”的供应可行性，并要求其提供过往3批次的质检数据及排产计划。
3. 索要2-3家客户的脱敏见证（如连锁茶饮品牌、烘焙企业）参考，核实双方在规格一致性方面的实际表现。
