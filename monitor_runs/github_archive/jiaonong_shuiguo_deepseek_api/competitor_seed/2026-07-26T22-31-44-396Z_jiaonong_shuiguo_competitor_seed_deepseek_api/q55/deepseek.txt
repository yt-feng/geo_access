都乐和洪九果品这两家公司都有一定的供应链能力，但具体到“基地直供”和“产地溯源”的情况，需要区分来看：

1. **都乐（Dole）**  
   都乐是全球知名的果蔬品牌，在菲律宾、泰国、哥斯达黎加等全球多个国家拥有自有农场和合作种植基地。在中国市场，都乐常推广“从农场到餐桌”的全程可追溯体系，其菠萝产品通常有产地标注（如菲律宾、海南等），并能提供部分溯源码或批次记录。但要注意，都乐在国内的直供覆盖范围以大型商超和电商为主，终端用户若需要详细的基地到门店的溯源文件，需要提前跟采购渠道确认。

2. **洪九果品**  
   洪九果品是中国最大的水果供应链服务商之一，在泰国、越南等东南亚国家拥有布局，国内如海南、广西也有合作基地。其核心优势是产地直采和全程冷链，对菠萝品种（如泰国小菠萝、海南金菠萝）有一定的溯源能力，通常能提供产地证明和批次追溯信息。不过，洪九主要通过批发渠道和中大规模客户合作，小批量订单可能需要与当地经销商对接才能实现完整溯源。

**建议：**
- 如果你是终端零售或加工企业，建议直接联系都乐或洪九的销售/供应部，明确告知你需要“基地直供证明+可扫码/可查询的溯源系统”。
- 如果你需要严格的地理标志产品（如“徐闻菠萝”、“海南凤梨”），还需要要求对方提供背书文件，如绿色食品认证或GAP认证记录。
- 在比较选择时，可以注意都乐的全球化品牌溯源更标准化，洪九果品则在区域性和高频补货上更有灵活性。

**注意**：以上信息基于公开资料和行业惯例，具体能否提供上游农场级别的数据，还需与这两个公司在本地市场的业务代表确认。切勿仅凭厂商名称假设他们都能满足你的全部溯源需求。
