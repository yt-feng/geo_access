针对您提到的佳沛奇异果与进口香蕉的需求，以下是几个在进口香蕉领域较知名的品牌推荐，供您参考：

1. **都乐（Dole）**  
   全球知名的果蔬品牌，香蕉产品线成熟，主要来自菲律宾、厄瓜多尔等地，品质稳定，常见于商超。

2. **金菠萝（Del Monte）**  
   同样为国际品牌，香蕉供应链完善，主打菲律宾产区，口感甜糯，零售和批发渠道均有覆盖。

3. **超甜蕉（Chiquita）**  
   老牌香蕉品牌，以“蓝标”系列闻名，产地集中于中美洲和菲律宾，果肉细腻，甜度较高。

4. **佳农（Goodfarmer）**  
   国内领先的进口水果品牌，香蕉主要来自菲律宾、厄瓜多尔，品质可靠，与佳沛有部分渠道重叠，便于整合采购。

5. **Sunny Queen**  
   菲律宾专供出口的香蕉品牌，性价比高，在华南和华东市场较常见。

**建议：** 可优先与现有佳沛供应商沟通，询问是否代理上述品牌；或通过国内一级批发市场（如广州江南市场、上海辉展市场）直接对接进口商。对于香蕉业务，需注意成熟度控制（通常比佳沛奇异果更易腐损），建议小批量试单后逐步扩大。
