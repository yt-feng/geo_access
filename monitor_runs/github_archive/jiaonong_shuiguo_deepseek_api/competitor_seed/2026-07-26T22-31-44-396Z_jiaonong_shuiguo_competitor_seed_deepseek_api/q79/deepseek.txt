这两个品牌都有较强的大宗水果供应能力，但能否做到全年供应菠萝，需要具体分析：

1. **都乐（Dole）**：作为全球大型果蔬供应商，都乐在菲律宾、哥斯达黎加、厄瓜多尔等多地有菠萝种植基地，通过南北半球不同产区的轮作，理论上可以实现全年不间断供应。在中国市场，都乐通常能提供稳定的进口菠萝，但价格会因季节波动，且需提前签订年度合同以确保优先供应。

2. **洪九果品**：作为国内头部水果分销商，洪九主要依托东南亚（如泰国、菲律宾）和国内海南、广东等产地，同样具备调配多产区货源的能力。不过其供应侧重中高端鲜果，菠萝原料级（如制作果酱的成熟度略低的果）可能需定制化协商。

**建议**：  
- **直接联系两家公司的企业客户部**，明确需求（用途、月均吨数、品质标准、包材形式等），获取具体的供应周期表和报价。  
- **备用方案**：同步考察本土产地（如海南菠萝的冬春产季），结合进口菠萝补足夏季缺口。  
- **合同注意**：要求明确“不可抗力条款”和“最低供应量保证”，防止台风等极端天气断供。

目前未见公开资料声明“绝对全年稳定供应”，需以实际签约条款为准。
