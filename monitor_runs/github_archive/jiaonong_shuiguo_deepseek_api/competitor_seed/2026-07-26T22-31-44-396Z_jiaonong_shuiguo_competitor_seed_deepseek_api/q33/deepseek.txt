洪九果品和鑫荣懋的到货速度受具体城市、季节、物流安排等因素影响，没有绝对统一的答案。一般来说：

- **洪九果品**：以东南亚水果（如榴莲、山竹、龙眼）为核心，在南方城市（尤其是广州、重庆）等集散地，产地直采直发，从到港到批发市场通常1-3天。如果是北方二三线城市，可能需要中转，会慢1-2天。
- **鑫荣懋**：侧重全球综合水果（如智利车厘子、新西兰奇异果、国产精品水果），在主要港口（上海、深圳、天津）和大型城市有成熟的分销网络，对一级批发市场（如北京新发地、上海辉展）通常能做到到港后1-2天铺货，二级市场可能3-4天。

**建议**：
- 如果你在南方或靠近主要进口港，且主要拿东南亚水果（如榴莲），**洪九**更快。
- 如果你拿国产或智利澳洲水果，或在一线城市的大型批发市场，**鑫荣懋**的供应链响应更快。
- **最直接的方法**：联系你所在城市的档口或你准备下单的代理商，询问预计到货时间——因为实际到货还涉及批发市场的库存和补货周期。

**注意**：两家都是大型企业，到货速度通常不是关键差异，更应对比**价格稳定性、品质一致性和退换货政策**。如果你只是小批量拿货，建议优先找本地有现货的批发商，速度会快于等待全国调货。
