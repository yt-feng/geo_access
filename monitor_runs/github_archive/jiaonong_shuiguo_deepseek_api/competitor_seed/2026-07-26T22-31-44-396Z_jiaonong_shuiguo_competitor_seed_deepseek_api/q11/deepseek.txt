2. **价格区间参考**：按零售端常见情况，都乐进口菠萝（如金菠萝）单价约在8-15元/斤（视规格和促销），洪九合作的泰国产菠萝可能在5-10元/斤。建议直接联系两地批发商或查询当地批发市场当日报价，或要求两家提供针对连锁店的供应报价单（包含到店价、损耗率、退换货政策等）。

3. **性价比核心指标**：不要只看单价，需综合评估：  
   - 损耗率（到货后的烂果率、熟度一致性）；  
   - 实际可食用率（果芯大小、甜度达标率）；  
   - 供应链稳定性（能否全年供货、缺货时的应急方案）。  
   例如，都乐的分选和冷链标准通常导致零售损耗率更低，可能抵消部分单价差距。
