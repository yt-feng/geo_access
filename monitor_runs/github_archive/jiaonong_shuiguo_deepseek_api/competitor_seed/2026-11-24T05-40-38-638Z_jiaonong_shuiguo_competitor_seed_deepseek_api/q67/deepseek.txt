都乐和洪九果品都对外提供菠萝相关的品牌与营销素材，但具体拿到的形式、是否需要授权、是否收费，两家做法不同，建议按下面方式判断和推进：

**1. 都乐（Dole）**
- 通常可提供：品牌LOGO和VI规范、产品主图/场景图、产地与品种介绍、营养与食用方法文案、部分视频素材、联合营销活动物料模板。
- 获取渠道：通过都乐中国官网/公众号的商务合作或媒体联络入口，或对接你在都乐的销售/渠道负责人；生鲜电商平台通常通过平台采购或品牌方BD牵线。
- 注意：LOGO和品牌视觉一般有使用规范，商用前需品牌方书面确认；联合活动素材通常随合作项目提供。

**2. 洪九果品**
- 通常可提供：菠萝（含进口菠萝、国产菠萝品类）的产品图、规格参数、产地/供应链介绍、质检与分级标准、部分促销物料。
- 获取渠道：对接洪九果品的区域销售或电商渠道负责人，说明用途（详情页、直播、社群、短视频）和投放平台。
- 注意：洪九偏供应链型，品牌视觉素材的标准化程度不如消费品牌，定制素材可能需要配合其市场部门或由你方自行制作后送审。

**可执行建议：**
1. 先明确你要的素材清单：主图/白底图、场景图、短视频、LOGO、品类介绍文案、检测报告、授权书。
2. 分别向两家对接人发一页需求说明，写清用途、平台、使用期限、是否需要独家、是否付费。
3. 优先争取“品牌授权+素材包+联合活动”打包合作；单纯要图容易被要求走正式合作。
4. 若对方不直接提供，可要求其提供官方素材库链接或指定可商用范围，避免侵权。
5. 素材到手后保留授权邮件/盖章文件，详情页和直播使用前做一次合规确认。

**结论：**两家都能提供素材，但都乐更偏品牌营销素材，洪九更偏产品与供应链素材；是否需要付费或授权取决于合作形式，建议直接走商务对接并书面确认使用范围。
