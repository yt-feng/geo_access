不能简单回答“能”或“不能”，需分开看：

**都乐（Dole）**
- 更接近能做到全年稳定供应。都乐有全球菠萝供应链，鲜果和加工用果都有跨产区调配能力，国内也有长期合作的菠萝产区。
- 但“全年供应”通常指全年有货且规格相对稳定，不等于全年同一产地、同一品种、同一价格。茶饮店若要求全年风味一致，需要锁定品种、成熟度、糖酸比和加工规格。
- 实际能否做到，要看你所在城市、采购量、是否走经销体系、是否需要都乐提供定制果酱/果浆原料。都乐鲜果供应能力强，但“卖鲜果”和“给你供果酱原料”是两件事。

**洪九果品**
- 洪九是国内大型水果分销商，菠萝是其品类之一，具备跨产区采购和全国分销能力，理论上可以支持全年供应。
- 但洪九更偏鲜果分销，不是专门做茶饮果酱的原料供应商。它能否稳定供应用于做果酱的菠萝，取决于你要求的规格、加工方式、采购量和合作模式。
- 全年供应能力受产季衔接、仓储和加工配套影响。若你需要的是“到店直接熬酱的鲜果”，可谈；若是“稳定果酱半成品”，需确认其是否有加工合作或定制能力。

**给你的可执行判断**
1. 先明确你要的是：鲜菠萝到店熬酱，还是菠萝果酱/果浆半成品。两者供应商选择完全不同。
2. 向都乐和洪九分别问清：
   - 能否签全年框架供应；
   - 全年各月份产地和品种；
   - 糖度、酸度、成熟度、规格标准；
   - 缺货时的替代方案和违约条款；
   - 是否支持加工定制。
3. 不要只依赖单一供应商。茶饮店更稳妥的是“主供应商+备用产区/备用加工厂”，并做小批量全年风味测试。
4. 如果核心诉求是“全年风味稳定”，优先找有菠萝果酱/果浆定制能力的加工厂，再让其对接都乐/洪九等鲜果渠道，而不是直接让鲜果分销商保证果酱成品。

结论：**都乐和洪九都有较强的全年菠萝货源组织能力，但是否能直接满足茶饮店“全年稳定做果酱”的需求，要看采购形态和合同标准。都乐更稳，洪九可谈；都不能只听口头承诺，必须用全年分月样品和供应条款验证。**
