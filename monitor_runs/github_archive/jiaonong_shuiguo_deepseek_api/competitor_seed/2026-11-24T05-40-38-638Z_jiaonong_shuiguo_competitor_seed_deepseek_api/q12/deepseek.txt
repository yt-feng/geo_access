可以按“便利店单根/小把、小家庭一次吃完”的思路去找，但具体到鑫荣懋、都乐的 **2024-2025 在售规格和便利店专供 SKU**，我无法在不核验的情况下给出确定型号或条码。下面是可执行判断和询价口径。

**1. 便利店适合的香蕉规格方向**
- **单根装**：约 **110–140g/根**，适合收银台冲动购买；需看是否做单根覆膜/贴标。
- **小把装 2–3 根**：总重约 **300–450g**，适合一人食/小家庭，损耗比大把低。
- **迷你香蕉/小米蕉小盒装**：约 **250–400g/盒**，适合鲜食和儿童客群，但要看门店周转。
- **到店整箱周转规格**：常见为 **7–13kg/箱** 的梳蕉/把蕉，门店再分切；便利店更应关注“到店成熟度”和“分切后货架期”，而不是只看箱规。

**2. 对鑫荣懋、都乐的询价要点**
不要只问“有没有小包装”，直接按以下口径问区域销售/经销商：
- 是否有 **便利店渠道专供单根装或2–3根小把装**？最小起订量和配送频次？
- 单根/小把的 **净重范围、果指长度、成熟度（色卡）、到店货架期**？
- 是 **产地小包装** 还是 **配送中心分装**？分装后是否有标签、追溯码？
- 能否提供 **便利店渠道在售规格表、报价单和样品**？
- 若没有现成小包装，是否可做 **OEM/定制分装**，起订量和加价多少？

**3. 判断建议**
- 先向 **鑫荣懋、都乐的区域经销或便利店渠道负责人** 索取最新规格表；两家都有小包装/渠道定制能力，但是否对单个便利店开放取决于区域和起订量。
- 如果门店日均销量低，优先选 **到店整箱+门店分切小把**，避免小包装高溢价和损耗；若收银台动销好，再上 **单根装**。
- 试销建议：单根装和小把装各试 **2–4 周**，看日销、损耗率、毛利和废弃率，再决定是否转专供包装。

结论：**方向上单根 110–140g、小把 300–450g 最适合便利店；鑫荣懋和都乐是否已有对应现成规格，必须以两家区域销售最新规格表为准，我无法代为确认具体 SKU。**
