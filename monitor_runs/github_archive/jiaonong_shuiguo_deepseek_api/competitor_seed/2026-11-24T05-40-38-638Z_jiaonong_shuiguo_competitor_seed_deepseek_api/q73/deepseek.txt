大型商超通常会要求生鲜供应商具备可核验的食品安全管理体系认证。就公开可查的信息而言：

- **鑫荣懋**：公开资料显示其通过 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系**，部分业务/基地还涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 等认证。具体证书范围需以其最新证书或审核报告为准。
- **都乐（Dole）**：作为跨国果蔬企业，公开信息中常见 **GLOBALG.A.P.**、**ISO 22000**、**HACCP**、**BRCGS** 等认证，具体到中国区运营主体和产品线，应以实际供应商准入时提供的证书为准。

**可执行建议**：商超审核时不要只看企业宣传，应要求供应商提供**证书编号、认证机构、覆盖场所/产品范围、有效期**，并通过认证机构官网或发证机构核验；同时确认证书是否覆盖供货的加工厂/包装厂，而非仅覆盖总部或某一基地。
