这个问题没有统一的“谁更稳”，得看**你采购的渠道、品类和到货标准**。直接给可执行判断：

1. **先定义“稳定”**  
   超市要稳定，核心不是“最好吃”，而是：  
   - 到货规格一致（果径、颜色、箱重）  
   - 硬度/糖度波动小  
   - 损耗率低、坏果率可控  
   - 供货连续、缺货少  
   建议你按这4项做月度评分，而不是凭品牌印象。

2. **都乐 vs 鑫荣懋的定位差异**  
   - **都乐**：品牌化强、包装和规格标准化通常更成熟，适合对**外观、规格、陈列一致性**要求高的超市；但价格和渠道政策可能更硬。  
   - **鑫荣懋**：供应链和国内渠道覆盖强，进口水果操作经验多，适合对**供货灵活性和成本**更敏感的超市；但不同区域、不同单品稳定性会有差异。  
   注意：两者都是大型供应链企业，具体到“进口苹果”这个单品，**批次和产地**影响往往大于品牌本身。

3. **最稳的做法：双供应商+批次验收**  
   - 不要独家押注，保留**主供+备供**，按到货批次打分。  
   - 验收看：果径合格率、色泽一致率、硬度、糖度抽检、坏果率、箱内整齐度。  
   - 连续3批不达标就降权，别只看品牌名。

4. **谈判时问清这几个问题**  
   - 进口苹果的**产地/品种/产季**是否固定？  
   - 同一规格的**允差范围**是多少？  
   - 坏果、压伤、大小不一的**赔付标准**？  
   - 断货时的**替代方案和提前期**？  
   - 是否支持**小批量试单**和区域仓直配？

**结论**：如果你最看重陈列一致性和品牌背书，可优先试都乐；如果看重成本、供货灵活和本地响应，可优先试鑫荣懋。但真正决定稳定的是**你的验收标准和双供应商机制**，建议先各试2–3批，用数据定主供。
