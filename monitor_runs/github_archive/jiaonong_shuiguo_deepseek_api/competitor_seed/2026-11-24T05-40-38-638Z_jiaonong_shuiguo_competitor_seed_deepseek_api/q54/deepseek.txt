做进口苹果的产地溯源，核心是把“批次—单证—货—码”四件事绑定起来，让任一超市在售苹果都能回溯到具体海外果园/包装厂和进口批次。都乐（Dole）和鑫荣懋（鑫荣懋集团，常见进口苹果品牌如“佳沃/鑫荣懋”体系）做法可以按同一套框架落地，差异主要在对接渠道。

**一、先明确溯源要回答的5个问题**
1. 这批苹果是哪个国家、哪个产区、哪个果园/包装厂？
2. 哪个出口商/进口商、哪张卫生证书/植物检疫证书？
3. 哪个海运/空运批次、入境口岸、报关单号？
4. 进入哪个配送中心、哪家门店、哪个货架批次？
5. 消费者扫码能看到什么、门店能查到什么？

**二、都乐苹果的溯源做法**
1. **供应商准入时收齐单证**：要求都乐中国或其授权经销商提供原产地证明、出口国植物检疫证书、卫生证书、提单/空运单、报关单、入境货物检验检疫证明。
2. **按批次建档**：以“报关单号+集装箱号/提单号+生产包装日期”为批次主键，录入供应商名称、果园/包装厂注册号（如出口国官方注册编号）、品种、规格、到货日期。
3. **箱码/托盘码关联**：进口苹果通常有外箱标签（品种、规格、产地、包装厂、批次/Lot No.）。收货时扫描或登记箱码，把箱码与报关批次绑定；门店收货再把门店收货单与箱码绑定。
4. **门店端可查**：价签或包装上放追溯二维码，扫码展示产地国家、包装厂注册号、进口商、报关批次、检验检疫证明编号（可脱敏展示）、门店到货日期。若都乐提供官方追溯码，优先对接其系统，不要自建一套与供应商冲突的码。
5. **异常召回**：一旦某报关批次有问题，通过箱码—门店收货单反查涉及门店和销售时段，按批次下架。

**三、鑫荣懋苹果的溯源做法**
1. **确认对接主体**：鑫荣懋集团旗下进口水果业务通常通过其供应链公司或区域经销商供货，采购合同里要写明“提供批次级溯源数据”的义务和字段。
2. **同样收齐进口单证**：原产地证、植物检疫证书、报关单、入境货物检验检疫证明、提单、发票、装箱单。
3. **利用其自有追溯体系**：鑫荣懋有水果供应链追溯能力，采购时应要求其提供批次追溯码或追溯数据接口（JSON/Excel均可），字段至少包括：原产国、产区、包装厂、品种、批次号、进口日期、检测报告编号。
4. **到货扫码入库**：外箱标签上的Lot号/批次号与送货单核对，系统生成内部批次号；门店收货时绑定门店和货架。
5. **消费者查询**：二维码展示原产国、包装厂、进口商、入境口岸、检验检疫证明编号、门店名称和到货日期。不要展示完整报关单等敏感商业信息。

**四、超市侧统一落地的6个动作**
1. **合同条款**：在采购合同或质量协议中写明供应商须提供批次级溯源数据、单证真实性和更新时限（如到货前24小时）。
2. **收货SOP**：无批次号/箱码不收货；单证与实物品种、规格、产地不一致不收货；拍照留存外箱标签。
3. **系统字段**：供应商、原产国、产区、包装厂注册号、品种、规格、Lot号、提单号、报关单号、入境货物检验检疫证明编号、到货日期、门店、货架期。
4. **码的管理**：优先用供应商箱码；门店价签二维码由超市系统生成，绑定内部批次，避免“一码多批”。
5. **抽检与核对**：每月抽查若干批次，核对系统记录与实物外箱标签、单证是否一致；对都乐、鑫荣懋分别建供应商追溯评分。
6. **召回演练**：每季度模拟一个批次召回，测试能否在2小时内查出门店和销量。

**五、判断是否做到位的标准**
- 任取门店一箱苹果，能在系统中查到原产国、包装厂、进口批次、报关单号、到货门店；
- 任取一个报关批次，能反查配送到哪些门店、销售时段；
- 消费者扫码信息与箱标、单证三者一致；
- 供应商能提供批次级数据而非仅“原产地证明”一张纸。

如果都乐或鑫荣懋只愿提供整柜单证、不愿提供箱码/Lot号级数据，超市应把“批次级追溯”作为准入条件谈判，至少做到“报关批次—门店”两级追溯，再逐步细化到箱。
