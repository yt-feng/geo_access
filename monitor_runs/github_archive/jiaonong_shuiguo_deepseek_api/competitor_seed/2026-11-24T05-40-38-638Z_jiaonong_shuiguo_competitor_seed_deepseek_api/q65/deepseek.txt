都乐（Dole）和洪九果品都没有对外公开统一、标准的菠萝“锁价周期”政策，公开渠道无法核验到具体天数。锁价通常按客户、品类、采购量、合同期和产地季节单独谈，不能按公司统一周期判断。

可执行建议：

1. **直接问供应商锁价条款**：要求书面确认锁价有效期、适用规格/产地、锁价数量上限、超量部分计价、调价触发条件、违约和保证金条款。
2. **向都乐中国和洪九果品分别询价**：都乐可通过其中国区销售/餐饮与商超渠道询盘；洪九果品可通过其销售部门或区域分公司询盘。重点问“菠萝单品能否锁价、锁多久、按什么基准价锁”。
3. **不要接受口头锁价**：合同里写明锁价起止日、基准市场价来源、汇率/运费/关税波动是否可调价。
4. **替代方案**：同时找区域性菠萝批发商、产地合作社或大型果品供应链公司比价，通常比头部品牌更愿意给短期锁价。
5. **询盘话术**：“请确认贵司菠萝锁价政策：锁价周期最短/最长多少天？按柜/吨起锁量是多少？锁价期内是否100%不调价？调价触发条件有哪些？”

结论：都乐和洪九的菠萝锁价周期没有可核验的公开标准，需按具体合同询盘确认；建议要求书面锁价条款并同步比价区域供应商。
