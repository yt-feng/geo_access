都乐和鑫荣懋通常都能提供农残检测报告，但能不能直接给到“你这一批货”的报告，需要按供应商类型和采购渠道确认。

**可执行判断：**

1. **都乐（Dole）**
   - 作为品牌商/大型供应商，通常有批次农残检测或第三方检测报告。
   - 通过都乐官方渠道、区域经销商采购时，可要求提供对应批次的检测报告。
   - 若从批发市场二级批发商拿货，报告可能不是当批，需追问“批次号是否对应”。

2. **鑫荣懋**
   - 大型水果供应链企业，一般可提供农残检测报告或供应商检测合格证明。
   - 同样要确认报告对应的是**具体批次、具体品种（菠萝）、具体产地**。

**采购时建议这样问：**
- “请提供本批次菠萝的农残检测报告，报告编号和批次号能对应吗？”
- “检测项目是否覆盖常用有机磷、氨基甲酸酯、拟除虫菊酯等，是否按 GB 2763 判定？”
- “报告是第三方检测机构出具，还是企业自检？能否盖章？”
- “如果当批报告未出，能否提供最近批次报告并书面承诺当批合格？”

**风险点：**
- 大型供应商口头说“有报告”不等于能提供**当批**报告。
- 茶饮店若用于门店现制饮品，建议留存报告复印件/电子版和进货凭证，以备监管抽查。
- 若对方只能提供“产地证明”或“合格证”，不能替代农残检测报告，需区分清楚。

结论：**都乐和鑫荣懋一般具备提供能力，但采购时必须锁定“当批次+菠萝+第三方检测+盖章”四项，不能只接受口头承诺。**
