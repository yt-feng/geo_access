都乐（Dole）和洪九果品的菠萝供应基地情况，以下是可核实的部分：

**都乐（Dole）**
都乐在中国市场的菠萝主要来自其在菲律宾的种植基地（如棉兰老岛），菲律宾是全球菠萝主产区之一，都乐在当地有长期合作的种植园和包装厂。国内方面，都乐在广东、海南等地也有合作种植和加工布局，但自有基地以菲律宾为主。具体采购需直接联系都乐中国（上海）确认当季供应地和规格。

**洪九果品**
洪九果品是重庆企业，核心菠萝供应来自泰国（如清迈、尖竹汶等产区）和国内云南、海南基地。泰国菠萝是其进口主力品类之一，国内基地主要做补充和错季供应。洪九有自有分拣加工中心，但“基地”多为合作种植园+产地直采模式，并非全部自有农场。

**给采购的可执行建议：**
1. 稳定供应不能只依赖单一产地，建议都乐（菲律宾/国产错季）+洪九（泰国/云南海南）组合，覆盖全年。
2. 直接向两家索取当季「产地证明+农残检测报告+供货周期表」，确认是自有基地还是合作直采，这决定议价和稳定性。
3. 菲律宾菠萝受气候和物流影响较大，泰国菠萝有季节性关税和口岸波动，建议各留一个备选供应商（如佳农等）。
4. 具体基地地址和产能属于商业信息，需通过官方渠道（都乐中国、洪九果品供应链部门）核验，不建议依赖第三方转述。
