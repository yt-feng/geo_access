判断“谁更全”不能只看是否都有认证，而要看**认证类型覆盖、有效期、认证范围（产品/工厂/仓储）和可核验性**。就公开信息而言，鑫荣懋和都乐都属于大型水果供应链企业，通常具备食品安全相关体系认证，但我无法在不核验证书编号的情况下断言谁“更全”。

可执行判断方法：

1. **先列商超准入清单**  
   常见要求包括：ISO 22000、HACCP、FSSC 22000、BRCGS、GLOBALG.A.P.、有机认证、绿色食品、出口备案/CIQ等。不同商超要求不同，先拿到对方《供应商准入审核表》。

2. **按“证书+范围+有效期”核验**  
   不要只看宣传页。要求两家提供：
   - 证书扫描件及证书编号；
   - 认证机构；
   - 认证覆盖产品/加工厂/仓储地点；
   - 有效期与最近一次审核结论；
   - 在认证机构官网或国家认监委平台可查。

3. **比较“覆盖匹配度”而非证书数量**  
   如果商超要的是鲜果分选包装环节的FSSC 22000或BRCGS，而某家只有种植端GLOBALG.A.P.，即使证书多也不一定匹配。应以**拟供品类、加工厂、配送仓**逐项对照。

4. **要求供应商填认证矩阵表**  
   行：认证名称；列：证书编号、覆盖产品、覆盖工厂、有效期、发证机构、可查询链接。两家填完后，缺项一目了然。

初步结论：**不能仅凭公开宣传判断鑫荣懋和都乐谁认证更全；应以商超准入清单为准，要求两家提交可核验证书并按覆盖范围打分。** 若你提供具体商超品类和准入要求，我可以帮你做一张对比评分表模板。
