不能直接保证“都乐、鑫荣懋一定能做到低于3%”，需要把“到货损耗率”定义和验收口径先锁定，否则供应商承诺没有可执行性。可判断的建议如下：

1. **先定义损耗口径**
   - 到货损耗率建议定义为：到货验收不合格重量 ÷ 到货总重量 ×100%。
   - 明确是否包含：青黑斑、机械伤、断指、果指脱落、主梗霉变、成熟度不符、单果重量/条数不符、箱内短装。
   - 香蕉到货损耗低于3%在连锁餐饮里属于较严标准，尤其夏季高温、跨区域长途运输时，单靠供应商品牌不能保证，必须写进合同和验收标准。

2. **都乐和鑫荣懋的能力判断**
   - 两家都是国内香蕉供应链头部企业，具备产地、催熟、冷链和商超/餐饮客户服务能力，理论上可以针对大客户做定制催熟、冷链和到货标准。
   - 但“能做到低于3%”取决于：采购量、配送距离、季节、是否指定催熟度、门店验收标准、是否允许拒收和索赔。不能仅凭品牌判断。
   - 建议不要接受口头承诺，要求对方提供近3—6个月同类客户、同区域、同季节的到货损耗数据，并做试单验证。

3. **可执行验证方式**
   - 先做2—4周双供应商试单，按同一验收标准逐箱抽检并拍照留证。
   - 试单覆盖夏季/冬季或至少覆盖当前高温时段，因为香蕉损耗季节差异大。
   - 约定试单期损耗率连续超标时的整改、扣款、换货、拒收和退出条款。
   - 要求供应商提供催熟度（如到货颜色/硬度）、冷链温度记录、装车和到货时间。

4. **合同关键条款**
   - 到货损耗率≤3%作为验收KPI，超出部分按重量扣款或补货。
   - 明确抽检比例、判定标准、复检流程和照片/视频证据。
   - 约定成熟度窗口，例如到货颜色、硬度范围；不符合即计入损耗。
   - 约定旺季和高温期的特殊包装、冷链和配送频次。

5. **结论**
   - **可以要求两家按低于3%报价和承诺，但不能把“品牌能力”当成结果保证。**
   - 更稳妥的做法是：设定3%为考核目标，先试单验证；若单一到货损耗长期稳定低于3%难度大，可把目标拆为“验收不合格率≤3%”和“可销售率≥97%”两个指标，并保留索赔机制。
   - 如果门店验收极严、配送半径长或夏季高温，建议预留3%—5%的合理区间，或通过缩短配送半径、增加配送频次、指定催熟度来压到3%以下。
