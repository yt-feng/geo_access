先说明：我无法核验都乐、鑫荣懋当前对你所在城市/仓的菠萝产地直发时效承诺，也不应给你编造具体“X小时/X天”的数据。下面给你可判断、可执行的结论与核验方法。

**结论：**
1. **不能只看品牌名判断时效**：都乐、鑫荣懋都是果品供应链品牌，菠萝“产地直发”时效取决于具体产地仓、发货仓、目的地、承运商、是否冷链/常温、截单时间，以及你作为B端客户签的配送条款。
2. **生鲜电商做菠萝直发，时效评估要看“到仓/到消费者”两段**：产地集货→区域仓/前置仓，和区域仓→消费者。品牌方通常强在产地组织与品控，末端时效由你的仓配网络决定。
3. **菠萝耐储性相对较好但怕低温冷害**：长途运输不宜简单套用低温冷链，需确认对方是常温通风车、控温车还是冷藏车，以及是否做催熟/分级。时效承诺必须和温控方案一起看。

**建议你直接向两家索取并对比这6项：**
- 具体发货仓/产地仓地址，到你指定收货仓的**标准时效、最晚时效、截单时间**；
- 菠萝品种、规格、成熟度，是否支持**催熟分级**和到货可售率承诺；
- 运输方式与温控记录，破损/腐损**赔付标准**；
- 旺季（节假日/雨季）时效保障和备货库存；
- 最小起订量、直发是否拼车、是否支持多批次小批量；
- 试单方案：先做**同一路线、同一规格的3—5批试单**，记录“下单—发货—到仓—上架”实际时长和损耗。

**可执行判断标准：** 若你做次日达/隔日达生鲜电商，要求供应商承诺“截单后到区域仓的时效+延迟赔付”，并用试单数据验证；若时效只给“一般2—4天”这类模糊口径，不宜直接作为直发主供应商。最终以两家给你的书面报价单/配送协议为准。
