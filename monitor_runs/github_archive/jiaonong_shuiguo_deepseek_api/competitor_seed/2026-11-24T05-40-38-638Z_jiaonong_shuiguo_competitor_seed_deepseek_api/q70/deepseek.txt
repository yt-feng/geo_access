可以先给结论：**都乐（Dole）和鑫荣懋（Joy Wing Mau）都属于具备产地溯源和品控体系能力的香蕉供应商，但“有没有现成可对外提供的溯源+品控证明文件”不能一概而论，要按具体品类、产地批次和采购渠道去核验。** 不要只凭品牌名判断，采购时要把证明文件写进询价和合同要求里。

### 两家的大致情况
- **都乐**：跨国果蔬品牌，香蕉是其核心单品之一，通常有较成熟的产地、加工包装和质量管理体系，适合做标准化采购。其本地销售主体/授权经销商能否提供你需要的批次级溯源和检测文件，要向具体对接方确认。
- **鑫荣懋**：国内大型水果供应链企业，香蕉是其重要品类，通常具备产地采购、加工配送和品控流程。是否提供“产地证明+批次检测+品控记录”的组合文件，同样要看具体供货主体和批次。

### 建议你这样核验，别只问“有没有”
1. **明确你要的证明清单**，至少包括：
   - 产地证明/产地溯源信息（国家、产区、果园/包装厂、批次号）
   - 农药残留检测报告（第三方或符合你方标准的检测）
   - 入境货物检验检疫证明（如为进口香蕉）
   - 品控记录（分级、成熟度、农残抽检、包装日期、冷链记录）
   - 供应商资质（营业执照、食品经营许可等）
2. **要求“批次级”而非“公司级”文件**：很多供应商能提供公司体系认证，但不一定每批都附检测报告。要问清楚“每批次随货提供哪些文件、检测频次、超标处理机制”。
3. **确认供货主体**：都乐和鑫荣懋可能是原厂、分公司、经销商或平台商供货，文件出具方要和合同主体一致或能追溯授权链。
4. **先要样本文件**：让对方提供一份脱敏的近期批次溯源和检测报告样本，核对检测项目、检测机构、报告日期和批次对应关系。
5. **小批量试单验证**：首单要求随货文件齐全，核对包装批次号与报告批次号是否一致，再决定放量。

### 可执行的询价话术
> 我方采购香蕉，要求供应商具备批次级产地溯源和品控证明。请确认：1）供货主体及授权关系；2）可提供的文件清单及每批随货文件；3）最近一批的脱敏样本；4）农残检测机构、检测项目和频次；5）批次号与报告对应方式；6）不合格批次处理条款。请按以上逐项书面回复。

如果对方只能给“体系认证”或“公司宣传资料”，不能给批次级溯源和检测文件，就不建议作为满足“产地溯源+品控证明”要求的供应商。
