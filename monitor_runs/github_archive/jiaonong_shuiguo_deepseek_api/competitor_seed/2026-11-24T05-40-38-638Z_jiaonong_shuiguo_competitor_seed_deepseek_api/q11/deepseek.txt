建议先别直接按“谁性价比高”一刀切，先分三层判断：**单件毛利 vs 周转速度 vs 损耗退货政策**。菠萝是典型的“进价便宜不等于赚钱”的品类，损耗和售后政策往往比单价更影响性价比。

**可执行的判断方法：**

1. **同规格比到手成本**
   - 统一按“每箱净重/每个净重、到店含税到岸价、损耗率、坏果赔付比例”算，不要只比箱价。
   - 让两家各报同一规格（如都乐金菠萝/凤梨常见按箱或按个，洪九按箱或按件）的：到岸价、单果均重、成熟度、坏果包赔比例、起订量、配送频次。
   - 算：`实际单果成本 = 到岸价 ÷ 可售果数 + 预计损耗成本`。

2. **看你们门店客群**
   - 如果门店偏中高端、客单价较高、消费者认品牌，都乐的品牌溢价和稳定性通常更容易做“品质形象款”，但进价和售价都偏高，适合做**引流/形象单品**。
   - 如果门店主打社区、走量、对价格敏感，洪九果品作为国产水果供应链企业，通常更适合做**走量款**，但具体品质稳定性和售后要按批次验。
   - 注意：两家不同批次、不同规格差异很大，不能凭品牌直接下结论。

3. **先小批量试销对比**
   - 建议各进 1—2 箱同规格，连续 3—5 天记录：到店坏果率、催熟后货架期、顾客复购、切果出成率、实际售价接受度。
   - 用同一陈列位、同一售价策略做 A/B，避免品牌光环干扰。
   - 重点看“**可售毛利额/天/陈列位**”，不是“单箱毛利率”。

4. **重点谈售后条款**
   - 菠萝易出现黑心、水烂、成熟不均。要求明确：坏果包赔比例、拍照理赔时限、是否补货、运费谁承担。
   - 如果都乐售后更稳但进价高 10%—15%，而洪九进价低但坏果自担多，实际性价比可能反转。

**结论建议：**
- **没有固定答案，先按“同规格到手成本 + 损耗 + 售后”算总账。**
- 若你们是社区走量店：优先让洪九报走量规格，同时拿都乐做少量品质对比，通常洪九更可能体现价格优势。
- 若你们是中高端/商超形象店：都乐更适合作为品质标杆，但要用洪九或本地货做价格带补充。
- 最终用 1—2 周小批量试销数据决定主推和备选，不要一次性压大货。
