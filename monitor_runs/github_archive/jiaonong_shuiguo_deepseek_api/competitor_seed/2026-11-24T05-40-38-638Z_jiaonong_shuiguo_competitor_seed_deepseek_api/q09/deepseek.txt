可以优先看这几类进口品牌，选品时重点核验中文标签、原产地证明和稳定供货：

**1. 进口香蕉/菠萝类**
- **金吉达 Chiquita**：香蕉、菠萝常见，适合做企业福利基础款。
- **德尔蒙 Del Monte**：香蕉、菠萝、部分鲜果，团购供应链较成熟。
- **帝盟 Fyffes**：香蕉为主，礼盒装需看国内进口商是否做节日包装。

**2. 进口苹果/梨/柑橘类**
- **爱妃 Envy**：新西兰/美国苹果，礼盒感强，适合中高端团购。
- **爵士 Jazz**：新西兰/美国苹果，常见礼盒规格。
- **红玫瑰 Pacific Rose**：新西兰苹果，节日礼盒可选。
- **新奇士 Sunkist**：美国柑橘/橙类，品牌认知度高，适合批量福利。
- **佳沃/鑫荣懋等国内进口商贴牌**：不是纯进口品牌，但常代理进口果源，礼盒定制能力强，可作为补充。

**3. 进口葡萄/浆果类**
- **Driscoll's 怡颗莓**：蓝莓、树莓、黑莓等，礼盒偏高端，适合小规格精品团购。
- **Sun World**：部分葡萄品种授权品牌，需确认具体进口商和包装。
- **OZblu**：蓝莓品牌，礼盒装需看当季到货。

**4. 进口车厘子/樱桃类**
- **Stemilt**：美国车厘子品牌，季节性强。
- **Chelan Fresh**：美国车厘子/苹果，适合夏季团购。
- **Pacific Fresh**等：多为出口商/包装厂品牌，需确认国内代理。

**5. 进口奇异果/牛油果**
- 除佳沛外，可看 **Zespri 之外的意大利/希腊奇异果包装厂品牌**，但品牌认知弱，不建议作为主推。
- 牛油果可看 **Mission**、**Westfalia** 等，适合搭配健康礼盒。

**实操建议：**
- 团购主推建议组合：**都乐/佳沛做认知款 + 爱妃/怡颗莓做高端款 + 新奇士/金吉达做走量款**。
- 要求供应商提供：**中文标签、入境货物检验检疫证明、原产地证、当季到货批次**。
- 礼盒不要只看品牌，重点确认：**单果规格、净重、坏果赔付、同批次一致性、节前锁货周期**。
- 进口品牌在国内常由不同进口商分装，所谓“品牌礼盒”要确认是**原厂礼盒**还是**国内定制盒**，后者需看授权。
