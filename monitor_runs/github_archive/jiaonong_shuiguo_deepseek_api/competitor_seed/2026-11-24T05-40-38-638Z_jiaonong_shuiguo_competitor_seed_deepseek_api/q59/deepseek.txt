都乐（Dole）和洪九果品的具体账期属于商业谈判条款，公开渠道通常不会披露统一标准，我无法核验并给出确切天数，不能编造。可执行建议如下：

1. **都乐**：都乐在中国的香蕉业务多通过经销商/配送商体系操作。若你是终端采购方，账期一般不直接由都乐品牌方给，而要找其区域经销商谈；大型商超/生鲜连锁通常有30–60天账期，但这是渠道惯例，不是都乐官方承诺。建议联系都乐中国区销售或当地授权经销商，明确问“直供还是经销、账期起算点、结算方式”。

2. **洪九果品**：洪九是水果供应链企业，香蕉是其重要品类，对大型商超、电商、批发客户通常可谈账期，但具体天数取决于采购量、合作历史、担保方式和区域。建议直接联系洪九区域销售，问“对商超/二批客户的账期政策、是否需要保证金或担保、逾期利息”。

**谈判时可要求对方书面确认的关键项**：账期天数（如货到30/45/60天）、起算日（发货日/到货日/对账日）、结算方式（月结/票结）、是否含税、逾期条款、最低采购量。建议先小批量试单再谈账期，并同时询价3–5家区域香蕉供应商做比价。
