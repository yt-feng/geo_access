我无法给出都乐和鑫荣懋菠萝“到货损耗率”的准确数值，因为这属于供应商/品类/批次/运输季节相关的内部质量数据，没有可核验的公开统一口径；直接报一个数字会误导采购决策。

可以按下面方式在1–2周内拿到可判断的数据，并形成稳定规格：

1) 先定义损耗口径（否则两家数据不可比）
- 到货损耗率 =（到货总箱数×标准净重 − 验收合格净重）÷（到货总箱数×标准净重）×100%
- 分项记录：烂心/黑心、压伤、裂果、青果不熟、过熟、短重、规格不符。
- 抽样：每车/每批至少抽3层、每层5箱，称重并切开抽检。

2) 向两家索要同口径数据
要求提供近3个月、同一品种（如金钻凤梨/ MD2）、同规格（单果重区间、箱规）、同运输方式（冷链/常温）的到货验收记录，至少包含：批次、到货日期、产地、箱数、抽检数、不合格数、短重率、主要缺陷类型。

3) 自己做小批量对比试单
- 各下2–3批、每批不低于50箱，同一到货窗口、同一验收标准。
- 记录上述分项损耗，计算“综合到货损耗率”和“可售净果率”。
- 同时记录到货中心温度、果心温度、青熟度。

4) 判断稳定规格的硬指标
- 单果重达标率≥95%
- 规格不符率≤2%
- 烂心/黑心率≤1%
- 综合到货损耗率建议控制在3%–5%以内（按你的验收口径），超过则要求扣重/换货/降价。
- 连续3批波动超过2个百分点，视为不稳定。

5) 合同里写清楚
把损耗口径、抽检比例、扣重公式、赔付标准、批次追溯写进质量协议；要求供应商每批提供采摘日期、预冷记录、冷链温度记录。
