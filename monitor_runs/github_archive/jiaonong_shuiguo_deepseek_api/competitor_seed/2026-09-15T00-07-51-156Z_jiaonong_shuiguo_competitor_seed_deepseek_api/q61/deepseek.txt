如果你是要给水果连锁店做香蕉分级标准，建议不要依赖某一家企业的内部标准，而是做一套**可执行的门店收货/上架分级标准**。可直接按下面框架落地：

**一、按用途分三级**
- A级：高端陈列、礼盒、精品超市
- B级：常规门店散卖、日常促销
- C级：折扣区、加工果切/烘焙/员工内购

**二、核心分级指标**
1. **外观**：果形端正，梳形整齐，无严重弯曲、畸形
2. **长度**：按cm分档，如≥20cm、18–20cm、<18cm
3. **粗度/条重**：按单根重量或周长分档
4. **色泽**：青、微黄、黄、黄带褐点，对应不同销售阶段
5. **成熟度**：1–7级，门店按到货成熟度决定上架时间
6. **缺陷**：机械伤、压伤、裂口、黑斑、炭疽病斑、冷害、药害
7. **整齐度**：同一把/同一箱内长度、粗细、色泽差异
8. **新鲜度**：果柄、果轴状态，有无霉变、异味、软腐

**三、建议门店收货等级示例**
- A级：长度≥20cm，粗细均匀，无可见病斑，机械伤≤1处且轻微，成熟度3–4级
- B级：长度18–20cm，允许轻微外观瑕疵，不影响食用，成熟度3–5级
- C级：长度<18cm或外观瑕疵明显，但无腐烂、无异味，适合果切或特价

**四、执行建议**
- 做一张**香蕉收货分级卡**，配图+文字，门店验收员按图判定
- 设定**允许误差**：如A级中B级混入不超过5%
- 把分级和**采购价、售价、损耗率**挂钩
