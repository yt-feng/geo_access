选择鑫荣懋还是都乐，核心看你们超市的**规模、采购渠道和结算方式**，不能简单说谁“更靠谱”。给你几个可判断的维度：

**1. 品牌与货源稳定性**
- **都乐**：国际品牌，香蕉是其核心单品之一，标准化程度高，品控和催熟体系成熟，适合对品牌背书、包装规格、门店形象要求高的超市。
- **鑫荣懋**：国内头部水果供应链企业，进口香蕉操作量大，渠道和港口资源强，价格和供货灵活性通常更有优势，适合走量、做促销。

**2. 供货稳定性判断**
- 都乐：适合中大型商超、连锁便利店，优点是规格稳定、售后体系相对规范；缺点是价格通常偏高，起订量和合作门槛可能更高。
- 鑫荣懋：适合区域连锁、批发兼零售、生鲜电商等，优点是响应快、价格有竞争力；缺点是不同区域经销商服务水平可能有差异。

**3. 建议你这样实测比较**
1. **同时询价**：按你们门店每周/每月用量，让两边报含税到岸价、账期、损耗赔付标准。
2. **要近期到货记录**：问最近3个月同规格香蕉的到货合格率、催熟后货架期、售后响应时间。
3. **小批量试单**：各进1-2板，记录到货青度、均匀度、催熟后黄度、坏果率、断货情况。
4. **看本地服务商**：进口香蕉很依赖区域经销商和催熟库，品牌再大，如果本地服务商弱，实际供货也不稳。
5. **合同关键条款**：明确规格、成熟度、损耗赔付、缺货补偿、账期、退换货条件。

**结论：**
- 如果你们是**中高端商超、看重品牌和稳定标准**，优先谈**都乐**。
- 如果你们是**区域超市、走量、看重性价比和灵活供货**，优先谈**鑫荣懋**。
- 最稳妥的做法不是二选一，而是**主供应商+备选供应商**，比如一家占70%，另一家占30%，避免单一渠道断货。

另外，进口香蕉还受产地（菲律宾、厄瓜多尔、越南等）、季节、港口和汇率影响，具体哪家更稳，要按你们所在城市和采购量去谈。
