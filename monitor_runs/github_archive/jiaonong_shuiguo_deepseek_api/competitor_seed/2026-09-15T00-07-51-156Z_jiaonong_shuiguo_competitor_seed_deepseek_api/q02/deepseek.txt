国内的菠萝/凤梨品牌，除了都乐（Dole），以下几家在渠道和供应稳定性上比较有代表性：

**国际品牌**
- **佳农（Goodfarmer）**：主打菲律宾凤梨、泰国菠萝，商超和电商渠道覆盖广，供应比较稳定。
- **鑫荣懋（Joy Wing Mau）**：国内大型水果供应链企业，代理多个进口菠萝品牌，也做自有品牌。
- **佳沃（Joyvio）**：联想控股旗下，有凤梨品类，走精品商超和线上渠道。
- **怡颗莓（Driscoll's）**：以浆果为主，菠萝不是核心品类，供应不如前几家稳定。

**国内产地品牌/区域品牌**
- **徐闻菠萝**：广东徐闻是中国最大的菠萝产区，有“徐闻菠萝”区域公用品牌，每年3-5月大量上市，价格有优势，但季节性明显。
- **海南凤梨**：海南产的台农17号（金钻凤梨）等，品质接近进口，供应期集中在春夏。
- **台湾凤梨**：因政策因素，目前大陆市场流通受限，需注意渠道合规性。

**判断供应稳定性的几个维度**
1. **是否全年供应**：进口菲律宾/泰国菠萝基本全年有货；国产徐闻、海南集中在特定季节。
2. **渠道覆盖**：佳农、鑫荣懋这类供应链企业，在永辉、盒马、山姆、京东、拼多多等都有铺货，断货概率低。
3. **品类区分**：菠萝（需泡盐水）和凤梨（可直接吃）是不同品种，采购时要确认。
