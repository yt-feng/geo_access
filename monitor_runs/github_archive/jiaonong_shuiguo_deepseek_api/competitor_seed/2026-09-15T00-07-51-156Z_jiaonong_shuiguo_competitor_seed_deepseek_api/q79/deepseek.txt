结论先说：**都乐全年供应菠萝基本能做到，但“全年稳定供应适合做果酱的菠萝”要看品种、区域和你的采购量；洪九果品更偏水果分销和供应链平台，能不能做到要按它的实际货源、加工能力和你的订单条件去谈，不能直接下结论。**

分开看：

**1. 都乐**
- 都乐是全球水果品牌，菠萝是其强项品类之一，有全球产地和供应链体系。
- 从“全年有菠萝”这个角度，通常可以通过不同产区轮换实现，比如菲律宾、泰国、哥斯达黎加等产地搭配。
- 但茶饮店做果酱，关注的不只是“有菠萝”，而是：
  - 品种是否适合熬酱，比如酸甜比、纤维感、出汁率、香气；
  - 成熟度是否稳定；
  - 到货规格是否统一；
  - 价格是否全年波动可控；
  - 是否能按你需要的频次和批量供货。
- 所以更准确的说法是：**都乐具备全年供应菠萝的能力，但是否适合做你的果酱原料，要拿样品试制和确认年度供应协议。**

**2. 洪九果品**
- 洪九果品是国内较大的水果分销和供应链企业，优势在渠道、产地采购和分销网络。
- 它能不能全年供应菠萝，取决于：
  - 它当年是否把菠萝作为稳定单品；
  - 它的货源是国产菠萝还是进口菠萝；
  - 能否做长期协议、锁量锁价；
  - 是否能提供适合加工的规格。
- 洪九不一定像都乐那样以菠萝自有品牌供应链见长，更多是平台型、分销型能力。因此不能简单说“能”或“不能”，需要直接问它：
  - 全年12个月能否稳定供货；
  - 主要产地和品种；
  - 月度可供量；
  - 是否支持年度框架协议；
  - 加工用果的价格和等级。

**3. 对茶饮店更实际的建议**
- 不要只找一家。菠萝有季节性，全年供应通常靠多产地、多供应商组合。
- 可以让都乐、洪九同时报价，并各拿样品做果酱测试。
- 重点问清楚：
  - 全年每月可供品种和产地；
  - 糖度、酸度、成熟度标准；
  - 是否可提供冷冻果块、果泥、浓缩汁等加工原料；
  - 最小起订量、送货周期、锁价周期；
  - 断供时的替代方案。
- 如果门店规模不大，更现实的是找**冷冻菠萝果块/果泥/果酱原料供应商**，而不是只依赖鲜果品牌。鲜果全年供应和加工原料全年供应是两回事。

**一句话总结：**
都乐大概率能全年供菠萝，但要做果酱需确认品种和加工适配；洪九果品要看实际品类和合作条件，不能默认它一定能全年稳定供。最稳妥的是两家都谈，同时准备冷冻果块或果泥的备选供应链。
