都乐和鑫荣懋都属于国内进口/高端水果供应链里比较成熟的玩家，但两家都不是纯快递型物流，而是“产地集货+冷链干线+销地分拨+城配”的模式。菠萝产地直发（尤其菲律宾/泰国/国产徐闻、海南等）的时效，关键不在品牌本身，而在你走的是哪种合作方式：是买断货、代销、还是只借他们的仓配。

下面按可判断的口径说。

**1. 都乐**
- 都乐强在进口香蕉、菠萝等品类的全球采购和国内冷链分拨，通常有较稳定的产地直发/港口入关后分拨能力。
- 如果你和都乐做产地直采或通过其供应链体系发货，一般时效取决于：
  - 进口菠萝：从菲律宾/泰国产地到国内口岸，再到区域仓，通常按“周”级别安排船期/柜期，不是快递次日达概念。
  - 国内分拨到销地：一线/新一线城市通常 1-3 天；二三线及偏远地区 2-5 天或更久。
  - 如果都乐已把货铺到区域仓，城配时效会快很多，但这时就不算严格“产地直发”。
- 都乐的优势是标准化和品控，劣势是对小批量、非计划性订单不够灵活，起订量和合同门槛通常较高。

**2. 鑫荣懋**
- 鑫荣懋同样是国内头部水果供应链企业，进口和国产水果都有布局，菠萝类目也有操作。
- 它的物流时效通常也依赖区域仓和冷链干线：
  - 产地/口岸到区域仓：按批次和线路，常见 2-7 天。
  - 区域仓到门店/前置仓：核心城市 1-2 天，周边 2-4 天。
  - 若做全国多仓分拨，整体到消费者或门店的时效可控制在 2-5 天左右，偏远地区更长。
- 鑫荣懋在商超、批发、电商仓配上有较强履约经验，适合有稳定量的B端客户；小批量、临时直发同样不占优势。

**3. 直接结论**
- 如果你要的是“今天下单、明天从产地发到消费者”这种生鲜电商直发，都乐和鑫荣懋都不是最优解，它们的模式更偏批量、计划性、仓配分拨。
- 如果你有稳定单量、能接受按批次发货：
  - 核心城市时效：通常 2-4 天可到。
  - 非核心区域：3-7 天较常见。
  - 进口菠萝还要叠加船期/清关时间，不能只看国内段。
- 如果单量小、SKU多、要求快，建议直接找产地合作社/产地代办+快递或专线冷链，而不是依赖都乐/鑫荣懋的直发。

**4. 实操建议**
- 不要只问“时效几天”，要问清楚：
  1. 是产地直发，还是区域仓发货？
  2. 起订量、结算方式、损耗谁承担？
  3. 冷链是全程温控还是干线冷链+普通城配？
  4. 菠萝成熟度是按发货地还是到货地标准？
  5. 售后是包赔比例还是按单理赔？
- 最稳的办法：让两家分别给你一条真实线路的报价和时效承诺，比如“徐闻/菲律宾产地→你所在城市仓→消费者”，并写明超时赔付和损耗标准。这样比笼统问品牌时效更有意义。
