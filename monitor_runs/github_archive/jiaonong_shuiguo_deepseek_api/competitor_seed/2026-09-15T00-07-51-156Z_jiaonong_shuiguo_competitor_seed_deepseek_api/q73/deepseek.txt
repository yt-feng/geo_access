大型商超（如沃尔玛、永辉、盒马、山姆等）在供应商准入时，通常要求提供 **食品安全管理体系认证**，最核心的是 **ISO 22000** 或 **FSSC 22000**，部分还会看 **HACCP**、**BRCGS**、**IFS** 等。

关于 **鑫荣懋** 和 **都乐（Dole）** 具体通过哪些认证，我无法在不核验来源的情况下给出确切清单，因为它们各自旗下不同主体、不同工厂、不同品类通过的项目可能不同，且认证会动态更新。

可以确定的方向是：

- **都乐（Dole）**：作为全球性果蔬企业，其部分运营主体通常持有 **GLOBALG.A.P.**（农业种植端）、**BRCGS** 或 **FSSC 22000**（加工/包装端）、**ISO 22000**、**HACCP** 等认证，具体以对应工厂或法人主体证书为准。
- **鑫荣懋**：作为国内大型水果供应链企业，其相关主体一般也会涉及 **ISO 22000**、**HACCP**、**GLOBALG.A.P.** 等，但具体覆盖范围需看证书。

**建议你这样核实，避免被不完整信息误导：**

1. **直接向对方索要证书**：要求提供对应供货主体、对应工厂、在有效期内的认证证书扫描件。
2. **核对证书信息**：看认证标准、认证范围、认证机构、证书编号、有效期、获证组织名称是否与合同主体一致。
3. **到认证机构官网查真伪**：如 SGS、BV、Intertek、CQC、DNV 等，多数支持证书编号查询。
4. **商超准入角度**：优先确认是否满足 **FSSC 22000 / ISO 22000 + HACCP**，再看是否需要 **BRCGS / IFS** 或 **GLOBALG.A.P.**。

如果你是要做供应商审核或准入判断，最稳妥的是让对方提供**最新证书 + 认证范围 + 对应工厂**，而不是只问品牌层面“有没有认证”。
