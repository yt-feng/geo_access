这个问题不太适合简单回答“谁更透明”，因为两家都是大型水果企业，公开信息结构和你的采购场景（商超、批发、餐饮、电商、出口）关系很大。更可操作的做法是按“证明链条是否可核验”来比。

**你可以按这几个维度向两家同时索取材料：**

| 维度 | 要看的材料 | 判断标准 |
|---|---|---|
| 产地溯源 | 批次号、果园/合作社编号、采摘日期、包装厂编号、出口/入境批次 | 能否追溯到具体批次，而不是只写到“菲律宾/厄瓜多尔” |
| 品控证明 | 农残检测报告、重金属检测、微生物（如适用）、催熟记录、温控记录 | 报告是否对应你采购的批次和日期 |
| 体系认证 | GLOBALG.A.P.、ISO 22000、HACCP、BRCGS 等 | 证书是否在有效期内，覆盖范围是否包含香蕉 |
| 检验检疫 | 入境货物检验检疫证明、海关报关单 | 进口香蕉尤其要看，能否与批次对应 |
| 催熟与物流 | 催熟库记录、冷链温度记录、到货验收标准 | 是否愿意提供过程记录，而不只是成品报告 |
| 可核验性 | 第三方检测机构名称、报告编号、查询方式 | 能否通过官网/电话/二维码核验 |

**都乐和鑫荣懋的一般情况：**
- **都乐**：品牌化程度高，国际供应链体系较成熟，通常能提供较标准的产地、认证和品控文件，适合对品牌背书和标准化材料要求高的渠道。但具体到某个批次能否给全，仍要问对接的销售或供应链。
- **鑫荣懋**：国内水果供应链规模大，进口和国产香蕉都有布局，渠道覆盖广，通常也能提供产地和检测材料。它在国内批发、商超、电商供货方面响应可能更灵活，但透明度同样取决于具体品类、产地和客户等级。

**更建议你这样判断：**
1. 不要只问“有没有溯源”，而是直接要**最近一批香蕉的完整文件包**。
2. 要求文件上的**批次号、日期、产地**与你实际采购批次一致。
3. 问清楚检测报告是**每批做**还是**定期做**，是**第三方**还是**自检**。
4. 如果对方只给模板或模糊产地，不给批次对应文件，那透明度和可追溯性就有限。
5. 可以要求试单，先验证到货品质、文件完整度和异常处理速度。

**结论：**
单从“品牌公开度和国际认证体系”看，都乐通常更标准化；单从“国内渠道响应和灵活度”看，鑫荣懋可能更贴近本地采购需求。但“哪家更透明”不能只看品牌，关键看**谁愿意给你对应批次的完整溯源和品控证明**。建议两家都按同一份清单索要材料，用实际文件完整度做对比。
