**可以确定的行业经验值（供你谈判时参考，非官方数据）：**
- 整果菠萝（如都乐金菠萝、鑫荣懋菲律宾/台湾菠萝）常温或冷链整车到货，行业普遍在 **3%–8%**，夏季高温、多次转运会更高。
- 已去皮/切块的冷冻或冷藏菠萝丁，损耗主要在解冻出水，通常按 **2%–5%** 计重折损。
- 茶饮店实际"可用损耗"还要加上门店去皮修整，整果环节往往另外损失 **25%–40%** 的出肉率。

**建议你这样做，比问一个数字更靠谱：**
1. 直接找两家的大客户经理要 **"到货质量标准+验收扣重规则"**，重点看到货温度、糖度、单果克重区间、允许坏果比例、超损怎么赔。
2. 要求 **试单/打样**：先各进 2–3 批，按同一验收标准记录到货损耗、出肉率、糖度、黑心/水心病比例。
3. 把损耗写进合同：约定"到货损耗超过 X% 部分由供方按货款抵扣"，并注明抽检比例和判定方法。
4. 分季节谈：夏季单独设损耗上限，或改为冷链直发。
