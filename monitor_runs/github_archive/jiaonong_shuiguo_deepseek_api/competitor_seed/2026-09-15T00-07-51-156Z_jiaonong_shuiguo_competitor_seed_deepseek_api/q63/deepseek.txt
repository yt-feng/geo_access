我无法直接核验都乐或洪九果品当前对社区团购渠道是否有“散装/小包装香蕉”的具体供货政策，所以不能给你一个确定的“有/没有”结论。可以给你几个可执行的判断和问法，避免被渠道话术带偏。

**先分清“散装”的两种含义**
1. **无包装裸果**：通常只适合门店/档口，社区团购分拣、配送损耗大，品牌方一般不愿做。
2. **小规格预包装**：比如2-3根装、500g装、1kg装，这才是社区团购常说的“小包装”。都乐、洪九这类品牌更可能提供的是这种，而不是真正的裸散装。

**怎么快速确认**
- 找**都乐/洪九的区域经销商或城市代理商**，不要只问总部客服。社区团购通常走经销商、批发市场或区域供应链。
- 直接问这4个问题：
  1. 有没有**小规格预包装香蕉**，最小起订量是多少？
  2. 是**品牌原厂小包装**，还是你们**二次分装**？
  3. 供货价按**斤/箱/份**怎么算，是否含包装和损耗？
  4. 社区团购渠道有没有**区域保护或授权限制**？

**如果品牌没有合适小包装，常见替代方案**
- 找**本地批发商做二次分装**，用都乐/洪九的货自己包成2-3根装或500g装。
- 换**国产香蕉产地直发**，做小包装更灵活，但品牌溢价低。
- 用**进口蕉其他品牌**或区域品牌，往往比都乐、洪九更容易谈小规格和社区团购价。

**我的建议**
先按“小规格预包装”去谈，不要执着于“散装”。如果对方只说“有散装”，你要追问是不是原厂包装、是否适合团购分拣。否则大概率是让你自己回去分装，损耗和人工都要算进成本。
