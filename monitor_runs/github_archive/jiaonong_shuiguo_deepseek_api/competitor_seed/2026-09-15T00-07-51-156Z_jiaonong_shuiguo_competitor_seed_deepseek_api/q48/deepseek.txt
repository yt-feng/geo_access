大型商超（如沃尔玛、永辉、盒马、山姆等）在引入水果供应商时，通常会要求提供**食品安全管理体系认证 + 产品/种植端认证 + 追溯与检测能力**这几类资质。就鑫荣懋和都乐而言，可以按下面这样判断。

## 一、通常会被要求的资质类型

1. **食品安全管理体系类**
   - ISO 22000 食品安全管理体系
   - HACCP 危害分析与关键控制点
   - FSSC 22000（部分商超更认可）
   - BRCGS / IFS（偏出口或高端零售）

2. **种植/产品端认证**
   - GLOBALG.A.P.（全球良好农业规范，果蔬供应商很常见）
   - 中国良好农业规范 GAP
   - 有机产品认证（针对有机品类）
   - 绿色食品认证（针对特定产品）

3. **流通与追溯类**
   - 食品经营许可证
   - 可追溯体系认证/审核
   - 第三方检测报告（农残、重金属等）

4. **企业信用与合规类**
   - 营业执照、进出口资质（如涉及进口水果）
   - 海关备案、检验检疫相关资质

## 二、鑫荣懋的情况

鑫荣懋是国内头部水果供应链企业，通常具备较完整的水果全链条管理能力，常见可对外提供的资质包括：

- ISO 9001 质量管理体系
- ISO 22000 或 HACCP 食品安全相关体系
- GLOBALG.A.P. 或中国 GAP（部分基地/品类）
- 食品经营许可证
- 进出口相关资质（其进口水果业务较多）
- 第三方农残、重金属等检测报告

不过要注意：**具体到某一单品、某一产地、某一批次，认证覆盖范围可能不同**。大型商超审核时往往看的是“该供应商+该品类+该基地”是否在认证范围内，而不是只看公司总部有没有证书。

## 三、都乐的情况

都乐（Dole）是国际果蔬品牌，体系认证通常更偏国际化，常见包括：

- ISO 22000 / HACCP
- GLOBALG.A.P.（其海外农场和部分合作基地较常见）
- BRCGS 或 IFS（部分加工/包装环节）
- 有机认证（针对有机香蕉、有机菠萝等品类）
- 食品安全相关体系及可追溯体系
- 进出口、检验检疫相关合规资质

同样地，**都乐不同产品线、不同国家/地区基地的认证并不完全一致**，商超审核时会按具体品类和供应链路径核查。

## 四、给商超采购/审核的可执行判断

如果你是要做供应商准入，建议不要只问“有没有资质”，而应按下面清单逐项核验：

1. **要证书原件或带二维码的电子证书**
2. **核对认证范围**：是否覆盖你采购的品类、加工环节、产地
3. **核对有效期**：是否在有效期内，是否临近复审
4. **核对认证机构**：是否为国家认监委认可或国际互认机构
5. **要最近一次审核报告或不符合项关闭记录**
6. **要近批次第三方检测报告**
7. **要可追溯演练记录**：能否从门店批次追到基地/批次

## 五、结论

- **鑫荣懋**：通常具备 ISO 9001、ISO 22000/HACCP、GAP、食品经营许可、进出口及检测报告等，具体看品类和基地。
- **都乐**：通常具备 ISO 22000/HACCP、GLOBALG.A.P.、BRCGS/IFS、有机认证等，具体看产品线和产地。
- **商超审核关键**：不是“公司有没有证”，而是“你采购的这个单品、这个基地、这个加工环节是否在认证覆盖范围内”。
