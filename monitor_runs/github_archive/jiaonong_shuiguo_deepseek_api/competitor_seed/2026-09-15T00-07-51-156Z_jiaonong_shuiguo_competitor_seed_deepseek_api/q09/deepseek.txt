除了都乐和佳沛，进口水果礼盒常被用作礼品团购的品牌还有这些，按品类给你梳理：

**综合类进口水果品牌**
- **新奇士（Sunkist）**：美国柑橘类代表，脐橙、夏橙礼盒认知度高，团购常见。
- **怡颗莓（Driscoll's）**：美国浆果品牌，蓝莓、树莓、黑莓礼盒，偏高端精致路线。
- **乐淇（Rockit）**：新西兰小苹果，单果小、包装精致，礼品属性强。
- **爱妃（Envy）**：新西兰苹果，果肉抗氧化、口感甜脆，礼盒档次不错。
- **爵士（Jazz）**：新西兰苹果，和爱妃同属T&G体系。
- **红玫瑰（Rose）**：新西兰苹果，部分渠道有礼盒。
- **Mr. Apple / 华盛顿苹果**：美国苹果产区品牌，礼盒常见。

**按品类的进口品牌**
- **车厘子/樱桃**：Stemilt、Chelan Fresh、Starr Ranch、Rainier（蕾妮，高价黄樱桃）
- **蓝莓**：Driscoll's、Hortifrut、Berries Paradise
- **牛油果**：Mission（墨西哥）、Hass 产区品牌
- **提子**：Sun World、Crimson Seedless 相关品牌
- **奇异果**：佳沛之外还有 **Kiwifruitz** 等，但认知度远不如佳沛
- **柑橘**：Sunkist、Wonderful（主要是石榴和柑橘）

**团购选品建议**
1. **要认知度**：佳沛、都乐、新奇士、怡颗莓最稳，员工/客户一看就懂。
2. **要差异化**：乐淇、爱妃、蕾妮车厘子，包装精致、单价高，适合预算充足的中高端福利。
3. **要控成本**：混装礼盒（柑橘+苹果+蓝莓）比单一高端单品更容易把单价压下来。
4. **注意季节**：车厘子（冬季智利/澳洲）、蓝莓（全年但产地轮换）、柑橘（冬春）都有明显档期，团购要提前锁定产季和货源。
