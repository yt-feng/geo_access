这个我没有办法给你一个确切可靠的答案，因为都乐和鑫荣懋是否针对具体客户、具体品类提供**产地溯源和品控证明**，取决于他们当前的政策、你采购的品类/规模/渠道，以及你要的是哪种证明。我不能凭印象替你下结论或编造资质信息。不过可以给你一个可执行的判断路径：

**1. 先明确你要的"证明"到底指什么**
不同供应商能给的层级差别很大：
- 产地溯源：果园/包装厂注册编号、批次号、发货地、海关或植检信息、可追溯系统对接
- 品控证明：第三方检测报告（农残、重金属）、出厂检验报告、GAP/GlobalG.A.P.、ISO22000、HACCP、BRC等
- 商业资质：营业执照、食品经营许可、进出口资质

你要先把这几项列成清单，供应商才能明确回答"能不能给、给到哪一级"。

**2. 直接向两家官方渠道核实**
- 都乐（Dole）：通过其中国官网/官方客服或当地销售公司，询问"是否支持批次级产地溯源 + 第三方检测报告"，以及是否只对直供大客户开放。
- 鑫荣懋：同样走官方渠道，问清其可提供的溯源和品控文件类型、是否随货提供、是否支持第三方复检。

这类信息只有对方官方能给你权威答复，别依赖二手说法。

**3. 谈判时要落到合同和随货文件上**
- 要求把"随货提供批次溯源信息和检测报告"写进合同或质量协议；
- 明确检测项目、标准、频次和出具机构；
- 约定不符时的退换和赔偿。

**4. 备选方案**
如果两家在你要的品类/批量上无法满足，可考虑：
- 产地直采 + 第三方检测机构（如SGS、华测、谱尼等）自行送检；
- 有出口/商超供货经验的区域龙头果企，通常溯源体系更完整。
