进口菠萝（主要是菲律宾/哥斯达黎加/泰国等产地的MD-2金菠萝）到货损耗高，核心不是"某一家公司有秘方"，而是**把损耗拆成环节、每个环节用可量化的动作卡住**。都乐和鑫荣懋的做法逻辑其实高度相似，下面按可操作的维度说。

## 先定位损耗到底发生在哪

进口菠萝全程损耗一般分四段，先测哪段占比大，再对症：
- **产地采收/预冷**：采后未及时预冷，田间热导致内部褐变
- **海运/冷链**：温度波动，菠萝对低温敏感（低于7℃易冷害，心部发黑）
- **口岸/中转**：清关滞留、温差冲击
- **到仓后催熟/分选/上架**：催熟不均、机械伤、货架期短

大商的损耗差异，八成出在**冷链温控和催熟管理**，而不是末端。

## 关键控制点（可照着做）

**1. 产地端**
- 采收成熟度卡在"七成左右"，太熟直接海运烂，太生到货糖度上不来
- 采后**快速预冷到10–13℃**，这是菠萝的适温区，别照搬其他水果的0–4℃
- 分级装柜，剔除机械伤果，伤果是霉菌的起点

**2. 海运/冷链**
- 全程**10–12℃、相对湿度85–90%**，菠萝不能进普通冷藏低温区
- 用气调或带通风的冷藏柜，避免乙烯积累催熟自己
- 到港前做温度记录仪回溯，一旦断链单独隔离处理

**3. 口岸到仓**
- 缩短清关滞留，滞留果单独标记
- 到仓立即复检：硬度、糖度、心部颜色

**4. 催熟与分选（损耗重灾区）**
- 菠萝是**非呼吸跃变型**，催熟逻辑和香蕉完全不同，过度催熟只会加速烂
- 按到货成熟度分批，先进先出，**按订单催熟**而不是一次性全催
- 分选线剔除软果、褐心果，单独走加工/特价渠道，别混进正价货架

**5. 数据化**
- 每批记录：产地、船期、温控曲线、到货损耗率、糖度
- 找出"高损耗批次共有的特征"（如某船期、某供应商、某温度段），反向谈判或调整采购

## 关于都乐 / 鑫荣懋

这两家的相对优势不在某个隐藏技术，而在于：
- **垂直整合**：都乐自己有种植和品牌标准，源头可控性强；鑫荣懋靠全球采购网络+国内渠道分销能力
- **规模摊薄**：大批量能承受单柜损耗，且能按渠道分流（正价、加工、B端）
- **标准化SOP**：温控、催熟、分选有固定参数和批次追溯

**但公开信息里没有他们具体的温控参数和催熟曲线**，上面给的是行业通用的菠萝冷链管理区间，不是这两家的内部数据，这点要说清楚。

## 给你的落地建议

如果你是在做进口菠萝生意：
1. 先装温度记录仪，跑3–5柜，**定位损耗发生在哪一段**
2. 重点查海运和到仓催熟两个环节，多数问题出在这
3. 建立批次档案，把损耗率和供应商/船期挂钩
4. 别追求"零损耗"，而是把**正价出货率**作为核心KPI，软果、次果走加工渠道止损
