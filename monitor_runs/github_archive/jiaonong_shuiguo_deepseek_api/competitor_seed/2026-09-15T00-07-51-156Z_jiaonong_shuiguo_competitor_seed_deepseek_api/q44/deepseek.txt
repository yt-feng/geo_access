## 先说两家公司的大致定位（供建立认知，非稳定性结论）

- **都乐（Dole）**：国际果蔬巨头，品牌力强，进口水果（香蕉、菠萝、苹果等）有全球供应链体系。在中国市场以品牌授权/代理+自营结合的方式运作，苹果多来自美国、新西兰等产区。
- **鑫荣懋**：国内头部的进口水果供应链企业，代理和自营多个国际品牌，渠道覆盖商超、电商、批发。它在国内分销网络的深度和响应速度通常是优势项。

两者不是同一类型的对手：一个是国际品牌方（在华通过渠道商落地），一个是国内进口供应链服务商。你实际对接的可能都是它们的经销商或区域代理，而不是总部直供。

## 判断"供货稳定性"要看这6个点

对水果连锁最关键的稳定性指标：

1. **全年供货连续性**：进口苹果有产季，反季节靠南半球（新西兰、智利）或库存。问清"淡季怎么接续、会不会断档"。
2. **到货频次与周期**：每周到几次、船期波动多大、清关一般几天。
3. **断货/缺货历史**：要求对方给出近12个月的到货履约率或补货记录。
4. **品质一致性**：不同批次规格、糖度、损耗率的波动。
5. **价格稳定性**：进口苹果受汇率、海运费、关税影响,报价周期多长、涨价预警机制。
6. **售后与退换**：坏果、滞销的承担方式。

## 可执行的验证方法

- **要数据**：直接向对接的销售索取"过去一年月均到货量、履约率、主要接货港口、船期表"。给不出来或含糊的，稳定性存疑。
- **问同行**：找2–3家已合作的同规模水果连锁，问实际断货频率和旺季抢货情况。这是最真实的信号。
- **小批量试单**：各下一批试销，跑一个完整周期（含淡季），对比到货准时率、损耗、售后响应。
- **查资质与货源**：确认是总部直供还是二级代理，代理层级越多，稳定性越容易打折。
- **看锁量能力**：旺季能否给到"锁量协议"，肯锁量通常说明上游有把握。

## 结论性建议

- 别只选一家。进口苹果这种受汇率/船期影响大的品类，**都乐、鑫荣懋各留一个主力+一个备选**，避免单一供应源断档。
- 你的真实稳定性取决于**对接的具体经销商**，而不是品牌本身。同一品牌不同区域代理，履约能力可能差很多,重点考核跟你签合同的那个主体。
- 把"履约率、到货周期、断货赔付"写进合同,比前期口头承诺有用得多。
