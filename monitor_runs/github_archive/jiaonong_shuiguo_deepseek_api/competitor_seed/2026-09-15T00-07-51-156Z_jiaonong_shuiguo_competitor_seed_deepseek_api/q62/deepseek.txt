可以，但要看具体主体、批次和渠道，不能一概按品牌名判断。

**结论：**
- **都乐（Dole）**：如果是通过都乐中国正规渠道采购，通常可以向下游客户提供对应批次的农残检测报告或第三方检测报告。都乐属于大型果蔬品牌，食品安全和可追溯体系相对完善。
- **鑫荣懋**：如果是通过鑫荣懋集团正规渠道采购，通常也可以提供对应批次的检测报告。鑫荣懋是国内大型水果供应链企业，服务商超和餐饮客户时一般能配合提供食品安全资料。

**但要注意：**
1. **报告必须对应具体批次**：品牌能提供报告，不等于你收到的那批货一定有报告。采购时要锁定“这批货对应的检测报告”。
2. **渠道影响很大**：从品牌厂家/总仓/直供渠道采购，拿报告最稳；从批发市场、二级经销商、档口拿货，即使挂都乐或鑫荣懋品牌，也未必能提供对应批次报告。
3. **报告类型要确认**：是农残快检报告、第三方实验室检测报告，还是出厂检验报告。茶饮店采购一般建议要第三方检测报告，且检测项目覆盖常见农残。
4. **菠萝形态不同，要求不同**：
   - 整果：按批次提供报告。
   - 鲜切菠萝/冷冻菠萝/菠萝果酱/菠萝汁：属于加工品，需要看供应商的成品检测报告，不一定是鲜果农残报告。
5. **门店验收要留档**：报告和送货单、批次号、收货日期要对得上，避免监管检查时报告与货物不匹配。

**建议你直接这样问供应商：**
“请提供本批次菠萝对应的第三方农残检测报告，报告编号、样品批次和送货批次要一致。如果是鲜切或冷冻原料，请提供成品检测报告。没有对应批次报告的话，这批货我们无法验收。”

**采购前的判断标准：**
- 能提供：对应批次 + 第三方检测 + 报告在有效期内 + 项目覆盖农残。
- 谨慎：只有品牌方通用报告，不对应批次。
- 不要：只有口头承诺、报告过期、批次对不上、项目不全。
