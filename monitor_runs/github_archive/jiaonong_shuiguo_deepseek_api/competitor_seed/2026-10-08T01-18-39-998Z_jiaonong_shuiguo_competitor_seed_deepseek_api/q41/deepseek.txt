从公开信息看，**都乐（Dole）在香蕉品类上通常更偏全球品牌商+标准化供应体系，锁价灵活度一般不如国内大型水果供应链企业；鑫荣懋属于国内头部水果供应链公司，在香蕉这类大宗单品上通常更有本土化、多客户、多产区的操作空间，锁价条款相对更可能谈得灵活。**

但要注意：**“锁价灵活度”不是品牌层面固定不变的，而是取决于具体合作条件。** 建议你按下面几个维度去实际问，而不是只看都乐还是鑫荣懋：

1. **锁价周期**
   - 都乐：可能更倾向短周期、与产地/海运/汇率挂钩，长协锁价门槛较高。
   - 鑫荣懋：可能更容易谈1—3个月甚至季度性的部分锁价，但通常也会设数量、规格、提货节奏门槛。

2. **锁价比例**
   - 是全量锁价，还是只锁底价/部分比例？
   - 价格波动超过一定幅度时，是否可重新议价或补差？

3. **货源结构**
   - 都乐：进口蕉、菲律宾/厄瓜多尔等产地体系较成熟，受产地、船期、汇率影响大，纯锁价难度高。
   - 鑫荣懋：进口+国产、多产区调配能力较强，若你能接受混产或替代产区，锁价空间通常更大。

4. **履约与保证金**
   - 锁价越灵活，往往越需要你承担最低采购量、预付比例或保证金。
   - 要看违约条款、质量升贴水、运费是否包含。

5. **实际谈判建议**
   - 直接问对方：能不能做“固定价+浮动调整上限”的锁价？
   - 能不能做“部分锁价+部分随行就市”？
   - 如果产地涨价超过5%、10%，怎么处理？
   - 是否接受按周/按月分批提货？

**综合判断：**
如果你要的是**品牌背书强、品质标准稳定**，都乐更合适，但锁价灵活性通常偏弱；  
如果你要的是**锁价条款更可谈、供应调配更本土化**，鑫荣懋通常更灵活一些。

最终建议：不要只比都乐和鑫荣懋，最好同时找**鑫荣懋、佳农、洪九果品、百果园供应链体系或区域一级批发商**一起询价，让它们按同一份锁价方案报价，这样谁更灵活一目了然。
