账期通常不是品牌方公开统一披露的固定政策，实际会按**采购量、合作年限、客户类型（商超/电商/批发/加工）、区域和信用评级**一单一议。都乐、洪九这两家都没有对外公开可核验的“标准账期”，我不能给你确定天数。

能确认的行业情况：
- **都乐（Dole）**：以品牌水果和供应链为主，对大型商超、电商通常可能有账期，但具体天数由都乐当地公司或授权经销商与客户谈，不同渠道差异很大。
- **洪九果品**：做水果分销和供应链，客户里商超、电商、批发渠道都有，账期同样按客户资质和采购规模确定，没有公开统一标准。

要拿到真实账期，建议直接做这四步：
1. **找对签约主体**：联系都乐中国/区域公司或授权经销商，洪九则联系其区域销售或供应链金融部门。
2. **问清账期口径**：是“货到后多少天付款”“月结30/60/90天”，还是“预付+尾款”，是否含承兑汇票。
3. **准备好资质材料**：营业执照、近半年采购流水、财务报表、纳税记录、历史回款记录，这些直接决定能不能给账期和给多久。
4. **用采购量换账期**：先报月度/年度采购计划，再谈“首单现结、次单起月结”或阶梯账期，比直接问“你们账期多久”更容易拿到方案。

如果你要的是**能提供账期服务的香蕉供应商**，更现实的路径是：
- 优先找**一级批发商、区域供应链公司、进口蕉承销商**，他们比品牌方更常给账期；
- 同时谈**供应链金融/保理**，由平台或资金方垫资，供应商接受度更高；
- 对都乐、洪九这类品牌/大型供应链企业，账期往往只给**有规模、有信用、有长期合作**的客户。
