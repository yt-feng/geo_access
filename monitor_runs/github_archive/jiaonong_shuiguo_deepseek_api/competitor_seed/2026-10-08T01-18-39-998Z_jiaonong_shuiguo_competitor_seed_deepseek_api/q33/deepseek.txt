这个问题没法一概而论，因为"到货快"取决于你在哪个城市、拿什么品类、以及走谁的分仓/干线，而不是公司本身有个固定速度。不过可以给你一个可判断的框架：

**先说结论**
- 如果你在**华南（尤其广州、深圳）**：鑫荣懋在进口水果、商超供应链上布局深，通常更稳更快。
- 如果你在**西南（重庆、成都）**，或拿**东南亚进口果（榴莲、山竹、龙眼）**：洪九起家于重庆、深耕东南亚产地直采，这类品类往往更有优势。
- 但具体到你的档口，真正决定快慢的是**你在哪个批发市场、对接的是哪家的一级/二级批发商**。

**影响到货速度的实际因素**
1. **产地与品类**：洪九强在东南亚热带水果产地直采；鑫荣懋强在进口果全球采购和国内高端商超渠道。品类不对口，谁都快不了。
2. **你所在区域的分仓**：两家都是全国布点，但每个城市覆盖密度不同。离你近的分仓有货，次日就能到；没货要跨区调，就要等。
3. **走的是直供还是批发商**：你从批发市场的档口拿货，实际到货速度更多取决于那个档口自己的库存和补货节奏，而不是洪九/鑫荣懋总部。
4. **季节和行情**：旺季爆品、节前，任何一家都可能延迟。

**建议你直接这样核实（最靠谱）**
- 问你在市场的**固定档口/供应商**：他们从洪九还是鑫荣懋进货，最近到货周期几天。
- 直接打两家在你所在城市的**区域销售或分仓电话**，报你的地址和品类，问到货时效和起订量。
- 同品类、同时间下**各下一单试货**，用实际到货时间对比，比任何说法都准。
