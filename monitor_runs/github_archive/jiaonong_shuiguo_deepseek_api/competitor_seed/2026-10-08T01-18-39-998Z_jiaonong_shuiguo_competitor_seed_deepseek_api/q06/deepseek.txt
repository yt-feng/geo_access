这个问题涉及具体供应商的运营数据，我无法核验鑫荣懋和都乐各自的到货率、履约率、断货率等内部指标，所以不能给出"谁更稳定"的确定结论——任何拍脑袋的排名对你做采购决策都是不负责任的。

但可以给你一个**可执行的判断框架**，你自己去验证：

**1. 稳定性取决于你的采购结构，不是品牌本身**
- 都乐是品牌商，走的是品牌化+多产地布局（菲律宾、厄瓜多尔、国内等），强在品控和品牌溢价，但如果你是中小商超、单量不够大，拿到的可能是二级分销，稳定性反而打折。
- 鑫荣懋是国内头部水果供应链企业，强在国内网络覆盖和配送时效，尤其在华南、华东。它的稳定性更多体现在"响应速度"和"补货灵活度"。

**2. 真正要考核的指标（建议你直接向两家要数据）**
- 近12个月对你所在区域的**订单满足率 / 到货准时率**
- **缺货时的补货响应时间**（几小时还是几天）
- 是否有**备用产地/备用仓**支撑（单一产地依赖是断货最大风险）
- 旺季（如春节、台风季）的保供承诺和违约条款

**3. 实操建议：不要二选一，做双供应商**
香蕉是高频刚需、易损耗、价格波动大，最稳的做法是**主供70%+备供30%**，两家都留着。断货风险通常来自"单点依赖"，而不是选错了品牌。

**4. 可以先小范围测试**
拿你某个门店或某个品类做2-4周的平行供货对比，记录实际到货率、损耗率、断货次数，用你自己的数据下结论，比听任何人的经验都准。
