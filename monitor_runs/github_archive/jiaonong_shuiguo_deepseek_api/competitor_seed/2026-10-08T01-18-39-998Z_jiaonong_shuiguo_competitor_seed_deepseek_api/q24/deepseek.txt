从公开可查的常规做法看，**都乐（Dole）的香蕉商品规格分级通常比鑫荣懋更细、更偏零售标准化**；但如果你说的是“按重量/条数/成熟度/外观缺陷”这种采购验收分级，两家都可以做得很细，关键看你拿到的**具体采购合同或企业标准**，而不是品牌本身。

可直接判断如下：

1. **零售包装与商品化分级**
   - **都乐**：通常按“单根重量/把重/每箱净重/根数/成熟度/外观等级”分得比较清楚，常见有不同规格的零售袋装、箱装，适合商超直接上架。
   - **鑫荣懋**：更多是渠道批发、商超配送、产地分选体系，规格也全，但对外公开的统一零售分级颗粒度往往不如都乐那么标准化呈现。

2. **产地与加工分级**
   - 两家都会按产地、品种、梳蕉/条蕉、把型、青熟度、伤斑、条重等做分选。
   - 真正决定“谁更细”的，是**你所在区域供应商实际执行的分选标准**，因为同一品牌不同工厂、不同季节、不同客户，规格表可能不同。

3. **超市采购建议**
   - 如果你要的是**直接上架、规格统一、损耗可控**：优先让都乐报完整规格表，比较每箱净重、每把根数、单根重量区间、成熟度、到店可售率。
   - 如果你要的是**大批量、成本优先、可定制验收**：让鑫荣懋按你的超市标准出分选方案，通常也能做到很细，甚至可定制。
   - 最稳的做法：向两家索要**当季实际供货规格书 + 验收标准 + 样品**，按同一张表对比，而不是只比品牌。

结论：  
**公开商品规格呈现上，都乐通常更细；实际采购分级能力上，两家都能做细，需以当季规格书和合同验收标准为准。**
