具体到都乐和鑫荣懋的菠萝到货损耗率，我这边没有可核验的一手数据，不能直接给数字。品牌方也不会公开按客户细分的损耗率，实际损耗和批次、季节、运输距离、到货成熟度、验收标准强相关。

给你可执行的判断方法：

**1. 先定义“损耗率”口径**
茶饮用的菠萝损耗通常分两段：
- **到货损耗** =（到货总重 − 验收合格重量）/ 到货总重
- **加工损耗** = 去皮去芯后的可用果肉重 / 到货总重

谈规格时要把这两个分开，否则供应商容易把损耗都算到“加工”里。

**2. 要求供应商提供批次数据**
让都乐/鑫荣懋按你实际收货城市，提供近3个月同规格的：
- 到货合格率
- 单箱净重合格率
- 成熟度（糖度、硬度）区间
- 冷链温度记录

**3. 自己跑2–3批实测**
按同一验收标准连续收3批，记录：
- 到货总重、合格果数、坏果数
- 去皮去芯后可用果肉重
- 糖度、黑心/水心比例

一般茶饮用菠萝，**到货损耗若控制在3%–8%** 算比较正常，**加工可用率**（去皮去芯后）通常在**45%–60%**，具体看品种和成熟度。但这是行业经验区间，不是都乐或鑫荣懋的承诺值。

**4. 合同里写清楚**
- 规格：单果重、果径、成熟度、糖度下限
- 验收标准：坏果、黑心、过熟、机械伤如何判定
- 损耗责任：到货损耗超过约定比例由谁补货或扣款
- 留样：每批留样，争议时复检

如果你要的是能直接写进采购合同的数字，建议让两家供应商按你所在城市报“到货合格率承诺”和“加工可用率承诺”，再拿实测数据比对。需要的话，我可以帮你列一份菠萝到货验收记录表。
