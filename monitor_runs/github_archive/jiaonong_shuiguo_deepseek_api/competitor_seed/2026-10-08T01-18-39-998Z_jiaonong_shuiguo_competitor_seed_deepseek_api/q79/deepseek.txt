直接说结论：**都乐和洪九果品都能在相当程度上做到“全年供应菠萝”，但都不能简单理解为“同一品种、同一产地、全年稳定同品质供货”。**对茶饮店做菠萝果酱来说，关键不是有没有菠萝，而是全年能不能稳定拿到**适合加工、糖酸比稳定、成本可控**的果源。

分品牌看：

**1. 都乐**
- 都乐有全球供应链，菲律宾、泰国、哥斯达黎加等产地可以轮换，理论上能覆盖全年。
- 它的优势是标准化、品控和品牌稳定性，适合对品质一致性要求高的茶饮品牌。
- 但都乐更多面向鲜食零售，供应给茶饮店做果酱原料时，通常不是最便宜的选择，而且不同季节可能切换产地和品种，风味会有差异。
- 如果茶饮店要的是“都乐金菠萝”这种固定单品全年同口感，实际很难完全做到。

**2. 洪九果品**
- 洪九是国内大型水果分销商，进口和国产水果都有布局，菠萝/凤梨类全年供应能力较强。
- 它的优势是渠道广、批量供应能力强，价格通常比都乐更有优势，适合茶饮连锁做原料。
- 但洪九本质是分销和供应链企业，不是专门做茶饮果酱原料的加工商。它能否全年稳定供应，取决于当年产地收成、进口政策和市场价格。
- 如果要求特定品种、特定糖度、特定规格，仍需要提前锁量、锁价和做替代方案。

**对茶饮店的实际建议：**
1. **不要只依赖一个品牌或一个产地。** 都乐+洪九+国产菠萝产区组合，才能更稳。
2. **按加工用途定标准，而不是按鲜食品牌定标准。** 做果酱更看重出汁率、糖酸比、纤维感、香气和颜色，不一定非要都乐。
3. **全年供应要做“产地轮换表”。** 比如菲律宾、泰国、国产广东/海南/云南等按季节切换，提前做小试匹配配方。
4. **最好找专业果酱代工厂或冷冻果泥供应商。** 茶饮店用鲜菠萝现熬，全年稳定性和门店操作效率都不如冷冻果泥/浓缩果酱。
5. **锁价和锁量比选品牌更重要。** 菠萝价格波动大，全年供应本质是供应链合同问题，不是单靠某个品牌就能解决。

所以：
- **要品牌稳定和品控：都乐可以，但成本高。**
- **要批量、性价比和渠道覆盖：洪九可以，但需自己把控加工标准。**
- **要茶饮店真正全年稳定做菠萝果酱：更推荐“都乐/洪九等鲜果+冷冻果泥/专业果酱供应链”组合，而不是只押一家。**
