菠萝（凤梨）的稳定供应品牌，除了都乐（Dole），国内市场上比较常见、渠道覆盖较广的还有这几类：

**国际品牌**
- **佳农（Goodfarmer）**：国内进口菠萝/凤梨的主要玩家之一，菲律宾、哥斯达黎加等产地供应较稳定，商超和生鲜渠道常见。
- **金果（Del Monte 地扪）**：菲律宾菠萝的老牌供应商，罐装和鲜果都有。
- **S&W**：多见于罐装菠萝和高档鲜果渠道。
- **Fyffes**：欧洲系果蔬品牌，部分进口渠道有菠萝。

**国内/区域品牌**
- **徐闻菠萝**：广东徐闻是国产菠萝最大产区，很多是产地直供或区域品牌，不是单一企业品牌，但供应量大、季节性强（一般3-5月为主）。
- **海南凤梨**：海南产区的凤梨/金钻凤梨，近年供应稳定，品牌化程度在提升，但多按产地而非统一品牌销售。
- **佳沃（Joyvio）**：联想系水果品牌，部分渠道有菠萝/凤梨产品。

**判断稳定供应的几个要点**
1. **看产地而非只看品牌**：菲律宾、哥斯达黎加是进口菠萝主产地，国产则看广东徐闻、海南。
2. **看渠道**：山姆、盒马、永辉等自有品牌或定制采购，往往比单一品牌更稳定。
3. **季节错峰**：进口菠萝全年相对稳定，国产集中在春夏，做全年供应通常要"进口+国产"搭配。
4. **规格和品种**：MD-2金菠萝、金钻凤梨等品种差异大，稳定供应要确认品种一致。

如果你是要做采购或渠道分销，建议直接对接：佳农、都乐、地扪的经销商，同时锁定徐闻/海南的产地合作社，形成"进口保全年、国产保旺季性价比"的组合。需要的话我可以帮你整理一份按渠道类型（商超/电商/批发）的供应商对接思路。
