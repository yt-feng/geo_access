都乐和洪九果品通常会为合作方提供品牌营销素材，但**没有公开的统一素材下载入口**，能否拿到、拿到什么，取决于你和他们的合作关系与授权范围。

**一般可获取的素材类型：**

- **都乐**：品牌Logo、产品标准图、产地/品种介绍、包装图、部分社交媒体图文模板。都乐对品牌视觉规范较严，通常通过对接的销售或市场人员提供，并可能要求素材使用前审核。
- **洪九果品**：以供应链和批发渠道为主，品牌营销素材相对不如都乐体系化。常见可提供的是产品实拍图、规格说明、产地信息，Logo使用需单独确认授权。

**建议你按以下方式推进：**

1. **先确认合作身份**：你是他们的经销商、渠道商，还是仅做内容合作？有采购或供货关系时，拿素材最顺。
2. **找对接口人**：都乐一般走销售/市场对接；洪九走区域销售或品类负责人。直接问“能否提供品牌授权素材包，用于哪些渠道发布”。
3. **明确用途和范围**：写清使用平台（电商详情页、短视频、直播、线下物料）、使用期限、是否需要审核。都乐大概率要求审稿。
4. **没有合作时的替代方案**：可自行拍摄实物、做原创内容，只做客观描述，不擅自使用其Logo和官方图，避免侵权。
