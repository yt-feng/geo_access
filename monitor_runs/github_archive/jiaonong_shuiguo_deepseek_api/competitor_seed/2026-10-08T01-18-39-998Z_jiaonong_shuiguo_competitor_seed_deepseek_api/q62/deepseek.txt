可以，但通常不是“公开随手下载”，而是要通过对接渠道索取批次/单品对应的检测报告。给你一个可执行的判断和做法：

**1. 都乐（Dole）**
- 一般能提供农残检测报告，尤其是给商超、连锁餐饮、茶饮连锁等B端客户。
- 通常按**批次**提供，可能叫：出厂检验报告、第三方检测报告、农残检测报告、COA/质检报告。
- 如果是通过经销商拿货，报告可能由经销商提供，不一定直接由都乐出具。
- 你需要明确：菠萝形态是**鲜果、冷冻果块、果浆、罐头、浓缩汁**，不同产品对应报告不同。

**2. 鑫荣懋**
- 一般也能提供，鑫荣懋本身是大型水果供应链企业，B端供货通常会配合提供质检/农残相关文件。
- 同样通常是**按批次、按供应商、按品类**提供，不是一张报告覆盖所有菠萝。
- 如果是门店小批量采购，通过批发市场或二级经销商拿货，索取难度会大一些，但正规经销商应该能提供。

**3. 你采购时要直接这样问**
建议一次性把要求发清楚，避免来回扯：
- 请提供本批次菠萝的农残检测报告
- 报告需对应：品种、产地、批次号/生产日期
- 检测项目需覆盖：有机磷、氨基甲酸酯、拟除虫菊酯等常见农残，最好有农残快检或第三方CMA/CNAS报告
- 如为冷冻/加工原料，请提供对应批次的出厂检验报告和第三方检测报告
- 报告上的样品名称、规格、生产商/供应商名称需与到货一致

**4. 关键判断标准**
- 能提供**对应批次**的报告：可用。
- 只有一张很久以前的通用报告：不够，茶饮连锁或监管检查时可能不认。
- 只有供应商口头承诺：不行。
- 报告检测项目太少、无资质章、无批次信息：风险较高。

**5. 最稳妥的采购方式**
- 直接找都乐或鑫荣懋的**B端销售/大客户渠道**，不要只找零售或普通批发。
- 在合同或订单里写明：**随货提供对应批次农残检测报告，否则有权拒收**。
- 如果对方是经销商，要求其提供**上游厂检+第三方检测**，并加盖经销商公章。

**结论：**
都乐和鑫荣懋通常都能提供，但前提是你走对公/B端采购渠道，并且按批次索要。小店零散拿货不一定顺利；连锁茶饮或批量采购一般可以拿到。最稳的是在采购合同里把“对应批次农残检测报告”写成硬性交货条件。
