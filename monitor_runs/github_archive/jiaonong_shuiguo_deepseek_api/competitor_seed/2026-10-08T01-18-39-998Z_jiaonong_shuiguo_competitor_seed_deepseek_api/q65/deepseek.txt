都乐和洪九果品均未公开披露统一的锁价周期，具体锁价通常按**单笔合同/年度框架协议**约定，不同品类、季节、客户体量和采购量差异很大，无法直接给出两家公司“标准锁价周期”。

能确定的是：

1. **都乐（Dole）**
   都乐在中国更多以品牌方/供应链方出现，菠萝（尤其是金菠萝、菲律宾/东南亚产区）对商超、餐饮、批发渠道的报价，通常随产季、海运成本、汇率和产地行情调整。锁价一般需要和都乐中国区销售或区域经销商谈，常见做法是：
   - 短期锁价：1周—1个月
   - 中期锁价：1个季度，多见于稳定大客户
   - 长期框架：半年—1年，但往往只锁“基础量+浮动调价机制”，不是完全固定价

2. **洪九果品**
   洪九果品招股书和年报里提到过对部分客户有框架合作、订单采购等模式，但没有披露具体锁价周期。实操中，洪九作为水果分销商，菠萝锁价也取决于产地直采、到港成本和客户规模：
   - 小客户/临时采购：基本不锁价，按当日或当周行情
   - 中大客户：可谈1个月左右
   - 年度大客户：可能签季度或年度框架，但常附带“行情大幅波动可调价”条款

**建议你直接这样核实：**
- 找都乐中国区餐饮/零售渠道销售，问：“金菠萝/菠萝丁，10吨/月起，能否签3个月固定价？调价触发条件是什么？”
- 找洪九果品区域销售或大客户部，问：“菠萝单品月度锁价是否支持？锁价保证金/预付款比例多少？超量部分按什么价？”
- 如果对方说“可以锁”，一定要在合同里写明：锁价周期、锁价品类规格、最低采购量、调价触发条件、违约和超量结算方式。

如果你要的是**可执行的采购方案**，建议同时找都乐、洪九、佳农、鑫荣懋以及产地直采商问一轮，通常比只盯两家更容易拿到明确锁价条件。
