我没法核验都乐（Dole）和洪九果品当前针对社区团购的“散装/小包装”供货政策，所以不能直接给你“有”或“没有”的确定答案。  
但可以给你一套可执行的判断和落地办法：

**1. 先明确你要的“散装”是哪种**
- **原箱散根**：整箱到货，团长/网格仓自己分装成 2–3 根或 4–5 根。
- **工厂预包小包装**：品牌方或供应商已经做成 500g、1kg、2–3 根装，带标签/条码。
- **无标签裸装**：仅用于自提或即时分拣，不进商超条码体系。

都乐和洪九果品通常更偏**原箱批发/渠道分销**，是否给社区团购做预包小包装，往往取决于区域经销商、采购量、仓配条件，而不是品牌全国统一政策。

**2. 直接问供应商这 6 个问题**
- 香蕉是**原箱**还是**预包小包装**？规格是多少？
- 小包装是**品牌方工厂做**，还是**区域经销商分装**？
- 起订量是多少？按件、按吨还是按车？
- 是否支持**一件代发**或**网格仓配送**？
- 小包装是否有**条码、标签、保质期标识**？
- 香蕉催熟状态是**青蕉、微熟、即食熟**哪种？到仓后还能放几天？

**3. 更现实的拿货路径**
- **都乐**：优先找你在当地的**都乐经销商/批发市场代理**，问有没有“社区团购小包装”或“电商专供装”。全国客服通常不直接处理小批量团购。
- **洪九果品**：优先问**区域销售/城市合伙人**，因为他们更可能给社区团购做定制分装。洪九强项在东南亚水果供应链，香蕉有操作空间，但小包装要看区域仓配能力。
- **如果两家都没有现成小包装**：找本地批发商做**代分装**，或者自己租用网格仓分装。社区团购里香蕉小包装，很多其实是团长侧或网格仓侧完成的。

**4. 建议你先做一个小测试**
- 先拿 **1–2 箱**都乐和洪九的香蕉，分别做：
  - 2 根装、3 根装、500g 装；
  - 记录分装后 24h、48h 的损耗、黑斑、断柄情况；
  - 算清楚“分装人工 + 损耗 + 包装材料”后的单份成本。
- 如果损耗超过 8%–10%，小包装可能不划算，除非你能把售价拉上去。

**5. 结论性建议**
- 不要默认都乐/洪九有全国统一的社区团购散装选项；
- 直接找你所在城市的**区域经销商**问“预包小包装/电商专供/团购装”；
- 如果没有，走**原箱 + 本地分装**更稳；
- 香蕉小包装的核心不是品牌，而是**催熟度、分装时效、损耗控制**。
