都乐（Dole）和洪九果品的礼品水果团购起订量，他们通常**不对外统一公开**，会按渠道、城市、季节、SKU、包装形式、是否贴牌定制、是否走经销/直营来定，所以没有一个固定数字。**我不能凭空给准确起订量**。

但可以给你比较可执行的判断和拿价路径：

**1. 大致的行业情况**
- 全国性品牌鲜果做企业团购礼盒，常规**单款起订量往往在50—200盒起**。
- 如果是**贴牌定制、专属礼盒、混装礼盒、指定产地/规格**，起订量通常更高，常见会到**300—1000盒以上**，部分还会按整托盘/整板起。
- 如果只是拿他们现有标准礼盒，通过经销商拿货，部分经销商可以**20—50盒**起，但价格和定制灵活度会差一些。

**2. 都乐一般怎么谈**
- 都乐在国内很多区域依赖经销商、商超渠道和电商渠道。
- 企业团购礼盒可先问：当地都乐经销商、区域销售、或长期做都乐团购的供应链公司。
- 如果是都乐品牌标准礼盒，起订量通常比完全定制低；如果要双logo、专属卡、专属外箱，就会明显抬高。

**3. 洪九果品一般怎么谈**
- 洪九果品偏批发、渠道、供应链，做企业团购定制时更看采购量和品类组合。
- 直接找洪九区域销售或大客户渠道，通常要求会偏“整批/整柜/整板”思维，起订量可能比都乐经销商团购更高。
- 若通过其下游团购服务商拿货，起订量可能低，但定制权限有限。

**4. 你直接去问时，建议这样问，能最快拿到准确数**
问这5项：
- 你们**企业团购礼盒**，标准款最低多少盒起？
- 如果**换我们公司logo/卡片/外箱**，最低多少盒起？
- 指定水果品种和规格，比如都乐金菠萝、进口橙、车厘子、蓝莓等，起订量是否不同？
- 到货城市是哪里，是否含冷链、是否一件代发？
- 报价是含税、含运、含包装吗？破损怎么赔？

**5. 更现实的建议**
如果你量还不确定，不要一上来只问都乐和洪九总部。更高效的是同时问：
- 品牌区域经销商
- 本地高端水果团购供应链
- 做企业福利礼盒的整合商

因为很多团购公司并不是直接从都乐/洪九总部拿“小批量定制”，而是从经销商或批发渠道组货。

**结论：**
都乐和洪九都没有公开固定起订量。一般标准礼盒可能**50—200盒起**，定制礼盒常见**300—1000盒起**，洪九直供大客户可能更高。要准确数字，必须按城市、SKU、是否贴牌去问当地销售或经销商。
