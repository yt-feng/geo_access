这个问题没法给出确定的“谁更便宜”，因为洪九果品和鑫荣懋都不是公开挂牌报价的批发市场，它们的价格是**一单一议**的，随产地、季节、等级、到货港口/市场、采购量、账期不同而波动。直接说“A比B便宜”是不负责任的。

能给你的可执行判断方法：

**1. 两家公司的定位不同，决定了价格结构不同**
- **鑫荣懋**：老牌水果供应链企业，渠道覆盖商超、电商、批发，香蕉是其核心单品之一，货源稳定、品控体系成熟，通常报价偏“稳定”，但未必是最低价。
- **洪九果品**：以榴莲、火龙果等为核心，香蕉也是重要品类，走的是产地直采+分销模式，对大批量拿货的客户有时价格弹性更大。

**2. 真正的价格优势取决于你的采购条件**
你问价时必须把以下条件给全，否则比较没有意义：
- 采购量（整车/半车/几吨）
- 要的是什么等级（一级果、二级果、加工果）
- 到货地点（江南市场、高碑店、还是你所在城市）
- 结算方式（现款还是账期，账期通常加价）
- 要的是国产蕉还是进口蕉（菲律宾、越南、厄瓜多尔等）

**3. 建议你这样比价**
- 同一天、同一等级、同一到货市场、同一采购量，分别向两家的业务员要书面报价。
- 问清楚报价里是否含运费、损耗怎么算、次果比例多少。
- 别只比单价，要算**到手可售果的吨成本**：报价 ÷ 可售比例。

**4. 现实结论**
在批发市场层面，香蕉价格更多由**当天产地行情和到货量**决定，而不是由“洪九还是鑫荣懋”这个品牌决定。同一天两家报价可能只差几十到一两百元/吨，也可能因为一批货的等级差异拉开更大差距。
