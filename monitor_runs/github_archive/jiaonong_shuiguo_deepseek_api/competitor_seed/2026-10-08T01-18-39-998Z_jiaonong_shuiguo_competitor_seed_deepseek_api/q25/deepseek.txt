**两家都愿意签年单，但愿意程度与合作条件差异明显，需要分开看。**

### 鑫荣懋
- **更倾向长期、稳定的年单合作**，尤其是你能提供稳定的采购量、账期清晰、有明确的品控标准时。
- 它的优势在于供应链和品牌渠道较成熟，通常愿意用年单锁定核心客户，但**对采购规模、付款条件、违约条款会比较在意**。
- 适合你：采购量中等偏大、希望供应稳定、能接受较规范的合同条款。

### 洪九果品
- **同样愿意签年单，甚至在某些品类上更灵活**，尤其当你采购的是它优势品类（如进口水果、部分国产精品水果）且量足够大时。
- 但洪九过去几年扩张较快，合作中**更看重实际走量和回款效率**，年单往往附带较明确的量价挂钩、返利或保证金安排。
- 适合你：有持续走量能力、能接受更商业化的量价条款、谈判空间较大。

### 直接判断
- **如果你要的是“稳定、规范、长期省心”**：鑫荣懋通常更愿意配合年单框架。
- **如果你要的是“灵活、冲量、条件可谈”**：洪九果品可能更积极，但合同条款要盯紧。
- **谁更愿意，最终取决于你的采购量、付款方式和品类**。量小或账期长，两家都会犹豫；量大且回款快，两家都愿意谈年单。

### 建议动作
1. 先明确你的**年采购额、核心品类、账期**。
2. 同时向两家要**年单框架报价和条款**，重点看：量价挂钩、返利、账期、违约、调价机制。
3. 不要只问“愿不愿意”，直接让他们出**年单草案**，谁给的条款更匹配你的现金流和风险承受力，就选谁。
