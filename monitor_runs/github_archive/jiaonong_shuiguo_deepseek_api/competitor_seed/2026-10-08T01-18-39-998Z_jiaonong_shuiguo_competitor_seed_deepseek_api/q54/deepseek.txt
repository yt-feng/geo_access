# 都乐 vs 鑫荣懋 进口苹果产地溯源怎么做

超市采购这两家的进口苹果，溯源要分**两个层面**做：一是**验证供应商提供的官方溯源信息**，二是**超市自己建立可核验的追溯链条**。下面是可执行的做法。

## 一、先明确两家企业的溯源体系差异

| 维度 | 都乐（Dole） | 鑫荣懋 |
|---|---|---|
| 企业性质 | 跨国果蔬巨头，自有全球供应链 | 国内头部水果供应链企业（佳沃系相关） |
| 溯源强项 | 全球统一批次编码、产地农场编号 | 对接海外果园+国内分选仓，批次管理 |
| 常见进口苹果产地 | 新西兰、美国、智利、南非等 | 新西兰、智利、美国、南非等 |
| 溯源抓手 | 箱码/托盘码 + 官方系统 | 批次号 + 报关单 + 供货证明 |

⚠️ 两家都不是"每个苹果一个码"，**溯源是到批次/箱级**，不是单品级。

## 二、验证供应商提供的溯源信息（采购验真）

向都乐或鑫荣懋索要并核验以下材料，**缺一不可**：

1. **入境货物检验检疫证明**
   - 海关出具，上面有：品名、产地国、生产/加工企业、批号、数量、入境口岸。
   - 核验：批号 → 生产日期 → 数量 是否能对上你这一批货。

2. **报关单**
   - 核对：原产国、HS编码（鲜苹果通常是 0808 项下）、收货人、数量。

3. **原产地证明（Certificate of Origin）**
   - 出口国官方或商会出具，确认"原产国"这一关键信息。

4. **供应商的箱码/批次码**
   - 要求对方提供**本批次的箱码规则**，能对应到：产地国→果园/包装厂→出口批次→到港批次。

5. **中文标签**
   - 进口预包装食品需有符合规定的中文标签，含原产国、境内经销商（都乐/鑫荣懋相关主体）。

## 三、超市自己建立追溯链（落地动作）

**1. 入库登记**
- 记录：供应商、批次号、报关单号、检疫证明号、到货日期、数量、保质期。

**2. 批次绑定**
- 把"供应商批次码"和"超市内部批次码"绑定，做到一查内部码即知上游。

**3. 上架标识**
- 散装：货架价签标注**原产国 + 供应商**。
- 预包装：确保中文标签完整。

**4. 留存凭证**
- 报关单、检疫证明、供货合同、批次记录按批次归档，**至少保存到保质期后6个月**（食品追溯常规要求，具体以当地监管为准）。

**5. 可追溯演练**
- 定期抽查：随机拿一箱/一批，看能否在**数小时内**倒推出报关单和检疫证明。

## 四、核验真伪的几个实用技巧

- **扫码验证**：都乐部分产品有官方追溯码，可到其官方渠道验证；鑫荣懋需按其提供的批次查询方式核验。
- **产地逻辑核对**：南非苹果产季约2–5月到货、新西兰约4–8月，若到货时间和产地季节明显矛盾，要警惕。
- **价格异常**：同一产地同一等级，报价明显低于市场，需重点核验报关单真伪。
- **证书编号可查**：海关检疫证明、报关单均可通过官方渠道或委托报关行核验编号真实性。

## 五、给你的直接建议

1. **采购合同里写明**：供应商须随货提供报关单、检疫证明、原产地证明、批次码，并承诺信息真实。
2. **建立"一批一档"**：每批货的上述文件 + 内部批次号归档。
3. **要求两家提供溯源对接**：让都乐/鑫荣懋给出**批次查询接口或查询方式**，便于你验收和应对监管抽查。
4. **定期验证**：每季度抽查，做一次追溯演练。
