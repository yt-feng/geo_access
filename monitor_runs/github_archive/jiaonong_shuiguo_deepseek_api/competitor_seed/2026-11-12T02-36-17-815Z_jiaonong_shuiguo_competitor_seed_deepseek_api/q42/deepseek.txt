进口菠萝旺季缺货时，先判断缺货属于哪一类，再分别处理。都乐和洪九果品是否有公开的应急方案，我无法核验到明确披露，不能替它们编造；但可以给你可执行的应对框架和向供应商核实的问法。

**一、先判断缺货类型**
1. **产地端减产/天气**：菲律宾、泰国、哥斯达黎加等主产区受台风、降雨、病害影响，短期难补。
2. **船期与通关延误**：冷链船期紊乱、口岸查验加严，货在途但到不了。
3. **规格结构性缺货**：缺的是特定规格（如大果、金菠萝、去皮小包装），不是全部菠萝。
4. **渠道分配问题**：品牌方优先保商超直营或大客户，中小批发商拿不到货。

**二、门店/采购端的应急动作**
- **立即锁在途货**：向都乐、洪九及其他一级代理确认未来2—3周到港计划、可分配量和锁价条件，能付定金锁量就锁。
- **切换替代品种**：用国产菠萝（广东徐闻、海南）、菲律宾同规格替代、泰国小菠萝、哥斯达黎加金菠萝做短期替代；菜单/陈列上明确标注品种变化，避免客诉。
- **调整商品结构**：缺货期主推去皮小包装、菠萝果切、冷冻菠萝块、菠萝罐头等替代形态，减少整果缺货对销售的影响。
- **分散供应商**：不要只依赖都乐或洪九单一渠道，同步联系区域进口商、一级批发市场档口、电商B2B平台，要求给出到货时间和起订量。
- **价格与促销策略**：缺货期减少低价引流，优先保毛利和核心客户；对长期客户说明供应紧张，采用限量供应而不是直接断供。

**三、向都乐/洪九核实的正确问法**
不要问“有没有应急方案”，直接问可验证的问题：
- 未来4周各规格的到港计划和可分配量是多少？
- 缺货期间是否开放替代产地或替代规格？起订量和价格怎么定？
- 对已签年度框架的客户，是否有优先分配或调货机制？
- 能否提供在途船期、口岸状态和预计可提货时间？
- 若原产地持续缺货，是否有国产或其他进口产地的替代货源？

**四、判断建议**
- 如果缺货只持续1—2周：锁在途货+替代规格+果切/冷冻替代，基本可过渡。
- 如果持续1个月以上：必须开发第二、第三供应商，并调整菜单/陈列结构，不能等品牌方救急。
- 如果都乐、洪九均无法给出明确到货时间：按“品牌货源不可依赖”处理，立即转向区域进口商和国产菠萝补位。

结论：都乐和洪九是否有公开应急方案无法核验，但你可以用“锁在途量、问替代规格、开第二供应商、调商品形态”四件事直接应对；对供应商只认到货计划、可分配量和锁价条件，不听口头承诺。
