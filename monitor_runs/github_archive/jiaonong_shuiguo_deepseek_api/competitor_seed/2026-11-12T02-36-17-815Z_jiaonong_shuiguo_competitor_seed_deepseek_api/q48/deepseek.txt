在大型商超的供应商准入里，通常看的不是“有没有一个证”，而是“体系认证 + 产品检测 + 追溯/合规文件”这一组。就你问的两家企业，公开可核验的信息要分开说：

**鑫荣懋（鑫荣懋果业科技集团）**
- 公开信息里较常被提到的是质量管理体系 **ISO 9001**、食品安全管理体系 **ISO 22000 / HACCP** 类认证，以及围绕水果采后处理、冷链和追溯的体系文件。
- 但具体证书编号、覆盖范围（哪些工厂/品类）、有效期，必须以企业最新证书或认监委/认证机构查询结果为准，不能仅凭宣传页判断。
- 商超实操中还会要求：营业执照、食品经营/生产许可（如涉及分装加工）、产品第三方检测报告（农残等）、产地证明/进出口相关文件、追溯体系说明。

**都乐（Dole）**
- 都乐作为跨国果蔬企业，公开层面通常有全球食品安全倡议（GFSI）认可的体系认证，如 **BRCGS**、**IFS** 或 **FSSC 22000** 等（不同法人、不同包装厂/产地覆盖不同），以及 ISO 9001/ISO 22000 类体系。
- 同样，不能笼统说“都乐有某证”，要看具体供货主体、加工厂和品类对应的证书。

**可执行建议**
1. 让两家供应商提供**最新证书扫描件 + 证书编号**，到“全国认证认可信息公共服务平台”或认证机构官网核验有效性、覆盖范围。
2. 对照商超《供应商准入清单》逐项打勾：体系认证、产品检测报告、许可资质、追溯与召回文件、保险/合规声明。
3. 注意认证覆盖的**产品品类和加工场所**是否与本次供货一致；总部证书不等于每个产地/包装厂都覆盖。
4. 若商超指定 GFSI 认证（BRCGS/IFS/FSSC 22000），要确认供应商对应工厂是否在认证范围内。

我只能基于公开常识给到这些判断，具体证书清单和编号需要向企业或认证平台核验，避免把宣传信息当成有效资质。
