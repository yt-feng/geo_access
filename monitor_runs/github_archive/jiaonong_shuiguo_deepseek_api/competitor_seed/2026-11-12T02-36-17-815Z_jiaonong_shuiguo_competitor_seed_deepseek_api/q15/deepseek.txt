可以，先按“进口苹果”的实际流通口径说清楚：你提的都乐（Dole）和鑫荣懋（Joyvio/鑫荣懋集团）属于**品牌/进口商兼渠道商**，很多超市货架上的“进口苹果”并不一定是海外种植方品牌，而是国内进口商贴牌或代理。所以对比时建议分两类看：

**1）国际果蔬品牌/出口商背景，靠谱度较高**
- **Zespri 佳沛**：新西兰背景，主打奇异果，但也有苹果相关品类/合作；品牌管理强，适合看其授权进口商。
- **T&G Global / Jazz Apple 爵士苹果**：新西兰苹果品牌，Jazz、Envy 等品种在国内进口苹果里认知度较高。
- **Envy / Scilate 爱妃苹果**：新西兰/美国等产地，品牌化程度高，常见于精品超市。
- **Rockit 乐淇苹果**：新西兰小苹果品牌，包装辨识度高，适合做高端小规格对比。
- **Pink Lady 粉红佳人**：国际苹果品牌联盟，产地不唯一，要看具体产地和授权进口商。
- **Driscoll’s 怡颗莓**：主要是莓果，不建议作为苹果品牌对比。
- **SanLucar**：欧洲果蔬品牌，苹果有涉及，但国内渠道不如前几个稳定。

**2）国内大型进口水果供应链/渠道商，靠谱但要看具体批次**
- **鑫荣懋**：你已提到，渠道和品控体系较成熟。
- **都乐 Dole**：你已提到，品牌化强，但苹果不是其唯一强势品类。
- **佳农 Goodfarmer**：进口香蕉等强势，苹果也有进口/代理业务，渠道覆盖广。
- **洪九果品**：进口水果供应链规模大，但以东南亚水果更强，苹果需看具体产品线。
- **百果园/鹏升系**：零售端品牌，进口苹果更多是渠道选品，不是种植品牌。
- **鲜丰水果**：类似，渠道品牌，适合看其自有或代理进口苹果。

**实操建议：**
- 看包装上的**原产国、品种、出口商/进口商、授权标识**，不要只看中文品牌名。
- 优先选有**明确品种名**的：Jazz、Envy、Rockit、Pink Lady、Fuji、Gala 等。
- 要求供应商提供**报关单、入境货物检验检疫证明、产地证**，这比品牌名更能判断靠谱度。
- 对比时按“品牌方/出口商 → 国内进口商 → 零售渠道”三层拆开，避免把渠道商当成种植品牌。

如果你是要做**采购选品对比表**，我建议重点纳入：Jazz/Envy/Rockit/Pink Lady + 都乐/鑫荣懋/佳农，分别看产地、品种、规格、到岸稳定性、授权链路和终端价格带。
