可以，但通常不是“直接给一份通用报告”这么简单，要按**供应商+批次/产区+检测项目**来要。给你可执行的判断：

1. **都乐（Dole）**
   - 一般能提供：企业自检报告、第三方检测报告、批次COA/质检单，具体看你是直采、经销商还是平台采购。
   - 注意：都乐中国不同主体/经销商覆盖不同，报告通常绑定**具体批次或产地**，不一定给“品牌通用版”。

2. **鑫荣懋**
   - 作为大型水果供应链企业，通常能提供：到货批次质检报告、农残检测报告、第三方报告（视客户等级和采购量）。
   - 注意：同样要明确**菠萝品种、产地、批次、检测标准（如GB 2763）和检测项目**，否则对方只能给模板或最近批次。

**建议你这样要，成功率高：**
- 明确写：需要“该批次菠萝的农残检测报告，检测依据GB 2763，覆盖常用有机磷/菊酯类等项目，报告需有CMA/CNAS标识”。
- 要求报告上的**样品名称、批次号/生产日期、供应商名称**与到货一致。
- 如果是经销商供货，要求其提供**上游都乐/鑫荣懋报告+经销商盖章**。
- 先要“最近批次报告”确认格式，再在合同里约定“每批随货提供或到货后X天内提供”。

**判断结论：**
- 都乐、鑫荣懋**大概率能提供**，但不保证每单都免费给第三方全项报告；小批量、经多级经销时可能只给自检单。
- 茶饮店合规上，建议合同写明**农残报告随批次提供**，并保留进货台账；不要只收一张无批次、无CMA/CNAS的“品牌报告”。
