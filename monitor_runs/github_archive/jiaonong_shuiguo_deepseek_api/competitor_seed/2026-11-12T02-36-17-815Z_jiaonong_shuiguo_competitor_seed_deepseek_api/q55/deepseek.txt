可以，但先区分两件事：**“基地直供”**和**“能做产地溯源”**不是一回事。你要找的是能提供**可核验溯源**的供应商，而不一定非要供应商自己拥有基地。

**都乐：**
- 有全球化种植和采购体系，在中国市场也有合作产区与供应商体系，部分品类会强调产地/农场信息。
- 但“是否基地直供”要看你对接的是都乐中国哪条业务线、哪个菠萝品种和包装规格。都乐更多是品牌化供应链企业，不一定对每个客户都开放“基地直供”口径。
- 可要求其提供：产地证明、批次追溯号、果园/包装厂注册信息、检测报告。能给出这些，比口头“基地直供”更有判断价值。

**洪九果品：**
- 是国内较大的水果供应链企业，在东南亚和中国部分产区有采购与合作基地体系，菠萝是其重要品类之一。
- 它更接近“产地采购+分选加工+冷链分销”的模式，部分品类可做到产地直采或基地合作直采，但具体到菠萝、具体产区、具体季节，需要按批次确认。
- 可重点问：是自有基地、合作基地还是产地经纪人采购；能否提供果园备案、采摘批次、加工厂记录和物流温控记录。

**给你一个可执行的筛选标准：**
1. 要求供应商提供**同一批次的产地证明+包装厂信息+检测报告**。
2. 问清是**自有基地、合作基地、产地直采还是市场调货**，写入合同或报价单。
3. 要求提供**追溯码或批次号**，并能从成品包装追到果园/包装厂。
4. 先小批量试单，核对包装标签、批次记录和实际到货是否一致。
5. 如果对方只说“基地直供”但拿不出批次文件，不建议作为溯源供应商。

**结论：** 都乐和洪九果品都具备较强的产地采购和供应链追溯能力，但是否对你这单做“基地直供”，要按具体品种、产区、季节和合同主体确认。建议把“基地直供”改写成可验收条款：**产地可证明、批次可追溯、文件可核验**。
