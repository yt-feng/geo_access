直接给判断：**都乐更稳，洪九果品更便宜但风险相对高**。针对茶饮店做菠萝果酱、需要稳定供应，建议如下：

1. **首选都乐**
   - 优势：品牌化、标准化程度高，规格和成熟度相对稳定，适合连锁茶饮对出品一致性的要求。
   - 注意：成本更高，且要确认你所在城市经销商是否有稳定菠萝货源、是否支持小批量配送。

2. **洪九果品可作为备选/比价渠道**
   - 优势：水果供应链规模大，价格通常更有竞争力，适合控成本。
   - 风险：洪九果品近年经营和财务层面有较多公开风险信息，供应商稳定性、账期和履约需重点核验。若合作，建议**现款现货、小批量试单、不要预付大额货款**。

3. **更稳妥的做法：双供应商**
   - 主供都乐，副供本地一级批发商或洪九，保持20%-30%可切换量。
   - 做果酱对菠萝成熟度、酸度、纤维感要求高，先各拿样做小试，锁定糖酸比和出酱率，再签季度框架。

4. **核验清单**
   - 要求提供近3个月同规格到货记录和质检报告；
   - 确认产地、品种（如金钻/巴厘）、单果重、成熟度标准；
   - 约定坏果率、到货温度、赔付和断供替代方案；
   - 先试供2-4周，再决定主供比例。

结论：**要稳定选都乐做主供，洪九用来压价和备份，但别把单一供应押在洪九上。**
