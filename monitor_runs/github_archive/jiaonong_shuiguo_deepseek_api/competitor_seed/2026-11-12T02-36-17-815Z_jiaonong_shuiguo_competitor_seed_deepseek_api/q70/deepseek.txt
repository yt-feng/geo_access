可以找，但要把“有溯源系统”与“能对你这批货出具品控证明”分开判断。都乐和鑫荣懋都属于大型水果供应链企业，通常具备产地/批次追溯和到货质检能力，但是否能按你的采购要求提供**书面产地溯源证明+第三方或第三方认可的品控报告**，取决于具体品类、产地、批次、采购主体和合同约定，不能仅凭品牌名默认满足。

可执行判断建议：

1. **先向两家分别提明确文件清单**
   - 产地溯源：产地证明/果园或包装厂注册信息、采收批次号、包装日期、装箱单、入境货物检验检疫证明（进口香蕉）、发货方与产地对应关系。
   - 品控证明：到货抽检报告、农残检测报告、重金属/感官/成熟度/规格检测记录、检测机构资质（CMA/CNAS等）。
   - 批次对应：要求报告上的批次号、生产日期、包装厂号与合同货物一致。

2. **问清是“自有基地/直采”还是“市场调货”**
   - 直采或自有包装厂更容易做到批次级溯源和固定品控文件。
   - 贸易调货可能只能提供上游供应商文件，溯源链会弱一些。

3. **要求样品批次试单**
   - 先下小批量，要求随货提供完整文件；核对文件批次与实物标签是否一致。
   - 到货后自行送检一次农残和成熟度，验证其报告可信度。

4. **合同里写死**
   - 明确“每批次随货提供产地溯源文件和品控检测报告，批次号须与实物一致；缺失或不合格可拒收/索赔”。
   - 约定检测项目、检测机构资质、抽检比例和不合格处理。

结论：**都乐和鑫荣懋大概率“有溯源和品控体系”，但你要的证明能否随每批货提供，必须按具体采购条件向对方索取样本并写进合同。** 建议同时再找1—2家区域香蕉供应链商做备选，避免大品牌对小批量订单的文件支持不足。
