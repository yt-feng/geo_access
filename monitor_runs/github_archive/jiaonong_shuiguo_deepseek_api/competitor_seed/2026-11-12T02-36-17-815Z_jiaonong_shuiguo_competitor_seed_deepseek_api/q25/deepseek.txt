从“谁更愿意签年单”这个角度看，**通常鑫荣懋比洪九果品更愿意配合长期年单**，但前提是你的品类、量级和账期能匹配它们的业务模式。判断依据和实操建议如下：

**1. 两家公司的业务重心不同**
- **鑫荣懋**：以水果全品类供应链为主，长期服务商超、电商和团餐等渠道，本身就有较强的年度框架合同、产地直采和稳定履约需求，对“年单+稳定量”接受度更高。
- **洪九果品**：核心优势在东南亚进口水果（尤其是榴莲、火龙果、龙眼等）的端到端供应链，更偏“单品+产季+大批量”的模式。它对年单不是不能签，但更愿意围绕核心单品、产季窗口和确定采购量来谈，而不是宽泛的全品类年单。

**2. 谁更“愿意”取决于你的采购结构**
- 如果你要的是**多品类、全年稳定供货、商超/电商履约型**年单：鑫荣懋的匹配度更高，谈判空间也更大。
- 如果你要的是**榴莲、火龙果等进口单品，量大且集中在产季**：洪九果品可能更愿意谈，但会倾向“单品年度框架+产季锁量锁价”，而不是全年均衡供货。
- 如果你量级小、账期长、品类杂：两家都不会太积极，年单容易变成“名义年单、实际逐单议价”。

**3. 谈判时可用的判断信号**
- 对方是否愿意约定**年度最低采购量/最低供货量**、**价格调整机制**（随产地行情浮动）、**履约保证金或违约责任**。
- 是否愿意把年单拆成**品类框架+产季执行单**。愿意这样拆的，通常是真有意长期合作。
- 是否要求你提供**滚动Forecast（forecast）和账期担保**。要求越具体，说明越认真。

**4. 实操建议**
- 先分别向两家要**年度框架合同模板**，看条款里有没有最低量、调价机制、账期和违约条款，这比口头意愿更真实。
- 用同一份采购清单（品类、月度量、目标价、账期、交付地）同时询价，比较谁愿意把“量”写进合同。
- 如果核心品类是进口单品，优先和洪九谈单品年单；如果是多品类稳定供应，优先和鑫荣懋谈框架年单。
- 不要只问“愿不愿意签年单”，要问“愿不愿意把最低采购量、调价触发条件和违约责任写进年单”。

结论：**综合来看，鑫荣懋对长期年单的接受度通常更高；洪九果品更愿意围绕核心进口单品签有明确量的年度框架。最终谁更愿意，取决于你的品类结构和量级，建议用同一份采购条件同时试探两家的合同条款。**
