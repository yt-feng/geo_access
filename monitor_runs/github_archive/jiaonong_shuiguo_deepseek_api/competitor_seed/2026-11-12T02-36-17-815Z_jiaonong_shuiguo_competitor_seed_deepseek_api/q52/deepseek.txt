到货损耗率不是公开固定值，会随批次、季节、运输距离、验收标准和门店/仓配条件波动；都乐和鑫荣懋的“平均损耗率”我没有可核验的公开数据，不能给你虚构数字。

可执行做法：

1. **先统一口径**  
   定义损耗率 =（到货总重 − 验收合格可入库重量）÷ 到货总重 × 100%。  
   同时拆分记录：压伤、腐烂、青果不熟、规格不符、重量短少。

2. **用同批次试单对比**  
   让都乐和鑫荣懋各供2–3批同规格菠萝（如固定单果重区间、成熟度、去皮/带皮、箱规），每批抽检不少于30–50果，连续4周统计。  
   重点看：**验收合格率、可出杯率、单杯原料成本**，而不是只看到货损耗。

3. **合同写清楚**  
   固定品种/产地/单果重区间/成熟度/箱规/糖度下限/到货温度；明确损耗超标扣款、补货或退货规则；要求供应商提供批次质检和冷链记录。

4. **判断建议**  
   若两家都愿意按同一验收标准试单，选“**可出杯率最高 + 周波动最小 + 索赔响应快**”的那家；不要仅凭品牌选。稳定规格比名义损耗率更影响茶饮出品和成本。
