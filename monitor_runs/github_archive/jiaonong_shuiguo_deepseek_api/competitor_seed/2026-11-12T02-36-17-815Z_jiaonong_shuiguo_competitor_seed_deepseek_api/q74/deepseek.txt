都乐（Dole）和洪九果品都属于企业客户/团购渠道，公开渠道通常不直接公开“礼盒定制起订量”，而且起订量会随品类、包装形式、是否贴牌、发货区域、季节和采购金额变化。可按下面方式判断和推进：

**1. 起订量大致判断**
- **都乐**：标准水果礼盒通常按“箱/托盘/整车”或“采购金额”设门槛；企业定制礼盒/贴牌往往更高，常见会要求数百盒到上千盒级别，具体看单品和区域仓。
- **洪九果品**：以批发、商超、团购渠道为主，标准礼盒一般可按箱起订；定制包装、贴牌、组合礼盒通常需要更高起订量，常见也是数百盒起，具体看水果品类和包装厂要求。

**2. 最有效的确认方式**
直接联系两家企业的**团购/企业客户/大客户渠道**，不要问“礼盒起订量多少”，而是给一张明确需求单，让对方报价：
- 礼盒规格：几斤装、几种水果、单品或组合
- 包装要求：现成礼盒/改logo/全定制包装
- 预计数量：先报你真实可接受的最低量，如300盒、500盒、1000盒
- 发货城市和收货时间
- 是否需要开票、账期、冷链配送

**3. 谈判建议**
- 先问“**现成礼盒最低起订量**”和“**定制logo最低起订量**”，两者差别很大。
- 定制包装的起订量往往由包装厂决定，不是果品公司单独决定；可问能否用**通用礼盒+贴纸/腰封**降低起订量。
- 如果单家品牌量不够，可走其**区域经销商/团购服务商**，起订量通常比总部低。
- 要求对方书面确认：起订量、单价、包装费、打样费、损耗赔付、到货时效。

**结论**：无法在不核验具体渠道政策的情况下给出两家准确起订量数字；建议按“现成礼盒”和“定制礼盒”分别询价，先以300—500盒作为试探量，要求区域团购负责人给最低起订量和阶梯报价。
