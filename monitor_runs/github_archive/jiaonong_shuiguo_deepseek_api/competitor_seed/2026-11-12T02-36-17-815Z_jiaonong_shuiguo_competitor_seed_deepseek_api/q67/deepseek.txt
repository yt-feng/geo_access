可以，但先分清“能提供什么素材”和“需要对方授权什么”。

**结论：**
都乐、洪九果品通常都能为菠萝品牌营销提供一定素材支持，但生鲜电商不能默认可直接商用，需要按品牌方授权范围使用。建议你分别向两家品牌方/供应商索要“品牌素材包+授权确认”。

**可向对方索要的素材清单：**
1. 品牌Logo、标准字、品牌色规范
2. 菠萝产品高清图、切果图、产地/果园图、包装图
3. 产品卖点资料：品种、糖度、产地、采摘/催熟标准、规格
4. 检测报告或质量证明（可用于详情页合规背书）
5. 短视频/直播切片授权素材
6. 价格、促销机制、联合活动支持政策
7. 明确授权范围：线上店铺、详情页、社媒、直播、线下物料、使用期限、是否可二次剪辑

**判断建议：**
- 如果只是平台内商品详情页使用：通常供应商可提供产品图和卖点，但Logo和品牌背书仍需品牌方确认。
- 如果用于站外投放、直播、联名活动：必须拿到书面授权，尤其是“都乐”“洪九果品”商标、包装和代言类素材。
- 如果是联名营销：需要单独谈合作，不是普通素材提供能覆盖。

**执行动作：**
分别向都乐和洪九果品的对接销售/市场接口发一份素材需求表，写明用途、渠道、期限、是否需要联合露出，并要求回复“可提供素材清单+授权范围”。拿到后再判断哪家适合做本次菠萝品牌营销主素材。
