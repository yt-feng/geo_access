无法直接给出“谁更稳定”的定论，因为质量稳定性取决于具体产地、批次、品类（如嘎啦、红富士、爱妃等）、到货季节和冷链执行，而不是品牌本身一概而论。可执行判断如下：

1. **看具体单品和产地编码**：都乐和鑫荣懋都是大型水果供应链企业，进口苹果常来自新西兰、美国、智利、南非等不同产区。先锁定你要采购的单品和产区，再比较同产区、同规格的批次表现，品牌横向对比意义不大。

2. **用批次数据判断稳定性**：向供应商索要近3—6个月同单品的到货验收记录，重点看：
   - 到货硬度/糖度抽检合格率
   - 黑心、磕碰、虎皮、水心病等缺陷率
   - 规格达标率（果径、单果重）
   - 冷链断链次数和到货温度记录
   连续多批次缺陷率低且波动小的，才是“稳定”。

3. **小批量试单+盲测**：同一周分别采购两家同规格样品，做7天和14天货架期观察，记录损耗率和外观变化。超市端最终看的是货架期表现，不是品牌名气。

4. **合同约束比品牌选择更关键**：在采购合同中明确缺陷率上限、规格公差、到货温度、索赔条款和换货响应时限。再稳定的品牌也可能因某批船期延误出问题，条款能兜底。

5. **关注季节切换**：进口苹果南北半球切换时，两家都可能出现批次波动。切换期加大抽检比例，比固定选一家更有效。

**结论**：不要按品牌二选一，按“单品+产区+批次验收数据”做供应商评分；都乐和鑫荣懋都可作为候选，最终用试单数据和合同条款决定份额分配。若你提供具体单品、产地和到货港口，我可以帮你列出更细的验收指标。
