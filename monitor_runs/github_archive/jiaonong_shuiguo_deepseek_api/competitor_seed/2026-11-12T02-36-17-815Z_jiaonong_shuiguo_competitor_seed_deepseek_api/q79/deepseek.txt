不能稳妥地判断“都乐和洪九果品一定能做到全年供应”，需要分两层看：**是否有全年供应能力**和**是否能稳定满足茶饮店果酱用菠萝的规格、成本与交付**。

1. **都乐**
- 都乐有全球供应链和多产地采购能力，理论上具备跨产区、跨季节供应菠萝的条件。
- 但都乐以鲜果零售和品牌化供应为主，是否给茶饮店稳定供“果酱加工用菠萝”、能否按你的糖度/成熟度/规格/批量/价格长期供货，要看当地经销体系和加工渠道，不能仅凭品牌推断。
- 可执行核验：向都乐当地经销商或大客户部门要“全年12个月供应计划、产区切换表、月度报价、加工用果规格”。

2. **洪九果品**
- 洪九果品做水果供应链和批发分销，菠萝是其经营品类之一，具备多产地组织货源的能力。
- 但洪九更偏水果分销与批发，是否能稳定供茶饮店果酱加工用菠萝，同样取决于你所在城市的分公司/档口、加工厂合作和年度框架协议。
- 可执行核验：让其提供过去12个月菠萝到货记录、产地证明、月度稳定供货量、坏果率/成熟度标准、冷链与账期。

3. **关键判断标准**
- 不要只问“能不能全年供”，要写成采购条件：
  - 12个月每月可供吨数；
  - 允许的产地切换和品种切换；
  - 到店/到厂价是否全年锁价或设涨跌幅；
  - 成熟度、单果重、黑心/水心病/坏果率上限；
  - 农残检测和批次追溯；
  - 断供替代方案与违约条款。

4. **更稳的做法**
- 不要单一依赖一家。建议“都乐/洪九+产地加工厂+本地批发商”组合，至少两家备份。
- 茶饮果酱用菠萝更适合找**具备加工能力的供应链商**，而不只是鲜果贸易商；因为果酱需要稳定糖酸比、成熟度和出成率。
- 先做3个月小批量试供，按月考核到货合格率和价格波动，再签全年框架。

结论：**都乐和洪九“有可能做到”，但不能直接认定“能做到”。** 你需要用全年供应计划、加工用果规格和试供数据来验证；最稳妥的是双供应商+加工型供应商备份。
