直接说结论：**没有可公开核验的、针对“洪九果品 vs 都乐香蕉”到货损耗率的官方对比数据**。任何给你一个精确百分比（比如“洪九3%、都乐2%”）的说法，基本都不可信，因为损耗率高度依赖批次、季节、运输距离、冷链、到货成熟度和验收标准，不是品牌固定值。

可以判断的几点：

1. **都乐（Dole）** 是国际品牌，优势在标准化分级、采后处理、冷链和成熟度控制，通常到货一致性更好；但批发市场拿到的都乐货，可能是进口商/经销商多级分拨后的货，冷链断链后损耗照样高。

2. **洪九果品** 是国内大型水果分销商，香蕉是其重要品类，优势在国内仓配和渠道覆盖；但不同市场、不同批次、不同成熟度到货差异大，不能简单认为损耗一定高于或低于都乐。

3. **你真正该比的是“这一批货”而不是“品牌”**。到货损耗率建议按以下口径自己测：
   - 到货总件数/总重量
   - 验收时不可销售果（压伤、黑斑、断裂、过熟、霉变）重量
   - 损耗率 = 不可销售重量 ÷ 到货总重量 × 100%
   - 同时记录：到货成熟度（几号色/青黄比例）、运输时长、车厢温度、是否催熟后发货

4. **批发市场实操建议**：
   - 同一市场、同一周、同规格各拿1-2件做对比测试，别只听供应商说。
   - 重点看：箱内上下层差异、蕉指饱满度、青硬度、切口、是否有水烂/黑腐。
   - 把“到货损耗”和“货架期损耗”分开算，香蕉真正亏钱常在到货后2-4天。
   - 要求供应商提供批次、产地、催熟日期、冷链记录；没有这些，品牌对比意义不大。
