除了都乐（Dole）和佳沛（Zespri），礼品团购可重点看这些进口/国际品牌水果礼盒，按品类给你分一下：

**综合水果/香蕉菠萝类**
- **金吉达 Chiquita**：香蕉强势，适合做企业福利基础款，礼盒常与苹果、橙子搭配。
- **德尔蒙 Del Monte**：菠萝、香蕉、部分浆果有优势，适合做混合果礼盒。
- **新奇士 Sunkist**：橙类、柠檬类认知度高，礼盒体面，适合节日团购。
- **爱妃 Envy / 爵士 Jazz**：苹果类高端品牌，礼盒装适合中高端预算。

**提子/葡萄类**
- **Sun World**：旗下有秋脆等提子品牌，进口提子礼盒常见。
- **Driscoll's 怡颗莓**：严格说是浆果品牌，蓝莓、树莓、黑莓礼盒很适合高端团购。

**车厘子/樱桃类**
- **Stemilt**：美国车厘子、苹果品牌，礼盒装常见。
- **Chelan Fresh**：车厘子、苹果类。
- **Fruitist**：车厘子、蓝莓等进口果礼盒常见。

**奇异果之外的特色品类**
- **Rockit 乐淇**：小苹果礼盒，便携、造型适合礼品场景。
- **Pink Lady 粉红佳人**：苹果礼盒，品牌辨识度高。
- **OZblu**：蓝莓品牌，适合高端小规格礼盒。

**选品建议**
- 预算80–150元/盒：金吉达/德尔蒙混合果、新奇士橙、Rockit小苹果。
- 预算150–300元/盒：怡颗莓蓝莓、Sun World提子、粉红佳人苹果、Stemilt车厘子。
- 高端300元以上：车厘子大规格礼盒、怡颗莓混合浆果、进口提子+蓝莓组合。

**注意**
- 礼品团购要确认：是否有正规进口报关/检疫证明、礼盒是否支持企业LOGO定制、起订量和配送时效、坏果赔付规则。
- 水果季节性强，车厘子、提子、蓝莓价格波动大，建议按交货月份锁品，不要只按品牌锁价。
