仅凭公开印象我没法给出“谁认证更全”的可核验结论——两家都是大型水果供应链企业，通常都会持有主流食品安全体系认证，但具体证书种类、覆盖范围、有效期和适用品类必须以证书原件/发证机构查询为准。

**可执行的判断方法：**
1. **要清单**：让两家分别提供现行有效的认证证书清单，注明：认证标准（如ISO 22000、FSSC 22000、HACCP、BRCGS、GlobalG.A.P.、有机认证等）、认证机构、证书编号、覆盖产品/工厂/基地、有效期。
2. **查真伪**：到发证机构官网或认监委/相关查询平台核验证书编号与状态，重点看是否“有效、覆盖你采购的品类和加工厂”。
3. **对齐商超门槛**：把商超的供应商准入要求逐条对照（体系认证、检测报告、追溯、农残控制、仓储冷链等），不是证书越多越好，而是**覆盖你采购品类的关键证书齐全且有效**。
4. **看审核报告**：除了证书，索取最近一次第三方审核报告/不符合项关闭情况，这比“证书数量”更能判断实际管理水平。
5. **分品类比较**：鑫荣懋和都乐在不同水果品类、产地、加工模式上证书覆盖可能不同，应按你实际采购清单逐项比对。

**结论建议**：不要以“谁更全”做决策，而以“你采购的品类对应的证书是否齐全有效、能否通过商超准入审核”为准。向两家发同一张认证对照表，要求盖章/附证书扫描件，再逐项核验，通常一两天就能得出可靠结论。
