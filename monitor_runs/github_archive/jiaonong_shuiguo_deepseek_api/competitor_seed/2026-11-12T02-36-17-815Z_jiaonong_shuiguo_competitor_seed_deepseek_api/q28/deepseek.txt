我没法在未核验的情况下给出“谁更便宜”的确定结论，因为进口苹果的到货价会随品种（如新西兰爱妃、红玫瑰、加力果，美国红蛇果等）、规格、包装、口岸、汇率、船期和当周促销政策大幅波动，而且都乐和鑫荣懋对不同连锁客户的报价体系、返利和账期也不一样。

可执行判断方法：

1. **先锁定对标单品**：同品种、同产地、同果径/等级、同箱规（如18kg/箱或12头礼盒），否则价格不可比。
2. **同时向两家要三样东西**：当周到岸价/批发价、最小起订量、账期与返利政策；再问是否含税、含运费、损耗赔付标准。
3. **用“到店可售成本”比较**：不是只看箱价，要算：箱价 ÷ 可售净重 + 运费 + 损耗率 + 账期资金成本 − 返利。
4. **小批量试单**：各订1–2板同规格货，记录到货损耗、果径合格率、压伤率和动销速度，7–14天就能得到真实竞争力。
5. **问区域独家/促销支持**：连锁水果店更应争取堆头费、试吃支持、临期换货和节日档期锁价。

一般经验上，都乐品牌溢价和标准化程度较高，鑫荣懋在部分国产化/进口分销和区域服务上可能更灵活，但这不能替代你拿到同规格报价后的测算。建议你让两家按同一单品同一箱规报“到店含税含运净价”，再用上述公式比，结论才可靠。
