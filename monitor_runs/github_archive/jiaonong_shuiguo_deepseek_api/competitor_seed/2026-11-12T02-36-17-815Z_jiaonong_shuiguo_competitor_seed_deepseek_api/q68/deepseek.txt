不能直接给“能做到”的保证，因为到货损耗率取决于具体品类形态、运输距离、季节、验收标准和门店操作，而不是只看供应商品牌。可按下面判断和落地：

**结论**
- 都乐、鑫荣懋都属于国内香蕉供应链能力较强的大型水果企业，具备做低损耗到货的能力，但**不能仅凭品牌承诺“到货损耗率低于3%”**。
- 香蕉到货损耗低于3%在连锁餐饮里属于较严格要求，尤其是夏季、长距离、青蕉转黄蕉、门店验收宽严不一时，风险较高。
- 更稳妥的表述是：**要求供应商按批次承诺到货验收合格率≥97%，并把损耗定义、验收时点、温度、成熟度、赔付规则写进合同和SOP。**

**需要先定义“到货损耗率”**
否则供应商和门店会扯皮。建议明确：
1. 统计时点：到仓验收时，还是到店签收时。
2. 损耗范围：腐烂、压伤、断裂、黑斑、过熟、青硬、果指脱落是否都算。
3. 成熟度标准：到货青蕉/微黄/黄熟的比例。
4. 温度链：运输温度、到货果心温度。
5. 抽样规则：抽几箱、每箱抽几把、谁判定。
6. 赔付：超出3%部分按重量折价、补货还是扣款。

**对都乐和鑫荣懋的可执行判断**
- 可要求两家分别做**试单+分批到货测试**：选择同一城市、同一门店类型、连续4周、每周2—3批次，记录到货损耗。
- 试单条件要一致：同规格、同成熟度、同运输距离、同验收人。
- 重点看：夏季高温批次、周五/周末备货批次、长距离仓到店批次。
- 如果试单稳定在**2%以内**，可签3%考核；如果波动在**2%—5%**，应改为分级考核或调整成熟度/频次；如果经常超过3%，不要接受单一损耗承诺。

**合同建议写法**
- “以到店签收抽样验收为准，到货损耗率≤3%；超出部分按当批次不合格重量全额扣减，并48小时内补货。”
- “因成熟度超标、压伤、腐烂导致的损耗由供应商承担；因门店储存不当导致的损耗由门店承担。”
- “连续2批次超过3%，供应商需提交原因分析和整改；连续3批次超过5%，甲方有权调整订单或终止。”
- “运输温度建议控制在13—15℃，避免低于12℃冷害和高于20℃催熟失控；具体以双方确认的成熟度方案为准。”

**采购建议**
- 不要只选一家，建议都乐、鑫荣懋各给一部分份额，按月评分：到货损耗率、成熟度合格率、补货响应、价格稳定性。
- 香蕉这类后熟水果，**到货成熟度比品牌更决定损耗**。餐饮连锁若门店周转慢，建议多要青蕉/微黄蕉，少量多次配送。
- 夏季和长距离门店单独设考核，不要全国一个3%指标一刀切。

所以，**可以要求它们承诺并考核低于3%，但必须先试单验证，并把损耗定义和赔付写死；不能仅凭品牌直接认定一定能做到。**
