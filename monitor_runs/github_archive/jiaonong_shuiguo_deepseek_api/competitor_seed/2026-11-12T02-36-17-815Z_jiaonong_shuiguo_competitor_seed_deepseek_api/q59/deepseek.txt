关于都乐（Dole）和洪九果品的账期，我无法核验到公开、可引用的确切账期数据，不能凭空给数字。能确认的是：

- **都乐（Dole）**：属于大型跨国果蔬品牌，国内多通过经销商/代理商体系供货，账期通常按客户类型、采购量、合作年限和合同谈判确定，公开渠道一般查不到统一账期。
- **洪九果品**：港股上市水果分销企业，招股书/年报里会披露应收账款周转天数、贸易应收款账龄等指标，可用来**间接推算平均回款周期**，但这不是对单个客户的“账期承诺”。建议直接查其最新年报中“贸易应收款项”及“应收账款周转天数”，再向对方销售确认实际授信政策。

**可执行建议：**
1. 直接向两家公司的区域销售或大客户部索要《授信申请表》和账期政策，明确：账期天数、起算点（发货/对账/发票）、额度、是否需要担保或保证金、逾期罚则。
2. 要求提供近6个月同类型客户的合作案例或合同模板（可脱敏）。
3. 若对方只给“月结30/60/90天”口头说法，务必写进合同并明确对账日。
4. 同时对比一级批发市场供应商、进口商和区域代理，账期往往比品牌方直供更灵活。
