除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些，按品类分：

**综合型国际果蔬品牌**
- **新奇士（Sunkist）**：美国柑橘类老牌，橙子、柠檬礼盒认知度高，适合商务送礼。
- **怡颗莓（Driscoll's）**：美国浆果品牌，蓝莓、树莓、黑莓，礼盒偏高端，适合女性/年轻客群。
- **卓莓（Driscoll's 中文另一译法，常与怡颗莓混用，需确认具体供应商）**：实际采购时认准“Driscoll's”英文标识。
- **SanLucar**：西班牙果蔬品牌，柑橘、葡萄等，欧洲礼盒质感不错。
- **Del Monte（地扪）**：部分进口水果和果干礼盒，但水果端不如都乐强。

**单一品类强势品牌**
- **Chiquita（金吉达）**：香蕉为主，礼盒场景偏弱。
- **Pink Lady（粉红佳人）**：苹果，礼盒辨识度高，适合中高端。
- **Envy / Jazz / Rockit（乐淇）**：新西兰/美国苹果品牌，Rockit 小苹果礼盒在团购里很常见。
- **Sun World**：以葡萄、车厘子授权品种为主，采购时看具体包装品牌。
- **Stemilt / Chelan Fresh / Oneonta**：美国车厘子季常见供应商品牌，适合夏季团购。
- **Prize / Vanguard / Rio King**：车厘子、蓝莓等进口商品牌，需按当季货源确认。
- **Zespri 之外的奇异果**：如 **Sungold**、**Golden Kiwi** 等，但品牌力不如佳沛。

**高端/小众礼品向**
- **Miyazaki Mango（宫崎芒果）**、**Shine Muscat（阳光玫瑰）** 日本/韩国产，多为产区品牌而非公司品牌。
- **Kissabel**：苹果品牌，部分高端商超有售。
- **Fruitist / The Fruit Company**：偏礼品篮渠道，国内团购直接采购较少。

**采购建议**
1. 先定品类：柑橘、苹果、车厘子、蓝莓、奇异果，不同品牌强势品类不同。
2. 认准英文商标和授权商，进口水果礼盒“同品类不同品牌”价差很大。
3. 团购要确认：是否支持定制腰封/贺卡、起订量、冷链发货、破损赔付。
4. 如果预算有限，可组合“1个强品牌+1个当季单品”，比全用大牌更划算。
