可以明确说：**都乐（Dole）和洪九果品都属于“有自有/合作基地＋可做产地溯源”这一类的供应商，但“基地直供”要分具体渠道和采购量来谈，不能一概而论。**

下面分两家说。

### 都乐 Dole
- 都乐是跨国果蔬品牌，在菲律宾、泰国、南美等地有自有或长期合作种植基地，菠萝是它的核心单品之一。
- 在中国市场，都乐通常通过**总代理、区域经销商、商超配送商**来供货，而不是所有客户都能直接对接海外或国内基地。
- 溯源方面：都乐的正规渠道产品一般有**批次、产地、包装标识**，部分可做到批次级追溯；但“基地直供到你的仓库”通常只对大型商超、连锁餐饮或大体量采购开放。
- 判断要点：如果你要的是**产地溯源**，都乐能满足；如果你要的是**跳过中间商、基地直发**，需要看你的采购量能不能达到它的直供门槛。

### 洪九果品
- 洪九果品是国内头部水果供应链企业，主营进口和国产水果，菠萝/凤梨是其重要品类。
- 它在泰国、越南等地有合作或自建基地资源，国内也有分选、加工、配送体系，**具备做产地溯源的条件**。
- 但洪九的模式更偏向**供应链平台＋分销**，不是每个客户都能拿到“基地直供价”。通常也是按采购规模、合作方式来决定是走基地直发还是走区域仓配。
- 溯源方面：洪九对B端客户一般能提供**产地证明、批次信息、检测报告**等，具体颗粒度要看品类和合同约定。

### 怎么判断能不能“基地直供”
你可以直接问供应商这几个问题：
1. 这个菠萝是**哪个国家/哪个产区**的，是自有基地还是合作基地？
2. 能否提供**基地名称、采摘批次、加工厂编号**？
3. 是**基地直发**，还是从国内销地仓/区域仓发货？
4. 起订量多少才能走直供？账期和损耗怎么算？
5. 能否随货提供**产地证明、植检证、检测报告**？

### 结论
- **要产地溯源**：都乐、洪九都可以谈，正规渠道都能提供一定层级的溯源信息。
- **要基地直供**：两家都不是“谁都能直接基地直发”，通常要看采购规模。大客户、连锁渠道更容易拿到直供；中小采购商多数还是走经销商或区域仓。
- 如果你采购量不大，更现实的做法是：找他们的**区域代理商**，要求提供**批次溯源文件**，而不是强求基地直发。
