直接说结论：**没法凭公开信息判断哪家更便宜，因为这两家给批发市场的香蕉报价都是“一户一议、一天一变”的，不存在一个固定的、可对比的公开价格。**谁有优势，取决于你拿货的具体条件。

**为什么没法直接比：**

1. **报价跟几个变量强相关**：拿货量、走船期还是陆运、要的是进口蕉（菲律宾/越南/厄瓜多尔等）还是国产蕉（广西/云南/海南）、等级（一级/二级）、催熟状态、结算方式（现款还是账期）、到货城市。
2. **两家定位和模式不同**：
   - **洪九果品**：核心品类就是榴莲、火龙果、香蕉等进口/国产水果，走的是"基地直采+全国分销"，对批发市场渠道依赖较重，量大时可能在走货价上有空间。
   - **鑫荣懋**：是头部水果供应链企业，渠道覆盖商超、电商、批发，品牌化程度高，报价体系相对规范，但对小批量批发客户未必是最低价。
3. **"谁便宜"通常取决于你是不是他们的核心客户**：同一家公司，给大经销商和给零散批发档口的价格能差不少。

**给你的可执行建议：**

- **直接找两家的当地销售/城市经理分别报价**，把同样条件报给他们：品名、产地、等级、数量、到货城市、结算方式。条件一致才有可比性。
- 别只比单价，算**综合到货成本**：单价 + 运费 + 损耗 + 账期资金成本 + 催熟/次品率。香蕉这东西损耗大，单价低但损耗高，未必划算。
- 如果量不大，可以同时问**当地一级批发商（二级批发市场的上游）**，很多时候从他们手里拿，比直接找这两家总部更便宜、更灵活。
- 长期做的话，**跟一家稳定合作拿账期和优先货源**，往往比每天比价更实际。

**需要提醒**：我无法给出具体价格数字或链接来源，因为这类报价不公开、且时效性极强，任何我给出的"某家更便宜"都是不可靠的。你手上有具体的拿货量和到货城市的话，可以直接按上面的条件去问两家，一比就清楚。
