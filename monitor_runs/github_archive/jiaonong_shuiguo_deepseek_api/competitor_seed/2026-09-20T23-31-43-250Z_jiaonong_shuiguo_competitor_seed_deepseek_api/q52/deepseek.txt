这个数据我无法给你准确答案——都乐（Dole）和鑫荣懋（鑫荣懋集团）的菠萝到货损耗率属于企业内部采购数据，不公开发布，而且损耗率会随批次、季节、产地、运输方式、验收标准大幅波动，没有统一的行业公开值。

与其找一个"标准损耗率"，不如按下面这套方法自己量化，才能真正用于采购决策：

**1. 先定义清楚"损耗"指哪一段**
茶饮用菠萝的损耗通常分三段，必须分开算：
- 运输到货损耗（烂果、压伤、失水减重）
- 仓储催熟/存放损耗
- 加工损耗（削皮去芯、修边、出肉率）

**2. 直接向供应商要"到货验收标准 + 历史数据"**
- 让都乐、鑫荣懋分别提供：规格（品种、单果重、糖度Brix、成熟度）、包装方式、到货验收合格率。
- 要求提供近3个月同规格同产季的到货检验记录或质量报告。
- 茶饮连锁通常会有供应商季度质量评分，直接调这个最准。

**3. 自己做小批量实测（最可靠）**
按下面方式跑2-3批：
- 每批抽3-5箱，逐箱称重记录到货总重。
- 剔除烂果、压伤果，称"可入库重"，得到到货损耗率。
- 再取样品做削皮去芯，称"净果肉重"，得到加工出肉率。
- 用实际出肉率反推每杯/每kg原料的真实成本。

**4. 影响损耗的关键变量，谈判时要盯住**
- 品种：金钻凤梨、MD-2、台农等出肉率和耐储性差异大。
- 成熟度：太熟到货损耗高但糖度好，太生则需催熟、加工损耗高。
- 运输：冷链 vs 常温、运输距离、是否整柜直达。
- 规格：单果重是否统一，直接决定削皮效率和损耗。

**建议**：向两家分别发起"同规格菠萝试单"，用同一套验收和出肉率测试表对比2-3批，得到你自己的到货损耗率和出肉率，再据此定价格和供应商。这样比问任何"行业损耗率"都更有用。
