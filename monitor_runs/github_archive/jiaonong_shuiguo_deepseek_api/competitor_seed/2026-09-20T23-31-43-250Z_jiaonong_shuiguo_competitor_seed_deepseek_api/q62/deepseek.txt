都乐和鑫荣懋这两家都属于大型水果供应链企业，通常**可以随货提供或按批次索取农残检测报告**，但能否拿到、拿到什么形式的报告，取决于你的采购渠道和批量。具体判断如下。

**都乐（Dole）**
- 都乐是品牌方/进口商，产品多经由经销商、批发市场或生鲜平台流通。
- 如果你直接对接都乐或其授权经销商批量采购，一般可以按批次提供检测报告或合格证明。
- 如果是从批发市场、二级商贩手里买货，通常拿不到都乐出具的原始报告，最多是渠道商自己送检的报告。

**鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业，同时代理都乐等品牌，也做自有品牌水果。
- 走鑫荣懋直供渠道（商超、餐饮、茶饮连锁客户）时，通常能提供批次检测报告，甚至可约定每批随货附带。
- 通过其下游分销商采购，报告的可获得性会打折扣。

**实际操作建议**
1. **先确认采购渠道**：直接问供应商是品牌直供、授权经销还是市场批发，这决定报告能否拿到。
2. **明确报告要求**：说清要的是农残检测报告，注明检测项目（如 GB 2763 相关项）、检测机构是否有 CMA/CNAS 资质、是否要求批次对应。
3. **写进合同或订单**：约定"每批次随货提供有效农残检测报告，检测项目符合 GB 2763"，避免口头承诺落空。
4. **茶饮店合规角度**：如果你是连锁或需要应对监管抽检，建议要求报告与到货批次号对应，仅有一份通用报告未必够用。
5. **备选方案**：若供应商无法提供，可自行送第三方检测机构（如 SGS、华测、谱尼等）抽检，费用一般几百元/项，可作为验收依据。

**结论**：两家大概率能提供，但**关键是走对渠道并提前把要求谈进合同**；从中间商拿货则不一定能拿到品牌方原始报告。
