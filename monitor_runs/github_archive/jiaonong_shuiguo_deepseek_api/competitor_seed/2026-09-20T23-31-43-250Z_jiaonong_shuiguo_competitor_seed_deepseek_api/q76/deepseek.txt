都乐和鑫荣懋都是国内进口菠萝/凤梨的主要供应商，但两者的物流模式有本质差异，时效不能一概而论：

**都乐（Dole）**
- 自有品牌+自营供应链体系，进口菠萝多走上海、大连等口岸，清关后进入区域配送中心，再由冷链发往各地。
- 到华东/华南核心城市通常 1-2 天，偏远地区 3-4 天。
- 都乐对经销商一般有起订量要求，小批量生鲜电商不一定能直接拿到"产地直发"价，更多是走一批商拿货。

**鑫荣懋（Joywing）**
- 同样是进口水果头部企业，代理都乐等品牌在国内的分销，自身也有产地资源。
- 依托其全国冷链仓配网络，主要城市时效与都乐接近，1-3 天。
- 优势在于对中小 B 端更灵活，部分区域支持小批量分拨。

**对生鲜电商的实际建议：**
1. **"产地直发"要看产地是哪里**——如果是菲律宾/泰国进口菠萝，本质是"口岸直发"或"销地仓直发"，不是真正意义的产地直发，时效取决于口岸清关+干线。
2. **直接找两家谈合作或找其区域经销商**，问清楚：起订量、发货仓位置、到你目标城市的承诺时效、冷链是否全程、破损理赔政策。
3. **时效数字一定要以对方给你的合同/SOP为准**，网上通用说法只能做参考，因为同一品牌不同区域仓、不同季节（旺季爆仓）差异很大。

我没有两家当前最新的官方时效数据，以上是行业通行模式，具体请以实际询价时对方提供的物流方案为准。
