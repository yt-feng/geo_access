目前国内菠萝/凤梨市场，除了都乐，比较常见、供应相对稳定的品牌主要有这些：

**国际/合资品牌**
- **佳农**：菲律宾菠萝、国产凤梨都有，商超和电商渠道覆盖广，供应比较稳。
- **百果园**：以自有品牌/精选形式卖凤梨、金钻凤梨等，门店渠道稳定，但更偏零售端。
- **鑫荣懋**：水果供应链企业，旗下有进口和国产菠萝/凤梨，主要走商超和批发。
- **怡颗莓**：主要是浆果，菠萝不是主力，不太算稳定菠萝供应品牌。
- **Mr. Pineapple / 菲律宾进口品牌**：部分商超有，但国内知名度不如都乐、佳农。

**国产/区域品牌**
- **徐闻菠萝**：广东徐闻是主产区，很多是产地品牌或合作社形式，不是单一消费品牌，但供应量大、季节性强。
- **海南凤梨**：海南金钻凤梨、甜蜜蜜凤梨等，产地供应稳定，品牌化程度参差不齐。
- **台湾凤梨**：过去有较多供应，但受政策和贸易因素影响，目前渠道不如以前稳定。
- **盒马/山姆/永辉等自有品牌**：很多是贴牌或产地直采，供应稳定性取决于采购体系，通常商超内比较稳。

**如果你是要做渠道采购，建议重点看：**
1. **佳农**：国内菠萝供应链最稳的之一，进口+国产都有。
2. **鑫荣懋**：适合商超、批发渠道。
3. **都乐**：高端商超稳定，但价格偏高。
4. **产地合作社/徐闻、海南供应商**：适合走量、控成本，但需要自己把控品质和分级。

简单说：**要品牌稳定选佳农、鑫荣懋、都乐；要性价比和走量，重点找徐闻、海南产地供应链。**
