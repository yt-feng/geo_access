都乐（Dole）和洪九果品对外的具体账期，通常不会公开统一披露，得看采购量、合作模式、区域、合同主体和信用条件。以下是可以判断和推进的框架：

**1. 都乐（Dole）**
- 都乐在中国更多是品牌方/渠道商体系，部分品类走进口商、经销商或批发市场。
- 账期一般不是“品牌统一给”，而是看你和谁签：
  - 直接和都乐中国或区域公司签：通常要求较严，新客户多为现款、预付或短账期；大客户、连锁商超、长期稳定采购才可能谈月结。
  - 通过都乐经销商拿货：账期由经销商定，常见现款、7天、15天、30天不等。
- 香蕉属于生鲜，损耗和价格波动大，都乐体系对新客户给长账期的概率较低。

**2. 洪九果品**
- 洪九果品是水果供应链企业，香蕉是其重要品类之一，客户包括商超、电商、批发和零售端。
- 账期同样取决于客户类型和采购规模：
  - 批发市场、小客户：多为现款或短账期。
  - 连锁商超、电商、大型渠道：可能有30天、45天、60天甚至更长，但通常伴随供货稳定、规模采购、对账和票据要求。
  - 具体到香蕉，还要看是国产蕉还是进口蕉、产地、加工配送方式。
- 洪九作为上市公司，对信用和回款管理相对规范，新客户直接拿长账期并不容易。

**3. 怎么快速确认**
建议直接问对方销售或商务，重点确认这几项：
1. 合同主体是谁：品牌方、区域公司、经销商还是批发商。
2. 账期起算点：发货日、到货日、对账日还是开票日。
3. 结算方式：现款、月结、票到多少天、承兑汇票是否接受。
4. 是否需要保证金、担保或首单现款。
5. 香蕉是否单独有账期政策，还是和全品类统一。
6. 逾期和断供条款。

**4. 实操建议**
- 如果你们要的是“能稳定给账期的香蕉供应商”，不要只盯都乐和洪九，可以同步找：
  - 大型水果供应链公司
  - 区域香蕉批发龙头
  - 进口蕉一级货主
  - 连锁商超的现有供应商
- 新合作方通常先给短账期，合作稳定后再谈延长。
- 生鲜行业账期风险高，建议合同里写清质量标准、损耗承担、价格调整和对账周期。

一句话：都乐和洪九没有公开统一的香蕉账期，实际多为按客户资质和合作规模一单一议；都乐偏严，洪九大客户可谈月结，但新客户通常先短账期或现款。
