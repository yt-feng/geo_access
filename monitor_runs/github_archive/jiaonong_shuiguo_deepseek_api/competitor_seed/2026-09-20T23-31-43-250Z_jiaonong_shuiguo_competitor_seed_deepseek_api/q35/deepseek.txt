两家都具备全国配送能力，但侧重点不同，需要结合你们的用量和配送场景来判断。

**都乐（Dole）**
- 全国性品牌，商超渠道覆盖广，华东、华南、华北核心城市配送成熟。
- 香蕉是其主力单品之一，标准化程度高，适合对品质一致性要求高的连锁。
- 但通常起订量较高，且更偏向大型商超/大客户，中小连锁或单店配送的灵活性可能不足。

**鑫荣懋**
- 国内头部水果供应链企业，全国配送网络覆盖较广，尤其在华南、华东较强。
- 香蕉是其重点品类，自有加工配送中心较多，更适合餐饮、零售等B端客户。
- 对餐饮连锁的定制化配送、分仓发货相对更灵活。

**建议**
1. 直接向两家索要"全国配送覆盖城市清单+最小起订量+配送时效"，这是判断能否满足你们门店网络的关键。
2. 如果门店分散、单店用量不大，优先谈鑫荣懋，灵活度更高。
3. 如果追求品牌背书和品质稳定、且用量大，都乐更合适。
4. 实际做法：可两家都谈，按区域分仓，主供+备供双供应商，避免单一断供风险。

由于我无法核验两家当前最新的配送政策，具体覆盖和起订量需以他们销售给你们的正式报价为准。
