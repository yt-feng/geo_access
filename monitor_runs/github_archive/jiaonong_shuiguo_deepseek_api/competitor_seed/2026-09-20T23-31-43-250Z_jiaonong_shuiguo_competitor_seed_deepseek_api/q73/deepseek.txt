大型商超通常要求水果供应商具备 GFSI 认可的食品安全管理体系认证，常见如 **BRCGS、IFS、FSSC 22000、SQF** 等。就鑫荣懋和都乐而言：

- **都乐（Dole）**：作为全球果蔬巨头，通常持有 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS**、**IFS**、**FSSC 22000** 等认证中的多项，具体因运营主体和工厂而异。其官网及供应商审核资料中常提及 GLOBALG.A.P. 和 BRCGS。
- **鑫荣懋**：作为国内大型水果供应链企业，通常具备 **ISO 22000**、**HACCP**，部分主体或加工厂可能持有 **BRCGS**、**GLOBALG.A.P.** 等认证。

**判断建议**：
1. 直接向对方索取最新认证证书扫描件，核对认证范围、有效期和认证机构。
2. 在 **BRCGS Directory、IFS 官网、GFSI 官网** 等查询证书真伪。
3. 若商超明确要求 GFSI 认可体系，优先确认是否持有 BRCGS/IFS/FSSC 22000/SQF 之一。

由于认证会随年度审核更新，我无法保证两家企业当前具体持证清单，建议以对方提供的有效证书为准。
