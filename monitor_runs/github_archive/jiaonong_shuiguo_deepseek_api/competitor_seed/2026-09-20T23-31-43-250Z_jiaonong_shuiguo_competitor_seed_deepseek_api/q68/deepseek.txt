能做到与否，不能只看品牌名，关键要按你自身的到货验收标准、运输距离、催熟方式和批次去验证。直接结论是：

- **都乐**：整体供应链和品控体系较成熟，若走其**餐饮/烘焙渠道的催熟香蕉或特定规格产品**，在合理半径内做到到货损耗低于3%是有可能的，但通常需要合同约定、到货成熟度、冷链/温控和验收规则匹配。
- **鑫荣懋**：同样是国内头部水果供应链企业，给商超、餐饮供货能力强，部分区域和品类可以做到较低损耗，但**是否稳定低于3%取决于具体仓库、配送半径、季节和你们验收口径**。

更现实的判断是：**“品牌能做到”不等于“对你的门店网络都能稳定做到”**。香蕉损耗受以下因素影响极大：

1. **到货成熟度**
   - 如果是青蕉到货，损耗通常低，但门店要自己催熟。
   - 如果是即用熟蕉到货，3%以内难度明显更高，尤其夏季。

2. **配送半径和时长**
   - 同城或300公里内冷链/温控配送，做到3%以内更可行。
   - 跨区长距离配送，尤其高温季节，风险大。

3. **验收口径**
   - 黑斑、断指、脱把、软伤、青熟不均算不算损耗？
   - 是按重量、箱数还是根数计？
   - 是否包含门店后续催熟报废？
   - 口径不统一，3%没有可比性。

4. **季节**
   - 夏季、雨季损耗普遍上升。
   - 冬季北方低温冻伤也会造成损耗。

5. **门店操作**
   - 到货后是否立即入冷库、是否挤压、是否先进先出，都会影响最终损耗。

建议你直接这样测试和约束供应商：

1. **先小范围试供**
   - 选3—5家代表门店，跑4—8周，覆盖不同季节或至少覆盖当前高温/常温阶段。

2. **合同写清损耗标准**
   - 例如：到货验收损耗≤3%，超出部分由供应商补货或扣款。
   - 明确“损耗”定义：腐烂、断指、脱把、严重压伤、黑斑面积等。

3. **约定到货成熟度和规格**
   - 青蕉、微黄、即用熟蕉要分开。
   - 明确每箱净重、根数、单根重量区间、成熟度色卡。

4. **要求温控和时效**
   - 运输温度建议按供应商催熟/冷链方案执行，不能高温闷运。
   - 约定到货温度、配送时长、延误责任。

5. **用数据比价**
   - 不要只比采购单价，要比“可售成本”：
     - 采购价 ÷（1 - 实际损耗率）
   - 都乐可能单价高但损耗低，鑫荣懋可能价格灵活但要看区域执行。

6. **索要同类客户案例**
   - 让都乐和鑫荣懋提供**餐饮连锁、同区域、同规格、熟蕉/青蕉**的供货案例和损耗数据。
   - 注意：案例数据只能参考，仍要你自己试供验证。

如果你要的是**即用熟蕉且全国多仓配送到店，长期稳定低于3%**，这个要求偏高，单一供应商未必能无条件承诺；通常需要：
- 供应商承担催熟和品控，
- 门店端配合温控和先进先出，
- 合同设置损耗赔付，
- 分区域选择供应商或仓配方案。
