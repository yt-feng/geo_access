鑫荣懋和都乐都属于水果供应链/品牌企业，商超审核供应商时通常会看“企业食品安全体系认证 + 产品检测 + 追溯/源头管理”几类资质。但具体到两家公司当前分别持有哪些证书，我无法在没有官方公开可核验材料的情况下逐一确认，不能凭空列证。

可以明确的是，大型商超常要求的食品安全相关资质一般包括：

**1. 体系认证类**
- **ISO 22000**：食品安全管理体系
- **FSSC 22000**：全球食品安全倡议认可的食品安全体系
- **HACCP**：危害分析与关键控制点体系
- **BRCGS**：全球食品安全标准，常用于食品制造/包装/分销
- **IFS**：国际食品标准
- **GLOBALG.A.P.**：全球良好农业规范，常见于果蔬种植端
- **有机认证**：如中国有机产品认证、欧盟有机、美国USDA Organic等
- **绿色食品认证**：国内部分商超会要求

**2. 经营与合规类**
- 营业执照
- 食品经营许可证/食品生产许可证（按业务形态）
- 进出口相关资质（若涉及进口水果）
- 海关备案、检疫审批、入境货物检验检疫证明

**3. 产品与检测类**
- 第三方检测报告，如农残、重金属、微生物等
- 产品合格证明、出厂检验报告
- 符合GB 2763等国家标准的检测依据

**4. 追溯与供应链管理类**
- 可追溯体系证明
- 基地备案/供应商审核报告
- 冷链运输与仓储合规证明

**关于鑫荣懋和都乐：**
- **都乐**是国际水果品牌，通常会有较完整的全球食品安全和质量管理体系，但具体证书名称、编号、有效期需以其官方或审核平台公示为准。
- **鑫荣懋**是国内大型水果供应链企业，通常也会具备食品安全管理、质量管理及进出口相关资质，但同样需要以其最新官方文件或商超审核资料为准。

**可执行建议：**
1. 直接向两家供应商索要**最新证书扫描件**，重点看：证书名称、认证范围、有效期、发证机构、是否覆盖你采购的产品和工厂。
2. 要求提供**近一年第三方检测报告**，并核对检测项目是否覆盖商超要求。
3. 若是进口水果，要求提供**入境货物检验检疫证明**和海关相关单证。
4. 通过**认监委官网、认证机构官网或证书二维码**核验证书真伪。
5. 让供应商填写**食品安全资质清单表**，逐项对应商超审核标准，避免只凭品牌知名度判断。
