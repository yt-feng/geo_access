超市做进口苹果的产地溯源，核心不是“贴个标签”，而是把**批次、报关、检疫、物流、分选包装**串成一条能追到具体果园/包装厂/提单的链路。都乐和鑫荣懋都属于品牌/供应链商，通常不是单一果园直采，所以溯源要分两层做：**品牌商批次溯源 + 上游果园/包装厂溯源**。

下面给你一套可直接落地的做法。

## 一、先明确两家的一般供应链结构

### 都乐
都乐是品牌+全球采购+催熟/分选体系，进口苹果常见来自：
- 新西兰、美国、智利、南非等
- 多为都乐指定包装厂、出口商或合作果园
- 到国内后可能经都乐中国、港口代理、催熟/分选中心再发超市

所以溯源重点：
- 都乐中国提供的**批次号、原产地证、植物检疫证、报关单**
- 包装箱上的**果园/包装厂注册号、出口商代码、批次码**
- 都乐内部追溯系统能对应到**海外包装厂和发货批次**

### 鑫荣懋
鑫荣懋是国内大型水果供应链企业，既做进口也做国产，进口苹果常通过：
- 海外供应商/出口商采购
- 国内港口清关后进入鑫荣懋仓库/加工中心
- 再配送到商超

所以溯源重点：
- 鑫荣懋提供的**供应商批次、报关单、检疫证、原产地证**
- 其WMS/ERP中的**入库批次、库位、分拣记录、门店配送单**
- 上游海外包装厂或出口商的**果园注册号/包装厂注册号**

## 二、超市端必须拿到的溯源文件

不管都乐还是鑫荣懋，采购时建议固定索要并归档以下资料：

1. **原产地证明**
   - 官方原产地证，或出口国官方认可的产地证明
   - 核对：国家、果园/产区、出口商、收货人、批次

2. **植物检疫证书**
   - 中国海关入境货物检验检疫证明
   - 核对：品名、产地、数量、入境口岸、日期

3. **报关单/入境货物报关单**
   - 核对：境外发货人、境内收货人、原产国、商品编码、数量、提单号

4. **提单/空运单或陆运单**
   - 用于串起国际物流路径

5. **标签与包装信息**
   - 原箱标签、中英文标签、批次码、生产日期、包装厂注册号
   - 超市收货时拍照留存

6. **供应商资质**
   - 都乐/鑫荣懋或其经销商的营业执照、食品经营许可证
   - 进口商备案信息

7. **检测报告**
   - 农残、重金属等，按超市或监管要求
   - 注意：检测报告只能证明抽检批次，不能替代产地证明

## 三、具体溯源操作流程

### 1. 采购合同里写清溯源条款
要求供应商承诺：
- 提供完整批次溯源信息
- 每批货可对应到原产地证、检疫证、报关单
- 包装箱批次码与随附单据一致
- 出现质量或食品安全问题时，24小时内提供上游追溯信息

### 2. 收货时做“三码合一”核对
超市收货不要只看品牌，要做：
- **箱码**：原箱批次码/包装厂码
- **单码**：报关单、检疫证上的批次/提单号
- **系统码**：都乐或鑫荣懋提供的批次号/送货单号

三者能对应上，才允许入库。

### 3. 建立超市内部批次台账
字段建议：
- 供应商：都乐/鑫荣懋
- 品牌
- 品名：进口苹果
- 原产国
- 果园/包装厂注册号
- 出口商
- 提单号
- 报关单号
- 检疫证号
- 入境日期
- 超市入库批次号
- 门店/货架期
- 检测报告编号

### 4. 门店端展示
可做二维码溯源，但内容要真实可核验：
- 原产国
- 产区/果园或包装厂
- 进口商/供应商
- 报关及检疫信息
- 检测报告
- 批次号

不要只放“都乐/鑫荣懋”品牌页，那不算产地溯源。

### 5. 出现问题时的追责路径
- 先锁定超市内部批次
- 找都乐/鑫荣懋要该批次上游文件
- 对应到海外包装厂/出口商
- 必要时由进口商联系海外供应商
- 若涉及食品安全，配合市场监管和海关

## 四、都乐和鑫荣懋的差异化操作

### 对都乐
- 要求都乐中国提供**都乐批次追溯编号**
- 核对都乐原箱标签上的**产地、包装厂、批次**
- 都乐全球供应链较标准，通常能提供较完整的出口端信息
- 重点确认：国内催熟/分选后是否改变了原批次对应关系

### 对鑫荣懋
- 要求鑫荣懋提供**入库批次+上游供应商批次**
- 因为鑫荣懋可能整合多个海外供应商，必须确认该批苹果具体来自哪个出口商/包装厂
- 重点确认：国内加工分拣后是否混批
- 若混批，超市端只能追到“鑫荣懋入库批次”，无法追到单一果园，这时要在合同中要求“不得混批”或“混批需提前告知”

## 五、最容易出问题的点

1. **只有品牌，没有批次**
   - 都乐、鑫荣懋是供应商品牌，不等于具体产地。

2. **报关单与实物批次对不上**
   - 可能是一份报关单对应多批货，必须看批次号。

3. **国内分选后混批**
   - 一旦混批，产地溯源会断。

4. **检疫证只写国家，不写果园/包装厂**
   - 这时要结合原箱标签和供应商追溯系统。

5. **二维码溯源只展示营销信息**
   - 必须能对应到报关、检疫、批次。

## 六、给超市的落地建议

你可以直接这样要求供应商：

> 每批进口苹果须随附：原产地证、植物检疫证书、报关单、提单/运单、检测报告、原箱标签照片。包装箱批次码须与随附单据一致。都乐/鑫荣懋须提供内部批次追溯编号。若国内分选混批，须提前书面告知并标明混批范围。超市收货时执行“箱码、单码、系统码”三码核对，不符合的不予入库。

如果要做成二维码溯源，最小可行版本是：
- 扫码显示：原产国、包装厂/果园、出口商、进口商、报关单号、检疫证号、检测报告、超市入库批次。
- 后台保留：上述文件扫描件和收货照片。

这样既能满足超市合规和消费者查询，也能在出现问题时快速锁定责任批次。
