关于都乐（Dole）和洪九果品的水果礼盒定制起订量，**没有统一的公开固定数值**，因为起订量会根据以下因素动态变化：

- **定制程度**：仅在礼盒外包装贴标，还是要求印专属LOGO、定制内衬、专属文案等，起订量差异很大。
- **水果品类与季节**：如车厘子、晴王葡萄等高价水果起订量通常较低；苹果、橙子等大众水果起订量可能更高。
- **礼盒规格**：单盒重量（如3斤/5斤/8斤）不同，起订量也会调整。
