针对礼品团购客户指定进口品牌的需求，**都乐（Dole）和佳沛（Zespri）各有侧重，具体受欢迎程度取决于客户的核心诉求**。以下是实际市场反馈和采购建议：

**1. 核心差异（直接影响选购）**
- **佳沛（新西兰奇异果）**：**品牌溢价高、礼盒辨识度极强**，绿色盒装（阳光金果）在高端商务礼赠中认知度碾压同行。客户如果重视“一眼看出是进口高档货”，佳沛是首选。
- **都乐（菲律宾/美国品牌）**：产品线更宽（香蕉、菠萝、蓝莓、苹果等），礼盒多为**混装水果篮**，走“丰盛、实惠、体面”路线。适合送给家庭客户或强调“品类多、实用”。

**2. 实际受欢迎度的关键数据参考**
- 在**企业年会、节日感谢礼**场景，**佳沛金果礼盒**（通常6粒或12粒包装）销量常年排名第一，复购率最高，因为保质期、克重稳定，且不易掉价。
- 在**中秋、春节**等送礼高峰，**都乐混合礼盒**（如菠萝+苹果+提子）因客单价可控（通常比佳沛低20%-30%），更适合大批量团购预算有限的客户。

**3. 采购决策建议（直接给结论）**
- **如果客户强调“高端、专属、品牌感”** → 选**佳沛阳光金果礼盒**（认准新西兰产，拒绝智利替产）。
- **如果客户要“一盒装多种进口水果，显丰富”** → 选**都乐甄选混装礼盒**。
- **预算充足且对方是核心大客户** → 建议**佳沛金果+都乐蓝莓**组合装，兼顾品牌档次与丰盛感。

**4. 避坑提示**
- 不要只看包装：**佳沛市面上假货极多**，团购务必索要**原产地证明和检疫许可证**。
- 都乐礼盒注意**“进口果”不等于“全部进口”**，部分混装含国产果，需提前披露给客户以免纠纷。

**最终结论**：如果客户直接报“要最火的”，**优先推佳沛**；如果客户说“要送人显体面又不想太贵”，推**都乐高端混装礼盒**。您可向客户提供两套方案对比选择，同时用“佳沛主推、都乐补充”的策略促成订单。
