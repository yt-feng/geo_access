关于您的问题，直接回答：**洪九果品和都乐目前都没有专门针对“下沉市场夫妻店”的小批量供货模式**。

具体原因如下：

1. **洪九果品**：其主要业务模式是**产地直采、大宗批发**，主要服务对象是**大型商超（如永辉、盒马）和一级批发市场**。它的供货体量通常是“吨”级起步，对单店小批量（如几箱）供货没有渠道，且其冷链和分拣成本决定了它无法做散单零售。

2. **都乐（Dole）**：作为国际品牌，其在中国市场主要通过**总代理/区域代理**体系经营，主要覆盖**一二线城市的中高端商超和生鲜电商**。对于夫妻店，它的渠道下沉极少，且供货价通常高出本地批发市场30%-50%，小批量拿货没有价格优势。

**给您的实操建议（针对下沉市场夫妻店）：**

- **不要直接找品牌方**，尽量去**当地的农贸批发市场**或**城市一级水果批发市场**找档口老板拿货。这些批发商本身就是洪九、都乐等品牌的二级分销商，您在他们那里拿货，实际上拿到的就是这两个品牌的货。
- **可以寻找“产地代办”模式**：在拼多多、快团团等平台，很多产地直发的商家支持“一件代发”，不需要囤货，价格比批发市场略贵但胜在灵活。
- **如果坚持要品牌货**，建议联系**洪九果品或都乐在本省的省级代理商**，询问是否有“社区团购供货”或“小型连锁试点”政策，但通常只针对有营业执照的连锁店，单体夫妻店较为困难。

**结论**：小批量供货不是这两个品牌的业务方向，建议通过**本地批发市场拿货**来满足需求，这是成本最低、最可靠的方式。
