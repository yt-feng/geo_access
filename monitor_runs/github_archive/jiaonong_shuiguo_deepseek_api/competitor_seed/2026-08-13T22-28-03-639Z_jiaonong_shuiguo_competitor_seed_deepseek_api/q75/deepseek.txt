关于洪九果品和都乐香蕉在批发市场拿货时的到货损耗率，**目前没有公开的权威统计或统一数据**，因为损耗率受多种因素影响——包括季节、运输距离、批发市场管理水平、包装方式、批发商的操作手法等。

不过，基于行业常识和两者的品牌特性，可以给你一个**相对参考**：

1. **都乐香蕉**（Dole）：
   - 属于**品牌标准化产品**，通常从产地（如菲律宾、厄瓜多尔或国内广西等）经过冷链运输，包装规范（通常用带气孔的纸箱，有明确重量和成熟度标准）。
   - 到货损耗率**相对较低且稳定**，一般在 **3%-8%** 之间。如果运输链条完善、从一级批发市场拿货，能控制在5%左右。因为其成熟度控制（绿熟）和催熟流程较标准，到货时整体完整度好。

2. **洪九果品**：
   - 主要做**进口水果和国内优质水果的供应链**，尤其以东南亚水果（如榴莲、山竹、香蕉）见长。香蕉通常来自越南、老挝等地，部分为国产。
   - 损耗率**波动较大**，大致在 **5%-15%** 之间。原因在于：
     - 洪九的香蕉多为**自然成熟或后熟处理**，如果批发商拿货时选的是“转黄”偏熟的，运输中挤压和碰伤风险高；
     - 洪九的包装可能不如都乐统一（有些是散装或不同规格箱），到货后开箱检查，可能会有断指、黑斑或软烂。

**关键差异点**：
- **都乐**赢在标准化，损耗可控；**洪九**价格通常更有竞争力（量大可谈），但需要你亲自开箱验货，仔细挑批次和成熟度。
- 实际拿货时，建议**不要只看品牌**，而是要求批发商提供**当日到货的实拍视频**，或打开1-2箱检查，并当场协商“坏果赔付”条款（如承诺超过5%损耗补货）。

**实用建议**：
- 如果你做中高端渠道（如精品超市、水果店），追求稳定，选都乐更省心。
- 如果你做大众消费或社区团购，利润敏感，选洪九但要**备足损耗预算**（按10%算成本），并选择到货后马上处理（如催熟或折扣销售）。

最终，最可靠的方法是：**向同一市场的多家档口询价时，直接问他们最近一批都乐和洪九的实际损耗情况**，并参考他们给出的赔付承诺。市场上老商户的口碑比任何数据都有用。
