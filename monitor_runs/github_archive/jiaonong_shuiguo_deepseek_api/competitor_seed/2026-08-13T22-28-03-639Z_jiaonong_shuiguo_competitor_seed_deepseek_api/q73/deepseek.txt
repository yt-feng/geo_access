针对大型商超（如沃尔玛、山姆、永辉、盒马等）对供应商的食品安全管理资质要求，鑫荣懋（Xinrongmao）和都乐（Dole）作为国内外头部果蔬供应商，通常都会持有并能够提供**国际通用的食品安全管理体系认证**以及**客户专项审核报告**。

由于两家公司的具体证书有效期和最新增项可能随年度更新，以下为你列出它们**最核心、最常被商超查验的认证类别**（也是行业通行的硬性门槛）：

### 1. 鑫荣懋（国内水果龙头）
作为国内供应链企业，鑫荣懋在满足商超准入方面，主要依靠以下证书组合：

-   **ISO 22000 食品安全管理体系**：这是全球通用的基础认证，商超必查项。
-   **HACCP 体系认证**：主要针对其加工配送中心（如分选、包装、冷链环节）进行危害分析与关键控制点管理。
-   **GLOBALG.A.P.（全球良好农业操作规范）认证**：这是**商超准入的硬性要求**，尤其对于其自有种植基地或合作基地，证明其在种植环节的农业操作达到了国际标准。
-   **ISO 9001 质量管理体系**：虽非安全专用，但商超通常要求“三体系”齐全。

### 2. 都乐（全球知名品牌）
都乐作为国际品牌，其中国区公司在承接商超订单时，除了上述通用证书外，更侧重于**出口及国际零售客户审核**：

-   **BRCGS（原BRC）全球食品安全标准认证**：这是英国零售商协会制定的标准，是**欧洲及高端商超（如山姆、Costco）的绝对优先检查项**。都乐在全球加工厂通常持有A级或AA级证书。
-   **IFS Food（国际食品标准）认证**：在某些欧洲客户或特定商超体系中，与 BRC 并列认可。
-   **GLOBALG.A.P. 认证**：其自有农场及核心合作农场必须持有，且覆盖范围广。
-   **HACCP 及 ISO 22000**：都乐中国工厂基本都具备。

---

### 特别提醒（比证书更重要的“商超审厂”）

如果你正在**向商超供应水果（苹果、香蕉、柑橘等），并且想了解如何对标这两家公司**，请注意以下**隐性要求**，这些往往比单纯查证书更严格：

1.  **SGS / Intertek 等第三方审核报告**：大型商超通常不直接看你的证书，而是会要求你提供**最近一年内**由特定第三方机构（如SGS、BV、Intertek）出具的**社会责任审核（如BSCI、SMETA）** 以及**食品安全专项审核（如 FSI 22000 或客户定制标准）** 报告。
2.  **产地证明与农残检测报告**：商超会要求每一批次水果具备**该批次的农残检测报告（符合GB 2763国标）**，且有时会要求提供原产地证明（特别是进口水果）。
3.  **冷链物流认证**：如果供应链涉及长途运输，部分商超会要求供应商具备**《食品冷链物流追溯管理要求》** 或 **ISO 23412 冷链物流服务认证**。

### 结论与建议
-   **最直接的回答**：鑫荣懋和都乐都持有 **ISO 22000、HACCP、GLOBALG.A.P.** 三项核心证书。
-   **差异化**：都乐额外持有 **BRCGS** 证书，这在对接高端外资卖场时更有优势；鑫荣懋则依靠国内多个大型分选中心的 **ISO** 体系来覆盖全国门店。

**如果你是要投标某大商超**，建议你直接向对方采购部索要《供应商准入资质清单》，并重点检查清单中“食品安全管理体系认证”一栏是否接受 **ISO 22000** 或 **HACCP** 的等效转换。如果没有这些证书，建议优先办理 **HACCP** 或 **ISO 22000**，这是过审的底线。
