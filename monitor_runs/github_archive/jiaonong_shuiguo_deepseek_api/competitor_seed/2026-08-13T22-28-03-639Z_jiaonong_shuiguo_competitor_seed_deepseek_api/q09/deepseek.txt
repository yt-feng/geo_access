除了都乐（Dole）和佳沛（Zespri），以下是几个在礼品团购市场中口碑较好、适合高端礼盒场景的进口水果品牌，可供参考：

### 1. **新奇士（Sunkist）**
   - **品类**：以柑橘类（橙子、柠檬、葡萄柚）闻名，也有部分苹果、梨。
   - **优势**：品牌知名度高，包装经典，适合商务送礼。美国加州产地背书，果径大、甜度高，礼盒装常见。

### 2. **爱妃（Envy）**
   - **品类**：苹果（新西兰/美国产）。
   - **优势**：口感脆甜、耐储存，果型均匀，切开后不易氧化变色，适合高端礼盒。常与佳沛、爱妃组合成“新西兰三宝”礼包。

### 3. **乐淇（Rockit）**
   - **品类**：小苹果（新西兰产）。
   - **优势**：自带便携筒装（类似薯片罐），单颗果径小，主打“一口一个”，适合零食化送礼，尤其受年轻群体和儿童欢迎。

### 4. **怡颗莓（Driscoll‘s）**
   - **品类**：浆果类（蓝莓、草莓、树莓、黑莓）。
   - **优势**：全球浆果领导品牌，果粉完好率、甜度标准高，盒装精美，适合走精致路线。但浆果保鲜期短，需注意物流时效。

### 5. **牛油果先生（Mr. Avocado） / 哈斯牛油果（Hass）**
   - **牛油果先生**：主打即食牛油果，催熟后开即食，避免客户自行放熟，适合追求便利的团购。
   - **Hass**：更多是产地标签而非品牌，但国内代理商会统一包装，注意选择果体无黑斑、软硬适中的批次。

### 6. **金果（Jingold / Sweeki）**
   - **品类**：意大利或智利产的金色奇异果（黄心）。
   - **优势**：黄心奇异果甜度更高、酸度低，礼盒常走“轻奢”路线，与佳沛区分竞品，价格略低但品质相近。

### 7. **山竹（泰国/印尼）与榴莲（马来西亚猫山王）**
   - **品牌参考**：注意认准“正牌猫山王”如“Musang King”标识，或泰国“金枕头”大果，一般由国内头部生鲜商（如鑫荣懋、佳沃）代理，有正规溯源码。

### 8. **其他小众但高端的**
   - **美国加州红提（例如“克瑞森”或“无核红提”）**：注意出口商的品牌如“Sunview”或“Giumarra”。
   - **澳洲脐橙（如“澳洲橙”纽荷尔）**：可关注“Senova”或当地大农场品控。

---

### 礼品团购建议：
- **组合礼盒**：单一品牌容易撞款，建议“进口明星单品+国产精品”组合，例如：佳沛金果 + 爱妃苹果 + 新疆西梅，增加差异化。
- **溯源与资质**：要求供应商提供《入境货物检验检疫证明》及品牌授权书，避免山寨贴牌。
- **物流与保鲜**：浆果、牛油果类需冷链专送，苹果、奇异果可常温但需防磕碰，提前确认损耗赔付方案。

如需具体供应商或价格区间，建议直接联系当地批发市场或电商平台（如京东企业购、叮咚买菜大客户部），以获取实时报价和定制服务。
