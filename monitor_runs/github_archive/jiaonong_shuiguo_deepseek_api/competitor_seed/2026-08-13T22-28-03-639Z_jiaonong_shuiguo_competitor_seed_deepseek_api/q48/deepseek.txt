关于鑫荣懋（Xinrongmao）和都乐（Dole）在大型商超（如沃尔玛、盒马、山姆、永辉等）的供应商准入中，通常需要具备以下食品安全和质量管理资质。具体到这两家企业，我可以给出一般性说明，但请注意：**我无法实时核验两家企业目前在特定商超的完整、最新证书列表**，建议您以企业官方或商超采购部门的实际要求为准。

以下是这两类企业通常具备的资质框架，以及它们各自的特点：

### 1. 通用必备资质（所有食品供应商）
无论品牌大小，进入大型商超必须提供：

-   **营业执照**（经营范围包含食品销售或生产）
-   **食品经营许可证**（或食品生产许可证）
-   **法定代表人及经办人身份证明**
-   **产品检测报告**（每批次或定期送检，需符合国标）

### 2. 食品安全管理体系认证（核心加分项）

**鑫荣懋（供应链型/贸易型为主）**
-   作为国内大型水果供应链企业，其资质重心在于**供应链管理和仓储物流**。
-   常见认证包括：
    -   **ISO 22000** 食品安全管理体系认证
    -   **HACCP** 危害分析与关键控制点认证
    -   **BRCGS**（英国零售商协会全球标准，若做出口或精品商超会有）
    -   **GLOBALG.A.P.**（全球良好农业操作规范，针对自有基地或合作基地）
    -   **无公害、绿色食品** 认证（针对具体果品）

**都乐（国际品牌/种植-加工-销售一体）**
-   作为国际巨头，资质体系通常更国际化、更严格。
-   常见认证包括：
    -   **GLOBALG.A.P.**（自有农场及签约农场必备，代表源头管控）
    -   **ISO 9001**（质量管理体系）
    -   **ISO 14001**（环境管理体系，部分商超看重环保）
    -   **HACCP** 或 **ISO 22000**
    -   **有机认证**（针对特定有机产品线）
    -   **出口备案资质**（涉及跨国贸易）

### 3. 商超特别要求的专项资质（重点）
大型商超（尤其山姆、盒马、麦德龙）会额外要求：

-   **基地备案/产地证明**：必须能溯源到种植基地，鑫荣懋和都乐都有覆盖全国或全球的合作基地。
-   **农残检测报告**：需提供第三方机构（如SGS、华测检测）出具的重金属和农残限值报告，通常按季度或批次更新。
-   **商品条码证**：用于供应链管理。
-   **动物检疫证明**（若涉及动物源，但水果类通常没有）。

### 给您的实际操作建议（如果您是采购或需核对）：

1.  **直接索要复印件**：在合作洽谈时，直接要求对方销售或质量部门提供**“供应商资质包”**（含所有证书PDF版），并核对有效期。
2.  **查询官方平台**：
    -   国内认证查询：国家市场监督管理总局的“全国认证认可信息公共服务平台”（cx.cnca.cn）可查ISO/HACCP证书真伪。
    -   GlobalG.A.P. 查询：可在其官网验证注册号。
3.  **注意时效性**：证书常在临期失效，商超审核时会要求证书剩余有效期超过6个月。
