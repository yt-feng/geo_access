关于**鑫荣懋**和**都乐**作为大型商超（如沃尔玛、山姆、永辉、盒马等）的供应商，其冷链物流配送覆盖城市的信息，以下是基于公开业务情况的概括：

1.  **鑫荣懋（Xinrongmao）**：
    -   覆盖范围：**全国性**。其业务网络覆盖国内主要的一二线城市及重点三线城市，包括但不限于北京、上海、广州、深圳、杭州、南京、成都、重庆、武汉、西安、郑州、沈阳、青岛等。
    -   配送特点：鑫荣懋拥有自建冷链物流体系及第三方合作网络，通常能够实现核心城市24小时内的“从产地到门店”配送。

2.  **都乐（Dole）**：
    -   覆盖范围：**全国性**。都乐在中国的主要业务覆盖华东、华南、华北及华西地区，重点城市包括上海、北京、广州、深圳、厦门、福州、杭州、苏州、南京、天津、成都、武汉等。
    -   配送特点：依托其进口和国内种植基地，都乐在全国设立了多个配送中心（DC），冷链物流覆盖主要商超的配送网络。

**重要提示：** 具体到某个具体城市或某个特定商超门店的配送情况，**会因商超自身的配送体系、门店区域以及双方合同约定的服务范围而有所不同**。大型商超通常要求供应商具备“最后一公里”配送能力，但**部分城市可能由商超自有物流（如京东物流、山姆云仓）进行末端提货或中转**。

**建议行动**：
如果您是采购方或合作方，需要精确确认某城市是否能配送，**最可靠的方法是直接联系鑫荣懋或都乐的销售代表/客服**，提供您所在的具体城市和商超名称，他们会根据其冷链节点（DC）的覆盖半径，给出准确的配送可行性答复。
