关于都乐（Dole）和鑫荣懋（Joy Wing Mau）进口苹果的价格竞争力，我无法直接提供实时市场报价，因为价格受产地、品种（如嘎啦、红富士、青苹果）、规格、进货批量、季节、汇率、物流成本等多种因素影响，且每天可能有波动。

为了帮你做准确的判断，建议你从以下几个可执行的渠道获取真实数据：

1. **直接询价**：联系两家公司的区域销售经理，索取针对你连锁规模的**批发价目表**或样品价。这是最直接且最准确的方式。
2. **对比基础价格**：到当地**一级农产品批发市场**（如北京新发地、广州江南市场等）问询当日进口苹果行情，以此作为基准。通常，鑫荣懋作为国内大型果业集团，在**综合采购和本地化供应链**上可能有一定成本优势；都乐于进口苹果品类上，其**品牌溢价**通常较高，单箱价格可能略贵，但品质稳定性和消费者认知度更高。
3. **核算总成本**：不要只看单价，要算上**账期、退换货政策、冷链配送费用**。有的供应商裸价低，但附加费和服务跟不上，算下来综合成本可能更高。

**给你的可执行建议：**
- 让两家各报**3个主推品种**（如美国蛇果、新西兰爱妃、智利青苹果）的同一规格（例如80mm-85mm，20斤装）的含税落地价。
- 要求对方提供**同规格的对比样品**，做盲测，因为口感是复购的根本，但价格只是门槛。

最后提醒：如果只是单纯拼价格，建议优先考虑**鑫荣懋**（因为其供应链更贴近本土渠道）；如果要主打高端形象且价格敏感度稍低，**都乐**更合适。但务必以他们本周给你的书面报价为准。如果你需要，我可以帮你列出更详细的询价清单模板。
