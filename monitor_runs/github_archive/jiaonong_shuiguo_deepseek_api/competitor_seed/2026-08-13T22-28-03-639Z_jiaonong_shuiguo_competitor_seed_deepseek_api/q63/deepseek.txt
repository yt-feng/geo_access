针对社区团购场景，关于**都乐（Dole）**和**洪九果品**的香蕉小包装/散装选项，直接回答如下：

**1. 都乐（Dole）**
- **散装/裸果**：**基本没有**。都乐在国内市场主打品牌化、标准化，其香蕉多以**预包装（如5-10斤整箱、袋装、礼盒装）**或**商超专供的冷柜陈列装**为主。社区团购如果想做，需要自行拆箱分装，通常没有“单根/小份散装”出厂形态。
- **替代方案**：可以采购其**整箱（如5kg/10kg）**，由你方或团购点人工分装为小袋（每份约1-2斤）。**但注意**：整箱采购价较高，且到货后需尽快分装销售，损耗率要计算在内。

**2. 洪九果品**
- **散装/裸果**：**有，且更灵活**。洪九在产地端（如东南亚基地）和批发端有较强掌控力，其**批发渠道（B端）**通常可以提供**未包装的裸果整箱（按箱计重，非固定小包）**，也支持按需分装（如每份500g/1kg装袋）或送装到社区点位。
- **合作方式**：直接对接其**区域销售经理**，明确提出“社区团购小包装需求”，他们可以按周或按单定制，价格通常比都乐低10%-20%。

---

**给你的实操建议：**

- **先用洪九做主力**，因为散装灵活性高、成本可控，适合社区团购的“低价+小份”逻辑。
- **都乐仅用于做“品牌背书”**，如果你有高端客群，可整箱进、自行分装，但务必测试损耗率（建议控制在5%以内）。
- **务必签合同前问清**：① 单箱毛重/净重偏差（通常±2%）；② 是否含包装费/分装费；③ 送达社区点的冷链条件；④ 残次果退换比例（洪九通常可谈5%内免费补货）。
