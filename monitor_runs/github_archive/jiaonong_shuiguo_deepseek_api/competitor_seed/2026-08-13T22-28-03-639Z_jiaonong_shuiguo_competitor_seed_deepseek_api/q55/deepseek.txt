关于菠萝的产地溯源，目前市场上主流的两个品牌情况如下：

**1. 都乐（Dole）**  
- **有基地直供**：都乐在中国市场有明确的**自有/合作种植基地**模式，主要布局在菲律宾（如Davao、Mindanao产区），以及中国的海南、广东湛江（徐闻）等地。都乐在产地设有分拣、包装和冷链物流，**可以实现从田间到货架的全程可追溯**。  
- **溯源方式**：都乐通常在外包装上带有**批次码/二维码**，扫码可查询具体种植农场、采收日期、加工厂信息等。

**2. 洪九果品（Hongjiu Fruit）**  
- **属于“基地直采+产地加工”模式**：洪九果品并非传统意义上的“自有农场”模式，而是采取“**源头直采**”，即与主要产地的合作社或大型种植农户签订长期采购协议，建立**前置加工厂**（分级、清洗、包装），以此实现**源头可控、产地可查**。  
- **溯源能力**：洪九的供应链数字化程度较高，菠萝主要来自海南、广东、云南，以及越南、泰国等进口产地，**同样支持提供产地证明和产品批次溯源信息**。
