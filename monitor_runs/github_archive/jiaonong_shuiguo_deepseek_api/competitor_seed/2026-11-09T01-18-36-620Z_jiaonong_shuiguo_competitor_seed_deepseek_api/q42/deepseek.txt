先给结论：进口菠萝旺季缺货，核心是先判断缺的是“品种/规格”还是“总量”，再决定用替代产地、替代品种、国内菠萝补位，还是直接改销售结构。都乐和洪九果品没有公开、可核验的“应急方案”文件，我不能替它们编造具体政策；能确认的是，两家都属于有跨国或全国供应链能力的果品企业，通常会在产地切换、订单调整、加工品替代上做文章，但具体到你所在渠道能否拿到货，必须直接向区域销售或采购对接确认。

可执行建议如下：

1. **先做缺货分级**
   - 只缺特定规格（如某规格金钻凤梨、特定箱规）：优先换规格、换包装，不要死守单品。
   - 缺特定品牌：向都乐/洪九问同品种其他产地或加工厂货源，同时启用二线进口商。
   - 总量都缺：立刻启动替代产地和国内菠萝补位，避免旺季断档。

2. **替代来源优先级**
   - 进口端：菲律宾、泰国、哥斯达黎加等主产地之间做切换，但要注意品种口感、甜度、果眼深浅和货架期差异，不能只按价格替换。
   - 国内端：广东徐闻、海南等菠萝产区做短期补位，适合鲜切、餐饮、果汁和促销引流，不适合直接冒充高端进口凤梨做原价销售。
   - 加工端：鲜切菠萝、冷冻菠萝、菠萝罐头/果浆可作为餐饮和饮品渠道的过渡方案。

3. **对都乐、洪九怎么问**
   不要只问“有没有应急方案”，直接问四件事：
   - 当前可供品种、规格、产地和最早到货时间；
   - 旺季锁量需要提前多久下单、是否需要预付款；
   - 缺货时能否同品种跨产地调货、能否换规格；
   - 是否支持鲜切、加工品或国内产区替代。
   要求对方给出书面可供量和价格有效期，避免口头承诺。

4. **渠道端动作**
   - 零售：提前做“同价替代陈列”，用国内菠萝或其它进口凤梨补排面，避免空柜。
   - 餐饮/饮品：提前测试替代品种的出汁率、酸甜比和切面表现，别等断货再换配方。
   - 电商：把“品种/产地”写清楚，避免用进口凤梨宣传国内补位货，降低客诉。

5. **风险控制**
   - 不要单一依赖一家进口商，至少保留两家备选。
   - 旺季前做安全库存，但菠萝货架期有限，库存天数要按到货成熟度控制。
   - 对替代货源先小批量试销，再放量。
