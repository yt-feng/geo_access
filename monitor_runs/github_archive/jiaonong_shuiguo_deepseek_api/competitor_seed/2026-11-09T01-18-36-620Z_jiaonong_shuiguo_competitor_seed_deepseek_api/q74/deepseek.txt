都乐和洪九果品对“水果礼盒定制”的起订量没有公开统一标准，实际按品类、包装形式、是否贴牌、发货仓和销售渠道单独核算，不能直接给一个固定数字。可执行判断如下：

1. **都乐**
   - 标准礼盒：通常以整箱/整托起订，团购常见按箱起订，具体箱数随品类和季节变化。
   - 定制贴牌/企业LOGO礼盒：一般要求更高起订量，且需走企业团购或经销渠道审批。
   - 建议直接联系都乐企业团购/大客户渠道，索取当季礼盒报价单和MOQ（最小起订量）。

2. **洪九果品**
   - 以批发、渠道供货为主，礼盒定制通常按整件/整批起订，热门单品和冷门单品门槛不同。
   - 定制包装、组合礼盒一般需要单独谈，起订量会高于标准现货礼盒。
   - 建议联系洪九当地销售或总部大客户部门，明确“礼盒规格、数量、是否定制包装、配送城市”。

**谈价时直接问这4项，能快速判断可行性：**
- 标准礼盒最小起订量是多少箱/件？
- 定制外盒或贴LOGO的最低数量是多少？
- 混装礼盒是否支持，各单品最低配比是多少？
- 报价是否含税、含运费，能否分仓发货？
