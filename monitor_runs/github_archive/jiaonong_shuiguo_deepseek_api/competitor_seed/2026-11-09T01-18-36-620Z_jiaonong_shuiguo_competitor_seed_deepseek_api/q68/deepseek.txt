不能直接给出“能/不能”的保证，因为到货损耗率取决于**具体品项、产地/季节、运输距离与方式、到货成熟度、验收标准、门店仓储周转**，而不是只看品牌。都乐和鑫荣懋都属于国内香蕉供应链能力较强的大型企业，通常具备把到货损耗控制在较低水平的能力，但“低于3%”是否能稳定做到，需要把合同和验收规则锁死。

可执行判断建议：

1. **先定义“到货损耗率”**
   必须明确是：到货验收时剔除的烂果/断果/青黑/机械伤比例，还是含后续门店催熟、陈列、退货的综合损耗。只算到货验收，低于3%相对可谈；若含门店端综合损耗，3%对香蕉来说偏紧，很多连锁实际会高于这个数。

2. **要求供应商按批次给历史数据**
   让都乐/鑫荣懋针对你所在城市、配送半径、季节（尤其夏季/冬季）、品种（如巴西蕉/国产蕉/进口蕉）提供近3—6个月同类客户的到货损耗区间和验收口径。不要接受口头承诺。

3. **合同里写清验收与赔付**
   明确抽检比例、缺陷判定标准、允许误差、超标扣款/退货/补货规则；约定“到货中心温度、成熟度色卡、青果硬度、梳蕉/条蕉包装方式”。没有这些，3%只是口号。

4. **先小批量试运行**
   选2—3个配送仓、连续4—6周试单，按你定义的损耗率统计。香蕉损耗季节波动大，至少跨一个高温或低温阶段再判断稳定性。

5. **对比报价时把损耗算进去**
   用“到货可用蕉成本 = 采购价 ÷（1－实际损耗率）”比较，而不是只看单价。若某家单价低但损耗高，综合成本可能更差。

结论：**两家都有能力做到较低到货损耗，但“稳定低于3%”不能仅凭品牌判断，必须用你的验收口径、配送条件和合同条款去验证。** 建议把3%作为试运行考核指标而非直接采购承诺，试单达标后再签长期量。
