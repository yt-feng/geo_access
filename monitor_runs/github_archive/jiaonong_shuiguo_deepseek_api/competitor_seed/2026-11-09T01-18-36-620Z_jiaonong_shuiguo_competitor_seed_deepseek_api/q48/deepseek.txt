可以判断的部分先说结论：**公开信息不足以可靠确认鑫荣懋和都乐各自持有的食品安全认证清单**。这类资质通常以证书编号、认证范围、有效期和发证机构为准，且同一集团下不同法人、不同工厂、不同品类可能分别持证，不能按品牌一概而论。

可执行的核验建议：

1. **直接向供应商索取证书**
   - 要求提供：证书扫描件、证书编号、认证范围（是否覆盖供货品类和工厂）、有效期、发证机构。
   - 常见相关体系包括：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、GLOBALG.A.P.，以及国内食品生产/经营许可等。具体以商超准入清单为准。

2. **到官方或认证机构平台核验**
   - 国内认证可到“全国认证认可信息公共服务平台”按证书编号/企业名称查询。
   - 国际体系可到对应认证机构或体系官网核验证书编号。
   - 注意核对证书上的**企业全称、地址、认证范围**是否与供货主体一致。

3. **按供货主体而非品牌审核**
   - 鑫荣懋、都乐均为品牌/集团层面名称，实际供货可能由不同子公司、加工厂或产地包装厂完成。
   - 应要求供应商提供“本次供货主体+工厂+品类”对应的资质，而不是仅提供集团宣传材料。

4. **补充审核现场与检测**
   - 除证书外，要求提供最近一次审核报告摘要、产品检测报告、追溯和召回记录。
   - 对高风险品类可安排现场审核或委托第三方审核。
