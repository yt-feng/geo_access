我无法给出都乐和鑫荣懋的准确到货损耗率，因为这类数据不是公开可核验的行业指标，随品类（鲜果/冷冻果块/果浆）、规格、季节、运输距离、验收标准和统计口径差异很大，直接报一个数字会误导采购决策。

可执行的做法：

1. **把“损耗率”定义写进询价单**：明确是“到货验收扣重率”还是“入库后7天可用率”，按重量计还是按箱/件计，是否含压伤、黑心、过熟、霉变、规格不符。
2. **向供应商索要近期批次数据**：要求提供近3个月同类规格的到货验收记录或质量报告，注明产地、采摘/加工日期、冷链方式和到货城市。
3. **自己做小批试单**：同一规格各下2—3批，按统一验收表逐箱记录，计算“到货扣重率”和“7天可用率”，试单量以能覆盖一个配送周期为准。
4. **合同里设损耗条款**：约定验收抽样比例、扣重规则、超标赔付或换货机制，并把“规格稳定”量化为糖度、单果重/块径、成熟度、色泽、异物的允收范围。
5. **区分原料形态**：鲜果菠萝的季节和成熟度波动大，冷冻果块/果浆的损耗口径完全不同，稳定规格优先考虑标准化加工形态并锁定批次。

如果你能说明是鲜果还是冷冻/果浆、规格、到货城市和验收口径，我可以帮你把验收表和损耗计算公式列出来。
