结论先说：**不能默认“都能做到全年稳定供应”，要按你需要的形态和区域分开判断。**

1. **都乐**
   - 都乐有全球菠萝供应链，国内也能做全年调配，但“全年有菠萝”不等于“全年同一产区、同一品种、同一糖酸度”。
   - 如果你要的是**鲜菠萝果肉做果酱**，都乐可以作为候选，但你要向供应商确认：全年供货产地切换、品种、成熟度、到货规格、批次稳定性、最小起订量和区域配送。
   - 都乐更偏品牌鲜果和餐饮供应链服务，是否能按茶饮店果酱加工需求提供稳定B端规格，要看具体城市和经销商。

2. **洪九果品**
   - 洪九是国内大型水果分销商，菠萝是其重要品类之一，具备跨产区采购和批发分销能力。
   - 但洪九的核心优势在**水果分销和批发**，不是专门为你做果酱原料的定制供应链。是否能全年稳定供你所需规格，要看你所在区域、采购量和是否有对应渠道。
   - 对茶饮用果酱，鲜果批次差异、熟度、纤维感、出汁率会直接影响出品，不能只看“有货”。

**可执行判断建议：**
- 不要只问“能不能全年供”，要拿**12个月供货计划表**：产地、品种、规格、糖度、酸度、到货价、最小起订量、替代方案。
- 先做**3个月小批量试供**，每月留样做果酱，测色泽、香气、酸度、出胶和稳定性。
- 茶饮店更稳的方案通常是：**鲜果+冷冻果肉/果茸+果酱基料组合**，而不是全年只靠单一鲜果供应商。
- 合同里写明：断供时的替代产地、品质偏差范围、赔付和提前通知期。

所以：**都乐和洪九都“有可能”参与全年供应，但不能仅凭品牌就认定能满足你茶饮果酱的全年稳定需求；必须按规格、区域和月度样品验证。**
