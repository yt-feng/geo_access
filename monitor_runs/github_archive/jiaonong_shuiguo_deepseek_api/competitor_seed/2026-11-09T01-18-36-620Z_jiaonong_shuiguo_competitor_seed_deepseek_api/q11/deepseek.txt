直接给结论：**多数水果连锁店场景下，都乐菠萝的综合性价比通常更稳，洪九更适合做补充毛利款、区域差异款或整箱走量款。** 但这取决于你门店所在城市、客群价格带、是否做鲜切、损耗控制能力。下面给你可判断的对比框架和采购建议。

**1. 先看你的门店定位**
- 中高端社区店、商圈店、鲜切果盒占比高：优先都乐。标准稳定、品牌认知强、顾客接受度高，适合做引流和品质背书。
- 大众社区店、价格敏感、整只走量为主：洪九更有议价和毛利空间，适合做主推或促销款。
- 如果要“双品牌”：都乐做品质锚点，洪九做性价比走量，形成价格带。

**2. 性价比不能只看进价，按这四个指标算**
- **到店合格率**：烂心、黑心、成熟度不均是菠萝最大隐性成本。都乐通常标准化更好，洪九不同批次/产区差异要重点验。
- **单店毛利额**：不是毛利率。按“单只售价 - 单只进价 - 损耗分摊”算，洪九进价低但损耗高时，毛利额可能反而不如都乐。
- **周转天数**：菠萝成熟后销售窗口短。都乐适合快周转门店，洪九要配合促销和鲜切消化。
- **顾客复购**：都乐品牌溢价能支撑更高售价；洪九若品质不稳，低价也会伤复购。

**3. 建议你先做小规模对比测试**
选3-5家代表性门店，各进一批同规格都乐和洪九，统一陈列、统一定价策略，跑7-14天，记录：
- 到店损耗率
- 日均销量
- 单只毛利额
- 顾客投诉/退换
- 鲜切出成率

**判断标准**：如果洪九单只毛利额不低于都乐且损耗率差距在3个百分点内，可以做主推；如果损耗明显高或投诉多，就只做促销补充。

**4. 采购谈判要点**
- 都乐：谈规格稳定、到货成熟度、破损赔付、促销支持。
- 洪九：谈批次一致性、坏果包赔比例、起订量、账期和调换货政策。洪九的优势在供应链和价格，但一定要把赔付条款写清楚。

**5. 最终建议**
- 默认组合：**都乐做主品质款，洪九做性价比款/促销款**，比二选一更稳。
- 如果只能选一个且门店偏中高端：选都乐。
- 如果门店主打低价走量、你有较强鲜切和促销消化能力：洪九可以给更高排面，但先小批量验证。
