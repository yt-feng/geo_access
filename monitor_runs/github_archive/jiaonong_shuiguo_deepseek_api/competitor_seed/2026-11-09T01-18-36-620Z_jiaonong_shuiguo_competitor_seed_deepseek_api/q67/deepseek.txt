都乐和洪九果品通常可以提供菠萝相关的品牌营销素材，但能否拿到、以什么形式拿到，取决于合作层级和用途授权，不能一概而论。

可执行判断如下：

1. **都乐**
   - 作为国际水果品牌，通常有较成熟的品牌视觉、产品图、产地故事、营养/食用场景素材。
   - 生鲜电商若已与其有采购或经销合作，可向对接的销售/市场渠道索取品牌授权素材包。
   - 若无直接合作，公开宣传物料一般不能直接商用，需取得书面授权。

2. **洪九果品**
   - 作为国内水果供应链企业，通常可提供产品规格、产地、分级、包装、质检等偏供应链和商品信息类素材。
   - 品牌营销类素材的丰富度和授权政策因品类、区域、合作方式而异，建议直接联系其区域销售或市场部门确认。
   - 同样，商用前需确认图片、品牌标识、文案的使用范围和期限。

3. **建议操作路径**
   - 先明确营销用途：详情页、直播背景、短视频、社群海报、线下物料。
   - 向两家对接人索要：品牌授权书模板、可商用素材包、素材使用规范、审核流程。
   - 若暂时拿不到品牌方素材，可先用自有实拍、产地实拍、检测报告、分级标准等做差异化内容，避免侵权。
   - 在合同中写明：素材提供方、授权范围、使用期限、是否可二次剪辑、是否可投流。

结论：**两家都有可能提供素材，但都乐偏品牌营销素材，洪九偏供应链商品素材；能否商用必须走书面授权，建议直接向对接销售/市场部门索取素材包和授权规范。**
