除了都乐，国内能相对稳定供货的菠萝品牌，可以按渠道和定位分几类：

**1. 佳农（Goodfarmer）**
- 国内菠萝供应链里比较稳的一家，商超、生鲜电商常见。
- 主打菲律宾、泰国、国产菠萝都有，品控和到货稳定性在进口果里算靠前。
- 适合商超、电商、批发档口长期拿货。

**2. 鑫荣懋（Joy Wing Mau）**
- 水果供应链大商，菠萝不是唯一品类，但商超渠道覆盖强。
- 旗下有自有/代理品牌，适合走 KA 商超和区域连锁。
- 稳定性更多体现在供应链能力，不是单一菠萝品牌心智。

**3. 洪九果品**
- 进口水果供应链为主，菠萝有涉及，走批发和商超渠道。
- 适合大宗采购，但具体到菠萝单品稳定性要看区域和季节。

**4. 百果园体系**
- 百果园自有品牌和供应商体系里有菠萝，但更多是零售端品牌，不是面向批发的大流通品牌。
- 适合零售参考，不适合作为大宗供货品牌。

**5. 区域国产菠萝品牌/产地供应链**
- 广东徐闻、海南、云南等产地有一批区域供应链公司，不一定有全国性品牌，但产地直发稳定。
- 徐闻菠萝季（通常 2—5 月）供应量大，适合做国产替代。
- 这类要看具体供应商，不是统一品牌。

**6. 进口方面**
- 菲律宾菠萝除都乐外，佳农、鑫荣懋、洪九等都有操作。
- 泰国小菠萝、香水菠萝有一些专做泰果的进口商，但品牌集中度低，稳定性不如佳农、都乐。

**实操建议：**
- 要全国商超稳定供货：优先谈 **佳农、鑫荣懋**。
- 要批发市场大宗：看 **洪九** 和当地一级进口商。
- 要国产性价比：直接找 **徐闻、海南产地供应链**，按季节锁量。
- 不要只看品牌，菠萝稳定性关键看：产地季节、到港/采摘周期、冷链、规格分级。建议同时备一个进口品牌 + 一个国产产地供应商，降低断供风险。
