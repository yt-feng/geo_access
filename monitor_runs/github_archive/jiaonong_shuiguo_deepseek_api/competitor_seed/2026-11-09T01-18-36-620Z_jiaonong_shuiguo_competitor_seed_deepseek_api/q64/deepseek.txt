我没法核验鑫荣懋和都乐各自冷链配送“覆盖哪些城市”的完整、最新名单，直接列城市会有过期或虚构风险。可执行的做法如下：

1. **先明确商超验收口径**  
   大型商超通常不是只看“覆盖城市列表”，而是要求供应商提供：冷链运输资质、温控记录、配送时效、目的地城市能否直达/次日达、是否有区域仓或干线合作。先向商超索取其《供应商冷链准入标准》和配送范围要求。

2. **向两家分别索要书面配送能力证明**  
   让鑫荣懋、都乐对应区域销售/供应链对接人提供：
   - 营业执照及冷链相关资质；
   - 冷链车辆/合作承运商清单；
   - 区域仓/中转仓地址；
   - 可配送城市清单及温区（冷藏/冷冻/恒温）；
   - 到目标商超门店或DC的配送时效和温控记录样例；
   - 近3个月同类商超配送案例。
   要求盖章或邮件确认，避免口头承诺。

3. **按目标城市做“点对点确认”**  
   不要问“你们覆盖哪些城市”，而是给出你要供货的商超门店/DC城市清单，逐城确认：能否直送、起送量、时效、温控记录、异常处理。这样得到的是可验收答案。

4. **核验渠道**  
   可查两家官网/官方公众号的“冷链物流/配送网络”介绍，但最终以区域负责人邮件确认为准；也可要求其提供与大型商超合作案例作为佐证。
