可以要，但不要默认“品牌方一定能直接给”。更稳妥的判断是：

1. **都乐、鑫荣懋通常能提供农残检测报告，但取决于采购渠道和批次**
   - 通过其官方经销/直供渠道采购，通常可申请该批次的检测报告或合规文件。
   - 通过批发市场、二级经销商拿货，品牌方不一定对你这批货出具报告，实际要由供货商提供。

2. **采购前直接这样确认**
   - 问供货商：“这批菠萝有没有**对应批次**的农残检测报告？”
   - 报告要能对应：**品名、批次/采收或包装日期、检测项目、检测机构、结论**。
   - 若只有一份“通用报告”但不是本批次，不能作为你这批货的验收依据。

3. **合同/订单里写清楚**
   - 要求随货提供**批次农残检测报告**；
   - 约定检测标准（如按 GB 2763 农残限量）；
   - 若抽检不合格，退换货及检测费用由供方承担。

4. **实操建议**
   - 先向都乐/鑫荣懋的**官方客服或当地销售**确认是否直供、能否随批出报告；
   - 同时让候选供货商先发一份**报告样张**，核对检测项目和批次信息；
   - 到货后保留样品，必要时自费送第三方复检。

结论：**能提供是常见情况，但必须锁定“对应批次”和“供货渠道”，不能只听品牌名。**
