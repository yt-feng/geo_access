都乐（Dole）和洪九果品都属于香蕉品牌/供应链企业，是否有“面向便利店的香蕉小包装定制”要分两种情况看：

1. **都乐**
   - 通常有面向商超、便利店渠道的小规格香蕉包装（如按把/按份、袋装或托盘覆膜等），但**是否接受便利店单独定制包装（印门店LOGO、指定克重/把数/袋型）**，需要走都乐当地分公司的渠道/KA业务确认。
   - 可执行判断：如果你要的是**现成小包装规格**，大概率可通过当地经销商或都乐KA拿货；如果是**定制印刷/定制规格**，通常有起订量、门店数量或年度采购量门槛，单店很难直接定制。

2. **洪九果品**
   - 洪九更多是水果供应链/批发分销型企业，香蕉是其重要品类之一，**可能有小规格分装或渠道专供包装**，但“便利店定制包装服务”并非公开标准服务，需向洪九当地销售/渠道商确认。
   - 可执行判断：若你只需要**小把香蕉、按份分装**，可问当地洪九经销商能否做“渠道分装”；若要**品牌定制袋/盒**，一般需要较大采购量和稳定门店网络。

**建议你直接问供应商这5个问题，能快速判断是否可做：**
- 最小起订量是多少（箱/袋/店/次）？
- 是否支持定制袋型、克重、把数、贴标或印刷？
- 定制包装是否额外收费，费用和打样周期多久？
- 配送频次和保鲜期能否匹配便利店（通常2–3天补货）？
- 是厂家直供还是经销商分装，责任归属谁？

**结论：**  
- 要**现成小包装**：都乐、洪九都可先问当地渠道，概率较高。  
- 要**便利店专属定制包装**：两家都不是公开标准服务，需按采购量谈；单店/小连锁通常难以直接定制，建议先找当地经销商做分装贴标，或找第三方包装厂做小批量定制袋+门店分装。
