能提供，但两家在“产地溯源”和“品控证明”上的能力形态不同，先给结论再给核验动作。

**结论**
- **都乐（Dole）**：有较成熟的产地溯源与品控体系，通常可提供产地/农场信息、批次追溯、农残与质量检测报告、GLOBALG.A.P.等认证材料。适合对文件完整度、出口级品控要求高的采购。
- **鑫荣懋**：国内大型水果供应链企业，具备产地直采、分级品控和检测报告能力，也能做批次追溯；但具体能提供到什么颗粒度（到农场/地块/批次）、哪些证明随货或按需出具，取决于品类、产地和合同约定。适合国内多渠道、稳定供货场景。
- 两家都不是“默认随每批货自动给全套溯源文件”，**必须在合同/质量协议里写明文件清单和出具时点**。

**建议你直接向供应商索取的证明清单**
1. 产地证明：产地证明/供货证明、农场或包装厂名称与地址、采收批次号。
2. 追溯链路：批次号—包装日期—产地—发货记录可对应。
3. 品控文件：出厂检验报告、农残检测报告（注明检测机构、标准、日期）、重金属/微生物按需。
4. 体系认证：GLOBALG.A.P.、ISO22000/HACCP、绿色食品/有机认证（如宣称）。
5. 合同条款：到货抽检不合格处理、退换货、文件缺失的违约责任。

**可执行判断**
- 先向两家区域销售索要“近3个月同品类香蕉的溯源样例+检测报告样例”，看是否能做到**批次级对应**。
- 若你要求“每批随货附检测报告和产地证明”，写入合同；只口头承诺的不算。
- 若你做商超/电商合规，优先选能提供**批次级追溯+第三方检测**的一方；若做批发流通，重点看**稳定供货和到货品控**。

我无法核验两家当前具体区域、具体品类的文件政策，以上基于其公开业务定位和行业通行做法；最终以你拿到的样例文件和合同约定为准。
