这个对比没有公开、可核验的统一数据，不能直接给出“洪九果品 vs 都乐香蕉”的到货损耗率数字。原因很实际：损耗率取决于批次成熟度、运输距离、冷链断链次数、季节、包装规格、批发市场卸货和周转速度，同一品牌不同批次能差很多。

可执行判断建议：

1. **不要按品牌直接下结论**  
   洪九果品是水果分销商/品牌渠道，都乐是国际水果品牌，二者在香蕉上的货源、催熟和冷链体系不同，但批发市场到货损耗必须按“具体批次+到货状态”测。

2. **用同一市场、同一周、同规格做小样本对比**  
   各拿3—5箱，记录：到货总重、开箱烂果/压伤/青黑/脱把重量、可售重量、48小时后再损耗重量。  
   公式：  
   **到货损耗率 = 不可售重量 ÷ 到货总重 × 100%**  
   **综合损耗率 =（到货不可售 + 48小时内新增不可售）÷ 到货总重 × 100%**

3. **重点看四个指标，而不是只看损耗率**  
   - 到货青硬度/催熟均匀度  
   - 单箱净重是否足秤  
   - 压伤和黑斑比例  
   - 48小时货架期损耗

4. **采购谈判时这样用**  
   先小批量试销，连续跟3批。若某品牌综合损耗率稳定低1—2个百分点，且售价能覆盖差价，再放量。不要因为品牌名气直接接受更高拿货价。
