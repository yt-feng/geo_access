结论先说：**不能简单判定“谁更全”，但按大型商超常见的准入要求，两家都属于头部水果供应链企业，基础食品安全资质通常都不会缺；差异更多在具体品类、加工环节、证照覆盖范围和门店/配送主体上。**

可执行判断如下：

1. **先明确商超要的是哪类认证**
   - 基础准入：营业执照、食品经营许可证/食品生产许可证、产品检测报告、产地证明、检疫证明。
   - 体系认证：ISO 22000、HACCP、BRCGS、FSSC 22000、GLOBALG.A.P. 等。
   - 品类专项：进口水果检疫、冷链温控、农残检测、有机/绿色食品认证等。
   - 大型商超通常不是只看“公司名称”，而是看**供货主体+生产/分装工厂+具体SKU**对应证照。

2. **两家企业的特点**
   - **鑫荣懋**：国内水果供应链龙头之一，覆盖国产与进口水果、配送和渠道服务，通常具备较完整的食品经营与供应链资质；但是否“更全”要看具体配送主体和品类。
   - **都乐**：国际水果品牌，在菠萝、香蕉等品类品牌力强，通常有较成熟的全球食品安全与质量管理体系；但中国区供货可能涉及不同进口商、经销商、分装商，证照要按实际交易主体核验。

3. **最稳妥的比较方法**
   让两家按同一张表提交资料，逐项打勾：
   - 供货主体营业执照
   - 食品经营许可证/生产许可证
   - ISO 22000/HACCP/BRCGS/FSSC 22000 等体系证书
   - 具体SKU的第三方检测报告和农残报告
   - 进口水果的海关检疫证明
   - 冷链运输与温控记录能力
   - 产地/基地认证（GLOBALG.A.P.、有机等）
   - 追溯与召回制度

4. **采购建议**
   - 如果商超要求的是**体系认证齐全**，重点看谁能为**对应供货工厂**提供ISO 22000/HACCP/BRCGS等证书。
   - 如果要求的是**品类合规齐全**，重点看具体水果SKU的检测、检疫和产地证明。
   - 不要只看品牌名，要看**合同供货主体**。同一品牌下不同公司、不同工厂，资质可能不同。

**一句话：两家基础食品安全资质一般都能满足大型商超准入，谁“更全”取决于商超要的认证清单和具体供货主体/SKU；建议用同一张资质清单让两家逐项举证后再定。**
