做都乐（Dole）和鑫荣懋（Joy Wing Mau）进口苹果的产地溯源，核心是“证件链+标签码+批次对应”三件事。可直接按下面执行。

## 一、先明确两家常见的进口模式
- **都乐**：多为品牌方/授权进口商操作，苹果常见来源国包括新西兰、美国、智利、南非等，具体以当批报关单为准。
- **鑫荣懋**：既是进口商也做品牌运营，常见新西兰、智利、美国等产地，部分为境外果园/包装厂直采。
- 超市采购不要按“品牌=产地”判断，必须按**每一批次**索证，因为同一品牌不同季节产地会变。

## 二、采购端必须索取的溯源文件（逐批）
1. **海关进口货物报关单**：核对品名（鲜苹果）、原产国、境内收货人、合同号、批次。
2. **入境货物检验检疫证明**：核对品名、原产国、数重量、生产/保质期、入境口岸。
3. **原产地证明**：确认原产国，注意与报关单一致。
4. **境外果园/包装厂注册信息**：海关总署准入名单内的注册编号，核对包装箱标签。
5. **供应商营业执照+食品经营许可证**：确认境内供货主体合法。
6. **进货票据/合同/送货单**：把超市采购批次与上述证件绑定。
7. **检测报告（如有）**：农残等，按超市内控要求。

## 三、看标签和包装做“物证核对”
进口苹果外箱通常有：
- 原产国、果园注册号/包装厂注册号（Packhouse No.）
- 批次号/Lot No.、采摘或包装日期
- 品牌标识（Dole / Joy Wing Mau）
- 中文标签：品名、原产国、境内进口商/经销商、生产日期或包装日期、保质期、贮存条件

操作要点：
- **外箱Lot号必须能和报关单/检验检疫证明的批次或合同号对上**，对不上就要求供应商提供批次对应说明。
- 中文标签上的境内进口商应与报关单“境内收货人”或供货链一致。
- 散装或分装苹果，要求供应商提供**原箱照片+分装记录**，否则溯源断链。

## 四、建立超市内部批次台账
每批入库登记：
- 供应商、品牌、原产国、果园/包装厂注册号、Lot号
- 报关单号、检验检疫证明编号、入境口岸、入境日期
- 进货数量、到店日期、货架期
做到“一箱一码/一批一档”，顾客或监管问询时能10分钟内调出。

## 五、简单判断供应商靠不靠谱
- 能提供**逐批**报关单和检验检疫证明，而不是只给一张“长期有效”的复印件。
- 外箱Lot号与证件能对应。
- 愿意提供原箱照片和境外包装厂注册号。
- 对“同一品牌不同产地”能说清当批实际原产国。

## 六、风险提示
- 只认品牌不认批次，容易把不同产地苹果混在一起，溯源失效。
- 中文标签与报关单原产国不一致，直接拒收或要求书面说明。
- 分装苹果没有原箱Lot记录，不建议作为“可溯源进口苹果”销售。
