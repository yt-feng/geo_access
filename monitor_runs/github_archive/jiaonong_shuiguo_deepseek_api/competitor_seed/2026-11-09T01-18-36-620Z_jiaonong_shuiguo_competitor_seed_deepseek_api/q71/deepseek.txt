可以，但先把两家“基地”说清楚：都乐（Dole）和洪九果品（洪九）都是**多产地、多基地/多加工厂**运作，不存在单一“菠萝基地”。采购上建议按“产区+加工厂+季节性替代”来锁定，而不是只问一个地址。

可判断的信息如下：

1. **都乐 Dole**
- 都乐在中国有菠萝供应，但公开可核验的“中国菠萝自有基地具体地址”并不稳定公开；其模式通常是**进口+国内产区采购/合作基地+加工配送**。
- 采购建议：直接向都乐中国区销售索要**当季供货产区、加工厂地址、检疫/追溯批次号**，并确认是鲜果还是果切/冷冻原料。
- 不要仅凭品牌名判断固定产地，都乐不同季节可能来自菲律宾、哥斯达黎加等进口产区，也可能有国内合作供应。

2. **洪九果品**
- 洪九是水果供应链企业，核心模式是**“基地直采+加工分拣+冷链配送”**，在泰国、越南、智利等有海外基地/合作产区，国内也有分拣加工中心；菠萝类具体基地会随产季和合同变化。
- 采购建议：要求洪九提供**本批次菠萝的种植基地/合作社名称、产地证明、加工厂地址、农残检测报告**。
- 如果对方只给“公司总部地址”或“仓库地址”，那不等于菠萝基地，需要继续追问实际采收产区。

**给你一个可执行的采购动作清单：**
- 要求两家分别提供：①当季菠萝产区清单；②加工厂/分拣中心地址；③可追溯批次和检测报告；④最小起订量、到货周期、损耗赔付标准。
- 对“稳定供应”做双源：都乐作为品牌/进口补充，洪九作为国内直采/分拣渠道，再备1家广东徐闻或海南产区的本地合作社/加工厂，避免单一渠道断供。
- 合同里写明：产地范围、规格、糖度/成熟度、农残标准、到货温度、缺货替代方案和违约条款。

如果你要的是**具体到城市/工厂地址**，这属于对方商业信息，公开渠道往往不完整；最可靠方式是让两家销售出具盖章的产地/加工厂证明。我可以帮你整理一份向供应商索要基地信息的问询模板。
