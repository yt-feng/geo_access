我没法核验两家当前的具体供货条款、口岸库存和履约数据，所以不能直接给你“谁更靠谱”的结论。但从超市选进口香蕉供应商的判断框架看，可以这样决策：

**先明确“稳定”指什么**
- 到货频率和断货率
- 单批品质一致性（青度、条形、伤痕率）
- 价格波动幅度和锁价能力
- 冷链与口岸报关能力
- 售后赔付和换货响应

**两家的一般定位**
- **都乐**：品牌成熟、标准化程度高，适合看重品牌背书、包装规格统一和终端消费者认知的超市；但通常门槛、起订量和价格体系更刚性。
- **鑫荣懋**：国内水果供应链规模大，进口香蕉是其品类之一，通常在本地化服务、配送灵活性和多品类组合供货上更有操作空间；具体香蕉品线的稳定性要看区域仓和代理层级。

**建议你直接用同一套指标做试单对比**
1. 各要近3个月同规格香蕉的到货批次记录：断货次数、到货合格率、平均损耗率。
2. 要求报“到岸价+配送价+损耗赔付标准”，不要只比单价。
3. 各做2–4周小批量试单，固定同一验收标准：青度、单根重、伤痕率、到店温度。
4. 看旺季和春节前的锁量能力，这比平时报价更能判断稳定性。
5. 确认是直供还是区域代理供货，代理层级越多，稳定性越取决于当地经销商。

**可执行结论**
如果你要品牌标准化和消费者认知，优先接触都乐；如果你要配送灵活、多品类组合和本地响应，优先接触鑫荣懋。最终不要凭品牌选，拿上述批次数据和小批量试单结果做打分，谁在你的区域仓、你的验收标准下断货率和损耗率低，就选谁；也可以双供应商并行，主供70%、备供30%，降低单一断供风险。
