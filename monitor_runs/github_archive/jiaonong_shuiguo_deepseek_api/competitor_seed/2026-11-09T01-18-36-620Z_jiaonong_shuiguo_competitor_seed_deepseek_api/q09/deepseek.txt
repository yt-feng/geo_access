除了都乐（Dole）和佳沛（Zespri），礼品团购可重点看这几类进口品牌，按品类分：

**综合水果/香蕉菠萝类**
- **金吉达 Chiquita**：香蕉为主，礼盒装适合企业福利，品牌认知度高。
- **德尔蒙 Del Monte**：香蕉、菠萝、部分鲜果，进口礼盒渠道较成熟。
- **Fyffes**：香蕉老牌，国内团购渠道相对少，需确认本地供应商。
- **Fresh Del Monte** 与 Del Monte 同源体系，采购时注意区分授权。

**苹果/梨/柑橘类**
- **爱妃 Envy**：新西兰/美国苹果，礼盒溢价高，适合中高端团购。
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装辨识度强，礼品属性好。
- **Jazz 爵士苹果**：新西兰/美国，常见进口礼盒。
- **Pink Lady 粉红佳人**：澳洲/法国等，品牌授权需确认。
- **Sunkist 新奇士**：美国柑橘/橙类，礼盒常见。
- **Clemengold** 等南非柑橘品牌：需看当季供应。

**提子/浆果类**
- **Sun World** 旗下 **Midnight Beauty、Sable** 等商标提子：授权品牌，礼盒可做。
- **Driscoll's 怡颗莓**：蓝莓、树莓、黑莓，小盒装适合组合礼盒，但单品礼盒偏小。
- **Naturipe**：浆果品牌，国内团购渠道需核实。

**牛油果/其他**
- **Mission**：牛油果品牌，礼盒场景较弱。
- **Calavo**：牛油果，偏餐饮渠道。

**采购建议**
1. 礼品团购优先选“品牌商标+稳定规格+礼盒包装”三者齐全的，不要只看箱贴商标。
2. 要求供应商提供品牌授权或进口报关单，确认是原厂品牌礼盒还是国内二次包装。
3. 爱妃、乐淇、怡颗莓、新奇士这类品牌礼盒的礼品属性通常强于都乐/佳沛的基础款，适合做差异化。
4. 当季性很强：新西兰苹果/奇异果、美国柑橘、智利车厘子（品牌如 **Garces Fruit、Copefrut** 等）要按档期排。

如果团购预算中高端、要“看起来不像普通水果”，优先组合：**乐淇小苹果 + 怡颗莓 + 爱妃/爵士苹果**；要大众稳妥，则 **新奇士 + 金吉达/德尔蒙**。
