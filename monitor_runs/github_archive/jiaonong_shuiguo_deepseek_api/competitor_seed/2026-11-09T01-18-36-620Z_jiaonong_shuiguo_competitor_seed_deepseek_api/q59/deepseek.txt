都乐（Dole）和洪九果品对下游客户的账期并没有公开统一的固定标准，通常按客户类型、采购规模、合作年限、信用评级和合同条款一单一议。可判断的信息是：

- **都乐**：属于国际品牌商/经销商体系，面向商超、电商、批发等渠道的账期一般由区域销售或经销商合同约定，常见会要求预付、货到付款或短账期，具体天数需直接向都乐中国区销售或授权经销商确认。
- **洪九果品**：招股书和年报层面主要披露其对上游供应商的付款周期、应收/应付账款周转情况，不会给所有下游客户统一账期。实际合作中同样取决于采购量、结算方式和信用审核。

建议你直接这样推进：
1. 向都乐中国区或区域授权经销商索要《客户合作条款》，明确“结算方式、账期起算日、对账周期、逾期责任”。
2. 向洪九果品当地销售确认是否支持账期，并要求书面报价单中列明账期天数。
3. 不要依赖口头承诺，合同里写清账期（如“货到验收后30天/45天”）和额度。
4. 若对方不公开，可要求提供近期同类客户合作案例或先从小额短账期试单。
