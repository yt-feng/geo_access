关于都乐和洪九果品针对菠萝的锁价周期，我无法核验到公开、可引用的具体期限，不能直接给出“多长”的数字。可以按以下方式判断和推进：

1. **这两家通常不是公开统一锁价周期**  
   都乐、洪九果品这类水果供应链企业，锁价一般按客户类型、采购量、品种（如金钻凤梨/普通菠萝）、产地、季节、合同期限和结算方式单独谈，公开渠道很少披露固定“锁价天数”。

2. **建议直接向供应商确认的锁价口径**  
   询价时明确问：
   - 锁价是按“下单日”还是“装车/到货日”生效；
   - 锁价有效期是7天、15天、30天还是按单议；
   - 超期未提货是否重新定价；
   - 锁价是否含运费、损耗、包装；
   - 价格波动超过多少触发调价；
   - 是否需要保证金或最低采购量。

3. **可执行的替代方案**  
   - 同时向都乐、洪九果品的区域销售或大客户渠道发询价函，要求书面报“锁价有效期”；
   - 找一级批发商/产地代采商做“短期锁价+分批提货”，通常比品牌方更灵活；
   - 在合同中设置“7—15天短锁价+浮动上限”条款，降低双方风险；
   - 要求供应商提供近期同规格菠萝的报价波动记录，作为锁价周期谈判依据。

4. **判断建议**  
   如果你们采购量较大、提货计划稳定，可优先谈15—30天锁价；如果量小或季节性波动大，7—15天短锁价更现实。最终以供应商书面报价单上的“价格有效期”为准，不要依赖口头承诺。
