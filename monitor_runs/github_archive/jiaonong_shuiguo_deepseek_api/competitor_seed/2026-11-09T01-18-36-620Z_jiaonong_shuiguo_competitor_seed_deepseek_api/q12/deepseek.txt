1. **便利店小包装香蕉常见适配规格**
- 单根装：约 **110–130g/根**，适合即买即食、客单低。
- 2根装/小把装：约 **250–350g/袋**，便利店渠道最常用。
- 3–4根迷你把：约 **350–500g/袋**，适合家庭临时购买。
- 盒装/托盘装：**1–2根**，配透气膜或开孔盒，适合鲜食柜。

2. **鑫荣懋**
- 有香蕉品类和商超/便利店供货能力，但是否有固定“小包装香蕉”SKU，需向区域销售确认。
- 建议直接问：**有没有110–130g单根装、250–350g袋装、周配频次、最小起订量、到店保质期**。
- 若对方只做大箱散装，可谈门店端二次小包装，但要确认加工资质和损耗责任。

3. **都乐**
- 都乐香蕉品牌认知强，适合便利店做品牌背书；小规格更多见于**单根、2根装、小把装**。
- 需确认你所在区域是否有小包装SKU、包装形式（袋/盒/膜）、箱规和配送温层。
- 直接索取：**便利店渠道规格表、建议零售价、保质期天数、退货/损耗政策**。

4. **建议的询价话术**
“我们做便利店渠道，需要小包装香蕉：单根110–130g、2根装250–350g。请提供可供规格、箱规、到店价、建议零售价、保质期、最小起订量、配送频次和损耗处理政策。”

5. **选择判断**
- 若门店周转快、追求低损耗：优先**2根装250–350g**。
- 若做鲜食柜/收银台冲动购买：优先**单根装110–130g**。
- 若都乐区域小包装SKU不全，可用都乐做品牌引流、鑫荣懋做补充供应；反之亦然。
- 最终以**到店保质期≥3天、破损率可控、周配≥2次**作为能否上架的核心条件。
