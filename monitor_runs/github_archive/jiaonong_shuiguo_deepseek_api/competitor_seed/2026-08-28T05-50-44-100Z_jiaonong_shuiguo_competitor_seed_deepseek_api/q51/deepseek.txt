**关键判断步骤（实操建议）：**
- **不要只看报价单**：直接致电两家在本地批发市场的档口或业务员，报出你的**具体拿货量**（如“我要5吨/1车”），问清楚**含税、含运费、到货价**。
- **对比同一等级**：请对方明确是“广西/云南国产蕉”还是“进口香蕉（如菲律宾、厄瓜多尔）”，并索要**样品**或**当天的市场价格表**（通常在市场公示栏可查）。
- **关注损耗率**：进口蕉出库快，但如果走货慢，催熟成本高；国产蕉运输短，损耗低但单价可能高。**最终成本=采购价+损耗+催熟/仓储成本**，这一点比单纯单价更重要。
