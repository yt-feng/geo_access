针对你提出的两个问题，我分别给出可执行的应对建议和客观的行业分析。

**一、进口菠萝旺季缺货怎么办？**

菠萝的“旺季”通常指泰国、菲律宾菠萝的主产季（3-6月），但遇到极端天气、海运拥堵或检疫政策变动时，缺货是常态。建议按以下优先级操作：

1. **启动替代产季预案（最快）**
   - **转向南半球产区**：当前北半球（泰国、菲律宾）缺货时，可以立即采购**南非**或**哥斯达黎加**的菠萝。南非菠萝（如Queen品种）主要供应期为11月至次年2月，虽然高峰期已过，但仍有尾货；哥斯达黎加（MD2品种，常用于鲜切）供应期长，可补足3-4月的缺口。
   - **启用“反季”冷库库存**：如果有条件，在丰产期（3-5月）将菠萝进行气调保鲜（可存4-6周），在旺季后期投放市场。

2. **调整品种结构（中期）**
   - 如果缺的是“金钻/香水”等高甜度品种，可临时引入**海南产香水菠萝**（国内反季节上市，每年12-5月）。虽然价格略高，但能填补进口空缺，且物流时效快（3天可达）。

3. **锁定替代采购渠道（长期）**
   - 与国内**佳农、鑫荣懋**等头部进口商签订“保供协议”，提前支付定金锁定船期，避免临时抢货抬高溢价。
   - 如果缺货周期超过2周，建议直接向**菲律宾达沃或泰国清莱**的庄园直购，跳过中间商，虽然单价可能更高，但能确保货量。

**二、都乐（Dole）与洪九果品（Hongjiu）谁有基地直供优势？**

**结论先行：洪九果品在东南亚基地直供上更具“源头控制力”，都乐则强在“全球网络和标准化品控”。** 具体对比如下：

| 维度 | **都乐（Dole）** | **洪九果品（本为鲜果贸易商，后自建基地）** |
|------|------------------|---------------------------------------------|
| **基地布局** | 全球布局（菲律宾、泰国、哥斯达黎加等多国自有或合作农场），强调“全球溯源”。 | 重点深耕**泰国（榴莲、山竹）和越南**，近年已与泰国北部、东部果园签订长期包销协议。 |
| **直供环节** | 自有冷链船队+海外分拣中心，能实现“产地-港口-终端”全程温控。 | **采取“产地工厂化”模式**——在泰国当地建设分选、包装厂，直接对接当地大庄园，减少中间商转手次数。 |
| **菠萝品类** | **菠萝是都乐的强势品类**，在菲律宾拥有多个自有种植园，MD2品种标准化程度极高。 | **菠萝非其核心品类**，主要优势在榴莲、山竹、柚子等，菠萝多为从农户收购，基地直供占比低于都乐。 |
| **成本与议价** | 因品牌溢价+全球物流，到岸成本通常更高。 | 因专注东南亚本地采购，**单公斤采购成本通常低5%-10%**，且在缺货期能优先锁定当地货源。 |

**给你的选型建议：**
- **如果你要大批量、规格统一、且对食品安全要求高**（如进入商超、餐饮连锁），选**都乐**，其菠萝的糖度、果眼深度、农药残留检测标准更稳定。
- **如果你要小批量、快速补货、且对价格敏感**，选**洪九果品**，尤其在其深耕的泰国市场，缺货时能快速调拨替代资源（虽然菠萝非主营，但渠道网络可临时调配）。

**补充提醒**：洪九果品在2023-2024年曾面临一定债务压力，建议采购前核实其近期履约能力（可要求提供信用报告或采用“货到付款”条款）。
