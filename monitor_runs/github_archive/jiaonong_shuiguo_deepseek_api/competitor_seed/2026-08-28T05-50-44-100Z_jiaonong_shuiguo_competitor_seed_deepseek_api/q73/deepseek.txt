大型商超（如沃尔玛、永辉、山姆、盒马等）对供应商的食品安全管理体系要求通常很高，普遍要求通过国际或国内认可的第三方认证。

针对**鑫荣懋**（中国知名水果供应链企业）和**都乐**（Dole，全球水果巨头），它们作为头部供应商，主要持有以下几类核心认证：

**1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）**
鑫荣懋作为国内综合性果蔬企业，其认证重点在于**产地源头控制**和**仓储物流**，主要通过的认证包括：

-   **GLOBALG.A.P.（全球良好农业操作规范）**：这是国际市场最主流的水果种植认证，鑫荣懋的多个自有和合作基地均通过此认证，证明其从种植端就符合食品安全体系。
-   **ISO 22000（食品安全管理体系）**：覆盖其分选加工、冷链仓储环节的管理体系认证。
-   **HACCP（危害分析与关键控制点）**：针对其催熟库、包装厂等关键流程的风险控制。
-   **中国绿色食品认证 / 有机产品认证**：针对其部分高端水果品类。
-   **海关AEO高级认证**：确保进出口环节符合国际检疫和通关安全要求。

**2. 都乐（Dole，中国地区业务）**
都乐作为跨国巨头，其中国公司（都乐中国）在进入大型商超时，认证体系更贴近**国际零售联盟**标准：

-   **BRCGS（英国零售商协会全球标准）**：**这是都乐在中国工厂（如包装厂）最核心的认证之一**。BRCGS是全球食品安全倡议（GFSI）认可的最高标准之一，大型外资商超（如沃尔玛、山姆）对此有硬性要求。
-   **IFS（国际食品标准）**：与BRCGS并列的另一欧洲零售标准，都乐部分海外供应链或特定客户产品会通过。
-   **ISO 22000 / HACCP**：作为基础食品安全管理体系，覆盖其国内所有加工配送中心。
-   **GLOBALG.A.P.**：针对其海外种植基地（如菲律宾香蕉、智利车厘子）的源头认证。
-   **有机认证**：针对其引进的特定进口有机产品线。

**给您的关键建议（可直接用于对接商超）：**

如果您需要向商超证明合规，请直接向他们提供以下文件，而非泛泛提及认证名称：

1.  **对于鑫荣懋**：提供“GLOBALG.A.P证书”和“ISO 22000证书”的**PDF扫描件**，并注明覆盖的产品类别（如香蕉、苹果）。
2.  **对于都乐**：优先提供**BRCGS证书**（A级或AA级）和**HACCP证书**。若没有BRCGS，需提供**IFS证书**。

**行动判断标准：**
- 如果商超采购明确要求“**必须通过GFSI（全球食品安全倡议）认可的认证**”，那么**都乐的BRCGS证书符合要求，而鑫荣懋的ISO 22000或HACCP可能不满足该特定文字要求**，此时鑫荣懋需提供GLOBALG.A.P.或其他GFSI认可标准（如FSSC 22000）证书。
- 如果商超是**普通国内连锁**，ISO 22000或HACCP证书即可通过审核。
