关于水果连锁店香蕉分级标准，**都乐（Dole）和洪九果品是否有公开的企业标准**，目前没有官方公开的、对外发布的全文本文件。不过，这两家公司在行业内确实有内部执行的分级体系，且其标准通常基于国家/行业通用分级规则（如GB/T 12953香蕉或NY/T 2610等），并叠加了采购商自定指标。

**具体情况说明：**

1. **都乐（Dole）**：作为全球知名果蔬品牌，其香蕉分级通常按**长度、粗度、成熟度（即色板等级）、疤痕面积**等细分，例如分为“特级、一级、二级”或商业上的“果王/大把/小把”。但该标准是内部采购文档，**不对外公开**，仅向合作供应商提供。在零售端，消费者看到的“都乐香蕉”标签多为品牌背书，不写分级代码。

2. **洪九果品**：作为面向B端（大型商超、连锁店）的进口水果企业，其香蕉分级标准更多是**按客户需求定制**，结合了产地（如菲律宾、越南）的出口标准及中国市场的消费习惯。其内部有“一二级果”“大中小果”等分档，但同样**未公开发布**可下载的文本。

**给你的实操建议：**

- **如果你是连锁店采购方**，建议直接联系都乐或洪九的销售/品控部门，索取其**《收货验收标准》**或**《香蕉品质要求》**样本（通常商务谈判时可提供）。注意索要时明确问：“贵司对香蕉长度、围度、成熟度色卡（如泽西8号色卡）、损伤容忍度的分级阈值是什么？”

- **如果需自行制定标准**，可参考行业通行做法：
  - **长度**：大果（≥19cm）、中果（15-19cm）、小果（≤15cm）
  - **围度（周长）**：标准果（≥16cm）、中小果（13-16cm）
  - **成熟度**：按“色卡1-8”分级，连锁货架期一般要求3-5级（绿转黄）
  - **瑕疵容忍**：机械伤、黑斑、软腐面积不得超过果表面积的2%-5%（视等级而定）

**重要提示**：这些阈值需结合你的目标客群和陈列成本来设定，**不要直接照搬欧美标准**，因为国内消费者偏好更绿、更耐存储的香蕉。
