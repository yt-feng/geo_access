关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商的食品安全资质，虽然我无法直接调取它们当前最新的证书原件，但根据行业惯例和公开信息，它们通常持有以下核心认证，这些资质是大型商超（如沃尔玛、山姆、永辉、盒马等）的基本准入门槛：

**1. 质量管理体系认证（基础门槛）**

-   **ISO 9001**：质量管理体系认证，确保流程标准化。
-   **ISO 22000**：食品安全管理体系认证，这是国际通用的食品链安全标准。
-   **HACCP**：危害分析与关键控制点认证，针对生产过程中的风险控制。

**2. 国际零售行业专用认证（商超硬性要求）**

-   **BRCGS（原BRC）**：英国零售商协会全球标准，是全球顶级零售商（如Tesco、Sainsbury's）认可的食品安全标准。
-   **IFS Food**：国际食品标准，在欧洲市场较为通行，与BRC类似。

**3. 良好农业规范（源头控制）**

-   **GLOBALG.A.P.**：全球良好农业操作规范，证明其种植、采收环节符合国际标准。
-   **中国GAP**：中国良好农业规范，国内商超通常认可此证书。

**4. 特定项目与可持续认证**

-   **有机认证**：针对特定有机产品线（如有机香蕉、有机蓝莓）。
-   **GRASP**：社会责任模块（常与GLOBALG.A.P.一起审核）。
-   **Sedex/SMETA**：商业道德审计，部分高端商超会要求。

---

**关于这两家公司的具体特点：**

-   **都乐（Dole）**：作为国际巨头，其资质通常非常齐全，且常持有**雨林联盟认证**（Rainforest Alliance）和**碳中和**相关认证，在海外进口水果方面，其出口国（如菲律宾、智利）官方检疫证书和农药残留检测报告也极为完善。
-   **鑫荣懋**：作为国内龙头，除了上述国际认证外，它还特别强调**果蔬产品质量安全追溯体系**，通常会提供**农药残留快速检测报告**（每批次），并且是中国农业部“绿色食品”认证的积极推动者。

**给您最实操的建议（如何核实）：**

由于这些证书有有效期且需年审，**在正式合作前，请务必直接向供应商索取以下两份文件**：

1.  **有效期内的认证证书复印件**（需加盖公章）。
2.  **最近一批次的第三方检测报告**（如SGS、华测、谱尼等出具）。

您也可以要求供应商通过**“全国认证认可信息公共服务平台”**（认监委官网）提供证书编号，您自行查询真伪，这是最稳妥的方式。不要轻信口头承诺，以纸质盖章文件为准。
