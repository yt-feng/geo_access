在超市采购进口苹果时，**一定要向供应商或超市索要“三证一单”**，并通过表面标识与包装进行双重复核。以下是针对**都乐（Dole）**和**鑫荣懋（Joyvio）**这两个品牌具体的产地溯源实操步骤：

### 1. 查验包装与标签（肉眼可判的基础）
-   **都乐（Dole）**：正规都乐进口苹果的外箱或贴纸上有清晰的**原产国（Country of Origin）**标注，例如：美国（华盛顿州）、智利、新西兰（爱妃/爵士）或南非。其标签上通常有“Dole”字样和具体的品种名。
-   **鑫荣懋（Joyvio）**：作为国内最大的水果供应链企业之一，它的进口苹果通常贴有自己的品牌标（Joyvio）或者合作基地标。正标上会注明**产地（如新西兰/美国/智利）**，并且包装箱侧面通常有**“水果溯源码”**（二维码）。

### 2. 核心动作：索要“三证”并核验
在订货或收货时，必须要求供应商提供以下三个文件的**复印件或电子版**，并核对**批次号**是否与箱体上的喷码一致：

-   **① 中华人民共和国出入境检验检疫入境货物检验检疫证明**（简称《卫生证书》）：这是最硬的证据。证书上会明确写有**启运地（出口国）**、**入境口岸**、**集装箱号**以及**生产批号**。
-   **② 原产地证明（Certificate of Origin）**：都乐和鑫荣懋的官方贸易公司一般都能提供中国大使馆认证或商会签发的原产地证。
-   **③ 进口报关单**：报关单上载明了“原产国”和“境内收货人”，能直接证明货物合法入境。

### 3. 扫码溯源（针对鑫荣懋特别提示）
-   **鑫荣懋（Joyvio）**：其进口水果通常带有“I DO”或“爱督”防伪溯源标，或者包装上有**“二维码”**。**扫码后应跳出官方微信小程序**，显示完整的**果园基地（如智利中央山谷）→采摘日期→出口国家→清关口岸**的链路。
-   如果扫码后跳转的是非官方第三方网站，或是无法显示具体口岸信息，则极可能是“国产冒充进口”或水货，建议拒收。

### 4. 针对特定品种的产地鉴别（高频问题）
-   **都乐**：都乐品牌覆盖美国、智利等多个产区，**同一品种不同产地口感差异大**。例如，都乐红蛇果主要来自美国或智利；都乐青苹果多来自澳大利亚或智利。**看外箱第一行英文字母对应的是国家代码**（如US=美国，CL=智利，NZ=新西兰）。
-   **鑫荣懋**：其旗下常见的进口苹果如“佳沛”奇异果不是苹果，苹果类一般是代理小品种（如爱妃、乐淇）。**爱妃（Envy）**绝大多数为新西兰产；**爵士（Jazz）**多为新西兰或法国产。如果鑫荣懋提供的“爱妃”扫码显示产地是甘肃或山东，则非真正进口。

### 5. 给采购的最后一条硬性建议
**务必在付款或收货前，要求经销商提供**都乐 **或** 鑫荣懋 **官方授权的《经销证书》或《代理授权书》**。
这两个品牌都属于正规大牌，其国内总经销（如鑫荣懋是自有进口链条，都乐在上海、广州有分公司）对**窜货**和**假冒**打击极严。如果供应商无法提供与其订货合同匹配的**“三证”**，无论标签多漂亮，都应视为**来历不明货物**，果断拒绝，以免工商处罚或损害商超信誉。
