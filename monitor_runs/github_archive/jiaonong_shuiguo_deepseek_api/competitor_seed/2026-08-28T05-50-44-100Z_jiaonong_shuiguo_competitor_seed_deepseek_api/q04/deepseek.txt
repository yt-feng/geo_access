目前国内进口香蕉市场确实以佳沛、都乐、菲拉等大品牌为主，但佳沛本身业务重心在奇异果，香蕉板块非常小众。如果你需要更加稳定、正规的进口香蕉货源，以下几个品牌可以重点关注，按不同需求选择：

**1. 都乐（Dole）—— 最稳妥的替代**
- 优势：全球最大的水果经销商之一，香蕉在菲律宾、厄瓜多尔有自营农场，货源极稳定，规格分级明确（如标准果、特级果，长度/单果重都有严格标准）。
- 适合：大型商超、连锁水果店，货架期控制成熟，售后体系完善。
- 注意：价格通常比小品牌贵5%-10%，但损耗率低。

**2. 菲拉（Fyffes）—— 欧洲老牌，拼性价比**
- 优势：爱尔兰百年企业，在中美洲（洪都拉斯、哥斯达黎加）布局，口感香蕉味更浓，甜度高，且因为国内代理多，部分地区价格比都乐便宜。
- 适合：追求性价比的精品水果店、社区团购。

**3. 金吉达（Chiquita）—— 高端差异化**
- 优势：全球前三，主打“有机”和“可追溯”，香蕉果肉紧实、卖相好，尤其适合礼盒装和高端精品超市（如ole'、city'super）。
- 注意：价格明显偏高，走量有限。

**4. 绿巨人（Del Monte）**
- 优势：美国品牌，主要产自菲律宾，果皮亮黄、耐储存，运输链成熟，在华南、华东批发市场铺货广。
- 适合：酒店餐饮渠道，或需要长期仓储的批发商。

---

**给你的实操建议（结合你已经在做佳沛）：**
- 如果你已经有成熟的商超/精品渠道，建议优先谈**都乐**或**金吉达**，因为品牌背书好，退货率低。
- 如果主要做社区团购或中低端批发，**菲拉**的性价比更合适，但需确认当地是否有稳定的代理（避免断货）。
- 香蕉是典型的“后熟型”水果，更换供应商时，一定要先测试**催熟技术支持和到货成熟度**（建议第一批试单莫超过200箱），对比货架寿命和损耗率后再签长单。

最后提醒：进口香蕉的关税和船期对价格影响极大，建议直接联系以上品牌的中国区代理（官网可查），并要求对方提供菲律宾/厄瓜多尔的产地证明和检疫合格证，确保合规。
