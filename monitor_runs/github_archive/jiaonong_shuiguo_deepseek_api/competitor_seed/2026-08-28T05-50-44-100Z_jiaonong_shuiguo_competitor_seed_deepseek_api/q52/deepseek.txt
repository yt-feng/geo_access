关于您询问的都乐（Dole）与鑫荣懋（Golden Wing Mau）菠萝在茶饮原料采购中的到货损耗率，这是一个高度依赖于**具体批次、物流条件、仓储周期以及您所在区域**的动态数据。

**直接结论：** 目前没有任何公开、标准的固定损耗率可供参考。采购方通常是通过**实际试单**来获取本企业的真实损耗数据。不过，基于行业经验和品牌特性，可以给您以下参考和建议：

**1. 行业经验参考值（非官方标准）**
- **都乐（Dole）**：其菠萝多为进口（如菲律宾、哥斯达黎加等），通常采用**标准化分拣与冷链运输**。在正常冷链（7-10℃）且收货后**24小时内**处理的前提下，**表皮机械伤**（如擦伤、压痕）的到货损耗率通常在 **3% - 5%** 左右；若涉及**内部褐变**（需切开验证），损耗可能上升至 **5% - 8%**。
- **鑫荣懋（Golden Wing Mau）**：作为国内头部水果供应链企业，其菠萝（常涉及国产海南、广东或进口）在分选环节通常执行较严的出厂标准。但由于其运输半径可能小于进口菠萝，**常温物流**占比稍高时，损耗率可能在 **5% - 8%** 之间；若采用**全程冷链**，则与都乐相近。

**注意**：以上仅为经验性估算，**不代表任何官方承诺**。实际数值受物流时长影响极大，例如超过48小时未开箱检查，损耗会显著上升。

**2. 采购实操建议（重点）**
由于您是茶饮原料采购，对菠萝的**熟度、糖度、纤维感**要求较高，建议您按以下步骤操作以获取*真实*损耗数据：

- **签订“到货损耗条款”**：在采购合同中明确约定“规格标准”（如单果重、果型、外观瑕疵允许比例）以及“超损扣款”机制。例如约定“到货24小时内发现腐坏率超过5%，超出部分由供方承担”。
- **执行小批量试单**：首次采购**仅采购1-2箱**，要求供应商提供检测报告（如糖度、酸度）。到货后**开箱全检**，记录：A. 表皮破损数；B. 切开后内部褐变比例；C. 过熟软果比例。
- **关注“到店后”损耗**：茶饮店常用菠萝是**鲜果切配**，若到货后需冷藏存放超过2天，需将“到货损耗率”与“门店存储期内损耗率”分开统计。例如：到货损耗3%，但存储3天后可能升至10%。

**3. 如何获取更精确数据**
- 直接向**供应商区域销售经理**索要“近3个月该品类在您所在城市的综合损耗率”参考值（部分大型供应商有内部统计）。
- 查看供应商的**出厂质检报告**，通常会有“瑕疵果比例”指标（如外观缺陷≤5%），这比到货损耗率更接近实际。
