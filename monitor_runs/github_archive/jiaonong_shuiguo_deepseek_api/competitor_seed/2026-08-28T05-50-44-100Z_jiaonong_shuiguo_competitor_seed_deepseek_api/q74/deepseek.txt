关于**都乐（Dole）**和**洪九果品**的水果礼盒定制起订量，由于两家都是大型供应链企业，**起订量通常没有公开的统一标准**，而是根据**季节、定制款式（包装/贴标/混装）、采购预算、淡旺季**动态调整。

不过，根据行业惯例和公开信息，可以给你以下参考判断：

**1. 都乐（Dole）**
- **性质**：国际品牌，主做香蕉、菠萝、牛油果等单品。
- **起订量参考**：
  - 如果是**纯水果散装（贴标/混装）**，一般最低**1-2吨**（或约100-200箱）起。
  - 如果是**礼盒装（含定制纸箱/手提袋）**，通常最低**500盒-1000盒**起，因为涉及开机印刷和包材成本。
  - 若仅做**简易腰封/贴纸**（不换外箱），起订量可降至**200-300盒**。
- **建议**：直接联系当地都乐经销商或大客户部，报出你的目标采购量（比如“300盒，混装苹果和香蕉”），对方会给出可行方案。

**2. 洪九果品**
- **性质**：国内头部进口水果供应链（榴莲、车厘子、山竹等）。
- **起订量参考**：
  - **散货批发**：通常**1柜（约20-25吨）**起订（针对生鲜大宗）。
  - **礼盒定制**：内部有“B端团购柔性定制”业务，**常见起订量为 100-300 盒**（针对定制礼盒，可指定水果组合和包装）。
  - 如果预算不足，可谈“**拼单定制**”——即洪九帮你在当地找其他企业拼一个柜，但周期较长。
- **建议**：在其官方小程序或联系区域大客户经理时，直接报出“**礼盒需求500盒，车厘子+蓝莓组合，需印刷logo**”，对方会给精确报价和起订线。
