关于菠萝供应商的锁价机制，**都乐（Dole）** 和**洪九果品**作为大型生鲜企业，具体锁价周期通常**没有固定统一标准**，而是根据采购规模、菠萝产地（如菲律宾、泰国、中国海南/湛江）、季节供应量及合同谈判结果动态制定。

不过根据行业惯例及企业对外披露的采购政策，可以给您以下参考：

1. **都乐（Dole）**：
   - 作为全球性品牌，其大宗采购（如为连锁商超或餐饮B端供货）通常提供 **月度锁价** 或 **季度锁价**。若采购量极大（如整柜/整船），可协商按 **单次订单锁价**（即合同时效内价格固定）。
   - 对于短期供货，一般为 **7-15天** 的短期锁价，以避免市场价格波动风险；长期锁价（如半年）需满足严格的批次验收标准，且通常伴随“浮动调价条款”（如产地天气导致减产时可能触发价格上浮）。

2. **洪九果品**：
   - 该公司主打“端到端”供应链，对核心客户（如大型商超、电商平台）常采用 **月结锁价** 模式，即月初确定本月采购价，期间不受市场波动影响。
   - 对新客户或零散订单，一般 **3-7天** 内有效，锁价周期较短，但可通过预付定金或签框架协议延长至 **1-3个月**。

**建议您直接与供应商官方联系确认**，因为：
- 以上周期基于行业惯例推测，并非官方承诺。
- 实际执行中，锁价周期受台风季（菠萝主产国如菲律宾6-10月降雨多）、国际海运成本、人民币汇率影响极大，供应商可能临时调整。
- 若您有具体采购量（如每月多少吨），可要求双方签订“价格保护协议”，明确锁定期及违约责任。

**行动建议**：
- 准备一份《菠萝采购询价单》，注明月均需求量、质量标准（如糖度、果重）、包装要求，分别发送至两家公司的B2B业务邮箱。
- 询问时直接提出：“针对2000吨/年的固定采购，能否提供季度锁价？除价格外，供应中断的赔偿条款如何约定？”
