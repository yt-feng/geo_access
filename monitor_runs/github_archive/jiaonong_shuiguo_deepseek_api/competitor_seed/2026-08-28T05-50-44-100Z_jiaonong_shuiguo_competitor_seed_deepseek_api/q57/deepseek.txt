关于“洪九果品”和“都乐”是否对下沉市场夫妻店提供小批量供货，目前没有公开的、权威的统一答复，但可以给你明确的判断和操作建议：

**1. 洪九果品：**
- **大概率不出小批量散货。** 洪九果品（股票代码：06689.HK）定位是“水果供应链第一股”，主营进口水果和高端国产水果的**大宗批发**，客户主要是大型商超、电商平台（如盒马、永辉）和二三级批发商，单批次出货量通常以“柜”或“吨”为单位。
- **建议你从当地批发市场拿货。** 洪九的货会流入当地一级或二级水果批发市场（如广州江南市场、北京新发地），夫妻店可以直接去这些市场的档口拿货，按筐/按箱买，价格比总代低，还能挑货。

**2. 都乐（Dole）：**
- **官方不直接对个人夫妻店供货。** 都乐在中国的主要渠道是大型商超、便利店连锁（如7-11、全家）和餐饮B端，不设“小额直供”业务。
- **你拿到都乐的货，通常通过经销商或批发市场。** 比如在上海辉展、广州江南等大型批发市场，有都乐授权的经销商档口，可以按箱批发（通常一箱起卖，比如一箱香蕉约13公斤、一箱凤梨约5头）。如果量少（如只买2-3箱），部分经销商愿意零售卖，但价格会高于整批价。

**实操建议（针对你的具体场景）：**
- **别直接找品牌方，找当地“二级经销商”或“水果市场档口”。** 打开高德地图搜你所在城市的“水果批发市场”，直接去市场问“有没有洪九/都乐的货”，档口老板会给你最小起订量（通常一箱起）。
- **如果乡镇没有大市场，可以依赖“B2B生鲜平台”。** 像美菜网、快驴进货、多多买菜（部分区域）有水果供应链，通常能按箱供货，虽然不是品牌直供，但能拿到接近批发的价格。
- **明确你的量级：** 如果你每次进货在500元以下，建议直接去本地菜市场或水果店串货；如果每次能进2000元以上，可以去批发市场谈“长期混批”优惠。

**一句话总结：** 这两个品牌都不做“夫妻店小批量直供”，但他们的货都在批发市场流通，你只要找到本地一级/二级批发市场，按“一箱”起订即可，别白跑官网和客服电话。
