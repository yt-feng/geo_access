可以要求两家提供，但是否“现成可给”取决于你拿货的品类、批次和渠道，不能一概而论。建议按下面判断和操作：

**1. 都乐（Dole）**
- 通常能提供：都乐鲜菠萝/菠萝制品一般有较规范的质量体系，商超/餐饮渠道常可申请到批次对应的检测报告或第三方农残检测报告。
- 注意：报告通常“按批次/按规格”出具，不是一张报告长期通用；鲜果和冷冻/罐头菠萝报告口径不同。
- 你应明确要：**GB 2763 农残项目、对应批次号、第三方CMA/CNAS报告、收货日期匹配**。

**2. 鑫荣懋**
- 通常也能提供：鑫荣懋是大型水果供应链企业，餐饮/茶饮客户较多，一般可提供供应商检测报告或第三方检测报告。
- 注意：其鲜果多为多产地采购，报告要落实到**具体产地、具体批次、具体供应商**；不同产区报告可能不同。

**3. 采购时直接这样问（可复制）**
> 我方采购菠萝用于茶饮原料，请提供本批次菠萝的农残检测报告：要求第三方CMA/CNAS资质、检测项目覆盖GB 2763中菠萝相关农残指标、报告批次号与我方到货批次一致。若为鲜果请提供产地和采摘/包装日期；若为冷冻/罐头请提供对应生产批号报告。

**4. 判断标准**
- 能提供“批次对应第三方农残报告”= 可用；
- 只给“型式检验报告/年度报告/厂家自检”= 需补第三方批次报告；
- 报告项目不全或批次对不上 = 不建议直接作为茶饮店合规依据。

**结论：** 都乐和鑫荣懋一般都有能力提供，但你要在合同/订单里明确“随货提供本批次第三方农残检测报告”，否则对方可能只给通用报告。建议先向对接业务员索取一份近期报告样本，确认检测项目和批次口径后再下单。
