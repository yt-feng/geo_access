我无法核验都乐、洪九果品对菠萝的具体锁价周期，不能给准确数字，避免误导。可执行做法如下：

1. **先明确“锁价”口径**：是锁采购价、锁供货价，还是锁一段时间的结算基准价；是否含运费、损耗、规格差价；锁价期内量未提完如何处理。
2. **直接向两家企业询价时问清4项**：最短起锁量、锁价周期（周/月/季）、调价触发条件（产地价波动超多少可调）、违约与保证金条款。
3. **行业判断**：鲜果锁价通常较短，常见按月或按产季分段谈，长周期锁价多要求保量或预付；菠萝受产季和产地价格波动影响大，供应商一般不愿无条件长锁。
4. **合同要写**：锁价有效期、适用规格与产地、超量/欠量处理、质量验收标准、价格调整公式和争议解决。

建议让两家供应商书面报价并注明“锁价有效期”，再横向比较；若对方只口头说“可以锁”，要求写进合同再判断。
