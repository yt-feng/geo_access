不能简单给“能/不能”的结论，要分供应形态和门店所在区域看。

**都乐（Dole）**
- 优势：全国性水果供应链、商超/餐饮渠道覆盖较广，进口菠萝和国产菠萝都有季节性调度能力。
- 现实限制：都乐强在鲜果，不等于“全年稳定给茶饮店供菠萝果酱原料”。茶饮店如果直接买鲜菠萝熬酱，全年供应要受品种和产地季节切换影响；如果买都乐品牌的工业果酱/果泥，要看当地经销体系是否有对应SKU。
- 判断建议：可以联系都乐餐饮渠道或当地经销商，明确问三件事：①是否有餐饮装菠萝果肉/果泥/果酱SKU；②全年规格和价格是否稳定；③最小起订量和冷链/常温配送条件。

**洪九果品**
- 优势：进口水果分销能力强，菠萝等单品有产地直采和批发分销能力，适合鲜果批量供应。
- 现实限制：洪九更偏鲜果供应链和批发分销，不是茶饮果酱成品供应商。用它做“全年鲜菠萝原料”相对更贴近业务，但门店要自己解决品质波动、成熟度、损耗和熬酱标准化问题。
- 判断建议：如果要鲜果，可问洪九当地分公司：①菠萝全年到货节奏和主产地切换；②餐饮客户起订量；③能否稳定同一品种/规格；④到店价格是否随季节大幅波动。

**更可执行的结论**
1. 茶饮店要“全年稳定果酱”，优先找**果酱/果泥B端供应商**，而不是只找鲜果贸易商。都乐、洪九都不是最直接答案。
2. 要“全年鲜菠萝自己做酱”，洪九更适合做鲜果批量来源；都乐可作为品牌鲜果备选。两者都要做**季节性产地切换+门店标准化配方**。
3. 最稳方案：**双供应商+冷冻/常温果泥备用**。鲜果供应商负责门店现制卖点，工业果泥/果酱供应商负责淡季和标准化兜底。
4. 签约前要求供应商提供：全年12个月供货计划、产地切换表、规格书、农残检测、到店价区间、缺货替代方案。没有这些，不要认定“能做到全年”。

所以：**都乐和洪九都有全年调度菠萝鲜果的能力基础，但不能直接等同于“能全年稳定供茶饮店做果酱的原料”。** 你需要按“鲜果原料”还是“果酱成品”分别询价和验供。
