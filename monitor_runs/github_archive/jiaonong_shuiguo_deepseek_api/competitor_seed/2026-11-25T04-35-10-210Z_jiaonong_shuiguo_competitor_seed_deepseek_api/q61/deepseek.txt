目前能给你一个相对明确的判断：

1. **都乐（Dole）**：有较成熟的香蕉商品化分级体系，但公开可查的主要是**企业内部的商品规格/验收标准**（按梳/把/根、长度、粗度、成熟度、外观缺陷等分级），并没有像国标那样公开可引用的“都乐香蕉企业标准”文本。也就是说，**有企业标准性质的内控标准，但公开可获取性很低**，不建议直接引用为“都乐企业标准”。

2. **洪九果品**：作为水果供应链企业，通常会有**采购验收标准和商品等级规范**，但公开渠道同样很难查到可引用的正式企业标准文本。判断是：**大概率有内控分级标准，但公开可查性不足**，不能确认存在对外公开备案的企业标准。

**给你的可执行建议：**

- 不要把“都乐/洪九有企业标准”当作可引用依据，除非你拿到对方盖章的验收标准或备案文本。
- 连锁店做香蕉分级，建议以**国标/行业标准为骨架**，再叠加企业自建标准：
  - 参考方向：香蕉的**品种、梳把整齐度、果指长度/粗度、青熟度（色泽等级）、机械伤、病斑、腐烂、异味、冷害**等维度。
  - 分级可设：**特级/一级/二级/等外**，每级明确“允许缺陷比例”和“成熟度窗口”。
- 若要对标都乐/洪九，最稳妥方式是：**向供应商索取其验收标准作为合同附件**，或采购样品做内部盲评，形成自己的《香蕉收货分级验收表》。

结论：**都乐和洪九大概率都有企业内控分级标准，但公开可核验的“企业标准”文本不足，不能确认可引用。** 你应自建标准并以供应商验收文件为准。
