这个数据我没法直接给你准确数字：**都乐和鑫荣懋的“到货损耗率”不是公开可查的固定指标**，会随品类形态（整果/鲜切/冷冻果肉）、季节产地、运输距离、验收标准、门店/仓配环节不同而明显波动。任何直接报一个“X%”的说法都需要核验来源。

可执行建议：

1. **先定义损耗口径**  
   到货损耗率建议拆成：
   - 到货验收损耗率 =（到货总重－验收合格重）/到货总重
   - 入库后损耗率 = 入库后至使用前的报废/失水/变质重量占比
   - 综合损耗率 = 从到货到出品前的总损耗  
   菠萝整果和鲜切/冷冻果肉的损耗差异很大，不能混比。

2. **向供应商索取可核验数据**  
   要求都乐、鑫荣懋分别提供近3个月同规格菠萝的：
   - 到货批次、总重、验收合格重
   - 损耗原因分类：机械伤、黑心、腐烂、成熟度不符、失水
   - 运输温控记录和到货温度
   - 验收标准（糖度、成熟度、单果重、瑕疵允许比例）

3. **自己做小批量对比测试**  
   选同一城市、同一季节、同规格，各进3—5批，按统一验收标准称重记录。建议至少跑2—4周，才能看出稳定规格下的真实差异。

4. **合同里写清损耗责任**  
   约定验收合格率下限、超标扣款/换货规则、到货温度要求、成熟度区间和抽检比例。稳定规格比单纯比损耗率更重要。
