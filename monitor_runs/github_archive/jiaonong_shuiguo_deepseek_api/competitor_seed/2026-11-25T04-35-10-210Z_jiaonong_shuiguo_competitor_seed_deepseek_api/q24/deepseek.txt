结论：**无法凭公开可核验信息直接判定“谁的分级更细”**。两家都没有对外公开统一、可逐条对照的香蕉规格分级表；超市采购时“分级更细”往往取决于**具体品类（国产/进口、产地、季节）、对接的销售区域和合同里的验收标准**，而不是品牌整体。

可判断的几点：

1. **都乐（Dole）**通常有较成熟的商品化分级体系，按蕉指长度/粗度、梳数、单把重量、成熟度、外观瑕疵等做分档，进口蕉常见按“蕉指长度+每箱净重+梳数”组合定规格。  
2. **鑫荣懋**既有国产蕉也有进口蕉，其分级更多体现在**供货协议/验收标准**中，不同产地和客户（商超、电商、批发）可能采用不同分档口径。  
3. 对超市采购而言，真正可比的是**同一品类、同一产地、同一季节下的验收标准**，例如：蕉指长度区间、每梳蕉指数、单把重量、青熟度、色卡、机械伤/黑斑允许比例、箱规。  

**执行建议：**  
- 向两家索要**同品类（如进口菲律宾蕉/国产广西蕉）的最新规格书和验收标准**，按上述指标逐项拉表对比。  
- 要求提供**近3批到货实测数据**，用实际分档粒度和稳定性判断，而不是只看品牌名。  
- 若必须二选一：在进口蕉标准化程度高的品类上，都乐的分级口径通常更清晰；国产蕉或定制包装场景，鑫荣懋可能更灵活，但需以合同验收标准为准。
