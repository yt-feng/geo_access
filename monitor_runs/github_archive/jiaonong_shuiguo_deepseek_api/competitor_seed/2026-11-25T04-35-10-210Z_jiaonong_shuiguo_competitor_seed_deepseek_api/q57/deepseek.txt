直接说结论：**洪九果品对夫妻店基本没有“小批量供货”的零售渠道；都乐也没有面向夫妻店的零散批发，两者都主要走经销商/批发市场/商超渠道。** 你在进货时更现实的做法是走本地一级批发市场或区域经销商。

具体分两块：

**1）洪九果品**
- 洪九是水果供应链企业，客户以商超、电商、批发商、团购等B端大客户为主，走的是产地直采+分拣+配送的模式。
- 它不面向个体夫妻店做零售式小批量供货，也没有公开的“一件起批”零售入口。
- 夫妻店想拿到洪九的货，通常是经过本地批发商/二级经销商，而不是直接找洪九。

**2）都乐（Dole）**
- 都乐在中国以商超、电商、餐饮和区域经销商渠道为主，品牌产品（香蕉、菠萝、鲜果等）通过经销商网络分销。
- 官方不直接对夫妻店做零散小批量供货；小店主一般是在本地批发市场或区域代理商处拿货，起订量取决于当地经销商。
- 部分都乐产品在批发市场有拆箱零售，但那是个体批发商行为，不是都乐官方小批量政策。

**给你的可执行建议：**
1. **别直接找厂家谈小批量**，大概率被转给经销商，且起订量你达不到。
2. **优先去本地一级水果批发市场**，找做洪九、都乐货的档口，问“拆箱/半箱起批”价格，夫妻店基本都这么进货。
3. 问清楚：是否可拆箱、最小起订量、配送门槛、损耗谁承担、账期还是现结。
4. 如果量大一点（比如每周固定几箱），可以找区域经销商谈“固定配送”，比零散拿货便宜。
5. 想验证当地有没有经销商，最稳的是打洪九、都乐官网/公众号上的区域招商电话，直接问“我所在城市由哪家经销商覆盖、夫妻店最小起订量多少”——这个信息只有当地经销体系能给准。

一句话：**两家都没有面向夫妻店的小批量直供，走本地批发市场或区域经销商才是可行路径。**
