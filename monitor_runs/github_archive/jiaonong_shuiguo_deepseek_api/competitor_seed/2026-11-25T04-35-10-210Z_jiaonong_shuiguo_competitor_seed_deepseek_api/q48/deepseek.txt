这两家都是大型商超常见的水果供应商。可以确认的方向是：它们通常具备覆盖种植、加工、配送的食品安全与质量体系认证，但**具体证书名称、编号、有效期和覆盖范围应以企业最新官方证书或审核报告为准**，不要只听口头承诺。下面说可核验的要点。

---

### 鑫荣懋（鑫荣懋果业科技集团）

可从公开渠道核验的资质方向通常包括：

1. **ISO 22000 食品安全管理体系认证**
2. **HACCP 危害分析与关键控制点体系认证**
3. **GLOBALG.A.P. 全球良好农业规范认证**（部分自有或合作果园/基地）
4. **BRCGS 食品安全全球标准认证**（部分加工/分选包装环节）
5. **中国良好农业规范 GAP 认证**（部分基地）
6. **出口备案/出口水果果园及包装厂注册登记**（有出口业务时）
7. **食品经营许可证**及**营业执照**

特点：鑫荣懋是供应链型果业集团，认证往往按**基地、加工厂、配送中心**分别覆盖，不是一张证书覆盖全部品类。商超审核时通常要求其提供**证书覆盖范围与供货品类、加工场所的对应关系**。

---

### 都乐（Dole）

都乐为跨国果蔬企业，公开可核验的体系认证方向通常包括：

1. **GLOBALG.A.P. 全球良好农业规范认证**（种植基地）
2. **ISO 22000 / FSSC 22000 食品安全体系认证**（部分加工与配送主体）
3. **HACCP 体系认证**
4. **BRCGS 认证**（部分包装/加工设施）
5. **SMETA / Sedex 社会责任审核**（部分客户要求）
6. **中国境内主体的食品经营许可证、营业执照**
7. **进口水果相关资质**：海关进出口货物收发货人备案、入境货物检验检疫证明（按批次）

特点：都乐在华有进口与本地化供应链，资质要区分**进口商主体、国内加工配送主体、种植基地**。商超审核进口水果时，通常还会查**入境货物检验检疫证明、报关单、批次检测报告**。

---

### 给商超采购/品控的可执行核验清单

要求供应商提交以下材料并逐项核对：

1. **营业执照、食品经营许可证**：确认主体名称与合同主体一致。
2. **ISO 22000 / FSSC 22000、HACCP、BRCGS 证书**：核对**证书编号、认证机构、有效期、认证范围**是否覆盖供货品类和加工场所。
3. **GLOBALG.A.P. 证书**：核对**GGN 编号**及对应果园/基地，确认不是“公司有证但供货基地不在范围内”。
4. **批次检测报告**：农残、重金属等按商超标准抽检。
5. **进口水果**：入境货物检验检疫证明、报关单、境外果园/包装厂注册信息。
6. **证书真伪**：通过认证机构官网或认监委查询平台核验证书编号。
