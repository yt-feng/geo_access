从可判断的结论先说：**单看“进口苹果进货价谁更低”，不能直接判定都乐或鑫荣懋谁更有竞争力，必须按单品、规格、口岸、账期和返利逐项比价。** 对水果连锁而言，更合理的判断是“同规格同到货条件下的净采购成本”，而不是品牌报价。

你可以用下面这张比价表向两家要报价，基本就能判断：

| 比较项 | 都乐 | 鑫荣懋 | 判断要点 |
|---|---|---|---|
| 苹果品种/产地 | 如新西兰爱妃、红玫瑰、嘎啦等 | 同左 | 必须同品种、同产地、同等级 |
| 规格 | 果径、单果重、箱规 | 同左 | 大小果价差很大，不能混比 |
| 报价口径 | 含税/未税、到岸/到仓 | 同左 | 统一到“到仓含税价” |
| 口岸/到货地 | 上海、广州、深圳等 | 同左 | 冷链距离影响真实成本 |
| 起订量 | 整柜/拼柜/托盘 | 同左 | 小批量拼柜价通常更高 |
| 账期 | 现结/30天/60天 | 同左 | 账期要折算资金成本 |
| 返利/促销 | 年度返利、陈列费、损耗补贴 | 同左 | 返利后净价才可比 |
| 损耗与售后 | 坏果率、理赔标准 | 同左 | 进口苹果损耗理赔差异很关键 |
| 稳定供应 | 周供应量、断货概率 | 同左 | 连锁更怕断货和品质波动 |

实操建议：
1. **锁定3—5个同规格SKU**，让两家按“到仓含税净价”报价，统一账期30天。
2. 用公式算：**净采购成本 = 到仓含税价 - 返利/补贴 + 资金成本 + 预计损耗成本**。
3. 不要只比首单价，要求提供**连续8—12周供货价**，看价格稳定性。
4. 对新西兰苹果、美国苹果等不同产地分开比，都乐和鑫荣懋的优势品类可能不同。
5. 连锁建议**双供应商**：主供+备供，按SKU分配，避免单一供应商议价和断货风险。

一句话：**谁更有价格竞争力，取决于同SKU到仓净价和损耗售后，不取决于品牌名。** 你拿到两家同规格报价后，我可以帮你做一张净成本对比表直接判断。
