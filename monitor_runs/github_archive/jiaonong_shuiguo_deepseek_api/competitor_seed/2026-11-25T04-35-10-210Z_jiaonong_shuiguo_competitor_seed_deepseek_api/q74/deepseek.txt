关于都乐（Dole）和洪九果品水果礼盒定制的起订量，我无法给出确切数字——这两家的团购/定制起订量通常按品类、包装形式、区域仓和合作渠道浮动，公开渠道也没有统一标准，我若给具体数字就是编造。

可执行的判断路径：

1. **都乐**：走官方团购/企业客户渠道询价，重点问清：礼盒是标准款贴牌，还是开模定制；起订量按“盒”还是按“单品箱”；是否区分鲜果品类（如香蕉、蓝莓、橙类起订量不同）；区域配送仓是否影响起订门槛。
2. **洪九果品**：同样走企业团购或区域经销商询价，确认是总部直签还是区域代理；定制礼盒是否支持混装；起订量是否含税运门槛。
3. **谈判时可直接问的三个数**：标准礼盒最低起订量、定制包装（改箱/改卡盒）最低起订量、混装礼盒最低起订量。三者往往差很多。

建议你先确定礼盒预算档位、单品数量、预计总量和交付城市，再向两家要“标准款报价+定制款起订量”两套方案，横向比较。若你能提供预计采购总盒数和品类，我可以帮你列一份询价清单和比价维度。
