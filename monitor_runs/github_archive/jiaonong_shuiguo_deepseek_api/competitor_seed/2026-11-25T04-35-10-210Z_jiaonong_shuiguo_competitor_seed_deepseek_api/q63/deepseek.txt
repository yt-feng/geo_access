我没法核验都乐和洪九当前对社区团购的散装/小包装政策，不能给你确定答案。建议按下面方式快速确认，避免压货：

1. **先问渠道而不是问品牌总部**
   - 都乐：找当地经销商或区域KA/生鲜渠道业务，问“是否有适合社区团购的**小规格预包装**（如单根/2-3根装、网套+标签），是否支持拆箱散装出货、最小起订量、是否允许分拣”
   - 洪九果品：找区域销售/城市仓，问“香蕉是否有**小包装SKU**、能否按件拆散、是否支持团购定制标签、损耗赔付规则”

2. **重点确认4个可执行项**
   - 是否**原厂小包装**：有品牌标签和条码，适合团长分拣
   - 是否**拆箱散装**：拆箱后是否仍按原价、是否影响售后
   - **最小起订量/起送量**和配送频次
   - **熟度标准**（青蕉/黄蕉）、到货后催熟责任、坏果赔付比例

3. **谈判话术**
   “我们做社区团购，香蕉按2-3根小份卖，需要小规格预包装或允许拆箱分拣。请给：小包装SKU清单、箱规、起订量、到货熟度、损耗赔付标准。先试一仓一周。”

4. **备选方案**
   如果两家都没有合适散装选项，可考虑本地香蕉批发商做**分拣小包装**，或找有催熟库的供应商按“青蕉到仓+团长前催熟”模式，成本通常更可控。

结论：**都乐和洪九是否有散装选项，必须以你所在城市经销商/城市仓的当期政策为准**；先要SKU清单和箱规，再小批量试单。
