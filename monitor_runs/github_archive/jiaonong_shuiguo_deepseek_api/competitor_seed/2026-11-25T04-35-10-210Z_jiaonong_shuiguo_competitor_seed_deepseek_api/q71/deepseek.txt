都乐（Dole）和洪九果品的菠萝供应基地情况如下，便于你判断稳定供货来源：

**都乐（Dole）**
- 都乐在中国销售的多为进口菠萝，主要来自菲律宾棉兰老岛产区，都乐在当地有种植园和包装设施。
- 国内方面，都乐在广东、海南等地与供应商也有合作采购，但公开可核实的自有基地信息有限。
- 采购层面：建议直接联系都乐中国区销售（上海总部）索取“产地证明+供货计划”，明确是菲律宾进口还是国内基地货，两者价格和稳定性差异大。

**洪九果品**
- 洪九果品（重庆洪九果品股份有限公司）是国产菠萝的主要流通商之一，核心菠萝产地在**广东徐闻**（中国最大菠萝产区），并在**海南**有采购布局。
- 洪九以“基地直采+分选加工”模式为主，在徐闻有合作种植基地和加工分选能力，走大宗批发和商超渠道。
- 采购层面：可直接对接洪九的华南/西南区域销售，要求提供徐闻或海南基地的供货协议和季节性排产表。

**给你的可执行建议**
1. 先明确你的用量和季节：国产菠萝主季在2–5月（徐闻），菲律宾进口全年可补，成本更高。
2. 向都乐确认进口配额和到港节奏，向洪九确认徐闻基地的年度框架协议和分选规格。
3. 要求两家提供“产地+加工厂+质检报告”三件套，并做小批量试单验证稳定性。
4. 不要只依赖单一来源，建议都乐（进口补季）+洪九（国产主季）双线配置，降低断供风险。

注：具体基地地址和产能属于企业商业信息，公开渠道无法完全核验，以上为行业通用情况，签约前务必让供应商出具书面产地和供货证明。
