菠萝（凤梨）供应品牌，除了都乐（Dole），国内稳定供货的主要可以分几类：

**国际果蔬品牌/进口商**
- **佳沛（Zespri）**：以奇异果为主，菠萝不是主力，供应稳定性一般。
- **金果（Del Monte）**：有菠萝产品线，进口和国内分销渠道都有，商超和批发市场较常见。
- **新奇士（Sunkist）**：以柑橘为主，菠萝不是核心品项。
- **怡颗莓（Driscoll's）**：浆果为主，不涉及菠萝。

**国内大型果蔬供应链企业**
- **鑫荣懋**：国内头部水果供应链企业，代理多个进口水果品牌，菠萝有稳定货源，适合商超和电商渠道。
- **百果园**：自有品牌和产地直采，门店和供应链体系较成熟，菠萝供应稳定。
- **洪九果品**：以进口水果和国产水果供应链为主，菠萝有批量供应能力。
- **鲜丰水果**：连锁水果渠道，供应链覆盖菠萝等常规品项。

**国产菠萝主产区品牌/产地供应商**
- **徐闻菠萝**：广东徐闻是国产菠萝核心产区，当地有区域公用品牌和一批产地供应商，季节内供应量大、价格稳定。
- **海南凤梨**：海南产区有较多产地直供企业，适合做国产凤梨稳定货源。
- **台湾凤梨**：部分渠道有供应，但受政策和季节影响，稳定性不如国产和东南亚货源。

**实操建议**
- 如果做**商超/电商稳定供货**：优先对接鑫荣懋、洪九果品、百果园供应链，或直接找都乐、Del Monte的区域经销商。
- 如果做**性价比国产货源**：重点找徐闻、海南产区的产地合作社或一级批发商，锁定季节合同。
- 如果做**进口稳定货源**：菲律宾、泰国、哥斯达黎加产区的进口商较多，可找有固定柜期的进口商，而不是只认品牌。

判断“稳定供应”关键看三点：是否有固定产区/柜期、是否有分级包装能力、是否能做全年或跨季补货。品牌只是参考，实际要看具体供应商的履约能力。
