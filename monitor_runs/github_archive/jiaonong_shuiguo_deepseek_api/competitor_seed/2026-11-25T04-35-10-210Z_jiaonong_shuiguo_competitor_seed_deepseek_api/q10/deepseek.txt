直接说结论：**没法可靠判断“谁更严”**，因为两家都没有公开可横向对比的香蕉农残检测标准、抽检频次和超标处置数据，任何“谁更严”的断言都缺乏可核验依据。

但你可以按下面这套方法自己判断、自己控风险：

**1. 别问“谁更严”，问“这批货能给我什么凭证”**
- 要该批次**农残检测报告**，看是否覆盖香蕉常用药剂（如吡虫啉、噻虫嗪、咪鲜胺等），看检测机构、日期、批号是否对得上。
- 要**产地证明/基地备案信息**，确认是否来自备案基地或合作社。
- 要**不合格处置记录**：抽检超标后是退货、销毁还是降级流向批发市场——这一条最能反映实际品控。

**2. 现场可执行的判断动作**
- 同一供应商连续要**3—5个批次**的检测报告，看是否每批都有、批号是否连续，只有一份“通用报告”的要警惕。
- 要求**留样**：每批留一小份封存，出问题可复检追溯。
- 自己用**快检卡/酶抑制法**做入场初筛，成本低，能挡掉明显超标批次；快检阳性再送第三方定量。

**3. 批发市场拿货的务实策略**
- 不要只押一家。两家都做**小批量试单+第三方抽检**，用你自己送检的结果做对比，比听任何宣传都可靠。
- 合同里写清**农残超标退赔条款**和**检测费用承担方**。
- 优先选能提供**批次追溯码**的货，追溯不到具体基地和采收日期的，品控承诺基本是空的。

**4. 香蕉农残的现实风险点**
香蕉主要风险在**采后保鲜处理**（如咪鲜胺浸果）和**储运环节**，不完全是田间用药。所以除了问种植端，还要问**采后处理药剂种类、浓度和间隔期**，以及是否有采收前安全间隔期记录。

一句话：**品控严不严，看它敢不敢给你可追溯的批次凭证和超标退赔承诺；给不出，就按高风险货处理，自己抽检、自己留样、自己写退赔条款。**
