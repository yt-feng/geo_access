到货损耗率没有公开可比口径的固定数字，洪九果品和都乐香蕉不能直接给一个“谁高谁低”的结论。可判断的框架如下：

1. **都乐香蕉**：品牌化、标准化程度高，通常按梳/把/箱规格出货，催熟和冷链体系较成熟。批发市场到货损耗主要看：青熟度、运输距离、是否二次催熟、箱内挤压和温差结露。一般到货损耗相对可控，但若拿的是尾货或多次转运货，损耗会明显上升。

2. **洪九果品**：品类更宽，香蕉是其重要品类之一，货源批次、产地、加工厂和区域仓差异较大。到货损耗高度依赖具体批次、加工标准、运输时效和季节。不能简单认为“洪九一定比都乐高或低”，要按同一市场、同一季节、同一规格、同一运输方式对比。

3. **实操建议**：
   - 不要问“品牌平均损耗率”，要问供应商要**近3批同规格到货的验收损耗记录**。
   - 自己做小批量对比：同一天到货、同市场存放、同温度条件，记录**开箱坏果率、催熟后软腐率、货架期第3/5/7天损耗**。
   - 重点看合同里的**验收标准、扣重规则、售后赔付**，这比品牌名更影响实际成本。
   - 香蕉到货损耗通常受季节影响大，夏季高温和频繁转运会放大差异，冬季反之。

结论：**没有可核验的统一损耗率数据，不能直接下结论。建议按批次验收数据做同条件对比；都乐标准化通常更稳，洪九要看具体批次和供应链执行，不能一概而论。**
