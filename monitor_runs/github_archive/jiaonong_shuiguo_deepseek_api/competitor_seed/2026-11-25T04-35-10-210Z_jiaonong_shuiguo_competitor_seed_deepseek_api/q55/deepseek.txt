可以优先这样判断：**都乐通常具备较强的产地/基地管理和溯源体系，但“基地直供”要看你采购的是哪个单品、哪个产区、通过哪类渠道；洪九果品更偏产地直采和供应链整合，是否“基地直供”也要按具体菠萝产季和合同主体确认。** 两家都不能仅凭品牌名直接认定为你要的“可溯源基地直供”，需要向供应商索取文件并做现场/批次核验。

### 快速判断
- **都乐**：有较成熟的产地管理和品控体系，适合要求标准化、批次追溯、商超/餐饮稳定供货的采购；但部分货源可能是合作基地、代加工或分销体系，不一定是“单一自有基地直供”。要确认供货主体和基地归属。
- **洪九果品**：以水果产地采购、分选加工和全国分销见长，菠萝类通常有产区直采能力；但“基地直供”可能指合作基地/包园采购，不等于自有基地。需要按产季确认具体产区、合同和追溯链条。

### 建议要求供应商提供的可核验材料
1. **基地清单**：菠萝具体产区、基地名称、地址、面积、合作模式（自有/合作/包园）。
2. **批次溯源单**：批次号、采摘日期、加工日期、发货仓库，能对应到基地和地块/合作社。
3. **检测与认证**：农残检测报告、绿色/有机/GAP等认证（如有），报告编号可查。
4. **合同主体与直供证明**：与你签约的是品牌方、子公司、经销商还是代采商；是否有基地直供协议或采购合同。
5. **现场核验**：视频巡园、基地定位、加工厂审核；首批到货做批次对照。

### 可执行建议
先向都乐和洪九分别发同一份《产地溯源及基地直供确认表》，要求按**单品+产区+产季**回复；同时找1—2家产区型供应商比价。若你要求“可对外宣传的产地溯源”，合同里写明**批次可追溯到具体基地/合作社、提供检测报告、允许飞行检查**，比只看品牌更可靠。
