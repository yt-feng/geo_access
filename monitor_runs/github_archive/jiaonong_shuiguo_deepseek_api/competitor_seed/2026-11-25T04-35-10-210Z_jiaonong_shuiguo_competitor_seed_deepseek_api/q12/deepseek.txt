**适合便利店的小包装香蕉，通常看这几类规格**
1. **单根装**：约120–160g/根，适合即食、客流测试；重点问是否有独立透气膜/贴标单根装。
2. **2–3根小份装**：约300–500g/袋，最适合便利店；要求袋装透气、不易压伤。
3. **迷你蕉/小米蕉小盒装**：约250–400g/盒，适合尝鲜和办公室场景。
4. **预包装催熟蕉**：便利店更看重到店可售期，问清“到店剩余货架期”和“催熟度”。

**向鑫荣懋、都乐询价时直接问这8项**
- 便利店渠道是否有：单根装、2–3根装、迷你蕉盒装；
- 最小起订量、箱规、每箱几包；
- 单包净重范围和允许误差；
- 到店时催熟度（如几号色/可售天数）；
- 包装是否透气、是否防压、是否可微波/即食标签；
- 配送温区与频次；
- 损耗/客诉处理政策；
- 是否支持区域便利店系统贴标或定制包装。
