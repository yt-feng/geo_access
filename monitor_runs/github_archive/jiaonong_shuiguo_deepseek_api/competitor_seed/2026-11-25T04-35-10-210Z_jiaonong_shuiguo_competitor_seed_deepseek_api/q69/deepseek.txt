都乐（Dole）和洪九果品在进口苹果上**都算分级比较严格的供应商**，但严格的方式和适合的采购场景不完全一样：

- **都乐**：品牌化、标准化程度高，进口苹果通常按果径、色泽、外观分级，批次稳定性较好，适合对规格统一、包装标识和供货稳定性要求高的超市。缺点是价格通常偏高，且具体规格要以当批到货标准和合同为准。
- **洪九果品**：以水果供应链和批发分销见长，进口苹果分级也较规范，果径分档和箱规通常清楚，性价比可能更好；但不同批次、不同产地和不同仓库的实物一致性，建议到货抽检确认，不能只看品牌。

**可执行建议：**
1. 采购合同里明确写清：品种、产地、果径范围（如80#/85#/90#）、单果重范围、色泽、允许瑕疵率、箱规、到货抽检比例。
2. 首批小批量试单，分别抽检都乐和洪九各3—5箱，记录果径合格率、坏果率、大小均匀度。
3. 要求供应商提供当批分级标准或质检报告；不接受只口头承诺“分级严格”。
4. 若超市最看重规格统一和陈列一致性，优先都乐；若更看重成本和供应弹性，可让洪九报价并附分级标准，再做对比。

结论：**两家都具备较严格的分级能力，但“严格”必须落到合同规格和到货抽检上；不能仅凭品牌判断。**
