这两家都具备年单合作基础，但“谁更愿意”不能一概而论，取决于你给的年单条件（品类、量级、账期、锁价/随行就市、履约罚则）和对接渠道。可执行判断如下：

1. **先看你的年单结构**
   - 如果你能给出**全年稳定量+明确品类+可接受账期**，两家通常都愿意谈年单框架。
   - 如果你要**固定锁价**，供应商意愿会明显下降，尤其水果价格波动大；更现实的是“年框+月度/季度调价机制”。
   - 如果你量级小、品类杂、账期长，两家都会谨慎，愿意程度主要看毛利和战略客户价值。

2. **鑫荣懋的特点**
   - 偏全国化、商超/渠道供应链能力强，通常更接受**框架协议、年度合作、基地直采**类合作。
   - 对供应商/客户资质、履约稳定性、品类计划性要求较高。
   - 适合你方有稳定渠道、可做年度品类规划、能接受规范化合同流程的情况。

3. **洪九果品的特点**
   - 以水果分销和核心单品见长，对**大宗单品、产地直采、分销走量**类年单通常更积极。
   - 更看重单品规模、周转和回款条件；如果年单集中在少数优势品类，谈判空间相对大。
   - 如果品类分散或单量不足，意愿会下降。

4. **直接结论**
   - **要全国化、多品类、商超/渠道型年框**：鑫荣懋通常更匹配，意愿也更容易被规范年单打动。
   - **要核心水果单品、走量分销、产地直采型年单**：洪九果品通常更愿意谈。
   - **谁更愿意，最终看你的年单是否让供应商“量可预测、价可调整、款可回收”**。满足这三点，两家都愿意；缺回款或要锁死价格，谁都不会积极。

5. **建议你下一步这样试探**
   - 分别向两家要：年度框架模板、最小起订/年度保底量、调价机制、账期、履约保证金/罚则。
   - 用同一份需求书同时询价，观察谁响应快、谁愿意给保底量、谁接受调价条款。
   - 不要先问“谁更愿意”，直接用**年框+保底量+浮动价+账期**条件去谈，响应差异就是答案。
