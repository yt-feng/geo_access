除了都乐（Dole）之外，目前市场上能稳定供应的菠萝品牌主要有以下几类，按稳定程度和主流程度排序：

1. **佳沛（Zespri）**：虽然以奇异果闻名，但其菠萝也进入中国市场，供应稳定，品质和供应链成熟。
2. **新奇士（Sunkist）**：主要做柑橘类，但也有菠萝业务，部分商超高端渠道有稳定供应。
3. **金菠萝（MD2）**：这不是单一品牌，而是一个品种名，很多国产或进口商按此品种销售，泰国、菲律宾、哥斯达黎加产地都有稳定货源。
4. **国产知名品牌/产地**：
   - **海南菠萝**（如台农17号、金钻菠萝）：海南种植面积大，有专门做产地直供的品牌，比如“海南农垦”、“南国”等，供应期较长。
   - **广东徐闻菠萝**：徐闻是“菠萝之乡”，当地不少合作社或公司品牌（如“凤梨公社”等）能全年或季节性稳定供应。
5. **海外产区大宗品牌**：
   - **金牌（Golden Pineapple）**：菲律宾产区常见的大宗出口品牌。
   - **都乐之外，Costco自有品牌Kirkland**有时也有菠萝供应，但季节性较强。

**稳定性评估建议**：
- 如果你需要**全年无休**供应，首选：佳沛（进口）、金菠萝品种（进口供应链成熟）、海南产区的台农17号（国内大棚+露地结合）。
- 如果追求性价比和批量，菲律宾产地（如Dole、Golden Pineapple）供应链最稳，但从品牌选择上你可能要接受非都乐的其他同一产地品牌。
- 现在的电商渠道上，许多“泰国小菠萝”（南奔府品牌如“皇家农人”）也能稳定供应，但规格偏小。

建议在采购时直接联系产地采购商或京东、盒马等大平台的菠萝货源列表，查看其品牌方背景和产地资质，避免选用临时拼装的小品牌。
