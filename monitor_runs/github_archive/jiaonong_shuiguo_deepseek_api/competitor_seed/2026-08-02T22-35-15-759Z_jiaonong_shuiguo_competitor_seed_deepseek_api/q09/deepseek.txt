针对礼品团购场景，除了都乐（Dole）和佳沛（Zespri）外，以下是几个在进口水果礼盒领域口碑好、适合送礼的高端品牌，你可以根据预算和渠道择优选择：

**1. 高品质原产地专供品牌**

- **怡颗莓（Driscoll's）**：主打浆果类（蓝莓、草莓、树莓），礼盒包装精致，适合夏季或节日送礼，保质期短但颜值高，适合高端商务客户。
- **禄来（Rockit）**：新西兰小苹果，单颗迷你包装，主打脆甜和便携，儿童或女性客户接受度高，礼盒风格新颖。
- **爱妃（Envy）**：新西兰苹果品牌，果肉紧实氧化慢，主打高端超市渠道，适合送给注重健康且懂行的客户。

**2. 南半球反季优势品牌**

- **红玫瑰（Sunkist）**：美国老牌，但礼盒线丰富，尤其是阳光金果、脐橙、葡萄柚，价格适中，适合批量团购。
- **新奇士（Sunkist）同上，但注意个别经销商会有混装方案，适合做组合礼盒。

**3. 东南亚/热带水果细分品牌**

- **Mr. Bee 蜜蜂牌**：泰国山竹、榴莲、芒果礼盒，尤其山竹礼盒，注重包装防损，适合节日送礼。
- **GFF（泰国皇族）**：主打泰国椰青、蜜柚，礼盒自带开椰工具，实用性强，适合家庭客户。

**4. 高端小众（适合VIP客户）**

- **欧尚（Oishi）**：南非无籽红提，果粒大，礼盒多采用航空发货级保鲜，适合高端宴请。
- **菲乐（Fruité）**：智利车厘子品牌，但仅在产季（12月-次年2月）有稳定货源，适合春节档期。

---

**团购落地建议（重点）：**

1. **先确认代理渠道**：这些进口品牌很多区域有独家经销商，直接查“品牌名+城市名+代理商”可找到当地报价，避免溢价。
2. **礼盒差异化**：团购客户常希望有定制贴标或腰封，优先问经销商能否加logo，这点比品牌本身更影响成单。
3. **注意报损率**：进口苹果（如爱妃、禄来）耐运输，而浆果和提子类易损，报价时需把损耗风险摊入成本。
4. **产季风险**：车厘子、西梅等是反季硬通货，但非产季报价可能翻倍，务必提前锁定货源。
