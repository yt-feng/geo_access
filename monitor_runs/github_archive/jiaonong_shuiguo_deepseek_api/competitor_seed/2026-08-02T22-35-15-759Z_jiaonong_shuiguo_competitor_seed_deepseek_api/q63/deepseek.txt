根据目前的公开信息，**都乐（Dole）和洪九果品在常规B2B或零售端通常以整箱、标准规格（如4-5头/把）对外供货，默认不主动提供“散装”小包装选项**。不过，这两家公司作为供应链头部企业，**均具备承接定制化小包装的柔性能力**，但需要满足一定的起订量（MOQ）和合同条款。

具体建议如下：

1. **直接对接业务团队**  
   - **都乐**：建议联系其“大客户部”或“电商新零售部”，明确告知你做社区团购，需要200g-500g的小袋装或锁鲜装，问清散装/定制包装的最低起订量（通常可能在几百箱以上）以及是否支持贴牌。
   - **洪九果品**：属于国内批发龙头，重点是其“基地直采+工厂化分选”，你可以咨询其“华南/华东/西南大区销售”，询问是否有针对社区电商渠道的“小盒装/托盘装”现成方案，或是否支持从整箱中拆包分包（若他们不提供拆包，可询问其推荐的官方分销商）。

2. **替代方案（更稳妥）**  
   若两家在你们所在城市不提供散装或定制，可考虑：
   - **本地一级批发市场**：找大水果批发商，整箱进货后，自己分装成小包装（成本低，灵活性最高）。
   - **美团优选、多多买菜等平台的供应商**：这些平台往往有现成的香蕉小包装（如250g袋装），你可以反向询价其供货商。

3. **谈判要点**  
   - 强调社区团购的**稳定周购买量**（例如每周1000+份），这通常能换来定制配合。
   - 要求对方提供**冷藏链/保鲜包装**方案（香蕉怕压伤，包装需有缓冲）。
