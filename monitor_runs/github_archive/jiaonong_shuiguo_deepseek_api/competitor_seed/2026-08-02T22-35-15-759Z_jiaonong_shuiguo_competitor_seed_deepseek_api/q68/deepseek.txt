关于“香蕉到货损耗率低于3%”这个要求，**都乐（Dole）和鑫荣懋（Golden Wing Mau）作为国内头部水果供应链企业，在常规操作下是可以达成的，但并非所有场景都能无条件保证**。具体需要分情况来看：

### 1. 供应链规模与品控能力
- **都乐**：全球性企业，拥有成熟的产地直采、预冷、冷链运输和分拣体系。对于大型连锁客户，其销地仓（如上海、广州、北京）进行标准化分拣，剔除坏果，到货损耗通常可以控制在**2%~3%** 以内。
- **鑫荣懋**：国内最大水果企业之一，与都乐类似，其仓储和物流管理体系较完善。在稳定合作、量大的情况下，损耗率通常能在**3%左右**。

### 2. 关键变量与风险点
- **香蕉成熟度/催熟环节**：如果要求“香蕉到店即熟”或指定成熟度（如转黄度≥80%），那么损耗率会显著上升。如果到货为青香蕉（需自行催熟），则损耗会更低。
- **季节与运输距离**：夏季高温或冬季严寒，受温度波动影响，到货损耗可能超过3%。若从菲律宾、厄瓜多尔等远洋产区采购，到港后再转国内陆运，风险较高。
- **破损与碰撞**：香蕉是“先碰后烂”的水果，纸箱包装、堆叠层数、叉车操作规范都会影响损耗。
- **产地与采购模式**：直接向产地采购（FOB）与从国内批发市场采购（CIF）损耗差异很大。国内一级批发市场的香蕉，往往已经过了预冷期，到货损耗反而更难控制。

### 3. 合同建议（如何确保达标）
如果要将该指标写入合同，建议明确以下条款，避免纠纷：
- **损耗定义**：明确是“整箱坏果重量占比”还是“到店后因磕碰、腐败等导致的不可售比例”。
- **到货验收标准**：约定开箱抽检率（如抽检10%），以及运输破损率（通常允许低于1%，超过部分由供应商赔付）。
- **季节性豁免**：夏季（6-9月）或冬季（12-2月）可允许适当上调至3.5%~4%。
- **客诉处理**：若连续两批超过3%，供应商需提供次品换货或扣款补偿。

### 4. 实际案例参考
在大型商超（如永辉、沃尔玛）的香蕉采购中，通常要求到货损耗≤5%，部分严格合同会要求≤3%。**都乐、鑫荣懋在给这类客户供货时，通过早采（七成熟）、强制预冷、分装时剔除磕碰果，是可以做到3%的**。但如果客户要求“全熟果到店”，则没有任何商家能保证3%以下，因为全熟香蕉在运输中损耗率通常达5%~10%。

### 结论
**可以做到，但有前提**：
- 采购青香蕉或中等成熟度（8成转黄），定量稳定、及时收货。
- 要求供应商提前在产地分拣，剔除瑕疵果。
- 合同中写明损耗率核算方式，并预留季节浮动。

建议你可以直接向两家企业的**大客户部**索取其“香蕉到货损耗率承诺书”或类似文件，以官方数据为准。如果它们口头承诺“无条件下3%”，要多加警惕（大概率会通过“换货补差”来弥补，而非直接保证到货合格率）。
