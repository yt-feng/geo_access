在超市采购进口苹果时，**规格统一性**主要取决于品牌的分级标准和批次管理。

关于**都乐（Dole）**和**洪九果品**的分级严格程度，结论如下：

1.  **都乐（Dole）**：作为国际知名品牌，其分级制度**非常严格**。
    -   它通常按照果径（如75mm、80mm、85mm等）、果形（高桩、扁圆）、着色度、糖度、病虫害等进行专业分级。
    -   同一批次内，大小和外观的一致性通常很高。但需要注意的是，**不同产地和国家（如美国、新西兰、智利）的标准会略有差异**，采购时需明确要求具体的果径和等级标准（如特级果、一级果）。
    -   **建议**：在采购合同中明确标注“果径范围±1mm”或“同一箱内果径差不超3mm”等具体条款，以锁定标准。

2.  **洪九果品**：作为国内头部水果供应链企业，其分级**基于源头基地和品控体系，严格度和都乐相当**，甚至在某些单品（如进口苹果）上采取“一果一码”或“全果分级”模式。
    -   洪九的优势在于其国内加工和分拣环节的数字化管理，能有效控制大小差异。
    -   但部分非核心品种或促销批次，可能存在“统货”情况，需特别沟通。
    -   **建议**：洪九的分级标准通常体现在其内部品控文件里，采购时直接要求其提供“规格等级说明”或“抽样报告”，并检查实际到货。

**实际操作建议（以便您做出判断）：**

-   **明确需求**：不要只写“规格统一”，要写清楚具体果径（如80mm-85mm）、单果重（如250g-280g）和等级（特级/一级），并注明允许的偏差范围。
-   **验货标准**：到货后，按箱随机抽样，用游标卡尺测量果径，若差异超过约定的3-5mm，可判为不合格并索赔。
-   **采购渠道**：如果对规格要求极高（如礼盒装），建议优先选择都乐，其品牌溢价高但标准稳定；如果追求性价比且量大，洪九的基地直采能力更有优势，但需更严格的到货抽检。

**结论**：**两家整体分级都很严格，都乐偏重国际市场标准，洪九偏重国内消费分级。您只需在采购合同中把分级指标量化，哪家都能达到您的要求。** 若您是在临时零售单次采购，建议优先看实际到货样品。
