关于进口苹果上架定价，**我无法直接给出“都乐”和“鑫荣懋”当前具体的批发报价**，因为价格会随产地（美国、新西兰、智利等）、品种（嘎啦、红富士、爵士等）、规格（大果/中果）、到港时间及汇率波动实时变化。

但可以给你一套**可执行的价格竞争力判断与谈判建议**：

1. **直接询价路径（最优先）**  
   - 联系两家公司的**区域销售经理**或**电商/商超渠道负责人**，直接要求提供“本周/本月到港的**同品种、同规格**”报价单（如：新西兰爵士苹果80#，每箱净重18kg）。
   - 同时要求对方提供**到货港口**（广州/上海/天津）和**含税/不含税**价格，避免只报“批发价”而忽略物流与损耗。

2. **竞争力对比的3个隐藏维度**  
   - **到货新鲜度**：进口苹果看“采摘-到港”时间（一般为30-60天）。短期到货的货，口感更脆，溢价能力更高。  
   - **果面等级**：同一箱内“大小均匀度”和“是否有轻微压伤”直接影响售价。要求对方提供**验收标准**（如“100%果径≥80mm，允许≤3%的黑点”）。  
   - **账期与退换货**：若对方能提供“首批试销、二次补货”或“非人为损果包赔”，实际成本可能更低。

3. **建议的决策动作**  
   - 若两家报价接近（价差≤5%），优先选**出货稳定、破损率低**的供应商——因为进口苹果损耗是利润最大杀手。  
   - 如果都乐品牌溢价较高，可让鑫荣懋提供**同品质的“OEM/散装”方案**，往往能优化毛利3-8个点。

4. **给你20秒速查定价锚点（非实时报价）**  
   以近期（2024-2025年）市场行情粗略参考：
   - 新西兰爵士/爱妃：高端，市场零售价约28-45元/斤。
   - 智利嘎啦：中端，零售价约12-18元/斤。
   - 美国红蛇果：中端，10-15元/斤。
   批发价通常为零售价的**40%-60%**，具体看渠道。

**最后提醒**：不要只比单一价格。建议你**同时索要两家“本季度到港批次”的样品各1箱**，实测脆度、糖度（果糖计）和货架期（模拟常温放置7天），再结合报价做最终决策。
