在中国市场，**都乐（Dole）的品牌知名度整体高于鑫荣懋（Xinrongmao）**，尤其在终端消费者（C端）的认知度上差距明显。

具体分析如下：

1.  **品牌属性不同**：
    -   **都乐**是国际知名品牌，主打进口水果（如都乐香蕉、凤梨），长期在商超、电商平台进行品牌露出，且通过包装、广告在消费者心中建立了“品质进口”的形象。在生鲜电商上，搜索“香蕉”时，都乐是高频出现的头部品牌。
    -   **鑫荣懋**是中国本土的头部水果供应链企业，它更多是**产业链上游的品牌**（种植、采购、分销），在B端（批发市场、商超渠道）名气很大，但对普通消费者而言，它的“品牌感”较弱，更多时候是以“佳沃”（其旗下品牌）或商超自有品牌的面目出现。

2.  **电商平台表现**：
    -   在京东、天猫、美团买菜、叮咚买菜等平台，都乐香蕉通常有官方旗舰店，且销量和评论量领先。
    -   鑫荣懋虽然也在为很多平台供货，但消费者在选购时往往更认“都乐”这个牌子，而非“鑫荣懋”。

**结论建议：**
如果你的生鲜电商平台需要**拿品牌来给消费者做信任背书**（比如突出品质、安全、进口），**首选都乐**，因为它自带流量和转化率。

如果是为了**供应链成本和稳定货源**，鑫荣懋是很好的供应商，但建议在页面上不要只打“鑫荣懋”三个字，而是打它的子品牌（如“佳沃”）或直接标注品种（如“佳农”或“进口”），否则消费者可能看不太懂。
