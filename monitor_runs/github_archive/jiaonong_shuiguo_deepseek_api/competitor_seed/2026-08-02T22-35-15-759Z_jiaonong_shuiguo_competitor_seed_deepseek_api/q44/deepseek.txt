关于都乐（Dole）和鑫荣懋（Golden Wing Mau）的供货稳定性，需要明确的是，目前我无法直接获取实时的供应链库存或物流数据，因此无法给出确切的“月度稳定率”或实时承若。但基于行业公开信息和一般商业规律，我可以给你一些判断维度和建议：

**1. 都乐（Dole）——以品牌溢价和全球化采购见长**
- **稳定性特点**：作为全球性果蔬巨头，都乐在中国市场主要依托进口供应链（如智利、新西兰、美国等产地），货源对接国际海运/空运，季节性产地切换能力强。
- **潜在风险**：长周期运输受港口拥堵、船期延误影响较大；价格较高，若遇产地天气灾害（如智利干旱）短期供应会紧张。
- **合作建议**：适合做中高端引流品，建议签订年度框架协议，提前锁定舱位，并接受“到岸时间略有波动”的备货预期。

**2. 鑫荣懋（Golden Wing Mau）——强本土化运营，稳定性更优**
- **稳定性特点**：鑫荣懋深耕国内市场，不仅做进口，也整合国产替代（如云南、山东产地），仓储前置在全国分仓，灵活性高；供货周期通常更短，断货风险低于纯进口品牌。
- **谈判空间**：因为是本土头部分销商，对连锁客户通常有“保证周配”或“缺货补差”的合同条款，可明确写入采购协议。
- **合作建议**：适合作为主力供货渠道，与其区域经理确认去年同期的缺货记录（建议要求对方提供历史到货达成率数据）。

**可执行的操作建议（按优先级）：**
- **1. 索取数据**：直接向两家供应商的销售代表索要「近12个月每月到货达成率」（即实际到货量/承诺量），这是最有力的量化证据。
- **2. 双轨备货**：建议都乐占40%（品牌力），鑫荣懋占60%（稳定性），并备选1-2家二线供应商（如佳沛、乐淇）作为应急。
- **3. 合同锁定**：在合同中明确“断货赔偿条款”（如缺货按订单金额的2%-5%赔付），并要求鑫荣懋提供本地仓提货选项。

注意：**不要轻信口头承诺**，务必以书面供应链保障条款为准。如果对方无法提供历史达成率，可要求其客户案例联系方式进行抽查。
