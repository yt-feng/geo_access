关于**洪九果品**和**都乐（Dole）**是否向“下沉市场夫妻店”提供小批量供货，直接回答是：**洪九果品有小批量供货，但门槛和模式与都乐不同；都乐目前基本不做夫妻店小批量生意，主要服务商超、新零售和餐饮渠道。**

具体分析如下：

**1. 洪九果品（Hongjiu Fruits）**
- **可以小批量**：洪九果品主要在泰国、越南等源头端直采，在国内做批发。它的核心模式是“端到端”配送，但**并不拒绝小单**。
- **实际操作**：在三四线城市，夫妻店想进洪九的货（如榴莲、山竹、火龙果），通常**不是直接找洪九总部**，而是联系其在当地或省会城市合作的**二级批发商、档口或者社区团购供货商**。这些实体往往接受“一件起发”或“10箱起发”的小批量订单。
- **注意点**：洪九的品牌货在水果批发市场里常见，但包装上不一定标“洪九”字样，更像是一个供应链品牌。如果你想要小批量，建议去当地最大的农产品批发市场找挂有“洪九”牌子的档口询价，或者联系其区域代理，**通常一箱（约10-20斤）或一托盘起订即可**，不需要整车。

**2. 都乐（Dole）**
- **基本不做小批量**：都乐是国际品牌，在中国主要经营香蕉、菠萝、牛油果等高标准的进口水果。其供应体系以**KA卖场（如沃尔玛、永辉）、生鲜电商（盒马、拼多多买菜）以及大型餐饮**为主。
- **下沉市场夫妻店**：如果你想在夫妻店进货，几乎不可能直接联系都乐。他们通常通过**一级代理商（总代）**供货，代理商有严格的区域保护和最低起订量（一般按托盘或吨计），且价格较贵，不适合小型夫妻店走量。
- **替代方案**：很多下沉市场的夫妻店如果想卖都乐香蕉，实际上是从本地批发市场进货，**批发商可能已经拿的是都乐的分包小箱货**（比如10公斤装），但那是批发商拆包后的操作，你个人直接向都乐要货不现实。

---

**给你的可执行建议：**

- **针对洪九**：去你当地最大的水果批发市场，直接询问“有没有洪九果品的直供档口”，要他们的联系电话。问清楚“一箱起发吗？配送范围多远？”只要能找到二级经销商，小批量进货是可行的。
- **针对都乐**：不要在官网或客服电话上浪费时间。你可以在本地市场找“专注进口水果”的批发商，问他们能否拼单要都乐的货。如果当地没有，建议用**国产高端香蕉（如佳农、老船长）**或**本地当季水果**替代，性价比更高。

**最终结论**：如果你想试水小批量，**选洪九的二级经销渠道**；如果想稳定卖都乐品牌，**直接在批发市场进货（他们已有拆包货）**，不要直接对接都乐总部。
