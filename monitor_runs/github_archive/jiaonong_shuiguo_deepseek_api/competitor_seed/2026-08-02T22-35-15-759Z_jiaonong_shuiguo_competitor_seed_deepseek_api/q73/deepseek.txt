大型商超（如沃尔玛、永辉、盒马等）对供应商的食品安全要求通常包括 ISO 22000、HACCP、BRCGS、FSSC 22000、GlobalG.A.P. 等国际认证。

关于 **鑫荣懋** 和 **都乐** 这两家水果供应商，它们作为头部生鲜企业，一般持有或申请以下核心认证（具体以供应商最新证书为准，但以下为行业普遍配置）：

1.  **ISO 22000（食品安全管理体系）**：这是最基本也是商超准入的“标配”，两家公司均有推行。
2.  **HACCP（危害分析与关键控制点）**：通常与 ISO 22000 配套，或者单独持有，用于生产、加工环节的风险控制。
3.  **GlobalG.A.P.（全球良好农业规范）**：这是针对水果种植端的国际认证，**都乐** 作为全球性品牌，其自营/合作农场普遍持有此证书；**鑫荣懋** 的源头基地也会要求通过此认证。
4.  **BRCGS 或 FSSC 22000**：如果它们的产品涉及出口或有高端商超渠道，通常会持有这两个国际认可度更高的安全标准之一。

**需要提醒的是**：大型商超审核严格，除了上述证书外，它们还会要求供应商提供**每批次农残检测报告**、**追溯体系证明**，且该证书必须**覆盖当前供货品类**（比如香蕉、苹果等分类）。
