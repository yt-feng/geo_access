关于都乐（Dole）和鑫荣懋（Xinrongmao）菠萝的**具体到货损耗率数字**，我无法提供精确的官方数据（这类数据通常为内部采购协议或季度统计，且受季节、运输距离、包装方式影响极大）。

不过，根据茶饮行业采购实践，可以给你一个可供参考的**行业基准范围**，以及**如何确认和谈判损耗率**的建议：

**1. 行业经验参考值（非官方承诺）**
- **都乐（Dole）**：作为外资品牌，其鲜果标准化程度高，包装缓冲较好（通常使用珍珠棉网套）。在冷链运输正常情况下，**到货损耗率一般在 3% - 5%**（指外表皮轻微擦伤，不影响内部果肉）。
- **鑫荣懋（Xinrongmao）**：作为国内头部果企，其菠萝多用防震纸箱或带孔周转箱。损耗率同样受“到货硬度”影响，若采用**非冷链**（常温）运输，损耗率可能上升到 **5% - 8%**。若采用冷链，则通常控制在 **3% - 6%**。
- **注意**：如果采购的是**催熟过度**或**雨天采摘**的菠萝，损耗率可能超过10%，这种情况下应直接拒收。

**2. 关键判断逻辑（比数字更重要）**
- **损耗率≠瑕疵率**：行业内除“烂心、发霉”外，表皮轻微压痕通常按**合理损耗**处理，不计入赔付。你需要和供应商明确“表皮破损超过几厘米算作超耗”。
- **两种采购模式损耗不同**：
  - **产地直采+冷链**：损耗低（2-4%），但起订量大。
  - **一级市场调拨（如江南市场）**：损耗波动大（5-10%），因为中间环节多。

**3. 建议你立即执行的动作（用于谈判和合同）**
- **索要“到货验收报告”**：让两家供应商各自提供近3个月的**同门店、同配送距离**的实际损耗统计数据（要求按箱数计）。
- **合同中设定“跌价补偿”条款**：例如约定“若单箱损耗率超过8%，超出部分按市场单价1.2倍赔偿，且冲抵下次货款”。
- **实测验收**：建议先各采购100箱，到货后当面开箱，记录：A. 烂心数；B. 压伤超过30%的个数；C. 果柄断裂数。对比后选择数据更优的一方，而不是直接相信宣传。

**核心结论**：不要相信“纸面损耗率”，**官方渠道不会公开承诺具体数字**。采购时，请务必要求**附上质检报告和到货实拍视频**，并把“损耗率上限”以合同条款形式固化下来。如果需要，我可以帮你起草一份损耗争议处理条款。
