关于都乐（Dole）和洪九果品的具体账期政策，由于合同条款、采购量、合作年限、结算方式等因素差异较大，**官方通常不会公开统一账期**，需与销售经理直接洽谈。

不过，根据行业惯例和公开信息，可提供以下参考：

1. **都乐（Dole）**：作为国际大型果蔬供应商，通常对大型商超、连锁渠道提供 **月结30天（收货后次月对账，第三个月付款）** 或 **月结45天** 的账期。中小客户或首单合作，通常要求**现款现货**或预付部分定金（如30%-50%）。
   
2. **洪九果品**：国内头部水果供应链企业，渠道覆盖广。对优质长期客户，一般可谈至 **月结15-30天** 或 **走货后45天内结清**。小批量采购或新客户，多为现款或短期账期（7-15天）。

**建议路径：**
- 直接致电两家公司大客户部或区域销售经理，明确告知年采购量、合作频率、是否为连锁终端，索取书面报价单及账期方案。
- 可参考行业通行条款，要求出示“对账周期+付款节点”白纸黑字，并要求优惠（如现款可折让1-2%）。
- 若涉及进口香蕉，还需确认账期是否与海运到港、清关周期联动。
