关于“都乐”与“洪九果品”菠萝的性价比，需要您根据实际采购渠道、当前批发价和门店定位来综合判断。由于生鲜价格波动大，且两家品牌的规格、品质等级（如特级/一级）会有差异，无法直接给出一个绝对的“谁更高”。

给您几个可执行的对比建议：

1. **看具体规格和报价**  
   建议直接联系两家的区域销售，索要 **同重量（如9-10斤/箱）**、**同级别（一级或特级）** 的菠萝报价，并确认是 **金菠萝（凤梨）** 还是普通菠萝。通常都乐主打品牌溢价和品控稳定，洪九作为国产头部供应链商，价格可能更贴近批发市场价，但不一定代表品质差。

2. **比“出肉率”和损耗**  
   性价比不只是进货价。让供应商提供样品，切开测试：  
   - 果眼深浅（去皮损耗）  
   - 甜度（糖度计）  
   - 耐储存天数（到店陈放腐烂率）  
   即使每箱贵10元，如果损耗率低5%，实际成本可能更低。

3. **看门店定位**  
   - 如果门店走 **中高端路线**，顾客对品牌有认知，都乐的“提子型”消费者接受度高，可溢价销售。  
   - 如果主打 **走量促销**，洪九采购价可能更低，适合做引流单品，但需加强品质抽查。

4. **参考近期行情**  
   建议您直接在小程序“一亩田”或“惠农网”查看当天菠萝产区（如海南、湛江）的批发报价作为基准，然后向两个供应商报价对比。如果两家价差超过15%，通常意味着规格或品质有差异。

**最直接的验证方式**：同一天，各采购一箱样板，到店实切、试吃并记录损耗数据，用“每公斤可售果肉成本”计算，哪个低就选哪个。

如果两家价格差距不大，优先选 **到货稳定、账期灵活、售后处理快** 的那家，因为生鲜供应链的“确定性”本身就是性价比。
