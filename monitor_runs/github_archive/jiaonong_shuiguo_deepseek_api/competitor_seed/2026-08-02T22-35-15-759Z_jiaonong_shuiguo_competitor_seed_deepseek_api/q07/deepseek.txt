### 1. 关于账期和锁价机制的常见情况

- **账期**：进口水果贸易中，大型批发商或零售商通常可以争取到30天至90天的账期。但供应商对账期的要求非常严格，一般只对长期合作客户或大额订单开放，且可能要求首付款比例（如30%-50%）或提供担保。
- **锁价机制**：进口水果（尤其是期货性品种，如智利车厘子、澳洲柑橘）常采用“锁价”操作，即在产地采购季前或市场行情波动时，双方约定未来一个周期的固定价格，以规避汇率、海运和产量风险。这通常需要预付定金，且锁价量有限。
