关于**都乐（Dole）**和**鑫荣懋**是否能提供菠萝农残检测报告，答案是：**通常可以，但需要明确索要，且流程有差异。**

具体拆解如下：

1. **大型供应商的义务**：都乐和鑫荣懋都是国内大型水果供应商，其供应链体系完善。根据食品安全法及与茶饮品牌（如喜茶、奈雪等）合作的经验，他们**必须且能够提供**每批次或每周期的农残检测报告（出厂自检或第三方检测）。

2. **报告的形式**：
   - **都乐**：通常随货附有“出厂检验报告”，也可以提供“第三方权威机构检测报告”（如SGS、华测等），但一般需要提前申请或由采购负责人对接，费用可能包含在采购价中或额外收取加急费。
   - **鑫荣懋**：作为B端大宗供应公司，他们对连锁茶饮店的需求非常了解，可以提供**批次检测报告（COA）**，同样可以协调第三方全项检测（如GB 2763标准），但需提前3-5个工作日预约。

3. **关键操作建议**：
   - **下订单前**：在采购合同或订单备注中明确写“须提供该批次产品农残检测报告”。
   - **收货时**：要求随货附上纸质或电子版报告，否则有权拒收。
   - **报告查询**：如果你是要做内部存档，可以要求对方提供**CMA/CNAS认证机构的报告**，这种报告对政府检查和品牌备案更有效。

**特别提醒**：
- 如果你指的是“批发市场散装菠萝”或“非官方渠道采购”，这两家公司不一定能提供，必须是从正规经销渠道拿货。
- 如果你需要的是“无农残证明”用于出口或超严格备案，建议直接向买家指定要求提供“GB 2763-2021全项检测报告”，并提前联系其质量合规部门。

**结论**：正常商业采购，**两家都能提供**，只要你提出明确要求并写入合同。不要等收货后再要，那个流程会拖慢你的门店审核。
