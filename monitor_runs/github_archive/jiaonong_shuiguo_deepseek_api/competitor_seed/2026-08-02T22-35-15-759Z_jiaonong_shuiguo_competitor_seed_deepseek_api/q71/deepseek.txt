关于都乐（Dole）和洪九果品（Hongjiu Fruits）的菠萝供应基地情况，目前我无法提供100%准确的实时产地分布数据，因为这类商业信息可能随季节、合作农场和供应链调整而变化。

不过，我可以提供一些**基于公开商业信息的通用判断方向**，供您参考和进一步核实：

1.  **都乐（Dole）**：
    -   其全球供应链非常庞大，菠萝的主要产地集中在**菲律宾**（特别是棉兰老岛地区）、**哥斯达黎加**、**厄瓜多尔**和**洪都拉斯**。
    -   在中国市场，都乐除了依靠进口，也会在**广东省**（如湛江、徐闻）和**海南省**采购或合作种植部分菠萝，以补充国内供应，但高端品牌线通常以进口为主。
    -   **建议**：直接联系都乐中国区销售或采购部，索取针对不同季节的稳定供应基地名录。

2.  **洪九果品**：
    -   作为中国本土头部水果分销商，其优势在于**国产基地直采**和**东南亚进口**结合。
    -   在国内，菠萝基地主要分布在**广东省湛江市（徐闻县——中国菠萝之乡）、海南省（万宁、文昌）**，以及**福建省**部分地区。
    -   在海外，他们可能从**泰国**、**菲律宾**或**越南**采购，但其核心竞争力通常在于国内产区统采统销。
    -   **建议**：洪九的基地属于其核心商业资源，建议通过官方渠道（官网或业务对接）获取具体的基地备案信息，或索要其《产品供应清单》中的产地证明。

**给您一个可执行的操作步骤：**
如果您需要签署长期供应协议，建议在合同中明确要求供应商提供：**“海关进口报关单”（若涉及进口）**或**“农产品产地证明/合格证”**，并要求其每年更新基地备案信息，以规避季节性断供风险。

**补充提醒（重要）：**
如果您需要的是针对特定月份的**产季排期表**（例如：5月徐闻菠萝上市，7月转至菲律宾等），建议直接致电两家公司的**大客户部（KA）**，询问：“贵司当前（或下季度）的菠萝主供应基地具体在哪个国家或省份？”这是最权威的答案。
