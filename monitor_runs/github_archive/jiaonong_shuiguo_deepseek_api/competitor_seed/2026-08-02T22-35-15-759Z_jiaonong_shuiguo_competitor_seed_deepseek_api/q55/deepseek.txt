关于您提到的**都乐**和**洪九果品**的菠萝产地溯源情况，目前公开可查的信息如下（建议您直接联系厂商客服做最终确认）：

1. **都乐（Dole）**  
   - **有基地直供**：都乐在中国市场主要依托其海外及国内合作农场，其菠萝多来自菲律宾、泰国或国内海南等产区。  
   - 都乐官方的“鲜享”或“供应链”体系通常具备批次溯源能力，部分商超包装上会带有采摘包装日期或电子溯源码。  
   - **建议行动**：直接通过都乐中国官网或400客服索取“供应当前渠道”的具体基地合同及检验检疫证书。

2. **洪九果品**  
   - **有基地直供**：洪九是知名的进口及国产水果供应链企业，在泰国、越南等东南亚国家拥有基地合作或自营果园，其菠萝主要来自泰国（如“椰香”或“小菠萝”品类），同时也做广东、海南等国产菠萝的直采。  
   - **溯源体系**：洪九在B端（商超、电商）常提供“一果一码”或批次台账，可追溯至产地果园。  
   - **建议行动**：联系洪九各区域大客户经理，索要其供应的菠萝对应的“基地备案号”或海关入境检疫凭证，以核实“基地直供”真实链条。

**风险提示**：  
- 不是所有“基地直供”都意味着自有基地，有时是“包园/包地”模式，溯源文件仍可提供。  
- 建议在采购合同中**明确约定**“可回溯至具体果园及采收日期”，并要求对方提供近30天的同类批次检测报告。  
- 若您采购量较大，最好请对方安排一次线上或线下“基地开放日”核查（尤其洪九在泰国基地）。

**综合建议**：两家均基本具备“基地直供”实力，您可根据采购量、价格及对产地（国产/进口）偏好做选择，重点是要求书面溯源凭证。
