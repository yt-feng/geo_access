关于**都乐（Dole）**和**洪九果品**的水果礼盒定制起订量，目前并没有公开的统一标准数字。起订量通常根据**季节、果品品类、定制复杂程度（是否印logo、包装规格）以及采购方资质**有较大差异。

以下是根据行业惯例给出的**参考范围**和**建议做法**，请以最终商务洽谈为准：

**1. 都乐（Dole）**
- **参考起订量**：通常为**100盒起订**（视具体SKU），如果是大批量团购（如企业福利），一般**500盒以上**会获得更优惠的定制和服务支持。
- **特点**：品牌溢价较高，包装多以标准化为主，深度定制（如完全更换礼盒设计）成本较高。
- **建议**：直接联系都乐中国团购部，报出你的采购数量（如200盒/500盒），他们通常可以灵活调整。

**2. 洪九果品**
- **参考起订量**：相对更灵活，通常**50盒起订**即可接定制（尤其是有采购协议或长期合作时）。
- **特点**：主打高性价比和产地直供，起订门槛通常低于都乐，且更愿意配合定制包装（如加印公司LOGO、写祝福语）。
- **建议**：官网或通过业务员询价，明确告知是“礼盒定制”而非“散货”，通常200-300盒就能获得较好价格。

### 给你的落地建议（重要）：
1. **不要只问起订量**，要同时问：
   - 含不含**定制礼盒设计费/打样费**？
   - 起订量内包含几种水果组合？
   - 是否可以**按节前急单**加急生产？
2. **打样确认**：先要求寄1-2个**样品礼盒**看实物，确认干冰/保鲜措施和包装质量。
3. **比价策略**：两家都询价，用**“我有具体数量（比如300盒），请给我含定制logo、含配送的最终报价”**，拿报价单对比。
