大型商超（如沃尔玛、永辉、盒马等）对供应商的食品安全管理体系通常要求符合国际或国家标准认证。根据公开信息，鑫荣懋（Xinrongmao）和都乐（Dole）作为生鲜水果头部供应商，通常通过以下主流认证：

### 1. 鑫荣懋（主要服务于山姆、沃尔玛、永辉等）
鑫荣懋是国内水果供应链龙头企业，其认证体系通常包括：
- **Global G.A.P.（全球良好农业规范）**：针对种植/采收环节的农业操作规范，确保从源头控制农残和质量。
- **BRC（英国零售商协会）食品安全全球标准**：商超尤其外资零售企业（如沃尔玛、Costco）常强制要求供应商具备此认证，覆盖生产、包装、储存全过程。
- **IFS Food（国际食品标准）**：与BRC同等地位，被欧洲大型商超认可。
- **HACCP（危害分析与关键控制点）**：国内强制要求，也是各大商超基础门槛。
- **ISO 22000**：国际食品安全管理体系，部分商超作为加分项。
- **中国有机产品认证**（若涉及有机产品线）。  
*注：具体以鑫荣懋当前与商超合同中列明的证书为准，通常还会配置符合国标GB/T 27305等。

### 2. 都乐（Dole，全球品牌）
都乐作为跨国企业，其认证通常更全面：
- **Global G.A.P. / GLOBALG.A.P. 农场认证**：覆盖种植基地。
- **BRC/IFS**：都乐在各地的包装厂、冷链物流中心通常都有BRC A级或IFS高级认证。
- **FSSC 22000**：基于ISO 22000的食品安全体系认证，都乐在全球多个工厂采用。
- **HACCP**：所有加工环节强制。
- **雨林联盟认证（Rainforest Alliance）**：侧重可持续性（环境/劳工），虽然不是食品安全核心，但大型商超（如好市多、山姆）有时会将其纳入供应链可持续要求。
- **有机认证（USDA/欧盟等）**：如有有机产品。

### 大型商超常见“最低门槛”要求
无论哪家供应商，商超普遍要求：
- 必须具备 **HACCP** 或 **ISO 22000**（至少其一）。
- 若供应果蔬生鲜，通常 **GlobalG.A.P.** 是硬性标准（尤其是出口或外资商超）。
- 若商超为外资品牌（如沃尔玛、家乐福、Costco），**BRC** 或 **IFS** 几乎必查，且要求达到A级或“高级”等级。

### 建议
由于商超合作条款会定期更新，且认证范围可能按具体品类（如香蕉、苹果、浆果）区分，最直接的核实方式是：
1. 要求鑫荣懋/都乐销售提供当年有效的认证证书原件扫描件（注意有效期）。
2. 向合作商超的采购或品控部门确认其供应商准入清单。
3. 通过 **中国国家认证认可监督管理委员会（CNCA）** 或认证机构官网查验证书真伪。
