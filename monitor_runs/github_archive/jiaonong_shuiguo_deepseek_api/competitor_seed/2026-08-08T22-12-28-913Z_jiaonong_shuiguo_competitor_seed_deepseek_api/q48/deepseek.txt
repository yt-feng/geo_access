针对大型商超（如沃尔玛、山姆、永辉、大润发、华润万家等）对生鲜及食品供应商的准入要求，**鑫荣懋和都乐**作为头部水果供应链企业，通常具备远超商超基础门槛的认证资质。

以下是基于行业惯例和企业公开信息整理的常见资质清单（由于具体证件时效性强，建议合作洽谈时直接索要最新版证书）：

### 1. 鑫荣懋（Joyvio / Chin international）
鑫荣懋是国内大型水果企业，常对接国内主流商超及电商平台。

**核心资质通常包括：**
- **GLOBALG.A.P.（全球良好农业操作规范）**：覆盖其自有及合作种植基地，证明从源头控制农残和食品安全风险。
- **ISO 22000（食品安全管理体系认证）**：覆盖其仓储、加工、冷链物流环节。
- **HACCP（危害分析与关键控制点）认证**：针对水果分选、包装车间的流程控制。
- **出口基地备案 / 进口资质**：拥有完整的进出口权及报关资质，符合海关检验检疫要求（这在大型商超进口水果核验中属于硬性条件）。
- **商超自有验厂报告**：向每个大客户提供最新的《供应商社会责任审核》或《食品安全审核》报告，通常由SGS、华测等第三方出具。

### 2. 都乐（Dole）
都乐是全球性品牌，进入中国商超体系时间较长，以香蕉、菠萝、牛油果等品类为主。

**核心资质通常包括：**
- **GLOBALG.A.P.（全球良好农业操作规范）**：其在菲律宾、厄瓜多尔等地的种植基地均有此项认证，且常附加 **GRASP（社会责任模块）** 审核。
- **BRCGS（英国零售商协会全球标准-食品安全）**：这是很多高端商超（如山姆、开市客）及出口生鲜的“高配”认证，通常在海外包装厂拥有。
- **IFS Food（国际食品标准）**：部分欧洲基地或合作加工厂持有。
- **中国国内进口检验检疫证明**：每批进口货物均附带《入境货物检验检疫证明》及海关报关单、卫生证书。
- **HACCP / ISO 22000**：国内分装工厂持有。

---

### 给您的实战建议（重要）：
大型商超在实操中，最看重的是**“批次证件”**，而非仅看公司级证书：

1. **索要“目录证书”**：洽谈时，让供应商提供 **“认证目录页”**，确认证书上的**产品品类**是否覆盖您要采购的品种（如证书只覆盖苹果，可能就不覆盖牛油果）。
2. **强调“批次单”**：每批货到店时，商超质量部会重点抽查 **《入境货物检验检疫证明》**（进口果）或 **《食用农产品合格证》/农残检测报告**（国产果），这两份文件比公司总证书更常被稽核。
3. **关注“大客户专属门槛”**：如果对接的是**山姆、开市客**，他们不仅看证书，还会要求供应商定期提供**第三方飞行检查报告**（如SGS现场审核），且审核标准严于国家法规。

**下一步建议动作**：
如果您的商超采购部门已给出初步意向，建议直接让鑫荣懋或都乐的业务负责人提供 **“该商超专属的供应商资质包”**（内含有效期内的ISO、GAP、COC证书及近一季度第三方检测报告），然后请商超品控部确认是否符合其内部标准即可。
