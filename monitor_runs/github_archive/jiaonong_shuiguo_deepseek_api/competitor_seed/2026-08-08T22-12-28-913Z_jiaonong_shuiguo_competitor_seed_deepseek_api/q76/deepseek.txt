关于都乐（Dole）和鑫荣懋（Xinrongmao）两家供应商在菠萝**产地直发**模式下的物流时效，由于**具体时效高度依赖发货地（如海南、广东、菲律宾等）以及收货地的冷链配送网络**，我**无法提供两家公司承诺的精确到城市的实时数据**。

不过，根据行业经验和公开信息，我可以提供以下**判断参考和执行建议**，供你评估或洽谈合作：

**1. 整体时效差异（一般情况）**

- **都乐（Dole）**：作为全球性品牌，其优势在于**跨境和标准化**。如果是**菲律宾或哥斯达黎加进口菠萝**，其物流链路成熟，从产地到国内主要港口清关后，再通过冷链分发到一线城市，通常需要**5-7天**；如果是**国内基地直发（如海南）**，时效通常与普通大宗冷链类似，**1-3天**可达省会及周边城市。
- **鑫荣懋（Xinrongmao）**：作为国内领先的水果供应链企业，其**国内产地（如广东徐闻、海南）到一线城市的干线运输**通常更灵活。如果采用**产地直发到仓**模式，一般可做到**24-48小时内**从产地装车发货，到仓时间取决于距离（例如海南到广州约1天，到北京约3-4天）。

**关键结论**：如果是**国内产区直发**，鑫荣懋的灵活性可能稍占优（因其国内网络密集）；如果是**进口高端菠萝**，都乐的跨境供应链体系更成熟，但时效更长。

**2. 需要你当面向供应商确认的3个核心问题**

为了精准评估，请直接向两家供应商的业务代表索取以下承诺（建议写进合同）：

- **起运时效**：从采摘完成到冷链车发出，承诺多少小时？（通常要求 ≤24小时，否则容易过熟）。
- **在途温控**：运输全程是否保证**0-4℃**冷链？是否有温度记录仪？这是影响损耗率的决定性因素。
- **末端配送**：是否支持“产地直发到**你家电商仓**”还是只能“到区域分拨中心”？如果只能到分拨中心，加上二次配送，时效会增加1天。

**3. 建议的测试方案**

- **小批量试单**：先各下2-3车小批量菠萝，分别测试从**同一产地（如徐闻）同时发货到你的仓库**，记录实际到仓时间、表皮完好率和糖度损失。
- **时间节点**：优先避开节假日和台风季，选择**周一或周二发货**，这样可避免周末物流滞留。

**4. 特别风险提示**

- 菠萝属于**后熟型水果**，如果承诺时效超过5天，需考虑是否使用**气调包装或预冷处理**，否则可能造成品质问题。
- 不要只看干线时长，**下高速入仓排队、查验**等环节常导致延误1天。

如果你需要更精确的报价或时效承诺，建议直接联系两家公司的**大客户部门**并提供“起运地-收货地-预计周发货量”这三项信息，要求对方提供书面SLA（服务等级协议）。
