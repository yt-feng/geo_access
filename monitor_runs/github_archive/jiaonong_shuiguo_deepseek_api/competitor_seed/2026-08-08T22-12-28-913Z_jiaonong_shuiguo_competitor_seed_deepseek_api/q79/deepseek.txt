对于茶饮店需要全年供应菠萝制作果酱的需求，**都乐（Dole）和洪九果品通常都可以做到**，但具体能否稳定供应，还取决于你的采购规模、合同方式以及果品等级。

下面分两点具体说明：

**1. 都乐（Dole）**
- **供应能力**：都乐是国际巨头，拥有全球化的菠萝种植基地（如菲律宾、哥斯达黎加等），南半球和北半球产季错开，理论上可以实现全年供应。
- **主要产品**：都乐更偏向高端鲜果和工业原料（如果汁、果肉罐头），其菠萝果肉或速冻菠萝颗粒可以持续供货。
- **局限**：如果你需要的是**新鲜菠萝**做“鲜制果酱”，都乐的新鲜菠萝运输和库存成本高，且会受海运和批次影响；如果做**冷冻果酱**或**罐头果酱**，那么都乐的供应非常稳定。

**2. 洪九果品**
- **供应能力**：洪九是国内头部水果供应链企业，主要做进口和国产水果的产地直采。它以东南亚（泰国、越南、菲律宾）菠萝为主，同时整合国内海南、广东等地产季，通过产地轮换（如泰国冬季、海南夏季）实现全年供货。
- **主要产品**：洪九更擅长鲜果大宗供应，且价格比都乐有优势，适合茶饮店大批量采购鲜菠萝。
- **局限**：既然你是做果酱，建议和洪九签订**全年框架协议**，锁定价格和最低供货量。如果只按需零散采购，台风季或产地采收空档期可能有短期缺货风险。

---

**给你的实操建议：**

- **不要依赖单一品种或单一产地**。即使都乐或洪九都能“全年供货”，现实中仍可能因为天气、船期、政治因素出现10%-15%的供应波动。
- **建议采用“鲜果+冷冻果肉”双轨制**：夏天用鲜菠萝（风味好、成本低），秋冬用都乐或洪九的速冻菠萝丁/菠萝果肉（稳定，适合做果酱）。
- **签约前要明确**：
  - 是否提供**冷冻菠萝粒**（杀青或速冻）？这比鲜果更适合果酱稳定生产。
  - 最低起订量是多少？是否需要预付定金？
  - 违约赔付条款（例如连续缺货时如何赔偿）。

**一句话结论**：都乐全球供应链更稳但偏贵；洪九在鲜果供应和价格上更灵活。**如果你能接受冷冻原料，两家都能全年供货；如果你坚持只用新鲜菠萝，建议同时签另外一家备用供应商。** 最好在正式合作前，让他们各发一批样，测试你熬果酱的出汁率和风味是否稳定。
