关于菠萝的到货损耗率，不同供应商、不同季节、不同运输距离和包装方式会有明显差异，**目前没有公开统一的固定数值**。

不过，根据行业内的普遍经验和水果供应链的常见标准，可以给你一个参考区间：

1.  **都乐（Dole）**：作为跨国品牌，其冷链和标准化程度较高。在夏季高温或长途运输下，损耗率一般在 **3%~5%**；如果是短途或品质特别好的批次，可以控制在 **2%~3%**。
2.  **鑫荣懋**：作为国内头部水果供应链企业，其损耗控制通常与都乐接近。常规情况下，到货损耗率多在 **3%~6%** 之间；若是需要催熟或二次分拣的批次，损耗可能略高至 **5%~8%**。

**给你的实操建议**：

- **不要只看“损耗率”**，更要看“**可利用率**”。茶饮店用菠萝通常只需果肉，去皮的损耗（冠、皮、芯）本身就要占30%以上，供应商的“到货损耗”只指**果体腐烂、压伤、变质**的部分。
- **一定要在合同里写清楚**：**“到货后12小时内开箱验收，腐烂率超过X%（建议写3%）允许拒收或按比例扣重”**，并且要附上开箱视频作为凭证。
- **季节差异**：冬季菠萝（如徐闻、海南反季节）损耗较低，但如果是夏季高温或遇到云南边境雨期，损耗会明显上升。
