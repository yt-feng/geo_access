大型商超（如沃尔玛、山姆、永辉、盒马等）对供应商的食品安全管理体系要求通常非常严格，必须具备**国际公认的食品安全认证**。鑫荣懋（XinRongMao）和都乐（Dole）作为国内水果行业的头部供应商，主要认证体系如下：

### 一、鑫荣懋（XinRongMao）
鑫荣懋是国内大型水果供应链企业，其认证体系覆盖国际和国内双标准，核心包括：

1.  **GLOBALG.A.P.（全球良好农业操作规范）**：这是全球认可度最高的农业标准，确保农场端的安全、可持续和可追溯。
2.  **BRCGS（英国零售商协会全球标准）**：尤其是**BRCGS Food Safety（食品安全）**，是大型商超（如沃尔玛、Tesco）进入其供应链的硬性门槛。
3.  **ISO 22000（食品安全管理体系）**：国际通用的管理体系认证。
4.  **HACCP（危害分析与关键控制点）**：在加工和分拣环节实施的预防性食品安全体系。
5.  **中国良好农业规范（China GAP）**：国内市场的必备证书，尤其用于对接国内大型连锁商超。

**补充说明**：鑫荣懋近年特别强调“从产地到货架”的全链路可追溯系统，其认证文件通常以英文双语呈现，便于国际商超审核。

### 二、都乐（Dole）
都乐是全球最大的新鲜果蔬品牌之一，其认证体系在跨国商超（如Costco、山姆）中认可度极高，主要包括：

1.  **GLOBALG.A.P.**：覆盖全球自有或合作农场的种植端认证。
2.  **BRCGS Storage & Distribution** 或 **BRCGS Packaging**：针对其仓储、冷链和包装环节（这是许多纯种植商不具备的优势）。
3.  **ISO 9001（质量管理体系）**：虽非食品安全专用，但作为全球运营的基础质量管理。
4.  **SQF（安全质量食品）认证**：这是北美（尤其是美国）商超极为看重的认证，其标准被GFSI（全球食品安全倡议）认可。
5.  **HACCP**：在加工、催熟环节普遍实施。

**特别注意**：都乐在应对商超审核时，通常会主动提供**年度第三方审计报告（如SGS或Intertek出具）**，并开放农场端视频验厂，以确保采购方通关。

---

### 给您的建议：
如果您是代表某大型商超进行验厂或审核：

- **优先查验**：两者是否持有有效的**GLOBALG.A.P.证书**（证明源头安全）和**BRCGS食品认证**（证明加工/分拣安全）。
- **注意有效期**：上述认证（如GLOBALG.A.P.）均有明确有效期（通常1-3年），需核对截止日期。
- **现场核查**：商超采购经理通常会重点检查**农残检测报告**（是否按国标或欧盟标准）、**追溯码系统**（如香蕉、苹果的批次溯源）和**冷链温度记录**。

若您需要具体的**证书编号**或**最新版证书扫描件**，建议直接向两家公司的**质量合规部（QA/QC）**索取，因为这类信息属于商业动态资料，不适宜在公开渠道完全披露。
