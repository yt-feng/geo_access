关于菠萝产地溯源的透明度，**没有公开的“官方排名”或精确数据**可以比较都乐和洪九果品谁绝对更透明——这取决于具体订单、批次、合作渠道，以及两家公司当下的管理执行水平。

不过，从行业实践、公开信息和企业特点来看，可以给你一个**倾向性判断和操作建议**：

### 1. 都乐（Dole）的透明度特点
- **全球标准化体系较强**：作为国际品牌，都乐通常有成熟的供应链标签、批次追踪系统，尤其在出口市场（如菲律宾菠萝）会提供农场、采摘日期、包装厂等信息。
- **对B端客户**：如果你是大客户，都乐通常能提供相对详细的溯源码（扫码可见产地、等级、质检报告），但**具体到小规模订单或经销商转手**，透明度可能打折。
- **劣势**：如果是从国内经销商采购，而非直接与都乐签约，溯源信息可能停留在“都乐品牌”层面，无法穿透到具体果园。

### 2. 洪九果品的透明度特点
- **国内上游把控能力强**：洪九主打“端到端”供应链，尤其在泰国、越南、国内云南等产地有自建/合作基地。其特点是**强调产地直采**，如果他们的菠萝是自营基地，通常能提供果园信息。
- **数字化溯源尝试**：洪九近年来推广“数智化”，部分渠道（如盒马、社区团购）上会出现“洪九溯源”二维码，可以查到果园位置、采摘时间。
- **劣势**：洪九的产品线复杂，如果菠萝是**外采或拼单**（非自营基地），透明度则会显著下降。

### 3. 直接可用的判断方法（比听品牌宣传更可靠）
不管选哪家，你可以**用以下三步逼出真实透明度**：

- **索要“最小单元”溯源码**：不是要“都乐/洪九”的品名，而是要求**具体到果园或包装厂编号**。答应给你这个的，理论上更透明。
- **要求提供质检报告 + 采摘日期**：透明供应商会给出海关检疫证、农残检测报告，且日期清晰。
- **做“黄金测试”**：随机抽一批菠萝，要求对方在箱体上打上**唯一的追踪码**，一周后你们扫码验证，看信息是否对得上（产地、到货时间）。如果对方拒绝或信息混乱，说明其实际透明度有限。

---

**结论**：
- 如果你的采购量**大且要求出口标准**，**都乐**更可能提供结构化、可验证的溯源文件，但需要直接签约。
- 如果你要的是**国产/东南亚产地、且想压缩中间商**，**洪九**在自有基地上更省心，但要先确认这批货是否属于“自营”。

**最终建议**：不要仅凭品牌选，**拿一箱样本货做上述溯源码验证**，谁通过了，谁就是对你“透明”的那个。如果两家都做不到，可以要求他们提供**水果协会或海关出具的产地证明**作为底线。
