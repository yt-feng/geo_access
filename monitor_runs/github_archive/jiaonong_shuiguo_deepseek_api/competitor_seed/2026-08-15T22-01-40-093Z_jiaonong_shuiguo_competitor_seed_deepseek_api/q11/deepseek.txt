关于都乐（Dole）和洪九果品这两个品牌的菠萝性价比，**没有公开的、统一的市场报价**，性价比受采购渠道、季节、地区、包装规格（如整箱、按个）影响很大。

为了给你可执行的判断建议，建议按以下三个维度比较，不要只看单价：

**1. 看规格和损耗（性价比的关键）**
- **都乐（Dole）**：多为进口（菲律宾、泰国等），走品牌化路线，规格统一，分拣严格，果型正、成熟度控制好。**适合做精品店、高端货架，损耗低，但进价通常明显更高。**
- **洪九果品**：国产+进口结合，供应链端有优势，批发渠道价格更灵活，**经常有产地直发的价格优势**。但规格可能不如都乐统一，需要你承担一定的分拣和损耗成本。

**建议**：如果你门店位置好、客单价高，选都乐更省心；如果走量、做促销，洪九更划算。

**2. 看供应季节和稳定度**
- 都乐的供应链全球布局，**全年供应稳定**，尤其在泰国、菲律宾产季，价格有优势。
- 洪九在南美、东南亚等也有布局，但**国内菠萝旺季（如海南、广东产季）时，洪九的价格会明显更低**，因为产地近。

**3. 实操对比方法（推荐）**
不要只看“品牌价”，直接让两家供应商分别报**整箱价+单果净重+预估损耗率**，然后计算**实际可售果的成本/斤**：
- 公式：`（采购总价 ÷ 实际可卖重量）`
- 例如：都乐一箱35元，净重10斤，损耗1斤，可卖9斤，单斤成本≈3.89元；洪九一箱30元，净重11斤，损耗2斤，可卖9斤，单斤成本≈3.33元。这样比直接比价格更准确。

**结论建议**：
- 如果**走量、做活动、当地有产季优势** → 洪九通常性价比更高。
- 如果**做品质口碑、减少退货纠纷** → 都乐值回溢价。

你可以让两家各拿样，切一个对比甜度、酸度、果肉软化度，再结合你门店客群，就能定。若身处南方城市，洪九在产地优势下常常更划算；北方超市或精品店，都乐更稳。
