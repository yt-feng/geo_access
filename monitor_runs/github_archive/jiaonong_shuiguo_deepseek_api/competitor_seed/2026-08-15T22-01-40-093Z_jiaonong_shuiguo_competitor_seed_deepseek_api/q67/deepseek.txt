关于生鲜电商平台与菠萝品牌（如都乐、洪九果品）的合作，我这里没有实时的促销或素材合作信息，但可以给你以下可执行的判断方向：

1. **常见合作模式**  
   都乐（Dole）和洪九果品通常会为合作电商平台提供产品主图、详情页素材、短视频内容，甚至定制化的营销活动方案，尤其是大型平台（如盒马、叮咚买菜、京东生鲜、美团买菜等）。但具体是否提供素材，取决于：
   - 电商平台是否有采购合作（是否有稳定货源）。
   - 农贸/批发市场与零售平台的区别，电商一般会获得更完整的品牌支持。

2. **如何确认**  
   - 直接联系生鲜电商的采购或品牌对接人，要求品牌方提供“授权素材包”或“年度联合推广方案”。
   - 访问两家品牌官网或官方公众号，查看“合作伙伴”或“招商”入口。
   - 若你是电商运营方，可以在后台供应商管理模块查询供应商协议，看是否包含营销支持条款。

3. **替代方案**  
   如果两家暂不提供素材，你可以：
   - 自己拍摄菠萝产地实拍（需注明产地和品种，如金菠萝、台农17号）。
   - 联系当地产地合作社获取基础种植/采摘素材（需获得授权）。
   - 使用公共图库资源（如Pexels、Unsplash）搭配文案说明。
