关于您提到的**都乐（Dole）**和**鑫荣懋（Joy Wing Mau）**这两家供应商，他们都具备成熟的水果供应链体系，并且通常可以提供**产地溯源**和**品控证明**。不过具体能否获取、以何种形式提供，取决于您采购的渠道（大宗批发、商超直供还是电商），以及您所在的地区。

具体情况分析如下：

1. **都乐（Dole）**：
   - 作为国际巨头，其香蕉通常有明确的产地（如菲律宾、厄瓜多尔等），包装上会标注农场信息，并符合GlobalG.A.P.（全球良好农业操作规范）等国际认证。
   - 他们可以提供**批次溯源**（通过包装上的溯源码或提供产地证明文件）和**质检报告**，但通常需要通过其**官方销售团队或区域经销商**洽谈，个人或小批量采购较难直接拿到全套溯源文件。

2. **鑫荣懋（Joy Wing Mau）**：
   - 国内头部水果企业，主要供应国内商超和批发市场，其香蕉产地多为国内（如云南、广西）或进口（如越南、菲律宾）。
   - 他们通常能提供**产地证明**和**农残检测报告**，且因为服务商超，品控文件体系相对完善（如ISO9001、HACCP等认证），但同样需要您以企业客户身份与其销售对接，才能获得正式盖章的品控文件。

**给您的可操作建议：**
- **直接联系官方销售**：请通过都乐中国官网或鑫荣懋官网找到“企业客户/合作”入口，写明您需要的“溯源文件”和“品控报告”具体要求，他们会按流程提供。
- **确认文件类型**：您提到的“品控证明”具体是指农药残留检测报告（须注明检测机构）、植物检疫证书，还是产地备案证明？明确后更容易获得。
- **替代渠道（更稳妥）**：如果您是商超或餐饮采购，可以要求供应商在合同中写明“随货提供当批次溯源码和第三方检测报告”；如果是小批量，建议选择大型批发市场内有“绿色食品”或“有机”认证的档口，他们更愿意提供简易版溯源单。
