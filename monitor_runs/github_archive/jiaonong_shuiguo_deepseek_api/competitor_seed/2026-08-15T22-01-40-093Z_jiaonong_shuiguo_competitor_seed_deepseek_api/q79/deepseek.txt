对于茶饮店需要全年稳定供应菠萝制酱的需求，**都乐（Dole）和洪九果品（Hongjiu）** 这类大型水果供应商，在供应链和全年供应能力上是有可能做到的，但存在一定条件和局限性。

**1. 供应能力分析：**

- **都乐（Dole）**：作为全球性的水果巨头，菠萝是他们的核心产品之一。都乐在全球（如菲律宾、哥斯达黎加、厄瓜多尔等）拥有大量自有或合作种植基地，并且具备成熟的冷链和分选技术。为了满足全年供应，他们通常通过在全球不同纬度、不同产季的基地轮换种植和采收，实现跨季节供应。**理论上完全可以做到全年供货**，但往往以整果、鲜切或批发为主。对于茶饮店，如果用量较大，可以与他们签订长期采购协议。
- **洪九果品（Hongjiu）**：这家公司以东南亚进口水果和国内优质水果分销为主，菠萝（尤其是香水菠萝、都乐风味的菲律宾菠萝）是他们的主要品类之一。洪九的优势在于**产地直采+多产地调度**，他们通过泰国、菲律宾、越南等多个产地轮换，或者国内云南、海南等反季节产地补充，也能做到全年供应。但他们更偏向于B端批发市场供货，对于小体量茶饮店，可能更多需要通过其区域经销商或市场档口对接。

**2. 现实注意事项（很重要）：**

- **价格波动**：即使能做到全年供应，不同季节的菠萝采购价差异很大（冬季进口成本高，春夏国产量大价格低）。如果做果酱，建议你提前锁定长期订单或选择“冷冻菠萝丁/原浆”作为备份方案，这样更稳定。
- **果型与糖度**：全年供应的菠萝，不同产地品质（酸度、纤维感、香气）有差异，做果酱时可能需要调整糖量和熬煮时间。建议在供应商处取样做小批量试制，确认风味一致性。
- **供应连续性风险**：极端天气（台风、寒潮）或国际物流问题可能打断供应。最好在合同中约定“最低保障量”或“替代产区条款”，并且自备冷冻库存缓冲。

**3. 给你的建议：**
- 如果茶饮店月用量在**几百公斤以上**，可以直接联系都乐中国区的大客户部或洪九的区域销售，签订年度框架协议，他们会为你规划全年排产。
- 如果用量较小，更推荐直接找**当地水果批发市场**的菠萝专营档口，他们通常代理洪九或都乐的产品，且有冷库，可以按周/按月稳定供货。
- 实操上，果酱生产建议**混用鲜果+冷冻果丁**，既保证风味新鲜度，又降低断供风险。

**结论：** 只要体量足够、提前签约，**都乐和洪九都能做到全年供应菠萝**，但需要你主动对接并谈好保障条款。如果只是临时采购，不建议依赖单一货源。
