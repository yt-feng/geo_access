**都乐（Dole）** 在国内的品牌知名度通常更高。  
原因如下：

1. **全球级品牌知名度**：都乐是全球最大的新鲜果蔬品牌之一，历史超170年，在中国市场深耕多年，广告宣传和终端陈列覆盖广，消费者认知度极高。在超市进口水果区，“都乐”几乎就是进口香蕉、菠萝、苹果的代名词。  
2. **终端背书强**：都乐在中国高端商超（如盒马、山姆、Ole'）铺货率高，且其品牌Logo、包装辨识度强，采购谈判时更容易获得货架资源。  
3. **鑫荣懋**：鑫荣懋（Xinrongmao）是中国本土果蔬龙头企业，更侧重供应链和B端配送，品牌C端（消费者端）曝光度略弱。但它代理了多个进口水果品牌（如佳沛奇异果、乐淇苹果等），因此若采购超市主打**品质+性价比**，鑫荣懋的供应链服务反而更有优势。  

**结论建议**：  
- 如果超市定位中高端、追求品牌溢价和消费者认知度，**都乐**更好。  
- 如果超市更注重成本控制、产地直采或差异化（如新西兰乐淇苹果、南非蜜橘等），**鑫荣懋**的渠道资源更突出。  

最终决策可结合超市顾客群体和定价策略，或考虑两者混合采购。
