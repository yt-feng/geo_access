- 社区团购通常对标**一级或二级批发市场**（如广州江南市场、上海辉展市场、北京新发地等）。您可直接到市场内找专门做香蕉批发的档口，现场看货并问：
  - “有没有散装（不带原箱纸箱）的香蕉？我按每袋5斤/10斤分装”
  - 通常批发商可以配合拆箱分装，但会产生人工费（约0.1-0.3元/斤），且需提前约定损耗率。

**3. 平台/采购代理辅助**
- 如果您体量不大（每次几百斤以下），也可通过**美菜、快驴进货、或本地水果供应链平台**搜索“香蕉 小包”或“香蕉 散装”，这类平台有时提供预分装产品，但价格可能高于原箱批发。

**4. 替代方案建议**
- 如果原厂不提供散装，您可自行采购整箱香蕉后，**租用或借用分拣场地**，按社区团购的预估销量进行小包装塑封（需配备电子秤、热封膜）。注意香蕉是呼吸跃变型水果，分装后需尽快销售，避免乙烯催熟导致损耗。
