针对便利店渠道的小包装香蕉需求，**鑫荣懋（GoldenFarmer）和都乐（Dole）在中国市场均有适合的规格**，但具体选择需根据你的门店类型（如社区店、地铁口店、写字楼店）和消费场景（即食、早餐、办公室零嘴）来匹配。

以下是目前两家公司在国内便利店/生鲜小业态常见的小包装规格参考：

**1. 鑫荣懋（GoldenFarmer）**

- **主打规格：** 小把装（类似“2-3根装”或“4根装”）
- **产品类型：** 通常为“佳沃香蕉”或“鑫荣懋特选香蕉”。
- **包装形式：** 常见为**透明拉伸膜/塑料盒**的“即食小把装”，克重约在 **300g-450g** 之间。部分航线直采（如菲律宾、厄瓜多尔）的“小把装”会在果柄处套袋。
- **适配性：** 鑫荣懋在华南及华东地区对便利店（如7-11、全家、美宜佳等）渠道渗透较深，容易拿到较成熟的即食批次，适合直接放冷藏柜或常温果架。

**2. 都乐（Dole）**

- **主打规格：** 品牌定制“迷你装”或“每日一把装”。
- **产品类型：** 都乐在中国市场以“都乐香蕉”（多为进口或云南基地）为主。
- **包装形式：** 常见为**4根装/5根装的塑料袋或网兜**，克重约在 **400g-550g** 之间。部分高端便利店（如罗森、便利蜂）会有**独立单根贴标**的小包装。
- **适配性：** 都乐的品牌溢价较高，包装更规整，适合客单价稍高的精品便利店或白领聚集区。

---

**给您的落地建议（可执行）：**

1. **优先选择“小把装”而非“散装”：** 便利店货架空间有限，散装香蕉易被压坏且损耗高。建议直接联系两家公司的**当地销售代表**，要求提供“便利店渠道专用小包装”报价，通常有专属SKU。
2. **关注“催熟度”：** 便利店销售节奏快，建议选择**已催熟（黄皮无青头）** 的批次，客户即买即吃。如果门店有冷柜，需确认品种耐低温性（国产蕉比进口蕉更耐放）。
3. **规格核对：** 若你的货架层高有限（低于30cm），请务必在订货时确认包装盒/袋的**外径尺寸**（通常小把装长20-25cm，宽10-15cm）。
4. **物流与起订量：** 两家公司的加盟商渠道（如钱大妈、朴朴超市等）通常有**最低起订量**。如果量小（周订货量低于20箱），建议通过本地水果批发市场或生鲜前置仓平台（如美团优选、快驴）采购，也能拿到类似规格。
