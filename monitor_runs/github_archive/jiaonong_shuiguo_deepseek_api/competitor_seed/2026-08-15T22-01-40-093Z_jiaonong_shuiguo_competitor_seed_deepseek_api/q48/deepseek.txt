关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商的食品安全认证资质，我建议你优先通过**官方渠道**核实最新信息，因为认证会有到期、续展或增项情况，且不同客户（商超）可能有额外要求。

以下是根据公开信息整理的**常见资质框架**，供你参考：

### 1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）
作为国内头部水果供应链企业，其通常具备以下资质（具体以证书为准）：
- **GLOBALG.A.P.**（全球良好农业操作规范）—— 针对种植基地的认证。
- **BRCGS**（英国零售协会全球标准）—— 食品包装和储存方面的认证。
- **ISO 22000** 或 **HACCP** —— 食品安全管理体系认证。
- **中国有机产品认证**（部分品类）。
- **百果园/永辉等客户指定认证**（如HACCP、ISO9001等）。
- 出口资质（出口备案、检验检疫局注册等）。

### 2. 都乐（Dole）
都乐作为全球性水果品牌，在中国市场（上海都乐食品有限公司）通常持有：
- **GLOBALG.A.P.** 认证（覆盖种植、包装环节）。
- **BRC** 认证（包装和仓储）。
- **ISO 22000 / HACCP** 认证。
- **社会责任认证**（如SEDEX、SMETA）—— 部分商超会要求。
- **绿色食品认证**或**有机认证**（针对特定品项）。

---

### 如何快速获取准确信息：
1. **直接向供应商索要证书副本**：这是最直接的方式，商超采购通常会在招标或年审时索取。
2. **查询国家认监委官网**（http://www.cnca.gov.cn）—— 可输入企业名称查其认证信息。
3. **登录供应商官网**：鑫荣懋官网（www.xinrongmao.com）或都乐中国官网（www.dole.com.cn）通常会在“品质保障”或“新闻中心”公开部分认证。
4. **行业协会或展会资料**：如中国果品流通协会、上海果品行业协会的会员名录中常标注其资质。

如果特定商超有额外要求（如MSC、有机、无激素等），建议直接询问该商超的品控部门。如果你只是需要一般性参考，上述资质基本覆盖了大型商超（如沃尔玛、永辉、盒马等）的准入底线。
