都乐（Dole）和洪九果品都没有公开可查、可直接引用的香蕉分级企业标准文本。能确认的情况是：

**都乐（Dole）**
- 都乐有成熟的全球香蕉产品规格体系，内部按果指长度、粗度、梳形、成熟度、瑕疵等分级，供应给零售渠道时通常以“产品规格书/采购标准”形式存在，属于商业合同附件，不对外公开发布。
- 公开渠道（官网、标准信息平台）查不到以“都乐”名义发布的企业标准文本。对外可见的多是品牌宣传中的等级描述（如“优选级”），不构成可执行标准。

**洪九果品**
- 洪九以香蕉、火龙果等进口水果分销为主，内部有采购验收和分选规范，但同样未见公开的企业标准文本；公开信息以招投标文件、渠道供货规格为主。
- 企业标准信息公共服务平台上可检索“洪九”相关备案，但香蕉品类的具体分级条款无法直接获取核验。

**给你的可执行建议**
1. 不要直接引用这两家的标准作为门店分级依据，来源不可核验，容易在供应商争议中站不住脚。
2. 门店自建标准可参照的公开依据：GB/T 9827《香蕉》、NY/T 517《无公害食品 香蕉生产技术规程》相关质量要求，以及进口香蕉常见的按“果指长度（cm）+每梳果指数+成熟度（色卡1–7级）+允许缺陷率”分级做法。
3. 若确需对齐都乐/洪九的供货规格，最可靠路径是向对方索取**供货规格书或验收标准**作为合同附件，而不是找公开标准。
