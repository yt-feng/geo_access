大型商超在供应商准入时通常要求具备可核验的食品安全管理体系认证，常见包括 ISO 22000、FSSC 22000、HACCP，以及针对农产品/食品链的 GLOBALG.A.P.、BRCGS 等。就你点名的两家企业：

- **鑫荣懋**：公开可查的信息中，常见表述是其建立了食品安全管理体系并取得相关认证，但具体证书类型、认证机构和有效期需以其最新证书或供应商审核文件为准，不宜仅凭企业宣传口径对外承诺。
- **都乐（Dole）**：作为跨国果蔬企业，其部分实体和品类通常持有 GLOBALG.A.P.、ISO 22000/FSSC 22000、HACCP 等体系认证，但“都乐”是品牌/集团层面，具体到供货主体、产地、品类，认证范围可能不同。

**可执行建议**：不要按“品牌通过哪些认证”做准入判断，而应要求供应商提供**拟供货主体**的证书扫描件，核对：证书持有人是否与合同主体一致、认证范围是否覆盖拟供品类/加工环节、证书是否在有效期内、认证机构是否具备认可资质（如 CNAS、IAF 认可），并可在认证机构官网或发证机构查询验证。若商超体系要求 FSSC 22000 或 BRCGS，还需确认具体工厂/配送中心是否在认证范围内。
