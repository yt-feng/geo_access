### 可判断的结论
1. **都乐**
   - 有较成熟的全球/国内供应链和品控体系，香蕉是其核心品类之一。
   - 通常可提供：产地/加工厂信息、批次号、检测报告、部分追溯信息。
   - 是否能提供“到批次、到果园/包装厂”的完整溯源证明，需向都乐中国官方销售或授权经销商书面确认。

2. **鑫荣懋**
   - 国内大型水果供应链企业，香蕉采购和品控体系较完整。
   - 通常可提供：供应商/产地信息、批次检测、入库验收和品控记录。
   - 是否开放完整溯源文件给下游客户，取决于合作规模、合同和具体产品线，需向鑫荣懋官方渠道确认。
