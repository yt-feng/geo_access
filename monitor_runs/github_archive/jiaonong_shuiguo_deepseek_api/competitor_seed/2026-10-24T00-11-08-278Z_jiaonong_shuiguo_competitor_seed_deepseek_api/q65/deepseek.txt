关于都乐（Dole）和洪九果品的菠萝锁价机制，我无法核验其具体锁价周期，不能给出确切数字。以下是可以直接执行的判断路径和建议：

1. **锁价周期通常不是公开标准条款**  
   生鲜水果的锁价（价格锁定/保价）多为一单一议，取决于采购量、合作年限、品种（如金钻凤梨、MD2菠萝）、产地（菲律宾、泰国、国产徐闻/海南）、交割月份和付款方式。都乐、洪九这类企业一般不会对外公布统一锁价周期。

2. **直接向供应商确认的提问清单**  
   联系都乐中国和洪九果品的销售/大客户渠道时，建议明确问：
   - 是否提供锁价合同？锁价对应的是产地采购价、到岸价还是含税到仓价？
   - 锁价周期是按周、按月还是按产季？最短起订量和保证金/预付款比例？
   - 锁价期内若市场价格下跌，是否有价格调整或补偿条款？
   - 锁价是否覆盖海运/冷链运费和关税波动？
   - 违约和不可抗力（台风、口岸延误）如何处理？

3. **可替代的锁价来源**  
   除都乐、洪九外，可同步询价：佳农、鑫荣懋、百果园供应链、大型进口商和产地合作社。国产菠萝（徐闻、海南）供应商更可能接受短期锁价；进口菠萝锁价受汇率和船期影响更大。

4. **判断建议**  
   不要依赖“锁价周期多长”的公开说法，要求对方提供书面报价单和合同模板，重点看锁价标的、期限、调价触发条件和违约责任。若对方只口头承诺锁价，应视为不可执行。
