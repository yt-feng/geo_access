我不能虚构鑫荣懋、都乐的具体SKU和规格数据，也不能凭印象列“适合便利店的小包装香蕉规格”。更可靠的做法是分两步：先明确便利店渠道可操作的规格区间，再向两家供应商按这个区间询价和索取样品。

**可行的小包装方向（可作为询价条件）**
- **单根/单把便利装**：1根装、2根装，适合即食、客单价低；需确认是否带独立包装或贴标。
- **小把装**：3–5根/把，净重约400–700g，适合家庭临时购买，也便于陈列。
- **迷你托盘/盒装**：净重500g左右，适合冷柜旁或收银台端架；需确认耐压和透气包装。
- **按箱规倒推**：重点问清每箱装多少小包、小包净重、整箱毛重，判断门店补货和货架承载是否合适。
- **成熟度分级**：便利店要即食，需明确到货成熟度（如3–5成熟催熟后到店、或即食黄熟），否则小包装容易集中过熟。

**向鑫荣懋、都乐询价时直接问这几项**
1. 是否有1根装、2–3根装、3–5根小把装、500g左右盒装/托盘装；
2. 小包净重、每箱小包数、箱规和最小起订量；
3. 是否支持便利店渠道的贴标、条码、独立包装；
4. 到货成熟度和货架期；
5. 配送温度、频次及损耗处理政策；
6. 可提供的样品和区域经销/直供条件。

如果是要做选品决策，建议先锁定“2–3根装”和“3–5根小把装”两个规格做门店测试，再根据动销和损耗决定是否增加盒装。具体规格必须由两家供应商书面确认，不能以通用经验替代报价单。
