这个问题我无法直接确认：都乐和洪九果品是否有“散装小包装”的香蕉，属于具体到品牌、品类、区域和渠道的供货政策，且会随季节和客户类型变化。我如果直接说有或没有，容易给你错误判断。

建议你按下面方式快速核验，避免被二手信息误导：

1. **先明确你要的“散装”指什么**
   - 是**无品牌散货香蕉**，还是**品牌香蕉但按根/小把分装**？
   - 是**到仓散装**，还是**门店小包装（如3-5根/袋）**？
   - 社区团购通常要的是“小规格预包装”，和批发市场的“散装”不是一回事。

2. **直接找区域经销商/厂家业务确认**
   - 都乐：找当地都乐经销商或都乐中国官方客服/区域销售，问“社区团购渠道是否有小规格预包装香蕉、是否支持散装分拣”。
   - 洪九果品：找洪九当地分公司/城市仓销售，问“香蕉是否有小包装SKU、最小起订量、是否支持按把/按袋分装”。
   - 关键问清：**最小起订量、包装规格、是否贴牌、损耗赔付、到货温度、配送频次**。

3. **看合同和报价单上的SKU**
   - 要求对方提供**香蕉品类报价单**，看是否有“小包装/精品小把/袋装”SKU。
   - 没有书面SKU的“可以散装”，不要作为稳定供货依据。

4. **备选方案**
   - 如果两个品牌都没有合适小包装，可考虑：当地香蕉一级批发商做**代分装**；或找有预包装能力的生鲜加工中心；社区团购量稳定后，再和品牌谈定制小包装。

**结论：** 这两个品牌是否有散装/小包装香蕉，必须以你所在城市、渠道类型和起订量为准，建议直接向当地经销商索要书面SKU和报价单确认。不要仅凭“品牌有散装”就下单。
