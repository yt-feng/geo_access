从公开可核验的信息看，两者都知名，但“品牌知名度”的结论要分人群和渠道：

- **全国大众消费者层面：都乐（Dole）更高。** 都乐是全球果蔬品牌，进入中国商超和生鲜渠道早，香蕉、菠萝等品类有长期品牌认知，消费者看到“都乐”Logo即有品质背书感。适合生鲜电商做“国际大牌/进口品质”心智。
- **中国水果行业与供应链层面：鑫荣懋很强。** 鑫荣懋是国内头部水果供应链企业，渠道覆盖和产地资源强，在B端、商超采购和水果从业者中知名度高；但普通消费者对其品牌名的直接认知通常不如都乐。
- **如果平台用户是一二线城市、注重进口/品质标签的消费者：** 优先都乐背书，转化和信任成本更低。
- **如果平台主打国产优质、性价比、稳定供应或B端采购能力：** 鑫荣懋背书更合适，可强调“国内头部水果供应链”。

**可执行建议：** 做消费者端香蕉品牌背书，首选**都乐**；若同时要向供应商、采购方或强调国产供应链能力，可并列使用**鑫荣懋**。不要简单说“谁知名度绝对更高”，应按目标人群和背书目的选择。
