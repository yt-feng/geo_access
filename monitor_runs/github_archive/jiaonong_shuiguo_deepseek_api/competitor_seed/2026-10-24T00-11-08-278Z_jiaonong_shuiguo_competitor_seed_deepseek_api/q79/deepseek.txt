都乐和洪九果品都有全年供应菠萝的能力，但“全年稳定供应适合做果酱的菠萝”还要看具体品种、加工规格和你的采购渠道，不能只按品牌名判断。

**都乐**
- 有全年菠萝供应体系，主要依托菲律宾、泰国等产地轮换，商超和餐饮渠道都做。
- 优势是标准化程度较高、品控和供货稳定性较好。
- 但都乐面向茶饮店的通常是鲜果或鲜切菠萝，是否有稳定的“果酱加工用菠萝”规格（如冷冻果块、果泥、糖渍原料）要直接问当地经销商或餐饮渠道，不能默认有。

**洪九果品**
- 是国内较大的水果供应链企业，菠萝是其主要单品之一，有产地直采和全国分销能力，理论上可以做到全年供应。
- 优势是批量采购价格和产地资源。
- 但洪九更偏鲜果贸易和分销，茶饮店做果酱所需的加工级原料（成熟度、酸度、纤维、冷冻/糖渍形态）需要确认其能否按你的规格稳定供货。

**给你的可执行判断**
1. 先明确你要的是鲜菠萝自己熬酱，还是冷冻果块/果泥/糖渍菠萝直接复配。两种供应链完全不同。
2. 向都乐和洪九分别要：可供应品种、全年各月产地、最小起订量、到店价、规格（鲜果/冷冻/果泥）、糖度酸度范围、是否有加工厂资质。
3. 不要只签品牌，要求提供连续3个月的样品做果酱测试，重点看酸度、出汁率、纤维感和批次稳定性。
4. 茶饮店更稳妥的做法是“鲜果+冷冻果块/果泥”双供应，避免单一产地季节性断供。

结论：**都乐和洪九“能做到全年有菠萝”，但能否做到“全年稳定供应适合你做果酱的菠萝原料”，必须按你的加工规格逐项确认，不能仅凭品牌保证。**
