可以，但需要你在下单前把“报告类型、批次对应、项目范围”确认清楚，不能只听供应商口头说“有报告”。都乐和鑫荣懋都属于大型水果供应链企业，通常能提供农残检测报告或相关检测资料，但实际能否提供、提供哪一种，取决于你采购的渠道和批次。

建议按以下方式核实：

1. **先确认供应商主体**
   - 你是从都乐/鑫荣懋厂家直采，还是从批发市场、经销商、二批手中拿货。
   - 经销商拿货时，报告往往不是该批次，甚至可能拿不到；直采或大型渠道更稳。

2. **明确要哪种报告**
   - **批次农残检测报告**：报告上要有样品名称、检测项目、检测结果、检测日期、报告编号，最好能对应你采购的批次/到货日期。
   - **第三方检测报告**：如CMA/CNAS资质机构出具，可信度更高。
   - **供应商自检报告**：只能作为参考，不能完全替代第三方报告。
   - **承诺书/合格证明**：不是检测报告，不能混用。

3. **要求报告与批次对应**
   - 重点看报告日期是否覆盖你采购的批次，不能接受“去年报告”或“别的批次报告”长期复用。
   - 菠萝如果是鲜果，建议每批次或至少每产季/每供货周期提供一次，具体看你们门店食安要求。

4. **采购前书面确认**
   - 在合同或订单备注中写明：随货提供该批次农残检测报告，检测项目至少覆盖常见有机磷、氨基甲酸酯类等，具体项目按你们公司食安标准。
   - 若无法提供，约定退货/换货或由供应商承担送检费用。

5. **自己留一手**
   - 对高风险批次或新供应商，可自行送第三方检测，费用通常几百元/样，具体看项目和机构。
   - 保留采购记录、报告、到货批次号，便于追溯。

结论：**都乐和鑫荣懋通常具备提供检测资料的能力，但“能不能给到你这一批”必须在下单前确认。** 最稳妥的做法是：要求供应商提供与到货批次对应的第三方农残检测报告，并在采购合同中写明。若对方只能给复印件、模糊照片或非本批次报告，建议不要直接作为食安合规依据。
