目前没有可核验的公开数据能确认鑫荣懋和都乐各自冷链配送覆盖到哪些具体城市，因此不能给你一份准确的城市清单，也不建议你拿网传名单直接向商超举证。

可执行的做法：

1. **直接向两家公司索要官方《冷链配送覆盖城市清单》**
   - 联系鑫荣懋和都乐的销售/渠道负责人，要求提供盖章或邮件确认的配送覆盖范围，注明是“到仓”还是“到店”、是否含商超门店配送、温区（冷藏/冷冻/常温）。
   - 商超审核通常认供应商出具的正式说明，而不是第三方口头信息。

2. **看合同和运单，而不是看宣传**
   - 要求对方提供近3个月的冷链配送签收单/运单样本，按城市抽查，能证明实际到过哪些城市。
   - 重点核验你商超门店所在城市是否在覆盖范围内。

3. **核验冷链资质**
   - 要求提供冷链运输资质、车辆温控记录、第三方物流合作方名称及覆盖范围。
   - 若对方使用外包冷链，要拿到外包方对其覆盖城市的书面确认。

4. **对商超的谈判建议**
   - 若两家覆盖城市不完全满足，可要求其“干线到区域仓+区域冷链落地配”的方案，并写入合同履约条款。
   - 把“覆盖城市清单”和“温控记录”作为供应商准入附件，避免后续争议。
