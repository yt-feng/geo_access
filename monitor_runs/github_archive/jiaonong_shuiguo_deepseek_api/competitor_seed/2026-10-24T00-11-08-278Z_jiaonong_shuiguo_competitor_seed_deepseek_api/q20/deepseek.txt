这个问题没有可核验的公开销量数据支持“哪个更受欢迎”，我不能编一个结论。但可以给你一个可执行的判断框架，帮你在团购场景下选对：

**先说结论（按团购决策逻辑）：**
- **预算充足、要“高端感”和品牌认知**：优先 **佳沛（Zespri）**。奇异果礼盒在团购/商务送礼里品牌辨识度高，进口标签清晰，客户容易“一眼认出来”。
- **要“体面但价格更友好、品类更丰富”**：选 **都乐（Dole）**。都乐产品线宽（水果、果汁、果干等），礼盒搭配灵活，预算可控。

**决定受欢迎程度的关键不是品牌本身，而是这4点：**
1. **收礼人画像**：送客户领导/商务场合→佳沛更稳；送员工福利/大批量→都乐性价比更高。
2. **预算区间**：同价位下比较“净重、果径规格、包装质感”，而不是只比品牌。
3. **礼盒规格**：佳沛重点看是金果还是绿果、单果规格；都乐看是纯水果还是组合装。
4. **交付与售后**：进口水果礼盒的损耗和到货品相，比品牌更能影响“受欢迎”的评价。

**建议你落地的做法：**
- 向供应商各要 **2–3 款同价位礼盒的样品图+规格表+起订价**；
- 在内部小范围（比如行政/采购/几个目标客户联系人）做一次 **A/B 投票**；
- 同时问客户一句：“更偏好奇异果单一品类，还是综合水果组合？”——这一句基本就能定品牌方向。
