这个对比没有可直接核验的公开统一数据，不能给你一个“洪九果品 vs 都乐香蕉到货损耗率”的确定数值。原因在于：到货损耗率取决于批次成熟度、运输距离/冷链、季节、包装规格、卸货方式、验收口径，同一品牌不同批次都可能差好几个点；洪九果品是批发/供应链企业，都乐是品牌方，二者统计口径也不完全一致。

可执行建议：

1. **不要按品牌定损耗，按“批次+链路”定**
   - 问供应商要近3批同规格到货的验收记录：到货总件数、验收合格件数、扣重/退换件数。
   - 重点看：青蕉/黄蕉比例、催熟方式、运输温度记录、到货日期与采摘/催熟日期间隔。

2. **现场做小批量试单**
   - 同一市场、同一季节，各拿1–2板/少量件做对比。
   - 统一验收标准：按件扣重、黑斑/压伤/断果比例、可售率。
   - 连续跟3–5批再判断，单批没有代表性。

3. **合同里写损耗口径和兜底**
   - 明确“到货损耗率”定义：按件数还是按重量；是否含催熟后损耗；验收时限。
   - 约定超出约定损耗的补货/扣款/退换规则。
   - 要求提供冷链温度记录和催熟批次信息。

4. **批发市场拿货的现实判断**
   - 都乐香蕉通常品牌化、规格和催熟标准较稳定，但价格和渠道层级会影响实际到货状态。
   - 洪九果品覆盖品类多、渠道广，具体到香蕉要看是哪个仓/哪个批次/哪种包装，不能只用品牌名判断损耗。
   - 真正影响你的是“上一手库存周转和冷链”，不是品牌名本身。
