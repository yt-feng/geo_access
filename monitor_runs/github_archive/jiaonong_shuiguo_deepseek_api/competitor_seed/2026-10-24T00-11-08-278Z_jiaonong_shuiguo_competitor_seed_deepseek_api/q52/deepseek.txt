这个数据我没法给你准确数字：都乐和鑫荣懋的到货损耗率属于企业采购履约数据，通常不公开，公开渠道也没有可核验的统一口径。直接报一个“损耗率”会误导你。

可以按下面方式拿到可判断的答案：

1. **先定义损耗口径**
   - 到货损耗率 =（到货总重 − 验收合格可用重）÷ 到货总重 ×100%
   - 建议分开记：压伤/烂心/黑心病、切口褐变、重量短装、规格不达标（单果重、直径、成熟度）
   - 茶饮原料建议再加“去皮去芯后出成率”，因为菠萝损耗大头在加工端，不在到货端。

2. **向两家索取同口径数据**
   - 要求提供近3个月、同一规格（如金钻凤梨/都乐金菠萝，按单果重或箱规）、同一到货城市的验收损耗记录
   - 要求写明抽检比例、验收标准、是否含运输短装
   - 让对方销售在报价单/合同中写“到货验收合格率”或“损耗赔付条款”，比口头损耗率可靠。

3. **自己做小批量对比试单**
   - 同规格各订3–5箱，连续2–3批
   - 每批记录：到货总重、坏果重、规格不符重、去皮去芯后净果重
   - 茶饮场景重点看：出汁率/果肉出成率、酸甜度稳定性、纤维感、氧化褐变速度

4. **谈判时用“可用净果成本”比较**
   - 不要只比箱价，算：箱价 ÷ 去皮去芯后可用果肉重 = 每公斤可用果肉成本
   - 再把损耗赔付、退换货响应时间写进合同。
