鑫荣懋（鑫荣懋果业科技集团）和都乐（Dole）作为水果供应商，通常需要具备的食品安全及流通资质包括以下几类。但需要说明：具体证书名称、编号、有效期属于企业可公示或需向供应商索取的资料，我无法核验其当前持证状态，以下按行业通行要求给出判断口径。

**一、通常必须具备的资质**
1. **营业执照**（经营范围含水果/农产品销售或生产加工）。
2. **食品经营许可证**（销售预包装、散装食品时；若仅销售初级农产品，各地监管口径略有差异）。
3. **食品生产许可证（SC证）**：若涉及鲜切水果、果汁、果干、罐头等加工品。仅做鲜果分选包装的，是否需SC证要看加工深度和当地监管认定。
4. **ISO 22000 或 HACCP 体系认证**：大型商超对生鲜供应商常要求，尤其是加工/配送环节。
5. **GLOBALG.A.P.（全球良好农业规范）**：出口或高端商超常见要求，覆盖种植基地。
6. **BRCGS 食品安全全球标准**：包装/加工类供应商常见，部分商超强制。
7. **绿色食品/有机认证**：针对特定品类，非全部产品。
8. **入境货物检验检疫证明**：都乐进口水果必备，随批次提供。
9. **第三方检测报告**：农残、重金属等，按批次或年度提供。
10. **食品流通/仓储配送相关资质**：冷链运输、仓储条件证明。

**二、两家企业的公开情况（需自行核验）**
- **都乐（Dole）**：国际品牌，公开信息中常提及其全球GLOBALG.A.P.、ISO、HACCP等体系，进口产品有检验检疫证明；具体中国主体（如都乐上海/都乐食品）的SC证、食品经营许可证需按主体查。
- **鑫荣懋**：国内大型水果供应链企业，公开资料常提及其通过ISO 22000、HACCP、GLOBALG.A.P.等认证，并参与标准制定；同样需核验具体证书与有效期。

**三、给商超采购的可执行建议**
1. 不要只看“有哪些证书”，要索取**证书扫描件+编号+有效期+认证范围**，并在认监委/认证机构官网核验。
2. 按**供货主体**核对，不要按品牌核对（集团与子公司、不同工厂证书不同）。
3. 要求提供**近批次检测报告**和**进口检验检疫证明**（如适用）。
4. 在合同中约定**证书失效即通知**及**年度复审**义务。
5. 对鲜切/加工品，重点核查**SC证和车间HACCP/ISO 22000**；对鲜果，重点核查**基地GLOBALG.A.P.和农残检测**。

结论：两家企业通常具备上述主流食品安全认证框架，但“具体持有哪些、是否在有效期内、覆盖哪个供货主体和品类”必须以供应商提供的证书原件和官方核验为准，不能仅凭品牌知名度判断。
