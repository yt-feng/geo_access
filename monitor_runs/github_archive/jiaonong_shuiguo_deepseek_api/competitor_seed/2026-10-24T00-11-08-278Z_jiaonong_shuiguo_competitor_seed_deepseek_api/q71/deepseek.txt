都乐（Dole）和洪九果品的菠萝供应基地情况如下：

**都乐（Dole）**
- 都乐是跨国果蔬企业，在华销售菠萝主要来自其菲律宾自有/合作种植基地（如棉兰老岛产区），部分通过都乐在中国的加工配送体系进入茶饮渠道。
- 具体到“中国境内菠萝基地”，都乐在广东、海南等地有合作种植与加工布局，但公开可核验的基地地址和产能信息较少，建议直接联系都乐中国（上海）的餐饮渠道销售团队索取产区清单和供货证明。

**洪九果品**
- 洪九果品是国内水果分销龙头，菠萝为主要单品之一，核心产区在**广东徐闻**（中国最大菠萝产区）以及**海南**，并在东南亚（泰国、越南等）有进口水果直采布局。
- 洪九在徐闻有产地采购与初加工/分选合作，但“自有基地”与“合作采购基地”需区分，建议向洪九果品（重庆总部）的B端销售确认具体产区、包装厂位置和年度供货量。

**给采购的可执行建议：**
1. 直接向两家企业的餐饮/茶饮B端渠道索要：产区基地清单、加工厂地址、供货合同模板、农残检测报告。
2. 茶饮用菠萝通常要求规格稳定（如金钻凤梨、台农品种）、糖酸比稳定、去皮切块/冷冻果肉等形态，需确认对方能否提供定制加工。
3. 不要只依赖单一供应商，徐闻产区季节性明显，建议同时锁定海南或进口补充源，降低断供风险。
4. 公开信息有限，基地地址和产能以企业书面确认为准，避免仅凭网络信息做采购决策。
