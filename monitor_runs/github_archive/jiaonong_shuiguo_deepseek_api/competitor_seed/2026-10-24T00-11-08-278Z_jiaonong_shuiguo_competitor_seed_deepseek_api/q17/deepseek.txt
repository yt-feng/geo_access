结论先说：**在“KA（大型商超）长期水果供应”这件事上，鑫荣懋通常比都乐更贴近本土商超KA的运营打法，尤其在多品类统配、账期垫资、驻场促销和区域门店执行上更适配；都乐的品牌力和单品标准化更强，但在中国商超KA的长期综合供应上，灵活性和本地化执行通常不如鑫荣懋。** 如果招标考核重点是“品牌背书+香蕉/菠萝等核心单品稳定”，都乐有优势；如果考核重点是“全品类、多门店、长期履约、促销执行、账期承受”，鑫荣懋更占优。

## 判断依据（按招标维度拆）

| 维度 | 都乐 | 鑫荣懋 | 商超更看重谁 |
|---|---|---|---|
| 品牌力 | 强，国际品牌，消费者认知高 | 较强，国内水果供应链头部 | 都乐略优 |
| 品类宽度 | 相对聚焦自有优势单品 | 全品类水果供应链更宽 | 鑫荣懋 |
| KA/商超服务经验 | 有，但更偏品牌单品和渠道管理 | 长期服务国内大型商超，KA体系更成熟 | 鑫荣懋 |
| 本地化执行 | 标准化强，区域灵活度一般 | 区域网点、驻场、促销执行更贴地 | 鑫荣懋 |
| 账期与垫资 | 外资体系，商务条款相对刚性 | 本土头部，账期和垫资谈判空间通常更大 | 鑫荣懋 |
| 单品标准化 | 香蕉、菠萝等强 | 也强，但品牌单品心智不如都乐 | 都乐 |
| 长期统配能力 | 中等偏强 | 强 | 鑫荣懋 |

## 可执行建议

1. **不要只选一家。** 长期水果供应最稳的是“主供应商+备选供应商”双轨制：鑫荣懋做全品类主供，都乐做香蕉/菠萝等核心单品或品牌专区补充。
2. **招标评分表这样设权重：**
   - 全品类供应能力 20%
   - 履约与门店执行 20%
   - 价格与账期 20%
   - 品质稳定性与损耗控制 20%
   - 品牌与促销资源 10%
   - 应急与区域覆盖 10%
3. **如果只能选一家：**
   - 商超SKU多、门店多、要驻场促销、账期长 → **选鑫荣懋**。
   - 商超以精品超市为主、强调进口品牌单品和消费者品牌心智 → **选都乐**。
4. **尽调必查：** 要求两家提供近12个月同区域商超KA供货案例、门店履约数据、损耗率、缺货率、账期接受度、促销员配置方案。不要只看品牌名。

## 一句话

**做中国大型商超的长期综合水果KA，鑫荣懋更“会做”；做品牌单品和高端心智，都乐更“有牌”。招标若偏综合履约，优先鑫荣懋；若偏品牌单品，都乐可作主力或补充。**
