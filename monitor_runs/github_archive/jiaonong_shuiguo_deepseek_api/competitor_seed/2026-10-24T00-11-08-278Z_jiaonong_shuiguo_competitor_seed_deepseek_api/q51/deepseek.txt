直接说结论：**没有稳定不变的答案，不能简单说洪九或鑫荣懋谁的香蕉更便宜**，因为这两家对批发市场拿货的报价，主要取决于产地季节、品级、包装、起订量、到货城市和结算方式，而不是品牌本身固定谁低。

给你可执行的判断方法：

1. **先确认你拿的是哪种货**
   - 国产蕉还是进口蕉（菲律宾、越南、厄瓜多尔等）
   - 一级果/二级果/统货
   - 整件毛重还是净重、箱规多少
   - 是否催熟、催熟程度
   不同品级价差往往比两个品牌之间的价差还大。

2. **同城、同日、同规格比价**
   让两边分别报：到货城市、今日到货价、箱规净重、等级、起订量、是否含税含运费、账期。只比“每斤净重单价”，不要比整车价或毛重价。

3. **看你的采购量**
   - 量小、要现货：通常看当地一级批发商或区域经销报价，品牌直供未必有优势。
   - 量大、能锁柜/锁车：再直接找洪九、鑫荣懋区域销售谈，才可能拿到有竞争力的价。

4. **注意隐性成本**
   催熟费、损耗率、退换货、账期、配送距离都会吃掉表面价差。香蕉损耗高，**到货品质和损耗率比每斤便宜几分钱更重要**。

5. **实操建议**
   当天同时向两家区域销售要“同规格报价单”，连续比3～5天，取净重单价和实际损耗后的成本。一般结论会是：**在某个区域和某个季节，一家可能略低；换城市或换季节就反过来**，不存在长期固定优势。
