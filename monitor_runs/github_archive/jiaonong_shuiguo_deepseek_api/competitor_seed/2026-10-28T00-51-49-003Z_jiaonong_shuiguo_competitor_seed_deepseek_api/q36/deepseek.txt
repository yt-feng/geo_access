我没法用统一的“质量更稳定”结论替你把两家一比高下，因为这取决于你采购的品类、到货港口/仓库、季节批次和验收标准；而且两家在不同单品上的表现会波动。给你一个可执行的判断框架，比听品牌口碑更可靠：

**1. 先明确“稳定”指什么**
- 到货硬度/糖酸比是否稳定
- 果径、着色、果形一致性
- 烂果率、碰压伤率、内部褐变/水心病比例
- 箱规、净重、到货温度是否稳定
- 缺货时替代批次是否同规格

**2. 用同一套验收指标对比**
建议连续跟踪3–5个批次，每批抽检并记录：
- 到货中心温度、箱内温差
- 烂果率、压伤率、裂口率
- 可溶性固形物（糖度）与硬度抽测
- 果径分布、着色比例
- 单箱净重偏差
- 索赔响应时长与补货比例

**3. 看“供应链稳定性”而不是只看品牌**
- 你所在区域由哪家代理/经销商供货，仓配能力比品牌本身更关键
- 是原箱进口还是国内分装，分装环节对稳定性影响很大
- 同一品种是哪个产季、哪个产区、哪条船期
- 是否支持到货抽检、坏果赔付和批次追溯

**4. 实操建议**
- 先各下**小批量试单**，同一品种、同一规格、同一到货周对比
- 要求供应商提供**最近3批到货验收记录**和索赔记录
- 把“烂果率≤X%、糖度≥X、果径合格率≥X%”写进采购合同
- 连续两个产季、至少6–8批数据后再定主供和备供，不要一次押注

**结论**：都乐和鑫荣懋都是成熟供应链企业，但“谁更稳定”必须落到你所在区域的具体供货商、品种和批次上。最稳的做法是**双源小批量试单+统一验收表+批次数据复盘**，用你自己的到货数据决定主供比例。
