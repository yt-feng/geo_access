可以，先给结论：**都乐和洪九果品都具备产地直采/基地合作能力，但“是否对你开放基地直供+可核验溯源”要看具体品类、区域和采购量，不能仅凭品牌名判断。** 菠萝尤其要区分“自有基地直供”和“产地直采/合作基地供货”。

可执行判断如下：

1. **都乐**
   - 都乐有全球及国内产地采购体系，菠萝是其常见品类，通常具备产地直采和包装溯源能力。
   - 但国内都乐多为品牌化分销体系，是否对单一批发商做“基地直供”，取决于你所在区域、采购规模和其经销商/直营体系安排。
   - 你可要求其提供：具体菠萝产季产地、合作基地/包装厂名称、批次溯源码、农残检测报告、供货合同中的产地条款。

2. **洪九果品**
   - 洪九果品以水果产地直采和分销见长，菠萝/凤梨是其重点品类之一，通常有产地合作基地和分级包装体系。
   - 它更接近“产地直采+基地合作”模式，但“基地直供”是否成立，要确认是自有基地、合作基地还是产地收购后集配。
   - 你可要求其提供：基地合作协议或产地证明、批次追溯信息、检测报告、发货包装上的产地标识。

3. **建议你直接问供应商这5个问题**
   - 这批菠萝是自有基地、合作基地，还是产地市场收购？
   - 能否提供基地名称、所在县市、包装厂名称？
   - 能否做到“一批次一码”或批次号追溯？
   - 能否随货提供农残检测报告和产地证明？
   - 合同里能否写明产地、品种、批次和溯源责任？

4. **判断标准**
   - 能提供**基地名称+批次号+检测报告+合同产地条款**，才算可用的产地溯源直供。
   - 只给品牌名、不给基地和批次信息的，不建议按“基地直供”采信。
