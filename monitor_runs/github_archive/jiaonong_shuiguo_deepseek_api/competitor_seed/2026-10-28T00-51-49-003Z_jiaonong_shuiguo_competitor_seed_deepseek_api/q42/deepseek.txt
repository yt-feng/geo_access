进口菠萝旺季缺货，先按“能不能补、补什么、怎么卖”三步处理；都乐和洪九这类头部进口商通常有应急机制，但具体方案需以当期合同和官方渠道为准，不能替它们确认。

**一、先判断缺口性质**
1. **短期断档（1–2周）**：优先调货、替代品种、调整陈列和预售，不建议大幅改价。
2. **持续缺货（3周以上）**：启动替代产地/品种，重做品类结构，避免把客流绑在单一进口菠萝上。
3. **品质型缺货**：旺季缺的往往是特定规格/熟度，不是所有菠萝都缺，先分清是“没货”还是“没对路货”。

**二、可执行的补货与替代**
- **换产地**：菲律宾、泰国、哥斯达黎加、马来西亚等产地按季节和准入情况轮换；国内海南、广东、云南菠萝可做短保替代。
- **换规格**：大果缺就上中果/小果，整果缺就用鲜切、果盒、餐饮装补位。
- **换渠道**：一级进口商、口岸批发市场、区域配送商、电商产地直发多线询价；优先锁有稳定柜期的供应商。
- **锁量不锁价**：对确定能到的货先签短期锁量协议，价格随行就市，避免旺季反复断供。
- **预售/预订**：对餐饮和团购客户做预售，按到货批次交付，减少空柜损失。

**三、都乐、洪九果品有没有应急方案**
- **都乐**：作为跨国果蔬品牌，通常有全球产地采购、多港口分拨和商超直供体系，旺季一般会通过跨产地调配、调整规格和优先保核心渠道来应对。但具体到某区域、某规格是否有货，需直接问都乐当地销售或官方客服。
- **洪九果品**：以进口水果分销为主，通常有产地直采、口岸仓和全国分销网络，缺货时一般会做产地切换、跨区域调拨和客户分级保供。具体应急政策同样要以洪九官方销售口径和合同为准。
- **关键动作**：不要等对方“有没有方案”，直接向两家提出三件事：①未来2–4周到货计划；②可替代产地/规格清单；③核心客户保供优先级和违约/缺货补偿条款。

**四、门店/渠道端怎么稳住销售**
- 进口菠萝缺货时，用国产菠萝、凤梨、鲜切果盒做价格带补位，避免直接空架。
- 把“进口”转为“品种/口感”卖点，减少消费者对单一产地的依赖。
- 对餐饮客户提前报备替代方案，签短期供货确认，避免临时毁约。
- 关注口岸通关和船期变化，旺季缺货常是船期延迟而非绝对无货。

**结论**：先分清短期断档还是持续缺货，再用多产地、多规格、多渠道路径补位；都乐和洪九大概率有应急调配能力，但必须向当地销售索要到货计划、替代清单和保供条款，不能默认它们一定保供。
