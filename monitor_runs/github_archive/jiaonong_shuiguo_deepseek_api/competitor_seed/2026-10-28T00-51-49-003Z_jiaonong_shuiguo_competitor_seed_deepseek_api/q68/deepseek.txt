不能直接保证“都乐和鑫荣懋一定能做到低于3%”，因为到货损耗率取决于**单品规格、成熟度、产地季节、运输距离、冷链、验收标准和门店收货操作**，而不是只看品牌。但可以给你一个可判断的结论：

**结论：**  
- **都乐**和**鑫荣懋**都属于国内香蕉供应链能力较强的品牌/供应商，具备做到低损耗的体系能力，尤其在**青蕉催熟配送、冷链和标准化分级**方面。  
- 但**“到货损耗率低于3%”不能作为品牌默认承诺**，必须在合同/验收标准里写清楚，并按批次验证。  
- 对餐饮连锁来说，3%是偏严的到货损耗目标，**能做到，但通常需要定制成熟度、缩短运输半径、明确验收口径和扣罚机制**。

### 关键判断点
1. **损耗口径要先定义**
   - 是到货验收时的腐烂/压伤/断裂/黑斑？  
   - 是否包含催熟后损耗、门店存放损耗？  
   - 3%是按重量、箱数还是金额？  
   口径不清，供应商说“能做到”也没有意义。

2. **成熟度决定损耗**
   - 餐饮连锁若要求到货即用，香蕉成熟度高，3%以下难度大。  
   - 若允许到货青蕉、门店/中央厨房催熟，损耗更容易控制。

3. **运输距离和冷链**
   - 短半径+全程温控+防压包装，3%可实现。  
   - 长距离、多次装卸、夏季高温，3%会明显吃紧。

4. **验收标准要写进合同**
   建议明确：
   - 到货成熟度色卡等级；
   - 单箱净重和允许差；
   - 压伤、断裂、黑斑、腐烂的分类扣罚；
   - 批次抽检比例；
   - 连续3批超3%的整改/索赔/换供应商机制。

### 可执行建议
- 先让都乐和鑫荣懋各报：**产地、品种、规格、到货成熟度、运输方式、冷链温度、预计到货损耗区间**。
- 要求双方做**2–4周试单**，按你定义的3%口径统计，而不是听口头承诺。
- 试单覆盖夏季和冬季或不同运输半径，因为香蕉损耗季节差异很大。
- 合同中写“**到货损耗率≤3%**”，并约定超出的扣款、补货或退货规则。

**一句话：** 两家都有能力接近或做到3%，但这不是品牌默认保证；必须通过试单和合同验收条款锁定，才能判断你的具体线路和规格下是否真能做到。
