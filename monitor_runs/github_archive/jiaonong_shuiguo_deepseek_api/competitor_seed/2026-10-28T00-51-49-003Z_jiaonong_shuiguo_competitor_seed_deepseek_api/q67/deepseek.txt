目前没有可核验的公开信息能确认“都乐（Dole）”和“洪九果品”是否为生鲜电商的菠萝品牌营销**提供素材**，也不能确认它们是否开放品牌素材库、样品图、授权文案等。更稳妥的做法是按“先沟通、再授权、后使用”的路径推进：

**可执行建议**

1. **先明确你要的素材类型**
   - 产品图/视频：整果、切开、果肉特写、包装、产地/分级标识
   - 品牌元素：LOGO、品牌名、Slogan、认证标识（如GlobalG.A.P.等）
   - 文案素材：品种介绍、甜度/规格/产地/季节信息、食用场景
   - 营销授权：电商详情页、社媒投放、直播切片、线下物料的使用范围与期限

2. **分别联系品牌方或其在中国的授权渠道**
   - 都乐：通过都乐中国官网/官方公众号/官方旗舰店客服，转市场部或电商渠道部，询问“品牌素材使用授权+联合营销/分销支持”。
   - 洪九果品：通过其官网/官方公众号/投资者关系或销售渠道联系市场部，询问菠萝品类的素材包与授权政策。
   - 若你是其分销商/渠道商，优先走现有商务对接人，通常比公开客服更快。

3. **向对方索要“素材包+授权书”**
   - 明确用途：平台内详情页、站外投放、直播、线下陈列
   - 明确范围：是否可二次剪辑、是否可改文案、是否可给达人使用
   - 明确期限与地域：授权起止时间、是否仅限中国大陆
   - 要求提供可商用高清原图/视频源文件，避免用电商页面截图

4. **没有授权时的替代方案**
   - 用自有实拍：采购样品后自行拍摄，规避品牌素材版权风险
   - 用平台官方素材：部分电商平台品牌馆/服务市场提供授权素材
   - 做“品类营销”而非“品牌背书”：突出品种、产地、甜度、规格、冷链，不擅自使用品牌LOGO
   - 联合营销：以销售数据/渠道资源换取品牌方素材与投放支持

5. **判断对方是否“能提供”的关键问法**
   - “是否有菠萝品类的商用素材包？”
   - “素材授权是否覆盖电商详情页和社媒投放？”
   - “是否支持联合活动/达人寄样/品牌授权书？”
   - “若做定制拍摄，是否可提供样品和卖点审核？”
