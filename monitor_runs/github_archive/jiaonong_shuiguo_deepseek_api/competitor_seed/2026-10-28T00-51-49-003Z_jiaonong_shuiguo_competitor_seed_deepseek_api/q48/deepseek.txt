优先给可执行结论：**我无法在当前对话中核验鑫荣懋（鑫荣懋果业科技集团）和都乐（Dole）各自“现有”的具体认证清单**，因为认证状态会随证书到期、换版、审核范围变化而变，且需要以证书编号、发证机构、有效期和覆盖产品/场所为准。下面给判断框架和可查路径，避免拿过期或错范围证书交差。

**一、大型商超通常要求的食品安全资质**
- **营业执照/食品经营许可证**（供应商主体合法经营）
- **ISO 22000 或 FSSC 22000**（食品安全管理体系，商超最常见）
- **HACCP 体系认证**（关键控制点，果蔬包装/加工环节常见）
- **GLOBALG.A.P.**（农业种植/果蔬供应链常见，尤其出口和大型零售）
- **BRCGS**（包装/加工/配送环节，部分商超指定）
- **有机认证/绿色食品认证**（如做有机或绿色品类）
- **产品检测报告**（农残、重金属、微生物等，按商超要求批次/年度）
- **溯源与合格供应商审核资料**

**二、对鑫荣懋和都乐的核验方法**
1. **直接向供应商索要“证书包”**：要求提供每张证书的扫描件，核对：证书编号、认证范围（产品/场所/活动）、发证机构、有效期、最近一次审核日期。
2. **到认证机构官网或国家认监委/全国认证认可信息公共服务平台查证**：输入证书编号或企业名称，确认状态“有效”且范围覆盖你采购的品类和工厂。
3. **核对“证企一致”**：证书持有人名称是否与合同主体一致；若为集团证书，确认覆盖具体生产/包装场所。
4. **要求供应商提供商超准入资料清单**：不同商超（如沃尔玛、永辉、盒马、山姆等）要求不同，以其最新《供应商准入/食品安全审核表》为准。

**三、可判断的建议**
- 不要仅凭供应商口头说“有ISO/FSSC/GLOBALG.A.P.”就采信，必须看**证书范围是否覆盖你采购的果蔬品类和实际发货场所**。
- 对都乐这类跨国品牌，注意中国区运营主体与全球证书的对应关系；对鑫荣懋这类国内供应链企业，注意集团总部证书与各产地/包装厂证书的区分。
- 若商超要求“认证+检测+现场审核”三件套，建议让供应商按**品类+场所+证书编号**做一张对照表提交。
