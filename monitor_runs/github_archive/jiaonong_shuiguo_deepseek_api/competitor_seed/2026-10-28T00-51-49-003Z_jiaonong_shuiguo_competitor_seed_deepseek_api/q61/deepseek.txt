都乐（Dole）和洪九果品都有用于内部采购/品控的香蕉分级要求，但公开可查、可直接引用的“企业标准”文本很少；对外能确认的结论是：**两家都有企业内控分级体系，但不宜把它们当作公开标准直接套用。** 下面按可执行方式说明。

## 1. 都乐（Dole）
- 都乐全球有成熟的香蕉质量规格体系，通常按**品种、等级（如一级/二级）、果指长度、单果重量、梳形/条数、青熟度、外观缺陷、机械伤、病害**等维度分级，并配合冷链和催熟管理。
- 公开渠道多为产品介绍、质量承诺和行业报道，**完整企业标准文本一般不对外公开**。
- 可判断：都乐有企业内控标准，但公开可核验的成文标准有限。

## 2. 洪九果品
- 洪九果品作为水果供应链企业，对香蕉等单品通常有**采购验收标准、分级分选要求、品控流程**，包括外观、成熟度、规格、缺陷率等。
- 其公开披露更多是招股书、年报、业务介绍中的品控体系描述，**未见公开可下载的香蕉企业标准全文**。
- 可判断：洪九有内部品控/分级要求，但同样不宜视为公开企业标准。

## 3. 给水果连锁店的建议
不要直接依赖“都乐/洪九企业标准”，更稳妥的是建立自己的门店分级标准：

1. **按用途分级**：门店零售、促销、加工/果切、催熟后销售分开定标准。
2. **核心指标**：品种、产地、果指长度/粗度、单果重、每梳条数、青熟度（颜色卡）、果面缺陷、机械伤、病害、整齐度。
3. **等级建议**：
   - 一级：果形整齐、无明显缺陷、长度和粗细达标、青熟度一致；
   - 二级：轻微外观缺陷但不影响食用；
   - 三级：适合促销、果切或加工。
4. **验收可量化**：抽检比例、缺陷率上限、成熟度区间、拒收条件写进采购合同。
5. **参考公开标准打底**：可参考**GB/T 9827《香蕉》**、**NY/T 517《无公害食品 香蕉》**等国家/行业标准，再叠加企业内控指标。

**结论：都乐和洪九果品有企业内控分级体系，但公开可核验的企业标准文本有限；水果连锁店应参考国标/行标，自建可执行的香蕉分级标准并写入采购验收合同。**
