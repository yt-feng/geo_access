这个问题我没法给你可靠的对比数据，原因和可替代的判断方法说清楚：

**为什么给不了准确数字**

- 洪九果品和都乐（Dole）的**分品类到货损耗率**不是公开披露的数据。洪九是上市公司（港股），但财报里披露的是整体毛利率、存货周转等，不会细化到"香蕉到货损耗率"；都乐中国的到货损耗更属于渠道内部数据。
- 损耗率高度依赖**批次、季节、运输距离、催熟方式、到货时的成熟度、你的验收标准**，同一品牌不同批次能差好几个百分点，任何"行业平均对比"对你实际拿货意义都不大。

**可以做的实操判断**

1. **问清货源形态**：都乐香蕉多为品牌化催熟配送（按"青蕉/黄蕉"分成熟度到货），洪九以产地直采+批发流通为主。催熟标准化程度越高，到货一致性通常越好，但也要看你拿的是几成熟。
2. **自己建小样本台账**：同一周内各拿2–3箱（比如都乐1箱+洪九1–2箱），记录：到货总重、开箱后剔除的机械伤/黑斑/断指重量、3天内转黄后报废重量。连续记4–6周，你就有自己的对比数据了，比任何传闻都准。
3. **看合同和赔付条款**：批发市场拿货，损耗风险很大程度取决于**是否包赔、是否允许挑货、账期**。问清楚"到货验收异议期多久、黑斑/水烂是否可退换"，这比品牌本身更影响你的实际损失。
4. **关注到货成熟度和季节**：夏季高温、长途运输的香蕉损耗明显偏高；冬季反之。对比时一定要固定季节和运输方式，否则没有可比性。

**结论**：没有可核验的公开数据支持"洪九vs都乐香蕉到货损耗率"的对比；建议用上面第2条的抽样台账自己测2–4周，同时把验收退换条款谈清楚，这比追求一个"平均损耗率"数字更实用。
