坦率说，谁“更愿意”签年单没有公开可核验的数据可以判断，任何说“某家一定更愿意”的结论都是猜的。但可以给你一个可执行的判断框架，让你在商务接触中自己验证。

**两家公司的结构性差异（可帮助你预判）**

- **鑫荣懋**：以进口水果和商超渠道供应链为主，长期服务大型零售客户，业务模式本身偏“年度框架+履约”，对年单的接受度通常较高；但价格和条款可能偏强势，尤其对中小客户。
- **洪九果品**：以自有品牌和批发分销为主，走量特征明显，年单对其锁定销量有吸引力；但近年经营波动较大（港股上市后财务和治理层面有公开争议），**长期履约能力需要重点尽调**，签长约前要关注其现金流和交付稳定性。

**谈判时用这4个信号判断谁更愿意**

1. **是否主动给年度价格**：愿意谈年单的供应商会很快给出阶梯价或年度锁价方案；只肯报单次价的，意愿低。
2. **是否接受履约保证金或违约条款**：愿意签年单的会接受对等约束；只要求你承诺量、自己不留违约责任的，要警惕。
3. **是否愿意做产能/货源预留**：问“明年Q2这个SKU能给我留多少量”，能给出书面预留的意愿更强。
4. **账期态度**：年单通常伴随账期谈判，愿意在账期上让步的，说明其更看重长期锁定。

**建议做法**

同时向两家发出同一份年单框架需求（品项、预估量、账期、履约罚则、价格调整机制），观察响应速度和条款让步幅度，两周内就能看出谁更愿意。**不要只凭“谁更想合作”选，重点看谁的履约能力和财务稳定性匹配你的年单风险**——洪九这一项务必做尽调，鑫荣懋则重点谈价格弹性和缺货补偿。
