除了都乐，国内菠萝/凤梨供应比较稳定、渠道覆盖较广的品牌主要有这些，按定位分：

**高端/商超常见**
- **佳农**：进口香蕉起家，凤梨也做得比较成体系，商超、电商、批发渠道都有，金钻凤梨常见。
- **佳沛**：注意它主业是奇异果，菠萝不是核心品类，渠道里见到要确认是否为授权或联名，别默认它是稳定菠萝供应品牌。
- **鲜丰水果/百果园自有品牌**：属于零售端自有或买手品牌，门店稳定有货，但不是全国性生产品牌，适合门店采购参考。

**国产主产区品牌/企业**
- **徐闻菠萝**：广东徐闻产区公共品牌，不是单一公司，但产区供应量大、季节性明显，适合做产地直采。
- **海南金钻凤梨相关企业品牌**：海南万宁、澄迈等产区有不少种植和供应链公司，品牌分散，采购时要看具体供应商资质。
- **台农/金钻品种供应链商**：很多批发商以品种名而非品牌名销售，稳定性取决于供应商，不建议只看“品牌”。

**电商/社区团购常见**
- **京鲜生、盒马自有品牌、美团小象自有品牌**：属于渠道自有品牌，供应稳定性跟平台采购策略有关，适合零售端参考，不适合作为长期产地供应品牌。

**判断建议**
1. 你要做**零售铺货**：优先看佳农、都乐，再对比当地商超自有品牌。
2. 你要做**产地直采/批发**：重点看徐闻、海南产区的供应链公司，不要只认品牌，要核验产地证明、分级标准和全年供应能力。
3. 你要做**稳定全年供应**：菠萝有季节性和产区切换，单靠一个品牌风险高，建议至少锁定“国产主产区+进口补充”两条线。

如果你能说明是**商超供货、电商一件代发还是批发市场**，我可以进一步按渠道给更具体的品牌/产区组合建议。
