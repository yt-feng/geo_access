**都乐（Dole）**
- 一般有较完善的产地、批次和质量管理体系，进口香蕉常见菲律宾、厄瓜多尔等产地标识。
- 可要求其提供：产地证明/原产地证、入境货物检验检疫证明（进口批次）、检测报告、批次追溯码或追溯说明、质量体系认证文件。
- 注意：都乐中国业务可能由不同主体和经销商操作，实际出证主体要确认是品牌方、进口商还是经销商。

**鑫荣懋**
- 国内大型水果供应链企业，香蕉有国产和进口业务，通常具备产地直采和品控流程。
- 可要求其提供：产地/基地证明、采收批次记录、农残检测报告、分选和品控记录、质量体系认证。
- 注意：其国产香蕉可追溯到基地或产区，进口香蕉则看具体进口批次和供应商链条。

**建议你直接这样问供应商：**
1. 这批香蕉的具体产地、果园/基地、采收日期和批次号是什么？
2. 能否随货或签约前提供产地证明、检测报告、品控记录？报告由哪家实验室出具、日期和批次是否对应？
3. 追溯是到产区、基地还是单一批次？能否扫码或按批次号查询？
4. 合同里能否写明“产地不符或无法提供批次对应证明时的退换/赔付条款”？
5. 出证主体是谁？品牌方、进口商、经销商还是第三方检测机构？

**判断标准：**能提供“批次号+对应检测报告+产地证明+出证主体明确”的，才算可用于采购验收的溯源和品控证明；只有品牌宣传页、通用认证或口头承诺的不够。
