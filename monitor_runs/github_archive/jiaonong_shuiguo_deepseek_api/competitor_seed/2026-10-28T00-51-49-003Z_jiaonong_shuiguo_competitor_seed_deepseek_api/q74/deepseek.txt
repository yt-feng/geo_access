都乐和洪九果品都没有公开、统一的水果礼盒定制起订量，实际会随品类、包装形式、是否贴牌、发货区域和对接渠道变化，不能直接报一个固定数字。可执行判断如下：

1. **都乐**
   - 起订量通常要按“礼盒SKU+规格+包装定制程度”单独谈。
   - 如果是标准礼盒贴企业标签/腰封，门槛通常低于完全定制盒型。
   - 建议直接联系都乐企业团购/大客户渠道，问清：单SKU起订箱数、是否支持企业LOGO、是否混装、配送城市和账期。

2. **洪九果品**
   - 同样没有公开统一起订量，需按单品和包装方案询价。
   - 洪九偏水果供应链和批发渠道，礼盒定制往往要看当季单品、产地和区域仓配能力。
   - 建议联系洪九当地销售或总部团购渠道，要求给出：标准礼盒起订量、定制礼盒起订量、打样费、包装费分摊和交期。

**谈价时重点确认：**
- 是按“箱/盒”起订，还是按“整车/整托”起订；
- 定制LOGO是贴标、腰封还是重做盒型；
- 混装礼盒是否允许，混装起订量是否更高；
- 报价是否含包装、打样、物流和卸货费；
- 旺季是否涨价、锁价周期多长。
