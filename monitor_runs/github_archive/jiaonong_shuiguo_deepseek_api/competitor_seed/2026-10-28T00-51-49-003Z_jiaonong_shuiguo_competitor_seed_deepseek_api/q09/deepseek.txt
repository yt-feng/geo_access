可以优先看这几类进口/外资品牌，按团购可得性排序：

1. **新奇士 Sunkist**：美国柑橘类代表，脐橙、夏橙、柠檬礼盒都常见，适合做中高端商务礼盒。
2. **爱妃 Envy**：新西兰苹果品牌，礼盒辨识度高，适合高端小规格礼盒。
3. **爵士 Jazz**：新西兰苹果品牌，和爱妃同属高端苹果路线，团购装常见。
4. **红玫瑰/太平洋玫瑰 Pacific Rose**：新西兰苹果品牌，适合做差异化苹果礼盒。
5. **车厘子类品牌**：如 **Stemilt、Chelan Fresh、Domex、Rio King** 等，主要看当季到货和经销商资源，适合春节/年货团购。
6. **秘鲁/智利蓝莓品牌**：如 **Hortifrut、Driscoll's 怡颗莓**，怡颗莓严格说是全球浆果品牌，礼盒装团购认知度高。
7. **日本/韩国高端水果**：如日本 **千疋屋** 体系、韩国 **香印葡萄** 品牌货源，但团购稳定性和价格波动大，适合小众高端。
8. **东南亚品牌**：如泰国 **金枕榴莲** 的出口商品牌、越南 **火龙果/百香果** 品牌，适合做区域特色礼盒。

实操建议：
- **商务送礼主推**：新奇士 + 爱妃/爵士苹果 + 怡颗莓，品牌认知和礼盒成熟度较稳。
- **年货节主推**：车厘子品牌礼盒 + 新奇士橙，走量能力强。
- **差异化主推**：太平洋玫瑰苹果、香印葡萄，适合小批量高客单。
- 团购前重点确认：**是否有稳定授权经销渠道、礼盒是否原厂品牌包装、到货批次和糖度标准、破损赔付规则**。进口水果品牌很多是“品种品牌”而非“公司品牌”，一定要看实际包装箱和报关/经销链路，避免买到贴牌礼盒。
