可以要，但不能只凭“品牌能提供”就判断一定给得到，建议按下面方式核实和约定。

1. **都乐、鑫荣懋通常能提供检测报告**
   - 两家都是大型水果供应链企业，通常可提供批次检测报告或第三方农残检测报告。
   - 但**具体到菠萝、具体批次、具体规格**是否能提供，需要向对接的销售/经销商确认。
   - 如果你是经经销商拿货，报告可能由经销商提供，不一定是品牌方直接给。

2. **采购时要明确问清这几点**
   - 是否有**本批次**的农残检测报告，而不是旧批次或通用报告。
   - 报告检测项目是否覆盖你关心的农残指标，检测机构是否有资质（CMA/CNAS）。
   - 报告上的品名、产地、批次号、供货商名称是否与到货一致。
   - 能否随货提供电子版/纸质版，后续每批是否都能提供。
   - 如果报告由第三方出，费用和周期谁承担。

3. **建议的合同/订单写法**
   - “供方须随货提供与到货批次一致的农残检测报告，检测机构具备CMA/CNAS资质；报告缺失或批次不符的，需方有权拒收。”
   - 先要一份**样品报告**核验格式和项目，再下正式订单。

4. **判断结论**
   - **大概率能提供**，但必须落实到具体供应商、具体批次和合同条款。
   - 不要只听“可以提供”，要拿到**报告样本+批次对应承诺**后再采购。
