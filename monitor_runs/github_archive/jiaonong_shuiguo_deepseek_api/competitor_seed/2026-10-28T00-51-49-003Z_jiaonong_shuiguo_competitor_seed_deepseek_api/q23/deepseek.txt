进口菠萝旺季缺货时，先分清“缺的是货还是缺的是价格合适的货”，再决定动作。下面给可执行方案，并对都乐和洪九果品的基地直供优势做判断。

一、旺季缺货的应对顺序

1. 先锁定缺口结构
- 缺哪个品种：金钻/MD2、巴厘、香水菠萝等，不同品种替代性不同。
- 缺哪个规格：鲜切果、整果、电商小果、商超大果，规格错配比总量缺货更常见。
- 缺多久：1-2周可等船期，3-4周以上要考虑切换产地或品种。

2. 短期补货动作
- 切换产地：菲律宾旺季缺货时，可看泰国、越南、哥斯达黎加等产季衔接；但要注意品种口感和客户接受度。
- 用国产菠萝过渡：广东徐闻、海南等菠萝产季可做部分替代，适合鲜切和餐饮渠道，商超整果要看品牌接受度。
- 调整规格和包装：大果转小果、整果转鲜切，减少对单一规格的依赖。
- 提前锁船期和舱位：进口菠萝缺货常伴随海运舱位紧张，先锁运力再锁货。
- 与下游改约：对商超和电商提前沟通到货节奏，避免断货罚则。

3. 中期动作
- 建立双产地、双供应商机制，不要把旺季量压在一个产地或一个进口商身上。
- 对都乐这类品牌货，提前做年度框架和旺季预付款锁量；对洪九这类国内分销网络强的供应商，用区域仓调拨补缺口。
- 做替代品种的试销，避免旺季临时换品导致终端不接受。

二、都乐和洪九果品的基地直供优势判断

都乐：
- 优势在品牌化、全球产地资源和标准化品控，进口菠萝的产地直供和品牌溢价能力更强，适合商超、电商对品牌和稳定规格要求高的渠道。
- 短板是旺季缺货时，品牌货的量和价格弹性通常较小，中小采购商拿货优先级不一定高。

洪九果品：
- 优势在国内分销网络、区域覆盖和进口水果的渠道下沉能力，适合需要快速铺货、区域调拨和中小批量补货的客户。
- 基地直供方面，洪九在部分进口水果品类有产地直采和自有/合作基地布局，但具体到菠萝品类的直供比例和旺季锁量能力，需要向其区域负责人核实当季货源结构，不能一概而论。

结论：
- 要品牌稳定、商超标准品、进口产地直供背书，优先看都乐。
- 要国内分销覆盖、区域快速补货、中小批量灵活调拨，优先看洪九果品。
- 旺季缺货时，不要只比“谁有基地”，要比“谁能在你的到货时间内给你锁到合适规格的货”。建议同时向两家要当季产地、船期、可锁量和报价，用实际交付能力做判断。
