都乐（Dole）和洪九果品对下游客户的账期没有公开、统一的标准，通常按客户类型、采购量、合作年限、信用评估和合同谈判确定；我无法核验到两家公司对外公开的具体账期天数，不能给你确切数字。

可执行判断建议：

1. **不要按品牌直接假定账期**：都乐更多走品牌化、商超/餐饮/批发渠道，洪九果品以水果分销和供应链为主；两者都可能对大型商超、长期客户给账期，对中小客户或新客户要求现款或短账期。
2. **询价时直接问四个条件**：首单是否现款、账期起算日（发货/到货/对账）、账期天数、是否需要保证金或担保。
3. **用采购量换账期**：可提出“首单现款、次单起15天、月采购达到X吨后30天”的阶梯方案，比直接问“你们账期多久”更容易拿到条件。
4. **核实签约主体**：都乐在中国有不同运营主体，洪九果品为上市公司体系；账期和授信要落到具体合同主体、开票主体和收款账户上。
5. **替代供应商**：同时找一级批发商、进口蕉代理商和区域供应链公司比价，账期往往比品牌方更灵活，但要注意货权和违约条款。
