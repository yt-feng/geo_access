关于茶饮店采购菠萝原料时要求提供农残检测报告的问题，**都乐（Dole）** 和 **鑫荣懋（Xinrongmao）** 作为大型水果供应商，**通常可以提供农残检测报告**，但具体情况取决于采购渠道、批次和合作方式。

以下是一些具体建议：

1. **直接联系供应商或采购方**：最可靠的方式是联系你的采购对接人（如批发商、区域经销商或官方客服），明确要求提供该批次菠萝的**第三方检测报告**或**供应商自检报告**。大型公司通常会保留此类文件用于合规。
   
2. **确认报告覆盖范围**：请确保报告包含**农药残留项目**（如有机磷、菊酯类等），并符合中国国家标准（GB 2763）或茶饮品牌方内部要求。如果是进口菠萝，还需有海关报关单和检疫证明。

3. **其他备选方案**：如果对方无法直接提供，可要求他们提供**上游基地或加工厂的检测资质**，或建议你自行送样至有资质的检测机构（如SGS、华测检测）进行检测，费用通常由采购方或供应商协商承担。

4. **行业惯例**：都乐作为跨国品牌，普遍有完善的质量体系；鑫荣懋作为国内头部生鲜企业，也通常有相关文件支持。但**小商户或非直供渠道**可能难以获取，需要走正式合同流程。

建议你在采购前，先通过电话或邮件书面确认报告事宜，并保留沟通记录，以保障合规和后续追溯。如果对方无法提供，需评估是否更换供应链。
