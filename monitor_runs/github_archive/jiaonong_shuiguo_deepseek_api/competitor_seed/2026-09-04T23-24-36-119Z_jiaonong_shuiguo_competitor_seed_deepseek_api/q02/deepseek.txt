除了都乐（Dole）之外，目前国内及进口市场能够稳定供应菠萝的品牌还有以下几个，按供应稳定性划分：

**一、大品牌主体（稳定优先）**
1. **金菠萝（Golden Pineapple）**：都乐旗下的核心品类之一，但如果你需要“非都乐”的稳定供应，可以直接关注其姊妹品牌——**佳沃（Joyvio）**，它是联想控股旗下的果业公司，有长期稳定的海南、菲律宾基地供应，商超和电商供货都较频繁。
2. **达乐（Dole）的竞争者——美国Driscoll's**：虽然以浆果知名，但近年来也布局菠萝品类，但规模较小。更主流的是**怡颗莓（Driscoll's）**的菠萝，主要在华东精品超市。
3. **墨西哥品牌**：如 **MegaFresh**、**Sun Belle**，主要供应美国及亚洲市场，国内部分高端批发市场有稳定渠道，但市场覆盖面不如都乐。
4. **国内优质品牌**：**海南红金龙**、**海南神泉集团**（产地直供，长期供应台农17号、香水菠萝等），主要走商超和社区团购，尤其是电商渠道，稳定性较高。

**二、区域型稳定批发渠道（非单一品牌，但能保证货源）**
- **广州江南果菜批发市场**、**上海辉展水果市场**内的**百果园**（旗下有“百果心享”）和**鲜丰水果**的自有品牌菠萝，这两家均有签约基地和稳定采购计划，供应全年不断。

**三、注意事项**
- 目前市面流通的进口菠萝（如都乐）以菲律宾产为主，稳定供应商家通常选**菲律宾德尔蒙特（Del Monte）**作为替代——它和都乐同为国际水果巨头，在国内也有成熟的冷链代理，很多渠道商直接通过其官方代理拿货，属于高稳定性选项。

建议采购时优先联系后三家（佳沃、百果园体系、德尔蒙特代理），并核对《入境货物检验检疫证明》和基地备案号，避免非正规渠道货物断供。如果您的需求是个人或小规模购买而非大宗批发，也可以直接选择“海南神泉”或“徐闻菠萝”地标品牌，当地政府和农业合作社能保证全年分批出货。
