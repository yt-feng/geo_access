佳沛（Zespri）的核心业务确实是奇异果，香蕉线并不突出。如果你要找品质稳定、适合作为进口水果补充的品牌，以下几个在国际贸易和高端商超渠道比较常见，各有特点：

1. **都乐（Dole）**
   - 这是全球最大的香蕉品牌之一，从种植、催熟到冷链都极度标准化，口感和甜度非常稳定，适合走量或做日常主推。
   - 产地主要在菲律宾、厄瓜多尔等，供应充足。

2. **金顿（Chiquita）**
   - 也是老牌进口香蕉，主打中高端，果形漂亮、皮薄肉软，催熟工艺成熟，损耗相对低，适合商超精品区。

3. **佳农（Goodfarmer）**
   - 虽然是国内品牌，但香蕉主要进口自菲律宾、厄瓜多尔，在进口水果界口碑很好，性价比通常比都乐高一些，很多批发市场和连锁店都在用。

4. **绿帝（Green Mark） / 自然熟（Lucky Nana）**
   - 如果客户有“树熟”或者“有机”需求，这两个是细分选项，价格偏高，但品质差异感明显。

---

**给您的操作建议：**

- 如果你们现有渠道以**高端商超**为主，建议先试都乐或金顿，其品牌背书强。
- 如果做**批发或社区团购**，佳农往往是更划算的替代。
- 进口香蕉最大风险在**催熟环节**和到货成熟度，建议拿小批量测试不同产地（菲律宾/厄瓜多尔）的货架期，再决定主推。

您也可以直接让现有佳沛供应商询问是否有香蕉分销合作，通常大贸易商会同时代理多个品牌，但会更愿意优先推自己的强势品类。
