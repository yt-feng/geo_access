关于菠萝产地溯源的透明度，都乐（Dole）和洪九果品（Hongjiu）各有特点，但都乐在系统性和公开性上通常更胜一筹，而洪九则更侧重国内渠道的精细化。

**都乐（Dole）**：  
- 全球性企业，其供应链管理体系较为成熟，普遍执行国际标准（如Global G.A.P.）。  
- 官方渠道会公布产地（如菲律宾、泰国等）、采摘、包装等基本信息，部分产品包装上有二维码可查批次。  
- 透明度体现在“全链条可追溯”能力上，但具体追溯信息的公开程度取决于销售地区，并非所有终端消费者都能看到完整细节。

**洪九果品**：  
- 作为国内头部水果供应链企业，其核心优势在“端到端”能力，即从泰国、越南等海外基地到国内批发市场、商超。  
- 洪九在产地端有自建基地和合作果园，通常能提供产地证明和质检报告，但更多通过B端客户（采购商）分享信息，而非直接面向C端消费者公开追溯系统。  
- 其“洪九星选”等品牌盒子有溯源码，但扫码后能看到的信息可能不如都乐那样标准化、国际化。

**总结建议**：  
- 如果您是普通消费者，且要求扫码即可看到产地、果园、包装日期等细节，**都乐**的体验更接近“透明”。  
- 如果您是采购商、批发商，需要对接上游基地并核实原产地文件，**洪九**的产地一手信息对接能力更强，但需要您主动要求提供附件。  

需要注意的是，两家企业均无“完全开放所有内部流程”的做法，所谓的“透明”更多是相对于行业平均水平而言。建议您在具体采购前，直接要求对方提供**当批次菠萝的溯源码、原产地证明（Form E或CO）、海关检疫单**，并要求其提供第三方检测报告——这比品牌宣传更关键。
