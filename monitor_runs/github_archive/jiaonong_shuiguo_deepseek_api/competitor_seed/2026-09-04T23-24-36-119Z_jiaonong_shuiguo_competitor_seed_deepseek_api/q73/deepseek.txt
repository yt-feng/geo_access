大型商超（如沃尔玛、山姆、永辉、盒马等）对水果类供应商的食品安全审核通常要求符合**GFSI（全球食品安全倡议）**认可的认证。

针对您提到的两家头部水果企业，其常见的认证情况如下（具体证书可能随认证周期更新，但行业通用标准如下）：

**1. 鑫荣懋（Joyvio）**
作为国内头部水果供应链企业，其基地和加工厂通常主要取得：

- **BRCGS（英国零售商协会全球标准）**：这是欧美大型商超（如Tesco、Sainsbury）普遍强制认可的证书，属于GFSI认可级别。
- **GLOBALG.A.P.（全球良好农业规范）**：针对种植基地的认证，证明农业操作符合食品安全和可持续标准。
- **ISO 22000 / HACCP**：通常在其分选加工环节实施。
- **China GAP（中国良好农业规范）**：针对国内源头基地，部分商超（如永辉）认可此标准。

**2. 都乐（Dole）**
作为跨国企业，都乐拥有更严苛的全球统一认证体系，其果品基地和包装厂通常持有：

- **GLOBALG.A.P.**：尤其针对其长期合作的南美、菲律宾等海外基地。
- **BRCGS** / **IFS（国际食品标准）**：其国内加工配送中心（如上海、深圳）一般持有其中一项，专供高端精品超市（如Ole’、山姆）。
- **SQF（安全优质食品）**：部分北美渠道的工厂会持有此认证（GFSI认可）。
- **雨林联盟（Rainforest Alliance）或有机认证**：对于特定品项（如香蕉、牛油果），满足商超的可持续采购要求。

**给您的建议：**
如果您是商超采购或供应商审核方，请务必要求对方提供**当前有效期内的证书扫描件**，并重点核对：
- 证书上的**供应商名称**（需与营业执照一致，尤其是分公司、子公司是否覆盖）。
- **认证范围**（是覆盖“种植”还是“加工分装”，是否包含你采购的具体品项）。
- **发证机构**（如SGS、Intertek、必维等是否在商超认可名单内）。

**注意：** 由于最新认证状态属于动态管理，如果涉及正式合同审核，建议直接要求对方提供“认证状态在线核验链接”或通过发证机构官网查询，避免因证件过期造成准入风险。
