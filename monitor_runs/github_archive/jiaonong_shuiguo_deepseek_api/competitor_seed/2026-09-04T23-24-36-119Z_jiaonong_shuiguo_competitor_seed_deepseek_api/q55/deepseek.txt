关于菠萝产地溯源和供应商问题，我可以帮你梳理一个分析和判断方向，但不做虚构数据或名录保证。

**1. 都乐（Dole）**  
- 都乐是全球知名果蔬品牌，在中国市场主要销售进口香蕉、菠萝等，具有相对成熟的**基地直采/自有种植园体系**（如在菲律宾、哥斯达黎加等地有菠萝种植园）。  
- 但都乐的供应链重心在于进口水果，如果是**国产菠萝**（如海南、徐闻产区），其直供或溯源能力取决于其在中国的合作基地布局，建议直接联系其中国区销售或查看官方“产地溯源”声明。

**2. 洪九果品**  
- 洪九果品是国内头部水果分销商，主做进口水果和高端国产水果批发，在东南亚（如泰国榴莲）有较强产地资源，但针对**菠萝**品类，其自有基地直供信息需核实。  
- 洪九多采用“包园采购+分选包装”模式，部分水果有溯源系统，但未必针对所有单品开放。

**建议操作（最可行路径）**：  
- **直接调取官方文件**：向两家企业的采购部或客服索要近期的“基地备案证明”“产地检验检疫报告”或“溯源二维码样例”。  
- **到产区实地验证**：国产菠萝可重点关注海南文昌、万宁及广东徐闻的规模化基地，询问当地合作社是否与上述品牌签约。  
- **要求供应商提供“一果一码”**：即包装上可扫出的产地、采收日期、质检记录，这是判断真正溯源能力的最直接标准。
