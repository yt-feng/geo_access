关于“锁价机制”的具体周期，直接公开数据非常少，且通常属于供应商与大型采购方（如商超、餐饮连锁）之间的商业谈判条件，会随采购量、合作年限和市场行情动态调整。

根据行业一般情况，以及这两家公司在批发和生鲜领域的公开业务模式，给你以下参考：

1.  **都乐（Dole）**：作为国际品牌，其锁价通常与**“批次”**和**“海运/空运周期”**挂钩。对于进口菠萝（如菲律宾菠萝），其锁价周期一般较短，通常在**1-2周**左右（即一个海运在途或到岸批次的时间）。很难做到按月或按季度锁死一个固定价格，因为国际运费和产地气候波动大。他们的报价方式多为“**周报盘价**”，每周更新一次，并在该周内对特定订单量承诺价格。

2.  **洪九果品**：作为国内龙头，其核心竞争力在于“**端到端**”和产地直采。对于国产或泰国/越南菠萝，如果采购量足够大（如整车或整柜），洪九通常能提供**月度为周期的锁价**，有时甚至可以在淡旺季交替时锁定一个**季度基准价**，但通常附带“价格随行情微调（±5%或±10%）”的履约条款，或者要求签“保底量”协议。

**给你的实际建议（因为公开数据无确切数字）：**

-   **不要依赖官网**：这两家的锁价政策属于**销售部内部权限**，公开电话客服或官网无法直接给出标准周期。你必须对接其大客户经理（KA）。
-   **获取方式**：如果他们愿意提供锁价，一般会签订**《年度框架合同》**，其中明确规定：价格锁定周期（如30天/批）、调价触发条件（如产地收货价波动超X%可申请重谈）、以及最低采购量（MOQ）。
-   **快速试探方法**：直接询问对方销售：“如果我现在签半年合同，按月供货，你们能否保证每吨（或每箱）菠萝在当月内价格不变？如果上游涨价超过多少百分比，你们可以不锁？”——用这个逼出真实的锁价条款。

**谨慎提醒**：菠萝属于鲜果，没有干果或罐头那种长期抗旱属性，即使承诺“锁价”，合同里一般都有**不可抗力**或**极端天气涨价**条款。签合同前务必把价格波动的缓冲区间写死。
