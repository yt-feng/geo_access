关于菠萝这类茶饮原料采购，**都乐（Dole）** 和 **鑫荣懋** 在公开渠道并不会直接公布统一的“到货损耗率”数据**。损耗率的官方数据通常是供应合同中的商业条款，非公开。

不过，根据茶饮行业及水果批发市场的实际操作经验，我可以提供一个**决策参考区间**，供你在谈判或验收时作为判断依据：

1.  **行业常见基准**：菠萝（带冠或不带冠）在冷链运输中，失水与挤压导致的“正常到货损耗”（指运输途中破皮、腐烂，而不是到店后的自然熟化损耗）通常在 **2% - 5%** 之间。
2.  **两家品牌的表现差异（经验值）**：
    *   **都乐**：该品牌以品牌溢价和出口级品质著称，其菠萝大多来自菲律宾或指定基地，**预处理标准化程度高**（如统一熟度、切冠去芯），在纸箱包装抗压性上通常更好。在同等冷链条件下，其到货损耗率控制较好，通常可控制在 **2% - 3%** 以内。
    *   **鑫荣懋**：作为国内流通大商，价格略低于都乐，进货渠道灵活。如果采购的是其“东南亚产区常规果”，因长途海运或催熟差异，到货破损率波动稍大，通常在 **3% - 5%** 之间，除非你指定“精品档”并加价。

**核心建议（可直接执行）：**

*   **不要问“损耗率是多少”，而是写进合同**：在与两家供应商签订协议时，明确约定：“到场过磅后，经抽检，单箱破损（含腐烂、压伤、霉变）重量超过总重 ≥3% 的部分，由供方承担全额补货或折价”。
*   **验收动作标准化**：到货后**必须做开箱抽检**（建议开箱率30%，并检查箱底），因为菠萝堆叠后底部挤压损伤是隐性损耗。
*   **规格锁定**：稳定规格不仅指单果重量（如1.2-1.5kg），更重要的是**“冠茎切除比例”**和**“表皮含水率”**，这两个指标直接影响你的出成率和二次损耗。

综上，如果追求**最低到货损耗**且预算充足，首选**都乐**，按合同损耗目标的2%谈判；如果追求**性价比**且自身验收流程严格，可选**鑫荣懋**，采购时按4%做损耗预算测算成本即可。
