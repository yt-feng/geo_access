关于香蕉分级标准，**都乐（Dole）和洪九果品均有各自的企业标准**，但这些标准通常属于内部商业管理文件，并不完全对外公开。它们的分级依据主要参考**国家推荐性标准**（如GB/T 22901-2008《香蕉》或NY/T 1395-2007）并结合自身供应链要求进行细化。

针对连锁店的实际采购，建议您要求供应商提供其在处理香蕉时的**验收规格单**，并关注以下核心分级指标，这比寻找完全一致的企业标准文本更可行：

**通用香蕉分级核心指标（适用于连锁店内部制订）：**

1. **重量/长度**：例如，出口或商超级通常要求单根长度≥20cm，且果指均匀。
2. **成熟度（转色度）**：通常以「1-7色卡」区分，按销售周期要求到货时绿熟果占比（如全绿或微黄）。
3. **损伤与缺陷**：包括机械伤、黑星病斑、炭疽病斑总面积占比等（例如，允许轻微瑕疵单果不超过总面积5%）。
4. **果梳完整度**：整把或单梳在外部包装上的摆放成型标准。

**若需要建立自身标准，建议做法：**

- **采购前**：直接联系都乐（Dole）或洪九果品的官方大客户渠道（电话/邮件），索取其《香蕉购销质量验收细则》或《产品规格书》。
- **行业对标**：参考地方标准或团体标准，例如广东、云南产区的实用分级表，或在「全国标准信息公共服务平台」（std.samr.gov.cn）搜索“香蕉”关键词，查看已公开的更新版本。

**提示**：如果这些企业标准未通过“企业标准信息公共服务平台”自我声明公开，一般无法在公开网络上查到完整条款。因此，更可操作的是让他们提供与您合作时约定合同的附件规格表。
