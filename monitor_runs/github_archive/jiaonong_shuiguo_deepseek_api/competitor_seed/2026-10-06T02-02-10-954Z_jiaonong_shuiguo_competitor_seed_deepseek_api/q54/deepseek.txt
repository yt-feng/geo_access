# 都乐（Dole）与鑫荣懋进口苹果的产地溯源怎么做

先说明一个前提：具体批次的溯源信息必须通过**供应商提供的单据和官方查询系统**核验，我不能凭空给出某批货的产地数据。下面给你可执行的判断框架。

## 一、先分清两家企业的性质

- **都乐（Dole）**：总部在美国、有全球种植和供应链体系的品牌商，很多进口苹果是其自有或合作果园直供。
- **鑫荣懋**：中国本土的大型水果供应链企业，主要做全球采购、分销，代理/引进多个海外品牌（如新西兰、智利、美国等产地苹果）。

**关键区别**：都乐偏“品牌方直供”，鑫荣懋偏“供应链服务商/进口商”。溯源路径不同。

## 二、溯源要拿到哪些材料（采购方必查）

按“从哪来→谁运来→是否合法入境”三层：

**1. 产地层**
- 果园/包装厂注册号（GlobalG.A.P.、产地国果园注册码）
- 原产地证明（Certificate of Origin）
- 品种、批次号、采摘/包装日期

**2. 进口层**
- 入境货物检验检疫证明（海关出具）
- 报关单（显示原产国、HS编码、数量）
- 植物检疫证书（出口国官方出具）

**3. 品牌/链路层**
- 都乐/鑫荣懋的授权或供货合同
- 箱唛（Carton Mark）上的批次、产地代码
- 冷链与物流轨迹记录

## 三、具体怎么操作

**对都乐：**
- 向都乐中国或其授权经销商索要该批次的**产地证明 + 海关入境检疫证明 + 箱唛照片**。
- 都乐部分产品有包装二维码，可扫出批次信息；也可通过其官方客服核验批次真伪。

**对鑫荣懋：**
- 因其中间商角色，要**逐层要单据**：鑫荣懋 → 海外供应商/品牌方 → 果园。
- 重点核对**报关单上的原产国**是否与标签一致，防止“转口货冒充原产”。
- 可要求提供其溯源系统截图或合作品牌方的授权文件。

## 四、超市采购的实操建议

1. **合同里写死溯源条款**：供应商须随货提供上述单据，缺一可拒收。
2. **核对“三码一致”**：箱唛产地码 = 报关单原产国 = 检疫证书签发国。
3. **扫码验证**：优先采购带可扫码溯源标签的批次。
4. **留样与抽检**：对高单价进口苹果做批次留样，必要时送第三方检测（农残、产地成分可辅助判断）。
5. **警惕低价“进口”**：转口贸易、二次分装容易造成产地模糊。

## 五、核验渠道

- 海关总署“进出口食品化妆品进出口商备案系统”可查进口商备案。
- 中国国际贸易“单一窗口”可核验报关信息（需权限）。
- 都乐、鑫荣懋官网/客服可核验授权渠道与批次。

**底线判断**：只要有一层单据缺失或“三码不一致”，这批货的产地溯源就不可信，不建议直接上架销售。需要我帮你把上面的核查清单做成一张可打印的验收表吗？
