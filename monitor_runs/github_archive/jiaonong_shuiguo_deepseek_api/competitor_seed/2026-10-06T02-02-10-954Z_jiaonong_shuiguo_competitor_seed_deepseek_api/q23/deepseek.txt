进口菠萝旺季缺货，本质是“海外产区节奏 + 船期 + 国内渠道库存”三层错配，不是单纯没货。可以按下面思路处理。

**一、先判断缺的是哪一类货**
1. **都乐金菠萝/菲律宾系**：旺季缺货通常来自菲律宾产区雨季、台风或船期延误。
2. **哥斯达黎加/厄瓜多尔系**：更多受海运舱位、到港检疫和批发市场分流影响。
3. **泰国小菠萝/香水菠萝**：边境陆运和口岸通关速度影响大。
4. **台湾凤梨/海南菠萝**：国产替代窗口，但品种和口感差异明显。

**二、可执行的补货方案**
- **短期**：优先找上海辉展、广州江南、嘉兴水果市场的一级批发商，问“在途柜”和“未卸柜”，不要只问现货。
- **锁柜**：直接跟进口商锁未来2—4周到港的整柜，接受分批提货，降低断货概率。
- **替代**：用国产海南/广东菠萝做鲜切、餐饮、饮品渠道替代；高端零售再保留都乐等品牌。
- **渠道切换**：如果做电商/社区团购，可临时切泰国小菠萝、国产金钻凤梨，避免单品断档。
- **价格策略**：旺季缺货时不要硬扛原价，提前设“替代SKU+组合装”，减少客户流失。

**三、都乐和洪九果品的基地直供优势**
- **都乐**：优势在**品牌化标准、海外长期合作农场、全球供应链和品控体系**。它不一定在每一个产地都“自有基地”，但更接近“深度合作基地+全球采购”模式，适合稳定做高端商超和品牌零售。
- **洪九果品**：优势在**国内分销网络、进口水果渠道覆盖和部分海外产地直采**。它更强调从产地到批销的高效流通，适合做批发、商超供货和规模化分销。
- **谁更有基地直供优势**：如果看**海外高端菠萝的稳定标准和品牌溢价**，都乐更强；如果看**国内批发流通效率和渠道下沉**，洪九果品更有优势。两者不是同一维度的“基地直供”。

**四、实际建议**
- 做高端零售：优先都乐，缺货时用其替代产地或国产精品凤梨补位。
- 做批发/商超供货：可同时对接洪九果品和一级进口商，锁在途柜。
- 做饮品/餐饮：不必死守品牌，按糖酸比和出成率选国产或泰国小菠萝更划算。
- 最稳的做法：**不要只依赖一个品牌或一个产地，建立“海外品牌+国产替代+批发市场现货”三层供应。**
