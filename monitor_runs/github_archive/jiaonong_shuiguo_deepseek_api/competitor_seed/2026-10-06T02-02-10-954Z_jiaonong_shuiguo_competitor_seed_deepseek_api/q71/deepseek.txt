都乐和洪九果品都属于大型水果供应链企业，但具体到“菠萝原料采购”这件事，需要先分清一件事：**它们的基地不是单一固定地点，而是多产区、多仓储、多加工点协同供应**。下面给你可判断的信息。

## 1. 都乐

都乐在中国市场的菠萝供应，主要不是靠“一个自有基地”，而是通过：

- **进口菠萝**：主要来自菲律宾、泰国等东南亚产区，其中菲律宾菠萝在都乐体系里占比较大。
- **国内合作种植/加工点**：在广东、海南、广西等菠萝主产区有合作基地或采购加工体系，但具体名单和产能一般不会完全公开。
- **供应链节点**：上海、北京、广州、深圳等地通常有仓储分拨中心，用于稳定供货。

对茶饮采购来说，都乐的优势是**标准化程度高、全年供应相对稳**，但成本通常高于国内产区直采。

## 2. 洪九果品

洪九果品是水果分销和供应链企业，菠萝属于其重点单品之一。它的供应体系一般是：

- **国内产区**：广东徐闻、海南、广西等菠萝主产区有采购和合作基地。
- **进口来源**：菲律宾、泰国等也有进口菠萝渠道。
- **加工分选中心**：在重庆、广州、上海、北京等地有分拨和加工布局，具体到菠萝的加工点要看当年产季和订单情况。

洪九的特点是**渠道广、产区切换能力强**，适合做稳定批量供应，但不同产季的品质波动需要你自己验厂验货。

## 3. 茶饮采购更该关注什么

如果你要的是“稳定供应”，不要只问基地在哪里，而要确认下面几点：

1. **你要的是鲜果、冷冻果肉、果茸还是浓缩汁**
   - 鲜果：看产区季节和冷链。
   - 冷冻果肉/果茸：看加工厂和锁鲜工艺。
   - 浓缩汁：看糖度、酸度、风味还原度。

2. **全年供应方案**
   - 国内菠萝主产季：广东徐闻、海南、广西。
   - 非产季：靠进口或冷冻库存。
   - 要问供应商：**产季切换时，风味和糖酸比怎么稳定？**

3. **验厂和样品**
   - 要求提供加工厂地址、批次检测报告、农残报告。
   - 先拿小样做盲测，再谈年度框架。

4. **合同里写清楚**
   - 糖度范围、酸度范围、果肉率、异物标准、冷冻温度、到货温度。
   - 断供替代方案和赔付条款。

## 4. 直接建议

如果你要找都乐或洪九做菠萝原料供应：

- **都乐**：适合对品牌、标准化、全年稳定要求高的茶饮品牌，但价格通常偏高。
- **洪九**：适合批量采购、多产区调配，但需要你自己加强品控和验厂。
- **更稳的做法**：不要只押一家。可以“都乐/洪九 + 国内徐闻/海南直采 + 冷冻果肉备用”组合供应。
