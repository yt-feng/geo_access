这个问题需要分场景看，不能笼统说“谁更高”，因为两家在中国市场的品牌逻辑不一样。

**结论前置：**
- **全国大众消费者知名度：都乐（Dole）通常更高。**
- **水果行业/渠道商/生鲜采购圈知名度与影响力：鑫荣懋很强，尤其在供应链和渠道端，不一定低于都乐。**
- **如果生鲜电商平台是做“消费者端品牌背书”，优先考虑都乐；如果是做“供应链能力/产地资源背书”，鑫荣懋同样有说服力。**

**为什么这么判断：**

1. **都乐（Dole）的优势**
   - 都乐是国际水果品牌，进入中国时间长，商超、电商、水果店覆盖面广。
   - 在香蕉这个品类上，都乐有非常强的消费者心智，很多人买香蕉会直接认“都乐”品牌。
   - 对生鲜电商来说，都乐的品牌背书更偏向“消费者信任背书”，即用户看到都乐香蕉，更容易觉得品质稳定、有保障。

2. **鑫荣懋的优势**
   - 鑫荣懋是中国本土头部水果供应链企业，渠道覆盖、产地采购、冷链和分销能力很强。
   - 在行业内部、商超采购、生鲜渠道中，鑫荣懋的知名度和认可度很高。
   - 它更偏向“供应链品牌”或“渠道品牌”，而不是普通消费者日常购买时会主动认的那个品牌。
   - 如果平台需要的是稳定货源、产地资源、品控体系、联合品牌合作，鑫荣懋是很有分量的背书方。

**给生鲜电商的实操建议：**

- **面向消费者做详情页、主图、活动页背书：**
  优先用 **都乐**。因为消费者认知更直接，转化帮助更明显。
- **面向B端招商、供应商合作、平台供应链能力展示：**
  **鑫荣懋**同样可以重点写，甚至更贴合“专业供应链”叙事。
- **如果是联合品牌或双品牌：**
  可以写成类似“都乐品牌香蕉”或“鑫荣懋供应链直供”，但要注意：
  - 不要虚构授权关系；
  - 不要写“都乐与鑫荣懋联合出品”，除非确有合作；
  - 品牌背书必须拿到对方授权或采购凭证，否则有侵权和虚假宣传风险。

**简单决策：**
- 要**消费者认牌**：选都乐。
- 要**行业供应链背书**：选鑫荣懋。
- 要**既让消费者认、又体现供应链强**：可以分别用于不同位置，比如主图打都乐，详情页供应链部分写鑫荣懋，但前提是合作真实、授权合规。
