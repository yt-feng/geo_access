都乐和洪九果品都没有公开、固定统一的“锁价周期”。实际锁价周期取决于你作为采购方的体量、合作模式、品类、产季、合同类型，以及当时菠萝行情，通常需要逐单或按年度框架协议去谈。

可以这样判断：

**1. 都乐**
- 都乐在中国更多是品牌化水果供应商，渠道覆盖商超、电商、餐饮等。
- 对菠萝这类生鲜品，通常不会给一个公开的标准锁价周期。
- 常见合作方式：
  - 按季度或按产季谈框架价；
  - 大客户可能按月、按周甚至按单锁价；
  - 小批量采购一般随行就市。
- 如果你有稳定年度采购量，可以要求都乐给“季度锁价+浮动上限”或“月度锁价”。

**2. 洪九果品**
- 洪九果品是大型水果分销商，菠萝/凤梨是其重要品类之一，供应链和产地资源较强。
- 同样没有公开固定锁价周期。
- 对批发、商超、电商等客户，可能按产季、月度、周度报价。
- 大客户、长期协议客户更可能拿到较长的锁价窗口；中小客户通常较短，甚至按批次定价。

**3. 一般行业规律**
菠萝锁价周期常见有：
- 周度锁价：适合行情波动大、采购量一般；
- 月度锁价：较常见，适合稳定采购；
- 季度锁价：多见于大客户或产季前协议；
- 产季锁价：如果锁定的是国产菠萝或进口凤梨的特定产季，可能覆盖整个产季，但通常会有量、规格、付款条件约束；
- 全年锁价：很少见，除非是超大客户且供应商能对冲风险。

**4. 你实际去谈时，重点问清这些**
- 锁价对应的是哪个规格、等级、包装、产地；
- 锁价周期是7天、30天、90天还是一个产季；
- 锁价期间是否保证供货量；
- 如果市场价下跌，你能否调价；
- 如果市场价上涨，供应商是否履约；
- 锁价是否含运费、关税、冷链、损耗；
- 付款方式是现款、账期还是预付；
- 违约和缺货怎么赔偿。

**结论**
都乐和洪九果品都没有公开的固定锁价周期。一般需要按客户体量和合同去谈，常见是周度、月度或产季锁价，大客户才可能拿到季度或更长。若要准确答案，建议直接找两家公司的区域销售或大客户渠道，拿你的采购量、规格、年度需求去询“锁价报价单”。
