都乐和洪九果品的具体账期属于商业条款，通常不对外公开披露，而且会因客户类型（商超、电商、批发市场、餐饮连锁等）、采购量、合作年限、信用评级、单品和季节而差异很大，所以没有一个固定的“官方账期”。以下是可核验的行业惯例和判断依据，以及可落地的谈法。

**1. 公开信息能确认什么**
- 都乐（Dole）是全球果蔬巨头，在中国有香蕉业务，主要通过经销商、商超直供等渠道。上市公司层面会在年报中披露整体应收账款周转天数（DSO），但这是全品类、全渠道的平均值，不能直接等同于香蕉给单个客户的账期。
- 洪九果品是港股上市公司，以水果分销为主，香蕉是其核心单品之一。其年报会披露应收账款周转天数等整体指标，同样不等于具体客户能拿到的账期。

要拿到准确账期，只能直接向其销售/大客户部门询价谈判，或问已有合作的同行。

**2. 行业常见账期区间（供谈判参考）**
- 大型商超/连锁：通常 30–60 天，强势渠道可能 60–90 天。
- 电商/社区团购：多为 7–30 天，部分平台压账期更久。
- 批发市场/二级经销商：现款或 7–15 天居多。
- 餐饮连锁/加工厂：15–45 天较常见。
- 新客户首单：多数要求现款或预付，合作后再逐步给账期。

**3. 更现实的建议**
- 直接联系都乐中国和洪九果品的销售部门，说明你的采购量、结算方式、回款能力，询“账期+价格+起订量”组合。
- 如果对方账期不理想，可考虑其他能提供账期的香蕉供应商：大型水果进出口商、区域一级批发商、进口蕉品牌代理商，通常比头部品牌更灵活。
- 谈判时准备好营业执照、近半年流水、下游合同等，账期本质是信用授信，材料越全越容易谈。
