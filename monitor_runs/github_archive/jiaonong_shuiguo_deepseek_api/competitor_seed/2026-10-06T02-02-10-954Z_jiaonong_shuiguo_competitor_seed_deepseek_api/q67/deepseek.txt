从公开信息看，**都乐（Dole）和洪九果品都可能提供品牌营销素材，但通常不是“公开随便下载”，而是要通过商务合作或渠道对接获取。** 能不能拿到、拿到什么形式，取决于你和他们的合作层级。

**具体来说：**

- **都乐（Dole）**  
  作为国际水果品牌，都乐对品牌视觉、商标、产品图、宣传文案有较严格的管理。  
  生鲜电商如果想用都乐的素材做营销，一般需要：
  - 先建立采购或经销合作关系；
  - 由对接的业务/市场人员提供官方授权的图片、LOGO、产品卖点、视频等；
  - 部分素材可能只允许在指定渠道、指定时间内使用。  
  **没有合作关系时，直接拿官网或电商详情页素材做商用宣传，存在侵权风险。**

- **洪九果品**  
  洪九果品是国内大型水果供应链企业，主要做批发、渠道和品牌运营。它对菠萝等单品通常有产地、包装、分选、品牌化素材。  
  生鲜电商如果和洪九有采购合作，可以找其销售或市场对接人，索取：
  - 产品实拍图；
  - 产地/加工/分选视频；
  - 品牌介绍和卖点资料；
  - 部分联合营销支持。  
  但洪九是否给“品牌营销素材”，同样要看合作体量和具体项目，不是所有客户都能拿到完整授权素材。

**你可以这样判断和推进：**

1. **先确认你手上有没有采购合同或意向订单。**  
   有合作：直接找业务对接人，说明用途（详情页、短视频、直播、社群），请求官方素材和授权范围。  
   没合作：先谈采购或联名营销，再谈素材。

2. **明确你要的素材类型。**  
   - 产品图/视频  
   - 品牌LOGO和VI  
   - 卖点文案/检测报告  
   - 产地故事/供应链素材  
   - 直播切片或达人种草授权  
   不同素材的审批难度不同，产品图通常比品牌LOGO容易，联合营销素材最难。

3. **注意授权边界。**  
   即使拿到素材，也要问清：  
   - 能不能商用？  
   - 能不能投流？  
   - 能不能给达人二次剪辑？  
   - 授权期限和渠道范围是什么？  
   否则容易产生商标或著作权纠纷。

4. **如果只是想做菠萝品类营销，不一定非等品牌方素材。**  
   可以自己做：
   - 产地实拍；
   - 开箱、切果、糖度测试；
   - 对比测评；
   - 供应链溯源内容。  
   这些原创素材反而更适合生鲜电商，也更安全。

**结论：**  
都乐和洪九果品**有可能提供**菠萝品牌营销素材，但一般建立在采购或商务合作基础上，需要官方对接和授权。没有合作时，不建议直接使用其品牌素材做商用宣传。最稳妥的做法是：先对接业务，再明确素材清单和授权范围。
