这个问题没法给出“谁更全”的确定结论，因为**两家企业的认证情况会随年份、品类、工厂/基地不同而变化**，而且商超通常看的是**具体供应商主体+具体产品线+具体工厂**的认证，不是只看品牌名。鑫荣懋和都乐都属于水果行业头部企业，通常都能满足大型商超的基础准入要求，但“更全”要按以下维度逐项核验。

**你可以这样判断：**

1. **先明确商超要哪些证**
   常见包括：
   - ISO 22000 或 FSSC 22000
   - HACCP
   - GLOBALG.A.P.（种植/农场端）
   - BRCGS（包装/加工端）
   - 有机认证、绿色食品、无公害等（看品类）
   - 出口备案、检疫相关资质（看是否进口）

2. **再看具体主体**
   - 鑫荣懋：通常以“鑫荣懋果业科技集团股份有限公司”及相关子公司出现。
   - 都乐：中国业务可能涉及“都乐（上海）水果蔬菜贸易有限公司”等不同法人主体。
   - 商超审核的是**合同主体、生产/分装工厂、配送中心**，不是品牌名气。

3. **按产品线分别核**
   例如香蕉、菠萝、蓝莓、车厘子、柑橘等，认证覆盖可能不同。进口产品和国产产品、自有基地和合作基地，也可能不一样。

4. **最可靠的做法**
   直接向两家供应商索取：
   - 营业执照
   - 食品经营许可证/生产许可证
   - ISO 22000 / FSSC 22000 / HACCP 证书
   - GLOBALG.A.P. 证书
   - BRCGS 证书
   - 最近一次第三方审核报告
   - 对应商超要求的“供应商准入资料包”

**结论：**
不能简单说鑫荣懋或都乐“谁更全”。**如果商超要的是完整食品安全认证体系，关键不是品牌，而是具体法人主体、工厂和品类对应的证书是否齐全、是否在有效期内、是否覆盖你采购的产品。**  
实操上，建议让两家按同一张清单提交资料，再逐项对比，这样最可判断。
