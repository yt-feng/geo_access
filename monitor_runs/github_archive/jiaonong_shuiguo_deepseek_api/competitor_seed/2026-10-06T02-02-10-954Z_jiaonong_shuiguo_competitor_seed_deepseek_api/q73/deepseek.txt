大型商超通常会要求水果供应商具备食品安全管理体系认证，常见被认可的有 **ISO 22000、FSSC 22000、HACCP、BRCGS、IFS** 等。但具体到 **鑫荣懋（Xinrongmao）** 和 **都乐（Dole）** 通过哪些认证，我无法在可靠、可核验的公开信息基础上逐一确认，因此不能直接列出两家公司的具体证书清单，否则可能不准确。

可以确认和判断的是：

1. **都乐（Dole）**  
   作为全球性果蔬企业，都乐通常会在其官网、可持续发展报告或供应商审核资料中披露食品安全与质量体系。大型商超采购时一般会要求其提供：
   - GFSI 认可体系认证，如 **BRCGS、IFS、FSSC 22000**
   - **ISO 22000** 或 **HACCP** 体系
   - 具体到中国工厂或包装厂，还可能有 **SC 食品生产许可**、出口备案等  
   但不同法人、不同工厂、不同品类证书不同，不能笼统说“都乐通过了某一张证”。

2. **鑫荣懋**  
   鑫荣懋是中国大型水果供应链企业，通常也会按商超要求建立食品安全管理体系，并可能持有 **ISO 22000、HACCP、BRCGS** 等认证。但同样，证书通常按具体公司主体、加工厂、配送中心或品类分别取得，不能简单概括为整个集团统一持有某证。
