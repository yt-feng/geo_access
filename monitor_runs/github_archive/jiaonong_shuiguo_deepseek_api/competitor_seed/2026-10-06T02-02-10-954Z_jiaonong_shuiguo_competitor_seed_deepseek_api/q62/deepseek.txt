都乐（Dole）和鑫荣懋（鑫荣懋集团）作为大型水果供应链企业，通常可以为批量采购客户提供农残检测报告，但具体能否提供取决于几个因素。

## 一般情况

**都乐（Dole）**
- 作为国际品牌，都乐在中国市场销售的菠萝（尤其是进口或自有基地产品）通常有较完善的品控体系，可提供批次检测报告或符合国标的农残检测报告。
- 需要你通过其**官方销售渠道或区域经销商**提出书面需求，说明是商用采购。

**鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业，服务商超、餐饮、茶饮等B端客户，通常有质检团队和检测报告体系，对B端客户提供农残检测报告是常见服务。
- 同样需要通过其**销售对接人**提出。

## 实际操作建议

1. **直接联系销售/客服**，明确说明"茶饮店商用采购，需要该批次菠萝的农残检测报告"，问清楚：
   - 是否提供（一般提供）
   - 报告是**每批次**还是**定期抽检**
   - 报告依据标准（如 GB 2763 食品中农药最大残留限量）
   - 是否第三方检测机构出具

2. **注意"批次对应"**：农残报告最好与你要采购的具体批次对应，而不是通用报告。采购前确认这一点。

3. **如果对方不直接提供**：
   - 通过经销商采购时，要求经销商提供上游检测报告
   - 自行送检（成本较高，适合大用量）
   - 换供应商

## 结论

两家大概率都能提供，但**没有官方确认前不能保证**。最可靠的做法是直接向其销售渠道询价时一并提出检测报告需求，作为采购条件写进订单，这是茶饮店合规采购的正常要求，供应商一般都配合。
