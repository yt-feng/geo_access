结论先说：**都乐（Dole）大概率有内部香蕉商品分级/验收标准，但通常不对外公开；洪九果品作为国内水果分销龙头，也应有自己的采购/分拣/出货等级要求，但同样未必以公开“企业标准”形式发布。**  
如果你是要给水果连锁店做香蕉分级标准，**不建议直接等这两家的公开标准，而应按“国标/行标 + 企业收货标准 + 门店销售分级”三层来建。**

### 1. 都乐有没有香蕉企业标准？

都乐是全球香蕉巨头，肯定有较成熟的**内部质量规格体系**，一般包括：

- 品种：如卡文迪什（Cavendish）
- 产地/庄园
- 果指长度、粗度、弯曲度
- 每梳/每把果指数量
- 成熟度/催熟阶段
- 外观缺陷容忍度：疤痕、黑斑、机械伤、日灼、病虫害
- 青蕉硬度、果肉状态
- 冷链和催熟要求

但这类文件通常是：
- 客户定向提供
- 合同附件
- 内部品控手册
- 商超/连锁定制验收标准

**公开渠道一般查不到完整“都乐香蕉企业标准”文本。**  
如果你需要，只能通过采购渠道向都乐业务或品控索取其**验收规格书**，而不是像查国标那样查到公开标准号。

### 2. 洪九果品有没有香蕉企业标准？

洪九果品做香蕉、榴莲等水果分销，通常也会有：
- 产地采购分级
- 加工厂分拣标准
- 催熟出货标准
- 客户定制等级

但洪九更偏**供应链和批发分销企业**，其标准多数是：
- 内部采购验收文件
- 客户供货规格
- 加工厂作业指导书
- 合同质量条款

**公开可查的、正式发布的企业标准文本，通常也没有或很难查到。**  
即使有企业标准备案，也不等于会公开全文，尤其水果这类非强制备案品类。

### 3. 更实际的判断

| 对象 | 是否有内部标准 | 是否公开可查 | 能否直接拿来用 |
|---|---|---|---|
| 都乐 | 基本肯定有 | 通常不公开 | 需商务索取 |
| 洪九果品 | 大概率有 | 通常不公开 | 需商务索取 |
| 国标/行标 | 有相关基础标准 | 可查 | 可作框架 |
| 连锁店自建标准 | 最实用 | 自己发布 | 最推荐 |

### 4. 水果连锁店香蕉分级建议

你可以直接建一套**门店可执行标准**，按下面维度分：

**A级/精品级**
- 果指长度、粗度均匀
- 每把果指数量整齐
- 无可见机械伤、黑斑、裂口
- 成熟度一致
- 适合礼盒、线上精品、高端门店

**B级/标准级**
- 果指略有长短差异
- 少量表皮轻微疤痕
- 成熟度基本一致
- 适合日常门店销售

**C级/促销级**
- 外观缺陷较明显
- 大小不匀
- 适合促销、切果、烘焙、奶昔

**加工级**
- 严重疤痕、过熟、断裂
- 不适合直接陈列
- 用于果切、果汁、甜品

### 5. 关键分级指标

建议至少写清：
1. 品种
2. 产地
3. 果指长度/粗度范围
4. 每把果指数
5. 成熟度（青、微黄、黄、熟）
6. 允许缺陷类型和比例
7. 机械伤、黑斑、炭疽病容忍度
8. 到店温度、冷链要求
9. 催熟到货状态
10. 陈列销售时限

### 6. 最稳妥做法

**不要只依赖都乐或洪九的标准。**  
建议：

1. 查：香蕉相关国标、行标、农残和包装标准  
2. 要：向都乐、洪九、其他供应商索取他们的**验收规格书**  
3. 建：自己做一份《香蕉采购验收与门店分级标准》  
4. 试：先跑1个月，按A/B/C级损耗和销售数据修正
