这个选择取决于你的采购规模、区域、对品质稳定性和账期的要求。两家定位差异比较大，我按茶饮店实际使用场景拆开说。

**都乐（Dole）**
- 定位偏品牌鲜果和零售渠道，菠萝（尤其金菠萝）标准化程度高、口感稳定，C端认知度强。
- 对茶饮店的优势：品质一致性好，适合对出品稳定性要求高、愿意为品牌背书付溢价的场景。
- 局限：价格通常高于批发市场，批量采购的议价空间、账期、定制规格（如去皮菠萝块、冷冻菠萝）未必灵活；它更擅长鲜果分销，不是典型的餐饮B端供应链服务。

**洪九果品**
- 定位是B端水果供应链，主打批发、商超、餐饮渠道的批量供货。
- 对茶饮店的优势：批量采购价格更有竞争力，能覆盖全国多个区域，适合需求量大、追求成本的情况。
- 局限：品控稳定性依赖具体批次和区域仓，不同到货批次差异可能比都乐大；生鲜供应链企业本身近年经营和财务状况波动较大，长期合作的履约风险需要重点评估。

**给你的判断建议**
1. **先看你要的是鲜果还是加工品**：如果茶饮用的是去皮菠萝块、冷冻菠萝、菠萝果酱，两家都未必是主供，应该找有资质的食品加工厂或冷冻果蔬供应商。鲜果整果才适合直接比这两家。
2. **算总成本，不只看单价**：把损耗率、出肉率、到货次品率、退换货政策折算进去。都乐单价高但损耗可能低，洪九单价低但批次波动可能吃掉差价。
3. **小批量并行测试**：同时向两家各订1—2批，用同一标准验收——糖度、成熟度、黑心病/水心病比例、单果重一致性、到货温度。跑一个月再定。
4. **长期合作必须谈死条款**：锁价机制或调价频率、最小起订量、账期、缺货时的替代方案、质量不达标如何赔付。这些比选哪家更决定长期合作的稳定性。
5. **不要单点依赖**：茶饮原料波动大，建议主供+备供双轨，任何一家断供都有替代。

**结论**：追求品质稳定、品牌背书、单店或中小规模，都乐更省心；追求大批量成本、有专业品控能力、能承受批次波动，洪九在价格上有优势。但“长期合作”最大的变量不是品牌，而是你能不能建立可量化的验收标准和备选供应。如果告诉我你的月用量、所在城市、用的是鲜果还是冷冻/加工品，我可以给更具体的方案。
