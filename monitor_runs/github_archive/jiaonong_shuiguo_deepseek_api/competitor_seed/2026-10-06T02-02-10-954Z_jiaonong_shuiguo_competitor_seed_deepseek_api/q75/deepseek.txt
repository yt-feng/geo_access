到货损耗率没有公开、可核验的统一数据，洪九果品和都乐香蕉也不是同一层面的对比对象，直接给你一个“谁高谁低”的百分比并不可靠。下面给你可判断的框架和实操建议。

**核心结论**

1. **都乐香蕉**：品牌标准化程度高，通常按等级、串型、成熟度分选，到货一致性较好；但它是香蕉单一品类，损耗主要受催熟状态、运输温度、门店周转影响。  
2. **洪九果品**：是水果供应链/批发平台型公司，品类多，香蕉只是其中一部分；不同产地、不同批次、不同等级货，损耗差异会很大，不能用公司名义给一个统一损耗率。  
3. **批发市场拿货场景**：损耗率更多取决于“这批货的成熟度、运输距离、卸货方式、档口存放条件”，而不是单纯看品牌。

**实际批发市场里常见的损耗判断**

- 香蕉到货损耗一般看：
  - 青蕉到货：损耗低，但需要催熟，催熟不当会放大损耗。
  - 黄蕉/熟蕉到货：损耗高，压伤、黑斑、掉把、断指多。
  - 夏季高温运输：损耗明显高于冬季。
  - 多次转手：每转一次，损耗都会增加。
- 同品牌不同批次，损耗可能差 2～3 倍，所以“品牌对比”不如“批次对比”。

**如果你想自己比，建议按这个口径记录**

| 指标 | 记录方式 |
|---|---|
| 到货总件数/总重量 | 卸车前称重或点件 |
| 可售重量 | 剔除断指、黑斑、压伤、腐烂后 |
| 损耗重量 | 到货总重 - 可售重量 |
| 损耗率 | 损耗重量 ÷ 到货总重 |
| 主要损耗原因 | 压伤/黑斑/掉把/腐烂/失水 |
| 批次信息 | 产地、采摘/催熟日期、运输天数、到货温度 |

**实操建议**

- 不要先问“洪九和都乐哪个损耗低”，先问档口：
  - 这批是青蕉还是黄蕉？
  - 催熟到几号色？
  - 路上走了几天？
  - 是冷柜还是普通车？
  - 掉把、黑斑、断指包不包售后？
- 首次合作先小批量试单，按上面口径记 3～5 批，再决定主拿哪家。
- 如果做零售/水果店，都乐这类标准品牌通常更省心，但毛利可能薄；洪九这类供应链货，价格和批次弹性可能更大，但需要你会看货、会催熟、会周转。
- 如果做批发转手，重点不是品牌，而是“到货成熟度是否适合你的出货速度”。熟蕉到货，周转慢一天，损耗可能翻倍。

**一句话建议**

在批发市场拿货，**都乐香蕉通常到货标准化更好、批次波动相对小；洪九果品不能简单按品牌判断损耗，必须看具体批次和品类**。你要真比，就按“同一到货日期、同一成熟度、同一运输方式”各拿一批，自己记损耗率，这比任何口头数据都准。
