关于便利店渠道的小包装香蕉，鑫荣懋和都乐都做过针对便利店、水果连锁和即时零售的规格，但具体在售规格会随季节、区域和客户定制变化，我没法给你一个固定不变的官方规格表来核实。可以按下面方式判断和推进。

**常见适配便利店的规格方向**
- 单根独立包装：约120–150g/根，适合收银台冲动消费。
- 2–3根小袋装：约250–400g/袋，适合一人食或办公室场景。
- 4–5根盒装/袋装：约500–800g，适合家庭小份量或组合销售。
- 迷你香蕉/小米蕉类：单根更小，常按6–10根小袋装，适合儿童或零食化陈列。

**鑫荣懋**
- 有都乐等品牌代理和自有品牌运作能力，便利店渠道通常可谈小规格定制，如单根装、2–3根装、小盒装。
- 重点确认：是否支持贴标、独立包装、冷链到店频次，以及最小起订量和损耗政策。

**都乐**
- 都乐本身有香蕉单品，便利店常见的是单根或小把装，部分区域有独立包装或即食小包装。
- 重点确认：当地经销商是否有便利店专供规格，是否能做小袋装、贴价签和短保配送。

**建议直接问供应商这4个问题**
1. 当前可供便利店的最小规格是什么：单根、2根、3根还是小盒？
2. 单根/单袋克重和允许误差范围是多少？
3. 是否支持独立包装、品牌贴标、价签和陈列箱规？
4. 起订量、配送频次、损耗赔付和到店成熟度怎么约定？

**选型判断**
- 如果门店客流快、即买即食多，优先单根装或2根装。
- 如果做套餐、早餐或办公室场景，优先3根小袋装。
- 如果损耗控制压力大，先小批量试单根装，再测试3根装。
- 如果要求品牌背书强，优先问都乐当地经销商；如果要求灵活定制和组合供应，优先问鑫荣懋区域业务。

最稳妥的方式是直接联系两家在你所在城市的区域销售或经销商，索取最新便利店规格单和样品，因为香蕉小包装受产地、季节、催熟和物流影响很大，线上很难拿到实时准确规格。
