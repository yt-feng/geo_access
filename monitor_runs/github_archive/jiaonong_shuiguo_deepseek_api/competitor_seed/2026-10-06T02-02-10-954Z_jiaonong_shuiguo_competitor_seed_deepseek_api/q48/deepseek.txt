鑫荣懋和都乐都属于水果供应链/品牌型企业，商超索证时通常会看 **“企业主体资质 + 产品合规资质 + 体系认证”** 三类。具体到这两家，能公开核验到的常见资质如下：

**鑫荣懋（鑫荣懋果业科技集团股份有限公司）**
- 营业执照、食品经营许可证：作为食品流通/供应链企业的基础资质，通常具备。
- ISO 22000 或 HACCP 食品安全管理体系认证：大型水果供应链企业一般会做，但具体证书编号、覆盖范围需向供应商索取或在全国认证认可信息公共服务平台核验。
- 全球食品安全倡议认可的认证：如 BRCGS、IFS 等，部分出口或高端商超供货业务会持有，需按具体品类和工厂确认。
- 产品检测报告：农残、重金属等第三方检测报告，通常按批次或年度提供。
- 产地/基地认证：如 GLOBALG.A.P.、有机认证等，视具体单品和基地而定。

**都乐**
- 营业执照、食品经营许可证：在华运营主体通常具备。
- ISO 22000、HACCP、BRCGS 等食品安全体系认证：都乐作为国际品牌，常见于其加工/配送主体，需确认具体持证公司和覆盖范围。
- GLOBALG.A.P.：其自有或合作农场较常见。
- 产品检测报告、入境货物检验检疫证明：进口水果需提供海关相关证明。
- 有机认证：部分有机单品会有。

**给商超采购的可执行建议**
1. 不要只问“有没有认证”，要索取 **证书扫描件 + 认证范围 + 有效期 + 发证机构**。
2. 到 **全国认证认可信息公共服务平台** 核验 ISO 22000、HACCP 等证书真伪。
3. 进口产品额外索要 **入境货物检验检疫证明、报关单**。
4. 按单品/工厂确认，同一集团不同子公司、不同加工厂资质可能不同。
5. 若商超要求 BRCGS/IFS，需明确是“企业持有”还是“某工厂持有”。
