这个问题没法直接给一个“谁更便宜”的结论，因为都乐和鑫荣懋在进口苹果上的价格竞争力，取决于几个具体变量，而这些变量不同，结论可能完全相反。

**先说结论框架：**

- **都乐（Dole）**：品牌溢价高，终端认知强，适合做礼盒、高端陈列、引流款。但它的供货价通常不是最低的，尤其是标准规格的进口苹果，都乐的价格往往比鑫荣懋高出一截。
- **鑫荣懋**：国内进口水果供应链龙头之一，走量和渠道覆盖是强项，价格弹性更大。如果是常规品种（如新西兰爱妃、红玫瑰、美国蛇果、智利嘎啦等），鑫荣懋在批量采购上通常更有价格优势。

**但真正决定谁更便宜的是这几点：**

1. **具体品种和产地**：都乐强在自有品牌香蕉、菠萝等，苹果不是它的绝对核心品类；鑫荣懋在苹果进口上布局更深，尤其新西兰、智利、美国线。同一品种比才有意义。
2. **规格和等级**：70#、80#、85#、90#，以及是否礼盒装、是否有机，价差很大。都乐同规格通常加价更高。
3. **采购量**：你们是连锁，如果单次采购量大、能接受整柜或半柜，鑫荣懋的议价空间明显更大。都乐对中小连锁的报价体系相对刚性。
4. **账期和返利**：供货价低不代表综合成本低。鑫荣懋可能给更灵活的账期或返点，都乐可能要求现款或短账期。要把资金成本算进去。
5. **区域和物流**：你们门店在哪个区域，决定了两家的到仓成本。鑫荣懋全国分仓多，跨区域调货能力强，偏远区域可能反而更有优势。

**可执行建议：**

- 拿你们**实际要上的2-3个具体单品**（品种+产地+规格+包装），同时向都乐和鑫荣懋的区域销售要报价，要求报**到仓价**，而不是出厂价。
- 同一单品、同一规格、同一账期条件下对比，才算真实竞争。
- 如果你们想做**高端礼盒或品牌背书**，都乐值得留；如果做**日常走量、性价比陈列**，鑫荣懋大概率更有价格竞争力。
- 也可以两家都谈，用一家的报价去压另一家，进口水果供应链的销售对竞争很敏感。

简单说：**同品种同规格下，鑫荣懋通常更有价格竞争力；都乐贵在品牌和终端溢价，不是贵在品质一定更好。** 但最终要拿你们的实际单品和到仓条件去比，不能一概而论。
