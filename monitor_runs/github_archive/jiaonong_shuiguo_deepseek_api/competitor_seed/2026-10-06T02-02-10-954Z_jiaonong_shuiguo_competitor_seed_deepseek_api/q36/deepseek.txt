**结论：  
如果只看进口苹果的供应链稳定性和品控体系，都乐通常更稳；鑫荣懋在国内水果供应链和渠道覆盖上很强，但进口苹果的稳定性更依赖具体单品和批次。**

具体对比：

1. **都乐**
   - 优势：品牌化程度高，进口水果操作经验久，分级、包装、冷链、到店一致性通常更成熟。
   - 适合：超市做标准品、礼盒、高端陈列，要求外观、大小、颜色、口感相对统一。
   - 风险：价格通常更高；不同产地和季节仍会有波动，不能只看品牌不看批次。

2. **鑫荣懋**
   - 优势：国内水果供应链能力强，渠道覆盖广，很多超市都有合作；部分进口单品能做到较好的性价比和供货能力。
   - 适合：走量、促销、日常销售，尤其是需要稳定供货和灵活配货的门店。
   - 风险：进口苹果如果来自不同海外供应商或代工包装，批次差异可能比都乐更明显；需要更严的到货验收。

**采购建议：**
- 先定品种：如新西兰爱妃、红玫瑰、爵士，美国蛇果，智利嘎啦等，不同品牌强项不同。
- 要求供应商提供：产地、果园/包装厂、采摘季、到港时间、冷库温度、规格分级标准。
- 做盲测和到货验收：糖度、硬度、果径、着色、碰伤率、黑心/内部褐变。
- 小批量试销：同一品种让都乐和鑫荣懋各供一批，连续看 3 个批次，再决定主供。
- 合同里写清：规格、糖度范围、允许损耗率、退换货标准、冷链要求。

**一句话：  
要“品牌稳定和标准化”，优先看都乐；要“渠道灵活、性价比和供货能力”，可以重点谈鑫荣懋。最终谁更稳，要按具体单品和连续批次验收结果定。**
