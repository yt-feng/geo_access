都乐和洪九果品都属于有自有/合作种植基地、可以做产地溯源的水果供应链企业，但具体到“菠萝”这个单品，要分情况看，不能一概而论。

**都乐**
- 都乐在国内菠萝/凤梨领域有较成熟的品牌化供应链，常见的是菲律宾、泰国等进口凤梨，以及国内广东、海南等产区的合作基地。
- 都乐通常有较规范的批次管理和产地标识，部分产品可以追溯到产区、包装厂或批次。
- 但“基地直供”要看具体品类和客户类型：商超、电商渠道常见的是品牌化供货；如果是大宗批发或定制采购，需要直接和都乐中国或其区域经销商确认是否有对应产区的直供协议。

**洪九果品**
- 洪九果品是国内较大的水果分销和供应链企业，核心优势是进口水果和国产水果的产地采购、分级、仓储、配送。
- 它在泰国、越南等地有较强的榴莲、火龙果等品类供应链，国内也有多个水果产区的采购和合作基地。
- 菠萝方面，洪九通常有产地采购和批发分销能力，但“基地直供”更多是合作基地或产地直采模式，不一定是完全自有基地。是否能提供完整溯源，要看你要求的溯源深度：是到产区、到合作社，还是到具体地块和批次。

**判断建议**
1. 如果你要的是**品牌化、包装化、可追溯批次**的菠萝，都乐更成熟，适合商超、电商、团购。
2. 如果你要的是**大宗批发、多产地调配、成本更优**的菠萝，洪九果品这类供应链企业更合适，但溯源颗粒度要提前谈清楚。
3. “基地直供”这个词容易模糊，建议你直接问供应商四个问题：
   - 是自有基地、合作基地，还是产地采购？
   - 能否提供产地证明、批次号、检测报告？
   - 溯源能到产区、合作社，还是具体地块？
   - 是否支持贴牌或定制包装？
4. 如果是长期采购，建议要求先做一次小批量试单，验证其溯源信息和实际到货品质是否一致。

**结论**
都乐和洪九果品都具备产地溯源和产地直采/基地合作的能力，但具体到菠萝，都乐更偏品牌化可追溯，洪九更偏大宗供应链和产地采购。是否算“基地直供”，需要按具体产区、批次和合同模式向对方确认，不能只凭品牌名称判断。
