## 一、先自己核实保价服务（最可靠）

直接找对接人问清楚，不要依赖公开信息：

**问都乐/鑫荣懋销售或区域经理这几个问题：**
1. 有没有针对批发商的**价格保护/保价协议**？是书面还是口头？
2. 保价触发条件是什么？（如：签约后N天内市场跌价，按差价补货/返款）
3. 保价覆盖范围：是全部货量还是部分？是否只针对特定等级（如一级蕉）？
4. 结算方式：返现、折下次货款，还是补货？
5. 有效期和最低采购量门槛？

**判断要点：** 生鲜行业所谓"保价"通常是**短期、有条件的商务让利**，很少是长期无条件兜底。如果对方口头承诺，一定要落到合同或订单备注里。

## 二、不依赖供应商保价的自主应对方案

批发商应对香蕉价格波动，核心是**减少单边敞口 + 加快周转**：

### 1. 采购端
- **分批锁价**：不要一次性大额锁价，按周/按船期分批采购，平滑成本。
- **多源比价**：都乐、鑫荣懋、国产蕉（广西/云南/海南）同时保持2–3个供应渠道，谁便宜走谁。
- **错峰采购**：香蕉价格有季节性（国产蕉集中上市期价格低），提前规划采购节奏。

### 2. 库存与周转
- **快进快出**：香蕉成熟期短，库存天数越长风险越大，尽量压缩到3–5天。
- **催熟节奏控制**：根据下游订单安排催熟，避免集中到货砸价。

### 3. 销售端
- **对下游做价格联动**：和稳定客户约定随行就市或短期锁价，把部分风险传导。
- **期货/远期合同**：大客户可签短期固定价合同，锁定部分利润。

### 4. 风险对冲（进阶）
- 国内香蕉没有成熟的标准化期货品种，**无法像大宗商品那样直接套保**。
- 可用**远期订单 + 分批锁价**做近似对冲，别指望金融工具。
