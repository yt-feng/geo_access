我不便给出“鑫荣懋/都乐具体覆盖到哪些城市”的确定名单，因为这类配送覆盖会随品类、仓网、客户合同、季节和项目制运作而变化，公开渠道往往也不是实时全量口径；若我直接列城市清单，容易给你错误的准入判断。

可以这样核验和判断：

1. **先确认商超要的“冷链物流”口径**
   - 是要求供应商自有/长期合作冷链仓配？
   - 还是只要具备冷链运输能力、能提供温度记录和到店履约？
   - 是覆盖商超全国DC，还是覆盖具体门店？
   - 要求整车、零担、多温区、还是城市配送？

2. **直接向两家公司要“冷链配送覆盖证明”**
   让对接的销售/供应链负责人提供：
   - 可配送城市/区域清单
   - 冷链仓位置
   - 配送时效
   - 温度监控方式
   - 是否可开冷链运输/仓储发票
   - 是否有大型商超合作案例

3. **更可靠的分层判断**
   - 鑫荣懋：通常在全国水果供应链和大型商超/电商渠道有较强仓配能力，但具体到某城市某门店，要看其当地仓配合作方。
   - 都乐：品牌和供应链体系较成熟，但实际配送也可能由区域经销商、第三方冷链或本地仓配执行，不同品类和区域差异较大。
   - 所以不能简单说“覆盖全国”或“只覆盖某几个城市”。

4. **给商超的替代方案**
   如果商超要求供应商必须有冷链物流，而你们不是自建冷链，可以准备：
   - 与第三方冷链物流公司的合同
   - 冷链运输资质、车辆温控记录
   - 仓储温控证明
   - 覆盖城市/线路承诺
   - 应急预案和货损处理机制
