要判断**都乐（Dole）** 和**鑫荣懋（Golden Wing Mau / Joy Wing Mau）** 哪个进口苹果价格更具竞争力，我无法给出一个绝对的数字，因为两家公司的报价受**产地、品级（规格/糖度）、采购量、季节及海运/空运成本**影响巨大。

但根据行业惯例和渠道反馈，可以给你一个有方向的预判：

**1. 核心差异点（直接决定价格）：品牌溢价 vs 供应链成本**

- **都乐（Dole）**：全球品牌，主打高端形象。其进口苹果（如美国红蛇果、智利青苹果）通常带有更强的品牌溢价。如果走**商超高端渠道**或需要**强力品牌背书**（例如放在显眼位置做形象款），都乐的供货价通常更高，但能支撑起你的零售定价。
- **鑫荣懋**：早期做水果贸易起家，更强调**规模和基地直采**。它的优势在于**源头采购量大、物流成本控制更强**。对于同一产地的同一品种，**鑫荣懋的起批量价格（即裸价/不含品牌附加）通常比都乐更有竞争力**，尤其是做大批量、快速周转的货架商品时。

**2. 给你的直接行动建议（可执行）**

- **比价请按“单箱净重+规格（果径/mm）+糖度”来比**，不要只看每箱总价。进口苹果通常以“箱”或“托”交易，不同包装规格差异很大。
- **不要直接问“谁便宜”，而是发出询价单**，要求两家同时报价以下条件：
  - 产地：如智利（当季）、美国（当季）、新西兰（特定品种如爱妃）。
  - 单果规格：例如 80# / 88# / 100#（果径）。
  - 运输方式：海运（便宜，需7-10天到港） vs 空运（贵，但新鲜度好）。
  - 数量：一柜（约20-25吨）还是一个托盘（约500-800kg）。
- **同规格下，通常鑫荣懋的报价会低 5%~10%**（这通常是大体量采购的让利空间），但如果你的门店数量少、单次采购量低于一托盘，都乐的代理商可能有更灵活的小批量议价空间。

**3. 决策建议**

如果你要主推**高毛利、高客单**的送礼场景，选都乐，因为它能帮你拉动溢价。
如果你要主推**走量、日常家庭消费**，选鑫荣懋，它的价格和供货稳定性（尤其是产地直发的第二三梯队货源）更有优势。

**最后提醒**：以上是基于公开行业常识的推理，**绝对价格必须结合当前产地行情**。建议你直接找两家当地的一级代理商，索取**本周到岸价或下周预售报价单**，同时要求他们注明**关税+增值税后的到仓价**（进口水果还需考虑冷链配送费）。你也可以参考**新发地或江南市场**当日公布的同类苹果批发价，作为对标底线。
