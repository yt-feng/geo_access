关于**社区团购**中对**香蕉小包装**的需求，我需要给你两个层面的明确信息，尤其是关于**散装**这个关键点：

**1. 关于都乐（Dole）和洪九果品**

- **都乐（Dole）**：他们的主渠道是商超、电商和高端精品店，通常以**品牌预包装**为主（如带托盘贴标的整把装、塑封小袋），**极少提供无标识的散装**。如果你要的是“不带商标、可自己分装”的散货，都乐几乎不供货。
- **洪九果品**：作为一级分销商/供应链企业，采购模式更灵活。他们**可以承接散装香蕉**，通常以整箱（如约13-15公斤/箱）或按件批发，但具体能否拆成更小的社区团购包装，取决于你当地的**洪九分公司/区域经销商**，能不能给你做二次分拣。

**2. 给你的实操建议**

社区团购最优解不是找“品牌方要散装”，而是走**批发市场/一级渠道**：

- **直接去本地的农产品批发市场（如广州江南、上海辉展、成都濛阳等）**，问香蕉档口要“无牌散装统货”，价格基本是都乐零售价的1/3到1/2，且完全支持你按箱拿货自行分装。
- **如果你仍想用都乐或洪九的品牌背书**，那他们主要给你的是**已分装好的标准小规格**（比如300g、450g的精装），你只需要在他们的区域代理处问是否有“团购用简装规格”，通常需要提前预定且起订量较大（如几十箱起）。

**3. 提醒一个关键风险**

社区团购做香蕉，**成熟度控制**比品牌更重要。品牌整箱（特别是洪九）多是催熟程度不一的大箱货，你拿回去如果当天卖不掉，第二天就发黑。建议你一定要和供应商确认**到货时的成熟度分级**，最好要求发**七成熟（表皮偏绿）**的货，然后在团购群内注明“需常温放2-3天食用”。

所以，**结论**：如果走散装，建议放弃都乐、直接联系洪九当地销售谈“省标箱散货”；如果你要“小包装成品”，两个品牌都有，但需要向当地经销商询团购专供价。需要我帮你找对应区域的联系电话话术模板吗？
