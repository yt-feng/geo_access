关于茶饮店采购菠萝原料时，供应商能否提供农残检测报告，以及都乐（Dole）和鑫荣懋（Xinrongmao）是否具备该能力，我的建议如下：

1. **通常情况**：大型水果供应商（如都乐和鑫荣懋）作为正规企业，一般会对其大宗商品（如菠萝）进行农残检测，并能够提供符合出口或国内销售要求的检测报告。但它们并非无条件自动提供，而是通常需要您作为采购方，在签订合同或采购订单时明确提出“需要农残检测报告”的要求，并写入合同条款。若未明确提出，对方可能只提供基础的质量合格证或自行出具的检测报告。

2. **报告类型区分**：请向对方明确索要“第三方权威机构出具的农残检测报告”（如SGS、华测、谱尼等），而非供应商自检报告。第三方报告在食品安全审核（如茶饮品牌总部合规审核）中认可度更高。都乐和鑫荣懋作为大厂，通常有这类报告储备，但需要您主动索取，并注意报告上的检测日期是否在合理时效内（一般3-6个月内有效或按您司要求）。

3. **实际操作建议**：
   - 直接联系您对接的销售或采购负责人，书面邮件说明需求：“请提供近3个月内该批次菠萝的第三方农残检测报告，覆盖GB 2763标准中菠萝相关项目。”
   - 若对方无法提供，您可以要求其在采购合同中增加“保证供应产品符合国家农残限量标准，并随货附检测报告”的条款。
   - 若您的茶饮店验收标准较高，建议您同时要求供应商提供“出口备案”或“GLOBALGAP认证”作为辅助依据，这些认证本身就包含严格的农残管控。

4. **风险提示**：如果购买的是非直采渠道（例如从批发市场小经销商采购），通常无法获得正规检测报告，这时需要您自行送检，或更换有能力的供应商。都乐和鑫荣懋作为品牌商，一般在大型商超、连锁餐饮渠道供应，若您的采购量较小（如低于一定吨数），它们可能不直接供货，而是通过经销商，此时报告的溯源性会变差。

**总结**：这两家公司作为大供应商，**理论上能提供**农残检测报告，但您必须**主动书面要求**并确认报告类型和有效期。若您签订合同前没有提出，后续补要可能困难。建议您在首次询价时就将此条件列入供应商审核表。如果对方推诿，这本身就是一个警示信号，请谨慎合作。
