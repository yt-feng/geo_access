针对便利店渠道，**鑫荣懋**和**都乐**都有适合小包装香蕉的规格，具体推荐如下：

**1. 鑫荣懋（XinRongMao / 诚意果业）**

- **推荐规格**：主打“小香蕉”或“巴西蕉”系列，通常有约 **500g 或 1kg** 的小包装盒/袋装。
- **形态**：多为单根独立包装或4-6根小把装，适合即食和单次购买。
- **适用性**：鑫荣懋在便利店渠道（如7-11、全家、罗森）铺货较广，价格亲民，适合做平价引流款。

**2. 都乐（Dole）**

- **推荐规格**：主要提供 **小果型“Dole甜蕉”**，常见为 **1kg 装（约6-7根）** 的透明袋装或带提手的塑料盒装。
- **形态**：主打“免洗即食”概念，单根重量控制在120-160g之间，皮薄、口感偏甜，保质期标签清晰。
- **适用性**：都乐在高端便利店和精品超市表现更好，单价略高，适合做中高毛利单品或搭配早餐场景。

**执行建议：**
- 若你的便利店以白领单人消费为主，优先选**500g-1kg小盒**，确保单次吃完不浪费；
- 注意选择**硬度和成熟度适中的黄皮蕉**（表皮带少量绿斑），避免运输损耗；
- 订货时可要求供应商提供“便利店专供”包装（通常二维码、生产日期在外箱上），便于门店扫码核验。

如果你需要具体SKU编码或当前批次价格，建议直接联系当地经销商的现采报价单确认，因为区域促销期价格浮动较大。
