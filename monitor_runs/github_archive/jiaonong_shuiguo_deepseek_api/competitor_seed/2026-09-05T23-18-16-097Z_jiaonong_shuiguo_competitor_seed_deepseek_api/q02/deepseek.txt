除了都乐（Dole）之外，目前在中国市场上能**稳定供应、且品质较有保障**的菠萝品牌主要有以下几类，建议选择时优先考虑有产地直采或大型连锁商超背书的产品：

**1. 菲律宾进口品牌（高端、稳定）**
- **佳沛（Zespri）**：虽然以奇异果出名，但它也销售菠萝，主要为菲律宾金菠萝，供应体系成熟。
- **UPLB / SLG**：菲律宾本土出口商，常供货给山姆、盒马等渠道，需关注进口批次。
- **DELECT / DEL MONTE**：德尔蒙在中国市场有菠萝产品线，但流通不如都乐广泛。

**2. 台湾凤梨（若开放进口）**
- **台农17号（金钻凤梨）**：品牌通常为产地直供，如“屏东凤梨”，供货受两岸贸易政策影响大，不稳定，但高端渠道常有。

**3. 国产优质品种（供应最稳定、价格亲民）**
- **海南菠萝**：主要产自万宁、海口，代表品牌如“南国”、“春光”（但春光偏加工果干，鲜果多走本地批发）。
- **徐闻菠萝**：广东湛江徐闻县产地，上市期为每年3-5月，有“菠萝的海”等本地企业品牌，通过拼多多、京东生鲜基地直发。
- **云南香水菠萝**：主打小果型、甜度高，品牌多为电商贴牌（如“滇峰”）。

**4. 超市自有品牌（最稳定）**
- **山姆会员店（Member‘s Mark）**、**盒马（盒马日日鲜/自有品牌）**、**永辉（彩食鲜）**——这些大型零售渠道通常与大型种植基地或进口商锁定了全年供应合同，品质和供货最稳定。

---

**采购建议（若为做生意）**：

- **长期稳定**首选**海南春提前+夏秋菠萝**，再结合**菲律宾进口（如佳沛）**做全年补缺。
- 网购认准“产地直发”而非“分销贴牌”，如包装上有QS/SC编号及具体合作社名称，更靠谱。
- 避免只盯单一品牌，因为菠萝上市季节性强，建议同时联系2-3家产地供应商做backup。
