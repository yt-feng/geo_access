关于洪九果品和鑫荣懋在香蕉产地直发方面的基地情况，我无法提供实时的、具体的基地分布数据，因为这类商业信息可能涉及内部供应链布局，且未在公开数据库中全面核验。

**不过，我可以给你提供基于行业常识的判断方向，供你参考：**

1.  **洪九果品**：以“端到端”供应链著称，尤其擅长进口水果（如东南亚香蕉、榴莲等）。它们通常采取**“产地驻点采购+包园”**模式，即在菲律宾、越南、柬埔寨等主产区和国内海南、广西等香蕉产区设有采购基地或长期包销协议。但具体基地名称和数量并非完全公开。

2.  **鑫荣懋**：作为国内头部果业企业，其供应链覆盖面广，在国内外均有布局。在香蕉方面，他们同样在云南、老挝、缅甸等产区有合作基地或自有果园，但同样不公开详细的基地清单。

**给你的实操建议（比纠结“谁有基地”更重要）：**

- **直接询证**：如果你是采购方，建议直接向两家公司的**大客户部或供应链负责人**索取“产地直供证明”或“基地认证文件”（如GAP认证、出口基地备案号）。这是最权威的方式。
- **考察检验**：基地并不等于品控。更关键的是**分选加工能力和冷链物流**。你可以要求对方提供最近批次的**农残检测报告**和**到货损耗率数据**进行比较。
- **决策关键点**：如果做线上生鲜，**损耗率和到货新鲜度**比“是否有基地”更重要。建议你先小批量试单（各采购1-2吨），对比实际到货品质和履约能力，再决定长期合作。

**结论：** 两者大概率都有产地资源，但**不要迷信“基地”说法**，建议以实际验厂、小批量测试和合同约束为准。如果你需要查询具体备案基地，可以询问对方是否具有**中国海关总署注册的境外果园/包装厂资质**（进口香蕉必查），这一信息可通过官方渠道核验。
