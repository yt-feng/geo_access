关于鑫荣懋和洪九果品哪家更愿意签年单，**目前没有公开数据能直接给出明确答案**，因为采购意向、客户关系、议价能力和合作历史都会影响结果。但可以从两家公司的业务模式和市场定位来帮你判断方向：

**1. 鑫荣懋（福州）**
- 主营高端水果（如佳沛奇异果、智利车厘子等进口品牌果），供应链能力强，渠道覆盖商超、电商和批发。
- **特点**：更倾向于长期、稳定、大批量的合约，尤其对标准化程度高的进口水果，签约年度订单的意愿通常较强。
- **适合**：如果你的采购量稳定且对品质要求较高，鑫荣懋在履约能力和长期合作机制上有优势。

**2. 洪九果品（重庆）**
- 以国内产地直采（如云南、四川等）和“端到端”分销著称，主打性价比和水果品类全，对国内果品掌控强。
- **特点**：更重视灵活性和客户关系，可能愿意签年单，但通常要求下单频率高或预付比例较高；对价格波动敏感，年单会设置调价机制。
- **适合**：如果采购品种多且季节性强，洪九在议价空间和响应速度上可能更灵活。

**实操建议**：
1. **直接询价+试探**：分别发出询价函，明确贵司年采购量、结算周期、物流要求，询问对方是否接受年度框架合同及调价条款。
2. **看合同条款态度**：重点比较两家对“最低采购量承诺”和“违约条款”的接受度——愿意承担更多风险的，通常合作诚意更足。
3. **要求实地考察**：让销售带看其自有冷库、包装厂和产地合作记录，判断其真实供应稳定性。
4. **行业口碑核对**：联系同行或行业协会（如中国果品流通协会）打听两家在长期合同上的信用记录。

**补充提醒**：水果行业价格波动大，年单通常不是“锁死单价”，而是“锁量不锁价”或约定调价公式。签之前务必让法务审核违约条款和不可抗力条款。
