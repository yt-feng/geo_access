关于社区团购香蕉小包装的需求，**都乐（Dole）和洪九果品都有散装或定制化业务**，但具体是否提供“小包装散装”以及合作门槛，建议您直接联系其B2B或社区团购对接部门确认。

以下是具体判断和建议：

**1. 都乐（Dole）**  
- 都乐在商超和生鲜电商渠道，有成熟的“整串/根”以及“小规格包装”产品（如500g/1kg包装）。  
- 但都乐更倾向于与大型商超、连锁门店、头部电商平台合作，**散装小批量（如10-20斤起发）** 可能需要走其区域经销或批发渠道。  
- 建议：联系都乐中国官方客服或“都乐中国市场部”，说明您是社区团购，询问是否支持“B端小包装定制”以及最低起订量。

**2. 洪九果品**  
- 洪九果品本身就是**专注批发和B端供应链**的企业，业务覆盖“基地直采、分拣加工、配送”，散装和定制化服务相对灵活。  
- 洪九主打“自有基地+加工厂”，对社区团购、生鲜电商有过“小颗粒度分拣”合作先例，比如500g-2kg的盒装或袋装香蕉。  
- 建议：直接联系洪九当地子公司或大区销售，明确要求“散装香蕉、小包装（如1-2kg预冷袋/纸箱）”，通常可谈。

**3. 一般社区团购采购建议**  
- 如果两家都不满足，可考虑**本地一级批发市场**（如广州江南市场、北京新发地等）的香蕉档口，批发商普遍支持“整件散卖”（约15-20斤/件），你买回后自行分装，成本更低。
- 请务必确认以下参数：  
  - 单根克重（通常120-150g以上为优）  
  - 成熟度（青熟、微黄、全黄，考虑运输时间）  
  - 每箱净重（如16斤/件，件内是否套袋）  
  - 物流配送方式（冷链/常温，是否支持次晨达）

**4. 如果直接谈，请准备这些信息**  
- 您的社区团购月均销量（如3-5吨）  
- 预期单包重量（如1公斤/包）  
- 采购频次（每周几批）  
- 需求城市（是否有当地仓/代发）

**最终建议**：  
先同时联系都乐客服（400电话）和洪九华南/华东大区，说明“社区团购，香蕉小包装（1-2kg/包），月采至少XX吨”，看谁能在最短时间内供货。如果两家都不接受小批量，就转向批发市场做二次分装。
