针对便利店渠道的小包装香蕉需求，**鑫荣懋**和**都乐**目前都有针对该渠道的专属小规格包装产品。具体规格和建议如下：

**1. 鑫荣懋（Golden Apple / 佳沃）**

- **常规小包装**：通常为 **400g-500g** 的袋装（约4-5根），适合即买即食。
- **便利店专用（重点）**：鑫荣懋与多个便利店系统（如7-11、全家、罗森）合作，常提供 **“单根装”** 或 **“2根装”** ，采用带透气孔的塑料小盒或贴标裸装，规格非常灵活，可以根据门店需求定制单果重量（通常要求果指粗壮、单根重量在120-160g之间）。
- **建议**：直接联系鑫荣懋的**新零售/便利店渠道经理**，他们可以按门店的收银台面积或日均销量定制包装（如 100g-150g/袋的小包装）。

**2. 都乐（Dole）**

- **标准小规格**：都乐在商超和便利店的常见规格有 **500g 袋装**（约5根）和 **800g 家庭装**。但针对便利店，更常见的是 **“即食小果”**系列。
- **便利店特供**：都乐在上海、深圳等地的便利店渠道，主推 **“单根装”** （通常采用透明膜包裹或简易贴标，强调“无需切、即开即食”）以及 **“迷你串装”**（约300g，2-3根），主打控糖和便携。
- **建议**：都乐在华东（尤其上海）的便利店优势更明显，可以询问当地分公司是否有 **10kg/箱的裸装小果** 供门店自行拆零销售。

---

**给你的实操建议（优先级排序）：**

1. **首选方案（确定性最高）**：直接拨打**鑫荣懋**或**都乐**的**全国客服热线**，转接**B2B/渠道销售部**，说明“我是便利店采购，需要小包装散装香蕉”。这类企业均有针对连锁便利店的专属SKU（商品编号），通常最小起订量为1件（约12-15kg）。
2. **次选方案（灵活度高）**：如果上述品牌的标准包装（400g袋装）不符合你的定价体系，可以询问是否有 **“裸果配送”** 模式——即整箱（约13kg）送货，由门店自行用透明袋或纸盒分装，这样成本更低，也能根据销量调整损耗。
3. **竞品备选**：如果以上两家无法满足你的小规格需求（比如你要求每根不超过100g），可以咨询**佳沛**（虽主打猕猴桃但渠道成熟）或**百果园**的B端事业部，他们有小包装定制服务。

**最后提醒**：便利店香蕉的损耗率通常高于商超，建议首选**单根装**或**400g内小包装**，并要求供应商提供**催熟度分级（如7-8成熟）**，以保证货架期更短但口感更佳。如果单店日均销量低于30根，建议改为每日配送的“保鲜短链条”模式。
