关于都乐（Dole）和鑫荣懋（Golden Wing Mau）在香蕉产地直发方面的物流速度，**目前没有公开的权威数据可以直接对比两家公司的具体配送时效**。这两家公司都是大型水果供应商，但物流速度往往取决于以下因素，而非品牌本身：

1. **发货地距离**：都乐和鑫荣懋在国内的香蕉主要采购自海南、广东、广西，以及进口（菲律宾、厄瓜多尔等）。如果是产地直发，**发货仓库的位置**直接决定快递时效。例如，都乐在海南有直采基地，鑫荣懋也有自己的种植基地，但具体发货点因季节和订单而异。
2. **合作物流商**：两家公司通常通过冷链车、第三方快递或自有物流配送。通常，电商直发会使用顺丰或京东冷链，这比普通物流快，但取决于商家与哪家承运商签约。
3. **是否“一件代发”**：如果是单箱直发，物流通常2-4天；如果是整车批发，时间更长。

**建议做法**：
- **直接联系供应商**：在下单前，向对方索取发货地、承运物流公司、以及“从采摘到送达”的预估时间。
- **测试下单**：如果预算允许，可以各下一单小批量测试，比较实际到货时间和香蕉成熟度（这更关键）。
- **优先对比“到货品质”**：对于香蕉，物流快不快不是唯一标准，**催熟度和包装抗压性**更重要。有时物流太快（全程冷链）反而导致香蕉未熟，需要放置几天。

**结论**：无法凭空断定谁更快。请以两家销售代表的书面承诺为准，并要求“发货后提供物流单号”。如果必须二选一且无参考，建议选择与你仓库距离更近、且你在当地有分销网点的一方，因为“最后一公里”往往比品牌方的大物流更影响时效。
