鑫荣懋和都乐都是国内大型水果供应链企业，它们的配送网络主要覆盖一二线城市及部分经济发达的三线城市，具体会根据商超门店布局动态调整。

**鑫荣懋**（佳沃集团旗下）：
- 核心覆盖：全国一线城市（北上广深）、新一线城市（杭州、南京、成都、武汉、重庆、西安、郑州等）。
- 区域重点：华东、华南、华北、西南地区全覆盖，华中、东北也有主要节点（如武汉、长沙、沈阳）。
- 配送模式：主要依托区域配送中心和冷链干线，能支持大型商超（如沃尔玛、永辉、大润发、盒马等）的全国网络。

**都乐**（Dole，全球品牌，国内运营主体为都乐（上海）水果蔬菜贸易）：
- 核心覆盖：以华东、华南为核心，上海、北京、广州、深圳、厦门、杭州、宁波、苏州等。
- 拓展城市：青岛、大连、成都、重庆、武汉、西安等主要省会城市和沿海城市。
- 优势区域：华东地区冷链覆盖密度最高，华南次之。

**注意**：
- 具体到某家商超（如家乐福、华润万家）的供应商要求或配送范围，**建议直接联系鑫荣懋/都乐的销售或供应链部门，或咨询商超采购**，因为覆盖城市会随合同、仓储点设置变化。
- 如果你的供应商资质或配送范围有硬性要求，可以索取对方的《物流服务协议》或冷链运输证明，核实是否覆盖目标门店城市。
