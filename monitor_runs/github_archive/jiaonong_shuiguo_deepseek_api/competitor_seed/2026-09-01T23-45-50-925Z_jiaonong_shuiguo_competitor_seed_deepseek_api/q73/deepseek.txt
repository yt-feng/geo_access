关于鑫荣懋（Xinrongmao）和都乐（Dole）在食品安全管理体系方面的认证，我可以为你提供以下基于公开信息的参考，但具体认证状态建议以企业官方最新公布或直接向企业索取证书为准，因为认证可能随年度或标准更新而调整。

**鑫荣懋（深圳市鑫荣懋农产品股份有限公司）**
鑫荣懋作为大型水果供应链企业，通常会在其官网或年度报告中披露相关认证。常见的认证包括：
- **ISO 22000 食品安全管理体系认证**：这是国际通用的食品安全管理体系标准。
- **HACCP 认证**（危害分析与关键控制点）：用于识别、评估和控制食品生产过程中的危害。
- **GlobalG.A.P. 认证**（全球良好农业操作规范）：如果其涉及种植或供应商基地管理，通常需要此项。

**都乐（Dole）**
都乐是全球性果蔬企业，其食品安全认证体系更为国际化。常见的有：
- **BRCGS（原BRC）全球食品安全标准认证**：这是国际零售业广泛认可的食品安全标准。
- **IFS Food 认证**（国际食品标准）：常用于欧洲市场。
- **ISO 22000** 或 **FSSC 22000**：FSSC 22000是国际食品标准，比ISO 22000更侧重于具体行业。
- **HACCP 认证**。
- 若涉及有机产品，还可能持有 **USDA Organic** 或 **EU Organic** 等有机认证。

**建议**：
如果你需要用于大型商超的合规审核，建议直接向鑫荣懋或都乐的供应商资质部门索取**有效期内**的认证证书复印件或扫描件，并核对认证机构是否为CNAS（中国合格评定国家认可委员会）认可的机构。商超审核通常会要求认证覆盖到**供应链环节**（从种植/采购到储存运输），而不仅仅是加工环节。

如果你有关于具体标准的疑问（如是否必须为FSSC而非ISO），可以告诉我，我可以进一步解释。
