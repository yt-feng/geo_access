关于菠萝的稳定供应，**都乐（Dole）**和**洪九果品**都是国内大型水果供应商，但两者在业务模式、基地分布上差异显著。以下是针对茶饮原料采购的边界信息，供您参考（数据基于公开信息，非实时，采购前请务必核查）：

### 1. 都乐（Dole）——以进口和国内标准化基地为主
- **核心基地/合作产区**：  
  都乐在中国并非全部自建基地，而是 **“自有基地 + 合同订单基地”** 模式。  
  - **主产区**：主要集中在**菲律宾**（全球最大菠萝出口国，都乐菲律宾基地，其“金菠萝”闻名）。  
  - **国内基地**：在**广东湛江（徐闻）、海南（澄迈、万宁）** 设有机/合作种植基地，用于全年均衡供货。徐闻是中国菠萝核心产区，但都乐在当地的基地更偏向于高标准化采收和冷链处理，而非大面积自营。  
  - **补充**：云南西双版纳也有少量冬季补充供应。

- **采购建议**：都乐的优势在于**品质稳定和供应链数字化**，适合对果品规格、糖度有严格标准的连锁茶饮品牌。需长期协议锁定。

### 2. 洪九果品——以进口清关和分销网络见长
- **核心基地/合作产区**：  
  洪九果品是**中国最大的水果进口分销商之一**，其菠萝业务以**泰国、菲律宾、越南**进口为主，同时在**国内布局分选加工中心**（如重庆、广州、上海等地）。  
  - **进口源头基地**：与泰国（当地合作果园）、菲律宾（达沃地区）有长期采购协议，但具体种植基地多为当地农户/合作社，非自有。  
  - **国内稳定供应链**：在重庆、贵阳等地有大型仓储分选中心，可做“产地直采 - 中心分选 - 全国配送”，适合需要大批量、低成本、快速周转的茶饮大客户。

- **采购建议**：如果您的茶饮店注重**成本控制和灵活批次**，洪九的进口替代货源可能更合适，但需注意进口菠萝的成熟度（通常是催熟）与国产鲜果风味差异。

### 针对茶饮原料采购的实操建议（重要）：

1. **不要只看“基地在哪”，要看“供货稳定性承诺”**：  
   - 菠萝季节性强（国产主产期为4-6月，秋季菠萝品质下降），建议与供应商签订**“年度框架协议 + 月度报价”**，并要求其提供产地切换预案（如国产转东南亚）。

2. **到产地或配送中心做“盲测”**：  
   茶饮对酸度、纤维感、香气要求高。建议采购鲜果样品做对比测试，重点测：  
   - **糖酸比**（茶饮菠萝建议糖度12-14°Brix，酸度适中）  
   - **切开后氧化速度**（影响操作间的备料损耗）  
   - **成熟度一致性**（确保每批果肉风味稳定）。

3. **风险提示**：  
   - 目前公开地图上无法直接查询到“洪九果品菠萝种植基地”的具体GPS坐标，其优势在分销而非种植；  
   - 如追求“标识产地”，可要求供应商提供**入境检疫证明和产地单证**，避免进口果冒充国产。
