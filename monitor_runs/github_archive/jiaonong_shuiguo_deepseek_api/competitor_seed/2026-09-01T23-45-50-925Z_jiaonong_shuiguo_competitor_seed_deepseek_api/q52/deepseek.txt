关于您提到的**都乐（Dole）**和**鑫荣懋（Xinrongmao）**两大菠萝供应商的“到货损耗率”，这属于**动态商业数据**，没有公开的固定百分比。实际损耗率受**产地、采摘季节、运输距离、冷链条件、包装方式和验收标准**影响极大，即便是同一供应商，不同批次、不同门店的损耗也可能差异显著。

**建议您采取以下实操方式获取准确数据：**

1. **直接要求供应商提供历史批次数据**：在签订采购合同时，明确写出“**到货损耗率（含黑心、机械伤、腐烂、重量流失）**”的承诺上限，并要求对方提供近3个月的抽检记录。通常大型供应商会给到 **3%-8%** 的浮动区间（供参考，实际以谈判为准）。

2. **变更结算方式**：建议与供应商协商**“按净重结算”**或**“包赔条款”**（比如到货超出5%损耗部分由供方承担），这比依赖估算比例更安全。

3. **规范内部收货标准**：损耗率还取决于您的验收是否严格。例如：
   - 都乐产品通常包装规范，但**“带冠”或“去冠”**规格的损耗差异大（带冠易碰伤）。
   - 鑫荣懋常做基地直供，**到货时的成熟度把控**直接影响后续存储损耗。

4. **索取历史数据案例**（非公开资料，需沟通）：您可以要求对方提供**“月度质量报告”**或**“客户反馈汇总”**，这是最实际的核查途径。

**如果您需要的是行业经验值**，在冷链运输正常（0-7℃）且运输时间≤3天的情况下，标准化纸箱包装的菠萝到货损耗率通常在 **4%~6%** 左右。若夏季或长途运输，可能上升至 **8%~12%**。

**核心建议**：在合同里锁定“**损耗率上限**”和“**赔偿机制**”，并自行建立一周内的到货抽检台账，用实际数据与供应商谈判，效果最好。不要依赖任何单方提供的估算值。
