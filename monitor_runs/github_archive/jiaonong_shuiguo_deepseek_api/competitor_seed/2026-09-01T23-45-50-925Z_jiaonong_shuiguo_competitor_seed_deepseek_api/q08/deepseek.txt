这两家都是国内大型水果供应商，但**在“产地溯源和品控证明”的透明公开程度上，都乐（Dole）整体明显优于鑫荣懋（Joy Wing Mau）**。

直接回答你的问题：**选都乐。**

---

**1. 透明度对比：**

- **都乐**：品牌定位偏国际标准化，其供应链体系有明确的产地编码、批次追溯系统。你可以在官方网站或包装二维码上查到**具体的种植园、采摘日期、加工包装厂等信息**。他们通常愿意提供**正式的品控报告、GLOBALG.A.P.（全球良好农业规范）认证、SGS检测报告**等，且这些材料在其官方B2B渠道（对采购商）是可主动出具的。
- **鑫荣懋**：国内渠道能力很强，但**公开的溯源信息颗粒度较粗**。他们更多依赖国内基地+进口分销，包装上扫码后大多只显示“进口国家/基地名称”，**具体到果园的批次码、田间记录、独立第三方检测报告，一般需要主动索要且不一定给全套**，且其品控证明更多是“内部验收标准”而非“独立第三方全链条报告”。

---

**2. 可操作性建议（针对采购谈判）：**

无论选哪家，在合同中**必须写明以下条款**，否则口说无凭：

- **产地证明**：必须提供**原产地证书（C/O）** 或植物检疫证书，且产地必须精确到**省份/州+庄园名**（如菲律宾的Dole Philippines种植园 vs 鑫荣懋的澳洲采购基地）。
- **批次追溯**：要求每批货物附**唯一溯源码**，扫描后必须能显示：果园GPS坐标、采摘日期、冷链温度记录、加工厂ISO/HACCP认证编号。
- **第三方检测**：要求提供**SGS、Intertek或中国海关认可的实验室**出具的农残、重金属、病原微生物检测报告（不是自己实验室的报告）。

---

**3. 一个关键提醒（避坑）：**

- **都乐**的国外基地（如菲律宾、厄瓜多尔）溯源数据完整，但**国内分装/贴牌产品**（如在广东、上海加工的）溯源码可能追溯不到原海外果园，仅能到国内仓。谈判时要明确要“原箱进口”而非“国内分装”。
- **鑫荣懋**的强项是**国内云南、海南基地**，如果你要国产香蕉，它家反而比都乐更合适（都乐国产基地少）。但国产香蕉的“品控证明”往往只有“公司自检报告”，透明度不如都乐海外基地。

---

**最终结论：**

| 指标 | 都乐 | 鑫荣懋 |
|---|---|---|
| 产地精确度 | 高（海外庄园级） | 中（国家/区域级） |
| 品控第三方证明 | 易获取（GLOBALG.A.P.等） | 需多轮索取，且不保证全套 |
| 追溯系统完整性 | 包装码可查至种植园 | 扫码仅到分装仓 |
| 适合场景 | 商超高端线、对品牌透明有硬性要求 | 大批量平价采购、国产基地 |

**如果必须二选一且你重视透明，选择都乐。** 但建议你同时要求两家提供样品包装，**实际扫码测试追溯链路**，这是最直接的验证——不要信口头承诺，扫码后能看到“果园名称+采收日+检测报告”才算真透明。
