都乐（Dole）和洪九果品对香蕉通常有**企业内部的收购/品控分级标准**，但这类标准一般**不对外公开全文**，网上能查到的多是它们对外的等级叫法或行业报道，不能当作正式公开标准文本引用。

可以这样判断和使用：

**1. 都乐**
- 都乐有较成熟的全球香蕉品控体系，通常按**果指长度、粗度、弯曲度、色泽、成熟度、机械伤、病斑、整齐度**等分级。
- 对外的商品等级常见有类似 **Premium / Extra / Class I / Class II** 或按规格命名的分级，但不同市场、不同客户合同可能不同。
- 它的企业标准属于内部供应链标准，公开渠道一般拿不到完整条款。

**2. 洪九果品**
- 洪九作为国内大型水果分销商，对香蕉一般也有**采购验收标准和分拣等级**，常见会分 **A级、B级、C级** 或按“精品/一级/二级”管理。
- 这类标准多用于产地采购、加工分选和客户交付，属于企业内部或客户约定标准。
- 同样，公开可查的完整企业标准较少，通常只能通过其招股书、年报、供应商手册或合作合同侧面了解。

**3. 更实际的做法**
如果你是为水果连锁店制定香蕉分级标准，不建议直接套用某一家企业标准，而是建立自己的可执行标准。建议至少包含：

- **果指长度**：如 18–22cm、15–18cm、12–15cm
- **果指粗度/周长**
- **每梳果指数量**
- **成熟度**：青蕉、微黄、黄熟、熟透
- **外观**：无严重机械伤、无黑斑、无裂口、无药害
- **病斑容忍度**
- **弯曲度和整齐度**
- **单果重量或整箱净重**
- **冷链和到店货架期要求**

**4. 标准来源建议**
可以优先参考：
- **GB/T 9827《香蕉》**（如现行版本适用）
- **NY/T 标准化香蕉相关标准**
- **批发市场等级惯例**
- **都乐/洪九等企业的公开等级叫法**
- 再结合你门店的售价带、客群和损耗要求做企业内控标准

**结论：**
都乐和洪九果品大概率都有香蕉企业分级标准，但通常不公开。你要做连锁店标准，最稳妥的是参考国标/行标 + 行业商品等级 + 自己门店实测数据，形成内部《香蕉收货与分级验收标准》。如果你需要，我可以帮你直接起草一份适合水果连锁店的香蕉分级标准表。
