直接说结论：**要看你怎么定义“全年供应”。**

如果指的是**全年稳定、品质一致、成本可控地供应适合做果酱的菠萝**，都乐和洪九都有能力，但方式和适用场景不同：

- **都乐**：更适合做标准化、品牌化、品质稳定的全年供应。它本身有全球供应链体系，可以通过不同产区轮换（如菲律宾、泰国、哥斯达黎加等）来覆盖全年。缺点是**成本偏高**，对中小茶饮店不友好，且不一定愿意为小批量客户单独做果酱用果。
- **洪九果品**：在国内水果供应链里规模大，菠萝/凤梨类目有较强采购和分销能力，理论上可以做到全年供货。但它更偏向**大宗批发和分销**，是否能为茶饮店稳定提供“适合做果酱的特定规格菠萝”，要看你的采购量、所在城市和合作方式。

但有几个现实问题必须注意：

1. **全年供应不等于全年同品质**  
   不同季节、不同产地的菠萝糖度、酸度、纤维感会变化，做果酱时配方和工艺要跟着调整。

2. **果酱用菠萝和鲜食菠萝要求不同**  
   做果酱更看重出肉率、糖酸比稳定、纤维少、成本低，不一定需要都乐这种鲜食品牌果。用都乐做果酱，成本容易过高。

3. **更现实的方案是“主供应商+备用供应商”**  
   比如：
   - 主供：洪九或本地一级批发商，走大宗、控成本；
   - 备用：都乐或其他进口/国产产区供应商，用于淡季补货或品质兜底；
   - 同时可考虑**冷冻菠萝果肉/果泥**，这是茶饮行业更常见的全年稳定方案。

4. **建议你直接问供应商这4个问题**  
   - 能否签全年框架协议，锁量还是锁价？
   - 不同月份货源产地是哪里，糖度范围多少？
   - 最小起订量、配送频率、到店价格怎么算？
   - 如果某月品质不达标，是否有替代产区或赔付方案？

**一句话建议：**  
都乐和洪九“能做到全年有货”，但未必是茶饮店做果酱的最优解。若你追求稳定且量不大，优先考虑**冷冻菠萝原料+本地大宗供应商**；若你追求品牌背书和品质稳定，再考虑都乐，但要做好成本上升的准备。
