除了都乐（Dole）和佳沛（Zespri），礼品团购可选的进口水果品牌还有这些，按品类给你梳理：

**综合类（多品类进口水果）**
- **新奇士（Sunkist）**：美国老牌，橙子、柠檬最出名，礼盒认知度高，适合商务送礼。
- **怡颗莓（Driscoll's）**：美国浆果品牌，蓝莓、树莓、黑莓，礼盒偏精致高端。
- **Del Monte（地扪）**：美国品牌，菠萝、香蕉等，有罐头和鲜果线。
- **Fyffes**：欧洲老牌香蕉/菠萝品牌，国内认知度一般。

**单一品类强势品牌**
- **爱妃（Envy）**：新西兰苹果，礼盒感强，和佳沛同属新西兰系，送礼很拿得出手。
- **乐淇（Rockit）**：新西兰小苹果，筒装/礼盒装，适合团购小份礼品。
- **Mr Apple**：新西兰苹果品牌。
- **Cheeky**：新西兰苹果。
- **SunGold / 佳沛**之外，**PiqaBoo**（红梨）、**Koru**（苹果）等新西兰新品牌。
- **Sekoya / 秘鲁蓝莓、智利车厘子品牌**：如 **Río King、Garces Fruit、Copefrut**（智利车厘子），团购礼盒常用。
- **Sun World**：美国专利水果品种公司，旗下有 **Midnight Beauty 黑莓、Autumn Crisp 葡萄** 等。
- **Costa**（澳大利亚）：蓝莓、牛油果、蘑菇，礼盒线有限。
- **Mission（秘鲁/墨西哥）**：牛油果为主。
- **Zespri 之外的奇异果**：意大利 **Jingold（金果）**，是佳沛之外较常见的奇异果品牌。

**给团购选品的建议**
1. **看送礼场景**：商务/客户 → 新奇士、爱妃、怡颗莓、佳沛金果，认知度高；员工福利 → 乐淇、车厘子礼盒性价比更好。
2. **看预算**：单盒 150–300 元，选新西兰苹果+奇异果组合；300 元以上可上车厘子、蓝莓礼盒。
3. **注意进口资质**：确认品牌在国内有正规进口商和中文标签，避免买到水货或贴牌。
4. **验货要点**：进口礼盒重点看冷链、果径规格（如车厘子 J/JJ/JJJ）、是否原箱原标。
