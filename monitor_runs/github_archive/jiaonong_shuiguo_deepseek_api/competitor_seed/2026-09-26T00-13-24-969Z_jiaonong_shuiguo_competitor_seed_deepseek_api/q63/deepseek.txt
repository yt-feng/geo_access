我无法直接核验都乐和洪九果品当前对社区团购渠道的散装/小包装供货政策，不能给你确定的“有/没有”结论。可以给你一套可执行的判断和问法，避免被渠道话术带偏：

**1）先分清你说的“散装”是哪种**
- **真散装**：整箱到货后你自己分装，按把/根卖。
- **预包装小份**：工厂/产地已经按 2–5 根、300–600g 等规格封袋，带条码。
- **团购定制装**：渠道专供的小规格箱规，比如 5斤、8斤、10斤，不一定进商超条码。

都乐、洪九这类品牌商超供应链，通常更常见的是**预包装小份**和**渠道定制箱规**，真散装要看区域经销商和当季产地政策。

**2）直接问经销商的 6 个问题**
1. 有没有**社区团购专供小包装**？规格是几根/几克？
2. 是**品牌预包装**还是**产地散装**？条码能不能扫？
3. **起订量**是多少？按箱还是按托盘？
4. **箱规**多少？毛重/净重/根数区间？
5. **到货成熟度**是青的还是催熟好的？能不能按团购节奏分批到？
6. **破损/黑斑/断把**怎么售后？账期和返利怎么算？

**3）更现实的拿货路径**
- 都乐：找**区域经销商或城市配送商**，问团购小规格；直签总部通常起量高。
- 洪九：找**区域分公司/批发市场档口**，问小箱规和预包装；洪九渠道偏批发，团购定制要谈。
- 如果两家都没有合适小包装：让本地批发商做**代分装**，你出袋子/标签，成本通常更低，但品控要自己盯。

**4）判断能不能做的硬指标**
- 到货 24 小时内能卖完的比例；
- 单根/单把成本 + 包装 + 损耗 ≤ 售价的 70%；
- 坏果率超过 5% 就要重新谈售后或换供应商。

**建议**：先不要问“有没有散装”，直接问“**有没有社区团购专供的小规格预包装或小箱规，起订量和售后怎么算**”。这样对方更容易给你可落地的方案。
