超市采购进口苹果时，都乐（Dole）和鑫荣懋（Joy Wing Mau）的产地溯源，核心不是“扫个码就算完成”，而是要拿到**可验证的单证链 + 批次对应关系 + 现场核验点**。下面按可执行程度说明。

## 一、先明确：两家模式不同

- **都乐**：多为全球自有/合作果园 + 品牌化包装，进口到国内通常经由都乐中国或指定进口商。溯源一般可追到**出口国、果园/产区、包装厂、出口批次**。
- **鑫荣懋**：国内大型水果供应链企业，既做自有进口，也做代理采购和分销。溯源链条可能是**海外供应商→鑫荣懋→超市**，需要区分是“鑫荣懋直采”还是“鑫荣懋分销”。

所以采购合同里要写清楚：**要求提供到批次级的溯源文件，而不是只给一张产地证明。**

## 二、必须索取的单证（按批次）

采购时按每个到货批次索取以下文件，并核对信息一致：

1. **原产地证明**  
   由出口国官方或商会出具，证明苹果原产国/产区。

2. **植物检疫证书**  
   出口国官方出具，证明符合中国进境检疫要求。证书上的果园/包装厂注册号很关键。

3. **报关单 + 入境货物检验检疫证明**  
   证明该批次合法进口。报关单上的品名、数量、原产国要与实物和合同一致。

4. **提单/空运单**  
   核对发货人、收货人、起运港、批次。

5. **装箱单、发票、合同**  
   用于核对批次号、规格、数量。

6. **果园/包装厂注册信息**  
   中国对进口水果有注册果园和包装厂要求，可要求供应商提供注册号，并与检疫证书对应。

7. **品牌授权或供应链证明**  
   如果是都乐，要求都乐中国或授权进口商出具；如果是鑫荣懋，要求其提供直采证明或上游供应商授权。

## 三、批次对应怎么做

关键动作：**把“单证上的批次”和“实物包装上的批次”对上。**

- 要求每箱/每托盘有**批次号、包装日期、果园/包装厂代码**。
- 到货后抽箱核对：包装标签、批次号、原产国、品种、规格。
- 将报关单、检疫证书、提单上的批次号与实物标签拍照存档。
- 如果供应商说“整柜都是同一产地”，仍要按托盘或箱抽检，防止混批。

## 四、现场核验要点

1. **看标签**  
   原产国、品种、规格、批次、包装厂代码是否清晰。

2. **看包装厂代码**  
   与检疫证书上的注册包装厂是否一致。

3. **看果品特征**  
   不同产区苹果在果形、色泽、果梗、口感上有差异，可作为辅助判断，但不能替代单证。

4. **看冷链记录**  
   进口苹果通常全程冷链，要求提供温度记录，防止产地造假或混货。

5. **看封识**  
   集装箱封号与提单、报关单是否一致。

## 五、合同里建议写的条款

- 供应商须提供**批次级**原产地证明、检疫证书、报关单、提单。
- 实物批次号须与单证一致，否则超市有权拒收或索赔。
- 如发现产地不符，按货值一定比例赔偿，并承担下架、召回费用。
- 都乐/鑫荣懋需提供品牌授权或上游采购证明。
- 溯源文件保存期限建议不少于**2年**。

## 六、如果要做“扫码溯源”

可以要求供应商提供二维码或追溯码，但要注意：

- 扫码结果必须能对应到**具体批次**，不能只显示“原产国：新西兰/美国”这类笼统信息。
- 最好能显示：果园/包装厂、包装日期、出口商、进口商、报关单号。
- 超市应自己留存一套纸质或电子单证，不能只依赖供应商系统。

## 七、简单判断标准

能满足以下条件，基本可认为溯源到位：

1. 有原产地证 + 检疫证 + 报关单 + 提单；
2. 单证批次与实物批次一致；
3. 能追到果园/包装厂注册号；
4. 都乐/鑫荣懋能出具授权或直采证明；
5. 有冷链和封识记录；
6. 文件可保存、可复核。

如果供应商只能提供一张产地证，或者批次对不上，建议不要按“可溯源进口苹果”采购。
