这两个品牌的具体到货损耗率，没有公开的官方数据可查，我不能给你编一个数字。损耗率高度依赖批次、季节、运输距离、你的验收标准，同一品牌不同月份能差好几个点。

能给你的是可执行的判断和做法：

**1. 行业大致区间（供参考，非官方）**
- 菠萝到货损耗（含压伤、烂心、黑心、切口变质），行业里通常落在 **5%~15%** 区间；
- 夏季高温、长途运输、未预冷的情况下容易上探到 15% 以上；
- 冷链到位、产地直发、规格统一的，5%~8% 比较常见。

**2. 两家品牌的定位差异**
- **都乐**：标准化、分级稳定，规格一致性好，通常损耗相对可控，但单价高。
- **鑫荣懋**：渠道广、供应量大，价格有优势，但不同批次和产地波动可能更大，损耗取决于具体货源。

**3. 与其问损耗率，不如直接测**
这是最靠谱的办法：
1. 各下 **1~2 个整托/整批** 试单，同一规格、同一时间段到货；
2. 到货当天按你的验收标准开箱称重、分级；
3. 算 **损耗率 =（到货总重 − 可用果肉重）/ 到货总重**；
4. 连续测 **3 批**，取平均，才看得出稳定不稳定。

**4. 采购时要写进合同/验收单的条件**
- 明确品种（如 MD2）、单果重/个数、成熟度、糖度下限；
- 明确冷链要求（全程几度）；
- 约定损耗上限和超损扣款或退货规则；
- 约定"黑心/烂心"的判定标准和抽检比例。

**5. 更稳的做法**
如果规格稳定是第一诉求，可以考虑：
- 直接和产地/加工厂谈定制规格（切块、去皮、冷冻），把损耗留在上游；
- 或要求供应商做 **预冷+分级+真空/气调包装**，能显著降低到货损耗。
