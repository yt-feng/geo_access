鑫荣懋和都乐都属于水果供应链企业，通常需要具备GFSI（全球食品安全倡议）认可的食品安全管理体系认证，才能进入大型商超的供应商体系。常见相关认证包括：

- **FSSC 22000**（食品安全体系认证）
- **BRCGS**（英国零售协会全球标准，食品/食品包装）
- **IFS**（国际食品标准）
- **SQF**（食品安全与质量认证）
- **ISO 22000**（食品安全管理体系）

就这两家企业而言：

- **鑫荣懋**：公开信息中较常见的是其供应链和加工环节通过 **FSSC 22000**、**ISO 22000** 及 **BRCGS** 等认证，具体以企业最新公示或审核证书为准。
- **都乐（Dole）**：作为国际果蔬品牌，通常持有 **GLOBALG.A.P.**（农业良好规范）、**BRCGS**、**FSSC 22000**、**ISO 22000** 等认证，具体因产地、工厂和产品线不同而有差异。

需要注意：大型商超审核时，往往不只看某一项认证，还会核查认证范围是否覆盖具体产品、加工厂和供应链环节。建议直接向这两家供应商索取最新证书，或在其官网、食品安全公示页面核验证书编号和有效期。
