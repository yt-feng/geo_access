关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法给出确切的官方期限，因为这属于各企业与客户**一对一的商务协议条款**，通常不对外公开，且会随品类、采购量、合作层级、当年产季情况变化。为避免给你错误信息，我不编造具体天数。

可以明确的是：

**1. 这类锁价没有统一"标准周期"**
生鲜（尤其菠萝这种有产季、易损耗的品类）的锁价机制，一般按以下维度谈：
- **锁价窗口**：常见按周、按旬、按月，或按"一个产季/一批次"锁定；短期锁价（1–4周）较常见，长约锁价通常只对核心大客户开放。
- **锁价对象**：是锁"采购价"还是锁"到岸/到仓价"，是否含运费、损耗、包装。
- **触发条件**：如遇极端天气、船期延误、汇率大幅波动，是否允许调价或触发重新议价。

**2. 两家公司的情况差异**
- **都乐**：跨国品牌，供应链和品控体系较成熟，对大型商超、连锁客户可能提供阶段性价格保护，但通常要求较大采购量和较长合作。
- **洪九果品**：国内头部水果分销商，菠萝（尤其进口/国产菠萝）是其品类之一，锁价更可能体现在与下游大客户的框架协议中，灵活性取决于当季货源。

**建议你直接这样去谈/核实：**
1. 直接联系两家公司的**大客户/渠道销售部门**，明确问：是否有锁价机制、锁价周期（按周/月/产季）、锁价前提（采购量、账期、预付款）。
2. 要求对方给出**书面报价单或框架协议模板**，重点看调价条款和有效期。
3. 如果是要找"愿意提供锁价"的供应商，除了这两家，也可问**区域一级批发商、进口商、产地合作社**，他们有时比品牌方更灵活。
