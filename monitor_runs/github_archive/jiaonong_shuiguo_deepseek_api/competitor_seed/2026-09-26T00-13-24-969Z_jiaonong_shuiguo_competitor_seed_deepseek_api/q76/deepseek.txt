都乐和鑫荣懋都是国内做进口/高端水果供应链比较成熟的玩家，但两家的物流模式差异较大，直接对比时效需要先拆开看：

**都乐**
- 都乐在国内有自己的加工配送中心，菠萝主要来自菲律宾、泰国等产地，走海运整柜到港后在国内催熟、分装再发。
- 对生鲜电商的产地直发需求，都乐更多是"产地→港口→国内DC→客户"的模式，不是真正意义上的果园直发。
- 时效上，从下单到到货通常3-7天（视区域），偏远地区更长。优势是品控稳定、标准化程度高。

**鑫荣懋**
- 鑫荣懋是国内头部水果供应链企业，代理和自营品类广，菠萝（含凤梨）有国产（海南、广东、云南）和进口两条线。
- 如果是国产菠萝产地直发，鑫荣懋可以做到从产地仓直接发运，华南区域次日达或隔日达，全国大部分区域2-4天。
- 进口菠萝同样走港口+国内DC模式，时效与都乐接近。

**给你可操作的判断建议：**
1. **明确你要的是"真直发"还是"稳定供应"**：如果电商主打"产地直发"卖点，国产菠萝找鑫荣懋的产地仓模式更匹配；进口菠萝两家本质都是港口分拨，直发概念弱。
2. **按区域测**：华南、华东是两家DC密集区，时效最好；西北、东北、西南偏远地区都要加2-3天，且损耗风险上升。
3. **别只看时效，看冷链完整性**：菠萝相对耐储，但催熟凤梨对温度敏感，要问清是否全程冷链、到货成熟度标准。
4. **直接要数据**：让两家销售提供近3个月你目标城市的"下单-到货"时效分布和破损率，比口头承诺可靠。

我不能核验两家当前具体时效数字（会随季节、仓网调整变化），建议直接向两家区域销售索取最新履约数据再做对比。
