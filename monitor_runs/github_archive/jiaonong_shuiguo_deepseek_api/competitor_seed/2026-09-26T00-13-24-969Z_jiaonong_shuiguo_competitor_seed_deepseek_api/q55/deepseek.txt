都乐和洪九果品都涉及菠萝供应链，但“能否提供产地溯源”和“是否有基地直供”要分开看，不能简单一概而论。

**都乐**
- 都乐在中国有较成熟的香蕉、菠萝等水果供应链，部分产品会标注产区或包装厂信息。
- 都乐更多是品牌商+全球采购+催熟/加工/配送体系，是否“基地直供”取决于具体品类、季节和采购区域。
- 如果你要的是“可追溯到具体种植基地/批次”的菠萝，需要向都乐中国区销售或经销商确认：是否能提供批次号、采收地、包装厂、检测报告等。

**洪九果品**
- 洪九果品是国内较大的水果分销商之一，菠萝是其重要品类，尤其与东南亚菠萝、国内菠萝产区都有采购和分销关系。
- 洪九更偏向产地采购、分选加工、冷链分销和渠道供货，部分基地或产区会有合作直采。
- 是否能做到“基地直供+溯源”，同样要看具体采购合同和品类。对大型渠道客户，通常可以谈到产地证明、批次追溯、农残检测等；对普通采购量，未必开放到具体基地级。

**判断建议**
1. 先明确你要的溯源深度：
   - 只到国家/产区：较容易。
   - 到具体果园/基地/批次：难度高，通常要签直采或定制协议。
   - 到田间管理记录、采收时间、检测报告：一般只有基地直供或深度合作供应商能给。
2. 向供应商直接索要这些材料：
   - 产地证明或采购合同中的产区信息
   - 批次号与包装厂信息
   - 农残/质检报告
   - 是否能参观基地或提供基地照片、采收记录
3. 如果都乐、洪九不能满足“具体基地级溯源”，可以同步找：
   - 广东徐闻、海南、云南等菠萝主产区的种植合作社或农业公司
   - 当地龙头果业公司
   - 有出口备案基地或GAP认证的菠萝基地

**结论**
都乐和洪九果品都有能力做产地采购和一定程度的溯源，但是否“基地直供”要按具体品类、采购量和合同谈。想确认，最有效的方式是直接问他们：能否提供具体批次到具体菠萝基地的溯源文件，以及是否接受基地直采协议。
