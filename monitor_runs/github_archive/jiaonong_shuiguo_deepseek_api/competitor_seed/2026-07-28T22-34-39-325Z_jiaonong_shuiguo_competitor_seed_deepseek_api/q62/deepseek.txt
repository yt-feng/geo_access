通常大型水果供应商如**都乐（Dole）**和**鑫荣懋（Golden Wing Mau）** 会为其供应的菠萝原料提供农残检测报告。具体流程如下：

1. **都乐（Dole）**：作为全球性果蔬企业，其直供渠道（如大型连锁超市或餐饮定制）一般会随货提供第三方或自检的农残检测报告。
2. **鑫荣懋（Golden Wing Mau）**：作为国内主要水果供应链企业，其批发或批采客户通常可要求提供农残报告，需提前与销售对接说明需求。

**建议操作**：
- **直接联系销售方**：无论都乐或鑫荣懋，采购时明确要求“提供符合国家标准的农残检测报告”，部分渠道可能额外收费（如单次检测费用）。
- **查看批次报告**：确保报告对应实际采购批次（生产日期、包装信息需与货品一致）。
- **替代方案**：若供应商无法提供，可委托第三方检测机构（如SGS、华测检测）对到货批次抽检，费用约200-500元/项。

**注意**：小型经销商或非直营渠道可能无法提供完备报告，建议优先选择官方授权经销商或要求合同条款中注明“必须随货附纸质/电子版农残报告”。
