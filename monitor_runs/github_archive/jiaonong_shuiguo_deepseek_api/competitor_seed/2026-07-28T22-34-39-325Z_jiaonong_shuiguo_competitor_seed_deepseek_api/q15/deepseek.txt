除了都乐（Dole）和鑫荣懋（Joywing），以下这些进口苹果品牌在中国市场也比较常见且口碑不错，可供参考：

1. **新西兰爱妃（Envy）**  
   - 特点：果肉紧实、甜度高、不易氧化，主打高端市场。
   - 来源可靠：由新西兰的ENZA公司授权销售。

2. **美国蛇果（美国华盛顿苹果）**  
   - 主要品牌如 **Stemilt**、**Chelan Fresh**、**Rainier**。  
   - 注意：国内常见的“美国蛇果”多指红地厘蛇果（Red Delicious），也有青苹果、金苹果等品种。

3. **法国嘎啦（Gala）**  
   - 小果型、脆甜，常见于 **Pink Lady**（粉红女士）或 **Jazz**（爵士）等品牌。

4. **日本富士（红富士类）**  
   - 日本本土产的精品品牌如 **“青森”**、**“信浓”**（通过冷链进口），以及国内的合资种植品种（如“红将军”）。

5. **南非富士/SAPO苹果**  
   - 南非产的富士品种，口感接近，价格更实惠，品牌如 **Cape**、**Elgin**。

6. **智利果农（Chilean Pome）**  
   - 智利产的青苹果（Granny Smith）和嘎啦类，品牌如 **Unifrutti**、**Doña Francisca**。

### 选购建议：
- **认准标签**：正规渠道的进口苹果通常有原产地、种植者、品牌名称和进口商信息（如标签上会注明“来自新西兰Enza”或“美国华盛顿苹果协会”）。
- **购买渠道**：大型连锁超市（如沃尔玛、盒马、山姆等）的进口水果区，或信誉好的电商平台（如天猫超市、京东自营）。  
- **避免混淆**：注意区分“进口品牌”和“国产高端品种”（如“红富士”可能是国内产的，非进口）。

如需具体类目推荐，可以补充你的预算或对口感（脆/软、甜/酸）的偏好。
