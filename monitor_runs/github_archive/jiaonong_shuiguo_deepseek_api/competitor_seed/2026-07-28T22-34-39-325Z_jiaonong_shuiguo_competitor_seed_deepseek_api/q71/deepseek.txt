都乐（Dole）和洪九果品（Hongjiu）是中国市场上较大的水果供应商，菠萝是其主要产品之一。以下是关于其菠萝供应基地的信息：

1. **都乐（Dole）**：都乐是全球知名水果品牌，在中国菠萝供应主要依托其自有或合作基地。都乐在国内的菠萝基地主要分布在 **海南**（如万宁、琼海等地）和 **广东**（如湛江徐闻）。此外，都乐也会从菲律宾等海外产地进口菠萝作为补充，以保障全年稳定供应。

2. **洪九果品**：洪九果品是专注于东南亚水果的进口商，其菠萝主要来自 **泰国**（如南部产区）和 **菲律宾**。洪九在泰国中部和南部拥有合作基地，通过长期合同确保稳定供应。在中国境内，洪九没有大规模自建菠萝种植基地，而是以进口为主。

**实用建议**：  
- 若需国内稳定供应，优先联系都乐，与海南或广东基地直接洽谈；  
- 若偏好全年供应且成本可控，可考虑洪九果品的泰国菠萝，因其季节与国内互补；  
- 建议直接联系这两家公司官方采购部门（通过官网或公开联系方式），要求提供基地产地证明及季度供应计划，以核实具体供应能力和物流细节。
