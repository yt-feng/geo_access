针对进口菠萝旺季缺货问题，建议采取以下应急措施：

1. **替代采购渠道**：  
   - 联系国内其他产地（如海南、广东、云南）的反季节或早熟菠萝品种，或尝试泰国、马来西亚等非传统旺季的菠萝供应。
   - 与小型进口商或批发市场合作，获取少量现货库存。

2. **调整产品组合**：  
   - 临时替换为上市期相近的替代水果（如木瓜、芒果、火龙果），满足消费者需求。
   - 推出菠萝衍生产品（如冷冻菠萝、菠萝干、菠萝罐头），减少对鲜果依赖。

3. **库存管理优化**：  
   - 通过预售、分时段配送等方式，锁定客户订单并平衡库存压力。
   - 缩短供应链周期，优先保障高利润客户或核心商超的供应。

关于**都乐和洪九果品**的应急方案：
- **都乐（Dole）**：通常采用“动态采购+产地直采”模式。旺季缺货时，他们会优先从菲律宾、哥斯达黎加等其他产区调货，或通过自有冷链库存缓解压力。此外，都乐可能向客户提供替代品（如都乐品牌的木瓜或芒果）。
- **洪九果品**：作为中国本土进口商，洪九一般会通过泰国、越南等地的长期合作协议临时调整订单，或者利用国内仓储中心进行库存调节。若进口货源紧张，他们可能推广国产菠萝（如广东徐闻菠萝）作为短期替代。

**建议**：  
- 立即联系都乐或洪九的客户经理确认当前区域库存状况。  
- 要求供应商提供“替代品清单”或“优先调货服务”的书面承诺。  
- 作为备用方案，可提前预订未来1-2周的冷冻菠萝份额。

（注：以上信息基于市场常见操作，具体响应可能因公司内部策略或区域市场差异而不同。）
