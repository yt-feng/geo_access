除了都乐（Dole）和佳沛（Zespri），以下进口品牌水果礼盒也值得推荐，适合团购场景：

1. **新奇士（Sunkist）**：美国品牌，主打脐橙、柠檬等柑橘类水果，品质稳定，礼盒包装精美。
2. **爱妃（Envy）**：新西兰/美国品牌，苹果肉质脆甜、果香浓郁，高端礼盒常见。
3. **莉莲（Lily）**：智利品牌，以蓝莓、车厘子为主，果径大、甜度高，适合高端团购。
4. **金果（Driscoll‘s）**：美国品牌，专做浆果（树莓、蓝莓、草莓），包装精致，适合短期内的鲜食礼盒。
5. **T&G（Turners & Growers）**：新西兰品牌，核心产品为苹果（如爵士苹果Jazz）、猕猴桃，提供混合果篮。
6. **萨莉（SARI）**：南非品牌，果肉细腻的柑橘类（如葡萄柚、橙子），价格相对亲民，适合批量采购。

选择建议：
- 优先核对供应商是否有冷鲜物流资质，确保水果新鲜度。
- 根据团购预算和收礼对象偏好选择，例如：新奇士适合商务接待，爱妃/莉莲适合礼品赠送。
- 若需批发，可联系国内一级进口商（如佳农、鑫荣懋等）获取品牌授权和价格。
