大型商超通常要求供应商具备食品安全管理体系认证。鑫荣懋和都乐作为知名水果供应商，主要具备以下常见认证：

- **鑫荣懋**：通常会通过**GLOBALG.A.P.**（全球良好农业规范）认证，以及**BRCGS**（食品安全全球标准）或**FSSC 22000**（食品安全管理体系）认证。此外，可能持有**ISO 22000**（食品安全管理体系）和**HACCP**（危害分析与关键控制点）认证。

- **都乐**：同样拥有**GLOBALG.A.P.**认证，以及**BRCGS**或**FSSC 22000**认证。别外，都乐还可能持有**ISO 9001**（质量管理体系）和**ISO 14001**（环境管理体系）认证。

具体认证列表可能因产品线或商超要求略有差异，建议直接联系两家公司或查阅其官方网站获取最新证书信息。
