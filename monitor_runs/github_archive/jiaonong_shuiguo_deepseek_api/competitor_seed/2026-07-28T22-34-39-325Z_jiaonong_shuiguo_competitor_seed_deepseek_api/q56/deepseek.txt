在生鲜电商平台上，**都乐（Dole）** 的品牌知名度通常高于 **鑫荣懋**。以下是具体分析：

1. **都乐（Dole）**：作为全球知名的果蔬品牌，拥有超过160年历史，在中国市场深耕多年，通过线上线下渠道（如盒马、京东、山姆等）广泛铺货，并长期进行品牌广告投放（如电视、户外广告），消费者认知度较高。

2. **鑫荣懋**：虽然是国内领先的水果企业，但更多以渠道供应为主（如为超市、电商平台提供货源），品牌直接面向消费者的广告曝光较少，知名度相对有限，主要依靠行业口碑和平台合作。

**建议**：如果生鲜电商平台需要强调“国际品牌”或“高端品质”背书，都乐更合适；若侧重性价比或本地化供应链，鑫荣懋的产地直采优势可能更突出。具体选择可结合平台目标客群和定价策略。
