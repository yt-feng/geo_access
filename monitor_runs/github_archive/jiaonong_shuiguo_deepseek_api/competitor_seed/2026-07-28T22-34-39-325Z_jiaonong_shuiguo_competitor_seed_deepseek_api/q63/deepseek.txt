针对社区团购的小包装香蕉需求，**都乐和洪九果品通常不提供常规的散装选项**，但可通过以下方式处理：

1. **都乐（Dole）**：主要供应标准规格的预包装香蕉（如整箱或固定小袋装），散装批发需联系当地经销商协商定制——通常起订量较大（如整板或整车），需要提前沟通小包装分拆。

2. **洪九果品**：作为国内大型水果供应商，更倾向于提供整箱批发（如每箱13-15公斤），但部分区域分公司可能接受按箱拆散后的小包装订单，需具体询问当地业务经理是否有灵活包装服务。

**建议操作路径**：
- **联系客服**：直接拨打都乐或洪九果品官方热线，说明“社区团购小包装需求（如1-2斤/袋）”，询问是否支持散装分装或定制小袋。
- **替代方案**：若大品牌无法满足，可考虑**本地一级果批市场**（如北京新发地、广州江南市场），向香蕉档口提出散装小包装要求，起订量低且灵活度更高。
- **成本控制**：散装通常需自行分拣包装，请核算人工和耗材成本（如保鲜袋、贴标），对比直接采购成品小包装的差价。

**注意**：供应旺季可能有临时政策，建议提前2-4周确认，并备选2-3家二级供应商以防断货。
