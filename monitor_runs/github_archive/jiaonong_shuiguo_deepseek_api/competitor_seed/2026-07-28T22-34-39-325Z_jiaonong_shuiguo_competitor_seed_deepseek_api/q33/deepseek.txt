洪九果品和鑫荣懋的到货速度受区域、产品种类、季节和仓库位置影响较大，无法给出绝对结论。以下是基于常见运营特点的分析：

1. **洪九果品**：通常以东南亚水果（如榴莲、山竹）及国内高性价比果品为主，在部分城市设有分仓。如果目标市场在其分仓辐射范围内，且是常规品种，到货可能较快（例如1-2天）。但若涉及稀缺或远距离调货，可能稍慢。

2. **鑫荣懋**：作为大型全品类水果供应链企业，物流网络覆盖较广，尤其在一二线城市和商超渠道。其标准订单的到货时效较稳定，通常为1-3天，但大批量批发或非通用品种可能需要预排期。

**实际建议**：
- 直接联系两家公司在您所在地的销售或仓库，询问当前库存品种的“最快到货时间”，并要求给出具体承诺（如“今日下单明日到”）。
- 如果同城市有分仓，通常**洪九**短距离运输更快；若需跨区域调货，**鑫荣懋**的成熟物流网络可能更可靠。
- 小批量试单：各进少量同品种，对比实际到货时间及品质稳定性。

最终速度取决于**具体品类、下单时间（如节假日前后）及供应商当前库存**。建议以实时沟通为准，避免依赖普遍结论。
