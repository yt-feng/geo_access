都乐（Dole）和洪九果品（Hongjiu Fruit）作为大型水果供应商，通常针对大型客户（如连锁超市、电商平台）提供锁价机制，但具体周期会因合同规模、市场行情、合作年限等因素动态调整。

- **都乐**：在长期合作框架下，锁价周期一般以**月度或季度**为主，部分稳定大单可协商至**半年**。紧急或小批量订单通常无锁价。
- **洪九果品**：锁价周期多集中在**1-3个月**，针对核心客户可延长至**半年**，但需提前签订协议并缴纳部分保证金，价格浮动条款较严格。

建议您直接联系两家的区域销售经理，明确说明预计采购量、合作周期、包装规格（如20斤/箱或出口级标准），以获取精确报价和锁价协议。同时可对比第三方批发市场（如上海辉展、广州江南市场）的现货价格波动，评估锁价必要性。
