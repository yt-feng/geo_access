针对茶饮店用菠萝做果酱、需要全年稳定供应的问题，都乐（Dole）和洪九果品（Hongjiu Fruit）作为大型水果供应商，理论上具备提供全年菠萝供应的能力，但实际可行性需结合以下因素分析：

1. **菠萝供应季节**：菠萝是热带水果，主要产季集中在春季至秋季（如中国海南、广东等产区的菠萝在3-6月为旺季），但通过南半球（如菲律宾、泰国等）的进口渠道，可以实现全年供应。都乐作为全球性品牌，有成熟的南半球菠萝采购链（如菲律宾菠萝）；洪九果品则在东南亚（泰国、越南）有深度布局，能补充中国产季空缺。

2. **商业合作基础**：
   - **都乐**：作为大品牌，通常向大型餐饮连锁提供标准化果品，可定制全年供应方案，但可能要求较高的最低起订量（MOQ）或长期合同，适合中大型茶饮品牌。
   - **洪九果品**：专注进口水果，在东南亚产地有控价权，可提供灵活的组合（如旺季用国产菠萝，淡季用泰国/菲律宾产），但需确认其是否有针对茶饮行业的果酱加工级供应链服务（如切块、冷冻或打成半成品果泥）。

3. **实际执行挑战**：
   - **果酱加工特性**：菠萝果酱需要稳定糖酸比和果胶含量，不同产季菠萝风味可能差异大（如冬季菠萝酸度较高），需供应商提供批次之间的质量管控方案（如混合配比或提前冻藏）。
   - **成本与物流**：反季节进口菠萝价格通常比国产季高30%-50%，且需冷链仓储。可根据茶饮店的日均菠萝用量（假设每日50-200公斤）评估是否可承受价格波动。

**结论**：两供应商均具备全年供应能力，但多乐更适体系化大客户（需预判合同门槛），洪九更适合需要灵活产季替换的中小客户。建议：
- 要求供应商提供过去两年的分月度菠萝供应价格和到货稳定性数据；
- 测试不同产季的菠萝样品制作果酱，确认风味是否可接受；
- 若用量弹性小，可考虑与供应商签带价格浮动条款的年度框架合同（如国产季固定价、进口季上浮不超过15%）。
