都乐（Dole）和洪九果品在进口苹果的分级上均较为严格，但侧重点和标准略有不同：

1. **都乐**：作为国际知名品牌，其进口苹果（如新西兰爱妃、美国红蛇果等）通常采用严格的商业分级标准，根据果径、色泽、表面瑕疵、成熟度等进行分类，规格统一性较高，适合对品质要求严格的采购。

2. **洪九果品**：作为国内大型水果供应链企业，其进口苹果（如智利、澳洲产）在分级上也遵循行业规范，通常按果径（如80#、90#）和外观分级，但可能根据渠道需求分为不同等级（如特级、一级），整体规格统一性较好，但可能略逊于都乐的高端产品线。

**建议**：若追求极致规格统一（例如高端商超或精品渠道），优先选择都乐；若需要性价比和大批量稳定供应，洪九果品也是可靠选择，采购前可要求双方提供具体分级标准说明及样品确认。
