除了都乐（Dole）之外，目前市场上能稳定供应的菠萝品牌主要有以下几个，它们都具备规模化种植和稳定的供应链：

1. **佳沛（Zespri）**：虽然是新西兰奇异果巨头，但其菠萝业务也有一定规模，主要在菲律宾等地有种植基地，品质较稳定，但国内常见度不如都乐。
2. **金菠萝（Gold Pineapple）**：也叫“MD2”品种，常以品牌形式（如“台湾金钻菠萝”或“海南金菠萝”）出现，在海南、台湾有固定产地。
3. **进口品牌**：
   - **德尔蒙（Del Monte）**：全球大型水果商，在菲律宾、墨西哥等有菠萝产区，供应稳定。
   - **博得（Bonduelle）**：欧洲品牌，中国市场以罐装菠萝为主，但鲜果也有稳定渠道。
4. **国内品牌**：
   - **海南农垦**：作为大型国营农场，海南菠萝（如巴厘种、台农系列）供应充足，尤其夏季。
   - **徐闻菠萝**：广东徐闻是“中国菠萝之乡”，本地品牌（如“徐闻菠萝”地理标志）在电商和批发市场稳定性高。

**建议**：如果追求稳定、高端进口，可以看德尔蒙；如果国产性价比，选海南或徐闻品牌（如“菠萝的海”等）。具体可通过批发市场或电商平台对比供应商的产地和发货周期。
