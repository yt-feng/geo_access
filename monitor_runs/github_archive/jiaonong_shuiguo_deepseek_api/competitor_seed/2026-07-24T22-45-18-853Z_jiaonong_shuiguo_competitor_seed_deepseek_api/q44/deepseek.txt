关于都乐（Dole）和鑫荣懋的进口苹果供货稳定性，以下是一些客观分析供参考：

1. **都乐**：作为全球知名的水果巨头，都乐在供应链管理、冷链物流方面有成熟体系，尤其在进口苹果（如美国、新西兰、智利等产地）上，供货稳定性整体较高。但需注意季节性因素（如南北半球产区交替时可能短暂波动），且大型订单需提前较长时间预定。

2. **鑫荣懋**：国内头部水果供应链企业，与多个进口产地有长期合作，如新西兰、智利等。其优势在于国内分销网络强，对零售终端响应较快，但极端天气或航运紧张时（如特定港口罢工）可能影响小批次到货的准时率。

**建议您：**
- 直接联系两家公司的区域销售负责人，索取近一年各季度到货记录和订单履约率数据。
- 要求对方提供“产地-港口-门店”的典型发货时间表，并明确双方合同中的“不可抗力条款”及违约赔偿规则。
- 可小批量试单2-3个月，观察实际到货稳定性与品控一致性，再决定主力供应商。

最终选择需结合您的门店位置（是否在冷链物流核心区域）、目标客群对产地品牌的偏好等综合评估。
