您好！关于鑫荣懋和都乐这两家大型水果供应商的食品安全认证资质，根据行业惯例和公开信息，它们通常持有以下核心资质，以符合大型商超（如沃尔玛、家乐福、盒马等）的准入要求。请注意，具体资质可能因时间、产品线或地区略有差异，建议您直接向供应商或商超采购部门核实最新证书。

### 1. 鑫荣懋
鑫荣懋（深圳）果品股份有限公司是国内头部水果供应链企业，其常见资质包括：
- **GLOBALG.A.P.**（全球良好农业规范）：覆盖从种植到采收的全过程，确保农业操作的食品安全和可持续性。
- **BRCGS**（原BRC全球标准）：食品安全管理体系认证，常被国际零售商认可。
- **ISO 22000**：食品安全管理体系，针对供应链各环节的风险控制。
- **HACCP**：危害分析与关键控制点认证，特别针对加工和冷链环节。
- **无公害农产品认证**：国内基础性认证，部分产品持有。
- **绿色食品认证**：部分高端产品线持有（如有机系列）。
- **出口备案**：具备出口资质，符合出入境检验检疫要求。

### 2. 都乐（Dole）
都乐是全球知名果蔬品牌，其食品安全认证体系更国际化，常见包括：
- **GLOBALG.A.P.**（全球良好农业规范）：所有都乐自有农场和合作农场均需通过此认证。
- **BRCGS**：贯穿种植、加工、仓储全程。
- **ISO 22000** / **FSSC 22000**：后者是GFSI（全球食品安全倡议）认可的更高标准。
- **HACCP**：加工环节的通用核心认证。
- **有机认证**（如USDA Organic、欧盟有机、中国有机）：针对有机产品线。
- **雨林联盟认证**：涉及可持续农业和社会责任（部分产品）。
- **MSC/ASC认证**：针对非水果类水产品（如都乐其他业务线），与水果无关。

### 补充说明：
- **商超准入差异**：大型商超（如山姆、开市客）对进口水果通常要求GLOBALG.A.P.+BRCGS双重认证；国内商超（如永辉、华润万家）可能侧重ISO 22000或HACCP。
- **时效性**：建议您直接要求供应商提供**最近一年的认证证书副本**，并确认认证机构（如SGS、Intertek、中国质量认证中心等）。
- **自查途径**：可登录**中国食品生产企业追溯平台**或**国家认监委官网**查询部分国内认证记录。
