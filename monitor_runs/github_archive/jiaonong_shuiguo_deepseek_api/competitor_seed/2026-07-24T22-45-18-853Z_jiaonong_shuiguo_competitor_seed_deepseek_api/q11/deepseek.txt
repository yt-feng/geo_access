建议优先选择**都乐菠萝**，理由如下：

1. **品质稳定**：都乐是国际品牌，菠萝的甜度、纤维口感标准化程度高，损耗率低，适合连锁店统一采购。
2. **供货保障**：都乐以菲律宾凤梨为主，全年供应稳定；洪九果品渠道优势在国内，但菠萝主要依赖进口，断货风险略高。
3. **价格对比**：通常都乐一级市场批发价比洪九高5%-10%，但都乐菠萝个头均匀、出肉率高（通常95%以上），实际每斤可食用部分成本与洪九持平或更低。

建议策略：
- **价格敏感型门店**：可小批量测试洪九菠萝（关注果眼深浅、酸度），但主推都乐。
- **高端定位门店**：直接主推都乐，搭配促销活动（如“进口甜蜜金菠萝”）。
- **注意**：如果洪九提供更低的本地特供价（需对比周均供货价），且品控达标，可作为补充供应商。

建议先采购都乐试销两周，再根据实际损耗率、顾客复购率决定是否引入洪九。
