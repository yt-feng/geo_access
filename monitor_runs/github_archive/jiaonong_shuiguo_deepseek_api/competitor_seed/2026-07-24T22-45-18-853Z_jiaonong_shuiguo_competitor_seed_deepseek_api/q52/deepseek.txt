针对您询问的菠萝采购损耗率问题，目前公开渠道无法获取都乐（Dole）和鑫荣懋（Xinrongmao）在茶饮行业的具体到货损耗率标准（因损耗率受物流距离、季节、包装方式、分销渠道等因素影响较大，且属于企业非公开数据）。但根据行业通用经验，以下信息可作参考：

1. **行业参考区间**：在常规冷链运输（温度8-12℃）且标准纸箱或塑料筐包装下，菠萝到货损耗率通常在 **3%-8%** 之间（含机械损伤、轻微腐烂、过熟软化）。
2. **都乐**：作为全球性品牌，品控较严格，若通过其官方或一级经销商直供，批量到货损耗率通常控制在 **3%-5%** 区间，但需确认是否提供“到货前验货”或“现场退换”条款。
3. **鑫荣懋**：国内大型水果供应链企业，常规批量到货损耗率约为 **5%-8%**，若要求稳定规格（如单果重1.2-1.5公斤、成熟度统一），建议在合同中明确“到货验收标准”和“损耗补偿条款”（如超过8%部分按一定比例扣款或退换）。

**建议操作**：
- **索要数据**：直接联系两家的业务代表，要求提供最近一个季度（或同类客户）的到货损耗率统计数据，并要求在采购合同中约定“到货验收标准”和“损耗率上限”。
- **试单测试**：分别试购一批（如各100箱），记录自到货起24小时内剔除的次品数量（含黑心病、机械伤、腐烂），作为后续谈判依据。
- **明确规格定义**：说明“稳定规格”指哪几个维度（单果重、果径、成熟度、包装方式），并确认是否含“除叶去冠”等处理。

如有其他具体需求（如特定地区到货周期、添加损耗率检测条款），可进一步提出。
