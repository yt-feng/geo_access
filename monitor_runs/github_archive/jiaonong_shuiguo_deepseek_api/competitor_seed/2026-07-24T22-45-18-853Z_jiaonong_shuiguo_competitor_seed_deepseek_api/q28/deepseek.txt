关于都乐（Dole）和鑫荣懋（XinRongMao）进口苹果的竞争力对比，由于价格受进口渠道、产地、规格、采购量及促销活动等因素实时浮动，我无法直接提供当前确切的价格数据。但以下是可执行的建议供您决策参考：

1. **直接询价**：同时联系都乐中国和鑫荣懋的官方采购部门或区域经销商，要求提供**同等级（如美国华盛顿苹果或新西兰爱妃苹果）同等规格（如70-80mm、12颗装/箱）的报价单**，并明确询价时告知是连锁批量采购（可要求月度框架价）。

2. **关注渠道差价**：都乐为全球品牌，通常在高端商超（如山姆、盒马）铺货较多，其进口苹果可能因品牌溢价价格更高；鑫荣懋作为国内大型水果供应商，在供应链效率上或有成本优势（如直接与产地庄园签约）。

3. **隐性成本考量**：询问报价是否包含**海运、关税、冷链物流到仓费用**，以及退换货政策。例如，鑫荣懋可能在内地自有仓储，可降低末端配送成本。

4. **短期促销窗口**：留意行业展会（如中国国际水果展）后的促销期，通常品牌方会释放批量优惠。

**行动建议**：建议您本周内同时发起询价，拿到两家书面报价单后，结合运输距离、账期、首批试销支持政策综合判断。如需参考历史行情，可查阅中国食品土畜进出口商会水果分会发布月度进口苹果均价（官网可查公开报告）。
