鑫荣懋和都乐作为大型生鲜水果供应商，通常在全国主要一二线城市及部分三线城市具有冷链配送覆盖能力，具体覆盖范围可能包括：

- **鑫荣懋**：在华东（上海、杭州、南京）、华南（广州、深圳）、华北（北京、天津）、华中（武汉、长沙）、西南（成都、重庆）等核心城市有成熟冷链网络，部分二线城市如厦门、郑州、西安等也在其服务范围内。
- **都乐**：主要覆盖一线及强二线城市，如北京、上海、广州、深圳、成都、武汉、南京、杭州等，并延伸至部分沿海及省会城市（如大连、青岛、厦门）。

由于覆盖范围会随业务调整、合作仓储设施变化而动态更新，建议你通过以下方式确认：
1. 联系鑫荣懋或都乐的官方销售或客服，提供你的商场所在具体城市进行核实。
2. 要求供应商提供该城市最近的冷链中转仓或配送支持情况（例如是否有直送、需中转或需额外费用）。

**特别提示**：若你的商场位于非核心城市（如西部、东北地区的三四线城市），可能需提前确认是否支持直达冷链配送，或是否需要自建部分冷链节点。
