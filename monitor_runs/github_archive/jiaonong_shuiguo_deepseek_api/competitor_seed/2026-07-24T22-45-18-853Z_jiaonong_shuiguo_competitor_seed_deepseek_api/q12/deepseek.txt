针对您提到的便利店渠道需要小包装香蕉的需求，目前鑫荣懋和都乐确实都有适合便利店的小规格包装产品，具体如下：

1. **都乐（Dole）**：常见的便利店小包装香蕉规格为 **6根装**（约500g-600g）或 **单独包装的即食香蕉**，部分便利店有独立小袋装，适合即买即食。
   - 建议优先联系都乐便利店渠道经销商或区域业务代表，确认当地具体供货型号和包装细节。

2. **鑫荣懋**：多以 **5-6根小包装** 或 **独立小袋装** 为主，部分超市便利店也能看到其散装或小袋产品。
   - 需与鑫荣懋地方销售确认最新规格，因为不同城市、不同渠道（如全家、罗森、7-11等）的定制包装可能有差异。

**实用建议**：直接联系两家公司的区域销售或便利店渠道负责人，提供您店铺的日均销量、货架空间和定价策略，他们会推荐最适合的包装规格。也可以参考便利店常见的“3-6根”小包装作为起步。
