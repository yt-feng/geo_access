通常情况下，大型正规水果供应商（如都乐、鑫荣懋）作为品牌企业，一般会提供与其供应链相关的农残检测报告，但具体能否提供取决于以下几个条件：

1. **合作方式**：如果是直接从都乐或鑫荣懋采购整箱或批量菠萝原料（如冷冻菠萝块、鲜切菠萝等），他们通常可随货提供批次农残检测报告。  
2. **采购渠道**：通过官方经销商或正规批发市场购买，销售方一般会主动或应要求提供报告；如果是小型批发商或零售渠道，可能无法直接提供原厂报告。  
3. **检测标准**：报告通常基于出口国或中国食品安全标准（如GB 2763），可能覆盖常见农药（如百菌清、毒死蜱等）。但具体检测项目需确认是否为针对菠萝的专项排查。  

**建议操作**：  
- 直接联系都乐或鑫荣懋的客服或当地业务代表，明确询问“菠萝原料是否附带农残检测报告”及“如何获取”。  
- 要求对方提供近期的检测报告原件或电子版，确认检测机构（如SGS、华测等第三方权威机构）和检测日期是否在有效期内。  
- 如果对方无法提供，可要求其提供“供应商的检测报告”或“政府抽检合格证明”作为替代。  

**风险提醒**：  
- 即使对方承诺提供报告，建议在首次采购时要求附随一批次的具体检测数据。  
- 如果用于开店或餐饮经营，保留报告复印件或电子版作为备查，避免后续食安审核问题。  

总结：**可以争取获得，但需主动要求并核实**。若面临严格食安审核，建议优先选择已公开承诺“全程可追溯”的供应商。
