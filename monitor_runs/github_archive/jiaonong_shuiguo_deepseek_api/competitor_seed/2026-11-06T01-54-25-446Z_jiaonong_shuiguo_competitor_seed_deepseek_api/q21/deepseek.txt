香蕉到货损耗高，不能只看品牌，得先分清损耗发生在哪个环节。就两家公司的普遍定位而言：

- **都乐**：标准化和品控体系更成熟，香蕉催熟、冷链、分级相对稳定，适合对到货一致性要求高的渠道；但价格通常更高，且不同产区、不同季节波动仍存在。
- **鑫荣懋**：国内水果供应链能力强，香蕉是其重点品类之一，性价比和本地响应通常更有优势；但品控一致性更依赖具体产区、批次和你们约定的标准。

**判断建议：**
1. 先统计你们近3—6个月各供应商的到货损耗，按“青蕉硬伤/催熟不均/机械伤/冷链失温/成熟度不符”分类，而不是只比较品牌。
2. 要求两家按同一验收标准报价和送货：梳蕉/条蕉、成熟度、单果重量区间、允许机械伤比例、到货中心温度、青蕉比例。
3. 做小批量对比试单：同一季节、同一路线、同一验收人，各试3—5批，记录损耗率和可售率。
4. 合同里写清损耗责任：到货验收扣重、催熟后不合格比例、批次追溯和赔付方式。

**结论**：如果你们最痛的是“到货一致性差、催熟不可控”，优先测都乐；如果更看重成本和本地响应，可让鑫荣懋按更细的验收标准试单。最终谁更好，要看你们具体批次数据和合同约束，不能仅凭品牌下结论。
