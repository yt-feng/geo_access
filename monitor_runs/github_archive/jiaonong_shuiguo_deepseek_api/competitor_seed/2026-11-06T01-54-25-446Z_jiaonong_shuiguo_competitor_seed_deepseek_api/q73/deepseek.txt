大型商超通常要求供应商具备可核查的食品安全管理体系认证。就鑫荣懋和都乐而言，**我无法在可核验范围内确认它们各自“通过哪些认证”的完整清单**，因此不宜列出具体证书名称或编号，以免误导。

可执行的判断建议：

1. **鑫荣懋（水果供应链企业）**：可重点核对其是否持有 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点**、**FSSC 22000** 或 **BRCGS** 等国际通行认证；具体以企业官网、审核报告或证书查询平台为准。
2. **都乐（Dole）**：作为跨国果蔬企业，通常会在其全球或中国区质量安全体系中涉及 **GFSI 认可方案**（如 BRCGS、FSSC 22000）及 **ISO 22000/HACCP** 等；但具体到中国区主体、品类和工厂，需逐项核验证书。
3. **商超准入实操**：不要仅凭品牌知名度判断，应要求供应商提供**证书扫描件、认证范围、有效期、发证机构及查询方式**，并确认认证范围覆盖拟供品类和加工场所。

如需准确名单，建议直接向两家企业的质量管理部门索取最新认证证书，或在认证机构公开查询系统中按企业主体名称核验。
