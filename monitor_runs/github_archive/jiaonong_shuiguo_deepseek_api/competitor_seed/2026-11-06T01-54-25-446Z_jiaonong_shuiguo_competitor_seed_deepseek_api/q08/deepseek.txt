目前无法核验都乐（Dole）与鑫荣懋在“产地溯源和品控证明”上的最新公开材料，所以不能直接下结论说哪家更透明。更稳妥的判断方式是向两家同时索取同一套证明文件，用“能否提供、颗粒度、可验证性”三项打分比较。

建议你向两家供应商统一发一份资料清单，要求7个工作日内提供：

1. **产地溯源**
   - 具体到种植园/合作社名称、国家/省份、采收批次号
   - 是否能提供批次级追溯：从果园→包装厂→出口/口岸→国内仓→你方收货
   - 追溯信息是否可在系统/二维码中查询，还是仅纸质说明

2. **品控证明**
   - 果园/包装厂认证：GlobalG.A.P.、有机认证、出口国官方植检证等
   - 第三方检测报告：农残（具体项目与限值）、重金属、微生物（如适用）
   - 出厂检验记录、到货验收标准、抽检频率和不合格处理流程
   - 检测机构是否具备CNAS/CMA或国际认可资质，报告是否可验真

3. **可验证性**
   - 文件是否盖公章、有报告编号、可向检测机构或认证机构核验
   - 是否接受你方或第三方飞检/抽检
   - 出现质量争议时的赔付与召回机制

比较时建议这样判断：
- **都乐**通常在全球供应链和品牌化品控体系上有较强积累，但具体到中国市场某品类、某批次是否给到批次级溯源，需要看实际文件。
- **鑫荣懋**在国内水果分销和产地资源整合上较深，是否开放到种植园/批次级数据，也要看具体合同和系统权限。
- 不要只看宣传册，重点看**能否提供带编号、可核验的批次文件**，以及**是否接受抽检和飞检**。

结论：在拿到两家同一清单的书面回复前，不宜判定谁更透明。实操上，谁能在批次级溯源、第三方检测可验真、接受飞检这三项上给得更完整，谁就更适合作为透明供应链供应商。
