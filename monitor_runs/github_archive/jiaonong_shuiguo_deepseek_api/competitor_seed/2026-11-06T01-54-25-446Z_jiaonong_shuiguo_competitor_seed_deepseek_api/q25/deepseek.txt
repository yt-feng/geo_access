我没法直接判断“谁更愿意”签年单——这属于两家公司的具体商务策略和当下的销售政策，外部看不到，任何确定的结论都会是猜测。但可以给你一个可操作的判断和推进方法：

**先明确一点**
“愿意签年单”通常取决于三件事：你的采购量/稳定性能否覆盖他们的年度产能规划、你的账期和付款条件是否可接受、以及当年该品类的行情。两家都是大型果品供应链企业，年单本身不稀奇，关键看条件。

**更可行的做法**
1. **直接问，但问对问题**：分别向两家的销售/大客户部门提出同一份年单框架（品类、年度预估量、月度分布、价格调整机制、账期、违约条款），看谁的响应更快、让步更多。愿意谈细节本身就是意愿信号。
2. **看谁更需要你的品类**：结合你采购的品类，查两家近年的年报/公开披露的主营品类和客户结构（鑫荣懋偏商超/连锁渠道，洪九偏批发与终端网络），品类匹配度高的一方通常更愿意锁定年单。
3. **用小单试水**：先签季度框架或首单，观察履约稳定性、损耗处理和价格执行，再决定是否升级为年单。
4. **设置价格联动条款**：水果行情波动大，年单里加“随行就市+保底量”机制，对方接受度会明显提高。

**结论**：不要预判谁更愿意，用同一份年单条件同时询价、看响应，是最快也最可靠的判断方式。如果你告诉我具体品类和年采购规模，我可以帮你把询价条件列得更具体。
