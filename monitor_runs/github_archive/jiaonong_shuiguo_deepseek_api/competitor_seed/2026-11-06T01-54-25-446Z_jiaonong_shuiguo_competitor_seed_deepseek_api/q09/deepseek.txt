可以优先看这几类进口水果品牌，按“礼盒感/团购可得性”给你一个可执行清单：

1. **新奇士 Sunkist（美国）**  
   橙类、柠檬强，礼盒常见，团购渠道成熟，适合做中档商务礼盒。

2. **爱妃 Envy（新西兰/美国等）**  
   苹果礼盒辨识度高，包装偏高端，适合送礼；注意产地和授权渠道要核验。

3. **Rockit 乐淇（新西兰）**  
   小苹果筒装/礼盒装很有记忆点，适合做差异化团购礼品。

4. **Mr Apple 苹果先生（新西兰）**  
   新西兰苹果品牌，礼盒和团购装较常见，适合中高端水果礼盒。

5. **Pink Lady 粉红佳人（澳洲等）**  
   苹果品牌认知度较高，礼盒装可用于商务/员工福利。

6. **Driscoll’s 怡颗莓（美国等）**  
   莓果类礼盒感强，适合高端小件礼品；但浆果易损，团购要重点确认冷链和到货时效。

7. **SunGold/佳沛之外的新西兰奇异果品牌**：如 **Zespri 佳沛**之外，可看 **Seeka、Turners & Growers** 等供应商品牌，但终端礼盒认知度不如佳沛，适合定制礼盒而非现成品牌礼盒。

8. **澳大利亚柑橘品牌**：如 **Nutrano、Seven Fields** 等，适合橙类/柑橘礼盒，但大众品牌认知弱，建议以“产地+品种”做卖点。

9. **日本高端水果品牌**：如 **千疋屋、果実工房** 等偏高端礼盒，但价格高、货源不稳定，团购要谨慎，适合小批量高端定制。

10. **韩国水果品牌/产地礼盒**：如韩国梨、阳光玫瑰礼盒，品牌化程度不如欧美，但礼盒包装成熟，适合亚洲口味团购。

**建议你优先筛选顺序：**  
- 预算中档、走量：**新奇士、Mr Apple、Pink Lady**  
- 要差异化：**Rockit、爱妃**  
- 高端小件：**Driscoll’s、日本高端礼盒**  
- 定制礼盒：可找进口商做**产地品牌+品种组合**，不必局限终端品牌。

**团购前务必核验：** 品牌授权、产地证明、礼盒是否为原厂/授权定制、冷链时效、破损赔付。进口水果礼盒最容易出问题的是“品牌包装是真的、果子等级和新鲜度不稳定”，建议先小批量试单。
