都乐（Dole）和洪九果品（洪九果品股份有限公司）具体种植基地位置，我无法在当前对话中核验到可靠来源，不能给你确切地址，建议直接向供应商索取“基地清单+产地证明/海关或检验检疫备案信息”来确认。

不过从茶饮原料采购的“稳定供应”角度，你可以这样判断和推进：

1. **先确认你要的是鲜果还是冷冻/果浆/罐头**
   - 茶饮店用菠萝多为冷冻果肉、果浆、罐头或鲜切。鲜果受季节和产地切换影响大；冷冻/果浆更适合稳定供应。
   - 若用鲜果，要求供应商给出全年产地切换表（如广东/海南/广西/云南/菲律宾/泰国等），并说明切换期品质波动。

2. **向都乐/洪九分别索取这些文件**
   - 营业执照、食品经营/生产许可（视原料形态）
   - 产品规格书（糖度、酸度、纤维、色泽、农残标准）
   - 产地证明或基地备案信息
   - 第三方检测报告（农残、重金属、微生物）
   - 近12个月批次检测记录和供货稳定性说明
   - 冷链/仓储能力说明（鲜果或冷冻）

3. **做双供应商+安全库存**
   - 主供都乐或洪九之一，副供选一家区域性果品供应链或冷冻果浆厂。
   - 鲜果建议保留7–15天安全库存；冷冻果浆按30–45天备货。
   - 合同中约定：产地切换提前通知、规格偏差处理、断供赔付、替代批次审批。

4. **到货验收指标**
   - 鲜果：糖度、酸度、成熟度、机械伤、霉变率、单果重区间。
   - 冷冻/果浆：可溶性固形物、pH、色泽、解冻失水率、微生物。
   - 每批留样，建立批次追溯。
