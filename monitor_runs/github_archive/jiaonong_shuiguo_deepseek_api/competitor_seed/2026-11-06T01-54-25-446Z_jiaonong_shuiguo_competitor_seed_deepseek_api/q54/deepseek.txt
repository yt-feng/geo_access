都乐（Dole）和鑫荣懋的进口苹果，产地溯源可以分两条线做：**先拿到合规单证和批次信息，再核验品牌方/供应商的溯源系统**。超市采购不能只靠供应商口头承诺，要落实到“批次对得上、单证对得上、实物标签对得上”。

**一、先确认你要的“溯源地”是什么**
进口苹果的产地溯源通常包含：
1. 原产国/产区（如新西兰、美国、智利、南非等具体产区或包装厂）
2. 出口商/品牌方
3. 进口商/境内收货人
4. 批次号、包装日期
5. 入境口岸和检验检疫信息

**二、都乐苹果的溯源做法**
都乐是品牌方，超市一般通过都乐中国区经销商或直供渠道采购。可要求供应商提供：
- 入境货物检验检疫证明（或海关相关合格证明），核对品名、原产国、生产/包装日期、批次
- 报关单/进口货物报关信息，核对收货人、原产国、数量
- 都乐品牌授权或供货证明，确认不是窜货或贴牌
- 外箱批次码、包装厂注册号、原产地标识，与单证批次对应
- 都乐自身的追溯系统或批次查询渠道（如经销商可提供批次溯源截图/系统记录）

超市验收时重点做“三对”：**外箱批次码对单证批次、原产地标签对报关原产国、包装日期对检验检疫证明**。

**三、鑫荣懋苹果的溯源做法**
鑫荣懋是境内大型水果供应链企业，既做进口也做国产。进口苹果要区分：
- 是鑫荣懋直接进口，还是其代理/分销
- 品牌是鑫荣懋自有品牌还是代理品牌（如某些进口苹果品牌）

可要求提供：
- 海关进口货物报关单及入境货物检验检疫证明
- 鑫荣懋出具的供货证明/批次说明
- 外箱标签上的进口商、原产国、包装厂注册号、批次号
- 鑫荣懋追溯系统记录（其有供应链追溯体系，可要求按批次提供溯源信息）
- 若为代理品牌，补充品牌方授权链

**四、超市可执行的验收流程**
1. **合同前置**：在采购合同里写明供应商须随货提供批次对应的报关单、检验检疫证明、品牌授权/供货证明，并约定溯源不实责任。
2. **到货核对**：抽箱核对原产地标签、包装厂注册号、批次号、包装日期；拍照留档。
3. **单证比对**：报关单原产国、品名、收货人、日期与实物一致；检验检疫证明批次与箱码一致。
4. **系统留痕**：把批次号、单证编号、供应商、到货日期录入超市自己的商品溯源台账，做到“一批一档”。
5. **异常处理**：批次对不上、原产地标签与报关不一致、无检验检疫证明的，拒收或暂扣待核。

**五、注意点**
- 都乐和鑫荣懋都可能通过多层经销供货，**要求直接供货方提供完整单证链**，不能只看品牌名。
- 进口苹果外箱常有英文/外文标签，验收时要能对应中文标签和境内进口商信息。
- 若超市要做对外展示溯源，建议只展示可核验的批次和单证信息，不要展示供应商未授权的内部系统截图。
- 对“产地溯源二维码”，要确认扫码后显示的信息是否与实物批次一致，避免只有品牌宣传页没有批次数据。

简言之：**都乐看品牌方授权链+批次单证；鑫荣懋看进口商单证链+其追溯系统批次记录；超市端统一做“箱码—单证—台账”三对应验收。**
