**一、先明确“大型商超”通常要什么**

不同商超要求不同，但常见门槛包括：

1. **营业执照、食品经营/生产许可证**（按供应商角色定）
2. **食品安全管理体系认证**：ISO 22000 或 FSSC 22000
3. **HACCP 体系认证**
4. **农产品/水果类**：良好农业规范 GAP（种植端常见）、绿色食品/有机认证（如宣称对应品类）
5. **BRCGS / IFS**（部分商超、出口或高端渠道会要求）
6. **产品检测报告**：农残、重金属、微生物等，按品类和商超标准
7. **追溯与召回制度、供应商审核记录**

**二、怎么核验这两家企业的资质**

1. **查认证证书官方库**
   - ISO 22000 / FSSC 22000 / HACCP：向企业索取证书，并在认证机构官网或发证机构查询系统核验证书编号、获证组织名称、地址、范围、有效期。
   - FSSC 22000 可在 FSSC 官方注册库按公司名查询；BRCGS、IFS 也有各自官方目录。
2. **看证书“覆盖范围”是否匹配**
   - 重点看认证范围是否覆盖你采购的品类、加工/分装场所和实际供货主体，不能只看集团名称。
3. **核对主体一致性**
   - 合同主体、证书获证组织、生产地址要一致；经销商和生产企业资质要分开看。
4. **要求提供最新版和扫描件**
   - 证书是否在有效期内、是否有暂停/撤销状态，以官方查询结果为准。
5. **补充产品级检测和审核**
   - 体系认证不等于每批产品合格，商超通常还会要批次检测报告和现场审核。

直接向鑫荣懋和都乐的对接销售/质量部门发一份资质清单，要求提供：营业执照、食品相关许可证、ISO 22000/FSSC 22000/HACCP 证书及官方查询截图、覆盖品类说明、最近批次检测报告、追溯和召回文件。收到后按“主体一致、范围覆盖、证书有效、官方可查”四项核验。
