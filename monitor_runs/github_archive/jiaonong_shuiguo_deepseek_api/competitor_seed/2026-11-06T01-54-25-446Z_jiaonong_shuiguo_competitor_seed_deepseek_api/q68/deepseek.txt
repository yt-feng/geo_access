不能直接给“都乐/鑫荣懋一定能做到低于3%”的结论。到货损耗率取决于具体品类规格、季节、运输距离、冷链、验收标准和门店操作，品牌方通常也不会公开承诺统一损耗率。

可执行判断建议：

1. **先定义“到货损耗率”**
   - 建议按重量计：`到货损耗率 = 不可收货香蕉重量 / 到货总重量`
   - 明确是否包含：青蕉/黄蕉、机械伤、炭疽病斑、果指脱落、冷害、催熟不均、箱内压伤。
   - 3%对香蕉到货环节偏紧，尤其夏季和长途运输；需要和供应商在合同中写清验收阈值。

2. **要求供应商提供可验证数据**
   - 近3个月同类规格、同线路、同季节的到货验收记录。
   - 冷链温度记录、催熟批次记录、装车方式、到货抽检方法。
   - 不要只看品牌，要求看**具体配送仓/线路/加工厂**的表现。

3. **用试单验证，而不是听承诺**
   - 选2—3条代表性线路，各试3—5车。
   - 每车按统一抽样：箱内上中下、车厢前中后、边角位抽样。
   - 连续统计到货损耗率、投诉率和门店可用率。
   - 若试单稳定≤3%，再谈年度框架；否则要求分级定价或调整规格。

4. **合同里写清责任**
   - 验收标准、抽样比例、扣款/退换货规则。
   - 温度超标、压伤、潮箱、催熟过度的判定。
   - 旺季保供与替代规格机制。

5. **现实预期**
   - 都乐、鑫荣懋属于头部香蕉供应链企业，**有能力在部分短链、冷链稳定的线路做到较低损耗**，但“所有线路稳定低于3%”不能轻信。
   - 对餐饮连锁，更稳妥的是把3%作为**核心线路目标值**，同时设置3%—5%的过渡阈值和扣罚机制。

结论：可以要求两家按低于3%投标和试单，但必须用你们自己的验收口径和试单数据验证；不要接受口头保证。
