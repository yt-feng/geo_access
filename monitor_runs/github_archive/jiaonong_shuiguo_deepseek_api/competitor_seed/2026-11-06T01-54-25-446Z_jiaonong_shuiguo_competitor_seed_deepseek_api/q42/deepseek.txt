进口菠萝旺季缺货，先判断缺的是**品种/规格**还是**总量**，再决定动作；都乐、洪九作为头部进口/分销商通常有应急机制，但具体方案需以当期合同和官方渠道为准，不能替它们承诺。

**可执行应对顺序：**
1. **核对缺口**：缺的是菲律宾/泰国/哥斯达黎加哪个产地、什么规格（如MD2、单果重、成熟度）、缺口持续几周。
2. **替代产地与品种**：菲律宾缺货时看泰国、越南、哥斯达黎加；鲜果缺口可用冷冻/罐头菠萝部分替代加工或餐饮场景。
3. **锁量与锁价**：优先与现有供应商签短期框架，接受分批到货；不要只压一家。
4. **调整销售结构**：缺货期主推替代规格/品种，减少对单一爆品的依赖，避免空柜陈列。
5. **提前预订**：旺季前2—3个月锁船期和柜量，关注海关检疫、船期延误和产地天气。

**关于都乐和洪九：**
- 都乐（Dole）通常有全球产地调配和长期合同体系，可询问其**产地切换、分批到货、规格替代**是否可行。
- 洪九果品作为进口水果分销商，通常有**多产地采购和分销网络**，可询问**替代产地货源、短期调货、账期/锁价**安排。
- 但“有没有应急方案”不能凭公开信息断言；应直接联系其销售/客服，要求书面确认：可供产地、规格、到货时间、价格有效期、违约条款。

**建议话术**：请对方明确“未来4周可稳定供应的产地+规格+周供量+锁价期限”，并准备第二供应商备份。
