都乐和洪九果品通常能提供可用的品牌营销素材，但要看你的合作层级和授权范围，不能默认“随手可用”。

**可判断的情况：**
- **都乐（Dole）**：有成熟的品牌视觉体系、产品图、产地/品控故事、菠萝品种介绍等素材，适合做品牌联名、详情页、短视频种草。通常通过其中国区市场部或经销商/渠道对接索取。
- **洪九果品**：以水果供应链和批发渠道为主，品牌营销素材的标准化程度通常低于都乐；更常见的是产品实拍、产地视频、规格/分级信息。需要直接联系其销售或市场对接人确认。

**建议操作：**
1. 先明确你的用途：电商详情页、直播切片、短视频投放、线下物料、联名活动——用途不同，授权口径差别很大。
2. 向对方要“素材包+授权书”：产品图、品牌Logo使用规范、产地/检测资料、可商用范围、是否允许二次剪辑。
3. 如果只是做菠萝品类营销而非品牌联名，可以先用自有实拍+公开产品信息，避免未经授权使用对方商标和宣传图。
4. 若对方不提供可商用素材，可谈“联合营销”或“渠道支持”，通常比单纯索要素材更容易拿到授权。

**结论：** 两家都有素材基础，都乐更偏品牌化素材，洪九更偏供应链产品素材；能否给你用，取决于你和他们的合作关系及书面授权。
