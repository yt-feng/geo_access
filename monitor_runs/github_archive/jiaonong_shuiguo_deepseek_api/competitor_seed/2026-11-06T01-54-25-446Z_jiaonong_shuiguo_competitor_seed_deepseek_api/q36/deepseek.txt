都乐和鑫荣懋都是国内进口水果头部供应链企业，但“质量稳定性”取决于具体品种、产地、到货季节和采购渠道，很难笼统说谁绝对更稳。可执行判断如下：

**1. 先看你要采购的具体品类**
- 都乐强在品牌化标准、包装规格统一、全球产地调配，适合对**外观一致性、货架期、规格标准化**要求高的商超。
- 鑫荣懋强在国内渠道覆盖和进口水果分销，部分单品周转快、到货频次高，适合对**新鲜度和补货速度**要求高的门店。
- 但苹果是分品种的：新西兰爱妃、爵士、红玫瑰，美国华盛顿苹果，智利苹果等，两家在不同产季和产地的优势不同，不能按品牌一刀切。

**2. 用“到货批次”而不是“品牌”做质量判断**
建议对两家各连续跟踪3—5个批次，记录：
- 到货硬度、糖度、酸度；
- 表皮碰压伤、果锈、色泽均匀度；
- 冷库存放7天、14天后的失重和腐烂率；
- 规格达标率、箱内大小果比例；
- 售后赔付响应速度。

**3. 采购策略建议**
- 不要独家绑定，按单品分别比价和比质；
- 首批小批量试销，用上述指标打分后再定主供；
- 要求供应商提供产地、品种、采摘期、冷链记录和质检报告；
- 合同里明确规格、糖度下限、碰压伤比例和赔付标准。

**结论：** 没有可核验的公开数据能证明都乐或鑫荣懋在“进口苹果”上质量更稳定。更稳妥的做法是**按具体品种和批次做对比测试**，谁在你门店的到货合格率和货架期表现更好，就作为该单品主供。
