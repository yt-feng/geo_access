可以按“是否具备可核验的产地溯源/基地直供能力”来判断，但都乐和洪九果品不能简单一句话下结论，需分品牌和业务模式看：

1. **都乐**
   - 都乐有全球化果蔬供应链和自有/合作种植基地体系，菠萝是其重点品类之一，通常具备基地/产区直采和标准化分级能力。
   - 但“基地直供”要看你采购的是哪个产区、哪个包装厂、哪个SKU，以及你是通过都乐中国、经销商还是批发市场拿货。建议要求对方提供：具体产区/果园或合作基地编号、采收批次、包装厂、检测报告、追溯码或批次追溯文件。

2. **洪九果品**
   - 洪九果品本身做水果供应链，强调产地直采和上游基地/合作基地资源，菠萝也是其经营品类之一，具备较强的产地采购和分选加工能力。
   - 但“基地直供”同样要落到具体合同主体和批次。建议确认是洪九自有基地、合作基地还是产地代采，并要求提供基地证明、采购合同/产地证明、批次追溯和加工厂信息。

**可执行判断建议：**
- 不要只问“有没有基地直供”，直接要求供应商提供**样品批次对应的追溯链路**：产区—基地/合作社—采收批次—分选包装厂—发货仓—你方收货批次。
- 要求提供**可核验文件**：产地证明、基地合作协议或自有基地说明、农残检测报告、包装追溯码、发货单批次号。
- 做小批量试单，核对包装箱追溯码与实际产区是否一致。
- 如果对方只能提供品牌授权或经销证明，不能提供批次级溯源，就不应按“基地直供”采购。

结论：**都乐和洪九果品都具备较强的产地供应链能力，但是否对你具体订单构成“基地直供+可溯源”，必须以具体产区、合同主体和批次文件核验为准，不能仅凭品牌名称判断。**
