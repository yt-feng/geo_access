结论先说：**都乐（Dole）和洪九果品是否公开了“企业标准”，现有公开渠道无法可靠核验，不能直接说“有”或“没有”。**  
更稳妥的判断是：**都乐大概率有较成熟的企业内控分级体系，洪九大概率也有面向B端和门店的分级要求，但这些通常不是对外公开备案的企业标准文本。**

下面把可判断的部分和不可判断的部分分开说。

## 1. 都乐的情况
都乐是全球性果蔬品牌，香蕉是其核心品类之一。  
从行业常识看，都乐这类跨国水果公司通常会有：

- 内部质量规格书
- 产品验收标准
- 分级/等级判定规则
- 包装、储运、成熟度控制标准

但这些多数属于：

- 企业内部标准
- 客户合同附件
- 供应链验收文件
- 不公开或半公开的技术资料

**能否称为“企业标准”？**  
如果按中国《标准化法》语境，企业标准通常指企业自行制定并可能在企业标准信息公共服务平台声明公开的标准。  
都乐中国是否针对香蕉专门公开声明了企业标准，**公开渠道无法确认**。  
所以更准确说法是：**都乐大概率有企业内部香蕉分级规范，但未必公开为可查询的企业标准。**

## 2. 洪九果品的情况
洪九果品是国内大型水果供应链企业，香蕉也是重要品类。  
这类企业通常会有：

- 采购分级标准
- 到货验收标准
- 仓储分选标准
- 面向商超、门店、批发客户的等级要求

但洪九作为供应链和渠道型企业，其标准更多体现为：

- 内部作业文件
- 客户交付规格
- 分选包装要求
- 合同质量条款

同样，**洪九是否公开了香蕉企业标准，公开渠道无法可靠核验。**

## 3. 对你做水果连锁店更实用的建议
你不需要纠结“都乐、洪九有没有公开企业标准”，而应建立自己的**门店可执行香蕉分级标准**。可以参考下面框架：

### 按用途分级
| 等级 | 适用场景 | 核心要求 |
|---|---|---|
| A级/精品 | 高端门店、礼盒、线上精选 | 果形端正、无斑点、长度均匀、成熟度一致 |
| B级/标准 | 常规门店销售 | 轻微外观瑕疵可接受、口感正常、成熟度较一致 |
| C级/促销 | 特价、果切、烘焙 | 外观要求低，但无腐烂、无严重压伤 |
| 加工级 | 果切、奶昔、甜品 | 成熟度高、可立即加工，不允许腐烂 |

### 按关键指标分级
建议门店验收至少看这几项：

1. **成熟度**：青、微黄、黄、黄带糖斑、过熟  
2. **果指长度**：如 16cm 以下、16–18cm、18–20cm、20cm 以上  
3. **果指粗细/饱满度**：饱满、一般、瘦小  
4. **果形**：端正、弯曲异常、畸形  
5. **表皮**：洁净、轻微擦伤、明显黑斑、腐烂  
6. **机械伤**：无、轻微、明显压伤/裂口  
7. **整齐度**：同批次颜色、大小、成熟度是否一致  
8. **到货温度与硬度**：判断是否冷害、催熟过度或未熟  

### 门店可执行简版标准
- **精品级**：长度一致、果形好、无黑斑、无压伤、成熟度一致，可即售或1–2天转黄。
- **标准级**：长度基本一致、轻微表皮瑕疵、无腐烂，适合正常货架。
- **促销级**：大小不匀、表皮瑕疵较多，但果肉正常，适合特价。
- **加工级**：成熟度高或有外观缺陷，但无腐败，适合果切。
- **拒收级**：腐烂、严重压伤、裂口、冷害、异味、发酸。
