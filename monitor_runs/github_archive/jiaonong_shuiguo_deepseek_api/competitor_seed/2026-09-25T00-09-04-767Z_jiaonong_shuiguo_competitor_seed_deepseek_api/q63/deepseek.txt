都乐和洪九果品都主要是做**整箱/件装**的香蕉批发和渠道供货，面向社区团购的**小包装散装选项通常不是标准公开产品**，需要分情况看：

**都乐**
- 都乐香蕉在国内渠道以**整箱（如4.5kg、12kg等规格）**为主，部分区域有**单根/小把预包装**，但多出现在商超、便利店渠道，不是给社区团购的常规散装供货。
- 社区团购若要做小包装，通常是**团购方自己从整箱分装**，而不是都乐直接提供散装。

**洪九果品**
- 洪九果品主要做**进口香蕉、国产香蕉的产地/一级批发**，供货形态以**整件、整柜、整箱**为主。
- 洪九一般也不直接提供面向消费者的“散装小包装”，社区团购渠道更多是采购整箱后自行分装或找其区域经销商拿小规格件装。

**实际可操作的建议**
1. **直接问区域经销商**：都乐和洪九在不同城市有不同经销商，有的经销商可提供**小规格件装**（如2.5kg、3kg），但这不等于散装。
2. **如果一定要小包装**：建议按“整箱采购 + 自行分装”来做，成本更可控，也更适合社区团购的按份销售。
3. **找替代供应链**：如果目标是香蕉小包装，可以同时问**本地水果批发市场、区域香蕉分装厂、生鲜B2B平台**，他们往往能提供2-3根/袋、500g-1kg/份的预包装。
4. **注意损耗**：香蕉分装后成熟快、易压伤，社区团购做小包装要控制分装时间和配送时效，否则损耗会明显高于整箱出货。

简单说：**都乐和洪九果品没有面向社区团购的标准“散装”选项，主要走整箱/件装；小包装通常要自己分装，或找能提供小规格预包装的经销商/分装厂。**
