# 都乐（Dole）与鑫荣懋 进口苹果产地溯源操作指南

进口苹果的"产地溯源"分两个层面：**① 供应商资质与单证核验**（证明合法进口、真实产地）；**② 果品本身的可追溯信息**（箱码、标签、批次，能追到果园/包装厂）。超市采购按下面做即可落地。

---

## 一、都乐（Dole）

都乐是品牌方+进口商，溯源体系相对标准化，主要抓手是**箱标 + 标签码 + 单证**。

1. **看包装箱（Carton）**
   - 箱体印有：品牌、品种、规格（如 count/size）、**原产国**、**包装厂代号（Packer Code / Packhouse No.）**、**批次号（Lot No.）**。
   - 这些都是溯源关键字段，采购时要**拍照留存并录入系统**。

2. **看果贴标签（PLU / 品牌贴）**
   - 都乐苹果贴通常含：品牌 logo、**PLU 码**（如 4131=红富士、4020=富士等，PLS 码代表品种和规格）、部分带**二维码/追溯码**，可扫到产地或批次信息。
   - 注意：PLU 只标品种规格，**不等于产地**，产地仍以箱标和单证为准。

3. **索要单证（核心）**
   - **原产地证书（Certificate of Origin）**
   - **出口国植物检疫证书 / 植检证（Phytosanitary Certificate）**
   - **入境货物检验检疫证明**（国内海关出具，证明合法入境）
   - **报关单 / 入境货物报关单**
   - **提单（B/L）或空运单**
   - **供应商/进口商的食品经营许可证、进货凭证**

4. **对接方式**
   - 都乐在国内有正规进口主体和经销体系，直接向**都乐中国授权经销商/进口商**索取上述单证，并确认其授权书。
   - 要箱标与单证上的**原产国、批次能对应**，否则存疑。

---

## 二、鑫荣懋（Golden Wing Mau）

鑫荣懋本身是**国内大型水果进口商/分销商**，很多进口苹果是它代理进口再分销，溯源更依赖**它的进口单证 + 自有追溯系统**。

1. **要进口主体信息**
   - 确认这批货是鑫荣懋**自营进口**还是**分销转手**。自营进口单证齐全；转手要追溯到上一手进口商。

2. **索要全套单证**（同上）
   - 原产地证、植检证、入境货物检验检疫证明、报关单、提单。
   - 鑫荣懋通常有**批次管理**，可要求提供该批次的对应单据。

3. **用它的追溯码/系统**
   - 鑫荣懋有自有供应链追溯体系，部分产品箱标或标签带**追溯二维码**，扫码可查产地、批次、进口信息。
   - 采购时明确要求：**按箱码/批次提供可核验的追溯信息**，并写入采购合同。

4. **核对箱标**
   - 原产国、包装厂、品种、规格、批次号，与单证一致。

---

## 三、超市采购的通用操作清单（都乐/鑫荣懋通用）

| 环节 | 动作 | 判断标准 |
|---|---|---|
| 供应商准入 | 查营业执照、食品经营许可证、进口商授权 | 证照在有效期、渠道正规 |
| 单证核验 | 收原产地证、植检证、入境检验检疫证明、报关单 | 原产国与箱标一致、批次对应 |
| 实物核对 | 拍照箱标、标签、PLU、批次码 | 三者信息一致，无涂改 |
| 系统留档 | 录入批次、产地、单证编号 | 可追溯到具体进货批次 |
| 合同约定 | 写明"须提供可核验产地溯源单证" | 便于追责与退换 |

---

## 四、避坑提醒

- **只看品牌贴不够**：都乐/鑫荣懋贴纸可被仿，必须**单证+箱标+批次三者交叉核对**。
- **PLU 不代表产地**：PLU 是品种规格码，产地看箱标和原产地证。
- **转手货要往上追**：非自营进口的，必须拿到最终进口商的单证，否则溯源断链。
- **扫码溯源要验证**：扫出的信息要和纸质单证对得上，别只信二维码页面。
- **检疫准入**：确认该苹果**原产国在中国海关准入名单内**（不同国家/品种准入不同），这是合法进口前提。
