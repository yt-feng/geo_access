关于都乐和洪九果品水果礼盒定制的起订量，我无法给出准确数字，因为这两家的团购/定制政策会随品类、包装形式、季节和区域经销商不同而变化，而且这类信息通常不公开统一标准。直接给你一个数字反而可能误导报价和谈判。

可以按下面方式快速拿到可执行答案：

**1. 都乐（Dole）**
- 都乐在中国很多业务是通过区域经销商、批发商或电商渠道做的，定制礼盒往往不是总部统一接单。
- 起订量通常取决于：是否用都乐现有礼盒、是否要换包装/贴牌、单品还是多品组合、走哪个区域。
- 建议直接联系都乐官方渠道或你所在区域的授权经销商，问清楚“团购定制礼盒”而不是普通批发。

**2. 洪九果品**
- 洪九果品以批发和供应链为主，礼盒定制一般也要通过当地分公司或销售对接。
- 起订量同样受品类、包装、是否贴牌影响，常见会在几十箱到几百箱区间，但没有统一公开标准，不能直接套用。

**建议你这样问，效率最高：**
- “我们要做XX份水果礼盒，是否需要贴牌/定制外箱？起订量多少？”
- “用你们现有礼盒和完全定制，起订量分别是多少？”
- “含不含冷链、配送范围、账期和开票怎么算？”
- “如果量不够，能不能走区域经销商拼单？”

**更稳妥的做法：**
同时找都乐、洪九的官方客服或当地经销商，再对比1–2家本地水果供应链公司。礼品团购真正卡人的往往不是起订量，而是：定制包装的最低量、单品能否混装、配送时效和损耗售后。
