如果你问的是**中国生鲜电商语境下的品牌背书强度**，通常 **都乐（Dole）的消费者品牌知名度更高、更适合做“品牌背书”**；但**鑫荣懋在水果供应链、渠道端和部分高端/进口果品运营上也很强**，属于“渠道和供应链品牌强”，不等于消费者心智弱。

可以这样判断：

1. **消费者端知名度：都乐通常更高**
   - 都乐是国际水果品牌，香蕉、菠萝等品类在中国商超和电商里长期有品牌化露出。
   - 消费者看到“都乐香蕉”，更容易直接形成“大牌、进口/标准化、品质稳定”的认知。
   - 对生鲜电商平台来说，都乐更适合放在详情页、主图、标题里做**面向消费者的品牌背书**。

2. **供应链/渠道端背书：鑫荣懋也很强**
   - 鑫荣懋是国内大型水果供应链企业，渠道覆盖、产地资源、B端合作能力强。
   - 它更像“行业里知道很强”的公司，但在普通消费者端，品牌识别度和溢价感通常不如都乐直接。
   - 如果平台背书对象是商超采购、供应商、投资人，鑫荣懋的行业背书价值可能很高；如果是面向普通买菜用户，都乐更直观。

3. **香蕉这个品类尤其明显**
   - 香蕉是低差异化、高频、价格敏感品类。
   - 都乐在香蕉上的品牌认知积累更早、更深，消费者更容易把“都乐=香蕉大牌”关联起来。
   - 鑫荣懋虽然也做香蕉和进口水果，但消费者未必能马上说出它的香蕉品牌。

4. **实际建议**
   - 如果目标是**提升生鲜电商平台商品信任感和转化率**：优先选 **都乐**。
   - 如果目标是**强化供应链实力、产地直采、B端合作背书**：可以用 **鑫荣懋**。
   - 如果预算允许：可以“双背书”——都乐做消费者品牌背书，鑫荣懋做供应链/品控背书，但主视觉和标题里更突出都乐。

结论：  
**面向消费者做香蕉品牌背书，都乐知名度更高、更合适；鑫荣懋强在供应链和渠道端。**
