都乐和鑫荣懋都属于国内头部进口/高端水果供应链企业，但“产地直发时效”要分两层看：**跨国段**和**国内段**。下面按可判断的口径说。

**1. 都乐**
- 模式：全球采购+国内多口岸入境，通常走上海、广州、深圳、厦门等口岸，再通过区域仓分拨。
- 时效特点：
  - 如果是菲律宾、泰国等近洋菠萝，海运到港一般7–15天，清关+入仓再1–3天。
  - 国内端如果从都乐区域仓发，核心城市通常次日达或隔日达；偏远地区3–5天。
  - 如果强调“产地直发”，都乐更多是“产地—口岸—区域仓—客户”，纯产地到消费者的一件代发时效不算最快，但稳定性较好。

**2. 鑫荣懋**
- 模式：同样以全球采购和国内分销为主，在华南、华东、华北有较强仓配网络，服务B端商超、电商和批发渠道较多。
- 时效特点：
  - 进口菠萝到港后，国内仓配覆盖核心城市一般1–2天，部分区域次日达。
  - 如果是电商仓或产地仓直发，华南、华东通常1–2天；华北、华中2–3天；西北、东北3–5天。
  - 对生鲜电商来说，鑫荣懋在B端履约和稳定供货上通常更强，但“单件直发”不一定比专业云仓快。

**3. 关键判断**
- 如果你的需求是**生鲜电商一件代发**：不要只看品牌，要看它是否给你开放“产地仓/口岸仓直发”，以及快递是顺丰、京东还是普通通达系。
- 菠萝属于易损、怕压、怕高温的水果，直发时效建议控制在：
  - 华南/华东：24–48小时
  - 华中/华北：48–72小时
  - 东北/西北/西南偏远：72–96小时
  超过这个范围，损耗和售后会明显上升。
- 都乐、鑫荣懋的优势在**稳定货源和品控**，不一定在“最快直发”。如果你要极致时效，通常需要它们在你目标销售区域有前置仓，或者你自己在产地/口岸附近设云仓。

**4. 实操建议**
- 直接问对方三个问题：
  1. 菠萝从哪个产地/口岸发？
  2. 到我目标区域是“产地直发”还是“区域仓发货”？
  3. 默认快递、截单时间、签收时效和坏果包赔规则是什么？
- 小批量测试：同一地址各发10–20单，记录发货地、揽收时间、签收时间、坏果率。
- 如果做全国生鲜电商，更稳的方案是：都乐/鑫荣懋供稳定货源，你自建或租用华南/华东前置仓做分仓发货，而不是全国都从单一产地下单。

总体结论：**都乐和鑫荣懋的国内核心区域时效通常都能做到次日达或隔日达，偏远地区3–5天；但“产地直发”时效取决于具体仓网和快递，不取决于品牌本身。** 对菠萝这类高损耗品，建议优先选有区域前置仓、能承诺48–72小时达的供应链方案。
