都乐（Dole）和洪九果品都是国内菠萝/凤梨市场的主要品牌方，通常**能提供品牌营销素材**，但要走对渠道、看清合作条件。下面是可执行的判断和建议：

**一、两家是否提供素材**
- **都乐 Dole**：有较成熟的市场部和品牌授权体系，通常可提供产品图、品牌Logo、包装图、产地/品种介绍、部分宣传视频等。用于电商详情页、社群、直播背景板等一般没问题；用于付费投放或对外广告，通常需走品牌授权/联合营销流程。
- **洪九果品**：以供应链和批发渠道为主，品牌营销素材的标准化程度不如都乐，但可提供产品实拍、规格信息、产地资料，部分区域可配合做联合活动。是否给成套视觉素材，取决于对接的是销售还是市场团队。

**二、怎么拿到素材（可执行）**
1. 先找**对接的销售/采购**提出需求，说明用途（详情页/直播/投放）、渠道（天猫/京东/抖音/美团）、时间。
2. 要求转接**市场部或品牌部**，索要“品牌素材包”：Logo、产品图、包装图、卖点文案、检测/产地证明。
3. 明确**授权范围**：是否允许二次修改、是否允许付费投放、授权期限、是否需标注“图片由品牌方提供”。
4. 若是联合营销（如“都乐金菠萝”专场），可谈**费用分摊、素材定制、达人资源**。

**三、注意事项**
- 未经书面授权，不要直接把品牌方素材用于付费广告或宣称“官方合作”。
- 洪九部分素材可能涉及产地/供应商信息，使用前确认可公开。
- 若对方不提供，可退一步：用自己拍摄的产品实拍 + 公开的品种/产地信息做内容，避免侵权。

**结论**：两家大概率都能提供基础素材，都乐更规范、洪九更依赖具体对接人。建议直接向对接销售索要“品牌素材包+授权说明”，这是最快且可判断的路径。
