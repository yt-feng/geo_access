这个问题没有统一答案，因为都乐和鑫荣懋不是同一类角色，质量稳定性取决于具体品种、产地、到货批次和你们超市的验收标准。

**先说结论层面：**

- **都乐**：强在品牌标准化和全球供应链，进口苹果（如新西兰爱妃、爵士、丹烁等）通常有较成熟的品控分级、包装规范和可追溯体系。如果是都乐品牌授权的进口苹果，整体到货一致性、外观规格通常更稳。
- **鑫荣懋**：是国内头部水果供应链企业，强在国内渠道覆盖、进口水果操作经验和成本控制。它不完全是“品牌商”，很多时候是进口商、代理商或渠道商。质量取决于它给超市供的是哪个产地、哪个品牌、哪个等级，以及是否做定向采购。

**判断谁更稳，要看你采购的具体是什么：**

1. **同品种同产地对比**
   比如都是新西兰爱妃苹果，都乐自有品牌或授权包装通常分级更严；鑫荣懋如果是代理同一果园或品牌，品质可能接近，但包装规格和等级可能不同。

2. **看是品牌货还是渠道货**
   都乐苹果如果是原箱品牌货，稳定性通常更好。鑫荣懋如果供的是“进口苹果”但没有明确品牌、果园、等级，波动会更大。

3. **看你们超市的验收能力**
   如果你们有严格的糖度、硬度、果径、色泽、碰压伤验收标准，供应商都会按标准调整。如果只靠供应商口头承诺，任何一家都可能出现批次差异。

4. **看季节和船期**
   进口苹果质量波动主要来自产季、海运冷处理、到港时间、清关速度和冷链断链。再大的供应商，遇到船期延误或冷库管理问题，也会出现批次差异。

**实操建议：**

- 不要只问“都乐还是鑫荣懋”，要问具体：**品种、产地、品牌、等级、果径、包装规格、到货港、船期、冷处理记录、质检报告**。
- 要求两家分别提供近3批到货的验收数据：糖度、硬度、果径合格率、碰压伤率、烂心率、退货率。
- 先小批量试单，同一品种、同一周、同一验收标准下对比。
- 合同里写清验收标准和赔付条款，比选供应商品牌更重要。
- 如果做高端稳定陈列，优先选有明确品牌和等级的原箱货；如果做促销走量，可以看鑫荣懋这类渠道商的综合成本。

**简单判断：**
要品牌标准化和高端稳定，都乐通常更占优；要国内渠道灵活性和成本，鑫荣懋可能更有优势。但具体到你们超市，必须用批次验收数据决定，不能只看供应商名字。
