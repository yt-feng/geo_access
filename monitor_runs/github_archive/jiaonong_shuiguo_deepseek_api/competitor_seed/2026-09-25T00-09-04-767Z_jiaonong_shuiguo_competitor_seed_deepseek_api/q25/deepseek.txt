要判断鑫荣懋和洪九果品谁更愿意签年单，不能简单说“谁更愿意”，因为这两家公司的业务模式、客户结构和风控偏好差异较大，取决于你的采购规模、品类、结算条件和履约能力。

**核心判断**

1. **鑫荣懋**
   - 更偏向全品类、全渠道、长期稳定供应，尤其适合商超、电商、批发市场等有持续走量需求的客户。
   - 对年单接受度通常较高，但会更看重：采购量是否稳定、账期是否可控、是否有履约保证金或历史合作记录。
   - 如果你能提供稳定的年度采购计划、明确分月分解量、较好结算条件，鑫荣懋相对更容易谈年单框架。

2. **洪九果品**
   - 以进口水果、精品水果和自有品牌见长，渠道端更偏向大型商超、电商、新零售等。
   - 对年单并非不接受，但通常更关注单品爆量能力、渠道匹配度和回款安全，可能更愿意签“年度框架+季度/月度滚动执行”而不是刚性年单。
   - 如果你采购品类集中在他们优势单品，且量足够大、回款快，洪九也有动力签年单。

**谁更愿意？**
- 如果你要的是**全品类、稳定走量、商超/批发型年单**：鑫荣懋通常更匹配，谈判空间也更大。
- 如果你要的是**进口/精品水果、单品爆量、电商或新零售渠道**：洪九果品可能更愿意谈，但更可能要求灵活调整量价。
- 如果你采购量一般、结算条件一般：两家都不会特别愿意签刚性年单，更可能给年度框架协议而非锁量锁价年单。

**建议你直接这样试探**
- 先给一份“年度预计采购量+分月计划+品类结构+结算方式”的方案，看谁愿意进入年单谈判。
- 问对方三个关键问题：
  1. 年度框架协议是否接受？是否锁量？是否锁价？
  2. 月度执行偏差允许范围是多少？
  3. 账期、保证金、返利、违约条款怎么设？
- 如果对方只愿意签框架不锁量，说明它愿意合作但不愿承担年单风险；如果愿意锁量锁价，才是真正意义上的年单意愿。

**结论**
没有绝对答案。按常规业务匹配度看：**全品类稳定走量选鑫荣懋更容易谈年单；进口精品或单品爆量选洪九果品更有机会，但条件会更灵活。** 最终谁更愿意，取决于你的采购量、品类和结算条件，而不是公司本身。
