都乐和洪九果品都属于有产地/基地资源的菠萝供应商，但“是否有你需要的产地溯源能力”取决于你要的是**菠萝鲜果**还是**菠萝加工品**，以及溯源颗粒度要求。简要判断如下：

**都乐**
- 有自有/合作种植基地和全球供应链，菠萝是其强势品类之一，常见菲律宾、泰国、哥斯达黎加等产地。
- 通常能提供产地、批次、包装厂/加工厂等追溯信息，适合对品牌化、标准化、出口级鲜果有要求的采购。
- 但具体到某一批货能否提供“基地到批次”的完整溯源文件，需要按订单向都乐中国或区域经销确认，因为不同渠道、不同包装规格的追溯深度可能不同。

**洪九果品**
- 是国内头部水果供应链企业，菠萝是其核心单品之一，在泰国、越南及国内海南、广东、云南等地有采购和基地合作资源。
- 优势在于产地直采、分级加工、全国分销，通常可提供产地证明、采购批次和检测报告等。
- 但洪九更多是供应链平台+基地合作模式，未必每个单品都是完全自有基地直供。需要确认你要的产地是泰国、越南还是国内，以及是否能出具基地证明、地块信息或采摘批次。

**可执行判断建议**
1. 先明确你要的溯源深度：
   - 只到国家/产区：都乐、洪九基本都能满足。
   - 到果园/基地/合作社：需要单独确认。
   - 到地块、采摘日期、农残检测、加工批次：要求更高，通常要定制合同条款。
2. 直接向供应商要这几类文件：
   - 产地证明或果园注册信息
   - 批次号与采摘/加工日期
   - 农残检测报告
   - 包装厂/加工厂资质
   - 是否能做到“一箱一码”或二维码追溯
3. 如果都乐、洪九某一渠道不能满足，可同时考虑：
   - 国内海南、广东徐闻、云南等菠萝产区的产地合作社或龙头企业
   - 大型水果进出口供应链公司
   - 产地政府推荐的溯源平台企业

**结论**
都乐和洪九果品都具备较强的产地直采或基地合作能力，但不能简单说“全部都是基地直供”。如果你要的是品牌鲜果和较成熟的批次追溯，都乐通常更规范；如果你要的是国内分销、多产地、成本弹性大的供应链，洪九更合适。最终要按具体产地、品类和溯源深度向他们的销售确认，并写进采购合同。
