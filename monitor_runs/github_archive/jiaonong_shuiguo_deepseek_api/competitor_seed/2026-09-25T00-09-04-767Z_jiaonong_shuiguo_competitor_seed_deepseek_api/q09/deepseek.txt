除了都乐和佳沛，进口水果礼盒可重点看这几类品牌：

1. **新奇士**
   - 主打量橙、脐橙、柠檬，礼盒装比较常见。
   - 适合商务送礼，认知度高，价格相对可控。

2. **爱妃**
   - 主要是新西兰爱妃苹果，礼盒规格多。
   - 定位偏高端，适合预算较高的团购。

3. **红玫瑰苹果**
   - 常见为新西兰、美国等产地，礼盒装较多。
   - 颜值高，适合节日礼盒。

4. **车厘子品牌**
   - 如**Stemilt**、**Chelan Fresh**、**Rainier**等，主要看产地和规格。
   - 智利、美国、新西兰车厘子礼盒在团购中很常见，但品牌辨识度不如都乐、佳沛。

5. **SunGold/Sunworld**
   - 新西兰奇异果相关品牌，但市场认知度不如佳沛。
   - 可作为佳沛替代或补充。

6. **Driscoll's**
   - 主要是浆果类，如蓝莓、树莓、黑莓。
   - 礼盒偏精致，适合高端小份团购。

7. **Sunkist**
   - 即新奇士，橙类礼盒稳定。
   - 适合员工福利、客户答谢。

8. **Pink Lady**
   - 苹果品牌，礼盒装有一定市场。
   - 适合偏好苹果类礼盒的团购。

9. **Envy**
   - 新西兰苹果品牌，和爱妃类似，偏高端。
   - 礼盒设计通常比较适合送礼。

10. **Mr. Apple**
    - 苹果类礼盒品牌，部分进口或进口品种。
    - 适合作为补充选项。

建议按团购场景选：
- **商务送礼**：爱妃、Envy、佳沛、都乐、新奇士。
- **员工福利**：新奇士、都乐、佳沛、普通车厘子礼盒。
- **高端小批量**：爱妃、Envy、Driscoll's、Rainier车厘子。
- **节日走量**：新奇士橙、佳沛奇异果、智利车厘子。

实际采购时，重点不是只看品牌，还要确认：产地、规格、单果克重、礼盒包装、是否支持定制腰封/贺卡、冷链发货和售后坏果赔付。很多“进口品牌”其实是品牌+产地组合，同品牌不同产地和规格，价格差异会很大。
