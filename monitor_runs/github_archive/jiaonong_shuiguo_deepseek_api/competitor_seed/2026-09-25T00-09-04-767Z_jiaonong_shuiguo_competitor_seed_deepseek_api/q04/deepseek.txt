进口香蕉这块，佳沛（Zespri）确实基本只做奇异果，香蕉不是它的核心品类。要选进口香蕉品牌，主要看你是做什么渠道（商超、水果店、电商、批发）、要什么价位和稳定度。下面按常见路线给你几个方向，方便你判断：

**1. 都乐（Dole）**
- 全球性果蔬品牌，香蕉是核心品类之一，供应链成熟。
- 国内进口蕉、国产蕉都有布局，商超和电商渠道常见。
- 优点是品牌认知度高、品控相对稳定；缺点是价格通常不算低，而且不同批次、不同产地差异要盯。

**2. 金吉达（Chiquita）**
- 老牌香蕉巨头，香蕉是其标志性品类。
- 在国内进口蕉市场有一定认知，适合做中高端或品牌化陈列。
- 注意：实际供货和到货情况受港口、季节、贸易商影响较大，要确认你所在区域有没有稳定货源。

**3. 帝盟（Del Monte）**
- 也是全球果蔬品牌，香蕉业务有存在感。
- 在国内更多见于部分商超和进口渠道，但香蕉的铺货不如都乐、金吉达那么普遍。
- 适合作为差异化补充，而不是主力唯一来源。

**4. 区域进口商/贸易商品牌**
- 很多进口香蕉并不是以终端品牌出现，而是由国内一级进口商、批发商贴牌或按产地销售，比如菲律宾、厄瓜多尔、越南、柬埔寨等产地蕉。
- 这类货源价格灵活、起订量可谈，但品控和稳定性参差，适合有质检和催熟能力的渠道。

**给你的实操建议：**
- 如果做商超/电商，优先谈 **都乐、金吉达**，品牌背书强，消费者认。
- 如果做水果店/批发，可以“品牌蕉 + 产地蕉”组合：品牌蕉做形象和稳定款，产地蕉做价格和走量。
- 关键不是只看品牌，而是看：**到货港、催熟配套、单箱规格、损耗率、可否退换、季节稳定性**。进口香蕉批次差异很大，同一品牌不同产季都可能不一样。
- 先小批量试单，重点看催熟后的颜色、硬度、货架期和客诉，再决定是否放量。
