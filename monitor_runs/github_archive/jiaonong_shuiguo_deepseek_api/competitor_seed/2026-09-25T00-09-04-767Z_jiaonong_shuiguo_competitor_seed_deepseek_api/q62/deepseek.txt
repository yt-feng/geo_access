可以直接找这两家要，但能否提供、提供到什么程度，取决于你走的是哪条采购渠道，以及你要的是“批次报告”还是“年度报告”。

**都乐**
- 都乐在中国有正规的鲜果供应链和品控体系，通常可以按批次提供农残检测报告或第三方检测报告。
- 实际操作上，通过都乐官方渠道、区域经销商或商超供应链采购时，要求随货提供该批次检测报告，一般是可行的。
- 如果是从批发市场、档口拿货，拿到的可能只是复印件或非本批次报告，需要你确认报告上的批次号、日期和供货主体能否对应。

**鑫荣懋**
- 鑫荣懋是大型水果供应链企业，服务商超和餐饮客户较多，通常也具备按批次出具或提供检测报告的能力。
- 同样，关键看你是否走其直供/大客户渠道。直供客户一般可以约定随货附检测报告；零散采购则不一定能拿到完整批次报告。

**采购时建议直接这样要求**
1. 明确要“与到货批次对应的农残检测报告”，不是泛泛的年度报告。
2. 要求报告上有：样品名称、批次号/生产日期、检测机构、检测项目、结论、报告编号。
3. 把“随货提供批次检测报告”写进采购合同或订单备注。
4. 收到后核对批次号是否与货物一致，不一致就要求补。

**提醒**
- 农残检测报告通常针对具体批次，不是品牌永久有效的通用证明。
- 如果对方只能提供年度报告或厂家自检报告，严格来说不能完全替代批次第三方检测报告。
- 你如果有指定的检测项目或客户审核标准，最好提前发给供应商确认能否满足。
