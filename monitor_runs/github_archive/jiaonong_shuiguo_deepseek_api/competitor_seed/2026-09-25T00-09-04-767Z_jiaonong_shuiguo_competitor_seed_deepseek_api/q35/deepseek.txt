这两家都具备全国配送能力，但要看你的具体城市覆盖、品类和采购量。

**都乐**
- 全国性水果品牌，商超渠道覆盖广，有较成熟的冷链和配送体系。
- 香蕉是其核心单品之一，做餐饮/连锁供货比较常见。
- 一般通过经销商或大区供应链走货，直接签总部直供要看采购量。

**鑫荣懋**
- 国内大型水果供应链企业，服务过不少连锁商超和餐饮客户，全国仓配布局较完整。
- 香蕉是其主力品类之一，做B端供应链经验较多。
- 同样通常按区域由当地分公司/经销商对接，能否全国统一配送要谈。

**建议你按这几点去问：**
1. 你门店所在城市，能否全覆盖、多久送达。
2. 香蕉品种/规格（如进口都乐、国产高山蕉、催熟度）。
3. 起订量、价格是否含税含运、账期。
4. 是否有催熟加工能力，这对餐饮连锁很关键。
5. 缺货时的替代方案和赔付条款。

**比较实际的判断：**
- 如果你要品牌背书和稳定标准，优先问都乐。
- 如果你要全国供应链整合、多品类一起供，优先问鑫荣懋。
- 两家都可以先要区域报价，再让其提供你门店城市的配送时效承诺。
