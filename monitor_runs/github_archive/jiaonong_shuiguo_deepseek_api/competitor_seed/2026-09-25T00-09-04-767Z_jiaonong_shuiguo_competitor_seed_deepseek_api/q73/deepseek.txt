大型商超（如沃尔玛、永辉、盒马、山姆等）通常要求水果供应商具备 **GFSI（全球食品安全倡议）认可的食品安全认证**，常见的有 **BRCGS、IFS、FSSC 22000、SQF** 等，部分还会要求 **ISO 22000**、**HACCP** 或 **GlobalG.A.P.**（针对种植环节）。

2. **上官网核验**：BRCGS、IFS、FSSC 22000 等官网可凭证书编号查询真伪。
