到货损耗率受批次成熟度、运输距离、冷链条件、季节和验收标准影响很大，没有统一固定值。不过按行业常见经验，可给你一个**采购谈判用的参考区间**（生香蕉/催熟蕉批发到货场景）：

| 品牌/渠道 | 常见到货损耗率参考 | 主要损耗点 |
|---|---|---|
| 洪九果品 | 约 3%–8% | 运输磕碰、到货成熟度不均、部分批次催熟过快 |
| 都乐香蕉 | 约 2%–6% | 冷链较稳，损耗主要在末端存放和成熟节奏 |

**怎么判断你实际该按哪个数谈：**

1. **先看你要的是生蕉还是熟蕉**
   - 生蕉到货，损耗通常低，重点看青硬度和冷链。
   - 熟蕉/即食蕉到货，损耗会明显上升，差 2–3 个点很常见。

2. **看运输距离和季节**
   - 同城/短途：都乐可能 1%–3%，洪九 2%–5%。
   - 跨省长途、夏季：都乐可能 3%–6%，洪九 5%–8% 甚至更高。

3. **验收标准决定损耗率**
   - 如果按“轻微黑点、花皮也算损耗”，数字会高。
   - 如果只算腐烂、断裂、不能售，数字会低。
   - 所以谈损耗前必须和供应商确认：**损耗按重量还是按件数、按外观还是按可售性**。

4. **实际采购建议**
   - 首次合作不要只看品牌，先小批量试 3–5 车/批，记录：到货时间、温度、青硬度、催熟天数、可售率。
   - 合同里写清：**到货损耗超过 X% 如何补货/扣款**。一般可谈：洪九超过 5%–6%、都乐超过 3%–4% 启动补损。
   - 如果做高端商超，都乐稳定性通常更好，但价格也高；如果做流通批发、走量，洪九性价比可能更合适，但要压损耗条款。

**结论：**
正常情况下，**都乐香蕉到货损耗率通常略低于洪九果品，大概低 1–3 个百分点**。但具体差多少，必须按你所在城市、季节、运输方式和验收口径实测。最稳妥的做法是：同一路线、同一季节，各发 2–3 批做对比，再定长期采购比例。
