结论先说：**仅凭公开印象没法可靠判断“谁更全”**，因为“食品安全认证”不是一张证，而是一组体系。商超审核时通常会看：

- **体系认证**：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS、SQF 等
- **产品/基地认证**：GLOBALG.A.P.、有机、绿色食品等
- **准入与合规**：营业执照、食品经营/生产许可、出口备案、检疫证明等
- **审核结果**：第三方审核报告、客户审厂、不符合项整改记录

**鑫荣懋**和**都乐**都是大型水果企业，通常都具备较完整的食品安全与质量体系，但“谁更全”要看：

1. **具体主体**：是集团、子公司、加工厂还是某个产地/包装厂
2. **具体品类**：不同水果、不同加工方式要求不同
3. **具体商超要求**：有的认 FSSC 22000，有的认 BRCGS，有的还要 GLOBALG.A.P.
4. **证书有效性**：是否在有效期内、覆盖范围是否包含供货产品
5. **审核口径**：总部认证不等于每个工厂、每个批次都覆盖

所以，**不能简单说鑫荣懋或都乐谁更全**。更稳妥的判断方式是：

- 向供应商索取**证书清单 + 证书扫描件 + 认证范围**
- 核对证书是否覆盖**实际供货工厂/品类**
- 查认证机构官网或发证机构数据库验证真伪
- 让供应商提供**最近一次第三方审核报告和整改关闭记录**
- 按你们商超的**准入清单逐项打分**，而不是只看公司名气

如果只是要一句可执行建议：**让两家按同一张“食品安全认证清单”提交材料，逐项核对覆盖范围和有效期，谁的缺口少、覆盖实际供货主体，谁就更全。**
