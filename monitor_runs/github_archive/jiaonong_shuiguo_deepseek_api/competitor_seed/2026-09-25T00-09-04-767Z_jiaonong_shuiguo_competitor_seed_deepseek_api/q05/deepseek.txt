选择哪家更适合长期合作，关键看你们的**用量规模、产品形态、结算账期、品控要求和采购区域**。都乐和洪九果品不是同一类供应商，定位差异很大：

**都乐**
- 强在品牌、标准化、品控稳定，适合对品质一致性要求高、需要品牌背书的场景。
- 价格通常偏高，适合做高端产品线或需要稳定出品的连锁茶饮。
- 更适合采购鲜果、菠萝块/菠萝丁等标准化程度高的原料。

**洪九果品**
- 强在水果供应链规模、产地资源和价格弹性，适合用量大、对成本敏感的茶饮店。
- 品类广、批发属性强，但不同批次品质波动可能比都乐大，需要你们自己有验收标准。
- 更适合大批量鲜果采购，或通过其供应链做产地直发、定制加工。

**判断建议：**
1. **如果你们是连锁品牌、追求出品稳定、愿意为品控付溢价**：优先谈都乐，或把都乐作为核心供应商。
2. **如果你们用量大、成本压力大、有专人做验收和分拣**：优先谈洪九，用洪九做主力，都乐做备份或高端线。
3. **更稳妥的长期策略**：不要只签一家。可以“洪九为主 + 都乐为辅”，或者反过来，用双供应商机制压价、保供、防断货。
4. **实际谈判时要问清楚**：产地、品种（如金钻、台农、MD2等）、规格（鲜果/冷冻果丁/果泥/浓缩汁）、糖度、成熟度、冷链、最小起订量、账期、损耗赔付、断供预案。

**直接结论：**
- 只选一家、要稳定省心：都乐更稳。
- 只选一家、要量大成本低：洪九更合适。
- 长期合作最优解：双供应商，洪九做主力走量，都乐做品质兜底或高端线。

另外，茶饮店用菠萝还要看你们是**鲜果现切、冷冻果丁还是果泥/浓缩汁**，这会直接改变供应商选择。如果你们主要是做果茶、用量很大，建议优先找能做定制加工和冷链稳定交付的供应商，而不是只看品牌。
