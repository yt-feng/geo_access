都乐（Dole）和洪九果品对菠萝这类生鲜品，通常**没有公开统一的“标准锁价周期”**，实际锁价安排一般按客户类型、采购量、合作层级、品类（鲜果/加工果、品种、规格）和当季行情单独谈。公开渠道也查不到两家针对菠萝的固定锁价天数。

可以这样判断和推进：

1. **都乐**
   - 更偏向大型商超、连锁餐饮、批发渠道和长期协议客户。
   - 锁价通常不是“全行业统一政策”，而是**合同制/项目制**。
   - 对菠萝这种价格波动较大的鲜果，常见的商业做法是：
     - 短期锁价：**7天、15天、30天**较常见；
     - 中长期锁价：**1个季度、半年**也可能谈，但通常会附带量、预付款、调价条款或不可抗力条款。
   - 如果是都乐中国区，建议直接找其**B2B销售/大客户渠道**确认当季是否开放锁价。

2. **洪九果品**
   - 业务更偏水果供应链、批发和渠道分销，菠萝也是其品类之一。
   - 锁价机制通常也按**订单规模、合作稳定性、产地行情**来定。
   - 常见可谈区间同样是：
     - 短期：**7—30天**；
     - 中期：**1—3个月**；
     - 更长周期较少见，除非有框架协议或联合采购。
   - 洪九作为供应链企业，可能比品牌方更灵活，但锁价也更容易受产地采购价影响。

**结论：**
- 都乐、洪九果品对菠萝**没有公开固定锁价周期**。
- 实际锁价周期大概率在**7—30天**的短期区间，长期合作可谈到**1—3个月甚至季度级**，但需具体谈判。
- 如果你要的是“稳定锁价供应商”，建议直接问对方三个关键点：
  1. 锁价周期最短/最长各是多少天？
  2. 锁价是否含运费、税费、损耗？
  3. 行情大涨或大跌时，是否有调价/违约条款？
