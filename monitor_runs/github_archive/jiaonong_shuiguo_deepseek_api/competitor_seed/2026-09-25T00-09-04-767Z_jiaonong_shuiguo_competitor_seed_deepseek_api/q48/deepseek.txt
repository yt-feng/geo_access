我无法核验鑫荣懋和都乐当前有效的具体认证证书清单，所以不能直接给你一份“都有哪些资质”的确定答案。资质会随认证周期、产品范围、工厂/基地不同而变化，必须以最新证书为准。

可以按下面方式快速判断和核验：

**一、大型商超通常要求的食品安全资质**
1. **营业执照、食品经营许可证/食品生产许可证**
2. **ISO 22000 食品安全管理体系**
3. **HACCP 危害分析与关键控制点体系**
4. **FSSC 22000 或 BRCGS、IFS 等 GFSI 认可体系**
5. **全球良好农业规范 GLOBALG.A.P.**
6. **有机认证、绿色食品、无公害农产品**（如对应品类）
7. **出口备案/海关注册、检疫相关资质**（如涉及进口水果）
8. **产品检测报告、产地证明、追溯体系文件**

**二、鑫荣懋**
鑫荣懋是国内大型水果供应链企业，通常会被商超要求提供：
- 营业执照及相关食品经营/流通资质
- ISO 22000、HACCP 等食品安全体系证书
- GLOBALG.A.P. 或类似基地认证
- 具体单品对应的检测报告、追溯和冷链管理文件

但具体到某一年度、某个品类、某个工厂是否持证，需查其最新证书。

**三、都乐**
都乐是国际水果品牌，通常具备较完整的国际食品安全和农业规范体系，常见可能包括：
- GLOBALG.A.P.
- ISO 22000 / HACCP
- BRCGS 或 FSSC 22000（视加工/包装环节）
- 有机认证（针对有机产品线）
- 海关/进出口及检疫相关合规文件

同样，具体证书以都乐或其供应商最新提供的为准。

**四、最可靠的核验方法**
1. 直接向鑫荣懋、都乐的**销售或质量部门**索取最新证书扫描件。
2. 检查证书上的：
   - 获证企业全称
   - 认证范围
   - 有效期
   - 发证机构
   - 是否覆盖你采购的产品和工厂
3. 到认证机构官网或国家认监委“认证认可业务信息统一查询平台”核验证书编号。
4. 要求提供**该批次产品**的检测报告和追溯文件，而不只是公司级证书。

如果你是要做商超供应商准入审核，建议直接按“公司资质 + 体系证书 + 产品认证 + 批次检测 + 追溯冷链”五项清单向两家索证，这样最稳妥。
