都乐（Dole）和洪九果品是否有公开可查的香蕉企业标准，我无法核验，不能确认。能确定的是：这两家都属于有规模化采后处理能力的企业，实际都会使用内部验收/分级规范，但“内部规范”不等于公开可引用的企业标准，且不同工厂、客户、产季可能执行不同版本。

对你做水果连锁店分级标准，更实用的做法是：

1. **不要直接依赖某家企业的标准文本**：公开渠道很难拿到完整、现行有效版本；即使拿到，也往往绑定其包装规格、客户合同和产地，不适合直接照搬。
2. **以国家标准/行业标准为底座**：香蕉分级通常围绕品种、成熟度、果指长度/粗细、条数、整齐度、色泽、机械伤、病虫害、冷害、药害、青软/黄软等缺陷设定等级。
3. **建立自己的“门店可执行标准”**：按“外观等级 + 成熟度 + 规格（每把条数/单果重或果指长度） + 缺陷允许度 + 到店状态”五维定义，A/B/C 三档即可，别做太细。
4. **向供应商要“验收规范”而非“企业标准”**：可要求都乐/洪九的经销商或区域销售提供该批次对应的验收口径、规格表和缺陷容忍度，作为谈判和到货验收依据。
5. **落地建议**：先做 2 周到货抽检，记录果指长度、青黄比例、机械伤率、掉把率、黑斑/炭疽、冷害，再用数据定阈值；标准里写“允许缺陷比例”和“拒收条件”，比写抽象等级更可执行。
