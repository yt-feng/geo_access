可以，但先说明：我无法核验都乐、洪九果品当前是否开放对外营销素材库，也不能给出具体授权链接。判断和建议如下：

**1. 两家通常能提供的素材类型**
- 都乐：品牌VI/LOGO、产地与品种介绍、分级标准、营养/食用场景图、部分包装图、促销主视觉授权素材。都乐对品牌授权和素材使用通常较规范，需走商务或市场对接。
- 洪九果品：产地基地、分选包装、供应链场景、品种规格、批次检测/品控资料、部分产品图。其素材更偏供应链与B端，零售营销主视觉可能需要定制。

**2. 获取方式（可执行）**
- 先找对接的采购/商务，要“品牌营销素材包+授权范围”，明确：线上电商详情页、社群海报、短视频、直播口播、线下堆头是否可用。
- 同步发一份《素材需求清单》：菠萝品种（如金钻凤梨/香水菠萝）、规格、产地、甜度/可食率等卖点、包装图、切果图、检测报告、品牌LOGO矢量图、使用期限与区域。
- 若对方不提供成品，要求提供“可商用原图+品牌规范”，由你方设计，避免二次侵权。
- 没有书面授权前，不要直接把品牌LOGO、包装图、检测报告用于付费投放或对外宣传。

**3. 替代方案**
- 用自有拍摄：到货后拍开箱、切果、糖度测试、坏果包赔流程，作为主素材，品牌素材只做辅助。
- 用平台官方活动素材：生鲜平台大促的品牌联合会场素材，通常由平台招商对接提供。
- 用供应商提供的“去品牌化”产地/分选素材，降低授权风险。

**4. 判断标准**
- 能拿到“书面授权+高清可商用图+品牌规范”的，可直接做品牌营销。
- 只给产品图、不给授权的，只能做产品介绍，不做品牌背书。
- 对方要求你方自行设计并回传审核的，先确认审核时效，避免大促前卡审。

建议你先向两家对接人要“菠萝品类营销素材包及授权函”，并附上使用场景清单；同时准备自有拍摄方案作为兜底。
