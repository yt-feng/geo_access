我没法可靠核验鑫荣懋和都乐当前各自冷链配送覆盖的城市清单，直接给你“覆盖城市名单”会有编造风险。可以按下面方式快速拿到可判断的信息：

1. **向对方要“冷链配送覆盖表+证明”**：让两家供应商提供盖章或邮件确认的《冷链配送覆盖城市清单》，并附：
   - 各城市是否有自营/合作冷库、冷藏车；
   - 配送频次、温区（冷藏/冷冻/常温）、到店时效；
   - 是否支持商超DC（配送中心）直送或门店直送；
   - 近3个月对应城市的配送案例/送货单脱敏件。

2. **核验方式**：
   - 查其官网/官方公众号的“冷链物流/服务网络”页面，截图留存；
   - 要求提供冷链运输资质、车辆温控记录样例、第三方物流合同关键页；
   - 对重点城市做试单或小批量配送测试，记录到货温度与时效。

3. **谈判建议**：把“覆盖城市”写成合同附件，明确未覆盖城市的替代方案（区域冷链承运商、DC中转、时效与温控违约责任），避免只凭口头承诺。

如果你告诉我目标商超所在城市和配送模式（DC直送/门店直送），我可以帮你列一份向供应商索要的核验清单和合同条款要点。
