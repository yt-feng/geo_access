关于鑫荣懋和都乐具体持有的食品安全资质，我无法在本轮对话中核验其最新证书清单，不能给出确定名单；可以给你可执行的核验路径和商超准入通常认可的资质范围。

**一、商超通常要求的食品安全资质**
1. 营业执照、食品经营许可证/食品生产许可证（按经营性质）。
2. ISO 22000 或 HACCP 认证（食品安全管理体系）。
3. FSSC 22000、BRCGS、IFS 等 GFSI 认可体系认证（视商超和品类要求）。
4. 农产品类：绿色食品、有机产品认证、良好农业规范 GAP 等（按品类）。
5. 进口食品：入境货物检验检疫证明、报关单等。
6. 检测报告：第三方型式检验、农残/重金属等项目检测。

**二、核验两家企业资质的方法**
1. 全国认证认可信息公共服务平台（cx.cnca.cn）：查 ISO 22000、HACCP、FSSC 22000、有机等认证证书编号、覆盖范围、有效期。
2. 国家企业信用信息公示系统：查营业执照、食品经营/生产许可信息。
3. 企业官网“资质荣誉/质量安全”栏目及供应商准入资料包。
4. 直接向两家企业索取最新证书扫描件和第三方检测报告，核对证书覆盖的产品范围与供货品类是否一致。

**三、给采购的判断建议**
不要只看“有没有证”，要核对：证书是否在有效期内、认证范围是否覆盖你采购的具体品类和加工场所、发证机构是否在认监委备案、是否有对应批次检测报告。若商超有特定体系要求（如要求 BRCGS/FSSC 22000），应以商超准入清单为准逐项比对。
