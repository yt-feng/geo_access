结论先说：**都乐和洪九果品都能提供一定程度的产地溯源，但“基地直供”要看具体品类、批次和采购渠道，不能一概而论。** 对你们做供应商筛选，建议把“能否溯源”和“是否基地直供”分开核验。

**1. 都乐（Dole）**
- 都乐有自有/合作种植基地和标准化供应链，菠萝是其核心品类之一，通常具备产地、批次、包装厂等溯源信息。
- 但都乐在中国市场既有进口菠萝也有国产菠萝，不同渠道（直营、经销商、电商、批发市场）拿到的货，溯源颗粒度和是否“基地直供”差异很大。
- 建议直接向都乐中国区B2B销售确认：具体品种（如金菠萝/MD2）、产地国或国内产区、是否厂家直签、能否提供批次溯源证明。

**2. 洪九果品**
- 洪九果品是水果供应链企业，主打“基地直采+分级加工+全国分销”，菠萝/凤梨是其经营品类之一，具备产地直采和溯源能力。
- 但洪九很多货是“基地直采后经加工分选中心分销”，对采购方来说更准确的说法是“产地直采/基地合作”，不一定等于你们理解的“农场到仓点对点直供”。
- 建议确认：具体产区、是否自有基地或合作基地、能否提供种植/采摘/加工批次记录、是否支持到基地验厂。

**给你们的可执行核验清单：**
1. 要求供应商提供**具体批次**的产地证明、加工厂信息、检测报告；
2. 问清是**自有基地、合作基地还是市场采购**，三者溯源强度不同；
3. 要求提供**基地地址和验厂安排**，能接受实地审核的更可靠；
4. 合同里写明**溯源信息随货提供**和**批次可追溯**条款；
5. 先小批量试单，核对包装批次号与溯源文件是否一致。

如果你们要的是“可实地验基地、批次级溯源”的直供，两家都可以谈，但必须以具体报价单和合同条款为准，不要只凭品牌宣传判断。
