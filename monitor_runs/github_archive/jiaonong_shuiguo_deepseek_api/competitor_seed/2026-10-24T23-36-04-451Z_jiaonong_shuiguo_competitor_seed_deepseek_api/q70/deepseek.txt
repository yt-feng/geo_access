能提供，但两家的“证明形态”不一样，建议你按下面方式核验，不要只接受口头承诺。

**都乐（Dole）**
- 通常可提供：产地/果园或产区信息、批次号、采收/包装日期、GlobalG.A.P.等认证、部分客户可拿到检测报告或质量规格书。
- 溯源形式多为“批次级溯源”，不是每根香蕉可查。需在合同里明确：随货提供批次号、产地、包装厂、检测报告（农残/重金属按你要求）、质量验收标准。
- 注意：都乐中国多为进口香蕉，产地会随船期变化（菲律宾、厄瓜多尔等），要确认你采购的是哪个产区、哪条供应链。

**鑫荣懋**
- 国内大型水果供应链企业，既有进口也有国产香蕉资源，通常可提供产地证明、检测报告、品控流程文件、批次追溯信息。
- 国产香蕉可做到“产区/基地+批次”追溯；进口香蕉同样按批次和报关/检疫资料追溯。
- 需确认具体是哪个基地或进口产区，因为其供应来源较多，不同品类证明能力不同。

**建议你直接问供应商这5项，能提供再谈：**
1. 本批次产地证明/果园或包装厂编号；
2. 批次号及追溯链路（从包装到发货）；
3. 第三方农残/重金属检测报告（近3个月内，按你标准）；
4. 品控文件：验收标准、抽检比例、不合格处理；
5. 认证证书：GlobalG.A.P./有机/绿色食品等，按你需要。

**判断建议：** 两家都具备产地溯源和品控证明能力，但都需在合同/订单中写死“随货文件清单”和“批次追溯要求”。如果要求“一物一码”或每批第三方全项检测，需提前确认是否额外收费及周期。
