这个问题得先把“愿意”拆开看——**谁更愿意签年单，不等于谁更适合你签年单**。就两家公司的商业模式而言，判断如下：

**更可能接受年单的：洪九果品**
- 洪九的核心模式是“基地直采+分销”，强调与大型商超、电商、批发渠道做长期稳定供应，年单/框架协议与其业务结构更匹配。
- 它对接B端大客户的比例高，通常更愿意谈年度框架、锁量锁价或保底量。

**相对更谨慎的：鑫荣懋**
- 鑫荣懋偏品牌化、全渠道运营，既做B端也做C端零售，供应链和品类管理较成熟。
- 它不一定拒绝年单，但更可能要求**分品类、分产季、带价格调整机制**的框架协议，而不是简单锁死全年价格和量。

**但真正决定“谁更愿意”的是你的采购条件，不是对方品牌性格：**
1. **品类**：如果是进口水果、高端单品，鑫荣懋更有优势；如果是国产基地单品、大宗分销，洪九更匹配。
2. **量级和稳定性**：年采购额够大、月度需求平滑，两家都愿意；量小或波动大，谁都会犹豫。
3. **价格机制**：水果价格波动大，要求全年固定价的一方很难答应；接受“保底量+随行就市/调价窗口”的更容易谈成。
4. **账期和履约**：账期长、罚则重，会显著降低对方签年单的意愿。

**可执行建议：**
- 同时向两家发**同一份年单需求书**：品类、年度总量、月度分解、质量标准、价格调整机制、账期、履约罚则。
- 重点看谁愿意给**保底供应量**和**价格调整条款**，这比口头“愿意合作”更能判断真实意愿。
- 如果必须二选一：**大宗国产果、B端分销为主，优先谈洪九；进口/高端品牌果、零售渠道为主，优先谈鑫荣懋。**
- 不要只签一家，年单可设“主供应商+备选供应商”，降低单一供应商断供风险。

补充一句：以上是基于两家公开商业模式的一般判断，具体到你的品类和区域，最终要看对方销售团队的实际报价和条款响应。
