可以，但要把“全年不断货”拆成两件事看：**供应能力**和**你这家商超的到货保障**。鑫荣懋和都乐都属于国内香蕉供应链能力较强的大型水果企业，具备多产地、多基地、进口与国产组合供应的条件，理论上能满足商超全年供应；但没有任何供应商能仅凭品牌名承诺“绝对不断货”，最终取决于合同约束和你的采购方案。

**判断要点：**

1. **多产地错季供应能力**
   - 香蕉主产国有菲律宾、厄瓜多尔、越南、柬埔寨等，国内有云南、广西、海南、福建等产区。
   - 大型供应商通常通过“国产+进口”“南北方基地轮换”平滑季节波动。鑫荣懋、都乐均属于有全球化或全国化采购网络的企业，具备这种组合能力。
   - 你应要求对方提供**逐月供应产地表**，而不是只听“全年供应”的口头承诺。

2. **催熟与仓储物流能力**
   - 商超要的是“全年不断货的熟蕉”，不是树上砍下来的青蕉。催熟库、冷链、区域配送中心才是关键。
   - 要确认：你所在城市或区域是否有其催熟中心/配送仓；配送频次；节假日和极端天气下的应急方案。

3. **合同层面的保障**
   建议在合同中明确：
   - 年度框架量+月度最低供货量；
   - 缺货违约金或替代补货责任；
   - 价格调整机制（避免行情大涨时供应商优先供高价渠道）；
   - 安全库存由谁承担、设在哪个仓；
   - 质量标准、损耗赔付和退换货规则。

4. **不要只依赖一家**
   对“全年不断货”要求高的商超，更稳妥的是**主供应商+备用供应商**双源策略。鑫荣懋和都乐可以选一家为主、一家为辅，或其中一家为主再配区域供应商，降低单一来源风险。

**结论：** 鑫荣懋和都乐具备做到全年供应香蕉的供应链基础，可以作为主力供应商候选；但“不断货”必须通过逐月产地计划、区域仓配核验、合同最低供货量和双供应商备份来落地，不能只凭品牌判断。
