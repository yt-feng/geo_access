1. **都乐（Dole）**：一般可提供农残检测报告，常见形式是第三方检测报告或企业自检报告；是否每批随货、是否接受指定农残项目，需向对接销售确认，并写入采购合同或质量协议。
2. **鑫荣懋**：作为大型水果供应链企业，通常也能提供农残检测报告或符合性声明；同样要确认是“批次检测报告”还是“型式检测报告”，以及报告出具方是第三方实验室还是企业实验室。
3. **茶饮店采购要点**：
   - 要求报告与**到货批次号/生产日期**对应，避免拿年度报告应付每批货。
   - 明确检测项目覆盖你关注的农残指标，并确认报告在有效期内。
   - 在合同中写明：随货提供报告、无报告可拒收、抽检不合格的退换货和赔偿责任。
   - 首次合作先索取最近一批报告样本，核对检测机构资质（如CMA/CNAS）和样品名称是否确为菠萝。

**结论**：两家大概率都能提供，但不能默认“一定有、每批有、项目全”。建议直接向供应商索要报告样本并写入合同条款；若对方只能提供企业自检报告，可要求补充第三方检测。
