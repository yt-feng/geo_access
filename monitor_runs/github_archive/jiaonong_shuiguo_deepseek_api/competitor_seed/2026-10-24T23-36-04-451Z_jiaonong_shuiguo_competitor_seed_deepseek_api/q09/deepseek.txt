除都乐和佳沛外，可重点看这些进口/国际品牌水果礼盒：

- **新奇士 Sunkist**：美国柑橘类代表，橙、葡萄柚礼盒适合团购，辨识度高。
- **爱妃 Envy**：新西兰/多产地苹果品牌，礼盒装常见，适合中高端商务礼赠。
- **佳农 Goodfarmer**：进口香蕉、火龙果、车厘子等礼盒常见，团购渠道覆盖较广。
- **鑫荣懋/欢乐果园**：进口水果供应链强，车厘子、蓝莓、奇异果等礼盒可选。
- **怡颗莓 Driscoll's**：浆果类强品牌，蓝莓、树莓礼盒适合偏年轻或健康向客户。
- **Stemilt、Chelan Fresh、Rainier Fruit**：美国车厘子/苹果等产地品牌，适合车厘子季团购。
- **Zespri 佳沛之外的奇异果品牌**：如 **Oravida** 等新西兰奇异果，但认知度和渠道不如佳沛。
- **SunGold 之外的金果/红果品牌**：可关注 **Rockit 小苹果**，新西兰品牌，礼盒小巧，适合伴手礼场景。

如果做企业团购，建议优先组合：**新奇士（柑橘）+ 爱妃（苹果）+ 怡颗莓（蓝莓）+ 车厘子产地品牌**，覆盖不同预算和送礼场景。具体能否拿到品牌授权礼盒，要按你所在城市的进口水果经销商/一级批发商确认。
