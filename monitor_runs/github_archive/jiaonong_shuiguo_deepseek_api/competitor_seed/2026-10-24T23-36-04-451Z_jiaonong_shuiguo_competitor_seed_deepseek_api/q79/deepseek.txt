可以做到“全年供应”，但要分清是**全年鲜果稳定供货**还是**全年稳定用于果酱加工的原料供应**，两者的保障方式不同。

**1. 都乐**
- 都乐有全球采购和国内多产地调配能力，菠萝全年供应通常没问题，适合对品牌和标准化要求较高的茶饮店。
- 但都乐更偏鲜果品牌供应，是否给你稳定供“果酱加工用菠萝”、是否有对应规格和长期合同价，要直接问当地经销商或都乐B2B渠道。
- 风险点：旺季品质稳定，淡季可能靠进口或不同产区切换，糖度、酸度、纤维感会有波动，做果酱需要自己定验收标准。

**2. 洪九果品**
- 洪九果品是国内大型水果分销商，菠萝等单品有全国分销能力，理论上具备全年供货能力，尤其适合批量采购。
- 但洪九的核心是水果分销，不是专门做茶饮果酱原料定制。你要确认：能否按你的加工规格分级、能否锁定全年价格、能否保证同一品种/成熟度、最小起订量和配送频次。
- 风险点：不同批次产地切换后，加工出酱的色泽和酸甜度可能变化，需要配方端留调整空间。

**可执行判断建议：**
- 不要只问“能不能全年供”，要问供应商要**12个月供货计划、产地切换表、月度参考价、菠萝品种/糖酸度范围、单果规格、加工用果比例**。
- 茶饮店做果酱，建议不要100%依赖单一鲜果供应商。更稳的方案是：**鲜果做差异化卖点 + 冷冻菠萝果肉/果泥或浓缩汁做全年基底**，都乐或洪九作为鲜果补充。
- 先小批量试供2-3个月，重点测：出酱率、糖酸度波动、纤维粗细、颜色氧化、冷冻解冻后的风味损失。
- 合同里写清：月度最低供应量、品质验收标准、断供替代方案、价格调整机制。

结论：**两家都有能力做到全年供应菠萝，但“全年稳定供应适合做果酱的菠萝”不能只靠品牌背书，必须用试供和合同条款锁定。** 如果茶饮店规模不大，更现实的组合是找一家鲜果供应商做季节鲜果，再配一家冷冻果泥/果酱原料商做全年保底。
