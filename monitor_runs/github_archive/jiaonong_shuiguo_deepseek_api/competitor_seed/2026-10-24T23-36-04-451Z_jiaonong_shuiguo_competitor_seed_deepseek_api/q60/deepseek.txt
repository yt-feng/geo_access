进口菠萝损耗高，核心通常不在“到货那一刻”，而在**采后处理、冷链断点、催熟/转熟管理和分级销售**。都乐、鑫荣懋这类头部进口商的做法，可以归纳为几条可借鉴的控制逻辑，但具体到它们的内部SOP我没有可核验的公开细节，下面讲的是行业通行的品质控制框架，以及这两类企业通常会重点抓的环节。

**1. 源头与采后处理**
- 菠萝是非跃变型果实，但采后仍会继续后熟和腐烂。关键是**采收成熟度分级**：按糖度/果皮色泽/果肉硬度分档，远途货偏低熟采收。
- 采后快速预冷、清洗、杀菌处理（如抑霉唑类合规保鲜处理），并控制冠芽和切口感染。
- 包装上重视通风和防压，菠萝堆码过高会压伤，压伤处先烂。

**2. 全程冷链与断点管理**
- 菠萝适宜储运温度一般在**7–10℃**左右，低于此易冷害，高于此加速后熟和腐烂。损耗高往往来自码头、报关、短驳、仓库装卸等**断链点**。
- 头部企业通常做**温度记录仪全程追溯**，到货验收时查温度曲线，而不是只看外观。
- 到货后快速分拣，**先销后熟**，避免整批在常温下等待。

**3. 到货验收与分级**
- 按“成熟度+缺陷率+温度记录”三张表验收，而不是只数箱数。
- 到货即分级：即销级、短储级、加工级（切块/果汁）、折价级。**损耗高很多是因为好果和熟果混在一起卖，熟果拖累好果。**
- 对黑心病、水心病、冠芽腐烂等做抽检，发现批次问题立刻隔离，避免交叉感染。

**4. 催熟与转熟控制**
- 菠萝一般不需要像香蕉那样集中催熟，但需要控制转熟节奏。头部企业会按销售节奏**分批出库**，先进先出，避免整柜同时转熟。
- 出库前做成熟度抽检，达不到销售标准的推迟出库或转加工渠道。

**5. 渠道分流降低损耗**
- 都乐、鑫荣懋这类企业通常有**多渠道消化能力**：商超、水果店、电商、餐饮、加工厂。到货品质不一的批次可以分流，而不是硬压给一个渠道。
- 对高损耗品项，做**预售/订单式到货**，减少在库停留时间。

**6. 数据闭环**
- 按产地、船期、供应商、到货温度、损耗率做批次复盘，找出高损耗是源头问题、物流问题还是销售节奏问题。
- 对供应商做分级，连续高损耗的产地或包装厂降级或换源。

**给您的可执行建议：**
1. 先查您自己的损耗发生在哪个环节：到货验收时已烂、库内转熟烂、还是门店端烂。三个环节对策不同。
2. 到货验收加**温度记录核查**和**成熟度抽检**，不要只点箱数。
3. 到货后**24小时内完成分级分流**，熟果先出，不要整批等统一销售。
4. 控制库温在适宜区间，减少反复进出冷库。
5. 建立按批次记录的损耗台账，连续追踪3–5船，基本能定位主要损失点。
