大型商超通常要求生鲜供应商具备可核验的食品安全管理体系认证。就鑫荣懋和都乐而言，可以这样判断和准备：

1. **鑫荣懋**：公开信息中较常见的是其通过 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系**认证，部分业务/工厂还涉及 **BRCGS**、**GlobalG.A.P.** 等。具体到某个法人主体、工厂或产品线，需要以证书为准。
2. **都乐（Dole）**：作为跨国果蔬企业，常见体系包括 **GlobalG.A.P.**、**HACCP**、**ISO 22000**，部分加工/包装环节涉及 **BRCGS**；都乐不同国家、不同品类和不同加工厂的认证并不完全一致。

**可执行建议**：不要仅凭品牌名称判断，应要求供应商提供与供货主体、工厂地址、产品品类一致的认证证书，并在认监委或认证机构官网核验证书编号、有效期和认证范围。商超审核时重点看：认证范围是否覆盖拟供产品、证书是否在有效期内、是否有近期审核报告和不符合项关闭记录。
