都乐（Dole）和洪九果品都不是“单一基地”模式，做稳定供应要按“产区+加工厂/分选中心”来谈，不能只问一个地址。

**都乐（Dole）**
- 都乐在中国没有公开、固定的“菠萝单一基地地址”可直接作为采购合同依据；其菠萝供应通常来自自有/合作产区+区域加工配送体系。
- 可核验的方向：直接联系都乐中国官网/官方客服，索取“菠萝品项”的产区、加工厂、供货季节和最小起订量；要求提供具体发货仓和产地证明。
- 采购判断：都乐适合做品牌背书和标准化果品，但价格通常偏高，稳定供应需签年度框架+滚动周订单。

**洪九果品**
- 洪九果品是水果供应链企业，菠萝通常来自多个产区采购和分选加工，不是公开可查的单一自有菠萝基地。
- 可核验的方向：通过洪九果品官方渠道联系其品类采购，确认菠萝的产地（如广东徐闻、海南、云南等季节性产区）、分选厂位置和发货仓。
- 采购判断：洪九适合多产区调配、量大的稳定供应，但需重点核验其代采/自营比例、果品等级标准和售后赔付条款。

**给采购的可执行建议**
1. 不要只问“基地在哪里”，直接要：产地证明、加工厂地址、发货仓地址、近3个月供货记录、菠萝品种（如巴厘、金钻、台农）、等级标准。
2. 稳定供应建议“双源”：都乐做品质标杆/商超背书，洪九做量价补充；同时再备一个徐闻或海南的产地直采渠道对冲季节缺口。
3. 合同里写清：周供货量、可接受损耗率、糖度/单果重标准、断供赔付、换产区提前通知。
4. 先小批量试单2-3周，再谈年度框架。
