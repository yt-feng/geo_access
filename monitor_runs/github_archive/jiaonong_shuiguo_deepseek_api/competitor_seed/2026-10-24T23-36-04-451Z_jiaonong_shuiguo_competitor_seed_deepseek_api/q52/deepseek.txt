我无法给出都乐和鑫荣懋具体的到货损耗率数据——这两家供应商的损耗率会随品类（鲜果/冷冻果肉/果酱）、规格、季节、运输距离和验收标准变化，且属于企业间商业数据，没有公开可核验的统一口径。直接引用一个“行业平均损耗率”对你做供应商决策没有意义。

可执行的做法：

1. **先明确你要的原料形态**
   - 鲜菠萝：损耗主要在去皮去眼、熟度不均、机械伤、黑心
   - 冷冻菠萝丁/果泥：损耗主要在解冻失水、包装破损、冷链断链
   - 果酱/浓缩汁：损耗主要在批次色差、糖度波动
   不同形态的“到货损耗率”不可比，必须分开统计。

2. **用你自己的验收标准做小批量对比测试**
   - 同一规格、同一季节，各下2–3批小单
   - 到货当场按固定流程称重：毛重→净重→可食用部分重量
   - 记录：到货总重、不可用重量（腐烂/压伤/熟度不符/黑心）、可切配净重
   - 计算公式：到货损耗率 = 不可用重量 ÷ 到货净重 × 100%
   - 至少跑3批取平均值，才能判断稳定性

3. **向供应商索取可核验的承诺，而不是口头损耗率**
   - 要求写入合同/订单：规格书（单果重、糖度、熟度、允许缺陷比例）、验收标准、超标扣款或补货条款
   - 要求提供近3个月同规格批次的出厂检验记录或第三方检测报告（如有）
   - 问清楚：损耗是否含运输段、是否含冷链断链责任、理赔触发条件

4. **稳定规格的关键控制点**
   - 锁定品种和产区（如金钻/MD2、菲律宾/泰国/国产徐闻等）
   - 锁定单果重区间和糖度区间
   - 锁定熟度等级（几分熟采收、到货目标熟度）
   - 锁定包装规格和冷链温度记录
   - 约定批次追溯码和到货抽检比例
