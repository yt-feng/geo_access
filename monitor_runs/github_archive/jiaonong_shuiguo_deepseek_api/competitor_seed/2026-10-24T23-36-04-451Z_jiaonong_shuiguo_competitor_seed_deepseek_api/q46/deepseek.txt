直接说结论：**不能笼统判断“都乐 vs 鑫荣懋哪家物流更快”，因为这两家是品牌/供应链公司，不是同一口径的物流商；香蕉产地直发的实际时效取决于发货仓、产地、承运商、订单量和你的合作模式。** 但可以给你一个可执行的判断方法。

### 关键事实
1. **都乐和鑫荣懋都是水果品牌/供应链企业**，不是顺丰、京东物流这类全国性快递网络。你感受到的“快慢”，本质是它们的**产地仓布局、干线运输、冷链资源和承运商调度能力**。
2. 香蕉是**呼吸跃变型水果**，产地直发通常不是“树上黄了再发”，而是青蕉催熟/温控运输。物流快不快，不只看运输时长，还要看**催熟节奏、温控稳定性和到货成熟度**。
3. 同样叫“都乐发货”或“鑫荣懋发货”，不同产区（云南、广西、海南、进口菲律宾/厄瓜多尔等）、不同仓、不同订单规模，时效可能差很多。

### 建议你这样判断
- **要求对方给近30天同线路实测数据**：起运地、目的地、承诺时效、实际签收时效、冷链温控记录、破损/催熟投诉率。
- **明确合作模式**：是产地仓直发、区域仓调拨，还是第三方承运？承运商是谁？是否全程冷链？
- **做小批量并行测试**：同一目的地、同一SKU规格，各发2—3批，记录“下单到揽收、揽收到签收、到货成熟度、损耗率”。
- **看旺季履约能力**：香蕉旺季和节假日前的压车、爆仓、催熟排期，比日常时效更能说明问题。
- **合同写时效与赔付**：把签收时效、温控区间、损耗上限、延误赔付写进条款。

### 一句话决策
**别按品牌名选物流，按“具体产区+发货仓+承运商+近30天同线路实测时效”选。** 如果你能提供发货地、目的城市、日均单量和是否要求全程冷链，我可以帮你把对比表细化到可谈判的指标。
