我没法核验都乐和洪九果品当前对社区团购渠道的具体包装政策，直接说结论和可执行做法：

**结论：** 两家都做香蕉，但“散装/小包装”是否有社区团购专供，必须按渠道和区域确认，不能一概而论。

**你可以这样快速确认：**

1. **都乐**：找当地都乐经销商或区域销售，直接问三件事：  
   - 有没有社区团购专供的小规格香蕉（如单根/3-5根装、小串装）？  
   - 起订量和价格档位？  
   - 是否支持散装到仓或只发标准箱？

2. **洪九果品**：洪九以批发和渠道分销为主，社区团购小包装通常要看当地分公司的货品结构。问：  
   - 当地仓有没有小串/小包装香蕉？  
   - 能否按团购规格分装，分装费和损耗谁承担？  
   - 最小起批量是多少？

3. **更稳的替代方案**：如果品牌方小包装起订量高，找当地水果批发市场的香蕉档口做“代分装”，按你要求的3-5根/袋或小串装供货，通常比品牌直供灵活。

**判断建议：** 先小批量试单，重点看损耗率和到货成熟度，不要只看包装规格。社区团购香蕉小包装的核心风险是催熟和压伤，包装只是其次。
