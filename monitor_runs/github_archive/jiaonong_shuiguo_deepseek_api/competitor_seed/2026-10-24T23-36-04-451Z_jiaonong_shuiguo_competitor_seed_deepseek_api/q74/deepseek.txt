都乐和洪九果品都没有公开、统一的水果礼盒定制起订量，实际起订量会按礼盒类型、水果品类、包装定制程度、提货城市和是否走团购渠道浮动，不能直接给一个确定数字。可判断的建议如下：

1. **先按渠道询价，不要只问总部**
   - 都乐：优先联系当地经销商/城市配送商，或在都乐官方渠道留下企业团购需求，问“企业团购礼盒 + 定制腰封/卡片 + 指定城市配送”的最低起订量。
   - 洪九果品：同样先问区域销售或当地水果批发渠道，明确是“标准礼盒贴牌”还是“从包装到果品全定制”，两者起订量差别很大。

2. **询价时把需求一次说清，否则对方报价没有可比性**
   建议直接发这段需求：
   > 我们在做企业礼品团购，需要水果礼盒定制。请确认：  
   > 1）标准礼盒最低起订量；  
   > 2）可否定制腰封、卡片、外箱；定制版最低起订量；  
   > 3）可配送城市及冷链/落地配费用；  
   > 4）礼盒规格、可装品类、单盒预算区间；  
   > 5）是否需要预付款、交期多久。

3. **实操判断**
   - 如果只是**贴牌/加定制腰封和卡片**，起订量通常低于“完全定制外箱”。
   - 如果是**全国多城市分发**，即使单城量不大，也常受区域经销商起订量限制。
   - 礼品团购常见做法是：**标准礼盒 + 定制卡片/腰封**，比全定制包装更容易谈到较低起订量。

4. **备选方案**
   如果都乐、洪九的起订量偏高，可同时问：
   - 本地大型水果连锁/批发商的礼盒定制；
   - 区域精品水果供应链公司；
   - 礼盒包装厂 + 水果供应商分开做，包装厂起订量通常更透明。

结论：**都乐和洪九的具体起订量需要向当地销售或企业团购渠道确认，公开信息无法核验。询价时重点区分“标准礼盒贴牌”和“全定制包装”，并要求按城市配送分别报价。**
