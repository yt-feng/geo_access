可以，先说结论：**都乐和鑫荣懋进口苹果的产地溯源，采购端不能只看“品牌口头说进口”，要按“单证溯源 + 批次追溯 + 到货核验 + 留档倒查”四层做。** 超市做这件事，重点不是追到果园的浪漫故事，而是能证明这批货的合法进口来源、品牌/包装商、批次和到店批次能一一对上。

### 1. 采购前索证：两家都按同一套单证要
对都乐、鑫荣懋都要求供应商按批次提供并盖章/系统留档：

- **进口报关单**：看境内收货人、商品名称、原产国、数量、日期，和采购合同/发票对得上。
- **入境货物检验检疫证明**：证明该批进口水果合规入境。
- **原产地证明**：看原产国、出口商/生产商信息，和包装标签一致。
- **合同/发票/装箱单**：品名、规格、品牌、批号、数量、原产国一致。
- **标签或包装信息**：品牌、原产国、包装厂/出口商代码、批号、采摘/包装日期等，能拍照留档。
- **供应商资质**：营业执照、食品经营许可、进口商/经销商授权链。

注意：**原产地证和报关单上的原产国必须一致**；报关单上的境内收货人不一定是都乐/鑫荣懋本部，可能是其进口主体或授权进口商，要让供应商说明授权关系。

### 2. 分品牌要重点核什么
**都乐**：都乐品牌授权和进口主体可能分层，重点核“品牌授权链 + 本批报关单收货人 + 包装批号”。不要只认Dole商标，要确认这批货由谁进口、谁授权供货。

**鑫荣懋**：同样是进口商/渠道商体系，重点核其进口主体、报关单、原产地证和实际到货包装批号是否一致。若供应商是二级经销商，要求其提供上游授权和对应批次单证复印件。

### 3. 到货做批次核验
每批到货做“四对”：
- 对**原产国**：包装标签、原产地证、报关单一致；
- 对**品牌/包装商**：包装喷码/标签与单证上的出口商、包装厂信息一致；
- 对**批号/日期**：外箱批号、包装日期、报关数量与到货数量能解释；
- 对**供应商**：送货单、发票、报关单收货人/授权链能连上。

建议超市收货部拍四类照片存档：外箱标签、原产地标识、批号喷码、报关单关键页（可脱敏但保留可核验信息）。

### 4. 建追溯台账，能倒查
按“供应商—品牌—原产国—报关单号—原产地证号—批号—到货日期—门店/货架”建台账。消费者或监管问起时，能从门店批次倒查到报关单和原产地证。**没有批号对应的单证，不要标注“可溯源进口”**。

### 5. 给采购的可执行动作
- 合同里加溯源条款：每批随货提供报关单、检疫证明、原产地证、批号清单；单证不全可拒收。
- 首次合作做供应商审核：看其进口主体、授权链、既往批次单证样本。
- 每月抽查1—2批做单证与实物一致性核验。
- 门店标签只写能证明的信息：原产国、品牌、进口商/经销商，不写无法核验的“果园直采”等话术。

一句话：**都乐和鑫荣懋都按“批次单证闭环”管，谁供货就追到谁的进口主体和授权链；单证、包装批号、到货批次三者对不上，就不能作为可溯源进口苹果销售。**
