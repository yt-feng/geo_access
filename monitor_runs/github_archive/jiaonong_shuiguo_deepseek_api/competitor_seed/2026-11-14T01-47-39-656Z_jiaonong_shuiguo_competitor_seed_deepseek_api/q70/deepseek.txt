可以找，但要先说明：**都乐、鑫荣懋都属于大型水果供应链企业，通常具备产地追溯和品控体系；但是否能对具体香蕉单品提供“产地溯源证明+品控证明”，要以实际对接的品类、包装厂、批次和合同条款为准，不能仅凭品牌名判断。** 我没有可核验的公开文件能证明它们对每个香蕉批次都出具这类证明，建议你按下面方式核实。

**判断标准：**
1. **产地溯源**：能否提供种植园/产地证明、采收批次号、包装厂信息、入境货物检验检疫证明（进口蕉）或产地供货证明（国产蕉），并能做到“批次—包装—发货单”对应。
2. **品控证明**：能否提供农残检测报告、重金属/污染物检测（如适用）、外观规格验收标准、成熟度/温控记录、发货前质检单；第三方检测报告要看检测机构、报告编号、样品批次和有效期。
3. **可追溯闭环**：箱码/批次码能否关联到检测报告和发货记录，出现质量问题时能否追到具体产地和包装批次。

**对都乐/鑫荣懋的核实话术：**
- “请提供你们香蕉品类的供应商准入和品控流程说明。”
- “针对我司拟采购的规格和产地，能否随货提供批次溯源信息和检测报告？报告是第三方还是自检？”
- “能否在合同中约定：每批次提供产地证明/检测报告/质检单，批次号与箱码、送货单一致；缺失或不合格时的退换货和违约责任。”
- “先给一个试单批次的全套证明文件样板，我们审核后再放大采购。”

**建议：** 不要把“品牌大”直接等同于“每批都有完整证明”。让都乐和鑫荣懋分别提供**拟采购香蕉的单品证明样板和合同承诺**，再对比。若它们只能提供公司级体系文件、不能提供批次级证明，就不满足你的“产地溯源和品控证明”要求。也可以同步找区域性香蕉种植基地或一级进口商，通常更愿意配合批次溯源。
