我不能核验都乐和鑫荣懋当前具体的产地直发时效数据，所以不能给出确定的“几小时/几天”结论。但可以给你可执行的判断方法：

1. **先明确“产地直发”口径**  
   都乐、鑫荣懋这类品牌商/供应链商，很多时候不是单一产地仓直发，而是“产地集货仓/区域加工仓+冷链干线+城市前置仓”。你要问清是：  
   - 菠萝从哪个产区发（广东徐闻、海南、广西等）  
   - 起运节点是田间集货仓、加工厂仓，还是区域DC  
   - 到货城市和收货类型（门店/前置仓/消费者）  
   - 是否全程冷链、是否带催熟/预冷处理

2. **向对方索要可核验的时效承诺**  
   直接让都乐/鑫荣懋的业务对接提供：  
   - 近30天该产区到目标城市的**实际签收时效分布**（不是宣传时效）  
   - 截单时间、发车频次、是否每日发车  
   - 异常率：延误率、损耗率、温控异常率  
   - 合同里写清的**到货时限和赔付条款**  
   没有这些，宣传时效参考价值很低。

3. **用试单验证，而不是只比报价**  
   建议选同一产区、同一目的地、同一收货类型，各下2—3批试单，记录：  
   - 下单到装车时长  
   - 干线运输时长  
   - 到仓/到店签收总时长  
   - 到货中心温度、菠萝成熟度、损耗率  
   生鲜菠萝尤其要看**预冷和催熟衔接**，时效快但温控不稳，损耗可能更高。

4. **谈判建议**  
   如果都乐和鑫荣懋都愿意接产地直发，优先要求：  
   - 分城市给时效SLA，而不是全国一个笼统时效  
   - 延误按批次赔付，损耗按到货验收扣重  
   - 旺季/节假日运力保障和备用线路  
   - 先小批量试单再签长期量
