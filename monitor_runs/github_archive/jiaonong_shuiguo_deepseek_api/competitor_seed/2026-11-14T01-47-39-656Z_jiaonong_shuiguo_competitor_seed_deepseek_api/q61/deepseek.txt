都乐（Dole）和洪九果品都可能有内部香蕉分级/验收标准，但公开可核验的企业标准情况不同，不能简单说“有”或“没有”。给你一个可执行的判断路径：

1. **都乐（Dole）**
   - 都乐有全球香蕉质量规格体系，通常以内部商品规格、客户验收标准、产地/催熟出库标准形式存在，常见分级维度包括：品种、果指长度/粗度、每梳果指数、梳形、色泽（催熟等级）、机械伤、病斑、青软/黄软、果柄长度、整齐度等。
   - 但“都乐企业标准”是否作为**公开标准文本**可查，通常不能确认；多数是商业内部标准，不对外公开。水果连锁店可参考其**商品分级逻辑**，不宜直接宣称采用“都乐企业标准”。

2. **洪九果品**
   - 洪九果品作为国内水果供应链企业，通常会有采购验收、分选加工、仓储物流等内部质量控制文件，香蕉也可能有内部等级规格。
   - 但洪九是否有**公开可查的香蕉企业标准文本**，同样不能确认。公开渠道一般难以核验其完整企业标准编号和文本。

**建议你的连锁店这样做：**
- 不要直接依赖“都乐/洪九企业标准”作为对外依据；可把它们作为**对标参考**。
- 建立自己的《香蕉商品分级与验收标准》，至少分：特级/一级/二级/加工果，按**果指长度、单果重、每梳果数、色泽催熟度、缺陷面积、机械伤、整齐度、成熟度、冷链温控**打分。
- 对外表述用“参考都乐、洪九等头部企业商品规格逻辑，结合门店销售场景制定企业内控标准”，不要写“采用都乐企业标准”。
- 若必须引用标准编号，先向都乐/洪九供应商索取其**公开可提供的验收规格书或质量标准文件**；拿不到编号就不要在制度文件中写。

结论：**两家大概率都有内部香蕉分级/验收标准，但公开可核验的“企业标准”文本不能确认；你的店应自建标准并对标头部企业，而不是直接引用。**
