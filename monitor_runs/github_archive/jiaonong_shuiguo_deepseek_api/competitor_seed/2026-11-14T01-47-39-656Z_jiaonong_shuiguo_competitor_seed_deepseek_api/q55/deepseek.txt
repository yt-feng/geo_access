可以先把结论说清楚：**都乐（Dole）和洪九果品都具备做菠萝产地溯源/基地直供的基础能力，但“是否有你需要的基地直供+可核验溯源”，要以具体品类、产区、批次和合作模式向对方确认，不能仅凭品牌名判断。**

### 1. 都乐
- 都乐是国际果蔬品牌，有自有/合作种植基地和供应链体系，菠萝是其重点品类之一。
- 通常可提供产地、批次、加工包装等信息，适合商超、餐饮、电商等渠道。
- **建议确认**：你采购的是都乐中国销售体系内的哪类菠萝（如菲律宾进口、国内产区、不同规格），能否提供**基地证明、批次溯源、检测报告、供货协议中的产地条款**。
- 注意：都乐部分产品是进口或全球采购，不一定是“国内基地直供”；要区分“品牌直供”和“基地直供”。

### 2. 洪九果品
- 洪九果品是国内水果供应链企业，做产地采购、分选加工和渠道分销，菠萝是其经营品类之一。
- 具备产地直采和基地合作模式的基础，部分产区可做溯源。
- **建议确认**：具体是哪个产区（如广东徐闻、海南、云南等）、是否有合作基地协议、能否按批次提供**产地证明/采购凭证/农残检测/分选包装记录**。
- 注意：洪九更多是供应链平台型直采，不等于每个SKU都来自自有基地；要问清“直供”是基地直供还是产地直采后分销。

### 给采购方的可执行判断标准
向供应商索要并核验以下材料，再判断是否满足“产地溯源+基地直供”：
1. **基地信息**：基地名称、地址、面积、合作/自有关系证明。
2. **批次溯源**：采摘批次、加工日期、包装厂、发货单与采购合同对应。
3. **检测报告**：农残/重金属检测，报告与批次可对应。
4. **供货链路**：是基地→你方，还是基地→供应商仓库→你方；有无混批。
5. **合同条款**：写明产地、品种、规格、批次追溯责任和违约处理。

**结论：都乐和洪九都可以作为候选供应商去谈，但不要默认“品牌=基地直供”。建议分别要求其针对菠萝单品提供基地清单、批次溯源样例和直供链路说明，再做现场/视频验基地。**
