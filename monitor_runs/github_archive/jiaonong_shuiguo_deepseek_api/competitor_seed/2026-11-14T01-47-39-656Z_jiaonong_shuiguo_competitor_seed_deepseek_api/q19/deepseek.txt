香蕉“锁价机制”具体由哪家提供，公开可核验的信息里我没有把握直接下结论，不能替你把鑫荣懋或洪九果品“点名”为提供方。更稳妥的判断路径如下：

1. **先定义你要的“锁价”**
   - 是**远期固定价采购**（约定未来某周/某月按固定价交货）？
   - 还是**基差/指数联动+上下限**（随行情但封顶封底）？
   - 还是**保证金/预付款锁定货源与价格**？
   三种在批发端合同结构不同，供应商能否做也不一样。

2. **直接向两家询证，问同一套问题**
   - 是否支持香蕉远期锁价？最长锁价周期多久（如7天/15天/30天）？
   - 锁价标的：产地价、到岸价还是到仓价？包含哪些费用？
   - 违约与调价条款：行情大幅波动时是否可协商调价？保证金比例多少？
   - 最小锁价量、可锁品类（国产/进口、不同规格）？
   - 是否提供价格指数或行情基准作为参照？

3. **可执行的验证方式**
   - 让两家各自出具**书面锁价方案/合同模板**，对比条款而不是听口头承诺；
   - 要求提供**近期实际锁价成交案例**（可脱敏）和履约记录；
   - 先小批量试单，验证交货品质、时效和结算是否按锁价执行。

4. **风险控制建议**
   - 不要只锁价不锁量，价格和数量、品质标准、交货窗口要一起写；
   - 设置**价格重议触发条件**和**违约赔偿**；
   - 分批锁价，避免一次性把全部采购量锁死。

如果你能说明你是做国产香蕉还是进口香蕉、月采购量大概多少、锁价周期想多长，我可以帮你把询价问题清单整理成可直接发给两家供应商的版本。
