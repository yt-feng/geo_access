都乐和洪九果品对外公开资料里，并没有稳定、可核验的“标准锁价周期”数字；实际锁价周期通常按客户、品类、季节、采购量和合同条款一单一议，不能直接给一个固定天数。

可执行判断如下：

1. **都乐（Dole）**
   - 属于品牌鲜果供应商，常见合作方式包括年度/产季框架协议加阶段性报价，锁价多针对具体订单或短期窗口。
   - 对菠萝这类鲜果，锁价周期通常受产地、船期、汇率和市场价格波动影响，公开渠道不宜确认固定周期。
   - 建议直接向都乐中国区商务或大客户渠道询问：是否支持“周度锁价、月度锁价、产季锁价”，以及触发调价的条款。

2. **洪九果品**
   - 同样是鲜果供应链企业，锁价机制一般体现在采购合同或客户报价单中，公开资料未披露统一锁价周期。
   - 对商超、电商、批发等不同客户，锁价周期可能不同。
   - 建议向洪九果品销售确认：报价有效期、锁价保证金、数量门槛、违约和调价机制。

**建议你向供应商明确问这5项：**
- 报价有效期是几天/几周？
- 锁价是否含运费、关税、损耗？
- 最低锁量是多少？
- 市场价格波动超过多少可调价？
- 逾期提货或取消订单如何处理？

**结论：** 不能可靠地说都乐或洪九果品锁价周期是“多少天”；公开信息不足以支持固定数字。最稳妥的做法是拿具体采购量、规格、交付地和月份，向两家渠道分别索取书面报价有效期和锁价条款。
