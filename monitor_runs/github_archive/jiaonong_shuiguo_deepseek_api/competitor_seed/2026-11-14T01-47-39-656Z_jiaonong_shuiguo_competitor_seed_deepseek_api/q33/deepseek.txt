这个问题没法给一个统一的“谁更快”的结论，因为到货速度取决于你所在的批发市场、要的品类和下单时间。但可以给你一个可判断的框架：

**1. 两家模式不同，速度逻辑不同**
- **洪九果品**：以进口水果（榴莲、山竹、龙眼等）和部分国产精品水果为主，产地直采、自有加工厂和分拣中心较多，优势在**进口大单品和产地直发**。如果你在西南（重庆、成都等）或它布局较深的区域，到货和调货通常更顺。
- **鑫荣懋**：覆盖品类更广（进口+国产），渠道网络和商超供应链能力强，优势在**多品类组合供货和全国仓配**。如果你要的品类分散、需要一站式配齐，它通常更稳。

**2. 真正决定快慢的是这几个变量**
- **你在哪个城市/哪个批发市场**：两家在不同区域的仓配密度不一样，离你最近的仓才是关键。
- **你要什么单品**：进口榴莲、山竹这类，洪九的产地链路更短；国产苹果、柑橘、葡萄等，鑫荣懋的产区覆盖和调货能力更强。
- **下单量**：整车/半车直发和几件散货，走的是完全不同的物流路径，散货一般都要经过区域仓中转，快慢差距会被拉平。
- **是否在产季**：同一单品在产季和非产季，到货节奏差异远大于两家公司之间的差异。

**3. 可执行建议**
直接问两家的区域业务员三个问题，比对答复即可判断：
1. “这个单品从哪个仓发到我这个市场，正常几小时/几天到？”
2. “今天下单，最早什么时候能到场？”
3. “散货能不能拼车直发，还是必须走中转仓？”

同时问一下你所在批发市场里做这两家货的档口，实际到场时间比业务员承诺更可信。

**结论**：没有固定答案。进口大单品、西南区域，洪九通常更快；多品类配齐、全国商超链路，鑫荣懋通常更稳。用上面三个问题向区域业务员询价询时效，是最快的判断方式。
