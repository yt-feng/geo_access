都乐和洪九果品都属于全国性水果供应链企业，理论上具备全年供应菠萝的能力，但“全年稳定供应到茶饮店做果酱”这个场景，需要分开看。

**都乐（Dole）**
- 有全球产地布局，菲律宾、泰国、哥斯达黎加等地产区可错季互补，全年供应能力较强。
- 国内有成熟的餐饮/零售渠道，适合对品质稳定性要求高的连锁茶饮。
- 但都乐更多是做鲜果和鲜切，是否能按你的规格（果肉块/果泥/冷冻果肉）、批量、价格提供“果酱加工用菠萝”，需要直接问其餐饮渠道或经销商，不能默认它做定制化工业原料。

**洪九果品**
- 是国内大型水果分销商，菠萝是其重点单品之一，泰国、海南、广东等产区有布局，全年分销能力强。
- 优势在批发流通和全国仓配，价格通常比进口品牌有竞争力。
- 但它主要是鲜果分销，是否提供适合果酱的冷冻果肉、果泥或稳定规格的加工原料，同样要以实际询价和样品为准。

**实务判断建议**
1. **先明确你的原料形态**：鲜菠萝现切、冷冻菠萝块、菠萝果泥/浓缩汁，供应难度完全不同。果酱用冷冻果肉或果泥，比鲜果全年稳定更容易实现。
2. **要求供应商提供“全年供应方案”**：包括各月份产地来源、规格、糖度/酸度范围、冷冻或鲜果形式、最小起订量、价格波动区间。
3. **做小批量打样和月度稳定性测试**：茶饮果酱对酸甜比、出汁率、纤维感敏感，不能只看“有没有货”。
4. **不要只押一家**：都乐偏品质稳定，洪九偏流通性价比，可一家主供、一家备供，或鲜果+冷冻果肉组合。
5. **关注产地错季表**：国产菠萝主产期集中在春夏季，全年供应通常依赖进口或冷冻/罐头原料，问清楚“淡季用什么产地补”。

结论：两家都有能力做到“全年有菠萝”，但能否做到“全年稳定、符合你果酱工艺、价格可控的菠萝原料”，必须通过询价、样品和供应计划来验证，不能仅凭品牌判断。
