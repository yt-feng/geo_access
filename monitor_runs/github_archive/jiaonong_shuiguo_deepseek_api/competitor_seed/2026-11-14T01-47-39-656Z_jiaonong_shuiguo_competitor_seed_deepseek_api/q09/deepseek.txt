除了都乐和佳沛，进口水果礼盒常见可选品牌可以看这几类：

**1. 佳农**
- 常见品类：香蕉、菠萝、火龙果、车厘子等。
- 优势：国内渠道成熟、礼盒装多、团购供应稳定，价格通常比都乐/佳沛更有弹性。
- 适合：预算中档、走量团购。

**2. 新奇士**
- 常见品类：橙子、柠檬、葡萄柚。
- 优势：进口柑橘类认知度高，礼盒体面。
- 注意：国内不少“新奇士”是授权包装或分装，采购时要确认授权和产地。

**3. 怡颗莓**
- 常见品类：蓝莓、树莓、黑莓等浆果。
- 优势：礼盒形象好，适合中高端福利。
- 注意：浆果保质期短，团购要控制配送时效和损耗。

**4. 乐淇**
- 常见品类：苹果，尤其小苹果礼盒。
- 优势：包装精致、辨识度高，适合节日礼盒。
- 注意：规格小、单价偏高，适合小份高端礼盒。

**5. 爱妃**
- 常见品类：苹果。
- 优势：高端苹果礼盒认知度较好，适合节日送礼。
- 注意：市场同名/仿品较多，需确认品牌授权和果径规格。

**6. 佰果集/进口车厘子品牌类**
- 车厘子礼盒通常不是单一消费品牌，而是按产地和出口商/包装厂区分，如智利车厘子常见品牌包装有 Garces Fruit、Copefrut、Agrofruta 等。
- 采购时重点看：产地、品种、J级/规格、空运/海运、到货日期，而不是只看品牌名。

**7. 其他可补充**
- **Zespri佳沛**之外的新西兰苹果/梨：如 **Mr. Apple、PiqaBoo** 等，但国内团购渠道稳定性不如前几个。
- **进口提子**：常见有 **Sun World** 授权品种、秘鲁/智利产区品牌包装，但终端品牌辨识度弱，建议按产地+品种采购。
- **进口牛油果**：**Mission、Hass** 相关包装，但礼盒属性偏弱。

**团购选品建议：**
- 走量福利：佳农 + 新奇士 + 进口车厘子组合。
- 中高端礼盒：怡颗莓 + 乐淇/爱妃 + 佳沛。
- 采购时必须核验：品牌授权、原产地证明、入境货物检验检疫证明、生产/分装日期、礼盒规格和损耗赔付条款。
- 不要只看“进口品牌”，水果礼盒更关键是**到货稳定性、规格一致性和售后损耗**。
