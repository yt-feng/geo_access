目前没有可核验的公开资料能证明鑫荣懋和都乐在“超市采购香蕉”这一场景下谁的分级更细；这类信息通常体现在各自的**企业内控标准、供货合同附件或门店收货规格书**里，公开宣传材料不足以做可靠比较。

可执行判断建议：

1. **先定你超市的用途**：是散称零售、精品陈列、还是餐饮/加工。用途不同，需要关注的不是“谁分级更细”，而是“谁的等级设置能匹配你的陈列和损耗要求”。
2. **直接索取规格书对比**：向两家供应商各要一份香蕉供货规格表，重点看是否明确了以下维度：
   - 按根/把/箱的等级划分层数；
   - 单根重量或每把根数区间；
   - 长度/粗度区间；
   - 成熟度（色卡/催熟阶段）分级；
   - 外观缺陷允许度（黑斑、机械伤、果指弯曲度等）；
   - 箱规、净重、允许损耗率。
3. **用同一张表打分**：把两家规格书按上述维度逐项对照，分级层数多且区间定义清楚的一方，对你而言就是“更细”。不要只看品牌名气。
4. **小批量试收验证**：各下一个小单，按你的收货标准实测到货合格率、等级混杂率和损耗，连续2—3批再定。
5. **注意区域差异**：同一品牌不同产区、不同配送中心执行标准可能不同，应以**你所在区域实际供货主体的书面规格**为准。

结论：无法据公开信息判定哪家分级更细；建议用“索取规格书+同表对比+试收验证”的方式做采购决策。
