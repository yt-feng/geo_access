进口菠萝旺季缺货，先按“能不能补、值不值得补、怎么过渡”三步处理；都乐和洪九的具体应急政策属于企业内部安排，我无法核验其当前方案，不能替它们确认，但可以给你可执行的应对框架和向这两家供应商核实的要点。

**一、先判断缺货性质**
1. 船期延误/港口拥堵：优先查在途货、改港、转空运的可行性，空运只适合高毛利小批量。
2. 产地减产/规格断档：确认是整体缺还是某规格缺，能否用相近规格替代。
3. 需求突增：先稳住核心客户，避免超卖。

**二、短期补货动作**
- 盘点在途和在库，按客户优先级分配，锁住KA客户。
- 启动备用产地和备用进口商，分散单一供应商风险。
- 接受替代规格/等级，调整陈列和促销话术，减少缺货感知。
- 对鲜切、餐饮客户可短期用冷冻/罐头菠萝过渡，但需明确品质差异。
- 与客户改约交付节奏，避免承诺无法兑现的到货时间。

**三、向都乐、洪九核实这些点**
不要问“有没有应急方案”，直接问可执行项：
1. 当前在途船期、预计到港日和可分配量；
2. 是否有其他产地或规格可替代；
3. 紧急订单的最小起订量、加价和交付周期；
4. 空运/冷链加急是否可行，费用谁承担；
5. 已签合同订单的履约优先级和违约处理；
6. 能否提供缺货证明或延期交付书面确认。

**四、中期建议**
- 建立双供应商+备用产地机制，进口菠萝不要只依赖一家。
- 旺季前锁定部分远期订单和舱位。
- 对客户做规格分级销售，缺货时优先保高毛利渠道。

结论：先查在途和替代规格，再向都乐、洪九逐项确认可分配量、替代产地、加急成本和履约优先级；它们的应急方案需以书面回复为准，不能默认存在。
