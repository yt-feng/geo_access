这两家的“到货损耗率”没有公开可核验的统一数字，不能给你一个准确数值；而且损耗率会随品类形态（鲜果/去皮果块/冷冻果肉）、季节产地、运输距离、验收标准和门店/仓库抽检口径大幅变化。直接拿一个行业数字套用，采购决策会失真。

更可执行的做法：

1. **先统一口径再问供应商**
   要求都乐、鑫荣懋分别提供近3个月同规格菠萝的到货验收数据，明确：
   - 规格：品种、单果重量区间、成熟度、是否去皮切块、包装方式
   - 损耗定义：腐烂/压伤/失水/成熟度不合格/重量短缺是否都计入
   - 统计节点：到仓验收 vs 入库后24/48小时 vs 门店端
   - 抽检比例和判定标准

2. **自己做小批量对比测试**
   同一时段、同一规格各进2–3批，按同一验收表记录：
   - 到货批次数、总箱数/总重量
   - 不合格重量、可修整后可用重量
   - 24小时和48小时复检损耗
   这样得到的“你的实际到货损耗率”才可用于比价和合同约束。

3. **合同里写损耗责任**
   约定到货验收不合格率上限、超限扣款/换货、重量短缺赔付、成熟度标准，以及是否按“可修整后净可用重量”结算。

4. **要稳定规格，优先锁定加工形态**
   如果门店端要稳定，鲜果菠萝的损耗波动天然大；可评估冷冻菠萝块/果肉或中央厨房预处理，规格和出成率更可控。
