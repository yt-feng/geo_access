可以要，但不能默认“品牌大就一定随货附农残报告”，需要在下单前书面确认。对都乐和鑫荣懋这类大型水果企业，通常具备检测能力或可提供批次检测资料，但是否给茶饮店随批次提供、是否免费、报告类型和批次对应关系，要按采购渠道确认。

建议你按下面执行：

1. **先问供应商要“本批次农残检测报告”**
   - 明确要：检测报告须对应你实际收货的批次/产地/日期。
   - 报告类型优先：第三方检测机构出具、带CMA标识的农残检测报告。
   - 至少覆盖：GB 2763 中菠萝相关农残限量项目；如你们有企业内控，再加内控项。
   - 报告上要有：样品名称、批次/生产日期、检测项目、结果、判定、检测机构盖章。

2. **分别确认渠道，不要只问品牌总部**
   - 都乐：确认你对接的是都乐直供、区域经销商还是批发市场档口。直供/大型经销通常更容易拿到批次报告；批发档口可能只能给复印件或上游报告。
   - 鑫荣懋：同样确认直供还是经销。连锁茶饮采购量较大时，可在合同里约定“每批次随货提供农残检测报告或电子版”。
   - 若对方说“每批都有”，要求先发一份近期同品类报告样例，确认格式和检测项目。

3. **合同/订单里写清楚**
   建议写：
   - 供方须随货提供对应批次的农残检测报告电子版或纸质版；
   - 报告须由具备CMA资质的第三方检测机构出具，检测项目符合GB 2763；
   - 无法提供时，买方有权拒收或要求换货；
   - 每季度/每半年提供一次型式检测报告，批次报告随货。

4. **到货核对**
   - 报告批次号、收货日期、品种是否对得上；
   - 报告是否为复印件模糊、过期或“通用报告”；
   - 保留收货单、报告和样品照片，便于追溯。

结论：**都乐和鑫荣懋一般“可以谈得到”检测报告，但是否能随每批次免费提供，取决于你的采购渠道和合同约定。采购前书面确认并写入订单，是最稳妥的做法。** 如果对方只能提供年度报告、不能对应批次，就不满足茶饮店农残溯源要求，建议换供应商或要求补做第三方检测。
