都乐（Dole）和鑫荣懋（Joy Wing Mau）进口苹果的产地溯源，核心是**“单证链+批次码+到货验收”三件套**。超市采购不需要自己做全链条溯源，而是把供应商的溯源能力变成可验收的条款和单据。

**一、先分清两家供应商的性质**

- 都乐：全球品牌商/进口商，通常自有或指定海外果园、包装厂，国内由都乐中国或其经销商供货，溯源体系相对标准化。
- 鑫荣懋：国内大型水果供应链企业，进口苹果多为全球采购后分销，可能同时经营多个海外产区（如新西兰、美国、智利、南非等），溯源要落到“具体批次对应哪个海外供应商/包装厂”。

**二、采购合同里必须写死的溯源条款**

1. 每批次提供**原产地证明**（Certificate of Origin），注明国家、产区、果园/包装厂注册号（如适用）。
2. 提供**植物检疫证书**（Phytosanitary Certificate），证书号与报关单对应。
3. 提供**入境货物检验检疫证明**及**海关报关单**，报关单上的品名、原产国、数量、日期要与到货批次一致。
4. 包装箱/托盘上必须有**可追溯批次码**（Lot No. / Batch Code），并能由供应商反查到：海外包装厂→出口商→海运/空运提单→国内入境口岸→配送仓。
5. 约定**追溯响应时限**：出现质量或舆情问题时，供应商须在24–48小时内提供该批次完整溯源链书面说明。

**三、到货验收时的操作**

- 核对包装箱批次码与随货单证、报关单是否一致，不一致拒收或暂扣。
- 抽取箱码拍照存档，建立超市内部“批次-供应商-到货日期-门店流向”台账。
- 对都乐可要求提供其全球批次查询入口或批次证明；对鑫荣懋要求提供该批次对应的海外供货商及包装厂信息，不能只给“鑫荣懋采购”这一层。
- 首次合作或新产区，要求供应商提供**溯源演示**：随机给一个箱码，看能否在约定时限内返回完整链条。

**四、日常管理建议**

- 把溯源单据作为**付款条件之一**，缺单证不结算。
- 每季度抽查1–2个批次做“逆向追溯”演练。
- 门店端价签/溯源二维码如要做消费者展示，只用供应商书面确认的信息，不自行推断产区。
- 对都乐和鑫荣懋分别建立供应商档案，记录其常供产区、包装厂代码、历史追溯响应表现。

**关键判断标准**：溯源是否合格，不看供应商品牌大小，而看**“给定一个箱码，能否在约定时间内闭合到海外包装厂和入境报关单”**。做不到这一条，就要求整改或调整采购批次。
