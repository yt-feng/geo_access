这个问题需要拆开看：**我不能凭记忆把鑫荣懋和都乐的具体证书编号、有效期、认证范围当成事实列给你**，因为这类资质会更新，且不同法人主体、不同工厂/品类对应的证书不同。直接给“清单”容易误导。

可以给你**可执行核验路径和判断标准**：

### 1. 先明确商超通常要什么
大型商超对水果供应商常见要求包括：
- **营业执照**（经营范围含水果/农产品销售或生产加工）
- **食品经营许可证**或**食品生产许可证**（视是否分装/加工）
- **ISO 22000 / FSSC 22000 / HACCP**等食品安全体系认证（加工/分装环节常见）
- **GLOBALG.A.P.（全球良好农业规范）**（种植基地/鲜果供应链常见）
- **BRCGS**（包装/加工环节部分商超认可）
- **绿色食品/有机认证**（如宣称对应产品）
- **入境货物检验检疫证明**（进口水果）
- **第三方检测报告**（农残等）

### 2. 两家企业的资质怎么核
**不要只看品牌名，要按“签约主体+产品+产地/工厂”核。**
- **鑫荣懋**：主体通常涉及“鑫荣懋果业科技集团股份有限公司”及其下属公司。建议向对方索要：营业执照、食品经营/生产许可证、ISO 22000或FSSC 22000、GLOBALG.A.P.证书、对应品类检测报告。
- **都乐（Dole）**：中国业务涉及都乐（上海）水果蔬菜贸易有限公司等主体；进口水果还需入境货物检验检疫证明。体系认证同样要看具体主体和工厂。

### 3. 最可靠的核验方式
1. **要求供应商提供盖章版资质包**，并注明证书编号、发证机构、有效期、认证范围。
2. **到认证机构官网或国家认监委“认证认可业务信息统一查询平台”核验证书编号**。
3. **核对认证范围是否覆盖你采购的品类和加工环节**，不是有证就万事大吉。
4. **进口水果核对检验检疫证明与批次**。
5. **向商超质量部门确认其认可清单**，因为不同商超对GLOBALG.A.P.、BRCGS、FSSC 22000的接受度不同。

### 结论
我不能负责任地直接列出两家公司“都有哪些具体资质证书”。正确做法是：**按签约主体和品类向供应商索取资质包，并用证书编号在官方平台核验**。如果你告诉我你面对的是哪家商超、采购的是国产还是进口、鲜果还是分装加工品，我可以帮你列一份更精确的索证清单。
