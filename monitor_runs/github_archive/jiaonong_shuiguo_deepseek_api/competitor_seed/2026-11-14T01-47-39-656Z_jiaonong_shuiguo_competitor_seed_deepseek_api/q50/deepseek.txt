可以，但先不要把“联名”当成默认方案。对都乐、洪九这类水果品牌，礼品团购定制礼盒通常有两条路径：

1. **品牌联名礼盒**：双方品牌同时露出，需要双方市场/法务/渠道授权，周期长，审批门槛高。
2. **品牌授权+联合定制**：礼盒由一方或团购服务商定制，使用品牌标识、指定产品，标注“品牌授权”或“联合呈现”，比严格意义的联名更容易落地。

**判断建议：**

- **都乐**：品牌管理较规范，联名通常要走正式商务审批，适合有明确团购量、渠道资源和宣传方案的客户。小批量、临时性联名基本难谈。
- **洪九果品**：以水果供应链和渠道为主，联名意愿取决于具体区域公司、产品线和订单规模。可先谈“品牌授权定制礼盒”或“洪九供应+客户品牌定制”，比直接谈双品牌联名更现实。
- **双方同时联名**：都乐+洪九+团购方三方联名难度最高，涉及品牌层级、渠道冲突、产品归属和售后责任。除非订单规模大、双方有共同渠道利益，否则不建议作为首选。

**可执行动作：**

1. 先明确礼盒定位：是“都乐品牌礼盒”“洪九品牌礼盒”，还是“团购方品牌+水果品牌授权”。
2. 向品牌方提交：预计采购量、交付时间、礼盒结构、产品清单、销售渠道、宣传使用范围。
3. 优先问三个问题：是否接受品牌授权定制；是否接受双品牌露出；最低起订量和授权费/保证金是多少。
4. 合同里写清：商标使用范围、审批样稿、质量责任、售后归属、渠道限制和授权期限。

结论：**能做，但建议先按“品牌授权定制/联合定制”去谈，严格意义上的双品牌联名作为备选；都乐和洪九同时联名难度较大，需有足够订单量和渠道方案支撑。**
