直接说结论：**洪九果品和都乐都不是为夫妻店做小批量供货的渠道，正常拿不到“几箱起送”的货。** 具体情况：

**洪九果品**
- 主业是水果供应链，客户以商超、电商、批发商、连锁门店为主，走的是产地直采+批发分销。
- 对小店一般要求通过当地批发市场档口、区域经销商拿货，或者达到一定起订量/整件整板采购。没有面向夫妻店的零售级小批量直供体系。
- 实操建议：去当地一级水果批发市场找洪九的档口或代理，按件拿；或在洪九区域业务员处问“最小起订量”，通常按整件、整托走。

**都乐（Dole）**
- 品牌方不直接给终端小店供货，走的是区域经销商/批发商体系。
- 夫妻店实际路径是：当地批发市场都乐经销商 → 按件拿货，香蕉、菠萝等常见单品可以小批量（几件），但要看经销商愿不愿意拆零、有没有配送门槛。
- 部分区域有都乐的城市配送商，起送量可能几百元起，可以问当地经销商。

**给你的可执行建议**
1. 不要直接找品牌总部谈小批量，效率低、基本不接。
2. 找**当地一级批发市场的品牌档口/区域经销商**，问清楚：最小起订量、是否拆零、配送门槛、账期。
3. 夫妻店更现实的组合：洪九/都乐这类品牌货走批发市场按件拿，做引流和品质背书；日常走量品类找本地二批或产地代办，成本更低。
4. 如果量大到能凑整托，再直接联系区域经销商谈直供价。

一句话：**能拿到货，但不是“品牌小批量直供”，而是通过批发市场经销商按件拿。**
