可以，但要先分清“能提供什么素材”和“找谁要”。

**结论：**
- **都乐（Dole）**：通常可以作为菠萝品牌营销的素材来源，尤其是其官方品牌、产品包装、产地/品种介绍、品牌视觉和部分公开传播内容。但商业使用需获得授权，不能默认可自由使用。
- **洪九果品**：作为水果供应链/品牌企业，可能提供产品资料、品牌介绍、包装视觉、产地与品控信息等素材，但是否开放给生鲜电商做联合营销，要看具体合作方式和授权范围。

**可执行建议：**
1. **先走商务对接**：分别联系都乐和洪九果品的电商/渠道/品牌市场团队，说明用途（详情页、短视频、直播、社媒、线下物料）、渠道范围、使用期限和是否联合露出。
2. **明确素材清单**：向对方索要品牌LOGO、产品高清图、包装图、产地/品种卖点、检测或品控资料、品牌授权书、可公开传播的短视频/直播素材。
3. **确认授权边界**：重点问清是否允许二次剪辑、是否允许投放付费广告、是否允许标注“官方合作”、素材使用期限和区域。
4. **无授权时不要直接商用**：公开网络图片、包装图、品牌LOGO不能默认用于电商详情页或广告投放，避免侵权和平台投诉。
5. **备选方案**：若品牌方素材开放有限，可改用自拍产品图、开箱实拍、产地溯源内容，或让对方提供“联合营销授权包”。

**判断标准：** 只要对方能出具书面授权并明确素材清单和使用范围，就可以用于营销；只有口头同意或只给公开宣传图，不建议直接商用。
