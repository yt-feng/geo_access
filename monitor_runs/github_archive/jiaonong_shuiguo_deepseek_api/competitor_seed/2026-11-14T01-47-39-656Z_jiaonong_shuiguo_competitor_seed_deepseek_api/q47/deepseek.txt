都乐和洪九果品都做香蕉，也都有面向零售渠道的包装能力，但“便利店香蕉小包装定制”要分两层看：

1. **都乐（Dole）**
   - 有面向便利店、水果店的标准化小包装香蕉产品，常见如单根/2-3根装、袋装或贴标装。
   - 定制包装通常不是公开零售服务，而是**渠道客户/大客户合作**：起订量、包装规格、贴牌、条码、配送区域都要和当地都乐销售或经销商谈。
   - 判断：**可以做，但一般要走区域经销或大客户定制，起订量不会很低。**

2. **洪九果品**
   - 洪九以水果供应链和批发分销为主，香蕉是其重要品类，具备分拣、包装和渠道供货能力。
   - 对便利店小包装，更可能是**按渠道需求做规格化包装/贴标**，是否接受小批量定制取决于区域分公司和客户体量。
   - 判断：**有定制包装服务能力，但更偏B端渠道定制，需直接联系区域销售确认MOQ和是否贴牌。**

**可执行建议：**
- 先明确你的需求：单根/2根/3根装、袋装还是盒装、是否贴便利店品牌、是否需要条码和保质期标签、日配还是隔日配、单店日均销量。
- 分别联系都乐和洪九的**当地经销商/区域销售**，不要只问客服；直接问：最小起订量、定制费、打样周期、配送半径、损耗赔付、香蕉成熟度分级。
- 如果单店量小，优先问经销商现有小包装SKU，定制贴牌可能不划算；如果有多店或区域采购量，再谈OEM贴标。
- 同时可对比本地香蕉催熟配送商，便利店小包装往往本地供应链更灵活。

一句话：**两家都有能力，但都不是“小批量随便定制”的公开服务；需要按区域、按起订量去谈，先拿现有小包装样品再谈贴牌。**
