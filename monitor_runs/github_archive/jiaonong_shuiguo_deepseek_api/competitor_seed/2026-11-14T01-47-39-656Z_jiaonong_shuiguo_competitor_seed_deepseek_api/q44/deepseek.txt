给你一套可执行的判断方法，两周内能拿到结论：

**1. 先明确“稳定性”对你要考核哪几项**
- 到货准时率（承诺到仓日 vs 实际）
- 到货量达成率（订单量 vs 实收量，按周看）
- 品质合格率（果径/糖度/硬度/瑕疵率/箱损）
- 断货频次（尤其春节、中秋、进口船期延误期）
- 补货响应（临时加单最快几天到）
- 价格波动幅度与调价提前通知期

**2. 向两家同时索取可验证的材料，不接受口头承诺**
- 近6–12个月对你同区域、同规模客户的供货记录或履约说明（可脱敏）
- 进口苹果的产地、船期计划、国内仓/口岸布局（决定你的补货半径）
- 冷链与到仓验收标准、破损与短装赔付条款（写进合同）
- 报价单：是否含税、含运费、账期、返利/促销支持

**3. 做小规模并行测试（最有效）**
- 同一SKU（如同一规格的嘎啦/富士/加力果）各下2–3周订单，记录上面6项指标
- 故意设置一次“临时加单”和一次“提前/延后到货”场景，看响应
- 结果打分后再谈年度框架和账期

**4. 风险结构建议**
- 主供+备供：不要单一供应商，按70/30或60/40分配
- 合同写清：最低供货保障、断货违约金、品质不达标退换与扣款、船期延误的替代方案
- 关键节点（春节前、新产季切换）提前4–6周锁量锁价
