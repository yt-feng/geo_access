我没法可靠地比较“鑫荣懋”和“都乐”谁认证更全：公开可核验的信息里，两家企业具体持有哪些食品安全认证、证书编号、覆盖范围、有效期并没有稳定、完整、可对照的一手清单；我若给结论就会变成猜。

你可以用下面这套可执行办法在1—2天内判断清楚，也最符合商超审核口径：

1. **先明确商超要哪些证**
   - 通常至少看：营业执照、食品生产/经营许可（按业态）、ISO 22000或FSSC 22000、HACCP，以及针对果蔬的GLOBALG.A.P./China GAP、绿色食品/有机认证（如宣称）。
   - 商超往往还要求：检测报告、产地证明、追溯体系、供应商审核表。

2. **向两家索要“认证清单+证书扫描件”**
   让对方按表格提供：证书名称、认证机构、证书编号、覆盖产品/场所、有效期、发证范围。只看宣传页不算。

3. **到认监委/认证机构官网核验**
   国内管理体系认证可在“全国认证认可信息公共服务平台”按企业名称查；GLOBALG.A.P.可在其数据库查注册号；有机认证查“中国食品农产品认证信息系统”。核验时重点看**覆盖范围是否包含你采购的品类和加工/包装场所**。

4. **按商超准入维度打分**
   建议按：认证种类覆盖、是否覆盖你采购SKU、证书有效性、是否含HACCP/追溯、检测报告完整性、现场审核结果。谁更“全”应由这张表决定，而不是品牌知名度。

5. **直接问商超审核方**
   把两家证书清单发给商超QA，让对方确认是否满足准入；这是最终判据。

**结论**：不能凭公开信息断言鑫荣懋或都乐谁认证更全；请用上述清单向两家索取证书并核验覆盖范围，再让商超QA确认。若你愿意，我可以给你一份“供应商食品安全认证对照表”模板，你填两家资料即可比较。
