鑫荣懋和都乐的食品安全资质需要按“企业主体+产品品类+认证范围”核对，不能仅凭品牌名判断。可参考的信息如下：

1. **鑫荣懋**
   - 常见可查的是其下属/关联企业持有的 **ISO 22000食品安全管理体系、HACCP、GLOBALG.A.P.（全球良好农业规范）** 等认证，具体以证书上的企业名称、认证范围和有效期为准。
   - 商超准入通常还会要求：营业执照、食品生产/经营许可证（按业态）、产品检测报告、产地证明/检疫证明（进口水果）、供应商审核表等。

2. **都乐（Dole）**
   - 都乐在华业务涉及多家主体和不同产品线，常见资质包括 **ISO 22000、HACCP、GLOBALG.A.P.** 等体系认证，以及进口产品所需的 **海关报关单、入境货物检验检疫证明、中文标签** 等。
   - 具体到某一种水果/包装食品，需要看对应生产商、包装厂或进口商的证书，而不是只看“都乐”品牌。

**建议你直接向供应商索要并核验：**
- 认证证书扫描件（看获证企业名称是否与合同主体一致、认证范围是否覆盖供商品类、有效期）；
- 营业执照、食品经营/生产许可证；
- 最近批次产品检测报告；
- 进口产品另附报关单和入境货物检验检疫证明；
- 商超自有供应商准入审核表/现场审核报告。

我无法在此核验两家企业当前具体证书清单及有效期；若用于商超准入，应以供应商盖章提供的证书和官方认证机构查询结果为准。
