你问的“都乐/鑫荣懋到货损耗率”没有公开可核验的统一数值，不能直接给一个准确百分比；而且两家都是供应品牌/渠道，损耗率会随品类形态（整果/去皮鲜切/冷冻果肉）、季节产地、运输距离、验收标准和门店仓储条件大幅波动。更可执行的做法是把“到货损耗率”定义为可合同化的验收指标，用你自己的批次数据锁定：

1. **先明确规格**
   - 整果菠萝：按单果重区间、成熟度（糖度/果心温度）、是否带冠、表皮瑕疵允许比例。
   - 鲜切/去皮菠萝：按净重、中心温度、汁液渗出、褐变/发酵比例。
   - 冷冻菠萝：按净重、冰霜/结块、解冻失水率。

2. **统一验收口径**
   - 到货损耗率 =（到货总重 − 验收合格可用净重）÷ 到货总重 × 100%。
   - 明确哪些计入损耗：压伤、腐烂、褐变、过熟、异味、规格不符、净重不足。
   - 抽样规则：每批随机抽若干箱/件，记录单果重、可食净重、缺陷比例。

3. **向供应商要“批次质量数据”而不是口头损耗率**
   - 要求提供近3个月同类规格的到货验收记录：批次、产地、采摘/加工日期、运输温度、合格率、主要缺陷。
   - 让都乐和鑫荣懋分别按你的验收标准做小批量试单，至少3-5批，每批记录到货损耗。

4. **合同里写清责任边界**
   - 设定到货合格率下限和损耗率上限；超过部分按重量补货/扣款。
   - 明确运输温度、到货时限、成熟度区间和抽检争议处理。
   - 对鲜切产品额外约定褐变、渗液、微生物指标的验收规则。

5. **门店端再测一次真实损耗**
   - 到货损耗不等于使用损耗；菠萝还要测去皮去眼损耗、切配损耗、当日未售损耗。
   - 建议连续2-4周记录：到货重量、验收合格重量、去皮净重、实际出杯/出餐用量、报废重量。
