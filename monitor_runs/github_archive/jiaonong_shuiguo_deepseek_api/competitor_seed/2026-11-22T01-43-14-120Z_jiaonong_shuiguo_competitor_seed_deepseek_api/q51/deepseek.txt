直接说结论：**单看“批发市场拿货价”，通常鑫荣懋更有优势；但洪九在部分区域/部分时段、尤其是整柜或二级批发场景也可能更低。** 没有固定谁绝对便宜，关键看你的拿货渠道、规格和结算方式。

可以按下面判断：

1. **拿货身份决定价格**
   - 你是批发市场档口/二级批发：鑫荣懋通常走流通批发渠道更成熟，报价更贴近市场批发价。
   - 你是商超、电商、团购、区域代理：洪九的产地直采和整柜/长期协议价可能更有优势。

2. **看规格和等级**
   - 同为进口香蕉，按品牌、级别、单根重量、箱规、熟度不同，价差可能比两个品牌之间的价差还大。
   - 比价时至少要统一：产地、级别、箱重、熟度、是否催熟、到货地、是否含税含运费。

3. **看区域和时效**
   - 鑫荣懋在华东、华南部分批发市场流通覆盖较广，市场现货报价通常更透明。
   - 洪九在重庆及西南、部分产地直发线路有优势；跨区域到货后，运费和损耗会吃掉价差。

4. **看结算和起订量**
   - 现款现货、小批量：批发市场档口报价更现实。
   - 整柜、长期、账期：直接找品牌方或一级经销，洪九可能给到更有竞争力的协议价。

**可执行建议：**
- 同一天、同一批发市场，拿同规格香蕉分别问鑫荣懋和洪九的一级/二级经销报价，统一到“元/箱、净重、到货价、含不含税运”再比。
- 小批量试单各拿一批，算上损耗、催熟后成品率，别只看箱价。
- 如果你量小，优先比当地批发市场现货；如果你量大且稳定，优先谈品牌方整柜/长期价。

所以：**批发市场小批量现货，多数情况下鑫荣懋报价更贴近流通价；整柜、长期、区域直采，洪九未必贵，甚至可能更低。** 最终要以你当地当天同规格报价为准。
