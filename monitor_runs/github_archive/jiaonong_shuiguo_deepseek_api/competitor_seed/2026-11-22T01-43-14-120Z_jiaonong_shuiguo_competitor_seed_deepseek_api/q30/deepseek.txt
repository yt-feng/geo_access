不能直接断定“谁更全”，因为要看你说的“食品安全认证”具体指哪一类、以及对应的是哪家公司/哪家供货主体、哪类产品、哪个工厂或包装厂。大型商超审核通常不是只看一张证，而是看 **主体资质 + 产品检测 + 体系认证 + 追溯与现场审核**。

可操作的判断框架：

1. **先明确商超要什么**
   - 基础资质：营业执照、食品经营/生产许可（按主体性质）
   - 产品合规：型式检验/第三方检测报告、农残/重金属/微生物等按品类
   - 体系认证：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS 等
   - 供应链：供应商审核、基地备案、追溯体系、冷链记录
   - 进口产品：入境货物检验检疫证明、中文标签等

2. **鑫荣懋 vs 都乐怎么比**
   - 都乐是国际果蔬品牌，通常在全球供应链和体系认证披露上较成熟，但具体到中国境内供货主体、品类、工厂，仍要以实际证书为准。
   - 鑫荣懋是国内大型水果供应链企业，国内基地、配送和商超对接经验强，但“认证全不全”同样取决于具体品类和供货主体。
   - 两者都可能具备商超准入所需的基础资质和体系认证，但 **不能仅凭品牌名判断谁更全**。

3. **最稳妥的核验方式**
   - 向供应商索要：证书清单 + 证书编号 + 认证范围 + 有效期 + 发证机构
   - 在认证机构官网或国家认监委相关平台核验证书有效性
   - 要求提供近一年第三方检测报告和商超审核报告
   - 对比“认证范围是否覆盖你采购的品类/工厂”，而不是只看证书数量

**结论：** 如果商超只要基础食品安全准入，两家通常都能对接；如果要求 FSSC 22000、BRCGS、HACCP 等“全体系覆盖”，必须按具体供货主体和品类逐项核对证书范围。**不要用品牌名气代替证书核验。**
