进口菠萝旺季缺货时，先按“能否换规格/换产地/换渠道”三步处理，再判断都乐和洪九果品的基地直供优势。

**一、旺季缺货的应对**
1. **先确认缺货类型**：是整体到港量不足，还是某规格（如金菠萝、MD2、鲜切用大果）断档。若只是规格断档，优先换规格或改鲜切原料。
2. **切换产地**：菲律宾（都乐主产地之一）供应紧张时，可评估哥斯达黎加、厄瓜多尔、泰国等替代来源，但需同步核对关税、检疫准入、运输时效和口感差异。
3. **调整渠道**：连锁商超/餐饮优先锁“产地直采+港口直发”；中小批发商可转向一级进口商拼柜、港口周边冷库现货，减少中间环节。
4. **用国产或其他热带水果替代**：鲜切、饮品、烘焙场景可临时用国产凤梨/菠萝或芒果、木瓜替代，先保菜单和货架不断。
5. **提前锁量**：旺季前2—3个月与供应商签框架量+浮动价，约定到港优先分配；对都乐这类品牌商，重点谈区域代理的配额，而不是临时现货。

**二、都乐 vs 洪九果品的基地直供优势**
- **都乐（Dole）**：优势在全球产地布局和品牌化标准，菲律宾、哥斯达黎加等自有/合作基地较成熟，适合对品质稳定、规格统一、品牌背书要求高的商超和餐饮客户；但国内终端多经代理商/经销商，中小客户未必能直接拿到“基地直供”价。
- **洪九果品**：优势在国内进口水果分销网络和“基地直采+分销”模式，东南亚水果（含菠萝/榴莲等）源头采购和国内批发渠道较强，适合需要稳定大批量、走批发/商超供货的客户；但其基地多为合作/包园采购，并非全部自有种植基地，直供能力要看具体品类和区域。
- **判断建议**：要品牌标准和全球供应稳定性，优先谈都乐的区域代理/直采配额；要国内分销效率和批量供货，优先谈洪九果品的基地直采协议。两者都不是“任何客户都能直接基地直供”，关键看你的采购量、所在区域和是否愿意签年度框架。

**可执行动作**：列出现有供应商的到港计划→向都乐、洪九各要一份旺季配额和替代产地报价→同步找1—2家港口一级进口商做备份→对鲜切/餐饮客户准备国产凤梨替代方案。
