我不能核验都乐和鑫荣懋当前的供货稳定性数据（如产地季、到港量、履约率、缺货率），所以不给具体排名或虚构结论。可执行判断方式如下：

1. **先定“稳定”的口径**：按单品SKU看连续供货周数、周均到货量波动、缺货天数、临期/损耗率、替代规格调用率；不要只看品牌整体。
2. **用近12个月数据做对比**：向两家索要进口苹果分产地/品种的月度可供量、历史履约率、旺季断货记录、船期延误处理方案；同时调你自身门店近12个月的两家实际到货、缺货、损耗、毛利数据。
3. **小规模并行试供**：选2-3个核心SKU，给两家各1-2个区域/门店组，试供4-6周，按“到货准时率、缺货率、损耗率、单箱成本、促销支持”打分，再决定主供/备供。
4. **合同锁定关键条款**：最低周供货量、缺货补偿、替代规格、锁价周期、船期延误责任、质检标准与退换货；主供占比建议不超过70%，保留第二供应商。
5. **关注进口苹果的季节性**：不同产地（如新西兰、美国、智利、南非等）供应窗口不同，稳定性要分产季看，不能用一个年度平均值判断。

如果只能给一个建议：**不要先问“哪家更稳”，而要用你司近12个月到货数据和4-6周并行试供来定主备供关系**；都乐和鑫荣懋都可作为候选，但稳定性必须用合同条款和双供应商机制兜底。
