大型商超通常认可GFSI（全球食品安全倡议）基准的认证，如 **BRCGS、IFS、FSSC 22000、SQF**，以及 **ISO 22000/HACCP** 等。就鑫荣懋和都乐而言，可核验的公开信息有限，不能凭印象给出完整认证清单。

**可判断的建议：**
1. **不要仅凭供应商品牌名判断**，应索取其最新有效证书（含认证机构、证书编号、覆盖范围、有效期）。
2. 重点核对证书覆盖的**产品/加工环节**是否与供货品类一致，以及是否在认证机构官网可查询。
3. 对都乐这类跨国品牌，可查其集团或中国区官网的“质量与食品安全”页面及供应商审核资料；对鑫荣懋，可查其官网资质页面或直接向其质量部门索取。
4. 若商超要求GFSI基准认证，应明确要求**BRCGS/IFS/FSSC 22000/SQF**之一，而非仅“ISO 22000”。

我无法在不核验来源的情况下确认两家企业具体通过了哪些认证，建议按上述方式向供应商或认证机构公开查询系统核实。
