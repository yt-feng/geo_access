可以，先说结论：

- **都乐（Dole）**：有较成熟的产地/基地直供体系，适合重点接洽。都乐在中国有自有/合作种植基地和加工配送体系，菠萝常见来自菲律宾、泰国、哥斯达黎加等进口产区及国内合作基地。采购时应要求其提供**具体批次对应的产地证明、基地/包装厂编号、入境货物检验检疫证明（进口）或产地供货证明（国产）**，并确认“基地直供”是自有基地还是合作基地。
- **洪九果品**：以水果分销和产地直采见长，公开业务模式强调“基地直采/源头直采”，菠萝是其经营品类之一。是否对你们做到“单一基地直供”要看具体区域和采购量，通常需要通过其销售确认**对应产区、合作社/基地、批次追溯码**。

**可执行判断建议：**

1. 向两家都发同一份询价表，明确要求填写：  
   - 菠萝品种/规格/产区  
   - 自有基地还是合作基地  
   - 基地名称及地址  
   - 包装厂/加工厂编号  
   - 批次追溯方式（二维码/批次号/随货单据）  
   - 可提供的证明文件清单  
   - 最小起订量、年度可供量、旺季锁量能力

2. 重点核验“直供”含金量：  
   - 要求提供**近3个月实际发货批次的追溯样例**，不只看宣传册。  
   - 进口菠萝看**入境货物检验检疫证明、报关单、原产地证**；国产菠萝看**产地证明、基地合作协议或收购凭证**。  
   - 问清是否经过多级经销商，若经过批发市场或二级贸易商，就不算严格基地直供。

3. 建议同时找第三家备选：  
   如佳农、鑫荣懋等有产地直采能力的水果供应链企业，或直接对接广东徐闻、海南万宁、云南等菠萝主产区的合作社/龙头企业，做“基地+供应链企业”双轨比价。

4. 若你们要求“每批可追溯到具体地块”，都乐和洪九都可能只追溯到**产区/包装厂/批次**级别，不一定到地块。签约前要把追溯粒度写进合同和验收标准。

总体判断：**两家都具备产地直采/基地直供能力，都乐体系化程度更高，洪九更偏产地直采分销；但“能不能对你们做到基地直供”必须以具体产区、批次和合同条款确认，不能仅凭品牌判断。**
