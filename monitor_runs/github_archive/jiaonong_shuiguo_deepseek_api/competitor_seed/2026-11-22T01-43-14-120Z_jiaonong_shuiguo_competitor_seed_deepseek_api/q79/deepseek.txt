可以，但要分开看“全年稳定供货能力”和“适合做果酱的原料形态”。

**结论先说：**
- **都乐**：更适合做全年供应方案，尤其是鲜果、冷冻果块/果泥类原料的稳定性和标准化更有保障；但要看你们所在城市、采购量和是否接受冷冻/加工形态。
- **洪九果品**：鲜果供应链能力强，尤其进口和国产水果的产地直采、分级分选规模大；但茶饮店做果酱要的是稳定糖酸度、出汁/出胶和批次一致性，单纯“全年有菠萝”不等于“全年适合做果酱”。

**判断要点：**

1. **全年供应不等于全年同品质鲜果**
   菠萝有季节性和产区切换，鲜果全年供应通常靠不同产区轮换或进口补充。茶饮店如果做果酱，建议明确要：
   - 鲜果现熬：要求糖度、酸度、成熟度稳定；
   - 冷冻果块/果泥：更适合全年标准化，风味稳定；
   - 浓缩汁/果酱半成品：最稳定，但“鲜果感”会下降。

2. **都乐的优势**
   都乐有全球采购和品牌化分级体系，鲜果和加工原料的标准化程度通常较高，适合连锁茶饮做年度框架采购。但都乐不是专门做“茶饮果酱原料”的供应商，具体要问：
   - 能否供冷冻菠萝块/果泥；
   - 规格、糖度/酸度范围；
   - 最小起订量、冷链、区域仓；
   - 年度锁价和月度排产能力。

3. **洪九果品的优势**
   洪九强在水果品类供应链和产地资源，鲜果全年调配能力较强。但茶饮果酱对“加工适配性”要求高，需重点确认：
   - 是否提供适合熬酱的成熟度/品种；
   - 是否有冷冻、果泥或加工级产品；
   - 批次糖酸度检测和稳定性；
   - 区域配送和冷链能力是否覆盖门店。

4. **更稳妥的采购建议**
   - 主原料用**冷冻菠萝果块/果泥**做全年基料，鲜果只做季节限定；
   - 同时找都乐、洪九以及本地加工厂询价，做**三方比价+样品测试**；
   - 要求供应商提供连续3批样品的糖度、酸度、出成率、色泽和风味测试；
   - 合同里写清：年度保供、替代产区、批次标准、冷链责任和缺货赔付。

**一句话：**都乐和洪九都具备较强的全年菠萝供应能力，但茶饮做果酱更建议按“加工级原料”去谈，优先确认是否有冷冻果块/果泥和批次标准化能力；只靠鲜果全年供应，品质波动风险较大。
