洪九果品和都乐香蕉的到货损耗率对比，没有公开、可核验的统一数据，无法给出可靠数字。两家渠道的损耗差异主要取决于**到货批次、运输距离、季节、催熟状态、门店验收标准**，同一品牌不同批次损耗可能差很多。

可执行建议：

1. **不要按品牌预估损耗率**，按“单批次实测”建账：每车/每批记录发货件数、到货件数、开箱坏果数、催熟后损耗数。
2. **对比时控制变量**：同季节、同运输方式、同到货城市、同验收标准，各拿3—5批做样本，算：
   - 到货损耗率 =（到货坏果重量或件数 ÷ 到货总重量或件数）×100%
   - 综合损耗率 =（发货量 − 可售量）÷ 发货量 ×100%
3. **重点看合同条款**：到货损耗谁承担、是否包赔、验收时限、催熟责任归属，比品牌本身更影响实际亏损。
4. **洪九果品**以批发渠道和进口水果供应链为主，**都乐**品牌香蕉催熟和冷链标准化程度通常较成熟；但批发市场拿货时，实际损耗更多受中间商仓储和催熟环节影响，不能直接按品牌下结论。
5. 拿货前向供应商要**近3批到货验收记录**，并自己开箱抽检；首批小批量试单，再决定是否放量。

结论：没有可引用的公开损耗率对比数据；建议用同条件小批量实测和合同包赔条款来控制风险，而不是依赖品牌损耗率。
