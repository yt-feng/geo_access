我没法核验都乐和鑫荣懋当前具体的物流时效数据，不能给你编一个“X小时/X天”的结论。但可以给你可执行的判断方法和谈法：

**1. 先明确你要的“产地直发时效”口径**
- 从产地仓/加工厂出库到销地仓：几小时/几天
- 从产地到消费者：是否含分拣、干线、末端配送
- 菠萝是否做催熟/预冷/分级，是否影响出库时间
- 发货地是广东徐闻、海南、云南等哪个产区，时效差异很大

**2. 向两家分别索要可核验的时效承诺**
让对方书面提供近3个月同产区、同目的城市的：
- 平均出库时长
- 干线运输时长
- 销地入仓/末端配送时长
- 准时率、破损率、温控异常率
- 旺季（3-5月菠萝季）的爆仓预案和备用线路

**3. 用试单验证，不要只看报价**
选你目标城市做2-3批小批量试单，记录：
- 下单到揽收时长
- 揽收到销地仓时长
- 到消费者签收时长
- 坏果率、黑心/水烂比例
- 异常件处理响应时间

**4. 合同里写清时效条款**
- 分产区、分目的城市约定时效
- 超时赔付标准
- 温控和破损责任划分
- 旺季运力保障和调仓机制

**5. 实操建议**
菠萝产地直发对时效和温控都敏感，建议不要只依赖一家：
- 都乐和鑫荣懋都谈，但以试单数据决策
- 同时备一家区域冷链/干线物流商做备份
- 优先选在徐闻/海南有产地仓或固定加工厂的合作方
