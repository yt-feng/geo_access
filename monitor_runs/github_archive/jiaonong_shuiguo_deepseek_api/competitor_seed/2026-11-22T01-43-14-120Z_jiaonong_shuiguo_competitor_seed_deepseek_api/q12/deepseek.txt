可以优先按“便利店单根/小串即食”场景去筛，但**鑫荣懋和都乐的具体小包装香蕉规格，我无法在不核验最新商品目录的情况下给出确定清单**，不建议直接报规格给渠道。可执行判断如下：

1. **先向两家要“便利店渠道专供/小规格香蕉”目录**
   - 明确问：是否有单根装、2-3根小串装、约120–150g/根、整包300–500g的即食香蕉规格。
   - 要三样东西：**最新规格表、包装图、供货区域与起订量**。没有这三样不要定。

2. **渠道适配判断标准**
   - 单根装：适合收银台冲动购买，重点看货架期和碰伤率。
   - 2-3根小串装：适合鲜食便利店，重点看是否按“即食/可即食”分级供货。
   - 包装：优先选透气膜/开孔袋，避免全密封导致水汽和黑斑；标签需有产地、等级、日期、贮存条件。

3. **向供应商必须确认的问题**
   - 是否有便利店专供小包装，还是只能从大箱中分装？
   - 到店成熟度是几分？货架期几天？配送频次？
   - 小包装是产地预包装还是区域仓分装？分装方资质和日期标识是否合规？
   - 最小起订量、单店配送门槛、损耗赔付规则。

4. **建议动作**
   - 同时向鑫荣懋和都乐的区域销售索要**便利店渠道案例和当前在供包装规格**；以对方盖章或邮件确认的规格表为准。
   - 先小批量试销2周，按“单根装 vs 2-3根装”对比日销、损耗率和退货率，再定主推规格。
