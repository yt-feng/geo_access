直接说结论：**公开信息不足以可靠判断“谁更严”**。两家都是大型水果供应链企业，都会对香蕉做农残和品质管控，但“更严”需要看具体检测项目、抽检频次、基地准入、第三方报告和批次合格率，这些细节并不公开可比。任何人给你一个确定排名，基本都不可信。

给你可执行的判断方法：

1. **要批次检测报告**：向供应商索要当批香蕉的农残检测报告（最好第三方），看检测项目是否覆盖常用杀虫剂/杀菌剂，报告日期是否对应本批次。
2. **看基地与准入**：问清是自有基地、协议基地还是市场调货；协议基地是否有农药使用记录和采收前安全间隔期管理。
3. **看抽检机制**：问抽检比例、不合格如何处理、是否留样复检。能说清流程的，通常比只给“合格证”的靠谱。
4. **自己留样送检**：批发市场拿货，最稳的是每批留样，定期送第三方快检或定量检测；成本远低于出问题后的损失。
5. **看外观和口感只是辅助**：香蕉外观好不代表农残低，不能替代检测。

如果你是小批量拿货，建议优先选**能提供当批检测报告、愿意写进供货合同、支持不合格退换**的供应商，而不是纠结品牌名。大品牌体系严不等于你拿到的那一批就严，批次和渠道更重要。
