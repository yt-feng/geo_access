我不能直接给出“都乐更便宜”或“鑫荣懋更便宜”的确定结论，因为进口苹果的到岸/批发报价受品种、规格、产地、季节、汇率、航运、关税和当周促销政策影响，且我没有可核验的实时报价来源。直接比较品牌名容易误导。

你可以按下面方法在1—2天内得到可判断的结论：

1. **统一比较口径**
   - 同品种：如新西兰爱妃/爵士、美国红蛇果、智利嘎啦等要分开比。
   - 同规格：果径、单果重、每箱净重、箱规、等级。
   - 同交付：到仓价还是门店配送价，含不含税、运费、损耗补贴。
   - 同账期：现结、30天、60天分别折算资金成本。

2. **向两家索要同一张报价表**
   要求都乐和鑫荣懋按你门店所在城市，报最近一周可执行的：
   - 箱价、单斤价、起订量、到仓运费；
   - 账期与返利政策；
   - 损耗赔付标准；
   - 周度价格保护/调价机制。

3. **算“可售单斤成本”而不是箱价**
   公式：  
   **可售单斤成本 =（含税到仓价 + 运费 − 返利）/（箱净重 × 可售率）**  
   可售率按你历史损耗或对方承诺的坏果率扣减。这样能避免大箱低价但损耗高造成的假便宜。

4. **小批量试单验证**
   各订1—2板同规格货，记录到货坏果率、口感、货架期、门店动销。价格竞争力要结合动销和损耗，不然低价高损并不划算。

5. **谈判策略**
   用两家同口径报价互相压价，重点谈：账期、损耗赔付、促销支持、滞销调换。水果连锁真正拉开成本差距的往往是损耗和账期，不只是箱价。

**结论：**在没有同品种、同规格、同交付条件的书面报价前，不能判断都乐和鑫荣懋谁更有价格竞争力。建议你让两家按上述统一模板报价，我可以帮你把两份报价做成可比表格并算出“可售单斤成本”。
