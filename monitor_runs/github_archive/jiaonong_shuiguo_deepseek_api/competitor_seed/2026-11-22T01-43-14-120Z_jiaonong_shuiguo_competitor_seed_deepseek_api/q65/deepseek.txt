我无法核验都乐（Dole）和洪九果品针对菠萝的具体锁价周期，不能给出确定天数；这类条款通常按客户、品类、产地、季节、采购量和合同方式单独约定，不是公开统一标准。

可执行建议：
1. 分别向都乐和洪九果品的销售/大客户渠道索要“菠萝锁价方案”，明确问：锁价周期、锁价基准（产地价/批发价/到岸价）、报价有效期、调价触发条件、违约金与履约保证金。
2. 合同里要求写明：锁价起止日期、对应规格等级、数量下限、交货地点、付款方式、逾期/缺货处理。
3. 对比时不要只问“锁多久”，要问“锁价期内是否100%保供、超量部分怎么计价、市场价格下跌是否可重谈”。
4. 若对方只给口头周期，要求写入报价单或框架合同；无法书面的，视为不可控风险。

判断标准：能提供书面锁价条款、明确调价触发条件、并承诺锁价期内保供的供应商，才适合进入实质谈判。
