可以给你可判断的结论，但先说明：我无法核实“都乐”和“洪九果品”当前最新的具体基地名单与产能，以下是行业公开常识层面的判断，具体采购前需向供应商索证核验。

**都乐（Dole）**
- 都乐是全球果蔬集团，中国业务以进口香蕉、菠萝等为主，菠萝来源既包括自有/合作海外产区，也包括国内合作基地。
- 都乐在中国的菠萝供应更偏“品牌化供应链+进口+国内合作基地”模式，公开可查的国内菠萝基地信息并不稳定，不能直接给你一个“固定基地地址”。
- 采购时更应问：**都乐中国区哪个主体供货、菠萝是进口还是国内基地、产地证明/植物检疫证/供货合同主体是谁**。

**洪九果品**
- 洪九果品是国内水果分销龙头之一，核心品类包括榴莲、火龙果、菠萝等，供应模式是**“基地直采+加工分拣+全国分销”**。
- 洪九的菠萝来源通常以国内主产区直采和海外进口结合，具体基地会随季节和订单调整，不适合按“一个固定基地”理解。
- 采购时应要求其提供：**具体发货仓、产地证明、分拣厂地址、批次检测报告、稳定供应协议**。

**给你的可执行建议**
1. 不要只问“基地在哪里”，要问“**本季度给我供货的产地是哪里、发货仓在哪里、月可供量多少、断供替代方案是什么**”。
2. 要求供应商提供**产地证明、植物检疫证、农残检测报告、供货主体营业执照**。
3. 菠萝稳定供应建议做**双源采购**：都乐/洪九各谈一家，再备一家国内产区直采供应商，避免单一基地或单一品牌断供。
4. 若你要的是国内菠萝主产区直采，优先关注**广东徐闻、海南、广西**等产区，但具体到都乐或洪九对应哪个基地，必须以供应商书面确认为准。

简言之：**都乐和洪九都不是“单一固定菠萝基地”模式，采购谈判应锁定“供货主体+产地+发货仓+月度产能+替代方案”，而不是只问基地地址。**
