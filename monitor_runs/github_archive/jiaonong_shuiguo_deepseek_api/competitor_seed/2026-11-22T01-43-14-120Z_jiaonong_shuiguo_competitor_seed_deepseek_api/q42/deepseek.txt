进口菠萝旺季缺货时，先分清缺的是“总量”还是“特定规格/品牌”。可执行判断如下：

**1. 先做缺口分级**
- 缺总量：优先找替代产地（菲律宾、泰国、哥斯达黎加等，视当季准入和检疫要求）和替代品种（如金钻凤梨、MD-2菠萝）。
- 缺规格：把大果缺口改小果/中果做促销装、餐饮装；把鲜切缺口改为冷冻/罐头原料。
- 缺品牌：都乐、洪九果品这类品牌商通常有“多产地+多包装+渠道调拨”的常规应急机制，但具体到某批次是否可调，需要直接向区域销售/供应链确认，不能仅凭品牌名判断一定有货。

**2. 对都乐、洪九果品的现实判断**
- 两家都是全国性水果供应链企业，通常具备产地直采、冷链仓储和多渠道分销能力，旺季缺货时可能有跨区域调拨、调整包装规格、用其他产地替代等动作。
- 但“有没有应急方案”不能对外部一概而论：需要问清三件事——① 当前可承诺的SKU和到货周期；② 是否接受替代产地/规格；③ 锁价和锁量条件。没有书面确认，不要按“有应急方案”做采购计划。

**3. 采购端应急动作**
- 立即锁量：对现有供应商下短期锁量单，接受分批到货。
- 并行询价：同时联系都乐、洪九及本地一级批发商，要求48小时内给可到货SKU清单。
- 改规格：把礼盒/精品大果需求转为餐饮装、鲜切装或家庭装，降低对单一规格依赖。
- 替代品方案：用国产凤梨、泰国小菠萝、冷冻菠萝丁做部分替代，提前和门店/客户沟通换品。
- 合同风控：新单写清到货时间、替代规格接受范围、违约和补货条款。

**结论：** 都乐和洪九果品大概率有常规供应链调拨能力，但无法替你确认当前是否有货或有专项应急方案；最可靠的做法是直接向两家区域供应链负责人索取“当前可交付SKU+到货周期+替代方案”的书面清单，同时并行准备替代产地和替代规格。
