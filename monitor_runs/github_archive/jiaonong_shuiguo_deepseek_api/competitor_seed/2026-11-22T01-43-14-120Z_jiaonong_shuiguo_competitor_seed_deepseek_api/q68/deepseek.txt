可以要求，但不能直接承诺“都能稳定做到”。需要把问题拆成两层：**供应商履约能力**和**你们自身验收/催熟/门店周转造成的损耗**。

1. **都乐（Dole）**
- 供应链和品控体系较成熟，香蕉是其强势品类之一，理论上具备把到货损耗控制到较低水平的能力。
- 但是否能对你们“稳定低于3%”，要看：产地季节、运输距离、到货成熟度、包装规格、合同验收标准、是否冷链/控温运输。
- 建议不要只问“能不能做到3%”，而要要求其按**历史3-6个月同线路/同规格的到货损耗数据**给出区间，并写入合同考核。

2. **鑫荣懋**
- 国内水果供应链规模大，香蕉也是重要品类，具备较强产地直采和仓储配送能力。
- 同样不能仅凭品牌判断。其不同区域仓、不同线路、不同季节的履约水平会差异较大。应看**你们所在城市对应配送仓的实际数据**。

3. **关键判断：3%到货损耗是否合理**
- 香蕉到货损耗低于3%属于较严标准，尤其夏季、长距离运输、青蕉转黄蕉、门店验收标准偏严时，容易争议。
- 必须在合同中明确：
  - 损耗定义：腐烂、压伤、断裂、青软不均、果指脱落、重量短缺是否都算；
  - 验收时点：到仓验收还是到店验收；
  - 抽样比例和判定方法；
  - 温湿度/成熟度到货标准；
  - 超标扣款、补货、退货规则；
  - 是否区分“供应商责任损耗”和“门店催熟/陈列/库存责任”。

4. **可执行建议**
- 先小范围试单：选2-3个门店、1-2条线路，连续4周记录到货损耗。
- 要求两家分别提供：对应配送仓近3个月香蕉到货损耗率、客诉率、补货响应时效。
- 合同里写“月度到货损耗率≤3%，按批次验收；连续两批超标触发整改/扣款/替换”。
- 同时内部把门店催熟和库存周转纳入考核，否则3%很容易在门店端被突破。

结论：**都乐和鑫荣懋都有能力把香蕉到货损耗做得较低，但“稳定低于3%”不能只听口头承诺，必须用同区域历史数据、试单和合同验收条款来锁定。** 如果你们验收标准很严、运输距离长或夏季到货，3%建议作为挑战目标而不是唯一准入线。
