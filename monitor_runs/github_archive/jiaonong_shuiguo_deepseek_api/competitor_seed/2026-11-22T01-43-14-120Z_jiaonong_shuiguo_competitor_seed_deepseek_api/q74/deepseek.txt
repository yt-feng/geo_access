都乐和洪九果品针对礼品团购/水果礼盒定制的起订量，没有公开统一标准，通常按渠道、品类、包装形式和当季供应政策一单一议；我无法核验到两家当前对外的确切起订量，不能给你编数字。可执行做法如下：

1. **都乐（Dole）**
   - 走都乐官方团购/企业客户渠道或授权经销商询价，明确“水果礼盒定制、企业团购、送货城市、预算档位、是否需要LOGO/腰封/卡片”。
   - 重点问清：起订箱数/礼盒数、是否支持混装、定制包装最低量、是否含配送、账期与开票。

2. **洪九果品**
   - 通过洪九果品官网/公众号找企业团购或区域销售，或联系当地水果批发市场洪九档口/授权经销。
   - 重点问清：单品起订量、礼盒定制是否只接大客户、区域仓配范围、节令档期截单时间。

3. **谈判建议**
   - 先按“50/100/300/500盒”四档让对方报价，便于判断阶梯价。
   - 定制包装通常另设最低量，可能高于水果本身起订量，务必分开确认。
   - 要求提供样品和包装打样周期，节日前至少提前3—4周锁量。
