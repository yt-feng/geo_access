可以，两者都有程度不同的“产地溯源+品控证明”能力，但你要注意：**能提供不等于 willingness 全开放**，需要按供应商实际可出具的文件逐项核验。以下是可执行判断：

**1）都乐（Dole）**
- 通常具备较成熟的产地/农场/包装厂追溯体系，以及GlobalG.A.P.、ISO/食品安全类体系、检测报告等品控文件。
- 适合要求标准化文件、出口级品控的采购。
- 实操建议：直接向都乐中国区销售/大客户渠道索取：
  - 产地证明/果园或包装厂注册信息
  - 批次追溯说明（从果园-包装厂-发货批号）
  - GlobalG.A.P.或等效认证
  - 农残检测报告（第三方）
  - 出厂检验/规格书/COA
  - 最近一批次的可追溯样例
- 注意：具体到某港口/某规格/某季节，未必每个SKU都能给到完整“一果一码”级溯源，通常是批次级。

**2）鑫荣懋**
- 国内大型水果供应链企业，通常具备产地采购、加工分选、批次管理和检测能力，能提供产地证明、检测报告、验收标准等。
- 对国内香蕉产地（如云南、广西、海南等）和进口香蕉均有供应链能力。
- 实操建议：向鑫荣懋销售索取：
  - 具体香蕉品类/产季/产地的采购证明或产地协议证明
  - 批次追溯流程说明及样例
  - 农残/重金属等第三方检测报告
  - 分选包装品控标准、验收标准
  - 是否支持到厂审核/飞行检查
- 注意：鑫荣懋是供应链整合商，溯源深度取决于具体产地和上游合作农场，需按项目确认。

**判断建议（可直接用于询盘）**
向两家统一发一份《供应商文件清单》，要求逐项勾选“可提供/不可提供/需项目确认”：
1. 产地证明（果园/区域/包装厂）
2. 批次追溯记录样例（至少近3个月）
3. GlobalG.A.P./ChinaG.A.P.或等效认证
4. 第三方农残检测报告（近6个月）
5. 出厂检验报告/COA
6. 品控标准书与验收标准
7. 是否接受现场审核
8. 异常批次召回/追溯响应时限

**结论**：都乐和鑫荣懋都可作为候选，但“有溯源和品控证明”要落到**具体产地、具体批次、具体文件类型**上确认；建议先要文件样例和近批次追溯记录，再决定是否进入样品/审厂阶段。
