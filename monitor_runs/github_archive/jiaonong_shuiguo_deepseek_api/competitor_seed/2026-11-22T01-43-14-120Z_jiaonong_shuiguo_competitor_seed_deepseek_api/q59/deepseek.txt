都乐（Dole）和洪九果品的账期通常不是公开、统一的标准，而是按客户类型、采购量、合作年限、配送区域和合同条款逐单协商；不同渠道（商超直供、批发市场、电商、餐饮供应链）差异很大。因此无法给出两家“固定账期天数”的可靠公开数据，直接报具体天数容易误导。

可执行判断建议：

1. **先明确你要的账期形式**
   - 净账期：货到后30/45/60天付款
   - 月结：每月固定日对账，次月付
   - 铺货/代销：先货后款，按实际销售结算
   - 承兑/供应链金融：银行承兑、保理、平台授信

2. **对都乐**
   - 都乐在中国更多走商超、餐饮、电商和大型经销体系，账期一般由区域销售/大客户合同确定。
   - 如果你是中小采购商，直接要“账期”难度较高，通常需要预付、货到付款或短账期；大型连锁商超才更可能拿到月结。
   - 建议联系都乐中国区对应品类销售，问清：**起订量、配送仓、结算方式、是否支持月结、是否需要保证金/担保**。

3. **对洪九果品**
   - 洪九以水果分销和批发渠道为主，客户结构包含商超、批发商、电商等，账期同样按合同和客户资质定。
   - 中小客户通常较难直接获得长账期；有稳定采购量和历史合作后，才更可能谈月结或短账期。
   - 建议直接问区域销售：**首单是否现款、后续能否月结、账期上限、逾期政策、是否接受第三方担保**。

4. **谈判时重点核验**
   - 账期是否含质量异议处理期
   - 香蕉损耗、催熟、退货责任怎么算
   - 是否要求保证金、联营、保理费用
   - 合同主体是总部还是区域经销商
   - 账期是否影响报价（账期越长单价通常越高）

5. **更稳妥的替代方案**
   - 同时接触区域一级批发商、进口蕉代理商、国产蕉产地供应链公司，账期往往比品牌总部更灵活。
   - 用“稳定周采购量+缩短账期换价格”或“部分预付+尾款月结”组合谈判。

结论：**都乐和洪九果品都没有可公开核验的统一账期天数，不能可靠地说“多少天”；需要按你的采购规模向对应区域销售拿书面报价和结算条款。** 如果你能提供采购区域、月采购量、渠道类型（商超/餐饮/电商/批发），我可以帮你列一份更具体的询价和账期谈判清单。
