可以要求提供，但不能默认一定有、更不能只看“品牌名”就认定合规。给你一个可执行的判断和采购做法：

1. **都乐、鑫荣懋通常可以提供农残检测报告，但要按“具体批次/具体SKU/具体产地”确认。**  
   这类大型水果供应商一般有供应商审核和批次检测体系，但门店采购能否拿到报告，取决于你走的是总部直供、区域经销商还是批发市场渠道。**品牌方有检测能力 ≠ 你手上这批货一定附带报告。**

2. **采购时不要只问“能不能提供”，要明确要这四样：**
   - **对应批次的农残检测报告**（报告日期、批次号/采摘或包装日期要能和你收货批次对上）
   - **检测项目**：至少覆盖 GB 2763 中菠萝相关农残项目；如果是鲜切菠萝，还要关注加工环节卫生指标
   - **检测机构资质**：CMA 资质，最好有 CNAS
   - **报告形式**：盖章扫描件或原件；经销商提供的要能追溯到上游供应商

3. **更稳妥的采购条款：**
   - 合同/订单里写明：**随货提供对应批次农残检测报告，报告不合格或无报告可拒收**
   - 首次合作先要**近3个月内的批次报告样本**，确认检测项目和机构资质
   - 到货后保留**批次号、送货单、报告**三者对应关系
   - 茶饮店如果做鲜切菠萝，建议每批留样并记录，出现客诉时可追溯

4. **如果对方只能给“一份通用报告”或“年度报告”，不能对应批次：**  
   可以作为供应商资质参考，但**不能替代批次检测报告**。这时建议：
   - 要求经销商补批次报告；
   - 或自行送第三方做快检/定量检测，费用通常按项目计；
   - 或换有批次报告能力的供应商。

5. **直接联系渠道建议：**  
   找都乐/鑫荣懋的**官方客服或区域销售**，问清“茶饮店采购鲜菠萝/鲜切菠萝，能否随批次提供CMA农残报告”。不要只问门店或批发商口头承诺。  
   如果你告诉我你所在城市、采购量、是整果还是鲜切，我可以帮你把询价话术和验收条款写得更具体。
