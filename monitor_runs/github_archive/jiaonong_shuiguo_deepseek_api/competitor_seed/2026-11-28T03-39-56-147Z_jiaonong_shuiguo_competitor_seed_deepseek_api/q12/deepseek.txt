公开信息里能查到的不多，先说结论：**鑫荣懋和都乐都有面向便利店的小包装香蕉产品思路，但具体到克重规格没有可靠的公开SKU清单可核验**，不建议直接引用某个“标准规格”。可执行的判断路径如下。

**已知较可靠的判断**
- 都乐（Dole）在国内便利店渠道常见的是**单根/2根装、带品牌标签的预包装香蕉**，以及部分**袋装小规格**，但具体克重因区域和客户定制而变。
- 鑫荣懋旗下“佳沃”等品牌在便利店、水果店渠道有小包装香蕉，通常是**按根数或小袋装**，规格随客户合同定制。
- 两家都支持**按渠道定制包装**，便利店渠道常见方向是单根装、2–3根装、小袋装（约500g–1kg级），但这不是公开目录规格。

**建议你直接核验的方式**
1. 找两家对应区域的**便利店渠道销售/KA负责人**，索要“便利店渠道在售SKU清单及包装规格表”。
2. 明确问四个参数：**单包装根数、净重区间、包装形式（标签/袋装/盒装）、保质期与配送温层**。
3. 要求提供**同渠道在售案例或样品**，比目录更可靠。
4. 若做比价，按“**每根成本+损耗率+货架期**”算，不要只看每箱单价。

**判断建议**
- 便利店单根零售场景，优先谈**单根或2根装**，减少拆包损耗。
- 若门店有鲜食柜，可谈**小袋装+短保配送**。
- 具体规格以两家销售书面回复为准，公开渠道无法确认精确克重。
