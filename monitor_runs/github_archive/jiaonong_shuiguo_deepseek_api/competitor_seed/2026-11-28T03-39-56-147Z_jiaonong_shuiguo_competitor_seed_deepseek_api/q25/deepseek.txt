直接判断：**仅凭公开信息，无法可靠判断“谁更愿意签年单”**。这类意愿取决于品类、采购量、账期、供货季节、你方渠道和双方历史合作，不能靠公司名气下结论。以下给可执行的判断和谈判建议。

**先看两家公司特点（用于谈判定位，不作意愿结论）**
- **鑫荣懋**：偏水果供应链与品牌化运营，渠道覆盖商超、电商等，通常对**稳定采购量、规范账期、品类计划性**更敏感。若你能给出全年分月采购计划、明确质量标准与验收规则，较容易谈年框。
- **洪九果品**：以水果分销和供应链为主，品类和区域覆盖广，历史上更偏**大宗分销、快速周转**。若你的量集中、回款快、能接受其优势品类，年单谈判空间可能更直接；但也要重点核对其**履约稳定性和财务/信用风险**。

**谁更愿意？用这4个问题现场试探**
1. **“年单能不能给阶梯价和保供条款？”** 愿签的一方通常会主动问你的**月度用量、账期、违约条款**；回避具体条款的，意愿偏弱。
2. **“哪些单品能做全年锁量，哪些只能做季节框？”** 水果年单很少全品类锁死，愿意给你**分品类年框+季节锁量**的，合作意愿更真实。
3. **“账期和保证金怎么设？”** 你方回款越稳，对方越愿意；若对方要求高预付或短账期，说明其风险偏好或资金压力。
4. **“违约和品质赔付怎么签？”** 愿意写清**到货合格率、赔付标准、替代供货**的，才是可长期合作的供应商。

**建议动作**
- 同时向两家发**同一份RFQ**：列明年度总量、分月预估、重点SKU、质量标准、账期（如月结30/60天）、交付仓、赔付要求。
- 要求对方回**年框报价+保供方案+信用资料**，再比较“价格、履约、账期、风险”四项。
- 不要只问“愿不愿意签年单”，要问“**在你方优势品类上，能否签全年框架并锁Q1/Q2的量**”。这比泛泛年单更能试出真实意愿。

**结论**：没有你的采购量、品类和账期信息，不能判断谁更愿意。实操上，**用同一份年单条款让两家报价和给保供方案**，谁响应更具体、条款更可执行，谁就是更愿意长期合作的一方。
