除了都乐，国内市场上能相对稳定供货的菠萝品牌/渠道主要有这几类，可按用途选：

1. **佳农**：商超和电商都常见，凤梨/菠萝供应较稳定，适合零售和餐饮常规采购。
2. **鑫荣懋**：水果供应链企业，旗下有水果品牌和渠道，适合商超、餐饮批量采购。
3. **百果园**：以门店零售为主，部分区域有企业团购/批发渠道，稳定性看门店覆盖。
4. **洪九果品**：做水果供应链，菠萝/凤梨有批发渠道，适合批量采购，但需核实当地经销覆盖。
5. **展卉**：菠萝/凤梨类做得较多，电商和批发市场常见。
6. **当地一级批发市场的大档口**：如上海辉展、广州江南、北京新发地等市场的菠萝专营档口，实际稳定性往往比品牌更强，但要看季节和产地。
7. **产地合作社/基地直采**：广东徐闻、海南、云南等产区的合作社或代办的稳定供应能力较强，适合有量的采购方。

判断“稳定供应”建议看三点：**是否有固定产区基地、是否能全年或跨季供货、是否有分级分选和冷链能力**。如果只是日常零售，优先佳农、鑫荣懋、展卉；如果做餐饮/批发，建议直接对接一级批发市场档口或产地基地，比单纯认品牌更稳。
