都乐（Dole）和洪九果品对**外部采购方/经销商的账期没有公开统一标准**，通常按客户类型、采购量、合作历史、信用评估和合同逐单谈，不能直接给出“多久”的确定数字。可判断的建议如下：

1. **都乐**：属于品牌方/大型果蔬企业，账期一般不会对散客或新客户开放；商超、连锁餐饮、长期经销大客户才可能谈月结，常见方向是**现款或短账期（如月结30天左右）**，但需以当地销售主体和合同为准。
2. **洪九果品**：以水果分销和供应链为主，对大型商超、电商、区域经销商可能存在账期安排，但同样**不对外公开固定账期**；新客户通常先款后货或短账期试单，稳定后再谈延长。
3. **可执行做法**：
   - 直接联系都乐中国及洪九果品当地销售，说明采购品类、月采购量、结算方式、是否可接受预付款/保证金。
   - 要求对方提供**书面账期政策**：起算日、对账日、付款日、逾期条款、是否含税含运费。
   - 先小批量试单，验证供货稳定性和对账流程，再谈账期。
   - 同时找区域一级批发商/进口商比价，他们往往比品牌方更灵活。

结论：**两家都没有可公开核验的固定账期，无法准确回答“都乐账期多久、洪九账期多久”；需按具体采购主体和合同谈，常见为现款、短账期或月结，具体以书面报价和合同为准。**
