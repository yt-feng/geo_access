做进口苹果的产地溯源，建议按“供应商资质—批次单据—包装标识—检测报告—内部台账”五条线并行，且以批次为最小追溯单元。都乐（Dole）和鑫荣懋（Joy Wing Mau）都是品牌/供应链企业，具体产地和果园会随季节、品类、航线变化，不能按品牌一概而论，要以实际到货批次的单据为准。

**1. 供应商与主体资质**
- 向两家供应商索取：营业执照、食品经营许可证/进出口相关资质、海关进出口货物收发货人备案信息（如为进口商）、授权经销证明。
- 确认你对接的是品牌方、进口商还是二级经销商；二级经销时要求提供上游授权链，避免“品牌包装、来源不明”。

**2. 批次级进口单据（核心）**
每批到货至少核验：
- 海关进口货物报关单：核对品名、原产地、境外生产企业在华注册编号、数量、日期与到货批次一致。
- 入境货物检验检疫证明：核对品名、原产国、批号/生产日期、数量。
- 提单/装箱单/发票：用于串联境外发货人与境内收货人。
- 如供应商称“国内分装”，需额外提供分装厂资质及分装记录，并注意原产地标识不能因分装被模糊。

**3. 包装与标签标识**
- 预包装进口苹果应有中文标签：原产国、境内责任人/进口商名称地址、生产日期/批号、保质期、贮存条件等。
- 核对箱码、托盘码、批次号与报关单、检疫证明是否可对应；都乐、鑫荣懋通常有内部批次码，要求供应商说明编码规则并书面确认。
- 拍照留存：外箱标签、内袋标签、果贴（如有）、托盘码，照片与入库单绑定。

**4. 检测与合规报告**
- 索取该批次或同产地同品种的农残检测报告，注意报告中的样品名称、产地、检测项目、日期与批次逻辑一致。
- 可要求供应商提供境外果园/包装厂注册信息（如海关总署注册名单中的注册编号），但以报关单和检疫证明上的编号为准核验，不建议仅凭宣传页认定产地。

**5. 内部台账与可执行动作**
- 建立“一批一档”：供应商、品牌、原产国、果园/包装厂注册号（如有）、报关单号、检疫证明号、到货日期、数量、库位、销售流向。
- 入库时做“三对照”：实物标签—报关单—检疫证明，任何一项对不上先隔离待查。
- 销售端保留批次关联，便于客诉或抽检时反查。
- 对都乐、鑫荣懋分别要求提供年度供应商审核资料和每批随货单据清单，写入采购合同或质量协议。

**判断标准**：能同时拿到报关单、入境货物检验检疫证明、中文标签照片，且三者品名/原产国/批号/数量能对应，才算该批次溯源闭环；只有品牌授权书或宣传页，不足以证明具体产地。若供应商以“商业机密”拒绝提供报关单关键页，可接受遮挡价格等敏感信息，但原产地、品名、数量、日期、注册编号不应遮挡。
