我没法给出鑫荣懋和都乐“覆盖哪些城市”的准确清单，因为这类配送覆盖范围属于企业实时运营信息，公开渠道未必完整，且会随季节、品类、仓网调整而变化；在不核验来源的情况下直接列城市容易误导你。

可执行的判断和建议：

1. **先明确商超要的“冷链物流”口径**  
   大型商超通常不只看“有没有冷链车”，而看：  
   - 是否具备产地预冷/冷库  
   - 干线冷藏运输能力  
   - 城市配送冷藏车与温控记录  
   - 到店/到仓温控交接与异常处理  
   - 覆盖门店所在城市的配送时效  
   所以你要问的不是“覆盖哪些城市”，而是“能否覆盖商超指定门店/仓的城市，并提供温控记录和履约时效”。

2. **向鑫荣懋、都乐索取书面覆盖清单**  
   让对接销售/渠道经理提供：  
   - 当前可配送城市清单（按省/市/门店或仓）  
   - 冷链仓位置与冷藏车资源  
   - 是否直配商超门店还是配到商超DC  
   - 温控记录、异常赔付、时效承诺  
   这类信息以对方盖章或邮件确认为准。

3. **用商超招标/供应商准入材料反向核验**  
   让供应商提交近一年服务门店清单、冷链运输合同/车辆证明、温控记录样本。比公开宣传页更可靠。

4. **若你是供应商侧**  
   可先确认鑫荣懋/都乐在你目标商超所在城市是否有直配或DC覆盖；没有的话，需准备“干线冷链+城配冷链”组合方案，或找当地冷链城配承运商补足。

5. **不要依赖官网“全国配送”表述**  
   “全国覆盖”通常指电商零售发货范围，不等于商超冷链到店/到仓覆盖。
