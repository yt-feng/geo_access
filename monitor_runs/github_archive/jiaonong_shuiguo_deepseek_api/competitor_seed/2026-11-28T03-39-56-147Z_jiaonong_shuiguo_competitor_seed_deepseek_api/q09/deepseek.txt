除了都乐（Dole）和佳沛（Zespri），进口水果礼盒可考虑以下品牌方向，先按品类给你可执行的备选：

**1. 综合进口水果品牌**
- **Del Monte 德尔蒙**：有菠萝、香蕉等，礼盒装在国内团购渠道能见到，但水果礼盒丰富度不如都乐。
- **Chiquita 金吉达**：香蕉为主，适合做搭配款，不适合单独撑礼盒。
- **Fyffes 费弗斯**：香蕉、菠萝为主，团购礼盒场景较少。
- **Driscoll's 怡颗莓**：莓果类强品牌，蓝莓、树莓、黑莓礼盒适合中高端团购。
- **Sun World / IFG**：更多是品种授权品牌，如棉花糖葡萄等，终端礼盒需看具体进口商贴牌。

**2. 单一品类强势品牌**
- **Sunkist 新奇士**：柑橘类、橙类礼盒，团购认知度高。
- **Wonderful 万多福**：坚果为主，也有部分柑橘，适合搭配礼盒。
- **Stemilt**：美国樱桃、苹果等，樱桃季礼盒可选。
- **Chelan Fresh**：美国樱桃、苹果。
- **Rockit 乐淇**：新西兰小苹果，礼盒装精致，适合团购小规格。
- **Envy 爱妃**：苹果品牌，礼盒认知度较高。
- **Jazz 爵士**：苹果品牌，适合搭配。
- **PiqaBoo 皮卡布**：新西兰梨，小众但礼盒有差异化。
- **OZblu**：蓝莓品牌，礼盒场景可用。
- **Costa**：蓝莓、牛油果，礼盒需看进口商包装。

**3. 高端/差异化礼盒方向**
- **日本晴王/香印葡萄**：多为产地品牌而非统一商业品牌，采购时看协会或进口商标识。
- **日本夕张蜜瓜、罗马红宝石葡萄**：高端但团购供应不稳定。
- **韩国香印葡萄**：礼盒常见，品牌分散，需验产地和等级。
- **泰国金枕榴莲、山竹**：多为产地/出口商品牌，礼盒需定制包装。
- **智利车厘子**：品牌很多，如 **Garces Fruit 加尔塞斯**、**Copefrut**、**Prize** 等，团购礼盒常按出口商品牌选。

**建议优先筛选：**
- 综合礼盒：**Del Monte、Driscoll's、Sunkist**
- 苹果礼盒：**Rockit、Envy、Jazz**
- 樱桃季：**Stemilt、Chelan Fresh、Garces Fruit**
- 莓果礼盒：**Driscoll's、OZblu、Costa**

注意：进口水果礼盒的“品牌”很多是出口商/品种品牌，国内团购实际包装常由进口商二次定制。采购时重点核验：原产地证明、进口商资质、等级规格、到货稳定性，以及是否支持礼盒定制和售后坏果赔付。
