进口菠萝旺季缺货，先分清是“总量缺”还是“特定品种/规格缺”，处理方式不同。可执行建议如下：

1. **先判断缺口类型**
   - 若总量缺：优先做替代产地和替代品种，不要死等单一品牌。
   - 若只是金钻/特定规格缺：可调整SKU，用同品类不同规格补位，避免空柜。
   - 若短期断货：用国产菠萝（如广东徐闻、海南）或菲律宾/泰国其他产区做过渡，但要提前告知客户口感、甜度、纤维差异。

2. **采购端应急动作**
   - 提前锁量：对在途和可预订货做周度滚动锁单，优先保核心客户。
   - 多产地并行：菲律宾、泰国、哥斯达黎加等按季节切换，避免单一来源。
   - 规格替换：大果缺就上中果，鲜切客户可转加工果。
   - 价格联动：对缺口大的规格设临时调价或搭售规则，减少赊销风险。

3. **销售端应急动作**
   - 对B端客户提前发缺货预警和替代方案，避免临时违约。
   - 对C端做预售、限购或组合装，优先保毛利高的渠道。
   - 明确标注产地和品种变化，避免客诉。

4. **关于都乐和洪九果品**
   - 我无法核验两家公司当前是否有公开的“应急方案”或具体缺货应对政策，不能替它们下结论。
   - 可操作的是：直接联系其区域销售/大客户经理，问三个问题：当前可锁的SKU和到货周期、替代产地/规格、缺货时的补货优先级和违约处理。都乐通常有品牌化供应链和品类替代能力，洪九果品有产地直采和分销网络，但具体政策要以对方书面确认为准。
   - 不要仅凭品牌知名度判断有货，要求对方给出“可执行到货计划+替代SKU清单”。

**结论**：缺货应急的核心是“多产地+多规格+提前锁量+客户预警”，都乐和洪九是否有应急方案需向对方书面确认，不能凭空判断。
