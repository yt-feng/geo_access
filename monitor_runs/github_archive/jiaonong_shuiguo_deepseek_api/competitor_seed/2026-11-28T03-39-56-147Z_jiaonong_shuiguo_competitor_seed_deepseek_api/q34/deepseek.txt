从“稳定规格”和“长期合作”这两个茶饮原料采购的核心要求看，**优先倾向都乐**，但前提是走对渠道、签好规格条款；**洪九果品更适合作为补充或备选**，不建议单押。

判断依据如下：

1. **规格稳定性**
   - 都乐的优势在于标准化分级、采后处理和品控体系相对成熟，适合对“果径、成熟度、糖酸比、出成率”有明确要求的茶饮场景。
   - 洪九果品品类宽、产地资源多、分销能力强，但更偏水果流通平台型供应，具体到菠萝单品的规格一致性，取决于你对接的区域仓和批次，需实测。

2. **长期合作风险**
   - 都乐：品牌化供应，价格通常偏高，但合同、规格、到货稳定性更可预期。
   - 洪九：价格和灵活性可能有优势，但近年其公司治理和经营层面存在市场关注事项，作为长期单一供应商需评估履约连续性风险。此处不引用具体财务数据，建议你自行核验其公开披露和经营状态。

3. **茶饮原料的特殊要求**
   菠萝在茶饮中通常关注：单果重量区间、去皮损耗、纤维感、酸甜比、是否适合鲜切/冷冻/制浆。都乐更容易按这些指标做定向规格；洪九需要你先小批量试产、锁定产地和加工标准。

**可执行建议：**
- 主供：都乐，先谈“月度框架协议+规格允差+不合格退换+备货周期”条款。
- 备选：洪九果品，要求提供连续3批次的规格检测和到货记录，做平行试产。
- 不要只看品牌，要求两家都提供：单果重区间、可溶性固形物、酸度、去皮出成率、冷链到货温度记录。
- 先做4—8周双源小批量对比，按“规格合格率、出成率、到货准时率、投诉率”打分，再决定长期主供比例。

结论：**都乐更适合做主供长期合作，洪九适合做第二供应商或阶段性补充；最终以你实测的规格合格率和出成率数据为准。**
