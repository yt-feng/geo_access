# 都乐和洪九果品能否保障菠萝全年供应

**结论：都乐更可能做到稳定全年供应，洪九果品存在不确定性，需要你自行核验。** 但两家是否"能做到"取决于你的采购规模、对品种/规格的要求和所在城市，建议按下面的方式验证。

## 关键判断点

**1. 菠萝本身全年有产，但品种和季节不同**
- 国内主产区：广东（徐闻为主）、海南、广西、云南、福建。海南菠萝集中在冬春，广东徐闻主要在春夏，广西、云南有补充批次，进口菠萝（菲律宾、泰国等）可填补淡季。
- 所以"全年供应"在**原料层面是可行的**，难点在于**品质一致性、品种统一和价格波动**，而不是有没有货。

**2. 都乐（Dole）**
- 都乐是全球性果蔬企业，有进口菠萝（菲律宾等）和国内供应链，商超和餐饮渠道常见，全年供应能力相对成熟。
- 但都乐以**鲜食标准果**为主，做果酱需要的可能是**加工型、次果或特定成熟度**的货，未必是其常规产品线。需要确认是否接受B端加工用途订货、起订量和价格。

**3. 洪九果品**
- 洪九是国内水果分销商，菠萝是其品类之一，有全国分销网络，理论上能做全年调配。
- 但它主要是**贸易/分销模式**，供应稳定性受产地收购和渠道波动影响，且近年经营层面有公开的财务与经营风险报道（具体以最新公开信息为准，我无法替你核验其当前履约能力）。**如果依赖单一供应商，风险较高。**

## 可执行建议

1. **直接问供应商三个问题**：能否签全年框架合同？淡季（如8–11月）货源来自哪里？能否提供加工用规格（成熟度、糖度、单果重）和样品？
2. **要求提供近12个月的供货记录或产地证明**，验证"全年"不是口头承诺。
3. **不要单押一家**：以都乐或洪九之一为主供，搭配一个产地直采或本地批发商作为淡季备份。
4. **做小批量试单**：先按1–2个月用量试供，测品质稳定性和到货准时率，再决定是否签长约。
5. **考虑替代方案**：如果鲜果全年品质不稳，"冷冻菠萝块/菠萝果茸"是茶饮店做果酱的常见替代，能解决季节性问题，也免去削皮损耗。

## 需要注意

我无法核验都乐和洪九当前的B端报价、起订量和实际履约情况，以上是基于行业常识的判断。**最终以你向两家官方渠道询价、索取供货方案后的答复为准**，尤其洪九的经营状况建议查最新公开披露后再决定是否合作。
