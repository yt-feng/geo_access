2. **专岗权限**：对接人能否直接协调订单、仓储、物流、售后和结算，还是只做“传话”。
3. **异常处理机制**：缺货、品质异议、临期、冷链断链、到货延迟的处理时限和赔付标准。

6. **试运行**：先给1—2个SKU或1个月小批量试单，记录响应时长、问题闭环率、损耗率和缺货率，再比较。
