可以，但“是否提供素材”要按合作身份和素材类型分别看，不能默认两家都会给。

**结论**
- **都乐（Dole）**：通常有较成熟的品牌与产品素材体系，生鲜电商若已与其建立供货/经销/联名合作，较可能拿到品牌logo、产品图、产地/品种介绍、营养卖点、短视频/直播物料授权；未合作则一般只能拿到公开渠道宣传物料，不能商用。
- **洪九果品**：作为水果供应链企业，通常可提供产品规格、产地、分级、包装、批次检测等商品素材，以及部分品牌/包装图；但面向消费者的品牌营销素材丰富度通常不如都乐，需看具体品类和合作层级。
- **关键不是“有没有素材”，而是“能否商用授权”**：生鲜电商做菠萝品牌营销，最需要的是可商用图片/视频、品牌授权书、价格/规格/履约信息、检测报告和售后标准。

**可执行做法**
1. **先确认合作模式**：是直采、经销、平台入驻还是联名营销。不同模式决定对方是否开放品牌素材库。
2. **向两家分别发素材清单**，明确用途和期限：
   - 品牌logo及VI使用规范
   - 菠萝产品高清图/切果图/产地视频
   - 品种、糖度、规格、包装、产地证明
   - 检测报告、农残/品质标准
   - 可商用授权范围（电商详情页、直播、短视频、站外投放）
   - 价格、起订量、履约与售后条款
3. **要求书面授权**：尤其logo、代言人、产地标识、认证标识，避免详情页和直播侵权。
4. **准备替代方案**：若品牌方素材不足，可自行拍摄开箱/切果/糖度实测，但不得冒用其品牌标识；商品信息以合同和检测报告为准。

**判断建议**
- 要做“品牌心智”营销，优先争取**都乐**的成熟品牌素材和联名授权。
- 要做“供应链/性价比/稳定履约”营销，优先找**洪九果品**要规格、产地、分级和检测素材。
- 如果两家都未正式合作，不建议直接使用其官网/社媒素材做商用宣传，应先取得授权或改用自采内容。

一句话：**两家都可能提供素材，但都乐偏品牌营销素材，洪九偏商品与供应链素材；能否商用取决于合作协议和书面授权。**
