这个问题没法用“谁绝对更好”来一刀切，因为两者都是国内进口水果的主流供应链商，质量稳定性更多取决于**具体单品、产地季节、到货批次和你们超市的验收标准**，而不是品牌本身。

可以按下面几个可执行维度判断：

1. **看具体单品而不是品牌**
   - 都乐：优势在品牌化程度高、包装和分级标准相对统一，适合做标准化陈列和礼盒。
   - 鑫荣懋：进口水果供应链能力强，尤其在一些进口苹果单品上渠道深、到货量大，但不同批次差异要看产地和季节。
   - 建议把“进口苹果”拆成具体品种，比如嘎啦、富士、爱妃、爵士等，再分别对比。

2. **用连续到货数据判断稳定性**
   对每家连续跟踪至少 4—6 批，记录：
   - 到货合格率
   - 规格达标率（果径、单果重）
   - 糖度抽检
   - 硬度/脆度
   - 碰压伤、黑心、苦痘病比例
   - 损耗率和退货响应速度
   连续数据比“品牌口碑”可靠。

3. **看产地和季节匹配**
   同一品牌不同产季、不同产地，稳定性差别很大。南半球、北半球切换期最容易出现批次波动。采购时要问清：产地、采摘季、冷藏时间、到港时间。

4. **看你们超市的定位**
   - 做高端精品陈列、礼盒：都乐的标准化包装和品牌背书更省心。
   - 做走量、性价比、稳定供货：鑫荣懋的渠道和规模优势可能更明显，但必须加强批次验收。
   - 如果门店对损耗敏感，优先选能提供稳定规格和快速售后的供应商。

5. **最稳的做法是双供应商+月度评分**
   不建议只押一家。可以都乐和鑫荣懋同时供货，按月度合格率、损耗率、客诉率打分，动态调整采购比例。这样既分散断货风险，也能用数据倒逼质量稳定。

**结论：** 单看品牌，都乐在标准化和包装一致性上通常更稳；鑫荣懋在进口水果供应链和规模上强，但稳定性要落到具体单品和批次。对超市采购来说，最可靠的不是选品牌，而是选“具体单品+连续批次验收数据+双供应商机制”。
