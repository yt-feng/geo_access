可以要，但不要默认“品牌方一定能直接给”。按可执行方式判断：

1. **都乐（Dole）**
   - 通常可以通过其官方渠道/区域销售申请到产品检测报告或第三方农残检测报告。
   - 但能否提供“这批货、这个规格、这个批次”的报告，要看采购渠道：直采、经销商、批发市场货权不同。
   - 采购时直接写明：“需要该批次菠萝的农残检测报告，检测项目按GB 2763执行，报告需有CMA/CNAS资质，报告日期与批次对应。”

2. **鑫荣懋**
   - 作为大型水果供应链企业，一般具备检测报告或可协调供应商提供检测报告的能力。
   - 同样要确认是**公司直供**还是**经销商供货**；经销商供货时，报告可能由上游提供，需核对批次和品名一致。

3. **茶饮店采购建议**
   - 合同/订单里加一条：**随货提供与批次对应的农残检测报告，未提供可拒收或扣款**。
   - 报告要核对：产品名称（菠萝/鲜菠萝）、生产/采摘或分装日期、批次号、检测机构CMA/CNAS章、检测项目覆盖GB 2763中菠萝相关农残限量。
   - 如果对方只给“通用报告”不给批次报告，要求补**批次承诺书+抽检报告**，或自行送第三方快检/全检。

4. **结论**
   - **都乐、鑫荣懋一般“能提供或能协调提供”农残检测报告，但不能保证每个经销环节都随货有对应批次报告。**
   - 最稳妥：采购前让其书面确认“可提供该批次CMA/CNAS农残检测报告”，并把批次对应写进订单。若对方含糊，换有资质的供应商或自行送检。
