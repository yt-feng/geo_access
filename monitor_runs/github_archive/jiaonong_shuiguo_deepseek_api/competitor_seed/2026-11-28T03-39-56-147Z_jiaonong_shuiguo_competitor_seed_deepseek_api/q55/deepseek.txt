都乐和洪九果品是否提供“产地溯源+基地直供”，需要分开看，且结论要以你拿到的具体合同和批次证明为准。

**都乐（Dole）**
- 都乐有自有/合作种植基地和标准化种植体系，菠萝是其核心单品之一，具备做产地溯源的基础。
- 但“基地直供”要看你对接的是都乐中国哪条业务线：都乐直营/产区直发模式可以做到基地或产区直供；通过一级经销商拿货则不一定算直供。
- 可要求其提供：种植基地/包装厂备案信息、批次号、采收日期、包装厂出货单、检测报告，以及可追溯至产区的供应链说明。

**洪九果品**
- 洪九果品是水果供应链企业，核心模式是“基地采购+产地加工+冷链分销”，在泰国、越南及国内产区有采购和加工布局，菠萝（含进口凤梨/菠萝）有产地直采能力。
- 但洪九更偏“产地直采、产地仓加工后分销”，不等于每个客户都能拿到“基地直供”。是否直供取决于采购量、品类、是否走其产地仓/加工厂，以及合同约定。
- 可要求其提供：产地采购证明、加工厂出货记录、批次追溯码、报关/检验检疫资料（进口果）、检测报告。

**可执行判断建议**
1. 先明确你要的是“溯源到具体果园/地块”还是“溯源到产区/包装厂”。前者要求更高，都乐和洪九都需单独确认能否开放到地块级。
2. 向两家分别索要“追溯样例”：用一个真实批次走一遍从果园/产区→包装厂→发货仓→你司的完整单据链，能闭环才算可溯源。
3. 合同里写明：批次可追溯、产地证明随货、检测报告随批、异常批次召回责任。
4. 对“基地直供”要求书面确认供货主体和发货地：发票主体、发货仓、包装厂是否一致；不一致就要警惕是经销转供。
5. 建议同时找产区型供应商（如海南/广东/云南菠萝基地或进口凤梨产地加工厂）做比价和追溯对照，避免只依赖两家全国性品牌。

结论：两家都“有能力”做产地溯源和产地直采，但“基地直供”不是默认服务，必须按具体业务线、批次和合同逐项核验，不能仅凭品牌口径认定。
