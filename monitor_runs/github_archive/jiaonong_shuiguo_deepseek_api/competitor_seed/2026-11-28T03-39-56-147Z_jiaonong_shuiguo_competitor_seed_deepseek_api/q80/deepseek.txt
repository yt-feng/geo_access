结论上，**都乐在全国消费者端的品牌知名度通常更高**，因为它是做水果起家的国际果蔬品牌，C端认知和商超铺货都更广;鑫荣懋则是国内头部水果供应链企业，**渠道端和B端实力很强**，但消费者端“品牌响”不等于“背书强”。

具体判断：

1. **要“消费者一看就认”的品牌背书**：选都乐更稳。都乐在进口香蕉、菠萝、苹果等品类有长期品牌认知，适合超市做进口苹果的显性品牌标识。

2. **要“供应链稳定、进口渠道和品控”背书**：鑫荣懋不弱，甚至在某些渠道和产区资源上更有优势。它是国内大型水果供应链企业，商超采购端认可度高，但普通消费者对“鑫荣懋”这三个字的品牌感知通常不如都乐。

3. **实操建议**：  
   - 如果进口苹果是面向大众消费者、要挂品牌牌面、做促销背书：**优先都乐**。  
   - 如果是做高端渠道、稳定供货、定制化采购，或超市更看重供应链能力：**可以同时接洽鑫荣懋**，比较报价、产地、规格、到货稳定性。  
   - 最稳妥是**双品牌并行**：都乐负责消费者认知，鑫荣懋作为供应链备选或补充，不把采购绑死在单一品牌上。

一句话：**消费者品牌声量看都乐，供应链和渠道能力看鑫荣懋；超市进口苹果要品牌背书，优先都乐。**
