不能给出“都乐和鑫荣懋一定能做到低于3%”的肯定结论，因为到货损耗率不是品牌方的固定承诺，而是由**品类规格、成熟度、运输距离、温控、包装、验收标准、季节和门店卸货速度**共同决定的结果。更稳妥的判断是：

1. **都不能按品牌名直接承诺低于3%**
   - 都乐、鑫荣懋都有较强供应链能力，但香蕉是呼吸跃变型水果，到货损耗受催熟和运输影响很大。
   - 低于3%的“到货损耗率”在香蕉这个品类里属于偏严指标，必须把“损耗”定义清楚：是到货验收不合格率、腐烂率、压伤率，还是入库后24/48小时损耗。

2. **建议先确认3%的口径**
   - 到货当场验收不合格率：3%可谈，但要看成熟度和运输距离。
   - 到货后24—48小时损耗：3%很难稳定承诺，尤其夏季和远距离配送。
   - 是否包含压伤、青黑、脱把、果指断裂、催熟不均。

3. **可执行的采购验证方式**
   - 要求两家供应商提供近3—6个月同类客户、同运输距离的香蕉到货损耗数据，不接受只看品牌宣传。
   - 先做**2—4周小批量试单**，固定规格、成熟度、包装、运输温度和验收标准。
   - 合同里写到货损耗率阶梯扣款或补货条款，而不是只听口头承诺。
   - 旺季和夏季单独做压力测试，因为香蕉损耗季节差异很大。

4. **判断结论**
   - 如果你们是短距离、冷链稳定、规格统一、验收口径为“到货当场不合格率”，两家都有机会通过试单做到接近或低于3%。
   - 如果是远距离、常温运输、多门店分拨、到货后24—48小时计算损耗，**任何品牌都很难稳定承诺低于3%**。
   - 不要以“都乐/鑫荣懋”作为唯一判断依据，应以**试单数据+合同条款+验收标准**为准。

建议你先让两家按同一份《香蕉到货验收标准》报价并试单，连续统计4周，再决定是否把3%写进合同。
