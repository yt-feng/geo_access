这个问题涉及具体企业的认证清单，我没法凭记忆给你准确、可核验的资质明细，直接罗列容易出错。下面给你可执行的核实路径和判断框架。

**一、正确核实渠道（按可信度排序）**

1. **认证机构官网查询**（最可靠）
   - 食品安全体系认证：认监委“全国认证认可信息公共服务平台”（cx.cnca.cn），输入企业全称可查有效证书及范围。
   - 国际体系认证：SGS、BV、TÜV、Intertek等机构官网的证书查询入口。
   - 有机/绿色食品：中国食品农产品认证信息系统（food.cnca.cn）。

2. **企业官方渠道**
   - 鑫荣懋（深圳市鑫荣懋果业科技集团）、都乐（Dole，中国运营主体为都乐（上海）水果蔬菜贸易有限公司）官网的“质量与安全”“关于我们”板块，通常会列示体系认证。
   - 上市公司或集团年报、ESG报告中的合规披露。

3. **直接向供应商索取**
   - 要求提供证书扫描件＋证书编号，并自行在发证机构官网验真，这是商超准入审核的标准做法。

**二、这类企业通常具备的资质类型（供你对照，不作事实断言）**

- ISO 22000 食品安全管理体系
- HACCP 危害分析与关键控制点
- BRCGS（全球食品安全标准，商超供应链常见要求）
- IFS 国际食品标准
- 有机产品认证（如涉及有机品类）
- 出口备案/检验检疫相关资质（如涉及进出口）
- 部分还有 GlobalG.A.P. 等源头种植端认证

**三、给商超采购的实操建议**

- 在供应商准入表中明确要求：证书编号、发证机构、有效期、认证范围（须覆盖你采购的品类和加工环节）。
- 对“集团认证”要确认覆盖的具体法人主体和工厂，避免拿总部证书套用具体供货主体。
- 证书到期前设置复检提醒，年度审核时要求更新。
