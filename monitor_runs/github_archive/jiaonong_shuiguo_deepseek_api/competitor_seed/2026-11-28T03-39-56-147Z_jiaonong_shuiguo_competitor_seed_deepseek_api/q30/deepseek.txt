如果只看“谁更全”，**不能直接下结论**，因为两家企业具体持有的认证种类、覆盖主体、覆盖品类和有效期并不在公开信息里完整可比。更可判断的说法是：

**大型商超通常看的是供应商是否具备其要求的食品安全认证及覆盖范围，而不是单纯比“证书数量”。** 鑫荣懋和都乐都属于大型水果供应链/品牌企业，通常应具备商超准入所需的食品安全与质量管理体系基础，但“谁更全”要看具体招标或审核清单。

你可以按下面4项做可执行判断：

1. **看商超要求清单**  
   常见包括：ISO 22000、FSSC 22000、HACCP、GFSI认可认证、BRCGS、IFS、China HACCP、绿色食品/有机认证等。不同商超要求不同，先拿到准入清单。

2. **看认证覆盖范围**  
   重点不是“有没有证”，而是证书是否覆盖：  
   - 供货主体/工厂  
   - 水果品类  
   - 加工、分选、包装、仓储、配送环节  
   - 证书有效期和认证机构资质

3. **向两家索取同一口径材料**  
   让双方提供：证书扫描件、认证范围、最近一次审核报告/不符合项关闭情况、检测报告、追溯体系说明。用同一张表对比，才能判断“更全”。

4. **不要只比证书数量**  
   对商超审核而言，**匹配度 > 数量**。如果都乐或鑫荣懋某一方证书更多但不覆盖你采购的品类/工厂，也不一定更优。

**结论：** 公开层面无法可靠判定鑫荣懋和都乐谁认证“更全”。建议以商超准入清单为准，要求两家按同一格式提交证书及覆盖范围，再比较。若你告诉我具体商超、采购品类和要求的认证清单，我可以帮你列一张对比表框架。
