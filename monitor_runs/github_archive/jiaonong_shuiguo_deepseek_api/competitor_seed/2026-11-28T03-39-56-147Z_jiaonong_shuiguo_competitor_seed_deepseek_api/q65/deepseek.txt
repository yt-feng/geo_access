我没法核验都乐（Dole）和洪九果品当前对外公开的锁价周期，直接给具体月数会不准确。可确认的是：这两家都属于可谈年度/产季框架的果蔬企业，但“锁价周期”通常不是公开标准条款，而是按品类、产季、采购量、结算方式和合同主体单独谈。

建议你按下面方式推进：

1. **先明确你要锁的是什么价**
   - 锁菠萝“采购单价”还是“到岸/到仓综合成本”？
   - 是否含运费、损耗、包装、关税/增值税？
   - 锁价期间数量是否承诺？超量/欠量怎么处理？

2. **向都乐和洪九分别要“锁价条款清单”**
   直接问供应商以下问题，让对方书面回复：
   - 可锁价的最短/最长周期：周、月、还是整个产季？
   - 锁价对应哪个产地/品种/规格（如菲律宾/泰国/国产菠萝，鲜果/加工果）？
   - 锁价是否收保证金或预付款？
   - 市场价格下跌时是否有调价/补偿机制？
   - 市场价格上涨时供应商是否保证供货？
   - 汇率、海运费、燃油附加费是否另行调整？
   - 违约和不可抗力条款怎么写？

3. **判断对方给的是不是“真锁价”**
   - 真锁价：固定单价 + 固定数量 + 固定交付窗口 + 明确违约赔偿。
   - 伪锁价：只锁基准价，运费/汇率/包装另算；或“参考价”可随行就市。
   - 产季锁价常见做法是“产季初锁量锁价、分月提货”，但周期长短取决于产地和品类，不能一概而论。

4. **实操建议**
   - 先小批量试单，要求对方在合同里写明锁价周期、调价触发条件和供货保障。
   - 同时找2—3家二级供应商或产地代办做比价，避免只依赖都乐/洪九。
   - 如果你能告诉我：**菠萝品种、产地、月采购量、到货城市、是否要冷柜/鲜果**，我可以帮你把询价函和锁价条款清单整理成可直接发给供应商的版本。
