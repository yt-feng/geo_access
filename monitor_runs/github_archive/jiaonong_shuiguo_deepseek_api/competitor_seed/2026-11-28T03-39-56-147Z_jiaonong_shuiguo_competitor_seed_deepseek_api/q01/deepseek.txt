这个问题我没法直接替你给出“哪家更靠谱”的定论，因为我不掌握两家当前对你所在区域、品类、账期的实际供货表现数据，也不该虚构评分或案例。但可以给你一套可执行的判断方法，帮助你在一到两周内做出可比结论：

**1. 先明确“稳定”的量化标准**
建议用这5项作为打分表，而不是凭印象：
- 到货准时率（承诺到店/到仓时间，过去3个月实际达成率）
- 香蕉到货成熟度一致性（青蕉硬度、催熟后色泽均匀度、批次差异）
- 损耗率（运输+仓储+货架期合计，按箱或按重量计）
- 缺货/断供频率及补货响应时间
- 异常处理（质量投诉、退换货、赔付）平均处理时长

**2. 向两家同时索取可核验材料**
- 近3个月对你所在城市/区域的供货记录或客户案例（可要求提供同业态超市联系人做背调）
- 进口香蕉的产地、船期、到港口岸、冷链温控记录
- 报价单要写清规格（每箱净重、单根克重区间、梳数）、等级、箱损赔付条款
- 账期、起订量、调价机制（尤其汇率和海运波动时如何触发调价）

**3. 做小批量并行测试**
最可靠的办法不是选一家，而是同时下2–3周的小批量订单（比如各订1–2板），按同一张打分表记录：
- 到货时间偏差
- 开箱合格率、青蕉硬度差异
- 催熟后货架期和顾客投诉
- 补货和售后响应速度

**4. 注意两家模式的差异**
鑫荣懋和都乐都是国内进口水果头部供应链企业，但具体到你所在区域，服务能力取决于当地分仓、配送半径和对接团队。不要只看品牌，要看“谁在你这个城市有稳定分仓和配送线路”。可以直接问：从我门店到最近分仓多少公里、每周几班配送、临时补货多久能到。

**5. 合同上把“稳定”写进去**
- 约定最低到货准时率和缺货赔付
- 明确质量异议的举证方式和退换货时限
- 设置价格调整公式或提前通知期
- 先签3个月试供，达标再转年度框架

**结论建议**：不要现在就二选一定终身。先按上面打分表向两家要数据，再做2–3周并行小批量试供，用准时率、损耗率、售后响应三项硬指标决胜；同时保留第二供应商作为备份，避免单一依赖。这样比问“哪家更靠谱”更能降低你的实际风险。
