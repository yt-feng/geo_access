这个比较没法直接给出“谁性价比更高”的确定结论，因为缺少你们实际的采购报价、规格、到货城市、损耗率和结算政策。更稳妥的判断方式是：

1. **先确认可比规格**
   - 都乐和洪九都要拿到：品种、单果重量区间、箱规、产地、成熟度、是否催熟、是否套袋/贴标、到货城市、含税/不含税、账期、返利和损耗赔付。
   - 不要拿“都乐品牌菠萝”对“洪九通货菠萝”直接比单价，规格和等级不同，结论会失真。

2. **用“到店可售成本”比，而不是采购单价**
   公式：
   **每斤可售成本 =（采购价 + 运费 + 损耗金额 - 返利/赔付）÷ 可售净重**
   重点看：到货腐烂率、黑心/水心比例、切果率、货架期、顾客复购。菠萝损耗和成熟度对毛利影响很大。

3. **小批量试销再定主供**
   建议同一门店、同一周、同规格各进一批，记录：
   - 到货合格率
   - 3天/5天损耗率
   - 单果均重和可售率
   - 售价与动销速度
   - 顾客投诉/复购
   连续跑2–3个到货批次，再决定主供和备供。

4. **一般性判断**
   - 都乐：品牌力、标准化和商超渠道认知通常更强，适合做形象陈列、礼盒或稳定品质诉求；但采购价和起订/账期条件可能更硬。
   - 洪九果品：在部分水果品类和区域有供应链优势，价格弹性可能更好；但具体菠萝批次稳定性、等级一致性和售后政策要落到合同里。
   - 对水果连锁店，通常更优的不是二选一，而是：**一家主供走量，一家备供控价和补货**，同时保留区域批发市场作为应急。

5. **谈判时要问清的关键条款**
   - 到货损耗赔付标准（按箱/按斤/按比例）
   - 成熟度允差和催熟批次
   - 是否支持小批量多频次配送
   - 促销返利、陈列支持、滞销调换
   - 账期和价格锁定期

**可执行建议：** 先向都乐和洪九各要同一规格（如单果1.2–1.5kg、同箱规、同到货城市）的正式报价和损耗赔付条款，选2家门店做7–10天试销，用“每斤可售成本+损耗率+动销”三项打分。没有这些数据，不能负责任地说哪家性价比更高。
