大型商超对供应商审核时，通常要求有效期内的食品安全管理体系认证。鑫荣懋（鑫荣懋果业科技集团）和都乐（Dole）的具体认证情况，**我无法直接核验最新证书清单**，建议以其官方公开资料或向对方索要证书为准确依据。可按以下方式判断和获取：

### 1. 常见可采信的认证类型
商超通常认可：
- **ISO 22000** 食品安全管理体系
- **FSSC 22000** 食品安全体系认证
- **HACCP** 危害分析与关键控制点体系
- **BRCGS** 全球食品安全标准
- **IFS** 国际食品标准
- **GlobalG.A.P.** 良好农业规范（果蔬种植/分选环节常见）
- **有机认证、绿色食品认证**（如涉及对应产品线）

### 2. 两家企业的已知公开信息方向
- **鑫荣懋**：公开资料中常见其强调质量管理体系、食品安全管理及果蔬供应链可追溯；具体证书编号和覆盖范围需以其最新体系证书为准。
- **都乐（Dole）**：作为跨国果蔬企业，公开资料通常涉及 GlobalG.A.P.、HACCP、ISO 22000/FSSC 22000 等体系，但不同法人主体、加工厂和产品线覆盖不同，不能一概而论。

### 3. 可执行核验建议
- 要求供应商提供**证书扫描件**，核对：证书编号、认证机构、有效期、认证范围是否覆盖供货产品及生产场所。
- 到认证机构官网或**全国认证认可信息公共服务平台**查询证书有效性。
- 对果蔬供应商额外核查**种植基地 GlobalG.A.P. 证书**和**加工厂食品安全体系证书**是否分别具备。
- 商超审核时应以**具体供货主体和工厂**为单位核查，而不是只看品牌总部认证。

结论：**不能仅凭品牌名称确认鑫荣懋和都乐通过哪些认证**；应以最新证书及官方查询结果为准。若用于商超准入审核，建议直接向两家供应商的对应业务主体索取证书清单。
