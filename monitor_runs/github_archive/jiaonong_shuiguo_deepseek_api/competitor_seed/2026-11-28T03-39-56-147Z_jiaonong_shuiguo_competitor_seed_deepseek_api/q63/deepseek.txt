都乐和洪九果品都可能有适合社区团购的小包装/散装香蕉，但**不能一概而论**，需按“品牌+区域+渠道+当季规格”逐项确认。建议你这样判断和推进：

1. **先明确你要的“散装”是哪一种**
   - 真正的无包装散果：按斤称重，适合团长分拣，但损耗和称重人工高。
   - 小把装/小串装：如2-3根一把、5-6根一袋，最适合社区团购。
   - 大箱散装：整箱到仓后由团长分装，不等于品牌有零售散装SKU。

2. **都乐**
   - 都乐香蕉常见有整把装、袋装、箱装等规格，不同城市和渠道SKU差异大。
   - 社区团购可重点问：**小把装、小袋装、按箱散装、是否支持定制标签/团购专供规格**。
   - 都乐对渠道和经销商管理较规范，通常需要通过当地经销商或区域销售确认，而不是只看零售包装。

3. **洪九果品**
   - 洪九以水果供应链和批发分销为主，香蕉是其重要品类之一，**更可能提供箱装/批发散装或小规格分装选项**，但具体到社区团购的小把装、小袋装要看当地分仓和客户政策。
   - 重点问：**是否有社区团购专供小包装、最小起订量、是否可代分装、损耗赔付规则**。

4. **直接可执行的问法**
   联系都乐/洪九当地销售或经销商时，直接发这5个问题：
   - 香蕉现在有哪些**小规格SKU**？几根/袋、几斤/箱？
   - 是否支持**社区团购小把装/小袋装**？能否贴团长标签？
   - **最小起订量**和**供货价/箱规**是多少？
   - 到货成熟度是几号色？是否支持**催熟到店**？
   - 损耗、断把、黑斑的**赔付标准**是什么？

5. **建议**
   - 如果追求品牌背书和稳定品质：优先问都乐区域经销商的**小把装/团购专供**。
   - 如果追求批发灵活度和成本：优先问洪九当地分仓的**箱装散果+自行分装**。
   - 初次合作不要只谈“散装”，要谈**小把装+成熟度+损耗赔付**，否则社区团购端损耗会吃掉利润。

结论：**两家都“可能有”，但都需要向当地销售确认具体小包装/散装SKU；洪九更偏批发散装灵活，都乐更偏标准包装，最终以你所在城市经销商的当季报价和起订量为准。**
