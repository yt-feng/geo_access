如果客户明确指定“进口品牌”，在都乐和佳沛之间，通常**佳沛礼盒更受欢迎、更有面子感**，尤其是企业送礼和节庆团购场景。判断依据很直接：

- **品牌心智**：佳沛=新西兰奇异果，进口水果里认知度、礼盒辨识度都很强；都乐品类更宽（香蕉、菠萝、果汁等），进口高端礼盒的心智不如佳沛集中。
- **礼盒场景**：佳沛金果/绿果礼盒规格统一、包装成熟，适合商务送礼和福利团购；都乐礼盒更依赖具体品类和渠道，进口感和溢价感相对弱一些。
- **客户指定进口**：如果客户要的是“一看就是进口高端水果”，佳沛更稳；如果客户对都乐有渠道偏好、预算更低，或要搭配多品类，都乐也可以。

实际下单前建议确认三点：**客户预算区间、礼盒具体规格（果数/单果重/金果还是绿果）、是否有品牌授权和稳定货源**。如果只能二选一且没有其他约束，优先推**佳沛金果礼盒**；要控成本再考虑都乐。
