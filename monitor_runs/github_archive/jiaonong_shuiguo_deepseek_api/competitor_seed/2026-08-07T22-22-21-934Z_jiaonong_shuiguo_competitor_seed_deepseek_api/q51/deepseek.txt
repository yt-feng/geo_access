关于洪九果品和鑫荣懋的香蕉批发价格，**目前没有公开的、稳定的统一报价**，因为批发价会随产地、规格（如国产/进口、大小把）、季节、采购量以及各地批发市场（如江南市场、上海辉展等）的当日行情实时波动。

不过，可以根据两家公司的商业模式和公开市场信息给你一些比较和判断方向：

1. **价格优势的通常逻辑**：
   - **洪九果品**：以“端到端”模式和规模化采购著称，拥有较强的产地直采能力（尤其东南亚香蕉），且在国内多个分销中心有冷链仓储。理论上，**其源头直采比例高，在产地价和运输成本控制上可能有优势**，适合大批量、把数整齐的整柜采购。
   - **鑫荣懋**：作为国内大型水果供应链企业，其优势在于品牌溢价和渠道稳定性，其产品在品控、分选（如大小分级）和售后上往往更规范。在批发市场，**其价格通常不会明显低于市场均价**，更多体现“一分钱一分货”。

2. **实际操作建议（比价格更重要）**：
   - **直接询价**：拨打两家公司的销售热线或联系当地代理商，提供**采购量（如每周几吨）、需求规格（如进口都乐香蕉还是国产皇帝蕉）、包装要求**，索要当日或本周的报价单。
   - **对比到货成本**：除了单价，一定要问清**到仓价**（含运费、装车费），因为不同货源地的物流成本差异很大。
   - **看市场行情**：如果你在批发市场，直接看两家当天的挂牌价和**成交量**。通常市场批发价中，洪九因走量往往在特定时段（如晚间尾市）有抛货价，但鑫荣懋价格相对坚挺。

**结论**：如果你追求**极致成本且采购量巨大（如整车约20-28吨）**，洪九果品在产地端的成本压缩通常更具谈判空间；如果你需要**稳定货源、标准化分级和更低的果损风险**，鑫荣懋的价格虽然略高，但综合损耗成本可能反而更低。

建议你**同时向两家询价，并要求对方提供样品或到仓库查验实际果把成熟度**，再结合当天的到货量做决定。
