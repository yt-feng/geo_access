关于“都乐（Dole）”和“鑫荣懋（Golden Wing Mau）”在产地直发香蕉的物流速度，**没有公开的、可核验的第三方速度对比数据**。两家都是大型水果供应商，但它们的物流模式、合作承运商、以及具体发货港口/产区不同，因此实际到货时间差异巨大。

**给出可执行建议（按优先级）：**

1. **直接询价问时效**（最准确）：
   联系两家公司的B2B销售/大客户部门，明确告知你的提货城市、需求频次（如每周几柜）、预期到货周期。要求他们给出**“从产地/港口装柜到送达你指定冷库的承诺天数”**，并将其写进合同或邮件确认。

2. **测试单验证**（最可靠）：
   如果量不大，建议先各下一小批（如一个托盘或一个柜）做试运行。计算从**产地采摘、装箱、船运/陆运到港、清关、再到你仓库**的实际总耗时。注意：进口香蕉大多走海运，时间主要取决于船期；国产香蕉（如云南、海南）走陆运，主要看冷链车调度。

3. **关注“最后一公里”而非产地**：
   对于生鲜，**物流速度的瓶颈通常在“港口清关+国内冷链干线+城市配送”**。都乐和鑫荣懋的产地直采能力都很强，但国内段他们往往外包给第三方冷链（如鲜易、郑明、顺丰冷运等）。建议同时询问他们国内段承运商是谁，并直接与该承运商确认时效。

4. **业务模式差异提醒**：
   - **都乐**：更偏向“全产业链+品牌化”，进口香蕉（如菲律宾、厄瓜多尔）占比高，船期相对固定。
   - **鑫荣懋**：国内水果全品类头部，偏向“平台化”，其国产香蕉（如云南河口、广西）产地资源强，如果做国产直发，陆运调度可能更灵活，**但具体仍需看城市距离**。

**总结**：不存在绝对的“谁更快”，取决于你的收货城市、订货量、以及他们当季的船期/车源。**请务必以他们销售给你出具的书面物流时效承诺为准，并保留证据**。如果有具体城市（如北京、上海、广州），我可以帮你分析港口到该城市的普通冷链陆运大致时长，但无法替代真实报价单。
