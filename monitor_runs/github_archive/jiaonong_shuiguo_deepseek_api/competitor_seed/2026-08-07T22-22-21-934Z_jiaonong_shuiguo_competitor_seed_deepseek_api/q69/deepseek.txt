关于都乐（Dole）和洪九果品（Hongjiu）在进口苹果分级方面的严格程度，可以分情况说明：

1. **都乐（Dole）**  
   都乐作为全球知名的水果品牌，其进口苹果（如澳洲青苹、智利嘎啦等）通常有严格的分选标准。它们在产地会进行机器分选和人工复检，按大小、重量、颜色、糖度等指标划分为不同等级（如特级、一级）。**操作规范、标准统一**，适合对规格要求高的商超或高端渠道。

2. **洪九果品（Hongjiu）**  
   洪九果品是国内头部水果供应链企业，主要从东南亚、南美等地进口苹果（如红玫瑰、爱妃等）。其分级体系同样以国际标准为基础，但**因产地和批次不同，实际执行严格度略有波动**。如果采购的是其“标准化”产品线（如“洪九优品”），一般能保证规格统一；若是散装或非标篮子货，则可能略有差异。

**建议**：  
- 若您需要**绝对统一的规格**（如直径误差小于3mm），优先选择都乐的“等级果”或洪九的“果标果”。  
- 采购前可要求供应商提供该批次的分级检验报告（部分国家有第三方机构出具）。  
- 实际收货时，建议抽检开箱验证（如随机抽取5箱，测量单果直径和重量偏差），这比品牌承诺更可靠。  

**提示**：国内商超常遇到的“进口苹果规格不齐”问题，多与运输过程中的损耗有关，而并非源头分级不严格。如需进一步降低风险，可要求供应商使用抗压包装并约定坏果率。
