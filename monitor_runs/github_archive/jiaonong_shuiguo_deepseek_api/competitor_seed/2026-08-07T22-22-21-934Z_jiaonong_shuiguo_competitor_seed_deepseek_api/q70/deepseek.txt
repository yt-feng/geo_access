都乐（Dole）和鑫荣懋（Golden Wing Mau）都是国内生鲜水果供应链领域的大型供应商，通常能提供产地溯源和品控证明。

不过，**“是不是有”取决于你对接的具体采购渠道和合同要求**。以下是几点参考建议：

1. **都乐（Dole）**：其进口香蕉（如菲律宾、厄瓜多尔等产地）通常附带相关报关单、原产地证书和检验检疫证明，能证明来源合法。但若要针对“某批次的农残检测报告”或“果园种植记录”等更细的品控溯源文件，需要向业务人员明确提出，是否能提供取决于该批次货物的记录完整性。

2. **鑫荣懋（Golden Wing Mau）**：作为国内主要水果运营商，一般也有产地记录和内部品控流程，对于大客户或批发渠道，通常可按需提供产地证明（如种植基地信息）和质检报告（如农残检测）。但具体到“是否支持二维码扫码溯源”这类功能，不一定所有批次都有。

3. **实操建议**：
   - 在询价前，**先列明你需要文件类型清单**（如：原产地证、CIQ出入境检验检疫证明、每批的农残检测报告、果园注册号等），要求对方书面确认能否提供。
   - 重点确认**“可追溯至具体种植园”**的级别，而非只是“产地国”层面。
   - 若对方无法承诺，可考虑要求样品检验采购，或寻找有“GLOBALG.A.P.（全球良好农业规范）”或“中国绿色食品”认证的中型供应商。
