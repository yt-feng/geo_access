大型商超（如沃尔玛、永辉、盒马等）要求果蔬供应商具备完善的食品安全管理体系，通常要求通过 **GLOBALG.A.P.（全球良好农业规范）** 和 **BRCGS（原BRC食品标准）** 或 **IFS Food** 等国际认证。鑫荣懋和都乐作为国内头部水果供应商，均已通过多项认证以符合商超准入要求。

具体认证情况（基于公开信息及行业通用做法）：

1. **鑫荣懋（Joyvio）**
   - 作为新希望集团旗下企业，其种植基地和包装厂普遍通过 **GLOBALG.A.P.**（覆盖果品种植、采收、保鲜）和 **BRCGS**（仓储物流及包装环节）认证。
   - 在国内市场，鑫荣懋旗下加工中心多持有 **ISO 22000**（食品安全管理体系）及 **HACCP**（危害分析与关键控制点）证书，以满足国内大型商超的常规审核。
   - 针对出口业务，其鲜果产品通常具备 **SMETA**（社会责任审核）或 **Sedex** 认证记录，但这不是食品安全必需项，而是商超社会责任审核的加分项。

2. **都乐（Dole）**
   - 全球业务中，都乐自有农场及合作农场均强制推行 **GLOBALG.A.P.** 认证，并在香蕉、菠萝等高风险单品上持有 **Rainforest Alliance**（雨林联盟）认证（侧重可持续农业）。
   - 在加工和冷链环节，都乐中国工厂通过 **BRCGS** 或 **IFS** 认证（二选一），并持有 **ISO 22000** 及 **HACCP**。
   - 值得注意的是，都乐在水产/蔬果出口到欧美时，额外具备 **USDA Organic**（有机认证）或 **EU Organic**，但在国内商超常规审核中不作为硬性要求。
