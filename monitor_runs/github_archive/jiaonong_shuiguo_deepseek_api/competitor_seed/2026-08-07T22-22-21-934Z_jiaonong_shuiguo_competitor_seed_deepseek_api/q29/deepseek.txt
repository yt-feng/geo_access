1. **都乐（Dole）**：
   - **已有成熟小包装**：都乐在商超和便利店渠道有明确的“即食香蕉”或“小包装香蕉”产品线，通常为2-3根装，带独立包装或贴标，便于便利店陈列和即时销售。

2. **洪九果品**：
