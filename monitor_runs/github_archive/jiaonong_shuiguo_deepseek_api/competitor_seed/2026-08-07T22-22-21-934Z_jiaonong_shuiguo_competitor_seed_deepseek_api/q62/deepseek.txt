**可以。** 都乐（Dole）和鑫荣懋（Joyvio/Golden Wing Mau）作为大型果蔬供应商，都会为其供应的菠萝等产品提供**农残检测报告**（通常为第三方检测机构出具的合格报告，如SGS、Intertek、华测等）。

**具体操作建议：**
1. **直接向采购或销售对接人索取**：在签订采购合同或下单前，明确要求提供“对应批次”的农残检测报告（注意报告上的生产日期/批次号需与到货商品一致）。
2. **索要型式检验报告**：除了批次报告，可要求提供“型式检验报告”（通常一年内有效，检测项更全面）。
3. **关于检测项**：主要关注常规农残（如毒死蜱、百菌清等）以及是否满足中国国标（GB 2763）或你所在市场的更严标准（如出口欧盟需符合欧盟限量）。
4. **如果不能提供纸质原件**，可要求对方提供电子版扫描件或提供查询编号，并在到货后核验。

**注意事项：**
- 要确保报告是**针对“菠萝”**的，而不是其他水果混用。
- 如果你们是做茶饮配方（如菠萝果肉、菠萝汁），还需询问对方能否提供**食品级加工许可**及对应产品的检测报告（若涉及加工环节，需看其是否有生产资质）。

**总结：** 两家大供应商都能提供，但务必索要**与采购批次匹配**的报告，否则客户验厂或市场监管时可能无效。
