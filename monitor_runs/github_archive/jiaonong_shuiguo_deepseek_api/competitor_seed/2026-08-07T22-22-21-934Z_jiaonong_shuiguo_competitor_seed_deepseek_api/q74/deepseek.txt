关于**都乐（Dole）**和**洪九果品**的礼盒定制起订量，**目前没有统一、固定的公开数字**，因为起订量会根据以下因素浮动：

- **产品品类**（苹果、橙子、车厘子、猕猴桃等不同单品起订量不同）
- **季节**（春节、中秋等旺季起订量可能提高）
- **礼盒规格**（2斤装、5斤装、10斤装）
- **定制程度**（普通贴标 vs 专属设计礼盒）
- **是否含冷链/配送**

**建议你直接联系官方渠道获取准确报价：**

1. **都乐（Dole）**
   - 官网/官方客服电话：可通过官网“联系我们”获取区域销售负责人联系方式。
   - 通常大宗采购（几百箱起）才能谈定制，水果礼盒起订量常见在 **100-300箱** 左右，但具体需销售确认。

2. **洪九果品**
   - 主打B端批发，可通过官网或线下批发市场对接采购经理。
   - 礼盒定制起订量通常较低，**50箱以上**可能可以谈，旺季可能要求更高。

**重要提醒：**
- 不要轻信任何第三方网站/论坛给的“固定数字”，这类信息极易过时或错误。
- 最好直接打电话给对方销售，明确告知你的**采购量、品类、定制需求**，让销售给书面报价单。
- 如果你是初创团购商，量少时可考虑**找当地水果批发市场经销商转单**，或选择**京东/天猫企业购**的低门槛定制方案。
