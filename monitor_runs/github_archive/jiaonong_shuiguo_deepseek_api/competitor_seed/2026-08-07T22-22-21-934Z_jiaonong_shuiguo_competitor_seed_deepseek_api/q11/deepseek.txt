关于“都乐”和“洪九果品”这两个品牌的菠萝性价比，我需要先说明：**我无法实时查询具体市场价格和促销信息**，且不同城市、不同进货渠道（批发/零售）、季节波动都会影响价格，因此无法给出一个准确的“谁更便宜”的数字结论。

但基于品牌定位和产品特点，我可以给你一个**可执行的判断框架**：

---

### 1. 品牌定位差异（关键因素）

- **都乐（Dole）**：国际品牌，做全球供应链，菠萝多为菲律宾、泰国进口，品质稳定（糖度、外观、成熟度控制严格），包装标准化程度高。通常定位中高端，**价格偏贵**，但损耗率低，适合做精品货架或直接面向C端零售。
- **洪九果品**：国内头部水果供应链公司（尤其在西南地区），以泰国、越南等东南亚菠萝为主（也有国产菠萝），强调**产地直采、性价比**，批发渠道能力强，**单价通常低于都乐**，但品质波动可能略大，需要自己验货。

---

### 2. 性价比测算建议（直接可做）

“性价比”不能只看进货价，要算**综合成本**：

**总成本 = 采购单价 × 采购数量 + 运输损耗 + 仓储损耗 + 人工处理成本 + 退货/坏果率损失**

**实际建议**：
- 先向两家供应商分别索取**批量报价单**（建议对比：5吨/10吨/整车），同时要求提供**售后赔付政策**（坏果率超过多少赔）。
- 然后做**抽样测试**：各进一箱，按门店标准验货（糖度、果形、黑心率、常温存放3天后的腐烂率）。
- **最终判断标准**：如果洪九的损耗率比都乐高5%以上，那看似便宜的价格可能反而不划算；如果损耗率接近，洪九大概率胜出。

---

### 3. 执行建议（针对连锁店）

- **如果走性价比路线**（社区店、打折促销）：优先试一下洪九果品，但必须**签订质量条款合同**，约定坏果率（一般≤3%可接受）。
- **如果走品质路线**（高端门店、企业团购）：都乐更稳，但建议把量控制在10%以内，作为品质背书。
- **混合策略**：两品牌各进少量试销两周，记录**每公斤毛利和顾客差评率**，用数据决定主推哪个。

---

### 4. 容易踩的坑

- 别只看“进口”标签：两家的进口菠萝都有不同产地等级，同品牌下也有A/B/C级，报价时要问清是**几级果**（例如都乐有“金菠萝”和普通菠萝，洪九也分“精品果”和“通货”）。
- 菠萝季节性强（东南亚旺季通常3-6月），**旺季洪九的议价空间更大**，淡季都乐价格可能反而接近。
