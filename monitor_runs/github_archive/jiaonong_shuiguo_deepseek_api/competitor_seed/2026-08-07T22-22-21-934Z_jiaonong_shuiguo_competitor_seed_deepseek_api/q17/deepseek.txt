在大型商超（KA，即Key Account，重点客户）的招标中，**都乐（Dole）和鑫荣懋（XinRongMao）各有明显的侧重**，但总体来看，**都乐在“品牌溢价”和“单品标准化”上更强，而鑫荣懋在“全品类运营”和“渠道综合服务”上更占优**。

具体分析如下，你可以根据商超的定位和招标需求来权衡：

**1. 都乐（Dole）—— 胜在“品牌力”与“高端标杆”**

-   **核心优势**：**国际品牌背书**。都乐是全球性的水果巨头，其香蕉、菠萝、牛油果等单品在消费者心中认知度极高，自带“稳定品质”标签。
-   **KA操作特点**：都乐在商超内通常占据**黄金位置**（主通道端头、生鲜区第一陈列位），走**高客单价**路线。
-   **擅长场景**：适合针对**中高端客群**的商超，或者商超需要提升生鲜区整体档次、打造“进口水果”形象、以及做**爆款单品引流**（比如常年稳定的都乐香蕉）时。它对**陈列标准**和**冷链损耗控制**有极严格的体系，执行力强。

**2. 鑫荣懋（XinRongMao）—— 胜在“全品类覆盖”与“本地服务”**

-   **核心优势**：**全球采购网络 + 本土化运营**。鑫荣懋是国内水果流通龙头，除了进口果，其国产果（如新疆西梅、云南蓝莓等）资源极强，能做到**产地直采**。
-   **KA操作特点**：它更像一个**“一站式水果解决方案供应商”**，能为商超提供**全品类**（国产+进口、当季+长线）的组合方案。善于配合商超做**档期促销**（如年货节、中秋节），且**仓配物流响应速度快**，能覆盖商超的多区域门店，减少缺货率。
-   **擅长场景**：适合**追求毛利和动销平衡**的商超，或者需要**多门店、多区域统一配送**，以及希望减少水果供应商数量、由一家统包以提高采购效率的招标项目。

---

**给招标方的最终建议（关键判断点）：**

-   **如果招标侧重“单品爆款”和“品牌背书”**（例如：商超主打精品路线，SKU不多但要求件件是精品），**选都乐**更稳妥。
-   **如果招标侧重“全品类综合毛利”和“门店运营深度”**（例如：商超要覆盖社区型客群，需要丰富的水果结构，且要求供应商派人驻店打理排面），**选鑫荣懋**更合适。

**实操提醒**：在招标评分表中，建议不单看报价，重点看**“报损率承诺”**（谁承担门店损耗）和**“新品试销支持”**（能否带来独家的差异化品种）。这两点上，都乐惯例按国际标准走，鑫荣懋则更灵活可谈。
