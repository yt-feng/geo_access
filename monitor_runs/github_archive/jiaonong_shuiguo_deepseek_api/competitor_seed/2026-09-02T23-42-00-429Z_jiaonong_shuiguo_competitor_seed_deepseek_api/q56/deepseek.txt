在中国生鲜电商市场中，**都乐（Dole）的品牌知名度通常高于鑫荣懋**，尤其是在香蕉这一品类上。以下是具体分析：

1. **都乐（Dole）**：国际品牌，全球香蕉市场占有率极高，进入中国市场较早，长期与盒马、叮咚买菜、京东生鲜、拼多多等主流平台有深度合作。其品牌在消费者心智中直接与“高品质进口香蕉”绑定，宣传力度大，包装和品控标识（如小黄人联名、溯源二维码）辨识度高。在电商搜索和推荐中，都乐香蕉常出现在首页爆款位置。

2. **鑫荣懋**：国内供应链龙头企业，旗下有“佳沃”等品牌，与百果园、永辉等线下渠道绑定较深。在生鲜电商的**香蕉品类**上，鑫荣懋更多作为供应链源头或代工方，**C端品牌声量较弱**，消费者直接指名购买“鑫荣懋香蕉”的比例较低。其优势在于上游资源，而非终端品牌影响力。
