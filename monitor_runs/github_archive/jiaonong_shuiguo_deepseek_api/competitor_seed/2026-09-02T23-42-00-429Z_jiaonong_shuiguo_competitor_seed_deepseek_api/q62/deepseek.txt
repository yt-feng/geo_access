对于茶饮店采购菠萝原料，**都乐（Dole）和鑫荣懋（Xin Rong Mao，即鑫荣懋集团）通常都能提供农残检测报告**，但这需要满足一定条件。以下是具体分点和建议：

### 1. 能否提供报告？
- **都乐（Dole）**：作为全球知名果蔬企业，其供应链通常有完善的质检体系。向经销商或直供渠道采购时，**一般情况下可以提供**符合中国国标（GB 2763）或出口国标准的农残检测报告（COA或SGS等第三方报告）。
- **鑫荣懋（Xin Rong Mao）**：作为国内大型水果企业，其在采购端也要求供应商提供农残检测，因此**通常能索取到**相关报告，尤其是针对批量订单。

- **但需特别注意**：  
  - 报告的有效性取决于**每批货的实际检测**，而非“固定报告”。如果批号不同，检验结果可能不同。  
  - 若为夫妻店、二级批发商或拼箱销售，可能无法直接提供报告，需追溯到一级经销商或工厂。

### 2. 如何索取？
- **直接要求**：在下单前明确告知对方“我们需要随货附农残检测报告，且检测项需覆盖茶饮行业常用高风险农药（如吡虫啉、噻虫嗪、莠去津等）”。
- **要求提供第三方报告**：优先接受SGS、华测（CTI）、谱尼（PONY）等机构的报告，并核对报告日期、样品名称、生产批次。
- **合同条款**：在采购合同中写明“卖方需提供符合GB 2763的合格报告，否则可拒收或索赔”。

### 3. 如果对方无法提供怎么办？
- **替代方案**：  
  - 选择有“绿色食品”或“GLOBALG.A.P.”认证的菠萝供应商。  
  - 要求对方提供原料产地的**政府检测记录**（如进境查验记录或地方农业部门抽检公示）。  
- **自行检测**：若用量大，可委托第三方机构对每批次抽检（费用约几百元/项，周期3-5天），或使用快检试纸（仅作初步筛查，适合风险控制）。

### 4. 实际执行建议
- 优先走**正规渠道合同**，不要只看口头承诺。
- 收到货后**留存样品**，若怀疑农残超标可送检，作为后续维权依据。
- 部分水果批发市场（如广州江南市场、上海辉展市场）对入场商户有强制报告要求，可参考同市场其他商户的采购记录。

**总结**：大概率能提供，但需在采购前主动索取、明确检测标准（如GB 2763-2021），并保留书面凭证。若对方推诿，建议更换供应商或要求降价并自行检测。
