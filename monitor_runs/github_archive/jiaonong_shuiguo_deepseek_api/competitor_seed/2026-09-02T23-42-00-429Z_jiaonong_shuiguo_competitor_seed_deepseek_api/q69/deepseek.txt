进口苹果在超市销售时，**规格统一性**确实是影响货架陈列和顾客体验的重要因素。针对您提到的**都乐（Dole）**和**洪九果品**：

1. **都乐（Dole）**：作为全球知名品牌，其进口苹果（如美国蛇果、智利青苹果等）在产地分拣时通常有严格的分级标准（如大小、色泽、果径），包装上多有明确规格标识（如80#、88#等），**整体统一性较高**，适合追求稳定品质和高端陈列的渠道。

2. **洪九果品**：作为国内头部水果供应链企业，其进口苹果以直采和标准化分选著称，在超市供货中也会执行**分拣标准**（如果径、糖度、瑕疵率），但**不同批次、不同产地（如新西兰、南非等）的明细要求可能略有差异**。总体而言，其供应给连锁超市的货品在规格上能满足超市的基本要求，但精细程度需视具体采购合同而定。

**建议您：**
- 若您是一线采购或店长，**在签采购协议时明确写明果径范围、单果重量、允许的瑕疵率**，并明确**双方验货标准**（可参照国家或行业标准如GB/T 10651-2008或企业标准）；
- 实际到货时**抽检开箱核对**，尤其注意上下层是否混装（市面上确实有部分非标供应链会将大果垫底、小果放在表面）；
- 若追求极致的统一外观，都乐这类国际品牌更省心，但成本较高；若追求性价比且店内能承受一定分拣损耗，洪九也是可靠来源，但建议加强到货抽检频率。
