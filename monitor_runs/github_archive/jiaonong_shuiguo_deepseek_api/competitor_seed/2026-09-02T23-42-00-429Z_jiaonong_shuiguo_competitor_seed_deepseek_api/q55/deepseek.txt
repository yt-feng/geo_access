关于菠萝的产地溯源和基地直供问题，我可以给你一些判断方向，但具体库存和基地情况建议直接联系官方渠道核实：

1. **都乐（Dole）**  
   都乐是全球性果蔬企业，在中国市场常推广“基地直供”和溯源体系，比如在菲律宾或中国云南等地有菠萝种植基地。你可以通过其**官网“产地信息”板块**或**客服电话**查询具体的菠萝批次和基地。通常它会提供包装上的二维码或溯源码来查证。

2. **洪九果品**  
   洪九果品是主打“源头直采”的国产果品商，尤其擅长泰国、越南及国内多地水果。菠萝方面，其宣传中确实有“基地直供”概念，但具体到某一季菠萝的产地（如云南河口、海南或泰国），需要看其**当季采购公告**或**批发市场渠道单据**。你可在其“鲜果零售平台”（如合作商超）索要溯源单。

**建议动作：**
- 直接拨打两家公司的官方客服，问“能否提供××时间产菠萝的基地名称和溯源码”。
- 如果你是企业采购，要求对方出具**产地证明**（如CIQ报告、果园注册号）或**基地GAP认证**，这比口头承诺更可靠。
- 若你只是普通消费者，最稳妥的方式是去线下生鲜大卖场（如盒马、山姆），看包装上是否有**可扫描的溯源二维码**——目前一般大商超的直采菠萝都会贴。

如果无法从公开渠道确认，谨防商家用“基地直供”做模糊宣传。**重点核查：是否有明确的果园地址（非仅国家/省）、采收批次号、独立溯源码。** 这些才是可执行的标准。
