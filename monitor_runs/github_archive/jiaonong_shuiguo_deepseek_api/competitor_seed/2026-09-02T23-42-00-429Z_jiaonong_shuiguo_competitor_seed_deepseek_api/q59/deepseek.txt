关于“都乐（Dole）”和“洪九果品”的账期政策，我无法提供确切天数，因为**账期是商业谈判结果，并非公开固定标准**，而且会随采购量、合作历史、市场行情波动。

以下是可直接参考的建议：

1. **都乐（进口品牌为主）**  
   - 通常对国内商超、批发商有 **月结30天、45天或60天** 的账期，取决于客户规模和订单稳定性。  
   - 如果你是从都乐的一级经销商或大区代理拿货，账期普遍较短（现款或15天），直签总部的账期可能最长到60天。

2. **洪九果品（国内头部进口水果分销商）**  
   - 洪九对大型连锁商超能提供 **30-60天账期**，对中小客户多为 **现款现货或7-15天**。  
   - 其核心结算模式常与“车板交易”或“代卖”挂钩，个别批发市场档口是日结。

**实操建议**（关键）：  
- 不要只看品牌名，直接联系他们的**区域销售负责人**，明确告知“每月采购量、稳定每周几柜、付款记录良好”等条件，索要书面账期方案。  
- 若您是初创采购商，建议第一笔采用“现款换取更长后续账期”的让步策略。  
- 警惕网上流传的“固定60天”等说法，避免对方口头承诺但合同不写。

如需进一步帮您起草合作谈判要点，可以补充您的采购规模（月箱数）和所在城市。
