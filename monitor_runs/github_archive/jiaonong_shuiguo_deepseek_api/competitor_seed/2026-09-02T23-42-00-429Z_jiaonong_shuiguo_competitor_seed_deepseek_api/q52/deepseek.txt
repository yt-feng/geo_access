关于菠萝到货损耗率的具体数据，**没有公开的统一标准**。损耗率高度依赖于采购季节、运输距离、包装方式、仓储条件以及收货时的验收标准，不同批次之间差异可能较大。

不过，基于常见的行业经验和这两家供应商的普遍合作模式，可以给你以下参考和建议：

**1. 行业经验参考值（非官方数据）**
- 都乐（Dole）和鑫荣懋作为大型水果供应商，通常对包装和冷链控制较严格。
- 按箱采购（如18-22斤/箱）时，正常情况下的到货损耗率（指软烂、破损、严重畸形等无法使用的）通常在 **3% - 8%** 之间。
- 如果运输时间超过48小时，或夏季高温高湿环境下，损耗率可能会上浮至 **8% - 12%**。

**2. 更可靠的做法（针对稳定采购）**
由于你要求“稳定规格”，建议不要依赖市场通用值，而是做以下动作：

- **索要企业标准**：直接向都乐或鑫荣懋的区域销售经理索取其内部《菠萝商品验收标准》或《到货损耗赔付协议》。大型供应商通常对整箱腐烂率有明确赔付条款（例如：单箱内烂果超过2个可整箱退换）。
- **进行小批量试单**：各进1-2箱，实际称重、检查外观和内部黑心率（菠萝常见的隐性损耗是内部褐变，外表看不出），记录真实损耗数。
- **约定“过磅损耗”**：在合同里写清楚“按净重结算”还是“按毛重结算”，以及特定时间点（如到货后8小时内）的损耗责任归属。

**3. 需要特别注意的风险**
- 菠萝是后熟型水果，如果到货时已过分成熟，即便外表完好，切开后内部可能已经发酵，这不算“破损”，但属于高损耗情况。
- 冬春季（如2-4月）由于菠萝糖度低、纤维硬，表皮受伤后更易腐败；夏秋季节损耗更高。

**结论**：无法给你一个固定数字，建议直接向供应商索取书面损耗保障条款，并先做3-5箱试单实测。如果追求极致稳定，可以考虑在合同中写明“到货时整体次品率超过5%，超出部分按采购价扣除”。
