关于“都乐”和“鑫荣懋”在香蕉产地直发中的具体物流速度，**我无法给出确切的对比数据**，因为这两家企业均未公开其面向不同城市的实时冷链时效承诺，且物流速度会受以下因素影响：

- **发货地**：香蕉产地（如菲律宾、厄瓜多尔或国内云南、海南）与目的地的距离。
- **物流模式**：是空运、海运+冷链，还是陆运。
- **城市范围**：一线城市可能次日达，而二三线城市可能需要2-3天。
- **批次与库存**：是否为当季鲜果，以及是否遇到船期或清关延迟。

**建议你采用以下可执行的验证方法**（比猜测更可靠）：

1. **直接询价并索要时效承诺**：联系两家公司的销售/客服，明确告知你的收货城市（例如上海、长沙），要求他们给出**从产地到你的仓库**的预计到货小时数（或天数），并要求写入合同或书面报价单。
2. **小批量试单测试**：订购一小箱或直接通过其To B平台下单，实际测试报关、到货时间及损耗率。这是最直接衡量速度的方式。
3. **关注冷链环节**：速度之外，更要确认是否全程冷链。香蕉对温度敏感（13-14℃），物流快但脱冷反而易催熟变质。
4. **询问“批次到货”而非“发货日”**：因为香蕉进口常涉及船舶到港或果园直采，确认“从果园采摘到送达仓库”的总周期比单纯问“快递几天”更有意义。
