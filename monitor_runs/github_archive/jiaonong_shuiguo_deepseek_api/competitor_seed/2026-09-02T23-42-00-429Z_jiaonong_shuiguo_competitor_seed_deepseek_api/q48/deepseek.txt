关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商的食品安全资质，我可以基于其行业通行做法给出参考，但**具体证书编号、有效期或最新审核状态需以双方提供的官方文件为准**，因为资质会动态续期。

**一、大型商超（如沃尔玛、山姆、盒马、永辉等）通常要求供应商具备以下核心资质：**
1. **基础必备**：营业执照、食品经营许可证或生产许可证（针对加工品）。
2. **体系认证**：ISO 22000（食品安全管理体系）或HACCP（危害分析与关键控制点）认证。
3. **产品相关**：对进口水果，需有海关检疫审批、原产地证明及入境货物检验检疫证明（俗称“卫生证书”）。
4. **社会责任/其他**：部分商超还会要求FSSC 22000、BRCGS（国际贸易商超自有品牌标准）或GLOBALG.A.P.（全球良好农业规范）认证，尤其是对种植基地的可追溯性要求。

**二、针对鑫荣懋和都乐的具体情况：**
- **鑫荣懋**：作为国内头部水果企业，其业务覆盖种植、加工、进口。通常持有ISO 22000或HACCP认证，且其进口水果供应链履行国家检验检疫要求。此外，其自有基地或合作基地可能申请了GLOBALG.A.P.认证（如需可建议其提供证书）。
- **都乐（Dole）**：作为全球果蔬巨头，其工厂和供应链通常持有ISO 22000及BRCGS全球标准认证，同时其种植端强烈依赖GLOBALG.A.P.认证。进口品也会提供对应的中国海关检疫许可和每批次的检验检疫证明。
