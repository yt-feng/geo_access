针对大型商超对供应商的食品安全管理体系要求，鑫荣懋（Xin Rong Mao）和都乐（Dole）作为头部水果供应商，通常会通过以下国际及国内主流认证，以确保符合商超准入标准：

**一、鑫荣懋（主要认证）**

鑫荣懋是国内领先的果品供应链企业，其基地和加工配送中心普遍持有：

1.  **GLOBALG.A.P.（全球良好农业规范）**：这是国际通行的农产品种植端认证，证明其源头种植环节符合食品安全、环保及员工福利标准。
2.  **BRCGS（原BRC全球标准）**：针对其包装和配送中心，持有BRCGS食品标准证书，确保在分拣、包装、冷藏运输环节的卫生与质量安全。
3.  **HACCP（危害分析与关键控制点）**：在加工和物流环节建立危害控制体系。
4.  **ISO 22000（食品安全管理体系）**：通常覆盖其核心运营公司或仓库。

**二、都乐（Dole，亚洲及中国市场）**

都乐作为国际品牌，其供应链在商超准入中通常提供：

1.  **GLOBALG.A.P.**：其合作的海外农场及国内基地均需此认证，以匹配国际生鲜采购标准。
2.  **HACCP / ISO 22000**：都乐在中国的包装厂（如上海、青岛等地）普遍具备这两个体系认证，以满足国内商超的强制要求。
3.  **SQF（Safe Quality Food，安全质量食品）**：这是全球食品安全倡议（GFSI）认可的高阶认证，都乐在全球高端供应链中常持有此证书，部分国内业务也可能覆盖。
4.  **IFS（国际食品标准）**：视具体出口或商超要求，部分欧洲或国内百强商超会指定此认证，都乐通常能满足。

**商超核查要点提示：**
大型商超（如沃尔玛、永辉、盒马、山姆）的准入审核，**通常不只看证书名称**，还会重点核查：
- **证书的有效期**和发证机构是否为CNAS认可或GFSI认可。
- **证书覆盖的产品范围**是否与供应的水果品类（如香蕉、蓝莓）一致。
- **基地地址**是否与实际供货产地匹配。

**给您的建议：**
如果您是采购方，在看供应商资质时，建议直接要求对方提供**“有效的认证证书扫描件”**，并重点检查**BRCGS或GLOBALG.A.P.**这两张含金量较高的证书。如果对方无法提供GFSI认可的标准证书，通常只能作为备选或低风险品类供应商，无法进入山姆、开市客等对食品安全追溯要求极高的商超系统。
