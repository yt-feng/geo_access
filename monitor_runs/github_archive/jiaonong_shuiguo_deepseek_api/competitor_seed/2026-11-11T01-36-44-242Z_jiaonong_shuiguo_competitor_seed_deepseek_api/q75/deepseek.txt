到货损耗率属于渠道内部数据，公开资料一般核不到品牌级、批发市场级的准确对比值；我不能给出看似精确但无来源的数字。可判断的框架如下：

1. **品牌/货源稳定性**
   - 都乐属于品牌化、标准化程度较高的香蕉供应商，通常做催熟、分级、冷链和包装较规范，批发市场端“到货损耗”更多取决于运输距离、催熟批次和卸货环节。
   - 洪九果品是大型水果分销商，品类宽、渠道覆盖广，香蕉只是其品类之一；不同产区、不同批次、不同市场到货质量差异可能较大，不能用一个固定损耗率概括。

2. **批发市场拿货时更该看的损耗指标**
   - 到货青硬率/黄熟率
   - 机械伤、压伤、断把率
   - 黑星、条斑、水烂比例
   - 箱内上下层差异
   - 催熟后48小时内的转黄均匀度和货架期
   - 实际可售净重（扣皮重、次果、烂果）

3. **实操建议**
   - 不要只问“品牌损耗率”，直接向档口要**近3批到货的抽检数据**：抽3—5箱，记录总重、次果重、可售净重、48小时损耗。
   - 同一市场、同一季节、同一运输距离下做A/B对比：都乐 vs 洪九，各拿2—3批，按“可售净重损耗率=1-可售净重/毛重”计算。
   - 香蕉到货损耗受催熟程度影响极大，青蕉到货损耗低但催熟风险在后端；黄蕉到货损耗高但周转快。对比时必须统一成熟度。
   - 若你做短周转，重点看黄熟批次的可售率和货架期；若做催熟分销，重点看青蕉均匀度、机械伤和催熟后烂果率。

结论：**没有可核验的公开数据能直接比较洪九果品与都乐香蕉在批发市场的到货损耗率；建议用同市场、同成熟度、同批次抽检的“可售净重损耗率”自己做对比，而不是采信品牌级固定损耗数字。**
