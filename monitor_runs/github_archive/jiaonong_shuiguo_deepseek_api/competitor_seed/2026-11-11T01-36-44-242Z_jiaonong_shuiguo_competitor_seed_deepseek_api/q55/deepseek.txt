都乐和洪九都可以作为“有产地溯源能力”的候选，但需要区分“基地直供”的实际含义和核验方式：

1. **都乐**
   - 属于品牌化、标准化程度较高的水果供应商，通常有较完善的产地、批次、加工厂和物流追溯体系。
   - 是否“基地直供”取决于具体品类、季节和采购渠道：都乐既有自有/合作基地，也会通过签约果园、加工厂和区域供应商组织货源。
   - 建议要求其提供：具体菠萝品种的产地证明、果园/包装厂备案信息、批次追溯码、检测报告和供货合同中的溯源条款。

2. **洪九果品**
   - 以水果供应链和产地直采为主要模式之一，菠萝是其重要品类，通常具备产地采购、分选包装和冷链配送能力。
   - “基地直供”要落到具体产区、果园和批次，不能只看公司宣传。需确认是自有基地、合作基地还是产地直采。
   - 建议要求其提供：合作基地清单或产地证明、采购合同/订单溯源、包装厂信息、农残检测报告、冷链记录。

**可执行判断建议：**
- 向两家都发同一份《产地溯源供应商问卷》，要求填写：菠萝品种、产区（县/镇）、果园或合作社名称、包装厂、采收批次、检测报告编号、冷链路径、是否可提供追溯码。
- 合同里写明“可追溯到具体果园/合作社及采收批次”，并约定随机抽检和资料不实责任。
- 先小批量试单，抽取包装箱追溯码反向核验产地和检测报告是否一致。
- 若你要求“严格基地直供”，优先选能提供果园合同、基地备案和批次对应关系的供应商；仅提供公司级溯源不够。

结论：两家都具备较强的产地组织和溯源基础，但是否“基地直供”不能一概而论，必须以具体菠萝产区、批次和合同资料核验为准。
