我没法核验都乐和鑫荣懋当前对具体水果连锁的供货稳定性数据，所以不给“谁更稳”的结论。但可以给你一套可执行的判断和谈判方法，水果连锁上进口苹果建议按下面做。

**1. 先明确“稳定性”拆成四个指标**
- 到货准时率：约定周度到货窗口，统计连续8–12周准时率。
- 规格达标率：果径、糖度、色泽、瑕疵率，按批次抽检。
- 缺货/替换率：缺货是否提前通知、是否允许同等级替换、替换价差谁承担。
- 价格波动机制：进口苹果受产季、汇率、海运影响，要求书面价格调整规则和提前通知期。

**2. 对两家做同条件试单**
- 各给2–3个SKU、连续4–6周、固定周订货量，记录准时率、损耗率、客诉率、毛利。
- 要求提供近3个月对应品类的供货记录或至少可验证的客户案例，但不能只看案例，以你门店试单数据为准。
- 试单期不要签独家或大额预付，账期尽量短。

**3. 合同里必须写清楚**
- 最低供货保障和缺货违约金；
- 规格不符的退换货时限与费用承担；
- 价格调整提前通知天数；
- 冷链到店温度记录和货损责任；
- 同一产区/品种的替代方案。

**4. 建议的渠道策略**
- 不要只依赖一家：都乐、鑫荣懋可同时做“主供+备供”，按品类或门店分组；
- 保留一个本地进口商或批发市场作为应急补充；
- 对进口苹果设置安全库存，按周销量覆盖1.5–2周为宜，具体看你的周转和冷链条件。

**直接判断标准**：连续8周准时率≥95%、规格达标率≥95%、缺货提前通知率100%、综合毛利达标，才可升为主供；否则维持双供或换备供。这样比问“哪家更稳”更能控制风险。
