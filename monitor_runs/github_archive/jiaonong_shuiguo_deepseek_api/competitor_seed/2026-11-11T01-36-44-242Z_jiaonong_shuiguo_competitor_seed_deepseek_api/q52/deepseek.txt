这个数据我没法直接给你准确数值。都乐和鑫荣懋的到货损耗率没有公开统一标准，会随品类（鲜菠萝/去皮菠萝/菠萝丁）、季节、产地、运输距离、验收标准和批次波动，任何单一数字都不可靠。

可执行建议：

1. **向供应商索取批次质检/到货验收记录**：要求提供近3个月同规格菠萝的到货验收单，重点看到货数量、不合格数量、扣重比例、损耗原因（机械伤、腐烂、成熟度不符）。
2. **自己跑小批量对比测试**：各下1—2个托盘同规格订单，按统一验收标准记录：
   - 到货总重 vs 订单净重
   - 外观不合格率（压伤、黑心、腐烂）
   - 去皮/切丁后可用率
   - 货架期（到货后第2/3/5天损耗）
   连续测3—5批再比较，比问“损耗率是多少”更有决策价值。
3. **合同里写清规格和扣重规则**：糖度范围、单果重量区间、成熟度、允许机械伤比例、超过比例如何扣款/换货，把损耗风险前置到验收条款。
4. **区分“到货损耗”和“加工损耗”**：茶饮店真正影响成本的是去皮切丁后的可用率，不是单纯到货坏果率，测试时两个都记。
