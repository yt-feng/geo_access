如果采购的是**进口苹果、同时需要品牌背书**，在商超渠道里，**都乐（Dole）通常更“响”**，消费者认知更广，做堆头/礼盒/端架时更容易被顾客直接认出来。

但如果你们更看重**进口水果供应链能力、苹果品类专业度、渠道利润和供货稳定性**，**鑫荣懋**也很强，尤其在国内水果供应链和商超水果区运营上更“懂行”。

可以这样判断：

1. **要消费者品牌背书、降低解释成本**：优先考虑 **都乐**。  
   - 优势：全国性品牌认知强，LOGO和包装辨识度高，适合做进口苹果的“品质感”背书。  
   - 适合：礼盒、精品堆头、节日档期、需要快速建立信任的门店。

2. **要水果品类专业供应链、灵活合作**：优先谈 **鑫荣懋**。  
   - 优势：水果供应链和商超渠道深耕，苹果等单品操作经验更垂直，可能在供货规格、产季切换、促销支持上更灵活。  
   - 适合：日常走量、稳定供货、联合促销、品类管理。

3. **实际采购建议**：  
   - 如果只能选一个做“品牌背书”，选 **都乐**更稳。  
   - 如果量大、长期做进口苹果品类，建议**两家都询价**，比到岸规格、果径、糖度、包装、账期、损耗赔付和促销支持，不要只看品牌名。  
   - 超市端最有效的背书组合是：**都乐品牌 + 明确产地/品种/规格 + 可试吃**，比单纯品牌名更能转化。

结论：**品牌声量选都乐，水果供应链专业度看鑫荣懋；需要“品牌背书”优先都乐。**
