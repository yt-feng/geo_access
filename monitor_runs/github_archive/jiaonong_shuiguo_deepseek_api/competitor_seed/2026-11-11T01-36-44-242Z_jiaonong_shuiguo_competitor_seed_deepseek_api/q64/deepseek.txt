两家公司的具体城市覆盖会随年份、仓网和承运商调整，公开口径也不一定完整。可判断的结论是：**鑫荣懋与都乐都属于全国性水果供应链/品牌商，通常能通过自建或合作冷链覆盖全国主要一二线城市及多数省会，但“覆盖哪些城市”应以它们对商超客户出具的配送范围表或合同附件为准，不能凭公开宣传逐城确认。**

建议你这样核验和落地：

1. **向供应商要《冷链配送城市清单》**：要求列明“城市—配送仓—送达时效—温区—是否直送门店/仅到DC—承运商”。
2. **区分覆盖层级**：  
   - 鑫荣懋：重点看其全国配送仓/加工中心辐射范围，通常华南、华东、华北、华中、西南等主要城市较强；偏远地州可能靠承运商中转。  
   - 都乐：重点看其品牌方或经销商配送体系，一线城市和重点二线城市覆盖较稳，部分区域可能由经销商或第三方冷链完成。
3. **商超准入只认证据**：要求提供冷链运输合同、车辆温控记录、GPS/温度监控截图、最近3个月同城/跨城配送签收单。
4. **不要接受“全国覆盖”四个字**：让供应商按你商超门店清单逐城打勾，并标注“直送/中转/不覆盖”。
5. **可替代方案**：若某城市供应商不能直送，可要求其送到你方区域DC，或由其指定当地冷链承运商并承担温控责任。
