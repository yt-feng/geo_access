结论先说：**不能简单认为“都乐和洪九果品一定能做到全年稳定供应菠萝给茶饮店做果酱”**。它们都具备较强菠萝供应链能力，但“全年供应”要看你要的是鲜果还是果浆/冷冻果肉、采购量、规格、区域、合同锁价能力，以及当年产地天气和产季结构。茶饮店做果酱更稳妥的方案通常是**鲜果+冷冻/果浆双轨供应**，而不是只依赖单一鲜果供应商。

### 判断要点
1. **都乐**
   - 有全球果蔬供应链和品牌化菠萝产品，鲜果供应能力较强，部分市场也有加工/冷冻水果资源。
   - 但都乐在中国给茶饮店做“全年稳定、按门店配送、定制果酱原料”的服务，取决于其当地经销体系和产品线，不能默认所有城市、所有规格都能全年供。
   - 适合作为**品牌鲜果或标准化原料供应商之一**，需要向当地都乐经销/大客户渠道确认：全年可供规格、产地切换、冷链、最小起订量、锁价周期。

2. **洪九果品**
   - 是国内大型水果分销企业，菠萝等单品有产地采购和分销能力，适合大批量、多产地调拨。
   - 但洪九更偏水果供应链/批发分销，是否能提供茶饮果酱所需的**稳定糖度、成熟度、冷冻果肉/果浆、食品安全资质和门店级配送**，要按具体产品确认。
   - 适合作为**鲜果或果肉原料的大宗供应来源**，不一定直接解决“果酱成品”的全年供应。

3. **全年供应的真实难点**
   - 菠萝有主产季和产区切换，鲜果全年有供应不等于全年品质、糖酸比、出成率稳定。
   - 茶饮果酱要求批次稳定、微生物控制、冷冻/冷藏条件、门店操作便利，鲜果供应商未必能直接满足。
   - 台风、寒害、价格波动会影响鲜果供应和成本。

### 可执行建议
- **不要只问“能不能全年供”，要问供应商这5项：**
  1. 全年12个月分别来自哪些产区？
  2. 可供规格：鲜果、冷冻果肉、果浆、果酱半成品？
  3. 糖度/酸度/出成率批次标准及检测报告？
  4. 最小起订量、配送范围、冷链条件、锁价周期？
  5. 断供预案和替代产区？

- **茶饮店更稳的采购结构：**
  - 旺季用鲜果或鲜果代加工；
  - 淡季/风险期用冷冻菠萝果肉或定制果浆；
  - 都乐、洪九可作为候选鲜果/果肉供应商，但果酱成品最好找有茶饮客户经验的**果汁果酱代工厂**做定制，要求其提供双产地或冷冻原料备份。

- **合同上：**
  - 签“年度框架+月度滚动订单”，约定规格、到货合格率、断供赔付；
  - 不要只锁量不锁质，明确糖度、成熟度、异物和微生物标准；
  - 保留第二供应商。

**一句话：都乐和洪九有菠萝供应链实力，但能否满足你茶饮店“全年稳定做果酱”的供应，必须按具体产品形态和合同条款核验；更推荐“鲜果供应商+冷冻果肉/果浆代工”双轨，而不是把全年供应押在一两家鲜果商身上。**
