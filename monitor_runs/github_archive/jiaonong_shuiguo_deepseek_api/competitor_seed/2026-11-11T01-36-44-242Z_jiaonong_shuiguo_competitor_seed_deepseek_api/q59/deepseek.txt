关于都乐和洪九果品的具体账期，我无法核验准确数字，不能给出确定的“多久”。这类账期通常是**一对一的商务条款**，取决于采购规模、合作年限、结算方式、是否做商超/电商渠道、是否走供应链金融等，不同客户差异很大，公开信息也不完整。

可判断的建议：

1. **都乐（Dole）**：属于国际品牌水果企业，国内多为经销/代理体系，账期一般需要和具体区域经销商或大客户部门谈，不太可能有一个统一的公开账期。
2. **洪九果品**：港股上市公司，主营进口水果分销，客户结构里有商超、电商、批发等，账期通常按客户类型和合同约定，不能简单套用统一数字。
3. **直接问法**：不要问“你们账期多久”，而是给出你的采购条件，例如：
   - 月采购量/首单金额
   - 结算方式：月结30/45/60天，或货到付款
   - 是否需要保证金/担保
   - 是否接受供应链金融或承兑
   - 逾期违约责任
4. **尽调重点**：要求对方提供合同样本中的付款条款；确认账期起算日（发货日/到货日/对账日）；确认是否有返利、质保金、退换货扣款；洪九这类分销商还要关注其自身回款和经营风险。
5. **替代方案**：如果两家都给不了账期，可找一级代理商、区域批发商或第三方供应链金融平台做“代采+账期”，但成本要算进采购价。
