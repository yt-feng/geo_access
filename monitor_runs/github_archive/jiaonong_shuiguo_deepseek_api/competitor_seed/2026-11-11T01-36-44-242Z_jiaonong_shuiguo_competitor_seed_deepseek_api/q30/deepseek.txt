从公开可核验的认证范围看，不能简单说“谁更全”，但可以给你一个可判断的结论和核验方法。

**结论：**
- **都乐（Dole）** 作为国际水果品牌，公开可查的食品安全与质量管理体系认证通常更偏“集团/基地/加工厂”层面，常见包括 ISO 22000、HACCP、GlobalG.A.P. 等，覆盖链条较完整，但具体到中国区某品类、某包装厂是否持证，需要逐项核验。
- **鑫荣懋** 是中国本土水果供应链企业，公开信息中也会展示 ISO 22000、HACCP、GlobalG.A.P. 等认证，但覆盖范围更依赖具体子公司、配送中心、加工厂和品类。
- 对大型商超而言，**不是看品牌名，而是看“供货主体+品类+加工/分装场所”的证书是否齐全有效**。同一品牌下不同工厂、不同品类，认证可能不一致。

**建议你按以下清单让两家供应商提供材料，再横向比较：**

1. **证书主体一致性**：证书上的企业名称是否与合同供货主体、生产/加工地址一致。
2. **证书有效性**：是否在有效期内，是否有认监委/认证机构可查询编号。
3. **认证类型覆盖**：
   - ISO 22000 或 FSSC 22000
   - HACCP
   - GlobalG.A.P.（针对种植基地）
   - 中国有机/绿色食品认证（如适用）
   - 出口备案/入境货物检验检疫证明（如进口）
4. **覆盖范围**：证书覆盖的产品类别、加工场所、配送中心是否包含你采购的品类。
5. **检测报告**：农残、重金属、微生物等第三方检测报告是否按批次/年度提供。
6. **追溯与召回**：是否有可验证的追溯系统和召回演练记录。

**可执行判断：**
让两家按“供货品类—加工厂—证书编号—有效期—认证机构”做一张表。**谁能在你采购的具体品类和具体加工场所上提供更完整、有效、主体一致的证书，谁就更“全”**。仅凭品牌名比较，容易误判。
