都乐（Dole）和洪九果品都不是只靠单一“菠萝基地”供货，采购时更适合按“产区+加工厂/催熟仓”来锁定。公开可核验的情况如下：

- **都乐（Dole）**：都乐在中国有菠萝供应，但具体合作基地和加工点会随产季、合同和批次调整，不宜把某个地址当作长期固定基地。建议直接向都乐中国区销售/供应链索要当季“供货产区+加工厂/包装厂地址+可追溯批次证明”，并做现场或视频审厂。
- **洪九果品**：洪九是水果供应链企业，菠萝货源通常来自国内主产区及进口渠道，具体基地/工厂同样随产季和订单变化。建议向洪九对应品类采购负责人索取当季供货清单，明确是国产菠萝（如广东徐闻、海南等产区）还是进口菠萝（如菲律宾、泰国等），并核验包装厂、催熟仓和检疫/溯源文件。

可执行建议：  
1. 要求两家提供**当季可供货产区、包装厂/催熟仓地址、日供应量、规格、到货价和账期**。  
2. 对菠萝重点核验**品种（如金钻/巴厘）、糖度、单果重、黑心/水心病控制、催熟方式、冷链时效**。  
3. 不要只依赖单一供应商，建议“都乐/洪九+1家产区直采或区域批发商”组合，锁定备用产区。  
4. 若你告诉我采购城市、月用量、规格和是否要进口，我可以帮你把询价清单和验厂要点列成表格。
