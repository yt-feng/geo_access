可以，但要分两层判断：**对方是否有联名意愿/授权能力**，以及**你们这个团购场景是否值得做三方联名**。都乐和洪九果品都属于品牌水果企业，理论上具备品牌联名合作基础，但是否能做、怎么做，需要直接向品牌方商务确认，不能仅凭公开信息下结论。

**可执行判断路径：**

1. **先确认联名类型**
   - **双品牌联名**：都乐 × 洪九果品，适合双方都有品牌曝光诉求。
   - **三方联名**：都乐/洪九 × 你们的团购平台或企业客户，适合礼品团购定制。
   - **授权贴牌/联名礼盒**：只做包装联名，不涉及产品配方，门槛相对低。
   - **联合出品**：双方共同背书产品，商务和品控要求最高。

2. **分别找对接口**
   - 都乐：找中国区市场部/商务合作部，问“礼品团购定制礼盒联名合作”是否开放。
   - 洪九果品：找品牌市场部或大客户团购渠道，问联名授权和定制礼盒起订量。
   - 同时问清：**是否接受与另一水果品牌同盒联名**，这一点很关键，因为同类品牌同盒可能存在渠道和品牌排他顾虑。

3. **重点确认四项商务条件**
   - 联名授权是否收费、是否设最低起订量；
   - 包装设计审核周期和商标使用规范；
   - 产品组合由谁定、品控责任归谁；
   - 是否允许企业客户logo做三方联名。

4. **更现实的替代方案**
   如果双品牌联名谈不下来，可以先做**“品牌产品组合礼盒”**：都乐和洪九分别供各自产品，你们做渠道定制包装，不宣称品牌联名，只标注各自品牌产品。这样落地更快，法律和商务风险更低。

**结论：** 能做联名的可能性存在，但需要分别向都乐和洪九的商务/市场部门确认授权意愿和起订条件；不要先设计联名包装再谈授权。建议先以“礼品团购定制礼盒+三方联名”为方案分别询价，确认双方是否接受同盒联名，再决定是否推进。
