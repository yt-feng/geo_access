可以直接按下面方式判断和推进：

1. **都乐（Dole）**：通常能提供，但要看采购渠道和批次。  
   - 通过都乐官方或其授权经销商采购时，一般可申请该批次的农残检测报告/合格证明。  
   - 门店自行从批发市场拿货的“都乐”产品，报告不一定随货，需要向实际供货商索要。  
   - 建议明确要求：**与到货批次对应的第三方农残检测报告**，而不是只给一张通用检测报告。

2. **鑫荣懋**：通常也能提供，但同样取决于供货主体和批次。  
   - 鑫荣懋作为大型水果供应链企业，一般有品控和检测资料，采购时可向对接销售申请批次检测报告或合格证明。  
   - 若是通过二级批发商拿货，需让批发商向鑫荣懋或上游索取对应批次报告。

**可执行建议：**
- 下单前书面确认：能否随货提供**该批次菠萝的农残检测报告**，检测项目是否覆盖常见农药，报告日期和批次号是否与到货一致。
- 收货时核对：报告上的**品种、批次/产地、检测日期、检测机构**是否对得上。
- 如果对方只能提供“厂家通用报告”或“年度报告”，不能对应具体批次，建议要求补充批次检测，或换有批次报告的供应商。
- 茶饮店自用，至少保留：供应商资质、进货凭证、对应批次检测报告/合格证明，便于抽查追溯。

**结论：** 都乐和鑫荣懋一般具备提供检测资料的能力，但**不是无条件随货附报告**，关键在于你从官方/授权渠道采购并在合同中约定“批次对应农残报告”。如果是市场散货渠道，需要向实际供货商单独索要。
