结论先说：**在“稳定规格”这个硬指标上，都乐通常更稳妥；洪九果品更适合作为补充或压价渠道，不建议单押长期主供。**但这里有个前提：都乐的强项在鲜果标准化和品牌品控，具体到茶饮用的菠萝原料（鲜果还是冷冻果块/果泥/糖渍）差异很大，先按你的形态分开判断。

## 分场景建议

**1. 用鲜菠萝现切**
- **都乐更适配长期合作**：优势是规格分级清楚、成熟度批次一致性相对好、有品牌追溯，适合连锁茶饮做SOP。
- **洪九果品**：国内水果分销规模大、产地资源广、价格谈判空间通常更好，但茶饮端要重点核验：单果克重区间、糖度下限、成熟度、黑心病/水心病比例、到货温差和损耗赔付。适合作为第二供应商或旺季补量。

**2. 用冷冻菠萝块/果泥/糖渍菠萝**
- 这两家的优势都不是“茶饮定制规格”，要看具体代工厂和产线。
- 都乐若有对应冷冻/加工SKU，品控体系通常更规范；洪九更多是鲜果流通强，加工品要确认是自产还是贴牌。
- 这类原料更应看：固形物含量、糖度/酸度区间、解冻失水率、果块尺寸公差、微生物和农残报告。

## 长期合作决策表

| 维度 | 都乐 | 洪九果品 |
|---|---|---|
| 规格稳定性 | 较强 | 中等，依赖批次和产地 |
| 价格 | 偏高 | 更有弹性 |
| 供应规模 | 稳定但需锁量 | 规模大，旺季调配能力强 |
| 茶饮定制能力 | 看具体SKU | 看具体加工渠道 |
| 适合角色 | 主供/标杆供应商 | 第二供应商/比价渠道 |

## 可执行做法
1. **先定原料形态和规格书**：单果克重、糖度Brix、酸度、成熟度、果眼深度、黑心率上限、到货温度、破损率赔付。
2. **两家同时送样，做3批次盲测**：每批测规格公差、糖酸比、出成率（去皮去眼后净肉率）、48小时冷藏后的风味变化。
3. **小批量并行供货1—2个月**：按同一SOP出杯，记录每批出成率波动和客诉。
4. **合同锁定**：主供70%—80%给稳定性更好的那家，第二供应商20%—30%用于比价和断供保险；写明规格偏差扣款和换货条款。

**一句话：都乐做长期主供更稳，洪九做备份和议价更合适；最终用3批次实测的出成率波动来定比例，而不是只看品牌。**
