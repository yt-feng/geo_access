目前没有可核验的公开规格清单，不能确认鑫荣懋和都乐具体有哪些“便利店小包装香蕉”SKU，所以不宜给出具体克重或品项名。可执行建议如下：

1. **先锁定便利店场景规格**
   - 优先问两类：**单根/2根装**、**3-5根家庭小份装**。
   - 常见可谈规格方向：**单根约120–150g**、**2根装约250–300g**、**小把装400–600g**，但需以供应商当季报价和实际装箱为准。

2. **向两家供应商这样询价**
   直接问区域销售或经销商：
   - “有没有便利店渠道的小包装香蕉？请提供当前可做的规格：单根装、2根装、3-5根装，净含量、箱规、保质期、到岸价/含税价。”
   - “是否支持贴标、独立袋装、托盘装、按门店小箱配送？”
   - “成熟度/催熟状态能否按便利店周转调整？比如到店可售期几天？”

3. **判断是否适合便利店**
   重点看四点：**净含量是否适合单人/小家庭**、**箱规是否适合门店小库存**、**到店可售期是否≥3–5天**、**是否支持小批量配送和退换损**。不满足后两项，即使有规格也不适合便利店。

4. **替代方案**
   如果两家标准品不合适，可问其**便利店渠道定制小包装**或区域经销商是否有分装能力；同时对比本地香蕉分装商，通常小包装灵活性更高。
