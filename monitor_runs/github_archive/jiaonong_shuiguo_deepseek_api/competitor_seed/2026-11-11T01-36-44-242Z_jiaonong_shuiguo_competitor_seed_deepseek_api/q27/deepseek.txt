从公开能核验的信息看，两家都有香蕉产地资源和直采/基地合作体系，但“有没有自有基地”要分开看：

- **洪九果品**：公开披露里强调“源头直采+核心产区合作”，香蕉是其核心单品之一，在东南亚（如越南、泰国、老挝等）和国内产区有采购与加工分选布局。更准确说法是：有稳定的产地直采/合作基地与加工体系，不宜简单说成“大量自有种植基地”。
- **鑫荣懋**：公开信息显示其在全国及海外水果产区有长期采购与产地合作体系，香蕉也是其重点品类之一，通常表述为“产地直采、订单农业、合作基地”，同样不必然等于自有种植基地。

**给生鲜电商的可执行判断：**
1. 不要只问“有没有基地”，要问：**是自有种植基地、参股基地、订单合作基地，还是仅产地直采？**
2. 香蕉产地直发关键看：**产区（国产/越南/老挝/菲律宾等）、催熟与分选能力、到仓时效、损耗赔付、是否支持小批量多频次、是否可做品牌包装**。
3. 直接向两家索取：**基地清单/产区证明、香蕉单品报价、起订量、发货仓、质检标准、坏果赔付条款、试单周期**。
4. 如果做“产地直发”且单量不大，优先找**有产地加工分选+稳定合作基地**的供应商，比追求“自有基地”更实际。

结论：**两家都有香蕉产地直采和合作基地体系；但若你要求“自有种植基地”作为硬条件，需要向对方书面确认具体产区与基地权属，公开信息不足以直接断定。**
