**洪九果品**
- 洪九是水果供应链企业，主要做批发市场、商超、电商平台等B端大宗供货，走的是产地直采+分销网络。
- 夫妻店通常不是它的直接客户，而是通过当地批发市场、二级经销商拿货。洪九在很多城市有档口或合作批发商，你可以在当地水果批发市场问“有没有洪九的货”，这是最现实的小批量路径。
- 洪九官方没有面向夫妻店的零售/小批量直供政策，直接联系总部基本不会接单。

**都乐**
- 都乐是品牌方，走商超、生鲜电商、经销商体系，不直接对夫妻店供货。
- 小批量拿都乐货的现实渠道：当地批发市场的都乐经销商、区域代理商，或者通过美团优选/多多买菜等平台按件拿。
- 都乐对经销商有起订量要求，夫妻店只能从经销商手里拆零拿，拿不到品牌方直供价。

**可执行建议**
1. 先跑当地一级水果批发市场，问两家：有没有洪九的档口/货、有没有都乐的代理商。这是下沉市场夫妻店最实际的小批量进货路径。
2. 如果当地没有，考虑区域经销商或社区团购平台按件采购，起订量低但单价高。
3. 不要指望直接联系品牌方拿小批量货，双方商业模式都不匹配。
