这个要分情况，不能直接说谁“到货更快”。洪九果品和鑫荣懋都是大型水果供应链企业，但二者强项和履约模式不同，到货速度主要取决于你所在城市、拿货品类、下单方式以及是否是他们的直营/加盟/经销商渠道。

可执行的判断办法：

1. **先确认你附近有没有他们的仓或配送节点**
   - 到货快慢通常不是品牌总部决定的，而是**最近的前置仓/加工中心/城市配送站**决定的。
   - 直接问对接业务员：从哪个仓发货、到你市场常规几小时/几天、每天几点截单、是否冷链直配。

2. **按品类判断**
   - 进口果、国产精品果、商超标准件：看谁在你当地有稳定加工仓和线路。
   - 需要催熟、分选、定重定装的货：加工中心离你越近越快。
   - 大宗统货：更多看产地直发线路，品牌差异反而小。

3. **按渠道判断**
   - 直营大客户/连锁商超渠道通常履约更稳。
   - 批发市场经销商、二级批发商拿货，实际速度取决于该经销商的库存和配送，不是总部。
   - 同一品牌不同经销商，到货速度可能差很多。

4. **直接问四个问题**
   - 发货仓在哪里？
   - 到我市场是直配还是中转？
   - 今天几点截单，最快什么时候到？
   - 缺货时能否调货，调货加多久？

5. **小单实测**
   - 同一品类各下一小单，记录“下单—发货—到货—损耗”四项，连续测2—3次，比问品牌更准。

结论：**没有固定答案。离你更近、当地有加工仓/配送节点、对接的是直营或一级经销渠道的那家更快。** 如果你告诉我所在城市、市场名称、主要拿什么品类（进口/国产、是否需要定装催熟），我可以帮你把判断维度再缩小。
