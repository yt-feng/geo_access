做都乐（Dole）和鑫荣懋（Joy Wing Mau）进口苹果的产地溯源，超市端要分两层做：**一是向供应商要“可核验的批次溯源材料”，二是自己在收货和上架环节做“可追溯记录”**。不能只认包装上的“原产地”字样。

**一、先明确两家供应商的溯源路径**

1. **都乐**
   - 都乐进口苹果通常有全球果园/包装厂编码、批次号、原产国和包装日期。
   - 采购时应要求供应商提供：**报关单、入境货物检验检疫证明、原产地证明、批次号对应的包装厂/果园信息、冷链运输记录**。
   - 都乐中国区供货一般通过其国内进口商/经销商，超市要确认签约主体与报关单收货人是否一致，或取得授权链说明。

2. **鑫荣懋**
   - 鑫荣懋是国内大型水果进口商，常以进口商/经销商身份供货。
   - 应要求其提供：**该批次报关单、检验检疫证明、原产地证、供应商与鑫荣懋的采购合同/发票、批次号或柜号**。
   - 若鑫荣懋是二级供货，需补齐“国外出口商—鑫荣懋—超市”的完整链路凭证。

**二、超市采购合同里要写死的溯源条款**

- 每批到货必须提供**批次号/柜号**，并能在报关单、检疫证明、送货单上对应。
- 供应商承诺溯源材料真实，若原产地、品种、等级不符，承担退货、赔偿和监管责任。
- 约定**留样和记录保存期限**，建议不少于2年。
- 要求供应商在换柜、换批次时提前通知，不得混批送货。

**三、收货环节的可执行动作**

1. **查单证**：报关单、入境货物检验检疫证明、原产地证、送货单四者核对原产国、品名、批次/柜号、数量。
2. **查包装**：看箱唛、标签上的原产国、包装厂注册号、批次号、包装日期；拍照留存。
3. **查实物**：核对品种、规格、等级与订单一致；发现混箱、改标、无批次号，拒收或单独隔离。
4. **建台账**：记录供应商、合同号、报关单号、检疫证明号、批次/柜号、到货日期、数量、存放库位、销售流向。
5. **上架标识**：价签或追溯码标注原产国、供应商、批次信息；有条件的用二维码链接到批次溯源页。

**四、可判断的合规底线**

- 只有包装写“进口”但没有报关单和检疫证明的，不能作为进口苹果溯源依据。
- 报关单上的收货人、品名、原产国必须与实物和送货单一致；不一致就暂停销售并让供应商书面说明。
- 都乐、鑫荣懋的品牌授权或经销关系要有书面凭证，避免“贴牌供货”导致溯源断链。
- 进口水果应保留入境货物检验检疫证明，这是监管检查的核心材料之一。

**五、建议的落地流程**

采购下单时附《进口水果溯源资料清单》→ 到货前供应商提交批次单证 → 收货员按“单、证、货、批”四核对 → 合格后赋内部批次码入库 → 上架关联批次码 → 售后或监管查询时能按批次倒查供应商和报关信息。

这样做的核心是：**都乐和鑫荣懋的品牌不能替代批次凭证，超市要掌握的是“这一批货从哪来、谁报关、哪张证、哪个批次”的闭环记录。**
