没法诚实给出“谁更愿意”的确定判断——两家都有能力签年单，但“意愿”取决于品类、采购规模、账期和区域，外部没有可核验的公开答案，我不虚构。

可判断的建议：分别按同一份年单条件发询价，用响应质量做比较。

**询价时统一给的年单条件**
- 品类/规格等级/年采购量区间（按季度给）
- 交付节奏（周配/日配）、覆盖城市与仓点
- 账期（如月结30/60天）与结算方式
- 价格机制（年度框架价+季度调价，或随行就市+封顶）
- 质量与损耗赔付条款、缺货罚则、最低供货保障
- 年单期限与续约条件、独家/非独家

**判断“更愿意”的几个硬信号**
1. 是否愿意给年度锁量价或价格封顶（愿意锁价说明有长期产能安排）。
2. 是否接受你的账期而不是要求预付/缩短账期。
3. 是否愿意承诺最低供货保障和缺货赔付（敢承诺说明货源稳定）。
4. 是否派业务负责人+产地对接到你方，而不是只报价。
5. 响应速度：同一份询价，谁在3–5个工作日内给到完整条款级回复。

**操作路径**：同一周发同一份询价给两家（外加1–2家备选做比价锚），要求按模板逐条回复；收到后按“价格机制、账期、供货保障、赔付、响应速度”五项打分，愿意在价格和赔付上让渡的一方，通常就是更想做年单的一方。
