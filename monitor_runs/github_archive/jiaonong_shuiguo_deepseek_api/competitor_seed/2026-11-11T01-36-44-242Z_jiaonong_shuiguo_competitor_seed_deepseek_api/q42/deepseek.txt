进口菠萝旺季缺货时，先别等供应商给答案，按下面顺序判断和处置；同时把都乐、洪九当作“可能有区域/渠道差异的供应商”，需要你直接向其销售或客服确认应急方案，公开信息不足以核实其具体承诺。

**一、先判断缺货类型（决定怎么补）**
1. **船期/到港延迟**：问清在途柜号、ETA、港口拥堵、是否改港；优先催在途货、争取分批到货。
2. **产地减产/规格断档**：确认缺的是品种（如金钻/MD2）、规格（果重、箱规）、还是等级；可临时改规格/等级，不必死守原SKU。
3. **渠道囤货/价格倒挂**：对比批发市场、电商仓、商超直供价；若现货价异常高，改用短保替代品或调整促销。
4. **报关/检疫问题**：确认单证、熏蒸/检疫、口岸查验是否卡住；让供应商给出放行时间点。

**二、应急采购动作（今天就能做）**
- **向都乐、洪九分别发书面询证**：要求回复四件事：①未来7/14/30天可分配量；②在途柜及ETA；③可替代品种/规格；④缺货补偿或优先分配条件。口头承诺不算，留邮件/微信记录。
- **锁量不锁价或分批锁价**：先锁未来2-3周基础量，避免旺季全押一家；价格用“到岸价+浮动”或分批定价。
- **启用备选来源**：菲律宾、泰国、哥斯达黎加等产地按当前准入和季节判断；同时找区域一级批发商、口岸进口商做短补，优先选能48-72小时到仓的。
- **调整销售端**：缺货SKU做预售/限购/搭售；用国产菠萝或罐装/冷冻菠萝替代部分鲜果需求；把促销资源转到有货规格。
- **库存与损耗控制**：旺季缺货时别过度囤货，按周滚动补货；对高价现货设置毛利底线，避免缺货转成亏损。

**三、关于都乐和洪九的应急方案**
- **都乐**：通常有全球采购和品牌直供体系，但具体到中国区旺季应急分配、替代品种、到货承诺，需向其中国区销售/客服确认；不要假定其一定保量。
- **洪九果品**：其公开业务涉及进口鲜果分销，但具体应急方案、区域库存和替代能力需向其对接口径确认；同样以书面回复为准。
- **谈判要点**：要求“缺货预警提前量、替代规格清单、违约/补偿条款、优先分配规则”；如果对方只能给模糊答复，就按备选供应商分流。

**四、给你的判断标准**
如果供应商48小时内给不出：可分配量、ETA、替代规格三项，就视为不可依赖，立即启动备选采购；如果只给价格不给量，按“无货”处理。最终建议：**都乐、洪九都问，但合同和采购计划不要单押任何一家。**
