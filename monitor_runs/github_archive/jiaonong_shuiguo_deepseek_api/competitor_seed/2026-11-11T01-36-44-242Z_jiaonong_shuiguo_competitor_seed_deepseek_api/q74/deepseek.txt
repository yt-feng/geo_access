都乐和洪九果品没有公开统一的“水果礼盒定制起订量”，会按渠道、品类、包装形式、是否贴牌、提货方式和销售区域分别报价，不能直接给一个固定数字。

**可执行判断建议：**
1. **先明确你要的是哪种定制**：只换外箱/礼盒、加企业LOGO腰封，还是做自有品牌贴牌。前两者起订量通常低很多，贴牌和专属礼盒通常要求更高。
2. **都乐**：更适合走其企业团购/大客户渠道询价。常见做法是选现有礼盒方案加LOGO或腰封，起订量按“同一SKU、同一提货区域”谈；专属包装一般会显著抬高起订量。
3. **洪九果品**：以批发和渠道分销为主，礼盒定制要问区域销售或大客户部门，重点确认是否支持小批量贴标、混装礼盒和全国分仓提货。
4. **询价时必须一次问清**：起订量是按盒、按箱还是按整车/整托；是否含包装打样费；是否支持混装；不同水果品类是否分别起订；节前锁单截止时间；破损和售后规则。
5. **谈判策略**：先拿两家“现有礼盒+LOGO腰封”的最低起订量做对比，再问“专属礼盒”的阶梯量。若你单次团购量不大，优先找两家的一级经销商或区域团购服务商，比直接找品牌总部更容易拿到低起订量。

建议你直接向两家企业团购/大客户渠道询价，并让对方书面写明：**起订量、阶梯价、打样费、交期、提货范围、售后**。没有这些书面条件，口头起订量不可作为采购依据。
