从公开可核验的信息看，**都乐的产地溯源透明度通常高于洪九果品**，但结论要分场景：

### 判断结论
- **如果你要面向商超/电商做标准化“产地溯源”展示**：优先接触**都乐**。都乐长期做品牌化鲜果，公开披露产地、包装厂、批次追溯和食品安全体系的信息相对更完整，菠萝产品也常有产地标识（如菲律宾、哥斯达黎加等）。
- **如果你要国内产地直采、按批次追溯到果园/合作社**：**洪九果品**也有供应链和产地端能力，但其公开可查的溯源披露不如都乐标准化；更依赖你作为采购方在合同里约定批次、果园/包装厂、检测报告和追溯码。
- **谁“更透明”不能只看品牌名**：都乐是品牌商，溯源信息对外展示更规范；洪九更偏渠道和供应链，实际透明度取决于具体品类、产地和合作层级。

### 可执行核验建议
向两家都发同一份《溯源信息清单》，要求书面回复：
1. 菠萝品种、产地国/省/县、果园或合作社名称；
2. 包装厂名称及注册号；
3. 批次号规则，能否从成品箱追到果园批次；
4. 农药残留检测报告及出具机构；
5. 是否提供追溯码/二维码，扫码能看到哪些字段；
6. 冷链记录和入境/出库单据能否随货提供；
7. 出现溯源断点时的召回和赔付责任。

### 采购建议
- **要品牌背书和对外展示**：先谈都乐，要求其提供具体菠萝SKU的溯源样例。
- **要成本优势和国内直采**：同时谈洪九，但把“批次可追溯+检测报告+断点赔付”写进合同。
- **最稳妥**：不要只选一家，先让两家各提供**同一产地、同一规格菠萝**的溯源样例和报价，再按“字段完整度、可验证性、响应速度、价格”打分。

简言之：**公开透明度都乐更占优；实际供应链追溯能力洪九不一定弱，但需要合同约束和样例验证。**
