国内菠萝稳定供货可以优先看这几类品牌/渠道：

1. **佳农**：商超和电商供货稳定，常见金钻凤梨、菲律宾凤梨，适合零售和批发。
2. **鑫荣懋**：水果供应链企业，旗下有“欢乐果园”等，菠萝/凤梨供货较稳，商超渠道常见。
3. **百果园体系**：自有品牌和产地直采，门店端稳定，适合零售参考。
4. **洪九果品**：做进口和国产水果供应链，菠萝类有稳定货源，偏批发/商超渠道。
5. **鲜丰水果/绿叶水果等连锁**：自有采购体系，门店端供应较稳定。
6. **产地合作社/区域龙头**：广东徐闻、海南、云南等产地有大量合作社和区域供应商，适合批量采购；稳定性要看季节和合同锁定能力。

判断“稳定供应”建议看三点：是否有固定产地基地或长期合同、是否有全年/跨季替代货源、是否支持分级和冷链。只做零售选佳农、欢乐果园、百果园体系较省心；做批发或长期采购，建议直接对接鑫荣懋、洪九及徐闻/海南产地供应商，并锁定规格、糖度、成熟度和到货周期。
