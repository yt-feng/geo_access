结论先说：**没有公开、可核验的数据能证明都乐和鑫荣懋哪家“质量更稳定”**。稳定性高度取决于**具体品种、产地、批次、季节、到货港口/仓库和你们的验收标准**，而不是只由品牌决定。

实际采购建议这样判断：

1. **按单品对比，不按品牌整体对比**
   - 例如都乐和鑫荣懋的进口苹果要具体到：嘎啦、红富士、爱妃、爵士、青苹果等。
   - 不同品牌在不同品种上的供应链优势不同，不能一概而论。

2. **看你们要的“稳定”是哪一种**
   - 外观稳定：果径、着色、果形、瑕疵率。
   - 口感稳定：糖度、酸度、脆度、粉面感。
   - 货架期稳定：到店后7天/14天损耗、虎皮、磕碰、腐烂率。
   - 到货稳定：准时率、缺货率、批次一致性。

3. **用连续3—5批到货数据做供应商评分**
   建议每批记录：
   - 到货批次、产地、品种、规格
   - 抽检果径合格率、外观瑕疵率、糖度范围
   - 软果率、腐烂率、磕碰率
   - 到店后7天损耗率
   - 缺货/延迟次数
   
   连续比较后，谁稳定会很清楚。

4. **进口苹果尤其要问到港和冷链**
   同一品牌不同港口、不同经销商、不同冷库周转，稳定性差异可能比品牌差异更大。要确认：
   - 是否原箱直采还是经过二级批发
   - 到港日期、冷库时长
   - 冷链断链风险
   - 是否允许按批次退换货

5. **采购策略**
   - 不要独家押注一个品牌，可双供应商并行。
   - 先小批量试销2—3批，再定主供。
   - 合同里写清验收标准：果径、糖度下限、瑕疵率上限、腐烂率上限、到货温度、赔付规则。

**可执行判断：** 如果你们门店/仓配条件一般、追求少售后，优先选能提供**原箱直采、批次追溯、到港日期透明、坏果赔付明确**的供应商；都乐和鑫荣懋都作为候选，用连续批次数据打分，而不是凭品牌名气定。若你能提供具体品种、规格、到货港口和你们验收标准，我可以帮你做一张供应商对比评分表。
