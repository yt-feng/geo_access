洪九果品和都乐香蕉的**具体到货损耗率数据，两家都不会公开披露分品类的精确数字**，批发市场里的实际损耗也高度依赖批次、季节、产地、运输距离和你的接货方式。所以任何给出"洪九是X%、都乐是Y%"的确定数字，基本都不可信。

能给的是行业里可参考的判断框架，以及你在批发市场可以实际验证的方法：

**损耗的主要来源（两家都逃不掉）**
- 运输环节：冷链断链、装卸碰撞、堆压
- 成熟度：到货时已过熟或催熟不均
- 批次差异：同一品牌不同产地/船期差异很大
- 你的接货和仓储：是否及时入冷库、翻箱、分级

**品牌层面的粗略差异（非精确数据）**
- **都乐**：标准化程度高，品控和冷链相对稳定，损耗波动较小，但价格高，且到货多为可即售状态，留给你的货架期短，卖慢了照样烂。
- **洪九**：以国产和进口多品项批发为主，品类杂、批次波动大，同一箱里等级和成熟度不均的概率更高，损耗方差大——可能某批很好，某批很差。

**结论**：从"稳定性"看都乐通常更可控；从"单批损耗"看没有固定谁高谁低，取决于具体批次。不要按品牌下赌注，要按批次验货。

**你在批发市场能自己做的验证**
1. 连续拿同一品牌 5-10 批，每批记录到货重量、可售重量、烂果重量，算出你自己的实际损耗率。
2. 开箱抽检：看青果比例、压伤、水烂、黑斑。
3. 问档口：这批的产地、船期/采摘期、到货几天。
4. 谈损耗条款：大额拿货时争取"到货当日烂果可退换"或按比例折价，这比研究品牌损耗率更实在。
