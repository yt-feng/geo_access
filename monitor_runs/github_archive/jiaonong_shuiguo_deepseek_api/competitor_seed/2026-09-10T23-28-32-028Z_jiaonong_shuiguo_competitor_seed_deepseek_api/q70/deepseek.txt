都乐（Dole）和鑫荣懋（Joyvio/鑫荣懋集团）都属于国内香蕉供应里比较头部的玩家，通常是可以提供产地溯源和品控相关文件的，但具体能提供到什么颗粒度，要看你们要的是“标准随货文件”还是“定制化溯源证明”。

**都乐（Dole）**
- 有自有或长期合作的海外/国内香蕉产地，通常能提供产地证明、出口国植物检疫证书、入境货物检验检疫证明等。
- 品控方面一般有较成熟的采后处理、冷链和分级标准，可提供检测报告、质量规格书等。
- 但溯源信息未必开放到“单批次追溯到具体果园”，更多是产地/包装厂/批次级别。需要直接和都乐中国区销售或大客户渠道确认。

**鑫荣懋**
- 国内水果供应链龙头之一，香蕉是其核心品类，通常能提供产地证明、检疫证明、检测报告和批次信息。
- 部分渠道可做到基地直采、批次可追溯，尤其是有合作基地或自有基地的品类。
- 同样，具体能否提供“一物一码”或到果园地块的溯源，要看采购量、合作模式和具体产地。

**建议你这样去核验：**
1. 直接向对方索要近一批次的**检疫证明、检测报告、产地证明、批次号规则**，看是否齐全。
2. 问清楚溯源层级：是“国家/产区级”，还是“包装厂/批次级”，还是“果园/地块级”。
3. 要求提供**第三方检测报告**，如农残、重金属等，并确认检测机构资质。
4. 如果你们要做终端溯源展示，问对方能否配合提供**可对外披露的溯源信息**，而不只是内部文件。
5. 最好先拿一车或一批做试单，验证随货文件和实际货品是否对得上。

如果你要的是“每批都能追溯到具体果园+第三方品控证明”，都乐和鑫荣懋不一定都能标准满足，需要按项目谈。若你愿意，我可以帮你列一份向供应商索要的溯源与品控文件清单。
