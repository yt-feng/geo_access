账期属于各家供应商的商务政策，通常不公开披露，且会随客户资质、采购量、合作年限、品类（进口香蕉/国产香蕉）、结算方式（月结/货到付款/承兑）而浮动，所以没有一个固定的"都乐账期多久、洪九账期多久"的标准答案。以下是你需要知道的关键点和可执行建议：

**1. 不要依赖网传数字**
网上流传的"某家30天、某家60天"多是个案或二手信息，不同客户拿到的条件差异很大，直接采信容易在谈判中被动。

**2. 都乐（Dole）**
都乐在中国有鲜果业务（含香蕉），主要走大型商超、批发市场和餐饮渠道。作为外资品牌，其账期政策一般由区域销售/大客户团队按合同谈判，通常对新客户倾向现款或较短账期，对稳定大客户才给月结。具体天数需直接对接其中国区销售。

**3. 洪九果品**
洪九是港股上市的鲜果分销商（"水果第一股"），香蕉是其核心品类之一，主要面向批发商、商超、电商等B端客户做分销，本身就带一定的信用销售性质，所以是较可能提供账期的对象。但具体账期同样按客户和品类一单一议。

**4. 实操建议**
- **直接问**：联系都乐中国区销售、洪九果品区域销售，说明你的采购量、结算历史和回款能力，让对方报价并给出账期方案。
- **谈判筹码**：账期长短和采购量、预付比例、合作稳定性强相关。愿意给预付款或首单现结，后续更容易谈到月结。
- **风险控制**：如果以账期采购再转售，注意自己的现金流，避免上游账期短、下游回款慢的错配。
- **验证资质**：确认对方是厂家/一级经销还是二级分销，层级不同账期和价格都不同。
