目前无法核验鑫荣懋和都乐在香蕉规格分级上的官方标准，不能直接给出“谁更细”的确定结论，因为两家在不同渠道、不同客户、不同批次的分级口径可能不同。

但从行业常见情况看，可以按以下方法判断和选择：

1. **都乐**  
   - 品牌化程度高，零售端常见分级多按：
     - 单根重量/克重
     - 每把根数
     - 长度、粗度
     - 外观瑕疵、成熟度
   - 对商超配送通常有较稳定的商品规格，但公开可查的“细分级表”不一定完整。

2. **鑫荣懋**  
   - 是国内大型水果供应链企业，给商超、电商、批发渠道供货多。
   - 分级往往更偏“客户定制”：可按门店类型、包装方式、催熟要求、单根克重、把型、颜色、成熟度等细分。
   - 如果你们采购量大，通常可以要求其提供更细的定制分级。

3. **实际判断建议**
   - 不要只看品牌，直接向两家索要：
     - 香蕉验收标准表
     - 规格分级表
     - 单根克重区间
     - 每箱净重、根数、把数
     - 长度、粗度、颜色、成熟度、瑕疵允许比例
     - 催熟到货成熟度
   - 让两家按同一张表报价，才能比较“谁分级更细、谁更适合你们超市”。

4. **结论**
   - 若你要的是**全国零售端标准化包装**，都乐通常更容易拿到稳定规格。
   - 若你要的是**按超市渠道定制细分**，鑫荣懋往往更灵活，可能能做得更细。
   - 但具体哪家分级更细，必须以你们所在区域采购对接人提供的现行标准为准。
