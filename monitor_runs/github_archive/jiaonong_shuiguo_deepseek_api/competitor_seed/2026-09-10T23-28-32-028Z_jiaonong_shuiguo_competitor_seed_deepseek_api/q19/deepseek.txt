直接说结论：**“香蕉锁价”不是鑫荣懋或洪九果品对外公开的标准产品名，普通批发商很难直接买到两家现成的“锁价机制”。** 这类安排通常是**一对一大客户/长期协议里的商务条款**，不是官网可查的公开服务。

可以按下面判断：

1. **鑫荣懋**
   - 偏大型商超、渠道、产地供应链，香蕉是其优势品类之一。
   - 更可能对**长期、稳定、大批量采购客户**谈价格保护、阶段性定价、锁量锁价。
   - 但不会对普通批发商公开挂出“锁价机制”。

2. **洪九果品**
   - 香蕉也是核心品类，过去主打进口+国产水果供应链。
   - 也主要面向大型渠道、商超、电商等。
   - 是否给锁价，取决于你的采购量、账期、合作稳定性，通常要单独谈。

**你能不能拿到锁价，关键不是“谁提供”，而是：**
- 你月采购量有多大；
- 能不能接受锁量、预付、保证金或最低采购承诺；
- 锁价周期多长（1周、1个月、1季度差别很大）；
- 价格波动风险由谁承担，超出区间怎么调价。

**实操建议：**
- 直接找两家的**区域销售/大客户经理**，不要问“有没有锁价产品”，而是问：  
  “我们月采X车/柜，能否签季度框架，约定基价+浮动区间+锁量？”
- 同时找**一级批发商、产地代办、进口商**谈，很多时候比找鑫荣懋、洪九更灵活。
- 锁价合同必须写清：  
  基准价、调价触发条件、锁量、违约、质量等级、交货地、账期。

如果你要的是“公开可买、标准化锁价”，两家大概率都没有；如果你量大且能长期合作，两家都可以谈，但需要一对一商务确认。
