可以要，但不能只听口头承诺，必须拿到与**实际供货批次对应**的检测报告。就这两家来说：

**都乐**
- 作为品牌方/大型供应商，通常能提供农残检测报告。
- 但要注意：都乐很多是品牌授权、经销商或加工厂在供货，报告可能是品牌方、加工厂或第三方检测机构出的。你要确认报告上的**样品名称、批次号、生产/加工日期**和你收到的货一致。

**鑫荣懋**
- 也是大型水果供应链企业，一般具备提供农残检测报告的能力，尤其对商超、连锁客户。
- 同样要确认是**批次对应报告**，不是一张通用模板或过期报告。

**采购时要盯住这几点：**
1. **报告类型**：要农药残留检测报告，最好是第三方 CMA/CNAS 资质机构出具。
2. **批次对应**：报告必须对应你这一批货的批次号/采收或加工日期。
3. **检测项目**：看是否覆盖菠萝常见风险农药，如毒死蜱、氯氰菊酯、溴氰菊酯、多菌灵等；如果只测一两项，参考价值有限。
4. **报告时效**：生鲜类通常要求近批次或近期报告，过期报告不能代表当前货。
5. **主体一致**：报告送检单位、供货主体、发票主体最好能对得上，避免“借报告”。
6. **留样复检权**：合同里写明你有权抽检、留样，不合格可退换并追责。

**实操建议：**
- 直接向对接的业务员要：**“请提供本批次菠萝的农残检测报告，并加盖公章或检测机构章。”**
- 如果对方说“有，但暂时给不了”，可以要求先发扫描件，收货时随货附纸质或电子版。
- 如果只能提供“品类通用报告”而不是“批次报告”，建议你自行送第三方快检或全检，费用一般几百元，比食品安全风险划算。

结论：都乐和鑫荣懋**通常都能提供**，但关键不是“能不能”，而是**是否为本批次、项目是否齐全、报告是否有效**。采购合同里要把这一条写死。
