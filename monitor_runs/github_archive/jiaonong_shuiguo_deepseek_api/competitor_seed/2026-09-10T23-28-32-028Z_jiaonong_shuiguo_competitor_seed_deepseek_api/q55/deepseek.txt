可以按“是否有自有/直控基地 + 是否能做到批次级产地溯源”来筛选。就你提到的两家：

**都乐（Dole）**
- 有较成熟的全球和国内供应链体系，在中国市场也有合作种植基地/订单农业基地。
- 通常可提供产地信息、批次信息，部分商超/大客户渠道可做到追溯码或批次追溯。
- 但“基地直供”要看你采购的量级和渠道：走都乐中国正规经销/直供体系，才可能拿到基地或指定产区货源；零散采购一般只能到批发市场或经销商层级。

**洪九果品**
- 是国内头部水果供应链企业，主打基地直采、产地直发模式，菠萝/凤梨类有较明显的产地直采和分选加工能力。
- 对大型商超、电商、批发客户，通常能提供产地证明、批次信息，部分品类可做到基地到销地的链路追溯。
- 但“能不能溯源到具体基地/果园”取决于具体品类、季节、采购量和合同要求，不是所有批次都能追溯到单一果园。

**给你的判断建议：**
1. 先明确你要的溯源层级：  
   - 只到“产地市县” → 两家基本都能满足。  
   - 要到“具体基地/果园/批次” → 必须签采购合同前书面确认，并要求提供追溯码、基地证明、检测报告、批次单据。
2. 直接问供应商这4个问题：  
   - 这个菠萝批次能否追溯到具体基地/果园？  
   - 能否提供基地合作协议或直采证明？  
   - 是否有批次追溯码/二维码？  
   - 出现质量问题时能否定位到具体产地和批次？
3. 小批量试单时，要求随货提供：产地证明、检测报告、批次号、采摘/加工日期。拿不到就别当作“可溯源直供”。
4. 如果你们是做商超、电商、团购，建议优先谈洪九这类产地直采供应链；如果看重品牌背书和稳定标准，可谈都乐体系。最终都要落到合同条款里。

**结论：**
- 都乐：有基地/合作基地体系，但“基地直供”通常限大客户或指定渠道。
- 洪九果品：基地直采属性更强，菠萝类较可能做到产地直发和批次追溯。
- 两家都不是“默认每个客户都能拿到基地级溯源”，必须按采购量、渠道和合同逐单确认。
