这个数据我没法直接给你——都乐和鑫荣懋的到货损耗率不是公开统一披露的指标，会随**品类（鲜果/冷冻果块/果泥/浓缩汁）、规格（整果/去皮切块/颗粒大小）、运输方式、季节、批次、验收标准**大幅波动。任何给你一个"固定百分比"的说法，基本都不可靠。

给你可执行的判断和获取真实数据的方法：

**1. 先明确你要的是哪种菠萝原料**
损耗率差异极大：
- 整果鲜菠萝：损耗主要在去皮、去眼、修边、成熟度不达标
- 冷冻菠萝块/果粒：损耗主要在解冻失水、破碎、冰衣
- 果泥/浓缩汁：损耗按投料换算，基本不叫"到货损耗"

**2. 直接向供应商索取书面数据**
找都乐/鑫荣懋的销售或客服，明确要求提供：
- 该规格近3–6个月的**到货验收合格率/损耗区间**
- 验收标准文件（糖度、成熟度、单果重、规格公差）
- 是否含"途损赔付"条款

**3. 最可靠的做法：自己做小批量实测**
建议采购前做3批、每批不少于1个托盘/整箱的到货实测，记录：
- 到货总重 vs 验收合格可用重
- 不合格原因分类（烂、青、过熟、规格不符、机械伤）
- 得出你自己的**实际可用率**

**4. 谈判时把损耗写进合同**
- 约定验收标准和不合格率上限
- 超出部分如何扣款/补货
- 锁定规格公差（单果重、直径、糖度区间）
