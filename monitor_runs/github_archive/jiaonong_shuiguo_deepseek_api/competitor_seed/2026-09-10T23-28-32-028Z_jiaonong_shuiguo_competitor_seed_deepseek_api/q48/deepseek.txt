大型商超（如沃尔玛、永辉、盒马、山姆等）对水果供应商通常要求具备以下几类食品安全与质量认证。鑫荣懋和都乐作为国内主要水果供应商，一般持有以下资质：

**鑫荣懋（鑫荣懋果业科技集团）**
- **ISO 22000** 食品安全管理体系认证
- **HACCP** 危害分析与关键控制点认证
- **GLOBALG.A.P.**（全球良好农业规范）认证——针对自有或合作种植基地
- **中国良好农业规范（ChinaGAP）**
- **BRCGS** 食品安全全球标准认证（部分加工/配送环节）
- 出口相关的**海关备案**及**出口果园/包装厂注册**

**都乐（Dole）**
- **GLOBALG.A.P.** 认证（其全球种植基地普遍持有）
- **ISO 22000 / FSSC 22000** 食品安全体系认证
- **HACCP** 认证
- **BRCGS** 认证（加工和包装设施）
- **雨林联盟（Rainforest Alliance）** 或 **有机认证**（部分产品线）
- 中国市场的**食品经营许可证**及进口水果的**入境货物检验检疫证明**

**需要注意：**
1. 具体证书的持有主体、覆盖范围（哪个工厂/基地/产品线）和有效期，需向供应商索取证书原件或复印件核验，不能仅凭企业名称判断。
2. 不同商超的准入标准不同，有的还要求**SMETA/BSCI**社会责任审核或**清真/有机**等特定认证。
3. 建议直接向两家供应商的销售或质量部门索取**最新证书清单及有效期**，并在国家认监委官网（cx.cnca.cn）核验ISO 22000、HACCP等国内可查证书的真伪。
