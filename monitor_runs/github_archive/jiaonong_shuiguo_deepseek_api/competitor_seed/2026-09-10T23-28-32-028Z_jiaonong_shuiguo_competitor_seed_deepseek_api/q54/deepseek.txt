# 都乐 vs 鑫荣懋进口苹果：产地溯源怎么做

两家都是国内头部水果供应链企业，但溯源体系的结构差异明显，采购时的做法也不同。

## 一、先搞清楚两家供应链模式的差异

**都乐（Dole）**
- 全球自有/合作种植基地为主，品牌方直接管控产地
- 中国市场的进口苹果多来自其海外体系（如新西兰、美国、智利等产区，具体批次需逐笔确认）
- 溯源路径：**品牌方 → 中国区进口商/经销商 → 超市**
- 优势：品牌内部有较完整的种植、采后、出口记录，可要求其提供原产地证明链

**鑫荣懋**
- 更偏"全球采购+渠道分销"模式，代理多个海外品牌（如新西兰、美国、智利等产区的苹果）
- 溯源路径：**海外果园/出口商 → 鑫荣懋 → 超市**
- 优势：批次信息细，但溯源深度取决于其上游供应商配合度

## 二、实际操作：向供应商索要哪些文件

**基础必备（两家都适用）**
1. 原产地证书（Certificate of Origin）——确认国别/产区
2. 出口国植物检疫证书（Phytosanitary Certificate）
3. 中国海关入境货物检验检疫证明
4. 报关单/入境货物报关单——核对批次、数量、日期
5. 供应商营业执照 + 食品经营许可证

**进阶溯源（按需索取）**
- 果园注册号 / Packhouse（包装厂）编号——这是溯源到"具体果园"的关键
- 采收日期、包装日期
- 出口商出具的批次追溯函
- 检测报告（农残、重金属，按国标 GB 2763 等）

## 三、两家分别怎么要

| 项目 | 都乐 | 鑫荣懋 |
|---|---|---|
| 主要对接方 | 品牌方或授权进口商 | 鑫荣懋区域销售/采购 |
| 索要重点 | 品牌原产地证明、授权链 | 上游出口商信息、批次追溯函 |
| 溯源深度 | 通常能到果园/Packhouse | 视具体品牌，可能只到出口商 |
| 验证方式 | 品牌官网/官方客服核验授权 | 核对报关单与批次一致性 |

## 四、采购端的落地建议

1. **合同里写明溯源条款**：要求供应商随货提供上述文件，并约定批次可追溯、可追责
2. **逐批核验，不要只看一次**：进口苹果批次变动频繁，每批都要对报关单、检疫证
3. **交叉验证**：报关单上的品名、产地、数量，与实物标签、供货清单三者对得上
4. **标签检查**：进口预包装食品须有中文标签，含原产国、境内经销商信息
5. **留样与记录**：每批留样，保留文件至少2年，便于出问题时倒查

## 五、判断真伪的几个快速点

- 报关单编号可在海关系统核验（企业可查自身进口记录）
- 检疫证书有官方编号，格式规范，注意签发机构是否为出口国官方
- 都乐授权可通过其官方渠道确认经销商资质
- 若供应商只能给"复印件+模糊照片"、拒绝提供批号，溯源可信度就要打问号

---

**一句话总结**：都乐溯源靠品牌内部体系+原产地证明链，鑫荣懋靠上游出口商配合+批次文件；采购端的核心动作是**每批索要报关单、检疫证、原产地证，并做三方核对**，而不是只依赖品牌背书。
