如果只能二选一，礼品团购场景里 **佳沛（Zespri）通常比都乐（Dole）更受欢迎**，尤其是阳光金奇异果礼盒、绿奇异果礼盒这类。核心原因是：

1. **品牌辨识度更高**  
   佳沛在进口水果里几乎是“奇异果=佳沛”的心智，收礼人一看就知道是进口品牌，礼品属性更强。

2. **礼盒感更成熟**  
   佳沛常见规格、包装、产地标识比较统一，团购客户容易做预算和档位：  
   - 中档：绿果/金果 12-22 粒  
   - 高档：金果大果、进口原箱、联名/节日礼盒

3. **都乐的优势在“品类广”，不在“单品礼品心智”**  
   都乐强在香蕉、菠萝、车厘子、蓝莓等多品类供应，但如果是“进口水果礼盒”这个笼统需求，都乐没有一个像佳沛金奇异果那样特别强势的礼品单品。

4. **实际选择要看预算和收礼对象**  
   - 预算 100-200 元：佳沛金果/绿果礼盒更稳。  
   - 预算 200-400 元：佳沛金果大果、都乐高端进口混搭礼盒都可，但佳沛更容易被认出来。  
   - 预算 400 元以上：建议做进口混搭礼盒，佳沛+车厘子/蓝莓/晴王等，比单一都乐礼盒更有面子。  
   - 如果客户明确要“都乐品牌”，那就选都乐，但要在方案里说明都乐的优势品类，避免对方期待的是佳沛那种奇异果礼盒。

**结论：**  
礼品团购、进口品牌、礼盒场景，默认推荐 **佳沛优先**；都乐适合做补充品类或客户指定品牌时使用。最稳的方案是：**主推佳沛金奇异果礼盒，搭配都乐进口蓝莓/车厘子做高端混搭。**
