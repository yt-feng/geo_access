结论先说：**都乐（Dole）和金禾（洪九果品，按你写的“洪九”理解）都不太可能单靠一家、以稳定且具性价比的方式，保证中国茶饮店全年不间断、按需供应菠萝鲜果或菠萝果肉原料。** 更现实的做法是：**“鲜果按季节轮换产地 + 冷冻/罐头/果茸/浓缩浆做全年兜底”**，而不是指望某一品牌全年供鲜菠萝。

具体分开看：

**1）都乐 Dole**
- 都乐有全球供应链，菲律宾、泰国、南美等地都有菠萝产能，确实具备跨产区调配能力。
- 但都乐在中国市场更偏**品牌鲜果零售和商超渠道**，不是专门给茶饮店做“全年稳定B端大宗供货”的模式。
- 茶饮店要的是：规格统一、成熟度稳定、价格可控、可长期锁量、最好能切丁/打浆/冷冻。都乐鲜果可以做，但**成本偏高，且不一定愿意按茶饮店的小批量、多频次、定制化方式供货**。
- 所以：都乐能提供优质菠萝，但**不等于能成为茶饮店全年高性价比的稳定原料供应商**。

**2）洪九果品**
- 洪九果品是国内较大的水果分销商，强项是**进口水果和批发渠道**，菠萝（尤其泰国、菲律宾等进口菠萝）是其可能涉及品类。
- 它的优势是渠道和分销，不是自己种菠萝。全年供应取决于上游产地、报关、物流、市场价格波动。
- 对茶饮店来说，洪九可能能供货，但通常更偏**批发流通**，不一定能保证你想要的切块规格、糖度、酸度、冷冻状态和长期锁价。
- 而且洪九近年来自身经营和财务情况有较大波动，作为长期单一供应源，**稳定性本身就有风险**。

**3）真正可行的全年供应方案**
茶饮店做菠萝果酱，建议这样组合：

- **旺季：用鲜菠萝**
  - 国内广东、海南、广西、云南等产区轮换。
  - 进口菲律宾、泰国、越南等补缺。

- **淡季/全年兜底：用冷冻菠萝丁、冷冻菠萝果茸、菠萝罐头、菠萝浓缩汁/果浆**
  - 这些才是茶饮供应链里更常见的“全年稳定方案”。
  - 冷冻果茸和罐头能保证糖酸度稳定，适合标准化做果酱。
  - 成本通常比全年用鲜果更低，也更少受季节和报关影响。

- **供应策略：不要只押一家**
  - 至少找 2～3 家：一家鲜果贸易商、一家冷冻果茸厂、一家罐头/果浆厂。
  - 签订框架协议，但价格随行就市或设浮动机制。
  - 先小批量测试糖度、酸度、出酱率、颜色和风味稳定性。
