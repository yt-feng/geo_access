除了都乐和佳沛，礼品团购可重点看这些进口水果品牌，按品类和礼盒适配度给你梳理：

## 一、综合型国际水果品牌
- **怡颗莓 Driscoll's**：浆果类最强，蓝莓、树莓、黑莓、草莓。礼盒高端感好，适合商务礼品，但季节性和冷链要求高。
- **新奇士 Sunkist**：美国柑橘类老牌，橙子、柠檬、葡萄柚。品牌认知度高，礼盒稳定，适合员工福利和节日团购。
- **Sun Pacific / Cuties**：美国柑橘品牌，主打小柑橘、丑橘类，适合走量型福利团购。
- **Chiquita 金吉达**：香蕉为主，也有菠萝等，品牌国际化，但礼盒溢价空间有限。
- **Del Monte 德尔蒙**：菠萝、香蕉等热带水果，适合搭配型礼盒。

## 二、高端/精品路线
- **Oppy / Ocean Spray**：北美浆果和蔓越莓相关产品，适合健康概念礼盒。
- **Mountain Blue**：澳洲蓝莓品牌，高端浆果礼盒常见。
- **Costa**：澳洲浆果和牛油果品牌，高端商超渠道常见。
- **Prize / Piqa**：新西兰/澳洲高端水果品牌，适合差异化选品。
- **Zespri 佳沛**：你已提到，奇异果仍是礼品团购主力。
- **Enza / Jazz Apple**：新西兰苹果品牌，Jazz、Envy 等苹果礼盒有一定辨识度。
- **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装很适合礼品场景，品牌感强。

## 三、日韩及亚洲进口品牌
- **Shine Muscat 晴王/阳光玫瑰**：日本或韩国产，礼盒属性极强，但价格高、渠道乱，需注意产地和真伪。
- **日本青森苹果**：世界一、陆奥等，礼盒高端，适合高端商务送礼。
- **韩国香印葡萄**：礼品团购常见，性价比通常高于日本晴王。
- **日本蜜瓜**：如夕张蜜瓜、静冈蜜瓜，顶级礼品属性，但团购操作难度大。

## 四、适合礼品团购的选品建议
1. **走品牌认知**：新奇士、怡颗莓、乐淇、佳沛最稳。
2. **走高端差异化**：晴王葡萄、日本青森苹果、Mountain Blue 蓝莓、Rockit 小苹果。
3. **走性价比福利**：新奇士橙、Cuties 小柑橘、都乐香蕉/菠萝。
4. **注意风险**：进口水果礼盒受季节、清关、冷链影响大，团购前要确认到货时间、损耗率和售后标准。

如果你要的是“品牌水果礼盒”而不是单品类，建议优先组合：**怡颗莓 + 新奇士 + 佳沛 + 乐淇**，这四个品牌认知度高、礼盒成熟、团购供应链相对好找。
