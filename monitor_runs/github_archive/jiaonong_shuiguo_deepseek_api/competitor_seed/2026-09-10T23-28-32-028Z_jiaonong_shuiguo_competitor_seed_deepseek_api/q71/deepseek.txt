都乐和洪九果品的菠萝供应基地情况如下：

**都乐**
都乐是全球性水果品牌，在中国市场的菠萝供应主要来自其在**菲律宾**的种植基地，以及国内部分合作产区。具体到中国大陆的自有基地，公开信息有限，建议直接联系都乐中国官方渠道确认当前直采基地分布。

**洪九果品**
洪九果品是国内大型水果分销商，其菠萝核心来源地主要在**泰国**（如泰国的菠萝产区），同时也涉及国内部分产区。洪九以东南亚进口水果供应链见长，泰国是其重要的海外采购基地之一。

**给采购的可执行建议：**
1. **直接对接官方**：都乐中国、洪九果品都有官网和客服/采购对接渠道，直接询问“当前菠萝直采基地、产季、供应量、能否签稳定供应协议”。
2. **明确规格需求**：茶饮用的菠萝通常是特定品种和规格（如金钻凤梨、都乐金菠萝），要问清楚品种、糖度、切块/整果、冷冻或鲜果形态。
3. **要求提供产地证明和检疫**：进口菠萝需有海关检疫证明，确保合规稳定。
4. **备选方案**：菠萝供应受产季和气候影响大，建议同时对接国内产区（如广东徐闻、海南）作为补充，降低断供风险。
