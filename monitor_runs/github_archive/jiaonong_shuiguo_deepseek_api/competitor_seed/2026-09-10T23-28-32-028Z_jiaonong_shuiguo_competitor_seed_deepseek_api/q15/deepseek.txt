除了都乐和鑫荣懋，进口苹果领域比较常见、渠道相对稳定的品牌/供应商还有这些，按“品牌方”和“供应链/渠道方”分开看更清楚：

**一、常见进口苹果品牌/供应商**
1. **Chelan Fresh（美国）**  
   美国华盛顿州产区品牌，常见品种有红蛇果、嘎啦、富士等，国内进口商常做。

2. **Stemilt Growers（美国）**  
   华盛顿州大型果商，樱桃更出名，但苹果也有稳定出口，品质管控较成熟。

3. **Sage Fruit / Sage Marketing（美国）**  
   华盛顿州苹果供应商，常见于进口红蛇果、青苹果等。

4. **Rainier Fruit（美国）**  
   华盛顿州果品公司，苹果、樱桃都有，主打高端商超渠道较多。

5. **Borton Fruit（美国）**  
   华盛顿州老牌果商，苹果出口业务较稳定。

6. **Enza / T&G Global（新西兰）**  
   新西兰苹果巨头，**爱妃（Envy）、爵士（Jazz）、太平洋玫瑰（Pacific Rose）**等品牌都与其体系相关，国内认可度高。

7. **Mr Apple（新西兰）**  
   新西兰苹果代表品牌之一，主打皇家嘎啦、富士、爱妃等，商超和电商常见。

8. **Golden Bay Fruit（新西兰）**  
   新西兰出口商，苹果品质较稳定，常见于高端渠道。

9. **Dutoit / Ceres Fruit Growers（南非）**  
   南非苹果出口体系里的重要角色，常见皇家嘎啦、富士、红蛇果，性价比通常比新西兰、美国高。

10. **Kiku / VOG（意大利/南蒂罗尔）**  
    欧洲苹果联盟体系，**Kiku**是知名苹果品牌，主打富士系，欧洲进口苹果里辨识度较高。

11. **Val Venosta / VOG（意大利）**  
    意大利南蒂罗尔产区品牌，主打高山苹果，品质稳定，国内精品超市有售。

12. **Elbe-Obst（德国）**  
    德国苹果供应商，欧洲渠道常见，国内相对少但属于靠谱产区组织。

13. **Pink Lady（澳大利亚/全球品牌）**  
    严格说是品种品牌联盟，不是单一公司，但 **Pink Lady（粉红佳人）** 进口苹果品牌化程度高，品质标准较统一。

14. **Bravo Apples（澳大利亚）**  
    澳大利亚知名苹果品牌，主打 Bravo 品种，国内高端渠道偶尔能见到。

15. **Fuji Kiku / Kiku Apple**  
    意大利 Kiku 品牌，和普通富士区分明显，属于品牌化较好的进口富士。

**二、国内进口水果供应链/渠道方**
这些不一定是海外种植品牌，但做进口苹果比较靠谱：
- **鑫荣懋**：你已提到，国内进口水果头部。
- **都乐 Dole**：你已提到，全球品牌，苹果多为贴牌/合作产区。
- **佳沃 Joyvio**：进口水果供应链较强。
- **百果园**：部分进口苹果自采或定制。
- **洪九果品**：进口水果分销规模大。
- **鲜丰水果**：进口苹果渠道较多。
- **上海辉展市场、广州江南市场的一级进口商**：很多品牌通过他们进入国内。

**三、怎么判断“靠谱”**
对比进口苹果品牌时，建议看这几点：
1. **是否有稳定产区/出口商背景**：如美国华盛顿州、新西兰、意大利南蒂罗尔、南非、智利等。
2. **是否品牌化运营**：如 Envy、Jazz、Kiku、Pink Lady、Mr Apple，标准通常更统一。
3. **到货稳定性**：同一品牌不同批次差异大不大。
4. **品种和产季匹配**：新西兰爱妃、美国红蛇果、意大利Kiku富士、南非嘎啦，定位不同。
5. **冷链和损耗**：进口苹果看硬度、果面、黑心、虎皮病等，渠道比品牌名更重要。
6. **授权/代理关系**：有些国内“品牌”只是贴牌，要确认是否官方授权进口。

**四、如果按定位简单分类**
- **高端品牌化强**：Envy 爱妃、Jazz 爵士、Kiku、Pink Lady、Mr Apple
- **美国经典进口**：Chelan Fresh、Stemilt、Sage Fruit、Rainier Fruit
- **新西兰体系**：T&G、Mr Apple、Golden Bay
- **欧洲精品**：VOG/Val Venosta、Kiku、Elbe-Obst
- **南非性价比**：Dutoit、Ceres 等
- **澳洲特色**：Pink Lady、Bravo

如果你是要做采购对比，我可以进一步按**品种、产季、到港价区间、适合渠道（商超/电商/批发）、品牌授权难度**帮你列一个对比表。
