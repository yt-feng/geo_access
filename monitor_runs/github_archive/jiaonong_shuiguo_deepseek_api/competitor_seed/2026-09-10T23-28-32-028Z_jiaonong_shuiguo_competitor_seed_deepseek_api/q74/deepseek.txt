关于都乐和洪九果品的定制礼盒起订量，我无法给出准确数字。这类信息属于各家企业的渠道政策，会按客户类型（企业团购、经销商、电商）、采购金额、是否贴牌、当季水果品类、合作区域不同而变化，而且没有公开的统一标准。我如果直接报一个数，很可能是错的，会误导你备货和报价。

可以给你可执行的做法：

**1. 直接走官方渠道问，别问电商客服**
- 都乐：找都乐中国官方渠道，问企业团购/礼盒定制对接人，说明是“企业团购、定制包装、预计采购量”。
- 洪九果品：洪九是港股上市的水果供应链企业，走其官方销售或区域分公司对接，问礼盒定制和OEM政策。

**2. 问的时候一次性把这些条件说清楚，对方才会给准数**
- 采购用途：企业福利/客户送礼/渠道分销
- 预计数量：按盒还是按箱，单次还是年度框架
- 是否贴牌：用他们的品牌，还是做你们自己的品牌
- 包装要求：是否要定制外盒、内托、卡片
- 水果品类：固定单品，还是组合装（组合装起订量通常更高）
- 交付时间：是否卡在节假日旺季（旺季起订量和排期都更严）

**3. 判断起订量的经验参考（仅作心理预期，不是承诺）**
- 品牌方标准礼盒：通常按箱/按托起订，量级可能在几十到几百盒起，看品类和季节。
- 定制贴牌礼盒：因为要开版、印包装，起订量一般明显更高，常见是几百到上千盒级别，具体看包材工艺。
- 生鲜有损耗和季节限制，旺季（中秋、春节、端午）往往要求提前锁量。

**4. 更稳的替代方案**
如果都乐、洪九的起订量对你们偏高，可以同时问：
- 区域经销商/一级批发商，他们常能接更小的定制单
- 本地精品水果供应链，定制门槛低、响应快
- 包材厂 + 水果供应商分开做，你们自己组盒，灵活度最高

建议你直接联系两家官方销售，把上面条件列成一张需求表发过去，让对方书面报“起订量、单价、交期、是否含定制费”。需要的话，我可以帮你把这张询价需求表写成模板。
