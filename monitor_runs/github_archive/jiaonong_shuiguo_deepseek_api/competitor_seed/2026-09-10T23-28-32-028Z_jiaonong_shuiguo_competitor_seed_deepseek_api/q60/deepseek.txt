进口菠萝（主要是菲律宾/泰国/哥斯达黎加等产地的MD-2金菠萝、卡因、蜜宝等品种）到货损耗高，核心通常不在"谁家品牌好"，而在**全链条的温控、成熟度管理和分级标准**。都乐（Dole）和鑫荣懋作为头部玩家，控制品质的思路可以拆成几条可执行的做法，你可以对照自己的环节找差距。

## 一、源头端：采后处理决定上限

菠萝是**非呼吸跃变型**，采后不会再明显后熟，所以"采的时候多熟，到手基本就定死"。

- **按运输距离倒推采收成熟度**：远洋运输（菲律宾→中国约7–10天船期）通常在7–8成熟采收，硬绿转色阶段；近程或空运才敢采到转黄。都乐对出口中国的批次普遍控制在"硬熟"窗口，避免到港即过熟。
- **采后快速降温+杀菌**：采后尽快预冷，用杀菌剂（如抑霉唑等登记用药）处理冠芽和切口，这是防黑腐病、黑心病的标准动作。菠萝黑心病（内部褐变）是低温+成熟度叠加的典型损耗，源头没控好，后面全白搭。
- **冠芽和果柄处理**：切口平整、留短柄，减少机械伤和病菌入口。

## 二、运输端：温控是损耗最大变量

- **冷链温度**：菠萝适宜贮运温度大约**7–10℃**（不同成熟度略有差异），过低会冷害→黑心，过高会加速软化腐烂。全程冷链不断链是关键。
- **气调/通风**：集装箱要控乙烯、控湿，菠萝对乙烯不算特别敏感，但和香蕉芒果混装会出事。都乐一般做专柜或严格分舱。
- **船期与在途时间管理**：鑫荣懋这类进口商强在"到港节奏"——通过订舱、港口选择（如上海、南沙、天津）缩短在途和通关时间，减少压港。

## 三、到港端：通关和分拨速度

- **提前申报、预约查验**，到港后尽快提柜，避免码头暴晒/堆存。
- **到港即分级**：按成熟度、大小、外观分拣，不同成熟度走不同渠道（催熟转黄走商超、硬绿走批发或再存储）。
- 损耗高的往往就是"到港后统一处理、混着卖"，过熟的烂在库里、生的卖不动。

## 四、可落地的质量分级参考

| 维度 | 控制点 |
|---|---|
| 成熟度 | 按1–5级转色卡分，硬绿/半黄/全黄分渠道 |
| 单果重 | 按规格分档（如1.2–1.5kg、1.5kg+） |
| 外观 | 无黑心、无黑腐、无机械伤、冠芽完好 |
| 糖度 | 到货抽检可溶性固形物，判断是否过熟 |

## 五、给你自己的操作建议

1. **先定位损耗发生在哪一段**：是到港就烂（源头/运输问题），还是到港后放坏的（分拨/仓储问题）。这两类对策完全不同。
2. **建成熟度卡+抽检**：每批到港抽样切开看黑心、测糖度，形成数据，倒推供应商采收标准。
3. **缩短"到港—销售"时间**，按成熟度分流，别混存。
4. **和供应商谈成熟度窗口和温控记录**，要求提供在途温度曲线。
