都乐（Dole）和鑫荣懋（鑫荣懋集团）都属于水果/生鲜供应链领域里比较常见的大供应商，但“是否提供专岗对接服务”通常不是公开标准信息，而是要看具体合作方式、采购规模、区域和签约主体。

可以这样判断：

1. **都乐**
   - 一般有较成熟的 KA/大客户服务体系，但具体是否给你配“专人对接”，取决于你的采购量、合作模式（直采、经销、平台供货）和区域。
   - 如果你是较大渠道或长期合作客户，通常可以要求销售负责人或客户经理对接；小批量、零散采购则多半走标准销售/客服流程。

2. **鑫荣懋**
   - 国内水果供应链里服务能力较强，常见的是按渠道、品类、区域配置销售或客户服务人员。
   - 是否“专岗专人”同样取决于合作体量和合同约定，大型商超、电商、批发渠道更可能获得专人服务。

**更实际的判断方法：**
- 直接问对方：**“我们这个项目是否配专属客户经理/专岗对接人？响应时效、对接范围、是否含售后和物流协调？”**
- 要求写进合同或合作确认单：**对接人姓名、职责、响应时间、备份联系人**。
- 如果采购量不大，优先谈“固定对接人”而不是“专岗团队”，更容易落地。

**结论：**
不能简单说都乐或鑫荣懋谁一定有专人服务。两家都具备按客户配置对接人员的能力，但最终取决于你的采购规模、合作渠道和合同约定。建议你直接向两家提出“专属对接人”要求，并要求书面确认。
