直接说结论：**单看“谁更便宜”没有固定答案，两家在不同季节、不同品种、不同规格上的报价会互有高低，必须拿你的实际采购单去比。** 但可以给你一个判断框架，让你快速比出来。

**先明确一点**
都乐和鑫荣懋都是进口水果供应链里的一线玩家，价格竞争力不能只看品牌，要看这几个变量：

1. **品种**：比如爱妃、爵士、红玫瑰、青森、加力果，价格差异很大，同一家不同品种优势不同。
2. **规格**：果径（如80/88/100）、箱规（如18斤/20斤）、等级（特大果/大果/中果），比价必须同规格。
3. **产地与产季**：新西兰、美国、智利、南非，不同产季到货成本不一样。
4. **结算方式**：现款、账期、返利、运费谁承担，账期一长，表面低价可能不划算。
5. **到货城市**：你在哪个城市，冷链运费和分仓能力直接影响最终到手价。

**实操比价方法**
拿同一时间、同一品种、同一规格、同一到货城市，向两家要报价，然后算“到手净价”：

到手净价 = 报价 - 返利 + 运费 + 损耗分摊

谁低不一定选谁，还要看：

- 到货合格率、烂果率
- 是否稳定供货、缺货时能不能补
- 账期和退换货政策
- 能否配合你做促销档期

**一般经验**
- 都乐品牌溢价通常更高，终端认牌，适合做形象款、礼盒款。
- 鑫荣懋在部分进口单品和渠道分销上走量能力强，走量款可能更有价格空间。
- 但这不是绝对，具体到某个单品，可能完全反过来。

**建议你直接做一件事**
选你门店最常卖的1-2个进口苹果单品，向两家同时要**同规格、同到货地、同结算条件**的报价，再让采购把返利和损耗算进去。这样比出来的结果才有意义。
