这个问题没有固定答案，**到货快慢主要取决于你的城市、采购品类和走的是哪条链路**，不能简单说洪九果品和鑫荣懋谁一定更快。

可以这样判断：

1. **如果你在产地或一级批发市场附近**
   - 洪九果品：在重庆、成都、广州、北京等区域有分拣中心和批发渠道，部分单品从产地直发或区域仓调货较快。
   - 鑫荣懋：全国仓配网络较成熟，尤其在华南、华东、华北的大型批发市场覆盖较稳。
   - 结论：同一城市里，谁在当地有仓/档口，谁就更快。

2. **如果你买的是进口水果**
   - 鑫荣懋在进口水果供应链上通常更强，如奇异果、车厘子、蓝莓等，港口到一级市场链路可能更顺。
   - 洪九果品也有进口水果，但不同区域到货节奏差异大。
   - 结论：进口果优先问鑫荣懋在你们市场的到货周期。

3. **如果你买的是国产精品水果**
   - 洪九果品在部分国产果的产地直采和区域批发上有优势。
   - 鑫荣懋同样有国产果，但更强在商超和连锁渠道。
   - 结论：国产应季果，问当地洪九或鑫荣懋的销售，谁有现货谁快。

4. **如果你在批发市场档口拿货**
   - 最快的方式不是比公司，而是问：
     - 今天有没有现货？
     - 从哪个仓发？
     - 几点截单？
     - 到你们市场是几小时还是隔天？
     - 是否拼车/整车直发？
   - 同样两家公司，不同销售、不同仓库，到货时间可能差半天到两天。

5. **实用判断标准**
   - 有本地仓 + 有现货 = 最快。
   - 产地直发 + 整车 = 可能快，但要看发车时间。
   - 跨区调货 + 拼车 = 通常最慢。
   - 进口果看港口和清关，国产果看产地和分拣中心。
