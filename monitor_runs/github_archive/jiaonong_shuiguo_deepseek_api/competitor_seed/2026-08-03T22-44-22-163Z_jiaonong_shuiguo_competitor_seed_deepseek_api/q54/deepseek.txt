在超市采购进口苹果时，进行**产地溯源**主要是为了确认水果的真实产地、是否为正品、是否符合海关和食品安全要求。以下是针对**都乐（Dole）**和**鑫荣懋（XinRongMao）**两个品牌的实操溯源方法：

**1. 查看包装上的标签（最直接）**
- 都乐：进口苹果外箱或独立果贴（PLU码贴纸）上，通常会印有**原产国**（如美国、智利、新西兰等）、**出口商**名称、**进口商**在中国登记的备案号，以及**农业标准代号（如USDA、EU Organic等）**。
- 鑫荣懋：作为国内大型水果供应链企业，其进口水果会明确标注**原产国**，并且外箱上会有**中文标签**，注明国内总经销商（鑫荣懋）的地址、电话和**海关进口检验检疫证明编号**。

**2. 扫描溯源码/二维码**
- 这两家公司近年在中高端渠道（如盒马、山姆、Ole'）销售的进口苹果，外箱或包装上通常会有**可追溯二维码**。
- 操作：用微信/支付宝扫描后，页面会显示：苹果品种、产地农场名称、采摘日期、包装厂信息、运输路线、入境口岸及对应的《入境货物检验检疫证明》编号。

**3. 要求出示“三证”（采购方必须做）**
- 在供货商/门店采购时，务必索取或查验以下文件：
  - **《入境货物检验检疫证明》（海关出具）**：上面有货物名称、数量、**原产国**、入境口岸、检验检疫结果。
  - **《海关进口货物报关单》**：核实申报的原产国是否与包装一致。
  - **《植物检疫证书》**：由出口国出具，证明无有害生物。

**4. 细节鉴别（防止贴牌/冒充）**
- 都乐（Dole）：进口果贴通常是**黑底金字**或**白底蓝字**的“Dole”标志，且PLU码（如美国蛇果是4016）必须与品种匹配。如果贴纸印刷粗糙、字体模糊，可能是假货。
- 鑫荣懋：它的进口苹果多为代理品牌（如代理智利、新西兰指定果园），外箱通常有**“鑫荣懋”或“Joywing”标识**，且外箱有**中英文双语说明**。如果只有拼音或没有中文标签，涉嫌走私或非法进口。

**5. 电话/官网核验（仅限官方渠道）**
- **拨打各品牌中国区客服电话**：都乐和鑫荣懋均设有国内客服，报出包装上的**批次号（Lot No.)**，官方可帮您核实该批次是否为其公司正规进口的商品。
- **注意**：不要直接打包装上印的国外电话，需联系国内主体。

---

**为您快速总结**：
- 最快方式：**扫包装二维码 + 核对中文标签的海关证明编号**。
- 最稳妥方式：**向供货商索取《入境货物检验检疫证明》纸质或电子件**。
- 防坑提示：如果外箱上只有外文，没有任何中文标签，或价格明显低于市场均价，大概率不是正规进口的正品，请直接拒收。
