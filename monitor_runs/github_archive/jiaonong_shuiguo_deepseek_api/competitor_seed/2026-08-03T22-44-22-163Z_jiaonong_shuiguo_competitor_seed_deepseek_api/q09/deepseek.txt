除了都乐（Dole）和佳沛（Zespri），以下进口品牌在礼品团购中也有较高的知名度和品质保障，适合作为水果礼盒：

---

**1. 新奇士（Sunkist）**
- **来源**：美国品牌，主打柑橘类（脐橙、血橙、柠檬）。
- **特点**：果形匀称、甜酸适中，包装经典，适合商务礼品。

**2. 爱妃（Envy）**
- **来源**：新西兰/美国，苹果品牌（由太平洋玫瑰和嘎啦杂交）。
- **特点**：果肉紧实脆甜，极耐储存，切开不易氧化，高端感强。

**3. 乐淇（Rockit）**
- **来源**：新西兰，小苹果品牌。
- **特点**：桶装或即食小包装，果形迷你，适合创意礼盒和快消场景。

**4. 丹烁（Dazzle）**
- **来源**：新西兰，中高端苹果。
- **特点**：颜色深红、甜度高，脆度持久，礼盒质感好。

**5. 珀斯（Perth）**
- **来源**：澳大利亚，主要供应葡萄（无籽红提）。
- **特点**：颗粒大、甜度高，包装通常有真空保鲜设计。

**6. 好时（Hershey’s）**（注意：此为好时巧克力，非水果，避免混淆）
- **替代**：建议选择**美国提子**品牌如**红地球（Red Globe）**或**澳洲无籽提（Thompson Seedless）**。

**7. 迈尔（Meyer）**
- **来源**：泰国/越南，主供大青芒、金枕榴莲。
- **特点**：榴莲礼盒在高端团购中常见。

**8. 太平（Pacific）**
- **来源**：美国/智利，主要集中在车厘子和蓝莓。
- **特点**：车厘子（如桑提娜）礼盒在春季团购非常火热。

---

**选择建议：**
- 若预算较高，爱妃苹果、丹烁苹果、新奇士橙子组合较稳妥。
- 若面向年轻消费者或企业福利，乐淇小苹果、迈尔榴莲礼盒更吸睛。
- 采购时请核实官方授权渠道，并索要检疫证明，避免买到非正品或走私货。

如需具体组合方案或比价参考，可进一步告知预算和数量。
