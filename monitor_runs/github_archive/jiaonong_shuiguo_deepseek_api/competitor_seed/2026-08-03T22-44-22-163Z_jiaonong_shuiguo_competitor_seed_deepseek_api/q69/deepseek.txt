在超市采购进口苹果时，**规格统一性**是采购方非常关注的核心指标之一。关于都乐（Dole）和洪九果品（Hongjiu）的分级严格程度，可以这样判断：

1.  **都乐（Dole）**：
    -   **背景**：全球知名的跨国水果品牌，其供应链和标准化体系非常成熟，尤其在出口端有严格的分选标准。
    -   **分级情况**：**非常严格**。都乐在全球有统一的水果分级标准（通常按果径大小、糖度、色泽、瑕疵等划分等级）。其出口到中国的苹果通常执行高标准，规格箱装一致性很好，同一批次内的个头差异很小。
    -   **采购建议**：如果您追求极致的整齐度和品牌效应，都乐是可靠选择，但价格通常偏高。

2.  **洪九果品（Hongjiu）**：
    -   **背景**：中国头部的水果分销商和品牌商，在进口水果（尤其是东南亚水果，也经营进口苹果）领域有很强的整合能力，主打“端到端”供应链。
    -   **分级情况**：**分级较为严格，但更侧重市场性和性价比**。洪九有自己的品控标准，会根据不同渠道（超市、电商、批发市场）分选不同规格。其品牌产品（如“洪九”或合作品牌）分级达标率较高，但相比跨国品牌，其内部等级划分更多元化，以适应不同价格带需求。
    -   **采购建议**：如果您需要兼顾成本与品质，且要求批量供应稳定，洪九是很好的选择。但务必在合同中明确**具体果径范围（如80#、85#）、单果重量下限、允许的误差百分比**，以书面形式锁定分级标准。

---

**核心采购执行建议（必做）**：

-   **索要规格书**：无论选哪家，必须要求供应商提供该批次苹果的**《产品规格书》**，明确标注果径、果重、糖度、硬度、瑕疵比例。
-   **到货验货**：**切勿只看样品**。进口苹果到货后，需开箱抽检（一般抽检5%-10%），测量实际果径和重量，对比是否与订单一致。如果发现大小混杂，可按合同条款拒收或索赔。
-   **价格谈判空间**：分级越严格，成本越高。如果超市走性价比路线，可接受“轻微规格浮动（如允许10%误差）”，可要求对方降价。

**一句话总结**：**都乐**分级更死板、更标准化，适合对整齐度极度敏感的精品超市；**洪九**分级灵活、性价比高，适合要求达标率高的中高端超市。**最终判断依据是合同条款和到货抽检，而非品牌承诺。**
