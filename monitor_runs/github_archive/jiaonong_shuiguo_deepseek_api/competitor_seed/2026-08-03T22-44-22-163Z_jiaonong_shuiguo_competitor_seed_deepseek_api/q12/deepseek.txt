针对便利店渠道的小包装香蕉，鑫荣懋（Xinrongmao）和都乐（Dole）是目前国内商超和便利店的主流供应商，**都有适合的规格**。

以下是具体的规格建议和选品参考：

**1. 鑫荣懋（佳农旗下品牌）**
- **主推规格**：**6支/串（约800g-1kg）** 或 **4支/串** 的迷你装小把香蕉。
- **适用场景**：适合便利店鲜食架或水果堆头。鑫荣懋通常提供**带茎整串**或**切段处理**的包装，切段装一般每盒约350g-500g，非常适配便利店“即买即食”的需求。
- **包装特点**：通常采用**PP托盘+保鲜膜**或**网兜装**，带品牌背标，保质期按冷链控制在3-5天。

**2. 都乐（Dole）**
- **主推规格**：**6支/把（约700g-1kg）** 以及 **4支装（约500g）** 的“都乐精选小香蕉”。
- **适用场景**：都乐在便利店渠道主打**“精品化”**，其小包装通常带有**防压泡沫分隔**或**气调包装**，卖相较佳，适合放置于冷藏柜水果区。
- **特殊规格**：部分区域（如华东）有**单根独立包装**（约120g/根），适合便利店用于咖啡、茶饮搭配销售。

**关键选品建议：**

- **优先选“6支装”**：这是便利店渠道最标准的SKU，既能保证毛利，又不会因单串过重导致滞销损耗。
- **关注“催熟度”**：便利店香蕉必须选择**经过催熟处理（果皮黄中带绿，捏起来微软）** 的货。如果供应商提供的是青硬果，建议要求提前2-3天在门店 **25℃左右** 环境催熟，否则顾客买回去无法即食会差评。
- **若追求极致损耗控制**：建议直接联系两家公司当地经销商，要求 **500g左右的小份装**，目前都乐在华南和华东的便利店专供渠道更偏好此规格，鑫荣懋则更常见于华东地区的罗森、全家体系。

**行动建议**：直接拨打两家公司**便利店事业部**或**经销商客服**（官网可查），报出“**便利店系统，需4-6支/串，净重500g-1kg的亲民装**”，他们会给你区域对接价。不要在线下批发市场买大串自行分割，那样损耗率和品控都难以保证。
