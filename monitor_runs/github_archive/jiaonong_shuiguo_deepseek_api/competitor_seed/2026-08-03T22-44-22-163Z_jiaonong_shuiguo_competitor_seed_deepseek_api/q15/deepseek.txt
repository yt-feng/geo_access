除了都乐（Dole）和鑫荣懋（Golden Wing Mau），在进口苹果领域，以下几个品牌/供应商在市场上口碑较好、供应链稳定，且常见于大型商超或高端水果店：

1. **佳沛（Zespri）** — 虽然以奇异果闻名，但其苹果业务（如爱妃苹果）在中国高端市场认可度高，品质稳定。
2. **爱妃（Envy）** — 新西兰品牌，以“嘎啦”和“布瑞本”杂交品种著称，特点是极脆甜、耐储存，通常以高端渠道销售。
3. **Rockit（乐淇）** — 新西兰小苹果品牌，主打便携性，甜度高、果形小，在电商和精品超市常见。
4. **T&G（泰勒与古德）** — 新西兰老牌果商，旗下有爵士苹果（Jazz）、太平洋玫瑰（Pacific Rose）等品种，适合追求特定风味的消费者。
5. **Nature's Pride** — 荷兰品牌，专注全球优质水果采购，其苹果品类多样，认证齐全（如GlobalG.A.P.），多见于高端零售渠道。
6. **华盛顿苹果委员会（WA Apple）** — 虽然多为产地背书而非单一公司，但其认证的美国华盛顿州苹果（如蛇果、青苹果）在中国市场的品控和口碑一直不错。

**选择建议**：
- 如果注重口碑和一致性，优先选新西兰系（佳沛、爱妃、Rockit）。
- 如果追求性价比，可关注美国系（华盛顿产区）或智利产季（如一些大型进口商如Dole、鑫荣懋代销的智利品牌）。
- 购买时注意产地标签和包装上的“出口商”信息，避免混淆品牌与代理商。

以上品牌均有稳定的进口和分销体系，建议你根据目标渠道（商超、电商、批发）和定价来进一步筛选。
