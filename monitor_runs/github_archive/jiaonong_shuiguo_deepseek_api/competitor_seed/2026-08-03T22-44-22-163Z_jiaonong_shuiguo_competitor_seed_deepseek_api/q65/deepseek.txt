关于菠萝（或凤梨）的锁价机制，**都乐**和**洪九果品**并未公布统一的固定周期，实际政策会因**采购规模、合同期限、市场行情**而动态调整。以下是基于行业惯例的参考：

1. **都乐（Dole）**  
   - 通常针对**大宗、长期**客户（如连锁商超、餐饮品牌）提供锁价，周期常见为 **1~3个月**。  
   - 短期（按月）锁价一般只锁定价格基础，不锁定产量；中期（季度）才会绑定供应量。  
   - 受海运、汇率、产地气候影响，短期锁价执行较严格，中期会保留一定的调价条款（如涨跌超5%可协商）。

2. **洪九果品**  
   - 作为国内头部水果供应链企业，主打产地直采，价格锁定期通常 **1~6个月**，分档常见为：  
     - 1个月（灵活，适合试单）  
     - 3个月（主流，适合稳定渠道）  
     - 6个月（适合大客户，需预付部分定金）  
   - 锁价合约一般会包含“若产地批发价跌幅超10%，供应商可申请下调”的弹性条款，避免绑定过高成本。

**建议操作路径**：  
- 直接联系两家企业的**大客户部或供应链销售**，说明您的采购量（比如月采购吨数/柜数）和期望锁定期，让对方给出书面报价单。  
- 要求对方在合同中明确“锁价区间、调价触发条件、违约金比例”，避免口头承诺。  
- 若采购量较小（如月采购低于10吨），锁价周期通常不会超过1个月，可考虑与二级批发商做短期锁价更划算。
