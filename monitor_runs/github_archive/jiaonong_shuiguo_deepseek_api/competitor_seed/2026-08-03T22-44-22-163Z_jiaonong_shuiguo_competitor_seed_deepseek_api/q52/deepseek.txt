关于**都乐（Dole）**和**鑫荣懋（Golden Wing Mau）**菠萝的到货损耗率，**没有公开的统一标准数据**，因为损耗率受**采购季节、运输距离、包装方式、收货验收标准**影响极大。行业经验数据大致如下，可作为谈判与验收参考：

**行业经验参考值（到货即验收，不含储存期）：**
- **都乐（Dole）**：通常为**5% - 10%**。都乐走高端商超与餐饮渠道，包装规范（多为纸箱+网套+分隔），果体成熟度控制较稳定，正常冷链运输下损耗偏低（碰压伤、霉变）。
- **鑫荣懋（Golden Wing Mau）**：通常为**8% - 15%**。鑫荣懋流通渠道广，价格通常比都乐有优势，但批次间成熟度和包装紧密度存在波动，若采购非标箱或混级果，损耗会上升。

**给你的实操建议（不要只依赖品牌名）：**

1. **合同强制锁定损耗条款**：不要谈“损耗率”，要谈“**验收标准**”。例如：到货24小时内，单箱内软化、霉变、腐烂、严重压伤果**超过5%**，整箱拒收或折价；超过10%，整批退货。写明“净重结算”或“去损耗后结算”。
2. **按季节调整预期**：菠萝产季（海南/菲律宾）高温高湿季节（5-9月）损耗普遍比冬季高3-5个百分点，建议旺季采购多预留浮动。
3. **到货抽检方法**：到货后**随机抽3-5箱**，开箱全检称重，计算实际损耗，同批次换算整体。若抽检超标，要求供应商补货或按比例扣款。
4. **索要“到货质量报告”**：大供应商（尤其都乐）通常有冷链在途数据，可要求其提供发货时的果温、成熟度记录，作为验收依据。

**总结：**
如果你要写入采购合同，**建议按“验收后净重结算”**，这样损耗率由供应商承担。若必须给一个预算值，**都乐按8%计提、鑫荣懋按12%计提**比较保险（高于其宣传值，但低于实际风险峰值）。
