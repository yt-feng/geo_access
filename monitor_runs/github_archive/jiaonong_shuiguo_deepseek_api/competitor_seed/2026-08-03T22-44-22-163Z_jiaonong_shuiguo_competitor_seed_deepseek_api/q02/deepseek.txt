除了都乐（Dole），目前市场上能稳定供应菠萝的品牌还有不少，主要取决于你所在的地区和购买渠道。以下是几个常见且口碑较好的品牌/供应商，供你参考：

1. **佳沛（Zespri）**  
   虽然以猕猴桃闻名，但部分市场也有菠萝产品线，供应链较稳定，品质把控严格。

2. **金菠萝（Golden Pineapple）**  
   常见于高端超市或电商平台，主打鲜食菠萝，果肉甜度高，产地多为菲律宾或哥斯达黎加。

3. **云南香水菠萝/湛江菠萝（产地品牌）**  
   国内本土品牌，如“徐闻菠萝”（湛江产）和“云南香水菠萝”，以电商、水果连锁店为主，季节性略强但产量大，近几年供应稳定。

4. **都乐之外的进口品牌：美国德尔蒙（Del Monte）**  
   全球老牌水果商，在亚洲市场有菠萝供应，尤其罐装和鲜果均有覆盖，超市常见。

5. **天猫/京东自营及生鲜平台自有品牌**  
   例如盒马鲜生、叮咚买菜等平台的自有品牌菠萝，一般以直采或与稳定基地合作，供货周期较固定，适合零售购买。

6. **广州江南市场、北京新发地批发市场**  
   如果你需要大批量或批发渠道，可以直接联系这些市场的菠萝专营商户，他们通常与泰国、菲律宾、海南、广东多个产区签有长期合同，供应量更稳。

**建议**：若追求全年稳定，首选进口品牌（都乐、德尔蒙、佳沛）或大型生鲜平台自有品牌；若考虑性价比且能接受季节波动，可选择海南或徐闻产地品牌。购买时注意查看产地、成熟度标签和冷链物流记录，避免买到催熟或积压果。如需要具体某城市或某渠道的稳定供应商，我可以进一步帮你梳理。
