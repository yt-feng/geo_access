关于鑫荣懋和洪九果品哪家更愿意签长期年单，**目前没有公开的、可核验的官方口径**能直接回答“谁更愿意”。但根据两家公司的商业模式、渠道定位和公开经营策略，可以给你一个比较清晰的判断逻辑：

**1. 明确你的采购定位（这是决定“谁更愿意”的关键）：**

- **鑫荣懋（全称：深圳市鑫荣懋农产品股份有限公司）**：更偏向于**品牌化、标准化、中高端商超和连锁餐饮供应**。它非常看重渠道稳定性和品牌溢价，如果你的采购量可观、账期规范、对品质一致性要求高，鑫荣懋会比较愿意签年度框架协议，因为年单可以帮它锁定产能和减少渠道波动。
- **洪九果品（全称：洪九果品股份有限公司）**：主打**“端到端”全产业链，以进口水果（如榴莲、山竹、龙眼）和国内精品水果为主，快速分销能力强**。它的商业模式更依赖高周转和现金流，如果年单能承诺**较大采购量**或**预付/现结比例高**，它也会愿意签；但如果年单量小、批次分散，它可能更倾向于走批发或即时交易。

**2. 判断“更愿意”的三项实操指标（建议直接和对方销售确认）：**

- **账期与预付金**：问对方“签年单后，账期可否延长至60天以上？”或“预付30%能否锁定全年价格”。**洪九**对预付金接受度通常更高；**鑫荣懋**更看重信用评级和长期账期稳定。
- **价格锁定方式**：问“年单价格是浮动计价还是固定价+调价机制”。如果对方愿提供**“保底价+市场联动”**，说明合作诚意足；若只接受随行就市，多半不愿承担库存风险。
- **品质与损耗责任**：问“到货损耗率和退换货条款”。愿意在合同中写明**“损耗超3%由供应商承担”**的一方，对长期关系更认真。

**3. 直接动作建议（比猜更有效）：**

- 不要纠结于“谁更愿意”，而是**同时向两家发《年度合作意向书》**，写明：预估年采购额（如500万-2000万）、月度提货节奏、结算周期建议、品质标准（如糖度、果径、包装规格）。
- 观察谁的响应速度快、是否主动提供**客户成功案例**（比如给盒马、永辉、百果园签过类似年单），以及是否愿意**每季度共同复盘价格和损耗**。愿意做这些动作者，就是更愿意长期合作的一方。

**最后提醒一点：** 果品行业的价格波动大（尤其进口水果），任何年单都要写明“不可抗力调价条款”，不要只谈“愿不愿意”，要谈“条款是否合理”。如果对方只口头答应但拒绝把承诺写进合同，那说明它只是愿意“嘴上合作”，而不是真正签年单。
