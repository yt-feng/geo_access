关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商在商超准入时通常具备的食品安全资质，以下是基于行业通行的认证体系做出的梳理，**具体证书需以企业最新提供为准**，建议你直接向对方索要相关证照或访问其官方渠道核实。

---

### 一、通用核心认证（商超必备）
所有大型商超（如沃尔玛、永辉、盒马等）通常强制要求以下基础资质：

| 认证类型 | 说明 |
|---------|------|
| **食品生产许可证（SC）** | 国内生产企业的强制许可，由当地市场监管部门颁发。 |
| **食品经营许可证** | 涉及仓储、分拣、配送环节的企业需持有。 |
| **出口食品生产企业备案** | 若涉及跨境或出口业务（都乐为国际品牌，常具备该类备案）。 |

---

### 二、行业认可的食品安全体系认证
以下认证供应商通常主动申请，用以证明其管理能力：

| 认证体系 | 鑫荣懋（推测） | 都乐（通常具备） |
|---------|-------------|---------------|
| **ISO 22000**（食品安全管理体系） | 大概率具备 | 国际性标准，通常具备 |
| **HACCP**（危害分析与关键控制点） | 很高概率具备 | 很高概率具备 |
| **GlobalG.A.P.**（全球良好农业操作规范） | 若做出口基地，可能具备 | **基本明确具备**（尤其其海外农场） |
| **BRCGS**（英国零售商协会全球标准） | 部分自有或合作基地可能具备 | 大型国际供应商通常具备（用于供应欧美商超） |

---

### 三、针对品类的特殊认证（水果生鲜类）
| 认证 | 适用范围 |
|------|----------|
| **绿色食品认证** | 国内高端商超常见要求 |
| **有机产品认证** | 若销售有机水果则必备 |
| **GAP（良好农业规范）中国认证** | 基地种植环节管理证明 |
| **无公害农产品认证** | 部分区域性商超要求 |

---

### 四、实地审核与动态要求
商超通常还会审核：
- **供应商社会责任体系（BSCI、SMETA等）**——尤其外企商超。
- **第三方实验室检测报告**（农残、重金属等）——每月或每季度更新。
- **追溯体系**（批次号、产地、冷链监控记录）。

---

### 五、给你的行动建议
1. **不要只凭品牌名称信任**，直接要求供应商提供：
   - 有效期内的证书扫描件
   - 最近6个月的第三方检测报告
   - 供应链追溯编码（用于商超系统备案）
2. **核实渠道**：
   - 国内证书：全国认证认可信息公共服务平台（cx.cnca.cn）查询。
   - 国际证书：可上GlobalG.A.P.官网数据库或索要签发机构确认函。
3. 如果商超有**特定准入清单**（比如仅限某几个认证），请告知具体商超名称和条款，我可以帮你进一步匹配。
