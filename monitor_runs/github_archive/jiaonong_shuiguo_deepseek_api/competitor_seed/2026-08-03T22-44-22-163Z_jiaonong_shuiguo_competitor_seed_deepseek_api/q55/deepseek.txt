关于菠萝产地溯源，以下是两个主要供应商的情况说明（基于公开信息，**截至2024年**，具体合作建议直接联系官方核实）：

1. **都乐（Dole）**  
   - **有基地直供体系**：都乐在全球（包括菲律宾、哥斯达黎加等）拥有自有或合作种植基地，其中国内业务也涉及海南、广东等产区。  
   - **溯源能力**：都乐普遍具备较完善的批次追踪系统，可通过包装二维码或标签查询产地信息，但**具体到“直供基地名称和地址”需联系其中国区供应链部门获取**。

2. **洪九果品**  
   - **有基地直供模式**：洪九果品以“基地直采+全球采购”为核心，在国内广东、云南等地布局有菠萝种植基地合作，在东南亚（如泰国）也有菠萝采购源。  
   - **溯源透明度**：其产品可通过溯源标签（部分电商渠道提供）追溯至采购源头，但基地合作方通常是“订单农业”或“协议种植”，并非全部自有产权基地。
