关于批发市场香蕉价格，**我无法直接获取洪九果品和鑫荣懋两家公司实时的、针对具体批发市场的报价**。

因为香蕉价格受**产地（进口/国产）、品种（如高把/普通）、成熟度、采购量、当日市场供需**影响极大，且两家都是面向B端的大供应商，其报价通常是**根据采购量和长期合作条件动态议价**，不会公开统一挂牌价。

不过，我可以给你提供**判断和操作建议**：

1.  **非固定优劣**：通常**洪九果品**在**进口水果（如泰国、越南、菲律宾香蕉）**的供应链上成本控制较强；**鑫荣懋**则在**全品类水果**分销上渠道更广。但批发市场的价格优势取决于**你所在的批发市场档口实际拿货价**，不能简单认为哪家绝对更便宜。

2.  **直接对比方法**：建议你**在当天上午（批发市场交易高峰）**，分别联系当地洪九果品和鑫荣懋的**授权批发档口**，索取：
    *   同一规格（如：18公斤/箱，或按件数）的报价。
    *   明确产地（如：国产海南蕉还是进口蕉）。
    *   问清楚是否含运输费、是否需整箱起批、是否有破损包赔政策。

3.  **额外提醒**：批发市场存在**分拣差价**，即使同品牌，大蕉（果肉厚实）和普通蕉价格也不同。**建议拿货时现场开箱验货**，观察蕉把是否新鲜、有无黑斑，避免只看价格。
