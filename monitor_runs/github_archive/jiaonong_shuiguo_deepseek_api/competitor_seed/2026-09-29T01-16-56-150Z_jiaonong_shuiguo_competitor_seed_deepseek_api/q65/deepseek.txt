关于都乐（Dole）和洪九果品的菠萝锁价机制，我无法给出可靠的官方锁价周期数字——这类条款通常按客户、品类、采购量、季节和合同单独谈，不对外公开统一标准，我也没有可核验的公开来源能确认具体天数。下面给你可判断、可执行的思路。

**先说结论**
- **都乐**：进口/品牌菠萝业务多以**周度报价**或**月度框架+当期确认价**为主，鲜果类很少给很长的固定锁价；具体锁多久取决于你是商超、电商还是批发客户。
- **洪九果品**：以国内分销和进口水果为主，常见做法是**按批次/按柜锁价**或**短期（1–4周）锁价**，长期固定价一般要有量或预付条件。
- 这两家都**不太可能对陌生客户直接报出标准锁价周期**，需要走采购/销售对接。

**你可以直接去问的关键问题**
1. 锁价是按**周、半月、月**，还是**按单柜/单批次**？
2. 锁价是否含**运费、关税、损耗**？
3. 触发调价的条件是什么（汇率、产地价、海运费、到港价）？
4. 锁价需要**预付比例/最低起订量/账期**吗？
5. 超期未提货怎么处理？

**更实际的做法**
- 同时找**一级进口商、产地直采商、大型批发市场档口**比价，锁价灵活性往往比品牌方更高。
- 要求对方给**书面报价单**，写明锁价期限、调价机制、违约责任。
- 如果想锁定较长时间，通常要用**预付款+框架协议**换，鲜果很难免费长锁。
