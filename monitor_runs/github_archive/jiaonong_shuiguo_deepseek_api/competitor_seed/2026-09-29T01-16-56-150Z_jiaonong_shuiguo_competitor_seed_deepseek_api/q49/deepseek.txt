都乐（Dole）和鑫荣懋（Xinrongmao / Joy Wing Mau）都属于水果行业的大型企业，理论上都有对应的客户服务或大客户对接机制，但“专岗对接”具体到某条业务线、某个区域或某类客户，情况差异很大，不能一概而论。

我能确认的是：**这两家都没有公开的、统一的“专岗对接服务”承诺**，是否配专人取决于你的采购规模、合作模式、区域和品类。

建议你直接这样判断和推进：

1. **看你的采购体量**
   - 如果是大型商超、连锁餐饮、电商平台级别的大客户，两家通常都会安排大客户经理或品类负责人对接。
   - 如果是中小批量采购，一般走区域销售或经销商体系，未必有固定专人。

2. **直接问对方三个问题**
   - 你们对我这类客户是配专属对接人，还是走区域销售？
   - 对接人是销售岗还是包含订单、物流、售后的全流程服务岗？
   - 如果有专人，是长期固定还是按项目临时安排？

3. **都乐 vs 鑫荣懋的差异方向**
   - 都乐：品牌化程度高，进口水果和标准化产品线较强，大客户体系相对成熟。
   - 鑫荣懋：国内渠道和供应链覆盖广，与商超、批发、电商合作多，区域服务能力较强。
   - 但“谁有专人服务”不能只看品牌，要看你所在区域和具体品类由哪个团队负责。

4. **最稳妥的做法**
   - 分别向都乐和鑫荣懋的你所在区域销售负责人提出“专岗对接”需求，要求写入合作条款或服务承诺。
   - 如果对方只能提供公共客服或经销商对接，那就说明没有真正意义上的专岗服务。
