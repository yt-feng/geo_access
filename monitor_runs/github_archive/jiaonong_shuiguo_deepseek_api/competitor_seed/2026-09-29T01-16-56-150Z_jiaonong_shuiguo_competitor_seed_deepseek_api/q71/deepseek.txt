都乐（Dole）和洪九果品都是大型水果供应链企业，但具体到“菠萝原料的稳定供应基地在哪里”，需要分开看，而且**公开可查的、能直接作为采购依据的基地地址信息有限**，我不虚构具体地址。下面给可判断的信息和采购建议。

## 1. 都乐 Dole

都乐是全球性果蔬集团，菠萝是其传统优势品类之一。

- **全球层面**：都乐在菲律宾、泰国、哥斯达黎加等地有菠萝种植和供应体系，菲律宾菠萝（如MD-2金菠萝）在国内茶饮渠道较常见。
- **中国业务**：都乐中国主要做进口水果和品牌化分销，国内销售主体和分选包装多集中在上海、广州等口岸和销地市场。
- **对茶饮采购的意义**：如果你要的是**稳定、标准化、可追溯的菠萝原料**，都乐更多是“品牌供应商+进口/分销”角色，不一定直接开放国内种植基地给你对接。实际对接通常通过都乐中国或其授权经销商。

**建议核实方式**：直接联系都乐中国官网的B2B/餐饮渠道入口，问清楚：
- 菠萝原料是进口还是国内基地；
- 能否提供产地证明、农残报告、批次稳定性；
- 最小起订量、锁价周期、冷链到仓方式。

## 2. 洪九果品

洪九果品是国内大型水果分销企业，核心模式是**从产地采购、分选加工、分销到全国**，不是单纯的自有种植基地模式。

- **菠萝相关产地**：洪九的菠萝供应通常涉及国内主产区（如广东徐闻、海南、云南等）以及部分进口来源。徐闻是中国重要菠萝产区，海南也是冬春菠萝供应地。
- **基地性质**：洪九更多是“产地合作+加工分选+供应链分销”，所谓“基地”可能是合作种植基地或产地采购网络，而非全部自有。
- **对茶饮采购的意义**：洪九的优势在分销网络和全国履约能力，适合需要多产地、多批次稳定供货的客户。但具体到菠萝，是否直供茶饮原料、是否做冷冻果肉/果浆，需要按产品线确认。

**建议核实方式**：联系洪九果品官方渠道，明确问：
- 菠萝是鲜果还是冷冻果肉/果浆；
- 主供产地是徐闻、海南还是进口；
- 能否按茶饮标准做糖度、酸度、纤维感、出汁率等指标；
- 是否有稳定的年度框架协议和备用产地。

## 3. 给茶饮采购的实操建议

如果你要的是**稳定供应**，不要只盯“基地在哪里”，更要看这几点：

1. **先定原料形态**
   - 鲜果现切：看产地季节和冷链。
   - 冷冻菠萝果肉/果块：看加工厂和冷冻链。
   - 菠萝果浆/浓缩汁：看代工厂和配方稳定性。
   - 菠萝粒/丁：看规格、糖度、杀菌方式。

2. **国内菠萝主产区参考**
   - **广东徐闻**：国内菠萝核心产区，春夏季供应集中。
   - **海南**：冬春上市，适合补淡季。
   - **云南、广西、福建**：也有一定产量，但茶饮规模化采购常以徐闻、海南为主。
   - **进口**：菲律宾、泰国等，适合全年补充，但受海运、关税、汇率影响。

3. **要求供应商提供**
   - 产地证明和批次检测报告；
   - 糖酸比、出汁率、纤维感等应用指标；
   - 年度供应计划、备用产地、锁价机制；
   - 试产样品，先做门店盲测再签框架。

4. **不要只依赖单一供应商**
   茶饮菠萝供应容易受台风、雨季、运输影响。建议至少“国内主产区+进口补充”双线配置，避免断供。

## 结论

- **都乐**：全球菠萝供应链强，中国业务偏进口和品牌分销，具体国内基地需向都乐中国B2B渠道核实。
- **洪九果品**：国内水果分销和产地采购网络强，菠萝可能来自徐闻、海南等主产区及进口，具体基地/加工厂需向洪九官方确认。
- **采购上**：与其只问“基地在哪里”，不如直接要求供应商提供**产地、加工厂、产品形态、检测报告、锁价和备用方案**，这才是稳定供应的关键。
