这个问题没法直接给出“谁更便宜”的确定答案，因为洪九果品和鑫荣懋对批发市场的报价是**一单一议、随行就市**的，受产地、季节、规格、拿货量、结算方式影响很大。直接说谁有优势都不准确。

给你几个可判断的维度：

**1. 两家定位不同**
- **洪九果品**：以榴莲、山竹、火龙果等进口水果起家，香蕉是其重要品类之一，走的是全国分销+直采模式，货源多来自东南亚（菲律宾、越南、老挝等）和国内产区。
- **鑫荣懋**：国内大型水果供应链企业，品类更全，香蕉同样是核心单品，渠道覆盖商超、批发、电商等。

**2. 价格优势取决于你的拿货条件**
- 拿货量大、能整车走：两家的直采价都可能比市场档口低，差距主要在产地和到货批次。
- 拿货量小、要拆件：鑫荣懋渠道分销体系较成熟，批发市场里的二级分销可能更灵活；洪九在进口蕉的整柜分销上有优势。
- 结算方式：现款现结通常比账期价低，这一点两家都一样。

**3. 实际怎么比**
最靠谱的做法是：
1. 问清楚**产地、规格（如每箱净重、每把条数）、成熟度、到货日期**；
2. 同一天、同一市场、同样规格下，让两家报价；
3. 把**损耗率**算进去——香蕉催熟和损耗差异可能比每箱几块钱的价差更影响实际成本。

**4. 结论**
- 如果你做**进口蕉、整柜走量**，洪九在进口蕉供应链上有传统优势，价格可能更有竞争力。
- 如果你要**品类组合、稳定供货、多渠道分销**，鑫荣懋的综合供应能力可能更合适。
- 单看“谁更便宜”没有固定答案，**必须拿同规格、同产地的实时报价来比**。

建议你直接联系两家的区域销售或当地批发市场代理，拿同一批次的报价单对比，同时问清退换货和损耗政策。这样比任何笼统结论都可靠。
