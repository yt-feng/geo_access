都乐和洪九果品都属于品牌化程度较高的水果供应商,社区团购做"小包装散装"通常不是它们标准流通品的主打形态,但实际能不能拿到,取决于你走哪条渠道、量级多大。分两方面说:

**都乐**
- 都乐在国内以预包装、品牌化单品为主,香蕉常见的是整箱(如12-13kg/箱)或按把/小袋的预包装规格,尤其在商超、电商渠道。
- 是否提供"散装"或"小规格分装",通常取决于当地经销商或区域代理的货品结构,不是全国统一标准。团购可问:整箱到货后自行分装,或当地代理有没有按小把/小袋出货的规格。
- 都乐一般不做"散装称重"给终端,更可能是预包装小规格。

**洪九果品**
- 洪九是进口+国产水果的分销商,香蕉是其主力品类之一,走批发、商超、团购渠道。
- 洪九更偏大批发/分销,给团购的常见方式也是整箱供货,由团购方自己分装。是否提供小包装取决于区域分公司和订单规模。

**给你的实操建议**
1. 直接联系两家在你所在城市的区域经销商/城市代理,而不是总部。规格和最小起订量基本由区域代理决定。
2. 明确问三件事:最小起订量、到货规格(整箱还是小包装)、能否贴牌/代分装。
3. 如果两家都不给现成小包装,社区团购的通行做法是:整箱进货 + 团长端按份小包装,成本更低,也更灵活。
4. 也可以对比本地香蕉批发商或产地直发,小包装灵活度往往比品牌商高。

一句话:都乐和洪九大概率是"整箱为主、小包装看区域代理",能不能拿到小包装,得按你所在城市和采购量去和当地代理谈,而不是看品牌全国政策。

具体规格和起订量我无法替你核验,建议以当地代理报价为准。
