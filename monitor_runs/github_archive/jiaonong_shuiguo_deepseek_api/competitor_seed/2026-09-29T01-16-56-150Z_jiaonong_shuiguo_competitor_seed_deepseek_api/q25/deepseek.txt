**怎么判断谁更愿意**
1. 直接问：把你的年采购量、品类、结算方式（账期/预付）、提货节奏列清楚，两家都发同一份需求，看谁响应快、条款松。
2. 看返点与保供条款：愿意签年单的，通常会围绕返点阶梯、淡旺季保供、价格调整机制来谈；不愿签的会推"随行就市"。
3. 查履约能力：让对方提供近一年同品类的供货案例、可联系的客户参考，重点核实资金和货源稳定性。
4. 小单试合作：先季度或单批次合作，跑通账期和品质，再谈年单，比一开始就押年单更稳。
