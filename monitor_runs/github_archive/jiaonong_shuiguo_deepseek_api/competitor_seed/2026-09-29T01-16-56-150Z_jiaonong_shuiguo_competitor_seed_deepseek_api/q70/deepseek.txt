可以优先看这两家，但要先区分“品牌方/大型果业公司”与“具体供货商”的证明口径。

**都乐（Dole）**
- 通常有较成熟的产地追溯和品控体系，尤其是其自有或合作种植基地、进口香蕉业务。
- 可要求提供：产地证明/果园或包装厂编号、批次追溯码、农残检测报告、GAP/GlobalG.A.P.等认证、出口国植物检疫证书、到货质检报告。
- 注意：都乐中国更多是品牌和供应链体系，具体证明要看你对接的是都乐直属、区域经销商还是批发商，后者未必能提供完整源头文件。

**鑫荣懋**
- 是国内大型水果供应链企业，香蕉是其重点品类之一，通常具备产地采购、加工配送和品控能力。
- 可要求提供：基地/产地信息、批次追溯、第三方检测报告、品控标准、验收记录、相关认证。
- 注意：鑫荣懋部分货源可能来自合作基地或海外供应商，能否做到“单批次到产地”的完整溯源，要按具体品类和采购渠道确认。

**建议你这样核验**
1. 直接问对方：能否提供“批次级”溯源，而不是只给产地国或品牌授权。
2. 索要近3个月内的农残/重金属检测报告，并核对报告编号、样品批次、检测机构资质。
3. 要求提供 GlobalG.A.P.、GAP、有机认证、出口检疫证等，按你的销售渠道要求匹配。
4. 先小批量试单，抽查追溯码能否对应到包装厂/果园和检测报告。
5. 合同里写明：产地不符、批次无法追溯、检测不合格时的退换和赔偿条款。

**结论**
都乐和鑫荣懋都可能提供产地溯源和品控证明，但“有没有”取决于你对接的具体主体和采购批量。大品牌/大供应链通常比普通批发商更规范，但一定要要求批次级文件，不能只看品牌名。
