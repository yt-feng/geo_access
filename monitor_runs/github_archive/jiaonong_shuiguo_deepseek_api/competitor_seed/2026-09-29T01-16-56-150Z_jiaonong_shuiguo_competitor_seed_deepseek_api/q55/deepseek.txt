都乐（Dole）和洪九果品都属于有自有/合作种植基地、可做产地溯源的水果供应链企业，但具体到“菠萝”这个单品、以及你所在区域能不能拿到基地直供，需要分情况看，不能一概而论。

**都乐 Dole**
- 都乐在中国有自有农场和合作基地体系，菠萝（尤其是菲律宾、泰国等进口菠萝，以及国内部分产区）通常有较完整的批次和产地信息。
- 但都乐对下游客户多是“品牌商+供应链”模式，能不能基地直供取决于你的采购量、合作身份（商超/批发/电商/加工厂）和区域。小批量一般走经销商，大客户才可能谈基地或总仓直发。
- 溯源信息相对规范，可要求提供批次号、产地证明、报关/检疫等文件。

**洪九果品**
- 洪九是国内较大的水果供应链企业，在东南亚（泰国、越南等）和国内产区有基地合作与采购网络，菠萝是其重点单品之一。
- 它更偏向“基地合作+产地直采+全国分销”，对大型渠道客户可以做到产地直发或区域仓直配。
- 溯源能力取决于具体基地和批次，通常能提供产地、采摘/加工批次等信息，但未必每个SKU都能追溯到单一地块。

**判断建议**
1. 先明确你要的“产地溯源”层级：是仅到国家/产区，还是要到具体基地、地块、批次？两者要求差别很大。
2. 直接问对方能否提供：产地证明、基地备案信息、批次号、检测报告、采摘/加工日期。
3. 基地直供通常有门槛：稳定采购量、账期、区域配送能力。量小的话，更现实的是找他们在当地的经销商或区域仓。
4. 除了这两家，也可以看鑫荣懋、佳沃、百果园供应链体系，以及广东徐闻、海南、云南等主产区的本地合作社/龙头基地，溯源反而可能更直接。

**结论**
都乐和洪九都有基地直供的能力和体系，但不是“默认对所有客户基地直供”。你需要按单品、采购量、区域去谈，并明确溯源深度。建议直接联系他们的区域销售，要求提供菠萝具体产季的基地和批次溯源方案，再对比报价和起订量。
