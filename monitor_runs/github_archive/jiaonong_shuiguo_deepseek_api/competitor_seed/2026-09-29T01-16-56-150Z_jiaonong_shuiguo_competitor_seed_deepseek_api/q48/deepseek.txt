鑫荣懋和都乐都属于水果供应链/品牌商，具体“有哪些食品安全认证”要分主体和工厂来看，不能只看品牌名。大型商超通常要求供应商提供以下一类或多类有效证书，并在有效期内、覆盖供货品类和加工环节：

**常见会被商超要求的资质/认证**
- 营业执照、食品经营许可证/食品生产许可证（SC）
- ISO 22000 食品安全管理体系
- HACCP 危害分析与关键控制点体系
- FSSC 22000 或 BRCGS、IFS 等GFSI认可的认证
- 出口备案/出口食品生产企业备案（如涉及出口）
- 绿色食品、有机产品认证（如对应产品宣称）
- 溯源、GlobalG.A.P. 等种植/养殖端认证（视品类）

**关于鑫荣懋**
鑫荣懋是国内大型水果供应链企业，通常具备营业执照、食品经营/生产相关许可，并会按客户要求建立ISO 22000、HACCP等食品安全体系。其具体认证证书、覆盖工厂和品类，需以它最新提供的证书扫描件为准，不同子公司/加工厂可能不同。

**关于都乐**
都乐（Dole）是国际水果品牌和供应链企业，通常具备较完整的食品安全与质量体系认证，常见包括ISO 22000、HACCP、GlobalG.A.P.、BRCGS等，具体取决于其所在国家、工厂和产品线。都乐中国相关主体也会按国内法规取得食品经营/生产许可等。

**给商超采购/供应商审核的可执行建议**
1. 不要只问“品牌有没有认证”，要按“签约主体+生产工厂+供货品类”逐项核对。
2. 要求供应商提供证书原件扫描件，核对：证书编号、认证范围、有效期、发证机构、获证主体名称。
3. 对进口水果，还要核对海关入境货物检验检疫证明、报关单等。
4. 对分装/加工环节，核对SC证和对应生产地址。
5. 如果商超要求GFSI认可认证，优先接受FSSC 22000、BRCGS、IFS等；ISO 22000和HACCP是否被接受，要看商超自身标准。
