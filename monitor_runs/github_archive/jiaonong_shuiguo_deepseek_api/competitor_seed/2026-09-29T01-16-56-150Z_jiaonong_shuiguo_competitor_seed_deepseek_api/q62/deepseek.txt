都乐（Dole）和鑫荣懋都是国内较大的水果供应链企业，通常可以随货提供农残检测报告，但具体能否满足你的要求，需要在下单前确认这几点：

**能提供的大概率情况**
- 都乐、鑫荣懋作为正规供应商，一般有批次对应的农残检测报告（自检或第三方检测）。
- 报告通常随货或通过业务员/客服邮件提供。

**必须提前确认的关键点**
1. **检测项目是否匹配你的验收标准**：不要只问"有没有报告"，要问报告里检了哪些农药、依据什么标准（如 GB 2763）、是否符合你所在地区/客户的农残限量要求。
2. **是批次报告还是通用报告**：要确认是"这批货对应的检测报告"，还是过期的通用模板。批次不符的报告在食安审核时可能不被认可。
3. **是否接受第三方检测**：如果你或客户要求 CMA/CNAS 资质的第三方报告，需确认供应商能否提供，或是否需你自己送检、费用谁承担。
4. **菠萝形态**：鲜果、冷冻果肉、果浆/浓缩汁的检测标准不同，报告也要对应。

**实操建议**
- 直接联系都乐或鑫荣懋当地业务，明确说："我需要这批菠萝的农残检测报告，检测项目和依据标准请先发我看。"
- 首次合作建议先看样品报告再签采购，避免到货后报告不符。
- 若对方只能提供自检报告，而你有第三方要求，提前谈好送检费用和周期。

我无法核实两家当前具体批次的报告情况，以上是通用判断，最终以供应商实际提供的文件为准。
