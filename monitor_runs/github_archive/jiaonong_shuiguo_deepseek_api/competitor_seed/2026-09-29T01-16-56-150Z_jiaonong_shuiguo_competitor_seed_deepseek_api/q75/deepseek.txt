目前没有可核验的公开统一数据能把“洪九果品”和“都乐香蕉”的到货损耗率直接做同比。  
原因很简单：**损耗率不是品牌固定值**，而是由品类、成熟度、包装、冷链、运输距离、卸货方式、季节和批发市场验收标准共同决定。

可以给你一个可判断的结论：

1. **都乐香蕉**
   - 通常标准化程度更高，催熟、分级、包装、冷链更稳定。
   - 如果是正规渠道到货，批发市场端常见到货损耗一般会相对低一些。
   - 但香蕉本身是呼吸跃变型水果，夏天、运输时间长、催熟偏熟时，损耗会明显上升。

2. **洪九果品**
   - 洪九是水果供应链企业，不是只做香蕉一个单品，香蕉只是其品类之一。
   - 它的损耗表现更取决于具体产地、批次、包装、是否催熟、到货市场。
   - 不能简单说“洪九一定比都乐高”或“一定低”。同品牌不同批次都可能差很多。

3. **批发市场实际对比时，建议你看这几个指标**
   - 到货总件数 / 总重量
   - 验收合格重量
   - 压伤、黑斑、断把、落梳、过熟、发霉比例
   - 卸货后24小时和48小时损耗
   - 是否含催熟费、冷链费、扣重规则

4. **经验判断**
   - 同规格、同成熟度、同运输条件下：
     - 都乐香蕉通常稳定性更强，到货损耗往往更低或更可控。
     - 洪九若走的是高性价比统货或非全程冷链，损耗可能更高；若是其标准供应链渠道，差距会缩小。
   - 但若都乐到货偏熟，或洪九到货偏生且冷链好，结果可能反过来。

5. **最可靠的做法**
   - 不要问“品牌损耗率”，要问“这批货的损耗率”。
   - 让供应商提供：产地、加工日期、催熟日期、运输温度、箱规、净重、验收标准。
   - 你自己在同一市场、同一季节、同一卸货条件下各拿3批做对比，记录：
     - 到货损耗率 = 到货即损重量 ÷ 到货总重量
     - 24小时损耗率
     - 48小时损耗率
     - 可售率

如果你要的是“批发市场拿货选哪个更稳”，我的建议是：  
**要稳定、少扯皮、损耗可控，优先看都乐这类标准化渠道；要价格和灵活度，可以看洪九，但必须按批次验货，不能按品牌盲拿。**
