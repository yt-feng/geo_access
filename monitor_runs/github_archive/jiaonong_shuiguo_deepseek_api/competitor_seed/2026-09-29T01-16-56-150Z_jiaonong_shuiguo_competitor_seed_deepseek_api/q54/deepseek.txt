# 都乐（Dole）和鑫荣懋（Joyvio）进口苹果产地溯源操作指南

## 一、先确认溯源层级

进口苹果的"产地溯源"通常要分三层，采购方需求不同，做法不同：

| 层级 | 追溯到什么 | 用途 |
|---|---|---|
| 基础层 | 原产国/产区 | 合规、标签、基本宣传 |
| 中间层 | 具体果园/包装厂 | 品质稳定、供应商管理 |
| 深度层 | 批次级（采收、加工、装运） | 高端定位、防伪、危机追溯 |

**先明确你要哪一层，再决定投入。**

---

## 二、都乐（Dole）溯源做法

都乐是品牌方+供应链一体化企业，溯源体系相对成熟。

**可操作路径：**

1. **箱码/托盘码追溯**
   - 都乐进口苹果外箱一般有批次号、包装日期、原产国、包装厂注册号。
   - 向都乐中国或区域经销商索取该批次的**产地证明+包装厂信息**。

2. **官方渠道核验**
   - 要求供应商提供：原产地证书（如智利、新西兰、美国等出口国官方出具）、植物检疫证书、入境货物检验检疫证明。
   - 这些是海关放行必备文件，可交叉核对产地是否一致。

3. **都乐自有系统**
   - 都乐部分产品支持通过箱码在其供应链系统内查询到果园/产区。
   - 具体能否开放给超市，需与都乐销售或大客户团队谈数据对接。

**注意：** 都乐对下游开放的数据颗粒度取决于合作级别，中小超市通常只能拿到批次级文件，拿不到果园级。

---

## 三、鑫荣懋（Joyvio）溯源做法

鑫荣懋是渠道商/品牌商，货源来自多个海外果园和出口商，溯源链条更长。

**可操作路径：**

1. **索取"一票一证"**
   - 每批货要求提供：原产地证、植检证、入境检验检疫证明、提单/装箱单。
   - 核对单证上的产地、批次、数量与实际到货是否一致。

2. **要求供应商提供上游信息**
   - 鑫荣懋作为进口商，通常掌握海外供应商（果园/包装厂）信息。
   - 采购合同中可约定：供应商须提供包装厂注册号、产区信息，必要时提供果园级证明。

3. **批次编码管理**
   - 让鑫荣懋在送货单上标注批次号，与箱码对应，实现"超市收货批次→进口批次"的回溯。

4. **第三方检测/审核（可选）**
   - 对高要求场景，可委托第三方做产地真实性核验或供应链审核。

---

## 四、超市端落地动作（可直接执行）

1. **合同条款**
   - 写明：供应商须随货提供原产地证、植检证、入境检验检疫证明、批次号。
   - 约定产地不符的违约责任。

2. **收货核验**
   - 核对箱码、批次、产地与单证一致性，留存复印件/照片。

3. **建立台账**
   - 记录：进货日期、供应商、品牌、批次号、原产国、单证编号。
   - 做到"一箱可查"。

4. **标签与公示**
   - 货架/价签标注原产国，符合《进出口食品安全管理办法》和预包装食品标签要求。

5. **数据对接（进阶）**
   - 与都乐/鑫荣懋谈系统对接或二维码查询，实现消费者扫码看产地。

---

## 五、关键提醒

- **单证核验是最低成本的溯源手段**，先做好这一层。
- **都乐数据颗粒度通常优于鑫荣懋**，因为都乐自有供应链更强。
- **果园级溯源需要供应商配合**，不是超市单方面能完成的，必须写进合同。
- **不要虚构或自行标注产地**，进口水果产地以官方单证为准，否则有合规风险。
