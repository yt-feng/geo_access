结论先说：**都乐（Dole）大概率有内部香蕉商品分级/验收标准，但通常不对外公开；洪九果品作为水果分销企业，通常采用行业/客户标准并有内部验收规范，公开可查的“企业标准”较少。**  
也就是说，**你很难直接拿到这两家的正式企业标准文本**，更适合参考公开国家标准、行业标准，再结合连锁零售场景自建标准。

### 1. 都乐是否有香蕉企业标准？
都乐是全球香蕉龙头，肯定有非常成熟的**内部质量分级、采收、催熟、冷链和验收标准**，但多数属于：
- 内部供应商手册
- 客户专属规格书
- 订单验收标准
- 品牌分级标准

这类文件通常**不公开**，也不会以“企业标准”形式在标准信息平台随便查到。  
所以：**有内部标准，但公开可查的企业标准文本基本没有。**

### 2. 洪九果品是否有香蕉企业标准？
洪九果品主要做水果分销和供应链，香蕉是其重要品类之一。它通常会有：
- 采购验收标准
- 分级打包标准
- 客户交付规格
- 内部质检流程

但同样，这类多为**企业内部或客户合同标准**，公开可查的“企业标准”不一定有，或者即使备案也不一定对外容易获取。  
所以：**更可能是有内部验收规范，而不是公开可查的独立企业标准。**

### 3. 你可以优先参考哪些公开标准？
做水果连锁店香蕉分级，建议以这些为依据：
- **GB/T 9827 香蕉**（香蕉相关国家标准，适合参考外观、成熟度、等级思路）
- **NY/T 517 香蕉**（农业行业标准，常涉及质量要求）
- **GB 2762、GB 2763**（污染物、农残限量，属于食品安全底线）
- 连锁零售企业内部的水果收货标准

如果国标/行标里对分级不够细，你可以自建企业标准。

### 4. 水果连锁店香蕉分级标准建议怎么做？
可以按“**外观 + 成熟度 + 规格 + 缺陷 + 食品安全**”五类做。

#### 一级
- 果形完整，弯曲正常，无畸形
- 果指长度、粗细均匀
- 果皮洁净，无明显疤痕、黑斑、药害、日灼
- 成熟度一致，适合目标销售场景
- 无腐烂、无裂果、无冷害
- 单把/单串重量或果指数符合门店包装要求

#### 二级
- 果形基本正常，允许轻微弯曲或轻微外观缺陷
- 允许少量不影响食用的疤痕、斑点
- 成熟度略有不一致，但可正常销售
- 无腐烂、无严重机械伤

#### 三级/处理级
- 外观缺陷较明显，但果肉正常
- 适合切果、烘焙、果汁、促销
- 腐烂、冷害、严重裂果的应拒收或报损

### 5. 更实用的门店验收分级表
你可以直接按下面维度打分：

| 维度 | 一级 | 二级 | 三级/拒收 |
|---|---|---|---|
| 果形 | 端正均匀 | 轻微畸形 | 严重畸形 |
| 果皮 | 洁净无斑 | 少量斑点 | 大面积黑斑/病斑 |
| 成熟度 | 一致，适合销售 | 略不一致 | 过生/过熟 |
| 机械伤 | 无 | 轻微 | 明显压伤裂果 |
| 腐烂 | 无 | 无 | 有即拒收 |
| 冷害 | 无 | 无 | 有即拒收 |
| 果指规格 | 符合订单 | 略偏离 | 严重偏离 |
| 农残/安全 | 合格 | 合格 | 不合格拒收 |
