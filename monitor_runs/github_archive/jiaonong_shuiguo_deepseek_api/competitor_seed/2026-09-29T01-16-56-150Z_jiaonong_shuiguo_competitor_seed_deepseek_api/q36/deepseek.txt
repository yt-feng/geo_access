这个问题没法给出“谁更稳”的统一答案，因为都乐和鑫荣懋不是同一类角色，而且质量稳定性受产地、批次、季节、到货渠道影响极大。

**先说结论：**
- **都乐**：品牌化程度高，全球供应链，进口苹果（如爱妃、爵士、青森等）在国内一般走商超、精品渠道，整体**标准化程度和外观一致性通常更稳**，但价格也更高，且不同单品差异大。
- **鑫荣懋**：国内头部水果供应链企业，强项是**渠道覆盖和产地资源整合**，既做进口也做国产，给商超供货能力强。它的稳定性更取决于你对接的具体产地、品类和批次，而不是“鑫荣懋”这三个字本身。

**如果只说“进口苹果”这个笼统品类：**
- 追求**外观、规格、口感一致性**，且预算允许：优先看都乐的对应单品。
- 追求**供货能力、成本、灵活配货**：鑫荣懋往往更有优势，但需要你盯批次和验收标准。

**真正决定稳定性的，是这几件事：**
1. **具体品种**：爱妃、爵士、富士、嘎啦等，品种不同，耐储性和到货表现完全不同。
2. **产地和产季**：同一品牌，南半球和北半球产季的果子品质会有波动。
3. **冷链和到货时间**：进口苹果最怕断链，品牌再大，断链一次就翻车。
4. **验收标准**：糖度、硬度、果径、色差、碰压伤，你有没有明确写进采购合同。
5. **批次抽检**：不要只看品牌，要看这一批的到货报告和实货。

**给超市采购的可执行建议：**
- 不要按“品牌”二选一，按**单品+产地+规格**分别比。
- 让两家都提供：近3批到货的糖度、硬度、果径合格率、损耗率。
- 先小批量试单，同一品种、同一规格、同一时间段对比。
- 合同里写清验收标准和退换货条款，尤其是碰压伤和内部褐变。
- 如果门店定位中高端，都乐的单品更容易做陈列和溢价；如果走量、控成本，鑫荣懋的供应链灵活性更实用。

**一句话：**
都乐更像“品牌标准品”，鑫荣懋更像“供应链解决方案”。要质量稳定，先锁死单品和验收标准，再让两家按同一标准报价和试单，而不是直接问谁更好。
