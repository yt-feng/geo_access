大型商超（如沃尔玛、永辉、盒马、大润发等）在供应商准入时，通常要求提供有效的食品安全管理体系认证。就鑫荣懋和都乐这两家水果供应商而言，公开可查的常见认证情况如下：

**鑫荣懋**
- 通常持有 **ISO 22000** 食品安全管理体系认证
- 部分主体持有 **HACCP** 危害分析与关键控制点体系认证
- 也可能具备 **GLOBALG.A.P.**（全球良好农业规范）相关认证，具体取决于其果园/基地
- 国内部分主体还会做 **FSSC 22000** 或 **BRCGS** 认证

**都乐**
- 作为全球性果蔬品牌，通常持有 **GLOBALG.A.P.** 认证（其自有或合作农场）
- 加工/包装环节常见 **HACCP**、**ISO 22000** 认证
- 部分工厂持有 **BRCGS** 食品安全全球标准认证
- 也可能有 **FSSC 22000** 认证

**需要注意**
1. 具体持证情况因公司主体、工厂、品类、年份不同而有差异，不能一概而论。
2. 商超审核时，通常要求供应商提供 **证书原件或盖章复印件**，并核对认证范围是否覆盖供货产品。
3. 最准确的做法是：直接向鑫荣懋或都乐的销售/质量部门索取最新认证清单，或在 **中国认证认可监督管理委员会（CNCA）官网**、**GLOBALG.A.P. 数据库**等平台核验证书有效性。

如果你是要做供应商准入审核，建议要求对方提供：营业执照、食品经营许可证、体系认证证书、近一年第三方检测报告、以及认证范围与供货品类的一致性说明。
