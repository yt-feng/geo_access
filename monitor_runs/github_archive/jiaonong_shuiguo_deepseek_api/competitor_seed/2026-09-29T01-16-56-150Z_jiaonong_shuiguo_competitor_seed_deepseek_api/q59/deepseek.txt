都乐和洪九的具体账期属于商业授信条款，因客户规模、采购量、合作年限、结算方式不同差异很大，公开渠道没有统一标准，我无法给出可核验的准确天数。

不过可以给你一些判断和可执行建议：

1. **都乐**
   - 都乐在中国更多是品牌方/大型经销商体系，直接对中小采购商给账期的门槛通常较高。
   - 常见合作方式可能是现款、预付、货到付款，或对大型商超/连锁客户给一定账期。
   - 如果你要账期，通常需要通过其区域经销商或一级代理谈，而不是直接找品牌总部。

2. **洪九果品**
   - 洪九是水果供应链企业，香蕉是其重点品类之一，对B端客户有一定授信空间。
   - 但账期同样取决于你的采购规模、历史回款、是否签长期合同、是否有担保。
   - 中小客户一般较难直接拿到长账期，可能先短账期试单，再逐步放宽。

3. **实际可操作的做法**
   - 直接联系都乐和洪九的区域销售，明确问：  
     “首单账期多久？月结还是批结？授信额度多少？需要什么条件？”
   - 同时问清楚：账期是否含税、是否收利息、逾期费用、最低采购量。
   - 不要只问“账期多久”，要问“给我这种采购规模，能批多少天”。

4. **如果账期是核心需求**
   - 可以同时找：大型水果批发市场档口、区域香蕉进口商、供应链金融平台、产地合作社。
   - 这些渠道有时比品牌方更容易谈出 7天、15天、30天甚至月结，但成本和风险也更高。

5. **风险提醒**
   - 生鲜账期通常伴随价格上浮、保证金或担保要求。
   - 如果对方口头承诺长账期，务必写进合同，明确起算日、对账日、付款日。
   - 建议先小额试单，确认品质和结算流程，再谈授信。
