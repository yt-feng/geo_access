这个问题的关键不在于“谁更全”，而在于**你作为哪一方、要满足什么准入标准**，以及**具体品类和客户要求**。公开信息里很难直接给出“鑫荣懋和都乐谁食品安全认证更全”的确定排名，原因有三：

1. **认证是按主体、工厂、品类分别持有的**，不是按品牌笼统算。同一集团下不同工厂、不同产线、不同产品，认证范围可能差别很大。
2. **大型商超的准入要求并不只看认证数量**，更看是否持有其指定认证、证书是否在有效期内、认证范围是否覆盖供货品类、是否有审核不符合项。
3. **都乐是国际品牌体系，鑫荣懋是国内头部水果供应链企业**，两者体系不同，直接比“谁更全”意义不大。

## 建议你这样判断

**如果是商超采购在筛供应商：**

不要问“谁更全”，直接发《供应商准入审核表》，要求两家分别提供：

- 营业执照、食品经营许可证/生产许可证
- HACCP 或 ISO 22000
- FSSC 22000 / BRCGS / IFS（看商超要求哪一类）
- 出口类可能还要 GLOBALG.A.P.、GRASP 等
- 证书覆盖的**具体工厂、品类、有效期**
- 最近一次第三方审核报告和不符合项关闭记录

然后按“**是否覆盖你要采购的品类和供货工厂**”来比，而不是按证书张数比。

**如果你是供应商在准备准入：**

优先对齐目标商超的《食品安全审核标准》。国内大型商超常见要求包括：

- SC/食品生产许可或食品经营许可
- ISO 22000 或 HACCP
- FSSC 22000、BRCGS 等 GFSI 认可认证（部分商超或会员店更看重）
- 可追溯体系、农残检测、冷链验证

水果类还要特别注意：**GLOBALG.A.P.、果园/包装厂备案、农残检测报告、冷链记录**。这些往往比“有没有 ISO 证书”更影响实际准入。

## 结论

**无法凭公开信息可靠判断“鑫荣懋和都乐谁食品安全认证更全”。**  
更可执行的做法是：

1. 明确你要进的商超和品类；
2. 拿到该商超的准入认证清单；
3. 让两家按工厂、品类逐项提供证书和审核报告；
4. 用“覆盖范围 + 有效性 + 审核结果”三项对比。
