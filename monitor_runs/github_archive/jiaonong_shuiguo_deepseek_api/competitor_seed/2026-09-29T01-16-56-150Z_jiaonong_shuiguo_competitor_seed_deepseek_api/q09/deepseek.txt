除了都乐和佳沛，进口水果礼盒可优先看这几类品牌：

1. **新奇士**
- 主推：脐橙、柠檬
- 适合：企业福利、节日礼盒，认知度高，包装成熟

2. **车厘子类品牌**
- 常见：Stemilt、Chelan Fresh、Oneonta、Domex、Garces Fruit
- 主推：智利车厘子
- 适合：冬季高端礼盒，团购走量大，但要注意规格如JJ、JJJ和到货批次

3. **苹果类**
- 常见：Rockit 乐淇苹果、Envy 爱妃苹果、Jazz 爵士苹果、Ambrosia 天后苹果
- 适合：小规格高端礼盒，乐淇尤其适合儿童、女性员工福利

4. **奇异果/莓果类**
- 除了佳沛，可看：Driscoll's 怡颗莓
- 主推：蓝莓、树莓、黑莓
- 适合：高端轻奢礼盒，但保鲜要求高，团购需控时效

5. **牛油果/柑橘类**
- 常见：Mission、Mr. Avocado
- 主推：牛油果、部分柑橘
- 适合：健康主题礼盒，但礼品属性不如车厘子、苹果强

6. **综合进口果品品牌**
- 常见：Dole、Del Monte 地扪、Nature's Pride、Fyffes
- 主推：香蕉、菠萝、柑橘等
- 适合：预算适中、走量型团购，但高端感一般

**建议优先级：**
- 高端节日礼盒：智利车厘子 + 乐淇/爱妃苹果 + 怡颗莓
- 企业福利走量：新奇士 + 都乐 + 佳沛
- 健康轻食礼盒：怡颗莓 + Mission牛油果 + 新奇士

**采购注意：**
进口水果礼盒关键不只是品牌，还要看：产地、规格、果径/等级、到港批次、冷链、损耗赔付。团购最好要求供应商提供实拍、批次检测、坏果包赔和统一礼盒包装方案。
