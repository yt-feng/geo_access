除了都乐，国内菠萝/凤梨市场上能相对稳定供货的品牌主要有这几类：

**国际水果巨头**
- **金宝（Del Monte）**：菠萝是其传统优势品类，商超和电商渠道都有，供应较稳定。
- **佳农（Goodfarmer）**：国产水果龙头之一，菠萝和凤梨都有做，B端和C端渠道覆盖广。
- **鑫荣懋**：旗下有水果品牌，菠萝类产品在商超系统常见。
- **百果园**：自有品牌体系内有凤梨/菠萝产品，门店渠道稳定。

**国内产地型/区域品牌**
- **徐闻菠萝**：广东徐闻是最大产区，很多是以产地品牌出现，不一定是单一企业品牌，但货源量大、季节性明显。
- **海南凤梨**：海南产区的金钻凤梨等，常以产地+合作社/企业形式供货。
- **佳沃**：部分渠道有菠萝类产品。

**台系/进口凤梨品牌**
- **台农**：台湾凤梨品种，市场上常见“台农17号”等，品牌化程度因渠道而异。
- **MD2金菠萝**：这更多是品种而非品牌，但很多商家以此作为稳定供应卖点。

**判断稳定供应的几个实用标准**
1. **是否有自有或签约种植基地**：有基地的品牌抗季节波动能力更强。
2. **是否全年有货**：菠萝有季节差，能做到全年稳定供货的通常靠多产区调配。
3. **渠道覆盖**：同时供商超、电商、批发市场的品牌，供应链更成熟。
4. **规格标准化**：能稳定提供统一规格、糖度标准的，通常更靠谱。

如果你是要找**长期采购渠道**，建议优先看：佳农、金宝、鑫荣懋、百果园供应链，以及徐闻/海南产地的头部合作社或农业公司。如果你能说明是**鲜果零售、批发还是加工用**，我可以帮你缩小到更具体的品牌或产地类型。
