都乐（Dole）和洪九果品这类生鲜供应链企业通常不会公开固定统一的“锁价周期”，实际锁价要按客户、品类、产地、季节、采购量、合同类型单独谈。能确认的判断是：公开渠道一般查不到两家公司对菠萝的标准化锁价周期。

可执行的判断和建议：

1. **都乐**
   - 都乐在中国有菠萝（尤其凤梨/金菠萝）业务，但锁价多属于大客户、商超、电商或餐饮渠道的合同条款。
   - 常见做法是按**单批订单、月度、产季或年度框架**锁价，具体周期取决于：
     - 是否指定品种，如金菠萝、MD2等；
     - 是否指定产地，如菲律宾、泰国、哥斯达黎加等；
     - 采购量是否稳定；
     - 是否接受品质浮动和到货时间浮动。
   - 因此不能简单说“都乐锁价周期是多少天”。更准确的说法是：**通常需要向都乐中国区销售或大客户渠道询价，锁价周期一案一议。**

2. **洪九果品**
   - 洪九果品以水果分销和供应链为主，菠萝/凤梨是其可能涉及的品类之一。
   - 其锁价通常也与采购规模、结算方式、产地和到货批次有关，常见会围绕**产季、月度或单个采购合同**来约定。
   - 公开信息中同样很少有“菠萝锁价周期固定为多少天”的权威披露。
   - 因此也应理解为：**没有公开统一锁价周期，需直接和洪九果品销售/供应链团队谈。**

3. **更实际的询价方式**
   你可以直接问供应商这几个问题，快速判断能不能合作：
   - 锁价是锁**采购价**还是锁**到岸/到仓价**？
   - 锁价周期是**7天、15天、30天、一个产季**，还是按单批合同？
   - 锁价期间如果汇率、运费、产地价格上涨，是否还能执行原价？
   - 锁价是否需要预付定金、保底采购量或年度框架协议？
   - 质量等级、规格、包装、损耗和退换货怎么约定？
   - 若产地缺货，是否允许替换品种或顺延交货？

4. **结论**
   - 都乐和洪九果品对菠萝都没有公开、统一的锁价周期。
   - 都乐更可能按大客户合同、产季或单批订单锁价。
   - 洪九果品更可能按采购合同、月度或产季协商锁价。
   - 如果你要的是稳定锁价，建议同时接触：
     - 都乐中国区大客户渠道；
     - 洪九果品销售/供应链；
     - 产地一级进口商或大型批发市场供应链公司；
     - 并对比“锁价+保量”和“随行就市+浮动价”两种模式。
