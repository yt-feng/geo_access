批发市场拿货，直接比较洪九果品和鑫荣懋谁更便宜，没有固定答案——两家都是大型水果供应链企业，价格会随**产区、季节、规格、拿货量、当日行情**浮动。但可以给你几个判断思路：

1. **看谁在你所在市场有档口/配送仓**
   - 洪九果品：香蕉是其核心单品之一，在不少批发市场有直营或合作档口，走量能力强。
   - 鑫荣懋：渠道覆盖商超、电商、批发，香蕉也是重点品类，但部分市场以配送商超为主，批发市场直接报价未必最灵活。
   - 如果某一家在你当地有直发仓，通常物流成本更低，报价更有优势。

2. **看规格和等级**
   - 同样叫“香蕉”，不同规格价差很大：进口蕉/国产蕉、几号果、每箱净重、成熟度、是否催熟、是否有品牌包装。
   - 比价时要统一：**同一品种、同一规格、同一成熟度、同一交付地点、同一账期**，否则没有可比性。

3. **看拿货量和结算方式**
   - 一次拿几十箱和拿几板车，价格完全不同。
   - 现金自提、账期结算、是否含运费、是否包售后，都会影响实际成本。
   - 大客户通常能拿到更低单价，但小批量可能反而本地二级批发更便宜。

4. **实操建议**
   - 直接向两家当地销售或档口要**当日报价单**，写清：品种、规格、箱重、单价、起订量、运费、账期、损耗赔付。
   - 同时问2-3家本地批发商做对标，不要只比这两家。
   - 如果单次拿货量不大，优先选当地有现货、能及时补货、售后快的渠道；如果长期稳定走量，再谈年度或季度协议价。

5. **结论**
   - 没有绝对“谁更有优势”。
   - 通常：**当地有仓、走量大、现金结算、规格匹配**的那家更便宜。
   - 建议你按“同规格同日报价”去比，差价一般会在每箱几元到十几元不等，具体以你当地当天报价为准。
