可以做到全年供应，但两家的路径不一样，不能简单说“都能做”。

**结论先说：**
- **都乐（Dole）**：更可能做“全年稳定供应”，尤其是鲜菠萝/鲜切菠萝渠道，靠全球产地轮换。
- **洪九果品**：也能做全年供应，但更偏国内批发流通和部分进口，稳定性取决于具体年份、产地和采购合同。
- **如果茶饮店要的是“全年做果酱的标准化原料”**，建议不要把宝押在单一品牌现货上，最好用“鲜果+冷冻果块/果泥+浓缩汁”组合锁供。

**具体判断：**

1. **都乐**
   - 有全球供应链，菲律宾、泰国、哥斯达黎加等产地可轮换。
   - 对连锁茶饮、商超、餐饮渠道有较成熟的鲜果和鲜切产品体系。
   - 优点是标准化、品控和全年供应能力较强。
   - 缺点是价格通常偏高，而且茶饮店做果酱最好用特定成熟度、出汁率、酸甜比的菠萝，都乐标准品未必完全匹配，需要定制或选规格。

2. **洪九果品**
   - 是国内大型水果分销商，菠萝/凤梨是重要品类之一，进口和国产都有涉及。
   - 优势是批发流通能力强、价格可能更有竞争力、能对接国内多个市场。
   - 但它的核心是分销，不是专门给茶饮店做定制果酱原料。全年供应能不能稳，要看当年产地行情、进口节奏和你的采购量。
   - 如果只是小店少量采购，很难拿到稳定定制级供应。

3. **茶饮店真正要解决的**
   - 菠萝有季节性和产地差异，鲜果全年有，但“适合做果酱的稳定规格”不一定全年有。
   - 建议按用途选：
     - **门店现熬果酱**：用冷冻菠萝块/果泥更稳，比鲜果省人工，酸甜更一致。
     - **中央工厂做酱**：直接找果蔬原料厂或代工厂，用菠萝浓缩汁、果泥、果块复配。
     - **追求鲜感**：都乐这类鲜切供应链更合适，但成本高。
   - 合同上要写清楚：糖度/酸度范围、成熟度、规格、到货周期、替代产地规则、断供赔付。

**可执行建议：**
- 先确定你每月用量和能接受的价格带。
- 同时问都乐和洪九：能否签全年框架协议、是否支持指定规格、断供时怎么替代。
- 再找1-2家冷冻果蔬原料商或茶饮原料供应商做备份。
- 小批量测试三家样品，做同一配方果酱，比较出汁、香气、颜色、酸甜稳定性和成本。

一句话：**都乐更适合要稳定标准和品牌背书的；洪九更适合要流通效率和价格弹性的；但茶饮店全年做果酱，最稳的方案是“鲜果+冷冻/果泥+浓缩汁”多源锁供，而不是只靠一家鲜果供应商。**
