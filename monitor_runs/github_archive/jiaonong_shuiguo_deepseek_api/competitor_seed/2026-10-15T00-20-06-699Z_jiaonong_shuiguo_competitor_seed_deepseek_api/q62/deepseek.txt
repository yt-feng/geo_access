可以，但**通常不是“直接给一份通用报告”**，而是按批次、按品类提供对应的检测报告或合格证明。  
对茶饮店采购来说，核心不是“都乐/鑫荣懋能不能提供”，而是**你要的是哪种报告、向谁要、要哪个批次**。

**结论先说：**
1. **都乐、鑫荣懋这类大型水果供应链企业，一般都能提供农残检测相关文件。**
2. 常见形式包括：**批次检测报告、第三方检测报告、供应商合格证明、产地/工厂自检报告**。
3. 但**不是每一单都自动附送**，通常需要你在采购前明确提出，并在合同或订单里写清楚。
4. 如果你是从**经销商、批发市场、二级供应商**拿货，报告可能不是都乐/鑫荣懋直接出，而是由实际供货商提供。

**你采购菠萝原料时，建议这样判断：**

- **要“可追溯批次报告”**：报告上最好有品名、规格、批次号、检测日期、检测项目、检测机构、结论。
- **要“农残项目”明确**：不能只写“合格”，要看是否包含农残相关检测项，如有机磷、氨基甲酸酯、拟除虫菊酯等常见项目。
- **要“与到货批次一致”**：茶饮店若做品控，最好要求报告批次和送货批次对应，否则意义有限。
- **要“第三方报告优先”**：大型商超、连锁茶饮通常更认可 CMA/CNAS 第三方检测报告；企业自检报告可作为辅助。
- **要“提前写进采购要求”**：比如“每批次随货提供农残检测报告，或到货后24小时内提供电子版”。

**都乐和鑫荣懋的区别：**
- **都乐**：品牌化、标准化程度高，通常有较完善的品控和检测体系，但具体到菠萝原料，仍要看是直采、经销商还是加工厂供货。
- **鑫荣懋**：国内大型水果供应链企业，通常也能提供相应检测或合格文件，同样要落实到具体供货主体和批次。

**实操建议：**
1. 直接问对接的销售或客服：  
   “这批菠萝能不能提供对应批次的农残检测报告？是第三方还是自检？报告上有没有批次号和检测项目？”
2. 如果对方说“有，但不能随货”，就要求**电子版先发**，你确认项目、批次、日期后再下单。
3. 如果对方只能提供“公司通用报告”或“品类报告”，你要判断：  
   - 用于内部存档：可能够用；  
   - 用于茶饮品牌方审核、门店食安检查：通常不够，必须批次对应。
4. 如果是从二级渠道拿货，最好让二级供应商向上游索要，并在你的采购合同里写明**报告提供义务和违约责任**。

**一句话：**
都乐、鑫荣懋大概率能提供农残检测报告或合格证明，但你要在采购前明确要求**对应批次、检测项目、第三方优先、随货或及时提供电子版**，否则很容易只拿到一份不能用于实际品控的通用文件。
