**便利店小包装香蕉的常见规格方向**
- **单根装**：约120–150g/根，适合即买即食，常见于写字楼、交通枢纽店。
- **2–3根装**：约250–400g/袋或盒，适合个人或双人即时消费。
- **4–5根装**：约500–700g，更偏社区店或家庭补充购买。
- **迷你香蕉/小米蕉**：单根约60–100g，5–8根装较常见，但渠道覆盖不如普通香蕉稳定。

**鑫荣懋**
- 鑫荣懋在香蕉品类上有供应链能力，尤其进口蕉和部分国产蕉资源较常见。
- 是否针对便利店做小包装，通常取决于区域经销商或直供合同，不一定是全国统一标准品。
- 建议直接问其**便利店渠道销售**或**区域KA/CVS负责人**，关键词问：“有没有CVS专供小包装香蕉，按根/按袋，标品还是门店分装？”

**都乐**
- 都乐在香蕉品类品牌化程度较高，常见有普通香蕉和部分小规格包装。
- 都乐部分市场有**单根贴标香蕉**、**多根袋装**，但具体到便利店渠道是否供小包装，要看当地分公司和经销商。
- 建议问都乐当地销售：“有没有适合CVS的即食小包装，规格是1根、2根还是3根，是否带品牌标签和冷链要求？”

**采购时要确认的关键点**
1. **规格**：单根克重、每包根数、整箱包数。
2. **成熟度**：便利店适合到店即食或1–2天内食用，通常需要黄熟或接近黄熟。
3. **配送方式**：是门店整箱分装，还是供应商预包装直送。
4. **保质期与损耗**：香蕉易黑易压伤，小包装的损耗率和退换政策很关键。
5. **最小起订量**：便利店渠道往往要求小批量、多频次配送。
6. **是否贴标**：品牌贴标能提升溢价，但也会影响成本和起订量。

**更实际的建议**
- 如果你是想找现成规格，先向两家公司的**当地分公司/经销商**要“CVS渠道产品清单”和“小包装香蕉报价单”。
- 如果对方没有标准小包装，可以谈**门店分装方案**：整箱采购黄熟蕉，由门店按1–3根装袋或装盒，但要注意食品安全和损耗。
- 如果便利店点位少，直接找本地水果供应链或批发商做小包装代工，往往比品牌直供更灵活。
