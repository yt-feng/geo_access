进口香蕉这块，先纠正一个常见误区：**佳沛（Zespri）主业就是奇异果，香蕉不是它的核心品类**，所以你觉得它香蕉业务弱是正常的，不用在佳沛身上找香蕉。

进口香蕉品牌，按你“做水果生意、要找稳定货源”的场景，主要分两类：

**一、国际大牌（品牌化程度高，适合做商超/精品渠道）**
- **都乐（Dole）**：全球香蕉巨头之一，菲律宾、厄瓜多尔等产地，供应链成熟，国内铺货广，做商超和电商都比较认。
- **金吉达（Chiquita）**：老牌香蕉巨头，品牌认知度高，但国内渠道没有都乐那么普及，看你能不能拿到稳定货。
- **德尔蒙（Del Monte）**：也是国际果蔬巨头，香蕉有份额，但国内更多见于加工/特定渠道，鲜果香蕉不如都乐常见。

**二、区域/产地品牌（性价比路线，适合批发、社区渠道）**
- **菲律宾香蕉**：国内进口香蕉主力，很多是都乐、金吉达等在当地代工或自有农场，也有大量非品牌货。
- **厄瓜多尔香蕉**：品质稳定，适合做中高端。
- **越南、柬埔寨香蕉**：近年增长快，价格有优势，适合走量。

**给你的实操建议：**
1. 如果你要的是“品牌背书+稳定供货”，优先谈 **都乐**，它是目前国内进口香蕉里渠道最顺、认知最广的。
2. 如果你要的是“利润空间”，别只盯品牌，直接找 **菲律宾/厄瓜多尔产地的一级进口商或口岸批发商**，很多货没有强品牌但品质不差。
3. 香蕉和奇异果渠道逻辑不同：奇异果靠品牌溢价，香蕉更多靠 **周转速度+损耗控制**，选品牌不如选稳定到货和成熟度可控的供应商。
