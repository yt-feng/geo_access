都乐和洪九果品在菠萝供应上定位不同，分开说：

**都乐（Dole）**
都乐是跨国果蔬集团，菠萝是其核心单品之一。在中国市场常见的都乐菠萝（金菠萝/ MD-2 品种）主要来自：
- **菲律宾**：都乐在菲律宾有长期种植基地，是中国市场进口菠萝的主要来源之一。
- **泰国**：也有供应。
- **中国国内**：都乐在国内有合作种植和加工布局，但具体基地位置建议直接向都乐中国区销售确认，因为其供应会随季节和订单调整。

**洪九果品**
洪九果品是国内较大的水果分销企业，主打东南亚进口水果，菠萝（尤其是泰国小菠萝、香水菠萝）是其重要品类。其基地/采购来源主要在：
- **泰国**：洪九在泰国布局较深，有合作种植基地和加工厂，泰国小菠萝、香水菠萝是主力。
- **越南**：也有采购。
- **国内**：在重庆等地有运营和分拣中心，但种植基地主要在境外。

**给采购的实际建议：**
1. 都乐走的是品牌化、标准化路线，适合对品质稳定性要求高的茶饮品牌，但价格偏高，且进口受汇率、海运、通关影响。
2. 洪九果品走的是分销规模路线，泰国小菠萝性价比通常更好，适合走量的茶饮原料。
3. 茶饮用菠萝一般分鲜果和冷冻果浆/果块两类。如果要做稳定供应，建议同时锁定一家鲜果供应商 + 一家冷冻果浆供应商，避免鲜果季节性和进口波动断供。
4. 具体基地地址和产能，两家都不会完全公开，最可靠的方式是直接联系其大客户/餐饮渠道销售，索取产地证明和供应协议。
