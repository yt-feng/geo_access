都乐和鑫荣懋都没有对外公开、按“茶饮原料采购口径”统计的到货损耗率，所以我无法给出一个可核验的具体百分比。任何直接说“都乐X%、鑫荣懋Y%”的数字，基本都来自个别采购方经验或供应商口头报价，不能当作稳定规格依据。

如果你要的是**可判断、可落地的答案**，建议这样看：

1. **损耗率不是一个固定值**
   会随以下因素大幅波动：
   - 季节：夏果/冬果差异明显
   - 产地：菲律宾、泰国、哥斯达黎加等不同
   - 规格：整果、去皮整果、块/丁、冷冻果
   - 运输方式：常温、冷链、到货距离
   - 验收标准：是否算黑心、裂口、压伤、糖度不足、大小不合规

2. **茶饮场景要分“到货损耗”和“加工损耗”**
   - 到货损耗：收货时不合格、烂果、压伤、黑心、规格不符
   - 加工损耗：去皮、去眼、切丁、修整后实际可用率
   茶饮店真正该盯的是：**每公斤到货能出多少可用果肉/果块**，而不是只看到货坏果率。

3. **行业经验区间（只能做谈判参考，不是官方数据）**
   以鲜菠萝整果、冷链到货、茶饮加工口径粗估：
   - 管理较好的品牌供应链：到货明显损耗常见在 **3%–8%**
   - 普通批发/常温运输：可能到 **8%–15%**
   - 夏季、远距离、验收松：超过 **15%** 也不罕见
   如果是已去皮真空或冷冻果丁，到货损耗通常更低，但加工损耗和出水率要另算。

4. **你要稳定规格，应该直接向供应商要这些数据**
   让都乐和鑫荣懋分别提供：
   - 近3个月同一单品的到货批次损耗统计
   - 验收标准：大小、糖度、黑心、压伤、裂口如何判定
   - 赔付规则：损耗超过多少可扣款/补货
   - 可用果肉出成率，而不是只报整果价格
   - 是否支持固定规格：单果重、直径、成熟度、切片/切丁尺寸

5. **最实用的判断方法**
   不要先问“你们损耗率多少”，而要小批量试单：
   - 同一规格各进3批
   - 每批抽检至少30–50公斤
   - 记录：到货不合格重量、去皮后可用重量、黑心率、糖度、出汁率
   - 连续3批稳定后再锁价锁量
