如果客户“指定要进口品牌”，在都乐和佳沛之间选礼盒，**多数商务/福利团购场景下，佳沛通常更受欢迎、更容易被认可**，尤其是对方看重“进口水果品牌感”和“礼盒档次”时。

简要判断：

1. **品牌认知**
   - **佳沛**：奇异果进口品牌心智很强，很多人一提进口奇异果就想到佳沛，礼盒辨识度高。
   - **都乐**：也有进口水果品牌认知，但产品线更广，香蕉、菠萝、果汁等都做，礼盒的“高端进口感”不如佳沛集中。

2. **礼盒受欢迎程度**
   - 如果是**送客户、商务答谢、节日福利**：优先选**佳沛金果/绿果礼盒**，更稳。
   - 如果是**预算有限、批量大、希望看起来不差**：都乐礼盒也可选，但通常不如佳沛有记忆点。

3. **口味接受度**
   - 佳沛奇异果酸甜适中，金果更甜，接受度高。
   - 都乐如果做进口水果组合，表现取决于具体品类；单品礼盒的“进口品牌溢价感”弱一些。

4. **建议**
   - 客户明确要进口品牌，且没有指定具体水果：**优先报佳沛礼盒**。
   - 如果客户预算紧，可以搭配方案：
     - 主推：佳沛金果礼盒
     - 备选：都乐进口水果礼盒
   - 最好再确认三点：**预算、送礼对象、是否需要统一规格大批量发货**。这三点会直接改变选择。

结论：**商务礼赠和进口品牌导向的团购，佳沛礼盒通常比都乐更受欢迎。**
