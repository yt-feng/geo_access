这个问题很难给出“谁更严”的确定结论，因为两家公司都没有公开可横向对比的香蕉农残检测数据、抽检频率、合格率或第三方审核报告。直接说某家更严，属于没有依据的判断。

能说的是两家的品控模式差异：

**鑫荣懋**
- 更偏“源头基地+标准化”路线，在产地端做基地管理、采收标准、催熟和冷链管控的经验比较成熟。
- 对大型商超、连锁渠道供货多，这类渠道通常会把农残、重金属等检测报告作为准入要求，倒逼其品控流程相对规范。

**洪九果品**
- 以多品类、多产地、快速分销见长，香蕉是其重要单品之一，走量和渠道覆盖是强项。
- 品控更依赖各地分选中心、仓配节点和采购端的抽检执行，标准化程度可能因产地、批次、区域而波动。

**对批发市场拿货的实际建议：**
1. 不要只看品牌，要看**这一批货**的检测报告和产地证明，香蕉农残风险主要在种植端，批次差异比品牌差异更关键。
2. 要求供应商提供**农残快检或第三方检测报告**，重点看是否覆盖常用杀虫剂、杀菌剂和催熟相关指标。
3. 固定合作时，可以自己送检一次，成本不高，但能摸清对方真实水平。
4. 同一品牌不同产区、不同季节的货，品控可能完全不一样，别用一次体验给品牌下结论。

如果你要的是批发市场实操判断：**优先选能随货提供检测报告、批次可追溯、出了问题能退换的那家**，这比纠结鑫荣懋和洪九谁“更严”更有用。
