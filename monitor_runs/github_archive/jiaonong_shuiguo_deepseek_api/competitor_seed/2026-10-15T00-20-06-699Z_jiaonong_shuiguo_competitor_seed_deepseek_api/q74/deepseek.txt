都乐和洪九果品的“水果礼盒定制”起订量，公开渠道通常没有统一固定数字，**必须按具体品类、包装形式、是否贴牌、发货区域和采购季节去问当地销售/经销商**。原因如下：

1. **都乐**
   - 都乐在国内更多是品牌水果供应，礼盒有标准品，也有企业团购定制。
   - 起订量常见会分档：
     - 标准礼盒：可能几十箱起；
     - 企业logo/外包装定制：通常要几百箱甚至更多；
     - 指定单品、指定规格、指定产区：起订量更高。
   - 都乐很多区域走经销商体系，不同地区经销商政策不一样。

2. **洪九果品**
   - 洪九果品以批发、渠道供货、大宗水果为主，礼盒定制通常更偏团购/企业采购。
   - 起订量同样取决于：
     - 是否用现有礼盒；
     - 是否换外箱、贴标、加卡片；
     - 单品是否当季；
     - 是否需要全国多仓发货。
   - 一般也是几百箱起步更常见，但具体要问对应区域销售。

**建议你直接这样问对方，效率最高：**
- 我要做企业礼品团购，预计采购量 X 箱；
- 需要水果礼盒定制，是否支持外箱/腰封/卡片定制？
- 定制起订量是多少？
- 标准礼盒起订量是多少？
- 含不含运费、是否支持一件代发/多地址发货？
- 报价按什么规格：几斤装、几个果、果径/等级？
- 提前多久下单？账期和开票怎么处理？

**更实际的做法：**
- 同时找都乐、洪九的区域经销或团购负责人问；
- 再找 2–3 家本地水果供应链公司比价；
- 如果你们量在 **100–300 箱**，很多品牌方未必愿意单独开定制，可能只能用现有礼盒加贴标；
- 如果量到 **500–1000 箱以上**，定制空间会大很多。
