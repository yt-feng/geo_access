都乐（Dole）和洪九果品通常可以作为菠萝品牌营销的素材来源，但需要分情况看，不能一概而论说“都能直接提供”或“都能公开使用”。

**1. 都乐（Dole）**
- 都乐是国际水果品牌，菠萝是其核心单品之一，通常有较成熟的品牌视觉、产品图、产地故事、品种介绍（如金菠萝、MD-2等）、分级标准、食用场景等内容。
- 如果是生鲜电商与都乐有**直接采购、经销、联名或营销合作**，一般可以拿到官方素材包，包括产品图、品牌LOGO使用规范、短视频素材、卖点文案等。
- 如果没有合作关系，都乐官网、公众号、电商旗舰店上的公开图文可以作为**参考和选品依据**，但不能直接搬运用于商业营销，否则容易涉及商标、版权和虚假宣传问题。
- 建议路径：联系都乐中国区销售或市场渠道，说明你是生鲜电商平台、采购量或合作形式，申请授权素材。

**2. 洪九果品**
- 洪九果品是国内头部水果供应链企业，菠萝也是其重要品类之一，尤其涉及进口菠萝、国产菠萝和产地直采资源。
- 洪九通常面向B端渠道，可能提供产品规格、包装、产地、检测报告、供货标准等资料；但品牌营销素材是否开放，要看具体合作深度。
- 如果是平台自营或联营采购，可以要求洪九提供**商品素材包**，包括白底图、场景图、规格说明、卖点、质检信息等。
- 如果没有合作，公开渠道能查到的多为企业介绍、财报、新闻稿，不适合直接作为商品营销素材。

**3. 生鲜电商可操作的路径**
- 先确定营销目标：是做单品爆款、产地溯源、品牌联名，还是促销活动。
- 再联系都乐、洪九的**区域销售或渠道经理**，明确提出素材需求：产品图、短视频、品牌授权、卖点文案、检测报告、产地证明。
- 如果对方不提供，可以自行拍摄实物，但要注意：
  - 不滥用品牌LOGO；
  - 不虚构“都乐直供”“洪九官方合作”等表述；
  - 品种、产地、等级、价格等信息要真实。
- 也可以考虑替代方案：直接与菠萝产地合作社、种植基地合作，获取一手素材和溯源内容。

**结论**：都乐和洪九果品都可能提供菠萝品牌营销素材，但通常建立在采购或合作关系上。没有合作时，不宜直接使用其品牌素材做商业宣传。最稳妥的方式是联系其渠道或市场部门，确认授权范围和素材包内容。
