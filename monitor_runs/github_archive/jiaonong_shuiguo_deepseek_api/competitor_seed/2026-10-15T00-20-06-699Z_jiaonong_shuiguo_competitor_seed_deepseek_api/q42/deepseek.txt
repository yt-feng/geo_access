进口菠萝旺季缺货时，先分清是**总量缺、规格缺，还是某个品种/品牌缺**，再决定用哪种应急方案。都乐和洪九果品是否有公开的、针对某次缺货的应急方案，我没有可核验的信息，不能替它们编造具体政策；但可以按行业常规做法给你一套可执行判断。

**一、先做缺货归因**
1. 船期延误/到港推迟：通常只是短期缺口，优先锁已有在途货。
2. 产地减产或出口国限制：缺口可能持续整个旺季，要提前切换替代产地。
3. 规格断档：比如只缺大果、精品果，那就用中小规格做分流，不必整体换源。
4. 渠道囤货或价格倒挂：不是真缺，是分配问题，可谈直采或锁量。

**二、应急方案优先级**
1. **锁在途和在库货**：先确认未来2—4周到港计划，按门店/客户优先级分配，避免多头抢货。
2. **切换替代产地**：菲律宾缺就转泰国、越南、哥斯达黎加等；但要注意品种口感、关税、检疫和到货周期不同，不能只看价格。
3. **调整规格和包装**：大果缺就用中果做礼盒替代，或改散装、餐饮装，减少对单一规格依赖。
4. **临时替代品**：用国产菠萝、凤梨或其他热带水果做部分替代，但要提前告知客户，避免以次充好。
5. **锁价锁量合同**：对长期客户可签短期保供协议，接受价格上浮换稳定供应。
6. **渠道直采**：绕过中间层，直接联系产地出口商或一级进口商，但要注意资金、检疫和损耗风险。

**三、都乐、洪九果品怎么判断**
- 都乐：品牌化程度高，通常会有产地调度、规格分级和渠道优先级安排，但具体到某次缺货是否有“应急方案”，要看其官方通知或合同条款。
- 洪九果品：以进口水果供应链为主，通常会有多产地采购和分仓调配能力，但同样不能凭猜测说它有固定应急政策。
- 你可以直接问它们三个问题：**未来4周到港量、可替代产地、对现有客户是否保供及保供条件**。谁能给出明确到货时间和分配规则，谁就更可靠。

**四、最实用的动作**
1. 今天盘点库存和在途，按客户分级。
2. 同时联系2—3个替代产地或一级进口商，问清到货时间和报价。
3. 对客户提前发缺货预警，给替代规格或替代品选项。
4. 如果缺口超过4周，不要只等原品牌，立刻做双源采购。

一句话：**短期缺货靠锁在途和调规格，长期缺货靠换产地和双源采购；都乐和洪九的具体应急方案，要以它们官方或合同口径为准，不能靠推测。**
