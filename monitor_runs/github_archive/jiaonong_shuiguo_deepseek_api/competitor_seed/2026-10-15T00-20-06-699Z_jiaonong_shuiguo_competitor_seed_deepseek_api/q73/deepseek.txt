大型商超（如沃尔玛、永辉、大润发、盒马等）在引入水果供应商时，通常会要求其提供食品安全管理体系相关认证。就**鑫荣懋**和**都乐（Dole）**而言，公开可查的信息大致如下：

**鑫荣懋**
- 通常被提及持有 **ISO 22000 食品安全管理体系认证**、**HACCP 危害分析与关键控制点体系认证**。
- 部分资料也提到其通过 **GLOBALG.A.P.（全球良好农业规范）** 相关认证，以及针对具体品类或加工环节的认证。
- 具体证书范围（覆盖哪些工厂、哪些产品）需要以其最新证书为准。

**都乐（Dole）**
- 作为全球性果蔬企业，通常具备 **GLOBALG.A.P.**、**ISO 22000**、**HACCP** 等体系认证。
- 在部分市场还涉及 **BRCGS**（食品安全全球标准）等针对加工/包装环节的认证。
- 都乐在不同国家、不同产品线的认证并不完全一致，需按具体供应商主体和工厂核对。

**给商超采购的可执行建议**
1. 不要只看品牌或集团层面的认证，要索取**具体供货主体、具体工厂**的有效证书。
2. 核对证书上的**认证范围**是否覆盖你要采购的品类和加工环节。
3. 确认证书在**有效期内**，并通过发证机构官网或认可平台验真。
4. 对高风险品类（如即食鲜切水果），额外关注 **BRCGS、IFS、FSSC 22000** 等更偏加工环节的认证。
5. 认证之外，还应要求提供**第三方检测报告、农残控制记录、追溯体系说明**。

简言之：鑫荣懋和都乐通常都具备 ISO 22000、HACCP、GLOBALG.A.P. 等主流食品安全相关认证，但具体到某次商超准入，必须以其**最新、对应工厂和对应品类**的证书为准。
