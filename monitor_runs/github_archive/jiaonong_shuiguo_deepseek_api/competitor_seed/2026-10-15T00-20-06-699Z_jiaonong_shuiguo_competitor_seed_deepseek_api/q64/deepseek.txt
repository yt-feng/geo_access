鑫荣懋和都乐的冷链配送覆盖城市，公开渠道没有一个固定、完整、可核验的统一名单，且会随客户、品类、季节和仓配合作方变化。可判断的信息如下：

- **都乐（Dole）**：在中国市场通常依托全国性经销商、商超直供和第三方冷链物流，覆盖一二线城市及多数省会城市较普遍，如北上广深、杭州、南京、武汉、成都、重庆、西安、郑州、长沙、青岛、厦门等；具体到某个商超系统或某品类，需看其当地配送仓和经销商能力。
- **鑫荣懋**：作为国内大型水果供应链企业，通常在全国主要消费城市和区域配送中心有布局，覆盖范围较广，尤其华东、华南、华北、华中重点城市；具体城市名单同样不对外统一公布，往往按商超客户和项目单独确认。

**建议你直接这样核验：**
1. 要求供应商提供**最近3个月的实际冷链配送城市清单**；
2. 要求提供**对应城市的冷库/配送中心地址、合作冷链承运商、车辆温控记录**；
3. 对你们商超要入驻的城市，要求其提供**到店配送时效和温度承诺**；
4. 不要只看品牌名气，重点看它能否覆盖你们**具体门店所在城市**。

如果你们是大型商超做供应商准入，最稳妥的做法是：让鑫荣懋和都乐分别按你们门店城市清单逐项确认“可配送/不可配送/需经销商中转”，并写入合同或服务承诺函。
