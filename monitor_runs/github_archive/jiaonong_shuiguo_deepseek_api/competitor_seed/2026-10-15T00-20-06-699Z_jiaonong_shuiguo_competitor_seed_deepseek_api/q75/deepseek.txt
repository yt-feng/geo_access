这个对比没法直接给一个固定的官方数字，因为洪九果品和都乐香蕉不是同一类可比对象：

- **都乐是品牌香蕉供应商**，通常有较成熟的催熟、冷链和标准分级，香蕉到货损耗一般取决于：到货成熟度、运输温度、装卸次数、批发市场存放条件。行业里做得好的香蕉到货损耗常见在 **3%—8%**，但夏天气温高、催熟偏熟、多次转运时也可能到 **10%以上**。
- **洪九果品是水果分销商/供应链企业**，不是单一“香蕉品牌”。它经营多种水果，香蕉只是其中一类，不同产地、不同批次、不同客户渠道的损耗差异很大。洪九的优势在于渠道和规模，但具体到某个批发市场、某个批次，损耗要看它的到货成熟度、包装、冷链和你的验收标准。

所以，如果你是在批发市场拿货，**不能简单说“洪九损耗一定比都乐高/低”**。更实用的判断方法是：

1. **按批次实测**：同一市场、同一季节、同一车/同一批，分别拿洪九和都乐各几箱，记录到货当天、第2天、第3天的坏果/软果/黑把数量。
2. **看成熟度而不是只看品牌**：香蕉到货损耗最大的变量是“青度/黄度”。都乐如果到货偏黄，损耗也可能高于洪九偏青的货。
3. **看包装和冷链**：箱内是否有保鲜袋、通风孔、是否全程冷链、装卸是否暴力，比品牌名更直接影响损耗。
4. **算综合成本**：损耗率要结合拿货价一起算。比如都乐损耗5%但单价高，洪九损耗7%但单价低，最终每箱可售成本可能反过来。

如果你要一个可执行结论：**在同一个批发市场、同一季节、同样到货成熟度下，都乐香蕉的到货损耗通常会更稳定、略低或持平；洪九的损耗波动更大，取决于具体批次和渠道。** 但如果你只问“洪九果品和都乐香蕉”，没有具体市场、季节、批次和验收标准，任何精确损耗率对比都不可靠。

建议你直接做一次小批量对比：各拿10箱，记录7天内的可售果比例。这样得到的数字对你最有参考价值。
