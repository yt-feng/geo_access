除了都乐，市面上比较常见、能相对稳定供货的菠萝品牌主要有这几类，你可以按渠道和用途来选：

**1. 佳农（Goodfarmer）**
- 国内菠萝供应链里比较强的品牌，商超、生鲜电商、批发渠道都常见。
- 主打菲律宾菠萝、国产菠萝都有，稳定性较好，尤其适合商超和电商走量。

**2. 鑫荣懋 / 欢乐果园**
- 鑫荣懋是大型水果供应链企业，欢乐果园是其旗下品牌之一。
- 在沃尔玛、山姆、盒马等渠道常见，菠萝供应相对稳定，品质分级也比较清楚。

**3. 百果园（旗下供应链品牌）**
- 百果园门店体系内会有稳定菠萝供应，部分产品也会做自有品牌或合作基地直采。
- 如果你看重门店零售端的稳定性，可以关注百果园渠道。

**4. 鲜丰水果**
- 类似百果园，属于连锁水果零售体系，有稳定的采购和分选能力。
- 部分门店会销售自有品牌或合作基地的菠萝。

**5. 洪九果品**
- 主打进口水果供应链，菲律宾菠萝、泰国菠萝等进口品类做得比较多。
- 适合批发、商超、电商供货渠道。

**6. 优果联 / 其他区域供应链品牌**
- 一些区域性水果供应链公司也会做菠萝，尤其在广东、海南、福建等产地周边。
- 这类品牌在本地批发市场稳定性不错，但全国知名度不如前面几个。

**7. 国产菠萝产地品牌 / 合作社**
- 广东徐闻、海南、福建漳州等产地有不少合作社和产地直供品牌。
- 如果是做区域生意或产地直采，徐闻菠萝的供应链稳定性这几年提升明显。

**简单判断建议：**
- 走商超、电商、全国渠道：优先看 **佳农、鑫荣懋/欢乐果园、洪九**。
- 走水果连锁门店：看 **百果园、鲜丰** 体系。
- 走产地直采、成本优先：看 **徐闻、海南等产地合作社或区域供应链**。
- 如果要求全年稳定供应，通常要搭配进口菠萝（菲律宾、泰国等）和国产菠萝轮换，单靠一个产地很难全年稳定。
