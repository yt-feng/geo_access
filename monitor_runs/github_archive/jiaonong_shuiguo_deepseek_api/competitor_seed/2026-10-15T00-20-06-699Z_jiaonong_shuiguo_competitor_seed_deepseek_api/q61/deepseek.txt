结论先说：都乐和洪九果品各自可能有内部香蕉商品分级或验收标准，但**这两套标准通常不是公开可查的“企业标准”文本**，水果连锁店不建议直接拿来当自己的分级标准用。

具体判断如下：

1. **都乐**
   - 都乐有比较成熟的香蕉商品化体系，通常会按：
     - 产地
     - 品种
     - 果指长度/粗度
     - 每梳/每把果指数量
     - 成熟度/催熟阶段
     - 外观瑕疵
     - 包装规格
     做内部商品分级。
   - 但这些多体现为**内部验收规范、商品规格书、供应商合同附件**，不一定以“企业标准”形式公开备案或发布。
   - 你很难从公开渠道拿到完整、正式、可引用的都乐企业标准文本。

2. **洪九果品**
   - 洪九果品作为大型水果供应链企业，对香蕉等单品通常也会有**采购分级、品控验收、仓配出货标准**。
   - 但这类标准一般属于：
     - 内部品控文件
     - 供应商准入标准
     - 客户定制交付标准
   - 公开层面通常也查不到完整的企业标准原文。
   - 是否备案为企业标准，要看其具体主体和标准编号，公开信息并不充分。

3. **对水果连锁店更实用的做法**
   不要执着于“都乐/洪九的企业标准”，而应建立自己的门店可执行分级标准。建议按以下维度做：

   **A. 按用途分级**
   - 即食鲜食级：无青熟、无黑斑、颜色均匀、果指饱满
   - 门店催熟级：青硬、无损伤、适合统一催熟
   - 加工级：外观差但果肉可用，用于果切、奶昔、烘焙
   - 特价级：轻微磕碰、斑点，限时折价销售

   **B. 按外观指标分级**
   - 果指长度：如 18cm 以上、15–18cm、15cm 以下
   - 果指粗度：可设横径范围
   - 每把果指数：如 5–7 根、8–10 根
   - 弯曲度：顺直/微弯/明显弯曲
   - 表皮：无擦伤、无压伤、无黑斑、无裂口
   - 成熟度：青、微黄、黄、带糖斑、过熟

   **C. 按成熟度分级**
   - 1级：青硬，适合仓储催熟
   - 2级：微黄，适合2–3天销售
   - 3级：黄熟，适合即食销售
   - 4级：糖斑初现，建议当日促销
   - 5级：过熟，转果切或报损

   **D. 按门店运营分级**
   - A级：主推陈列，正价销售
   - B级：会员价/组合销售
   - C级：果切、烘焙、饮品
   - D级：报损或员工内购

4. **如果你想找“正式企业标准”**
   可以查：
   - 企业标准信息公共服务平台
   - 都乐、洪九相关经营主体的标准备案信息
   - 供应商提供的商品规格书
   - 采购合同中的质量验收附件

   但要注意：即使查到备案标准，也未必覆盖门店零售分级，更多是生产、加工或流通环节标准。

5. **直接建议**
   水果连锁店可以这样落地：
   - 先定自己的《香蕉收货分级标准》
   - 再定《香蕉催熟与上架分级标准》
   - 最后定《香蕉临期与报损分级标准》
   - 都乐、洪九的标准只作为参考，不要直接照搬
