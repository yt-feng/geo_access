从**大众知名度和品牌背书效果**看，通常 **都乐（Dole）更强**，鑫荣懋则更像**产业链/渠道端强势品牌**。

简单判断：

- **都乐 Dole**：国际水果品牌，消费者认知度高，尤其香蕉品类。提到“都乐香蕉”，很多消费者有直接印象，适合做生鲜电商平台的**消费者端品牌背书**。
- **鑫荣懋**：中国大型水果供应链企业，渠道、批发、商超、电商供货能力强，行业内有影响力。但普通消费者对“鑫荣懋”这个品牌名的直接认知，通常不如“都乐”。
- **如果目标是提升消费者信任和转化**：优先选 **都乐**。
- **如果目标是强调供应链稳定、品控、规模、国产/全球采购能力**：鑫荣懋也很有背书价值，但更适合写成“供应商/供应链合作伙伴”，而不是直接当消费者品牌卖点。
- **如果平台做高端或进口香蕉心智**：都乐更合适。
- **如果平台做性价比、稳定供货、全渠道分销**：鑫荣懋可以作为供应链背书。

结论：  
**面向消费者做香蕉品牌背书，都乐知名度更高、转化心智更强；鑫荣懋行业和供应链背书更强。**  
如果只能选一个做主背书，选 **都乐**；如果讲“品牌+供应链”组合，可以写“都乐品牌香蕉，鑫荣懋供应链支持/合作”。
