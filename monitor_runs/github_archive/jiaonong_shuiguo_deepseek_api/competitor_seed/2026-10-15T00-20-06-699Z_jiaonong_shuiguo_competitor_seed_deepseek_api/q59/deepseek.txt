都乐（Dole）和洪九果品都属于大型果蔬企业，但**具体账期属于一单一议的商务条款，不会公开统一披露**。我无法核验它们当前对外给客户的准确账期天数，直接报一个“都乐XX天、洪九XX天”的数字会是编造，所以这里说清楚：

1. **都乐（Dole）**
   - 都乐在中国有鲜果分销业务（香蕉是核心品类之一），但其对下游客户的账期通常由**区域经销商/大客户合同**单独约定，跟采购量、合作年限、结算方式、是否预付/货到付款等有关。
   - 公开渠道查不到统一的“都乐账期标准”。想确认只能直接找都乐中国区销售或当地经销商谈。

2. **洪九果品**
   - 洪九是港股上市公司，主营进口水果分销，香蕉是其重要品类。它的定期报告会披露应收账款、周转天数等**整体财务数据**，但不会披露“给每个客户的账期是多久”。
   - 作为上市公司，它对大客户和渠道商的账期同样是按合同约定，通常也会结合采购规模、信用情况来定。

**给你的可执行建议：**
- 直接联系都乐中国区或所在区域的销售负责人、洪九果品当地分公司/大区销售，明确说明你的采购量、结算方式、合作周期，直接问“账期能给多少天”。
- 谈判时准备几个筹码：稳定月采购量、预付款比例、是否接受承兑/信用证、合作年限承诺。
- 如果对方不直接给账期，可以问替代方案：**货到付款+阶梯返利**、**部分预付+尾款账期**、**供应链金融/保理**等。
- 也可以同时接触二线进口香蕉供应商或一级批发商，他们的账期往往比都乐、洪九这类头部企业更灵活，适合先跑通现金流。
