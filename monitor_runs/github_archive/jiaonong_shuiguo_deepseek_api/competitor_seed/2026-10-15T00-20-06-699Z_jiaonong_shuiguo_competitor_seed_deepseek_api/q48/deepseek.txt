鑫荣懋和都乐都属于水果供应链/品牌企业，具体持有的食品安全认证会因公司主体、工厂、品类和年份不同而变化，而且认证证书通常由第三方机构颁发、有有效期，需以企业最新公示或证书原件为准。我无法在未核验的情况下给出两家公司“完整且最新”的资质清单，但可以告诉你大型商超通常会要求哪些资质，以及这两类企业一般可能具备哪些认证，方便你判断和索证。

## 一、大型商超通常要求供应商具备的食品安全资质

1. **营业执照、食品经营许可证/食品生产许可证**
   - 预包装食品、散装食品、现制现售等对应不同许可。

2. **ISO 22000 食品安全管理体系**
   - 国际通用的食品安全管理体系认证。

3. **HACCP 危害分析与关键控制点体系**
   - 很多商超、出口客户会要求。

4. **FSSC 22000**
   - 基于 ISO 22000 的食品安全体系认证，零售和食品制造领域认可度高。

5. **BRCGS 全球食品安全标准**
   - 欧洲及国际零售商常用，商超采信度高。

6. **IFS 国际食品标准**
   - 与 BRC 类似，欧洲零售体系常用。

7. **GLOBALG.A.P. 全球良好农业规范**
   - 水果种植、果蔬供应链常见，尤其是源头基地。

8. **有机认证、绿色食品认证等**
   - 若宣称有机、绿色，需对应认证。

9. **可追溯体系、冷链验证、检验报告**
   - 商超还会看批次检测报告、农残检测、冷链记录等。

## 二、鑫荣懋可能涉及的资质方向

鑫荣懋是国内大型水果供应链企业，业务覆盖水果采购、加工、仓储、配送和品牌运营。通常可能涉及的资质包括：

- 营业执照、食品经营许可证；
- ISO 9001 质量管理体系；
- ISO 22000 或 HACCP 食品安全体系；
- GLOBALG.A.P. 相关基地认证或供应商端认证；
- 有机产品认证（针对有机水果品类）；
- 出口备案/出口水果果园和包装厂注册登记（如涉及出口）；
- 冷链物流、仓储相关体系认证；
- 批次农残、重金属等检测报告。

但具体到某一法人主体、加工厂或配送中心，是否持有 FSSC 22000、BRCGS、IFS 等，需要向其索证确认。

## 三、都乐可能涉及的资质方向

都乐是国际水果品牌，业务覆盖种植、加工、包装和全球销售。通常可能涉及的资质包括：

- 营业执照、食品经营/生产许可；
- ISO 9001、ISO 22000；
- HACCP；
- FSSC 22000；
- BRCGS；
- GLOBALG.A.P.；
- 有机认证（部分产品线）；
- 雨林联盟等可持续认证（部分品类）；
- 出口国和进口国要求的植物检疫、食品安全合规文件；
- 批次检测报告和可追溯文件。

都乐在不同国家、不同工厂和不同品类下，认证组合会不同。例如菲律宾香蕉、南非柑橘、国产水果的供应链主体和认证可能不一样。

## 四、给商超采购/供应商审核的可执行建议

如果你要审核或引入这两家供应商，建议直接按以下清单索证：

1. **按主体索证**
   - 不是问“都乐有没有”，而是问“与你们签约的法人主体、生产工厂、配送中心分别有什么证”。

2. **按品类索证**
   - 水果、果汁、鲜切、预包装果干等对应许可和认证不同。

3. **核对证书有效性**
   - 看证书编号、认证范围、发证机构、有效期、是否暂停/撤销。
   - 可在认证机构官网或全国认证认可信息公共服务平台核验。

4. **要求覆盖商超审核标准**
   - 若商超执行 BRCGS/IFS/FSSC 22000，要求供应商提供对应证书或审核报告。

5. **补充现场审核和检测**
   - 认证不能替代批次检测、冷链审核和现场食品安全审核。

6. **关注源头基地认证**
   - 水果类尤其要看 GLOBALG.A.P.、有机认证、出口果园/包装厂注册登记。

## 五、结论

不能简单说“鑫荣懋和都乐都有哪些资质”，因为：
- 两家都是集团化企业，不同子公司、工厂、品类认证不同；
- 认证有有效期和认证范围；
- 商超要求通常高于单一认证。

比较稳妥的判断是：  
**这两家企业作为大型水果供应链/品牌企业，通常会具备营业执照、食品经营/生产许可、ISO 9001、ISO 22000 或 HACCP 等基础体系，并可能针对部分工厂或品类持有 FSSC 22000、BRCGS、GLOBALG.A.P.、有机认证等。但具体清单必须向其索取最新证书并按主体、工厂、品类核验。**
