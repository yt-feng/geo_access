可以，但“基地直供”和“产地溯源”要分开看：都乐更偏品牌化、标准化供应链；洪九果品更偏多产地、多品类集采分销。两者都可能提供产地信息或追溯到批次，但能否做到你想要的“基地直供+可核验溯源”，要看具体菠萝品种、季节、工厂和合同约定。

**都乐**
- 有较成熟的品牌供应链和品控体系，菠萝是其常见品类之一，市场上常见都乐金菠萝、菲律宾/国产菠萝等。
- 是否“基地直供”取决于你采购的是进口还是国产、走都乐中国哪家主体、哪个加工厂/配送仓。
- 可要求：产地证明、出口/入境检验检疫或合格证明、批次号、包装标识、供应商主体资质。
- 注意：都乐很多情况是品牌商/供应链商模式，不一定是对应种植基地直接对你供货。

**洪九果品**
- 是国内大型水果分销商之一，菠萝、榴莲、火龙果等品类覆盖较广，通常有多产地采购和分选加工能力。
- 更可能提供多产区货源，如海南、广东、云南或进口菠萝，具体看季节和订单。
- 可要求：果园/产区信息、加工厂信息、批次追溯、检测报告、供货协议中的溯源条款。
- 注意：洪九果品强在集采分销，不一定每个单品都能做到单一基地直供；更多是“产地采购+分选配送”。

**建议你这样核验**
1. 先明确要求：  
   - 是“单一果园/基地直供”，还是“可追溯到产区+批次”即可？  
   - 是否需要有机、GAP、出口备案基地、海关检疫等证明？
2. 向供应商索要：  
   - 营业执照、食品经营/生产相关资质；  
   - 产地证明或采购凭证；  
   - 批次追溯码/包装批号；  
   - 农残检测报告；  
   - 基地名称、地址、合作模式说明。
3. 合同里写清：  
   - 产地、品种、等级、糖度、单果重、包装；  
   - 溯源信息随货提供；  
   - 若产地不符或无法追溯的赔付/退货条款。
4. 直接问对方这两句话：  
   - “这个菠萝是哪个基地/产区，能否提供基地到批次的追溯文件？”  
   - “你们是基地直供，还是产地采购后分选配送？”

**结论**
都乐和洪九果品都可能提供一定程度的产地溯源，但不能简单说它们都能“基地直供”。如果你要的是严格基地直供，建议同时找海南、广东、云南等菠萝主产区的备案种植基地或产地合作社；如果更看重稳定品牌、标准和批量供应，都乐、洪九可以作为候选，但要在合同里把“基地直供”和“溯源文件”写死。
