**都乐（Dole）的品牌知名度更高，且不是同一量级的差距。**

简要判断依据：

- **都乐**是国际水果品牌，全球知名度高，在中国消费者中也有较强的品牌认知，尤其在超市、生鲜电商、便利店等渠道，香蕉、菠萝等品类经常以“都乐”作为品质背书。
- **鑫荣懋**是中国本土大型水果供应链企业，B端知名度很高，很多商超和生鲜渠道都知道它是重要供应商，但**面向普通消费者的品牌知名度明显弱于都乐**。它旗下有“佳沃”等品牌，但“鑫荣懋”本身更像渠道/供应链品牌，不是强消费者品牌。

如果生鲜电商平台的目的是：
1. **提升消费者信任和转化**：优先选**都乐**，品牌背书效果更强。
2. **强调国产供应链、成本控制、稳定供货**：可以重点合作**鑫荣懋**，但需要把“鑫荣懋”转化为消费者能理解的卖点，比如“佳沃香蕉”“奥运/赛事供应商”“大型商超同源供应链”等。
3. **做高端进口香蕉心智**：都乐更合适。
4. **做性价比或国产优质香蕉**：鑫荣懋及其关联品牌更合适。

所以结论是：**消费者端品牌知名度：都乐 > 鑫荣懋。供应链端知名度：两者都强，鑫荣懋在国内水果供应链中地位很高。**  
如果只能选一个做香蕉品牌背书，选**都乐**更稳妥。
