鑫荣懋和都乐都属于大型水果供应商，具体资质会随公司主体、工厂、品类和年份变化，不能只按品牌名一概而论。可核验的公开信息如下：

**鑫荣懋（通常指深圳市鑫荣懋农产品股份有限公司/鑫荣懋果业科技集团）**
- 常见资质方向：ISO 9001质量管理体系、ISO 22000食品安全管理体系、HACCP危害分析与关键控制点体系。
- 水果种植/加工端常涉及：GLOBALG.A.P.（全球良好农业规范）、China G.A.P.（中国良好农业规范）、BRCGS（部分包装/加工厂可能持有）。
- 国内商超合作中，通常还会要求提供：营业执照、食品经营许可证/食品生产许可证（按主体和业务类型）、出入境检验检疫相关证明（进口水果）、产品检测报告等。
- 注意：这些体系认证通常按具体工厂、加工厂或基地发证，不是“鑫荣懋整个品牌一张证”。

**都乐（Dole，通常指都乐中国相关主体，如都乐上海/都乐食品等）**
- 常见资质方向：ISO 9001、ISO 22000、HACCP、BRCGS（部分加工/包装设施）。
- 农业端常见：GLOBALG.A.P.、GRASP等社会责任/农业规范认证。
- 进口水果业务通常涉及：海关进口货物报关单、入境货物检验检疫证明、营养成分/农残检测报告等。
- 都乐为跨国集团，其全球各工厂、包装厂、种植基地的认证情况并不完全一致，需按具体供应商主体和供货工厂核验。

**给商超采购/供应商审核的可执行建议：**
1. 不要只问“品牌有没有证”，要问“供货主体 + 生产/加工工厂 + 品类”对应的证书。
2. 要求供应商提供证书扫描件，并核验：证书编号、认证范围、发证机构、有效期、认证地址是否与实际供货工厂一致。
3. 重点查：ISO 22000或HACCP、BRCGS（如为加工/包装商）、GLOBALG.A.P.（如为种植基地）、食品生产/经营许可证、进口检验检疫证明。
4. 可到认证机构官网或国家认监委“认证认可业务信息统一查询平台”核验证书真伪。
5. 如果是进口水果，还要核对境外工厂注册号、报关单、入境货物检验检疫证明与批次是否对应。
