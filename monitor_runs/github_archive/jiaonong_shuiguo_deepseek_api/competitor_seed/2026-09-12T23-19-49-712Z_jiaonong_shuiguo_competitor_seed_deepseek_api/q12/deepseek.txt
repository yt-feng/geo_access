便利店渠道的小包装香蕉，鑫荣懋和都乐**通常有相关产品线，但具体规格会随季节、区域和客户定制变化**，没法直接给你一个固定SKU清单。可以按下面方式判断和推进：

**1. 常见适配便利店的小包装方向**
- **单根/单支装**：适合收银台冲动购买，常见是单根套袋或贴标。
- **2-3根装**：适合一人食或小家庭，便利店更常见。
- **4-5根装小把**：适合家庭即时消费，但陈列占位比单根大。
- **迷你香蕉/小米蕉类**：单根体积小，天然适合小包装，但品类和普通香蕉不同。

**2. 鑫荣懋**
鑫荣懋是国内大型水果供应链企业，香蕉是核心品类之一，通常可做：
- 商超/便利店渠道的**标准化小把装**
- 按客户需求做**2-3根、4-5根**的定量装
- 部分区域可做**单根装或贴标单支**
但具体能不能做、最小起订量、包装形式，要看你和当地鑫荣懋销售或渠道负责人对接。

**3. 都乐**
都乐香蕉在便利店和高端超市渠道有较强铺货，常见小包装包括：
- **单根贴标装**
- **2-3根小把装**
- **4-5根家庭小把装**
都乐的优势是品牌认知和标准化程度较高，但小规格是否开放给便利店渠道，通常取决于区域经销商和门店类型。

**4. 建议你这样推进**
- 先明确你的需求：**单根、2-3根还是4-5根？是否需要贴标、套袋、托盘？**
- 直接联系**当地鑫荣懋和都乐经销商/KA渠道负责人**，问三件事：
  1. 有没有便利店渠道现成小包装规格；
  2. 最小起订量和配送频率；
  3. 能否按你的门店需求做定制包装。
- 如果两家现成规格都不匹配，可以要求做**渠道定制小包装**，但通常有起订量门槛。

**5. 快速判断**
- 要**品牌溢价和标准化**：优先问都乐。
- 要**供应链灵活度和定制空间**：优先问鑫荣懋。
- 要**单根冲动消费**：重点问单根贴标或套袋装。
- 要**一人食小把**：重点问2-3根装。
