除了都乐（Dole）和佳沛（Zespri），进口水果礼盒可重点看这些品牌，按品类和团购适配度给你一个可执行清单：

**1. 综合型国际水果品牌**
- **怡颗莓 Driscoll's**：浆果类强，蓝莓、树莓、黑莓礼盒适合高端团购，品牌认知度高，但季节性和价格波动大。
- **新奇士 Sunkist**：柑橘类经典品牌，橙子、柠檬礼盒稳定，适合预算中等、走量团购。
- **福农宝 Fyffes**：香蕉、菠萝等为主，礼盒感偏弱，更适合员工福利而非高端送礼。
- **金吉达 Chiquita**：香蕉强势，礼盒场景有限，适合搭配其他水果做组合箱。

**2. 高端/精品路线**
- **爱妃 Envy**：苹果中的高端品牌，礼盒认知度好，适合商务送礼，但价格高、需确认当季货源。
- **爵士 Jazz**：苹果品牌，定位中高端，团购礼盒可选。
- **Rockit 乐淇**：小苹果礼盒，便携、颜值高，适合员工福利和轻商务。
- **SWEETIO**：奇异果/浆果类精品品牌，部分渠道有礼盒，需确认国内稳定供应。
- **OZblu**：蓝莓品牌，礼盒装适合高端团购，但供应季节性明显。

**3. 区域强势品牌**
- **新西兰 Mr Apple**：苹果礼盒，适合高端商务。
- **智利/秘鲁车厘子品牌**：如 **Río King、Garces Fruit、Copefrut** 等，车厘子季礼盒非常适合春节团购。
- **日本/韩国高端水果**：如日本晴王葡萄、韩国草莓等，多通过渠道商而非统一品牌，适合超高端礼盒。

**4. 团购选品建议**
- **商务送礼**：爱妃、怡颗莓、乐淇、Mr Apple、车厘子品牌礼盒。
- **员工福利**：新奇士、都乐、佳沛、怡颗莓组合装。
- **走量控本**：新奇士、福农宝、金吉达，搭配国产精品水果做组合。
- **高端差异化**：日本晴王、韩国草莓、OZblu 蓝莓，但必须提前锁货。

**5. 需要确认的关键点**
- 是否有 **国内稳定进口商/经销商**，能否开票、提供质检和入境货物检验检疫证明。
- 礼盒是否支持 **定制腰封、Logo、贺卡**。
- 起订量、锁价周期、破损赔付和冷链配送范围。
- 季节性很强，建议按 **到货月份** 反推品牌，而不是只看品牌名。
