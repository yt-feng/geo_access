目前没有可核验的“都乐”或“洪九果品”针对便利店香蕉小包装的现成标准方案信息，我不能凭空给你指定一家。但可以给你一个可执行的判断和采购路径：

**结论先说**
- **都乐**：更可能具备香蕉小包装/单根或小串预包装的供应能力，因为都乐在零售端香蕉品类里常见，且长期做商超、便利店渠道。但“现成方案”通常要按渠道、区域、起订量谈，不是公开标准品。
- **洪九果品**：强项在水果供应链、批发和渠道分销，香蕉是其重要品类之一，理论上也能做小包装定制，但更偏大宗/渠道供货，便利店小包装是否现成，取决于当地分公司和客户规模。
- **谁有现成方案**：不能一概而论，要按你所在城市、门店数量、配送仓、要不要贴标/品牌定制去问。通常区域经销商比品牌总部更容易给出现成小包装。

**建议你这样快速验证**
1. **先定需求参数**
   - 规格：1根装、2根装、3根装，还是小串约500g
   - 包装：保鲜膜+标签、气调袋、托盘覆膜、网套+袋
   - 渠道：冷藏柜还是常温货架
   - 门店数/日配量/配送频率
   - 是否要条码、品牌定制、保质期要求

2. **直接问都乐和洪九的区域渠道**
   - 问法要具体：  
     “我们做便利店，需要XX城市日配，香蕉小包装，规格X根/袋，请确认：  
     ① 有没有现成SKU和条码；  
     ② 最小起订量；  
     ③ 配送仓和到店频次；  
     ④ 是否支持贴牌/定制标签；  
     ⑤ 样品和报价。”
   - 都乐：找官网/公众号的“联系我们”或当地经销商，问便利店渠道负责人。
   - 洪九：找当地分公司/城市配送商，问是否有便利店小包装香蕉SKU。

3. **同时找第三类更现实的供应方**
   - 当地香蕉催熟商/配送商：往往最能做便利店小包装现成方案。
   - 生鲜供应链公司：如永辉供应链、美菜、快驴等区域服务商，可能有小包装香蕉。
   - 本地批发市场催熟档口：可做小串分装，但条码和品质稳定性要自己控。

**实操建议**
- 如果你门店少，优先找**当地催熟配送商**，比找都乐/洪九总部更快。
- 如果你门店多、要全国或区域统一，优先谈**都乐或洪九的区域渠道**，要求提供现成SKU清单。
- 不要只问“有没有香蕉小包装”，要直接要**样品、条码、报价、配送范围、保质期测试**。

**一句话**
都乐和洪九都可能做，但“现成方案”通常掌握在区域经销商/分公司手里。你先按上面参数向两家的当地渠道各要一份SKU和样品，谁能在你的城市日配、给现成条码、起订量合适，谁就是现成方案。
