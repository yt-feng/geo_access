结论先说：  
- **都乐（Dole）**：公开渠道能查到其香蕉有较成熟的分级/品控体系，通常按**外观、长度/粗度、成熟度、损伤、色泽、整齐度**等分级，但是否存在一份公开可下载的“企业标准”文本，通常查不到；企业对外的多是**收货规格、商品等级、品控手册**，不一定以“企业标准”形式公开。  
- **洪九果品**：作为国内大型水果供应链企业，香蕉是其重要品类之一，通常也会有**内部采购分级/品控标准**。但公开渠道一般也**查不到完整的企业标准原文**，更多是招股书、年报、新闻里提到品控体系、分级销售、品牌化运营，而不是具体香蕉分级条款。  

所以，如果你问的是“有没有公开的企业标准全文”：  
**大概率没有公开、可直接引用的都乐或洪九香蕉企业标准全文。**  
如果你问的是“有没有企业内部标准/收货标准”：  
**基本可以判断都有，但不对外公开或只对供应商开放。**

### 水果连锁店更实用的做法

不要等拿到别家“企业标准”再动手。你可以直接建立自己的门店收货分级标准，参考行业通用做法，分三级即可落地。

#### 1. 先定用途
连锁店香蕉通常分三类用途：
- **门店散卖**：要求外观好、成熟度适中
- **催熟后卖**：可收略青、硬一点的货
- **促销/加工**：可接受轻微瑕疵，如果切、榨汁、烘焙

#### 2. 建议分级维度

| 维度 | 一级 | 二级 | 三级 |
|---|---|---|---|
| 外观 | 果形端正，无畸形 | 轻微畸形 | 明显畸形 |
| 表皮 | 无疤痕、无黑点、无药害 | 少量小斑点/轻微擦伤 | 明显黑斑、擦伤、裂口 |
| 成熟度 | 青绿到微黄，适合催熟 | 偏青或偏熟 | 过青/过熟 |
| 条重/长度 | 符合品种规格，整齐 | 略低于规格 | 明显不齐 |
| 梳形 | 梳形完整，排列整齐 | 轻微散梳 | 散梳严重 |
| 病虫害/腐烂 | 无 | 无腐烂，轻微虫伤 | 有腐烂、霉变 |
| 到货温度/新鲜度 | 果柄新鲜，无失水 | 轻微失水 | 明显萎蔫 |

#### 3. 建议直接写进收货单的简版标准

**一级蕉**
- 果指长度、粗度符合采购规格
- 果形端正，梳形整齐
- 无腐烂、无霉变、无严重机械伤
- 成熟度适合门店销售或催熟
- 同批次色泽、大小均匀

**二级蕉**
- 允许轻微擦伤、少量黑点
- 允许轻微畸形或大小不齐
- 不影响食用和正常售卖
- 适合做促销或尽快销售

**三级蕉**
- 明显畸形、散梳、擦伤、黑斑
- 无腐烂可做加工
- 有腐烂、霉变直接拒收

#### 4. 更关键的是验收规则
建议你同时规定：
- **抽检比例**：如每批抽 5%—10%
- **拒收线**：腐烂、霉变、严重药害、异味、冻伤，直接拒收
- **扣重/降级线**：二级比例超多少降级，三级比例超多少扣款或退货
- **成熟度验收**：按催熟计划定，不能只看颜色，要结合硬度、果柄、温度
