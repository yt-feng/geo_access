都乐和洪九果品对外的标准账期没有公开统一口径，通常按客户类型、采购量、合作年限、区域和品类单独谈，不能直接给一个固定天数。能确认的是：

- **都乐**：以品牌水果和商超/餐饮/批发渠道为主，合作门槛相对更高。新客户一般很难直接拿到账期，常见做法是先款后货或预付定金，稳定合作后再谈月结，实际可能落在 **30天左右** 这个区间，但并非公开承诺。
- **洪九果品**：以批发、商超、电商等渠道为主，客户结构更分散，账期更偏“一客一议”。行业内常见的是 **30～60天**，部分大客户或长期合作可能更长，但同样没有统一标准。

如果你要找“能提供账期服务的香蕉供应商”，建议直接按下面方式问，效率最高：

1. **先问是否支持账期**：不要只问“账期多久”，先确认对方对新客户是否开放账期。
2. **问清账期起算点**：是发货日、到货日、对账日还是开票日？这比天数本身更关键。
3. **问清额度**：账期通常和授信额度绑定，比如“30天账期，额度20万”。
4. **问清条件**：是否需要保证金、担保、首单现结、连续合作几个月后才给账期。
5. **问清逾期规则**：逾期利息、停供、取消授信的条件。

更实际的建议是：  
都乐和洪九这类头部供应商，**新客户直接拿账期难度较大**；如果你需要账期，优先找**区域一级批发商、产地代办、大型农批市场档口**谈，往往比品牌方更容易给到 **15～30天** 的短期账期。  
如果你量稳定，可以直接提出“首单现结，第二单起30天账期”作为谈判起点。
