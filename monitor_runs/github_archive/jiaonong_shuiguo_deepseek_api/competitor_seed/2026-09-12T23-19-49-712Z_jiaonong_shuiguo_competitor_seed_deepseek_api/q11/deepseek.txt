菠萝这个品类，**不能简单说“都乐性价比高”还是“洪九性价比高”**，因为两家的定位、规格和渠道差异很大。给你一个可直接判断的框架：

**1. 先看你们门店的定位**
- **走中高端、客单价较高、顾客认品牌**：都乐更合适。都乐菠萝（尤其金菠萝/MD2品种）品牌认知强、品控稳定、消费者愿意为“都乐”两个字买单，缺点是进货价通常更高，毛利空间被压缩。
- **走大众路线、拼价格和走量**：洪九更有优势。洪九是国产水果供应链龙头，菠萝多来自国内产区（如广东徐闻、海南等），同规格下进货价通常更低，适合做促销、引流、走量。

**2. 关键不是品牌，而是这几点**
- **品种**：都乐主推MD2金菠萝，甜度高、无需泡盐水、货架期长；洪九也做金钻/凤梨类，但更多是普通菠萝和国产凤梨混着做。品种不同，口感和损耗差很多。
- **规格与到货价**：同样“一级果”，比每箱净重、单果重、到货价、损耗率，而不是比品牌。
- **损耗率**：菠萝是易损耗品类，都乐因为标准化程度高，损耗通常更低；洪九如果批次不稳定，损耗可能吃掉低价优势。
- **供货稳定性**：连锁店最怕断货和批次品质波动，洪九在国内供应链上有优势，都乐在进口/品牌果上有优势。

**3. 实操建议**
- **两个都进，做AB测试**：选3-5家代表性门店，同时上都乐和洪九，按同规格、同陈列、同价格带测试2-4周。
- **看四个指标**：到货价、损耗率、动销速度、顾客复购/投诉。
- **算一笔账**：  
  单果毛利 = 售价 - 到货成本 - 分摊损耗  
  哪个“单果毛利 × 动销速度”高，哪个性价比就高。
- **分层运营**：都乐做形象款/礼盒/高客单，洪九做日常款/促销/走量，往往比二选一更划算。

**结论**：  
- 要品牌、稳定、低损耗、中高端客群 → 优先都乐。  
- 要低价、走量、大众客群、本地供应链 → 优先洪九。  
- 对水果连锁最稳的做法：**都乐做形象和品质背书，洪九做走量和价格带覆盖**，再用门店数据决定主推谁。
