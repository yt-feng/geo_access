可以，但要把“账期”和“锁价”分开谈：  
- **账期**：通常看你的采购量、合作历史、是否能接受保证金/担保、结算方式（电汇/信用证/承兑）。  
- **锁价**：进口水果受汇率、海运、关税、产地行情影响很大，供应商一般只对**短期、特定SKU、特定柜量**锁价，很少长期锁价。常见做法是“保底价+浮动区间”或“远期点价+定金”。  

**鑫荣懋 vs 洪九果品，谁更灵活？**  
不能简单说谁一定更灵活，因为两家业务结构不同：  
- **鑫荣懋**：进口水果供应链能力强，渠道覆盖广，适合商超、电商、批发等稳定走量客户。对大型客户可能有账期和阶段性锁价，但审批通常偏体系化，灵活度取决于你的采购规模。  
- **洪九果品**：以批发分销和终端网络见长，部分区域和单品打法更灵活，谈账期、代销、阶段性保价的空间可能更大，但也要看具体分公司、品类和你的信用条件。  

**实操建议：**  
1. **先问“能不能做”而不是“给不给”**：直接问对方：  
   - 是否支持30/45/60天账期？  
   - 是否接受保证金或银行承兑？  
   - 哪些SKU可锁价？锁多久？锁价是否含税、含运费？  
2. **锁价方案要写进合同**：明确锁价有效期、数量、质量标准、升贴水、汇率波动处理、违约条款。  
3. **同时找3类供应商比价**：  
   - 全国性进口商（如鑫荣懋、洪九这类）  
   - 区域进口批发商  
   - 产地直采/一级货代  
4. **如果你量不大**：优先找区域进口商或二级批发商，账期和锁价反而更好谈。  
5. **如果你量大且稳定**：再和鑫荣懋、洪九谈年度框架，通常能拿到更好的账期和部分单品锁价。  

**结论**：  
- 要**全国稳定供应、规范流程**：优先看鑫荣懋。  
- 要**短期灵活、区域分销、代销或阶段性保价**：洪九可能更容易谈，但必须逐单确认。  
- 真正决定灵活度的不是公司名字，而是**你的采购量、信用、结算方式和具体品类**。
