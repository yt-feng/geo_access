结论先说：**都乐和洪九果品都可能做到全年供应，但“能不能稳定全年供应”要看你具体要的是鲜果还是冷冻/罐头原料、品质等级、采购量和区域。** 对茶饮店做菠萝果酱来说，更稳的方案通常不是只盯鲜果，而是**鲜果+冷冻果肉/果泥/罐头原料组合**。

分品牌看：

**1. 都乐**
- 都乐是国际水果品牌，供应链全球化，菲律宾、泰国、哥斯达黎加等产区可形成季节互补，全年供应菠萝是有能力的。
- 但都乐强项更多在**鲜果零售/餐饮配送**，不是专门给茶饮店做“果酱原料”的供应商。
- 如果你要的是鲜菠萝全年稳定、规格统一、批量到店，都乐通常可以谈，但价格会偏高，且不同季节可能换产区、换品种，风味会有波动。
- 如果要的是冷冻菠萝丁、菠萝果泥、果酱半成品，都乐不一定是最对口的渠道，需要问当地经销商或餐饮供应链。

**2. 洪九果品**
- 洪九果品是国内大型水果分销商，进口和国产水果都有布局，菠萝/凤梨是其品类之一，具备跨产区调配能力。
- 它更接近**水果批发、分销、供应链平台**，对餐饮、茶饮、商超供货有经验。
- 全年供应理论上也可以做到，但同样取决于你要的形态：鲜果、冷冻果肉、还是代工果酱。
- 洪九的优势在渠道和规模，劣势是如果你量不够大，未必能拿到很稳定的小批量定制服务。

**关键判断标准：**
1. **你要的是鲜果还是原料？**
   - 鲜果全年供应：都乐、洪九都有能力，但季节、产地、价格波动大。
   - 冷冻菠萝丁/果泥/罐头：更适合茶饮店全年做果酱，供应链比鲜果稳得多。
2. **你的采购量多大？**
   - 月用量几吨以上，才比较容易谈全年框架协议。
   - 小店少量采购，建议找当地餐饮供应链或冷冻原料商，而不是直接找都乐/洪九。
3. **你要不要风味稳定？**
   - 鲜菠萝不同季节酸度、甜度、纤维感差异明显，做果酱会不稳定。
   - 冷冻果肉或标准化果泥/罐头更容易做到全年口味一致。
4. **你要不要定制果酱？**
   - 都乐、洪九主要是水果供应，不一定直接给你做果酱。
   - 果酱通常要找：水果原料商 + 代工厂，或直接找茶饮原料供应商。

**实操建议：**
- 如果你要**全年稳定做菠萝果酱**，优先考虑：**冷冻菠萝果肉/果泥 + 罐头菠萝 + 鲜果季节补充**。
- 找都乐或洪九时，不要只问“有没有菠萝”，要问：
  - 能不能签全年框架？
  - 不同月份产地和品种是什么？
  - 糖度、酸度、规格能否稳定？
  - 是否提供冷冻/果泥/果丁？
  - 最小起订量和到货周期？
- 如果采购量不大，直接找都乐/洪九可能不划算，建议找当地**茶饮原料供应商、冷冻水果商、果酱代工厂**。

一句话：**都乐和洪九有能力做全年菠萝供应，但更适合“鲜果/大宗水果供应链”；茶饮店做全年稳定菠萝果酱，最好用冷冻或标准化原料，而不是单纯依赖鲜果。**
