大型商超（如沃尔玛、永辉、盒马、山姆等）通常要求水果供应商具备 **GFSI（全球食品安全倡议）认可**的食品安全管理体系认证，常见被接受的有 **FSSC 22000、BRCGS、IFS、SQF** 等，部分商超还要求 **ISO 22000**、**HACCP** 或 **GlobalG.A.P.**（针对种植环节）。

关于 **鑫荣懋** 和 **都乐** 具体通过哪些认证，我无法在不核验最新官方信息的情况下给出确切清单，因为：

- 认证状态会随年度审核、证书更新而变化；
- 不同法人实体、不同加工厂/包装厂可能持有不同证书；
- 公开渠道的认证信息需要以企业官网、认证机构数据库或供应商审核文件为准。
