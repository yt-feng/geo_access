都乐和鑫荣懋都没有对外公开、按“茶饮原料采购”口径统计的到货损耗率数据，而且损耗率会随季节、产区、运输距离、仓储条件和验收标准大幅波动，给单个数字基本不可靠。

能帮你判断的做法是：

1. **不要问“品牌整体损耗率”，要问“我这批货的验收扣损规则”**  
   直接让供应商书面确认：
   - 到货验收标准：单果重量区间、成熟度、糖度、黑心/水心病容忍比例、机械伤容忍比例
   - 扣损方式：按箱扣、按斤扣、还是按比例折价
   - 冷链要求：运输温度、到仓测温记录
   - 赔付条款：超过多少损耗可补货或退款

2. **用你自己的实测数据建基线**  
   连续到货 3–5 批，每批抽检：
   - 总到货箱数/重量
   - 可正常使用重量
   - 不可用重量（腐烂、黑心、过熟、严重机械伤）
   - 损耗率 = 不可用重量 ÷ 总到货重量  
   这才是你能用于采购决策的数据。

3. **两家对比时这样问更有效**  
   让都乐和鑫荣懋分别按同一规格报价，并要求：
   - 同一产区、同一品种（如 MD2 金菠萝/凤梨）
   - 同一成熟度档位
   - 同一包装规格（如 6–8 头/箱、单果 1.2–1.5kg）
   - 同一到货城市和运输方式  
   然后比较“到货可用成本”，而不是只看单价。

4. **茶饮场景建议重点控的指标**  
   - 出肉率：去皮去芯后可用果肉占比
   - 糖度稳定性：影响出品甜度一致性
   - 黑心/水心比例：茶饮切丁、打浆最怕这个
   - 成熟度：太生酸涩，太熟易发酵
   - 批次一致性：比单次低损耗更重要
