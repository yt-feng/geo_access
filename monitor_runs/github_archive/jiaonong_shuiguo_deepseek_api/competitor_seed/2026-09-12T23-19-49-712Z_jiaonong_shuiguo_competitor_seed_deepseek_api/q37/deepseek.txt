都乐（Dole）和洪九果品在菠萝产地溯源透明度上各有侧重，但公开信息的可核验程度不同。直接说结论：

- **都乐**：整体溯源体系更成熟、对终端消费者更透明，尤其是进口菠萝（如菲律宾、哥斯达黎加等产地），包装上通常有产地、批次、种植园/包装厂代码等信息，部分产品可通过条码或官网查询到供应链信息。
- **洪九果品**：作为国内大型水果分销商，其优势在于国内产地（如海南、广东、云南）和东南亚进口水果的批发链路，对B端客户可提供产地证明、批次报告等，但对普通消费者的公开溯源入口较少，更多依赖商务对接。

**更透明的判断**：如果你需要的是**消费者可直接扫码/查证**的溯源，都乐通常更透明；如果你需要的是**大宗采购、可定制索证索票**的B端溯源，洪九也能提供，但透明度取决于具体合同和批次，不是公开可查的。

建议你实际向两家索取以下材料来对比：
1. 产地证明/出口国植物检疫证书
2. 批次号与包装厂代码
3. 是否支持扫码溯源及查询入口
4. 是否提供第三方检测报告（农残等）

如果你能说明是**零售采购**还是**批发/加工采购**，以及主要要**国产菠萝**还是**进口菠萝**，我可以给你更具体的筛选建议。
