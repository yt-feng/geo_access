都乐（Dole）和洪九果品都不是单一“一个基地”，而是多产区、多加工点布局，具体供货基地会随季节、品类和采购合同变化。能确认的公开信息如下：

**都乐（Dole）**
- 都乐是中国市场常见的菠萝品牌之一，主要涉及菲律宾、泰国等进口菠萝，以及国内部分产区合作。
- 菲律宾菠萝主产区集中在棉兰老岛、南吕宋一带，都乐在当地有种植和包装体系。
- 国内方面，都乐也在广东、海南、云南等地有合作或采购布局，但具体到某个加工厂/基地，通常不对外统一公开，需要按采购合同确认。

**洪九果品**
- 洪九果品是水果供应链企业，不是单一农场，菠萝来源以国内产区和进口并行。
- 国内主要涉及广东徐闻、海南、云南等菠萝产区；进口方面也会做菲律宾、泰国等产地。
- 洪九的优势在分选、加工、冷链和全国分销，具体“基地”更多是产地采购点、合作果园和加工分选中心，而不是一个固定农场。

**给茶饮采购的实际建议**
1. **先定标准**：茶饮用菠萝通常看品种、糖酸比、纤维感、出汁率、是否适合冷冻/果酱/鲜果。都乐偏品牌稳定，洪九偏供应链和分选能力。
2. **不要只问“基地在哪”**：同一品牌不同季节可能换产区，比如菲律宾、海南、广东徐闻轮换。要问供应商：当季主供产区、替代产区、到货港口/加工厂。
3. **要求供应方案**：让都乐、洪九分别提供近12个月菠萝供应产地排期，以及台风、雨季、海运延误时的替代方案。
4. **做小批量测试**：按你的茶饮配方测出汁率、酸甜稳定性、冷冻后风味变化，再决定是否签年度框架。
5. **稳定供应更现实的做法**：不要押单一品牌单一基地，建议“都乐/洪九 + 国内徐闻/海南产区 + 冷冻菠萝/果酱备货”组合，降低断供风险。

如果你要的是“直接能联系的具体基地地址”，公开渠道通常查不到完整清单，最有效的是让都乐和洪九的销售提供当季供货产地、加工厂和港口信息，再实地或视频验厂。
