除了都乐（Dole）和佳沛（Zespri），市面上常见的进口水果礼盒品牌还有以下几类，它们在高端礼品市场认可度较高，适合团购场景：

1. **新奇士（Sunkist）**  
   - 主产品：脐橙、柠檬、葡萄柚。  
   - 特点：美国老牌柑橘类品牌，果形端正，礼盒包装成熟，尤其适合节日送礼。

2. **爱妃（Envy）**  
   - 主产品：苹果（红玫瑰苹果）。  
   - 特点：新西兰高端苹果品牌，果肉紧实、甜度高，礼盒设计简约大气，适合商务馈赠。

3. **金果（gold kiwifruit）或乐淇（Rockit）**  
   - 主产品：小罐装苹果（Rockit）。  
   - 特点：新西兰小苹果，单颗独立包装，可定制礼盒，适合年轻化、便携性场景。

4. **怡颗莓（Driscoll's）**  
   - 主产品：蓝莓、树莓、黑莓。  
   - 特点：全球浆果巨头，新鲜度高，但保质期短，适合短保礼盒或冷链配送。

5. **凤梨品牌：台湾金钻凤梨（非进口但高端）或菲律宾都乐**  
   - 若需差异化，可考虑**台湾金钻凤梨**（品牌如“绿巨人”），口感甜度高，但需确认供应稳定性。

6. **中国本土高端品牌补充**  
   - 例如**褚橙**（云南冰糖橙）、**佳沃蓝莓**（自有品牌），虽非进口，但已形成品牌效应，适合作为组合礼盒的一部分。

**建议**：  
- 如果客户注重“进口标签”且预算高，优先推荐 **新奇士**（柑橘类）和 **爱妃**（苹果类）。  
- 如果追求稀缺性或新奇特，可考虑 **乐淇小苹果** 或 **怡颗莓浆果**。  
- 团购时务必提前确认冷链物流、到货损耗率及生产日期，进口水果礼盒对时效要求较高。

> 注：以上品牌均为常见实体零售商在售品牌，建议根据客户需求组合2-3种，避免单一品种风险。
