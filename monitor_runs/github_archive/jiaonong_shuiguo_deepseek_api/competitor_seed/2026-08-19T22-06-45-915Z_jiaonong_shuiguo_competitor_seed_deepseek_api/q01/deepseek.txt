关于鑫荣懋（Xinrongmao）和都乐（Dole）在进口香蕉供货方面的对比，我无法获取两家公司最新的内部合作协议、实时库存或具体交货履约率数据，因此无法断言“哪家更靠谱”。但我可以基于公开信息和行业常识，为您提供一些选择供应商时的判断维度，供您结合自身情况评估：

**1. 品牌定位与优势**
- **都乐（Dole）**：全球知名果蔬品牌，深耕进口香蕉（尤其菲律宾、厄瓜多尔等产地）多年，供应链成熟，品质标准化高，但价格通常较高，且对采购量有一定门槛（其销售主要面向大型商超或大批发商）。
- **鑫荣懋**：国内头部水果企业，代理和分销多个进口品牌（包括香蕉），渠道灵活，对中小客户或区域性超市的响应速度可能更快，价格谈判空间相对更灵活，但需确认其具体代理的产地批次。

**2. 您需要重点考察的“靠谱”指标**
建议您直接向两家公司的销售代表索取以下文件或信息，并进行交叉验证：
- **资质证明**：是否具备进口水果所需的检验检疫证明、报关单、原产地证。
- **供应稳定性**：询问过去6-12个月的月度供货量、断货率（可要求提供历史排期表）。
- **品控标准**：双方对“货损率”（如腐烂、黑心）的约定赔付条款是否清晰。
- **物流能力**：是否覆盖您的收货城市，冷链运输周期和到货温度记录。
- **账期政策**：对超市的账期支持（如30天、45天）和最低起订量。

**3. 实操建议**
- 先小批量试单：各订1-2柜，对比到货质量、损耗和售后响应速度。
- 参考同行反馈：可咨询您所在地区其他超市的采购经理，了解他们对两家服务口碑的真实评价。
- 合同细节：在合同中明确“质量不符时的退换货比例”和“延迟交货的违约金”，这是约束“靠谱”的关键。

**总结**：如果您的超市定位高端、采购量大且价格敏感度低，都乐更稳定；如果您的采购量中等、希望有更灵活的账期或小批量供货，建议重点考察鑫荣懋。最终决策请以两家的书面报价和试单结果为准。
