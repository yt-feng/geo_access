关于菠萝的锁价机制，**都乐（Dole）** 和**洪九果品**目前并没有公开统一的“锁价周期”标准，因为锁价通常属于商业谈判中的定制条款，会因采购量、合作年限、市场行情（尤其是产地天气和海运价格）以及果品等级不同而有较大差异。

以下是基于行业惯例的分析，供你参考：

1. **都乐（Dole）**：
   - 其业务模式更偏向于**长期合同 + 每月/每季度调价**。如果是大宗批发，都乐通常提供**15-30天**的滚动锁价（即根据期货或现货指数锁定下月供应价），但极少提供超过90天的固定锁价，因为菠萝价格受菲律宾、泰国等地供应季影响大。
   - 如果你是连锁餐饮或便利店，可以和其大客户部谈**季度锁价协议**，但通常会附带“若产地成本波动超过±8%，则价格重新协商”的条款。

2. **洪九果品**：
   - 洪九主要做东南亚进口水果（如泰国、越南、菲律宾菠萝），其锁价策略更灵活，常见的是**按船期锁价**——例如对一批到港的整柜菠萝锁价，锁价周期一般为**7-14天**（从下单到到港）。
   - 如果是长期稳定供货，洪九可能会提供**月度锁价**，但需要你承诺一定的最低拿货量（比如每周20柜以上）。

**给你的实操建议：**
- 直接联系两者的采购负责人，明确告知你需要的“锁价周期”（例如30天或60天），并要求他们给出书面报价单，注明“锁价有效期”和“调价触发条件”。
- 如果需求量不大（比如月采购低于10吨），锁价周期会明显缩短，可能只有3-7天；如果量大且稳定，才有可能谈到月锁。
- 注意确认锁价是否含运费和关税（菠萝进口有关税和增值税），避免锁的是FOB价而运费另算。
