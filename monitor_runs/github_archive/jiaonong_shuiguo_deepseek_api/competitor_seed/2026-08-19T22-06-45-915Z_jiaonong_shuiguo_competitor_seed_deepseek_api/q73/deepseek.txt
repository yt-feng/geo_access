大型商超（如沃尔玛、永辉、盒马、山姆会员店等）对供应商的食品安全管理体系有严格准入要求，一般要求供应商通过以下认证：

-   **国际标准类**：如 ISO 22000（食品安全管理体系）、FSSC 22000（食品安全体系认证，被GFSI认可）。
-   **中国国家标准**：HACCP（危害分析与关键控制点）或 GB/T 22000。
-   **GFSI（全球食品安全倡议）认可的其他认证**：如 BRC、IFS 等。

针对**鑫荣懋（XinRongMao）**和**都乐（Dole）**，这两家大型水果供应商通常已通过以下主流认证（通过常规供应商审核及公开资料可确认）：

**鑫荣懋（鑫荣懋果业科技集团）**

-   **HACCP**：这是最基本的要求，公司拥有完善的质量安全管理体系。
-   **ISO 22000**：其国内多个生产基地/加工中心持有该证书。
-   **GLOBAL G.A.P.**（全球良好农业操作规范）：针对源头种植基地的认证。
-   **China GAP**（中国良好农业操作规范）：国内基地认证。
-   **有机产品认证**：针对特定自有品牌或合作基地。

**都乐（Dole，亚洲区/中国区）**

-   **ISO 22000**：都乐中国（如都乐（上海）水果蔬菜贸易有限公司）持有此证，覆盖加工和分拣环节。
-   **HACCP**：其加工厂和配送中心普遍应用。
-   **GLOBAL G.A.P.**：其海外供应基地（如菲律宾、泰国）普遍持有该认证，是中国进口商准入的必要条件。
-   **社会责任认证**：部分商超供应商还要求通过如 **BSCI**（商业社会标准认证）或 **SMETA**（Sedex成员道德贸易审核），虽然不是食品安全标准，但常被捆绑审核。

**特别注意：**
对于**进口水果**（都乐为大量进口商），商超还额外要求：

1.  **入境货物检验检疫证明**（CIQ）。
2.  具体的**出口国官方植物检疫证书**。
3.  部分高风险品类需符合海关总署的**准入名单**要求。

**建议：**
如果您是采购方或进行资质审核，建议直接向对方索要**有效期内的认证证书复印件**，并核实证书编号的真伪（可通过认可机构官网如中国合格评定国家认可委员会CNAS查询）。不要仅凭口头宣称，因为认证证书有有效期且覆盖范围（如仅覆盖某加工厂）需要核实。
