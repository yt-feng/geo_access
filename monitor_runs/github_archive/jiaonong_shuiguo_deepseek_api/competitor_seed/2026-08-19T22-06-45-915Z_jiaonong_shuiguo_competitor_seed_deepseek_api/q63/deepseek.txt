关于您提到的“都乐”和“洪九果品”是否有香蕉散装/小包装选项，**建议您直接联系这两家公司的区域销售或批发渠道确认**，因为他们的产品线会根据地区、季节和客户类型（商超、社区团购、批发市场）有所不同。

不过，根据行业的一般情况，给您一些参考信息：

1. **都乐（Dole）**：  
   - **通常情况**：都乐在国内市场主要面向商超和电商，以标准化包装（如整箱、预包装袋）为主。散装或定制小包装在部分地区可能不直接供应，但**如果有社区团购量级（如一次几十箱）**，可以尝试联系其经销商申请定制包装（如5kg小袋装）。
   - **建议**：拨打都乐官网的客服电话或联系当地经销商，重点询问“团购定制”和“散装出货”可能性。

2. **洪九果品（Hongjiu）**：  
   - **通常情况**：洪九是国内大型水果供应链企业，主做批发和商超渠道，**散装、定制小包装是其业务之一**，但具体要看您所在的城市和采购量。他们更倾向于有稳定订单的客户。
   - **建议**：直接搜索“洪九果品 + 您所在城市”或拨打官网电话，说明是社区团购渠道，询问是否有“小包装定制”或“整箱分装”服务。

**补充实操建议**：  
- 如果两家都不提供散装，您可以考虑**自己拆箱分装**：
  - 从批发市场（或产地直采）购买整箱香蕉（如22斤/箱），自己用保鲜膜或小袋分装成1kg/2kg小包，成本低且灵活。
  - 注意香蕉催熟和保鲜问题，建议分装后尽快配送。

**最终提醒**：采购前务必确认**起订量、最低运费、账期**，以及**售后坏果赔付规则**——社区团购对损耗率敏感，务必在合同中列明。
