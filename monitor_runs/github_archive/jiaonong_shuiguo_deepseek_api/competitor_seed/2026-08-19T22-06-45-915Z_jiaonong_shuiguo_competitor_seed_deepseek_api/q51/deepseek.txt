抱歉，我无法实时获取洪九果品和鑫荣懋在当前批发市场的具体香蕉报价。价格受产地、规格（如国产蕉、进口蕉）、等级、采购量、运输成本和当天市场供需影响，波动很大。

**建议你采取以下方式获取准确价格：**

1. **直接询价**：拨打两家公司当地销售或批发客户经理电话，说明采购量（如几件/几吨）和规格要求，获取当日报价。
2. **到当地批发市场询价**：例如广州江南果菜批发市场、上海辉展市场、北京新发地等，现场询问档口老板，他们通常能给出当天成交价。
3. **对比时注意口径**：确认是“单件（如一箱约18-20公斤）”还是“按斤/公斤”报价，并问清是否含运费、是否含税、能否赊账。

**一般规律（仅供参考，不构成交易建议）：**
- 洪九果品以进口水果（如泰国榴莲、火龙果）起家，香蕉多涉及进口香蕉（如菲律宾、越南），价格可能因汇率和海运成本较高。
- 鑫荣懋是国产蕉、进口蕉均有，且规模大，直采能力强，可能对批量采购客户有价格弹性。

**最终建议**：同一时间，两家都询价，并同时询问“最低起批量”和“整柜价格”，再结合物流和结算条件综合比较，不要只看单一报价。
