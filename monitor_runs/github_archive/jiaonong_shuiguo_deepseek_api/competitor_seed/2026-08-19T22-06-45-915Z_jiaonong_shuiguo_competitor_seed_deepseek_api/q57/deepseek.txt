关于**洪九果品**和**都乐（Dole）**对下沉市场夫妻店的小批量供货情况，我可以给出清晰的判断：

**结论：** 这两家目前**基本没有**针对个人夫妻店的小批量供货业务，主要服务对象是大型商超、连锁水果店、批发市场及餐饮大客户。

---

**1. 洪九果品（Hongjiu）**
- **商业模式**：洪九果品是“端到端”的鲜果供应链品牌，主要从泰国、越南等地进口榴莲、山竹、龙眼等单品，然后批发给**永辉、盒马、百果园、区域连锁超市**等大型零售终端。他们实行“自有工厂 + 大仓直发”，对订单量有最低起订量要求（通常按柜或按吨计）。
- **对夫妻店**：洪九一般会通过**当地的水果批发市场（如嘉兴市场、广州江南市场）**由二级批发商拆箱分销。夫妻店若想进货，可以去本地批发市场找摊档，而不是直接对接洪九总部。洪九官网和经销商体系均不提供“一件代发”或“小批量混批”服务。

**2. 都乐（Dole）**
- **品牌定位**：都乐主要做标准化进口香蕉、菠萝、木瓜等高周转单品，供应给沃尔玛、山姆、全家、罗森等大型连锁及便利店系统。
- **对夫妻店**：都乐在国内没有开放C端或小B端的批发订货通道。他们通常通过**区域总代理**铺货，代理商会按行政区划分给水果店。夫妻店要进货都乐产品，最现实的方式是去本地的**一级水果批发市场**找持有都乐代理权的档口，整箱采购（如香蕉一箱约13kg），但**不设立直达小店的配送体系**。

---

**给您的实操建议（针对下沉市场夫妻店）：**

1. **首选渠道**：去您所在城市/县城的**中心水果批发市场**，找专门经营进口水果的档口，问老板“有没有洪九的榴莲/都乐香蕉”。这些档口通常就是洪九和都乐在当地的二级分销节点，可以整箱拿货，价格比超市低，且能凑单混批。
2. **次选方案**：如果您能凑到几家人一起拼单，可以联系当地的**区域代理商**（通过批发市场老板获取联系方式），申请按“小批量托盘”进货，量大一些可谈价格。
3. **不要尝试**：别给洪九或都乐总部打电话下单，他们不会接散单；也不要在其官网/小程序找“小店进货”入口，基本不存在。

**一句话提醒**：夫妻店想拿这两家的货，核心资源在您当地的**批发市场档口**，而不是品牌总部。
