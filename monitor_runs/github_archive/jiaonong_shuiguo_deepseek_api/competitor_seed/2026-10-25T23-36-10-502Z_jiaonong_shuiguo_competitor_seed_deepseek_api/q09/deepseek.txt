可以优先看这几类进口品牌（按常见渠道可采购性排序）：

1. **新奇士 Sunkist（美国）**：橙类礼盒成熟，适合企业团购，品牌认知度高。
2. **爱妃 Envy（新西兰/美国）**：苹果礼盒，溢价能力和包装质感适合礼品。
3. **红玫瑰/爵士等新西兰苹果品牌**：如 **Jazz、Rockit（乐淇）**，乐淇小苹果筒装礼盒在团购渠道辨识度很高。
4. **车厘子类**：**Stemilt（美国）**、**Chelan Fresh（美国）**、**Vanguard（智利/秘鲁）** 等出口商品牌，礼盒装常见；车厘子季节性强，需按产季锁货。
5. **秘鲁/智利蓝莓品牌**：如 **Hortifrut**、**Camposol** 等，适合搭配组合礼盒。
6. **佳农（Goodfarmer）**：严格说是中国品牌但进口水果供应链强，进口香蕉、车厘子、蓝莓礼盒在团购中常见，可作为“进口货源品牌”备选。
7. **都乐、佳沛之外的猕猴桃**：可看 **Zespri 之外的意大利/智利猕猴桃出口商品牌**，但团购品牌溢价通常不如佳沛，建议作为价格带补充。

**建议组合**：高端主推 **乐淇苹果 + 爱妃苹果 + 佳沛**；大众走量用 **新奇士橙 + 进口车厘子/蓝莓组合**。采购时重点确认：原箱标签、果径/规格、到货批次、礼盒是否为原厂礼盒还是分装、售后坏果率。车厘子和蓝莓必须按产季和船期锁货，不要只看品牌名。
