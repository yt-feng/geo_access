大型商超通常把“冷链物流覆盖”理解为供应商能对目标门店/区域做到可控温运输与交付，但**鑫荣懋、都乐这类水果供应链企业的配送覆盖城市会随品类、仓网、客户合同和季节变化，公开渠道也没有一份稳定、可核验的“全城市清单”**。因此我不能凭印象给你列城市名单，避免你拿去做商超准入材料时被认定为不实。

可执行的做法：

1. **先明确商超要的“覆盖”口径**  
   让采购写清：是要求覆盖其全部门店，还是只覆盖某几个DC/区域；是要求供应商自有冷链，还是允许第三方冷链承运；是否需要城市级名单或仓网证明。

2. **向鑫荣懋、都乐索要正式覆盖证明**  
   直接联系其销售/大客户部门，要求提供：
   - 服务商超客户的冷链仓/DC分布城市
   - 可配送城市及对应温区
   - 是否由自有车队或签约冷链承运商完成
   - 针对你所在商超门店/DC的配送方案与时效
   这类材料通常以《服务能力说明》《冷链配送网络图》《客户案例》形式提供，比公开搜索可靠。

3. **用“区域覆盖+承诺时效”替代“全城市清单”**  
   商超准入材料中可写：华东、华南、华北等区域核心城市可直配，其他城市经区域DC中转，具体以合同附件门店清单为准。让供应商盖章确认你需要的门店清单。

4. **核验方式**  
   要求提供近期同类商超客户的送货单/冷链温控记录样例（脱敏）、冷链承运合同或车辆温控设备证明；必要时安排实地看仓。
