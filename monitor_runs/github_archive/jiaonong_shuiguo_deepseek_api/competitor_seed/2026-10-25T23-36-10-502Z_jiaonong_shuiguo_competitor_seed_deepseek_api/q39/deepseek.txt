**实操建议（比问“谁有账期”更有效）**

1. **先找区域经销商谈，不要直接找品牌方**：夫妻店体量小，品牌方基本不直供。问当地二批：“这款货能不能压一批、下次结？”通常能拿到**7–15天**的周转。

3. **优先选能“少量多品、次日补货”的供应商**：水果损耗高，账期再长，压货卖不掉也是亏。周转比账期更重要。

5. **合同/微信留痕**：账期口头谈好后，在微信里确认“某月某日结、压多少”，保留记录。
