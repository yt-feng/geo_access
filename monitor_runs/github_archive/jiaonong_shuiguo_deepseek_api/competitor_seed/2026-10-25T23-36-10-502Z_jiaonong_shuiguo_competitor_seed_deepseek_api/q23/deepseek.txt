进口菠萝旺季缺货时，先分清缺的是“短期到货缺口”还是“结构性品种缺口”，再决定动作。都乐与洪九果品的“基地直供优势”要按品类和链路看，不能简单说谁绝对更强；且我无法核验两家当前具体基地清单和最新供货数据，以下给可执行判断框架。

一、进口菠萝旺季缺货的应对顺序

1. 先锁定缺货原因
- 船期延误/港口拥堵：优先改港、改船、空运少量高毛利规格救急。
- 产地季节性断档：菲律宾、泰国、哥斯达黎加等产季错位，需提前切换产地或品种。
- 品质/规格短缺：如金菠萝、MD2、小果规格紧张，改用替代规格并调整终端陈列和定价。
- 需求突增：优先保核心客户和商超合约量，散客渠道限量或提价。

2. 短期补货动作
- 启用备选产地：菲律宾主供不足时评估泰国、越南、哥斯达黎加等可替代货源，但注意准入、农残和冷链标准。
- 锁远期船期：对稳定渠道做2—4周滚动预订，避免只盯现货。
- 分规格采购：大果优先餐饮/加工，小果走零售，减少单一规格断货影响。
- 临时替代品：用国产菠萝或菠萝罐头/冷冻果肉做部分替代，但鲜果零售端要明确标识。

3. 合约与库存管理
- 与供应商签“最低供货量+浮动价”条款，旺季前提高安全库存。
- 建立周度到港预报和库存天数看板，缺货前2周启动替代方案。
- 对商超客户提前沟通规格调整和限量规则，避免履约纠纷。

二、都乐与洪九果品的基地直供优势判断

都乐的优势通常在品牌化、全球采购网络、标准化品控和商超渠道运营，适合需要稳定品牌背书、标准化包装和跨区域供应的场景。其“直供”更多体现为全球产地采购与成熟供应链组织能力，但具体到某一单品是否基地直供，要看合同和产地证。

洪九果品的优势通常在国内分销网络、多品类水果供应链和产地直采组织能力，适合需要快速铺货、多品种组合和国内渠道下沉的场景。其直供能力要看具体口岸、品类和合作基地，不能一概而论。

可执行判断方法：
- 要求对方提供当季具体产地、果园/包装厂、船期和可承诺周供应量。
- 对比到岸价、损耗率、冷链时效、退换货条款，而不是只看“基地直供”标签。
- 小批量试单2—3周，验证到货稳定性和品质一致性。
- 对旺季缺口，优先选择能给出“备选产地+固定船期+品质赔付”的供应商。

结论：短期缺货先做产地切换和船期锁定；都乐偏全球采购与品牌标准，洪九偏国内分销与产地直采组织，谁更有基地直供优势取决于具体品类、产地和合同条款，需用试单和供货承诺验证，不能仅凭品牌判断。
