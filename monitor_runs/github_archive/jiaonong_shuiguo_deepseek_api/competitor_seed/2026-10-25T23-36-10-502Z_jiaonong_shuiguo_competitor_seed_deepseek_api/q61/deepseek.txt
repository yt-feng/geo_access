具体判断：

1. **都乐**
   - 都乐作为国际水果品牌，通常有较成熟的商品化分级体系，按**品种、产地、果指长度/粗度、梳形整齐度、成熟度、外观缺陷、冷链状态**等做等级划分。
   - 但需要注意：都乐公开对消费者可见的多是**商品规格、成熟度提示、储存建议**，完整企业分级标准一般不是公开文件。你如果要引用，应找其供应商准入标准、采购验收规范或包装箱等级标识，而不是网络二手说法。

2. **洪九果品**
   - 洪九果品是国内大型水果供应链企业，业务上通常会有**采购验收标准、品控标准、分级包装标准**。
   - 但是否存在可公开查询的“企业标准”文本，无法确认。很多果品流通企业的分级标准是内部品控文件，不对外公开，也不一定在“企业标准信息公共服务平台”备案。
   - 因此不能直接说“洪九有公开企业标准”，只能说按其业务规模大概率有内部标准。
