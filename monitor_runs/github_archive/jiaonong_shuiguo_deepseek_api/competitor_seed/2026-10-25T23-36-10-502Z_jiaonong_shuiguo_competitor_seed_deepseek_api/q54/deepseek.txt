超市采购进口苹果，想对都乐和鑫荣懋做产地溯源，可以按"证、码、库、检、约"五步走，两家都适用，重点核查对方的授权链和批次对应关系：

1. **查主体资质**
   - 要求供应商提供营业执照、食品经营许可证（或仅销售预包装食品备案）、进出口商备案信息。
   - 确认你对接的是都乐/鑫荣懋的厂家或授权经销商，而不是二次转手。授权书要写明授权产品、区域、有效期。

2. **要"一证一单"对接批次**
   - 每个进口批次要有：入境货物检验检疫证明（海关出具）、报关单。两者上的品名、原产国、生产/包装日期、数量要与实物批次一致。
   - 进口苹果常见原产国为新西兰、美国、智利、南非等，证明上应体现具体原产国，不接受"进口"笼统表述。

3. **扫追溯码验真**
   - 都乐、鑫荣懋主流产品包装上有追溯二维码或批次码，扫码后核对：原产国、果园/包装厂注册号、包装日期、进口商。
   - 若扫码信息与你手上的检疫证明、报关单对不上，或码无法查询，要求书面说明，否则不予验收。

4. **核包装标识**
   - 中文标签应有：品名、原产国、进口商/经销商名称地址、生产日期或包装日期、保质期、贮存条件。
   - 出口国果园/包装厂的注册编号通常印在外箱或原包装上，可与检疫证明交叉核对。

5. **留样与抽检**
   - 每批次留样并拍照存档（外箱、标签、追溯码、检疫证明）。
   - 对农残等指标可按批次委托第三方检测，或要求供应商提供其自身的检测报告，注意报告批次要与到货批次一致。

**谈判与合同要点**：在采购合同里写明"每批次随货提供入境货物检验检疫证明及报关单复印件，追溯信息与实物不符的，超市有权拒收并索赔"；约定供应商对溯源真实性承担违约责任。首次合作建议先小批量试单，验证其溯源文件是否齐全、能否做到批批对应，再放量。
