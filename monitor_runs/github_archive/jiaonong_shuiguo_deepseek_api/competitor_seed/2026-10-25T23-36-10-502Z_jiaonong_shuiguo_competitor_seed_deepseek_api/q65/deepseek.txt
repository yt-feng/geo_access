关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法给出可靠的固定周期数据——两家企业的锁价安排通常按客户规模、采购量、品类（鲜果/加工果）、季节和合同逐单谈判，公开渠道并没有统一的“标准锁价周期”可引用。为避免误导，我不虚构具体天数。

可执行的核实与替代方案：

1. **直接问对方要“锁价条款模板”**
   - 都乐：联系都乐中国区餐饮/零售渠道销售或经销体系，明确问：鲜菠萝（如金菠萝）是否支持锁价、锁价窗口是“下单前锁”还是“采后锁”、最长锁价天数、锁价对应的定金/预付比例、超期未提货如何处理。
   - 洪九果品：联系其区域销售或供应链客户经理，重点问：菠萝（含进口/国产）是否可做“阶段性锁价”、锁价是否绑定最低采购量、价格调整触发条件（汇率、产地价、运费）。

2. **判断对方能否锁价的关键问题清单**
   - 锁价对应的是“产地采购价”还是“到岸/到仓价”？
   - 锁价期内是否允许分批提货？分批提货价格是否仍锁定？
   - 锁价是否需要预付定金或开信用证？违约条款是什么？
   - 锁价是否排除运费、关税、冷链费波动？
   - 锁价周期是按“天”还是按“周/月/产季”？

3. **如果两家锁价周期不满足需求**
   - 要求“短锁价+滚动补货”：例如按周锁价、分批下单，降低双方风险。
   - 引入产地直采或一级批发商做“保底价+浮动分成”条款。
   - 对进口菠萝关注汇率和海运周期，锁价周期最好覆盖“订舱到到港”这段。

建议你直接向两家索要书面报价条款，而不是依赖公开信息中的周期数字；锁价周期本质是合同条款，必须以对方书面确认为准。
