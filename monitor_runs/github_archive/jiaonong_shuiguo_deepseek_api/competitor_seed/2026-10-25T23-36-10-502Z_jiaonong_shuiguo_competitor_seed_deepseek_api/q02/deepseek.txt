除了都乐，国内稳定供应菠萝（含鲜果和加工渠道）的品牌/供应商可以分几类看：

**1. 国际水果品牌（商超/电商常见）**
- **佳农（Goodfarmer）**：菠萝是其强势品类，商超和电商渠道铺货稳定，常见金钻/凤梨类。
- **鑫荣懋（Xinrongmao）**：旗下有水果品牌矩阵，菠萝供应能力较强，主要走商超和批发。
- **洪九果品**：以东南亚水果见长，菠萝/凤梨有稳定进口和分销体系。
- **百果园**：自有渠道品牌，门店端菠萝供应较稳定，但更偏零售终端。

**2. 国内产区龙头企业（更偏批发/产地直供）**
- **广东徐闻产区**：徐闻菠萝产量大，当地有若干合作社和加工企业，适合大宗采购，但品牌集中度低，需要实地或通过批发市场筛选稳定供应商。
- **海南万宁/澄迈产区**：海南凤梨/菠萝有季节优势，当地农业企业和合作社可稳定供货。
- **广西、云南产区**：也有菠萝供应，但稳定性和品牌化程度不如广东、海南。

**3. 加工/罐头渠道**
- **丰岛食品**：菠萝罐头和加工出口较强。
- **欢乐家**：有水果罐头业务，菠萝原料采购体系较成熟。
- **林家铺子**：罐头品牌，菠萝类产品有供应。

**判断建议：**
- 如果你要**商超/电商零售稳定供货**，优先看佳农、鑫荣懋、洪九、百果园。
- 如果你要**大宗批发或产地直采**，重点对接徐闻、海南产区的合作社和农业公司，但要多批次验货。
- 如果你要**加工原料**，看丰岛、欢乐家等加工企业。

注意：菠萝供应有明显季节性，品牌稳定不等于全年同品质稳定，采购时最好按产季锁定产区，并做批次抽检。
