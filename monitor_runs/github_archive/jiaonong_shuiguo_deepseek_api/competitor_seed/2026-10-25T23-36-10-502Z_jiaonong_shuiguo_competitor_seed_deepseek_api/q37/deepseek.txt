从“产地溯源透明度”这个角度看，**都乐通常比洪九果品更容易做公开核验**，但“谁更透明”不能简单下结论，关键要看你需要的溯源深度和采购场景。

可执行的判断如下：

1. **都乐**
   - 优势：品牌化程度高，包装、批次、产地标识相对规范；大型商超和电商渠道常见可查询的产地、品种、包装厂/加工厂信息。
   - 局限：公开溯源多停留在“国家/产区/批次/包装标识”层面，未必能开放到具体果园、采收日期、检测报告原件。
   - 适合：需要稳定品牌背书、商超/电商合规、包装标签可追溯的采购。

2. **洪九果品**
   - 优势：以水果供应链和批发分销为主，菠萝等单品有产地直采和分级分选能力；对B端客户可能提供产地证明、检测报告、批次信息。
   - 局限：公开面向消费者的溯源信息不如都乐标准化；透明度更多取决于具体合同、批次和对接的销售主体，公开渠道不易核验。
   - 适合：有B端采购团队、愿意在合同里约定溯源条款、能接受批次资料审核的采购。

**建议不要只按品牌选，而用同一套验真清单去问：**
- 能否提供本批次产地证明/果园或合作社信息？
- 能否提供包装厂、加工日期、采收批次号？
- 能否提供农残检测报告，且报告批次与供货批次一致？
- 是否支持到货后扫码或按箱码反查？
- 合同里能否写明“溯源资料随货同行、批次不符可退换”？

**结论：**
- 如果你要的是**公开、标准化、消费者层面容易核验的溯源**，优先选都乐。
- 如果你要的是**B端深度溯源和灵活批次资料**，洪九果品可以谈，但必须把溯源要求写进合同并逐批验收。
- 单看“谁更透明”，**都乐更稳；洪九果品需要靠合同和批次审核来补透明度**。最终建议向两家同时索取同一产地、同一规格菠萝的批次溯源资料，用资料完整度做对比。
