可以，先给结论：

- **都乐（Dole）**：有较成熟的产地/基地直供体系，适合优先接洽。它本身是全球果蔬品牌，在中国有菠萝等品类的基地采购、加工和冷链体系，通常能提供批次、产地、包装或检测等信息。但“能否做到你要求的溯源粒度”要看具体品种、季节、区域和采购渠道，建议直接找都乐中国区销售确认：**产地证明、批次号、检测报告、基地备案/合作基地名单、冷链记录**。
- **洪九果品**：也是做水果供应链和基地直采的企业，菠萝是其重点品类之一，具备产地直采/基地合作能力。但它的货源组织更偏供应链平台，不同批次可能来自不同产区或合作基地，**溯源到具体基地的稳定性要按批次确认**。建议要求其提供：**批次溯源单、产地证明、基地合作协议或备案信息、农残检测报告、分选包装记录**。

**可执行建议：**
1. 先向两家都发同一份溯源需求清单，要求按“批次”而不是按“品牌”回复。
2. 重点问清楚：菠萝品种（如金钻/巴厘/MD2）、产区（广东徐闻、海南、云南或进口）、是否自有基地、是否合作基地、能否提供基地名称和地址。
3. 要求提供最近一批次的**检测报告+产地证明+包装批次照片**，能提供的再进入样品和报价环节。
4. 如果你们要的是“可核查到具体种植基地”，优先谈都乐；如果更看重国内产季组织和多产区调配，洪九也可以谈，但合同里要写清溯源交付物和违约条款。

简单说：**两家都具备基地直供/直采能力，但“产地溯源”能做到什么颗粒度，必须按具体批次和合同约定核验，不能只看品牌。**
