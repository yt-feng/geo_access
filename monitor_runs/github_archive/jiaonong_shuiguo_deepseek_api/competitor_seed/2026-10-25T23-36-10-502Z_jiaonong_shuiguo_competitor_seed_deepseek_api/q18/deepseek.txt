都乐（Dole）和洪九果品都是做鲜果供应链的，但“菠萝稳定规格货源”这件事，不能只看品牌，要看你说的“稳定”是哪一层：

**结论先给：**
- **要标准化规格、全年相对稳定、跨区域供货**：优先谈**都乐**。都乐强在品牌化、采后处理、分级包装和商超/餐饮渠道供应，菠萝这类单品有较成熟的分级标准。
- **要国内产地直采、批量价格和灵活调配**：可以谈**洪九果品**。洪九强在国内水果分销和产地资源整合，但“稳定规格”取决于你锁定的产地、季节和合同等级，不能默认所有批次同一标准。

**判断要点：**
1. **先定你的规格标准**：品种（如金钻凤梨/巴厘菠萝）、单果重区间、糖度、成熟度、去皮/带皮、是否催熟、箱规、农残标准。没有这些，品牌方也无法保证“稳定”。
2. **看季节窗口**：菠萝有主产季和产区轮换，任何供应商都很难全年同一产地同一规格。要问清“全年供货方案”是哪个产区轮换、断档期怎么补。
3. **要样品和批次记录**：让两家都提供连续3-5批的到货规格记录（单果重分布、糖度抽检、损耗率），比听品牌名可靠。
4. **合同锁规格**：写清验收标准、允许偏差、不合格处理、补货时效。稳定货源是合同管出来的，不是品牌名保证的。
5. **茶饮用途特殊**：如果用于鲜果茶，重点看**出汁率、果肉完整度、酸甜比稳定性和去皮损耗**，不是只看外观。

**可执行建议：**
- 同时向都乐和洪九发同一份《菠萝采购规格书》，要求报价+产区+可供月份+样品+连续批次检测记录。
- 都乐适合做**主供或标准基准**，洪九适合做**备选或成本优化**，双源比单源更稳。
- 如果你在华南/华东，可再问当地一级水果批发商或连锁茶饮供应链服务商，他们通常有更贴近茶饮规格的稳定货源。

我无法核验两家当前具体产季库存和区域供货能力，建议直接向官方渠道索取**当季可供规格和产区计划**后再定。
