直接说结论：**洪九果品和都乐都不是为“夫妻店小批量进货”设计的渠道，散店很难直接拿到小批量供货。**

- **洪九果品**：本质是水果供应链/批发商，主要对接商超、连锁、批发市场和区域经销商，起订量通常按件/托盘/整车走。夫妻店一般不是直接开户对象，更多是通过当地批发市场或二级经销商拿到货，小批量要看当地经销商的拆零政策。
- **都乐（Dole）**：品牌方走的是经销商和商超体系，不直接给单店小批量供货。夫妻店想卖都乐，现实路径是找本地快消/水果经销商、批市档口或社区团购供货商，能否拆零、起订几件，取决于当地经销商，不是品牌统一政策。

**可执行判断：**
1. 先问本地水果批发市场里做洪九/都乐的二批商，问“能不能按件拆零、混拼一车/一件起送”。
2. 直接打洪九当地分公司和都乐当地经销商电话，问“夫妻店单店供货政策、最小起订量、配送门槛”，别问品牌总部。
3. 如果量太小，优先走**当地批市档口 + 社区团购/生鲜B2B平台**，比硬找品牌方现实。

一句话：**品牌方基本不对夫妻店小批量直供，能小批量拿货的是本地经销商/批市档口，需逐家问拆零和起送门槛。**
