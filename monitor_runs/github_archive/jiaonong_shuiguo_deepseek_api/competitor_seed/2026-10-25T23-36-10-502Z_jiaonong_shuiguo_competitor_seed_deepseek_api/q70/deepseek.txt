可以找，但要把“有相关能力”和“能提供符合你要求的证明”分开判断。按公开可查的信息：

- **都乐（Dole）**：有较成熟的产地/农场溯源和品控体系，通常能提供产地信息、批次追溯、质量体系相关文件（如 GlobalG.A.P. 等认证、检测报告、规格书）。但是否能按你的项目提供**具体批次**的产地溯源报告、农残检测、品控记录，需要向都乐中国业务对接确认，不能仅凭品牌背书认定。
- **鑫荣懋**：是国内大型水果供应链企业，具备产地采购、分级包装和品控能力，通常可提供供应商审核、检测报告、批次信息等。但“产地溯源到具体果园/批次”的颗粒度，取决于是其自有基地、合作基地还是市场采购，需逐项确认。

**建议你这样核验，别只问“有没有”：**
1. 要求提供**近6个月同品类香蕉**的产地证明/采购合同关键页、批次追溯样例、农残检测报告、品控标准书。
2. 明确溯源颗粒度：国家/产区/包装厂/果园/批次，能否做到“一批一码”。
3. 问清异常处理：农残超标、到货不合格的退换货和赔付条款。
4. 两家都发**同一份供应商资料清单**，对比回复完整度；能提供样例文件的优先。

结论：**都乐和鑫荣懋大概率具备体系能力，但能否满足你的“产地溯源+品控证明”具体标准，必须让两家按批次提供文件样例后判断。** 如果对方只给品牌介绍、不给批次文件，就不应视为满足要求。
