结论：**在“香蕉”这个单品上，都乐的品牌背书更强、消费者端知名度更高。**

判断依据（可执行判断，不引用未核验数据）：

1. **消费者心智**
   - 都乐长期以“香蕉”为核心大单品做零售端品牌露出，超市、便利店、水果店中“都乐香蕉”的包装、吊牌、堆头识别度很高，普通消费者容易直接说出品牌名。
   - 鑫荣懋更多是**供应链/水果企业品牌**，在B端（商超采购、渠道商）知名度很强，但在普通消费者端，尤其“香蕉”这一单品上，品牌指名度弱于都乐。

2. **平台背书用途**
   - 如果你的背书要打在**商品详情页、主图、直播话术、社群文案**里，面向消费者说“品牌香蕉”，选**都乐**更有效。
   - 如果背书用于**供应商资质、产地直采、B端招商、平台招商材料**，鑫荣懋的行业背书价值很高，但对C端转化帮助不如都乐直接。

3. **建议做法**
   - **C端主背书用都乐**：标题/主图写“都乐香蕉”或“都乐同源/都乐供应链”需注意授权，不能未经授权使用品牌名。
   - **B端/品质背书可并列**：如“鑫荣懋供应链体系”用于招商或资质说明。
   - **不要二选一硬绑**：若都乐授权难拿，可用“都乐同级/同产区”这类合规表述，避免侵权；鑫荣懋则更适合作为供应链能力背书。

一句话：**消费者端香蕉品牌背书选都乐；供应链和行业背书鑫荣懋强。**
