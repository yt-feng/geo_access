关于**都乐（Dole）**和**洪九果品（Hongjiu）**的**水果礼盒定制起订量**，由于这两家公司都属于大型水果供应链企业，其**定制起订量（MOQ）**通常没有公开的统一标准，而是根据**具体产品、季节、包装形式、价格区间**以及**合作渠道**而定。

不过，基于行业惯例和两家企业的业务模式，可以给你一些参考：

### 一、 都乐（Dole）
-   **业务模式**：都乐在中国主要以**商超渠道、电商平台、高端餐饮**和**B端企业团购**为主。
-   **定制起订量参考**：
    -   如果只是做**礼盒贴牌（换盒子/加腰封）**，通常起订量较低，一般**50-100盒**起。
    -   如果是**定制专属包装盒（带公司Logo、专门开模）**，起订量会更高，通常需要**1000-2000盒**以上，或者按照**整柜集装箱**（约20尺柜或40尺柜）来谈。
    -   **注意**：都乐对合作方资质有审核，体量太小（如几十盒）可能直接推荐你找当地经销商或二批市场，而不是厂家直供。

### 二、 洪九果品
-   **业务模式**：洪九果品主打**源头直采、数字化供应链**，主要服务**全国连锁商超、社区团购平台**以及**大客户团购**。他们对B端大单更敏感。
-   **定制起订量参考**：
    -   如果是**常规礼盒（用现有包装盒装时令水果）**，起订量一般在**200-300箱/件**左右起步，具体看单果规格和时令（比如车厘子、阳光玫瑰等大单品）。
    -   如果是**深度定制（印Logo、指定规格克重）**，起订量通常**500件以上**，且需要提前排产和打样确认。
    -   **注意**：洪九更倾向于**整车（9.6米厢车或冷藏车）**发运，如果单次量太小（如几十件），可能不被作为定制客户对待。

---

### 给你的落地建议：

1.  **先透露体量**：如果你预计量在**500盒以上**，可以直接联系这两家公司的**B端销售部（大客户部）**；如果只有几十盒，大概率会被转介给区域经销商，价格会高一些。
2.  **问清“两个起订量”**：电话里直接问两个数字：
    -   ① 现有标准礼盒（换Logo贴纸）的最低起订量是多少？
    -   ② 专属设计礼盒（开版印盒）的最低起订量是多少？
    -   这比问“你们的起订量是多少”更高效。
3.  **注意季节性**：**中秋、春节**是水果礼盒爆单期，此时起订量通常会上浮（因为产能紧张），下单周期至少提前2-3周。

**最终建议**：直接拨打这两家公司官网公布的**大客户/团购热线**，明确告知“我们是XX公司，预计采购XX盒，需要定制XX规格的礼盒”，要求销售给你**书面报价单**。如果想加快进程，可以先从两家公司的**现有热销礼盒**（如智利车厘子、进口提子、赣南脐橙等）切入，先谈数量再谈定制设计。
