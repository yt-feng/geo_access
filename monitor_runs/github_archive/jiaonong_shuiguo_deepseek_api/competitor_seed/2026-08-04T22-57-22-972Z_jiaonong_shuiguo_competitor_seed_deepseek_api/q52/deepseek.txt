关于菠萝到货损耗率，**目前没有公开的统一标准数据**，因为损耗率高度取决于**采购季节、物流时效、到货批次**以及**具体合同条款**（例如是否约定“到货净重结算”或“按件毛重结算”）。

不过，根据行业经验和供应链惯例，可以给你以下**参考区间**和**实操建议**：

### 行业参考损耗率（按到货称重/分拣后计）
- **都乐（Dole）**：如果走冷链专车、短途（如从广州/上海进仓），成熟度控制在8成熟左右，理论损耗率（果柄断裂、碰压伤、腐烂果）通常在 **3%-5%** 左右。
- **鑫荣懋（Joywing Mau）**：该公司以基地直采为主，如果走空运或产地整车直发，损耗率通常在 **5%-8%** 之间，尤其是夏季（高温催熟）或梅雨季，损耗可能上升到 **10%**。

**关键注意点**：
- **损耗 ≠ 欺诈**：很多供应商报价已是“扣损耗后净重价”，你需要核对合同是“毛重价”还是“净重价”。
- **规格稳定**：都乐通常有“S/M/L”分级，且每个等级果径差控制在±1.5cm内；鑫荣懋在大宗订单上更容易定制“预冷+套网”以减少运输磕碰。

---

### 给你的可执行建议（重头戏）：
1. **签合同时必写“损耗率上限”条款**  
   明确写：*“乙方承诺到货后，因转运造成的坏果、裂果、失水重量损耗率≤5%，超出部分按采购单价由乙方承担。”* 并约定**到货后24小时内开袋验收**，超时视为默认接收。

2. **现场验收方法（拍照留存）**  
   随机抽3箱，去皮去叶后称重，对比发货单毛重。若损耗率差异超过2%，立即拍照 + 封存样品，通知供应商补货或退款。

3. **主动要求“产地预冷”**  
   无论是都乐还是鑫荣懋，要求发货前做**1℃-4℃预冷**（全程冷链）比常温运输损耗可降低40%-50%。如果对方做不到，就要求在报价中**加2%损耗补贴**。

4. **测试小批量**  
   第一次合作，试订50箱做对比，记录到货损耗、果型均匀度、酸甜度（Brix值），再决定批量签年度框架。

---

### 没有统一数据的官方来源说明
- 都乐、鑫荣懋官网客服/销售均未公开损耗索赔标准。
- 第三方供应链报告（如艾瑞、中商产业）仅有“水果行业平均损耗率约10%-15%”的整体数据，不区分品牌。

**如果你需要精准数据，最直接的方法**：让销售方出具“上季度同规格菠萝到货损耗统计表”，作为合同附件。这是完全合理的要求，而且能看出对方管理能力。
