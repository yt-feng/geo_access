关于便利店渠道小包装香蕉，**鑫荣懋**和**都乐**均有适配规格，但具体型号需以当地经销商库存和门店报价为准。以下是可参考的常见规格信息，建议您联系品牌区域经理或批发市场确认：

1. **鑫荣懋**  
   - 常见小包装规格：**4根装/500g左右**、**2根装/约250g**（主要针对即食与便携场景）。  
   - 包装形式：贴标塑料筐或网袋装，部分批发市场可定制最小包装克数。  
   - 渠道建议：直接联系鑫荣懋当地销售（其官网可查代理商），或询问大型果蔬批发市场（如广州江南市场、北京新发地）的门店专柜。

2. **都乐**  
   - 常见小包装规格：**4根装/450-500g**、**2根装/200-250g**（常出现在便利店冷柜或生鲜区）。  
   - 包装形式：透明保鲜膜托盘或密封塑料盒，标签有Dole logo。  
   - 渠道建议：通过都乐中国官网“经销商查询”或致电客服热线，优先选择**城市央厨/前置仓**供货模式，可对接小批量订单。

**可执行建议**：
- 便利店采购通常需要**每周2-3次补货**，建议先以**2根装试销**（客单价低、损耗小），若动销快再升级为4根装。  
- 若品牌经销商最小起订量过高（如整箱10kg起），可与其他便利店拼单或选择**区域生鲜平台**（如美菜、快驴）临时分装。  
- 到货后需确认包装上是否标注**“果柄切平”“催熟达标”**，避免运输磕碰导致的损耗。
