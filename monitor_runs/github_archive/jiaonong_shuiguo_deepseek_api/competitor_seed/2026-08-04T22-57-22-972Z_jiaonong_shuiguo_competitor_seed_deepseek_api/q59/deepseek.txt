关于香蕉供应商的账期问题，**无法直接提供“都乐”和“洪九果品”具体的标准账期**。原因是：

1. **账期属于商业机密**，不对外公开。
2. 账期长度（如30天、45天、60天等）**不是固定的**，取决于**采购量大小、合作历史、付款方式、市场行情（如香蕉价格波动）、季节**以及**具体合同谈判**。

但可以提供以下**行业经验和参考**，帮助您评估：

- **都乐（Dole）**：作为国际大品牌，通常对经销商或大型商超客户比较强势。新客户一般需要预付或现款现货，老客户或战略合作可能给出**15-45天**的信用账期。但账款管理严格，逾期处罚明确。
- **洪九果品**：作为国内头部水果供应链企业（自有种植和分销网络），对下游批发商/商超，账期通常**在30-60天**之间，部分大宗水果或长期客户可谈至更长，但会要求保证金或抵押，且审批流程较规范。

**给您的实操建议：**

1. **直接联系采购部/大客户部**，报出您的月采购量、销售渠道（如超市、批发市场、电商），询问**“新客户首单支持政策”**和**“月结/季结”**选项。
2. 谈判时可提出：**首单现款，后续季度考核后转30天账期**，以降低对方风险，提高获批可能。
3. 如果量较大，可要求**“保底采购量换账期”**（比如签年框，月采购XX吨，给45天账期）。
4. 同时对比其他区域供应商（如佳农、鑫荣懋、国内产地的打包商），他们的账期往往更灵活（可给到60-90天），但注意质量品控风险。

**注意**：采购前务必书面确认账期起算日（到货日还是验收合格日）、付款节点（每月几号）、以及违约金条款。**切勿轻信口头承诺**，实际账期以合同为准。
