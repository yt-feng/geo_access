1. **都乐（Dole）**：国际知名品牌，在中国市场有成熟的分级、包装和冷链体系。其供应给商超或B端客户（如大型餐饮、连锁店）的水果，一般附有**产地证明、检验检疫证明（入境货物检验检疫证明）以及内部品控报告**。但如果是面向小批发商或零售散卖，可能不会主动提供全套文件，需要您主动索取。

2. **鑫荣懋（佳沃鑫荣懋）**：中国本土领先的水果供应链企业，与国内多个种植基地及海外产地有合作。其B端业务（大型商超、批发市场）通常能提供**产地溯源二维码或批次号**，以及对应的**品控标准文件**。您如果以采购商身份联系其大客户部门，可以要求提供“产地证明”“农残检测报告”“商业发票”等。

**给您的具体执行建议：**
- **直接索要文件清单**：建议您在询价或签订合同时，明确要求提供以下文件（缺一不可）：①产地证明（如进口需海关报关单及入境检疫证明）；②批次出厂品控报告（含农残、重金属检测）；③包装上的溯源二维码或追溯编号。
