在超市采购进口苹果时，**都乐（Dole）** 和 **鑫荣懋（XinRongMao）** 的产地溯源，主要分为“官方查验”和“实物辅助”两步。以下是可执行的操作方法：

### 一、最直接的方法：看包装与标签（唯一硬性凭证）
进口水果必须有**中文标签**（中国检验检疫要求），这是根溯源的关键。

- **看“原产国”**：
    - 都乐（Dole）进口苹果通常来自**美国（华盛顿州）、智利、新西兰**。
    - 鑫荣懋（XinRongMao）因是综合水果服务商，进口苹果常来自**新西兰（爱妃、皇后）、美国、南非、智利**。
- **看“生产商/包装厂”编号**：标签上会有英文字母+数字的组合，这是海外果园/包装厂在出口国的注册号（如新西兰的PFR编号）。可通过该编号在当地官方农业部门官网反查该包装厂是否在该国注册。

### 二、官方溯源码（最可靠）
现在正规进口水果上均有**可撕开的防伪溯源码**（贴在中文标签下方或旁边）。

1. **扫码后看域名**：务必看扫码后弹出的网址是否为官方溯源系统（如中国海关总署的**“单一窗口”**或**跨境通**平台，以及进口商自建的溯源系统）。如果扫码后跳转到乱七八糟的第三方商城，则为可疑。
2. **核对报关信息**：如果标签上有**报关单号**或**卫生证书号**，可通过**“海关总署”官网 → 办事服务 → 进出口商品检验** 输入该编号核查报关记录。

### 三、根据品牌特性针对性操作
- **都乐（Dole）**：
    - 查看其官方公众号或官网的“产品溯源”入口，输入**包装标签上的PLU码（4位数或5位数）**。例如，美国产的嘎啦苹果PLU码通常是**4133**（普通）或**3113**（有机），通过PLU码可核对品种与种植方式，这本身就是一种溯源特征。
- **鑫荣懋（XinRongMao）**：
    - 鑫荣懋拥有全产业链追溯系统，其进口水果的包装箱上通常有**“云追溯”或“一物一码”**。撕开标签二维码，进入其官方小程序/公众号，输入包装箱侧面的**箱码（Batch No.）**，可查到具体的**海外产区、分拣日期、到港时间**。

### 四、现场辅助验证（无需工具）
1. **看果梗与果皮**：长途海运的进口苹果都是**打蜡**（食用蜡）或**气调保鲜**的，果皮光亮、果梗翠绿且湿润。
2. **看包装箱材质**：进口原箱的纸箱通常较硬，色调偏**土黄色（牛皮纸色）**，印刷清晰且无重影。如果纸箱颜色发白、印刷模糊，很可能是国内二次分装的仿冒箱。

### 五、最强提醒（避坑）
- **不要只凭品牌logo**：都乐和鑫荣懋在中国有本地种植基地（如鑫荣懋在新疆、山东有合作果园）。**如果标签显示“中国产”，那就不属于进口溯源范畴**，不要被“品牌名”误导为“进口”。
- **正规商超（盒马、山姆、沃尔玛）采购时**，可直接要求供应商出示**该批次的海关《入境货物检验检疫证明》复印件**，正本在商超总部留存，复印件上会明确写清**原产国、唛头、生产批号**。

---

**总结一句话**：索要**海关检验检疫证明**最权威，其次**扫溯源码看官方域名**，辅助**核对PLU码和包装厂编号**。只要能在这三个环节套上对应信息，基本可确认真实进口溯源。
