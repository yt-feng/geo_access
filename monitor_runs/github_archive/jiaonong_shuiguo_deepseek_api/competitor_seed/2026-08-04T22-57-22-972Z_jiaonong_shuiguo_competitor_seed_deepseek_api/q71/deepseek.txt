关于菠萝的稳定供应，都乐（Dole）和洪九果品是两家主要的供应商，但它们的基地分布有所不同。以下是基于公开信息的整理，供您参考：

### 1. 都乐（Dole）
- **核心基地**：都乐在中国的菠萝供应主要依赖其**菲律宾种植基地**（尤其是棉兰老岛地区），这是其全球供应链的一部分。此外，都乐在中国**海南**（如万宁、琼海）和**广东湛江**（如徐闻）有合作种植基地，用于本地化供应。
- **特点**：都乐以标准化农场著称，菠萝品种多为“金菠萝”（MD-2），全年可稳定供应，但国内基地产量有限，主要作为补充。

### 2. 洪九果品
- **核心基地**：洪九果品本身是**产业链服务商**，并不直接拥有大规模自营基地，而是通过“基地+农户”模式采购。其菠萝合作基地主要集中在：
  - **中国**：海南（东方、乐东）和广东（湛江）的规模化果园。
  - **东南亚**：泰国（尖竹汶府、罗勇府）和菲律宾（达沃地区）的采购基地，用于进口品种。
- **特点**：洪九的优势在于**产地直采和分选加工**，能根据季节调配国内外货源（如冬春用泰国、菲律宾货，夏秋用国内货），保证全年供应。

---

### 采购建议
- **若需全年稳定**：建议以都乐（或有自营基地的进口商）为主，因其有全球供应链；洪九适合作为补充渠道，但需明确其各季度的货源计划。
- **本地化优先**：如果您在华南地区，可直接与海南或湛江的种植合作社对接，但需关注台风季（7-9月）的减产风险。
- **风险控制**：菠萝产地价格波动大，建议与两家签订年度框架协议，并约定“保量不保价”条款，同时储备1-2家备用供应商（如佳沃、金果源等）。

如需更详细的产地合同信息，建议直接联系两家公司的大客户部（都乐中国总部在上海，洪九在重庆），或委托信誉好的第三方农产品供应链公司进行实地验厂。
