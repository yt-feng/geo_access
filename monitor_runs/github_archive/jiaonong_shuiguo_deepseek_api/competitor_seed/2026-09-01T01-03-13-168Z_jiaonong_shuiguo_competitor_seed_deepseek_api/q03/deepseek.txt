关于洪九果品和鑫荣懋的香蕉质量及到货损耗对比，我无法提供最新的实时数据或内部统计数据，因为这两家公司的具体供应链损耗率属于商业机密，且不同批次、不同运输路线的表现差异较大。

不过，我可以给你一些基于行业公开信息的判断逻辑，供你参考：

**1. 品牌定位与业务模式差异：**
- **洪九果品**：以“进口水果+国产精品”为主，尤其在榴莲、山竹等品类上规模较大。香蕉并非其绝对核心单品，但作为日常水果也有覆盖。其供应链特点是基地直采（尤其东南亚产地） + 自建加工配送中心。
- **鑫荣懋**：是中国最大的水果供应链企业之一，香蕉是它的核心优势品类之一。它深耕香蕉全产业链，从海外农场（如菲律宾、厄瓜多尔）到国内分选、催熟、冷链物流体系非常成熟，对香蕉的催熟工艺和货架期管理有较强技术积累。

**2. 到货损耗的关键因素：**
损耗率主要取决于**运输时间、冷链温度控制、催熟工艺**和**终端分拣能力**。
- 历史上，鑫荣懋因香蕉业务规模大，其催熟库和冷链管理标准化程度较高，理论上在可控损耗（如腐烂、黑斑）方面经验更丰富。
- 洪九果品近年也在强化产地直采和数字化的分选系统，但香蕉业务规模相对鑫荣懋小，其损耗控制能力可能因产区（如云南蕉、进口蕉）不同而有差异。

**3. 实际判断建议：**
- 如果你是想采购香蕉，建议**不要只看品牌**，而是**重点考核具体批次**：向供应商索要最近3个月的平均到货损耗率报告（如有），并要求做实物抽检。
- 可以比较两家在**你所在城市或区域**的仓储点距离和配送时效。距离越近、转运次数越少，损耗通常越低。
- 建议小批量试单：分别采购一车或几箱，对比到货时的外观、硬度、糖度及坏果率，这是最直接可靠的方式。

**总结：** 仅从品牌看，鑫荣懋在香蕉品类的专业性和规模上可能更具稳定性优势；但洪九果品在产源直采上有其特色，只是香蕉非其最强项。具体损耗高低请以实际到货检验为准。
