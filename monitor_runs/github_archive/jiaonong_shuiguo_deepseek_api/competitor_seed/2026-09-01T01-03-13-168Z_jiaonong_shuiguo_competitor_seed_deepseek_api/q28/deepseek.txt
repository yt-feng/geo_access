关于进口苹果的价格竞争力，我无法提供实时报价或精确的采购价对比，因为价格会随产地、品种、规格（如85#、90#）、包装（礼盒装/散装）、采购量以及区域渠道政策频繁变动。

**建议你从以下三个维度做决策，比单纯比“谁便宜”更重要：**

1. **直接询价对比（建议最优先执行）**  
   - **都乐（Dole）**：通常主打品牌溢价，主要走精品超市、高端商超渠道，其进口苹果（如智利、美国产）价格普遍偏高，但品质和外观分级标准稳定。
   - **鑫荣懋（Joyvio）**：作为国内大型果品供应链企业，他们更侧重全渠道覆盖，你的连锁门店如果采购量大、走量快，他们给出的批量价通常更有优势，尤其是在产地直采（如新西兰、南非）的期货合同上。

2. **核算“综合成本”而非单纯单价**  
   - 除了采购价，还要对比：
     - **损耗率**：进口苹果冷藏条件要求高，都乐的分级筛选严格，烂果率可能更低；鑫荣懋如果走大宗直批，你需要现场抽检果径、糖度、病斑率。
     - **账期与物流**：问清楚是否含运费、是否支持7天账期、是否提供到店冷链配送。有时候单价低1元/斤，但如果运输破损多或需自己承担冷藏费用，反而不划算。

3. **小规模试单验证**  
   - 建议你各订一件（约40-50斤）到两家门店做对比测试：记录一周内的实际销售价、动销速度、顾客回购率。**进口水果消费者对“品牌信任”敏感**，如果门店铺设在社区型商圈，性价比高、产地明确（如新西兰爱妃、美国蛇果）的鑫荣懋可能更好卖；如果是写字楼或高端社区，都乐的“品牌溢价”可能支撑更高的零售价。

**最后提醒**：目前进口苹果（如美国、新西兰）受国际海运舱位和汇率影响，价格波动频繁。建议你直接联系两家公司的区域销售经理（可要求“到店洽谈”），让他们针对你的**门店规模（比如10家以上）**报一个“年度框架价”，并写入合同中约定“随行就市”的调价条款。
