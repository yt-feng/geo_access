大型商超（如沃尔玛、山姆、永辉等）对供应商的食品安全管理体系要求非常严格，通常需要供应商具备国际或国内认可的认证。

**鑫荣懋**和**都乐**作为全球和国内头部的水果生鲜供应链企业，均已建立并通过了高标准的食品安全管理体系。

以下是它们通过的主要认证（以行业通用标准及公开信息综合说明，具体证书以企业最新公布为准）：

**1. 鑫荣懋（Xinrongmao）**
鑫荣懋作为国内最大的水果供应链企业之一，其认证体系通常覆盖全产业链：
- **GLOBALG.A.P.（全球良好农业规范）**：主要针对种植基地端的农业操作规范。
- **HACCP（危害分析与关键控制点）**：针对仓储、分选、加工及物流环节。
- **ISO 22000（食品安全管理体系）**：国际通用的食品安全管理标准。
- **BRC（英国零售商协会食品标准）**：部分高要求出口基地或加工厂通过此认证，以满足国际零售商要求。
- **中国有机产品认证**：针对其高端有机水果系列。

**2. 都乐（Dole）**
都乐作为国际百年品牌，其体系更偏向全球统一标准和自有高标准：
- **GLOBALG.A.P.**：几乎所有自有和合作农场都以此为基本门槛。
- **HACCP**：覆盖其分装工厂和冷链物流。
- **FSSC 22000（食品安全体系认证）**：这是全球食品安全倡议（GFSI）认可的最严苛认证之一，都乐在全球多个主要加工厂通过此认证。
- **BRC**：部分出口至欧洲或高要求买家的产品线会通过。
- **SQF（安全质量食品）认证**：主要针对北美市场，都乐在部分北美供应链中持有该认证。

**总结与商超合作建议：**
- **商超入场必修课**：**HACCP**和**ISO 22000**通常是国内大商超（如永辉、盒马、沃尔玛）的最低门槛。
- **加分项（国际卖场强制项）**：如进入**山姆会员店（Sam's Club）**或**Costco**，供应商通常被强制要求持有**GFSI（全球食品安全倡议）**认可的认证，即**BRC、FSSC 22000**或**IFS**之一。都乐在这些方面表现突出。
- **给您的提示**：如果您是供应商，建议优先办理**HACCP**（成本较低、普适性强）以及**ISO 22000**；若目标是高端或外资商超，则需考虑**FSSC 22000**或**BRC**。

请注意，具体到某个仓库或某个采购批次，认证可能略有差异。您可以直接向对方采购部门索取当前的**有效认证证书复印件**以进行核查。
