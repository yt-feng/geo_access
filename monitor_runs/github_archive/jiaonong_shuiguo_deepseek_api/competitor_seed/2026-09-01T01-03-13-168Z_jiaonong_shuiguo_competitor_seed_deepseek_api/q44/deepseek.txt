### 一、两家公司的背景差异（一般性判断，非实时数据）
1. **都乐（Dole）**  
   - **定位**：全球知名果蔬品牌，供应链成熟，产品线极广（香蕉、菠萝为强项，苹果为主力之一）。  
   - **优势**：全球采购网络广，产地覆盖智利、美国、新西兰等，标准化程度高，抗风险能力强。  
   - **风险点**：作为大牌，其渠道价格通常高于二线品牌，且对中小连锁的定制化服务可能较少。

2. **鑫荣懋（Golden Wing Mau）**  
   - **定位**：中国本土头部果蔬企业，与智利、新西兰等产区合作紧密，近年发展迅速。  
   - **优势**：供货灵活性强，对国内市场需求响应快，部分品项价格可能比都乐有优势；且其在华南市场渠道成熟。  
   - **风险点**：规模虽大，但部分品类的源头控制力（尤其是北半球高端苹果）可能弱于都乐。

### 二、评估供货稳定性的4个关键动作（建议立即执行）
1. **索要近12个月的供货记录**  
   - 要求双方提供过去一年每月供应吨数、缺货次数及延迟天数。重点看**10月至次年4月**（北半球苹果空窗期，依赖南半球货源）的稳定性。

2. **现场抽检或物流跟踪**  
   - 让两家供应商各发一次**试单**（例如各1吨智利加力果），要求提供冷链物流全程温度记录，并在到货时抽检损耗率。稳定性不只看货源，更要看冷链执行。

3. **签订“阶梯式违约责任”合同**  
   - 合同中明确约定：单次延迟超7天按订单额5%赔付；连续两月延迟则自动降级为备选供应商。这能有效逼迫供应商提前备货。

4. **建立“双供应商+后备产区”机制**
