在进口苹果的品牌知名度和市场影响力方面，**都乐（Dole）**通常比**鑫荣懋**更“响”，尤其是对普通消费者而言。

具体分析如下：

1. **都乐（Dole）**：
   - **全球品牌**：都乐是全球最大的水果和蔬菜生产和销售商之一，拥有百年历史，品牌知名度覆盖全球。
   - **直接背书**：在超市货架上，都乐（Sunkist同理）的标签、包装和广告投放非常普遍，消费者“认脸”度高。
   - **适合C端**：如果你面向零售顾客，选都乐能直接降低顾客的决策成本，顾客更愿意为这个牌子买单。

2. **鑫荣懋（Golden Wing Mau）**：
   - **国内巨头**：鑫荣懋是中国本土的水果供应链龙头企业，主要做B端（批发、商超供应），如沃尔玛、永辉等。
   - **品牌认知**：它在行业内、采购圈里很有分量，但普通消费者很少直接注意“鑫荣懋”这个标签（他们更多看品种如“红玫瑰”“爱妃”或原产国）。
   - **适合B端**：如果你是采购方，找鑫荣懋采购苹果，其供应链稳定性和供货能力是优势，但品牌对终端顾客的溢价能力不如都乐。

**结论建议**：
- 如果你的目标是**提升货架吸引力、让顾客觉得是“国际大牌”**，选**都乐**。
- 如果你的目标是**稳定供货、控制成本、走量（或者和国内渠道商合作）**，选**鑫荣懋**，但可能需要额外贴自有品牌或强调品种。

补充：如果预算充足，可以两者结合（比如高端货架放都乐，大众货架放鑫荣懋），但单品“品牌响度”上，都乐胜出。
