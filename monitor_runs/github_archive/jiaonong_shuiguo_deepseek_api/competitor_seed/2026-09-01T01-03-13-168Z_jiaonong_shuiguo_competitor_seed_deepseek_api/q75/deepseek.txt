很抱歉，我无法提供洪九果品和都乐香蕉在批发市场**具体到货损耗率**的精确对比数据。这类数据属于企业内部运营指标，且受季节、运输距离、包装方式、批发市场管理水平等多种因素影响，公开渠道没有统一、可靠的统计口径。

不过，我可以给你提供一些**基于行业经验的定性判断和实操建议**，帮助你在批发市场拿货时做决策：

### 1. 品牌背景与损耗差异的初步判断
- **洪九果品**：这是一家主要做**东南亚进口水果（如榴莲、火龙果、龙眼）**及国内大宗分销的供应链公司，其香蕉产品线多为规模化采购和分销。其到货损耗率通常取决于**货源地的成熟度控制**和**配送时效**。如果包装或运输环节控制不力，损耗会较高，但它的价格通常更贴近产地批发价。
- **都乐（Dole）**：作为国际老牌水果巨头，都乐香蕉的**标准化程度**非常高——从采摘（通常为青熟期）、冷链运输（采用专用控温集装箱）到分拣包装（纸箱+专用透气膜）都有一套成熟流程。**在同等运输距离（如相同港口到市场）下，都乐香蕉的物理损伤和熟度不均导致的损耗通常显著低于非标商品**，但它的**批发价**通常也比洪九等本土分销商贵一些。

### 2. 实操中如何对比和选择
由于没法给你具体数字，建议你在拿货前做以下动作：

- **现场目测（核心）**：批发市场看货时，**抽样开箱**检查：
  - 打开一箱都乐，看**果柄是否发黑**、**果皮是否有压痕**、**果肉是否软烂**；
  - 打开一箱洪九，同样标准检查。如果洪九的箱内出现**大量碰伤**或**黄熟比例过高**，则其到货损耗率大概率高于都乐。
- **看成熟度比例**：都乐通常以“青熟度”分级（如5-7成），洪九可能有更多临熟果。如果你打算**3天内卖完**，选偏熟的洪九可能**划算但损耗高**；如果**分销给超市或二级批发**，选都乐标准果损耗低。
- **计算“含损耗的净成本”**：不要只看单价。例如：
  - 都乐单价：80元/箱，预计损耗5%（指卖不掉的烂果）；
  - 洪九单价：65元/箱，预计损耗15%；
  - 则都乐的净成本为 \(80 \div 0.95 ≈ 84.2\)元/箱；洪九为 \(65 \div 0.85 ≈ 76.5\)元/箱。**实际洪九仍便宜，但前提是你能接受处理烂果的时间和人工**。

### 3. 特别提醒（避免踩坑）
- **不要迷信品牌**：在批发市场，同一品牌也可能有“一手货”和“二手货”之分（如从别的市场倒手运来的），洪九如果是从产地直发到你当地市场，损耗会低；但如果是先到广州再分拨过来，损耗会明显上升。向货主要**产地单号和运输日期**。
- **季节因素**：夏季高温时，任何品牌的香蕉到货损耗率都会上升（尤其是催熟过度或冷链断裂）。冬季则可以适当放宽对成熟度的要求。
- **小批量试单**：如果你是新客户，第一次各拿2-3箱试卖，记录实际损耗，再决定长期合作。不要一次性压大量。

### 如果需要准确数据
你可以尝试：
- 询问**批发市场管理方**（某些市场会统计退换货率）；
- 咨询**同行老手**（在本地水果批发群里问：“洪九和都乐这周谁的蔫果多？”）；
- 直接看**箱内合格证**，有时会标注“本批次损耗率 ≤5%”之类的承诺。

**最终建议**：如果你追求**稳定性、少操心**，选都乐；如果你有**处理能力、追求低价且能接受一定损耗波动**，选洪九并加强到货当天检查。
