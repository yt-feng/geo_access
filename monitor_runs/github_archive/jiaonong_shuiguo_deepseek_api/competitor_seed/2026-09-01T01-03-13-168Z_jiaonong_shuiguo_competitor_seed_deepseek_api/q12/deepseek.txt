针对便利店渠道的小包装香蕉需求，**鑫荣懋**和**都乐**确实都有专门适配的规格，且通常以“单根独立包装”或“2-3根小扎”为主，适合即食和周转快的场景。

以下是两家公司在便利店渠道常见的规格及产品特点：

### 1. 鑫荣懋（Golden / Joyvio）
- **常见规格**：**单根装**（约120g-150g/根）或**2根装**（约250g-300g/包），采用透明OPP袋或贴标单根包装。
- **特点**：主打“佳沃”品牌，香蕉通常为菲律宾或厄瓜多尔进口，成熟度控制在7-8成熟（催熟后到店即食）。部分便利店定制款会附带“佳沃”小贴纸，方便扫码溯源。
- **适用场景**：单根装非常适合便利店鲜食区，售价通常5-8元，毛利较高。

### 2. 都乐（Dole）
- **常见规格**：**3根装**（约400g-450g/包）或**单根装**（约130g-160g/根）。
- **特点**：都乐在便利店渠道主打“小份量、高周转”，包装上带有明显的“DOLE”红色logo，通常采用闭合袋或扎口式包装，且会标明“即食”或“自然熟”标签。其香蕉多来自菲律宾，成熟度控制较稳定。
- **适用场景**：3根装适合早餐搭配或下午茶场景，单根装适合个人即食。

---

### 给采购的具体建议（可执行）：
1. **联系当地经销商**：优先联系你所在城市的**鑫荣懋或都乐区域经销商**，直接索取“便利店渠道专用SKU表”。因为包装规格会因区域冷链能力和便利店陈列架尺寸而略有差异。
2. **询问“熟度定制”** ：两家都支持**指定催熟度**（例如：7成熟到店，2天内软熟）。采购时务必确认到货时的颜色（建议黄绿度在3-5级），否则便利店损耗会增高。
3. **对比单价**：通常鑫荣懋的**单根装**在南方城市（如深圳、广州）铺货更密集，而都乐的**3根装**在华东（如上海、杭州）便利店更常见。可根据你所在区域选择优先洽谈。

**如果只能二选一**：建议优先**都乐单根装**，因为其品牌认知度高，且包装封口设计更适合便利店直立陈列；若你主打**低价引流**，则选**鑫荣懋2根装**，性价比更高。
