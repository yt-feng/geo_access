大型商超（如沃尔玛、山姆、盒马、永辉等）对供应商的食品安全资质通常要求非常严格，核心包括**ISO 22000（食品安全管理体系）**、**HACCP（危害分析与关键控制点）**，以及针对果蔬类产品的**GLOBALG.A.P.（全球良好农业规范）**。

针对您提到的鑫荣懋（中国大型水果供应链企业）和都乐（Dole，全球水果巨头），它们作为头部供应商，通常具备以下层面的资质：

**1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）**
- **国际通行认证**：通常持有**GLOBALG.A.P.（全球良好农业规范）** 认证，这是其对接国际商超（如山姆、Costco）的标配。
- **国内质量管理**：持有**ISO 9001质量管理体系**和**ISO 22000食品安全管理体系**认证。
- **专项认证**：如果其产品涉及有机水果，还会持有**中国有机产品认证**。此外，其供应链物流环节通常有相应的**HACCP**控制文件。
- **商超准入**：由于鑫荣懋是沃尔玛、山姆、永辉、盒马等的主要供应商，其通常已通过这些商超的**供应商审核（如社会责任审核和食品安全飞行检查）**。

**2. 都乐（Dole）**
- **源头控制**：都乐作为全球品牌，其自有农场和合作农场普遍持有**GLOBALG.A.P.**（全球良好农业规范）认证，这是其出口到欧美和国内高端商超的基础。
- **加工与物流**：其在中国的加工配送中心（如上海、青岛等地）持有**BRCGS（英国零售商协会全球标准）**或**IFS（国际食品标准）**认证，这是欧洲零售巨头的高门槛认证，国内高端商超（如山姆会员店）非常认可。
- **专业认证**：其产品线中的香蕉、菠萝等通常附带**雨林联盟（Rainforest Alliance）认证**或**Fair Trade（公平贸易）认证**，虽然这属于可持续认证，但在高端商超的供应商评估中属于加分项。

**给您的建议：**
如果您是**采购方**，在引入这两家供应商时，可以直接要求对方提供**“三证一报告”**：
1. **营业执照**（含食品经营/生产许可）。
2. **ISO 22000或HACCP体系认证证书**（复印件加盖公章）。
3. **GLOBALG.A.P.证书**（如果是直采基地）。
4. **当批次农残检测报告**（需由第三方权威机构如SGS、华测出具）。

**特别提醒**：由于认证证书有有效期且范围可能变动，建议您在采购合同中明确约定“证书有效性失效或范围不符时，供应商需承担违约责任”。如果您需要具体核验某一张证书的真伪，请将证书编号发给我，我可以指导您去国家认监委官网查询。
