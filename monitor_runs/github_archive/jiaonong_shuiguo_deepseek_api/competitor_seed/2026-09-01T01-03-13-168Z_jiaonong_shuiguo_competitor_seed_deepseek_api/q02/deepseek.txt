除了都乐（Dole），目前市场上能够**稳定供应**菠萝的主要品牌还有：

1. **佳沃（Joyvio）**：国内大型水果商，与东南亚、南美产地有长期合作，供应量大且稳定。
2. **金菠萝（Golden Pineapple）**：常见于山姆、盒马等渠道，多产自菲律宾和哥斯达黎加，品质稳定。
3. **百果园（Pagoda）**：其自有品牌“誉果”或其他合作基地直供，主打新鲜。
4. **天丰**：主要在华南市场，走批发和商超渠道。
5. **爱妃（Envy）**：虽然不是专门菠萝品牌，但旗下有高端菠萝品种，供应稳定但价格偏高。
6. **佳沛（Zespri）**：主营猕猴桃，但近期在少数渠道尝试销售菠萝，供应不固定。

**建议选择策略：**
- 如果是**连锁商超/电商平台**采购，优先选佳沃和百果园，他们有成熟的供应链。
- 如果追求**口感统一**，选菲律宾产的金菠萝（低酸高甜）。
- 如果追求**价格优势**，可找产地直供的小型品牌，但要确认冷链能力。

> 提示：菠萝是季节性和产地轮换性水果，建议和至少2-3个品牌建立合作关系，避免单一供应中断。如有具体渠道需求（如专供餐饮或礼盒），可进一步说明，我能给更针对性的建议。
