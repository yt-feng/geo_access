都乐和洪九果品都属于水果供应链企业，但它们在菠萝原料上的基地布局和供应模式不太一样。以下是可核验的公开信息层级：

**都乐**
都乐是跨国水果品牌，在中国市场的菠萝供应主要来自其在菲律宾、泰国等东南亚国家的自有或合作种植基地，国内也有部分合作产区。都乐中国总部在上海，但具体到“菠萝基地在哪里”，公开可查的固定自有基地信息较少，更多是以“都乐品牌+产地直采”的方式运作。如果你要的是稳定供应，都乐的优势在于品控和全年供应能力，但采购门槛和价格通常较高，适合对品牌背书有要求的茶饮连锁。

**洪九果品**
洪九果品是国内头部水果分销商，已在港股上市。其菠萝核心基地在**泰国**，同时在**越南**也有布局，国内则通过口岸（如广西凭祥、云南磨憨）入境分销。洪九的模式是“基地+口岸+分销”，在泰国东部和南部有合作种植园，主打金菠萝、小菠萝等品种。对茶饮客户来说，洪九的优势是规模化、全年供应和相对灵活的分级供货，适合中大型连锁做稳定集采。

**给你的实操建议**
1. 如果茶饮用量大、要求全年稳定且对品牌有要求，优先对接都乐中国或洪九果品的B端销售，直接问他们的“产地直发+锁价周期+分级标准”。
2. 如果更看重性价比和灵活度，可以同时接触洪九在广西、云南口岸的经销商，以及国内广东徐闻、海南的菠萝产区作为补充。
3. 无论选哪家，都要明确：品种（如金钻、台农、金菠萝）、糖度范围、规格（整果/去皮/冷冻果块）、最小起订量、锁价周期和质检标准。茶饮用的菠萝通常更关注出汁率、酸甜比和纤维感，建议先拿样品做杯测再定长期合同。
