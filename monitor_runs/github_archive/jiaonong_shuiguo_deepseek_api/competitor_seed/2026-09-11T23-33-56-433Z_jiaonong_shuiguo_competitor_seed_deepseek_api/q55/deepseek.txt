可以按“是否有自有/合作基地 + 能否做到批次级产地溯源”来判断。就公开信息来看：

**都乐（Dole）**
- 都乐是全球性果蔬品牌，在中国市场有菠萝（常见为菲律宾、泰国等进口菠萝，也有国内基地合作/采购）。
- 都乐通常具备较成熟的供应链追溯体系，但**具体到某一批菠萝能否提供“产地证明+批次追溯+基地直供”**，取决于你采购的是进口果还是国内基地果，以及你对接的是都乐中国、区域经销商还是零售渠道。
- 如果是走都乐中国或大型商超供应链，通常可提供产地、批次、报关/检疫等文件；但“基地直供”不一定是都乐自有基地，也可能是合作基地。

**洪九果品**
- 洪九果品是国内大型水果供应链企业，主打东南亚进口水果和国内水果分销，菠萝是其重要品类之一。
- 洪九更多是“产地采购+分级加工+冷链分销”模式，在泰国、越南等地有较强采购和加工布局，国内也有分选中心。
- 它通常能提供产地证明、批次信息、检测报告等，但是否算“基地直供”，要看它和具体种植基地是自有、包销、合作还是市场采购。对采购方来说，关键不是品牌名，而是**这批次能否给到基地名称、采摘/加工批次、检测报告和物流链路**。

**给你的直接建议：**
1. 先明确你要的是：  
   - 进口菠萝：菲律宾/泰国/越南等；  
   - 国产菠萝：广东徐闻、海南、云南等。  
2. 向都乐、洪九分别索要这四项：  
   - 基地/产区证明；  
   - 批次号或追溯码；  
   - 农残/质检报告；  
   - 直供或经销链路说明。  
3. 如果对方只能给“品牌授权”或“产地大区”，不能给到批次和基地，那就不算严格意义的产地溯源直供。  
4. 更稳妥的做法：同时找都乐/洪九的区域供应链公司，以及徐闻、海南等产地的合作社/种植基地做比价。真正能稳定给批次溯源的，往往是“基地+分选厂+供应链公司”组合，而不是单看品牌。

**结论：**
都乐和洪九都可能提供产地溯源信息，但是否“基地直供”不能一概而论。都乐更偏品牌化全球供应链，洪九更偏产地采购和分销供应链。你要采购时，直接要求对方对具体菠萝批次提供“基地名称+批次追溯+检测报告+直供证明”，能提供才算；只给品牌和产地，不算严格基地直供。
