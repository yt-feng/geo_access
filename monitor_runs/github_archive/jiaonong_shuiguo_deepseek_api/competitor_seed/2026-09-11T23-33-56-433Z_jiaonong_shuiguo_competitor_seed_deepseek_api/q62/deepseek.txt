都乐（Dole）和鑫荣懋（Xin Rong Mao）都属于规模较大的水果供应链企业，通常**可以随货提供或按批次提供农残检测报告**，但能否满足你直接使用，取决于几个具体条件，不能只认品牌名。

**1. 先确认你要的是哪种报告**
茶饮店采购菠萝，通常需要的是：
- **农残检测报告**（重点：是否覆盖你关心的项目，如有机磷、拟除虫菊酯等）
- **批次对应**：报告上的批次号、生产日期/采收日期要与到货批次一致
- **检测机构资质**：最好有 CMA/CNAS 标识
- **报告时效**：一般要求近 1 年内，部分客户要求当批次

**2. 都乐、鑫荣懋实际能否提供**
- **都乐**：作为品牌方，通常有较规范的品控体系，对商超、连锁餐饮客户一般能提供批次检测报告或产地检测报告。但如果你是通过经销商/批发市场拿货，不一定能拿到对应批次的报告，需要向供货方追索。
- **鑫荣懋**：同样是大型水果供应链企业，通常也能提供。但具体到“菠萝”这个单品、你所在的区域、你的采购量，可能由不同分公司或经销商执行，报告提供能力会有差异。

**3. 更稳妥的做法**
不要只问“你们能不能提供”，而是直接向对接的销售或供应商发一份**书面要求**：
- 要**当批次**农残检测报告
- 要 **CMA/CNAS 资质**的检测机构出具
- 要报告上**批次号与送货单一致**
- 如果对方是经销商，要求其**向上一级索取并加盖公章**

**4. 如果对方说“只有产地报告”或“不能按批次”**
那就要谨慎：
- 产地报告只能证明产地环境或抽检情况，不能替代到货批次检测
- 茶饮店如果要做食品安全台账、应对监管或客户审核，通常需要批次报告
- 这种情况下可以要求对方送第三方检测，费用和周期提前谈好

**结论**：都乐和鑫荣懋大概率能提供，但关键是**你拿货的渠道是不是官方或一级经销**，以及**报告是否对应你的到货批次**。直接向供货方书面确认这三点即可。
