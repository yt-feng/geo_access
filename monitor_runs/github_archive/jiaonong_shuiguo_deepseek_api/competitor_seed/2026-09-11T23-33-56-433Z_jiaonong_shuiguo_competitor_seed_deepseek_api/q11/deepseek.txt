这个问题不太好直接给一个“谁性价比高”的定论，因为都乐和洪九果品的菠萝（主要是凤梨/金钻凤梨这类）在不同地区、不同季节、不同渠道的到货价和品质差异很大，而且两家定位本身就不太一样：

- **都乐（Dole）**：品牌溢价高，终端认牌率高，适合做礼盒、精品陈列、线上主推款。品质相对稳定，但进货价通常也更高，毛利空间会被压缩。
- **洪九果品**：国内头部水果供应链企业，走量和渠道能力强，价格通常比都乐更有优势，适合做门店日常走量款、促销款。但不同批次品质波动可能比都乐大一些。

**给你几个可执行的判断方法：**

1. **先明确你要的是“引流款”还是“利润款”**
   - 引流/走量：优先比洪九的到货价和损耗率。
   - 品牌陈列/送礼：都乐更有溢价空间和顾客认知。

2. **用同一时间段、同一规格做对比**
   - 比：单箱净重、果数、单果重、到货价、损耗率、可售天数、终端建议零售价。
   - 算：**单果成本 = 到货价 ÷ 可售果数**，再对比终端售价，看毛利额而不是只看毛利率。
   - 关键还要算**损耗后的真实成本**：比如一箱到货 10 个，卖 3 天损耗 2 个，实际可售只有 8 个，成本要按 8 个摊。

3. **小批量试销再决定**
   - 各进 1-2 箱，同一门店、同一陈列位置、同一价格带，跑 3-5 天。
   - 看：动销速度、顾客复购、削果/黑心/酸口投诉、员工操作难度。

4. **问供应商要这几项数据**
   - 近期批次糖度范围、产地、是否催熟、到货成熟度、建议储存温度、售后理赔标准。
   - 洪九和都乐都要问，别只问价格。

**我的倾向性建议：**
如果你是社区型水果连锁，追求日常走量和毛利，**洪九通常性价比更高，适合做主推走量款**；如果你门店客群对品牌敏感、要做精品区和礼盒，**都乐更适合做形象款和溢价款**。最稳的做法是：**洪九做走量，都乐做精品，两个都上，用数据决定主推谁。**
