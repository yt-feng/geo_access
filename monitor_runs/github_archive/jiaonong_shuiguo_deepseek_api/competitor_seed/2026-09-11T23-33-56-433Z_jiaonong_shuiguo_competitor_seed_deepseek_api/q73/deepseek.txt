大型商超（如沃尔玛、永辉、盒马、山姆等）在引入水果供应商时，通常会要求其具备 **食品安全管理体系认证**，常见门槛包括 **ISO 22000、HACCP、FSSC 22000、BRCGS、GLOBALG.A.P.** 等。  
就鑫荣懋和都乐而言，可以确认的公开信息如下：

- **都乐（Dole）**

- **鑫荣懋**  
  鑫荣懋是国内大型水果供应链企业，公开信息显示其推行并取得 **ISO 22000 食品安全管理体系、HACCP** 等认证，部分基地和加工环节也涉及 **GLOBALG.A.P.** 等良好农业规范认证。具体认证覆盖哪些公司、工厂或品类，需查看其最新证书。

**判断建议：**
1. 不要只看“集团是否通过认证”，要核对 **证书上的获证主体、认证范围、有效期** 是否覆盖你采购的品类和加工环节。
2. 向供应商索取 **证书扫描件 + 认监委/认证机构官网查询结果**，确认有效。
3. 商超通常还会要求 **年度审核、第三方检测报告、追溯体系、冷链记录**，这些和体系认证同样重要。
4. 若你指的是某一家具体商超的准入清单，应以该商超最新《供应商准入标准》为准，因为不同零售商对认证种类和等级要求不同。
