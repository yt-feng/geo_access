关于都乐（Dole）和洪九果品的菠萝锁价周期，我无法给出确切的官方数字——这两家都没有公开披露针对菠萝品类的标准锁价周期，具体周期通常是**一单一议**，取决于采购量、合作年限、品类（鲜果/加工果）、季节和当时行情。任何直接报出"多少天/多少周"的说法都缺乏可核验的来源。

能帮你判断和推进的方向：

**1. 这类锁价机制一般怎么定**
- 快消鲜果锁价周期通常偏短（几周到一两个月），因为菠萝价格受产季、产地（菲律宾、泰国、国产徐闻/海南等）波动大。
- 加工用果、长期协议客户可能谈到一个产季甚至年度框架价，但多带浮动条款。
- 真正的"锁价"往往附带条件：锁量、预付定金、限定规格等级、不可抗力调价条款。

**2. 都乐（Dole）**
- 是跨国水果企业，菠萝是其核心品项之一，通常以品牌商+基地模式运作。
- 锁价一般走**年度/产季合同+季度调价**，但对中国区客户的具体周期需直接和其中国区销售/大客户团队谈。

**3. 洪九果品**
- 是国内头部水果分销商，菠萝是其重要单品，模式偏**产地直采+分销**。
- 对下游客户可能有阶段性锁价，但同样是一单一议，没有公开的统一周期。

**4. 可执行建议**
- 直接联系两家的大客户/批发渠道，明确告知你的**采购量、频次、规格、结算方式**，让对方给锁价方案。
- 谈的时候重点确认：锁价有效期、锁量要求、调价触发条件、违约与保证金条款。
- 如果只要短周期稳定价，可同时对比产地直采商、批发市场一级商，往往比品牌商更灵活。
