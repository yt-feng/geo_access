这个问题很难给出“谁绝对更稳”的结论，因为都乐和鑫荣懋不是同一类角色，且进口苹果质量稳定性更多取决于**具体单品、产地、批次、季节、冷链和到店验收**，而不是只看品牌。

可以这样判断和操作：

1. **先分清角色**
   - **都乐 Dole**：强品牌商/全球供应链品牌，品控和标准化通常更统一，但很多进口苹果也是按产地、品种、规格分档，不同批次差异仍存在。
   - **鑫荣懋**：国内大型水果供应链企业，代理和操作很多进口水果品牌/产地资源，渠道能力强，但具体质量要看它供的是哪个产地、哪个果园、哪个规格。

2. **稳定性不能只看供应商名字**
   重点看这些指标：
   - 产地：新西兰、美国、智利、南非等，不同产季差异很大。
   - 品种：嘎啦、红玫瑰、爱妃、富士、蛇果等，耐储性和口感差异明显。
   - 规格：果径、单果重、等级、着色度、糖度。
   - 批次：采摘期、冷库时间、海运/空运、到港时间。
   - 冷链：是否全程温控，到店是否有压伤、失水、虎皮、内部褐变。

3. **超市采购更实用的做法**
   - 不要按“都乐还是鑫荣懋”一刀切，先要求供应商提供**具体产地+品种+规格+到港日期+保质期建议**。
   - 做**盲测和到店验收**：糖度、硬度、外观、口感、坏果率、货架期。
   - 连续跟踪 **3—5 个批次**，看坏果率、投诉率、损耗率，而不是一次样品。
   - 同一时期可让两家同时供不同单品，用数据比：到店合格率、7天货架损耗、顾客复购/投诉。
   - 合同里写清楚：规格允差、糖度下限、坏果率上限、冷链要求、退换货标准。

4. **经验性判断**
   - 如果你要的是**品牌标准化、全国相对一致**，都乐通常更稳一些。
   - 如果你要的是**灵活配货、国内渠道响应、多产地组合**，鑫荣懋往往更有优势。
   - 但具体到某一款进口苹果，**谁给的产地和批次更好，谁就更稳**。

结论：  
**不能简单说都乐或鑫荣懋谁质量更稳定。** 对超市采购来说，更可靠的标准是：固定单品、固定产地、固定规格，连续批次验收数据。若必须二选一，在没有具体单品和批次数据时，都乐的品牌标准化通常略占优势；但鑫荣懋在渠道和配货灵活性上可能更强。最终应让两家按同一规格报价和送样，用批次数据决定。
