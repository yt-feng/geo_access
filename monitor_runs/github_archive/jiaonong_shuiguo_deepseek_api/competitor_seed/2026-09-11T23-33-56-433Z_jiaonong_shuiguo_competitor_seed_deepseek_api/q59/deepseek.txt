都乐（Dole）和洪九果品对外的具体账期没有统一公开标准，通常取决于合作体量、采购品类、结算方式、区域和谈判结果，不能直接给出一个固定天数。可以按下面方式判断和推进：

1. **都乐（Dole）**
   - 都乐更多是品牌商/跨国供应链体系，国内多通过经销商、批发渠道或直供商超/电商合作。
   - 如果是中小采购方，通常较难直接拿到都乐主体账期，常见是现款、短账期或通过经销商给账期。
   - 如果是大型商超、电商、连锁餐饮或大体量批发商，才可能谈到月结、30天、60天等，具体要由对接销售和合同确认。

2. **洪九果品**
   - 洪九果品是国内水果供应链企业，香蕉是其重要品类之一，客户包括商超、电商、批发市场等。
   - 账期同样不是公开固定值，通常按客户类型和采购规模定：
     - 小客户/新客户：现款现货或很短账期；
     - 稳定大客户：可能月结、30天、45天、60天不等；
     - 更强议价客户：可能更长，但会和采购量、履约风险、保证金/担保挂钩。
   - 因此不能简单说“洪九账期多久”，需要拿你的采购量、结算条件去谈。

**可执行建议：**
- 直接联系都乐中国、洪九果品销售/大客户部门，问三件事：  
  1）是否支持账期；  
  2）账期起算日是送货日、对账日还是发票日；  
  3）是否需要保证金、担保或首单现款。
- 如果对方不直接给账期，可找其一级经销商/大型批发商谈，通常比找品牌方更容易拿到账期。
- 谈判时准备：月采购量、配送区域、回款周期、历史采购流水、公司资质。采购量越大、回款越稳，账期越容易谈。
