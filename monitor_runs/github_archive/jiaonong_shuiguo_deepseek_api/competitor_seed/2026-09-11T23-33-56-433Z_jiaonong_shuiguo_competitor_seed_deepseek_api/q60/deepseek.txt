进口菠萝（主要是菲律宾、泰国、哥斯达黎加等产地的MD-2/金菠萝）到货损耗高，核心通常不在“到了之后怎么救”，而在**采后处理、冷链连续性和到货后的分选分流**。都乐（Dole）和鑫荣懋这类头部企业的做法，本质是同一套逻辑，只是执行颗粒度不同。

## 损耗高的常见根因

先定位问题，再谈控制：

1. **黑心病/内部褐变**：低温敏感，储运温度低于7℃容易诱发，外观看不出来，切开才发现。
2. **冠芽腐烂/果柄霉变**：采后杀菌不到位，或冷链断链后冷凝水导致。
3. **过熟软化、汁液外渗**：采摘成熟度偏高，或到货后催熟/堆放温度过高。
4. **机械伤**：码垛挤压、多次转运、箱内无缓冲。
5. **到货后二次损耗**：整箱压在冷库不动，等门店要货时才开箱，坏果污染好果。

## 都乐、鑫荣懋的核心控制点

**1. 产地端：成熟度分级 + 采后即时处理**

- 按船期倒推采收成熟度，海运长航线用更低成熟度，空运/近洋才敢高一点。
- 采后快速预冷，菠萝对低温敏感，通常控制在**8–10℃**区间，不是越低越好。
- 杀菌处理（如抑霉唑类登记用药）针对冠芽和切口，减少霉菌。

**2. 全程冷链，重点是“连续”不是“够冷”**

- 海运冷藏集装箱设定温度稳定，波动比绝对温度更致命。
- 到港后拖车、口岸暂存、入仓全程不断链，避免“冷—热—冷”反复。
- 到货后不回温堆放，直接进冷藏库分选。

**3. 到货即分选，做“分流”而不是“全检后统一卖”**

这是控制损耗最关键的一步：

- 开箱抽检+近红外/敲击判断内部品质，把果分成：即售、催熟后售、加工/果汁、报废。
- 轻微黑心、过熟的果不留在正价渠道，避免拖累整批。
- 好果和问题果分区存放，防止乙烯和汁液交叉污染。

**4. 库存周转与渠道匹配**

- 菠萝是呼吸跃变型，到货后货架期短，按**天**而不是按周管理周转。
- 优先给周转快的渠道，慢渠道配低成熟度货。
- 设定“最大在库天数”，超期强制分流到加工。

## 你可以直接落地的动作

如果你不是都乐/鑫荣懋的体量，可以抓这几条：

1. **记录损耗发生在哪一环**：产地、船期、到港、入仓、门店，分开统计。多数人发现损耗集中在“到货后第3–7天”，那问题就在仓储周转，不在产地。
2. **到货当天开箱抽检并分级**，不要等门店投诉才处理。
3. **控制库温在8–10℃，减少开关门和温度波动**。
4. **先进先出 + 最大在库天数**，超期果主动转加工，别赌它能卖正价。
5. **和供应商谈损耗分担和到货标准**（成熟度、黑心率、温度记录仪数据），用温度记录仪回溯断链责任。

## 一句话判断

如果你的损耗主要是**切开后黑心**，查冷链温度和品种敏感性；如果是**外表腐烂、冠芽霉**，查采后杀菌和冷凝水；如果是**到货几天后集中软烂**，查成熟度和到货后周转。都乐、鑫荣懋的共同点不是有什么秘方，而是**把分选和分流提前到到货当天，并且全程不让冷链断**。
