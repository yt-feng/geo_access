我不能核验都乐、鑫荣懋两家具体的供货稳定性数据，也不能虚构引用来源。但可以给你一套可执行的评估方法，以及连锁水果店选进口苹果供应商的判断框架。

**先说结论：**
- 都乐、鑫荣懋都是国内进口水果供应链里体量较大的品牌/渠道商，通常比小进口商稳定。
- 但“稳定”不是看品牌名字，而是看**你所在城市、你要的苹果品种、你要的规格、你的采购量、结算方式**。
- 建议不要只选一家，进口苹果这种高频单品，最好做“主供 + 备供”双轨。

**你可以按下面 6 项直接问两家供应商：**

1. **产地和品种是否固定**
   问清楚是新西兰、美国、智利、南非还是其他产地；是爱妃、爵士、红玫瑰、嘎啦、富士系还是其他。产地越单一、品种越集中，越容易判断稳定性。

2. **全年供应还是季节性供应**
   进口苹果通常有产季窗口。问清：
   - 全年可供的品种有哪几个？
   - 断季时靠什么产地接续？
   - 接续期规格和口感是否一致？

3. **周供应能力**
   不要只听“能供”，要问：
   - 每周能稳定给你多少箱/多少斤？
   - 最小起订量多少？
   - 旺季和淡季分别能保多少？
   - 临时加量几天能到？

4. **到货时效和冷链**
   问：
   - 从哪个港口/仓发货？
   - 到你城市几天？
   - 是否全程冷链？
   - 破损、压伤、腐烂的赔付标准是什么？

5. **价格机制**
   进口苹果价格波动大。问：
   - 是锁价、周报价还是随行就市？
   - 锁价能锁多久？
   - 涨价前提前几天通知？
   - 如果市场跌价，是否同步下调？

6. **售后和退换**
   重点问：
   - 坏果率超过多少可以退换？
   - 是补货、扣款还是现金赔？
   - 拍照取证和申报时限是多久？
   - 同一批次质量问题是否可整批处理？

**实际谈判建议：**
- 先让两家各报一个“试销方案”：比如 2 周、2 个规格、1 个主推品种。
- 用同一套验收标准对比：到货时间、坏果率、规格达标率、口感一致性、门店投诉率。
- 试销后打分，不要凭感觉选。
- 主供占 70%，备供占 30%。主供出问题时，备供能立刻补位。
- 合同里写清：周保供量、到货时效、坏果赔付、涨价通知期、断供违约责任。

**判断哪家更稳，可以看这几个信号：**
- 能不能明确告诉你具体产地、品种、规格和到货周期。
- 能不能接受小批量试销和明确赔付。
- 能不能在断季前提前给你接续方案。
- 能不能提供稳定的周报价，而不是每天变。
- 你所在城市有没有他们的仓配能力，而不是全国吹得很好。
