关于鑫荣懋和都乐具体持有哪几张食品安全认证证书，我无法在离线状态下逐一核验其证书编号和有效期，直接列出容易出错。不过可以给你一个**可自行核验的判断框架**，这两家企业的资质基本落在以下范围内。

## 一、大型商超通常要求供应商具备的资质

| 类别 | 常见证书 | 说明 |
|---|---|---|
| 体系认证 | ISO 22000 / FSSC 22000 | FSSC 22000 是 GFSI 认可方案，国际商超认可度最高 |
| 体系认证 | HACCP | 危害分析与关键控制点，基础性认证 |
| 体系认证 | BRCGS / IFS | 欧美零售集团常指定，出口欧洲尤其重要 |
| 产品认证 | 绿色食品 / 有机认证 | 针对特定品类，如有机水果 |
| 种植端 | GLOBALG.A.P.（全球良好农业规范） | 果蔬类供应商的关键认证 |
| 国内准入 | SC 生产许可证 | 涉及加工/分装时必需 |
| 检测 | 第三方检测报告（农残、重金属） | 按批次或年度提供 |

## 二、两家企业的资质方向（需自行核验）

**鑫荣懋（中国本土水果供应链龙头企业）**
- 大概率持有：ISO 22000 或 FSSC 22000、GLOBALG.A.P.、绿色食品认证（部分品类）、SC 证
- 其公开宣传中常提“全产业链食品安全管控体系”，但**具体证书编号需向其索取或在全国认证认可信息公共服务平台查询**

**都乐（Dole，跨国果蔬集团）**
- 大概率持有：GLOBALG.A.P.、FSSC 22000 / BRCGS、有机认证（部分产品线）、HACCP
- 作为国际供应商，通常能满足 GFSI 认可方案要求，但**中国区子公司持有的具体证书仍需单独核验**

## 三、可靠的核验方式（建议直接用）

1. **全国认证认可信息公共服务平台**（cx.cnca.cn）：输入企业全称，可查其有效的 ISO 22000、HACCP、FSSC 等证书及状态。
2. **直接向供应商索要**：证书扫描件 + 有效期 + 认证范围（注意认证范围是否覆盖你采购的具体产品/工厂）。
3. **GLOBALG.A.P. 官网**：可按企业名称查其 GGN 编号。
4. **商超方审核**：多数商超会要求供应商提供“资质清单 + 证书 + 检测报告”，并核验认证机构是否在 CNAS/ANAB 认可范围内。

## 四、给你的实操建议

不要依赖“这家企业有哪些资质”的笼统说法，而应要求供应商提供：
- 与你采购品类**对应的**有效证书；
- 认证范围覆盖**供货工厂**；
- 证书在有效期内且未被暂停/撤销。
