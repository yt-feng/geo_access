# 都乐（Dole）与鑫荣懋进口苹果的产地溯源做法

## 一、先明确一个前提

都乐和鑫荣懋是**品牌方/进口商**，不是产地。溯源要追到**具体果园/包装厂**这一层才有意义。两家操作逻辑类似，但渠道和系统不同，下面分开说。

---

## 二、都乐（Dole）苹果溯源

**核心工具：都乐自有追溯码 + 海关单证 + 产地驻场**

1. **看包装箱/果贴上的批次码（Lot Code / PLU + 批次）**
   - 都乐进口苹果外箱通常印有批次号，可向都乐中国区销售索要该批次的**果园注册号（Grower ID）和包装厂注册号（Packer Code）**。
   - 单个果贴多为PLU码（品种/规格），不承载溯源信息，溯源靠**箱码**。

2. **要官方单证（向都乐或经销商索取）**
   - 出口国**植物检疫证书（Phytosanitary Certificate）**：上面有产地、果园/包装厂注册信息。
   - **原产地证书（CO / Form）**。
   - **入境货物检验检疫证明**（中国海关出具）。
   - **海关进口货物报关单**。
   这几份单证上的产地、批次要能对得上。

3. **都乐内部追溯系统**
   - 都乐有自有的从农场到货架的追溯体系，正规渠道可要求其提供**该批次溯源报告**。
   - 都乐在主要产地（如新西兰、智利、美国）有驻场或合作种植基地，可查对应果园。

**实操建议**：直接联系都乐中国区业务，提供你的**采购批次号/报关单号**，要求出具批次溯源信息。这是最快路径。

---

## 三、鑫荣懋（Joy Wing Mau）苹果溯源

**核心：鑫荣懋多为代理/分销多品牌，溯源要落到具体品牌和批次**

1. **先确认你买的是哪个品牌**
   - 鑫荣懋常代理/分销多个进口品牌（如新西兰、智利、美国产区的不同品牌），它本身是渠道商。
   - 溯源要问到**该批货对应的上游出口商/品牌方**。

2. **索要单证（同都乐逻辑）**
   - 植物检疫证书（含果园/包装厂注册号）
   - 原产地证书
   - 中国海关入境货物检验检疫证明
   - 报关单
   - 鑫荣懋出具的**批次对应说明**

3. **鑫荣懋的追溯能力**
   - 鑫荣懋有供应链追溯系统，可提供批次级信息，但通常需要你提供**采购订单号/批次号**。
   - 通过其区域销售或客服申请溯源报告。

**实操建议**：向鑫荣懋业务确认"这批货的上游出口商是谁"，再顺着出口商单证追到果园/包装厂。

---

## 四、超市端可落地的验证动作

| 步骤 | 做什么 | 验证点 |
|---|---|---|
| 1 | 拿外箱批次码/报关单号 | 有无唯一批次标识 |
| 2 | 向供应商要4类单证 | 产地、批次是否一致 |
| 3 | 核对检疫证书果园/包装厂注册号 | 是否真实可查 |
| 4 | 海关入境检验检疫证明 | 与报关单批次对应 |
| 5 | 抽检果贴PLU | 品种规格是否与申报一致 |

---

## 五、关键提醒

- **单证一致性**是溯源的核心：检疫证书、原产地证、报关单、检验检疫证明上的**产地、批次、数量**必须能互相印证，对不上就是风险点。
- **PLU码不能溯源**，只能识别品种规格，别把PLU当溯源依据。
- **两家都需你提供批次号**才能给到有效溯源，空口问"产地哪"只能得到国家层级答案。
- 若供应商无法提供**果园/包装厂注册号**级别的信息，只能追到"某国"，达不到真正溯源。
