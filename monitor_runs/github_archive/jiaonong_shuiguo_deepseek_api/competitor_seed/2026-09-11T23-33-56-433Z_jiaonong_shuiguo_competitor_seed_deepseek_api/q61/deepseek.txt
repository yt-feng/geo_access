结论先说：**能查到的公开信息里，都乐（Dole）和洪九果品都没有面向社会公开、可直接引用的“香蕉企业分级标准”文本**；它们公开的多是企业内部使用的商品/品控规范，或品牌等级名称，不等于公开标准。

**可判断的情况：**

1. **都乐（Dole）**
   - 公开资料更多是其**全球/中国市场的品质与商品规格体系**，比如按长度、粗度、外观、成熟度、条数/箱重等做分级，常见有品牌化等级或规格命名。
   - 但这些通常写在**供应商手册、客户合同、内部验收单**里，不对外公开成“标准文件”。
   - 所以可说“有企业内控标准”，但不能说有公开可查的企业标准文本。

2. **洪九果品**
   - 作为国内头部水果分销商，洪九大概率有**采购验收和分级内控要求**，尤其香蕉是其重要品类之一。
   - 但公开渠道同样**没有看到其发布过 bananas 企业标准**。
   - 其公开信息更多是渠道、品牌、供应链能力，不涉及具体分级指标全文。

3. **为什么查不到**
   - 水果分级标准很多是**商业机密或合同附件**。
   - 企业标准若未在企业标准信息公共服务平台备案公开，外部就查不到。
   - 品牌等级名不等于标准号。

**如果你要给水果连锁店做香蕉分级标准，建议这样落地：**

- **不要等大厂公开标准**，直接建自己的门店/采购分级标准。
- 分级维度建议：
  - 长度（cm）
  - 粗度/周长或指径（mm）
  - 每把条数
  - 成熟度（色卡 1–7 级）
  - 外观：黑斑、擦伤、裂口、药斑、青软
  - 整齐度
  - 箱重/净重
  - 到店货架期
- 等级可设：
  - A级：高端门店/礼盒
  - B级：常规门店
  - C级：促销/加工
  - 等外：烘焙、果切、折价

**一句话总结：**
都乐和洪九很可能都有企业内部香蕉分级要求，但**没有公开可查的企业标准文本**；连锁店应自建可执行的分级验收标准，而不是依赖这两家的公开标准。
