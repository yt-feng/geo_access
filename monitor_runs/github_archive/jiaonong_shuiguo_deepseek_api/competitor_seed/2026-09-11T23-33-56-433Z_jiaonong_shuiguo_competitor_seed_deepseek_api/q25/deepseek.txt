这个问题没法直接给出“谁更愿意”的确定答案，因为两家都是大型水果供应链企业，是否愿意签年单、以及愿意给什么条件，主要取决于**品类、采购量级、结算方式、履约节奏和你方的渠道能力**，而不只是公司名字。

给你一个可判断的框架和实操建议：

**1. 先分清你签的是哪种“年单”**
- 如果是有保底量的年度框架协议：两家通常都能谈，关键看你量够不够大、是否稳定。
- 如果是锁价年单：水果是生鲜，价格波动大，两家都会很谨慎，通常只对部分进口果、标品果或长期稳定品类做锁价，国产应季果很难全年锁死。
- 如果是账期年单：这取决于你的信用和结算条件，不是供应商单方面“愿不愿意”。

**2. 两家的一般特点（用于判断谈判方向）**
- **鑫荣懋**：强在进口水果、商超渠道、品牌化运营，供应链体系成熟。对大型商超、电商、连锁渠道的年度合作比较熟悉，通常更愿意谈年度框架，但条件和考核会比较细。
- **洪九果品**：强在东南亚进口水果尤其是榴莲、火龙果等品类，以及批发和分销网络。对大宗、稳定走量的年度合作也有经验，但具体是否给年单，要看品类和你的分销能力。

**3. 真正决定“谁更愿意”的变量**
- 你的年采购额是否达到他们的重点客户门槛
- 是否接受保底量、预付或短账期
- 品类是否是他们主控的强势单品
- 你是否有稳定的下游出货渠道
- 是否接受价格随行就市、只锁量不锁价

**4. 建议你直接这样去谈**
分别向两家提出同一份需求，包含：
- 年度预估采购量、分月节奏
- 目标品类和规格
- 结算方式（账期/预付/货到付款）
- 是否要求锁价，还是接受随行就市
- 违约和保底条款

然后对比谁给的**年度返利、账期、优先供货、价格机制**更好。

**5. 一个更实际的结论**
没有哪家天然“更愿意签年单”。通常：
- 如果你做**商超/电商/品牌渠道**，鑫荣懋可能更匹配。
- 如果你做**批发/大宗分销**，尤其东南亚果品，洪九可能更匹配。
- 如果你量不够大，两家都可能只给季度或项目合作，而不是真正的年单。
