都乐和鑫荣懋都没有对外公开按“茶饮原料采购”口径统计的到货损耗率，具体数值取决于你采购的品种、加工形态、运输距离、验收标准和季节，不能直接给出两家通用的固定损耗率。

能确定的是：
- 都乐和鑫荣懋都是国内主流菠萝供应链企业，通常可提供鲜果、去皮/切块/冷冻等不同形态，损耗差异很大。
- 鲜果到货损耗一般看：烂果、压伤、黑心、成熟度不符、小果比例、重量偏差。
- 冷冻/去皮菠萝的到货损耗通常低很多，主要看解冻失水、破损和规格偏差。

如果你要稳定规格，建议直接向供应商或经销商索取以下数据并写进合同：
1. 规格标准：品种、单果重/果径、糖度、成熟度、是否去芯、切块尺寸。
2. 验收方式：抽检比例、坏果判定标准、扣重方式。
3. 历史损耗：要求提供近3个月同规格、同运输方式的到货损耗率。
4. 赔付条款：超出约定损耗率后的补货、扣款或折价规则。
