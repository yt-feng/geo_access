都乐和洪九果品都是国内菠萝供应链里比较常见的企业，但它们的基地布局和业务模式差别较大。下面按可核查的信息说清楚，并给出采购建议。

## 都乐（Dole）

都乐是跨国果蔬企业，在中国市场销售的菠萝主要来自其在华合作或自营的种植基地，**核心产区在广东省湛江市徐闻县**一带。徐闻是中国最大的菠萝产区，都乐在这里有合作种植和分选包装体系。此外，都乐在**海南**也有菠萝相关供应布局。

都乐的特点是：
- 标准化程度高，果形、糖度、成熟度分级较稳定；
- 品牌溢价明显，采购单价通常高于市场散货；
- 适合对出品一致性要求高的连锁茶饮品牌。

## 洪九果品

洪九果品是重庆起家的水果供应链企业，采用“基地+加工+分销”模式。其在菠萝上的基地布局主要涉及：
- **广东徐闻**：核心菠萝采购与加工区域；
- **海南**：季节补充产区；
- **云南**：部分热带水果品类，菠萝供应视季节和订单而定。

洪九的优势在于全国分销网络和加工分选能力，适合需要多区域、多品类一站式采购的客户。不过洪九近年经营层面有较大波动，**建议在合作前核实其当前实际运营状态、基地是否正常供货**，不要仅凭历史资料判断。

## 对茶饮采购的实际建议

1. **要稳定供应，先锁定产区而不是只锁定品牌**。菠萝有强季节性，徐闻主产季集中在每年3—6月，海南可错峰补充。单靠一个基地很难全年稳定。

2. **建议至少双源采购**：都乐或同类标准化供应商保底品质，洪九或产区直采做成本补充，避免单一供应商断供。

3. **重点核验**：供应商能否提供基地地址、加工厂位置、当季可供应量、糖度标准（茶饮一般要求14°Brix以上）、冷链能力。

4. **实地或视频验厂**：茶饮对菠萝的用途不同（果肉、果汁、果酱），对品种要求也不同，巴厘菠萝和台农系列在出汁率、纤维感上差异明显，需按产品配方确认品种。
