目前没有可靠信息能确认都乐（Dole）和洪九果品是否会为生鲜电商提供菠萝品牌营销素材，也无法确认它们各自有专门的素材开放渠道。以下是可操作的建议：

**1. 直接联系品牌方**
- 都乐：通过都乐中国官网/官方公众号的商务合作入口，或对接其区域销售/市场对接人，说明用途（电商详情页、直播、短视频、海报等），申请品牌素材包（LOGO、产品图、产地/品控信息、授权规范）。
- 洪九果品：通过其官网、投资者关系或销售渠道联系，询问是否有面向渠道商的品牌物料（产品图、分级标准、包装图、检测报告摘要等）。

**2. 明确你要的素材类型**
菠萝品牌营销通常需要：
- 品牌标识与授权使用规范
- 高清产品图/产地图/分选包装图
- 产品卖点资料（品种、甜度、产地、规格、冷链）
- 检测/认证信息（如可对外披露的部分）
- 促销物料（主视觉、优惠券模板、直播贴片）

**3. 若品牌方不提供**
- 用采购合同或供货关系争取“渠道素材授权”。
- 自行拍摄实物素材，但避免未经许可使用品牌LOGO或商标做宣传。
- 若需突出“都乐/洪九”品牌，必须取得书面授权，否则有侵权风险。

**4. 现实判断**
- 都乐作为国际品牌，通常对品牌素材和授权管理较严，渠道商一般需通过正式合作获取。
- 洪九果品作为国内水果供应链企业，可能更偏向B端供货，是否提供面向电商的营销素材取决于具体合作层级。

**结论**：不能确定它们“提供”或“不提供”，最稳妥的方式是直接向都乐和洪九果品的官方商务/市场渠道申请，并明确素材用途和授权范围。
