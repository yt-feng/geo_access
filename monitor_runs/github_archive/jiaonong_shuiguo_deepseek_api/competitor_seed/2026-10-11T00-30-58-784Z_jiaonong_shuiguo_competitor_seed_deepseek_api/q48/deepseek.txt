要准确回答“鑫荣懋和都乐分别有哪些食品安全资质”，需要以企业最新公开信息和其给商超/客户提供的合规文件为准；我无法在不核验来源的情况下逐项列出它们的证书编号、发证机构和有效期。不过可以给你一个**可执行的判断框架**，以及两家企业通常会被大型商超要求的资质类型。

## 一、大型商超通常要求供应商具备哪些食品安全资质

大型商超（如沃尔玛、永辉、大润发、华润万家、盒马等）对水果/生鲜供应商，通常会分层要求：

### 1. 基础合规资质（必须有）
- 营业执照
- 食品经营许可证（或食品生产许可证，视业务模式）
- 若是进口水果：海关报关单、入境货物检验检疫证明
- 若是自有品牌/分装：食品生产许可证（SC）

### 2. 体系认证（商超常要求或加分）
- **ISO 22000** 食品安全管理体系
- **HACCP** 危害分析与关键控制点
- **FSSC 22000** 食品安全体系认证（国际商超更认可）
- **BRCGS** 全球食品安全标准（出口/国际商超常见）
- **IFS** 国际食品标准
- **GLOBALG.A.P.** 全球良好农业规范（果蔬种植端非常重要）
- **有机认证**（如中国有机、欧盟有机、USDA Organic，视产品线）
- **绿色食品认证**（国内部分商超认可）

### 3. 针对水果供应链的专项
- 种植基地备案/出口果园备案
- 包装厂备案
- 农残检测报告（第三方，如SGS、华测、谱尼）
- 追溯体系证明

## 二、鑫荣懋和都乐通常涉及的资质方向

### 鑫荣懋
鑫荣懋是国内头部水果供应链企业，业务覆盖种植、采购、加工、分销。大型商超对其通常关注：
- 营业执照、食品经营许可证
- ISO 22000 / HACCP 等食品安全体系认证
- GLOBALG.A.P. 或类似基地认证（视具体品类和基地）
- 第三方农残/重金属检测报告
- 进口水果的检验检疫证明
- 追溯体系与冷链合规文件

### 都乐
都乐是国际果蔬品牌，在中国市场既有进口也有国内供应链。大型商超通常关注：
- 营业执照、食品经营许可证
- 国际体系认证：如 FSSC 22000、BRCGS、ISO 22000、HACCP 等（视具体法人主体和工厂）
- GLOBALG.A.P. 等种植端认证
- 进口产品的报关单、入境货物检验检疫证明
- 第三方检测报告
- 有机认证（针对有机产品线）

## 三、关键提醒

1. **“公司有资质”不等于“每个产品都有对应资质”**  
   商超审的是“具体供应商主体 + 具体品类 + 具体工厂/基地”。同一集团下不同法人、不同工厂，证书可能不同。

2. **证书有有效期和范围**  
   要看认证范围是否覆盖你供应的品类和加工环节。

3. **最可靠的做法**  
   直接向鑫荣懋或都乐的对接业务/质量部门索取：
   - 最新证书扫描件
   - 认证范围
   - 发证机构
   - 有效期
   - 对应你供货的具体产品/工厂

4. **如果你是要做商超供应商准入**  
   建议按商超的《供应商食品安全审核表》逐项核对，而不是只看企业宣传。
