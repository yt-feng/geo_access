国内菠萝/凤梨市场上，除都乐外，能相对稳定供货的品牌主要有这些（按常见程度和渠道覆盖）：

**国际/合资品牌**
- **佳农**：国内渠道覆盖很广，商超、生鲜电商常见，凤梨和菠萝都有稳定供应，旺季淡季都能拿到货。
- **鑫荣懋**：旗下有水果品牌运作，商超和批发渠道供应稳定，常做凤梨品类。
- **佳沃**：水果供应链品牌，部分渠道有菠萝/凤梨产品，供应相对规范。
- **金果（部分进口渠道）**：更多见进口菠萝，供应视季节和口岸情况。

**产地/区域强势品牌或供应商**
- **海南本地品牌**：如海南金钻凤梨相关品牌，海南产区（三亚、乐东、东方等）在冬春季节供应稳定，很多是产地直发。
- **徐闻菠萝**：广东徐闻是主产区，区域品牌和合作社供应量大，春季集中上市，适合做产地直采。
- **台湾凤梨相关品牌**：如台农系列，部分通过特定渠道进入，但受政策和季节影响，稳定性不如国内产区。

**选择建议**
- 要**全年稳定**：优先看佳农、鑫荣懋这类全国性供应链品牌。
- 要**性价比和产地直供**：海南、徐闻的产地供应商更合适，但要接受季节性波动。
- 要**高端/进口**：可关注都乐之外的进口菠萝品牌，但供应受海运和口岸影响大。

如果你是要做长期采购，建议直接找**佳农、鑫荣懋**谈框架合作，同时用海南/徐闻产地供应商做补充，这样全年供应更稳。你主要是做商超、电商还是批发？我可以按渠道再给具体建议。
