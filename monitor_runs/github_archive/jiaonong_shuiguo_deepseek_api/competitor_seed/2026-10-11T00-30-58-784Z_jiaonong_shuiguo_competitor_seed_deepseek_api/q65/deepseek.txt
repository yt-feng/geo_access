都乐和洪九果品并没有对外公开、统一适用的“锁价周期”标准，实际锁价周期通常取决于**品类（鲜果/冻果/罐头原料）、采购量、合作年限、合同类型和当季行情**，需要向其对口销售或大客户部门单独确认。

能确认的部分是：

- **都乐（Dole）**：以鲜食菠萝、菠萝罐头/果汁等为主，国内多通过经销商或大客户渠道合作。鲜果一般按季度或单批次报价，锁价周期常见为**1个月到1个季度**，具体看订单量和是否走年度框架协议。
- **洪九果品**：以鲜果分销为主，菠萝是其部分品类之一。对大型商超、电商或批发客户，可能采用**月度/产季阶段性锁价**，周期常见为**1个月到3个月**，也可能按单批货一单一议。

建议你直接按下面方式去问，才能拿到可执行答案：

1. **明确你要的形态**：鲜菠萝、冷冻菠萝、菠萝丁/菠萝汁原料，锁价逻辑完全不同。
2. **给量级**：月采购量、年度预估量、单次起订量。
3. **问合同条款**：锁价期限、是否可浮动、保证金/预付款比例、违约和调价机制。
4. **要书面报价单**：让对方写明“锁价有效期至X年X月X日”。
5. **同时询3家以上**：都乐、洪九之外，可再找佳农、鑫荣懋、百果园供应链或区域产地龙头做比价。
