这个问题我没法给你一个可靠的“谁更愿意”的结论，因为**供应商是否愿意签年单，主要取决于你自身的采购量、品类、账期、价格条款，以及当下双方各自的库存和销售策略**，而不是某家公司固定有个“愿意/不愿意”的标签。这类信息属于企业内部的商务政策，外人无法准确判断，我如果硬说谁更愿意，就是编造。

不过我可以给你几点可判断、可执行的分析框架，帮你谈判时判断：

**1. 两家公司的模式差异（背景）**
- **鑫荣懋**：国内头部水果供应链企业，渠道覆盖商超、电商、批发等，偏“稳定供货、标准化”的打法。
- **洪九果品**：以进口水果（尤其是榴莲、火龙果等）和自有品牌见长，历史上更偏大单品、强渠道分销。

**2. 判断谁更愿意签年单，看这几个条件**
- **你的采购规模**：年采购额越大（比如千万级以上），越有资格谈年单，两家都会有兴趣。
- **品类是否匹配他们的强项**：选他们各自走量、利润稳的品类，年单更容易谈成。
- **付款条件**：现款或短账期，供应商更愿意锁量；长账期会让他们更谨慎。
- **是否接受价格联动**：水果价格波动大，年单通常是“框架量+随行就市价格”或“保底量+浮动价”，纯固定价年单很难谈。
- **淡旺季分担**：你能否在淡季也稳定拿货，帮他们平滑库存，这是加分项。

**3. 实操建议**
- 不要问“谁愿意”，而是**同时向两家发出年单意向询价（RFQ）**，给出你的预估年量、品类、账期、交货要求，看谁响应积极、条件更好。
- 直接问对方的销售：**“年度框架协议你们通常怎么做？保底量、价格机制、账期怎么设？”** 这比问意愿有用得多。
- 如果确实想长期合作，可以先签**半年框架+季度滚动订单**试水，再续年单，双方风险都低。
