# 都乐（Dole）与鑫荣懋进口苹果的产地溯源做法

## 一、先明确一个前提

都乐和鑫荣懋都是**品牌商/进口商**，不是单一产地。同一品牌下会有多个国家、多个果园、多个包装厂的货。所以溯源要分两层做：

1. **品牌/进口商层面**：确认这批货是谁进口、从哪国来的
2. **单品批次层面**：确认这箱苹果具体来自哪个果园/包装厂

超市采购要的是**可验证、可追责**，不是听供应商口头说"这是新西兰的"。

---

## 二、都乐苹果的溯源路径

都乐是国际品牌，进口到中国的苹果常见来自新西兰、美国、智利、南非等。

**要拿到的凭证：**

| 环节 | 凭证 | 核验点 |
|------|------|--------|
| 出口国 | 原产地证（Certificate of Origin） | 出口国官方或授权机构签发 |
| 中国入境 | 入境货物检验检疫证明 | 海关出具，有报关单号 |
| 中文标签 | 预包装食品中文标签 | 产地、进口商、生产日期 |
| 箱码/批次 | 箱体喷码或标签 | 可对应到具体包装厂和日期 |
| 品牌授权 | 都乐中国或授权经销商的供货证明 | 确认货源链路 |

**都乐的特点**：品牌方通常有较规范的批次管理，可以要求供应商提供**都乐官方的批次追溯信息**。都乐部分产品有二维码可查。

---

## 三、鑫荣懋苹果的溯源路径

鑫荣懋（Xin Rong Mao）是国内大型水果进口商/分销商，代理多个国际品牌，也做自有品牌。它的货来源更杂，溯源要更细。

**要拿到的凭证：**

1. **进口报关单 + 入境货物检验检疫证明**（最关键，证明合法入境和原产国）
2. **鑫荣懋出具的批次证明或供货单**，注明：品种、规格、产地国、包装厂编号、生产日期/采摘季
3. **原箱标签**：进口苹果原箱通常有出口商、包装厂代码（如新西兰的 ZGS、美国的包装厂编号）、批次号
4. **中文标签**：符合 GB 7718 的预包装标签

**鑫荣懋的特点**：作为贸易商，它可能同时供多个产地的货，同一SKU不同批次产地可能不同。**必须按批次索证，不能按年度或按品牌一次性索证。**

---

## 四、超市实操建议（可执行清单）

**采购时必做：**

1. **每批次索要三证**：原产地证、入境货物检验检疫证明、报关单
2. **核对原箱喷码**：包装厂代码、批次号、日期，与证明文件对得上
3. **留存中文标签照片**：产地、进口商、日期
4. **要求供应商书面确认**：本批次产地国 + 包装厂 + 采摘季
5. **建立批次台账**：进货日期、批次号、产地、供应商、凭证编号

**抽检验证：**

- 扫描箱体二维码/条形码，看是否跳转到可验证的溯源页面
- 对高单价批次，可要求供应商提供**出口国官方溯源链接**（如新西兰的 NZ Apples、美国的 usapple 相关系统）
- 必要时送第三方做**稳定同位素/元素指纹**检测，用于验证产地真实性（成本较高，适合高风险批次）

---

## 五、关键判断标准

| 能溯源 | 不能溯源 |
|--------|----------|
| 有报关单+检疫证明，批次号对得上 | 只有口头承诺"进口的" |
| 原箱喷码清晰，可对应包装厂 | 散装无原箱、无批次 |
| 中文标签规范，进口商明确 | 标签模糊或后贴 |
| 供应商能提供品牌方批次证明 | 供应商说不清具体产地 |

---

## 六、一句话总结

**都乐**：要品牌方批次追溯 + 进口三证，相对规范。  
**鑫荣懋**：要按批次索证，重点核报关单、检疫证明和原箱包装厂代码，不能按品牌笼统认定产地。

核心原则：**一箱一码、一批一证、证货对应**。做不到这三点，溯源就是空话。
