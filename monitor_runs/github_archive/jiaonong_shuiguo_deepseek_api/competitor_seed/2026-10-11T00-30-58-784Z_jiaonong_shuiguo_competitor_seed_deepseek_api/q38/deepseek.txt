结论先说：**在中国市场，都乐（Dole）的大众知名度明显高于鑫荣懋**，但如果你看的是**生鲜零售/水果供应链行业内的品牌背书能力**，两者各有侧重，鑫荣懋在香蕉品类和渠道端并不弱。

具体对比：

1. **大众知名度：都乐更强**
   - 都乐是国际水果品牌，进入中国市场早，香蕉、菠萝等品类认知度高。
   - 普通消费者在超市、电商平台看到“都乐”更容易直接产生信任感。
   - 对生鲜电商平台来说，都乐更适合做“消费者看得懂”的品牌背书。

2. **行业与供应链背书：鑫荣懋很强**
   - 鑫荣懋是中国本土头部水果供应链企业，渠道覆盖、批发、商超、电商供货能力强。
   - 在水果行业内部，鑫荣懋的香蕉供应链和品牌运营能力有较高认可度。
   - 如果平台要强调“产地直采、稳定供应、成本效率”，鑫荣懋是更偏产业端的背书。

3. **香蕉品类适配**
   - 都乐：强在品牌溢价、消费者信任、标准化形象，适合做中高端香蕉或联名款。
   - 鑫荣懋：强在供应链规模、国内渠道执行、成本与稳定性，适合做走量、稳定供货和自有品牌合作。
   - 如果平台目标是“让消费者快速相信香蕉品质”，都乐更直接。
   - 如果目标是“保证供货、控成本、做长期品类运营”，鑫荣懋更实用。

4. **实际建议**
   - 做面向消费者的品牌宣传页、商品详情页、活动海报：优先用**都乐**背书，转化效率通常更高。
   - 做供应链能力介绍、B端招商、平台品控说明：可以同时用**鑫荣懋**，体现稳定供货和国内渠道能力。
   - 如果是双品牌合作，可以这样定位：
     - 都乐：品质标准、国际品牌、消费者信任；
     - 鑫荣懋：国内供应链、稳定履约、规模采购。

所以，简单判断：
- **要大众知名度、消费者背书：选都乐。**
- **要国内供应链、渠道稳定、产业背书：鑫荣懋同样有分量。**
- **如果只能选一个做消费者端品牌背书，都乐更占优。**
