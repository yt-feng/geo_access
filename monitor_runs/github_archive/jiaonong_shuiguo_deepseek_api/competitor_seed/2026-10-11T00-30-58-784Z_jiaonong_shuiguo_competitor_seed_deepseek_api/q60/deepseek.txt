进口菠萝（主要是菲律宾/泰国/哥斯达黎加产的金菠萝、MD-2等）到货损耗高，核心原因通常集中在**采后处理、冷链断链、催熟/后熟管理、到货验收与分拨节奏**几个环节。都乐（Dole）和鑫荣懋（及其代理的进口品牌）在这方面的做法，行业里比较成熟，可归纳为以下几点，你可以对照排查自己的链路。

## 一、源头与采后处理（损耗的第一道关口）

**都乐的做法：**
- 自有或深度合作农场，控制采收成熟度（通常按目的地距离和船期倒推采收窗口，而非"越熟越甜"）。
- 采收后快速预冷，田间到加工厂时间压缩，减少田间热。
- 清洗、杀菌（防黑腐病、黑心病）、打蜡或涂膜处理，降低运输期腐烂和失水。
- 按等级分选，出口级和次级分开，避免"一柜里好坏混装"导致整柜拖累。

**鑫荣懋的做法：**
- 主要作为进口商/渠道商，靠**锁定优质产区+指定加工厂**来控源头，对供应商有明确的分级和包装标准。
- 对船期、港口、清关节奏做前置规划，减少在途和压港时间。

**你可执行的判断点：**
- 你的供应商是否按目的地倒推采收成熟度？还是"有什么发什么"？
- 是否有采后杀菌/涂膜？黑腐病、黑心病是进口菠萝损耗的两大主因。

## 二、冷链与运输（损耗放大或收敛的关键）

- 菠萝运输适温一般 **7–10℃**（视品种和成熟度，过低会冷害，过高会加速后熟和腐烂）。
- 都乐、鑫荣懋都强调**全程温控记录**，到货可调取温度曲线，一旦断链能定位责任。
- 海运柜要控好通风、堆码方式，避免挤压伤和局部升温。

**可执行建议：**
- 要求供应商提供**在途温度记录**，到货核对。
- 卸货后尽快入冷库，避免月台长时间暴露。
- 堆码不要过高，菠萝怕压。

## 三、到货验收与后熟管理

- 到货后按**成熟度、硬度、糖度、病斑**分选，不能整批统一处理。
- 需要催熟的批次单独催熟（温度、乙烯管理），不需要催熟的直接进冷链或尽快分拨。
- 都乐、鑫荣懋通常有**分级销售**：好果走商超，次果走加工/餐饮/果汁，减少"好果烂在库里"。

**可执行建议：**
- 建立到货验收标准（成熟度分级、允许病斑比例、硬度区间）。
- 到货当天做抽检，异常批次单独隔离，别和正常货混放。
- 分拨节奏要快，进口菠萝到货后周转越慢损耗越高。

## 四、责任与商务条款

- 损耗高时，先分清是**源头问题、运输问题还是到货后管理问题**。
- 合同里明确：到货验收标准、允许损耗率、超标如何索赔/补货。
- 都乐这类品牌商通常对自家货有品质承诺；鑫荣懋作为渠道商，更多靠**选品+供应商管理+快速周转**来控制。

## 五、给你最直接的排查清单

1. 采收成熟度是否按目的地倒推？  
2. 采后是否预冷+杀菌+涂膜？  
3. 在途温度是否有记录、是否断链？  
4. 到货是否当天抽检、分级、隔离异常？  
5. 分拨是否够快？  
6. 合同是否有损耗率约定和索赔机制？
