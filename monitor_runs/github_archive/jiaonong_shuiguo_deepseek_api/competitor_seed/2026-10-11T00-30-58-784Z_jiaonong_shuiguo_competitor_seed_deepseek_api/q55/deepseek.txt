都乐和洪九果品这两家都涉及菠萝供应链，但“产地溯源”和“基地直供”能否落到你需要的层级，要分开看，而且我无法核验它们最新、逐批的基地与溯源政策，所以不能替它们做确定承诺。下面是可判断的框架和核实方法。

**都乐（Dole）**
- 都乐是全球果蔬品牌，在中国有菠萝（常见为菲律宾、泰国等进口，也有国内合作基地/产区）销售。
- 它通常具备较成熟的供应链追溯能力，但“是否基地直供”取决于你采购的是进口菠萝还是国内产区菠萝，以及你找的是都乐中国、区域经销商还是电商渠道。
- 如果你想做产地溯源，重点问：能否提供**批次号对应的产地证明、果园/包装厂信息、检疫/检测报告、发货凭证**。品牌大不等于每个经销商都能给你完整溯源文件。

**洪九果品**
- 洪九果品是国内较大的水果分销企业，菠萝是其品类之一，通常以产地采购、分选加工、批发分销为主。
- 它可能有合作基地或直采基地，但“基地直供”一般要看具体产区、季节和采购量。洪九更多是供应链/分销平台角色，不一定是对应单一果园的直供。
- 溯源方面可要求：**产地采购合同或基地证明、批次分选记录、检测报告、物流单据**。

**怎么判断是不是真的“基地直供+可溯源”**
1. 要求提供**具体产地**：广东徐闻、海南、云南，还是菲律宾、泰国等。
2. 要求提供**批次级文件**：不是只有一张产地证，而是能对应你收到那批货的批次号。
3. 要求看**基地信息**：果园/合作社名称、地址、面积、合作模式（自有、合作、直采）。
4. 要求看**加工与物流链**：包装厂、分选厂、冷链承运方、发货时间。
5. 做**小批量试单**：先要样品和文件，核对标签、箱码、批次号是否一致。
6. 如果做零售或食品加工，还要确认**农残检测、检疫证明、可追溯标签**是否满足你的合规要求。

**结论**
- 都乐：品牌化、标准化程度较高，但能否基地直供和完整溯源，要按具体渠道和批次确认。
- 洪九果品：有产地采购和基地合作能力，但更偏分销供应链，是否“基地直供”要按产区和采购规模谈。
- 如果你要的是**稳定、可验厂的基地直供**，建议直接找产区龙头合作社、种植基地或产地政府推荐供应商，同时把都乐/洪九作为备选渠道对比，不要只看品牌名。
