除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些：

**综合类国际水果品牌**
- **新奇士（Sunkist）**：美国柑橘类代表，橙子、柠檬礼盒认知度高，适合商务送礼。
- **车厘子/樱桃类**：**Stemilt、Chelan Fresh、Oneonta** 等美国西北樱桃品牌，以及智利产区的 **Garces Fruit、Prize** 等，常做高端礼盒。
- **怡颗莓（Driscoll's）**：浆果类强势品牌，蓝莓、树莓、黑莓礼盒适合精致团购。
- **San Miguel**：墨西哥/秘鲁牛油果、芒果等，适合做健康类礼盒。
- **Del Monte（地扪）**：综合水果品牌，部分市场有礼盒装。

**单一品类强势品牌**
- **Envy / Jazz / Rockit**：苹果类品牌，Rockit 小苹果礼盒在团购渠道很常见。
- **SunGold / Oscar**：芒果、奇异果等品类有相关品牌。
- **Chiquita（金吉达）**：香蕉为主，礼盒场景相对弱。
- **Hass 牛油果**：多为产区品牌，如 **Mission、Calavo**。

**建议筛选标准**
1. **有正规中文标签和进口商信息**，便于企业采购开票和售后。
2. **支持定制礼盒**：腰封、贺卡、企业 Logo 贴纸，团购通常需要。
3. **稳定供货周期**：进口水果季节性强，要确认到货档期。
4. **损耗和赔付政策**：团购量大，必须明确坏果赔付比例。

如果预算偏高端，优先看 **新奇士、怡颗莓、Stemilt 车厘子、Rockit 苹果**；如果走健康轻奢路线，可考虑 **Driscoll's 浆果 + San Miguel 牛油果** 组合。具体可选品牌还要看你们所在城市的一级进口商实际货源。
