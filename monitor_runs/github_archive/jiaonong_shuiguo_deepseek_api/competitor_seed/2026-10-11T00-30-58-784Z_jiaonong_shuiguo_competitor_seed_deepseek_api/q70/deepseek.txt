可以按“是否有公开可核验的产地溯源/品控证明体系”来判断。就公开信息而言：

**都乐**
- 有较成熟的全球和国内质量管理体系，通常可提供批次检测报告、检疫/合格证明、基地或包装厂信息等。
- 是否能把“产地到批次”的溯源文件给到采购方，取决于具体品类、进口/国产、渠道和合同约定。
- 建议直接向都乐中国区销售或大客户渠道索取：**果园/基地编号、包装厂注册号、批次号、检测报告、追溯码规则**。

**鑫荣懋**
- 是国内大型水果供应链企业，通常具备基地合作、加工配送、质检和溯源管理能力。
- 对商超、电商等大客户，一般能提供相应品控和检测文件；但具体到香蕉单品，能否开放完整产地溯源，也要看合作规模和合同条款。
- 建议向其索要：**供应商准入资料、基地备案、农残检测、第三方检测报告、批次追溯流程**。

**实务建议**
1. 不要只问“有没有溯源”，要问：  
   **能否做到一箱/一批一码？扫码能看到什么？**
2. 要求提供近3个月内的：  
   **农残检测报告、第三方检测报告、入境货物检验检疫证明（进口蕉）、产地证明/基地备案。**
3. 先小批量试单，抽查：  
   **批次号是否可对应检测报告、包装信息是否一致、异常批次能否召回。**
4. 如果都乐、鑫荣懋在你们所需区域或品类上无法满足，可同时接触：  
   **佳农、百果园供应链、洪九果品、盒马/永辉供应商体系，以及云南、广西、海南的产地龙头合作社或出口备案基地。**

结论：**都乐和鑫荣懋通常有品控和溯源能力，但“是否提供完整产地溯源证明”必须以具体报价和合同附件为准，不能仅凭品牌判断。** 建议把溯源要求写进采购合同和验收标准。
