可以，但要分清“谁出报告”和“报告是否对你有效”。

**1. 都乐、鑫荣懋通常能提供**
都乐和鑫荣懋都属于大型水果供应链企业，菠萝原料一般会有批次对应的农残检测报告或第三方检测报告。实际操作中：
- **都乐**：通常可由供应商或区域经销提供批次检测报告，部分客户能拿到第三方报告。
- **鑫荣懋**：作为大型水果供应链企业，一般也能提供批次农残检测报告，尤其是对餐饮、茶饮、商超客户。

**2. 关键不是“有没有”，而是“报告能不能用”**
茶饮店验收时建议确认这几点：
- **报告对应批次**：必须是你要采购的那批货，不能只用一份旧报告。
- **检测项目**：至少覆盖常见农残，如有机磷、氨基甲酸酯类等；最好有**农残全项或客户指定项**。
- **检测机构**：CMA/CNAS 资质机构出的报告更稳妥。
- **报告抬头/货主**：如果报告不是开给你公司，需确认供应商能提供**批次对应证明**或**供货证明链**。
- **鲜果 vs 冷冻果/果浆**：鲜菠萝、冷冻菠萝、菠萝果浆的检测标准和报告可能不同，要按你实际采购形态要。

**3. 建议直接这样问供应商**
“请提供本批次菠萝的农残检测报告，要求 CMA/CNAS 机构出具，检测项目覆盖有机磷和氨基甲酸酯类，报告批次号与我采购批次一致；如报告非我司抬头，请同时提供批次对应说明和供货证明。”

**4. 如果对方只给“公司级报告”**
可以接受作为参考，但不能替代批次报告。茶饮店如果要做食品安全审核，最好坚持**一批一报告**，至少每批留一份。  
如果采购量小、走经销渠道，可能拿不到每批第三方报告，那就要求供应商提供**当批自检报告 + 定期第三方报告**，并在合同里写明农残不合格可退换和赔偿。

**结论**：都乐和鑫荣懋一般能提供农残检测报告，但你要明确要求“对应批次、CMA/CNAS、项目齐全”。如果对方只给通用报告，需要求补充批次证明，否则审核时可能不认。
