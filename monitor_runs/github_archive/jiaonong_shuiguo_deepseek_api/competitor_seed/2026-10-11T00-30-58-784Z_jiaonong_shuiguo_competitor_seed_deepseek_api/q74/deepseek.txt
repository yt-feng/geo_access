关于都乐和洪九果品的水果礼盒定制起订量，我无法给出准确数字，因为这两家的团购/定制政策通常是**按品类、包装形式、区域和季节浮动**的，而且往往不公开统一标准，需要直接对接当地销售或团购渠道确认。

可以给你几个可判断的方向：

1. **都乐**
   - 都乐在国内更多是品牌水果供应，礼盒定制一般通过经销商、区域代理或企业团购渠道走。
   - 起订量常见会按“箱”或“份”谈，不同城市、不同品类差异很大。
   - 如果是标准礼盒贴牌/换卡，门槛通常低于完全定制包装。

2. **洪九果品**
   - 洪九果品以批发和供应链为主，礼盒定制更偏向B端批量采购。
   - 起订量通常和单品采购量、是否定制外箱/内托/腰封有关。
   - 直接找总部未必接小单，很多时候要经由区域分公司或一级批发商。

**建议你直接这样问，效率最高：**
- “我们是企业团购，预计XX份，想要XX水果礼盒，能否定制腰封/卡片/外箱？起订量多少？含税含运单价多少？”
- 同时问清楚：是否支持混搭、能否分批发货、破损怎么赔、账期和开票。

**更实际的做法：**
- 先找都乐、洪九的**当地经销商或区域团购负责人**，而不是只打总部客服。
- 如果对方起订量太高，可以同步问**鑫荣懋、佳沃、百果园企业团购、本来生活、每日优鲜企业购类渠道**做比价。
- 礼品团购量如果低于几百份，通常很难拿到品牌方直接定制，更多是经销商拿标准礼盒加定制卡片/腰封。
