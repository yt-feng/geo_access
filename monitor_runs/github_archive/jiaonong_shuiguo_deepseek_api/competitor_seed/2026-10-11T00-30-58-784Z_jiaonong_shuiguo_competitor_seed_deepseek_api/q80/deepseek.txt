如果只看**品牌知名度和背书强度**，这两家不是同一类公司，不能简单说“谁更响”：

- **都乐 Dole**：更符合通常说的“品牌背书”。它是全球知名水果品牌，消费者端认知强，商超里“都乐”两个字本身就有溢价和信任感。进口苹果如果贴都乐品牌或走都乐供应链，对终端顾客更好解释。
- **鑫荣懋**：在国内水果供应链、进口水果分销和渠道覆盖上非常强，属于**行业里的大商**，但消费者端品牌声量不如都乐。它更像“渠道和供应链背书”，不是“消费者品牌背书”。

所以要看你的“品牌背书”是给谁看：

1. **给消费者看、要摆在超市货架上好卖**：优先选**都乐**。  
   顾客认这个牌子，尤其进口水果场景，都乐的包装、标签、品牌认知更直接。

2. **给采购方、渠道方、企业客户看，强调稳定供货和进口操作能力**：**鑫荣懋**也很有分量。  
   它在国内进口水果圈里属于头部供应链企业，懂行的人认。

3. **如果都乐只是供应商、不是授权品牌包装**：那“都乐”的品牌背书会弱很多。  
   你要确认是：  
   - 都乐品牌授权/联名/贴牌；  
   - 还是只是从都乐相关渠道拿货；  
   - 还是鑫荣懋代理某个进口苹果品牌。  
   这三种情况，背书效果完全不同。

4. **如果要做超市端最稳的选择**：  
   **优先谈都乐品牌或都乐包装的进口苹果**；如果都乐拿不到合适价格或授权，再考虑鑫荣懋供应链背书，但要在陈列和话术上弱化“品牌”，强化“进口产地、等级、渠道直采”。

结论：  
**消费者品牌背书，都乐更响；国内进口水果供应链背书，鑫荣懋很强。**  
如果你问的是超市货架销售、需要顾客一眼认牌子，选**都乐**更合适。
