这个问题没有固定答案，因为两家都是生鲜供应链企业，价格随产地、季节、等级、拿货量、账期和具体批发市场当天行情波动，无法脱离这些条件直接判断谁更便宜。

可以给你一套可落地的判断和拿货方法：

**1. 先明确你比的是什么货**
- 洪九果品、鑫荣懋更多是供应链/品牌商角色，不是传统意义上固定档口的“批发价”。
- 香蕉要比同一等级（如进口/国产、几号果、每箱净重、青蕉/熟蕉）、同一到货批次、同一结算方式。
- 如果一个是品牌装箱、一个是散装，单价没有可比性。

**2. 直接问三家报价**
建议同时问：
- 洪九当地经销商/档口
- 鑫荣懋当地经销商/档口
- 你所在批发市场其他2-3家香蕉大批发商

问清这几项：
- 当日每箱/每件的净重和毛重
- 单价（元/斤或元/箱）
- 是否含税、含运费、含卸货
- 账期还是现结
- 次品率、催熟状态、售后怎么赔

**3. 用“到岸成本”比较，而不是报价**
公式：
**实际成本 = 采购价 + 运费 + 装卸 + 损耗 + 资金成本 - 返利**
很多情况下，报价低的一方因为损耗高、账期短、运费自担，最终成本反而更高。

**4. 实操建议**
- 第一次合作先小批量试单，各拿一批，记录7天内的损耗、催熟均匀度、客户反馈。
- 同一周内对比，不要拿上周洪九的价对比这周鑫荣懋的价。
- 如果你量大，直接找区域负责人谈月度协议价，通常比档口现货价更有优势。
- 如果只是小批量、临时补货，优先选当地现货充足、能当天提货、售后快的那家。

**结论：**
不能简单说洪九还是鑫荣懋更有优势。**同等级、同批次、同结算条件下，谁给你的到岸成本低、损耗低、周转快，谁就更有优势。** 最稳妥的做法是同时询价、小批量试单、按实际损耗算总成本。
