目前我无法核验鑫荣懋、都乐针对便利店渠道的实时在售规格，不能直接给准确SKU。以下是可执行的判断与对接方式：

**便利店小包装香蕉常见规格方向**
- **单根装/2根装**：适合即买即食，通常按根售卖或挂条陈列。
- **3-5根小把装**：适合1-2人单次消费，常见于便利店冷柜旁或收银台附近。
- **150g-500g小包装**：部分品牌会做定量预包装，方便标价和控损。
- **即食蕉/超小蕉**：如小米蕉、皇帝蕉等，单根小、适合小包装。

**鑫荣懋与都乐**
- 这两家都属于头部香蕉供应商/品牌商，通常有**多渠道分规格**能力，但是否有便利店专用小包装，取决于区域、季节、客户定制和最小起订量。
- 都乐在零售端常见品牌香蕉，但便利店小规格更多可能是**区域经销或定制包装**，不一定是全国统一标品。
- 鑫荣懋渠道覆盖广，便利店小包装往往需要按客户需求做**定制规格、定制标签、定制箱规**。

**建议直接问供应商这几个问题**
1. 有没有**便利店渠道现成小包装规格**：单根、2根、3-5根、150g/250g/500g？
2. 是**固定标品**还是**客户定制**？起订量多少？
3. 包装形式：挂条、托盘覆膜、袋装、盒装？
4. 是否支持**即食催熟度**和**短保配送**？
5. 配送温度、频次、损耗赔付政策？
6. 能否提供**便利店渠道已有案例**和对应规格？

**更稳妥的采购做法**
- 先让两家供应商提供**规格表+报价单+样品**。
- 若他们没有现成小包装，可要求做**区域定制小包装**，通常比找新供应商更稳。
- 同时对比本地香蕉催熟配送商，便利店小包装往往本地供应链更灵活。
