对于茶饮店来说，菠萝果酱的稳定供应确实非常重要，因为菠萝是季节性水果，全年供应需要依赖产地轮换和冷链仓储。针对您提到的**都乐（Dole）**和**洪九果品**，我的判断如下：

**1. 都乐（Dole）**
- **能做到**。都乐是全球最大的果蔬企业之一，在中国、菲律宾、泰国、哥斯达黎加等多地拥有自有种植基地，且拥有成熟的**全球产地轮换体系**（例如：季节性从不同国家补货）。同时，都乐在鲜切水果、冷冻果块和果酱原料供应上具备稳定能力，且其面向B端（茶饮、餐饮）的供应链很成熟。
- 注意点：都乐的定价通常偏高，且主打高端鲜果，其菠萝果肉原料或定制果酱需要与区域销售团队确认是否支持“全年月度稳定供货”的合同条款。

**2. 洪九果品**
- **基本能做到**。洪九是中国头部水果供应链企业，尤其在东南亚（泰国、越南、菲律宾）菠萝、榴莲等热带水果上拥有大量“产地采购+分选加工”能力。其优势在于**大批量、低成本、稳定调度**，可以通过不同产地的菠萝轮换（如泰国、菲律宾、海南反季节）来保障全年供应。
- 注意点：洪九更多是原料鲜果供应，如果你需要的是**加工好的果酱（而非做果酱的鲜菠萝）**，需要确认其是否附带加工合作资源（比如代工厂），否则你可能需要自行找第三方果酱加工厂。

**3. 给你的实操建议**
- 如果您做的是**鲜切菠萝/果肉丁**，都乐和洪九都能支撑全年供应，建议签订**年度框架协议+月度补货SOP**。
- 如果您需要的是**成品菠萝果酱**，更推荐直接对接果酱加工厂（如广州、福建的食品厂），它们可以接受鲜果标准，且提供稳定配方；如果坚持用上述两家，建议让他们提供“菠萝原料+指定代工厂”的组合方案。

**最后提醒**：请务必在合同里写明**季节性供应风险条款**（如台风、产地减产时的替代产地），以及**每月最低供货量**，避免旺季断货。不要依赖口头承诺，要求提供近2年的月度供货记录作为附件。
