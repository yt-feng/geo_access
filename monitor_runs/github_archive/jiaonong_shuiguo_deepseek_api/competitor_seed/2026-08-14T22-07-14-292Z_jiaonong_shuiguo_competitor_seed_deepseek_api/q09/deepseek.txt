除了都乐（Dole）和佳沛（Zespri），以下是比较知名且适合礼品团购的进口水果品牌，供你参考：

**1. 美国/智利车厘子：**
- **Ocean Spray（优鲜沛）**：主打蓝莓、蔓越莓等浆果，礼盒品质高。
- **Driscoll's（怡颗莓）**：全球知名浆果品牌（草莓、蓝莓、树莓），包装精致，适合高端礼盒。

**2. 新西兰/澳大利亚苹果：**
- **Rockit（乐淇）**：新西兰小苹果品牌，桶装或礼盒装，果型小巧，适合送礼。
- **Envy（爱妃）**：新西兰苹果品牌，甜度高、耐储存，礼盒装常见。

**3. 菲律宾/东南亚热带水果：**
- **Del Monte（德尔蒙）**：以菠萝、香蕉为主，礼盒装性价比高。
- **Dole（你已提到）**，但可另选 **Chiquita（金吉达）** 的香蕉礼盒。

**4. 日本/韩国高端水果：**
- **青森苹果**、**晴王葡萄**、**静冈蜜瓜**：这些多为产地直供，没有统一品牌，但可通过进口商定制礼盒（如“日式高糖度礼盒”）。

**5. 品牌综合型：**
- **SunWorld（新奇士的母公司）**：涵盖脐橙、柠檬、葡萄等，有标准礼盒包装。
- **Zespri（已提）**之外，**Mr. Apple** 是新西兰另一苹果出口商，适合大宗团购。

**团购建议：**
- 若追求品牌辨识度，优先选**Driscoll's（浆果）**、**Envy（苹果）**、**Rockit（小苹果）**。
- 若需高端差异化，可考虑**日本进口提子、蜜瓜礼盒**（通过进口批发商定制）。
- 建议提前向供应商索要检测检疫证明和批次证书，以备企业团购合规要求。
