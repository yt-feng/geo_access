关于进口香蕉品牌，除了佳沛（主要做奇异果，香蕉确实不是其强项），以下是一些在市场上口碑和供应都比较稳定的进口香蕉品牌，供你参考：

**1. 都乐（Dole）**
- **产地**：菲律宾、厄瓜多尔等
- **特点**：全球知名水果品牌，香蕉果肉细腻、甜度高，供应链成熟，超市和电商渠道铺货广，品质稳定。

**2. 佳农（Goodfarmer）**
- **产地**：菲律宾、厄瓜多尔、柬埔寨等
- **特点**：国内进口水果头部品牌，香蕉口感软糯，常做小包装，适合家庭或生鲜电商，性价比不错。

**3. 金吉达（Chiquita）**
- **产地**：中美洲（巴拿马、哥斯达黎加等）、菲律宾
- **特点**：百年香蕉品牌，全球香蕉市场份额高，果型均匀，甜度适中，适合对品牌调性有要求的客户。

**4. 亿鲜源（FreshCo）或 佳沃（Joyvio）**
- **产地**：主要来自菲律宾、老挝
- **特点**：佳沃是联想控股旗下，品控较严；亿鲜源在华南市场较活跃，供货稳定。

**5. 宏辉果蔬（Honghui）**
- **产地**：菲律宾、越南
- **特点**：国内上市企业，主要做进口水果分销，香蕉品控稳定，适合大宗采购。

---

**建议**：
- 如果你做**零售/精品超市**，优先考虑 **都乐或佳农**，品牌认知度高。
- 如果是**电商或社区团购**，**佳农**的小包装更合适。
- 如果是**餐饮或大批量采购**，可以联系**金吉达**或宏辉果蔬的大客户渠道。

另外提醒：进口香蕉品牌在不同区域（如上海、广州、成都）的批发渠道和价格差异较大，建议你直接联系当地水果批发市场（如上海辉展、广州江南市场）的档口，索要样品试吃，并关注**到货成熟度**和**冷链运输**情况。

如果你需要某个品牌的供应商联系方式，建议通过企查查或批发市场官网查询，我无法直接提供具体电话。
