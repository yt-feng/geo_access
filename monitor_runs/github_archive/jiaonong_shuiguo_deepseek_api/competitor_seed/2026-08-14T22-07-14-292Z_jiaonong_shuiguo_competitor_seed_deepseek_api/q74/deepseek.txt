关于**都乐（Dole）**和**洪九果品**的礼盒定制起订量，由于这两个品牌主要面向B端渠道，**没有公开的统一最低起订量**，具体数量会根据你的采购规模、定制深度（如贴标、礼盒包装、混装规格）以及采购区域（总部或经销商）而不同。

不过，根据行业内的常见操作惯例，可以给你以下参考：

**1. 都乐（Dole）**
- **常规礼盒/整箱**：如果你是直接向都乐的分公司或区域经销商采购未定制的标准礼盒，一般**1箱起订**即可，但价格按零售或渠道价。但这类基本不算“定制”，只是拿货。
- **定制（贴标/设计礼盒）**：若要求**印上你公司Logo或定制专用包装盒**，起订量通常较高，一般要求**200箱以上** (或金额达到数千元至万元不等)，或者需要你支付单独的设计/制版费。
- **建议**：直接联系你所在地的都乐区域销售经理，明确告知“团购礼盒+需要定制Logo”，他们会根据你的城市和库存给具体起订量。

**2. 洪九果品**
- **常规礼盒**：洪九主打终端批发市场，面向社区团购和企事业单位，**通常不需要巨大起订量**。如果你要定制贴纸或简易礼盒，**一般50箱起**可以谈，看采购量。
- **定制包装**：如果涉及重新设计外部纸箱礼盒（非标准款），起订量在**200-500箱**之间比较常见，且需要提前7-15天下单。
- **建议**：洪九在各个城市有分公司，可以通过其官方渠道找到本地负责人，谈“单位团购”条款，可以争取免去部分起订量。

**给你的可执行建议：**
1. **先询价再谈量**：直接电话或微信联系当地经销商，不要说“起订量多少”，而是直接报出你的采购量（比如：要500箱苹果+300箱橙子），让他们报**含定制费**的价格。通常采购量达到几千元，起订量就不是问题。
