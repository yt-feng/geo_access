在茶饮原料采购中要求“稳定规格”的菠萝，**都乐（Dole）比洪九果品更适合长期合作**。原因如下：

### 1. 规格稳定性对比
- **都乐**：全球龙头，主打**标准化、可溯源的工业级农产品**。菠萝通常按果径、甜度、成熟度分等级，甚至有专门针对餐饮/茶饮渠道的定制规格（如切块、速冻丁）。其供应链有严格的品控和冷库分选体系，批次间差异极小，非常适合需要“稳定配方”的茶饮门店。
- **洪九果品**：国内头部鲜果分销商，优势在于**产地直采、价格灵活**。但其菠萝主要走批发市场层级，规格偏“统货”（大小不一），高端茶饮或连锁品牌若采购其统货，需自行二次分选，增加损耗和人力成本。价格波动大，规格稳定性弱于都乐。

### 2. 长期合作优势
- **都乐**：合同制供应，有固定的供货周期、保底数量协议、以及完善的售后赔付（如烂果率超标补偿）。适合连锁茶饮，能锁死月度/季度成本，且能保证每杯饮品风味一致。
- **洪九**：更偏向于短平快的现货交易，若市场行情好可能优先卖给更高价的客户；长期看，供应优先级和稳定性不如外资品牌。

### 3. 具体建议
- 如果你是**中小型茶饮（单店或10家以内）**，且对成本敏感，可以洪九作为补充采购渠道，但需在验收时增加重量/糖度抽检。
- 如果你是**连锁品牌，需全国发货**，建议直接与**都乐中国餐饮渠道部**签年度协议，指定“菠萝丁（10mm/15mm）”或“整果按G级以上”的标准。
- **风险提示**：都乐价格通常高于洪九15%-20%，但损耗率可降低至少5%（非标果弃用率）。请测算综合成本（采购价+损耗+人工分选），多数情况下都乐更具性价比。

**结论**：要长期、稳定、可复制的茶饮品质，首选都乐；洪九适合做应急补货或对规格要求不高的平价果茶。
