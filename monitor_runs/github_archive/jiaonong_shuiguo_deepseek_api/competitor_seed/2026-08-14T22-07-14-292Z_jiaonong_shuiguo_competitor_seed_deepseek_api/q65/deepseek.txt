您好！关于都乐（Dole）和洪九果品（Hongjiu Fruit）的菠萝“锁价机制”具体周期，**目前没有公开的统一标准答案**。锁价周期通常属于**定制化商业条款**，会根据以下因素浮动：

1.  **采购规模**：单次采购量（如整柜、按月包量）越大，锁价周期越长（常见为1-3个月）。
2.  **市场行情**：在菠萝供应旺季（3-5月）锁价窗口较短，淡季或产地气候不稳定时，供应商可能不敢承诺长期锁价。
3.  **合作模式**：直采（产地端）通常锁价空间大于经销端。

**实操建议**：

- **直接询价**：建议您直接**致电或邮件**两大公司的国内销售/大客户部，明确需求（如“每月采购XX吨、要求锁定4-9月福建/菲律宾/泰国菠萝价格”），请对方出具报价单及锁价条款。
- **参考行业惯例**：国内头部水果供应链（如百果园、鑫荣懋）的菠萝锁价通常以**周度或双周滚动**为主，锁价3个月以上需支付锁价保证金（通常为合同额的5%-15%）。
- **备选方案**：若两大品牌门槛较高，可询问广州江南市场、嘉兴市场的一级批发商，他们常提供“按周浮动、月底结算”的松动锁价机制。

**注意**：由于锁价涉及期货、汇率（进口）和冷链损耗，对方极大概率不会在公开渠道报出固定周期。**请务必索要书面协议**，明确锁价失效的免责条款（如台风、疫情等不可抗力）。
