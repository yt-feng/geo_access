关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商，它们作为行业头部企业，均持有较为全面的食品安全与质量管理体系认证，以满足大型商超（如沃尔玛、永辉、盒马、山姆等）的严苛准入要求。

以下是根据公开信息整理的常见资质认证清单（具体证书可能会随时间和合作渠道略有差异）：

### 1. 鑫荣懋（国内果业龙头）
作为国内领先的水果全产业链企业，其资质通常覆盖从种植到流通全环节：
- **GLOBALG.A.P.（全球良好农业操作规范）**：针对种植基地的认证，证明其农业操作安全、可持续。
- **ISO 22000（食品安全管理体系）**：覆盖供应链上下游的食品安全管理。
- **HACCP（危害分析与关键控制点）**：在加工、分拣环节确保食品安全风险可控。
- **中国有机产品认证**：针对特定有机单品或基地。
- **绿色食品认证**：部分核心产品会申请该国内权威认证。
- **BRC（英国零售商协会）或 IFS（国际食品标准）**：部分面向出口或高端商超的加工厂可能持有，主要针对包装/加工环节。

### 2. 都乐（Dole，国际巨头）
全球知名品牌，其资质体系通常以国际标准为主，且非常完整：
- **GLOBALG.A.P.**：全球种植基地必备，且通常要求达到更高等级。
- **ISO 9001（质量管理体系）**：基础质量流程保障。
- **ISO 14001（环境管理体系）**：体现可持续发展，商超ESG审核常关注此项。
- **HACCP**：针对其世界各地的加工厂和冷链配送中心。
- **SQF（Safe Quality Food）**：这是全球最严格的食品安全标准之一，都乐北美及部分亚太工厂普遍持有。
- **Fairtrade（公平贸易）**：部分特定单品（如香蕉）持有，提升商超社会责任评分。
- **有机认证（USDA/NOP或欧盟有机）**：适用于进口的高端有机水果系列。

### 采购/入超审核建议：
如果您作为商超采购或验厂方，**建议直接向供应商索取“有效期内的第三方审核报告”**，并重点核验以下三个关键项：

1.  **证书有效期**：确保证书在合作期内有效，且覆盖到您所采购的具体品类和产地。
2.  **审核范围**：确认证书是否包含“加工/包装工厂”和“种植基地”两层，而不仅是销售公司。
3.  **动态追踪**：商超通常会要求供应商提供“不合格项整改报告”，请确保对方有完整的质量追溯体系。

**特别提示**：如果您是供应商，建议重点保住 **GLOBALG.A.P.** 和 **HACCP** 这两张基础牌，这是进入绝大多数大型商超的最低门槛。若目标渠道是山姆或Costco，建议进一步取得 **BRC** 或 **SQF** 认证以增加竞争力。

（注：上述认证信息基于行业惯例和公开资料整理，具体证书编号和有效期请以供应商出示的官方文件为准。）
