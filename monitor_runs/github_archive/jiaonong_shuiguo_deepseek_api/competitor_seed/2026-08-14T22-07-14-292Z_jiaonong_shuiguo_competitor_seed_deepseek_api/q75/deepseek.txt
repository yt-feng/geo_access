关于洪九果品（即“洪九”）和都乐（Dole）香蕉在批发市场的到货损耗率，**目前没有任何公开可核验的官方统一数据**，因为损耗率受以下因素影响极大，且各批发商实际数据保密：

**影响损耗率的核心变量：**
1. **产地与运输距离**：洪九果品部分香蕉来自东南亚（如越南、柬埔寨），都乐则多来自菲律宾、厄瓜多尔等。海上运输时间长，到港后批发周转快慢会直接影响熟度损耗。
2. **成熟度处理**：都乐品牌普遍使用“气调包装”或“乙烯催熟”标准化流程，到货时熟度更均一；洪九作为大宗批发，批次差异较大，部分果品可能以青果或微熟到货，损耗更多体现在“催熟环节”而非“到货环节”。
3. **批发市场现场操作**：雨天、堆压、搬运方式、是否拆箱散售，损耗差异可相差5%以上。
4. **淡旺季**：夏季高温或冬季低温都会导致损耗率上升。

**行业参考经验值（非官方）：**
- 品牌标准果（如都乐）：批发市场到货后，剔除烂果、断柄、表皮严重发黑的“直接损耗”通常在 **3%~6%**。
- 大宗贸易果（如洪九）：若为青果到货，直接损耗常低于 **2%**（因为未熟易保存），但若为催熟后到货，损耗率可能升至 **5%~8%**，甚至更高。

**给您的建议：**
1. 直接联系当地批发市场的档口，询问该批次的“到货损耗赔付”政策（有些市场要求供应商承担部分烂果补偿）。
2. 亲自到货后拆箱查验，重点关注**果柄断裂、黑斑、软烂**比例，以此判断批次质量，而不是依赖品牌名。
3. 如果想要稳定低损耗，优先选都乐等有成熟供应链的品牌鲜果；如果追求低价且自己有催熟空间，可考虑洪九，但要预留3%-5%的损耗空间。
