对不起，我无法直接比较洪九果品和鑫荣懋这两家公司的具体进货价格，因为它们的定价策略、区域市场、产品分级和渠道政策都不尽相同，且没有公开的统一价目表可供核验。

不过，我可以给你一些实用的判断方向：

1. **洪九果品**：主攻榴莲、山竹等进口高端水果，以及部分国产精品，其供货模式是“产地直采+大型分销”，更侧重批发大客户和连锁商超。它的价格通常较高，但胜在货源稳定和品质把控，不太适合价格极度敏感的夫妻老婆店作为主力进货渠道。

2. **鑫荣懋**：覆盖面更广，从进口到国产、从低端到高端都有，在部分区域市场（尤其华南）有较强的分销网络。对于下沉市场，鑫荣懋有时会有促销政策或尾货处理，价格可能更低，但这主要取决于所在城市或批发市场的经销商实力。

**实际建议**（供你操作）：
- **问当地批发市场**：直接去你所在城市的农产品批发市场，问两家在当地的总代理商要当日报价单。通常“当天现金结算”的价格会比官方指导价便宜10%-20%。
- **对比同等品质**：价格敏感不等于只买最便宜。比如同样一箱苹果，洪九的可能是特级果，鑫荣懋的可能是统货，后者单价可能便宜30%，但损耗率也高。你要核算“到店成本价+损耗后”的实际毛利。
- **小批量试单**：两家都拿少量货试销一周，记录实际售罄率和退货率，再决定主供渠道。

如果你告诉我具体城市和主卖品类（比如香蕉、橙子还是进口水果），我可以帮你大致估算哪家更具价格优势。但仅凭“下沉市场”这一条件，我无法给出确定性结论。
