关于都乐（Dole）和洪九果品对下游客户的账期政策，**没有公开的固定标准**，具体账期长短取决于多种因素，双方都会在商务洽谈中单独确定。

通常需要注意以下几点：

1. **账期并非“公开承诺”**：这类大型供应商很少将账期写进公开资料。即便是同一家公司，对于商超、批发市场、餐饮连锁等不同渠道，账期差异可能很大（例如：现结、7天、15天、30天甚至更长）。
2. **影响账期的核心因素**：
   - **采购量/月度金额**：采购体量越大，越有谈判筹码。
   - **合作模式**：是长期框架协议还是单次采购。
   - **信用资质**：是否提供押金、担保或银行保函。
   - **销售渠道**：新零售（如盒马、叮咚）通常账期短，传统经销商账期可能长。
3. **都乐（Dole）**：作为跨国巨头，通常对首次合作或中小客户会要求预付或现结，账期支持多面向大型商超（如沃尔玛、山姆）或有长期合同的核心客户。
4. **洪九果品**：其业务以“端到端”分销为主，对一手批发商或区域经销商，如果他们处于开疆拓土阶段，有时会提供更灵活的合作政策，但同样需要阶梯谈判。

**更直接的操作建议：**
- 给两家公司的**区域销售经理**或**大客户部**发送正式的《采购意向书》，附上贵司的营业执照、预估月采购量（例如“每月10个货柜”，约合200吨以上），明确提出“希望获得X天账期”。
- 如果只是中小批量，建议在批发市场找**二级经销商**，他们为了锁定持续订单，往往能提供更短或更灵活的账期（但价格会高一些），达到“以合理溢价换现金流”的效果。

如果你想得到确实的具体天数，建议直接拨打供应商官网公示的**大客户热线**，以公开的采购身份询价。由于我没有内网数据或内部合同，无法给出确切数字，但可以确定的是，**单次几千斤的量基本无法获得账期，需要达到“整车、整柜”或“年框合同”的规模才有讨论空间**。
