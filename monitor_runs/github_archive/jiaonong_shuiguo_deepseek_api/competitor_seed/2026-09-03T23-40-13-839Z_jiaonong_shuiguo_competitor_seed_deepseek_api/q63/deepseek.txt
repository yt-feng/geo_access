关于你提到的**都乐（Dole）**和**洪九果品**是否有**香蕉散装/小包装**选项，我的核实和建议如下：

### 一、直接结论
1. **都乐（Dole）**：  
   - **官方公开信息中，其主营产品以“整箱”“标准果”为主**（如5-7根/把的常规捆装、按件批发），**没有明确的“散装小包装”公开报价或服务**。  
   - 建议直接联系都乐的**社区团购/批发渠道部门**（通常通过当地经销商），询问能否**按“把”或“小箱”供货”，一般经销商可以灵活拆分为10-20斤的小件。

2. **洪九果品**：  
   - 洪九主要面向大型商超、批发市场，**以小包装“香蕉单把”或“小件（约5-10斤/件）”为主**，常用于社区零售。  
   - 其部分区域经销商**支持散装**，但需要你提前确认当地分公司的最低起订量（通常20件起，但也有针对社区团购的试单政策）。

### 二、可执行建议（按优先级）
如果你现在要尽快落实采购，请按以下顺序行动：

1. **打通本地一级经销商**（最快）：  
   - 打电话给当地水果批发市场（如广州江南市场、上海辉展、成都濛阳等），直接问：“我要社区团购，要Dole或洪九的香蕉，能否按10-15斤/件的**拆零小包装**供应？有没有起订量？”  
   - 多数大型批发商会同意拆分，价格比整箱高约5%-10%，但灵活。

2. **平台询价**：  
   - 在**快驴、美菜、蜀海**等B2B生鲜平台上，直接搜索“都乐香蕉小包装”或“洪九香蕉”，部分城市已有规格为“5斤/袋”或“3把/件”的团购件。

3. **替代方案（短期应对）**：  
   - 如果上述品牌暂无小包装，可用**国产香蕉（如云南蕉、海南蕉）**做小包装，成本更低，但请确认品控和甜度是否符合你的社区定位。

### 三、合同与价格提醒
- 香蕉受运输损伤影响大，**小包装不适合长途快递**，建议选择同城或邻近城市货源，避免损耗。  
- 若对方报价远低于市场价（当前香蕉一级批发价约2.5-4元/斤），需警惕品质风险（如催熟剂、黑心）。
