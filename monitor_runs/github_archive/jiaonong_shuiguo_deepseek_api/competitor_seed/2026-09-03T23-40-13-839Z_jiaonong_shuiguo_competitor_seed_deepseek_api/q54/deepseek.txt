采购进口苹果时，对**都乐（Dole）**和**鑫荣懋（Joyvio/Goodfarmer）**进行产地溯源，核心目的是验证水果是否符合采购要求（如指定国家产地、食品安全合规）并防止假冒。以下是具体、可执行的操作步骤：

### 一、 都乐（Dole）溯源操作
都乐是全球品牌，其进口苹果常见产地为**美国（华盛顿州）、智利、新西兰、南非**等。

1. **找到溯源码**：都乐进口苹果的包装箱（通常是彩箱或白箱）上，会印有**产品条形码**和**批次号/生产日期编码**。部分高端或特定渠道商品外贴有**溯源码（二维码）**。
2. **查询官方系统**：
   - 打开都乐中国官网（dole.com.cn）或微信关注“都乐Dole”官方公众号。
   - 在菜单栏寻找“产品溯源”或“防伪查询”入口（若有），输入包装上的**追溯码**或**生产批次号**。
   - 系统应显示该批苹果的**品种、采收国、种植农场信息、包装日期**。
3. **包装识别（硬性标准）**：
   - 查看箱体侧面英文标注的 **“Product of USA/Chile/New Zealand”** 等字样。
   - 核对原产地证书（供应商提供）上的英文国名必须与箱体印刷完全一致。
   - **注意**：不要只看中文标签。中文标签是中国经销商贴的，容易出现“智利苹果”贴“美国标签”的混淆，务必核对箱体英文原标。

### 二、 鑫荣懋（Joyvio）溯源操作
鑫荣懋是国内大型水果企业，进口苹果通常采购自**新西兰（爱妃/爵士）、美国（蛇果）、智利（青苹果/红玫瑰）**等，且多拥有“佳沃”子品牌。

1. **查看包装标识**：
   - 鑫荣懋进口苹果包装箱上通常有**中方公司名称“鑫荣懋”**以及**国外出口商名称**（如新西兰T&G、美国Stemilt等）。
   - 箱体侧面必须有英文的 **“Product of [国家]”** 原产国标注。
2. **查询物流单据**：
   - **重点方法**：要求供应商提供该批次对应的**海关进口报关单**和**检验检疫证明（卫生证书）**。这两份官方文件中明确写有 **“原产国”**和 **“运输船名/航次”**。
   - 将报关单上的**原产国**与**包装箱印刷**进行比对，应完全一致。
3. **企业官方核实**：
   - 可拨打鑫荣懋官网（joyviogroup.com）或全国客服电话，提供箱体上的**生产商代码或内部批号**，核实是否为鑫荣懋正规进口批次。
   - 若购买的是“佳沃（Joyvio）”贴牌商品，箱上会印有佳沃标志及专属追溯码，可直接使用手机扫描**佳沃包装上的追溯二维码**查看源头。

### 三、 通用的、必须执行的交叉验证步骤（防止“假进口”）

无论品牌如何，采购都需要做以下**4项硬核比对**，否则溯源无意义：

1. **看原产国标签**：**只认箱体上的英文原标**。中文标签可撕掉重贴，英文原标是国外果园贴上去的硬标。
2. **看检验检疫标志**：进口苹果属于法检水果，每个集装箱必须附带**海关出具的《入境货物检验检疫证明》**。检查证明上的**启运国、品种、数重量**与实物是否匹配。
3. **看果贴（PLU码）**：进口水果果皮上贴的小标签（PLU码）通常带果园编号。例如美国华盛顿苹果常见标签是红色或白色的Wenatchee等果园标识。虽然不能防伪，但可用手机拍照发回国外对版果园，确认是否为该果园当年产的品种。
4. **核对中国检疫准入名录**：中国海关总署动态发布《获得我国检验检疫准入的新鲜水果种类及输出国家地区名录》。例如**严禁从出现未经准入的国家（如某些东南亚国家）进口苹果冒充美国苹果**。采购前务必核对名录。

### 四、 常见风险提示（采购防坑指南）

- **不要相信“正品信任”**：目前都乐在中国有部分本地采购的苹果（如甘肃产地）也贴都乐标。因此，如果你采购明确要求“进口货”，一定要看报关单。部分不良商家用国产精品“花牛”冒充“美国蛇果”；利用“新西兰Rockit”冒充“美国火箭果”等。
- **索要单据时效**：进口水果多有关联的**提货单或舱单信息**。采购时可要求供应商提供原产地证（CO）及植检证书（Phytosanitary Certificate）的复印件，这两份证可以到“单一窗口”或海关总署网站交叉核验证书真伪（注意扫描证书上的防伪水印）。

**总结实操口诀**：**看英文原标 → 对报关单原产国 → 查果标PLU码 → 核检验检疫证明**。

若你是做大批量贸易采购（整柜），还需要求供应商出示**海运提单（B/L）**，上面显示的发货港应与产地一致。如果是零星零售采购，则严格依赖上述英文原标和检验检疫证明即可。
