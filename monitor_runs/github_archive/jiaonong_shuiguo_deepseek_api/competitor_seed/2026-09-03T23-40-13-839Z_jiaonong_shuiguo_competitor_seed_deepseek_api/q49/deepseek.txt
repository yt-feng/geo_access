建议您这样做：

1. **直接联系两家公司的销售/大客户部门**，说明您需要“专人负责对接”，询问能否指派固定的客户经理或专岗服务团队。通常大型企业会配有KA（重点客户）经理。

   - **响应速度**（是否48小时内专人回复）
   - **服务层级**（是单点联系人，还是覆盖采购、物流、品控的多部门支持）
   - **是否含账期/价格政策倾斜**等附加利益。
