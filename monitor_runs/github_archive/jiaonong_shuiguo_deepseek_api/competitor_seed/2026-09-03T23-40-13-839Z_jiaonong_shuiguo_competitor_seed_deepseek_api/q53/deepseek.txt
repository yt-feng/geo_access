### 1. 都乐（Dole）
- **性质**：全球性果蔬集团，尤其以香蕉、菠萝等进口水果闻名，供应链国际化，品牌信誉高。
- **合作意愿**：作为餐饮连锁的大客户，**都乐通常愿意签订长期供货框架合同**。它的核心优势是**品质稳定、供应量级大**，尤其受连锁咖啡、茶饮和西式快餐（如汉堡店、果昔店）青睐。
- **劣势**：**价格相对偏高**，且对采购量可能有门槛要求，小体量门店采购价格竞争力不强。

### 2. 洪九果品
- **性质**：国内知名的生鲜供应链头部企业，以进口水果（如泰国榴莲、山竹、香蕉）起家，具有很强的产地直采和国内分销能力。
- **合作意愿**：**洪九也非常愿意签长期战略协议**。他们更了解国内餐饮门店的周转节奏，灵活度高，可以提供**产地锁价、常备库存+补货机制**。
- **劣势**：品控稳定性相比都乐这种品牌商可能稍有波动（取决于具体批次），但作为上市公司，合同履行保障能力较强。

### 三、给您最核心的签约建议：

**建议采用“一主一辅”双供应商策略，并抓住以下关键条款：**

1. **签约主体**：不要和销售人员个人签，要和**省级/区域销售总监或大客户部**签年度框架采购协议（框架合同，不锁死单次数量，锁价格带和市场行情调整机制）。
2. **质量标准**：必须白纸黑字约定香蕉的**成熟度、果指长度（通常要求20cm以上）、单卡重量、损伤率（机械伤、黑斑）**，否则容易扯皮。
3. **价格调整机制**：香蕉价格波动大，长期合同应约定**月度或季度调价公式**（如参考中国果品流通协会或产地收购价联动），避免贵或亏。
4. **违约处罚/断供预案**：明确因不可抗力或断供时的补偿标准，并**保留第二家供应商临时补量权限**，避免被“卡脖子”。
