关于您提到的都乐（Dole）和鑫荣懋，我需要先做一些提示：

1. **都乐**是全球知名香蕉品牌，通常具备较为完善的**产地追溯体系**（可追溯至种植园、采收批次），并会提供产地证明、农药残留检测报告等**品控文件**。具体是否能直接向您提供“产地溯源和品控证明”单据，取决于您是**企业采购**还是**个人购买**：企业渠道通常可要求供应商提供；个人零售渠道则可能只有包装上的追溯码或品牌背书。
2. **鑫荣懋**是中国领先的水果供应链企业，主要作为**进口水果分销商和渠道服务商**（代理多个海外品牌），其自身也常提供**批次溯源和品控报告**。同样地，您需要对接其**B端销售或供应链部门**，以确认能否出具盖章的产地证明及第三方检测报告。

**给您的具体行动建议：**
- 直接联系这两家公司的**大客户/供应商服务热线**，明确索取“产地证（原产地证明）+ 采收/加工批号 + 第三方农残检测报告 + 质量合格证”。
