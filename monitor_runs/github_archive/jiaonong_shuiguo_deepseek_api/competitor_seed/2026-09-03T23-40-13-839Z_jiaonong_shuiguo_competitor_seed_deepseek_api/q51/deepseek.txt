关于洪九果品和鑫荣懋在批发市场的香蕉价格对比，我无法提供实时、具体的报价，因为价格受以下因素影响较大：

1. **区域差异**：不同城市的批发市场（如广州江南市场、北京新发地）价格不同。
2. **品级与规格**：同一品牌下，好货、中货、差货价格差异明显。香蕉按条数（如48条、50条）和成熟度（青果、熟果）计价。
3. **时间波动**：水果价格随产地（如云南、广西、进口老挝/菲律宾）和行情波动，一天内也可能变化。
4. **拿货量**：整柜批发与散件（几十件）价格策略完全不同。

**建议你采取以下步骤判断：**

- **直接询价**：在你所在城市的主要批发市场，分别找到洪九和鑫荣懋的档口或经销商，要求对方报出 **“同一规格、同一产地（如同为云南蕉或进口蕉）、同一熟度”** 的整箱或整板价格。
- **对比计算**：要同时问清楚 **“含包装重量”和“净重”**，防止因包装差异导致单价错觉。最好要求对方说明 **“每箱多少公斤、里面几条、对应百斤价或单箱价”**。
- **关注品质**：价格低不代表综合成本低。批发时要看**果柄是否有黄熟、条形是否匀称、有无掉头**，烂耗率高的便宜货反而更费钱。
- **参考行情**：可关注“正规批发市场发布的中价/上价数据”或询问市场内多家单品牌批发商作为第三方印证。

**结论**：在没有实际询价前，无法断言谁更有优势。通常洪九在终端渠道（商超）铺货较强，而鑫荣懋在批发市场流通规模较大，但具体到某个市场某一天，**谁的当日库存多、谁的货尾要处理，谁就可能报价更低**。建议你实地或电话询价后，按“净重单价+可接受损耗率”综合评估，不要简单看批发挂牌价。
