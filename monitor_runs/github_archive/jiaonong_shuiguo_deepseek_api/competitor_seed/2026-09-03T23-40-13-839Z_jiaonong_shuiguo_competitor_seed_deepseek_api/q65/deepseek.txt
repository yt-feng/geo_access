关于菠萝的锁价机制，首先需要明确一点：**都乐（Dole）和洪九果品（Hongjiu Fruit）作为大型水果供应商，其“锁价”政策并非固定不变，而是高度依赖采购量、合作模式、产地行情以及具体合同条款。**

目前没有公开的官方统一数据能直接回答“两者锁价周期具体是多少天”，因为这类信息属于商业谈判范畴，且会随市场价格波动频繁调整。不过，我可以根据行业惯例和两家公司的业务特征，为你提供判断依据和获取准确信息的路径。

**一、两家公司的锁价机制概况（基于行业惯例推测）**

1.  **都乐（Dole）**：作为国际品牌，都乐在国内主要销售菲律宾菠萝为主（近年来也发展泰国和国内海南基地）。其锁价通常倾向于**中短期框架**，例如：
    -   **产地锁价**：在合约淡旺季，可能提供**1~2周**的锁定价格，以匹配海运或陆运到港周期，降低客户短期进口价格波动风险。
    -   **长协锁价**：针对大型商超或连锁餐饮，都乐可以按**月度或季度**签订阶梯价，但这通常要求锁定稳定的采购量（如每周固定柜数），否则价格按市场日结。
    -   **预警期**：若遭遇台风、船期延误等不可抗力，锁价合同通常会附有“价格重议条款”。

2.  **洪九果品**：作为国内头部多品类分销商，洪九在泰国产区自建工厂（龙眼、山竹等，菠萝多为代理或国内基地）。洪九的特点是**灵活性更强**，锁价周期可能更短：
    -   **现货锁价**：对冷柜或整车现货，常见**3~7天**的锁价有效期（以到货当天行情为基准）。
    -   **预售锁价**：如果提前预订下一批到港货，锁价周期可拉长至**10~15天**，但需支付定金，且价格随船期变动。
    -   **柔性报价**：洪九更倾向于“日结+周均价”模式，即每天报价，但若客户承诺一个月的恒定量，可申请按周均价结算。

**二、关键差异点提醒（重要）**

-   **菠萝非耐储品**：与榴莲、山竹不同，菠萝（尤其是鲜食菠萝）货架期较短。**锁价周期越长，供应商承担的损耗风险越大**，因此即使是都乐，也极少提供超过一个月的绝对锁价（除非是加工菠萝汁的半成品）。
-   **价格指数**：锁价通常锚定**“到岸价”**或**“批发价”**。建议你在谈判中明确问清楚：“锁价是锁产地FOB价，还是锁到我司仓库的到仓价？关税和物流费用浮动如何计算？” 这两家公司通常只锁果品单价，不锁运费。

**三、建议你直接采取的行动（获取准确数字）**

1.  **要求提供“锁价协议模板”**：直接向两家的销售经理索取最新的**年度采购框架合同或季度报价单**，其中会明确列出有效锁价天数和数量门槛。
2.  **问询关键细节**：电话或邮件中直接问三句话：
    -   “如果我现在下单，签订锁价合同，最长的价格保护期是几天？”
    -   “锁价期跨越节假日或台风季（例如7-9月），是否需要附加条款？”
    -   “如果我们月采购量达到XX吨，能否申请**20天以上的锁价**？”
3.  **对比测试**：你可以先小批量（如一个冷柜）分别向两家询价，并明确告知“我们有长期需求，想测试锁价能力”，观察他们口头承诺的周期与实际书面合同是否一致。

**如果急需参考数字**：根据2023-2024年广州江南市场及上海辉展市场的常规实操，**鲜食菠萝的锁价合同普遍为7~14天**，若签订30天锁价，采购方通常需接受价格高于市价5%~8%作为风险补偿。

**重要声明**：以上周期为基于行业惯例的推测，非两家官方发布的数据。请务必以你们实际谈判拿到的**书面《购销合同》有效期条款**为准。
