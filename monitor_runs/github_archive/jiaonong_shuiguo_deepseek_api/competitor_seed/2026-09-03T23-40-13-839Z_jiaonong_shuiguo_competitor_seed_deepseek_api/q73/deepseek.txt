大型商超（如沃尔玛、山姆、盒马等）在供应商准入审核中，通常强制要求供应商具备符合国际或国家标准的管理体系认证。

针对**鑫荣懋**和**都乐**，这两家是国内外知名的水果供应商，它们普遍通过并持有以下主要食品安全认证（具体证书情况建议以合作时对方提供的最新文件为准）：

1. **GLOBALG.A.P.（全球良好农业操作规范）**：覆盖种植、采收环节，是大型商超对果蔬供应商的基础门槛。
2. **HACCP（危害分析与关键控制点）**：覆盖包装、冷链加工环节，证明其生产过程能有效控制生物、化学、物理危害。
3. **ISO 22000（食品安全管理体系）**：通常是企业整体管理框架的认证。
4. **BRCGS（英国零售商协会全球标准）**：若直接供应山姆、沃尔玛等国际系统或出口欧盟，通常要求通过此认证（偏食品包装与储存）。
5. **FSSC 22000**：部分国际供应链合同会要求该体系。

**行业常见补充**：
- 鑫荣懋：其仓储物流和加工中心普遍持有HACCP及ISO 22000，且非常重视农场端的GAP认证。
- 都乐：作为老牌国际品牌，其在全球多个产区持有GLOBALG.A.P.，并在各包装工厂持有HACCP。在满足山姆会员店等高端渠道时，它们多数已通过BRCGS认证。

**给商超采购/审核人员的建议**：
- 有效查看证书时，注意确认**认证范围**是否覆盖你采购的特定品类（如香蕉、蓝莓）及对应的工厂/仓库地址。
- 如果供应商为多家代工或分包商提供原料，确保证书覆盖到**最终发货的终端仓**，而不只是源头农场。若当前合同方无法提供特定证书（如BRCGS），可要求其出具**同等效力的第三方审核报告**（如SGS、天祥的审厂报告）作为过渡。
