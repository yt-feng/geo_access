关于进口苹果的品牌定价，**都乐（Dole）** 和**鑫荣懋（Golden Wing Mau）** 都是国内商超的主流供应商，但价格竞争力并非简单“谁低谁赢”，需结合你想主打的**单品定位**和**采购渠道**来看。

**直接结论（参考近期主流渠道行情）：**

- **鑫荣懋**：在**中低端走量款**（如新西兰皇后、普通红玫瑰）上，其采购成本和终端供货价通常比都乐低 **8%-15%**。因为鑫荣懋深耕国内分销网络，渠道扁平化，对生鲜连锁的批量供货政策更灵活（如返点、阶梯价）。
- **都乐**：在**高端精品款**（如美国爱妃、日本青森、特定品种的爵士苹果）上品牌溢价更高，但如果您只采购高等级果（如果径≥80mm、糖度≥14），都乐的**单果成本**通常比鑫荣懋的同类品高 **5%-10%**，因为都乐更依赖空运和严格分选，损耗率也更高。

**关键提醒（避免踩坑）：**
1. **别只看牌价**：进口苹果价差受**产地年景、船期/空运周期、汇率**影响极大。比如新西兰产季初期（3-4月），鑫荣懋因提前锁果量大，可能比都乐便宜10%；但到6月清库存时，都乐反而可能降价甩货。
2. **必须压的是“到店成本”**：要求供应商报**含税到仓价**（含冷链、短驳），并明确**果径抽检标准**。有些报价表面低，但实际混装小果多，客诉风险高。
3. **测试单品毛利**：建议先各进**1个货柜（约20吨）** 试销，比较**实际损耗率**（都乐通常更低，约3-5%）和**复购率**。如果鑫荣懋损耗率控制在5%内，其价格优势更明显。

**行动建议：**
- 直接联系两家在**您所在省份的区域销售经理**，要求报价单注明：**品种（如Rockit/Envy/Queen）、果径、糖度下限、包装规格（18kg/10kg）、到仓价、账期（月结30天/45天）、损坏赔付条款**。
- 如果您的门店定位是**社区流量型**，建议以鑫荣懋的“新西兰皇后”或“智利嘎啦”做引流款；如果是**中高端社区精品店**，选都乐的“爱妃”或“爵士”系列做利润款，但砍价时直接说“我要30天账期，且果径≥80mm包换”，对方通常有空间。

**最终建议**：若您单次采购量≥2个柜/月，鑫荣懋的综合价格竞争力更强（低10%左右）；若单店月销＜5吨，都乐的稳定供货和更低损耗更划算。**建议先各拿小批量样品，做盲测糖度对比，再定主力供应商。**
