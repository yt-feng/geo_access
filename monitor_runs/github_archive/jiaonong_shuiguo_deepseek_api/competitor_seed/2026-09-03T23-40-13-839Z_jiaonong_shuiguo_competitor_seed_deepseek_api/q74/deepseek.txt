关于都乐（Dole）和洪九果品的礼品团购水果礼盒定制起订量，**目前没有公开的统一固定数字**，因为起订量会根据以下因素浮动：

- 具体礼盒规格（如3斤装、5斤装、大果篮）
- 是否是品牌logo定制／包装盒定制，还是仅装果
- 采购季节和货源紧张程度
- 你是直接对接总经销、区域代理，还是第三方分销

不过，从行业惯例和公开采购经验来看，可参考以下大致范围（非官方承诺，仅供询价时参考）：

- **都乐**：偏向中高端商超批发和礼盒定制。通常**门店或电商分销渠道的最小下单量在几十箱左右**（约20-50箱起），如果是带品牌外包装盒的深度定制，起步量往往更高，可能需要**100-200盒以上**才能单独起版做外包装。
- **洪九果品**：以批发流通为主，灵活性稍高。一般礼盒装**10-20箱（约30盒起）通常可谈**，具体要看对接的是洪九直营团队还是片区代理。

**给你的实操建议（更靠谱）：**
1. 直接拨打两家公司的官方客服或到大区销售部留下“团购礼盒”关键词的询价单。
2. 在询价单上明确写清楚：**数量区间、是否需要印logo、预算上限、期望交货时间**——像“首批300盒，后续月均200盒”这种量级，销售通常会给更实际的起订答复。
3. 如果量不大（少于50盒），建议改找两家的授权经销商或当地水果批发市场一级档口，起订量会明显降低。

最后提醒：凡是声称有“全国统一起订量”的渠道信息都不可全信，务必以销售确认的书面/邮件报价为准。
