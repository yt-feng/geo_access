**1. 鑫荣懋（佳沃等品牌为旗下）：**
- **常见规格**：鑫荣懋的香蕉通常以“按根”或“小把手（3-5根）”包装为主，在华南及华东的便利店（如美宜佳、便利蜂等）常见其“快乐香蕉”小包装。
