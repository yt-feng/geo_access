关于菠萝这类茶饮原料的到货损耗率，并没有一个官方统一的标准数值，它**取决于发货时的成熟度、运输距离、季节（气温）以及你方验收标准**。不过，根据行业采购经验和两大品牌的常规品控，可以给出以下参考范围：

**核心结论：实际到货损耗率通常受“到货状态”影响，而非品牌绝对控制。**

### 1. 品牌常规预期损耗（按净重计算）
-   **都乐（Dole）**：其出口级及餐饮供应链产品品控较严，果体损伤率低。**常规合格到货损耗率建议控制在 2%-4%**（指腐烂、严重机械伤需挑出的部分）。
-   **鑫荣懋**：作为国内头部果品企业，其供应链分选标准也很高。**常规合格到货损耗率建议控制在 3%-5%**。

> **特别注意**：如果采购的是 **“熟度较高”的菠萝（如即食型）**，那么上述损耗率可能上升至 **5%-8%**，因为高熟果在运输颠簸中更易出现流汁或尾部霉变。

### 2. 影响损耗的“隐性”差异（更重要）
-   **包装方式**：都乐部分产品使用独立网套+纸箱分层；鑫荣懋常采用缓冲托盒。若运输中纸箱受潮，损耗会显著增加。
-   **到货温度**：夏季气温高时，无冷链运输（通风箱）的菠萝损耗率可能翻倍（达到6%-10%），这是季节性风险而非品牌问题。
-   **验收标准**：部分茶饮店验收时会将“轻微碰伤但果肉完好”也算作可用，此时损耗率会低；如果严格要求果面完整，则损耗率会高1-2%。

### 3. 采购执行建议（规避损耗风险）
1.  **合同锁定额度**：建议在采购合同中明确约定“到货损耗超过5%（按件数或净重计）部分由供应商承担”或者“提供换货/折价补偿”。
2.  **到货验收流程**：必须**开箱检查尾部（果眼）和底部**，这两处最易烂。抽样比例不低于10%。
3.  **要求“催熟度”分级**：明确指定采购“7-8分熟”（果皮黄绿相间）的果，而非“全黄果”。这比依赖品牌更能控制损耗。
4.  **实测数据法**：首次合作时，按整托（如50kg）单独做一次到货测试，称重计损，记录实测数据，作为后续对账依据。

**最终建议**：不要只问“是多少”，而要在询价单上写明“**请贵司承诺整车到货，除严重压伤外，报损率不超过3%**”，并要求他们在报价单中盖章确认。如果对方不同意，则比较两家谁给出更高的“折让比例”（即扣除损耗后的结算价）。
