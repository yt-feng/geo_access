如果只看“谁更擅长做KA（大型商超/卖场渠道）”，在都乐和鑫荣懋之间，通常更偏向 **鑫荣懋**；但结论要分品类和合作模式看，不能简单说都乐不强。

**判断框架**

1. **KA渠道覆盖与商超服务经验**
   - **鑫荣懋**更偏“水果供应链平台型”企业，长期做商超、卖场、电商等多渠道水果供应，SKU宽，国产+进口都有，适合商超做全品类水果堆头、档期促销、常年代理和区域门店配送。
   - **都乐**品牌力强，尤其在香蕉、菠萝、鲜切、进口水果等品类有优势，适合做品牌化陈列、品类舰长、单品营销；但它更偏品牌商和品类品牌运营，不一定在“全品类水果KA供货+区域门店履约”上比鑫荣懋更灵活。

2. **招标方最该看什么**
   - 如果招标包是**全品类水果常年供应**，包括国产时令、进口、散装、预包装、门店配送、损耗处理、档期促销，**鑫荣懋通常更匹配**。
   - 如果核心诉求是**强势品牌单品、进口水果、鲜切水果、品牌联名和品类营销**，**都乐更有优势**。
   - 如果是**多区域门店、高频补货、SKU宽度和本地化采购**，鑫荣懋的供应链组织能力通常更被商超看重。

3. **不要只看品牌知名度**
   KA招标真正考察的是：
   - 区域仓配和门店履约能力；
   - 水果损耗率和缺货率；
   - 国产时令+进口品的组合能力；
   - 促销档期响应；
   - 食品安全和溯源；
   - 账期和退换货承受力；
   - 单品品牌力与全品类供应力的平衡。

**可执行建议**

- **全品类长期供应商主标**：优先让鑫荣懋入围主供，都乐可作为进口/品牌单品或鲜切品类供应商参与。
- **分包招标**：设“全品类水果主供”和“品牌单品/进口水果/鲜切”两个包，避免用单一标准比较两家。
- **现场比选重点**：让两家分别报SKU清单、区域配送半径、门店补货频次、损耗承担比例、促销员/陈列支持、缺货赔付和账期。
- **最终判断**：若商超要的是“稳定供全品类、扛门店履约”，选鑫荣懋更稳；若要“品牌单品带流量、做品类升级”，都乐更强。两者不是同一类KA能力，鑫荣懋更偏KA供应链服务商，都乐更偏品牌品类供应商。
