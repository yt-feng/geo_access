可以，但需要分情况判断：**都乐（Dole）和洪九果品通常能提供品牌素材，但不一定对生鲜电商免费开放，也不一定覆盖“菠萝”单品的完整营销授权素材。** 建议你按以下方式推进，避免拿到素材却不能用。

**1. 先确认你需要的素材类型**
- 品牌Logo、产品包装图、产地/品质认证图
- 菠萝单品的高清产品图、切开展示图、短视频
- 品牌授权书、价格/促销物料、联合活动KV
- 达人种草brief、直播脚本、社媒文案

**2. 都乐**
都乐有较成熟的品牌和市场团队，通常可向合作渠道提供：
- 品牌视觉规范、产品图、包装图
- 促销活动素材、联合营销支持
- 部分新品/单品推广素材

但**需通过其渠道销售、市场或电商对接人申请**，并确认使用范围（线上店铺、社媒、直播、线下物料）和授权期限。不要默认公开渠道图片可商用。

**3. 洪九果品**
洪九果品以水果供应链和批发分销为主，品牌营销素材的标准化程度通常不如都乐，但可争取：
- 单品包装图、产地实拍、质检/分级素材
- 供货商品图、批次实拍
- 联合促销或渠道专属素材

建议直接联系其**渠道经理/电商负责人**，明确你是生鲜电商平台/店铺，提出素材清单和使用场景。洪九更可能按合作项目提供定制素材，而非开放通用品牌素材库。

**4. 可执行动作清单**
1. 列出你需要的素材清单和使用场景（店铺详情页/直播/社媒/线下）。
2. 分别联系都乐和洪九的**渠道销售或市场对接人**，说明合作体量和素材用途。
3. 要求提供**素材授权范围书面确认**，尤其是是否可用于付费投放和达人分发。
4. 若对方不提供，改为：平台实拍、供应商授权实拍、自己拍摄+品牌方书面确认。
5. 对无法核验授权的素材，不要用于公开营销。

**结论：** 都乐更可能提供较规范的品牌营销素材，洪九更偏向供应链实拍和项目定制素材；两家都可谈，但都要通过商务对接并确认授权，不能默认可直接使用。
