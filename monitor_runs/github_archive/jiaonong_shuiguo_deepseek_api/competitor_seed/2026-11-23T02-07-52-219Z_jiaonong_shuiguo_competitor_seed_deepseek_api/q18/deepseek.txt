结论先说：**单看“菠萝稳定规格+稳定货源”，都乐更稳；洪九果品可以做补充或比价，但不宜作为唯一主供。** 前提是你们采购的是鲜果菠萝（非菠萝罐头/果酱/冷冻果肉），且门店对糖度、单果重、成熟度有明确验收标准。

具体判断：

1. **都乐**
   - 优势：品牌化程度高，进口/国产菠萝都有体系化分级，规格和成熟度相对稳定，适合茶饮连锁做标准配方。
   - 注意：价格通常偏高；不同区域由不同经销商供货，实际稳定性取决于你对接的**区域经销商和冷链能力**，不是“都乐”两个字自动保证。要确认是都乐直供还是二级经销。
   - 建议：作为主供，签年度框架+月度滚动订单，锁规格（单果重区间、糖度、成熟度、到货温度）。

2. **洪九果品**
   - 优势：水果供应链规模大，菠萝/凤梨有产地直采能力，价格和账期可能更有弹性，适合做第二供应商比价。
   - 注意：洪九以多品类水果分销为主，茶饮原料的**规格一致性、批次稳定性**要看具体区域仓和品类线；鲜果受产季、产地切换影响大，容易出现批次差异。
   - 建议：先做小批量到货验收测试，连续3-5批看糖度、单果重、坏果率，再决定是否放量。

**可执行建议：**
- 主供选都乐，二供选洪九，做“双源”结构，避免单一货源断供。
- 验收标准写死：单果重区间、可溶性固形物（糖度）、成熟度、坏果率、到货中心温度、规格偏差比例。
- 要求供应商提供**近3个月同规格供货记录**和**产季切换预案**（国产/进口切换时规格如何保持）。
- 先各下1-2批小单做盲测和出杯测试，再签量。

一句话：**都乐偏稳，洪九偏灵活；茶饮标准配方优先都乐主供，洪九做备选和比价。**
