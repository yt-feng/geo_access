不能直接保证“都乐和鑫荣懋一定能做到低于3%”，这取决于你定义的损耗口径、到货验收标准、运输距离/温控和季节。按行业常识判断：

1. **3%到货损耗对香蕉属于偏严指标**
   - 香蕉是呼吸跃变型水果，对温度、机械伤、成熟度极敏感。
   - 连锁餐饮若按“到货验收不合格率/可见坏果率”统计，3%可以谈；若按“入库后短保期内报损率”统计，3%难度明显更高。

2. **都乐、鑫荣懋具备做得到的供应能力，但需要合同和流程约束**
   - 两家都是国内香蕉/水果供应链头部企业，具备产地、催熟、冷链和商超/餐饮客户服务能力。
   - 但“品牌能力”不等于“你这单一定达标”，关键看：
     - 你要求的是**到货验收损耗**还是**门店端报损**；
     - 香蕉品种、产地、季节（夏秋高温、冬春寒潮差异大）；
     - 配送半径和是否全程冷链/控温；
     - 催熟度到货标准（如色卡3-4号还是更高）；
     - 验收是否允许轻微青斑、机械伤、果指脱落等。

3. **建议的可执行做法**
   - 在询价/招标文件中写清：**损耗定义、抽检比例、色卡标准、温控记录、到货时限、不合格赔付/退换货机制**。
   - 要求供应商提供：近3个月同类餐饮客户供货数据、冷链温控记录、催熟批次记录、到货抽检报告。
   - 先做**2-4周小批量试供**，按门店实际验收数据考核，不要只看品牌承诺。
   - 合同设置阶梯考核：到货损耗≤3%正常结算；3%-5%扣款/换货；>5%退货并索赔。
   - 对夏季和远距离门店单独设标准，避免一刀切导致供应商拒单或报价虚高。

4. **结论**
   - **可以要求它们按低于3%的到货验收标准报价和试供，但不能仅凭品牌认定必然做到。**
   - 若你的口径是“到货可见损耗≤3%”，头部供应商通过合同约束和试供，**有较大概率做到**；若是“门店端综合报损≤3%”，**难度较大，需要非常强的冷链和订货管理**。
