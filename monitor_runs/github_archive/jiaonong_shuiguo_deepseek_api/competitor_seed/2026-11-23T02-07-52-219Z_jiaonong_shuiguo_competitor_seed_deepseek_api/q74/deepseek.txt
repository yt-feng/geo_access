都乐和洪九果品的水果礼盒定制起订量没有统一公开标准，通常按渠道、品类、包装形式、是否贴牌、配送区域和结算方式单独报价，不能直接给一个固定数字。可执行判断如下：

1. **都乐**
   - 更适合走其企业团购/礼品渠道或区域经销商，不是直接找品牌总部就能统一定制。
   - 起订量一般取决于：是否用都乐现有礼盒、是否做企业LOGO贴标、是否换包装、选什么单品/组合、是否全国配送。
   - 实操建议：先问“现有都乐礼盒团购起订量”和“企业LOGO定制起订量”两个口径；通常贴标/换卡套的门槛低于完全定制包装。

2. **洪九果品**
   - 同样以区域经销、批发渠道和团购渠道为主，礼盒定制起订量随品类和区域波动较大。
   - 如果是用现有礼盒加企业标识，门槛通常低于开版定制；进口/高端单品组合的起订量通常更高。
   - 实操建议：直接联系洪九当地城市经理或经销商，问清“礼盒团购最低起订量、混装是否可行、贴标费、开版费、配送起送量”。

**建议你询价时固定问这6项：**
- 现有礼盒最低起订量是多少盒？
- 企业LOGO贴标/卡套定制最低多少盒？
- 完全开版定制包装最低多少盒、开版费多少？
- 能否混装品类？混装是否加价？
- 配送起送量和是否送到指定地址？
- 报价是否含税、含运费、账期条件？

**结论：** 都乐和洪九都没有可对外直接引用的统一起订量，必须按区域和定制方式询当地团购/经销渠道。若你告诉我所在城市、预计采购盒数、预算区间和是否要印企业LOGO，我可以帮你把询价话术整理成可直接发给业务员的版本。
