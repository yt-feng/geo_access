结论：两家都具备全国配送能力，但“全国配送”要拆成两层看：**全国到仓/到城市**和**全国到门店（尤其连锁餐饮高频小批量）**。按餐饮连锁香蕉稳定供应，建议优先谈都乐，同时把鑫荣懋作为备选或区域补充。

1. **都乐（Dole）**
   - 全国配送能力较强，商超、餐饮渠道覆盖广，冷链和城市配送体系相对成熟。
   - 香蕉是都乐核心品类，标准化程度高，适合连锁餐饮做稳定规格、稳定熟度。
   - 更适合你这种“全国多城市门店、需要稳定供应和品牌背书”的场景。
   - 注意：都乐更多是品牌+供应链体系，具体到每个城市能否“到店配送”、起订量、配送频次，要按城市和门店数量确认。

2. **鑫荣懋**
   - 也是全国性水果供应链企业，配送网络覆盖广，服务商超和餐饮客户，香蕉供应能力强。
   - 优势在产地资源、品类整合和成本弹性，适合做多品类联合采购。
   - 但全国配送的“到店能力”和区域密度要具体看城市，部分区域可能到仓强、到店弱。

**可执行建议：**
- 让两家分别按你门店所在城市报：**配送范围、到店还是到仓、起订量、配送频次、冷链条件、香蕉规格/熟度、损耗赔付、缺货替换方案、锁价周期**。
- 先选3—5个代表性城市做试单，重点看：**到店准时率、熟度稳定性、损耗率、缺货响应**。
- 全国主供可优先都乐；如果成本压力大或多品类采购，鑫荣懋可做备选/区域补充，避免单一供应商。

一句话：**都乐更适合全国连锁餐饮的稳定到店供应；鑫荣懋具备全国配送能力，但要到城市层面核实到店配送密度。最终以试单数据定主供。**
