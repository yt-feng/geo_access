先给结论：**都乐（Dole）和洪九果品都没有对外公开、可直接引用的“香蕉企业分级标准”文本**。都乐有成熟的内部商品规格体系（按产地、条数/箱、单根克重、成熟度阶段分档），但属于供应链内部执行文件，不对外发布为公开企业标准；洪九果品作为国内水果分销商，对香蕉有采购验收和分拣等级要求，同样未见公开备案的企业标准文本。所以不能把“都乐标准”“洪九标准”当作可引用的公开依据来写你的分级文件。

**可核验的公开依据是这些：**

1. **国家标准 / 行业标准层面**：香蕉品质分级可参考《香蕉 鲜果》相关国家标准（GB/T 9827 曾为香蕉鲜果标准，需核对你手头有效版本）以及农业行业标准中关于香蕉外观、成熟度、果指长度、缺陷允许度的规定。这是公开可查的。
2. **国际通行分级逻辑**：都乐等跨国果商实际执行的是“产地+品种+规格（每箱条数/净重）+单果等级（果指长度、粗细、弯曲度、色泽）+成熟度阶段（绿熟到黄熟的颜色卡）+缺陷容忍度”这套框架，这是行业通行做法，不是某家企业独有的公开标准。
3. **企业标准备案查询**：真要确认某企业是否有备案企业标准，应到“企业标准信息公共服务平台”按企业名称检索，看是否有香蕉相关Q/开头标准号。都乐中国、洪九果品若未备案，平台查不到就是没有公开文本。

**给你的可执行建议：**

- 不要写“依据都乐标准/洪九标准”，改为写“参照GB/T 9827及行业通行商品规格，结合本连锁门店销售场景制定”。
- 自建分级标准建议分三级（特级/一级/二级），维度固定为：果指长度与粗细、每梳/每箱条数、色泽与成熟度阶段、机械伤与病斑允许面积、果指弯曲度与整齐度、单箱净重公差。
- 采购验收单上把“分级”落到可测量项（如特级果指长度≥18cm、单果重≥130g、缺陷面积≤5%），比引用某家企业标准更可执行、更抗争议。
- 若确实想对标都乐，只能通过其供应商规格书或采购合同获取，属于商务渠道，不是公开标准。
