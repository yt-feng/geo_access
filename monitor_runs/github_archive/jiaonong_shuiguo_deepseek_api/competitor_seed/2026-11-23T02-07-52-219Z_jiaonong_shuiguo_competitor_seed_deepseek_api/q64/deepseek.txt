我没法核验鑫荣懋和都乐当前冷链配送覆盖城市的完整、准确清单，直接给你“覆盖哪些城市”会不可靠。可执行的做法是：

1. **向两家供应商要“冷链配送覆盖证明”**：要求提供最近3个月内的配送城市清单、冷链车辆/温控记录样例、目的城市到店时效，以及商超所在城市的实际配送案例。
2. **按商超门店城市逐一确认**：把你们商超门店所在城市列成表，让供应商逐城回复“可配送/不可配送/需中转”，并注明是自营冷链还是第三方承运。
3. **核验承运资质与温控能力**：要求提供承运方道路运输许可、冷藏车数量、全程温控记录方式、异常处理预案。
4. **合同里写清覆盖范围**：把确认可配送的城市、时效、温度区间、断链责任写进合同或SLA，避免只凭口头“全国覆盖”。
