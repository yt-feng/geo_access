我不掌握都乐和洪九果品当前菠萝的具体供货价、规格、损耗率和门店结算政策，所以不能直接给“哪个性价比更高”的确定结论。性价比不能只看进货单价，要看**单店可售毛利 = 售价×可售率 − 进货成本 − 损耗 − 加工人工**。建议你按下面方式在1周内用真实数据判定。

**1. 先统一比较口径**
- 同为菠萝还是凤梨品种，明确品种、产地、单果重量区间、成熟度、是否催熟/即食。
- 比较到店价：含税、含运费、起订量、账期、退换货、破损赔付。
- 按“每公斤可售果肉/每箱可售个数”折算，不按箱价直接比。

**2. 做小批量盲测**
各进同一数量、同一售价档，连续7天记录：
- 到货合格率、坏果率；
- 去皮/去眼损耗率、可售果肉克重；
- 自然熟/催熟一致性，切开后黑心、水心病、酸度；
- 顾客复购和投诉；
- 单店日销、报损量、加工耗时。

**3. 算单店真实毛利**
用公式：  
**单果毛利 = 零售价 −（单果进价 ÷ 可售率）− 单果分摊损耗 − 加工人工**  
哪家“可售率×稳定供货×售后赔付”更好，哪家性价比高，往往不是箱价最低的那家。

**4. 建议的决策规则**
- 如果两家价差在5%以内：优先选**到货稳定、坏果赔付快、成熟度可控**的一家做主供。
- 如果洪九价格明显低但损耗高：只适合做促销引流，不建议全量主推。
- 如果都乐价格高但即食稳定、客诉低：适合做中高端门店和礼盒/即食杯。
- 最优通常是“双供应商”：都乐做品质标杆和稳定供应，洪九做价格带和促销补充，但先各试销2周再定比例。

**5. 直接向供应商索要这几项**
近3个月同规格到货合格率、坏果赔付标准、冷链到店温度记录、最小起订量、账期、节日锁价能力、临期/破损处理政策。没有这些数据，单比“哪个便宜”容易误判。
