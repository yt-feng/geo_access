可执行判断如下：

1. **都乐（Dole）**
   - 都乐是全球水果供应商，菠萝供应通常依托其全球/亚洲产区与国内加工、催熟、仓配体系，不是单一“一个基地”。
   - 采购沟通时应直接问：**供货菠萝的产地国/国内产区、品种（如金菠萝/MD2等）、到货港口或工厂、催熟/加工能力、周稳定供应量、可签框架协议周期**。
   - 验证方式：要求提供**产地证明、果园/包装厂注册信息、检测报告、近3个月供货记录或样单**，并让其书面确认“稳定供应周量+断供替代方案”。

2. **洪九果品**
   - 洪九是国内水果分销企业，菠萝供应通常涉及国内主产区采购及进口果源组合，具体基地/产区会随季节和订单变化。
   - 采购时应要求其明确：**当前供货季的产地（如广东/海南/云南或进口来源）、包装厂、发货仓、最小起订量、周供应能力、价格联动机制**。
   - 验证方式：要求提供**产地采购合同/供货证明、包装厂信息、质检报告、仓配地址**，并做小批量试单。

**建议你直接向两家销售索要一份“菠萝供应保障表”**，必须包含：产地、品种、规格、当前周可供量、旺季/淡季切换产区、发货仓、到货时效、断供赔付或替代方案。拿到后再判断谁能做稳定供应。
