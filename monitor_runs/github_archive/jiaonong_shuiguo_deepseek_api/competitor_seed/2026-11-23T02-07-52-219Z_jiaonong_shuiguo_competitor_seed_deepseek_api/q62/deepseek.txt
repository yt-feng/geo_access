可以要求提供，但**不能默认承诺两家都一定能随货提供到“符合你验收要求”的农残检测报告**。建议按下面方式判断和操作：

1. **都乐（Dole）**  
   - 通常有较规范的食品安全和供应商管理体系，批量供货时可向对接业务员/经销商申请：  
     - 该批次菠萝的农残检测报告或出厂检验报告；  
     - 检测项目是否覆盖你关注的农残指标；  
     - 报告是“批次报告”还是“型式检验/定期报告”。  
   - 注意：都乐很多货通过经销商或批发渠道走，**终端门店拿到的报告可能不是当批**，要明确写进采购合同/订单要求。

2. **鑫荣懋**  
   - 属于大型水果供应链企业，通常具备检测和溯源能力，**可要求提供农残检测报告或第三方检测报告**。  
   - 同样要确认：报告对应品种、产地、批次、检测机构、检测日期、检测项目，以及是否接受你方验收标准。

3. **最稳妥的采购做法**
   - 下单前书面确认：**随货提供与到货批次对应的农残检测报告，检测项目覆盖 GB 2763 中菠萝相关限量项目**；不能提供的，约定由供应商送检或你方抽检，费用/责任写清。
   - 收货时核对：报告批次号、品名、日期与实物一致；报告复印件加盖供应商公章或附电子可验真渠道。
   - 若用于茶饮店连锁/中央厨房验收，建议把“每批随货报告+年度第三方型式检测”写入供应商准入条件。

**结论：都乐和鑫荣懋通常“可以申请/要求”提供农残检测报告，但是否能提供当批、是否符合你的验收项目，必须在下单前让对接供应商书面确认。** 不要仅凭品牌口头承诺。
