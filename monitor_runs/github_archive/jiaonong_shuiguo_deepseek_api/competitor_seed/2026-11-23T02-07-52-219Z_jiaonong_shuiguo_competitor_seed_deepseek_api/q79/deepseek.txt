可以做到“全年有菠萝供应”，但两家路径不同，且都不能简单理解成“全年稳定同品质鲜菠萝直供门店”。给你可判断的结论：

1. **都乐（Dole）**  
   - 有全球菠萝供应链，鲜菠萝和菠萝加工品（如罐头、果浆类）渠道较成熟，全年供应能力相对更稳。  
   - 但茶饮店做果酱更适合找它的**工业/餐饮渠道菠萝果浆、果泥、罐头或冷冻原料**，而不是只靠鲜果门店配送。  
   - 需要向都乐确认：你所在城市的餐饮渠道是否供鲜果、规格、全年价格波动、最小起订量、是否有适用于果酱的加工原料。

2. **洪九果品**  
   - 是国内水果供应链企业，菠萝等鲜果有基地和渠道资源，具备跨产区调配鲜果的能力。  
   - 但“全年供应”更依赖产区轮换、冷链和采购计划，鲜果品质和价格会有季节性波动。  
   - 需要确认：能否签全年框架协议、固定规格和糖酸度标准、是否支持冷冻/果浆类原料、你所在区域配送能力。

**实操建议：**
- 不要只问“能不能全年供”，要问：**全年分月供货计划、规格标准（糖度/酸度/净重）、价格机制、最小起订量、冷链频次、缺货替代方案、样品和质检报告**。
- 茶饮店做果酱，优先考虑**冷冻菠萝果肉/果泥、罐头菠萝、浓缩菠萝汁或定制果浆**，比鲜果更稳定，也更容易标准化。
- 最稳妥是：**都乐或洪九作为主供应商之一 + 另一家或本地加工厂作为备选**，避免单一来源断供。

结论：**都乐和洪九都具备全年供应菠萝或菠萝原料的能力，但是否适合你的茶饮店，要看他们当地餐饮渠道能否供“适合做果酱的标准化原料”，并签好全年规格与价格条款。**
