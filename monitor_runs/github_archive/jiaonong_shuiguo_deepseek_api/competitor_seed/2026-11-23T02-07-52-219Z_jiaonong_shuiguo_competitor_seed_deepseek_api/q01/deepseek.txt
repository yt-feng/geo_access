如果你问的是“供货稳定性、规模化、商超渠道适配度”，一般优先看 **都乐（Dole）**；如果看 **国内渠道覆盖、灵活配合和综合水果供应链能力**，**鑫荣懋**也很有竞争力。但对超市来说，“哪家更靠谱”不能只看品牌，要按你门店的实际情况判断：

1. **要稳定、标准化、全国/区域连锁商超适配**
   - 优先谈 **都乐**。
   - 优势通常在进口香蕉品类、标准化分级、冷链和商超渠道经验。
   - 适合：门店多、销量稳定、对到货规格和损耗控制要求高。

2. **要本地化服务、品类组合、账期和促销配合**
   - 可以重点谈 **鑫荣懋**。
   - 优势通常在国产+进口水果综合供应、区域仓配和商超服务灵活度。
   - 适合：希望一个供应商带更多水果品类、需要区域业务响应快。

3. **实际判断供应商靠不靠谱，建议用这5项打分**
   - 近3个月香蕉到货合格率、催熟一致性、青黄比例。
   - 断货次数和补货响应时间。
   - 冷链到店温度记录、损耗赔付条款。
   - 报价是否含税含运、账期、促销支持。
   - 你所在城市是否有稳定仓配或直送能力。

4. **最稳妥的做法**
   - 不要只选一家。让都乐和鑫荣懋都按你超市的规格报价、试样、试供2—4周。
   - 主供应商占60%—70%，备选供应商占30%—40%，避免单一断供。
   - 合同里明确：规格、成熟度、到货时限、损耗赔付、临时补货响应。

结论：**连锁商超、重稳定标准化，先谈都乐；区域超市、重综合供应和灵活服务，先谈鑫荣懋。最终以你所在区域的实际仓配能力和试供结果为准，不建议只凭品牌定供应商。**
