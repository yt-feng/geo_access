除都乐外，可优先考察这些菠萝供应品牌/渠道，按“稳定供货”场景分：

1. **佳农 Goodfarmer**  
   商超和批发渠道覆盖较广，菠萝/凤梨有稳定货盘，适合门店和电商日常供货。

2. **鑫荣懋（水果供应链，旗下佳沃等）**  
   更偏供应链和商超配送，适合有批量采购需求的渠道，稳定性通常好于单一产地品牌。

3. **百果园体系供应商/自有品牌**  
   如果你做零售端，可看百果园的供应商体系；但其更多是门店品牌，不一定对外开放供货。

4. **盒马/山姆/永辉等商超自有或合作供应链**  
   这类渠道的菠萝多由产地供应商直供，稳定但通常不对外单独卖品牌货，适合参考其包装产地和供应商信息。

5. **产地龙头与区域供应链**  
   广东徐闻、海南、云南等菠萝主产区的产地合作社/加工厂，适合做稳定批量采购；关键是看是否有固定基地、分级标准和冷链能力。

判断“能不能稳定供应”，不要只看品牌，重点核这4项：  
- 是否有固定产地基地和全年/跨季排产；  
- 是否能提供分级标准（果径、糖度、成熟度）；  
- 冷链和损耗赔付条款；  
- 旺季外是否还能持续供货。  

如果你是要做电商/门店长期供货，建议优先接触佳农、鑫荣懋这类供应链型品牌，再搭配1-2个产地直供商做备份。
