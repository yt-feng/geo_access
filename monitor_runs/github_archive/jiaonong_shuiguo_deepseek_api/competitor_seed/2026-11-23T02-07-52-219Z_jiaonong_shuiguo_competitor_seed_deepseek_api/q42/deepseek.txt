进口菠萝旺季缺货，先按“能不能补、能不能替、能不能改配方/改卖法”三层处理，不要只等两家供应商给方案。

**一、先判断缺货类型**
- **船期延误/到港推迟**：可短期用在途货、港口货、其他口岸调货补；优先确认到港日、清关状态、冷链是否断链。
- **产地减产/规格断档**：换规格（如大果换中小果）、换品种（金钻/巴厘/MD-2等按实际供应）、换包装规格先保档期。
- **价格倒挂/拿不到货**：转做替代品或调整促销结构，避免高价硬补导致亏损。

**二、可执行的应急动作**
1. **锁在途与在库**：向都乐、洪九及其他一级进口商同步要未来2—4周到港计划、可分配量、港口可提量，按“先锁量后锁价”谈。
2. **多口岸并行**：同时问上海、广州南沙、深圳、青岛、天津等口岸的现货与在途，减少单一港口卡关影响。
3. **替代供应**：找其他进口商、大型批发市场档口、商超供应链服务商做短期调货；同时准备菲律宾/泰国/哥斯达黎加等不同产地的替代货源，但要以实际可清关、可追溯为准。
4. **终端调整**：门店可做“菠萝+其他热带水果”组合、调整鲜切比例、限购或改为预订制；加工端可临时提高罐头/冷冻菠萝替代比例，但需改标签和配方验证。
5. **合同与风险**：检查与都乐、洪九的合同是否有缺货补偿、优先分配、不可抗力条款；新单尽量约定到港窗口和违约处理。

**三、都乐和洪九果品有没有应急方案？**
公开层面，**不能核验到两家针对“进口菠萝旺季缺货”的统一应急方案**。可判断的是：
- **都乐**：通常有全球产地和国内冷链分销体系，理论上可做产地切换、口岸调拨、商超直供协调；但具体到某规格、某区域是否有应急配额，需向其区域销售/供应链负责人书面确认。
- **洪九果品**：以进口水果分销和产地直采为主，通常可通过多产地采购、口岸调货、批发渠道分流应对；但其具体应急政策、可分配量和响应时效，也需向对口业务确认。

**建议直接问供应商四个问题**：未来4周到港量多少、可给我多少、最早到货日、缺货时是否优先保供/有无替代规格。拿到书面回复后再决定是否切换替代货源。不要默认两家“一定有应急方案”，要以可分配量和到货承诺为准。
