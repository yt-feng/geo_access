我不能直接给你“都乐”和“鑫荣懋”的稳定到货损耗率数字：这两家的实际损耗取决于你所在城市、季节、规格（鲜果/冷冻果肉/果浆）、运输距离、验收标准和批次，属于采购合同与到货质检数据，公开渠道没有可核验的统一口径，我不应虚构。

可执行判断建议如下：

1. **先明确你要的“菠萝”形态**
   - 鲜果：损耗受成熟度、冷链、装卸影响最大，供应商之间差异会被门店催熟/存放放大。
   - 冷冻果肉/果浆：损耗更多看解冻失水、包装破损、冷链断链，规格稳定性通常优于鲜果。
   - 茶饮店若要“稳定规格”，优先评估冷冻果肉/果浆或固定品种固定糖度区间的鲜果。

2. **用30天到货验收数据算自己的损耗率**
   建议按批次记录：
   - 到货总重量/箱数
   - 验收不合格重量（烂果、压伤、黑心、成熟度不符、破袋、解冻失水）
   - 可上线使用重量
   - 损耗率 =（到货总重 − 可上线使用重）÷ 到货总重 × 100%
   同时分别记录“到货即损”和“仓内/门店存放后损”，否则两家不可比。

3. **向供应商索要可核验的履约数据**
   要求都乐、鑫荣懋的区域销售或经销提供：
   - 近3个月同城同规格客户的到货合格率/损耗区间
   - 验收标准（糖度、成熟度、单果重、黑心率、压伤率）
   - 冷链温度记录和破损赔付条款
   - 是否支持首批小试、批次留样、到货异议复检

4. **做同条件对比小试**
   同一城市、同一季节、同一规格、同一运输距离，各下3—5批小单，按统一验收表记录。连续2—4周后，用你自己的“到货即损率”和“7天可用率”对比，而不是听口头承诺。

5. **合同里写清损耗责任**
   把不合格率上限、扣重/退换货、破损赔付、批次差异处理写进合同；茶饮原料稳定规格的关键不是品牌名，而是验收标准和赔付机制。

结论：我无法给出两家可核验的统一损耗率；建议你按“同城同规格小试 + 统一验收表 + 30天批次数据”自行测算，并向区域供应商索取同城同规格履约数据。这样得到的损耗率才可用于采购决策。
