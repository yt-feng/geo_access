直接结论：**都乐更稳、更省心；鑫荣懋更看具体到货批次和你在哪个区域采购。** 但两家都不是“闭眼稳”，茶饮店做果酱更需要把标准写进采购合同和验收流程。

可以这样判断和执行：

1. **优先选都乐的理由**
   - 都乐品牌化程度高，菠萝品种、成熟度分级、冷链和门店供货稳定性通常更可控，适合你这种“要稳定品质做果酱”的场景。
   - 缺点是价格通常更高，而且不同区域经销商执行水平有差异，不能只看品牌。

2. **鑫荣懋不一定差，但要按批次验**
   - 鑫荣懋是国内大型水果供应链企业，菠萝供应能力不弱，价格和区域响应可能更有优势。
   - 风险在于：它更像供应链平台，实际到货品质受产地、季节、催熟/成熟度、区域仓和经销商影响更大。你需要用数据筛供应商，而不是只看公司名。

3. **果酱用途的关键指标，采购时要写清楚**
   - 品种和产地：固定品种，不接受混发。
   - 成熟度：做果酱建议统一在适合加工的成熟区间，避免一批偏生一批过熟。
   - 糖酸比/可溶性固形物：至少约定抽检范围和拒收标准。
   - 果肉率和纤维感：茶饮果酱要稳定出杯，纤维过粗、出汁率波动都要设上限。
   - 规格：去皮/带皮、切块大小、单果重量区间。
   - 冷链和到货温度：到货测温，超温拒收或折价。
   - 批次一致性：要求同一配方锁定同一产区/同一加工标准。

4. **最稳妥的做法**
   - 先小批量并行测试：都乐和鑫荣懋各进2—3批，同配方打样，记录糖酸、出成率、颜色、香气、果酱稠度和门店出杯稳定性。
   - 用“盲测+批次合格率”决定主供和备供，不要只选一家。
   - 合同里写：主供占70%，备供占30%，连续两批不合格就切换比例。

**一句话建议：** 如果你不想花太多精力管供应，选都乐做主供；如果你有品控能力、想控成本，就让鑫荣懋做备供或区域主供，用批次验收数据说话。
