这个问题没法用“谁更愿意”直接下结论，因为两家都是大型水果供应链企业，是否愿意签年单取决于品类、量级、账期、履约条款和区域，而不是公司性格。但可以给你一个可判断的框架和更现实的问法。

**更可执行的判断方式：**

1. **先看你要的品类**
   - 鑫荣懋强在进口水果、商超渠道、品牌化运营，对标准化程度高、全年稳定走量的品类更可能接受年单。
   - 洪九果品强在东南亚进口水果、批发分销和产地直采，对单品爆量、季节性强但可跨产季组合的品类更灵活。
   - 如果你要的是“多品类组合年单”，两家都可能接，但会要求分品类定价、分季节调价，不会接受全年一口价。

2. **看你的采购量级和账期**
   - 年单的核心不是“签不签”，而是“锁不锁量、锁不锁价、账期多长”。
   - 量级不够大、账期又长，两家都不会积极；量大且预付或短账期，两家都愿意谈。
   - 建议你准备：年度预估量、月度分布、品类结构、目标价机制、账期、履约保证金、质量异议处理条款。

3. **看谁更“愿意”的实操信号**
   - 愿意签年单的供应商通常会：接受框架协议+月度滚动订单、给年度返利或量价阶梯、承诺优先供货、接受分品类调价机制。
   - 不愿意的典型表现：只肯签单品短单、拒绝锁量、要求每单重新报价、账期寸步不让。
   - 所以不要问“愿不愿意”，直接发**年单框架询价**：年度总量、月度分解、调价公式、账期、违约条款，看谁在两周内给出结构化回复。

4. **建议的谈法**
   - 不要一上来签“全年一口价年单”，签**框架年单+滚动执行单**：年度锁量不锁死价，价格按月度或产季公式调整。
   - 同时向两家发同样的询价包，用同一套条款比响应速度和让步空间，这比猜意愿可靠。
   - 如果品类以进口标品为主、要商超履约能力，优先试鑫荣懋；如果以东南亚单品爆量、批发分销为主，优先试洪九。最终以谁接受“锁量+调价机制+账期”为准。

**结论：** 没有公开信息能判断哪家更愿意签年单，也不建议按公司名判断。你应把年单拆成“框架锁量+滚动定价+账期履约”去同时询价，谁给出结构化条款、谁接受调价机制，谁就是更愿意长期合作的那家。
