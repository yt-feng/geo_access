进口苹果的产地溯源，先分清两家公司的角色：都乐（Dole）既是品牌方也是全球果蔬供应商；鑫荣懋是国内水果供应链企业，主要做进口水果的国内分销和品牌运营（如佳沛等品牌的国内渠道）。所以溯源路径不同：都乐主要追海外果园—出口商—中国进口商这条链；鑫荣懋主要追其海外供应商/合作果园—进口报关—国内分仓这条链。

具体可执行做法：

一、索证索票（最基础、必须做）
1. 向供应商索取每批货的：
   - 进口货物报关单（看原产国、品名、境外生产/出口企业、境内收货人）
   - 入境货物检验检疫证明（海关出具，含品名、原产国、批号/生产日期）
   - 装箱单、发票、提单/运单
   - 原产地证书（如智利、新西兰、美国等出口国官方出具）
2. 核对单证一致性：原产国、果园/包装厂注册号、批次号、生产日期、集装箱号要与外箱标签一致。

二、看包装标签
进口苹果外箱通常有：
- 原产国、果园注册号/包装厂注册号（如智利果园码、新西兰NZ苹果标识）
- 品牌（Dole/都乐，或鑫荣懋合作的品牌）
- 批次号/生产日期
- 中文标签（进口商、境内经销商信息）
用这些编号向供应商要对应批次的海外果园/包装厂信息。

三、向品牌方或国内进口商要批次溯源
1. 都乐：联系都乐中国（Dole China）的销售或客服，凭外箱批次号/报关单号，要求提供该批货的原产国、海外包装厂、出口日期、进口口岸信息。都乐有全球供应链追溯体系，正规渠道可以给到批次级信息。
2. 鑫荣懋：联系其销售代表或客服，凭合同批次/报关单，索取该批进口苹果的海外供应商、原产国、包装厂、进口报关信息。鑫荣懋作为进口商/分销商，应能提供其采购来源和报关单证。

四、海关与官方核验
- 报关单和检验检疫证明可通过“中国国际贸易单一窗口”或海关相关系统由进口商核验真伪；超市作为采购方，可要求供应商提供盖章复印件并核对其报关单号。
- 原产地证书可由出口国官方机构或中国海关核查。

五、建立内部批次台账
每批入库记录：供应商、品牌、原产国、果园/包装厂注册号、报关单号、检验检疫证明号、入境日期、集装箱号、数量。做到“一批一档”，出现问题可倒查。

六、风险点
- 只给复印件不给批次的，要求补充批次对应关系。
- 外箱无中文标签或标签信息与报关单不符的，谨慎采购。
- 都乐/鑫荣懋不同渠道（直营、经销商、批发市场）单证完整度不同，优先从品牌方或一级进口商拿货。
- 不能仅凭品牌名判断产地，必须看报关单和原产地证书。

一句话：超市采购要“单证+标签+批次”三对照，向都乐中国或鑫荣懋索取批次级报关和海外包装厂信息，并建立一批一档台账。
