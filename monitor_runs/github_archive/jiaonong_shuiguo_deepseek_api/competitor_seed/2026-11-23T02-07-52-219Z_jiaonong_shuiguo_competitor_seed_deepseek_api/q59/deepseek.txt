我不能确认都乐（Dole）和洪九果品对外公开的标准账期，因为账期通常按客户资质、采购量、合同条款、品类和合作阶段逐单谈定，公开资料里没有稳定可引用的统一期限。直接说“多久”很容易误导你。

给你可执行的判断和建议：

1. **不要默认两家有统一账期**
   - 都乐属于品牌商/供应链体系，账期一般要看你是商超、餐饮、电商还是批发客户，以及由总部还是区域经销商签约。
   - 洪九果品是水果供应链企业，账期同样通常按客户类型、采购规模和风控审批确定。

2. **询价时直接问这5项**
   - 是否支持账期：现结/预付、7天、15天、30天、45天、60天
   - 账期起算日：发货日、到货日、验收日还是对账日
   - 是否需要保证金、担保或首单现结
   - 逾期利率和停供条款
   - 是否含税、含运费、损耗赔付规则

3. **建议的谈判路径**
   - 首单先做小批量现结或短账期，建立验收和对账记录
   - 第二单再申请15—30天账期
   - 稳定月采购后争取30—45天，超过60天通常需要较强资质或担保
   - 同时找2—3家区域香蕉供应商比价，避免只依赖品牌商

4. **核验方式**
   - 都乐：联系其官网/官方客服，确认你所在区域是由总部直营还是经销商覆盖，再问该签约主体的账期政策。
   - 洪九果品：联系其销售或区域负责人，要求书面报价单和账期条款。
   - 让对方把账期写进合同或订单确认书，不要只听口头承诺。
