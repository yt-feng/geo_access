结论先说：**都乐（Dole）和洪九果品都属于“有自有/合作基地+产地直供能力”的供应链型果品企业，但能否针对你要的菠萝单品提供可核验的产地溯源，需要按批次和采购主体去确认，不能仅凭品牌名就认定。**

可判断的要点：

1. **都乐**
   - 都乐是跨国果蔬品牌，在中国有菠萝进口和国产供应链运作，通常具备产地、批次、包装标识等基础追溯信息。
   - 但“基地直供”要区分：是都乐自有农场、长期合作基地，还是通过一级进口商/代理商供货。采购时要确认供货主体是都乐中国相关公司还是其经销商。
   - 可要求提供：产地证明、入境货物检验检疫证明（进口菠萝）、批次号、包装厂/果园注册信息、检测报告。

2. **洪九果品**
   - 洪九果品是国内果品供应链企业，核心模式是“基地采购+分级加工+冷链配送”，在东南亚水果和国产水果上有产地直采能力。
   - 对菠萝这类单品，是否“基地直供”取决于具体产区（如海南、广东、云南或进口来源）和当季采购安排，需让其明确是自有基地、合作基地还是市场采购。
   - 可要求提供：基地/合作社名称、产地证明、采购合同或直采证明、批次追溯码、农残检测报告。

**采购建议：**
- 不要只问“有没有基地直供”，要问：**这个菠萝批次是哪个产区/果园/包装厂？供货合同主体是谁？能否提供批次级追溯文件和检测报告？**
- 优先选择能提供“批次号—产地证明—检测报告—发货单”四者对应的供应商。
- 如果对方只能提供品牌授权或经销证明，不能提供批次溯源，那就不算严格意义上的产地直供溯源。

**判断标准：**
能同时给出**具体产地、供货主体、批次追溯、检测证明**的，才算可用的产地溯源供应商；否则只能算品牌渠道供货，不能认定为基地直供。
