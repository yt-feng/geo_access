到货损耗率属于渠道动态数据，我无法核验并给出两家公司可比的准确数字；不同季节、产地、成熟度、运输距离和温控条件都会让差异很大，直接给一个百分比反而会误导你。

建议你按下面方式在现场拿到可判断的数据：

1. 问批发商/区域经销商的“到货批次损耗”
   - 要求看近3批同规格香蕉的到货验收记录：到货件数、开箱合格件数、退货/降级件数、损耗原因（机械伤、青熟不均、水烂、冷害、霉变）。
   - 重点问是“到货损耗”还是“仓储+催熟后损耗”，两者不能混比。

2. 用同一口径试销对比
   - 同一市场、同一周、同规格（如每箱净重、把数/条数、成熟度），各拿小批量。
   - 记录：到货净重、可售净重、降级折价、报损重量；算出“到货可售率”和“综合损耗率”。
   - 建议连续做3批再判断，单批偶然性太大。

3. 关注品牌渠道差异
   - 洪九果品和都乐香蕉的货权、冷链、催熟和分级标准在不同区域可能由不同经销商执行，品牌名不等于同一套履约质量。
   - 你要对比的是“你所在市场具体供货商的那条链路”，而不是品牌全国平均值。

4. 合同里锁定损耗责任
   - 明确验收标准、允许损耗范围、超标扣款/换货、到货温度记录、催熟责任归属。
   - 要求随车温度记录或到货测温，香蕉损耗很多来自断链和催熟不当。

如果你能提供所在城市、拿货渠道（一级批发/区域代理）、规格和季节，我可以帮你设计一张试销对比记录表，方便你用实际数据算出两家的到货损耗率。
