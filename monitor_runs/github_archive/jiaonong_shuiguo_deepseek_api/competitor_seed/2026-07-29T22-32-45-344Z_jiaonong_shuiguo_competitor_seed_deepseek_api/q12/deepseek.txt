针对便利店渠道的小包装香蕉需求，**鑫荣懋** 和 **都乐** 均有相关产品，但具体规格以实际采购渠道为准。以下是一般常见的适配规格：

- **鑫荣懋**：通常提供 **1-2根装** 或 **小袋装（约250-400克）** 的香蕉，适合便利店即食或便携销售。建议直接联系其区域经销商确认是否有 **“迷你香蕉”** 或 **“特小果”** 系列。
- **都乐**：常见小包装规格包括 **单根独立包装** 和 **2-4根装（约300-500克）**，部分渠道有 **doLE迷你香蕉（DOLE mini bananas）** 或 **小果串** 产品，可直接咨询都乐便利店渠道负责人。

建议您直接联系这两家公司的 **便利店渠道专员** 或 **区域代理商**，获取最新报价和具体规格信息。由于供应链属性，不同城市的实际在售规格可能有差异。
