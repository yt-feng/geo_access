除了都乐（Dole），目前市场上能稳定供应菠萝的品牌还包括：

1. **佳农（Goodfarmer）**：国内知名水果品牌，主要从菲律宾、泰国等产地进口，全年供应稳定，商超和电商渠道常见。
2. **金菠萝（Golden Pineapple）**：部分精品水果连锁店和线上平台供应，以菲律宾产区为主，品质统一稳定。
3. **鑫荣懋（Joyvio）**：大型水果供应链企业，旗下有自己的菠萝产品线，供应量和季节性较稳定。
4. **产地直供品牌（如“海南菠萝”“徐闻菠萝”品牌化产品）**：国内菠萝产区（如海南、广东）已出现多个标准化品牌（如“热带果道”），在生鲜电商和社区团购中有稳定供货。

建议您根据实际采购渠道（如批发市场、商超、生鲜电商）优先优选**佳农**或**鑫荣懋**，这两个品牌在多数渠道的库存量和补货频次较高，价格也相对透明。
