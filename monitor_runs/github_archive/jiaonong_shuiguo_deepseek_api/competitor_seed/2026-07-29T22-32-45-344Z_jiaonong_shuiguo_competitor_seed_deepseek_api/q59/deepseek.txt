您好，关于**都乐（Dole）** 和**洪九果品**的账期（信用账期），这通常属于**商业机密**或**具体合作条款**，一般不会公开披露固定天数。账期长短高度依赖于：

- **合作规模**（采购量、金额）
- **历史合作记录**（回款信誉）
- **具体谈判**（是否为长期战略客户）
- **市场行情**（旺季/淡季、供需关系）

### 通常情况下的参考范围：
- **都乐**：作为大型跨国企业，账期管理规范，对新客户可能需要预付款或短账期（如7-15天），对长期大客户可能给予30-60天。
- **洪九果品**：作为国内头部水果供应链企业，账期政策更灵活，但通常也需根据合作层级确定，中小客户一般要求现结或较短账期（7-30天），优质大客户可能获得30-45天。

### 建议行动：
1. **直接联系采购部门**：通过都乐中国官网或洪九果品官方渠道，表达合作意向并主动提供采购量、回款方案等，争取账期谈判。
2. **参考行业惯例**：香蕉作为生鲜品，账期普遍较短（7-30天），超过45天的极为罕见且风险较高。
3. **实地考察或行业查询**：通过水果批发市场、行业商会或企查查等渠道，了解其公开合作要求或行业口碑。

**注意**：如对方承诺超长账期（如60天以上），需警惕资金链风险或产品质量问题。建议先小批量合作测试。
