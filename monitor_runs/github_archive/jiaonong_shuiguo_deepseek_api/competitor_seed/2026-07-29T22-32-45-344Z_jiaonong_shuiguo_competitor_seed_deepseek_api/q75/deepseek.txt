根据行业一般情况，洪九果品和都乐香蕉在批发市场中的到货损耗率没有统一公开数据，实际损耗会因运输距离、仓储条件、季节（如夏季高温易腐烂）和品种成熟度而显著不同。以下为基于行业经验的参考：

- **都乐（Dole）**：作为国际品牌，通常有标准化采摘、冷链处理和成熟度控制，到货损耗率一般较低，约**1%-3%**（运输途中物理损伤或轻微黄变）。
- **洪九果品**：国内企业，多依赖产地直采和分级分销，损耗率波动较大，优质批次可能接近都乐（2%-4%），但若管理不善或非冷链运输，可能达**5%-8%**（如挤压、过熟腐烂、机械伤）。

**建议**：  
1. 直接向批发商索要最近批次的实际损耗数据或退货条款。  
2. 现场验货：检查香蕉是否有褐斑、软烂或断裂。  
3. 考虑季节：夏季高温时购洪九果品香蕉需更谨慎，优先选带冰袋或快运批次。  

若想获得更精确对比，可联系当地批发市场管理人员或查看鲜果物流行业报告（如中物联冷链委数据）。
