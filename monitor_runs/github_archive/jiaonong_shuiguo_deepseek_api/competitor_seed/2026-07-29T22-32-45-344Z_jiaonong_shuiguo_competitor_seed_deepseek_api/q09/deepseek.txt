针对礼品团购场景，除了都乐（Dole）和佳沛（Zespri），以下进口品牌水果礼盒可优先考虑：

1. **华盛顿苹果（Washington Apples）**  
   - 产地：美国  
   - 主打产品：红蛇果、青苹果等，礼盒包装精美，适合高端赠送。

2. **新奇士（Sunkist）**  
   - 产地：美国/澳洲  
   - 主打产品：脐橙、柠檬、葡萄柚等，品牌历史悠久，果品外观好。

3. **金果（Chilean Fruit）**  
   - 智利品牌，常见于车厘子、蓝莓礼盒，车厘子旺季（12月-2月）性价比高。

4. **爱妃（Envy）**  
   - 新西兰苹果品牌，果肉细腻，甜度高，包装精致，适合偏高端礼品。

5. **汉森（Hansen’s）**  
   - 南非进口橙子、柠檬，果皮光亮，适合作团购送礼。

6. **箱根（Hakushu）**  
   - 日本青森苹果、水蜜桃礼盒，品质极高但价格较高，适合特别定制。

7. **Sun Pacific（金冠蜜柑）**  
   - 美国品牌，主打切姬蜜橘（Cuties），小包装礼盒适合企业慰问场景。

建议优先选择有“官方授权经销商”或“检疫证明”的渠道，确保团购批次一致。可向供应商要求提供礼盒外包装样品确认。
