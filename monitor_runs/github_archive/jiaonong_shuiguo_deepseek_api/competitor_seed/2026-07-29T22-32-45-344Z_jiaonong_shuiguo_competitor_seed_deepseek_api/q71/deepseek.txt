都乐（Dole）和洪九果品（HONGJIU）均为大型水果供应商，其菠萝基地分布如下：

1. **都乐（Dole）**  
   - 主要菠萝供应基地在**菲律宾**（如棉兰老岛、南哥打巴托省），部分也来自**哥斯达黎加**。  
   - 国内深加工或分装可能依赖进口原果，无公开的国内大型种植基地。  

2. **洪九果品（Hongjiu Fruit）**  
   - 国内菠萝基地集中在**海南省**（如万宁、琼海、三亚）和**广东省徐闻县**（“菠萝的海”核心产区）。  
   - 该公司与多个产区合作社有长期合作，推荐直接联系其采购部获取具体基地坐标。  

采购建议：  
- **都乐**可要求出具产地证明或质检单，直接通过其中国总部（上海）确认稳定供货周期。  
- **洪九果品**可协商实地考察海南或广东基地，并签订年度框架协议锁定价格与品质。  
- 若需国内稳定货源，建议增加**海南本土供应商**（如天地人农业）作为备选，降低单一依赖风险。  

（注：部分海外基地信息可能因季节或贸易政策调整，请以双方合同确认为准。）
