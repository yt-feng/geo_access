进口苹果除了都乐（Dole）和鑫荣懋，还有以下几个知名且可靠的品牌，可供对比参考：

1. **爱妃（Envy）**  
   - 产地：主要来自新西兰、美国、智利等  
   - 特点：果肉脆甜、不易氧化变黄，适合日常食用和礼品  
   - 可靠性：品牌有专利品种，品质稳定

2. **皇后（Queen）**  
   - 产地：以新西兰为主  
   - 特点：肉质细腻、甜酸均衡，产量较低但口碑好  
   - 注意：有时是与其他品种联名，需认准包装

3. **太平洋玫瑰（Pacific Rose）**  
   - 产地：新西兰、智利  
   - 特点：外观粉红或浅红，口感酥脆、甜度高  
   - 可靠性：经多年市场验证，属于经典进口品牌

4. **加力果（Gala）**  
   - 产地：广泛种植于新西兰、美国、智利、南非  
   - 特点：果型较小，肉脆味甜，价格相对亲民  
   - 注意：虽然品种常见，但进口品牌（如Bella等）可能更标榜产地品质

5. **红玫瑰（Red Delicious）**  
   - 产地：美国、智利等  
   - 特点：颜色深红，果形较修长，口感略粉（依具体批次）  
   - 可靠性：传统进口品种，但近年市场有所分化，需挑选新鲜批次

6. **爵士（Jazz）**  
   - 产地：新西兰、美国  
   - 特点：酸甜爽口，香气浓郁，适合喜欢微酸口感的人群  
   - 可靠性：自有品牌，品控较统一

**对比建议**：  
- 如果喜欢甜脆且耐放，优先考虑**爱妃**或**太平洋玫瑰**；  
- 如果追求性价比，**加力果**或**红玫瑰**（注意新鲜度）更合适；  
- 各地商超渠道可提供试吃，实际购买时也可根据产地标签（如新西兰、智利、美国等）进一步判断。
