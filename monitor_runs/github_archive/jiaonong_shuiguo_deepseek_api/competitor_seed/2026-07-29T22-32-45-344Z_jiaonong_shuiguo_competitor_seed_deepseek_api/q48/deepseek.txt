通常情况下，大型商超（如沃尔玛、永辉、盒马等）要求供应商具备的食品安全认证主要包括：**ISO 22000食品安全管理体系、HACCP危害分析与关键控制点体系认证**。部分零售商超还会要求**GLOBALG.A.P.（全球良好农业规范）**、**BRCGS（全球食品安全标准）**或**FSSC 22000**等特定国际标准。

针对**鑫荣懋**和**都乐**两个大型水果/生鲜供应商，其公开可查的常见资质包括：

1. **鑫荣懋（Xinrongmao / Joyvio）**
   - **主要认证**：通常具备**ISO 22000**和**HACCP**认证。
   - **国际认证**：获得**GLOBALG.A.P.**认证（针对其出口及高端商超渠道的水果/蔬菜）。
   - **其他奖项或资质**：作为中国果业头部企业，常通过**SGS**或**Intertek**等第三方权威机构审核，并持有**有机产品认证**（部分品类）。
   - **自主检测**：企业设有**CNAS认可实验室**，能提供内部检测报告。

2. **都乐（Dole）**
   - **主要认证**：全球通用**ISO 22000**、**HACCP**。
   - **行业特定认证**：**雨林联盟（Rainforest Alliance）认证**（针对香蕉、菠萝等核心品项，这是大型超市特别要求的可持续+安全双重标准）；同时具备**GLOBALG.A.P.**。
   - **产地国认证**：例如美国总部持有**FDA登记**、**USDA有机认证**；在中国市场拥有海关备案的**进口商检验检疫证明**。
   - **社会责任类认证**：部分商超还会查验**SEDEX（社会责任审核）**，都乐通常也具备。

**如何验证？**
- 你可以直接向鑫荣懋或都乐的销售/对接人员索要**最新有效期内（一般12或24个月）的认证证书扫描件**。
- 大型商超采购系统中，这些供应商的**资质档案（如供应商准入审核表）**通常会直接列出上述对应认证项，你也可以在**商超自己的供应商门户**内检查认证是否已过期。

如果还需要更具体到某个城市或特定商超（如旗下高端超市）的清单，建议直接咨询该商超的**品控或采购部门**，他们会有详细的最新准入目录。
