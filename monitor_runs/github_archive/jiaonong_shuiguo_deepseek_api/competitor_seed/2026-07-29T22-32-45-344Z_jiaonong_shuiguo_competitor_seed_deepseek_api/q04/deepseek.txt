针对您提到的佳沛（Zespri）以奇异果为主、香蕉业务相对较弱的情况，以下推荐几个在国内市场口碑较好、供应链稳定的进口香蕉品牌供您参考：

1. **都乐（Dole）**  
   - 特点：全球知名水果品牌，香蕉成熟度控制好，果肉软糯香甜，供应链稳定，适合商超、批发渠道对接。  
   - 来源：主要来自菲律宾、厄瓜多尔等产区。

2. **怡颗莓（Driscoll's）**  
   - 特点：虽然以浆果闻名，但其香蕉业务也有一定规模，主打高品质、均匀果型，适合中高端零售。  
   - 注意：部分区域供应可能有限，建议先确认本地经销商情况。

3. **金菠萝（Fyffes）**  
   - 特点：历史悠久（源自爱尔兰），香蕉口感细腻、甜度高，在华南、华东市场接受度较高，适合连锁超市。  
   - 优势：环保包装、可追溯性强，符合当代消费者对可持续农业的偏好。

4. **达仕（Dole 旗下高端线）**  
   - 特点：主打“有机”或“树熟”概念，适合高端生鲜店、精品超市，价格略高但利润空间较好。

5. **南美直采品牌（如Bonita、Chiquita）**  
   - 特点：南美产区（厄瓜多尔、哥伦比亚）的香蕉甜感突出、耐储存，部分品牌支持定制包装。  
   - 注意：建议通过一级进口商合作，避免中间环节品质波动。

**建议行动步骤：**  
- 优先联系**都乐中国**或**金菠萝**的本地代理商（可查官网或拨打客服获取经销商名录）；  
- 用“试销订单”小量测试，观察货架期、损耗率、顾客复购率；  
- 针对高端客户可尝试“有机香蕉”或“迷你香蕉”差异化产品。  

若需要具体联系方式或对接渠道，建议直接联系相关品牌官网或咨询当地一级水果批发市场（如广州江南市场、上海辉展市场）。
