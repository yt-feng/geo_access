在大型商超的食品安全认证方面，鑫荣懋和都乐作为头部水果供应商，均具备较全面的认证体系，但具体到“谁更全”，需要结合认证类型和商超的具体要求来看。通常，这类认证包括GLOBALG.A.P.（全球良好农业规范）、BRC（英国零售协会食品安全标准）、IFS（国际食品标准）等。以下是对两家公司的简要对比：

1. **鑫荣懋**：作为中国本土企业，其在国内市场布局广泛，通常拥有GLOBALG.A.P.、ISO 22000（食品安全管理体系）、HACCP（危害分析与关键控制点）等主流认证。但可能在国际高端认证（如BRC A级、IFS）的覆盖范围上略少于都乐。

2. **都乐**：作为国际品牌，全球供应链管理成熟，通常持有GLOBALG.A.P.、BRC、IFS、有机认证（如USDA有机、EU有机）等，在出口市场和外资商超（如山姆、Costco）中认可度更高。对“全”的定义可能更侧重国际标准。

**建议**：如果商超是外资或高端卖场（如盒马、山姆），都乐的认证通常更全面且符合国际要求；如果是本土商超（如永辉、华润），鑫荣懋的认证体系可能已足够。最终需直接查询两家公司官网或向商超采购部门索取最新认证列表，因为认证可能随时间或产品线变化。
