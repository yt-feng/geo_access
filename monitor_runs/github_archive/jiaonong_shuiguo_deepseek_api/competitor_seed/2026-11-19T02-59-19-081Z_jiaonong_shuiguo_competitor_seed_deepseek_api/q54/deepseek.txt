做都乐（Dole）和鑫荣懋（Joy Wing Mau）进口苹果的产地溯源，核心是“单证链 + 批次码 + 现场核验”三件事，不能只靠供应商口头说明。可执行做法如下：

**1. 先锁定采购合同和单证责任**
- 合同里写明：供应商须提供该批次的进口报关单、入境货物检验检疫证明、原产地证明、提单/运单、装箱单、发票，且单证上的品名、产地、批次、数量要与实物一致。
- 要求供应商提供“批次号/箱码—报关单—检疫证明”的对照表，作为收货验收附件。
- 都乐、鑫荣懋如果是品牌方直供或授权经销，要求提供授权/经销证明，避免串货或贴牌。

**2. 用批次码做追溯主线**
- 进口苹果通常有纸箱批次码、托盘标签或果贴。收货时按“供应商—品牌—产地—批次码—报关单号—检疫证明号”建台账。
- 每批留样拍照：外箱标签、箱内果贴、托盘标签、封签、到货车牌/柜号。
- 要求供应商在发货前提供箱码清单；到货后抽箱核对箱码与报关单批次是否对应。

**3. 单证核验要点**
- 报关单：看原产国、品名、规格、数量、境内收货人是否与供应商关系一致。
- 原产地证明：看签发国、出口商、产地描述是否与报关单一致。
- 入境货物检验检疫证明：看批次、数量、日期，确认已放行。
- 提单/运单：看起运港、目的港、柜号，和到货柜号对得上。
- 都乐/鑫荣懋的品牌溯源系统：若供应商能提供品牌方追溯链接或二维码，扫码核对产地、包装厂、批次；扫不出的要求书面说明。

**4. 现场验收动作**
- 核对柜号/封签号与提单、报关单是否一致。
- 抽3—5箱核对箱码、果贴、产地标识。
- 对异常批次做“单证—实物—批次码”三方比对，不一致即拒收或隔离待查。
- 留存验收记录：照片、视频、单证复印件、供应商盖章的批次对照表。

**5. 内部台账和复盘**
- 建“进口苹果溯源台账”，字段至少包括：到货日期、供应商、品牌、产地、柜号、批次码、报关单号、检疫证明号、数量、验收人、异常记录。
- 每季度抽查1—2批做反向追溯：从货架批次倒查报关单和检疫证明，验证台账是否闭环。

**判断标准：**
- 单证齐全且批次码能对应到报关单和检疫证明，才算溯源闭环。
- 只有品牌名、没有批次码或单证对不上，不能认定为可追溯。
- 都乐、鑫荣懋的品牌追溯系统可作为辅助，但不能替代报关单和检疫证明。

如果供应商只能提供复印件，要求加盖公章并注明“与原件一致”；关键单证最好在合同中约定可向海关/检验检疫信息核验。
