不能简单回答“能”或“不能”，要分两层看：**全年有货**和**全年稳定适合做果酱**不是一回事。

### 1. 都乐
都乐具备较强的全球采购和供应链能力，理论上可以通过不同产区轮换做到菠萝全年供应。但对茶饮店做果酱而言，关键不是“有没有菠萝”，而是：
- 全年品种、成熟度、糖酸比是否稳定；
- 到货是鲜果还是冷冻/罐头/果浆原料；
- 你所在城市的经销渠道是否能稳定拿到同规格货；
- 最小起订量、价格波动和冷链条件。

所以都乐**大概率能提供全年供应方案**，但要以你当地经销商的报价、规格和供货合同为准，不能仅凭品牌判断。

### 2. 洪九果品
洪九果品是国内大型水果分销企业，菠萝是其经营品类之一，具备跨产区采购和分销能力。但它的强项更偏鲜果大宗分销，是否能为茶饮店提供**全年稳定、适合做果酱的菠萝原料**，要看：
- 你采购的是鲜果还是加工原料；
- 洪九在你所在区域是否有稳定配送；
- 是否能承诺全年同品种、同成熟度；
- 是否支持小批量、高频次配送。

因此，洪九**有全年供货能力的基础**，但不等于能直接满足茶饮店果酱的标准化需求。

### 可执行判断建议
不要先问“品牌能不能”，直接向供应商要这5项：
1. **全年供货计划表**：几月到几月用哪个产区、什么品种；
2. **样品一致性**：连续3批样品的糖度、酸度、成熟度、出汁率；
3. **规格与形态**：鲜果、冷冻果块、果茸、果浆哪种可全年供；
4. **最小起订量和配送频次**：能否支持门店小批量；
5. **断供预案和价格机制**：旺季/淡季价格浮动、替代产区。

### 结论
- **都乐**：更可能有全年供应方案，适合进一步谈稳定规格和加工形态。
- **洪九果品**：有全年采购分销基础，但需确认是否适合茶饮果酱的标准化和小批量配送。
- **最稳妥做法**：不要单一依赖一家。用“都乐/洪九鲜果或果茸 + 一家冷冻果浆/果茸加工商”做双供应，先锁全年样品标准，再签供货框架。茶饮果酱更建议优先测试**冷冻菠萝果茸/果浆**，比鲜果全年稳定性更好。
