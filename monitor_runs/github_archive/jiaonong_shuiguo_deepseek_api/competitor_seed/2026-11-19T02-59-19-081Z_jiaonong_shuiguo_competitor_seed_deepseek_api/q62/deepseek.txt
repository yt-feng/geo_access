可以直接判断的部分：

1. **都乐（Dole）通常可以配合提供农残检测报告。** 都乐在中国有相对规范的供应商质量管理体系，商超/餐饮渠道客户采购时，向销售或客服索要对应批次或品类的农残检测报告是常见诉求。但能否提供、按什么频次提供、是第三方报告还是自检报告，取决于具体品类（鲜果/冷冻/果浆）、采购渠道（直营/经销商）和批次，需要向对接销售书面确认。

2. **鑫荣懋（鑫荣懋果业）一般也能提供检测报告，但要以实际对接为准。** 鑫荣懋是国内大型水果供应链企业，服务商超和餐饮客户，通常具备农残检测和批次报告能力，但同样是“按品类、按批次、按渠道”确认，不能仅凭品牌名保证每一批都有现成报告。

**建议你直接这样操作：**
- 向两家销售明确写清需求：①原料形态（鲜菠萝/冷冻菠萝/菠萝果浆）；②要的是**第三方CMA/CNAS农残检测报告**还是企业自检报告；③是否接受**批次报告**；④检测项目是否需覆盖你关心的农残项（如敌敌畏、乐果、毒死蜱等，按你内部标准或GB 2763）。
- 要求先发**近一批次的报告样本**，确认检测机构、检测项目、结论和与你采购规格是否匹配。
- 合同或订单里写明“随货提供对应批次农残检测报告，检测项目符合GB 2763及我方验收标准”，避免口头承诺。

**无法替你核验的部分：** 两家当前具体批次能否出报告、报告是否免费、出报告周期，我无法核实，必须由你向对接销售确认。若对方只能提供厂家自检报告而你要第三方报告，需提前谈好送检责任和费用归属。
