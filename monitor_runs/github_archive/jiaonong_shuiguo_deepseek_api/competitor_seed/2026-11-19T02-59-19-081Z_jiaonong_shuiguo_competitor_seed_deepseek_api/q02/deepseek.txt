除了都乐，国内渠道里能相对稳定供货的菠萝品牌/供应商，通常要分“鲜果品牌”和“供应链渠道”两类看。下面这些是市场上较常见、可作为备选的方向，但稳定性会受季节、产地和渠道影响，建议先小批量试单：

**鲜果/水果品牌类**
1. **佳农**：商超和电商渠道覆盖较广，菠萝有稳定铺货，适合零售和餐饮采购。
2. **鑫荣懋**：水果供应链企业，旗下有品牌化水果，菠萝类可询盘，适合商超、团购渠道。
3. **百果园**：自有渠道为主，部分区域有菠萝供应，适合门店型采购，不一定对外大批量供货。
4. **洪九果品**：做进口和国产水果供应链，菠萝可询盘，适合批发市场、商超渠道。
5. **鲜丰水果**：以门店零售为主，供应链采购可咨询，适合区域门店合作。
6. **盒马/山姆/永辉等自有品牌或直采**：不是传统品牌，但渠道直采的菠萝稳定性往往比小品牌强，适合零售采购。

**产地与供应链类**
7. **广东徐闻产区供应商**：徐闻菠萝量大，产地合作社、代办和加工厂较多，适合找稳定货源，但需要验货和分级。
8. **海南菠萝产区供应商**：海南菠萝上市期有优势，适合季节性补货。
9. **云南/广西产区供应商**：可作为错季或补充货源。
10. **大型批发市场档口**：如嘉兴、广州江南、北京新发地等市场的菠萝档口，适合短期稳定拿货，但品牌化程度低。

**判断建议**
- 如果你是**零售/商超**：优先谈佳农、鑫荣懋、洪九，以及盒马/山姆类直采渠道。
- 如果你是**餐饮/加工**：优先找徐闻、海南产地供应商或大型批发档口，按规格和成熟度分级采购。
- 如果你是**电商/团购**：佳农、鑫荣懋这类品牌化供应链更稳，售后和分级更规范。
- 不管找谁，先确认：**产地、品种（如金钻/巴厘）、规格、成熟度、全年可供月份、冷链条件、次品率**，再小批量试单。

提醒：菠萝供应季节性很强，所谓“稳定”通常是“某个产区+某个渠道”的组合稳定，而不是单一品牌全年稳定。建议至少备2个产区+1个品牌供应链作为组合。
