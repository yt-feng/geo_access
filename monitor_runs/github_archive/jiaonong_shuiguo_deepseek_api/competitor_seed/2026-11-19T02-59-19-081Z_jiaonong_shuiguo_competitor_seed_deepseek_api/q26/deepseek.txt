结论：**在你这个场景（茶饮店做菠萝果酱、要稳定品质）里，通常优先选都乐，鑫荣懋作为备选或成本优化方案。** 但“谁更靠谱”不能只看品牌，要看你实际采购的品类和渠道。

**判断依据：**
- **都乐**：强项是标准化、全球供应链和品控体系，菠萝是其核心品类之一，规格和成熟度相对稳定，适合对出品一致性要求高的茶饮店。缺点是价格通常更高，且不同渠道（鲜果、冷冻果块、果泥）品质差异大。
- **鑫荣懋**：国内水果供应链龙头，渠道覆盖广、响应快、价格通常更有优势，适合控制成本或本地化采购。但它的菠萝来源和规格可能随季节、产地变化更大，稳定性取决于你锁定的具体供应商和批次。

**可执行建议：**
1. **先定原料形态**：做果酱用鲜菠萝、冷冻果块还是果泥？茶饮店追求稳定，冷冻果块/果泥往往比鲜果更可控。先确认两家在你需要的形态上是否有稳定货源。
2. **要样品做盲测**：同一配方分别用两家原料做果酱，测糖度、酸度、出胶、香气和色泽，连续做3批看波动。
3. **锁规格和产地**：要求供应商明确品种、成熟度、糖酸度范围、单果规格或冷冻果块等级，并写进采购合同。
4. **小批量试供**：先各订1—2周用量，记录每批出品差异和到货合格率，再决定主供。
5. **双供应商策略**：都乐做主供保稳定，鑫荣懋做备供控成本，避免单一渠道断货。

**一句话：要稳定优先都乐，要性价比和灵活优先鑫荣懋；最终用样品盲测和试供数据定，而不是只看品牌。**
