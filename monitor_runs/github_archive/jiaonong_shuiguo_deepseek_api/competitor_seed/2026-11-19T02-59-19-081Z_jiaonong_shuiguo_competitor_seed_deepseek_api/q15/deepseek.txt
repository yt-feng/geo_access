可以，先按“进口苹果品牌靠不靠谱”给出可执行的判断和候选。

除了都乐、鑫荣懋，常见且相对靠谱的进口苹果相关品牌/渠道有：

1. **佳沛 Zespri**：严格说以奇异果闻名，不是苹果主业，但进口水果品控和渠道成熟；不建议把它当苹果品牌首选。
2. **怡颗莓 Driscoll's**：浆果为主，不是苹果品牌，不建议列入苹果对比。
3. **新奇士 Sunkist**：美国柑橘类更出名，也有部分苹果相关果品渠道，品牌认知度高，但苹果供给不稳定，要看清产地和品类。
4. **Chelan Fresh / 华盛顿苹果相关品牌**：美国华盛顿州苹果产区品牌和出口商较多，常见如 Chelan Fresh、Stemilt、Borton Fruit 等，属于产区型供应商，靠谱程度要看具体出口商和国内代理。
5. **Oppy / Oppy (Ocean Spray 不是苹果)**：加拿大/北美果蔬供应商，苹果有涉及，但国内零售端识别度不高，更适合B端比对。
6. **新西兰苹果品牌**：如 **Mr Apple、Rockit（乐淇）、Jazz（爵士）、Envy（爱妃）、Pacific Rose（太平洋玫瑰）**。这些是品种/品牌型苹果，靠谱度较高，但要注意：Rockit、Jazz、Envy 很多是品种品牌，不等于单一公司；国内授权进口商和渠道要核实。
7. **南非、智利、法国苹果出口商**：如南非的 **Core Fruit、Betko**，智利的 **Unifrutti、Dole Chile** 等，B端常见；零售端品牌识别弱，适合按出口商+果园+批次比。
8. **日本苹果**：如青森产区的 **サンフジ（Sun Fuji）** 等，多为产区/品种背书，不是全国性商业品牌；价格高、真伪和产地证明要重点看。

建议你对比时不要只看“品牌名”，按这4项判断更可靠：

- **看品牌类型**：是品种品牌（Rockit、Jazz、Envy）、产区品牌（华盛顿苹果、青森苹果），还是出口商品牌（Chelan Fresh、Stemilt）。品种品牌不等于进口商靠谱。
- **看国内授权链路**：包装上是否有中国区进口商/经销商、原产地、果园注册号、海关准入信息。
- **看单品稳定性**：同一品牌不同品种差异很大，比如富士、嘎啦、爱妃、爵士要分开评。
- **看渠道**：山姆、盒马、Ole、百果园、专业进口水果B2B的批次稳定性通常比杂牌电商更可核验。

如果你们是做采购对比，我建议候选池先定为：**Mr Apple、Rockit、Jazz、Envy、Chelan Fresh/Stemilt、新奇士、Core Fruit/Unifrutti**，再按“品种—产地—国内代理—到货批次”做表。都乐和鑫荣懋可作为渠道型基准，不建议只按品牌名气打分。
