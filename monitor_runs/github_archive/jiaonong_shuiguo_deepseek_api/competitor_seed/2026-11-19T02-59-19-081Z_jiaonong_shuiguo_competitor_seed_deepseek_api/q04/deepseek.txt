佳沛（Zespri）确实以奇异果为核心，香蕉不是它的强项。进口香蕉品牌可以按“源头品牌”和“国内进口商/渠道品牌”两类看：

**国际源头品牌（较常见）**
- **Dole 都乐**：香蕉是其传统强项，菲律宾、厄瓜多尔等产地供应链成熟，国内商超和批发渠道覆盖广，适合做稳定走量。
- **Chiquita 金吉达**：全球香蕉老牌，品质标准稳定，适合中高端商超和餐饮渠道。
- **Del Monte 德尔蒙**：香蕉、菠萝等热带水果都有，进口香蕉在部分渠道可见，可作为补充品牌。
- **Fyffes**：欧洲老牌香蕉商，国内直接铺货不如都乐、金吉达普遍，更多见于特定进口商渠道。

**国内进口商/渠道品牌**
- 很多国内水果进口商会有自有或贴牌的菲律宾、越南、厄瓜多尔香蕉，价格和货源灵活，但品牌稳定性不如上述国际品牌，适合作为补充或价格带产品。

**选择建议**
- 要**稳定走量、商超覆盖**：优先谈 **Dole 都乐**，其次 **Chiquita 金吉达**。
- 要**中高端差异化**：可考虑 **Chiquita** 或特定产地的 **厄瓜多尔香蕉**。
- 要**价格带补充**：找国内一级进口商做菲律宾/越南香蕉贴牌或渠道品牌，但要注意品控和催熟一致性。
- 香蕉业务的关键不只是品牌，还有**催熟能力、到货节奏和损耗控制**，建议先小批量试单，比较到货成熟度、货架期和售后。
