我无法核验都乐和鑫荣懋当前的到货损耗率数据，直接给具体百分比会是编造。可执行判断如下：

1. **先向供应商要“同规格、同运输方式、同到货城市”的3个月损耗记录**，不要接受口头承诺或全国平均值。要求按批次列出：到货总箱数、可验收箱数、扣重/降级箱数、损耗原因。

2. **自己做到货验收试单**：至少连续3批、每批不少于你们单店/中央仓一周用量，按统一标准记录：
   - 到货损耗率 =（到货总重量或箱数 − 验收合格量）÷ 到货总量
   - 同时拆分：运输破损、成熟度超标、霉变/黑心、规格不符、重量短缺
   茶饮用菠萝通常更该看“可切果肉出成率”，而不只是外观损耗率。

3. **合同里写清规格和扣罚**：品种/产地、单果重量区间、成熟度（如糖度、果眼深度）、允许损耗上限、超标扣款或退换货、冷链温度记录。都乐和鑫荣懋都是大型果品供应链企业，但不同区域、不同加工厂和季节差异很大，不能用一个固定损耗率对比。

4. **对比时用同一口径**：都乐和鑫荣懋分别报“到仓价、含税、含运费、验收标准、账期、退换货响应时间”，再结合实测损耗算“合格果肉单位成本”。

**结论：这两家的准确到货损耗率需要你向对应区域销售/经销商索取近期批次数据，并用3批试单验证；没有这批数据前，不建议按某个固定百分比做采购决策。**
