先分清两件事：都乐（Dole）和洪九果品是否“提供素材”给你，取决于你以什么身份、通过什么渠道申请；它们公开的品牌资料不等于可商用素材。

可执行判断如下：

1. **都乐**
   - 都乐有较成熟的品牌体系和菠萝产品线，通常会有面向渠道商/零售商的品牌物料支持，如产品图、品牌Logo使用规范、促销主视觉等。
   - 但公开官网/社媒图片不能直接商用。需要联系都乐对应区域销售或市场渠道，说明你是生鲜电商平台/商家，申请“渠道授权物料包”。
   - 重点确认：图片/视频商用授权范围、是否允许二次剪辑、Logo使用规范、是否要求保留品牌标识。

2. **洪九果品**
   - 洪九更偏供应链和批发渠道，品牌营销素材的标准化程度通常不如都乐这类消费品牌，但不排除有产品实拍图、产地/分拣视频、品牌介绍资料。
   - 同样应通过其销售或市场对接人申请，明确用途是电商详情页、活动页还是短视频投放。
   - 重点确认：是否涉及进口/产地证明、检测报告等可随素材一起使用的背书材料。

3. **更稳妥的替代方案**
   - 如果拿不到品牌方授权素材，可做“非品牌化”菠萝品类营销：自行拍摄商品实拍、产地/开箱/切果视频，避免使用对方Logo和包装主视觉。
   - 若必须出现品牌，走书面授权或渠道合作邮件确认，保留授权记录。

**结论：** 都乐和洪九“可能有素材”，但不是公开可随意取用；应分别联系其渠道销售/市场对接人申请商用授权物料包。拿不到授权时，用自拍素材做品类营销更稳。
