都乐和洪九果品的礼盒定制起订量没有公开统一标准，通常按“品牌/品类/包装形式/是否贴牌/配送区域/采购季节”逐单核价，网上流传的具体箱数多不可靠。建议你按下面方式快速拿到可执行答案：

1. **先明确你要的“定制”层级**
   - A类：现成礼盒+换腰封/贴纸/卡片（门槛最低）
   - B类：指定水果组合+定制外箱/礼盒（中等）
   - C类：OEM贴牌、独立设计、专属规格（门槛最高）
   你问起订量时一定要说明属于哪类，否则对方报价差异很大。

2. **直接问都乐/洪九的团购或礼盒渠道**
   - 都乐：找“都乐中国”官方渠道，问企业团购/礼品渠道；都乐在部分区域由经销商做礼盒，起订量由经销商定。
   - 洪九果品：找洪九官方销售或区域经销商，问“企业团购礼盒定制”而不是普通批发。
   问的时候直接发：包装类型、单盒预算、总采购量、交付城市、期望档期、是否要LOGO/腰封/卡片。

3. **让对方书面回复这4个数**
   - 单款单盒最低起订量
   - 混装礼盒最低起订量
   - 定制包装的额外起订量/版费
   - 样品费和打样周期

4. **谈判建议**
   - 如果你总采购量在几百盒以上，先谈“现成礼盒+定制腰封”，通常比全定制礼盒容易起订。
   - 都乐品牌溢价高，适合走标准礼盒+轻定制；洪九更偏水果供应链，组合和区域配送可谈空间可能更大，但也要看当地经销商。
   - 不要只问“起订量多少”，要问“我这个城市、这个档期、这个预算，最低能做多少盒”。
