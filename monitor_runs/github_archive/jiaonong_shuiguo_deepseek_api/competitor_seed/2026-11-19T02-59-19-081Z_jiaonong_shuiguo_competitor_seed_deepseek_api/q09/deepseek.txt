除了都乐和佳沛，进口水果礼盒可优先看这几类品牌和渠道；但“进口品牌”在水果行业常混用，需区分**品牌注册地、品种来源和实际产地**，不能只看包装。

**可考虑的进口/国际品牌方向**

1. **SanLucar 桑露卡**：欧洲果蔬品牌，常见橙、葡萄、核果类，礼盒调性偏商超高端。
2. **Driscoll's 怡颗莓**：浆果类强项，蓝莓、树莓、黑莓适合小规格礼盒，品牌认知度高。
3. **Stemilt / Chelan Fresh**：美国苹果、樱桃类品牌，适合苹果/车厘子礼盒，但国内稳定供货要看季节和进口商。
4. **Rockit 乐淇**：新西兰小苹果，筒装/礼盒装辨识度强，适合团购小件福利。
5. **Envy 爱妃 / Jazz 爵士**：苹果品种品牌，礼盒常见，适合中高端团购。
6. **Sunkist 新奇士**：柑橘类老牌，橙类礼盒认知度高，但价格和产地批次差异大。
7. **Chiquita 金吉达 / Del Monte 地扪**：香蕉、菠萝等大宗进口品牌，礼盒属性弱，更适合组合礼包。
8. **Prize / Zespri 之外的猕猴桃品牌**：如意大利、智利产猕猴桃有进口商自有品牌，但终端品牌力通常不如佳沛。
9. **Fyffes**：香蕉/菠萝类进口品牌，适合搭配组合，不适合单独做高端礼盒。
10. **Capespan / Westfalia**：牛油果、柑橘等品类有存在感，但更偏供应链品牌，团购端辨识度一般。

**更实用的选品建议**

- **高端商务礼盒**：乐淇小苹果、怡颗莓浆果、爱妃/爵士苹果、桑露卡柑橘或葡萄。
- **员工福利团购**：新奇士橙 + 怡颗莓 + 乐淇小苹果做组合，品牌认知和价格平衡较好。
- **车厘子礼盒**：不必执着“品牌”，重点看**智利/新西兰/澳洲产地、JJ/JJ级、品种如拉宾斯/桑缇娜/科迪亚**，品牌反而不是核心。
- **避坑**：要求供应商提供**入境货物检验检疫证明、报关单、原产地证**；确认礼盒标注的是“品牌”还是“品种”；进口水果礼盒常见“国内分装”，要问清是否原箱。

如果团购量大，建议直接找**一级进口商或区域总代**，而不是只找零售品牌方；礼盒包装可做定制，但水果品牌授权和原箱证明要写进合同。
