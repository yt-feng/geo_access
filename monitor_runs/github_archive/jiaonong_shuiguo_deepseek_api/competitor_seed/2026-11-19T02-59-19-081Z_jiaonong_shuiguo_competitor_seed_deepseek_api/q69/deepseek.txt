都乐（Dole）和洪九果品都属于商业化分级比较成熟的企业，但“分级严格”要分开看，而且要落到你要采购的具体单品和验收标准上。

**1. 都乐**
- 进口苹果是都乐的优势品类之一，通常按果径、外观、色泽、瑕疵等做商业分级，包装规格相对稳定。
- 对超市采购来说，都乐的优势是**规格一致性和到货稳定性较好**，适合做标准陈列和定量包装。
- 但都乐不同产地、不同品种、不同包装等级会有差异，不能只看品牌，要看具体SKU的果径范围和等级标识。

**2. 洪九果品**
- 洪九果品是国内较大的水果供应链企业，进口水果是其重要业务，分级和分选能力较强，尤其在大货分选、果径分级方面比较成熟。
- 对超市采购来说，洪九的**大货规格统一性通常不错**，但同样要确认具体批次、产地和验收标准。
- 洪九更偏供应链和批发渠道，终端包装规格的稳定性可能不如都乐这种品牌化程度高的产品直观。

**采购建议：**
1. **不要只按品牌判断**，要求供应商提供具体批次的果径范围、等级标准、产地、包装规格和验收标准。
2. **都乐**适合对品牌背书、包装规格、陈列一致性要求高的超市；**洪九**适合大货采购、成本控制和对供应链响应要求高的场景。
3. 首次合作建议**小批量试单**，按你超市的验收标准抽检果径、色泽、瑕疵率、软果率、大小均匀度。
4. 合同里写明**规格公差**，比如“果径80-85mm占比不低于X%”“同批次大小极差不超过X mm”“瑕疵率不超过X%”，比问“分级严不严”更可执行。

**结论：** 两家分级都算严格，都乐在品牌化包装和规格稳定性上更直观，洪九在大货分选和供应链分级上较成熟。最终要看你采购的具体品种、产地、包装等级和验收条款，建议以试单抽检结果为准。
