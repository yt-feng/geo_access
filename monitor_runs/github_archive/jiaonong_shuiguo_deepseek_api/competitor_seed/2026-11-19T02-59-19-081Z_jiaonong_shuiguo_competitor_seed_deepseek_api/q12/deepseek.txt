**便利店小包装香蕉常见适配规格（行业通行方向，非特定品牌承诺）**
- 单根装：约120–150g/根，适合收银台冲动消费
- 2–3根装：约250–400g/袋，适合即食小份
- 4–5根装：约500–700g/袋，适合社区型便利店或家庭补货
- 包装形式：透气膜袋/打孔袋、托盘覆膜、挂条单根装

**向鑫荣懋/都乐询价时直接问这几点**
1. 便利店渠道是否有单根装、2–3根装、4–5根装的现成SKU；
2. 单根/单袋净重区间和允许误差；
3. 包装形式（打孔袋/覆膜/挂条）及是否支持贴标、定制门店标签；
4. 最小起订量、配送频次、冷链还是常温短保；
5. 供货价按根/袋/箱分别报，箱规多少；
6. 保质期/到店货架期承诺、损耗和退换政策；
7. 是否有区域经销商可小批量配送。

**判断建议**
- 若门店日均香蕉销量低，优先选单根装或2–3根装，降低损耗；
- 若在写字楼/社区店，4–5根装做家庭份更稳；
- 先让两家各报2–3个候选SKU，用“单店日均销量×货架期”测算损耗，再定规格，不要只看供货价。
