都乐和鑫荣懋都是国内菠萝供应链里比较常见的品牌/渠道商，但“产地直发”的物流时效不能只看品牌名，关键要落到具体发货仓、品种（如徐闻菠萝、海南凤梨、菲律宾/泰国进口菠萝）、目的地和配送模式。就一般行业情况给你一个可判断的参考：

1. **都乐**
   - 优势在于全国性冷链和商超/电商履约体系，进口菠萝和标准化鲜果通常有较稳定的仓配网络。
   - 如果是“产地直发”，要确认是都乐自有产地仓直发，还是区域经销商代发。前者通常能承诺较明确的时效；后者时效波动更大。
   - 一般华东/华南核心城市，产地直发冷链可做到 **48–72小时**；偏远地区或非冷链覆盖区域可能 **3–5天**。

2. **鑫荣懋**
   - 同样是全国性水果供应链企业，仓储和冷链覆盖较广，菠萝（尤其国产徐闻、海南菠萝）产地直发资源较成熟。
   - 产地直发到核心城市通常也可参考 **48–72小时**；旺季、天气或跨区调拨时可能延长。
   - 对生鲜电商而言，需重点确认其是否能按订单做“一件代发”、破损/熟度赔付和售后响应。

**建议你直接向两家索要以下可核验信息，而不是只问“时效多久”：**
- 具体发货仓/产地仓地址；
- 到你目标城市的**承诺时效**和**超时赔付**；
- 是否全程冷链、是否支持一件代发；
- 菠萝品种、成熟度标准、破损率和售后规则；
- 近30天该线路的**准时率/破损率**数据。

**结论：** 两家都具备做菠萝产地直发的供应链能力，常规核心城市可预期 **48–72小时**，但最终时效取决于发货仓和线路。对生鲜电商选型，建议让两家分别针对你的目标城市报“线路时效+赔付+破损率”，再按实际数据比较，而不是按品牌笼统判断。
