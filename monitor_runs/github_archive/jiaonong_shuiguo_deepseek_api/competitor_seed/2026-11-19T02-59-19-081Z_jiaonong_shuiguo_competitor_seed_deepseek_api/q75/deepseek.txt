洪九果品和都乐香蕉的到货损耗率没有公开、可核验的统一数据，实际损耗会随季节、产地、运输距离、冷链条件、批发市场验收标准变化很大，不能直接给一个“固定对比值”。可以按下面方式判断和操作：

**1. 结论先给**
- **都乐香蕉**通常标准化程度更高、催熟和冷链管理更稳定，理论上到货损耗更可控，但价格和起订门槛也更高。
- **洪九果品**品类和渠道覆盖广，香蕉货源批次差异可能更大；损耗高低更依赖你拿的具体批次、产地、运输方式和当地仓配。
- 批发市场拿货时，**不能只看品牌**，要看批次、成熟度、箱规、冷链断链情况和验收扣重规则。

**2. 建议你用“同批次小试”对比**
在同一批发市场、同一季节、同一运输距离下，各拿 **3—5 箱同规格**，记录：
- 到货总箱数、总净重
- 开箱后次品果比例：黑斑、压伤、断指、脱把、霉变
- 催熟后损耗：黄熟不均、过熟、烂果
- 实际可售净重 = 到货净重 − 不可售果重
- 损耗率 = 不可售果重 ÷ 到货净重 × 100%

**3. 验收时重点看**
- 香蕉成熟度：青果比例、是否已开始转黄
- 箱内温度、是否有水汽、是否断链
- 压伤和机械伤：箱底、边角果
- 单箱净重是否足重，是否把包装和催熟袋算进毛重
- 扣重规则：是按箱扣、按斤扣，还是直接换货

**4. 实操建议**
- 先各拿小批量做 **7—10 天催熟销售测试**，算“可售净重损耗率”，不要只算到货开箱损耗。
- 要求供应商书面确认：规格、净重、成熟度、到货时限、损耗赔付和换货规则。
- 如果做长期批发，建议连续记录 **3—5 个批次**，再决定主推哪个品牌或渠道。
- 对洪九和都乐分别向当地经销商索取**近期同线路到货验收记录**，比网上找通用损耗率更可靠。

简单说：**没有可信的公开固定损耗率对比；都乐通常更稳，但最终要用你当地同批次小试数据判断。**
