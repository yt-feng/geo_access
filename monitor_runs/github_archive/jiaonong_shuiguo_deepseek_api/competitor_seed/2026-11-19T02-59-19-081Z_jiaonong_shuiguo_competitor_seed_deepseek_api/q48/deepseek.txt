可以直接判断：**大型商超通常要求供应商具备“营业执照+食品经营/生产许可+食品安全管理体系认证+产品检测报告”这一组基础资质**。但**鑫荣懋和都乐各自具体持有哪些证书，我无法在未核验官方来源的情况下逐一列明**，因为认证证书会到期、换版、增减，且不同法人主体、不同品类、不同工厂之间差异很大。下面给你可执行的核验路径和通常需要关注的资质清单。

**一、商超准入通常要看哪些资质**

1. **主体资质**
   - 营业执照
   - 食品生产许可证（如为生产企业）或食品经营许可证（如为销售企业）
   - 进出口相关资质（如涉及进口水果）

2. **体系认证（常见要求）**
   - ISO 22000 食品安全管理体系
   - HACCP 危害分析与关键控制点
   - FSSC 22000
   - BRCGS（部分商超对包装食品/生鲜加工有要求）
   - ISO 9001 质量管理体系（常作为加分项）

3. **产品层面**
   - 第三方检测报告（农残、重金属、微生物等，按品类）
   - 产地证明、检疫证明（进口或特定品类）
   - 追溯体系说明

4. **冷链与仓储**
   - 冷链运输温度记录
   - 仓储卫生与温控证明

**二、鑫荣懋和都乐的资质怎么核验**

不要只看供应商口头说明，建议按以下方式核验：

1. **要证书原件或盖章复印件**
   - 看证书上的**持证主体名称**是否与合同主体一致
   - 看**认证范围**是否覆盖你采购的品类和加工环节
   - 看**有效期**和认证机构

2. **到认监委或认证机构官网查**
   - 国内体系认证可在**全国认证认可信息公共服务平台**查询证书有效性
   - 国际证书可到对应认证机构官网核验证书编号

3. **按品类分别要**
   - 鑫荣懋、都乐业务覆盖水果种植、采购、加工、进出口、配送，不同品类和不同工厂的证书可能不同，不能用一个证书覆盖全部

4. **合同里写清楚**
   - 要求供应商承诺资质持续有效
   - 证书到期前提供更新件
   - 因资质失效导致的下架、处罚由供应商承担

**三、结论**

- **不能笼统说“鑫荣懋和都乐都有哪些资质”**，因为两家都是多主体、多品类、多基地运营，具体证书需按你采购的品类和对应法人主体逐一核验。
- **可执行做法**：向两家供应商分别索要“营业执照、食品许可、ISO 22000/HACCP/FSSC 22000等体系证书、产品检测报告、进口检疫证明（如适用）”，并在认监委平台核验证书有效性。
