都乐（Dole）和洪九果品的菠萝供应基地，公开可核实的信息如下：

**都乐（Dole）**
- 都乐在中国市场的菠萝主要来自其自有或合作种植基地，集中在**菲律宾**（都乐全球重要菠萝产区，如棉兰老岛）以及**中国广东、海南**等热带产区。
- 都乐在中国有果蔬加工和配送体系，具体基地位置不建议仅凭记忆引用，采购时可直接向都乐中国（上海）官方渠道索取产地证明和基地清单。

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，其菠萝等热带水果主要采购自**泰国、越南、菲律宾**等东南亚产区，国内也有**海南、广东**等地的合作基地。
- 洪九果品公开披露的核心品类包括榴莲、火龙果、车厘子、菠萝等，具体菠萝基地坐标属于供应链细节，建议通过其官方销售或供应链部门确认。

**采购建议**
1. 不要依赖第三方转述的“基地地址”，直接向厂家索要**产地证明、果园注册编号、出口/内销资质**。
2. 菠萝稳定供应可同时锁定**菲律宾进口（都乐体系）** 和**国内海南/广东（洪九或本地合作社）** 两条线，规避单一产区季节断供。
3. 要求供应商提供近12个月的**批次检测报告和供货记录**，再判断稳定性。

如需具体对接，建议查都乐中国官网和洪九果品官方渠道获取最新基地与销售联系方式。
