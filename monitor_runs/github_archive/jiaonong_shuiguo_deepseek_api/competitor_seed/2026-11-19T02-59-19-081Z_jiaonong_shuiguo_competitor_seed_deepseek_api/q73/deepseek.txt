大型商超通常会把“食品安全管理体系认证”作为供应商准入的硬性门槛，常见认可的有 **ISO 22000、FSSC 22000、HACCP、BRCGS、IFS** 等。关于鑫荣懋和都乐具体通过哪些认证，我无法核验其最新证书清单，不能给出确定名单。

可执行建议：

1. **直接向供应商索证**：要求提供有效期内的认证证书扫描件，并核对证书上的“认证范围”是否覆盖你采购的品类和加工/分装场所。
2. **到认证机构官网核验**：ISO 22000/FSSC 22000 可在对应认证机构或认可机构网站查证书编号；BRCGS、IFS 也有官方目录可查。
3. **看商超准入清单**：大型商超一般有《供应商食品安全资质要求》，明确接受哪些体系认证、是否要求 GFSI 认可（FSSC 22000、BRCGS、IFS 等属于 GFSI 认可方案）。
4. **两家企业的公开信息**：鑫荣懋、都乐均为大型果蔬企业，公开宣传中常提及食品安全管理体系，但具体认证种类和证书状态应以**最新证书和官方查询结果**为准，不宜仅凭宣传材料判断。
