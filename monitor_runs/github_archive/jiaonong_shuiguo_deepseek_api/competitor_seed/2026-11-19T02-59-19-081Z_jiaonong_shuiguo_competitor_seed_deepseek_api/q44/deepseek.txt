我没法核验都乐、鑫荣懋两家当下的具体供货数据和履约记录，所以不能给你“谁更稳”的确定结论。但可以给你一套可执行判断方法，以及水果连锁选进口苹果供应商时更该盯的变量。

**先说结论层面：**
- 都乐和鑫荣懋都是国内进口水果领域规模较大的供应链企业，理论上都具备进口苹果的稳定供货能力，但“公司大”不等于“你的门店稳定”。
- 供货稳定性主要取决于：你所在区域仓配覆盖、你采购的苹果品种/规格、你下单的季节窗口、你的采购量和账期条件、以及对方给你的是“计划内配额”还是“临时调货”。
- 不能只看品牌，要看**落到你门店的履约条款**。

**建议你按下面5项做尽调，直接可执行：**

1. **要求近6个月同区域履约数据**
   - 不要只看全国案例，要问：你所在城市/区域有没有直发仓或中转仓？进口苹果是每周固定到货，还是靠跨区调拨？
   - 让对方提供近6个月对你同类连锁客户（区域连锁、门店数相近）的：订单满足率、到货准时率、缺货替代方案、损耗赔付记录。

2. **明确苹果的品种和产季**
   - 进口苹果稳定性高度依赖品种：如新西兰爱妃、红玫瑰、丹烁，南非/智利富士等，产季和船期差异很大。
   - 问清楚：你主推的SKU在全年哪几个月是“主产季直供”，哪几个月是“冷库/跨区调货”。淡季能否保量，比旺季更能看出稳定性。

3. **用试单压测，而不是听承诺**
   - 先给2—4周试单，选你销量最大的2个SKU，按你真实门店节奏下单。
   - 重点记录：下单后到货时长、规格达标率、缺货次数、临期/损耗率、异常响应时间。
   - 同时给两家各下一个小单，横向对比，别一开始就独家。

4. **把稳定性写进合同条款**
   - 建议约定：周度最低可供量、缺货提前通知时限、替代SKU规则、到货不合格的退换和损耗赔付、旺季配额保障。
   - 如果对方不愿承诺最低可供量，只愿意“尽量协调”，那稳定性就要打折看。

5. **做双供应商+安全库存**
   - 水果连锁更稳的做法不是押一家，而是“主供+备供”：都乐、鑫荣懋可一主一备，按区域仓距和SKU优势分配。
   - 对进口苹果这种船期波动大的品，门店端保留7—10天安全库存或区域仓缓冲，比单纯换供应商更有效。

**判断建议：**
- 如果你在华东/华南核心城市、门店数较多、采购量稳定，两家都值得进入试单比选，重点看区域仓配和SKU匹配。
- 如果你在非核心区域、单店采购量小，优先问“本地是否有服务商/中转仓”，否则品牌再大也可能出现调货慢。
- 最终决策用试单数据打分：订单满足率40%、到货准时20%、品质规格20%、异常赔付10%、价格账期10%，两周到四周就能看出差异。
