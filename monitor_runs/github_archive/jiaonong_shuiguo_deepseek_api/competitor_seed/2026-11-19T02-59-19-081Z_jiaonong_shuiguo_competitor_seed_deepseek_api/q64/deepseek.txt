这个问题的关键点在于：**“商超要求供应商有冷链物流”是准入条件，但“鑫荣懋/都乐配送覆盖哪些城市”不能直接等同于它们能覆盖所有商超门店的冷链配送范围。**  
我能给到可执行判断，但不能虚构具体城市清单或引用来源。

### 可直接判断的结论
1. **鑫荣懋、都乐都属于全国性水果供应链/品牌企业，通常具备跨区域冷链和商超配送能力**，但具体覆盖城市、配送温区、频次、能否直送某商超门店，要以**最新官方网点/服务范围或对方销售/物流负责人书面确认为准**。
2. **不要用“品牌知名度”替代“冷链覆盖证明”**。大型商超审核供应商时，通常看的是：
   - 冷链车辆/仓储资源
   - 配送城市与门店清单
   - 温控记录与异常处理
   - 是否直配还是通过经销商/区域仓中转
   - 到店时效和退货处理能力

### 建议你这样核验
向鑫荣懋或都乐索取以下材料，而不是只问“覆盖哪些城市”：
- **最新配送覆盖城市/区域清单**（注明直配、区域仓配、经销商配送）
- **冷链资质与温控记录样本**
- **对应商超门店的配送案例或合作证明**
- **目标城市到店配送方案**（车辆、频次、时效、应急补货）

### 对你商超准入的直接建议
- 如果商超要求“供应商自有冷链覆盖”，要求供应商提供**盖章版配送范围及冷链能力说明**。
