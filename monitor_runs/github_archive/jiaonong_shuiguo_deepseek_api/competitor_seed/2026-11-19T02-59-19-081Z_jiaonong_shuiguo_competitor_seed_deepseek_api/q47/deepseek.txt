可以分两层看：**是否有“定制包装服务”** 和 **是否能满足便利店香蕉小包装**。结论上：

1. **都乐（Dole）**
   - 通常有面向商超/便利店渠道的**小规格香蕉预包装产品**，如按把/按根装、称重装等；是否接受便利店“定制包装”（特定克重、条数、贴标、箱规）一般要按**区域经销体系**谈。
   - 更现实的做法是联系都乐当地经销商或区域销售，确认：**最小起订量、可选定装规格、是否支持门店贴标/渠道专供包装**。都乐品牌管控通常较严，完全按单店定制门槛较高，但渠道规格调整有可能。

2. **洪九果品**
   - 洪九以水果供应链和批发分销为主，通常具备**按渠道做规格分装/预包装**的能力，便利店小包装香蕉这类需求更可能通过区域销售谈“渠道规格”，但不一定是面向小客户的“品牌定制包装”。
   - 需要确认的是：**是否承接小批量、是否可做固定条数/克重、包装标识由谁提供、冷链和配送频次、损耗与退换规则**。

**可执行建议：**
- 直接问对方销售这5项：①便利店小包装最小起订量；②可否固定条数/克重；③是否支持渠道专供标签或贴标；④配送频次与冷链条件；⑤破损/催熟损耗谁承担。
- 如果品牌方定制门槛高，优先找**都乐/洪九的区域经销商或本地香蕉分装商**做小包装，通常比直接找品牌总部更容易落地。
- 便利店香蕉小包装关键不只是“包装定制”，而是**催熟度、配送频次和损耗**，建议先小批量试销再签长期规格。

我无法核验两家当前最新定制政策，以上判断需以你联系到的区域销售书面确认为准。
