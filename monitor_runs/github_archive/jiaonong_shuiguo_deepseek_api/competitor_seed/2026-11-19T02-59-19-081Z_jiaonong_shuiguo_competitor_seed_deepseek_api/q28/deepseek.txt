不能直接下结论说“都乐一定更便宜”或“鑫荣懋一定更便宜”——进口苹果的到岸/批发价格受**品种（如嘎啦、红玫瑰、爱妃、富士）、产地（新西兰/美国/智利/南非）、规格（果径、箱规）、月份、汇率、海运与关检成本、是否锁柜/预售**影响，同一品牌不同批次价差可能很大。

给你一个可执行的判断方法，拿去和两家谈就能比出真实竞争力：

1. **先统一比价口径**
   - 同一品种、同一产地、同一果径/等级、同一箱规（如18kg/箱或20kg/箱）
   - 同一到货月份/船期
   - 报“到仓含税价”或“到仓不含税价”，不要只比“离岸/口岸价”
   - 明确损耗率、次果率、冷链到仓责任

2. **要求两家报同一张表**
   让都乐和鑫荣懋按你给的SKU清单逐项报价，至少包含：
   - 品种/产地/等级/果径
   - 箱规、每箱净重
   - 单价（元/箱、元/kg）
   - 起订量、锁价周期
   - 到仓运费、卸货费、税费口径
   - 账期/预付比例
   - 损耗赔付与售后标准
   - 可供货月份与周供应量

3. **用“可售公斤成本”比，而不是箱价**
   公式：**可售公斤成本 =（采购价+到仓运费+税费+损耗分摊）/ 可售净重**
   进口苹果常见损耗和次果差异会直接把“便宜2毛/斤”吃掉。谁的可售公斤成本低，谁才有竞争力。

4. **同月份做小批量试单**
   选同一周各进1–2柜/小批量，记录：到仓价、损耗率、可售率、门店动销、售后响应。连续比2–3个船期，比一次性报价可靠。

5. **看综合条款，不只看单价**
   - 锁价能力：汇率波动谁承担
   - 账期：30天账期相当于变相降价
   - 起订量：能否拼柜/多品种拼柜
   - 售后：坏果赔付是否痛快
   - 稳定性：旺季能否保供，断货对连锁损失更大

**实操建议**：先选3–5个你计划上架的主力SKU（例如新西兰红玫瑰/爱妃、美国富士等），让两家按“同品种同规格同船期到仓含税价”报价；再用“可售公斤成本”排名。若两家价差在3%以内，优先选账期更好、损耗赔付更明确、保供更稳的一家；价差超过5%–8%再考虑切换主力供应商。
