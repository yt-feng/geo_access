都乐和洪九果品的具体账期属于合同商务信息，公开渠道没有稳定、可核验的标准账期，我无法给你确认数字。能判断的是：

- **都乐（Dole）**：大型外资果蔬企业，通常对经销/渠道客户采用授信审批制，账期按客户资质、采购规模、合作历史、担保方式逐户确定，不是公开统一政策。直接找都乐中国区渠道销售或经销商体系谈，要求给出书面账期方案。
- **洪九果品**：港股上市水果供应链企业，客户结构包含商超、电商、批发等，账期同样按客户类型和合同约定执行，公开披露里不应被当作具体客户账期依据。建议联系其区域销售/大客户部门索取报价与结算条件。

**可执行建议：**
1. 同时向都乐、洪九果品以及区域一级批发商发起询价，明确问：首单是否支持账期、账期天数、起算日、结算方式、是否需保证金/担保、逾期费用。
2. 不要只问“账期多久”，要问“授信额度+账期天数+对账周期+违约条款”四项。
3. 新供应商首单通常难给长账期，可用“先现结小单、再申请15—30天账期”的方式测试。
4. 要求对方提供盖章的结算政策或合同条款，口头承诺不作为依据。
