## 能确认的情况

**都乐**
- 都乐有较成熟的全球香蕉品控体系（源于其自有种植和供应链），对外有品牌分级惯例，比如按"规格/梳数/果指长度/外观"分档，也常见"都乐金标/普通"这类市场说法。
- 但**没有公开的企业标准文本可查**，你看到的更多是其营销分级或行业通行的分级描述，不是可引用的标准文件。

**洪九果品**
- 洪九是水果分销龙头，香蕉是其核心品类之一，内部一定有采购和品控分级要求。
- 同样**没有公开的企业标准全文**。它更多执行的是国标/行标加内部验收细则。

## 可参考的公开标准（比企业标准更适合落地）

企业标准多为内部文件，你真正能拿来用的其实是这些公开标准：

- **GB/T 9827《香蕉》** — 国家推荐标准，含等级（优等/一等/合格）、果指、缺陷等指标
- **NY/T 517《无公害食品 香蕉》** 等农业行业标准
- **主要出口国的分级惯例**：如厄瓜多尔、菲律宾香蕉按"果指长度、梳重、成熟度、机械伤"分级

## 给你的实操建议

1. **不要指望拿到都乐/洪九的内部标准**，这类文件基本不外流；可以直接联系其采购或品控部门洽谈时索取"验收标准"，但通常只在合作后提供。
2. **连锁店自建分级标准**，建议以 GB/T 9827 为骨架，结合自身售卖场景（散卖/礼盒/熟果）设三档：
   - 精品级：果指长度达标、无疤痕黑斑、梳形整齐
   - 标准级：轻微外观瑕疵、成熟度统一
   - 处理级：可做熟果/切果/促销
3. 关键可量化指标建议固定下来：**果指长度(cm)、每梳果指数、单梳重量、成熟度(色卡1-7)、允许缺陷比例**。
