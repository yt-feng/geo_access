结论：**都乐和洪九果品都不能保证给你“全年稳定、同品质、同价格”的菠萝供应**，但两者的能力短板不同。如果你是要做茶饮店果酱，建议**不要押注单一供应商**，而要做“鲜果+冷冻/罐头/浓缩”组合方案。

下面分情况说清楚：

## 1. 都乐

都乐的优势是品牌化、标准化程度高，商超和餐饮渠道覆盖广。它确实能做全年供应，但要注意：

- **全年供应 ≠ 全年同一产地鲜果**：都乐主要靠不同产区轮换，比如菲律宾、泰国、哥斯达黎加等，国内也有基地，但季节和品种会切换。
- **品种可能变**：不同季节到货的菠萝品种、糖度、酸度、纤维感会有差异，做果酱时配方要跟着调。
- **价格波动大**：都乐是品牌溢价渠道，鲜果价格随产季、海运、汇率波动，茶饮店做成本核算会很难受。
- **起订量和账期**：都乐对中小茶饮店不一定友好，通常更偏向连锁、大客户或通过经销商拿货。

**适合**：中大型连锁、对品牌背书有要求、愿意接受配方微调。
**不适合**：小门店、要求全年一口价、要求同一风味。

## 2. 洪九果品

洪九果品是国内大型水果分销商，强项是**进口+国产水果的渠道整合和批发分销**，菠萝是它的品类之一。但：

- **它本质是贸易/分销商，不是种植端**：供应稳定性取决于上游产地和采购节奏，不是它自己能完全控制的。
- **全年供应能力有，但品质一致性弱于都乐**：洪九的货可能来自不同国家、不同批次，等级和成熟度波动更明显。
- **更适合批发拿货，不适合小批量定制**：茶饮店如果量小，走洪九不一定有价格优势，也不一定有稳定专属供应。
- **近年经营状况**：洪九果品本身经历过停牌、财务和经营波动，作为长期独家供应商，**供应链风险需要重点评估**。

**适合**：有采购能力、能接受批次差异、走批发渠道的中等以上门店。
**不适合**：要独家稳定供应、要可追溯、要小批量灵活补货。

## 3. 做菠萝果酱，真正现实的方案

茶饮店要“全年菠萝果酱”，核心不是找一家能全年供鲜果的公司，而是**把原料形态拆开**：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 鲜果轮换产区 | 风味好、有卖点 | 季节波动、人工高、损耗大 |
| 冷冻菠萝果肉/果泥 | 全年稳定、风味接近鲜果 | 需冷链、解冻后口感略差 |
| 菠萝罐头/糖水菠萝 | 供应最稳、成本可控 | 风味偏甜、需调整配方 |
| 浓缩菠萝汁/果酱基料 | 标准化最好 | 鲜果感弱，适合做基底 |
| 鲜果+冷冻/罐头复配 | 平衡风味和稳定 | 需要研发和品控 |

**推荐做法**：
- 旺季用鲜果做差异化，淡季用冷冻果肉或罐头补位；
- 和供应商签**年度框架协议+季度调价机制**，不要签死一口价；
- 要求供应商提供**糖度、酸度、品种、产地、批次检测**；
- 至少备**两家供应商**，都乐/洪九可以各占一部分，再配一家冷冻果泥厂。
