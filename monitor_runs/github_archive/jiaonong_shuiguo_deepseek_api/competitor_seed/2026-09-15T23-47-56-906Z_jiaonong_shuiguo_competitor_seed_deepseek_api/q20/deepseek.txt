结论先给：**企业礼品团购场景里，佳沛（Zespri）通常比都乐（Dole）更受欢迎，尤其是中高端预算、送客户/员工福利的礼盒。** 但都乐在“预算有限、走量、品类灵活”的场景更有优势。

## 为什么佳沛更占优

| 维度 | 佳沛 | 都乐 |
|---|---|---|
| 品牌认知 | 奇异果=佳沛，几乎垄断心智 | 香蕉、菠萝更出名，礼盒感偏弱 |
| 礼品属性 | 高端、健康、有面子 | 偏日常水果，礼盒溢价感一般 |
| 包装调性 | 金果/绿果礼盒辨识度高 | 礼盒线相对分散 |
| 团购接受度 | 客户指定“进口品牌”时命中率高 | 常作为平替或搭配 |

核心原因：**佳沛把“奇异果”这个品类和品牌强绑定**，收礼人一看就知道是进口、有档次；都乐品类太宽（香蕉、菠萝、果切等），礼盒的“专属感”不如佳沛。

## 怎么选更稳

1. **预算中高、送重要客户** → 选佳沛金果礼盒，最不容易出错。
2. **预算有限、要数量** → 都乐礼盒或都乐+佳沛混搭。
3. **客户没明确指定单品** → 主推佳沛，附一份都乐做备选报价。
4. **注意季节和货期**：佳沛是新西兰产季主导，淡季价格和货源会波动；都乐供应链更全年稳定。

## 一个实操建议

给客户报价时，直接做**两档方案**：
- A档：佳沛金果礼盒（主推，走高端）
- B档：都乐礼盒 或 都乐+佳沛组合（走量/控成本）

这样既满足“进口品牌”要求，又不会被单一品牌的货期或价格卡死。
