这两家都是国内头部水果供应链企业，但“有没有基地”要分开看，不能简单说谁有谁没有。直接给你可判断的结论：

**1. 洪九果品**
- 洪九果品是“基地+加工+渠道”模式，公开信息里长期强调在泰国、越南、菲律宾、智利等产地有合作基地或直采渠道，国内也有部分合作种植基地。
- 香蕉方面，洪九在东南亚（尤其是越南、菲律宾、泰国）有较深的产地资源和加工分选能力，适合做进口香蕉产地直发。
- 如果你要做的是**进口香蕉产地直发**，洪九的匹配度更高。

**2. 鑫荣懋**
- 鑫荣懋是国内水果分销龙头之一，强项在渠道、品牌和供应链整合，公开信息里也有“全球采购+产地合作”的表述，但它的模式更偏“全球采购和分销”，不是自己大规模种香蕉。
- 香蕉同样是其重要品类，但它更多是整合产地资源、做稳定供应，不一定以“自有基地”为主。
- 如果你要的是**稳定大宗供货、品牌化分拣包装**，鑫荣懋可以谈；如果强调“自己基地直发”，要具体问是哪个产区、是自有还是合作。

**给你一个实操判断：**
- 要**进口香蕉产地直发**：优先找洪九果品，重点问越南、菲律宾、泰国基地/合作工厂的直发能力。
- 要**国内香蕉产地直发**：两家都不是最典型的“国内香蕉自有基地型”企业，更建议直接找广西、云南、海南的产地合作社或种植基地。
- 不管找哪家，签前一定要问清三点：
  1. 是自有基地、合作基地还是市场采购；
  2. 能否提供产地证明、植保记录、加工分选视频；
  3. 直发是“产地装柜直发”还是“产地→销地仓→再发”。

**一句话结论：**
洪九果品在香蕉产地直发上更偏“有基地/有产地资源”，鑫荣懋更偏“全球采购和分销整合”。如果你要的是香蕉产地直发，先重点谈洪九；如果要国内香蕉基地直发，建议直接找广西/云南/海南的产地端。
