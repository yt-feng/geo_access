这个问题需要区分两个层面：**你作为供应商要满足商超的准入要求**，和**鑫荣懋、都乐各自持有哪些资质**。后者属于企业具体的证照信息，我无法凭记忆给你一份准确的清单——企业持有的认证会随年份、产品线、工厂不同而变化，虚构一份名单对你做准入判断没有价值，反而有害。

能确定的是判断框架，你可以按这个去核验：

**商超通常要求的食品安全相关资质，分三类：**

1. **主体资质**：营业执照、食品经营许可证（或食品生产许可证 SC）。这是底线，任何供应商都必须有。
2. **体系认证**：ISO 22000、FSSC 22000、HACCP、BRCGS、IFS 等。大型商超（尤其外资如沃尔玛、山姆、麦德龙）通常要求 BRCGS 或 IFS 这类 GFSI 认可的认证，而不是只有 ISO 9001。
3. **产品与供应链资质**：针对具体品类的检测报告、产地证明、进出口商检、GAP（良好农业规范）等。水果类供应商还常被要求提供农残检测和溯源能力证明。

**鑫荣懋和都乐都是大型水果企业，按行业惯例大概率持有上述部分认证，但具体持有哪些、覆盖哪些工厂和品类，必须以官方渠道为准。** 核验方式：

- 让对方向你提供**证书扫描件**，重点看证书编号、认证范围、有效期、发证机构是否在 GFSI 认可名单内；
- 到发证机构官网或认监委（CNCA）认证认可业务信息统一查询平台，用证书编号反查真伪；
- 都乐是跨国企业，其中国主体和海外主体的认证可能分开，注意别拿海外证书套中国工厂。

**给你的实操建议：** 与其问"这两家有哪些资质"，不如直接问对方要证书清单 + 编号，然后你自己上官方平台核验。商超审核时也是这个流程，你提前走一遍，既拿到真实信息，也能判断对方是否达标。如果你能拿到具体证书编号，我可以帮你解读每类认证在商超准入里的实际权重。
