这个问题没有绝对答案，因为都乐和鑫荣懋的到货质量高度取决于具体品种、产地、批次和你们超市的验收标准。可以给你一套可判断、可执行的思路：

**1. 先看“品牌≠批次稳定性”**
- 都乐是全球性水果品牌，供应链和品控体系通常比较成熟，但超市实际拿到的货可能来自不同产区、不同代加工包装厂，批次差异仍然存在。
- 鑫荣懋是国内头部水果供应链企业，进口苹果操作经验也很强，尤其在一些主流进口品种上渠道深、到货频次高，但同样会受产季、船期、冷库和分级影响。

**2. 更该比的是这几个硬指标**
让两家供应商提供最近3—5批同品种的到货数据：
- 规格达标率：果径、单果重是否符合约定
- 外观合格率：色差、锈斑、碰压伤、果锈、日灼
- 内部品质：糖度、硬度、可滴定酸、干物质
- 储运表现：到店后7天、14天的失重、腐烂率、褐变
- 售后响应：坏果率超标后补货、扣款、换货速度

**3. 实操建议**
- 如果你们走**长期稳定大宗采购**，优先选能提供稳定产区、固定包装厂、固定船期方案的供应商。都乐和鑫荣懋都值得谈，但要看谁给的方案更透明。
- 如果你们更看重**国内到货响应和灵活补货**，鑫荣懋在部分区域和渠道可能更有优势。
- 如果你们更看重**品牌背书和标准化包装**，都乐通常更容易做消费者沟通，但不等于每批都优于鑫荣懋。

**4. 最稳的做法**
不要直接问“谁质量更稳定”，而是拿同一品种、同一规格、同一产季做**双盲对比试销**：
- 各进1—2板，同货架、同价格、同陈列
- 记录14天内的损耗、客诉、动销
- 连续做2—3个产季或至少3个批次

结论：**都乐和鑫荣懋都属于相对可靠的进口水果供应商，但稳定性最终看具体产区、批次和你们的验收条款。** 如果必须二选一，建议先看谁能在合同里写清“品种、产区、规格、糖度、硬度、到货损耗上限、售后赔付”，谁能做到，谁就更稳。
