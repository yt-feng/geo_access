损耗率属于企业内部经营数据，公开渠道没有洪九果品和都乐香蕉按品类披露的到货损耗率，所以没法给出两个准确的对比数字。直接说“XX% vs XX%”的基本都是编的。

能确定的是两边模式差异很大，这会直接影响你实际承担的损耗：

**都乐（Dole）**
- 品牌方/进口商主导，香蕉多在产地或催熟中心做标准化处理，到批发市场时规格、成熟度相对统一。
- 通常按箱/按件计价，等级和成熟度分得细，你拿到的货“货不对板”的概率低。
- 品牌方对渠道和储存有要求，如果按它的条件走，损耗主要来自你自己的催熟和周转，而不是到货环节。

**洪九果品**
- 是国内水果分销商，做的是多品类、多产地的集采分销，香蕉只是其中一块。
- 货来自不同产地和批次，同批货内部一致性不如都乐，到货损耗更依赖当批货的产地、运输和仓储情况。
- 走的是“性价比+规模”路线，价格通常更有空间，但你需要自己有分拣、催熟和快周转的能力。

**对你拿货的实际建议：**
1. 别看平均值，看你自己那批货。损耗率跟产地、季节、运输距离、冷链、你拿货后的存放条件强相关，同一品牌不同批次都能差很多。
2. 第一次合作先小批量试，记录三个数：到货时已坏/软果比例、催熟后报废比例、最终可售比例。这才是你的真实损耗。
3. 谈判时把损耗写进条款：约定到货验收标准、坏果赔付或补货比例，比事后扯损耗率有用得多。
4. 如果你没有自己的催熟和快销渠道，都乐的稳定性更省心；如果你有分拣和周转能力、追求毛利，洪九这类分销货源空间更大，但损耗风险要自己扛。
