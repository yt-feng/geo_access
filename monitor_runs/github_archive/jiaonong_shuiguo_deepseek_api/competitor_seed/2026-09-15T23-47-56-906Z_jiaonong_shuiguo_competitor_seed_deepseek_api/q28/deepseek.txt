直接给结论：**不能一概而论，要按“单证 + 到货月份 + 规格 + 结算账期”四个条件拉同口径报价来比。**  
但从水果连锁通常的采购经验看：

- **鑫荣懋**：在进口水果供应链里通常更强，尤其南美、智利、新西兰等产区资源和港口分仓能力较深，**大盘走量、长期稳定供货的裸价往往更有竞争力**。
- **都乐**：品牌溢价、终端包装和消费者认知更强，适合做**引流款、礼盒款、门店品牌背书**，但同规格下**裸价通常不一定最低**。
- **如果你们是连锁门店，追求毛利和稳定供应**：先重点谈鑫荣懋，通常更容易拿到有竞争力的到仓价。
- **如果你们要做高端陈列、节日礼盒、线上爆款**：都乐的品牌价值可能能抵消一部分进货差价。

但真正判断谁便宜，不能只看品牌，要看这 4 个关键点：

1. **同规格同等级**
   - 比如：80#、88#、100#，还是 72#；单层还是双层；净重还是毛重。
   - 进口苹果常见规格差异很大，不锁规格比价没有意义。

2. **同到货港/到仓地**
   - 上海、广州、深圳、青岛、郑州、北京到仓价完全不同。
   - 要问清楚是港口提货价、批发市场交货价，还是送到你们总仓价。

3. **同结算账期**
   - 现款现货、7 天、15 天、30 天、铺底代销，价格差可能比品牌差还大。
   - 账期越长，供应商报价通常越高。

4. **同月份和同船期**
   - 进口苹果价格波动大，新货、旧货、尾期货、冷库货差别很大。
   - 要按同一到货周或同一船期报价。

建议你直接让两家按下面模板报价，然后横向比：

| 维度 | 要求 |
|---|---|
| 品项 | 进口苹果具体品种，如新西兰爱妃、红玫瑰、丹烁、智利嘎啦等 |
| 规格 | 果径、等级、箱规、净重 |
| 产地/品牌 | 都乐/鑫荣懋具体品牌线 |
| 到货时间 | 具体月份/船期 |
| 交货地 | 你们总仓或指定城市 |
| 价格 | 含税/不含税、到仓价/自提价 |
| 账期 | 现款/7天/15天/30天 |
| 起订量 | 整车/托盘/拼柜 |
| 损耗与售后 | 烂果率、理赔标准、退换条件 |

实操建议：

- **先让两家报同一单品**，比如都报新西兰爱妃 80# 或智利嘎啦 100#，不然比不出来。
- **不要只比单箱价，算“到手可售成本”**：  
  到手可售成本 = 采购价 + 运费 + 损耗 + 扣重 + 资金成本 - 返利  
  这样才公平。
- **如果你们门店多、销量稳定**，可以拿鑫荣懋的报价去压都乐，或反过来让两家竞标。
- **如果量不大**，都乐和鑫荣懋未必给到最好价格，可能还要看区域批发商或港口一手货代。

一句话：  
**要稳定走量和裸价竞争力，优先比鑫荣懋；要品牌溢价和终端动销，优先看都乐。最终谁便宜，必须拿同规格、同到仓、同账期的书面报价来比。**
