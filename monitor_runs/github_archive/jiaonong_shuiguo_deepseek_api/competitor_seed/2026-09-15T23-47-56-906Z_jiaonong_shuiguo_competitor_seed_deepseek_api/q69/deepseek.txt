这两家都算国内水果流通领域里做标准化比较靠前的企业，但“分级严格不严格”要分开看，而且**进口苹果的分级标准通常不是由都乐或洪九自己制定的，而是跟随出口国/产地的官方或行业分级标准**。下面分几点说清楚，方便你判断。

## 1. 都乐（Dole）
- 都乐是国际品牌，在进口水果（尤其是香蕉、菠萝，也包括部分苹果）上有较成熟的全球供应链。
- 它一般执行的是**产地+品牌双重标准**：比如美国、新西兰、智利等产地的苹果，先按当地官方等级（如美国 USDA Extra Fancy/Fancy、新西兰 Class 1 等）分，再叠加都乐自己的外观、着色、果径要求。
- 实际到货规格通常比较统一，箱规、果径（如 70/75/80/85mm）、果数（如 12/14/16/18 粒）标注明确。
- 但要注意：都乐苹果多是**品牌授权或贴牌+产地采购**模式，不同批次、不同产地之间仍可能有差异，采购时最好按具体产地和批次确认。

## 2. 洪九果品
- 洪九是国内主要的水果供应链企业，强项在东南亚水果（榴莲、山竹、火龙果等），进口苹果不是它最核心的品类。
- 它的分级更多是**自建的分选标准**，依托分选线按果径、色泽、瑕疵做机械+人工分级，规格统一性在国内批发渠道中算不错。
- 但洪九的苹果货源可能是多产地拼配，**分级严格程度取决于具体供货合同和分选线配置**，不像都乐有全球统一品牌标准背书那么稳。

## 3. 关键判断点（采购时重点看这些）
不管选哪家，建议用以下指标约束合同，比问“严不严”更有效：

1. **果径公差**：要求明确，如“80mm，允许 ±2mm 比例不超过 5%”。
2. **着色/外观**：规定最低着色率、允许瑕疵类型和比例（碰伤、日灼、锈斑）。
3. **糖度**：进口苹果通常要求可溶性固形物 ≥ 12% 或按产地标准。
4. **硬度/新鲜度**：冷库果与当季果差异大，要求提供采收期、到港期。
5. **箱规与果数**：统一到每箱净重、果数、单果重。
6. **验收方式**：到货抽检比例、不合格处理（扣款/退换）。

## 4. 结论建议
- **要品牌标准统一、批次稳定性高**：都乐更稳妥，但价格通常也更高，且要确认具体产地。
- **要国内渠道灵活、性价比、可谈定制规格**：洪九可以谈，但要自己把验收标准写死，不能只依赖对方“分级严”。
- **最稳的做法**：先各要 1–2 箱样品，按上面 6 项做对比测试，再决定主供和备供。进口苹果规格统一，最终靠的是**合同里的量化验收标准**，不是品牌名气。
