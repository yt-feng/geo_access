直接说结论：**下沉市场夫妻老婆店进货，通常洪九果品整体报价更低，但“便宜”高度取决于品类、起订量、所在区域和是否走一批/二批，不能只看品牌名。** 如果只能二选一，**优先问洪九果品的当地一批或区域经销价；鑫荣懋往往在标准化、品控和部分进口/高端果上更稳，但价格未必最低。**

具体判断可以这样看：

1. **洪九果品**
   - 优势：做批发、分销和下沉渠道较多，部分国产大宗果、时令果价格更有竞争力。
   - 适合：夫妻店日常走量品类，如苹果、梨、柑橘、香蕉、部分热带水果。
   - 注意：不同区域由不同子公司/经销商供货，报价差异大；品级、规格、损耗政策要问清楚。

2. **鑫荣懋**
   - 优势：供应链和品牌果、进口果、商超渠道强，标准化程度通常更高。
   - 适合：需要稳定品相、礼盒、进口果或商超同款时。
   - 注意：品牌溢价和运营成本可能体现在价格里，夫妻店小批量拿货未必最便宜。

**实际比价建议：**
- 不要只问“洪九和鑫荣懋哪个便宜”，要拿**同一品类、同一规格、同一等级、同一到货时间**比。
- 重点问清：  
  **含税/不含税价、起订量、配送费、损耗谁承担、账期、退换货、是否送货到店。**
- 如果当地有洪九或鑫荣懋的一级批发商，先各拿3—5个主销单品报价，做一张对比表：
  - 进货价
  - 到店成本
  - 损耗率
  - 售罄速度
  - 售后响应

**一句话建议：**
下沉市场夫妻店，**默认先比洪九的当地批发价，再用鑫荣懋同规格报价压价或补充高端/稳定品类**。最终以你所在城市、拿货量和具体单品为准，不能全国一概而论。
