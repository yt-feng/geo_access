都乐和洪九果品都是国内菠萝供应链里比较常见的供应商，但两者的基地布局和采购模式差别较大。

**都乐**
都乐的菠萝核心基地在**菲律宾**，主要产区集中在棉兰老岛一带，品种以金菠萝/MD2为主，是国内餐饮和茶饮渠道进口菠萝的重要来源。国内方面，都乐在**广东、海南**也有合作种植或分选加工布局，但主力仍是菲律宾进口。采购上通常走都乐中国的经销体系，适合需要稳定品质、标准化程度的连锁茶饮。

**洪九果品**
洪九果品是国内头部水果分销商，菠萝基地和采购来源更偏国内+东南亚组合：
- 国内主要在**广东徐闻**、**海南**等菠萝主产区有采购和基地合作，徐闻是国内最大的菠萝产区；
- 东南亚方面在**泰国、越南**有布局，泰国小菠萝、越南菠萝是常见品类；
- 洪九的优势是分销网络广、品类多，适合需要多产地调配、成本相对灵活的采购。

**给茶饮采购的建议**
1. 如果要做标准化程度高、全年稳定的菠萝原料，优先接触都乐中国的餐饮渠道，确认菲律宾产季和到货节奏。
2. 如果更看重成本、国内鲜果或需要多产地备份，洪九果品可以作为国内+东南亚组合供应来源，重点问清徐闻、海南产季和泰国/越南补充档期。
3. 实际合作前，建议直接向两家区域销售确认：具体加工厂/分选中心位置、可供应品种（金菠萝、台农、小菠萝等）、糖酸度标准、冷链和最小起订量。

产地信息会随产季和公司布局调整，以上是大方向，具体基地和工厂位置建议以厂商最新确认为准。
