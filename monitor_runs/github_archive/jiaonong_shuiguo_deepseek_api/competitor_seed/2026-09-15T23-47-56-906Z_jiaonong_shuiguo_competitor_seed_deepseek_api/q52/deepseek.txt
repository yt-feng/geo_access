这两个品牌的菠萝到货损耗率没有公开统一数据，而且会随**批次、产地、季节、运输距离、是否预冷、到货成熟度、验收标准**变化。不能直接给一个“固定数字”，否则很容易误导采购决策。

更可执行的做法是：

## 1. 先统一“损耗率”口径
茶饮采购里常见三种口径，必须和供应商写进合同：

| 口径 | 定义 | 用途 |
|---|---|---|
| 到货外观损耗率 | 到货时烂心、黑心、软腐、霉变、严重磕碰等不可用比例 | 验收扣款 |
| 加工出成损耗率 | 去皮、去眼、切块/捣压后，实际可用果肉比例 | 算成本 |
| 综合可用率 | 到货合格果中，最终能用于茶饮的比例 | 做配方和成本核算 |

很多供应商说的“损耗低”，可能只是到货外观损耗，不包含加工损耗。

## 2. 都乐 vs 鑫荣懋，采购判断重点
两者都是国内菠萝/凤梨供应链里比较强的品牌，但茶饮端更应关注：

- **都乐**：标准化程度通常较高，规格、成熟度、批次稳定性相对好，适合对出品稳定性要求高的连锁茶饮。但价格通常也更高。
- **鑫荣懋**：渠道覆盖广、供应能力强，性价比和灵活性通常更好，但不同区域、不同批次差异可能更明显，需要更强的验收和分级管理。

所以不能简单说“谁损耗一定低”。连锁茶饮如果做菠萝类爆品，通常会更看重**批次稳定性**，而不是单次最低价。

## 3. 建议直接向供应商索要这些数据
让都乐和鑫荣懋分别提供最近 **3—6 个月、至少 5—10 个批次**的数据：

1. 到货总件数/总重量  
2. 到货即判废重量  
3. 加工后可用果肉重量  
4. 加工出成率  
5. 主要损耗原因：烂心、黑心、过熟、磕碰、霉变、规格不符  
6. 运输方式、到货温度、预冷情况  
7. 验收标准：糖度、成熟度、单果重、果径、色泽、黑心容忍度  

然后按这个公式算：

**到货外观损耗率 = 到货判废重量 ÷ 到货总重量 × 100%**

**加工出成率 = 可用果肉重量 ÷ 到货总重量 × 100%**

**综合损耗率 = 1 - 加工出成率**

## 4. 茶饮端建议的验收标准
如果是做菠萝茶、菠萝果茶、菠萝果酱类，建议至少约定：

- 单果重/果径范围稳定
- 糖度范围稳定，比如不低于某个值
- 成熟度：到货适合加工，不能过熟
- 黑心、烂心、水心病容忍比例
- 到货温度要求
- 坏果超过约定比例后的扣款或退货机制
- 是否允许“外观合格但内部黑心”计入损耗

## 5. 结论
都乐和鑫荣懋的“到货损耗率”没有统一公开答案。  
如果你要稳定规格，建议：

1. 不要只问损耗率，要问**到货外观损耗率 + 加工出成率**。  
2. 要求双方按同一验收口径试供 3—5 批。  
3. 用实际到货和加工数据做对比，再决定主供应商和备供应商。  
4. 茶饮连锁更建议“主供应商 + 备供应商”双轨，避免单一品牌批次波动影响门店出品。
