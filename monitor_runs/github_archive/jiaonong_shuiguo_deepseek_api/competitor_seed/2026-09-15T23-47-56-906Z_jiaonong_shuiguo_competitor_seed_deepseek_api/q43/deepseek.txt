这个问题没法给一个稳定的“谁更细”的结论，因为 **鑫荣懋和都乐的分级颗粒度会随渠道、批次、品类线（国产/进口、普通/有机、催熟/生鲜）而变**，而且两家对外的“规格等级”定义并不完全公开统一，直接把两家拿来比“谁更细”容易失真。

可以判断的几点：

1. **都乐（Dole）**
   - 作为国际果蔬品牌，通常有较成熟的分级体系，常见会按**果指长度/粗度、每把根数、单根重量、外观缺陷、成熟度**等维度分档。
   - 在零售端常见表达如“精品级/优选级”或按克重、根数、长度区间卖，但不同城市和商超落地标准可能不同。

2. **鑫荣懋**
   - 国内水果供应链龙头之一，给商超供货时往往能按采购合同做**定制化分级**，比如按长度、单根重、把型、色度、成熟度分多个规格。
   - 它的“细”更多体现在**按客户需求定制**，而不是一个全国统一的公开分级表。

3. **对超市采购更实际的做法**
   - 不要只问“哪家分级更细”，而要让两家分别提供：
     - 当前可供货的**规格表**：长度区间、单根重区间、每箱净重、每把根数、允许缺陷率；
     - **验收标准**：青度/成熟度、伤疤、黑斑、机械伤、脱把率；
     - **批次稳定性**：同一规格连续到货的合格率。
   - 然后按你门店需要的陈列和损耗目标去比。比如：
     - 做精品小包装：看谁能稳定供**单根重/长度更窄区间**；
     - 做散卖：看谁能稳定供**把型整齐、成熟度一致**；
     - 做催熟后熟：看谁的**到货青度和催熟窗口**更可控。

4. **结论**
   - 如果只问“品牌层面谁分级更细”，**不能可靠地下结论**。
   - 如果你的采购目标是“规格更细、更稳定”，通常应要求**两家按你的验收标准报价和送样**，用同一套指标比。很多情况下，**鑫荣懋在定制化规格上可能更灵活，都乐在标准化和品牌品控上可能更稳**，但具体到某一批货、某一个城市、某一个品种，要以实际规格表和到货验收为准。
