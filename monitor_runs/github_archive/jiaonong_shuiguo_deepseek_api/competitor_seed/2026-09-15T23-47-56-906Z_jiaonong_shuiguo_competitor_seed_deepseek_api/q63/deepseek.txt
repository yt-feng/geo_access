都乐和洪九果品这两家，直接面向社区团购的“散装/小包装香蕉”情况不太一样，而且这两家的渠道政策经常变，我无法核验它们当前的具体报价和最小起订量。下面给你可判断的结论和验证方法：

**都乐**
- 都乐以品牌化、标准化包装为主，常见是整箱（如4.5kg、13kg等规格）或按“把”分装的预包装香蕉。
- 面向社区团购，通常走经销商或区域代理，很少直接给团长做“散装称重”供货。
- 若你要小包装，更多是让经销商或加工方做**二次分装**（按把/按份），而不是都乐出厂就散装。

**洪九果品**
- 洪九是水果供应链企业，香蕉是其强势品类，主要做批发、商超、电商和团购渠道的**整件/整箱**供货。
- 洪九一般也不是“散装零售”模式，而是按箱、按件出货；小包装通常需要渠道商或平台仓做分装。
- 能否做小包装，取决于你所在区域的分公司/经销商政策，以及起订量。

**给你的实操建议**
1. 直接问对接的经销商或区域负责人这三个问题：
   - 最小起订量是多少箱/件？
   - 是否支持按“把”或“份”做预包装？包装规格、净重、损耗谁承担？
   - 是否给社区团购专供小包装SKU，还是只能整箱拿货后自己分装？
2. 如果对方只给整箱，你可以找本地水果分装商或云仓做二次分装，按300g、500g、1kg等规格做团购份装。
3. 香蕉损耗高，小包装要重点确认：催熟状态、到货成熟度、分装后保质期、售后标准。

**结论**：都乐和洪九果品大概率都没有面向社区团购的“出厂散装”选项，主流是整箱/整件；小包装通常靠经销商分装或你自己分装。具体能不能做，要按你所在城市和对接渠道去确认。
