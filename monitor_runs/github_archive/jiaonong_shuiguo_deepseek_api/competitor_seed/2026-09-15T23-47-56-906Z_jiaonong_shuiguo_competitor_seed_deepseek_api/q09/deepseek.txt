除了都乐（Dole）和佳沛（Zespri），进口水果礼盒里常见、适合礼品团购的品牌还有这些，可按品类和定位来选：

**综合水果/高端礼盒类**
- **新奇士 Sunkist**：美国柑橘类代表，脐橙、柠檬、葡萄柚都有，礼盒认知度高，适合企业福利。
- **金吉达 Chiquita**：香蕉为主，也有部分综合水果礼盒，价格相对亲民。
- **福瑞斯 Fyffes**：香蕉、菠萝等，偏商超渠道。
- **乐淇 Rockit**：新西兰小苹果，单果装、筒装礼盒很有辨识度，适合做精致伴手礼。
- **爱妃 Envy**：新西兰苹果品牌，红皮、脆甜，礼盒装常见，适合中高端团购。
- **爵士 Jazz**：新西兰苹果，和爱妃同属一个体系，也有礼盒。
- **红玫瑰/太平洋玫瑰 Pacific Rose**：新西兰苹果，部分进口商做礼盒。

**樱桃/车厘子类**
- **Stemilt**：美国西北樱桃代表品牌之一，车厘子季礼盒常见。
- **Chelan Fresh**：美国樱桃品牌，礼盒装较多。
- **Starr Ranch**：美国樱桃，部分高端渠道有。
- ** Reid Fruits**：塔斯马尼亚樱桃，澳洲高端樱桃，礼盒定位偏高端。

**提子/葡萄类**
- **Sun World**：旗下有 Autumn Crisp、Midnight Beauty 等专利葡萄品种，进口提子礼盒常见。
- **IFG**：专利葡萄品种公司，很多进口无籽提子礼盒会标其品种。
- **Costa**：澳洲/智利等产地葡萄、蓝莓等，部分礼盒。

**蓝莓/浆果类**
- **Driscoll's 怡颗莓**：蓝莓、树莓、黑莓，礼盒和组合装都有，团购认知度高。
- **Costa**：蓝莓、牛油果等，礼盒装常见。
- **Naturipe**：美国浆果品牌，部分进口蓝莓礼盒。

**牛油果/其他**
- **Mission**：牛油果品牌，也有礼盒组合。
- **Calavo**：牛油果，偏餐饮和商超。
- **Zespri 佳沛**：你已提到，奇异果礼盒仍是团购主力。

**选品建议**
1. **企业福利团购**：优先选新奇士、怡颗莓、乐淇、爱妃，认知度高、包装规整、价格带清晰。
2. **高端商务送礼**：选澳洲塔斯马尼亚樱桃、新西兰爱妃/乐淇、佳沛金果礼盒。
3. **预算有限但要有品牌感**：金吉达、福瑞斯、新奇士普通装。
4. **注意季节**：车厘子主要看智利、美国、澳洲产季；柑橘看美国、澳洲；奇异果全年较稳。
5. **核验渠道**：进口水果礼盒品牌授权和货源差异大，团购前要确认报关单、产地证明、品牌授权，避免买到贴牌或混装货。
