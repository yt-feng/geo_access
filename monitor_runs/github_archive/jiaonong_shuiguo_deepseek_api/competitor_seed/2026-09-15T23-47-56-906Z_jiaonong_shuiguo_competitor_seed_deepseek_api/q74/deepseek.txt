可以给你可执行的判断和操作建议：

**1. 两家渠道定位不同，起订量预期差别很大**
- **都乐**：品牌化程度高，标准礼盒走商超/电商/经销体系多。定制（换包装、贴企业logo、组合装）通常门槛偏高，很多情况要通过区域经销商或大客户渠道谈，纯小批量很难做。
- **洪九果品**：以批发、渠道分销、产地直采为主，B端属性更强。团购/礼盒定制相对更灵活，但同样看品类和量，热门单品（如进口车厘子、榴莲等）旺季门槛会明显提高。

**2. 询价时一定要让对方明确这几个变量，否则报价没意义**
- 单品还是组合礼盒
- 是否要贴企业logo/换外箱
- 单款起订量 vs 总订单起订量
- 是否含冷链、配送、税费
- 提货周期和旺季档期（春节、中秋前最紧）

**3. 实操建议（按优先级）**
- **先找区域经销商，不要一上来找总部**：经销商手里有现成礼盒方案，起订量往往比总部定制低，还能拼单。
- **直接要“礼盒定制起订量清单”**：让对方按品类发一份，比口头问“多少钱起订”更靠谱。
- **用“组合礼盒+多品类合订”凑量**：比如把车厘子、蓝莓、猕猴桃组合，总量达到门槛即可，比单品类死磕更容易谈。
- **备选方案**：如果两家门槛都太高，可考虑本地精品水果供应链或礼盒包装厂+产地直采组合，小批量更友好。
