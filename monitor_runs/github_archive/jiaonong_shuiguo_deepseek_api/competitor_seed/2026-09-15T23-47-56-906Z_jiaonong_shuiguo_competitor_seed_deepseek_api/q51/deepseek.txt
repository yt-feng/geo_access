直接说结论：**没有固定答案，要按当天、按品类、按你的拿货量和结算方式来比**，两家不同市场、不同批次的报价经常反过来。

给你几个可判断的维度：

1. **看品类档次**
   - 洪九果品：香蕉是其核心大单品之一，走量规模大，通常在中低端走量货、国产蕉上价格弹性更强。
   - 鑫荣懋：偏中高端和品牌化水果，进口蕉、品牌蕉、品相要求高的货上更有优势，但单价不一定更低。

2. **看拿货量**
   - 整车/大吨位：洪九往往更有议价空间。
   - 中小批量：两家差距可能被物流、账期、返点吃掉，实际到手价要看具体政策。

3. **看结算和附加条件**
   - 现款现货 vs 账期
   - 是否含运费、装卸、损耗补贴
   - 是否有返利、搭赠、次果处理政策
   这些比表面报价更能决定真实成本。

4. **看区域**
   - 你在哪个批发市场、哪个城市，直接决定谁的到货成本和区域报价更有优势。华南、华东、西南差异很大。

**实操建议：**
- 同一天向两家当地销售或档口要**同规格、同产地、同成熟度**的报价；
- 问清楚**到岸价还是档口价**、含不含运费和损耗；
- 按你实际周用量谈**月度框架价**，不要只比单次报价；
- 如果量不大，优先比**当地一批/二批**的即时价，而不是比洪九、鑫荣懋总部政策。
