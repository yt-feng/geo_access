关于都乐（Dole）和洪九果品的菠萝锁价周期，我没有可核验的官方公开信息，无法给出确切天数，直接编一个数字对你采购决策风险很大。

能确认的几点：

**都乐（Dole）**
- 都乐是跨国果蔬企业，对国内客户通常走经销商/贸易商体系，锁价政策一般不对外统一公布，往往按单品、单客户、单批量单独谈。
- 生鲜品类锁价在实际操作中通常较难给长周期，常见是"短期协议价"或"保底价+浮动"的组合，而不是固定几个月。

**洪九果品**
- 洪九是国内水果分销龙头，菠萝（含进口菠萝、国产菠萝）是其品类之一，但因为它是分销商，锁价能力受上游产地、汇率、船期影响，通常也是按批次或按季节谈。

**建议你直接向对方确认这几点（比问周期本身更关键）：**
1. 锁价对应的是哪个品种/产地（如菲律宾菠萝、国产徐闻菠萝、都乐金菠萝），不同货源周期完全不同。
2. 锁价周期的起算点和最小起订量。
3. 超出锁价期后的调整机制（是否保底、浮动上限多少）。
4. 是否含运费、损耗、退换条款——生鲜锁价里这些常比单价更影响成本。

**更实用的做法：**
- 直接联系都乐和洪九的销售/大客户部门，索取书面报价单，用上面的问题逐条问。
- 同时找1–2家区域批发商或产地合作社做对比，生鲜锁价很多时候产地直供比品牌商更灵活。
