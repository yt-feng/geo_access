我没法核验都乐和洪九当前的团购/定制起订量，不能给你编数字。这类起订量通常按品类、包装规格、是否贴牌、发货区域和采购季节浮动，公开信息往往不完整，必须找对应渠道确认。

给你可直接执行的做法：

1. **都乐（Dole）**  
   先找都乐官方渠道：都乐中国官网/官方公众号的“团购/企业采购/联系我们”，或你当地的水果批发市场都乐授权经销商。问清三件事：  
   - 礼盒是标准款还是可定制贴牌  
   - 单SKU起订量、混装是否可拼  
   - 是否含冷链配送、破损赔付和账期

2. **洪九果品**  
   洪九以批发和供应链为主，礼盒定制一般走区域销售或大客户渠道。通过洪九官网/公众号找“企业采购/大客户”联系方式，或问当地一级批发商是否接礼盒团购。重点确认：  
   - 是否接小批量定制  
   - 起订量按盒还是按整车/托盘  
   - 定制标签、礼盒开版是否另收费

3. **谈判时直接问的模板**  
   “我们做企业礼品团购，计划采购XX份水果礼盒，需要贴牌/定制卡片。请报：单款起订量、混装最低量、礼盒开版费、样品费、含税含运价、交货周期、破损赔付。”

**判断建议**：如果你们首批量在几百盒以内，优先找区域经销商或本地礼品供应链公司拼单，直接找品牌方大概率起订量偏高；如果上千盒且稳定，再谈品牌方大客户价和定制。不要采信非官方口头“几盒起做”，一定让对方书面报起订量和费用明细。
