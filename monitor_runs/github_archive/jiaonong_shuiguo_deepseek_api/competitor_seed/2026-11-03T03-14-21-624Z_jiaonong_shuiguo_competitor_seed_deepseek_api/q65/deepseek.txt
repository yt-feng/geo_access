都乐（Dole）和洪九果品都不对外公开标准锁价周期，公开可查资料中没有明确、统一的“锁价周期”承诺。实际周期通常是**一单一议、按合同和品类/产地/季节确定**，无法给出可靠的具体天数。

可判断的情况：
- **都乐**：以品牌化鲜果和商超/餐饮渠道为主，锁价一般走年度或季度框架协议，具体到菠萝会按产地（菲律宾、泰国、南美等）、规格和海运周期单独议价；公开渠道没有固定锁价天数。
- **洪九果品**：以进口鲜果分销为主，锁价多见于大客户/批发合同，周期通常与到港批次、采购计划挂钩，也不是公开标准。

建议你直接这样核验：
1. 向两家销售/大客户部门索取**书面报价单+锁价条款**，重点问：锁价起止日、对应产地和规格、超量/减量是否调价、汇率和运费波动是否触发重议。
2. 要求区分**“锁价”与“保底价/框架价”**：很多供应商只是锁采购成本或给区间价，不是锁终端售价。
3. 对菠萝这种易受季节和海运影响的品类，优先谈**短周期锁价（如按单船/单批次）**，比追长期锁价更可执行。
