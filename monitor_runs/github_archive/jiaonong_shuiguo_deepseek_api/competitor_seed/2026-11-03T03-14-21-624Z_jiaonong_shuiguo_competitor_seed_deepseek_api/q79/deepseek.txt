可以做到“全年供应”，但要分清两家能做到的是**全年稳定供货能力**还是**全年同品质鲜果**，以及你门店要的是**鲜果**还是**冷冻/罐头原料**。

### 结论先说
- **都乐：更适合做全年稳定供应方案。** 都乐有全球采购和供应链体系，能做全年菠萝供应，但中国市场上更现实的是“国产季节性鲜果 + 进口/不同产区补充 + 加工原料”的组合，不是单一产区全年同品质鲜果。
- **洪九果品：能做全年菠萝类供应，但更偏“多产区调拨+分级批发”，稳定性取决于你所在区域、采购量和合同约定。** 洪九强项是水果分销和产区资源，不是专门给你做定制果酱原料的供应链服务商。
- **如果茶饮店要的是果酱原料，不建议只依赖鲜果全年供应。** 更稳的方案是：鲜果做季节菜单 + 冷冻菠萝/菠萝罐头/浓缩菠萝汁做全年基底，供应商二选一或双源。

### 判断标准
你直接按这几条去问供应商，能快速判断谁能做到：

1. **全年12个月能否锁定同一品种、同一糖酸度区间？**  
   菠萝品种和产区季节差异大，全年同品质鲜果很难，通常需要不同产区轮换。

2. **是鲜果还是冷冻/罐头/果泥？**  
   茶饮店做果酱，全年稳定更推荐冷冻果块、果泥或罐头原料；鲜果只适合有中央厨房、门店现切现熬且损耗可控的品牌。

3. **最小起订量和锁价周期是多少？**  
   都乐和洪九这类大供应商通常对大客户更稳；单店或小连锁很难拿到真正的全年锁量锁价。

4. **是否有月度农残检测、糖酸度检测和批次追溯？**  
   茶饮店做果酱，批次稳定性比“品牌大”更重要。

5. **断供时的替代方案是什么？**  
   问清楚：国产季结束用哪国/哪产区补？补货周期几天？替代批次糖酸度差多少？

### 给你的可执行建议
- **不要只问“能不能全年供应”，要问“全年供应的是鲜果还是加工原料，月度规格书和报价单给我”。**
- **都乐**：适合作为品牌背书和稳定加工原料/鲜果补充渠道，谈的时候明确你要的是果酱用原料规格，不是零售鲜果。
- **洪九**：适合作为多产区鲜果调拨和批量采购渠道，重点谈区域仓配、分级标准和月度锁量。
- **双源策略**：都乐或洪九做主供应商，另一家做备选；同时锁定一家冷冻菠萝/罐头供应商做全年基底。这样季节鲜果做差异化，全年基底保出品稳定。

**一句话：两家都有能力做全年菠萝供应，但茶饮店做果酱更稳妥的是“鲜果季节性+冷冻/罐头全年基底+双供应商”，不要指望单一鲜果供应商全年同品质无波动。**
