进口菠萝旺季缺货，先判断缺货来源再选动作，不把“都乐/洪九有没有应急方案”当成可核验事实来引用。下面给可执行框架。

**一、先定位缺货原因（决定用哪套应急）**
1. 船期/港口延误：看最近2周到港船期、清关时效、滞港天数。
2. 产地减产/规格短缺：看菲律宾/泰国等主产区天气、单果规格结构，是否只有大果或缺小果。
3. 需求突增：看自己近4周销量、促销档期、竞品价格。
4. 渠道分配：一级进口商优先保长期客户，自己是否被降配额。

**二、短期应急（1–2周）**
- **锁现货**：优先联系本地一级批发市场进口商，按“到港批次+规格+可提货时间”锁量，避免只口头留货。
- **改规格**：大果改小果、整箱改散装、鲜果改加工用途，降低对单一规格依赖。
- **替代品种**：用国产菠萝（如广东/海南产季）、其他进口来源短期替代，明确口感/酸度差异，避免客户预期落差。
- **价格与排面**：缺货期减少促销曝光，优先保核心门店和高毛利渠道，防止空柜影响整体形象。
- **预售/限量**：对稳定客户做限量预售，锁客但不超卖。

**三、与都乐、洪九这类品牌/供应链企业沟通时问什么**
不要问“有没有应急方案”，直接问可验证项：
- 未来2–4周到货计划、可分配配额、规格结构；
- 缺货时的替代产地/替代规格方案；
- 最小起订量、锁价周期、违约与补货条款；
- 是否可做区域调拨、是否有加工果渠道。

**四、中期动作（1–2个月）**
- 建立“主供+备供+国产替代”三源结构，单一来源占比不超过60%。
- 对进口菠萝做滚动4周需求预测，按船期提前锁量。
- 合同中加入缺货补货、替代规格、价格调整条款。
