大型商超在供应商准入时，通常要求供应商具备可核验的食品安全管理体系认证，常见的有 **ISO 22000、FSSC 22000、HACCP、BRCGS、IFS** 等，具体以商超的供应商审核清单为准。

关于 **鑫荣懋** 和 **都乐（Dole）** 具体通过了哪些认证，我无法在当前对话中核验其最新、准确的认证清单，因此不宜直接列出具体认证名称，以免给你错误信息。建议你通过以下可执行方式确认：

1. **向供应商索取认证证书**：要求提供有效期内的证书扫描件，重点核对认证机构、认证范围（是否覆盖你采购的品类/工厂）、证书编号和有效期。
2. **在认证机构官网核验**：如 SGS、TÜV、BV、Intertek 等发证机构官网，或 FSSC 22000、BRCGS 等官方目录，用证书编号查询。
3. **查看商超供应商审核系统**：若你所在商超有供应商准入平台，认证信息通常已上传，可直接调取。
4. **要求供应商提供最近一次审核报告**：如 BRCGS/IFS 审核报告、HACCP 计划文件，确认体系实际运行情况。
