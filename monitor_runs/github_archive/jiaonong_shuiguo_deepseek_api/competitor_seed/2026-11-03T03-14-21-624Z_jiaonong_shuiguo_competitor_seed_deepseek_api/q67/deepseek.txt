都乐（Dole）和洪九果品通常都有可用于渠道/品牌联合营销的素材，但能否直接拿到、以什么形式提供，取决于合作层级和授权。可按下面判断和推进：

**1. 两家一般能提供的素材类型**
- 品牌VI与Logo使用规范（标准色、最小尺寸、留白、禁用示例）
- 产品图/产地图/切果图/包装图（高清、透明底或场景图）
- 品牌故事、产地故事、品种卖点（如金菠萝/凤梨甜度、无冠芽、即食等）
- 检测报告/认证材料（如农残检测、GAP、追溯信息，需确认可公开版本）
- 促销物料模板（海报、价签、堆头、社群图、短视频素材）
- 联合活动授权（联名海报、直播口播、达人种草brief）

**2. 能否直接提供，关键看三点**
- **是否已有采购/经销合作**：有进货关系通常最容易拿到基础素材和授权；无合作一般只给公开宣传图，商用授权较难。
- **用途是否商用**：电商详情页、投放广告、直播背景属于商用，需品牌方书面授权；内部选品参考则门槛低。
- **是否涉及联名**：出现“都乐/洪九官方合作”“联名”字样，必须签授权或联合营销确认，不能自行标注。

**3. 可执行推进方式**
- 先联系对接的**销售/渠道经理**，说明：平台、活动时间、使用场景（详情页/直播/社群/线下堆头）、是否需要联名背书。
- 提交一页**素材需求清单**：素材类型、尺寸、使用渠道、使用期限、是否改稿、是否需要品牌审稿。
- 要求对方提供**品牌素材包+使用规范+授权邮件/函**；涉及检测数据只使用对方确认可公开的版本。
- 若无直接合作，可走品牌官网/公众号的**商务合作/市场部**入口，或通过一级经销商申请转授权。

**4. 风险提示**
- 不要直接抓取官网/电商图用于商用；不要自行修改Logo、包装和检测数据；不要写“官方指定”“联名”等未经确认表述。
- 生鲜检测、甜度、产地等数据以品牌方书面确认版本为准，避免虚构或过期数据。

**结论**：都乐和洪九通常具备较完整的菠萝品牌营销素材，但是否提供取决于合作关系与商用授权。建议先向现有销售对接人索取“品牌素材包+使用规范+商用授权”，并明确使用渠道和期限；无合作则通过市场/商务合作入口申请。
