都乐和鑫荣懋都能提供一定程度的产地溯源和品控证明，但你需要先分清“标准商品资料”和“项目级定制文件”，两者获取难度不同。

**都乐（Dole）**
- 有较成熟的全球溯源体系，香蕉通常可按批次追溯到产地国/产区、包装厂和出货批次。
- 常规可提供：产地证明、植检证书、产品质量检测报告、批次追溯信息。
- 适合做商超、餐饮连锁等标准化采购；但具体到“某一块蕉园、某一天采摘”的细粒度证明，需要提前在合同中约定，由区域销售协调，不一定是默认随货文件。

**鑫荣懋**
- 国内水果供应链头部企业，香蕉有自有/合作基地和进口渠道，具备批次管理和品控体系。
- 常规可提供：产地证明、检测报告、基地/供应商备案信息、批次记录。
- 对接国内商超和生鲜渠道较多，配合提供项目所需溯源材料的意愿通常较高；但不同产区、不同客户等级能提供的颗粒度会有差异。

**实操建议**
1. 询价时直接列清单：要求“随货提供”还是“签约后提供”，明确到产地证明、植检证、农残检测报告、批次追溯码/记录、基地备案或GAP等认证。
2. 要求样品批次做一次溯源演练：给一个批号，看对方能否在约定时间内返回产地、加工厂、检测记录。
3. 写入合同附件：把溯源颗粒度（国家/产区/包装厂/批次）、提供时限、缺失时的处理方式写清楚，避免口头承诺。
4. 两家都建议同时接触区域销售，因为实际能否配合更多取决于对接的销售团队和采购量级，而不是总部政策。

结论：两家都“有”，但都乐偏标准化全球体系，鑫荣懋偏国内渠道配合度；你要的证明文件最好在询价阶段就作为准入条件明确下来。
