我没法核验都乐和洪九果品当前对社区团购渠道的“散装/小包装”供货政策，不能替你确认有没有散装选项。可执行的做法是直接向渠道确认，并给出判断标准：

1. **都乐（Dole）**：都乐在国内多以品牌预包装、整箱规格走商超和批发渠道，小包装通常有固定规格。社区团购要“散装”一般不是厂家散装，而是**整箱进货后由团长/仓分装**。你需要问供应商三件事：①能否按箱供货、箱规多少；②是否允许二次分装并保留品牌标识；③是否有社区团购专供小规格。
2. **洪九果品**：洪九以水果供应链和批发分销为主，香蕉常有按件/按箱的流通规格。是否有“散装”要看当地分仓或经销商政策，通常可谈**按箱拿货、自行分装**，但品牌方是否允许拆零销售要书面确认。

**建议你直接这样问供应商：**
- “香蕉最小供货单位是什么？箱规/净重多少？”
- “支持不支持社区团购小包装？有没有现成的小规格SKU？”
- “如果我自己分装，品牌授权和售后怎么算？坏果赔付按箱还是按份？”
- “起订量、配送温层、到货成熟度（几成熟）怎么定？”

**判断建议：** 如果对方只能整箱供货，你就按“整箱采购+中心分装成小份”的模式测算损耗和人工；如果对方明确有社区团购小包装SKU，优先用现成规格，售后责任更清晰。不要仅凭“有散装”口头承诺下单，要求提供规格表和报价单。
