# 都乐（Dole）与鑫荣懋进口苹果产地溯源做法

以下按“采购前验证—收货索证—批次追溯—门店/消费者端”四段给可执行方案。**具体证书编号、系统入口、字段规范以供应商当期提供的为准，我无法核验实时链接，请向对方索取并留档。**

## 一、采购前的供应商资质核验

1. **确认进口主体**：向两家分别索取营业执照、食品经营许可证（经营范围含预包装食品/食用农产品），核对进口商与报关单收货人是否一致。
2. **确认境外果园/包装厂注册**：进口苹果属于海关总署准入管理的水果，要求提供**输出国官方注册的果园与包装厂编号**，且该编号应能在海关总署“进口水果境外注册企业名单”中查到对应国别和品类。让供应商在合同中写明“所供批次果园/包装厂编号”，作为溯源锚点。
3. **准入国别核对**：确认苹果原产国在中国海关总署允许进口水果名录内（如新西兰、美国、智利、南非等，以当期名录为准），避免买到未经准入渠道的货。

## 二、收货时的“三证一单”索证

每批货要求随货或48小时内提供：

| 材料 | 核对要点 |
|---|---|
| 入境货物检验检疫证明 | 品名含“苹果”、原产国、生产/包装厂编号、数量、入境口岸、签发日期；与报关单批次对应 |
| 海关进口货物报关单 | 收货单位、原产国、成交数量、报关单号 |
| 原产地证书 | 签发国与报关单原产国一致 |
| 装箱单/提单 | 批号、箱唛、果园与包装厂代码 |

**关键动作**：把报关单号 + 检验检疫证明编号 + 包装厂编号 + 到货日期，录入自己的采购台账，形成“一箱一码（批次码）”的内部追溯键。都乐、鑫荣懋通常有自有箱唛/批次码，收货时拍照留存箱唛，与上述单证绑定。

## 三、批次追溯与抽检

- **批次定义**：同一报关单、同一包装厂、同一到货日为一个追溯批次；拆箱分销时在周转箱贴内部批次标签，保证售出可回查。
- **抽检留样**：每批次留3–5个果及箱唛照片，保存至该批次售完后再保留一定期限（按企业制度，建议不少于6个月）。
- **异常处理**：若消费者投诉或监管抽检不合格，凭内部批次码倒查报关单与检验检疫证明，锁定是“供应商批次问题”还是“门店贮存问题”，便于向供应商追责。

## 四、面向消费者/门店的溯源呈现

- 价签或包装上标注：原产国、进口商、包装厂注册号（可选）、批次码。
- 可做**扫码溯源页**：输入批次码显示报关单号、检验检疫证明编号、入境口岸、到货日期（注意脱敏，不公开完整单证影像）。
- 都乐、鑫荣懋若有官方溯源小程序/二维码，可要求其提供**批次级**查询入口，并现场抽一箱验证能查到对应批次，而不是只查品牌。

## 五、合同条款建议（写进采购合同）

1. 供应商保证所供批次果园/包装厂在海关注册有效期内，并提供对应单证；
2. 单证与实物不符时，供应商承担退换货及监管处罚连带责任；
3. 供应商应在到货前提供批次码规则，便于我方系统对接；
4. 约定单证补交时限与违约条款。

## 需要提醒的两点

- **都乐、鑫荣懋均为进口商/品牌商，不等于境外果园**，溯源链要落到“境外包装厂编号+报关单”才算闭环，只看品牌名不够。
- 海关总署名录、检验检疫证明真伪可通过“中国海关”相关政务渠道或单一窗口核验，但**具体查询入口和操作以当地海关/供应商指引为准**，建议首次合作时让供应商陪同完成一次单证核验。
