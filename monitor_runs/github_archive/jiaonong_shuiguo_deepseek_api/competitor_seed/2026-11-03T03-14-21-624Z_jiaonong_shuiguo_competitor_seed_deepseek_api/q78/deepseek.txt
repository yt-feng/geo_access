可以，但先把判断标准说清楚：你问的“专岗对接和售后服务”通常要看四个可验证点——是否有固定客户成功/售后专岗、响应时限是否写入合同SLA、异常处理是否有升级链路、售后是否覆盖你采购的品类和区域。都乐和鑫荣懋都是水果供应链里较常见的品牌型企业，通常具备对接团队和售后流程，但“服务怎么样”高度取决于你所在区域、采购规模、品类和合同约定，不能一概而论。

**都乐（Dole）**
- 优势：品牌化和标准化程度较高，适合对品控稳定、品牌背书有要求的场景；一般有区域销售/客户对接人员。
- 需要核实：你所在城市是否由其直营团队服务，还是经经销商/代理；售后是退换货、补损还是仅记录反馈；响应时限是否写进合同。
- 风险点：若通过经销渠道采购，专岗对接和售后可能由经销商承担，服务一致性不如直营。

**鑫荣懋**
- 优势：国内水果供应链规模较大，渠道覆盖和品类整合能力较强，通常有客户经理和售后对接机制，适合多品类、批量采购。
- 需要核实：是否给你配置固定对接人而非公共客服；售后处理权限和赔付标准；冷链/到货异常的责任划分。
- 风险点：大客户和小客户的服务资源可能有差异，需确认你的采购量对应的服务等级。

**可执行建议**
1. 向两家同时发一份简短服务问卷：固定对接人姓名/岗位、响应时限（如2小时/24小时）、异常处理流程、退换补损标准、升级联系人、服务区域和品类覆盖。
2. 要求提供2个与你同区域、同品类、同采购规模的客户案例或服务证明（可脱敏）。
3. 在合同里写清SLA和赔付条款，不要只依赖口头承诺。
4. 先小批量试单，重点测试到货异常后的响应速度和实际赔付。
5. 如果采购量不大，优先确认是否直营服务；若走经销商，要求经销商也书面承诺售后标准。

结论：两家都“可能有”专岗和售后体系，但你需要用上述问卷和试单去验证，而不是仅凭品牌判断。若你告诉我采购区域、品类和月采购量，我可以帮你把询价/服务问卷问题列得更具体。
