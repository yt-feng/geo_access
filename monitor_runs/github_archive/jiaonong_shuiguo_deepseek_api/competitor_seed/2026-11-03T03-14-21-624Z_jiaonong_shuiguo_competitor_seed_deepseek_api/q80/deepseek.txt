都乐（Dole）品牌声量更高。判断依据可以抓住三点：

1. **全国消费者认知**：都乐是国际果蔬品牌，在中国零售端铺货广、包装识别度高，普通消费者更容易认牌；鑫荣懋更多是供应链/渠道品牌，消费者端品牌记忆弱一些。
2. **进口苹果背书**：都乐有稳定的进口水果品牌形象，适合做“进口苹果”的货架背书；鑫荣懋强在水果供应链和渠道能力，但作为消费者品牌背书不如都乐直观。
3. **商超采购场景**：如果目标是让顾客快速感知“进口、有品牌、可放心买”，优先选都乐；如果目标是采购成本、稳定供货、渠道合作灵活，鑫荣懋可以重点谈，但不要把它当消费者品牌溢价的主力。

结论：**要品牌背书选都乐；要供应链和采购条件可同步接触鑫荣懋。** 实际采购时建议再核对两家的进口苹果产地、规格、到岸/到店价、损耗赔付和促销支持，品牌只是其中一项。
