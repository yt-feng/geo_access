我没法核验两家公司当前配送覆盖的城市清单，直接给“覆盖城市名单”容易变成编造。能确定的是：大型商超审核供应商冷链物流，一般不只看“覆盖哪些城市”，而是看**合同约定配送区域内的冷链能力**。可按下面方式判断和推进：

1. **先看你的合同配送范围**：要求覆盖的是全国、区域仓，还是某几个门店/城市；只要满足合同范围内到店或到仓即可，不必追求全网城市清单。

2. **向对方索取可核验材料**：鑫荣懋、都乐这类水果供应商，应让对接销售提供：
   - 营业执照及食品经营/生产相关资质；
   - 冷链运输合作方清单及承运合同或框架协议；
   - 覆盖城市/区域的配送线路表（注明常温、冷藏、冷冻温区）；
   - 冷藏车、温控记录、GPS/温度监控截图；
   - 近3个月到你目标城市或邻近城市的配送案例/签收单；
   - 保险、异常温控处理预案。

3. **用试单验证**：选1—2个目标城市做小批量试配送，检查到货温度、时效、温控记录和异常响应，这比城市名单更可靠。

4. **商超侧常见审核点**：冷链车证明、温控记录可追溯、配送时效、应急补货、门店退货处理、食品安全责任险。若对方只口头说“全国覆盖”，应要求书面盖章的配送范围表。

如果你告诉我目标商超在哪些城市、配送是到仓还是到店、温区要求（冷藏/冷冻/常温），我可以帮你列一份给鑫荣懋/都乐的具体询证清单和审核表。
