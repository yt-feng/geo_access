直接给结论：**如果只在这两家选，茶饮店做菠萝果酱的稳定供应，优先看都乐；洪九果品不是不能合作，但要先做供应商审核和到货抽检，不建议只凭品牌名气直接把主力供应切过去。**

判断依据和可执行建议如下：

1. **都乐更适合优先谈**
   - 都乐是国际水果品牌，菠萝是其核心品类之一，标准化分级、冷链和餐饮/工业渠道经验相对成熟。
   - 茶饮果酱要的是**批次稳定**：糖度、酸度、成熟度、纤维感、出成率要稳定，不是偶尔买到好吃的鲜果就行。
   - 建议先让都乐提供：菠萝品种/产地、全年供应窗口、到店规格（鲜切/冷冻/果块/果泥）、糖酸度区间、冷链方式、最小起订量、报价和账期。

2. **洪九果品要更谨慎**
   - 洪九是国内水果分销规模较大的企业，但公开信息中曾出现财务披露、审计相关争议，采购前应做正式供应商尽调，不能只看“规模大”。
   - 如果合作，建议先小批量试单，重点测：到货成熟度一致性、坏果率、糖酸度波动、冷链断链情况、旺季保供能力和售后赔付。
   - 要求其提供近批次检测报告、产地证明、冷链记录和违约保供条款。

3. **更稳的做法：不要单押一家**
   - 主力供应商选一家标准化能力强的，备选供应商保留一家区域菠萝产地供应商或冷冻果浆供应商。
   - 茶饮店果酱用菠萝，建议优先评估**冷冻菠萝块/果泥/浓缩菠萝汁**，比鲜果更利于全年稳定和标准化；鲜果适合做门店鲜切或差异化产品。
   - 设定验收标准：可溶性固形物、总酸、成熟度、坏果率、出成率、微生物指标，按批次留样。

4. **最终怎么选**
   - 先同时向都乐和洪九发同一份询价与样品需求，做**盲测果酱**和**连续3批到货稳定性测试**。
   - 评分权重建议：批次稳定性40%、保供能力20%、价格20%、食品安全与追溯10%、售后10%。
   - 谁能在你的核心产季外仍稳定供货、且糖酸度波动小，谁就更靠谱。

一句话：**都乐更适合作为优先主力候选，洪九果品可以作为备选或比价对象，但必须先审核、试单、抽检，不建议单押。**
