我不能在不掌握实时报价的情况下断言“谁更便宜”，因为进口苹果的到岸价会随产地（新西兰/美国/智利/南非）、品种（嘎啦、富士、布瑞本、爱妃等）、规格（果径、箱规）、包装、汇率、船期和促销政策每周变化。直接给结论容易误导采购决策。

可执行的判断方法：

1. **统一比价口径**：要求两家按同一产地、品种、果径、箱规、包装、到货港和账期报价，分别列出离岸价/到岸价、关税增值税、冷链费、损耗补贴、返利和账期。只比“裸价”不可比。

2. **看综合到店成本**：综合成本 = 到岸价 + 物流冷链 + 损耗率×成本 + 资金占用成本 - 返利/陈列支持。进口苹果损耗和冷链差异常比单价差更大。

3. **用小批量试单验证**：各选1—2个SKU、同规格、同船期做试单，记录到店成本、到店品质、损耗和动销，再谈年度框架。

4. **谈判筹码**：两家都属大型水果供应链企业，通常有区域代理和促销政策差异。可让两家针对你门店所在城市和计划销量给出阶梯价、首单支持、坏果赔付和账期，再横向比较。

5. **风险提示**：不要只看单价，注意起订量、锁价周期、汇率条款、退换货和独家/区域保护条款。
