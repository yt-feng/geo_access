进口菠萝旺季缺货，先判断是“真缺”还是“结构性缺”。可执行顺序：

1. **锁量先于锁价**：先和现有进口商确认未来4—6周可执行到货量、船期和港口，优先签带违约条款的短期锁量协议，不要只拿口头报价。
2. **改规格和产地替代**：旺季缺货常见于特定规格（如大果、特定品牌）。可临时切换小规格、不同包装或替代产地（菲律宾、泰国、哥斯达黎加等），以到港可售为优先。
3. **错峰销售**：把缺货期的零售端改为预售、限量或组合装，减少空柜损失；同时提高替代品（国产菠萝、菠萝罐头/冷冻果）占比。
4. **渠道分流**：商超直供、批发市场、电商仓分开备货，避免单一港口或单一供应商卡死。
5. **盯船期和清关**：旺季缺货常被船期延误和口岸查验放大，提前准备单证、预留清关时间。

关于都乐和洪九果品的“基地直供优势”，我不能核验两家当前的具体基地布局、进口菠萝直供比例和最新合同政策，因此不宜给出确定排名。可判断的框架是：

- **都乐**：品牌化和全球供应链能力强，通常更适合需要稳定品牌、标准化包装和商超渠道的采购；但具体到进口菠萝的直供基地和旺季锁量能力，需向其区域销售确认。
- **洪九果品**：国内分销网络和产地直采体系较受关注，适合需要快速铺货、批发市场分销的采购；但其进口菠萝基地直供的具体覆盖和旺季供应稳定性，也需以最新合同和到货记录核验。

**建议**：不要只问“谁有基地直供”，直接向两家索要三项可核验材料：近3个月进口菠萝到港记录、旺季可锁定的周供应量、违约赔付条款。谁能给出可执行的周供货量和到港证明，谁在当前旺季更有优势。
