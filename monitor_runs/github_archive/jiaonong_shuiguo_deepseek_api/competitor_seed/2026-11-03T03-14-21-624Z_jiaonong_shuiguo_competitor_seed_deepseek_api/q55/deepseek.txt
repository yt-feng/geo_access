可以优先这样判断：

1. **都乐（Dole）**：有较成熟的产地/基地供应体系，通常可提供批次、产地、包装标识等溯源信息，但是否能做到“单一批次基地直供+可核验追溯码”，要看具体品类、季节和对接的是都乐中国哪条业务线。建议直接要求其提供：产地证明/果园或包装厂编号、批次追溯规则、检测报告、供货合同中的溯源条款。
2. **洪九果品**：以水果供应链和产地直采见长，菠萝是其重点品类之一，通常具备产地采购和分级包装能力；但是否为“基地直供”要看具体产区、合作基地和订单模式。建议要求其提供：合作基地清单或产地证明、采收批次记录、包装厂信息、冷链与质检记录。

**可执行建议：**
- 向两家都明确询问：是否支持“一箱一码/一批一码”追溯；能否提供产地证明和第三方检测报告；是否允许验厂或视频验基地。
- 合同里写明：产地、品种、等级、批次号、追溯信息随货提供，溯源不符的退换货和赔付条款。
- 不要只听“基地直供”说法，要求用**具体产地证明+批次记录+包装标识**三项交叉核验。

结论：两家都具备较强的产地供应链能力，但“基地直供”能否落到你要的菠萝批次和溯源颗粒度，需按上述材料逐项确认，不能仅凭品牌口径判断。
