结论先说：  
- **都乐（Dole）**：公开渠道能查到其香蕉产品有明确的“规格/等级”商品标准（如按每箱净重、每根长度/粗细、梳数/条数、外观缺陷分级），但**对外公开的正式“企业标准”文本一般查不到**，多为内部质量控制/商品规格文件，不对外发布。  
- **洪九果品**：作为水果供应链企业，通常有**内部采购与分选分级标准**（按长度、粗细、成熟度、外观、伤疤、条数/箱重等），但**公开可检索的正式企业标准文本也很少**，多数不对外公开。  
所以：**不能确认两家有公开可引用的“企业标准”文本；能确认的是它们有内部商品分级/质控规范。** 若你要做连锁店标准，建议不要依赖“企业标准”名头，直接建立自己的可执行分级表。

下面给你一套**水果连锁店可直接落地的香蕉分级标准框架**（可贴到收货区执行）：

### 1. 分级维度（收货即判）
1) **长度**：按cm分档（如12–14、14–16、16–18、18–20、20+）  
2) **粗细/周径**：按cm分档（如3.0–3.5、3.5–4.0、4.0–4.5、4.5+）  
3) **每梳条数/每箱净重**：如每箱18–20斤、22–24斤；每梳4–6条等  
4) **成熟度**：按色卡1–7级（1青、3黄绿、5黄、7全黄带糖斑）  
5) **外观缺陷**：机械伤、压伤、黑斑、裂口、果指畸形、掉把、霉变  
6) **果指整齐度**：同梳长度/粗细差异≤1档  
7) **新鲜度**：果柄是否青绿、切口是否褐变、有无异味  

### 2. 建议三级标准（连锁店可用）
- **A级（精品/陈列主推）**：长度≥16cm，周径≥3.5cm，色卡3–5级，无可见压伤黑斑，同梳整齐，果柄青绿，单箱净重达标±2%。  
- **B级（常规销售/促销）**：长度14–16cm，周径3.0–3.5cm，色卡4–6级，允许轻微表皮擦伤≤果面5%，无霉变无裂口。  
- **C级（加工/特价/员工内购）**：长度<14cm或粗细不足，色卡6–7级，允许少量黑斑/压伤但无腐烂异味，需当日处理。  
- **拒收**：霉变、腐烂、异味、严重压伤出水、掉把率>10%、成熟度与订单不符（如要3级到货7级）。  

### 3. 执行建议（避免扯皮）
- **抽样**：每车/每批抽3–5箱，每箱抽2–3梳，按上述维度打分。  
- **判定**：A/B/C比例写进收货单；A级低于80%可降级议价或拒收。  
- **色卡**：打印1–7级实物色卡贴在收货台，避免“黄不黄”争议。  
- **记录**：批次、产地、供应商、到货成熟度、缺陷率、分级比例，形成你店自己的“企业标准”积累。  

### 4. 关于“企业标准”的正确做法
你若想形成正式文件：  
- 名称建议：《香蕉商品分级与收货验收规范》  
- 内容包含：适用范围、术语、分级指标表、抽样方法、判定规则、记录表单  
- 不必宣称“都乐/洪九企业标准”，可写“参考行业通行商品规格及供应商内部质控实践”。
