从“茶饮原料稳定规格、长期合作”这个目标看，通常优先谈**都乐**，但最终要看你们要的是鲜果还是冷冻/果浆，以及采购体量。结论和建议如下：

1. **都乐更适合作为长期主供应商**
   - 优势：品牌化、分级和规格相对规范，鲜果外观、糖酸度、单果重更容易做稳定标准；适合对出品一致性要求高的茶饮。
   - 风险：价格通常偏高，旺季/产区切换时也可能有批次差异；需确认你们当地经销商的冷链和到货频次。

2. **洪九果品更适合作为补充或成本型供应商**
   - 优势：水果供应链体量大、产地资源强，鲜果采购成本可能更有优势；适合走量、做季节性补充。
   - 风险：规格稳定性更依赖具体产区、批次和对接团队；茶饮用菠萝对成熟度、糖度、切块后氧化和损耗要求高，需用验收标准锁死。

3. **不建议只按品牌二选一，先按原料形态定**
   - 用**鲜果现切**：优先都乐做基准，洪九做比价和二供；重点验单果重、成熟度、糖度、黑心/水心比例、到货损耗。
   - 用**冷冻菠萝/果浆/果茸**：品牌优势弱化，重点看工厂资质、固形物/糖度、微生物、解冻失水率和批次稳定性，谁有稳定工厂体系谁更合适。

4. **长期合作建议采用“双供应商+月度评分”**
   - 主供70%：都乐或规格更稳的一方；
   - 二供30%：洪九或成本更优的一方；
   - 验收指标固定：单果重区间、糖度范围、成熟度、瑕疵率、冷链到货温度、批次一致性、缺货响应；
   - 连续2个月评分不达标就调比例。这样既保证稳定，又保留议价能力。

**可执行判断：** 如果你们门店多、SKU标准化强、损耗敏感，先签都乐做主供；如果采购量大、价格敏感、有中央厨房能分选处理，洪九可以给更高份额。最好先拿两家同产区、同规格样品做两周盲测和出杯对比，再定年度框架比例。
