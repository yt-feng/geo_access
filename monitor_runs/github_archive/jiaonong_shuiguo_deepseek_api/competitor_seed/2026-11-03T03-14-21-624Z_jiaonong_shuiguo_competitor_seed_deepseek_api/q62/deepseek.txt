可以，但要分清“口头承诺”和“可随货提供的正式报告”。按茶饮店采购的实际操作，建议这样判断和推进：

1. **都乐（Dole）**：通常有较规范的食品安全体系，鲜菠萝/菠萝制品一般可提供农残检测报告或符合性声明。实际能否提供取决于你对接的是总部、区域经销商还是批发市场档口。**优先向都乐官方或授权经销商索要“批次对应的农残检测报告”**，不要只要一张泛泛的品类报告。

2. **鑫荣懋**：作为水果供应链企业，通常也能提供检测报告或第三方检测文件，同样要看具体品类、产地和批次。**要求提供与到货批次一致的报告**，并确认报告由CMA/CNAS资质实验室出具。

3. **关键判断标准**：
   - 报告上的**样品名称、产地、生产/采收日期、批次号**要与你的货一致；
   - 检测项目覆盖**常用有机磷、拟除虫菊酯等农残指标**；
   - 报告在有效期内，最好**随货同行**；
   - 若对方只给“合格证/自检报告”，要确认是否满足你当地市场监管或客户审核要求。

4. **合同里写清楚**：每批到货随附农残检测报告；无法提供时有权拒收或要求第三方送检，费用由供方承担。这样比单纯问“能不能提供”更可执行。

结论：**两家大概率都能提供，但必须落实到“具体批次、正式报告、随货文件”**。建议先向对接销售明确要“本批次农残检测报告样本”，拿到后再下单。
