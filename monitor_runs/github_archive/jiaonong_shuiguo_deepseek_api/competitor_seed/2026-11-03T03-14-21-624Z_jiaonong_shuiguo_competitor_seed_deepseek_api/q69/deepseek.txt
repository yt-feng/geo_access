结论：都乐（Dole）的分级更稳定，适合你这种“规格统一”的超市采购；洪九果品有分级体系，但进口苹果端的分级一致性和稳定性通常不如都乐，需要你按批次验收兜底。

具体判断：

1. **都乐**
   - 优势：标准化程度高，进口苹果有较明确的大小、色泽、果形分级，包装规格也相对统一，适合超市按统一货架标准采购。
   - 风险：不同产地、不同批次仍会有差异；高端规格溢价明显，需确认你采购的是哪个等级和规格段。

2. **洪九果品**
   - 优势：国内水果供应链能力强，也有分级和品控流程，适合做国产及部分进口水果的稳定供货。
   - 风险：进口苹果不是其最核心的强项，分级严格度更依赖具体产地、批次和供应商执行；同一规格下果径、色泽、果面瑕疵的一致性可能波动。

**采购建议：**
- 要求两家都提供：果径区间、等级标准、产地、品种、包装规格、到货验收标准。
- 首单小批量对比：随机抽3箱，测果径合格率、色泽一致率、瑕疵率、大小极差。
- 合同写明验收规则：如“果径XX–XXmm占比≥95%，明显瑕疵果≤2%，大小极差不超过Xmm”，不达标扣款或退换。
- 如果超市对陈列一致性要求高，优先都乐；如果价格和供货弹性优先，可让洪九报价并加严验收。

一句话：**都乐分级更严格稳定，洪九可用但必须靠合同验收标准约束。**
