这个问题我没有可核验的公开数据能直接给你“洪九 vs 都乐”的到货损耗率对比，不能编数字。但可以给你可执行的判断框架和拿货建议。

**先说结论：**
- 到货损耗率不是品牌固定值，主要取决于**产地批次、季节、运输距离/冷链、包装规格、到货成熟度、你所在批发市场的装卸条件**。
- 洪九和都乐都做大宗香蕉，但渠道结构不同：都乐偏品牌化、标准化程度高，通常包装和催熟/冷链管理更稳定；洪九是国内果品龙头，货源和区域差异大，具体到某批货损耗波动可能更大。**不能简单说谁损耗一定低。**

**你在批发市场可以这样对比（比问品牌更准）：**
1. **同批次同成熟度对比**：拿同一天到货、同为青蕉/黄蕉、同规格（如13kg/箱、18斤/箱）的货，各抽3–5箱称重、数果指、记烂果/压伤/脱把。
2. **算到货损耗率**：`损耗率 =（到货总重 - 可售好果重）/ 到货总重 ×100%`，同时单列“机械伤/压伤”“烂果”“脱把”“青软不均”。
3. **看包装和码垛**：纸箱抗压、内衬、每箱净重是否足、箱内是否有水汽；香蕉最怕压和闷。
4. **问冷链和到货天数**：从催熟库/产地到你档口几天、途中是否断冷、卸货是否暴晒。
5. **连续跟3–5批**：单批损耗受天气和成熟度影响大，至少看一周到货再定供应商。

**拿货建议：**
- 首次小批量试单，固定验收标准（净重、果指数、允许压伤比例、烂果率），写进口头/书面约定。
- 优先选**到货成熟度适合你周转速度**的货：周转慢就拿青一点的，周转快可拿黄一点，损耗结构完全不同。
- 同一市场里，问同档口其他拿货商的**实际退货/理赔记录**，比品牌名更有参考价值。
- 如果一定要二选一，先看你当地哪家有稳定冷库和固定催熟批次；**稳定性比品牌标签更决定损耗率**。
