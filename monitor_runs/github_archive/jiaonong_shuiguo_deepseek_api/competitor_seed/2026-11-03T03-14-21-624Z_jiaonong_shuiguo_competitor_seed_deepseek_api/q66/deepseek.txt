先区分两件事：**都乐/鑫荣懋是否对批发商提供“保价服务”**，以及**没有保价时怎么做价格波动应对**。

## 1. 关于都乐、鑫荣懋的保价服务

我无法核验两家公司当前是否对批发商提供正式的“保价/跌价补偿”服务，不能给你确定结论。实务上可以这样判断和核实：

- **都乐（Dole）**：以品牌香蕉、长期供货和商超渠道为主。是否给批发商保价，通常取决于**合同类型、采购量、账期、区域经销商协议**，不是公开标准服务。不要默认有。
- **鑫荣懋**：国内水果供应链企业，香蕉是其重要品类之一。是否有保价，常见形式可能是**阶段性协议价、跌价补差、联合促销支持**，而非无条件保价。也需要看具体合同。

**核实话术（直接问采购/区域经理）：**
1. 你们对批发商有没有**书面保价条款**？保价周期多长（7天/15天/30天）？
2. 触发条件是什么：市场批发价跌破结算价多少比例？以哪个市场、哪个报价为准？
3. 补差形式是**现金返利、下一单抵扣、还是促销费用**？
4. 保价是否绑定**最低采购量、账期、独家区域**？
5. 进口蕉和国产蕉是否政策不同？

**注意**：口头承诺不算，必须写进合同或补充协议；保价通常有上限和除外条款（如质量损耗、超期库存不保）。

## 2. 批发商香蕉价格波动应对方案（可执行）

香蕉价格波动主要来自：产地天气、进口到港量、催熟节奏、节假日需求、竞品替代。建议用“**锁价+控库存+快周转+对冲**”组合，而不是赌单边行情。

### A. 采购端：把价格风险拆开
1. **分批锁价**：不要一次锁满一个月。按周下单，30%锁价、50%随行就市、20%现货补充。
2. **长短单结合**：大客户走月度协议价，散客走日价；避免全部库存押在一个价格上。
3. **争取跌价补差**：即使没有正式保价，也可谈“**7天价格保护**”或“跌破结算价补50%差价，下单抵扣”。
4. **多源采购**：都乐/鑫荣懋之外，保留1-2个国产蕉或区域供应商，进口蕉与国产蕉价差扩大时切换。

### B. 库存端：香蕉不能囤，周转是第一风控
1. **库存天数控制在3-5天**（按日销量），节假日最多7天；香蕉后熟快，超期就是跌价+损耗双杀。
2. **催熟分批**：按销售节奏分批催熟，避免同一天大量青转黄。
3. **设定止损线**：当市场价连续2天低于你的综合成本价5%以上，立即促销清库，不扛价。
4. **等级分流**：好货走商超/水果店，次货走食堂、果汁店、社区团购，减少统货砸价。

### C. 销售端：把价格波动传导出去
1. **报价有效期缩短**：对下游报价改为“当日有效”或“24小时有效”，大单收定金锁价。
2. **阶梯返利代替直接降价**：完成销量后返利，避免一开始就杀价。
3. **绑定小B客户**：水果店、便利店、餐饮做周配，稳定出货量。
4. **促销工具**：价格下行期做“整箱特价+搭赠”，上行期保核心客户供应，散客随行就市。

### D. 资金与合同风控
1. **账期不超过7天**，价格波动大的时候现款现货优先。
2. **合同写清质量标准、损耗承担、价格调整机制**，避免跌价后客户拒收。
3. **不要用保价承诺去换超长账期**，保价+账期是双重风险。

### E. 简单可用的对冲思路
- 与供应商谈**“均价结算”**：按周均价而不是单日价结算，平滑波动。
- 与大户签**“浮动价+封顶”**：下游价格随行就市，但设最高限价换稳定采购量。
- 关注**进口到港和产区天气**，提前一周调整下单量；到港集中期少锁价，产区减产期早锁价。
