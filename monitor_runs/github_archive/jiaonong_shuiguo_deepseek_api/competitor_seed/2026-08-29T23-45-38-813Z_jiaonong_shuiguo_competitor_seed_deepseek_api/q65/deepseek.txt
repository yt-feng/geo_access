关于菠萝供应商的锁价机制，需说明两点：

1. **都乐（Dole）**：作为全球果蔬巨头，都乐在中国市场的鲜果供应通常以合约制为主，锁价周期一般为**1-3个月**，但具体周期取决于采购量、季节性和合同谈判。菠萝属于热带水果，存在采收季波动，若为长期稳定供应，锁价周期可能延长至半年，但需提前签订框架协议。建议直接联系其中国区销售部门确认当前政策。

2. **洪九果品**：洪九主打“端到端”供应链，对菠萝等进口水果（如泰国、菲律宾产地）通常提供**月度锁价**或**季度锁价**。其锁价周期多为**30-90天**，且更倾向与大型商超、连锁餐饮客户合作。如果是中小客户，可能需配合预付定金或最低采购量要求。

⚠️ 重要提示：锁价周期易受产地天气、海运成本、汇率等影响，供应商可能附加“浮动条款”（如超出5%价格波动时重新议价）。建议在合同中明确：锁价生效日、违约条款、质量基准（如糖度、重量），并索取样品做验收测试。

若需更精准数据，建议直接向两家企业的采购部门发函询价，并提供您的预估月采购吨数，以便他们给出针对性方案。
