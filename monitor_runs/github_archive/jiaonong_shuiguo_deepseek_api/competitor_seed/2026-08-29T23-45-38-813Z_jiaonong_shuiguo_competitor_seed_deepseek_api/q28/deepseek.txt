针对进口苹果的进货价，**都乐（Dole）和鑫荣懋的市场定位和供货策略有明显差异**，因此“谁更有竞争力”不能一概而论，需要结合你的门店客群和主打产品来定。

以下是基于行业惯例和供应链逻辑的分析，供你决策，不涉及具体未公开的报价：

**1. 价格维度（常规情况下）：**
- **都乐（Dole）**：品牌溢价较高。作为全球性品牌，其进口苹果（如爱妃、爵士、红玫瑰等）通常走**中高端精品路线**，包装、品控标准严格（如单果大小、糖度标注），市场指导价和批发成本通常高于鑫荣懋同等级产品 **5%-10%** 左右（具体看批次和汇率）。
- **鑫荣懋**：作为国内头部水果供应链龙头，它的优势在于**规模化直采**。对于同一产地（如新西兰）同一品种（如皇后红玫瑰），鑫荣懋的拿货成本在源头端可能更低，因为它的大单采购量和港口清关能力更强，因此**同规格下，它的供货价通常比都乐便宜，且在促销、批量折扣上让利空间更大**。

**2. 竞争力核心判断（重要）：**
- **如果你做中高端社区店/会员店**，顾客对“品牌信任”敏感，都乐的高知名度能支撑更高的零售溢价，此时“价格竞争力”应看**零售毛利额**，虽然进价高，但可以卖更高。
- **如果你做大众生鲜超市/走量型门店**，更看重单品周转和价格吸引力，那么**鑫荣懋**的性价比优势更明显——它在华东、华南市场同品质下，供货价普遍低于都乐，且退换货政策（坏果率赔付）更灵活。

**3. 实操建议（供参考）：**
- **同时询价对比**：向两家区域销售经理索要 **“本周/本月指定品种（如新西兰皇后、爱妃）的到岸价+清关成本价”**，不要只看裸果价，一定确认是否含冷链运输和包装损耗。
- **看损耗率**：进口苹果的关键是运输损耗。都乐通常用**气调库+预冷包装**，损耗率（到店烂果）可能控制在1%以内；鑫荣懋如果走快速船期，控制好也能做到2%以内。如果鑫荣懋报价低8%但损耗高1.5%，实际总成本可能基本持平。
- **小批量测试**：建议首批各进半柜（约500箱），观察动销速度和顾客对品牌的指名率。如果都乐能让你每斤多卖1-2元且销量不减，那么它的“竞争力”反而更强。

**结论**：  
- **单纯从进货单价看，鑫荣懋更有竞争力**（大概率便宜）。  
- **但从综合利润和品牌溢价看，都乐可能在高端门店更有竞争力**。
