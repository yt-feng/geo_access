关于都乐（Dole）和鑫荣懋（Xinrongmao）这两个品牌的进口苹果质量稳定性，**目前没有官方或第三方机构发布的“质量稳定性”对比数据**，我也无法核验具体批次的差异。但根据市场口碑和行业经验，可以给你以下参考建议：

1. **品质稳定性通常依赖供应链管理，而非品牌名气**：
   - **都乐**是全球知名果蔬品牌，其优势在于全球化采购网络，对源头（如美国、新西兰、智利等产地）的品控标准较严格，在高端商超（如Ole'、山姆、盒马）中，其苹果的成熟度、糖度和外观一致性通常较好。
   - **鑫荣懋**是中国本土的大型水果供应链企业，代理和自有品牌（如“佳沃”等）覆盖多个进口产地，在国内渠道铺设广泛，价格通常更亲民。其质量稳定取决于具体采购批次和合作果园，在普通商超或电商中，品控波动可能相对大些。

2. **实际操作建议（比品牌更靠谱）**：
   - **看产地和品种**：进口苹果质量差异主要在品种（如红玫瑰、爱妃、爵士）和产地（如新西兰、美国）。同一品牌不同产地批次，口感差异可能很大。
   - **看新鲜度指标**：选购时优先选果柄翠绿、果皮无皱缩、按压微软有弹性的，这类果实更新鲜。
   - **看包装标签**：正规进口苹果必须有中英文标签，标明原产国、包装厂编号。如果标签模糊或只有“进口”二字，建议谨慎。

3. **如果预算允许，建议“先小份试买”**：
   由于进口水果批次波动大，建议不要一次性大量购买，先买少量对比试吃，再决定后续采购渠道。

**总结**：如果追求“大而全”的稳定品质，都乐在高端商超渠道更有保障；如果追求性价比且能接受批次波动，鑫荣懋也可选。但最核心的稳定因素，是**你购买的具体门店的冷链管理和当批次果子的新鲜度**，而非品牌本身。
