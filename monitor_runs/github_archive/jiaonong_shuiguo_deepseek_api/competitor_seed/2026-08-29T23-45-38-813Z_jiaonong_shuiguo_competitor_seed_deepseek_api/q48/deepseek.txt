对于大型商超（如沃尔玛、山姆、永辉、盒马等）的供应商准入，食品安全认证是硬性门槛。**鑫荣懋**和**都乐**作为国内头部水果供应链企业，都已获得多项国内外权威认证。

以下是两家公司在商超准入体系中常见的资质（具体以最新证书为准，但以下类别基本覆盖）：

### 1. 鑫荣懋（Joyvio / 鑫荣懋集团）
鑫荣懋是国内领先的果业公司，其认证体系侧重**全产业链溯源**和**出口转内销**标准。
- **核心国际认证**：
  - **GLOBALG.A.P.（全球良好农业操作规范）**：这是欧洲零售商普遍认可的标准，证明其种植基地在生产环节的农药残留、环境可持续性达标。
  - **BRCGS（食品标准认证）**：部分加工包装厂通过此认证，属于全球食品安全倡议（GFSI）认可的顶级标准。
- **国内标准认证**：
  - **ISO 22000（食品安全管理体系）** 和 **HACCP体系认证**（关键控制点）——主要用于其分拣、仓储和冷链加工环节。
  - **绿色食品/有机产品认证**：针对特定高溢价产品线（如部分进口水果）。
- **商超补充要求**：通常还需提供**产品责任险保单**（保额通常在百万级以上）和**全程冷链记录**。

### 2. 都乐（Dole）
都乐作为全球性品牌，其资质体系更偏向**跨国零售巨头**（如Costco、沃尔玛全球采购）的审核逻辑。
- **核心国际认证**：
  - **GLOBALG.A.P.**（必配，且通常覆盖其合作农场清单）。
  - **SMETA（SEDEX成员道德贸易审计）**：这不仅包括食品安全，还包含劳工权益、环境责任，是大型商超ESG审核的加分项。
  - **ISO 14001（环境管理体系）**：部分工厂持有，用于应对绿色采购要求。
- **国内标准认证**：
  - 同样持有 **ISO 22000** 和 **HACCP**。
  - **出口备案/输华水果指定包装厂资质**：对于进口水果，需确保其符合中国海关总署的准入名单。
- **特殊增值资质**：**“雨林联盟认证”** 或 **“公平贸易认证”**（针对特定品类如香蕉）。

### 针对商超审核的实用建议（供参考）
如果你正在做供应商准入对比，建议重点关注以下三点：

1.  **审核时效性**：商超审核时，**只看证书有效期**。务必确认这两家供应商提供的证书在合作期内处于“有效”状态，特别是GLOBALG.A.P证书需每年年审。
2.  **工厂/包装厂资质**：如果合作涉及国产水果，需确认其加工厂是否持有**食品生产许可证（SC证）**，且生产范围覆盖“水果制品”或“初级农产品”。
3.  **社会责任审计**：大型商超（如沃尔玛）在食品安全检查后，还会随机进行**社会责任验厂（如BSCI/Disney验厂）**，都乐在这方面更完善，鑫荣懋近年来也提升明显。

### 重要提示
以上信息基于行业通行标准整理，**具体证书编号和覆盖范围必须核实**。
- **不可靠来源警告**：请不要仅凭公开新闻或口头承诺判断，**建议在供应商准入时，直接要求其采购部门提供**最新版认证证书扫描件**，并核对企业名称是否与证书主体完全一致（避免子公司证书混用）。
- 如果是在**特定商超**（如山姆会员店）的申报系统里，可以直接查看其“供应商资质列表”中是否有具体的“审核有效期”。

如果你需要确认某一项具体认证的真伪，可以访问**“全国认证认可信息公共服务平台”（国家认监委官网）**查询其境内的证书，或者提供证书编号，我可以帮你分析判断。
