针对礼品团购客户指定进口品牌的需求，**都乐（Dole）和佳沛（Zespri）** 在市场上都很受欢迎，但适用场景和受众略有差异。以下是具体分析和建议：

### 1. 核心差异对比
| 维度 | 都乐（Dole） | 佳沛（Zespri） |
|------|--------------|----------------|
| **主打品类** | 以香蕉、菠萝、蓝莓、草莓等**多品类水果礼盒**为主 | 专注**奇异果（猕猴桃）**，有黄心、绿心等 |
| **品牌认知** | 综合水果品牌，大众认知度高 | 奇异果专属高端品牌，科技感强 |
| **礼盒视觉** | 色彩丰富，适合节日走亲访友 | 包装简约精致，显得更有档次 |
| **受众定位** | 家庭日常、大众客户 | 健康人群、商务送礼、注重品质 |

### 2. 针对礼品团购的建议
- **如果客户注重“健康科技感”或送商务客户**：**首选佳沛**，因为其奇异果定位清晰，单价高，包装精致，容易体现“用心挑选”。
- **如果客户注重“丰富果品”或家庭送礼**：**首选都乐**，因为一盒里可以有多种进口水果，显得实惠且大众接受度广。
- **如果客户预算较高且想体现“稀缺性”**：可以推荐**佳沛阳光金果礼盒**（如超大果），或**都乐“顶奢”混合果篮**（含菠萝+蓝莓+车厘子等高价值果）。

### 3. 核心判断依据（供你向客户解释）
- **佳沛奇异果礼盒**：果肉食用率高、营养价值明确（富含维C），适合强调“健康”的客户。
- **都乐礼盒**：品类灵活，可定制组合（如香蕉+苹果+橙子），适合需要“大面积摆台”或“数量多”的团购。

### 4. 实操建议
- 如果客户未明确具体甜度偏好，**推荐佳沛黄心奇异果**（甜度高，大众接受度强）。
- 确认交货时建议索要**检疫证明和中文标签**，避免海关/海关物流问题。
- 可让客户提供预算范围，帮你进一步锁定具体规格（如24头、30头等）。

**一句话总结**：  
- 送商务伙伴/强调品质 → **佳沛**更受欢迎；  
- 送家庭客户/追求丰富种类 → **都乐**更受欢迎。
