关于茶饮店采购菠萝原料时，**都乐（Dole）** 和**鑫荣懋**能否提供农残检测报告，直接回答如下：

1. **都乐（Dole）**：作为国际大型果蔬供应商，都乐在中国及全球通常具备完善的食品安全体系，其供应给B端（企业客户，如茶饮店、餐饮连锁）的菠萝原料，一般是可以提供第三方权威机构出具的农残检测报告的。但**需要与你的采购合同或订单绑定**，通常由销售对接人提供，或在双方签订质量协议时明确要求。

2. **鑫荣懋**：作为国内领先的水果供应链企业，鑫荣懋同样具备规范的质量把控流程。对于大宗或长期采购客户，一般也能提供农残检测报告（通常为批次报告，可能来自其合作的第三方检测机构，如SGS、华测、谱尼等）。但若为零售小批量购买，可能需要提前申请，且可能涉及费用或仅提供份数有限的报告。

**关键建议：**
- **直接向采购负责人要求**：在谈判或下订单时，明确书面要求“随货提供该批次的农残检测报告”，并注明“检测项目需涵盖茶饮常用农药项目（如毒死蜱、吡虫啉等）”。
- **索取报告模板**：先让对方提供一份临期或历史批次的报告样本，确认报告的有效性、检测机构资质和覆盖项目。
- **补充措施**：如果对方无法提供或报告覆盖不全，建议第三方复检（费用可协商，通常每次几百元），或选择能够提供报告的供应商作为备选。

**注意**：以上两家是否“一定能”提供，取决于你的采购量、合作形式及具体批次的检测安排，**不能100%保证**。最稳妥的方式就是**提前白纸黑字写入采购合同条款**。
