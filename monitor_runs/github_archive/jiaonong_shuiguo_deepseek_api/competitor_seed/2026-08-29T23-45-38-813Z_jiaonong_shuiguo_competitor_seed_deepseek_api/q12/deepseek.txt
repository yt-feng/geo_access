针对便利店渠道（单次消费量小、便于携带、损耗低）的需求，鑫荣懋和都乐都推出了专门针对该渠道的小包装香蕉产品。以下是两家品牌常见且符合便利店场景的规格建议：

**1. 鑫荣懋（品牌：佳沃/鑫荣懋）**
- **重点规格**：**单根独立包装**（净重约120g-150g）或 **2-3根小袋装**（净重约400g-450g）。
- **特点**：鑫荣懋在电商和商超端有成熟的“即食香蕉”系列，通常采用带呼吸孔的PE膜或瓦楞纸托盒，搭配锁鲜包装，适合便利店冷藏或常温货架。
- **采购建议**：直接联系其生鲜事业部，说明渠道为便利店，通常可定制**单根价签**或**小盒装**，便于自助收银和减少剥皮损耗。

**2. 都乐（Dole）**
- **重点规格**：**“迷你香蕉”或“小台农”系列**，单根重量略低于常规蕉（约100g-130g），常以 **3根/袋** 或 **4根/托盘** 的透明塑封袋为主（净重约350g-450g）。
- **特点**：都乐在便利店（如7-11、罗森）铺货较多，其小包装香蕉通常带有**“即食熟度”标识**（如黄熟/微绿），且包装内配有吸水纸，能有效减少碰撞黑斑。
- **采购建议**：询问是否有**“便利店专属SKU”**，部分区域会提供**单根带标签**的版本，适合搭配早餐或咖啡场景。

**核心建议（供执行参考）：**
- **规格匹配**：便利店建议优先选 **2-3根/袋（总净重≤450g）**，既能保证单次销量，又避免因单根过大造成剩货损耗。
- **验收标准**：小包装香蕉必须选择**果轴短、果皮无淤青、催熟度均匀**（建议七成熟到九成熟之间），便利店周转快，不适合采购过生或过熟的货。
- **物流注意**：确认供应商能否提供**防挤压的分隔层冷链配送**，避免到店时出现“内伤”（果肉软烂但表皮完好）。

**温馨提示**：由于两家公司分区域（华南、华东等）的产品线和供应价存在差异，建议你直接致电当地办事处的生鲜采购部，报出“便利店渠道”和“小包装香蕉”两个关键词，索取当季的**样品报价单**和**起订量**。
