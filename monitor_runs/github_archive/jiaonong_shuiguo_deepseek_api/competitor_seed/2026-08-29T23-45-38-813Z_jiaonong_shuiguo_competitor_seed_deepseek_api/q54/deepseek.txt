采购进口苹果时，对**都乐（Dole）**和**鑫荣懋（Joywing Mau）**这两个品牌的产地溯源，核心逻辑是一样的：**从包装标签→官方验证→抽查实物→追溯文件**，层层递进。

以下是具体的操作步骤和查验方法：

### 第一步：看包装与标签（最直观，先排除低仿）

1.  **中文标签（必查）**：根据中国法规，进口食品必须有中文标签。
    -   **都乐**：标签上会明确标注“原产国”，常见的是**美国（华盛顿州）、新西兰（霍克湾、尼尔森）、智利、南非**。如果标注的是“中国山东”或“陕西”，那一定是国产冒充或分装不规范的。
    -   **鑫荣懋**：鑫荣懋是**中国公司**（深圳企业），它主要是进口商和品牌运营商。它的标签上通常有**“原产国”**（例如：智利、新西兰、美国、澳大利亚）以及**“经销商：鑫荣懋（深圳）或 鑫荣懋（上海）”**。如果只写“鑫荣懋”而没有原产国，且价格便宜，需警惕。
2.  **外包装箱信息**：
    -   **都乐**：正规进口纸箱外会有完整的**英文唛头**，包含出口商、品种（如：Red Delicious）、包装厂代码（如：美国华盛顿州常见的Ex. pkt. 1053等）。
    -   **鑫荣懋**：多为“鑫荣懋”自有品牌箱（Joywing Mau），箱体上通常印有**国外果园农场代码（ORCHARD CODE）**和**包装厂代码（PACK CODE）**。这些代码是核心验证点，因为国外农场有严格的注册制度。

### 第二步：官方渠道验证（防伪核心，最重要）

这是区分正品与高仿的关键步骤。

1.  **都乐（Dole）**：
    -   **溯源系统**：都乐在中国市场普遍推行了**“二维码追溯”**。在水果的贴标或外箱上找**带“溯源”字样的二维码**。
    -   **查验方式**：扫描后，应进入**都乐官方微信公众号或官方小程序**，输入或扫描物流码/追溯码，可查询到**采摘日期、包装日期、出口口岸、报关单号（部分）**等详细信息。
    -   **注意**：如果二维码跳到的是**个人微信、随机网页或第三方电商店铺**，极有可能是假冒。
2.  **鑫荣懋（Joywing Mau）**：
    -   **源头对接**：鑫荣懋作为国内进口商，它并不像都乐那样有专属的全球种植体系，它更多是**包销国外基地**（如智利车厘子、新西兰奇异果等）。
    -   **查验方式**：重点看其**“进口食品溯源码”**（即中国海关监管的“溯源码”，通常贴在最小销售单元或外箱上）。
    -   **查询渠道**：打开**海关总署或地方海关的官方微信公众号（如“掌上海关”）**，找到“食品溯源”功能，输入溯源码，系统会显示对应的**《入境货物检验检疫证明》**信息（包含收货人、启运地、入境口岸、品名、规格、批次号）。**如果包装上没有这组溯源码，或扫码后提示“查无此码”，即为非正规渠道货。**

### 第三步：索取与核对《入境货物检验检疫证明》（采购合规的关键）

作为超市采购，**光看包装不够，必须留档纸质或电子版证明**。

1.  **向供应商索要**：要求供应商提供该批次苹果对应的**《入境货物检验检疫证明》**（海关出具）。
2.  **核对信息**：
    -   核对证明上的**“品名”**（如：鲜苹果）、**“原产地”**（智利/新西兰等）、**“生产日期/批次”**是否与**你采购的这批实物纸箱上的批次号一致**。
    -   **重点**：证明上的**“收货人”**必须是正规进口商（如鑫荣懋或都乐的国内分公司），如果收货人是一个你没听过的小贸易公司，且无法给出合理解释，建议谨慎。

### 第四步：物理特征抽查（辅助判断）

如果上述信息都对，可以抽查实物：

-   **都乐**：贴纸通常是**彩色印刷**，有立体感，撕下来贴纸背面有**断层（易碎）**或带有**唯一的序列号**。假冒的贴纸字体粗糙，容易完整撕下。
-   **鑫荣懋**：其代理的国外苹果（如新西兰品种），果把附近通常有红色或绿色的小贴标（原产国信息），且同一批次果实大小、颜色均匀度高。若大小差异极大，可能是混装拼箱，需警惕产地不纯。

---

### 采购实操建议（最省事的办法）

1.  **直接要求企业授权**：要求供应商提供**都乐（Dole）中国区**或**鑫荣懋**出具的**《经销商授权书》**（正本或彩印件）。没有授权的货源，十有八九是水货（走私）或假货。
2.  **防伪码优先**：**优先选择带“中国海关溯源码”或“官方防伪二维码”的产品**。如果没有溯源码，且价格比市场均价低20%以上，坚决不采购。
3.  **留档证据**：在采购入库时，拍下**《入境货物检验检疫证明》首页 + 外箱喷码特写 + 防伪标签特写**，三者存入档案，以备市场监督管理局抽查。

**补充说明**：由于进口水果的溯源系统会随海关政策和品牌方策略调整，建议在首次大批量采购前，**直接拨打包装箱上的“消费者服务热线”**（都乐和鑫荣懋都有400电话），报出箱号或批次号，客服会当场告知你该批货是否为其直供渠道，这是最权威、零成本的核验方法。
