大型商超（如沃尔玛、山姆、永辉、盒马等）对供应商的食品安全管理体系有严格准入要求，通常要求供应商具备**国际或国家级认证**。以下是鑫荣懋和都乐这两家主要水果供应商常见的认证情况：

---

### 鑫荣懋（Xin Rong Mao，中国果蔬行业龙头）
- **主要认证体系**：
  - **GLOBALG.A.P.**（全球良好农业规范）：覆盖种植、采收、包装环节的农业操作规范。
  - **BRCGS**（英国零售商协会全球标准，现为BRCGS）：针对食品包装、储存和分销的认证，商超认可度高。
  - **FSSC 22000**：食品安全管理体系认证，基于ISO 22000和HACCP基础。
  - **ISO 22000**：食品安全管理体系。
  - **中国有机认证**：针对部分有机产品线。
  - **HACCP认证**：关键控制点管理。
- 说明：鑫荣懋通常为其合作基地或自有包装中心申请上述认证，且可能针对不同SKU（如出口产品）额外满足进口国要求。

---

### 都乐（Dole，全球果蔬巨头）
- **主要认证体系**：
  - **GLOBALG.A.P.**：全球实施，覆盖农场端。
  - **BRCGS**：主要用于包装和配送中心。
  - **IFS Food**（国际食品标准）：欧洲商超常要求，都乐部分设施持有。
  - **ISO 22000**：部分工厂持有。
  - **HACCP**：普遍应用。
  - **雨林联盟认证**（Rainforest Alliance）：针对可持续农业，商超社会责任类要求。
  - **美国有机认证（USDA Organic）** 或 **中国有机认证**：视产品线而定。
- 说明：都乐作为全球企业，其文件通常能提供多国认证证书，以便进入不同市场零售渠道。

---

### 给你的实用建议：
1. **核对具体SKU**：同一公司的不同产品线（如香蕉、菠萝、蓝莓）可能使用不同基地，认证范围需以该批次产品为准。
2. **要求提供证书原件扫描件**：向供应商索要有效期内（通常在1-3年）的认证证书副本，并检查认证机构签字和证书编号。
3. **注意覆盖环节**：商超审核时，除认证外还会巡查冷链、物流、追溯系统，认证只是准入基础。
4. **动态更新**：认证会过期或升级，建议每季度向供应商索取最新状态。
