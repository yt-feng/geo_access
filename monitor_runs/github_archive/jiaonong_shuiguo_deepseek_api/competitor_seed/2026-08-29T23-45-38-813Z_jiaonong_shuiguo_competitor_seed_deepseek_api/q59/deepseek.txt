关于“都乐”和“洪九果品”的具体账期（如月结、周结），**属于企业内部商业政策，通常不公开披露**，且实际账期会因合作规模、采购量、信用资质、市场行情而有较大差异。

**给你的建议：**

1. **直接联系官方渠道**：  
   索要账期条件最有效的方式是联系其销售或大客户部门。  
   - **都乐（Dole）**：中国区主要通过经销商或直营大客户渠道供货，可在其官网找到“联系我们”或联系本地销售办事处。
   - **洪九果品**：国内头部水果供应链企业，主要面向B端（批发市场、零售渠道），建议通过其官网或客服电话获取区域销售经理联系方式。

2. **替代方案建议**：  
   如果你在找账期供应商，还可以考虑：
   - **本地水果批发市场**：老牌档口常有“先货后款”惯例（账期通常7-30天），可谈。
   - **集中采购平台**：如美团快驴、美菜网等（部分有账期政策）。
   - **产地直采合作社**：部分大型合作社支持部分账期，但需押金或保底量。

3. **沟通注意点**：  
   首次询价时，需明确告知你的采购量、采购频率、企业资质（如营业执照），并主动询问账期上限、押金比例、价格上浮条件。

如需精确数字，请直接致电其总部或区域经理，口头问询最易获得实际政策。
