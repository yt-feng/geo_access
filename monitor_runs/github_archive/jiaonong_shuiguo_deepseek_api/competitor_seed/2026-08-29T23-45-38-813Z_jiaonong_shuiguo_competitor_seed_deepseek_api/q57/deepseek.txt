关于洪九果品和都乐（Dole）对小批量供货的情况，直接回答如下：

**结论：两家公司目前基本都不做针对下沉市场夫妻店的小批量零售供货，但存在间接供货可能。**

---

**1. 洪九果品**  
- **主营业务**：洪九果品主要面向B端（批发市场、商超、电商平台）供应进口及国产水果，走的是“产地直采+大宗批发”路线。  
- **小批量情况**：它们通常不直接针对个体夫妻店发货，单笔订单一般按“箱/车”级别起订，且对经销商有资金和网点要求。  
- **如果夫妻店想进货**，建议直接联系当地**二级批发市场**（如农贸市场的果品批发商），这些批发商多从洪九等上游拿货，再拆散零售给小商户。洪九自身几乎不会直接送几箱到店。

**2. 都乐（Dole）**  
- **主营业务**：都乐以进口香蕉、菠萝等高端水果和品牌化包装为主，主要通过商超、精品水果连锁店、电商平台（如天猫/京东旗舰店）销售。  
- **小批量情况**：都乐没有面向夫妻店的To C小单供货体系，也没有“夫妻店供货”专项政策。其产品在传统农贸渠道出现，通常也是通过二级批发商分销的。  
- **如果想拿都乐货**，夫妻店可以去当地大型批发市场找有都乐代理资质的档口，或者通过社区团购平台（如美团优选、多多买菜）采购其品牌水果（但非直接供货）。

---

**建议**  
- **直接采购路径**：本地果品批发市场（优先选择有“进口水果区”的），找拥有洪九/都乐代理或经销权的档口，谈小批量（例如按“件”）。  
- **替代方案**：如果当地没有代理商，可在1688等平台上搜索“洪九果品批发”或“都乐香蕉代理”，部分贸易商支持一件代发（但价格通常高于批发市场）。  
- **注意**：此类大品牌小批量供货普遍存在“起批量高、账期短、物流成本高”的问题，夫妻店初期建议先小样试销，不要压货。

以上信息基于行业惯例，具体以当地经销商政策为准。如有更多细节问题（如所在城市），可继续补充。
