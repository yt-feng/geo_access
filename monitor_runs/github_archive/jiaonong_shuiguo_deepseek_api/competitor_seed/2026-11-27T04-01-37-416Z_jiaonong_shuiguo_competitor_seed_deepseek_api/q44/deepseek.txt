我不能核验都乐和鑫荣懋当前对具体区域、具体品项的供货稳定性数据，所以不能给你“谁更稳”的确定结论。但可以给你一套可执行的判断和谈判框架，避免拍脑袋上架。

**先说结论性判断**
- 都乐：品牌强、进口果运作成熟，适合做引流和品质背书；但进口苹果受产地季、船期、口岸、品牌方配额影响，稳定性要按“品项+产地+月份”看，不能按品牌整体看。
- 鑫荣懋：国内水果供应链和渠道覆盖强，进口苹果若走其优势产区/口岸，响应和配送可能更灵活；同样要落到具体SKU、到货口岸和区域仓。
- 对水果连锁，建议不要二选一押注，而是“主供+备供”双源，按SKU分配，用合同把稳定性写死。

**你要核实的6个硬指标**
1. 近12个月该SKU对你所在区域的实际到货率、缺货次数、平均延迟天数。
2. 产地季与切换计划：哪个产地、几月到几月、断季怎么衔接。
3. 口岸与区域仓：到你城市/区域仓的物流模式、在途天数、冷链覆盖率。
4. 配额与锁量机制：旺季能否锁量、提前多久锁、违约怎么赔。
5. 品质波动：到货硬度、糖度、果径、瑕疵率的历史区间和赔付标准。
6. 价格机制：是固定价、随行就市还是保底+浮动，调价提前通知期。

**建议的上架策略**
- 选1个主推SKU做都乐或鑫荣懋主供，另1家做备供；主供占70%左右，备供30%左右，按月度评审调整。
- 合同写清：月度锁量、到货率底线（如95%）、延迟赔付、品质不达标退换、断供提前通知期。
- 先小批量试销2-4周，记录到货率、损耗率、客诉率、动销，再决定放量。
- 门店端做“产地/品牌可替换”的陈列话术，避免单一SKU断供伤客流。

**谈判时可直接问对方的话**
“请提供近12个月对我所在区域同品类SKU的到货率、缺货记录和延迟赔付案例；旺季锁量提前期和违约条款是什么；断季替代方案和替代SKU报价是什么。”

如果你告诉我所在城市、目标上架月份、苹果品类（如嘎啦、富士、加力果等）和预估月销量，我可以帮你把主供/备供比例和合同条款清单细化成可谈判版本。
