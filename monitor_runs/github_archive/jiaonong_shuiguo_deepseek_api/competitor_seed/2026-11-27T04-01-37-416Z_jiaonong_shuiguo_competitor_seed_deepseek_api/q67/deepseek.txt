都乐（Dole）和洪九果品是否提供菠萝品牌营销素材，没有公开统一的“对外素材包”承诺，需按合作身份分别判断：

**1. 都乐（Dole）**
- 都乐有成熟的菠萝品牌资产（如金菠萝/金钻菠萝等品线），通常会对**经销商、商超、生鲜电商平台**提供产品图、主视觉、卖点文案、产地/品种介绍、部分视频素材等。
- 但一般不是无条件公开下载，而是通过**业务对接人/品牌市场部**申请，可能要求：
  - 已签订采购或合作合同；
  - 素材仅用于约定渠道和期限；
  - 使用前审核、不得修改品牌标识和宣称。
- 可执行动作：联系都乐对接的销售或市场人员，说明渠道、活动周期、使用场景（首页banner/详情页/直播/短视频/社群），索要“品牌素材使用授权+素材包”。

**2. 洪九果品**
- 洪九果品以水果供应链和批发分销为主，品牌营销素材的标准化程度通常低于都乐这类消费品牌。
- 是否提供素材取决于具体合作：**采购客户、渠道客户、联名/促销活动**可能拿到产品图、包装图、产地信息、检测/分级标准等；公开传播用素材一般需单独沟通。
- 可执行动作：向洪九业务负责人明确需求清单（产品白底图、场景图、短视频、卖点文案、授权范围），确认是否可提供及是否收费/需审核。

**建议直接这样问对方：**
> 我们计划在生鲜电商渠道做菠萝品牌营销，需使用贵司产品图、品牌视觉、卖点文案和短视频素材。请确认：①可提供的素材清单；②使用授权范围与期限；③是否需要审核；④是否收费；⑤素材交付格式和时间。

**判断结论：**
- 都乐：**较可能提供**，但需业务对接和授权，不是公开素材库。
- 洪九果品：**可能提供基础产品素材**，品牌营销级素材需具体谈，标准化程度较低。
- 若用于公开品牌宣传，务必拿到**书面/邮件授权**，避免商标和图片版权风险。
