都乐和洪九果品都有面向渠道的散装/称重货，但“社区团购小包装”能否直接拿到，取决于你对接的是哪一层渠道和是否要贴标分装。按可执行判断：

1. **都乐**
   - 都乐有散装香蕉、整箱香蕉和部分小规格预包装香蕉，常见于商超、水果渠道。
   - 社区团购小包装通常不是都乐标准零售SKU直接供给，更多是经销商/区域代理做分装，或团购平台定制小规格。
   - 你需要问对接的都乐区域经销商：是否有“散装称重香蕉”“小规格预包装/团购定制装”，以及最小起订量、是否允许二次分装贴标。

2. **洪九果品**
   - 洪九以香蕉、火龙果等品类起家，渠道端有整箱、散装称重和部分预包装规格，适合批发/商超/团购供货。
   - 社区团购小包装一般可通过洪九区域销售或经销商申请“小规格分装/团购装”，但要看当地仓配能力和起订量。
   - 重点问：是否支持按把/按份分装、能否贴团购标签、损耗和催熟状态怎么控、最小起订量和配送频次。

**建议你直接这样问供应商：**
- “有没有散装称重香蕉，适合社区团购按份分装的规格？”
- “最小起订量多少？是否支持代分装、贴标、按团购份数出货？”
- “到货成熟度是几号色？社区团购2-3天售卖窗口能不能匹配？”
- “破损、掉把、催熟不均的售后标准是什么？”

**结论：** 两家都有散装/称重渠道货，但“香蕉小包装”大概率要区域经销商或分装商来做，不是品牌方标准团购小包装直接供。先找当地都乐、洪九区域经销/代理确认分装和起订量，再决定是否自建分装。
