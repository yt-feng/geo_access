佳沛（Zespri）确实以奇异果为主，香蕉不是其核心业务。进口香蕉品牌建议按“渠道稳定性 + 品牌认知 + 损耗控制”来选，几个可优先考察的方向：

1. **都乐（Dole）**：进口香蕉里认知度高、渠道成熟，适合做商超和水果店标品，品控和供货相对稳定。
2. **金吉达（Chiquita）**：国际香蕉老牌，餐饮、商超渠道常见，适合走量型销售。
3. **德尔蒙（Del Monte）**：进口果蔬品牌，香蕉有稳定供应链，适合做品牌组合。
4. **Fyffes**：欧洲市场常见香蕉品牌，若你有对应进口渠道可评估。
5. **国内进口商/一级批发商的贴牌或产地直采**：菲律宾、厄瓜多尔、哥伦比亚等产地香蕉，实际利润和稳定性往往比品牌本身更关键。

实操建议：
- 先看你现在渠道是**商超、水果连锁、餐饮还是批发**。商超更适合都乐、金吉达这类认知品牌；批发和水果店可重点比产地直采价格和损耗。
- 进口香蕉核心不是“品牌强不强”，而是**到货熟度、催熟能力、损耗率、周供货稳定性**。建议先小批量试销2—3个品牌/产地，按7天损耗率和复购率筛选。
- 如果佳沛合作已有稳定供应链关系，也可以问其经销体系是否能对接香蕉品类，但不建议把香蕉作为佳沛品牌延伸来推。

优先顺序建议：**都乐 / 金吉达先试，德尔蒙备选，同时对比一个产地直采渠道。**
