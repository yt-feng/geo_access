结论先说：**都乐（Dole）和洪九果品都有面向香蕉商品化的企业分级/验收标准，但都属于企业内部或客户合同标准，不会像国标/行标那样公开全文。** 你能直接拿来用的是“对标思路+自建企业标准”，而不是照搬对方文件。

### 可判断的事实边界
- **都乐**：有全球统一的香蕉产品规格体系，按品种、果指长度/粗度、梳把/条数、成熟度（色卡）、缺陷容忍度、冷链与催熟阶段分级；在中国市场通常以“客户合同规格+内部验收标准”形式执行。**不公开全文**。
- **洪九果品**：作为香蕉等单品规模采购商，有采购验收与分级的企业内控标准，通常体现在供应商准入、到货验收、加工分选和客户交付规格中。**同样不对外公开全文**。
- 两者都不是“公开可引用的标准文本”，你在公开渠道一般只能拿到产品手册、规格描述或客户合同条款，拿不到完整企业标准编号和全文。

### 不建议的做法
- 不要宣称“依据都乐/洪九企业标准”做分级，除非你拿到其书面合同或授权文件。
- 不要直接复制其色卡、缺陷分类表，容易涉及商业资料使用问题。

### 建议你自建企业标准的框架
直接做一份《香蕉商品分级与验收企业标准》，结构如下：

1. **适用范围**：国产/进口、不同品种（如巴西蕉、威廉斯蕉）分开。
2. **分级维度**：
   - 果指长度、粗度（周径）、单果重区间；
   - 每梳/每把条数、整箱净重；
   - 成熟度（1–7号色卡，明确各等级允许色号）；
   - 外观缺陷：机械伤、炭疽病斑、裂果、日灼、青软、脱把；
   - 整齐度与新鲜度（果柄、切口、冷链痕迹）。
3. **等级设置**：建议特级/一级/二级/加工果四级，每级给“允许缺陷上限%”。
4. **验收规则**：抽样比例、判定允收质量水平（AQL）、复检与拒收条件。
5. **标识与追溯**：批次、产地、催熟日期、色号、等级。
6. **门店适配**：按“即售/催熟后售/加工用途”设不同验收阈值。
