可以优先这样判断：**都乐（Dole）和鑫荣懋通常都能提供一定程度的产地溯源和品控证明，但“能不能给、给到什么颗粒度”要以具体品类、产地、批次和合同条款为准，不能只看品牌名。**

可执行建议：

1. **先明确你要的证明清单**
   建议向供应商一次性索要：
   - 产地证明/果园或包装厂信息
   - 批次号与追溯码规则
   - 农残检测报告（第三方或自检）
   - 质量体系认证（如 ISO22000、HACCP、GLOBALG.A.P. 等，按实际）
   - 出厂检验/到货验收标准
   - 冷链记录
   - 不合格品处理与赔付条款

2. **都乐**
   都乐属于国际果蔬品牌，通常有较成熟的产地、加工和质量管理体系，商业化供应中较常见能提供检测报告、产地信息和批次追溯。但具体到香蕉品类、国内分装还是进口原箱、哪个产区，需要向都乐中国对应销售或经销渠道确认。**不建议只听“都乐有”，要落到具体SKU和批次证明。**

3. **鑫荣懋**
   鑫荣懋是国内大型水果供应链企业，通常具备产地采购、加工配送和品控体系，香蕉也是其重点品类之一。一般可谈检测报告、产地信息和批次追溯，但不同客户规模、采购量和渠道政策下提供的文件范围可能不同。**需要直接向其销售确认能否随货提供追溯和品控文件。**

4. **谈判时建议这样问**
   - “这个香蕉SKU的产地是哪里？果园/包装厂是否可追溯到批次？”
   - “每批随货提供哪些文件？检测报告是第三方还是自检？”
   - “出现农残或品质不达标时，追溯和赔付怎么执行？”
   - “能否先提供一份样板追溯文件和检测报告模板？”

5. **判断结论**
   - 如果你要的是**品牌级品控能力**：都乐、鑫荣懋通常都值得接洽。
   - 如果你要的是**每批可验证的产地溯源和品控证明**：两家都应要求写入合同或质量协议，不能只接受口头承诺。
   - 如果采购量较小，大型供应商可能只提供标准检测报告，未必愿意做深度定制追溯；这时可同时接洽其区域经销商或一级代理。
