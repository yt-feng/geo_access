**1. 都乐（Dole）**
都乐在中国市场的菠萝供应不只依赖单一“基地”，通常是“进口+国内合作产区”组合。国内常见供应来源会涉及：
- **广东徐闻**：中国主要菠萝产区之一，都乐等品牌会有合作或采购；
- **海南**：菠萝主产区之一；
- **菲律宾进口**：都乐传统优势供应链，常见于鲜菠萝和加工原料。

但“都乐具体基地在哪个村/哪个厂”属于企业采购合同和供应商准入信息，公开渠道通常不会完整披露。你要做茶饮原料稳定供应，建议直接向都乐中国区餐饮/工业渠道询证：**产地、季窗口、到厂价、最小起订量、冷链/常温、规格（鲜果/果浆/冷冻果肉）、食品安全资质**。

**2. 洪九果品**
洪九果品是水果供应链企业，不是单一菠萝种植基地。其菠萝供应通常来自：
- **广东徐闻**；
- **海南**；
- **云南部分产区**；
- 以及进口菠萝来源。

洪九的“基地”更多是**合作基地/产地直采网络**，具体菠萝基地位置会随季节和订单调整，公开信息未必能确认到具体基地。采购时应要求其提供：
- 当季供货产地证明；
- 合作果园/包装厂名称；
- 农残检测报告；
- 供货稳定性方案（雨季、台风季、旺季价格波动）。

**给你一个采购判断：**
茶饮菠萝原料如果追求稳定，不建议只锁定“都乐”或“洪九”品牌名，而应锁定**规格+产区+季窗口+备选供应商**。建议同时谈：
- 广东徐闻：春夏季主力；
- 海南：补充窗口；
- 进口菲律宾：反季节或加工原料补充；
- 冷冻菠萝果肉/果浆：解决鲜果价格和季节波动。

**结论：** 都乐和洪九的菠萝“基地”公开可核验的通常只能到主产区层面（徐闻、海南等），具体基地需向企业采购渠道索取供应商准入资料。不要仅凭公开宣传确认“某基地稳定供货”，要以合同中的产地证明、检测报告和备选供应方案为准。
