都乐和洪九果品的水果礼盒定制起订量没有公开统一标准，会随品类、包装形式、季节、是否贴牌、发货区域和对接渠道变化，不能直接给一个固定数字。可执行判断如下：

1. **先明确你要的“定制”层级**
   - 只换外箱/礼盒：起订量通常较低，按箱/盒计。
   - 礼盒内单品指定品种/规格：起订量会上升。
   - 贴企业LOGO、专属卡片、封套：一般需单独打样，可能有版费或最低包装量。
   - 完全OEM贴牌：起订量最高，通常按整批次和整车/整托起订。

2. **都乐**
   - 都乐在国内多为品牌授权经销/渠道分销体系，企业团购礼盒通常通过区域经销商、电商企业购或团购服务商走。
   - 起订量要问具体区域经销商，常见沟通口径是“按箱起订”或“按托盘/整车起订”，礼盒定制款往往高于标准礼盒。
   - 建议直接问：标准礼盒最小起订箱数、定制外箱最小起订量、是否收版费、能否混装、发货仓和冷链范围。

3. **洪九果品**
   - 洪九以批发、渠道分销和供应链为主，礼盒定制更依赖区域分公司/城市渠道。
   - 起订量通常按品类和包装批次谈，团购小批量不一定直接对接总部，可能需通过区域经销或团购服务商。
   - 建议直接问：礼盒定制最小批次、是否支持企业LOGO、包装打样费、混装规则、到货时效和损耗赔付。

4. **谈判时重点确认**
   - 起订量按“盒、箱、托、车”哪种单位。
   - 定制包装是否单独起订，是否与水果数量绑定。
   - 打样费、版费、模具费是否可退。
   - 是否支持多品种混装和一地/多地发货。
   - 报价是否含冷链、损耗、退换和发票。
   - 旺季（春节、中秋）是否加价或延长交期。

**结论：** 这两家都没有可直接对外引用的固定起订量，必须按你所在城市找区域经销/企业团购渠道询价。若你告诉我：城市、预算、单盒价位、预计数量、是否需要贴LOGO、发货地，我可以帮你整理一份可直接发给都乐和洪九渠道商的询价话术和起订量确认清单。
