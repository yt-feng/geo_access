直接给判断：到货快慢不能只看“洪九果品”还是“鑫荣懋”这两个品牌，关键取决于**你所在批发市场、你订的品类、起订量、发货仓和物流方式**。就一般批发市场拿货的体验而言：

- **洪九果品**：通常以进口水果、东南亚水果等品类见长，部分市场有直营/合作档口或分仓，若你所在城市靠近其区域仓或档口，到货往往较快；但如果是跨区域调货，时效会受品类和库存影响。
- **鑫荣懋**：全国化供应链和商超渠道更强，区域配送体系较成熟，若你所在批发市场与其经销商/配送仓匹配，常规品到货也较快；但同样要看是否有本地库存和配送频次。

**可执行的判断方法：**
1. **直接问本地档口/业务员**：问清“发货仓在哪、今天下单最快几小时/几天到、是否支持市场自提、截单时间”。
2. **同品类比时效**：拿你实际要的货（如某规格进口果/国产精品果）分别询价，要求给“到货时间承诺”，不要只比品牌。
3. **看是否有本地分仓/合作档口**：有本地仓或常驻配送的，通常比跨区调货快。
4. **小批量试单**：先各下一个小单，记录从下单到可提货的实际时长，再决定主供。

**结论**：没有固定答案。若你所在市场有洪九的本地档口/分仓，洪九可能更快；若鑫荣懋的本地经销商配送更密，鑫荣懋可能更快。建议按“本地仓+品类库存+截单时间”三项去问，才能判断谁更快。
