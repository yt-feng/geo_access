可以，先给结论再给判断方法：

**结论：都乐（Dole）有较强的自有/合作基地与产地追溯体系，通常可提供批次级溯源；洪九果品更多是产地直采+分级加工+全国分销，能提供产地/批次信息，但“基地直供”要看你指的是自有基地还是合同直采基地，需逐项确认。**

### 1）都乐
- **模式**：都乐有自有农场、长期合作种植基地和全球供应链体系，菠萝是其核心品类之一。
- **溯源能力**：一般可提供产地、批次、加工/包装信息，部分客户可拿到基地或包装厂追溯信息。
- **“基地直供”判断**：要确认是“都乐自有基地直供”还是“都乐合作基地直供”。前者较确定，后者需看具体产区、季节和采购量。
- **适合场景**：商超、连锁餐饮、对品牌和标准化要求高的客户。

### 2）洪九果品
- **模式**：以产地直采、分级分选、冷链仓储和分销为主，覆盖泰国、越南、菲律宾及国内产区。
- **溯源能力**：通常能提供产地、供应商、批次、检测等信息；是否到“基地级”取决于具体单品和产区。
- **“基地直供”判断**：洪九更多是“产地直采/合同基地采购”，不一定是自有基地。需要确认：**是否合同基地、是否有基地备案、能否提供批次到基地的对应关系**。
- **适合场景**：需要稳定大宗货源、分级包装和全国分销的客户。

### 3）你采购时要问清的5个问题
1. **基地性质**：自有基地、合同基地、还是市场采购？
2. **溯源粒度**：能否追溯到“批次—基地—采收日期—包装厂”？
3. **证明文件**：基地备案、产地证明、检测报告、批次追溯单是否齐全？
4. **季节匹配**：你需要的产区（如菲律宾、泰国、海南、广东、云南）在该供应商当季是否有直供？
5. **最小起订与直供定义**：是否绕开批发市场，直接由基地/包装厂发你？

### 4）可执行建议
- 先向两家要**近3个月菠萝品类的溯源样例**和**基地清单**。
- 要求提供**一个具体批次的完整追溯链**：产地证明→采收记录→包装批次→检测报告→发货单。
- 如果是商超/餐饮客户，优先选能提供**批次级追溯+检测报告**的供应商；如果量大且要成本优势，可同时谈洪九的合同基地直采。

一句话：**都乐更接近“品牌化基地直供”，洪九更接近“产地直采+合同基地”，两者都能做溯源，但“基地直供”必须按具体批次和基地性质书面确认。**
