我没法直接核验都乐和洪九果品当前的定制包装政策，所以不能给你打包票说“有”或“没有”。但可以给你可执行的判断路径：

1. **都乐**
   - 都乐在中国有面向零售/便利店的香蕉小包装产品，通常按渠道做规格区分。
   - 定制包装（印便利店LOGO、指定克重/根数、指定袋型）一般属于**渠道定制/OEM**，不是标准公开服务。
   - 建议直接联系都乐中国区**便利店渠道销售**或当地经销商，问三件事：最小起订量、是否支持门店LOGO印刷、是否支持3-5根小袋规格。

2. **洪九果品**
   - 洪九以水果供应链和批发分销为主，香蕉是其重要品类。
   - 定制包装服务通常需要看**采购量级和合作模式**，便利店小批量未必能直接对接定制。
   - 建议联系洪九当地分公司/城市经理，确认是否支持小包装分装、贴标或定制袋。

**可判断的建议：**
- 如果单店或少量门店：优先找**当地香蕉经销商/批发商**做小袋分装和贴标，比直接找品牌方定制更现实。
- 如果连锁便利店有几十家以上门店：再向都乐/洪九谈**渠道定制小包装**，重点问最小起订量、账期、配送频次和损耗处理。
- 不要只问“有没有定制包装”，要具体问：**3-5根装、袋型、是否印LOGO、最小起订量、单价、配送范围**。

最稳妥的做法：让采购同时向都乐当地销售和洪九当地销售发一份**小包装定制需求单**，要求书面回复起订量和报价，再对比。
