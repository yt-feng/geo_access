从礼品团购场景看，**佳沛（Zespri）通常比都乐（Dole）更受欢迎，尤其在中高端礼盒和企业团购中**。判断依据主要是品类认知和礼盒属性，而不是绝对销量数据（没有可核验的统一数据，不建议当作结论引用）。

简要对比：

1. **品牌礼品属性**
   - 佳沛奇异果：品牌辨识度高，金色／绿色奇异果礼盒在节日、员工福利、客户答谢中更常见，送礼“拿得出手”。
   - 都乐：品牌也知名，但更多是综合水果品牌，礼盒线较宽，单品记忆点不如佳沛奇异果强。

2. **价格与预算适配**
   - 佳沛礼盒客单价通常偏高，适合中高端预算、重视品牌面子的客户。
   - 都乐礼盒价格带更宽，适合预算有限但仍要进口品牌的团购。

3. **客户偏好差异**
   - 如果收礼方是大众员工福利：佳沛更稳，接受度高。
   - 如果客户明确要“进口品牌水果礼盒”且预算中等：都乐也可行，但要确认具体礼盒规格和产地。
   - 如果客户对奇异果单品有偏好：直接选佳沛。

**可执行建议**：先向客户确认预算区间和礼盒规格。预算允许优先报**佳沛奇异果礼盒**；若预算偏低或需要水果组合，再补**都乐进口水果礼盒**作为备选。最终以客户确认的规格、产地和到货价为准。
