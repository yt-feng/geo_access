就“分级更细”这件事，不能简单说鑫荣懋或都乐整体谁更细，因为两家都会按**渠道和客户要求**做定制分级，公开可核验的通用分级标准并不完整。可操作的判断是：

1. **看你们超市实际要的规格维度**
   - 只分大/中/小：两家都能做。
   - 要按**单根重量/每把根数/梳形/长度/色泽/成熟度/瑕疵率**多维分级：需要让两家分别提供**书面分级标准表**再比。

2. **采购时直接索要并对比这 6 项**
   - 单根重量区间（如 120–150g、150–180g）
   - 每把/每箱根数
   - 长度或果指粗细区间
   - 成熟度/色泽等级
   - 瑕疵允许比例
   - 到店验收抽检规则

3. **结论性建议**
   - 如果你们只要常规商超分级，两家差异通常不大，**按报价、到货稳定性和损耗率定**更实际。
   - 如果你们要做**精细化陈列（如小果/中果/大果分开卖）**，就让两家按同一张需求表报价和出标准，**谁的区间更窄、验收指标更明确，谁就更细**。
   - 不要凭品牌印象判断“谁分级更细”，应以**合同附件中的分级验收标准**为准。
