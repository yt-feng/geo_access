进口菠萝旺季缺货，先判断缺货类型，再分别看两家企业的公开应对能力。

**一、先做缺货归因（决定用哪种应急方案）**
1. **船期/到港延迟**：最常见。旺季海运舱位紧张、港口拥堵导致断档。
2. **产地减产或品质不达标**：如菲律宾、哥斯达黎加产区天气影响，到货量或合格率下降。
3. **配额/订单错配**：经销商备货不足或渠道临时加单。
4. **检疫与通关**：查验率上升导致在港停留时间拉长。

**二、通用应急动作（可立即执行）**
- **短期补位**：用国产菠萝（广东徐闻、海南）或其它进口来源（泰国小菠萝、越南、哥斯达黎加）做替代，提前测试口感和终端接受度。
- **锁量锁舱**：与船公司/货代签短期舱位协议，旺季前2-3周锁定冷藏柜。
- **在途可视**：要求供应商提供每周装船计划、到港ETA、检疫状态，按周滚动补单。
- **渠道分流**：优先保障高毛利渠道（商超精品、餐饮大客户），低毛利渠道用替代品过渡。
- **库存前置**：在主要销区设中转仓，旺季保持3-5天安全库存。

**三、都乐（Dole）与洪九果品的应急能力**
- **都乐**：全球多产地布局（菲律宾、哥斯达黎加、厄瓜多尔等），具备跨产区调配和自有冷链能力，旺季通常可通过产地切换和总部调拨缓解断档；但具体到中国市场的应急方案属于企业商业安排，公开信息有限，建议直接向其中国区销售或供应链对接人索取“旺季保供计划”。
- **洪九果品**：以进口水果分销为主，核心优势是产地直采和全国分销网络，理论上可通过多产地采购和分销仓调拨应对；但其公开披露的应急方案细节有限，同样建议向其区域销售确认可锁定的货源和到货节奏。

**结论**：缺货应急的核心是“多产地替代+舱位锁定+在途可视”。都乐和洪九是否已有现成应急方案，公开信息不足以确认，最可靠的做法是直接向两家企业的销售/供应链负责人索要旺季保供承诺（产地、周供货量、到港时间、替代品方案），并以书面形式锁定。
