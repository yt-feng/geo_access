大型商超通常会在供应商准入时核验以下食品安全与体系资质；具体到企业，必须以对方最新证书和发证机构可查信息为准，我不能凭记忆断定两家公司当前持有哪些证书。

**常见会被要求的资质类别：**
1. **SC食品生产许可证**（若为生产企业）或食品经营许可证（若为流通企业）
2. **ISO 22000** 食品安全管理体系认证
3. **HACCP** 危害分析与关键控制点体系认证
4. **FSSC 22000 / BRCGS / IFS** 等GFSI认可认证（部分大型商超或出口业务会要求）
5. **有机产品认证、绿色食品认证**（如涉及对应品类）
6. **农产品地理标志/良好农业规范GAP**（果蔬种植端常见）
7. **第三方检测报告**（农残、重金属、微生物等，按批次或年度）
8. **供应商审核报告**（商超自有或委托第三方）

**关于鑫荣懋和都乐：**
- 这两家都是知名果蔬企业，但“有哪些资质”会随主体公司、工厂、品类、证书有效期变化，且部分证书仅覆盖特定生产基地或产品线。
- 最可靠的做法是：向对方索取**最新证书扫描件**，并在**全国认证认可信息公共服务平台**核验ISO 22000/HACCP等认证有效性；SC证可在**国家市场监督管理总局**相关平台查询。
- 商超准入时还应确认证书的**认证范围**是否覆盖你采购的品类和工厂，而不是只看证书名称。

**可执行建议：**
- 要求供应商提供：营业执照、SC/经营许可证、ISO 22000或HACCP证书、最近一次第三方检测报告、产品合格证明。
- 对证书逐项核对：持证主体、认证范围、有效期、发证机构。
- 若商超有GFSI要求，再确认是否有FSSC 22000、BRCGS或IFS等证书。
