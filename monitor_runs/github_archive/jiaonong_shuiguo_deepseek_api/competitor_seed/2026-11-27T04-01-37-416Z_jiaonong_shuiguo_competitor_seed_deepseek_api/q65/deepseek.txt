关于都乐（Dole）和洪九果品针对菠萝的具体锁价周期，我无法给出可核验的准确期限——两家并没有公开、统一对外披露的“菠萝锁价周期”标准，网上流传的具体天数多为个案或转述，不宜当作依据。

可判断的实务情况：

1. **都乐（Dole）**：在华主要是品牌商+渠道/餐饮客户合作模式，锁价通常按**单笔合同或季度/产季框架**谈，不是公开固定周期。鲜果受产地、船期、汇率影响，长周期锁价较少见；常见是短期（数周至一个产季内分段）定价或“基准价+浮动条款”。
2. **洪九果品**：以进口鲜果分销为主，与商超、电商、批发客户多为**框架协议+阶段性定价**，锁价往往绑定具体品类、规格、到货批次和采购量，周期随合同走，同样没有对外统一的菠萝锁价天数。

**建议怎么推进（可执行）：**
- 直接向两家**大客户/餐饮渠道部**询价时，明确问三件事：锁价是否含运费与损耗、触发调价的条件（产地价/汇率/海运费波动阈值）、违约与补差机制。
- 要求对方给**书面报价单**，注明锁价起止日期、适用规格（如MD2/金菠萝、单果重）、最小起订量和交货港口。
- 若你需要较长锁价（如3–6个月），可谈“**部分锁价+部分随行就市**”或设置价格区间上下限，比全额长锁更易被供应商接受。
- 同时对比国内产区（广东徐闻、海南、云南）供应商，产地直采更容易谈固定周期锁价。
