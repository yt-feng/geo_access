做进口苹果的产地溯源，核心是“批次可追、单证可验、标签可对”。都乐（Dole）和鑫荣懋（Joy Wing Mau）都属于品牌商/进口商体系，具体操作要落到**你作为超市采购方**能拿到什么、验什么、留什么。下面按可执行步骤说。

## 1. 先明确溯源目标
超市采购做溯源，至少要能回答四个问题：
- 这批苹果从哪个国家/产区、哪个果园或包装厂来；
- 哪个批次、什么时候装运、什么时候入境；
- 经过哪些进口商/经销商到超市；
- 单证、标签、实物三者是否一致。

## 2. 向供应商索取的必备单证
无论是都乐还是鑫荣懋，采购时应要求其提供并按批次归档：
1. **原产地证明**（Certificate of Origin）：确认国家/地区，部分品类可细化到产区。
2. **入境货物检验检疫证明**：海关出具，核对品名、原产国、批号、数量、入境日期。
3. **报关单**：核对进口商、原产国、成交方式、批次信息。
4. **装箱单/发票/提单**：用于串起“国外发货—入境—国内流通”链条。
5. **供应商资质**：营业执照、食品经营许可证；进口商若为都乐/鑫荣懋体系，核对主体名称是否与单证一致。
6. **检测报告**：农残等按你们超市验收标准索取，注意报告对应批次和日期。
7. **品牌授权或经销链路证明**：确认你拿货的经销商确实在都乐/鑫荣懋授权链路内，防止串货。

## 3. 都乐的操作要点
都乐通常是品牌化包装，溯源相对标准化：
- 看**果贴/箱贴上的批次码、包装厂注册号、原产国**；
- 要求供应商提供该批次对应的**入境检验检疫证明+报关单**；
- 都乐国内主体可能是都乐中国相关公司，核对发票抬头、报关单境内收货人、检验检疫证明收货人是否一致；
- 若通过二级经销商拿货，要求其提供**从都乐体系到该经销商的流转凭证**，至少发票或出库单能对应批次。

## 4. 鑫荣懋的操作要点
鑫荣懋既是进口商也是国内分销商，链路可能更长：
- 确认报关单上的**境内收货人**是鑫荣懋体系公司，还是其上游进口商；
- 要求提供**鑫荣懋到你的供货发票/出库单**，并标注批次或生产日期；
- 若鑫荣懋是分销商而非直接进口商，要求补齐**上游进口商到鑫荣懋**的凭证；
- 核对包装箱上的**果园/包装厂注册号、原产国、批次号**与单证是否一致。

## 5. 超市内部落地动作
建议做成“一批一档”：
- 收货时抽箱核对：原产国、品牌、批次码、包装厂号、标签与单证一致；
- 收货单上增加“原产国、入境检验检疫证明编号、报关单号、批次号”字段；
- 留存单证扫描件，保存期限按你们内控和监管要求，通常不少于保质期满后6个月，进口食品建议更长；
- 价签/电子屏可展示原产国和进口商，但不要虚构“果园直采”等无法验证的信息。

## 6. 快速判断供应商是否靠谱
- 只给复印件不给看原件核对：要求加盖公章并注明“与原件一致”；
- 单证批次和实物批次对不上：拒收或要求换批次；
- 报关单原产国与包装标签不一致：暂停收货；
- 经销商说不清上游链路：不建议作为溯源依据。

**一句话建议**：都乐、鑫荣懋都按“品牌方/进口商单证 + 批次码 + 实物标签”三对照来做；直接进口就拿报关单和入境检验检疫证明，二级经销就拿完整流转凭证，缺一环就不算可溯源。
