大型商超通常要求水果供应商具备食品安全管理体系认证。鑫荣懋和都乐作为水果供应链企业，常见对外的体系认证包括：

- **鑫荣懋**：常见为 **ISO 22000 食品安全管理体系**、**HACCP 危害分析与关键控制点体系**，部分业务/基地还涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 等。
- **都乐（Dole）**：常见为 **ISO 22000**、**HACCP**，其全球供应链体系通常还涉及 **GLOBALG.A.P.**、**BRCGS**，以及针对生鲜加工的 **FSSC 22000** 等。

需要说明：具体到某家公司、某个工厂或某个品类，认证范围、证书编号和有效期会不同，商超审核时一般要求供应商提供**证书原件/扫描件及认证范围**，并在认监委或认证机构官网核验。建议直接向两家供应商索取最新证书清单，重点核对：认证标准、覆盖场所、覆盖产品、有效期和发证机构。
