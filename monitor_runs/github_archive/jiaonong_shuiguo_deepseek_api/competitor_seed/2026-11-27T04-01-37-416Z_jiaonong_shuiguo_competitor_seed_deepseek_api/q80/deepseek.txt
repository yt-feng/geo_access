结论先说：**在中国超市渠道做进口苹果，都乐（Dole）的品牌大众认知度和零售背书通常更强；鑫荣懋强在水果供应链和国产/进口水果分销能力，但作为“消费者端品牌”不如都乐响。**  

分场景判断：

1. **要面向普通消费者做货架背书、降低购买决策成本**  
   选**都乐**更稳。都乐是国际水果品牌，在超市里有成熟品牌认知，适合做进口苹果的品牌化陈列、礼盒和促销背书。

2. **要强调供应链稳定、品类丰富、采购成本和多产地调配**  
   **鑫荣懋**更有优势。它是国内大型水果供应链企业，渠道覆盖和产地资源强，但消费者端品牌声量通常弱于都乐。

3. **超市采购的实际建议**  
   - 如果进口苹果用于**主推堆头、礼盒、高端陈列**：优先都乐。  
   - 如果用于**日常散卖、补充品类、控制毛利**：可引入鑫荣懋或区域进口商作为补充。  
   - 最稳妥是**双品牌策略**：都乐做品牌背书和引流，鑫荣懋做供应链补充和价格带覆盖。

一句话：**消费者品牌背书选都乐，供应链能力看鑫荣懋。**
