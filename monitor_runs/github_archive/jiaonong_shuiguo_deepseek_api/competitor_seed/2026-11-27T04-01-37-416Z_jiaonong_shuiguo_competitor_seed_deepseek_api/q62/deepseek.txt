可以，但要先分清“能提供”具体指哪一种，并提前锁定批次和报告类型。

**结论：**
- **都乐（Dole）和鑫荣懋一般都可以提供农残检测报告**，但通常不是“随便给一份通用报告”，而是需要你按采购批次、品种、产地、供应商主体去索取。
- 茶饮店采购菠萝原料，**最好要求“与到货批次对应的农残检测报告”或“供应商年度/批次检测报告+到货批次追溯信息”**，否则报告与原料对不上，门店食安审核时容易被质疑。

**实操建议：**
1. **下单前书面确认**：让供应商在报价单/合同里写明可提供“农残检测报告”，并注明报告类型：第三方检测报告、供应商自检报告、批次报告或年度报告。
2. **索要报告时给全信息**：品名（菠萝/凤梨）、品种、产地、加工厂/包装厂、生产日期或批次号、送货日期、供应商全称。
3. **核对报告关键点**：检测机构、报告编号、样品名称、检测项目（农药残留项）、检测结果、报告日期、批次/样品编号是否与到货一致。
4. **都乐**：通常走经销商或区域供应链，报告要找**实际供货主体**要，不一定直接对接到都乐总部；如果是都乐品牌产品，可要求经销商提供对应批次报告。
5. **鑫荣懋**：同样按实际签约供应商索取，重点确认是**鑫荣懋直供**还是二级经销商供货；二级供货时报告链条要完整。
6. **茶饮店更稳妥的做法**：首次合作先要一份近期第三方农残检测报告做准入，之后每批到货索取批次追溯信息；高风险季节或审核前再抽批次要报告。

**判断标准：**
- 能提供“带批次号、与送货单能对应”的报告：可用。
- 只能提供“很久以前的通用报告”或“报告样品与到货批次无关”：不能作为该批原料的合格依据。
- 供应商拒绝提供或含糊其辞：建议更换供应商或要求第三方抽检。
