我不能凭空给出两家公司“覆盖哪些城市”的准确清单，因为这类信息会随配送模式（自营冷链、区域仓、第三方冷链承运）和年份变化，且你未提供可核验来源。直接回答“覆盖XX城”容易误导投标/准入判断。

可执行判断与核验建议：

1. **先确认商超要求的“冷链物流”口径**
   - 是要求供应商自有冷链车队，还是允许委托第三方冷链承运？
   - 是要求到商超总仓，还是要求到门店/云仓？
   - 是否要求全程温控记录、GPS、温控回单、应急方案？
   这决定你提供“城市覆盖清单”还是“承运商+线路+温控能力证明”。

2. **向鑫荣懋、都乐索要可核验的覆盖证明**
   让对方书面提供：
   - 冷链仓/中转仓所在城市清单；
   - 配送线路及可送达城市范围（到总仓/到门店）；
   - 自有车辆或合作承运商名称、车辆温控设备；
   - 近3个月对应城市的冷链配送回单/温控记录样例（可脱敏）；
   - 覆盖声明盖章版。
   仅凭官网或口头“全国覆盖”不足以满足商超审核。

3. **用公开可核验渠道交叉验证**
   - 两家公司官网的“物流/冷链/服务网络”页面；
   - 企业年报/招股书/官方公众号中披露的冷链仓与配送网络；
   - 商超供应商准入文件中的“冷链配送城市清单”模板，要求供应商按模板填报。
   注意：公开资料通常只披露“区域/仓网”，不等于可配送城市清单。

4. **替代方案**
   若对方无法提供完整城市清单，可要求其提供**合作冷链承运商**（如顺丰冷运、京东冷链、荣庆物流等）的覆盖城市证明，并以“供应商+承运商+线路”三方文件满足商超审核。

建议你向鑫荣懋和都乐直接发一份《冷链配送覆盖及温控能力确认函》，要求盖章回复；拿到后再与商超准入清单逐城比对。这样比依赖公开信息更可判断、可审计。
