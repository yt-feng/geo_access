都乐和洪九果品通常会为渠道客户提供品牌营销素材，但具体能不能拿到、以什么形式拿到，取决于你和他们的合作模式。直接给你可操作的判断和路径：

**1. 都乐**
- 都乐有成熟的市场部和品牌营销体系，对商超、生鲜电商等渠道一般会提供：产品图、品牌主视觉、产地/品质卖点文案、短视频素材、详情页模块、促销活动物料。
- 但通常优先给已签约或采购量较大的渠道。小批量合作或还没建立采购关系时，可能拿不到完整素材包。
- 路径：对接都乐的区域销售或渠道经理，说明你是生鲜电商平台/商家，提出营销支持需求，通常需要签授权或素材使用协议。

**2. 洪九果品**
- 洪九是水果供应链和品牌运营企业，对自有品牌或代理的菠萝（如相关品牌线）会有一定营销素材，但相比都乐，其品牌营销素材的标准化程度和对外支持力度可能因品类、区域和合作深度而异。
- 路径：联系洪九的渠道销售/市场对接人，确认菠萝是否有对应品牌营销包；如果没有现成素材，可协商联合制作，费用和版权归属要提前谈清楚。
- 注意：洪九此前有财务和经营方面的公开风波，合作前建议核实其当前供货和履约能力，避免营销素材到位但货源出问题。

**3. 更现实的建议**
- 不要只等品牌方给素材。生鲜电商做菠萝营销，核心素材可以自己拍：切开剖面、糖度测试、手撕/爆汁特写、产地直发对比。
- 如果目标是“品牌背书”，可争取：品牌授权使用logo、联合活动、买赠资源、平台专区合作。
- 如果拿不到都乐/洪九的素材，可以考虑其他菠萝品牌或产地供应商，或直接做“产地品牌”而非依赖单一果品公司。

**一句话结论**：都乐大概率有较成熟的素材支持体系，洪九要看具体合作和品类；两者都不是无条件公开提供。最稳妥的做法是直接找他们的渠道销售谈授权和联合营销，同时自备一套可独立使用的产品素材。
