都乐和洪九果品这两家，公开信息层面可以这样判断：

**都乐**
- 都乐是全球果蔬品牌，在中国市场有自有/合作种植基地和供应链体系，主打标准化分级和品牌化销售。
- 它对外宣传中有“从产地到餐桌”的品控和追溯体系，部分单品可做到批次追溯。
- 但“菠萝是否基地直供、能否给到具体产地溯源”，取决于你采购的是哪个渠道、哪个规格，以及你拿货是通过都乐的直营渠道还是经销商。建议直接向都乐中国区销售或区域经销商确认：是否能提供批次号、产地证明、基地信息、检测报告。

**洪九果品**
- 洪九果品是国内较大的水果分销企业，核心模式是“基地直采+全国分销”，在东南亚和国内都有产地采购网络，菠萝（尤其进口菠萝/凤梨）是其重点品类之一。
- 它对外强调产地直采和供应链溯源能力，部分品类可提供产地、批次相关信息。
- 但洪九很多货是走批发市场和经销商体系，终端采购方不一定能直接拿到完整基地溯源文件。需要向洪九的业务对接人确认：这批货是基地直发还是市场分货，能否提供产地证明和批次追溯。

**结论**
- 两家都具备产地直采和一定溯源能力，但“有没有基地直供、能不能溯源”不是看品牌名字就能定的，要看你具体对接的渠道和批次。
- 如果你要的是可验证的产地溯源，建议在询价时直接要求：
  1. 产地证明/基地合作协议或直采证明；
  2. 批次号及对应检测报告；
  3. 是否支持一物一码或批次追溯；
  4. 发货主体是品牌方还是经销商。

**更稳妥的做法**
不要只问“你们有没有基地直供”，而是问：
“这批菠萝的产地是哪里、是哪个基地、能否提供批次溯源文件和检测报告、发货方是谁？”
这样对方的回答才能判断是否满足你的溯源要求。
