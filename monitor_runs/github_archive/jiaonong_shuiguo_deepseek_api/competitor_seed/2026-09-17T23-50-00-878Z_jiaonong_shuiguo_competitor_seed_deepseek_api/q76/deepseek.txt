生鲜电商做菠萝产地直发，都乐和鑫荣懋的物流时效可以从以下几个维度判断：

**1. 都乐（Dole）**
- 都乐在国内有成熟的冷链体系，菠萝主要来自菲律宾、泰国及国内广东/海南产区。
- 进口菠萝走海运+港口冷链，国内分仓发货；国产菠萝（如广东徐闻、海南）可做到产地仓直发。
- 时效参考：产地仓→一线城市通常 24-48 小时；二三线城市 48-72 小时；偏远地区 72 小时以上。
- 优势：品控标准化程度高，适合对品质一致性要求高的渠道。

**2. 鑫荣懋**
- 鑫荣懋是国内头部水果供应链企业，与多个国产菠萝产区有直采合作，冷链覆盖较广。
- 产地直发时效与都乐接近：核心城市 24-48 小时，一般城市 48-72 小时。
- 优势：国产菠萝（如徐闻菠萝）供应链更深，价格弹性可能更大，适合走性价比路线。

**3. 实际选型建议**
- **先确认具体产地**：菠萝是徐闻、海南还是进口？不同产地到你的仓/消费者的距离差异很大。
- **要真实报价和时效承诺**：直接找两家在你目标产区的销售或供应链负责人，要「产地→你指定城市」的门到门时效和破损率数据，而不是只看品牌。
- **小批量测试**：先各发 1-2 批到你的核心销售城市，实测到货时间、损耗率、成熟度，再决定主供应商。
- **注意菠萝特性**：菠萝后熟快，物流时效每多 24 小时，货架期和损耗风险明显上升，72 小时以上要谨慎。

**结论**：两家时效在同一量级，核心城市都能做到 24-48 小时，差距更多体现在具体产地、发货仓位置、你的订单量和议价能力上。建议直接向两家索取针对你目标产地的时效承诺和试单数据，而不是依赖通用判断。
