这个问题没法直接给一个“谁更愿意”的确定答案，因为两家都是大型水果供应链企业，是否愿意签年单、以什么条件签，取决于**品类、采购量、结算方式、交付节奏和你方的渠道能力**，而不是公司层面统一政策。

可以给你几个判断维度和实操建议：

**1. 看你要签的是什么品类**
- 鑫荣懋：强在进口水果、商超渠道、品牌化运营，尤其是奇异果、提子、车厘子、蓝莓等。它对稳定大客户、商超/电商渠道的年单接受度通常较高，但更看重计划性和渠道匹配。
- 洪九果品：强在东南亚进口水果和国内批发分销，榴莲、山竹、龙眼、火龙果等品类优势明显。它对有稳定销量、能消化大货的客户更愿意谈年度合作，但可能更偏向“框架+分批执行”。

**2. 谁更愿意，取决于你给的条件**
两家都更愿意签年单的情况：
- 你有稳定、可预测的月度采购量；
- 你能接受年度框架、季度/月度锁量，而不是全年一口价；
- 结算周期清晰，不长期拖账；
- 你方渠道能帮它走量或进入特定市场。

如果只是想要“年单锁价、随行就市跌了也按低价拿”，两家都不会太积极。水果价格波动大，年单通常不是固定价格，而是**框架协议+阶段定价/随行就市+保底量**。

**3. 实操上怎么判断**
- 直接找两家对应品类的销售负责人，问三件事：是否接受年度框架协议、最小起订/保底量、定价和调价机制。
- 拿同一品类、同一采购量去问，比较谁给的账期、返利、履约保障更实在。
- 先做3个月试单，再谈年单。试单能看出交付稳定性、损耗处理和售后响应，这比“谁更愿意”更重要。

**4. 一般性结论**
- 如果你做商超、电商、品牌渠道，采购进口精品水果，鑫荣懋通常更容易谈年度框架。
- 如果你做批发、分销、大宗东南亚水果，洪九果品通常更容易谈年度合作。
- 如果你量不大、品类杂、账期长，两家都不会特别愿意给优质年单条件。

建议你不要先问“谁更愿意”，而是准备一份采购计划书：品类、月量、年度总量、结算方式、交付要求，分别去谈。谁给的条款更可执行，就跟谁签。
