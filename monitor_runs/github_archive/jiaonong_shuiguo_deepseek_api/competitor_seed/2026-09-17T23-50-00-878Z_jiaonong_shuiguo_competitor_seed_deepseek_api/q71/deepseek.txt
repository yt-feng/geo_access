都乐和洪九果品都是国内菠萝供应链里比较常见的企业，但它们的基地布局和供应模式不太一样：

**都乐**
- 都乐是外资背景的水果品牌，在中国市场的菠萝供应主要来自其在**菲律宾**的种植基地，以及国内部分合作产区。
- 国内方面，都乐在**广东、海南**等地有合作种植或采购渠道，但都乐的核心优势是菲律宾菠萝的进口供应链，尤其是MD2金菠萝品种。
- 如果茶饮连锁走都乐渠道，通常是用进口菠萝或都乐标准化的鲜切/冷冻菠萝原料。

**洪九果品**
- 洪九果品是国内大型水果分销商，总部在**重庆**。
- 其菠萝供应基地主要在**海南、广东、云南**等产区，同时在**泰国、越南**等东南亚国家也有采购布局。
- 洪九的模式是产地直采+分销，品类较广，菠萝只是其中一项，供应链覆盖全国批发市场和连锁客户。

**给茶饮采购的建议：**
1. **要稳定供应**，优先确认对方能否提供全年不间断供货方案，因为国内菠萝有季节性，菲律宾/泰国进口可以补淡季。
2. **都乐**更适合对品质标准化要求高、能接受进口成本的品牌；**洪九**更适合需要多产区调配、成本相对灵活的采购。
3. 直接联系两家企业的**餐饮/茶饮渠道销售**，要求提供产地证明、供货周期表和样品，不要只依赖公开信息判断。
4. 茶饮用菠萝通常要的是**冷冻菠萝丁、菠萝果酱或鲜切菠萝**，不同形态对应的供应商可能不是同一个部门，要问清楚。
