能确定的是行业惯例，供你判断：

- **锁价本质是"固定价+固定量+固定窗口"**，周期一般分三档：短期约2–4周（走现货行情、小单），中期1–3个月（常规批发/餐饮连锁），长期3–6个月甚至按产季锁（大客户、全年框架）。
- **都乐（Dole）**：以品牌化鲜果和商超渠道为主，锁价多体现在年度/季度框架协议里，实际执行常按月调价或分批定价，不是简单一个固定周期。
- **洪九果品**：走批发和渠道分销，锁价更贴近产季和产地行情波动，通常按单议价、周期偏短（数周至1–2个月），大客户才可能谈季度锁价。

**你要拿到真实周期，建议直接问这4点**（比网上查更靠谱）：
1. 锁价窗口起止日期、对应哪个产地/产季；
2. 锁价是否含运费、损耗和等级差价；
3. 锁量不足或超量的违约/补价规则；
4. 期间行情大涨大跌时的调价触发条件。
