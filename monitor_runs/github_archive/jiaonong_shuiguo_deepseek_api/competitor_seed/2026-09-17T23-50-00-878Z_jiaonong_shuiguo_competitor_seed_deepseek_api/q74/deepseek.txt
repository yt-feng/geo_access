都乐和洪九果品的**礼盒定制起订量没有统一公开标准**，通常按以下逻辑走，需要你直接找对应渠道确认：

**1. 都乐**
- 都乐在中国多为品牌授权/经销商体系运作，企业团购定制一般通过**区域经销商或大客户渠道**谈。
- 常规现货礼盒起订量相对低，常见 **几十箱起**；如果是**定制logo、指定包装、指定果品组合**，起订量通常会抬到 **几百箱甚至上千箱**，具体看品类和档期。
- 节日旺季（春节、中秋）起订量会更高，且需提前锁量。

**2. 洪九果品**
- 洪九更偏**批发、供应链、渠道分销**，企业团购定制一般走销售或大客户部门。
- 定制礼盒通常要求 **整板/整车或较大批量**，常见门槛在 **几百箱到上千箱**；部分单品或现货标准礼盒可能低一些。
- 是否接小批量定制，取决于当地分公司、当期库存和包装厂排期。

**建议你直接这样问，能最快拿到准确数字：**
1. 我要做企业团购礼盒，**定制logo+指定果品**，最低起订量多少箱？
2. 如果是**用你们现有礼盒只贴标/换外箱**，起订量能不能降低？
3. 节日旺季的**最晚下单时间**和**锁量规则**是什么？
4. 报价是**含税含运**还是到仓价？破损和售后怎么算？

**更实际的做法：**
- 同时找都乐、洪九的**当地经销商/分公司**，不要只找总部客服。
- 如果你们单次需求低于几百箱，建议优先谈**现有礼盒+贴标**，或找本地水果供应链做定制，起订量可能降到 **50–100箱**。
