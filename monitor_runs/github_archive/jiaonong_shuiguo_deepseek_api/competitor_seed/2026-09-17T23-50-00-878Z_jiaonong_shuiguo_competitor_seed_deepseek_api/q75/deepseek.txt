到货损耗率没有公开的统一官方数字，洪九果品和都乐香蕉也不会对外发布按批发市场口径统计的损耗率。实际损耗受批次成熟度、运输距离、冷链、包装、季节、卸货方式和市场周转速度影响，同一品牌不同批次都可能差很多。

可以给你一个批发市场实操的判断框架：

**1. 通常谁更稳**
- **都乐香蕉**：标准化、品牌化程度高，通常催熟和冷链控制更稳定，到货一致性较好，损耗相对更可控。
- **洪九果品**：品类和渠道更杂，香蕉只是其中一部分，不同产地、不同批次、不同客户等级差异较大。不能简单说洪九一定比都乐差，但稳定性通常不如都乐这种单一强势品牌。

**2. 批发市场常见损耗区间**
仅作经验参考，不是官方数据：
- 管理较好的冷链到货：**3%—8%**
- 普通批发市场到货、再周转1—3天：**8%—15%**
- 夏季高温、催熟偏熟、挤压严重：**15%—25%甚至更高**

都乐如果冷链和成熟度控制好，通常更容易落在偏低区间；洪九要看具体批次和拿货渠道，波动可能更大。

**3. 你真正该对比的指标**
不要只问到货损耗率，建议按这批货实际算：
- 到货总件数/总重量
- 卸货后立即挑出的坏果、断果、过熟果
- 24小时后不能卖或只能降价的货
- 实际可售重量
- 损耗率 = 不可售或降价损失重量 ÷ 到货总重量

**4. 拿货建议**
- 同一市场、同一时间段，各拿1—2件同规格货做对比。
- 记录到货温度、青熟度、箱内是否有水汽、压伤情况。
- 都乐通常适合求稳、做中高端或商超渠道。
- 洪九如果价格明显低，必须把损耗和降价风险算进去，别只看拿货价。
- 夏天下手要保守，香蕉过熟损耗会迅速放大。

**结论**：没有可靠公开数据能直接给出“洪九果品 vs 都乐香蕉”的到货损耗率对比。实操上，都乐通常更稳定、损耗更可控；洪九波动更大，取决于批次和渠道。最靠谱的办法是按同市场同批次实测，用实际可售重量算损耗。
