**便利店小包装香蕉常见规格方向**
- 单根装：约120–180g/根，适合即时消费
- 2–3根装：约300–500g/袋，适合小家庭或办公室
- 4–5根装：约600–900g/袋，接近社区超市小规格
- 迷你香蕉/小米蕉：单根约60–100g，整袋5–8根较常见

**鑫荣懋、都乐是否适合**
- 这两家都是国内香蕉主流供应商，通常具备按渠道定制包装的能力，便利店小包装一般属于可谈的定制项。
- 关键不是“有没有现成规格”，而是“起订量、配送频次、损耗承担、门店补货方式”能否匹配便利店。

**建议直接向供应商确认这几点**
1. 是否有便利店渠道现成小包装规格，如单根、2根、3根装
2. 单袋克重、根数、包装形式（袋装/盒装/挂条）
3. 最小起订量、是否支持区域仓或门店直配
4. 保质期、到店成熟度、催熟控制标准
5. 损耗和退换货政策
6. 条码、价签、陈列方式是否适配便利店系统

- 先让两家各提供便利店渠道产品手册或报价单
- 要求寄样，按你目标门店做7–14天试销
- 对比单店日均销量、损耗率、毛利额后再定规格
