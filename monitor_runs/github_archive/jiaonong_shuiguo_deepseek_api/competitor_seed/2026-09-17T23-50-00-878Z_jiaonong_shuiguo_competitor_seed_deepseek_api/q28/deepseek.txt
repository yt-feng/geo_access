这个问题没法直接给一个“谁更便宜”的结论，因为都乐和鑫荣懋给水果连锁的价格是**一店一议、一单一议**的，取决于品种、规格、产季、采购量、账期、是否带返利、是否走总仓配送等。

不过可以给你一个可判断的框架和实操建议：

**1. 先明确比价口径**
不要只比“每斤报价”，要统一成：
- 品种：如新西兰爱妃、红玫瑰、爵士，还是美国蛇果、智利嘎啦等
- 规格：果径、单果重、每箱个数
- 等级：一级/二级、是否带箱重、是否净果
- 到货方式：产地直发、区域仓配、门店配送
- 结算：现款、账期、返利、损耗补贴
- 税率：是否含税、开票类型

**2. 都乐和鑫荣懋的定位差异**
- 都乐：品牌溢价较强，终端认知度高，适合做礼盒、中高端陈列、品牌背书。通常价格不一定最低，但动销和毛利结构可能更好。
- 鑫荣懋：进口水果供应链能力强，很多商超和连锁的进口苹果来自其体系，价格竞争力通常体现在大批量、稳定供应和区域仓配。具体到某个单品，可能比都乐低，也可能因为品牌授权、包装规格不同而更高。

**3. 建议你这样比**
找两家分别要同一产季、同一品种、同一规格的报价，做成一张表：

| 对比项 | 都乐 | 鑫荣懋 |
|---|---|---|
| 品种/规格 |  |  |
| 箱规/净重 |  |  |
| 到店价/斤 |  |  |
| 起订量 |  |  |
| 账期 |  |  |
| 返利/补贴 |  |  |
| 损耗率承诺 |  |  |
| 配送频率 |  |  |
| 售后 |  |  |

然后按“**实际到店净成本 = 含税到店价 - 返利 - 损耗补贴 + 配送/损耗成本**”来算，而不是看表面报价。

**4. 更现实的结论**
如果你门店多、单量大、走总仓，鑫荣懋通常更有机会拿到有竞争力的价格；如果你要做品牌陈列、礼盒、线上引流，都乐可能更合适，哪怕采购价略高，终端溢价也能覆盖。

**5. 直接可执行的做法**
- 先选1-2个主力进口苹果单品，让两家按同一规格报价。
- 要求提供近3个月对同类连锁的供货案例或参考价区间，但不要指望对方给底价。
- 用“试销2周”的方式比：同一门店、同一陈列位、同一售价，看毛利额和损耗，不只比进货价。
- 如果两家都愿意谈，可以用一家价格压另一家，但不要只压价，要同时谈账期和损耗。
