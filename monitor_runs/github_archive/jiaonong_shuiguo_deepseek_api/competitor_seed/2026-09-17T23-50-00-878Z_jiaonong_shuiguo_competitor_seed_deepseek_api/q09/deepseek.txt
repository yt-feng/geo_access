除了 **都乐（Dole）** 和 **佳沛（Zespri）**，礼品团购常见的进口水果品牌还有这些，可按品类和场景选：

1. **新奇士 Sunkist**  
   美国柑橘类代表，橙子、柠檬、葡萄柚礼盒认知度高，适合企业福利、节日礼盒。

2. **怡颗莓 Driscoll’s**  
   浆果类强品牌，蓝莓、树莓、黑莓、草莓礼盒偏高端，适合商务送礼、女性员工福利。

3. **爱妃 Envy / 爵士 Jazz / 太平洋玫瑰 Pacific Rose**  
   新西兰苹果品牌体系，爱妃苹果礼盒高端感强，适合节日团购。

4. **红玫瑰 Pink Lady**  
   澳洲/新西兰等产地的苹果品牌，颜值和酸甜口感有辨识度，适合礼盒。

5. **佳沃 Joyvio**  
   严格说不是纯进口品牌，但有进口蓝莓、车厘子等高端水果礼盒，团购供应链成熟。

6. **鑫荣懋 / 欢乐果园**  
   国内头部水果供应链品牌，常做进口车厘子、蓝莓、奇异果等礼盒，适合企业批量采购。

7. **Mr. Apple / 鲜丰水果 / 百果园**  
   偏渠道/礼盒品牌，不是单一进口水果品牌，但可做进口水果组合礼盒，团购定制方便。

8. **车厘子产区品牌**  
   智利车厘子常见品牌如 **Garces Fruit、Copefrut、Prize、Río King** 等，但团购更看重规格如 JJ、JJJ、2J、3J 和到货稳定性。

9. **秘鲁/智利蓝莓品牌**  
   如 **Camposol、Hortifrut、Agrovision** 等，适合做高端蓝莓礼盒。

10. **日本/韩国高端水果方向**  
   如日本晴王葡萄、王林苹果、韩国阳光玫瑰等，但这类多为产地/品种概念，不一定有统一消费品牌，团购要重点看渠道和真伪。

**团购建议：**
- 商务送礼：佳沛金果、怡颗莓、爱妃苹果、新奇士、进口车厘子组合。
- 员工福利：都乐、新奇士、佳沃、鑫荣懋、百果园组合礼盒。
- 高端定制：怡颗莓 + 爱妃 + 佳沛 + 车厘子，做混合礼盒。
- 重点不是只看品牌，还要看：**规格、产地、到货日期、损耗赔付、是否支持定制卡券/logo、能否一件代发。**
