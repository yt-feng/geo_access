**都乐（Dole）**
- 作为品牌方/进口商，一般能提供其批次或产地对应的农残检测报告（常见为第三方检测机构出具，如SGS、华测、谱尼等）。
- 实操上多通过其经销商或区域供应链服务商提供，直接找都乐总部不一定对接到你这家小店。
- 报告通常针对**特定批次/产地/日期**，不是一张报告永久通用。

**鑫荣懋**
- 国内大型水果供应链企业，通常也能提供农残检测报告，多由其品控或对接的第三方检测机构出具。
- 同样需要按**采购批次**索取，且经其分销渠道时，报告可能由分销商转发。

**采购时要核对的点**
1. 报告上的品名、产地、批次/生产日期是否和你收到的货一致。
2. 检测项目是否覆盖你关心的农残指标（如毒死蜱、多菌灵、吡虫啉等，按菠萝常检项）。
3. 出具机构是否有CMA/CNAS资质。
4. 报告日期是否在合理有效期内（通常按批次，不是按年）。
5. 是“委托检测”还是“监督抽检”，前者只对送样批次负责。

**建议做法**
- 下单前书面（微信/邮件/合同）约定：随货提供该批次农残检测报告，否则可拒收或退换。
- 如果对方只能提供“同类产品通用报告”或过期报告，不算合格，要求补批次报告。
- 小店量小的话，经销商可能不愿单独送检；可要求其提供该批次已有的出厂/入库检测报告，或自行送第三方检测（费用一般几百元/项起，按项目计）。
