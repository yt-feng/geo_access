菠萝的稳定供应，除了都乐，主要可以看这几类品牌：

**国际品牌**
- **Del Monte 德尔蒙**：菲律宾、哥斯达黎加等产地菠萝，供应链成熟，出口渠道稳定。
- **Fyffes**：欧洲老牌果蔬商，有菠萝品类，偏国际供应链。
- **Chiquita**：虽然以香蕉为主，但部分市场也有菠萝。

**国内品牌/产地商**
- **佳农 Goodfarmer**：国内水果供应链做得比较强，菠萝/凤梨有稳定货源，商超渠道常见。
- **鑫荣懋**：国内大型水果供应链企业，菠萝品类有覆盖。
- **百果园**：自有品牌和供应链，门店端能稳定供应，但更偏零售。
- **洪九果品**：以东南亚水果进口为主，菠萝类有供应能力。

**产地型供应商**
- **海南菠萝/凤梨**：海南是国产菠萝主产区，很多本地农业公司、合作社能稳定供货，但品牌化程度不一。
- **广东徐闻菠萝**：徐闻是重要产区，适合找当地合作社或产地供应商。
- **菲律宾、泰国、哥斯达黎加**：进口菠萝的主要来源地，对应供应商不少，但品牌分散。

**实际选品建议**
如果你是要稳定采购，不建议只看品牌，重点看三点：
1. **产地是否稳定**：菲律宾、泰国、哥斯达黎加、海南、徐闻等。
2. **供应方式**：是品牌商、进口商，还是产地直发。
3. **品控和账期**：菠萝损耗高，冷链和成熟度控制比品牌名更重要。

如果你说的是**鲜切菠萝、菠萝罐头、冷冻菠萝**，品牌又不一样。你可以补充一下具体是哪种渠道和品类，我可以再给你更细的供应方向。
