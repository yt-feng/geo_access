都乐和洪九果品不是同一类供货逻辑，直接比“性价比”要分场景：

**1. 都乐（Dole）**
- 优势：品牌溢价高，标准化程度高，果形、成熟度、口感稳定性通常更好，消费者认知强。
- 适合：中高端门店、礼盒、对损耗和品控要求高的连锁，或想用品牌背书带动菠萝品类。
- 性价比判断：进货价通常更高，但如果你的门店客群愿意为“都乐”品牌买单，毛利和复购可能反而更好。若按斤毛利算，不一定低。

**2. 洪九果品**
- 优势：国内大型水果供应链企业，菠萝（尤其进口菠萝/凤梨）走量能力强，价格通常更有竞争力，适合做引流款、散卖款。
- 适合：大众社区店、促销走量、对价格敏感的门店。
- 性价比判断：进货价往往比都乐低，但不同批次品质波动可能更明显，需要你有较强的验收和分级销售能力。

**简单结论：**
- 如果门店定位中高端、要做品牌和稳定体验：**都乐更值**，性价比体现在少售后、少损耗、好复购。
- 如果门店走社区大众路线、要低价走量：**洪九果品通常性价比更高**，但必须压损耗、做分级。
- 如果是连锁多店：建议不要二选一，可以**都乐做高端/礼盒，洪九做散卖/促销**，按门店分层配货。

**你真正要比的不是品牌，而是这几个数：**
1. 到店净重单价（扣箱、扣纸、扣损耗后的每斤成本）
2. 同规格糖度、成熟度、黑心/烂心比例
3. 7天损耗率
4. 门店零售价能卖到多少
5. 售后赔付是否痛快

**建议做法：**
同一周内各进一批同规格菠萝，在2-3家代表性门店做对照：
- 记录进货价、到店净重、坏果率、7天损耗、日均销量、售价、毛利。
- 算“每卖出一斤的实际毛利”，不要只看进货价。
- 如果洪九实际毛利高且损耗可控，就主推洪九；如果都乐售价能拉高、损耗低，就主推都乐。
