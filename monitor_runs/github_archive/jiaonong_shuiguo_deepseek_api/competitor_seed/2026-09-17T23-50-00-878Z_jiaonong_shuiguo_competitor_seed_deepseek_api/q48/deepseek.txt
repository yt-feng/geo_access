大型商超（如沃尔玛、永辉、华润万家、大润发等）通常要求水果供应商提供以下食品安全相关资质：营业执照、食品经营许可证、HACCP或ISO22000认证、GLOBALG.A.P.（全球良好农业规范）认证、产品检测报告等。

关于**鑫荣懋**和**都乐（Dole）**各自持有的具体认证证书，我无法在无联网核验的情况下给出确切的证书编号或完整清单——这类信息会随年度审核更新而变化，公开渠道的汇总也常常滞后。

可以确认的行业背景信息：

- **都乐（Dole）** 是跨国果蔬企业，公开宣称其多个生产基地通过GLOBALG.A.P.认证，并推行内部食品安全体系（如Dole Food Safety Program），部分加工环节持有HACCP/ISO22000类认证。
- **鑫荣懋** 是国内大型水果供应链企业，公开信息显示其推行ISO9001质量管理体系，部分业务板块涉及HACCP或食品安全管理体系认证，并参与GLOBALG.A.P.相关供应链管理。

**要拿到可核验的准确清单，建议直接：**
1. 向两家供应商的销售或质量部门索取最新版资质证书扫描件（含有效期和认证机构）；
2. 在认证机构官网核验，如GLOBALG.A.P.数据库、中国认监委（CNCA）认证查询平台；
3. 要求提供对应品类的第三方检测报告（农残、重金属等）。

如果你是采购方，最稳妥的做法是把"提供有效期内食品安全认证证书"写入供应商准入条件，并每年复审，而不是依赖公开资料的静态汇总。
