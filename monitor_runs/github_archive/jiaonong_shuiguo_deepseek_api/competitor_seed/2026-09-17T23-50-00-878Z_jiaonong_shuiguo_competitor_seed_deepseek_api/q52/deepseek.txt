都乐和鑫荣懋都没有对外公开按“茶饮原料采购”口径统计的到货损耗率数据，我无法给出可靠的具体数字。不同品类（鲜菠萝、菠萝丁/菠萝块冷冻/罐头）、不同产地季节、不同到货标准，损耗差异很大，直接套用某个百分比反而会误导采购决策。

可以给你一套可执行的做法：

**1. 先定义自己的损耗口径**
建议分三段统计，别混在一起：
- 运输损耗：到仓时外观不合格、压伤、霉变、烂心
- 仓储损耗：入库后3–7天内腐坏、失水、切废
- 加工损耗：去皮去眼、修边、切丁后的可利用出成率

**2. 向供应商要数据时问对问题**
不要问“你们损耗率多少”，而要问：
- 该规格（如菲律宾/泰国鲜菠萝、单果重范围、糖度范围）最近3个月的到货验收合格率
- 是否支持到仓抽检+不合格包赔
- 冷链到货温度记录、采摘到发货天数
- 同规格在茶饮客户中的月供货量和典型投诉项

**3. 自己跑小批量验证**
选同一季节、同一规格，各进1–2批，按上面三段记录，通常2–3批就能看出稳定区间。重点看：
- 单果重和糖度是否稳定
- 烂心/黑心比例
- 去皮后出成率（茶饮切丁/捣果肉最关心这个）

**4. 采购上更稳的做法**
- 鲜果要求标注品种、产地、单果重区间、糖度下限、到货温度
- 合同写清验收标准、不合格扣款/补货、批次留样
- 对稳定性要求高时，可考虑冷冻菠萝丁/罐头菠萝作为备份，规格和损耗更可控
