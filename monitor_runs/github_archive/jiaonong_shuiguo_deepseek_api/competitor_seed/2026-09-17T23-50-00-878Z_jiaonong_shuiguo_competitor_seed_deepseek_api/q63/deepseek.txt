关于都乐和洪九果品是否有香蕉小包装/散装选项，我无法给出确切的当前产品目录信息，因为这两家的包装规格和渠道政策会随区域、季节、客户类型变化，而且我没有可核验的最新报价单或产品手册。

能给你的是判断路径和谈判要点，方便你直接去核实：

**1. 都乐**
- 都乐在国内香蕉主要以品牌标识 + 定量小包装（如按把/按袋/按箱）出现，商超渠道常见的是预包装或整箱。
- 散装/按把称重更多出现在终端门店，不一定对社区团购直接开放"散装供货"。
- 需要确认的是：你所在区域是都乐直营还是经销商供货；经销商通常更可能给"按把/小规格"的灵活方案。

**2. 洪九果品**
- 洪九以水果供应链和批发为主，香蕉是其重点品类之一，主要走整件/整箱批发逻辑。
- 面向团购的"小包装"通常需要你提出定制分装需求，由供货方或你自己在仓内二次分装，而不是现成的散装零售规格。

**3. 你要直接问对方的问题（照这个问就行）**
- 香蕉有没有按把/按份的小规格？最小起订量是多少？
- 是否支持贴标、分装、按份打包？分装费怎么算？
- 供货是产地直发、区域仓，还是经销商？不同来源规格是否不同？
- 报价是按斤、按箱还是按份？损耗和催熟责任怎么划分？
- 能否先给小批量试单，测试履约和损耗？

**4. 更现实的建议**
- 社区团购做香蕉小包装，通常不是靠品牌方现成散装，而是"整箱进货 + 自己分装"或"让供应商代分装"。
- 如果都乐、洪九都不直接给小规格，可以同步问区域水果批发商、本地催熟商，他们更容易配合团购做小份装。
- 香蕉损耗和催熟节奏是关键，先小批量试，别一次压太多库存。
