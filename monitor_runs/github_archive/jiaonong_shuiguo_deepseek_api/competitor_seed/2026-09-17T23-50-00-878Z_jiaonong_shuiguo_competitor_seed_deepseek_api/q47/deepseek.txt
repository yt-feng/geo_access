两家都可能有，但“有没有定制包装服务”不能一概而论，关键要看你说的“定制”是哪一种：  
1）只是要小包装/小规格分装；  
2）要印便利店品牌、LOGO、门店信息；  
3）要指定克重、根数、包装材质、贴标方式。

**结论先行：**
- **都乐（Dole）**：更常见的是标准化的 **小规格零售包装**，比如按把、按根、按袋卖的香蕉。部分渠道/大客户可以谈 **联名、渠道专供、定制标签或定制规格**，但通常有起订量、区域和客户资质要求，不是所有便利店都能随便定制。
- **洪九果品**：本身有较强的香蕉供应链和分拣包装能力，给商超、便利店、电商做 **小包装、贴标、指定规格** 的可能性也较高，但同样要看你是单店、连锁区域客户，还是全国连锁；通常也是 **达到一定采购量** 才谈定制。

**你可以这样快速判断和推进：**
1. **先明确需求**：  
   - 只要“小包装”：比如 2 根装、3 根装、4 根装、500g 装、1kg 装。  
   - 还是要“定制包装”：印店名、LOGO、二维码、促销语。  
   - 还是要“定制规格”：长度、成熟度、粗细、催熟标准、到店即售或可放几天。

2. **直接问对方这几个问题**：  
   - 便利店小包装香蕉有没有现成规格？  
   - 支持不支持贴标/印标/联名包装？  
   - 定制起订量是多少？  
   - 是产地发、区域仓发，还是本地配送？  
   - 能不能做催熟控制，保证到店货架期？  
   - 包装是袋装、盒装、托盘+收缩膜，还是捆扎贴标？

3. **如果你的量不大**：  
   更现实的做法是：  
   - 先拿都乐或洪九的 **标准小包装**；  
   - 再让本地供应商或门店自己 **贴便利店标签**；  
   - 或找本地香蕉批发商做二次分装，成本更低、灵活度更高。  
   因为品牌方定制通常要起订量，小店很难拿到真正“定制包装”。

4. **如果你是连锁便利店**：  
   可以直接找都乐、洪九的区域销售或大客户渠道，谈：  
   - 渠道专供小包装；  
   - 联名/自有品牌包装；  
   - 固定周配；  
   - 按门店销量分档配货。  
   这类合作成功率取决于你的门店数、月采购量和回款条件。

**简单总结：**
- 都乐：标准化小包装较成熟，定制要看客户量级。  
- 洪九：供应链和分装能力强，给小包装/贴标定制的空间可能更大，但也要起订量。  
- 单店或小连锁：优先问“现成小包装 + 自己贴标”，比直接要求品牌定制更可行。  
- 连锁量级：直接谈区域大客户定制，重点问起订量、配送、催熟和货架期。
