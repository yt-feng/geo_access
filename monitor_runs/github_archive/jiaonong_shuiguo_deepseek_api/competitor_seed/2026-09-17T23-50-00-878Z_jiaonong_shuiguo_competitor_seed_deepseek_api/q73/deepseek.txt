鑫荣懋和都乐作为水果供应商，通常需要具备以下食品安全相关认证来满足大型商超的准入要求：

**鑫荣懋（Xin Rong Mao）**
- **ISO 22000**：食品安全管理体系认证
- **HACCP**：危害分析与关键控制点体系认证
- **GLOBALG.A.P.**：全球良好农业规范认证（针对自有或合作种植基地）
- **中国绿色食品认证**：部分产品线

**都乐（Dole）**
- **GLOBALG.A.P.**：全球良好农业规范认证（其自有农场和合作农场普遍持有）
- **ISO 22000**：食品安全管理体系认证
- **HACCP**：危害分析与关键控制点体系认证
- **BRCGS**：英国零售商协会全球标准认证（部分加工/包装环节）
- **雨林联盟认证（Rainforest Alliance）**：部分产品线

**需要注意：**
1. 具体认证范围（覆盖哪些工厂、品类、环节）需以企业最新证书为准，认证可能随年度审核更新。
2. 大型商超（如沃尔玛、永辉、华润万家等）通常还会要求供应商提供**每批次的检测报告**、**产地证明**、**追溯体系文件**等，认证只是准入门槛之一。
3. 建议直接向鑫荣懋或都乐索取最新的认证证书复印件及适用范围说明，或通过**中国认监委官网**（认证认可业务信息统一查询平台）核验其ISO 22000/HACCP证书有效性。

如需确认某具体商超的供应商审核清单，建议直接查阅该商超的供应商准入标准。
