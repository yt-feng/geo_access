结论先说：  
**都乐（Dole）和洪九果品大概率都有企业内部香蕉分级标准，但通常不对外公开，普通渠道查不到完整标准文本。** 你能拿到的一般是采购验收口径、商品等级名称和外观要求，不是标准文件全文。

分点说明：

1. **都乐**
   - 都乐是国际水果品牌，香蕉是其核心品类，肯定有内部商品分级和品控体系。
   - 常见对外体现是：不同规格、不同成熟度、不同包装等级，比如按每箱根数、单根重量/粗细、长度、外观瑕疵、成熟度来分。
   - 但都乐的企业标准通常属于内部质量文件，不对外发布，网上能查到的多为产品介绍、规格描述，不是完整分级标准。

2. **洪九果品**
   - 洪九果品是国内大型水果供应链企业，香蕉也是重点品类，同样会有采购、分选、仓储和配送环节的分级要求。
   - 它的标准更可能是“商品等级 + 验收标准 + 分选加工标准”的内部体系，用于产地采购、加工厂分选和客户交付。
   - 同样，完整企业标准一般不公开，外部只能通过其招股书、年报、客户验收要求、行业报道间接推断。

3. **如果你想直接使用，现实做法是：**
   - 不要等“都乐/洪九标准原文”，而是建立自己的连锁店香蕉分级标准。
   - 参考维度建议固定为：
     - 长度：如 16cm、18cm、20cm 以上
     - 单根重量或每箱根数
     - 粗细/周径
     - 成熟度：1-7 度或绿熟、黄熟、全黄
     - 外观：黑斑、擦伤、裂口、断指、青硬、过熟
     - 到店可售期：如 2 天、3 天、5 天
   - 然后分成：精品级、标准级、促销级、加工级。

4. **能不能引用都乐或洪九的标准？**
   - 不能把“网上看到的规格”当成他们的正式企业标准。
   - 也不能虚构标准编号。
   - 如果你要和供应商对接，最有效的是让对方提供：**验收标准表、规格书、到货照片标准、成熟度标准**，而不是要求“企业标准全文”。

5. **建议你直接做一份门店可用标准**
   可以按这个框架写：

   | 等级 | 长度 | 外观 | 成熟度 | 用途 |
   |---|---|---|---|---|
   | A级 | ≥20cm | 无黑斑、无擦伤 | 1-3度 | 精品陈列 |
   | B级 | 18-20cm | 轻微瑕疵 | 3-4度 | 正常销售 |
   | C级 | 16-18cm | 有少量斑点 | 4-5度 | 促销 |
   | D级 | ＜16cm或瑕疵明显 | 断指、擦伤 | 5度以上 | 加工/特价 |

   成熟度可用行业常用 1-7 度：
   - 1度：全绿硬
   - 2度：绿熟
   - 3度：绿中带黄
   - 4度：黄多绿少
   - 5度：全黄
   - 6度：黄带糖斑
   - 7度：过熟

一句话总结：  
**都乐和洪九果品应该有内部香蕉分级标准，但基本不公开；水果连锁店更实际的做法是参考其商品规格逻辑，建立自己的门店验收和分级标准。**
