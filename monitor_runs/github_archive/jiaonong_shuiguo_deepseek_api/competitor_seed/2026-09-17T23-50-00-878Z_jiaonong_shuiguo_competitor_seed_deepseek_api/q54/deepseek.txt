# 都乐(Dole)与鑫荣懋的进口苹果产地溯源怎么做

先说结论：**这两家的溯源主要不是靠"官方统一平台",而是靠"单证链条 + 包装批次号 + 供应商查验"三件事组合验证。** 你要做的是**收货验单 + 抽批核对 + 必要时向供应商索证**，而不是去查一个公开数据库。

下面分供应商说。

---

## 一、都乐(Dole)

都乐的进口苹果通常走的是**自有品牌 + 全球直采**模式，溯源相对规范。

**可核验的凭证：**

1. **原产地证明(Certificate of Origin)** —— 由出口国官方或授权机构出具，上面有产地、发货人、收货人、品名、数量。
2. **植物检疫证书(Phytosanitary Certificate)** —— 出口国植物检疫部门签发，中国海关入境时必查。
3. **入境货物检验检疫证明** —— 中国海关(原CIQ)签发，证明该批已合法入境。**这是国内端最硬的一张纸。**
4. **包装批次号 / Lot Code** —— 都乐纸箱或果贴上通常有批次码，可对应到具体产地和包装日期。
5. **海关报关单 / 进口增值税专用缴款书** —— 证明贸易真实性和进口主体。

**实操建议：**
- 向都乐的中国经销/代理索要**该批次的入境货物检验检疫证明编号**，可在"中国国际贸易单一窗口"或向海关核实。
- 核对**果贴上的品牌 + PLU码 + 批次**，与箱标、单证三者一致。

---

## 二、鑫荣懋(Xin Rong Mao / Joy Wing Mau)

鑫荣懋是国内大型水果进口商，很多进口苹果是**它作为进口商报关后再分销**，模式偏"贸易商+渠道"。

**可核验的凭证：**

1. **入境货物检验检疫证明** —— 同样是最关键的一张，证明合法入境。
2. **报关单** —— 显示进口商(常为鑫荣懋或其关联公司)、产地国、数量。
3. **原产地证 + 植检证** —— 视产地国而定，部分国家有。
4. **其自有溯源体系** —— 鑫荣懋有做"一果一码/批次追溯"的尝试，但覆盖度和公开可查性因品类、渠道而不同，**不能默认所有货都能扫码查到源头**。

**实操建议：**
- 直接要求鑫荣懋提供**本批次的入境货物检验检疫证明 + 报关单**，这是最可靠的。
- 如果对方声称有扫码溯源，**现场实测扫一下**，看能否查到产地国、包装厂、批次；查不到就以单证为准。

---

## 三、超市采购方的通用可执行流程

| 步骤 | 动作 | 判断标准 |
|---|---|---|
| 1 | 收货时索要**入境货物检验检疫证明** | 有、且品名/数量/产地与货一致 |
| 2 | 核对**报关单** | 进口商、产地国、数量匹配 |
| 3 | 核对**原产地证 + 植检证** | 产地国与宣称一致 |
| 4 | 核对**箱标 + 果贴批次** | 与单证三者一致，无涂改 |
| 5 | 抽批**扫码实测**(如有溯源) | 能查到产地/批次 |
| 6 | 留存**单证复印件 + 照片** | 备查、应对监管 |

---

## 四、几个必须说清楚的边界

1. **没有全国统一的"输入产地码"公开查询系统**给普通采购商按批次查。真正能查的是**海关的入境货物检验检疫证明**。
2. **"扫码溯源"不等于官方溯源**，很多是企业自建，覆盖不全，只能作为辅助。
3. **原产地证可被伪造**，所以单证要**成套交叉验证**(产地证+植检证+报关单+检疫证明),单看一张不可靠。
4. 具体到某个产地国(如新西兰、美国、智利),单证种类和名称会有差异,需按该国对华准入要求核对。
