都乐和鑫荣懋的产地直发时效没有统一的公开承诺值，实际取决于发货产地、目的地、是否用其冷链仓配、以及当季运力。可以按下面方式判断和推进：

1. **先锁定产地和到货城市**  
   菠萝产地直发常见从广东徐闻、海南、广西等地发出。你需确认是“产地仓直发”还是“销地仓调拨”，两者时效差异很大。

2. **向两家分别索要时效表**  
   直接问区域销售或供应链对接人，要求提供：
   - 起运产地仓/合作果园到你的收货城市的**标准时效**
   - 冷链干线班次（每周几班、截单时间）
   - 是否支持**一件代发**、面单和售后归属
   - 旺季/节假日时效波动承诺
   - 坏果率、到货温度或成熟度验收标准

3. **用试单核验，不只看口头承诺**  
   建议选同一产地、同一目的地、同一包装规格，各下小批量试单，记录：下单到揽收、揽收到目的地、签收总时长、破损/坏果率、温控情况。至少跑2—3个批次再定。

4. **合同里写清时效和赔付**  
   把“截单时间、发出时限、到达时限、延误赔付、坏果赔付、旺季运力保障”写进合同或SLA，避免只靠销售口头说明。

**可执行结论**：目前无法可靠给出都乐和鑫荣懋的具体时效数字；建议你先确定产地和目的城市，再向两家区域供应链负责人索要书面时效表，并用小批量试单对比。若你提供“发货产地—收货城市—预计日单量—是否需要一件代发”，我可以帮你整理一份向两家询价和试单的核对清单。
