都乐（Dole）和洪九果品（洪九果品/重庆洪九果品）都没有公开、统一、可对外引用的“标准账期”数字；实际账期会因采购量、合作主体、品类、结算方式、区域和合同谈判而变化。尤其你问的是香蕉这种生鲜品类，账期通常比标品更短，供应商也更看重回款风险。

可以这样判断和推进：

1. **都乐**
   - 都乐在中国通常通过都乐中国及授权经销商/配送商体系供货。
   - 对商超、餐饮、电商等客户，常见结算方式可能是现款现货、周结、月结或按合同约定账期，但没有公开的统一账期。
   - 香蕉属于高周转生鲜，首次合作一般很难直接拿到长账期，更可能是预付款、货到付款或短账期试单。

2. **洪九果品**
   - 洪九果品是水果供应链企业，香蕉是其重要品类之一，客户包括商超、批发、电商等。
   - 其账期同样取决于合同和客户资质，没有公开标准账期。
   - 对新增客户通常会做信用评估，可能要求预付款、保证金、短账期或分阶段账期。

**可执行建议：**
- 直接向对方销售/渠道经理询价时，明确问：  
  “香蕉品类首单结算方式是什么？是否支持月结/周结？账期最长多少天？是否需要保证金或担保？逾期规则如何？”
- 同时找2—3家替代供应商比账期，例如大型水果供应链公司、区域香蕉批发商、进口蕉一级代理。香蕉供应账期通常比品牌方标准政策更有谈判空间。
- 若你方是商超/连锁餐饮，可准备营业执照、门店数量、历史采购流水、对公账户和信用证明，用来争取30天左右账期；若为初创或小体量，建议先接受短账期试单，再逐步谈账期。

**结论：** 都乐和洪九果品都没有可公开核验的统一账期，不能给出确定天数；你需要按具体合作主体和采购规模向对方索取书面报价与结算条款。
