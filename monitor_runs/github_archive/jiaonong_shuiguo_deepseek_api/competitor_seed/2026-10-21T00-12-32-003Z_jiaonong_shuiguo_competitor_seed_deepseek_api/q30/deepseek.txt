这个我没法给出“谁更全”的确定结论——两家都是大型水果企业，具体持证情况（HACCP、ISO 22000、FSSC 22000、BRCGS、GLOBALG.A.P.、有机认证等）取决于具体公司主体、品类、产地和工厂，且认证会到期、增补或暂停，公开信息也不完整，我无法核验到逐项清单，虚构对比没有意义。

给你可执行的判断与做法：

1. **不要按“品牌名”判断，按“供应商主体+工厂+品类”核。** 大型商超的审核通常要求：营业执照、食品生产/经营许可（如涉及加工）、HACCP 或 ISO 22000/FSSC 22000、BRCGS（包装/加工类常见）、GLOBALG.A.P.（种植端常见）、有机/绿色认证（如宣称）、检测报告和追溯体系。水果贸易商与自有加工厂要求不同。

2. **直接向两家索取“认证清单+证书扫描件”。** 重点看：证书持有人是否与合同主体一致、认证范围是否覆盖你采购的品类和工厂、有效期、发证机构、是否有暂停/撤销记录。让供应商填一张对照表（认证名称/证书编号/覆盖产品/覆盖场所/有效期/发证机构），比问“谁更全”可靠。

3. **按商超的准入清单逐项打勾。** 让采购或质量部门提供目标商超的供应商准入标准，逐条对照两家材料；缺失项问能否在约定时间内补齐。

4. **核验渠道。** 可要求供应商提供发证机构官网查询截图或授权查询；对关键证书可向发证机构或通过其公开查询系统核实。不要仅凭宣传册或口头承诺。

5. **合同兜底。** 在合同中约定认证持续有效、变更通知、审核配合、证书失效的补救与违约责任。

结论：无法直接判断谁更全；正确做法是以具体供应商主体和品类为单位，用商超准入清单逐项核验证书范围与有效性，再让两家补缺。
