都乐（Dole）和洪九果品的菠萝供应基地，公开可核验的信息如下：

**都乐（Dole）**
- 都乐在中国市场的菠萝主要来自其在**菲律宾**的种植基地（如棉兰老岛产区），这是都乐菠萝全球供应链的核心产区之一。
- 国内方面，都乐在**广东、海南**等地有合作或自营的鲜果供应体系，但都乐官方对外披露的“自有菠萝基地”信息有限，建议直接联系都乐中国（上海）的鲜果事业部确认国内直采基地的具体位置和供应季。
- 注意：都乐很多国内销售菠萝实际是进口菲律宾菠萝，采购时需问清“进口还是国产、到港口岸、供应季”。

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，其菠萝核心基地在**泰国**（如尖竹汶、罗勇等产区），以泰国小菠萝、香水菠萝为主，通过磨憨、凭祥等口岸进入中国。
- 国内方面，洪九在**海南、广东徐闻**等菠萝主产区有采购或合作基地，但以其泰国进口菠萝为核心品类。
- 洪九的基地多为“合作种植+订单采购”模式，不是全部自有农场，采购谈判时要明确是基地直供还是市场调货。

**给采购的可执行建议**
1. 先定品类：要泰国小菠萝/菲律宾菠萝（进口季稳定）还是徐闻/海南菠萝（国产季3—6月集中）。
2. 直接向都乐中国、洪九果品区域销售索要：产地证明、果园/包装厂备案号、供应月份表、到岸口岸。
3. 稳定供应建议“进口+国产”双轨：国产季用徐闻/海南补量，进口季用菲律宾/泰国锁价，避免单一产区断供。
4. 要求供应商提供近12个月的供货记录和异常停供说明，比只看基地位置更能判断稳定性。

以上基地信息中，都乐菲律宾、洪九泰国及海南/徐闻布局属于行业公开信息；具体自有基地坐标和当季供应量需向企业官方核实，不宜直接采信二手说法。
