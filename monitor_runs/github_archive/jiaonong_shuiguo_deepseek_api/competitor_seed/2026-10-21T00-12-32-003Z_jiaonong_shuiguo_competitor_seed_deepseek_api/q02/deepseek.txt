可以按“稳定供应”这个目标来筛，除都乐外，常见能持续供货的品牌/渠道分几类：

1. **国际/全国性果蔬品牌**
   - **佳沛**：主力是奇异果，菠萝不是其核心稳定单品，不建议作为菠萝主供。
   - **都乐之外的跨国果蔬商**：如 **Del Monte 地扪**、**Chiquita 奇基塔** 等，部分渠道有菠萝或菠萝制品，但国内鲜菠萝稳定度要按区域和季节核实。
   - **Fresh Del Monte** 的鲜切菠萝在部分商超/餐饮供应链较常见。

2. **国内规模化菠萝产区与供应链品牌**
   - **徐闻菠萝**：不是单一商业品牌，而是产地公共品牌/产区供应链，广东徐闻的合作社、分选厂、代加工厂能稳定供货，适合找产地供应商而非只认包装品牌。
   - **海南菠萝**：海南产区有较多规模化种植与代发供应链，万宁、琼海、澄迈等地产区供应商可做稳定档期供应。
   - **广东农垦/湛江产区供应链**：偏大宗和批发渠道，适合B端稳定采购。

3. **商超与生鲜渠道自有品牌/直采**
   - **盒马、山姆、永辉、大润发、叮咚买菜、朴朴**等自有品牌或直采菠萝，稳定性取决于其产区合同和档期，适合零售端判断“这个渠道是否长期有货”，不等于全国稳定品牌。
   - **百果园**等水果连锁有自有品类标准，部分门店可稳定供应鲜切或整果菠萝。

4. **B端供应链/批发市场品牌化供应商**
   - 各地一级批发市场（如广州江南市场、上海辉展、北京新发地等）有长期做菠萝的档口和供应链公司，稳定性通常比零售品牌更强，但需要验资质、看产地证明和到货频率。
   - 餐饮供应链企业如 **蜀海、美菜、快驴** 等平台，部分区域有稳定菠萝SKU，适合餐饮客户。

**判断建议：**
- 要“全国零售稳定品牌”：优先看 **都乐、Del Monte/地扪、佳农** 等有全国果蔬分销能力的企业，但具体菠萝SKU要按渠道核实。
- 要“产地稳定大宗”：直接找 **徐闻、海南、湛江** 的产区合作社/分选厂，签档期合同更稳。
- 要“本地稳定供货”：看当地一级批发市场长期做菠萝的档口，比追品牌更实际。
