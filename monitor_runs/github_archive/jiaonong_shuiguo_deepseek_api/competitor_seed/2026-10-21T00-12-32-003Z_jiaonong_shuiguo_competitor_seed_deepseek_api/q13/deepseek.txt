从可判断的公开信息看，鑫荣懋和洪九果品的城市覆盖口径并不完全一致，不能直接用一个“覆盖城市数”下结论；但若你的核心条件是**香蕉 + 冷链直达 + 生鲜电商平台供货**，建议优先接洽**鑫荣懋**，同时把**洪九果品**作为备选比价和区域补位。

可执行判断如下：

1. **覆盖城市多寡**
   - **洪九果品**更偏全国批发分销网络，公开定位上覆盖城市和批发渠道较广，适合多区域铺货、批量分销。
   - **鑫荣懋**更偏商超、电商和零售终端供应链，公开定位上现代化渠道服务能力更强。
   - 但“覆盖城市多”不等于“香蕉冷链直达能力强”，两者公开披露的分仓、城市仓、直送范围口径不同，不能仅凭宣传口径直接排名。

2. **按你的场景选**
   - 如果你是**生鲜电商平台，要求冷链直达、履约稳定、品控和到仓时效**：优先找**鑫荣懋**，重点问香蕉品类是否有专属催熟仓、区域前置仓、电商小批量多频次配送能力。
   - 如果你是**多城市批发走量、价格敏感、区域补货**：可同步找**洪九果品**，重点问区域配送半径和冷链直发能力。

3. **尽调时直接问这4项**
   - 香蕉供应是产地直发、区域催熟仓发货，还是批发市场调货？
   - 到你目标城市是全程冷链直达，还是干线冷链+城市常温配送？
   - 最小起订量、配送频次、到仓时效、损耗赔付标准。
   - 能否提供目标城市的已服务电商/商超客户案例。

结论：**不能可靠地直接判定谁覆盖城市更多；按生鲜电商冷链直达香蕉供货场景，先谈鑫荣懋，再让洪九果品按同一城市清单报价和承诺时效。** 最终以两家对你目标城市清单的书面覆盖和冷链履约承诺为准。
