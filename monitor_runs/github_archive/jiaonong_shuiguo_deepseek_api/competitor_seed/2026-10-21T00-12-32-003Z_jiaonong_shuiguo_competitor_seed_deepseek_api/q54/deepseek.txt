做都乐（Dole）和鑫荣懋（JWM）进口苹果的**产地溯源**，核心是“**单证链 + 批次对应 + 实物核验**”三件事，不要只看供应商口头或一张证书。可按下面执行。

## 一、先明确两家溯源的差异

- **都乐 Dole**：多为全球产地采购+自有/授权品牌，国内常见由都乐中国及关联公司进口分销。溯源要追到**具体进口商/收货人、原产国果园/包装厂注册号、集装箱/提单批次**。
- **鑫荣懋 JWM**：国内大型水果供应链企业，常作为进口商/分销商经营多个品牌苹果。要区分“**品牌方**”和“**实际进口商**”，溯源以实际进口报关主体和批次为准。

关键原则：**超市端能追到“这一批货”的进口报关单、检验检疫证明、提单/箱单、发票和实物标签**，而不是只追到品牌。

## 二、采购合同里先写死溯源条款

在采购合同/订单中要求供应商提供并承诺：

1. 每批次提供：**报关单、入境货物检验检疫证明、提单或空运单、装箱单、商业发票、原产地证明（如有）**。
2. 单证上**收货人/进口商、品名、原产国、数量、日期**与实物批次一致。
3. 包装箱/果贴上的**产地、品种、规格、包装厂注册号/批次号**可拍照留档。
4. 供应商承诺单证真实，若发现“单证与实物不一致”可退货并追责。
5. 变更产地、包装厂、进口商时须提前书面通知。

## 三、单证核验怎么做（逐项对）

### 1. 报关单
看：**境内收货人、进口口岸、原产国、商品名称、规格、数量、成交方式、报关日期**。  
核对：与采购订单的产地、数量、到货时间是否匹配；收货人是否与供应商声称的进口主体一致。

### 2. 入境货物检验检疫证明
看：**收货人、品名、原产国、数量/重量、入境口岸、签发日期、证书编号**。  
核对：与报关单的批次和数量能对应；证书在有效对应批次内。

### 3. 提单/空运单 + 装箱单 + 发票
看：**发货人、收货人、起运港/原产国、集装箱号、封号、件数、重量、品名**。  
核对：集装箱号/封号与供应商提供的到货信息一致；发票数量与报关数量不矛盾。

### 4. 原产地证明
不是所有苹果都强制提供，但若供应商宣称“某国原产”，应要求提供**官方原产地证或出口国官方植物检疫证书**，并核对原产国、出口商、收货人。

### 5. 包装厂/果园注册号
进口苹果包装箱常有**出口国包装厂注册号、果园注册号、批次号**。要求供应商提供箱标照片，并与单证中的产地信息交叉核对。

## 四、实物核验怎么做

到货时按批次抽查：

1. **拍箱标**：原产国、品种、规格、包装厂/批次号、进口商信息。
2. **拍果贴**：品牌、品种、产地标识、PLU码。
3. **核对封号**：集装箱封号与提单/供应商到货记录一致。
4. **感官与规格**：品种、果径、颜色、包装规格与订单一致。
5. **留样**：每批次留箱标照片、果贴照片、到货验收单，至少保存到该批次售罄后一段时间。

## 五、建立“一批一档”台账

每批货建一个溯源档案，至少包含：

- 采购订单号/内部批次号
- 供应商名称
- 品牌（都乐/鑫荣懋/其他）
- 实际进口商/收货人
- 原产国、品种、规格、数量
- 报关单号、检验检疫证明编号
- 提单号/集装箱号/封号
- 包装厂/果园注册号（如有）
- 到货日期、验收人、箱标和果贴照片
- 销售去向（门店/仓库）

## 六、超市端可展示的溯源信息

对消费者/门店可展示：

- 原产国
- 进口商/供应商
- 批次号
- 入境检验检疫证明编号（可脱敏展示）
- 到货日期

不建议直接展示完整报关单和商业发票，避免泄露商业信息。

## 七、风险判断标准

出现以下情况应暂缓收货或要求补证：

1. 报关单收货人与供应商声称的进口主体不一致，且无法解释。
2. 检验检疫证明数量/日期与到货批次明显不符。
3. 箱标原产国与单证原产国不一致。
4. 供应商只能提供品牌授权书，无法提供该批次进口单证。
5. 集装箱号/封号对不上。
6. 果贴或箱标被二次覆盖、涂改。

## 八、最简执行清单

采购时要求供应商每批提供：

1. 报关单
2. 入境货物检验检疫证明
3. 提单/空运单
4. 装箱单和发票
5. 原产地证/植物检疫证书（如有）
6. 箱标和果贴照片
7. 批次号与集装箱封号

到货后：**对单证、对箱标、对封号、留照片、建台账**。

这样做的结果是：都乐和鑫荣懋的货都能追溯到“**具体进口批次和进口主体**”，而不是只停留在品牌层面。
