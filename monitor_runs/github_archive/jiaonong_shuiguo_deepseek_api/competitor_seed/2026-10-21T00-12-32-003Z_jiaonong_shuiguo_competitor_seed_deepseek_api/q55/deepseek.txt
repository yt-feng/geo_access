都乐和洪九果品都属于有产地/基地资源、可谈“基地直供+溯源”的供应商，但**是否对你这一单开放基地直供和批次级溯源，要按品类和合同单独确认**，不能默认全品项都支持。

**都乐（Dole）**
- 有自有及合作种植基地，菠萝是其重要品项之一，具备产地直供能力。
- 溯源通常体现在批次、包装标识、产地证明、检测报告等文件上；是否能开放到“基地—田块—采收批次”级别，需要向都乐中国区销售确认。
- 适合对品牌稳定性、标准化要求高的渠道；起订量和价格通常高于批发市场。

**洪九果品**
- 以水果供应链和产地直采为主，菠萝（尤其进口菠萝）是其重点品类之一，具备基地/产地直采资源。
- 溯源能力一般可提供产地证明、入境货物检验检疫证明（进口）、批次信息等；国内基地直供的田块级溯源需具体确认。
- 适合需要规模化直采、价格有竞争力的渠道；对溯源颗粒度要提前写进合同。

**可执行建议**
1. 向两家分别索要：菠萝产地清单、基地/合作社名单、当季可供批次、溯源文件模板。
2. 明确你要的溯源层级：产地证明级、批次级、基地/田块级，三者成本和管理要求不同。
3. 要求提供近一批次的完整溯源样例（产地证明、检测报告、采收/加工日期、包装批次号）。
4. 合同中写明：产地不符或溯源文件缺失的退换货与违约责任。
5. 若两家基地直供门槛过高，可同步接触产地龙头合作社或区域供应链公司做补充。

结论：**两家都“有基地直供能力”，但都乐偏品牌标准化直供，洪九偏产地直采供应链；能否对你开放基地直供和批次溯源，需按具体菠萝品类、采购量和合同逐项确认。**
