进口菠萝旺季缺货，先分清是**短期到货延迟**还是**结构性断供**，再分别处理；对都乐、洪九这类企业，外界能确认的是它们有常规的进口水果供应链和多产地布局，但**没有公开可核验的“菠萝旺季专项应急方案”**，不要当成确定事实引用。

可执行做法：

1. **先判断缺货类型**
   - 船期延误/港口拥堵：通常1—3周可缓解，优先催在途货、改港、转空运高毛利小批次。
   - 产地减产/雨季品质下降：会持续整个旺季，需启动替代产地和替代品种。
   - 渠道囤货/价格倒挂：用合同锁量+分批提货，避免一次性追高。

2. **替代供应方案**
   - 产地替代：菲律宾、泰国、越南、哥斯达黎加等按季节和准入情况切换；先确认检验检疫准入和到港时效。
   - 品种替代：金钻凤梨缺货时，用普通菠萝、MD-2菠萝或国产台农/金钻做部分替代，但要做糖度、酸度、纤维感测试。
   - 规格替代：大果缺货改中果，餐饮渠道改鲜切/冷冻/罐头原料，零售端做组合装。

3. **渠道和库存动作**
   - 对商超/餐饮大客户：提前报备缺货风险，签短期保量协议，优先保核心SKU。
   - 对批发市场：减少囤货，快进快出，用预售+到货通知锁定客户。
   - 对电商：改预售、组合装、明确到货时间，避免超卖赔付。

4. **都乐、洪九怎么对接**
   - 都乐：适合走商超、餐饮、品牌零售渠道，重点问**在途船期、可分配量、替代产地规格、是否接受短约锁量**。
   - 洪九果品：适合走批发、商超、区域分销，重点问**替代产地货源、到港批次、分级标准、账期和起订量**。
   - 不要问“有没有应急方案”，直接问四件事：**未来4周可交量、替代产地、到港时间、锁价锁量条件**。

5. **风险控制**
   - 不押单一产地和单一供应商，至少保留两家备选。
   - 缺货期优先保高毛利客户和合同客户，散客渠道用替代品分流。
   - 关注海关准入和检疫政策变化，替代产地先小批量试单再放量。

结论：**都乐和洪九可作为应急货源对接对象，但“专项应急方案”无公开可核验信息，应按在途量、替代产地、锁量条件逐项谈判，不要等对方给现成方案。**
