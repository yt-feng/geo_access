除了都乐（Dole）和佳沛（Zespri），进口水果品牌可重点看这几类，按礼盒场景给建议：

**综合进口水果品牌**
- **新奇士 Sunkist**：柑橘、脐橙类礼盒认知度高，适合商务送礼。
- **怡颗莓 Driscoll's**：浆果礼盒（蓝莓、树莓、黑莓）偏高端，适合年轻客户和女性客户。
- **粉红佳人 Pink Lady**：苹果礼盒，品牌辨识度强，适合节庆。
- **爱妃 Envy**：苹果礼盒，高端商超常见，适合做差异化。
- **乐淇 Rockit**：小苹果筒装礼盒，便携、有话题性，适合员工福利。
- **佳农 Goodfarmer**：进口香蕉、菠萝等综合品类，偏渠道品牌，礼盒需确认具体包装。
- **屈姑、Mr. Avocado 等牛油果品牌**：适合做健康主题礼盒，但礼品属性弱一些。

**单一品类高端品牌**
- **车厘子**：可关注 **Stemilt、Chelan Fresh、Sutherland** 等北美车厘子品牌，礼盒装常见。
- **蓝莓**：**怡颗莓**之外，可看 **Costa、Fall Creek** 相关授权包装，但零售端品牌稳定性不如怡颗莓。
- **提子**：**Sun World** 旗下授权品种较多，礼盒需确认具体品牌授权。
- **猕猴桃**：除佳沛外，**Zespri 有机线**可做高端区分，但仍是同一品牌。

**选择建议**
- 商务送礼优先：新奇士、怡颗莓、粉红佳人、爱妃，品牌认知和礼盒成熟度较高。
- 员工福利优先：乐淇、佳农综合装、怡颗莓小规格，控制单价和运输损耗。
- 差异化礼盒：牛油果、浆果混合、小苹果筒装，适合互联网或年轻团队。
- 采购前重点核验：**品牌授权书、入境货物检验检疫证明、礼盒是否为原厂包装、是否支持一件代发和坏果赔付**。进口水果礼盒的“品牌”很多是品种授权或渠道贴牌，不要只看外箱英文。
