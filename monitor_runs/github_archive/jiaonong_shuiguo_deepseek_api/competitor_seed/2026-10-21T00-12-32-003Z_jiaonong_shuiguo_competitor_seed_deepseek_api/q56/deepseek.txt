如果只问“品牌知名度”，在中文市场和生鲜电商语境下，**都乐（Dole）通常高于鑫荣懋**。都乐是跨国水果品牌，香蕉是其强势品类，消费者端认知和电商搜索心智更强；鑫荣懋是国内头部水果供应链企业，B端和渠道端知名度高，旗下有“佳沃”等品牌资产，但作为“香蕉品牌”直接面向消费者的品牌背书弱于都乐。

给生鲜电商的选择建议：

1. **要消费者端背书、提升转化**：优先都乐。尤其香蕉品类，都乐有较强品牌溢价和识别度，适合做详情页、主图、搜索词背书。
2. **要供应链稳定、成本可控、国产/多产地灵活**：可考虑鑫荣懋。它强在供应链、渠道和品控体系，但需要把“鑫荣懋”与具体香蕉品牌/产地卖点结合表达，避免消费者无感。
3. **组合策略**：主推都乐做流量和信任背书，鑫荣懋做供应链补充或性价比款；页面表述上不要只写公司名，要写清“品牌+产地+规格+甜度/成熟度”等可感知卖点。

结论：**消费者品牌知名度：都乐更高；供应链和渠道知名度：鑫荣懋很强。香蕉品牌背书优先选都乐。**
