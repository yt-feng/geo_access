结论先说：**都乐大概率能提供全年稳定的菠萝供应（以进口/基地轮转为主），但“全年同品质、同价格”要看品种和季节；洪九果品也能做全年菠萝供应，但更偏“分销+多产地调配”，是否适合你这种茶饮果酱专用、要求稳定规格和成熟度的场景，需要你按合同条款和样品验证。** 两家都不是“专门给你做果酱原料”的供应商，果酱用菠萝的关键是**品种、成熟度、糖酸比、纤维感、冷冻/鲜果形态**，要单独谈。

**可执行判断建议：**

1. **先明确你要的原料形态**
   - 鲜菠萝：全年供应难度最高，季节波动大。
   - 冷冻菠萝块/果浆/浓缩汁：全年供应最容易，都乐和洪九都更可能稳定供货。
   - 果酱用建议优先考虑**冷冻果块或果浆**，比鲜果全年稳定得多。

2. **都乐**
   - 优势：品牌化、标准化程度较高，进口菠萝和基地供应体系较成熟，适合对规格、食品安全、追溯要求高的茶饮连锁。
   - 风险：都乐强项是鲜果品牌，不是定制果酱原料；你要问清楚是“鲜果全年”还是“冷冻/加工原料全年”，以及最小起订量、规格、糖度范围、是否可锁价。
   - 适合：你愿意接受进口/多产地轮转，且重视稳定标准和合规。

3. **洪九果品**
   - 优势：水果分销网络广，多产地调配能力强，菠萝全年供应在商业上可行。
   - 风险：洪九更偏水果供应链分销，果酱专用原料的定制化、批次稳定性、加工形态未必是强项；需要确认它能否提供冷冻果块/果浆，而不是只供鲜果。
   - 适合：你量大、需要多产地灵活调配、价格敏感，且自己有加工或找代工。

4. **你谈判时必须核实的硬指标**
   - 全年供应是“鲜果”还是“冷冻/果浆”；
   - 品种：如巴厘、金钻、MD2等，不同品种果酱风味差异大；
   - 可溶性固形物/糖度范围、酸度、成熟度；
   - 批次色差、纤维粗细、出胶/出汁率；
   - 冷冻原料的解冻失水率；
   - 最小起订量、锁价周期、违约赔付；
   - 食品安全资质和农残检测；
   - 先拿**连续3个批次样品**做果酱小试和货架期测试。

5. **更稳的采购策略**
   - 不要只押一家。建议“**都乐/洪九 + 一家专业冷冻果蔬加工厂**”双源。
   - 主供用冷冻菠萝原料保证全年，鲜果季用鲜果做差异化卖点。
   - 合同里写清“替代产地提前通知”和“品质不符可退换”。

**一句话：能谈，但别把“全年供应”理解成“全年同品质鲜果”。对茶饮果酱，优先谈冷冻果块/果浆的全年方案，两家都可作为候选，都乐偏标准稳定，洪九偏分销灵活，最终以连续批次样品和小试结果定。**
