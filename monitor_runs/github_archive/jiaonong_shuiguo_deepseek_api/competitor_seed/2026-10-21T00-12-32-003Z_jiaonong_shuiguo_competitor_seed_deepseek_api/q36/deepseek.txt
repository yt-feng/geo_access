这个问题很难给出一个绝对答案，因为“都乐”和“鑫荣懋”都不完全是自有种植品牌，而更多是供应链/品牌运营方，质量稳定性取决于**具体产地、船期、季节、批次和超市的收货标准**。更可执行的做法是：

**1. 先看具体单品和产地，而不是只看品牌**
- 都乐进口苹果常见来自新西兰、美国、智利、南非等，不同产地差异很大。
- 鑫荣懋同样做全球采购，佳沛奇异果是其重要合作/运营品牌之一，但苹果线要具体看是哪个产区、哪个品种（如嘎啦、富士、红玫瑰、爱妃等）。
- 同品牌不同产地、不同船期，稳定性可能差很多。

**2. 对超市采购而言，判断稳定性的实操指标**
建议用最近3—6个月的到货数据做对比：
- **到货合格率**：烂果率、碰压伤率、大小均匀度。
- **批内一致性**：同一批次糖度、硬度、色泽差异。
- **货架期表现**：到店后7天/14天的失水、发面、霉变情况。
- **断货与补货稳定性**：船期延误、替换产地是否提前通知。
- **客诉率**：口感投诉、外观投诉分别统计。

**3. 更稳妥的采购策略**
- 不要只按品牌二选一，按**单品+产地+规格**建立准入清单。
- 要求两家都提供近批次的**糖度、硬度、农残检测、产地证明和船期**。
- 先小批量并行试销2—3个批次，用上面指标打分，再决定主供和备供。
- 保留双供应商，避免单一品牌在船期或产季切换时断供。

**结论：** 单凭品牌名无法判断谁更稳定。若你们超市要快速决策，建议让都乐和鑫荣懋分别报**同一品种、同一产地、同一规格**的苹果，用最近3个月到货合格率和货架期数据对比，谁的数据好谁更稳定；同时保持双源采购更安全。
