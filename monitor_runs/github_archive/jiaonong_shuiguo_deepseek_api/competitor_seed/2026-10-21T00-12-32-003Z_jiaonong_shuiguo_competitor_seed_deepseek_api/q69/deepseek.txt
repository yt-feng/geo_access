可以做结论：**都乐（Dole）在进口苹果的商品化分级和规格一致性上通常更稳，适合超市采购“规格统一”的要求；洪九果品强项更多在国产水果供应链和分销规模，进口苹果的分级稳定性要看具体产地、批次和供货渠道，不宜默认它比都乐更严格。**

判断依据和建议：

1. **都乐的优势是品牌化标准**
   - 都乐是国际果蔬品牌，进口苹果通常按品种、产地产区、果径/等级、包装规格做商品化分选，超市采购时更容易拿到明确的规格表。
   - 但要注意：都乐不同单品、不同进口来源，分级口径也可能不同，采购时要看具体合同规格，而不是只看品牌。

2. **洪九果品要按“渠道能力”看，不按“进口苹果分级专家”看**
   - 洪九果品是国内大型水果分销企业，优势在采购网络、品类覆盖和分销效率。
   - 它是否“分级严格”，取决于你对接的是它的哪个进口单品、哪个产地、哪一级批发渠道。不能简单说它分级不严格，但也不能像都乐那样默认有统一的进口苹果品牌分级体系。

3. **超市采购最实际的做法**
   - 要求供应商提供：**果径范围（如80/85/90）、着色标准、糖度参考、瑕疵率、单箱净重、包装方式、到货批次抽检报告**。
   - 先小批量试单，按批次抽检：**果径合格率、颜色一致性、碰压伤比例、大小混装率**。
   - 合同里写清楚：**规格不符的退换货标准、批次差异处理、到货验收抽样比例**。
   - 如果目标是长期稳定统一规格，优先选能提供**固定产地+固定分级口径+固定包装规格**的供应商，而不是只看品牌名。

**一句话建议：**  
要“规格统一、少出批次波动”，优先按都乐的明确规格单品去谈；洪九可以作为比价和备选渠道，但必须用你自己的验收标准去锁定批次，不能只依赖供应商口头承诺。
