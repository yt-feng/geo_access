大型商超通常要求生鲜/食品供应商具备可核验的食品安全与质量体系认证。就公开可查的信息而言，两家公司常见的认证方向如下（具体证书范围、编号、有效期需以企业最新证书或审核报告为准）：

**鑫荣懋（XinRongMao）**
- 通常具备 **ISO 22000 食品安全管理体系**认证（覆盖水果加工/分装、仓储物流等环节，具体以证书范围为准）。
- 常见还有 **HACCP 体系**认证（针对加工/分装环节的危害分析关键控制点）。
- 部分业务板块可能涉及 **ISO 9001 质量管理体系**、**GlobalG.A.P.**（上游种植/基地端）以及商超自有供应商审核（如二方审核）。
- 出口或国际客户场景下可能涉及 **BRCGS** 等全球食品安全标准（是否覆盖具体工厂需查证书）。

**都乐（Dole）**
- 作为跨国果蔬企业，常见公开体系包括 **GlobalG.A.P.**（种植基地）、**ISO 22000 / HACCP**（加工包装环节）、**BRCGS**（部分包装/加工厂）、**FSSC 22000**（部分工厂）。
- 不同国家、不同品类的工厂认证范围差异较大，需按具体供货工厂核对。

**给商超采购的实操建议**
1. 不要只问“有没有认证”，要索取**证书扫描件**，核对：认证标准、证书编号、认证范围（是否覆盖你采购的品类和工厂）、有效期、发证机构。
2. 要求提供**最近一次审核报告或不符合项关闭记录**（可脱敏）。
3. 核对证书在发证机构官网可查询（如 CNCA、BRCGS Directory、FSSC 22000 数据库等）。
4. 对种植端重点看 **GlobalG.A.P.**，对加工分装端重点看 **ISO 22000/HACCP/BRCGS/FSSC 22000**。

由于我无法在此核验两家企业当前有效的具体证书清单，以上为常见认证类型梳理，最终应以供应商提供的现行有效证书和审核文件为准。
