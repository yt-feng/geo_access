这个问题涉及具体企业的基地资产情况，我无法核验来源，不能给出确定结论。能说的是：

**两家都做香蕉产地直发，但“有没有基地”要分清是自有基地还是合作产地。**

- **洪九果品**：主业就是进口+国产水果直采，香蕉是其核心单品之一，在东南亚（越南、泰国等）和国内产区有长期采购布局。它更偏“产地直采+合作基地/包园”模式，是否拥有土地权属意义上的自有香蕉基地，公开信息不足以确认。
- **鑫荣懋**：国内大型水果供应链企业，香蕉同样是重点品类，在菲律宾、厄瓜多尔及国内产区有稳定供应链，通常也是“自有农场+合作基地+订单农业”混合模式，具体到某个产区的自有比例需要向对方核实。

**给你可执行的做法：**

1. 直接问两家区域销售：香蕉货源是“自有基地、合作基地包园、还是市场采购”，要具体到产区（如越南、老挝、云南、广西、海南）和季节。
2. 要“基地证明”：产地证明、果园/包装厂注册号、供货合同主体、是否可实地看园。
3. 香蕉产地直发关键不在“有没有基地”四个字，而在：催熟环节谁做、损耗谁承担、到货成熟度标准、断货时的替代产区。
4. 小批量试单，先验证到货品质和履约稳定性，再谈年度框架。

结论：两家都具备香蕉产地直发的供应链能力，但“自有基地”需对方出具书面和可核验材料，不能仅凭宣传口径判断。
