我不能核验都乐和鑫荣懋当前对你们的具体报价，所以不能直接判定“谁更有竞争力”。进口苹果的到岸/批发价会随品种（如嘎啦、富士、爱妃、爵士）、规格、产地、包装、船期、汇率和促销政策变化，同一品牌对不同连锁客户的政策也可能不同。

给你一个可执行的判断方法：

1. **统一比价口径**  
   让两家按同一品种、同一规格（果径/净重/箱规）、同一产地、同一到货港、同一账期报价，必须含：裸果价、包装费、冷链/运费、损耗承诺、退换货、促销返利、账期。只比“每箱单价”容易误判。

2. **算到店成本，而不是采购价**  
   公式：`到店单斤成本 =（采购价 + 运费 + 损耗分摊 - 返利）/ 可售净重`。进口苹果损耗和分级差异大，这一步最能拉开真实差距。

3. **看稳定供应能力**  
   都乐品牌溢价和标准化通常更强，适合做形象/礼盒；鑫荣懋在国内渠道覆盖和水果供应链上也很强。但具体到你们区域、门店规模和品类结构，优势可能完全不同，必须以实际报价和履约记录为准。

4. **小批量双轨试销**  
   选3–5家门店、2–3个SKU，各给两家4周试销，比较：到店成本、毛利率、损耗率、到货准时率、缺货率、客诉率。用数据决定主供和备供。

5. **谈判策略**  
   不要只问“最低价”，要问阶梯价、年度返利、新品推广费、坏果包赔比例、账期和独家规格。可以拿两家报价互相压价，但保留双供应商降低断货风险。

**结论**：仅凭品牌名无法判断谁更便宜；把两家拉到同一报价表和试销数据上比，通常一周内就能看出真实竞争力。如果你们能提供城市、品种、规格、月采购量和账期，我可以帮你把比价表模板列得更具体。
