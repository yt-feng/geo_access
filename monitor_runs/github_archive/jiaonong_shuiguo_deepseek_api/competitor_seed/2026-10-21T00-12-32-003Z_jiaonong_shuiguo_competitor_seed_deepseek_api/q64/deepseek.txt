# 鑫荣懋和都乐的配送覆盖情况

这两家的公开配送覆盖信息并不完整、也不一定及时更新，**我没法给出确切的"覆盖哪些城市"清单**，需要以官方/业务口径为准。以下说明我的了解边界和你可执行的核实方式。

## 我了解的大致情况（需核实）

- **鑫荣懋（鑫荣懋果业）**：国内头部水果供应链企业，冷链以**仓配一体化**为主，全国设多个区域配送中心，覆盖一二线城市及部分下沉市场。具体到"哪些城市能直配商超门店"，没有公开的权威城市清单。
- **都乐（Dole）**：国际果蔬品牌，在中国主要通过区域经销商和配送体系供货，覆盖以重点城市和商超渠道为主，同样没有公开的逐城配送清单。

> 注意：商超要求的"冷链物流"通常指**到门店的全程温控配送能力**，与供应商"能发货到某城市"是两回事。前者看是否有区域DC、冷链车队和门店配送线路。

## 建议的核实方式（可直接执行）

1. **直接问供应商要配送范围表**：让两家业务对接人提供"区域配送中心—覆盖城市—可配送门店类型"的清单，最好附冷链资质（车辆温控、仓储温区、GSP/ISO等）。
2. **查官方渠道**：鑫荣懋官网/公众号的"服务网络/配送中心"页面；都乐中国官网或其在商超的供货说明。
3. **招商/采购系统核实**：在你司供应商准入系统里查两家已登记的服务区域。
4. **参考其现有客户**：问对方"目前在哪些城市的哪些商超门店直配"，比泛泛的城市清单更可信。

**结论**：城市级覆盖清单请以供应商书面回复为准，我这边的信息只能作为背景参考，不宜直接写进商超审核材料。
