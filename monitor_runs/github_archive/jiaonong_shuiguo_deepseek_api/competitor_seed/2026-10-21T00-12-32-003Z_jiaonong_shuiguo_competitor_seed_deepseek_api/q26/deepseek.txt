没法替你拍板说“谁更靠谱”，因为两家都是大型水果供应链企业，具体到“菠萝做果酱”的稳定品质，取决于你拿到的**品种、产地批次、成熟度、加工规格和验收标准**，而不是品牌名本身。给几个可判断、可执行的点：

**1. 先明确你要的是哪种“菠萝原料”**
- 鲜果菠萝：看品种（如金钻/巴厘）、产地（菲律宾/泰国/国产广东海南等）、成熟度，鲜果批次波动天然大。
- 冷冻菠萝丁/菠萝果肉/菠萝果茸：更适合做果酱，规格稳定，比鲜果好控。
- 菠萝浓缩汁/果浆：适合调稳定酸甜，但风味层次和“果肉感”要另配。

**2. 都乐 vs 鑫荣懋的定位差异**
- 都乐：品牌化程度高，鲜果标准、包装和追溯体系较成熟，适合要“品牌背书+相对稳定鲜果”的店；但成本通常偏高，且不同渠道拿到的货可能不是同一等级。
- 鑫荣懋：供应链体量大、渠道覆盖广，鲜果和加工果都有资源，价格谈判空间可能更大；但具体品质要看你对接的供应商/区域仓，不能只看集团名。

**3. 做果酱更该看的硬指标**
要求两家都提供同一套样品和检测/规格：
- 可溶性固形物（糖度）、酸度、pH
- 成熟度/色泽/果肉完整度
- 农残检测报告
- 冷冻品还要看解冻失水率、微生物指标
- 批次一致性：连续 3 批样品的糖酸比波动范围

**4. 实操建议**
- 不要按“品牌”定，按**样品盲测 + 连续批次稳定性**定。
- 让两家各供 2–3 批同规格样品，你做小锅果酱，测出胶、色泽、酸甜、香气和出品杯测差异。
- 合同里写清：品种、产地、规格、糖度范围、成熟度、验收拒收标准、批次追溯。
- 如果门店规模不大、要省心，优先考虑**冷冻菠萝果肉/果茸的固定规格供应商**，比鲜果更容易稳定；都乐和鑫荣懋都可问，但关键看他们能否给你固定加工规格。

**结论**：做果酱追求稳定，优先选“固定加工规格+可追溯批次”的供应商，而不是单纯比都乐和鑫荣懋。若必须二选一，先让两家按你的果酱配方各送同规格样品做盲测和连续批次验证，再按糖酸稳定性、价格、供货响应定；没有样品数据前，任何“谁更靠谱”的结论都不靠谱。
