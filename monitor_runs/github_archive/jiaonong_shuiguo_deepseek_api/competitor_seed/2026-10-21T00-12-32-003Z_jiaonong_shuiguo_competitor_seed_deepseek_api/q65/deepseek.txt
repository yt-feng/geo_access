关于都乐和洪九果品的菠萝锁价周期，我无法给出可核验的具体数字，不能凭空编造。以下是可执行的判断和建议：

1. **公开信息通常不披露**：都乐（Dole）和洪九果品对商超、批发客户的锁价/框架协议属于商业合同条款，一般不会在官网或公开报道中写明“锁价周期”。不同客户、不同品类（鲜果/加工果）、不同采购量，周期差异很大，从单批次锁价到季度框架都有可能。

2. **不要直接采信“标准周期”说法**：如果对方销售或中间商报出一个固定周期，应要求写入合同并明确触发条件（如市场价格波动超过多少可调价、违约如何处理）。

3. **建议直接向供应商确认的清单**：
   - 锁价是按单批次、月度还是季度？
   - 锁价是否含运费、包装、损耗？
   - 市场价格下跌时是否可重新议价？上涨时供应商是否履约？
   - 锁价对应的菠萝品种、规格、产地和交货期。
   - 违约赔偿和保证金条款。
