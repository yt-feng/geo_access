到货损耗率不是固定值，取决于批次、运输距离、季节、验收标准和门店/仓库存放条件。都乐（Dole）和鑫荣懋（鑫荣懋集团）都不会公开统一的“到货损耗率”承诺值，我无法核验具体数字，不应给出虚构数据。

可执行建议：

1. **先定义损耗口径**：到货损耗 =（到货件数×标准净重 − 验收合格净重）/ 标准净重。要求供应商按同一口径提供近3个月批次数据。
2. **向两家分别索取书面数据**：近3个月同品种、同规格（如菠萝单果重区间、成熟度、包装规格）的到货批次损耗统计，以及冷链方式和到货时效。
3. **自己做小批量对比试单**：同一路线、同一验收标准，各下2–3批，记录破损、腐烂、失水、成熟度不达标比例。通常对比2–3周即可判断稳定性。
4. **合同里写验收与赔付条款**：明确规格允差、成熟度、损耗上限和超标扣款/补货机制，比问“损耗率是多少”更有效。
5. **稳定规格的关键**：锁定品种（如金钻/巴厘）、单果重区间、成熟度等级、包装层数和冷链温度，并要求每批附质检报告。
