可以明确分开看：

**1）都乐（Dole）**
通常有面向零售/便利店渠道的小规格香蕉产品，也具备按渠道做包装规格、标签、陈列包装的商务定制能力，但这类定制一般不是公开零售服务，需要走都乐官方渠道或区域经销商洽谈。便利店可问：小把/单根装、袋装/盒装、条码与标签、起订量、配送频次、损耗退换政策。

**2）洪九果品**
洪九主要是水果供应链/批发分销企业，具备分拣、分级、包装和渠道供货能力，通常可以谈小包装、贴标、按门店规格分装等定制，但同样要以区域销售或官方商务确认为准，不宜默认所有城市、所有门店规模都能接。

**结论：**
- 两家“有没有定制包装服务”：**大概率都有商务定制能力，但不是公开标准化服务，需要直接联系官方/区域经销确认。**
- 便利店更现实的做法：先找**本地都乐经销商**和**洪九区域销售**，同时对比本地香蕉分装商；小包装香蕉的关键不只是包装，而是**催熟度、配送频次、损耗承担和起订量**。

建议你询价时直接发这5项：门店数量、单店日销量、期望规格（单根/2-3根/小把）、是否需要贴门店标签、是否接受隔日配。这样对方才能给可执行报价。
