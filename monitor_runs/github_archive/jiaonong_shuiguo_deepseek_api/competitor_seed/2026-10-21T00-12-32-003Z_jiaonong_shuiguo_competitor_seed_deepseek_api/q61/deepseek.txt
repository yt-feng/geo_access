结论先说清楚：

1. **都乐（Dole）**：都乐公开面向客户/终端的有香蕉产品规格与分级做法（按品种、产地、果指长度/粗度、梳数/把数、成熟度、外观缺陷、包装规格等分级），但**我没有可靠公开来源证实“都乐有对外发布、可引用的企业标准文本（标准号级）”**。更稳妥的表述是：都乐有内部产品规格/验收分级体系，是否以“企业标准”形式公开备案，无法从公开资料核验。
2. **洪九果品**：洪九有香蕉等品类的采购、分选、包装和品控流程，属于企业内控/产品规格体系；**同样没有可靠公开来源证实其对外发布可引用的香蕉“企业标准”文本或标准号**。不要把它们当成可直接引用的公开标准。

给水果连锁店的可执行建议：

- **不要等待或引用都乐/洪九的“企业标准”作为门店分级依据**，除非你能拿到对方书面规格书或标准文本；否则以“供应商规格书+到货验收标准”形式落地。
- 自建门店香蕉分级标准，建议按以下维度设置可判定阈值：
  1. **果指长度/粗度**（按品类定位设区间，如精品/常规/促销三档）；
  2. **梳形与把数**（整梳、散把比例，断指率上限）；
  3. **成熟度**（到货青度/催熟后色卡等级，建议用色卡编号判定）；
  4. **外观缺陷**（机械伤、黑斑、炭疽病斑、裂果、日灼、污损的面积或个数上限）；
  5. **整齐度**（同批次长度、色泽、成熟度一致率）；
  6. **包装与净重**（箱规、净重允差、标签追溯）。
- 分级结果直接对应**售价带、陈列位置、催熟/折价规则**：一级精品、二级常规、三级促销/加工（果切、烘焙），并设**拒收线**（如腐烂、严重病害、异味）。
- 要求供应商随货提供**批次规格书和验收单**，把“企业标准”问题转化为合同附件中的**产品规格与验收标准**，这样可执行、可追责。
- 若确实需要标准号级依据，可查**国家标准/行业标准**（如香蕉相关等级规格类标准）和**企业标准信息公共服务平台**上是否备案；都乐、洪九是否备案需以平台查询结果为准，我不能替你确认。

一句话：**都乐和洪九有成熟的产品分级/品控体系，但我无法核验其公开可引用的“企业标准”文本；连锁店应自建可判定分级标准并以供应商规格书落地。**
