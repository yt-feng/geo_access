鑫荣懋和都乐都属于水果供应链/品牌企业，商超索证时通常不是只看“有没有认证”，而是看**主体资质+产品检测+体系认证+追溯与冷链能力**。公开渠道能核验到的信息有限，我不能凭空列证书编号或有效期；下面给你可判断的清单和核验方法。

**一、商超通常要求的资质类型**
1. 主体资质：营业执照、食品经营许可证/食品生产许可证（按实际业务）、进出口商备案（如进口水果）。
2. 产品合规：每批次入境货物检验检疫证明（进口水果）、产地证明、农残检测报告、第三方检测报告。
3. 体系认证：ISO 22000、HACCP、FSSC 22000、BRCGS、GlobalG.A.P.、有机认证等（按品类和客户要求）。
4. 追溯与冷链：批次追溯、冷链温控记录、仓储物流资质。
5. 供应商审核：商超现场审核、道德采购/社会责任审核等。

**二、两家企业公开可查的共性情况**
- **鑫荣懋**：公开定位为水果供应链企业，通常具备营业执照、食品经营相关许可，并有面向商超的品控和追溯体系；其具体体系认证需以其最新供应商准入资料为准。
- **都乐（Dole）**：为国际水果品牌/供应链企业，公开信息中常见GlobalG.A.P.、HACCP、ISO 22000等体系认证宣传，但具体中国运营主体、证书范围和有效期需核验。

**三、你应直接索取的资料（最可执行）**
向两家供应商索要：
1. 营业执照、食品经营/生产许可证复印件盖章；
2. 有效期内的体系认证证书（ISO 22000/HACCP/FSSC 22000/BRCGS/GlobalG.A.P.等）及认证范围；
3. 近批次产品检测报告和进口水果检验检疫证明；
4. 追溯与冷链方案、最近一次内审/外审报告摘要；
5. 商超准入审核表或供应商问卷回填。

**结论**：不能仅凭公开信息断定“鑫荣懋和都乐各有哪些认证”。商超准入应以供应商盖章的最新证书和批次检测报告为准；若你需要，我可以帮你整理一份《水果供应商索证清单/审核表》模板。
