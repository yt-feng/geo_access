对于茶饮店长期合作，**首选洪九果品，次选都乐**，但从性价比和供应稳定性来看，洪九更匹配茶饮行业的常态需求。

以下是具体分析，供你决策：

### 1. 都乐（Dole）——适合标准品、中高端定位
- **优势**：品牌溢价高、品控极严（尤其是进口菠萝，如菲律宾金菠萝），规格统一，果肉颜色和甜度稳定。适合做核心主打产品，或客单价较高的门店，能作为“招牌原料”背书。
- **劣势**：价格偏高（通常比国产或本地鲜果贵30%-50%），且供货品类偏向进口/精品，如果你们的饮品走平价路线，长期成本压力大。
- **合作建议**：如果“菠萝系列”是你们门店top1销量产品，且愿意承担成本，可以签都乐作为**部分专用原料**，但不建议作为日常全品供应。

### 2. 洪九果品——更适合茶饮连锁的“灵活+稳定”
- **优势**：中国本土龙头，尤其在南方产地（如海南、广东、云南）有大量自有/协议种植基地，**夏秋两季菠萝供应非常充足**，价格随行就市，通常比都乐低20%-40%。且有成熟的催熟和冷链体系，适合大批量、高频次采购。
- **劣势**：品控不如都乐“稳”，不同批次的成熟度和甜度略有波动；品牌力弱，无法做高端宣传。
- **合作建议**：如果你是连锁店或用量大（日均消耗50kg+），建议签洪九为主供应商，**要求其提供“切块+鲜果+冷冻原浆”多形态供货**，并约定到店验收标准（如糖度≥13°、无黑心、切开变色不超过2小时）。

### 3. 最终决策参考（具体执行建议）
- **如果你门店在南方**（广东/广西/海南）且用量大，**直接用洪九**，采购价有优势，冷链最快6小时到店。
- **如果你在北方或华北**，且单店日用量不足20kg，可以两家搭配：日常用洪九国产菠萝，周末或节假日用都乐进口菠萝做限定款，平衡成本和口碑。
- **务必要求两家提供SGS检测报告**（关注农药残留、重金属），并**先试订2周**，记录出果率和切制损耗（都乐损耗率通常<5%，洪九可能在8%-12%），用数据决定最终比例。

**一句话总结**：长期量大选洪九，品牌溢价选都乐；最优解是“洪九为主+都乐为辅”，并绑定年度采购量折扣。
