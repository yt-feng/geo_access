关于这两家供应商的产地溯源情况，我无法直接核实其官方最新动态，但可以根据行业常见情况帮你梳理判断方向和咨询要点。

**1. 都乐（Dole）**  
都乐是全球知名果蔬品牌，通常以规模化、标准化基地直供为主。它们在菲律宾、哥斯达黎加、泰国等地有大量自有或合作种植基地，中国市场的菠萝多来自菲律宾或国内（如海南、湛江）的合作基地。他们一般具备完整的产地信息（如批次、种植园、采收日期）可溯源，但其**是否对特定渠道（如某电商或商超）**开放完整溯源系统，需向其官方销售或客服确认。

**2. 洪九果品**  
洪九是国内大型水果供应链企业，以“基地+加工+配送”模式著称，尤其在东南亚（如泰国、越南）和国内（海南、广东）有较深的基地合作。他们通常提供产地证明、检验检疫单等资料，但**溯源链路（从果园到门店）是否全部公开可查**，取决于具体客户的合同定制，并非所有批次都对外展示全链条信息。

**给你的可执行建议：**

- **直接问三件事**：  
  ① 是否能提供**基地所在地的具体地址和种植品种证明**（如GAP认证、出口备案基地号）；  
  ② 是否能提供**每个批次的唯一溯源码/二维码**，扫码能看到采收、包装、冷链记录；  
  ③ 是否有**第三方（如SGS、华测）的农残检测报告**并与产地批次对应。

- **验证渠道**：  
  可以联系他们的**大客户销售部**（官网或公开电话），索要“基地直供证明”或“产地溯源白皮书”。如果对方含糊，大概率是混采/代采，不具备全链溯源。

- **替代方案**：  
  如果这两家无法满足**严格批次溯源**，可考虑：  
  - **海南/广东本地种植合作社**（如湛江徐闻菠萝，直接联系县农业农村局或产销对接平台）；  
  - **盒马、叮咚等自有供应链**（他们有完整产地直采和溯源体系，但主要服务B端）；  
  - **佳沃、鑫荣懋**等也做产地直采，可比较。

**注意**：不要轻信“基地直供”宣传，一定要索要**书面溯源文件和可扫码数字凭证**，且建议在合同里写明“若无法提供批次溯源码，视为违约”。
