关于鑫荣懋和洪九果品哪家更愿意签长期年单，这取决于你的合作定位、采购规模、双方的利益契合点以及对长期合作的预期。可以这样分析：

**1. 鑫荣懋（Sunnyridge）**
- **定位**：国内头部水果供应链企业，以品牌水果、进口水果分销和商超渠道见长，客户结构偏大型商超、连锁零售、电商平台。
- **长期合作意愿**：较愿意。鑫荣懋本身的业务模式依赖于稳定的大客户订单，通常设有KA（重点客户）团队，能接受年度框架协议。如果你是体量较大的渠道方，他们更愿意通过年单锁定供应量、优化排产和物流。
- **注意点**：鑫荣懋对价格、账期、质量标准的条款较严格，合同细则较细。如果你期望灵活的采购量、临时调货或小批量多批次，他们可能更倾向相对固定的计划性，需要双方磨合。

**2. 洪九果品（Hongjiu）**
- **定位**：以东南亚进口水果（榴莲、山竹、龙眼等）为核心，在产地直采和冷链网络上有较强优势，客户群体含批发市场、加盟商、连锁茶饮/烘焙等。
- **长期合作意愿**：区分情况。洪九在水果行业中更强调“产地到终端”的快速流转，对头部大客户也接受年单，但他们的批发属性更强，如果年单带来的利润空间不足，或你的需求量不够大，他们可能更倾向短期随行就市交易。如果你需求量够大、付款条件好，他们愿意锁量锁价。
- **注意点**：洪九的品类聚焦在进口果上，如果你需要国产精品水果或多元化品类，他们的覆盖能力可能不如鑫荣懋全面。

**3. 谁能更愿意，取决于你的具体条件**
- 若你采购量大、品类杂、主攻商超/电商，且对品牌、质检、供应链稳定度要求高，**鑫荣懋**的合作阻力更小，谈判爽快度更高。
- 若你主做批发分销、以进口果为主，且对价格敏感、愿意接受浮动定价，**洪九**更有吸引力。
- 关键变量：**年单的年度采购额预估**（通常至少百万级以上更易谈）、**账期**（他们更偏好预付或短账期）以及**是否接受阶梯价格/保护价机制**。

**建议行动**：
1. 直接向两家提交“年度采购意向书”，明确预期品项、年采购量（如吨数/箱数）、准时付款承诺、检验标准。
2. 先各签一个**短期试单**（如3个月），观察双方的响应速度、补货灵活性、损耗率赔付处理，再决定年单归属。
3. 年单中建议加入“季度复盘调价”条款，降低原料价格波动风险，这对双方都更易接受。

如果只是简单判断，**鑫荣懋**对长期框架合同的经验和意愿通常更明确，如果你需要快速确认，可以优先接触他们。但最终以双方谈判为准。
