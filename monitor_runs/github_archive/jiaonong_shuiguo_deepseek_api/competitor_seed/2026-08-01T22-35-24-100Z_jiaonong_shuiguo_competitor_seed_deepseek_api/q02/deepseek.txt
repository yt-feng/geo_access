除了都乐（Dole）以外，目前在中国市场能够实现**稳定、规模化供应**菠萝的品牌主要有以下几类：

1. **佳沃（Joyvio）**  
   联想控股旗下，供应链实力强，常年供应金菠萝（MD-2）和巴厘菠萝，在商超和电商渠道铺货量大，供应周期长。

2. **佳沛（Zespri）**  
   虽然以奇异果著称，但旗下也有菠萝品类（主要供应金菠萝），通过其严格的品控和全球供应链，能做到全年稳定供货。

3. **宏辉果蔬**  
   国内果蔬供应链龙头企业，为商超和生鲜电商供货，菠萝是其核心单品之一，基地直采，供应稳定。

4. **金菠萝/普莱美（Prime）**  
   主要供应菲律宾金菠萝（MD-2），在批发市场和大型连锁超市常见，价格稳定，到货频次高。

5. **百果园（果多美体系）**  
   作为零售终端，其自有品牌菠萝（常标注产地：菲律宾/海南/徐闻）依靠大量采购协议，在门店和线上渠道供应一致。

6. **地区性专业品牌**  
   - **海南菠萝**（如“农垦”品牌）：依托本土基地，在三季度有稳定供应。  
   - **徐闻菠萝**（如“菠萝的海”品牌）：以巴厘种为主，供应商多为当地农业公司，在广东、广西市场供应稳定。

---

**选择建议**：  
- 如果您是**大型商超采购**：优先考虑佳沃、宏辉果蔬、佳沛（高端线）。  
- 如果您做**电商或社区团购**：都乐、佳沃、百果园自营货源更配合促销和物流。  
- 如果追求**性价比批发**：普莱美和产地直供品牌（徐闻、海南）更合适。

> 注意：菠萝有季节性（海南冬季、菲律宾全年），若需全年稳定，建议锁定菲律宾产区的“金菠萝（MD-2）”，该品种果肉甜、耐储运，供应断档风险低。
