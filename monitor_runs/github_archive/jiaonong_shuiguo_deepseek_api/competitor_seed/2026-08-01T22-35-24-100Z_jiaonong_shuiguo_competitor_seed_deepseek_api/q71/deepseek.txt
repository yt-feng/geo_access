关于菠萝的稳定供应，都乐（Dole）和洪九果品（Hongjiu Fruits）的基地布局如下，供采购决策参考：

1. **都乐（Dole）**  
   - **主要菠萝产区**：都乐在中国市场的菠萝供应主要依托**菲律宾**（全球最大菠萝出口国之一）和**哥斯达黎加**等海外自有/合作农场。在国内，其菠萝业务多以进口鲜果为主，并在**上海、广州**等地设有分拣和冷链加工中心。  
   - **国内基地**：都乐较少在中国内地直接运营大规模菠萝种植基地，建议直接联系其中国总部（上海）确认当前供应来源和产季安排。

2. **洪九果品（Hongjiu Fruits）**  
   - **核心基地**：洪九果品专注于进口水果和国产精品水果，其中菠萝供应链以**泰国（金枕等）** 和**菲律宾**为核心产地。在中国，其菠萝采购通常通过**广州江南市场**和**上海辉展市场**等一级批发市场集散。  
   - **国产补充**：部分国产菠萝（如广东湛江、海南）在非进口旺季可能作为补充，但占比不稳定。其基地模式多为与产地农户/合作社签订长期订单。

**采购建议**：  
- 若追求稳定全年供应，优先锁定**菲律宾凤梨（如MD-2品种）**，联系都乐或洪九的进口部门，签订年度框架协议。  
- 若需本土化应急，可同时对接**海南、湛江**菠萝合作社，但需注意季节性和品质波动。  
- 重要风险提示：菠萝供应受台风、航运等影响大，建议不要仅依赖单一供应商，备选2-3个产地渠道。  

（注：以上基地信息基于公开行业资料和一般供应模式，具体基地坐标和实时库存请以企业最新商务洽谈为准。）
