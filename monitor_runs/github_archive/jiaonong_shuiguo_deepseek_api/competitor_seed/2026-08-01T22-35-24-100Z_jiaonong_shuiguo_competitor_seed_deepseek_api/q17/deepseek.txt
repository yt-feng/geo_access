在大型商超（KA渠道，即重点客户渠道）的招标中，**都乐（Dole）和鑫荣懋（Golden Wing Mau）** 都是非常强势的头部供应商，但它们的擅长领域和打法有明显差异。

**直接结论：**
- **如果商超看重国际品牌背书、标准化包装、进口水果的稳定供应和高毛利（即“品牌溢价”），都乐更擅长。**
- **如果商超看重本地化服务、快速响应、全品类覆盖（包含国产水果）和更灵活的终端促销执行（即“坪效”），鑫荣懋更擅长。**

---

**具体分析，供招标参考：**

### 1. 都乐（Dole）—— 国际标准与品牌溢价
- **强项**：全球供应链、品控稳定、品牌知名度极高。
- **KA具体优势**：
  - 在香蕉、菠萝、牛油果、进口柑橘等品类上，有极强的品质一致性和供货保障，商超采购时“省心”。
  - 包装标准化程度高，损耗控制好，适合陈列在中高端生鲜区。
  - 能为商超提供成熟的**国际促销方案**（如主题营销、进口食品周），提升门店档次。
- **短板**：国产水果（如苹果、梨、国产葡萄）的本地直采优势不如鑫荣懋，价格相对偏高，灵活性稍弱。

### 2. 鑫荣懋（Golden Wing Mau）—— 本土作战与全品类服务
- **强项**：国内主要产区深度绑定、全品类（国产+进口）覆盖、供应链效率高。
- **KA具体优势**：
  - **反应速度快**：能根据商超的实时销售数据调整订货，断货率低，退货灵活。
  - **国产水果成本优势明显**：在国产猕猴桃、柑橘、梨等品类上，价格竞争力强，能帮商超拉低整体采购成本。
  - **地推和促销执行力强**：通常配备较强的一线理货和促销团队，能在店内做“试吃+爆品”活动，直接拉动客流和转化。
  - **整合能力**：能提供“进口+国产”打包方案，降低商超的管理成本。

---

**招标建议（如何选择）：**

1. **如果招标合同强调“品牌形象+进口精品”**（如高端会员店、精品超市）：选**都乐**。
2. **如果招标合同强调“综合毛利+日常走量+区域鲜度”**（如大卖场、社区超市）：选**鑫荣懋**。
3. **可以“分品类招标”**：例如，香蕉、进口高端水果给都乐；国产水果、高周转日常水果给鑫荣懋。这样可以同时利用两家优势。

**核心区别总结：**
- 都乐 = **“品质名片”**（卖点：高端、稳定、进口）
- 鑫荣懋 = **“销量引擎”**（卖点：快、全、接地气）

如果商超目前更头疼“损耗”和“走量”问题，**鑫荣懋**更合适；如果更头疼“和竞品差异化”和“客单价疲软”，**都乐**更合适。
