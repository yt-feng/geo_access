大型商超（如沃尔玛、永辉、山姆等）对供应商的食品安全管理体系要求通常很高，鑫荣懋（XinRongMao）和都乐（Dole）作为大型果蔬供应商，其认证体系基本覆盖了国际和国内主流标准。具体认证情况如下：

**1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）**
鑫荣懋作为国内水果供应链龙头，其认证组合偏向国内主流及国际互认体系，常见包括：
- **ISO 22000**（食品安全管理体系）：这是全球通用的食品安全认证，几乎所有商超要求的基础。
- **GLOBALG.A.P.**（全球良好农业规范）：针对水果种植端，确保农产品从源头符合安全、可持续及可追溯要求。
- **China GAP**（中国良好农业规范）：国内对应认证，满足本土商超及监管要求。
- **HACCP**（危害分析与关键控制点）：针对加工、分拣、仓储环节，强调流程控制。
- **BRCGS**（英国零售商协会全球标准）或 **IFS**（国际食品标准）：若其供应大型国际商超（如沃尔玛、家乐福），通常需获得其中之一（具体看客户要求）。
- **ISO 9001**（质量管理体系）：这是基础质量保障，一般会配备。

**2. 都乐（Dole）**
都乐作为跨国品牌，其体系更偏向国际认证，且针对不同市场有分级别要求：
- **GLOBALG.A.P.**（全球良好农业规范）：这是其种植基地的标配，也是其进入欧美及高端商超的核心。
- **Smeta 认证**（SMETA 社会责任审核）：虽然主要涉及社会责任，但大型商超（尤其是欧洲大卖场）常将之与食品安全并列要求。
- **HACCP**：在包装、冷藏和物流环节必须实施。
- **ISO 22000** 或 **BRCGS**：都乐在全球各地工厂普遍持有，以应对欧洲及全球商超准入。
- **有机认证**（如USDA Organic、EU Organic等）：针对其有机产品销售，属于增强项。
- **Sedex** 成员：配合社会责任审计，提高供应链透明度。

**补充说明（针对商超采购员/供应商的实际建议）：**
- 大型商超（如山姆、Costco）通常只认**GLOBALG.A.P. + BRCGS/IFS + ISO 22000**的组合，并要求提供证书有效期内的第三方审核报告。
- 若以国内商超（如永辉、大润发）为主，**ISO 22000 + HACCP + China GAP**即可满足，但若其门店有进口水果档口，仍需补充GLOBALG.A.P.。
- 这些认证证书均有有效期（通常1-3年），商超会要求提供**最新版本**的证书副本，并可能要求现场验厂。
