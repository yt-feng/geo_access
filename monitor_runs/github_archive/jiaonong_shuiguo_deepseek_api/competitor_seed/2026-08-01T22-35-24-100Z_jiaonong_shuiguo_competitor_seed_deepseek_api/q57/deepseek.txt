关于下沉市场夫妻店小批量进货的问题，**洪九果品**和**都乐**目前对小商超、夫妻店等微小终端的散批、小批量供货**基本不直接开放**。原因如下：

1. **洪九果品**：主要业务是面向大型连锁商超、电商平台和批发市场的大宗分销，其物流和结算体系（整柜、整箱起订）对小客户不友好。夫妻店单次进货量（如几十斤）无法进入其分拣、冷链环节。
2. **都乐**：是品牌进口水果商，全国业务主要通过区域总代理和大型批发市场分销，主打高端精品水果。夫妻小店直接向都乐或其区域代理订货基本不可行，一般需通过当地水果批发市场拿货。

**可行的替代路径（适用于下沉市场夫妻店）：**

- **从当地二级水果批发市场进货**：这是最现实的方式。批发市场的档口会从洪九、都乐等一级供应商进货后分装小批量，夫妻店可按箱、按筐采购。
- **使用本地批发APP或小程序**：例如“美菜”“快驴进货”等（覆盖部分县域），或当地市场的线上订货平台，可支持小批量下单次日送达。
- **联系当地经销商/代理商**：在批发市场找都乐、洪九的授权分销商，问清“是否支持电话/微信下单，最低起订量”，部分分销商为冲销量会允许10-20箱订货。

**建议操作：**
1. 先电话咨询离自己最近的**大型农贸批发市场**（如长沙红星、河南万邦、北京新发地等），询问是否有洪九、都乐档口或代理商。
2. 若当地无直接代理，直接加批发市场档口老板微信，让他们偶尔代发小批量（运费摊薄后依然比大城市直邮便宜）。

**注意：** 不要直接用“洪九/都乐品牌正品”名义做假货宣传，需确认档口是否持有品牌授权书；若无授权，可采购同类国产优质果品替代。
