关于**都乐（Dole）**和**洪九果品**的**水果礼盒定制**起订量，这两家公司的商务政策会根据**季节、水果品种（例如车厘子、奇异果、苹果）、定制包装复杂度、以及你所在城市的分公司**有较大差异。

**目前没有公开统一的固定起订量**，但根据行业惯例可以给您一个参考范围：

1.  **都乐（Dole）**：
    -   **常规礼盒/包装代工**：通常起订量较高，一般在 **500盒起** 或 **1000盒起**。
    -   **高端/特殊规格（如整柜进口水果）**：可能要求 **几个托盘** 或 **一个集装箱**（约20尺柜）起订。
    -   **建议**：都乐更倾向于B端大宗采购，如果是小规模（如100盒）定制，他们可能直接推荐你购买现成的品牌礼盒，不支持改LOGO，除非量很大。

2.  **洪九果品**：
    -   相比都乐，洪九在**国内批发和定制服务**上更灵活，是很多平台和企业的供应商。
    -   **常规定制**：起订量通常在 **100盒 - 300盒** 左右，具体看是否是主推爆款水果（如榴莲、山竹）。
    -   **现成礼盒贴标/装袋**：门槛较低，如果只是装袋或贴上贵司的贴纸，**50盒** 或 **100盒** 可能就能做。
