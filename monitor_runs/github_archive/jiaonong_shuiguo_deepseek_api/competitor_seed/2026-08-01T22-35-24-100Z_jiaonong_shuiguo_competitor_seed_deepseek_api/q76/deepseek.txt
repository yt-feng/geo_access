菠萝产地直发涉及冷链物流和供应链时效，以下是基于公开信息的分析，但具体时效会因季节、产地、天气和发货地而异，建议下单前咨询客服确认：

1. **都乐（Dole）**  
   - 通常采用产地（如菲律宾、海南、广东等地）直采后，通过冷链干线运输至城市分仓，再配送到消费者。  
   - 时效参考：在温度适宜、运输通畅的情况下，从采摘到送达一般需要 **2-4天**。  
   - 特点：品牌自建有物流体系或合作大型冷链服务商，对温度控制较严格，但偏远地区时效可能延长至5天。

2. **鑫荣懋（Xinrongmao）**  
   - 作为国内生鲜供应链企业，常与产地农户或合作社直接合作，运输模式类似，但可能更多依赖第三方冷链物流。  
   - 时效参考：在主要城市（一线/新一线）通常为 **2-3天**，二线城市或中西部可能需 **4-5天**。  
   - 特点：批量采购成本较低，但若遇节假日或极端天气，时效可能波动。

**建议操作**：  
- 在平台（如京东生鲜、盒马、叮咚买菜）搜索具体商品时，查看商品页标注的“次日达/隔日达”服务，或直接联系店铺客服询问“产地直发到您所在城市需几天”。  
- 购买前确认是否支持“破损包赔”或“烂果赔付”，以对冲时效风险。  
- 如需稳定时效，优先选择标注“当地仓发货”的菠萝（传统保鲜方式），而非严格意义上的产地直发。
