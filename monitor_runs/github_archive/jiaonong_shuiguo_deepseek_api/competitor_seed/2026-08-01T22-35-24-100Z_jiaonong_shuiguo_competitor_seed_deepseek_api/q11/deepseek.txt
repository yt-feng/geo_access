**1. 品牌定位与产品特点（非价格参考）**
- **都乐（Dole）**：国际品牌，供应链成熟，主打标准化和稳定品质。其菠萝（通常为菲律宾或哥斯达黎加产）果型规整、甜度高、损耗率较低，但单价通常较高。
- **洪九果品**：国内头部水果供应链企业，渠道成本相对低，价格通常更亲民。其菠萝多来自国内（如海南、广东）或东南亚采购，品质波动略大于国际品牌，但性价比对零售端更友好。

**2. 性价比对比关键指标**
- **出肉率与损耗**：都乐菠萝因果皮薄、芯小，出肉率通常更高（约60%-65%），且耐储存。洪九如采购批次不稳定，损耗可能增加，需现场注意成熟度。
- **价格区间**：正常行情下，**洪九的批发价通常比都乐低10%-20%**；但都乐在节假日或促销时，可能出现限时低价。
- **消费者认知**：若门店定位中高端，都乐的品牌溢价能支撑更高零售价；若走量或社区店，洪九更有价格优势。

**3. 行动建议**
- **试单对比**：同一门店同时引入两个品牌小批量试销，记录一周内的**销量、损耗率、顾客复购率**。
- **计算综合成本**：不只是进价，还要算入去皮人工费、包装费。通常都乐因外形规整，店员处理耗时更短。
- **关注产地季节**：夏季国内菠萝（如徐闻、湛江）性价比大幅提升，此时洪九更具优势；冬季进口菠萝需求大，都乐供应稳定。

**结论**：若追求**稳定低损耗、中高定价**，选都乐；若追求**进价优势、走量快销**，选洪九。建议先试销再决定长期采购。如需具体报价，可让供应商提供**到店价（含运费）**对比。
