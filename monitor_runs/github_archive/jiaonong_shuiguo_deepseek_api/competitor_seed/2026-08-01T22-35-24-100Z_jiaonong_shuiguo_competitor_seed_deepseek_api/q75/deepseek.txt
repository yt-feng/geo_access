抱歉，我无法直接提供洪九果品和都乐香蕉这两家具体品牌在批发市场“到货损耗率”的准确对比数据。因为该数据属于商业内控指标，会受产地、运输距离、季节、包装方式、批发市场管理等多个变量影响，公开渠道没有统一权威统计。

给你可执行建议：

1. **直接问批发市场档口**：不同档口经销不同品牌，你可以在当地大型水果批发市场（如广州江南市场、北京新发地、上海辉展等）询问长期做香蕉的档口老板，他们自己心里有数。

2. **自己小批量试货**：各拿1-2箱，记录到货时的“坏果/断柄/黑疤/软烂”比例。通常都乐香蕉以标准化、冷链成熟著称，开箱损耗会相对低；洪九果品（主打进口水果供应链）以性价比和渠道灵活著称，但具体损耗要看批次。

3. **关注香蕉品类特点**：香蕉到货损耗主要是“压伤、碰伤、自然成熟过度”。如果走陆运时间超过3天，损耗率普遍会上升到5%-10%甚至更高；冷链和纸箱硬度很关键。

4. **行业经验值参考**（非官方，仅为市场常见说法）：一般香蕉批发到货损耗率在3%-8%算正常，优质品牌+短途冷链可控制在3%-5%，长途或夏季高温可能到10%以上。

如果你想核实，建议去批发市场现场观察或联系两家公司的区域销售，让他们提供同城客户案例。我无法替你虚构确切数字。
