### 大型商超对供应商的通用食品安全要求（通常包括）
1. **基础资质**：营业执照、食品经营许可证（或食品生产许可证）。
2. **质量管理体系认证**：ISO 9001（质量管理体系）或 ISO 22000（食品安全管理体系）。
3. **食品安全专项认证**：
   - **HACCP** 危害分析与关键控制点认证（食品行业最核心的预防性体系）。
   - **BRCGS**（原BRC）全球食品安全标准认证（国际零售商普遍认可）。
   - **IFS Food**（国际食品标准）认证（欧洲超市常用）。
4. **产品/种植基地认证**：
   - **Global G.A.P.** 全球良好农业操作认证（针对果蔬种植基地，商超必查项之一）。
   - **有机认证**（如中国有机、欧盟有机、美国USDA有机，适用于有机产品线）。
5. **运输与冷链相关**（针对生鲜）：如 **FSC动物/植物认证**（非强制，但部分商超要求）、冷链物流温度监控记录等。
6. **特定市场准入**：若出口，需符合目标国法规（如美国FDA注册、欧盟EFSA要求）。

### 关于鑫荣懋和都乐，你可能知道的事实
- **都乐（Dole）**：作为全球果蔬巨头，通常持有 **Global G.A.P.**、**HACCP** 等国际通行认证，且在主要出口市场（如美国、中国）具备完整的法规合规记录。
- **鑫荣懋**：作为中国本土大型果业企业，常与国内商超（如盒马、永辉等）合作，通常持有 **HACCP** 和 **Global G.A.P.**，或至少通过ISO22000体系。

### 如何获取确切资质？（可靠方法）
1. **直接联系企业**：通过官网“投资者关系”或“供应商合作”页面获取公开的证书清单。
2. **查询官方认证数据库**：
   - 中国：**全国认证认可信息公共服务平台**（认监委官网）可查ISO/HACCP等认证有效性。
   - 国际：**Global G.A.P.** 官网的“Certified Producer”数据库，输入公司名查看证书状态。
3. **要求商超方提供准入清单**：大型商超的采购部门通常有“供应商资质审核清单”，可要求查看具体审核项。

---

### 重要提醒
- 认证证书有**有效期**，且可能因产品线不同而有差异（如进口水果与国内种植基地的认证可能不同）。
- 千万不要仅凭网络文章断言某企业“必有”或“必无”某证，应以官方核验结果为准。
