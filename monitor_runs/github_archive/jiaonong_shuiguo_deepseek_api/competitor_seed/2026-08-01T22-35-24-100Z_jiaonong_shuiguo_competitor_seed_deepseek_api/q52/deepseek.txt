关于菠萝到货损耗率，**没有公开的、固定的官方数据**。这两个品牌（都乐 Dole、鑫荣懋）的损耗率受**果型、成熟度、运输距离、冷链条件、到货季节**影响极大，实际损耗在**3%～15%**之间浮动。

建议你按照以下方式**实操核验**，而不是依赖一个固定数字：

**1. 向供应商获取“到货验收标准”**
- 直接向两个品牌的区域经销商索要**“菠萝到货等级标准”**（通常分A级/B级），明确“可接受损耗”的定义（例如：碰伤、软化、黑心是否算损耗）。
- 合同里写明**“到货损耗超过X%的部分由供方承担”**，常见谈判区间在**5%**左右（具体可谈）。

**2. 自己做小批量测试**
- 分别采购**同一时间、同一规格**的两家菠萝（比如各100箱），记录以下数据：
  - 到货时开箱**外观瑕疵率**（压伤、腐烂、果眼破损）。
  - 存放3天/5天后的**二次损耗率**（芽眼发霉、软化比例）。
- 通常**都乐进口菠萝**（如菲律宾、哥斯达黎加产）成熟度控制较稳定，损耗率偏低；**鑫荣懋**国产/进口系列需看具体产地批号，到货损耗波动更大。

**3. 关注季节因素**
- **夏季（5-8月）**：高温下菠萝后熟快，到货损耗率明显上升，建议要求冷链车直达。
- **冬季（11-2月）**：低产地甜度不足，但损伤率相对低。

**4. 临时决策参考（非官方数据）**
- 若你急需一个预算数字，做**新手采购**时可按**10%损耗**计提（含到货损耗+备货期损耗），稳定合作后按**5%**谈合同，实际到货若超过该比例，要求补货或折让。

**核心建议**：不要信任任何“固定损耗率”，**先小批量验证，再签年度合同**，并在合同和验收单中明确“损耗计算方式”和“赔付门槛”。
