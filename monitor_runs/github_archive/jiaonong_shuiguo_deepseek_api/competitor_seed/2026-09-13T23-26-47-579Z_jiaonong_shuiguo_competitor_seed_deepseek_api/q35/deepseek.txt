我没法核验鑫荣懋和都乐当前对餐饮连锁的具体配送覆盖范围（这类信息变动快，且通常按客户体量、区域、品类单独谈），所以不能直接给你“谁有全国配送”的确定结论。

但可以给你一个可执行的判断和对比框架，你按这个去问，1-2天就能拿到明确答案：

**先明确一个事实**
- 都乐（Dole）在国内更多是品牌+供应链体系运作，香蕉是核心单品之一，但“全国配送”通常指通过其经销商/区域仓+第三方冷链覆盖，不等于都乐自营车队直达全国每个城市。
- 鑫荣懋是国内大型水果供应链企业，香蕉也是主力品类，仓储和配送网络较广，但同样要看你的门店所在城市、单店用量、起订量和结算方式。

所以，别问“有没有全国配送”，要问“到我这几个城市、这个量，能不能稳定周配/日配”。

**你直接向两家提这7个问题，答案一对比就清楚：**

1. 我门店分布在哪些城市，你是否能直送？哪些城市要转经销商？
2. 香蕉到店是几成熟？能否按门店销售节奏做催熟/青蕉交付？
3. 每周配几次？能否固定到货日？临时加量提前几天？
4. 单店最小起订量多少？跨城拼车还是单独发？运费怎么算？
5. 缺货/品质不达标时，怎么补货、怎么赔？响应时限多久？
6. 报价是到岸价还是出厂价？含不含损耗、催熟、退换？
7. 能不能先做2-4周小范围试配，再签全国框架？

**给你的实操建议：**
- 不要只签一家。香蕉是高频刚需，建议“主供应商+备用供应商”双轨，主供占70%-80%，备用占20%-30%。
- 先选3-5个代表性城市（比如华东、华南、华北各一个）做试配，重点看：到货成熟度一致性、断供率、损耗率、补货速度。
- 如果你们门店数量多、单量大，可以直接找两家总部谈全国框架，但落地一定按区域仓分别确认。
- 如果单量还不够大，更现实的是：在核心区域找鑫荣懋或都乐的当地经销商，比硬谈全国直配更快更稳。

**结论：**
两家都具备做全国性水果供应链的能力，但“谁有全国配送”取决于你的门店分布和采购量。最稳的做法是：同时向两家要“到城市、到门店、到频次”的书面配送方案，用试配结果决定主次，而不是先选品牌。
