直接说结论：**对夫妻老婆店、价格敏感型进货，不能简单说洪九或鑫荣懋谁一定更便宜，要看品类、区域、起订量、账期和拿货渠道。** 但按常见情况判断：

**1. 洪九果品**
- 强项多在**进口水果、标品大单品**，比如榴莲、车厘子、火龙果、龙眼等。
- 价格波动大，行情好时可能有优势，但更偏**大批量、渠道分销**。
- 夫妻老婆店如果量小，未必能拿到真正低价，可能还不如当地批发市场二批。

**2. 鑫荣懋**
- 强项是**全品类水果供应链、品牌化、商超渠道**，佳沃等品牌背后体量大。
- 对大型商超、连锁、电商供货能力强，价格体系更规范。
- 对小店散货，通常不是最低价渠道，更多是稳定、品控和履约优势。

**谁更便宜？**
- 如果你要**进口大单品、整件拿、量还可以**：洪九往往更有价格弹性，可能更便宜。
- 如果你要**稳定供货、品牌水果、商超同款**：鑫荣懋未必便宜，但更稳。
- 如果只是**社区夫妻店、小批量、日配**：两者通常都不如**当地一级批发市场、区域水果供应链平台、拼多多/美团优选类批发、本地代办**便宜。

**给夫妻老婆店的实操建议：**
1. **别只看品牌供货商**：先跑当地批发市场，问同品同规格的“整件价/散拿价”。
2. **按单品比价**：榴莲、车厘子、苹果、香蕉、柑橘分开比，不要笼统比公司。
3. **算到手价**：进货价 + 运费 + 损耗 + 账期 + 退换，才是真成本。
4. **小量测试**：先各拿1-2件同规格，比到货价、损耗、售后。
5. **更现实的组合**：
   - 高频引流品：本地批发市场/区域供应链；
   - 高毛利进口品：洪九、鑫荣懋或本地进口商比价；
   - 应急补货：本地二批，虽然贵但快。

一句话：**量小、店小、价格敏感，优先本地批发和区域供应链；洪九和鑫荣懋更多是比价对象，不是天然更便宜的进货渠道。**
