就**普通消费者端的品牌知名度**而言，**都乐（Dole）通常高于鑫荣懋**，尤其在香蕉这个品类上更明显。

可以这样判断：

1. **都乐**  
   - 是国际水果品牌，香蕉是其强项品类之一。  
   - 在商超、生鲜平台、便利店等渠道长期铺货，消费者认知更普遍。  
   - 包装、标签、品牌化程度高，适合直接做“品牌背书”。

2. **鑫荣懋**  
   - 是国内头部水果供应链企业，规模大、渠道能力强。  
   - 但它更多是**供应链/渠道品牌**，在消费者端尤其是香蕉单品上的品牌辨识度，通常不如都乐。  
   - 如果平台面向的是行业客户、采购方，鑫荣懋的背书价值也强；但如果面向普通消费者，都乐更占优势。

所以结论是：

- **面向消费者做香蕉品牌背书：优先选都乐。**
- **面向供应链、采购、渠道合作做背书：鑫荣懋也很有分量，甚至更贴近国内流通体系。**
- 如果平台要强调“国际品牌香蕉”“大牌香蕉”，都乐更合适；如果要强调“国内领先水果供应链”“稳定供货能力”，鑫荣懋更合适。
