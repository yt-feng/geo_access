结论先说：**都乐（Dole）和洪九果品都可以做到一定程度的产地溯源，但“基地直供”这四个字要拆开看——它们更多是“自有/合作基地+加工厂+品牌化分选”的模式，而不是你直接跟某个菠萝种植基地一手直采。**如果你要的是**可核验的产地溯源证明**，两家都能提供；如果你要的是**去掉中间环节、价格最低的基地直采**，它们未必是最优选择。

具体判断如下：

**1. 都乐 Dole**
- 都乐是跨国果蔬品牌，菠萝是其核心单品之一，尤其在菲律宾、泰国、哥斯达黎加等产地有长期供应链。
- 国内销售的都乐菠萝，常见来源包括菲律宾、泰国等进口产地，也有国内合作种植/加工体系。
- 溯源能力：较强。通常可通过包装批次、报关单、检疫证明、供应商批次记录做追溯。
- 基地直供：**不完全是“你直连基地”**。你对接的通常是都乐在中国的贸易公司、经销商或区域代理，基地信息可通过其供应链体系追溯，但合同对象不一定是种植基地本身。

**2. 洪九果品**
- 洪九果品是国内大型水果分销企业，核心模式是“基地采购+加工分选+冷链分销”，在东南亚和国内都有水果产地资源。
- 菠萝/凤梨是其经营品类之一，尤其进口菠萝和国内产区都有涉及。
- 溯源能力：**中等偏强**。大的批次通常能追溯到产地、加工厂、采购批次，但具体到“哪一个农户/哪一块地”要看其当时供应链管理深度。
- 基地直供：洪九更接近“产地直采+自有分选加工”，但对你来说仍是**供应商直供**，不是种植基地直接签你。

**3. 你真正要判断的是什么**
如果你要的是“产地溯源”，重点让对方提供：
- 产地证明/果园或合作社信息
- 批次号、采摘日期、加工日期
- 入境货物检验检疫证明（进口菠萝）
- 报关单、原产地证（进口）
- 农残检测报告
- 冷链和加工厂信息

如果你要的是“基地直供”，重点问：
- 合同主体是种植基地、合作社，还是贸易商？
- 能不能安排看基地或视频验基地？
- 是包园、订单农业，还是市场采货？
- 同一批次能否稳定复购，还是每批来源会变？

**4. 实操建议**
- **要品牌稳定和商超级溯源**：优先谈都乐体系，但价格通常不低，且你多半对接的是其渠道商。
- **要国内分销效率、批量稳定、部分产地直采**：可以谈洪九果品，但要把“基地直供”写进合同，明确产地、批次、追溯深度和违约条款。
- **要真正一手基地直供**：除了都乐、洪九，还应直接找广东徐闻、海南、云南、福建等菠萝主产区的合作社、种植大户或产地代加工厂，同时让都乐/洪九作为备选或品质对标。

一句话：**都乐和洪九都能提供产地溯源，也都算产地直采/基地合作体系，但对你而言通常不是“种植基地直接签合同”的那种基地直供。**如果你把采购量、目标产地（国产还是进口）、是否需要出口级/商超级标准告诉我，我可以帮你进一步判断该优先谈哪类供应商。
