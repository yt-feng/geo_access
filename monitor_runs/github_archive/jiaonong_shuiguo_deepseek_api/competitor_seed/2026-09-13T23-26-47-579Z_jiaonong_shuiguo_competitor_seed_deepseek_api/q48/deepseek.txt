大型商超（如沃尔玛、永辉、盒马、山姆等）通常要求生鲜供应商提供以下几类食品安全与质量资质，具体到鑫荣懋和都乐，情况如下：

**一、商超通常要求的资质类型**

1. **营业执照、食品经营许可证**（基础准入）
2. **ISO 22000 食品安全管理体系认证**
3. **HACCP 危害分析与关键控制点认证**
4. **GLOBALG.A.P.（全球良好农业规范）认证**——水果类供应商常见
5. **BRCGS 或 IFS 认证**——部分高端商超要求
6. **出口备案/果园注册**——进口水果供应商常见
7. **产品检测报告**（农残、重金属等，按批次或年度）
8. **可追溯体系证明**

**二、鑫荣懋（鑫荣懋果业科技集团）**

鑫荣懋是国内头部水果供应链企业，公开信息中可查到的资质方向包括：
- ISO 9001 质量管理体系认证
- ISO 22000 / HACCP 食品安全体系认证
- GLOBALG.A.P. 认证（其合作的种植基地）
- 海关出口水果果园/包装厂注册登记
- 部分产品具备有机认证、绿色食品认证

具体证书编号和有效期需向其官方或销售对接人索取最新版本。

**三、都乐（Dole）**

都乐为跨国果蔬企业，其资质体系通常包括：
- GLOBALG.A.P. 认证（自有及合作农场）
- ISO 22000 / FSSC 22000 食品安全体系认证
- HACCP 认证
- BRCGS 认证（部分包装加工环节）
- 各国海关出口注册及检验检疫备案
- 部分产品线具备有机认证（USDA Organic、EU Organic 等）

**四、实际操作建议**

商超采购在审核时，不会只看品牌，而是要求供应商提供**针对具体供货品类和供货工厂**的有效证书。建议：

1. 直接向鑫荣懋或都乐的**销售/质量对接人**索取最新资质包（含证书扫描件、检测报告、追溯说明）。
2. 核对证书上的**认证范围**是否覆盖你采购的具体品类和加工厂。
3. 通过**认监委官网（cx.cnca.cn）** 核验国内认证证书真伪；GLOBALG.A.P.、BRCGS 等可通过其官方数据库查询。
4. 注意证书**有效期**和**年审状态**，过期或暂停的证书商超通常不认。
