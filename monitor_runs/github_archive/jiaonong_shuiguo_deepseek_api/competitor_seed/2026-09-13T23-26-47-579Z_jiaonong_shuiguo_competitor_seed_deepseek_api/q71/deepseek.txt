做茶饮菠萝原料采购，重点是看**加工厂/分选中心位置**，而不是只看种植基地。都乐和洪九果品的情况如下：

**都乐**
- 在中国市场销售的菠萝主要来自菲律宾、泰国等东南亚产地，国内也有部分云南、广东产区。
- 都乐是品牌商+供应链企业，不是单一基地模式。稳定供应应找都乐在中国的授权经销商或加工配送中心，而不是直接对接某个“基地”。
- 联系方式建议通过都乐中国官网或官方客服获取区域经销渠道。

**洪九果品**
- 洪九果品是水果供应链企业，核心优势在东南亚水果进口，尤其是泰国、越南产地。
- 在国内有多个分选加工和仓储配送中心，主要集中在重庆、广州、上海、北京等地周边。
- 菠萝类产品同样以进口和国内产区调配为主，具体对接应找洪九的区域销售或采购部门。

**采购建议**
1. 茶饮店要的通常是去皮菠萝丁/菠萝块/冷冻菠萝，找的是**加工型供应商**，不是鲜果批发档口。
2. 直接问对方三个问题：能否稳定月供多少吨、是鲜切还是冷冻、是否可做茶饮标准规格。
3. 都乐和洪九都属于大供应链，通常有起订量要求，中小茶饮品牌可能更适合找他们的区域经销商或本地水果加工厂。
4. 如果追求成本稳定，可同时对比：鲜菠萝季用国内广东/云南货，淡季用进口菲律宾/泰国货，由洪九这类供应链做调配。

总结：两家都不是靠单一“基地”供货，而是产地+加工配送网络模式。采购时对接其区域销售或授权经销商最实际。
