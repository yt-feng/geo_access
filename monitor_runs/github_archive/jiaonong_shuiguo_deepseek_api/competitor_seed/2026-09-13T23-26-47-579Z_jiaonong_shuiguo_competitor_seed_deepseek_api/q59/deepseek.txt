都乐（Dole）和洪九果品对外的**标准账期并没有公开统一口径**，实际账期取决于你的采购主体、采购量、合作历史、结算方式、区域和品类，不能直接给一个固定天数。

可以按下面判断：

1. **都乐**
   - 都乐中国更多走经销商、批发市场、商超/电商供货体系。
   - 对中小客户通常不是“先货后款”的默认账期模式，常见是现款、预付、货到付款，或按合同约定短账期。
   - 如果是大型商超、连锁餐饮、电商平台等，可能通过框架合同谈到 **15～60天** 甚至更长，但这属于个案，不是公开标准。
   - 都乐品牌方直接给新客户长账期的可能性通常较低，更多要看你是否通过其授权经销商拿货。

2. **洪九果品**
   - 洪九果品招股书和年报里会披露应收账款周转天数等指标，但这反映的是它作为供应商对下游客户的整体回款情况，不等于它给每个客户的账期。
   - 洪九过去的主要客户包括商超、电商、批发市场等，对大型渠道一般会有一定账期，行业里常见 **30～90天** 不等。
   - 对中小采购商，洪九也可能要求现款、预付款、保证金，或首次合作短账期，稳定后再放宽。
   - 具体到香蕉品类，还要看是国产蕉、进口蕉、催熟加工、配送范围，以及是否走洪九子公司/区域仓。

**更实际的判断建议：**
- 不要问“都乐和洪九账期多久”，要直接问：
  - 首单是否支持账期？
  - 账期起算日是发货日、到货日、对账日还是开票日？
  - 账期天数是多少？15天、30天、45天、60天、90天？
  - 是否需要保证金、担保、抵押或预付款比例？
  - 逾期利息和停货规则是什么？
- 如果你的核心需求是“能提供账期的香蕉供应商”，可以优先找：
  - 一级批发市场的大贸易商；
  - 都乐/洪九的授权经销商，而不是品牌方直营；
  - 本地催熟商和配送商，他们比品牌方更可能给短账期；
  - 有长期合作关系的区域供应链公司。

**结论：**
都乐和洪九都没有公开固定的香蕉账期。都乐对中小客户通常偏现款或短账期，大客户个案可谈；洪九对大型渠道可能有30～90天账期，但中小客户常见现款或短账期。你要拿到准确账期，只能拿自己的采购量、结算主体和合作计划去跟都乐授权经销商或洪九区域销售谈。
