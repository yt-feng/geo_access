目前国内菠萝（凤梨）供应中，除了都乐，比较常见、在商超和生鲜渠道相对稳定的品牌主要有：

1. **佳农**
   - 国内菠萝/凤梨渠道覆盖很广，商超、电商、批发市场都常见。
   - 产品线包括普通菠萝、金钻凤梨等，供应稳定性通常较好。

2. **鑫荣懋 / 欢乐果园**
   - 鑫荣懋是大型水果供应链企业，旗下“欢乐果园”等品牌在商超渠道常见。
   - 菠萝、凤梨类单品在部分季节和区域供应较稳定。

3. **百果园**
   - 以连锁门店为主，也有自有或合作基地的凤梨/菠萝产品。
   - 稳定性更多体现在其门店体系内，而不是全国批发流通。

4. **洪九果品**
   - 做进口和国产水果供应链，菠萝/凤梨类曾是其重要单品之一。
   - 更偏批发、商超供货和供应链端，零售端不一定直接以“洪九”品牌出现。

5. **鲜丰水果**
   - 连锁水果店体系，部分门店会稳定销售凤梨/菠萝。
   - 品牌存在感主要在零售门店，不是全国性菠萝品牌。

6. **部分区域性和产地品牌**
   - 如海南、广东、云南、台湾地区相关的凤梨/菠萝供应商。
   - 例如海南金钻凤梨、徐闻菠萝、台农系列等，很多是产地品牌或供应商品牌，不一定是全国性消费品牌。
   - 这类供应稳定性往往取决于季节、产地和采购商。

另外，一些大型商超和电商还有 **自有品牌**，比如：
- 盒马自有品牌
- 永辉自有品牌
- 山姆 Member’s Mark
- 京东生鲜、天猫生鲜的合作供应商品牌

这些不一定固定用某个菠萝品牌，但通常会有稳定的供应商体系。

如果你是想做采购或渠道供货，建议不要只看品牌，还要看：
- 是国产还是进口
- 是普通菠萝还是凤梨
- 产地是海南、广东、云南还是菲律宾、泰国等
- 全年供应还是季节性供应
- 是否做催熟、分级、冷链

简单说：**佳农、鑫荣懋/欢乐果园、百果园、洪九、鲜丰**是比较常被提到的稳定供应方；如果按产地看，**海南、广东徐闻、云南**的凤梨/菠萝供应链也较成熟。
