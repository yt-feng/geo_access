都乐和鑫荣懋都没有对外公开、按茶饮原料口径统计的“到货损耗率”标准数据；这个指标高度依赖你采购的具体形态（鲜果/冷冻果肉/果泥/果丁）、规格、运输距离、仓储条件和验收标准，不同批次差异会很大。

能给你的可执行判断如下：

1. **先分清你买的是哪种“菠萝原料”**
   - 鲜菠萝：损耗主要来自压伤、黑心、过熟、霉变、切口氧化、去皮修整损耗。
   - 冷冻菠萝丁/果肉：损耗主要来自化冻失水、碎渣、冰霜、封口破损。
   - 菠萝果泥/浓缩汁：损耗主要来自包装破损、胀包、温控失效。
   这三种的“到货损耗率”不可比。

2. **行业参考区间（只能作为内部试算，不是品牌承诺）**
   - 鲜菠萝整车/整柜到货：外观可接受损耗常见约 **3%–8%**；管理差或长途高温可能到 **10%以上**。
   - 冷冻菠萝丁/果肉到货：按重量计，正常约 **1%–3%**；若冷链断链或反复化冻，可能 **5%以上**。
   - 果泥/浓缩汁：正常低于 **1%**，主要是破包、胀包等异常。
   注意：这是经验区间，不是都乐或鑫荣懋的官方数据。

3. **你要稳定规格，建议直接向供应商索要这些数据**
   让对方按你所在城市、到货频次、包装规格提供：
   - 近 **3–6个月** 同规格到货批次记录
   - 每批次：发货重量、到货净重、拒收重量、可修整使用重量
   - 验收标准：糖度、成熟度、果丁尺寸、冻伤/黑心/压伤允收比例
   - 运输温控记录和到货温度
   - 异常批次赔付或补货条款

4. **更实用的做法：自己做一次对比测试**
   选都乐和鑫荣懋各 **2–3个批次**，同路线、同季节、同验收人，按下面公式算：
   - 到货损耗率 =（发货净重 - 到货合格可用净重）÷ 发货净重 × 100%
   - 同时记录：拒收率、修整损耗率、报废率
   连续测 **1个月**，你得到的数据比任何供应商口头承诺都可靠。

5. **采购合同里建议写死**
   - 规格：品种、果径/果丁尺寸、糖度、成熟度、冷冻状态
   - 允收损耗上限和超标扣款/补货
   - 到货温度、包装完整性、批次追溯
   - 抽检比例和争议处理方式
