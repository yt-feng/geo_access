结论先说：**都乐基本能做到全年供应菠萝（尤其是进口/不同产区轮转），洪九果品也具备全年做菠萝供应的能力，但两家都不是“单一产区全年产”，而是靠多产地、多季节轮换来实现。对茶饮店做果酱来说，真正要确认的不是“能不能全年有”，而是“全年同一品种、同一糖酸比、同一成熟度是否稳定”，这比有没有货更关键。**

### 1. 都乐
都乐是跨国水果品牌，菠萝供应能力强，通常依靠不同产区和季节做全年调配，比如菲律宾、泰国、哥斯达黎加等产地轮转，国内也有相关供应链布局。

- **全年供应能力：较强**
- **适合茶饮/果酱：可以，但要看具体品种**
- **风险点：**
  - 不同产季、不同产地的菠萝，糖度、酸度、香气会有差异。
  - 茶饮果酱如果要求风味稳定，不能只按“都乐菠萝”下单，要锁具体品种、规格、成熟度、糖度范围。
  - 都乐更多是鲜果品牌，是否给你做果酱原料的稳定B端供应，要看你找的是都乐直供、经销商还是加工厂。

### 2. 洪九果品
洪九果品是国内大型水果供应链企业，强项是进口水果和全国分销，菠萝/凤梨是其常见品类之一。它通常也是通过多产地采购来做到全年供应。

- **全年供应能力：具备**
- **适合茶饮/果酱：可以，但更偏供应链和批发逻辑**
- **风险点：**
  - 洪九的优势在“货源组织和分销”，不一定直接给你做定制化果酱原料。
  - 同样存在不同批次风味波动问题。
  - 如果你要的是长期稳定配方，最好让供应商提供多批次糖度、酸度、出汁率、纤维感数据。

### 3. 茶饮店做菠萝果酱，真正的判断标准
不要只问“全年有没有菠萝”，要问这4个问题：

1. **能不能锁定同一品种？**
   比如金钻凤梨、MD-2、台农等，不同品种香气差异很大。

2. **能不能锁定糖度/酸度范围？**
   例如糖度稳定在多少Brix，酸度多少，不能这批很甜那批很酸。

3. **能不能全年供果酱原料，而不是鲜果？**
   鲜果全年有，不等于果酱原料全年稳定。果酱更看重成熟度、出汁率、纤维和香气。

4. **最小起订量和价格波动如何？**
   茶饮店如果量小，直接找都乐/洪九可能不划算，通常要通过经销商或果酱加工厂。

### 4. 更现实的建议
如果你是一家茶饮店，想做全年稳定菠萝果酱：

- **不要只依赖都乐或洪九鲜果直供。**
- 更稳妥的是找**果酱加工厂/冷冻果泥厂**，让他们用都乐、洪九或其他产地的菠萝做原料，再按你的配方做标准化果酱。
- 要求供应商提供：
  - 全年供货承诺
  - 多批次检测报告
  - 糖度、酸度、pH、微生物指标
  - 样品盲测
  - 替换产地时的提前通知

### 一句话总结
**都乐和洪九果品都具备全年组织菠萝货源的能力，但“全年有菠萝”不等于“全年果酱风味稳定”。茶饮店更应该找能锁定品种、糖酸度和加工标准的供应链或果酱厂，而不是只盯鲜果品牌。**
