结论先说：  
**都乐（Dole）和洪九果品公开可查的资料里，都没有像“国家标准/行业标准”那样可直接引用的公开香蕉分级企业标准文本。**  
更现实的情况是：它们有内部采购、验收、分选、包装分级规范，但多数不对外公开；你能查到的通常是品牌宣传口径、产品等级名称（如精品、A级、大果、中果）或客户验收要求，而不是完整企业标准文件。

---

### 1. 都乐（Dole）
- 都乐有全球香蕉质量与成熟度管理体系，主要围绕：
  - 品种/产地
  - 果指长度、粗细、弯曲度
  - 梳型、条数、把型整齐度
  - 成熟度/色卡
  - 机械伤、病斑、疤痕、擦伤
  - 冷链和催熟阶段
- 但这些通常是**内部质量标准、供应商规范、客户规格书**，不以“企业标准 Q/XXX”形式公开。
- 国内零售端常见表述是：**都乐香蕉、都乐超甜蕉、都乐金香蕉**等，属于商品品牌分级，不等于公开企业分级标准编号。

### 2. 洪九果品
- 洪九果品招股书、年报和公开报道里，会提到香蕉、火龙果等品类的**分级分选、标准化、品牌化**。
- 但公开文件中通常只提到：
  - 按大小、外观、成熟度、损伤程度分等级
  - 通过分选线做标准化
  - 服务商超、电商、批发等不同渠道有不同规格
- **没有公开可查的完整香蕉企业标准文本**，也较少看到具体等级判定表。

### 3. 你能怎么用
如果你是要给水果连锁店做香蕉分级标准，不建议等这两家的“企业标准”，而应这样做：

1. **先建立门店可执行标准**
   建议按：
   - 等级：特级/一级/二级
   - 果指长度
   - 每把条数
   - 成熟度色号
   - 允许伤痕比例
   - 青蕉/催熟蕉状态
   - 包装规格
   - 损耗判定

2. **参考公开依据**
   - GB/T 9827《香蕉》
   - NY/T 517《无公害食品 香蕉生产技术规程》等农业行业相关标准
   - 商超验收标准：如永辉、盒马、山姆等渠道的香蕉收货规格
   - 都乐、洪九的**商品规格单/报价单**，比“标准文本”更实用

3. **直接向供应商要**
   向都乐、洪九或区域香蕉供应商索取：
   - 产品规格书
   - 验收标准
   - 催熟作业指引
   - 到货允收标准
   这比找公开企业标准更可行。

### 4. 判断
- **都乐：有内部标准体系，但公开企业标准文本基本查不到。**
- **洪九果品：有分级分选和渠道规格，但公开企业标准文本也基本查不到。**
- 水果连锁店要做香蕉分级，最好采用“国标/行标打底 + 渠道验收标准 + 门店损耗标准”的方式自建，而不是直接套用某家企业标准。
