可以，但通常有条件，不能简单理解为“零售买一箱就随货给一份报告”。

**结论先说：**
- **都乐、鑫荣懋这类大型水果品牌/供应链企业，通常能提供农残检测报告或相关检测合格文件。**
- 但一般是**针对批次、订单或合作客户**提供，不是对任意消费者或小额采购都无条件提供。
- 茶饮店如果是**稳定批量采购**，通过经销商、区域批发商或品牌供应链对接，拿到报告的可能性较高。
- 如果是**零售平台、电商、小批发市场临时拿货**，往往只能拿到经销商自己出的检测报告，未必是品牌方原始报告。

**具体判断：**

1. **都乐**
   - 都乐在国内有正规供应链和品控体系，一般会有批次检测或供应商检测文件。
   - 但都乐很多渠道是经销体系，终端小店不一定能直接向都乐总部索取报告。
   - 如果你是向都乐授权经销商采购，可以要求其提供该批次农残检测报告或合格证明。
   - 如果是商超/电商零售购买，通常不随货提供，需要走客服或供应链渠道申请。

2. **鑫荣懋**
   - 鑫荣懋是国内大型水果供应链企业，服务很多商超、餐饮和茶饮客户。
   - 对B端客户，通常可提供检测报告、产地证明、合格证等文件。
   - 同样要看你是直接与鑫荣懋合作，还是通过下级批发商拿货。
   - 下级批发商不一定能提供鑫荣懋原始报告，可能只有自己的检测文件。

**茶饮店采购建议：**

- 采购前直接问供应商三句话：
  1. **“这批菠萝能不能提供对应批次的农残检测报告？”**
  2. **“报告是品牌方/产地出具的，还是你们经销商自己出的？”**
  3. **“报告上的批次号、日期能不能和到货批次对上？”**

- 合同中写明：
  - 供应商须随货或到货后提供**对应批次**农残检测报告；
  - 如抽检不合格，退换货及赔偿条款；
  - 报告需盖CMA/CNAS资质检测机构章更稳妥。

- 如果供应商只能给“通用报告”或“很久以前的报告”，要谨慎。农残检测报告最好和**具体批次**对应。

**实操结论：**
都乐和鑫荣懋**大概率能提供**，但你要通过**B端采购渠道**去要，并且明确要求**对应批次**。如果只是临时从批发市场拿货，能不能拿到品牌方报告就不一定了。最稳的方式是：找他们的区域经销或直供客户经理，先确认“是否能随批次提供农残检测报告”，再下单。
