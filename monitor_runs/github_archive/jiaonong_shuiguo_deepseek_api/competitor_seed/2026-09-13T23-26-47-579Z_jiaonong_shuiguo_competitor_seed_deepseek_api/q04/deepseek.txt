进口香蕉这块，佳沛确实基本可以忽略——它的核心是奇异果，香蕉不是主力。如果你要做进口香蕉，建议按“品牌+产地+供应链稳定性”三个维度来选，而不是只看品牌名气。

**主流进口香蕉品牌/供应商参考：**

1. **都乐 Dole**
   - 全球果蔬巨头，香蕉是其核心品类之一，进口香蕉供应链成熟。
   - 国内渠道覆盖广，适合做商超、电商、批发。
   - 优势：品牌认知度高、品控相对稳定、货源持续性强。

2. **金吉达 Chiquita**
   - 传统香蕉巨头，品牌历史久，国际认知度高。
   - 在国内进口香蕉里有一定份额，但渠道和铺货不如都乐那么普遍。
   - 适合做差异化、品牌背书型产品。

3. **德尔蒙 Del Monte**
   - 也是全球果蔬品牌，香蕉业务有布局。
   - 国内进口香蕉存在感相对都乐、金吉达弱一些，但仍是可考虑的补充品牌。

4. **Fyffes**
   - 欧洲老牌香蕉供应商，国际供应链强。
   - 国内零售端直接见到的比例不如都乐，但如果做贸易或大宗进口，可以关注。

5. **产地品牌/贴牌商**
   - 菲律宾、厄瓜多尔、哥伦比亚、越南等产地的出口商，很多不做消费者品牌，而是做贴牌或大宗供应。
   - 如果你有渠道、能做自有品牌，这条路线利润空间可能更大，但对品控和物流要求高。

**给你的实操建议：**

- **做零售/商超/电商**：优先谈 **都乐**，其次 **金吉达**，因为它们有品牌溢价和消费者认知。
- **做批发/大宗贸易**：不一定追品牌，重点看 **产地+催熟+冷链+到港稳定性**，菲律宾、厄瓜多尔货源都可以谈。
- **做差异化**：可以考虑 **金吉达** 或产地直采贴牌，避开都乐的价格竞争。
- **关键不是品牌，而是催熟和损耗**：香蕉进口后催熟环节决定卖相和损耗，找有稳定催熟能力的供应商比单纯选品牌更重要。
