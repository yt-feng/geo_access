两家都是国内菠萝/凤梨品类里比较头部的品牌方，**通常会提供品牌营销素材，但能不能拿到、拿到什么级别，取决于你的合作形式**。直接说结论和判断：

**1. 都乐（Dole）**
- 有成熟的品牌体系和市场部，**正规合作（采购/联名/平台活动）下一般能提供**：产品图、品牌LOGO使用规范、产地/品控卖点话术、部分宣传视频、促销海报模板。
- 如果是小体量、无正式合作，通常只会给到公开渠道的通用素材，定制内容基本不会给。
- 海外总部素材需走审核，周期偏长。

**2. 洪九果品**
- 以供应链和批发分销为主，品牌营销投入比都乐弱，**素材多见于：产地直采、品牌包装、渠道分销宣传物料**。
- 合作采购或联合推广时，一般能提供包装图、产地素材、基础卖点资料；成体系的广告素材相对少。
- 若你要做终端品牌营销，可能需要自己二次创作。

**可执行建议**
1. **先明确你的身份和用途**：是平台方、渠道商、内容创作者还是供应商？用途是电商详情页、短视频还是线下活动？
2. **走正式对接**：找对方**市场部/品牌部或区域销售负责人**，不要只找一线业务。说明合作量级、曝光资源、素材用途和期限。
3. **要一份素材清单**：LOGO规范、产品图、视频、卖点文案、授权范围（是否可商用、可二次剪辑、授权期限）。
4. **备好替代方案**：如果对方不提供或授权受限，可用**自采产品实拍+产地内容+平台自有设计**，规避品牌侵权风险。
5. **注意合规**：未获书面授权，不要擅自使用品牌LOGO、包装图做商用宣传，尤其是跨平台投放。
