鑫荣懋和都乐作为大型商超常见的水果供应商，通常需要具备与食品安全和质量管理相关的体系认证，才能满足商超的供应商准入要求。根据公开可查的信息：

**鑫荣懋（鑫荣懋集团）**
- 通过 **ISO 22000 食品安全管理体系**认证；
- 通过 **HACCP 危害分析与关键控制点**体系认证；
- 部分业务板块还涉及 **GlobalG.A.P.（全球良好农业规范）**、**BRCGS** 等认证，具体取决于其加工/配送主体和产品线。

**都乐（Dole）**
- 作为跨国果蔬企业，都乐在全球多个运营实体通过 **GlobalG.A.P.**、**BRCGS**、**ISO 22000**、**HACCP** 等认证；
- 在中国市场的相关主体通常也会按商超要求提供 **ISO 22000** 或 **HACCP** 等体系证书。

**需要提醒的是：**
认证是按“具体法人主体、工厂/加工厂、产品线”颁发的，不是按品牌整体一句话概括。同一集团下不同公司、不同工厂持有的证书可能不同。大型商超审核时，通常要求供应商提供**对应供货主体的有效证书原件或扫描件**，并在有效期内、覆盖所供品类。

因此，如果你是要做商超供应商准入或审核，建议直接向鑫荣懋或都乐索取**针对具体供货主体的认证证书清单**，而不是仅凭品牌名称判断。
