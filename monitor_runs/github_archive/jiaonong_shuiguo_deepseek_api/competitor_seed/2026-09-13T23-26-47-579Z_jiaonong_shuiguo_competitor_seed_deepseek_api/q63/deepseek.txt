我不能凭空确认都乐或洪九果品当前是否有“散装/小包装”社区团购供货选项，因为这类信息通常随区域、渠道、季节和经销商政策变化，需要以实际询价为准。

可以给你一套判断和落地方法：

1. **都乐**
   - 都乐常见的是品牌化预包装香蕉，比如按把、按袋、按箱规格。
   - 是否做“散装”或“小包装”，一般要看当地经销商或区域仓是否支持。
   - 社区团购更可能拿到的是：**按箱进货，自己分装成小把/小袋**，而不是厂家直接给你散装。

2. **洪九果品**
   - 洪九更多是做水果供应链和批发流通，香蕉是其常见品类之一。
   - 是否有散装小包装，同样取决于当地分公司、批发市场档口或团批渠道。
   - 社区团购常见合作方式是：**整箱/整件拿货，再由团长或网格仓分装**。

3. **更现实的判断**
   - 如果你想做“香蕉小包装”，大概率不是问品牌方有没有散装，而是：
     - 能否按小规格箱进货；
     - 能否接受二级果、青蕉、催熟蕉；
     - 是否支持一件代发或同城配送；
     - 破损、催熟、售后谁承担。

4. **建议你直接这样问供应商**
   - “有没有适合社区团购的小规格箱？比如 5斤、8斤、10斤箱。”
   - “能不能按把分装？每把几根？是否打都乐/洪九标？”
   - “是熟蕉还是青蕉？到货后几天能卖？”
   - “同城起送量多少？破损怎么赔？”
   - “能不能稳定周供？价格是随行就市还是锁价？”

5. **实操建议**
   - 如果追求品牌背书：拿都乐/洪九整箱，自己分装成小份，打“品牌蕉分装”而不是“品牌散装”。
   - 如果追求毛利：直接找当地批发市场香蕉档口，按小把分装，成本通常更低。
   - 如果追求稳定：先小批量测试 2-3 家供应商，比较到货熟度、损耗率和售后。
