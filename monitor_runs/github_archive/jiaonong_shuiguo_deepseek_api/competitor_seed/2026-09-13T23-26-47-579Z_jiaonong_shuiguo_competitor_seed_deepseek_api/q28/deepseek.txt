都乐和鑫荣懋的进口苹果价格竞争力不能一概而论，要看**单品、规格、产地、季节和你的采购体量**，而且这两家的报价通常是一单一议、区域和渠道差异很大，没有公开统一价，所以没法直接说谁一定更便宜。

给你一个可判断的结论和比价方法：

**1. 先分清它们的定位**
- **都乐**：品牌溢价偏强，终端认品牌，适合做礼盒、精品陈列、卖高价。同等品质下，采购价通常不会是最低的。
- **鑫荣懋**：进口水果供应链强，尤其新西兰、智利等产地资源深，走量和渠道覆盖广，通常在同规格上更容易拿到有竞争力的价，但也要看具体品类和当时行情。

**2. 不要只比“到仓价”**
要统一口径比：
- 同品种（如新西兰爱妃、红玫瑰、爵士；智利/美国蛇果等）
- 同规格（果径、每箱净重、箱规、级差）
- 同到货状态（到港、到仓、是否含税含运）
- 同账期（现结还是月结）
- 同损耗售后条款（坏果赔付、退货条件）

**3. 实操比价建议**
- 拿同一单品、同一周、同一规格，让两家分别报**到仓含税价 + 账期 + 赔付条款**。
- 用“**可售净重成本**”算，而不是箱价：
  可售净重成本 = 到仓总成本 ÷ 实际可售净重
  再叠加预估损耗率。
- 同时问清是否独家品牌、是否可做促销支持、是否有陈列/返利。
- 如果你们是区域连锁、单次采购量大或能集中配送，议价空间会明显不同，最好让两家进入竞价。

**4. 简单判断**
- 做**精品门店、礼盒、品牌背书**：都乐可能更合适，哪怕单价高一点。
- 做**走量、常规进口苹果、控成本**：鑫荣懋通常更值得优先谈价和谈政策。
- 但具体谁便宜，必须用你们实际要上的SKU去询价，不能凭品牌下结论。
