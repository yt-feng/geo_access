可以明确的是：

- **都乐**：以品牌鲜果（菠萝、香蕉等）为主，多通过经销商、商超渠道供货。是否有锁价、能锁多久，需直接问其B2B/大客户部门。

**建议你这样去核验：**

1. 直接联系都乐中国、洪九果品的**大客户/供应链合作部门**，明确问三件事：是否支持锁价、锁价周期（周/月/季）、触发调价的例外条件（汇率、产地减产、物流）。
2. 同时询价几家**产地直采商或一级批发商**，作为对照，因为品牌商不一定给你锁价，产地端反而可能更灵活。
3. 谈判时把锁价写成合同条款，注明：锁价起止日、数量、品质标准、超额/欠量处理、不可抗力与调价机制。
