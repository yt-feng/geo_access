都乐和洪九果品的菠萝，性价比不能只看“单价/个”，要结合你的门店定位、损耗率、客单价和周转速度来判断。下面给你一个可执行的对比框架，你按这个去谈和试销基本不会跑偏。

## 先给结论（按常见场景）

- **走大众销量、门店客单价偏低、想控损耗**：优先试**洪九果品**。通常拿货价更有优势，适合做引流款或常规款，毛利空间更容易做。
- **走中高端、门店客单价高、顾客认品牌**：优先试**都乐**。品牌溢价和稳定性更好，适合做品质款、礼盒款或即食菠萝。
- **最稳的做法**：两家都小批量试销 1–2 周，用同一门店、同一陈列位、同一价格带做 A/B 对比，看**实际售罄率、损耗率、复购和客诉**，而不是只看进货价。

## 为什么不能只比进货价

菠萝是强损耗品类，性价比要算“到手可售成本”：

**真实单果成本 = 进货价 ÷（1 - 损耗率）**

举例：
- 洪九进货 8 元/个，损耗 20%，真实成本 = 8 ÷ 0.8 = **10 元/个**
- 都乐进货 11 元/个，损耗 10%，真实成本 = 11 ÷ 0.9 = **12.2 元/个**

如果洪九损耗能压到 15% 以内，它性价比明显更高；如果洪九到店熟度不齐、黑心/烂果多，损耗冲到 30%，真实成本就反超都乐。

## 你重点对比这 6 项

1. **到货熟度一致性**
   - 都乐通常标准化更好，批次稳定。
   - 洪九看具体产地和批次，波动可能更大。
   - 熟度不齐会导致今天卖不完、明天全熟，损耗直接上升。

2. **单果重量和出肉率**
   - 同样一个菠萝，去皮后净肉差 100–150g，顾客感知和毛利差很多。
   - 让两家各发一箱，现场称重、去皮测出肉率。

3. **坏果率和售后**
   - 问清楚：黑心、烂心、水伤、过熟是否包赔，怎么举证，几天内有效。
   - 这一条对水果连锁很关键，能直接决定实际成本。

4. **供货稳定性**
   - 都乐品牌货，旺季可能紧俏，价格也硬。
   - 洪九供应链规模大，但不同区域仓配能力不一样，要看你所在城市。
   - 连锁店最怕今天有货明天断货，顾客刚认就没了。

5. **账期和起订量**
   - 洪九如果给账期、起订量低，现金流压力小。
   - 都乐如果要求现款、起订量高，会占资金。
   - 性价比要算资金周转，不只是毛利。

6. **顾客认不认**
   - 都乐有品牌背书，适合做“都乐金菠萝”这类明确标识。
   - 洪九在终端消费者心智里不一定强，更适合做“高性价比菠萝”而不是品牌款。
   - 如果顾客不认，你卖都乐也溢价不上去，那都乐的性价比就低。

## 建议的试销方案

选 3–5 家代表性门店，分两组：

- A 组：都乐，定价按你正常品质款
- B 组：洪九，定价低 1–2 元或做促销款

连续跑 7–14 天，记录：

- 进货个数、进货金额
- 售出个数、售出金额
- 报损个数、报损金额
- 客诉次数
- 顾客复购/询问品牌情况

最后算三个数：

1. **损耗率 = 报损个数 ÷ 进货个数**
2. **真实单果成本 = 进货价 ÷（1 - 损耗率）**
3. **单果毛利 = 实际售价 - 真实单果成本**

谁的单果毛利高、周转快、客诉少，谁性价比就高。

## 我的操作建议

- **大众社区店、销量型**：洪九做主力，都乐做少量品质款。
- **商场店、中高端社区、礼盒需求**：都乐做主力，洪九做促销补充。
- **不确定时**：先各进 1–2 箱试销，不要一次压太多。菠萝周转慢，压货就是亏。
- **谈判时**：拿两家的报价、损耗承诺、包赔政策互相压，重点争取**坏果包赔**和**账期**，这比单价便宜 0.5 元更值钱。
