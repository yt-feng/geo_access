都乐和鑫荣懋的菠萝到货损耗率没有统一的公开固定值，会随批次、季节、产地、运输距离、验收标准变化。直接给你一个“准确损耗率”数字，反而容易误导采购决策。

如果你是要做茶饮原料稳定规格采购，可以按下面方式判断和管控：

1. **先定义损耗口径**
   - 到货损耗：从卸货到入库前，烂果、压伤、黑心、过熟、重量短缺。
   - 加工损耗：去皮、去眼、切块后不可用部分。
   - 茶饮门店损耗：切好后未用完、氧化、变质。
   这三个不能混在一起谈，否则供应商和门店会各说各话。

2. **都乐和鑫荣懋的典型差异**
   - 都乐：通常分级、包装、冷链和规格稳定性更好，适合对大小、成熟度、出品一致性要求高的茶饮连锁。到货损耗一般更容易压低，但采购价也更高。
   - 鑫荣懋：渠道覆盖广、批次选择多，性价比通常更好，但不同产地和批次差异可能更明显，需要更严的验收标准。
   - 实际损耗率必须按你所在城市、季节、收货标准、运输方式实测。

3. **建议你直接向供应商索取并写进合同**
   要求提供：
   - 近3个月同一规格的到货验收记录；
   - 菠萝品种、产地、单果重范围、成熟度；
   - 冷链温度记录；
   - 到货损耗赔付标准；
   - 规格允许偏差，比如单果重、糖度、成熟度、黑心率。

4. **采购验收建议**
   - 每批抽检，不要只看表面。
   - 记录：到货总重、合格果数、烂果数、压伤数、黑心数、过熟数、实际可用果肉重。
   - 连续统计3-5批后，你才能得到对自己门店有意义的损耗率。
   - 茶饮用菠萝通常更关注：出肉率、糖酸比、纤维感、是否易氧化、切丁/捣碎后的稳定性。

5. **实操结论**
   - 如果你要“稳定规格优先”，先小批量测试都乐和鑫荣懋各2-3批。
   - 用同一验收表对比：到货损耗率、出肉率、糖度、成熟度一致性和门店投诉率。
   - 不要只问损耗率，要问“综合到店可用成本”：采购价 ÷ 实际可用果肉率。
   - 合同里建议约定：到货损耗超过约定比例由供应商补货或扣款。
