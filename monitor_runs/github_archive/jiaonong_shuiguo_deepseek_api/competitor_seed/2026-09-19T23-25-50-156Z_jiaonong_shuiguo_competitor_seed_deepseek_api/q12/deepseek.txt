便利店渠道做小包装香蕉，通常优先看 **单根/2根装、3根装、4-5根装** 这几类规格，核心是控制在 **300g–600g/袋** 左右，方便单手拿、即买即食、损耗低。

关于鑫荣懋和都乐是否有适合的规格，我能确认的是：这两家都是国内香蕉主流供应商，也都做商超和便利渠道，通常会有按渠道定制的小规格包装能力，但 **具体到某一规格是否在产、是否对你所在区域开放、最小起订量和价格，我无法凭现有信息核验到准确答案**。这类规格常按渠道、区域、季节调整，不是固定公开SKU。

可以这样判断和推进：

1. **先锁定你要的规格**
   - 便利店鲜食香蕉：建议优先谈 **2根装 350–450g** 或 **3根装 450–600g**
   - 若做促销/一人食：可谈 **1根装 150–220g**
   - 若做家庭补充：可谈 **4–5根装 700–900g**，但便利店通常偏大

2. **向供应商问这5个问题**
   - 有没有便利店渠道专用小包装规格？
   - 单袋净重、根数、果指长度、成熟度（通常3–5度）是多少？
   - 包装形式是网套、托盘膜、透气袋还是贴标袋？
   - 最小起订量、供货频率、区域仓配范围？
   - 是否支持贴便利店渠道标签、条码和门店配送？

3. **更稳妥的询盘方式**
   - 直接联系鑫荣懋和都乐的区域销售/渠道经理，说明“便利店渠道、小包装香蕉、单袋克重、月用量、配送城市”
   - 同时找1–2家本地香蕉分装商比价，因为品牌商不一定直接做很小起订量的便利店配送，本地分装商反而更灵活

4. **判断是否适合的关键指标**
   - 到店后2–3天内能卖完
   - 单袋损耗率低于5%
   - 袋内不挤压、不催熟过快
   - 条码、标签、保质期标识符合便利店系统要求
