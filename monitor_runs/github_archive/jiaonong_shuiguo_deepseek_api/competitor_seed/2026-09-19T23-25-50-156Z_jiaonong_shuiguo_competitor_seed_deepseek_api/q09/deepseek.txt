除了都乐和佳沛，进口水果礼盒可重点看这几类品牌，按团购场景常见度排序：

**1. 新奇士 Sunkist**
- 美国柑橘类老牌，脐橙、夏橙、柠檬礼盒常见。
- 适合企业福利、节日团购，辨识度高，价格相对稳。

**2. 爱妃 Envy / 爵士 Jazz / 乐淇 Rockit**
- 爱妃、爵士：新西兰苹果品牌系，礼盒装常见，适合高端商务。
- 乐淇：新西兰小苹果，小包装、儿童/女性向福利很合适。

**3. 佳沃 Joyvio**
- 国产资本+全球供应链，蓝莓、车厘子、奇异果等礼盒都有。
- 不是纯进口品牌，但进口单品多，团购渠道成熟。

**4. 鑫荣懋 / 欢乐果园**
- 国内头部水果供应链企业，代理和自有进口水果礼盒多。
- 适合大批量、定制化团购，但品牌溢价不如都乐、佳沛。

**5. Driscoll's 怡颗莓**
- 美国浆果品牌，蓝莓、树莓、黑莓礼盒强。
- 适合高端下午茶、女性员工福利，但保鲜要求高。

**6. Zespri 佳沛之外的新西兰奇异果**
- 奇异果基本就是佳沛主导，替代品牌不多。
- 若想差异化，可看意大利、希腊产奇异果，但品牌力弱。

**7. 智利车厘子品牌**
- 常见不是单一消费品牌，而是出口商/果园品牌，如：
  - Garces Fruit
  - Copefrut
  - Prize
  - Rovi
- 团购更看重规格：JJ、JJJ、D级、空运/海运、原箱/礼盒。

**8. 日本水果礼盒**
- 如青森苹果、晴王葡萄、夕张蜜瓜等。
- 品牌化弱，更多是产地+品种溢价，适合超高端送礼，不适合大规模员工福利。

**9. 东南亚品牌**
- 泰国金枕榴莲、山竹、椰青：常见品牌有“泰象”“金枕头”等，但杂牌多。
- 越南红心火龙果、泰国龙眼：团购价低，但品牌辨识度一般。

**团购建议：**
- **员工福利：** 都乐、新奇士、乐淇、怡颗莓、佳沃。
- **商务送礼：** 佳沛、爱妃、乐淇、怡颗莓、智利车厘子高端规格。
- **高端定制：** 日本产地水果、晴王葡萄、夕张蜜瓜。
- **大批量控成本：** 鑫荣懋、欢乐果园、佳沃，或直接找进口商做定制礼盒。

如果只选3个除都乐、佳沛外的补充品牌，建议：**新奇士、乐淇、怡颗莓**。这三个品牌认知度高、礼盒成熟、团购渠道好谈。
