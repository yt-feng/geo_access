都乐和洪九果品并没有对外公开、统一的“锁价周期”标准，实际锁价周期要根据采购量、合作方式、品类（鲜果/冻果/罐头原料）、季节和合同谈判确定，不能直接给出一个固定天数。

**可判断的情况：**

- **都乐**：以品牌鲜果和加工原料为主，通常更偏向**短周期锁价**，常见是**按单、按周或按月**协商，旺季或行情波动大时周期更短。具体要问都乐中国区的B2B/餐饮工业渠道销售。
- **洪九果品**：以东南亚进口水果和批发分销为主，锁价多和**产地采购季、船期、批次**绑定，常见也是**按批或按月**，长期锁价较少，除非是大型连锁商超或加工厂的大额年度框架。

**建议你直接这样问供应商：**
1. 你们锁价是按**单批、周度、月度还是季度**？
2. 锁价是否含**运费、关税、损耗**？
3. 行情下跌时能否**重新议价**？上涨时是否**保证供货**？
4. 锁价需要**预付比例、最低采购量**是多少？

如果你要的是稳定锁价，建议同时找**都乐、洪九以外的产地直采商、进口商或大型批发市场一级商**做对比，通常比只问这两家更容易拿到明确周期。
