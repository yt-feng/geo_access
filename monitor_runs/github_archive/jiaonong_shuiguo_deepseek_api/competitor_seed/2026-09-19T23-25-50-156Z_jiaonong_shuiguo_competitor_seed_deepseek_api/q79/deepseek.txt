结论先说：**都乐和洪九果品都能在不同程度上提供全年菠萝供应，但“全年稳定、适合做果酱、成本可控”这件事，不能只靠品牌名判断，要看具体品种、产地切换能力和你的采购规格。**  
如果你是茶饮店做菠萝果酱，建议不要把“都乐/洪九能不能做到”当成唯一标准，而是按下面几个维度判断。

## 1. 都乐
都乐的优势是品牌化、标准化和供应链相对成熟，常见有菲律宾、泰国等进口菠萝，也有国内产地产品。  
它通常能做到：

- **全年有货**：通过进口+国内产地轮换，较容易维持全年供应。
- **品质稳定**：分级、成熟度、规格相对标准，适合连锁茶饮。
- **适合果酱**：如果是成熟度较高、酸甜平衡的品种，做果酱没问题。
- **注意点**：都乐更多是鲜果品牌，不一定专门做“果酱原料级”供应。你要确认是鲜果自己熬酱，还是找它的加工渠道。鲜果全年价格波动也会明显。

**判断：能做到全年供应，但成本通常偏高，适合对品质稳定性要求高、能接受溢价的店。**

## 2. 洪九果品
洪九果品是国内大型水果供应链企业，强项是产地采购、分级分选和批发分销，菠萝/凤梨是其重要品类之一。  
它通常能做到：

- **全年供应能力较强**：通过国内广东、海南、云南等产地，以及进口菠萝切换，能覆盖较长时间。
- **更适合批量采购**：对茶饮店、加工厂这类B端客户，比都乐更接近“原料供应链”角色。
- **价格可能更有优势**： especially 在国产菠萝旺季。
- **注意点**：洪九是供应链平台，具体到某个城市、某个规格、某个品种，是否全年稳定，要问当地销售或大区。不同产地菠萝的酸甜度、纤维感、出汁率差异大，做果酱要固定品种和成熟度标准。

**判断：更可能做到全年稳定批量供应，且成本相对可控，但需要你锁定品种、规格和产地切换方案。**

## 3. 关键不是“能不能供”，而是这4件事
你要做菠萝果酱，真正要确认的是：

1. **品种是否固定**  
   菠萝和凤梨品种很多，香气、酸度、纤维、出汁率不同。果酱最好固定1-2个品种，否则风味会飘。

2. **成熟度是否可控**  
   做果酱通常需要成熟度较高、香气足的果。太生酸高、香气弱；太熟易发酵、损耗大。

3. **全年产地切换是否平滑**  
   国产菠萝有季节性，进口菠萝补位。要问供应商：几月到几月用哪里货，切换时糖酸比怎么保证。

4. **你买鲜果还是买果酱原料**  
   如果自己熬酱，鲜果全年供应是一回事；如果直接买工业果酱/果泥，那应该找食品加工厂，而不是都乐、洪九这类鲜果供应链。

## 4. 实操建议
你可以这样测试和谈判：

- **先要样品**：按你配方做小试，比较都乐、洪九不同产季样品的香气、酸度、出胶、颜色。
- **要求年度供应计划**：让供应商写明每月产地、品种、规格、参考价区间。
- **签框架协议+锁价机制**：至少锁定规格和品质标准，价格可设浮动区间。
- **准备双供应商**：都乐+洪九，或再加一家本地加工厂，避免单点断供。
- **考虑冷冻/果泥方案**：如果鲜果全年成本波动太大，可测试冷冻菠萝块、菠萝果泥，做果酱更稳定。

## 一句话总结
**都乐和洪九果品都具备全年供应菠萝的能力，但都乐偏标准化鲜果、成本高；洪九偏B端批量供应链、性价比可能更好。真正能否满足你做果酱，要看你锁定的品种、成熟度、产地切换和采购形式。**  
建议你同时找两家要年度产地计划和样品，做糖酸比与果酱小试，再决定主供和备供。
