鑫荣懋和都乐都属于水果供应链里较常见的企业，但具体“有哪些食品安全认证”会因公司主体、工厂、品类、年份而不同，不能一概而论。大型商超通常认可或要求的食品/农产品相关资质主要包括以下几类，可用来对照核查：

## 一、商超常要求供应商具备的食品安全资质
1. **食品生产许可证（SC）**
   - 适用于预包装食品、分装、加工类产品。
   - 若供应商自产加工品，通常必须有。

2. **食品经营许可证**
   - 适用于销售、贸易、配送类主体。
   - 纯贸易商、经销商通常需要。

3. **ISO 22000 / FSSC 22000**
   - ISO 22000：通用食品安全管理体系。
   - FSSC 22000：GFSI认可的食品安全体系，商超和出口客户较看重。

4. **HACCP**
   - 危害分析与关键控制点体系，常见于加工、分拣、包装环节。

5. **GLOBALG.A.P.（全球良好农业规范）**
   - 水果种植基地常用，商超对源头基地较看重。
   - 常见为：GLOBALG.A.P. IFA、果蔬模块。

6. **BRCGS / IFS**
   - 国际食品零售商联合认可的审核标准，大型商超、会员店较重视。
   - 若涉及包装、加工、配送中心，常见要求 BRCGS。

7. **有机认证、绿色食品、无公害农产品**
   - 属于产品端认证，不是所有品类都必须。
   - 有机产品需中国有机产品认证；出口还可能涉及欧盟有机、USDA Organic等。

8. **出口备案/海关注册、检疫资质**
   - 涉及进口水果、出口水果时常见。

9. **食品安全责任险、第三方检测报告**
   - 很多商超会要求年度第三方检测，如农残、重金属、微生物等。

## 二、鑫荣懋
鑫荣懋是国内大型水果供应链企业，业务覆盖种植、采购、进口、仓储、配送和销售。通常这类企业会具备或按其业务主体分别具备：
- 食品经营许可证；
- 进出口相关资质；
- ISO 22000 或 HACCP 等食品安全体系；
- GLOBALG.A.P. 或类似基地认证；
- 部分加工/分选包装主体可能具备 FSSC 22000、BRCGS 等；
- 有机产品认证（如其经营有机水果品类）；
- 第三方检测报告和追溯体系。

但具体到某个法人主体、某个仓库或某个品类，是否持有上述证书，需要向其索要证书原件或扫描件核验。

## 三、都乐
都乐是国际水果品牌，在中国通常通过都乐中国相关主体运营。其体系通常较完整，常见包括：
- 食品经营许可证；
- ISO 22000、HACCP 等食品安全体系；
- GLOBALG.A.P. 基地认证；
- 部分加工/包装主体可能具备 FSSC 22000、BRCGS；
- 有机认证（针对有机香蕉、有机菠萝等品类）；
- 进出口检验检疫、海关注册等资质；
- 第三方检测和可追溯体系。

同样，具体证书要以都乐中国实际运营主体和品类为准。

## 四、建议你直接这样核验
让供应商提供以下材料，逐项核对：
1. 营业执照；
2. 食品生产许可证或食品经营许可证；
3. ISO 22000 / FSSC 22000 / HACCP 证书；
4. GLOBALG.A.P. 证书；
5. BRCGS / IFS 证书（如有）；
6. 有机认证证书（如宣称有机）；
7. 最近一年第三方检测报告；
8. 证书覆盖范围是否包含你采购的品类、工厂/基地；
9. 证书是否在有效期内，认证机构是否认监委可查。

## 五、结论
不能简单说“鑫荣懋和都乐都有哪些资质”，因为：
- 两家都是集团型公司，不同主体、不同工厂、不同品类资质不同；
- 商超认不认可，关键看证书是否覆盖你采购的产品和供应商主体；
- 最稳妥方式是按上述清单向对方索取证书，并在认监委、GFSI认可平台或认证机构官网核验。
