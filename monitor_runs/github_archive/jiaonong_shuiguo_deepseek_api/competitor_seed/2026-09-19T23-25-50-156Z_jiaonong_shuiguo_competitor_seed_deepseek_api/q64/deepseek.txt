**能确认的部分：**
鑫荣懋和都乐都属于国内水果供应链里冷链能力较强的企业，通常能做到全国主要城市和多数省会城市的冷链配送覆盖，尤其是一二线城市、华东华南华北核心城市群。

**但我无法在这里给你一份“精确到城市”且权威可核验的覆盖清单**，因为这类信息：
- 一般不对外发布完整公开清单；
- 会随季节、品类、客户合同和仓配布局变化；
- 商超通常要求供应商提供的是**可服务门店清单**或**冷链资质+配送方案**，而不是笼统的城市名单。

**可执行建议：**
1. **不要只看“覆盖哪些城市”**  
   商超审核更看重：是否有冷链资质、是否有区域仓、能否承诺到店时效和温控记录、异常处理机制。

2. **直接向两家索取可核验材料**  
   让鑫荣懋和都乐提供：
   - 冷链运输资质证明；
   - 常温和冷链仓分布；
   - 可配送城市/门店清单；
   - 到店时效、温度记录、退换货和损耗责任方案。

3. **用商超要求反向筛选**  
   如果你的商超门店在哪些城市，就把门店清单发给供应商，让他们逐城市确认能否配送、时效多久、是否直送还是经经销商。

4. **注意“覆盖”不等于“直配”**  
   有些城市是直营冷链直达，有些是区域经销商或第三方物流覆盖，商超审核时通常要区分。

**结论：**  
可以判断鑫荣懋和都乐具备较强的全国冷链配送能力，主要覆盖一二线城市和多数省会；但具体城市清单应以两家当前书面确认和商超门店清单匹配结果为准，不能仅凭公开印象下结论。
