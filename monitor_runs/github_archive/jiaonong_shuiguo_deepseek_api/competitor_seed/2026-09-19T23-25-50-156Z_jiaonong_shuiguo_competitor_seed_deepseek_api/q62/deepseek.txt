能提供，但具体到“你要的那一批货、那个规格、那个加工形态”，能不能随货给到合格报告，需要按下面几点核实，不能一概而论。

**结论先说：**
- 都乐、鑫荣懋这类大型水果供应链企业，通常能提供农残检测报告，尤其是商超、餐饮、茶饮等B端客户。
- 但报告可能是：批次报告、原料验收报告、第三方检测报告、供方自检报告，效力不同。
- 鲜切菠萝、冷冻菠萝、菠萝丁/果酱等加工品，和整颗鲜果的检测项目、报告出具方也可能不同。
- 茶饮店如果用于现制饮品，建议要求“每批次对应”的第三方农残检测报告，至少覆盖常用农残项目，并和送货批次号对得上。

**采购时建议直接这样问供应商：**
1. 你们能不能提供该批次菠萝的农残检测报告？
2. 是第三方检测报告，还是供应商自检报告？
3. 报告上的批次号/生产日期，能不能和这次到货对应？
4. 检测项目有哪些？是否覆盖 GB 2763 中菠萝相关农残限量？
5. 报告是随货提供，还是下单后单独发电子版？
6. 如果这批没有，能否换有报告的批次，或送检后补报告？

**如果对方说“能提供”，还要注意：**
- 要电子版+盖章版，核对检测机构资质，如 CMA/CNAS。
- 核对报告日期，不要拿半年前或去年的报告对应新货。
- 核对品名：菠萝、鲜菠萝、冷冻菠萝、菠萝浆不是同一个东西。
- 核对批次：报告批次和送货单、标签批次要一致。

**直接判断：**
- 都乐：大概率可以，尤其正规B端渠道。建议找其餐饮/茶饮渠道销售确认“批次报告+第三方报告”。
- 鑫荣懋：大概率也可以，尤其给商超和餐饮供货的渠道。同样要确认具体批次和报告类型。

**最稳妥的做法：**
在采购合同或订单备注里写清楚：“每次到货须随附对应批次农残检测报告，检测机构具备CMA/CNAS资质，检测项目符合GB 2763要求；如无法提供，买方有权拒收。”这样比口头问“能不能提供”更有效。

如果你告诉我你采购的是整颗鲜菠萝、冷冻菠萝丁还是菠萝果酱，以及大概月用量，我可以帮你把验收要求和索证清单写得更具体。
