鑫荣懋和都乐都是国内大型商超常见的水果供应商，但**“谁认证更全”不能一概而论**，关键要看：

1. **你作为商超/采购方要求的是哪类认证**
2. **具体品类、加工环节、工厂/配送中心是否纳入审核**
3. **证书是否覆盖你采购的SKU和供货主体**

一般商超最常要求供应商具备这些食品安全/质量体系认证：

- **ISO 22000**：食品安全管理体系
- **HACCP**：危害分析与关键控制点
- **FSSC 22000**：部分商超更认可，覆盖食品制造/加工
- **BRCGS**：国际食品标准，常用于出口和高端商超
- **IFS**：国际食品标准
- **GLOBALG.A.P.**：农业种植端良好农业规范
- **有机认证**：如中国有机、欧盟有机等，按品类
- **绿色食品/无公害认证**：国内部分渠道要求
- **SC生产许可**：若涉及分切、加工、包装
- **出口备案/海关注册**：若涉及进口或出口

就公开信息而言：

- **都乐**：作为国际水果品牌，通常在全球供应链、种植基地、加工包装环节有较完整的国际认证体系，常见包括GLOBALG.A.P.、ISO 22000、HACCP、BRCGS等，具体取决于产地、品类和运营主体。
- **鑫荣懋**：国内大型水果供应链企业，通常也具备ISO 22000、HACCP等体系认证，并会按商超要求提供基地认证、加工厂认证和检测报告。其优势在于国内渠道覆盖和供应链整合，认证覆盖往往按客户和品类配置。

所以，如果你问的是**“谁证书数量更多”**，没有公开统一清单，无法直接下结论。  
如果你问的是**“谁更适合大型商超审核”**，建议按下面方式判断：

**更可执行的判断方法：**

1. **要求两家分别提供证书清单**
   - 证书名称
   - 证书编号
   - 认证范围
   - 有效期
   - 发证机构
   - 覆盖工厂/基地/品类

2. **核对是否覆盖你采购的具体商品**
   - 例如都乐香蕉、鑫荣懋奇异果，认证可能落在不同主体或工厂。

3. **看商超自身审核标准**
   - 有的商超只认ISO 22000/HACCP
   - 有的要求FSSC 22000、BRCGS
   - 有的要求GLOBALG.A.P.或有机认证

4. **看是“公司级认证”还是“基地/工厂级认证”**
   - 公司有证，不代表每个供货基地都有证。

5. **看检测和追溯能力**
   - 农残检测报告
   - 追溯体系
   - 冷链记录
   - 不合格品召回流程

**结论：**
- 如果只看国际认证广度和品牌全球化程度，**都乐通常更占优势**。
- 如果看国内商超渠道适配、本地供应链配合和按需补证能力，**鑫荣懋通常也很强**。
- 但“谁更全”必须拿到**具体证书清单和认证范围**才能判断，不能仅凭品牌下结论。

如果你是商超采购，最稳妥的做法是：让两家按你公司的《供应商食品安全准入清单》逐项提交证书和检测报告，缺哪项补哪项，再比较通过率。
