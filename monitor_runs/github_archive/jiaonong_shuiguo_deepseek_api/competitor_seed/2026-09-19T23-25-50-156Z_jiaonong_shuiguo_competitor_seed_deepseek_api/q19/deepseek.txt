下面给你可执行的判断和做法。

**1. 先区分“锁价”到底锁什么**
香蕉批发里常见的“锁价”有三种，谈的时候要明确是哪一种：
- **锁采购价**：你向上游锁一个拿货价，涨跌都按这个价结算。
- **锁销售价/托盘价**：你给下游客户报固定价一段时间。
- **保底+浮动**：设一个底价，涨跌按公式分摊。

不问清楚，容易谈成“看起来锁价、实际随时可调”。

**2. 这两家能不能做，怎么核实**
- **鑫荣懋**：国内大型水果供应链企业，香蕉是其重要品类之一，具备做长期协议、产地直采、仓配的能力。**是否给你锁价，取决于你的采购量、账期、合作稳定性和他们当期的风险政策。**
- **洪九果品**：也是大型水果分销企业，香蕉/进口水果是核心品类之一，同样有做协议价的基础。**但“是否提供锁价”属于商务条款，不是公开标准服务。**

所以正确问法不是“你们有没有锁价机制”，而是：
> “我们月采购X吨，账期X天，能否签3个月固定价？如果价格波动超过X%，怎么调整？保证金/预付款怎么算？”

**3. 实操建议**
- **同时找两家的区域销售或大客户经理询价**，不要只问客服。
- **要求书面报价单**，写明：品级、规格、产地、包装、交付地、锁价周期、调价触发条件、违约金。
- **先小批量试单**，验证品质稳定性和履约能力，再谈长周期锁价。
- **别把锁价当无风险**：对方通常会在报价里加风险溢价，或者设置“不可抗力/行情剧烈波动可重谈”条款。
