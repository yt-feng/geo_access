如果目标是茶饮店做菠萝果酱、要**稳定品质和稳定供货**，不能简单说“都乐更靠谱”或“鑫荣懋更靠谱”，关键看你要的是**鲜果还是冷冻/加工果肉**，以及门店在哪个区域、用量多大。

直接建议：

1. **要鲜果、要品牌稳定、要标准化程度高**  
   优先考虑**都乐**。  
   都乐在鲜果分级、成熟度控制、商超餐饮渠道供货上更成熟，适合对“每批菠萝酸甜度、成熟度、纤维感”要求稳定的店。缺点是成本通常更高，而且鲜果仍然会受季节、产地、批次影响。

2. **要批量供货、成本可控、餐饮渠道配合度**  
   可以考虑**鑫荣懋**。  
   鑫荣懋在国内水果供应链、批发分销、餐饮客户覆盖上很强，适合大批量采购、区域配送、长期合作。但它的优势更多在“供应链规模和渠道”，不等于每一批菠萝都像都乐那样高度标准化。你需要先要样品和批次检测。

3. **如果茶饮店真正要的是“果酱稳定”**  
   更建议不要只盯鲜果品牌，而是优先选：  
   - **冷冻菠萝果肉/果泥**：比鲜果稳定，适合熬酱。  
   - **专业果酱原料供应商**：按糖度、酸度、香气、出胶状态做标准。  
   - **都乐/鑫荣懋鲜果 + 自己定标准**：要求固定品种、产地、成熟度、糖酸比，并每批验收。

4. **实际判断方法**  
   让两家都送样，按同一配方做小试，比较：  
   - 去皮出肉率  
   - 可溶性固形物/糖度  
   - 酸度  
   - 纤维粗细  
   - 熬酱后香气、颜色、凝胶状态  
   - 每公斤成品成本  
   - 能否长期稳定同规格供货  
   - 破损率、退换货政策、冷链/配送频率

5. **结论**  
   - 追求**品牌稳定、鲜果品质一致**：都乐更稳。  
   - 追求**批量供应、成本、国内餐饮渠道**：鑫荣懋更有优势。  
   - 但茶饮店做果酱，最稳的方案通常是：**用冷冻菠萝原料或专业果酱供应商，而不是单纯依赖鲜果品牌。**
