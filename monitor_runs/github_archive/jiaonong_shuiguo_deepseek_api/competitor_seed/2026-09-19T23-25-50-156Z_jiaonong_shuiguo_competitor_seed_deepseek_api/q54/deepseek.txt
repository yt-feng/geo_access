# 都乐（Dole）与鑫荣懋（Joy Wing Mau）进口苹果的产地溯源做法

先说结论：**两家的溯源体系都建立在"批次码/标签码 → 内部系统 → 上游果园/包装厂"这条链路上，但你能拿到的颗粒度，取决于采购时签的合同条款和对方开放的系统接口。** 超市端要做的核心动作是：**把"批次对应关系"和"证明文件"落到收货环节，而不是等出问题再追。**

下面分两部分说。

---

## 一、两家的大致差异（帮你判断该要什么）

**都乐（Dole）**
- 全球性品牌，进口苹果多来自美国（华盛顿州为主）、新西兰、智利等产区。
- 溯源通常以**PLU码 + 箱标批次号 + 托盘号**为核心，包装箱上有产地国、果园/包装厂编号、采收/包装日期。
- 作为品牌方，其出口端普遍具备 GlobalG.A.P. 等认证，可提供**产地证明、植物检疫证书（Phytosanitary Certificate）、原产地证**。
- 但对中国超市客户，开放到"具体果园"的程度一般有限，多半到**包装厂/产区+批次**这一层。

**鑫荣懋（Joy Wing Mau）**
- 国内头部进口水果供应链企业，本身就是"进口商+分销"角色，代理多个海外品牌和自有渠道。
- 溯源链条是**海外供应商/果园 → 鑫荣懋进口批次 → 分销给你**。它的批次管理往往更贴近国内客户需求，可能提供**批次溯源查询或纸质批次对应表**。
- 关键点：你要追的"产地"，在它这里可能是**它上游的海外供应商产地**，中间多一层，追溯时要盯住"这批货对应哪个进口批次/报关单"。

**共同点**：真正的溯源锚点是**箱标批次 + 报关单 + 植检证**，不是口头承诺的"某某产地"。

---

## 二、超市端可执行的操作（按收货流程走）

**1. 合同/采购协议里写死溯源条款**
- 要求供应商提供：报关单、入境货物检验检疫证明、原产地证、植检证（按品类）。
- 约定**批次可追溯**：每批货能对应到具体进口批次号。
- 约定出问题时的召回与责任条款。这一条是后面所有操作的依据，没有它，索要数据会很被动。

**2. 收货环节做"批次绑定"**
- 记录**箱标批次号 / 托盘号 / PLU码 / 包装日期**，与你内部收货单绑定。
- 拍下箱标、产地标识照片存档。
- 同一SKU不同批次**分开收货、分开放置**，避免混批导致无法追溯。

**3. 索要并核验文件**
- 报关单：核对品名、产地国、数量、日期与实物批次是否对得上。
- 植检证 / 入境检验检疫证明：核对产地、批次。
- 原产地证：确认产地国别。
- 都乐/鑫荣懋的**批次对应表或查询入口**（部分可通过其客户系统或业务对接人获取）。

**4. 建立内部溯源台账**
- 字段建议：入库日期｜供应商｜品牌｜产地国/产区｜批次号｜报关单号｜植检证号｜数量｜货架期｜关联销售记录。
- 目的：一旦出现质量问题或监管抽检，能在**小时内**定位到批次并下架。

**5. 追溯演练（可选但有用）**
- 随机抽一个在售批次，要求供应商在约定时限内回复其产地/包装厂信息，检验对方响应能力。

---

## 三、实操建议（针对你"超市采购"的场景）

- **优先要"批次级"而非"产地级"溯源。** "进口自新西兰"这种信息对召回没用，批次号才有用。
- **都乐**：直接向其对接口的业务/客服索要**批次对应表和随货文件**，开放接口的可能性取决于你的采购量。
- **鑫荣懋**：因为它本身是进口商，可以要求它提供**该批货对应的报关单和上游产地信息**，相对更直接。
- **最容易被忽略的一环**：收货时没记批次号。很多超市溯源失败都卡在这里，而不是卡在供应商不配合。
