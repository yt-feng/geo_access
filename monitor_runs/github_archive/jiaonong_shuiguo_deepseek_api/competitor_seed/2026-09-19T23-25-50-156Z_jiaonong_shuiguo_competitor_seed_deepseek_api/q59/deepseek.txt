都乐和洪九果品对下游客户的账期并没有公开统一的标准，实际账期取决于合作规模、采购量、结算方式、信用资质和具体签约主体，不同客户拿到的条件可能差别很大。

可以给你几个判断方向：

1. **都乐**
   - 都乐在中国更多通过经销商、批发市场和商超渠道走货，直接给中小客户放账期的空间通常不大。
   - 如果是大型商超、连锁水果店、电商平台或长期大客户，才更可能谈月结，常见可能是 **30天左右**，但这不是公开政策。
   - 中小采购方一般更可能是现款现货、款到发货，或者短账期。

2. **洪九果品**
   - 洪九果品是较大的水果供应链企业，过去主要做批发、商超和零售渠道，理论上对大客户可能有账期安排。
   - 但洪九果品近两年经营和财务情况波动较大，账期政策可能收紧，甚至要求预付款或现款结算。
   - 即使能谈账期，也更可能针对大型连锁商超、电商、长期稳定采购方，常见也是 **30—60天** 这类区间，但同样没有公开统一标准。

3. **实际建议**
   - 不要直接按“都乐/洪九账期多久”去判断，最好直接联系其区域销售或大客户部，说明你的采购量、结算周期、历史合作和信用情况。
   - 问清楚：是否支持账期、账期起算日、是否要保证金、是否走供应链金融、逾期费用怎么算。
   - 如果对方要求先款后货，可以尝试用**首单现结、后续月结**或**部分预付+尾款账期**去谈。
   - 同时可以找一级批发商、区域总代、进口蕉一级货主谈，往往比直接找品牌方更容易拿到短账期。
