大型商超（如沃尔玛、山姆、永辉、盒马等）在引入水果供应商时，通常要求其具备 **GFSI（全球食品安全倡议）认可的食品安全认证**，常见包括 **BRCGS、IFS、FSSC 22000、SQF** 等，部分还会要求 **ISO 22000**、**HACCP** 或 **GlobalG.A.P.**（针对种植环节）。

关于**鑫荣懋**和**都乐**具体通过哪些认证，我无法在当前对话中核验其最新、完整的认证清单，因此不能凭空列出具体证书名称或编号。建议你通过以下可执行方式确认：

1. **直接向供应商索取认证证书扫描件**  
   重点看：认证标准、认证机构、证书编号、有效期、认证范围是否覆盖你采购的产品/工厂。

2. **在认证机构官网核验证书真伪**  
   - BRCGS：BRCGS Directory  
   - IFS：IFS Database  
   - FSSC 22000：FSSC 22000 Database  
   - SQF：SQFI Assessment Database  
   用证书编号或企业名称查询。

3. **要求供应商提供审核报告或最近一次审核结果**  
   大型商超通常不只看证书，还会看审核等级（如 BRCGS A/AA/AAA、IFS Higher Level 等）。

4. **确认认证覆盖的具体场地**  
   同一集团不同工厂/包装厂认证情况可能不同，必须核对到具体供货主体。
