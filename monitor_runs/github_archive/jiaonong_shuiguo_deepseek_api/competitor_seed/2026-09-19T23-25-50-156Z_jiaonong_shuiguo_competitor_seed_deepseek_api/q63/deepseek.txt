我没有能力核验都乐和洪九果品当前的散装/小包装供货政策，所以不能直接给你“有”或“没有”的确定答案。不过可以给你一套可执行的判断和推进方法：

**1. 先明确你要的“散装”到底是哪种**
社区团购里通常有三种：
- **整箱散根装**：一箱里是散香蕉，不是精装礼盒，可按根/按份分拣。
- **定量小包装**：如2根装、3根装、500g装、1kg装，带袋/托盒。
- **门店散称货源**：供应商按斤供货，你们自行分装。

都乐、洪九这类品牌商更多是**按箱/按件**出货，是否有小规格，取决于区域经销商和渠道政策，不一定是全国统一。

**2. 直接问供应商这几个关键问题**
联系都乐或洪九当地经销商时，直接问：
- 有没有**小规格箱规**，比如5kg、8kg、10kg？
- 箱内是**散根**还是**梳蕉/把蕉**？
- 能不能做**2根装、3根装、500g装**的固定小包装？
- 小包装是**原厂预包装**，还是经销商/第三方分装？
- 起订量、供货价、损耗赔付、冷链/催熟状态怎么算？
- 是否支持**社区团购一件代发或网格仓配送**？

**3. 更现实的替代方案**
如果都乐、洪九没有合适小包装，社区团购通常这样解决：
- 找**区域水果批发商/经销商**拿散装香蕉，自行分装。
- 找**本地催熟库或香蕉专业供应链**，他们更容易做小规格。
- 用**二级品牌或产地直发**做小包装，成本更低。
- 都乐可做**引流品**，洪九或本地货做**利润品/日常品**。

**4. 判断建议**
- 如果你们单量小：优先找本地经销商散装分装，不要死磕品牌原厂小包装。
- 如果你们单量大且稳定：可以跟都乐/洪九区域经销商谈定制小包装或专属规格。
- 如果要做品牌心智：都乐小包装有价值，但成本通常更高。
- 如果要做性价比：洪九或本地供应链更灵活，但小包装未必是原厂。

**最稳妥的做法**：直接联系都乐和洪九在你们城市的**区域经销商**，不要只问总部客服。问清楚“有没有小规格箱规、能否代分装、起订量和配送方式”，这是最快能确认的路径。
