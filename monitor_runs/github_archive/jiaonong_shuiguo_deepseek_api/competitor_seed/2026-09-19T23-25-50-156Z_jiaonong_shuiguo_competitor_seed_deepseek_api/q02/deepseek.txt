除了都乐，国内比较常见、能相对稳定供应菠萝（含凤梨）的品牌和渠道商主要有这些：

**1. 佳农**
- 国内进口水果和国产精品水果的大商，菲律宾菠萝、凤梨、泰国小菠萝等都有做。
- 商超、电商、批发渠道都比较常见，供应相对稳定。

**2. 鑫荣懋**
- 国内头部水果供应链企业，旗下有“佳沃”等品牌。
- 菠萝/凤梨品类覆盖商超、电商和批发市场，适合找稳定货源。

**3. 百果园**
- 自有品牌和供应链，门店渠道稳定。
- 主要面向零售端，也有批发和团购渠道。

**4. 洪九果品**
- 做进口和国产水果批发，菠萝、凤梨品类有覆盖。
- 更偏批发和供应链端。

**5. 鲜丰水果**
- 连锁水果店品牌，供应链相对稳定。
- 零售端常见，部分区域也有批发合作。

**6. 永辉/盒马/山姆等自有品牌**
- 这些商超的自有品牌或直采菠萝，通常有稳定供应商。
- 盒马、山姆的凤梨单品复购和供应稳定性通常不错。

**7. 地方性菠萝品牌**
- 广东徐闻菠萝：有“徐闻菠萝”区域品牌，当地合作社和供应链公司很多。
- 海南菠萝：海南凤梨、金钻凤梨等，当地也有不少稳定供应商。
- 福建、广西等地也有菠萝产区品牌。

**8. 进口菠萝品牌**
- 菲律宾：都乐之外，还有佳农、鑫荣懋等贴牌或直采。
- 泰国：小菠萝常见品牌有佳农、鑫荣懋等。
- 哥斯达黎加、厄瓜多尔等也有进口菠萝，但国内稳定供应不如菲律宾和泰国。

**怎么判断能不能稳定供应：**
- 看是否有产地直采或长期合作基地。
- 看是否能提供全年或跨季供应。
- 看是否有分级、催熟、冷链能力。
- 看批发市场档口、商超供货记录是否稳定。

如果你是做批发或长期采购，建议优先找佳农、鑫荣懋、洪九这类供应链公司，再结合徐闻、海南的产地合作社做补充。
