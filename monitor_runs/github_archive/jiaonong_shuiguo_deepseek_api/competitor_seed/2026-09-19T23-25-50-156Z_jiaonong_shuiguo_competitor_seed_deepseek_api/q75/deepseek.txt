两者的到货损耗率没有统一的官方公开对比数字，因为损耗率受季节、产地、运输距离、冷链条件、批发市场卸货方式、你拿货的成熟度等多因素影响，同一品牌不同批次都可能差很多。下面给你一个可判断的框架和行业常见区间，供你谈判和验货时参考。

**一、常见区间（经验值，非官方数据）**

| 维度 | 洪九果品 | 都乐香蕉 |
|---|---|---|
| 品牌定位 | 国内大型水果供应链，品类多、渠道广 | 国际品牌，香蕉标准化、催熟体系成熟 |
| 香蕉到货损耗常见区间 | 约3%–8%（视批次/季节） | 约2%–6%（视批次/季节） |
| 主要损耗来源 | 催熟不均、压伤、青黄不一致、尾货 | 运输磕碰、催熟过头、个别批次色差 |
| 稳定性 | 批次波动相对大 | 标准化程度通常更高，波动相对小 |

注意：这只是行业里比较常见的经验区间，不代表任何一方的承诺值，也不能当作合同依据。

**二、影响损耗的关键变量（比品牌更重要）**

1. **成熟度**：拿青蕉还是黄蕉，损耗能差一倍以上。青蕉耐放，黄蕉到货即需快速出货。
2. **冷链**：全程冷链 vs 断链，损耗差异非常明显。
3. **运输距离与季节**：夏季高温、长途运输损耗普遍上升。
4. **包装与码放**：纸箱透气性、堆高、是否压箱。
5. **卸货方式**：人工抛卸 vs 规范搬运，磕碰损耗差别大。
6. **你所在市场的周转速度**：走得快，损耗自然低。

**三、建议你这样实测对比**

- 同一时期、同一市场，各拿一批（比如各10箱），记录：到货总重、可售重量、次品重量。
- 分品类统计：压伤、霉变、催熟过度、青蕉不熟。
- 连续跟踪3–5批，取平均，才有参考意义。
- 把损耗折算成**每斤实际可售成本**，再和报价一起比，而不是只看拿货价。

**四、采购谈判要点**

- 合同里明确：到货验收标准、损耗超出部分如何补货或折价。
- 要求供应商提供当批的催熟记录、冷链温度记录。
- 首次合作先小批量试单，别一上来压大货。

**一句话结论**：都乐香蕉因标准化和催熟体系通常损耗略低、更稳定；洪九品类广、价格和批次弹性大，损耗波动可能更大。但具体到你的市场，必须以自己连续几批的实测数据为准，品牌只能作参考。
