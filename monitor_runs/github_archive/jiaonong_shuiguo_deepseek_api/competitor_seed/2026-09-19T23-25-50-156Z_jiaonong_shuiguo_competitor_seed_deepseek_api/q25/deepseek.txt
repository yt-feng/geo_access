这个问题的核心不是"谁更愿意"——**两家都愿意签年单，但愿意的条件和风险差别很大**，尤其在洪九果品目前的情况下，判断逻辑完全不同。

**鑫荣懋**

- 国内头部水果供应链企业，以长期稳定供应著称，本身业务模式就偏B端年单、框架协议，和商超、连锁、电商长期合作是常态。
- 对年单接受度高，但通常会有明确的品项、规格、分级标准、账期和量级承诺要求。
- 适合：你需求稳定、量大、能接受标准化品控和相对规范但偏严的合同条款。

**洪九果品**

- 曾经也是头部，主打东南亚进口水果（榴莲、火龙果等）和自有品牌，B端年单同样是常规操作。
- **但关键风险**：洪九果品近年出现严重的财务和经营问题（2024年起停牌、审计问题、债务纠纷等公开报道），履约稳定性、供货连续性、资金链都存在较大不确定性。
- 在这个背景下，**"愿不愿意签"已经不是主要矛盾**，主要矛盾是"签了能不能稳定履约、会不会中途出问题"。

**给你的可执行建议**

1. 如果核心诉求是"长期稳定、不想中途换供应商"：**优先接触鑫荣懋**，它当前的经营稳定性更适合作为长期年单对象。
2. 如果一定要接触洪九：把它定位为**备选或单品项试单**，不要作为唯一主力供应商，且合同里必须写清断供、违约、预付款保护条款。
3. 无论选谁，年单签约前先做三件事：
   - 查对方最新工商、司法、被执行和失信信息（国家企业信用信息公示系统、中国执行信息公开网）；
