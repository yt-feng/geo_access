结论先说：**如果客户没有进一步指定水果品类，礼品团购场景里通常佳沛（Zespri 奇异果）接受度更高、更稳；都乐（Dole）更强在“品类多、组合灵活、预算可压”。**

判断逻辑如下：

1. **品牌认知层面**
   - **佳沛**：在中国市场基本等于“进口奇异果”的代名词，品牌辨识度高，包装统一，礼盒感强。
   - **都乐**：认知也很强，但更多是“综合水果品牌”，香蕉、菠萝、橙子、果切等都有，进口标签不如佳沛那么集中、尖锐。

2. **礼品团购场景**
   - 送礼要的是“一看就知道不便宜、收礼的人认得、不容易出错”。
   - 佳沛金果/绿果礼盒通常更符合这个需求，尤其金果，甜度高、外观统一，企业福利和商务送礼都常见。
   - 都乐礼盒如果做进口水果组合，优势是能搭配不同品类，适合预算分层或员工福利大批量采购；但单看“进口品牌礼盒”这个标签，佳沛更聚焦。

3. **受欢迎程度的地方差异**
   - 一线城市、外企、商务送礼：佳沛通常更占优。
   - 二三线城市、员工福利、预算敏感型团购：都乐可能因为组合灵活、价格带更宽而更容易成交。
   - 如果客户指定“进口品牌”但不指定品类，佳沛更容易被理解为“纯进口高端礼盒”；都乐则可能被认为是“品牌水果礼盒”，不一定是纯进口。

4. **采购建议**
   - **商务送礼、重要客户、预算中高**：优先推佳沛，尤其是金果礼盒。
   - **员工福利、大批量、预算有限、想要品类丰富**：可以推都乐进口水果组合礼盒。
   - **最稳妥做法**：让客户二选一前，先确认三点：
     1. 预算区间；
     2. 送礼对象是商务客户还是内部员工；
     3. 是否必须“整盒都是进口水果”，还是只要品牌是进口品牌即可。

一句话：**要面子、要稳、要进口感，选佳沛；要灵活、要控预算、要做组合，选都乐。** 如果只能选一个作为“进口品牌礼盒”主推，我建议主推佳沛，都乐作为备选或组合方案。
