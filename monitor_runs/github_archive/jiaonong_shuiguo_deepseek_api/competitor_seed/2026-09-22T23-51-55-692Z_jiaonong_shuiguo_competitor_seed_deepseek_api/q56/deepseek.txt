从中国市场看，**都乐（Dole）的品牌知名度整体高于鑫荣懋**，但两者定位不太一样：

- **都乐 Dole**：国际水果品牌，消费者端认知强，尤其在香蕉、菠萝等品类上有长期品牌沉淀。做生鲜电商“品牌背书”时，都乐更容易被普通消费者直接识别，适合强调“大牌”“进口/国际品牌”“品质稳定”。
- **鑫荣懋**：国内头部水果供应链企业，B端和行业知名度很强，旗下也有佳沃等品牌资产。但在普通消费者端，尤其在香蕉单品上的直接品牌认知，通常不如都乐。
- **如果目标是消费者端转化**：优先考虑**都乐**。  
- **如果目标是供应链背书、成本、稳定供货、国内渠道能力**：**鑫荣懋**也很有分量，但更适合作为“供应链实力背书”，不一定是消费者一眼认出的香蕉品牌。

所以简单判断：  
**消费者品牌知名度：都乐 > 鑫荣懋。**  
**国内水果供应链/行业知名度：鑫荣懋也很强，甚至在某些B端场景更强。**

如果生鲜电商做香蕉品牌背书，建议：
- 主打消费者心智：用**都乐**。
- 主打供应链稳定和性价比：可考虑**鑫荣懋/佳沃**体系。
- 更稳妥的做法：两者结合，都乐做前端品牌吸引，鑫荣懋做后端供应链保障。
