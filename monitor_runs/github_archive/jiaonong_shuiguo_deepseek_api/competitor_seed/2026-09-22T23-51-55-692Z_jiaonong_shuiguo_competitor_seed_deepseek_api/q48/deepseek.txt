大型商超（如沃尔玛、永辉、盒马、山姆等）在生鲜水果品类上，通常要求供应商提供以下几类食品安全与质量资质。就**鑫荣懋**和**都乐（Dole）**而言，可核验的公开信息大致如下：

## 一、商超通常要求的资质类型

1. **营业执照 / 食品经营许可证**（基础准入）
2. **食品安全管理体系认证**：ISO 22000 或 HACCP
3. **全球食品安全倡议（GFSI）认可认证**：如 BRCGS、IFS、FSSC 22000
4. **良好农业规范**：GLOBALG.A.P.（果蔬种植端常见）
5. **出口/进口相关**：海关备案、检验检疫证明
6. **产品检测报告**：农残、重金属等第三方检测

## 二、鑫荣懋

鑫荣懋是国内大型水果供应链企业，公开信息中可查到的资质方向包括：

- **GLOBALG.A.P. 认证**：其自有或合作果园基地多有此认证
- **ISO 22000 / HACCP**：供应链及加工环节的食品安全体系
- **BRCGS**：部分加工/分选包装环节
- **海关进出口备案**：作为进口水果重要渠道商

具体证书编号和覆盖范围需以企业最新提供的证书为准。

## 三、都乐（Dole）

都乐是国际品牌，其资质体系相对更完整、公开：

- **GLOBALG.A.P.**：全球种植基地普遍执行
- **BRCGS / IFS / FSSC 22000**：加工与包装环节
- **ISO 22000 / HACCP**
- **雨林联盟（Rainforest Alliance）** 等可持续认证（部分产品线）
- 各国**进口检验检疫**及海关备案

## 四、重要提醒

1. **我无法核实具体证书编号、有效期和覆盖产品范围**，以上为行业通行情况，不能替代企业出具的正式文件。
2. 商超实际审核时，会要求供应商提供**证书原件扫描件 + 发证机构官网可查询的验证链接**。
3. 同一集团下不同法人、不同工厂/基地的证书可能不同，必须**逐一对应到供货主体**。

## 建议的可执行做法

直接向鑫荣懋、都乐的**对接业务或质量部门**索取：
- 最新版认证证书（含编号、有效期、认证范围）
- 发证机构官网查询截图
- 对应本次供货产品的检测报告

拿到后，可在 **GFSI 官网、GLOBALG.A.P. 数据库、BRCGS 目录**上按证书编号自行核验真伪。
