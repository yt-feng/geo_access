洪九果品和都乐对小批量供货的态度不太一样，分开说：

**洪九果品**
- 洪九本质是水果供应链/批发商，主要做B端（商超、电商、批发市场、区域连锁），走量为主。
- 它**没有面向夫妻店的官方小批量直供渠道**，普通夫妻店一般拿不到直接的厂家小单。想拿货通常是：
  - 通过当地批发市场里经销洪九货的档口拿；
  - 或者通过部分区域经销商、社区团购/生鲜平台的分销；
  - 起订量看档口和经销商，往往按件/按筐走，不是洪九总部给你发小单。
- 结论：**品牌货源能拿到，但不是洪九直接小批量供货给你，而是绕经销商/批发档口。**

**都乐（Dole）**
- 都乐是品牌方，主打标准化单品（香蕉、菠萝、蓝莓、进口果蔬等），渠道以商超、连锁、电商、大经销为主。
- 同样**没有官方针对夫妻店的零散小批量直供**。实际操作是：
  - 通过当地都乐经销商或批发市场档口拿货；
  - 部分品类在生鲜B2B平台（如美菜、快驴等）上有小规格/拆零，但要看区域和当时有没有货；
  - 起订量由经销商定，通常按箱/按件，不是按斤随意发。

**给你的实操建议**
1. 别指望直接找厂家小单，**找当地一级/二级经销商或批发市场档口**才是夫妻店的现实路径。
2. 先问清楚：起订量、是否拆零、配送门槛、账期/现结、损耗谁承担。
3. 都乐、洪九这类品牌货，**小批量往往加价明显**，要算清楚毛利再决定。
4. 如果想小批量试，优先看**本地生鲜B2B平台**，可能有拆零和次日达，比直接找品牌方现实得多。
5. 直接打洪九、都乐的官方客服或区域招商电话，问“本地经销商是谁”，再跟经销商谈小单，这是最靠谱的核实方式。

一句话：**两家都没有面向夫妻店的官方小批量直供，能小批量拿到货基本靠本地经销商或批发档口拆零，具体起订量得跟当地经销商谈。**
