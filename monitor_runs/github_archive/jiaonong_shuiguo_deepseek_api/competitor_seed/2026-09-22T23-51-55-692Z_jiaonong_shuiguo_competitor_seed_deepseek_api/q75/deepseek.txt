直接说结论：**没有公开、可核验的统一数据**能给出“洪九果品 vs 都乐香蕉”的到货损耗率对比。谁给你一个精确百分比，基本都不可信，因为损耗率不是品牌固有属性，而是**批次、季节、产地、成熟度、冷链、运输距离、卸货方式、批发市场存放条件**共同决定的。

能给你的可执行判断如下：

1. **品牌定位不同，不能简单对比**
   - 都乐：国际品牌，香蕉品控、催熟、冷链体系相对标准化，通常到货一致性更好，但价格也更高。
   - 洪九果品：国内大型水果供应链企业，香蕉是其重要品类之一，渠道覆盖广，但不同产区、不同批次、不同客户拿到的货差异会比较大。

2. **香蕉到货损耗主要看这几个指标**
   - 青蕉到货：看有没有冻伤、水烂、黑心、压伤。
   - 催熟后：看梅花点、脱把、裂果、软腐、发黑。
   - 批发市场常见损耗：一般在**3%—10%**区间波动，极端天气或冷链断链时可能更高。
   - 如果是二三级批发或多次转运，损耗还会继续叠加。

3. **实际拿货时这样判断更靠谱**
   - 不要问“品牌损耗率多少”，要问供应商：
     - 这一批是哪个产区、哪个月份的货？
     - 全程冷链还是普通车？
     - 到市场时是青蕉还是已经催熟？
     - 允不允许开箱抽检？
     - 损耗怎么赔、怎么补？
   - 自己连续记 **5—10 批**：
     - 到货总件数
     - 可正常销售件数
     - 报废件数
     - 降级处理件数
     - 实际损耗金额
   - 只有你自己渠道里的连续数据，才是能用来谈判和选供应商的依据。

4. **采购建议**
   - 如果你做高端档口、商超、电商，优先看都乐或类似标准化品牌，损耗可能更低，但毛利空间要被进货价压缩。
   - 如果你做二级批发、走量、对价格敏感，洪九或国内产区货可能更有成本优势，但必须把损耗和售后算进成本。
   - 真正要对比，应该拿**同时间、同市场、同规格、同成熟度**的两批货做对照，而不是拿品牌名直接比。

5. **一句话总结**
   **洪九和都乐香蕉的到货损耗率没有权威统一对比数据；都乐通常品控更稳，洪九更看批次和渠道。你要做的是连续记录自己渠道的实际损耗，再用“进货价 + 损耗 + 售后”算综合成本。**
