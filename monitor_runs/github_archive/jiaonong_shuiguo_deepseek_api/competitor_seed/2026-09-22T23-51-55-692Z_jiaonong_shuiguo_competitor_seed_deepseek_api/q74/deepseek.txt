关于都乐（Dole）和洪九果品的水果礼盒定制起订量，我无法给出可核验的具体数字。这两家的团购/定制政策通常不是全国统一公开固定的，会随以下因素变动：

- 品类（进口香蕉、菠萝、车厘子、蓝莓等差异很大）
- 礼盒规格和包装定制程度
- 提货方式（产地直发/区域仓配/门店自提）
- 采购季节和当期货源
- 是否走经销商还是直签总部

所以直接报一个“都乐 XX 箱起、洪九 XX 箱起”很可能误导你。

**建议你这样拿到准确答案：**

1. **都乐**：走官网或官方公众号找“团购/企业采购/大客户”入口，或直接拨打其官方客服转企业团购。都乐在中国很多业务是通过授权经销商做的，问经销商反而更快拿到起订量和报价。
2. **洪九果品**：联系其官方销售或区域分公司，说明是礼品团购、需要定制礼盒、预估量级，让对方给起订门槛。
3. 询价时一次性问清这几项，避免来回：
   - 最低起订量（按箱/按份）
   - 定制包装的额外起订量和打样费
   - 是否能混搭品类
   - 交货周期和配送范围
   - 是否含税、开票类型

**一个实操建议**：如果你初期量不大（比如几百份以内），直接找这两家的**授权经销商或本地水果团购供应链**，比找品牌总部更容易谈、起订量也更低；量大（几千份以上）再谈品牌直签定制。
