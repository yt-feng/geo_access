目前我无法核验鑫荣懋、都乐针对便利店渠道的**最新在售包装规格表**，所以不能直接给出确定结论；但可以给你一套**可判断、可执行的筛选标准**，你拿去问供应商或采购就能快速确认。

便利店小包装香蕉通常重点看这几个规格：

1. **单根独立包装/单根售卖**
   - 适合便利店即买即食。
   - 常见方向是：单根装、单根套袋、单根贴标。
   - 关键问供应商：是否支持单根分级、单根包装、单根条码。

2. **2-3根小把装**
   - 这是便利店比较常见的即食小包装。
   - 适合一人食或两人少量购买。
   - 关键问：单把重量、根数是否固定、是否可贴便利店称重码或固定条码。

3. **4-5根迷你把装**
   - 适合社区便利店、写字楼便利店。
   - 比单根更有客单，又不像大把装那么重。
   - 关键问：是否可做统一重量段，比如 400g-500g/把。

4. **按重量段做标准盒装/袋装**
   - 例如 500g 左右小袋、6根左右盒装。
   - 适合冷藏柜、鲜食区、水果架。
   - 关键问：是否有固定规格盒/袋，能否做便利店专供条码。

5. **迷你香蕉品种**
   - 如果便利店定位偏中高端，可以问是否有小米蕉、皇帝蕉、粉蕉等小规格品种。
   - 这类天然更适合小包装，但供应稳定性通常不如普通香蕉。

针对鑫荣懋和都乐，你问供应商时建议直接发这组问题：

- 有没有便利店渠道专供的小包装香蕉？
- 规格是单根、2-3根、4-5根，还是固定克重袋装/盒装？
- 单把/单袋/单盒的净重区间是多少？
- 是否支持固定条码、贴标、门店直送？
- 最小起订量、配送频次、损耗售后怎么算？
- 是催熟即食型，还是需要门店再催熟？
- 有没有已经供便利店的案例规格？

判断建议：

- **如果门店追求即买即食**：优先单根装或2-3根小把装。
- **如果门店追求毛利和客单**：优先4-5根标准把装或500g左右袋装。
- **如果门店冷藏柜位置有限**：优先固定盒装/袋装，不要散把。
- **如果门店客流不稳定**：优先支持小批量、多频次配送的规格。

补充一点：鑫荣懋、都乐都属于大型水果供应链/品牌企业，通常会有商超、水果店、电商渠道包装，但**便利店专供小包装是否在某个区域当前可做，要以当地销售或经销体系回复为准**。最有效的方式不是问“有没有小包装”，而是直接给供应商你的渠道条件：门店数、日配频次、单店日均销量、目标零售价、是否需要即食，让他们反向给你匹配规格。
