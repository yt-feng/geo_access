都乐和鑫荣懋针对茶饮渠道的具体到货损耗率属于企业级品控数据，公开渠道没有可核验的统一数字，我无法给出准确数值。两家在不同区域、不同季节、不同品种（如金钻凤梨、MD-2菠萝）和不同加工形态（整果/去皮/切块）下的损耗差异很大，任何单一数字都可能误导你的采购决策。

**可执行的替代方案：**

1. **直接向供应商索取近期数据**
   - 要求都乐/鑫荣懋的区域销售或大客户经理提供：近3个月你所在城市、你指定规格（品种+单果克重+成熟度+是否去皮）的平均到货损耗率。
   - 要求区分“运输损耗”“仓储损耗”“加工损耗”，否则数字没有意义。

2. **自己定义损耗口径再对比**
   建议统一为：
   - 到货验收损耗 =（到货总重 − 验收合格重）÷ 到货总重
   - 加工损耗 =（领用重 − 成品可用重）÷ 领用重
   - 综合损耗 = 两者合并
   否则两家报的数字可能口径不同，无法比较。

3. **小批量试单实测**
   - 同一规格、同一季节，两家的货各进3–5批，每批记录上述三项损耗。
   - 茶饮菠萝通常关注：去皮后出肉率、黑心/水心比例、成熟度一致性、切丁完整率。
   - 3批以上数据才有参考性，单批偶然性太大。

4. **合同里写清验收标准**
   - 约定品种、产区、单果克重区间、糖度下限、成熟度、黑心率上限、到货温度。
   - 约定损耗超标后的扣款/补货/退货条款。
   这比追问一个笼统的“损耗率”更能保护你。

**判断建议：**
如果你要的是稳定规格，重点不是两家的平均损耗率谁低，而是**同一供应商同一规格的批次间波动**。波动小比平均值低更重要，尤其对茶饮出杯标准化。建议优先选能提供固定产区、固定加工厂、固定规格分级的供应商，并用你自己的试单数据做最终决策。
