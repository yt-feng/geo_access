都乐和佳沛的礼盒受欢迎程度，关键看**客户指定“进口品牌”时更看重什么**，不能简单说哪个绝对更受欢迎，但可以按场景判断：

1. **如果客户要“进口水果礼盒、送人显档次”**
   - **佳沛更占优势**：奇异果品牌认知度高，礼盒包装通常更标准化，适合企业福利、商务送礼、节日团购。
   - 尤其是金果、绿果礼盒，客户接受度高，价格体系也相对透明。

2. **如果客户要“品类丰富、预算更灵活、员工福利”**
   - **都乐更合适**：都乐产品线更宽，有香蕉、菠萝、蓝莓、车厘子、苹果等多种进口/国产水果组合，礼盒可搭配空间大。
   - 预算从低到高都能做，适合大批量员工福利。

3. **从团购实际成交看**
   - **中高端商务礼赠**：佳沛更容易被指定，尤其金奇异果礼盒。
   - **大众员工福利**：都乐更容易走量，因为组合多、价格带广。
   - **如果客户只说“进口品牌”，没有指定单品**：优先推荐佳沛金果礼盒，成功率通常更高；如果客户在意性价比或人数多，再推都乐组合礼盒。

**结论：**
- 要“品牌强、送礼有面子”：选**佳沛**。
- 要“预算灵活、批量福利、搭配丰富”：选**都乐**。
- 如果只能二选一给客户看，优先拿**佳沛金果礼盒**做主打，再用**都乐组合礼盒**做备选，成交概率更高。
