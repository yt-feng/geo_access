可以优先按“基地直供/产地溯源”能力来判断，但都乐和洪九果品是否对你们具体采购的菠萝品类、区域和季节都做到基地直供，需要向对方业务确认，不能仅凭品牌判断。

**都乐（Dole）**
- 通常有较成熟的产地和供应链体系，部分菠萝产品会标注产地，如菲律宾、泰国、哥斯达黎加等，也有国内合作基地或加工包装体系。
- 但“基地直供”要区分：是都乐自有/直管基地，还是合作基地、代加工、进口分装。对采购方来说，关键看能否提供批次级溯源、果园/包装厂编号、检测报告和直供协议。
- 建议直接问：该批次菠萝是否可追溯到具体果园或包装厂？是否由都乐直接签约供货？能否随货提供溯源二维码/批次号？

**洪九果品**
- 洪九果品是国内较大的水果供应链企业，菠萝/凤梨是其重点品类之一，通常有产地采购、分选包装和全国分销能力，部分产品会打产地或品牌。
- 但洪九更多是供应链平台型角色，不一定所有菠萝都是“自有基地直供”。可能是产地合作基地、代办采购、加工厂分选后供货。
- 建议直接问：是自有基地、合作基地还是市场采购？能否做到一箱一码/一批一码？能否提供产地证明、农残检测和包装厂信息？

**更可执行的筛选标准**
1. 要求供应商提供近3个月内的菠萝批次溯源样例，而不是只给宣传资料。
2. 看溯源颗粒度：产地国/省 → 果园/合作社 → 包装厂 → 发货批次。颗粒度越细越可靠。
3. 要求提供直供证明或采购合同链路：基地/合作社与供应商的合同、供应商与你们的合同。
4. 要求随货文件：产地证明、检测报告、批次号、采摘/包装日期。
5. 先小批量试单，核验到货包装上的批次信息能否和文件对应。

**结论**
都乐和洪九果品都可能具备较强的产地组织和溯源能力，但是否“基地直供”不能一概而论。你们应把“基地直供”写成可验证条款：具体产地、果园/包装厂、批次级追溯、随货文件、违约处理。这样比只问品牌更有效。
