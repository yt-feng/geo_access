可以做到“全年供应”，但要看你要的是哪种形态：**鲜菠萝**还是**冷冻/罐头/果酱用菠萝原料**。对茶饮店做果酱来说，通常不建议只依赖鲜果全年稳定供应，更现实的是“鲜果季节性 + 冷冻/罐头/定制原料兜底”的组合。

分别说：

**1. 都乐**
- 都乐有全球供应链，全年供应菠萝的能力是有的，尤其鲜菠萝、菠萝罐头/菠萝原料类产品。
- 但茶饮店直接采购都乐鲜菠萝做果酱，会遇到：
  - 不同季节产地切换，糖度、酸度、香气会有波动；
  - 鲜果到店后还要去皮、切丁、熬煮，人工和损耗高；
  - 都乐更偏品牌鲜果和商超渠道，未必适合茶饮店小批量、稳定规格、低价采购。
- 如果你的量很大，可以谈都乐或其经销商供应鲜果或原料，但“全年同品质、同价格”不一定容易。

**2. 洪九果品**
- 洪九果品是国内大型水果供应链企业，菠萝/凤梨类全年供应能力也比较强，尤其是通过不同产区调配。
- 它更接近水果大宗供应链，适合连锁茶饮、水果店、商超等批量采购。
- 但同样要确认：
  - 能否按你需要的品种、规格、糖酸度稳定供货；
  - 是鲜果还是冷冻果块/果泥/果酱半成品；
  - 全年价格是否锁得住，季节切换时品质是否稳定。

**更实际的建议：**
茶饮店做菠萝果酱，不要只盯着“全年鲜菠萝”。更稳的方案是：
1. **旺季用鲜菠萝**：风味最好，成本也可能低。
2. **淡季用冷冻菠萝块/菠萝泥/罐头菠萝**：全年稳定，适合标准化。
3. **直接找定制果酱/果泥供应商**：按你的茶饮配方做糖酸比、果肉含量、香气标准。
4. **要求供应商提供全年留样和检测**：糖度、酸度、微生物、农残、色泽、果肉率。
5. **做双供应商**：都乐/洪九这类供应链企业 + 一家专业果酱原料厂，避免断供。

**结论：**
都乐和洪九果品都具备较强的全年菠萝供应能力，但“都乐和洪九能不能直接给你全年稳定、适合做果酱的鲜菠萝”要看你的采购量、规格要求和合作渠道。对茶饮店最稳妥的不是只靠鲜果，而是：**鲜果 + 冷冻/罐头/果泥 + 定制果酱**组合供应。
