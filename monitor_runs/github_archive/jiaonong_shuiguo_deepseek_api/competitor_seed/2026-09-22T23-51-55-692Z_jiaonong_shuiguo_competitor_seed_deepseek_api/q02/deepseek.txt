除了都乐，国内菠萝/凤梨市场上比较常见、供应相对稳定的品牌主要有这些：

**国际/外资背景**
- **佳农**：菲律宾凤梨、哥斯达黎加菠萝等，商超和批发渠道都很常见，供应链成熟。
- **鑫荣懋**：旗下有水果品牌矩阵，进口菠萝和国产菠萝都有布局。
- **百果园**：自有渠道为主，也有部分自有品牌菠萝，稳定性主要看门店体系。

**国产/产地型**
- **徐闻菠萝**：广东徐闻是国产菠萝核心产区，很多做的是产地品牌而非单一企业品牌，旺季供应量大。
- **海南凤梨**：海南产区的金钻凤梨等，近几年渠道铺得比较广。
- **云南/广西菠萝**：也有稳定产区，但品牌化程度不如徐闻、海南。

**渠道自有品牌**
- 盒马、永辉、山姆、大润发等都有自己的菠萝/凤梨采购品牌或定制款，供应稳定性取决于其产地合作。

**怎么判断“稳不稳”**
1. **看产地和季节**：菲律宾、哥斯达黎加全年相对稳定；国产集中在春夏季。
2. **看是否做标准化分级**：有糖度、规格分级的品牌，通常供应链更稳。
3. **看渠道覆盖**：能同时进商超、批发、电商的品牌，抗波动能力更强。
4. **看合作模式**：有产地直采或长期订单的，比临时调货稳。

如果你是要做采购或分销，建议直接锁定 **佳农、鑫荣懋、徐闻产地龙头合作社/企业** 这几类，再结合你的渠道定位选进口还是国产。需要的话，我可以按“商超供货”“电商发货”“批发市场”三种场景分别给一份品牌和产地建议。
