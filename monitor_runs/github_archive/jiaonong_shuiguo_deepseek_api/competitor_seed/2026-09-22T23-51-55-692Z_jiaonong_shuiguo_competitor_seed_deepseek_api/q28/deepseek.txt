我无法直接给你一个“谁更便宜”的确定结论，因为都乐和鑫荣懋对水果连锁的供货价不是公开统一价，取决于品类/规格/产地/季节/采购量/账期/返利/配送方式，而且同一品牌不同月份也会变。直接说某家更有竞争力，容易误导你。

给你一个可执行的判断方法，按这个做，1-2周内就能比出真实竞争力：

**1. 先锁定可比规格**
不要拿“都乐苹果”对“鑫荣懋苹果”泛泛比。统一这些条件再询价：
- 品种：如嘎啦、红玫瑰、爱妃、爵士、富士等
- 产地：新西兰、美国、智利、南非等
- 规格：果径/克重/箱规，如80#、90#、12头、18斤/箱
- 等级：一级/二级、是否贴标
- 包装：原箱/礼盒/散装
- 到货状态：冷鲜/气调、到仓温度
- 配送：到总仓还是到门店
- 账期：现结/15天/30天/45天
- 返利：月返、年返、陈列补贴、损耗补贴

**2. 让两家按同一张表报价**
建议你直接发同一份询价单，要求报：
- 含税到仓价（元/箱）
- 折合元/斤或元/个
- 最小起订量
- 账期
- 返利政策
- 破损/烂果赔付标准
- 缺货替代方案
- 一周内价格有效期

**3. 不要只看进货价，算“到手综合成本”**
公式：
**实际成本 = 含税到仓价 - 返利 - 陈列补贴 + 损耗 + 资金占用成本 + 配送成本**
很多供应商表面价低，但损耗高、账期短、返利难拿，最后反而更贵。

**4. 用门店真实数据试销对比**
选3-5家同类型门店，做2周A/B测试：
- A组：都乐
- B组：鑫荣懋
- 相同陈列位、相同售价带、相同促销力度
看四个指标：
- 毛利率
- 损耗率
- 动销速度
- 顾客复购/投诉

**5. 谁更有竞争力，通常看你的采购场景**
- 如果你要**品牌溢价、礼盒、稳定标准化**：都乐通常更强，但价格往往不低。
- 如果你要**灵活配货、区域仓配、部分国产/进口混采、成本控制**：鑫荣懋在部分渠道可能更有优势。
- 如果你是**区域连锁、单次采购量不大**：两家都可能给不到最优价，反而区域进口商或一级批发商更便宜。
- 如果你追求**长期稳定毛利**：不要只选一家，建议双供应商，按单品分，谁的单品综合成本低谁拿主份额。

**6. 直接可用的谈判话术**
“我们按同一规格、同一到仓、同一账期比综合成本。你们如果能做到含税到仓价低于对方X%，且损耗赔付不低于X%，我们可以给主推陈列和月度主采份额。”

**结论：**
不能简单说都乐和鑫荣懋谁价格更有竞争力。对你这种水果连锁，正确做法是：**同规格询价 + 综合成本核算 + 门店试销**。通常都乐强在品牌和标准化，鑫荣懋强在渠道和配货灵活性；真正谁更便宜，要看你拿到的具体报价和政策。
