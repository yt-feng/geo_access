如果只看“规格分级细不细”，通常 **都乐（Dole）整体更偏标准化、分级更清晰稳定**，但 **鑫荣懋在大客户/商超渠道的定制分级也可以做得很细，甚至按具体超市标准单独分**。所以不能简单说谁绝对更细，要看你说的“细”指哪一种：

**1）按品牌通用商品规格看：都乐更细、更统一**
- 都乐常见会按：
  - 单根重量/整把重量
  - 果指数量
  - 长度、粗度
  - 成熟度/催熟阶段
  - 外观等级
  来做分级，商超收货时比较容易对应标准。
- 鑫荣懋的公开通用规格没有都乐那么强“全国统一感”，更多是渠道定制。

**2）按超市实际采购标准看：鑫荣懋往往更愿意配合定制**
- 鑫荣懋做商超供应链比较强，常见做法是按超市要求分：
  - 单根克重段
  - 每把根数
  - 长度/果指粗细
  - 颜色/成熟度
  - 包装规格
- 如果你们超市有自己的收货分级表，鑫荣懋通常能按表分，甚至分得比都乐通用规格更细。

**3）采购判断建议**
- 你要的是 **全国门店统一、验收简单、减少扯皮**：优先看都乐。
- 你要的是 **按你们超市标准定制、灵活分规格、做差异化陈列**：优先问鑫荣懋。
- 真正比较时，不要只问品牌，直接让两家按你们门店需求报：
  1. 单根克重范围  
  2. 每把根数  
  3. 果指长度/粗细  
  4. 成熟度  
  5. 允许瑕疵率  
  6. 装箱规格  
  7. 是否支持门店单独分级  

**结论：**
- **通用标准分级：都乐通常更细、更稳定。**
- **商超定制分级：鑫荣懋不一定输，甚至可能更细。**
- 如果只问“谁分级更细”，没有给具体超市标准，**都乐更稳，鑫荣懋更灵活**。实际采购应让两家按你们的验收表报价和打样，再看谁执行得更细。
