大型商超对供应商的食品安全体系要求，通常集中在 **GFSI 认可的食品安全认证**、**产品/体系认证**和**可追溯能力**上。就鑫荣懋和都乐而言，可公开核实的情况如下：

**都乐**
都乐是跨国果蔬企业，其供应链和加工环节通常涉及以下认证：
- **GLOBALG.A.P.**：农业种植环节的全球良好农业规范认证，常见于其自有或合作果园。
- **BRCGS**：包装/加工环节的食品安全全球标准认证，常见于其加工厂。
- **ISO 22000 / HACCP**：部分加工和配送环节的食品安全管理体系认证。
- **有机认证**：针对有机产品线，如 USDA Organic、EU Organic 等。

**鑫荣懋**
鑫荣懋是国内大型水果供应链企业，公开信息中常涉及：
- **ISO 22000** 食品安全管理体系认证。
- **HACCP** 危害分析与关键控制点体系认证。
- **GLOBALG.A.P.**：其部分合作基地或自有基地会做该认证。
- **BRCGS**：部分加工/分选包装环节可能持有。
- **有机产品认证**：针对有机水果品类。

**需要提醒的是：**
具体到某一工厂、某一品类、某一批次，认证范围可能不同。大型商超审核时，看的不是企业“有没有证”，而是：
1. 认证证书是否在有效期内；
2. 认证范围是否覆盖该商超采购的具体产品和生产场所；
3. 是否有对应的审核报告、整改记录和可追溯记录。

如果你需要用于供应商准入判断，建议直接向对方索要 **认证证书扫描件 + 认证范围 + 最近一次审核报告**，再对照商超自己的《供应商食品安全准入标准》逐项核对。
