如果你说的是**按“外观规格/等级标准”分得细不细**，通常 **都乐（Dole）更细、更标准化**，但**鑫荣懋在国内渠道的实际到货分级也可能很细，尤其是给商超做定制时**。两者不是同一种“细”。

可以这样判断：

1. **都乐**
   - 强项是**全球品牌化、标准化分级**。
   - 常见会按：  
     - 长度/果指粗细  
     - 每箱把数、每把根数  
     - 单果重量区间  
     - 成熟度/催熟阶段  
     - 外观缺陷等级  
   - 对商超来说，都乐的优势是**规格稳定、可预期、包装标识清楚**，适合直接做货架分级。
   - 但都乐不一定在国内每个渠道都开放很细的等级给你选，更多是它自己的商品化标准。

2. **鑫荣懋**
   - 强项是**国内供应链和渠道定制**。
   - 如果你们是超市采购，鑫荣懋往往可以按你的需求做：  
     - 不同长度段  
     - 不同单果重  
     - 不同成熟度  
     - 不同包装规格  
     - 不同门店业态分档  
   - 也就是说，**它可能不是公开等级最多，但可谈的定制分级可以很细**。
   - 缺点是不同产地、不同批次、不同区域仓，标准一致性可能不如都乐稳定。

3. **结论**
   - 要**现成标准细、标识统一、跨批次稳定**：选 **都乐** 更稳。
   - 要**按超市自身货架和价格带做定制分级**：找 **鑫荣懋** 往往更灵活。
   - 如果只问“哪家分级更细”这个笼统问题：  
     **公开商品标准看，都乐更细；实际商超定制看，鑫荣懋可以做到很细，甚至更贴合你的需求。**

4. **采购建议**
   你直接让两家各发一份**香蕉规格书**，重点对比这 6 项：
   - 单果重量区间
   - 果指长度区间
   - 每箱净重
   - 每箱把数/每把根数
   - 成熟度到店标准
   - 允许缺陷率和次品处理

   谁能把这 6 项写清楚、并能稳定按批次交付，谁的分级对你就更“细”。
