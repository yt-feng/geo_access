都乐和鑫荣懋的进口苹果产地溯源，核心是“看包装标识 + 查官方单证 + 扫码验证 + 向供应商索证”四步。超市采购要把这四步变成可执行的验收动作，否则只靠果箱上的英文产地字样不够。

**一、先分清两家公司的溯源体系差异**

- **都乐**：全球化品牌，进口苹果多来自新西兰、美国、智利、南非等。包装上通常有都乐全球统一的批次码/追溯码，部分产品支持扫码查看果园、包装厂、出口批次信息。但国内销售的都乐产品，溯源信息颗粒度取决于其中国公司或授权进口商是否接入。
- **鑫荣懋**：国内头部水果供应链企业，代理和自营进口水果较多，包括新西兰、智利、美国等产区的苹果。其溯源更多依赖进口报关单、检疫证书和自有批次管理系统，终端包装上不一定有面向消费者的独立追溯码。

**二、采购验收时必须索要的四类单证**

1. **入境货物检验检疫证明**：这是进口水果合法入境的核心凭证。上面会列明品名、产地国、生产/加工企业、入境口岸、数量、批号。要核对证书上的产地国、品种、批次与实际到货是否一致。
2. **海关进口货物报关单**：核对收货人、进口日期、原产国、商品编码、数量。报关单上的原产国必须与包装标注一致。
3. **原产地证书**：由出口国官方或授权机构出具，证明苹果的原产国。部分协定税率国家还需要优惠原产地证。
4. **供应商资质与批次台账**：都乐或鑫荣懋的经销授权、供货合同、本批次出货单。要求供应商提供“批次—单证—门店”的对应关系。

**三、包装和标签的现场核验点**

- 原产国英文/中文标识是否与单证一致，例如 New Zealand、USA、Chile。
- 品种、规格、净重、包装厂编号、出口商名称是否清晰。
- 是否有都乐或鑫荣懋的品牌标识、批次码、生产日期/包装日期。
- 中文标签是否载明境内进口商或经销商名称、地址、联系方式。预包装进口水果必须有符合中国要求的中文标签。
- 如果包装只有“进口苹果”而没有具体原产国，不能通过验收。

**四、扫码和系统验证怎么做**

- 都乐产品：扫包装上的二维码或追溯码，看是否能跳转到都乐官方或授权追溯页面，显示果园、包装厂、出口批次、检测信息。若扫码只跳到电商页面或无信息，不能作为溯源依据。
- 鑫荣懋产品：询问其业务员是否提供批次追溯查询入口或系统账号。大型超市可要求对接其供应链系统，按批次调取报关、检疫、物流信息。
- 门店端可建立台账：记录到货日期、供应商、批次号、检疫证号、报关单号、原产国、数量。做到“一批一档”。

**五、给超市的落地建议**

1. 把“入境货物检验检疫证明 + 报关单 + 原产地证”列为进口苹果收货必备，缺一不可。
2. 要求都乐/鑫荣懋供应商在送货单上注明批次号，并与单证批号对应。
3. 对高单价或礼盒装苹果，抽检扫码验证，留存截图或照片。
4. 每季度复核供应商资质，包括其进口商备案、授权链是否完整。
5. 如果供应商只能提供复印件，要求加盖公章并核对原件；关键单证可向海关或市场监管部门核验。

**关键判断标准**：包装原产国、检疫证原产国、报关单原产国、原产地证四者一致，且批次能对应到具体送货单，才算完成可追溯。任何一项对不上，就应暂缓收货并要求供应商补充证明。
