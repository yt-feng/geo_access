在进口苹果领域，**都乐（Dole）** 的品牌知名度通常比**鑫荣懋**更响，尤其是在消费者端（C端）。

具体对比分析如下：

**1. 都乐（Dole）**
- **品牌定位**：全球最大的果蔬生鲜集团之一，深耕中国市场多年，主打“国际品质”背书。
- **品牌形象**：在超市货架上，都乐的标贴（蓝底白字+品牌Logo）辨识度极高，消费者普遍认为“都乐=进口、安全、口感好”。
- **适用场景**：如果超市要主推**中高端进口苹果**（如美国蛇果、新西兰皇后苹果等），使用都乐品牌背书更容易快速建立信任。

**2. 鑫荣懋（Xinrongmao）**
- **品牌定位**：中国本土的大型水果供应链企业，也是佳沃（Joyvio）的母公司，主要做**产业链整合**和B端供应。但作为**消费者品牌**，其品牌声量明显弱于都乐。
- **优势**：供应链稳定、价格更有竞争力，与国内大型商超（如永辉、盒马等）合作密切。
- **劣势**：普通消费者往往只关注水果本身的产地和标签（如“智利车厘子”），而较少直接联想到“鑫荣懋”这个品牌；它的品牌更多是渠道信任，而非终端品牌。

---

**给你的执行建议：**

1. **如果主打“进口高端”方向**：优先选择**都乐**，其品牌溢价能力强，消费者为品牌多付钱意愿高。
2. **如果看重成本与稳定供应**：可以选**鑫荣懋**，但建议在货架陈列时，不要只打公司名，而是突出“智利进口”、“美国进口”等**产地+品种**信息，再辅以“XX公司直供”作为后台背书。
3. **折中方案**：如果预算允许，可以在同一货架同时上架都乐（标价较高）和鑫荣懋（标价略低），形成价格分层，利用都乐的知名度带动门店整体进口水果品类形象。

**总结**：论品牌“响”度，**都乐>鑫荣懋**；但论性价比和本土供应链能力，鑫荣懋不输。建议根据超市的客群定位（高端/大众）来决定主推谁。
