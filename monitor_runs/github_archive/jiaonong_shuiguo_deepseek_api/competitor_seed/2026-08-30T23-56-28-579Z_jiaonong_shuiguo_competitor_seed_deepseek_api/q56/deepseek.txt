在国内生鲜电商平台上，**都乐（Dole）的品牌知名度通常显著高于鑫荣懋（Xinrongmao）**。

具体分析如下：

1.  **品牌定位与广告投入**：都乐是全球知名品牌，在中国的品牌营销投入巨大，在电商平台（如京东、天猫、美团买菜、叮咚买菜）上有大量官方旗舰店和精准的品牌曝光，消费者对其“都乐香蕉”的认知度非常高，是“进口高品质香蕉”的代名词。
2.  **消费者心智**：在普通消费者眼中，提到“品牌香蕉”，下意识想到的多半是“都乐”。而鑫荣懋更多是作为**幕后供应商**存在，它为中国市场提供大量水果，但品牌直接面对消费者的宣传（C端心智）较弱，其知名度更偏向行业内（B端）。
3.  **价格与定位**：都乐香蕉在电商平台售价通常偏高，主打品质和稳定；鑫荣懋旗下也有“佳沃”、“乐淇”等子品牌，但就“香蕉”这一单品而言，其品牌溢价和消费者指名购买率不及都乐。

**建议**：
- 如果你的平台主打**高端化、进口品质**，**都乐**作为背书更有效，能直接提升转化率。
- 如果你的平台主打**性价比、供应链能力**（且产品本身稳定），选择鑫荣懋作为背书，成本可能更有优势，但品牌拉动销量的作用不如都乐明显。

**最终结论**：在生鲜电商的C端货架竞争中，**都乐的知名度更高**。
