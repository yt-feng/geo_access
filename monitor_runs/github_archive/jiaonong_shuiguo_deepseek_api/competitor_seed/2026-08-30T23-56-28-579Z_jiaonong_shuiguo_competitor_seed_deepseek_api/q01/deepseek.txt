关于鑫荣懋和都乐的供货稳定性，我无法提供实时的合同履约数据或内部运营信息，但可以基于公开行业信息给你一些判断维度和参考建议：

**1. 两家公司的背景与市场地位：**
- **鑫荣懋**：国内大型水果企业，深耕中国市场，渠道覆盖广，对国内商超和批发市场的响应速度通常较快。其优势在于本土化服务和对国内市场的理解。
- **都乐（Dole）**：国际知名品牌，全球供应链体系成熟，尤其在菲律宾、厄瓜多尔等产地的香蕉种植和品控上有长期积累。其优势在于源头基地稳定性和标准化程度高。

**2. 判断“稳定”的关键因素（建议直接向对方索要以下信息）：**
- **产地与合同保障**：询问其进口产地（如菲律宾、厄瓜多尔）是否有多地备选方案，以应对产地天气、罢工或海运问题。要求提供长期合同框架（如季度/年度锁价或保量协议）。
- **冷链与损耗率**：进口香蕉对冷链要求极高。要求对方提供近6个月的到货损耗率数据（行业中正常范围通常在3%-5%以内），并明确断货赔付条款。
- **库存与铺货能力**：若你的超市有跨区门店，需确认对方在不同港口（如上海、广州、大连）是否有独立仓储，能否保证分批到货。
- **应急响应**：明确节假日或促销季的加单流程（通常需要提前7-14天确认），以及船期延误时的替代方案。

**3. 实操建议：**
- **小批量试单**：不要直接签长期大合同，先以2-4周的小批量试单测试两家的到货准时率、香蕉催熟度（一般要求绿熟果肉比在70%-80%）和售后处理时效。
- **要求第三方背书**：请对方提供目前在合作的大型商超（如永辉、盒马、沃尔玛）的案例，甚至可实地考察其主要港口周转仓。
- **成本对比**：注意都乐作为品牌商，价格通常偏高5%-10%；鑫荣懋作为渠道商，价格可能更灵活，但需确认其是否有时依赖临时采购买手，影响货源稳定。

**最后提醒：** 没有绝对的“谁更稳定”，关键取决于你的采购量级和所在区域。建议优先选择**在当地有分仓、且能提供书面保供条款**的一方。若你计划年采购量超过500吨，可要求双方提供驻场品控服务。
