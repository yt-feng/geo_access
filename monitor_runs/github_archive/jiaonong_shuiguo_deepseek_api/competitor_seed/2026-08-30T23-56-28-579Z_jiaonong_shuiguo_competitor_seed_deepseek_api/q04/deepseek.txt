关于进口香蕉品牌，佳沛（Zespri）确实以奇异果为主，香蕉业务并非其强项。如果您需要进口香蕉，可以考虑以下几个知名品牌（主要来自菲律宾、厄瓜多尔、哥伦比亚等产区），它们在国内市场流通较广，品质稳定：

1. **都乐（Dole）**  
   - 全球最大的果蔬生鲜集团之一，香蕉是其核心产品线。在中国市场有完整的冷链和分销体系，果肉软糯、甜度高，常见于商超和精品水果店。

2. **怡颗莓（Driscoll's）**  
   - 虽然以浆果闻名，但其香蕉业务在亚太地区也有布局，主打高端进口路线，果型饱满、成熟度控制好。

3. **金吉达（Chiquita）**  
   - 历史悠久的美国香蕉品牌，主产自中南美洲，特点是皮薄肉细、香气浓郁。国内部分进口超市（如Ole'、盒马鲜生）有售。

4. **佳农（Goodfarmer）**  
   - 国内老牌进口水果商，代理菲律宾、厄瓜多尔等地的香蕉，性价比高，供应链稳定，适合批发或批量采购。

5. **绿巨人（Green Giant）**  
   - 旗下有进口香蕉业务，主打非转基因和可追溯种植，适合注重健康标签的客户。

**选择建议**：  
- 如果追求**高端商超渠道**，优先考虑都乐或怡颗莓；  
- 如果注重**价格竞争力**，佳农或金吉达的常规规格更合适；  
- 注意查看产品标签上的**产地和品种**（如“大麦克”“卡文迪什”），不同批次甜度可能有差异。

另外，建议您直接联系本地一级批发市场的水果进口商，他们通常能提供试吃样品，并告知当前批次的实际口感。如果您的业务有特定需求（如有机认证、催熟周期），务必在采购前明确说明。
