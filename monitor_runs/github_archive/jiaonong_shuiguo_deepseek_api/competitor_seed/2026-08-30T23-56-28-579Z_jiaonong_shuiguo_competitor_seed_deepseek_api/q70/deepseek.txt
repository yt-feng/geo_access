关于香蕉供应商的产地溯源和品控证明，我来为你分析一下：

---

**都乐（Dole）**  
- 是国际知名果蔬企业，旗下香蕉产品以菲律宾、厄瓜多尔、哥斯达黎加等产地为主。  
- 都乐在行业内较早推行**全程冷链+溯源体系**，其包装上通常标有产地、批次号、采摘日期等信息。  
- 面向B端客户（如商超、餐饮渠道），都乐可以提供**批次检测报告**（如农药残留、重金属等），并可配合提供产地证明文件。  
- 但注意：具体能否提供“实时可扫码的农户级溯源”，需要和供应商区域销售确认，因为不同市场/渠道执行力度有差异。

**鑫荣懋（Joyvio，原佳沃鑫荣懋）**  
- 是国内头部水果供应链企业，香蕉业务主要对接东南亚（越南、菲律宾）及国内海南、广西基地。  
- 鑫荣懋已建立**数字化水果追溯平台**，对B端客户通常可以提供**产地证明、加工包装地点、入库质检报告**等。  
- 部分大客户可申请到**批次溯源二维码**，扫码可看到果品来源、加工厂、检测结果。  
- 同样，具体“品控证明”的详细程度，取决于合作规模和采购形式（如代采、贴牌、直供）。

---

**给你的实操建议：**
1. **直接联系对方销售/大客户部**，明确要求提供：产地证明（如原产地证）、批次检测报告（农残/重金属）、品控流程说明（如GLOBALG.A.P.、HACCP认证）。  
2. 问清楚是否支持**扫码溯源**（比如包装箱贴码），以及能否覆盖到**果园或农户级别**。  
3. 如果是大批量采购，可要求样本验货，并在合同里写明“不满足品控要求可以拒收/退货”条款。  
4. 如果两家无法同时满足，也可考虑**佳农（Goodfarmer）、百果园（B端）、诚实果品**等，它们也有成熟的溯源体系。
