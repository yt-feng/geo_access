除了都乐（Dole）和佳沛（Zespri），以下是几个在礼品团购市场口碑较好、品质稳定、适合礼盒装的进口水果品牌，供您参考：

1. **新奇士（Sunkist）**  
   - 美国品牌，主打橙子、柠檬、葡萄柚等柑橘类水果。  
   - 礼盒包装精美，果径均匀，适合高端商务礼品。

2. **爱妃（Envy）**  
   - 新西兰品牌，品种为爱妃苹果（俗称“太平洋玫瑰”），果肉紧密、甜度高，耐储存。  
   - 礼盒规格多样，常用于公司福利或节日礼品。

3. **怡颗莓（Driscoll's）**  
   - 美国品牌，以蓝莓、树莓、草莓为主，新鲜度高，果粒饱满。  
   - 适合短期礼盒（需冷链），适合高端水果篮搭配。

4. **乐淇（Rockit）**  
   - 新西兰品牌，主打迷你苹果，单果大小统一，带专属筒装/盒装，便携且颜值高，适合年轻客户或伴手礼。

5. **蜜尔（Melville）或 南非蜜橘类品牌**（如Clemengold）  
   - 如果是柑橘类，南非蜜橘（如ClemenGold）甜度高、无籽，礼盒装常用于中秋或春节档。

6. **泰国椰青/椰皇品牌**（如Koh Coconut）  
   - 如果礼品偏热带水果，椰青礼盒（带开椰器）近年流行，但需注意保质期和运输。

---

**给您的建议：**  
- 如果是**高端商务送礼**，优先选新奇士或爱妃；  
- 如果是**年轻化或创意礼盒**，乐淇苹果或怡颗莓浆果更吸睛；  
- 团购前务必确认**品牌授权证书**和**水果到货新鲜度**，进口品牌对冷链要求高，提前和供应商约定质检标准。
