1. **洪九果品**：主营进口水果和国内高端果品，香蕉以进口（如菲律宾、厄瓜多尔）和国产优质产区的货为主。品控上通常有分级标准，但损耗率与运输距离、冷链管理、终端仓储条件强相关。总体在行业内属于中上水平，但具体到货损耗需要看批次和物流环节。

2. **鑫荣懋**：国内大型水果供应链企业，香蕉业务覆盖进口和国产，供应链体系成熟，尤其是冷链物流和分仓管理较规范。在规模化操作下，到货损耗通常控制得较好，尤其对商超渠道的配送经验丰富。
