关于菠萝到货损耗率，**行业没有统一标准**，实际数值取决于采购季节、运输距离、冷链条件以及具体批次，不能一概而论。

不过，根据茶饮行业的实际采购经验，我可以给你一个**参考区间**（以到货后24小时内、常温或冷链状态下验收为准）：

- **都乐（Dole）**：作为老牌进口品牌，其菠萝（多有菲律宾或哥斯达黎加产）通常经过严格分选，果型规整，表皮完好率较高。如果走**冷链干线**，常温短驳，正常到货损耗率一般在 **3%-6%** 之间。如果遇到台风季或海运长时间滞留，损耗可能接近8%。
- **鑫荣懋（Xinrongmao）**：作为国内大型水果供应链企业，鑫荣懋自营基地或国内产菠萝（如徐闻、海南）到货损耗率通常更低，预计在 **2%-5%**。因为国内运输半径短，且其通常有更高的周转率，压果风险小。

**给你的实操建议（更可靠）：**

1. **不要只看品牌，要约定合同条款**：在采购合同或采购单中，明确写明“到货损耗率”的验收标准（例如：超过5%的部分由供应商承担扣减），同时约定**表皮碰伤、发霉、内部褐变**的判定标准。
2. **要求到场抽样**：每次到货时，开箱随机抽3-5箱，称重并计算“坏果/软化果/明显失水”的重量占比，记录在《验收单》上。连续记录10次，你就能得出针对你所在城市、特定季节的真实损耗率。
3. **注意菠萝的特殊性**：菠萝的损耗主要来源于**果柄发霉**和**表皮碰撞压伤**（内部往往完好），在验收时不要只看外观，要按压检查果肉硬度。

**结论：** 如果你要定规格（如单果重1.2-1.5kg），建议先按**5%**做库存预留，并要求供应商提供批次质检报告。实测一两周后，再要求供应商针对损耗率做出价格或赔付调整。
