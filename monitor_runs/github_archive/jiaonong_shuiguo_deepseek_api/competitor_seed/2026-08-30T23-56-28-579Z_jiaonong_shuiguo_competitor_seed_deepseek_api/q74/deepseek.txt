关于**都乐（Dole）**和**洪九果品**的礼品团购水果礼盒起订量，**没有统一标准**，通常由以下因素决定，且**需要直接联系当地经销商或大客户经理获取确切数字**。

根据行业通行的做法，你可以参考以下信息：

### 1. 起订量的普遍规则（非官方，供参考）
- **都乐（Dole）**：
  - 作为跨国品牌，他们的**经销商体系**和**大客户（B2B）部门**通常有明确门槛。
  - 一般**礼盒定制**（如加印Logo、礼盒包装）的起订量通常在 **50-100盒** 左右，或者按**箱**（如整箱采购，通常5-10箱起）。
  - 如果仅是**团购整箱（不带定制）**，起订量可能更低，如10箱起。
- **洪九果品**：
  - 以批发、供应链见长，渠道很灵活。
  - 普通团购可能**一箱（3-5公斤）起可谈**，但**礼盒定制**（如加印品牌、节日款包装）通常起订量在 **30-50盒** 或 **10箱** 以上。
  - 如果是高端进口水果（如车厘子、晴王葡萄），起订量可能按**托盘级**（几百箱）来计算，但通常有单独供应链负责人。

### 2. 影响起订量的关键因素
- **定制程度**：是否需要印企业Logo、改礼盒设计？定制程度越高，起订量通常越大。
- **水果品类与时令**：如季节性水果（荔枝、大闸蟹配水果）可能起订更灵活。
- **供货区域**：你是哪个城市？一线城市起订量可能更低，二线以下城市起订量可能偏高。
- **交付日期与冷链**：是否需要冷链专车，会影响他们设置最低订单金额。

### 3. 如何快速获取准确数字（可执行建议）
- **直接电话**：搜索“都乐 城市名 经销商”或“洪九 城市名 大客户”，直接致电，告知“企业团购，预计采购XX盒，需要定制礼盒”，立刻获得报价和起订口径。
- **电商线索**：在天猫/京东的旗舰店客服处留资，他们会转给线下大客户团队。
- **参考竞品**：同时询价“佳沃、本来生活、京东京鲜生”等，对比起订门槛，便于压价。

### 4. 一个提醒
- 价格**不透明**，起订量是**谈判结果**。你可以在询价时明确说“我们是长期礼品采购，首批测试下单50盒，看能否给到最优惠价和最低起订量”，大概率能谈到更低门槛。

**结论**：**无法给出固定数字**，但按行规，**礼盒定制类起订量通常在50-100盒**，普通团购可能10-30盒即可启动。建议拿你的具体数量和城市去电话谈，2小时内能得到明确答案。
