**洪九果品：**
洪九果品在水果产业链上游布局较深，尤其是在东南亚（如越南、泰国）和国内云南、海南等热带水果产区有较强优势。其模式更多是“端到端”直采，即直接与产地果园或合作社合作，并自建分拣加工中心。在香蕉方面，洪九在越南、老挝等国家有稳定的采购渠道和合作基地，国内则在云南、广西有布局。但需要注意，洪九的基地更多是“合作基地”或“包销基地”，而非完全自有的种植园。

**鑫荣懋：**
鑫荣懋（佳沃鑫荣懋）是国内头部水果供应链企业，其优势在于全球采购网络和国内分销体系。在香蕉方面，鑫荣懋在南美（厄瓜多尔等）、菲律宾、东南亚有成熟的进口渠道，同时在国内云南、海南、广东有自建或合作基地。鑫荣懋更偏向于“买手制”+“基地合作”，其昆明等地的基地主要用于分选和包装，而非大规模种植。
