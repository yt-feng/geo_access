您提到的**都乐（Dole）**和**洪九果品**都是大型水果企业，他们确实会有内部的企业标准，用于果蔬分级，但由于这类标准通常是**商业机密**，一般不公开全文，只有内部采购、品控部门掌握。

**关于都乐（Dole）：**
都乐作为国际品牌，采用的是全球统一的质量标准体系。其香蕉分级主要参考国际通行做法（如联合国欧洲经济委员会UNECE标准），并结合自身品牌定位，侧重于：
- **果长**（如18-22厘米以上为特级）
- **果径**（粗度等级）
- **成熟度**（以色卡级数为准，如从3级到7级）
- **外观瑕疵**（黑斑、伤痕、擦伤等）
- **果柄完整性**（是否预留2-3厘米手柄）
都乐在零售端通常售卖“帝王蕉”或“特级蕉”，等级高于普通市场标准，但具体分几个等级、每级阈值，属于内部文件。

**关于洪九果品：**
洪九果品（重庆洪九果品股份有限公司）作为国内头部水果供应链企业，其香蕉分级标准与产地（如菲律宾、厄瓜多尔、缅甸）和下游渠道（盒马、永辉等商超订单）深度绑定，会有不同客户定制化等级。其标准侧重：
- **单梳重量**（每把5-8公斤等）
- **梳数**（每箱约8-12梳）
- **果指数量**（每梳12-18根）
- **新鲜度**（青果/熟果比例）
同样，该标准未对外公开发布。

**建议获取方式：**
如果您是采购方或合作商，可通过以下渠道获取权威分级依据：
1. **国家标准**：目前中国有《GB/T 15864-2014 香蕉》国家标准，这是公开的强制/推荐性标准，明确了香蕉的感官指标、理化指标和等级划分（优等品、一等品、二等品），可作为通用参考。
2. **行业标准**：农业农村部发布的《NY/T 1395-2007 香蕉等级规格》也是公开的。
3. **直接咨询企业**：如果您有合作意向，可以向采购部索取其“品控规格书”或“验收标准”，一般合作谈判时会提供。

**结论：** 这两家企业都有各自的企业标准，但不公开。您若需要具体数值，最可靠的是依据国标/行标，或在实际业务对接中要求对方提供分级细则。
