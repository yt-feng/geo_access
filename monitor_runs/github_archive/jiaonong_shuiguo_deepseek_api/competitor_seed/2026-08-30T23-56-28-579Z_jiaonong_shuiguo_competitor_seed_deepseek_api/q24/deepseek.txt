关于鑫荣懋（Xinrongmao）和都乐（Dole）在香蕉规格分级上的细致程度，**目前没有公开的、统一的行业标准来比较**。这两家公司的分级体系属于企业内部标准，可能随市场区域、销售渠道（如商超、电商、批发）不同而异。

不过，根据行业公开信息和常见做法，可以给出以下判断参考：

1. **都乐（Dole）**：作为国际香蕉巨头，其分级体系通常更严格、更标准化。都乐在亚洲市场主要针对高端商超和精品水果店，其规格分级通常细化到**果指长度（如17cm、19cm、22cm）、果径（如按周长或宽度）、成熟度（绿熟、半熟、黄熟）、以及外观缺陷（如擦伤、斑点）**。其分级系统更偏向于国际通行的贸易标准，如按“手”（即一把）和“指”（单根）来划分，且对瑕疵率有明确容忍度。

2. **鑫荣懋**：作为国内头部水果供应链企业，其分级也较为细致，但更多结合**国内消费者偏好和商超货架要求**。通常分为特级、一级、二级，重点区分果形、色泽、单果重（如每箱净重），并关注是否带柄、有无激素嫩皮等。在电商渠道和社区团购中，其分级可能更为简化（如按大小尺寸直接标注）。

3. **实际差异**：如果以“颗粒度”来比，**都乐在专业贸易和高端零售领域的分级更细、更严格**，因为其要满足全球不同市场的合同要求。而**鑫荣懋在产品分级上强调实用性和性价比**，对果指的尺寸区间划分可能相对宽泛（例如以2cm为一个等级，而都乐可能以1cm为一个等级）。

**建议**：如果您需要采购并做规格分级，建议不要仅依赖品牌名称，而是：
- 直接向两家供应商索取其**书面规格书或产品标准表**，具体看果指长度、直径、单箱净重、允许的水锈或挤压伤比例等参数。
- 询问其是否提供**定制化分级**（例如按您要求的单果重量或成熟度天数）。

如果您是消费者，想要知道哪个品牌的分级更“细”，更实用的是看**购买时商品标签上的分级说明**——都乐通常标注“特级”“一级”及果指长度，鑫荣懋通常以“超大”“大”等口语化分类，购买时以实物为准。
