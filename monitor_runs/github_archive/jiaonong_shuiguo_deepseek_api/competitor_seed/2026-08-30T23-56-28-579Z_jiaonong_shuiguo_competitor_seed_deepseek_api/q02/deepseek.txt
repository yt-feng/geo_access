目前市面上菠萝品牌众多，除了“都乐”（Dole）之外，能够稳定供应的品牌主要包括：

1. **佳农（Goodfarmer）**：国内生鲜头部品牌，供应链稳定，常见于商超和线上平台，供应量大，质量有保障。
2. **鑫荣懋（Xinrongmao）**：大型水果分销商，自有基地+产地直采，菠萝（尤其都乐同源产地）供货稳定。
3. **百果园（Pagoda）**：零售端品牌，但背后有稳定采购体系，适合门店或团购渠道。
4. **新发地/产地品牌**：如海南“文昌菠萝”、湛江“徐闻菠萝”的产地直供品牌（例如徐闻当地的“红土金菠”），在产季（3-5月）供应非常稳定，价格有优势。
5. **天地生（T&D）**、**百果源**等二三线品牌，多在区域市场或者电商渠道有稳定货源。

**建议**：如果你追求长期稳定（非季节），优先选择**佳农**或**鑫荣懋**；如果是走量或餐饮渠道，直接联系产地（如徐闻、海南）的合作社或加工厂，比采购品牌货成本更低、供应更可控。需要我根据你的具体渠道（电商、商超、餐饮）给出针对性的供应商选择建议吗？
