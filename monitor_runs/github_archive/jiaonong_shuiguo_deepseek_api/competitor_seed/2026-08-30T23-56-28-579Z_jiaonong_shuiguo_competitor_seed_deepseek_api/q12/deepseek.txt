针对便利店渠道的小包装香蕉需求，**鑫荣懋**和**都乐**都有适配的规格，但侧重点略有不同。以下是具体信息和建议：

### 1. 鑫荣懋
- **常见规格**：
  - **小包装（约500g-800g）**：通常为2-3根装，适合即食或单人消费。
  - **迷你装**：部分渠道会供应单根独立包装（约150g-200g），适合便利店抓取购买。
- **渠道适配**：鑫荣懋在商超和便利店渠道铺货较广，尤其与罗森、全家等有合作，建议直接咨询当地经销商确认具体SKU。

### 2. 都乐
- **常见规格**：
  - **小盒装（约4-5根，600g-1kg）**：适合家庭或多次购买。
  - **独立小包装**：针对便利店，都乐也提供单根或双根装（约200g-400g），强调“即开即食”。
- **渠道特点**：都乐在华东、华南便利店渗透率高，且常与鲜食品牌联名（如香蕉+牛奶组合），建议优先联系区域销售。

---

### 给您的执行建议：
- **优先联系区域经销商**：两家公司不同区域的SKU差异大，直接打电话给当地办事处，说明“便利店小包装”需求，最可靠。
- **尝试“小罐装”或“果切组合”**：如果两家都没有现货，便利店常用的替代方案是：
  - 与本地水果供应商协商定制小规格（如3根装）。
  - 选择都乐的“迷你香蕉”或国产“超甜蕉”小包装作为临时替代。
- **注意保鲜期**：小包装香蕉的损耗率高，建议先小批量试单，观察周转率。

如果需要具体联系电话或报价，建议通过**鑫荣懋官网**或**都乐官网**的“联系我们”入口，或通过企查查/爱企查查询当地分公司信息。
