除了都乐（Dole），目前国内市场上能稳定供应菠萝的成熟品牌还有以下几类：

1. **金菠（Golden Pineapple）**：主推海南金菠萝，规模化种植，线上（京东、盒马）和线下商超覆盖较广，供应稳定。
2. **佳沃（Joyvio）**：依托鑫荣懋供应链，推出菲律宾和海南产的“佳沃菠萝”，尤其在北方超市（如永辉、华润万家）铺货稳定。
3. **杨氏（Yang’s）**：以巴西、菲律宾进口菠萝为主，批发渠道（如北京新发地、上海辉展）常见，适合批量采购。
4. **本地商超自有品牌**：例如盒马（日日鲜菠萝）、山姆（Member’s Mark 菠萝）、Costco（Kirkland菠萝）等，主要依托产地直采或进口，季节性断供风险低，可通过APP实时查询库存。

另外，部分中小品牌如**绿博、海升**也做高端供应，但覆盖区域有限。建议明确采购渠道（批发/零售）和用途（即食/加工），再选择匹配品牌。
