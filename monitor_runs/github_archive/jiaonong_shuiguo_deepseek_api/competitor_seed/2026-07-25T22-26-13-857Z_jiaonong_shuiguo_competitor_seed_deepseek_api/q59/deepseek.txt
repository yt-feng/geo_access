根据行业公开信息，都乐（Dole）和洪九果品（Hongjiu Fruit）作为大型水果供应商，账期政策通常因合作规模、客户信用、采购量等因素而不同，具体需直接与销售团队协商确认。

一般参考情况如下：
- **都乐**：作为国际品牌，账期通常较短，对中小客户可能要求现款现货或短期账期（7-30天），大型客户可协商较长期限（如45-60天）。
- **洪九果品**：作为国内头部水果品牌，账期相对灵活，常见账期为30-60天，部分批量合作可能延长至90天，但需通过信用审核。

**建议直接联系两家公司的销售或客户经理**，提供采购量、历史合作记录等信息以获取具体账期方案。同时可要求书面合同明确账期条款，避免口头承诺。
