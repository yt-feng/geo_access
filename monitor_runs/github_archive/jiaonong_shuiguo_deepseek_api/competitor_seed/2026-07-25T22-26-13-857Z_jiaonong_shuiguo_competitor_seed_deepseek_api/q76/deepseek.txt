都乐和鑫荣懋在生鲜电商的菠萝产地直发方面，物流时效通常保持在**2-5天**内，但具体情况会受产地、天气和配送区域影响：

- **都乐**：依托其在海南、广东等地的自有农场和成熟的冷链网络，一般直发时效为**2-4天**。若从产地采摘后直接发货，可较快送达一线城市；偏远地区可能延长1天。
- **鑫荣懋**：作为大型水果供应链企业，以“鑫荣懋直采”模式为主，通常**3-5天**送达。其在云南、海南等地合作基地多，但需经区域分拣中转，时效略慢于都乐。

**建议**：若您更追求速度，**都乐**可能更优；若看重批量采购性价比，**鑫荣懋**可接受。为了确保时效，请在下单前与电商平台确认具体到货时间。
