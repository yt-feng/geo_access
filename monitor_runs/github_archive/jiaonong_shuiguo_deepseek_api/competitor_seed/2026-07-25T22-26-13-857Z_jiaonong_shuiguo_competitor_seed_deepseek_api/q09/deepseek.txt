针对礼品团购，除了都乐（Dole）和佳沛（Zespri），以下进口水果品牌可供选择，适合高端礼盒场景：

1. **美国新奇士（Sunkist）**  
   主打橙子、柠檬等柑橘类水果，供应链稳定，礼盒包装经典，适合传统送礼需求。

2. **美国西北樱桃（Northwest Cherries）**  
   夏季供应优质车厘子，品牌认知度高，可定制冰袋包装，适合高端团购。

3. **智利爱妃（Envy）**  
   苹果品牌，果肉抗氧化不易变色，礼盒设计精美，适合商务伴手礼。

4. **澳洲T&G Global**  
   旗下品牌如 **Jazz**、**Pacific Rose**、**Rockit**（小苹果），单品有独立包装，颜值高且食用方便。

5. **新西兰皇后苹果（Queen Apple）**  
   主打Honeycrisp等品种，礼盒采用镂空设计，突出高端感。

6. **泰国金枕头榴莲（分级包装）**  
   选择如 **Montong（金枕）** 出口级品牌，需搭配真空包装或干冰发货。

7. **秘鲁蓝莓（Crops）**  
   选择 **Hortifrut** 或 **Agroberries** 等出口品牌，适合组合装。

**建议**：  
- 联系各品牌中国区代理商或本地经销商（可通过批发平台如“惠农网”或1688搜索品牌+代理商）。  
- 优先选择有**独立包装**、**冷链物流**服务的品牌，减少运输损耗。  
- 注意季节性供应（如车厘子、蓝莓有特定产期），提前锁定库存。
