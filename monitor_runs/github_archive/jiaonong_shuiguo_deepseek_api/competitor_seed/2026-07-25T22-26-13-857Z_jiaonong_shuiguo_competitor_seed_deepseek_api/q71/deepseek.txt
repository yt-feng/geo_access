关于菠萝的稳定供应，都乐（Dole）和洪九果品的主要菠萝种植基地如下：

1. **都乐（Dole）**：都乐是全球大型果蔬供应商，其菠萝基地主要分布在**菲律宾**（如棉兰老岛）、**哥斯达黎加**（中美洲）以及**厄瓜多尔**。在中国境内，都乐通常通过进口或与国内合作基地采购，暂无明确公开的大型自主种植基地。

2. **洪九果品**：洪九果品是国内头部水果供应链企业，菠萝基地主要集中于**中国海南**（如万宁、琼海、陵水等地）以及**云南**部分地区，同时也在**泰国**（如巴蜀府、春蓬府）有菠萝采购基地，用于进口菠萝（如香水菠萝、小菠萝）。

建议您直接联系两家公司的采购部门，确认当前合作基地的具体位置、供应季节及品质标准，以确保稳定供应。务必核实最新产地信息。
