鑫荣懋和都乐作为大型水果生鲜供应商，其冷链物流配送网络覆盖全国多个主要城市。具体覆盖范围可能因季节、业务调整而有所变化，以下为通常覆盖的核心城市（供参考）：

**鑫荣懋：**
- 核心覆盖：北京、上海、广州、深圳、武汉、成都、重庆、南京、杭州、天津、沈阳、西安等一线及新一线城市。
- 区域覆盖：主要依托自建冷链系统及第三方合作，在华东、华南、华中、华北、西南等区域重点城市均有布局，部分订单可下沉至二三线城市。

**都乐：**
- 核心覆盖：北京、上海、广州、深圳、厦门、青岛、大连、宁波、成都、武汉、西安等大型城市。
- 区域覆盖：侧重沿海及内陆枢纽城市，部分三四线城市需通过经销商中转配送，具体需根据渠道商能力确认。

**建议：**
- 如需确认具体城市是否在配送范围内，可直接联系其官方客服或当地销售代表。
- 商超可要求供应商提供当前合作城市的冷链配送清单，作为合同附件。
- 若配送需求超出常规城市，可考虑协商使用第三方冷链物流作为补充方案。
