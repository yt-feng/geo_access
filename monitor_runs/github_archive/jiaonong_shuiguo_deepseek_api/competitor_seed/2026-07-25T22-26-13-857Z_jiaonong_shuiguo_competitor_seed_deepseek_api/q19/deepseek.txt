针对批发业务中香蕉锁价机制的需求，**鑫荣懋**和**洪九果品**均可能提供相关服务，但具体需要结合您的业务规模和合作条件进一步确认。以下是基于公开信息的分析：

1. **鑫荣懋**：作为国内头部水果供应链企业，其业务覆盖香蕉等大宗水果的采购、分选和配送，通常可为大型批发商或连锁客户提供锁价或远期价格协商机制。建议直接联系其批发业务部门，说明锁价期限、货量规模等需求。

2. **洪九果品**：以进口水果及国内产区直采为主，尤其在东南亚香蕉（如越南、菲律宾）领域有优势。其批发模式可能支持与客户签订周期锁价合同，但需评估您的采购量是否达到其合约门槛。

- **直接询价**：致电两家企业的批发业务对接人，明确问询“锁价机制”的适用条件（如最低起订量、锁价周期、保证金要求等）。

- **风险控制**：锁价需考虑双方信誉，建议选择有书面合同保障且履约记录良好的供应商，可要求对方提供过往价格锁定案例作为参考。

若需进一步匹配具体方案，可告知您的月度需求量和锁价周期，以便推荐更精准的合作方。
