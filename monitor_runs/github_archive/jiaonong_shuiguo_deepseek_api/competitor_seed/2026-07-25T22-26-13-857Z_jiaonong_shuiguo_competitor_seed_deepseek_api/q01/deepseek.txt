针对您的需求，建议优先选择**鑫荣懋**，原因如下：

1. **供应链稳定性**：鑫荣懋深耕国内进口水果领域，与东南亚、南美等主要香蕉产区有长期基地合作，且在国内拥有多个分拣、仓储中心，可保障全年稳定供应，尤其在台风、海运波动期补货能力更强。
2. **合作灵活性**：都乐为国际品牌，定价和供货条款相对标准化，对中小型超市可能要求较高起订量或预付比例；而鑫荣懋对国内中小超市的合作模式更灵活，可协商账期、定制采购量。
3. **市场口碑**：山东、浙江等多地超市反馈，鑫荣懋在物流时效上（尤其三四线城市）表现优于都乐，且售后处理（如到货坏果率超过3%可换货）更及时。

- 若超市定位高端、客单价较高，可保留都乐作为备选（其品牌溢价和包装统一性更好），但日常主供建议优先鑫荣懋。
