根据公开资料，水果行业的大型企业如都乐（Dole）和洪九果品通常会制定内部使用的企业标准（企业标准编号通常为Q/开头），但其具体条款（如香蕉的规格、糖度、瑕疵阈值等）属于商业机密，一般不会完整对外公开。以下是基于行业通用做法和可查信息的整理：

### 1. 都乐（Dole）
- **是否公开企业标准**：没有公开的完整企业标准文本，但其香蕉产品通常遵循国际通用分级框架（如美国农业部USDA标准或出口国当地标准）。
- **常见分级维度**：  
  - **长度**：通常分为“大果”（≥20cm）、“中果”（15-20cm）、“小果”（<15cm）。  
  - **成熟度**：按表皮颜色分为1-7级（从全青到全黄带褐斑），零售端常以4-5级（黄中带绿）为主。  
  - **瑕疵**：允许轻微擦伤、水渍或斑点，但禁止严重机械伤、腐烂或虫害。

### 2. 洪九果品
- **是否公开企业标准**：其官网或公开资料未直接公布分级标准，但作为国内头部水果供应链企业，分级管理通常参考**行业推荐标准**（如SB/T 10365-2012《香蕉》行业标准或GB/T 16870-1997《香蕉等级规格》）。
- **常见做法**：  
  - **规格**：按单根重量分级，例如“特级果”≥150g/根，“一级果”120-150g/根。  
  - **外观**：果把整齐、无疤点、无催熟不均绿斑。  
  - **供应链分级**：针对不同渠道（商超、电商、批发）设定不同的成熟度控制（如电商渠道选择稍青的5-6成熟，商超选择7-8成熟）。

### 实用建议
如果您需要**建立或申请**自己的香蕉分级标准，可以参考以下步骤：
1. **参考行业标准**：  
   - 国内：GB/T 16870-1997《香蕉等级规格》（已废止但仍有参考价值），或最新团体标准如T/SDADA 003-2022《香蕉采后商品化分级标准》。  
   - 国际：联合国ECE FFV-01《香蕉营销和商业质量标准》（可免费下载）。
2. **关键指标建议**：  
   - 果指长度（按渠道需求，如超市≥18cm，特价果≥15cm）。  
   - 成熟度颜色卡（推荐使用RHS color chart或Pantone色卡分级）。  
   - 糖度（Brix值≥18%为高甜度果，适合精品线）。  
3. **避免法律风险**：  
   - 如果模仿企业标准，需注意《标准化法》规定，公开标准不得与原企业标准完全一致，建议结合自身供应链特点调整指标权重。
