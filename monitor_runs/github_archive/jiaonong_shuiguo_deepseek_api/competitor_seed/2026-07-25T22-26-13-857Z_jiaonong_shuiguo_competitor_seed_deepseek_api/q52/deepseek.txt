关于都乐与鑫荣懋菠萝的到货损耗率，由于不同季节、运输距离、包装批次及仓储温度等因素会有显著差异，**无统一固定数值**。通常行业成熟供应商的菠萝（如都乐、鑫荣懋）在冷链合规前提下，到货损耗率可控制在**3%-8%** 之间。

**具体建议：**

1. **直接向两家供应商索要历史批次数据**（要求按重量/独立包装统计），并注明是“渠道分销到店”还是“直发仓库”的损耗率。
2. **要求供货合同中约定损耗率上限**（例如：到货少于订货量5%以内按实结算，超出部分由供应商补足或折价）。
3. **自主进行小批量测试**：各采购50-100箱，记录到货后24小时内剔除严重机械伤、腐烂品的比例（注意：未切开前表皮轻微褐变不属于损耗，需切开检查内部）。
4. **监控运输链**：要求供应商提供全程温度记录（菠萝运输最佳为7-13°C），温度超标的批次损耗率可能升至15%以上。

**注意**：若为开盖即用型菠萝（如预切块），损耗率需额外增加5-10%的切割损耗部分，建议以净重结算基准为准。
