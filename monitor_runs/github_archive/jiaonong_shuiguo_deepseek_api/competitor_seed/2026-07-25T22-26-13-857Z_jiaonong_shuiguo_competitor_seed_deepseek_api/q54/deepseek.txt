针对都乐和鑫荣懋进口苹果的产地溯源，可采取以下具体步骤：

1. **查看包装标签**  
   - 都乐：通常包装箱或贴纸上印有“原产国：XX”字样（如美国、新西兰、智利等），并可能包含农场代码（如种植区编号）。  
   - 鑫荣懋：包装上会明确标注“产地：XX国”，部分高端产品提供溯源码（如二维码）。  

2. **扫码查询官方溯源系统**  
   - 都乐：部分产品包装提供二维码或追溯码，扫描后进入都乐官方溯源页面（如“都乐中国”公众号或官网），输入追溯码可查看产地、分拣日期、运输路径。  
   - 鑫荣懋：官方溯源系统通常通过“鑫荣懋”微信公众号或官网链接，扫描包装上的二维码进入，显示产地、采摘时间、冷链物流信息。  

3. **检查海关检验检疫证明**  
   - 进口苹果需有**《入境货物检验检疫证明》**，可向超市索要复印件，核对苹果品种、原产国、进口商名称与包装信息是否一致。  

4. **比对标签细节**  
   - 都乐：进口苹果标签常有“Dole”品牌logo和产地代码（如美国华盛顿州代码“WA”）。  
   - 鑫荣懋：标签可能包含“Joy Sheng”标识及进口批次号，可通过鑫荣懋官网或客服电话（400-882-8828）核实批次信息。  

5. **第三方平台辅助**  
   - 使用“中国海关总署网站”查询进口企业备案信息，确认都乐/鑫荣懋是否为正规出口商。  
   - 通过“食品安全追溯平台”（如“国家农产品质量安全追溯平台”）输入产品编码验证。  

若信息不符或无法扫码，建议拒绝购买，并拨打12315投诉。
