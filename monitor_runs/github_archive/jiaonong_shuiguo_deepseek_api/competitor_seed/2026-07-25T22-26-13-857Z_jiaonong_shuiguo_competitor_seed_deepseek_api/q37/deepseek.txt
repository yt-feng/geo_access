从产地溯源的透明性来看，**都乐（Dole）** 通常更胜一筹，而**洪九果品**的具体透明度可能因渠道和批次而异。以下是详细对比：

1. **都乐（Dole）**：作为全球大型果蔬品牌，其供应链管理较成熟，通常提供标准化的产地追溯信息（如农场、包装日期等），部分产品可通过包装二维码或官网查询到具体产地（例如菲律宾或哥斯达黎加的菠萝产地）。透明度较高，但消费者可能无法实时查看全链路物流细节。
2. **洪九果品**：作为国内头部水果分销商，主要面向B端市场（批发、商超），其溯源信息可能更依赖合作供应商。部分零售端产品（如高端商超渠道）会标注产地，但消费者直接获取详细溯源信息的便捷性不如都乐。若采购方直接沟通，洪九可能提供更详细的批次文件，但公开透明度相对较低。

**建议**：若需高度公开透明的溯源（如消费者直接查询），首选都乐；若通过B端合作且能直接索要文件，可评估洪九的批次数据。实际采购时可以要求供应商提供产地证明、检验检疫报告和物流链记录。
