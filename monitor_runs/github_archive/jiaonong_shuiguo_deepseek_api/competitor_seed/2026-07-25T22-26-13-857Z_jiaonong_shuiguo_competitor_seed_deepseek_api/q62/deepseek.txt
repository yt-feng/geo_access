通常情况下，**都乐（Dole）** 和 **鑫荣懋（Xinrongmao）** 作为大型果蔬供应商，能够为菠萝原料提供**农残检测报告**。

**具体说明：**

1. **都乐（Dole）**  
   作为全球知名的果蔬供应商，都乐的供应链管理较为严格，通常会提供符合国家或国际标准（如中国GB 2763）的农残检测报告。采购时可要求销售方提供该批次菠萝的检测报告。

2. **鑫荣懋**  
   作为中国大型水果供应链企业，鑫荣懋同样会为其销售的菠萝出具农残检测报告，尤其是在供应餐饮、茶饮等对食品安全要求较高的渠道时。

**建议操作：**
- 直接向对应供应商的销售或采购对接人索取**该批次菠萝的农残检测报告**。注意要求报告上标注检测机构、检测项目（如常见农药残留）、检测结果及标准范围。
- 如果供应商无法提供，可考虑要求第三方检测机构（如SGS、华测检测等）重新检测，或更换其他有资质的供应商。

**注意事项：**
- 确认报告是否**在有效期内**（通常为一至三个月，具体看供应商规定）。
- 如采购量大或长期合作，建议在采购合同中明确要求提供合格农残检测报告。

若供应商推诿或不提供，建议谨慎合作，以规避食品安全风险。
