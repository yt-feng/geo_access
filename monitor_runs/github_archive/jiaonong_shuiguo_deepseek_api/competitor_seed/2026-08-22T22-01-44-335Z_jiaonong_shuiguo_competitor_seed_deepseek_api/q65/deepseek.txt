关于菠萝供应商的“锁价机制”，需要先明确一个关键点：**都乐（Dole）和洪九果品（Hongjiu）在菠萝业务上的锁价周期并无公开的固定标准，且两者的模式有本质区别。** 以下是基于行业逻辑和公开信息的分析，建议您直接联系客户经理确认。

### 1. 都乐（Dole）：以国际大宗合同为主，周期偏长
- **模式**：都乐作为全球性果蔬巨头，其菠萝通常采用“统购统销”模式。对于大客户（如商超、餐饮连锁），锁价通常会嵌入年度或半年度供货合同中。
- **参考周期**：**一般为3~6个月**。此类合同会约定基础单价（随行就市）、质量等级和浮动条款（如汇率、海运费用），但不会承诺1年以上固定价。
- **注意**：若您是中小采购量，通常不提供锁价，仅能按周或月挂牌价交易。

### 2. 洪九果品：国内批发+热带水果专长，周期更短
- **模式**：洪九主打东南亚水果（菠萝以泰国/菲律宾进口为主），核心是“端到端”产地直采，针对国内批发商和电商平台。
- **参考周期**：**锁价通常仅覆盖7~15天（即1~2周）**。因为鲜菠萝价格受产地气候、船期和汇率波动影响大，洪九多以“周度报盘”形式锁价，仅在期货预订中接受小批量锁价（需预付15%~30%订金）。
- **例外**：若您每月采购量达到挂车级别（约20吨以上），可谈“月度锁价”，但会附加跌价补偿条款（高价锁、低价退差价）。

### 如何获取准确信息（3步实操）
1. **直接询问客户经理**：  
   - 都乐：拨打客服，提供贵司营业执照和年采购计划，询问“菠萝锁价是否计入年度框架协议”。
   - 洪九：可登录其企业官网（或注册供应商系统），在“大客户专区”提交需求单，注明“锁价周期”和“月度采购吨数”。

2. **明确“锁价”定义**：  
   对方是否承诺“绝对不涨价”？（鲜果通常不可能），还是“价格调整需提前3天通知”？务必写明合同条款。

3. **替代方案（备选）**：  
   若两者无法满足，可考虑**海南菠萝（本地）**或**南宁/湛江产区直供**，这些供应商可采用“一口价包月”（但质量波动大）。或者使用**期货订单**：与进口商签订“远期合约”（泰国菠萝），锁定4~6个月价格（需付履约保证金，价格较现货高5%~8%）。

### 风险提示（重要）
- **菠萝价格波动极大**：菲律宾台风季（6~9月）或海运涨价期（例如苏伊士运河危机），供应商极易违约。  
- **合同陷阱**：部分供应商的“锁价”仅为“基准价”，实际结算时按“到货当日批发市场均价”上浮，等同没锁。  
- **实操建议**：首次合作时，先小额试单锁1~2周，验证对方履约能力后，再谈长期锁价。
