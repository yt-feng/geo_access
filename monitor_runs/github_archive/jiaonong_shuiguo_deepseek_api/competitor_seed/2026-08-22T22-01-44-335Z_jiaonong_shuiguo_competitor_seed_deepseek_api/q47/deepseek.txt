根据我目前掌握的信息，**都乐（Dole）**和**洪九果品（Hongjiu）**作为大型水果品牌/供应商，**通常都具备定制化包装服务**，但具体能否为便利店提供“香蕉小包装”定制，取决于门店的采购规模、合作模式以及您的具体需求。

以下是具体建议和判断依据：

1. **都乐（Dole）**：作为全球性品牌，其主要优势在于品牌形象和标准化供应链。在大型商超（如盒马、永辉、山姆）中，确实常见其**自有品牌的小包装香蕉**（如2-3根装，或5-6根装）。如果您是便利店连锁（如全家、罗森）或具有一定单店订单量，**建议直接联系其华东/华南的渠道销售或大客户部**，洽谈小包装定制（如克重、封口装、贴标）。但如果是单店小体量，可能走批发市场的标准件（18kg/箱）更划算。

2. **洪九果品**：这是国内头部的水果供应链企业，核心优势在于**“分选+包装”能力极强**。他们在国内多个口岸（如广州、重庆）有自有分选线，且大量供应给连锁便利店、社区团购渠道。**他们非常擅长做末端小包装**（如保鲜膜包3根、托盘装、贴指定标签）。适合便利店做**联名定制**或**区域专供**。建议联系其业务经理，提供您的POS/SKU需求，他们通常能快速打样。

3. **实操判断**：
   - **若您是连锁便利店采购**：建议直接通过采购系统下单，或让供应商报“定制包材费+分选费”，通常起订量在500-1000箱/月可谈。
   - **若您是单店/小型连锁**：建议直接去当地水果批发市场找“国产香蕉档口”，很多档口本身就代切代包（例如4-5根一包），成本更低，且无需工厂定制费。

**结论**：**两者都提供，但“定制”门槛不同。都乐偏标准化大客户，洪九更灵活且适合便利店**。最直接的验证方式是拨打两家官方客服电话，或通过其微信公众号/官网的“商务合作”入口咨询，报出您的便利店名称和月需求量，他们会给出明确答复。
