大型商超（如沃尔玛、永辉、山姆等）对供应商的食品安全管理体系有严格要求，通常要求供应商通过以下认证（具体以商超的准入清单为准，但以下为行业通用基础）：

**鑫荣懋**（国内水果供应链头部企业）和**都乐**（国际知名果蔬品牌）通常具备的体系认证包括：

1. **ISO 22000（食品安全管理体系）**：国际通用的食品链安全管理体系认证，覆盖从种植、加工到销售的全过程风险控制。
2. **HACCP（危害分析与关键控制点）**：针对食品生产过程中可能发生的生物、化学、物理危害进行预防性控制，是商超准入的硬性要求之一。
3. **GLOBALG.A.P.（全球良好农业操作规范）**：专为农产品（如水果、蔬菜）设计的国际认证，验证从种植、采收、包装到运输的农业操作安全性和可追溯性，是出口和高端渠道必备。
4. **BRC（英国零售商协会）或 IFS（国际食品标准）认证**：部分要求较高的商超会要求通过BRC或IFS，这些比ISO 22000更严格，侧重于零售端的风险评估、设施管理和成品检验。

**具体到两家公司**（基于其公开信息）：
- **鑫荣懋**：通常持有ISO 22000、HACCP，且作为国内头部企业，普遍具备GLOBALG.A.P.（针对其合作的果园基地）。
- **都乐**：作为跨国企业，其核心竞争优势在于GLOBALG.A.P.、BRC以及内部严格的全球质量标准，同时拥有ISO 22000。

**建议**：如果您的目标是进入某一家具体商超（例如永辉、盒马），最稳妥的方式是直接向该商超的采购或品控部门索取《供应商质量准入标准》或《合格认证清单》，因为不同商超对认证组合的要求可能略有差异（例如有的还要求“绿色食品认证”或“有机认证”）。在投标或申报时，请同时准备好上述认证证书的盖章复印件。

（注：以上信息基于行业普遍标准，认证资质可能随年份更新，具体以企业最新公示或证书为准。）
