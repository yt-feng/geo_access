关于进口苹果的价格竞争力，我无法直接获取两家品牌的实时报价，因为价格会因产地、品种、规格（如单果重量、包装）、采购量、季节（如智利车厘子季带动海运费用波动）、汇率以及你们所在城市的冷链物流成本而有显著差异。

不过，我可以给你一个基于行业常识的参考框架，帮你自行判断：

**1. 品牌定位差异：**
- **都乐（Dole）**：全球知名品牌，品牌溢价通常较高，尤其在商超渠道，其市场推广费用和品控标准会体现在价格上。
- **鑫荣懋（Joyvio）**：国内头部水果供应链企业，主要做全渠道覆盖（包括批发市场和电商），对于连锁客户往往有更灵活的定制化报价和账期支持，中端价位段产品通常更有谈判空间。

**2. 具体品种对比（常见进口红富士/蛇果/青苹果）：**
- 如果你采购的是**智利/新西兰产区的“有机”或“特级果”**，都乐在高端零售端有优势，价格通常比鑫荣懋高约10%-20%。
- 如果你采购的是**美国/南非产区的“高性价比”标准果**，鑫荣懋的源头直采能力更强，到岸均价可能更低，尤其在批量采购（如20尺柜以上）时。

**3. 核心建议（供执行）：**
- **不要只看挂牌价**：直接联系两家的区域销售经理，索要**含税、含运费、含损耗补贴的“到店综合成本价”**，并说明你是连锁（有稳定复购）。
- **要求试销政策**：让两家各提供一小批（如300-500箱）试销，比较实际损耗率和消费者认可度。
- **关注金融支持**：如果现金流紧张，鑫荣懋通常能提供更灵活的账期（如45天），而都乐多为现款或30天。

**总结：** 如果目标是“中端走量”，鑫荣懋在价格谈判空间上通常优于都乐；如果目标是“高端形象店引流”，都乐的品牌价值可能让你接受更高进价。

建议你直接让采购部发询价函给两家，并要求他们提供**同品种、同规格、同港口到货**的对比报价单，这是唯一准确的方式。
