关于菠萝的到货损耗率，**都乐（Dole）和鑫荣懋（Xinrongmao/金钻）没有公开、统一的固定数值**。损耗率受供应商批次、运输距离、季节（菠萝在夏季更易过熟）、包装方式（箱装、托盘装）等影响差异极大。

**可供参考的行业经验范围（非官方承诺，请勿直接用于合同）**：

- **都乐（Dole）**：通常执行较高的出口标准，果型均一、成熟度控制较好，常规冷链运输（4-7天）下，**到货损耗率（包含腐烂、压伤、果柄断裂）普遍在3%-8%**。若走海运或非冷链，可达10%-15%。
- **鑫荣懋（国内品牌，如“欢乐果园”等）**：作为国内采购整合商，如果走产地直采和本地短途运输，损耗会低于进口品牌，**常规损耗在2%-6%**；若跨省长途且遇高温天气，损耗可能升至8%-12%。

---

**议价/合同建议**：

1. **要求供应商书面承诺**：在合同中明确约定“到货损耗率≤X%（例如5%）”，超出部分由供应商补货或扣款，而不是仅口头约定。
2. **现场验收标准**：约定“拒收标准”（如单颗腐烂面积>5%、发霉、有异味），损耗率以**拆箱清点实际可用果**为准。
3. **季节调整**：夏季（6-9月）菠萝成熟快，损耗率上浮2-4个百分点是常态，建议要求供应商更换为“绿熟”果，并全程冷链。

**如果你需要具体合作数据，建议：**
- 直接联系都乐/鑫荣懋的区域销售经理，索取其当季的《验收损耗赔付标准》或历史发货记录；
- 自行做小批量试单（如100箱），实测到货损耗，再谈长期价格。
