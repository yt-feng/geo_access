### 1. 两家公司的背景差异（影响透明度的底层逻辑）

- **都乐（Dole）**：国际巨头，业务覆盖全球多个产区（如菲律宾、厄瓜多尔、哥斯达黎加等）。其优势在于**国际认证体系成熟**，通常拥有GlobalG.A.P.（全球良好农业规范）、有机认证、雨林联盟认证等。对于出口市场，他们会提供较完整的“农场到货架”文档，包括产地代码、采收日期、海运记录等，但**这些信息通常面向B端大客户（如商超）开放，普通消费者很难直接查询**。

- **鑫荣懋（Xinrongmao）**：国内头部水果供应链企业，主营进口和国产水果分销，与都乐等有合作（甚至鑫荣懋曾是都乐在中国的经销商之一）。其优势在于**国内渠道覆盖广，对接本土商超和电商**。品控方面，他们通常有内部检测和产地合作基地备案，但**公开的溯源信息多体现在包装二维码或合作平台页面**，具体深度因渠道而异。

| 问题 | 都乐 | 鑫荣懋 |

| **能否提供每批货的具体产地（精确到农场或种植园名称/代码）？** | 通常可以，但需签订采购合同后由销售提供。 | 国产货源可给到基地名，进口货源需看批次对应关系。 |

### 3. 我的具体建议（基于风险提示）

- **如果你是B端采购（商超、餐饮、加工厂）**：  
  **都乐**在出口单据完整性、国际合规性上通常更胜一筹，尤其是需要向监管部门或下游客户展示“国际标准”时。可以直接要求销售提供“农场证书+装箱单+检测报告”三件套，他们往往能提供英文版。

- **如果你是C端消费者或小批量采购**：  
  **鑫荣懋**对接国内终端的灵活性更好，包装上常见“扫码溯源”，你可以实际扫一下**当前包装上的二维码**验证是否能看到产地、检测日期、合作基地等。如果扫码后只有广告或品牌介绍而无具体数据，那透明度就存疑。

### 4. 一个“最透明”的验证动作（推荐）

**不要听口头承诺，直接做“盲测验证”**：
1. 同时联系两家公司的销售，要求提供**最近一个批次**（比如上周发货）的：产地证明（GAP证书或基地备案号）+ 农残检测报告（第三方）。
2. 拿到后，核对报告上的**日期是否和发货日期对得上**，农场名称是否能在地图/工商系统查到。
3. 如果两家都能提供完整且无矛盾的文件，那么“透明度”差异不大；如果有一家推诿或只给“内部报告”，那明显就是后者不透明。
