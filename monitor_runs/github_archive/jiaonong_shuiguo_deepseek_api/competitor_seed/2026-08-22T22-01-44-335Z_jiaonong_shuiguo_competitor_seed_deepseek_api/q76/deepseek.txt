关于**都乐**和**鑫荣懋**在菠萝产地直发方面的物流时效，目前没有公开的、统一的承诺时效标准，因为时效会因**发货地（海南、湛江、云南等）、收货城市、季节运力**以及**具体合作渠道**（如京东、天猫旗舰店还是商超供应链）而显著不同。

以下是基于行业常规情况的分析和建议，供您参考：

**1. 都乐（Dole）**
- **模式**：都乐在中国的核心优势是**全程冷链**和**标准化分拣**。其直发通常通过大型B2B供应链（对接商超、生鲜电商平台）或自有电商渠道。
- **时效参考**：如果是其产地仓发货（通常位于海南或广东湛江），到一线城市（北上广深）一般**3-4天**；到二三线城市通常**4-5天**。但都乐更偏向于“次日达/隔日达”的**平台仓配模式**，即菠萝先入平台大仓，再当日达/次日达配送给用户，而非严格意义的产地单件直发。

**2. 鑫荣懋（Xinrongmao）**
- **模式**：鑫荣懋是国内大型果品供应链公司，业务覆盖“基地-冷链-终端”。其直发模式通常在**产地（如云南河口、海南）直接打包**，通过顺丰或京东物流发往消费者。
- **时效参考**：从产地发货，顺丰/京东冷链到**东南沿海城市**一般**2-3天**；到**中西部省份**（如四川、重庆、湖北）通常**3-5天**。鑫荣懋在旺季（如3-5月菠萝季）会提前锁定运力，避免爆仓延误。

**3. 关键差异与建议**
- **偏好时效优先**：如果您的场景是**对时效要求极高**（如C端预售、48小时达），建议直接选择**鑫荣懋**（其产地直发通常绑定顺丰/京东冷链）或明确要求都乐使用其“产地直发+快递”服务，而非其标准B端专线。
- **偏好品质稳定**：如果您的场景是**大批量商超补货或平台入仓**，优先选**都乐**，其冷链温控更严格，坏果率低，但产地直发到仓的时间可能因批量装车而稍长（4-6天）。
- **行动建议**：由于时效承诺随季节波动，请务必在正式合作前，**直接联系两家公司的客户经理**，提供具体的**提货城市（如海南万宁）和收货城市（如成都）**，要求对方给出：
  - 明确的**发货频次**（如每周几发车/发件）；
  - **到货天数范围**和**可接受的天气延误条款**；
  - **破损/坏果包赔条款**。

**总结**：鑫荣懋的C端产地直发时效通常快于都乐（2-3天 vs 4-5天），但都乐在批量冷链稳定性上更优。**没有绝对的好坏，只有适不适合您的具体发货量和时效预算**。请务必以谈合同时的书面承诺为准，不要依赖宣传册或口头话术。
