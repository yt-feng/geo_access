关于菠萝原料的稳定供应，您所提及的两个品牌（都乐、洪九果品）在菠萝供应链上的基地情况如下，供您参考：

1. **都乐（Dole）**：都乐是全球知名果蔬品牌，其菠萝主要产自**菲律宾**（著名的“都乐菠萝”多来自菲律宾棉兰老岛等产区），同时在中国广东（如湛江、徐闻一带）及海南也有合作种植基地或采购网络。若需稳定供应，建议直接联系都乐中国区的餐饮/批发渠道，获取当季产地动态及直供协议。

2. **洪九果品**：洪九是国内的头部水果供应链企业，其菠萝基地主要在**中国广东湛江（徐闻菠萝产区）**及**海南（万宁、文昌等）**，同时依托泰国、菲律宾等进口渠道补充反季节档期。洪九在产地通常采用“基地+合作农户”模式，可提供全年稳定供货。

**采购建议**（可执行）：
- **明确规格**：写明所需品种（如巴厘、金钻凤梨）、糖度、单果重量、成熟度（青菠萝/半熟/即食）。
- **产地联动**：若您在中国南方，优先对接洪九广东/海南基地；若追求高端品牌溢价，则考虑都乐进口档（成本较高）。
