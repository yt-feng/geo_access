关于洪九果品和鑫荣懋在**香蕉产地直发**方面的基地情况，具体信息如下：

**1. 洪九果品（重庆洪九果品股份有限公司）**
- **产地布局**：洪九果品以“端到端”模式著称，尤其在**东南亚**（如越南、老挝、柬埔寨）和国内（云南、海南等）有较强的基地和供应链布局。
- **香蕉基地**：**洪九在香蕉上重点依托**越南**和**老挝**的基地（或与当地大型农场深度合作），以及国内**海南、云南**的香蕉基地。他们控股或深度绑定上游种植园，以实现产地直发。
- **优势**：洪九在“产地直接采购+自有加工分选”上投入大，如果问“谁有基地”，洪九的说法更明确，且自有基地比例较高。

**2. 鑫荣懋（深圳市鑫荣懋农产品股份有限公司）**
- **产地布局**：鑫荣懋是国内大型水果供应链企业，主要依托**长期合作的全球优质产区和基地**，包括国内（云南、广西等）和海外（越南、菲律宾、缅甸等）。
- **香蕉基地**：鑫荣懋**在海外香蕉（如菲律宾、越南）及国内云南、广西有合作或自营的种植基地**，但更偏“供应链企业+基地合作”模式，公开信息中“自有产权基地”提法不如洪九显著。
- **优势**：鑫荣懋的优势在于**渠道和分选、冷链**，基地多为“订单农业”或长期协议，**并非全部自有**。

---

**结论（针对您的需求）**：
- 如果您要**严格意义上的“产地直发+稳定自有基地”**，**洪九果品**在**越南/老挝/海南**的香蕉基地更明确、自营程度更高。
- 如果您更看重**供货稳定性、分选包装和全国配送能力**，**鑫荣懋**也可以满足，但基地多为“深度合作”，建议您直接联系其采购/大客户部门确认具体产地基地资质。

**操作建议**：无论选哪家，建议：
1. 要求对方提供**基地的种植面积、产地证明（如GAP认证）**；
2. 明确**单票发货量、损耗率、到货质检标准**；
3. 先做**小批量试单**，检验到货品质和损耗后再决定长期合作。
