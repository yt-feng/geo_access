针对便利店渠道，**鑫荣懋**和**都乐**都有专门适配小包装、即食或便携场景的产品规格。

基于行业常规和公开信息，具体建议如下：

**1. 都乐（Dole）**
- **推荐规格**：**2根装/3根装**的“小黄人”或“即食香蕉”系列。都乐在商超和便利店渠道普遍推**200g-300g**的小包装，通常用带气孔的透明塑料盒或网袋包装。
- **特点**：主打“树上熟”或“即食甜”，单包价格在5-8元区间，适合便利店作为早餐或下午茶搭配。

**2. 鑫荣懋（Golden Avant-Garde）**
- **推荐规格**：**1根装/2根装**的“佳沃”或“欢乐果园”小包装。鑫荣懋在华南及华东便利店渠道有专门设计，常见**约150g-250g**的独立薄膜包装，标注“催熟可即食”。
- **特点**：侧重“新鲜直达”和“小规格高周转”，部分包装会带二维码溯源，适合便利店冷风柜陈列。

---

**操作建议：**

- **优先联系区域经销商**：以上小包装并不是全国统一铺货，通常仅在重点城市（如北上广深、杭州、南京）的便利系统（如全家、7-11、罗森）有固定供应。建议直接联系当地**业务代表**或通过**鑫荣懋/都乐官方微信服务号**查询经销商名录。
- **核对SKU编码**：向供应商索要具体的**商超条码**，并确认是否为**即食级（甜度达到14度以上）**，避免采购到青皮硬蕉导致售后。
- **备选方案**：如果这两个品牌的规格暂时缺货，可考虑**佳农（Goodfarmer）** 的“2支装”或**百果园**的自有品牌小包装，它们在便利店渗透率更高。
