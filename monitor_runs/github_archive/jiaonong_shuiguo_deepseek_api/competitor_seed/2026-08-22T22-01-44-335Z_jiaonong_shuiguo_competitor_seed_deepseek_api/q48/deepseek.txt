鑫荣懋（Xinrongmao）和都乐（Dole）作为大型水果供应商，通常都持有与食品安全相关的资质认证，以符合商超的准入要求。不过，具体资质会根据其业务范围、出口市场以及合作商超的要求有所不同。

以下是这两家公司常见的食品安全相关资质（基于公开信息）：

**1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）：**
- **Global G.A.P.**（全球良好农业操作规范）：涵盖种植、采收、包装等环节的食品安全管理体系。
- **BRC**（英国零售商协会）食品安全全球标准：被国际零售商广泛接受。
- **ISO 22000**（食品安全管理体系）：适用于食品供应链各个环节。
- **HACCP**（危害分析与关键控制点）：针对生产加工环节的食品安全控制体系。
- 国内：通常具备**SC**（食品生产许可证）以及商超要求的**产品质量检验报告**。
- 部分合作项目可能持有**有机认证**或**绿色食品认证**。

**2. 都乐（Dole，都乐亚洲/中国公司）：**
- **Global G.A.P.** 和 **BRC**：作为国际品牌，这是其全球供应链的基础认证。
- **ISO 9001**（质量管理体系）和 **ISO 22000**：常见于其加工和分销环节。
- **HACCP**：用于其包装和配送中心的危害控制。
- **社会责任认证**（如Sedex/SMETA）：虽然不是直接食品安全，但大型商超（如沃尔玛、山姆）常要求。
- 在中国国内，同样具备**SC**及进境水果检验检疫证明（如有进口业务）。

---

**如何精准核实？**
由于资质会随门店、产品线（如鲜果、即食沙拉、果汁）和认证有效期而变化，建议您按以下方式确认：

1. **直接索取**：要求供应商提供**最新的认证证书扫描件**（注意查看有效期和认证范围）。
2. **查询官方数据库**：
   - 中国国内认证可查**“全国认证认可信息公共服务平台”**（认监委官网）。
   - 国际认证（如BRC、Global G.A.P.）可在其各自官网的认证目录中查询。
3. **咨询商超采购标准**：告知商超的采购经理您需要的具体资质列表，通常合同附件中会明确要求。

---

**关键提示**：
- 如果商超要求的是**特定商超自己的验厂标准**（如沃尔玛的FCCA、家乐福的IFS），请直接问供应商是否已通过该标准审核。
- 注意区分**“证书”**和**“报告”**：例如，农药残留检测报告是每批货都需要提供的，而证书是持续有效的。

请以供应商提供的纸质版扫描件或官方截图为准，避免仅依赖口头承诺。如果您需要针对合作的特定商超（如盒马、永辉、Costco）确认具体要求，可以进一步告诉我。
