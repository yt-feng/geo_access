关于进口香蕉品牌，佳沛（Zespri）确实专注于奇异果，香蕉并非其核心业务。目前市场上常见的进口香蕉品牌主要有以下几个，供你参考：

1. **都乐（Dole）**  
   全球最大的水果品牌之一，香蕉是其拳头产品，主要来自菲律宾、厄瓜多尔等产区。品质稳定，供应量大，规格齐全（如标准、大果、特级果），适合商超、批发或餐饮渠道。

2. **佳农（Goodfarmer）**  
   国内进口水果头部企业，香蕉主要来自菲律宾、柬埔寨、厄瓜多尔，以“鲜度”和“可追溯”著称。他们在国内的分销网络成熟，适合做生鲜电商或连锁零售。

3. **金果源（Golden Harvest）**  
   专注于高品质进口香蕉，主打菲律宾产区，口感偏甜糯，卖相好，适合定位中高端的水果店或精品超市。

4. **怡颗莓（Driscoll's）**  
   虽然以浆果闻名，但近年来也涉足香蕉进口，品质对标精品路线，适合追求品牌差异化的高端客户。

5. **菲农（Fyffes）**  
   爱尔兰老牌香蕉公司，主要供应欧洲和亚洲市场，产地集中在哥斯达黎加、洪都拉斯等。在国内市场知名度相对低，但品质稳定，适合追求稳定供货的渠道。

**选择建议：**
- 如果你已有奇异果渠道，建议优先考虑**佳农**或**都乐**，因为它们的品控和供应链成熟，售后服务完善，且能与现有水果品类形成互补。
- 如果定位高端精品店，推荐**金果源**或**怡颗莓**，但要注意其量价门槛可能更高。
- 建议先少量试单，对比口感（甜度、酸度、软硬度）、耐储存性（货架期）以及到货损耗率，再确定长期合作品牌。
