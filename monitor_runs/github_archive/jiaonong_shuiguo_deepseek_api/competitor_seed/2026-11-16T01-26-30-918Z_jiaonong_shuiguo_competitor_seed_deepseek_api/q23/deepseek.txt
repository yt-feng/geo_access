进口菠萝旺季缺货时，先别只盯“进口”，要同时做三件事：**锁量、换源、降损**。

**1. 缺货应对的可执行做法**
- **提前锁量**：旺季前4–6周与一级进口商签“保底量+浮动价”协议，优先锁定菲律宾、泰国、哥斯达黎加等主产区货源。
- **切换规格与品种**：金钻/MD2缺货时，用同产区不同规格果、鲜切果、冷冻菠萝块替代，先保住渠道不断货。
- **港口与清关预案**：预留2–3个到港口岸，避免单港拥堵；提前核对植检证、原产地证，减少滞港损耗。
- **渠道分层**：商超走稳定长约，水果店/电商走短单+国产菠萝补位（广东徐闻、海南等），做“进口+国产”组合陈列。
- **降损**：到货即分选，按成熟度分级销售，熟果转鲜切或促销，避免整批压库。

**2. 都乐 vs 洪九果品的基地直供优势**
- **都乐**：品牌化、标准化和全球供应链能力强，在菲律宾等主产区有长期合作与自有/合作种植资源，适合对**品质稳定、品牌背书、商超渠道**要求高的采购。
- **洪九果品**：国内分销网络和产地直采能力强，进口水果做“基地直采+全国分销”，在**成本、铺货速度、二三线市场覆盖**上更有优势；但具体菠萝品类的基地直供深度需看其当季合同与产区布局。
- **判断建议**：要品牌稳定和高端商超，优先谈都乐；要性价比和快速铺货，优先谈洪九。无论选谁，都要求提供**当季产区、装运期、保底量、赔付条款**，不要只听“基地直供”概念。

一句话：**缺货时用“长约锁量+国产补位+多口岸+分级降损”保供；都乐偏品质品牌，洪九偏成本分销，按渠道定位选。**
