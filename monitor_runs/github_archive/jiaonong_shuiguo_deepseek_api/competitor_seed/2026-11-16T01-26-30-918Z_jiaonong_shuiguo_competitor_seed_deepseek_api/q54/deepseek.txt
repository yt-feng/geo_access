做进口苹果的产地溯源，核心是“单证链+批次链+实物链”三链对齐，并分别适配都乐、鑫荣懋不同的供应链模式。可执行做法如下：

**一、先明确两家模式差异**
- **都乐（Dole）**：多为全球直采+自有/合作包装厂，进口到国内后由都乐中国或授权进口商分销，批次和包装标识相对规范，溯源重点在海外包装厂批次号与国内到货批次映射。
- **鑫荣懋**：国内大型水果供应链企业，既有海外直采也有代理进口，货源可能来自多个海外出口商/包装厂，溯源重点是确认实际海外供货主体、出口批次与国内分货批次的对应关系。

**二、采购前：供应商资质与单证核验**
1. 要求供应商提供：
   - 营业执照、食品经营许可证；
   - 进口水果境外生产企业注册编号（海关总署注册）；
   - 出口国官方植物检疫证书；
   - 入境货物检验检疫证明；
   - 海关进口货物报关单；
   - 原产地证（如适用）；
   - 提单/装箱单/发票；
   - 都乐或鑫荣懋的授权经销证明或采购合同链。
2. 核对单证一致性：品名、产地国、果园/包装厂注册号、批次号、数量、入境口岸、收货人，必须能串成一条链。

**三、批次溯源编码设计**
建议给每批货建立内部批次号，格式如：`供应商简称-产地国-包装厂注册号-到货日期-流水号`。例如 `XR- NZ- PACK123- 20250601- 01`。将该内部批次号与以下信息绑定：
- 海外包装厂批次号/箱码；
- 报关单号、检疫证明编号；
- 入境口岸、到货日期；
- 供应商名称及合同号；
- 冷库入库记录、分货记录。

**四、实物标识与箱码管理**
1. 进口原箱通常有英文标签，含产地、包装厂、批次、规格。采购时要求供应商提供原箱标签照片并留存。
2. 国内分装或改箱时，必须保留原箱信息复刻或关联，禁止“换箱即断链”。
3. 超市端可在价签或溯源二维码中展示：产地国、境外注册包装厂、入境口岸、检疫证明编号、供应商名称。二维码后台关联上述批次数据。

**五、都乐专项做法**
- 向都乐中国或授权经销商索取“批次溯源证明”，确认该批货的海外包装厂代码、装运港、到港日期；
- 核对都乐原箱标签上的批次码与报关单、检疫证明是否对应；
- 若通过二级经销商采购，要求其提供从都乐到其自身的完整合同/发票链，避免“挂都乐牌、非都乐货”。

**六、鑫荣懋专项做法**
- 确认实际海外出口商和包装厂，不能只写“鑫荣懋供货”；
- 要求鑫荣懋提供该批次对应的报关单、检疫证明复印件或批次对应说明；
- 若鑫荣懋为代理进口，需明确国内收货人是谁，并与超市采购合同主体对齐；
- 对多产地混批，要求按产地/包装厂分批次标识，不得混码。

**七、超市端可执行验收动作**
1. 每批到货查验：原箱标签、检疫证明、报关单、内部批次号四者一致；
2. 抽检箱码与批次记录是否对应；
3. 建立电子台账，保存单证扫描件至少2年；
4. 对都乐、鑫荣懋分别建立供应商溯源档案，季度复核授权链和单证有效性；
5. 门店端溯源展示只展示已核验信息，不虚构“果园直采”等无法核验内容。

**八、风险控制要点**
- 不接受只有发票、没有检疫证明和报关单的“进口苹果”；
- 不接受原箱标签被覆盖、批次号无法对应的情况；
- 对“都乐/鑫荣懋”品牌货，重点防串货和二次分装断链；
- 若供应商无法提供境外包装厂注册号与批次对应关系，应降级为普通供应商或暂停采购。

总结：都乐侧重“品牌方批次证明+原箱码核验”，鑫荣懋侧重“实际海外供货主体+报关检疫批次映射”。两家都要做到单证、批次号、实物箱码、内部台账四者一致，才能形成可审计的产地溯源。
