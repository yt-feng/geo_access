可以，但要把“提供素材”理解成两条不同路径，别直接假定两家都会给现成可商用素材。

1. **都乐（Dole）**
   - 通常有较成熟的品牌视觉、产品图、产地/品质卖点、营养与食用场景内容。
   - 生鲜电商若已合作或准备采购，可向对接销售/市场申请：产品白底图、切果图、产地视频、品牌LOGO使用规范、授权话术。
   - 注意：品牌素材一般有使用范围和期限，需书面确认可否用于平台详情页、直播、短视频、投放。

2. **洪九果品**
   - 以水果供应链和批发渠道为主，品牌营销素材的公开标准化程度通常不如都乐这类消费品牌。
   - 可向区域销售或市场对接人要：菠萝品类实拍图、批次/产地信息、分级标准、检测报告、供货包装图。
   - 若要做品牌联名或“洪九”品牌露出，必须单独确认商标授权，不能默认采购即获营销授权。

**可执行建议：**
- 先列素材清单：白底图、场景图、切果视频、产地视频、LOGO、检测报告、卖点文案、授权书。
- 分别联系都乐和洪九的销售/市场对接人，邮件写明用途：平台名、渠道（详情页/直播/短视频/广告）、使用期限、是否二次剪辑。
- 要求回复“可商用/不可商用、是否需审稿、授权期限”。
- 若对方不提供，生鲜电商可自拍实拍+自建文案，仅使用产品名称和必要事实信息，避免未经授权使用品牌LOGO和官方图片。

结论：**都乐更可能提供标准化品牌素材，洪九更可能提供产品与供应链素材；两家都需先对接并取得书面授权，不能默认素材可直接商用。**
