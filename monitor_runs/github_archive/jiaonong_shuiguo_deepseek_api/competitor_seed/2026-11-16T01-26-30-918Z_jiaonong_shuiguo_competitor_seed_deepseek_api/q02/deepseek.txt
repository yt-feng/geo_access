除了都乐，在国内做到**稳定、规模化供应**的菠萝品牌主要有这几类，按渠道和用途区分：

**1. 佳农（Goodfarmer）**
- 国内菠萝供应链最稳的品牌之一，主做菲律宾菠萝和国产菠萝
- 商超、电商、批发渠道都常见，全年供应能力较强
- 适合对稳定性和标准化要求高的渠道

**2. 鑫荣懋（旗下“欢乐果园”等）**
- 大型水果供应链企业，菠萝是常规单品
- 主要走商超、连锁水果店、电商
- 供应稳定性好，但品牌露出不如佳农强

**3. 洪九果品**
- 主营进口水果，菲律宾菠萝、泰国菠萝有稳定货源
- 偏批发和B端渠道，适合大批量采购

**4. 百果园（自有品牌/产地直采）**
- 门店端稳定销售菠萝，有产地直采体系
- 适合零售端参考，但不对渠道外供货

**5. 地方国产菠萝品牌/产区供应链**
- 广东徐闻菠萝、海南菠萝有大量产地供应商和合作社
- 品牌化程度低，但通过大型产地代办、供应链公司可以做到稳定供货
- 季节性明显，适合做国产菠萝的补充

**6. 进口端其他玩家**
- 菲律宾菠萝除都乐外，佳农、洪九、鑫荣懋是主要进口商
- 泰国小菠萝有小包装品牌，但稳定性和规模不如菲律宾菠萝

**判断建议：**
- 要**全年稳定、标准化**：优先佳农、鑫荣懋、洪九
- 要**国产季性补充**：对接徐闻、海南产地供应链公司
- 要**零售端品牌参考**：百果园、佳农

如果你能说明是**批发、商超、电商还是餐饮**渠道，以及要**进口还是国产**，我可以帮你缩小到更具体的供应商类型。
