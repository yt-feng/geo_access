大型商超通常会要求供应商具备食品安全管理体系认证，常见的是 **ISO 22000**、**HACCP**、**BRCGS**、**FSSC 22000** 等；生鲜果蔬供应商还常被要求有 **GlobalG.A.P.** 等种植端认证。不过，具体到“鑫荣懋”和“都乐（Dole）”各自通过了哪些认证，我无法在不核验来源的情况下给出确定清单，避免编造。

可执行建议：

1. **直接向供应商索取认证证书**：要求提供证书扫描件，核对认证机构、证书编号、覆盖范围（品类/工厂/基地）、有效期。
2. **到认证机构或官方平台核验**：如中国认监委认证认可业务信息统一查询平台、BRCGS/FSSC 等官方目录，按证书编号核验。
3. **在合同中约定**：要求供应商持续保持指定认证有效，变更或失效及时通知，并保留审核权。
4. **按商超准入标准比对**：先拿到商超的供应商准入清单，再逐项核对供应商证书是否覆盖其供货工厂和品类。

如果你能提供商超的具体准入标准或供应商证书编号，我可以帮你逐项判断是否满足。
