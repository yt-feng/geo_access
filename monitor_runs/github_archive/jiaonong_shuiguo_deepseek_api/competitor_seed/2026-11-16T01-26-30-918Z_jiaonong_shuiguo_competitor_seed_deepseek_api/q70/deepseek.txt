可以找，但要把“供应商有没有”与“具体批次能不能提供”分开判断。都乐（Dole）和鑫荣懋都属于大型香蕉品牌/供应链企业，通常具备较规范的产地管理、质量体系和追溯能力，但公开渠道不一定能直接核验每一批货的完整证明文件。建议按下面方式确认：

1. **先明确你要的证明清单**
   - 产地证明：果园/产区、采摘批次、包装厂信息
   - 追溯文件：批次号、箱码/托盘码、出入库记录
   - 品控证明：农残检测报告、重金属/微生物等按需检测、质量检验单、ISO/HACCP/GLOBALG.A.P.等体系证书
   - 进口/流通文件：报关单、检验检疫证明（进口香蕉）、供货商资质

2. **向都乐、鑫荣懋询价时直接问**
   - “该批次能否提供产地证明和批次追溯码？”
   - “品控报告是第三方检测还是企业自检？报告日期和批次是否对应？”
   - “是否支持到货抽检、不合格退换货？”
   - “能否提供体系证书和供货商营业执照/食品经营许可证？”

3. **判断标准**
   - 能提供**批次对应**的检测报告和追溯信息，才算真正可溯源
   - 只有企业宣传页、体系证书，但不能对应具体批次，不足以作为品控证明
   - 优先选择愿意在合同中写明“随货提供批次检测报告、产地证明、追溯信息”的供应商

4. **补充渠道**
   - 都乐、鑫荣懋可通过其官网/官方客服、区域销售或大型批发市场经销商联系
   - 同时可对比佳农、鲜丰水果供应链、当地一级批发商等，要求同样文件
   - 若做商超/电商，建议把“批次追溯+第三方农残检测+到货验收标准”写入采购合同

结论：都乐和鑫荣懋大概率具备相关体系和能力，但能否提供你要的“产地溯源和品控证明”，必须以具体区域销售和具体批次书面确认为准。不要只看品牌，重点看**批次对应文件**和**合同约束**。
