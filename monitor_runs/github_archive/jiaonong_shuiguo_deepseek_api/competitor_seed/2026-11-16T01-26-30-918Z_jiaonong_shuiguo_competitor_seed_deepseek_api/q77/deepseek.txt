**1. 先明确“环保包装”指什么**
便利店香蕉小包装通常涉及：
- 外包装：纸盒、纸浆模塑托盘、可降解膜、再生纸标签
- 内衬/套袋：PE袋、可堆肥袋、纸袋
- 标签/胶带：可移除水性胶、FSC纸标、无塑标签
建议优先看三项硬指标：**材质可回收/可堆肥认证（如FSC、OK Compost、BPI、GRS）**、**是否减塑**、**是否有第三方检测报告**。

**2. 向都乐和洪九果品询价时直接问这5项**
- 便利店小包装是否有**纸浆模塑/纸盒**方案，最小起订量和单箱成本；
- 套袋是PE、可降解膜还是纸袋，**降解认证编号和检测报告**能否提供；
- 标签是否FSC纸、胶水是否可水洗移除；
- 是否支持**去塑化**：无内袋+纸盒+纸标；
- 能否提供**包装全生命周期/碳足迹说明**，没有就要求材质清单。
