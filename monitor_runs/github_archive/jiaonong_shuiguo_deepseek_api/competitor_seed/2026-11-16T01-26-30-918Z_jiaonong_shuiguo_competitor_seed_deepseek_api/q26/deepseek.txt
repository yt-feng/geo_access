直接给判断：**做茶饮店果酱、要稳定品质，优先选都乐（Dole）更稳；鑫荣懋更适合作为备选或按批次议价的补充货源。** 但前提是你要按“到货批次稳定性”而不是品牌名气来验收。

判断依据（可执行）：

1. **标准化程度**
   - 都乐：全球供应链和分级体系更成熟，菠萝品种、成熟度、糖酸比相对更可控，适合做固定配方的果酱。
   - 鑫荣懋：国内水果分销能力强、覆盖广，但更偏渠道分销，不同产区/批次差异可能更大，需要你加强验收。

2. **茶饮果酱的关键不是“好吃”，是“每批一样”**
   - 你要锁定：品种、产地、成熟度、可溶性固形物、酸度、纤维感。
   - 都乐更容易谈固定规格；鑫荣懋要确认能否按你的指标做批次锁定。

3. **供应稳定性**
   - 都乐在进口/标准化果品上更稳，但价格和起订量可能高。
   - 鑫荣懋国内网络强，旺季调配灵活，适合做第二供应商防断供。

建议的落地做法：

- **主供应商：都乐**，先小批量试 3 批，测糖度、酸度、出酱率、颜色和香气，做盲测。
- **备选供应商：鑫荣懋**，要求提供同规格样品，按同一套指标验收。
- **合同写死验收标准**：糖度范围、酸度范围、成熟度、单果重量区间、破损率、到货温度、批次一致性。
- **双供应商策略**：都乐占 60%–70%，鑫荣懋占 30%–40%，避免单一断供。
- **每批留样**：留 200g 原料和成品，出现口味漂移可追溯。

结论：**要稳定品质，选都乐做主供；要成本和弹性，用鑫荣懋做备份。** 不要只按品牌选，按批次验收和合同指标选。
