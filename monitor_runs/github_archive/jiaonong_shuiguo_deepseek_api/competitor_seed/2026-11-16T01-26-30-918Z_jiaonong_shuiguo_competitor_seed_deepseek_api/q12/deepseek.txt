1. **先锁定你要的规格**
   - 单根独立包装：适合收银台冲动购买，通常要求单根重量稳定、外观无伤。
   - 2–3根小把装：适合早餐/即时消费，需明确单把净重区间（如300–500g，按你门店实际定位定）。
   - 迷你香蕉/小米蕉小盒装：适合差异化，但供应稳定性通常不如常规香蕉。
   - 建议同时约定：单根/单把重量公差、成熟度（如3–4号色）、到店货架期、破损率上限。

2. **向鑫荣懋和都乐分别这样询价**
   - “是否有便利店渠道的小包装香蕉：单根独立包装、2–3根小把装、迷你蕉盒装？”
   - “可提供的单根/单把净重区间、成熟度、包装形式、每箱数量、最小起订量、配送频次、报价？”
   - “能否提供样品和当前包装规格书/产品目录？”
   - 要求对方书面确认**当前可稳定供应的规格**，不要只接受口头“可以做”。

3. **判断哪家更适合**
   - 若你要全国门店稳定供货：优先看都乐、鑫荣懋这类品牌商的标准化小包装能力和配送覆盖。

   - 便利店核心不是“有没有小包装”，而是**单根重量稳定、成熟度可控、破损率低、补货频次匹配**。

4. **建议的验证动作**
