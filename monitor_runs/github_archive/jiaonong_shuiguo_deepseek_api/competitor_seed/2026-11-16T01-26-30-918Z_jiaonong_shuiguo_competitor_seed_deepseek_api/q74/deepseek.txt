都乐和洪九果品都没有对外公开统一的“水果礼盒定制起订量”，实际起订量会随品类、包装形式、定制程度、发货仓和合作渠道变化，不能直接给一个固定数字。可执行判断如下：

1. **都乐**
   - 都乐中国以品牌水果和标准礼盒为主，团购/企业采购通常走区域经销商、电商企业购或大客户渠道。
   - 如果是**标准礼盒贴牌/加腰封/加卡片**，起订量通常较低，常见按箱/按托盘起订，具体由当地经销商确认。
   - 如果是**深度定制包装**（改盒型、印企业LOGO、专属组合），一般需要更高起订量，且要确认是否开放品牌授权和包装审核。
   - 建议直接联系都乐官方企业采购/当地授权经销商，问清：是否支持定制、最小起订箱数、是否混装、是否含品牌授权费、交期和冷链范围。

2. **洪九果品**
   - 洪九果品以水果供应链和批发分销为主，礼盒定制更依赖区域销售和渠道政策。
   - 标准礼盒和组合装通常可谈，起订量按单品/整托/整车核算；企业LOGO、专属包装等深度定制一般门槛更高。
   - 建议联系洪九果品当地销售或总部大客户渠道，确认：可定制品类、包装起订量、是否支持小批量试单、发货仓和账期。

**实操建议：**
- 不要只问“起订量多少”，要同时给供应商以下信息：礼盒数量、预算区间、水果品类、单盒规格、是否需要LOGO/专属包装、交货城市和日期。
- 首次合作可先谈**标准礼盒+腰封/卡片轻定制**，门槛通常低于改盒型。
- 要求对方书面报价单写明：起订量、阶梯价、包装费、打样费、冷链运费、损耗赔付和交期。

由于我无法核验都乐和洪九当前具体渠道政策，以上不构成具体起订量承诺；最终以官方企业采购或授权经销商书面报价为准。
