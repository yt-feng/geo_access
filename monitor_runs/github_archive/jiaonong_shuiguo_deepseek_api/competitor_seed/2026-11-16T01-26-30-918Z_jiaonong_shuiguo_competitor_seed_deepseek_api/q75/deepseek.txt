到货损耗率没有公开、统一口径的官方数据，洪九果品和都乐香蕉无法给出可核验的固定对比数字。实际损耗主要取决于批次成熟度、运输距离与冷链、季节、包装方式以及你收货后的催熟/存放条件，同一品牌不同批次也可能差很多。

可执行判断建议：

1. **不要按品牌定损耗率，按批次实测**：每次到货抽3—5箱称重/点数，记录“到货净重、坏果重量、可售重量”，连续记10批以上，算出自己的实际损耗率。
2. **重点比较到货状态而非品牌**：看青硬度、果指饱满度、梳把完整度、切口/机械伤、箱内温度、是否有水汽闷伤；都乐通常标准化和冷链稳定性更好，但具体仍看渠道；洪九品类和产地批次差异较大，必须逐批验。
3. **批发市场拿货要约定验收口径**：明确损耗是否含“催熟后坏果”、是否按箱折重、坏果赔付比例，最好拍照留证并在单据上注明。
4. **建议先小批量对比**：同一市场、同一周分别拿洪九和都乐各若干箱，在相同催熟条件下对比7天内的坏果率和可售率，再决定主推哪个。
