直接结论：**没有公开可核验的“质量稳定性”排名能证明都乐一定优于鑫荣懋或反之**。对超市采购而言，更稳的做法不是选品牌，而是选**进口来源国/品种+到货批次+验收标准+供应商退换货条款**。

可判断的建议：

1. **先看具体单品和产地**  
   都乐、鑫荣懋都更多是品牌/供应链商，苹果质量取决于具体产地、品种、采收季和冷链。比较时要限定到：比如“新西兰嘎啦”“美国红蛇果”“智利富士”，不能笼统比品牌。

2. **用批次验收数据判断稳定性**  
   建议连续看 3-5 批到货：
   - 到货硬度、糖度、酸度
   - 碰压伤、裂果、霉心、黑心病比例
   - 果径均匀度、着色均匀度
   - 货架期 7 天后的损耗率
   - 冷链断链记录  
   哪家批间波动小，哪家对你更稳定。

3. **超市采购更应约束合同**  
   在合同里写清：到货合格率、损耗率上限、抽检比例、不合格退换货、冷链温度记录、批次追溯。品牌只是加分项，条款才是稳定性保障。

4. **实操选择**  
   - 高端鲜食苹果、标准化包装：可优先试都乐，但必须按批次验收。
   - 追求性价比和本地供应链响应：鑫荣懋可重点试单。
   - 最稳妥：两家同时做小批量对比试销，用 2-3 个到货周期和损耗数据决定主供/备供。

所以：**不能简单说谁质量更稳定；应通过限定单品、连续批次验收和合同约束来判断。** 如果你能提供具体品种、产地、包装规格和近几批验收数据，我可以帮你做更具体的对比框架。
