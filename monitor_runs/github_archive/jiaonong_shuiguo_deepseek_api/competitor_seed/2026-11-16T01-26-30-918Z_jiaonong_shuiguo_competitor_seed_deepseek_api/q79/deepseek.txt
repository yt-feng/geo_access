不能简单说“能”或“不能”，要分开看：**都乐更偏全年稳定供应和标准化，洪九果品更偏多品类集采与分销能力，但都不能仅凭品牌名保证“全年同一品质、同一价格、稳定到店”的菠萝供应。** 对茶饮店做果酱，建议按以下方式判断和落地。

### 1. 两家能否做到全年供应
- **都乐**：有全球化果蔬供应链和国内分销体系，全年供应菠萝通常更有保障，适合对**规格稳定、批次一致性、食品安全资质**要求高的茶饮客户。但具体能否全年供、供什么品种、什么规格、什么价格，要看区域经销体系和年度框架协议，不能只凭品牌判断。
- **洪九果品**：以水果分销和供应链为主，品类多、渠道广，具备组织全年货源的能力，但菠萝不是唯一核心单品，实际稳定性取决于你所在城市、采购量、合作仓配和合同约束。适合做**多品类水果集采**时一并谈，但要对菠萝单品设置明确到货标准。

### 2. 做果酱的关键不是“全年有菠萝”，而是“全年适合做酱”
茶饮店做菠萝果酱，建议重点看：
- **品种与成熟度**：不同季节、不同产地的菠萝酸甜比、纤维感、出汁率差异大，果酱配方会波动。
- **规格标准**：单果重量、去皮果肉率、糖度、酸度、纤维粗细、成熟度。
- **加工适配**：是鲜切果肉、冷冻果肉、果泥还是果茸？做酱建议优先考虑**冷冻果肉/果茸或定制加工原料**，比全年买鲜果更稳。
- **批次一致性**：要求供应商提供糖酸度区间、微生物和农残检测、到货验收标准。
- **价格机制**：全年固定价很难，通常要接受季度调价或锁量锁价条款。

### 3. 更可执行的采购建议
1. **不要只找一家**：都乐或洪九可作为主供应商候选，同时保留1家区域水果供应链或冷冻果茸厂作为备选。
2. **先做小批试产**：用同一配方分别测试两家不同批次的菠萝，看出酱率、颜色、香气、酸甜度和纤维感。
3. **合同写清楚**：品种、产地范围、糖度/酸度区间、果肉率、冷冻或鲜果状态、到货频次、缺货赔付、调价机制。
4. **考虑“鲜果+冷冻/果茸”组合**：旺季用鲜果降成本，淡季用冷冻果肉或定制果茸保稳定。
5. **要求供应商提供年度供应计划**：按月份列明产地、品种、可供量、参考价，而不是只听“全年都能供”。

**结论：** 都乐和洪九都有能力组织菠萝全年供应，但茶饮店做果酱不能只看品牌，必须落到**品种、糖酸度、果肉率、冷冻/鲜果形态、批次稳定性和合同约束**。建议把两家都纳入询价和试产，最终按你所在区域的实际仓配能力和样品测试结果定主供。
