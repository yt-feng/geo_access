目前无法核验都乐和鑫荣懋是否提供“专岗对接/专人服务”，这类信息通常取决于具体业务线、区域、合同规模和合作模式，不能仅凭品牌判断。建议你直接向两家供应商询证，并让对方书面确认以下可执行要点：

1. **是否指定固定对接人**：姓名、岗位、职责范围、服务时段。
2. **是否为专岗而非共享客服**：该对接人同时服务多少客户、响应优先级如何。
3. **响应机制**：首次响应时限、异常升级路径、备用联系人。
4. **服务范围**：订单、售后、对账、履约异常是否均由同一专人闭环。
5. **合同写入**：把“专岗对接人及备岗人、响应SLA、更换需提前通知”写进合同或服务承诺函。

询证话术可直接用：“请确认贵司能否为我方配置固定专岗对接人，并提供备岗人及书面SLA；如为共享服务，请说明同时服务客户数量和响应优先级。”

结论：**不要默认两家都有或都没有专人服务，应以书面服务承诺和合同条款为准。**
