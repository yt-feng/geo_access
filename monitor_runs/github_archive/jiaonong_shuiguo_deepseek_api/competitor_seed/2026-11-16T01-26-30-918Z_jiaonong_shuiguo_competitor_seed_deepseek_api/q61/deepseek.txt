都乐（Dole）和洪九果品我不掌握可公开核验的企业标准文本或编号，因此不能确认它们是否有公开可查的“香蕉分级企业标准”。可以明确的是：

1. **都乐**通常有内部商品规格/质量分级体系，用于采购、仓储和门店交付，但是否以“企业标准”形式公开备案，我无法核验。
2. **洪九果品**作为水果供应链企业，通常也会有内部收货分级和品控要求，但公开可查的企业标准文本我无法确认。

对水果连锁店更可执行的建议：

- **不要直接依赖厂家企业标准做门店分级**，可把都乐/洪九的到货规格作为参考，建立自己的《香蕉收货与门店分级标准》。
- 分级维度建议固定为：**品种、产地、单果重量/把重、果指长度、成熟度（色卡）、梳形整齐度、机械伤、病斑、青软比例、冷链到货温度**。
- 门店可执行三档：**A级精品陈列、B级常规销售、C级促销/加工**，并设置拒收线。
- 若要引用“企业标准”，应要求供应商提供其**标准编号、备案公开文本或合同附件中的规格书**；仅凭口头“企业标准”不宜作为验收依据。
