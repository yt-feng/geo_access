可以先把“靠谱”拆成四件事来判断：供货稳定性、到港与催熟能力、质量一致性、商务条款与风险。就你超市的场景，我给一个可执行的判断框架和倾向性建议。

**结论先说：**
- 如果你要的是**全国性、标准化程度高、品控和到货节奏稳**的进口香蕉供应，**都乐（Dole）通常更稳**，适合对卖相、规格一致性、促销档期要求高的超市。
- 如果你更看重**国内渠道覆盖、灵活拼柜/多产地切换、区域配送响应**，**鑫荣懋在部分区域和部分品类上更有优势**，但香蕉的稳定性要按“具体区域分公司+具体产地+具体规格”去核，不能只看品牌。

**建议你用下面5项做招标/试单对比：**

1. **产地与季节切换方案**
   - 问清：菲律宾、厄瓜多尔、越南、柬埔寨等产地如何切换；某产地断供时替代方案是什么。
   - 都乐全球产地多，切换通常更成熟；鑫荣懋国内分销强，但要看当地分公司实际掌握的一手货源。

2. **到港+催熟+配送链路**
   - 进口香蕉关键不是“到港”，而是**催熟库能力、成熟度控制、冷链配送频次**。
   - 要求供应商明确：催熟库位置、到你门店的配送频次、断货补货时效、节假日保供方案。
   - 这一项比品牌更重要。谁在你所在城市有催熟库和稳定日配，谁就更靠谱。

3. **质量一致性指标**
   - 不要只问“好不好”，要写进合同：果指长度/粗度、每箱净重、青果硬度、到店成熟度、黑斑率、掉把率、拒收标准。
   - 先做**2—4周试单**，按门店真实损耗率对比，而不是按报价对比。

4. **价格与商务条款**
   - 比“到岸价”没意义，要比**到店综合成本**：报价+损耗+配送费+退换货+账期。
   - 账期、破损赔付、临期/过熟处理、促销档期锁价能力，都写进框架协议。

5. **区域落地能力**
   - 鑫荣懋和都乐都是全国性玩家，但**具体到你的城市，服务能力取决于当地分公司/经销商**。
   - 建议同时约两家当地负责人，要求提供：本地在供超市名单（可脱敏）、催熟库地址、配送车辆与频次、应急联系人。

**实操建议：**
- 不要二选一直接定年度供应商。先**双供应商试单**：都乐为主供，鑫荣懋为备供/区域补充，或反过来，按你门店所在区域的实际响应定。
- 试单周期建议**4周**，覆盖一个完整补货周期和一个周末促销档。
- 评分表权重建议：供货稳定性30%、质量一致性25%、到店综合成本20%、催熟配送能力15%、商务条款10%。

**一句话：** 全国标准化选都乐更稳；区域灵活性和国内渠道响应看鑫荣懋当地团队。最终用“本地催熟库+试单损耗+保供条款”三项定，不要只凭品牌拍板。
