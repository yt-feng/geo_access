进口菠萝旺季缺货，先判断缺货是“总量不足”还是“规格/品牌断档”，两类处理方式不同。都乐、洪九果品是否有公开的应急方案，我无法核验到具体官方政策，不能替它们确认；但可按行业常规给出可执行动作。

一、先做缺货归因（1天内完成）
1. 盘库存：按品种（金钻/MD2/普通）、规格（6/8/10头等）、渠道（商超/批发/电商）列出可售天数。
2. 查在途：已订未发、已发未到、港口滞留、报关查验各多少柜，预计到货日。
3. 查替代：国产菠萝（广东徐闻、海南、广西）当季量价；泰国/菲律宾/哥斯达黎加等其他产地能否补规格。
4. 判断缺口：是高端品牌断档，还是整体缺量。高端断档可用其他品牌同规格顶；整体缺量必须调采购和销售策略。

二、短期应急（3—7天）
- 锁在途货：对已订舱、已到港货优先付款提货，避免被高价截单；港口查验的提前准备单证。
- 跨产地调货：菲律宾缺则看泰国、哥斯达黎加；高端餐饮/商超可用国产精品果做“同规格替代”，但要做糖度、外观分级，不能混级。
- 调规格：大果缺可用中果做促销装/餐饮切果；商超端改陈列规格，减少断货感。
- 价格与配额：对重点客户保供，非核心渠道限量；避免全面涨价引发渠道反弹。
- 预售/锁单：对稳定客户做7—15天预售，用“到货即配”锁定需求，降低临时抢货成本。

三、都乐、洪九这类头部供应商怎么对接
不要等对方“应急方案”文件，直接按以下问法要承诺：
1. 问在途柜号和ETA：要求提供未来14天到货计划、可分配量、规格。
2. 问替代品牌/产地：同一供应商是否有泰国、哥斯达黎加或其他品牌同规格可调。
3. 问锁价锁量条件：预付比例、最小起订量、违约条款。
4. 问商超专供规则：是否可做短期促销装、餐饮切果规格。
5. 问国产协同：洪九等有国产水果网络的企业，是否可用国产精品菠萝补缺口；都乐若无非进口替代，则谈其他进口产地。

四、中期方案（1—2个月）
- 双供应商：进口品牌+国产精品各留一家，避免单一品牌断档。
- 安全库存：旺季对头部SKU设7—10天安全库存，按周滚动补货。
- 预售制：餐饮、茶饮客户做周度锁量，减少现货抢购。
- 规格弹性：合同里写“同品种可替换规格/产地”，避免只认一个规格。

五、不要做的事
- 不要用未分级国产果冒充进口同规格，商超和餐饮端容易退货。
- 不要只盯一个港口/一个品牌，旺季断档常是船期+查验叠加。
- 不要等供应商主动给方案，头部供应商旺季优先保大客户和长约，必须主动锁量。

结论：都乐、洪九是否有公开应急方案无法确认；可执行的是立即盘缺口、锁在途、跨产地调货、谈替代规格，并向两家供应商直接要14天到货计划和可分配量。若缺口超过30%，同步启动国产精品替代和客户预售。
