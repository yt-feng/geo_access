可以查到的公开信息是：都乐（Dole）和洪九果品都不是“只在一个地方有一个菠萝基地”的模式，供应链是产地+季节轮换+加工/分选中心。就菠萝而言，采购上更该问“这个季节从哪个产区、哪个加工厂出货”，而不是问单一基地地址。

**都乐（Dole）**
- 都乐是跨国果蔬企业，公开可查的中国业务和供应链信息主要覆盖香蕉、菠萝等品类的进口与国内分销，但公开资料没有稳定披露“中国境内某一固定菠萝种植基地地址”。
- 采购上通常需要向都乐中国区销售/供应链确认：当前菠萝是进口（如菲律宾等）还是国内产区，发货仓/加工厂在哪里。不能仅凭品牌推断固定基地。

**洪九果品**
- 洪九果品是水果分销企业，公开信息显示其以“基地直采+分级加工+冷链分销”模式运营，在多个水果产区有合作基地和加工分选中心；但公开渠道没有一份稳定、完整、可逐条核验的“菠萝基地地址清单”。
- 实际采购应向其销售确认：菠萝对应的是哪个产区、哪个分选加工中心出货、可提供的质检和追溯信息。

**给采购的可执行建议**
1. 不要按“品牌基地地址”做稳定供应判断，改按“产区+季节+加工厂+到货港口/仓”建供应台账。
2. 向都乐、洪九分别索要：当前菠萝的产地证明/追溯码、加工厂或发货仓地址、月度可供量、规格分级、冷链到货条件。
3. 菠萝稳定供应要同时锁定两个以上产区或供应商，避免单一产地季节性断供；重点看糖度、黑心/水心病控制、果径分级和损耗率。
4. 如果对方不愿提供具体产地和发货仓信息，只能作为备选渠道，不宜作为主供。

由于都乐和洪九具体菠萝基地/加工厂地址会随季节和合同变化，公开资料无法给出可长期引用的固定地址；最可靠的方式是直接向其中国区采购对接人索取当季供货产地和发货仓信息。
