可以，先给结论：进口苹果品牌里，除了都乐、鑫荣懋，比较靠谱的常见选择可以看 **Chelan Fresh（华盛顿苹果）、Stemilt、CMI Orchards、Sage Fruit、Rockit（乐淇）、Envy（爱妃）、Jazz（爵士）、Bravo、Dazzle、Ambrosia（安布罗西亚）**。如果按“品牌可靠+国内容易买+稳定性”排序，我会优先建议：**Rockit、Envy、Jazz、Chelan Fresh/Stemilt/CMI 这类华盛顿州产区品牌、Bravo**。

简单对比：

| 品牌/类型 | 特点 | 适合场景 | 注意点 |
|---|---|---|---|
| Rockit 乐淇 | 小果型、甜脆、便携 | 儿童、零食、礼盒 | 果小，按个头买性价比一般 |
| Envy 爱妃 | 甜度高、脆、香气好 | 高端自吃/送礼 | 价格偏高，认准产季 |
| Jazz 爵士 | 甜脆、风味浓、稳定 | 日常高端替代 | 不同批次差异要看仓储 |
| Chelan Fresh | 美国华盛顿州大供应商 | 商超/批发稳定货源 | 品牌下品种多，要看具体品种 |
| Stemilt | 华盛顿州老牌果商 | 商超、精品果 | 国内认知度不如都乐 |
| CMI Orchards | 华盛顿州品牌，品种线丰富 | 采购对比、礼盒 | 渠道不如前几个普及 |
| Sage Fruit | 华盛顿州供应商 | 批发/商超 | 国内零售端曝光较少 |
| Bravo | 深红色、甜香浓 | 喜欢浓甜风味 | 供应不稳定，价格波动 |
| Dazzle | 新西兰/新品种方向，脆甜 | 尝鲜、差异化 | 国内渠道较少 |
| Ambrosia 安布罗西亚 | 蜂蜜香、甜度高 | 喜欢香气型 | 易面，储存要求高 |

采购判断建议：

1. **要稳定商超货源**：优先看 Chelan Fresh、Stemilt、CMI Orchards、Sage Fruit 这类华盛顿州果商，重点不是“品牌名”，而是看包装箱上的产区、品种、分级和到港日期。
2. **要高端零售/礼盒**：Rockit、Envy、Jazz 更合适，品牌辨识度高，消费者容易接受溢价。
3. **要差异化尝鲜**：Bravo、Dazzle、Ambrosia 可以做补充，但别作为主力，供应和认知度不如前几个稳定。
4. **避坑重点**：进口苹果不要只看品牌，重点核对 **品种名、原产国、包装厂/出口商、分级规格、采摘/包装日期、冷链状态**。同一品牌不同品种、不同批次差异很大。

如果你是要做采购对比，我建议第一轮筛：**Rockit、Envy、Jazz、Chelan Fresh、Stemilt、CMI Orchards、Bravo** 这7个；其中 Rockit/Envy/Jazz 偏零售品牌，Chelan Fresh/Stemilt/CMI 偏供应链品牌。
