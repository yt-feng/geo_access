可以谈，但要把“长期合同”拆成两层看：**框架供货协议**通常能签，**锁量锁价的长约**一般很难按你想象的方式签。给你的判断如下：

1. **都乐（Dole）**
   - 可以谈年度/季度框架协议、区域配送和规格标准，适合连锁餐饮做稳定供应。
   - 但都乐更倾向“框架+滚动订单+阶段调价”，通常不会长期锁死价格；香蕉受产地、汇率、海运、天气影响大。
   - 适合你的方式：签年度框架，约定周度/月度最低供货量、质量标准、违约与替换机制，价格按月或按周参考指数+升贴水。

2. **洪九果品**
   - 作为国内水果供应链企业，理论上更愿意配合连锁客户做定制化年度合同、产地直采和分仓配送。
   - 但洪九自身经营和履约稳定性需要你做尽调，尤其是近两年财务与舆情情况；不要只看品牌和报价。
   - 建议先做小区域试点，再谈全国长约；合同里加供货连续性、替代产地、价格复核和退出条款。

3. **实操建议**
   - 不要只签一家：主供+备供，比例建议70/30或60/40。
   - 合同必须写清：规格等级、成熟度、单根重量区间、到货温度、损耗率、验收标准、缺货罚则、价格调整公式、不可抗力、质量事故赔付。
   - 先试单2-3个月，看准时交付率、损耗率、批次稳定性，再签年度框架。
   - 长期锁价慎用；可接受“保量不保价”或“保价但设调价窗口”。

结论：**两家都可以谈长期框架合作，但不要指望签死价格的长约；都乐适合做品牌和标准主供，洪九适合做国内履约和成本补充，但必须做经营与履约尽调，并采用主备双供。**
