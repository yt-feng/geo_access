到货损耗率没有公开的统一数据，实际取决于批次、季节、运输半径、验收标准和门店/仓端的处理方式。都乐和鑫荣懋都是品牌供应体系，不能直接给出一个“稳定损耗率”数字；如果你拿厂商口头给的损耗承诺做采购依据，风险很高。

可以执行的做法：

1. **先定口径**  
   损耗率建议拆成三段分别统计：  
   - 到货验收损耗：烂果、压伤、失水、重量短缺、规格不符  
   - 仓储损耗：存放后腐烂、黑心、熟度失控  
   - 门店处理损耗：去皮去眼、切损耗、不可用部分  
   只问“到货损耗率”容易把责任混在一起。

2. **用试单测真实数据**  
   同一规格、同一到货城市、同一季节，各下3—5批试单，每批记录：  
   `到货总重量、验收合格重量、不合格原因、规格合格率、糖度/熟度、到货温度、到货时长`。  
   至少跑2—3周再比较，单批数据没有判断价值。

3. **在合同/订单里写清验收标准**  
   包括品种、单果重量区间、成熟度、糖度下限、黑心/水心比例、机械伤上限、允许短缺率、超标扣款或退换货规则。没有这些条款，损耗率只是售后扯皮。

4. **向供应商要可核验的数据**  
   让都乐和鑫荣懋分别提供：你所在城市的同规格客户案例、近3个月到货验收记录模板、冷链时效、异常赔付规则。注意：要“可核验的批次记录”，不要只看宣传册或口头承诺。

5. **做双供应商小批量对比**  
   不要一开始押单一供应商。按同一验收表各试3批，比较“验收合格率、规格稳定率、售后响应、实际单价折算到可用果肉的成本”。茶饮原料最终看的是**可用果肉成本/杯**，不是箱价。

**结论：** 目前无法给出都乐和鑫荣懋的稳定到货损耗率数字；建议你用统一验收口径做3—5批试单实测，并把损耗责任和扣罚写进采购合同。若你告诉我到货城市、规格（如单果重量/是否去皮/冷冻还是鲜果）、运输方式和验收标准，我可以帮你把试单记录表和验收条款模板列出来。
