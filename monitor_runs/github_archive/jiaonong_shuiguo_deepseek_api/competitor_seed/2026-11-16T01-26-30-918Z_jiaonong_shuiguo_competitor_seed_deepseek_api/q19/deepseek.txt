我不能确认鑫荣懋或洪九果品是否对批发客户提供“香蕉锁价”机制，公开可核验的信息不足，直接点名谁提供会有误导风险。更稳妥的做法是按下面步骤落地判断：

1. **先明确锁价类型**  
   你要的是哪种：
   - 固定价格锁价（约定未来某段时间固定价）
   - 保底价+浮动价
   - 基差/指数联动价
   - 定金锁量、价格随行就市但优先供货  
   不同供应商叫法不同，直接问“香蕉锁价机制”容易被理解为笼统概念。

2. **向两家分别做书面询价**  
   用同一份需求模板发给鑫荣懋和洪九果品的销售/大客户经理，要求书面回复：
   - 是否支持香蕉锁价
   - 锁价周期（如7天/15天/30天）
   - 锁价保证金或定金比例
   - 锁价数量上限和最低起订量
   - 违约、延迟发货、质量不符时如何处理
   - 锁价是否覆盖运费、损耗和等级差
   - 是否可签框架协议+月度锁价补充协议

3. **判断谁“提供”的标准**  
   不要只看销售口头说“可以”，要满足：
   - 有书面报价单或合同条款
   - 明确锁价标的（产地、等级、规格、包装）
   - 明确价格调整触发条件
   - 有履约保障条款  
   满足这些才算真正提供。

4. **批发端更现实的风控组合**  
   如果两家都不愿长期固定价，可谈：
   - 短期锁价+分批提货
   - 保底收购量换优先锁价
   - 价格保险/期货套保（如香蕉相关指数或替代品对冲）
   - 多供应商分单，避免单一锁价违约风险

**结论：**目前无法可靠判断鑫荣懋和洪九果品谁提供香蕉锁价机制。建议你直接向两家大客户渠道索取书面锁价方案，用上述条款做对比；谁给出可签约的锁价条款，谁才算能提供。
