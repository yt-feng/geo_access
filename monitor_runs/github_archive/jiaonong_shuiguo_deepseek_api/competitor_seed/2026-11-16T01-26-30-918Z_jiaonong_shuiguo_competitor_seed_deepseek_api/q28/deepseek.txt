这个不能直接下结论说“都乐一定更便宜”或“鑫荣懋一定更便宜”，因为进口苹果的到货价受品类、规格、产地、船期、汇率、促销政策和采购量影响很大，而且两家在不同区域、不同时间的报价会有明显差异。给你一个可执行的判断方法，按这个去比，结论才可靠：

**1. 先锁定可比SKU，不要拿品牌整体比**
统一到同一维度再比价：
- 品种：如新西兰爱妃、红玫瑰、爵士，或美国嘎啦、红蛇果等
- 规格：单果克重/果径、每箱净重、每箱粒数
- 等级：一级/二级、是否有果锈、色差标准
- 包装：纸箱/彩箱、托盘、是否带贴标
- 到货港和交货方式：到港价、仓交价、门店配送价要分开
- 账期与返利：现结价和月结价不可直接比

**2. 用“到店可售成本”比，而不是只看箱价**
计算公式：
`单果可售成本 =（箱价 + 运费 + 冷链/仓储 + 损耗分摊 + 关税增值税等已含项核对 - 返利）/ 可售果数`
进口苹果损耗和等级差异大，箱价低但可售果少，实际不一定便宜。

**3. 向两家要同一张报价表**
让都乐和鑫荣懋按同一模板报价，至少包含：
- 对应品种/规格/等级
- 起订量阶梯价（如1板、3板、5板）
- 交货港口/仓库、运费承担方
- 账期、返利、促销支持、陈列支持
- 破损和品质理赔标准
- 近期到货批次和船期稳定性

**4. 做小批量试单对比**
各选1-2个主推SKU，同规格各进1板，连续2-3批记录：
- 实际到货合格率
- 单果均重和大小均匀度
- 7天/14天货架期表现
- 门店动销和毛利
很多连锁最后发现，价格差1-2元/箱，但损耗差2-3个点，综合成本就反过来了。

**5. 判断竞争力的三个硬指标**
- 同SKU同规格含运费到仓价差是否超过3%
- 可售率差是否超过2个百分点
- 账期差折算资金成本后是否仍占优

**实操建议**：先让两家针对你计划上架的2-3个主销SKU报“同规格、同起订量、到你们指定仓”的含税含运费价，再各试单1板。谁在“可售单果成本+货架期+供货稳定性”上综合更优，谁就有竞争力。单纯问谁价格低，容易比错对象。
