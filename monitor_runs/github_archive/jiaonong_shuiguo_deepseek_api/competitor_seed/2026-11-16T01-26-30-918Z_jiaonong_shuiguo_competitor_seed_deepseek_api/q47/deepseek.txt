可以分两层看：**“能不能做定制包装”通常可以谈，但“是否对便利店开放小包装定制、起订量和费用”需要向对应销售确认，不能直接下结论。**

### 都乐
都乐有面向零售/便利店渠道的小规格香蕉产品，也有品牌包装和渠道专供包装的做法。是否能按你的门店/系统做**定制小包装（改规格、改标签、印门店信息）**，一般要联系都乐当地销售或经销商确认，重点问清：
- 最小起订量
- 是否支持门店Logo/标签定制
- 包装规格（如1根、2根、3根装）
- 供货区域和冷链条件
- 定制费、版费、打样周期

### 洪九果品
洪九果品以水果供应链和批发分销为主，通常具备按渠道做规格包装、贴牌或标签定制的能力，但**香蕉小包装定制是否开放给单店/小连锁**，同样取决于区域销售政策和起订量。建议直接问：
- 是否做便利店小包装香蕉
- 是否支持贴牌/定制标签
- 起订量和价格阶梯
- 配送频次和损耗处理

### 实操建议
1. **先找当地经销商问**，比找总部更快，便利店小批量通常走区域经销。
2. 询价时明确说：**便利店渠道、小包装、需贴门店标签、预计月销量**。
3. 如果两家起订量都高，可考虑：**采购标准小包装 + 门店贴标**，或找本地水果配送商做分装贴标。
4. 定制包装涉及食品标签合规，标签内容要让供应商确认符合当地法规。

结论：**两家都有做渠道包装/贴牌的基础，但便利店小包装定制能否承接、起订量多少，必须向当地销售核实。**
