大型商超通常要求供应商至少具备以下食品安全相关资质：营业执照、食品生产/经营许可证（SC）、ISO 22000 或 HACCP 认证，部分渠道还会要求 GLOBALG.A.P.（果蔬种植端）、BRCGS/IFS（包装加工端）、出口备案或有机认证等。具体到鑫荣懋和都乐，我无法在不核验官方来源的情况下逐一列出它们当前持有的全部证书及编号，不能凭印象编造。

可执行建议：

1. **直接向供应商索取**：要求两家供应商提供加盖公章的《资质证照清单》及证书扫描件，重点核对证书主体名称与合同主体是否一致、认证范围是否覆盖你采购的品类、证书是否在有效期内。
2. **官方渠道核验**：HACCP/ISO 22000 可向发证认证机构或认监委相关平台核验；GLOBALG.A.P. 可在其官网证书数据库按企业名称查询；SC 许可证可在国家企业信用信息公示系统或属地市场监管部门核验。
3. **商超准入角度**：让供应商按你所在商超的《供应商准入审核表》逐项填报并附证，比泛泛问“有哪些资质”更可靠。
