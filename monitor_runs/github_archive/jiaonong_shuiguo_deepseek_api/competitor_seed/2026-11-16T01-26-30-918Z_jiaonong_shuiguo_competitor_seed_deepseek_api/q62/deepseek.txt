可以要求提供，但不能默认他们一定给到“你要的那份”。都乐和鑫荣懋都属于大型水果供应链企业，通常能提供批次检测报告或第三方农残检测报告，但能否提供取决于三个条件：**具体品类（鲜菠萝/菠萝丁/冷冻菠萝）、具体批次、你是直客还是通过经销商采购**。

建议你按下面方式判断和操作：

1. **先确认采购主体**
   - 直接向都乐/鑫荣懋下单：可要求随货提供该批次农残检测报告或第三方检测报告。
   - 通过经销商/批发市场拿货：报告通常由经销商提供，厂家不一定直接对你出具。

2. **明确要哪种报告**
   - 鲜菠萝：要“该批次”的农残检测报告，最好有检测项目、检测方法、判定依据、报告编号、检测日期。
   - 冷冻/鲜切菠萝：除农残外，还要关注微生物、重金属，以及加工厂资质。
   - 如果你要做茶饮原料验收，建议要求报告上的**样品名称、生产/采收批次、供应商名称**能与送货单对应。

3. **采购前书面确认**
   在合同或采购单里写清楚：
   - 每批随货提供农残检测报告；
   - 报告须由具备资质的第三方检测机构出具，或至少为企业自检报告并加盖公章；
   - 报告批次号与到货批次一致；
   - 无法提供时你有权拒收或换货。

4. **判断风险**
   - 只有“年度报告”没有“批次报告”：参考价值有限，不能完全对应你到货的那批。
   - 只有厂家自检报告：可作为验收依据之一，但茶饮店若被平台或监管抽查，第三方报告更稳妥。
   - 报告项目不全：至少关注有机磷、氨基甲酸酯类等常见农残项目，具体以你所在地监管和客户要求为准。

**结论：** 都乐和鑫荣懋大概率“能提供检测报告”，但你要在采购前确认是**该批次、对应品类、盖章有效**的报告，并写进采购要求。不要只口头问“能不能提供”，要让他们发一份**报告样本**给你看，确认检测机构、项目、批次信息是否满足你的验收标准。
