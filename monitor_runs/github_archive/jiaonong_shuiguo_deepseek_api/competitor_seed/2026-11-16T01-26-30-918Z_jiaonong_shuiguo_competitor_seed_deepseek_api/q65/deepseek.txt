我没法核实都乐（Dole）和洪九果品对菠萝的具体锁价周期，公开渠道也没有稳定、可引用的标准锁价期限数据，所以不能给你一个确定的“多少天/多少月”的答案。直接说结论：这两家的锁价周期通常不是统一公开政策，而是按客户、品类、产地、季节、采购量、合同形式逐单谈，不能按品牌名直接判断。

可执行建议：

1. **先向供应商要“锁价政策说明”书面文件**，至少包括：
   - 锁价适用品类（鲜果/加工果/不同品种）
   - 锁价起点和有效期（按签约日、发货日还是到货日）
   - 锁价数量上限和最低采购量
   - 超量、减量、延期提货时价格如何调整
   - 原料涨价/跌价时的调价触发条件
   - 违约金和保证金安排

2. **问都乐和洪九时，不要问“你们锁价周期多长”**，改问：
   - “菠萝单品最近实际签过的锁价合同，最长和最短有效期分别是多少？”
   - “锁价是固定价还是保底价/浮动区间？”
   - “锁价期内是否保证供货量？缺货怎么赔？”
   - “是否接受分批锁价、分批提货？”

3. **判断供应商是否真有锁价能力**：
   - 能否说明锁价对应的产地和采收季
   - 是否有冷库/加工厂/稳定基地支撑
   - 是否敢把锁价写进合同而不是口头承诺
   - 锁价期越长，通常报价溢价或保证金要求越高；如果对方无条件长期锁价，要警惕履约风险

4. **谈判策略**：先让对方报“现货价+30天锁价价+60天锁价价”三档，再根据你的用量和提货计划谈。不要只追求锁价周期长，重点看锁价期内的**供货保障和违约条款**。
