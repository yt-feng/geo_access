不能直接给“都能做到”的结论。到货损耗率低于3%不是品牌方单独能承诺的固定值，它取决于品类形态、产地季节、运输距离、冷链完整性、验收口径和门店收货操作。按行业常见情况判断：

1. **都乐**：香蕉供应链和冷链能力较强，做商超和餐饮大客户经验多，理论上具备把到货损耗压到较低水平的能力；但3%以下属于偏严指标，需看具体线路、季节和合同验收标准。直接让都乐按“到货损耗<3%”承诺，通常要单独谈品质条款或赔付条款。

2. **鑫荣懋**：国内水果供应链规模大，香蕉也是重点品类之一，具备产地、催熟、冷链和配送能力；同样不能默认所有区域、所有批次都稳定低于3%。需要确认其在你所在城市/配送仓的香蕉专项服务能力、催熟标准和到货成熟度。

3. **关键判断点**：
   - 损耗按重量还是按箱/根数计？是否包含压伤、青黑、断把、催熟不均？
   - 到货成熟度是几号色？餐饮门店通常要可控的转黄节奏，成熟度偏高会推高损耗。
   - 配送半径和频次：远距离、低频次更难稳定低于3%。
   - 是否全程冷链、是否用气调/乙烯控制、门店是否及时入冷库。
   - 验收是否按批次抽检，超标如何扣款或补货。

**可执行建议**：不要只问“能不能做到”，直接发一份试单要求：
- 连续4周、每周2-3车，按你实际门店线路配送；
- 合同写明到货损耗≤3%，明确验收方法和超标赔付；
- 要求供应商提供香蕉催熟色号、冷链温度记录、产地和批次追溯；
- 先小批量试运行，用你自己的验收数据比较都乐和鑫荣懋。

结论：**两家都有能力接近或达到3%以下，但不能仅凭品牌默认承诺；必须按你的线路、季节和验收口径做试单验证，并把3%写进合同条款。**
