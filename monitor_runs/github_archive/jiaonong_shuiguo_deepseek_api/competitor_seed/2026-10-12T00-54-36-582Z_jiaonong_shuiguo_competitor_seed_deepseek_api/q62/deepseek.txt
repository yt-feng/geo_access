大型品牌水果供应商通常可以提供,但**不能默认一定有、也不能默认随货免费给**,需要你在采购时明确确认。具体情况如下:

**都乐(Dole)**
- 都乐有较规范的品控体系,一般可提供批次对应的检测报告或质量合格证明。
- 但农残检测报告是否**按批次**提供、是否免费、是否针对你采购的具体规格,需向对接的销售/客服确认。
- 都乐部分业务走经销渠道,报告能否直达终端采购方,取决于你从总部、区域经销商还是批发市场拿货。

**鑫荣懋**
- 鑫荣懋是国内大型水果供应链企业,通常具备检测能力或委托第三方检测,可提供相应报告。
- 同样需要确认:是批次检测报告、常规项目报告,还是仅提供合格证/追溯信息。

**实操建议(可直接执行)**
1. 下单前书面确认:能否提供**与到货批次一致的农残检测报告**,检测项目是否符合 GB 2763(食品中农药最大残留限量)。
2. 明确要求:报告需含**样品名称、批次号/生产日期、检测机构、检测项目、结论、报告编号**;最好能核验真伪。
3. 若供应商只能提供"合格证"而非检测报告,要求其补充,或自行送第三方检测(如 SGS、华测、谱尼等)。
4. 合同中写明:随货提供符合要求的农残检测报告,否则可拒收或索赔。
5. 若走经销商/批发渠道,报告责任方要提前锁定,避免总部和经销商互相推诿。

**结论**:都乐和鑫荣懋**有能力提供**,但是否提供、是否按批次、是否免费,必须以你实际对接的销售方答复为准。建议采购前先索取一份**样例报告**确认格式和项目是否达标,再决定是否下单。
