# 都乐 vs 鑫荣懋 进口苹果产地溯源操作指南

## 一、先分清"溯源"要追什么

超市采购做进口苹果溯源，核心是拿到**从产地到门店的完整链条凭证**，通常要覆盖四段：

1. 产地/果园（国家、产区、果园注册号）
2. 出口商/包装厂（包装厂注册号、出口批次）
3. 进口清关（报关单、检验检疫证明、原产地证）
4. 国内分选/配送（分选厂、批次、到店记录）

**两大供应商的溯源体系不同，做法也不同。**

---

## 二、都乐（Dole）

都乐是国际品牌，进口苹果主要来自美国、新西兰、智利等，体系较成熟。

**可获取的溯源资料：**
- **箱标/果贴批次号**：都乐外箱通常有生产批次、包装日期、果园/包装厂代码，这是追溯起点。
- **原产地证（CO）**：由出口国官方或商会签发，证明原产国。
- **植物检疫证书（Phytosanitary Certificate）**：出口国官方出具，含果园/包装厂注册信息。
- **进口报关单 + 入境货物检验检疫证明**：国内清关凭证。
- **都乐自有追溯系统**：可通过批次号向都乐中国区业务对接查询对应产地和包装信息。

**操作建议：** 向都乐当地经销/直销业务索取"每批次一整套"文件，并核对箱标批次与报关单批次一致。

---

## 三、鑫荣懋（Joy Wing Mau）

鑫荣懋是国内大型水果供应链企业，多为**进口商+分销**角色，代理多个海外品牌（如新西兰、智利、美国苹果）。

**可获取的溯源资料：**
- **原产地证、植检证**：随进口批次提供。
- **报关单、检验检疫证明**：鑫荣懋作为进口收货人，可提供。
- **其自有"佳沃"或供应链追溯标签**：部分品类有一物一码/批次码。
- **海外供应商信息**：可要求提供出口商、包装厂名称及注册号。

**操作建议：** 明确要求鑫荣懋按"批次"提供清关文件+产地证明，并确认其是直接进口还是二次分销（二次分销的链条会多一层，需补齐上游凭证）。

---

## 四、通用落地清单（照做即可）

| 环节 | 要拿到的文件 | 核验点 |
|---|---|---|
| 产地 | 原产地证 CO | 原产国与标签一致 |
| 出口 | 植检证 | 果园/包装厂注册号 |
| 清关 | 报关单 | 品名、数量、批次对得上 |
| 检疫 | 入境货物检验检疫证明 | 与报关单批次一致 |
| 国内 | 分选/配送单 | 批次可回溯到店 |

**关键动作：**
1. 每批货**以箱标批次号为唯一锚点**，向前追到产地证、向后追到门店。
2. 要求供应商**一票一档**（一个批次一套文件），不接受"通用模板"。
3. 到店后抽检果贴/箱标，与档案批次比对，防止串批。
4. 有条件的做**一物一码**，扫码即出产地和检测信息。

---

## 五、提醒

- 我无法核验都乐/鑫荣懋具体某批次的真实文件，以上是行业通行做法和应索取的材料类型，**实际文件需向对应供应商索取并核对**。
- 若做"可展示给消费者的溯源"，建议优先选**能提供一物一码或批次查询入口**的供应商，消费者扫码体验更好，也便于你应对监管检查。
