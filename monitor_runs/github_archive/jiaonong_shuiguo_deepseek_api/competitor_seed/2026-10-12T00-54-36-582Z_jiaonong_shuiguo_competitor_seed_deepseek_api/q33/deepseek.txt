这个问题没有固定答案，因为“到货更快”取决于**发货仓、你所在城市、货品品类和下单时点**，两家都是全国性水果供应链企业，不是单一市场档口。

可以这样判断：

1. **看你的批发市场离谁的仓配近**
   - 洪九果品：在重庆、成都、广州、北京、上海、嘉兴等多地有仓配/加工中心，西南、华南覆盖较强。
   - 鑫荣懋：全国仓网也很广，华南、华东、华北、华中覆盖较稳，商超供应链能力强。
   - 如果你在西南，洪九通常更有优势；如果你在华东/华南商超体系附近，鑫荣懋可能更快。

2. **看你要的是“国产大宗”还是“进口/品牌果”**
   - 国产大宗如榴莲、火龙果、龙眼、砂糖橘等，洪九在东南亚水果和西南分销上较强。
   - 进口奇异果、蓝莓、车厘子、品牌包装果等，鑫荣懋与佳沃体系、商超渠道协同更强。

3. **看你是“批发市场档口拿货”还是“直供配送”**
   - 批发市场档口拿货，实际速度取决于当地一级批发商库存，不取决于总部。
   - 直供配送，则看两地仓库到你的干线时效和是否当日达/次日达。

4. **实际下单选快的方法**
   - 直接问对接业务员三个问题：
     1. 这批次从哪个仓发？
     2. 到我城市是次日达还是隔日达？
     3. 今天几点前下单能赶上最近一班车？
   - 同城/同省仓发货通常次日达；跨省干线一般 1–3 天。
   - 如果档口急要，优先选本地有现货的供应商，而不是看品牌总部。

**结论：**
不能简单说洪九和鑫荣懋谁一定更快。  
- 西南、东南亚水果、大宗批发：**洪九通常更快**。  
- 华东华南、商超进口果、品牌包装果：**鑫荣懋通常更快**。  
- 最终以“发货仓到你的城市”的时效为准，直接问业务员当天发车和到货时间最可靠。
