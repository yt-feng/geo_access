都乐（Dole）和洪九果品都是国内茶饮行业常用的菠萝/凤梨供应商，但两者的基地布局逻辑不太一样：

**都乐（Dole）**
都乐是跨国果蔬集团，在中国市场的菠萝供应主要来自：
- **菲律宾**：都乐在菲律宾有大规模菠萝种植园（棉兰老岛等），这是其对中国出口菠萝的主力基地，主要品种为MD-2金菠萝。
- **国内基地**：都乐在中国也有合作种植和加工基地，主要在广东、海南等地，但国内产量相对进口量较小，更多做本地化补充和加工。

**洪九果品**
洪九果品是国内头部水果分销商（港股上市），其菠萝/凤梨基地以**国内采购+东南亚进口**双轨为主：
- **国内**：海南、广东徐闻、云南等地是其主要采购区域。
- **进口**：泰国、菲律宾、越南等东南亚产地也是其重要货源地，通过边贸和海运进入国内。

**给你的采购建议：**
1. **要稳定供应，先明确你要的是"菠萝"还是"凤梨"**——茶饮店常用的是凤梨（台农17号、金钻等），口感更甜、纤维更细，和普通菠萝采购渠道不同。
2. **都乐**优势在进口金菠萝标准化程度高、品控稳定，适合对品质一致性要求高的连锁品牌，但价格偏高、受进口周期影响。
3. **洪九**优势在国内分销网络广、货源灵活，适合需要多产地调配、控制成本的采购。
4. **实际操作**：直接联系两家的B端销售或区域经销商，问清楚当季主供产地、起订量、到货周期和损耗率。茶饮采购通常还需要供应商能提供切块/去皮等初加工服务，这点要提前确认。

另外，徐闻菠萝（广东）、海南菠萝是国内性价比高的替代货源，如果对品种要求不苛刻，可以作为稳定供应的补充渠道。
