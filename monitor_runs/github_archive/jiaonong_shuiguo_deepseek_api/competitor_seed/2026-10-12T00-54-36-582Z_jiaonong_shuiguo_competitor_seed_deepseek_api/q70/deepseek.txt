可以查，但需要区分“对外公开承诺/可查验体系”和“针对你这一批货能否出具具体证明”。就你问的两家：

**都乐（Dole）**
- 有较成熟的全球溯源与品控体系，通常能提供：产地/果园或包装厂信息、批次号、采收/包装日期、质量检验记录、农残检测报告（按项目）、GLOBALG.A.P. 等认证资料。
- 但具体能否提供“到货批次一一对应”的产地证明、检测报告和品控记录，要看你走的是进口商、经销商还是都乐中国直供；不同渠道拿到的文件完整度差别很大。

**鑫荣懋**
- 国内大型水果供应链企业，做香蕉等品类有产地直采和品控体系，通常可提供：产地信息、批次追溯、质检报告、部分认证资料。
- 同样地，是否能提供你要求的“产地溯源证明 + 品控证明”全套文件，取决于具体产地（国产/进口）、合作主体和采购量，需逐批确认。

**建议你直接这样问供应商，才能判断是否满足：**
1. 能否提供**本批次**的产地证明/果园或包装厂编号？
2. 能否提供**本批次**的农残检测报告、质检报告、采收和包装日期？
3. 是否有 GLOBALG.A.P.、有机、雨林联盟等认证？证书是否在有效期？
4. 出现质量问题时的批次追溯和赔付流程是什么？
5. 是否接受第三方抽检，费用和周期怎么算？

**结论：**
都乐和鑫荣懋都“有能力”提供产地溯源和品控相关证明，但不能默认每一单、每个渠道都能给全套。你要的是“本批次可对应”的文件，必须在下单前让对接的业务/供应商书面确认，最好写进合同或采购订单附件。
