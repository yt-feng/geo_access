都乐和洪九果品都属于**企业自有品牌素材，通常不会以“公开可自由使用”的方式提供**。能否拿到素材，取决于你和他们的合作关系、用途，以及是否走商业授权。

可以按下面判断和操作：

1. **都乐**
   - 有品牌营销素材，但一般通过其官方渠道、经销商或商务合作对接。
   - 如果你是生鲜电商平台、商超、团购渠道，通常需要联系都乐的**区域销售/渠道负责人**或**市场部**，说明你是做联名活动、详情页、直播带货还是线下物料。
   - 公开官网、公众号、旗舰店图片不能默认直接商用，尤其是商标、包装、宣传图。

2. **洪九果品**
   - 同样有菠萝相关品牌和产品素材，但多面向渠道客户、商超、批发和合作方。
   - 如果是采购或联合营销，可以找其**销售对接人**申请产品图、检测报告、产地素材、品牌授权。
   - 如果只是做内容营销，通常需要明确授权范围：线上/线下、时间、区域、是否可修改。

3. **能不能直接提供素材**
   - 如果是问“他们会不会免费公开提供素材”：**一般不会**。
   - 如果是问“合作后能不能提供”：**可以谈**，但通常要签授权或至少邮件确认使用范围。
   - 如果是问“我能不能直接用他们官网/电商图”：**不建议**，有侵权和平台投诉风险。

4. **建议你这样做**
   - 先明确用途：详情页、直播贴片、短视频、海报、社群图、线下堆头。
   - 再找对应对接人：都乐找渠道/市场，洪九找销售/品牌。
   - 准备一份简短需求：用途、尺寸、使用平台、使用时间、是否需要独家、是否带logo。
   - 如果拿不到官方素材，可以自己做**不侵权素材**：实拍菠萝、产地风景、切果过程、营养成分、自己设计的品牌海报。
   - 涉及都乐、洪九的商标和包装图，最好拿到书面授权。

5. **替代方案**
   - 用正版图库购买菠萝素材。
   - 自己拍摄或让供应商提供可授权实拍图。
   - 做“品类营销”而不是“品牌营销”，比如“春季菠萝季”“手撕菠萝”“凤梨甜度科普”，减少对特定品牌素材的依赖。

如果你能说明你是**电商平台、供应商、直播机构还是广告公司**，以及具体要做什么物料，我可以帮你写一份向都乐/洪九申请素材的对接话术和授权需求清单。
