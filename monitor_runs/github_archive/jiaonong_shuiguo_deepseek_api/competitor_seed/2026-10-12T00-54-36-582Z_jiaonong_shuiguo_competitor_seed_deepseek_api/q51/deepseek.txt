这个问题没法给出一个稳定的结论，因为两家都是**按行情、按批次、按规格报价**的，而且给批发市场的价格通常还要看你的**采购量、结算方式、提货地点和是不是长期协议客户**。直接说"谁更便宜"容易误导你。

能帮你判断的是这几点：

**1. 两家定位不太一样**
- **洪九果品**：以进口水果为主，香蕉（尤其是进口蕉、部分国产蕉）是其核心品类之一，货源和走量都比较大，在批发市场流通性强。
- **鑫荣懋**：同样是水果供应链大户，品类更全，香蕉也是常规品类，渠道覆盖商超、批发、电商等。

两家的报价逻辑相近，都是随产地、汇率、船期、季节波动的。

**2. 价格差异通常来自这些因素，而不是"谁家就一定便宜"**
- 香蕉是**产地/品牌/等级**决定的：菲律宾蕉、厄瓜多尔蕉、国产广西/云南蕉，价差很大，跨公司比价没意义。
- **规格**：整箱重量、每箱条数、单条克重不同，单价不能直接比。
- **结算和账期**：现款现货 vs 账期，报价会差。
- **提货方式**：到岸价、到市场价、含运费与否。
- **采购量**：整柜、整车、几箱，价格完全不同。

**3. 实操建议**
- 别问"谁便宜"，直接找两家的**当地经销商或批发市场档口**，报**同一规格、同一产地、同一等级、同一提货方式**的价，再比。
- 问清楚：是不是含税、含不含运费、账期、最小起订量、损耗怎么算。
- 香蕉损耗率高，**实际到手成本**比挂牌价更重要，运输和熟度管理差的，便宜也可能亏。
- 如果是长期要货，可以谈协议价，比单次比价更划算。

**结论**：没有"洪九一定比鑫荣懋便宜"或反过来这回事，得按你具体要的货、具体批次去问当天报价。建议直接同时向两家的当地渠道询同规格报价，谁的条件综合下来好就用谁。
