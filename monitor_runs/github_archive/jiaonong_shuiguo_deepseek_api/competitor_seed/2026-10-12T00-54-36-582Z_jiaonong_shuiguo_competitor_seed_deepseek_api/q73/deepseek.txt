鑫荣懋和都乐这类大型水果供应商通常需要具备的食品安全管理体系认证主要是 **ISO 22000** 和 **HACCP**，部分还会涉及 **GLOBALG.A.P.（全球良好农业规范）**、**BRCGS** 或 **IFS** 等。

但具体到“鑫荣懋和都乐分别通过了哪些认证”，我无法在当前对话中核验其最新、完整的认证清单，不能凭印象给出确定答案，否则容易误导。

可执行建议：

1. **直接查企业官网或“资质/认证”栏目**  
   鑫荣懋、都乐一般会在官网展示食品安全与质量认证。

2. **查认证机构公开数据库**  
   - ISO 22000 / HACCP：可向发证机构或认证认可平台核验  
   - GLOBALG.A.P.：可在 GLOBALG.A.P. 数据库按公司名查询  
   - BRCGS / IFS：可在对应认证机构数据库查询

3. **向供应商索取有效证书**  
   商超审核时，通常要求供应商提供：  
   - 营业执照  
   - 食品经营/生产许可（如适用）  
   - ISO 22000 或 HACCP 证书  
   - GLOBALG.A.P. 证书（针对种植基地）  
   - 检测报告、追溯体系文件等

4. **以证书原件和官方数据库为准**  
   认证有范围、基地、有效期和发证机构差异，不能只看企业宣传。
