除了都乐，国内市场上能相对稳定供应菠萝（含金菠萝/凤梨）的品牌和渠道主要有以下几类，但"稳定"因季节、地区和渠道差异较大，建议结合你所在区域实际验证：

**一、国际/合资品牌**
- **佳农（Goodfarmer）**：菲律宾菠萝、凤梨供应较稳定，商超和电商常见。
- **鑫荣懋**：代理多个进口水果品牌，菲律宾菠萝有一定供应量。
- **怡颗莓（Driscoll's）**：主要是莓类，菠萝不是主力，需确认。

**二、国内产区品牌/企业**
- **海南**：万钟、绿晨等，主打海南金钻凤梨，季节性较强（冬春为主）。
- **广东徐闻**：徐闻菠萝（"愚公楼"等地标品牌），每年3–5月集中上市，量大但不全年稳定。
- **云南**：河口、元江等地有反季节菠萝，部分企业做全年供应但规模有限。
- **台湾凤梨**：因政策原因大陆进口受限，目前已基本不进入大陆市场。

**三、渠道自有品牌**
- 盒马、永辉、沃尔玛、山姆等常有自有或定制菠萝，供应链相对稳定，但品牌方不对外统一。
- 电商平台（拼多多、抖音）上的产地直发商家，稳定性参差，需看店铺评分和发货地。

**判断建议：**
1. 如果你要的是**全年稳定**，优先找佳农、鑫荣懋这类做进口菲律宾菠萝的贸易商。
2. 如果是**季节性大批量**，直接对接徐闻、海南产地合作社或批发市场。
3. 具体供应情况建议直接联系品牌方或其区域经销商确认，因为水果供应受产地气候、船期、政策影响很大，我无法给出实时的稳定供货承诺。
