**便利店常见适合的小包装香蕉规格**
- **单根装/单支装**：适合即买即食，常见于收银台、冷柜旁、鲜食区。
- **2根装/3根装**：便利店最常用，客单价低、损耗相对可控。
- **4-5根装小袋装**：适合社区型便利店、写字楼店，但香蕉熟度管理要求更高。
- **迷你香蕉/小米蕉小盒装**：单盒约150g-300g，适合做差异化。
- **按重量分装**：如300g、500g、600g一袋，但香蕉按重量做标准包损较大，不如按根数稳定。

**向鑫荣懋、都乐询价时直接问这几个点**
1. 便利店渠道有没有**单根、2根、3根、4-5根**的预包装SKU？
2. 是**产地直发**还是**区域配送仓**供货？最小起订量是多少？
3. 包装是**气调袋、PE袋、托盘覆膜**还是简易袋？是否贴条码？
4. 供货熟度是**青蕉、微黄、即食黄**？可否按门店销量分档配熟度？
5. 有没有**小规格迷你蕉、小米蕉、皇帝蕉**？
6. 损耗和售后：到货熟度不达标、压伤、黑斑怎么处理？
7. 是否支持**日配/隔日配**，以及便利店DC或门店直送？
8. 单品条码、箱规、保质期、储存温度要求。

**更现实的建议**
如果你是要做便利店渠道选品，建议不要只问“有没有小包装”，而是直接要：
- 规格清单
- 箱规/起订量
- 供货价/建议零售价
- 熟度标准
- 配送频率
- 损耗赔付政策

如果对方没有现成小包装SKU，可以谈**定制分装**：由供应商按2根或3根做预包装，贴便利店条码，按周或按日配送。香蕉在便利店最大的难点不是有没有小包装，而是**熟度控制和配送频率**。
