从公开可核验的品牌认知角度看，**都乐（Dole）的品牌知名度通常高于鑫荣懋**，尤其是在终端消费者层面。

可判断依据：

1. **都乐是全球化水果品牌**
   - 都乐长期做全球水果供应链和品牌营销，在中国市场也有较高曝光。
   - 在香蕉、菠萝等品类里，都乐常被消费者直接认作品牌，属于“品牌即品类”的典型之一。

2. **鑫荣懋更偏渠道、供应链和B端品牌**
   - 鑫荣懋在中国水果行业里很强，采购、分销、供应链能力都很突出。
   - 但它过去更多是行业品牌、渠道品牌，面向普通消费者的直接品牌认知弱于都乐。
   - 它旗下或代理的一些品牌、单品可能知名度更高，但“鑫荣懋”这个母品牌本身的大众认知不一定强。

3. **生鲜电商做“品牌背书”要看你卖给谁**
   - 如果目标是**C端消费者快速建立信任**，都乐更占优势。
   - 如果目标是**行业合作、供应链稳定、采购背书**，鑫荣懋也很有分量。
   - 如果平台想突出“国产/本土供应链强”，鑫荣懋可能更合适；如果突出“国际品牌、稳定品质”，都乐更合适。

**结论：**
- **大众消费者知名度：都乐 > 鑫荣懋**
- **水果行业/供应链知名度：两者都强，鑫荣懋不弱，甚至在国内渠道端很有影响力**
- **生鲜电商香蕉品牌背书：优先选都乐，更利于C端转化和信任建立。**
