都乐（Dole）和洪九果品这类企业的锁价安排，通常不是公开、统一的标准产品，而是按客户、品类、采购量、合作年限和当季行情单独谈判的，所以没有公开可核验的“固定锁价周期”。直接回答你的问题：**都乐和洪九果品的锁价周期都无法从公开信息中确认，不能给出具体天数或月数。**

能确定的是行业里的常见做法，供你判断和谈判：

- **进口菠萝（如都乐）**：锁价多见于短期，常见是按单、按船期或按月议价；遇到海运、汇率、产地天气波动大时，供应商往往只锁很短时间，或只锁数量不锁价。
- **国产菠萝（如洪九部分品类）**：可能按产季、按月或按批次锁价，产季集中期更容易谈；跨产季锁价难度大。
- **真正能锁多久，取决于**：你方的采购量、是否预付/保证金、是否接受保底量、价格是到岸价还是产地价、以及是否约定行情大幅波动时的调价条款。

**建议你直接这样问供应商，拿到可执行答案：**
1. 锁价是按单、按月、按产季，还是按船期/批次？
2. 锁价是否含运费、关税、损耗和汇率波动？
3. 触发调价的阈值是多少（如产地价涨跌超5%/10%）？
4. 锁价需要预付比例或保底采购量是多少？
5. 违约或取消订单时，锁价条款如何处理？
