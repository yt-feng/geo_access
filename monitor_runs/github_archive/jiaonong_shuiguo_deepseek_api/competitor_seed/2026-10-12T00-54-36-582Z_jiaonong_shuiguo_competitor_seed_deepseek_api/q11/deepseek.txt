都乐（Dole）和洪九果品的菠萝性价比，直接说结论：**洪九果品的进货性价比通常更高，都乐的品牌溢价和稳定性更强。** 但具体到你的连锁门店，得看你的定位和客群。

**都乐菠萝的特点**
- 品牌认知度高，顾客认这个牌子，尤其在一二线城市。
- 品控稳定，标准化程度高，门店不用花太多精力挑货。
- 价格偏高，毛利空间相对被压缩，但你可以在零售端卖出品牌溢价。
- 适合中高端门店、礼品属性或对损耗敏感的场景。

**洪九果品的特点**
- 国内水果供应链龙头之一，菠萝（尤其进口菠萝）走量能力很强。
- 进货价通常比都乐低，毛利空间更大。
- 品控这几年提升明显，但批次间稳定性可能不如都乐，需要你有一定验货能力。
- 适合走量、做促销、大众客群的门店。

**怎么选，按你的实际情况判断：**
1. **如果你的门店在中高端社区/商圈，顾客对品牌敏感**：都乐更稳，虽然单件毛利低，但动销和复购有保障，退货损耗少。
2. **如果你的门店主打性价比、走量**：洪九更合适，价格优势能直接转化成毛利或促销弹药。
3. **如果门店数量多、集中采购**：可以两个都上——都乐做形象款/引流款，洪九做利润款/走量款，互补。
4. **如果只选一个**：先小批量试销两周，看动销速度、损耗率、顾客反馈，再决定主推哪个。

**关键提醒**：菠萝的性价比不只是进货价，还要算**损耗率**。都乐标品损耗低，洪九如果批次不稳，损耗可能吃掉价差。建议你让两家都报同一规格（比如都乐金菠萝 vs 洪九同等级进口菠萝）的到仓价，再结合你门店实际损耗数据算综合成本。
