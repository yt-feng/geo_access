结论先说：**鑫荣懋和都乐这类大型水果供应商，通常都具备较完整食品安全与质量体系认证，但具体“有哪些资质”会因公司主体、工厂/加工厂、品类、年份不同而不同，不能一概而论。**  
如果你是要给商超做供应商准入，**不能只记公司名字，要拿到具体证书扫描件并在认监委/认证机构官网核验。**

下面按两家分别说明常见资质类型。

## 一、鑫荣懋
鑫荣懋是国内大型水果供应链企业，通常涉及的资质/认证可能包括：

1. **营业执照、食品经营许可证**  
   作为食品经营/流通企业的基础资质。

2. **ISO 22000 食品安全管理体系**  
   大型商超常要求供应商具备。

3. **HACCP 危害分析与关键控制点体系**  
   很多商超、出口业务会要求。

4. **ISO 9001 质量管理体系**  
   部分客户或招投标会要求。

5. **GLOBALG.A.P. / 全球良好农业规范**  
   如果涉及自有基地、合作果园或出口，常见。

6. **BRCGS / IFS 等国际食品标准**  
   若其加工厂、包装厂面向高端商超或出口，可能具备其中一种。

7. **有机产品认证、绿色食品认证**  
   仅针对特定产品线，不是公司所有水果都有。

8. **出口备案/出口食品生产企业备案**  
   若涉及出口业务。

9. **可追溯体系、冷链相关认证或审核**  
   商超通常会做现场审核，不一定只看证书。

**判断建议：**  
让鑫荣懋提供：
- 公司主体营业执照
- 食品经营许可证
- ISO 22000/HACCP 证书
- 对应加工厂/包装厂的 BRCGS/IFS/ISO 22000
- 具体品类对应的 GLOBALG.A.P.、有机证等
- 证书编号和认证机构

然后去 **全国认证认可信息公共服务平台** 查证书是否有效。

## 二、都乐
都乐是国际水果品牌，通常在中国通过都乐中国相关主体运营。其常见资质可能包括：

1. **营业执照、食品经营许可证**  
   基础资质。

2. **ISO 9001、ISO 22000、HACCP**  
   国际品牌供应链常见。

3. **GLOBALG.A.P.**  
   都乐很多自有或合作农场会做全球良好农业规范认证。

4. **BRCGS / IFS**  
   若涉及加工、包装、配送中心，可能具备。

5. **有机认证**  
   针对有机香蕉、有机菠萝等特定产品线。

6. **雨林联盟、公平贸易等可持续认证**  
   这类偏可持续发展/社会责任，不等同于食品安全认证，但商超也可能加分。

7. **出口国官方注册/准入资质**  
   进口水果涉及海关准入、检疫审批、境外果园/包装厂注册等。

8. **冷链与质量审核报告**  
   商超通常还会要求都乐提供第三方审核报告、检测报告。

**判断建议：**  
都乐如果是进口水果，商超除了看食品安全认证，还会看：
- 海关进口货物报关单
- 入境货物检验检疫证明
- 境外生产企业注册信息
- 中文标签
- 核酸检测/消杀证明（如政策需要）

## 三、商超准入时，建议你直接这样要资料
不要问“你们有什么资质”，而要按下面清单要：

1. **主体资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证
   - 进口商备案、海关相关资质

2. **体系认证**
   - ISO 22000
   - HACCP
   - ISO 9001
   - BRCGS/IFS
   - GLOBALG.A.P.

3. **产品认证**
   - 有机认证
   - 绿色食品
   - 地理标志
   - 特定客户要求的认证

4. **检测与合规**
   - 第三方检测报告
   - 农残检测
   - 重金属、微生物等
   - 进口检验检疫证明

5. **证书核验**
   - 证书编号
   - 认证机构
   - 有效期
   - 认证范围是否覆盖你采购的品类和工厂

## 四、关键提醒
1. **公司有证，不代表每个工厂、每个品类都有证。**  
   一定要看证书上的“认证范围”和“地址”。

2. **ISO 22000/HACCP 是常见底线，BRCGS/IFS 更偏国际商超硬要求。**

3. **GLOBALG.A.P. 是农产品种植环节认证，和加工厂认证不是一回事。**

4. **有机认证只对特定产品有效，不能拿一张有机证覆盖所有水果。**

5. **最稳妥的方式：让供应商提供证书扫描件，并到认监委官网核验。**
