进口苹果品牌里，除了都乐（Dole）和鑫荣懋（Joy Wing Mau），常见且相对靠谱的还有这些，按市场认知度和供应链稳定性排：

**国际果蔬巨头系**
- **怡颗莓（Driscoll's）**：虽然以浆果出名，但部分渠道也有苹果类产品，品控体系成熟，主要看具体产季和渠道。
- **佳沛（Zespri）**：核心是奇异果，苹果不是主力，遇到贴牌或联名款要谨慎，别默认它家苹果和奇异果同水准。
- **新奇士（Sunkist）**：美国老牌柑橘和水果合作社，苹果有涉及，品牌历史久，但国内渠道真假混杂，认准正规进口商。
- **都乐（Dole）**：你已提到，供应链稳定，商超常见。
- **戴尔蒙蒂（Del Monte）**：国际果蔬品牌，苹果有涉及，但国内新鲜苹果存在感不如罐头类强。

**产地/品种导向型（更值得关注）**
进口苹果很多时候品牌不如产地和品种重要：
- **新西兰**：爱妃（Envy）、爵士（Jazz）、红玫瑰（Pacific Rose）、皇后（Queen）、嘎啦等，由 **T&G Global**、**Mr Apple** 等运作，品控普遍较好。
- **美国**：华盛顿州苹果，常见 **Stemilt**、**Chelan Fresh**、**Rainier Fruit** 等，蛇果、青苹果、蜜脆（Honeycrisp）是主力。
- **智利/南非**：多为大宗出口，品牌分散，看进口商和到货新鲜度。
- **日本**：青森苹果、阳光富士等，品质高但价格贵，渠道乱，认准正规贸易商。

**判断“靠不靠谱”的实用标准**
1. **看进口商和经销商**，不只看品牌：鑫荣懋、百果园、洪九、佳沃等体系相对规范。
2. **看品种和产地**：爱妃、爵士、蜜脆、太平洋玫瑰等，比泛泛的“进口苹果”更有参考价值。
3. **看包装溯源码**：正规进口一般有原产地、果园/包装厂编号、批次。
4. **警惕伪进口**：国内分装、贴外文标签、号称“进口”但无中文标签和检疫信息的，风险高。
5. **按渠道选**：山姆、盒马、Ole'、京东自营、天猫超市等，比来源不明的水果摊更稳。

**简单结论**
如果只比品牌，除都乐、鑫荣懋外，可重点关注 **T&G Global（爱妃/爵士）、Mr Apple、Stemilt、Chelan Fresh、新奇士**。但进口苹果真正决定体验的是 **品种+产地+进口商+新鲜度**，品牌只是其中一环。
