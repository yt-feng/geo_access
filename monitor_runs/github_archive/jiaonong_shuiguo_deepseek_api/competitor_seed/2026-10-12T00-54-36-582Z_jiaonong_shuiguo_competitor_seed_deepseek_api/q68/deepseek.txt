结论先说：**不能简单判断“都乐/鑫荣懋能不能做到”，因为到货损耗率取决于品种、成熟度、包装、冷链、运输距离、验收标准，以及你们门店/仓的卸货与暂存条件。**  
但可以给你一个可执行的判断框架，并按行业经验给出大概判断。

## 1. 先定义“到货损耗率”怎么算
餐饮连锁必须先把口径写死，否则供应商都能“做到3%”：

- 分子：到货验收时判定为不可用/降级/直接报废的香蕉重量（或箱数折重）
- 分母：该批次到货总重量（或总箱数折重）
- 判定项建议包括：
  - 严重压伤、裂果、断把、发黑腐烂
  - 青软不均、过早黄熟、已过熟
  - 冻伤、水烂、霉变
  - 单箱短缺/净重不足是否计入
- 验收时点：到店卸货后立即验收，还是入冷库后2小时/24小时验收，结果差异很大。

**如果你们把“到货后24小时仍可用”也算进去，3%以下对香蕉非常苛刻。**

## 2. 都乐和鑫荣懋大概是什么水平
按行业常见能力判断：

- **都乐**：品牌化、标准化强，进口蕉/精品蕉供应链成熟，冷链和催熟控制通常较好。  
  在**全程冷链、整箱托盘、距离合理、验收即时**的条件下，做到**3%以内是有可能的**，尤其是他们主推的标准化产品。
- **鑫荣懋**：国内水果供应链头部，香蕉品类覆盖面广，既有国产蕉也有进口蕉，履约能力取决于具体产区、加工中心、承运商和你们所在城市。  
  在**同一套严格冷链和包装标准**下，也有能力做到**3%左右或以内**，但不同区域、不同季节波动可能比都乐更明显。

关键不是“品牌能不能”，而是：**他们给你们报的是哪个产品标准、哪个产地、哪条线路、哪种包装、哪段责任。**

## 3. 香蕉到货损耗低于3%的关键条件
如果你们要写进合同，建议要求供应商同时满足这些条件，否则3%很难稳定：

1. **品种与成熟度**
   - 明确是国产蕉还是进口蕉，如巴西蕉、菲律宾蕉、厄瓜多尔蕉等。
   - 到货成熟度建议控制在 **3-4号色**（偏青、未转黄）或按你们加工需求定。
   - 若要求到货即用、偏黄熟，损耗率会明显上升。

2. **包装**
   - 纸箱+内衬袋+果指保护，整把不散。
   - 单箱净重、码垛层数、通风孔要明确。
   - 散装、反复倒箱、简易筐装，3%基本很难稳定。

3. **冷链**
   - 香蕉对温度极敏感：理想运输/暂存通常 **13-15℃**，不能低于12℃太久，也不能高温闷柜。
   - 要求全程温控记录，到货查温度记录。
   - 夏季/冬季跨区域运输是损耗高发段。

4. **运输与装卸**
   - 托盘化运输、减少人工搬运。
   - 卸货时间、暴晒/雨淋、月台温度都要管。
   - 多次中转、拼车、非直达，损耗会上去。

5. **验收与责任**
   - 到货多少小时内验收。
   - 外观标准、色卡标准、单箱允许差果比例。
   - 超出3%怎么赔：补货、折价、扣款还是退货。
   - 是“到店验收为准”还是“入仓后为准”，必须写清。

## 4. 给餐饮连锁的实操建议
你可以这样判断和落地：

### 先做小批量测试
选同一线路、同一门店/仓，分别让都乐和鑫荣懋各供3-5批，按统一标准验收：
- 每批记录：到货温度、成熟度、箱损、净重、坏果重量、压伤比例
- 连续跑2-4周，覆盖常温/高温/雨天
- 看的是**平均损耗+最差批次损耗+波动**

### 合同里不要只写“损耗低于3%”
建议写成：
- 到货验收损耗≤3%，超出部分按重量折价扣款；
- 单批次损耗＞5%可拒收或整批退货；
- 连续2批次＞3%触发整改；
- 因成熟度、冻伤、压伤导致的不合格，供应商承担；
- 验收时点和判定标准附照片/色卡/视频标准。

### 同时准备兜底方案
香蕉损耗很难靠单一供应商完全压住，餐饮连锁更稳的做法是：
- 主供+备供双源；
- 都乐做高标准主供，鑫荣懋做区域/价格补充，或反过来；
- 中央仓做一次分选，把到货损耗转移成仓内可控损耗；
- 对门店实行“先进先出+色卡管理”，否则供应商到货合格，门店放坏也算不清。

## 5. 直接回答你的问题
**在严格冷链、标准包装、合理成熟度、即时验收、路线不极端的前提下：**
- 都乐：**有条件做到到货损耗低于3%**，稳定性通常更好。
- 鑫荣懋：**也有条件做到**，但要看具体区域、产品线和承运执行，波动可能更大。
- 如果你们要求“到货后放1-2天还能用且损耗低于3%”，**两家都不能轻易保证**，必须用测试数据和合同条款约束。

最稳的做法不是问“他们能不能”，而是：  
**用你们的验收标准让他们试供3-5批，谁稳定低于3%，谁就能做到。**
