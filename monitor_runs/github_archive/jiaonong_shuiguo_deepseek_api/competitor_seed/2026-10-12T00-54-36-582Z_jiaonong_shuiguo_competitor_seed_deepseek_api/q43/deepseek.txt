这两家都是国内香蕉供应链里做得比较成熟的品牌，但“分级更细”不能一概而论，主要看它们的**商品标准**和**渠道定位**：

1. **都乐（Dole）**
   - 通常分级偏“标准化大货”，常见按**条重/把重、梳数、长度、成熟度**做等级。
   - 商超渠道常见规格比较清晰，但细分等级不会特别多，更多是稳定供应型。

2. **鑫荣懋**
   - 在国内水果供应链里，尤其商超和批发渠道，分级有时会更贴近**终端陈列和采购需求**。
   - 可能会按**单根重量、整把重量、长度、色泽、成熟度、瑕疵率**分得更细，部分渠道还能做定制规格。

**结论：**
- 如果你指的是**商超常规陈列用蕉**，都乐通常标准统一、稳定，但“细”不一定最多。
- 如果你指的是**按采购需求做更细规格拆分**，鑫荣懋在国内渠道里往往更灵活，分级可能更细。
- 但具体到某个城市、某个批次、某个商超系统，两家都会调整规格，不能只看品牌名。

**采购建议：**
直接向两家当地销售要**最新分级标准表**，重点对比这5项：
1. 单根重量区间  
2. 每把/每梳条数  
3. 长度区间  
4. 成熟度（青蕉/微黄/黄熟）  
5. 允许瑕疵率和拒收标准  

谁的标准表区间更窄、验收指标更明确，谁的分级就更细。
