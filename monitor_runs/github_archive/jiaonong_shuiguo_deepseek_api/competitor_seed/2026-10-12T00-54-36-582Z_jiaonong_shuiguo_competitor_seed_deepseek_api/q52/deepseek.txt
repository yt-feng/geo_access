我无法给出都乐和鑫荣懋在茶饮原料采购场景下的具体“到货损耗率”数字，因为这属于供应商合同、仓储运输条件和批次质量共同决定的动态数据，公开渠道没有可核验的统一口径，我也不应编造一个百分比。

可以给你的可执行做法是：

1. **直接向两家供应商索要近3个月到货验收数据**
   - 要求按你所在城市/仓库、按批次提供：到货总箱数、验收合格箱数、拒收或降级箱数、损耗原因分类。
   - 口径必须统一：是“重量损耗”“箱数损耗”“鲜果坏果率”还是“加工后可利用率”，这几个完全不同。

2. **自己做一个7—14天到货测试**
   - 同一天、同规格、同运输距离分别收都乐和鑫荣懋。
   - 每批记录：到货温度、外观、黑心/水心/烂心、压伤、成熟度、切开后可用果肉重量。
   - 对茶饮最关键的指标不是单纯损耗率，而是：**可切丁/可打浆的可用果肉率**。

3. **签约时写清楚验收标准**
   - 规格：单果重量、直径/长度、成熟度、糖度范围。
   - 损耗责任：到货验收不合格部分由谁承担、是否补货、是否扣款。
   - 批次差异处理：同一供应商不同季节、不同产地也可能差很多，不能只看品牌。

4. **建议的询价问法**
   - “请提供近3个月发往我所在区域的批次验收报表，按箱数和重量分别统计到货损耗。”
   - “如果按茶饮加工后可用果肉计，你们的历史平均可用率是多少？”
   - “出现黑心、水心、过熟、压伤时，验收扣重和补货规则是什么？”

如果你告诉我你所在城市、仓库条件、采购规格（比如整果还是冷冻果丁、单果克重、是否要求糖度），我可以帮你列一张到货验收记录表，方便你直接拿去对比都乐和鑫荣懋。
