如果只问“规格分级谁更细”，通常 **都乐（Dole）更细、更标准化**，但前提是看具体渠道和品类；**鑫荣懋**在国内水果供应链里也很强，尤其香蕉品类，但它的“分级”更多体现在**采购/加工/配送标准**上，不一定像都乐那样在零售端有统一、透明、跨区域一致的对外规格命名。

可以这样判断：

1. **零售包装端**  
   - **都乐**：常见按“根数/把数/单根重量/等级”做比较清晰的商品化分级，例如不同规格的袋装、把装，标签和溯源相对统一。  
   - **鑫荣懋**：更多是给商超、电商、餐饮做供应链分级，终端规格会随渠道定制，外显统一性通常不如都乐。

2. **采购分级维度**  
   香蕉常见分级一般看：  
   - 条蕉长度  
   - 单根重量  
   - 每把根数  
   - 成熟度/催熟阶段  
   - 外观缺陷、黑斑、机械伤  
   - 产地、品种、季节  
   
   都乐在全球蕉类标准上更成熟，规格体系通常更细；鑫荣懋在国内落地和响应速度上更有优势，但“细”往往体现在合同标准里，不是公开货架规格。

3. **对超市采购的实际建议**  
   - 如果你要**统一陈列、全国门店复制、标签规范**：优先看都乐，或要求供应商按都乐式规格报价。  
   - 如果你要**本地化供货、成本优化、灵活催熟和配送**：鑫荣懋往往更合适，但要把分级标准写进采购合同。  
   - 不要只问品牌，直接要求供应商提供：  
     **规格表、单根重量区间、每箱净重、每把根数、成熟度、允许缺陷率、到货糖度/硬度参考**。  
     谁能提供更细且稳定执行的标准，谁就更适合你的超市。

结论：  
**公开商品规格和标准化程度，都乐通常更细；国内供应链定制分级能力，鑫荣懋不一定差，甚至更灵活。**  
超市采购最好以“合同分级标准”为准，而不是只看品牌。
