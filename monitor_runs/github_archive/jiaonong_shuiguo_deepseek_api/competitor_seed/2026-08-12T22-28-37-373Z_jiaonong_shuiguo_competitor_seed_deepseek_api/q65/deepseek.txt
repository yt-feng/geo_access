关于菠萝的**锁价机制**（通常指“远期锁价”或“价格保险”），**都乐（Dole）** 和**洪九果品**这两家企业的官方公开资料中，**并未明确披露针对菠萝品类的具体锁价周期**，因为锁价通常属于定制化商业谈判，不同客户、不同产地（如菲律宾凤梨、徐闻菠萝）、不同合同量差异巨大。

不过，结合行业惯例和两家公司的公开商业模式，可以给您以下参考判断：

**1. 都乐（Dole）**
- **锁价模式**：都乐是全球最大的果蔬集团之一，主营进口菠萝（如菲律宾金菠萝）和国内高附加值菠萝。其供应链多为全球产地直采+品牌分销。
- **常见锁价周期**：针对零售客户（商超、电商）的年度框架合同，通常提供**1-3个月的固定价格窗口**；针对大宗贸易商，可能提供**季度或半年度**的锁价（需预付定金、锁定船期和规格）。**极少提供超过6个月的锁价**，因为海运价格波动和产季风险高。
- **建议**：直接找都乐中国区（如上海总部）的“重点客户部”或“大宗贸易组”谈，明确告知“我要为某项目锁3个月价格”，对方能给出明确报价单，内含具体期限。

**2. 洪九果品**
- **锁价模式**：洪九以“端到端”供应链著称，尤其在泰国榴莲、山竹、龙眼上有优势，菠萝（主要为国产徐闻菠萝和越南金钻）也有覆盖，但菠萝并非其绝对主力品类。
- **常见锁价周期**：它对国内种植端（徐闻产地）能直接谈“包园价”或“短期锁价”；对下游批发客户，通常提供**7-30天的短期锁价**，因为产地价格波动仍大。若采购量大（如每月50柜以上），可能谈**按季度锁价**。
- **建议**：洪九的采购负责人通常更灵活，可尝试要求“按月度锁价+跌价补偿条款”，这在果品行业较常见。

**给您的实操建议（重点）**：

1. **不要单纯依赖口头询价**，两家公司都需要您提供：**预估年采购量、单次采购吨数/柜数、规格要求（颗数/kg）、是否需要冷链专线、结算方式**，对方才会给出锁价周期。
2. **行业默认安全锁价期**：对菠萝这类大宗鲜果，**1-3个月**是大多数供应链公司的风险可控范围。超过3个月，对方通常要求在价格上附加“风险升水”（即报价上浮）。
3. **如果只能选一家**：若您主做**进口菠萝（菲律宾/越南）**，都乐更稳；若您主做**国产菠萝（徐闻）**，洪九更贴近产区。
