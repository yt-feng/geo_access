关于**都乐（Dole）**和**鑫荣懋（Golden Wing Mau）**两大水果供应商的菠萝到货损耗率，**没有公开、统一的行业标准数字**，因为该数值受以下关键因素影响极大：

- **运输距离与时效**（航空 vs 海运/陆运）
- **采购季节**（夏季高温损耗高，冬季低）
- **菠萝成熟度**（催熟果 vs 青皮果）
- **包装方式**（箱装、网套、托盘）
- **末端门店仓储条件**

**实际可执行的建议：**

1. **直接向供应商索取“到货验收标准”**：合同中应明确写明“容许损耗率”（通常为**3%~8%**之间，因距产地远近而异）。都乐和鑫荣懋作为大供应商，通常在商务条款中会明确约定“坏果率超过X%可拒收或索赔”。

2. **自行建立验收标杆**：建议你连续采购3-5批，每次随机抽检10-20箱，记录：
   - 重量损耗（失水）
   - 外观伤疤/霉变比例
   - 顶部叶子枯萎程度
   用你的实测数据作为考核供应商的基准，比问任何“行业标准”更可靠。

3. **特别提示（针对菠萝）**：菠萝的损耗主要发生在**冠芽（叶子）折断**和**底部发霉**。建议在采购合同中要求供应商供应**“无冠芽/半冠芽”**规格，可显著降低运输损耗。

**如果你需要具体数字作为谈判参考**（非官方数据，仅供参考）：
- 国内短途运输（产地至同省仓库）：损耗率通常在 **1%~3%**
- 跨省长途陆运（24小时以上）：损耗率通常在 **5%~8%**
- 夏季高温或海运：损耗率可能高达 **10%~15%**

**操作建议**：不要只依赖“损耗率”，更有效的方法是要求供应商提供每批次的 **“到货质量报告”**，并建立“按质计价”或“超额损耗折扣”条款。
