关于鑫荣懋和都乐这两家大型水果供应商的食品安全管理体系认证，我可以根据公开信息为你梳理。**请注意：认证状态和具体范围可能随时间调整，建议直接向供应商索取最新证书或查询其官网/国家认监委系统核实。**

以下是两家公司常见的第三方食品安全认证（大型商超入场时通常要求具备其中一种或多种）：

**1. 鑫荣懋（中国知名水果供应链企业）**
鑫荣懋在行业内通常持有的关键认证包括：
- **BRCGS（全球食品安全标准）**：这是国际零售联盟认可的食品安全标准，尤其被沃尔玛、永辉等大型商超看重。
- **ISO 22000（食品安全管理体系）**：国际通用的体系认证。
- **HACCP（危害分析与关键控制点）**：通常作为基础要求，甚至强制要求。
- **GLOBALG.A.P.（全球良好农业操作规范）**：针对种植端的认证，如果他们自营农场或与基地合作，会持有此项。
- 部分生鲜产品（如香蕉）可能还有**有机认证**或**绿色食品认证**。

**2. 都乐（Dole，全球性果蔬巨头）**
都乐作为跨国公司，其中国业务通常持有：
- **IFS Food（国际食品标准）**：与BRC并列的欧洲零售联盟标准，但都乐在亚洲市场更多使用BRC/ISO。
- **ISO 22000** 同样常见。
- **HACCP**。
- **GLOBALG.A.P.**（其全球供应链种植端必做）。
- 特定品类（如香蕉）可能持有**雨林联盟（Rainforest Alliance）或雀巢/联合利华类可持续认证**——虽然这属于可持续性认证，但往往和食品安全同时被商超供应链审核要求。

**如何快速确认？**
- 你可以在**中国国家认证认可监督管理委员会（CNCA）**官网的“认证结果查询”中输入公司名称，查看其持有的有效体系认证（如ISO 22000、HACCP）。
- 或直接通过供应商提供的“供应商资质文件包”（常见为PDF/扫描件）查看证书复印件。

**重要提示**：大型商超（如盒马、山姆、Costco）通常会要求供应商提供**有效期内的第三方审核报告**，比如BRC/FSSC 22000的A级或B级认证，而非仅仅是ISO证书。如果你在谈判采购，建议要求对方提供**最近一次第三方审核的评分结果**，这比证书名称更重要。
