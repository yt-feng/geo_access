关于水果连锁店香蕉分级标准，**都乐（Dole）和洪九果品的企业标准目前没有公开的、可完整核验的官方文件**。这两家公司通常采用行业通用标准、供应商合同指标或内部品控手册，但不会公开发布详细的等级划分细则。

不过，我可以为你提供目前水果行业中普遍采用的**香蕉分级核心指标**，供你制定企业标准时参考：

**一、香蕉分级的主要维度（通用行业标准）**

1.  **外观/果形**
    *   果指长度：通常按果指长度分等级（如：≥20cm为特级，≥18cm为一级，≥15cm为二级）。
    *   弯曲度：要求自然弯曲，无明显畸形。
    *   果柄完整性：果柄要新鲜、无干枯、无断裂。

2.  **成熟度（催熟前）**
    *   绿熟期（1-2级）：表皮全绿，适合运输储存。
    *   微黄期（3级）：果把开始转黄，即发即售。
    *   黄熟期（4-7级）：大面积转黄，适合门店销售。**分级通常按底色转黄比例、果肉硬度、糖度（Brix值）**来区分。

3.  **生理缺陷**
    *   黑斑、疤痕、虫眼、裂果、冻伤（低温褐变）等。按缺陷数量或面积占比划分等级（如：不允许/允许≤5%面积）。

4.  **重量与把型**
    *   单把重量（如：1.5-2.5kg/把为标准装），整把形状必须扇形展开良好。

**二、行业实操中的常见分级方式（可供你直接采用）**

虽然两家巨头没有公开标准，但国内大型批发市场（如嘉兴水果市场）和连锁商超（如永辉、百果园）普遍采用如下近似分级：

| 等级 | 外观要求 | 生理缺陷允许范围 | 成熟度要求 |
|------|----------|------------------|------------|
| **特级（A级）** | 果形美、果指长（≥20cm）、色泽均匀、果面无瑕疵 | 无黑斑、无裂口、无机械伤 | 绿熟期或微黄期，无软化 |
| **一级（B级）** | 果形较一致、果指中等（18-20cm） | 允许≤3%果面有轻擦伤、≤2个/cm²以下黑点 | 成熟均匀，无明显催熟障碍 |
| **二级（C级）** | 果形允许轻微不均、果指偏短（15-18cm） | 允许≤10%果面有斑点、轻微冻伤、果柄残缺 | 允许软化不均，但可正常催熟 |

**三、给水果连锁店的具体建议**

1.  **不要依赖“大牌标准”**：都乐主要面向商超直供，其内部标准以“整柜到货合格率”为准；洪九果品是供应链企业，其标准更多基于产地和渠道差异。直接照抄不现实。
2.  **建议自建分级**：用“**到货外观等级（A/B/C）+ 催熟后糖度（Brix≥16-18）+ 单把净重**”作为硬性指标，对供应商写进合同。
3.  **量化验收**：推荐统一采用**按缺陷数量/面积评分制**（比如100分制，扣分超过15分为C级），比模糊描述更易执行。
