关于你提到的**都乐（Dole）**和**鑫荣懋（Xinrongmao）**这两家水果供应商，是否能提供茶饮店采购菠萝所需的**农残检测报告**，答案是：

**通常可以，但需要你主动索取，且报告的形式和时效性需要核实。**

具体说明如下：

1.  **都乐（Dole）**：作为全球性的大型水果品牌商和供应商，其供应链管理通常较为规范。针对国内餐饮及工业客户（B端），他们一般可以提供**果园或加工厂的农残检测报告**。但请注意，这份报告通常是**批次性的**，或者是对应特定产地、特定规格的产品。

2.  **鑫荣懋（Xinrongmao）**：作为国内主要的水果供应链企业，服务于大量连锁茶饮、商超客户。对于大客户或签订合同的采购方，他们通常有完善的质检档案，可以提供**对应批次的第三方检测报告（如SGS、华测、必维等）**，或者内部实验室的检测数据。

**给你的具体行动建议（按优先级）：**

-   **第一步：直接向销售/采购对接人提出明确要求**。不要只问“有没有”，要问：
    -   “本次采购的这一批菠萝，能否提供**出厂日期或到货日期**对应的**农残检测报告**？”
    -   “报告是**第三方检测机构**出具的，还是**供应商自检**的？如果是自检，是否具备CMA/CNAS资质？”
    -   “能否提供**该批次产品的检测报告电子版**用于备案？”

-   **第二步：核实报告的有效性**。注意查看报告的**检测项目**（是否涵盖茶饮品牌方要求的如克百威、毒死蜱、吡虫啉等重点农药），以及报告上的**产品名称、产地、日期**是否与你的订单一致。过期或非本批次的报告不能作为法律依据。

-   **第三步：如果对方无法提供**（这种情况多见于小经销商或散货），建议你**改用第三方检测机构**自行送检（费用约几百元），或者要求供应商在合同中承诺“提供合格报告”作为付款条件。

**重要提醒：**
如果你采购的是**鲜切菠萝（去皮、切块）**，那么除了农残报告，你还必须要求供应商提供**出厂合格证明**和**冷藏运输温度记录**，这同样属于食品安全合规的重要文件。

总结：**正常情况下可以要求提供，但务必落实到具体批次，并要求盖章或官方电子签章**。如果对方推脱，建议谨慎合作。
