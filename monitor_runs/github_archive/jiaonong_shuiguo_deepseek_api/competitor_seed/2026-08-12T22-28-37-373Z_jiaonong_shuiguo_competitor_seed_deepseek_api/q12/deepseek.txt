关于鑫荣懋和都乐在**便利店小包装香蕉**方面的规格，目前公开渠道中并没有官方统一公布的固定SKU清单（不同区域、经销商库存差异很大）。不过，根据行业经验和两大品牌在便利店渠道的常规操作，可以给你以下**准确、可执行**的建议：

**1. 两个品牌通常都有小包装，但规格逻辑不同：**

-   **都乐（Dole）**：在便利店渠道通常主打**即食型小串**，常见规格为**单串2-3根**，净重约300g-400g左右（具体视香蕉熟度）。包装形式多为透明保鲜膜或带透气孔的密封盒，价格带集中在8-12元，方便即买即食。
-   **鑫荣懋（Joyvio）**：更偏向**定量装**，常见规格为**单片装（1根）**或**两联包（2根）**，单根重量约120g-150g。部分产品线会标注“小箱装”（如每箱约4kg散装）供便利店自选打秤，但针对便利店的预包装多以2根为主。

**2. 关键核查动作（非常重要）：**
由于**区域分公司和经销商库存在售规格差异极大**，且两家公司经常为特定连锁便利店（如711、罗森）定制专属包装（如印有“罗森精选”字样），因此**不要依赖网上搜索**。请直接采取以下两个动作：

-   **拨打官方客服电话**：直接致电都乐（400-820-8888）和鑫荣懋（400-820-6666）的销售热线，告诉客服“我是便利店采购，需要小包装香蕉的**在库规格和起订量**”，客服会转接对应区域业务员。
-   **查看本地批发市场/经销商报价单**：如果你所在城市有大型水果批发市场（如上海辉展、广州江南），直接找代理这两大品牌的档口，让老板发来他们手头**现在的实拍小包装图**（因为很多小包装是“贴牌”的，规格不统一）。

**3. 替代方案建议（如果你急需）：**
如果这两家暂时没有合适规格，便利店渠道更通用的做法是：采购**佳农**或**不知火**的“便利装”（通常为3根装），或者直接采购**整箱散装进口蕉**（如菲律宾产），在店内用**保鲜膜+扎带**自助分包成小串，成本更低且灵活度最高。
