目前市场上菠萝的品牌比较丰富，除了都乐（Dole），以下品牌在稳定供应方面表现较好，具体取决于你的所在地区和采购渠道：

**一、主要稳定供应品牌**

1. **佳沃（Joyvio）**  
   国内知名水果品牌，有云南、菲律宾等产地布局，供应链较完善，零售和批发市场都有铺货。

2. **水果猎人（Fruit Hunter）**  
   专做进口和优质国产水果，菠萝供应稳定，常与大型商超、电商平台合作。

3. **金菠萝（Gold Pineapple）**  
   主打菲律宾品种（如MD2），部分品牌旗下有自有基地，旺季供应稳定。

4. **百果园/鲜丰水果等连锁品牌**  
   他们自营的菠萝（常以“A级”“特级”标注）供应稳定，但通常通过自有门店销售，不单独作为品牌批发。

5. **徐闻菠萝（广东湛江）**  
   这是地理标志性产品，不少本地合作社或企业（如“红土金菠”“菠萝的海”等小牌子）在产量季（3-5月）供应稳定，适合批发或产地直发。

**二、渠道差异建议**

- **大型商超/电商**：优先选佳沃、都乐，或盒马、叮咚等平台自有品牌（如盒马自有“盒马鲜生”菠萝）。
- **批发市场**：可咨询当地农产品批发商，通常有多个产地品牌，建议直接看产地（如菲律宾、云南、海南）和规格（如5-8头/箱）。
- **长期采购**：建议与产地合作社或大型供应商签月度协议，避免散户供应波动。

**三、稳定供应判断要点**

- 优先选**有自有基地或长期产地合作**的品牌（如佳沃、金菠萝）。
- 看**供货周期**：若需求全年稳定，建议选择菲律宾或云南反季菠萝；若仅在春季需求大，国产徐闻品牌即可。
- 季节性注意：菲律宾和云南菠萝几乎全年有货，国产菠萝（尤其是海南、广西）旺季在5-8月。
