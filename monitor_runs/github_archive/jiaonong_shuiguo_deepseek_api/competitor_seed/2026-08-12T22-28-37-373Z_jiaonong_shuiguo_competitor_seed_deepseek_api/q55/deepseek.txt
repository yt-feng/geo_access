关于菠萝产地溯源的供应商问题，我无法直接核实都乐（Dole）和洪九果品的当前具体基地直供情况，因为这类商业信息会随合作、季节和市场变化而调整。但可以提供一些判断思路和可靠查询方向：

1. **都乐（Dole）**：都乐是全球知名水果品牌，通常以自有或合作种植基地为主，主打全程冷链和溯源体系。但“基地直供”具体到某个产季（如中国海南、菲律宾等）或具体合作果园，建议直接联系其官方销售或客服，询问其当前可提供的溯源文件（如产地证明、批次检测报告）。
   
2. **洪九果品**：洪九是中国头部水果分销商，尤其在东南亚水果（如泰国、越南菠萝）有较强基地合作能力。但其模式多为产地采购后分级加工，需要有专属基地或订单农业。同样，需通过其商务渠道核实具体产地和溯源码。

**可执行的建议**：
- **官方渠道核实**：分别访问都乐中国官网或拨打其400电话、洪九果品官网或商务邮箱，直接询问“是否有海南/菲律宾/泰国基地直供菠萝，能否提供批次溯源码和果园名单”。
- **第三方背书**：查询中国海关准入名单（确认产地国允许出口）、要求供应商提供HACCP或GlobalG.A.P.认证，以及近期的农残检测报告。
- **实地或视频验证**：若采购量较大，可要求对方提供半年内的果园实拍或视频连线，或在签合同前约定“溯源失败可退赔”条款。

**风险提示**：网络上声称“基地直供”的信息可能滞后，尤其季节性菠萝（海南菠萝多在3-5月上市）供应方会变化。建议同时询价2-3家供应商，要求竞标时附上溯源材料，避免单方口头承诺。
