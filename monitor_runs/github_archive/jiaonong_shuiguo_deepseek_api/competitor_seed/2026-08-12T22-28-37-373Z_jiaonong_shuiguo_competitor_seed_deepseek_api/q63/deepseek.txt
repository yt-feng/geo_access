针对社区团购需要**香蕉小包装**的需求，直接回答您的问题：

**1. 都乐（Dole）**
*   **结论**：**基本没有散装选项**。
*   **原因**：都乐在国内的零售渠道主打品牌化、标准化的**整箱或预包装**（如4-6根/袋的“小甜蕉”），主要供应商超、电商和精品水果店。它的散装或通货（B级果）很少零单流出，即便有也是发往B端批发市场，且通常要求大批量起订。
*   **替代方案**：如果您需要“都乐”品牌来做社区团购的**引流款**，可以直接在本地水果批发市场找**都乐经销代理**，按整箱拿货后自行拆箱分装成小袋。注意：都乐整箱价格较高，且果柄较长，分装损耗较高。

**2. 洪九果品（Hongjiu）**
*   **结论**：**有，且更适合您的需求**。
*   **原因**：洪九是国内头部的水果供应链企业，其模式就是“**源头直采 + 三级分销**”，在各大城市有自营的B端批发档口和加工分拣中心。他们有大量**散装、通货、二级果（B/C级）**供应，专门对接社区团购、生鲜店、商超分装商。
*   **具体操作**：您需要联系当地**洪九果品城市分公司/批发档口**，直接订购**整箱散装巴西蕉/菲律宾蕉**（通常17-18公斤/箱），回来自己用PE保鲜袋分装成小袋。洪九的散装价格比都乐低20%-40%，且果型歪扭、斑点果比例高，更适合低价团购走量。

---

**给您的实操建议（针对社区团购）：**

1.  **最优路径**：直接去**本地最大水果批发市场**的进口蕉区，找**洪九**或**其他来货商**（如佳沛、好丽友代理），买**散装巴西香蕉**。不要买都乐小包装，因为它的包装成本占了售价的30%以上，团购利润会被吃光。
2.  **规格建议**：社区团购做小包装，建议用**4-6根/袋（约1.2-1.5斤）**，售价定在**5.9-7.9元**，毛利控制在20%-25%。千万别用7-8根的大袋，容易压熟发黑。
3.  **关键提醒**：香蕉是**后熟**水果，从批发市场拿货时，务必跟供应商确认**“青熟度”**（果柄处应呈绿色带黄），并索要**检测报告**（硫酰氟、多菌灵残留）。如果拿太熟的，到客户手上1天就发黑投诉。

**总结**：**用洪九散装，别用都乐小包装**。洪九能提供散装通货，都乐主做预包装。您只需找到当地洪九的批发档口，说明“社区团购散装需求”即可。
