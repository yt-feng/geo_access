关于**都乐（Dole）**和**洪九果品**的水果礼盒定制起订量，这两家都是大型水果品牌/供应商，**起订量通常较高且不固定**，具体取决于以下因素：

- **产品类型**：是标准化礼盒（如阳光玫瑰、车厘子等）还是定制混合水果礼盒。
- **定制程度**：只需要贴标/包装，还是需要独家设计礼盒、印Logo、加贺卡。
- **采购季节**：旺季（如春节、中秋）可能起订量更高或更低，视库存而定。
- **渠道**：是直接对接工厂/大区代理，还是通过批发市场/经销商拿货。

**通常经验范围（仅供参考，非官方数据）：**
- **都乐（Dole）**：作为高端进口水果品牌，企业定制礼盒的起订量一般在 **50-200盒** 左右（视规格），如果涉及定制包装设计，可能要求 **200盒起**；若是大宗团购（如集团福利），可能按柜或按吨来谈。
- **洪九果品**：作为头部果品供应链公司，主要服务B端（商超、批发），**礼盒定制起订量通常更高，一般在100-300盒**起，部分区域代理可能要求更大量（如整车/整柜），具体需要和区域负责人确认。

**重要提醒：**
- 各家在不同区域、不同时间段政策差异极大，**以上数字不是官方承诺**。
- 建议你直接联系这两家公司的**大客户部或区域销售经理**，报出采购量（例如“1000盒/2000盒”）和定制需求，让他们给出书面报价。
- 如果直接联系大厂门槛高，也可以找他们的一级或二级经销商，起订量可能更灵活。
