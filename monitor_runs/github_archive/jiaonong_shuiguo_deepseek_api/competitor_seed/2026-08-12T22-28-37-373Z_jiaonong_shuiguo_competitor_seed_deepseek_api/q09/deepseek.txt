除了都乐（Dole）和佳沛（Zespri），以下是几个在礼品团购中较受欢迎、品质较高的进口水果品牌，适合高端礼盒场景：

1. **新奇士（Sunkist）**  
   - 美国品牌，主打橙子、柠檬、葡萄柚等柑橘类。  
   - 特点：果皮光滑、甜酸适口，包装常带有标志性“Sunkist”标签，辨识度高。  
   - 适合：商务礼盒、节日伴手礼。

2. **哥伦比亚麒麟果（Columbia Gold Pitahaya）**  
   - 哥伦比亚产黄皮火龙果（麒麟果）。  
   - 特点：甜度高，果肉细腻，外观金黄，视觉冲击力强，高端感足。  
   - 注意：需冷链运输，价格较高。

3. **泰国椰青（如“皇家椰青”品牌）**  
   - 泰国香水椰青（如“椰树牌”或“May士”）。  
   - 特点：椰水清甜，带有天然香味，适合夏季或健康主题礼盒。  
   - 推荐：可搭配其他水果组成“热带水果组合”。

4. **澳洲柑橘（如“澳大利亚脐橙”）**  
   - 澳大利亚产脐橙、柠檬，常见品牌如“Costa”或“Mildura”。  
   - 特点：果肉紧实，甜中略带酸，耐储存，适合大批量团购。

5. **智利车厘子（如“吉制”或“拉宾斯”品种）**  
   - 智利产车厘子，冬季（12月-2月）大量供应中国市场。  
   - 品牌：常见有“Dole”（智利产区）或“Pacific Nut”（太平洋坚果旗下车厘子），但更多以等级（如J级、JJ级）区分。  
   - 特点：果大、脆甜，是春节礼盒的“硬通货”。

6. **南非葡萄柚（如“Star Ruby”红宝石）**  
   - 南非产葡萄柚，品牌较少但品质稳定。  
   - 特点：低糖高酸，适合喜欢清爽口感的客户，可搭配蜂蜜或茶包做健康礼盒。

7. **新西兰爱妃苹果（Envy）**  
   - 新西兰品牌，由太平洋果品公司（Pacifica）推广。  
   - 特点：果肉极脆、甜度高，耐碰压，切开不易氧化，高端水果店常售。

8. **法国/意大利猕猴桃（如“Zespri”以外的“Gold”黄心品种）**  
   - 部分欧洲品牌如“Oscar”或“Meli”也出口奇异果，但国内少见。  
   - 建议：直接选佳沛（Zespri）阳光金果或绿果，因为其在中国市场供应链成熟。

---

**筛选建议（针对礼品团购）：**  
- **冬季（春节）**：智利车厘子、澳洲荔枝（如“L&B”）、新西兰苹果。  
- **夏季（端午/中秋）**：哥伦比亚麒麟果、美国新奇士橙、泰国椰青。  
- **高端定制**：可以组合“新奇士橙+智利车厘子+佳沛奇异果”，再配高档礼盒包装。  
- **注意验证渠道**：进口水果需确认检疫证明和中文标签，避免买到假冒品牌。

如需具体供应商或产地信息，建议直接联系进口水果贸易商（如鑫荣懋、佳沃）获取保真渠道。
