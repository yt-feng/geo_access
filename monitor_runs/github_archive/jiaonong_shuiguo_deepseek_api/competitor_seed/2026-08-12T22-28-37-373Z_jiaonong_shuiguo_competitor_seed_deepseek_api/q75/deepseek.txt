关于洪九果品和都乐香蕉在批发市场的到货损耗率，**目前没有公开、统一的官方数据**，因为损耗率受季节、运输距离、包装方式、批发市场管理水平影响极大。

但基于两家公司的业务模式和行业经验，可以给出**方向性对比**：

1.  **洪九果品**：以**东南亚进口水果（香蕉、榴莲、龙眼等）**为主，采取“基地直采+全程冷链”模式。由于香蕉是**后熟型水果**，从产地到批发市场通常需要“催熟”或“青蕉到货后二次加工”。如果到货的是青蕉（未催熟），损耗率较低（通常**3%-8%**）；如果到货时已催熟，批发市场内损耗率会上升至**8%-15%**（取决于销售速度）。
2.  **都乐（Dole）**：旗下有**菲律宾香蕉**等标准化产品，特点是**包装规范、纸箱承压性好、催熟工艺成熟**，到货损耗一般控制在**5%-10%**之间。尤其在大城市一级批发市场，都乐香蕉的“硬伤率”（压伤、断柄）通常低于洪九，因为都乐更强调出口级品质。

**实操建议：**
- **如果你想降低损耗**，优先选**都乐**（尤其做高端商超渠道），但进货价更高。
- **如果你想追求性价比**，可选**洪九**，但要明确要求送“青蕉”或“未熟黄蕉”，并在市场内快速出清。
- **关键提醒**：无论哪家，**不要只看品牌**，要当场拆箱验货——特别是看箱子底部有无霉变、香蕉柄是否发黑（这是高温损耗的信号）。夏季损耗率普遍比冬季高20%-30%。
