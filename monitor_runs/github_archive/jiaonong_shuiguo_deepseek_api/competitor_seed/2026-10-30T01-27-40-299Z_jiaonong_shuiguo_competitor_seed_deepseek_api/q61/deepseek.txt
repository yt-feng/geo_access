可以直接这样判断：**都乐（Dole）和洪九果品都有围绕香蕉商品化分级的内部/企业标准或作业规范，但通常不是公开可下载的“标准文本”，外部能核验到的多是其公开宣传中的等级口径、客户规格书或行业报道，不能当作正式标准原文引用。**

### 1. 都乐
- 都乐有较成熟的香蕉商品化分级体系，常见按**果指长度、粗度、条数/箱、成熟度、外观缺陷、整齐度**等分级。
- 对零售客户通常以**规格书/订单标准/验收标准**形式存在，而不是公开企业标准编号。
- 可参考其官方商品资料中的规格描述，但**不宜声称“都乐公开企业标准编号为XXX”**，因为通常核验不到。

### 2. 洪九果品
- 洪九作为水果供应链企业，香蕉是其重要品类，通常有**采购验收标准、加工分级规范、配送规格**等内部标准。
- 公开信息中较难核验到正式“企业标准”文本或编号；更多是招股书、宣传材料、客户合作中的品控描述。
- 因此可以说其“有内部分级/品控规范”，但**不宜直接说其公开了企业标准**。

### 3. 给你的可执行建议
如果你要给水果连锁店做香蕉分级标准，不建议依赖都乐/洪九的标准原文，建议自建门店可执行标准，包含：
- **外观**：无严重碰伤、黑斑面积、梳形整齐、果指弯曲度；
- **规格**：果指长度、粗度、每箱净重、每梳条数；
- **成熟度**：到店青度/催熟后色卡等级；
- **缺陷容忍度**：机械伤、病斑、裂口、脱把比例；
- **验收抽样**：抽检比例、不合格判定、退货/降级规则。

### 4. 核验方式
若必须确认企业标准：
- 查**企业标准信息公共服务平台**是否有相关企业标准备案；
- 向都乐/洪九业务方索取**产品规格书、验收标准或质量协议**；
- 以合同附件形式固化，而不是引用公开报道。

结论：**两家大概率都有内部企业级分级/规格体系，但公开可核验的正式企业标准文本通常拿不到；门店落地应自建标准并向供应商索取规格书作为合同依据。**
