**都乐（Dole）**

**洪九果品**
- 洪九果品是重庆起家的水果供应链企业，菠萝主要来自其在**泰国、越南**的采购基地（如泰国南部、越南南部产区），以及国内**广东徐闻、海南**等菠萝主产区的合作基地。
- 洪九以“基地直采+自有加工分选”模式运营，具体到某个基地的地址和产能，属于其供应链内部信息，公开资料不完整，建议直接联系洪九果品的采购部门确认当季可用产地和供应量。
