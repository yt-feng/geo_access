关于都乐（Dole）和洪九果品的具体账期，我无法给出可核验的确切数字。账期属于各家与客户逐单协商的商务条款，不对外公开披露，且因客户资质、采购量、品类、合作年限、结算方式差异很大，网上流传的"XX天账期"大多不可靠，我不做猜测。

能给的可执行建议：

1. **直接问对方销售/大客户部**，问四个问题即可判断：
   - 标准账期多少天？是否有起订量或月采购额门槛？
   - 是否需要预付定金/首单现结？新客户前几单是否现款？
   - 走什么结算工具（银行承兑、商业承兑、账期保理）？承兑贴息谁承担？
   - 逾期罚则和额度上限是多少？

2. **两家的大致定位**（可核验的公开信息）：
   - 都乐：国际品牌，国内以商超、餐饮、加工渠道为主，通常通过授权经销商/进口商分销，直接对终端给账期的空间取决于你对接的是都乐主体还是其经销商。
   - 洪九果品：港股上市的鲜果分销商（2022年上市），核心模式就是向商超、电商、批发客户做分销，本身对下游客户提供一定账期是其业务特征之一——这也意味着它对上游/新客户的风控会较严，通常要求资质审核、额度审批。

3. **实操路径**：同时接触两家的区域销售 + 各找1–2家一级经销商比价，把"账期天数、首单条件、承兑贴息、断供风险"做成对比表；新供应商建议先小批量现结跑1–2个月，再谈账期。
