进口菠萝旺季缺货，先不要等供应商给答案，按“可替代、可切换、可止损”三条线同时处理；都乐和洪九是否已有公开的应急方案，我无法核验，不能替它们确认，建议直接向对接销售/大区经理书面确认。

**一、先判断缺货性质（决定动作）**
- 船期延误/港口拥堵：优先改港、改船、分批提货，确认在途货ETA。
- 产地减产/规格断档：立即启用替代规格和替代产地。
- 供应商分配不足：要求书面分配量、到货周计划，并同步启动第二供应商。
- 价格暴涨囤货：锁定短期用量，不追高囤货，避免损耗。

**二、门店/渠道端应急（今天就能做）**
1. 盘点库存：按SKU、到货日、可售天数做表，优先保高毛利渠道和核心门店。
2. 替代方案：用同用途鲜果替代（如其他进口菠萝产地、国产菠萝、凤梨类），明确告知顾客“产地/规格调整”，避免客诉。
3. 调整陈列和促销：缺货SKU下架或合并陈列，主推有货SKU，停止缺货品类的引流投放。
4. 锁量不锁价：对在途货和已订未发货运单逐票确认，能分批到就先分批到。
5. 损耗控制：旺季缺货时更易出现“有货就压”，按日销量补货，避免集中到货后烂损。

**三、对都乐/洪九的确认话术（直接发给对接人）**
- 请书面确认：本周/下周可分配到我司的菠萝SKU、数量、到货日、港口。
- 是否有替代产地/替代规格的应急货源？起订量、价格、时效。
- 在途延误的货，能否改港/改船/分批提货？费用谁承担？
- 若分配不足，能否给出优先分配规则和补偿/调货方案？
- 请提供近4周供货计划表，便于我司排产和门店分配。

**四、供应商策略**
- 不要只依赖都乐或洪九单一家：同步联系第二进口商、一级批发市场、产地直采渠道。
- 对都乐、洪九分别谈“保底量+浮动量”，保底量写进短期补充协议。
- 要求到货质量标准和拒收条款，缺货期最容易出现规格降级。

**五、止损底线**
- 设定可接受替代品的毛利下限和客诉上限。
- 若缺货持续超过2周，启动品类结构调整，不把旺季销售押在单一进口菠萝上。

结论：都乐和洪九有没有“应急方案”需要它们书面确认；你能立刻做的是盘点可售天数、启用替代SKU、锁定在途货、启动第二供应商，并把分配量和到货计划落到周表。
