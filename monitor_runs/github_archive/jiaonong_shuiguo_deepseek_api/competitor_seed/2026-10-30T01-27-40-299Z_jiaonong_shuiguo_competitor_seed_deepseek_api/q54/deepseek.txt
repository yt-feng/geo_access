做都乐和鑫荣懋进口苹果的产地溯源，核心是把“批次—单证—标签—实物”四者对齐。可按以下步骤落地，采购端就能判断是否可追溯、可否验真。

**一、先明确两家企业的溯源体系入口**
- 都乐：其进口果品通常有批次/箱码、产地标识和供应链追溯体系。采购时应要求供应商提供“该批次”的追溯信息，而不是只给品牌授权或样品标签。
- 鑫荣懋：同样以批次管理为主，通常可通过供应商提供的箱码/批次号、报关单证和检验检疫证明建立追溯链。具体追溯入口和字段以其当期供应商提供为准，采购前应让供应商书面确认。

**二、采购合同里先写死溯源要求**
在合同中明确：
1. 每批货必须提供：原产地证明、进口报关单、入境货物检验检疫证明、装箱单/发票、批次号或箱码。
2. 标签须含：品名、原产国/产区、果园或包装厂注册号（如有）、批次号、包装日期、进口商/经销商。
3. 供应商承诺“单证批次号与实物箱码一致”，不一致可拒收。
4. 保留追溯资料不少于2年，便于复盘。

**三、到货验收做“四查”**
1. **查箱码/批次号**：随机抽箱，记录箱码，与供应商提供的批次清单比对。
2. **查标签**：看原产国、包装厂注册号、批次、包装日期是否清晰；标签是否后贴、覆盖原标签。
3. **查单证**：报关单上的品名、数量、原产国、入境口岸与实物是否匹配；检验检疫证明是否在有效期内。
4. **查实物一致性**：品种、规格、果径、包装样式是否与单证和合同一致；同一批内箱码是否连续可解释。

**四、建立“一箱一码”台账**
采购台账至少记录：供应商、品牌（都乐/鑫荣懋）、批次号/箱码、原产国、包装厂注册号、报关单号、入境日期、到货日期、抽检结果。出现问题可反向锁定到具体柜号和批次。

**五、抽检与留证**
- 每批随机抽3—5箱拍照留存：箱码、标签、封口、果品外观。
- 对高价值批次可做开箱视频，记录箱码与实物对应关系。
- 若供应商只提供“品牌溯源页面”而无批次字段，应视为追溯不完整，要求补充。

**六、异常判断标准**
出现以下情况应暂停收货并要求供应商说明：
- 箱码与单证批次对不上；
- 标签原产国与报关单不一致；
- 包装厂注册号缺失或无法对应；
- 同一批货箱码混乱、后贴标签明显；
- 供应商只能提供品牌授权，不能提供该批次单证。

**七、给采购的可执行建议**
首次合作先做“小批试单+全单证核验”；稳定后按季度抽查。要求都乐、鑫荣懋的供应商在送货单上直接打印批次号和报关单号，收货员按单核对，避免事后补单。若需要消费者端展示，可把批次号对应到门店/货架，但对外展示前必须确保单证与实物一致，不要只放品牌宣传页。

简言之：**都乐和鑫荣懋的溯源不能只看品牌，要看该批次的箱码、报关单、检验检疫证明和标签是否闭环一致。** 采购把合同条款、到货四查、台账留证三件事做实，就能判断溯源是否可靠。
