这个问题没法直接得出“谁更愿意”的结论——**“愿意签年单”是供应商的商务政策，不是公开可查的固定属性**，而且两家在不同品类、不同客户体量、不同年份下的态度会变化。硬给一个“谁更愿意”的排序，等于替你编一个没有依据的判断。

能给你的可执行判断是：

**先明确“年单”对果品供应商意味着什么**
- 水果是价格波动大、损耗高、产地季节性强的品类，供应商对“锁量锁价”的年单天然谨慎。
- 真正愿意签年单的供应商，通常要求：保底量、价格联动机制（随行就市或指数挂钩）、账期明确、违约条款清晰。
- 所以对方“愿不愿意”，更多取决于你给的**量、账期、价格机制**，而不是公司名字本身。

**怎么判断这两家谁更配合（可操作）**
1. 用同一份询价模板分别找两家的销售/大客户部门，明确写：年度预估量、分月节奏、品类清单、期望价格机制（固定价还是随行就市）、账期、验收标准。
2. 看回应质量：谁愿意给分月报价、谁主动提价格联动条款、谁愿意谈保底量，谁就更接近“能签年单”的合作方。
3. 要求对方提供**同类客户年单案例**（不必给客户名，给合作模式即可），能说清机制的可信度更高。
4. 小批量试单 1–2 个月，再谈年单——果品供应商对试单后的长期合作意愿，比初次谈判的表态可靠得多。

**关于这两家的公开信息，我只说确定的部分**
- 鑫荣懋、洪九果品都是国内较大的水果供应链企业，洪九果品是港股上市公司（品类以进口水果、东南亚水果见长），鑫荣懋在国产精品水果和商超渠道供应链上有较深积累。
- 但“谁更愿意签年单”属于具体商务谈判结果，公开资料无法核验，我不替你下结论。

**结论**：别先问“谁更愿意”，而是带着明确的量、账期、价格机制去谈，用对方的报价结构和条款灵活性来判断。需要的话，我可以帮你写一份用于分别询价、便于横向对比的年单询价模板。
