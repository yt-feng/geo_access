结论先行：**两家都不能按“菠萝产地溯源 + 基地直供”直接当作现成答案，需要分别核实，且核实口径不同。**

**都乐（Dole）**
- 都乐有自有/合作种植基地体系，部分品类可做到产地和批次信息较完整，但“是否对你们这个采购主体做菠萝基地直供+溯源到具体地块/批次”，取决于其中国区销售主体、当季货源和客户规模。
- 建议直接问都乐中国区销售：①菠萝是自有基地还是合作基地；②能否提供批次级追溯（基地名称、采收日期、包装厂、检测报告）；③是否支持你们要求的最小起订量和直发。
- 不要只接受“品牌溯源”，要确认是**单品批次溯源**。

**洪九果品**
- 洪九是水果供应链企业，核心能力在产地采购、分选加工和分销，很多品类是“产地直采/基地合作”，但不等同于每个菠萝SKU都能做到基地直供和全链条溯源。
- 建议要求其提供：①该菠萝SKU的产地证明和合作基地清单；②是否可追溯至具体包装批次；③是否由洪九自有分选厂加工；④能否出具承诺函或写入合同。

**可执行的判断标准**
1. 要求供应商提供**一个真实批次的完整追溯样例**：基地/合作社名称、采收时间、加工厂、检测报告、发货单能对应上。
2. 问清“直供”定义：是基地直发，还是经其分选中心再发；后者仍可溯源，但不是严格基地直供。
3. 把溯源要求写进合同：批次号、产地证明、检测报告、异常召回责任。
4. 先小批量试单，验证追溯信息能否闭环。

**建议**：都乐偏品牌和标准化，洪九偏供应链整合；若你们要的是“可验证的批次溯源”，两家都可谈，但必须用样例批次和合同条款验证，不能仅凭“有基地”判断。
