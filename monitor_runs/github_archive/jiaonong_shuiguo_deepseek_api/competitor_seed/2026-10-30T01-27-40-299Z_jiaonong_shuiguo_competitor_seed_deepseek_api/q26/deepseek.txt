直接给判断：**做茶饮果酱，优先选都乐更稳；鑫荣懋不是不能选，但更适合你已经有稳定货源和验货能力、追求性价比时用。**  
不过“谁更靠谱”不能只看品牌，还要看你是买**鲜果**还是**冷冻/罐头果肉**，以及你所在城市的配送条件。

**可执行结论：**

1. **要稳定品质、标准化出品：优先都乐**
   - 都乐的菠萝供应链和品控体系更成熟，规格、成熟度、批次稳定性通常更好。
   - 适合茶饮店做果酱，因为果酱对糖酸比、成熟度、纤维感要求稳定。
   - 缺点是价格通常更高，且不同区域供货可能仍有差异。

2. **要性价比、本地配送灵活：可看鑫荣懋**
   - 鑫荣懋水果供应链能力强，尤其鲜果分销和渠道覆盖不错。
   - 但茶饮果酱用的菠萝，关键不是“水果品牌大”，而是**到店批次是否稳定、成熟度是否一致、是否适合熬酱**。
   - 如果本地经销商能稳定供货、允许验货、退换货清楚，可以测试。

3. **更稳的做法：不要只按品牌定，按原料形态定**
   - 如果买**鲜菠萝**：都乐优先，要求固定产地、固定规格、固定成熟度。
   - 如果买**冷冻菠萝果肉/果浆**：重点看工厂、糖度、解冻出水、纤维完整度，品牌反而次要。
   - 如果买**罐头菠萝**：看固形物、糖水浓度、酸度，都乐和鑫荣懋都可比较，但罐头体系里专业罐头厂可能更合适。

**建议你做一次小批量对比测试：**

- 各拿都乐和鑫荣懋同规格样品，按同一配方熬酱。
- 测：出酱率、颜色、酸甜平衡、纤维感、出水、冷藏后稳定性、3天和7天风味变化。
- 记录每公斤果酱成本，而不是只看原料单价。
- 连续测3个批次，批次差异比品牌更重要。

**一句话：**  
**没有验货和批次测试能力，选都乐更省心；有本地稳定渠道和品控能力，鑫荣懋可以作为成本备选。最终以同配方熬酱测试和连续批次稳定性定供应商。**
