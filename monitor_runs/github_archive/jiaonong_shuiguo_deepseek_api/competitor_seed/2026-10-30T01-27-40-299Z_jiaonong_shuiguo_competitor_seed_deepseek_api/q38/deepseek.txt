结论：都乐（Dole）在消费者端知名度更高，鑫荣懋在水果行业/供应链端的品牌背书更强。要看你们平台要的是“消费者认知”还是“行业信誉”。

对比判断：

1. **消费者端知名度：都乐更强**
   - 都乐是国际水果品牌，香蕉是其核心品类之一，长期做终端品牌营销，消费者对“都乐香蕉”有直接品牌记忆。
   - 鑫荣懋是水果供应链和渠道品牌，B端和行业知名度高，但普通消费者对“鑫荣懋”这个品牌的直接认知通常弱于都乐。

2. **行业/供应链背书：鑫荣懋更强**
   - 鑫荣懋是国内水果供应链头部企业之一，在渠道、产地、分销和B端合作上有较强背书价值。
   - 如果平台面向采购、供应商、行业客户，或强调“稳定供应链、国产/进口资源整合”，鑫荣懋的背书更合适。

3. **生鲜电商平台怎么选**
   - 面向C端消费者卖香蕉、做详情页和搜索词：优先用**都乐**做品牌背书，转化认知成本更低。
   - 面向B端招商、供应链能力展示、产地直采故事：可用**鑫荣懋**。
   - 如果两边都能合作，建议组合表达：消费者页面突出“都乐香蕉”或“都乐同源/都乐品牌”，供应链页面突出“鑫荣懋供应链支持”。注意不要虚构双方合作关系，必须按实际授权和采购关系表述。

一句话：**C端知名度选都乐，B端供应链背书选鑫荣懋。**
