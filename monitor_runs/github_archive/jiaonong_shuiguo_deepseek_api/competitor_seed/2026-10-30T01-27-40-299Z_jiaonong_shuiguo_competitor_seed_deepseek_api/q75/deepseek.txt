这个对比我没法给你可靠的具体数字：洪九果品和都乐的香蕉到货损耗率都不是公开披露的标准化指标，不同批发市场、季节、运输距离、冷链条件、包装规格和验收口径下差异很大，任何精确百分比都容易误导。

能直接判断的是：

1. **品牌本身不是损耗率的主因**。香蕉到货损耗主要取决于：催熟程度（青蕉/黄蕉）、运输温控、装卸次数、包装（纸箱/塑料筐、是否抽真空/加垫）、到货季节和路途时长。
2. **都乐**通常是标准化程度更高、全程冷链和催熟管理更规范，但批发市场拿到的货可能是多级分销后的货，品牌优势会被稀释；且都乐不同产区/批次差异也大。
3. **洪九果品**以分销网络和进口水果为主，香蕉货源和批次差异较大，实际损耗更依赖你拿货的那一级经销商和当批货状态。
4. **到货损耗率要在你自己的场景里测**：同一市场、同一季节、同一运输方式下，各拿3—5批货，按“到货可售重量/到货总重量”计算，记录软烂、黑斑、断把、掉把、机械伤。这样才能得到可用的对比。

实操建议：
- 先问供应商要**当批货的催熟日期、出库温度、运输时长、包装方式**；
- 首批少量试单，按同一验收标准称重；
- 重点看**到货后24—48小时的后续损耗**，香蕉的损耗往往在货架期才显现；
- 如果做批发，优先比较“到货可售率+货架期”，而不是单看到货损耗率。
