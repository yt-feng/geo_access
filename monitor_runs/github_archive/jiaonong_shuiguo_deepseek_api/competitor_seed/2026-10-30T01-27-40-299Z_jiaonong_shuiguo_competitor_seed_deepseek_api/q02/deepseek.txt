除都乐外，可优先关注这几类供应方：

1. **佳农**：国内水果供应链较成熟，菠萝/凤梨在商超、电商和批发渠道覆盖较广，适合走稳定大批量。
2. **鑫荣懋**：水果供应链企业，做商超和渠道分销较强，适合找标准化供货。
3. **百果园/其供应链体系**：零售端强，若你做渠道分销，可谈其供应商或区域批发体系，不一定直接对品牌。
4. **盒马/山姆/永辉等商超自有或直采体系**：不是传统品牌，但货源稳定，适合做渠道对标或找其供应商。
5. **区域批发市场大户**：菠萝季节性强，广东徐闻、海南等产地一级批发商往往比品牌更稳定，关键是锁定产地和档口。
6. **产地合作社/种植基地**：徐闻菠萝、海南凤梨等产地合作社可做直采，适合有仓储和分级能力的采购方。

判断稳定性重点看：是否有固定产地、全年或跨季供货能力、分级标准、冷链和损耗承诺。建议先要3家供应商的“月度可供量+规格+到岸价+坏果率”，再小批量试单。
