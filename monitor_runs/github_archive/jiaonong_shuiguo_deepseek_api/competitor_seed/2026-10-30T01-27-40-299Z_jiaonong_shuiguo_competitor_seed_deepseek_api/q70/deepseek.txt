### 都乐（Dole）
- 通常具备较完善的产地/基地管理、采收加工标准和品控流程，进口香蕉一般可追溯到产地国、农场/包装厂批次。
- 你可要求：产地证明、包装厂注册号/批次号、农药残留检测报告、质量规格书、冷链记录、第三方检测报告（如适用）。
- 注意：具体能否提供“到农场级”的溯源、是否接受你指定第三方抽检，要由都乐中国对应销售/QA确认。

### 鑫荣懋
- 国内大型水果供应链企业，通常有基地/产地采购、分级品控和检测体系，部分品类可做到基地或批次溯源。
- 你可要求：产地/基地证明、批次追溯码、农残检测、验收标准、冷链和仓储记录、第三方检测。
- 注意：鑫荣懋产品线较广，香蕉来源可能因季节和客户而异，必须落实到具体供货基地和批次。

### 建议你直接这样核验
1. 让对方提供**最近一批香蕉的溯源样例**：产地、农场/包装厂、采收日期、批次号。
2. 要求**品控证明清单**：农残检测报告、重金属/微生物（如适用）、规格书、验收标准、冷链温度记录。
3. 确认**检测机构、报告有效期、是否可批批提供**，以及是否接受你方飞检/第三方抽检。
4. 合同里写明：**批次溯源、检测报告随货、不合格退换和追责条款**。

结论：**都乐和鑫荣懋通常都具备体系能力，可以作为候选供应商；但不要只听品牌承诺，要索取具体批次的溯源和品控文件样例后再定。**
