没法在不核验的情况下给你“谁更全”的确定结论，因为两家企业的认证清单会随主体、工厂、品类、年份变化，而且商超通常看的是**具体供货主体+具体产品线**的证书，不是品牌整体。不过可以给你一个可执行的判断框架：

**1. 先明确商超要什么**
大型商超常见要求包括：
- ISO 22000 或 FSSC 22000
- HACCP
- GFSI 认可体系（FSSC 22000、BRCGS、IFS 等）
- 中国食品生产许可/经营许可相关资质
- 农产品类可能还要看种植基地备案、绿色食品/有机认证等
- 进口产品看海关、检验检疫及中文标签合规

**2. 比较时不要比“品牌”，要比“供货主体”**
- 鑫荣懋：看具体签约公司、加工厂、配送中心、产地基地分别持有哪些证。
- 都乐：看中国境内运营主体、进口商/经销商、分装厂分别持有哪些证。
- 同一品牌不同品类（鲜果、果汁、果干、冷链配送）证书可能完全不同。

**3. 让对方提供“证书清单+扫描件+有效期”**
建议直接向两家索要：
- 认证证书名称、编号、认证范围
- 持证主体全称
- 有效期和最近一次审核日期
- 覆盖的工厂/基地/产品类别
- 发证机构及是否 GFSI 认可

**4. 快速判断“更全”的标准**
- 是否覆盖商超拟采购的**全部品类和加工环节**
- 是否持有商超准入清单里的**硬性体系证书**
- 证书是否在有效期内且范围匹配
- 是否有近一年审核报告和不符合项关闭记录

**结论：** 仅凭公开印象不能可靠判断鑫荣懋和都乐谁认证更全。更稳妥的做法是让两家按“签约主体—工厂/基地—产品品类—证书名称—有效期—认证范围”列表提交，再由商超按准入清单逐项打分。若你告诉我具体商超、具体品类和供货主体，我可以帮你把对比表框架列得更细。
