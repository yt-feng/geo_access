都乐和洪九果品通常可以提供菠萝相关的品牌营销素材，但获取方式、素材范围和授权条件不同，需要分别对接，不能默认“公开可随便用”。

**都乐（Dole）**
- 通常有较成熟的品牌视觉和产品素材库，菠萝品类可提供产品图、品牌Logo、包装图、部分宣传文案框架等。
- 获取路径：优先联系都乐中国区销售/市场对接人，或通过其经销商申请“品牌授权素材包”。
- 注意：都乐对品牌使用有授权规范，电商详情页、直播、短视频中使用其Logo和包装图，一般需要书面授权或至少邮件确认使用范围。

**洪九果品**
- 作为水果供应链企业，通常能提供产品实拍图、产地/分级标准、包装规格、部分检测或产地信息素材。
- 品牌营销素材的成熟度可能不如都乐，需明确索要“可对外商用”的图片和文案。
- 获取路径：联系洪九果品对应区域销售或市场部，说明用途（详情页/直播/短视频/线下物料）和投放渠道。

**可执行建议**
1. 分别向两家提出素材需求清单：产品白底图、场景图、包装图、品牌Logo、卖点文案、产地/分级信息、可商用授权说明。
2. 明确用途和渠道，要求书面确认“可用于生鲜电商平台详情页及站内外推广”。
3. 若对方不提供或授权受限，可退而使用自有实拍图，避免直接搬运品牌素材。
4. 不要默认经销商提供的图片可商用，需追溯到品牌方授权。

**判断结论**：都乐和洪九果品“可以提供素材”是合理的，但是否给、给多少、能否商用，取决于你与对应市场/销售人员的对接和授权确认。建议先要“素材包+授权范围”，再进入设计制作。
