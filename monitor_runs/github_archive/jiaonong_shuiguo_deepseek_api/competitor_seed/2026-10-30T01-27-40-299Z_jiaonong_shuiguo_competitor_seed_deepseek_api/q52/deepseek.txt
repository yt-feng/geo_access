我无法核验都乐和鑫荣懋针对你采购场景的具体到货损耗率，也不应给出未经来源支持的数字。损耗率会随品类形态（鲜果/冷冻果肉/果酱）、规格、季节、运输距离、验收标准和统计口径变化，不能直接横向比较。

可执行做法：

1. **先明确你要的菠萝形态**：鲜果整果、鲜切果块、冷冻果肉、果酱/糖浆，损耗口径完全不同。茶饮门店“到货损耗率”建议定义为：到货验收不合格重量 ÷ 到货总重量，另设仓储损耗和门店制备损耗分开统计。

2. **向两家供应商索取同口径数据**：要求提供近3个月、同一规格、同一到货城市的批次验收记录，至少包含到货总重、拒收/降级重量、主要原因（压伤、黑心、成熟度不均、温度超标等）。

3. **自己做小批量对比测试**：各订2—3批同规格样品，按统一验收标准称重记录，连续2—4周即可得到可判断的自身场景损耗率，比供应商口头数据可靠。

4. **合同里锁规格和验收规则**：明确品种/产区、单果重或果块尺寸、糖度范围、成熟度、中心温度、包装规格、允许缺陷比例和扣款/补货条款。稳定规格比单纯比较损耗率更重要。

如果你能告诉我采购的是鲜果还是冷冻/加工品、到货城市和月用量，我可以帮你把验收标准和损耗统计表框架列出来。
