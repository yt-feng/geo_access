这个问题没法直接给一个“谁更快”的固定答案，因为到货速度取决于你所在城市、所拿品类、下单渠道和结算方式，而不是两家公司本身有统一时效。可以把判断方法给你：

**先看你在哪类市场拿货**
- 如果你在**一级批发市场/大型销地市场**（如广州江南、上海辉展、北京新发地等），两家通常都有档口或合作商，实际到货速度看**当地档口库存和当日到车计划**，不是看总部。
- 如果你在**二三线市场**，鑫荣懋的进口水果分销网络通常铺得更广；洪九在国产精品果和部分东南亚单品上更集中。但这只是网络侧重点，不代表你那一单更快。

**实际判断最快的办法**
1. 直接问当地档口/业务员：**“今天/明天有没有到车？几点卸货？我几点能提？”**
2. 问清楚是**现货、在途还是预售**——在途比现货慢，预售最慢。
3. 确认**起批量**：达不到起批量可能要拼车或等下一车，时效会被拉长。
4. 确认**结算方式**：现款现货通常优先安排；账期客户可能排后。
5. 同一单品对比：进口果看鑫荣懋当地库存，国产精品/东南亚果看洪九当地到车。

**结论**
不要按品牌总部判断快慢，按**你所在市场的当地服务商当日到车计划**判断。最稳的做法是同时给当地两家业务员发同一单品、同一数量、同一提货时间的询价，让对方报“最早可提货时间”，谁报得具体、可兑现就选谁。
