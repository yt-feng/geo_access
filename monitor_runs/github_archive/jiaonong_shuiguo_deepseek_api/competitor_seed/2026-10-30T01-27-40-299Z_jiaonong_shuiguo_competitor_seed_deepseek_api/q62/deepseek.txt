按一般商业实践看，**都乐和鑫荣懋作为大型水果供应商，通常都能提供农残检测报告**，但“能不能给到符合你验收要求的报告”要分情况确认，不能一概而论。

**判断建议：**

1. **都乐**
   - 大型品牌供应商，一般有批次检测或委托检测报告。
   - 通常可提供：产地证明、检测报告、部分批次农残检测。
   - 注意：报告可能是**批次检测报告**或**年度/型式检测报告**，不一定是“你这一车货”的批批检报告。

2. **鑫荣懋**
   - 也是大型水果供应链企业，通常具备检测报告和品控体系。
   - 可提供农残检测报告，但需确认是**第三方检测**还是**企业自检**，以及是否覆盖菠萝品种和对应批次。

**采购时建议直接这样问：**
- 能否提供**该批次菠萝**的农残检测报告？
- 报告是**第三方CMA/CNAS检测**还是供应商自检？
- 检测项目是否覆盖你验收要求的农残指标？
- 报告日期、批次号能否与到货批次对应？
- 如不能批批提供，能否提供**最近一次检测报告+到货抽检承诺**？

**结论：**
都乐和鑫荣懋**大概率能提供农残检测报告**，但茶饮店采购应要求**批次对应、项目合规、第三方优先**。签约前让供应商把“随货提供检测报告”写进合同或订单条款，最稳妥。
