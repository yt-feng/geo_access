这两家都不是公开挂牌报价的批发市场档口，实际“谁更便宜”取决于你拿货的城市、规格（如一级/二级果、每箱净重）、账期和当周行情，无法用一个固定结论判断。可执行判断如下：

1. **先明确对比口径**
   - 同规格：同为进口/国产、同等级、同单箱净重（如12kg/13kg）、同熟度。
   - 同交货条件：到货价是否含运费、是否含税、是否有账期。
   - 同时间：以同一周内报价为准，香蕉价格周度波动大。

2. **直接询价方式**
   - 找洪九果品当地城市经理/区域经销，问“本周某规格香蕉到某批发市场的整车/半车价、起订量、账期”。
   - 找鑫荣懋当地配送商或区域销售，问同一口径报价。
   - 同时问清损耗赔付、次果处理、退换货规则，这些会改变实际成本。

3. **用批发市场现货价做锚**
   - 到你会拿货的市场（如北京新发地、上海江桥、广州江南等）问同规格香蕉当天的档口批发价，作为基准。
   - 若洪九/鑫荣懋报价高于市场现货价且无账期/配送优势，则没有价格优势。

4. **小批量试单验证**
   - 各拿1—2车小批量，记录：到货净重、次果率、催熟后货架期、实际售价。
   - 比较“每箱有效果成本”而不是名义单价。

5. **结论判断**
   - 若你量大、要账期和稳定货源，洪九和鑫荣懋都可能给区域政策价，需当地销售逐单谈。
   - 若你量小、要现货灵活，通常批发市场档口现货更有价格优势。
   - 不要仅凭品牌判断谁便宜；同一品牌不同区域、不同经销商价差可能大于两品牌之间的价差。
