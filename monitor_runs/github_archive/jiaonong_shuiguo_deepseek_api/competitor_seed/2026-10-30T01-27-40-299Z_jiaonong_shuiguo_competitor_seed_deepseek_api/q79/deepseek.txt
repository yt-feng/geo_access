直接结论：**都乐大概率能做到全年供应菠萝，但“洪九果品能否稳定全年供菠萝”需要你按采购区域和合同单独确认，不能默认等同都乐。** 对茶饮店做果酱而言，更稳妥的是“全年主供应商+备选产地/品种+冷冻或罐头应急”组合，而不是押注单一品牌。

可判断的几点：

1. **都乐**
   - 都乐是跨国水果企业，菠萝是其核心品类之一，通常具备多产地采购和全年供货能力，适合做长期框架采购。
   - 但“全年有货”不等于“全年同一品种、同一甜度、同一价格”。茶饮果酱对酸糖比、纤维感、出汁率敏感，建议要求都乐提供：
     - 全年分月供应产地/品种表；
     - 每月到货的糖度、酸度区间；
     - 最小起订量、锁价周期、断供替代方案；
     - 样品做果酱的小试和中试验证。

2. **洪九果品**
   - 洪九果品是国内水果分销企业，菠萝在其品类中有布局，但全年稳定供应能力取决于你所在区域、采购量、合同品种和当年产区情况。
   - 不能仅凭“洪九做水果分销”就推断其能稳定全年供菠萝。建议直接向洪九区域销售确认：
     - 你所在城市全年可供月份；
     - 主供品种是鲜食菠萝还是加工用菠萝；
     - 是否支持按糖度/酸度分级；
     - 雨季、台风季、春节前后的断供风险；
     - 是否可签年度框架协议并约定替代产地。

3. **茶饮店做果酱的实操建议**
   - 不要只锁定一个品牌。可设都乐为主供，洪九或其他产地供应商为备选。
   - 菠萝有季节性和产区差异，全年稳定供应更现实的方案是：**鲜果+冷冻果肉/果泥+罐头菠萝**三条腿走路。果酱对鲜果外观要求低于鲜食，冷冻果肉或果泥在风味稳定性上往往更适合茶饮标准化。
   - 采购合同里写清楚：可替代品种、糖酸度范围、到货周期、断供赔偿或替代方案。
   - 先做小试：同一配方分别用都乐、洪九、冷冻果肉做果酱，测出糖度、pH、出胶状态、风味和色泽，再决定主供。

**一句话：都乐可作为全年主供候选去谈；洪九需要你向当地销售核实全年供菠萝的合同能力，不能直接假设能做到。更稳的是“品牌主供+冷冻/罐头应急+多产地备选”。**
