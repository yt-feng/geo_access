都乐和鑫荣懋都属于头部水果供应链企业，但两者的物流模式不同；菠萝产地直发时效不能只看品牌，还要看具体发货仓、目的地和是否走冷链整车/零担。可先按下面判断：

1. **都乐**
   - 通常有全国多仓分拨+成熟冷链体系，产地直发更多见于大单品/大宗订单。
   - 对生鲜电商的参考时效：华东/华南核心城市通常可做到**产地发运后1–3天到仓**；偏远或非核心城市一般**3–5天**，具体以起运地、到货仓和是否整车直发为准。
   - 优势是标准化和品控较稳；劣势是直发灵活度不一定适合小批量高频补货。

2. **鑫荣懋**
   - 同样有较强产地采购和冷链网络，偏商超、渠道批发和大型客户供应，产地直发能力也较强。
   - 参考时效与都乐接近：核心城市**1–3天到仓**，非核心区域**3–5天**；如果走市场批发/区域分拨，可能多一道中转。
   - 优势是产地资源和渠道覆盖；需要确认具体菠萝品种、包装规格和起运仓。

**可执行建议：**
- 直接向两家索取你计划发货的**具体产地（如广东徐闻/海南/云南等）→你所在城市仓**的**近30天实际签收时效**，不要只问“平均时效”。
- 重点核验：起运仓、是否全程冷链、整车/零担、最小起订量、破损/压伤赔付、到仓预约时效。
- 生鲜电商建议先小批量试单，按**48小时/72小时签收率、到仓破损率、温控记录**做对比，再决定主供和备供。

结论：两家在核心区域通常都能做到**1–3天**，非核心区域**3–5天**；但菠萝产地直发的真实时效必须以具体线路和近期履约数据为准，不能只用品牌判断。
