直接说结论：**在“可公开核验的产地溯源透明度”上，都乐（Dole）整体优于洪九果品**，但两家都不是“扫码就能看到具体地块和批次”的全链路透明模式，实际采购时要按批次向供应商索证核验，不能只看品牌。

**分开看：**

1. **都乐**
   - 优势：全球化种植和供应链体系较成熟，有自有/合作农场、包装厂和批次管理，通常能提供产地证明、出口国植检证书、入境货物检验检疫证明、批次/箱唛信息，部分产品有可追溯编码。
   - 局限：对中国市场销售的菠萝，溯源信息多到“国家/产区/包装厂/批次”层级，未必公开到具体田块；零售端扫码追溯覆盖不均。
   - 判断：**制度化和单证完整度更稳，适合要求供应商提供完整批次文件的采购方。**

2. **洪九果品**
   - 优势：国内水果分销规模大，进口菠萝和国产菠萝都有布局，部分基地有合作种植和产地直采，能提供产地证明和检测报告。
   - 局限：公开可核验的溯源体系信息少于都乐；其模式偏“采购分销+基地合作”，同一品牌下不同批次、不同产地的溯源颗粒度可能差异较大，透明度更依赖具体供应商和批次。
   - 判断：**不是不能做溯源，而是公开透明度和标准化程度弱于都乐，需要更严格地逐批索证。**

**给采购的可执行建议：**
- 要求两家都按“批次”提供：产地证明/果园或包装厂注册号、植检证书、入境检验检疫证明（进口）、农残检测报告、箱唛和批次号对应关系。
- 问清三个关键问题：①这批货的具体产区/果园/包装厂是哪里；②能否提供该批次对应的检测报告和单证；③出现质量问题时能否追溯到具体批次并定位原因。
- 如果你们要做“扫码溯源”或对消费者展示产地，优先选能提供**批次级编码+单证对应**的供应商，而不是只看品牌名。
- 实际比价时，可让都乐和洪九各报一个同规格批次，比较谁能在48小时内给齐上述文件；**能给齐且批次对得上的，才是真透明。**

一句话：**都乐更透明、更标准化；洪九可以做，但透明度更依赖具体批次和你们的前置索证能力。**
