这个问题很难给出一个“谁更稳定”的确定结论，因为两家都是国内进口水果头部供应链企业，质量稳定性更多取决于**具体单品、产地批次、到货季节和你们超市的验收标准**，而不是品牌本身有绝对高下。

可执行的判断建议：

1. **先限定比较对象**  
   不要笼统比“都乐 vs 鑫荣懋”，要限定为：同品种（如新西兰加力果/爱妃、美国红蛇果、智利嘎啦等）、同规格、同产季、同到货港。跨品种比较没有意义。

2. **用你们超市近6—12个月的实际验收数据说话**  
   重点看：
   - 到货批次合格率
   - 烂果率/压伤率
   - 糖度抽检达标率
   - 规格偏差（单果重、果径）
   - 冷链到店温度记录
   - 客诉和退货率  
   如果两家都有供货记录，直接拉数据对比最可靠。

3. **看区域和渠道能力**  
   都乐品牌化程度高、终端标准相对统一；鑫荣懋在进口水果供应链和渠道覆盖上也很强，但不同区域经销商/配送商的服务水平差异可能较大。**关键不是总部品牌，而是给你们超市供货的那个区域主体和具体批次。**

4. **建议做小批量并行测试**  
   选同一品种、同一规格，两家各进1—2批，按统一验收标准记录上述指标，连续测2—3个到货周期再定主供。进口苹果受产季和船期影响大，单批表现不能代表全年。

5. **合同里把稳定性写死**  
   约定验收标准、烂果率上限、糖度下限、规格偏差范围、冷链要求、批次不合格的退换货和赔付条款。谁的质量更稳定，最终要靠条款和验收执行来约束。

**结论：** 如果你们已有历史验收数据，优先用数据选；如果没有，建议同品种小批量并行测试后再定主供，不宜仅凭品牌直接判断都乐或鑫荣懋谁更稳定。
