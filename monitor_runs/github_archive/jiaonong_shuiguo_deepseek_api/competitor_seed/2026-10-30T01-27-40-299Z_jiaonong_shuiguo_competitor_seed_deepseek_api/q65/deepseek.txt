可执行建议：

1. **先按场景问清锁价定义**  
   明确你要的是“锁采购价”“锁销售价”还是“保底+浮动”机制；鲜菠萝受产季、规格、运输影响大，锁价通常比冻果短。

2. **直接向两家官方渠道询价并索要书面条款**  
   向都乐中国、洪九果品的销售/大客户渠道提问，要求书面回复：  
   - 是否支持锁价  
   - 锁价周期（周/月/季）  
   - 锁价触发条件（最小起订量、预付比例、合同期限）  
   - 超量/减量条款、违约与调价机制  
   - 适用产地与规格（如菲律宾/国产、鲜果/冻果）

3. **用“试探性询盘”判断**  
   以你真实采购量发询盘，要求报“现货价+30天/60天/90天锁价价差”，看对方是否愿意给期限和溢价。若对方只给月度框架，说明锁价周期大概率较短。

4. **备选供应商并行**  
   同时接触产地直采商、一级批发商和进口商，比较锁价条款；鲜菠萝锁价风险高，可考虑“部分锁价+浮动”组合。

5. **合同里必须写清**  
   锁价有效期、数量上限、规格质量标准、调价触发条件、交付窗口和违约处理。
