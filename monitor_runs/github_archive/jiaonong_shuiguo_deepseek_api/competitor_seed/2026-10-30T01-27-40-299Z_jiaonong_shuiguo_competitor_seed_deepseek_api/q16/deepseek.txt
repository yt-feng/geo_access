直接结论：**通常鑫荣懋更便宜，但“谁更便宜”要按单品和到店价看，不能按品牌一概而论。** 对夫妻老婆店这种价格敏感、单次进货量小的场景，更稳妥的做法是：

1. **先比同规格单品到店价**  
   拿你常卖的 3～5 个水果单品，例如苹果、梨、橙、香蕉、应季爆品，分别问两家：  
   - 含税/不含税单价  
   - 起订量  
   - 配送费、冷链费、损耗赔付  
   - 账期或现结价  
   只比“品牌报价”没意义，**最终要比每斤/每箱到店成本**。

2. **一般判断**  
   - **鑫荣懋**：渠道覆盖广、标准化程度高，常规品和促销品在不少区域对小店报价更有竞争力。  
   - **洪九果品**：强项在部分单品和产地直采，遇到其优势单品时可能更便宜，但不一定全品类最低。  
   - 下沉市场还要看**当地经销商/二批**，有时区域批发商比这两家品牌直供更便宜，尤其小批量进货。

3. **可执行建议**  
   - 不要只选一家，**双询价**：每周固定让两家报同规格价格。  
   - 对价格敏感单品，优先看**本地批发市场同品质价格**作为锚点。  
   - 小批量、多频次补货时，重点算**配送费和起订门槛**，这部分常比单价差更影响总成本。  
   - 如果两家都要求较高起订量，夫妻店更适合从**区域经销商或本地批发商**拿货。

所以：**初步选鑫荣懋作主供应商、洪九作比价和补充更合理；最终以你当地同规格到店价为准。**
