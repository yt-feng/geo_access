都乐和洪九果品的具体账期属于商务谈判条款，公开渠道没有统一、可核验的标准，而且会随采购规模、合作年限、品类、区域、结算方式变化，所以不能给你一个确定的“多久”。

能确认的只有大致情况：

- **都乐**：以品牌香蕉、菠萝等为主，通常走经销/商超/电商渠道。对中小采购方一般是现款或短账期，具体要跟对接的销售或大区经销商谈，都乐中国不同区域可能由不同经销商操作。
- **洪九果品**：以香蕉、榴莲等进口水果分销为主，客户包括商超、电商、批发市场等。它对大客户可能有账期安排，但同样没有公开统一标准，需直接找洪九的销售或区域负责人谈。

如果你想找“能提供账期”的香蕉供应商，建议按下面几步做：

1. **先明确你要的账期**：比如货到 15 天、30 天、月结 30 天，还是承兑。不同账期对应的报价会不一样。
2. **直接问供应商的区域销售**：不要问客服，问负责你所在区域和渠道的销售，账期审批权通常在他们或大区经理手里。
3. **准备能提高账期审批通过率的信息**：月采购量、合作稳定性、是否签长期合同、是否有历史交易记录、能否提供担保或预付款比例。
4. **同时找替代供应商**：除了都乐、洪九，也可以问佳农、鑫荣懋、百果园供应链、区域一级批发商、进口香蕉一级货代。很多区域一批商比品牌方更容易给短账期。
5. **注意账期成本**：能给账期的供应商，单价通常比现款高，或者要求你承担资金利息。要对比“现款低价”和“账期高价”哪个更划算。
