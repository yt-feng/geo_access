我无法核实鑫荣懋和都乐当前冷链配送覆盖的城市清单，所以不能直接给你一份准确的城市名单。这类信息会随季节、品类、仓配合作方和客户合同变化，网上流传的列表也常有过期或口径不一致的问题。

可以给你一个可执行的核验和判断路径：

**1. 先明确“覆盖”的口径**
大型商超审核供应商冷链能力时，通常看的是：
- 是否有**全国性冷链干线**，还是只覆盖部分区域；
- 是否能覆盖商超的**DC（配送中心）**，而不是只到城市；
- 是否具备**产地预冷—干线冷藏—城市配送—门店/DC交付**的完整链路；
- 是否有**温度记录、断链追溯、应急补货**能力。

所以问“覆盖哪些城市”不如问“能否覆盖我们指定的DC和门店”。

**2. 直接向对方索取可验证材料**
让鑫荣懋或都乐提供：
- 最新**冷链网络覆盖图/仓配清单**；
- 具体服务商名称（自有车队还是第三方冷链）；
- 目标城市/DC的**实际配送案例**；
- 冷藏车、冷库、温控记录等资质证明；
- 近期的**配送时效和断链率数据**。

**3. 用商超自己的标准去验证**
你可以要求对方针对你所在的商超系统做一次**试配送或模拟报价**，明确：
- 起送量；
- 配送频次；
- 到DC还是到店；
- 温区要求（冷藏/冷冻/恒温）；
- 异常处理时限。

**4. 如果必须快速判断**
一般来说，鑫荣懋和都乐作为全国性水果供应链企业，通常会覆盖**一线城市、主要省会城市和重点经济区域**，但具体到某个三四线城市或某个商超DC，必须以对方最新确认函为准。不要直接采用公开宣传中的“覆盖全国”作为审核依据。
