除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些：

**综合类国际水果品牌**
- **德尔蒙（Del Monte）**：菠萝、香蕉、鲜切水果等，礼盒装常见，品牌认知度高。
- **新奇士（Sunkist）**：美国柑橘类代表，脐橙、柠檬礼盒适合商务送礼。
- **怡颗莓（Driscoll's）**：浆果类强势品牌，蓝莓、树莓、黑莓礼盒包装精致，适合高端团购。
- **乐淇（Rockit）**：新西兰小苹果，筒装/礼盒装辨识度高，适合员工福利和商务伴手礼。
- **爱妃（Envy）**：新西兰/美国苹果品牌，果大、卖相好，常见高端礼盒。
- **爵士（Jazz）**：苹果品牌，礼盒装较多。
- **青森（Aomori）**：日本苹果产区品牌，世界一号等大果礼盒适合高端送礼。
- **SWEETEE**：美国新奇士体系外的柑橘/葡萄柚品牌，部分渠道有礼盒。
- **SunGold / SunWorld**：葡萄、核果类品牌，夏季礼盒可选。

**单品强势品牌**
- **佳沃（Joyvio）**：虽是中国品牌，但常做进口蓝莓、车厘子礼盒，团购渠道成熟。
- **鑫荣懋**：国内进口水果供应链品牌，代理多个国际品牌，适合企业团购定制。
- **Mr Apple**：新西兰苹果品牌，礼盒装常见。
- **Chelan Fresh**：美国车厘子、苹果品牌。
- **Stemilt**：美国车厘子、苹果、梨品牌。
- **Oneonta**：美国车厘子品牌。
- **Vanguard**：智利车厘子品牌，冬季团购热门。
- **Garces Fruit**：智利车厘子品牌。
- **Copefrut**：智利车厘子、蓝莓品牌。

**按场景建议**
- **高端商务送礼**：怡颗莓、乐淇、爱妃、青森苹果、日本/韩国高端葡萄礼盒。
- **员工福利团购**：新奇士脐橙、德尔蒙菠萝、佳沃蓝莓/车厘子、Mr Apple。
- **冬季团购**：智利车厘子品牌（Vanguard、Garces、Copefrut等）+ 新西兰/美国苹果。
- **夏季团购**：美国车厘子、SunWorld葡萄、Driscoll's浆果。

**注意**
1. 很多“进口品牌”在国内有分装或授权种植，采购时要确认原产地、规格、糖度、包装是否适合团购。
2. 礼品团购重点不只是品牌，还要看：果径/规格统一、损耗率、冷链、能否定制贺卡/手提袋、开票和售后。
3. 建议直接找一级进口商或区域总代拿货，比如鑫荣懋、佳沃、百果园供应链等，比零散批发更稳。
