都乐（Dole）和洪九果品的菠萝供应基地，可以这样判断：

**都乐（Dole）**
- 都乐在菲律宾有长期菠萝种植和加工基地，主要在南棉兰老岛、北棉兰老一带，如布基农、南达沃等产区。
- 在中国市场，都乐也销售菲律宾进口菠萝，部分季节有国内合作基地，但核心稳定供应仍以菲律宾产区为主。
- 采购时通常走都乐中国公司或授权经销商，不是直接对接菲律宾农场。

**洪九果品**
- 洪九果品是国内水果分销龙头之一，菠萝不是只靠单一自有基地，而是“自有基地 + 产地直采 + 进口”组合。
- 其国内菠萝采购重心主要在广东徐闻、海南、云南等产区；进口方面也会做菲律宾、泰国等来源。
- 洪九的优势是分选、催熟、冷链和全国分销，不是像都乐那样以单一品牌农场基地为核心。

**给茶饮采购的实操建议**
1. 先确定你要的是鲜果、冷冻果肉、果泥还是浓缩汁。茶饮店用菠萝，很多其实是冷冻菠萝丁、菠萝果肉或果酱，不是整果。
2. 要稳定供应，优先找：
   - 都乐：适合要品牌背书、菲律宾进口稳定货；
   - 洪九：适合要国内多产区调配、全国分仓配送；
   - 地方加工厂：适合定制冷冻菠萝丁、糖渍菠萝、菠萝果酱，成本更低。
3. 签供应协议时重点看：
   - 规格：品种、糖度、酸度、纤维感、切型；
   - 冷冻还是鲜果；
   - 年度锁价还是随行就市；
   - 断供替代方案，比如菲律宾货紧张时能否切广东徐闻或海南货。
4. 如果做连锁茶饮，建议“双源采购”：都乐/进口源 + 国内徐闻/海南源，避免单一产地天气或通关问题导致断供。

简单说：都乐稳定供应核心看菲律宾基地；洪九更多是国内多产地直采加进口分拨。你要做茶饮原料，最好直接问他们要“菠萝原料规格书”和“近12个月产地供应比例”，这比只问基地在哪里更实用。
