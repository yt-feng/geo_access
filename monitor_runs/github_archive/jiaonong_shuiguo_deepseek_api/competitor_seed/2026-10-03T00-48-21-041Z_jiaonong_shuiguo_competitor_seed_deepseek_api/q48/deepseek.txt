商超若在供应商准入中要求“食品安全认证”，通常会核验两类材料：一是通用食品安全管理体系认证，二是具体产品的检测/合规证明。就鑫荣懋和都乐这类水果供应链企业来说，公开可查的信息往往不是完整清单，而且不同主体、不同品类、不同工厂/包装厂持有的资质也可能不同，所以不能仅凭品牌名给出确定结论。

可以按下面方式判断和核验：

1. **鑫荣懋**
   - 常见可核验方向：ISO 22000、HACCP、FSSC 22000、BRCGS、GLOBALG.A.P.、绿色食品/有机认证、出口备案等。
   - 注意：鑫荣懋体系下可能有多个子公司、加工厂、配送中心，认证通常对应具体法律主体和场所，不是“鑫荣懋”三个字统一覆盖。

2. **都乐**
   - 都乐为跨国果蔬品牌，常见可核验方向：GLOBALG.A.P.、ISO 22000、HACCP、BRCGS、FSSC 22000、有机认证、雨林联盟等。
   - 注意：都乐在中国可能涉及不同运营主体、进口商、加工配送企业，具体证书要以实际供货主体为准。

3. **商超准入时建议直接索要**
   - 营业执照、食品经营许可证/食品生产许可证；
   - ISO 22000、HACCP、FSSC 22000、BRCGS 等体系证书；
   - GLOBALG.A.P.、有机、绿色食品等产品认证；
   - 第三方检测报告、入境货物检验检疫证明（进口产品）；
   - 证书认监委官网/认证机构官网可查性截图。

4. **最稳妥的核验方式**
   - 要求供应商提供证书扫描件；
   - 到“全国认证认可信息公共服务平台”核验体系认证；
   - 对有机产品到“中国食品农产品认证信息系统”核验；
   - 核对证书上的企业名称、地址、认证范围是否与实际供货主体一致。
