直接结论：**不能简单说都乐或鑫荣懋谁一定更便宜，进口苹果的价格竞争力主要取决于品类/产地、规格、到货批次、结算方式和你的采购量。** 但从水果连锁的常规操作看，可以给你一个判断框架：

**1. 都乐 vs 鑫荣懋的定位差异**
- **都乐**：品牌溢价通常更高，终端认品牌，适合做中高端陈列、礼盒、稳定品项。  
  但它的价格往往不是最低，优势在品牌、标准化、品控稳定、消费者认知。
- **鑫荣懋**：国内大型水果供应链企业，进口水果操作能力强，渠道覆盖广，部分品项在批量采购时价格可能更有弹性。  
  优势在供应链规模、进口操作、部分单品性价比和灵活度。

**2. 谁更有价格竞争力，要看这几个条件**
- **具体品种**：比如新西兰爱妃、红玫瑰、太平洋玫瑰、美国蛇果、智利嘎啦等，不同公司优势品项不同。
- **规格和等级**：70#、80#、85#、90#，以及一级果、二级果、贴牌果，价差很大。
- **到货港口和批次**：上海、广州、深圳、天津等港口成本不同，当季到货量大会压低价格。
- **结算方式**：现款、账期、返利、运费承担、损耗补贴，都会影响真实到手价。
- **采购量**：你如果是几十家店统一采购，议价空间和单品锁价能力完全不同。
- **是否需要贴牌/定制包装**：都乐通常品牌管控更严，鑫荣懋在定制和渠道合作上可能更灵活。

**3. 实操建议：不要只问“谁便宜”，要拿同一标品比价**
建议你让两家按同一标准报价：

- 同一品种：如新西兰爱妃苹果
- 同一规格：如80#、90#
- 同一等级：如一级果
- 同一包装：如18斤/箱、20斤/箱
- 同一到货港/到你仓运费
- 同一账期：如现款、15天、30天
- 同一返利和损耗政策

然后比较 **到手净价**，而不是挂牌价。

**4. 更可能的情况**
- 如果你要**品牌拉动、礼盒、高端门店**：都乐可能更合适，但价格通常不占优。
- 如果你要**批量走量、常规门店、成本优先**：鑫荣懋在部分进口苹果单品上可能更有价格竞争力。
- 如果你采购量大且多门店分销：建议两家都谈，甚至引入第三家比价，避免被单一供应商锁定。

**5. 最直接的动作**
你可以先向都乐和鑫荣懋各要一份 **进口苹果单品报价单**，重点看：
1. 爱妃/红玫瑰/嘎啦/蛇果等主推单品
2. 80#、85#、90# 三个规格
3. 一箱净重、到仓价、账期、返利
4. 最近3个批次的到货价和损耗率

拿到同一口径的数据后，谁更有竞争力就一目了然。  
**一句话：都乐强在品牌和稳定，鑫荣懋强在供应链和部分品项价格弹性；具体谁便宜，必须按同品种、同规格、同账期比到手价。**
