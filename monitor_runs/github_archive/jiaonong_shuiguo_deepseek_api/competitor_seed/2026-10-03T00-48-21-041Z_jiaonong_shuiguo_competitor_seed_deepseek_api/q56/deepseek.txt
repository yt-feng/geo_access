如果只问 **在中国生鲜电商平台做“品牌背书”时的全国性品牌知名度**，通常 **都乐（Dole）更高**。

更具体判断：

1. **都乐（Dole）**
   - 全国性认知更强，属于典型国际水果品牌。
   - 在香蕉品类里，“都乐香蕉”消费者心智更直接，平台做背书时更容易被用户识别。
   - 适合强调：进口/国际品牌、标准化、稳定供应链、商超同款。

2. **鑫荣懋**
   - 是中国头部水果供应链企业，B端和渠道端知名度很强。
   - 旗下有“佳沃”等品牌体系，但在普通消费者端，尤其香蕉单品上的直接品牌认知，通常不如都乐。
   - 优势更多在：国内供应链、渠道覆盖、成本控制、稳定供货、产地资源。

所以结论是：

- **消费者端品牌知名度：都乐 > 鑫荣懋。**
- **渠道端/供应链端知名度：鑫荣懋也很强，甚至在某些B端场景不弱于都乐。**
- **如果生鲜电商平台要做香蕉品牌背书、提升消费者信任和转化，优先选都乐更稳。**
- **如果更看重供货能力、成本、国内履约和长期供应链合作，鑫荣懋也值得重点合作。**

建议实际决策时再看三个指标：  
1. 你平台用户是一二线还是下沉市场；  
2. 卖的是都乐授权货、进口货，还是国产蕉；  
3. 对方能否给到稳定货源、账期、售后和营销资源。  
品牌知名度只是背书，最终还要看供货和价格是否匹配。
