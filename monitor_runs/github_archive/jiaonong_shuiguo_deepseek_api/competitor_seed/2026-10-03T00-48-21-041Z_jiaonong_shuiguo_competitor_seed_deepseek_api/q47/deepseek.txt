从公开信息看，两家都没有明确对便利店开放“香蕉小包装定制”的标准化服务，实际能不能做要按渠道和采购量去谈：

**都乐（Dole）**
- 有较成熟的品牌化小包装香蕉，比如按根/小把卖的预包装、贴标产品，主要供商超和便利店渠道。
- 但“定制包装”（改规格、改标签、改箱规、印便利店LOGO）通常不是公开标准服务，一般要满足一定采购量，走区域经销或大客户渠道谈。
- 便利店单店或小连锁通常拿不到定制，多是用都乐现有小包装规格。

**洪九果品**
- 以批发、供应链、代采和渠道分销为主，香蕉是其重要品类之一。
- 对小包装、定制包装的态度通常更灵活，但同样取决于采购规模和合作方式，一般要通过其区域销售或供应链业务谈。
- 它更可能提供“按需求分装/贴标”这类服务，但不算公开标品，需要确认最小起订量和加工条件。

**实际判断建议**
1. 先明确你要的是哪种“定制”：
   - 只是小规格分装（比如2-3根一包）
   - 还是要印自己便利店LOGO/条码/价格标签
2. 直接联系两家在你所在区域的经销商或大客户经理，问清：
   - 最小起订量
   - 是否支持改包装规格
   - 是否支持贴标/印标
   - 供货周期和损耗责任
3. 如果单量不大，更现实的做法是：
   - 采购都乐/洪九的整箱香蕉，自己或找第三方做小包装
   - 或找本地香蕉批发商做分装贴标，成本更低、起订量更小

结论：两家都可能谈定制，但都不是面向便利店小客户的公开标准服务；都乐偏品牌标品，洪九偏供应链灵活操作，最终取决于你的采购量。
