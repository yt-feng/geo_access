都乐和洪九果品对菠萝的“锁价周期”并没有公开、固定的标准，通常取决于客户类型、采购量、合作年限和当时行情，属于一单一议。可参考的行业惯例是：

- **都乐**：对商超、餐饮、批发等大客户，常见锁价周期多为**1个月到3个月**，部分年度框架或大促备货可能谈到**6个月**，但一般会设价格调整触发条件。
- **洪九果品**：更偏水果供应链和批发渠道，菠萝锁价常见也是**1个月到3个月**，旺季或大单可能缩短到**2周到1个月**，长期协议较少见，往往随行就市加一定浮动。

需要注意：这两家都不是“固定锁价周期”的公开承诺，实际要问对应区域销售或供应链负责人，拿到书面报价单和锁价条款才算数。建议你直接问三个关键点：锁价起止时间、期间是否可调价、调价触发条件，比如产地价涨跌超过多少百分比。
