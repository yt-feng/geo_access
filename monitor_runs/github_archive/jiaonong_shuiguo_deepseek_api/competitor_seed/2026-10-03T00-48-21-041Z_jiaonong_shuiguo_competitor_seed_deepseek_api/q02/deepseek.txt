菠萝的稳定供应品牌，除了都乐（Dole），主要可以分几个层次来看：

**国际果蔬巨头（全年相对稳定）**
- **Del Monte（地扪）**：在菠萝罐头和鲜果都有布局，菲律宾、哥斯达黎加等产地供应较成熟。
- **Fresh Del Monte**：鲜菠萝在北美、欧洲渠道常见。
- **Fyffes**：主要是香蕉，但也有菠萝等热带水果品类。
- **Chiquita**：以香蕉为主，部分市场也做菠萝。
- **Naturipe / Bonita / Golden Circle**（区域品牌）：在特定市场有稳定供应。

**菲律宾系（鲜菠萝重要来源）**
- **Sumifru（住商水果）**：菲律宾菠萝出口大户，很多商超的菲律宾菠萝来自这里。
- **Marsman / Dizon Farms / Lapanday**：菲律宾本地大型种植出口商。
- **Philpack**：菠萝加工和出口较有名。

**哥斯达黎加系**
- **Grupo Acon / Upala Agricola / Verba Odrec**：哥斯达黎加菠萝出口商，供应欧美和部分亚洲市场。

**国内品牌/供应链**
- **佳沃（Joyvio）**：有热带水果品类，但菠萝不是其最核心单品。
- **鑫荣懋**：进口水果供应链强，常操作都乐、菲律宾菠萝等。
- **百果园**：自有渠道会做菠萝品类，但品牌供应更多是采购整合。
- **盒马/山姆/永辉自有品牌**：很多是贴牌或直采，背后供应商可能是菲律宾、哥斯达黎加或国内基地。

**国内产地供应**
- **广东徐闻菠萝**：国内最大产区之一，但季节性强，主要是春季。
- **海南菠萝**：冬春上市，台农、金钻等品种。
- **云南、广西**：有一定面积，但稳定性和规模不如徐闻、海南。

**如果你是要做渠道采购，建议这样判断：**
1. **要全年稳定**：优先看都乐、Del Monte、Sumifru、鑫荣懋这类供应链商。
2. **要性价比**：菲律宾菠萝通常比都乐便宜，但品控波动大一些。
3. **要国内新鲜短链**：徐闻、海南基地直采，但集中在特定季节。
4. **要加工/罐头**：看 Del Monte、Philpack、Dole 等。
5. **要小批量试销**：先找鑫荣懋、百果园供应链或本地批发市场一级商，确认到货稳定性再签长期。

简单说：**鲜果稳定供应，国际上看都乐、Del Monte、Sumifru；国内渠道看鑫荣懋、佳沃、百果园；产地看徐闻和海南。** 如果你能告诉我你做的是商超、电商还是批发，以及目标价位，我可以帮你缩到更具体的采购方向。
