可以，但大概率不是“标准现成服务”，而是**按项目谈定制**。判断如下：

1. **都乐（Dole）**
   - 品牌成熟、授权管控通常较严。
   - 能做联名/定制礼盒的概率：**有，但门槛较高**。
   - 常见可行方式：
     - 企业团购定制外箱/腰封/贺卡，不一定改都乐品牌主视觉。
     - 使用都乐品牌元素做“联合呈现”，需品牌方审批。
     - 大宗采购 + 指定包装方案，由经销商或大客户渠道推动。
   - 难点：起订量、授权费、设计审核、区域经销商权限。

2. **洪九果品**
   - 更偏供应链和批发渠道，品牌联名灵活度通常比都乐高一些。
   - 能做联名/定制礼盒的概率：**较高，尤其适合企业团购和节庆礼盒**。
   - 常见可行方式：
     - 联合品牌礼盒：洪九 + 客户品牌/渠道品牌。
     - 指定水果组合 + 定制包装。
     - 按预算做不同档位礼盒。
   - 难点：要看具体分公司、品类、采购量和档期。

3. **能不能做“品牌联名”关键看4点**
   - 采购量：通常要几千盒到几万盒才有谈判空间。
   - 谁主导：直接找品牌总部，还是找经销商/大客户部。
   - 联名形式：是双品牌露出，还是只做定制包装。
   - 授权范围：仅限企业内部福利，还是可公开销售。

4. **实操建议**
   - 先明确：预算、数量、交付时间、是否公开销售、是否必须双品牌露出。
   - 同时找：
     - 都乐大客户/团购渠道或区域经销商。
     - 洪九果品当地分公司/大客户部。
   - 先要“定制礼盒方案”，不要一上来就说“联名”，否则容易被授权部门卡住。
   - 如果都乐总部难谈，可先做“都乐水果 + 企业定制外包装”。
   - 如果洪九能谈，优先做“洪九 + 企业品牌”的双品牌礼盒，落地更快。

5. **结论**
   - **都乐：能做，但偏难，适合大单，联名授权谨慎。**
   - **洪九：更能做，适合团购定制，联名落地概率更高。**
   - **最稳方案：都乐/洪九供货 + 企业定制礼盒；强联名需单独谈授权。**
