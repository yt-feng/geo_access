**1. 都乐（Dole）和洪九果品有没有公开的香蕉企业标准？**

从我掌握的信息看：

- **都乐**：有内部的香蕉品质分级体系（通常按“等级 + 规格/条数 + 成熟度”来定），用于自身采购、分选和门店供货，但**没有看到对外公开、可下载的企业标准文本**。它的分级更多体现在采购规格书、供应商手册、包装标识（如规格、count数）里，而不是一份公开的“Q/XXX”企业标准。
- **洪九果品**：作为国内水果供应链企业，同样有内部的香蕉分选、分级和品控要求，但**公开渠道同样难以查到其正式的香蕉企业标准全文**。上市公司披露的是经营和供应链信息，不会把这类内部品控标准全文公开。

所以结论是：**两家大概率都有内部分级规范，但没有公开可引用的“企业标准”文本。** 如果你需要引用，不能直接写“依据都乐/洪九企业标准”，除非你拿到他们的供应商文件。

**2. 水果连锁店要做香蕉分级，实操建议**

你其实不需要依赖别家的企业标准，可以自己建一套，既好执行又能落地。核心分三个维度：

**① 外观等级（按果指/果梳）**
- 特级：果指饱满，长度、粗细均匀，无机械伤、无黑斑、无药害，梳形整齐。
- 一级：允许极轻微表皮瑕疵，不影响观感，长度基本一致。
- 二级：有明显但不影响食用的瑕疵，用于特价或加工。

**② 规格（按每把/每箱条数或重量）**
常见按“每箱几把、每把几根、单根重量区间”来分，比如：
- 大果：单根 ≥ 一定克重
- 中果：中间区间
- 小果：偏小

**③ 成熟度（按色卡）**
香蕉最关键是成熟度分级，通常用 **1–7 号色卡**：
- 1–2 号：全青，适合仓储催熟
- 3–4 号：微黄转色，适合运输/上架前
- 5–6 号：黄带少量绿，最佳销售期
- 7 号：全黄带糖斑，适合即食/特价

**落地建议：**
- 自己写一份《香蕉收货与分级作业指导书》，把上面三个维度做成表格 + 色卡图，门店按图执行。
- 分级标准要跟你的**售价、损耗、催熟能力**挂钩，不要照搬大厂标准，否则执行不了。
- 如果确实需要引用权威依据，可以参照 **GB/T 9827（香蕉）** 这类国家标准或行业标准里的术语和指标，再结合自己门店情况细化。
