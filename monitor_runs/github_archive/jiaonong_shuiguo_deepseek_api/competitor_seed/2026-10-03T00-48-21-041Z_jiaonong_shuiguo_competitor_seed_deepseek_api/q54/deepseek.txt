如果超市要采购都乐（Dole）和鑫荣懋（Joywing Mau）的进口苹果，产地溯源通常不能只靠“品牌口头说明”，而要把**供应商资质、批次单据、包装标识、检测/检疫证明、到货验收记录**串成一条可追查链路。下面按可执行方式说明。

## 一、先明确：都乐和鑫荣懋的角色可能不同

### 1. 都乐（Dole）
都乐通常是国际品牌/供应链品牌方。你采购的可能是：
- 都乐自有或授权进口商供货；
- 国内经销商/代理商供货；
- 都乐品牌授权包装，但实际进口商是另一家公司。

所以溯源时要区分：
- **品牌方**：Dole；
- **实际进口商/收货人**：看海关进口货物报关单；
- **境外果园/包装厂**：看原产地证、植检证、包装箱代码；
- **国内供货商**：和你签合同的公司。

### 2. 鑫荣懋（Joywing Mau）
鑫荣懋通常是国内大型水果供应链企业，可能既是进口商，也是分销商。它可能：
- 自己进口；
- 从其他进口商采购后分销；
- 代理多个国外品牌。

因此同样要看**具体批次的进口报关单和原产地证明**，不能只看“鑫荣懋供货”就认为产地一定完整可溯。

## 二、超市采购时要索取的核心溯源文件

按批次索取，最好每批到货都对应一套：

1. **合同/订单**
   - 品名：进口苹果，品种如嘎啦、红蛇果、富士、爱妃等；
   - 原产国；
   - 规格、等级、包装；
   - 批次号/生产日期/采摘季；
   - 供货商名称。

2. **海关进口货物报关单**
   - 看“境内收货人”“境外发货人”“原产国”“商品名称”“数量”“报关单号”。
   - 这是判断是否真实进口的关键文件之一。

3. **入境货物检验检疫证明**
   - 海关出具，证明该批货物已检验检疫。
   - 注意核对品名、原产国、数量、批号、日期是否与到货一致。

4. **原产地证书**
   - 由出口国官方或授权机构出具。
   - 看原产国、出口商、收货人、品名、数量。
   - 有些国家/品类可享受自贸协定税率，原产地证也用于关税优惠。

5. **植物检疫证书**
   - 出口国官方出具。
   - 证明符合中国植物检疫要求。
   - 核对果园/包装厂注册号（如有）。

6. **装箱单、发票、提单/运单**
   - 用于核对批次、数量、集装箱号、船名航次、到港日期。
   - 超市可据此把“门店到货批次”追到“进口批次”。

7. **供货商资质**
   - 营业执照；
   - 食品经营许可证/仅销售预包装食品备案（按当地要求）；
   - 进口商备案信息；
   - 品牌授权书或经销授权链。

8. **检测报告**
   - 农残、重金属等，按超市风险和合同要求。
   - 注意检测报告对应批次，不能拿旧报告通用。

9. **包装标识照片**
   - 原箱标签、中文标签、批次码、果园/包装厂代码、原产国。
   - 都乐和鑫荣懋的箱子通常有品牌、规格、产地、批次信息。

## 三、都乐苹果溯源具体怎么做

### 可执行步骤
1. 要求供货商提供**本批次报关单**，核对：
   - 境内收货人是谁；
   - 原产国是否与标签一致；
   - 报关单号、到港日期、数量是否匹配。

2. 核对**都乐品牌授权链**：
   - 如果供货商不是都乐中国或授权进口商，要求提供授权书；
   - 确认是“都乐品牌”还是“都乐品种/都乐包装”。

3. 核对**原箱标签**：
   - 原产国；
   - 果园/包装厂注册号；
   - 批次号/Lot No.；
   - 包装日期；
   - 品种、规格。

4. 建立批次映射：
   - 超市采购单号 → 供货商送货单 → 报关单号 → 原产地证号 → 门店收货批次。
   - 这样出现客诉或监管检查时能快速定位。

5. 如果都乐供货商只能提供经销商发票，不能提供报关单：
   - 要求其上游进口商提供；
   - 否则该批次溯源不完整，建议降级采购或拒收。

## 四、鑫荣懋苹果溯源具体怎么做

### 可执行步骤
1. 确认鑫荣懋是**进口商**还是**分销商**：
   - 若报关单境内收货人是鑫荣懋，溯源链较短；
   - 若不是，要求其提供上游进口商报关单和授权/购销链。

2. 索取**批次对应报关单和检疫证明**：
   - 核对原产国、品种、数量、集装箱号、到港日期。

3. 核对**鑫荣懋出库单/送货单**：
   - 看批次号、门店收货日期、数量。
   - 最好有鑫荣懋系统内的批次追溯码。

4. 核对**原箱标签和中文标签**：
   - 原产国；
   - 进口商/经销商；
   - 生产日期/包装日期；
   - 保质期或最佳食用期；
   - 批次码。

5. 如果鑫荣懋从其他进口商拿货：
   - 要求提供完整链条：国外出口商 → 国内进口商 → 鑫荣懋 → 超市。
   - 每一环的发票、合同、批次号要能对应。

## 五、超市内部要做的溯源管理

1. **一店一码/一批一码**
   - 收货时录入：供货商、报关单号、原产地证号、检疫证号、批次号、到货日期。

2. **保留文件期限**
   - 一般不少于保质期满后6个月；没有明确保质期的，不少于2年（按食品安全法及当地监管要求执行）。

3. **标签合规**
   - 进口预包装苹果若直接销售给消费者，中文标签要符合要求；
   - 散装或简易包装按当地市场监管要求执行。

4. **到货验收**
   - 查原箱标签是否完整；
   - 查批次是否与单据一致；
   - 查是否有霉烂、虫害、异常气味；
   - 拍照留存。

5. **供应商审核**
   - 都乐、鑫荣懋这类供应商也要年审；
   - 重点看进口能力、授权链、批次单据提供能力、召回配合能力。

## 六、判断溯源是否合格的简单标准

一个批次如果能做到以下闭环，基本算可追溯：

**境外果园/包装厂 → 出口商 → 进口报关单 → 入境检验检疫证明 → 国内进口商/经销商 → 超市配送单 → 门店收货批次**

如果只能提供：
- 品牌授权书；
- 发票；
- 检测报告；
- 但没有报关单/检疫证明/原产地证；

那只能算“品牌可说明”，不算“批次可溯源”。

## 七、实操建议

1. **合同里写明**
   - 供货商必须随货或到货后24小时内提供本批次报关单、检疫证明、原产地证、批次号。
   - 不能提供则超市有权拒收或扣款。

2. **优先选择能提供电子批次追溯的供应商**
   - 都乐、鑫荣懋这类大供应商通常有系统，可要求对接批次码。

3. **不要混批**
   - 不同报关单、不同到港日期的苹果不要混成一个门店批次，否则客诉时无法定位。

4. **重点核对三个号**
   - 报关单号；
   - 原产地证号；
   - 原箱批次号/Lot No.。
   这三个能对应，溯源基本成立。

5. **监管检查时能拿出的材料**
   - 供货商资质；
   - 报关单；
   - 入境货物检验检疫证明；
   - 进货台账；
   - 销售记录/门店收货记录。
