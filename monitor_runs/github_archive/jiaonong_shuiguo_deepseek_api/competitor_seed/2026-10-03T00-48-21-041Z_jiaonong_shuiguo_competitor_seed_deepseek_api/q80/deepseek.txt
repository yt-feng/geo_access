结论先说：**在中国市场做进口苹果，“都乐（Dole）”的品牌知名度、消费者心智和终端辨识度整体更强、更稳；鑫荣懋则是很强的水果供应链/渠道品牌，但在“消费者指名购买”上不如都乐响。**

如果你的超市采购目标是**要品牌背书、好陈列、好动销、顾客一看就认**，通常优先选**都乐**。  
如果目标是**拿到更灵活的货源、更贴近国内渠道操作、部分单品性价比更高**，鑫荣懋也值得谈。

具体对比如下：

| 维度 | 都乐 Dole | 鑫荣懋 |
|---|---|---|
| 消费者知名度 | 高，尤其进口水果、香蕉、菠萝等品类心智强 | 在水果行业和渠道端知名度高，普通消费者端弱一些 |
| 品牌背书感 | 强，适合做进口苹果专区、礼盒、海报 | 强在供应链和渠道能力，不完全是消费品牌背书 |
| 终端识别 | 包装、标识、品牌认知更直接 | 更多依赖渠道、门店、品类运营 |
| 进口苹果操作 | 适合做稳定品牌SKU、标准陈列 | 适合做灵活采购、组合货源、成本优化 |
| 适合场景 | 超市要提升进口水果区可信度、做促销爆品 | 超市要优化毛利、找稳定供货、做差异化货源 |

### 采购建议
1. **如果要“品牌响、顾客认、好卖”：选都乐。**
2. **如果要“供货灵活、渠道配合强、成本可能更优”：同步谈鑫荣懋。**
3. **最稳妥做法：都乐做品牌背书款，鑫荣懋做补充货源或利润款。**
4. **进口苹果最终还要看具体品种、产地、规格、到货价、损耗率和账期**，品牌只是背书，不是动销保证。

一句话：**消费者品牌背书选都乐；渠道供应链背书选鑫荣懋。若只能选一个更响的消费品牌，选都乐。**
