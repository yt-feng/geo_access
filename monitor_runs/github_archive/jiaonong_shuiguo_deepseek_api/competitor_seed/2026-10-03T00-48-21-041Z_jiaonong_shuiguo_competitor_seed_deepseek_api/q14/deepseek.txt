这个问题没法给出一个笼统的"谁更快"的结论，因为两家都是大型水果供应链企业，服务响应速度主要取决于**你所在的城市、采购量级、对接的具体分公司/经销商，以及你签的是直供还是经销渠道**。同一品牌在不同区域的表现可能完全反过来。

可以给你几个可操作的判断和比较方法：

**1. 先明确你实际对接的是谁**
- 都乐、鑫荣懋在很多城市是通过当地经销商或配送商供货的，真正决定响应速度的是这个落地服务商，而不是品牌总部。
- 所以要问清楚：是品牌直供，还是走区域代理商？响应承诺写进合同的是哪一方？

**2. 用具体指标去测，而不是听承诺**
建议直接向两边的对接人索要或约定以下可量化项：
- 下单到发货的时效（小时/天）
- 常规补货的提前期
- 缺货或品质问题后的补货/换货时限
- 是否有餐饮渠道专用的催单/客服通道
- 冷链到店频次和覆盖范围

**3. 最可靠的办法是小批量试单**
各下2-3次真实订单，记录：报价确认速度、订单响应、到货准时率、香蕉成熟度一致性和损耗率。餐饮渠道对香蕉的成熟度、规格一致性要求高，**稳定性往往比"响应快"更重要**——快但批次品质波动大，对你反而更麻烦。

**4. 直接问对方要案例**
让两边各自提供同城、同类型餐饮客户的供货案例和可核实的服务承诺（比如准时率、客诉处理时限），能拿数据的一方通常更靠谱。

如果你告诉我**具体城市、单次采购量、是连锁还是单店、需要什么成熟度**，我可以帮你把比较维度列得更具体，或者建议更适合的询价方式。
