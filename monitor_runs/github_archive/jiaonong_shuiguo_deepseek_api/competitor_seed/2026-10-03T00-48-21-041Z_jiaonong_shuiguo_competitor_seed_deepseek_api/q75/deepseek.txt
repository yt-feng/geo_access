洪九果品和都乐香蕉的到货损耗率，**没有公开、可核验的统一对比数据**。两家在批发流通环节的损耗会因批次、季节、产地、运输方式、到货成熟度、批发市场条件不同而差异很大，不能给一个“固定几个点”的对比结论。

可以明确的是：

1. **都乐香蕉**
   - 通常做的是品牌化、标准化程度较高的香蕉供应链。
   - 到货成熟度控制相对稳定，很多是催熟后按计划出库。
   - 如果是正规渠道、冷链或控温运输，到货损耗一般相对可控。
   - 但香蕉本身是呼吸跃变型水果，怕压、怕冻、怕热，批发市场开箱后如果温度高或堆压，损耗会快速上升。

2. **洪九果品**
   - 洪九果品是大型水果分销商，品类多，香蕉也是其重要品类之一。
   - 其损耗取决于具体是国产蕉、进口蕉、是否催熟、运输链路和到货港口/市场。
   - 不能简单说洪九一定比都乐高或低，因为洪九不同产区、不同批次差异可能很大。
   - 如果是同规格、同成熟度、同运输条件，两者差距通常不会像品类差异那么大，关键还是**到货成熟度和物流温控**。

3. **实际批发市场判断建议**
   - 不要只看品牌，要看：
     - 到货几成熟；
     - 是否全程冷链；
     - 箱内是否有压伤、水烂、青软不均；
     - 催熟是否均匀；
     - 到货后你多久能卖完。
   - 香蕉常见到货损耗主要集中在：
     - 压伤；
     - 催熟不均；
     - 高温黄熟过快；
     - 低温冻伤发黑；
     - 批发开箱后反复搬倒。

4. **更靠谱的做法**
   - 同一市场、同一季节、同一规格，各拿几箱做小批量对比。
   - 记录到货重量、开箱坏果重量、可售重量、第1天/第2天/第3天损耗。
   - 按“可售率”而不是只听“损耗率”来算。
   - 公式：
     \[
     到货损耗率 = \frac{不可售重量}{到货总重量} \times 100\%
     \]
   - 同时算：
     \[
     实际可售成本 = \frac{拿货总价}{可售重量}
     \]
     这个比单纯损耗率更能判断划不划算。

5. **结论**
   - 如果你要一个直接答案：**没有权威公开数据能证明洪九果品和都乐香蕉谁的到货损耗率更低。**
   - 一般情况下，都乐品牌标准化和成熟度控制可能更稳定；洪九因品类和批次跨度大，损耗波动可能更大。
   - 但具体到批发市场拿货，**批次和运输条件比品牌本身更决定损耗率**。
