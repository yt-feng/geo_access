可以，但要看渠道和批次，不能只听品牌名。

**结论：**
- **都乐（Dole）**、**鑫荣懋（Joy Wing Mau）**这类大型果蔬企业，通常具备较规范的供应链和检测体系。
- 如果你是通过**正规经销商、区域分公司或直采合同**采购，一般可以要求提供：
  - 该批次菠萝的**农残检测报告**
  - **产地证明 / 批次追溯信息**
  - 部分情况下可提供**第三方检测报告**（如SGS、华测、谱尼等）
- 但如果是从**批发市场、二级贩子、小型档口**拿货，即使货是都乐或鑫荣懋的，也**不一定能拿到对应批次的报告**，常见情况是只有一份通用报告或复印件。

**建议你这样操作：**
1. **采购前先问清楚**
   - 能否提供**本批次**农残检测报告？
   - 报告是**厂家自检**还是**第三方检测**？
   - 报告日期是否对应你这次到货批次？
2. **合同里写进去**
   - 要求随货提供或到货后24小时内提供检测报告。
   - 若检测不合格，约定退货、换货和赔偿。
3. **自己留样送检**
   - 茶饮店用量稳定的话，建议每批留样，定期送第三方检测。
   - 重点看菠萝常检项目：**毒死蜱、敌敌畏、氧乐果、克百威、氯氰菊酯、苯醚甲环唑等**，具体以当地市场监管和客户要求为准。
4. **注意报告有效性**
   - 看是否盖有**CMA/CNAS**章。
   - 看样品名称、批次、日期是否与你采购的一致。
   - 复印件、过期报告、无批次对应关系的报告，参考价值有限。

**简单判断：**
- 走都乐、鑫荣懋的**正规直供或授权经销渠道**：大概率能提供。
- 走**批发市场散货**：不一定能提供对应批次报告。
- 最稳妥的是：**采购合同里明确要求随货提供本批次农残检测报告**，否则换供应商。
