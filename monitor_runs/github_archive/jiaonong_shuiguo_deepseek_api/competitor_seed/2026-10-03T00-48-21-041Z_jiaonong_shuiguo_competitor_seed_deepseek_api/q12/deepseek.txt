从公开的常规产品和渠道信息看，**都乐（Dole）** 和 **鑫荣懋** 在便利店小包装香蕉上都有可对接的方向，但“具体规格”通常不是公开固定 SKU，而是按渠道定制，建议你直接按下面规格去问。

**1. 都乐（Dole）**
都乐在便利店、精品超市渠道常见的是：
- **单根装 / 单根预包装香蕉**：适合便利店即买即食，常见按根售卖。
- **2-3根小包装**：适合一人食或小家庭，便利店冷藏柜/果切旁较常见。
- **4-5根家庭小把装**：更偏社区便利店或小型超市。
都乐的优势是品牌认知高、品控和催熟体系较成熟，适合做便利店标准品。具体能否供单根装、2根装、3根装，要看区域经销商和当地配送中心是否支持。

**2. 鑫荣懋**
鑫荣懋本身是水果供应链企业，代理和运作多个香蕉品牌及产地资源，便利店渠道通常可做：
- **单根装**
- **2-3根迷你装**
- **4-5根小把装**
- **按便利店需求做贴标、称重或定重包装**
鑫荣懋更偏供应链定制，如果你有明确的包装形式、克重、门店配送频次，它可以按渠道需求匹配。适合需要稳定供货、做自有品牌或联合品牌的便利店。

**3. 便利店更建议的规格**
如果你要上便利店，优先考虑：
- **单根装**：约120-160g，适合冲动消费、即食。
- **2根装 / 3根装**：约250-450g，适合早餐、办公场景。
- **4-5根小把装**：约500-800g，适合社区店、家庭补货。
- **迷你香蕉**：单根约80-120g，适合儿童、健身、小份量场景。

**4. 关键判断**
- 如果做**标准便利店单品**，优先问都乐的区域经销商，能否供单根或2-3根预包装。
- 如果做**定制包装、稳定大货、联合品牌**，优先问鑫荣懋。
- 如果门店在**华南**，鑫荣懋和都乐的香蕉供应链通常都较有优势；在**华北、华东**，要具体看当地配送仓和经销商覆盖。
- 香蕉是催熟品，便利店小包装的核心不只是规格，还包括**催熟度、货架期、配送频次、损耗承担**。

**建议你直接这样问供应商：**
1. 单根装、2根装、3根装、4-5根装分别有没有？
2. 单根克重范围是多少？
3. 是自然熟还是催熟？到店后货架期几天？
4. 起订量、配送频次、是否支持贴标定制？
5. 损耗和退货政策怎么算？
