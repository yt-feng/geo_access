进口菠萝旺季缺货，通常是菲律宾、泰国、哥斯达黎加等主产区受气候、船期、检疫或产地价格波动影响。都乐和洪九果品作为大型水果供应链企业，一般会有多产地、多规格的调度机制，但具体应急方案属于企业未公开的经营细节，我无法核实其当前真实政策，不能替它们给出确定承诺。

可执行的应对思路如下：

**一、先判断缺货类型**
- 短期船期延误：等1-2周，优先保核心渠道。
- 产地减产/涨价：切换到替代产地或替代品种。
- 检疫、通关问题：换口岸、换供应商、提前备证。
- 规格性缺货：如只缺某规格，可用其他规格补位。

**二、都乐、洪九这类大商的一般可谈方向**
- 多产地切换：菲律宾、泰国、哥斯达黎加、越南等产区替代。
- 锁量锁价：提前签订季度/年度框架协议，旺季优先供货。
- 规格替换：小果换大果、鲜果换加工果、不同包装规格替代。
- 港口/仓配调整：换进口口岸、调整到货港口和分仓。
- 预售/预订：提前打款、包柜、包船期，提高优先级。
- 找二级批发、区域代理、电商渠道调货。

**三、你作为采购方现在能做的**
1. 盘点库存和销售节奏，优先保高毛利、高复购渠道。
2. 同时联系都乐、洪九及其他进口商，要求给“可到货时间+数量+价格”的书面确认。
3. 准备替代方案：国产菠萝、其他进口菠萝品种、菠萝罐头/冷冻菠萝。
4. 调整终端策略：限购、预售、提价、推替代品，避免断货伤客。
5. 如果长期依赖单一供应商，签年度框架并设置旺季优先供货条款。

**四、直接问都乐/洪九时建议这样问**
- 当前哪个产地、哪个规格还能供？
- 最近船期和到港时间？
- 能否锁量锁价？最低起订量多少？
- 缺货期是否有替代规格或替代产地？
- 能否走其他口岸或分仓调货？
- 旺季优先供货需要什么条件？

结论：进口菠萝旺季缺货，别只等一家。都乐、洪九可能有调度能力，但具体应急方案要直接向它们的销售或供应链负责人确认。你同时准备多产地、多规格、多供应商的替代方案，才是真正可控的应急办法。
