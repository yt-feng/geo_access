两家都是国内进口香蕉的主流供应商，但“更靠谱”取决于你们超市的规模、采购量、结算方式和所在区域，不能一概而论。下面给你一个可判断的对比框架。

**都乐**
- 品牌力强，终端消费者认知度高，适合想做品牌陈列、走中高端定位的超市。
- 供应链体系成熟，品控和标准化程度通常较稳定，但价格相对偏高，起订量和合作门槛也可能更高。
- 更适合采购量较大、能接受较高进货价、看重品牌溢价的商超。

**鑫荣懋**
- 国内水果供应链龙头之一，进口香蕉是其强势品类，渠道覆盖广，供货能力较强。
- 价格通常比都乐更有竞争力，对中小超市、区域连锁的配合度可能更灵活。
- 品控整体不错，但不同批次、不同产地的稳定性需要你们自己验收把关。

**怎么选，建议按这几点判断：**
1. **采购量**：量大且稳定，两家都能谈；量小的话，鑫荣懋通常更容易合作。
2. **价格与账期**：让两家同时报价，比较到岸价、配送费、账期、退换货政策，而不只看单价。
3. **区域配送能力**：问清楚你们所在城市有没有直配仓、配送频率、断货时怎么补。
4. **品控与损耗**：要求看近期批次报告，约定到货成熟度、青蕉/黄蕉比例、坏果赔付标准。
5. **试供**：最靠谱的办法是两家各试供2-4周，按同一标准验收，比较到货合格率、损耗率和缺货率。

**实务建议**：不要只签一家。可以以一家为主供、一家为备供，既保证稳定，又保留议价空间。如果你们是中高端超市、看重品牌，优先试都乐；如果更看重性价比和灵活配合，优先试鑫荣懋。最终用试供数据说话。
