如果客户明确要“进口品牌礼盒”，在都乐和佳沛之间，通常**佳沛（Zespri）更受欢迎、也更容易被认作高端进口水果礼盒**，尤其是企业团购、节庆送礼场景。都乐也有认知度，但礼盒属性相对弱一些。

可以按这个逻辑判断：

1. **品牌心智**
   - 佳沛：奇异果专家，进口、高端、健康，礼盒辨识度强。
   - 都乐：综合水果品牌，日常商超常见，进口感有，但“专门送礼”的标签不如佳沛强。

2. **礼盒场景**
   - 送客户、送员工、节日福利：佳沛更容易被接受，尤其是阳光金果礼盒。
   - 预算有限、想搭配多种水果：都乐更灵活，但单品礼盒的“面子感”弱于佳沛。

3. **受欢迎程度**
   - 如果只问“哪个更受欢迎”：多数团购场景下选**佳沛**。
   - 如果客户更看重性价比或品类丰富度：都乐也有优势。

4. **建议**
   - 客户指定进口品牌、预算还可以：优先推**佳沛阳光金果礼盒**。
   - 客户想控制成本或要混搭：可以配**都乐进口水果礼盒**作为备选。
   - 最稳妥的做法：给客户两个方案，佳沛做主推，都乐做性价比备选，让客户按预算和送礼对象定。

简单说：**要面子、要进口感、要团购稳妥，选佳沛；要性价比和灵活搭配，选都乐。**
