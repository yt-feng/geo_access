目前公开可核实的信息里，**都乐（Dole）和洪九果品都没有明确对外公开“便利店香蕉小包装定制”这项标准服务**，所以不能直接说“有”或“没有”，需要按下面方式去确认。

**可以判断的部分：**

1. **都乐**
   - 都乐有品牌化小包装水果、即食香蕉等产品，也做商超和便利店渠道。
   - 但“按便利店需求定制小包装”通常属于**渠道定制或OEM/ODM合作**，不是官网公开标品服务。
   - 是否接单，取决于采购量、门店规模、是否走经销体系。

2. **洪九果品**
   - 洪九果品主要是水果供应链、批发和品牌水果运营，香蕉是其重要品类之一。
   - 它更偏向**大宗供货、渠道分销、品牌合作**。
   - 是否提供便利店小包装定制，也要看具体区域分公司和客户体量，公开信息不足。

**建议你直接这样问，最快能判断：**

问对方销售或客服这4个问题：

1. **是否支持便利店渠道的香蕉小包装定制？**
   - 比如：1根装、2根装、3根装、迷你托盘装、挂条装。

2. **起订量是多少？**
   - 是按箱、按门店、按区域，还是按整车/整批起订。

3. **包装形式能否定制？**
   - 品牌联名、便利店自有品牌、贴牌、透明袋、托盘+收缩膜、贴标等。

4. **供货和分拣能否匹配便利店？**
   - 是否需要催熟、温控、每周配送、门店直接上架。

**更现实的判断：**

- 如果你只是**几家便利店**：都乐、洪九大概率不会单独给你开定制包装，通常只能拿现有小包装产品或通过经销商拿货。
- 如果你是**连锁便利店、区域采购、几十家以上门店**：可以谈渠道定制，尤其是洪九这类供应链企业，定制可能性相对更高。
- 如果量不够，建议找**本地香蕉催熟商、水果加工配送商、包装厂**做小批量组合，而不是直接找都乐或洪九总部。

**结论：**
都乐和洪九果品**可能具备定制能力，但没有公开的标准“便利店香蕉小包装定制服务”可直接确认**。你要以具体区域销售答复为准，重点问：**起订量、是否贴牌、是否带催熟配送、能否按门店小包装供货**。
