都乐和鑫荣懋并没有对外公开、可直接引用的“茶饮原料采购到货损耗率”官方数据，具体损耗会随品类形态（整果/去皮/冷冻果块/果泥）、季节、产地、运输距离、冷链条件、验收标准而变化，不同客户和不同批次差异很大。因此我不能给你一个确定的百分比，否则就是编数据。

可以给你可执行的判断和操作建议：

1. **先明确你要的“菠萝”形态**
   - 整果：损耗主要在压伤、黑心、成熟度不均、冠芽/皮重量。
   - 去皮菠萝/菠萝块：损耗主要在失水、发酵、断链、汁液流失。
   - 冷冻菠萝块/果泥：损耗主要在解冻析水、包装破损、温度波动。
   不同形态的到货损耗率没有可比性。

2. **向供应商直接索要“验收损耗口径”**
   让都乐和鑫荣懋分别书面确认：
   - 到货损耗定义：按件数、重量、还是可利用率？
   - 验收标准：黑心、压伤、成熟度、中心温度、糖度、异味、异物。
   - 赔付规则：是否按实际损耗补货/扣款，免赔比例是多少。
   - 批次追溯：产地、采摘/加工日期、冷链记录。

3. **建议你做小批量对比测试**
   同一时间段、同一门店/仓库、同一验收人，分别进都乐和鑫荣懋各3批以上，记录：
   - 到货总重量
   - 可立即使用重量
   - 不可用重量（分原因）
   - 存放24h/48h后可用重量
   - 实际出品杯数/公斤
   用“可利用率”而不是单纯“损耗率”评估，更贴近茶饮成本。

4. **茶饮端常见参考区间（仅作内部测试对照，不是官方数据）**
   - 整果菠萝：到货不可用率通常可能在中低个位数到10%以上，取决于季节和运输。
   - 去皮/鲜切菠萝：若冷链不稳，24–48h内失水、发酵、异味造成的可用率下降可能明显高于整果。
   - 冷冻菠萝块/果泥：包装完好、全程-18℃以下时，到货损耗通常较低；但解冻析水会影响实际使用量。
   这些只能作为你自测时的观察方向，不能当作都乐或鑫荣懋的承诺值。

5. **更稳的采购做法**
   - 要求供应商提供“周/月批次质量报告”和“客诉/赔付记录”。
   - 合同里写清验收标准、免赔额、补货时效、冷链温度记录。
   - 对茶饮门店，优先选规格稳定、开袋即用、损耗可计量的形态，如冷冻果块/果泥/浓缩汁，而不是依赖整果现场处理。
   - 如果必须用鲜果，建议双供应商+安全库存，避免单一品牌断链。
