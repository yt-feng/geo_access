可以，但通常不是“无条件随货附送”，而是按批次向供应商索取。给你可直接执行的判断：

1. **都乐**
   - 一般能提供农残检测报告，尤其是商超/餐饮渠道供货时。
   - 通常是：**批次检测报告**或**第三方检测报告**，不是每箱都有一张。
   - 如果你从经销商/批发市场拿货，报告要向上游经销商要，不一定能直接找都乐总部拿到。

2. **鑫荣懋**
   - 也通常能提供农残检测报告，属于大型水果供应链企业，一般有品控和检测体系。
   - 同样按**批次**提供，采购时可要求随货或到货后补发电子版。
   - 若是二级批发商供货，报告仍要向实际供货方索要。

3. **你采购时要明确问这几项**
   - 是否有**本批次**农残检测报告？
   - 报告是**第三方CMA/CNAS**出具，还是供应商自检？
   - 检测项目是否覆盖你关心的农残指标？
   - 报告上的**批次号/生产日期**能否和到货一致？
   - 能否盖章或提供电子版存档？

4. **现实建议**
   - 直接找都乐、鑫荣懋官方或区域销售，通常比批发市场更容易拿到规范报告。
   - 如果是小店少量采购，可要求经销商提供最近批次报告；若对方长期无法提供，建议换供应商。
   - 茶饮店用于鲜果原料，最好把“每批次提供农残检测报告”写进采购合同或订单备注。

结论：**都乐和鑫荣懋一般都能提供，但你要按批次向实际供货方索要，并核对批次是否一致。**
