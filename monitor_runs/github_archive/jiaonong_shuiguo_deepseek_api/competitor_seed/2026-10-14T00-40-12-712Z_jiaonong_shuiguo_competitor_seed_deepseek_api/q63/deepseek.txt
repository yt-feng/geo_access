都乐和洪九果品在社区团购渠道一般都可以谈“散装/小包装”，但公开零售端不一定直接标注“散装选项”。给你几个可执行判断：

1. **都乐**
   - 都乐香蕉常见是整把/整串销售，也有按重量分装的家庭装。
   - 社区团购常见做法：按 **500g、1kg、1.5kg** 做小包装，或按 **3-5根/份** 分装。
   - 是否支持散装，取决于你对接的是都乐直营、区域经销商还是批发市场货源。直营通常要求起订量和规格统一；经销商更灵活。

2. **洪九果品**
   - 洪九更多是产地/批发供应链模式，香蕉是其强势品类之一。
   - 社区团购渠道通常可以谈 **按件、按箱、按重量分装**，但“散装”一般不是品牌零售包装，而是由团购方或仓配端二次分装。
   - 如果你们要小包装，建议直接问洪九区域销售：能否提供 **净重5kg/箱、10kg/箱** 的原料箱，再由你们分装成 **500g/1kg**。

3. **实操建议**
   - 先明确你要的是：
     - 品牌预包装小份？还是
     - 原料箱到仓后自己分装？
   - 问供应商这4个问题：
     1. 最小起订量是多少？
     2. 能否按500g/1kg/3-5根做规格？
     3. 分装是你们做还是我们做？
     4. 报价含不含分装、损耗、冷链/配送？
   - 社区团购更稳的模式通常是：**整箱进货 + 中心仓分装 + 次日配送到团长**，因为香蕉后熟快，品牌方直接做小散装成本高、损耗也高。

4. **结论**
   - 都乐、洪九大概率都能通过渠道谈小包装/分装供货，但“散装”通常不是标准零售SKU。
   - 如果你要的是直接可售的散装小份，最好找区域经销商或批发商；如果走品牌直供，多半要接受整箱规格，自己二次分装。
