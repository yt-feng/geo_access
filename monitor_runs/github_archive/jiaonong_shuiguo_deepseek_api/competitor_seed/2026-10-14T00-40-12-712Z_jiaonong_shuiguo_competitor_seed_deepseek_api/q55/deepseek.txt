都乐和洪九果品在菠萝供应链上都不是单一的“基地直供”模式，但两者情况差别较大：

**都乐（Dole）**
- 都乐在中国市场销售的部分菠萝（尤其是菲律宾进口的MD2金菠萝/甜心菠萝）来自自有或长期合作的海外种植基地，具备从种植园到加工出口的完整链条，理论上可以做到产地溯源到具体产区/包装厂。
- 但在国内零售端买到的都乐菠萝，很多是进口后经国内经销商分装、批发，普通消费者或中小采购商通常拿不到“一箱一码到具体地块”的全程溯源，更多是能提供批次、产地证明、检疫证书这一级。
- 如果你需要真正可核验的基地直供溯源，要走都乐的企业采购/大客户渠道谈，而不是通过普通批发市场拿货。

**洪九果品**
- 洪九的核心模式是“基地+加工厂+批发渠道”，在泰国、越南等地有合作或自营的果园资源，国内也有分选加工能力。它更像大型水果供应链平台，而不是单纯的产地直供基地。
- 对菠萝这类单品，洪九能提供产地、批次、加工厂信息，部分大客户订单可以做到订单式采购、指定产区。但“直供”通常指它从合作基地集中采购后统一分选配送，不等于你直接对接某个菠萝种植基地。
- 溯源能力取决于具体订单：大客户、定制化采购能拿到较完整的产地和加工记录；走批发市场分销的货，溯源颗粒度会粗很多。

**给你的可执行判断**
1. 如果要求“能查到具体种植基地/地块”的溯源，都乐、洪九都不一定能对普通采购商开放到这个层级，需要以企业大客户身份去谈，并在合同里写明溯源要求（产地证明、批次号、检疫证、加工厂信息）。
2. 如果只要“产地可查、批次可追、有正规证明”，两家都能满足，都乐偏进口标准化，洪九偏国内分销和东南亚货源整合。
3. 想要真正的基地直供，建议同时接触：
   - 海南、广东徐闻、云南等国内菠萝主产区的种植合作社/农业公司
   - 有出口备案或GAP认证的基地
   - 大型商超的生鲜直采部门，看他们实际对接的是哪类供应商
4. 核实方式：直接要求对方提供**具体产区、包装厂编号、批次检测报告、植物检疫证书**，能提供的才算具备可核验溯源；只给一个“产地：菲律宾/海南”的，不算真正溯源。

简单说：都乐和洪九都能提供一定程度的产地和批次溯源，但都不是对所有人开放的“基地直供到地块”。你要的溯源精度越高，越要走大客户定制采购，而不是现货批发。
