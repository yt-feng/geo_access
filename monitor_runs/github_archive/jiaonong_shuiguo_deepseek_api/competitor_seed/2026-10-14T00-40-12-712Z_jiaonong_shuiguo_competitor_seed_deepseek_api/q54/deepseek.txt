# 都乐（Dole）与鑫荣懋（Joyvio/鑫荣懋集团）进口苹果产地溯源实操

## 一、先厘清一个关键点

**都乐**和**鑫荣懋**严格说角色不同：

- **都乐（Dole）**：全球果蔬品牌/供应商，很多苹果是它自己在产地（如新西兰、美国、智利）组织货源再出口，品牌方即供货方。
- **鑫荣懋**：中国本土水果供应链企业，更多是**进口商/渠道商**角色，它从海外果园或出口商采购，再分销给超市。

所以溯源路径不一样：都乐偏"品牌方直供溯源"，鑫荣懋偏"进口商+海外供应商溯源"。下面分开说，最后给超市统一验收动作。

---

## 二、都乐苹果的溯源做法

### 1. 拿到品牌方提供的溯源信息
直接向都乐的对接销售/客服索取：
- **原产国 + 具体产区**（如新西兰 Hawke's Bay、美国华盛顿州）
- **果园/包装厂编号（Packer Code / Grower ID）**
- **批次号（Lot/Batch No.）**
- **采摘/包装日期**
- **出口报关批次**

都乐作为品牌方通常能提供较完整的批次追溯，正规渠道会配合出具**产地证明（Certificate of Origin）**。

### 2. 识别包装上的溯源码
都乐进口苹果常见标识：
- 果箱/果贴上的 **PLU 码**（如 4133 = 新西兰富士，4131 = 美国红蛇果等）
- 箱标上的 **Packer No.**、**Country of Origin**
- 部分高端线有二维码，扫码可查果园/包装信息

### 3. 核验文件链
要求提供并核对：
- 出口国**植物检疫证书（Phytosanitary Certificate）**
- **原产地证**
- **入境货物检验检疫证明**（中国海关出具）
- 报关单（收货人、原产国、批次）

---

## 三、鑫荣懋苹果的溯源做法

鑫荣懋是进口商，溯源要"穿透"到它的海外供应商。

### 1. 索取进口商层面的文件
向鑫荣懋业务对接人要：
- **原产国、海外供应商/果园名称**
- **进口批次号、报关单号**
- **入境货物检验检疫证明**
- **原产地证 + 植物检疫证**

### 2. 要求提供海外供应商信息
关键动作：让鑫荣懋说明**这批货具体来自哪个海外果园/出口商**，最好能拿到：
- 海外包装厂编号（Packer Code）
- 果园注册号（Grower Registration No.，部分国家如新西兰、澳洲有）
- 出口批次号

### 3. 借助海关/口岸信息交叉验证
- 用**报关单**上的原产国、批次、收货人，与实物箱标比对
- 通过海关"进口食品化妆品进出口商备案系统"或口岸检验检疫信息核对

---

## 四、超市通用验收与溯源落地动作（两家都适用）

| 环节 | 具体动作 |
|---|---|
| 采购前 | 要求供应商提供原产国、产区、果园/包装厂编号、批次规则说明 |
| 到货时 | 核对箱标：原产国、PLU码、批号、包装厂编号与文件是否一致 |
| 文件核验 | 植物检疫证、原产地证、入境检验检疫证明、报关单四件套 |
| 批次管理 | 每批货建立台账：批次号↔供应商↔报关单↔上架时间 |
| 追溯演练 | 定期做"从货架果贴→批次→报关单→果园"的反向追溯测试 |
| 数字化 | 要求供应商提供二维码/批号查询接口，接入超市溯源系统 |

---

## 五、给你几个可判断的实操建议

1. **优先要"批次号 + 包装厂编号"**，这是溯源最小可用单元，比只有"原产国"有用得多。
2. **文件四件套缺一不可**：原产地证、植物检疫证、入境检验检疫证明、报关单。缺哪个就质疑哪一批。
3. **都乐看品牌批次，鑫荣懋看进口商+海外供应商**，别把两家的溯源要求混为一谈。
4. **做一次反向追溯演练**：随机拿一颗苹果的果贴/箱标，能否追回报关单和果园，追不到就说明溯源链断了。
5. **警惕"只写原产国"的模糊标注**，那只能证明国别，不能证明具体产区/果园。
