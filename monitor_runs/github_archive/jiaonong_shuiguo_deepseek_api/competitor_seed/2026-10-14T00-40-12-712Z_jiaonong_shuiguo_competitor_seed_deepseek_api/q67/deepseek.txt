都乐和洪九果品通常可以提供菠萝相关的品牌营销素材，但**没有公开的、面向所有生鲜电商的一站式素材库**，需要按合作身份和用途去对接。具体判断如下：

**一、都乐**
- 可以提供：品牌Logo、产品包装图、产地/品种介绍、部分宣传海报、短视频素材、营养或食用场景文案。
- 一般通过**都乐官方销售/市场对接人**或经销商提供，通常要求你是其合作渠道、采购方或有联名/推广合作。
- 如果只是普通电商想直接拿素材商用，通常需要获得书面授权，不能自行下载后直接用于商品详情页或广告。

**二、洪九果品**
- 可以提供：菠萝/凤梨品类的产品图、包装图、基地或供应链相关素材、部分品牌宣传内容。
- 洪九更偏供应链和批发渠道，素材支持通常和**采购合作、渠道推广、活动联名**绑定。
- 同样需要找其对口的销售或市场人员申请，确认是否可用于电商页面、短视频、直播背景等。

**三、实操建议**
1. **先确认你的身份**：是采购方、渠道商，还是仅做内容推广。合作越深，越容易拿到高清图和授权。
2. **直接对接官方渠道**：找都乐、洪九的销售负责人或市场部，说明用途、投放平台、使用期限。
3. **明确素材清单**：产品白底图、场景图、包装图、短视频、品牌VI、卖点文案、检测/产地证明。
4. **拿到授权再商用**：尤其注意Logo、包装、代言人形象、音乐、字体，避免侵权。
5. **如果暂时没有合作**：可以先做自有品牌内容，或使用你已采购商品的自拍素材，不要直接搬运品牌方素材。

**结论**：都乐和洪九通常“能给”，但不是公开随便拿；需要以合作方身份向官方申请，并确认商用授权范围。
