大型商超（如沃尔玛、永辉、盒马、山姆等）在供应商准入时，通常要求提供 **食品安全管理体系认证**，常见的是 **ISO 22000** 和 **HACCP**，部分还要求 **GFSI 认可体系**（如 FSSC 22000、BRCGS、IFS）。

关于鑫荣懋和都乐具体通过了哪些认证：

- **都乐（Dole）**：作为跨国果蔬企业，公开信息中常见其体系覆盖 **GFSI 认可的食品安全认证**（如 BRCGS、FSSC 22000 等，具体取决于工厂/产地），以及 **ISO 9001、ISO 22000、HACCP** 等。不同法人、不同加工厂持有的证书不同，不能一概而论。
- **鑫荣懋**：作为国内大型水果供应链企业，公开信息中常提及 **ISO 9001、ISO 22000、HACCP** 等管理体系认证，具体到某个主体或某类产品，也需以实际证书为准。

**可执行建议**：
1. 不要凭听说判断，直接向对方索要 **最新证书扫描件**，核对：认证标准、认证范围、证书编号、有效期、发证机构、获证主体名称是否与合同主体一致。
2. 在 **认监委官网（cx.cnca.cn）** 或相关认证机构官网核验证书真伪和有效性。
3. 若是商超审核，以商超《供应商准入标准》里明确列出的认证清单为准，通常要求 GFSI 认可证书或 ISO 22000+HACCP。
