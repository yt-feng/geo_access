除了都乐，国内能相对稳定供应菠萝（含金钻凤梨、香水菠萝等）的品牌和渠道主要有：

**1. 佳农**
- 国内进口香蕉/菠萝类做得比较大的供应商之一，菲律宾菠萝、哥斯达黎加菠萝都有稳定货源
- 商超、生鲜电商铺货广，B端餐饮供应链也常用
- 优点是全年供应稳定，缺点是风味偏标准化，不是特别“惊艳”

**2. 鑫荣懋**
- 国内头部水果供应链企业，代理和自有品牌都有
- 菠萝/凤梨品类覆盖国产（海南、广东、云南）和进口
- 适合商超、电商、团购等渠道稳定拿货

**3. 洪九果品**
- 以进口水果为主，泰国、菲律宾菠萝有稳定渠道
- 主要面向B端批发、商超、电商
- 供应链能力强，但终端品牌辨识度不如都乐

**4. 鲜丰水果 / 百果园（自有品牌）**
- 百果园有“熊猫大鲜”等自有品牌，凤梨/菠萝是常备单品
- 鲜丰也有自有或合作品牌
- 适合零售端，货源随季节切换国产/进口

**5. 国产产区品牌（按季节）**
- **海南**：金钻凤梨、香水菠萝，3–6月为主
- **广东徐闻**：菠萝主产区，春季大量上市
- **云南**：部分反季节或早熟品种
- **台湾**：金钻凤梨（通过贸易商进入，政策/渠道有波动）

**6. 电商/商超自有品牌**
- 盒马、永辉、大润发、山姆等都有自有或定制菠萝/凤梨
- 背后供应商通常是佳农、鑫荣懋、洪九这类
- 稳定性取决于具体门店和季节

**判断建议：**
- 要**全年稳定**：优先找佳农、鑫荣懋、洪九这类供应链企业
- 要**国产当季性价比**：海南/徐闻产区直采
- 要**零售品牌化**：百果园、鲜丰、盒马自有品牌
- 要**B端餐饮/批发**：直接对接佳农、鑫荣懋、洪九的区域经销商
