关于都乐和洪九果品的具体账期，我无法给出可核验的准确数字，因为这属于双方商务谈判条款，不同客户、不同采购量、不同区域、不同品类（国产蕉/进口蕉）都会有差异，且很少公开披露。直接报一个"账期XX天"给你反而可能误导决策。

可以确定和可操作的信息如下：

**都乐（Dole）**
- 大型跨国果蔬企业，在国内有正规经销/直供体系。
- 对大型商超、连锁、电商等大客户通常有账期安排，但对中小客户多为现款或预付。
- 具体账期需通过其中国区销售或区域经销商谈，没有对外统一的公开标准。

**洪九果品**
- 国内头部水果分销商，香蕉是其核心品类之一，主要做批发和渠道分销。
- 作为分销商，它本身对下游可能给账期，但它作为你的供应商时，给你的账期取决于你的采购规模和信用。
- 同样没有公开的统一账期标准。

**建议你这样去核实和谈判：**
1. 直接联系都乐中国区销售、洪九果品当地分公司，问"针对我们这种采购量，账期能给到多少"。
2. 同时问清楚：账期起算点（发货日/到货日/对账日）、结算方式（月结30/60/90天）、是否需要保证金或担保。
3. 找3-5家供应商横向比价，账期通常是谈判筹码——采购量大、合作稳定、能接受溢价的，账期更容易谈长。
4. 如果对方是经销商而非厂家直供，账期政策往往更灵活，可以先从区域经销商切入。

如果你告诉我你的采购规模、所在区域、是商超/电商/批发哪种渠道，我可以帮你把谈判要点列得更具体。
