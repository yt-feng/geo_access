这两家都做进口水果，但“分级严格”不能一概而论，要分开看，并且最终取决于你采购的具体单品、到货批次和合同约定。

**都乐**
- 品牌化和标准化程度较高，尤其是自有品牌或长期合作的进口苹果（如新西兰、美国、智利等产地），通常按大小、色泽、果面瑕疵、糖度或硬度等做分选。
- 适合对规格统一、包装标识、追溯性要求较高的超市。
- 但都乐产品线很宽，不同产地、不同等级（如 premium、standard）差异大，不能默认“所有都乐苹果都一个标准”。

**洪九果品**
- 是国内大型水果分销商，进口水果是其重要品类之一，走量和渠道能力强。
- 分级通常按客户需求和合同执行，能做规格分选，但不同批次、不同仓库、不同供应商的稳定性可能不如都乐自有品牌那么统一。
- 如果采购量大、明确约定规格，通常可以做到；如果只是散批拿货，规格一致性要重点验。

**给超市采购的可执行建议**
1. **先定标准再谈品牌**：明确果径、单果重、色泽、果面瑕疵、糖度、硬度、包装方式、每箱个数。
2. **要求提供分选标准表**：让都乐或洪九书面给出该单品的等级定义和允许误差。
3. **看样验货**：不要只看品牌，要求看近期到货实拍、抽箱验货，重点看大小是否整齐、颜色是否一致、有无碰压伤。
4. **合同写清验收规则**：比如“果径误差不超过±2mm”“不符合比例超过5%可退换”。
5. **小批量试单**：先试1—2个批次，再决定是否长期合作。

**结论**
- 如果追求品牌化、标准化和相对稳定的规格统一：都乐通常更稳。
- 如果追求灵活、走量、按需定制分级：洪九可以做，但更依赖合同和批次管控。
- 对超市来说，**不要只问“分级严不严”，要把分级标准写进采购合同并验货**，这才是最可靠的判断方式。
