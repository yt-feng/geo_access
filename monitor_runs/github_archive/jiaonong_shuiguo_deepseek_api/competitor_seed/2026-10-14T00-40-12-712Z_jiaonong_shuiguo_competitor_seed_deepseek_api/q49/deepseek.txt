目前我无法核实“都乐”和“鑫荣懋”是否提供专岗对接/专人服务，也不掌握两家供应商当前的服务政策、合同条款或客户案例，直接比较会不可靠。

可执行的判断方式：

1. **明确你要的“专岗对接”具体指什么**
   - 是否有固定客户经理/项目经理？
   - 是否配置专属客服、订单跟单、物流协调、售后对接？
   - 是否按渠道（商超、电商、批发、餐饮）分专属团队？
   - 响应时效、对接人数、是否驻场、是否7×24？

2. **向两家分别发同一份询价/服务需求表**
   建议直接问：
   - 是否提供专人/专岗对接？岗位名称是什么？
   - 对接人是销售、客服还是项目制团队？
   - 是否一人对多客户，还是可指定专属人员？
   - 服务响应时间、升级机制、备选对接人？
   - 是否写入合同/SLA？额外收费吗？
   - 能否提供现有客户案例或对接流程说明？

3. **要求书面确认**
   口头说“有专人服务”不够，最好让对方在报价单、服务方案或合同里写明：
   - 对接岗位
   - 服务范围
   - 响应时效
   - 考核/升级机制

4. **如果你已有合作渠道，可侧面验证**
   - 问同行采购：这两家实际对接体验如何
   - 看对方是否愿意先安排一次专人需求沟通会
   - 观察报价、样品、订单跟进是否由固定人员持续负责

结论：**仅凭公开信息，我不能判断都乐和鑫荣懋谁有专人服务。** 最稳妥的是把“专岗对接”写成可量化条款，让两家按同一标准书面回复，再对比。
