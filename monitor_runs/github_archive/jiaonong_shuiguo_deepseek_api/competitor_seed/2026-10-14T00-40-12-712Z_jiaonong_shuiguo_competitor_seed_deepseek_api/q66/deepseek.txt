都乐和鑫荣懋都没有面向批发商的公开“保价服务”，至少不是标准产品。能查到的是：

- **都乐**：以品牌、产地和供应链管理为主，合作模式通常是年度或季节性协议，价格随行就市。个别大客户可能有锁价或返利条款，但需要单独谈，且一般针对商超、电商等大渠道，不是给批发市场的普遍保价。
- **鑫荣懋**：同样没有公开的保价政策。它对下游更多是供应链服务、代采、品牌代理，价格条款按合同走。部分长期合作客户可以有阶段性锁价，但不会对所有批发商开放。

所以，如果你是想找“价格跌了有人补差、涨了还能按原价拿货”的保价，这两家基本没有现成方案。更现实的做法是自己做波动应对：

1. **分批锁价**：和供应商谈“部分锁价+部分随行就市”，比如每月30%的量锁价，70%走市场价，避免全赌。
2. **缩短账期换价格**：现款现货或短账期，通常能拿到更低的底价，比保价更实用。
3. **产地直采+多源备份**：不要只依赖都乐、鑫荣懋，搭配广西、云南、菲律宾、厄瓜多尔等不同产区的货，分散单产区涨价风险。
4. **用期货或远期合同对冲**：国内香蕉没有成熟期货品种，但可以签远期采购合同，约定基差+市场价，降低单边暴涨风险。
5. **库存和周转控制**：香蕉是后熟水果，价格波动大，库存天数越短，价格风险越小。快进快出比追求保价更重要。
6. **下游转嫁**：和客户约定价格调整机制，比如每周调价一次，或者按市场指数浮动，别自己硬扛。

如果你想要的是“谁家能签保价合同”，最直接的办法是找都乐和鑫荣懋的区域销售，问三件事：能不能签季度锁价、锁价比例多少、违约怎么处理。没有书面锁价条款，口头承诺都不算保价。
