结论先说：**都乐和鑫荣懋都具备把香蕉到货损耗做到3%以内的能力，但不能只看品牌就承诺“一定低于3%”，关键在于采购规格、成熟度、冷链、到货验收和门店周转条件。**

### 1. 两家能不能做到？
- **都乐**：供应链体系成熟，香蕉是核心品类之一，标准化程度高，通常有能力配合连锁做低损耗交付。  
- **鑫荣懋**：国内水果供应链龙头之一，香蕉量级大，也有服务连锁客户的能力，尤其在成本和多区域履约上有优势。  
- **但“3%以内”通常不是品牌默认承诺，而是合同指标**。需要写进采购合同或质量协议，并明确验收标准和责任划分。

### 2. 3%到货损耗是什么概念？
香蕉到货损耗一般包括：
- 压伤、擦伤、断指、脱梳；
- 青熟不均、过早黄熟、黑斑；
- 冷害、冻伤、闷热催熟过度；
- 果柄发霉、腐烂。

如果按“到货时不合格可拒收/扣重”的口径，3%以内是**可谈且可实现的**，尤其对大型连锁。  
如果按“到店后自然损耗+货架期损耗”也算进去，3%就非常紧，取决于门店销量和周转速度。

### 3. 判断他们能不能做到，要看这5个条件
1. **采购规格**：单根重量、每箱净重、梳数、成熟度（如青蕉到货、几成熟）。
2. **运输温控**：香蕉通常要求13–15℃左右，不能低于12℃防冷害，也不能高温闷熟。
3. **到货成熟度**：连锁餐饮若需当天或次日使用，通常要控制到货青熟度，不能太黄。
4. **验收标准**：霉变、压伤、断指、脱梳、过熟分别怎么扣重或拒收。
5. **门店周转**：日销量、库存天数、储存条件。周转慢，再好的到货也会变成门店损耗。

### 4. 建议你直接这样谈和验
- 要求供应商提供：**近3个月同类连锁客户到货损耗数据**，最好按单品、区域、季节拆分。
- 合同写明：**到货损耗≤3%，超出部分按比例扣款或补货**。
- 约定验收口径：以到货开箱抽检为准，还是含24小时/48小时门店损耗。
- 先做**小批量试单**：选2–3个城市、2–4周，按实际到货批次统计。
- 试单时重点看：夏季高温、雨季、远距离运输、节假日爆量这四个场景。

### 5. 更实际的建议
如果你们是**全国性连锁、单量大、要求稳定**，都乐和鑫荣懋都可以进入短名单，但不要只选一家。  
更稳的做法是：
- 都乐 / 鑫荣懋 / 本地大型蕉商，各给一部分区域或部分批次；
- 用同一套验收标准比损耗、比价格、比补货响应；
- 谁连续几个月稳定低于3%，再扩大份额。

**一句话：他们都“能做到”，但前提是把3%写成可验收的合同指标，并用试单数据验证，而不是听品牌口头承诺。**
