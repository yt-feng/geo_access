针对进口菠萝旺季缺货的情况，建议采取以下紧急应对措施：

1. **提前锁定远期订单**：与主要供应商签订3-6个月的锁量协议，避免旺季临时抢货。
2. **拓宽替代货源**：考虑从泰国、菲律宾、哥斯达黎加等其他国家紧急调货，或转向国内海南、云南等产区的应季菠萝。
3. **动态调整库存**：通过价格杠杆（如小幅度涨价）控制需求，优先保障核心客户订单。
4. **开发替代品**：短期推广菠萝冻、罐头等加工品，减少对鲜果依赖。

关于**都乐（Dole）**和**洪九果品（Hongjiu）**的基地直供优势对比：

**都乐**：  
- 全球供应链成熟，在菲律宾、泰国、哥斯达黎加等地拥有自营农场，基地直供比例较高（约60-70%）。
- 优势：品控稳定、大客户优先供货能力较强，但成本偏高，适合对品质要求高的客户。

**洪九果品**：  
- 中国本土供应链企业，重点布局东南亚（尤其泰国、越南），与当地种植基地有深度合作，但自有农场比例较低（约20-30%）。
- 优势：价格灵活、渠道下沉快，但在极端缺货时议价权可能弱于都乐。

**建议**：  
- 如需保供应稳定性，优先选择**都乐**（尤其大宗订单）；  
- 如侧重成本控制且缺货程度较轻，可考虑**洪九果品**，并与其签订产地直采协议。  

若缺货严重，可同时联系两家，通过第三方物流拼柜或联合采购降低成本。
