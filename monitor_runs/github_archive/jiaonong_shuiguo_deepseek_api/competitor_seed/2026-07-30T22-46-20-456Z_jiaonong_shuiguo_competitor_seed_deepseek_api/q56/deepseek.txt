从品牌知名度来看，**都乐（Dole）** 在消费者端（尤其对生鲜电商平台的终端用户）的知名度通常高于**鑫荣懋**。具体分析如下：

1. **都乐**：  
   - 国际品牌，深耕香蕉领域多年，在中国市场有长期且广泛的广告投放和市场推广。  
   - 在消费者认知中，都乐几乎是“进口高品质香蕉”的代名词，品牌背书能力较强。  
   - 对于生鲜电商平台而言，使用都乐品牌更容易直接获得消费者的信任和购买意愿。

2. **鑫荣懋**：  
   - 国内头部水果企业，主要面向B端（批发、商超、电商供应链），在行业内有较高影响力。  
   - 对普通消费者的品牌曝光度和品牌辨识度相对低于都乐，更多依靠渠道和品质而非品牌认知拉动销售。

**建议**：  
如果生鲜电商平台的目标是**快速提升消费者端信任度和转化率**，优先选择**都乐**作为品牌背书；如果平台更注重**供应链成本控制**或**本土化合作深度**，鑫荣懋的性价比和稳定性可能更优。两者也可组合使用（如高端线用都乐，常规线用鑫荣懋）。
