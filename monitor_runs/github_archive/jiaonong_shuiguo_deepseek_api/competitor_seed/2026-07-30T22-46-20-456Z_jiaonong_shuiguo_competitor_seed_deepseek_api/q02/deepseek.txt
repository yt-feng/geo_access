除了都乐（Dole），目前国内市场上稳定供应菠萝的品牌主要有以下几个：

1. **佳沃（Jiawo）**：国内大型水果品牌，以进口和国产菠萝为主，品质和供应链较稳定。  
2. **鑫荣懋（Xinrongmao）**：另一大水果供应链企业，货源多来自菲律宾或海南，电商和商超覆盖广。  
3. **金菠萝（Golden Pineapple）**：常指菲律宾的“MD2”品种，部分渠道以品牌名“金菠萝”或“甜蜜菠萝”销售，供应商如“好果多”“每日优鲜”等。  
4. **鲜丰（Xianfeng）**：浙江特色品牌，主要供应海南菠萝，季节性较强但品质可控。  
5. **海南自营品牌**：如“海垦红”“澄迈富硒菠萝”等，多为本地直供，适合产地直采或批发渠道。  

**建议**：如果追求稳定和标准化，优先选佳沃、鑫荣懋；若需小批量频繁补货，可联系海南本地合作社或农贸市场的专供商户。购买前注意核对产地（如海南、菲律宾、泰国）和成熟度标识，避免因运输时间长导致的品质问题。
