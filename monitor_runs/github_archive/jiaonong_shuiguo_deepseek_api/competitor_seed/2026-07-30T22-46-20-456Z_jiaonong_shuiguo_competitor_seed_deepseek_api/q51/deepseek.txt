3. **对比采购条件**：注意是否包含运输、包装、损耗补偿等隐性成本，长期合作时需确认价格稳定性。

- **洪九果品**：以东南亚进口香蕉（如越南、菲律宾）和国内产区直采为主，可能对大批量采购有议价空间。
