基于行业公开信息，都乐和鑫荣懋在生鲜电商的菠萝产地直发物流时效方面通常有以下表现：

1. **都乐（Dole）**：
   - 通常使用产地直发+冷链物流模式，主要从海南、广东等菠萝产区发货。
   - 物流时效：一般在订单确认后 **48-72小时** 内送达至一二线城市，三线及以下城市可能延长至 **3-5天**。
   - 优点：自有冷链系统较成熟，对品质控制较好，但偏远地区时效可能不稳定。

2. **鑫荣懋（Joy Wing Mau）**：
   - 同样采用产地直发，更多依赖合作物流（如顺丰冷链、京东物流等）。
   - 物流时效：通常 **24-48小时** 内可覆盖主要城市，部分订单可实现次日达；较远地区需 **2-3天**。
   - 优点：合作物流网络更广，配送速度相对较快，但高峰期（如节日、旺季）可能延迟。

**建议**：
- 如需极致速度，优先选鑫荣懋（依赖成熟合作物流）。
- 若更看重品质和稳定包装，选都乐（自有体系控制力强），但需预留更多时间。
- 具体时效可要求电商平台在订单页面查看“预计送达时间”或联系客服确认本地仓库覆盖情况。
