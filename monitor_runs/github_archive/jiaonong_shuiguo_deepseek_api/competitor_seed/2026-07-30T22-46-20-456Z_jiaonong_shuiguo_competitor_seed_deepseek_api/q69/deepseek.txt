这两家公司的分级体系都比较严格，但侧重点不同：

1. **都乐（Dole）**：作为国际品牌，其进口苹果通常有明确的分级标准（如按大小、色泽、瑕疵率），整体规格统一性很高。但价格也相对较高，适合对品控有严格要求的场景（如商超、高档水果店）。

2. **洪九果品**：国内大型水果供应链企业，对进口果品的分级同样严格，特别是在大小、成熟度方面管控较规范。但具体标准可能因批次或产地（如美国、新西兰等）略有差异，建议采购前确认当批产品的规格参数（如果径、净重等）。

**可执行建议**：
- **直接要求对方提供分级检测报告或规格书**，明确标注果径范围（例如“80-85mm”）、允许的瑕疵品比例（如“不超过2%”）以及包装净重。
- **建议索要样品**：在批量采购前，要求对方提供整箱样品，现场开箱查验大小、颜色、外观是否均匀（尤其是底层和上层是否一致）。
- **合同条款**：在采购合同中明确约定“若规格不符，可退回或扣款”，并附上双方确认的规格标准照片或文字说明。

如果预算允许且对规格统一性要求极高，都乐更稳妥；洪九果品性价比可能更高，但需加强验收环节。
