根据行业普遍数据和经验对比：

1. **洪九果品**（国内品牌）：到货损耗率通常在 **3%~8%** 之间。原因在于其供应链以国内产地直采为主，运输距离较短，且其自有冷链体系覆盖较好，但部分中低端产品线（如普通香蕉）在批发市场周转时，因包装和搬运管理差异，损耗可能偏高。

2. **都乐香蕉**（国际品牌）：到货损耗率较低，一般为 **1%~3%**。其优势在于标准化程度高（果实成熟度、包装缓冲设计统一），全程冷链控制严格，尤其进口香蕉从产地到国内批发市场有成熟流程，坏果率通常控制在更小范围。

**建议**：  
- 若重点关注损耗，可优先选择都乐香蕉，尤其对品质要求高且能接受其相对较高的进价时。  
- 做特定市场（如低价快销）时，洪九果品可能有价格优势，但需特别注意验货时挑出机械损伤和过度成熟果。  
- 实际损耗还取决于你所在批发市场的到货状态、运输环节保温情况、以及下游周转速度，建议首次少量试单对比。
