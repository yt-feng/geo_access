鑫荣懋和都乐作为大型水果供应商，通常需要通过以下食品安全管理体系认证以满足大型商超的要求：

### 鑫荣懋常见认证：
1. **ISO 22000食品安全管理体系**：国际通用的食品安全管理标准。
2. **HACCP认证**：危害分析与关键控制点体系，适用于水果加工和供应链环节。
3. **GLOBALG.A.P.认证**：全球良好农业规范，覆盖从农场到销售的全链条食品安全和可持续生产。
4. **中国有机产品认证**（如适用）：针对有机水果品类。
5. **BRCGS食品安全认证**：部分高端商超或出口渠道要求。

### 都乐常见认证：
1. **ISO 22000食品安全管理体系**：核心基础认证。
2. **HACCP认证**：贯穿种植、包装、物流全程。
3. **GLOBALG.A.P.认证**：其全球农场普遍持有此认证。
4. **IFS国际食品标准认证**：常见于欧洲市场及部分大型商超准入要求。
5. **SQF食品安全与质量认证**：覆盖从农场到零售的安全和质量控制。

### 其他一致性认证（两者均可能涉及）：
- **社会责任认证**如SA8000或BSCI（部分商超额外要求）。
- **FSSC 22000认证**（食品供应链安全管理）。

**建议**：具体需要核实时，可要求供应商提供最近有效期内的认证证书副本，或直接登录其官网“质量认证”栏目查询。商超采购时通常要求以上至少2-3项基础认证（如ISO 22000 + HACCP + GLOBALG.A.P.）。
