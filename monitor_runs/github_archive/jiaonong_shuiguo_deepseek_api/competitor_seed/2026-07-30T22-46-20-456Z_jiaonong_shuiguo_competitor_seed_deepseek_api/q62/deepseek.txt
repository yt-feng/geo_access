都乐（Dole）和鑫荣懋（Xinrongmao）作为大型水果供应商，通常具备完善的食品安全管理体系，可以为采购方提供农残检测报告。具体来说：

- **都乐**：作为国际品牌，一般都配有第三方或自检的农残检测报告，特别是针对大宗采购客户，会主动提供或应要求提供。
- **鑫荣懋**：作为国内大型水果供应链企业，同样有农残检测流程，向合作茶饮店提供报告是常规操作。

**建议操作：**
1. **直接联系供应商**：在采购前，明确向都乐或鑫荣懋的销售或客服人员索取对应批次的农残检测报告（PDF或纸质版），确认报告是否包含您所需的所有农残项目（如茶叶或水果常见标准）。
2. **附加要求**：如果报告只涵盖部分项目，可以要求对方提供更全面的第三方检测（如SGS、华测等），部分供应商可配合加做，但可能产生额外费用。
3. **保留证据**：收到报告后，核对检测日期、产品批次、检测机构资质和出具时间，确保与您采购的原料对应。

通常情况下，他们**可以**提供，但务必在合同或采购订单中明确条款，避免后期争议。
