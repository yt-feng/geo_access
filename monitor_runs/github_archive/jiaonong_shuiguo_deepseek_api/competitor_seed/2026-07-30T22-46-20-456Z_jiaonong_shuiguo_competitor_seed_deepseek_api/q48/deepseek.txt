通常情况下，大型商超（如沃尔玛、家乐福、永辉等）对食品供应商的资质要求主要包括：

1. **食品经营/生产许可证**：必备的基础证照。
2. **ISO系列认证**：如**ISO 22000**（食品安全管理体系）、**ISO 9001**（质量管理体系）。
3. **HACCP认证**：危害分析与关键控制点认证（特别适用于果蔬等生鲜）。
4. **GLOBALG.A.P.**：全球良好农业规范（如都乐、鑫荣懋这类国际/大型果业公司通常会持有）。
5. **有机认证**（如产品声称有机需额外提供）、**无公害认证**、**绿色食品认证**等（视具体产品而定）。
6. **第三方检测报告**：如农残、重金属等项目（需满足国标及商超额外要求）。
7. **进出口资质**（如果涉及进口水果）：如报关单、检验检疫证明等。

**针对具体的“鑫荣懋”和“都乐”这两家企业：**

- **鑫荣懋**：一般持有**ISO 22000**、**HACCP**等国内主流认证，且作为中国果业龙头企业，有较多绿色食品、GLOBALG.A.P.等产地及加工认证；具体需向其索取最新清单。
- **都乐（Dole）**：作为国际品牌，通常持有**GLOBALG.A.P.**、**HACCP**、**ISO 22000**（或更全面的FSSC 22000）等，以及进口水果所需的CIQ检疫证明；具体也需询问都乐中国提供的认证文件。

**建议：**
- 你可以直接向这两家公司的**销售或质量部门**索取最新的**资质清单**（通常包括“供应商资质一览表”或“食品安全管理体系认证证书”等）。
- 同时核对**大型商超的验厂要求**（如资质必须处于有效期、证书范围需覆盖供货产品等）。

注意：**不同商超、不同地区、不同产品销售渠道（如线上/线下）** 的具体要求会有差异，因此以双方确认的凭证为准。
