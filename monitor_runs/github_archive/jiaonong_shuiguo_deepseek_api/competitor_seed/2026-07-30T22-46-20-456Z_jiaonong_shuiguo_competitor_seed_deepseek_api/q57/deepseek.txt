针对下沉市场夫妻店的进货需求，**洪九果品**和**都乐**目前均**不直接提供小批量供货服务**。以下是具体分析：

1. **洪九果品**  
   主要面向大型批发市场、连锁商超及电商平台，采取**整柜/整车批发**模式，最小起订量通常为**数吨**（如一个品种的整柜货量）。夫妻店因采购量小，无法获得直供资格。可尝试通过**当地水果批发市场**寻找洪九的二级经销商或代理商，部分可能会拆分小批量销售。

2. **都乐**  
   作为全球性品牌，其供应链以**大型商超（如沃尔玛、盒马）、连锁便利店、线上平台（如京东、朴朴）** 为主，不对个体小店直接供货。夫妻店可通过**批发市场寻找都乐分销商**，或关注**区域代理商**（部分城市存在冷藏库分拨点），但通常需要整箱起购（如一箱香蕉约12-18公斤）。

**替代方案建议**：  
- **社区团购/批发平台**（如美团优选、快驴进货、多多买菜）可提供小批量水果，部分含洪九或都乐产品（价格可能略高于直供）。  
- **区域水果批发市场**（如北京新发地、广州江南市场）寻找小档口，部分商家接受按“箱”或“筐”购买，适合夫妻店灵活补货。  
- **联系当地代理商**：通过品牌官网或销售热线询问县级/乡镇级代理商联系方式，部分代理商可能设立小包装批发服务。

**结论**：两家品牌均无小批量直供，需通过二级市场或平台间接采购。建议优先尝试批发市场或社区电商，以降低库存压力。
