根据一般的行业经验和公开数据，**都乐（Dole）** 和 **鑫荣懋（Joy Wing Mau）** 作为大型跨国或国内头部水果供应商，在供应链管理和品控上具备较强能力，理论上可以将香蕉到货损耗率控制在较低水平。

但需注意以下几点：

1. **损耗率取决于具体品控标准与运输条件**：香蕉在运输、仓储、分销过程中可能因温度、湿度、处理方式产生“压烂”、“擦伤”、“熟度不均”等问题。3%的损耗率属于较高要求，需要双方合同明确约定“到货时可接受瑕疵比例”以及“退货/理赔条款”。
2. **供应商实际能力差异**：
   - **都乐**：作为全球香蕉巨头，其大规模冷链管理系统成熟，通常能支撑较低的到货损耗（部分零售合作案例中可做到1-2%）。
   - **鑫荣懋**：国内领先水果企业，香蕉供应链整合能力强，但具体损耗率需以实际合同条款和物流执行情况为准。
3. **建议措施**：
   - 双方签订采购合同时，明确约定“到货损耗率≤3%”及对应的验收标准、赔偿责任。
   - 可要求供应商提供过往同类客户（如大型超市、连锁餐饮）的损耗率数据或合作案例。
   - 到货时严格执行抽样检验（如随机开箱检查5-10%），按重量或数量计算实际损耗。
   - 考虑调节运输包装（如增加缓冲材料、调节熟度标准）以降低损耗。

**结论**：两家供应商**有潜力**满足该要求，但需通过合同条款、验收流程和过程管理来保障。建议先以试单方式验证一批次的损耗率，再决定长期合作。
