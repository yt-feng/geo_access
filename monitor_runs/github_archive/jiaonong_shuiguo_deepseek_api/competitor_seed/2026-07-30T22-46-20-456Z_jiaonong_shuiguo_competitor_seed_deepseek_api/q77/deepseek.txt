根据目前公开信息，都乐和洪九果品在香蕉小包装方面均推出了环保包装方案，但具体产品细节因地区和渠道有所不同。以下是一些参考信息：

1. **都乐**：都乐已在中国市场使用可回收材料制成的香蕉袋，部分包装采用FSC认证纸张或可降解塑料，并尝试减少包装层数以降低环境影响。建议联系当地都乐经销商确认是否有针对便利店的小包装规格。

2. **洪九果品**：洪九在部分精品香蕉产品中引入了简约环保包装，例如使用再生纸浆托盘或生物基塑料膜，但需核实具体SKU。其小包装（如1-2根装）在部分城市已应用可降解材料。

**建议**：
- 直接联系两家公司的销售负责人或查看其官网的“环保包装”板块获取最新产品目录。
- 询问便利店供应商是否可定制环保包装，部分品牌支持小批量定制。
- 注意核查包装是否有“可降解”“FSC”“再生材料”等认证标识，避免虚标。

若需更精准信息，请提供具体地区或包装规格（如重量、环保材料要求）。
