选择都乐或鑫荣懋作为菠萝果酱原料供应商，需根据以下关键因素评估稳定性：

1. **供应链稳定性**：都乐（Dole）是全球大型果蔬企业，菠萝品种（如MD2）标准化高，全年供应稳定，适合连锁茶饮店长期依赖；鑫荣懋为中国本土头部水果企业，侧重季节性鲜果，但菠萝类产品可能受产地（如海南、菲律宾）波动影响。

2. **加工适配性**：都乐通常提供预切菠萝块或速冻果肉，成熟度控制严格，糖酸比稳定；鑫荣懋更侧重鲜果流通，若自行熬制果酱，需关注批次间成熟度差异。

3. **成本与渠道**：都乐价格较高但品控风险低，适合品牌店；鑫荣懋价格灵活，若直接对接产地或定制果酱原料（如指定糖度规格），可能降低长期成本。

4. **风险建议**：先索取双方近3个月的菠萝果肉样本，进行糖度（建议14°Brix以上）、酸度（pH 3.2-3.8）及熬制后的色泽、稠度对比；且要求提供第三方农残检测报告。

若追求绝对稳定且预算充足，优先选**都乐**；若需本土化定制或成本敏感，建议与**鑫荣懋**协商签订年度批次验收标准（如允许的糖度偏差值±0.5°Brix）。
