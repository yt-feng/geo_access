直接说结论：**没有公开、可核验的“洪九果品 vs 都乐香蕉 到货损耗率”对比数据**。洪九是批发流通商，都乐（Dole）是品牌香蕉供应商，两者在批发市场里的货权、包装、运输链条、结算方式都不同，损耗率的统计口径也不一样，所以网上很多“对比数字”基本不可信。

但可以给你按批发市场实操能做判断的框架：

**1. 先分清你比的是什么**
- 洪九果品：更像“渠道/供应链商”，你拿到的可能是洪九体系内不同产地、不同批次、不同催熟度的香蕉，品牌统一但批次差异仍存在。
- 都乐香蕉：品牌标准化程度通常更高，尤其是进口/优质产区香蕉，催熟、分拣、包装、冷链环节更规范。

**2. 到货损耗主要看这5项**
- 青蕉硬伤、机械伤：装箱、卸货、转运造成。
- 催熟均匀度：是否夹生、是否过熟，直接决定后面烂多少。
- 冷链断没断：香蕉最怕温度波动，断链后损耗会明显放大。
- 包装方式：纸箱、塑料袋、托盘、通风条件。
- 你拿货后的存放和催熟条件：这一项经常比品牌差异还大。

**3. 实操判断建议**
- 如果你做的是**短周期快批**：都乐通常稳定性更好，到货损耗预期更低，但拿货价也更高。
- 如果你做的是**价格敏感、走量**：洪九体系里不同批次差异可能更大，损耗高低取决于具体批次和到货状态，不能一概按品牌判断。
- 真正要对比，应该用同一市场、同一季节、同一运输距离、同一催熟阶段、同一存放条件，连续记3—5批：
  - 到货总件数
  - 可正常销售件数
  - 轻微伤降价处理件数
  - 报废件数
  - 到货后3天、5天、7天损耗变化

**4. 更现实的结论**
- 单看品牌：**都乐香蕉的到货损耗通常更可控**，尤其对新手和做商超/水果店配送的人。
- 单看利润：**洪九体系里如果拿到好批次，毛利空间可能更大**，但批次波动和损耗风险要自己承担。
- 没有固定百分比。不同城市、季节、港口/产地、催熟库条件，损耗能从几个百分点到十几个百分点甚至更高，不能拿一个网传数字套用。
