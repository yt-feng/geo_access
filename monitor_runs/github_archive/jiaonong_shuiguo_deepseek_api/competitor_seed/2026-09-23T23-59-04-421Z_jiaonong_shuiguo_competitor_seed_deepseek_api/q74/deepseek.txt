我不能凭空给都乐和洪九的起订量数字，这类政策通常随渠道、品类、包装形式、合作模式变化，而且我无法核验最新来源。下面给你可执行的判断和获取准确数字的方法。

**先说结论：**
- **都乐**：礼品团购/企业定制一般走区域经销商或大客户渠道，不是全国统一一个起订量。常见门槛取决于你是否要贴牌、是否指定礼盒、是否指定单品。
- **洪九果品**：以批发和渠道分销为主，团购定制通常也要对接区域销售，起订量往往按“件/箱/板/整车”谈，不是固定零售式起订。

**你可以按下面方式快速拿到准确答复：**

1. **直接找官方渠道**
   - 都乐：找官网/公众号里的“企业团购/大客户合作/联系我们”，转区域销售。
   - 洪九果品：找官网/公众号/客服，问对应城市或区域的团购负责人。

2. **问的时候一次把条件说清**
   对方才能给你准确起订量：
   - 城市/收货地
   - 预算单价
   - 数量（例如 100 份、500 份、1000 份）
   - 是否要定制礼盒、腰封、卡片、LOGO
   - 指定水果品类还是混合装
   - 是否需要一件代发/分地址配送
   - 期望交付时间

3. **重点确认这 6 项**
   - 起订量：按份、按箱还是按整车
   - 是否支持混搭
   - 定制包装是否额外收费、多少起定
   - 是否含运费、分拣费、损耗
   - 账期和付款方式
   - 坏果/售后赔付标准

**经验判断：**
- 如果你只要 **100～300 份**，通常更适合找区域经销商或本地水果供应链，不一定能直接拿到品牌方最低价。
- 如果做到 **500～1000 份以上**，再找品牌区域大客户渠道谈，起订量和价格空间会更好。
- 如果要 **礼盒贴牌/专属包装**，起订量通常会明显高于普通团购。
