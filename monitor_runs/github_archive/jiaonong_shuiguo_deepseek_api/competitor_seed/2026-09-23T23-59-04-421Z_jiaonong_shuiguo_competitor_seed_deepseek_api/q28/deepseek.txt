我不能凭空给出“都乐更便宜”或“鑫荣懋更便宜”的确定结论，因为进口苹果的实际拿货价受**品类（如新西兰爱妃、红玫瑰、爵士；美国蛇果；智利/南非苹果等）、规格、包装、到港批次、汇率、账期、返利政策、区域仓配**影响很大，而且两家在不同单品上的报价策略并不一致。

但可以给你一套可直接判断的办法，以及经验性判断：

**经验结论（仅作方向参考）**
- **都乐**：品牌溢价更强，终端认知高，适合做礼盒、精品陈列、线上引流款。通常**同规格裸果报价未必最低**，但动销和溢价能力可能更好。
- **鑫荣懋**：进口水果供应链能力强，尤其在新西兰、智利等产区操作深，部分单品和整柜/大货采购上**往往更有价格弹性**，适合走量、做促销、做日常主推。
- 所以不能简单说谁更有竞争力，要看你目标是**毛利**还是**周转**：
  - 要品牌背书、礼盒溢价：都乐可能更合适。
  - 要批量走货、价格竞争：鑫荣懋通常更值得重点谈。

**建议你这样比价，才不会被“表面报价”误导**
1. **锁定同一单品同一规格再比**
   - 例如：新西兰爱妃苹果，70#/80#/90#，12粒装/18粒装/整箱，净重多少。
   - 不同规格混着比，结论没有意义。

2. **要求报“到仓含税价”**
   - 包括：货价、关税、增值税、运费、冷链、损耗承担、落地费。
   - 只看港口价或批发市场价，容易误判。

3. **把返利和账期折算进去**
   - 月返、季返、年返、新品补贴、陈列补贴、损耗补贴。
   - 账期30天和现款现货，资金成本差很多。
   - 建议算“综合采购成本”：
     **综合成本 = 含税到仓价 - 可确认返利 + 资金占用成本 + 损耗成本**

4. **按单品做AB对比**
   - 选3-5个你实际要卖的单品，让两家分别报价。
   - 每个单品看：报价、起订量、到仓时间、果径/糖度/硬度、损耗率、售后理赔。

5. **小批量试单**
   - 同一门店、同一陈列、同一价格带，各试2周。
   - 看真实动销、损耗、客诉、毛利，而不是只看采购价。

**如果你要快速决策**
- 做**礼盒/精品/品牌心智**：优先谈都乐，但要求它给陈列和品牌支持。
- 做**日常走量/促销爆款**：优先谈鑫荣懋，重点压到仓价和返利。
- 最稳的是：**同一单品让两家同时报价，按综合成本比，不要按品牌印象比。**
