都乐和洪九果品通常不对外提供可直接用于第三方营销的免费素材（品牌Logo、产品图、包装图、广告视频等），原因和可行路径如下。

**1. 版权和授权现实**
- 都乐（Dole）和洪九果品都是有品牌资产的公司，其产品图、Logo、宣传视频均受商标权和著作权保护。
- 未经授权使用这些素材做营销，即使是在生鲜电商平台上，也可能构成侵权或被品牌方投诉下架。
- 品牌方一般只对授权经销商、合作渠道或联合营销项目开放素材库。

**2. 能拿到素材的可行路径**
- **走商务合作**：联系都乐或洪九果品的渠道/市场部门，说明你是生鲜电商平台，提出联合营销、品牌专区、产地溯源内容等合作，通常可换取官方素材授权。
- **通过现有供货关系**：如果你已从他们的经销商或批发渠道进货，可请上游供应商协助向品牌方申请素材包。
- **平台侧资源**：部分生鲜电商平台与品牌方有年度框架合作，可让平台招商或品类运营帮你对接品牌素材。
- **自行拍摄**：购买其产品后自行拍摄实物图、开箱视频，用于自己店铺的商品详情和内容营销，风险较低，但不得修改或暗示品牌官方背书。

**3. 不建议的做法**
- 直接从官网、电商详情页、社交媒体下载图片或视频使用。
- 用都乐/洪九的Logo做店铺装修、主图角标或宣传海报而不获授权。
- 声称“官方合作”“品牌直供”但没有书面依据。

**4. 如果只是想借菠萝品类做营销**
不一定非要都乐或洪九的素材。可以：
- 用自有供应链的菠萝做产地、品种、糖度、催熟等差异化内容。
- 找国产菠萝产区（如广东徐闻、海南、云南）的供应商或合作社，他们往往更愿意提供素材和联合推广。
- 做“菠萝选购指南”“凤梨vs菠萝”“切菠萝教程”等工具型内容，不依赖特定品牌素材。

**结论**：都乐和洪九果品一般不会直接给外部免费素材，需通过商务合作或供货渠道申请授权；若只是做菠萝品类营销，可优先用自有产品或产区供应商素材，规避版权风险。
