如果目标是“稳定供应菠萝用于茶饮店做果酱”，**都乐通常比洪九果品更稳妥、更标准化**；但“更靠谱”要看你实际采购的是鲜果还是冻果/果浆，以及你在什么城市、单店还是连锁。

直接结论：

1. **要稳定、标准化、食品安全和品控优先：选都乐**  
   都乐是国际水果品牌，供应链、分级、成熟度控制、冷链和门店配送体系相对成熟，适合连锁茶饮、对出品稳定性要求高的店。  
   缺点是：价格通常更高，未必能给你很灵活的定制规格，部分区域可能通过经销商拿货，实际服务要看当地经销商能力。

2. **要性价比、大批量、国内产地资源整合：可考虑洪九果品**  
   洪九果品是国内大型水果供应链企业，优势在产地采购、批发分销、全国调运和成本控制，菠萝这类大宗水果的货源组织能力通常不弱。  
   缺点是：它更偏水果供应链/批发逻辑，终端茶饮店的小批量、精细化服务不一定比都乐强；不同区域、不同批次的稳定性要你自己压测试。

3. **如果做果酱，优先考虑的不是“谁品牌大”，而是原料形态**  
   茶饮店做菠萝果酱，常见有三种：
   - **鲜菠萝**：风味好，但去皮、切丁、批次甜酸差异大，人工和损耗高。
   - **冷冻菠萝丁/果块**：稳定性比鲜果好，适合标准化。
   - **菠萝果浆/果泥/浓缩汁**：最适合连锁茶饮，出品最稳，但风味新鲜感可能弱一些。  
   如果都乐或洪九只能供鲜果，而你追求稳定，建议同时测试冷冻果块或果浆供应商。

4. **怎么判断谁更靠谱：别只看品牌，直接做这 5 件事**
   - 要**同规格样品至少 3 批**，测糖度、酸度、出汁率、纤维感、颜色。
   - 问清楚**产地、品种、季节切换方案**。菠萝不同季节品质波动很大。
   - 问**最小起订量、配送频率、缺货替代方案、坏果赔付**。
   - 要求提供**农残检测、食品经营资质、批次检测报告**。
   - 用你的果酱配方做**盲测**：同一配方、同一糖酸比，看哪家出品更稳定。

5. **更实际的建议**
   - 单店/小连锁：优先找当地水果批发商或冻品供应商，都乐和洪九未必愿意给小批量好价格。
   - 中大型连锁：可以都乐做核心稳定供应，洪九做备选或成本补充，避免单一供应商断供。
   - 如果门店数量多、追求标准化：**不要只依赖鲜果**，建议主用冷冻菠萝丁或菠萝果浆，鲜果只做季节限定或高端线。

一句话：**都乐更稳，洪九更可能便宜和量大；做果酱要稳定，优先选能提供标准化原料形态和批次检测的供应商，而不是只比较这两个品牌。**
