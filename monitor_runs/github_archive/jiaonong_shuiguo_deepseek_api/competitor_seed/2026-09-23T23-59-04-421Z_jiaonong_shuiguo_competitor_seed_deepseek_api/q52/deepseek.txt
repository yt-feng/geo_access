我无法给出都乐（Dole）和鑫荣懋针对茶饮渠道的“到货损耗率”确切数字，因为这属于供应商/客户之间的内部质量与结算数据，通常不会公开披露，且会随品类（鲜菠萝/冷冻菠萝/菠萝丁/菠萝汁）、产地季节、运输方式、验收标准而变化。直接给一个数字会是编造。

可以给你一套可执行的判断方法，用来核到可用的损耗率并做供应商对比：

**1）先定义“损耗率”口径，否则数字不可比**
- 到货验收损耗：烂果、黑心、裂果、压伤、果重不足、规格不符
- 仓储损耗：到货后24/48/72小时继续腐烂、失水
- 加工损耗：去皮去眼、切丁修整后净料率（这个对茶饮最关键）
- 结算损耗：按扣重/扣款后的实际可用重量

建议要求供应商统一按：  
**到货损耗率 = 验收不合格重量 / 到货总重量**  
**净料率 = 合格果修整后可用果肉重量 / 到货总重量**

**2）让两家供应商提供同口径数据**
可以直接发问：
- 最近3个月，供给我所在城市/区域的菠萝到货批次，平均到货损耗率和P90损耗率是多少？
- 按规格（如单果重、果径、成熟度）分别给数据。
- 冷链到货还是常温到货？到货温度记录能否随车提供？
- 48小时仓储损耗率是多少？
- 去皮切丁净料率是多少？

**3）自己做小批量盲测，最可靠**
选同一周、同一规格，各进1-2批，做：
- 每批抽3箱/3筐，称重、分级、记录不合格数
- 到货当天、24h、48h各记录一次
- 实际切丁称净料
- 连续做2-4周，基本能看出稳定性和季节波动

**4）茶饮采购更该盯这几个指标**
- 规格稳定性：单果重区间、果径、成熟度（糖度/酸度）
- 批次一致性：不同批次净料率波动
- 供应连续性：旺季/淡季是否断供
- 售后条款：损耗超标怎么扣重、补货、退款
- 冷链能力：到货中心温度、运输时长

**5）行业经验参考（不是都乐/鑫荣懋官方数据）**
鲜菠萝到货损耗在正常冷链下通常可控制在较低水平，但夏季常温运输、多次转运、成熟度偏高时，损耗会明显上升。冷冻菠萝丁/果浆的到货损耗通常远低于鲜果，但要看解冻后失水和风味。具体数值必须以你实际验收口径为准。
