超市采购进口苹果时，“都乐（Dole）”和“鑫荣懋（Joy Wing Mau）”的产地溯源通常可以从两条线做：**向供应商索取合规文件** + **对到货批次做现场核验**。两家都不是简单“卖一个产地”的品牌，实际货源会随品类、季节、口岸和合同变化，所以不能只认品牌，要认**批次**。

下面按可执行流程说明。

## 一、先明确要追溯什么
对超市来说，进口苹果溯源至少要能回答：
1. 这批苹果的原产国/产区是谁？
2. 是谁出口、谁进口、谁供货给超市？
3. 到货批次号、生产日期/包装日期是什么？
4. 是否经过中国海关合规入境？
5. 如果出现质量问题，能否追到具体果园/包装厂/集装箱？

## 二、向都乐或鑫荣懋采购时，应索取的溯源文件
### 1. 基础商业与合规文件
- 合同/订单：写明品名、品种、规格、原产国、包装厂、批次号。
- 发票、装箱单：核对批次、数量、集装箱号。
- 提单/空运单：核对起运国、起运港、收货人。
- 中国海关进口货物报关单：核对原产国、境内收货人、商品编码、数量。
- 入境货物检验检疫证明：这是进口水果合规入境的关键文件之一。
- 海关进口增值税专用缴款书等：用于国内流通合规和税务核验。

### 2. 产地与供应链文件
- 原产地证明：由出口国官方或授权机构出具，核对原产国。
- 植物检疫证书：出口国官方出具，核对果园/包装厂注册信息。
- 包装厂注册号/果园注册号：很多国家输华水果要求果园和包装厂在华注册。
- 出口商/进口商资质：确认都乐或鑫荣懋对应主体，是直接进口还是二级分销。
- 批次追溯单：最好能提供“果园—包装厂—集装箱—口岸—超市门店”的链路。

### 3. 品牌方或供应商出具的追溯证明
- 都乐：可要求其中国公司或授权经销商出具批次追溯函，说明原产国、包装厂、进口商、批次。
- 鑫荣懋：同样要求其对应进口主体或事业部出具批次追溯文件。
- 注意：品牌授权书只能证明“有权销售”，不能替代原产地和检疫文件。

## 三、现场到货核验怎么做
### 1. 看包装标签
重点核对：
- 原产国英文/中文标识
- 品种、规格、等级
- 包装厂注册号
- 批次号/Lot No.
- 包装日期
- 出口商/进口商名称
- 中文标签是否合规

### 2. 核对“单货一致”
把报关单、检疫证、装箱单、提单上的信息与实物标签逐项核对：
- 原产国是否一致
- 批次号是否一致
- 包装厂编号是否一致
- 数量、规格是否一致
- 集装箱号是否能对应到本批

### 3. 扫码或查注册信息
如果标签上有二维码、追溯码：
- 扫描后看是否跳转到品牌方或官方追溯页面
- 核对页面信息与实物标签是否一致
- 若跳转到非官方页面，要警惕

### 4. 海关与官方核验
- 报关单可通过“中国国际贸易单一窗口”或委托报关行核验。
- 输华果园/包装厂注册信息，可查海关总署相关公告或注册名单。
- 检疫证、原产地证可向供应商索取原件或清晰扫描件，必要时向出证机构核验。

## 四、都乐和鑫荣懋的实操差异
### 都乐
- 都乐是国际品牌，供应链可能涉及多个国家，如新西兰、智利、美国、南非等。
- 采购时要确认：是都乐中国直接进口，还是都乐授权经销商供货。
- 重点索要：都乐中国或授权主体的批次追溯函、报关单、检疫证、原产地证。
- 如果对方只给“品牌授权”，不给批次文件，溯源不完整。

### 鑫荣懋
- 鑫荣懋是国内大型水果供应链企业，既做进口也做国产，可能同时代理多个国外品牌。
- 采购时要确认：鑫荣懋是直接进口商，还是国内分销商。
- 重点索要：对应批次的进口报关单、检疫证、原产地证、包装厂信息。
- 如果鑫荣懋从其他进口商拿货，要追到上一手进口商和报关单。

## 五、建议超市建立的溯源台账
每批进口苹果入库时，至少登记：
- 供应商名称
- 品牌（都乐/鑫荣懋）
- 原产国
- 品种
- 批次号
- 包装厂注册号
- 集装箱号
- 报关单号
- 检疫证号
- 到货日期
- 保质期/包装日期
- 对应门店/货架

这样一旦出现质量问题或监管检查，可以快速定位和召回。

## 六、简单判断标准
如果供应商只能提供：
- 品牌授权书
- 发票
- 泛泛的产地说明

但不能提供：
- 本批次报关单
- 入境货物检验检疫证明
- 原产地证
- 包装厂/批次信息

那么这批货的溯源是不完整的，超市应谨慎采购，至少不能作为“可追溯进口苹果”销售。

## 七、最稳妥的做法
1. 采购合同里写明：供应商必须随货提供本批次报关单、检疫证、原产地证、批次追溯单。
2. 到货时做“单货核对”，不一致就拒收或暂扣。
3. 对都乐、鑫荣懋分别确认其供货主体是直接进口还是分销。
4. 建立批次台账，保留文件至少到保质期后一定期限。
5. 高风险品类可要求供应商提供果园/包装厂注册号，并向海关公开信息核验。
