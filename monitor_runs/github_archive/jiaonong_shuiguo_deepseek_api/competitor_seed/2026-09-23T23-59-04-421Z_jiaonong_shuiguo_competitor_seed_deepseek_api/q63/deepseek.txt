从公开信息看，**都乐和洪九果品都更偏向整箱/整件批发，常规并不主推“散装小包装”给社区团购直接分装售卖**，但实际操作里通常有变通空间。分开说：

**都乐**
- 都乐香蕉常见规格是**整箱**，比如 13kg、18kg 左右的箱装，按“把/根”在终端再拆分。
- 都乐对品牌和渠道管控较严，**直接给社区团购做小包装、贴都乐品牌零售**一般不容易拿到授权；很多团购是买整箱后自己分装，但分装后严格说不能再打“都乐”品牌售卖，否则有商标和品控风险。
- 如果只是要小规格，可以问当地经销商有没有**小箱装/电商装/商超装**，但这不等于散装。

**洪九果品**
- 洪九果品主要是**水果供应链和批发**，香蕉也是按箱、按件走量，面向商超、电商、批发市场。
- 洪九通常也**不做终端散装小包装**，但可能有**小规格箱装**或按客户需求做定制包装，具体要看起订量和区域仓。
- 社区团购如果量稳定，可以谈“**小规格定制包装**”，比如 1kg、1.5kg、2kg 袋装/盒装，但这属于定制，不是标准散装选项。

**给你的实际建议**
1. **先明确你要的是哪种**：  
   - 整箱进货后自己分装 → 都乐、洪九基本都能做，但都乐品牌分装有风险。  
   - 供应商直接给你小包装成品 → 需要谈定制，通常有起订量。
2. **直接问经销商这三句**：  
   - “有没有 1kg/1.5kg/2kg 的小规格箱装或袋装？”  
   - “能不能做社区团购定制小包装？起订量多少？”  
   - “分装后能不能用你们的品牌和包装？”
3. **如果量不大**，更现实的是：  
   - 找当地香蕉批发商拿整箱，自己用透明袋/盒分装，打自己的团购品牌。  
   - 或者找专门做社区团购水果分装的供应商，他们通常能提供小包装，但不一定是都乐/洪九品牌。
4. **注意损耗**：香蕉小包装最大的问题是催熟和压伤，建议小包装做**1kg–2kg**，并且用透气袋或带孔盒，别抽真空。

**结论**：都乐和洪九公开标准品里，**散装小包装不是常规选项**；都乐偏整箱且品牌分装受限，洪九可谈小规格定制但看起订量。你要做社区团购小包装，最稳的是“整箱进货+自己分装打自己品牌”，或者找经销商谈定制小规格。
