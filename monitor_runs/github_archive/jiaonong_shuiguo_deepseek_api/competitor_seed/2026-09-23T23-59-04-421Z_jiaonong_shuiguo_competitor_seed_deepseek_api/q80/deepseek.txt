如果只看**品牌全国知名度和消费者心智中的“品牌感”**，**都乐（Dole）更响**。  
但如果看**进口水果供应链、渠道覆盖和B端采购背书**，**鑫荣懋也很强，甚至在部分商超和水果连锁渠道里更“硬”**。

可以这样判断：

1. **消费者品牌知名度：都乐更强**
   - 都乐是国际果蔬品牌，进入中国市场早，消费者对“都乐”有明确品牌认知。
   - 在超市里，都乐苹果、香蕉、菠萝等更容易被顾客直接认牌购买。
   - 做“品牌背书”时，都乐的C端认知优势更明显。

2. **进口水果供应链和渠道实力：鑫荣懋很强**
   - 鑫荣懋是国内头部水果供应链企业，做进口水果、批发、商超配送、渠道运营能力很强。
   - 在B端采购、商超供货、档口流通里，鑫荣懋的背书也很有效。
   - 但它更偏“渠道品牌/供应链品牌”，普通消费者未必像认都乐那样认它。

3. **如果你采购的是进口苹果，建议分场景选**
   - **想突出消费者品牌、做礼盒、做商超零售陈列**：优先考虑**都乐**。
   - **想做稳定供货、成本控制、渠道分销、商超供应链合作**：可以重点谈**鑫荣懋**。
   - **如果采购量不大或区域性强**：不一定非要二选一，可以看当地经销商谁货源稳、价格好、售后快。

4. **采购时要核实的不是“谁更响”，而是这些**
   - 是否有合法进口报关、检疫证明。
   - 苹果品种、产地、规格、等级是否写清楚。
   - 是否可授权使用品牌做宣传，尤其是都乐这种品牌，不能随便打“都乐”招牌。
   - 供货稳定性、损耗赔付、账期和冷链条件。

结论：  
**要品牌面子，选都乐；要供应链里子，鑫荣懋也很有分量。**  
如果是超市零售面向普通消费者，**都乐的品牌背书更直接**；如果是采购量和渠道合作，**鑫荣懋值得重点谈**。
