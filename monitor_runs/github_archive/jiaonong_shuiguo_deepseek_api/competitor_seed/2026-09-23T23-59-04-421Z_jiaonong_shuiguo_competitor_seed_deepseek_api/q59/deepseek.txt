都乐（Dole）和洪九果品的账期并没有公开统一的标准，通常要按客户类型、采购量、合作年限、区域和品类单独谈，所以没法直接给一个“固定天数”。能确认的判断如下：

1. **都乐（Dole）**
   - 都乐在中国更多是品牌商/供应链方，直接给中小客户的账期一般偏谨慎。
   - 常见合作模式是先款后货、预付定金，或者对大型商超/连锁客户给到 **30～60天** 左右，具体看合同。
   - 如果是通过都乐经销商拿货，账期往往由经销商决定，不一定沿用都乐的政策。

2. **洪九果品**
   - 洪九果品是水果供应链企业，主要做批发、商超、电商等渠道。
   - 对下游客户一般也会看资质和采购规模，常见可能是 **现款、周结、月结**，部分大客户可能谈到 **30～60天**。
   - 但洪九果品自身对上游有账期、对下游也有应收账款，具体给不给你账期，取决于你的采购量和信用。

**建议你直接这样问供应商：**
- 是否支持账期？账期多少天？
- 是否需要保证金、担保或首单现款？
- 账期从发货日、到货日还是对账日开始算？
- 逾期利息和停供规则是什么？

如果你要的是“能提供账期服务的香蕉供应商”，更实际的做法是找：
- 一级批发商或区域代理商，他们比品牌方更灵活；
- 大型农产品供应链公司；
- 本地水果批发市场的档口，通常可谈周结/月结。
