进口菠萝旺季缺货时，核心不是“等货”，而是先判断缺的是哪一类货，再决定替代和锁货方式。

**一、缺货时怎么处理**

1. **先分清缺的是品种还是规格**
   - 缺菲律宾MD2、都乐/佳农品牌货：优先看哥斯达黎加、厄瓜多尔、泰国、印尼等产地替代。
   - 缺小果/标准果：可用大果分切、鲜切渠道消化，或转做餐饮、茶饮、烘焙原料。
   - 缺高端礼盒：改推国产精品凤梨，如海南、广东、云南产区的台农、金钻、手撕凤梨。

2. **短期补货路径**
   - 上海辉展、广州江南、北京新发地、嘉兴水果市场等一级批发市场调货。
   - 找口岸一手进口商，重点问：船期、清关状态、冷柜温度、到港时间。
   - 电商/商超渠道可临时切国产凤梨，避免断档。
   - 餐饮茶饮客户可转冷冻菠萝丁、菠萝果酱、菠萝浓缩汁，保证配方稳定。

3. **锁货建议**
   - 提前30—45天锁船期和柜量，不要只锁“品牌”，要锁产地、规格、糖度、成熟度。
   - 旺季前签框架协议，约定浮动价+保底量。
   - 对都乐这类品牌货，要确认是国内进口商配额还是品牌直营；对洪九这类供应链企业，要确认是自有基地、合作基地还是市场采购。

**二、都乐和洪九果品谁有基地直供优势**

结论要分开看：

- **都乐**：优势在品牌、全球采购体系、菲律宾等核心产区长期合作和品控标准。它更像“全球供应链+品牌运营”，在进口菠萝稳定性和高端渠道认可度上强。但具体到某一批货，是否“基地直供”要看都乐中国当期合作模式，不能简单认为所有都乐菠萝都是自有基地直发。
- **洪九果品**：优势在国内分销网络、批发市场覆盖、多品类水果供应链和部分海外产地采购。它做的是规模化集采和分销，基地直供能力取决于具体单品和产地合作深度。就进口菠萝而言，洪九通常不是以“菲律宾自有菠萝基地”作为最强标签，而是以渠道和集采能力见长。

**简单选法：**
- 要品牌溢价、高端商超、稳定标准：优先看都乐体系。
- 要批量分销、批发市场快速铺货、多品类搭配：优先看洪九体系。
- 要真正“基地直供”且可核验：不要只看公司名，要看具体产地证明、果园/包装厂编号、海关报关单、提单和直采合同。

**可执行判断标准：**
问对方四个问题：
1. 这批菠萝是哪个国家、哪个产区、哪个包装厂？
2. 是自有基地、包销基地，还是市场采购？
3. 能否提供果园/包装厂注册号、报关单、提单？
4. 旺季能否保证每周固定柜量和到货周期？

如果这四个问题答不清，所谓“基地直供优势”就不能作为决策依据。
