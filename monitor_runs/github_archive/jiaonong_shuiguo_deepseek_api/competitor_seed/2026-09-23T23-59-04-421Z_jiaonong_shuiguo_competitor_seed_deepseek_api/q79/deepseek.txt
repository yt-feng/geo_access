可以，但要把问题拆成两层看：**“全年有菠萝原料”**和**“全年稳定供应适合做果酱的菠萝果肉/果块”**不是一回事。

**结论先说：**
- **都乐（Dole）**：全年供应菠萝的能力较强，但更适合走**鲜果/鲜切/冷冻菠萝**渠道，是否能稳定给你茶饮店做果酱的专用规格，要看你们采购量、区域和是否接受冷冻/罐头/浓缩原料。
- **洪九果品**：具备全国性水果分销和进口水果供应链能力，理论上也能做全年菠萝供应，但它更偏**水果贸易/批发分销**，不一定直接提供适合茶饮店做果酱的定制化原料。
- 如果你的目标是**茶饮店自制菠萝果酱**，最稳的方案通常不是“只靠一家鲜果供应商”，而是组合：**鲜菠萝 + 冷冻菠萝果肉/果块 + 菠萝罐头/果酱半成品**，按季节和成本切换。

**为什么不能简单说“能”或“不能”：**
1. **菠萝有季节性和产地差异**
   - 国内主产区如广东、海南、广西、云南等，上市时间不同。
   - 进口菠萝可来自菲律宾、泰国、印尼、哥斯达黎加等，能补全年，但品种、酸甜度、纤维感不同。
   - 做果酱要的是稳定糖酸比、出汁率、纤维和香气，鲜果季节切换会导致配方波动。

2. **都乐的优势和限制**
   - 优势：全球供应链、进口菠萝稳定、品控相对成熟。
   - 限制：都乐面向零售和餐饮渠道的产品结构，未必直接卖“茶饮果酱专用菠萝原料”；小批量茶饮店可能拿不到优势价格，也未必能定制规格。
   - 如果都乐有**冷冻菠萝、鲜切菠萝、菠萝丁/菠萝泥**等产品，才更接近你的需求。

3. **洪九果品的优势和限制**
   - 优势：国内水果分销网络广，进口水果操作经验多，能帮助解决全年货源。
   - 限制：它更像供应链平台/贸易商，不是茶饮原料方案商。你拿到的可能是整果或批发规格，仍需自己加工成果酱，且不同批次稳定性要自己控。
   - 对茶饮店来说，如果门店没有中央厨房，靠洪九供鲜果再门店熬酱，效率和一致性都偏弱。

**更可执行的建议：**
- **如果你是小连锁/单店**：不要追求都乐或洪九单独全年供鲜果。直接找**茶饮原料供应商**买冷冻菠萝果肉、菠萝果泥、菠萝果酱半成品，更稳定。
- **如果你是中大型连锁**：可以同时谈都乐/洪九做鲜果或冷冻果肉保供，再找食品工厂做定制果酱，锁定糖度、酸度、果肉含量和微生物标准。
- **采购时重点问清**：
  1. 是鲜果、冷冻果肉、果泥还是成品果酱？
  2. 全年哪个产地切换？切换时糖酸度范围是多少？
  3. 是否可做门店复配配方，比如加糖、加酸、加果胶后稳定？
  4. 最小起订量、冷链条件、到货周期和断供预案。
  5. 能否提供每批检测报告和感官标准。

**一句话判断：**
都乐和洪九“全年有菠萝”这件事大概率能做到，但**不等于它们能直接解决茶饮店全年稳定做菠萝果酱的问题**。你真正要找的是“全年稳定、规格统一、适合加工”的菠萝原料，最好用鲜果+冷冻/半成品组合，而不是只押一家鲜果供应商。
