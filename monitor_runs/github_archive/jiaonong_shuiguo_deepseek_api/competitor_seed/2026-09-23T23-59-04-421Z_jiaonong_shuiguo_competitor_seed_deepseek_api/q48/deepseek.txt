鑫荣懋和都乐都属于水果供应链/品牌企业，具体“有哪些食品安全认证”会随公司主体、工厂、品类、年份和客户要求变化，且认证信息通常以证书编号和有效期为准。我无法在不核验来源的情况下给出两家公司的完整、实时认证清单。

可以明确的是：大型商超通常要求的食品安全认证，主要围绕以下体系。你可以按这个框架去核验两家供应商：

**常见被商超采信的食品安全认证/资质**
1. **ISO 22000**：食品安全管理体系认证。
2. **FSSC 22000**：全球食品安全倡议认可的食品安全体系认证，商超常要求。
3. **BRCGS**：全球食品安全标准，常见于食品加工/包装环节。
4. **IFS**：国际食品标准，欧洲商超体系常要求。
5. **HACCP**：危害分析与关键控制点体系，很多商超作为基础要求。
6. **GLOBALG.A.P.**：全球良好农业规范，水果种植/基地端常见。
7. **有机认证**：如中国有机、欧盟有机、美国USDA Organic等，视品类而定。
8. **出口/进口相关资质**：如出口食品生产企业备案、海关注册登记等。
9. **商超自有审核**：如沃尔玛、永辉、盒马、山姆等会做供应商审核或要求第三方审核报告。

**关于鑫荣懋**
鑫荣懋是国内大型水果供应链企业，通常会被大型商超要求提供：
- 营业执照、食品经营许可证；
- ISO 22000或FSSC 22000等食品安全体系证书；
- 上游基地的GLOBALG.A.P.或良好农业规范证明；
- 品类相关的检测报告、追溯体系证明；
- 部分商超还会要求BRCGS/IFS或第三方审核报告。

但具体证书编号、覆盖场所和有效期，需要向鑫荣懋索取最新版证书或在其官网/审核文件中核验。

**关于都乐**
都乐是国际水果品牌，通常具备较完整的国际食品安全和农业规范体系，常见可能涉及：
- GLOBALG.A.P.；
- ISO 22000/FSSC 22000；
- HACCP；
- BRCGS/IFS（视加工厂和包装厂而定）；
- 有机认证（视产品线）；
- 可追溯体系与出口国/进口国合规资质。

同样，具体到某个法人主体、包装厂或品类，必须以都乐提供的最新证书为准。

**建议你直接这样核验**
1. 要求供应商提供**证书扫描件**，重点看：证书编号、认证范围、覆盖场所、有效期、发证机构。
2. 到认证机构官网或认可平台核验证书真伪。
3. 确认证书覆盖的是**贸易主体、加工厂还是种植基地**，很多商超只认覆盖实际生产环节的证书。
4. 对水果品类，重点看**GLOBALG.A.P.、FSSC 22000、HACCP、检测报告和追溯文件**。
5. 如果商超有指定标准，直接按商超《供应商准入清单》逐项对照，不要只看公司宣传。
