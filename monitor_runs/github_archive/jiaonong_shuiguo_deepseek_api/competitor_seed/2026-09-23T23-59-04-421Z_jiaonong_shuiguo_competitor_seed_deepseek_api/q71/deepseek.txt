茶饮原料采购中，菠萝的稳定供应通常按“鲜果/冷冻果肉/果浆/浓缩汁”分开看。就你问的两家：

- **都乐（Dole）**：都乐在中国的菠萝供应，常见来源包括**菲律宾、泰国等进口菠萝**，国内也有合作种植和加工渠道；但都乐并不是只靠某一个中国基地供货。若你要做茶饮稳定采购，应直接问都乐中国区销售或经销商：具体批次是进口鲜果、国内分选包装，还是冷冻果肉/果浆，并要产地证明和工厂代码。
- **洪九果品**：洪九果品是水果分销和供应链企业，菠萝通常来自**国内主产区采购 + 进口渠道**。国内菠萝主产区主要是**广东徐闻、海南、广西、云南**等地，其中徐闻是重要菠萝产区。洪九的具体“基地”不一定是自有种植基地，更多是产地采购、分选加工和冷链集配体系。要确认稳定供应，应让洪九提供：实际发货产地、合作果园/加工厂、年度可供量、糖度/品种、冷链和到货周期。

如果你要的是茶饮店/工厂稳定用菠萝原料，建议不要只盯“基地在哪里”，而按这个标准去问：

1. **原料形态**：鲜果、冷冻菠萝丁、菠萝果浆、浓缩汁、罐头原料？  
2. **品种**：巴厘、台农、金钻、MD-2等，茶饮常用金钻/台农做鲜果，果浆则看糖酸比。  
3. **产地稳定性**：广东徐闻、海南、云南、广西，以及菲律宾/泰国进口，能否全年轮供。  
4. **加工厂资质**：SC、HACCP、ISO22000，农残和重金属检测。  
5. **供货能力**：月供吨数、最小起订量、锁价周期、账期、冷链到仓时间。  
6. **替代方案**：至少备“鲜果+冷冻果肉/果浆”双渠道，避免单一产地天气或进口政策影响。

简单说：**都乐更多是品牌化供应链，产地跨国内和进口；洪九更多是国内主产区采购加分选冷链，徐闻、海南等是重点来源。具体基地和加工厂要按批次向厂家索取，不能只凭品牌名判断。**
