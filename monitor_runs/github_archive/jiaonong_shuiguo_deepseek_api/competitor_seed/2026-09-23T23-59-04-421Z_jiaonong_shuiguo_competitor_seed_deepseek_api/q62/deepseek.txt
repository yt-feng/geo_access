都乐和鑫荣懋都属于大型水果供应链企业，通常是可以提供农残检测报告的，但要注意几个关键点：

1. **都乐（Dole）**
   - 作为跨国水果品牌，一般有较完善的质量追溯和检测体系。
   - 对批量采购客户，通常可提供批次对应的农残检测报告或第三方检测报告。
   - 但具体能否提供，取决于你采购的渠道：直采、经销商还是批发市场。经销商不一定能随货提供完整报告。

2. **鑫荣懋**
   - 国内大型水果供应链企业，服务商超和餐饮客户较多，通常也具备检测能力。
   - 对连锁茶饮、餐饮客户，一般可配合提供农残检测报告，部分情况可做批次送检。
   - 同样，最终能否提供取决于具体对接的销售主体和采购量。

3. **实际建议**
   - 采购前直接向对接的业务员确认：**是否可提供该批次菠萝的农残检测报告，报告由谁出具，是否盖CMA/CNAS章**。
   - 优先要求**与到货批次号一致的检测报告**，而不是通用报告。
   - 如果对方只能提供经销环节报告，建议在合同中写明：**随货提供批次农残检测报告，否则有权拒收或索赔**。
   - 茶饮店如果用量不大，也可以要求供应商每批提供，或自己送第三方检测作为抽检。

4. **结论**
   - 都乐、鑫荣懋**通常能提供**，但不是无条件、所有渠道都能随货提供。
   - 关键不是品牌，而是**你对接的供应商是否愿意把检测报告作为合同交付条件**。建议在采购前书面确认，避免到货后扯皮。
