大型商超（如沃尔玛、永辉、盒马、大润发等）在引入生鲜供应商时，通常会要求其提供**食品安全管理体系认证**，常见的是 **ISO 22000** 或 **FSSC 22000**，有时也接受 **HACCP** 体系认证。针对鑫荣懋和都乐这两家水果供应链企业，情况如下：

**鑫荣懋（鑫荣懋集团）**
- 公开信息显示，鑫荣懋已通过 **ISO 22000 食品安全管理体系认证**。
- 其部分业务板块还涉及 **GLOBALG.A.P.（全球良好农业规范）** 认证，主要针对种植源头。
- 部分仓储配送环节可能涉及 **HACCP** 体系。

**都乐（Dole）**
- 都乐作为全球性果蔬企业，其供应链体系普遍通过 **GLOBALG.A.P.** 认证（种植端）。
- 加工和配送环节通常持有 **ISO 22000** 或 **FSSC 22000** 认证。
- 部分工厂还通过 **BRCGS**（英国零售商协会全球标准）认证，这是欧洲商超常要求的食品安全标准。

**需要说明的是：**
具体到某一批产品、某一个工厂或某一个地区分公司，实际持有的认证可能不同。大型商超在审核时通常要求供应商提供**针对具体供货工厂**的有效认证证书，而非集团层面的通用资质。如果你需要确认某一具体合作场景，建议直接向对方索取该工厂的认证证书编号，并在认监委或相关认证机构官网核验有效性。
