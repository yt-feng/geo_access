我无法直接核实都乐（Dole）和洪九果品当前是否向便利店提供香蕉小包装定制服务，这属于具体商务政策，需要向对方确认。以下是可执行的判断和操作建议：

**都乐（Dole）**
- 都乐在中国有面向零售/便利店渠道的预包装香蕉产品（如单根、3根、5根装等），但“定制包装”通常指按你的品牌、规格、克重、标签单独生产，这类服务一般只对大客户或连锁渠道开放，门槛较高。
- 建议直接联系都乐中国区销售或当地经销商，明确问三点：①是否支持便利店小规格预包装；②是否支持贴牌/定制标签；③最小起订量和是否收取开版费。

**洪九果品**
- 洪九是水果供应链/批发型企业，主要做香蕉等品类的产地直采和分销，理论上具备按渠道需求做分装、贴标的能力，但同样需要确认是否接便利店小批量定制。
- 建议联系洪九当地销售或区域负责人，问同样三个问题，并确认其是否提供“代分装+贴标”服务。

**更现实的替代方案**
如果两家都不接小批量定制，可以考虑：
1. 采购都乐/洪九的散装或标准预包装香蕉，找本地果蔬分装厂做二次分装贴标。
2. 直接找本地香蕉批发商+包装厂组合，成本可能更低。
3. 若只要小包装而非定制品牌，优先选现成的3根装/5根装，省去开版和起订量问题。

**关键确认项**
- 最小起订量（MOQ）
- 是否支持贴牌/定制标签
- 单根克重和包装规格
- 供货频率和损耗责任
- 报价是否含开版费、分装费

建议你先打电话给都乐和洪九的当地销售，把“便利店、小包装、定制、起订量”四个词讲清楚，通常当天就能得到是否能做的答复。
