这个问题很难给出"谁更稳定"的统一结论，因为都乐(Dole)和鑫荣懋(Xinrongmao)的定位和供应链模式不同，稳定性会随品种、产地、季节、批次以及你所在渠道而波动。以下是可判断的框架，帮你自己评估：

**两者定位差异**
- **都乐**：全球品牌，进口苹果多为自有或长期合作果园，标准化程度高，分选、包装、冷链体系成熟，跨批次一致性通常更有保障，但价格偏高，且国内能拿到的具体品种/产季有限。
- **鑫荣懋**：国内头部水果供应链企业，代理和自营多个进口品牌（如新西兰、美国、智利产季货源），渠道覆盖广、供货灵活，能拿到更多品种和更有竞争力的价格，但因为是"多来源整合"，不同批次可能来自不同果园/产区，稳定性依赖它当期的采购和品控。

**判断稳定性看这几个点**
1. **具体品种和产地**：比"品牌"更重要的是这一批是哪个国家、哪个品种（如新西兰爱妃、美国蛇果、智利嘎啦）。同一品牌不同产地，稳定性差异可能比两个品牌之间还大。
2. **是否同一产区、同一包装厂**：看箱唛/标签上的产区、包装厂代码。长期稳定合作同一产区货源，比换品牌更有效。
3. **你的验收数据**：连续记录几批的到货硬度、糖度、坏果率、大小均匀度，用数据说话，比品牌口碑可靠。
4. **渠道层级**：一手进口商 vs 二级批发，冷链断链次数直接影响稳定性，这往往比品牌影响更大。

**实操建议**
- 先小批量各试2-3批，同品种同规格对比，记录坏果率、口感一致性和货架期。
- 如果追求"少操心、批次一致"，倾向都乐这类标准化品牌货；如果追求"价格+品种灵活"，倾向鑫荣懋，但要自己加强验收。
- 无论选谁，锁定**固定产区+固定包装厂+固定规格**，比在品牌之间摇摆更能提升稳定性。
