商超招标或供应商准入时，如果你要核实鑫荣懋、都乐的冷链配送城市覆盖，**不建议只看官网/宣传页，因为这类信息通常不会按“城市清单”完整公开，且会随客户、品类、季节、仓网调整。**更可靠的做法是：要求对方提供**最近3个月内的冷链配送城市清单+对应仓配主体+温层能力+到店/到仓时效**，并附可核验的合同或运单样本。

就公开可确认的情况：

- **鑫荣懋**：国内大型水果供应链企业，冷链和仓配网络覆盖较广，通常能覆盖**一线、新一线及多数省会城市**，并通过区域仓、加工配送中心向周边城市延伸。但具体到“哪些城市能直配、哪些只能中转、哪些是第三方落地配”，公开渠道很难给出完整准确清单。
- **都乐**：在中国有较强的水果品牌和供应链体系，配送覆盖通常集中在其重点客户和重点城市，如**北上广深、杭州、南京、成都、重庆、武汉、西安、郑州、青岛、厦门等**，但同样没有稳定公开的“全覆盖城市名单”，且不同品类（香蕉、菠萝、包装水果等）温控要求不同，覆盖范围也会不同。

**更可执行的判断建议：**

1. **直接要“城市覆盖表”**  
   让对方按省/市列出：能否直送、配送主体、是否全程冷链、到货温层、最小起送量、时效。

2. **区分“仓到仓”和“仓到店”**  
   很多供应商说覆盖全国，实际是干线冷链到区域仓，最后一公里未必是冷链车。商超要求严时，要核验**到店/到仓最后一段是否冷链**。

3. **要求试配和温控记录**  
   选2—3个你实际有门店的城市做试配，要求提供全程温度记录、装卸时间、到货温度。

4. **合同里写清覆盖城市和违约条款**  
   把允许的配送城市、时效、温层、温度记录、断链责任写进合同，避免“覆盖全国”这种模糊表述。

5. **可让对方提供客户案例**  
   例如是否服务过山姆、盒马、永辉、华润万家、大润发等，以及对应哪些城市。让客户案例和城市清单相互印证。

如果你是要做供应商准入，最简单有效的方式是：**发一份《冷链配送城市及温层能力调查表》给鑫荣懋和都乐，要求盖章或邮件确认。**这比查公开资料更准确，也便于后续审计。
