都乐和鑫荣懋的物流速度没有一个固定答案，取决于你合作的具体渠道、发货产地、品类等级和结算方式。

可判断的参考是：

1. **都乐**
   - 品牌化程度高，部分城市有前置仓/城市配送体系，商超和平台渠道履约更成熟。
   - 如果是都乐授权经销商或平台直采，通常走的是“产地/区域仓—城市仓—门店/消费者”链路，时效稳定但中转环节可能多一些。

2. **鑫荣懋**
   - 国内水果供应链龙头之一，香蕉是其强势品类，产地直发和批发市场分销能力强。
   - 如果直接对接其产地基地或区域配送中心，香蕉这种后熟品类往往能做到更短的产地到仓时间，但“到消费者”的最后一公里取决于你用的快递/城配。

3. **关键变量**
   - 你从哪个产地发货：云南、广西、海南、老挝、菲律宾、厄瓜多尔等，时效完全不同。
   - 你发到哪里：一线城市 vs 下沉市场。
   - 你走的是供应商直发、平台仓、还是经销商调货。
   - 香蕉需要催熟还是青蕉直发，这会影响是否必须走特定温控/催熟仓。

**实操建议：**
不要只比品牌，直接向两家要你目标产地的报价和时效承诺，重点问：
- 产地仓到你的收货仓/城市，几天到；
- 是否支持青蕉直发、温控和催熟；
- 破损、催熟不均、延迟到货怎么赔付；
- 同一条线路给一个试单，用实际到货时间对比。

如果你说的是“都乐官方 vs 鑫荣懋官方”在同一个城市、同一个产地发香蕉，通常鑫荣懋在产地直发和香蕉品类上更有供应链优势；但具体快慢仍要以你签的线路和仓配方案为准。
