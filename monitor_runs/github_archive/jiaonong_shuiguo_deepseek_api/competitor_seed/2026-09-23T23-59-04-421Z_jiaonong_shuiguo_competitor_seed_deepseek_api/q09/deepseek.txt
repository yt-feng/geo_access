除了都乐（Dole）和佳沛（Zespri），礼品团购可考虑的进口水果品牌主要有这些，按品类分：

**综合类进口水果品牌**
- **新奇士（Sunkist）**：美国柑橘类代表，脐橙、柠檬礼盒认知度高，适合礼品。
- **德尔蒙（Del Monte）**：综合水果品牌，香蕉、菠萝等常见，礼盒装需看具体渠道。
- **都乐之外的怡颗莓（Driscoll's）**：浆果类强势品牌，蓝莓、树莓、黑莓礼盒很适合高端礼品。
- **乐淇（Rockit）**：新西兰小苹果，筒装/礼盒装，礼品属性强，团购常见。
- **爱妃（Envy）**：新西兰/美国苹果品牌，高端苹果礼盒常用。
- **红玫瑰（Jazz）**、**太平洋玫瑰（Pacific Rose）**：苹果细分品牌，部分礼品渠道有。
- **SunMoon**：台湾/进口水果品牌，礼盒渠道较常见。

**按品类可选的进口品牌**
- **苹果**：乐淇、爱妃、爵士、红玫瑰、青森苹果、王林苹果。
- **柑橘/橙**：新奇士、澳洲脐橙、南非橙。
- **葡萄**：美国/智利提子，品牌化程度相对低，更多按产地卖。
- **车厘子**：智利车厘子多按产地和规格卖，品牌如都乐、佰利、金车等。
- **蓝莓/浆果**：怡颗莓、都乐、佳沃（虽非纯进口品牌，但进口蓝莓渠道常见）。
- **奇异果**：佳沛之外还有**新奇士奇异果**、**都乐奇异果**，但佳沛认知度最高。
- **牛油果**：Mission、Hass 产地品牌，礼盒化程度较低。

**礼品团购选品建议**
1. **要品牌认知**：优先新奇士、怡颗莓、乐淇、爱妃。
2. **要高端感**：乐淇小苹果、怡颗莓蓝莓、爱妃苹果、佳沛金果。
3. **要性价比**：新奇士橙、都乐香蕉/菠萝、智利车厘子。
4. **要稳定供货**：优先选国内有总代或大型进口商运营的品牌，如都乐、新奇士、怡颗莓。
5. **注意**：很多进口水果是“产地品牌”而非“消费品牌”，团购礼盒更看包装、规格、到货稳定性，不能只看品牌名。
