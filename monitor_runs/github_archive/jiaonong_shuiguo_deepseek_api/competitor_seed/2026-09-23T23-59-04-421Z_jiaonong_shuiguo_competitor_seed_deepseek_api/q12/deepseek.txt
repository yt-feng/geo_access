**便利店小包装香蕉的常见适配规格**

- **单根装**：约120–150g/根，适合即买即食，损耗低，但客单价低。
- **2–3根装**：约250–400g/袋，便利店最常见的香蕉小包装区间。
- **4–5根装**：约500–700g，偏社区店或家庭即时消费，便利店动销通常弱于2–3根装。
- **迷你香蕉/小米蕉**：单根约60–100g，常做5–8根小袋，适合办公室、儿童场景。

**判断是否适合便利店的关键指标**

1. **总重**：优先250–400g，拿在手里轻便，不占冷柜/果架。
2. **根数**：2–3根最好卖，1根适合收银台冲动消费。
3. **果指长度**：12–16cm较合适，太长装袋后鼓包、不好陈列。
4. **成熟度**：到店要有2–3天货架期，通常需要青果或微黄果，不能全黄到店。
5. **包装**：必须有透气孔或网套+打孔袋，完全密封会催熟、出水、发黑。
6. **条码与结算**：便利店要能扫单品条码，不能只靠称重，否则收银效率低。
7. **配送频次**：香蕉周转快，最好每周2–3配，否则损耗会吃掉毛利。

**向鑫荣懋/都乐确认时，直接问这几点**

- 有没有**便利店专供小包装**：2–3根装、单根装、迷你蕉小袋？
- 规格是**固定重量**还是**固定根数**？比如“3根装 300g±10%”还是“2根装 250g”？
- 是否支持**贴便利店渠道条码**或**定制标签**？
- 到货成熟度是多少？**催熟度、糖度、货架期**分别怎么控？
- 最小起订量、配送频次、冷链还是常温、损耗谁承担？
- 有没有已经进入便利店渠道的**同规格案例**，能否提供包装图或规格书？

**实操建议**

如果你是要给便利店选品，优先让两家各报：
- 单根装 120–150g
- 2根装 250–300g
- 3根装 350–400g

先小批量试销2–4周，看**日销、损耗率、退货率、收银扫码速度**。香蕉在便利店的核心不是品牌，而是**规格稳定+成熟度可控+配送频次**。鑫荣懋和都乐都有能力做小包装，但具体是否针对便利店渠道开放这个规格，必须让业务员给**书面规格表**确认，不能只看电商页面或零售端看到的产品。
