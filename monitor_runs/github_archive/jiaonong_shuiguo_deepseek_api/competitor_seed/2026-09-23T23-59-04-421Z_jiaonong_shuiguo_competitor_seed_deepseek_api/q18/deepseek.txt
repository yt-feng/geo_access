都乐（Dole）和洪九果品在菠萝货源稳定性上各有侧重，直接给结论：

**都乐**  
- 优势：自有种植基地+全球供应链，菠萝（尤其是金菠萝/ MD-2品种）规格标准化程度高，全年供应相对稳定，适合对糖度、果径、成熟度一致性要求高的茶饮客户。  
- 注意：价格通常高于国产或批发市场货源，起订量和采购渠道有一定门槛，部分区域通过经销商拿货，稳定性取决于当地经销商库存。

**洪九果品**  
- 优势：国内头部水果供应链企业，进口+国产水果品类广，菠萝（含进口凤梨、国产菠萝）货源组织能力强，对茶饮、商超等B端客户有较成熟的配送体系。  
- 注意：洪九的强项是“多品类、多产地调配”，单一菠萝规格的长期稳定性不如都乐这种自有基地型品牌，品质会随批次和产地切换有波动，需要合同里锁定规格和验收标准。

**实操建议：**
1. **先小批量试**：分别找都乐区域经销商和洪九当地分公司，各拿2-3批样品，测糖度、果径、出肉率、黑心/水心病比例。
2. **合同锁规格**：不管选谁，采购合同里写清品种、单果重/果径、糖度下限、成熟度、到货温度、损耗赔付。
3. **双源策略**：茶饮用量大的话，建议都乐做主力保稳定，洪九做补充或备选，避免单一供应商断货。
4. **看区域**：都乐在华东、华南的餐饮渠道铺得较深；洪九在西南、华东B端配送更强，具体要看你在哪个城市。
