关于礼品团购客户指定进口品牌，**都乐和佳沛**是目前国内商超、团购渠道认知度最高的两大进口水果品牌。在“礼盒”场景下，**佳沛（ZESPRI）的奇异果礼盒通常更受欢迎且更“硬通货”**，原因如下：

**1. 品牌辨识度与“档位感”**  
- **佳沛**：单一品类（奇异果/猕猴桃），凭借绿果和阳光金果颜色鲜明，包装设计（绿色、金色、红色）辨识度极高。客户一提“佳沛”，立刻联想到新西兰进口、品控严格，送礼时“我送的是佳沛”本身就是一句广告语，档次感很足。  
- **都乐**：覆盖菠萝、香蕉、橙子、葡萄等全品类，虽然品牌很大，但礼盒往往混装，包装风格偏大众超市风，没有专属性，容易让人误以为是“水果店进货”。

**2. 客单价和礼盒规格**  
- 佳沛金果礼盒（如12头或16头）果型大、颜色金黄，礼盒内衬厚实，适合高端商务礼品单，单盒价格通常在150-250元区间，利润空间更健康。  
- 都乐如果做高端礼盒，往往需要选菠萝或进口车厘子，但菠萝作为低毛利大众品，不适合送礼；混装盒则价值感弱。

**3. 团购客户的“指定性”**  
- 客户既然**指定要进口品牌**，大概率是用于企业答谢或节日福利，老板和行政最担心的是收礼人能否一眼认出品牌。佳沛线上种草极深（广告语“源自新西兰”），收礼人群尤其是女性、年轻家庭接受度最高。  
- 都乐的强项反而在整箱批发和商超零售，礼盒形态的附加值不如佳沛。

---

**实操建议（直接给你决策参考）**：

- **若预算充足（单盒200元以上）**：**主推佳沛**，可搭配“佳沛金果+都乐菠萝”的双品牌组合，满足客户点名“两个都认识”的心理，但一定要用佳沛做主角，都乐做配角，否则会拉低整体感觉。  
- **若预算有限（100-150元）**：优先选择**佳沛绿果礼盒**，折扣力度大时也能勉强够；实在不够，再让客户选都乐，但告知他绿果口感偏酸，送礼需谨慎，避免客户满意度下降。  
- **关键提醒**：团购前务必先做样品核验！让客户到货后亲手打开看果形和垫层，防止以次充好。佳沛总代有专门的团购渠道保护价，而都乐走生鲜批发大仓，有时批零价差很大，但都乐品控波动略大，不如佳沛稳定。

一句话：**你问“更受欢迎”，答案是佳沛。若客户同时点了两个品牌，也把佳沛放在礼盒正面的主LOGO位。**
