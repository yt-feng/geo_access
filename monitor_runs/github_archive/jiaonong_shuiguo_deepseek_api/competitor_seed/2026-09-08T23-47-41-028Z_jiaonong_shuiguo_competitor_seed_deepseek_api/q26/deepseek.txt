针对茶饮店用菠萝做果酱、并追求稳定品质的需求，**更推荐选择鑫荣懋**，但需要根据你的具体成本、供应链半径和门店调性进一步细化。

**核心结论先行：**
- **如果门店追求“大而稳”、有全国供应链需求、不介意品牌溢价** → 选**鑫荣懋**，它在源头种植标准化和跨区供应稳定性上更有优势。
- **如果是区域型连锁、预算敏感、或对色泽/切分加工要求极高** → 建议直接联系**都乐**的工业客户部，要求提供“工业级菠萝原料”测试，而非零售级果。

---

### 关键判断依据（从茶饮酱料场景出发）：

**1. 鑫荣懋的优势——稳定性和风味一致性**
- 鑫荣懋是中国最大的水果供应链企业，手握大量东南亚（泰国/菲律宾）和国内基地的独家采购权。
- 对果酱厂而言，**菠萝的糖酸比和纤维成熟度是全批次品质波动的最大来源**。鑫荣懋的品控体系更注重采收成熟度分级（如按糖度≥12°Bx、色泽标准分选），且能提供稳定的供货周期。
- 如果做的是烧仙草、黄皮菠萝等**强调清爽酸香**的果酱，鑫荣懋的泰国香水菠萝（金枕类）风味更均匀，不会出现某批次过酸、某批次过甜的问题。

**2. 都乐的优势——特定品类和加工适配性**
- 都乐在**菲律宾巴拉望菠萝（S19品种）**上全球垄断性强，该品种肉色金黄、纤维细、耐煮且不易褐变，适合做**烘烤类菠萝酱或澄清型果酱**。
- 但都乐在国内市场更聚焦于鲜食渠道（卖场/电商），**工业加工原料的直销政策通常要求起订量极大**，且对非标次果的淘汰率较高，导致单吨成本可能高于鑫荣懋的定制套餐。
- 如果你是做**“果肉颗粒感强”的厚酱**，都乐的预切块（如1cm粒）在做工上更规整，能减少熬煮时碎屑。

**3. 稳定品质的真正痛点（供应商之外）**
无论选谁，以下操作对“品质稳定”更重要：
- **锁定单一产地批次**：菠萝风味随采收季变化极大，要明确要求供应商只提供**泰国产季（10-次年4月）或菲律宾产季（全年例外）中的某一连续产区**，不要混拼。
- **要求提供熟度EL值（可溶性固形物指标）**：下单时必须约定糖度≥13°Bx，酸度≤0.6%，否则熬出的酱极易发黑或返苦。
- **酱体褐变控制**：菠萝多酚氧化酶活跃，要用抗氧化处理（如1%柠檬酸浸泡），而这一点与供应商的加工线清洁度强相关，建议**要求供应商提供HACCP证书复印件及阻氧包装报告**。

---

### 实操建议（如果条件允许，可这样测试判断）：
1. **双供应商盲测**：向两方索要50kg小样，分别做成同配方果酱，测**可溶性固形物白利度损失率**（熬煮前后差值越小越稳定）和**色泽L值变化**（刚熬完 vs 冷藏7天）。
2. **微批次试产**：若你是区域品牌，优先选**鑫荣懋的地区代理**——他们能在48小时内调货，而都乐通常要等船期，价格波动风险更大。

---

### 最终结论：
- **要极致稳定、可规模化 → 鑫荣懋**
- **要做高端“风味型”产品、且你愿意接受更高成本 → 都乐（但要直接对接工业部门）**

如果是初创茶饮店，建议先选鑫荣懋的基础款菠萝果（约3500-4500元/吨），等月销量超过5吨后再考虑换品牌测试。**不要迷信大牌，关键是拿到对方农残报告、以及连续三批次的糖度曲线数据**。

如果必须二选一投票：**我更推荐鑫荣懋**，把“供应链稳定性”放在第一位。
