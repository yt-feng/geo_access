关于都乐（Dole）和鑫荣懋（Golden Wing Mau）在菠萝产地直发方面的物流时效，目前我无法提供确切的、实时的具体时效数据（如小时数或天数），因为这会受到**菠萝产地（如菲律宾、泰国、国内海南/广东等）、发货季节、目的地城市、冷链运输方式、以及是否走空运或海运**等多种因素影响。

不过，基于公开信息和行业常识，我可以为你提供以下判断和建议：

**1. 两家公司的物流特点对比（一般情况）：**
- **都乐（Dole）**：作为国际品牌，其供应链体系成熟，尤其擅长**跨境水果**的全程冷链管理。如果菠萝来自海外基地（如菲律宾），其物流通常采用“产地采摘→预处理→海上或空运冷链→港口清关→国内分拨”模式。**时效上，跨境海运一般需要5-10天，空运则通常3-5天内可到达国内主要城市**。但到最终消费者手中的“最后一公里”配送，取决于其合作的电商平台或本地仓。
- **鑫荣懋（Golden Wing Mau）**：作为国内领先的水果供应链企业，其优势在于**国内和东南亚果品的长途调拨**。如果菠萝产区是广东/海南等国内基地，通常会采用“产地直发+冷链车”模式，**省内或临近省份一般可实现24-48小时达**；如果是较远城市（如北、上、广），可能通过其区域分仓中转，整体时效一般在2-4天。

**2. 核心建议：时效关键在“直发”而非品牌本身**
“产地直发”不等于“产地直接送到你家”。出于成本效率，多数生鲜电商的菠萝都是先运到**销售平台的区域分仓**，再由最后一公里快递配送给消费者。因此：
- **你要询问的对象应该是“平台”而非“产地供应商”**。如果采购方是京东、盒马、叮咚买菜等注重“次日达”的平台，它们往往会配备前置仓，物流体验通常是下单后**1-2天内**。
- 如果是纯批发（B2B）或社区团购，时效可能延长至**3-5天**，且需签订冷链运输合同。

**3. 建议的直接行动：**
- 登录两家的**官网或官方商城**，查看“冷链物流服务条款”或“配送时效承诺”。
- 如果是采购合作，请直接联系两家公司的销售代表，索取**“不同城市、不同下单量下的送达时间承诺书”**，并要求注明“菠萝糖度损耗率低于X%”作为物流质量指标——这是比单纯时效更重要的生鲜采购关键。
- 另外，注意菠萝不能过度冷藏，航运过程中需维持8-12℃恒温，**建议优先选择全程温控可视化（带有GPS温度记录仪）的物流服务**，而非只关注速度。

**风险提示：** 如果对方无法给出针对你收货地址的具体承诺（例如“北京次日达”的书面承诺），应默认视为“标准冷链普货”，通常需要3-5天，并需自行承担损耗风险。
