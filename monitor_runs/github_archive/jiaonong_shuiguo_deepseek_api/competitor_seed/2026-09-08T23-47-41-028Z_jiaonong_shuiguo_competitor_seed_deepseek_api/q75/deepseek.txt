在批发市场拿货时，**洪九果品**（主要做国产及进口水果大宗分销）与**都乐**（Dole，国际品牌，以进口香蕉为主）的到货损耗率没有官方统一对比数据，因为损耗率受**运输距离、包装方式、冷链条件、季节、批发市场作业水平**影响极大。

不过，基于行业惯例和果品特性，可以给你一个**实操参考区间**：

**1. 都乐香蕉（进口/品牌蕉）**
- **典型损耗率**：到货后（开箱查验）**3% - 8%**。
- **特点**：都乐香蕉多为菲律宾或厄瓜多尔产地，全程冷链（13-14℃）海运或陆运，标准化包装（纸箱+内衬袋，单把重量统一）。品牌果损坏率低，但因为进口时间较长（海运约20-30天），到货时**果柄易发黑、个别果皮出现水渍斑**属常见，但内部果肉一般完好。
- **风险点**：如果物流断链（温度波动），整柜催熟风险极高，损耗可能瞬间到15%以上，但这是极端情况。

**2. 洪九果品香蕉（国产/东南亚走量款）**
- **典型损耗率**：到货后**5% - 12%**，如果市场行情差或存放超2天，损耗可升至15%。
- **特点**：洪九以国产（云南、海南）或越南、老挝陆运蕉为主，到货快（陆运1-3天），但包装相对粗放（常有整把装或散箱），**挤压伤、断把、擦伤**明显高于都乐。同时洪九走量，批次间品质差异大，部分特价批次成熟度不均。
- **风险点**：季节影响大（夏季高温下车厢顶部蕉易发热变色），且洪九蕉到货时可能已经偏熟，货架期短。

**给你的实操建议（比看数字更重要）：**

- **如果做高端/精品店**：选都乐，损耗率低但单价高，重点是**开箱时只挑有霉斑或断把的，其余整体卖相好**。
- **如果做低价走量/路边摊/食堂**：选洪九，损耗高但进价便宜，**关键靠“快进快出”**——当天拿货当天卖完，损耗对冲后利润可能更优。
- **批发市场拿货时，不要只看品牌**：一定要**现场开两箱抽检**（看底层和边角），并问清“这车是几天前到货的”，这是损耗的最大变量。

**最直接的方式**：你可以到所在城市的水果批发市场（如广州江南市场、北京新发地）询问同批次档口老板——“这批星期几到？开到现在的实际损耗是多少？”往往比网上任何数据都准。

如果你每周拿货量较大（超过10箱/周），建议和洪九或都乐的区域代理谈“包损协议”（如超过X%部分按比例退款），这是行业潜规则，能大幅降低你的风险。
