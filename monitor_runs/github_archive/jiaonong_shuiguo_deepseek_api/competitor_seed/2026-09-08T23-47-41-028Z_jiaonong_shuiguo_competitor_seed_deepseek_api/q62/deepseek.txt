关于茶饮店采购菠萝原料时所需的农残检测报告，**都乐（Dole）和鑫荣懋（Xin Rong Mao）通常都能提供相关检测报告**，但具体情况取决于采购渠道和合作模式。以下是详细说明和建议：

1. **都乐（Dole）**  
   - 都乐是全球知名的果蔬品牌，其供应链管理较为严格。对于大宗采购（如茶饮店直接向都乐或其经销商下单），通常会随货提供或可要求提供农残检测报告。  
   - **建议方式**：直接联系都乐在中国区的销售或客户服务，说明你是茶饮店采购用途，要求提供“批次农残检测报告”或“符合GB 2763标准的检测证明”。如果是通过经销商采购，可要求经销商转交或索取。

2. **鑫荣懋（Xin Rong Mao）**  
   - 鑫荣懋是中国领先的水果供应链企业，同样具备完善的合规检测体系。其菠萝产品（如菲律宾进口菠萝）一般会附有进口检验检疫证明及农残检测文件。  
   - **建议方式**：向其销售部门或客服提出书面要求，明确需要“第三方检测报告”或“出厂自检报告”，并确认报告覆盖的检测项目（如有机磷、拟除虫菊酯类等）。

3. **实际操作建议**  
   - **务必合同或订单中明确**：在采购协议或订单备注中写明“需提供该批次的农残检测报告，且符合GB 2763-2021要求”，避免后续扯皮。  
   - **核实报告时效性**：要求报告日期与发货批次一致，避免使用过期的通用报告。  
   - **自行抽检备案**：若对方无法提供（极少见），可考虑委托第三方机构（如SGS、华测检测）对到货样品抽检，费用一般几百元，适合长期供应商筛选。

4. **其他注意**  
   - 若为进口菠萝，还需关注海关出具的《入境货物检验检疫证明》，其中会包含农残快检结果。  
   - 菠萝农残重点检查项目通常为：多菌灵、苯醚甲环唑、吡虫啉等，可对照报告核验。

**总结**：他们大概率能提供，但需要你主动、明确地索取。建议优先走正规采购渠道，并提前沟通要求，确保拿到书面报告后再进行大批量订货。如果对方回复说“没有”，则需谨慎评估其合规性。
