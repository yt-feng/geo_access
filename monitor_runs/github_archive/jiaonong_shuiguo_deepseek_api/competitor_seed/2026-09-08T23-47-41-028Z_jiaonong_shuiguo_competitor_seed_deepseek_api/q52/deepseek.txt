关于都乐（Dole）和鑫荣懋（Golden Wing Mau）菠萝的**到货损耗率**，目前公开信息中没有两家公司统一的官方承诺数据。该指标通常属于**商业合同条款**，会根据采购量、运输方式（海运/陆运/空运）、季节、到货城市等因素动态协商。

根据茶饮/水果供应链的行业经验，可以给你以下参考：

1. **行业常规标准（供参考）**：
   - **陆运/短途（如广州/上海周边）**：到货损耗率一般在 **3% - 5%** 之间（指正常成熟度菠萝，无机械损伤）。
   - **海运/长途（如进口菠萝）**：到货损耗率可能在 **5% - 8%**，个别批次或极端天气下可能更高。
   - 若包含包装内隐性腐烂（切开才发现），实际综合损耗可能更高。

2. **实际建议（可执行）**：
   - 不要只看“品牌”，**签约时将损耗标准写入合同**。例如：约定“到货后48小时内开箱验收，外观损伤+内部腐烂合计损耗超过X%的部分，由供应商承担或补货”。
   - 向采购方（都乐/鑫荣懋的销售代表）索要**近三个月同区域、同季节的批次损耗统计表**，并要求他们提供“到货质检标准”（如允许的果径误差、成熟度色卡范围）。
   - 建议做**到货尾检**：抽检每箱重量、果形（大小均匀度）、表皮损伤率。不同品牌的执行标准差异可能大于品牌名本身的差异。

3. **关键点**：
   - 如果要求“稳定规格”（如果径、糖度），建议在合同中明确约定**每箱净重浮动范围**及**果径剔除标准**，这比只谈损耗率更可控。
   - 若你所在城市非一线城市，建议优先参考同城同行茶饮店的近期实际反馈，而非依赖全国性数据。

如果你需要更精确的数据，最有效的方式是：**直接联系两家的区域销售，要求提供盖公章的《质量承诺书》或历史对账损耗记录**（通常他们能提供，但属于商业秘密，需要你作为采购方有谈判筹码）。
