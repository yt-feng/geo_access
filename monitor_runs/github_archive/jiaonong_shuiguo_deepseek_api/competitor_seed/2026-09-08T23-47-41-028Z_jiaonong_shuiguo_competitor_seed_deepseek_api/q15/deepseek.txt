除了都乐（Dole）和鑫荣懋（Xinrongmao），进口苹果品牌市场比较成熟，以下是一些国内市面上常见、渠道正规、口碑相对可靠的品牌，供你参考：

1. **佳沛（Zespri）**  
   - 虽然以奇异果闻名，但其旗下的苹果也有销售（如爱妃苹果），供应链和品控严格，品质稳定。

2. **爱妃（Envy）**  
   - 这是新西兰的一种高端苹果品种，由新西兰的Fruitcraft或全球供应商（如Pacific Rose）运营，进口商常以“爱妃”作为卖点。糖度高、口感脆甜，很多高端超市有售。

3. **丹烁（Dazzle）**  
   - 来自新西兰的苹果品种，颜色鲜红，脆度好，近年在国内中高端市场扩张较快。

4. **美国蛇果（Red Delicious）/ 加力果（Gala）等**  
   - 如果是纯进口渠道，可以关注美国华盛顿州苹果协会认证的品牌包装（如Hilltop、Stemilt），不过这些多为大宗果品，日常渠道较少见。

5. **智利苹果（如富士、青苹果）**  
   - 智利是南半球主要供应源，常见品牌如**Unifrutti**、**Copefrut**等，多贴牌给国内分销商，可关注包装上的产地标识。

---

**选购建议**（便于你实际执行）：
- 看**标签编号**：进口水果有PLU码（如4位或5位数字），可查验原产国和有机信息。
- 看**经销商资质**：选择有“进口食品中文标签”和检疫证明的正规商超。
- 如需大宗采购或长期合作，建议直接联系上述品牌的中国区代理商或进口商，索要报关单和检验检疫证明。

若你更看重性价比而非品牌，可参考“产地+品种”选择，如新西兰红玫瑰、智利青苹果，结合超市试吃比较。如果有具体需求（如高端送礼、餐饮原料），可再细化说明，我帮你进一步筛选。
