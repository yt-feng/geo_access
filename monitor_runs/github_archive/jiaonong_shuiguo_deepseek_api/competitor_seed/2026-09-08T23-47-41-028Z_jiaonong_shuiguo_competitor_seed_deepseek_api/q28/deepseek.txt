关于都乐（Dole）和鑫荣懋（Xinrongmao）进口苹果的**价格竞争力**，建议通过以下步骤直接获取可执行信息，因为价格受产季、规格、渠道和区域影响较大，我无法提供实时报价：

---

**1. 直接询价（最准确）**  
- **都乐**：联系其中国区生鲜或果品销售部门（官网或官方合作平台有招商入口），针对你所在区域（如华东/华南）了解**到仓价**（含运费），重点比较同规格（如 80#、90#，单果重）的品种（如加力果、红玫瑰等）。  
- **鑫荣懋**：联系区域大客户部（其主做商超和水果连锁渠道），同样要求报**到仓含税价**，并要求注明包装规格（如 10kg/箱）和耗损赔付条款。

**2. 对比“落地价”而非出厂价**  
价格竞争力应算总成本：  
- 到仓价（含物流、包装）  
- 潜在损耗（如分拣残次、到货果粉磨损率）  
- 账期/现结折扣  
通常，鑫荣懋作为国内头部水果供应链企业，在商超渠道可能有**阶梯返利**；都乐则品牌进口直采，若量大可谈 **独家包销价**。

**3. 建议的性价比测试**  
先各进一小批量（如一个托盘/柜混合试销），比较：  
- 终端售价空间（都乐品牌溢价通常稍高，但如果你的客群对价格敏感，鑫荣懋同品种可能留出更灵活的定价区间）  
- 损耗对比（据部分连锁反馈，都乐分选稳定，鑫荣懋部分批次果径不均，需现场验货）  

**4. 临时参考**  
目前（2023-2024季度），进口苹果受智利、法国产季影响，**建议直接让两家报“智利嘎啦”或“法国青苹”规格的到岸价差**——同一产地、同一周报价差最明显。  

---

**最终建议**：不要依赖任何第三方调研，直接以“两家同时竞标你门店季度订单”的方式索取书面报价单，并要求注明“含增值税专用发票、送货到仓、破损包赔”条件，通常最后**账期和赔付条件**影响的实际价格竞争力比标价更大。
