关于菠萝产地溯源的问题，我帮你梳理一下**都乐（Dole）和洪九果品**的情况。

**1. 都乐（Dole）**
- **有基地直供，且是全球性的大公司**。都乐在菲律宾、泰国、哥斯达黎加等地拥有自有或合作的大型菠萝种植园，并实行“从农场到餐桌”的全链条管理。
- **溯源能力**：都乐有严格的品控体系，能提供批次溯源信息，例如产地、种植园编号、采收日期等。在中国市场，主要供应进口菠萝（如菲律宾菠萝），也有部分中国国产基地（如广东湛江、海南）的合作订单，但具体直供基地要看当地经销商。

**2. 洪九果品**
- **有基地直供，但模式以“基地+产地仓”为主**。洪九果品是中国头部水果供应链企业，其特点是整合多地优质产区资源（包括海南、广东、广西等地的菠萝产区），并与产地合作社或种植大户建立长期合作，属于**产地直采+产地仓发运**模式。
- **溯源能力**：洪九果品在产品包装上通常带有产地信息，但它的**核心优势是分销效率**，而非像都乐那样的国际级产地品牌追溯体系。如果你想做严格的产地地块级溯源，可能需要与洪九直接对接其合作基地或查看产品码。

---

**给你的实际建议（针对采购）：**

- **若要求高精度溯源（地块到批次）**：首选**都乐**的进口业务或指定国产合作基地，可要求对方提供“溯源码”或“SOC（供应商质量管理）报告”作为合同附件。
- **若重视本地供应、价格和批量**：可联系**洪九果品**的区域采购经理，要求实地考察其合作基地，并让其在采购合同中明确“产地村/镇+种植户编号”条款。
- **务必要求**：在合同中写入“若发现产地或批次不符，按进货价1:1退赔”的违约追责条款，不要只依赖口头承诺。
