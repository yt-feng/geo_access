针对菠萝的稳定供应，除了都乐（Dole），目前市场上确实有几家实力较强的品牌和渠道，能够做到全年或长期稳定供货。具体推荐如下（按可靠性排序）：

**1. 佳农（Goodfarmer）**
- **优势**：是目前国内菠萝进口量最大的品牌之一，主攻菲律宾菠萝（特别是“金菠萝”），与大型商超（如山姆、永辉）和线上生鲜平台（如叮咚买菜）有深度合作。
- **稳定性**：供应链成熟，季节性波动较小，基本全年有货，替代都乐的首选。

**2. 菲农（Seald Sweet 或 菲律宾本地品牌）**
- 注意：这个常用于指代菲律宾产的“MD2”品种。目前大量水果批发市场的“金菠萝”其实来自菲律宾当地合作农场。
- **稳定渠道**：如果你是通过批发市场，看箱体标识是否为“MD2”或“菲律宾农场直供”，这类往往不限单一品牌，走量最大，货源最稳定。

**3. 天猫/京东自营的“京东京鲜生”或“百果园”**
- 百果园有自己的菠萝供应链，部分拼团或自有品牌菠萝（如A级菠萝）供应稳定。
- 京东买菜/小象超市的自有品牌菠萝，产地切换灵活（冬春海南，夏秋菲律宾/巴拿马），能做到不断档。

**4. 产地直供（海南菠萝 - 非品牌化）**
- 如果是面向餐饮或批发：**海南万宁、文昌**的“巴厘菠萝”和“香水菠萝”在每年3-7月供应量极大。虽然是无品牌散货，但通过产地代办，能实现7天连续发货。

---

**给你的可执行建议（判断标准）：**
- **看果眼深浅**：稳定供应的商业菠萝（都乐、佳农）多为 **MD2品种**，特点是叶子不带刺、果眼浅。
- **比价与合同**：如果需求量较大（如餐饮/社区团购），建议直接与佳农区域代理商或百果园采销部联系，签订**月度供货协议**，锁定价格和发货周期。散货市场的稳定性不如品牌商，但价格会低10-20%。

**如果非都乐不可替代，目前最保险的选择是：佳农的菲律宾金菠萝（全年）、海南香水菠萝（季节性窗口）。** 不建议选择非主流的南美小品牌，其船期延误风险较高。
