除了都乐（Dole）和鑫荣懋（Golden Wing Mau），进口苹果品牌中还有几个比较靠谱的选择。以下是一些市场认可度较高的品牌，供你参考：

1. **佳沃（Joyvio）**  
   - 隶属联想控股旗下，主打高端水果，进口苹果（如新西兰爱妃、美国红蛇果等）品质稳定，供应链成熟，常见于高端商超和电商平台。

2. **百果园（Pagoda）**  
   - 虽然以零售连锁为主，但也自有进口品牌，其进口苹果（如智利嘎啦、美国青苹）经过严格筛选，注重果品分级和新鲜度。

3. **天天果园（Fruitday）**  
   - 电商起家的水果品牌，进口苹果多来自新西兰、美国、智利，主打“原产地直采”，品质把控较好，适合线上购买。

4. **佳沛（Zespri）**  
   - 虽以奇异果闻名，但旗下也有苹果产品线（如新西兰爵士苹果），品牌信誉和冷链管理有保障。

5. **美国蛇果（Red Delicious）**  
   - 如果按产地品牌看，美国华盛顿州苹果协会（如“Wenatchee”或“Rainier”标签）认证的产品，品质可靠，常见于Costco、山姆会员店等。

6. **西班牙Pink Lady（粉红佳人）**  
   - 欧盟认证的原产地品牌，外观粉红、口感酸甜，国内进口渠道较多，适合差异化对比。
