关于都乐（Dole）和鑫荣懋（Golden Wing Mau）在香蕉产地直发的物流速度，我无法提供实时、精确的对比数据，因为两家公司的配送时效会受到**具体产地（如菲律宾、厄瓜多尔、国内云南/海南等）、起运港口、目的城市、季节、清关和冷链配置**等多重因素影响，且两家都没有公开统一承诺的“产地到门”小时数。

为了帮你做判断，我给出**可执行的决策建议**：

1. **明确你的收货地**：如果是北上广深等一级港口城市，两家通常都能实现“产地摘采后5-7天到仓”（含海运或陆运）；如果是二三线城市，需要看他们是否在当地有分仓或合作冷链。

2. **直接索取物流承诺**：联系两家公司的**大客户部或供应链负责人**，要求对方提供：
   - 从指定产地（例如菲律宾达沃）到你的**具体收货仓库**的**全程冷链时效承诺**（例如“门到门不超过7天”）。
   - 他们的**断链风险点**（如转驳站、港口清关延误）及赔付条款。

3. **小批量试单实测**：这是最保险的方法。各订一小批（比如各1吨），同一时间从同一产地发货，记录从采摘、出港、到港、清关、内陆配送的每个节点时间。**用真实数据比较，而不是听销售说辞**。

4. **特例注意**：
   - 如果产地不同（例如都乐偏重南美/菲律宾，鑫荣懋有国内海南基地），物流差异很大。国内基地直发通常比进口快2-3天。
   - 旺季（春节前、夏季）港口拥堵概率高，时效会波动。

**结论**：在没有实测数据前，**无法判定哪家更快**。建议优先选**离你收货地更近的分仓/基地**，并尽快启动小批量试单验证。如果只比较品牌专业度，两家都是头部，物流体系成熟，但**速度取决于具体线路，而非品牌名气**。

如果你提供“发货产地+收货城市”，我可以帮你推测哪种运输方式（海运/陆运）更可能优先，但无法给出精确天数。
