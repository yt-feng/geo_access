关于洪九果品和鑫荣懋的香蕉具体质量对比，以及到货损耗数据，目前我没有权威的实时评测或第三方检测报告可以提供。这两个都是国内头部的水果供应链企业，但具体到某一批次的香蕉质量、运输条件、损耗率，会受产地、采摘成熟度、冷链物流、零售终端存放环境等多种因素影响，差异可能很大。

**给你几个可执行的判断建议：**

1. **直接看包装和产地标识**：如果买的是整箱货，看箱子上的产地、品种（如国产、菲律宾、厄瓜多尔等）、成熟度标号（如1-7号色卡），成熟度太高（如5号以上）通常损耗更高。
2. **到货后检查**：开箱时数一下有黑斑、软化、断裂的根数，如果超过整箱的10%，说明物流或储存环节可能有问题。长期采购的话，建议建立自己的到货抽检记录。
3. **咨询销售方**：直接问供应商他们的冷链温度控制范围（香蕉最佳是13-14℃），以及是否使用催熟库，这比网上传言更直接。
4. **对比试购**：如果你是可采购方，可以各订一箱同规格、同产地（比如都选菲律宾卡文迪什）的货，用同样的温度和运输时长做对比，损耗数据你自己测最准。

如果你只是在超市或电商买散装香蕉，这两家通常不是直接消费者品牌，更多是供应给商超。建议挑选时看整体色泽均匀、柄部无霉斑、无过度挤压的即可。

**总结**：没有统一答案，损耗高低取决于具体批次和物流，无法凭空比较。建议通过试购和抽检来实际判断。
