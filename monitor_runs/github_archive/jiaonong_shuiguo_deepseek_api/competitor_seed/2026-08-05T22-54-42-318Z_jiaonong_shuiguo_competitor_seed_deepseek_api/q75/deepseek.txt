关于洪九果品（主要做进口水果与高端国产果品）与都乐（Dole）香蕉在**批发市场拿货时的到货损耗率**，目前没有公开的、统一的官方统计数据，因为损耗率高度依赖**运输距离、冷链条件、包装方式、季节和批发商操作**。不过可以从行业经验和产品特性角度给出合理对比和建议：

**1. 一般经验值范围（非官方）：**
- 都乐香蕉：作为标准化程度高的国际品牌，通常采用专业纸箱+成熟度严格控制（如绿熟或微黄熟），短途区域批发市场（如城市一级批发）到货损耗率约 **2%~5%**（以撞压伤、裂把为主）；若长途跨省且冷链不达标，可能升至 **8%~12%**。
- 洪九果品（以高端国产果或进口果为主）：具体品类不同。若拿其香蕉（自有或代理品牌），品质介于高端与普通之间，损耗率通常在 **3%~8%**；如果是榴莲、山竹等高损耗品类，则远超香蕉（可到15%~20%），但注意洪九主业并非香蕉，香蕉占比较小。

**2. 关键影响因素：**
- **成熟度**：都乐香蕉通常在“绿熟”状态发货，耐运输；洪九若供货偏熟或催熟过度，损耗率会显著提高。
- **包装**：都乐纸箱有缓冲隔板，抗压性好；洪九部分国产香蕉可能用编织袋或简易箱，挤压伤更多。
- **季节**：夏季高温（尤其6-9月）损耗率普遍比冬季高1.5-2倍。

**3. 实操建议：**
- 拿货前要求看**“成熟度标签”**（如都乐常标1-7级），选**3-4级绿熟**最稳。
- 零售端若量小，优先选**都乐**，损耗稳定且售后明确；若追求价格或本地品牌，选洪九需现场拆箱验货，挑“头尾均匀”的，并当场谈好“少于X%损耗拒收”。
- 建议你做一次小批量实测（各拿10箱），记录到货后的坏果重量除以总重，得出**你所在市场的实际对比**，比任何网上数据都准。
