关于礼品团购客户指定进口品牌，**都乐（Dole）** 和**佳沛（Zespri）** 都是非常经典的选择，但它们的受众和受欢迎程度有明显差异。

**结论先行：如果客户追求“高端、健康、有辨识度”，首选佳沛（奇异果）；如果客户追求“大众接受度高、应季性强、色彩喜庆”，首选都乐（菠萝/香蕉/橙子等）。**

具体对比和建议如下：

**1. 品牌定位与受众人群**
- **佳沛（Zespri）**：主打**新西兰奇异果**，定位是“水果中的爱马仕”，品质稳定，甜度高，尤其是阳光金果（黄心）辨识度极强。礼盒装通常颗粒大、包装精致，非常适合送给注重生活品质、懂水果的客户或领导。
- **都乐（Dole）**：覆盖品类极广（菠萝、香蕉、蓝莓、牛油果、榴莲等），品牌知名度同样极高，但单品档次不如佳沛。礼盒多为混装或单一大众水果，适合送给普通员工、合作伙伴或家庭场景，显得实惠、体面。

**2. 节日/送礼场景的差异**
- **春节/中秋**：都乐的**都乐金菠萝**或“金菠萝+车厘子”组合通常更受欢迎，因为菠萝寓意“旺财”，金色外观喜庆；而佳沛奇异果绿盒/金盒虽然高端，但部分长辈对奇异果的认知度不如菠萝高。
- **高端商务拜访/年终答谢**：**佳沛阳光金果礼盒（买3盒装那种）** 更受欢迎，因为单价高、来源清晰（新西兰），送出去更有“特意挑选”的感觉。

**3. 库存与应季性（团购执行角度）**
- **佳沛**：全年供应稳定（尤其金果），但价格波动较小，适合任何时间点团购。
- **都乐**：菠萝/香蕉虽然全年有，但真正口感巅峰是春夏；若团购在冬季，都乐礼盒可能不如佳沛显得“鲜嫩”。

**4. 给您的实操建议**
- **第一步：直接向客户确认使用场景。** 问一句：“这批礼盒是发给员工福利，还是送给外部重要客户？”这决定选品方向。
- **第二步：若客户未明确，推荐“组合拳”**：在一份礼盒中，放入**佳沛阳光金果（6个装）+ 都乐金菠萝（1个）**，既满足了“进口品牌”的要求，又兼顾了高端感和大众接受度。目前不少企业团购都采用这种搭配。
- **第三步：建议提供试吃样品**。让客户采购负责人品尝后再定，因为口感满意度直接关系复购。

**总结：**
- 如果只能选一个，且预算允许 → **佳沛金果礼盒**（认可度最高，不易踩雷）。
- 如果客户喜欢“大而全”或预算有限 → **都乐菠萝/香蕉礼盒**（接受度广，价格亲民）。
- 如果客户是女性为主（如教师、医护、行政），**佳沛**更受欢迎；如果客户是中年男性居多，**都乐**更稳妥。
