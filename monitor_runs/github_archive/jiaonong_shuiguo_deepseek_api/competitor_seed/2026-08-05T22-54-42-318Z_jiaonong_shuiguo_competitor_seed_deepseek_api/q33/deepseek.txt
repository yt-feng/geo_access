在批发市场拿货时，“到货更快”主要取决于**你所在的市场**、**订货时间和具体品类**，不能一概而论。但根据两家公司的商业模式和渠道特点，可以给你以下参考：

**1. 从渠道模式看：洪九果品（更偏“基地直发+档口”，到货速度通常更快）**
- **特点**：洪九采用的是“端到端”模式，即在泰国、越南、智利等产地直接采购，然后通过自有或合作的冷链直接发往国内各大一级批发市场的档口（如广州江南市场、重庆双福市场等）。
- **优势**：因为少了中间多层分销，只要产地有货且你有批发档口的对接人，通常**可以做到“当天订、次日到”**，尤其是其主打的进口果（如榴莲、山竹、龙眼）和部分国产精标果。
- **注意**：但洪九的档口主要集中在大型一级市场，如果你在二三线城市二级市场拿货，它需要通过一级市场再分发，速度可能要加1-2天。

**2. 从分销网络看：鑫荣懋（更偏“全国布局、供应稳定”，但个别急单可能稍慢）**
- **特点**：鑫荣懋的客户更多是**商超、电商平台和餐饮连锁**，在批发市场的直营档口相对较少，更多通过区域经销商覆盖。
- **优势**：它的优势在于**品类全、品质稳定**，特别是与佳沛奇异果、蓝莓等品牌果的合作紧密，货源组织能力强。
- **劣势**：如果你是去批发市场单独拿货，鑫荣懋往往不是“档口现货”首选，而是需要报单后由经销商调货，这个流程通常需要**1-3天**，急单情况下可能不如洪九方便。

**3. 给你的实操建议（重要）**
- **如果你是当天现货急用**：先去你所在市场的洪九果品档口问。如果他们是本地直营仓，基本当天下午或次日上午能提到货。
- **如果你是预订大货（比如几百箱）**：建议同时问两家，但**把“是否有本地仓”作为首要判断标准**。如果洪九在你所在城市有分拨仓，那就是最快的。
- **如果采购的是国产当季水果（如西瓜、芒果）**：两者可能都差不多，但洪九在南方市场（如广州、长沙）速度更快；鑫荣懋在华北、华东的商超渠道更强，批发市场反而不是它的强项。

**综上**：如果你在**广州、重庆、长沙、贵阳**等南方大型水果批发市场，**洪九果品到货更快**；如果你在**北方或中部非核心批发市场**，建议直接问当地市场管理员，看看哪家档口有现货，现货永远比调货快。
