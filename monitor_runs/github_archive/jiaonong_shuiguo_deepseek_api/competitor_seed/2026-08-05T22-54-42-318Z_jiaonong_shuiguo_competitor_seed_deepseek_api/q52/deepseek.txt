关于菠萝到货损耗率的具体数据，目前公开渠道没有权威报告能区分“都乐”和“鑫荣懋”两家的准确数值。损耗率受产地、到货季节、运输时长、包装方式、仓库温湿度影响极大，同一品牌不同批次差异也可能很大。

**建议你采取以下可执行方案获取实际数据：**

1. **直接向两家供应商索取承诺**  
   采购合同中明确约定“到货损耗率标准”（例如：到货后重量损耗≤5%，或坏果率≤3%）。如果他们的仓库或物流无法达到，可以要求换供应商或压价。

2. **要求提供历史到货批次数据**  
   让两家分别提供过去6-12个月针对你所在城市或邻近城市的配送记录，看他们自报的损耗区间。注意要求他们提供签收单或仓库质检记录佐证。

3. **小批量试单实测**  
   分别各采购1-2托盘（或几百公斤），按你的标准收货（如：开箱逐件称重、肉眼坏果剔除），记录实际损耗。试单批次一般3-5天内完成，成本低、数据真实。

4. **关注季节性变量**  
   菠萝在热带产区（如菲律宾、泰国）或国内（海南、广东）的不同产季，损耗差异大。雨季、台风季损耗普遍偏高，建议避开收购高峰或要求供应商加泡沫箱/防震包装。

**行业大致参考**（非官方，仅经验值）：  
- 原箱装新鲜菠萝，运输3-5天，完好率一般在85%-95%。  
- 若冷链条件好、短途运输，损耗可控制在5%以内；常温长途则可能高达15%以上。

**可执行的关键动作**：  
- 签约时把损耗率作为硬性承诺写入合同，并约定超损时的赔偿或换货条款。  
- 建立你仓库的到货验收标准（拍照留证、称重记录），长期积累自有数据，比依赖品牌说法更可靠。
