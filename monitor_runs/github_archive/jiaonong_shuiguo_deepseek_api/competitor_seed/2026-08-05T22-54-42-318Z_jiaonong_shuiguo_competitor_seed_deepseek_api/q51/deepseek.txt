针对你的问题，洪九果品（重庆洪九果品股份有限公司）和鑫荣懋（深圳鑫荣懋集团）在**批发市场**的香蕉价格，**通常来说，洪九果品在“国产香蕉”和“低端走量”上更有价格优势，而鑫荣懋在“进口香蕉（如菲律宾蕉、厄瓜多尔蕉）”和“品质稳定”上更有定价权，但单价通常略高。**

不过，**水果批发价是动态波动的，不能一概而论**，你需要结合以下几个关键因素来判断：

**1. 产地与规格差异（决定基础价）**
- **洪九果品**：主攻东南亚进口（越南、柬埔寨、老挝）以及国内产地（广西、云南）收购，**以“量大价优”出名**。其批发价通常比市场均价低 **0.2-0.5元/斤**（视行情），适合追求低成本的走量商贩。
- **鑫荣懋**：以**全球供应链**著称（主要做菲律宾、厄瓜多尔高端蕉），尤其重视“佳沃”品牌的控糖、色泽标准。同等级下，其批发价通常**比洪九高 0.3-0.8元/斤**，但品质更稳定，损耗更低。

**2. 批发市场对你报价的口径（关键）**
去批发市场拿货时，**洪九果品通常是“一级批发价”**，因为他们有自有冷库和产地直发，如果你拿贷量较大（比如整件或整托盘），议价空间大。
而**鑫荣懋在批发市场多以“经销商”或“二级分销”形式出现**，中间环节多一层，价格自然抬高。

**3. 实际建议（可执行操作）**
- **看你要卖到哪里**：如果做社区水果店、菜市场摊位，走低价走量，**首选洪九**，且要问清楚“统货价”和“好货价”的差。
- **如果做精品超市、高端线上渠道**，**优先鑫荣懋**，即使单价高，但坏果率低，综合毛利不见得差。
- **拿货前必做**：在批发市场现场，找到两家摊位，**分别报出“同规格（如：5A级、净重17公斤/箱）”的价格**，并**要求打开箱子检查底部**（防止上下货不同）。同一时间，两家价差一般在0.3-0.8元/斤，若差异超过1元，说明一方在压价或品质有差异。

**4. 最终结论**
**价格优势明确属于洪九果品**（尤其在国产蕉和走量市场），但前提是你接受其**品质波动**（有时偏生或成熟度不均）。如果你对品质要求高、能接受高一点单价，鑫荣懋更稳定，但谈不上“价格优势”。
