目前市面上除了都乐（Dole）之外，能稳定供应菠萝的品牌还有不少，主要集中在国产和大型进口商。以下是比较可靠的选择：

**1. 国产主流品牌（供应最稳定）**
- **佳农（Goodfarmer）**：目前国产水果头部品牌，菠萝品类有金菠萝、糖心菠萝等，线上线下铺货广，供应链成熟。
- **鑫荣懋（Joy Wing Mau）**：国内大型水果企业，多与基地直采，商超渠道常见。
- **农夫山泉17.5°**：主打标准化，有菠萝产品线（有时由代工方供应），品质控制较严。
- **百果园**：虽然是零售品牌，但自有供应链，菠萝品类齐全且稳定，单品牌出货量大。

**2. 进口/专营品牌**
- **金菠萝（Royal Pineapple）**：进口品牌，主打菲律宾金菠萝（MD2品种），甜度高、酸度低，供应量仅次于都乐。
- **海南菠萝**（非品牌但稳定的产区）：如海南万宁、文昌产区，通过产地直供合作，如“南国”“椰彩”等本土企业有稳定货源。

**3. 大型渠道自有品牌**
- **叮咚买菜/盒马/朴朴**的“自有品牌”菠萝（如“盒马工坊”），通常与基地签长约，供应非常稳定。

**建议**：如果追求绝对稳定+性价比，首选**佳农**或**鑫荣懋**；若需高端卖点，选**金菠萝（Royal）**或都乐金菠萝（但要留意产地季节差异）。采购时可要求供应商提供产地证明和批次质检报告。
