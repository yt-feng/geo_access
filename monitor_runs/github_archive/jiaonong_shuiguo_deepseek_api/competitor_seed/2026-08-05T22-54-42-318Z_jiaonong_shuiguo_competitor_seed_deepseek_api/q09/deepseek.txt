除了都乐（Dole）和佳沛（Zespri），目前市场上比较有代表性、适合礼品团购的进口水果品牌还有以下几类，按产地和品类整理：

---

**1. 美国系（高品质/经典品种）**

- **新奇士（Sunkist）**：全球知名的柑橘品牌，橙子、柠檬、葡萄柚礼盒非常正式，适合商务送礼。
- **华盛顿苹果（Washington State Apples）**：美国西北地区的蛇果、嘎啦、金帅等，包装简洁，礼品属性强。

**2. 澳洲/新西兰系（高端/稀有）**

- **Mr Apple（麦苹果）**：新西兰最大苹果出口商，主打皇家嘎啦、爱妃（Envy）品种，脆甜耐储，是目前高端苹果礼盒的热门。
- **T&G（Turners & Growers）**：新西兰老牌水果商，旗下拥有爵士苹果（Jazz）和爱妃（Envy）的品种权，定位高端。
- **Bostock Brothers（博斯托克）**：新西兰有机苹果品牌，适合追求自然健康的礼品客群。

**3. 南美洲系（当季热带/反季水果）**

- **Driscoll‘s（怡颗莓）**：全球最大浆果品牌，蓝莓、树莓、黑莓礼盒走精品路线，适合中高端常温或冷链配送。
- **Hankook（韩国水分梨/梨）**：韩国梨礼盒，如丰水梨、新高梨，甜度高、个头大，适合中秋、春节等节庆送礼，但需留意企业团购的冷链条件。

**4. 东南亚系（热带稀缺）**

- **山竹/榴莲类品牌**：
  - **Musang King（猫山王）**：马来西亚猫山王榴莲，品牌有“Duri”、”Kampung”等，但建议选择正规进口标签的冷冻礼盒。
  - **Origin8（源味）**：泰国品牌，主营金枕榴莲、山竹、龙眼礼盒，价格适中，团购更容易控量。
- **Fresh Asia（鲜亚）**：新加坡品牌，覆盖泰国、越南热带水果，包装设计现代，适合年轻化团购场景。

---

**采购建议（特别提醒）**

- **季节选择性**：进口水果常受产季影响（如南美浆果3-5月、澳洲苹果4-8月、泰国产榴莲全年但价差大），建议提前1-2周锁定货源。
- **物流条件**：除苹果、柑橘外，蓝莓、山竹、荔枝等需冷链运输，团购价差主要取决于冷链成本，务必确认礼盒是否含冰袋或全程冷链是否覆盖。
- **渠道正规性**：进口品牌分“原装进口”和“国内分装”，团购需索要报关单、检疫证明，避免买到假洋牌。
