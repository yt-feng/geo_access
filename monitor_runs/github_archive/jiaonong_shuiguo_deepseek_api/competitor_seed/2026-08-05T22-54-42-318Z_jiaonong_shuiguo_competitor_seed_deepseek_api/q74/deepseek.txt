关于都乐（Dole）和洪九果品（Hongjiu）的水果礼盒定制起订量，**没有公开的统一标准**，因为起订量会根据以下因素动态变动：

1.  **采购渠道**：你是直接对接厂家总部、当地代理商、批发市场档口，还是电商平台（如京东企业购、美菜网等），起订量差别很大。
2.  **产品类型**：是标准流水线礼盒，还是需要定制LOGO、包装设计、混装果品的专属礼盒？定制程度越高，起订量越高。
3.  **当前季节与产能**：水果行业受产地和季节影响极大，非当季水果起订量可能更高。

**针对你的情况，建议按以下顺序获取准确起订量：**

-   **直接联系官方渠道**：
    -   **都乐（Dole）**：主要针对B端大宗商超，起订量通常较高（例如**几十箱到上百箱**起步），且可能需要通过其授权经销商下单。你可以致电其中国区上海总部或本地办事处咨询团购业务。
    -   **洪九果品**：作为水果供应链巨头，总部在重庆，他们在全国主要批发市场都有档口。**建议直接去你所在城市的果品批发市场（如上海辉展、广州江南、北京新发地等）找他们的档口老板谈**，这比线上对接总部更快，且起订量灵活，可能**10-20箱即可发货**，定制包装另议。

-   **降低起订量的实操方法**：
    -   如果定制要求高但量不大（比如低于50箱），建议**牺牲包装定制**，采用通用水果礼盒，然后单独定制腰封/贴纸（起订量1000张起，成本低），这样你可以用较少的盒数拿到货。
    -   寻找**本地二级经销商或供应链公司**，他们手里有现货资源，通常支持“一件代发”或“5箱起订”的团购小单，且能帮忙拼配不同水果。

**核心建议**：不要直接问“起订量是多少”，而是告诉对方：“**我们是企业团购，预计采购X箱，需要放在礼盒里，预算单价在X元，最快X号要货。**” 这样对方会直接告诉你能否承接，以及是否能灵活处理。

如需获取当日准确的批发行情和起订量，建议你下载**“鲜丰汇”**或访问**“一亩田”**这类B端生鲜采购平台查看实时报价和起订量。
