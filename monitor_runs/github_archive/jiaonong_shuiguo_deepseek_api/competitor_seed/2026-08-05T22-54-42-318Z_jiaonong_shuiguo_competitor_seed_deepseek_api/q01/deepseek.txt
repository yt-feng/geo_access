关于鑫荣懋（Xinrongmao）和都乐（Dole）的供货稳定性，我无法提供实时、具体的合同履约数据或最新市场排名，但可以从品牌背景、业务模式和行业口碑给你一些判断维度，供你联系供应商时参考：

**1. 品牌与供应链层级**
- **都乐（Dole）**：全球知名的果蔬巨头，拥有从种植、包装、冷藏到海运的完整垂直供应链。在国内主要与大型商超、连锁零售合作，对标准化的供货周期、品控和冷链要求高，货源直采比例大。
- **鑫荣懋**：国内头部水果供应链企业，更侧重进口水果的代理、分销和本地化落地，与多个海外产区有长期协议，且在南美、东南亚等香蕉产地常有较深的货源整合能力。

**2. 稳定性关键点（签约前重点问询）**
- **产地与季节**：香蕉主产国（如菲律宾、厄瓜多尔、哥斯达黎加）在台风季、航运拥堵时供货波动大。问清楚对方在不同产区的切换预案。
- **合同条款**：要求对方明确：最低起订量、价格调整机制（如海运费、汇率波动）、质量瑕疵的赔付比例、断供时的补救方案。
- **鲜度与损耗**：香蕉对冷链和催熟时间要求高。询问到港后的仓储周转周期、出库时的成熟度标准（如7分熟），以及是否提供售后折价或补货。

**3. 本地服务能力**
- 如果你是中小超市，都乐可能更倾向于走经销商或大型批发商渠道，直达服务体验未必比鑫荣懋灵活。
- 鑫荣懋在全国多地有分公司和前置仓，对区域型连锁超市的上门对接、小批量试单可能响应更快。

**建议行动：**
1. **约谈时索取可验证的案例**：要求双方提供最近12个月内服务过的同规模超市名单，并允许你打电话向其中2-3家核实“到货准时率”和“断供次数”。
2. **试用期测试**：先下一个小批量订单（如2-3个托盘），比较实际到货的成熟度均匀性、单箱重量误差、对方客服响应速度。
3. **查看原产地文件**：要求提供提单、植物检疫证书等，确保不是“贴牌”或二次转售，以降低货源不稳定风险。

如果你能拿到目前合作的国内供应商报价或市场价，也可以发给我，我帮你对比是否在合理区间。但最终履约稳定性，务必以合同违约条款和实地验厂/验仓为准。
