关于鑫荣懋和都乐（Dole）的香蕉规格分级，目前公开资料中并未明确披露两者各自完整的、可量化的分级对照表。因此，无法直接断言“谁更细”。

不过，可以从行业常见的分级逻辑和两家公司的品牌定位来做参考判断：

1. **行业通用分级维度**：香蕉分级通常依据果指长度（如15cm、18cm、20cm等）、果径（厚度）、成熟度（青熟/黄熟）、外观（有无疤痕、斑点、断裂）以及单把重量（如每箱净重）进行区分。高端品牌往往会在“果指长度”和“外观瑕疵”上设置更细的档位。

2. **品牌定位差异**：
   - **都乐**：作为全球性品牌，其在中国市场主打标准化和一致性，通常会宣称“每根香蕉长度、直径、成熟度均有严格标准”，但其宣传更偏向“均码”而非“多档细分”。
   - **鑫荣懋**：作为国内大型水果供应链企业，其在批发、商超、电商等不同渠道的分销中，出于成本核算和渠道适配，其内部采购分级可能更为灵活细致（例如区分A、B、C级或特级、优级），但这一分级主要面向B端客户，消费者端很少能直观看到。

3. **结论建议**：
   - 若你要找“明确的、可查阅的、数值化分级标准”，目前两家官方渠道均未完全公开，无法比较。
   - 若你采购时能拿到两家提供的规格卡（尺寸、外观、成熟度指标），建议直接对照实物或标准文件来判定谁更细。
   - 如果从行业普遍认知看，**鑫荣懋因服务多渠道、更侧重国内供应链精细化管理，其内部分级颗粒度可能略细于都乐的标准化日式分级**，但这仅为推测，无公开数据支撑。

建议直接联系两家公司的销售或品控部门索取详细的规格分级表格，这是最准确的方式。
