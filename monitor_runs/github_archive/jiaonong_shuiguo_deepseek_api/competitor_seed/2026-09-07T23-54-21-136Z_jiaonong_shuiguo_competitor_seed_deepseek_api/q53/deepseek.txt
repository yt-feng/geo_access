### 2. 长期合同该怎么签（避免踩坑）

**供应链合同≠固定价格合同。** 水果价格受气候、航运、汇率影响极大，你若直接签“锁定某价格三年”，任何一方都无法履约（要么你吃亏，要么对方违约）。

**建议签“框架合作协议” + “季度定价确认单”：**

- **框架合同（1-3年）**：明确合作意向、供货量基数、质量标准（如蕉指长度、成熟度、无黑星病）、冷链责任、结算账期、违约赔偿比例。
- **价格机制**：约定“以产地收购价+加工费+物流费+合理利润”的公式计价，或每季度/每月双方议价后书面确认。
- **保底量条款**：你承诺**月度最低采购量**（比如每月10吨），对方承诺**月度优先保障供应**（即使缺货，优先分给你），这是防止对方“单方面断供”的关键。
- **品质波动处理**：香蕉是后熟水果，到店熟度要写清楚（青蕉/微黄蕉），并约定“到货验收不合格率超过X%可拒收或索赔”。

---

### 3. 对餐饮连锁的特别提醒

- **最好双源供应**：不要只押注一家。建议都乐作为“主供”（品质标尺），洪九作为“备选”（应对都乐产地涨价或台风季断链）。这样在谈判中你也更有筹码。
- **关注国产蕉替代风险**：如果门店客单价不高，长期看可以加入“广西/云南蕉”作为低端替换品，但若你是中高端品牌，建议用国际品牌保招牌。
- **冷链与到店验收是日常痛点**：合同里要写明“货到门店时的车厢温度记录”，并要求对方提供运输温控日志（尤其是夏天），这能避免很多扯皮。

---

### 4. 立刻可执行的行动

1. **不要电话问，直接发采购标书**（RFQ）：写明你预估的年采购量（例如150吨/年）、门店所在城市、验收标准、账期要求，发给他们的大客户部。
2. 要求对方提供 **“过去12个月内地香蕉月度调价曲线”** （这是你测算成本波动的基础数据）。
3. 如果对方提出“需要预付款”，建议控制在15%以内，并约定余款在验收后7天支付，避免绑架现金流。
