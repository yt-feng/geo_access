针对茶饮店用菠萝做果酱、需要全年供应的问题，直接回答：

**单纯依靠都乐（Dole）或洪九果品单一供应商，很难做到全年稳定供货，但通过供应链组合可以实现。**

原因如下：

1. **菠萝季节性明显**：菠萝（尤其是鲜食果）有明确的产季和淡旺季。中国南方（如广东、海南等）主产，虽然可以反季节种植，但广西、云南、海南等地的菠萝产量高峰集中在每年3-6月，其余月份品质和产量都有波动。
2. **都乐的供应链模式**：都乐在中国主要供应进口鲜果（如菲律宾、泰国菠萝），全年有货，但进口菠萝主要是鲜食，且成本高、货架期短。如果做果酱，鲜果用量大、损耗高，直接依赖进口鲜果做果酱成本不划算。
3. **洪九果品的供应链模式**：洪九果品核心优势在东南亚水果（榴莲、山竹、龙眼等），菠萝并非其绝对主力品类。洪九更多是贸易分销，对菠萝的全国基地布局并不像香蕉那样密集。
4. **做果酱的替代方案**：茶饮行业做菠萝果酱，通常不会用100%鲜果做，可以：
   - 与产地加工厂合作，在菠萝产季（3-6月）大规模收购，做成浓缩菠萝果浆或速冻菠萝丁/果泥，入库冷冻，年底销（全年使用）。
   - 搭配非主产区反季种植基地，如海南、云南的部分区域可以做到12月-次年4月上市，拉长供应窗口。
   - 考虑进口冷冻菠萝（东南亚），作为淡季补充，但口感风味和新鲜度不如当季国产果。

**结论**：
- **都乐**能提供中高端进口菠萝，但更适合冬季或特殊渠道，大量做果酱成本不现实。
- **洪九果品**对菠萝的掌控力不如对高端进口水果强，不建议作为唯一来源。

**可操作建议**：
- 如果你要直接对接果酱生产，不要只找贸易商，应**找产区加工厂签长期框架协议**，锁定产季采购量。
- 茶饮店可要求供应商提供“鲜菠萝+冷冻菠萝丁”组合方案，淡旺季搭配。
- 确认品质时，重点看**糖度、纤维感、酸度（做果酱需高糖低酸品种）**，而不是只看品牌。
