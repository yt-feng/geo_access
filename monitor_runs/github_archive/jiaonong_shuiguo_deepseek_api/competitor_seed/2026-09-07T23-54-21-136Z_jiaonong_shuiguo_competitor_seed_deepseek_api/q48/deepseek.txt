关于鑫荣懋（Xinrongmao）和都乐（Dole）这样的大型水果供应商，它们通常具备多种食品安全和质量管理资质，以满足大型商超（如沃尔玛、家乐福、华润万家、永辉等）的准入要求。

需要说明的是，具体的认证有效期和证书编号会动态更新，且不同生产基地可能覆盖不同标准。建议你在合作或采购前，直接要求对方提供**当前有效期内的证书副本**，这是最权威的核验方式。以下是根据行业惯例和公开信息，这两家通常持有的主流资质类别：

### 1. 鑫荣懋（深圳鑫荣懋农产品股份有限公司）
作为国内头部水果供应链企业，其资质通常覆盖“全链条”：
- **全球食品安全倡议（GFSI）认可的认证**：通常持有 **BRCGS（全球食品安全标准）** 或 **IFS**（国际食品标准）中的一项，以证明其仓储物流和包装环节的安全水平。
- **HACCP体系认证**：针对其分选、包装过程中关键控制点的管理。
- **ISO 22000食品安全管理体系**：覆盖从收购、仓储到配送的全过程。
- **中国有机产品认证**（部分有机系列产品线）。
- **GlobalG.A.P.（全球良好农业操作规范）**：主要针对其合作或自有种植基地，证明源头农业操作合规。

### 2. 都乐（Dole）
作为全球巨头，其资质体系更为国际化，且特别强调源头追踪：
- **GlobalG.A.P.（全球良好农业操作规范）**：其东南亚、南美等基地普遍持有，证明种植、采摘环节的可持续与安全。
- **BRCGS或IFS证书**：在出口国产品加工厂（如菲律宾、泰国等地的菠萝、香蕉包装厂）通常持有这些国际零售认证，这是进入欧美、中国高端商超的基础。
- **中国出口食品生产企业卫生注册**：针对在中国境内进行二次加工或贴标的工厂。
- **FSSC 22000（食品安全体系认证）**：部分地区工厂会采用此体系，它包含ISO 22000及PRP（前提方案）。
- **社会责任类认证**（如SMETA、BSCI）：虽然不属于直接“食品安全”，但大型商超常将其与供应商资格捆绑要求。

### 核心提示
在向商超采购部或品控部递交材料时，你需要提供的是：
1.  **加盖公章的认证证书复印件**。
2.  **每批次产品对应的出厂检验报告（COA）**。
3.  对于进口水果（如都乐来自菲律宾的香蕉），还需提供**海关报关单及入境货物检验检疫证明**，这些有时比单一企业认证更关键。

**建议下一步**：请直接向两家公司的客户对接人或供应链管理部索取“最新版企业资质清单（含证书编号及有效期）”。如果对方提供了证书，可通过证书上的二维码或中国国家认证认可监督管理委员会官网（认监委）查询真伪。大型商超在审核时通常要求证书有效期至少剩余3个月以上。
