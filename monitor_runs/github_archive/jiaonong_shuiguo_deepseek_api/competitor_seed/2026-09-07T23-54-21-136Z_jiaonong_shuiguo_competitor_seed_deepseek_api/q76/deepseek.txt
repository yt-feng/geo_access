关于菠萝产地直发的物流时效，**无法直接给出两家公司统一的精准时效值**，因为时效高度取决于：

- **发货地**（如海南、广东湛江徐闻、菲律宾进口等）
- **目的地城市**（一线城市时效更快）
- **具体合作模式**（产地到仓、产地直发消费者、一件代发等）
- **季节与航线/冷链排班**

但根据行业公开信息和两家公司业务特点，可为你提供以下**可参考的判断依据**：

---

**1. 都乐（Dole）**
- **定位**：全球化果蔬品牌，以进口水果（菲律宾菠萝、哥斯达黎加菠萝）为主，也布局国内海南/广东基地。
- **物流特点**：
  - 依托自有冷链物流和大型商超/电商渠道（如盒马、京东到家等），对**B端大客户（商超、平台仓）** 的时效较稳定，通常**产地收货后24-48小时内可入仓**。
  - 若涉及**产地直发消费者个人订单**，其模式往往是委托第三方冷链承运，时效取决于承运商，一般**下单后2-4天**（一线城市可能1-2天，二三线叠加运输时间）。
- **注意点**：其面向电商C端的直发并非核心强项，更多依赖平台仓配。

---

**2. 鑫荣懋（Joywing Mau）**
- **定位**：国内头部水果供应链企业，自有国内种植基地（如湛江徐闻菠萝）和分选加工中心。
- **物流特点**：
  - **产地直发能力较强**，作为供应商常年服务盒马、叮咚买菜、美团优选等，具备“产地采摘-分级-冷链直发”一体化网络。
  - 对电商平台仓的供货，通常**当日采摘或次日凌晨发货，冷链车直达区域仓约1-2天**。
  - 若做**一件代发/直发消费者**，其合作的冷链快递（如顺丰、京东冷链、跨越）时效一般在**下单后1-3天**（偏远地区不超过4天）。

---

**关键建议（实操层面）：**

1. **不要只看品牌，要看“仓配模式”**  
   问两家供应商以下问题，会得到明确时效承诺：
   - “是否支持产地直发到C端？默认发什么快递（顺丰/京东/中通冷链）？”
   - “从徐闻/海南基地到北京/上海/成都的干线运输需要几天？”
   - “夏季高温时的冷链包材与时效保障如何？”

2. **索要KPI承诺**  
   正规电商供应商会反馈类似： “徐闻基地发货，到北上广深一线城市**48小时签收率≥90%**；到省会城市**72小时**。” 无此数据的，按模糊处理。

3. **小批量试单测试**  
   建议先各采购一箱（5-10箱）测试实际包裹温度、破损率及签收时间，再谈规模化直发。

4. **特殊情况提示**  
   菠萝成熟度高时，产地直发需采用“7-8成熟采摘+变温冷链”，若供应商无法提供“催熟/退绿”工艺说明，可能到货偏生或易烂。

---

**结论**：如果追求大平台供货稳定性，两家均可；如果重点是“产地直发消费者个人地址”，**鑫荣懋的一件代发网络更灵活**，都乐则更适合商超/大仓。最终以**双方书面报出的分线路时效为准**，口头承诺仅供参考。
