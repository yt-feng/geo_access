要判断都乐（Dole）和洪九果品菠萝的性价比，需要结合**产地、成本结构、供货稳定性和终端价格**来衡量。以下是实操建议：

**1. 看产地区分定价区间（菠萝成本大头在产地和损耗）**
- **都乐**：多为菲律宾/泰国等境外产地，品牌溢价高。通常整箱进口、规格标准化高，但到店成本（含关税、冷链、品牌授权）更贵。
- **洪九果品**：中国国内龙头，以泰国、越南及国内云南/海南产地为主，产地直采比例高，常规渠道成本通常低于都乐，尤其在下沉市场更有价格优势。

**2. 核算到店净成本（不能只看批发价）**
- 拿出两家给到你的**到店报价（含运费损耗）**，均摊到**可售果肉率**：都乐去皮损耗率低（约15-20%），洪九因品种和批次差异损耗可能偏高（约20-25%）。
- 按公式：**可售公斤成本 = 到店每公斤价格 ÷ (1 - 损耗率)**。算出来再对比。

**3. 权衡附加值（决定你能否卖更高单价）**
- 都乐适合走“进口品质、精品装”路线，可卖15-20元/斤，客单价拉高但走量慢。
- 洪九适合做促销引流款、切块试吃款，定价10-13元/斤，周转快。
- 所以 **你的定位决定性价比**：若你门店主打社区平价走量，优先洪九；若商圈精品店重体验，都乐可承担高毛利。

**4. 实操建议（一旦要采）**
- 先各进少量（各1-2箱）试卖7天，记录每日损耗、售后投诉和实际售罄天数，算出每筐的**真实毛利额**，不是毛利率。
- 若拿不到两家直供，建议找当地一级批发市场要**当日参考价**做比价基础。
- 另注意：菠萝季节价格波动大，最好在4-6月签供货锁价协议（若双方同意）。

**结论：没有固定赢家。通常洪九在到手成本低10-15%时，整体性价比更高，适合快周转；若你是做品牌溢价店且控损耗能力强，都乐的标准化会降低隐性成本。最终建议以“到店净成本+损耗率+实际售罄速度”三组数据算清楚再定。**
