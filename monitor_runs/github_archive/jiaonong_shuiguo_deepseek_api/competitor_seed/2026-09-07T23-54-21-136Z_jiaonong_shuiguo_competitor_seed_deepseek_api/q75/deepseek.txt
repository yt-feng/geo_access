关于洪九果品和都乐香蕉在批发市场拿货的**到货损耗率**，没有一个官方统一的标准数字。因为损耗率高度依赖**运输距离、运输时效、冷链条件、批发市场环境（温度/湿度）、香蕉的成熟度（催熟程度）以及上下货操作方式**。

不过，基于行业普遍认知和两家品牌的商业模式，可以给你一个**经验性对比框架**，供参考：

### 1. 洪九果品（进口及国产大宗批发）
- **商业模式**：洪九果品主做“端到端”的大规模供应链，从海外产地（如越南、柬埔寨）直采或国内产区（如云南）采购，依靠规模化、标准化分选和自有冷链物流进入国内一级批发市场（如广州江南市场、上海辉展）。
- **损耗特点**：
  - **优势**：由于产地直采且量大，单箱成本低；分选标准统一，果指大小均匀，**到货时成熟度控制较严**（通常带绿，适合长途运输后催熟），机械损伤率相对可控。
  - **劣势**：长途海运或车运是主要风险点。如果市场行情差、周转慢，**货架期压力大**，进入冷库或常温存放后损耗会集中爆发。在**一级批发市场拿货**，损耗率通常相对较低，因为当天的货基本带绿，批发商有主动催熟空间。
  - **预估范围（到货当天至3天内）**：如果成熟度合适且操作规范，**损耗率通常在3%-6%**（剔除烂果、断柄、挤压出水）。极端天气或操作粗暴下会超8%。

### 2. 都乐（Dole，品牌果品）
- **商业模式**：都乐是全球品牌，但进入批发市场的货品多数是**品牌精标果**，单箱规格高（如“都乐超甜蕉”），主要走**精品商超、水果店和高端批发**渠道。在普通批发市场，都乐多为**中转分销**，而非核心大宗走量。
- **损耗特点**：
  - **优势**：因为单箱价值高，包装更考究（有纸箱+隔板或气调袋），**抗压抗摩擦能力更强**，长途运输中的物理损耗最低。
  - **劣势**：都乐高端线（如甜蕉）通常**成熟度偏高**（部分已黄熟），以适应精品零售的即买即食需求。如果你在批发市场拿到的是黄熟度较高的批次，**呼吸作用强**，在高温批发市场内停留超过24小时，表皮黑点、果肉变软概率急剧上升。
  - **预估范围**：**完好到货率较高（物理损耗可能仅1%-3%）**，但若市场环境温度高（超过28℃）且你当天卖不完，次日**“软熟报废”损耗可能达10%-15%**。

---

### 给你的实操建议（比数据更重要）：

1. **看货不看品牌**：无论拿洪九还是都乐，**到货后当场逐箱抽检**（开箱看果柄发黑情况、果皮是否有噬斑、按压两头硬度）。损耗率在1%-2%是正常，超过5%就应要求换箱或折价。
2. **洪九适合走量**：如果你的客户偏好“价格敏感、量大、耐存放”，选洪九大宗货，到手后自行控温（15-18℃）催熟即可控制摊薄损耗。
3. **都乐适合高毛利精品店**：如果你面向高端社区或写字楼，都乐品牌溢价高，但售价也高，即便损耗高一点，单斤毛利能覆盖。**千万别进黄熟度高的都乐做库存**。

**结论：** 如果单比“物理到货损耗”（箱子里的烂果、断果），**都乐略优于洪九**（约低1-2个百分点）；但如果算“综合到货后48小时的变现损耗”（考虑你卖不卖得掉），**洪九大宗货可随时调整催熟节奏，反而更抗风险**。

最终请以你所在市场的当日批次成熟度为准，**务必抽箱验货再谈价**。
