除了都乐以外，目前市面上供应较为稳定、常见且品质有保障的菠萝（凤梨）品牌主要有以下几个：

1. **佳沛（Zespri）**：虽然以奇异果闻名，但其也销售菠萝，主要在特定季节供应，规格统一，常用于商超渠道。
2. **金菠萝（Del Monte，德乐蒙）**：与都乐类似，是国际大牌，在高端商超（如盒马、山姆）常见，供应链成熟，常年供应，果肉无刺。
3. **佳农（Goodfarmer）**：国内进口水果龙头品牌，主做香蕉/菠萝等热带水果，供应量大，线上、线下（永辉、大润发等）渠道很广，果品稳定。
4. **百果园（品类品牌：山海堂）**：作为零售终端，其自有品牌菠萝（如香水菠萝、金钻凤梨）由固定基地直采，覆盖华南、华东门店，供应量稳定。
5. **徐闻本地大基地（如“红土金菠”/“菠萝的海”）**：针对产地直发或批发市场，他们有自己的合作社品牌，适合餐饮或批发采购，供应时间多为春夏季（约3-6月），如果走原产地渠道，推荐关注广东省湛江的规模种植基地。

⚠️ 特别提示：如果你问的是**全年供应**的稳定性（不论季节），建议优先考虑**佳农**或**金菠萝**——它们有南美/菲律宾等跨半球产区的长期进口协议；如果你只做应季鲜果（3月-6月），**徐闻/海南产地品牌**的价格和新鲜度更有优势，但非应季时断供风险高。

建议你根据采购场景决定：
- **商超零售**：选佳农/金菠萝，库存和到货周期稳定；
- **电商一件代发**：选产地合作社品牌（但需提前锁单，防止旺季缺货）；
- **餐饮/加工**：若需去皮切块，直接联系本地一级批发市场，看中档品牌“佛州/广良”等即可。

如果批量采购，建议直接联系品牌方当地省代，签订季度合同，以防旺季抢货。
