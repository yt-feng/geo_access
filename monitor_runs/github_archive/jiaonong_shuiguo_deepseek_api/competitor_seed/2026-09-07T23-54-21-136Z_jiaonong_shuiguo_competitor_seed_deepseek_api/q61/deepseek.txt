关于水果连锁店香蕉分级标准，**都乐（Dole）和洪九果品是有企业标准的**，但这两家公司具体的官方详细分级细则（如尺寸、成熟度、糖度阈值等）通常不对外完全公开，而是作为其供应链内部的品质控制手册或采购规格书来执行。

**1. 都乐（Dole）**
- **有企业标准**。作为全球果蔬巨头，都乐拥有严格的内部质量体系（通常基于国际标准如GlobalG.A.P.，以及其自有的包装分级系统）。
- 其香蕉分级主要关注：**果指长度**（通常按厘米或英寸分级，如特级/一级/二级）、**果梳排列**、**成熟度**（色卡分级）、**外观瑕疵**（如黑斑、擦伤、蓟马疤痕比例）以及**糖度/口感**。但其公开渠道不会提供“一二级标准数值表”，只会声称符合出口或国内商超最高等级标准。

**2. 洪九果品**
- **有企业标准**。洪九果品在水果供应链中强调“端到端”标准化，其香蕉采购通常执行自定的**分级体系**（如特大果、大果、中果等），对应果指长度、单梳重量及成熟度控制。
- 其标准往往对标国内头部商超（如盒马、永辉）的采购规格，但属于内部协议，不对外公布具体数值。

**给您最实际的建议（用于您自己的连锁店）：**

如果您需要一套**可直接执行的分级标准**，不建议依赖这两家公司的保密文件，而是参照行业通用做法并自行建立标准：

- **长度分级**（市场主流）：一般按果指长度（厘米）分为：
  - 特级（AAAA）：≥26cm
  - 一级（AAA）：22cm ~ 26cm
  - 二级（AA）：19cm ~ 22cm
  - 三级（A）：16cm ~ 19cm
- **净重分级**（按单梳）：单梳净重 ≥1.2kg / 0.9-1.2kg / 0.7-0.9kg
- **成熟度色卡**：参照国际色卡（如1-7号色），店面销售建议在**4号色（黄绿交替）到5号色（全黄带微绿）** 之间上架，6-7号色仅做即食促销。
- **瑕疵标准**：单梳表面总瑕疵面积不超过3%或5%，果指开裂、断指、蓟马痕迹超过2个则降级。
