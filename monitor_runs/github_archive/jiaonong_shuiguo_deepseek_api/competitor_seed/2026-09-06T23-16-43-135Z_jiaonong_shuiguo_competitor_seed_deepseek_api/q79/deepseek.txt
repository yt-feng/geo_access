对于茶饮店需要**全年稳定供应菠萝**用于制作果酱，**都乐（Dole）和洪九果品**是行业内非常有力的供应商，但具体能否做到，取决于你门店的**采购规模、品质要求和预算**。

以下是针对这两个供应商的实际情况分析：

**1. 都乐（Dole）**
- **能力：** 都乐是全球性果蔬巨头，拥有**全球化种植基地和冷链网络**（如菲律宾、哥斯达黎加等）。他们可以做到“全年供应”，因为不同产区的菠萝成熟期互补。
- **优势：** 品种标准化程度高（如都乐金菠萝），单个果重、甜度、酸度相对统一，**非常适合茶饮连锁做SOP（标准作业程序）**，果酱风味稳定性好。
- **注意点：** 都乐偏向**大宗批发和大型连锁客户**，如果你是小微茶饮店，可能拿不到直供价格，通常需要通过当地经销商或批发市场采购。另外，进口菠萝成本较高，会直接影响果酱原料价。

**2. 洪九果品**
- **能力：** 洪九是国内头部水果供应链公司，主打**“端到端”直采模式**，在泰国、越南等东南亚产区有长期基地，同时也结合国内海南、广东等地菠萝供应。
- **优势：** 在国内市场的**议价能力和灵活度更强**，可以按区域分批配送，能搭配国产和进口货源调节价格。对中小型连锁或区域茶饮店来说，洪九在**成本控制和物流响应**上可能更友好。
- **注意点：** 洪九的菠萝更多用于鲜果零售和批发，若你指定“制作果酱专用的成熟度”，需要和对方采购确认。因为果酱需要较高糖度与较低纤维感，**C级果或次果反而更适合、更便宜**——这个你需要主动提出需求，否则对方默认供鲜售A级果。

**给你的直接建议：**

- **如果你是中小茶饮（月采购量<2吨）：** 不要只依赖某一个供应商。建议**洪九做主力**（价格、周期灵活），都乐作为备选补充，同时找1-2家本地菠萝罐头/果酱代工厂作为临时备份。
- **正式合作前，务必做“跨季测试”**：让供应商在**1月（国内淡季）和7月（泰国雨季）**各送一批样品，你熬制果酱对比出胶率、色泽和味道。因为全年供应≠风味全年一致，产季不同菠萝香气差异明显。
- **合同条款：** 在采购合同中明确要求“**一年内品质波动范围（如糖度Brix≥10%波动不超过2）**”，防止夏季和冬季换产地后口感突变。

**快速结论：** 都乐能保证“全年有货”，洪九能保证“全年有性价比”，但**能做到和做得好是两回事**。建议签订“年度框架协议”锁定价格和批次，并保留第三方检测权。
