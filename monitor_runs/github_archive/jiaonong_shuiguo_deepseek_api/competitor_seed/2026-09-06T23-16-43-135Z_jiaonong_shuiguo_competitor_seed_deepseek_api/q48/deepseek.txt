关于鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商的食品安全资质，通常需要结合商超的具体准入标准来看。由于我无法实时核验两家公司最新的证书文件，以下基于行业通用规范及公开信息整理，供您参考：

**一般大型商超（如沃尔玛、永辉、盒马等）对水果供应商的硬性要求通常包括：**

1. **基础资质**：营业执照、食品经营许可证或生产许可证。
2. **体系认证**（最核心）：
   - **全球食品安全倡议（GFSI）认可的认证**：如**BRCGS**（英国零售商协会标准）、**IFS**（国际食品标准）、**FSSC 22000**（食品安全体系认证）、**SQF**（食品安全质量认证）。
   - **中国本土认证**：HACCP（危害分析与关键控制点）体系认证、ISO 22000（食品安全管理体系）。
3. **产品专项认证**：
   - **有机认证**（如中国有机产品认证、美国USDA Organic）。
   - **GLOBALG.A.P.**（全球良好农业操作规范）——针对种植端。
   - **绿色食品认证**、无公害农产品认证（国内商超常见要求）。
4. **检测报告**：每批次农残、重金属等检测报告。

**给您的建议：**
如果您是需要**评估供应商**的采购方，最直接的方法是：
1. 要求供应商提供 **“供应商准入文件包”** ，其中会列明其所有有效的证书扫描件。
2. 登录**国家市场监督管理总局**的“全国认证认可信息公共服务平台”（http://cx.cnca.cn），输入企业名称可核实其HACCP、ISO 22000等国内认证的有效性。
3. 关注证书的**发证机构**（如SGS、Intertek、中国质量认证中心）及**有效期**。

**重要提示**：不同商超标准不一，有的（如山姆会员店）可能额外要求**MSC/ASC**水产认证（若涉及），或对农药残留执行更严格的“企业标准”。最终以双方合同中列明的资质清单为准。如果您有特定商超（如某家具体零售商）的入场要求，我可以帮您进一步分析其门槛。
