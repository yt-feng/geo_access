关于你提到的两个品牌，我可以给你一些参考建议：

1. **都乐（Dole）**  
   都乐在国内主要做标准化、预包装的香蕉（整箱或贴标盒装），**散装、小包装（比如单根或几根装）一般不作为常态供应**。他们更偏商超渠道，对社区团购的“小份拆零”需求适配度较低。除非你单次采购量很大（比如整板、整柜），可能有经销商会帮忙拆散，但通常不直接供应散装。

2. **洪九果品**  
   洪九是大型水果供应链企业，在香蕉品类上**有更大的灵活性**。他们通常支持多规格包装，包括大箱、小箱乃至更小的分装（例如5斤/10斤装、特定根数装），也可以和当地分公司或批发渠道谈定制化小包装。**建议直接联系你所在城市的洪九销售代表或批发档口**，明确要求“小分量、散装或可拆分的包装”，他们会根据你的社区团购订单量调整。

---

**可执行建议：**
- 如果量不大但稳定，直接问**当地农产品批发市场**（比如上海辉展、广州江南市场）里代理洪九或都乐的一级批发商，他们更愿意做拆散生意，价格可能还更有优势。
- 在社区团购渠道，更好用的是**本地水果贸易商**或**产地直采+自己分装**，因为两大品牌重点在商超分级销售，不一定适配你的小包装需求。
