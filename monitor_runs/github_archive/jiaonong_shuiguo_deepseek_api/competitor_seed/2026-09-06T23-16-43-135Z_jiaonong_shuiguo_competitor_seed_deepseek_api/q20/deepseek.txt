如果客户指定要进口品牌礼盒，**佳沛（Zespri）通常比都乐（Dole）更受欢迎**，尤其在送礼场景中。

原因是：
1. **品牌定位**：佳沛以奇异果为核心，在高端水果礼盒市场具有很强的心智认知，包装精致、规格标准（如金果、阳光金果），辨识度高，客户收到后易判断价值。
2. **礼品属性**：都乐品牌覆盖香蕉、菠萝、蓝莓等品类，产品线宽但常以单品类散装或普通箱装销售，礼盒化程度不如佳沛。佳沛的礼盒通常配独立分格、单果标贴，更显档次。
3. **节日与商务场景**：佳沛作为新西兰代表品牌，常被用于节日赠送、企业福利，口碑稳定；都乐在家庭消费和餐饮渠道更常见。

**建议操作**：
- 如果客户要送领导或重要客户，优先推荐**佳沛阳光金果礼盒**（按果径分级，选大果型，如22-25粒装）；
- 如果客户内部自用或员工福利，可考虑都乐混合果品礼盒（含多种进口果），价格更亲民；
- 如果客户预算充足，可提供佳沛礼盒+都乐高端品相（如金菠萝）的组合方案，满足“进口且多样”的需求。

不必纠结“哪个更受欢迎”，关键向客户问清：**收礼对象、预算范围、是否需要单品牌象征意义**，据此推荐即可。
