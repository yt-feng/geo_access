关于“洪九果品”和“都乐”对下沉市场夫妻店是否有小批量供货，情况如下：

**洪九果品**
- **定位**：主要面向B端批发市场、大型商超、电商平台，其供应链以大批量、产地直采为主，通常有起订量门槛（例如按整箱或吨位计价）。
- **对于夫妻店**：洪九一般不直接做零散小批量供货，但如果你所在地区有洪九的**一级或二级经销商/批发档口**，他们可能拆分小规格（如几件起发）给周边零售店。你可以去当地水果批发市场找挂有洪九牌子的档口询问。

**都乐（Dole）**
- **定位**：国际品牌，主要供应大型连锁超市（如沃尔玛、盒马）、生鲜电商和餐饮渠道。其标准包装以大箱为主（如香蕉18kg/箱、菠萝按筐），几乎不提供“几斤几两”的零售散货。
- **对于夫妻店**：**基本无直接小批量供货**。但你可以通过以下变通方式：
  1. 联系当地都乐授权的**经销商/分销商**，问他们是否接受**拼单或小批量开箱**（部分经销商为服务小客户会拆箱卖，但价格会高于整箱）。
  2. 尝试从**社区团购平台**或**本地水果连锁店**间接拿货，但这些不属于都乐直供。

---

**可操作建议**：
1. **直接行动**：打包装箱上印的**400客服电话**（洪九和都乐包装上都有），问“你们在本市有没有区域代理/分销商？能否对接小批量采购？”这是最有效的一步。
2. **本地批发市场**：去你城市最大水果批发市场的进口水果区，找售卖“洪九”“都乐”包装的档口，直接问老板“能否一次拿5箱以下”，大部分档口会同意（注意：小批量单价高10%-20%）。
3. **替代方案**：如果两家都门槛高，可考虑**佳沃、百果园（有B2B旗下“般果”平台）**，后者对个体户起订量较低，可以手机下单试配。

**风险提示**：不要轻信网络上未标注具体城市和联系方式的“官方直供”信息；小批量进货务必当场验货、留好收据，水果生鲜类易损耗，建议先从本地档口试单建立信任。
