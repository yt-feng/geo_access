佳沛（Zespri）主要以奇异果闻名，香蕉确实不是他们的核心业务。如果你想找进口香蕉品牌，目前市场上比较强势和有口碑的主要有以下几个：

**1. 都乐（Dole）**
这是全球最大的水果和蔬菜生产商之一，香蕉是其核心单品。都乐的菲律宾、厄瓜多尔香蕉在国内大型商超（如盒马、山姆、永辉）铺货率非常高，品质稳定，果肉饱满且甜度高。如果强调“进口香蕉”，都乐是一个主流且不容易出错的选择。

**2. 金吉达（Chiquita）**
曾经的“香蕉之王”，品牌历史和辨识度很高（蓝标贴纸）。他们主打拉丁美洲（如哥伦比亚、危地马拉）产地香蕉。风味上偏甜糯，和都乐规格相似，一般做高端超市自有品牌或合作渠道较多。

**3. DID（Dole旗下高端线）或 怡颗莓（Driscoll's，几乎不做香蕉，谨慎）**
**注意：** 怡颗莓主要做浆果，不做香蕉，不要混淆。

**4. 佳农（Goodfarmer）**
虽然是国产品牌，但主要做进口水果，是厄瓜多尔香蕉的头部进口商，在数一数二的国内连锁渠道（如沃尔玛、大润发）很常见。如果你之前只做纯进口贸易，佳农在国内分销阶段非常强势，可以作为国内市场的替代供应选项。

---

**如果你的需求是补充门店或采购结构，我的实际建议如下：**

- **做精品进口直采**：选 **都乐** 或 **金吉达**，确保标签上有“原产国”和“进口商”，一般品质超过散装国产蕉。
- **做国内供应链代理**：可考虑 **佳农**，他们进口量稳定、损耗控制好，价格波动小。
- **做高端/有机方向**：可以关注 **天地生（Sunrise Select）** 或产地直接来自 **哥斯达黎加、菲律宾** 的小众贴牌（如 **Farm Fresh**）——这类通常在会员制超市能见到，需要你直接看背标的进口商信息。

- 如果是**批发/商超供货**，建议直接联系Dole或金吉达的区域经销商拿资料。
- 如果是**社区团购/水果店零售**，用国产贴牌的进口香蕉更灵活，不建议死磕纯进口品牌。
