关于洪九果品与鑫荣懋在批发市场的香蕉价格优势，我没有实时的一手市场数据或官方报价，无法直接比较具体价格。但可以给你几个**可操作的方向**来判断：

1. **直接询价（最准）**：在对应批发市场（如广州江南市场、北京新发地等）里，直接找两家的一级或二级批发档口询价，报规格（如国产蕉/进口蕉、件数、等级）要当日实价。
2. **看渠道定位**：洪九果品在东南亚进口蕉（如越南、老挝）上量大、走货快，价格通常贴近产区成本；鑫荣懋偏高端综合果品，香蕉品控和售后可能更稳，但批发价未必最低。
3. **看“尾货/库存款”**：洪九在大量到货日上午常有清仓价，适合囤货；鑫荣懋更看重终端渠道，临时清货少。
4. **按市场现价逻辑估算**：通常在产地价+物流+市场费基础上，进口蕉（如菲律宾蕉）中间差价约0.5-1元/公斤，国产蕉（如南宁、河口蕉）更便宜。

建议你**本周内到市场，分别找两家档口要“同规格、同等级”的报价单**，做比价。如果不方便去现场，可打电话给两家公司在当地办事处问“市场批发部电话”。

**额外提示**：如果量大，可直接谈“整车发货”或“代采佣金”，价格往往可比档口价再低5%-8%。如果你告诉我所在城市和大概拿货量，我可以帮你预估常见批发价的合理范围，但不保证是实时准确数。
