不过，根据行业一般规律，给您两个参考方向：

1.  **都乐（Dole，跨国品牌）**：
    *   因为是国际大品牌，其**经销体系**通常是区域代理制。起订量门槛相对较高，如果是**礼盒定制的标准规格**（如常见的香蕉、菠萝礼盒），一般**100盒-300盒**起订（视果品单价而定，采购金额可能在1万-3万元左右），且需要签订采购协议或走大客户部流程。
    *   **建议**：在您所在城市，直接搜索“都乐 区域经销商”或“都乐 团购渠道”，告知对方是企事业单位团购，通常会有专门的团购经理对接，千万**不要**在超市零售渠道问，那边只卖现货不给定制。

2.  **洪九果品（国内头部供应链）**：
    *   洪九的优势在于**产地直采**和**多品种组合**（比如车厘子+蓝莓+奇异果）。由于它走的是大批发+新零售路线，起订量相对灵活，但为了防止拆单损耗，**通常1个品类**（如单一品种如龙眼、榴莲）起订量在**50箱-100箱**（箱规，非礼盒个数）。
    *   如果是**精装礼盒（含包装定制）**，通常按**金额**来算，一般最低**起订金额在5000元~8000元**人民币左右，数量大概是**50盒**起步（具体视盒子大小）。
    *   **建议**：在您的城市找到洪九的分公司或前置仓，报出“需要团购定制，预计采购量10-15万元左右”，他们的销售会立刻给您报一个比官网更低的梯度价。

**给您一个加分操作（防止被报高价）：**
无论联系哪家，**建议话术**是：“我们公司准备做员工福利，这个月大概有**200+份**的体量，后续季度也会持续采购。你们针对这种规模的定制礼盒，单盒成本控制在XX元以内的方案是什么？起订量和交期是多少？”
