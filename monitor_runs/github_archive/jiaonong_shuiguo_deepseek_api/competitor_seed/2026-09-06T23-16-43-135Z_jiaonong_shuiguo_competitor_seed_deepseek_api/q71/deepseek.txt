关于菠萝的稳定供应，都乐（Dole）和洪九果品（Hongjiu）都是国内茶饮市场重要的水果供应商。针对您关心的**菠萝（通常是都乐金菠萝或巴厘菠萝）**的稳定供应，其背后核心的**加工基地和种植基地**情况如下：

### 1. 都乐（Dole）
都乐作为全球性品牌，在中国市场的菠萝供应主要依托其**进口和国内加工分销网络**。

- **核心鲜果供应基地（种植）**：都乐的菠萝主要来自其海外自有/合作农场，**菲律宾（如棉兰老岛）**是全球都乐菠萝的核心产区，也是其供应中国市场的主要来源。
- **中国境内加工/配送基地**：
  - **上海**：都乐在中国的主要运营总部和大型冷链配送中心（主要在青浦、浦东等地）。
  - **广州**：都乐在华南有重要的仓储和分拣中心。
  - **其他分仓**：如北京、郑州等地设有配送仓。
  
  *注意*：对于茶饮连锁，都乐通常提供的是**预切块菠萝或整果配送**，果园不在中国，但会在上海、广州等地的工厂进行清洗、分拣和切割。

### 2. 洪九果品（Hongjiu）
洪九果品是国产水果及东南亚水果的头部供应链企业，强调“端到端”的基地直采。

- **核心菠萝采购/种植基地**：
  - **国产基地**：**广东湛江（徐闻）**和**海南（万宁、文昌）**是洪九果品稳定的国产菠萝直采基地，特别是台农系列和巴厘品种。
  - **进口基地**：洪九在**泰国（用于香水小菠萝）**和**菲律宾**有深度合作的果园，作为国产货架的补充。
- **中国境内的冷链加工基地**：洪九果品在**重庆**（总部）、**广州**、**上海**设有大型智能化分选包装中心，可根据茶饮客户要求规格（如切成1.5cm见方）进行加工。

---

### 采购建议（针对茶饮稳定供应）

为了确保不断货，建议您：

1.  **明确供应周期**：国产菠萝主要供应期为**3月-7月**（徐闻、海南）；都乐进口金菠萝可全年供应（菲律宾产季长）。若您需全年稳定，可**以都乐等进口品牌为主，以洪九的国产精品（如香水菠萝）在特定季节做风味升级**。
2.  **锁定报价模式**：洪九通常采用“产地价+加工费”模式，更适合预算敏感的茶饮大单；都乐通常采用“品牌溢价+稳定品质”模式。建议对比您当前的位置（如在华东推荐都乐上海仓、在西南推荐洪九重庆仓）以降低冷链运输损耗。
3.  **实地审核**：即便有基地，务必让采购经理实地验厂，特别是要求查看其**自动化削皮去芯设备**，这直接关系到您茶饮产品的出品效率和损耗率。
