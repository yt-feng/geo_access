除了都乐和佳沛，礼品团购可重点看这几类进口水果品牌，按“是否有明确品牌礼盒、团购可操作性、认知度”来分：

**一、综合进口水果品牌（适合做企业礼盒）**
1. **新奇士/Sunkist**：美国柑橘类代表，脐橙、夏橙、葡萄柚礼盒认知度高，适合春节、中秋企业福利。
2. **怡颗莓/Driscoll's**：浆果类强品牌，蓝莓、树莓、黑莓礼盒偏中高端，适合预算较高的客户。
3. **爱妃/Envy**：新西兰苹果品牌，礼盒装常见，单品辨识度高，适合做高端苹果礼盒。
4. **乐淇/Rockit Apple**：新西兰小苹果，筒装/礼盒装适合商务伴手礼，规格统一，团购好操作。
5. **红地厘/Red Delicious 等苹果品牌**：这类多为品类品牌，不如爱妃、乐淇适合做统一品牌礼盒。

**二、高端/精品进口水果品牌**
6. **Megaphone**：澳大利亚高端水果品牌，常见塔斯马尼亚车厘子等，适合高端礼盒。
7. **Cherry Hill / Reid Fruits / 43 Degrees South**：澳洲车厘子品牌，季节性强，适合冬季高端团购。
8. **Stemilt**：美国樱桃、苹果、梨品牌，部分礼盒可做。
9. **Chelan Fresh**：美国樱桃品牌，夏季车厘子团购常见。
10. **PrimaFresh / Vanguard**：进口葡萄、车厘子等精品水果供应商品牌，偏渠道品牌，礼盒定制空间大。

**三、佳沛之外的新西兰水果品牌**
11. **Bostock**：新西兰苹果、梨品牌，适合高端苹果礼盒。
12. **Mr Apple**：新西兰苹果品牌，礼盒装常见。
13. **Golden Bay Fruit**：新西兰苹果、梨，部分做高端礼盒。

**四、日韩方向**
14. **日本青森苹果**：通常不是单一商业品牌，而是产区品牌，礼盒溢价高，但团购供应不稳定。
15. **日本晴王葡萄/香印葡萄**：多为产区或果园品牌，礼盒感强，但价格高、季节短、真假混杂。
16. **韩国新高梨/圆黄梨**：礼盒装常见，适合企业福利，但品牌集中度不如欧美。

**团购选品建议：**
- **走量、预算中等**：新奇士、Mr Apple、Bostock、乐淇。
- **中高端、送礼体面**：怡颗莓、爱妃、乐淇、Megaphone。
- **高端、季节性强**：澳洲车厘子品牌、日本青森苹果、晴王葡萄。
- **要稳定供货、可定制礼盒**：优先找国内进口商或一级批发商，用“品牌水果+定制外盒”组合，而不是只盯原厂礼盒。

**注意：**
很多进口水果是“产区品牌”或“品种品牌”，不一定有全国统一零售礼盒。团购时重点确认：是否有原箱品牌、能否贴标/定制礼盒、到货规格是否统一、损耗和售后谁承担。
