都乐和洪九果品的**水果礼盒定制起订量**，公开渠道通常不会给统一标准，实际要看**品牌方/区域经销体系、礼盒类型、包装定制程度、采购季节和交付城市**。我无法核验到两家当前官方统一起订量，所以不能给你一个准确数字，避免误导。

可以按下面方式判断和推进：

**1. 先区分两种“定制”**
- **轻定制**：贴企业LOGO、换腰封、贺卡、外箱贴纸。起订量通常低很多，可能几十到几百盒，但品牌方未必直接接。
- **深度定制**：专属礼盒结构、指定水果组合、独立包装、印刷定制。起订量通常更高，常见要**几百到上千盒**，部分单品甚至按整板/整箱起订。

**2. 都乐**
都乐在国内更多是品牌授权、区域经销和渠道分销体系。  
- 如果你找的是**都乐官方或总代**：一般偏向大客户、连锁商超、电商平台，团购定制起订量可能较高。  
- 如果你找的是**区域经销商**：起订量弹性更大，但可定制的包装和果品组合有限。  
- 建议直接问：是否支持企业LOGO、最低多少盒、能否混搭、是否含运费、能否开票。

**3. 洪九果品**
洪九果品偏水果供应链和批发分销，优势在货源和品类，不一定擅长小批量礼盒定制。  
- 如果是**标准礼盒**，起订量可能相对灵活。  
- 如果是**完全定制礼盒**，通常要按他们的包装厂和果品分拣要求走，起订量会明显提高。  
- 建议问清楚：是洪九直营接单，还是区域子公司/经销商接单。

**4. 你询价时直接问这8项**
1. 企业团购定制最低起订量是多少盒？
2. 是否支持LOGO、腰封、贺卡、外箱定制？
3. 可指定哪些水果品类和规格？
4. 不同起订量对应的单价阶梯？
5. 是否含包装、分拣、配送、上楼？
6. 能否开增值税专票？
7. 下单到交付需要多少天？
8. 破损、坏果怎么赔付？

**5. 更现实的建议**
如果你团购量在**100～300盒**，优先找：
- 都乐/洪九的**区域经销商**
- 当地大型水果批发商
- 专业礼盒定制商，再由他们采购都乐、洪九果品

如果你量在**500盒以上**，再直接找品牌方或大区渠道谈，起订量和价格会更有空间。

**结论：**
都乐和洪九没有我能核验的公开统一起订量。常见情况是：轻定制几十到几百盒可谈，深度定制通常几百盒起，具体必须问对应区域经销商或大客户渠道。最有效的方式是同时找**品牌区域经销**和**本地礼盒定制商**比价，不要只等品牌总部回复。
