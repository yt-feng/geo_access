都乐和鑫荣懋的具体到货损耗率属于厂商/渠道内部品控数据，公开渠道通常查不到稳定、可核验的统一数字；而且损耗率会随季节、产地、批次、运输距离、加工方式（整果/去皮/冷冻块/果浆）、验收标准不同而大幅波动。直接给你一个百分比反而是不负责任的。

可以给你一套可执行的判断和采购做法，用来拿到并比较两家的真实损耗：

**1. 先定义“损耗率”口径**
否则两家数字不可比。建议拆成：
- 运输损耗：到货后腐烂、压伤、破皮
- 加工损耗：去皮去芯、修整切除
- 总可用率：能用于出品的净果重量 ÷ 到货毛重

**2. 要求供应商提供并书面确认**
向都乐、鑫荣懋的业务分别要：
- 近3个月同规格的到货验收数据（按批次）
- 规格书（品种、单果重、糖度、成熟度、包装、冷链温度）
- 验收标准与赔付条款

**3. 自己做小批量实测（最可靠）**
选同一时期、同规格，各进1–2批，按下面记录：
- 到货毛重
- 分拣后可用果重
- 修整后净果重
- 腐烂/压伤/未熟果占比
这样得出的才是你门店真实损耗。

**4. 茶饮场景建议关注**
- 鲜果门店：优先看成熟度一致性和压伤率，损耗常比品种差异更影响成本
- 中央工厂/冷冻块/果浆：重点看净果率、糖度稳定性和解冻出水率
- 季节性：夏季高温运输损耗通常高于冬季

**5. 谈价与合同**
- 把损耗率或净果率写进规格书
- 约定超标赔付/补货
- 先小批量试单，再签长期价
