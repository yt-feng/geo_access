这个需要分情况看,而且我无法实时核验两家最新的供货政策,所以给你判断路径而不是拍结论。

**都乐(Dole)**
- 都乐在国内渠道以**品牌化预包装**为主,常见的是整把/整袋(如 5-6 根装、按重量袋装),以及商超单根卖但带都乐标签。
- 严格意义的"散装"(无品牌、按斤称、可自由拣选)通常不是都乐的直接产品形态,而是**渠道商拆袋零售**。社区团购想拿"都乐品牌 + 小包装",一般是走**预包装小规格**,不是散装。
- 能否做小包装定制,取决于你是否达到其经销体系的起订量,通常要通过区域经销商或供应链服务商谈。

**洪九果品**
- 洪九是水果供应链/批发型企业,主打**产地直采+批发分销**,给商超、电商、团购供货。
- 它更可能提供**按箱/按件**的货源,是否支持"小包装"要看具体品类和合作规模。散装或小包装往往由洪九或下游做**分装**,而不是天然就有的零售小包。
- 社区团购场景下,更现实的是谈**定制小包装代工/分装**,而不是问它"有没有散装现货"。

**给你的可执行建议**
1. 别问"有没有散装",直接问:**"香蕉能不能做 XX 克/袋的小包装?起订量多少?是否贴牌?到货是预包装还是需要我们自己分装?"** 这样对方才能给准数。
2. 两条路并行:
   - 走品牌:找都乐/洪九的**区域经销或供应链服务商**,谈小规格预包装。
   - 走成本:自己找产地或批发市场拿货,找**分装点做小包装**,成本更低但品控和损耗要自己扛。
3. 香蕉是**后熟易损品**,小包装的关键不是"散不散",而是**催熟度、到货熟度、损耗率、配送温控**。先小批量试单,测损耗再放量。
