直接给结论：**单看“谁更便宜”没有稳定答案，必须按品类、规格、到货港、结算方式和当周行情逐单比。** 但按行业常见情况，可以这样判断：

1. **都乐（Dole）**
   - 品牌溢价通常更高，尤其是标准化程度高、面向商超/精品渠道的进口苹果。
   - 报价往往更“规范”，但未必是最低价。
   - 适合做品牌背书、稳定品质、礼盒或中高端门店。

2. **鑫荣懋**
   - 国内水果供应链龙头之一，进口苹果操作量大，渠道和产地资源深。
   - 在很多进口果品上，**实际拿货价可能更有竞争力**，尤其是整柜、长期合作、期货或大规格包装。
   - 但也要看它当周主推哪个产地和规格，价格波动大。

**更实用的比价建议：**

- **同一条件比**：同一品种（如新西兰爱妃、红玫瑰、爵士；美国蛇果；智利嘎啦等）、同一规格（果径/净重/箱规）、同一到货港、同一账期。
- **问清费用口径**：是裸果价、含税价、到仓价，还是到店价？是否含冷链、损耗、退换、账期。
- **看综合成本**：不要只看单箱价。都乐可能单价高但损耗低、动销稳；鑫荣懋可能单价低但需要自己承担更多分选和损耗。
- **小批量试单**：先各拿1-2板或几箱，同店同价测试7-14天，比毛利率、损耗率、客诉率。
- **锁价周期**：进口苹果受汇率、海运、产地减产影响大，问清楚报价有效期和锁价条件。

**一句话建议：**
如果你要品牌和中高端稳定输出，优先谈都乐；如果你要量、要综合成本、要灵活供应链，优先谈鑫荣懋。最终谁更有竞争力，取决于你拿的是哪个产地、哪个规格、多大采购量，以及是否长期合作。
