都乐和洪九果品是国内菠萝供应链里比较常见的两个选择，但两者的定位和基地布局差异较大，分开说。

**都乐**
都乐是外资果蔬品牌，在中国市场的菠萝主要来自其在华合作的种植基地和东南亚进口。国内方面，都乐在广东湛江、海南等地有合作种植和加工布局；进口方面，菲律宾、泰国是其主要来源地。都乐的优势是标准化程度高、品控稳定、适合连锁茶饮对规格一致性的要求，但价格通常高于国产菠萝，且部分时段依赖进口，受汇率和海运影响。

**洪九果品**
洪九果品是国内头部水果分销商，菠萝是其核心单品之一。其主要基地和采购来源集中在：
- 国内：广东徐闻（中国最大菠萝产区）、海南
- 进口：泰国、菲律宾、越南等东南亚产地

洪九的模式是"基地采购+分销"，在徐闻等地有较强的产地资源，价格相对有优势，供应量也大，适合对成本敏感、用量大的茶饮品牌。但品控一致性可能不如都乐，需要你自己在收货标准上把关。

**给采购的建议**
1. 茶饮用菠萝通常要的是去皮菠萝块/菠萝丁或冷冻菠萝，先明确你要的是鲜果还是加工品，这决定了你该找种植基地还是加工厂。
2. 都乐和洪九都可以谈，但更实际的做法是同时对接徐闻当地的菠萝加工厂，直接锁产地，成本更低。
3. 稳定供应不能只靠单一供应商，建议"主供应商+备选产地"双轨，尤其菠萝有明显的产季波动（徐闻菠萝集中在2-4月）。
4. 签合同前务必确认：规格标准（糖度、大小、成熟度）、冷链条件、到货周期、次品处理方式。

具体基地地址和当前供货能力，建议直接联系两家公司的销售或通过其官网/官方渠道核实，这类信息变动较快，我不便给出可能过时的具体地址。
