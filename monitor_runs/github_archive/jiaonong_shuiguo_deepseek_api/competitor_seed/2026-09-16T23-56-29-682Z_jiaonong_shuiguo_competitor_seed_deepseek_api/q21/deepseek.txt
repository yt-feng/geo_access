# 香蕉到货损耗率高的排查与品牌对比

## 先说结论

**无法简单判定"鑫荣懋和都乐谁更好"**，因为：

1. 两者定位不同：**都乐**是全球品牌，强在源头种植园管理和标准化催熟体系；**鑫荣懋**是国内头部水果供应链企业，强在国内全程冷链和渠道分销。都乐的品控体系更成熟、标准更统一，但具体到你的到货损耗，**取决于采购的是哪个产地、什么熟度、走什么物流**。
2. 香蕉损耗高，**大概率不是"品牌"问题，而是熟度/温控/催熟环节的问题**。换品牌往往解决不了。

## 香蕉到货损耗的核心原因（按影响排序）

| 环节 | 典型问题 | 表现 |
|---|---|---|
| 催熟度 | 到货熟度与销售节奏不匹配 | 青蕉到货后集中转黄，卖不完就烂 |
| 冷链断链 | 运输温度波动、装卸暴晒 | 蕉指发黑、柄部霉变 |
| 包装 | 箱内挤压、无通风孔 | 压伤、炭疽病扩散 |
| 周转 | 到货后堆放、未及时分拣 | 乙烯催熟整批 |
| 产地 | 雨季蕉、病害蕉 | 本身耐储性差 |

**先做一件事**：统计近几批的损耗率、到货熟度（几号色卡）、运输时长和温度记录。没有这组数据，换供应商只是碰运气。

## 两个品牌的客观差异

- **都乐**：自有/合作种植园多，采后处理（去轴、清洗、保鲜）标准化程度高，催熟多由授权催熟商按统一色卡执行。**适合对熟度一致性要求高的商超、连锁**。
- **鑫荣懋**：代理多个产地（菲律宾、厄瓜多尔、国产等），供应链灵活、响应快，能按客户需求定制熟度。**适合需要灵活配货、区域分销的场景**，但不同产地/批次质量差异可能更大。

**关键提醒**：你拿到手的货，实际品质更多取决于**当批产地和催熟商**，而非品牌本身。同一品牌不同批次都可能差别很大。

## 可执行建议

1. **先锁定问题环节**：用色卡记录到货熟度，连续记 5 批，判断是"到货就损"还是"到货后损"。前者是供应商/物流问题，后者是你的仓储/销售节奏问题。
2. **谈采购时明确指标**：约定到货色号范围（如 3-4 号）、糖度、允许损耗率，写进合同并留扣款条款。这比选品牌更有效。
3. **对比测试**：同时向两家各下一批**同产地、同熟度**的货，记录损耗，用数据决定。
4. **改善到货后管理**：到货立即分拣、剔除伤蕉，库温控制在 13-15℃，避免与苹果等乙烯源混放。
