**便利店小包装香蕉常见适配方向**
- **单根装/单支装**：适合收银台、鲜食柜，通常要求外观整齐、无伤痕。
- **2-3根装小袋**：适合早餐、办公场景，客单价更友好。
- **4-5根装 mini 袋**：适合家庭即时消费，但便利店动销通常弱于单根/2-3根。
- **小把蕉/小米蕉/皇帝蕉类**：天然小规格，更容易做单根或小袋装。

**向鑫荣懋、都乐询价时直接问这几项**
1. 是否有**便利店渠道专供小包装香蕉**，如单根装、2根装、3根装、5根装。
2. 规格：单根克重、每袋根数、每箱袋数、整箱净重。
3. 品种：普通香蕉、小米蕉、皇帝蕉、粉蕉等。
4. 包装：是否带品牌袋、透气孔、托盘、贴标、条码；是否支持定制门店标签。
5. 履约：起订量、配送温层、到店频率、保质期/催熟状态。
6. 价格：出厂价、到仓价、含税与否、损耗补贴或退换政策。
7. 渠道保护：是否已有便利店系统在售，能否给同渠道案例。
