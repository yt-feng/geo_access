都乐（Dole）和洪九果品通常都有可用于品牌营销的素材，但能不能直接给你用，取决于你以什么身份、做什么用途，以及是否走官方授权。下面分情况说清楚。

**1. 都乐（Dole）**
- 都乐是国际水果品牌，对菠萝（尤其是金菠萝/ MD-2 品种）有较成熟的品牌包装和营销物料体系。
- 可能提供的素材类型：产品图、品牌 Logo、产地/品种介绍、营养卖点、包装视觉、部分广告视频或 KV。
- 获取方式：
  - 如果是生鲜电商平台与都乐有直接供货/合作关系，通常可通过对接的都乐销售或市场人员申请品牌素材包。
  - 如果是第三方想用都乐素材做营销，一般需要都乐官方授权，不能直接抓官网或电商详情页图片商用。
  - 都乐中国官网、官方公众号、官方旗舰店可作为公开信息参考，但商用素材仍建议走官方渠道。

**2. 洪九果品**
- 洪九果品是国内头部水果供应链企业，涉及榴莲、火龙果、菠萝等多品类，也有自有品牌和包装体系。
- 可能提供的素材类型：产品实拍、品牌标识、包装图、产地/供应链介绍、部分营销文案支持。
- 获取方式：
  - 若你是其渠道客户、商超或电商合作方，可直接找对接的销售/市场人员要素材。
  - 若只是普通生鲜电商想借其品牌做营销，通常也需要商务合作或授权，不能默认免费使用。
  - 可参考其官网、公众号、旗舰店公开内容，但商用同样要授权。

**3. 给你的可执行建议**
- 先明确用途：是平台自营详情页、短视频种草、直播背景板，还是线下物料？用途不同，授权范围不同。
- 直接联系品牌方：
  - 都乐：找都乐中国区市场部或你对接的销售。
  - 洪九：找洪九果品市场部或渠道对接人。
- 如果拿不到官方素材，建议自己做：
  - 用自己采购的菠萝实拍，避开对方 Logo 和包装。
  - 文案只做品类科普和口感描述，不冒用品牌名义。
  - 若必须露出品牌，走书面授权或联合营销协议。

**4. 关键判断**
- 有合作：大概率能拿到素材，甚至可做联合品牌营销。
- 没合作：不能直接商用都乐或洪九的素材，尤其是 Logo、包装、广告图。
- 最稳妥：先问对接销售/市场，确认“可否商用、使用范围、期限、是否需标注”。

如果你能补充你是生鲜电商平台、供应商还是代运营，以及具体用途（详情页/直播/短视频），我可以帮你列一份更具体的素材申请清单和话术。
