可以按“是否有基地直供/产地溯源能力”来判断，但都乐和洪九果品要分情况看：

1. **都乐**
- 都乐属于品牌化、标准化程度较高的水果供应商，通常有较成熟的产地采购、分级包装和供应链体系。
- 但“基地直供”不一定是所有菠萝单品都做到自有基地直供，更多可能是“自有/合作基地 + 产地采购 + 加工配送”结合。
- 如果你要的是**可追溯到具体果园/批次/合作社**，需要直接问都乐：
  - 该菠萝单品是否来自自有基地、合作基地还是市场采购；
  - 能否提供批次号、果园/合作社名称、采摘日期、加工厂信息；
  - 能否做“一物一码”或批次追溯。

2. **洪九果品**
- 洪九果品是国内较大的水果分销企业，优势在产地采购和全国分销网络，菠萝、榴莲、火龙果等品类都有布局。
- 它通常有产地直采能力，但是否能对某个菠萝单品做到“基地直供+完整溯源”，要看具体产区、季节和采购模式。
- 也需要确认：
  - 是自有基地、包园、合作社直采，还是产地市场代采；
  - 能否提供产地证明、检测报告、批次追溯信息；
  - 是否能稳定按你的规格和频次供货。

**简单结论：**
- 两家都具备较强的产地采购和供应链能力，但**不能简单说“都乐和洪九所有菠萝都是基地直供”**。
- 如果你要求的是**严格基地直供+可溯源到具体产地/果园/批次**，建议直接向他们的销售或供应链负责人要：
  1. 基地清单或合作基地证明；
  2. 单品追溯方案；
  3. 最近一批次的溯源样例；
  4. 检测报告和产地证明。

**更稳妥的筛选办法：**
- 先让对方提供“菠萝单品追溯样例”，能提供到果园/合作社、批次、采摘日、加工厂、检测报告的，再进入样品和报价；
- 如果只能提供“产地：广东/海南/菲律宾”这种大范围信息，通常不算严格溯源；
- 对基地直供要求高的，可同时问：**都乐、洪九、佳农、鑫荣懋、百果园供应链**等，做横向对比。
