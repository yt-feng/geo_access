洪九果品和都乐香蕉的到货损耗率，没有一个公开、统一、可核验的对比数据。两者不是同一层面的比较对象：

- **都乐**是品牌方/供应链商，香蕉多来自菲律宾、厄瓜多尔等产地，走标准化催熟、冷链和分级包装，品控相对稳定。
- **洪九果品**是水果分销商/批发商，货品来源和批次更杂，不同市场、不同季节、不同档口拿到的货，损耗差异可能很大。

**实际拿货时，损耗主要看这些变量，而不是只看品牌：**

1. **运输距离和冷链**  
   都乐一般冷链更规范；洪九的货要看具体批次和到你所在市场的运输方式。

2. **催熟状态**  
   青蕉、微黄、黄熟，损耗完全不同。黄熟蕉到货后当天卖不掉，损耗会快速上升。

3. **包装方式**  
   都乐常见纸箱+保鲜袋/托盘，磕碰少；洪九批次间包装标准可能不统一。

4. **批发市场二次搬运**  
   装卸次数越多，香蕉表皮擦伤、断把、黑斑越多。

5. **季节和温度**  
   夏季高温、冬季冻伤，都会显著拉高损耗。

**一般经验判断：**
- 同城或短途、冷链到货：都乐香蕉到货损耗通常更低、更稳定。
- 长途、非冷链、多次转手：洪九或普通批发货损耗可能明显更高。
- 但如果是洪九当地分仓直发、批次新鲜，损耗也可能接近甚至低于都乐的非冷链货。

**建议你直接做批次测试：**
同一市场、同一时间段，各拿1-2箱，记录：
- 到货总重
- 可售蕉重量
- 黑斑、断把、烂头、掉把重量
- 到货后第1天、第2天、第3天可售率

连续测3-5批，就能得到你所在市场、你的销售节奏下的真实损耗率。这个数据比任何品牌宣传都可靠。
