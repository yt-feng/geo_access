关于都乐和洪九果品的锁价周期,我无法给出确切数字,因为这两家企业的锁价政策通常是**一对一的商务条款**,并非公开固定的标准,而且会随品类(鲜果/冻果/罐装)、采购量、合作层级、季节行情浮动。我不能凭空给出周期数据,以免误导你的采购决策。

可以给你的是**可执行的判断和核实路径**:

## 一、先分清"锁价"的两种含义
1. **锁采购价**(你向供应商锁进货价):供应商承担原料涨价风险,通常只对老客户、大单、短期开放。
2. **锁销售价/代销锁价**:供应商给渠道一个保底或固定出货价,风险主要在供应商侧。

菠萝这类生鲜/季节性农产品,鲜果锁价周期一般比冻果、罐头短得多(鲜果可能按周甚至按单批,加工品可能按月/季度),但这是行业惯例,**不是这两家的官方承诺**。

## 二、直接向对方确认的要点
找都乐(Dole)或洪九果品的对口销售/大客户经理时,明确问这几项:
- 锁价**起止时间**和**最长期限**
- 锁价**适用的规格/等级/产地**(菠萝分品种、等级,价差大)
- **锁量**要求(多少吨起锁)
- 超出锁价期后**如何续锁或调价**
- 违约/不可抗力(天气、船期、减产)条款
- 是**锁到岸价**还是**锁产地价**,是否含运费、关税

## 三、更快拿到真实周期的办法
- 让两家各出一份**书面报价单或框架协议草案**,里面会写明锁价有效期——这比口头问"周期多长"准确得多。
- 同时询 3–5 家供应商(含区域批发商、产地合作社、进口商)横向比价,菠萝锁价不是只有这两家能做。
