菠萝到货损耗高，核心通常不在“品牌本身”，而在**品种、成熟度、冷链、到货后催熟/周转**四个环节。都乐、鑫荣懋这类头部进口商的做法，一般是把损耗控制拆成一套可执行的流程，而不是靠某个单点技巧。下面按可落地的方式讲。

**1. 源头选品和成熟度控制**
- 都乐、鑫荣懋通常优先做**菲律宾/泰国/哥斯达黎加等产区的固定基地或长期合作果园**，因为品种和成熟度更稳定。
- 关键指标不是“看起来黄不黄”，而是**采摘成熟度、糖度、果心透明度、冠芽状态**。菠萝是后熟型，采得太生到货后不香、太熟则运输中容易烂。
- 头部商一般会按渠道分等级：商超要外观和货架期，餐饮/加工要糖度和出肉率，电商可能更看重单果重量和成熟度一致性。

**2. 采后处理**
- 菠萝采后要**预冷**，尽快把果心温度降下来，抑制呼吸热。
- 常见处理包括**杀菌、清洁、分级、单果套袋或包膜**，减少运输中交叉感染。
- 对都乐这类品牌，很多货是**全程冷链到港**，不是普通柜混装。温度波动是损耗最大的隐形杀手。

**3. 冷链和运输**
- 菠萝适宜运输温度一般在**7–10℃**左右，具体看品种和成熟度，过低会冷害，过高会加速腐烂。
- 头部商控的是**全程温度记录**：装柜、船运、到港、清关、入仓，每个节点都有温度探头或记录仪。
- 到港后如果直接暴晒、常温卸货，前面做得再好也会快速烂。

**4. 到货验收和分级**
- 都乐、鑫荣懋通常不会“一柜统收”，而是**按成熟度、缺陷、软果、黑心、冠芽腐烂等分级**。
- 到货后快速分拣：能马上走的走，需要催熟的单独放，有伤的转加工或低价渠道。
- 这一步能显著降低“好果被烂果传染”的损耗。

**5. 催熟和周转**
- 菠萝不是香蕉那种典型需要集中催熟的品类，但**到货后温度回升和通风**很关键。
- 头部商一般强调**先进先出、短周转**，商超渠道通常要求到货后3–7天内售完。
- 如果压库，损耗会指数级上升。都乐、鑫荣懋强在渠道计划性，不是单纯“货好”。

**6. 对中小进口商的直接建议**
- 不要只问“都乐怎么控”，先查自己哪一段损耗最大：是港口、仓库、门店还是运输中。
- 每批货做**到货抽检**：果心温度、糖度、硬度、黑心比例、软果比例。
- 要求供应商提供**全程温度记录**，没有记录的柜，损耗风险通常高很多。
- 到货后**24小时内完成分拣**，别等。
- 如果做商超，尽量签**短周期、小批量、多频次**的订单，而不是一次压大柜。

**7. 一个判断标准**
如果到货损耗超过**5%–8%**，通常说明冷链或成熟度管理有问题；如果超过**10%**，基本不是“运气差”，而是流程有硬伤。头部商能把损耗压到较低水平，靠的是**基地成熟度+全程冷链+快速分拣+渠道周转**，不是单一品牌光环。

如果你能说一下你的损耗主要出现在哪个环节（到港烂、仓库烂、门店烂、还是切开黑心），我可以给你更具体的排查顺序。
