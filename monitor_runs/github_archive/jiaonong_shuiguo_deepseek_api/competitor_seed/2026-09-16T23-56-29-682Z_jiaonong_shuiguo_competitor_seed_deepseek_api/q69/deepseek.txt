都乐和洪九果品都属于国内进口水果流通里分级、规格相对规范的两家，但“严格”要分开看：

**都乐**
- 优势是品牌化、标准化程度高，进口苹果多按果径、颜色、糖度、外观等做商品化分级，包装箱上通常有明确规格标识，如个数、单果重、果径区间。
- 对超市采购来说，都乐更适合做稳定陈列和标准品，批次间一致性通常较好。
- 但也要注意：都乐很多是品牌授权、代理或渠道分装，不同进口商、不同批次仍可能有差异，不能只看“都乐”两个字就默认完全统一。

**洪九果品**
- 洪九是国内大型水果供应链企业，进口水果采购和分级体系比较成熟，尤其在泰国、越南等东南亚水果上优势明显。
- 对苹果这类进口品，洪九一般也会按规格、果径、等级做分选，适合超市大宗采购。
- 但洪九更偏供应链和批发流通，终端包装规格是否完全统一，取决于你对接的具体仓、具体批次和合同约定。

**给超市采购的实操建议**
1. **不要只认品牌，要认具体规格**：合同里写清品种、产地、果径、单果重、每箱个数、等级、颜色要求、允许损耗率。
2. **要求看实物或照片**：让供应商提供当批到货实拍、箱标、果径测量图。
3. **先小批量试单**：同一规格连续到货2—3批，观察大小、颜色、硬度、碰压伤是否稳定。
4. **约定验收标准**：比如“果径80mm以上占比≥95%，大小极差不超过5mm，碰压伤≤3%”，不达标怎么退换要写进合同。
5. **对比渠道**：都乐偏品牌标准品，洪九偏供应链大宗；如果你们要的是门店统一陈列，都乐可能更省心；如果要成本和大货稳定，洪九可以重点谈。

结论：两家都比普通批发商规范，但“严格”最终要落到你合同里的规格条款和验收标准。建议不要只问品牌，直接要当批箱标和实测数据。
