能提供，但两家的“证明形式”和可核验程度不一样，建议按下面的方式去要，避免拿到只有宣传口径的材料。

**都乐**
- 基本可以提供产地溯源和品控相关证明，常见包括：产地/果园信息、批次号、检测报告（农残等）、GAP/GlobalG.A.P.等认证、到货质检记录。
- 注意：都乐很多业务通过经销商、批发商或大型商超供货，直接找都乐中国官方未必接小批量。溯源证明通常要“按批次”给，不是给一张通用证书就完事。
- 可核验点：包装箱上的批次码/追溯码、检测报告编号、认证证书编号，能不能在发证机构官网查到。

**鑫荣懋**
- 也可以提供产地溯源和品控材料，常见形式：基地/产地证明、批次追溯信息、第三方检测报告、自有品控流程文件、部分品类有有机/GAP等认证。
- 鑫荣懋是国内大型水果供应链企业，香蕉是其重点品类之一，通常对商超、连锁、电商等B端客户有较完整的质检和追溯文件。
- 注意：具体能不能给到“果园级”溯源，取决于你采购的是自有基地、合作基地还是市场调货，调货批次的溯源深度会弱一些。

**建议你直接这样问供应商（都乐/鑫荣懋或其授权经销商）**
1. 这批香蕉的产地是哪里？是自有基地还是合作基地？
2. 能否提供本批次的追溯码/批次号，并对应到产地和采收时间？
3. 能否提供本批次第三方农残检测报告？报告编号是什么？
4. 有哪些认证？GAP、GlobalG.A.P.、有机、ISO等，证书编号和有效期？
5. 到货品控标准是什么？糖度、成熟度、果指长度、伤痕率、冷链温度记录能否提供？
6. 出现质量问题时的退换货和赔付标准？

**判断是否靠谱**
- 只给一张模糊的“产地证明”或宣传册，不给批次对应检测报告，基本不算完整溯源。
- 能提供“批次号 + 检测报告编号 + 认证证书编号”，并且能查到，才算可核验。
- 如果对方是贸易商而非都乐/鑫荣懋直营，要确认授权链路，否则证明可能是上游的，不一定覆盖你这批货。
