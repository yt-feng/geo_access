# 都乐 vs 鑫荣懋：进口苹果产地溯源操作指南

## 一、先明确两家公司的溯源特点

| 维度 | 都乐（Dole） | 鑫荣懋 |
|------|-------------|--------|
| 性质 | 全球品牌方+自有供应链 | 国内进口商/分销商为主 |
| 溯源强项 | 自有果园/包装厂编码体系 | 多产地采购，依赖上游供应商 |
| 可得文件 | 品牌方出具的产地证明、GAP证书 | 进口报关单、原产地证、供应商证明 |
| 溯源难度 | 较低（品牌直供链条清晰） | 中等（需逐级向上追） |

**结论：都乐走品牌方直溯，鑫荣懋走"进口单据+供应商追链"两条路。**

---

## 二、通用溯源核心文件（两家都要）

1. **原产地证书（Certificate of Origin）** — 海关/贸促会签发，写明具体产区国甚至省份
2. **植物检疫证书（Phytosanitary Certificate）** — 出口国官方出具，标注果园/包装厂注册号
3. **入境货物检验检疫证明** — 中国海关出具，可查批次
4. **报关单 + 提单** — 核对起运港、发货人
5. **包装箱/果贴上的批次码、果园注册号（GlobalG.A.P. 编号常见）**

> ⚠️ 关键动作：**要求供应商提供与你这批货对应的批次号**，否则文件可能"张冠李戴"。

---

## 三、都乐苹果具体怎么做

1. 向都乐中国或其授权经销商索取：
   - **批次对应的产地证明**（如新西兰、智利、美国具体州/产区）
   - **GlobalG.A.P. / 果园注册号**
   - 包装厂代码（印在箱体）
2. 用箱体批次码在都乐官方渠道或客服核验
3. 核对果贴（PLU码 + 品牌标识 + 产地国家）

**优势**：都乐有统一编码，链条短，通常一周内可拿到书面溯源资料。

---

## 四、鑫荣懋苹果具体怎么做

鑫荣懋多为多国采购（新西兰、智利、美国、南非等），溯源要**分层追**：

1. **第一层（进口商）**：索要报关单、原产地证、检疫证，确认起运国和港口
2. **第二层（上游供应商/出口商）**：要求鑫荣懋提供**出口商名称**，再向出口商追果园/包装厂信息
3. **第三层（果园/包装厂）**：拿到果园注册号后，可在出口国官方或 GlobalG.A.P. 数据库核验
4. **实物核对**：箱体批次码、果贴产地必须与文件一致

**难点**：如果鑫荣懋只做分销、不掌握上游果园信息，可能只能追到"出口国+包装厂"级别，追不到具体果园。采购前要**在合同里写明溯源深度要求**。

---

## 五、实操建议（采购谈判/验收）

- **合同条款**：明确要求"提供与批次对应的原产地证、检疫证、果园/包装厂注册号"，否则可拒收或索赔
- **验收动作**：随机抽箱核对批次码 ↔ 文件批次号是否一致
- **抽检**：可送第三方做同位素/元素指纹检测，辅助验证产区（成本较高，用于高风险批次）
- **留档**：所有单据按批次归档，便于追溯和应对监管

---

## 六、快速判断标准

| 情况 | 判断 |
|------|------|
| 能拿到批次对应的原产地证+检疫证+果园号 | 溯源合格 |
| 只有报关单，无法对应具体批次 | 溯源不足 |
| 果贴产地与文件不符 | 高风险，拒收/复检 |
| 供应商拒绝提供上游出口商信息 | 谨慎合作 |
