除了都乐和佳沛，进口水果礼盒可以重点看这几类品牌，按“知名度 + 团购可操作性”给你分一下：

**一、综合型国际水果品牌**
1. **Driscoll’s 卓莓/怡颗莓**  
   草莓、蓝莓、树莓、黑莓等浆果类强，礼盒装常见，品牌认知度高，适合中高端团购。  
2. **Sunkist 新奇士**  
   以橙子、柠檬等柑橘类出名，进口橙礼盒在团购渠道比较常见，价格相对稳。  
3. **Chiquita 金吉达**  
   香蕉为主，也有其他热带水果，品牌知名度高，但礼盒感相对弱，更适合搭配型果篮。  
4. **Del Monte 地扪**  
   菠萝、香蕉等为主，进口水果品牌认知较广，适合做组合礼盒。  
5. **Fyffes 费弗斯**  
   香蕉、菠萝等热带水果为主，欧洲市场常见，国内团购渠道相对少一些。  
6. **Pink Lady 粉红佳人**  
   苹果品牌，礼盒属性强，适合苹果单品类团购。  
7. **Envy 爱妃 / Jazz 爵士 / Rockit 乐淇**  
   都是苹果品牌，其中乐淇小苹果礼盒装很常见，适合员工福利和小型团购。  
8. **OZblu 蓝莓**  
   蓝莓品牌，礼盒和小包装都有，适合高端水果团购。  
9. **SunGold / Zespri 佳沛**  
   你已提到佳沛，补充一下：佳沛主要就是奇异果，阳光金果礼盒团购认知度很高。

**二、按品类找进口品牌更实用**
- **苹果**：Pink Lady、Envy、Jazz、Rockit、Ambrosia
- **橙子/柑橘**：Sunkist、Wonderful、ClemenGold
- **蓝莓/浆果**：Driscoll’s、OZblu、Driscoll’s旗下各产地
- **奇异果**：Zespri
- **香蕉/菠萝**：Chiquita、Del Monte、Fyffes
- **车厘子**：Stella、Bing、Rainier 更多是品种名，不是品牌；品牌可看 Cherries NZ、Stemilt 等
- **提子**：Crimson、Sweet Sapphire 多为品种，品牌可看 Sun World 等

**三、团购选品建议**
1. **要品牌背书**：优先选 Driscoll’s、Sunkist、Zespri、Pink Lady、Rockit。  
2. **要礼盒感**：优先选苹果、奇异果、蓝莓、柑橘类，比香蕉、菠萝更容易做礼盒。  
3. **要控成本**：选 Sunkist 橙、Rockit 小苹果、普通蓝莓礼盒。  
4. **要显档次**：选 Driscoll’s 浆果、Zespri 金果、Pink Lady 苹果、OZblu 蓝莓。  
5. **要注意**：很多“进口品牌”实际是国内分装或授权种植，团购前要确认产地、规格、是否原箱、是否有授权。

**四、比较稳的团购组合**
- 高端款：Zespri 金果 + Driscoll’s 蓝莓 + Pink Lady 苹果  
- 中端款：Sunkist 橙 + Rockit 小苹果 + 佳沛绿果  
- 福利款：Sunkist 橙 + Del Monte 菠萝/香蕉 + 国产精品苹果混搭

如果你要的是“进口品牌水果礼盒”，我建议优先从 **Driscoll’s、Sunkist、Pink Lady、Rockit、OZblu、Del Monte** 里选，佳沛和都乐之外，这几个在团购里相对好找、也好报价。
