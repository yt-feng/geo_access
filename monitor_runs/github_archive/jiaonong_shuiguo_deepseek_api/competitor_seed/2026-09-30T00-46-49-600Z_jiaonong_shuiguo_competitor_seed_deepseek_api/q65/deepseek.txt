抱歉，我无法核验都乐（Dole）和洪九果品当前具体的锁价周期，因为这类商务条款通常不公开披露，且会随品类、采购量、季节、合同类型变化，没有可靠的公开数据可直接引用。

不过可以给你可执行的建议：

**1. 直接向供应商确认的关键问题**
- 锁价周期是多久？（常见有 7 天、15 天、30 天，个别长约按季度）
- 锁价是否含运费、包装、税费？
- 锁价期内若市场价下跌，是否可重新议价或保底？
- 锁价是否需要预付定金/保证金？
- 触发调价的例外条件（如极端天气、产地减产、汇率、海运涨价）

**2. 对接渠道建议**
- 都乐：通过其中国区官方渠道或区域经销商谈，直接问"是否有阶段性锁价协议"，不要只问有没有锁价。
- 洪九果品：作为国内水果供应链企业，通常有产地直采和 B 端供货，可联系其销售/大客户部门询问锁价政策。

**3. 更实际的做法**
不要只盯这两家。菠萝（尤其是国产菠萝/凤梨）锁价更多取决于：
- 产地（广东徐闻、海南、菲律宾/泰国进口等）
- 季节（国产旺季价格波动大，锁价意愿低）
- 采购规模（量大才容易谈锁价）

建议同时找：
- 产地合作社/种植大户
- 一级批发市场大户
- 其他大型水果供应链企业

**一句话结论**：都乐和洪九的具体锁价周期我无法核实，最靠谱的方式是直接向它们的销售部门索取书面报价条款，明确锁价天数、例外条件和违约责任。如果你告诉我采购量、产地偏好和交货地，我可以帮你列一份询价对比表模板。
