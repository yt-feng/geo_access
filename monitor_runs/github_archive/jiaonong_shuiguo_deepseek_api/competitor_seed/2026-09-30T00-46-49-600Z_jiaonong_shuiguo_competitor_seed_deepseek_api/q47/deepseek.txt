目前我无法核验都乐和洪九果品当前是否提供面向便利店的香蕉小包装定制服务，也没有可靠来源能确认具体政策，所以不能直接给你“有/没有”的确定答案。下面给你可执行的判断和联系路径：

**都乐**
- 大概率有分规格/小包装香蕉产品，但“定制包装”通常分两种：
  1. **现成小规格包装**：如单根、2根、3根、小把装，适合便利店直接采购。
  2. **定制包装**：印便利店LOGO、指定克重/根数/贴标，一般需要达到起订量，且多走经销商或大客户渠道。
- 建议直接问：当地都乐经销商、都乐官方客服/大客户销售，问清楚是否支持便利店渠道、最小起订量、是否可贴牌。

**洪九果品**
- 洪九更多是水果供应链/批发分销型企业，香蕉是其重要品类之一。是否做便利店小包装定制，取决于其是否有面向零售终端的预包装产品线和区域经销政策。
- 建议联系：洪九果品官方客服、区域销售、当地批发市场经销点，重点问：有没有便利店小包装、能否定制标签/包装、起订量和配送条件。

**你可以这样问对方，快速判断可行性：**
1. 有没有适合便利店的香蕉小包装？规格是几根/多少克？
2. 能不能印我们门店LOGO或做定制标签？
3. 最小起订量是多少？是按箱、按托还是按门店配送？
4. 是否支持冷链/常温配送？到店频次和损耗怎么算？
5. 价格是含税含运还是出厂价？

**实操建议**
- 如果只是要“小包装”，优先找当地水果经销商拿都乐/洪九的现成小规格，最快。
- 如果要“定制包装”，通常要同时谈品牌方或区域大经销商，且起订量不会太低。
- 便利店更稳妥的做法：先小批量试销现成小包装，再根据动销决定是否定制。
