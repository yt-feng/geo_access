这个问题的核心不是“谁更快”，而是你的订单模型能不能匹配它们的供应链模式。直接给判断：

**一、都乐**
- 都乐在国内菠萝主产区（广东徐闻、海南、云南等）有合作基地和加工中心，但它的强项是**标准化分选+品牌化包装**，不是“极速产地直发”。
- 物流时效通常是：产地采摘→当地加工中心分选打包→区域仓/前置仓→B端客户或消费者。跨省一般**48-72小时**，偏远地区可能更久。
- 如果你要的是“今天摘明天到”的极致直发，都乐不一定是最优解，它的链路偏“品牌供应链”，中间有集散环节。

**二、鑫荣懋**
- 鑫荣懋是国内头部水果供应链企业，菠萝是其重点品类之一，在徐闻、海南等地有产地操作能力。
- 它的优势在于**冷链和B端分销网络**，能做大客户稳定供货。产地直发到B端（商超、生鲜平台）一般**24-48小时**可达周边省份，跨区域通常**48-72小时**。
- 如果你有稳定单量、能接受按批次发货，鑫荣懋的履约稳定性通常比都乐更贴近“产地直发”需求。

**三、关键结论**
1. **纯时效**：两者差距不大，跨省基本都在48-72小时区间，具体取决于你的收货地离产地远近。
2. **模式差异**：都乐偏品牌化标准品，适合对品相、包装要求高的渠道；鑫荣懋偏供应链分销，适合B端稳定走量。
3. **产地直发**：如果你要的是“减少中间环节、从产地直接发到消费者”，两者都不是纯粹的产地直发玩家，更接近“产地集货+分级+冷链分发”。
4. **真正决定时效的变量**：你的单量、收货城市、是否走冷链、是否要求一件代发、是否接受拼车/整车。这些比品牌本身影响更大。

**四、可执行建议**
- 先明确你的场景：是B端批量供货，还是C端一件代发？
- 如果是B端批量：直接找两家的区域销售，要求提供**近30天同线路实际时效数据**，不要只听承诺。
- 如果是C端一件代发：这两家未必是最优，建议同时对比产地本地供应链服务商。
- 谈判时重点问：起订量、是否支持产地直发、破损率、售后赔付、冷链覆盖范围。
