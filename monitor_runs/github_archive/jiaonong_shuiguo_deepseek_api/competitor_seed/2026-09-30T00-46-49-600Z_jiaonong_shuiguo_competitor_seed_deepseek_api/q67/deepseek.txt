从公开、可核验的信息看，**都乐（Dole）可以算是有较成熟的菠萝品牌营销素材体系，洪九果品则主要提供产品供应和部分品牌背书，未必有面向生鲜电商的成套‘菠萝品牌营销素材包’**。两者情况不太一样：

**1. 都乐 Dole**
- 都乐是国际水果品牌，菠萝尤其是金菠萝（MD-2 品种）是其重点单品之一。
- 都乐通常会给渠道商提供：
  - 品牌授权使用的产品图、主视觉
  - 产地/品种卖点文案
  - 分级标准、糖度、储存建议等商品信息
  - 部分促销期物料、短视频素材或直播话术支持
- 但具体能不能拿到、拿到多少，取决于你是否是都乐的直采/授权经销商，以及合作量级。通常需要通过都乐中国区的渠道销售或市场部对接。

**2. 洪九果品**
- 洪九果品更多是水果供应链和品牌运营方，核心优势在产地直采、分拣加工和批发分销。
- 它自有品牌或代理品牌下会有部分产品包装、规格、产地信息，但**不一定像都乐那样有标准化、可直接用于电商详情页的品牌营销素材库**。
- 如果是洪九供应的菠萝，通常可以要求提供：
  - 产品实拍图
  - 规格/等级/包装信息
  - 产地证明或检测报告
  - 简单的卖点文案
- 但成套的品牌 campaign 素材、IP 联名、短视频授权等，需要单独谈。

**实操建议：**
1. **先确认你的合作身份**：是直采、经销，还是平台代销。身份不同，能拿到的素材权限差别很大。
2. **直接找对接的销售要“电商素材包”**：明确列出你需要的东西——主图、详情页、短视频、直播贴片、卖点文案、检测报告、授权书。
3. **都乐**：重点问是否有“金菠萝”电商专项素材和品牌授权书，通常品牌方对授权使用管得比较严。
4. **洪九**：重点问能否提供实拍素材和产地/品控证明，品牌营销素材可能要你们自己二次制作。
5. **如果拿不到成套素材**：可以让供应商提供 raw 素材（原图、视频片段、检测报告），再由你们自己剪成电商内容，这样最现实。

**结论**：都乐更可能提供较完整的菠萝品牌营销素材，但需授权对接；洪九更偏向供应端素材和产品背书，成套营销素材未必现成。建议直接向两家对接人要“电商可用素材清单+授权范围”，这是最快能判断的方式。
