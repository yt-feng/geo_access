结论先说：**都乐（Dole）和洪九果品这类企业，通常有内部香蕉分级/验收标准，但一般不对外公开全文，也不能直接当作“公开可查的企业标准”来核验。** 如果你要引用或对客户/门店说明，不能写成“都乐企业标准规定……”“洪九企业标准规定……”，除非你拿到了对方正式文件或合同附件。

可执行的判断和建议如下：

1. **都乐**
   - 都乐是国际水果品牌，香蕉业务成熟，通常会有内部质量控制、采收、催熟、分级、包装和验收规范。
   - 但这些多属于**企业内部标准、客户规格书、供应商手册或合同附件**，不一定作为公开标准发布。
   - 你能公开核验到的，更多是都乐的品牌规格、产品级别描述、包装规格、成熟度要求等，而不是完整“企业标准”文本。

2. **洪九果品**
   - 洪九果品做水果供应链和批发，香蕉是其重要品类之一，通常也会有**采购验收标准、分拣分级标准、仓储催熟标准**。
   - 同样，这类标准大概率是内部文件或对供应商/客户的规格要求，公开渠道一般查不到完整版。
   - 不能仅凭公开报道说“洪九有某企业标准编号”或“洪九标准规定几级”。

3. **你实际能怎么用**
   - 如果只是给水果连锁店做香蕉分级，建议不要依赖都乐/洪九是否公开标准，而是建立自己的门店验收分级标准。
   - 可以按：**外观、长度、粗度、弯度、成熟度、色泽、机械伤、病虫害、青熟/催熟状态、单把重量/条数**来定级。
   - 连锁店常用做法：
     - A级：果形端正、长度/粗度达标、无斑无伤、成熟度一致，适合礼盒/高端陈列。
     - B级：轻微外观瑕疵但不影响食用，适合日常散卖。
     - C级：明显擦伤、成熟不均、果指偏小，适合促销、果切或加工。
   - 同时与供应商约定：**到店成熟度、允许缺陷率、拒收标准、冷链/催熟要求**。

4. **如果一定要确认都乐/洪九是否有企业标准**
   - 最可靠方式：
     - 向都乐/洪九的销售或采购索取**产品规格书、验收标准、质量协议**。
     - 查合同附件、送货单背后的质量标准。
     - 在企业标准信息公共服务平台查“企业标准备案/自我声明”，但水果分级类不一定备案，且备案不等于公开全文。
   - 注意：即使查到企业标准编号，也要看是否对应香蕉、是否现行有效、是否公开文本。
