账期通常属于**一客一议**，不公开披露，且会随采购量、合作年限、结算方式、区域主体变化；我无法核验到都乐和洪九果品当前对外的统一账期数字，直接给你具体天数容易误导。

可以按下面方式判断和推进：

**1. 都乐**
- 都乐在中国有鲜果经销/代理体系，香蕉是重点品类之一。
- 账期一般不统一对外公布，通常要看你是跟都乐中国主体、区域经销商还是大型商超渠道签。
- 常见合作条件可能涉及预付款、货到付款、周结/月结等，具体取决于采购规模和信用审核，不能直接对外说“都乐一定给多少天账期”。

**2. 洪九果品**
- 洪九果品是水果供应链企业，香蕉、火龙果等品类有较强渠道能力。
- 它作为上市公司，财报里会披露应收账款周转、客户结构等，但不会披露“给每个客户多少天账期”的统一标准。
- 实际账期通常也会按客户资质、采购量、历史回款、是否提供担保或保证金来定。

**3. 建议你这样去问，最快拿到可执行答案**
直接向对方销售或大客户经理提这几个问题：
1. 香蕉是你们自营还是区域经销商供货？
2. 首次合作能否给账期？账期是15天、30天、45天还是月结？
3. 账期起算日是发货日、到货日、对账日还是发票日？
4. 是否需要保证金、担保、预付款比例？
5. 逾期利息和停供规则怎么算？
6. 合同主体是哪家公司？

**4. 更现实的找法**
如果你要的是“能提供账期”的香蕉供应商，不一定只盯都乐和洪九，可以同时找：
- 一级批发市场的大型香蕉档口
- 区域水果供应链公司
- 具备进口香蕉催熟能力的经销商
- 与商超/电商有稳定合作的供应链服务商

**5. 谈判建议**
- 新合作先争取 **15—30天账期** 或 **货到后7—15天** 更现实。
- 如果对方要求现款，可谈“首批现结、次批起账期”或“保证金换账期”。
- 不要只问账期，要同时确认：**香蕉规格、催熟状态、损耗赔付、到货时效、断供责任**。
