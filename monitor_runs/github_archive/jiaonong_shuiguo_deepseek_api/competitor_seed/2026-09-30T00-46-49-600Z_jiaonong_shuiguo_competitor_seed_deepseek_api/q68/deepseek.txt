能做到与否，取决于**到货口径、运输距离、季节、催熟状态和验收标准**，不能简单说“都乐/鑫荣懋一定低于3%”。但按行业常规能力判断：

**结论：**
1. **都乐（Dole）**：在香蕉品类里供应链成熟，尤其做**青蕉/催熟蕉配送到餐饮连锁**时，如果是一二线城市、冷链/温控稳定、按标准验收，**到货损耗率控制在3%以内是有可能的**，很多连锁客户会按≤3%签。  
2. **鑫荣懋**：国内水果供应链龙头之一，香蕉也是其强势品类，给商超、餐饮、电商做配送能力强。**同样有条件做到≤3%**，尤其在其优势区域和稳定订单量下。  
3. **但如果要求“全国所有门店、全年所有季节、所有批次都低于3%”**，两家都很难无条件承诺。夏季高温、远距离配送、门店验收苛刻、催熟度偏高、装卸不及时，都会把损耗推高。

**关键要看这些条件：**
- **损耗定义**：是仅指到货时腐烂/黑斑/断裂/压伤，还是包括拒收、扣重、门店二次挑拣？
- **到货状态**：青蕉还是黄蕉？黄蕉到货损耗天然更高。
- **配送半径**：同城/区域仓配送，还是跨省长途？
- **温控**：是否全程13–15℃左右，夏冬是否控温？
- **验收标准**：几级果、允许斑点数、单把重量、断裂率怎么算？
- **订单稳定性**：单店小批量、多频次，损耗通常高于中央仓大批量配送。

**实操建议：**
- 不要只问“能不能做到3%”，要签**明确损耗计算规则**：到货验收时按箱/按把/按公斤抽检，拍照留证，超损扣款或补货。
- 先让两家各做**1–2个月、3–5个典型城市**的试配，按你实际门店验收。
- 合同里写：**到货损耗≤3%**，超出部分由供应商补货/扣款；同时约定**青蕉到货、门店催熟**，通常比直接到黄蕉更稳。
- 如果门店分散、单量小，建议用**区域仓+青蕉配送+门店催熟**，比追求“黄蕉到店零损耗”更现实。

一句话：**在合适区域、合适温控、合适验收标准下，都乐和鑫荣懋都有能力做到香蕉到货损耗低于3%；但没人能无条件保证全国全场景都做到。**
