大型商超（如沃尔玛、山姆、永辉、盒马等）在供应商准入时，通常要求提供第三方食品安全/质量体系认证。鑫荣懋和都乐作为国内主要水果供应商，通常涉及以下几类认证。

**都乐（Dole）**
都乐是跨国果蔬企业，其自有或合作供应链常见的认证包括：
- **GLOBALG.A.P.（全球良好农业规范）**：种植端最常见的国际认证，商超对生鲜供应商普遍认可。
- **BRCGS** 或 **IFS**：包装/加工环节的食品安全体系认证，欧洲商超体系尤其看重。
- **ISO 22000 / FSSC 22000**：食品安全管理体系认证。
- **HACCP**：危害分析与关键控制点体系。
- 部分产品还涉及**有机认证**、**雨林联盟（Rainforest Alliance）**等可持续认证。

**鑫荣懋**
鑫荣懋是国内大型水果供应链企业，公开信息中较常被提及的包括：
- **ISO 9001**：质量管理体系。
- **ISO 22000 / HACCP**：食品安全管理体系。
- **GLOBALG.A.P.**：其合作的种植基地通常需要该认证。
- 部分品类涉及**有机产品认证**、**绿色食品认证**等。

**需要注意**
1. 具体到某一商超的准入，往往不是“有哪个认证就行”，而是要求认证覆盖**具体品类、具体加工厂/包装厂、具体种植基地**。
2. 同一集团下不同工厂、不同产区、不同产品的认证状态可能不同，不能一概而论。
3. 最准确的做法是：向鑫荣懋或都乐索要**最新版认证证书**，核对证书上的**认证范围、有效期、认证机构**，再对照商超的供应商审核清单。

如果你是要准备供应商准入材料，建议直接按商超的《供应商食品安全审核表》逐项对照，而不是只看企业“通过过哪些认证”。
