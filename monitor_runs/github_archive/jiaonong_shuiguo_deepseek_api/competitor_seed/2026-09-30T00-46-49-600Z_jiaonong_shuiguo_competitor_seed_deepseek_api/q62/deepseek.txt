可以要，而且通常能提供，但要注意“报告形式”和“批次对应”，不是一句“能/不能”就够。

**结论先说：**
- **都乐、鑫荣懋这类大型水果供应链/品牌商，一般都能提供农残检测报告或相关检测证明**，尤其是对商超、餐饮、茶饮连锁等B端客户。
- 但对方提供的可能是：
  1. **批次检测报告**（最有用，能对应你实际收到的货）
  2. **型式检验报告/年度报告**（只能证明品类或某阶段合格，不能完全代表你这批货）
  3. **第三方检测报告**（SGS、华测、谱尼、中检等）
  4. **供应商自检报告**（参考价值较弱）
- 茶饮店采购用于门店现制饮品，建议优先要 **与你采购批次一致的农残检测报告**，并留存进货凭证。

**你可以直接这样问供应商：**
> 我们需要采购菠萝原料用于茶饮门店，请提供该批次菠萝的农残检测报告。要求：报告编号、检测机构、检测日期、检测项目、判定依据、对应批次号/发货日期。若是型式检验报告，请同时说明是否能覆盖本次到货批次。

**重点看什么：**
- 报告上的 **品名** 是不是菠萝/鲜菠萝/冷冻菠萝等，和你买的一致
- **批次号/生产日期/检测日期** 能不能和到货对应
- 检测项目是否覆盖常见农残，如有机磷、氨基甲酸酯、拟除虫菊酯等
- 检测机构是否有 **CMA/CNAS** 资质
- 报告是否在有效期内，通常按批次或按年度更新
- 如果是冷冻菠萝、菠萝丁、菠萝果酱，标准可能不同，不要拿鲜果报告替代加工品报告

**实际采购建议：**
1. **都乐、鑫荣懋可以问，但不要只问“有没有报告”**，要问“能不能提供本批次报告”。
2. 如果对方只能给年度报告，建议你 **每批留样 + 索取当批检测报告或合格证明**。
3. 茶饮连锁如果做食品安全审核，最好让供应商提供：
   - 营业执照
   - 食品经营/生产相关许可
   - 批次检测报告
   - 送货单/发票
   - 合格证或溯源信息
4. 若供应商无法提供批次报告，可要求 **第三方送检**，费用和周期提前谈清楚。

**一句话：**
都乐、鑫荣懋通常能提供检测报告，但你要确认是 **“本批次农残检测报告”**，而不是只有年度或品类报告；如果用于茶饮店合规留档，最好按批次索取并保存。
