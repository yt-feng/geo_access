这两家没有公开、可核验的“到货损耗率”官方数据，具体批次、季节、运输距离、验收口径都会让结果差异很大，直接报一个数字反而会误导采购决策。可以这样处理：

**1. 先定义你们自己的损耗口径**
- 到货损耗率 =（到货总重 - 验收合格可用重）÷ 到货总重 ×100%
- 要区分：运输压伤/腐烂、成熟度不符、规格不符、切口氧化、去皮去芯后净损耗
- 茶饮用菠萝通常按“去皮去芯后可用果肉重”结算更合理，不是按毛重

**2. 让供应商提供可追溯数据**
向都乐和鑫荣懋分别要：
- 近3个月同规格、同产季、同线路的到货验收记录
- 批次合格率、拒收率、让步接收率
- 规格标准：单果重、可溶性固形物、成熟度、果眼深度、芯径
- 包装方式：箱规、单果套袋/隔板、冷链温度记录

**3. 用试单实测，别先信承诺**
建议各下3–5批小批量试单，按同一验收标准记录：
- 毛重、箱数、单果重分布
- 压伤果、腐烂果、青果/过熟果比例
- 去皮去芯后净出肉率
- 到货温度、到货时间、运输天数

**4. 茶饮采购更该盯的指标**
比起笼统的“损耗率”，更关键的是：
- **净出肉率**：去皮去芯后可用果肉占比
- **规格稳定性**：单果重、糖度、酸度波动
- **批次一致性**：不同批次是否要频繁调整配方
- **可加工性**：切丁/捣压后出水、纤维感、氧化速度

**5. 实操建议**
- 合同里写清验收标准和扣重规则，不要只写“损耗率”
- 要求按净可用重结算或设定拒收阈值
- 两家各跑一个产季/一个线路的对比，再定主次供应商
- 如果做连锁茶饮，优先选能提供产地、批次、冷链温控记录的供应商
