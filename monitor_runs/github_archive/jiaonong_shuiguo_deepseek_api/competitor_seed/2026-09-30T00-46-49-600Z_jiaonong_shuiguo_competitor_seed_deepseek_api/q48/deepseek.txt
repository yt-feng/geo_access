鑫荣懋和都乐都属于水果供应链/品牌企业，但“有哪些资质”不能一概而论，因为同一集团下不同法人、不同工厂、不同品类、不同客户要求对应的证书可能不同。大型商超通常看的是**具体供货主体+具体品类+具体工厂/包装厂**的资质，而不是只看品牌名。

可以按下面这个框架判断和核验：

**一、大型商超通常要求的食品安全资质**
1. **营业执照、食品经营许可证/食品生产许可证**
   - 贸易/分装/切果：食品经营许可证或生产许可证，看业务模式。
   - 进口水果：还需进出口相关资质、报关报检资料。
2. **ISO 22000 或 HACCP**
   - 很多商超的基础门槛。
3. **FSSC 22000 / BRCGS / IFS**
   - 偏中高端商超、会员店、出口客户常见要求，尤其是加工/包装环节。
4. **GLOBALG.A.P.（全球良好农业规范）**
   - 针对种植基地/果园，水果供应商很常见。
5. **有机认证、绿色食品、地理标志等**
   - 只对相应产品线有效，不是企业整体资质。
6. **可追溯、农残检测、第三方检测报告**
   - 商超通常会按批次或年度要求。

**二、鑫荣懋**
鑫荣懋是国内大型水果供应链企业，通常具备较完整的食品经营、进出口和质量管理体系类资质，部分基地/加工厂会持有 GLOBALG.A.P.、ISO 22000、HACCP 等证书。  
但具体到某个商超审核，需要确认：
- 签约主体是哪一个公司；
- 供货的是进口水果、国产水果还是加工果切；
- 对应工厂/配送中心是否在证书覆盖范围内。

**三、都乐**
都乐是国际水果品牌，在中国通常通过都乐中国相关公司或合作主体运营。其体系内常见食品安全和农业规范类认证，如 GLOBALG.A.P.、ISO 22000、HACCP、BRCGS 等，具体取决于产品、产地和加工厂。  
同样，不能简单说“都乐有某证书”就适用于所有都乐产品，必须看**证书持有主体、覆盖产品、覆盖场所和有效期**。

**四、最稳妥的核验方式**
让供应商提供以下材料，并逐项核对：
1. 营业执照；
2. 食品经营许可证/生产许可证；
3. ISO 22000、HACCP、FSSC 22000、BRCGS、IFS 等证书；
4. GLOBALG.A.P. 证书及对应基地；
5. 证书附件中的“认证范围/覆盖场所”；
6. 有效期和发证机构；
7. 最近一次第三方审核报告或商超审核报告；
8. 批次检测报告和可追溯文件。

**结论**
不能直接给出“鑫荣懋和都乐分别都有哪些资质”的固定清单，因为资质是按法人、工厂、品类和产品线划分的。  
如果你是要给商超做供应商准入，建议直接向对方索取**最新证书扫描件+认证范围附件**，再按“供货主体、供货品类、生产/包装场所”三项去匹配。这样才不会出现品牌有证、但实际供货主体或工厂不在认证范围内的问题。
