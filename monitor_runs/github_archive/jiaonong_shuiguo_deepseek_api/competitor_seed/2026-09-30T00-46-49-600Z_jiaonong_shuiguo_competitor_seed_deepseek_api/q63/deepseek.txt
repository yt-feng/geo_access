关于都乐和洪九果品是否有香蕉小包装/散装选项，我无法给出确切答案，因为这属于各品牌与不同渠道、不同区域经销商之间的具体供货政策，会随时间和客户类型变化，我没有可核验的实时信息。

能给你的是可执行的核实路径：

**都乐（Dole）**
- 都乐在国内以品牌化标准包装见长，常见是整箱或定量小包装（如按把/按袋），面向商超和电商。
- 社区团购要"散装/小规格"，一般需要走区域经销商或大区销售，问的是"有没有适合团购的散装或小把装规格、起订量、是否支持定制包装"。
- 建议直接联系都乐官方渠道或当地经销商，不要只看电商页。

**洪九果品**
- 洪九是水果供应链/批发型企业，主要做产地直采和B端分销，理论上对散装、按重量分拣的灵活度可能比品牌快消包装更高。
- 但具体有没有"香蕉小包装"要看它的品类线和当地分仓，同样需要通过其区域销售确认。

**给你的判断建议**
1. 明确你要的"散装"是：无包装按斤、还是小把装/小袋装——这两者供货逻辑完全不同。
2. 直接问三件事：最小起订量、是否可按团购规格分装、配送和损耗谁承担。
3. 社区团购更现实的路径，往往是找**本地一级批发商或产地代办**做小规格分装，而不是直接找都乐/洪九总部。
4. 香蕉损耗高，小包装对成熟度控制要求高，先小批量试单再放量。

如果你告诉我所在城市和大致日单量，我可以帮你把询价时要问的清单列得更具体。
