菠萝（凤梨）在国内的稳定供应品牌，除了都乐（Dole），主要还有以下几类，具体取决于你要的是**鲜果批发、商超零售，还是加工原料**：

**1. 国际水果巨头**
- **佳农（Goodfarmer）**：国内菠萝/凤梨供应链很强，商超和批发渠道常见，菲律宾、泰国、国产凤梨都有。
- **鑫荣懋（Joywing Mau）**：旗下有“欢乐果园”等品牌，商超渠道覆盖广，菠萝供应稳定。
- **百果园**：自有渠道为主，也有“耙耙柑”之外的凤梨品类，门店稳定供应。

**2. 国产凤梨主产区品牌/企业**
- **海南凤梨**：如“天地人”“诺丽”“台壹号”等，海南澄迈、万宁、东方等地供应较稳定，季节集中在春夏季。
- **广东徐闻菠萝**：徐闻是最大产区，当地有“徐闻菠萝”区域公用品牌，很多合作社和贸易商稳定供货。
- **台湾凤梨**：如“台农17号（金钻）”，但受政策影响，大陆市场供应不稳定，需看渠道。

**3. 电商/生鲜平台自有品牌**
- **盒马**：有自有品牌凤梨，供应链较稳定。
- **叮咚买菜、美团买菜**：常有固定供应商，但品牌不突出，更多是产地直采。
- **京东生鲜、天猫超市**：佳农、都乐、鑫荣懋等品牌常见。

**4. 加工/餐饮渠道**
- 如果是做果汁、果切、烘焙原料，常用**佳农、鑫荣懋、安德利、国投中鲁**等，但后两者更多是浓缩果汁方向。

**判断稳定供应的关键：**
- 看是否**产地直采+冷链**，而不是单纯贴牌。
- 看**全年供应能力**：国产凤梨有季节，进口凤梨（菲律宾、泰国）可补全年。
- 看**规格一致性**：商超和餐饮更看重单果重量、糖度、成熟度稳定。

如果你是要做**批发或长期采购**，优先谈**佳农、鑫荣懋、都乐**这三家，供应链最稳；如果是**区域零售**，可以叠加**海南/徐闻产地合作社**做差异化。
