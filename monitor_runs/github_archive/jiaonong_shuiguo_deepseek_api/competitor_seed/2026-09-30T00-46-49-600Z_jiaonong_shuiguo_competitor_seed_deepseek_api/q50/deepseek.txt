可以谈，但要把“品牌联名”和“定制礼盒”分开看，否则容易误判可行性。

**1. 都乐和洪九果品能不能做品牌联名？**
- **都乐：** 可以做联名/授权合作，但门槛较高。都乐是国际水果品牌，国内一般通过都乐中国或其授权经销商/服务商操作。联名通常要求有品牌曝光、渠道资源、采购量或营销资源，不是单纯“印个logo”就能批。适合企业礼品、平台联名、节日礼盒等场景。
- **洪九果品：** 也可以谈，但洪九更偏供应链和批发流通，品牌联名不是它的标准业务。它更强在货源、分拣、包装和渠道履约。联名能不能做，取决于具体对接的是总部、区域公司还是经销商，以及采购规模和合作方式。
- **两者互相联名？** 都乐 × 洪九这种“双品牌联名”理论上可以谈，但实际落地难度大。因为双方都是水果品牌/供应链方，联名价值不如“水果品牌 × 企业IP/平台IP/节日IP”清晰。更常见的做法是：都乐或洪九作为**产品供应/品牌背书方**，你的企业或礼品公司作为**定制方**，做“联合呈现”而不是严格意义的品牌联名。

**2. 礼品团购定制礼盒的可行路径**
- **路径A：直接找品牌方**
  - 都乐：找都乐中国或授权服务商，谈企业团购、节日礼盒、联名授权。
  - 洪九：找总部或区域销售，谈定制包装、贴牌、组合礼盒。
  - 适合采购量大、有品牌营销需求的企业。
- **路径B：找品牌经销商/礼品服务商**
  - 很多经销商手里有都乐、洪九的货，也能做礼盒定制。
  - 优点是灵活、起订量低；缺点是“联名”通常只能做渠道联名，不一定能拿到品牌官方授权。
- **路径C：自己做礼盒，采购品牌水果**
  - 你设计礼盒，里面放都乐或洪九的水果。
  - 外包装可以写“精选都乐/洪九果品”等，但**不能未经授权使用品牌logo做联合商标**，否则有侵权风险。
  - 这是最容易落地的方式。

**3. 关键判断标准**
- **采购量：** 联名通常有起订量要求，几千盒到几万盒不等，具体看品牌和渠道。
- **授权范围：** 是只允许用logo，还是允许写“联合品牌”？授权期限、区域、渠道都要明确。
- **费用：** 可能有品牌授权费、设计审核费、最低采购额、保证金等。
- **审核周期：** 品牌方审核包装、文案、logo使用通常需要时间，节日礼盒要提前1-2个月启动。
- **渠道限制：** 有些品牌联名款不能低价电商销售，只能企业团购或指定渠道。

**4. 实操建议**
1. 先明确你的需求：是只要定制礼盒，还是必须官方联名？
2. 如果只是礼品团购，优先找都乐/洪九的**授权经销商或礼品渠道商**，比直接找品牌总部更快。
3. 如果要官方联名，准备一份合作方案：采购量、渠道、曝光资源、联名形式、预算。
4. 包装设计前先确认品牌授权边界，避免先设计后审核不通过。
5. 合同里写清：授权范围、logo使用规范、审核流程、交货周期、售后和损耗责任。

**结论：**
都乐和洪九果品都可以谈定制礼盒，都乐做官方联名的可能性相对更高，但门槛也更高；洪九更偏供应链定制。两者互相联名不是常规操作。对大多数礼品团购来说，更现实的是找授权经销商做“品牌水果+定制礼盒”，而不是追求严格的双品牌官方联名。
