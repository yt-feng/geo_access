直接说结论：**没有一个可公开核验的、固定统一的“洪九果品 vs 都乐香蕉”到货损耗率对比数据**。损耗率取决于批次、季节、产地、运输距离、冷链条件、包装方式、到货成熟度、批发市场验收标准等，不同市场、不同档口、不同时间差异会很大。谁给你一个精确到小数点的对比，基本都不可信。

但可以给你一个**可执行的判断框架**，按这个去问、去看、去试，比要一个“标准答案”有用得多。

**一、两家货的本质差异**
- **都乐香蕉**：品牌化程度高，通常有较稳定的产地、加工催熟和冷链体系，货品标准化程度相对高。到货一致性通常更好，但价格也更高。
- **洪九果品**：以水果供应链和批发为主，香蕉是其重要品类之一，但货源、批次、渠道差异可能更大。不同市场拿到的货，可能来自不同产地和加工厂，损耗表现不一定统一。
- **关键点**：都乐是品牌+体系，洪九更偏供应链平台/渠道。比较损耗率时，不能只比品牌，要比**具体批次和到货状态**。

**二、到货损耗率一般看哪些环节**
香蕉到货损耗通常不是单一数字，要拆开看：
1. **运输损耗**：压伤、擦伤、断指、脱把。
2. **催熟损耗**：青转黄不均匀、青硬、软烂、裂口。
3. **仓储损耗**：温度过高或过低导致黑心、发酸、过快成熟。
4. **验收扣重**：批发市场按件、按箱、按斤扣损耗，规则不同。
5. **尾货损耗**：当天卖不完，第二天降价或报废。

**三、怎么在批发市场实际对比**
你可以用同一市场、同一时间段、同一验收标准去试：
1. **各拿一批同规格货**：比如同为中把、同产地、同催熟度、同箱重。
2. **记录到货原始重量和件数**。
3. **开箱后分拣**：好果、次果、废果分别称重。
4. **算到货损耗率**：
   - 到货损耗率 =（次果+废果重量）÷ 到货总重量 × 100%
   - 如果只算废果，就是废果率。
5. **连续跟3到5批**：单批没意义，香蕉批次波动很大。
6. **记录到货后24小时、48小时变化**：有些货到货看着好，放一天就出问题。

**四、实操建议**
- **如果你做短保快销**：优先看到货成熟度和当天可售率，不要只看品牌。
- **如果你做二批或门店**：都乐通常更稳，但加价空间可能小；洪九或其他渠道货可能价格灵活，但要承担批次波动。
- **验收时重点看**：
  - 青度是否一致
  - 有没有水烂、黑心、裂口
  - 箱内是否有明显压伤
  - 把数是否均匀
  - 催熟是否均匀
- **不要只听供应商说损耗率**：让他写进单据或聊天记录，约定扣重标准。比如“到货24小时内，废果超过X%按比例扣款”。

**五、如果你要一个大致参考**
在批发市场实际操盘中，香蕉到货损耗因条件不同，可能从**低个位数**到**十几个百分点**都有。都乐体系货通常波动小一些，洪九或其他渠道货可能批次差异更大。但这只是经验判断，不能当成固定对比数据。

**最稳的做法**：你在当地市场同时拿都乐和洪九各一批，按上面方法称重分拣，连续记3批，就能得到你自己渠道下真实的损耗对比。这个数据比任何网上说法都可靠。
