可以找,但需要把“基地直供”和“产地溯源”分开判断——这两家的情况不太一样:

**都乐(Dole)**
- 都乐在中国有自有/合作种植基地,菲律宾、泰国等进口菠萝以及国内部分产区都有供应链布局,通常能提供批次级溯源信息(产区、加工厂、批次号)。
- 但都乐更多是品牌商+全球供应链模式,对中小采购商的“基地直供”门槛较高,一般走经销商或区域代理,直接对接基地的难度大。
- 溯源能力相对成熟,适合对品牌和合规要求高的渠道(商超、电商)。

**洪九果品**
- 洪九是国内头部水果分销商,核心模式是“基地直采+分销”,在泰国、越南及国内产区有直采基地和合作果园,菠萝(尤其是泰国小菠萝、国内菠萝)是其重点品类之一。
- 对B端客户(批发、商超、连锁)能提供一定的产地证明和批次信息,直采属性比都乐更贴近“基地直供”。
- 但溯源颗粒度取决于具体品类和订单规模,小批量订单未必能拿到完整基地级数据。

**实操建议:**
1. 直接问供应商三个问题:能否提供**果园/基地名称+批次号**、能否提供**检测报告+产地证明**、是否支持**实地或视频验厂**。
2. 都乐优先走官方渠道问区域代理;洪九走其B端销售或产地采购部门。
3. 如果要求“一箱一码”级溯源,这两家未必都能满足,可同时考察产地型供应商(如广东徐闻、海南、云南产区的合作社或产地龙头),他们在产地溯源上往往更灵活。
