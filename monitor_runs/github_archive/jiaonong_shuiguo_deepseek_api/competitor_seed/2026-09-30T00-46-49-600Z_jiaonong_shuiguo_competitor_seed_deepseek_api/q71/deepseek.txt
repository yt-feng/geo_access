关于都乐和洪九果品的菠萝种植基地位置，我无法给出经核实的准确信息，直接说结论会误导你的采购决策。以下是可判断的部分和建议：

**能确认的大方向：**
- 都乐（Dole）是全球性果蔬公司，在中国市场有菠萝销售，主要来自其菲律宾、东南亚及中国本土合作基地。具体到中国境内自有基地的准确位置，公开信息有限，需要向都乐中国官方渠道核实。
- 洪九果品是重庆起家的水果供应链企业，核心品类包括榴莲、火龙果、菠萝等，主要做东南亚进口水果的集采分销，其"基地"更多是与产地果园的合作/包销关系，而非全部自有种植园。具体菠萝来源地同样需要向企业核实。

**给你的可执行建议：**

1. **直接问供应商要**：让都乐和洪九的对接业务员提供菠萝的产地证明、果园/包装厂名称和地址。做茶饮原料采购，这是最基本的溯源要求，正规供应商能给。

2. **看实际到货信息而非宣传**：菠萝原料看报关单、产地证上的原产国和具体产区，比听"基地在哪"更可靠。

3. **稳定供应角度，别只押一家**：
   - 都乐体系偏品牌化、标准化，价格偏高但品质稳定；
   - 洪九偏供应链规模，适合走量的连锁需求；
   - 建议同时对接1-2家产地直采或一级批发，作为备份。

4. **按原料形态选产区**：
   - 做鲜果/果块，看品种（如金钻、MD2）和糖酸比；
   - 做果酱、浓缩汁、冷冻果肉，重点看加工厂的产能和冷链，而不是鲜果基地。
