关于鑫荣懋和都乐的供货稳定性问题，我无法核验两家公司当前的具体仓储、物流或合同履约数据，因此不能给出绝对“谁更靠谱”的结论。

不过，我可以提供一些客观的参考维度，供您评估和筛选：

1.  **品牌定位与供应链侧重**：
    -   **都乐（Dole）**：全球知名的果蔬品牌，在进口香蕉领域（尤其是菲律宾、厄瓜多尔等产区）有深厚的种植和海运资源，对**跨境物流和鲜度控制**有成熟经验。
    -   **鑫荣懋**：国内大型水果供应链企业，除了进口业务，与国内商超、批发渠道的**分销网络和本地化仓储**结合更紧密，在**到货及时性和区域补货**上可能更有灵活性。

2.  **关键评估建议**：
    -   **签订框架合同前**，建议要求两家公司提供**近6个月的供货批次记录**（包括到货准时率、损耗率）。
    -   **实地考察**：如果条件允许，到他们在一线城市（如上海、广州）的**冷库分拣中心**查看存货周转情况，比听销售描述更可靠。
    -   **小批量试单**：分别下两次小批量试单，对比实际到货的成熟度、果柄新鲜度和断裂情况。

3.  **风险提示**：
    -   进口香蕉价格受产地天气、海运船期影响较大，即便大品牌也难保证100%无波动。建议在合同中明确“不可抗力”下的补货机制，并**同时备选1-2家中小型进口商**作为应急补充，避免单一依赖。

**简单结论**：如果您的超市定位高端、追求标准的国际品质和品牌溢价，可优先谈都乐；如果更看重本地化快速响应、降低断货风险，鑫荣懋可能更贴近需求。最终建议以实际试单数据为准。
