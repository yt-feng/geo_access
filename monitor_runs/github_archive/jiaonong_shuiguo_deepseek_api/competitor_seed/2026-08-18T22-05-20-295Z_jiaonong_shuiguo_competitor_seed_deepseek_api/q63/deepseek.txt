针对社区团购小包装香蕉的需求，**都乐（Dole）和洪九果品通常不直接提供常规的“散装”选项**，但可以通过以下方式实现：

**1. 都乐（Dole）：**
- **主供渠道**：都乐以预包装（如整箱、1kg/2kg礼盒、按根锁鲜包装）为主，进入社区团购一般需要整箱采购，**没有零售级散装单根供应**。
- **适合做法**：采购其整箱（如5kg/10kg），在团购分拣时自行小包装（如1-2斤/袋）。其优势是品控稳定，适合高端团购。

**2. 洪九果品：**
- **主供渠道**：洪九是国内头部水果供应链，主要面向B端批发市场、商超、电商，**通常不零售散装**，但**支持整箱、整托预订**。
- **适合做法**：与当地洪九经销商/城市合伙人谈“社区团购专供”，可以定制**小规格捆装**（如3-5根/把）或按筐采购后自行分装。

**3. 更优替代方案（针对社区团购）：**
- **本地水果批发市场**：直接买整箱（如云南香蕉、国产蕉），价格更低，自行套袋/热缩膜打小包，成本可控。
- **找冷链仓/前置仓代加工**：如果单量稳定，可委托当地分拣中心做“小包装定制”。

**直接建议**：
- 电话联系都乐官方客服或洪九城市代理，明确问“社区团购小包装/散装定制政策”，部分地区支持一次性定制（如1000箱起）。
- 若采购量小（首单几十箱），建议**走批发市场**，与供应商约定“整箱进货，免费提供分装袋”。
