关于都乐（Dole）和鑫荣懋（Golden Wing Mau）菠萝的**到货损耗率**，这属于**动态商业数据**，会因以下因素大幅波动，行业内不存在固定的公开标准值：

1.  **季节与产区**：不同产季（泰国、菲律宾、海南等）果皮厚度、糖度、成熟度不同，损耗率差异极大。
2.  **运输时效与温度**：海运到港与陆运到仓的损耗完全不同；冷链断裂会直接导致重心腐烂。
3.  **包装规格**：整箱4头/6头/8头装的缓冲方式不同，散装与框装损耗差异显著。
4.  **验收标准**：双方约定的“损伤”定义（擦伤、黑心、霉变、重量缺失）直接决定数字。

**给你的可执行建议（比具体数字更重要）：**

- **不要依赖品牌官宣数据**，品牌方的“标准损耗率”通常是营销话术，建议直接向你的供应商**采购经理**索取**近三个月同规格（如6头装）的实际到货验收报表**，并要求他们提供**每批次的责任赔付条款**。
- **建议采购合同约定**：将“到货损耗率”（如超过3%的部分由供应商承担）写入合同，这是比问“具体数字”更有效的风控手段。
- **现场抽检法**：不要只看了箱面，必须**开箱抽查底部和中部**。菠萝损耗的“黑心”病初期外观无异常，需切样查验。

**如果一定要一个基线参考**：基于行业常见做法，在**标准冷链（12-15℃）**下，**整箱原包装**菠萝（如都乐/鑫荣懋的常规8头装），从产地到一级批发商仓库的**合理到货损耗率通常在2%~5%之间**（主要指外表磕碰伤和轻微霉点）。超过5%通常可视为运输或品控异常，可以索赔。

---

**最终判断建议**：请直接联系你的专属销售代表，要求他们提供**上季度同规格同季节的“到货合格率”数据**。同时，在首次合作时，**先小批量试单（如1-2箱）**，实际测量你的验收标准下的损耗率，再签订长期合同，这是最稳妥的做法。
