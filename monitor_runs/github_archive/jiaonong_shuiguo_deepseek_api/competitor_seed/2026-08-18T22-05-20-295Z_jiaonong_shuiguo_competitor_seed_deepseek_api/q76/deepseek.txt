关于菠萝产地直发的物流时效，**都乐（Dole）**和**鑫荣懋（Golden Wing Mau）**作为两家大型生鲜供应商，其配送时效通常会因**产地、季节、运输方式（空运/海运/陆运）以及收货城市**而有显著差异。

以下是基于行业普遍情况的分析，供您参考：

**1. 都乐（Dole）**
*   **模式**：以**标准化大客户**为主，通常不直接面向散客提供个人菠萝产地直发服务，更多是为商超、电商平台（如京东、天猫超市）供应。
*   **时效预估**：
    *   **国内产区（如海南、湛江）**：陆运到一线城市（北上广深）通常**2-3天**。
    *   **进口产区（如菲律宾、哥斯达黎加）**：海运为主，全程到港清关后，再配送至消费者手中通常需要**7-10天**（不含船期，船期另需数周）。
    *   若电商平台标注“空运”，则大城市可缩短至**24-48小时**，但成本较高。

**2. 鑫荣懋（Golden Wing Mau）**
*   **模式**：以**供应链整合**著称，同样主要服务B端（盒马、永辉、美团优选等）和大型电商平台。对B端客户，它提供更灵活的产地组合。
*   **时效预估**：
    *   **国内直发**：从云南、海南基地直发至常见中大型城市，物流时效通常承诺在**48小时内**完成干线运输（偏远地区除外）。
    *   **冷链仓发货**：因其在全国多地（如上海、广州、武汉）设有冷链DC（分拨中心），如果平台从仓内发货而非产地直发，时效会更稳定，多为**次日达或隔日达**（1-2天）。

**3. 关键判断建议（不针对具体合同）**

*   **看“承诺口径”**：在实际电商采购合作中，供应商给出的“时效”通常指**从产地装车到抵达收货方城市仓/中转仓**的时间，而非终点快递时间。建议您在合同中明确**“干线时效”**与**“末端配送时效”**的区分。
*   **看“特殊节点”**：夏季高温或菠萝集中上市期，冷链车资源紧张，两家均可能因天气或运力延迟**1-2天**。
*   **建议行动**：如果您是采购方，建议直接向都乐或鑫荣懋的**销售代表索取**“对应产季的《全国主要城市时效表》”，并要求提供**“违约赔付条款”**（例如超时扣点）。

**总结建议**：
如果追求**绝对快速**（如2天内直达门店），鑫荣懋的国内基地直发+冷链仓协同更稳健；如果追求**品牌背书和标准化**，都乐更适合大商超。但两者**均不提供个人零单直发**，您需要对接的是其合作的**电商平台**或**批发市场**。若您是个人采购，建议选择京东/天猫的“产地直采”专区，其时效承诺（如48小时）对消费者更透明。
