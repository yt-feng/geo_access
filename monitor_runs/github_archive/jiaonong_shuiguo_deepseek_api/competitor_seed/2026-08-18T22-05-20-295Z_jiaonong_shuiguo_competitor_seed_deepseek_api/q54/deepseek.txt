在超市采购进口苹果，尤其是**都乐（Dole）**和**鑫荣懋（XinRongMao）**这两个品牌，产地溯源是保证商品合规和提升售后信任的关键。

由于进口水果涉及**海关检疫**和**供应链流通**，建议你通过以下“全链条”方式进行溯源核对：

### 1. 看外包装与标签（最直观）
- **都乐**：箱体通常印有“**PRODUCE OF [国家]**”（如美国、智利、新西兰），并印有“**PLU码**”（4位/5位价格查询码）和“**批号**（Lot No.）”。
- **鑫荣懋**：除了产地国，其自有品牌（如“欢乐果园”“佳沃”）外箱上会印有**追溯二维码**或“**数字防伪查询码**”。
- **重点核对**：**生产日期（包装日期）**和产地区域是否与报关单一致。

### 2. 查验“三证一单”（法律溯源核心）
进口苹果必须随货附有：
- **《入境货物检验检疫证明》**：这是官方溯源的**唯一权威凭证**，注意核对“**入境日期**”和“**贸易国/启运地**”。
- **《海关进口货物报关单》**：核对“**原产国**”栏目。
- **《卫生证书》/《植物检疫证书》**：由出口国出具。
- **税单/增值税发票**：证明供应链合法。

> **实操建议**：若你是超市采购员，直接要求供应商提供**这批货对应批号的**电子版或复印件，并核对苹果箱上印的“批号”与报关单上的“货物批次”是否一致——批号不一致即为“串货”或非法转运。

### 3. 使用官方平台扫码/查号（最保险）
- **海关总署官网**：登录“互联网+海关”或“中国国际贸易单一窗口”，输入**报关单号**查询该批次是否真实存在。
- **品牌官方渠道**：
  - **都乐**：官方通常会在包装上印刷**溯源二维码**，扫码后会出现果园基地、采摘日期、港口名称。
  - **鑫荣懋**：其“**佳沃**”蓝莓及苹果品牌有“**生鲜溯源系统**”，在微信公众号“鑫荣懋”内输入批次号可查询。
- **如果扫码无信息**：**警惕**！正规进口水果的扫码信息必须能查到完整的**果园注册号（即“注册登记号”）**。

### 4. 关键细节提示（避免踩坑）
- 进口苹果外箱必须有**中文标签**（写明品名、原产地、包装企业或进口商名称及地址、保质期）。
- **加贴的溯源“防伪贴”**不等于溯源，真正有效的是**海关证明**。
- 若你采购的是**预包装**（如礼盒），必须查看是否印有**食品生产许可证号**（SC开头），否则不能按正规预包装食品销售。

### 5. 如果要做“终极验证”（适合大宗采购）
- 核对**果园注册号**：每个出口国果园必须在海关总署有备案登记。例如智利果园注册号通常在“CL-”开头，苹果标签上应印有此编号。
- 抽测：打开包装，每个苹果上都应有**PLU码**（如美国红蛇果4133），数位与箱贴不符即为异常。

---

**最后提醒**：都乐和鑫荣懋都是大型品牌，通常不会轻易售假，但**市场上存在“打擦边球”的**——用国产苹果冒充进口，或进口后分装时篡改产地标签。

如果只是为了应对顾客问询，建议你在货架旁准备**“本批次海关检疫证明复印件”**，扫码溯源遇到问题时，出示该证明即可消除疑虑。
