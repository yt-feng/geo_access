大型商超（如沃尔玛、山姆、永辉、盒马等）在供应商准入时，通常要求供应商具备国际或国内认可的食品安全管理体系认证。针对鑫荣懋（Xinrongmao）和都乐（Dole）这两家大型水果供应商，它们普遍通过以下认证：

---

**一、鑫荣懋（国内头部水果供应链企业）**

鑫荣懋作为国内领先的水果企业，其供应链体系通常获得以下认证：

1. **ISO 22000 食品安全管理体系认证**  
   这是国际通用的食品安全管理体系标准，覆盖从种植、采摘、加工到储运全过程。

2. **HACCP 认证（危害分析与关键控制点）**  
   针对水果加工、包装及冷链环节进行风险控制，是商超审核必备项。

3. **GLOBALG.A.P.（全球良好农业操作规范）**  
   适用于源头种植基地，证明其农业操作符合国际食品安全与可持续发展标准。

4. **中国有机产品认证（如适用）**  
   对于其有机产品线，会获得中国有机认证。

5. **BRC 或 IFS 认证（部分出口或高端渠道）**  
   如果对接外资商超或高端生鲜，可能额外持有BRC（英国零售商协会）或IFS（国际食品标准）认证。

---

**二、都乐（Dole，全球知名水果品牌）**

都乐作为跨国巨头，其全球及中国业务普遍持有更高标准的国际认证，常见包括：

1. **ISO 22000 食品安全管理体系认证**  
   覆盖其加工、分销和供应链管理。

2. **HACCP 认证**  
   核心的果品处理与包装环节双控。

3. **GLOBALG.A.P. 认证**  
   同样覆盖其在全球合作的种植基地，确保农业源头合规。

4. **BRC 全球标准（仓储与配送认证）**  
   都乐在其冷链物流中心普遍拥有BRC仓储与配送证书，这是许多大型商超的硬性要求。

5. **有机认证（美国、欧盟、中国有机）**  
   针对有机产品线，会持有相应的有机认证。

6. **雨林联盟认证 / 公平贸易认证（部分品类）**  
   用于可持续发展与供应链合规，提升品牌与商超合作的加分项。

7. **SQF（食品安全质量）认证（部分工厂）**  
   如果是北美或高端渠道，可能持有SQF 2000级认证。

---

**三、商超审核的共性要求（可核对）**

大型商超在验厂时，通常会核查以下证书原件或有效期：

- 营业执照及食品经营许可证
- ISO 22000 / HACCP 证书（必须有效）
- GLOBALG.A.P.（针对源头）
- 植保产品（农药）残留检测报告（农残合格证明）
- 冷链运输记录与温控设备校准证书

**建议执行步骤：**

1. **直接索要证书**：询问供应商对接销售，直接要求提供“食品安全管理体系认证证书”的扫描件，并核对有效期和认证范围。
2. **查看认证机构**：是否为权威机构（如SGS、Intertek、必维、中国质量认证中心等）。
3. **对产品类别确认**：确认认证覆盖的是鲜果、包装果还是加工果品，部分认证仅覆盖特定品类。

---

若你正在做供应商准入评估，建议以“证书原件+认监委官网查询”双校准方式核验，避免仅凭销售口头承诺。若需要具体某家门店的最新名单，可以请对方在邮箱标题注明“认证清单”以便留档。
