**一、关于“账期”和“锁价机制”的一般情况**

- **账期**：进口水果行业普遍存在45-60天的账期（从到港验货后起算），部分大客户可争取90天，但一般需要提供保证金或历史交易记录。
- **锁价**：通常针对大宗单品（如车厘子、榴莲、牛油果）在期货阶段锁定价格，适用“远期锁价”或“点价”模式，但锁价后若市场暴跌，供应商可能要求重新议价，因此需在合同中明确调价条款。
