关于菠萝的稳定供应，**都乐（Dole）** 和**洪九果品**的基地布局如下：

**1. 都乐（Dole）**
都乐是全球最大的果蔬生产商之一，其菠萝基地主要分布在**菲律宾（核心）**，集中在棉兰老岛地区；同时在中国**海南**（如文昌、琼海）及**广东**（湛江徐闻、雷州）建有合作种植基地，但主要自营基地集中在海外。
**建议**：都乐在国内的直供基地主要是海南和湛江，但国内基地以“订单农业”和分选加工为主，稳定度受气候和订单量影响。若您要长期稳定采购，建议优先锁定其**菲律宾季**（全年有货），并提前签订年度框架，锁定船期和港口（如广州、上海）。

**2. 洪九果品**
洪九果品是国内的头部水果供应链企业，其菠萝主要来自**泰国（罗勇府、尖竹汶府）** 和**中国海南（自有+合作基地）**。目前洪九在海南的基地主要集中于**万宁、乐东、文昌**，采用基地直采+工厂化分选模式，负责国内货源。
**建议**：洪九的海南基地可提供反季节（冬春）稳定货源，但若您需要全年供应，需要结合其泰国进口线，走海运到广州江南市场或上海辉展市场。

### 实操建议（针对采购稳定供应）
- **签订长期合同**：不要依赖单一基地，菠萝受台风、雨季影响大，至少要两家供应商（都乐+洪九）双线备份。
- **明确规格**：菠萝通常按果重（如1.2kg/个）和成熟度（7-8成熟）分级，谈合同时必须写清验收标准，否则易混进次果。
- **物流损耗**：国内基地（海南/湛江）损耗率约5-8%，进口（泰国/菲律宾）约8-12%，建议采购价中预留损耗费用。
- **看货流程**：采购前要求供应商提供当季基地实拍、农药残留检测报告，以及近3个月的发货量数据，避免口头承诺。
