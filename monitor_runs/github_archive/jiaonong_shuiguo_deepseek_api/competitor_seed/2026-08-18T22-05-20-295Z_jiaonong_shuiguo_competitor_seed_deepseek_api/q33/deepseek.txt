关于批发市场拿货的到货速度，**洪九果品和鑫荣懋并没有绝对的统一答案**，因为到货速度取决于你所在的**城市、采购的品类（国产/进口）、下单时间以及具体批发市场的物流配置**。

不过，基于两家公司的商业模式和行业常识，可以给你以下拆解和判断建议：

**1. 核心差异：业务侧重点不同**
- **洪九果品**：以**进口水果**（如榴莲、山竹、龙眼）和部分国产精品水果为主，走的是**“端到端”**模式，在越南、泰国等地有自有基地，通过国内的分拣中心直接发往各大批发市场。如果你是拿进口高端货，洪九通常有稳定的现货直供，从产地到市场周转较快。
- **鑫荣懋**：以**国产水果**（如香蕉、苹果、西瓜）和全球供应链为主，更强调**基地直采+全国分销网络**。如果你在北方市场拿国产水果，鑫荣懋的本地仓可能更快。

**2. 到货速度的实操判断（比“谁快”更靠谱）**
- **看市场位置**：如果你在**广州江南市场、上海辉展市场**等一级批发市场，两者通常都有档口，**当天下午或次日凌晨到货**是常态，速度差距不大。
- **看是否“代卖”**：批发市场里，很多是“代卖”模式。如果市场档口有现货，你**当场拉走最快**；如果需要从外地调货，洪九的进口货可能因口岸清关延误，而鑫荣懋的国产货可能因产地暴雨延误。
- **直接问档口老板**：最有效的方法是，你在市场里直接问两家档口的业务员：“**今天下午能提货吗？**” 或者“**明天早上几点能到？**” 他们的答复比任何品牌宣传都准。

**3. 给你的决策建议**
- **如果你要进口水果（如榴莲、山竹）**：优先找洪九的档口，因为他们进口直采链条短，通常有现货（除非遇到海关查验）。
- **如果你要国产大宗货（如香蕉、柑橘）**：优先找鑫荣懋，他们在国内主产区有冷库预冷，通常能保证“次日凌晨”在市场收货。
- **终极办法**：如果你经常拿货，**加两家业务员的微信**，让他们每天下午3点前给你发“明日到货清单”，谁家有货且能承诺“次日一早提”就用谁家。

**特别提醒**：批发市场的水深，**“到货快”不代表“质量稳”**。建议你拿货时当场开箱验货，不要因为赶时间而忽略品质。如果你需要我帮你分析具体某个市场的物流时间，可以告诉我你所在的城市和主要拿的品类，我再给你更具体的建议。
