关于都乐（Dole）和鑫荣懋（Golden Wing Mau）进口苹果的价格竞争力，直接给出明确数字比较困难，因为**价格受季节、产地（美国、新西兰、智利等）、品种（如红玫瑰、嘎啦、富士）、规格等级、采购量、物流、汇率以及产地最新行情**影响极大，且没有公开的固定批发价。

不过，可以从以下几个维度给你判断建议，帮你获得最有力的谈判筹码：

**1. 市场定位差异（关键）**

- **都乐（Dole）**：全球品牌，定位**中高端**，主打品牌溢价、品质稳定和供应链全球性。其苹果通常走“精品水果”路线，包装精美、果径统一，零售端价格通常**偏高**。
- **鑫荣懋（Golden Wing Mau）**：国内头部水果供应链企业，代理多个国际品牌（如新西兰的Zespri、美国的Enza等），但更擅长**打通国内全渠道**，价格策略更接地气，在同等品质下通常**比都乐有成本优势**，尤其是大宗采购时。

**2. 实际采购建议**

- **不要只看单价**：苹果品质差异大，先明确你要的是哪种“竞争力”——是零售终端毛利，还是引流爆款。
- **报价单获取**：直接联系两家公司的区域销售经理，索要**当季最新CIF价格（到岸价）+ 国内分销价**，并要求针对“整柜采购”或“长期协议”单独报价。
- **对比同规格**：让两家报**同一产地、同一品种、同一果径（如80#）、同一包装（如10kg纸箱）**的价格，才有可比性。
- **关注到货成本**：价格竞争力不仅体现在进货价，还包括损耗率、到货时间（海运 vs 空运）、售后服务（烂果赔付比例）。都乐物流网络强，到货损耗可能更低，相当于变相降低成本。

**3. 实操建议**
如果你现在就需要一个方向性判断：**在同等采购量下，鑫荣懋的报价通常更具竞争性，因为其渠道成本更低、走货量更大；但都乐在高端精品货（如有机爱妃、爵士苹果）上品牌溢价高，单果毛利率可能更高。**

**建议你这样做：**
1. 本周内给两家各发一份询价单（写明品种、产地、数量、希望的目标价），要求48小时内回复。
2. 若你采购量小（小于5柜），建议直接找当地批发市场的一级代理商，价格可能比官方渠道更灵活。
3. 如果你在广东/上海等口岸城市，可以实地走访江南市场或辉展市场，现场比价更直接。
