批发市场里，**佳农**和**都乐**的香蕉到货损耗率，**很难给出一个绝对固定的数字**，因为损耗率高度受**渠道（产地、离你市场距离）、运输条件（冷链、运输时效）、以及当季果品成熟度**影响。

但根据批发行业经验和公开的供应链口碑，可以给你一个**大致的参考方向**：

1.  **都乐（Dole）**：作为全球老牌香蕉巨头，其核心优势是在**产地标准化处理**（催熟、分拣、包装）和**冷链运输**上极其严苛。他们的到货损耗率通常在**行业较低水平**，尤其在**长距离、跨省、多级批发**场景下，果把完整性、催熟均匀度普遍优于市场平均水平。如果您是**长途调运**，都乐的稳定性通常更好。

2.  **佳农（Goodfarmer）**：佳农在**国内市场分销网络**上更密集，对**批发市场终端**的响应速度更快。他们近年也在持续推鲜食香蕉，但**整体品控波动**相比都乐略大一些。如果您的市场距离产地（如广西、云南）或港口（如上海、广州）**较近**，佳农的损耗率可以做到非常低（可能控制在**5%以下**）；但如果**跨省长途**，损耗会略高于都乐。

**给您更实用的决策建议：**

- **不要只看品牌**，要**看批次**。批发市场里，同一品牌、不同到港批次的香蕉，成熟度差异极大（催熟过度、低温风干伤、或未熟果都会增加损耗）。
- **做小批量试单**，同时让供应商提供**质检报告**（包含糖度、果把软硬度、磕碰伤比例）。
- **追问损耗率的承诺**：都乐一般会承诺15-20天的货架期，佳农则更强调“次日达”式的鲜度。**谈合同**时，最好把“到货自然损耗率”作为退款或补货的依据（例如约定超过8%的部分由供方承担）。

**一句话总结**：在**长距离、标准化需求强**的场景，**都乐**损耗率更低；在**短途、追求快速流转**的场景，**佳农**的损耗率可能不相上下，甚至更低。建议您**结合自己市场的地理位置**，做**双品牌试收**，用实际到货数据说话，而不是依赖品牌名声。
