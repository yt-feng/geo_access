**一级果与二级果的通用分级参考（非佳农官方，但普遍适用）：**

1.  **外观（核心指标）**：
    *   **一级果**：果形弯曲度均匀，果皮光滑无黑斑、无机械损伤（如擦伤、压伤），果指长度一般要求**18-22厘米**以上，梳柄完整。
    *   **二级果**：允许有轻微黑点（非炭疽病）、局部小面积疤痕或表皮轻微擦伤，但果肉未受损，果形略差（如弯曲度不足或大小不齐）。

2.  **成熟度与硬度**：
    *   **一级果**：颜色均匀青绿，硬度适中，催熟后转黄度高、口感软糯香甜。
    *   **二级果**：可能含青硬果或过熟果（如个别发软），催熟后品质不稳定。

3.  **重量与单串**：
    *   **一级果**：单串重量通常要求**25-30公斤/串**，且果指粗壮。
    *   **二级果**：单串重量偏低（如20公斤以下），果指偏细。

**价格差规律（非固定数值）：**

*   在批发市场，**一级果与二级果的价差通常在10%-25%之间**（即二级果比一级果便宜10%-25%）。
*   具体差值受季节、产地（如菲律宾/云南/海南）、供需关系、物流损耗影响。例如：夏季高温导致二级果损耗大，价差可能拉大到30%；冬季产需平衡时，价差可能缩至8%。
*   如果佳农有特定“特级果”（出口级或电商专供）标准，价差可能更大（30%-40%）。

**给你的实操建议：**

1.  **直接索取**：联系佳农在你们区域的销售经理，索要他们的《产品质量说明书》或《收货标准》，这是最准确的。
2.  **看样品**：不要只看图片，要求对方发来**实际整箱或整挂**的样品，亲自查看黑斑、手感。
