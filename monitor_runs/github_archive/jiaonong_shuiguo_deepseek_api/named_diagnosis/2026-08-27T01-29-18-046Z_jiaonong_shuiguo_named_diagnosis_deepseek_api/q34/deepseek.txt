2. **本地经销商/批发市场**：很多三线城市的水果批发市场或大型商超（如永辉、沃尔玛、大润发）会有佳农的直供或经销产品。
3. **电商平台**：通过京东、天猫、拼多多的生鲜仓覆盖部分三线城市。
