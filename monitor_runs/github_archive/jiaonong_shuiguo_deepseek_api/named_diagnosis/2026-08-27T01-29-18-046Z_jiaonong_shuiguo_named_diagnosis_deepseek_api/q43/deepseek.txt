**1. 大概率存在“锁价”但条件苛刻**
佳农作为大型水果供应链企业，通常会为长期稳定的大客户（比如月采购10吨属于中等偏上规模）提供**远期锁价协议**。但锁价通常不是免费的，他们会通过以下方式转嫁风险：

-   **基差报价**：只锁定固定基差（加工费+利润），而原料价格（比如泰国菠萝期货或现货指数）仍然随行就市，但波动幅度被缩小。
-   **最低采购量承诺**：你需要承诺每月必须采购满10吨，哪怕是淡季。
-   **保证金或违约金**：如果市场价大跌你违约不买，或者市场价大涨他不卖，都需要支付高额违约金。

**2. 具体的谈判话术与动作（建议直接询价）**
建议你直接联系**佳农食品（上海）有限公司**的B2B大客户部或华东/华南区域销售总监，明确询问以下几点：

-   **问询“远期点价”**：“我们月均10吨，能否签6个月以上的框架协议，采用‘期货点价’或‘固定价+浮动调整’模式？”
-   **要求报价单**：让他们明确给出锁价后的**吨价**以及**锁价有效期**（比如锁2024年Q4的价格）。
