关于佳农水果的到货损耗率，我暂时没有获取到其官方公开的具体数据。

通常水果行业的到货损耗率（指从产地/仓库发货到门店或客户收货期间因磕碰、腐烂、失水等产生的损耗比例），会因水果品类、运输距离、包装方式和季节而差异很大。一般行业参考范围如下：

- **高损耗品类**（如草莓、荔枝、山竹、鲜榴莲等）：3%-8%甚至更高。
- **中等损耗品类**（如苹果、梨、柑橘类）：1%-3%。
- **低损耗品类**（如香蕉（未熟度较好时）、哈密瓜）：1%以内。

佳农作为大型品牌进口水果商，通常在分选、冷链和包装上投入较大，目标是控制在 **2%-5%** 左右的综合损耗，但具体到某批货，需以实际单据为准。如果你是在采购或谈判合同，建议直接向佳农的销售或客服索取其质检标准和损耗承诺数据，或者以合同约定的“到货检测”条款为准。
