关于佳农是否提供去皮切块等加工服务，**建议直接联系佳农官方客服或当地经销商确认**，因为这类服务通常不是默认提供的，且可能因区域、订单量而异。

以下是一些可行建议，供您参考：

1. **直接咨询**：拨打佳农官网或包装上的客服电话，说明您的需求（如“茶饮店批量采购菠萝，是否需要加工服务”），并询问是否有“净菜加工”或“定制切割”业务。
2. **向经销商确认**：如果您从当地批发市场或代理商进货，让经销商转达需求，他们更清楚当地是否有加工能力。
3. **备选方案**：
   - 如果佳农无此服务，可考虑**当地中央厨房或果蔬加工厂**代加工（需注意食品卫生资质）。
   - 也可以自己采购**去皮菠萝**或**冷冻菠萝丁**（部分品牌有此类产品，但风味和口感可能略有差异）。

**提醒**：如果佳农提供加工服务，务必确认加工后的保鲜方式（如冷链配送）、保质期和卫生标准，以符合茶饮店食安要求。
