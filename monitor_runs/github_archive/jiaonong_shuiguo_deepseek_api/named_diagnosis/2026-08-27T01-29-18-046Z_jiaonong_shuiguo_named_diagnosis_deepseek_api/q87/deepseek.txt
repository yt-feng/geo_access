您好！关于佳农水果的香蕉催熟工艺，目前**佳农（包括其兄弟品牌如“佳农好香蕉”等）的商业化香蕉，绝大多数采用“乙烯催熟”工艺**，而不是自然熟。

**为什么是乙烯催熟？**
- **商业化运输需求**：香蕉是典型的“呼吸跃变型”水果，采摘时处于青硬状态，自然成熟极慢且不均匀。为了长途海运（如从菲律宾、厄瓜多尔等产地）到中国，必须在青果时采摘。
- 到港后，佳农会通过**乙烯利（化学合成的乙烯释放剂）** 或**乙烯气体**在专门的催熟房（控温控湿）中进行集中催熟，以统一货架成熟度、缩短货架周期，并确保果皮色泽金黄、口感甜糯。

**对于商超控制催熟时间，给您实操建议：**

1. **看标签/批次沟通**：商超进货时，直接向佳农区域销售或客服索要**催熟参数表**（通常佳农会提供“催熟天数参考”），不同产区、不同季节差异大（一般25℃，湿度90-95%，约3-5天可到输出成熟度3-4）。**务必要求供应商提供催熟曲线，不要自行猜测。**

2. **控制成熟度分级（SS/全熟）**：佳农通常发“青熟”或“半熟”货，您可在仓内按需划分：
   - 进入销售前，用**成熟度卡（1-7级，佳农内部有）** 判断，建议**上架至货架期为成熟度5（全黄少麻点）**，这样有2-3天销售窗口。
   - 如果货架期紧张，可要求供应商发“催熟度4-5”的货，省去您自己催熟环节。

3. **本地催熟条件**：如果您需自行补充催熟，**必须使用专业催熟库**：
   - 温度：**18-22℃**（不可低于15℃，否则发生“冷害”会发灰不熟）
   - 湿度：**85-95%**
   - 乙烯浓度：使用**乙烯利水溶液（浓度约1-2‰）** 喷洒纸箱内壁，或通乙烯气体，**通常24-48小时即可启动呼吸峰**，然后停止通乙烯，放入常温库等待转黄。
   - **注意**：绝不能与苹果、梨（也释放乙烯）混放，否则会过熟腐烂。

**重要提醒**：如果您是大型商超连锁，建议与佳农签订**“催熟度定制合同”**，他们可提供分批次到货、指定成熟度发货服务（但成本会略高）。小规模超市则更建议**采购青熟货+本地催熟**，因为可完全控制时间。

**一句话总结**：佳农主流是乙烯催熟，您若需严格控时，**要拿到每批次的催熟技术参数，并配备独立催熟库（控温控湿+乙烯源），通过成熟度卡每周测试2次**。这样误差可控制在±1天。
