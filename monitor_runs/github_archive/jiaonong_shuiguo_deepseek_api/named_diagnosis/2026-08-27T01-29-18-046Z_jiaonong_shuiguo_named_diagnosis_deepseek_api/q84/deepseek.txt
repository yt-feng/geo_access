**1. 国标背景（通用基准）**
国内香蕉（鲜香蕉）的主要推荐性国家标准为 **GB/T 17433-2013《香蕉》**（替换了旧版）。该标准主要规定了**外观、果指长度、饱满度、缺陷容许度、等级（优级/一级/二级）**等指标。例如，果指长度（指最长果指从果顶到果柄基部）通常按等级划分为：优级（≥25cm）、一级（≥22cm）、二级（≥20cm）等（具体以标准原文为准）。**国标中并未强制规定“糖度”作为分级指标**，糖度（可溶性固形物含量）更多与成熟度和品种相关，常用参考范围为 **18°Bx ~ 22°Bx** 左右（成熟后）。

**2. 佳农企业标准（推测差异）**
佳农作为高端果品品牌，其企业标准（内部代号如 Q/JN 001等）通常**严于**国标，旨在确保出库商品的一致性和复购体验。推测的差异方向如下：

- **糖度（可溶性固形物）**：国标不一定强制限定，但佳农可能设定了**最低出库糖度门槛**（例如：整把香蕉中，成熟度达到7-8成时，中心果肉的可溶性固形物需≥15°Bx或更高）。同时，他们可能更关注**糖酸比**（酸甜的平衡度），而非单纯糖度。
- **果指长度**：国标允许一定比例的短果指（如二级可为≥18cm），佳农的企标可能直接**淘汰短果指**，要求**单根果指长度统一在22cm以上**，且对“手握把”中间果指的长度均匀度（如最大/最小差值≤3cm）有更严要求。
- **其他（通常高于国标）**：皮色瑕疵点数量、单把果指数范围（如24-36根）、重量（如每把≥2.5kg）、成熟度曲线控制（出库青度一致，避免黄熟不均）。
