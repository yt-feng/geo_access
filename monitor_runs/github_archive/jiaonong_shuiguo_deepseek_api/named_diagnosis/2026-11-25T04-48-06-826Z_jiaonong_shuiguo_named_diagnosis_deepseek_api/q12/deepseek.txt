佳农水果（佳农食品控股旗下品牌）的香蕉规格会随年份、产地（如菲律宾、厄瓜多尔、越南等）和客户订单调整，公开渠道没有一个长期固定、全渠道统一的“规格表”。因此，下面给出的是行业常见做法和可落地的判断框架，而不是佳农官方承诺的精确分级。

**一、佳农香蕉常见规格维度**

1. **按单根重量分级（最常用）**
   - 小果：约 110–130g/根
   - 中果：约 130–150g/根
   - 大果：约 150–180g/根
   - 特大果：约 180g/根以上
   实际订单常以“每箱净重 + 每把根数 + 单根重量区间”共同约定，例如 13kg/箱、每把 5–6 根、单根 130–150g。

2. **按每箱净重**
   - 常见 12kg、13kg、13.5kg、18kg 等箱规；商超和电商还会出现 1kg、2kg、5kg 小包装。
   - 同一箱规下，根数越少通常单根越大。

3. **按梳/把规格**
   - 整梳、半梳、每把 4–6 根等；零售端更看重“每把根数整齐、单根均匀”，而不是单纯大果。

4. **按成熟度与外观**
   - 青蕉（催熟前）、黄蕉（即食/催熟后）；果指长度、弯曲度、粗细、着色均匀度、无机械伤和病斑等。

**二、不同渠道的分级侧重点**

- **商超/大卖场**：重视外观整齐、单根大小均匀、每把根数一致、货架期稳定；常用中到大果，箱规以 12–13kg 为主，要求着色和成熟度批次一致。
- **水果连锁/精品店**：偏好中大果、果形周正、色泽好，小包装和礼盒装比例更高；对单根重量上限和外观瑕疵更敏感。
- **电商/社区团购**：更看重耐运输、损耗低和性价比；常用中果，按净重小包装，允许单根略小但要求均匀、少压伤。
- **批发市场/二批**：以箱规、净重和到货成熟度为核心，分级相对粗，强调出成率和耐储运。
- **餐饮/茶饮/加工渠道**：更关注出肉率、成熟度一致、供应稳定和成本，对外观要求低于零售，常用大果或特定成熟度青蕉。
- **出口/商超直采**：通常有客户专属分级标准，按果指长度、粗度、着色、缺陷率、农残和冷链记录综合验收。

**三、可执行建议**

如果你是采购或选品，不要只问“有几种规格”，而应要求供应商提供当批次的：产地、箱规净重、每箱根数/把数、单根重量区间、成熟度、缺陷率上限、冷链和催熟方式。然后按渠道做三档：商超用“均匀中大果+稳定成熟度”，电商用“中果+耐运小包装”，批发用“标准箱规+到货成熟度”。具体佳农当季规格，以其销售合同或当批质检单为准。
