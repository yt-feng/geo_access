**1）45天账期：能谈，但不要当成默认**
- 佳农这类水果供应链企业通常更看重回款速度和损耗风险，45天不算离谱，但对新签长期合同的首轮报价来说偏长。
- 建议话术：把45天和“年度采购量/门店数/账期起算方式/对账周期”绑定，比如“年度框架量达到X、对账后45天付款”，而不是无条件45天。
- 必须写清：账期从**收货验收合格且发票入账后**起算，还是从发货起算；生鲜损耗、质量异议期间是否暂停账期；逾期付款的违约责任。
- 如果对方卡得紧，可退一步：首月30天，连续3个月无质量争议后转45天；或用部分预付款/缩短对账周期换45天。

**2）首批铺货支持：可以要，但要具体化**
不要只说“给点支持”，直接列可谈项：
- 首批铺货的**账期延长或首单赊销额度**；
- **进场费/条码费/堆头费减免**；
- 首批**损耗补贴或滞销调换比例**（比如5%–10%内可换货）；
- **促销员/试吃/陈列物料**支持；
- 首批**价格折让或搭赠**（搭赠比直接降价更好谈，也保价盘）；
- 冷链到店、配送频次、缺货补货响应时间。

**3）合同里必须补的风险条款**
- 质量标准、验收标准和异议时限；
- 损耗承担比例和调换货规则；
- 价格调整机制（水果价格波动大，别签死价）；
- 最低采购量是否绑定返利，未达标是否影响账期；
- 账期与质量索赔的抵扣权。
