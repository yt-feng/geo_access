简短结论：通常做不到“到具体农场”的公开溯源，但可以拿到GLOBALG.A.P.证书；实际能追到哪一级，取决于佳农供货的是自有/合作基地还是多源拼货，以及你们拿到的证书编号与批次是否对得上。

可执行判断与做法：

1. **产地溯源层级**
   - 佳农香蕉多为跨国/多产区采购（如菲律宾、厄瓜多尔、越南、柬埔寨等），商超渠道常见做法是“国家/产区+包装厂/加工厂+批次”溯源，**不一定对终端公开到具体农场**。
   - 若你们合同要求“农场级”，需要在采购合同/质量协议里明确：**农场名称、农场编号、GLOBALG.A.P.证书编号、包装厂编号、批次对应关系**，并要求供应商随每批提供。
   - 只靠包装箱码或商品条码，一般只能追到批次/包装厂，不能证明具体农场。

2. **GLOBALG.A.P.证书怎么要、怎么核**
   - 向佳农业务/质量部门索取：**证书PDF + 证书编号 + 认证机构 + 认证范围（作物/产品）+ 有效期 + 持证主体名称**。
   - 关键核对点：
     - 持证主体是否与合同供货主体一致，或是否有清晰的供应链关系说明；
     - 认证范围是否覆盖“香蕉/Banana”；
     - 证书是否在有效期内；
     - 证书上的农场/生产商编号能否与你们批次对应；
     - 可要求提供**GGN编号**，并在GLOBALG.A.P.官方数据库核验。
   - 注意：GLOBALG.A.P.通常是**生产者/农场级认证**，贸易商证书不能替代农场证书；若佳农是贸易商，应让其提供上游农场/包装厂的证书及授权供应链声明。

3. **商超验收建议**
   - 在质量协议中写明：每批随货提供**产地证明/植物检疫证书（如适用）、包装厂注册号、GGN编号、证书有效期截图**。
   - 建立“**证书-农场-包装厂-批次**”四联表，抽批核对；证书过期或范围不符即拒收。
   - 若供应商只能给“国家级产地+GLOBALG.A.P.证书”但不能对应农场，你们应把验收标准降为“**产区/包装厂级可追溯 + 有效GLOBALG.A.P.证书**”，或在合同中要求农场级并据此考核。

一句话：**公开溯源到具体农场一般不现实；但通过合同和随批文件，可以要求并核验到农场/GGN级。GLOBALG.A.P.证书要拿“持证主体+GGN+范围+有效期”，并在官方库核验。**
