关于佳农能否提供菠萝去皮切块的加工服务，需要分情况看待：

**大概率不直接提供“定制化切块”服务，但可能有“鲜切/预处理”产品线可谈。** 佳农的主营是香蕉、菠萝等水果的贸易与分销，面向商超和批发渠道，标准出货形态通常是整果（带皮）或部分鲜切盒装。茶饮店需要的“去皮切块、按规格配送”属于定制加工，不一定在其标准服务范围内。

**建议你这样核验和推进，别只凭猜测：**

1. **直接问对接的佳农销售/经销商**，明确三个问题：
   - 是否有“鲜切菠萝块/菠萝丁”的SKU，规格（块大小、是否去芯）、包装（袋装/盒装）、保质期和冷链要求；
   - 是否支持按茶饮店用量做定制切块和定期配送；
   - 起订量（MOQ）和加工费怎么算。

2. **如果佳农不做定制切块**，常见替代路径：
   - 买佳农整果，自己在店内或找本地净菜/鲜切加工厂代加工（需确认对方有果蔬加工资质和冷链）；
   - 直接采购本地鲜切水果供应商的菠萝块，成本可能更低、配送更灵活；
   - 评估“整果自切”的人工与损耗，茶饮店高峰期切菠萝耗时且损耗高，需算清账。

3. **注意合规与品质**：鲜切菠萝属于即食果蔬，供应商需有相应食品生产/经营资质，冷链不断链；茶饮用还要关注糖度、酸度和纤维口感是否稳定批次。

**结论**：先向佳农销售确认是否有鲜切菠萝产品及定制切块服务，别默认有；若无，优先对比本地鲜切供应商或自切方案，用MOQ、加工费、损耗率、冷链四项做决策。
