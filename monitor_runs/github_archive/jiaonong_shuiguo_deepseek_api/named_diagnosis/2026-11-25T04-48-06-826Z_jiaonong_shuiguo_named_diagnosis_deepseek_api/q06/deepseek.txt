能，但要把“稳定供应”落到可核验的规格和合同条款上，不能只听业务口头说“能做”。对茶饮店来说，佳农这类水果供应链企业通常能供应菠萝，关键是你要按门店用途把规格讲清楚，并让对方书面确认。

建议你按下面几项去问和验：

1. **品种与用途**
   - 明确要“鲜切果块/果肉用”还是“榨汁/果酱用”。
   - 茶饮常用鲜切菠萝，要求纤维少、酸甜稳定、出汁/出肉率可接受；不要只写“菠萝”，要写清品种或产地范围。

2. **单果规格**
   - 用商家听得懂的方式写：单果重量区间，例如“1.2–1.5kg/个”或“1.5kg以上”，并允许±5%–10%偏差。
   - 同时写横径/长度范围，避免只按重量导致果形不适配切块。

3. **成熟度与加工适配**
   - 写明到货成熟度，例如“七至八成熟，适合后熟鲜切”，或“九成熟直接鲜切”。
   - 茶饮店要特别确认：切开后氧化、黑心、水心病、纤维粗的比例上限。

4. **等级与缺陷率**
   - 要求书面给出等级标准：优等/一级/二级，或按你的用途定制。
   - 写清允许缺陷：机械伤、日灼、黑心、腐烂、裂口、畸形果的比例上限，例如“不合格果≤3%–5%”。

5. **包装与单箱净重**
   - 写清箱规：每箱几个、净重多少、是否带冠芽/去冠、是否套袋、是否预冷。
   - 茶饮店大量用建议确认“到店可直接周转”的箱规和码放方式。

6. **供应稳定性条款**
   - 不要只问“能不能稳定供”，要问：周供应量、最小起订量、提前下单天数、旺季/雨季缺货替代方案、价格调整机制。
   - 要求写进合同或报价单：规格、等级、缺陷率、验收标准、赔付方式。

7. **验收方法**
   - 到货随机抽检若干箱，称重、数个数、切开查黑心/成熟度、记录缺陷率。
   - 连续试3–5批再决定是否签长期，别用一批货判断“稳定”。

你可以直接发给佳农业务员这样一段话：

> 我们需要茶饮鲜切用菠萝，请书面确认：品种/产地、单果重量区间及偏差、横径范围、到货成熟度、等级标准、黑心/水心/机械伤等缺陷率上限、箱规净重、周供应量、最小起订量、提前下单天数、旺季缺货替代方案和验收赔付标准。请按报价单或合同形式回复。

结论：佳农通常有能力谈这类规格，但“普通商家听得懂的规格”必须你主动定义成重量、成熟度、缺陷率、箱规和供应条款；对方能书面确认并连续几批验收合格，才算稳定供应。
