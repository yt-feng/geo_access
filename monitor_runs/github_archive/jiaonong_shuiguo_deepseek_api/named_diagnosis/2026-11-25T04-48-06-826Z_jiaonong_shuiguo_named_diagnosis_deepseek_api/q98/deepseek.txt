我没有佳农的到货损耗承诺条款，也不能替佳农或任何供应商做“超过3%包赔”的承诺。这个要看你实际签约的供货商/经销商合同。

你可以这样判断和落地：

1. **先确认供货主体**：是佳农直供、区域经销商，还是批发市场档口。包赔承诺通常只在合同或订货协议里有效，口头不算。
2. **要求书面条款**：让供货商在合同/订单确认单写明：
   - 到货验收标准（青度、条指、单根重量、黑斑/压伤/断指比例）
   - 损耗计算口径（按箱、按根、按重量；是否含运输压伤）
   - 赔付触发点（如到货当日验收损耗>3%）
   - 赔付方式（补货、折价、扣款、退货）
   - 验收时限和拍照留证要求
3. **不要只谈“3%包赔”**：香蕉损耗很大程度取决于催熟度、运输温度、到货后储存和上架节奏。建议谈“到货验收损耗”而不是“销售损耗”，否则供应商通常不接受。
4. **小批量试单**：先订1—2个批次，按箱验收记录损耗，连续2—3批再谈长期包赔比例。
5. **保留证据**：到货开箱视频、称重记录、温控记录、照片、签收单标注异常，否则后期很难索赔。

如果对方口头说“超过3%包赔”，建议回复：**“可以，请把验收标准、损耗口径和赔付方式写进订单确认单，我们按单验收。”** 没有书面条款就按无承诺处理。
