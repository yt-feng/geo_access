佳农水果的售后整体属于“生鲜常规水平”：坏果包赔一般有，但体验取决于购买渠道——京东自营、天猫旗舰店、抖音/拼多多店铺、线下商超的理赔入口和时效不一样，不能一概而论。到货有坏果，建议按下面步骤处理，成功率最高：

1. **先别急着扔，拍照/录视频留证**
   - 拍外箱面单（含订单号/批次）
   - 坏果与包装同框拍，能看出坏果数量和整体到货状态
   - 切开坏果拍内部，证明是腐烂/变质而非表皮瑕疵
   - 最好开箱时一镜到底录个短视频，生鲜理赔很吃证据

2. **尽快在平台订单里申请售后**
   - 京东：订单→申请售后→“商品破损/腐烂/少件”，上传照片，通常自营生鲜审核较快
   - 天猫/淘宝：订单→退款/售后→选择“生鲜腐烂变质”，按客服要求补图
   - 抖音/拼多多：订单→申请售后，部分店铺会要求加微信或走店铺客服，仍建议在平台内留痕
   - 线下商超购买：直接找服务台，凭小票和坏果照片处理

3. **沟通时把诉求说清楚**
   - 明确是“部分坏果”还是“整箱严重损坏”
   - 常见处理是：按坏果比例退款/补发/补偿优惠券；整箱腐烂一般可全额退或补发
   - 不要接受“表皮瑕疵不算坏果”这种模糊说法，腐烂、霉变、异味、软烂出水都属于质量问题

4. **注意时效和边界**
   - 生鲜一般要求签收后24小时内反馈，越早越好
   - 已切开、已食用一部分仍可理赔坏的那部分，但证据要对应
   - 因放太久、未冷藏导致的坏果，商家可能拒赔；收到后按包装说明储存
   - 如果平台客服拖延，可在平台内升级投诉或申请平台介入，保留聊天记录

**实用建议**：优先在京东自营或品牌旗舰店买，售后入口规范；收到后先开箱检查再签收/确认收货，坏果集中拍一张“全家福”最省事。别先跟快递员纠缠，直接走订单售后更快。
