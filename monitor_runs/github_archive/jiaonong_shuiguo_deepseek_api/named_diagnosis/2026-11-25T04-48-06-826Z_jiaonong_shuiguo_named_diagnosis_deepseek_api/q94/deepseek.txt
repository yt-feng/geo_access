佳农（Goodfarmer）香蕉的分级属于企业/产地执行标准，公开渠道通常查不到完整、可核验的正式分级文件；价格差也不是固定数值，会随产地、季节、规格、到货港口和合同量波动。直接给“一级果比二级果贵多少元”容易失真。

可执行的做法如下：

1. **先锁定“佳农标准”的准确口径**  
   向佳农区域销售/经销商索要：  
   - 香蕉验收分级标准（企业标准编号或验收单）  
   - 规格说明：每箱净重、梳数/条数、单条重量区间、长度区间  
   - 外观缺陷允许度：黑斑、机械伤、青软、裂口、果指粗细不均、着色度  
   - 成熟度/催熟到货状态  
   没有这些参数，“一级/二级”不可比。

2. **价格差用“同批次、同规格、同到货日”对比**  
   让供应商对同一批货同时报：一级果箱价、二级果箱价、折合每公斤价。  
   行业里常见情况是二级果按一级果的**折价比例**成交，而不是固定差价；具体比例必须以当日报价单为准。你可以要求报价单写明：等级、箱规、净重、单价（元/箱）、折合元/kg、起订量、运费承担。

3. **谈判时重点看可量化指标**  
   建议把分级写成验收条款：单条重量、果指长度、允许缺陷比例、青软率、到货温度、损耗赔付。价格差应绑定这些指标，而不是只写“一级/二级”。

4. **核验渠道**  
   最可靠的是佳农官方客服/区域经理或你现有批发商提供的盖章报价单和验收标准；电商页面和行业文章只能参考，不能当作佳农正式标准。
