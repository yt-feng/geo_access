佳农有面向礼品/团购场景的水果礼盒，但具体礼盒系列、规格和团购政策会随渠道和档期变化，建议按下面方式确认：

1. **先确认购买渠道**
   - **官方渠道**：佳农官方旗舰店/官方小程序/官方客服，适合确认是否有“企业团购/礼品卡/定制礼盒”业务。
   - **商超与会员店**：山姆、盒马、永辉等常有佳农礼盒装，适合小批量送礼。
   - **经销商/团购平台**：企业团购通常走区域经销商，能谈批量价、开票、配送和定制贺卡。

2. **重点问清这几项**
   - 是否有**企业团购专线**和**起订量**
   - 礼盒是**固定搭配**还是可**按预算定制**
   - 是否支持**发票、统一配送、分地址发货**
   - 是否有**节令档期**（中秋、春节、端午等）专属礼盒
   - **保质期、到货时效、破损赔付**规则

3. **可执行的判断建议**
   - 10盒以内：优先看山姆/盒马/京东自营的佳农礼盒，省事。
   - 20盒以上：直接联系佳农官方客服转团购，或找本地水果批发商拿佳农货源做礼盒。
   - 需要印企业Logo/贺卡：必须提前问定制周期，通常节前要预留更长时间。
