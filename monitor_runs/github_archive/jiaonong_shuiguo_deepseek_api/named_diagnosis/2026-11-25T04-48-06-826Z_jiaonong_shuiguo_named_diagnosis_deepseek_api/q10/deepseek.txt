大概率有，但“专门客户经理”要看你的采购规模和合作渠道。佳农这类水果供应链企业通常会对批发商、商超、电商等客户做分层管理：采购量稳定、账期合作、区域配送条件明确的批发客户，一般会安排销售经理或渠道经理对接；零散询价或首次合作，多由区域销售统一接待，未必一开始就配专属客户经理。

建议你直接这样确认，最可执行：

1. 找佳农官方渠道  
通过佳农官网、官方公众号或官方客服电话，转到你所在区域的销售负责人，不要只找经销商或二级批发。

2. 开头就说清三点  
- 你做批发，月采购量/单品需求大概多少  
- 所在城市和是否有冷库/配送能力  
- 希望账期还是现款，是否需要稳定货源和分级报价  

3. 直接问一句  
“像我们这种批发商，是区域销售经理对接，还是可以申请专属客户经理？达到什么采购规模可以配专属对接人？”

4. 判断对方是否重视你  
如果对方愿意给你区域经理联系方式、报价单、起订量和账期政策，说明可以进入正式对接；如果只让你联系当地经销商，说明你的量级可能还不到直供客户经理层级。

结论：佳农通常有面向批发客户的销售对接机制，但是否“专门客户经理”取决于你的采购规模和区域。先通过官方渠道找到区域销售，明确采购量后申请专属对接，是最快的方式。
