佳农水果（佳农食品控股/佳农集团）对不同渠道客户的账期没有公开统一标准，通常要按客户类型、采购规模、合作历史、结算方式和合同逐笔审批，不能一概而论。

**一般规律（供判断）：**
- **商超/连锁零售/电商平台等大客户**：常见为月结，账期多在 30～60 天，具体取决于合同约定、对账周期和是否有返利/费用抵扣。
- **批发市场、餐饮、小型零售客户**：多为现款现货、周结或短账期，通常不会给很长账期。
- **经销/代理客户**：可能结合保证金、授信额度、销售规模给一定账期，但需要审批。
- **新客户**：一般可以申请，但首单通常要求现款或预付，或先做短账期试合作；之后根据回款记录、采购量和资质再谈延长。需要提供营业执照、开票信息、对接人及合同资料，并通过信用评估。

**可执行建议：**
1. 直接联系佳农当地销售/大客户经理，说明你的渠道类型、月采购量、结算方式和期望账期。
2. 新客户首次沟通时准备好：公司资质、下游客户或门店情况、历史采购流水、开票及对账能力。
3. 首单可争取“现款+小批量试单”，稳定合作 2～3 个月后再申请月结或延长账期。
4. 账期务必写进合同，明确对账日、付款日、逾期责任和返利费用抵扣方式。

具体账期以佳农当地销售和正式合同为准，建议不要仅凭口头承诺安排资金。
