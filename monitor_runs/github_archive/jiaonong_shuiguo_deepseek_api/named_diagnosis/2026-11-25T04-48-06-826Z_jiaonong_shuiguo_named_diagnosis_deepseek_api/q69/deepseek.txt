可以这样判断和推进：

1. **大概率有餐饮渠道产品，但“定制规格”需向官方确认**
   佳农是国内较大的水果供应链企业，菠萝是其重点品类之一，餐饮/茶饮/烘焙渠道通常会有鲜切、冷冻或大包装原料形态。但具体是否有“切片/切块”定制，以及尺寸、杀菌/保鲜方式、起订量，需要看其餐饮渠道产品目录。

2. **建议直接问这 6 个问题**
   - 是否有餐饮专供菠萝：鲜切、冷冻、糖水/罐头，还是仅整果？
   - 切片厚度/切块尺寸范围，能否按客户要求定制？
   - 包装规格：袋装/盒装/桶装，单袋净重，每箱数量。
   - 起订量和供货周期，是否支持区域配送。
   - 保鲜方式与保质期：冷藏鲜切还是冷冻，解冻/开封后使用时限。
   - 是否有样品和规格书、检测报告。

3. **核验渠道**
   优先联系佳农官方客服或当地餐饮渠道经销商，索取“餐饮渠道产品手册/报价单”；也可在展会（如餐饮供应链展、茶饮原料展）现场确认。不要仅依赖电商页面，因为电商多为零售规格。

4. **替代方案**
   如果佳农暂不提供所需切片/切块定制，可考虑其整果+中央厨房鲜切，或找有鲜切水果资质的供应链服务商代切；冷冻菠萝块则可看其他 B2B 果蔬供应商。
