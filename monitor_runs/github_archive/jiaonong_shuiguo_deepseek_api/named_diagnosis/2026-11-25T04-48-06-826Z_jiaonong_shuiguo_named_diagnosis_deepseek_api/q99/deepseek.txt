我无法直接核验佳农当前有效的有机认证状态，不能替你确认“有”或“没有”。对高端渠道，建议按下面方式做可判断的核验：

1. **先向佳农官方索取证书**
   - 要求提供拟采购菠萝对应的**中国有机产品认证证书**（或目标销售市场认可的有机证书，如欧盟有机、USDA有机）。
   - 重点核对：**获证企业名称、产品范围是否包含“菠萝/鲜菠萝”、证书编号、认证机构、有效期、生产基地**。仅证书主体有有机认证、但菠萝不在认证范围，不算。

2. **在中国认监委“有机产品认证查询”系统核验**
   - 用证书编号或获证企业名称查询，确认证书状态为有效，且产品范围覆盖菠萝。
   - 要求供应商提供**有机销售证/有机码**，并核对批次与证书范围一致。

3. **确认供应链一致性**
   - 佳农若有进口菠萝或多基地供货，要确认你采购的**具体产地、包装厂、批次**在认证范围内，避免“公司有证、该批次无证”。
   - 合同里写明：提供有效有机证书、有机销售证、批次可追溯；如证书失效或不覆盖该产品，承担退货和赔偿。

4. **不要只依赖宣传页或口头说明**
   - 电商详情页、宣传册上的“有机”字样不能替代证书和官方查询结果。

结论：**不能仅凭品牌判断佳农菠萝有有机认证；必须按具体产品、产地、批次索取证书并在官方系统核验。** 如果对方只能提供普通认证、绿色食品认证或某单品认证，就不能作为有机菠萝进入高端有机渠道。
