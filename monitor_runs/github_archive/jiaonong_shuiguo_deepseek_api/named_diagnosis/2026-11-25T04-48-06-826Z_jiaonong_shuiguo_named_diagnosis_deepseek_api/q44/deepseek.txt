**关于“历史超标”**
- 不能仅凭品牌名判断。农残是否超标取决于具体批次、产地、种植季和检测项目，同一品牌不同批次结果可能不同。
- 可行核验路径：
  1. 国家市场监管总局及各省市市场监管局官网“食品安全抽检信息”栏目，按“香蕉”+“吡虫啉/噻虫嗪/苯醚甲环唑”等常检项目检索；
  2. 农业农村部农产品质量安全监管司的例行监测通报；
  3. 海关总署进出口食品抽检信息（若涉及进口香蕉）；
  4. 直接向佳农索要该批次的第三方检测报告，并核对报告编号可在检测机构官网/CMA资质平台查验。

**采购合规证明怎么要（超市抽检能过的关键）**
向供应商索取并留存：
1. **该批次**的第三方检测报告（CMA/CNAS资质），检测项目覆盖 GB 2763 中香蕉对应的农残限量，报告日期与到货批次对应；
2. 供应商的**承诺达标合格证**（食用农产品销售者应附具）；
3. 进货查验记录：供货者许可证、购货凭证、批次追溯信息；
4. 如为进口，索取入境货物检验检疫证明；
5. 合同里写明：农残超标即退换货、供应商承担抽检不合格导致的损失，并约定每批随货附检测报告。
