佳农水果的到货损耗率没有对外公开的统一标准，实际控制目标会随品类、运输距离、季节和渠道而变化。可参考的行业口径是：

- **香蕉**：到货损耗通常控制在 **2%～5%**，夏季高温或长距离运输时可能放宽到 **5%～8%**。
- **苹果、梨、柑橘等耐储水果**：一般 **1%～3%**。
- **葡萄、草莓、樱桃、蓝莓等易损水果**：通常 **3%～8%**，冷链不到位时可达 **10%以上**。
- **整体到货损耗**：商超/生鲜渠道对佳农这类品牌水果的验收，常见可接受区间约为 **3%～5%**；具体以合同验收标准为准。

判断建议：如果你是采购或门店验收，不要按“佳农统一标准”谈，应直接查**采购合同/验收单上的品类损耗条款**，并区分“到货损耗”和“仓储陈列损耗”。若没有合同数据，可按上述品类区间做内控，易损品单独设阈值。
