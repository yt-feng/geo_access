这个需要和佳农水果（或你当地经销商）具体确认，我不能替你确认他们的政策。可按下面方式快速落地判断：

1. **先确认找谁**
   - 如果你从佳农区域经销商/代理商进货：直接找对应业务员或经销商，问“堆头陈列+试吃支持政策”。
   - 如果是总部直采/连锁统采：让采购对接佳农KA或区域负责人。
   - 门店自行采购：一般只能找当地经销商申请，厂家直投概率较低。

2. **问清4件事**
   - 是否提供**堆头陈列物料**：堆头围挡、价签、POP、地贴、试吃台等，是免费提供还是押金/成本价。
   - 是否提供**试吃支持**：试吃品、试吃员、试吃台、一次性用品，支持数量和时间段。
   - 是否有**促销员/临促**支持，费用谁出。
   - 是否有**陈列奖励/返利**：按堆头位置、面积、陈列天数、销量达成给费用或货补。

3. **费用分担常见谈法**
   - 门店出**位置和人力**，供应商出**试吃品+物料**；
   - 堆头物料供应商承担，门店承担陈列执行和损耗；
   - 试吃员费用双方各半，或按销量达成由供应商补；
   - 做“陈列协议”：约定堆头位置、面积、天数、试吃场次、销量目标、费用分担和核销方式。

4. **你直接发给对方的问法**
   “我们商超计划做佳农水果促销，需要堆头陈列和试吃支持。请确认：①堆头物料是否免费提供及清单；②试吃品/试吃台/试吃员支持标准；③费用如何分担；④是否需要签陈列协议及核销要求。请给书面政策。”

建议先让对方给**书面支持清单和费用分担方案**，再决定是否给堆头资源。
