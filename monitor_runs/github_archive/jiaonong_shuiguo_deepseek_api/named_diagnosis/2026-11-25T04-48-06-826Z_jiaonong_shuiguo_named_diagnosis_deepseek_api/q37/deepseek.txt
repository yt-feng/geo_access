你可以用下面方法快速判断“高还是低”：

1. **先定对标对象**：同城市、同渠道（如永辉/盒马/美团买菜/大润发）、同规格（500g或1kg、散装或袋装）、同品种（都乐/佳农/普通国产香蕉）比价。
2. **看单价而非总价**：用“元/500g”或“元/kg”比较，避免被箱装重量和促销误导。
3. **取样3家以上**：同一天记录佳农价 + 本地普通香蕉价 + 市场均价（当地商超/菜市场/生鲜平台），取中位数。
4. **判断规则**：
   - 佳农单价 ≥ 市场均价 **10%以上**：偏高；
   - 在 **±10%以内**：基本持平；
   - 低于市场均价 **10%以上**：偏低。
5. **注意品牌溢价**：佳农通常有品牌、分级和品控溢价，略高于普通散装香蕉是常见现象，不代表“贵得离谱”。
