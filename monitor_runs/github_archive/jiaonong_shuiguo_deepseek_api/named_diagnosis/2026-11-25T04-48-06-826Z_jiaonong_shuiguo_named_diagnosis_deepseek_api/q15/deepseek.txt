我无法核验佳农官方披露的“产地直供比例”这一具体指标，因此不能给出准确百分比；这类数据通常只在企业年报、招股书或对外宣传材料中零散披露，口径也可能不同（自有农场、协议基地、直采、代理采购是否计入并不统一）。判断“高不高”建议直接查佳农官方渠道或上市/发债披露文件中的采购模式说明，并看是否区分“直采/基地合作/市场采购”。

香蕉来源方面，佳农是全球化采购，具体国家结构会随季节、价格和供应情况调整，公开信息中较常见的是从厄瓜多尔、菲律宾、哥伦比亚、哥斯达黎加、越南等地采购；中国市场销售的部分香蕉也来自东南亚和南美产区。若需要准确到某一年度的主要来源国及占比，应以佳农官方披露或海关/行业报告为准，我不能凭印象给出具体比例。
