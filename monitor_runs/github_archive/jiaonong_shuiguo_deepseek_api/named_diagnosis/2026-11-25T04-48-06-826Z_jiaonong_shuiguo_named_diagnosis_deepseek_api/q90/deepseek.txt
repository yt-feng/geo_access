2. **茶饮店适用规格**：若用于饮品，通常要10mm左右小丁、IQF单冻、解冻后不出水太多；具体以你菜单（是否打碎、是否做果肉感）和杯型决定，不要只看“多大”。
3. **索样测试**：让供应商寄样，按你门店实际用法测：解冻失水率、口感、酸甜度、是否带黑点/纤维、与茶底融合后的颜色和沉淀。
4. **备选方案**：若佳农不供冷冻丁，可同时问：都乐、鲜丰/百果园供应链、冷冻水果B2B厂家（如冷冻果蔬加工厂），并索取**食品生产许可、检测报告、箱规和报价**。
5. **下单前核对**：合同里写清果丁尺寸、净重、固形物、糖度范围、冻储温度、破损率/异物标准，避免到货规格不符。
