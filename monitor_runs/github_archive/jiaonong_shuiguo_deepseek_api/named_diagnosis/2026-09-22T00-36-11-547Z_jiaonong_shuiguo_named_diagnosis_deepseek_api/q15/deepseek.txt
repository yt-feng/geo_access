佳农水果整体以“全球产地直采/产地直供”为核心模式，但**具体直供比例并没有公开、稳定披露的统一数字**，不同品类、年份和渠道口径可能不同。可以判断的是：  
- 对香蕉、菠萝、火龙果、车厘子等主力单品，佳农通常采用产地采购、产地加工/催熟、冷链到港分发的模式，直供程度相对较高。  
- 对部分小品类或季节性水果，可能会通过贸易商、批发市场或区域供应商补充，因此不能简单说“所有水果都高比例产地直供”。

**香蕉主要来自哪些国家：**  
佳农香蕉通常以**厄瓜多尔、菲律宾、越南、柬埔寨、哥伦比亚、哥斯达黎加**等为主，其中：  
- **厄瓜多尔**：常见主力来源之一，供应稳定、果品标准化程度高。  
- **菲律宾**：传统重要来源，尤其适合中国市场的运输距离和成本。  
- **越南、柬埔寨**：近年对华出口增长明显，陆运/海运优势较强。  
- **哥伦比亚、哥斯达黎加**：也是全球重要香蕉出口国，会按季节和价格进入供应组合。

如果你问的是“佳农官方披露的产地直供比例”，目前没有可靠公开数据可直接引用；更准确的说法是：**佳农以产地直采为主，香蕉来源多国组合，厄瓜多尔、菲律宾、越南、柬埔寨是常见来源。**
