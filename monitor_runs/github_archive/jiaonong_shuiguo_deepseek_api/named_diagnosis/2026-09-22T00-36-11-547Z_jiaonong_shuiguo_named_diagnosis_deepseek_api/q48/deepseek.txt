1. **先确认对接主体**
   - 佳农通常按品类、渠道、区域、客户类型（商超、电商、批发、餐饮、加工）分别管理。

2. **可重点争取的优惠方向**
   - **阶梯返利**：按年度/季度累计吨位给返点，而不是一开始直接降价。
   - **大客户价**：针对核心单品给年度协议价或锁价期。
   - **账期支持**：如月结、承兑、信用额度。
   - **物流补贴**：整车发运、区域仓配送、运费分摊。
   - **市场费用**：促销支持、陈列费、新品推广费。
   - **优先供应**：旺季保供、稀缺单品配额。
   - **定制包装/规格**：降低你的分拣和损耗成本。

3. **谈判时不要只问“1000吨有什么政策”**
   建议直接给对方一个可测算的方案，例如：
   - 年度总采购量：1000吨
   - 分品类：香蕉X吨、菠萝X吨、火龙果X吨等
   - 月度采购计划：尽量均衡
   - 结算方式：现款/月结30天/60天
   - 交付方式：产地直发/区域仓/到岸价
   - 目标：年度返利、账期、运费、旺季保供

4. **让对方书面确认**
   最终优惠政策应体现在：
   - 年度框架协议
   - 价格附件
   - 返利确认单
   - 对账与结算规则
   - 保供与违约条款

   你可以直接对佳农业务负责人说：

   > 我们年度采购量预计1000吨以上，希望谈长期框架合作。请按品类、月度均衡采购、结算账期、配送方式分别给出大客户价格、年度返利、运费支持和旺季保供方案。我们需要书面报价和返利规则，便于内部审批。
