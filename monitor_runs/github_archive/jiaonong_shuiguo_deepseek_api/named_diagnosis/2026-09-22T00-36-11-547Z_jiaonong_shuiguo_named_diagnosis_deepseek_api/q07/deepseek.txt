佳农（佳农水果）有两条不同业务线，配送范围差别很大，需要区分：

**1. 佳农作为水果品牌/供应商（佳农食品控股）**
它主要是做批发、商超供货、电商平台供货（如盒马、京东、天猫等）。这种情况下你买到的是通过商超或电商平台，配送范围取决于**你下单的平台**，而不是佳农自己：
- 京东/天猫：一般全国大部分县区可发，但生鲜类可能受冷链限制。
- 盒马/叮咚/美团买菜：只覆盖开通城市，多数县城没有。

**2. 佳农自营的电商/小程序（如有）**
佳农有天猫、京东旗舰店，也有一些自有渠道。生鲜配送通常会标注“部分地区不发货”或“偏远地区不配送”，具体以下单时系统提示为准。

**关于你们县城能不能送到：**
我没有实时查询你所在县城的能力，无法直接确认。建议你按以下方式核实：

1. 打开京东或天猫搜“佳农官方旗舰店”，选一个商品，**填你所在县城的收货地址**，系统会直接提示“是否可配送”。
2. 如果提示不可达，换平台（拼多多、抖音商城）再试，不同平台冷链覆盖不同。
3. 若都不行，可看当地大型超市/水果店是否有佳农货源，或通过社区团购渠道。

**关键提醒**：生鲜（尤其香蕉、菠萝等）对冷链要求高，很多品牌只覆盖地级市及以上，县城能不能到，最终以**下单页面填地址后的系统判断**为准，不要只看宣传文案。
