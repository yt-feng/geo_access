目前我无法直接核验佳农官方是否提供“去皮切块”这类定制加工服务，所以不能给你确定答复。建议你按下面方式快速确认，避免采购后才发现加工不了：

1. **先问佳农官方渠道**
   - 打佳农官方客服/销售电话，直接问：  
     “菠萝能否做去皮、切块、冷链配送的原料级加工？最小起订量、规格、价格、配送范围？”
   - 如果你是从经销商拿货，也要问经销商是否能代加工，还是只能发整果。

2. **确认关键条件**
   - **加工形态**：去皮整果、切块、切片、碎丁？  
   - **规格**：块大小、每袋重量、是否有糖度/成熟度要求？  
   - **包装与保存**：真空袋、冷链、冷冻还是冷藏？保质期多久？  
   - **起订量**：茶饮店用量通常不大，很多加工厂会有最低起订量。  
   - **价格**：加工费、包装费、冷链运费是否另算。  
   - **资质**：是否有食品生产/分切相关资质，能否提供检验报告。

3. **如果佳农不直接做，替代方案**
   - 找当地**净菜加工厂/中央厨房/果蔬分切厂**代加工佳农菠萝。
   - 直接采购**已去皮切块的冷冻/冷藏菠萝原料**，不一定非要佳农品牌。
   - 让门店员工自行处理，但要注意损耗、人工、食品安全和出品稳定性。

4. **茶饮店实际建议**
   - 如果用量稳定且大，优先找“原料供应商+代加工”一体方案。
   - 如果用量小，买整果自己切或买现成冷冻菠萝块更划算。
   - 先拿小样测试：出汁率、酸甜度、纤维感、是否影响茶饮口感。

你可以直接这样问供应商：  
**“佳农菠萝能不能做去皮切块？规格、起订量、价格、冷藏/冷冻配送、资质和保质期分别是什么？”**  
如果对方说不能，就基本可以判断佳农该渠道不提供这项加工服务。
