我无法确认佳农当前是否有“冷冻菠萝丁”这款在售原料，也不能给出其官方规格，避免给你错误信息。以下是可执行判断与核验路径：

**1）先确认你要的是哪种“菠萝丁”**
- **冷冻菠萝丁**：速冻后按袋/箱卖，通常用于茶饮店直接分装、打冰沙、做果茶。
- **糖水菠萝丁/罐头菠萝丁**：开罐即用，保质期长，但风味和成本不同。
- **新鲜菠萝切丁**：门店现切，损耗和人工高。

茶饮店常用的是**冷冻菠萝丁**或**糖水菠萝丁**，要看你菜单是“鲜果感”还是“稳定出品”。

**2）佳农是否供应，按这个顺序核验**
- 看佳农官网/官方公众号/官方小程序里是否有“冷冻水果/餐饮原料/菠萝丁”类目。
- 直接问佳农官方客服或区域销售：是否有**冷冻菠萝丁**、**糖水菠萝丁**，以及**是否对茶饮渠道供货**。
- 如果你是从经销商拿货，让经销商提供**产品包装图、规格表、配料表、执行标准、保质期、储存条件**。
- 要求寄样：确认**丁的大小、解冻后出水、甜度、纤维感、是否带芯**。

**3）规格通常怎么判断**
冷冻菠萝丁常见规格一般会标：
- **单袋净含量**：如 1kg/袋、2kg/袋、5kg/袋等；
- **整箱规格**：如 10kg/箱、20kg/箱等；
- **果丁尺寸**：如 8×8mm、10×10mm、15×15mm 等；
- **包装形式**：袋装、箱装、餐饮大包装。

但**佳农具体有没有、具体是多少，必须以官方或经销商最新报价单/规格书为准**，我不能替你编一个规格。

**4）如果你要快速替代方案**
- 找本地冷冻水果供应商，问“冷冻菠萝丁 10×10mm 餐饮装”；
- 找罐头类供应商，问“糖水菠萝丁 餐饮大罐”；
- 如果一定要佳农，建议直接让采购联系佳农官方渠道，明确问：**有没有冷冻菠萝丁、最小起订量、箱规、丁尺寸、是否支持茶饮店供货**。

**建议你直接发这句去问：**
“请问佳农是否有冷冻菠萝丁用于茶饮店？请提供：产品名称、丁的尺寸、单袋净含量、整箱规格、保质期、储存条件、是否对餐饮渠道供货、最小起订量和报价。”
