佳农（Goodfarmer）的香蕉绝大多数是**乙烯催熟**，不是树上自然熟。

简要说明：

- 香蕉在产地是**青果采收**，靠海运/冷链运到销地，不会在树上等到成熟。
- 到达销地后，在**催熟库**用**乙烯气体**处理，常用的是：
  - **乙烯利**（液体，释放乙烯）或
  - **乙烯气体**（如 Ethy-Gen，把乙醇转化为乙烯）。
- 这属于**人工诱导催熟**，但因为用的就是植物自身成熟时产生的乙烯，所以与“自然熟”在机理上一致，只是时间被提前和控制。

**商超控制催熟时间的建议：**

1. **确认是哪种催熟方式**
   - 如果是佳农的催熟库出货，通常已经过乙烯处理，到店后主要是**控温**来延缓或推进后熟。
   - 如果是青果到店自行催熟，才需要自己用乙烯利/乙烯。

2. **温度控制最有效**
   - **13–15℃**：明显延缓后熟，适合暂存。
   - **16–18℃**：后熟平稳，适合正常周转。
   - **20–22℃**：催熟较快，适合需要尽快上架。
   - **低于 12℃**：易冷害，果皮发黑、果肉不熟。

3. **乙烯只用于“启动”**
   - 用乙烯处理后，**通风排掉乙烯**，否则会继续加速。
   - 之后靠温度和后熟状态管理，不靠持续加乙烯。

4. **按硬度/色度分批**
   - 色度 2–3 度：还可放，控温 13–15℃。
   - 色度 4–5 度：接近可售，控温 16–18℃。
   - 色度 6 度以上：尽快销售，别再催。

5. **商超实操**
   - 到货先分级，不要整批同温处理。
   - 每天看色度和手感，比固定天数更可靠。
   - 需要延迟销售：**13–14℃ + 通风 + 不要密封**。
   - 需要加快：**20–22℃ + 必要时补一次乙烯**，但别反复催。
