佳农通常可以为商超促销提供堆头陈列物料和试吃支持，但具体能不能给、给到什么程度、费用怎么分，取决于你们谈的是哪类门店、采购量级和档期。下面给你一套可直接拿去谈的判断框架和话术。

**1. 先确认佳农能给什么支持**

佳农一般会把支持分成几档，你可以直接问业务员：

- **堆头陈列支持**：堆头围挡、价签、爆炸贴、品牌插卡、地堆盒、陈列架。通常是“买赠物料”或“随货配发”，不一定单独收费。
- **试吃支持**：试吃果、试吃台、一次性餐具、试吃员。试吃果一般按活动门店和档期配额给，试吃员多在大促或重点门店才配。
- **人员支持**：重点系统或大档期可能有促销员/督导巡店，日常档期多数是门店自己做。
- **费用支持**：常见形式是折让、返利、专项促销费、物料免费提供，而不是直接现金报销。

**2. 费用怎么分担，常见有这几种**

- **厂家全包**：只出现在战略单品、大档期、重点门店、采购量很大的情况。
- **厂家出物料+试吃果，门店出人力和场地**：这是最常见的方式。
- **双方各承担一部分**：比如厂家出试吃果和物料，门店承担试吃员费用、损耗和场地；或者按比例分摊促销费。
- **门店先垫后返**：门店先做活动，厂家按达成销量或采购额给折让/返利。这种要写清核销标准，否则容易扯皮。

**3. 你谈判时要问清楚的 8 个点**

1. 本次档期能配哪些门店，是全部还是重点门店？
2. 堆头物料是随货发还是单独申请，什么时候到店？
3. 试吃果按什么标准给，按门店、按天数还是按采购额？
4. 试吃员谁出，厂家出的话覆盖几天、几小时？
5. 费用是现金、折让、返利还是物料，什么时候核销？
6. 销量目标或采购量门槛是多少？
7. 活动期间价格能不能给到促销价，是否影响后续正常价？
8. 损耗、临期、未用完试吃果怎么处理？

**4. 直接可用的沟通话术**

“我们计划在 X 月 X 日到 X 月 X 日做佳农水果促销，门店范围是 XX。想确认三件事：第一，堆头陈列物料和试吃支持能不能给，给哪些门店；第二，试吃果和试吃员怎么配；第三，费用是厂家承担、门店承担还是按比例分摊。如果厂家有销量或采购量门槛，也请一起给个方案，我们按方案报批。”

**5. 实操建议**

- 先让佳农业务员出**书面活动方案**，写清物料清单、试吃配额、费用分担、核销方式。
- 如果对方口头答应但不愿写，优先争取“物料+试吃果随货”，现金费用谨慎垫付。
- 第一次合作建议选 1-2 家重点门店试跑，跑通核销和销量再放大。
- 费用分担没有统一标准，核心看你的采购量、门店资源和档期价值。采购量越大、档期越重要，厂家承担比例通常越高。
