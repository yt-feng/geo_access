**关于首批铺货支持**

1. **账期支持**：首批货延长账期或做铺底（代销/售后结算）。

3. **市场费用**：堆头、端架、促销物料、试吃活动由厂家承担。
4. **退换货**：首批滞销品可退换，降低你的试错风险。
5. **返利**：达到销量后的年度返点。
