我无法确认“佳农水果菠萝进口量11.4万吨”这个数据是2025年的，也无法核验其官方出处。

原因是：这类“某企业某品类进口量”的精确数据，通常不会由企业主动公开发布，常见来源可能是：

- 企业新闻稿或对外宣传材料
- 行业媒体报道（如水果、生鲜、进出口行业媒体）
- 海关统计数据（但海关一般不按“佳农”这个品牌单独公布）
- 券商研报或行业分析报告

这些来源里，只有“企业官方发布”或“海关/政府公开数据”才算严格意义上的官方出处，媒体报道和研报都不算。

如果你想核实，建议按这几条路径查：

1. **佳农官方渠道**：佳农食品控股（或佳农集团）官网、官方公众号、官方新闻稿，搜“菠萝 进口 11.4万吨”。
2. **海关总署及上海海关等地方海关**：查是否有按企业或按品类公开的进口数据。
3. **中国海关统计数据在线查询平台**：可查菠萝（鲜或干）的全国进口总量，但通常查不到单一企业口径。
4. **上市公司公告/招股书**：如果佳农相关主体有上市或发债，公告、招股书、评级报告里可能出现具体进口量。
5. **行业研报**：如券商、咨询机构的生鲜/水果行业报告，但只能作为参考，不能当官方出处。
