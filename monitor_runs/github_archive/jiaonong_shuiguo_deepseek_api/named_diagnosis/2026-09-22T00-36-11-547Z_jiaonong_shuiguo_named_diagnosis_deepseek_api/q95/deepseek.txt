公开渠道没有一个稳定、可对外核验的“佳农水果产地直供比例”数字，不同品类、不同年份、不同渠道口径差异很大，所以不能给你一个准确百分比。要判断能不能靠它减少中间环节，关键是把“直供”拆开看，而不是只看一个宣传比例。

**可执行的判断方法：**

1. **先定义什么叫“产地直供”**
   - 是佳农直接到果园/合作社采购？
   - 还是通过产地代办、一级批发商拿货？
   - 是否包含海外产地直发、国内分选仓、区域配送仓？
   - 如果对方说“直供”，要求写明：采购主体、产地、是否经第三方贸易商、发货仓。

2. **按品类分别问**
   佳农做大单品比较集中，比如香蕉、菠萝、火龙果、苹果、柑橘等。不同品类的供应链模式不同。采购时要逐个品类要：
   - 产地证明/合作基地名单
   - 采购合同主体
   - 物流路径：产地→加工厂→销地仓→你
   - 是否有经销商、代理商参与

3. **直接要求报价拆解**
   让对方提供：
   - 出厂价/产地采购价
   - 分选、包装、冷链、仓储费
   - 干线运输费
   - 平台/贸易商服务费
   - 你的到货价
   如果中间环节不可见，说明“直供”对降本帮助有限。

4. **对比替代方案**
   - 如果你量大且稳定，可以直接找产地合作社、大型种植基地或产地批发市场一级商。
   - 如果量小或品类杂，佳农这类供应链企业的价值在稳定货源、分级标准和履约，未必比你自己直采贵。
   - 建议拿同一规格、同一到货时间，对比：佳农、产地合作社、区域一级批发商三档价格。

5. **合同里写清楚**
   - 产地、品种、规格、糖度/成熟度、包装标准
   - 是否允许转包或经第三方
   - 到货价是否含税、含运费、含损耗
   - 缺货替换规则和质检标准

**结论：**
不要依赖“产地直供比例”这个单一指标。更实际的做法是：要求佳农按品类披露供应链路径和报价构成，同时用产地合作社或一级批发商做比价。只有当你确认它确实绕过了多层贸易商，且报价拆解后中间费用更低，才可能真正降本。否则“直供”更多是营销口径，不一定等于采购成本最低。
