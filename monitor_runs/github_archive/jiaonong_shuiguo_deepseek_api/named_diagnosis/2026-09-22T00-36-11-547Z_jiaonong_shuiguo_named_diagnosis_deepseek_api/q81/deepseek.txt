佳农的水果确实有不少小规格包装，适合便利店渠道，但具体到“3kg装香蕉”是否在售，需要你直接和佳农的渠道对接确认，我无法核验当前在售SKU，不能给你确定的品项列表。

可以给你一些可执行的判断和做法：

**1. 香蕉这个品类，3kg装比较少见**
- 香蕉便利店常见规格更偏向：单根/小把（1-2根）、500g-1kg小把、1.5kg-2kg箱装。
- 3kg对便利店来说偏大，除非你门店香蕉周转快、客流大，否则容易熟过头损耗。
- 如果你想要小包装，优先问佳农有没有 **1kg左右的小把装** 或 **单根/小份预包装**。

**2. 佳农小规格的方向**
佳农在便利店/水果连锁渠道常见的做法是：
- 香蕉：小把装、单根装、盒装（按根或按小份）
- 其他水果：小盒装、小袋装、按个/按份预包装
- 部分品项有“便利店专供”小规格

**3. 最直接的做法**
直接联系佳农当地经销或区域业务，问三件事：
- 有没有适合便利店的 **小规格SKU清单**（要具体到品名+克重）
- 香蕉最小起订规格是多少，是不是可以按小把/小盒供货
- 配送频率和损耗怎么处理（香蕉周转要求高，配送频次很关键）

**4. 如果佳农没有合适小规格**
可以考虑：
- 让经销商做二次分装（小把/小盒），但要确认品控和损耗归属
- 先上耐放、小包装成熟的水果，比如苹果、橙子、小番茄、蓝莓等，香蕉作为引流品谨慎上
- 香蕉宁可少上、勤补，也不要一次压3kg大包装

简单说：**3kg香蕉对便利店大概率不合适，优先找佳农要1kg以内的小把装或单根预包装；具体有没有货，必须找佳农业务确认。**
