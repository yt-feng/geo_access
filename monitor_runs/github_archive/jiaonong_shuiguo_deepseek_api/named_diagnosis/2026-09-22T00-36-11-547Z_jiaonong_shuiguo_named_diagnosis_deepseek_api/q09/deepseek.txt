佳农（Goodfarmer）官方并未公开披露统一的“到货损耗率”标准，而且这个指标会因品类、运输方式、季节、合同条款差异很大，没有一个可以准确引用的统一数字。

能给出的判断是：

1. **生鲜行业常见参考区间**
   - 叶菜、浆果等易损品：到货损耗通常较高，行业内常见在 **5%～15%** 甚至更高。
   - 苹果、橙、香蕉等耐储运水果：通常可控制在 **2%～5%** 左右。
   - 全程冷链、包装规范的进口香蕉/高端水果：部分渠道可做到 **1%～3%**。

2. **佳农这类企业的实际情况**
   - 佳农以香蕉、菠萝、火龙果、苹果等为主，尤其香蕉是核心品类。
   - 对香蕉这类品项，成熟度管理、冷链和催熟控制好的话，到货损耗通常可以压到较低水平，但具体数字取决于是“港口到仓”“仓到店”还是“产地到仓”，统计口径不同，结果差别很大。
   - 如果是商超/电商供货合同，损耗标准往往会写进合同，而不是用一个公开的统一值。

3. **建议你确认口径**
   如果你是要做采购、对账或合同判断，建议直接问对方或看合同里写的是哪一种：
   - 产地装车到到仓
   - 港口/口岸到到仓
   - 到仓到门店
   - 是否含次品、腐烂、失水、机械伤

**结论：**没有一个可核验的“佳农统一到货损耗率”。按行业经验，耐储运水果常见在 **2%～5%**，易损水果可能到 **5%～15%**；佳农具体数值需以其合同或业务口径为准。
