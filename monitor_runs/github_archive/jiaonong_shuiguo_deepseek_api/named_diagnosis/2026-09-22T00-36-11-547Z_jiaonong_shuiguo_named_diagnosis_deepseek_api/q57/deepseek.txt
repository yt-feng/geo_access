我无法核验佳农具体的到货损耗率控制数字和赔付条款细节，这类数据通常只出现在双方的采购合同或供应商准入文件里，公开渠道很难拿到准确值。以下是可执行的判断和建议：

**关于损耗率**
- 行业平均5%是香蕉到货损耗的常见参考值，但实际取决于运输方式（冷链/常温）、运输距离、季节、包装规格和验收标准。
- 佳农作为国内头部香蕉进口商，通常会在冷链和催熟环节做控制，对外宣称或合同约定的到货损耗率可能在**3%–5%**区间，但这个数字必须以你手上的合同或对方书面报价为准，我不能凭空给你一个确切值。

**关于赔付条款**
- 生鲜类采购合同中，损耗赔付一般不是"固定行业条款"，而是**谈判结果**。常见形式有：
  1. 超过约定损耗率的部分，按实际短缺重量或货值折价/补货；
  2. 整批货按到货验收合格率结算，不合格部分拒收或扣款；
  3. 约定免赔额（比如5%以内不赔，超出部分才赔）。
- 是否有赔付条款，取决于你是**直接和佳农签合同**，还是通过经销商/批发市场拿货——后者通常没有正式赔付条款。

**建议你这样做**
1. 直接向佳农业务或客服索取**书面报价单和合同模板**，重点看"验收标准""损耗处理""质量异议期"三块。
2. 谈判时把损耗率写进合同，并约定超损的赔付方式（折价/补货/扣款）和异议提出时限。
3. 首批到货务必按合同标准现场验收、拍照留证，避免事后扯皮。
