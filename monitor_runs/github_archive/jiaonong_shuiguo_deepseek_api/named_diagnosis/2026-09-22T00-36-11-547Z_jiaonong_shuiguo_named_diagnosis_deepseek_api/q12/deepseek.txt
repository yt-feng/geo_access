佳农水果的香蕉并没有一个对外完全固定的“官方规格表”，实际规格会随产地（如菲律宾、厄瓜多尔、越南等）、季节、到货批次和客户订单变化。下面按行业常见做法给你一个可判断的框架，但具体数字要以佳农当批次的装箱单/报价单为准。

**一、常见规格维度**

1. **按单根重量/等级分**
- 大果：单根约 180–220g 以上，条型粗长，适合高端商超、精品水果店。
- 中果：单根约 140–180g，最通用，适合超市、社区团购、电商。
- 小果：单根约 100–140g，适合便利店、促销装、餐饮切果。
- 特小/加工果：100g 以下或外观次一级，多用于烘焙、奶昔、果切、餐饮。

2. **按每箱净重分**
- 常见 12kg、13kg、18kg、20kg 等箱规，不同产地和包装厂会有差异。
- 也有 4.5kg、5kg、10kg 等小包装，主要走电商、社区团购、家庭装。

3. **按每箱根数/把数分**
- 如 4–6 把/箱、5–7 把/箱等，偏渠道定制。
- 商超喜欢按“把”陈列，电商喜欢按“根数+净重”标品化。

4. **按成熟度/催熟阶段分**
- 青蕉：适合长途运输、批发市场、需要二次催熟的渠道。
- 微黄/黄熟：适合商超、水果店、即时零售。
- 熟蕉：适合餐饮、烘焙、果切、促销。

**二、按渠道的分级建议**

| 渠道 | 建议等级 | 关键要求 |
|---|---|---|
| 高端商超/精品店 | 大果、中果 | 条型均匀、无擦伤、无黑斑、把型整齐、成熟度一致 |
| 普通超市/卖场 | 中果为主 | 性价比高、外观正常、货架期稳定 |
| 社区团购/电商 | 中果、小果 | 标品化、净重稳定、耐运输、适合家庭装 |
| 便利店 | 小果、中果 | 单根或小把装、即食友好、周转快 |
| 餐饮/烘焙/果切 | 中果、小果、加工果 | 重出肉率、成熟度可控、价格优先，外观要求低 |
| 批发市场 | 青蕉、中果/大果 | 耐储运、可催熟、批次稳定 |
| 出口/长途 | 青蕉、硬绿 | 按目的国检疫和成熟度标准，通常更早采收 |

**三、实际采购时怎么判断**

1. 先问佳农当批次的 **产地、箱规、单根克重范围、每箱根数、成熟度**。
2. 再看 **外观等级**：条型、色泽、机械伤、黑斑、把梗完整度。
3. 最后按渠道定：
   - 要卖相：选大果/中果，黄熟或微黄。
   - 要周转：选中果，微黄。
   - 要成本：选小果/加工果，熟度可高。
   - 要运输：选青蕉，到仓再催熟。

如果你是要做采购或渠道分级，最稳妥的方式是直接向佳农当地销售索要 **当批次产品规格书和装箱单**，因为他们的规格会按订单和产地调整，不存在全年完全统一的一套数字。
