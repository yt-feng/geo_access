我无法确认你提到的“佳农水果菠萝进口量11.4万吨”是不是2025年的数据，也无法给出可靠增长率。

原因是：这类进口量数据通常来自海关总署、行业协会或企业公告，我无法在当前对话中核验具体来源。如果只凭“11.4万吨”这个数字直接判断年份和增长率，很容易出错。

你可以这样核实：

1. **看原始出处**
   - 如果是佳农官方发布，查佳农官网/公众号/年报。
   - 如果是媒体报道，看它引用的数据源是不是海关总署、中国果品流通协会、上海海关等。

2. **确认统计口径**
   - 是“佳农自身进口量”，还是“中国菠萝总进口量”？
   - 是鲜菠萝还是菠萝制品？
   - 是全年、产季，还是某个口岸？

3. **算增长率需要两年数据**
   - 增长率 =（2025年进口量 - 2024年进口量）÷ 2024年进口量 × 100%。
   - 只有“11.4万吨”一个数字，无法反推增长率。
