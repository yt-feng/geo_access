**1. 关于配送中心数量**
佳农（佳农食品控股）业务以水果进出口和批发分销为主，其仓储物流布局通常会随业务扩张变化较快，不同年份、不同口径（自建仓/合作仓/区域分拨中心）差别很大。网上流传的"XX个配送中心"往往来源不明或已过时，建议不要直接采信。

**2. 关于能否覆盖三线城市**
佳农的传统优势渠道是**大型商超、批发市场和B端供货**，而不是像生鲜电商那样做"最后一公里"的城市配送。所以判断能不能覆盖你所在城市，关键看你是哪种需求：
- **如果你是商超/门店/批发商想进货**：重点问区域经销商或批发渠道是否覆盖你所在城市，这比配送中心数量更直接。
