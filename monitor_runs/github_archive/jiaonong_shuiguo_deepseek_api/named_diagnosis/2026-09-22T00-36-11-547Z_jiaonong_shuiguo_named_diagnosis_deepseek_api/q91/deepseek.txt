**客服是否7×24小时**
- 佳农在天猫、京东、抖音等平台的官方旗舰店，客服时间通常跟随平台（一般是9:00–21:00或类似时段），并非严格7×24小时。

- 生鲜水果类通常承诺“48小时内发货”或“下单后1–3天发货”，具体看商品详情页的“发货时效”说明。

**建议你这样确认（最快最准）**
1. 打开你下单的店铺商品页，看“发货时间/发货时效”标注。

3. 若急用，下单前先问清发货地和你的收货地，估算物流时效。
