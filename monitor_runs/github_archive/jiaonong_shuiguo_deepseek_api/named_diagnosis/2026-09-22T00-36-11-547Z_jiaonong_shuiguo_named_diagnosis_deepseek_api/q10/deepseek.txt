- 是否给你**单独配一个专属客户经理**，取决于你的采购量、合作稳定性、区域和渠道类型（批发市场、商超供货、电商、餐饮供应链等）。
- 采购量小或初次合作，通常先由区域销售或客服对接，量做起来后才可能升级为专人负责。

**你可以这样确认和推进：**

1. **直接问官方渠道**：通过佳农官网、官方公众号或客服电话，说明你是批发商，问“负责XX区域/XX品类的大宗批发对接人是谁”，要求转区域销售。
2. **问清楚对接机制**：是固定客户经理，还是按订单由销售团队轮流处理。
3. **谈合作时直接提要求**：比如“我们月采购量大概X吨，希望能有固定对接人负责报价、账期、缺货协调”，量够的话对方一般会给。
