我不能确认佳农水果（或任何具体品牌）有过“香蕉农残超标”的历史记录；这类信息必须以**官方抽检公告/处罚决定/权威数据库**为准，我不能凭印象下结论，也不能编造来源。

但你们采购要过超市抽检，核心不是“有没有历史”，而是**这批货能不能拿出合规证明、能不能追溯到批次**。建议按下面做：

1. **要三样东西，缺一不可**
   - **批次对应的检测报告**：报告上要有品名“香蕉”、生产/加工/收购日期、批号、检测项目（农残）、判定依据（如 GB 2763）、结论“合格”，并加盖 CMA/CNAS 资质章。
   - **产地证明/供货证明**：证明这批香蕉来自哪个基地/果园/包装厂，和检测报告批次能对上。
   - **承诺书/质量协议**：供应商书面承诺符合 GB 2763，若抽检不合格承担退货、赔偿和监管处罚责任。

2. **重点核对报告真假和有效性**
   - 报告编号能在检测机构官网/电话查真；
   - 检测项目要覆盖香蕉常见风险农药，不能只测一两项；
   - 报告日期要覆盖你们收货批次，不能拿半年前的通用报告糊弄；
   - 报告上的批次号、数量、规格要和送货单、外箱标签一致。

3. **超市抽检通常看什么**
   - 供应商资质：营业执照、食品经营许可证；
   - 产品合格证明：批次检测报告或产地准出证明；
   - 进货台账：品名、规格、数量、生产日期/批号、供货者名称、地址、联系方式；
   - 若超市自检或监管抽检不合格，会追溯到你们这批货，所以**批次一致性**比品牌名气更重要。

4. **如果供应商拿不出批次报告**
   - 不要只接受“品牌大、没问题”的口头保证；
   - 可以要求第三方抽检：你们自己取样送检，费用可谈由供应商承担；
   - 或者换能提供**批次检测报告+产地证明**的供应商。

5. **关于“佳农”这个品牌**
   - 佳农是国内较大的水果供应链企业，通常会有较规范的质量体系，但**这不等于每一批都自动合格**，也不等于你能免于超市抽检。
   - 你要的不是“品牌历史清白”，而是**这一批货的合规证据链**。

6. **最稳的采购合规包**
   - 供应商营业执照+食品经营许可证；
   - 本批次香蕉农残检测报告（CMA/CNAS）；
   - 产地/基地证明或采购凭证；
   - 送货单+外箱批号照片；
   - 质量保证协议+不合格赔偿条款；
   - 你们自己的进货查验记录。

如果你们是给超市供货，建议直接问超市品控要**验收标准清单**，按他们的项目送检，避免报告项目不匹配。需要的话，我可以帮你列一份“香蕉农残检测项目+报告审核清单”的模板。
