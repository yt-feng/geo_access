佳农（Goodfarmer）主营香蕉、菠萝等进口及国产水果，苹果品类里**红富士是其常见单品之一**，但具体在售与否取决于产地、季节和渠道批次，建议以你对接的佳农销售或官方渠道的当季报价单为准。

关于**新疆阿克苏苹果**：
- 阿克苏苹果的核心品种本身就是**红富士**（阿克苏是红富士的优质产区）。
- 佳农是否有阿克苏产地的苹果，公开信息里并不稳定，不能确认其常年有阿克苏货源。佳农的苹果更多是山东、陕西等产区，阿克苏苹果在国内更多由新疆本地果企、合作社或专门做新疆果的贸易商供应。

**采购建议（可执行）：**
1. 直接问佳农销售：要"阿克苏红富士"的产地证明、果径规格、糖心比例、包装和当季报价，确认是否真有阿克苏货源。
2. 如果佳农没有，走专门渠道：新疆阿克苏本地果业公司/合作社、做新疆果的批发商，或阿克苏苹果地理标志授权企业。
3. 核验产地：阿克苏苹果有地理标志，可要求提供产地证明、检测报告；糖心（果核透明）是阿克苏红富士的典型特征，但非唯一判断标准。
4. 比价时注意规格：按果径（如80#、85#、90#）、糖心率、装箱重量统一口径再比。

一句话：佳农有红富士，但不一定保证是阿克苏产地；要阿克苏苹果，建议同时向佳农和新疆本地专营渠道询价核实。
