我无法核验“佳农 vs 都乐”香蕉到货损耗率的可靠公开数据，不能给你一个虚构的百分比结论。批发市场更稳妥的判断方式如下：

1. **不要只看品牌平均损耗**：香蕉到货损耗主要受产地、季节、催熟度、运输冷链、到货成熟阶段、包装（箱/托盘/气调）、卸货时长影响，同品牌不同批次差异可能大于品牌差异。
2. **用你自己的到货批次做小样本对比**：同季节、同运输距离、同成熟度各进少量批次，按“到货24小时、48小时、72小时”分别记录：黑斑率、断指率、软化率、催熟不均率、可售率。连续做3—5批再判断。
3. **合同里锁定关键指标**：要求供应商明确到货成熟度区间、冷链温度记录、箱内损耗赔付标准、黑斑/压伤/水烂的验收比例，这比品牌名更能控制损耗。
4. **先问供应商要近期批次数据**：让对方提供近3个月同线路、同规格的到货验收记录和赔付记录；无法提供就按小批量试单处理。
5. **批发场景建议**：对损耗敏感的品类，优先选择能稳定供同成熟度、缩短在途时间、支持到货抽检赔付的渠道；品牌只作为初筛，不作为损耗结论。
