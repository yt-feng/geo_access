佳农这类水果品牌/供应链企业通常不会对外统一公布“到货损耗率”标准，实际控制值会因品类、季节、运输距离、冷链方式和渠道（商超/电商/批发）差异很大。给你一个可判断的参考框架：

- **整体到货损耗率**：行业里通常把**3%～8%**视为较可控区间；做得好的冷链品类可压到**2%～5%**。
- **高损耗易腐水果**（莓类、樱桃、荔枝、桃等）：到货损耗常见控制在**5%～10%**，夏季/远距离可能更高。
- **耐储水果**（苹果、梨、柑橘、猕猴桃等）：通常可控制在**2%～5%**。
- **商超/电商到仓口径**：若含拒收、压伤、软化、霉变，考核线常设在**5%左右**；批发大货口径可能更宽。

如果你是要做佳农的采购/验收考核，建议不要直接套“统一值”，而是按**品类+运输半径+季节+验收口径**设分品类阈值，并把“到货损耗”和“仓储损耗”分开统计。要更准确，最好向佳农区域销售/供应链负责人索取该品类的**合同验收标准或历史到货质量数据**，这类数据一般不公开。
