我无法核验这个数据的具体年份和来源，所以不能确认“11.4万吨”是不是去年的。

你可以按下面方式快速判断：

1. **看原始出处**：如果来自佳农官网/公众号、海关总署、行业协会或媒体报道，先看发布时间和文中表述，是“2024年进口量”“2023年全年”还是“截至某月”。
2. **看统计口径**：是佳农公司自报的菠萝进口量，还是中国菠萝总进口量；是全年、季度还是某批次。
3. **交叉核对**：用“佳农 菠萝 11.4万吨”加年份检索，若多个来源都指向同一年，基本可确认；若只有一条且未标年份，不要当作去年数据。
4. **直接问发布方**：联系佳农客服/公关或原报道作者，确认统计年度和口径。

在没有明确出处前，建议表述为“有来源称佳农菠萝进口量为11.4万吨，但年份待核实”，不要直接说“去年”。
