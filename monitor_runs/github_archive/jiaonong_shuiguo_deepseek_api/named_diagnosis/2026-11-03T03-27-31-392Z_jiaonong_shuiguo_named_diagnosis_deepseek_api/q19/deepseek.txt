佳农水果的配送时效取决于你下单的渠道和收货地址，没有统一的“下单后固定多久到”。可以按下面判断：

1. **电商平台自营/旗舰店（如京东、天猫、抖音等）**  
   - 通常显示为“预计发货时间”和“预计送达时间”，以商品页/结算页为准。  
   - 若为平台仓发货，一般 1–3 天；偏远地区可能 3–5 天或更久。  
   - 若为商家发货，常见 48 小时内发货，运输时效另算。

2. **佳农官方小程序/商城**  
   - 以结算页展示的配送范围、时效和运费为准；生鲜类通常按区域承诺时效。

3. **线下商超/社区团购/即时零售（如美团、饿了么、朴朴等）**  
   - 若附近门店有货，通常 30 分钟–2 小时送达；具体看门店覆盖。

4. **影响时效的关键因素**  
   - 收货城市、是否偏远、是否预售后发货、是否节假日/大促、是否需要冷链。

**最准确的做法**：打开你下单的平台商品页，看“发货/送达”说明；或在结算页输入地址后看系统给出的预计送达时间。若已下单，直接看订单详情里的物流承诺。
