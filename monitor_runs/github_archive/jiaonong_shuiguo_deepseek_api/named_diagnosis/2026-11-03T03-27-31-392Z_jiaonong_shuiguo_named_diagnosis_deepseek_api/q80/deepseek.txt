1. **向供应商/佳农官方索要**
   - 要“**与本次到货批次对应**”的检测报告，不接受只有品名、没有批次的通用报告。
   - 报告上应有：样品名称（香蕉）、生产/进口商或供货商、**批号/生产日期/采收或包装日期**、检测机构、报告编号、检测日期、检测项目、方法、限量和结论。
   - 确认检测项目覆盖你方市场抽检常检项：常见为有机磷、氨基甲酸酯、拟除虫菊酯等农药多残留；具体以当地市场监管抽检细则和平台要求为准。

2. **核验报告有效性**
   - 看检测机构是否具备**CMA**资质（必要时**CNAS**），报告是否在有效期内。
   - 通过报告上的机构名称/编号到该机构官网或官方查询渠道核验，避免复印件、PS件。
   - 核对报告批次与送货单、外箱标签、合格证是否一致。

3. **采购合同里写清楚**
   - 每批随货提供**批次农残检测报告**；抽检不合格由供方承担退换货、检测费和监管处罚相关责任。
   - 约定抽检标准：按你所在地市场监管部门当季水果抽检项目和GB 2763农药最大残留限量执行。
   - 保留留样和进货台账，便于追溯。

4. **自己复核**
   - 对高风险批次可送第三方检测机构做“农药多残留筛查”，费用和周期问当地CMA机构；采购量大的可要求供方承担或分摊。
