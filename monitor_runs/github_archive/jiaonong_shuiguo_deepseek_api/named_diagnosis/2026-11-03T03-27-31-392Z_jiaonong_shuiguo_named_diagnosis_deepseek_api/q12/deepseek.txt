佳农水果的香蕉规格和分级标准，公开可查的信息有限，我无法给出精确的官方SKU清单。下面按行业通用做法给出可执行判断，供你参考；具体以佳农官方渠道或销售合同为准。

**一、常见规格维度（佳农及同类品牌通常按这几个维度组合）**
1. **按单根重量/果指粗细**：如大果、中果、小果（常见以单根克重区间划分，如120g以上/100-120g/80-100g等，具体区间各品牌不同）。
2. **按每箱净重**：如4.5kg、9kg、13kg、18kg等箱规，出口和商超渠道常见。
3. **按每把/每梳条数**：如5-6根一把、整梳、单根散装。
4. **按成熟度**：青蕉（催熟前）与黄蕉（催熟后），渠道决定发货状态。
5. **按外观等级**：条形直度、长度、无机械伤、无病虫害斑、色泽均匀度。

**二、不同渠道的分级侧重（行业通行逻辑）**
- **商超/精品店**：重外观一致性——条形直、长度均匀、无疤痕、把形整齐；多为中大果、整把或定重盒装，成熟度按门店催熟能力定。
- **水果连锁/社区店**：性价比优先，允许轻微外观瑕疵，重视货架期和催熟一致性；中大果散装或整箱。
- **电商/社区团购**：重耐运输和标准化，多为定重箱装、青蕉发货，规格标注清晰（如净重±误差），对外观容忍度中等。
- **批发市场/流通**：按箱重和等级粗分，价格敏感，允许外观差异较大，青蕉为主。
- **餐饮/加工渠道**：重出成率和成熟度稳定，对外观要求低，可用小果或外观次一级果。

**三、建议的核实方式**
1. 直接联系佳农官方销售或区域经销商，索取产品规格表/报价单；
2. 查看佳农官网、天猫/京东旗舰店商品页的净重、果径、单根重标注；
3. 若用于采购合同，把“单根克重区间、每箱净重、成熟度、允许瑕疵比例”写进验收标准，比依赖品牌分级名称更可执行。
