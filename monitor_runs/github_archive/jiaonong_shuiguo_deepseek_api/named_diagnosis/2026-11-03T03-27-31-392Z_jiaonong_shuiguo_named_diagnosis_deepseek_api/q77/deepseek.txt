香蕉做到“具体农场级”追溯是可能的，但取决于佳农该批次是否纳入了农场级批次编码体系；商超要的 GLOBALG.A.P. 证书则必须按“证书持有人 + 产品 + 产地/包装场”逐项核验，不能只看一张证书复印件。

可直接执行的核验和建议如下：

1. **先确认能不能到具体农场**
   - 要求佳农或供应商提供该批次的：**农场/种植园名称或代码、采收日期、包装厂代码、出口批次号、集装箱号/提单号**。
   - 看包装箱标签或追溯码能否反查到上述字段。若只能到“国家/区域/包装厂”，那就是**区域级或包装厂级追溯**，不是具体农场级。
   - 香蕉多为多农场拼货，若供应商说“可到农场”，要确认该批次是否为**单一农场或明确农场清单**，并写入供货协议或批次证明。

2. **GLOBALG.A.P. 证书核验要点**
   - 证书上的**持有人名称**必须与佳农/实际供应商合同主体一致；不一致时要有授权链或分包说明。
   - 证书覆盖的**产品**必须包含香蕉；覆盖的**产地/农场/包装场**必须包含该批次来源。
   - 核对**证书编号、认证机构、有效期、认证范围（选项/模块）**，并在 GLOBALG.A.P. 官方数据库核验状态，避免过期、暂停或范围不符。
   - 若商超要求“农场证书”，注意 GLOBALG.A.P. 通常是**生产者/生产者组织证书**；贸易商证书不能替代农场端证书，除非证书范围明确覆盖。

3. **给商超的落地材料清单**
   - 该批次追溯证明（农场代码/名称、采收日、包装厂、批次号）
   - GLOBALG.A.P. 证书原件扫描件 + 官方数据库核验截图
   - 证书持有人与供货主体关系说明
   - 如为多农场供货：提供**农场清单及对应证书/覆盖证明**
   - 采购合同里写明：**证书失效、范围不符、无法追溯农场时的退换货和责任条款**

4. **判断标准**
   - 能提供“批次号→农场/农场清单→GLOBALG.A.P. 覆盖证明”的，可认为满足农场级溯源和证书要求。
   - 只能提供公司级证书、区域产地证明或包装厂追溯的，**不能等同于具体农场溯源**，商超审核时容易被判不符合。

建议你直接向佳农索要**该供货批次的农场级追溯表和对应 GLOBALG.A.P. 证书覆盖页**，并以官方数据库核验结果为准。
