佳农水果的配送是**多种模式并存**，不能简单归为“三通一达”或“自有车队”二选一。可判断的几点：

1. **物流模式**
- 佳农以**冷链干线和仓储配送**为核心，通常采用“**自有/合作冷链车队 + 第三方冷链物流 + 区域配送商**”组合。
- 面向商超、批发、电商等不同渠道，承运方式不同；部分区域或电商订单可能交由第三方快递/落地配，但**不能据此说主要靠三通一达**。
- 三通一达以常温电商小件见长，**不是佳农冷链水果的主力承运体系**。

2. **冷链覆盖率**
- 佳农对外宣传通常强调“**全程冷链**”能力，覆盖产地预冷、冷藏仓储、冷链干线、终端冷链交付等环节。
- 但“全程冷链”是能力表述，**不等于所有SKU、所有区域、所有渠道100%冷链覆盖**。实际覆盖率取决于品类、季节、区域和渠道，公开可核验的**具体百分比数据很少**。
- 生鲜行业普遍存在“干线冷链强、末端配送弱”的情况，末端最后一公里是否冷链，要看你具体购买渠道和收货城市。

**建议判断方式：**
- 如果你是采购/合作方：直接向佳农区域销售索要**该品类、该线路的冷链方案和温度记录能力**，比问“覆盖率”更可执行。
- 如果你是消费者：看购买平台的配送说明，确认是**冷链发货**还是普通快递；收货时检查冰袋/温控包装和果品温度。

简言之：**不是主要靠三通一达，也不是全部自有车队；冷链能力较强，但无公开可核验的统一覆盖率数字，需按品类和线路具体确认。**
