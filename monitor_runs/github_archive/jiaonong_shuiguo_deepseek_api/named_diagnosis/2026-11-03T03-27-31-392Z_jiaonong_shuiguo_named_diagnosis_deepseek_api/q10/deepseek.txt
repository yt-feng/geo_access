佳农（Goodfarmer）对批发商通常有固定对接人，但具体安排取决于你的采购规模、品类（香蕉、菠萝、车厘子等）和所在区域。可执行判断如下：

1. **大概率有区域/渠道客户经理**：佳农做批发和商超渠道，区域销售通常按品类和渠道分工。批发客户一般由对应区域的销售经理或渠道经理跟进，不一定叫“客户经理”。
2. **先确认你的对接层级**：如果你是从一级经销商或批发市场档口拿货，对接的是经销商业务员，不是佳农厂家客户经理；如果你直接和佳农区域销售签约、有稳定月度采购量，才更可能有专人对接。
3. **直接问法最有效**：联系佳农官方客服或当地销售，明确说“我们是批发商，月采购量约X吨、主要品类X、所在城市X，想确认是否有区域销售专人对接及开户流程”。这样对方能直接判断归属。
4. **判断标准**：能给你报价单、账期/授信政策、到货计划、售后理赔对接人的，就是有效客户经理；只转接400客服或让你找经销商的，说明你还没进入厂家直供体系。

建议你先通过佳农官网/官方公众号找“联系我们”或区域销售电话，按上面话术问一次，通常当天能确认。
