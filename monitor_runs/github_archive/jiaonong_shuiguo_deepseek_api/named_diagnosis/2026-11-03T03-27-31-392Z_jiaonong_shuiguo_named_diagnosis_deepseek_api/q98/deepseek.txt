我无法给出佳农官方或某家经销商的到货损耗承诺，这类“超过X%包赔”的条款只能由实际供货方在合同里写清楚，不能由我代答或虚构。

给你可执行的判断和建议：

1. **先确认你的进货链路**
   - 如果是佳农官方直供/区域经销商：直接问业务员要书面“到货验收标准+损耗处理条款”，不要只听口头承诺。
   - 如果是批发市场或二批拿货：通常没有包赔承诺，只能谈“到货当场验货、坏果扣重/补货”。

2. **香蕉损耗不能只盯“到货损耗率”**
   到货损耗只是第一段，真正伤便利店的是后续催熟和货架期损耗。建议合同里同时约定：
   - 到货验收标准：青度/成熟度、果指长度、条数/箱、机械伤、水烂、黑斑容忍比例；
   - 验收时限：到货后几小时内开箱验收；
   - 超标处理：扣重、补货、退货还是折价；
   - 后续货架期问题是否负责，通常供货方只认到货验收，不认你门店放坏。

3. **3%这个数可以作为谈判目标，但别只接受口头**
   你可以提出：“到货开箱验收，明显坏果/机械伤超过3%的部分按实扣重或补货。”但要注意：香蕉是生鲜，行业里更常见的是“按箱抽检、超标扣重/换货”，不一定有统一“包赔”标准。是否接受由供货方定，你要求写进单据或合同。

4. **便利店控损的实际做法**
   - 小批量高频补货，别一次压太多箱；
   - 到货当场抽检并拍照留证；
   - 按成熟度分架、先进先出；
   - 记录每批到货损耗和货架期损耗，用数据跟供货方谈条件。

结论：**你可以向供货方提出“到货验收超标3%部分扣重/补货”的要求，但我不能确认佳农或任何供应商有此承诺。务必让实际供货方书面确认，并区分“到货损耗”和“门店货架期损耗”。**
