佳农（Goodfarmer）主要做香蕉、火龙果、菠萝、车厘子等进口/国产水果，售后政策通常取决于你从哪个渠道购买，不能一概而论。可以按下面判断和处理：

1. **先确认购买渠道**
   - 京东自营/天猫旗舰店/抖音旗舰店/拼多多官方店：一般走平台售后，坏果通常支持“拍照取证+按比例赔付/补发/退款”。
   - 线下商超/水果店：找门店处理，通常换货或退款，但各家执行不一。
   - 社区团购/第三方店铺：售后由团长或店铺承担，佳农官方不一定直接兜底。

2. **到货有坏果的处理步骤**
   - **先别扔**：保留坏果、包装箱、快递面单，拍清晰照片/视频，最好把坏果和面单放一起拍。
   - **尽快申请**：多数平台要求签收后24—48小时内反馈，越早越好。
   - **走平台售后入口**：订单页选“售后/退款/坏果赔付”，上传证据，说明坏果数量。
   - **联系店铺客服**：如果平台入口处理慢，直接找店铺客服，要求按坏果比例赔付或补发。
   - **保留沟通记录**：聊天记录、客服承诺截图都留好，便于平台介入。

3. **常见赔付方式**
   - 按坏果比例部分退款；
   - 补发坏果部分；
   - 整单退款/退货（坏果比例高或整箱变质时）；
   - 平台优惠券补偿。
   具体以店铺页面“售后说明”和平台规则为准。

4. **如果售后不顺畅**
   - 先申请平台官方介入；
   - 电商平台可走投诉入口；
   - 保留证据向12315投诉。

**建议**：下单前先看商品详情页的“坏果包赔”说明和店铺评分，优先选京东自营、天猫旗舰店等售后入口明确的渠道。到货后第一时间开箱验货，坏果拍照别丢，24小时内提交售后，处理效率通常最高。
