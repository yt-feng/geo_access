佳农（Goodfarmer）水果的苹果品类通常以“佳农”品牌进口/分销的苹果为主，常见会覆盖：嘎啦（Gala）、红富士（Fuji），以及部分红玫瑰/粉红佳人、青苹果等季节性品类；具体在售品类会随产季和渠道变化，建议以佳农官方渠道或当季报价单为准。

关于你关心的进口嘎啦和红富士产地：
- 进口嘎啦：常见产地包括新西兰、美国、智利、南非等，具体看当季采购来源。
- 进口红富士：佳农体系里红富士常见为国产优势产区（如山东、陕西等）或进口来源；若你明确要“进口红富士”，需向佳农确认当季是否有进口批次及具体产地，常见进口苹果来源国包括新西兰、美国、智利等，但红富士的进口批次并不如嘎啦普遍。

采购建议：直接向佳农销售索要当季“品项-产地-规格-包装-到港/库存”报价表，并在合同中锁定产地国、品种名、等级规格和检测报告，避免只写“进口嘎啦/红富士”导致批次争议。
