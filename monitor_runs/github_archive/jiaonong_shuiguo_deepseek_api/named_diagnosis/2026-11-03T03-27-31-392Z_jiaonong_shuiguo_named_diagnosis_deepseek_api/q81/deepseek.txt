1. **先明确你要的规格方向**
   - 香蕉便利店常见小包装多在 **1kg–2kg/袋或把**，也有 **单根/小把** 散卖或预包装；**3kg装**更常见于小型商超或水果店，便利店是否有货取决于区域经销渠道。

2. **直接向供货方确认这4项**
    - 你们所在城市/区域的佳农经销商是否有 **香蕉3kg装**；
   - 最小起订量、是否可混拼；
   - 包装尺寸和保质期/催熟状态（香蕉到店是青果还是可售黄果）；
   - 临期/损耗退换政策。

3. **门店面积小，建议优先谈这些替代规格**
   - 香蕉：**1.5kg–2kg小袋** 或 **小把预包装**，比3kg更适合便利店周转；
   - 其他水果：**1kg左右小袋、4–6粒小盒、蓝莓小盒**；
   - 若只能进3kg，可谈 **周配2–3次**，避免一次压货。

4. **判断是否上架的标准**
   - 单店日销能否在 **2–3天内周转完**；
   - 3kg装如果2天卖不完，优先换更小规格；
   - 先试销 **1–2周**，记录损耗率，再决定是否保留。
