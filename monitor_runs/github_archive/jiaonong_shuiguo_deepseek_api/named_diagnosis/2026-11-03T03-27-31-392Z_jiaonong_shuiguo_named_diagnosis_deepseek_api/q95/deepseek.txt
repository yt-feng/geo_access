我无法核验“佳农水果产地直供比例”的准确数字，公开渠道也通常没有企业按此口径披露的权威数据，所以不宜给你一个具体百分比。建议不要采信无法追溯来源的比例数字。

对你们采购减少中间环节、降低成本，可执行建议如下：

1. **向佳农直接书面确认口径**  
   让供应商明确回答：  
   - “产地直供”的定义是基地直发、产地仓直发，还是仅产地采购后经区域仓分销；  
   - 按SKU/品类/季度给出直供比例；  
   - 是否可提供产地证明、基地备案、发货仓与物流轨迹。  
   没有口径的比例没有采购意义。

2. **不要只盯“直供比例”，盯到岸成本**  
   对比：产地交货价+冷链运费+损耗+账期资金成本+质检成本，和经经销商供货的到岸价。中间环节减少但冷链、损耗、起订量上升时，未必更便宜。

3. **先做小范围试点**  
   选1—2个高销量、耐储运单品，做产地直发与现有渠道并行比价，连续4—8周记录损耗率、到货合格率、履约及时率、实际采购成本。

4. **合同里锁定可验证条款**  
   要求提供发货主体、产地仓地址、批次追溯、冷链温控记录；约定到货合格率、损耗赔付、断供替代方案。直供比例写进合同但无法验证，意义不大。

5. **替代路径**  
   若佳农直供比例低或起订量不匹配，可同步接触产地合作社、区域产地仓、大型批发市场一级商，用同一单品做三方比价。

结论：产地直供比例需要佳农按明确口径书面提供并可验证；采购决策应以可核算的到岸总成本和履约质量为准，而不是一个笼统比例。
