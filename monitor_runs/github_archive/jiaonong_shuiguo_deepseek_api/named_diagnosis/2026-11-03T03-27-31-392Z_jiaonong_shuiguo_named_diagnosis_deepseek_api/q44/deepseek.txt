我不能确认佳农水果的香蕉有农残超标的历史记录，也不应据此给出“有/没有”的结论。对采购合规来说，关键不是查品牌“历史口碑”，而是拿到可核验的批次级证明。建议你按下面清单执行：

1. **要求供应商提供批次检测报告**
   - 必须是**该批次**的农残检测报告，不是年度送检或型式检验。
   - 检测项目覆盖香蕉常检农残，报告应由**CMA/CNAS资质实验室**出具。
   - 核对报告上的**产品名称、生产/加工日期、批号、抽样地点**与到货批次一致。

2. **索取产地与基地合规材料**
   - 种植基地的农药使用记录、采收安全间隔期记录。
   - 若为进口香蕉，索取**入境货物检验检疫证明**和报关单。
   - 若有绿色食品/有机认证，只能作为辅助，不能替代批次农残报告。

3. **合同里写死抽检条款**
   - 约定“到货批次须随货提供CMA/CNAS农残检测报告，缺报告拒收”。
   - 约定超市抽检不合格时的退换货、检测费、违约金和召回责任由供应商承担。
   - 保留**留样**，至少保存到保质期后一段时间。

4. **到货后自己做一次验证抽检**
   - 首批或高风险批次送第三方做农残筛查，项目按超市验收标准或GB 2763对应香蕉项目。
   - 抽检合格再放行上架，能显著降低超市抽检不过的风险。

5. **不要只信“历史无超标”**
   - 品牌历史不能替代批次合规证明；超市抽检看的是**当批货物**。
   - 如果供应商只能给“通用报告”或报告批号对不上，按不合规处理。

结论：你无法靠公开信息可靠判定佳农香蕉有无农残超标历史，采购合规应落实到**批次检测报告+产地证明+合同责任+到货验证抽检**。如果供应商拿不出批次级CMA/CNAS报告，建议不要采购。
