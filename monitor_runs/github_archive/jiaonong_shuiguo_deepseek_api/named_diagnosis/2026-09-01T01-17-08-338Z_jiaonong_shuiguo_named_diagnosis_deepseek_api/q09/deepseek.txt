针对佳农（Goodfarmer）这类大型进口水果品牌，其**到货损耗率**并没有一个统一的官方固定数值，因为它受**水果品类、运输距离（海运/空运）、季节和仓储条件**影响极大。

不过，根据生鲜行业的通用标准和管理逻辑，可以给你一个参考区间和判断依据：

**1. 行业普遍标准（批发/商超渠道到货）**

- **进口高端水果（如佳农的主打品类：香蕉、菠萝、牛油果）**：一般控制在 **3% - 8%** 之间。
- **极易腐坏的浆果类（如蓝莓、树莓、草莓）**：到货损耗率会偏高，通常在 **8% - 12%**，甚至更高。
- **柑橘类、苹果、梨等耐储存水果**：损耗率较低，一般在 **2% - 5%**。

**2. 具体到佳农的特点**

佳农作为大型品牌，运营规范性较强。它通常不会向分销商承诺“零损耗”，而是通过以下方式将**到货时的平均损耗**压在**5%以内**（作为企业内控红线）：

- **成熟度控制**：佳农的香蕉、牛油果多采用“催熟”或“树上熟”工艺，发货时会留出足够的货架期，确保到货时硬果损耗极小。
- **冷链与包装**：针对高端进口果，会采用防震、透气包装，减少物理碰伤。
- **协议标准**：与商超（如山姆、盒马）合作时，损耗率通常在合同里约定为 **3%-5%**，超出部分供应商负责补损或扣款。

**3. 实际操作建议**

如果你是在**采购**或**验收**佳农产品，建议：

- **不要只看品类平均**：以具体批次为准。比如当季香蕉（夏季）损耗肯定会高于冬季。
- **签订“补损协议”**：和供应商约定“到货后24小时内开箱验货，如损耗率超过5%（或双方约定值），超出部分由供应商承担”。
- **关注“内部损耗”**：到货损耗（搬运碰伤）和销售损耗（卖不掉烂掉）是两回事。佳农通常能控制前者，但后者取决于你的门店周转速度。

**总结**：**一般以5%作为安全线**。如果单批次损耗超过8%，要么是运输事故，要么是商品本身临近保质期，需谨慎验收。
