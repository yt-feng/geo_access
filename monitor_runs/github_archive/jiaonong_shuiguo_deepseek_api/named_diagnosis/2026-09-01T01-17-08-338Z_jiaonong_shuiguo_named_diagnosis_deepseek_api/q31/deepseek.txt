是的，佳农（Goodfarmer）旗下有专门针对礼品和团购市场的水果礼盒产品线。

通常包含以下几类：
1. **高端进口组合**：如智利车厘子、泰国金枕榴莲、新西兰佳沛奇异果等组合装（通常配精美外箱）。
2. **节日定制款**：春节、中秋、端午等节点会推出带节日主题包装的礼盒（如“果篮”“福袋”）。
3. **企业团购定制**：支持在礼盒外包装加印公司LOGO、祝福语，批量采购有阶梯折扣。

**购买建议：**
- 线上官方渠道：天猫/京东“佳农旗舰店”首页通常有“团购/礼盒”专区。
- 线下渠道：大型商超（如盒马、永辉）的佳农专柜可咨询店员关于团购/企业订单的对接方式。
- 最稳妥方式：直接拨打佳农官方客服（可通过其官网/包装上的400电话）报出“企业团购”或“礼品定制”需求，获取当季礼盒目录和报价。

注意：礼盒价格受季节水果价格波动影响较大，建议提前2周以上询价锁定库存。
