关于佳农（Joyvio）能否稳定供应适合茶饮店的菠萝，我可以明确告诉你：**能，而且他们对餐饮渠道（B端）有专门的规格体系，不是只有超市里的整果。**

不过，为了让采购更顺利，你需要和他们沟通时明确**几个关键参数**。以下是你听得懂、也能直接拿去和他们业务员对线的“规格白话”：

**1. 先明确你买的是“带皮果”还是“果肉”**
- **带皮果（整菠萝）**：佳农常见规格是 **5kg/箱（约4-6个头）**，或者 **10kg/箱**。用于自己切丁、做鲜果茶。
- **去皮果肉（切丁/切块）**：如果你不想雇人削皮，他们也有 **1kg/袋 或 2kg/袋 的冷冻/鲜切菠萝丁**，甜度统一。

**2. 你要的核心卖点（茶饮专用）**
- **糖度（白利度）**：茶饮店一般要求 **11°-13° Brix**（这个数值越高越甜）。佳农的菲律宾菠萝（MD2品种）通常是这个范围，你做冰沙或柠檬茶不会太酸涩。
- **成熟度**：如果你买整果，一定要要求 **“转黄期”**（果皮泛黄、按起来微软），不要买全青的，不然放两天也不熟。

**3. 怎么下订单最稳妥（防断货）**
- **方案A（整果）**：提前 **3-5天** 下单，佳农在批发市场（如广州江南市场、上海辉展市场）都有固定档口，可以日配。
- **方案B（冷冻果肉）**：这个最稳，几乎不会断供，但你要有冷冻柜（-18℃），解冻后做饮品不影响口感。

**4. 给你的靠谱咨询话术（直接照抄）**
> “你好，我是茶饮店（或公司），想拿你们菲律宾MD2菠萝的**餐饮装**。请问有没有**5kg带皮装**或者**可做茶饮的1kg鲜切丁**？你们给餐饮客户是走**冷藏直送**还是**市场自提**？我需要每周固定送**XX箱**，能否签个保供协议？”
