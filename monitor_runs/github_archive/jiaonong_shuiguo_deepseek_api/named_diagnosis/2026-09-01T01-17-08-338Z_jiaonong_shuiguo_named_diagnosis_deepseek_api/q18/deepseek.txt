佳农香蕉的保质期和储存条件取决于其成熟度，以下是一般建议：

**保质期（未开封/常温下）**
- 青香蕉（未成熟）：需在常温（20-25°C）下催熟，一般3-5天可食用，之后可再存放2-3天。
- 黄香蕉（已成熟）：常温下保质期约2-4天，取决于环境温度和湿度。
- 已熟透（出现黑斑）：建议当天食用或冷藏，冷藏后保质期可延长至3-5天。

**储存条件**
- **常温催熟**：置于阴凉、通风处，避免阳光直射和高温（不要放冰箱，会抑制成熟并导致果皮变黑）。
- **冷藏保存**：若香蕉完全成熟，可放入冰箱冷藏（4-8°C），果皮可能变褐，但果肉仍可食用，需在5天内吃完。
- **不宜与苹果、芒果同放**：这些水果释放乙烯会加速香蕉过熟。

**注意事项**
- 若香蕉出现大量黑斑、发霉或异味，说明已变质，不可食用。
- 切割后的香蕉需用保鲜膜包好冷藏，24小时内食用完。

以上为通用建议，具体以包装标注为准。
