**2. 是否有进口苹果？**
**有，但通常只占该品牌苹果线的一小部分。** 佳农会季节性、区域性引进以下品种，具体要看当季市场供应：

- **青苹果（Granny Smith）**：通常来自智利或美国，酸度高，适合烘焙或喜欢酸口的人。
