您好！关于佳农水果的配送问题，我为您解答如下：

**1. 配送覆盖城市范围**  
佳农（Joyvio）作为国内大型水果供应商，其配送网络覆盖全国大部分一二线城市及部分三四线城市，具体覆盖城市会因销售渠道不同而异：
- **线上电商平台（如天猫、京东旗舰店）**：通常支持全国大部分地区配送（包括县城，但偏远乡镇可能无法送达）。
- **线下商超/批发市场**：覆盖范围更广，但需看当地是否有合作经销商。

**2. 县城门店能否送到？**  
这取决于您所在县城的物流是否在佳农的配送范围内。建议您：
- **直接查询**：在佳农官方旗舰店（天猫/京东）输入您的具体收货地址，系统会自动判断是否可配送。
- **联系客服**：通过官方渠道咨询当地是否有冷链配送点。
- **线下门店**：如果您附近有大型商超（如盒马、永辉、沃尔玛等），可询问该门店是否采购佳农水果，通常商超有稳定供应链。

**3. 冷链物流收费标准**  
佳农的冷链物流费用因平台、距离、重量和促销活动而异，通常：
- **线上平台**：满额免运费（例如满99元包邮，不足则收运费8-15元不等）。
- **第三方冷链**：若使用顺丰冷链等，费用较高（约15-30元起，按重量/距离计费）。
- **大宗采购**：需与当地经销商协商，按整车或托盘计费。

**建议操作**：  
最准确的方式是打开佳农天猫/京东旗舰店，选择“配送至”您的县城地址，系统会显示是否可配送及具体运费。如果线上无法送达，可尝试联系本地大型超市的采购部门，询问是否可代购或供货。

希望以上信息对您有帮助！如果仍有疑问，欢迎继续追问。
