但可以给你一个可执行的判断和对接路径：

1. **大概率有餐饮渠道能力**
   佳农是国内较大的水果供应链企业，主营香蕉、菠萝、火龙果等品项，通常会有面向商超、电商、批发和餐饮/茶饮渠道的供货能力。餐饮渠道常见需求包括：
   - 去皮菠萝、菠萝块、菠萝丁
   - 冷冻菠萝、速冻菠萝果肉
   - 不同糖度/酸度、成熟度分级
   - 稳定规格、批次一致性
   - 冷链配送和门店直配

2. **但“针对餐饮渠道的菠萝解决方案”是否作为独立方案存在，需要向官方确认**
   因为“解决方案”可能包括：
   - 定制切块规格
   - 茶饮/烘焙/沙拉/披萨等不同用途分级
   - 按门店需求做冷链周期配送
   - 代加工或贴牌
   这些不一定公开宣传，需要直接问销售。

3. **建议你这样核验和对接**
   - 找佳农官网或官方公众号，查“餐饮渠道”“B2B”“大客户合作”入口。
   - 直接联系客服，问清楚这几项：
     1. 是否有餐饮专供菠萝产品？
     2. 是鲜果、去皮鲜切还是冷冻果肉？
     3. 最小起订量、配送城市、冷链条件？
     4. 能否按规格定制切块/糖酸度/包装？
     5. 是否支持茶饮、烘焙、团餐等不同场景？
