这个问题没法给你一个准确的“每箱便宜几块”的数字，因为佳农和都乐的香蕉批发价**不是全国统一固定价**，它随下面这些因素每天/每地区都在变：

- 产地（菲律宾、厄瓜多尔、越南、国产等）和季节
- 规格（单根克重、每箱净重，比如18斤/20斤/25斤装）
- 等级（一级果、二级果、外观瑕疵率）
- 到货口岸和你的城市（上海、广州、北京、郑州价差明显）
- 采购量、是否长期合作、是否现款
- 当天的市场到货量和行情

所以“佳农比都乐一箱便宜几块”这种说法，**在不同时间地点可能完全相反**：行情紧的时候都乐可能还更贵，走货慢的时候两者都可能倒挂。

**能给你的可判断结论：**

1. **品牌定位上**，都乐（Dole）在国内商超和高端渠道的品牌溢价通常更高，终端零售价一般略高于佳农。批发端佳农**大概率**有一定价格空间，但不是绝对每次都比都乐低。

2. **走量批发的实际价差**，同一规格、同一等级、同一天同一个市场对比，常见区间大致在**每箱几元到十几元**，具体哪头低、低多少，必须以你当地当天的报价为准。这个数字我不能凭空给你一个确定的“便宜3块”或“便宜5块”，那样会误导你。

3. **对批发商真正重要的不是单箱差价，而是：**
   - 同规格下的**净重和损耗率**（箱皮重、烂果率）
   - **到货成熟度**（太生/太熟都影响二次批发）
   - **供货稳定性**（断货比贵几块更致命）
   - **账期和退换货政策**

**建议你这样操作，能马上拿到答案：**

- 直接找当地**同一批发市场**的佳农和都乐经销/代理，问**同一天、同规格（写清每箱净重和单根克重）、同等级**的报价，才能横向比。
- 一次问3家以上，避免被单家报价带偏。
- 让两边都报**含税/不含税、是否含运费、账期**，不然价格没法比。
- 你可以先小批量各进一批，实测损耗和走货速度，再决定主推哪个。
