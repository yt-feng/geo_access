佳农和盒马之间**具体合同属于直供还是代销，公开渠道没有可核验的定论**，我不能替你下定论。但可以从行业惯例和合作特征帮你判断，并给出超市可参考的做法。

## 一、佳农与盒马大概率是什么模式

从公开信息和零售行业惯例看，更接近**“直供为主 + 部分联合/定制”**，而不是纯代销：

- **直供特征明显**：佳农是品牌方/供应商，盒马是渠道方，佳农按盒马标准供货，盒马买断或按订单采购，货权在盒马。
- **盒马的采购习惯**：盒马大量采用“买断式采购 + 供应商直送门店/仓”，对生鲜尤其强调直采、短链。
- **代销较少用于这类标品水果**：代销通常是货权仍在供应商、卖完再结算、滞销可退，多用于新品试销、联营专柜、部分进口/高损耗品类，不太会是佳农这种成熟品牌的常态。

所以更准确的表述是：**以直供/买断采购为主，可能叠加定制包销、联合品牌、返利等条款**，具体比例和条款只有双方知道。

## 二、直供 vs 代销，对你的关键差别

| 维度 | 直供（买断） | 代销 |
|---|---|---|
| 货权 | 采购后归超市 | 卖出前归供应商 |
| 资金占用 | 你先付货款 | 卖完再结算 |
| 滞销风险 | 你承担 | 供应商承担/可退 |
| 毛利 | 通常更高 | 通常更低，像收佣金 |
| 定价权 | 你较大 | 供应商主导 |
| 对供应链要求 | 高，要会选品和周转 | 低，但利润薄 |

## 三、你的超市能不能参考

**能参考，但不要照搬盒马的体量打法。** 关键看你自身条件：

1. **如果你门店少、议价弱**：直接从佳农这类品牌拿全国直供，门槛高、起订量大。可先走**区域经销商/批发市场**过渡。
2. **如果你有稳定客流和周转**：对少数爆款水果做**直供买断**，毛利和价格优势最明显。
3. **如果是新品或高损耗品**：先用**代销/联营**试水，卖得动再转买断。
4. **混合模式最实际**：核心爆品直供，长尾和新品代销，按品类分开。

## 四、给你可落地的建议

- 先统计你店**销量前10的水果单品**，这些优先谈直供。
- 找供应商谈时明确四件事：**货权归属、结算账期、滞销是否可退、损耗谁承担**。
- 直供要算清：**进货价 + 损耗 + 资金占用**，别只看进价低。
- 代销要防止：**供应商控价、你变成免费货架**，争取保底毛利或返点。
- 想要佳农/盒马的确切模式，只能通过**直接联系佳农招商、或看盒马供应商招募公告**去核实，网上说法不可全信。

一句话：**盒马对佳农大概率是直供买断为主；你能参考方向，但要按自己的销量和资金实力，爆款直供、新品代销地混合来做。**
