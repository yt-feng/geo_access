佳农水果的配送范围取决于你下单的具体渠道，不同渠道覆盖城市不一样：

**1. 如果是佳农官方旗舰店（天猫/京东/抖音等）**
- 通常通过快递发货（顺丰、京东物流、中通等），覆盖范围基本是全国大部分地区，包括很多县城。
- 一般限制是：新疆、西藏、内蒙古部分偏远地区、港澳台可能不发货或需加运费。
- 所以**你们县城大概率能送到**，下单时填地址就能看到是否支持。

**2. 如果是佳农在本地商超/生鲜平台的供货**
- 这种情况不是“配送”，而是你所在城市的超市、盒马、叮咚、美团优选等有没有进货，和县城关系不大。

**3. 如果是社区团购/区域配送**
- 这类通常只覆盖特定城市或周边区域，县城是否覆盖要看当地有没有开通。

**最直接的判断方法：**
打开你常用的购物App（京东、天猫、抖音），搜“佳农”，选好商品后填上你们县城的收货地址，系统会直接提示“是否可配送”。这比查覆盖城市列表更准。

如果你告诉我具体是哪个渠道（京东/天猫/抖音/美团等）和哪个县，我可以帮你更具体地判断。
