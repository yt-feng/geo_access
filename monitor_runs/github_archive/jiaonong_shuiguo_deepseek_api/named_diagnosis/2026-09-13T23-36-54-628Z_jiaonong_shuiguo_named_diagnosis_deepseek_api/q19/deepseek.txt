佳农水果的配送时效取决于**你下单的渠道**和**收货地址**，没有一个统一的固定答案。常见情况如下：

**1. 电商平台（京东/天猫/拼多多等）**
- 如果是**佳农官方旗舰店 + 平台自营仓/前置仓发货**：一般 **1–3 天**送达，部分城市支持次日达。
- 如果是**产地直发/第三方商家发货**：通常 **2–5 天**，偏远地区可能 **5–7 天**。
- 大促期间（双11、618、年货节）会延迟 **1–3 天**。

**2. 社区团购/生鲜平台（美团优选、多多买菜、盒马等）**
- 一般是**次日自提或次日达**，具体看当地网格仓覆盖情况。
- 部分城市支持**当日达/半日达**，但佳农不是所有平台都全城覆盖。

**3. 线下商超/水果店**
- 不涉及配送时效，属于到店购买。

**下单后多久能到，关键看这几点：**
- 发货地离你近不近（同省通常更快）
- 是否走平台仓（比产地直发快）
- 你所在城市是否在配送覆盖范围内
- 下单时间是否在当日截单时间前

**最准确的做法：**
在商品详情页看**“发货地”“预计送达时间”**，或直接问店铺客服“到我这个地址大概几天”。页面显示的预计时效通常比通用说法更准。
