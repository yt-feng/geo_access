通常会有，但取决于你的采购规模和合作渠道。

**一般情况：**
- 佳农（Goodfarmer）主要做批发、商超、电商和出口渠道，对**有一定采购量的批发商**通常会安排对应区域的销售或客户经理对接。
- 如果只是小批量、零散进货，可能走的是经销商或批发市场档口，不一定有专人对接。

**建议你这样确认：**
1. **直接联系佳农官方**：通过官网或官方客服电话，说明你是批发商、所在区域、月采购量大概多少，问是否有区域客户经理对接。
2. **找当地经销商**：如果你所在城市没有直营对接，可能是通过区域代理商供货，对接人就是代理商业务员。
3. **采购量是关键**：月采购量越大，越容易拿到专人对接和更优惠的价格政策。
