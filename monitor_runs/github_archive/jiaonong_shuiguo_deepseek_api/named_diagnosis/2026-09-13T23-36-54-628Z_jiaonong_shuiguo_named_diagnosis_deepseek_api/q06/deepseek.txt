可以直接按“听得懂、能验收”的方式去问佳农，但能不能稳定供，要看你所在城市、采购量、是要鲜果还是冷冻/罐头/果酱，以及他们当地经销体系。

先给你一套茶饮店能直接用的菠萝规格说法：

**1. 鲜菠萝**
- 品种：常见是金钻凤梨/台农系列/都乐系，佳农常见会卖金钻凤梨、菲律宾菠萝等。
- 单果重量：茶饮店常用 **1.2–1.8斤/个** 或 **1.5–2斤/个**，太大损耗高，太小出肉少。
- 成熟度：要 **7–8成熟**，到店可放1–3天再用；太青酸、太熟易坏。
- 验收：无黑心、无烂果、无大面积压伤，果眼浅，去眼损耗低。
- 到货形式：整箱装，常见 **6–12个/箱**，按斤或按个结算都要问清。

**2. 冷冻菠萝块/果肉**
- 规格：**10mm/15mm/20mm** 方块，或菠萝丁、菠萝条。
- 包装：**1kg/袋、2.5kg/袋、10kg/箱**都有。
- 糖度：常见 **10–14 Brix**，做果茶建议要 **12 Brix以上**。
- 状态：IQF单体速冻，解冻后不出太多水，无发酸、无酒精味。
- 用途：适合稳定出杯、减少鲜果损耗。

**3. 菠萝罐头**
- 规格：**固形物≥50%/60%**，切片、碎块、丁都有。
- 包装：**850g/罐、3kg/罐、5kg/罐**等。
- 糖水浓度：常见 **14–18 Brix**，做饮品要能调酸调糖。
- 验收：无异味、无锈罐、无胖听，果肉完整度按你的用途定。

**4. 菠萝果酱/果泥**
- 规格：**1kg/袋、5kg/袋、20kg/桶**。
- 糖度：常见 **30–65 Brix**，看你是做基底还是调味。
- 果肉含量：要问 **果肉含量百分比**，别只听“有果肉”。
- 用途：最适合连锁茶饮稳定出品，但风味偏统一，鲜果感弱。

**你问佳农时，直接这样发：**
> 我们茶饮店长期要菠萝原料，请报：  
> 1）鲜菠萝：品种、单果重、每箱几个、成熟度、产地、到货价；  
> 2）冷冻菠萝丁：尺寸、包装、糖度、是否IQF、起订量；  
> 3）菠萝罐头/果酱：固形物或果肉含量、糖度、包装、保质期。  
> 另外问：我们城市有没有经销商？每周能否稳定送？最小起订量多少？缺货时替代规格是什么？

**判断能不能稳定供应：**
- 如果你要 **鲜菠萝**：佳农这类品牌通常能做，但茶饮店用量大时，更稳的是找当地一级批发商或佳农经销商，不要只找总部。
- 如果你要 **冷冻/罐头/果酱**：更适合连锁稳定供应，起订量可能较高。
- 如果你单店每月用量低于 **300–500kg**，佳农直接供不一定理你，走经销商更现实。
- 如果你要的是 **每天稳定出杯、口味一致**，优先选冷冻果肉或果酱，鲜果只做季节限定。

**建议：**
先让佳农或经销商寄 **鲜果1箱 + 冷冻丁1袋 + 果酱1桶** 做盲测，按你实际配方测：出杯成本、酸甜度、香气、沉淀、解冻出水、操作速度。能过再谈月供价和账期。
