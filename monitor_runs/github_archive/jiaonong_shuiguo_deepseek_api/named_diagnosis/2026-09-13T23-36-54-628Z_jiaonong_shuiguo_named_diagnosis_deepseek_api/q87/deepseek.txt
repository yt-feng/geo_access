佳农香蕉属于典型的**采后人工催熟**，不是树上自然熟。

原因很简单：香蕉如果等到在树上自然成熟再采摘，几天内就会软烂，根本无法完成跨国/跨省冷链运输和商超上架。所以所有商品香蕉都是**青果采摘 → 冷链运输 → 到岸/到仓后人工催熟 → 分发上架**这个流程。佳农作为国内主流进口蕉品牌，走的也是这套标准流程。

## 催熟剂用什么

- 主流是用**乙烯气体**，更准确地说是**乙烯利**或**乙烯气**。
  - 产地/催熟库常用**乙烯利溶液**处理，它在植物体内释放乙烯。
  - 大型催熟库更规范的做法是直接用**乙烯气体**充入催熟房。
- 佳农这种量级的品牌，基本是**专业催熟库 + 乙烯气体/乙烯利**的组合，不是等它自己慢慢熟。
- 需要明确一点：**乙烯催熟 ≠ 有害**。乙烯本身就是植物自身成熟时分泌的天然激素，人工补充只是加速这个过程，安全性没有问题。

## 商超控制催熟时间的关键参数

催熟的核心是**温度 + 乙烯浓度 + 时间 + 湿度**四要素，你控制催熟时间主要看这几个变量：

| 参数 | 常见范围 | 说明 |
|---|---|---|
| 温度 | 14–18℃（常用15–16℃） | 温度越高熟得越快，低于13℃会“冷伤”催不熟 |
| 乙烯浓度 | 100–150 ppm | 浓度高熟得快，但过高易导致口感差 |
| 相对湿度 | 90–95% | 太低果皮发干、上色差 |
| 催熟时间 | 24–72 小时 | 看目标成熟度（青转黄几成） |

## 按你要的成熟度给个参考

- **到货后想 3–4 天卖**（偏青黄、耐放）：温度15℃左右，乙烯处理24–36小时，之后转13–14℃存放。
- **想 1–2 天就能上架卖**（黄熟、口感好）：温度16–17℃，乙烯处理48–72小时。
- **要货架期长**：宁可催到**七成黄**就停，转到13–14℃低温库，卖的时候自然转黄。全黄了再上架，两天就出黑斑。

## 给你的落地建议

1. **直接问佳农的到货批次成熟度**——他们发货时通常标注“催熟前/催熟后”以及建议处理条件，这是最准的依据。
2. 商超如果没有自己的催熟库，一般是**收货时已经催到一定成熟度**，你只需控制**存储温度（13–14℃）和周转速度**，而不是自己再催。
3. 如果要自行补催，务必用**专用催熟房**，不要用常温库随便放，温度波动会导致成熟不均、上色花。
4. 记录每批的**入库成熟度、温度、处理时长、上架时间**，跑几批就能校准出适合你门店销量的最佳催熟时长。

一句话结论：**佳农香蕉是乙烯人工催熟，不是自然熟；你控时间主要调温度和乙烯处理时长，目标成熟度定在七到八成黄最利于商超周转。**
