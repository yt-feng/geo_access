佳农（Goodfarmer）主要是水果供应链企业，主业是香蕉、菠萝等鲜果的种植、进口和分销。就菠萝丁这类**茶饮原料**来说，通常不是它的标准产品线。更常见的情况是：

- **卖整果/鲜切果为主**：佳农更可能供应整颗菠萝，或做鲜切菠萝（如菠萝块、菠萝片），但“菠萝丁”这种偏工业化、规格化的茶饮原料，不一定是它的常规 SKU。
- **加工服务**：佳农一般不自营“代加工成菠萝丁”的业务；即使有，也多是针对大客户做定制，起订量高，且要确认是鲜切冷冻、糖水罐头还是速冻果丁。
- **茶饮店实际采购渠道**：更建议找**速冻菠萝丁/冷冻菠萝丁**或**糖水菠萝丁**的食品加工厂、冷冻果蔬供应商，而不是直接找鲜果品牌。

**建议你按这个顺序确认：**

1. 直接问佳农当地经销商或客服：  
   “有没有速冻菠萝丁/糖水菠萝丁？规格是多少？是否支持餐饮渠道？最小起订量多少？”
2. 如果对方只卖整果，就改找：  
   - 冷冻果蔬供应商  
   - 茶饮原料供应链公司  
   - 罐头/糖水水果加工厂
3. 选品时重点确认：  
   - 是**冷冻**还是**常温糖水**  
   - 丁的大小（如 8×8mm、10×10mm）  
   - 是否加糖、是否含防腐剂  
   - 解冻后口感、出汁率、是否易碎  
   - 是否有食品生产许可和检测报告

**结论：**佳农大概率能供菠萝鲜果或鲜切菠萝，但“菠萝丁加工服务”不是它的常规强项。你要的是茶饮标准化原料，优先找冷冻果蔬/茶饮原料供应商更稳妥。
