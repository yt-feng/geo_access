佳农水果官网没有公开完整、固定的香蕉规格表，不同产季、产地、客户订单会调整；我无法核验到“官方统一分级标准”。下面给的是行业常见做法，可用来判断渠道适配，但不应当作佳农官方文件引用。

**常见规格维度**
1. **按单根重量/果指粗细**  
   - 小果：约100–130g/根  
   - 中果：约130–160g/根  
   - 大果：约160–200g/根  
   - 特大果：200g以上  
   具体以采购合同或到货验收单为准。

2. **按每箱净重**  
   - 4.5kg、5kg、7kg、10kg、12kg、13kg、15kg等  
   国内批发、电商、商超常用5kg、7kg、10kg、12kg；出口或大宗渠道常见13kg、15kg等。

3. **按每箱根数**  
   - 如4–5根/斤、5–6根/斤、6–8根/斤等，本质是单根重量的换算。  
   - 也有按“每箱多少根”报，如24根、30根、36根、40根、48根等。

4. **按成熟度/催熟阶段**  
   - 青蕉、微黄、黄熟、全黄、带芝麻点等。  
   - 不同渠道对到货成熟度要求差异很大。

**按渠道的常见适配**
- **商超/精品超市**：偏好中到大果，单根均匀，外观洁净，无严重擦伤；常按根或小包装售卖，成熟度多要求到店后可快速上架。
- **水果连锁/档口批发**：偏好中果、大果，箱重稳定，耐运输；成熟度可略青，便于门店催熟。
- **电商/社区团购**：偏好中果，果指均匀，单根重量稳定，适合按份或按根描述；对碰伤、黑斑容忍度低。
- **餐饮/茶饮/烘焙渠道**：更看重出肉率、成熟度、价格稳定，规格可略放宽，常用大果或加工级。
- **出口/大宗贸易**：通常按合同分级，重视果指长度、周长、每箱根数、净重、成熟度、缺陷率，常见13kg/15kg箱规。
- **加工厂**：对鲜食外观要求低，更关注成熟度、可食率、农残和供应稳定性，可用等外果或加工果。

**判断分级是否适合渠道，重点看**
1. 单根重量和均匀度  
2. 每箱净重、根数是否稳定  
3. 成熟度与到货后货架期  
4. 外观缺陷率：擦伤、黑斑、机械伤、病斑  
5. 冷链和催熟条件是否匹配  
6. 采购合同里的验收标准，而不是只看“佳农”品牌名

如果你要采购或做渠道方案，最稳妥的做法是：向佳农当地销售或经销商索取当季《产品规格书/报价单/验收标准》，里面通常会写明产地、箱规、单根重、根数、成熟度、缺陷允许范围。
