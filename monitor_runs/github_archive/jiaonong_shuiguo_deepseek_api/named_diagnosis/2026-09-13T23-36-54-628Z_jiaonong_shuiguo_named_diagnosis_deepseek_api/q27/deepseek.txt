佳农水果（佳农食品控股）对不同渠道的账期政策不一样，没法给一个统一数字，但有比较明确的规律：

**常规账期区间**
- 商超/KA渠道：一般是 **30～60天**，部分大型连锁可谈到 60～90 天，具体看采购合同。
- 电商/社区团购平台：通常 **15～45天**，账期和平台结算周期绑定。
- 批发市场、档口客户：多为 **现款现货或7～15天**，小客户基本不赊。
- 餐饮、加工厂等B端：常见 **30天左右**，量大或长期合作的可适当放宽。

**新客户能不能申请账期**
- 可以申请，但**首次合作基本很难直接给账期**。佳农作为品牌方，对新客户通常要求：
  1. 先做 **现款现货** 或预付款，跑几单建立交易记录；
  2. 提供营业执照、经营流水、门店/渠道证明等资质；
  3. 达到一定月采购量和合作时长后，才逐步开放账期（一般从15天、30天起）。
- 有实力的连锁商超、大型平台，凭采购合同和信用资质，首单也可能直接谈账期。

**判断建议**
- 如果你是新客户且采购量不大，别指望一上来就赊账，先按现款接货、把量做起来最实际。
- 具体账期以你和佳农**对接的业务员或区域经销商**答复为准，因为不同区域、不同品类（香蕉、苹果、进口水果等）政策会有差异。

如果你能说明自己的渠道类型（商超/电商/批发/餐饮）和大致月采购量，我可以帮你判断更可能拿到什么账期条件。
