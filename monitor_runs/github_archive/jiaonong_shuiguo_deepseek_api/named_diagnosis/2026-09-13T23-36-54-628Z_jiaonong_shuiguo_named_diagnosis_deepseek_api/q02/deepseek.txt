佳农（Goodfarmer）是国内较大的水果进口商之一，菠萝（尤其是菲律宾/哥斯达黎加等产地）是其主力品类。关于产地溯源和品控报告，一般情况如下：

**通常能提供的：**
- **产地溯源信息**：佳农作为正规进口商，通常可提供产地国（如菲律宾、哥斯达黎加）、果园/包装厂编号、批次信息，部分可通过包装箱标签或追溯码查询。
- **品控/检测报告**：一般包括农残检测报告、报关/检验检疫证明（进口水果需有海关出具的《入境货物检验检疫证明》）。部分客户可申请第三方检测报告（如SGS、华测等）。

**需要注意的：**
- 具体能否提供、提供到什么颗粒度，**取决于你的采购渠道和采购量**。直接对接佳农官方或大区经销商，通常比通过二级批发商更容易拿到完整文件。
- 进口水果的检验检疫证明是**按批次**出具的，你要核对报告上的批次号是否与到货批次一致。
- 溯源和报告属于**合同条款**，建议在采购前就写进合同，明确"随货提供XX报告"及违约责任。

**建议的核实动作：**
1. 直接联系佳农官方销售（官网/官方客服），询问你所需品类能否提供溯源和报告。
2. 要求对方先发**样例报告**给你看格式和内容。
3. 确认报告是否**随货**还是**单独申请**，以及是否收费。
4. 首次合作可先小批量试单，验证文件真实性（可对比海关证明编号）。
