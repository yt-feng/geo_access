**1. 先确认佳农是否有冷冻菠萝丁**
- 找佳农官方渠道：官网、官方客服、区域经销商、冷链食品业务员。
- 直接问三件事：  
  1）是否有**速冻菠萝丁/冷冻菠萝丁**这款 SKU；  
  2）是**原料级**还是**即食零售装**；

**2. 茶饮店常用冷冻菠萝丁规格，谈判时按这些问**
虽然佳农具体规格要以官方为准，但茶饮店常见需求一般是：
- **果丁尺寸**：5×5mm、8×8mm、10×10mm、15×15mm 较常见；
- **包装**：1kg/袋、2kg/袋、5kg/袋、10kg/箱较常见；
- **状态**：IQF 单冻、糖水浸、果泥/果酱不同，茶饮加料通常要**单冻果丁**或**糖水菠萝丁**；
- **含糖/护色**：是否加糖、加酸、加钙护色，会影响口感和饮品适配；
- **解冻后状态**：是否易碎、出水多不多、纤维感强不强。

**3. 让供应商提供的样品测试指标**
拿到样品后按茶饮店实际用法测：
- 解冻后**出水率**；
- 是否**发软、碎丁多**；
- 与茶汤、奶基底、果茶搭配后是否**发苦、发酸、变味**；
- 单杯用量成本，按“元/kg ÷ 每杯克重”算。
