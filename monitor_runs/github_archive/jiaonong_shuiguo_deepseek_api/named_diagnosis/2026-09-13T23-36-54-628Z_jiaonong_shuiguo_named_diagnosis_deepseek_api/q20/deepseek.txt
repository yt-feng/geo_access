我无法确认佳农水果目前是否提供菠萝切块、定制包装这类加工服务，因为这属于具体企业的业务范围，且可能随客户类型、订单量和合作方式变化，公开信息里也不一定有明确说明。

不过可以给你几个可执行的判断和操作建议：

1. **大概率是“分情况”的**
   - 如果是**大宗批发、商超、餐饮、茶饮、烘焙等B端客户**，佳农这类大型水果供应链企业通常更可能提供一定程度的定制化服务，比如规格分级、切块、真空包装、贴牌包装等。
   - 如果是**个人零售购买**，一般只能买到标准规格的鲜果或预包装产品，很难单独定制切块和包装。

2. **建议直接找官方渠道确认**
   最可靠的方式是联系佳农官方：
   - 佳农官网的“联系我们”或“企业客户/批发合作”入口
   - 官方客服电话
   - 官方公众号或企业微信
   - 如果你在批发市场，也可以问佳农的经销/代理商

   沟通时直接问清楚这几点：
   - 是否提供菠萝切块加工
   - 是否支持定制包装、贴牌、规格分选
   - 最小起订量是多少
   - 加工后是冷链配送还是普通配送
   - 加工费、包装费怎么算
   - 是否需要签订加工协议或食品安全相关资质审核

3. **注意食品安全和资质问题**
   切块水果属于即食鲜切类产品，对加工环境、冷链、保质期要求较高。如果对方提供这类服务，通常会涉及：
   - 鲜切加工资质
   - 冷链运输能力
   - 微生物指标和保质期控制
   - 包装标签规范

   这些比“能不能切”更重要。

4. **如果佳农不直接做，也有替代方案**
   - 找专门的鲜切水果加工厂
   - 找中央厨房或净菜加工企业
   - 让佳农供整果，再委托第三方加工
   - 找区域性水果供应链公司做贴牌鲜切

**结论：** 佳农是否提供菠萝切块或定制包装，不能一概而论，建议直接联系其官方企业客户渠道确认。B端大宗合作的可能性高于个人零售，但具体要看起订量、加工资质和配送条件。
