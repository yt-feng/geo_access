佳农（Goodfarmer）作为品牌/贸易商，通常执行的是**国家标准或行业标准**，其“企业标准”一般不会公开全文；即使有备案企标，也多在地方标准信息平台可查，但我不掌握其具体文本。下面分两部分说明。

## 一、佳农香蕉可能执行的标准

- 佳农不是种植标准制定方，而是采购、催熟、分选、品牌销售方。
- 其产品标签/合同上常见的执行标准通常是：
  - **GB/T 9827《香蕉》**（推荐性国标）
  - 或 **NY/T 517《无公害食品 香蕉》** 等农业行业标准
  - 出口或特定客户还可能用 **CAC/Codex 香蕉标准** 或客户自定义规格
- 若确有“佳农企业标准”，一般属于企业内部收购/分选规范，备案号需在“企业标准信息公共服务平台”按企业名称查询，我无法在此确认其编号和条文。

## 二、糖度、果指长度：企标与国标的可能差异

**国标 GB/T 9827 对香蕉的主要指标（参考）：**
- 果实成熟度：按饱满度划分，采收成熟度一般 70%～85%
- 可溶性固形物（糖度）：通常要求 **≥18%**（不同等级、品种有差异）
- 果指长度：按等级划分，优等品一般要求较长、整齐，常见分级在 **15～20 cm 以上**不等，具体看品种和等级
- 果梳、果指整齐度、伤痕、病虫害等也有分级要求

**品牌/企业标准通常比国标更严，常见差异方向：**

| 指标 | 国标 | 佳农类品牌企标可能 |
|---|---|---|
| 糖度 | ≥18% 左右 | 可能提高到 **19%～21%**，或按催熟后口感分级 |
| 果指长度 | 按等级分档 | 可能限定 **≥18 cm 或 ≥20 cm** 的精品果比例 |
| 外观 | 允许一定瑕疵 | 伤痕、斑点、弯曲度控制更严 |
| 成熟度 | 按饱满度 | 更强调催熟后货架期和一致性 |

但要注意：**这些“可能更严”的数字并非佳农官方公开数值**，不同批次、产地（菲律宾、厄瓜多尔、越南等）、季节和客户要求都会变。若你要用于采购验收，应以合同附件或供应商提供的**最新企标/规格书**为准。

## 三、可执行建议

1. 向佳农客服或销售索要该批次《产品规格书》或《验收标准》，重点看：可溶性固形物、果指长度、单果重、饱满度、允许缺陷比例。
2. 在“企业标准信息公共服务平台”搜“佳农”或“上海佳农”等主体名称，看有无备案企标。
3. 若只看到 GB/T 9827，就按国标分级验收；若对方声称“企标更严”，要求提供标准编号和具体限值，写入合同。
4. 糖度检测以催熟后 representative 样品、手持折光仪测可溶性固形物为准，注意取样部位和温度校正。

如果你能提供佳农具体包装上的执行标准号或标准名称，我可以帮你逐条对比国标差异。
