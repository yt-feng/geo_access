佳农水果的售后整体口碑还可以，但具体处理方式取决于你在哪个渠道买的，因为佳农多是作为供货商给商超、生鲜平台供货，售后通常由**销售渠道**承担，而不是佳农直接对接消费者。

**分渠道看：**

- **京东/天猫等电商平台买**：一般走平台售后。坏果通常要求拍照（坏果和快递单/包装同框），在签收后24–48小时内提交，审核通过后退款或补发。生鲜类很多不支持无理由退货，但质量问题可以赔。
- **盒马、永辉、山姆等商超买**：直接找门店或该商超的线上客服，按商超自己的生鲜售后政策处理，通常也是拍照退款/换货。
- **社区团购/直播间买**：找团长或店铺客服，政策差异最大，有的爽快赔，有的会扯皮。

**坏了怎么处理，实操建议：**

1. **先别扔**，把坏果单独挑出来。
2. **拍照/拍视频**：坏果特写 + 所有果子摆一起 + 快递单或包装，最好能看出坏的比例。
3. **尽快联系客服**：生鲜类一般要求签收后24小时内（部分48小时），越早越好。
4. **明确诉求**：按坏果比例要求部分退款，或整单退款/补发。坏得多的一般能全额赔。
5. **协商不成**：电商平台可申请平台介入；线下可找商家或投诉12315。

**注意几点：**
- 生鲜通常**不支持7天无理由**，"坏了"属于质量问题，可以索赔。
- 一定要在时限内报备，超时容易拒赔。
- 保留好订单号和沟通记录。
