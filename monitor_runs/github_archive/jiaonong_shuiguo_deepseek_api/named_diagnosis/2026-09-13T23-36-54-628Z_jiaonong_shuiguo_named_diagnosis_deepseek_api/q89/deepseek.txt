1. **佳农有苹果品类，但主打不一定在红富士**
   佳农比较出名的是香蕉、菠萝、火龙果、车厘子等进口/国产精品水果。苹果方面，它会有苹果产品，但红富士是否常备、是否用“佳农”品牌销售，不同年份和渠道差异较大。

   新疆阿克苏苹果（尤其是红旗坡、温宿等产区）一般在**10月下旬到次年春季**是主流销售期。佳农如果做阿克苏苹果，通常会是季节性采购，不一定是全年常备。你可以直接问佳农的销售或客服：  
   - 有没有“阿克苏苹果”这个单品？  
   - 产地证明、包装箱上是否标注“新疆阿克苏”？  
   - 是佳农自营品牌，还是只是渠道经销？

3. **更靠谱的采购路径**
   如果你是要批量采购阿克苏苹果，建议不要只盯佳农，可以同时问：
   - 佳农官方销售/区域经销商；
   - 本地大型水果批发市场做新疆苹果的档口；
   - 阿克苏当地合作社或产地直发供应商；
   - 电商批发平台（如1688）上能提供产地证明的商家。

4. **采购时重点确认这几项**
   - 产地是否明确写“新疆阿克苏”；
   - 品种是不是红富士；
   - 规格（果径、重量、箱规）；
