佳农香蕉的保质期和储存条件，通常可以按下面判断：

**一、保质期**
- **常温未熟/半熟状态**：一般 **3～7天**，具体看购买时的成熟度。  
- **已经变黄、有少量糖斑**：通常 **1～3天内** 最好吃完。  
- **冷藏后**：如果已经成熟，放入冰箱冷藏可延长 **2～4天**，但表皮容易变黑。  
- **冷冻**：去皮后密封冷冻可保存 **1～2个月**，适合做奶昔、烘焙，不适合直接鲜食。

**二、储存条件**
1. **未熟或半熟香蕉**
   - 放在 **室温、阴凉、通风处**，避免阳光直射和暖气旁。
   - 不要急着放冰箱，低温会抑制成熟，表皮也容易变黑。
   - 如果想催熟，可和苹果、梨一起放在纸袋里。

2. **已经成熟**
   - 尽快吃；吃不完可 **冷藏**。
   - 冷藏时用保鲜膜包住香蕉柄，或整根装入保鲜袋，减少乙烯释放和水分流失。
   - 表皮变黑不代表里面一定坏，剥开后看果肉：如果果肉正常、无异味，通常还能吃。

3. **切开后**
   - 切开香蕉容易氧化变黑，建议尽快食用。
   - 可滴少量柠檬汁，或密封冷藏， **24小时内** 吃完较稳妥。

4. **冷冻保存**
   - 去皮，切段或整根密封袋装，尽量排空气。
   - 使用时无需完全解冻，可直接打汁或做烘焙。

**三、判断是否变质**
出现以下情况建议不要吃：
- 果肉发酸、发酒味、发霉；
- 果肉大面积软烂、流汁；
- 表皮或果肉有霉点；
- 冷藏后虽然皮黑，但果肉若也发黑发臭，就应丢弃。

**简单结论**：佳农香蕉和普通香蕉储存原则基本一致。没熟放室温，熟了尽快吃；吃不完可冷藏2～4天，或去皮冷冻1～2个月。
