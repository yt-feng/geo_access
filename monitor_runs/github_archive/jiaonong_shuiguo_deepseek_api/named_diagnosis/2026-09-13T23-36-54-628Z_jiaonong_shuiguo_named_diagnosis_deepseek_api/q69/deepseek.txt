我无法核验佳农官方是否针对餐饮渠道提供菠萝切片/切块的定制规格，所以不能直接下结论。不过可以给你一套可执行的核实和判断方法：

**1. 先确认“佳农”具体对接主体**
- 佳农旗下有不同业务线/子公司，餐饮渠道定制通常走**B2B食材供应链**，不是普通电商零售款。
- 建议直接找：佳农官方客服、当地经销商、或者其餐饮渠道销售，问“是否有餐饮专供/定制加工”。

**2. 问清楚这几个关键点**
你可以直接这样问供应商：
- 有没有**餐饮渠道专供的菠萝切片、切块、菠萝丁**？
- 规格：切片厚度、切块尺寸、每包克重、每箱包数？
- 状态：**鲜切、冷冻、糖水罐头、还是巴氏杀菌冷藏**？
- 包装：真空袋、马口铁罐、冷冻袋、还是大包装？
- 起订量、供货周期、是否支持贴牌/定制尺寸？
- 是否有**SC生产许可、检验检疫、冷链资质**？

**3. 判断是否属于“定制规格”**
餐饮渠道常见菠萝产品一般分几类：
- **鲜切菠萝**：冷藏短保，适合茶饮、沙拉、自助餐。
- **冷冻菠萝丁/块/片**：适合烘焙、饮品、餐饮备货。
- **糖水菠萝罐头**：片、块、丁都有，稳定性高。
- **整果菠萝**：餐饮门店自己削切。

如果佳农没有直接做鲜切定制，也可能通过**经销商或加工厂代工**提供。

**4. 更稳妥的替代方案**
如果佳农官方确认没有餐饮定制切片/切块，你可以：
- 找佳农经销商问“能否代订加工”；
- 找其他餐饮供应链品牌对比，如安井、鲜到家、蜀海、美菜、彩食鲜等渠道；
- 直接找有SC资质的果蔬加工厂做OEM定制。

**5. 最有效的核实话术**
“你们有没有针对餐饮渠道的菠萝切片或切块？是鲜切、冷冻还是罐头？规格和起订量是多少？有没有餐饮专供包装？”
