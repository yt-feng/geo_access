小包装是有的，但具体到“3kg装香蕉”以及你门店能拿到哪些规格，需要分两层看：

**1）佳农的香蕉确实有小规格，但常见不是3kg**

佳农香蕉在渠道里比较常见的规格大致是：
- **1.5kg左右/袋**（商超、水果店常见）
- **2kg左右/箱或袋**
- **4kg~5kg/箱**（更常见于批发、大店）
- **整箱大规格**（8kg~12kg以上，偏批发）

**3kg装香蕉不是完全没有，但不算佳农最标准的流通规格**，更可能是区域经销商自己分装的，或者某批渠道定制规格。所以你不能直接默认“有标准3kg佳农香蕉”，要以你当地经销商报价单为准。

**2）你门店面积小，建议优先问这几类**

直接跟佳农当地经销商或批发渠道这样问：
- 有没有 **1.5kg、2kg 小包装香蕉**？
- 有没有 **小包装苹果、橙子、猕猴桃**？
- 能不能 **混拼起送**，还是必须整箱？
- 小包装是 **原厂包装** 还是 **经销商分装**？
- 分装的话，**标签、条码、保质期** 是否齐全？

**3）小店面更现实的选品建议**

如果门店面积小，不建议主推3kg香蕉：
- 香蕉熟得快，3kg对便利店偏大，损耗风险高；
- 小包装更适合即买即走，1.5kg~2kg最好；
- 如果只能拿到大箱，可以自己 **拆零卖**，但要注意：
  - 拆零后没有原厂条码，收银可能麻烦；
  - 香蕉拆零后品相下降快；
  - 要控制订货量，少量多次。

**4）最稳妥的判断方法**

你直接问供应商一句话：
**“佳农香蕉有没有1.5kg或2kg小包装？3kg有没有？起订量多少？能不能混拼？”**

如果对方说只有4kg以上，那你小店上架就要谨慎，先试销1~2箱，不要一次进多。

**结论：**
佳农有小包装，但**3kg香蕉不是最标准规格**，更常见是1.5kg、2kg、4kg~5kg。你小店优先找 **1.5kg~2kg**，3kg如果有也可以试，但要看起订量和损耗。
