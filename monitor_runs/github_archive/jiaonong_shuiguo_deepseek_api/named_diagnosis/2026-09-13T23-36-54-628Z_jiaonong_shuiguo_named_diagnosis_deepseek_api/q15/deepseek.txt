佳农（佳农食品控股/Goodfarmer）以进口水果和国内精品水果为主，**“产地直供比例”没有公开的统一官方口径**，不同品类差异很大：  
- 香蕉、菠萝、火龙果等进口大单品，更接近“海外产区直采/合作庄园+自有催熟加工”的模式，直供比例通常较高。  
- 国内苹果、梨、柑橘、葡萄等，多通过产区合作社、加工厂和批发市场组织货源，是否叫“直供”取决于口径。  
所以不能简单说整体直供比例“高”或“不高”，要看具体品类和年份。

**香蕉主要来自哪些国家：**  
佳农香蕉常见来源包括：
1. **厄瓜多尔**  
2. **菲律宾**  
3. **越南**  
4. **柬埔寨**  
5. **老挝**  
6. 部分时段也有 **哥伦比亚、哥斯达黎加、墨西哥** 等中南美来源。

其中，**菲律宾、厄瓜多尔、越南、柬埔寨**是较常见的主力来源。实际到货结构会随价格、关税、海运、产区天气和季节变化而调整。  
如果你问的是某一款具体佳农香蕉包装上的产地，最准确的是看包装箱/标签上的“原产国”标识。
