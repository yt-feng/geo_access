我无法核实“佳农水果香蕉农残超标”的具体历史记录，也没有可引用的官方通报数据库。直接说结论：**不能凭我这里的记忆给你“有/没有超标历史”的定论**，而且这类结论对你们超市抽检合规没有直接法律效力。你们要的是**可验证的合规证明链**，不是一句“没超标”。

下面是采购端能落地、能过超市抽检和监管查验的做法。

## 1. 先明确一点：农残合规证明是什么

超市抽检/监管通常认这几类文件，**缺一不可**：

1. **供应商资质**：营业执照、食品经营许可证（或生产许可证）。
2. **批次检测报告**：该批次香蕉的农残检测报告，最好是**CMA/CNAS资质机构**出具，检测项目覆盖 GB 2763 中香蕉对应的农药限量。
3. **产地证明/供货凭证**：证明这批货的来源、批次、数量。
4. **进货查验记录**：你们自己的台账，含品名、批次、数量、供货者、日期。
5. **承诺书/质量协议**：供应商对农残符合 GB 2763 的书面承诺。

**关键点**：检测报告必须是**对应你们采购的那一批次**，不能用一张通用报告或很久以前的报告。超市抽检看的是“这批货”，不是“这个品牌”。

## 2. 怎么查佳农的农残历史

你自己可以去核验，不依赖我：

- **国家市场监管总局**：食品安全抽检通报，按“香蕉”“佳农”检索。
- **各省市市场监管局**：抽检不合格名单，很多地方局会公布。
- **农业农村部**：农产品质量安全例行监测、监督抽查结果。
- **信用中国 / 国家企业信用信息公示系统**：查供应商主体是否有行政处罚。
- **裁判文书网**：查是否有相关质量纠纷判决。

检索时注意区分：**“佳农”品牌 vs 具体供应商主体**，很多抽检通报写的是某批次、某供货商，不一定是品牌方。

## 3. 采购合规操作建议（按优先级）

**第一步：向供应商书面索要**
- 本批次香蕉的 CMA/CNAS 农残检测报告，检测项目覆盖 GB 2763 香蕉限量。
- 产地证明、供货凭证。
- 质量安全承诺书。
- 若供应商是贸易商，要求其提供上游种植基地/加工厂信息。

**第二步：合同里写死**
- 农残须符合 GB 2763 现行版本。
- 每批次随货提供检测报告，否则拒收。
- 抽检不合格的违约责任、退赔、召回责任。
- 保留追偿权。

**第三步：你们自己留样**
- 每批留样，保存到保质期后一段时间。
- 台账记录批次、供货者、日期、数量。
- 这是超市抽检时你们能自证“已尽查验义务”的关键。

**第四步：必要时自检或送检**
- 对高风险批次，自己送第三方检测。
- 成本可摊入采购，但能避免整批下架和罚款风险。

**第五步：抽检不合格的应对预案**
- 立即下架、封存、召回。
- 通知供应商、留存证据。
- 向监管报告，配合处理。
- 依据合同追偿。

## 4. 直接回答你的问题

- **“佳农香蕉有没有农残超标历史？”** 我无法核验，不能给你确定答案。你需要去官方抽检通报和信用系统查，且要区分品牌和具体批次/主体。
- **“能不能靠这个判断能不能过超市抽检？”** 不能。超市抽检看的是**你们采购批次的检测报告和进货查验记录**，不是品牌历史。
- **“采购要合规证明”** 正确做法是：**每批次 CMA/CNAS 农残检测报告 + 资质 + 产地凭证 + 承诺书 + 你们自己的台账和留样**。
