佳农（佳农食品控股）主营香蕉等生鲜水果的贸易和分销，主要做**整根香蕉的批发供应**，面向商超、水果店、电商等渠道，通常**不提供餐饮加工用的香蕉切片**这类初级加工品。

如果你需要的是**加工好的香蕉片**，建议分两种情况确认：

1. **鲜切香蕉片（冷藏短保，用于甜品、饮品、摆盘）**
   - 这类通常由**净菜/鲜切加工厂**或**中央厨房**提供，不是佳农这类水果贸易商的常规业务。
   - 常见规格：厚 3–8mm 圆片，真空袋或气调包装，冷藏 2–5℃，保质期一般 1–3 天（视工艺和包装）。
   - 需要确认：是否护色处理（防褐变）、是否加抗坏血酸/柠檬酸、单袋克重、到货温度。

2. **冷冻香蕉片 / 香蕉果泥 / 香蕉干**
   - 如果是冷冻或烘干产品，找**冷冻水果加工厂、果干厂**更合适。
   - 冷冻片常见规格：厚度 5–10mm，IQF 单冻，-18℃储运。
   - 香蕉干：片状或条状，水分和糖度按厂家标准。

**建议你直接这样问佳农或供应商：**
- 你们是否做鲜切/冷冻香蕉片，还是只供整蕉？
- 切片厚度、单包规格、包装形式（真空/气调/IQF）？
- 是否护色、保质期、储运温度？
- 起订量、送货频次、报价（按 kg）？

如果佳农只供整蕉，你可以让他们推荐合作的**鲜切加工厂**，或者你自行找本地净菜厂代加工，原料用佳农香蕉、加工由第三方完成，这是餐饮连锁比较常见的做法。
