可以做到“批次级/农场级”溯源，但**不一定能在零售包装或公开页面上直接查到具体农场**。通常要分两层看：

1. **对你商超审核而言**
   - 佳农这类出口型水果供应商，一般能提供：
     - GLOBALG.A.P.证书
     - 果园/农场注册信息
     - 包装厂信息
     - 批次号、采摘日期、出口日期
     - 可追溯性文件
   - 如果商超要求“农场级溯源”，应让佳农按**具体供货批次**提供对应农场的追溯文件，而不是只要一张公司层面的证书。

2. **GLOBALG.A.P.证书关键点**
   - GLOBALG.A.P.通常是**按生产商/农场/注册单位**发证，不是只按贸易公司发证。
   - 你要核对证书上的：
     - 持证主体
     - 农场/生产地点
     - 产品范围是否包含香蕉
     - 证书编号
     - 有效期
     - 认证机构
     - 证书状态是否有效
   - 如果证书持证方是佳农的关联公司、合作社或合作农场，也要确认它和实际供货农场的关系。

3. **能否到具体农场**
   - 如果商超要求“到具体农场”，可行做法是：
     - 要求佳农提供该批次对应的**农场名称/代码、地址、GGN编号**
     - 提供该农场的GLOBALG.A.P.证书或证书覆盖证明
     - 提供从农场到包装厂到出口的追溯链
     - 必要时做**二方审核/飞行检查**
   - 如果佳农只给“佳农公司证书”或“产地：菲律宾/厄瓜多尔”这类信息，通常**不能满足农场级溯源要求**。

4. **实操建议**
   - 直接向佳农索要：
     - 该批次的追溯码/批次号
     - 对应农场清单及GGN号
     - 对应GLOBALG.A.P.证书
     - 包装厂GLOBALG.A.P.或相关认证
     - 追溯演练记录
   - 如果对方只能给公司证书，不能对应到批次农场，就应要求补充，或把要求写进采购合同/质量协议。

5. **结论**
   - **佳农具备做批次级、农场级溯源的能力**，尤其是出口商超渠道。
   - 但**是否能到具体农场，取决于你采购的具体批次和佳农的供应链组织方式**。
   - 商超要GLOBALG.A.P.证书是合理要求；你还应进一步要求**证书与具体农场、具体批次对应**，否则证书的审核效力会打折。
