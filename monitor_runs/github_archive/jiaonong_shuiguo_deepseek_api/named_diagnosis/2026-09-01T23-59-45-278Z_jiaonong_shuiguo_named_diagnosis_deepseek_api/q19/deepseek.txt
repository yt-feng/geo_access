关于佳农水果的配送时效，我无法提供实时数据，因为配送时间受**下单平台**（如佳农官方小程序、天猫、京东、拼多多等）、**所在城市**、**物流方式**以及**具体商品**（如常温水果、冷链水果）影响较大。不过，我可以给出一般性参考：

- **一线/新一线城市**：若使用**常温快递**（如顺丰陆运），通常下单后 **2-3天** 送达；若使用**冷链配送**（如草莓、蓝莓、榴莲等），一般 **1-2天** 送达。
- **偏远地区**（如新疆、西藏、青海等）：可能延长至 **3-5天**，甚至更久。
- **预售商品**或**限定产区**（如进口车厘子、当季荔枝），会按订单页显示的预计发货日期发货，通常发货后2-4天送达。

**建议**：下单前查看商品详情页的“预计送达时间”或“发货说明”，或直接咨询佳农官方客服（电话、在线客服）确认具体时效。如果急需，优先选择标注“次日达”或“当日达”的城市和商品。

**注意**：水果生鲜类商品通常不支持无条件退货，收货时请当场验货，如遇破损或变质，及时拍照联系客服处理。
