关于**佳农水果（Goodfarmer）** 的香蕉规格与分级标准，我需要先说明：**具体的规格型号和分级标准属于企业内部的商业运营细节，公开渠道（官网、官方社交媒体）通常不会公布非常精确的数字参数（如每箱净重、果指长度、梳数等）的完整细则**，且不同时期、不同产季（如菲律宾产地、厄瓜多尔产地）可能会调整。

不过，根据行业通行的香蕉分级逻辑以及佳农的市场定位，可以给出以下**可参考的框架性信息**：

### 1. 常见规格（按包装/重量）
佳农香蕉通常以**箱**为单位批发，常见规格包括：
- **大箱（约13.5kg - 14kg/箱）**：主要用于商超、水果店、电商大仓。
- **小箱（约6.8kg - 7kg/箱）**：主要用于精品超市、社区生鲜店、外卖平台。
- **特别定制箱**：针对大型连锁（如盒马、山姆）会有专属包装规格。

### 2. 分级标准（行业通用框架，佳农执行类似标准）
国内香蕉分级主要参考**《香蕉（GB/T 20000）》相关标准**或出口国的分级（如菲律宾采用日本/韩国标准），核心指标包括：

| 指标 | 优级（A级/果王） | 一级（B级） | 二级（C级） |
|------|------|------|------|
| 果指长度 | ≥18cm | 15-18cm | <15cm |
| 梳数（每箱） | 每把通常5-6梳 | 4-5梳 | 3-4梳 |
| 果指丰满度 | 饱满、无棱角 | 较饱满 | 欠饱满 |
| 外观缺陷 | 无黑斑、无机械伤、无虫眼 | 允许轻微擦伤 | 允许明显瑕疵 |
| 成熟度（到货时） | 半熟（青转黄，催熟后稳定） | 半熟 | 半熟或偏生 |

**注意**：佳农在商超渠道通常主推**A级（果王）**，其特点是果指粗长（一般在20cm以上）、单果重、梳形漂亮；社区团购/线上平台则以B级为主。

### 3. 不同渠道的区分建议
- **高端商超（如ole'、山姆）**：要求每箱果实大小均匀、无疤痕，通常供应A级，且需要每箱附有产地溯源码。
- **普通连锁商超（永辉、大润发）**：A/B级混合，但包装整洁，标签明确。
- **电商/社区团购（拼多多、美团优选）**：主打性价比，通常使用B/C级，但会标注“小果/中果”字样，价格更低。
- **餐饮/烘焙渠道**：更关注成熟度稳定性（催熟损耗率），不追求外观美观度，可用B级。
