关于佳农水果的具体到货损耗率，**没有公开的、标准化的统一数据**。因为损耗率受水果品种（如香蕉、苹果、榴莲）、运输距离、季节、包装方式、仓库管理水平等因素影响巨大。

不过，可以从行业角度给你一个大致的参考范围：

-   **行业平均水平**：一般水果生鲜电商或批发商的综合到货损耗率在 **5% - 10%** 之间。
-   **佳农这样的大型品牌**：通常通过预冷、冷链运输和标准化包装，会将**常规品类**（如苹果、梨、柑橘）的到货损耗控制在 **2% - 5%** 以内。
-   **高损耗品类**：像**香蕉、草莓、榴莲**这类易腐或皮薄的水果，到货损耗率可能达到 **8% - 15%**，甚至更高（特别是夏季）。

**如果你想获取佳农的最新数据**，建议直接联系其**销售客服**或**区域负责人**，询问具体品类的“到货损耗承诺”或“坏果包赔”条款，这才是最可靠的依据。

另外，如果涉及采购决策，建议你索要对方的**质保协议**，明确超过约定损耗率的赔付方案，这比一个绝对数值更有价值。
