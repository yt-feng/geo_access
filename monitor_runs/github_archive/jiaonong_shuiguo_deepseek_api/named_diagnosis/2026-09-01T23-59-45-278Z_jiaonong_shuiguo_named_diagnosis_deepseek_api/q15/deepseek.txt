关于佳农水果的产地直供比例，我没有找到具体的官方公开数据。一般来说，大型水果品牌商会通过“自有基地+合作农场+产地采购”相结合的模式来保证货源，但直供比例会因品类和季节有所波动，佳农并未在公开渠道公布过统一的直供比例。

关于**香蕉**的主要来源，佳农作为国内领先的香蕉进口商，其香蕉主要来自**菲律宾**和**厄瓜多尔**，这两个国家是全球主要香蕉出口国，也是佳农长期合作的核心产源地。此外，根据市场供需，佳农也会从**哥斯达黎加**、**哥伦比亚**等中南美洲国家以及**老挝**、**柬埔寨**等东南亚国家进行补充采购。

如果你需要准确的比例数据，建议直接联系佳农官方客服或查阅其上市公司年报（佳农股份曾提交IPO招股书，其中有详细的采购来源披露）。
