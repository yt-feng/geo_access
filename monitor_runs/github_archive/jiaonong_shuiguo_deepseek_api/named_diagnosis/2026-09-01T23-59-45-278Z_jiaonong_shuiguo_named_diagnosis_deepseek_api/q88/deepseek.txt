### 第二步：物流成本测算公式（核心）

社区团购一件代发的物流成本，**几乎不由“重量”决定，而由“件数”和“地域”决定**。你可以按以下结构向佳农的销售经理索取报价单：

**成本 = 快递费（首重+续重） + 包装耗材费 +（可能存在的）平台服务费/代发服务费**

**针对水果的特殊点（一定要问清）：**
- **首重**：一般水果默认首重1kg。佳农的香蕉、菠萝等单品常超1kg。
- **续重价格**：每增加0.5kg或1kg的加价，这一项决定了大果、箱装是否划算。
- **保价/理赔费率**：水果易损耗，必须问清楚：**“如果运输途中坏了，是按件赔付还是按斤赔付？理赔上限是多少？”** 这个风险成本必须算进去。

**给你一个快速测算模板（以广东-广西地区为例）：**

假设你想卖佳农的某款进口香蕉，总货值约50元/箱。
- 快递费（一件代发专线价）：江浙沪皖包邮区约4-5元/箱；跨省（如广州发湖南）约6-8元/箱；偏远地区（新疆、西藏）通常不接或加价15元以上。
- 包装耗材：佳农一般自带纸箱，但如果要加泡沫箱+冰袋（视季节），耗材费增加2-4元/箱。
- **结论**：一件代发的真实物流成本大概率在 **5-12元/单** 之间（不含赔付风险）。
