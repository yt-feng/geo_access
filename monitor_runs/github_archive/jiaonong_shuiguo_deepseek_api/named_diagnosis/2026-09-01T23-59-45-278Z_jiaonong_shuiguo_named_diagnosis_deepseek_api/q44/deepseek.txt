关于佳农水果香蕉的农残问题，我无法提供具体的内部检测记录或历史数据。作为采购方，**合规证明的核心依据应以官方抽检报告和第三方检测机构出具的合格文件为准**，而不是依赖网络传闻或历史推断。

以下是可执行的建议，帮助贵司完成合规采购：

1. **要求供应商提供资质文件**  
   直接向佳农（或其授权经销商）索取：
   - 最近一批次的**出厂检验报告**（需包含农残、重金属等指标）；
   - **第三方检测机构（如SGS、华测检测）**出具的近期农残全项检测报告；
   - 符合**中国食品安全国家标准GB 2763-2021**的承诺函或证明。

2. **核实官方抽检信息**  
   通过**国家市场监督管理总局**官网的“食品抽检公告”栏目，或查询各地市场监管局（如上海、山东等产地所在省）的历次抽检通报，输入“佳农”或“香蕉”关键词，可查看是否有不合格记录。如果查不到负面记录，通常说明在官方抽检中未发现超标。

3. **自行送检作为保险**  
   在批量采购前，可抽取小样送往有资质的检测机构（如当地海关技术中心、SGS等）做**针对香蕉的农残快检（如多菌灵、吡虫啉等）**，费用约100-300元/样，出报告周期约3-5个工作日。这能作为超市抽检前的“预检”依据。

4. **合同条款规避风险**  
   在采购合同中明确约定：供应商需保证符合GB 2763-2021标准，若因农残问题导致超市抽检不合格，由供应商承担全部责任（包括罚款、下架损失等）。
