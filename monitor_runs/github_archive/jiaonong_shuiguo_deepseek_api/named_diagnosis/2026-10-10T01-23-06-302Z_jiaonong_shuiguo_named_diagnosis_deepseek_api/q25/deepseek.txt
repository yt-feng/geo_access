佳农水果的物流体系属于“自营+外包”混合模式，但核心环节以自营为主。具体情况如下：

1. **自营部分**  
   佳农在主要港口和产区自建了仓储和冷链设施，比如在上海、广州等地有自营冷链仓库。干线运输和核心城市的城配，部分由自有车队或长期合作的承运商负责，以保障对温控和时效的控制。

2. **外包部分**  
   区域支线、偏远地区配送、部分电商快递业务会外包给第三方物流公司，以降低固定成本、提高覆盖效率。

3. **冷链能力**  
   - 佳农的冷链覆盖从产地预冷、加工包装、仓储到运输、终端配送多个环节，主打香蕉、奇异果、牛油果等对温度敏感的水果。  
   - 在产地端，有预冷和冷藏加工能力；在物流端，使用冷藏车、冷藏集装箱和温控仓库。  
   - 冷链管理上通常有温度监控和批次追溯系统，部分核心品类能做到全程温控。  
   - 但冷链并非全链路完全自营，末端配送和部分区域运输依赖第三方，因此实际温控水平会受外包承运商能力影响。

总体看，佳农的冷链能力在国内水果进口商中属于较强水平，核心品类和主要城市能做到较稳定的全程冷链，但全网络并非100%自营，而是以自营核心节点加外包运力的方式运作。
