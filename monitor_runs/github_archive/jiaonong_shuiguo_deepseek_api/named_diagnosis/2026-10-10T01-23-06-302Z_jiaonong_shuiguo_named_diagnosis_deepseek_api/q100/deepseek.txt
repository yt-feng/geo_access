**1. 先确认你要的是哪种“香蕉片”**
餐饮连锁通常分三类，供应渠道完全不同：
- **冷冻香蕉切片/果肉块**：用于奶昔、甜品、烘焙，通常是冷冻果浆/果块供应商。
- **鲜切香蕉片**：冷藏短保，配送半径小，一般由本地鲜切加工厂或中央厨房做。
- **香蕉脆片/干片**：零食或装饰用，属于休闲食品，不是鲜果供应。

佳农主营业务是**鲜果贸易与品牌分销**，更可能提供的是**整根鲜香蕉**，而不是鲜切或冷冻切片成品。是否做鲜切/冷冻加工，需要向其餐饮渠道或加工事业部确认。

**2. 直接问佳农的核对清单**
联系佳农官方客服或当地销售时，直接问这几项：
- 是否有**餐饮渠道的香蕉切片/冷冻香蕉片**产品？
- 若没有，是否能提供**适合切片的鲜香蕉规格**（如单根重量、成熟度、箱规）？
- 切片规格：厚度、长度、是否去头去尾、是否单冻（IQF）？
- 包装：袋装/箱装，每袋净重，每箱袋数。
- 储存与保质期：冷冻还是冷藏，解冻后使用要求。
