佳农水果（通常指上海佳农食品集团）的具体客户政策属于其内部商业条款，公开渠道一般不会有完整、准确的书面版本，我也没有办法核验当前真实的折扣比例、返点门槛或账期条件。如果我直接给你一套数字，很可能是编造的，反而会误导你们的采购谈判。

不过，我可以给你一个可执行的判断和推进路径：

**1. 1000吨/年这个量级，通常能进入“大客户/重点客户”谈判通道**
佳农的主营品类是香蕉、菠萝、火龙果、椰青、苹果等进口和国产水果。按1000吨年采购量算，已经是区域经销商或大型连锁渠道的水平，一般不会只享受标准批发价，而会进入年度框架协议谈判。可能的让利形式包括：

- 阶梯返点：按年度或季度累计采购量分档返利
- 价格折让：在牌价基础上给协议价或一单一议
- 账期支持：如月结、票到若干天
- 市场费用支持：陈列、促销、损耗补贴
- 优先供应：旺季或紧俏品类的配额保障

但具体档位和比例，必须由佳农方根据品类、结算方式、提货地点、是否含税含运费来定，不同品类差异很大（比如香蕉和椰青的毛利结构完全不同）。

**2. 建议你这样去谈，比问“有什么优惠政策”更有效**
直接问“有什么政策”，对方通常只会给标准话术。更有效的做法是：

- 先明确你们要采购的品类结构：哪几个单品、各占多少吨
- 明确提货方式：产地自提、区域仓配送、还是到岸
- 明确结算：现款、月结、还是承兑
- 明确年度总量承诺：1000吨是保底还是预估
- 然后要求对方给出**分品类的年度协议价 + 返点阶梯 + 账期**三项具体条件

**3. 更可靠的信息获取渠道**
- 直接联系佳农官方销售或大客户部，要求提供年度合作方案
- 通过你们已有的批发市场、商超或电商渠道，打听同行的实际结算条件
- 要求对方出具书面报价单和框架协议草案，而不是口头承诺

如果你告诉我你们的具体品类、提货区域和结算方式，我可以帮你把谈判要点和需要对方书面确认的条款列成一份清单。
