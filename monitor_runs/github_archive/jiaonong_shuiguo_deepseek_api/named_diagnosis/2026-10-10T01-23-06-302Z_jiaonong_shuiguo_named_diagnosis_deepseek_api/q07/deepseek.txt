佳农水果的配送覆盖范围会随业务模式变化，主要分两种情况：

**1. 如果你说的是佳农自营/官方渠道（如天猫、京东旗舰店、官方小程序）**
- 通常是**全国大部分地区可发**，但生鲜类一般只发**地级市及以上**或**部分县级市**。
- 很多店铺会标注“偏远地区、部分县城、乡镇不发货”，具体看商品页的“配送说明”。
- **你们县城能不能送，取决于你下单的平台**：在天猫/京东下单时，填上你的详细地址，系统会直接提示“是否可配送/是否加运费”，这是最准确的判断方式。

**2. 如果你说的是佳农给商超、批发市场的供货**
- 佳农更多是**供应商**角色，水果进入各地超市、水果店后再零售。
- 这种情况下覆盖的是**有合作门店的城市**，和“配送到家”是两回事。

**建议你这样做：**
1. 打开你常用的平台（京东/天猫/抖音/佳农官方小程序），搜“佳农”，选具体商品，填你县城的收货地址，看是否显示可配送、运费多少。
2. 直接问店铺客服：“XX省XX县XX镇能发货吗？”客服能给最准答复。
3. 如果官方渠道不送，可以看当地大型超市或生鲜平台是否有佳农产品，通常县城超市是能买到的。

简单说：**佳农官方快递不保证覆盖县城，能不能送到要以你下单时填地址后的系统提示为准；但佳农水果通过超市渠道，很多县城其实买得到。**
