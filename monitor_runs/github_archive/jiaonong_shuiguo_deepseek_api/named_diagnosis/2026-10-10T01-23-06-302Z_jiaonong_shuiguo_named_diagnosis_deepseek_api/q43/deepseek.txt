关于佳农能否给茶饮店做10吨/月的菠萝锁价合同，我没法直接替佳农确认，因为锁价属于企业级商务条款，取决于他们的货源结构、产地季节、销售政策和你的合作条件。但可以给你一个可执行的判断和谈法。

**先说结论**
- 10吨/月，年化约120吨，这个量在佳农体系里不算大到一定能拿到长期锁价，但也不是没得谈。
- 佳农做香蕉、菠萝等进口和国产水果，确实有较强的产地和供应链能力，但是否愿意锁价，通常要看：
  - 你要的是“固定单价”还是“保底+浮动”
  - 锁多久：3个月、6个月还是12个月
  - 规格：鲜菠萝、冷冻菠萝、菠萝丁、菠萝汁、果酱，差别很大
  - 付款方式：现款、预付、账期
  - 是否接受产地、品种、等级替换

**大概率能谈成的几种形式**
1. **短期锁价**
   比如锁1到3个月，更适合茶饮店。全年锁价对供应商风险太大，佳农不一定接。
2. **保底价+浮动上限**
   约定一个基准价，市场涨跌超过一定幅度再调价。比如±8%以内不调，超出部分双方分摊。
3. **区间锁价**
   设定最高采购价，低于最高价时随行就市。你控制成本上限，供应商也不至于亏太多。
4. **锁量不锁价**
   保证每月10吨供应和优先发货，价格按周或按月参考产地行情。这个最容易谈成。
5. **组合采购**
   鲜果+冷冻果搭配。鲜果价格波动大，冷冻果、果丁、果酱更容易锁价。

**你去谈的时候，直接问这几个问题**
- 10吨/月，年度框架协议，能不能做3个月或6个月锁价？
- 如果全年锁价不行，能不能做“保底价+涨跌熔断”？
- 锁价对应什么规格、品种、产地、等级？
- 是否接受预付、现款或缩短账期换锁价？
- 如果产地减产，锁价合同是否保证供货？违约怎么处理？
- 报价含不含运费、损耗、税费？
- 是否愿意签最低供货量+价格调整机制？

**你要注意的风险**
- 锁价合同一定要写清楚：规格、等级、产地、包装、交货周期、验收标准、损耗归属。
- 如果只写“菠萝锁价”，不写品种和等级，后面容易扯皮。
- 供应商愿意锁价时，通常会把风险溢价加进去。你要比较“锁价单价”和“随行就市均价+波动成本”，不一定锁价就最划算。
- 茶饮店如果配方允许，最好做双供应商，避免单一供应商断供或涨价。

**最实际的建议**
先让佳农报两种方案：
1. 每月10吨，随行就市，月度定价；
2. 每月10吨，3个月/6个月锁价，或者保底价+浮动上限。

拿到报价后，你再对比自己过去6到12个月的实际采购均价。如果锁价只比均价高3%到5%，但能帮你稳定菜单成本和毛利，就值得签；如果高太多，就谈“锁量不锁价+价格上限”。
