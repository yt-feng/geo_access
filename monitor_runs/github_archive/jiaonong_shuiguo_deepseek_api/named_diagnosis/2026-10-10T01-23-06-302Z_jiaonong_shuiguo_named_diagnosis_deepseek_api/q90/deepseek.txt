1) **先确认佳农是否有冷冻菠萝丁**
- 直接找**佳农官方渠道**：佳农官网/官方公众号/官方客服电话，或你所在区域的**佳农经销商**。
- 问法要具体：  
  “是否有**速冻/冷冻菠萝丁**？是**IQF单体速冻**还是糖水/糖渍冷冻？  
  规格：**每袋净重、每箱袋数、丁的尺寸（mm）、固形物/糖度、是否加糖、包装形式**？  
  起订量、冷链、到货价、是否有食品生产许可/检验报告？”

2) **如果佳农没有冷冻丁，替代方案**
- 用**佳农菠萝原料**自己做：门店现切丁后冷冻，或采购**菠萝果肉/菠萝块**再切丁。  
- 找其他冷冻水果供应商：常见冷冻菠萝丁规格有：
  - 丁尺寸：**10×10mm、15×15mm、20×20mm** 等  
  - 包装：**1kg/袋、2kg/袋、10kg/箱** 等  
  - 工艺：**IQF速冻**、**糖水冷冻**、**糖渍冷冻**  
  但具体要按供应商实际报价和样品确认。

3) **采购时重点确认**
- 是**冷冻菠萝丁**还是**糖水菠萝丁**：茶饮店做饮品，通常更关注**出汁、甜度、颗粒完整度、是否结块**。
- **解冻后状态**：是否出水严重、是否发软、是否有纤维感。
- **微生物/添加剂**：是否有防腐剂、色素、甜味剂。
- **冷链**：运输和到货温度是否稳定，避免反复冻融。

4) **最稳的做法**
先让佳农官方或经销商提供**产品规格书+样品**，你拿样品做一杯测试：  
- 解冻后丁是否完整  
- 加入茶汤/奶基底后是否影响口感  
- 单杯成本是否可接受
