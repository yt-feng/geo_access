佳农水果的香蕉规格并没有一个统一公开、固定不变的“官方分级表”，它会按**品类（国产/进口、普通香蕉/有机香蕉/高原蕉等）、包装形式、单根重量/长度、整箱净重、销售渠道**不断调整。下面按行业常见做法给你一个**可判断、可执行**的框架，并说明哪些需要以佳农当期报价单/装箱单为准。

## 一、常见规格维度

佳农香蕉通常从以下几个维度定规格：

1. **单根重量（最核心）**
   - 小果：约 90–120g/根
   - 中果：约 120–150g/根
   - 大果：约 150–180g/根
   - 特大果：180g以上/根
   > 不同产地、季节会有浮动，实际以箱标为准。

2. **每把/每梳根数**
   - 常见 4–6 根/把
   - 也有 5–7 根/把、整梳装
   - 电商小包装常见 2–3 根/袋或单根装

3. **整箱净重**
   - 常见：4.5kg、5kg、7kg、8kg、10kg、12kg、13kg、15kg 等
   - 进口香蕉常见 12–13kg/箱或 18–20kg/箱（视产地和运输方式）
   - 国产香蕉常见 5kg、8kg、10kg 箱装

4. **成熟度/催熟阶段**
   - 青蕉（未催熟，适合长途、再催熟）
   - 微黄/转黄（适合短途批发、门店二次催熟）
   - 黄熟（适合即时零售、电商、水果店直接上架）

5. **外观等级**
   - A级：果形整齐、弯曲度好、无疤无伤、色泽均匀
   - B级：轻微花皮、轻微擦伤，不影响食用
   - C级/加工级：外观瑕疵明显，适合榨汁、烘焙、加工

## 二、按渠道的分级建议

以下是行业通行的渠道匹配逻辑，佳农具体执行可能略有差异，但判断标准基本一致：

| 渠道 | 推荐规格 | 分级重点 | 原因 |
|---|---|---|---|
| **商超/精品超市** | 中果-大果，单根130–180g，整箱5–10kg，A级 | 外观整齐、长度一致、无斑无伤、成熟度可控 | 陈列好看，损耗低，客单价高 |
| **社区水果店** | 中果，单根120–150g，5–8kg箱，A/B级 | 性价比高，允许轻微花皮 | 周转快，价格敏感 |
| **电商/即时零售** | 小果-中果，单根90–140g，小包装2–5根/袋或1–2kg装，A/B级 | 单份重量稳定、耐运输、成熟度偏青或微黄 | 减少压伤，控制客诉 |
| **批发市场/农贸** | 大果/特大果，整箱10–15kg，B级为主 | 价格优先，允许轻微外观瑕疵 | 走量，下游自行分拣 |
| **餐饮/烘焙/果汁** | 加工级，单根不限，整箱大包装，C级或B级尾货 | 果肉可用、成熟度高、成本低 | 不看重外观 |
| **团购/企业福利** | 中果-大果，5–10kg礼箱，A级 | 包装完整、果形统一、成熟度适中 | 送礼属性，重视品相 |

## 三、实操判断建议

如果你要采购或给渠道供货，可以按这个顺序确认：

1. **先问佳农业务员要当期规格书/装箱单**  
   重点看：单根克重范围、每箱净重、每箱根数、成熟度、等级（A/B/C）。

2. **按渠道倒推规格**
   - 高端渠道：优先 A级 + 中大果 + 成熟度可控
   - 走量渠道：优先 B级 + 大果 + 价格低
   - 电商：优先小中果 + 耐运输 + 小包装

3. **不要只看“几斤箱”**  
   同样5kg箱，可能是大果20根，也可能是小果40根，渠道适配完全不同。必须同时看**单根重+根数+等级**。

4. **成熟度比规格更容易出问题**  
   电商和远距离渠道建议要青蕉或微黄蕉；门店近距渠道可以要黄熟蕉。催熟程度不匹配，比规格错一级更容易造成损耗。

## 四、结论

佳农香蕉没有对外统一固定的“几种规格”标准，实际是按**单根重量、整箱净重、根数、成熟度、外观等级**组合定价。  
**渠道分级核心逻辑是：**
- 商超/精品：A级、中大果、外观优先
- 电商/即时零售：A/B级、小中果、小包装、耐运输
- 批发/农贸：B级、大果、价格优先
- 餐饮加工：C级或B级尾货、成熟度高、成本优先
