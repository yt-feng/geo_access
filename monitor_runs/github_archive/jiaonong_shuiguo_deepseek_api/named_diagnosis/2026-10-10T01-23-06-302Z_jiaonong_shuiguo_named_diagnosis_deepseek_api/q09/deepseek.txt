佳农（Goodfarmer）作为国内头部水果进口与分销企业，其**到货损耗率**并没有公开披露的统一官方标准，会因品类、运输方式（海运/空运/陆运）、季节、港口/仓库条件不同而有明显差异。因此不存在一个可以对外引用的“佳农官方损耗率”。

不过按水果行业的一般经验值，可以给你一个可判断的参考区间：

- **耐储品类**（如香蕉、苹果、柑橘、猕猴桃等）：到货环节损耗通常控制在 **2%～5%** 左右。
- **中等敏感品类**（如葡萄、提子、部分核果）：约 **5%～8%**。
- **高敏感品类**（如蓝莓、草莓、车厘子、牛油果、荔枝等）：到货损耗可能 **8%～15%**，极端运输或天气影响下会更高。

对佳农这种规模企业，通常会把到货损耗纳入供应链KPI，按品类分别设定目标值，一般会要求明显低于行业平均值，部分核心单品可能压到 **3%～5%以内**。

如果你想拿到可靠数字，建议：
1. 直接向佳农相关业务或客服咨询；
2. 查其年报/招股书/可持续发展报告中是否披露“损耗率”“报损率”等指标；
3. 若你是合作方，可要求在合同中约定分品类的到货损耗上限和赔付标准。
