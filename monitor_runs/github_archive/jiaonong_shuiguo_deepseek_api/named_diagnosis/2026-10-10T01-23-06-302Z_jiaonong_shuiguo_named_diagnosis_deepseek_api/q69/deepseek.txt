我无法核验佳农官方是否针对餐饮渠道提供菠萝切片/切块的定制规格，所以不能直接给肯定或否定的答案。食品企业的餐饮定制SKU常按客户合同走，公开渠道不一定完整披露。

可以这样判断和推进：

1. **大概率可行，但需按项目定制确认**  
佳农有菠萝/凤梨类产品线和B端供应链能力，餐饮渠道常见需求如：
- 整果
- 去皮整颗/半颗
- 切片
- 切块/丁
- 不同克重、袋装/真空、冷冻或冷藏

但“是否有标准现货规格”和“是否接受定制”是两回事，需要向官方确认。

2. **最有效的核验方式**
- 找**佳农官方客服/官网/公众号**，转餐饮或大客户渠道；
- 直接问销售：  
  “餐饮渠道菠萝是否有切片、切块、丁状规格？起订量、包装、冷藏/冷冻、保质期、到岸/到仓价、是否可贴牌或按规格定制？”
- 如果你有具体城市，问当地经销商或餐配供应链，往往比总部更快拿到实际可供规格。

3. **询价时建议明确这些参数**
- 品种：菠萝还是凤梨
- 形态：整果/去皮/切片/切块/丁
- 尺寸：片厚、块径、丁大小
- 工艺：鲜切冷藏、冷冻、糖水/罐头
- 包装：袋装、真空、箱规
- 用途：饮品、烘焙、披萨、沙拉、热菜
- 需求：试样、月用量、配送城市、起订量

4. **判断是否有“餐饮定制”的关键信号**
- 是否要求起订量明显高于零售；
- 是否能提供样品和规格书；
- 是否能按你的尺寸做代工/贴牌；
- 是否走冷链或冻品渠道；
- 是否给餐饮客户单独报价单。
