佳农水果的配送时效取决于你所在的地区、购买渠道和配送方式。佳农本身是水果供应商/品牌方，并不是像京东、美团那样自建全国配送网络，所以“多久能到”主要看你在哪个平台下单。

**不同渠道的大致情况：**

1. **电商平台（京东、天猫、拼多多等）**
   - 一般走快递，发货后 **1-3天** 送达，偏远地区可能 **3-5天**。
   - 部分商品标注“次日达”或“48小时发货”，以商品页说明为准。

2. **生鲜平台（叮咚、美团买菜、盒马等）**
   - 如果当地有前置仓/门店，通常 **30分钟到2小时** 送达。
   - 具体以平台显示的预计送达时间为准。

3. **京东自营/佳农官方旗舰店**
   - 标“次日达”的地区，通常下单后 **次日** 到；其他地区 **1-3天**。

4. **商超/批发渠道**
   - 如果你是通过线下商超或经销商拿货，属于 B 端配送，时效由当地经销商决定，常见是 **1-2天**。

**影响时效的关键因素：**
- 你所在城市是否在冷链/仓储覆盖范围内
- 下单时间（是否在当日截单时间前）
- 水果品类（部分需冷链，可能慢一些）
- 大促期间（如双11）会延迟

**建议：**
直接看你下单页面的“预计送达时间”最准。如果是急用，优先选本地生鲜平台或京东自营次日达；如果不急，普通快递即可。
