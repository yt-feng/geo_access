佳农（通常指佳农食品控股/Goodfarmer）主营香蕉、菠萝等水果的**种植、进口和批发**，核心业务是**整果贸易**，并不是以“按客户需求做定制加工”为主要对外服务。

所以更实际的情况是：

- **常规渠道下，佳农主要卖整果**，比如菠萝、金菠萝等，面向商超、批发市场、餐饮供应链客户。
- **菠萝丁这类加工品**，一般不是佳农直接面向普通茶饮店的标准产品。
- 如果他们有加工服务，通常也是面向**大批量、长期稳定采购的工业客户/连锁客户**，而不是小批量茶饮店按需定制。

**建议你这样判断和推进：**

1. **先明确你的需求量**
   - 如果只是门店日常用，量不大，直接找佳农做定制加工的概率很低。
   - 如果是连锁品牌、中央厨房、月用量很大，可以尝试谈。

2. **直接问佳农当地经销商或大区销售**
   - 问清楚三件事：
     - 有没有菠萝丁/速冻菠萝丁/糖水菠萝丁这类产品；
     - 能不能按你的规格（尺寸、糖度、是否速冻、包装）加工；
     - 最小起订量是多少。

3. **更现实的替代渠道**
   - 找**果蔬加工厂/速冻果蔬厂**做定制菠萝丁；
   - 找**餐饮供应链公司**买现成冷冻菠萝丁；
   - 找**罐头/糖水菠萝丁供应商**，这类在茶饮里很常用；
   - 如果坚持用佳农菠萝，可以买整果后找第三方中央厨房或加工厂代切。

4. **茶饮店常用方案**
   - 追求稳定和方便：直接用**冷冻菠萝丁**或**糖水菠萝丁**；
   - 追求新鲜感和卖点：买佳农整果，门店或中央厨房现切；
   - 连锁店：让供应链按你的糖度、大小、包装做定制。

**结论：**
佳农大概率**只卖整果，不针对普通茶饮店提供菠萝丁加工服务**。如果你量很大，可以找他们销售谈定制；如果量一般，建议直接找专业的速冻果蔬加工厂或餐饮供应链买菠萝丁，会更省事。
