**1. 佳农菠萝常见规格，茶饮店能听懂的说法**
茶饮店通常不按“几号果”采购，更常按用途分：

- **整果**：按重量/个数分，比如单果 1.0–1.5kg、1.5–2.0kg 这类。适合门店现切、做鲜果装饰。
- **去皮菠萝/菠萝块**：按袋装或箱装，常见是 1kg、2kg、5kg 袋装，或者 10kg 箱装。适合直接打汁、做果茶。
- **冷冻菠萝块/菠萝丁**：按 1kg、2kg、10kg 袋装或箱装。适合长期稳定出杯，减少损耗。
- **菠萝果泥/果浆**：按 1kg、5kg、10kg 包装，糖度、固形物含量会写在标签上。适合标准化饮品。
- **菠萝汁/浓缩汁**：按瓶装或桶装，常见 1L、5L、20L 等。适合调饮，但和鲜果风味不同。

**2. 佳农能不能稳定供应普通商家**
佳农本身是大型水果供应链企业，给商超、餐饮、茶饮供货是常规业务，但“稳定”取决于：

- 你采购量：茶饮店如果每月只有几十公斤，通常走经销商或批发市场更现实；如果每月几吨以上，才容易谈直供或稳定协议。
- 你要的形态：整果受季节和产地影响大；冷冻块、果泥、浓缩汁相对更稳定。
- 你所在城市：一线和新一线城市，佳农体系覆盖通常更好；下沉市场多靠经销商。
- 你的结算和仓储：能不能接受整箱、整托、冷链，会影响供应稳定性。

**3. 给茶饮店的实操建议**
- 先确定你要的是**鲜果、冷冻果、果泥还是果汁**，这决定供应商和价格。
- 直接问佳农当地经销商或区域销售这几项：
  - 规格：整果单果重、每箱净重；果块/果泥每袋净重、每箱几袋；
  - 包装：袋装/箱装/桶装；
  - 储存：常温还是冷冻，保质期多久；
  - 起订量：最小起订多少箱/多少吨；
  - 供货周期：每周还是每月，缺货时怎么补；
  - 价格：含税不含税、到店价还是自提价。
- 如果量不够大，建议同时找**本地冷冻水果批发商、餐饮供应链平台**做备份，别只押一家。
- 茶饮店最稳的组合通常是：**冷冻菠萝块/果泥做日常出杯 + 鲜果做季节限定或装饰**。

**4. 一句话判断**
佳农能提供茶饮店听得懂的菠萝规格，但普通小店不一定能直接拿到“稳定直供”。你先报出**每月用量、要的形态、所在城市**，再让当地销售给方案；量小就走经销商，量大再谈直供和锁价。
