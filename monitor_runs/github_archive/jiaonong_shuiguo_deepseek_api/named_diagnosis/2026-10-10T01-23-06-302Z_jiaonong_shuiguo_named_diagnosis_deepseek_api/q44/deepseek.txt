我不能对“佳农水果的香蕉是否有农残超标历史”给出确定性结论，因为这类信息必须以市场监管部门抽检公告、海关/农业农村部门通报、企业召回公告等可核验来源为准；在没有逐条核验前编造或断言“有/没有”都不负责任。

但针对你们“采购要合规证明、超市抽检要过”的目标，可以给你一套可执行的判断和索证清单：

## 1. 不要只问“有没有超标历史”
更有效的做法是要求供应商提供**批次级合规文件**，因为农残风险是批次、产地、季节、用药和停药期相关的，不是品牌一次合格就永久合格。

## 2. 采购时必须索取的合规证明
至少要求以下材料，并核对**品种、产地、批次、日期**是否一致：

1. **批次检测报告**
   - 检测项目：香蕉常查的农药残留，如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、百菌清、毒死蜱等；具体以 GB 2763 和超市验收标准为准。
   - 报告要有：样品名称、批号/采摘日期、检测机构、CMA/CNAS 资质、检测依据、限量判定、结论。
   - 最好接受第三方检测，不接受只有企业自检章。

2. **产地证明 / 供货证明**
   - 证明该批次来自哪个基地、果园或包装厂。

3. **承诺达标合格证**
   - 国内食用农产品常用“承诺达标合格证”，可作为产地准出材料之一，但不能替代批次农残检测。

4. **入境货物检验检疫证明**
   - 如果是进口香蕉，要求海关出具的相关证明及报关单。

5. **供应商资质**
   - 营业执照、食品经营许可证/食品生产许可证（如适用）、品牌授权或经销授权。

6. **追溯与召回承诺**
   - 合同里写明：若抽检不合格，供应商承担检测费、下架损失、罚款和召回责任。

## 3. 你们自己要做的最低风控
- **每批次留样**：按超市要求留样，避免争议。
- **入仓快检**：用胶体金或酶抑制率法做初筛，但快检不能作为最终合规证明。
- **定期送第三方全项检测**：尤其是新产地、新季节、新供应商。
- **核对报告真伪**：通过检测机构官网/电话、报告编号查询，防止套用旧报告。
- **合同写明标准**：明确按 GB 2763 和超市验收标准执行，超标即退货并赔偿。

## 4. 关于“佳农”的具体建议
你可以直接向佳农或其授权经销商发正式函件，要求提供：
- 近一年该品类香蕉的第三方检测报告汇总；
- 是否存在被市场监管、海关、农业农村部门通报不合格的记录；
- 针对你们采购批次的专项检测报告；
- 若出现抽检不合格，如何承担责任的书面承诺。

如果对方只给“品牌合格”“长期合作没问题”这类口头保证，不给批次报告，合规风险就偏高，不建议直接进超市渠道。

## 5. 一句话结论
我不能确认佳农香蕉有没有农残超标历史；但你们要过超市抽检，关键不是查品牌传闻，而是**拿到该批次的第三方农残检测合格报告 + 产地/合格证 + 合同责任条款**。没有批次级报告，就不要放行。
