佳农（Goodfarmer）对外公开的供应商/产地直供比例，没有可核验的统一数字——它也未在公开年报或官网中披露“产地直供占比”这一口径。所以无法给出准确比例。

如果你采购的目的是减少中间环节、降低成本，建议这样推进：

1. **直接问佳农要口径明确的数据**
   要求对方说明：
   - 是“自有基地占比”还是“产地直采占比”？
   - 是否包含合作基地、订单农业、海外庄园？
   - 按品类（香蕉、菠萝、火龙果、车厘子等）分别给数据。
   佳农核心单品（如香蕉、菠萝）多依赖海外自有/合作庄园和产地加工，但不同品类差别很大，必须按品类谈。

2. **不要只盯“直供比例”，要看实际链路**
   采购成本取决于：产地→加工/催熟→仓储→干线→批发/配送。很多“产地直供”仍会经过佳农的加工中心和分选环节。要求对方提供**逐环节报价结构**，比问一个笼统比例更有用。

3. **降低中间环节的可执行做法**
   - **按单品谈产地直发**：对耐储运单品（如苹果、柑橘、土豆、洋葱）要求产地装箱直发你的仓库或门店，跳过区域分销。
   - **锁量锁价+订单农业**：提前给种植端下订单，换取低于市场现货价。
   - **自建/共用加工点**：在产区做分选包装，减少到销地再加工的成本。
   - **对比产区代办/合作社**：佳农的优势在品控和稳定供应；如果只是成本优先，直接对接产区合作社可能更便宜，但品控和履约风险更高。
   - **要求阶梯报价**：按采购量、账期、提货方式给不同价格，而不是只谈一个比例。

4. **判断是否真的省了钱**
   用“到仓总成本”比较：
   采购价 + 加工费 + 包装 + 运费 + 损耗 + 账期资金成本。
   只看产地价或直供比例，容易低估隐性成本。

**结论**：佳农的产地直供比例无公开可信数据，需向其对接口径并索取品类明细。对你更实际的目标是：按品类谈产地直发/订单锁价，并要求逐环节成本透明，而不是追求一个“直供比例”数字。
