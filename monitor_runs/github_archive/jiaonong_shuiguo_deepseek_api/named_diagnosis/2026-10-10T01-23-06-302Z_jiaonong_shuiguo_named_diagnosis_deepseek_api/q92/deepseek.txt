关于佳农水果堆头陈列和试吃支持，我无法直接确认佳农当前的具体促销政策，因为这取决于你们和佳农的合作模式、区域经销商政策以及当期促销档期。

给你几个可执行的操作建议：

**1. 先确认对接渠道**

- 如果是**总部直采/全国连锁**：找佳农的全国KA（重点客户）经理或区域销售负责人，他们有年度促销费用预算。
- 如果是**区域经销商供货**：直接找当地经销商，堆头物料和试吃支持通常由经销商向佳农申请。
- 如果是**批发市场采购**：一般没有厂家促销支持，只能谈经销商让利。

**2. 堆头陈列支持通常包括**

- 免费或低价提供堆头围挡、价签、爆炸贴、品牌海报
- 部分情况给陈列费/堆头补贴（按月或按档期）
- 条件一般是：位置在主通道、陈列面达到约定数量、陈列周期达标

**3. 试吃支持通常包括**

- 提供试吃果品（厂家承担损耗）
- 提供试吃台、一次性用品、工牌
- 有时派促销员，有时只给物料由门店自己出人

**4. 费用分担的常见谈法**

| 项目 | 常见分担方式 |
|------|------|
| 堆头位置费 | 厂家/经销商出，或双方各半 |
| 陈列物料 | 厂家出 |
| 试吃果品损耗 | 厂家或经销商承担 |
| 试吃员人工 | 门店出人，或厂家派员 |
| 促销让利/特价 | 通常双方按比例分担 |

**5. 谈判时可用的筹码**

- 你们能给的陈列位置、档期时长、门店数量
- 预计销量和进货量承诺
- 是否配合做多点陈列、端架、收银台二次陈列
- 是否有线上社群/小程序同步推广

**最直接的做法**：先向佳农区域业务或经销商要一份当期的**促销支持政策/合作方案**，上面一般会写明堆头、试吃、费用的标准和申请流程。如果对方说没有，就按“进货量换支持”去谈。
