佳农（Goodfarmer）有对外系统对接能力，但**没有公开的、自助申请的OpenAPI文档**。他们主要走B2B大客户/供应商系统对接模式，具体走法如下：

## 实际情况

1. **对接入口**：通常通过佳农的**大客户部/电商渠道部/IT部门**发起，属于商务+技术双线流程，不是开发者门户那种模式。
2. **接口形式**：常见是 **EDI报文**、**SFTP文件交换**、或**定制REST/WebService API**，具体取决于双方ERP能力和订单规模。
3. **对接内容**：商品主数据（SKU/规格/箱规/条码）、库存/可售量、价格/促销、下单、订单状态、发货/物流、对账。

## 你要走的流程

1. 先找**对接的佳农业务负责人（销售/渠道经理）**，说明你是生鲜电商、要对ERP直连，让他转介其IT。
2. 明确技术对接清单（见下），让对方给出接口文档或对接规范。
3. 双方约定环境：测试环境、鉴权方式（多为Token/签名）、频率限制、失败重试。
4. 联调 → 压测 → 灰度 → 上线。

## 建议你提前确认的技术点

- 商品/库存同步是**推送还是拉取**，实时还是定时（生鲜库存变化快，尽量要准实时）
- 下单接口是否支持**锁库存/预占**，避免超卖
- 发货和物流节点是否回传（生鲜对时效敏感）
- 价格是含税/不含税、是否按渠道差异化
- 限流、超时、重试、幂等设计（下单必须幂等）
- 数据格式：JSON / XML / 文件

## 提醒

佳农的接口文档通常**不对外公开**，网上搜不到现成文档是正常的，不要轻信第三方卖的「佳农API文档」。对接前务必让商务把技术方案和SLA写进协议。
