佳农（Goodfarmer，主要指其菲律宾/厄瓜多尔等进口香蕉）在供应链上通常采用**乙烯催熟**，而不是“树上自然熟后直接卖到你手里”的那种自然熟。

原因很实际：香蕉如果等树上自然熟再采摘，根本经不起国际海运和商超周转。所以行业通用做法是：

- **产地采收**：青果、硬度高时采摘
- **冷链运输**：低温抑制后熟
- **到港/配送中心**：进入催熟库
- **催熟**：用**乙烯气体**或**乙烯利**诱导后熟
- **控温控湿**：控制催熟速度和均匀度
- **分级出货**：按商超要求的成熟度（比如1-7级色卡）发货

所以你问“乙烯催熟还是自然熟”，答案是：**佳农这类商品香蕉基本是人工乙烯催熟，不是树上自然熟。**  
“自然熟”在商超语境里通常只指**没有额外催熟剂、靠自身后熟或常温放熟**，但佳农这种规模化进口蕉，几乎不会走纯自然熟路线。

对你们商超控制催熟时间，关键不是纠结“乙烯还是自然”，而是抓这几个变量：

1. **到货成熟度**  
   问供应商要色卡等级，常见1-7级。到货是2级还是3级，后面时间差很多。

2. **催熟温度**  
   香蕉催熟常用 **15-18℃** 起步，后期可到 **18-20℃**。温度越高熟得越快，但容易青软、断指、风味差。

3. **乙烯浓度与时间**  
   催熟库一般用乙烯气体，浓度约 **100-150 ppm**，处理 **24-48小时**，然后通风排乙烯。  
   如果是乙烯利浸泡/喷洒，则按供应商方案，时间和浓度更敏感。

4. **湿度**  
   相对湿度建议 **85%-95%**，太低会失水、表皮发暗。

5. **CO₂控制**  
   催熟过程中香蕉会释放CO₂，浓度过高会抑制后熟，需要通风换气。

6. **目标货架期**  
   如果你们希望到店后 **2-3天** 转黄销售，催熟终点一般控制在 **3-4级**；  
   如果要 **4-5天** 慢慢卖，控制在 **2-3级** 出货。

7. **季节与产地**  
   菲律宾蕉、厄瓜多尔蕉、国产蕉的后熟速度不同；夏季快、冬季慢，不能一套参数用全年。

给商超的实操建议：

- **不要自己从青果开始催**，除非有催熟库和经验。最好让佳农或一级供应商按你们要的成熟度出货。
- **到货后不要立即进冷库**。青蕉进低温会“冷伤”，后熟不齐、发黑。
- **到店后放在13-15℃、通风处**，需要加速转黄可到18-20℃。
- **按批次记录**：到货色级、温度、湿度、乙烯处理时间、出货色级、货架表现。跑2-3轮就能定出你们的专属参数。
- **和供应商明确写进合同**：到货成熟度、允许误差、乙烯使用方式、催熟后到达门店的天数。

一句话：**佳农香蕉是人工乙烯催熟。你们要控制催熟时间，核心是控制到货色级、催熟温度、乙烯处理时长和出货成熟度，而不是等它自然熟。**
