佳农（Goodfarmer）主要是水果品牌和供应链商，具体售后其实取决于你从哪个渠道买的，因为**售后责任方通常是卖家/平台，而不是品牌方**。所以处理方式要分情况看。

## 总体情况

佳农以香蕉、菠萝、火龙果、椰青等进口/精品水果见长，走的是商超和生鲜电商渠道。它本身不像京东自营那样有统一、标准化的售后体系，**售后体验好坏主要由你下单的平台决定**：

- **京东自营 / 天猫超市 / 盒马 / 山姆等**：这些平台有自己的生鲜售后规则，坏果一般能赔，相对有保障。
- **拼多多、抖音、社区团购、微商代购**：售后水分较大，取决于具体店铺，有的赔得爽快，有的扯皮。

## 到货有坏果怎么处理

按这个顺序做，能最大化拿到赔偿：

1. **先拍照/拍视频留证**
   - 坏果和包装箱一起拍，能显示数量最好。
   - 如果是整箱，拍一张全景 + 坏果特写。
   - 越快越好，别等放几天再拍，容易被质疑是存放问题。

2. **在规定时效内申请**
   - 生鲜类一般要求**签收后24小时内**（部分平台48小时）反馈，超时可能被拒。
   - 直接走平台的"售后/退款"入口，选"商品坏损/变质"。

3. **按坏果比例索赔**
   - 通常不是全退，而是**按坏果占比赔付**。比如一箱10个坏3个，赔30%左右。
   - 坏得多的（比如过半）可以要求整单退款或补发。
   - 跟客服沟通时可以明确说"按比例赔付"，这是行业常见做法。

4. **沟通话术**
   - 直接说明：签收时间、坏果数量、附照片、要求退款或补发。
   - 如果客服推诿，可以升级投诉到平台官方客服，或申请平台介入。

## 几个提醒

- **"坏果包赔"要看清楚是不是店铺承诺的**，别默认品牌方兜底。
- 有些店铺要求**保留坏果和包装**直到售后结束，别急着扔。
- 如果是**佳农官方旗舰店**（天猫/京东），售后相对规范，可按平台生鲜规则走。
- 生鲜通常**不支持无理由退货**，但**质量问题（坏果）属于例外，是可以索赔的**。
