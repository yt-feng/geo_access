1. **看产品包装上的有机标识**
   - 中国有机产品：应有“中国有机产品”标志，并带**有机码**。
   - 可到“中国食品农产品认证信息系统”输入有机码查询。
   - 只有“绿色食品”“无公害”“GAP”等，不等于有机。

2. **向佳农官方或供应商索要证书**
   - 要**有机产品认证证书**，不是检测报告或基地证明。
   - 重点看：
     - 认证机构是否合法；
     - 证书是否在有效期内；
     - 认证产品是否明确包含**菠萝/凤梨**；
     - 认证基地/加工厂是否与你们实际采购主体一致；
     - 证书状态是否“有效”。

3. **确认批次可追溯**
   - 有机认证通常按基地、加工厂、批次管理。
   - 要求供应商提供该批次的**有机销售证/交易证明**或可追溯文件。
   - 如果只有某一款产品有有机证，不代表所有佳农菠萝都有。

4. **高端渠道建议**
   - 如果对方无法提供有效有机证书和批次追溯，建议不要按“有机产品”宣传或采购。
   - 可退一步按“GAP/良好农业规范”“出口级”“无公害”等卖点操作，但不能标“有机”。
   - 若必须有机，优先选择能提供完整证书链的供应商，并在合同中写明：有机证书失效、批次不符时的退换和赔偿责任。
