佳农水果（佳农食品控股旗下）的配送覆盖和收费，取决于你走的是哪条渠道，得分开看：

**1. 覆盖范围**
佳农主要是水果供应链企业，业务分几块：
- **商超/生鲜渠道供货**：通过永辉、盒马、大润发、山姆等卖场销售，这些门店本身覆盖到地级市甚至部分县域。
- **电商零售**：在天猫、京东、抖音等平台有旗舰店，走的是各家快递/平台仓配，覆盖按平台物流能力走。
- **B端批发/餐饮供货**：按合同和起订量配送。

所以"佳农配送覆盖哪些城市"没有统一答案——**看你是通过哪个渠道下单**。

**2. 你们县城门店能不能送到**
- 如果是你们县城自己的门店想进货（B端）：一般需要联系佳农当地经销商或区域业务，多数情况下县域是通过**经销商/二批**覆盖，而不是厂家直送。能否直供取决于起订量、距离和当地有没有代理。
- 如果是消费者在电商平台买：看平台物流能不能到你县，通常快递能到就能送，但生鲜类可能受"不发偏远地区"限制。

**3. 冷链物流收费**
佳农没有公开统一的冷链报价，通常是：
- 按**重量/体积+距离**计费；
- 有**起订量**要求，低于起订量可能加收或走零担；
- 冷链零担、整车、快递冷链价格差异大。

**建议你直接做这两步：**
1. 打佳农官方客服电话或官网/公众号，问清你所在区域由哪个经销商负责，以及是否有厂家直供政策。
2. 提供你的县城名称、门店类型、预计月采购量，让对方给具体配送方案和报价。

没有具体的城市和采购量，任何"能不能送、多少钱"的答复都不准确，别信笼统的承诺。
