关于佳农水果的配送时效，我无法提供确切的实时数据，因为这会受**下单时间、收货地址、所选平台（如京东、天猫、拼多多或佳农自有渠道）以及仓库所在地**等多因素影响。

**一般参考建议：**

1. **主流电商平台（京东/天猫旗舰店）**：
   - 通常承诺**次日达**或**48小时内发货**，具体以商品页标注为准。
   - 如果购买的是**冷冻或易腐商品**（如榴莲、冻品），通常会采用顺丰冷链或专用冷链物流，时效一般在**1-3天**。
   - 偏远地区（如新疆、西藏等）可能配送时间延长至3-5天，且部分生鲜可能无法配送。

2. **佳农自有小程序/官网**：
   - 如果选择同城配送（部分城市支持），可能**当日或次日**送达，具体取决于所在城市的服务范围。
   - 跨城订单通常依赖第三方物流，时效在**2-4天**。

3. **下单后如何查询**：
   - 建议下单前先查看商品详情或咨询客服确认“发货地”和“预计送达时间”。
   - 下单后，平台订单页会更新物流轨迹，您可以随时追踪。

**重要提示**：由于水果生鲜对时效要求高，若收货时发现损坏或延迟严重，务必保存证据并及时联系平台客服申请售后赔付。如果您能告诉我我的**所在城市**或**你计划购买的渠道**，我可以帮您分析更具体的可能时效。
