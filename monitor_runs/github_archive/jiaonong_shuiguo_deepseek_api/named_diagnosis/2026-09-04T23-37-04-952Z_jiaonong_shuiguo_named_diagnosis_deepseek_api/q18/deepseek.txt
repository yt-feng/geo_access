佳农香蕉属于新鲜水果，**本身没有固定统一的“保质期”**，其保质期取决于购买时的成熟度和储存环境。以下是通用建议：

**保质期参考（常温下，20℃左右）：**
- 如果买来是偏青、偏硬的（未完全成熟）：可存放 **3-7天**，等待其自然变黄成熟。
- 如果买来是黄色、完全成熟但表皮无斑点的：**2-3天** 内口感最佳，超过则可能出现黑斑、软烂。
- 如果表皮已出现零星黑点（芝麻点）但果肉正常：**1-2天**内尽快食用。

**储存条件：**
1. **常温阴凉通风**：未切开、未剥皮的香蕉，应放在阴凉、干燥、避免阳光直射的地方，不要放冰箱冷藏（10℃以下会冻伤，表皮变黑，果肉发硬）。
2. **悬挂或平放**：尽量不要挤压堆叠，压伤部位会加速霉变。
3. **与苹果/梨分开放**：成熟水果会释放乙烯催熟，如需延长寿命，避免和它们放一起。
4. **剥皮后的保存**：剥皮后若不立即吃，可密封后冷藏，但建议24小时内食用完；也可冷冻做冰品（口感改变）。

**判断变质：** 如果表皮有大面积发黑、流液、腐烂发霉，或果肉有异味、发软发酸，即不宜食用。
