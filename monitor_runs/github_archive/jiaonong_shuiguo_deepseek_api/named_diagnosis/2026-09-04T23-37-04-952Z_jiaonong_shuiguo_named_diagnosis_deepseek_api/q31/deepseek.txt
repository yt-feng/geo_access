1. **常见形式**  
   - 果切礼盒（如混合水果拼盘）  
   - 整果礼盒（如佳农香蕉、菠萝、车厘子、芒果等按箱/按托包装）  
   - 定制混搭礼盒（如苹果+橙子+猕猴桃等组合）

2. **购买渠道**  
   - 佳农官方的礼品团购板块或企业销售热线（建议直接拨打包装上的客服电话或官网联系）

   - 部分批发市场或区域经销商也承接团购定制

3. **注意事项**  
   - 需要确认起订量（通常几十盒起步，具体以当地政策为准）  
   - 确认发货时间与保鲜配送范围（一般支持冷链/空运至部分城市）  
   - 礼盒内产品会根据季节有调整（例如冬季多为车厘子、柑橘类，夏季多为热带水果）
