我无法核验佳农水果当前是否有针对餐饮渠道的菠萝切片/切块定制规格，所以不能给出确定答复；这类信息会随产品线和客户政策变化，需要以官方渠道为准。

建议你按下面方式快速确认：

1. **找对渠道**：直接联系佳农官方客服或当地销售，说明是“餐饮/团餐/饮品渠道”，询问是否有**冷冻菠萝块、菠萝丁、菠萝切片、糖水菠萝片**等B端规格。
2. **问清关键参数**：
   - 规格：切片厚度/直径、切块尺寸（如10×10mm、20×20mm）
   - 状态：冷冻、冷藏、糖水罐头、鲜切
   - 包装：袋装/箱装，净重
   - 起订量、供货周期、冷链要求
   - 是否可贴牌或按客户要求定制
3. **要样品和检测报告**：餐饮渠道通常可先要样品试菜，并索取检验检疫、农残/微生物等报告。
4. **备选方案**：如果佳农没有对应定制规格，可同时问**冷冻水果供应商、罐头厂、净菜加工厂**，这类渠道更常做餐饮定制切块/切片。
