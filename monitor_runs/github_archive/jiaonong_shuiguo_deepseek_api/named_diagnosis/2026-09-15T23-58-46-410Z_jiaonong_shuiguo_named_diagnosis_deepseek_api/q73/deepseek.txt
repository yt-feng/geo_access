佳农的水果业务里，苹果是重要品类之一，常见会涉及：

**佳农苹果常见品类**
- 嘎啦苹果
- 红富士苹果
- 其他苹果如青苹果、皇后苹果等，具体会随产季和渠道变化

不过，“佳农具体在售的苹果品类清单”会因年份、产季、渠道（商超、电商、批发、出口）不同而变化，建议以佳农官方渠道或对接销售确认当前可供货品类为准。

**关于进口嘎啦和红富士的产地**
- **嘎啦（Gala）**：进口常见产地包括 **新西兰、美国、智利、南非** 等。其中新西兰嘎啦在部分高端渠道较常见。
- **红富士**：严格说红富士是品种体系，进口红富士常见产地包括 **美国、新西兰、智利** 等；但中国本身也是红富士主产国，且佳农在国内有苹果供应链，实际采购时可能是国产红富士或进口红富士，需要和供应商明确区分。

**采购建议**
1. 先确认你要的是“进口嘎啦”和“进口红富士”，还是“佳农品牌苹果”即可，不限定进口。
2. 让佳农或经销商提供：当前产季、产地、规格（果径/等级）、包装、起订量、到货港/交货地、报价有效期。
3. 重点核验：原产地证明、植物检疫证书、报关单、品牌授权或经销证明。
4. 如果用于商超或电商，还要确认是否支持定制包装、条码、质检报告和稳定复供。
