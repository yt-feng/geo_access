佳农香蕉的包装或官方渠道通常不会标注一个固定“保质期”，因为香蕉是后熟型水果，保质期主要取决于**购买时的成熟度**和**储存温度**。可以按以下标准判断：

**一、常温储存（最常见）**
- **青香蕉**：室温阴凉处（约20–25℃），一般 **3–7天** 逐渐转黄成熟。
- **已转黄的香蕉**：室温下通常 **2–4天** 内吃完最佳，之后很快出现黑斑、软烂。
- **避免**：阳光直射、暖气旁、密闭塑料袋里捂太久，会加速腐烂。

**二、冷藏储存**
- 香蕉**完全转黄后**可以冷藏，能延长 **3–5天** 左右。
- 注意：冷藏后**香蕉皮会变黑**，这是冷害和氧化导致，不代表果肉一定坏了；只要果肉正常、无异味，仍可食用。
- **青香蕉不建议冷藏**，会停止正常后熟，口感变差。

**三、冷冻储存**
- 熟透吃不完的香蕉可去皮切段冷冻，保存 **1–2个月**，适合做奶昔、烘焙。
- 冷冻后不适合直接当鲜果吃。

**四、判断是否还能吃**
- 可以吃：表皮有黑斑，但果肉仍呈乳白/淡黄、质地正常、无酸腐味。
- 不建议吃：果肉发黑、出水、发黏、有酒味/酸味/霉味，或表皮长霉。

**五、实用建议**
- 想催熟：和苹果或熟香蕉一起放在纸袋里，室温放置。
- 想延缓成熟：成熟后分开存放，减少挤压，可冷藏。
- 佳农香蕉如果是整把购买，建议吃多少拿多少，未吃的尽量不要提前剥开或清洗。
