可以这样判断和查证：

1. **看抽检层级**
   - 国家市场监管总局、各省/市市场监管局会定期发布食品安全监督抽检通告。
   - 抽检通常按“批次”公示，不是按品牌汇总，所以很难直接得出“佳农香蕉合格率X%”。

2. **看香蕉主要风险项**
   - 香蕉抽检常见关注项包括：农药残留（如吡虫啉、噻虫嗪、苯醚甲环唑等）、重金属、防腐保鲜剂等。
   - 正规渠道销售的佳农香蕉一般会经过供应商自检和渠道抽检，但具体结果要看对应批次。

3. **实际购买时怎么判断**

   - 看包装是否有产地、批次、经销商信息。
