佳农（Goodfarmer）有针对礼品和团购场景的水果礼盒，但具体在售的礼盒类型、规格和价格会随季节、渠道和地区变化，通常没有一份长期固定的“官方礼盒清单”。

比较稳妥的判断方式是：

1. **看官方渠道**
   - 佳农官网、官方微信公众号/小程序、天猫/京东官方旗舰店，一般会设“礼盒”“团购”“企业采购”等入口。
   - 如果有企业团购需求，通常可以通过这些入口找到团购联系方式，或直接联系客服询问。

2. **常见礼盒方向**
   佳农以香蕉、菠萝、火龙果、椰青、车厘子等进口/国产水果为主，礼盒通常围绕这些品类做组合，例如：
   - 单一水果高端礼盒（如车厘子、椰青、菠萝）
   - 多品类水果组合礼盒
   - 节庆礼盒（春节、中秋等）
   - 企业定制团购礼盒（可印 logo、定制祝福卡等，需达到一定起订量）

3. **团购是否支持定制**
   企业团购一般可以谈：
   - 起订量
   - 礼盒内容搭配
   - 外包装/腰封/卡片定制
   - 配送时间和地址分批配送
   但具体政策要以佳农当地经销商或官方客服确认为准。

4. **直接确认话术**
   你可以直接问客服：
   > “你们现在有没有适合企业团购的水果礼盒？起订量多少？能不能定制包装和卡片？能否分批配送到不同地址？给我一份当前可做的礼盒报价单。”

5. **注意**
   - 水果礼盒季节性强，车厘子、柑橘等品类价格波动大，报价通常有有效期。
   - 不同地区可能由不同经销商供货，官方旗舰店有货不等于你所在城市团购渠道也有同款。
   - 如果是大批量采购，建议至少提前 1–2 周对接，节庆前要更早。

简单说：**有，但需要按当前季节和所在地区找佳农官方或当地经销渠道确认具体礼盒和团购政策。**
