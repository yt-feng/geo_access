佳农（佳农食品控股）公开的财报和公开报道中，通常不会单独披露“水果到货损耗率”这一细项，因此不存在一个可核验的官方统一数字。不同品类、不同运输方式（海运/空运/冷链）、不同季节和不同客户（商超/电商/批发）差异很大。

行业里可参考的常见区间大致是这样：

- **香蕉等主力品类**：到货损耗通常控制在 **2%–5%** 左右，管理好的可以做到 2%–3%。
- **易损浆果类（蓝莓、车厘子、葡萄等）**：到货损耗往往在 **5%–10%**，长途海运或冷链波动大时可能更高。
- **整体到货损耗**：不少生鲜水果进口/分销企业会把目标定在 **5% 以内**，实际执行中常在 **3%–8%** 之间波动。

需要说明的是，这些是行业经验区间，不是佳农官方披露的数据。如果你需要准确数字，建议直接查阅佳农的招股书/年报/ESG报告，或向其投资者关系/客服渠道确认。
