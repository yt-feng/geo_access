目前公开渠道能查到的佳农香蕉具体在售规格，会随批次、销售渠道和季节变化，没有一个固定不变的“官方规格表”。不过按国内香蕉行业和商超/电商常见的做法，可以给你一个可判断的框架：

**一、佳农香蕉常见的规格维度**

通常不是按“品种”分，而是按**果指长度、单把重量、整箱重量、成熟度**来分：

1. **按果指长度/等级分**
   - 小果：果指较短，常见用于家庭装、电商小包装
   - 中果：商超散卖、社区团购主力
   - 大果/特级果：果指长、外观整齐，多用于精品商超、礼盒

2. **按单把重量分**
   - 常见有 1kg 左右、1.5kg 左右、2kg 左右等把装
   - 电商更常见 1–2kg 的小把装或家庭装

3. **按整箱规格分**
   - 常见 10kg、12kg、13kg、15kg 等箱规
   - 批发渠道常见 12–13kg 左右净重或毛重规格
   - 电商/社区团购常见 5kg、10kg 小箱

4. **按成熟度分**
   - 青蕉：适合长途运输、批发、催熟后销售
   - 微黄/黄熟：适合商超、水果店即售
   - 熟蕉：适合即时消费、餐饮、烘焙

**二、不同渠道的分级标准思路**

| 渠道 | 关注重点 | 常见分级倾向 |
|---|---|---|
| 批发市场 | 耐运输、箱规统一、出肉率 | 青蕉为主，按果指长度和把重分等级 |
| 商超/精品超市 | 外观整齐、色泽一致、无伤痕 | 中大果、特级/一级果，成熟度可控 |
| 水果店/社区团购 | 性价比、即食性 | 中果为主，微黄或黄熟 |
| 电商 | 单把重量稳定、耐压包装 | 小把装、家庭装，中果居多 |
| 餐饮/烘焙 | 成熟度、出肉率、成本 | 熟蕉或大果，对颜值要求较低 |
| 礼盒/礼品 | 果指均匀、无斑、包装好 | 特级大果，外观优先 |

**三、实际判断建议**

如果你是要采购或做渠道分级，建议直接向佳农官方或区域经销商索取当批次的：
- 果指长度范围
- 单把重量范围
- 整箱净重/毛重
- 成熟度标准
- 允许的伤果率、青果率、异形果比例

因为香蕉是生鲜品，同一品牌不同产地、不同季节的规格会有浮动，行业里更常见的是“按批次确认规格”，而不是全国统一固定标准。
