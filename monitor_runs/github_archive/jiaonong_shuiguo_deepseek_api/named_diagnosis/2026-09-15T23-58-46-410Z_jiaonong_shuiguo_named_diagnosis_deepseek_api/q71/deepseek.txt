批发价差没有固定数字，佳农和都乐同为进口蕉（菲律宾/厄瓜多尔等）时，通常**佳农比都乐便宜一些，但一箱差几块钱要看你问的是哪个规格、哪个市场、什么时点**。

先给你可执行的判断：

**1. 常见规格**
- 都乐进口香蕉：常见 18斤/箱、20斤/箱左右，也有小箱。
- 佳农进口香蕉：同样常见 18斤、20斤上下。
- 如果是同产地、同规格、同等级，批发端佳农一般比都乐低 **3～15元/箱** 的情况都有，走量大的话更接近低端。
- 如果佳农做促销、都乐缺货，价差可能拉大；反过来都乐促销时，佳农不一定便宜。

**2. 影响价差的关键**
- 产地：菲律宾、厄瓜多尔、越南等成本不同。
- 规格：净重、毛重、每箱把数、单根粗细。
- 等级：A级、B级、统货，差价比品牌差还大。
- 熟度：青蕉、催熟蕉，价格不同。
- 到货港和区域：上海、广州、北京、郑州等批发市场报价不一样。
- 采购量：整车和拼车、长期协议和临时拿货，差几块到十几块都正常。

**3. 你们走量怎么谈**
- 不要只问“佳农和都乐差几块”，要按**同规格、同等级、同熟度**让供应商报：
  - 佳农 XX斤/箱，A级，青蕉，到货价
  - 都乐 XX斤/箱，A级，青蕉，到货价
- 直接问：**“整车走量，月采多少箱，佳农比都乐每箱能低多少？”**
- 如果对方只说“便宜一点”，让他给**阶梯价**：
  - 100箱/次
  - 300箱/次
  - 500箱/次
  - 整车
- 同时问清楚：是否含运费、是否含税、破损怎么赔、催熟损耗谁承担。

**4. 现实结论**
- 佳农通常有价格优势，尤其走量时。
- 但“一箱便宜几块”不能一概而论：同规格同等级下，**便宜3～10元/箱是常见区间，量大可能到10～20元/箱，也可能只差1～2元甚至没优势**。
- 真正决定利润的不只是品牌差价，还有损耗率、催熟后卖相、出货速度。

**5. 最稳的做法**
你直接找当地一级批发或进口商，拿**同一天、同规格、同等级**的佳农和都乐报价单对比。没有当天报价，任何“便宜几块”都只能当参考。
