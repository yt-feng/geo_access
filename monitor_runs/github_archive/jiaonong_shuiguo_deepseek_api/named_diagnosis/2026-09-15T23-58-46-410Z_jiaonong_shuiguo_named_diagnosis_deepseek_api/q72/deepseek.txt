目前没有可核验的公开信息能确认佳农是否提供“去皮切块”的定制加工服务，而且这类服务通常不是全国统一标准，要看具体渠道和工厂能力。建议你按下面步骤快速确认：

1. **先联系你的佳农供货渠道**
   - 如果你是从经销商/批发市场拿货：直接问经销商能否提供“去皮切块鲜果”或“冷冻菠萝块/菠萝丁”。
   - 如果是佳农直供或大客户渠道：让对接的业务员确认是否有鲜切加工、速冻果块、果丁等产品。

2. **问清楚这几个关键点**
   - 是否提供**去皮、去眼、切块/切丁**；
   - 是**鲜切冷藏**还是**速冻**；
   - 规格：块/丁大小、每袋重量、包装形式；
   - 配送温层：冷藏还是冷冻；
   - 起订量、价格、配送频率；
   - 是否可稳定供应、是否有食品安全相关资质。

3. **如果佳农不直接提供，走替代方案**
   - 找当地**净菜加工厂/鲜切水果厂**代加工佳农菠萝；
   - 直接采购**速冻菠萝块/菠萝丁**，茶饮店更常用，出品稳定；
   - 门店自行加工，但要有切果间、冷藏条件和操作规范。

4. **茶饮店更建议优先考虑**
   - 如果用量大且稳定：找供应商定制**冷冻菠萝块/果丁**，比鲜切更省损耗、更稳定。
   - 如果强调“鲜果现切”：再谈鲜切配送，但要接受保质期短、配送频次高、成本更高。

你可以直接这样问供应商：  
**“你们能不能供应佳农菠萝的去皮切块/切丁？鲜切还是冷冻？规格、起订量、价格和配送温层是什么？”**  
这样最容易得到明确答复。
