我无法核实"佳农水果"香蕉是否有农残超标的历史记录。这类具体企业的抽检不合格信息，需要以官方公示为准，我不能凭印象给你结论，否则会误导你的采购决策。

不过可以给你一套**可执行、能过商超抽检的合规操作路径**：

## 一、先自己查权威来源（免费且可留证）

1. **国家市场监督管理总局**官网 → "食品安全抽检"栏目，按"香蕉""佳农"关键词检索。
2. **各省市场监管局**官网（佳农主要进口口岸：上海、广州、深圳、青岛等），查进口食品抽检公告。
3. **海关总署**"进口食品化妆品安全监督抽检"公告，查进口香蕉。
4. 国家企业信用信息公示系统查供应商主体是否有行政处罚。

查到"无记录"≠"没超标过"，只是说明在公示范围内未见。这点要跟超市采购讲清楚。

## 二、采购要拿到的合规证明（超市抽检能用的）

向佳农或其授权经销商索取，**逐项留档**：

- **营业执照 + 食品经营许可证**（进口的还要有海关报关单、入境货物检验检疫证明）
- **每批次的出厂检验报告 / COA**，检测项目必须含：**农药残留（有机磷、拟除虫菊酯、氨基甲酸酯等）、重金属、真菌毒素**
- **第三方检测报告**（CMA/CNAS资质），报告要有批次号、生产日期、检测日期
- **承诺书**：供货方对农残符合 GB 2763《食品中农药最大残留限量》的书面承诺
- 若为进口：**入境货物检验检疫证明**是核心，比国内自检报告更被商超认可

## 三、关键判断点（决定你抽检会不会翻车）

1. **报告要"对应批次"**：拿几个月前或别的批次的报告，超市抽检到你实际卖的批次，照样不合格。必须**一批一检、随货同行**。
2. **检测机构要有 CMA 资质**，且报告在有效期内。
3. **自检报告不能替代第三方检测**：很多商超只认 CMA/CNAS 第三方报告。
4. **建议留样**：每批留 1–2 公斤封存 6 个月，万一抽检有争议可复检。
5. **合同里写清责任条款**：农残超标导致的罚款、下架、赔偿由供货方承担，并约定复检机制。

## 四、最实际的建议

仅靠佳农的品牌或历史口碑，**过不了合规审查**。你要做的是：

- 向佳农索要**近 1–2 年该品类的第三方检测报告和入境检验检疫证明**，看是否有异常批次；
- **要求逐批随货提供检测证明**，而不是一次性给一份通用报告；
- 必要时**自己花几百元做一次第三方抽检**（香蕉农残检测市场价约 300–800 元/项组），作为采购前的验证。
