关于佳农水果的堆头陈列和试吃支持，我无法直接替你确认，因为这取决于你和佳农具体的合作渠道、采购合同以及区域经销商政策。不过可以给你一个可执行的判断和谈判路径：

**1. 先确认你对接的是哪一层**
- 如果是**总部直采/全国连锁协议**：堆头、试吃、物料通常写进年度合同或促销协议，费用分担按合同走。
- 如果是**区域经销商/代理商供货**：支持力度由当地经销商定，弹性更大，但也更依赖采购量。
- 如果是**批发市场拿货**：基本没有品牌方促销支持，堆头和试吃要你自己承担。

**2. 佳农这类品牌通常可能给的支持形式**
- 堆头陈列：提供围挡、地贴、价签、堆头箱、主题物料，或给陈列补贴。
- 试吃：提供试吃果、一次性餐具、试吃台物料，或派促销员。
- 费用分担常见几种：
  - 品牌方全出物料，商超出场地和人力；
  - 双方按比例分担，比如品牌出果品和物料、商超出人；
  - 商超先垫付，达到约定销量后品牌方返点或核销；
  - 按采购额给一定比例的促销费用额度。

**3. 你谈判时可以这样问对方**
直接找佳农业务或经销商确认这几条：
- 本次促销能否提供堆头物料和试吃果？
- 试吃果按什么比例配送，是否计入损耗？
- 促销员谁出，工资谁承担？
- 陈列补贴/促销费是按采购额点数，还是固定金额？
- 核销需要什么凭证：照片、销量、陈列协议还是发票？

**4. 给你的实操建议**
- 先看合同里有没有“市场支持”“促销费用”“陈列协议”条款，有就按条款要。
- 没有合同约定的，用采购量做筹码谈：承诺堆头位置、陈列周期、进货量，换品牌方物料和试吃支持。
- 费用分担上，优先争取“品牌出物料和试吃果、商超出场地和基础人力”，这对商超最划算。
- 所有口头承诺要落到书面，写清支持内容、数量、时间、核销方式。
