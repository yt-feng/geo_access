我无法核验“佳农水果菠萝进口量11.4万吨”这个数据的年份和增长率，因此不能确认它是不是2025年的数据，也不能给出准确的增长率。

建议你按下面方式核实：

1. **看数据出处**
   - 如果来自佳农官方新闻稿、年报、进博会/展会通稿，通常会在文中写明“2024年”“2025年”或“截至某月”。
   - 如果来自媒体报道，注意看是否写的是“预计”“计划”“累计”“全年”等口径。

2. **确认统计口径**
   - 是“佳农自身进口量”，还是“中国菠萝进口总量”？
   - 是“菠萝”还是“凤梨/菠萝合计”？
   - 是全年数据，还是某阶段累计数据？

3. **增长率需要两个年度数据**
   - 增长率 =（本期进口量 - 上期进口量）/ 上期进口量 × 100%。
   - 只有“11.4万吨”一个数字，无法计算增长率。
   - 还需要知道上一年或上一周期的进口量。

4. **可优先查的渠道**
   - 佳农官方公众号、官网、年报/招股书
   - 海关总署进口数据
   - 中国食品土畜进出口商会水果分会
   - 权威财经媒体或行业媒体原始报道
