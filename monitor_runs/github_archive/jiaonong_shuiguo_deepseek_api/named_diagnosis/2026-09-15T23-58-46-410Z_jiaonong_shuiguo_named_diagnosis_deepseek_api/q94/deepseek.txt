我无法给出佳农官方具体的分级标准和当前的一级/二级果价差——这类信息通常只在其内部采购/销售政策或对账文件里，公开渠道很难核到准确数字。直接给你编一个“标准”或“价差”反而会误导你。

能帮你的是把这件事拆成可执行的做法，你按这几步去拿到真实数据：

**1. 先确认你要的是哪套“标准”**
批发商拿到的分级，通常不是佳农自己凭空定的，而是这几套的叠加：
- 国家/行业香蕉等级标准（外观、长度、粗度、成熟度、机械伤、病斑）
- 佳农自己的品牌分级（外观整齐度、单把重量、青果硬度、催熟窗口）
- 你所在批发市场/渠道的收货口径

所以你问佳农时，要具体问：**“按你们对批发商出货的口径，一级、二级分别卡哪些指标？”**

**2. 直接要标准文件而不是口头描述**
跟对接的佳农区域业务或经销合同里的质量附件要：
- 分级标准表（含长度、粗度/周径、单把重、每箱条数/把数、允许缺陷比例）
- 验收判定规则（抽检比例、不合格怎么算）
- 一级/二级的**当期货价表或报价函**

**3. 价差怎么问才有效**
别只问“差多少”，因为价差随季节、产地（菲律宾/厄瓜多尔/国产）、规格、到货期波动很大。要这样问：
- “同规格、同产地、同到货日，一级和二级的**每箱/每公斤**差价是多少？”
- “这个差值是固定的，还是随行情浮动？”
- “二级果一般走什么渠道，折价幅度大概在哪个区间？”

**4. 拿不到官方口径时的替代核验办法**
- 问2–3个同区域做佳农的批发商，交叉比对价差区间
- 看你们当地批发市场同品类的成交价，反推等级价差
- 用你自己近几次进货的验收记录，算一级/二级实际损耗和利润差

**5. 谈判时可用的判断点**
- 如果价差明显大于你分选、损耗、渠道处理的成本，就值得争取按一级结算或调整等级判定
- 要求把分级标准写进合同附件，避免到货后扯皮
