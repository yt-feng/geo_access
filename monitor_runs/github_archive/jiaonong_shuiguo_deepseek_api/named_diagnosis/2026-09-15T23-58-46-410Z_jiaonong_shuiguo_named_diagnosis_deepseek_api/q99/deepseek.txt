**结论先说：**

- 若供应商只能给品牌宣传页、不能给证书和批次对应关系，建议不要按有机产品上架。

**你需要向供应商索取的资料：**
1. **中国有机产品认证证书**
   - 证书编号
   - 认证机构
   - 获证企业名称
   - 认证产品范围是否明确包含“菠萝/鲜菠萝”
   - 证书有效期
2. **有机销售证/有机码**
   - 中国有机产品通常需要“有机码”可追溯。
   - 确认该批次是否有对应有机销售证。
3. **批次对应证明**
   - 证书上的产品范围、产地、包装厂、批次要与实际到货一致。
4. **检测报告**
   - 农残检测报告只能作为辅助，不等于有机认证。
5. **标签审核**
   - 有机产品最小销售包装上应有中国有机产品认证标志、有机码、认证机构名称等。

**判断要点：**
- 如果证书产品范围只写“香蕉”“苹果”等，没有“菠萝”，不能按有机卖。
- 如果证书是境外有机认证，如欧盟有机、USDA Organic，不等于自动符合中国有机销售要求；国内销售通常还要看中国有机认证或相关进口有机证明。
- 如果只有“绿色食品”“GAP”“无公害”等，不是有机认证。
- 如果供应商说“基地是有机的”“种植过程有机”，但没有证书，不能作为有机产品宣传和销售。

2. 拿到后到**全国认证认可信息公共服务平台**查证书编号是否有效。
3. 若对方无法提供，建议将该产品定位为“优质菠萝/常规高端水果”，不要标“有机”。
4. 如果高端渠道必须有机，建议同时找**有明确菠萝有机认证的产地供应商**做备选，要求先寄证书和样品批次资料。
