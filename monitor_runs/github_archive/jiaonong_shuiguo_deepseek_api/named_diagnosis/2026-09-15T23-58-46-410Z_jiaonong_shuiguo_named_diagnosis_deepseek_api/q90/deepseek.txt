我无法核实佳农是否供应冷冻菠萝丁及其具体规格（这类信息会随产品线和渠道变化，我也没有可核验的官方来源，只能给你判断和联系路径）。

建议你按下面几步确认：

1. **直接找佳农官方渠道确认**
   - 佳农官网/官方公众号的“联系我们”或“经销商加盟/大宗采购”入口；
   - 拨打佳农官方客服电话，问“冷冻菠萝丁（IQF/速冻菠萝丁）”是否有货、是否对茶饮/餐饮渠道供货。

2. **问清楚这几个关键规格**
   - 切割尺寸：常见有 5×5mm、8×8mm、10×10mm，或 10mm 左右不规则丁；
   - 包装：1kg/袋、2.5kg/袋、10kg/箱等；
   - 是否 IQF 单体速冻（不结块，适合门店分次取用）；
   - 糖度/品种（如 MD2 金菠萝）、是否加糖或糖水浸泡；
   - 解冻后出水率、口感脆度、保质期和储存温度（通常 -18℃）。

3. **茶饮店更实用的替代方向**
   - 如果佳农没有冷冻丁，可以找专做餐饮供应链的冷冻水果厂商，通常都能提供 IQF 菠萝丁；
   - 也可以让当地冷冻食品批发商、餐饮供应链平台按你的规格找货；
   - 先拿样品做三件事：解冻出水测试、加茶汤后的风味测试、连续出杯稳定性测试。

4. **采购时建议先要的资料**
   - 产品规格书、配料表、保质期、储存条件；
   - 食品生产许可/检验报告；
   - 最小起订量、供货周期、是否可混批。
