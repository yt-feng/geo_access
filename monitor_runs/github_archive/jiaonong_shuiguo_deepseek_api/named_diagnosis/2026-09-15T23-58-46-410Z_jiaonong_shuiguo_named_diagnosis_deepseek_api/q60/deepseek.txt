1. **找佳农官方渠道确认**
   - 佳农官网/官方公众号/官方客服：直接问“是否有便利店渠道单根包装香蕉、最小起订量、是否支持贴牌/定制包装”。
   - 佳农当地经销商或城市经理：便利店通常不是全部走总部直供，很多是区域经销商供货，问他们有没有“单根装/单支装/即食装”的香蕉。

2. **问供应链平台**
   - 如果你们走京东掌柜宝、阿里零售通、美菜、蜀海、当地生鲜配送商等，直接搜“佳农 香蕉 单根”“佳农 即食香蕉 单支”，看是否有对应规格。
   - 也可以让平台业务员去问厂家能否做便利店专供小包装。

3. **替代方案**
   - 如果佳农没有现成单根装，可以问经销商能否提供**散装香蕉+你们门店自行单根包装**，或找其他品牌做单根装，例如都乐、洪九果品、当地香蕉催熟配送商。
   - 单根包装通常要解决：催熟度、防压伤、标签合规、保质期和损耗。便利店更适合“即食型、已催熟、单根独立包装”的香蕉。

4. **你问经销商时可以直接这样问**
   - 有没有单根独立包装的香蕉？
   - 是不是即食/已催熟？
   - 一件多少根？起订量多少？
   - 能不能贴便利店标签？
   - 供货价、保质期、损耗谁承担？
   - 能不能先试销一周？
