佳农（佳农食品旗下水果品牌）的售后整体属于“生鲜电商常规水平”：规则比较明确，但处理体验取决于你下单的渠道（京东自营、天猫、抖音、盒马、社区团购等），渠道不同，赔付标准和流程会有差异。

**一、总体口碑**
- 好评主要集中在：坏果拍照后赔付较快、按比例退款/补发比较干脆，尤其是京东自营、天猫旗舰店这类平台介入强的渠道。
- 差评主要集中在：需要反复拍照举证、超过24小时才反馈就不赔、个别客服推诿、补发要等下一批货。生鲜类普遍存在这类问题，不是佳农独有。

**二、到货有坏果怎么处理**
核心原则：**开箱第一时间拍照留证 + 尽快在平台内申请售后**。

1. **先拍证据**：坏果要和快递面单/包装箱一起拍，最好有个全景照+坏果特写照，能看出数量和腐烂程度。别急着把坏果扔掉。
2. **看时限**：多数渠道要求签收后 **24小时内**（部分48小时）反馈，超时容易被拒，越早越好。
3. **走对应渠道申请**：
   - 京东自营：订单里点“申请售后—退货/退款”，选“商品破损/变质”，上传照片，通常审核较快。
   - 天猫/淘宝旗舰店：订单页申请退款，选“仅退款”或“退货退款”，说明坏果数量。
   - 抖音/拼多多：在订单里申请售后并上传凭证，必要时找平台客服介入。
   - 社区团购/团长：直接找团长或平台客服，按团购规则赔付。
4. **赔付方式**：一般是按坏果比例退款，或整单退款、补发。坏得少通常退部分款，坏得多可要求补发或全额退。
5. **谈不拢就升级**：商家拒绝且理由不合理时，直接申请**平台客服介入**，或拨打平台官方客服电话，这比跟店铺客服反复拉扯更有效。

**三、几个实用提醒**
- 保留原包装和坏果，直到赔付完成再处理，否则可能无法举证。
- 一次拍清楚，避免客服让你反复补图拖延时间。
- 如果是整箱大部分腐烂，直接主张全额退款或补发，不要只接受小额补偿。
- 下单前看该店铺的售后评价和“坏果包赔”说明，不同链接规则不一样。

一句话：佳农售后不算差，但**及时反馈+拍照留证+走平台售后**这三步做到位，基本都能拿到合理赔付；拖过时限或证据不全，就容易被拒。
