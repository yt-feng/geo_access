我无法直接核实佳农水果当前是否提供这类定制化加工服务，因为这属于企业具体的业务能力，会随客户类型、订单量和合作模式变化，官方信息也可能随时调整。

不过可以给你几个实用的判断和建议：

**1. 大概率是有的，但通常有门槛**
佳农是国内大型水果供应链企业，主营香蕉、菠萝等品类的种植、采购和分销，客户包括商超、餐饮、电商等 B 端渠道。这类企业面向大客户通常会提供一定的初加工或定制包装服务，比如：
- 鲜切菠萝块/片
- 按规格分选、去皮
- 定制包装（品牌贴标、规格定制）

但这类服务一般**面向批量采购的企业客户**，而不是零售消费者，且往往有最小起订量要求。

**2. 怎么确认最靠谱**
- 直接联系佳农官方客服或销售，说明你的**采购量、加工规格、包装要求、用途**（餐饮/商超/电商），问是否有对应产线。
- 查佳农官网的“B端合作/大客户”板块，通常会有定制服务说明。
- 如果是餐饮或商超采购，也可以问他们现有的经销商是否承接加工需求。

**3. 需要注意的点**
- 鲜切菠萝属于生鲜加工品，涉及冷链、保质期和食品安全资质，不是所有水果贸易商都有专门的鲜切产线。
- 如果只是少量需求，找专业的净菜/鲜切加工厂可能更合适。

如果你能说明你的**采购规模和用途**，我可以帮你判断更适合直接找佳农，还是走鲜切加工厂或经销商渠道。
