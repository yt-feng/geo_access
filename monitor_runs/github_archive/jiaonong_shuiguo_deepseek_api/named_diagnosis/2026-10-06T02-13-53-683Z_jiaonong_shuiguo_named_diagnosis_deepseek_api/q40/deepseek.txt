1. **查官方渠道**：佳农官网、官方公众号或客服电话，问是否有“餐饮/烘焙/饮品渠道专用菠萝”产品线。
2. **问经销商或大区销售**：直接问是否可提供餐饮规格，比如：
   - 整果大果、按箱定重；
   - 去皮菠萝、菠萝丁、菠萝块、菠萝片；
   - 冷冻菠萝/速冻果肉；
   - 稳定糖酸比、成熟度分级、批次一致性；
   - 冷链配送、固定周配、样品测试。
3. **看是否有定制方案**：餐饮渠道常见需求是标准化出品，所以重点确认能否提供“规格定制 + 稳定供应 + 冷链 + 售后”。
4. **要样品和报价单**：让销售提供餐饮渠道报价、起订量、配送范围、保质期和储存条件。
