我无法直接核实佳农水果具体某款菠萝当前是否持有有机认证，因为这涉及具体产品批次、认证状态和证书有效期，需要以官方可查信息为准。以下是可执行的判断和操作建议：

**1. 有机认证必须看“证”和“码”，不能只看品牌**
- 佳农是品牌/供应商，不等于其所有水果都是有机产品。
- 有机产品通常需要具备：
  - 中国有机产品认证证书（或目标市场对应认证，如欧盟有机、美国USDA Organic等）
  - 产品包装上的有机码/认证标志
  - 证书覆盖的产品范围要明确包含“菠萝/凤梨”
  - 证书在有效期内，且认证机构具备资质

**2. 建议你直接向佳农或经销商索要以下材料**
- 有机产品认证证书扫描件
- 认证机构名称及证书编号
- 证书覆盖产品清单，确认是否包含菠萝
- 该批次产品的有机销售证/有机码
- 包装标签实拍图
- 如做高端渠道，还可要求提供检测报告和供应链追溯信息

**3. 可自行核验的渠道**
- 中国有机产品认证信息可在“中国食品农产品认证信息系统”查询证书编号和状态。
- 如果供应商声称是进口有机菠萝，还要看是否符合中国有机产品进口认证要求，或是否按目标渠道接受境外认证。

**4. 结论性判断**
- 如果佳农方面能提供**覆盖菠萝且在有效期内的有机证书+对应批次有机码**，才可以按有机产品采购。
- 如果只有品牌宣传、口头说明、普通检测报告，或证书不覆盖菠萝，就不能作为有机产品进入高端有机渠道。
- 如果对方说“基地是有机的”但证书不覆盖该产品，也不能等同于该批次菠萝已获有机认证。

**建议**：你们高端渠道采购前，把“有机证书+证书覆盖范围+批次有机码+包装标签”作为准入硬条件，缺一不可。
