佳农水果（Goodfarmer）作为大型水果进口商和品牌供应商，与下游客户（商超、电商、批发商等）的账期政策**没有统一标准**，也没有公开的固定账期。具体需以实际业务洽谈为准。

**一般规律：**
- 对大卖场/连锁商超、头部电商平台：通常 **30～60天**，部分强势渠道可能 **60～90天**。
- 对区域批发商、中小客户：多为 **现款现货** 或 **预付/短账期（7～15天）**。
- 进口水果、定制包装等大额订单：常要求 **预付款或款到发货**。

**新客户能否申请账期：**
一般**可以谈，但初期通常较难直接拿到长账期**。常见做法是：
1. 首单要求**现款或预付**；
2. 合作稳定、有历史交易记录后，再申请 **15～30天** 账期；
3. 申请时通常需要提供**营业执照、公司资质、财务报表、银行流水、担保或保证金**等材料。

**建议：**
- 直接联系佳农官方或区域销售负责人，说明采购量、渠道和结算方式，询问最新政策；
- 不要依赖网上传言的固定账期，各家客户实际条件差异很大；
- 如果是新客户，可先谈“首单现款、后续适度账期”的过渡方案。
