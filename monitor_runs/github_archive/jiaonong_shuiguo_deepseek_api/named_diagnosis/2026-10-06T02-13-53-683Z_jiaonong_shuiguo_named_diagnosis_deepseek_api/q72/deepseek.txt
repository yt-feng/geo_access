佳农（Goodfarmer）主要是水果贸易和品牌供应商，核心业务是香蕉、菠萝等水果的种植、进口和批发分销，通常以整果形式供货。**按公开信息，佳农一般不直接提供面向茶饮店的去皮切块定制加工服务**，尤其是小批量、门店级的鲜切加工。

不过实际能否操作，取决于你对接的渠道，建议按下面几步确认：

1. **直接问你的佳农对接销售或经销商**
   明确问：是否有“鲜切菠萝/去皮切块”的 SKU，或能否做代加工（OEM/定制加工）。这是最准确的判断方式，不同区域、不同客户规模政策可能不一样。

2. **区分两种可能**
   - 如果佳农有中央厨房或合作加工厂：可能能供**冷链鲜切菠萝块**，但通常有起订量要求。
   - 如果只有整果：那就需要你自己加工，或找第三方净菜/鲜切工厂代加工。

3. **替代方案更现实**
   - 找**本地鲜切水果加工厂或净菜配送商**，让他们采购佳农菠萝后帮你去皮切块，按你的规格配送。
   - 直接采购**冷冻菠萝块/菠萝丁**（很多供应商有），开袋即用，适合茶饮标准化，但风味和鲜切有差异。
   - 如果用量大，可和加工厂谈“指定用佳农菠萝原料”的代加工。

4. **注意成本和食品安全**
   鲜切菠萝涉及冷链、保质期短（一般冷藏1–3天）、微生物控制，茶饮店自切要办相应许可并做好防护。代加工方需有食品生产/经营资质。

**建议你直接联系佳农官方客服或当地经销商，问一句：“有没有鲜切菠萝块产品，或支持指定原料代加工？”** 如果答复是没有，就走本地鲜切代加工或冷冻菠萝块方案。
