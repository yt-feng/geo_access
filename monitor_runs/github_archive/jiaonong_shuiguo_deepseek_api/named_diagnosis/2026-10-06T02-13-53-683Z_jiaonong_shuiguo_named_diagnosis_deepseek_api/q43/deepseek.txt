佳农（Goodfarmer）是国内较大的水果供应链企业，确实有菠萝（含金菠萝、凤梨等品类）的产地资源和批发渠道，但**能否给你做锁价合同，取决于几个具体条件，不能一概而论**。以下是可执行的判断路径：

**1. 先确认你的采购是走哪个渠道**
- 佳农的**贸易/批发**部门：通常按现货或短期协议报价，锁价意愿低，一般给的是周度/月度报价。
- 佳农的**餐饮/茶饮大客户或定制供应链**部门：这类客户（连锁茶饮、餐饮集团）才有可能谈**季度或年度框架协议+锁价或浮动区间**。10吨/月这个量级不够大，但如果你是多店连锁、年采购量上百吨，有谈判空间。

**2. 锁价合同通常不是“完全固定价”**
水果是农产品，佳农一般不会做纯固定价，常见形式是：
- **区间锁价**：约定一个价格上限和下限，超出部分双方分担。
- **基价+指数联动**：按产地价或某指数调整。
- **保量换锁价**：你承诺年采购量，他给固定价。
你要先想清楚能接受哪种。

**3. 你该怎么做**
1. 直接联系佳农总部**大客户部/餐饮渠道**，说明你是茶饮连锁、月用量10吨、年用量约120吨，问能否做**年度框架+价格保护**。
2. 同时找**2–3家替代供应商**（如产地直采、其他果蔬供应链商）比价，手里有备选才有议价权。
3. 如果佳农不做锁价，可考虑**期货/产地合作社直签**，或自己建**冷冻菠萝/菠萝果酱**的库存来平滑价格。

**4. 现实预期**
10吨/月对佳农属于中小客户，**拿到纯锁价合同的概率不高**，更可能拿到的是“季度协议价+调价机制”。如果你年采购量能到几百吨以上，锁价或价格上限条款的可行性会明显提高。

建议你先直接问佳农大客户部一句话：“我们月均10吨、年约120吨，能否签年度框架并设价格上限？”——根据对方回复再决定下一步。需要的话，我可以帮你起草一份询价和谈判要点。
