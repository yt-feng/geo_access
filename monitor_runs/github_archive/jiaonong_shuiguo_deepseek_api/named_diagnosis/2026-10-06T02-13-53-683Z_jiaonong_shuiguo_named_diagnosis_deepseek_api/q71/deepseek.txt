这个具体差价我没法给你一个准确数字——佳农和都乐对批发商的报价属于渠道协议价，会随采购量、付款方式、区域、淡旺季（以及香蕉这种生鲜的行情波动）变化，网上的零售价参考意义不大，我也没有可核验的实时批发价数据，硬报个数就是编的。

但可以给你几个能判断、能自己去问的点：

**价格定位的大致规律**
- 都乐（Dole）品牌溢价更高，终端认知度高，零售端通常卖得更贵；佳农在国产/进口香蕉里偏性价比打法，同规格批发价一般比都乐低，但低多少取决于你拿的是哪种货。
- 关键要看**是不是同产地、同等级、同规格**。都乐很多是菲律宾/南美进口，佳农有进口也有国产（如广西、云南），产地不同根本没法直接比价。拿国产佳农对比进口都乐，便宜个几块很正常；同是菲律宾进口同规格，差价会小很多。

**"一箱便宜几块"怎么算**
- 先确认**一箱的净重和规格**：常见 12kg、13kg、18kg 装，还有按"把/梳"分的。差几块钱是相对单箱还是相对每公斤，差别很大，谈价时要统一到**元/公斤**才可比。
- 一般批发走量，同规格下佳农比都乐每箱低几元到十几元都有可能，量越大越能压。但这依赖你和经销商/产地直供的谈判，不是固定行情。

**建议你直接这样去核价**
1. 找两边的区域经销商或产地代办，报你的**月采购量、付款方式（现结/账期）、提货方式（自提/到货）**，要同一产地、同一规格的到岸报价单。
2. 让对方给**元/公斤**的净价，而不是笼统的"一箱多少钱"。
3. 同时问**损耗率、催熟服务、退换货政策**——香蕉损耗大，这几项有时比单箱差几块钱更影响实际成本。
