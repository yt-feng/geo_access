**1. 先区分你属于哪类客户**
- **大宗/批发客户（商超、餐饮、茶饮、食品厂等）**：佳农作为水果供应链企业，通常更可能针对这类客户提供分级、规格筛选、贴牌包装等服务，切块等深加工也可能通过其供应链或合作工厂实现。

**2. 直接核实的最快方式**
- 打佳农官方客服电话，问清楚：是否支持菠萝切块、切丁、去芯、真空包装、贴牌等，以及最小起订量（MOQ）。

- 是否需要SC/食品生产资质、检验报告、冷链条件。
- 最小起订量和交货周期。
