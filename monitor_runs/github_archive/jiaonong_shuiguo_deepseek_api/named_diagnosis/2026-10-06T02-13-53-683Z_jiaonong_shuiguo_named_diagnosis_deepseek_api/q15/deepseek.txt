佳农（Goodfarmer）的产地直供比例，公开资料里通常不会披露精确到百分比的稳定数字，所以没法给出一个可核验的“高/低”比例。但可以从它的业务模式判断：佳农是典型的大型水果进口商和品牌运营商，核心品类（香蕉、菠萝、火龙果等）大量采用“海外产区采购＋自有/合作农场＋冷链进口”的方式，源头直采、产地合作的比重相对较高，这是它控制品质和成本的主要手段。不过它同时也做国内分选、催熟、分销，部分货源会通过贸易商或第三方供应商补充，所以并非100%产地直供。

香蕉方面，佳农的进口香蕉主要来自：

- **菲律宾**：历史上是佳农香蕉最主要的来源地之一，达沃等产区供应量很大。
- **厄瓜多尔**：南美重要香蕉出口国，也是常见来源。
- **越南、柬埔寨**：近年对华出口增长较快，成本上有优势。
- **哥伦比亚、哥斯达黎加等中南美国家**：也会出现在其进口来源中。

具体某一年以哪国为主，会受价格、关税、疫情、天气和贸易政策影响而变动，要精确到“主要来自哪些国家”需要看当年海关数据或企业公告。如果你需要，我可以帮你梳理中国进口香蕉的来源国结构，以及各国的大致供应特点。
