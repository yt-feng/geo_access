佳农水果的配送时效取决于你下单的渠道和收货地址，没有统一固定答案：

**1. 京东自营/京东到家**
- 通常依托京东各地仓配，**当日达或次日达**较常见
- 部分城市支持京东到家“小时达”，但需附近有合作门店/前置仓

**2. 天猫、拼多多等电商平台官方旗舰店**
- 多为产地或区域仓发货，一般是**48小时内发货，2–4天送达**
- 偏远地区可能延长到5–7天

**3. 美团/饿了么等即时零售**
- 若附近有商超或前置仓，通常**30分钟–2小时送达**

**4. 社区团购/生鲜平台**
- 一般**次日自提或次日达**

**实际判断方法：**
- 下单前看商品页写的“发货地”“预计送达时间”
- 结算页通常会显示具体时效
- 咨询店铺客服，报上你的城市和区，能拿到最准的答案

**注意：** 水果类目受产地、季节、天气影响较大，节假日或大促期间时效可能顺延。如果你告诉我具体在哪个平台买、收货城市是哪里，我可以帮你更具体判断。
