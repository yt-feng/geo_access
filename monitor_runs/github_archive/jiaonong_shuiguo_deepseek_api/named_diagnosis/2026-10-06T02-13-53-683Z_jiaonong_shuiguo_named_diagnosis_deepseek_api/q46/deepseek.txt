香蕉催熟这件事，先分两个层面看：**佳农自己做还是外包**，以及**便利店“到店即熟”该怎么操作**。

## 1. 佳农的催熟是自营还是外包？

这个没有公开的统一答案，而且**很可能因区域、渠道、品类而不同**：

- 佳农作为国内头部香蕉进口商/品牌商，在主要销地（如上海、北京、广州等）通常有自己的**催熟加工中心**，走“港口→自有/合作催熟库→配送”的模式。
- 但在部分区域或中小渠道，也可能采用**委托第三方催熟服务商**或**区域经销商自行催熟**的方式。
- 对外零售渠道（比如给便利店供货），往往是通过**经销商或供应链服务商**来交付，催熟环节可能在这些合作伙伴手里完成。

所以，**不能一概而论说佳农全国统一自营或全国外包**。要确认你所在区域的具体情况，最直接的办法是问对接你的佳农业务员或经销商：

> “我们这批货是在你们哪个催熟库做的？是你们自营还是委托第三方？催熟到什么色号/硬度出库？”

## 2. 便利店要“到店即熟”，关键不在谁催熟，而在交付标准

“到店即熟”本质是一个**成熟度交付标准**问题，不管谁催熟，你都要把标准写清楚：

- **色号**：香蕉常用1–7号色卡。到店即熟一般要**5号色左右**（黄、基本无绿），如果要当天卖，5–6号更合适。
- **硬度/手感**：微软、无硬芯，但不过软出水。
- **到店时间**：从出催熟库到门店最好控制在**24–48小时内**，否则运输中会继续后熟，到店就过熟了。
- **配送温度**：香蕉怕冷，**不能低于13℃**，否则会冻伤发黑；也不能高温闷着。
- **批次一致性**：同一批货色号要齐，不能有的绿有的已经起黑点。

## 3. 给便利店的实操建议

1. **直接向供应商提“到店成熟度标准”**：要求按5号色、可即食交付，写进订单或合同。
2. **问清楚催熟责任方**：是佳农自营库、第三方催熟商，还是区域经销商。责任方不同，售后和调货速度不一样。
3. **小批量试单**：先订1–2箱，记录到店色号、当天售卖情况、第二天变化，再决定稳定订货量。
4. **门店存放**：到店后**常温、通风、避光**，不要放冷柜；当天卖不完的，第二天会更熟，适合做特价或加工（奶昔、果切）。
5. **如果佳农本地没有即熟交付能力**，可以找**本地专业香蕉催熟服务商**，让他们按你的色号标准加工后配送到店，这对便利店往往更灵活。

## 结论

佳农是否自营催熟，**要按你所在区域和对接渠道去确认**，不能直接下结论。但对便利店来说，更有效的做法是：**不管谁催熟，都把“到店即熟”的色号、硬度、配送时间和温度写成明确标准**，并要求供应商按标准交付。这样你才能稳定拿到“到店即熟”的香蕉。
