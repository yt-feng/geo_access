佳农（Goodfarmer）作为国内头部水果进口商和品牌商，公开渠道**没有统一披露**一个官方的“到货损耗率”标准数字。水果损耗率因品类、运输方式、季节、到货口岸和仓储条件差异极大，不同品项之间没有可比性。

可以给你一些行业内可参考的判断区间（非佳农官方数据）：

- **耐储品类**（如苹果、梨、橙、猕猴桃等）：到货损耗一般可控制在 **3%~5%** 左右，管理好的能压到 2%~3%。
- **中等易损品类**（如葡萄、柑橘类部分品种、火龙果等）：常见 **5%~8%**。
- **高易损品类**（如香蕉、牛油果、车厘子、蓝莓、芒果、水蜜桃等）：**8%~15%** 都算正常，冷链断链或压货严重时可能超过 15%。

如果是要做采购或考核参考，建议不要直接套用“佳农标准”，而是：

1. **按单品分别设阈值**，不要用统一损耗率。
2. 在合同或验收标准里明确：**到货损耗 = 不合格数量 / 到货总数量**，并写清判定口径（烂果、压伤、失水、规格不符是否计入）。
3. 参考自己历史到货数据，取 3~6 个月的均值再上浮 1~2 个百分点作为控标线。
