佳农香蕉的保质期和储存条件，通常可以参考以下通用标准（不同批次、季节、包装方式会有差异，最终以包装标注为准）：

**保质期**
- 常温下一般 **3～7 天**，具体取决于成熟度：越黄越熟，越快坏。
- 冷藏（已成熟）约 **5～10 天**，但表皮会变黑。
- 冷冻（去皮后）可存 **1～3 个月**，适合做奶昔、烘焙。

**储存条件**
1. **未熟（偏绿、硬）**：室温阴凉处（约 18～22℃），避免阳光直射，不要放冰箱，否则会停止成熟、表皮发黑。
2. **已熟（黄、有香味）**：
   - 尽快吃，或放冰箱冷藏延缓果肉变质（皮黑不影响果肉）。
   - 想再放久一点，可去皮切段冷冻。
3. **不要和苹果、梨、番茄等放一起**：它们释放乙烯，会加速香蕉成熟腐烂。
4. **悬挂存放**：减少受压，避免表皮快速变黑。
5. **不要密封在塑料袋里**：容易闷出水和霉，可用纸袋或透气容器。

**判断是否还能吃**
- 可吃：表皮有黑点、但果肉正常、无异味。
- 不建议吃：果肉发软流水、酸味/酒味明显、有霉斑。
