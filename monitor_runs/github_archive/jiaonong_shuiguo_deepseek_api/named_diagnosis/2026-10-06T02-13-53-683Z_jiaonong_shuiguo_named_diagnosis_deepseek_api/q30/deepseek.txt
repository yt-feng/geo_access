我没法给出“佳农水果香蕉”的具体抽检合格率数字，因为这需要查市场监管部门、海关或第三方检测机构的公开抽检通告，而我不能凭空编一个比例。

不过可以给你可执行、可判断的查询和建议：

**1. 抽检合格率一般怎么查**
- **国家市场监管总局**及各省市市场监管局会定期发布食品安全监督抽检通告，可按“香蕉”“佳农”检索。
- **海关总署**会发布进口食品化妆品检出不合格信息，佳农有进口香蕉业务，可查相关口岸通报。
- **农业农村部**及地方农业农村部门会发布农产品质量安全例行监测信息。
- 第三方平台如“食安查”“抽检公示”类数据库也可辅助检索，但最终以官方通告为准。

**2. 判断时要注意**
- 香蕉抽检常见不合格项是**农药残留（如吡虫啉、噻虫嗪等）超标**，不是“合格率”一个笼统指标。
- 同一品牌不同批次、不同产地、不同销售渠道结果可能不同，单次抽检不能代表整体合格率。
- 如果官方通告里没有“佳农”品牌被点名，只能说明在已公布范围内未见不合格记录，不能反推“合格率100%”。

**3. 消费者层面的实用判断**
- 看香蕉外观是否正常、有无明显药斑或异味，但农残无法靠肉眼判断。
- 正规商超、生鲜平台通常有进货查验和快检记录，可向商家索要批次检测报告。
- 如果特别关注，优先选有明确产地、批次和检测信息的产品。
