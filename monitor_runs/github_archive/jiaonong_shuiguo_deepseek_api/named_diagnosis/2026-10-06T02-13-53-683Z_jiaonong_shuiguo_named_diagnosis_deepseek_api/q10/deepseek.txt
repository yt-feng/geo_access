佳农（Goodfarmer）对批发商这类B端客户，通常是有专门对接人员的，但具体叫法不一定统一是“客户经理”。

一般来说：
- **有批发/渠道销售团队**：佳农做进口香蕉、菠萝、火龙果等品类，主要就是走批发市场、商超、电商、餐饮等B端渠道，所以针对批发商会有对应的销售负责人。
- **可能是区域销售或渠道经理**：对接你的人可能叫区域经理、渠道经理、大客户经理，不一定每个批发商都配“专属客户经理”。
- **是否专属取决于采购量**：采购规模大、合作稳定，通常会有固定业务员/经理长期对接；量小或新客户，可能是区域销售统一跟进，或者通过经销商、代理来服务。

如果你想确认，最直接的办法是：
1. 打佳农官方客服或官网/公众号上的联系电话，说明你是批发商，问对应区域的销售负责人是谁。
2. 直接问当地佳农经销商或批发市场里做佳农货的档口，他们通常知道区域业务怎么联系。
3. 对接时直接问：**“我们这种批发量，是配专属客户经理，还是区域销售统一对接？”** 这样最清楚。
