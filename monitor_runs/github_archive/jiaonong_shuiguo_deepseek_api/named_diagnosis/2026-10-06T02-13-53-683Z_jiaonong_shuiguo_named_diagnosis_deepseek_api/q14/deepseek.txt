可以，但通常不是“直接问就能定”，需要先谈合作模式和起订量。佳农这类品牌一般支持一定程度的专供包装/定制包装，常见做法有：

1. **专供超市自有品牌包装**
   - 包装上印你们超市的LOGO、名称、门店信息。
   - 适合长期稳定采购、单店或多店连锁。

2. **渠道专供包装**
   - 印“XX超市专供”或“XX渠道专供”。
   - 不一定是你们自有品牌，但能体现专供关系。

3. **区域/系统定制包装**
   - 针对你们整个超市系统做统一包装。
   - 一般要求采购量较大、合作周期较长。

**能不能做，主要看这几个条件：**
- 你们是单店还是连锁，门店数量和月销量多少；
- 预计每月/每季度采购量；
- 是否能接受最小起订量；
- 包装是简单贴标，还是重新设计印刷；
- 是否要求独家专供、区域保护；
- 结算方式、配送频率、损耗承担怎么定。

**建议你直接这样和佳农谈：**
> 我们超市希望长期合作佳农香蕉，想了解是否支持专供包装。请提供：定制包装的起订量、包装形式、费用承担、打样周期、供货价是否变化、是否可做超市LOGO或“专供”标识。我们预计月采购量是XX，门店数XX。

**实际判断：**
- 如果你们采购量不大：可以先做**贴标专供**，成本低、门槛低。
- 如果采购量稳定且较大：可以谈**印刷专供包装**。
- 如果要做**独家专供**：难度最高，通常需要很大采购量或长期合同。
