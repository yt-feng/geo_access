我没有佳农官方披露的“产地直供比例”数据，无法给一个准确百分比。这个比例按品类、季节、基地类型差异很大，而且属于企业内部供应链信息，公开渠道通常查不到。直接报一个数字会误导你。

不过，你要的核心目标是**减少中间环节、降低成本**，这个可以给可执行的做法：

**1. 先向佳农或其区域经销商书面索取供应链信息**
- 问清：该单品是“自有基地/合作基地直发”，还是“产区采购后经中央仓/区域仓中转”。
- 要求明确：从产地到你们仓库的**物流节点数**、每段承运方、是否经过批发市场。
- 只有拿到这个，才能算出真实直供比例。

**2. 关键不是“直供比例”，而是“链路层级”**
水果成本里中间环节通常在这几处：
- 产地经纪人/代办
- 产区集货商
- 产地批发市场
- 销地批发市场
- 区域分仓二次分拣

每多一层，加价大致在 5%–15%，损耗和周转也会上去。你要压缩的是这些层，而不是单纯追求一个比例数字。

**3. 可落地的降本路径**
- **单品直采试点**：挑1–2个耐储、需求稳定的单品（如苹果、橙类），直接找产区合作社或佳农基地签直发，跳过销地批发。
- **产地直发到仓**：约定“产地装车—到你们仓”一站式，减少中途换装。
- **包销/锁量锁价**：旺季前锁量，换取产地直供价和优先发货。
- **规格标准化前置**：把分拣、分级放到产地做，避免到销地再分拣加价。
- **物流拼车/整车**：整车直发比零担经批发市场通常省 8%–20%，量小时可多品拼车。

**4. 判断佳农是否真直供的验证方法**
- 看合同主体：是佳农产地公司、区域子公司，还是第三方贸易商。
- 看发票和物流单据：起运地是否为产区，是否经非必要中转仓。
- 实地或视频看基地/产地仓。
- 要求提供批次追溯编码。

**建议动作：** 先选一个你们采购量最大的单品，按上面问清单链路层级，算出当前各环节加价，再和佳农谈“产地仓直发你们中心仓”的方案。这样比纠结一个笼统的直供比例更能直接降本。
