佳农水果的苹果品类通常以**进口苹果**为主，常见会涉及：

- **嘎啦果 / 嘎啦苹果**
- **红富士苹果**
- **皇后苹果**
- **爱妃苹果**
- **爵士苹果**
- **青苹果（如澳洲青苹等）**
- **蛇果 / 花牛类（部分渠道）**

不过具体在售品类会随季节、批次和渠道变化，建议以佳农官方渠道或你对接的销售当日报价单为准。

关于你提到的两个品类：

1. **进口嘎啦**
   - 常见产地：**新西兰、智利、美国、南非**等。
   - 其中新西兰嘎啦在国内进口渠道较常见。

2. **进口红富士**
   - 常见产地：**新西兰、美国、智利、日本**等。
   - 但需要注意，红富士本身起源日本，进口红富士常见也有**新西兰、美国**等产区；日本产红富士在部分高端渠道会有，但价格通常较高。

如果你是要采购，建议直接向佳农确认这几点：
- 当季可供的是哪个产地；
- 规格：果径、单果重、箱规；
- 包装：原箱、贴标、品牌授权；
- 到货港和交货周期；
- 是否支持长期稳定供应。
