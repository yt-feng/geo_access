目前没有可直接核验的“3kg装香蕉”这一佳农官方规格信息，我不能凭印象给你确认。建议你按下面方式快速判断和落地：

1. **先确认佳农是否有小包装**
   - 直接问佳农当地经销商/业务员：有没有面向便利店的小规格，比如：
     - 香蕉：1kg、1.5kg、2kg、3kg
     - 苹果/橙子等：2粒、4粒、6粒、1kg、1.5kg
   - 要求对方发**最新产品规格表/报价单**，以表格为准，不要只听口头说“有”。

2. **便利店小面积选品建议**
   - 优先选：**小袋装、小盒装、可挂条装、可堆头小箱**
   - 香蕉这类易损水果，通常更适合：
     - 1kg–2kg小袋
     - 3–5根装
     - 按“把”卖，而不是整箱3kg直接上架
   - 如果只有3kg箱，也可以门店拆分成小把/小袋售卖，但要注意：
     - 是否有拆零许可和标签
     - 损耗和催熟管理
     - 称重收银是否方便

3. **如果没有小包装，怎么谈**
   - 问经销商能否提供：
     - 小规格专供便利店渠道
     - 拆箱混搭供货
     - 少量多频配送
     - 试销政策、损耗补贴、陈列支持
   - 先小批量试销，比如先订1–2箱，观察3–7天动销和损耗。

4. **更稳妥的替代方案**
   - 如果佳农小包装不合适，可同时看：
     - 都乐、新奇士等有便利店小规格的品牌
     - 本地批发市场的小袋分装货源
     - 区域水果供应链的便利店专供装

**结论：**“3kg装香蕉”不能直接确认是佳农现有规格。你最该做的是找佳农当地经销商要**最新规格表**，并明确问“有没有1kg/2kg/3kg小包装或便利店专供装”。如果有，优先上1kg–2kg；如果只有3kg，建议拆零卖，不要整箱陈列。
