我无法直接核验佳农官方是否提供餐饮渠道专用的菠萝切片/切块定制规格。建议你通过下面几种方式确认，通常能很快得到准确答复：

1. **打佳农官方客服电话**  
   直接问：是否有餐饮/烘焙/饮品渠道专用的菠萝产品，如切片、切块、碎粒、果泥等，以及最小起订量、包装规格、是否冷冻/冷藏。

2. **联系当地经销商或城市经理**  
   餐饮渠道很多是经销商在做，经销商往往比总部客服更清楚本地能不能供、起订量多少、是否支持定制。

3. **在佳农官网/公众号/小程序查产品中心**  
   重点看是否有“餐饮专供”“烘焙原料”“饮品原料”“冷冻水果”“鲜切水果”等分类。

4. **问具体规格参数**  
   确认时最好直接问：
   - 切片厚度/直径
   - 切块大小
   - 是否去芯
   - 冷冻还是冷藏
   - 每袋/每箱净重
   - 保质期和储存条件
   - 最小起订量和配送范围

5. **替代判断**  
   如果佳农没有公开的餐饮定制规格，常见情况是：  
   - 鲜果渠道以整果为主；  
   - 冷冻水果或果切类更可能做餐饮规格；  
   - 真正定制往往需要达到一定采购量。

如果你告诉我你所在的**城市、需要的规格（切片/切块/大小）、用途（饮品/烘焙/沙拉/炒菜）和预计月用量**，我可以帮你整理一份直接发给佳农客服或经销商的询价话术。
