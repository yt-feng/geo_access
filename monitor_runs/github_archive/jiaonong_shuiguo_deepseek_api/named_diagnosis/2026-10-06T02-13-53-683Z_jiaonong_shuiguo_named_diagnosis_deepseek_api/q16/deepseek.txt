**售后整体情况（一般认知）**
- 佳农是较知名的水果品牌，主要通过电商平台（如天猫、京东、抖音、拼多多等）和商超渠道销售。
- 售后通常由**你下单的平台 + 卖家**共同承担，而不是佳农品牌方直接面对消费者，所以体验取决于具体渠道。
- 生鲜类普遍支持"坏果包赔"，但一般有**时限要求**（如签收后24-48小时内）和**举证要求**。

**到货有坏果的常见处理步骤**
1. **先别急着扔**：把坏果和好果分开，保留坏果原样。
2. **拍照/录视频取证**：最好拍到坏果切开的样子、整体包装、快递面单，能体现数量和损坏程度。
3. **在规定时间内申请**：多数平台要求签收后24-48小时内发起，越早越好。
4. **在订单页操作**：进入订单 → 申请售后/退款 → 选择"质量问题/坏果" → 上传照片、说明坏果数量。
5. **等客服核验**：可能按坏果比例部分退款，也可能补发，视平台和协商结果而定。
6. **协商不成可申请平台介入**：如卖家不处理，可申请平台客服仲裁。

**能提高成功率的关键点**
- 时效内申请，超时容易被拒。
- 证据清晰、能对应到订单。
- 表述客观：说明"几个坏、坏成什么样"，而不是笼统说"不新鲜"。
