佳农（Goodfarmer）的物流模式不是“三通一达”那类快递，而是**自有冷链物流 + 第三方冷链/普货物流结合**的混合模式。具体可以从几个层面看：

**1. 物流模式**
- 佳农做的是生鲜水果供应链，核心品类如香蕉、菠萝、火龙果、车厘子、蓝莓等，对温控和时效要求高，**主要依靠自有或长期合作的冷链车队、冷链仓储**，而不是三通一达。
- 三通一达主要覆盖电商小件、常温快递，佳农的整柜、托盘、批发市场配送等场景并不匹配。
- 但在部分电商零售、社区团购、商超补货的末端环节，可能会用到第三方快递或城配公司做“最后一公里”。

**2. 冷链覆盖率**
- 佳农对外没有公开披露精确的“冷链覆盖率”百分比，所以无法给出一个可核验的确切数字。
- 从业务结构推断：**从产地预冷、港口冷库、干线冷链到销地冷库，核心环节基本是冷链覆盖的**；尤其是进口水果和高端品类，断链风险高，必须全程温控。
- 到了批发市场分销、部分二级经销商、末端零售环节，**冷链覆盖率会下降**，因为国内水果流通链条长，最后一公里和终端陈列环节常有常温暴露。

**3. 判断建议**
- 如果你是做采购或合作评估，不要只看“有没有自有车队”，而要看：**产地预冷能力、冷库节点、干线温控记录、销地配送时效、断链赔付条款**。
- 直接向佳农索要：冷链运输温度记录、第三方审计报告、各品类履约时效数据，这比问“覆盖率”更有意义。

**结论**：佳农不是三通一达模式，而是以自有/合作冷链为主、第三方为辅；冷链在核心链路覆盖较好，但全链路到终端并非100%冷链，且官方未公开具体覆盖率数字。
