**关于损耗率**

- 5% 是行业内常被引用的香蕉到货损耗参考值，但实际损耗受运输方式（常温/冷链）、运输距离、季节、成熟度（青蕉到货 vs 催熟后到货）、装卸次数影响很大，不同品类和渠道差异明显，很难用一个统一数字对比。
- 佳农是国内香蕉进口/分销规模较大的企业之一，通常会在冷链和青蕉处理环节做控制，但具体能压到多少（比如是否显著低于 5%），需要看它的官方资料或合同约定，公开信息里一般查不到权威数字。
- 如果你是想做商务判断，建议直接向佳农的业务/销售索要：近期的到货合格率、损耗率区间、以及在合同里如何界定"损耗"和"责任分界点"（离港、到港、到仓还是到店）。

**关于赔付条款**

- 香蕉属于生鲜，多数供应商合同里对损耗的处理方式是：约定一个合理的免赔/自担比例，超出部分按重量或金额折价、补货或赔付；也有的按"到货验收标准"（如青度、条重、机械伤比例）来判定责任。
- 具体有没有赔付、赔付比例多少、是按吨还是按比例、是否只补货不赔现金，各家公司合同条款不同，必须以合同原文为准。这类条款通常不会公开，属于一对一的商务约定。

**建议你这样做**

1. 直接问佳农要书面的"到货验收标准 + 损耗责任划分 + 赔付方式"，不要只信口头承诺。
2. 在合同里写明：损耗定义、责任分界点（哪个环节起算）、免赔比例、超标后的处理方式（折价/补货/退款）和时限。
3. 如果有历史合作数据，用自己的到货记录核算实际损耗，比引用行业平均值更可靠。
