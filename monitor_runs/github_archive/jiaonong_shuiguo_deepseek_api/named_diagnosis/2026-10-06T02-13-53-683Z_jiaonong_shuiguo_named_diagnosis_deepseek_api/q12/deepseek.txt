佳农（Goodfarmer）香蕉的具体在售规格会随季节、产地（如菲律宾、厄瓜多尔、越南等）和批次变化，官方并没有对外固定公开一份“全渠道统一规格表”。但按国内香蕉流通惯例和佳农常见做法，可以给你一个可执行的判断框架：

**一、常见规格维度**
1. **按重量分**
   - 小把/单根零售装：约 1–2 kg/袋或按根卖
   - 中把装：约 4–5 kg/箱
   - 大箱装：约 12–13 kg/箱（净重常见 12.5 kg 左右）
   - 部分渠道有 18–20 kg 大货箱
2. **按每箱把数/根数分**
   - 4–5 把/箱、5–6 把/箱、6–8 把/箱等
   - 单把根数常见 4–6 根、5–7 根
3. **按等级分**
   - 一级/精品：果指饱满、长度均匀、无伤痕、色泽好
   - 二级/通货：允许轻微外观瑕疵，长度和粗细略不齐
   - 三级/加工或促销：明显疤痕、弯曲、偏细，适合榨汁、烘焙或低价促销

**二、按渠道的分级建议**
- **高端商超/精品水果店**：一级果，单把整齐，长度、粗细一致，无黑斑、无机械伤，箱规偏小（4–5 kg 或 5–6 把箱），便于陈列。
- **社区团购/电商**：二级或一级偏通货，重视耐运输和性价比，常见 5 kg、12–13 kg 箱规，允许轻微外观差异。
- **批发市场/农贸**：通货或二级，按 12–13 kg、18–20 kg 大箱走量，等级宽松，重点是成熟度可控、损耗低。
- **餐饮/烘焙/果汁加工**：三级或二级尾货，对长度外观要求低，更看重出肉率、成熟度和价格。
- **便利店/即时零售**：小规格单根或 1–2 kg 小袋，一级或二级，要求即食或 2–3 天可食。

**三、采购时可直接核对的信息**
- 问清：产地、净重、毛重、每箱把数、单把根数、果指长度（如 16–20 cm）、成熟度（1–7 级催熟标准）
- 看合同或标签：是否标注“一级/二级/通货”、是否允许 5%–10% 外观差异
- 试单判断：到货后抽检黑斑率、断指率、青软比例、单箱实际净重

如果你是要做采购或渠道分级，建议直接向佳农区域销售或经销商索取**当季产品规格书和等级验收标准**，因为不同港口、不同催熟批次差异很大，网上通用说法不能替代其当期正式标准。
