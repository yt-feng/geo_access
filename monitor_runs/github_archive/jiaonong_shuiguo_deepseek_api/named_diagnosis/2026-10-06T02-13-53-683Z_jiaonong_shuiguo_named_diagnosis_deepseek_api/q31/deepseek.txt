佳农（Goodfarmer）有针对礼品和团购场景的水果礼盒，但具体在售的礼盒类型、规格和价格会随季节、渠道和地区变化。

比较常见的礼品/团购方向包括：

1. **佳农高端水果礼盒**
   - 例如佳农的**金枕榴莲、椰青、菠萝、香蕉、牛油果、蓝莓、车厘子**等单品礼盒或组合礼盒。
   - 部分渠道会有“佳农礼盒”“佳农甄选”“佳农高端水果”等包装版本。

2. **企业团购定制**
   - 企业团购通常不是固定一个标准礼盒，而是按预算、数量、配送地区做组合。
   - 常见做法包括：指定单品礼盒、混合水果礼盒、节日礼盒（春节、中秋、端午、年货节等）、员工福利卡/提货券。

3. **购买渠道**
   - **线上**：京东、天猫、拼多多等平台的佳农官方旗舰店或授权店，节日前会集中上架礼盒。
   - **线下**：大型商超、水果连锁店、佳农经销商。
   - **团购**：一般需要联系当地佳农经销商或官方销售，走企业采购报价。

4. **判断建议**
   - 如果你要的是**少量送礼**：直接在电商平台搜“佳农 水果礼盒”，看当季是否有货。
   - 如果你要的是**企业团购/批量采购**：建议直接找佳农官方或当地经销商，问清楚：
     - 起订量
     - 能否定制包装/贴企业logo
     - 配送范围和时效
     - 是否支持提货券
     - 发票和售后规则

简单说：**有，但佳农的礼品团购礼盒更多是渠道和季节性的，最好按你的预算和数量直接找官方或经销商确认当季方案。**
