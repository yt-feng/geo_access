佳农（水果品牌/供应链）本身主要是水果供应商，配送到“门店/经销商”的体系和你说的“消费者配送到家”可能不是一回事。要判断你们县城门店能不能送到、冷链怎么收费，需要先确认你问的是哪种场景：

1) **你是门店/经销商，想从佳农进货**
- 覆盖城市：通常不是“按城市零售配送”，而是按**区域经销商、批发市场、商超供应链**覆盖。很多县城不是佳农直配，而是通过当地一批商/经销商/批发市场拿货。
- 能不能送到你们县城门店：取决于当地是否有佳农经销商或合作冷链仓。没有的话，一般不能直送，只能到就近城市仓/批发市场自提，或由经销商二次配送。
- 冷链收费：一般不是公开统一价，常见按**件数/箱、重量、体积、距离、温区**计费，也可能“满额免运费”。县城如果单量小，通常运费更高，甚至不接零担冷链。

2) **你是消费者，想在线上买佳农水果配送到家**
- 覆盖城市：要看具体销售渠道，比如京东、天猫、美团、盒马、朴朴、永辉等。佳农作为供货品牌，配送范围由平台决定，不是佳农统一规定。
- 你们县城门店能否送到：如果平台在你们县有前置仓/门店/快递冷链覆盖，就能送；否则通常只能快递到县城，或根本不支持。
- 冷链收费：平台一般显示在结算页，常见是包邮、满额包邮、按件/重量加收冷链费。

**最直接可执行的判断方法：**
- 如果你是门店进货：直接找佳农官方客服/区域销售，问“XX省XX县是否有经销商或冷链直配”。没有官方确认，不要按“全国县城都能送”理解。
- 如果你是消费者：打开你常用的购买平台，把收货地址设成你们县城门店/家里，看是否显示“可配送”和运费。能下单并显示冷链配送，才算能送。
- 如果平台不显示，问平台客服：“佳农这个商品到XX县XX镇是否冷链可达？运费怎么算？”以结算页为准。

**结论：**
佳农没有对外的“全国统一县城门店配送覆盖表”和“统一冷链收费标准”。你们县城门店能否送到，关键看当地有没有佳农经销商/平台冷链覆盖；冷链费也通常按渠道、距离、重量/件数、温区单独算。最靠谱的是拿具体地址去问官方或购买平台客服。
