佳农香蕉的“保质期”没有统一固定值，通常取决于成熟度和储存方式。可按以下判断和执行：

**1. 常见保质期参考**
- **常温、青香蕉**：一般可放 **3～7天** 逐步转黄；夏天更快，冬天稍慢。
- **常温、已熟黄香蕉**：通常 **1～3天内** 最好吃完，出现黑斑后更短。
- **冰箱冷藏**：能延缓过熟，但香蕉皮会变黑，果肉一般还可食用；熟香蕉冷藏通常再放 **2～4天** 问题不大。
- **冷冻**：去皮后冷冻可保存 **1～3个月**，适合做奶昔/烘焙，不适合直接鲜食口感。

**2. 储存条件建议**
- **未熟青香蕉**：放在室温阴凉通风处，**不要冷藏**，可与苹果一起放加速成熟。
- **已熟黄香蕉**：室温尽快吃；想延缓过熟可**冷藏**，表皮变黑不代表果肉坏。
- **不要放塑料袋里闷着**，容易捂坏、发霉。
- **避免阳光直射和高温**，也不要贴近暖气。
- **不要和已烂水果混放**，会加速变质。
- 切开后需密封冷藏，尽快食用。

**3. 判断是否还能吃**
- 可吃：表皮有黑点但果肉正常、无异味。
- 不建议吃：果肉发酸、发黏、渗液、霉点、明显酒味或腐烂味。

**最简执行版**：青香蕉常温放熟；黄香蕉尽快吃，吃不完冷藏；想长期保存就去皮冷冻。
