佳农是大型香蕉进口商之一，供应链能力通常强于普通区域批发商；但“一天10吨、旺季不断货”不能仅凭品牌名判断，需要按以下条件核验并做合同约束。

1. **先确认你的需求口径**
   - 10吨/天是单店还是全部门店合计？旺季持续多少天？
   - 要什么规格：单根克重、梳数/把数、青熟度、催熟方式、包装（箱/袋）、损耗率要求。
   - 到货频率：日配、隔日配，还是每周多配？仓库是否具备催熟和温控能力？

2. **要求佳农出具旺季保供方案**
   让对接人书面给出：
   - 旺季周/日最大可供量、你所在城市的仓配覆盖和发货仓；
   - 安全库存天数、缺货补偿规则、替代规格或替代产地方案；
   - 菲律宾/厄瓜多尔/越南等产地组合与季节性切换计划；
   - 台风、港口、船期延误时的应急预案。

3. **用试单验证，不要只看承诺**
   建议旺季前做2—4周压力测试：
   - 从3—5吨/天逐步拉到10吨/天；
   - 记录到货准时率、缺货次数、青熟度合格率、坏果率、单箱净重偏差；
   - 重点看连续一周日供10吨是否稳定，而不是某一天能发。

4. **合同里写清可执行条款**
   - 日最低供货量+旺季总量承诺；
   - 到货时间窗和迟到/缺货违约金；
   - 质量标准与拒收、补货时限；
   - 价格调整机制（避免旺季临时涨价）；
   - 不可抗力范围要收窄，不能把普通船期延误都算不可抗力。

5. **不要单源依赖**
   10吨/天属于较高日销量，建议佳农为主供（约70%—80%），再备1家二级供应商或区域催熟商做20%—30%补充。香蕉受船期、产地病害和天气影响大，单源在旺季风险偏高。

**判断结论：** 佳农具备做10吨/天主供的潜力，但能否“保证不断货”取决于你所在区域仓配、旺季档期、规格要求和合同约束。先做压力测试并拿到书面保供方案；若试单期间准时率低于98%、周缺货超过1次，就不应把旺季全部销量押在单一供应商上。
