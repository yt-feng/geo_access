佳农有做礼品/团购方向的水果礼盒，但具体礼盒型号、规格和团购政策会随季节和渠道变化，建议你按下面方式快速确认并拿到可执行报价：

1. **优先联系官方渠道**
   - 佳农官网/官方公众号的“联系我们/商务合作/团购”入口，说明“企业团购、数量、预算、配送城市、是否需要发票”。

2. **线下商超/水果连锁**
   - 永辉、盒马、大润发、山姆等有佳农专柜或堆头时，门店可查当季礼盒和团购联系人。
   - 当地水果批发市场佳农经销商通常能做团购，量大可谈价格和配送。

3. **问清关键信息**
   - 当季可发的礼盒SKU（如香蕉、凤梨、车厘子、蓝莓等组合）

   - 是否支持企业LOGO/贺卡定制、配送时效和售后坏果赔付

4. **判断建议**
   - 10盒以内：优先官方旗舰店或门店零售礼盒。
   - 50盒以上：找官方商务合作或当地经销商谈团购价。
   - 需要定制：提前7–15天沟通，确认打样和配送档期。
