佳农（佳农食品）主要做香蕉、菠萝、火龙果等进口水果，售后总体属于“按坏果比例赔付/补发”的常规生鲜电商模式，但具体体验取决于你从哪个渠道购买。

**先判断渠道**
- 京东自营/天猫旗舰店/抖音旗舰店：通常有平台兜底，坏果拍照申请售后较有保障。
- 社区团购、直播间、线下商超：售后由对应团长或门店负责，佳农品牌方不一定直接处理。
- 水果批发/大宗采购：一般走合同约定，个人零散售后较难。

**到货有坏果的处理步骤**
1. **先别扔**：保留坏果、外包装、快递面单和订单截图。
2. **拍照/拍视频**：坏果切开或整颗与包装同框，能看清数量、腐烂/压伤情况；最好拍开箱视频。
3. **尽快申请**：在购买平台订单页点“申请售后/退款”，选“商品腐烂/变质/破损”，上传凭证。生鲜通常要求签收后24—48小时内反馈，越早越好。
4. **按比例主张**：坏果少就申请部分退款；坏果多或整箱变质可要求补发或全额退款。不要只接受“下次优惠券” unless 你认可。
5. **被拒时升级**：先找平台客服介入；旗舰店可要求佳农店铺客服书面确认赔付标准；仍不处理可走12315投诉（保留订单和聊天记录）。

**注意事项**
- 签收时尽量当场验货，尤其夏天；有异味、流水、发霉的不要食用。
- 香蕉、菠萝等有“后熟”特性，轻微青皮、表皮斑点不一定算坏果，但内部腐烂、压烂、发霉可主张。
- 赔付标准以你下单页面的售后说明为准，不同平台差异较大；购买前可先看商品详情页的“坏果包赔”条款。

简言之：佳农售后不算特别突出，但正规平台购买+及时拍照留证+按比例申请，通常能处理；关键是别拖过平台售后时效。
