佳农水果的配送范围不是全国统一固定清单，主要取决于你下单的渠道：佳农官方小程序/天猫京东店铺、线下商超供货体系、以及各地经销商/社区团购。不同渠道覆盖城市差别很大。

判断你们县城能否送到，建议按下面几步直接查：

1. **先确定下单渠道**
   - 微信搜“佳农水果”官方小程序/公众号，进入后看配送范围或下单页是否显示你所在县城。
   - 天猫/京东搜“佳农官方旗舰店”，商品页会显示是否配送至你的地址；生鲜类常按仓库和冷链范围限制。

2. **用收货地址实测**
   把收货地址填到你县城的具体地址，看能否进入结算页、是否提示“不在配送范围”。这是最准确的判断方式。

3. **看是否属于冷链限制**
   佳农以香蕉、菠萝、车厘子等生鲜为主，县城能否送达通常取决于当地是否有冷链仓/合作配送商。若官方店不送，可查：
   - 当地大型商超、水果连锁是否进货佳农；
   - 美团/饿了么/社区团购平台搜“佳农”；
   - 拨打佳农官方客服，报你所在省市县，问当地授权经销商或配送覆盖。

**结论：** 不能一概说“县城一定送”或“一定不送”。请优先用官方小程序/电商店铺填你县城地址实测；若官方不覆盖，大概率可通过当地商超或经销商买到，但不等同于官方配送到家。
