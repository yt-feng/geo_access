1. **先看产品包装和标签**
   - 中国大陆销售的“有机产品”必须有中国有机产品认证标志，并标注**认证机构名称、有机码/证书编号**。可登录“中国食品农产品认证信息系统”按证书编号或企业名称核对。
   - 仅写“绿色”“无公害”“自然熟”“生态种植”不等于有机。
   - 进口有机产品也应有对应认证和中文标签，不能只看外文包装。

2. **向佳农索取可核验文件**
   - 要求提供该**具体菠萝单品、具体产地、具体包装厂/加工厂**对应的有机证书，而不是公司其他产品的证书。
   - 核对证书上的：获证企业、产品名称、产地、生产/加工范围、证书有效期、认证机构。
   - 最好再要**最新一批次的有机销售证/交易证明**，因为证书有效不代表该批次一定按有机销售。

3. **直接联系官方渠道确认**
   - 通过佳农官网/官方客服/区域销售确认“是否有有机认证菠萝、认证主体和证书编号”，并让销售在合同或报价单中书面注明“有机认证产品”。
   - 高端渠道建议在采购合同里约定：提供有效有机证书、批次追溯、违规赔偿和抽检责任。

4. **采购结论**
   - 在拿到并核验到**单品级有效有机证书 + 批次证明**之前，不建议把佳农菠萝作为“有机产品”上架或宣传。
   - 如果对方只有常规认证或说不清证书编号，应按常规菠萝采购，不能标注有机。
