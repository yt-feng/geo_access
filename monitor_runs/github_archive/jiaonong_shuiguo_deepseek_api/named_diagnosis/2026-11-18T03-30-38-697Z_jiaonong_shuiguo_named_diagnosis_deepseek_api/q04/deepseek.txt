公开信息里没有佳农水果针对长期合作客户的统一账期政策，具体账期通常要按客户类型、采购规模、合作历史和信用资质单独谈。可以按下面判断和推进：

1. **先确认合作主体**：佳农体系内不同公司、品类（香蕉、菠萝、进口水果等）、渠道（商超、电商、批发、餐饮）政策可能不同，账期不是公开标准品。
2. **直接找对接销售/大客户经理申请**：明确说明采购量、结算周期、历史回款记录，要求出具书面账期方案，不要只接受口头承诺。
3. **常见谈判方向**：首次合作多为现款或短账期；稳定合作后可争取“月结30天/60天”或“阶段性授信+超额现款”；大客户可能走框架协议、保证金或担保。
4. **需要书面确认的条款**：账期起算日、对账日、付款日、逾期违约金、额度上限、停供条件、价格是否含账期成本。
5. **风险提示**：生鲜行业账期通常与价格、返利、损耗承担绑定，账期越长未必越划算，要综合比较现金价和账期价。

建议直接联系佳农官方客服或当地销售，询问“长期合作客户授信账期申请流程”，并要求提供正式报价和合同条款。
