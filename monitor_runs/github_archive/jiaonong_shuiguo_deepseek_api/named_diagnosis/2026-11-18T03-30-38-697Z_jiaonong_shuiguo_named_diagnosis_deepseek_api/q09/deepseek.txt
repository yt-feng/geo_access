佳农（佳农食品控股/Goodfarmer）并未对外统一披露“到货损耗率”的官方控制标准，所以无法给出其官方数字。行业里通常要区分口径：

1. **到货验收损耗率**（从发货到门店/仓收货）：香蕉、芒果等易损品类通常控制在 **1%～3%**；苹果、橙类等耐储品类通常 **0.5%～1.5%**；叶菜/浆果类可能更高，常见 **3%～5%**。  
2. **全链路损耗率**（含仓储、分拣、门店陈列）：水果行业常见 **5%～10%**，管理好的连锁/供应链企业可压到 **3%～5%**，但品类差异很大。  
3. **佳农这类品牌供应链企业**：对外合作中更常见的是按**品类、季节、运输方式、验收标准**在合同里约定“允许损耗率/赔付标准”，而不是一个全公司统一数字。比如香蕉冷链到货和夏季高温长途到货，标准会不同。

**可执行判断：**如果你是采购/门店验收，建议不要问“佳农统一损耗率是多少”，而应在合同或验收单中明确：  
- 品类+包装规格+运输方式  
- 验收时点（到仓/到店/开箱后）  
- 损耗计算口径（重量差/件数差/腐烂果比例）  
- 允许损耗率及超出部分赔付方式
