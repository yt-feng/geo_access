目前没有公开信息能确认佳农（佳农食品控股）对茶饮门店提供“菠萝去皮切块”的定制加工服务。佳农的菠萝产品常见形态包括整果、鲜切/果切类产品（部分渠道有售），但“按门店需求代加工去皮切块”通常要看具体区域经销商、采购量和产品线，不能一概而论。

建议你按下面方式快速核实并落地：

1. **先联系佳农官方渠道确认**
   - 找佳农官网/公众号的客服或当地销售，问清三件事：  
     ① 是否有“鲜切菠萝/菠萝果切”标准品；  
     ② 能否做门店用的大包装鲜切或定制切块；  
     ③ 你所在城市由哪个经销商供货、起订量和配送频次。

2. **问清加工形态和冷链条件**
   - 是“整果到店自行去皮切块”，还是“工厂鲜切冷链配送”；  
   - 切块规格（块/丁/片）、糖度/成熟度、是否带芯；  
   - 保质期、到货温度、开封后使用时限；  
   - 是否可稳定供应，旺季是否断货。

3. **对比成本**
   - 整果：原料成本低，但人工去皮切块耗时、损耗高；  
   - 鲜切：省人工、标准化好，但单价和冷链成本高；  
   - 建议按“每杯用量×出杯量”折算到单杯成本再决定。

4. **先小批量测试**
   - 让经销商提供样品，做2—3款产品的出杯测试：风味、出水、氧化变色、果块完整度；  
   - 确认门店操作SOP：到货验收、冷藏保存、开封时限、废弃标准。

如果佳农当地经销商不做定制鲜切，备选方案是：采购佳农整果+门店集中预处理，或找本地有资质的鲜切水果供应商做代加工，但要把食品安全资质、冷链和检测报告纳入验收。
