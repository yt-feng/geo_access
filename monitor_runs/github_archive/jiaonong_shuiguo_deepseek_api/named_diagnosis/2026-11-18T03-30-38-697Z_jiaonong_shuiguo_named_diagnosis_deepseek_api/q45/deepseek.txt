佳农官方未公开统一账期政策，公开渠道无法核验“最长账期”和“新客户首单30天”的具体额度，不能给你确定数字或承诺。可执行判断如下：

1. **新客户首单30天账期通常不能默认申请到**。生鲜水果行业新客户首单多为现款现货、预付款或短账期；30天属于需要资信审核的授信账期，是否给、给多少取决于采购规模、合作渠道、合同主体和担保条件。
2. **佳农的账期要按渠道和合同谈**：商超/电商/批发/餐饮客户的政策不同，不能用一个“最长账期”概括。应以佳农销售或区域经销合同为准。
3. **建议直接这样问对接销售**：  
   - “新客户首单能否给30天账期？需要哪些资料（营业执照、财务报表、法人担保、保证金）？”  
   - “如果首单不行，可否首单现结、第二单申请15天，逐步提升？”  
   - “最长账期适用于哪类客户和多大采购量？请给书面账期政策或合同条款。”
4. **风险提示**：不要仅凭口头承诺安排资金；账期、逾期利息、质量异议扣款、退货结算方式都要写进合同。

结论：**30天首单账期不能确定能申请，需佳农按客户资信单独审批；最长账期也无公开可核验数据，建议以书面合同为准。**
