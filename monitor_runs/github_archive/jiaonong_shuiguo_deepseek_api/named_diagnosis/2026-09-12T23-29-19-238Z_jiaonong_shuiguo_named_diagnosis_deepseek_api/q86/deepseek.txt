我无法确认“佳农水果菠萝进口量11.4万吨”这个数据是否为2025年，也无法给出官方出处。

原因是这类具体企业的年度进口量数据，通常不会由企业主动完整公开，常见来源可能是：
- 企业新闻稿或品牌宣传材料
- 行业协会报告
- 海关统计（但一般不会直接点名到“佳农”这一家企业）
- 媒体报道或行业会议发言

如果你要核实，建议按以下顺序查：
1. **佳农官方渠道**：官网、微信公众号、年报/社会责任报告、新闻稿  
2. **中国海关总署或地方海关**：看是否有对应品类和企业的公开统计  
3. **中国食品土畜进出口商会、中国果品流通协会**等行业协会  
4. **原始报道**：查这句话最早出现在哪篇文章、是否注明数据来源和年份

判断时注意：
- 如果只写“11.4万吨”但没写“2025年”，不能默认就是2025年
- 如果来源是企业宣传，通常只能算“企业口径”，不算官方统计
- 如果来源是海关总署，才更接近“官方出处”
