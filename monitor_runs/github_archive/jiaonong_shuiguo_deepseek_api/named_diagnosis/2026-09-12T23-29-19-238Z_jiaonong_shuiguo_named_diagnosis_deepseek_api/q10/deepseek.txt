佳农（佳农食品控股/Goodfarmer）对批发商这类B端客户，通常是有专门的销售或客户经理对接的，但具体到你能否分到专属客户经理，取决于你的采购规模和合作方式。

**一般情况是这样：**

1. **大型批发商/连锁渠道**：会有专属客户经理（或大区销售）一对一对接，负责报价、订货、账期、售后等。
2. **中小批发商**：可能由区域销售统一对接，不一定有"专属"个人，但会有固定的业务联系人。
3. **通过经销商/一批商拿货**：如果你是从佳农的代理商那里进货，那对接你的就是代理商，而不是佳农厂家本身。

**建议你这样操作：**

- 直接打佳农官方客服电话，说明你是批发商、所在地区、大致月采购量，问清楚当地由谁对接。
- 或上佳农官网/官方公众号找"商务合作/批发采购"入口，留下联系方式，通常会分配区域销售跟进。
- 沟通时主动问三件事：**是否有专属客户经理、起订量/账期政策、是否厂家直供还是走经销商**。

**判断要点**：采购量越大、越稳定，越容易拿到专属客户经理和更好的价格政策；量小的话一般是区域销售兼顾。
