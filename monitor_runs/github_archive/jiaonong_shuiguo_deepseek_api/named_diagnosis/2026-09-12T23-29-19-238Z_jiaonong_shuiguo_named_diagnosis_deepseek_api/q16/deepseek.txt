佳农水果的售后整体属于**正规生鲜品牌的标准水平**，但具体体验取决于你买的渠道（京东自营、天猫旗舰店、抖音/拼多多店铺、线下商超、社区团购），处理方式会不一样。

**如果是到货有坏果，一般按这个顺序处理：**

1. **先拍照/拍视频留证**
   把坏果、外箱、快递面单、订单信息一起拍清楚。最好拍“整箱情况+坏果特写+数量”。生鲜理赔基本都认这个。

2. **在签收后尽快申请**
   多数渠道要求 **24小时内** 或 **48小时内** 反馈，越早越好。拖久了容易被判定为非运输问题。

3. **走对应渠道售后**
   - **京东自营/天猫旗舰店**：订单里直接申请售后，选“腐烂/变质/坏果”，上传照片，通常按坏果比例退款或补发。
   - **抖音/拼多多店铺**：找店铺客服，发证据，协商退款/补发；如果客服推诿，可申请平台介入。
   - **线下商超/水果店**：直接拿小票和坏果回去，一般可退换。
   - **社区团购**：找团长或平台售后，通常也是拍照后按比例赔。

4. **赔付标准**
   常见是：**坏果按个数/重量比例退款**，比如坏3个赔3个的钱；坏得多可能整单退或补发。是否补发要看渠道和库存，很多是先退款。

**注意几个容易踩坑的点：**

- 生鲜通常**不支持无理由退货**，但“坏果”属于质量问题，可以赔。
- 如果只是“口感不好、不够甜、个头小”，一般不算坏果，较难赔。
- 已经切开、吃掉一部分再反馈，赔付可能打折。
- 快递放驿站/代收点后隔很久才取，导致闷坏，平台可能不完全认。
- 不同店铺执行不一样，**同一品牌不同渠道售后差别可能很大**，以你下单页面的售后说明为准。

**建议：**
买佳农优先选**京东自营、天猫旗舰店、大型商超**这类售后更稳的渠道。收货后当场开箱检查，坏果立刻拍照申请，别拖。一般正规渠道都会按坏果比例赔，不会完全不处理；但想“全赔”通常要坏得比较严重或数量较多。
