佳农水果的配送时效取决于**下单渠道**和**收货地区**，没有统一的固定时效。大致情况如下：

**1. 电商平台（京东/天猫/拼多多等）**
- 一般走平台仓或佳农自有仓发货，**下单后 24～48 小时内出库**较常见。
- 运输时效看地区：
  - 一线及周边城市：**1～2 天**送达；
  - 普通地级市：**2～4 天**；
  - 偏远地区（新疆、西藏、内蒙部分、部分乡镇）：**3～7 天甚至更久**。
- 生鲜类通常走顺丰/京东冷链，实际时效以商品页标注的“预计送达时间”为准。

**2. 商超/生鲜平台（盒马、美团买菜、朴朴、叮咚等）**
- 如果是本地前置仓发货，通常是**当日达或次日达**，部分支持 **30 分钟～2 小时**即时配送。
- 这种时效取决于你所在城市是否有其仓配覆盖。

**3. 线下批发/门店自提**
- 属于当场拿货，不涉及配送。

**最准确的判断方法：**
1. 打开你下单的具体商品页，看**“配送”或“预计送达”**说明；
2. 下单前把收货地址填进去，系统会显示**预计到达日期**；
3. 直接问店铺客服：“我地址是 XX，一般几天到？”

**简单结论：** 同城生鲜平台多为当日/次日达；电商快递一般 1～4 天，偏远地区更久。具体以你下单页面显示的预计送达时间为准。
