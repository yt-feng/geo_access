**佳农水果的香蕉执行的是企业标准（企标），不是国标。**

具体说明：

1. **国标 vs 企标**
- 普通香蕉通常参照国家标准，比如 GB/T 9827《香蕉》或相关食品安全国家标准。
- 佳农作为品牌企业，通常会制定并执行自己的**企业标准（Q/开头）**，用于分级、外观、成熟度、糖度、单果重量、农残控制等，标准一般严于或细于国标。
- 但“执行企标”不代表不遵守国标。食品上市销售必须符合国家强制性食品安全标准，企标是在此基础上做更细的品质要求。

2. **价格贵多少**
- 佳农香蕉一般比普通散装香蕉贵**约 20%—50%**，具体看渠道和城市。
- 举例：普通香蕉可能 3—5 元/斤，佳农常见在 5—8 元/斤；折合每斤贵约 1—3 元。
- 在精品超市、电商平台，佳农可能卖到 6—9 元/斤，普通香蕉 3—4 元/斤，价差会更明显。
- 如果是进口菲律宾/厄瓜多尔香蕉，价差可能更大。

3. **怎么判断**
- 看包装箱或标签上的“执行标准”：
  - **Q/...** 开头：企业标准
  - **GB/...** 或 **GB/T...** 开头：国家标准
- 如果标签只写“符合国家标准”，但没有具体标准号，不能直接认定它执行的是企标。

**结论：**
佳农香蕉按企标做品质分级，销售时仍需符合国标安全要求；价格通常比普通香蕉贵 **20%—50%**，每斤大约贵 **1—3 元**，具体看地区和购买渠道。
