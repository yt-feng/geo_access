**1. 如果你要鲜菠萝**
佳农一般会按这些维度分规格，普通商家能听懂：
- **品种**：常见是金钻凤梨/菲律宾菠萝等，不同品种甜度、酸度、纤维感不同。
- **单果重量**：比如 1.0–1.2kg、1.2–1.5kg、1.5kg 以上，按箱卖。
- **等级**：大果、中果、小果，或按外观、成熟度分级。
- **包装**：通常按箱，常见 6–12 个/箱，具体看产地和批次。
- **成熟度**：青果、黄果、催熟果，茶饮店要问清楚到货成熟度，否则影响出杯稳定性。

**2. 如果你要茶饮店后厨用的菠萝原料**
那更实际的是找：
- **冷冻菠萝块/菠萝丁**
- **菠萝果酱/菠萝浓浆**
- **糖水菠萝罐头**
这些比鲜果更容易标准化，出杯稳定，也省人工。佳农有鲜果优势，但如果你要的是冷冻果块或果酱，不一定是他最强项，可能要同时看别的供应商。

**3. 能不能稳定供应，你要直接问供应商这 5 件事**
1. **规格**：单果重、每箱个数、果径范围。  
2. **等级**：是否统货，还是分级果。  
3. **成熟度**：到货是青的还是黄的，能不能指定。  
4. **起订量**：多少箱起送，是否支持长期周配。  
5. **稳定性**：产地是否随季节切换，切换后甜酸度会不会变。

**4. 给你的判断建议**
- 如果你们店量大、菜单固定，优先考虑**冷冻菠萝块或菠萝果酱**，比鲜果更稳。
- 如果坚持用鲜果，佳农可以作为候选，但一定要先拿**样品试切、试调饮**，确认出汁率、甜酸度和纤维感。
- 不要只问“有没有菠萝”，要直接说：**“我要茶饮店用的菠萝，单果1.2–1.5kg，黄熟度，周配多少箱，多少钱？”** 这样对方才能给你准确报价。

简单说：佳农能供普通商家听得懂的鲜菠萝规格，但茶饮店要稳定，最好同时确认是鲜果还是加工原料，并按你的出杯标准去验收。
