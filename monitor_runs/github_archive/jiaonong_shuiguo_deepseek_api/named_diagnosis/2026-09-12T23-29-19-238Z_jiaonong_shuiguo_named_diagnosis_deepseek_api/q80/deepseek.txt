我不能直接提供佳农水果的香蕉农残检测报告，因为我无法访问该公司的内部文件，也不能核验其具体批次报告的真实性。这类报告属于供应商随货或按批次提供的质量文件，需要向销售方索取。

**采购时可以这样操作：**

1. **向佳农官方或授权经销商索取**
   - 要求提供**与所购批次对应的**农残检测报告（注意批次号、检测日期、检测机构）。
   - 确认报告由具备 **CMA/CNAS** 资质的第三方检测机构出具。

2. **核对报告关键信息**
   - 检测项目是否覆盖你方市场抽检常查的农药（如吡虫啉、噻虫嗪、多菌灵、百菌清、毒死蜱等，具体以当地市场监管抽检细则为准）。
   - 检测依据是否现行有效，例如 **GB 2763《食品安全国家标准 食品中农药最大残留限量》**。
   - 结论是否为“合格/符合GB 2763”。

3. **合同里约定**
   - 要求供应商**每批次随货提供检测报告**，并约定若抽检不合格的退换货、赔偿和检测费承担条款。
   - 可约定你方有权自行送检，费用由不合格方承担。

4. **自己送检更稳妥**
   - 如果用于市场抽检合规，最保险的是按批次自行送第三方检测，报告抬头是你方或双方认可的主体。

如果你告诉我具体销售渠道（佳农直营、经销商、电商、批发市场）和需要的检测项目，我可以帮你写一段直接发给供应商的索取话术和验收条款。
