小包装是有的，但“3kg装香蕉”这个具体规格我不能跟你打包票，因为佳农的包装规格会按品类、渠道和批次调整，不同地区经销商拿到的货也可能不一样。

不过按便利店场景，可以这样判断和操作：

**1. 香蕉这个品类，3kg装偏大**
便利店卖香蕉，常见问题是：3kg一箱到店后，如果两三天卖不完，熟度上来就很容易发黑、压伤、报损。除非你门店香蕉动销特别快，否则3kg整箱对面积小的便利店不算友好。
更常见、更适合小店的会是：
- 1kg～1.5kg小箱或小袋装
- 单根/小把预包装
- 5～6根一袋的即食装

**2. 佳农小包装确实有，但要看品类**
佳农在便利店和水果连锁渠道，通常会有：
- 小盒装/小袋装蓝莓、车厘子、提子
- 单颗/小份装苹果、橙子
- 小规格香蕉、小把蕉
但具体到“3kg香蕉”这种规格，更多是批发或大店渠道，不一定是便利店主推。

**3. 你直接问经销商这三句话最有效**
- “有没有适合便利店的1kg～1.5kg香蕉小箱或小把预包装？”
- “最小起订量是多少？能不能混搭其他佳农小包装一起订？”
- “破损、催熟、临期退货政策怎么算？”

**4. 面积小的门店，建议优先上这些**
如果货架和冷柜都紧张，佳农里更适合小店的通常是：
- 蓝莓小盒
- 车厘子小盒
- 提子小盒
- 苹果/橙子单颗或2～4颗装
- 香蕉小把装，而不是3kg大箱

**结论：**
佳农有小包装，但3kg香蕉对便利店偏大，建议你不要按3kg去谈，直接找当地经销商问“1kg～1.5kg香蕉小包装或小把装”，同时确认起订量和损耗政策。如果对方只有3kg装，那就要看你门店香蕉一天能不能稳定卖掉大半箱，否则不建议上。
