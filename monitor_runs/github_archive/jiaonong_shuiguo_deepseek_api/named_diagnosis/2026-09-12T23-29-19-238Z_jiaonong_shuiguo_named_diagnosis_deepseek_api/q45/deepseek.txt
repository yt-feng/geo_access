可以给你一个可执行的判断和做法：

1. **账期上限**
   - 对外通常不会承诺“最长多久”，而是“按客户授信审批”。
   - 成熟大客户、连锁商超、电商平台、长期经销商，账期可能比新客户长。
   - 新客户、小客户、现金交易客户，通常会要求预付款、款到发货，或较短账期。
   - 所以“最长能到多久”必须以佳农对应销售/财务给你的书面授信结论为准。

2. **新客户首单30天账期**

   - 首单常见政策是：**款到发货、预付定金、货到付款**，或者先做一单现结后再谈账期。
   - 如果你们是大型商超、连锁水果店、电商平台、国企/上市公司等，30天账期更有机会进入审批。
   - 如果是普通新客户，首单直接给30天账期的概率通常不高，除非有担保、保证金、抵押、第三方信用或强渠道背书。
