佳农水果的香蕉规格并没有一个对外完全统一、固定不变的公开分级表，实际会随产地（如菲律宾、厄瓜多尔、越南等）、季节、批次、客户订单和渠道要求调整。因此下面给的是行业里常见、也常被佳农这类品牌商采用的分级思路，不能等同于佳农官方实时标准；若要精确到某个SKU，需要看当批次的装箱单、规格书或直接问区域销售。

**一、常见的香蕉规格划分方式**

1. **按每箱净重**
   - 4.5kg、5kg、7kg、10kg、12kg、13kg、15kg、18kg、20kg等。
   - 商超、电商常用小箱，如4.5–7kg；批发市场、餐饮、加工渠道常用10–20kg大箱。

2. **按每箱根数/把数**
   - 常见有每箱4–6把、5–7把、7–9把等。
   - 也有按单根数量标的，如每箱约20–30根、30–40根、40–50根不等，取决于单根重量和把型。

3. **按单根重量/条重**
   - 小果：约90–120g/根。
   - 中果：约120–150g/根。
   - 大果：约150–180g/根。
   - 特大果：180g以上/根。
   - 不同市场叫法可能不同，有的用“条重”，有的用“单根克重”。

4. **按长度和粗度**
   - 长度常见分档：16–18cm、18–20cm、20–22cm、22cm以上。
   - 粗度常用围度或直径表示，如3.0–3.5cm、3.5–4.0cm、4.0cm以上。
   - 高端商超更看重长度、粗细、弯度、色泽一致。

5. **按成熟度和颜色**
   - 青蕉：适合长途运输、催熟后销售。
   - 微黄/转黄：适合短途配送、即时零售。
   - 黄熟：适合即食、餐饮、促销。
   - 分级通常用色卡，如1–7级，1级全青，7级全黄带糖斑。

6. **按外观等级**
   - A级/精品：果形直或弯度均匀，无黑斑、无机械伤、无擦伤、无病虫，把型整齐。
   - B级/通货：轻微擦伤、果形略不齐，但不影响食用。
   - C级/加工果：外观瑕疵较多，适合榨汁、烘焙、果切、餐饮加工。

**二、不同渠道常见的分级标准方向**

1. **高端商超/精品超市**
   - 偏好：单根重120–160g，长度20cm以上，粗细均匀，果形弯度一致，青转黄可控。
   - 包装：小箱4.5–7kg，每箱把数整齐，常要求可追溯、农残合格、催熟方案配套。
   - 等级：以A级或精品级为主，外观瑕疵容忍度低。

2. **电商/社区团购/即时零售**
   - 偏好：单根重100–150g，长度18–22cm，成熟度可调，耐配送。
   - 包装：5kg、7kg、10kg，或按份/按把预包装。
   - 等级：A/B级混装常见，重点是到货成熟度一致、破损率低。

3. **批发市场/农贸渠道**
   - 偏好：单根重120–180g，长度18cm以上，青蕉为主，耐运输。
   - 包装：10–20kg大箱，按把或散装。
   - 等级：B级/通货为主，价格敏感，外观要求相对宽松。

4. **餐饮/烘焙/果切/加工渠道**
   - 偏好：单根重150g以上或偏小果均可，重点是可食率、出肉率、成熟度稳定。
   - 包装：10–20kg，散装或大把。
   - 等级：B/C级，允许轻微外观瑕疵，但要求无腐烂、无严重病虫。

5. **出口/跨境渠道**
   - 偏好：按目的国标准，通常要求长度、围度、成熟度、农残、检疫非常严格。
   - 包装：多为12–18kg箱，按根/把/梳分级。
   - 等级：以A级或出口级为主，色卡、糖度、硬度和冷链记录都有要求。

**三、判断佳农某批香蕉规格时，建议看这几个字段**

- 产地：菲律宾、厄瓜多尔、越南、柬埔寨等。
- 净重：如4.5kg/箱、7kg/箱、13kg/箱。
- 条重：如120–150g/根。
- 长度：如18–20cm、20–22cm。
- 把数/根数：如每箱5–7把、每箱约30根。
- 等级：A级、B级、通货、加工果。
- 成熟度：青蕉、微黄、黄熟，或色卡级别。
- 渠道：商超、电商、批发、餐饮、出口。

**结论：**
佳农香蕉常见规格可按“箱重、根数/把数、单根重、长度、成熟度、外观等级”六类划分。不同渠道的核心差异是：高端商超要A级小箱、外观整齐；电商要成熟度可控、耐配送；批发要青蕉大箱、耐运输；餐饮加工要B/C级、重出肉率；出口要严格按目的国标准。具体到某一批佳农香蕉，最准确的做法是查该批次规格书或问销售，因为品牌商的分级会随订单和产地调整。
