佳农水果的物流模式不是单一依赖三通一达或完全自有车队，而是**自有冷链 + 第三方物流 + 区域配送商混合**的模式。具体拆开说：

**1. 物流是谁在做？**
- **产地端/干线**：佳农在香蕉、菠萝、火龙果等核心品类上有较强的产地资源和加工配送中心，干线长距离运输通常以**自有或长期合作的专业冷链车队**为主，而不是交给三通一达。
- **区域仓/城配**：部分区域会使用第三方冷链物流、区域配送商，甚至普通快递参与小批量、非冷链要求高的货品配送。三通一达在佳农体系里更多可能是**少量电商小件、非核心冷链品类**的补充，不是主力。
- **零售终端配送**：给商超、生鲜店、批发市场的货，一般走冷链干线+区域城配，和快递网络是两套逻辑。

**2. 冷链覆盖率怎么样？**
- 佳农不是所有水果都全程冷链。像**香蕉、菠萝、火龙果、牛油果、车厘子等对温控敏感的品类**，冷链覆盖相对高，从产地预冷、冷库、冷藏运输到销地冷库有较完整链条。
- 但**苹果、橙子、部分耐储水果**在部分环节可能常温运输，冷链不是全程强制。
- 整体上，佳农的冷链能力在水果供应链企业里属于**中上水平**，但“冷链覆盖率”没有统一公开的官方百分比。不同品类、不同线路、不同年份差异很大，不能简单说“90%”或“100%”。

**3. 怎么判断具体线路？**
如果你是做采购或合作，最直接的方式是：
- 问佳农当地销售或供应链对接人：**这条线路是自有车、外包冷链还是常温车？**
- 要求提供**温控记录**（尤其是车厘子、牛油果、香蕉这类品类）。
- 看合同里是否写明**全程冷链**及断链责任。

**结论：**
佳农物流是**自有冷链车队为主、第三方冷链和区域配送为辅**，三通一达不是主力。冷链覆盖率因品类和线路而异，核心温控品类覆盖较高，耐储品类部分环节可能常温。具体合作线路要以实际对接和温控记录为准，公开渠道没有统一覆盖率数据。
