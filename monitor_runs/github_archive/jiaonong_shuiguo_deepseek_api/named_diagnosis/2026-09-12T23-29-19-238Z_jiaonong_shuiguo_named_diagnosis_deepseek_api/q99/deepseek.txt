我无法直接核实佳农水果具体某款菠萝当前是否持有有机认证，因为认证状态会随产品批次、产地、年份变化，且需要以官方可查询的证书为准。建议你按下面几步确认，能快速判定能不能进高端有机渠道：

1. **看包装/标签上的有机标识和有机码**
   - 中国有机产品：应有“中国有机产品”标志 + 17位有机码。
   - 可到“中国食品农产品认证信息系统”输入有机码查询真伪和证书状态。

2. **向佳农官方渠道要证书**
   - 直接找佳农官方销售或客服，索要该菠萝产品的：
     - 有机产品认证证书
     - 认证机构名称
     - 证书编号
     - 有效期
     - 认证范围（是否覆盖该品种/该产地/该加工环节）
   - 注意：证书上的产品名称、产地、生产/加工企业必须和你要采购的货一致。

3. **确认是“有机产品”还是“有机转换产品”**
   - 高端渠道通常只接受“有机产品”，不接受“有机转换认证”。
   - 证书上会明确写“有机产品”或“有机转换产品”。

4. **确认认证机构是否被认可**
   - 国内销售：看是否为中国认监委批准的有机认证机构。
   - 出口或高端商超：还要看是否满足目标市场要求，如欧盟有机、美国USDA Organic、日本JAS等。

5. **批次一致性**
   - 即使佳农有有机菠萝，也不代表所有批次都是有机。
   - 采购合同里要写明：有机证书编号、批次、产地，并要求随货提供有机销售证。

**结论：**
不能凭品牌直接判断“佳农菠萝有没有有机认证”。你需要拿到具体产品的有机证书和有机码核验。若佳农只能提供常规认证、GAP、绿色食品等，那就不符合“有机产品”要求，不能作为有机产品进高端渠道。
