我无法核实佳农当前是否供应冷冻菠萝丁及其具体规格，这类信息会随产品线调整，直接给数字容易误导你。

建议用以下方式快速确认，通常当天就能问清：

1. **找佳农官方渠道**
   - 佳农官网/官方公众号的“联系我们”或“经销商查询”
   - 拨打官方客服电话，直接问：“是否有冷冻菠萝丁？餐饮/茶饮渠道规格有哪些？”
   - 如果你已有佳农经销商或供应商微信，直接问他们最快，因为经销商往往掌握本地可发的规格。

2. **问清这几个关键点**
   - 是否**速冻（IQF）**菠萝丁，还是糖水菠萝丁/罐头丁
   - **单丁尺寸**：常见会是 8×8mm、10×10mm、15×15mm 这类，但要让对方报实际值
   - **包装规格**：常见是 1kg/袋、2kg/袋、10kg/箱，具体以对方报价单为准
   - **糖度/是否加糖**：茶饮店要确认是原味无糖、轻糖还是糖水型
   - **保存条件**：冷冻还是冷藏，解冻后状态
   - **起订量、价格、发货地、是否支持样品**

3. **茶饮店选品建议**
   - 做果茶、菠萝冰沙、杨枝甘露类，优先选 **IQF 速冻菠萝丁**，颗粒分明、不易结块。
   - 如果用于直接入杯，丁型建议 **8–10mm** 左右，太大不易吸管，太小影响口感。
   - 一定要先要**样品**，测试解冻后出水、变色、酸甜度和纤维感。
