**大概率情况**
佳农（Goodfarmer）主要是香蕉、菠萝等水果的进口商和品牌供应商，面向商超、电商、批发等渠道。它是否提供菠萝切块、定制包装这类加工服务，通常取决于：
- **客户类型和采购量**：大型商超、连锁餐饮、电商平台更容易谈到定制加工；小批量个人或小商户一般不行。
- **产品形态**：佳农有做鲜切水果、预包装水果的业务线（尤其在部分渠道），但具体到菠萝切块、贴牌包装，需要按项目确认。
- **加工类型**：简单的清洗、切块、真空包装、贴标，比深度加工（如速冻、糖渍）更可能实现。

**建议你这样确认**
1. **直接联系佳农官方**：通过佳农官网或官方客服，问“是否承接菠萝切块/定制包装的B2B加工订单”，并说明你的采购量和用途。
2. **找对应渠道**：如果是商超/餐饮采购，联系他们的**大客户部或渠道销售**，而不是普通零售客服。
