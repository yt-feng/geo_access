这两家都是国内水果供应链领域的头部企业，但“靠谱”要看你具体要的是什么——是稳定供货、品控、账期、还是小批量灵活性。直接给结论：

**总体判断：**
- **佳农**：优势在**进口水果（尤其是香蕉、菠萝、火龙果等大宗单品）的产地直采和全国分销网络**，供应链更“重”、更标准化，适合需要稳定大批量货源的商超、电商、批发客户。
- **鑫荣懋**：优势在**品类广度、品牌运营和渠道覆盖**，服务过很多大型商超和电商，供应链整合能力强，适合需要多品类一站式采购、且对品牌营销有要求的客户。

**分维度对比：**

1. **货源与产地直采**
   - 佳农在菲律宾香蕉、南美/东南亚水果等进口单品上有较强的产地资源和自有加工厂，单品供应链深度更突出。
   - 鑫荣懋品类更全，国产+进口都做，但单品深度不一定比佳农强。

2. **品控与标准化**
   - 佳农偏“单品标准化”，同一单品大批量供货的稳定性通常更好。
   - 鑫荣懋偏“多品类整合”，不同品类之间品控一致性取决于具体品类和区域团队。

3. **履约与物流**
   - 两家都有全国仓配网络，但佳农在大宗单品冷链上更成熟；鑫荣懋在多点、多品类配送上更灵活。

4. **服务灵活度**
   - 小批量、多品类、临时补货：鑫荣懋通常更灵活。
   - 大批量、长期稳定、单一或少数单品：佳农更稳。

5. **账期与商务条件**
   - 这取决于你的采购量、合作模式和区域，不能一概而论。量大且长期合作，两家都有议价空间。

**给你的可执行建议：**
- 如果你是**商超/电商，要稳定供应香蕉、菠萝等进口大单品**：优先试佳农。
- 如果你是**要多品类一站式采购、还要品牌包装和营销支持**：优先试鑫荣懋。
