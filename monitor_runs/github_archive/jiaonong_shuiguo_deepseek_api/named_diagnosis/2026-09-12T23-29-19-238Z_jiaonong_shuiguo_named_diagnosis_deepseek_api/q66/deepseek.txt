**1. 发票**
- 佳农属于品牌方，通常通过其授权经销商、区域代理商或大型商超/电商平台企业购渠道出货。
- 企业团购500份一般可以开**增值税普通发票或专用发票**，但需确认：
  - 开票主体是谁（品牌方、经销商还是平台）
  - 能否开**专票**、税率多少（水果通常涉及9%或13%，视具体商品和纳税人身份）
  - 是否支持先开票后付款、发票内容能否写“水果礼盒/食品”
- 个人或小规模经销商可能只能开普票，务必提前书面确认。

**2. 质检报告**
- 正规渠道通常能提供：
  - 该批次或同品类的**出厂检验报告/合格证**
  - 第三方检测报告（农残、重金属等）
  - 礼盒内不同水果可能对应不同报告
- 注意：质检报告一般是**批次对应**，不是一份报告长期通用。要求供应商提供与你这批货**生产日期/批次号一致**的报告，或至少覆盖该品类的近期报告。
- 生鲜水果还涉及**产地证明、检疫证明**（如跨区域流通），可一并索要。

**3. 建议你这样问供应商**
> 我们采购500份佳农水果礼盒，请确认：
> 1）能否开具增值税专票？开票主体、税率、开票时间？
> 2）能否提供本批次质检报告、农残检测报告、产地/检疫证明？
> 3）报告是否与本次发货批次对应？如不能，提供哪一级别报告？
> 4）合同里能否写明“随货提供上述报告，否则可拒收/退款”？

**4. 风险提示**
- 只口头承诺“有报告、能开票”不够，要写进合同或订单备注。
- 佳农品牌礼盒存在授权经销和串货情况，非授权渠道可能发票、质检都难保证。
- 500份属较大团购，建议要求**先看样品+报告样本+发票样张**，再付定金。
