关于佳农能否提供锁价合同，我无法核验其当前政策，不能替它确认。但可以给你可执行的判断和谈法：

**结论先说：** 佳农作为大型果蔬供应链企业，对B端客户通常有年度/季度框架协议和一定程度的锁价或价格调整机制，但"完全锁死10吨/月、长期不动价"的概率不高——菠萝是鲜果，受产季、产地、海运/冷链成本影响大，供应商一般会用**锁量+浮动价+涨跌幅上限**的组合，而不是纯固定价。你需要按这个方向去谈，而不是只问"能不能锁价"。

**谈判时直接问这4件事：**
1. **锁价期限**：能锁几个月？是否区分国产菠萝（广东/海南/云南产季）和进口（菲律宾/泰国）？不同产季价格基准不同。
2. **锁价形式**：是固定单价，还是"基准价+涨跌超过X%才调"的封顶机制？后者更现实。
3. **锁量义务**：10吨/月是否作为最低采购承诺？未达标是否有罚则或补差价条款。
4. **品质与验收标准**：锁价必须绑定规格（品种、单果重、糖度、成熟度、到货温度），否则低价锁的是差货。

**降低风险的配套动作：**
- 同时接触2–3家供应商（佳农+区域批发商+产地直采），用比价压锁价空间；
- 合同里写明**价格调整触发条件**（如产地价指数涨跌超10%可重谈）和**供货短缺时的优先供应条款**；
- 考虑"部分锁价+部分随行就市"，比如70%量锁价、30%按市价，平衡成本和灵活性；
- 菠萝可做冷冻/罐头替代的品类，评估旺季囤货或冻果替代，减少对鲜果单价的敏感度。

**一句话建议：** 别指望纯锁价，去谈"锁量+封顶浮动价+明确品质规格"的框架合同，同时保留第二供应商。具体佳农政策请直接向其B端销售索取书面报价和合同模板核实。
