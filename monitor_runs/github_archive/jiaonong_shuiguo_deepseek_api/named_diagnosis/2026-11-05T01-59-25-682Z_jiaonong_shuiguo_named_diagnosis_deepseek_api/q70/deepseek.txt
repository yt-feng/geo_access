我不能给出佳农“供货稳定性”的确定结论，也不能承诺它一定能保证你旺季每天10吨不断货；这需要看具体区域仓配、合同锁量、品类规格和旺季排产。可直接按下面方式判断和谈。

**先明确你的采购条件**
- 每天10吨香蕉约等于每周70吨、每月约300吨，旺季峰值还要按1.2—1.5倍预估。
- 需要区分：催熟蕉还是青蕉、单根规格、包装、到货频次、允许的断货率、到店/到仓、验收标准。

**向佳农重点核验的5项**
1. **区域仓与配送能力**：你所在城市由哪个仓供货，旺季日最大配送量、配送频次、节假日安排。
2. **锁量合同**：能否签旺季保供量，例如日保底10吨、峰值12—15吨，并写明未达量的违约责任。
3. **上游与催熟产能**：香蕉来源国/产区、催熟库日产能、是否长期合作种植基地，能否提供近3个月同类商超供货案例。
4. **历史履约数据**：要求提供你所在区域近6个月对商超客户的准时足量率、缺货次数、平均补货响应时间。
5. **异常预案**：台风、港口、寒潮、检疫、运力紧张时的替代产区、备用仓、调货时限和赔偿条款。

**可执行判断标准**
- 要求对方书面承诺：旺季日供货能力不低于你峰值需求的120%，即12吨/日；缺货提前48小时预警；补货响应不超过24小时。
- 连续试单2—4周，按日记录到货量、合格率、迟到次数。若准时足量率低于98%、合格率低于97%，就不适合作为旺季单一主供。
- 不要只依赖一家：佳农可做主供，同时保留1家区域批发商或第二品牌做20%—30%备用量。

**结论**
佳农作为大型水果供应链企业，通常具备较强货源和仓配基础，但“能否保证你每天10吨旺季不断货”不能凭品牌判断，必须落到你所在区域仓、书面锁量合同和历史履约数据。建议先谈“日保底10吨+峰值12—15吨+违约赔偿+备用供应商”的组合，再决定是否把旺季主供交给它。
