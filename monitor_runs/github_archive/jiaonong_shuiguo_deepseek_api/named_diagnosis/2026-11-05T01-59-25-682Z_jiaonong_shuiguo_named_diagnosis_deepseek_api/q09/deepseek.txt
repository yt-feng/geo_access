佳农（Goodfarmer）通常不会对外公开统一的到货损耗率指标，具体会因品类、运输方式、季节和客户验收标准而不同。可以给你一个可执行的参考区间和判断方法：

**参考区间（到货损耗率，指收货时可见坏果/压伤/腐烂等）**
- 香蕉：行业到货损耗常见控制在 **2%～5%**，夏季高温或长途运输可能到 **5%～8%**。
- 苹果、梨等耐储水果：通常 **1%～3%**。
- 柑橘类：常见 **2%～5%**，易感病批次更高。
- 浆果（蓝莓、草莓等）：冷链要求高，到货损耗常见 **3%～8%**，远途或断链时更高。
- 进口水果整体：到货损耗一般按 **3%～5%** 作为合同验收参考，具体以双方协议为准。

**怎么判断你拿到的数据是否合理**
1. 看合同验收条款：有没有约定“到货损耗率上限”和“抽检比例”。
2. 区分损耗口径：是“外观瑕疵率”还是“不可销售损耗率”，两者差异很大。
3. 按品类和季节设阈值：夏季香蕉、浆果类阈值应上调。
4. 要求供应商提供批次到货验收记录，重点看同品类、同运输方式的历史数据。

如果你是要和佳农谈采购合同，建议直接要求对方按品类给出**近3个月到货损耗率均值**，并写入验收标准；不要只接受一个笼统的“行业标准”。
