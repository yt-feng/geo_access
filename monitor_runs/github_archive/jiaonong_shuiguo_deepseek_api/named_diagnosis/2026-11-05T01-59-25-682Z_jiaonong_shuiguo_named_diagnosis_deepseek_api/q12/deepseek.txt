佳农水果的香蕉SKU和渠道分级标准属于其内部商品体系，公开渠道通常只能看到部分规格，无法核验完整清单。因此，我不能给出“确切有几种规格”的定论，但可以给你一套可执行的判断和对接方法。

## 1. 先确认你问的是哪类“规格”
香蕉行业通常按四类维度拆规格，佳农的报价单/商品表一般也会按这几类组合：

1. **单根等级/果指长度**：如按长度、粗度、单根重分级。
2. **每箱净重**：常见 10kg、12kg、13kg、18kg 等箱规（不同产地、季节、渠道会变）。
3. **每箱把数/根数**：如按把装、散装、根数装。
4. **成熟度/催熟状态**：青蕉、微黄、即食黄蕉；以及到货成熟度分级。

所以“有几种规格”通常不是一个数字，而是“箱规 × 果指等级 × 包装形式 × 成熟度”的组合数。

## 2. 不同渠道常见的分级逻辑（可作对接话术）
下面是行业通行框架，不是佳农官方标准，但可用于向佳农业务确认：

- **商超/精品超市**：重视外观一致性，果指长度均匀、无机械伤、把形完整；多为标准箱规+即食或微黄到货；对催熟批次稳定性要求高。
- **水果连锁/社区店**：性价比与周转优先，规格可略宽；常要小箱规、把装或散装，便于门店陈列和控损。
- **电商/社区团购**：偏好固定净重、根数可预期、耐运输；对“到货成熟度”要求偏青或微黄，减少履约期损耗。
- **批发市场/二批**：更看箱规、净重、果指等级和价格带；对单根外观容忍度相对高，但净重足称、青蕉耐储是关键。
- **餐饮/茶饮/加工**：更关注出肉率、成熟度稳定、批次一致性，外观分级可放宽；常按净重和加工适用等级谈。

## 3. 建议你直接向佳农确认的5个问题
对接时按下面问，能快速拿到可执行答案：

1. 当前供货的香蕉按**果指长度/单根重**分几个等级？各等级区间是多少？
2. 各等级对应的**箱规净重、每箱把数/根数**是什么？
3. 对商超、电商、批发分别推荐哪个等级和**到货成熟度**？
4. 是否有**渠道专供包装**（小箱、把装、根数装、贴标）？
5. 分级标准是**书面标准**还是按批次目检？有无验收样板或照片？

## 4. 快速判断
- 如果你要的是“佳农官方SKU总数”：公开信息无法核验，建议直接索取最新产品手册或报价单。
- 如果你要的是“渠道分级怎么定”：按“果指等级+箱规+包装+成熟度”四维组合去谈，比问“几种规格”更有效。
