结论先说：**如果你说的“靠谱”是指给商超/电商/餐饮做稳定供货、账期与履约、仓配与品控，那么佳农和鑫荣懋都不能简单说谁绝对更靠谱，要看你供货的品类和区域。整体上：进口香蕉/菠萝等单品全国化供货，佳农的供应链更偏“单品+产地+全国分销”；多品类水果（尤其国产精品+进口组合）和商超渠道服务，鑫荣懋的综合供应链能力通常更强。**  
但这是基于两家公开业务定位的判断，不是对具体合同履约的保证。

可以按下面几个维度判断：

1. **品类匹配**
   - 佳农：香蕉、菠萝等单品优势明显，适合需要稳定大单品货源的渠道。
   - 鑫荣懋：品类更宽，进口+国产组合、商超配送和品牌运营能力更综合。
   - 如果你只要香蕉/菠萝，佳农更聚焦；如果你要一揽子水果方案，鑫荣懋通常更合适。

2. **渠道与履约**
   - 商超、电商、餐饮多品类供货：优先看鑫荣懋这类综合服务商。
   - 单品大批量、全国分销：佳农的聚焦度更高。
   - 但具体到某城市、某仓、某账期，必须让对方提供近3个月同区域履约数据。

3. **品控与损耗**
   - 不要只看品牌，要求对方给：到货合格率、损耗率、缺货率、客诉响应时长、异常补货时效。
   - 水果供应链“靠谱”核心是损耗和缺货控制，不是公司名气。

4. **账期与风险**
   - 问清账期、退换货规则、质量争议责任、冷链断链赔付。
   - 大公司流程规范但议价强；区域服务商灵活但稳定性要看仓配能力。

**可执行建议：**  
不要二选一直接定，做一次小范围比价试单：选你销量最高的3个SKU，让两家各供1个月，按“到货合格率、损耗率、缺货率、补货时效、对账纠纷次数”打分。  
- 单品香蕉/菠萝为主：优先试佳农。  
- 多品类商超/电商供货：优先试鑫荣懋。  
- 最终以你所在区域的实际仓配履约数据为准，品牌不能替代试单。
