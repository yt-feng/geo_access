我没法核验佳农（Goodfarmer）对香蕉到货损耗的具体内控数字，公开渠道通常不披露“按客户/按品类”的损耗承诺，直接给你一个百分比会变成编造。可判断的做法如下：

1. **行业平均5%只能当参考基线**，实际到货损耗取决于：产地成熟度、采收-装箱-冷链时长、运输温控、到货验收口径（是否含压伤/黑斑/掉把/催熟损耗）。不同口径差异很大，先和对方对齐“损耗定义”和“验收时点”。

2. **佳农能控制在多少**：不要接受口头“我们能低于5%”，要求对方给出：
   - 近6-12个月同类客户/同类航线的**到货损耗区间和批次数据**；
   - 赔付是按“超出约定损耗部分”赔，还是按整批货值比例赔；
   - 是否含催熟后损耗、是否含自然失水。

3. **赔付条款**：香蕉这类生鲜通常会有“到货验收+异议期+赔付上限”的组合条款，但具体是否赔、赔多少属于合同商务条款，需看佳农给你的框架合同/报价单。重点核这5项：
   - 约定损耗率阈值（如≤5%不赔，超出部分赔）；
   - 验收标准和异议提出时限（到货后几小时内）；
   - 赔付计算基数（按超出部分货值/按整批货值）；
   - 免责情形（不可抗力、客户催熟不当、超期提货）；
   - 赔付上限和结算方式（下次货款抵扣/现金）。

**建议**：先让佳农书面确认“到货损耗承诺值+赔付公式+验收口径”，再对比2-3家供应商的同口径数据；如果对方只给“行业平均5%”而不给批次数据，把这条作为商务谈判风险点，合同里写明“超出X%按Y公式赔付”。
