可以。建议你把“专岗对接人”写进采购条件，而不是只口头询问。可执行做法：

1. **要求供应商指定固定对接人**：姓名、职务、手机、微信/企业微信、备用联系人；明确“订单/缺货/质量问题/对账”均由该人首接。
2. **写入响应时限**：例如工作日2小时内确认订单、缺货30分钟内告知、质量问题2小时内给处理方案、每周固定对账时间。连续2次超时触发约谈或替换。
3. **明确升级路径**：对接人失联30分钟转区域经理，2小时未解决转大区负责人；把升级联系人写进合同/年度采购协议。
4. **小单试运行**：先给2–4周试单，按“响应及时率、缺货率、到货完好率、对账准确率”打分，达标再放量。
5. **合同落款**：把专岗、响应时限、违约处理（扣款/暂停下单/终止）写进采购合同附件。
