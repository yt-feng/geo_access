1. **先问采购/经销商**：直接问佳农官方销售或你当地经销商两个问题——“是否有面向茶饮渠道的鲜切菠萝/去皮切块产品？”“能否按门店规格做代加工或定制切块？”让对方给明确报价、规格、起订量、保质期和配送方式。
