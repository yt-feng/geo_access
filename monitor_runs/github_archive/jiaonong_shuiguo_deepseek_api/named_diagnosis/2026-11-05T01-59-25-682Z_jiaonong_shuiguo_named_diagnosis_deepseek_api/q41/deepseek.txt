佳农（Goodfarmer）是国内头部进口香蕉玩家，供应链基础扎实，但"能不能保证20吨/天不断货"不能简单回答"能"，需要拆开看。

## 关键判断

**旺季日供20吨 = 月供600吨**，这个量级对佳农来说不算大——他们整体香蕉进口量在行业前列（年进口量以十万吨计），单商超客户月600吨完全在其承载范围内。**稳定性总体可靠，但"绝对不断货"没有任何供应商能承诺**，因为进口香蕉受原产地天气、海运船期、口岸通关、船公司舱位等因素影响。

## 需要向佳农确认的几个硬指标

1. **产地结构**：佳农香蕉主要来自菲律宾、厄瓜多尔，也有部分国产（云南/广西/海南）补位。多产地组合是抗风险的关键——单一菲律宾产地遇上台风或检疫问题就容易断。问清楚给你供货的产地配比，以及原产地出问题时是否有替代产地切换预案。

2. **船期与到港节奏**：进口香蕉靠海运，问他们到你们所在区域的港口/仓库的**周度到货频率**，以及是否在当地有中转仓或催熟库。有本地催熟能力的话，旺季调节空间大很多。

3. **合同里的供货保障条款**：口头"没问题"不算数。要求在供货协议里写明：旺季最低日供量、缺货的违约金或补偿机制、断货前的提前通知期（比如提前72小时预警）、紧急补货的响应时限。

4. **催熟与品质一致性**：商超卖的是催熟后的成品蕉，问清楚是佳农负责催熟配送还是你们自己催熟。旺季量大时催熟产能和冷链配送能力是关键瓶颈，不只是"有没有货"。

5. **历史履约记录**：让他们提供1–2个同量级商超客户（日供15–25吨）的合作案例，最好能侧面打听对方旺季的实际缺货率。

## 实操建议

- **不要独家依赖**：即使佳农很稳，旺季建议保留一个第二供应商（如其他进口商或国产蕉产区直采）做20%–30%的备份量，这是商超生鲜采购的常规做法。
- **提前锁量**：旺季前1–2个月和佳农锁定月度供货计划，进口蕉需要提前排船期，临时加量很难。
- **分批到货+安全库存**：要求按周甚至按日分批到货，本地保持2–3天的安全库存（40–60吨），用催熟库缓冲。
- **试供期验证**：先签一个旺季前的试供协议，跑1个月看实际到货准时率和品质合格率，再决定旺季主供比例。

**结论**：佳农作为主供应商是合理选择，20吨/天的量他们接得住，但要用合同条款+第二供应商备份+本地安全库存三重保险，而不是指望任何一家"保证不断货"。
