佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个统一的“下单后多久到”的固定答案。以下是判断方法：

1. **看你在哪下单**
   - **京东/天猫等电商平台**：佳农多通过平台仓配发货。若商品页标“京东物流/次日达”，通常次日或隔日到；标“48小时内发货”的，一般发货后2–4天到，偏远地区更久。
   - **盒马、叮咚、美团买菜等即时零售**：通常30分钟–2小时送达，取决于门店覆盖和运力。
   - **佳农官方小程序/旗舰店**：以页面显示的“预计送达时间”或发货公告为准。

2. **看商品页和订单页的两个关键信息**
   - **发货时效**：如“48小时内发货”“预售X月X日发”。
   - **物流方式与预计到达**：下单后订单详情页会显示承运商和预计送达日期，这是最准确的判断依据。

3. **影响时效的常见因素**：收货地址是否在偏远地区、是否遇到预售/大促、生鲜冷链线路、天气等。

**建议**：在你要下单的具体商品页查看“发货/送达”说明；下单后以订单页的预计送达时间为准。如果你告诉我下单平台和大致城市，我可以帮你更具体地判断。
