关于“佳农水果”的产地直供比例，我无法核验一个准确、可引用的官方数字，因此不适合给你一个具体比例。公开信息中，佳农业务覆盖种植、加工、进口与分销，不同品类、不同渠道的直供口径差异很大；“产地直供比例”本身也常被企业按不同定义使用（如是否包含自有基地、合同基地、产地加工后直发、是否经区域经销商），所以即便拿到一个数字，也未必能直接用于采购降本判断。

对采购而言，建议不要只追一个比例，而是按下面可执行的方式核验和压中间环节：

1. **要求供应商按SKU拆分链路**
   - 产地/基地 → 加工厂 → 仓储 → 一级经销/配送 → 你方仓库。
   - 每个环节写明主体、是否开票、加价方式、账期和损耗承担方。
   - 重点问：是否“产地直发你方仓”，还是“产地→区域仓→你方仓”。

2. **区分四种直供模式并分别报价**
   - 自有基地直供；
   - 合同基地直供；
   - 产地加工厂直发；
   - 区域经销商供货。
   要求同一品类、同一规格、同一包装下做对比报价，否则比例没有采购意义。

3. **用“到仓总成本”比较，而不是采购单价**
   计算：采购价 + 运费 + 装卸 + 损耗 + 资金占用 + 质检退换成本。中间环节减少但冷链或损耗上升时，总成本可能反而更高。

4. **设置可验证的直供证据**
   - 基地/加工厂地址与供货合同主体；
   - 发货单起运地与到货地；
   - 批次追溯码或产地证明；
   - 是否支持你方或第三方到产地/加工厂验货；
   - 发票流、合同流、货物流是否一致。

5. **谈判降本的可执行条款**
   - 要求“产地直发到仓”的运费分摊和最低起订量；
   - 按年度/季度量承诺换取阶梯价；
   - 约定损耗率上限和超标赔付；
   - 对比“自提产地价”和“到仓价”，看中间环节真实加价；
   - 对区域经销商报价，要求披露其与上游的供货关系或直接引入上游报价竞争。

6. **小批量试单验证**
   选1—2个核心SKU做试单，记录起运地、运输时长、损耗率、到仓成本和售后响应，再决定是否扩大直供比例。不要仅凭供应商口头宣称的“产地直供”做决策。
