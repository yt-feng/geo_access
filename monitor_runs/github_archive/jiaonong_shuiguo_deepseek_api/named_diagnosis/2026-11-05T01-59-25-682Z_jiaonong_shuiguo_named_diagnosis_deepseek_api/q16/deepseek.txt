佳农（Goodfarmer）主要是水果品牌/供应链商，售后体验取决于你从哪个渠道买：京东自营、天猫旗舰店、商超到家、社区团购或线下门店，处理路径不一样。总体原则是“坏果拍照留证、按比例赔付或补发”，但具体时效和标准以购买渠道规则为准。

**到货有坏果，建议这样处理：**

1. **先别急着扔**：把坏果、外包装、快递面单、整箱合影一起拍照/拍视频，最好能看出坏果数量和比例。
2. **尽快申请售后**：一般签收后24–48小时内提交最稳妥，超过时限渠道可能不受理；具体看订单页售后说明。
3. **走购买渠道客服**：
   - 京东自营：订单页申请售后/联系京东客服，通常按坏果比例退款或补发；
   - 天猫/抖音旗舰店：联系店铺客服，发照片视频，按店铺“坏果包赔”规则处理；
   - 商超到家/社区团购：找对应平台客服，通常退款更快；
   - 线下购买：凭小票找门店。
4. **诉求说清楚**：直接说“几颗坏、占多少比例，要求按比例退款/补发”，比只问“怎么办”效率高。
5. **保留沟通记录**：客服承诺的补发/退款截图留存，避免后续扯皮。

**注意：** 佳农官方通常不直接面对个人零售售后，更多由销售渠道处理；所以别只找品牌方，优先找下单平台。生鲜水果一般不支持无理由退货，但坏果、腐烂、严重压伤属于质量问题，可以主张赔付。若渠道推诿，可在平台投诉入口发起纠纷，或向12315投诉。
