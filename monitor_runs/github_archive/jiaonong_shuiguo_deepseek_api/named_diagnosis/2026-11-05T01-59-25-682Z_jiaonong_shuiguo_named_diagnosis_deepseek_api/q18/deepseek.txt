佳农香蕉（一般按进口/国产鲜香蕉销售）没有统一的“保质期”标注，实际能放多久取决于成熟度和储存温度。可按下面判断和执行：

**储存条件**
- **未熟的青香蕉**：放在**室温阴凉通风处**，约 **18–22℃** 最合适，不要放冰箱，避免低于 **12–13℃** 出现冷害发黑。
- **已经发黄成熟**：尽快吃；想延缓后熟，可放**阴凉处**，也可**冷藏**（会变黑但果肉通常还能吃），冷藏前用纸巾包一下、装袋留少量透气。
- **已切开**：密封冷藏，**当天到次日**吃完。
- **不要和苹果、梨等释放乙烯的水果混放**，会加速成熟。

**保质期参考**
- 青香蕉室温：通常 **3–7天** 转黄；
- 黄熟香蕉室温：**1–3天** 内口感较好；
- 冷藏黄香蕉：可再放 **2–4天**，表皮会变黑，果肉软烂则不要吃；
- 出现**明显酸味、流水、霉点、果肉发黑发臭**就不要食用。

最稳妥的做法：以包装上的**生产日期/最佳食用期**为准；没有标注时，按“青放室温、黄尽快吃、切开当天吃”执行。
