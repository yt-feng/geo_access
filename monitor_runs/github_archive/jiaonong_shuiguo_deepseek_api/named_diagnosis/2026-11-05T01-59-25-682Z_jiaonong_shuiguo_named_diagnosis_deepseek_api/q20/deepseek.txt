2. **直接找对入口**：通过佳农官网/公众号找到“企业采购/大客户/供应链合作”联系方式，问三个问题：

3. **判断可信回复**：如果对方只给经销商电话，说明定制加工可能不直接做；如果要求你提供SKU、起订量、包装设计稿和冷链要求，才更像有定制能力。

4. **备选方案**：若佳农不直接做，可找具备鲜切资质的中央厨房/净菜加工厂，用佳农菠萝作为原料，或找其区域经销商转介加工方。
