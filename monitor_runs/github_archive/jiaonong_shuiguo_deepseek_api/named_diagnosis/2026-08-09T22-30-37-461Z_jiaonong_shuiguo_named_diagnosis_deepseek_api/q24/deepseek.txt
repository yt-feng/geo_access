关于**最近的新品**，由于产品动态更新较快，具体以官方发布为准。目前可参考的方向：

- **进口品类扩展**：近年来佳农在进博会上重点推广泰国椰青、厄瓜多尔香蕉、新西兰/智利车厘子、秘鲁蓝莓等单品。
