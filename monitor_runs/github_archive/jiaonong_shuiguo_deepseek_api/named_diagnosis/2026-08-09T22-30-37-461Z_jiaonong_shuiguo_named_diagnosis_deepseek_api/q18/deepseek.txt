关于佳农香蕉的保质期和储存条件，以下是具体建议：

**保质期（一般情况）**
- **未开封（原包装）**：在常温下，一般可保存3-7天（视环境温度和成熟度而定，通常佳农香蕉上市时多为7-8成熟）。
- **已开封/剥皮**：建议在1-2天内食用完，剥皮后需冷藏并用保鲜膜包裹，避免氧化变黑。

**储存条件**
- **最佳常温储存**：温度15-25℃，阴凉、通风、干燥处，避免阳光直射。香蕉是后熟水果，常温下会继续成熟。
- **冷藏保存**：若香蕉已完全成熟（表皮出现黑斑），可放入冰箱冷藏（4-8℃）。但注意，低温会使香蕉表皮变黑（冷害），这是正常现象，不代表内部变质，果肉仍可食用。冷藏可延长保质期2-4天。
- **避免**：不要与苹果、梨等同放（它们释放乙烯促进催熟）；不要密封在塑料袋中（易导致霉菌生长）。

**判断变质**
- 果肉变软、有酒精味或霉变、果皮大面积发黑且有黏液，则不宜食用。

如需更精确的保存时间，请以产品包装上的“生产日期/保质期”标签为准，并注意购买时的成熟度。储存条件相同，品牌间差异不大。
