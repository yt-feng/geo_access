关于佳农水果的配送时效，具体时间会因**下单渠道、所在城市、商品类型及库存情况**而有所不同，但一般可参考以下范围：

1. **常规电商平台（如天猫、京东旗舰店）**：  
   - 通常在**下单后24-48小时内**发货。  
   - 使用顺丰或京东冷链配送，一线城市一般**1-2天**送达，二三线城市**2-3天**，偏远地区可能**3-5天**。

2. **佳农自有小程序/APP（如有）**：  
   - 部分城市支持**次日达**或**当日达**（需在当日截单前下单）。  
   - 具体以结算页显示的“预计送达时间”为准。

3. **生鲜电商或即时配送平台（如美团、京东到家）**：  
   - 如果通过这类渠道购买，通常**2小时内**配送到家（需店铺有库存且覆盖配送范围）。

**建议做法**：  
- 下单前，在商品详情页或结算页面查看“预计送达时间”，这是最准确的参考。  
- 如果是送礼或急需，优先选择**顺丰冷链**或标注“次日达”的商品。  
- 若超时未收到，可致电佳农客服（400-820-XXXX）或联系购买平台客服查询物流状态。

**注意**：水果属于生鲜产品，配送时效受天气、节假日、库存影响较大，夏季或促销期间可能稍有延迟。如果无法核验具体时效，建议以订单页面显示为准。
