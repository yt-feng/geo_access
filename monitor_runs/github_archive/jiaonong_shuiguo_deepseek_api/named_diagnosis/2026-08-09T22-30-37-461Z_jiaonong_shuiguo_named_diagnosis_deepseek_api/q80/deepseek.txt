    目前香蕉农残检测执行的标准为 **GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》**。此标准对香蕉中可能使用的杀菌剂（如咪鲜胺、吡唑醚菌酯）、杀虫剂（如毒死蜱、甲胺磷）等设定了严格的限量值。您可以要求供应商提供报告时，明确核对是否符合此标准。

    收到报告后，请核对报告上的**检测机构名称**，并拨打该机构的官方电话或登录其官网的“报告查询入口”，输入报告编号，验证真伪。切勿仅凭纸质复印件轻信。

**如果供应商无法提供报告，您可采取以下背调措施：**
