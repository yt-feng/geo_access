关于香蕉到货损耗率及佳农的赔付情况，由于我无法实时查询该企业最新内部数据或合同条款，以下信息基于行业常识和公开信息整理，供您参考：

1. **行业平均损耗率**：您提到的5%是行业普遍参考值，但在实际运输中，香蕉属于高损耗品类，受温度、湿度、运输时长影响很大，行业实际波动常在3%-8%之间。

2. **佳农的损耗控制**：佳农作为国内头部香蕉进口商和分销商，其冷链管理和分拣标准通常优于行业平均。但**公开渠道未披露其具体损耗率数字**，且该数据会因采购地（如菲律宾、厄瓜多尔）、季节、到货港口不同而差异明显。若您是在与经销商/批发商洽谈，可要求对方提供近3个月的单批次到货损耗记录作为参考。

3. **赔付条款**：
   - **出厂/经销环节**：佳农与下游经销商（如批发市场大客户、商超）的合同中，**通常会对到货水分流失、黑斑、腐烂等设置“到货残损率”理赔阈值**，常见做法是超过约定比例（如3%-5%）后按超出部分赔付或折价。
   - **终端零售环节**：您在超市/电商购买的个人售后，通常遵循“坏果包赔”政策，但一般以收货后24小时内的烂果照片为凭证，单笔订单赔付，不针对整批货。
   - **需注意**：赔付条款必须写进合同或订货单备注，口头承诺无效。且不同业务渠道（一级批发、商超直供、电商代发）条款差异大，您需明确自己的合作身份。

**建议**：若您需精确数据，最稳妥的方式是直接联系佳农区域销售或客服，索取《产品质量与到货补偿协议》样本，同时索取其最近一次对您所在市场的《批次验收标准》。
