关于佳农水果（Goodfarmer）香蕉的具体规格和分级标准，目前公开渠道（如官网、公开新闻、电商页面）并没有统一发布的正式文件。不同包装、不同销售渠道（商超、电商、批发市场、餐饮）的实际规格可能由采购方、经销商或特定订单决定。

不过，我可以根据行业常见的香蕉分级逻辑和佳农在不同渠道的常见做法，给您一个通用的参考框架（非官方数据，仅供判断）：

**一、佳农香蕉常见的“规格”类型（按箱重或单根克重）**

1.  **按箱规**：市面上常见佳农香蕉的包装规格包括：
    *   **小箱装（电商/零售）**：通常为4.5kg（9斤）或5kg（10斤）整箱，适合家庭囤货或生鲜电商。
    *   **中箱装（商超/精品超市）**：常见为6kg（12斤）或10kg（20斤）装，用于货架陈列或配送到商超后分装。
    *   **大箱装（批发/餐饮/团购）**：常见为13.5kg（27斤）或15kg（30斤）标准出口香蕉箱，主要用于批发市场、大型食堂或餐饮连锁。

2.  **按单根重量（果指规格）**：
    *   **大果**：单根带皮重约150克-200克，果肉饱满，适合零售高价包装。
    *   **中果**：单根带皮重约120克-150克，性价比较高，是中端渠道主流。
    *   **小果/次果**：单根低于120克，通常用于榨汁、烘焙或散装低价处理。

**二、不同渠道的分级标准（行业通行做法，佳农大致遵循）**

分级主要依据**果指长度、果径粗度、果面完整度、成熟度（色卡）** 四个维度：

1.  **商超/高端精品超市（如盒马、山姆、ole'）**：
    *   **外观标准**：要求果形笔直，无青头、无疤、无黑斑，色泽均匀金黄（七成熟至八成熟）。
    *   **长度标准**：通常要求果指长度在18-22厘米以上（俗称“长果”或“超长果”），且整把大小均匀。
    *   **包装**：多为独立小包装或塑料托盘加保鲜膜，强调卖相。

2.  **生鲜电商/社区团购（如叮咚、美团优选）**：
    *   **标准**：会适当放宽外观要求，但必须保证无严重磕碰、无腐烂。
    *   **规格**：通常以“中果”为主（单根130-160克），整箱发货，强调新鲜度和价格优势。
    *   **成熟度**：通常发7成熟（偏硬）货，便于运输，让用户在家自然熟。

3.  **餐饮/商用渠道（奶茶店、果切店、烘焙坊）**：
    *   **核心指标**：果肉出成率（出肉多）、甜度高、软糯。对外观疤痕要求相对较低。
    *   **特色**：更多采购“大果”或“特选果”，因为单根大，切片或打泥效率高，损耗小。

4.  **批发市场/二级分销**：
    *   **标准**：通常只需达到基本等级（无大面积腐烂、无冻伤），按箱价批发，规格不固定，以走量为主。

**三、如何获取佳农特定规格的准确信息**

由于公开资料有限，建议您通过以下方式获取最准确的分级：

1.  **联系官方客服/销售**：直接致电佳农官方或联系其大宗业务部门，询问“针对XX渠道（如社区团购）的香蕉分级标准”。
2.  **查看实际包装**：佳农的纸箱上通常会印有“XX kg”字样，以及是否有“指定采摘日”或“果指长度”的标识（部分出口级货会有）。
