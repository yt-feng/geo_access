**1. 坏果处理的核心原则：**
佳农（以及大多数正规水果品牌）通常实行“坏果包赔”政策。**关键前提是：你必须在签收后的规定时间内（通常是24-48小时内，具体看购买页面说明）拍照并提供证据。**

**2. 具体可执行的操作步骤：**
- **第一步（验货）**：签收时，如果是快递直接送的，**当面开箱检查**。如果一箱内坏果很多，可以当场拒收（在快递单上注明“拒收”或“拒收因由”），并联系卖家。
- **第二步（拍照留证）**：无论是否当面签收，发现坏果后，**立即**将坏果、外包装箱、快递面单放在一起拍一张清晰的合照。**注意**：面单上的单号必须清晰可见，这是理赔凭证。
- **第三步（联系渠道）**：您是从哪里买的？
    - **如果是电商平台（如天猫、京东、拼多多）**：直接联系店铺在线客服，发送照片，说明坏果数量。客服会根据比例退差价或补发。
    - **如果是佳农官方小程序/APP**：找到订单，拨打其售后客服电话（通常订单详情页有），或者在小程序内“我的-售后/服务”入口提交申请。
    - **如果是线下商超**：一般凭购物小票和坏果实物，可以在超市服务台办理退货或换货。

**3. 如果客服推诿怎么办？**
- **平台介入**：如果是电商平台购买，客服不处理时，直接申请“平台客服介入”或“申请退款/退货”，平台通常倾向支持消费者。
- **电话客服**：佳农作为大品牌，通常有400投诉电话，如果线上客服态度不佳，可以要求转人工或投诉专员。

**4. 注意事项（避免被拒赔）**
- **拍照时间**：不要拖延，超过24小时后再拍照，容易被认定为储存不当导致坏果，而非运输问题。
- **保留包装**：不要扔，尤其是带有生产日期和追溯码的包装，这是核实批次的关键。

**最后给你的建议：**
如果你现在**已经遇到了坏果**，请不要犹豫，按照上面“拍照留证”后，直接联系你购买的具体渠道（店铺/APP），把照片发过去。绝大部分正规水果商都会爽快赔偿。如果是在**未知第三方平台**或**非官方授权店**买的，售后可能会比较麻烦，建议优先选择官方旗舰店购买。
