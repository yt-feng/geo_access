关于佳农水果的苹果品类，**佳农（Goodfarmer）** 确实有销售红富士苹果，其产品线中常包括国产红富士（如山东栖霞、陕西洛川等产区的）以及部分进口品种（如新西兰爱妃、爵士等），但**红富士是它常规供应的品类之一**。

至于**和鑫荣懋（Sunkist的国内运营方，主做进口水果）比哪个性价比高**，这需要结合具体购买渠道和单品来看，因为两者定位和供应链不同：

1. **品牌定位差异**：
   - **佳农**：主打全品类水果，国产和进口都有，价格区间较宽，促销活动多，走**大众性价比路线**。
   - **鑫荣懋**：更侧重高端进口水果（如智利车厘子、新西兰奇异果等），其苹果多以**进口品种**为主（如太平洋玫瑰、加力果等），价格通常偏高。

2. **红富士具体对比**：
   - **如果同样买国产红富士（比如山东烟台）**：佳农的零售价通常比鑫荣懋更便宜（例如盒马/京东上，佳农红富士约5-8元/斤，鑫荣懋若卖国产货则定价更高，因为它更少做国产基础款）。
   - **如果买进口红富士（如美国蛇果、新西兰红玫瑰）**：鑫荣懋品牌下有优势，但佳农也有同品类，价格相差不大，需看折扣。

3. **性价比判断建议**：
   - **追求日常口粮苹果**：选佳农的红富士更划算，因为国产红富士本身价格低，且佳农采购量大，成本控制好。
   - **追求特定产地或品种（如洛川、阿克苏冰糖心）**：建议直接找产地直发或当地品牌，比大商超更便宜。
   - **线上购买时**：直接对比同一平台（如京东生鲜、盒马）的同规格重量（比如5斤装）的到手价，通常佳农会便宜10%-20%。

**总结**：如果你是买普通红富士，**佳农性价比高于鑫荣懋**；若你买的是鑫荣懋特有的进口高端苹果，则不存在可比性，需按品质和口味偏好决定。建议购物时直接搜“佳农红富士”和“鑫荣懋红富士”看满减后的实际单价，最直观。
