您好！佳农确实有针对不同渠道的规格，但**小包装香蕉通常不是3kg装**，这个规格更多是商超或餐饮渠道的大包装。

针对您小面积便利店的需求，建议优先考虑以下**小规格**（一般500g-1.5kg之间）：

1. **佳农超甜蕉/国产香蕉**：常见有 **500g/袋** 或 **1kg/袋** 的挂装小包，适合散卖或整袋零售。
2. **果切/小包装果盘**（如有供货）：部分区域提供 **250g/300g** 的即时果切，保质期短但动销快。
3. **佳农蓝莓/小番茄等**：有 **125g/盒** 或 **250g/盒** 的杯装，适合冷柜陈列。

**建议操作：**
- 直接联系您所在城市的**佳农当地经销商**（可通过官网或微信公众号“佳农食品”查找区域负责人），说明“便利店小面积、需求小规格”，他们一般会提供订货目录。
- 如果3kg装是唯一可选，不建议整箱进货——香蕉熟得快，3kg约占1个果篮位置，小门店容易损耗。可改为**拿1箱（约15kg）拆散后按根或按斤零售**，成本更可控。
