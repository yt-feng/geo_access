公开渠道没有一个可核验的“佳农水果产地直供比例”统一数字。佳农业务线覆盖进口香蕉、菠萝、火龙果、车厘子等多品类，不同品类的采购模式差异很大，整体比例会随品类和年份变化，不建议直接采信某个网传百分比。

对你们采购降本更实际的做法是：

1. **先分清“直供”指什么**
   - 是佳农直接从海外/国内产地农场采购？
   - 还是佳农从产地经手贸易商再供给你们？
   - 还是你们想绕过佳农，直接对接产地？
   这三种口径的成本结构完全不同。

2. **要求佳农提供品类级溯源信息**
   针对你们要采购的具体单品，要求其提供：
   - 产地/农场或合作基地
   - 是否自有或包销基地
   - 进口还是国产
   - 报关/港口/一级批发等环节
   这样能判断中间有几层。

3. **用报价拆解来压中间环节**
   让供应商按“产地成本 + 物流/冷链 + 关税/损耗 + 服务费”拆报价，而不是只给一个到岸价或批发价。重点看：
   - 是否有多级贸易商加价
   - 冷链和损耗是否合理
   - 账期、退换货、分拣包装是否额外收费

4. **小批量试单验证**
   选1—2个单品做试单，对比：
   - 佳农直采报价
   - 产地贸易商报价
   - 一级批发市场报价
   用实际到货成本、损耗率和履约稳定性判断，而不是只看名义采购价。

5. **如果目标是最大程度减少中间环节**
   可以考虑：
   - 对进口单品，直接对接海外出口商或国内一手进口商
   - 对国产单品，对接产地合作社或大型基地
   - 与佳农谈“基地直发”或“定制包销”，但通常需要起订量和稳定采购量
   佳农的优势在品控、冷链和稳定供应，完全绕开它不一定总成本最低。

**结论**：佳农的产地直供比例没有可靠公开数据可直接引用；建议你们按具体单品向佳农索取溯源和报价拆解，并用试单对比实际到货成本，再决定是继续通过佳农采购还是部分绕开中间环节。
