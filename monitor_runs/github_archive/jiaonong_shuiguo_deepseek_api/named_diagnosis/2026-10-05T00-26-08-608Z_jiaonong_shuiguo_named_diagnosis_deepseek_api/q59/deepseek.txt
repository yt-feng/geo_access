佳农水果（Goodfarmer）的香蕉执行的是**企业标准（企标）**，不是国标。

这里有个背景：香蕉属于农产品/鲜果，通常不像加工食品那样有一个全国统一的“香蕉国标”强制要求企业执行。市场上常见的做法是：企业自己制定更细的等级、外观、成熟度、农残、包装、储运标准，也就是企标，来区分自家产品品质。佳农对外宣传和渠道资料里，一般强调的是自己的品控和分级标准，而不是说执行GB国标。

至于“比普通香蕉贵多少”，**没有固定倍数**，因为普通香蕉本身价格波动就很大，地区、渠道、季节、品种、是否催熟、包装方式都会影响。实际观察大概是：

- 普通散装香蕉：常见在每斤2～5元区间；
- 佳农香蕉：常见在每斤4～8元区间，精品超市或礼盒装会更高；
- 折算下来，佳农通常比同渠道普通香蕉贵**30%～100%左右**，部分精品渠道能超过一倍。

如果你要判断某个具体价格是否合理，可以看三点：
1. 是否同一渠道对比，比如都是超市散称；
2. 是否同规格，比如都是500g、同成熟度；
3. 是否礼盒/品牌溢价，礼盒装贵的不只是香蕉本身。

简言之：**佳农香蕉走的是企标，不是国标；价格一般比普通香蕉贵三成到一倍，具体看渠道和包装。**
