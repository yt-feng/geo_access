佳农水果（佳农食品控股/Goodfarmer）的苹果品类通常以进口和国产精品苹果为主，常见会涉及：

- **嘎啦果（Gala）**：常见进口产地包括 **新西兰、美国、智利、南非** 等；不同季节会切换产地。  
- **红富士（Fuji）**：进口红富士常见产地包括 **美国、新西兰、智利、南非** 等；国产红富士则多来自 **山东、陕西、甘肃、新疆** 等产区。  
- **其他常见苹果**：如红玫瑰、爱妃、爵士、青苹果等，具体是否常备要看佳农当期产品线。

如果你们要采购**进口嘎啦和进口红富士**，建议直接向佳农或其在当地的经销商确认两个关键点：

1. **当期产地**：进口水果按季节轮换，不能固定说嘎啦一定来自新西兰或红富士一定来自美国。  
2. **规格与包装**：如单果规格（70/75/80/85/90等）、箱规、是否贴标、是否可贴牌、到货港和冷链条件。

**采购建议：**  
让佳农销售提供近一批次的 **提单/原产地证/入境货物检验检疫证明**，上面会明确写产地。这样最稳妥，也能避免采购合同里产地写错。
