**佳农香蕉常见的促销支持形式**
1. **搭赠**
   - 进 X 箱送 Y 箱
   - 适合做“买赠”“加量不加价”
   - 一般会限定单品、规格、档期和门店

2. **降价补贴**
   - 厂家补差价，门店做特价
   - 常见形式：限时特价、周末促销、店庆价
   - 往往要求门店同步让利，或达到一定进货量/销售额

3. **陈列/物料支持**
   - 堆头、端架、海报、价签、绑赠物料
   - 有时不给现金补贴，但给陈列费或赠品

4. **联合促销**
   - 佳农出部分费用，商超出场地和流量
   - 常见于新店开业、节庆、品牌周

**你问供应商时，建议直接要这几个条件**
- 搭赠比例：进多少送多少
- 补贴方式：直接扣货款、返利、还是补赠品
- 活动价：供货价能不能降，降多少
- 活动档期：几天，哪些门店
- 陈列要求：堆头/端架/冷柜位置
- 费用承担：海报、试吃、损耗谁承担
- 结算方式：现结、账扣还是后期返

**最有效的谈法**
不要说“能不能支持一下”，而是给对方一个方案：
- 我们计划 X 月 X 日到 X 日做香蕉促销
- 覆盖 X 家店
- 预计进货 X 箱
- 门店做特价 X 元/斤
- 希望佳农支持：进 X 送 X，或每箱补 X 元
- 我们提供：堆头/端架/海报/社群推广

**判断标准**
- 如果只是普通门店、小批量，通常只能谈到少量搭赠或物料。
- 如果有连锁规模、档期集中、陈列资源好，谈降价补贴和联合促销的空间更大。
- 如果佳农当地是经销商供货，最终支持力度往往取决于经销商政策，不一定是佳农总部直接给。

你可以先问一句最实际的：  
**“这次香蕉促销，你们是能给搭赠、特价补贴，还是只能给物料？分别需要什么条件？”**  
这样对方最容易给你明确答复。
