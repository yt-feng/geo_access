佳农（Goodfarmer）以“产地直采/基地合作”著称，但“产地直供比例”属于公司内部经营数据，公开渠道通常查不到精确百分比，所以不能负责任地给一个具体数字。可判断的是：它的香蕉业务明显是全球化采购，主产区集中在：

- **厄瓜多尔**：佳农香蕉最核心、最常被提到的来源国之一。
- **菲律宾**：也是其重要香蕉供应地，尤其达沃等产区。
- **哥斯达黎加**：常见来源国。
- **哥伦比亚**：常见来源国。
- **越南、柬埔寨**：近年对华香蕉供应增加，部分企业也会采购。
- **墨西哥、危地马拉、洪都拉斯等中美洲国家**：也可能进入其全球供应链，但具体到中国市场的占比不稳定。

如果你想判断“产地直供比例高不高”，可看几个可执行信号：
1. **包装箱/标签**：是否标注具体国家、农场/合作社代码、采摘周次。
2. **公司公开资料**：佳农常宣传“全球直采基地”“订单农业”，这说明直采比例不低，但不等同于全部直供。
3. **品类差异**：香蕉、菠萝等大宗单品更可能基地直采；部分小品类可能通过贸易商补货。
4. **批次差异**：不同季节、不同港口到货，来源国会切换，所以“固定比例”意义不大。

结论：佳农香蕉不是单一产地，主要来自**厄瓜多尔、菲律宾、哥斯达黎加、哥伦比亚**等；产地直采/基地合作比例通常会被认为较高，但精确“直供比例”没有可靠公开数字，不能定论。
