佳农（佳农食品控股）主营香蕉、菠萝等水果的种植、进口和批发，通常以**整果或初加工果品**形式供货，**一般不直接提供面向茶饮门店的定制去皮切块加工服务**。不过具体能否做，取决于你对接的是哪一级渠道：

**可以这样判断和操作：**

1. **直接问对接的佳农销售/经销商**
   问清楚三点：
   - 是否支持“去皮切块”或“鲜切菠萝”规格；
   - 加工后是冷藏、冷冻还是糖水浸泡包装；
   - 最小起订量和配送周期。

2. **看渠道层级**
   - 佳农总部/大区：通常做整果、大宗批发，鲜切定制少；
   - 区域经销商或生鲜供应链商：可能提供鲜切、分装服务；
   - 第三方中央厨房/净菜加工厂：更可能承接这类门店用加工需求。

3. **茶饮店更现实的方案**
   - 买佳农整果，自己门店或中央厨房切；
   - 找本地鲜切水果供应商，指定用佳农菠萝；
   - 直接采购“鲜切菠萝/冷冻菠萝块”成品，省人工且出品稳定。

4. **注意成本和品质**
   鲜切菠萝易出水、发酵、变味，茶饮店要重点确认：
   - 冷链是否稳定；
   - 切块规格是否统一；
   - 保质期和到货状态；
   - 是否泡糖水或加保鲜处理。

**结论：** 佳农能否提供去皮切块，不能一概而论，大概率要看你对接的经销商或加工渠道；建议直接向对方要“鲜切菠萝”报价和规格，若没有，就找本地鲜切供应链或自己加工。
