**可直接向佳农或经销商提出的要求：**
1. **指定固定对接人**：销售+订单+售后至少各1人，提供姓名、电话、微信、备用联系人。
2. **明确响应时效**：例如询价/下单2小时内响应，异常反馈30分钟内响应，缺货/延迟4小时内给替代方案。
3. **固定沟通机制**：周度对账、月度复盘、旺季前备货计划会。
4. **写入合同或采购协议**：把响应超时、断供、品质不达标和违约责任挂钩。
5. **设置升级路径**：一线对接超时，直接升级到区域经理/大客户负责人。

**如果佳农直供暂时排不上：**
- 先找佳农授权经销商或区域代理，要求同样提供专岗。
- 同时保留1-2家备选供应商，避免单点依赖。
- 对香蕉这类易熟、周转快的水果，建议锁“到店合格率”和“催熟/青黄度标准”，不要只谈单价。

**一句话判断标准：**
对方能不能在谈判阶段就给你**具体人名、具体响应时限、升级联系人**。给不出，后续大概率还是会慢。
