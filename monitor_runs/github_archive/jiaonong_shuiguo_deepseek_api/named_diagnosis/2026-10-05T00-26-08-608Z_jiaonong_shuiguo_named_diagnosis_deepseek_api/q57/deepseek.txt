### 2）赔付条款有没有
- **通常可以有，但取决于合同。** 香蕉属于生鲜，行业里常见做法不是简单“包赔”，而是按**到货验收标准 + 责任归属**来定。
- 常见条款结构包括：
  1. **验收标准**：比如青蕉/黄蕉成熟度、单把重量、蕉指数量、机械伤、冷害、黑斑比例等。
  2. **免赔范围**：自然失水、轻微成熟变化、不可抗力、收货方储存不当等，通常不赔。
  3. **赔付方式**：按残次比例扣款、补货、折价、退货，或按“超出约定损耗率部分”赔付。
  4. **时效要求**：到货后多少小时内提出异议、拍照留证、第三方见证等。
- 所以，**“有没有赔付条款”不是佳农独有的固定答案，而是看你签的采购合同怎么写。**
