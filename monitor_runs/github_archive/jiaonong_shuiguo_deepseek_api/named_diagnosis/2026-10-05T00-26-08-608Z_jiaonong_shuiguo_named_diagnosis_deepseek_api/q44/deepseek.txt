我可以先直接说结论：**公开可核查的信息里，没有“佳农香蕉农残超标”的权威通报或处罚记录被广泛确认**；但这**不等于可以给超市出具“无农残超标”的合规证明**。你们采购要过超市抽检，核心不是查“品牌有没有黑历史”，而是让**这一批货**满足可追溯、可检测、可合规。

分开说：

**1）关于“历史超标”**
- 我无法凭空给你一个“佳农从未超标”的官方结论。
- 这类信息应以**市场监管总局/各地市场监管局抽检通告、海关退运/销毁通报、农业农村部门通报**为准。
- 如果佳农或其供应商被抽检不合格，通常会出现在上述官网的“食品安全监督抽检信息通告”里；但目前我无法核验到一条被权威公开确认的“佳农香蕉农残超标”记录。
- 所以对外别说“佳农保证没超标过”，只能说“未检索到被权威公开通报的不合格记录”，这更稳妥。

**2）超市抽检真正认什么**
超市/监管抽检看的是**当批次**，不是品牌历史。你要准备的合规材料通常是：
- **供应商资质**：营业执照、食品经营许可证。
- **产品合格证明**：出厂检验报告，或第三方检测报告（CMA/CNAS）。
- **检测项目**：香蕉重点看**吡虫啉、噻虫嗪、噻虫胺、苯醚甲环唑、丙环唑、百菌清、咪鲜胺**等；最好按**GB 2763《食品中农药最大残留限量》**对应香蕉的限量判定。
- **批次对应**：报告上的品名、批号/生产日期、规格、供应商必须和你们进的这批货一致，否则超市不认。
- **溯源凭证**：进货单、发票、产地/果园/包装厂信息、通关单（进口时）、检疫证明。
- **承诺书/质量保证协议**：供应商盖章，写明“符合GB 2763，若抽检不合格承担退换及赔偿”。

**3）给你们的可执行做法**
1. 找佳农或你们的上游经销商要：**该批次的第三方农残检测报告 + 出厂检验报告 + 资质 + 批次对应证明**。
2. 报告必须带**CMA章**，检测项目覆盖香蕉常用农药，判定依据写**GB 2763**。
3. 如果上游只给“年度报告”或“同品类报告”，要求补**本批次**报告；超市抽检只认对应批次。
4. 你们自己可做**入仓快检**：酶抑制率法先筛，阳性再送第三方定量复检。快检不能替代法定报告，但能降低风险。
5. 合同里写清：**农残超标则全额退货、承担检测费/罚款/下架损失**。
6. 留样：每批留**不少于1kg**，冷藏/冷冻保存到该批售罄后一段时间，便于复检。

**4）如果超市就是要“无农残超标证明”**
严格说，**没有任何供应商能出具“绝对无农残”的证明**，因为香蕉种植可能使用农药，合规指的是**不超GB 2763限量**。你能拿到的最强证明是：
- 本批次**第三方检测报告，结论为“所检项目符合GB 2763要求”**；
- 供应商**质量承诺函**；
- 完整**溯源链**。

**一句话建议**：别把重点放在“佳农有没有黑历史”，而要盯住**这一批货有没有CMA第三方报告、项目是否覆盖香蕉常用农残、批次是否对得上**。这三样齐了，超市抽检合规性基本就稳；缺批次报告，品牌再大也可能被卡。
