我无法核验佳农水果针对“年采购量1000吨以上客户”的具体优惠政策，这类政策通常属于企业未公开或会随品类、区域、合作周期、结算方式、履约条件变化的商务条款，直接给一个固定答案容易误导你。

更可执行的做法是：

1. **先明确你方的采购结构**
   - 年采购量1000吨是**单品类**还是**全品类合计**？
   - 主要品类：香蕉、菠萝、火龙果、苹果、柑橘等？
   - 是**全年均衡采购**，还是季节性集中采购？
   - 交货地、是否要冷链、是否到仓、账期多久？

2. **向佳农官方渠道要政策**
   建议直接联系：
   - 佳农官网/官方公众号的商务合作入口
   - 区域销售负责人
   - 大型商超/批发市场渠道经理
   - 如果你已有对接人，直接发正式询价函

3. **询价时重点问这几项**
   - 是否有**阶梯返利**：如500吨、1000吨、3000吨不同返点
   - 是否有**年度框架协议价**
   - 是否给**账期支持**：现款、30天、60天
   - 是否承担**运费/冷链费**
   - 是否给**市场推广费、陈列费、损耗补贴**
   - 是否保证**优先供货、稳定价格**
   - 返利是**月返、季返还是年返**
   - 返利按**采购额还是采购量**计算

4. **谈判时不要只问“优惠几个点”**
   1000吨级采购更值得谈的是：
   - 全年锁量锁价比例
   - 价格随行就市时的封顶机制
   - 破损/烂果赔付标准
   - 临时加单的响应时效
   - 账期和承兑贴息
   - 独家区域或渠道保护

5. **建议你这样发询价**
   > 我方预计年采购水果1000吨以上，品类包括XX，主要销往XX区域，结算方式可接受XX。希望了解年度框架合作政策，包括阶梯价、返利、账期、运费、损耗赔付和优先供货条件。请提供正式报价方案。
