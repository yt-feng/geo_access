佳农（佳农食品控股/佳农水果）主要做水果供应链和批发分销，配送能力通常分几类，不能简单用“覆盖哪些城市”一概而论：

1. **覆盖范围**
   - 佳农的全国性网络一般覆盖一二线城市、主要省会城市和部分经济较发达地级市。
   - 具体到县城，往往要看当地是否有佳农的经销商、批发市场档口、商超配送仓或合作冷链承运商。
   - 佳农更多是面向商超、生鲜店、批发商、电商仓等B端客户，不是像快递一样直接承诺“全国每县都送”。

2. **你们县城门店能不能送到**
   - 如果你们门店是商超、水果店、社区生鲜店，建议先问当地佳农经销商或区域业务员，确认是否在配送线路内。
   - 如果当地没有直配，通常可以通过区域批发市场、二级经销商或第三方冷链物流中转。
   - 最稳妥的判断方式：提供“省+市+县+门店类型+大概采购量”，让佳农当地销售或客服查配送线路。

3. **冷链物流怎么收费**
   - 佳农一般不会公开统一冷链运费表，因为费用受起送量、距离、温区、车型、是否拼车、是否上楼、是否长期合作影响。
   - 常见计费方式：按件/箱、按重量、按体积、按趟/车、按公里，或“满额免运费、未满额加收配送费”。
   - 县城或偏远线路通常会有最低起送量，达不到可能加收运费或只能到就近城市自提/中转。
   - 具体费用需要问当地经销商或承运商报价，不能只按快递价格估算。

4. **建议你这样问**
   - “我们门店在XX省XX市XX县，主要采购香蕉/苹果/火龙果等，月采购量大概X箱，能否直配到店？”
   - “如果直配不到，最近的中转仓/经销商在哪里？到县里是自提还是送货？”
   - “冷链运费按什么计费？起送量多少？是否含卸货？时效几天？”
   - “损耗和温控问题怎么赔付？”
