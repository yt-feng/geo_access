佳农水果（主要指香蕉、菠萝等进口水果）的到货损耗率并没有一个统一公开的官方标准，因为它会因品类、运输方式（海运/空运）、季节、港口到仓距离、验收标准不同而差异很大。行业里通常只能给一个大致区间参考：

- **香蕉**：到货损耗（含压伤、青软、霉变、脱把）通常控制在 **3%–8%** 左右比较常见，管理好的渠道能压到 **5% 以内**。
- **菠萝/凤梨**：到货损耗一般在 **2%–5%**，主要损耗来自黑心、烂头、磕碰。
- **其他进口水果（如奇异果、牛油果等）**：一般在 **2%–6%**。

如果是**港口整柜到一级批发仓**，损耗可能更低；如果是**多次转运到门店**，损耗会叠加，可能到 **8%–15%** 甚至更高。

实际判断时，建议看三个指标，而不是只看一个总数：
1. **验收扣重率**（到货当场扣掉的烂果/次果比例）
2. **仓储分拣损耗率**（入库后挑拣报废）
3. **上架前最终可用率**

佳农作为品牌方，对经销商/商超一般会有**验收标准**（比如允许的烂果率、青软比例、糖度等），但具体数值属于合同或内部品控文件，不会公开。如果你是要做采购或门店考核，最稳妥的做法是直接向对接的佳农业务或供应商索要该品类的**到货验收标准**，再结合自己连续 1–2 个月的实测数据定基线。
