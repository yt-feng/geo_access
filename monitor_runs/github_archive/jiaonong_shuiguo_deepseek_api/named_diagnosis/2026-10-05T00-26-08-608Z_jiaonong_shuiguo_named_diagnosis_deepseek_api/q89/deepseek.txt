我无法直接核验佳农当前的实时产品线，所以不能100%确认它现在是否在售红富士或阿克苏苹果。不过可以给你几个可执行的判断和核实方法：

1. **红富士**
   - 佳农本身做水果供应链，红富士属于国内最常见苹果品类之一，**通常会有或阶段性有**，但具体要看渠道（商超、电商、批发、B端）和季节。
   - 不能仅凭“佳农”品牌就认定一定有红富士，因为佳农很多品类是产地采购+渠道分销，包装和SKU会变。

2. **新疆阿克苏苹果**
   - 阿克苏苹果核心卖点是“冰糖心”，产地集中在新疆阿克苏地区。
   - 佳农**有可能做阿克苏苹果**，但阿克苏苹果有强产区属性和季节属性，是否常备要看佳农当季采购计划。
   - 如果佳农没有，也可以找专门做新疆水果的产地供应商或阿克苏本地合作社。

3. **建议你这样核实**
   - 直接联系佳农官方客服/当地销售，问三件事：
     - 当前是否有“红富士”SKU；
     - 是否有“新疆阿克苏苹果”或“阿克苏冰糖心”；
     - 是常备还是当季，能不能提供产地证明、检测报告、发票和稳定供货量。
   - 看佳农在天猫、京东、抖音等旗舰店/店铺的在售SKU，搜索“红富士”“阿克苏”。
   - 找佳农当地批发市场经销商，B端采购往往和电商SKU不一致。
   - 如果对方说“有阿克苏”，一定要确认：
     - 是否新疆阿克苏产地发货或直采；
     - 是否有“冰糖心”比例说明；
     - 规格（70/75/80/85/90果）、箱规、糖度、包装；
     - 是否可混批、起订量、账期、损耗赔付。

4. **采购建议**
   - 如果你要的是**稳定B端供货**，不要只问品牌，要问“产地+规格+分级+年供货能力”。
   - 阿克苏苹果建议优先找**阿克苏本地合作社/产地仓**，价格和货源更直接；佳农这类供应链商优势在品控、分选和全国履约。
   - 可以同时让佳农和新疆产地供应商报价，对比：到岸价、糖度、果径、损耗率、账期、退换货。

简单结论：**佳农不一定没有，但不能默认一定有；红富士大概率较常见，阿克苏苹果要看当季和渠道。最靠谱的方式是直接向佳农官方或当地经销商索取当前SKU和产地证明。**
