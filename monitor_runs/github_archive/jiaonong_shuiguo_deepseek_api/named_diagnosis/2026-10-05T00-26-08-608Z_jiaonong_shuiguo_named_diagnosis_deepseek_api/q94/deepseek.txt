## 一、分级标准（行业通用做法，佳农具体标准需向其确认）

国产/进口香蕉批发环节通常按以下维度分级：

| 维度 | 一级果 | 二级果 |
|------|--------|--------|
| 果指长度 | 通常≥18-20cm | 16-18cm或更短 |
| 果指粗细 | 均匀、饱满 | 偏细或不均 |
| 每梳条数 | 5-8条为主，整齐 | 条数不齐，可能3-4条 |
| 外观 | 无疤、无黑点、无机械伤 | 允许少量疤痕/色差 |
| 成熟度 | 青果均匀，催熟后一致 | 成熟度参差 |
| 梳形 | 整齐、紧凑 | 松散、变形 |

**注意：** 佳农作为品牌商，其内部分级代号（如A级/B级、精品/普通）和具体数值门槛属于商业信息，不同批次可能调整，必须向其业务员索取当批次的《验收标准》或《分级说明》。

## 二、一二级价格差（参考区间）

香蕉一二级果的价差**不是固定值**，通常表现为：

- **一级果比二级果高 15%-30%**，具体看行情；
- 行情好时价差拉大（一级果抢手），行情差时价差缩小甚至倒挂；
- 按箱计价时，一级果每箱可能贵 **5-15元**（以18-20斤/箱计，仅为量级参考，非实际报价）。

## 三、给你的可执行建议

1. **直接找佳农业务或区域代理**，要求提供：当批次规格书、验收标准、一二级报价单。这是唯一准确来源。
2. **横向比价**：同时问都乐、陈氏阳光、以及本地一级批发商的同类分級货，用价差反推佳农报价是否合理。
3. **看货定级**：批发环节最终以实物定级，要求看样或视频验货，重点看果指长度、整齐度、伤痕率。
4. **合同写明降级条款**：约定到货后若实际等级不符，如何折价或退货，避免扯皮。
