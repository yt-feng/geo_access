佳农香蕉的保质期和储存条件，通常可以按“未熟、已熟、已剥开”三种状态来判断：

1. **未完全成熟、表皮偏绿的香蕉**
   - **储存条件**：常温阴凉通风处放置，避免阳光直射和靠近暖气。
   - **保质期**：一般可放 **3～7天**，具体看室温。温度越高熟得越快。
   - **建议**：不要直接放冰箱冷藏，容易表皮变黑、口感变差。

2. **已经成熟、表皮黄色的香蕉**
   - **储存条件**：常温尽快食用；如果已经熟透，可放冰箱冷藏 **1～3天**。
   - **保质期**：常温通常 **1～3天**；冷藏后果肉可再放 **1～3天**，但表皮会变黑，属于正常现象。
   - **建议**：想延缓成熟，可把香蕉分开，或用保鲜膜包住香蕉根部。

3. **已经剥开或切开的香蕉**
   - **储存条件**：密封冷藏，尽量隔绝空气。
   - **保质期**：建议 **24小时内** 吃完；冷藏一般不超过 **1～2天**。
   - **建议**：可加少量柠檬汁减缓变黑。

4. **冷冻保存**
   - 熟透香蕉可去皮切段后密封冷冻，通常可保存 **1～3个月**，适合做奶昔、烘焙，但不适合直接当鲜果吃。

**简单判断：**
- 绿香蕉：常温催熟，3～7天。
- 黄香蕉：尽快吃，常温1～3天，冷藏1～3天。
- 剥开香蕉：冷藏，24小时内最好吃完。

具体保质期还会受运输、包装、成熟度和室温影响，包装标签上若标有储存方式，以标签为准。
