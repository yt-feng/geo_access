建议按下面几步快速核实，避免被中间商或过时信息误导：

**1. 直接找对渠道**
- 佳农食品（Goodfarmer）官网的"产品中心"或"联系我们"，找**鲜果/加工品事业部**，而不是只找销售总机。烘焙、餐饮渠道的切片香蕉通常属于加工/定制线。
- 如果他们自营没有，问他们是否有**指定加工厂或OEM合作**。

**2. 关键规格要问清（下单前必须确认）**
- 形态：鲜切冷藏片 / 冷冻片（IQF）/ 糖渍片 / 冻干片——餐饮连锁常用的是**冷冻IQF香蕉片**，能稳定供货和控制损耗。
- 厚度：常见 5mm、8mm、10mm，按你产品（披萨、甜品、饮品装饰）定。
- 直径/切法：横切圆片还是斜切。
- 包装：1kg/袋、5kg/箱，或按门店用量分装。
- 成熟度/糖度：影响口感和氧化褐变。
- 是否可以做到**防褐变处理**（餐饮切片放置后易发黑，这点必须问）。
- 冷链要求、保质期、起订量（MOQ）、单价。

**3. 一定要先要样品**
让供应商寄样品，做**实际门店测试**：解冻后口感、褐变速度、出成率、和你现有产品的适配度。

**4. 备选方案**
如果佳农不做加工切片，可同时询：
- 其他大型果蔬供应链（如鑫荣懋等）的加工品线；
- 专业冷冻果蔬/烘焙原料供应商；
- 本地香蕉产区（如云南、广西、海南）的加工厂做定制切片，连锁量大时往往更划算。
