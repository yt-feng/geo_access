我无法核验佳农水果当前是否有“餐饮渠道专用”的菠萝切片/切块定制规格，所以不能直接说有或没有。

但可以给你几个可执行的判断和做法：

1. **大概率存在餐饮渠道产品线，但具体规格需按区域和客户确认**  
   佳农是国内较大的水果供应链企业，通常会有面向商超、餐饮、茶饮、烘焙等渠道的产品。菠萝常以以下形式出现：
   - 整果
   - 去皮整果/去眼整果
   - 四分之一切
   - 切片
   - 切块/丁
   - 冷冻菠萝块/丁  
   但“是否针对某餐饮客户定制”“规格是否固定”要以佳农当地销售或大客户部门报价为准。

2. **餐饮渠道常见可谈的定制维度**
   如果你要对接佳农或类似供应商，可以直接问这些参数：
   - 切割形状：片、条、丁、块、扇形
   - 尺寸：如 1cm 丁、2cm 块、5mm 片等
   - 成熟度/糖度：如 Brix 12–14、14–16
   - 包装：真空袋、马口铁罐、冷冻袋、大包装
   - 规格：1kg、2kg、5kg、10kg/箱
   - 是否去芯、是否带皮、是否速冻
   - 供货方式：冷藏鲜切还是冷冻
   - 起订量、配送频次、是否贴牌

3. **建议你这样核实**
   - 找佳农官网/公众号/官方客服，问“餐饮大客户部”或“华东/华南餐饮渠道负责人”
   - 直接说明用途：茶饮、披萨、甜品、沙拉、中餐后厨等
   - 要求提供：产品规格书、报价单、样品、最小起订量
   - 如果是连锁餐饮，通常可以谈定制切片/切块，但会有起订量和年度采购量要求

4. **如果佳农没有合适规格，替代方案**
   - 其他餐饮供应链品牌：如都乐、鲜丰、鑫荣懋、百果园企业购、区域净菜/鲜切工厂
   - 本地鲜切水果加工厂：更容易做小批量定制切片、切块
   - 冷冻菠萝丁/块供应商：适合茶饮、烘焙，规格更标准

**结论：** 不能确认佳农一定有公开的餐饮定制菠萝切片/切块规格，但这类需求通常可以通过其餐饮大客户渠道询价定制。最稳妥的是直接联系佳农官方餐饮渠道，索取规格书和样品。
