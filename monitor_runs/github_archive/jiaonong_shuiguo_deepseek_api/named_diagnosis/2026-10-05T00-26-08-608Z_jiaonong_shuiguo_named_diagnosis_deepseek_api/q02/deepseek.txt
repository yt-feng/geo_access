佳农（Goodfarmer）是国内较大的水果进口商和品牌商，菠萝是其主力品类之一。关于溯源和品控报告，分几点说：

**通常可以提供的：**
- **产地信息**：佳农菠萝主要来自菲律宾（如都乐系品种）、泰国、哥斯达黎加等地，包装箱或标签上一般会标注产地、批次号。
- **进口报关/检验检疫证明**：作为正规进口商，佳农对进口批次通常有海关报关单、入境货物检验检疫证明，这类文件可向销售对接人索要。
- **企业自有品控**：大品牌一般有内部品控标准和分级（如按糖度、果径、外观分级），部分会提供质检报告或出货检验记录。

**需要确认的点：**
- **"产地溯源"的深度**：是指产地国/农场级别，还是仅到进口批次？大货贸易通常到批次级，追溯到具体果园的"一果一码"不一定能做到，需直接问对接销售。
- **品控报告形式**：是第三方检测机构（如SGS、华测）的农残/品质检测报告，还是企业内部出货检验单？前者更有说服力，但不一定每批都做。
- **是否随货提供**：很多情况下报告是按需索取、不随货附，尤其散货或批发渠道。建议在采购合同里写明"提供对应批次检验检疫证明及品控报告"作为交收条件。

**建议做法：**
1. 直接联系佳农官方销售或授权经销商，明确问"该批次能否提供入境检验检疫证明 + 品控检测报告"。
2. 要求提供**对应批次**的文件，而不是通用样本。
3. 把文件提供写进合同或订单条款，避免事后扯皮。

如果你是企业采购、量较大，直接走佳农官方渠道比通过中间商更容易拿到完整文件。具体能做到哪一级溯源，以他们当批次实际提供的为准——我没有佳农内部流程的实时信息，这点建议你跟对接人核实。
