**发票**
- 一般能开：**增值税普通发票/增值税专用发票**。
- 需提供：公司名称、税号、开户行及账号、地址电话等开票信息。
- 发票内容常见为：**水果、食品、礼盒、农产品**等，具体能开什么品名要看供应商资质和税务口径。
- 若走电商平台，通常支持电子发票；若走经销商/批发商，也可开专票，但可能要加税点或满足起开金额。

**质检报告**
- 正规供应商通常可提供：**批次质检报告/出厂检验报告**。
- 若是佳农品牌礼盒，可要求提供：**该批次产品的质检报告、产地/供应商资质、营业执照、食品经营许可证**等。
- 注意：质检报告一般对应**具体批次**，不是一份报告永久通用。你采购500份时，应要求随货或发货前提供**对应批次**报告。

**建议你下单前确认这4点**
1. 是否支持开**增值税专票**，税点多少，是否另加费用。
2. 能否提供**对应批次**质检报告，而不是旧报告或通用报告。
3. 500份是否支持**一件代发/统一发货**，运费和破损怎么算。
4. 礼盒是否支持**定制卡片、LOGO、包装贴**，以及售后破损补发规则。
