建议你按以下方式核实：

1. **找佳农官方渠道确认**
   - 佳农官网/官方公众号的客服或“联系我们”
   - 官方销售电话，直接问：是否有**冷冻菠萝丁**、是否面向茶饮/餐饮渠道、最小起订量
   - 如果你从经销商拿货，让经销商提供**佳农冷冻菠萝丁的规格书和检测报告**

2. **重点问清这些规格**
   - 丁的大小：常见为 **5×5mm、8×8mm、10×10mm**，但以厂家实际为准
   - 包装：**1kg/袋、2kg/袋、10kg/箱**等
   - 是否**IQF单体速冻**
   - 糖度/酸甜度、是否加糖或糖水浸泡
   - 解冻后出水率、软烂程度
   - 是否适合直接入饮品、是否需要提前解冻
   - 保质期、储存温度、产地、批次稳定性

3. **茶饮店使用建议**
   - 如果用于**出品装饰/口感颗粒**，优先选 **8×8mm或10×10mm**，太小容易沉底且口感弱，太大不易吸管吸出
   - 如果用于**打冰沙/果茶基底**，5×5mm或更碎也可
   - 冷冻菠萝丁直接入冷饮通常可行，但要做**解冻出水测试**，避免稀释饮品
   - 先要**样品**做3件事：解冻后口感、出水率、与茶汤/糖浆搭配后的风味稳定性

4. **如果佳农没有**
   可同步问这些常见供应方向：
   - 其他果蔬冷冻供应商的**IQF冷冻菠萝丁**
   - 餐饮供应链平台的**冷冻菠萝丁/菠萝颗粒**
   - 本地冷冻水果批发商
   - 直接找菠萝罐头/速冻水果工厂做贴牌或定制规格
