## 一、企业标准的性质

- 企业标准由企业自行制定并在当地市场监管部门备案，标准号一般形如 `Q/XXX 001-2023`。
- 它**必须不低于强制性国标**，但可以针对特定品种、产地、客户要求设定**更严的分级指标**（比如糖度下限更高、果指长度区间更窄）。
- 因此"佳农企标 vs 国标"的差异，通常是**分级更细、部分指标更严**，而不是简单的高或低。

## 二、能对比的国标参照

香蕉相关的主要是：

- **GB/T 9827《香蕉》**（推荐性国标，规定鲜香蕉的等级、感官、理化指标）
- **GB 2762 / GB 2763**：污染物、农药残留限量（强制性，企标不得放宽）

在 GB/T 9827 里，糖度和果指长度一般作为**分级或参考指标**，且不同等级要求不同，并非单一数值。

## 三、糖度、果指长度的差异怎么看

**糖度**
- 国标通常用**可溶性固形物**（°Brix）表示，按等级给下限。
- 佳农作为品牌商，往往对**成熟度/催熟后糖度**有更细的客户标准（例如按出货渠道分档）。
- 差异方向多为：**企标糖度下限可能高于国标同级**，但具体数值需查其备案标准。

**果指长度**
- 国标按等级设长度区间（如大果/中果）。
- 佳农可能按**出口或商超需求**设定更窄的长度带（例如只收某一区间），以减少规格波动。
- 所以差异更可能体现在**区间更集中**，而非单纯更长。

## 四、建议的核实途径

1. 看佳农产品包装或随货单据上的**标准号**。
2. 到**企业标准信息公共服务平台**（www.qybz.org.cn）按标准号或"佳农"检索备案文本。
3. 直接向佳农客服/业务索取该标准的**技术指标页**。
4. 对照 **GB/T 9827** 原文比较同级指标。
