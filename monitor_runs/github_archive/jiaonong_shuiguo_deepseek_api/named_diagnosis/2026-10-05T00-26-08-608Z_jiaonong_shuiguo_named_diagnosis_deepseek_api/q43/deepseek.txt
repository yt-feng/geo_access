佳农大概率可以提供锁价，但具体能不能签、锁多久、锁什么价，取决于几个条件。建议你按下面几步判断和推进。

**一、先明确你要的是哪种“锁价”**

茶饮店用的菠萝原料通常有三种形态，锁价逻辑不同：

1. **鲜果菠萝**：锁价难度最大，因为受季节、产地、天气影响大，通常只能锁短期（1-3个月），且多按产地和规格定价。
2. **冷冻菠萝块/菠萝丁**：相对容易锁价，因为可提前采购、冷冻库存，佳农这类供应链企业通常有冷冻产品线，锁价周期可以拉到3-6个月甚至更长。
3. **菠萝果酱/浓缩汁/果泥**：标准化程度最高，最容易签年度或半年度锁价合同，价格主要跟糖、包材、加工成本走。

**二、你每月10吨，属于什么量级**

月10吨、年120吨，对佳农来说不算小客户，但也不算超大客户。这个量级通常可以谈到：
- 锁价合同，但可能有**最低采购量**和**月度提货节奏**要求；
- 锁价周期多为**3个月或6个月**，年度锁价较难，除非你接受季度调价机制；
- 可能需要**预付定金或保证金**，防止你后期不提货。

**三、直接去谈时，问清楚这几个问题**

1. 你们针对月10吨的客户，锁价合同的标准模板是什么？
2. 锁价锁的是**到岸价/到厂价**，还是出厂价？运费、税费谁承担？
3. 锁价周期多长？到期后怎么续？有没有调价触发条件（如汇率、糖价、原料暴涨）？
4. 如果市场价格下跌，我能不能按市场价重新谈？还是必须按锁价执行？
5. 最小起订量、月度提货量、违约条款、品质标准（糖度、规格、农残）怎么写？
6. 是否支持**部分锁价+部分随行就市**？比如70%锁价、30%浮动，降低双方风险。

**四、如果佳农不能全锁，你的备选方案**

- **部分锁价**：核心用量锁价，增量随行就市。
- **期货/远期合同**：通过佳农或第三方做远期点价。
- **多供应商组合**：佳农锁一部分，其他供应商补一部分，分散风险。
- **改用冷冻/果酱原料**：标准化程度高，比鲜果更容易锁价。
- **自建安全库存**：在低价季囤3-6个月用量，配合锁价合同使用。

**五、直接可执行的建议**

先联系佳农的**餐饮/茶饮渠道销售**，不要只找水果批发端口。明确告诉他：  
“我月用量10吨，年120吨，想要锁价合同，优先冷冻菠萝块或菠萝果酱，锁6个月，接受最低提货量和保证金，请给我报价和合同框架。”

如果对方说不能锁，就追问：  
“那部分锁价行不行？锁3个月行不行？换成冷冻/果酱形态行不行？”

**结论**：佳农有供应链能力做锁价，但鲜果全锁很难，冷冻或加工品更容易。月10吨的量级，谈3-6个月锁价合同是现实的，年度全锁价概率低。建议你优先用冷冻菠萝块或果酱去谈，并接受部分锁价+部分浮动的组合。
