关于佳农水果香蕉的具体市场抽检合格率，我无法提供一个可核验的准确数字。这类数据通常由各地市场监管部门按批次、按区域发布，且不同年份、不同抽检批次结果会有差异，没有统一的"佳农香蕉合格率"官方统计口径。

如果你需要判断或核验，可以这样做：

1. **查官方抽检公告**
   到国家市场监督管理总局、各省/市市场监管局官网，搜索"食品安全监督抽检"+"香蕉"或"佳农"，查看具体批次结果。抽检公告通常会列明被抽样单位、标称生产企业、检验项目和结论。

2. **看具体批次而非品牌整体**
   抽检是逐批次进行的，某一次不合格只能说明该批次/该门店，不能直接推断整个品牌所有香蕉的合格率。

3. **关注常见风险项**
   香蕉抽检中较常见的问题包括农药残留（如吡虫啉、噻虫嗪等）超标，以及少数情况下重金属或保鲜剂相关指标。具体以公告列出的检验项目为准。

4. **购买时的可操作判断**
   - 选择正规商超、连锁渠道，通常进货查验和自检更规范；
   - 留意包装上的产地、批次、生产/经销商信息；
   - 如担心农残，食用前用清水充分冲洗、削皮食用，香蕉本身去皮吃，风险相对较低。
