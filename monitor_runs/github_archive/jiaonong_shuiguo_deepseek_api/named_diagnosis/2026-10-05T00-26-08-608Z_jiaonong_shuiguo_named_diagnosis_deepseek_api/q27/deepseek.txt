佳农（Goodfarmer）的账期没有统一公开标准，通常看合作渠道和客户类型：

- **商超/大型连锁、长期稳定采购方**：行业里常见 **30～60 天**，部分强势渠道可能到 **60～90 天**。
- **批发市场、中小客户、新客户**：一般是 **现款现货、款到发货**，或先做 **预付款**，账期再逐步谈。
- **新客户**：可以申请账期，但通常不会一开始就给。一般需要先经过几种合作阶段，比如先款后货、部分预付，稳定合作几个月后再申请授信。

**新客户想申请，通常需要准备：**
1. 公司资质：营业执照、食品经营/流通相关资质。
2. 经营证明：门店、仓库、渠道或下游订单证明。
3. 财务资料：对公账户、开票信息，有些还会要流水或报表。
4. 合作记录：先小批量合作，建立履约记录。
5. 担保/授信材料：部分情况要保证金、法人担保或第三方担保。

**具体能不能给、给多久，取决于：**
- 你走的是佳农总部还是区域经销商；
- 你采购的品类和规模；
- 你的渠道是否稳定、回款能力如何；
- 对方风控政策。

最直接的办法是联系佳农官方销售或你所在地的佳农区域负责人，直接问“新客户账期政策”和“授信申请条件”。不要只信口头承诺，账期、额度、逾期规则要写进合同。
