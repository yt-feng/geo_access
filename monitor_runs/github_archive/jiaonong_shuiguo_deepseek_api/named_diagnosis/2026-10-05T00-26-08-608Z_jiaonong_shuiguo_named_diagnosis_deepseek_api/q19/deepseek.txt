佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个统一固定答案。可以按下面几种情况判断：

1. **电商平台自营/旗舰店（如京东、天猫、拼多多）**
   - 一般走平台仓或佳农合作仓发货。
   - 有货且在你所在城市覆盖范围内：通常 **次日达或隔日达**，部分城市支持当日达/半日达。
   - 偏远地区、乡镇：一般 **2–4天**，甚至更久。

2. **社区团购/生鲜平台（如美团优选、多多买菜等）**
   - 通常按“次日自提”模式，**下单后第二天到自提点**。
   - 具体以平台显示的到货时间为准。

3. **佳农官方小程序/直营渠道**
   - 一般会标明发货地和预计时效，常见是 **48小时内发货，发货后1–3天送达**。
   - 进口水果或预售商品可能更久。

4. **线下商超/水果店配送**
   - 如果是美团、饿了么、京东到家等本地即时零售，通常 **30分钟–2小时送达**，但依赖附近门店有货。

**下单后多久能到，最准确的判断方法：**
- 看商品页写的“发货时效”和“预计送达时间”；
- 下单时填写地址后，系统会显示预计到达日期；
- 看是否预售、是否进口、是否冷链，这类通常更慢；
- 直接问店铺客服发货地和快递公司。
