我没有佳农官方对“茶饮店菠萝丁加工/定制切丁”服务的可核验信息，不能直接替他们确认。建议你按下面方式快速判断和推进：

1. **先问清你要的“菠萝丁”是哪一种**
   - **冷冻菠萝丁**：茶饮店最常用，开袋即用，规格常见 8×8mm、10×10mm 等。
   - **糖水菠萝丁/罐头菠萝丁**：适合直接加入饮品，但甜度和脆度不同。
   - **新鲜菠萝切丁**：保质期短，门店处理成本高。
   - **菠萝果酱/果泥**：不是丁，但很多茶饮店实际会用。

2. **佳农大概率不是只卖整果，但是否给茶饮店做定制加工要看渠道**
   佳农以香蕉、菠萝等水果供应链见长，通常会有：
   - 整果批发；
   - 商超/电商零售果；
   - 部分冷冻水果、果切或餐饮渠道原料。
   但“按你要求的尺寸做菠萝丁、贴牌、稳定供货”属于**餐饮工业原料定制**，一般要问对部门，不是普通门店或电商客服能直接答复。

3. **你可以直接这样问佳农或经销商**
   复制下面问题去问：
   - 你们有没有**冷冻菠萝丁**或**糖水菠萝丁**的餐饮装？
   - 规格是多少？比如 8×8mm、10×10mm，还是不定尺？
   - 是**佳农自产/代工**，还是只做整果批发？
   - 起订量多少？是否支持**贴牌定制**？
   - 供货是冷冻、冷藏还是常温？保质期多久？
   - 有没有**样品**和**质检报告/规格书**？
   - 发货地、到货周期、能否稳定月供？

4. **如果佳农不做定制，替代方案**
   - 找**冷冻水果餐饮供应商**：更可能提供标准菠萝丁。
   - 找**罐头/糖水菠萝丁厂家**：适合茶饮，规格稳定。
   - 找**果蔬加工厂代工**：可定制尺寸、糖度、包装，但起订量通常较高。
   - 本地批发市场先拿**冷冻菠萝丁样品**测试口感、出杯稳定性。

5. **茶饮店选菠萝丁重点看**
   - 大小是否均匀，是否容易堵吸管；
   - 解冻后是否出水、发软、变酸；
   - 糖度是否和你的茶底匹配；
   - 每杯成本，不是只看每公斤价格；
   - 是否需要冷冻储存，门店冰箱是否够用。

**结论：佳农是否能提供加工菠萝丁，不能凭公开常识确定；它可能卖整果，也可能有餐饮原料渠道，但定制切丁通常要走餐饮/工业渠道确认。你先按“冷冻菠萝丁/糖水菠萝丁餐饮装”去问，并同时找2-3家专业冷冻水果或罐头供应商比样，最快。**
