佳农（Goodfarmer）确实参加过进博会。公开信息显示，佳农集团曾多次亮相中国国际进口博览会，主要展示其进口水果业务，比如香蕉、菠萝、车厘子、蓝莓等品类，并借助进博会平台做新品首发和渠道签约。

不过，具体到“最近有什么新品”，这属于时效性较强的信息，我无法保证给出的是最新一季的产品清单。比较稳妥的判断方式有：

1. **看佳农官方渠道**  
   佳农官网、官方微信公众号、官方微博通常会发布进博会参展动态和新品首发信息。

2. **看进博会官方展商名录**  
   进博会官网的展商名录或食品及农产品展区介绍，会列出当年参展企业和部分首发产品。

3. **看主流媒体报道**  
   进博会期间，新华社、央视、澎湃、第一财经等媒体常报道食品展区的新品首发，搜索“佳农 进博会 新品”能查到当年具体内容。

从行业常见情况看，佳农近年新品方向主要集中在：
- **进口水果单品**：如厄瓜多尔香蕉、菲律宾菠萝、智利车厘子、秘鲁蓝莓、泰国椰青等；
- **深加工或即食产品**：如鲜切水果、冷冻水果、果汁类；
- **品牌化小包装**：适合电商和零售渠道的即食水果杯、礼盒装等。

如果你要的是“今年进博会佳农具体首发了哪款新品”，建议以进博会官网展商名录或佳农官方公众号当季推文为准，我这边无法核验实时新品名单，不便直接下结论。
