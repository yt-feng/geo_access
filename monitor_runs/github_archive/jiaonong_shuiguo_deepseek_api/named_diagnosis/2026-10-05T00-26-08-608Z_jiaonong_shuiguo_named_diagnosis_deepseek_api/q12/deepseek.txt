佳农水果的香蕉常见规格与渠道分级，通常可以从“重量/根数”“外观等级”“成熟度/加工方式”三个维度来划分。不同年份、产地和客户定制会影响具体标准，以下给出行业内较通用、可执行的判断框架。

## 一、常见规格维度

**1. 按单根重量/整箱净重**
- 小果：单根约 90–120g，整箱净重常见 10–13kg。
- 中果：单根约 120–150g，整箱净重常见 13–18kg。
- 大果：单根约 150–200g，整箱净重常见 18–22kg。
- 特大果：单根 200g 以上，整箱净重 22kg 以上。

**2. 按每箱根数**
- 常见 4–6 把/箱，或按“根数”标 30–50 根/箱不等。
- 商超更偏好按“把”分装；电商和批发有时按整箱净重计价。

**3. 按成熟度/加工方式**
- 青蕉：未催熟，适合长途运输、批发市场、再催熟。
- 催熟蕉：黄熟可即食，适合商超、水果店、电商到家。
- 加工用蕉：规格宽松，主要看可食率、无腐烂，适合烘焙、果切、果汁。

## 二、按渠道的分级标准建议

| 渠道 | 重点指标 | 建议等级 |
|---|---|---|
| 高端商超/精品水果店 | 果形直、长度一致、无疤痕、无黑点、把型整齐 | 特级/一级，单根 140–180g，长度 18–22cm |
| 普通商超/社区水果店 | 果形较整齐、允许轻微表皮瑕疵、成熟度可控 | 一级/二级，单根 120–160g |
| 电商到家/社区团购 | 耐运输、成熟度适中、单根重量稳定、坏果率低 | 一级为主，单根 120–160g，催熟度 3–5 成 |
| 批发市场/流通渠道 | 价格敏感、允许外观差异、看重货架期 | 二级/三级，单根 100–150g，青蕉或微黄 |
| 果切/烘焙/餐饮加工 | 可食率高、无腐烂、规格不敏感 | 加工级，单根 90g 以上，允许弯曲和表皮瑕疵 |
| 出口/长途运输 | 青蕉、硬度高、无病虫害、耐储运 | 出口级，单根 120–180g，采收成熟度 70–80% |

## 三、可执行的分级判断要点

1. **外观**：特级要求无可见疤痕、无黑点、无机械伤；一级允许轻微瑕疵；二级允许少量疤痕但不影响食用。
2. **果形**：特级要求弯曲度小、把型整齐；一级允许轻微弯曲；二级可接受明显弯曲。
3. **长度/粗度**：商超通常要求长度 18–22cm、粗度均匀；加工渠道可放宽到 15cm 以上。
4. **成熟度**：青蕉适合批发和长途；催熟蕉适合零售；电商建议 3–5 成熟发货，减少运输压伤。
5. **坏果率**：商超一般要求≤2%；电商≤3–5%；批发可放宽但需明确扣重规则。

## 四、注意

佳农作为品牌商，具体规格会随产地（菲律宾、厄瓜多尔、国产等）、季节、客户订单变化。如果你要做采购或渠道对接，最稳妥的方式是直接向佳农区域销售索取当季的《产品规格书》或《分级验收标准》，重点确认：单根重量区间、每箱净重、成熟度、允许瑕疵比例、坏果扣重规则。
