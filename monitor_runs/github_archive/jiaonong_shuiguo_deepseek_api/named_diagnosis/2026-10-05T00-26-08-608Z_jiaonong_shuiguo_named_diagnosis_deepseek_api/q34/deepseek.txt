**1. 配送中心数量**
佳农（上海佳农食品控股）旗下有多个业务板块（香蕉、菠萝、进出口水果等），其仓储/配送中心分布通常不会在官网完整公开。建议通过以下渠道核实：
- 佳农官网或官方公众号的“仓储物流/服务网络”介绍；
- 直接拨打佳农官方客服或销售电话，说明你的城市和采购量，问是否直配；
- 通过其天猫/京东旗舰店或当地经销商询价。

**2. 能否覆盖三线城市**
这取决于两件事，不是“有没有配送中心”这么简单：
- **你是B端还是C端**：如果你是商超、水果店、批发商（B端），佳农一般通过区域经销商或批发市场分销，很多三线城市能拿到货，但不一定由厂家直配。如果你是个人消费者（C端），主要通过电商平台下单，由快递/落地配送达，覆盖范围广，但生鲜品类可能受冷链限制。
- **你的采购量**：B端如果单次采购量小，厂家通常不直发，需要走本地经销商。

**3. 建议你这样确认**
- 明确你的身份（个人/门店/批发）和大致月采购量；
- 在地图上搜“佳农 经销商”“佳农 批发”看你所在城市或邻近地级市有没有；
- 直接联系佳农官方，报出你的城市，问“能否直配、起订量多少、走哪个仓”；
- 同时问本地大型水果批发市场，很多三线城市的佳农货就是从那里来的。
