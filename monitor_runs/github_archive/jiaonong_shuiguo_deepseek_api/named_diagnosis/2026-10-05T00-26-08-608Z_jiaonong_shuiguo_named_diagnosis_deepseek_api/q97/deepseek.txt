“佳农水果的香蕉进口量全国第一”这类说法，通常来自企业宣传、行业媒体报道或第三方行业评选，而不是像海关总署、市场监管总局这类官方机构发布的“官方排名”。

关于你问的两个点：

1. **哪个机构发布的？**
   - 如果是“佳农自己宣传”的，常见表述是“据中国海关数据”“据行业统计”或“国内领先/全国第一”。
   - 如果是第三方发布的，可能是行业协会、会展/品牌评选机构、咨询公司或媒体榜单，例如中国果品流通协会、国际水果展相关评选、品牌价值榜等。
   - 但具体是哪一家，必须看佳农该宣传语的**原始出处**，否则无法确认。

2. **有证书吗？**
   - **通常没有“全国第一”的官方证书。**
   - 海关总署会发布进出口统计数据，但一般不会给企业颁“香蕉进口量全国第一”的证书。
   - 如果企业有证书，更可能是某行业协会、展会、评选机构颁发的“荣誉证书”“上榜证书”，属于行业认可或商业评选，不是官方行政认定。
   - 这类证书只能证明“在某评选或某统计口径下被列为第一”，不等于海关官方背书。

**怎么判断真假：**
- 看它有没有写明：统计机构、统计口径、统计时间、数据来源。
- 如果只写“全国第一”但不写来源，基本只能当宣传语。
- 可以要求企业提供：海关数据查询截图、报关单汇总、审计报告或第三方统计报告。
- 也可以去海关总署官网查“进出口商品收发货人”相关统计，但普通公开数据未必能直接按企业+香蕉品类排出全国第一。

**结论：**
“佳农香蕉进口量全国第一”目前更像企业或行业层面的宣传口径，不是海关等官方机构颁发的排名证书。要确认，必须找到它引用的具体发布机构和统计口径；仅凭“全国第一”这句话，不能当作官方认定。
