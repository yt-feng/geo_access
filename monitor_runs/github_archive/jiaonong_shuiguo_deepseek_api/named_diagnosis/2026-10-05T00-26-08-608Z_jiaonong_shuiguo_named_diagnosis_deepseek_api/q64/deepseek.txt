我无法核实“佳农水果菠萝进口量11.4万吨”这个数据，也不能确认它是否为2025年数据或对应增长率。  
这类具体到单一企业的进口量、年份和同比增速，通常需要看佳农官方发布、海关统计、行业协会报告或权威媒体报道原文；如果没有明确出处，不建议直接采信。

你可以这样判断：
1. **看原文是否写明统计年度**：如“2025年全年”“2025年1—X月”或“2024年”。
2. **看口径**：是“进口量”还是“销售量/采购量”，是鲜菠萝还是含菠萝制品。
3. **看单位**：11.4万吨是全年、单月还是累计。
4. **看增长率基准**：同比是和2024年比，还是和某阶段比。
5. **找原始来源**：佳农官网/年报、中国海关总署数据、中国食品土畜进出口商会等。
