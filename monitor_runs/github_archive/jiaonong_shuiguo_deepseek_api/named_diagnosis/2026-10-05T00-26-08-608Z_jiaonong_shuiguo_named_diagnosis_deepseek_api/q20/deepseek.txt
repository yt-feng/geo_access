佳农（Goodfarmer）主要是水果品牌和供应链企业，业务以香蕉、菠萝等品类的种植、采购、分选、贸易和渠道分销为主。对于“菠萝切块、定制包装”这类加工服务，通常需要看具体场景：

1. **面向商超/餐饮/茶饮等B端客户**  
   佳农这类供应链企业一般可以提供一定程度的定制化服务，例如：
   - 按规格分选（大小、成熟度）
   - 定制包装（箱规、标签、品牌露出）
   - 冷链配送
   - 部分鲜切或预包装产品

   但“切块”属于鲜切加工，涉及SC食品生产许可、冷链保质期和微生物控制，不是所有水果贸易商都自营。佳农部分渠道可能会通过合作工厂或指定加工商来完成。

2. **面向普通消费者**  
   一般不走“定制化加工”，主要是标准箱装、电商规格或门店零售包装。

3. **能否做，关键确认这几点**
   - 你要的是**鲜切菠萝块**，还是**整果按规格包装**？
   - 需求量多大？是单次还是长期？
   - 销售渠道是商超、餐饮、茶饮还是电商？
   - 是否需要贴牌、定制标签、特定克重/盒型？
   - 收货城市和冷链条件？
   - 是否需要供应商具备鲜切水果生产资质？

**建议直接联系佳农官方渠道**：官网、官方客服、区域销售或当地经销商，说明“菠萝鲜切/定制包装”的需求。如果佳农自营不承接鲜切，他们通常也能告知是否由合作加工厂承接，或推荐有资质的鲜切供应商。

简单说：**整果分级和定制包装，佳农较可能提供；鲜切块类定制加工，要看区域和合作加工能力，需具体询价确认。**
