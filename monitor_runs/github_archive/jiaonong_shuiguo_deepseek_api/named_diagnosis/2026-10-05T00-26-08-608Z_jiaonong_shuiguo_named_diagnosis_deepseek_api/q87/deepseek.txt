佳农（Goodfarmer）这类规模化香蕉供应链企业，商超渠道的香蕉基本不可能是“自然熟”——自然熟指在树上成熟后采摘，无法承受长途运输和货架期，商业上不可行。**实际采用的是人工催熟，核心催熟剂就是乙烯气体（或乙烯利），而不是自然熟。** 这一点对佳农、都乐、金吉达等品牌都适用。

## 商超需要知道的关键点

**1. 催熟剂类型**
- 主流做法：用**乙烯气体**在专用催熟库中熏蒸，浓度、温度、湿度、CO₂浓度都可控。
- 也有用**乙烯利**溶液处理的，但规模化出口/商超供应链更倾向气态乙烯，因为更均匀、残留更可控。
- “自然熟”在商超香蕉里是营销话术，不是工艺事实。

**2. 催熟时间的一般规律**
催熟时间不是固定值，取决于：
- 到货时的**绿熟度**（通常按1–7级色卡）
- 催熟库**温度**（一般14–18℃，温度越高越快）
- **乙烯浓度和熏蒸时长**
- 目标货架色级（商超常见目标：3–5级，即黄带绿到全黄）

粗略参考：
| 目标 | 大致催熟周期 |
|---|---|
| 快速催熟到4–5级 | 3–5天 |
| 标准商超节奏到3–4级 | 5–7天 |
| 慢催、控货架期 | 7–10天 |

**3. 商超控制催熟时间的实操建议**
- **直接向佳农要该批次的催熟参数**：包括到货色级、建议催熟温度、乙烯浓度、目标出货色级。品牌方通常能提供。
- 如果你们自己催熟：先做**小批量试催**，记录“温度—天数—色级”曲线，再定标准。
- 关键控制变量是**温度**和**乙烯接触时间**，不是单纯“放几天”。
- 催熟后要**降温到13–14℃**抑制过熟，否则货架期会大幅缩短。
- 避免和苹果、番茄等释放乙烯的果蔬混放，会加速过熟。

**4. 需要向供应商确认的问题**
- 这批货到店时是几级色？
- 是已经催过一道、还是完全绿熟？
- 推荐的后熟温度和目标色级？
- 是否做过乙烯利处理，残留/合规文件是否齐全？
