公开资料里，佳农（Goodfarmer）以香蕉、菠萝等品类的供应链和批发分销见长，但**是否有专门面向餐饮渠道的“菠萝解决方案”**，我无法从可核验的公开信息中确认其当前在售的产品包或服务方案。

能确定/较常见的情况是：

- 佳农长期做菠萝进口与国内分销，菠萝是其核心单品之一，餐饮、茶饮、烘焙等 B 端客户通常可以通过其经销体系采购。
- 餐饮渠道常见的“解决方案”一般包括：规格分级（如整果、去皮果、切片/切丁/切块）、成熟度/糖度控制、冷链配送、稳定供货周期、定制包装等。这类能力很多大型水果供应链企业都具备，但**具体是否以“餐饮渠道菠萝解决方案”名义打包，需要向佳农官方确认**。

建议你直接核实的方式：

1. 找佳农官网或官方公众号，看“餐饮渠道/大客户/批发”入口或联系方式。
2. 直接联系其销售，问清四点：  
   - 是否有餐饮专用规格（去皮、切块、冷冻/鲜切等）；  
   - 最小起订量和配送范围；  
   - 菠萝品种、产地、糖度/成熟度标准；  
   - 能否按门店需求做稳定周配或定制包装。
3. 如果是茶饮/连锁餐饮，可直接问是否有“鲜切菠萝”“冷冻菠萝块”“菠萝果酱/果浆”等细分产品线。

如果你告诉我你是做茶饮、烘焙还是中餐，以及需要的形态（整果/鲜切/冷冻/果浆），我可以帮你列一份更具体的询价清单。
