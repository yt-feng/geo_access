关于佳农水果的配送时效，具体时间会因**下单平台**（如佳农官方小程序、天猫、京东、拼多多等）、**所在城市**以及**商品类型**（如常温果、冷链果）而有所不同。

通常情况下的参考范围如下：

1.  **标准配送（一二线城市）**：
    -   如果是佳农在主流电商平台的官方旗舰店，一般下单后 **48小时内** 发货。
    -   发货后，同城或周边城市通常 **1-2天** 送达；跨省运输通常 **3-5天** 送达（偏远地区可能更长）。

2.  **生鲜冷链（如蓝莓、车厘子、榴莲等）**：
    -   这类商品多采用**次日达**或**隔日达**服务，具体视仓库是否在您所在城市有前置仓。
    -   如果仓库与收货地址同城，最快可实现 **当日达** 或 **次日达**。

3.  **特殊因素**：
    -   法定节假日、大促期间（如双11）、恶劣天气等会影响时效，具体以商家页面显示的“预计送达时间”为准。

**建议操作**：
在下单前，请仔细查看商品页面的“配送说明”或“运费/时效”标签。**最准确的做法是：将商品加入购物车并输入您的收货地址后，结算页面会显示精确的“预计送达日期”。** 这样可以避免因虚构信息导致的误导。
