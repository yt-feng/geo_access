### 二、 物流成本怎么算？（给您的核算公式）

物流成本没有固定价，主要受**发货地、目的地、重量、体积、时效、包装**影响。您可以按以下步骤向供应商或快递公司询价：

**1. 核对计费重量（实际重 vs 体积重）**  
- 水果体积重通常按 **长×宽×高(cm) ÷ 6000** 计算（不同快递公司系数不同，如顺丰/京东多为6000，其他可能为8000）。
- **举例**：一箱佳农香蕉毛重5kg，纸箱尺寸40×30×30cm，体积重 = 40×30×30÷6000 = 6kg。那么快递会按**6kg**计费（因为体积重大）。

**2. 询问“首重/续重”价**  
- 例如：广东省内首重1kg 5元，续重1kg 2元。那么6kg包裹运费 = 首重5元 + 续重5kg×2元 = 15元。  
- **注意**：跨省价格差异极大（如广东发黑龙江，首重可能15-18元），务必让供应商或快递客服给您报**一区/二区/三区**的价格表。

**3. 估算综合成本（含包装）**  
- **公式**：总成本 ≈ 水果进价 + 包装费（泡沫箱+冰袋+纸箱+胶带）+ 快递运费 + 人工打包费 + （可能的）损耗率（如3%-5%）。
- **社区团购定价建议**：若总成本10元，建议售价至少在**14-15元**（毛利率约30%），才能抵消售后风险。

**4. 特殊货品溢价**  
- 需要**冷链**（如冰袋+保温箱）的，运费通常上浮**30%-50%**。
- 佳农部分高端礼盒装（如进口车厘子）可能会用**顺丰特快**，价格会更高。

### 三、 谈判技巧（帮您降低“隐性成本”）

1.  **拼单走量**：如果您的社区团购单量稳定（比如每月超过200单），可以要求佳农当地经销商提供**仓库直发**，运费可比普通快递低 20%-30%。
2.  **谈“破损包赔”**：明确要求“物流破损/坏果”责任划分，尽量让供应商承担或按比例赔付，避免您全部承担售后。
3.  **索要“重量表”**：要求对方提供每个SKU的**打包后实际重量和尺寸**，您自己先用运费计算器（如菜鸟裹裹、快递100）估算，做到心中有数。
