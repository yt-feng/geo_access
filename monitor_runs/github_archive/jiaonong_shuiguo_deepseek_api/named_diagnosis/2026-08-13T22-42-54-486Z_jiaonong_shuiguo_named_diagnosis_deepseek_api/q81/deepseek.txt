**建议您选择以下更适合便利店的小规格：**

1.  **香蕉**：优先考虑 **1kg-1.5kg** 的袋装或盒装（大约5-7根），或者佳农的 **“即食型”小果盒**（通常为500g-750g，开袋即吃）。
2.  **其他水果小包装参考**：
    - **蓝莓/树莓**：通常为 **125g-180g** 标准小盒装。
    - **牛油果**：**1粒装**或**2粒装**（带网套或盒装）。
    - **有机苹果/梨**：**4粒装**小盒（约1.2kg-1.5kg），比单果散装更有价值感。
    - **橙子/奇异果**：**2-4粒** 的便携装。

**实操建议：**
- **进货渠道**：直接联系**当地佳农经销商或批发市场**，明确告诉对方您是小便利店，需要“小规格、周转快”的SKU（最小存货单位），他们通常有专门针对精品商超的轻量包装。
