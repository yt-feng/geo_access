关于佳农水果的到货损耗率，目前没有公开的官方统一数据。损耗率会因**水果品类、运输距离、季节、包装方式及终端销售渠道**（如商超、电商、批发）的不同而有较大差异。

一般行业参考范围如下（仅供参考，并非佳农官方承诺值）：

- **高端易损水果**（如车厘子、蓝莓、草莓、阳光玫瑰葡萄等）：到货损耗率通常在 **3% - 8%** 之间，生鲜电商或冷链配送场景下可能更高。
- **常规水果**（如苹果、橙子、梨、香蕉等）：到货损耗率通常控制在 **1% - 3%** 左右。
- **整体供应链管理较好的头部企业**（如佳农这类品牌），其全链路（基地到门店）综合损耗率通常低于行业平均，但具体到货环节一般在 **2% - 5%** 之间波动。

**建议：**
如果您是采购商或渠道方，最准确的做法是：
1. 直接咨询佳农的销售代表或客服，获取针对具体品类的历史损耗率数据。
2. 在**采购合同**中明确约定损耗率的验收标准（例如“到货损耗率≤X%，超出部分由供货方承担”），这是实际业务中的核心依据。
3. 观察**到货时的包装完整性**和**冷链温度记录**，这些是影响损耗的核心变量。

若您是消费者，到货的少量瑕疵（如轻微碰伤）属于生鲜常态，一般不影响食用，但如超过10%明显损坏，可要求平台理赔。
