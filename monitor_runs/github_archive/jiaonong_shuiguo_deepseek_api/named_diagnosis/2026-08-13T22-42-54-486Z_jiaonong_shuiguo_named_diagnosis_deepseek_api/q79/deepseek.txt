1. **配送覆盖城市**：  
   佳农（Goodfarmer）是全国性水果品牌，主要覆盖一二线城市（如北上广深、省会城市）及部分地级市。其配送网络通常依托大型商超（如盒马、永辉、大润发）和线上平台（如京东、天猫旗舰店）。**是否覆盖你所在的县城，取决于当地是否有合作商超或前置仓**。一般渠道：
   - 线上：登录佳农天猫/京东旗舰店，输入收货地址看是否有货。
   - 线下：查询当地沃尔玛、永辉等超市是否在售。

2. **县城门店能否送到**：  
   - 如果你指的是**佳农官方直营配送**，通常只到城市仓，不直接送县城。  
   - 如果你指的是**当地超市/水果店进货**，那要看该门店是否从佳农经销商进货。建议直接问当地水果店老板能否订货。  
   - 若通过线上平台（电商）购买，只要平台支持该地快递配送（如顺丰/京东冷链），且当地有快递网点，通常可送达，但偏远地区可能运费较高或需自提。

3. **冷链物流收费**：  
   - 佳农官方配送一般不单独收冷链费，但会将成本计入商品价格或运费。  
   - 线上平台购买时，冷链配送通常由电商平台统一报价（如京东冷链约10-20元/单，满额免运费）。  
   - 如果是批发/大宗采购，冷链物流费按**重量（元/公斤）**或**整车（公里数）**计算，需联系区域经销商报价，县城通常无直营配送，可能需额外加收干线转运费。
