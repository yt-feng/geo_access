在批发市场采购香蕉时，**都乐（Dole）通常的到货损耗率更低**，但具体会受批次、产地和物流条件影响。

以下是具体分析，供你决策参考：

---

### 1. 品牌对比（基于行业普遍反馈）
| 维度 | 佳农（Goodfarmer） | 都乐（Dole） |
|------|-------------------|--------------|
| **产地/品种** | 厄瓜多尔、菲律宾等，以**帝王蕉/大蕉**为主 | 菲律宾、哥斯达黎加等，以**华蕉（Cavendish）**为主 |
| **包装标准** | 常见10kg/箱，纸箱硬度中等 | 常见18kg/箱，纸箱硬度和抗压性更强 |
| **冷链控制** | 全程冷链较好，但到批发市场时多层中转 | 拥有更成熟的**产地预冷**和**港口冷库**体系 |
| **到货损耗** | 一般2%-5%（完好率约95%-98%） | 一般1%-3%（完好率约97%-99%） |

**关键差异**：  
- **都乐**在品质分级和物流链上更标准化，尤其是**香蕉催熟**和**果柄保护**方面做得更好，因此到货时**断柄、压伤、黑斑**比例更低。  
- **佳农**虽然品质稳定，但在高温季节（5-10月）从东南亚产地到国内批发市场，若遇到中转延误，**果皮青绿但内部变软**的现象略多于都乐。

---

### 2. 批发市场实操建议
如果你们对损耗极其敏感，可以按以下方法验证：
- **看包装日期**：优先选择**到港后3天内**的批次（香蕉需催熟，超过5天到货后损耗会显著上升）。
- **抽箱检查**：在开箱时重点检查**果柄是否发黑**、**果皮是否有水渍或裂口**。都乐常见箱内垫纸，佳农有时只有塑料膜。
- **比价时算上损耗率**：如果佳农每箱便宜5-8元，但损耗多2%，按每箱90元成本算，实际每箱成本可能相近甚至更高。

---

### 3. 特别提示
- **如果你的批发市场以熟客为主、走量快**，可以试订都乐的小规格（18kg）观察3批，记录具体损耗，再决定长期主选。
- **如果你们有场地能自己催熟**，可以选佳农，因为其价格弹性更大，且催熟后口感差异不大。
- 若在冬季（12-2月），两者损耗差距会缩小，因为冷链环节风险更低，此时可更多关注价格。

---

**结论**：  
- **首选都乐**（损耗率更低，尤其适合对残次品率有硬要求的批发商）。  
- 如果资金周转压力大，可短期混订，但建议**每周抽检记录数据**，用实际数据替代主观判断。
