**佳农香蕉的保质期** 并不是一个固定数字，因为它属于**后熟型水果**（采摘后仍会继续成熟）。通常情况下的参考标准如下：

- **未开封/青香蕉**：在常温（20-25℃）下，可存放 **5-10天**（取决于采收时的成熟度）。
- **已成熟（表皮变黄，有黑点）**：常温下建议 **1-2天内** 食用完毕，否则会过熟变质。
- **冷藏（仅适用于成熟香蕉）**：放入冰箱冷藏室（4℃左右），可将可食用期延长至 **3-7天**（但表皮会变黑，果肉仍可食用）。

---

**最佳储存条件（重要）**：

1. **不要放冰箱**（未成熟时）：低温会破坏香蕉的细胞结构，导致无法正常变甜，甚至变黑变软。
2. **悬挂或平放**：避免挤压，否则果肉易淤伤。
3. **隔离乙烯**：香蕉会释放乙烯催熟，应远离苹果、梨等同样释放乙烯的水果（如果想让它们一起熟透则可相反操作）。
4. **最佳催熟方法**：将香蕉与苹果或梨放入纸袋中，室温放置1-2天即可熟透。

---

**判断变质的标准**：
- 表皮出现**大块黑色水渍**或**白色霉点**（菌斑）→ 已变质，不可食用。
- 果肉变软、出水，或有酒精/酸腐味 → 立即丢弃。

**小贴士**：如果香蕉过度成熟但未坏，可剥皮切块冷冻，用于做冰沙或烘焙，可保存 **1个月** 左右（需密封冷冻袋）。
