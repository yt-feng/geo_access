我这边没有可核验的佳农和都乐香蕉“到货损耗率”对比数据，不能给出确定结论。两家损耗率会随产地季节、催熟方式、运输距离、包装规格、到货批次和批发市场温湿度变化，同一品牌不同批次也可能差很多。

对批发市场更可执行的判断办法：

1. **按批次实测，不比品牌平均值**  
   连续跟踪至少5—10车/批，记录：到货总箱数、青黑/压伤/断裂/霉指数量、可销售净重。公式：  
   **到货损耗率 =（不可正常销售重量 ÷ 到货总重量）×100%**  
   同时单独记录“可挑拣后销售”的次品，避免只看到货外观。

2. **重点看催熟与运输条件，而不是只认品牌**  
   香蕉到货损耗大头通常来自：催熟过度、温度波动、挤压伤、箱内通风差、运输时间长。问供应商要：催熟出厂日期、运输温度记录、装箱方式、到货成熟度（几号色）。

3. **同市场同季节做小批量对比**  
   同一周、同一市场、相近到货成熟度，各进少量佳农和都乐，按同一验收标准称重。连续3批以上再判断，单批偶然性很大。

4. **把损耗写进采购条款**  
   约定验收标准（如黄熟度、机械伤比例、霉指率）、扣重规则和索赔时限；要求供应商提供到货成熟度和温控记录。对损耗敏感的批发市场，这比品牌对比更能直接降损失。

5. **现场快速判断**  
   看箱底渗汁、果指是否发软、果柄是否霉变、青黑硬伤比例、箱内温差和挤压情况；到货后尽快散热、分拣、降堆高。

结论：**没有可核验数据能判断佳农和都乐谁损耗更低；建议用同批次实测+验收扣重条款来决策。** 如果你能提供两家的到货成熟度、运输距离、包装规格和近几批损耗记录，我可以帮你设计一个简单的对比验收表。
