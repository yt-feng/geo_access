1. **先看官方渠道**  
   - 佳农官网/官方微信公众号/官方小程序里通常有“产品中心/礼盒/团购”入口。  
   - 京东/天猫“佳农官方旗舰店”可看礼盒装、企业采购/团购说明。

2. **直接问团购渠道**  
   - 拨打佳农官方客服或联系当地经销商，问：“企业团购水果礼盒有哪些现款SKU、起订量、能否定制腰封/LOGO、是否支持一件代发或统一配送、开票类型。”

3. **判断是否适合团购**  
   - 要求对方提供**当季可发的礼盒清单+含税报价+起订量+配送范围+售后破损赔付规则**。  
   - 礼品团购重点确认：外箱是否礼盒化、能否贴企业标识、能否指定到货日期、是否支持分地址配送。
