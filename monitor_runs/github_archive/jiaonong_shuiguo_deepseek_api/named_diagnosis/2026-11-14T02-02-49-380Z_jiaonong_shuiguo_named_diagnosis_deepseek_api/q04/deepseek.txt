佳农（佳农食品控股/Goodfarmer，进口香蕉、火龙果、车厘子等为主）对长期合作客户通常有账期谈判空间，但没有统一公开的账期政策，是否给、给多久取决于客户类型和合作体量。可参考的判断：

1. **合作渠道决定账期可能性**
   - 商超、连锁水果店、电商平台等有稳定采购量的客户，账期较常见（如月结30/45/60天，或按到货验收后30-60天）。
   - 批发市场档口、一次性采购客户，多为现款现货或短账期（7-15天）。
   - 餐饮/加工客户看合同约定。

2. **长期合作通常要“先跑量再谈账期”**
   - 一般先以现款或预付合作一段时间，建立稳定采购记录后，再申请账期。
   - 账期往往与年度采购量、回款记录、是否独家/主推品类挂钩，可作为谈判筹码。

3. **官方口径需直接核实**
   - 佳农没有对外公示的标准化账期方案，最终以销售合同和区域销售/大客户经理审批为准。建议直接联系佳农当地销售或大客户部，说明采购规模、结算习惯，索取书面报价与账期条件。
   - 核实要点：账期起算日（到货/验收/开票）、是否有账期保证金或担保、逾期罚则、调价与退货条款。

**结论**：有谈账期的空间，但属于“一事一议”的商务条件，不是公开固定方案。若你是采购方，先准备采购量预测和回款记录去谈；若你是想确认佳农官方政策，最可靠的是让对接销售出具书面合同条款。
