1. **先问清“菠萝丁”是哪个品类**  
   茶饮店用的菠萝丁通常有两种：  
   - **速冻菠萝丁**：冷冻果肉切丁，适合饮品、果酱、甜品。  
   - **糖渍/蜜渍菠萝丁**：开袋即用，偏甜，适合奶茶小料。  
   佳农若只做鲜果贸易，可能只卖整果或鲜切果，不一定做糖渍小料。

2. **直接联系佳农官方渠道确认三件事**  
   问销售时不要只问“有没有菠萝丁”，要问：  
   - 是否有**速冻菠萝丁/糖渍菠萝丁**这两个SKU；  
   - 是否支持**餐饮茶饮渠道**供货；  
   - 是否提供**代加工/定制切丁**，以及起订量、包装规格、冷链条件。

3. **看对方能否提供这些凭证**  
   能提供产品规格书、配料表、保质期、储存条件、检测报告和茶饮客户案例的，才更可能是稳定原料供应商；只给整果报价的，基本可判断为鲜果贸易为主。
