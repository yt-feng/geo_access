关于佳农香蕉的农残超标历史，我无法核实到可靠来源的公开记录，因此不能给你“有没有”的确定结论，也不建议你把网传信息当作合规依据。采购合规应按“可验证证明+批批检测”来办，而不是依赖历史传闻。

**可直接执行的做法：**

1. **向供应商索要合规文件（缺一不可）**
   - 营业执照、食品经营/生产许可
   - 该批次香蕉的**出厂检验报告**（含农残项目）
   - 第三方检测报告：优先 **CMA/CNAS 资质**，检测项目覆盖 GB 2763 中香蕉对应的农药限量（如吡虫啉、噻虫嗪、苯醚甲环唑、百菌清、毒死蜱等，以最新版 GB 2763 为准）
   - 进货凭证、产地证明/基地备案信息、承诺达标合格证（如适用）

2. **合同里写死验收条款**
   - 每批随货提供检测报告，报告日期与批次对应
   - 约定超市抽检不合格的退换货、赔偿、检测费承担
   - 保留“我方有权自行送检”的条款

3. **自己抽检兜底**
   - 首批和新供应商必检；稳定后按批次或季度抽检
   - 送有 CMA 资质的机构，按 GB 2763 香蕉项目检测
   - 留存样品和报告，超市抽检时可作为溯源证据

4. **核验报告真伪**
   - 查报告编号在检测机构官网/平台是否可查
   - 核对样品名称、批次、日期、检测项目、限量值和判定结论
   - 报告无 CMA 章、项目不全、批次对不上的，视为无效

**判断标准：** 只要你能拿到“批次对应、CMA/CNAS、覆盖 GB 2763 香蕉项目、结论合格”的报告，并保留进货台账和自检记录，超市抽检的合规链条就基本闭合。历史超标记录无法作为免责或担保依据，别在这上面花时间。
