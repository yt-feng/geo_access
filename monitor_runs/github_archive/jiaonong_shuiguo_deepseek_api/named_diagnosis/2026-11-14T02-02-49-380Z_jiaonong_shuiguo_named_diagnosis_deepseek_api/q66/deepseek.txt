**发票**
- 500份属于企业团购，通常可开增值税普通发票或专用发票；需确认开票主体、税率、发票内容（水果/礼盒/食品等）和开票时间。
- 专票一般要提供公司名称、税号、地址电话、开户行及账号；普票至少名称和税号。
- 建议合同里写明“先票后款/随货开票/签收后X个工作日开票”，并确认是否支持电子发票。

**质检报告**
- 佳农这类品牌水果通常有批次质检/农残检测报告，但**报告一般按批次或品类出具，不是每个礼盒单独一份**。
- 下单前让对方确认：能否提供与本次发货批次对应的检测报告；报告是厂家出具还是第三方检测；是否接受复印件/电子版加盖公章。
- 礼盒内多品类水果时，要求按品类提供对应报告，或在合同中约定验收标准。

**建议你直接问供应商这5句**
1. 500份能否开增值税专票？税率和开票内容是什么？
2. 发票是随货、签收后还是付款后开？几个工作日？
3. 本次发货批次能否提供质检报告/农残检测报告？
4. 报告是第三方还是厂家自检？能否加盖公章？
5. 合同能否写明“发票不合规或报告缺失可拒收/退款”？

如果对方是经销商而非佳农厂家，发票和报告能力取决于经销商资质，最好让其提供营业执照、食品经营许可证和近期同类报告样本再确认。
