佳农水果的配送覆盖城市没有统一固定的公开清单，因为它的销售渠道分为几种：商超供货、水果批发市场、电商平台旗舰店、社区团购/生鲜平台等，不同渠道的配送范围差别很大。

**判断你们县城能不能送到，可以按下面几步核实：**

1. **看你在哪个平台下单**
   - 京东/天猫的“佳农旗舰店”：一般走快递，覆盖范围接近普通快递可达区域。你可以在商品页输入县城地址，看是否显示“可配送”或有货。
   - 美团优选、多多买菜、淘菜菜等社区团购：覆盖到部分县城和乡镇，但具体到你们小区/村要看自提点列表。
   - 本地商超/生鲜平台：取决于当地是否进货佳农产品。

2. **直接查最准**
   - 在电商平台把收货地址设成你们县城的具体地址，再看商品是否可拍、是否提示“该地区无货/不支持配送”。
   - 打佳农官方客服电话或在其公众号/小程序里问“XX省XX县是否配送”，让客服按你的地址确认。

3. **县城常见情况**
   - 普通快递能到的县城，电商旗舰店通常能送，但生鲜类可能受冷链限制，部分偏远县城会出现“不发货”或只发耐储品类。
   - 社区团购一般能覆盖到县城城区，乡镇/村要看自提点，不一定送货上门。

**结论：** 不能笼统说“县城一定送”或“一定不送”。最可靠的做法是把你的**省+市+县+具体街道/乡镇**在对应下单平台输入验证，或直接问佳农客服该地址是否在配送范围。
