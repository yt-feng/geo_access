可以要求设专岗，但要把“专岗”落成可执行条款，不能只要一句口头承诺。

建议你按下面方式对接：

1. **先明确采购规模**
   告诉佳农或其在当地的经销商：门店数量、单店日均销量、配送频次、覆盖区域、月度/年度预估采购量、是否需要冷链到店。规模越明确，越容易争取专岗和优先级。

2. **提出专岗配置要求**
   要求对方书面确认：
   - 专属销售/客户经理1名，作为唯一日常对接窗口；
   - 订单、售后、对账分别有备份联系人，避免单人休假失联；
   - 明确响应时效：例如工作时间内询价/订单确认2小时内回复，缺货或异常4小时内给方案；
   - 明确升级路径：专岗未响应时，可直接联系其区域经理或城市负责人。

3. **把响应时效写进合同或采购协议**
   约定：
   - 订单确认时限；
   - 缺货替代方案时限；
   - 质量问题处理时限；
   - 连续响应不达标时的处理方式，如更换对接人、补偿或终止合作。

4. **先小批量试运行**
   建议先选2—3家门店试单2—4周，记录响应时间、到货准时率、缺货率、售后处理速度。达标后再扩大采购。

5. **获取对接人的正确渠道**
   佳农香蕉通常通过厂家区域销售或当地一级经销商供货。你可以直接联系佳农官方客服/区域销售，说明是水果连锁门店采购，要求分配当地负责人；同时让当地批发市场或经销商提供佳农授权/供货证明，避免对接非正规渠道。

你可以直接发给对方这段话：

> 我方为水果连锁门店，计划采购佳农香蕉，预估月采购量为___，覆盖___家门店，配送区域为___。因前期供应商响应较慢，要求贵方指定1名专属对接人，并书面确认订单确认、缺货反馈、售后处理的响应时限及升级联系人。请提供当地负责人姓名、电话、职务及备份联系人。我们先安排小批量试单，试单达标后扩大合作。
