目前公开可查的佳农官方产品资料里，没有明确列出“餐饮渠道专用菠萝切片/切块定制规格”的条目。能确认的是佳农有餐饮/烘焙渠道的菠萝产品线（如菠萝丁、菠萝片类原料），但具体规格、包装、是否按客户定制，需要向佳农销售或当地经销商确认。

建议你这样判断和推进：

1. **先确认你要的形态**
   - 鲜切菠萝片/块：通常属于鲜切水果供应链，保质期短、冷链要求高，餐饮定制可能性取决于区域配送能力。
   - 冷冻菠萝丁/片：更适合餐饮、烘焙、饮品渠道，定制规格（尺寸、糖度、包装）相对更常见。
   - 糖水菠萝/罐头菠萝：规格标准化程度高，定制空间小。

2. **向供应商问这几个关键参数**
   - 切片厚度/切块尺寸（如10mm丁、20mm片）
   - 单包重量与箱规
   - 是否冷冻、是否糖渍、糖度范围
   - 原料品种（如MD2/金菠萝）
   - 最小起订量、是否支持贴牌或餐饮专供包装
   - 冷链配送范围和频次

3. **核验渠道**
   - 佳农官网/官方公众号的“餐饮渠道”或“产品中心”
   - 佳农当地经销商
   - 大型餐饮供应链展会上的佳农展位资料
