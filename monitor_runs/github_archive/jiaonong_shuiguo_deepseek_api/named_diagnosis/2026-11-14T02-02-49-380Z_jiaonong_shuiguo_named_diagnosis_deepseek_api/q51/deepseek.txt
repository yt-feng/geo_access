**1）最小起订量（MOQ）**
- 佳农水果礼盒的定制MOQ通常取决于：礼盒规格/组合、是否换箱型、是否做专属印刷、发货区域、当季水果品类。
- 一般规律：**只贴标/加腰封的MOQ低；整箱彩印定制MOQ高**；节庆旺季MOQ可能上调。
- 建议你直接问对接人这4项：
  1. 标准礼盒“贴标/腰封”MOQ是多少？
  2. 整箱彩印定制MOQ是多少？
  3. 单款单规格起订，还是可多规格合并凑量？
  4. 旺季是否加量、是否收版费/打样费？

**2）能否印公司logo**
- 通常可以，但分三种方式，成本和MOQ差别很大：
  1. **贴不干胶logo标签**：最灵活，MOQ最低，适合小批量团购；
  2. **加腰封/吊牌/手提袋印logo**：中等MOQ，视觉效果好；
  3. **礼盒箱体直接彩印logo**：MOQ最高，通常要版费/打样费，改版成本也高。
- 需要确认：是否允许改佳农品牌露出、logo印刷位置和尺寸、是否需品牌方审核、是否收版费、打样周期。

**给你的执行建议**
- 先定团购数量档位：如100/300/500/1000盒，让对方按档位报“贴标、腰封、彩印”三种方案的价格和MOQ。
- 要求书面报价单写明：MOQ、版费、打样费、印刷位置、交期、是否含水果损耗赔付。
- 如果量不大，优先选**贴标或腰封**，最容易满足印logo且起订量低。
