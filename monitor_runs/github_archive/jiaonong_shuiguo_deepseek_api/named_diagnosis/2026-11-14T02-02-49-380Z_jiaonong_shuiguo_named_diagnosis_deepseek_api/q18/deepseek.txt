佳农香蕉的包装或官方渠道通常不会给出统一的“保质期天数”，实际保质期取决于成熟度和储存温度。可按下面判断和处理：

1. **储存温度**
   - 未熟/偏青香蕉：放在**13℃左右**的阴凉通风处，避免低于10℃，否则易冻伤发黑。
   - 已熟香蕉：室温阴凉处尽快吃；想延后1–2天可放冰箱冷藏，但**表皮会变黑**，果肉通常仍可食用。

2. **保质期参考**
   - 青香蕉室温（约20–25℃）：通常**3–7天**逐渐转黄成熟。
   - 已熟黄香蕉：室温通常**1–3天**内食用最佳。
   - 冷藏熟香蕉：可放**2–3天**，但外观会变差。
   - 切开后的香蕉：密封冷藏建议**24小时内**吃完。

3. **储存要点**
   - 不要清洗后存放，保持干燥。
   - 悬挂或平放，避免挤压。
   - 与苹果、梨等释放乙烯的水果分开可减缓成熟；想催熟则可放在一起。
   - 表皮出现少量黑点通常表示成熟，不一定变质；若果肉发酸、流汁、霉变则不要食用。

最准确的做法是看佳农包装上的**生产日期/最佳食用期**和标签储存说明；不同批次、产地和运输成熟度会有差异。
