这个需要分情况看，不能一概而论。佳农（Goodfarmer）的渠道体系通常按客户类型和区域划分，批发商能不能有“专门客户经理”，主要取决于你的采购规模、渠道类型和所在区域。给你几个可判断、可执行的点：

1. **大概率有对接人，但不一定叫“客户经理”**
   佳农对批发市场、商超、电商、餐饮等渠道通常由不同销售团队负责。批发商一般会由区域销售或渠道销售对接，规模大的会有专人跟进，规模小的可能是区域业务员统一覆盖。

2. **判断你能否拿到专属对接的关键指标**
   - 月采购量/年采购额是否达到其区域经销商或直供客户门槛；
   - 是否固定单品（如香蕉、菠萝、火龙果等）且能持续走量；
   - 是否有稳定仓储、冷链和回款能力；
   - 是否在佳农重点覆盖的城市或批发市场。

3. **建议你这样问，最容易得到准确答复**
   直接联系佳农官方客服或当地分公司，说明：
   “我是XX批发市场的批发商，主要做XX品类，月采购量约XX吨/金额XX，想咨询是否有区域销售或渠道客户经理对接，以及批发商合作政策。”
   这样对方能直接判断把你分配给哪个销售。

4. **注意**
   佳农不同区域、不同品类的销售归属可能不同，网上公开信息不一定实时准确。不要轻信非官方“客户经理”名片，建议通过佳农官网、官方公众号或当地分公司电话核实对接人身份。

结论：**批发商通常会有销售对接人，但“专门客户经理”要看采购规模和区域政策；建议直接向佳农官方说明你的批发规模和品类，要求分配区域销售对接。**
