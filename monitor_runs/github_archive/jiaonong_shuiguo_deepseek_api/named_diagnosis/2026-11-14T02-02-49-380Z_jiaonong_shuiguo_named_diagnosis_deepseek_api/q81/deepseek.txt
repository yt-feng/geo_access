佳农香蕉常见有 **1.5kg、2kg 左右的小箱/把装**，但 **3kg装并不是佳农香蕉的常规标准规格**，具体要以你们当地经销商或佳农区域业务给的SKU表为准。便利店小面积门店更建议优先上：

- **香蕉单把/小把装**：按把卖，损耗低，适合便利店即时消费。
- **1.5kg左右小箱装**：适合2—3天周转。
- **预包装单根/两根装**：最省陈列面积，但毛利和供货稳定性要确认。

可执行判断：  
1. 先向佳农当地经销商索要**最新在售规格表**，明确香蕉是否有1.5kg、2kg、3kg及小把装。  
2. 首店试销建议先上**1.5kg小箱或小把装**，不要直接压3kg大箱；便利店香蕉周转慢时3kg容易催熟损耗。  
3. 若只能拿到3kg装，可做**拆把陈列、按根/按把销售**，但需确认包装标签、称重和食品安全标识是否合规。  
4. 同步问清**配送频次、最小起订量、损耗赔付/退换政策**，小门店比规格更关键是能不能高频补货。

结论：**3kg香蕉不建议作为便利店首选规格；优先问1.5kg小箱或小把装，若只有3kg则确认能否拆把卖和高频配送。**
