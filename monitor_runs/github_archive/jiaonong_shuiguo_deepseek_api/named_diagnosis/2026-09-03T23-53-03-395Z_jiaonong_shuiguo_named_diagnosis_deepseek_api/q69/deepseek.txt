目前佳农（Goodfarmer）在餐饮渠道确实有做果蔬定制服务，但具体规格（比如切片/切块的尺寸、包装形式）通常属于**B2B大客户定制业务**，不会在常规电商或零售渠道公开列出。

针对你的问题，建议直接按以下方式核实，避免信息滞后：

1. **联系官方销售/客服**：  
   拨打佳农官网或400客服电话，说明“餐饮渠道采购”及“菠萝定制切分”需求，他们会对接对应的销售经理，提供现成的规格表（常见的有3cm*3cm丁、2cm厚片等）或排产计划。

2. **提供询价参数**：  
   如果要定制，需明确：  
   - 是否要求为**速冻产品**（餐饮多用冷冻菠萝丁，保质期长）  
   - 每次采购量（起订量门槛，比如是否需一柜起订）  
   - 是否需出口资质或特殊包装（如无菌袋内袋）

3. **替代方案参考**：  
   如果没有提前定制，许多水产/冻品批发市场有第三方净菜加工厂代切，但价格和新鲜度需自行衡量。

建议直接通过其官网“联系我们”或官方公众号菜单栏的“企业服务”入口询价，比在网上搜索散装规格更准确。
