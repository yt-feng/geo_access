佳农香蕉作为生鲜水果，其“保质期”通常指**最佳食用状态**而非严格的过期时间，具体受成熟度、储存环境影响。以下是通用建议：

---

### 1. **保质期（从购买时算起）**
- **常温（未切开）**：若香蕉表皮尚带绿，可存放 **3~7天**；若已全黄或带黑点，建议 **1~3天**内食用完。
- **冷藏（整根未剥皮）**：可延长至 **7~10天**，但表皮会变黑（不影响果肉）。
- **冷冻（剥皮后密封）**：可保存 **2~3个月**，适合做奶昔或烘焙。

---

### 2. **储存条件**
- **理想温度**：**12~15℃**（阴凉通风处），避免阳光直射。
- **避免低温**：不要放入冰箱冷藏室（低于10℃会加速表皮变黑），除非已完全成熟且吃不完。
- **隔离乙烯**：香蕉会释放乙烯催熟其他水果，建议与苹果、梨分开存放，或悬挂放置减少受压。

---

### 3. **延长保鲜技巧**
- **包裹根茎**：用保鲜膜包住香蕉柄，可减缓成熟。
- **分串存放**：吃多少洗多少，未洗的香蕉不要沾水。
- **已剥皮处理**：若切开，需密封冷藏并在 **24小时内** 食用。

---

### 4. **判断是否变质**
- **可食用**：表皮有黑斑或变黑，但果肉无酒精味、无发软流水、无霉点，仍可食用。
- **不可食用**：果肉变软烂、有异味（酒味或酸味）、表面长白毛/霉斑，请丢弃。

---
