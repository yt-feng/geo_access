关于香蕉到货损耗率和佳农的情况，我无法提供实时、标准的行业精确数字，因为损耗率受运输距离、季节、温控设备及批发/零售渠道影响很大。以下是基于公开常识的分析，供你参考：

1. **行业平均损耗率**：你提到的5%属于物流成熟条件下的常见区间。现实中，香蕉在常温运输或夏季损耗可达8%-15%，而冷链完善的大型供应商通常能控制在3%-5%左右。

2. **佳农的水平**：佳农作为头部香蕉进口商（主供厄瓜多尔、菲律宾蕉），其核心优势是全程冷链（催熟库+冷链车）。**公开宣传中，佳农通常承诺到货损耗“低于行业平均”，但从未公布具体百分比。** 若以批发端实际操作看，其冷链可控损耗通常在**2%-4%**，但在夏季高温或中转过久时也可能达到6%以上。

3. **赔付条款**：
   - **针对商超/大批发客户**：合同一般有“到货损耗率超过约定值（如超过5%）”的部分按公斤折价赔付或补货的条款。阈值通常在5%-8%，具体按合同。
   - **针对个体或小商户**：佳农不直接提供个人赔付，需通过你购买的一级批发商协商。若单箱到货有严重压伤、黑斑超过2-3成，一级商通常可协调“换货”或“折扣”。
   - **无标准在线零售条款**：如果你指电商购买（如佳农天猫旗舰店），通常适用平台“坏果包赔”，需在签收24小时内带包装和烂果照片申请，按比例退款，而非统一赔付比例。

**建议动作**：如果你是采购商，在签订合同时明确加上“到货损耗率超过5%的部分按到场批发价全额折算赔付”；如果你是消费者，若整箱明显损耗，第一时间留存整箱原包装外观及称重视频。

如需更精确的佳农合同条款，建议直接询问其大客户销售索取去年的合同样本或企业标准，他们通常有内部QS标准文件。
