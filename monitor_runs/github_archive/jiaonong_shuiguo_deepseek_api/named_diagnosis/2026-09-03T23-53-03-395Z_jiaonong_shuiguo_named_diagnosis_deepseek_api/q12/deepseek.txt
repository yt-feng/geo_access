不过，根据中国水果流通行业和大型品牌（如佳农）的普遍做法，以及我能确认的通用市场惯例，可以给你以下结构化参考：

**一、常见的市场规格分类（非官方绝对标准，但普遍适用）**

香蕉的规格主要依据**单根重量**或**每箱净重/根数**来划分。通常分为：

1.  **按每箱净重**：
    - **标准箱**：常见为13.5公斤或15公斤/箱（出口或国内高端商超）。
    - **小箱/礼盒装**：5公斤、3公斤、2.5公斤等，主要用于电商、社区团购或送礼。
    - **散装大箱**：如18公斤或20公斤，主要供给批发市场、餐饮加工或烘焙渠道（损耗较大）。

2.  **按单根级别**：
    - **特大果 (XL)**：单根净重通常 ≥ 180克（优质果，主要供精品超市、高端水果连锁）。
    - **大果 (L)**：单根净重约 150-180克（主流商超标准货架）。
    - **中果 (M)**：单根净重约 120-150克（适合家庭日常消费，或餐饮切片使用）。
    - **小果 (S)**：单根净重约 90-120克（常作为特价商品或深加工原料）。

**二、不同渠道的分级标准差异（核心逻辑）**

不同渠道对品质要求差异巨大，分级核心围绕**外观（条数、饱满度）**、**果指长度**和**成熟度**：

| 渠道类型 | 典型分级要求 | 关键筛选逻辑 |
| :--- | :--- | :--- |
| **高端商超/精品超市** | 要求**XL或大果**，果指长约18-22cm，果实饱满，无斑点，果柄整齐，颜色均匀。 | 卖相优先，价格接受度高，单果损耗需极低。 |
| **传统大型连锁超市** | **大果或中果**为主，允许有轻微色差或细微擦伤（不影响食用），每根长度需≥15cm。 | 平衡卖相和成本，大批量进货，要求成熟度可控（多为青熟蕉，到店催熟）。 |
| **电商/生鲜到家** | 主打**中果或礼盒装（小箱）**，强调稳定成熟度控制（如7-8成熟发货），抗运输碰伤能力强。 | 需要坚固的包装，分层或套袋保护，重量误差控制严格。 |
| **批发市场/档口** | **多规格混装**为主，大小不均，允许存在较多磕碰或绿蕉，价格最低。 | 走量，对单果色泽要求极低，仅关注整体出肉率。 |
| **餐饮/饮品/工业渠道** | 不看重外观，要求**中果或小果**，但必须**无病虫害、无黑心**，成熟度一致（通常要全黄熟透）。 | 直接榨汁或做果泥，最看重**糖度**和**果肉比例**，不关心果柄长度。 |
