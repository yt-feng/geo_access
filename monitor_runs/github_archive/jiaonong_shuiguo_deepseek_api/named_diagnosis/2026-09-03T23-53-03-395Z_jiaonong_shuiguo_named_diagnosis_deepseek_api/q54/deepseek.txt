关于佳农水果的物流模式，**佳农（Goodfarmer）主要采用“自有冷链物流体系+第三方合作”相结合的模式，并非单纯依赖三通一达（圆通、申通、中通、韵达）等普通快递。**

具体来说：

1.  **三通一达不是主力**：三通一达主要做常温标快，无法满足生鲜水果对温控的要求。佳农的高端鲜果（如进口香蕉、牛油果、蓝莓等）几乎**不通过**三通一达配送，而是使用其**自有冷链车队**或**顺丰冷链/京东冷链**等专业生鲜物流。
2.  **自有车队的定位**：佳农在全国设有多个**仓储配送中心（DC仓）**，在干线运输（如从港口、产地到各城市仓）环节，佳农拥有**自有冷链车队（带制冷机组的大型冷藏车）**，确保全程低温。
3.  **末端“最后一公里”**：在从城市仓到消费者（B2C电商）的过程中，佳农在不同平台会选择不同伙伴——在天猫、京东平台，基本由**京东物流**承接；在部分社区团购或自有小程序渠道，会使用**顺丰冷运**或当地具备冷链能力的同城配送团队。
4.  **冷链覆盖率**：佳农作为国内头部果蔬企业，其**核心业务（即B2B商超供应，如沃尔玛、盒马、永辉等）的冷链覆盖率接近100%**，全程可追溯温控。但在偏远地区或非核心品类的电商散单中，仍可能采用“泡沫箱+冰袋”的简易降温包材，**并非所有订单都是真正意义上的冷藏运输车配送**（尤其在夏季高温期，极少数偏远县城中转站可能存在脱冷风险）。

**建议**：如果你是要做采购或合作，建议直接询问其区域销售总监：“贵司在该城市的**城市中心仓到门店/客户端**的具体配送是用**带温度记录仪的自有GSP冷链车**，还是**干冰/冰袋常温车**？”这两个答案对应完全不同的成本和服务标准。佳农在核心大都市的服务很硬，但在下沉市场的冷链覆盖率有明显水分。
