**能，但前提是你得先跟他们确认清楚“要哪个规格”——因为菠萝的供应是按“个”和“箱”走的，不是按斤。**  

跟佳农这类大批发商打交道，你需要锁定这两个核心信息：  

1. **单果重量规格**  
   常见的有大概 **1.2～1.8公斤/个**（中果）、**1.8公斤以上/个**（大果）。做奶茶店通常用中果，因为出肉率够、单个切起来效率高。你要问清楚他们这批货是多大果径。  

2. **箱装规格**  
   通常是 **6个/箱 或 8个/箱**，8个装的多为中果。建议你直接问“我要8个装的，单果1.2公斤起，能不能按周固定给我排计划？”  

---

**给你的实操建议：**  

- **不要问**“你们菠萝多大”，要问“**单果多重？一箱几个？**”  
- **要求签短期协议**（比如每周固定送一次），让他们给你报**期货价**（锁定7～15天价格），防止旺季狂涨。  
- **让他们提供样品**——寄2个给你切，看果眼深度、纤维粗细（太粗影响打汁口感）。  
- 如果量不够大，不建议直接对接佳农，可以先问本地一批批发市场，拿货价可能更低。  

如果你一天用不到 **50公斤**，佳农可能不会给你特惠价，但也能供应，就是单价高一点。所以先报出你的月用量，让他们业务报价。
