佳农（Goodfarmer）并未在公开渠道常态化披露“产地直供比例”这一具体数字，不同品类、不同年份差异也很大，所以任何给你的精确百分比都需要警惕来源。

可以确认的是它的供应链模式方向：

- 佳农以全球直采+产地合作基地为主，在香蕉、菠萝、火龙果、车厘子、牛油果等品类上，很多是直接从产地/产区合作方采购，再经自有或合作的分选、催熟、仓储、冷链体系分销。
- 它并不等于“100%从田间直达你”，中间仍有口岸、报关、冷链仓储、催熟加工、区域分拨等环节，只是相比传统多级批发，层级更短。

**如果你采购的目标是减少中间环节、降成本，更实用的做法是：**

1. **按单品分别问，不要问整体比例**  
   直接向佳农要某一具体SKU的供应链路径：产地、是否自有基地/合作基地、是否经第三方贸易商、口岸、仓储节点。

2. **要求报价拆解**  
   让供应商拆分：产地采购价、国际/国内物流、报关、冷链仓储、催熟加工、分拨、损耗、账期成本。这样才能判断哪一层可以压缩。

3. **判断能否绕过佳农直采**  
   - 如果你们单品类采购量足够大且稳定，可以直接对接产区出口商、合作社或境外产地供应商。
   - 如果量不够大、品类多、需要催熟和稳定到货，佳农这类供应链商的集采、冷链和品控能力反而可能比你们自己直采更便宜。
   - 香蕉、牛油果等需要催熟加工的品类，直采未必省，催熟和损耗管理才是成本大头。

4. **用对比采购验证**  
   同一规格、同一产季、同一到货标准下，让佳农、产区出口商、一级批发商分别报价，比较到仓综合成本，而不是只看采购单价。

5. **谈条件而不是只谈价格**  
   可以争取：年度框架协议、产地锁定、规格分级、损耗赔付、账期、到仓价而非离岸价、优先供应权。

**结论：** 佳农的产地直供比例没有公开权威数字，不能作为采购决策依据。你们应要求按SKU披露供应链路径和成本结构，再用“到仓综合成本”对比直采方案。对于采购量大、标准化程度高的单品，直采可能降本；对于需要催熟、冷链、多产地调配的品类，保留佳农这类供应链商往往更划算。
