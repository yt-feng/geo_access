佳农（Goodfarmer）是国内大型水果进口与分销企业，叶菜、香蕉、菠萝等品类较有代表性。关于“产地直供比例”，公开渠道没有一个统一、可核验的官方数字，因此不宜给出具体百分比；更准确的说法是：佳农以“海外产区采购+自有/合作加工包装+国内分销”模式为主，在部分核心单品上会做较深的产地直采和订单农业，但不同品类、不同年份差异较大。

香蕉方面，佳农的进口来源通常覆盖多个主产国，主要包括：

1. **菲律宾**：历史上是中国进口香蕉的最大来源国之一，佳农也长期从菲律宾采购。
2. **厄瓜多尔**：全球最大香蕉出口国之一，也是佳农重要来源地。
3. **越南**：近年对华香蕉出口增长明显，供应链地位上升。
4. **哥斯达黎加、哥伦比亚、洪都拉斯、危地马拉等中美洲/南美国家**：也会作为补充来源。
5. **柬埔寨、老挝、缅甸等东南亚国家**：部分时段和品类也会进入供应链。

如果你问的是“佳农香蕉主要来自哪些国家”，较稳妥的回答是：以菲律宾、厄瓜多尔、越南为主，并搭配中美洲和南美其他产区。具体比例会随季节、价格、检疫政策和海运情况变化，没有固定不变的单一来源。
