1. **找佳农官方渠道问**
   - 佳农官网/官方公众号/官方客服电话
   - 直接问：是否支持餐饮渠道定制规格，如菠萝切片、切块、丁、整果/半果、去皮芯、真空包装、冷链配送等。

2. **问清关键规格参数**
   - 形态：整果、去皮整果、半切、切片、切块、菠萝丁
   - 尺寸：片厚/块径/丁大小
   - 包装：袋装、真空、托盘、大包装
   - 保存：冷藏/冷冻、保质期
   - 起订量：最小起订量、是否支持长期供货
   - 配送：是否冷链、覆盖区域

3. **通过餐饮供应链渠道确认**
   - 如果你用的是美菜、蜀海、锅圈、永辉彩食鲜、盒马企业购等，查它们是否有佳农餐饮装菠萝。
   - 也可以问当地佳农经销商/批发商，餐饮定制通常由区域经销或大客户渠道承接。

4. **替代判断**
   - 如果佳农没有明确餐饮定制，可看其他餐饮供应链品牌是否有“菠萝切片/切块/丁”的冷冻或冷藏标准品。
   - 餐饮渠道常见形式是：冷冻菠萝丁、糖水菠萝片、鲜切菠萝块，不一定挂佳农品牌。
