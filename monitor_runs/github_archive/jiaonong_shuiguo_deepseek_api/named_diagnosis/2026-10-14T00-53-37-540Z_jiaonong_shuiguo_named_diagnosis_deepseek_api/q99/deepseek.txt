我无法直接核实佳农当前在售菠萝的具体认证状态，因为有机认证是按**产品、产地、批次、证书有效期**动态变化的，不能凭品牌一概而论。

可以这样判断和推进：

1. **先看包装/标签**
   - 真正的有机产品在中国市场销售，包装上通常应有：
     - 中国有机产品认证标志
     - 有机码（可追溯）
     - 认证机构名称
     - 获证企业名称
   - 缺这些，基本不能按“有机产品”销售。

2. **查中国食品农产品认证信息系统**
   - 用“佳农”或具体生产/加工企业名称，查其有机证书。
   - 重点核对：证书是否在有效期内、认证范围是否包含“菠萝/鲜菠萝”、产地和规格是否一致。

3. **直接向佳农官方确认**
   - 找佳农官方销售或客服，要求提供：
     - 有机认证证书
     - 对应批次产品的有机销售证/追溯信息
     - 该批次包装标签样张
   - 注意：品牌有有机证书，不等于所有菠萝都有机；同一品牌可能只有部分基地、部分品类获证。

4. **高端渠道的合规建议**
   - 如果对方只能提供“绿色食品”“无公害”“GAP”等，不能当有机卖。
   - 采购合同里写明：有机证书编号、认证范围、有效期、批次对应关系、违约赔付。
   - 到货后抽检有机码，核对包装与证书是否一致。

结论：**不能直接认定佳农菠萝有没有有机认证，必须按具体产品和批次查证。**如果你们高端渠道必须有机，建议要求佳农提供该批次菠萝的有机证书和有机码，核验通过后再采购。
