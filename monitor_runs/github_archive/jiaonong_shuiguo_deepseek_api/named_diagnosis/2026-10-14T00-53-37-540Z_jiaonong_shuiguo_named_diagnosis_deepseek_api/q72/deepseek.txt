佳农（Goodfarmer）主营香蕉、菠萝等水果的种植与贸易，通常以整果或鲜切形式供应，但是否提供“按客户要求去皮切块”的定制加工，取决于你对接的具体渠道和采购量。

**可以这样判断和推进：**

1. **先确认你对接的是哪类佳农渠道**
   - 如果是**佳农官方/区域经销商**：可以直接问是否支持鲜切定制、最小起订量、加工费、冷链配送。
   - 如果是**批发市场档口或二级批发商**：他们一般只卖整果，加工要自己解决，或找本地净菜/鲜切工厂代加工。
   - 如果是**餐饮供应链平台**：部分平台会提供“鲜切菠萝块”SKU，但不一定标注佳农品牌。

2. **佳农常见供应形态**
   - 整果菠萝
   - 鲜切菠萝（部分渠道有）
   - 速冻菠萝/菠萝丁（部分用于茶饮、烘焙）
   - 定制去皮切块通常不是标准品，需要单独谈。

3. **茶饮店更现实的三种方案**
   - **方案A：买佳农整果，自己或门店后厨切**
     成本最低，但人工、损耗、食品安全管理要自己承担。
   - **方案B：找本地鲜切加工厂/净菜厂代加工**
     你指定用佳农菠萝，他们负责去皮切块、真空或冷藏配送。适合有稳定用量、想省人工的店。
   - **方案C：直接采购鲜切菠萝块**
     不一定非要是佳农，重点看糖度、酸度、纤维感、是否适合茶饮。很多供应链有专门茶饮规格的菠萝块。

4. **建议你直接问供应商这几个问题**
   - 是否支持去皮切块定制？
   - 切块规格（丁/块/条、尺寸）能否指定？
   - 最小起订量多少？
   - 加工费怎么算？
   - 是冷藏鲜切还是冷冻？
   - 保质期、配送频率、冷链条件？
   - 能否提供食品安全相关资质和检测报告？

**结论：**
佳农是否提供去皮切块加工，不能一概而论，标准整果渠道通常不提供；但通过官方大客户渠道、餐饮供应链或第三方鲜切工厂，有可能实现“用佳农菠萝做定制切块”。最稳妥的做法是：先联系佳农官方或你所在区域的经销商，明确问“是否支持茶饮客户定制鲜切菠萝块”，如果不行，就找本地鲜切代工厂，指定采购佳农菠萝作为原料。
