1. **先看你们现有合作渠道**
   - 如果你们已经和佳农或洪九有采购/配送协议，直接问对接销售：成都仓是否有现货、今天/明天能否送到、起送量、冷链车型、截单时间。
   - 配送快慢通常取决于**成都本地仓是否有货**，而不是品牌整体。

2. **重点问这4个问题**
   - 成都仓/西南仓有没有你们要的SKU现货？
   - 截单时间是几点？当天送还是次日送？
   - 到成都门店是直送还是中转？中转一般更慢。
   - 冷链、装卸、预约入仓是否包含？门店急需时这些最容易卡住。

3. **如果必须二选一，实操建议**
