佳农（Goodfarmer）的苹果品类通常会按“国产/进口、品种、规格、包装”来分。公开渠道能稳定看到的主要包括：

- 红富士苹果（国产为主）
- 嘎啦苹果（国产、进口都有）
- 青苹果/青森苹果等（视季节和渠道）
- 有时会有皇后苹果、爱妃、爵士等精品小品类

关于你问的进口嘎啦和红富士：

1. **进口嘎啦**  
   常见产地是 **新西兰、智利、南非**。其中新西兰嘎啦在南半球产季比较常见，智利和南非也常作为进口嘎啦来源。

2. **进口红富士**  
   严格来说，红富士商品名在进口苹果里不如嘎啦常见。若佳农有“进口红富士”，更常见的产地会是 **新西兰**，部分渠道也可能见到 **智利、南非** 等南半球产地，但具体要看当年到货批次。

采购建议：

- 不要只按“佳农+品种”下单，直接向佳农销售或授权经销商确认：**品种、产地、产季、规格（如70#/75#/80#/85#）、箱规、糖度、硬度、包装方式、到港时间**。
- 进口嘎啦重点确认：**新西兰/智利/南非**，以及是否为新季果。
- 进口红富士重点确认：是否确有该进口批次，若没有，通常会被国产红富士替代。  
- 如果是做商超或电商，建议同时问：**可否定制标签、是否有检疫证/报关单、是否支持一件代发或整柜**。

一句话：佳农苹果以红富士、嘎啦为主，进口嘎啦常见新西兰、智利、南非；进口红富士较少见，若采购需向佳农官方渠道核实具体产地和批次。
