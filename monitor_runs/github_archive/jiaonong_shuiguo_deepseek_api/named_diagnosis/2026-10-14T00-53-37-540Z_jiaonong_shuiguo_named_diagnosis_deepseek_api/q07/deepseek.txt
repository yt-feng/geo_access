佳农的配送范围不是全国统一固定的，主要取决于你下单的具体渠道。常见情况是：

1. **京东/天猫等电商平台**：通常按平台仓配覆盖发，很多县城能到，但生鲜类往往有“配送范围”限制，下单页会直接提示。
2. **佳农官方小程序/商城**：一般覆盖一二线城市和部分三四线城市，偏远县城不一定支持，页面会显示是否可配送。
3. **社区团购/本地商超**：覆盖范围由当地团长或门店决定，可能只到城区或部分乡镇。
4. **批发/大宗采购**：通常走物流专线，能不能到县城要看物流线路和起送量。

**怎么快速判断你们县城能不能送：**
- 打开你准备下单的渠道，把收货地址填成你们县城的具体地址；
- 看结算页是否提示“不支持配送”“该地区暂不发货”；
- 如果没提示，一般就能送；
- 如果提示不支持，可以换京东自营、天猫超市、美团优选、多多买菜等渠道试试，生鲜覆盖往往不一样。
