佳农水果（通常指佳农集团/佳农食品控股）的到货损耗率并没有一个对外公开、统一适用于所有渠道和品类的官方固定数值。实际控制目标高度取决于品类、运输方式、季节、到货验收标准和渠道类型。

从行业惯例和生鲜水果供应链的常见水平看，可以给你一个可判断的参考范围：

- **整体到货损耗率（从发货到收货验收）**：通常控制在 **3%—8%** 比较常见。
- **耐储运品类**（如香蕉、苹果、橙子、猕猴桃等）：到货损耗率往往可控制在 **2%—5%**。
- **易损/高呼吸跃变品类**（如草莓、蓝莓、樱桃、荔枝、葡萄、芒果等）：到货损耗率可能达到 **5%—10%**，极端情况下更高。
- **商超/电商仓到货验收口径**：很多企业会把可接受损耗设在 **5%以内**，超过部分由供应商承担或按协议扣款。
- **产地直发、冷链较完善的情况**：部分品类可压到 **3%左右**。
- **普通冷链或中转较多的情况**：5%—8%更现实。

需要注意几点：

1. **“到货损耗率”口径不同，数值差异很大**  
   有的只算外观不合格、腐烂、压伤；有的把重量差异、水分流失、规格不符也算进去。口径不同，3%和8%没有直接可比性。

2. **佳农不同品类差异明显**  
   佳农以香蕉、菠萝、火龙果、苹果、猕猴桃等为主，其中香蕉、菠萝等相对耐储运，损耗通常低于浆果类。若你问的是某个具体品类，范围会不同。

3. **实际以合同/验收标准为准**  
   如果是供应商、经销商或商超合作，最可靠的是看合同里的“到货验收标准”和“损耗承担条款”，而不是套用行业平均值。
