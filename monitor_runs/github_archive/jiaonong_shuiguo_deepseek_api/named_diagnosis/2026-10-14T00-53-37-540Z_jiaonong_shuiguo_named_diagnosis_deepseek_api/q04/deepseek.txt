佳农水果（佳农食品控股/佳农集团）主要做香蕉、菠萝、火龙果等进口水果的批发和供应链，B端客户包括商超、电商、水果连锁和批发市场商户。针对长期合作客户，账期方案通常是**有的，但不是标准化公开政策**，而是按客户类型、采购规模和合作历史单独谈。

## 一般规律

**会有账期的情况：**
- 大型商超、连锁水果店、电商平台等稳定走量的长期客户
- 合作时间长、回款记录良好的老客户
- 采购量大、有年度框架协议的客户

**账期通常的形式：**
- 现款现货 → 月结15天/30天 → 月结60天，按合作深度递进
- 部分采用"预付款+尾款账期"的混合方式
- 生鲜品类账期一般比标品短，因为上游采购也要现金周转

**不太会给账期的情况：**
- 新客户、中小批发商
- 单次采购、无稳定量的客户
- 信用记录不明的客户

## 建议你这样做

1. **直接联系佳农的销售或大客户经理**，说明你的采购量、频率和结算需求，账期是需要一对一谈的，网上查不到统一标准。
2. **准备能证明实力的材料**：营业执照、过往采购流水、下游渠道证明，这些是谈账期的筹码。
3. **先从小账期试起**：比如先谈月结15天，跑顺几个月再争取延长。
4. **确认合同细节**：账期起算日、逾期利息、断供条款、最低采购量承诺，这些都要写清楚。

## 提醒

- 佳农是上市公司体系（曾冲刺IPO），财务和信用管理相对规范，账期审批流程会比小供应商严格，别指望一上来就给长账期。
- 具体政策会随市场、品类、区域调整，**以官方渠道答复为准**，不要轻信第三方转述的"标准账期"。
