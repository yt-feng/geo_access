佳农香蕉的保质期和储存条件可以按“未熟—催熟后—已熟”三个阶段来判断：

**1. 未熟/青香蕉**
- 储存温度：**13–15℃** 左右较合适，阴凉通风处即可。
- 不建议放冰箱冷藏，低温容易冻伤，导致表皮变黑、口感变差。
- 保质期：通常可放 **3–7天**，具体看采摘成熟度和室温。
- 如果想延缓成熟，可保持通风、避免和苹果/梨等释放乙烯的水果放在一起。

**2. 催熟后或开始变黄**
- 室温 **18–22℃** 下，一般 **2–5天** 会达到适口状态。
- 成熟速度受温度影响很大：夏天快，冬天慢。
- 想加快催熟，可和苹果或梨一起放在纸袋里；想减慢，就分散放置、降低温度但不要低于约 12℃。

**3. 已完全成熟**
- 最好尽快吃，通常 **1–2天内** 口感最佳。
- 如果吃不完，可以剥皮后切段冷冻，用于做奶昔、香蕉泥；冷藏会加快表皮变黑，但果肉若未冻伤，短时间内仍可食用。
- 已经切开或剥皮的香蕉，建议密封冷藏，**24小时内** 吃完。

**简单判断**
- 表皮青绿、硬：还没熟，放室温。
- 表皮黄、略有香味：适口期，尽快吃。
- 表皮出现黑点但果肉正常：很甜，适合马上吃或做烘焙。
- 果肉发酸、出水、有酒味：不要吃。

**注意**：佳农不同批次、包装和销售渠道可能标注不同，以上是香蕉通用储存规律；如果包装上有明确“保质期/储存条件”，以包装标注为准。
