**一、到货发现坏果，先做这几件事**
1. **不要急着把坏果全扔掉**：先拍照/录视频留证。
2. **拍摄要点**：
   - 坏果和快递面单/包装箱放在一起拍；
   - 切开坏果拍内部（证明是烂心、发霉、软腐等）；
   - 拍整体数量，能看出“坏了几个/一共几个”。
3. **尽快联系客服**：一般要求签收后24–48小时内反馈，越早越好，超时可能被拒。
4. **走原购买渠道申请**：在订单页点“申请售后/退款”，选“质量问题/坏果”，上传照片。

**二、常见处理方式**
- **按坏果比例赔付**：最常见。比如一箱10个坏了3个，退3个的钱或按比例退款。
- **补发**：部分店铺会补发坏果或整箱重发。
- **全额退款/仅退款**：坏得比较多时可能给全退。
- **退货退款**：生鲜一般不要求寄回，因为寄回也会烂，多为直接退款。

**三、如果客服不处理怎么办**
1. 再走平台官方售后入口，申请平台介入；
2. 保留聊天记录、照片、订单截图；
3. 平台介入仍不解决，可向12315投诉（说明商家和平台）。

**四、提高成功率的关键**
- 签收后尽快开箱，别放几天才说坏；
- 照片要能证明“到货时就坏”，不是自己放坏的；
- 不要只文字说“坏了”，一定带图/视频；
- 按购买渠道的规则来，别跨渠道找客服。
