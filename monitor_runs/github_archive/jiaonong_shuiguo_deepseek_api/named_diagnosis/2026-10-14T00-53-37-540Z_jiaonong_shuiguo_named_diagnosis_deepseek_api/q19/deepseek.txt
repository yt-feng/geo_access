佳农水果的配送时效主要取决于你下单的渠道和收货地址，并没有统一的固定答案。可以分几种常见情况来看：

1. **京东自营/京东超市**
   如果商品标有“京东自营”且显示“次日达”，通常下单后**次日送达**；部分城市支持“当日达”，一般要求上午下单、下午送达。具体以商品页显示的预计送达时间为准。

2. **天猫/淘宝旗舰店**
   一般走快递，发货后**1—3天**送达，偏远地区可能**3—5天**。大促期间可能延迟。

3. **美团/饿了么/京东到家等即时零售**
   如果你所在城市有佳农水果的门店或前置仓，通常**30分钟—2小时**送达，适合急用。

4. **社区团购/多多买菜等**
   一般**次日自提**，按平台规定的提货点时间领取。

5. **线下商超或水果店代购**
   取决于门店自己配送，通常**1—3小时**或当天送达。

**判断方法：**
下单前直接看商品页的“预计送达时间”或结算页的配送选项，这是最准确的。也可以先问客服：“发什么快递、从哪个仓发货、到我这里大概几天？”
