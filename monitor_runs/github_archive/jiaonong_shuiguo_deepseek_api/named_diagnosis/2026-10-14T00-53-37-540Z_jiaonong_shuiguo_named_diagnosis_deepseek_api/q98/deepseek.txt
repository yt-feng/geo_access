我们不是佳农官方，也不掌握你和具体经销商、供应商签的合同条款，所以不能直接给你“超过3%包赔”的承诺。这个承诺只能由你的供货方在合同或订单确认里写明。

不过，便利店卖佳农香蕉想做损耗控制，可以按下面这套去谈和落地：

**1）先明确“损耗率”怎么算**
一定要在合同里写清楚，否则后面扯皮：
- 是按“到货件数/箱数”算，还是按“到货重量”算？
- 是只算到货当天验收时的坏果、烂果、断果，还是包括后续门店陈列损耗？
- 损耗率 = 坏果重量 ÷ 到货总重量，还是 = 坏果箱数 ÷ 到货总箱数？
- 谁负责验收、拍照、称重、留存记录？

**2）常见可谈的条款方向**
你可以要求供应商在合同里写明，例如：
- 到货验收时，坏果/烂果超过 **3%**，超出部分按重量补货或折价退款；
- 到货 **24小时内** 发现内部变质、催熟不均、青硬不熟，可申请售后；
- 因供应商冷链或成熟度控制问题导致的批量损耗，由供应商承担；
- 补货、退款、折价三选一，并写清时效，比如 **48小时内处理**。

**3）如果对方不肯承诺3%包赔，可以换条件**
- 要求到货价再低几个点，把损耗风险折进价格；
- 要求小批量、多频次配送，比如每天或隔天送，减少门店压货；
- 要求按“成熟度”分批到货，比如一部分黄熟、一部分青蕉，方便控损；
- 约定首批试销期，比如先试2周，按实际损耗再谈长期条款。

**4）便利店自己必须做的控损动作**
香蕉损耗很大一部分不是到货坏，而是门店管理问题：
- 到货先拆箱检查，别整箱闷着；
- 青蕉和熟蕉分开存放，避免乙烯催熟集中爆发；
- 陈列不要堆压，挂起来或单层摆放更好；
- 每天挑出过熟蕉，及时做折扣、切果盒或员工内购；
- 记录每天销量、报废量、天气、促销，找出订货规律；
- 夏天和冬天订货量要分开定，不能一个量走全年。

**5）你去谈的时候可以直接问这几句**
- “到货验收坏果超过3%，超出部分怎么赔？”
- “是补货、折价还是退款？多久处理？”
- “24小时内发现内部变质算不算售后？”
- “冷链断链或催熟问题导致批量坏果，谁承担？”
- “能不能先小批量试销，按实际损耗再签长期？”

**结论：**
“超过3%包赔”不是行业统一标准，而是你和供应商谈出来的合同条款。你可以把它作为谈判目标，但一定要写成书面条款：**按什么口径算、谁来验收、怎么赔、多久赔**。如果对方不承诺，就压进货价、改小批量配送，或者先试销再决定。
