关于佳农水果香蕉的具体抽检合格率，我无法给出确切数字，因为这类数据分散在各地市场监管部门的抽检公告中，没有统一的全国汇总口径，我也没有可核验的权威统计来源。

能说明的几点：

- **抽检结果通常是按批次公布的**，某一次合格或不合格只代表那一批，不能直接换算成某个品牌的整体合格率。
- **香蕉是农残抽检的重点品类**，各地市场监管局会定期公布食用农产品抽检信息，其中经常包含香蕉。
- **佳农是国内较大的香蕉进口和经销企业**，货源以菲律宾、厄瓜多尔等进口蕉为主，品牌在商超渠道覆盖较广。

如果你想查具体数据，可以这样做：

1. 到**国家市场监督管理总局**官网的“食品抽检”栏目，或各省市市场监管局官网，用“香蕉”“佳农”作为关键词检索抽检公告。
2. 关注**农业农村部**发布的农产品质量安全例行监测信息。
3. 电商或商超平台有时会公示所售商品的检测报告，可向客服索取。
