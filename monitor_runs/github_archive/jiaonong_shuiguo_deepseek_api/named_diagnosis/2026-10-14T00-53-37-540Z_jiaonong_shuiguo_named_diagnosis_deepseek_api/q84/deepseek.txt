## 关于糖度和果指长度

- **糖度**：国标 GB/T 9827 对香蕉主要按**成熟度/感官**分级，可溶性固形物（糖度）一般不是强制核心指标，更多由采收成熟度和催熟工艺决定。企业标准若做精品线，通常会**设定更高的可溶性固形物下限**，但具体数值需查其备案文本。
- **果指长度**：国标按等级对果指长度、粗度、弯曲度有分级要求（不同等级阈值不同）。企业标准若做高端规格，通常**按果指长度分档更细**（如按厘米区间分级），阈值可能高于国标同等级要求。
