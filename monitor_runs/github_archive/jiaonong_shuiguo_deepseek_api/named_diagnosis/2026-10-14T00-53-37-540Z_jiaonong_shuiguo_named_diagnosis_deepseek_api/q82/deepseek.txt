抱歉，我无法直接给出“佳农”和“鑫荣懋”在华东地区谁配送更快的确切结论，因为配送时效取决于具体合作模式、仓库位置、下单时间、门店地址、是否走三方物流以及当天的截单时间，且这类数据会动态变化，没有可核验的公开统一口径。

但针对你“上海门店要次日达”的目标，可以按下面步骤快速判断和落地：

1. **先确认合作仓在哪**
   - 问对方销售/客服：华东仓或上海仓的具体地址、是否支持上海门店直发。
   - 若仓库在苏州、嘉兴、昆山、上海本地，次日达概率高；若从深圳、广州、山东等外地发，次日达通常不稳。

2. **问清截单时间和配送模式**
   - 关键问题：每天几点截单？截单后当天发还是次日发？
   - 是供应商自送、冷链干线+落地配，还是快递/城配？
   - 上海门店次日达一般要求：**华东本地仓 + 当日截单前下单 + 次日城配/冷链落地配**。

3. **直接做小批量实测**
   - 同一天、同一门店、同一时间段，分别向佳农和鑫荣懋各下一个小单。
   - 记录：下单时间、发货时间、到店时间、是否冷链、是否破损、是否需自提。
   - 连续测 3—5 次，比问任何人“谁更快”都准。

4. **合同里写死时效**
   - 不要只依赖口头承诺。
   - 建议写：上海门店订单，截单前下单，**次日 XX 点前送达**；超时赔付或扣款；冷链温控要求；缺货/破损处理。
   - 这样即使某次慢了，也有约束。

5. **通常更稳的判断逻辑**
   - 谁在上海或华东有前置仓/DC，谁更快。
   - 谁用自有冷链城配，谁比走普通快递更稳。
   - 谁支持“次日达”写进合同，谁更可控。
   - 佳农和鑫荣懋都是大型水果供应链企业，但具体到上海门店次日达，**不是品牌层面一比一能定，而是看对接你的区域仓和配送商**。
