佳农水果的香蕉规格和分级会因产地、季节、批次以及具体销售渠道有所差异，公开可查的统一标准并不完整。以下是行业里常见的做法，供你判断和对接时参考：

**一、常见规格维度**

佳农香蕉通常按以下几个维度组合定规格：

1. **按重量/把重**
   - 常见有 1.5kg、2kg、2.5kg、3kg 等装箱或把重规格
   - 商超常见单把 1kg 左右的零售装

2. **按根数/梳数**
   - 单把 4–6 根、6–8 根等
   - 整箱按梳（手）数计，如 4 梳、5 梳、6 梳装

3. **按果指长度和粗度（等级核心）**
   - 特级/一级：果指长、粗度均匀，外观完好
   - 二级：略短或略有外观瑕疵
   - 这是分级最主要的依据

4. **按成熟度**
   - 青蕉（催熟前）与催熟蕉分开供应
   - 不同渠道对到货成熟度要求不同

**二、不同渠道的分级倾向**

| 渠道 | 分级重点 | 常见规格倾向 |
|---|---|---|
| 高端商超/精品店 | 外观一致、无瑕疵、果指长 | 一级/特级，小把精装 |
| 普通商超 | 外观较好、规格整齐 | 一级为主，标准把重 |
| 水果连锁/社区店 | 性价比、周转快 | 一级/二级，中等把重 |
| 电商 | 耐运输、标准化 | 定重装箱，成熟度偏青 |
| 批发市场 | 量大、价格敏感 | 二级及以下，大箱装 |
| 餐饮/加工 | 出肉率、成本 | 二级，对长度要求低 |

**三、需要注意的**

- 佳农作为品牌商，具体分级标准以**当期采购合同或供应商手册**为准，不同产地（如菲律宾、厄瓜多尔、国产）标准可能不同。
- 对接时最稳妥的做法是直接向佳农业务或经销商索取**当批次的产品规格书/验收标准**，里面会写明果指长度、粗度、把重、成熟度、允许瑕疵率等硬指标。
