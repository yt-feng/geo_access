我无法确认"佳农水果菠萝进口量11.4万吨"这个数据的年份和增长率——这类具体的企业经营数据我手里没有可核验的来源，不能凭印象给你补一个年份或增长率，那样容易误导你。

给你几个可判断、可执行的核实路径：

1. **看原始出处**  
   这个11.4万吨是从哪里看到的？如果是新闻报道、行业报告或企业通稿，先看文中是否标注了统计年份（如"2024年""2025年"）和同比/环比表述。很多转发会丢掉年份，导致误读。

2. **找权威来源交叉验证**  
   - 企业侧：佳农食品控股（集团）的官网、年报、IPO/发债披露文件，或官方公众号新闻稿。
   - 行业侧：中国海关总署的进出口统计数据（按HS编码查鲜菠萝/菠萝制品）、中国果品流通协会、农业农村部相关报告。
   - 媒体侧：新华网、人民网、第一财经、界面新闻等对佳农的报道，通常会写明"据佳农方面介绍，2024年进口XX万吨"。

3. **注意口径差异**  
   "菠萝进口量"可能指：鲜菠萝、菠萝罐头、菠萝汁，或含菠萝的混合水果，不同口径数字差别很大；也可能是"佳农自身进口量"而非"全国进口量"。核实时要看清定义。

4. **增长率怎么算**  
   如果两个年份的数据都能拿到，增长率 =（本期－上期）÷ 上期 ×100%。单看一个11.4万吨无法反推增长率，必须有上一期的基数。
