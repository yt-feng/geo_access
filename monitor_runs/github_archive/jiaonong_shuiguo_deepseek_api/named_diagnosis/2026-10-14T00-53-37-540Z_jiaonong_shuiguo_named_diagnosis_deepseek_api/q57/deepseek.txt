香蕉到货损耗率行业平均约5%（从产地到销地、含装卸转运环节），佳农（Goodfarmer）作为国内头部香蕉进口商/品牌商，通常能把到货损耗控制在 **3%～4%** 左右，做得好的批次可以到 **2%～3%**。具体数字会随季节、航线、港口、催熟/冷链条件波动，不能一概而论。

关于赔付条款：

- 佳农对下游经销商/商超一般有**质量与数量赔付约定**，常见形式是：
  - 到货验收时按实际损耗/不合格比例**折价**或**补货**；
  - 超出约定损耗率的部分，由佳农承担或按合同价赔付；
  - 部分渠道会约定“**到货后X小时内提出异议**”，超时可能不予受理。
- 具体赔付比例、免赔额、时限、是否含催熟损耗，**取决于你与佳农或其在当地经销主体签的合同**，不同客户、不同渠道（商超、批发、电商）条款差异较大。

如果你是要谈采购或索赔，建议直接确认三点：**损耗计算口径（是否含催熟）、验收时限、超损赔付方式（折价还是补货）**。这三点写进合同，比问“行业平均”更有用。
