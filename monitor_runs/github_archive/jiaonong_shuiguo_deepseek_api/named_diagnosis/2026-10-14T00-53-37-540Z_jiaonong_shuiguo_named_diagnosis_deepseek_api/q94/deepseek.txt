佳农（Goodfarmer）的香蕉分级标准属于企业内部的商品分级规范，通常不会完整对外公开，而且不同产地（菲律宾、厄瓜多尔、越南等）、不同季节、不同客户类型（商超直供 vs 批发流通）的标准和价差都可能不一样。所以没有一个固定的“官方公开数字”可以直接引用。

可以给你一些行业通用的判断框架，方便你和佳农的业务人员对接时核对：

**香蕉分级通常看这几个维度**

- **条重/单根重量**：一级果一般要求单根重量在某一区间（如 120–160g 或按客户要求），偏轻偏重都会降级。
- **条数/梳型**：每梳的条数是否整齐、是否满梳，缺条、跳把会影响等级。
- **外观**：条身直度、棱角是否明显、有无黑斑、机械伤、药害、日灼。
- **色泽与成熟度**：青果的均匀度、颜色一致性。
- **长度/粗度**：长度和周长是否达标。
- **瑕疵比例**：允许的次品率上限。

**关于一级和二级的价差**

国内香蕉批发市场里，同批次一级果和二级果的价差通常不是固定值，常见区间大概在 **每箱差 5–20 元**，折合到每斤约 **0.3–1.5 元**，具体取决于：

- 当季货源紧不紧（缺货时价差拉大）
- 二级果的瑕疵程度（轻微外观问题 vs 明显损伤，价差能差很多）
- 销售渠道（二级果走电商、加工、低价批发，价格弹性大）

**建议你直接这样问佳农业务/客服，能拿到准确答案：**

1. 你们现在的分级是按条重还是按梳型，具体分几级？
2. 一级果的具体指标（条重区间、允许瑕疵率）是什么？
3. 同期一级和二级的报价分别是多少，按箱还是按斤？
4. 这个价差是固定的还是随行就市？
