关于香蕉的到货损耗率，**佳农**作为国内头部香蕉品牌，其行业公开数据（依据其2022-2023年部分招商材料及果业论坛披露）显示：

- **到货损耗率**：佳农通常宣称可以控制在 **3% - 4%** 以内，低于行业平均的5%。这主要得益于其全程冷链（产地预冷+海运控温+国内冷库）和催熟工艺的标准化。
- **实际波动**：如果是夏季（高温）或远距离海运（如菲律宾、厄瓜多尔），损耗率可能升至 **4%-5%**；冬季或南美近途（如云南产区）则可控制在 **2.5%** 左右。

**关于赔付条款：**

佳农（以及主要水果批发商/电商平台）的赔付通常遵循**“到货即检、超损理赔”**原则，具体条款因渠道而异：

1. **批发/商超渠道（如沃尔玛、盒马）**：合同中一般约定，若到货损耗率超过 **5%**，超出部分按采购价全额赔付；若因催熟不当导致黑心、软烂，经检测确认后，整批货可拒收或按比例折价。
2. **电商/社区团购（如京东、美团优选）**：对消费者端，提供“坏果包赔”——单箱损耗超过 **10%**（即2-3根）即可申请整箱退款或补发；对供应商，则按平台规则扣除相应违约金。

**注意事项：**
- 条款中通常**不包含**“自然熟透变黑”（因运输时间过长导致）和“人为挤压”的赔付，这两类一般不在责任范围内。
- 如果你是与经销商/批发市场合作，务必在合同里写明**“到货后48小时内查验”**，否则逾期视为默认收货。

建议你在签约或采购前，要求对方提供**近三个月的批次损耗报告**，并明确**“损耗率≤3.5%为达标”**的条款——这比仅凭行业均值更可靠。
