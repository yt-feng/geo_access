关于佳农水果（Goodfarmer）香蕉的具体规格和分级标准，我无法提供完全精确、实时的企业内部数据（因为不同产区、季节和合作渠道可能有微调），但根据行业通行做法和佳农作为大型进口水果商的公开信息，可以给出以下参考框架：

**1. 常见规格（按单根重量或包装箱规格）**
佳农香蕉通常以**箱装**为主，常见规格包括：
- **标准出口箱**：常见为 18kg/箱 或 22kg/箱（对应不同产区，如菲律宾、厄瓜多尔等）。
- **小包装（零售/电商用）**：如 1kg、2kg、5kg 的预包装袋/盒，或按“把”售卖（每把约4-7根）。

**2. 分级核心标准（行业通用，佳农基本遵循）**
主要依据**果指长度、粗度、成熟度、完好度**分级：

- **按果指长度**（通常测量果身中部）：
  - **AAA级（大果）**：果指长度 ≥ 22cm（部分标准为24cm+），外观饱满。
  - **AA级（中果）**：果指长度 18-22cm。
  - **A级（小果）**：果指长度 15-18cm。
  - **等外果/次果**：低于15cm或有明显伤残。

- **按成熟度（催熟前）**：
  - **绿熟期（硬绿）**：适合长途运输，发往商超后自行催熟。
  - **微黄期**：部分商超直接上架（如精品超市）。

- **按缺陷分级**：无黑斑、无机械伤、无腐烂、柄部完整。

**3. 不同渠道的侧重**
- **大型商超（如沃尔玛、永辉）**：通常要求**AA级及以上**，长度均匀，成熟度适中（七成熟），包装规格以20kg左右大箱为主，便于统一陈列。
- **精品超市/高端水果店（如盒马、Ole）**：倾向**AAA级**，且外观完美，成熟度略高（八成熟），多用2-5kg小包装，强调即食性。
- **电商/社区团购（如美团优选）**：常采用**2-4kg的小箱或散装**，对尺寸要求稍宽松（AA级即可），但需防挤压，成熟度偏绿（约六成）以延长运输周期。
- **餐饮/烘焙/饮品店**：多采购**价格敏感的A级**或大包装（20kg以上），对成品外观要求低，但对糖度、口感稳定性有要求。

佳农有“佳农”“欧莎”等子品牌，不同品牌定位对应不同分级。具体到某批次，建议直接联系其官方采购部或查看产品箱唛上的标识（如“Size: 26-30 per box”代表每箱果指数）。
