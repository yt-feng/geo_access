关于佳农水果的苹果品类，目前公开资料中，佳农主要经营**进口苹果**，常见品类包括：**红富士（Fuji）、嘎啦（Gala）、蛇果（Red Delicious）、青苹果（Granny Smith）、金帅（Golden Delicious）**等。具体以当季采购清单为准。

针对您关注的**进口嘎啦**和**红富士**，佳农的进口苹果产地通常为**智利、新西兰、美国**（西北部如华盛顿州）和**南非**。

- **进口嘎啦（Gala）**：主要产地为**新西兰、智利**（南半球供应期，如3-10月）和**美国**（北半球供应期）。
- **进口红富士（Fuji）**：主要产地为**智利、美国（华盛顿州）**，少数来自新西兰。

建议您直接联系佳农官方销售或区域经销商，确认当前库存和具体产地批次（因季节和船期，产地会有调整）。如需获取最新采购联系方式，可查询佳农官网或致电其客服。
