在香蕉的到货损耗率方面，**通常都乐（Dole）的损耗率更低**，但实际表现会受渠道、运输批次和天气影响，建议你以**实际开箱验收数据**为准。

**关键对比点（基于批发市场经验）：**

1. **品控标准**：都乐是国际品牌，对采后处理（预冷、催熟控湿、纸箱抗压）要求更严，到货时“黑把、烂果、压伤”比例通常低于国内品牌。佳农水果（国内品牌）近年品控提升，但在极端高温或长途运输中，损耗波动稍大。
2. **到货规格**：都乐常用高强度瓦楞纸箱+海绵隔层，对挤压缓冲更好；佳农部分批次用普通纸箱，若物流野蛮装卸，损耗会明显上升。
3. **区域差异**：在南方批发市场，佳农的本地仓储和周转较快，损耗可能更低；北方市场或跨省直发，都乐优势更明显。
4. **价格与损耗平衡**：都乐单价通常高10%-15%，但若都乐损耗率低3-5个百分点，**整体成本可能反而更划算**。

**给你的具体操作建议：**

- 拿两个品牌的**各5箱试探性进货**，到货后当场开箱，记录：烂果、断柄、压伤、黑皮占比。
- 特别关注**“柄部发黑”**，这是催熟和装运不达标的高发损耗点。
- 对比时统一看“剔除损耗后净重/总进货重量”，而不是只看外观。
- 如果当地有都乐官方经销商，可要求**“到货赔偿条款”**（超出损耗率部分可补货），佳农很少提供此保障。

**一句话结论**：追求稳定低损耗优先选都乐；如果佳农当地渠道能提供更短运输时间和现场退换货，也可以小批量测试，但“无赔偿条款”时慎大批量采购。
