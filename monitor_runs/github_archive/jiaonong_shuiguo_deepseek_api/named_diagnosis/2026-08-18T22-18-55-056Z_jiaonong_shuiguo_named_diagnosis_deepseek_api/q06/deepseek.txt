针对你的问题，**佳农（Goodfarmer）是可以稳定供应的，而且他们的规格划分非常清晰，完全符合普通茶饮店老板能听懂的逻辑。**

不过，为了让采购更清晰，建议你向佳农对接时，直接问清楚以下**两种最常见的商用规格**就行：

**1. 箱装散果（最常见，适合门店现切）**
- **规格**：一般按“箱”卖，每箱约 **8个装** 或 **10个装**（重量约15-20公斤/箱）。
- **成熟度**：他们会明确标注是“**青熟**”（放2-3天催熟）还是“**即食**”（到手就能用）。
- **适合**：如果你需要自己控制果肉新鲜度，或者做果泥、做菠萝丁，选这个。

**2. 去皮菠萝果肉（免切，适合快速出杯）**
- **规格**：按“**桶**”或“**袋**”装，比如 **1公斤/袋** 或 **2.5公斤/桶**。
- **形式**：通常是冷冻果肉或糖水菠萝丁，**糖度、酸度是标准化的**，出杯口感最稳定。
- **适合**：如果你的门店出杯量大，不想浪费人工削皮，直接买这个最省事。

---

**给你一个直接、可执行的建议：**
和佳农对接时，**不要问“有没有大规格”**，直接这样说：

> “您好，我这边是茶饮店，我需要**稳定供应**。请给我报 **10公斤/箱的整果** 和 **2.5公斤/桶的冷冻果肉** 的出厂价，并且请在报价单上写清楚**每箱的个数和每桶的净重**。”

他们肯定会给你一个很清晰的答复。

**如果涉及到供货稳定性，再补充确认一个信息：**
- 问清楚他们**是产地直发还是经销商库存发货**。如果是产地直发，遇到台风或产季尾巴，可能会有补货延迟；如果是经销商中转仓（比如上海、广州仓），那基本是一周两送，非常稳。

**采购前最后提醒一点：**
佳农主要做**菲律宾菠萝**，和国产都乐菠萝比，切出来的**果眼更浅**，损耗小。但要注意**菠萝芯**的硬度，如果做茶饮，建议明确要求“**去芯或半芯**”，这样打出来的果汁更细腻。你可以直接让他们在合同里注明“去芯”二字。

如果你需要具体某个城市（比如一线城市）的佳农服务商电话或大客户经理对接方式，我无法直接给你真实的联系方式，但你可以**在微信搜索“佳农鲜品”小程序**，里面有“企业采购”入口，提交你的餐饮执照信息和意向采购量（比如月需求500公斤），他们的业务员会在1个工作日内主动联系你，并且能提供标准化的报价单。
