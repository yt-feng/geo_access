**1. 能否开发票？**
可以。正规的水果礼品供应商（如佳农官方经销商、大型商超或专业礼品公司）在采购合同中通常包含增值税普通发票或增值税专用发票（需提供公司开票信息）。建议您在下单前与供应商明确开票类型、税率及开票时间，确保“先票后款”或“货款两清后开票”的流程符合您公司的财务要求。

**2. 能否提供质检报告？**
可以。作为大宗采购，供应商应能提供本批次水果的**出厂检验报告**或**第三方质检报告**（如农残检测、重金属检测等）。若供应商无法提供，您可以要求其提供产地证明及官方抽检记录，或商定由您指定的第三方检测机构进行抽样检测（费用由谁承担可协商）。
