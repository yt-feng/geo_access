关于佳农水果（佳农食品控股（集团）股份有限公司，通常指其B2B批发或商超供应业务）的账期，**没有统一的固定天数**，这取决于合作模式、采购规模、信用资质等因素。

**一般情况下的账期参考：**

- **商超/大卖场渠道（如沃尔玛、永辉等）：** 账期通常为 **60天至90天**，部分大型连锁甚至可达120天。这是行业惯例，供应商需垫资。
- **连锁餐饮/烘焙/茶饮企业（大客户）：** 通常为 **30天至60天**，视合同而定。
- **社区团购/电商平台（代销或直采）：** 账期较短，通常在 **7天至30天** 之间，但取决于平台结款规则。
- **批发市场/经销商（现款现结）：** 多数为**先款后货**或**货到付款**，账期极少。

**关于新客户能否申请账期：**

**可以申请，但难度较大，条件严格。** 新客户通常难以直接获得长账期，佳农风控较严。对于新客户，常见的政策是：

1.  **首单现款或短账期：** 首次合作通常要求**预付全款**或**货到付款**，或提供15-30天的极短账期。
2.  **提供资料审核：** 申请账期需提交营业执照、法人身份证、近半年财务报表或银行流水、以及历史采购合同（证明有其他供应商的账期记录）。
3.  **额度限制：** 即使获批，初始信用额度通常较低（比如5万-20万人民币），且需要抵押或预付款担保。
4.  **需对接业务经理：** 佳农的销售多为区域负责制，直接联系当地业务负责人，由其对客户信用评级后上报总部审批。

**给您的具体建议：**

- **如果您是小型餐饮/水果店：** 建议走**现款采购**，或与当地经销商合作（经销商可能有更灵活的短账期）。
- **如果您是连锁商超或大型餐饮企业：** 请直接联系佳农的**大客户部**，提供公司资质和年采购预算，谈判空间较大，可争取45-60天的账期。
- **关键点：** 申请时明确告知**预计年采购量**（比如100万以上），这能显著提高您获批账期及额度的可能。

（注意：以上信息基于行业普遍实践，具体条款请以与佳农签署的购销合同为准。如有确切金额意向，建议直接联系佳农官网公示的地区销售电话获取最新政策。）
