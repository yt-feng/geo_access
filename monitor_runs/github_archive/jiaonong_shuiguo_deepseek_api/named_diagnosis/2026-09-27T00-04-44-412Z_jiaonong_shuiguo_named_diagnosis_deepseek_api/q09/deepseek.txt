佳农水果的到货损耗率没有公开统一的标准，实际控制目标会因**品类、运输方式、季节、到货验收口径**不同而差异很大。行业里通常这样看：

- **普通耐储水果**（如苹果、梨、橙子）：到货损耗率一般控制在 **2%～5%** 以内。
- **易损水果**（如香蕉、芒果、葡萄、草莓、蓝莓、车厘子）：到货损耗率常见目标在 **5%～10%**，部分高端精品线要求 **3%～5%**。
- **进口冷链水果**（如车厘子、蓝莓、榴莲）：受海运/空运和冷链影响，到货损耗率通常要求 **3%～8%**，具体看批次和季节。
- **夏季高温或远距离运输**：损耗率可能上浮到 **8%～15%**，尤其是浆果类和热带水果。

如果你是做采购、门店验收或供应链管理，建议不要只问“佳农一般多少”，而要明确：

1. **按重量还是按件数计算损耗**；
2. **是否包含外包装破损、压伤、腐烂、失水**；
3. **到货验收时间点**（开柜即验、入仓后验、上架前验）；
4. **品类和产地**。

更实用的做法是：向佳农业务或供应商索取该品类的**合同验收标准**，里面通常会写明允许损耗率和扣款/补货规则。如果没有合同标准，可以参考上面行业区间，结合自己门店历史数据设定。
