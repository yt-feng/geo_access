我无法直接提供佳农水果的香蕉农残检测报告——我没有该企业的报告文件，也不能代替厂家出具或调取检测数据。

不过，你采购时想要拿到合规、能应对市场抽检的报告，可以按下面操作：

**1. 直接向供应商索取**
- 找佳农官方销售/客服，或你对接的经销商，明确要“该批次”香蕉的农残检测报告。
- 注意是**对应批次**的报告，不是随便一份历史报告。市场抽检看的是你实际进货那批货。

**2. 确认报告的有效性**
报告要能满足抽检核查，重点看这几项：
- 检测机构有 **CMA** 资质（必要时还要 **CNAS**）；
- 检测项目覆盖香蕉常检农残，如**吡虫啉、噻虫嗪、多菌灵、百菌清、毒死蜱、克百威、氧乐果**等；
- 报告上有**样品名称、批次/生产日期、检测依据标准、检测结果、结论**；
- 结论为“合格/符合”；
- 最好能追溯到你这批货的**批号或进货凭证**。

**3. 如果供应商给不了对应批次报告**
- 要求其补做，或你自己送第三方检测机构对该批次抽检；
- 采购合同里写明：**供应商须随货提供符合国家标准的农残检测报告，并承担因农残不合格导致的抽检损失**。

**4. 注意标准**
国内香蕉农残一般参照 **GB 2763《食品安全国家标准 食品中农药最大残留限量》**，具体项目限值以最新版为准。你可以让供应商在报告里注明依据的是该标准。

**一句话建议**：报告要找佳农官方按“实际进货批次”提供，并核验 CMA、批次对应和检测项目；拿不到就自己送检或写进合同追责。如果你把供应商给到的报告图片或检测项目发我，我可以帮你逐项看是否符合抽检要求。
