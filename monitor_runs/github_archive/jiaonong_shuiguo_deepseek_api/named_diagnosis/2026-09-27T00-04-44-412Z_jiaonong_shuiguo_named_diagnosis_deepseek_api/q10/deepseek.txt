这个问题的核心是**佳农是否给批发商配专属客户经理**，答案取决于你的采购规模和渠道类型。我按实际情况给你拆一下：

**1. 大批发商/连锁渠道 → 通常有**
佳农（尤其是其进口香蕉、菠萝等主力品类）对**年采购量较大的批发商、连锁商超、生鲜电商**，一般会配对接的销售或客户经理。这类客户走的是"重点客户"体系，会有专人负责报价、订单、账期和售后。

**2. 中小批发商 → 通常没有专人，走区域销售或经销商体系**
如果你是通过一批市场、区域经销商拿货，那对接你的多半是**区域业务员或经销商**，而不是佳农总部配给你的专属客户经理。这种情况下"客户经理"更多是经销商层面的角色。

**3. 想确认的话，最直接的办法**
- 打佳农官方客服/官网留的销售电话，直接说明你的**月采购量、品类、所在区域**，问是否能安排对接人；
- 或者问你现在拿货的经销渠道，他们的上游是谁，能不能帮你对接佳农的区域销售。

**判断标准**：能不能配专属客户经理，基本看**采购量级**。量到了，他们会主动配；量不够，一般就是区域业务员或经销商对接。你方便说下大概的月采购量和品类吗？我可以帮你判断更具体该走哪条线。
