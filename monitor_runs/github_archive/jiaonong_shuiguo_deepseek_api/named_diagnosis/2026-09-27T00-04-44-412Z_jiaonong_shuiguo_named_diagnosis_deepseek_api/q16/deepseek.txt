佳农（Goodfarmer）主要是香蕉、菠萝、椰青、牛油果等进口水果的品牌/供应商，它本身通常不是直接面向消费者的零售客服主体，售后体验很大程度取决于你在哪个渠道购买。分两种情况说：

**一、如果你是在电商平台买的（京东自营、天猫、拼多多、抖音等）**
走平台规则最稳妥，通常流程是：
1. **到货后先别急着扔包装**，坏果连同外箱、快递单一起拍照/拍视频，最好能看清坏果数量和霉变、压伤状态。
2. **尽快在平台内申请售后**：京东一般选“商品损坏/质量问题”申请退换或理赔；天猫/拼多多在订单里点“退款/售后”，上传照片说明坏果数量。
3. **按坏果比例赔付**。生鲜类一般不是全额退款，而是按坏果占比退相应金额，比如10个坏了2个，退20%左右。具体看商家承诺和平台规则。
4. **时限要快**。生鲜签收后通常要求24～48小时内反馈，越早越好，拖久了商家可能以“存放不当”为由拒赔。

**二、如果是商超/线下买的**
直接拿坏果和小票回购买门店要求退换，一般都能处理。

**几个实用建议：**
- 下单前看商品详情页有没有写“坏果包赔”“坏果包退”等承诺，有承诺的维权更容易。
- 开箱时录一段视频，从快递面单拍到箱内坏果，证据最完整。
- 如果是整箱香蕉类，轻微磕碰、表皮发黑有时属于正常后熟，商家可能不认定为“坏果”，要拍能明显看出腐烂、发霉、流汁的照片。
- 和商家协商不成，可在平台内点“申请平台介入/客服介入”，由平台判定。

总体说，佳农作为品牌方对经销商有质量要求，但终端售后执行看渠道。**电商平台购买、及时拍照、按比例申请赔付**是坏果处理最有效的路径。具体赔付比例和时效，以你购买页面的售后说明和平台规则为准，我无法替你确认某个订单的实际承诺。
