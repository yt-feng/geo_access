佳农和盒马这类合作的**公开细节通常不会完整披露**，所以无法直接确认它是“纯直供”还是“纯代销”。但可以按零售业常见做法帮你判断，并给出超市可参考的落地方式。

## 1. 佳农与盒马更可能是什么模式

大概率不是单一模式，而是**混合模式**，常见组合是：

- **头部单品/爆品：偏直供**
  - 佳农作为品牌方或一级供应商，直接供货给盒马。
  - 盒马采购后自营销售，赚进销差价。
  - 适合香蕉、菠萝、椰青等标准化程度高、周转快的单品。

- **新品/试销/联名/礼盒：偏代销或联营**
  - 供应商把货放进盒马渠道，盒马按销售额扣点。
  - 卖不掉可能退货、换货或由供应商承担损耗。
  - 适合不确定性高、需要试水的新品。

- **部分品类可能是“直供+返点+账期”**
  - 表面是直供，实际合同里有返利、促销费、损耗分担、账期等条款。
  - 所以不能只看“直供还是代销”两个标签。

简单说：  
**佳农给盒马供基础大单品，更像直供；做新品、礼盒、联名、促销资源位时，可能带代销/联营成分。**

## 2. 你们超市能不能参考

能参考，但不要照搬。关键看你们自己的三个条件：

1. **门店规模和销量**
   - 单店或小连锁销量小，直供拿不到好价格，也压不起库存。
   - 区域连锁有一定销量，才适合谈直供或联营。

2. **现金流和损耗承受能力**
   - 直供：你买断，毛利可能高，但损耗和库存风险归你。
   - 代销：你风险小，但毛利低，且供应商可能不愿配合。

3. **是否有冷链和周转能力**
   - 水果直供最怕压货。
   - 没有稳定客流和冷链，直供容易变成高损耗。

## 3. 给超市的可执行建议

### 建议一：先做“分类分级”，不要一刀切

| 品类 | 建议模式 | 原因 |
|---|---|---|
| 香蕉、苹果、橙子等高频大单品 | 直供或产地直采 | 销量稳，适合拿成本优势 |
| 椰青、菠萝、进口水果 | 直供+账期 | 品牌化强，适合做毛利 |
| 新品、小批量礼盒 | 代销/联营 | 降低试错成本 |
| 本地应季水果 | 联营或代销 | 价格波动大，直供风险高 |

### 建议二：先谈“小批量直供试销”

不要一上来就签全年大合同。可以这样谈：

- 先选 3—5 个单品；
- 供应商给直供价；
- 你给 1—2 个月试销期；
- 约定损耗分担比例；
- 卖得好再扩大采购。

这样既能测试直供，又不至于库存压死。

### 建议三：合同里必须写清楚这 6 件事

1. **结算方式**：直供买断，还是代销扣点；
2. **退货条件**：临期、损耗、卖不动怎么处理；
3. **账期**：现结、30 天、45 天还是 60 天；
4. **促销费用**：堆头、DM、试吃谁承担；
5. **价格保护**：供应商降价时，你的库存怎么补差；
6. **独家或区域保护**：附近同行能不能拿到同价。

### 建议四：如果你们量小，优先考虑“联营/代销+保底毛利”

对小超市更稳的方式是：

- 供应商供货；
- 你提供货架和收银；
- 按销售额扣 15%—25%；
- 损耗由供应商承担或双方按比例承担；
- 设保底毛利，卖不到保底供应商补。

这比纯直供更适合客流不稳定、资金不宽裕的超市。

### 建议五：不要只盯着佳农

佳农和盒马的合作，核心不是“佳农”两个字，而是：

- 品牌水果；
- 稳定品质；
- 稳定供应；
- 有动销支持。

你们可以找**区域水果供应链公司、批发市场头部商户、产地合作社**做类似模式。  
对中小超市来说，区域供应链往往比全国品牌更灵活。

## 4. 最终判断

- **佳农和盒马**：很可能是直供为主、代销/联营为辅的混合模式，具体要看品类和合同。
- **你们超市**：可以参考，但建议先用“小批量直供试销 + 新品代销 + 大单品直供”的组合，不要直接照搬。
- **最稳做法**：高频大单品谈直供，新品和礼盒谈代销，本地应季水果谈联营，同时把损耗、账期、退货、促销费用写进合同。
