## 一、香蕉常见的规格维度

香蕉不是只按“几根”分，通常同时看这几个维度：

1. **单根重量/条重**
   - 小条：约 90–120g
   - 中条：约 120–150g
   - 大条：约 150–180g
   - 特大条：180g 以上
   - 不同公司区间会调整。

2. **每箱净重**
   - 常见：4.5kg、5kg、7kg、10kg、12kg、13kg、15kg、18kg、20kg 等。
   - 商超、电商、批发市场常用不同箱重。

3. **每箱根数**
   - 常见：3–5根装、6–8根装、10–12根装、13–16根装、18–22根装等。
   - 根数越少，通常单根越大，适合零售小包装。

4. **成熟度/催熟阶段**
   - 青蕉：适合长途运输、批发、催熟库。
   - 微黄/黄绿：适合商超、水果店。
   - 黄熟/即食：适合电商、即时零售、便利店。
   - 全熟：适合餐饮、烘焙、果汁。

5. **外观等级**
   - A级：果形直、饱满、无疤、无黑点、色泽均匀。
   - B级：轻微花皮、果形稍弯，但不影响食用。
   - C级/加工级：外观差，适合加工、餐饮、果汁。

6. **产地/品种**
   - 菲律宾、厄瓜多尔、越南、云南、广西、海南等。
   - 品种如巴西蕉、威廉斯蕉、小米蕉、粉蕉等，规格差异很大。

## 二、按渠道看，常见分级标准

| 渠道 | 常见规格 | 分级重点 | 适配逻辑 |
|---|---|---|---|
| 大型商超 | 5kg/7kg/10kg箱，单根130–160g，6–12根装 | A级、果形整齐、颜色一致、无斑 | 陈列好看，损耗低，客单价稳定 |
| 社区水果店 | 7kg/10kg/12kg箱，单根120–150g | A/B级，允许轻微花皮 | 价格敏感，周转快 |
| 电商/即时零售 | 3–6根小包装，单根120–150g | 成熟度可控、耐运输、无严重碰伤 | 配送易坏，需小规格和即食/微黄 |
| 批发市场 | 12kg/13kg/15kg/20kg大箱 | 青蕉为主，A/B级混合 | 走量，靠催熟和分销 |
| 餐饮/茶饮/烘焙 | 10kg/15kg/20kg，或加工级 | 成熟度、出肉率、价格 | 不要求外观，要求稳定供应 |
| 便利店/自动售货 | 1–3根装，单根100–130g | 即食、小规格、独立包装 | 冲动消费，方便拿取 |
| 团购/福利 | 5kg/7kg/10kg箱，家庭装 | 性价比、外观尚可 | 量大，价格优先 |

## 三、如果按“等级”粗略划分

- **精品级**：单根约130–160g，A级，6–8根/箱，适合高端商超、精品水果店、礼盒。
- **商超级**：单根约120–150g，A/B级，10–12根/箱，适合连锁超市、社区店。
- **电商级**：单根约110–140g，微黄成熟，3–6根小包装，适合线上、即时零售。
- **批发级**：单根约100–150g，青蕉，12–20kg/箱，适合批发市场、催熟商。
- **加工级**：单根不限，B/C级，适合餐饮、果汁、烘焙。

## 四、判断佳农香蕉具体规格的方法

你可以直接看这5个地方：

1. **外箱标签**：通常写净重、根数、单根克重、等级、产地、催熟建议。
2. **合同/报价单**：会写“规格：XXg XX根/箱”或“XXkg/箱”。
3. **佳农官网/公众号/小程序**：看产品中心或招商资料。
4. **业务员提供的装箱单**：最准确，能对应批次。
5. **电商详情页**：看单果重、总重、根数，但电商描述有时不按批发分级。
