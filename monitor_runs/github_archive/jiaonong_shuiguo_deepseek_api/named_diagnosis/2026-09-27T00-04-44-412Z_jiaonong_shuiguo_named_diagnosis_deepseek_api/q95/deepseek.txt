佳农（Goodfarmer）并没有在公开渠道披露“产地直供比例”这一具体数字，我无法给你一个可核验的准确百分比。它的业务模式本身主要就是产地采购+自有加工/分选+渠道分销，所以“直供”在不同口径下差别很大（按其采购端算、按到零售端算、按是否经批发市场算，结果完全不同）。

对你们采购端更实际的做法是：不要纠结这个比例，直接按可执行的降本路径去谈。

**建议的询价与谈判要点**

1. **明确你要的口径**
   - 是“产地装车价”还是“到你们仓库价”？
   - 是否含分选、包装、催熟、冷链、损耗？
   - 要求对方拆分报价：果价 + 加工费 + 包装 + 物流 + 账期成本。

2. **争取跳过一级批发**
   - 直接问佳农区域销售或大客户部能否做“产地直发”。
   - 要求提供产地或加工厂地址、批次、采摘/加工日期。
   - 小批量先试单，验证品质稳定性和到货损耗。

3. **用数量换直供资格**
   - 单品类年度/季度预估量给到对方，换产地直发价。
   - 约定阶梯价：比如按柜/按吨/按车，量越大单价越低。
   - 要求锁定一个采购窗口期的价格，减少中间倒手。

4. **替代方案：直接对接产地合作社或加工厂**
   - 佳农本身也是从产地采购，你们可以平行接触同类产地的合作社、包装厂。
   - 重点看：分选能力、冷库、是否有出口级品控、能否稳定供货。
   - 通常能比经品牌商再分销低一截，但要自己承担品控和物流。

5. **成本对比表这样算**
   - A：佳农到仓价
   - B：产地直发到仓价（含运费、损耗、账期）
   - C：批发市场采购价
   - 用“到手可用斤价”比较，而不是报价单单价。

**现实判断**
如果你们采购量不大、品类杂、要求账期，佳农这类品牌商的分销体系未必比批发市场便宜多少；真正降本要靠“单品聚焦 + 产地直发 + 自担部分物流/品控”。量足够大时，再找佳农谈直供，或直接找其上游产地供应商，才更有可能把中间环节压掉。
