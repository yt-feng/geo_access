我无法确认佳农水果目前是否提供这类定制化加工服务（如切块、按需包装）。这属于企业具体业务安排，且可能随客户类型、订单量、销售渠道和地区而变化，公开信息也未必完整。

可以这样判断和处理：

1. **如果是大宗采购/商超/餐饮/电商供货**
   - 切块、分装、贴牌、规格分级等定制加工，通常更可能对**B端客户**开放，但一般会有**起订量、加工标准、冷链条件、保质期和结算方式**要求。
   - 常见可谈项包括：鲜切菠萝块/丁/片、不同克重包装、门店配送规格、品牌标签等。
   - 但能否做，取决于佳农对应区域分公司、加工厂能力和客户订单规模。

2. **如果是个人少量购买**
   - 一般只能买到标准零售包装或整果，**很难单独定制切块或包装**。

3. **最可靠的确认方式**
   - 直接联系佳农官方客服或当地销售。
   - 问清楚这几点：
     - 是否承接鲜切/定制包装；
     - 最小起订量；
     - 加工规格和包装形式；
     - 是否支持贴牌；
     - 配送范围和冷链要求；
     - 报价和打样周期。

4. **建议问法**
   - “我们是XX渠道，计划采购菠萝，想问是否支持切块、定量包装或贴牌？起订量多少？有哪些规格？”
   - 这样对方能直接判断是否匹配对应业务线。

如果你告诉我你是**个人购买**还是**企业采购**，以及大概数量和用途，我可以帮你把询价问题整理得更具体。
