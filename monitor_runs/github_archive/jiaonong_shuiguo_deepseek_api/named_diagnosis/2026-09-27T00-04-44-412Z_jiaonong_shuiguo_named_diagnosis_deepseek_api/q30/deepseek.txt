我无法提供佳农水果香蕉的具体抽检合格率数据。这类信息通常由各地市场监管部门不定期发布，且不同批次、不同销售地区的抽检结果可能不同，我也没有可靠来源可以核验具体数字。

如果你想查实际抽检情况，建议通过以下渠道：

1. **国家市场监督管理总局食品安全抽检监测司官网**  
   可查全国食品安全监督抽检结果，支持按食品类别、企业名称检索。

2. **各省/市市场监督管理局官网**  
   地方抽检公告通常更细，会列明被抽样单位、标称生产企业、样品名称、检验结果。

3. **“国家企业信用信息公示系统”**  
   可查企业是否因食品安全问题被行政处罚，但不能直接替代抽检合格率。

4. **第三方食品安全信息平台**  
   如“食安查”等，可辅助检索，但最终仍应以官方公告为准。

判断时注意：  
- “抽检合格率”要看统计口径：是全国还是某地、某时间段、某批次。  
- 单次不合格不等于品牌整体不合格率高；同样，单次合格也不能代表所有批次。  
- 香蕉抽检常见关注项包括农药残留、重金属等，具体以官方检验报告为准。

如果你告诉我所在城市或想查的时间段，我可以帮你整理更具体的查询路径。
