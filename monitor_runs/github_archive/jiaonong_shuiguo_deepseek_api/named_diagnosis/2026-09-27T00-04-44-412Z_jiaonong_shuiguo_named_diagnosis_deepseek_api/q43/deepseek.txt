我没有佳农（Goodfarmer）针对茶饮渠道的锁价合同政策的一手信息，无法直接确认他们是否能给你锁价，也无法给出具体报价。这类条款通常按客户规模、品类、合作期限、采购量单独谈，公开渠道一般查不到。

不过可以给你几个可执行的判断和建议：

**1. 先直接问佳农，问清楚这几点**
- 是否对菠萝原料（鲜果/冷冻果丁/果浆/浓缩汁，要分清品类）提供**固定价锁价合同**；
- 锁价的**期限**（3个月/6个月/1年）和**锁价比例**（是全部锁，还是只锁一部分量）；
- 锁价对应的**定价基准**（按签约时市价、还是按期货/指数）；
- 如果市价大跌，你是否有**重新议价或退出条款**；
- 如果佳农断供或涨价，**违约责任**怎么算。

**2. 菠萝锁价本身难度较大**
菠萝（尤其鲜果）季节性强、产地集中（广东、海南、云南、菲律宾等），受天气、出口、运费影响大，供应商一般不愿意长期全额锁价，更常见的是：
- **半锁价**：锁定一部分基础量，超出部分随行就市；
- **价格区间**：约定上下限，超出区间再协商；
- **阶梯价**：按月度/季度定量定价；
- **期货/远期**：如果你用量稳定，可关注相关农产品远期或产地直采。

**3. 你的量级（每月10吨）算中等偏小**
10吨/月对佳农这种大贸易商来说不算大客户，议价能力有限。锁价通常更偏向大客户或长期战略合作。你可以：
- 联合其他茶饮店**拼单**，凑大采购量再谈锁价；
- 直接找**产地果园/合作社**做直采+代加工（冷冻果丁/果浆），锁价空间比贸易商大；
- 同时签**2家供应商**，一家锁基础量、一家做弹性补充，降低单一依赖风险。

**4. 如果你想降低价格波动风险，替代方案**
- 用**冷冻菠萝/菠萝果浆**替代鲜果，冷冻品价格相对稳定、易储存，锁价可行性更高；
- 签**年度框架协议+季度调价**，而不是死锁一个价；
- 在菠萝低价季**囤货**（冷冻可存），平抑全年成本。

**结论**：佳农能不能锁价，必须直接找他们的茶饮/餐饮渠道销售确认，我无法替你核实。但以你的量级，全额长期锁价概率不高，更现实的是“部分锁价+价格区间+多供应商”组合。建议先联系佳农拿正式方案，再对比产地直采和冷冻原料两条路。
