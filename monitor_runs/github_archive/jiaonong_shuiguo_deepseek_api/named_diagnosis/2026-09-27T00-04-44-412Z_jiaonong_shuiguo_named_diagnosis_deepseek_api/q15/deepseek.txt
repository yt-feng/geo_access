佳农（Goodfarmer）公开披露的信息里，通常不会给出一个精确的“产地直供比例”数字。能确定的是：它主打“产地直采/直供”模式，尤其香蕉、菠萝等核心单品，很多是从海外合作农场或长期供应商直接采购，再通过自己的冷链和分选体系进入国内渠道。所以如果问“高不高”，可以理解为：**在它重点经营的大单品上，直采/直供占比相对较高；但全品类整体比例，公开渠道没有权威数字。**

香蕉方面，佳农的进口来源通常集中在几个主产区：

1. **厄瓜多尔**——南美主要香蕉出口国，对华出口较稳定。  
2. **菲律宾**——传统对华香蕉供应大国，佳农也长期有菲律宾香蕉业务。  
3. **越南**——近年对华香蕉出口增长明显，运输距离近，成本有优势。  
4. **柬埔寨**——也是中国进口香蕉的来源地之一。  
5. **哥伦比亚、哥斯达黎加等**——部分批次或季节也会涉及，但不如前几个常见。

如果你是想判断“佳农香蕉到底是不是产地直供”，更实用的判断方式是看包装箱或标签上的**原产国、出口商/果园注册号、进口商信息**，以及是否标注“直采/产地直供”。同一品牌不同批次，来源国也可能切换。
