能确定的是：5%是行业里常被提到的参考水平，但“到货损耗率”本身口径很关键，谈赔付前必须先对齐定义，否则数字没有可比性。

**建议你这样判断和推进：**

1. **先对齐损耗口径**
   - 是“到货即抽检损耗”，还是“到货后24/48小时损耗”？
   - 是重量损耗、数量损耗，还是不合格品率？
   - 是否包含青蕉转黄过程中的失水、催熟损耗、机械伤、压伤、黑斑？
   - 抽检比例、抽样方法、判定标准是什么？

2. **佳农可能给出的控制水平**
   - 公开层面通常不会承诺一个固定“全国统一损耗率”。
   - 实际合作中常见做法是按客户约定：比如到货验收合格率、单项缺陷率、赔付触发线。
   - 如果对方声称能显著低于5%，要问清楚对应的是哪个口径、哪个季节、哪条线路、哪种包装和运输方式。

3. **赔付条款重点看这些**
   - 触发条件：超过多少损耗开始赔，是按整批赔还是按超出部分赔？
   - 计算基数：按采购金额、到货数量，还是按不合格重量？
   - 免赔额/免赔率：是否设了3%、5%的免赔门槛？
   - 举证方式：谁检测、何时检测、是否允许复检、第三方检测是否认可？
   - 赔付形式：现金折让、补货、下批抵扣，还是退货？
   - 时效：到货后几小时内提报有效，过期是否视为验收合格？
   - 除外责任：台风、高温、港口延误、客户方卸货不及时等是否免责？

4. **最稳妥的做法**
   - 直接向佳农索取你所在渠道的**标准供货合同/质量协议模板**，重点看“验收标准”和“质量赔付”章节。
   - 要求对方书面确认：损耗率定义、目标值、赔付触发线和计算方式。
   - 如果是大客户，可以把“到货48小时损耗率”写进合同，并约定超出部分按重量或金额赔付。
