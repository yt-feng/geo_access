佳农（Goodfarmer）有针对礼品和团购场景的水果礼盒，但具体产品会随季节、渠道和地区变化，建议你按下面方式确认和筛选。

**1. 常见礼盒方向**
佳农比较常见的是围绕自家优势单品做礼盒，例如：
- 香蕉礼盒
- 菠萝/凤梨礼盒
- 猕猴桃礼盒
- 苹果、橙子等应季水果组合
- 部分节庆档期的混合水果礼盒

**2. 礼品团购通常怎么走**
- **企业团购/批量采购**：一般联系佳农官方销售、区域经销商，或京东/天猫等平台的企业购入口。
- **电商零售礼盒**：京东、天猫、拼多多等平台搜索“佳农 水果礼盒”“佳农 团购礼盒”，能看到当前在售款。
- **线下渠道**：大型商超、水果连锁店、批发市场经销点也可能有节庆礼盒。

**3. 判断是否适合团购，重点看这几点**
- 是否支持**批量下单、开票、对公付款**
- 是否支持**定制贺卡、外箱贴标、logo印刷**
- 配送范围是否覆盖你的收货城市
- 礼盒是**固定组合**还是可自选搭配
- 节假日前是否要**提前锁库存**，尤其是中秋、春节、端午前后
