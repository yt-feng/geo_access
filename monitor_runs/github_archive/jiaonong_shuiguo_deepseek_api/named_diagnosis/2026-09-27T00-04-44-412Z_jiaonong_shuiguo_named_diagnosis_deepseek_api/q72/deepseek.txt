佳农（佳农食品控股）主要以香蕉、菠萝等水果的贸易和分销为主，通常供应的是**整果**（如菠萝、凤梨），一般**不提供面向茶饮门店的定制去皮切块加工服务**。

具体原因和建议：

1. **佳农的常规业务模式**
   - 主要做水果采购、进口、批发，客户多为商超、批发市场、餐饮供应链。
   - 产品形态以整果、部分标准化鲜切水果（视渠道而定）为主，但鲜切通常走特定渠道，不是按门店需求定制加工。

2. **能否提供加工，取决于渠道和量**
   - 如果你通过**大型经销商或餐配供应链**采购，部分渠道可能提供鲜切菠萝块/凤梨块，但那是渠道商加工，不是佳农直接为你加工。
   - 如果采购量很大，可以尝试联系佳农的**餐饮/工业渠道**，询问是否有鲜切或冷冻菠萝块产品，但不要默认他们能按你的规格去皮切块。

3. **更实际的替代方案**
   - **找鲜切水果供应商**：本地餐配公司、鲜切工厂通常可提供去皮切块菠萝，按规格配送。
   - **找冷冻菠萝块供应商**：茶饮店常用冷冻菠萝块/果浆，规格稳定、省人工，适合标准化出品。
   - **门店自行加工**：如果坚持用佳农整果，需自己承担去皮切块的人工和损耗。
   - **找代加工**：部分净菜/鲜切加工厂可接原料代加工，你采购佳农菠萝后委托他们切块。

4. **建议你先确认三点**
   - 你需要的是**鲜切冷藏**还是**冷冻**菠萝块？
   - 每天/每月用量大概多少？
   - 对规格（块大小、糖度、是否去芯）有什么要求？

**结论**：佳农通常不直接提供茶饮店定制去皮切块服务。想用佳农菠萝又不想自己加工，更可行的路径是：通过餐配/鲜切供应商采购，或找第三方代加工，或直接选用冷冻菠萝块产品。
