我无法确认"佳农水果"的香蕉有过农残超标记录——手头没有可核验的抽检数据库或官方通报来源，不能给你肯定或否定的结论，这点必须先说清楚。

而且这类问题本身也**不能靠"有没有历史"来判断**，历史没超标不等于你这批货合格，超市抽检看的是**这一批的检测结果和随货证明**。下面按采购合规的实际需要给你可执行方案。

## 一、你需要向供应商索要的合规文件

对香蕉这种水果，超市/市场监管抽检通常会关注农药残留（如吡虫啉、噻虫嗪、多菌灵、咪鲜胺等）和重金属。你要让佳农或其经销商提供：

1. **本批次的出厂检验报告 / 第三方检测报告**
   - 必须带 CMA（或 CNAS）资质章
   - 报告要有样品名称、批号、检测项目、检测方法、结果、报告日期
   - 报告日期要能对上你采购的这批货
2. **产地证明 / 供货凭证**
3. **营业执照、食品经营许可证**（供应商资质）
4. **承诺书 / 质量保证协议**（约定农残超标时的退换货和责任）

## 二、判断报告能不能用（关键）

- **报告不是通用的**：一批一份。拿去年的、别批的报告顶不了你这批货。
- **项目要对口**：香蕉常见关注的农残项目要在报告里，不能只有一两个不相关的；最好是全项或按 GB 2763 相关限量检。
- **检测方法要对**：一般是 GB 23200 系列或 GB/T 20769 等农残检测方法，不是快速检测卡糊弄。
- **第三方 vs 自检**：自检报告抽检时说服力弱，建议至少第三方 CMA 报告，或进货后你自己送检批批取样。

## 三、最稳的做法：自己送检一批

如果这批货量大、要进正规超市，最稳妥是**进货前/进货时自己委托 CMA 第三方按批抽检农残**。这样：
- 超市抽检时你有对得上批次的报告；
- 万一出问题，责任链条清晰，能向供应商追责。

## 四、怎么查佳农的抽检历史（你自己能核验的途径）

我不替你下结论，但这些是权威可查的渠道：
- **国家市场监督管理总局**及各省市市场监管局官网的"食品抽检通告/不合格食品"公告；
- **企业所在地市场监管局**官网；
- 用"佳农 + 香蕉 + 抽检"在官方渠道检索。

注意：搜到有通报也不能直接推断"佳农整体有问题"，可能是个别批次或经销商环节；搜不到也不代表你这批就合格。

## 五、给你的采购动作清单

1. 向佳农/经销商**书面索要本批次 CMA 检测报告 + 资质文件**；
2. 核对报告批号、日期、项目是否匹配你这批货；
3. 量大的话**自己送检一批**；
4. 合同里写明**农残超标退换货及赔偿条款**；
5. 把报告留档，超市抽检时随货提供。
