我无法直接核验佳农水果当前的官方配送范围（这类信息会随渠道、季节、合作方调整），所以不能给你一个准确的城市清单。可以按下面方式判断你们县城能不能送到：

**1. 先分清你买的是哪种“佳农”**
- 如果你是在**京东/天猫/拼多多/抖音等平台**买佳农水果：配送范围通常由平台店铺和快递决定，不是佳农统一规定。
- 如果你是在**美团/饿了么/京东到家**买：一般只覆盖有合作门店或前置仓的城市/区县，县城能不能送取决于当地有没有上架门店。
- 如果是**佳农官方小程序/旗舰店**：以结算页显示的地址为准。

**2. 最准确的判断方法**
把水果加入购物车，填写你们县城的详细地址，到结算页看：
- 能不能选到你们县/镇/街道；
- 有没有显示“不支持配送”；
- 运费和预计送达时间是否出现。
**能进入结算并生成订单，基本就是能送。**

**3. 县城通常是什么情况**
- 普通快递能到的县城：京东/天猫等电商渠道通常能送，但可能是从外地仓发货，时效较慢。
- 即时零售/次日达：往往只覆盖地级市城区和部分经济较好的县，普通县城不一定有。
- 偏远乡镇/村：可能只能送到县城驿站或镇级网点，需要自提。

**4. 如果结算页显示不能送**
可以试：
- 换平台店铺（不同店铺发货仓和快递不同）；
- 问客服“发什么快递、到不到XX县XX镇”；
- 看详情页有没有“不发货地区”说明；
- 找当地水果店/社区团购，他们有时能拿到佳农货源。
