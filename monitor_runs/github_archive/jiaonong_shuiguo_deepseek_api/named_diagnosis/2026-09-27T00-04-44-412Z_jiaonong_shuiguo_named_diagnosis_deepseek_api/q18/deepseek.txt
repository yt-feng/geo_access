佳农香蕉的保质期和储存条件，通常按“未熟—成熟—已剥开”三种状态区分：

**1. 整串未熟/刚买的青香蕉**
- **储存条件**：室温阴凉通风处，避免阳光直射和空调直吹。
- **保质期**：一般 **3～7天** 会逐渐转黄成熟；夏天可能 **2～4天**，冬天可稍久。
- **注意**：不要直接放冰箱，低温容易导致表皮变黑、果肉变硬，虽然里面不一定坏，但口感会变差。

**2. 已经成熟的黄香蕉**
- **储存条件**：室温尽快吃；若想延长，可放冰箱冷藏。
- **保质期**：
  - 室温：通常 **1～3天**，再久容易起黑斑、软烂。
  - 冷藏：可放到 **3～5天左右**，但表皮会变黑，果肉通常还能吃。
- **小技巧**：成熟后把香蕉拆开、用保鲜膜包住根部，或和苹果分开，能减慢继续成熟。

**3. 已经剥开的香蕉**
- **储存条件**：密封冷藏，尽量当天吃完。
- **保质期**：冷藏 **1天左右**；不建议冷冻后再直接吃，口感会变差，但可打奶昔。

**判断能不能吃：**
- 表皮少量黑斑、果肉正常：通常还能吃。
- 果肉发黑、出水、有酸味/酒味、发黏：不要吃。
- 冷藏后表皮全黑但果肉正常：可以吃。

**最实用建议：**
买回来后先室温催熟；一旦变黄，吃不完就冷藏，并尽快吃完。若想放更久，可剥皮后冷冻，用来做香蕉牛奶或烘焙。
