我无法确认佳农目前是否供应冷冻菠萝丁，也不能确认其具体规格——这类信息会随产品线和渠道变化，我如果直接给数字就是编造。

不过可以给你可执行的判断和操作建议：

**1. 佳农大概率有相关产品，但需要确认三个关键点**
- 是“冷冻菠萝丁”还是“菠萝果肉/菠萝块/菠萝碎”
- 是否属于**速冻（IQF）**，还是糖水/罐头类
- 是面向B端餐饮批发，还是仅零售小包装

茶饮店要的是**速冻IQF菠萝丁**（开袋即用、颗粒分明、不结大块），和超市冷冻水果不是一个品类。

**2. 规格通常是这几个维度，问的时候要问全**
- 单丁尺寸：常见在 **8×8mm、10×10mm、12×12mm** 左右（不同厂家命名可能不同）
- 包装：常见 **1kg/袋、2kg/袋，或10kg/箱**
- 糖度/是否加糖：是否糖渍、含糖量多少
- 固形物/含水：解冻后出水情况
- 保质期与储存：-18℃冷冻、保质期一般12–24个月

**3. 最靠谱的核验方式**
- 佳农官网/官方公众号查“餐饮渠道/冷冻水果”产品线
- 直接联系佳农**餐饮或批发渠道客服**，要产品规格书（PDF）
- 找当地冷冻水果批发商问“有没有佳农菠萝丁”，同时对比其他品牌报价
- 拿样测试：重点看**解冻出水、丁型完整度、酸甜度、是否有纤维渣**

**4. 如果佳农规格不合适**
茶饮店常用替代方向：其他冷冻水果品牌的IQF菠萝丁、糖水菠萝丁（需控糖调整配方）、或直接采购鲜菠萝自行切丁冷冻（成本低但人工和稳定性差）。
