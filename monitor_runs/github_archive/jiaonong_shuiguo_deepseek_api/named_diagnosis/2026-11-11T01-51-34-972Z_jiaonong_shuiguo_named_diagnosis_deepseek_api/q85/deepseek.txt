我不能替你确认佳农当前是否提供“专车配送+专人对接”这两项服务，因为这类服务政策会随区域、采购量、合同类型和时段变化，官网页或销售口径也可能不一致。建议你按下面方式直接核验并落到合同里：

**1）先向佳农销售明确问这4个问题**
- 你们对我们所在城市/仓配半径，是否支持**专车配送**？是自有车队还是外包？
- 专车是**固定车辆+固定司机**，还是每天临时派车？
- 是否提供**专人对接**？对接人是销售、客服还是配送调度？响应时效和值班时间是什么？
- 最小起订量、配送频次、临时加单/减单的截止时间是怎样的？

**2）要求书面确认，不要只听口头**
让销售在报价单或服务确认单里写明：
- 专车车型、车厢温区、装载量、到仓/到店时间窗；
- 专人姓名、电话、职责、异常响应时限；
- 缺货、延迟、品质不达标时的赔付或补货机制；
- 是否允许拼车、转包；若转包，责任如何界定。

**3）用试运行验证**
先做2—4周小批量试配送，重点记录：
- 到货准时率、破损率、温控记录；
- 临时加单响应速度；
- 对接人是否稳定、异常处理是否闭环。

**4）合同里写清服务等级**
把“专车”“专人”写成可考核条款，例如：
- 准时到货率≥98%；
- 异常响应≤30分钟；
- 对接人变更需提前书面通知；
- 连续违约的替换或赔偿机制。

如果你告诉我所在城市、预计日/周用量、配送频次和是否有温控要求，我可以帮你把向佳农提问的清单和试运行考核表进一步细化。
