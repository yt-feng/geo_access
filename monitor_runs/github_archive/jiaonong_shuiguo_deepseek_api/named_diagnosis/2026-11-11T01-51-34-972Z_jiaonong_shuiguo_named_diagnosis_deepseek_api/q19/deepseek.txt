佳农水果的配送时效取决于**下单渠道、收货地址和配送方式**，没有统一承诺，需要分情况看：

1. **电商平台（天猫/京东/抖音等佳农旗舰店或自营）**
   - 一般走平台仓配或商家发货，页面会标注“预计送达时间”。
   - 常见情况：现货商品下单后 **24–48小时内发货**，快递运输 **1–3天** 到多数城市；偏远地区可能更久。
   - 生鲜水果通常使用顺丰/京东/中通等，具体以商品详情页和订单物流为准。

2. **京东自营/天猫超市等“次日达”渠道**
   - 若商品属于本地仓现货且地址在覆盖范围，可能 **次日达或隔日达**；生鲜类有时支持当日达/次日达，但要看具体SKU和收货地。

3. **社区团购/本地生活平台**
   - 通常 **次日自提** 或按团长通知时间到货，时效由平台和团长安排决定。

4. **线下商超/水果店配送**
   - 若通过美团、饿了么等本地即时零售下单，通常 **30分钟–2小时** 送达（取决于门店距离和运力）。

**判断建议：**
- 下单前直接看商品页的“配送/预计送达”说明，这是最准确的。
- 生鲜水果对时效敏感，建议优先选**本地仓发货、冷链/生鲜专送**的渠道。
- 若着急，选京东自营、天猫超市本地仓或即时零售平台；若不着急，普通快递渠道通常1–3天。
