**1. 香蕉常见规格维度**
- 按单根重量：如小果、中果、大果、特大果（具体克重区间需以佳农当季标准为准）。
- 按梳/把规格：每把几根、每梳重量区间。
- 按箱规：每箱净重（如 4kg、8kg、10kg、12kg 等）、每箱把数/根数。
- 按成熟度：青蕉、微黄、黄熟、即食熟度。
- 按外观等级：果指长度、粗细、弯曲度、色泽、条斑、机械伤、黑点、青硬比例等。

**2. 不同渠道的分级建议逻辑**
- **商超/精品店**：优先果指均匀、长度和粗细一致、色泽好、无机械伤和明显黑点；箱规稳定，成熟度可控，适合小规格精品包装。
- **水果连锁/社区店**：重视性价比和周转，规格可略宽，允许轻微外观瑕疵但不影响食用；成熟度偏青黄，便于货架期。
- **电商/即时零售**：强调抗压和耐运输，果指不宜过熟，单根或小把包装需统一克重；减少黑点和压伤投诉。
- **批发市场/大宗流通**：以箱规、净重、成熟度、出成率和耐储运为主，外观分级可放宽，但需明确青硬比例和损耗责任。
- **餐饮/加工渠道**：更关注出肉率、成熟度一致性和单价，对果指外观要求相对低。
