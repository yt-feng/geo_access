我不能直接给你一个"每箱便宜几块"的确定数字，因为这类批发差价随时在变，而且取决于你拿的规格、区域、渠道和返利政策。给你可执行的判断方法：

**先说结论性判断**
- 佳农和都乐在国内香蕉批发上，**同规格同等级时佳农通常略便宜，但优势不稳定**，往往在0.5～3元/箱这个量级，遇到都乐促销或佳农紧俏时可能倒挂。所以"有没有优势"要按批次核，不能按品牌拍。
- 走量批发商的真实差价，**主要不在标价，而在返利、运费、损耗赔付和账期**。标价差的几块钱，常被后三项吃掉或放大。

**怎么自己核出准确差价（半天能做完）**
1. 锁定可比规格：同一箱重（如13kg/箱）、同一等级（如一级/二级）、同一成熟度、同一包装，别拿不同规格比。
2. 同时问两家区域经销商的**到岸价**（含运费），而不是出厂价。
3. 问清返利：月/季返点、达成量门槛、现款折扣、损耗包赔比例、退换货政策。
4. 折算成"每箱综合成本"再比：标价 − 返利 − 损耗赔付 + 运费 + 账期资金成本。
5. 各拿3～5批不同到货日的数据做均值，单批容易被行情误导。

**谈价时可用的杠杆**
- 用另一家的到岸价+返利打包报价去压价，比单问"能便宜几块"有效。
- 走量时优先谈**阶梯返利和损耗包赔**，这两项对批发商的实际收益通常大于标价那1～2块。
- 问清是否分区域保护价、是否限制窜货，避免低价拿货但被断供。
