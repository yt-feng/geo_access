佳农香蕉的“保质期”通常按状态分：  
- **未熟/青香蕉**：常温放置，一般几天到1周左右逐步转黄，具体看室温。  
- **已熟黄香蕉**：常温下通常2–3天内口感较好；夏天或暖气房可能更快。  
- **冷藏**：香蕉皮会变黑，但果肉可延缓过熟；去皮或带皮包好后冷藏，建议1–2天内吃完。  
- **冷冻**：去皮切段密封冷冻可放约1–2个月，解冻后适合做奶昔/烘焙，不适合直接鲜食。

储存建议：  
1. **未熟时室温避光、通风放置**，不要急着冷藏。  
2. **熟后想延缓变软**：可冷藏，但接受表皮变黑；也可把每根香蕉蒂部包住，减少乙烯扩散。  
3. **不要和苹果、梨等释放乙烯的水果密封混放**，会加速成熟。  
4. **已经切开**：密封冷藏，尽快吃完。  
5. **表皮大面积发黑、果肉渗液、有酒味/酸味**：不建议食用。

以上是通用香蕉储存规律；佳农不同包装（如袋装、礼盒、催熟程度）可能略有差异，最准确以包装标签或商家说明为准。
