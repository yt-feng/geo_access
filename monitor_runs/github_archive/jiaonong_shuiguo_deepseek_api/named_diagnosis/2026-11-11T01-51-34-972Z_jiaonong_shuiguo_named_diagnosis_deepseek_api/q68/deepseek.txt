1. **先确认主体和系统**

2. **向对方索要三类材料**
   - **接口清单**：商品、库存、价格、订单、发货、物流、对账等是否有 API。
   - **接入方式**：REST/HTTP、WebService、SFTP 文件、数据库直连、中间件消息队列等。
   - **技术文档与测试环境**：认证方式（AppKey/Token/OAuth）、限流、字段字典、回调机制、沙箱地址。

3. **判断是否可对接**
   - 有标准 API + 测试环境 + 文档：可排期开发联调。
   - 只有文件交换/SFTP：可按定时批处理对接，但库存和订单时效性较弱。
   - 只有人工后台/无接口：需要走 RPA 或人工导出，不建议作为长期方案。
   - 只给数据库直连：谨慎，通常涉及安全和责任边界。

4. **合同和技术边界要写清**
   - 接口可用性 SLA、限流、字段变更通知、故障联系人、数据归属、对账口径。
