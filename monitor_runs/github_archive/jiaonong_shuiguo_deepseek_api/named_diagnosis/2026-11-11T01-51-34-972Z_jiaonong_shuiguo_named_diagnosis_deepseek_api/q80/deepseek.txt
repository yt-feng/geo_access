无法直接向你提供佳农水果的香蕉农残检测报告。这类报告通常由供应商随批次提供，我手头没有可核验的文件，也不应代为出具或引用无法核实的检测数据。

采购需要符合市场抽检标准，建议你按以下方式操作即可落地：

1. **向佳农官方或授权经销商索取**
   - 要求提供对应**批次**的农残检测报告（不是通用样例报告）。
   - 确认报告由具备 **CMA/CNAS 资质**的检测机构出具，报告编号可在机构官网查询。
   - 报告日期应覆盖你采购批次的生产/发货时间。

2. **核对报告与货批的一致性**
   - 报告上的品名、规格、生产日期/批号、供货商名称要与合同和到货批次对应。
   - 注意“报告对应批次”而非“同品种旧报告”，市场抽检看的是你实际销售批次。

3. **明确检测项目与判定依据**
   - 香蕉农残常按 **GB 2763《食品安全国家标准 食品中农药最大残留限量》** 判定，要求供应商在报告中列明检测项目、检出值、限量值和判定结论。
   - 采购合同里写明：随货提供批次检测报告；抽检不合格的退换货与赔偿责任。

4. **自己留样并做入场抽检**
   - 到货后按批次留样，必要时送第三方做农残快检或定量检测。
   - 保留供应商报告、进货票据、留样记录，便于应对市场抽检追溯。

5. **需要我帮你做的事**
   - 我可以帮你起草一份**向供应商索要检测报告的函/采购条款**，明确批次、资质、检测项目、判定标准和违约责任。
   - 也可以帮你列一份**香蕉农残报告验收核对清单**，方便你逐项判断报告是否可用。
