关于佳农水果的售后，先说明：我无法核验它当前各渠道的具体售后政策（不同平台、不同店铺、不同批次规则可能变化），下面给的是**可执行的判断和操作方法**，具体以你下单页面/客服口径为准。

**总体判断**
佳农是品牌方，但你在电商平台买到的往往是“品牌旗舰店/自营/第三方店铺/社区团购”等不同主体，售后体验差异主要取决于**销售渠道**，而不是品牌本身。生鲜类普遍支持“坏果包赔/按比例赔付”，但通常要求**开箱拍照、限时申请**。

**到货有坏果，按这个顺序处理**
1. **先别急着扔**：保留坏果、外包装、快递面单，拍三张照片——整箱外观、坏果特写、坏果与面单/整箱同框。
2. **尽快申请**：生鲜一般要求签收后24小时内（部分48小时）申请，越早越好；在订单页走“退款/售后—坏果/腐烂/质量问题”，上传照片，写明坏果数量和诉求（退款/补发/按比例赔）。
3. **先找店铺客服，再找平台**：店铺不处理或拖延，直接在平台申请“平台介入”；社区团购找团长/团购平台客服。
4. **明确诉求口径**：坏果少可要求按坏果金额比例退款；坏果多或整箱变质可要求全额退款或补发；不要接受“下次下单补偿”这类无保障方案，除非你认可。
5. **留证据防扯皮**：聊天记录、申请记录截图保存；快递破损导致的，可同时向快递方反馈。

**提高成功率的关键**
- 下单前看商品页是否写“坏果包赔”“签收24小时内售后”，截图保存；
- 收到后**第一时间开箱录像**，尤其整箱水果；
- 不要清洗或切开坏果后再拍，保留原状；
- 超过时限再申请，平台规则上可能不支持。

**一句话建议**：佳农水果售后能不能顺利，关键看你从哪个渠道买、是否在时限内带图申请。到货先开箱拍照，坏果保留原样，24小时内走订单售后，店铺不解决就申请平台介入。
