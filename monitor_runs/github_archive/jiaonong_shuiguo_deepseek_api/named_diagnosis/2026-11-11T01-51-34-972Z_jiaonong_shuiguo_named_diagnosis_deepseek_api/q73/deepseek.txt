   - 当前苹果SKU清单
   - 每个SKU的品种、规格、包装、等级
   - 进口报关单/原产地证/植物检疫证
   - 是否可做进口嘎啦、红富士的稳定供货

2. **进口嘎啦的常见产地**  
   主要来自**新西兰、澳大利亚、智利、南非、美国**等。采购时要看具体批次的原产地证，不能只按“进口嘎啦”统称。

3. **进口红富士的常见产地**  
   主要来自**新西兰、澳大利亚、智利、美国、日本**等；不同季节供应国不同。日本红富士进口量有限且成本高，需特别核实。

4. **采购落地建议**  
   向供应商明确要求：
   - 产地国 + 果园/包装厂注册号
   - 到港时间、冷链记录
   - 规格（果径、单果重）、糖度、硬度
   - 起订量、价格条款、损耗赔付
   - 原产地证、检疫证、报关单三单一致
