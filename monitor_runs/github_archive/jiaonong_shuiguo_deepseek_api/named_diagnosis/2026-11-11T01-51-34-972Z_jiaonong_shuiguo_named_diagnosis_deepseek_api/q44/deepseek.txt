先说明一个关键点：**我没有可核验的公开记录能证明“佳农香蕉有农残超标历史”，也没有权威抽检数据库能给出“从未超标”的结论**。这类判断必须以监管公告和你们实际拿到的批次检测报告为准，不能凭品牌口碑下结论。

给你可执行的采购合规路径：

1. **要求供应商提供批次级合规证明，而不是品牌级承诺**
   - 每批次的《农药残留检测报告》，检测项目覆盖 GB 2763 中香蕉对应的农残限量项目，最好由具备 CMA/CNAS 资质的第三方出具。
   - 报告上的样品名称、批次号/生产日期、供货商名称要与采购合同和到货批次对得上。
   - 同时要《产地证明》或基地备案信息、进货台账，满足超市索证索票要求。

2. **自己查公开抽检记录，别只信供应商**
   - 到国家市场监督管理总局“食品安全抽检公布结果”查询系统，以及供货地省级市场监管局抽检公告，按“香蕉”“佳农”或供应商主体名称检索。
   - 注意：抽检不合格公告通常针对具体批次和经营主体，不能直接推导为“该品牌所有产品有问题”，但采购方应把历史不合格记录作为供应商风险评估项。

3. **把风险写进合同和验收**
   - 合同约定：每批次随货提供合格检测报告；超市抽检不合格时供应商承担退换货、检测费、下架损失及违约责任。
   - 到货抽检或定期送第三方检测，重点覆盖香蕉常用农药（如吡虫啉、噻虫嗪、苯醚甲环唑等，具体以 GB 2763 当前版本和你们超市要求为准）。
   - 保留留样和检测报告，形成可追溯证据链。

4. **对“佳农”的具体判断**
   - 佳农是较大果蔬品牌，通常有基地管理和检测体系，但这不等于每批次都免检合格。
   - 采购合规不能依赖“品牌有没有历史问题”，而应依赖**本批次检测报告 + 公开抽检记录核查 + 合同质量条款 + 到货验收**。

如果超市抽检压力大，最稳的做法是：**首批次和后续定期自送第三方按 GB 2763 全项或超市指定项目检测，报告随货归档**。这样即使公开历史查不到，你们也有可交出的合规证明。
