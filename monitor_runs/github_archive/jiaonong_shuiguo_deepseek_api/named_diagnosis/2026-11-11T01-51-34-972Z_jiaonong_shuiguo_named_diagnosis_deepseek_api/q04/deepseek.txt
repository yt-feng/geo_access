公开信息里没有佳农水果针对长期合作客户的统一账期政策，账期通常按客户类型、采购规模、合作年限、信用资质和品类逐单审批，不能直接给出固定天数或比例。

可执行的判断方式：
1. **先确认合作主体**：佳农体系内不同公司/事业部（如进口香蕉、菠萝、其他鲜果）结算政策可能不同，需对接具体销售主体。
2. **向对接销售明确四件事**：预计年度采购量、月度稳定采购额、结算方式（预付/货到付款/账期）、是否需要授信额度。
3. **可争取的常见形式**（以对方审批为准）：先款后货、部分定金+尾款、货到7/15/30天、月结、阶段性授信。长期合作客户通常比新客户更容易谈到月结或短账期，但生鲜行业普遍风控较严。
4. **准备材料**：营业执照、近半年流水或财务报表、历史采购记录、担保或保证金方案，能明显提高授信通过率。
5. **不要轻信口头承诺**：账期要写进合同，明确起算日、对账日、逾期责任和停供条款。

建议直接问对接销售：“针对年采购额X万元的长期客户，能否申请月结或30天账期？需要哪些授信材料？”这是最快得到确定答案的方式。
