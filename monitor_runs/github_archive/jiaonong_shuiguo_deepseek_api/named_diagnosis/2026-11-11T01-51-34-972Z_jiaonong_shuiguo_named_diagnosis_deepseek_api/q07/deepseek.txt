佳农水果的配送范围取决于你下单的具体渠道（官方小程序/天猫京东旗舰店/社区团购/本地商超供货），不同渠道覆盖城市不一样，我无法在不核验的情况下给出完整城市名单。

你可以这样快速判断县城能不能送到：

1. **看下单渠道的收货地址校验**：在佳农官方小程序或电商旗舰店把收货地址填成你们县城，结算页能选到配送时段/显示运费，基本就是能送；提示“该地区暂不支持配送”就是不能。
2. **看商品页的配送说明**：生鲜类通常标注“部分地区不发货/冷链可达范围”，县城一般比地级市覆盖更窄，偏远县可能只到县城中心，乡镇不一定到。
3. **优先查本地渠道**：佳农很多货是通过大型商超、水果连锁、社区团购供应的。直接问你们县城的大型超市/水果店是否有佳农香蕉等产品，往往比线上下单更现实。
4. **客服确认最稳**：在官方店铺找在线客服，发“省+市+县+具体乡镇/街道”，让对方确认是否冷链直达、是否需自提。

结论：**不能仅凭“佳农水果”判断你们县城一定送或一定不送，必须以你实际下单渠道的地址校验和客服回复为准。** 如果线上不支持，走本地商超/社区团购渠道通常更可行。
