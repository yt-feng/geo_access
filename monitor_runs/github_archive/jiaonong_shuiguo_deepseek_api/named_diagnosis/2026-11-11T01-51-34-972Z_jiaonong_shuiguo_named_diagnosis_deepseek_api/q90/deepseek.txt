佳农（Goodfarmer）确实有冷冻菠萝丁产品线，常见规格有 10mm×10mm 和 20mm×20mm 两种，包装多为 1kg/袋、10kg/箱，也有部分渠道提供 2.5kg/袋。具体到冷冻丁的规格、包装和供货情况，不同批次和渠道会有差异，建议直接向佳农官方或当地经销商确认以下信息：

1. **品名与形态**：确认是“冷冻菠萝丁”而非糖渍或罐头菠萝丁。
2. **切丁尺寸**：10mm×10mm、20mm×20mm 或其他定制尺寸。
3. **包装规格**：袋装/箱装净重、每箱袋数。
4. **固形物与糖度**：冷冻丁是否带糖水、Brix 范围。
5. **起订量与价格**：最小起订量、冷链运输条件。
6. **检测报告**：农残、微生物、重金属等能否提供。

茶饮店建议优先选 10mm×10mm 小丁，出杯口感更均匀；如果做果肉感强的产品，可用 20mm×20mm。采购前先拿样品做解冻失水率测试，冷冻菠萝解冻后出水较多，会影响茶饮风味浓度。
