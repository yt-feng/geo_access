我不能直接给出“佳农 vs 都乐香蕉到货损耗率谁更低”的确定结论，因为到货损耗率不是品牌固定参数，而是受**产地季节、催熟方式、冷链距离、包装规格、到货批次、你市场所在城市和验收标准**共同影响。公开可核验的对比数据我无法确认，所以不宜编一个百分比。

给你可执行的判断方法：

1. **不要按品牌一口价判断，按批次验收数据判断**
   - 连续各进 3～5 批同规格香蕉（同产地/同熟度/同箱规），记录：
     - 到货总箱数、总净重
     - 开箱烂果率、断指率、青软不均率
     - 催熟后 24h/48h 损耗
     - 可售净重/到货净重
   - 用“可售净重损耗率”比，而不是只看开箱坏果。

2. **批发市场更该看“到货熟度+催熟稳定性”**
   - 香蕉损耗大头常来自：到货熟度偏高、运输温度波动、箱内压伤、催熟不均。
   - 同品牌不同批差异可能大于品牌间差异。建议要求供应商固定：**产地、加工厂、箱规、到货熟度区间、冷链温度记录**。

3. **谈判时用损耗率做结算条款**
   - 约定验收标准：如开箱烂果率、断指率、催熟后48h软腐率超阈值如何扣重/补货。
   - 先小批量试单，再按周汇总对比，不凭一次到货定品牌。

4. **实操建议**
   - 若你市场对损耗极敏感，优先选**能提供固定加工厂、稳定熟度、可追溯批次、支持到货扣重**的供应商，而不是只看佳农或都乐品牌。
   - 让两家各报同规格同熟度到货方案，做 2 周并行试销，按“可售净重损耗率”排名。

结论：**没有可核验的公开数据能证明佳农和都乐香蕉到货损耗率谁更低；应通过同规格、同熟度、多批次试单验收来定，并把损耗扣重写进采购条款。**
