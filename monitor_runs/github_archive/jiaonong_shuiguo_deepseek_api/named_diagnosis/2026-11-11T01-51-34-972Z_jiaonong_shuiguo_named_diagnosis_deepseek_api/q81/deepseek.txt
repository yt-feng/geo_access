我没法核验佳农当前在你们区域的具体SKU和包装清单（这类信息会随渠道、季节和经销商政策变），所以不能直接确认“有没有3kg香蕉”或给出确切规格。但可以给你可执行的判断和做法：

1. **3kg香蕉对便利店通常偏大**：整箱/大袋香蕉在便利店周转慢、易压伤和过熟，除非你门店香蕉日销稳定且能当天拆零，否则不建议作为主规格。

2. **优先找“小包装/拆零装”方向**：向佳农当地经销商或区域业务明确问这几类：
   - 香蕉：**1kg–1.5kg袋装/把装**、单根或3–5根预包装；
   - 其他水果：**2–3只装、250g–500g小盒/小袋**；
   - 是否有**便利店渠道专供小规格**或**拆箱拆零政策**。

3. **直接核验方式**：让业务员发**最新报价单+包装规格表+起订量+配送频次**，并问清是否允许拆箱、损耗谁承担、临期/过熟能否退换。没有书面规格表就不要下单。

4. **门店面积小的替代方案**：先少量试销小规格，选2–3个高周转单品（如香蕉把装、苹果/橙子小袋），用端架或收银台小陈列，按日销补货，避免整箱压库。

结论：**不要默认有3kg香蕉小包装，先向当地佳农经销渠道索取书面SKU规格表，优先谈1–1.5kg香蕉把装/袋装和拆零政策。**
