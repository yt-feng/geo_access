佳农（佳农食品控股/佳农水果）针对经销或商超客户通常有阶段性锁价/价格保护安排，但**是否锁3个月、能否锁价，要看客户类型、品类、合同和当时行情**，不能一概而论。给你可判断的建议：

1. **大概率没有“标准3个月锁价”**
   - 香蕉是鲜果，产地价、运费、损耗、汇率/进口成本波动大，供应商一般不愿无条件锁3个月。
   - 常见做法是：**短期锁价（如7天、15天、30天）**、**月度框架价+调价机制**、**保底价/最高限价**、**价差补偿（价格保护）**，而不是固定3个月。

2. **看你是哪类客户**
   - 商超/连锁/大客户：更可能谈**季度框架协议+调价窗口**，但会附带销量承诺、结算账期、损耗分担、行情触发条款。
   - 批发/中小客户：一般是**随行就市、当日/周报价**，锁价空间小。
   - 电商/社区团购：可能有短期活动价保护，但通常不覆盖3个月。

3. **合同里要重点确认的条款**
   - 锁价期限、适用规格/等级、数量上限；
   - 触发调价的行情条件（如产地价涨跌超X%）；
   - 价差补偿方式（返利、下批抵扣、现金补偿）；
   - 运费、损耗、退换货谁承担；
   - 违约和销量未达标的处理。

4. **直接核实方式**
   - 找佳农当地销售/大客户经理要**书面报价单和框架合同模板**，明确问“香蕉能否锁价3个月、锁价附加条件是什么”。
   - 要求把价格保护写成**合同附件**，不要只接受口头承诺。
   - 若对方说可以锁3个月，务必确认是否**限量、限规格、可调价**，避免“名义锁价、实际调价”。

结论：**佳农可能有价格保护/短期锁价机制，但“锁价3个月”不是行业常规，需个案谈，且大概率附带销量、调价触发和限量条件。** 建议你以书面合同为准，先谈1个月锁价+调价窗口，再争取更长周期。
