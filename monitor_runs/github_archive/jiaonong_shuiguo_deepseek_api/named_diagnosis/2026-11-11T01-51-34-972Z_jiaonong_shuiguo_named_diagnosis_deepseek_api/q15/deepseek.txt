关于佳农水果的“产地直供比例”，公开渠道没有统一、可核验的官方口径，我不能给出一个准确百分比。可以判断的是：佳农属于以全球采购/产地资源整合为主的水果供应链企业，香蕉、菠萝等核心单品通常采用“产地采购+催熟加工+渠道分销”的模式，但“直供比例”会随品类、年份和统计口径变化，需以企业年报、招股书或官方披露为准。

香蕉方面，佳农的香蕉来源通常以香蕉主产国为主，常见包括：
- 厄瓜多尔
- 菲律宾
- 哥伦比亚
- 哥斯达黎加
- 危地马拉
- 洪都拉斯
- 墨西哥
- 越南、柬埔寨等东南亚国家也可能作为补充来源

具体到某一年度、某个港口或某个渠道的香蕉来源国，会受季节、价格、关税、航运和供应稳定性影响，佳农通常会多国采购、动态调配，不宜简单理解为固定来自某几个国家。若要精确到“某批次/某年度主要来自哪些国家”，需要查佳农官方披露或进口报关/供应链资料。
