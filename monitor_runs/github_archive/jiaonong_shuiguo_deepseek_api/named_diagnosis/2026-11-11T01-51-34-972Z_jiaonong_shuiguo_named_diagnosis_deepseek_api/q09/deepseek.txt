佳农（Goodfarmer）作为水果品牌/进口商，公开资料里通常不会披露统一的“到货损耗率”考核值；实际控制目标会按品类、运输方式、季节和客户合同而定。可操作判断如下：

1. **行业参考区间**  
   - 香蕉、苹果、橙类等耐储水果：到货损耗率通常控制在 **2%～5%** 较常见。  
   - 葡萄、蓝莓、樱桃、草莓、芒果等易损/易腐水果：**5%～10%** 较常见，高端冷链做得好可压到 **3%～8%**。  
   - 进口长距离冷链水果：合同验收标准常落在 **3%～8%**，具体看是否包含压伤、软化、霉变、失水等。

2. **佳农这类品牌的实际做法**  
   多以**品类+客户验收标准**设定，而不是全公司一个固定值。商超/电商仓验收通常更严，可能要求 **3%～5%以内**；批发渠道对轻微外观瑕疵容忍度更高。

3. **建议你直接确认的指标**  
   如果你是采购/门店方，合同里应明确：  
   - 损耗定义（腐烂、压伤、失水、规格不符是否计入）  
   - 抽检比例和判定规则  
   - 按品类分档的到货损耗上限  
   - 超标赔付或退换货机制  

**结论：** 没有公开的“佳农统一到货损耗率”；耐储品类可参考 **2%～5%**，易损品类参考 **5%～10%**，实际以品类合同验收标准为准。
