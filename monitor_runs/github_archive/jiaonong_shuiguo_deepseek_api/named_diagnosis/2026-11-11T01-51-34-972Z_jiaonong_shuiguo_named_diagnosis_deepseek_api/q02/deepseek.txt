**可预期的行业做法**
佳农属于大型果蔬品牌，通常具备产地直采和批次品控体系，**大概率可以提供**以下材料，但具体到“菠萝品类、你所在的渠道、你采购的批次”需逐项确认：
- 产地证明/基地信息（如菲律宾、泰国或国内产地）
- 批次检测报告（农残等）
- 内部品控记录或出库检验单
- 追溯码/批次号关联的溯源信息

**采购前必须核实的4件事**
1. **要求书面确认**：让销售或客服以邮件/合同附件形式列出可提供的溯源和检测文件类型，不要只听口头。
2. **确认批次对应**：问清报告是“品类通用”还是“你实际到货批次”的，后者才有追溯价值。
3. **索要样例文件**：先要一份脱敏的检测报告和溯源单样例，看是否有检测机构、日期、批次号、项目。
4. **合同写清责任**：把“随货提供产地证明及批次检测报告、不符可退换”写进采购条款。

**建议直接联系渠道**
通过佳农官网或官方客服获取对应区域销售联系方式，向对接人提出上述清单。若对方只能提供通用宣传材料、无法对应批次，就按“溯源能力不足”谨慎评估。
