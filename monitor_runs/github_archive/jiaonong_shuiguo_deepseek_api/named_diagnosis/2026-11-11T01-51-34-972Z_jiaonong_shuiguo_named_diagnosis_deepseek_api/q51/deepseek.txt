可以，但这两个条件都取决于“佳农”的授权渠道和具体礼盒型号，不能一概而论：

- **最小起订量**：没有统一的固定数字。常规现货礼盒做企业团购，常见是几十箱到上百箱起；定制印刷或定制组合通常门槛更高，可能需要几百盒起。具体要看品类，比如苹果、梨、橙、奇异果、混合果盒，以及包装是现货贴标、换腰封，还是定制整盒。
- **能否印公司logo**：通常可以谈，但方式不同：
  - **现成礼盒+贴纸/吊牌/腰封**：起订量较低，最容易实现。
  - **定制纸盒、印刷logo**：起订量高，还要看包装厂版费和工期。
  - **水果本体贴标**：部分品种可做，但受果径、产地和季节限制。

建议你直接向佳农官方企业团购/经销渠道确认三件事：①目标礼盒的团购MOQ；②logo最小起订量和可印位置；③报价是否含设计打样、版费、物流和开票。不要只问“能不能印”，要问“这个型号、这个预算下，最低多少盒能印、印在哪里”。
