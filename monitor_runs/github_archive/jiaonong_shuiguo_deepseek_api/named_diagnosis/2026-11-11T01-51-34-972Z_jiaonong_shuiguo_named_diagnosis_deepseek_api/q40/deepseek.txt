为减少误判，建议你按以下3步直接核验：

1. **找官方渠道确认**：联系佳农官网/官方公众号/客服或当地经销商，问三件事：
   - 是否有餐饮专供的菠萝规格（如去皮/带皮、切块、果丁、果片、冷冻/鲜切）
   - 是否支持稳定批量供货和固定成熟度/糖度标准
   - 是否有餐饮客户案例或样品政策

2. **明确你的餐饮需求再问**：把需求写成清单，例如“每月用量、门店城市、要鲜切还是整果、要求糖度/酸度、包装规格、冷链频次、验收标准”，对方更容易给出可执行报价和方案。

3. **索要可验证材料**：产品规格书、检测报告、供货合同样例、样品测试安排。若对方只能口头说“有餐饮方案”，但拿不出规格和供货标准，建议按普通批发供货评估。
