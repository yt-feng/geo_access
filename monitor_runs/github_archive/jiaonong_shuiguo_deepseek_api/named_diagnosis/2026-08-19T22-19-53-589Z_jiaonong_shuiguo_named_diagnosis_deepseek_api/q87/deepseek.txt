针对佳农（Goodfarmer）水果的香蕉催熟工艺，**目前其商业化产品（尤其是商超渠道）基本采用“乙烯催熟”工艺，而非自然熟。** 这一点是行业标准做法，原因如下：

**1. 为什么必须用乙烯催熟？**

- **自然熟不可控**：香蕉是典型的呼吸跃变型水果，采摘时是青硬状态。如果完全依靠自然放置（自然熟），成熟时间极不稳定（可能5-15天不等），且容易因温度波动导致成熟不均、糖心不足。
- **运输与货架期冲突**：自然熟会导致在运输途中大量过熟腐烂。因此行业内统一采用“青蕉采后运输 → 到目的地催熟房用乙烯气体熏蒸”的标准流程。

**2. 佳农的催熟工艺核心参数（供商超参考）**

- **催熟剂**：使用的是**乙烯气体**（通过乙烯利溶液加热释放，或直接使用高纯度乙烯气瓶），浓度通常控制在 **10-100 ppm** 之间。
- **温度控制**：催熟房温度严格控制在 **18℃-20℃**（绝不能高于24℃或低于14℃，否则易产生黑皮或僵化）。
- **湿度**：保持在 **90%-95%** 相对湿度。
- **时间周期**：**从青蕉进入催熟房到完全可售卖（约7-8成熟），通常需要 48-72 小时（2-3天）**。如果商超需要加速（例如促销），可升高温度至20℃并提高乙烯浓度，但最快也要 **36小时**，且会牺牲部分甜度和货架期。

**3. 您商超控制时间的实操建议**

- **到货后确认催熟度**：佳农到货时一般会在箱体标注“催熟度”或“出货日期”。若标注为“已催熟”（即商家已完成乙烯熏蒸），那么到货后只需在 **16-18℃** 环境中放置 **1-2天** 即可自然转黄，**切勿再次使用乙烯**，否则会迅速过熟。
- **若为青蕉（未催熟）**：建议您自建催熟库，按上述参数操作。控制时间的核心是**设定好温度与乙烯浓度**，可在催熟房内放置温湿度记录仪，每2小时记录一次。
- **分批催熟**：为了商超连续供货且避免积压，建议将到货分3批，每批间隔 **24小时** 进催熟房，这样每天都有成熟度合适的香蕉上架。

**4. 如何验证是“乙烯催熟”而非“自然熟”？**

- 看香蕉**果柄断裂处**：乙烯催熟的香蕉果柄通常呈绿色或黄绿色，且断裂面干燥；自然熟的果柄往往变黑。
- 看**糖斑（梅花点）**：自然熟的香蕉糖斑较多且分布均匀，乙烯催熟的糖斑较少、出现较晚。

**关键提醒**：商超若需要精确控制催熟时间，**不要依赖自然熟**。自然熟的窗口期完全不可控，尤其在梅雨季节或高温天，极易在2天内全部烂掉。务必与供应商确认到货状态（青蕉/半熟蕉），并依据上述参数操作。如果您的商超没有专用催熟房，建议直接采购“已催熟至7成熟”的到货批次，到店后只需常温存放1天即可销售。
