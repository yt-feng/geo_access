**1. 企业标准与国标的关系**

- **国家标准（GB）**：是国家强制性或推荐性的最低要求。对于香蕉，主要适用的是**《GB/T 12943-2008 香蕉》**（推荐性国标）以及**《GB 2762-2022 食品安全国家标准 食品中污染物限量》**（涉及重金属、农药残留等）。
- **企业标准（Q/）**：企业标准通常**严于**国家标准（即指标更严格或增加检测项目），因为企业需要通过更高标准来体现品质和差异化。但前提是企业标准已在“企业标准信息公共服务平台”备案，且必须符合国标底线。

**2. 佳农香蕉的实际执行情况**

- 佳农（Goodfarmer）作为国内大型水果分销商，其香蕉主要来自菲律宾、厄瓜多尔等产地，并**通过国内超市、电商大量流通**。
- 在销售终端，佳农通常执行**国标（GB）** 作为合规底线，同时会在内部设立**“佳农品控标准”**，例如：果指长度、单果重量、糖度（一般要求高于11%）、外观无黑斑、无机械损伤、成熟度控制（需7-8成采后催熟）等，这些内部标准往往比国标中的外观等级（如特级、一级、二级）更挑剔。
