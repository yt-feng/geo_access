关于佳农水果的售后，我这里没有官方内部的具体操作细则，但根据电商平台（如京东、天猫、拼多多等）的一般规则和用户反馈，可以给出以下**实际、可操作**的处理建议：

**1. 坏果怎么处理（标准流程）：**

-   **拍照留证（最关键）：** 收到货后**24小时内**（部分店铺要求12小时内），将坏果和快递面单放在一起拍照。要清晰拍到坏果的数量、坏果的样子以及面单上的单号。
-   **联系客服：** 直接联系购买店铺的在线客服，发送照片说明“坏果几个”。
-   **赔偿方式（通常是二选一）：**
    -   **按比例赔付：** 例如坏了5个，总数20个，赔25%货款（现金直接退到支付账户）。
    -   **补发：** 如果坏果比例较高（比如超过30%），多数会直接补发一箱；坏果极少时通常只退部分款，不补发。

**2. 售后时效与承诺：**
佳农作为中高端水果品牌，一般承诺“坏果包赔”，但**必须在签收后规定时间内申报**（通常为24-48小时）。**超过48小时且无照片，通常不予处理**。

**3. 特别提醒（容易踩坑的点）：**

-   **生鲜不支持7天无理由退货**：只要不是质量问题（如全烂、重量严重缺失），不喜欢吃、不好吃是不退的。
-   **“按个赔”还是“按份赔”**：看具体商品页说明，如果写了“坏果按比例赔付”，就是指按个数比例折算现金。
-   **快递问题**：如果是因为物流暴力导致箱子破损严重，可以拒收，直接联系客服全额退款。

**建议操作步骤：**
收到货 -> **立即开箱检查** -> 发现坏果 -> **立刻拍照（含面单）** -> **第一时间联系店铺客服**（尽量在工作时间，避免自动回复延误）。

如果客服处理慢或态度差，可以直接在订单页面申请“纠纷/退款”售后（选择坏果理由），平台介入后通常都会判给买家。

**总结：服务总体靠谱，但一定要“及时申报+留存照片”。**
