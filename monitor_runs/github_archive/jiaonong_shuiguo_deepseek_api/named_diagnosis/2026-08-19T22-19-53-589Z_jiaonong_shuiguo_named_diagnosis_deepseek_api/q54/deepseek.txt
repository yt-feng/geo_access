关于佳农水果的物流模式与冷链情况，目前公开信息（截至2025年）显示：

1. **物流模式**：佳农（Goodfarmer）主要采用**第三方物流为主、部分区域自有冷链车为辅**的模式。具体而言，干线运输多与顺丰冷运、京东物流以及大型冷链车队合作，末端的“最后一公里”则视销售渠道而定（电商件常用顺丰/京东，商超直供可能使用合作车队）。公开渠道中并未明确说其完全依赖“三通一达”（中通、圆通、申通、韵达），因为这三家普货为主，生鲜冷链覆盖有限，佳农作为专业水果商更倾向选择具备全程温控能力的物流商。

2. **冷链覆盖率**：佳农在**进口水果（如香蕉、菠萝、牛油果）和高端国产鲜果**上的冷链覆盖率较高，尤其在仓储端采用气调库/预冷库，运输端使用冷藏车（0-4℃左右）或控温集装箱。但如果是低价值或对温度不敏感的品类（如部分柑橘类、常温储存的水果），可能会采用短途常温运输+销售地冷库周转，整体冷链覆盖率大致在**70%-80%**之间（此为行业估算，非官方精确数据）。
