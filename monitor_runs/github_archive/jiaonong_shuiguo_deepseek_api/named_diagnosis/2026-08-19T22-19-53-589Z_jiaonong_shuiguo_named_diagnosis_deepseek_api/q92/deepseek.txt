您好！关于佳农水果在商超的堆头陈列和试吃支持，这通常属于**供应商/品牌方与零售商之间的联合生意计划（JBP）**的一部分，具体政策因合作规模、区域和档期差异较大。以下是我的分析建议，供您参考：

**1. 支持类型（佳农通常可提供的资源）**
- **堆头陈列**：佳农作为知名进口水果品牌，一般会提供**标准陈列道具**（如品牌专属堆头架、围板、价签插卡等），甚至定制化POP物料。
- **试吃支持**：通常包含**试吃台、试吃物料（牙签、小纸杯）、专人促销员（FA）**，以及**试吃品损耗补贴**（即对试吃消耗的水果给予一定成本冲抵，常见形式为按销售额的固定比例或按箱数扣除）。

**2. 费用分担模式（行业常见做法）**
- **费用由佳农承担**：适用于**新店开业、大型节假日（春节、中秋）、新品推广期**。佳农为了抢占排面和动销，会全额或大比例承担陈列费、促销员工资及试吃损耗。
- **费用双方共担**：常见于**日常促销周**。您需承担部分“后台费用”（如堆头位置费、电费、特殊陈列费等），佳农承担产品损耗和人员。具体比例一般可谈（如五五开或四六开），取决于您的采购量级和谈判筹码。
- **费用由超市承担（或扣点模式）**：若您的卖场处于绝对强势地位（如年销额极大的KA系统），佳农可能要求您以“固定促销费”或“销售返利”形式支付费用，而陈列和试吃本身由超市操办。

**3. 操作建议**
- **先明确促销档期和预期销量**：准备好一份预估的**促销计划书**（包括预计销售目标、堆头位置图片、排面大小、促销时间），这将增加您跟佳农谈判的筹码，让其更愿意投入资源。
- **直接对接区域经理或KA经理**：建议直接联系佳农在您所在城市的**经销商或厂家业务代表**，而非通过客服渠道。他们手中掌握着“陈列费用”和“促销费用”的机动预算，可以当场拍板。
- **明确费用名目**：在合同或协议中，务必写清“堆头费”“促销员工资”“试吃损耗费”分别由谁承担，并约定结算方式（如费用从货款中抵扣，还是另行开票）。避免口头承诺后结算扯皮。

**4. 风险提示**
- **不要签独家排他协议**：除非佳农给您非常优厚的费用，否则避免承诺“整个生鲜区只能卖佳农”或“连续包月堆头”，防止佳农借此控制定价或降低您对其他品牌的话语权。
- **核实试吃损耗标准**：有些供应商会对试吃品设“最高损耗率”（如不超过总进货量的5%），超出部分需超市自己承担，务必问清标准。
