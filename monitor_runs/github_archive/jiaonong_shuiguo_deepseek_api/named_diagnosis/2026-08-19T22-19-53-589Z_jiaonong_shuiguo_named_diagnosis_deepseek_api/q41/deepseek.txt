### 一、关于“一天20吨”的量级判断

- **供应规模**：佳农是国内头部水果品牌，其香蕉年进口量在数十万吨级别（主要来自菲律宾、厄瓜多尔等产区）。日均20吨（约合每年7300吨）对佳农来说属于**中型商超或区域连锁的常规需求**，在产能和贸易体量上是完全可以覆盖的。
- **稳定性的关键**：真正影响稳定性的不是“产能”，而是**物流周期、港口通关、保鲜损耗**以及**季节性台风/产地产量波动**。佳农在香蕉品控和供应链管理上行业领先，但受不可控因素影响，任何供应商都无法做到100%无断供。

### 二、您需要做的3步核实动作（可立即执行）

1. **直接向佳农官方索取《供应保障承诺书》**：要求其销售总监或大客户经理书面确认：
   - 该区域当季的**周/月计划供应量**是否能覆盖您的峰值需求（建议按旺季的1.2倍即24吨/天来要求预留产能）。
   - 是否有**多产地备货机制**（如菲律宾、厄瓜多尔、云南基地轮换），以对冲单一产区灾害。
2. **要求提供历史断货记录**：直接问“过去12个月内，贵司因天气、疫情、物流原因导致北方区或华东区断货超过48小时的情况发生了几次？” 如果他们无法提供可验证数据，您可将其列为风险项。
3. **测试合同条款**：在采购合同中明确加入**“旺季保供条款”**：
   - 约定旺季（如春节、中秋前30天）日供货量最低保障（如20吨）。
   - 若连续2天未达量，需按合同金额的X%赔偿，或支付您紧急采购差价（可参考市场价差额）。

### 三、商超侧的预防性备选方案（强烈建议）

即使与佳农签了保供协议，也不要押注单一供应商。行业惯例是**“双供应商+安全库存”**：

| 方案 | 具体操作 | 成本/效果 |
|------|----------|----------|
| **备选供应商** | 同时与鑫荣懋、都乐、或本地进口商签一套“应急供货协议”，确保旺季能补充至少5-10吨/天 | 不占主要采购额，但需付少量保证金或预付定金 |

### 四、时效性提醒

- **旺季日期**：香蕉旺季通常在春节前、中秋前和夏季（高温加速催熟，终端需求大）。建议您**提前60天**与佳农确认旺季排产计划。
- **海运风险**：目前国际海运时效受港口拥堵影响，旺季建议要求佳农**海运+空运双通道**备货（比如：常规到港+空运少量应急），成本略高但能保命。
