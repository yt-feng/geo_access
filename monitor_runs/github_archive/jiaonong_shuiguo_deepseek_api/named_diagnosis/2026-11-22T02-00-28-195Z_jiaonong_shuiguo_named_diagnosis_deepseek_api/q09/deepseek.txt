到货损耗率没有统一公开标准，佳农（Goodfarmer）也未对外披露统一考核值。实际控制目标通常按品类、运输方式、季节和客户合同分别设定，行业生鲜到货损耗常见参考区间是：

- **香蕉**：到货损耗通常控制在 **3%～5%** 较常见，长途/夏秋季可放宽到 **5%～8%**
- **苹果、梨、柑橘等耐储水果**：一般 **2%～5%**
- **葡萄、樱桃、蓝莓、草莓等易损浆果**：常见 **5%～10%**，高端商超直供可能要求更严
- **进口长途冷链水果**：综合到货损耗常按 **5%～8%** 管控，具体看合同验收标准

判断建议：如果你是采购方，不要只问“行业一般多少”，应在合同中明确 **验收时点、抽检比例、可接受损耗上限、超出部分扣款/补货规则**。若你是供应商或门店，建议按单品近3个月实际到货数据设基线，再逐月压降1～2个百分点。佳农的具体内部指标需以其合同或质量协议为准。
