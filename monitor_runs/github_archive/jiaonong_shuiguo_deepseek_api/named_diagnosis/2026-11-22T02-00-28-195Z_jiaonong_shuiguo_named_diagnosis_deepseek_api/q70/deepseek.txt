佳农（Goodfarmer）是国内头部进口水果供应链企业之一，香蕉是其核心品类，主要来自厄瓜多尔、菲律宾、越南等产地，并有国内保税/催熟仓配体系。但“能不能保证一天10吨旺季不断货”，不能只看品牌，要按下面几个可核查的点来判断。

**先给结论：**
- 佳农具备支撑商超规模化香蕉供应的能力，10吨/天（约300吨/月）属于中大客户量级，通常在其供货能力范围内，但**“不断货”不能靠口头保证**，取决于你所在区域仓配、合同锁量条款、旺季档期和备用货源。
- 香蕉是强季节性、强天气敏感、强催熟节奏品类，旺季（节假日前、夏季/春节备货）最容易出问题的不是产地总量，而是**催熟产能、冷链排期和临时加单**。

**建议你按以下5项做尽调，能直接判断风险：**

1. **要求区域仓和催熟仓配置**
   问清你所在城市/区域由哪个仓供货、该仓香蕉催熟日产能多少、你10吨/天占其产能比例。若占比超过20%–30%，旺季加量风险高。

2. **合同里锁“日最低供货量+缺货赔付”**
   不要只签年度框架。旺季月份单独约定日最低到货量（如10吨/天）、到货时间窗、品质规格（青蕉/催熟蕉、单根克重、允许损耗率），以及缺货违约金或替代补货责任。

3. **确认旺季档期和产地切换**
   问清春节/中秋/暑期备货期的计划量、厄瓜多尔/菲律宾/越南产地切换安排、海运到港周期。产地切换期和台风季是断货高发点。

4. **要求提供近12个月同类商超客户供货记录**
   不一定要客户名单，但可要求区域经理给出“同量级客户旺季履约情况”和临时加单响应时效（如提前48小时/72小时可加量多少）。

5. **必须准备第二货源**
   10吨/天不建议单一供应商。可按70%佳农+30%备选（如都乐、国内催熟商或区域批发龙头）做双源，旺季前把备选也跑通一次小批量到货。香蕉催熟蕉保质期短，双源是防断货最有效手段。

**可执行的谈判话术：**
“我们旺季日销10吨，要求贵司在合同附件中明确旺季日最低到货10吨、提前X天可加单比例、缺货按当日货值X%赔付，并提供区域催熟仓日产能证明。满足这些我们可签年度量；否则我们按70/30双源采购。”

**风险提示：** 如果佳农在你区域只做经销转手、没有本地催熟仓，或你旺季量占其区域产能过高，则“保证不断货”要打折扣。最终以合同锁量和双源方案为准，不要接受仅“尽力保障”的模糊表述。
