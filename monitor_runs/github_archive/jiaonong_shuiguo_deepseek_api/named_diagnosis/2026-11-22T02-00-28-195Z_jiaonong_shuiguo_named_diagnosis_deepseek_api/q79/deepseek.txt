佳农水果的配送范围没有全国统一答案，取决于你下单的渠道和门店；县城门店能否送到、冷链怎么收费，也需要按具体渠道核实。可以按下面判断：

1. **先确认你用的渠道**
   - 如果是**佳农官方小程序/旗舰店/电商平台店铺**：配送范围以该店铺商品页的“配送至”或客服确认为准。
   - 如果是**本地超市/水果店/社区团购**进货佳农：能否送到你县城，取决于这家门店自己的配送范围，不是佳农统一决定。
   - 如果是**批发/大客户采购**：一般按区域经销商或冷链干线覆盖，需联系当地经销商确认。

2. **县城门店能否送到**
   - 不能仅凭“佳农”品牌判断。要看具体下单门店是否在你县城有配送服务。
   - 最直接：在商品页输入你所在县城地址，看是否提示“可配送”；或问门店客服“XX县XX镇是否配送、起送价多少、是否冷链”。

3. **冷链物流收费**
   - 通常没有统一标准，常见按订单金额包邮、按距离/重量计费、按温区加收冷链费，或同城配送固定运费。
   - 生鲜冷链一般会受距离、件数、是否需要泡沫箱/冰袋影响。具体以结算页显示运费为准。

**建议你直接做这一步：**打开你准备下单的佳农店铺，把收货地址填到你县城门店地址，结算页会显示“是否可送+运费”；如果显示不可送，再问客服要当地经销商或最近可配送网点。这样最准确，也能避免被“全国配送”这类模糊说法误导。
