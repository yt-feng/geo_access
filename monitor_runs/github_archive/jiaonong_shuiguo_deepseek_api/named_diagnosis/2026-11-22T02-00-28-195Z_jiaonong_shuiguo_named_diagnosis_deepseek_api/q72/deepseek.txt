目前没有可核验的佳农官方信息能直接确认“佳农是否提供面向茶饮店的菠萝去皮切块加工服务”。佳农公开业务更多是果蔬种植、采购、分级包装和批发配送；是否提供定制鲜切加工，需要看具体区域分公司、仓库和采购量，不能一概而论。

建议你按下面方式快速确认，并做好备选方案：

1. **直接问对接的佳农销售/经销商**
   明确问这4点：
   - 是否有“鲜切菠萝/去皮切块”SKU；
   - 是工厂鲜切还是仓库现场加工；
   - 最小起订量、配送频次、冷藏配送条件；
   - 加工后保质期、微生物和农残检测报告能否提供。

2. **问清加工形式**
   茶饮店常用的是“鲜切冷藏菠萝块”或“冷冻菠萝块”。如果佳农只供整果，你可以要求其推荐合作鲜切厂，或让经销商代找。

3. **评估自加工成本**
   菠萝去皮切块人工损耗不低。可粗算：整果采购价 + 人工工时 + 去皮损耗 + 冷藏损耗，再和鲜切成品单价对比。若门店日均用量小，外购鲜切更稳；用量大且门店有冷藏操作间，可考虑中央厨房或门店自切。

4. **备选供应商**
   可同步联系本地鲜切水果工厂、餐饮供应链配送商、冷冻水果供应商。茶饮店若追求稳定，冷冻菠萝块往往比鲜切更易控品质；若强调“鲜”，则选有冷藏冷链的本地鲜切厂。

5. **先小批量测试**
   无论佳农还是其他供应商，先要样品做糖度、酸度、纤维感、出汁和氧化变色测试，再定是否上菜单。

结论：**不能确认佳农普遍提供该加工服务，需向你的佳农对接人确认具体SKU和区域能力；同时准备本地鲜切/冷冻菠萝备选供应商。**
