**可执行建议：**

1. **先向佳农区域业务/经销商要小包装SKU清单**
   明确问这几点：
   - 香蕉是否有 **2kg/3kg/5kg** 箱装或袋装；
   - 是不是 **门店可整箱上架** 的陈列箱，还是周转箱；
   - 最小起订量、配送频次、损耗/售后政策；
   - 香蕉到店成熟度，是否适合便利店小批量快周转。

2. **便利店小面积更适合的佳农品类顺序**
   香蕉体积大、易压伤、周转要求高，小门店优先考虑：
   - **小袋装苹果/橙/梨**（2-3个/袋）；
   - **单根或小把香蕉**（如果供应商支持分把配送）；
   - **预包装奇异果、小番茄、提子小盒**；
   - 香蕉若做，建议 **按把/小篮陈列**，不要整3kg箱直接堆放。

3. **3kg香蕉是否适合你店，按这个标准判断**
   - 日均能卖 **8-12根以上**，再考虑3kg装；
   - 门店有 **18-22℃、通风、避免挤压** 的陈列位；
   - 能接受 **2-3天周转**，否则香蕉损耗会吃掉毛利；
   - 若日均销量低于5根，优先让供应商配 **1-1.5kg小把/小篮**，或先做预售/团购。

4. **订货前做7天试销**
   先订最小规格试卖，记录：到店成熟度、日销量、报损率、顾客接受价格。若7天报损超过10%-15%，就不要上3kg整箱。

**结论：**“3kg装香蕉”需要向佳农当地经销渠道书面确认，不能凭常规包装推断。你门店面积小，建议优先争取 **1-2kg小把/小篮香蕉** 或小袋装水果；3kg装只适合日均销量稳定、能快速周转的门店。
