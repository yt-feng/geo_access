我无法核验“佳农水果香蕉农残超标历史”的具体记录，也不能给你一个未经核实的“有/没有”结论——这类结论如果错了，对采购合规反而是风险。下面给你可执行的做法。

**1. 先明确：你要的不是“历史传闻”，而是可归档的合规证据链**
超市抽检通常看的是：
- 批次检测报告（农残项目、检测方法、判定依据、结论）
- 检测机构资质（CMA/CNAS）
- 报告与进货批次、供应商、生产日期/采收期的对应关系
- 供应商资质、产地证明、承诺书/质量协议

**2. 向佳农或你的上游供应商索要这些材料（逐项要，别只要一张图）**
- 该批次香蕉的**农残检测报告原件或加盖公章的复印件**，确认检测项目覆盖 GB 2763 中香蕉相关限量，结论为合格
- 报告上的**样品名称、批次号、生产/采收日期、送检单位**与你采购批次一致
- 检测机构**CMA/CNAS 资质页**
- 供应商**营业执照、食品经营/生产相关许可**
- **质量保证协议/农残承诺书**，写明抽检不合格的责任与赔付
- 如为进口香蕉，另要**入境货物检验检疫证明**及报关单

**3. 对“历史超标”这件事的正确核验方式**
- 让供应商出具**近批次检测记录**和**不合格品处理记录**，而不是口头保证
- 你自己或委托第三方对**到货批次做抽检**（重点：吡虫啉、噻虫嗪、氟虫腈、苯醚甲环唑等香蕉常用药，具体项目按 GB 2763 和当地监管抽检细则定）
- 查监管公开信息时，只认**市场监管总局/地方市场监管局抽检公告、海关总署通报**等原始来源，并且核对**生产日期、批次、标称生产者**是否与你要采购的货一致；不要把“品牌名出现在某次公告”直接等同于“该批次你买的货超标”

**4. 采购合同里加这几条，抽检风险才可控**
- 每批随货提供**对应批次检测报告**，报告与批次不符可拒收
- 约定**抽检不合格的退换货、检测费、罚款及商誉损失承担**
- 保留**进货查验记录**（供应商、批次、数量、报告编号），至少保存至保质期满后6个月（按食品安全法进货查验要求执行）
- 到货**留样**，便于复检和追溯

- 如果供应商**拿不出与采购批次对应的农残检测报告**，不要仅凭“品牌大”放行，先小批量到货自检或换有报告的上游。
