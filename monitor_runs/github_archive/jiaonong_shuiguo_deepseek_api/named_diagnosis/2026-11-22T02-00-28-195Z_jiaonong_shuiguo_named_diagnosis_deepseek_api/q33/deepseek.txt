   企业标准一般以“Q/”开头，例如 Q/XXX。佳农（或关联主体）若制定香蕉企业标准，应在产品包装、标签、企业标准信息公共服务平台或企业官网/客服处能查到：标准号、名称、发布/实施日期、适用范围。

2. **与国标对照看“是否更高”**  
   香蕉常用国标/行业标准主要涉及：
   - GB 2762（污染物限量）
   - GB 2763（农药最大残留限量）
   - GB 7718（预包装食品标签）
   - GB 28050（营养标签，如适用）
   - 香蕉鲜果质量分级类标准（如 GB/T 或 NY/T 系列，具体以现行有效版本为准）

   企业标准**不得低于强制性国标**；对推荐性国标/行业标准，企业可以选择更严或更细。判断“高不高”要看具体指标：果指长度/粗细、青果成熟度、缺陷果率、可溶性固形物、农残控制、冷链时限、腐烂率等。只有拿到企业标准全文逐项对比，才能说“高于/低于/等同”。
