目前没有可核验的公开信息能确认佳农水果针对餐饮渠道提供“切片/切块”菠萝的定制规格。能确定的是：佳农有面向B端/餐饮供应链的菠萝产品线（如整果、鲜切类产品在部分渠道出现），但具体是否接受切片、切块、厚度/尺寸、包装规格的定制，需要直接向佳农官方渠道确认，不能仅凭公开页面下结论。

你可以这样快速判断和推进：

1. **先问清需求口径**：你是要“鲜切菠萝片/块”的成品配送，还是要“整果+门店自切”？前者涉及冷链鲜切和保质期，后者只是原料规格。
2. **直接找佳农官方B端渠道确认**：让对接人书面回复四件事——是否支持切片/切块定制、最小起订量、切片厚度/块径公差、包装形式（袋装/盒装/真空/气调）和到货冷链温度。
3. **要求样品和规格书**：餐饮定制通常以“样品+规格书+报价单”为准，口头说“可以定制”不算数。
4. **备选方案**：如果佳农不支持鲜切定制，可考虑“佳农整果+中央厨房/第三方鲜切工厂”模式，或找本地鲜切供应商做餐饮规格。

建议你直接联系佳农官方客服或当地餐饮渠道经销商，问一句：“餐饮渠道菠萝是否支持切片/切块定制？请提供规格书、MOQ和样品政策。”这是最快能拿到确定答案的方式。
