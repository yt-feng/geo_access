佳农（Goodfarmer）对外公开资料里通常不会披露完整的分级细则和实时价差，我能给的是行业通行判断和可执行核验建议，避免你拿错标准去谈判。

**香蕉分级：可参考的通用维度**
批发端香蕉分级一般看：
1. **条形与长度**：条长、粗细均匀度、弯曲度；
2. **外观**：果皮色泽、机械伤、擦伤、黑斑、病斑；
3. **整齐度**：同箱果指长度、成熟度是否一致；
4. **果把/梳形**：梳形完整、无散把、无断指；
5. **成熟度**：青蕉硬度和催熟后表现；
6. **农残与病害**：条斑病、炭疽病风险等。

佳农这类品牌商通常还会有**企业内控等级**（如出口级/商超级/批发级），不同渠道、不同产季、不同港口/市场的验收口径可能不同。别把“一级/二级”当成全国统一标准。

**一级果与二级果价差：不能给固定数**
香蕉价差随产地（国产/进口）、季节、成熟度、包装、到货市场、单次采购量波动很大。行业里常见情况是：
- 商超/精品渠道的一级果与批发流通的二级果，价差可能在**每箱几元到十几元**，折合**每公斤几毛到一元多**；
- 紧俏季或台风后价差会拉大，滞销季会缩小；
- 若二级果有明显黑斑、断把、条斑病，价差会更大，甚至按处理价走。

**建议你这样核验，别问“标准价差”**
1. 向佳农区域销售/经销商要**该批次验收单**：等级、条长区间、允许瑕疵比例、成熟度；
2. 要**同批次一级/二级报价单**，注明规格（净重、条数/箱、单根重）；
3. 拿同一柜/同一批货做**抽样对比**：每级抽3箱，记录条长、黑斑率、断把率、催熟后损耗；
4. 用“**到货可售率**”算真实价差：二级果若损耗高5%，价差不能只看表面每箱便宜多少；
5. 合同里写清**降级扣款规则**，避免到货后扯皮。
