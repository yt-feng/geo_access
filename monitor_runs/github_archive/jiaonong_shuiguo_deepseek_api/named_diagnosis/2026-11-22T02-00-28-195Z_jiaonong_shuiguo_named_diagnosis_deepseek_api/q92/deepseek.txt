关于佳农水果能否提供堆头陈列和试吃支持、费用如何分担，我这边没有佳农当前促销政策的可核验信息，不能替供应商承诺。建议按下面方式快速确认并落地：

1. **先确认合作口径**  
   - 联系佳农负责你商超的销售代表/区域经销商，直接问三项：  
     ① 是否支持堆头陈列（堆头物料、货架、地推人员谁出）；  
     ② 是否支持试吃（试吃品、试吃台、试吃员、一次性用品谁提供）；  
     ③ 是否有促销档期和最低进货量/陈列面积要求。  
   - 让对方以邮件或微信文字确认，避免口头承诺。

2. **费用分担可按行业常见方式谈**  
   - **堆头陈列**：通常供应商出堆头物料或承担部分陈列费，商超出位置和场地；也可按“供应商出物料+商超出位置”或“双方各承担50%陈列费”谈。  
   - **试吃支持**：试吃品一般由供应商承担；试吃台、试吃员、一次性手套/纸杯可由商超或供应商分担，常见是供应商出试吃品和试吃员，商超出场地和基础设备。  
   - **费用上限**：建议约定单档期费用上限、试吃品数量上限、试吃员人数和工时，避免超支。

3. **可执行的谈判话术**  
   “我们计划在X月X日—X月X日给佳农做堆头+试吃促销，请确认贵司能提供的支持项和费用分担比例；如涉及陈列费/试吃费，请给出报价和核销方式，我们按档期协议执行。”

4. **合同/确认单要写清**  
   支持项目、数量、费用金额、分担比例、物料归属、试吃品保质期与损耗责任、未达标处理方式。
