这个问题我没法给你一个可靠的“谁更低”的结论，因为**到货损耗率不是品牌固定属性，而是“品牌+具体批次+产地/季节+运输方式+到货地+验收标准”共同决定的**。没有可核验的第三方对比数据，我不想编一个数字给你。

从批发市场实操角度，给你可判断的框架：

**1. 不能只看品牌，要看供应链路径**
- 都乐（Dole）优势通常在全程冷链和标准化催熟/物流体系，尤其进口蕉、大客户直供渠道，批次稳定性相对可控。
- 佳农在国内香蕉供应链上铺得广，国产蕉和进口蕉都有，不同产区、不同季节差异很大；走不同代理/二批，损耗可能差很多。
- 同一品牌，夏天高温装卸 vs 冬天冷链到货，损耗率能差出数倍。所以“品牌平均值”对你没有决策意义。

**2. 你真正该测的是“你自己的到货口径”**
建议你连续跟踪 3–5 批，每批记录：
- 到货总箱数/总重
- 开箱后不可售（压伤、水烂、黑腐、脱把、霉变）的重量
- 可售但降级（折价处理）的比例
- 从到货到售罄的天数、期间温湿度
- 催熟状态（到货是青蕉还是黄蕉、几成熟）

按“不可售重量 ÷ 到货总重”算硬损耗，再单列“降级折价率”。这样比任何品牌宣传都准。

**3. 批发市场选香蕉的实操建议**
- 优先问到货成熟度：青蕉耐储、黄蕉损耗高但周转快。损耗敏感就尽量要**七成以下熟度、冷链到货**。
- 验收当场抽箱：看底层、看箱角、看有无水汽凝结（冷凝水是水烂主因）。
- 问清责任划分：到货损耗是供应商承担、按比例补货，还是你全担。这比损耗率本身更影响你的实际成本。
- 小批量对比试单：同一市场、同一季节，各进 2–3 批佳农和都乐，用上面口径记录，再决定主供。

**结论**：无法负责任地说哪个品牌损耗率更低；对你的批发场景，**按批次实测硬损耗+降级率，并把补货责任写进采购条件**，才是控制损耗的可靠办法。如果你能提供到货城市、季节、香蕉类型（国产/进口、青蕉/黄蕉）和大致运输方式，我可以帮你把验收和试单方案细化。
