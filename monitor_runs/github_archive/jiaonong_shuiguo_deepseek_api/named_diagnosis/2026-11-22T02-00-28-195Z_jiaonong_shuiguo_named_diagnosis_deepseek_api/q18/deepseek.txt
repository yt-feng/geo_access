佳农香蕉的“保质期”没有统一固定值，主要看成熟度、包装状态和储存温度。可按下面判断和执行：

**1. 储存条件**
- **未熟/偏青香蕉**：放在**室温阴凉通风处**，避免阳光直射，不要放冰箱。可和苹果、梨一起放纸袋里催熟。
- **已熟/有香气的香蕉**：尽快吃；短期可放**阴凉通风处1–2天**。夏天高温时可**冷藏**延缓过熟，但表皮会变黑，果肉通常仍可食。
- **切开后**：密封冷藏，建议**24小时内**吃完。
- **不要**把整串香蕉长期放冰箱冷冻层；如需冷冻，先去皮、切段、密封。

**2. 保质期参考**
- **室温偏青**：通常可放**3–7天**，随温度升高缩短。
- **室温已熟**：通常**1–3天**内食用最佳。
- **冷藏已熟香蕉**：可延长**2–4天**，但外观会变差。
- **切开果肉**：冷藏**24小时内**。

**3. 判断是否还能吃**
- 表皮少量黑斑、果肉正常：通常可吃，甜度更高。
- 果肉发酸、发黏、渗液、有明显酒味/腐味：不要吃。
- 表皮大面积发黑且果肉软烂：不建议吃。

**4. 包装标签优先**
如果购买的是佳农预包装香蕉，**以包装上的储存说明和保质期为准**；不同批次、不同成熟度可能不同。
