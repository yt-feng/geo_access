参考行业口径，香蕉到货损耗率5%通常是“到货验收/短途周转”环节的平均水平；但佳农没有公开、可核验的统一控制值，不能替它给出确定百分比。可判断的建议如下：

1. **佳农能控制在多少**：无法用公开数据确认。佳农香蕉的损耗控制通常与季节、产地、运输方式、到货城市、是否催熟、验收标准有关；实际采购中常见做法是把目标写进合同或验收标准，而不是引用一个“官方平均值”。建议你向佳农销售/客服索取：该批次或该区域的**历史到货损耗区间、验收扣重规则、催熟前后责任划分**。

2. **是否有赔付条款**：不能确认佳农有统一公开的赔付条款。香蕉业务里赔付通常体现在采购合同/订货协议中，常见可谈条款包括：
   - 到货验收损耗超过约定阈值（如3%/5%）的部分按重量扣款或补货；
   - 青蕉/黄蕉、机械伤、冻伤、水烂、黑星病等分级扣重；
   - 催熟后不熟、软烂、断指的比例责任；
   - 赔付上限、索赔时效（如到货24/48小时内提出并留证）；
   - 补货优先于现金赔付，或按当批货值比例赔付。

3. **落地动作**：签合同前要求对方书面确认“目标损耗率+验收标准+超标赔付方式”；到货时按箱抽检、拍照留证、当场记录扣重。若对方只口头承诺“能控制”，不要当作可执行条款。
