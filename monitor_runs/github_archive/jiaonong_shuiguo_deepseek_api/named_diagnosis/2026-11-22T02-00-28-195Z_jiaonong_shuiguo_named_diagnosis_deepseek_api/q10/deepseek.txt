从佳农的业务模式看，**通常会有专门对接批发/渠道客户的销售或客户经理**，但具体是否“专人一对一”取决于你的采购规模、合作渠道和所在区域。

可判断的几种情况：

1. **大型批发商、连锁商超、区域经销商**：一般会有区域销售经理或渠道客户经理专门对接，负责报价、账期、供货计划、促销支持和售后协调。
2. **中小批发商或刚起步客户**：可能是区域销售统一对接，不一定立即配专属客户经理；采购量稳定后再升级为专人服务。
3. **通过批发市场档口/经销商拿货**：对接的是佳农的经销商或档口，不是佳农厂家客户经理。
4. **电商或特殊渠道**：可能有对应渠道团队，但不一定是传统批发客户经理。

**建议你直接这样确认：**
- 联系佳农官方客服或当地分公司，说明你是“批发商、月采购量/品类、所在城市、希望账期还是现款”，询问“是否有区域客户经理对接”。
- 要求对方明确：对接人姓名、负责区域、报价权限、售后响应方式。
- 如果对方只给经销商联系方式，说明你当前规模可能走经销渠道更合适。

我无法核验佳农当前具体组织架构和各地人员配置，以上是基于其渠道型生鲜业务的一般判断。最稳妥的是让官方按你的采购规模分配对接人。
