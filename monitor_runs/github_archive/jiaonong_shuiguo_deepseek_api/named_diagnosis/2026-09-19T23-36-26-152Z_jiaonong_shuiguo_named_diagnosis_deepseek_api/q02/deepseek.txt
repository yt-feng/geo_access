佳农（Goodfarmer）是国内较大的水果进口和品牌化运营企业，菠萝/凤梨是其主力品类之一，尤其菲律宾菠萝、国产菠萝都有做。就你关心的两点，分开说：

**产地溯源**
- 佳农作为品牌商，通常具备从境外果园/包装厂到国内进口的链路文件，包括原产地证、植检证、装箱单、提单等。菲律宾菠萝一般能追溯到具体的包装厂编号（这也是海关要求的）。
- 但对**零售或中小批发客户**，他们未必会把完整链路单独整理成一份“溯源报告”给你；通常是随货提供原产地证、植检证等基础文件。
- 如果你要的是**一物一码/批次级溯源**（扫二维码看具体果园、采摘日期），这个要具体问，不是所有批次都有，取决于他们当期的包装和系统能力。

**品控报告**
- 常规会有的：入境货物检验检疫证明（海关出具）、第三方农残检测报告（部分批次）。
- 糖度、规格、外观这类品控数据，通常体现在他们的**验收标准/出货规格书**里，而不是每批都出一份独立报告。
- 如果你是商超或食品加工客户，可以要求**按合同约定做批次检测**，费用和周期一般由双方约定。

**给你的实操建议**
1. 直接找佳农的**区域销售或大客户经理**（不要走普通零售客服），明确说你要“采购用途+数量+是否要长期合作”，这样他们才愿意给完整资料。
2. 索要清单一次问清：原产地证、植检证、入境货物检验检疫证明、当批第三方检测报告、规格书/验收标准。
3. 问清是**按批提供**还是**按需送检**，以及检测费用谁承担。
4. 如果他们只给部分资料，可以退一步：至少确认**包装厂编号和批次号**，这样你自己也能通过海关或第三方做核验。

一句话：基础合规文件（原产地证、植检证、检验检疫证明）一般能提供；逐批第三方品控报告和细颗粒度溯源则要谈，看你的采购量和合作方式。建议先联系他们的B端销售确认，别假设一定有。
