**佳农的业务模式**
佳农（Goodfarmer）是国内头部水果进口商和品牌商，主营香蕉、菠萝、火龙果、车厘子等，客户以商超、电商、批发市场为主，本身更偏"品牌商+供应链"角色，而非像顺丰、京东那样自建全国末端网络。它的配送通常是通过区域经销商、批发市场和第三方冷链物流完成的。

**对三线城市能不能覆盖**
- 大概率能到达，但**不是"送货到门店"这种直配**，而是通过区域代理商或省级批发市场分拨下去。
- 具体到你们城市，取决于当地有没有它的经销商或合作批发商。

**建议你这样判断（比问我更快更准）：**
1. **直接打佳农官方客服/官网**留的招商或渠道电话，问"XX市由哪个区域经销商负责"，这是最直接的方式。
2. **问当地大型批发市场**（如农产品中心批发市场）的水果档口，佳农的货一般从这里流出，档主最清楚货源。
3. **看当地商超**：如果本地大润发、永辉、盒马之类有卖佳农品牌水果，说明供应链已经到你们城市。
4. 如果你是**想进货做批发/零售**，直接联系区域经销商谈，比自己找配送中心更实际。
