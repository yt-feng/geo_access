佳农（Goodfarmer）是国内较大的水果进口与分销企业之一，苹果品类通常以进口苹果为主，常见会涉及：

- **嘎啦（Gala）**：常见产地包括**新西兰、美国、智利、南非**等，不同季节会切换南半球/北半球产区。
- **红富士（Fuji）**：常见产地包括**美国、新西兰、智利、南非**等；部分渠道也会销售国产红富士，但“进口红富士”主要看当季到货。
- **其他常见苹果**：如爱妃（Envy）、爵士（Jazz）、皇后（Queen）、太平洋玫瑰（Pacific Rose）、青苹果（Granny Smith）等，具体以佳农当季产品册为准。

关于你采购进口嘎啦和红富士的产地：

1. **嘎啦**  
   - 若当前是南半球产季，常见为**新西兰、智利、南非**。  
   - 若北半球产季，常见为**美国**等。  
   - 具体到港批次要以佳农官方销售或当季报价单为准。

2. **红富士**  
   - 进口红富士常见产地为**美国、新西兰、智利、南非**等。  
   - 其中美国红富士、新西兰红富士在部分渠道较常见。  
   - 同样，实际产地随季节和批次变化，不能固定说只来自某一国。

**采购建议：**  
如果你要采购进口嘎啦和红富士，不要只问“佳农产地是哪里”，而应向佳农官方或授权经销商索取：  
- 当季产品目录  
- 到港批次原产地证明  
- 规格、等级、包装、糖度、硬度等指标  
- 报价单和起订量  

因为进口苹果的产地会按产季轮换，同一品类不同月份可能来自不同国家。
