你可以按下面方式快速确认并判断：

1. **看下单渠道**
   - 如果是**天猫/京东/抖音等平台旗舰店**：客服在线时间通常以店铺页面标注为准，很多是每天 9:00–21:00 或类似时段，不一定 7×24。
   - 如果是**佳农官方小程序/官网**：页面一般会写“客服时间”或“服务时间”。
   - 如果是**线下商超/经销商**：那不叫佳农官方客服，处理时间取决于具体门店。

2. **周末下单是否有人处理**
   - **平台店**：周末通常可以下单，但**人工客服和发货处理可能顺延**，尤其是生鲜类还要看仓库排班。
   - **官方小程序/官网**：是否能周末处理，要看其公告；不少生鲜商家周末可接单，但发货可能按工作日或次日排。
   - **是否“有人处理”**：下单成功不等于马上有人工审核；自动接单和人工处理是两回事。

3. **最快确认方法**
   - 打开你准备下单的页面，找“客服”或“服务时间”；
   - 直接发一句：“周末下单今天能处理/发货吗？”
   - 看自动回复里有没有写服务时段；
   - 如果着急，优先选页面明确写“周末发货”或“48小时内发货”的链接。

4. **实用建议**
   - 周末下单前先问客服：**今天是否发货、最晚什么时候发、坏果怎么赔**。
   - 如果客服不在线，别默认“7×24有人处理”，按“可能顺延到工作日”来预期。
   - 生鲜水果对时效敏感，急用的话尽量选**本地仓/次日达/平台自营**，并保留聊天记录。
