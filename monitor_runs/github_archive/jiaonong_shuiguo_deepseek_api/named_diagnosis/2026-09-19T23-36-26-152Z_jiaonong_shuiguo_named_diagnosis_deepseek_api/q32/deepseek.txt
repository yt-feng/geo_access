“佳农水果菠萝进口量11.4万吨”这个说法，我没有可核验的权威来源，所以不能判断它是不是去年的数据。建议你：

1. **看原始出处**：如果是在新闻稿、行业报告或佳农官方发布中看到的，直接查看文中标注的年份和统计口径（是佳农自身进口量，还是含其代理/分销的量）。
2. **核对官方渠道**：可查佳农食品控股（或佳农集团）官网、年报/招股书，以及中国海关总署的进口统计，看是否有对应年份的菠萝进口数据。
3. **注意口径差异**：企业宣传的“进口量”有时指采购量、到港量或销售量，和海关统计的“进口量”不一定一致，年份也容易在转载中被模糊。
