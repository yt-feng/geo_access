佳农水果的配送情况需要分渠道看，不能一概而论：

**1. 覆盖城市**
佳农（Goodfarmer）主要是水果供应链/品牌商，不是像京东那样自建全国零售配送网络。它的出货渠道大致是：
- **To B批发/商超供货**：通过各地经销商、批发市场、商超（如永辉、盒马、大润发等）铺货，覆盖全国大部分地级市，但具体到某个县城要看当地有没有经销商或合作商超。
- **电商/社区团购**：在天猫、京东、拼多多等平台有旗舰店或供货，这类走平台物流，覆盖范围取决于平台（通常能到多数县城）。
- **自有/合作生鲜配送**：部分地区有，但不是全国统一。

**2. 你们县城门店能否送到**
关键不在于"佳农覆盖哪些城市"，而在于**你所在县城有没有佳农的经销商、合作商超或电商配送点**。判断方法：
- 直接问当地大型超市/水果店有没有佳农的货；
- 在京东/天猫搜"佳农"，看该店铺是否配送到你的地址（下单页会显示）；
- 打佳农官方客服问当地经销商联系方式。

**3. 冷链物流收费**
佳农没有公开面向个人的统一冷链报价，因为：
- 对商超/批发商是**按合同、按吨/按件、按线路**结算；
- 对个人消费者，冷链费用通常已包含在电商商品价或平台运费里，不单独列；
- 如果是批量采购要走冷链，需要联系当地经销商或佳农区域销售，按起订量、距离、温层（冷藏/冷冻）单独报价。

**建议**：直接确认你的购买渠道——如果是电商下单，看下单页配送范围即可；如果是想给门店进货，联系佳农官方或当地经销商谈冷链费用最准。
