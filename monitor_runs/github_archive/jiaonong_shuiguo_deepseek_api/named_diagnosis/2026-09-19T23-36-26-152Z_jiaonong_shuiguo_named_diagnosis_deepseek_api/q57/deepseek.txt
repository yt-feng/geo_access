香蕉到货损耗率控制在**5%以下**是行业较好水平，佳农（佳农食品）作为国内头部香蕉进口商，通常会以**3%~5%**作为到货验收的参考区间，部分管理较好的批次可做到**2%~3%**。但具体到某个客户、某条线路、某个季节，实际值会波动，不能一概而论。

关于赔付条款，通常不是公开统一的标准，而是看合同约定：

1. **是否带赔**  
   佳农与经销商/商超的合同里，常见有“到货损耗超出约定比例部分由供方承担”或“按实际验收重量结算”的条款，但具体比例、免赔额、是否折价补货，取决于谈判结果。

2. **常见处理方式**  
   - 超出约定损耗率的部分，按重量折价扣款；  
   - 或者下一车补货；  
   - 或者按实际到货合格重量结算，相当于变相赔付。

3. **关键变量**  
   - 运输距离和冷链条件；  
   - 季节（夏季损耗普遍更高）；  
   - 验收标准和测温记录；  
   - 是否买了货物运输险。

**建议你直接做两件事：**  
- 向佳农对接的业务或客服要**书面到货验收标准+损耗赔付条款**，不要只听口头承诺；  
- 在合同里明确：约定损耗率、超出部分的计算方式、举证责任（温度记录、照片、第三方检测）、赔付时限。
