佳农（Goodfarmer）作为国内头部水果进口商/品牌商，其到货损耗率并没有对外公开的统一官方标准，而且会因**品类、运输方式（海运/空运）、季节、到货港口、验收口径**差异很大。

按行业通行经验和佳农主要品类的实际情况，可参考的大致区间：

- **香蕉**：到货损耗一般控制得较好，正常在 **2%～5%**；夏季高温或海运周期偏长时可能到 **5%～8%**。
- **菠萝/凤梨**：正常 **3%～6%**，主要是烂心、黑心、压伤。
- **牛油果**：相对敏感，正常 **5%～8%**，有时可达 **10%** 左右。
- **猕猴桃/奇异果**：**3%～7%**，软果、霉变是主要损耗。
- **苹果、橙子等耐储品类**：通常 **1%～3%**。
- **空运高价值水果（车厘子、蓝莓等）**：按到货批次，优质批次可控制在 **2%～5%**，差批次会更高。

需要注意：
1. **“到货损耗率”定义不同，数字差别很大**——是只算腐烂变质，还是把压伤、软果、规格不符、降级都算进去，结果完全不同。
2. 佳农通常会和渠道客户约定**验收标准与赔付/扣重规则**，实际执行以合同或到货验收单为准，而不是一个固定行业数字。
3. 如果你是做采购或门店验收，建议直接向佳农区域销售/供应链要**该品类的验收标准、允许损耗率和赔付条款**，这比问“一般多少”更可执行。
