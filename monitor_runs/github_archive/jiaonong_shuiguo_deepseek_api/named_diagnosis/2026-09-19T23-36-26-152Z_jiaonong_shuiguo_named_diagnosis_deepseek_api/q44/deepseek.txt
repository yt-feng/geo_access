关于佳农水果香蕉的农残超标历史，我没法给你一个可核验的结论——我无法确认它是否曾出现在各地市场监管抽检不合格名单中。这类信息必须以官方抽检公告为准，我不能凭印象或传闻替你下判断。

不过你们采购要过超市抽检，关键不在于"历史有没有事"，而在于**拿到当期可验证的合规证明**。给你一套可执行的清单：

**必须向供应商索取的证明（缺一不可）**
1. **第三方检测报告**：针对本批次香蕉的农残检测，检测项要覆盖 GB 2763《食品中农药最大残留限量》中香蕉的相关项目（常见如吡虫啉、噻虫嗪、多菌灵、咪鲜胺、百菌清等，具体以最新版 GB 2763 为准）。报告要有 CMA 资质章，且检测日期对应你们采购的批次。
2. **产地证明 / 供货凭证**：能追溯到具体产地、果园或合作社，便于出问题时定位。
3. **合格证 / 承诺达标合格证**：农产品承诺达标合格证，是现在流通环节的常规要求。
4. **进货台账**：品名、批次、数量、供货者、日期。

**几件事你必须自己核验，别只信供应商给的复印件**
- 报告编号去出具机构官网或官方平台验证真伪（假报告、套用报告很常见）。
- 报告上的**批次号 / 生产日期**要和实际到货一致，防止"一批报告走天下"。
- 检测项目是否覆盖香蕉，有些报告只测了常规几项，不够。

**想查佳农或任何品牌的历史抽检记录**
- 国家市场监督管理总局"食品安全抽检"栏目；
- 各省市市场监管局官网的不合格食品通告；
- 用品牌名 + "抽检不合格" + 年份 定向检索。
这些是公开可查的，你自己或让供应商提供检索结果更稳妥。

**一句话建议**：谈判时把"每批随货提供本批次第三方农残检测报告（CMA）+ 承诺达标合格证"写进采购合同，作为验收和付款条件。这样无论品牌历史如何，你们每一批都有合规凭证，超市抽检才兜得住。
