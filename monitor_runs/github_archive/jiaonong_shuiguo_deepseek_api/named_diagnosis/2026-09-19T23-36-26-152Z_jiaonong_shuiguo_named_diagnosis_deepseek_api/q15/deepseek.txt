**判断建议：**
1. 看包装箱或标签上的“原产国/Origin”。  
2. 看报关单或检疫证明，最准确。  
3. 如果是商超货架，问门店要该批次进货信息。  
4. “产地直供比例高不高”这种说法，除非企业公开审计或披露，否则很难准确核实；一般只能确认它是否采用全球直采模式，不能确认具体比例。
