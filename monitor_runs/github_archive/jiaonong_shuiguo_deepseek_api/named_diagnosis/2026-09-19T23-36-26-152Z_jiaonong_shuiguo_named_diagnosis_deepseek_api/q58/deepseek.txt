佳农（Fruitco/佳农食品）主要以**香蕉、菠萝等生鲜水果的种植、进口和批发**为主，面向商超、批发市场和餐饮渠道供应**整果**居多。

关于**菠萝丁这类加工品**，佳农是否提供定制加工，目前没有公开、稳定的明确信息可以核验，不能直接替它确认。比较稳妥的判断和建议是：

1. **佳农大概率不是首选加工供应商**
   它更偏生鲜水果供应链，不是专门做茶饮原料切丁/冷冻果丁的加工厂。即使有加工业务，也通常是标准化规格，不一定愿意按茶饮店的小批量、特定尺寸定制。

2. **建议先直接问佳农当地销售或客服**
   问清楚这几点：
   - 是否供应菠萝丁/冷冻菠萝丁/糖水菠萝丁
   - 规格：尺寸（如5mm/8mm/10mm）、含糖/无糖、冷冻还是常温
   - 包装：袋装/罐装/桶装，起订量
   - 是否可代加工、贴牌或按需切丁
   - 供货周期、冷链条件、价格

3. **更对口的供应商类型**
   如果佳农只卖整果，建议转向：
   - 冷冻水果丁加工厂
   - 茶饮原料供应链公司
   - 罐头/糖水水果丁厂家
   - 当地果蔬加工厂（可代切丁、速冻）

4. **茶饮店选菠萝丁要重点确认**
   - 是**冷冻丁**还是**糖水罐头丁**，两者口感、出杯方式和保存条件不同
   - 是否含防腐剂、糖度多少
   - 解冻后是否出水、发软
   - 是否有食品生产许可SC、检测报告
   - 最小起订量和冷链配送能否覆盖你门店

**结论：佳农更可能只卖整果，加工服务不确定，需要直接向当地佳农渠道核实；如果它不接定制，建议找专门的冷冻果丁或茶饮原料加工厂。**
