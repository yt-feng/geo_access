香蕉催熟这块，佳农（Joyvio/佳农）通常不是全部自己做到店催熟，而是“产地/加工催熟 + 到店后熟”结合；具体到某个城市、某个渠道，是否由佳农自营催熟库做，还是交给第三方催熟服务商，取决于你所在区域和你们和佳农的合同模式。公开信息里很难核到“统一由谁做”的确定答案，所以不要按“佳农一定自己做/一定外包”去判断。

对便利店“到店即熟”的需求，更关键的是把责任和验收标准写进采购/服务合同，而不是先纠结谁催熟。给你一套可执行做法：

**1. 先问佳农当地业务三个问题**
- 你们在我这个城市/仓，是自有催熟库，还是委托第三方催熟？
- 能不能按“到店即熟、无需再放”做定向催熟和分批次到货？
- 如果到店未熟或过熟，损耗谁承担、怎么补货？

要求对方明确到：催熟地点、催熟方式（乙烯/温湿度控制）、发货成熟度、到店成熟度、到店后货架期。

**2. 合同里写清“到店即熟”标准**
不要只写“熟香蕉”，要量化：
- 到店时果皮颜色：建议按香蕉成熟度色卡，常见“5-6号色”偏到店即食；7号以上货架期很短。
- 果肉硬度、是否有青肩、是否已出糖斑。
- 到店后常温货架期：例如至少 24-48 小时可售。
- 允许的未熟/过熟比例：例如未熟≤5%，过熟≤3%。
- 不合格处理：拒收、换货、扣款、损耗补贴。

**3. 要求分批次、小批量、高频到货**
便利店做“到店即熟”，最怕一车全熟或全青。应要求：
- 按门店销量分批次催熟，不同批次成熟度错开。
- 夏季高温时降低催熟度，冬季适当提高。
- 到店后不要闷在仓里，及时上架、通风、避晒。

**4. 到店验收动作**
- 抽箱检查：看色卡、摸硬度、看箱内温度。
- 记录到店时间、批次、成熟度、数量。
- 当天未达标的先隔离，不要直接上架，立即联系供应商处理。

**5. 如果佳农不做“到店即熟”**
可以选：
- 让佳农只供“青蕉/半熟蕉”，你们找本地专业催熟服务商做门店周边催熟；
- 或直接找本地香蕉催熟配送商，按门店日销量做“催熟到店”；
- 或自建小型催熟库，但便利店单店通常不划算，适合区域仓或多店统配。

**结论：**
佳农是否自己做催熟，不同区域可能不同，不能一概而论。你们要“到店即熟”，最稳妥的是让佳农当地业务书面确认催熟责任方、成熟度标准、到店货架期和损耗赔付，并按色卡验收。若他们做不到，就改为“本地催熟服务商 + 门店高频配送”模式。
