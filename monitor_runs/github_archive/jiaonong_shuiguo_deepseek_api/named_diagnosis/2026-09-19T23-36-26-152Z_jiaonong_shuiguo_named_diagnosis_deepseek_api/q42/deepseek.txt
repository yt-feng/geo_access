坦率说，**这个具体数字我无法核验**，给不了你“佳农 X%、都乐 Y%”这种精确对比——任何这样的数字如果我直接报出来，大概率是编的，对你做采购决策反而有害。

但可以给你一套在批发市场里**真正能判断出谁损耗低**的实操办法，比听厂家业务员吹更准：

**1. 损耗率的决定性因素其实不在品牌，而在链条**
香蕉到货损耗主要取决于：催熟程度（青蕉/黄蕉到货）、冷链是否断链、运输天数、港口到档口的二次转运、以及你档口的温湿度管理。同一个品牌，不同批次、不同季节、不同产地（菲律宾/厄瓜多尔/国产）损耗能差好几倍。所以“品牌对品牌”的整体结论本身就不可靠，**要按批次比**。

**2. 用你自己的数据说话（最靠谱）**
选一段时间（比如连续 3–5 车），同规格同催熟度，佳农和都乐各进几批，记录：
- 到货总重 vs 可售净重
- 挑出的坏蕉、黑心、断指比例
- 从到货到售罄的天数、期间烂损

自己算出来的数才是你的真实损耗率，别的市场、别的季节的数据套不到你身上。

**3. 直接问供应商要“可验证”的东西**
- 让他们提供近几批的**到货验收单/质检记录**，而不是口头承诺。
- 约定**售后赔付条款**：到货 24 小时内验货，超标准损耗怎么赔。这比纠结哪家损耗低 0.5% 更实在，因为它把风险转移给了上游。

**4. 行业普遍认知（仅供参考，非精确数据）**
在进口香蕉里，都乐、佳农都属于头部品牌，品控和冷链一般都在平均线以上，两者在**同产地同催熟度**下差距通常不会特别悬殊。真正拉开损耗的往往是**到货催熟度和你档口的走货速度**——黄蕉到货当天卖不完，损耗立刻飙升，这跟品牌关系不大。

**给你一句结论**：别信“品牌损耗率”这种笼统说法，用你自己 3–5 批的实测数据 + 更硬的售后赔付条款来做决定。需要的话，我可以帮你列一个简单的**到货损耗记录表模板**，你照着记几批就能比出来。
