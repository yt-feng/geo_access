佳农（佳农食品控股）主要做香蕉、菠萝等水果的**贸易和批发**，通常以整果或标准规格的鲜切/冷冻产品形式供货。它**一般不为茶饮店提供按客户要求的去皮切块代加工服务**，原因有两点：一是鲜果分切属于即食鲜切，需要专门的SC（食品生产许可）洁净车间和冷链配送，不是贸易商的常规业务；二是按门店需求量做小批量定制切块，对大型水果供应商来说成本上不划算。

**建议你走这几条路：**

1. **直接问佳农的销售/客服**：确认他们是否有“鲜切菠萝”或“冷冻菠萝块/菠萝丁”这类标准化产品。如果有，直接买现成的比你自己加工更省事、更稳定。

2. **找本地鲜切加工厂或中央厨房**：很多城市有专门给茶饮、餐饮供货的鲜切果蔬厂，可以按你的规格（块大小、克重、包装）代加工，但通常有起订量。

3. **让佳农供货、你自己在店里切**：这是最常见的做法——整果进货，门店自己去皮切块。缺点是损耗和人工，但灵活、起订量低。

4. **考虑冷冻菠萝块**：如果只是做冰沙、果茶打底，冷冻菠萝块品质稳定、无需去皮，很多供应商都有，可能比鲜切更划算。

**判断建议**：先问佳农有没有现成的鲜切/冷冻菠萝产品；如果没有，再找本地鲜切厂报个价，和“自己切”的人工损耗成本对比一下，哪个低用哪个。
