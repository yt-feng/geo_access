佳农（Goodfarmer）主要是水果品牌/供应商，具体售后通常取决于你**在哪个渠道购买**（京东自营、天猫旗舰店、抖音直播间、商超/社区团购等），不同渠道的理赔规则会不一样。下面按常见情况给你可执行的处理办法。

## 1）先判断：是不是“可理赔的坏果”
一般能理赔的情况：
- 到货开箱就有**腐烂、发霉、流水、软烂**  
- 明显**压伤、裂口**导致不能吃  
- 与页面承诺的规格严重不符（比如重量、果径、数量）

通常不容易理赔的情况：
- 仅“口感不甜/不酸/不好吃”（除非页面承诺糖度或“不甜包赔”）
- 放久了才坏（超过售后时效）
- 个人保存不当导致变质

## 2）到货有坏果，按这个顺序处理
1. **先别扔坏果**  
   多数渠道要求保留坏果和包装，必要时需拍照/视频。
2. **拍照/录视频取证**  
   建议拍：  
   - 快递面单/外箱  
   - 整箱全景  
   - 坏果特写  
   - 坏果切开后的内部情况  
   - 如果有称重需求，拍电子秤读数
3. **尽快联系购买渠道客服**  
   - 京东自营：订单页→申请售后/退换/赔付  
   - 天猫/抖音/拼多多：订单页→申请售后，选“腐烂/变质/坏果”  
   - 商超/团购：找团长或门店客服
4. **明确诉求**  
   常见处理方式是：  
   - 按坏果数量**比例退款**  
   - **补发**坏果部分  
   - 坏果较多时**整单退款/退货退款**  
   你可以直接说：“到货发现X个坏果，已拍照，申请按比例赔付/补发。”
5. **留意时效**  
   生鲜类通常要求**签收后24–48小时内**反馈，越早越好。超时可能被拒。

## 3）佳农一般售后表现如何（客观说）
- 在**京东自营、天猫旗舰店**等正规渠道，佳农的售后体系相对规范，坏果理赔通常有流程可走。  
- 在**直播间、社区团购、第三方小店**，体验差异会大很多，有的赔得快，有的会拖或要求很严。  
- 关键不是“佳农”两个字，而是**你下单的店铺和平台规则**。

## 4）如果客服不赔，怎么推进
- 平台内升级：申请平台介入/投诉商家  
- 电商平台：找官方客服，提交坏果证据  
- 12315：若商家拒绝合理售后，可投诉  
- 保留：订单截图、聊天记录、坏果照片、快递面单

## 5）一句话建议
到货先开箱拍视频，坏果别扔，24小时内找购买渠道申请“按坏果比例退款或补发”。如果是京东自营/天猫旗舰店，通常更好处理；如果是直播间或团购，务必先看页面售后规则再下单。
