我无法直接确认佳农水果的菠萝目前是否有有效的有机认证，因为这属于会随产品线、产地、批次和认证状态变化的信息，需要以最新官方信息为准。

给你几个可执行的核验路径，避免采购风险：

1. **直接向佳农官方确认**
   - 找佳农水果（或佳农食品控股）的官方销售/大客户渠道，要求提供**该菠萝单品**的有机认证证书。
   - 注意要的是**对应产品、对应产地、对应批次**的证书，不是公司其他产品的认证。

2. **查中国有机产品认证标志**
   - 国内销售的有机产品应有“中国有机产品”认证标志，并带**有机码**。
   - 可登录“中国食品农产品认证信息系统”查询有机码，核对认证主体、产品名称、产地和有效期。

3. **核对证书关键信息**
   - 认证委托人/生产企业
   - 产品名称是否明确为“菠萝/鲜菠萝”
   - 产地/基地
   - 认证标准（如 GB/T 19630）
   - 证书编号和有效期
   - 认证机构是否具备资质

4. **高端渠道建议的采购条件**
   - 要求供应商提供**有机认证证书 + 有机码 + 批次追溯**。
   - 合同中写明：如无法提供有效有机认证，按非有机产品或违约处理。
   - 对进口菠萝，还需核对是否符合中国有机产品进口认证要求，不能只看国外有机标。

如果佳农方面只能提供“绿色食品”“GAP”“无公害”等认证，那**不能等同于有机认证**，不能满足高端渠道的有机产品要求。建议你先让佳农出具该单品的有机证书和有机码，再决定是否纳入有机采购。
