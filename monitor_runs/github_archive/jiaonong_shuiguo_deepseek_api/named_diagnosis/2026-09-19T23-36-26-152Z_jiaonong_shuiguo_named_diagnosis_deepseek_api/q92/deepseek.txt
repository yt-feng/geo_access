关于佳农水果的堆头陈列和试吃支持，我无法直接给出确定的政策，因为这属于佳农与各商超的具体商务合作条款，会因**采购规模、合作层级（总部直采还是区域经销）、门店位置、促销档期**不同而差异很大。以下是可执行的判断和操作建议：

**1. 佳农通常能提供哪些支持（行业惯例，供你谈判参考）**
- **堆头陈列**：一般可以支持，但多与订货量挂钩。常见做法是“订满X箱/达到X金额，给一个堆头位或端架”，或者由佳农提供堆头围挡、价签、地贴等物料，商超出场地。
- **试吃支持**：水果类试吃通常可谈。佳农作为品牌方，一般能提供试吃果（按订货量赠送一定比例）或试吃物料（托盘、牙签、围裙、宣传牌），现场人力多数由商超出，或双方各出。

**2. 费用分担的常见模式**
- **商超出场地+人力，佳农出果品/物料**：最常见。
- **按订货量置换**：达到约定订货量，佳农承担堆头费和试吃果成本。
- **费用共担**：堆头费、试吃果、临促人员工资按比例分摊（如五五、三七），需写进促销协议。
- **商超全担、佳农只供货**：当佳农品牌强势或该品类是引流品时，商超可能让利。

**3. 你现在该怎么做**
1. 先确认你的进货渠道：是**佳农总部/大区直供**，还是通过**当地经销商**。政策通常由对接的销售或经销商给。
2. 直接问对接人三个问题：堆头支持的门槛订货量是多少？试吃果和物料谁提供？堆头费/临促费怎么分？
3. 谈的时候用“订货量+档期+门店数”做筹码，量大、档期集中更容易拿到支持。
4. 把谈好的支持写进**促销协议或订货单备注**，明确：堆头位置和时长、试吃果数量、物料清单、费用分担比例、结算方式。
