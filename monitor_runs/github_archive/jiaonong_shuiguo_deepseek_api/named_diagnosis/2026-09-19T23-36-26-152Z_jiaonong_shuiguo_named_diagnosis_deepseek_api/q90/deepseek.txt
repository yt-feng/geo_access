我无法直接核验佳农当前是否有“冷冻菠萝丁”这款在售原料，也不能凭空给出规格。建议你用下面方式快速确认，避免拿到错误货源：

**1. 先确认佳农是否有冷冻菠萝丁**
- 佳农更常见的是**鲜菠萝、菠萝罐头、速冻水果/果浆**等品类，但是否有专门给茶饮店的**冷冻菠萝丁**，要以官方渠道为准。
- 直接找：佳农官网/官方公众号/官方客服，问“是否有冷冻菠萝丁，适合茶饮店做原料，能否提供样品和检测报告”。

**2. 问规格时直接要这些信息**
向供应商索要：
- 包装规格：如 **1kg/袋、2kg/袋、5kg/袋、10kg/箱** 等
- 果丁大小：如 **5×5mm、8×8mm、10×10mm** 或粗丁/细丁
- 是否速冻、是否加糖、是否糖水浸泡
- 固形物含量、解冻后出水情况
- 保质期、储存条件：**-18℃冷冻保存**
- 是否含防腐剂、香精、色素
- 产地、批次、检测报告、SC/食品生产资质

**3. 茶饮店选菠萝丁重点看**
- **解冻后是否发软、出水多**：会影响出品口感和杯量
- **酸甜度是否稳定**：不同批次差异大会影响配方
- **丁型是否均匀**：影响吸管吸入、出杯美观
- **是否可直接入杯**：有些冷冻丁适合打冰沙，有些适合做果茶小料

**4. 如果佳农没有，替代方向**
可以同步问：
- 其他冷冻水果供应商
- 菠萝罐头丁供应商
- 餐饮供应链平台/当地冷冻食品批发商
关键词用：**冷冻菠萝丁、速冻菠萝丁、菠萝果丁、茶饮小料菠萝丁**

**最稳妥的做法**：先让佳农产品/销售确认“有没有冷冻菠萝丁”和“最小起订量、样品政策”，拿到实物样品后再测试解冻出水、口感、酸甜稳定性和出杯效果。
