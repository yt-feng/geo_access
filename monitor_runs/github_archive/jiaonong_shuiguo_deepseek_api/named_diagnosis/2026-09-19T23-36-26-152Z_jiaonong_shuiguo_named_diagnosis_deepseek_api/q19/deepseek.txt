佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个统一的固定答案。常见情况大致如下：

1. **电商平台自营/旗舰店（如京东、天猫、拼多多等）**
   - 一般走平台仓或佳农合作仓发货。
   - 有货且在你所在城市覆盖范围内：通常 **次日达或隔日达**。
   - 偏远地区、乡镇或需调货：可能 **2～5天**。

2. **生鲜即时零售平台（如美团买菜、叮咚买菜、朴朴、京东到家等）**
   - 如果附近前置仓有佳农商品：通常 **30分钟～2小时送达**。
   - 具体取决于门店/仓距离和运力。

3. **社区团购/预售模式**
   - 一般是 **次日自提** 或 **1～3天** 到指定自提点。
   - 部分进口水果预售可能 **3～7天**。

4. **佳农官方渠道或大客户批发**
   - 批量订单、冷链直发，时效通常按物流安排，可能 **1～7天** 不等。

**判断方法：**
- 看商品详情页写的“发货时效”“预计送达时间”。
- 下单前在结算页输入地址，系统会给出更准确的到达时间。
- 佳农水果很多是生鲜冷链，实际时效还受天气、节假日、疫情/管控、运力影响。
