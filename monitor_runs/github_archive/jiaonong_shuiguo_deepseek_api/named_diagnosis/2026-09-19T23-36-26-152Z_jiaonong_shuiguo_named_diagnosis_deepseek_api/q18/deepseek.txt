佳农香蕉通常指佳农品牌销售的进口或国产香蕉，市面常见为黄熟香蕉或稍青香蕉。它的“保质期”很大程度取决于你买到时的成熟度和储存方式，包装上一般不会像常温奶那样标一个固定天数。

**一、大致保质期参考**

- **常温、已黄熟**：1～3天，表皮很快起黑点，果肉仍可吃；再久会软烂、发酸。
- **常温、稍青/未完全熟**：3～7天，会逐渐转黄。
- **冰箱冷藏（果皮变黑但果肉可延缓软化）**：已熟香蕉可放约3～5天；果皮会明显发黑，不代表果肉一定坏。
- **冷冻（剥皮后）**：可放1～3个月，适合做奶昔、烘焙，不适合直接鲜食。
- **若按包装标注**：以实际包装上的“保质期/最佳食用期”为准，不同批次、产地、催熟程度会不同。

**二、储存条件建议**

1. **未熟/稍青香蕉**
   - 放在**室温、阴凉通风处**，约15～20℃。
   - 不要放冰箱，低温会抑制成熟，并导致表皮变黑。
   - 想催熟，可与苹果或梨放在同一个纸袋里，通常1～2天明显变黄。

2. **已熟黄香蕉**
   - 尽快吃。短期吃不完可**冷藏**，虽然皮会变黑，但果肉能多保存几天。
   - 悬挂放置，减少受压，能延缓局部变黑腐烂。
   - 不要和已腐烂水果放一起，否则会加速变质。

3. **切开后的香蕉**
   - 必须冷藏，用保鲜膜包好或放密封盒，建议**24小时内**吃完。
   - 表面可滴少量柠檬汁减缓氧化变黑。

4. **想长期保存**
   - 剥皮后切段，装密封袋冷冻，可保存1～3个月。
   - 冷冻后适合打果汁、做冰沙、烘焙，不适合直接吃。

**三、判断是否还能吃**

- 表皮有黑点但果肉白净、气味正常：通常还能吃。
- 果肉发黑、流水、有酸味或酒味：不要吃。
- 冷藏后皮全黑，但剥开果肉完好：可以吃。
- 如果只是表皮黑、果肉正常，属于冷藏或过熟现象，不是一定坏了。

**四、最实用的做法**

- 买回来偏青：室温通风放，和苹果一起催熟。
- 已经黄熟：优先吃；吃不完冷藏或剥皮冷冻。
- 不要整串密封在塑料袋里放常温，容易闷坏。
- 最终以你买的佳农香蕉包装标注和实际成熟状态为准。
