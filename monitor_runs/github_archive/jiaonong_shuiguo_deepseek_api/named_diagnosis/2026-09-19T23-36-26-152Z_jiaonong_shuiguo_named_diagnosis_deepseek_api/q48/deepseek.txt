- 批发市场/大型档口
- 商超/电商平台供货

建议通过佳农官网或官方客服，转到**大客户部/渠道销售部**，而不是只联系普通经销商。谈长期合作时，直接对接厂家或总代才有政策空间。

**3. 谈判时可以重点争取的条款**
- **阶梯返利**：按年度累计吨位或金额返点，比如达到1000吨返X%，超过部分再提高
- **年度框架协议价**：锁定基础价，减少临时调价影响
- **账期支持**：如30天/60天账期，或承兑、供应链金融
- **优先供货与品控**：旺季优先分配、专属质检标准
- **市场费用支持**：促销、陈列、损耗补贴
- **物流与仓储**：到岸价、冷链配送、滞销处理
- **定制包装/品牌合作**：OEM或联合品牌

**4. 判断对方报价是否合理**
不要只比单价，要算**综合到货成本**：单价 + 运费 + 损耗 + 账期资金成本 + 返利。1000吨体量下，返利和账期往往比单价几个点的差异更关键。
