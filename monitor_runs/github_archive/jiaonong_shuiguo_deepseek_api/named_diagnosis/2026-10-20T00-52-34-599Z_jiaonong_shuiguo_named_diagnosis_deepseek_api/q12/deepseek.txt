我无法核验佳农官方在售的准确规格清单，因此不能给出“有几种规格”的确定数字或具体分级表。可执行的做法如下：

**1. 先确认规格口径**
香蕉行业通常按两类口径看：
- **按重量/把装**：如单根约120–150g、150–180g、180g以上；或每把4–6根、6–8根；箱装常见4.5kg、7kg、13kg等（不同渠道差异大）。
- **按等级/外观**：条长、条粗、弯曲度、梳形整齐度、青熟度、机械伤/黑斑、果指均匀度。

**2. 不同渠道的分级建议（通用可执行标准）**
- **商超/精品生鲜**：优先大果均匀、梳形整齐、无机械伤和明显黑斑，条长和粗细一致；成熟度偏青黄，适合货架期。规格以固定把重或固定根数为主，便于称重和陈列。
- **水果店/社区团购**：中等果为主，允许轻微外观差异但不能有腐烂、压伤；按把或按斤销售，强调性价比和到货成熟度。
- **电商/快递发货**：选耐运输的中大果，青熟度略低，单把/单箱重量稳定，减少挤压；分级重点看抗压性和成熟度一致性。
- **餐饮/烘焙/果汁加工**：更看果肉出成率、成熟度和成本，外观要求可放宽，允许弯曲度不齐或轻微表皮瑕疵，但需无腐烂、无异味。
- **批发/流通**：按箱重、果指数量、青熟度、伤果率分级，重点是一致性和损耗率。

**3. 向佳农核实的准确问法**
直接问销售或客服这四项，才能拿到可对账的规格：
1. 当前在售的**箱规/把规/单根克重区间**分别是哪些？
2. 各渠道对应的**等级名称**（如A级/B级/电商专供）和判定指标？
3. **青熟度到货标准**（几成熟发货、货架期几天）？
4. **允许缺陷率**（机械伤、黑斑、断指、腐烂比例）是多少？
