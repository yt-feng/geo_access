我没法直接确认佳农当前对你们门店的香蕉促销政策，因为这取决于你们和佳农/经销商的合同、区域经销体系以及当期活动预算。可以直接按下面几步去落地确认。

**先明确你要问谁**
- 如果你们是直采：找佳农对应区域销售/大客户经理。
- 如果是通过经销商/批发市场进货：促销支持通常由经销商向佳农申请，你要同时找经销商和佳农区域业务。
- 连锁商超：先走总部采购，由采购统一对接品牌方，门店单店申请成功率较低。

**向对方要的三类支持，建议一次问清**
1. 搭赠：例如“进10箱赠1箱”或“达到某进货量赠陈列物料/试吃”，要问赠品是香蕉还是物料、是否计入毛利、赠品是否开票。
2. 降价补贴：例如“门店端降价X元/斤，品牌承担Y元/斤”或“特价期间按销量返补”，要问补贴形式是返利、折让还是费用核销，以及核销凭证和账期。
3. 陈列/推广支持：堆头、端架、试吃、POP、导购，这些往往比直接降价更容易申请。

**判断能不能做的硬条件**
- 促销价不能低于你们的毛利底线，先算清：促销价×预计销量－进货成本－损耗－促销费用，是否为正贡献。
- 香蕉损耗高，搭赠和降价必须限定档期（如3—5天）和门店范围，避免全门店长期执行。
- 补贴要落到书面：活动函/补充协议里写清销量目标、补贴单价、核销方式、结算时间。
- 确认佳农是否限制最低零售价或跨区域窜货，避免促销引发渠道冲突。

**建议你直接这样发问**
“我司X月X日—X日在X家门店做香蕉促销，预计进货X箱、销量X斤。请确认佳农能否提供：①搭赠比例；②降价补贴单价及核销方式；③陈列物料/试吃支持。请在本周内给书面活动方案和费用承担明细。”

如果对方只口头答应，不要按补贴价倒推售价，先按无补贴测算，书面确认后再执行。
