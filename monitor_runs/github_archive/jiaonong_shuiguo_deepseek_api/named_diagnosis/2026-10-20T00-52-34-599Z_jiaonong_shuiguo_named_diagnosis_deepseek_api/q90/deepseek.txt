我不能凭可靠来源确认佳农（Goodfarmer）是否供应“冷冻菠萝丁”，也不能确认具体规格。为避免给你错误采购信息，建议你按下面方式快速核验：

**1. 直接问佳农官方渠道**
- 佳农官网/官方公众号找“冷冻果蔬”或“餐饮供应链”业务入口；
- 拨打官方客服，问三件事：
  1. 是否有**速冻菠萝丁/冷冻菠萝丁**（IQF）；
  2. 规格：**单丁尺寸（如10×10mm、15×15mm等）、包装规格（如1kg/袋、10kg/箱）、是否加糖/无添加**；
  3. 起订量、供货区域、是否支持样品。

**2. 让供应商提供可核验资料**
- 产品规格书（含丁尺寸、包装、固形物、糖度）；
- 检验报告/出厂检测；
- 样品实拍和到货温度记录。

**3. 茶饮店采购判断标准**
- 优先选**IQF速冻、无糖或轻糖、解冻后不出水**的菠萝丁；
- 到样后测：解冻失水率、酸甜度、纤维感、是否发软；
- 确认**冷链到店温度≤-18℃**和最小起订量。
