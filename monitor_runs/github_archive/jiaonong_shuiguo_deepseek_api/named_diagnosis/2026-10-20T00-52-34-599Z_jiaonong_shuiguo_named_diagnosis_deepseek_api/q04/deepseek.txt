佳农（佳农食品控股/Goodfarmer）作为大型水果进口与分销企业，通常会针对不同渠道客户设计差异化商务政策，但具体账期方案属于合同条款，公开渠道一般不会披露标准细节。所以**无法确认它是否有统一的“长期合作账期方案”**，更不应给出具体天数。

可判断的是：

1. **大概率存在差异化授信/账期安排**
   佳农客户覆盖商超、电商、批发市场、餐饮/加工等，长期稳定、采购量大的客户通常更可能谈到账期或阶段性授信，但会与采购规模、合作年限、回款记录、担保方式挂钩。

2. **账期不是公开标准政策，而是逐户审批**
   水果行业资金周转快、损耗和价格波动大，供应商对账期普遍谨慎。长期合作客户即使有账期，也常见“首单现款/预付、后续按评级给短期账期、超额部分现结”这类组合，而非一刀切。

3. **最有效的核实方式**
   - 直接联系佳农官方销售/大客户渠道，说明采购品类、月采购量、渠道类型、结算习惯，询问是否可做授信申请；
   - 要求对方提供书面报价与结算条款，明确账期天数、起算点、额度上限、逾期责任、是否需保证金/担保；
   - 不要仅凭销售人员口头承诺，账期必须写入合同或授信协议。

**建议**：如果你是想与佳农谈长期合作账期，准备“月采购量、历史回款记录、可提供的担保或保证金、结算周期诉求”四项材料去谈，成功率更高；同时保留现款现货作为备选，因为水果供应商对账期审批通常较严。
