佳农水果的香蕉执行的是**企业标准（企标）**，不是国标。佳农作为品牌商，通常会制定自己的企业标准（如Q/开头的标准号）来规范产品分级、外观、成熟度、农残等指标，这类标准需在“企业标准信息公共服务平台”备案，属于企标范畴；国标则是GB开头的通用标准，适用于行业底线要求。

至于**比普通香蕉贵多少**，没有固定统一数字，取决于渠道、品种、规格和促销：
- 常见情况：佳农香蕉（多为进口或精品国产）比同渠道普通散装香蕉贵约 **20%–50%**；
- 精品商超/电商礼盒装可能贵 **50%以上**；
- 促销时价差可能缩小到 **10%–20%**。

建议直接对比你所在渠道的**每斤单价**：用佳农单价除以普通香蕉单价减1，即得实际溢价比例。若要确认具体标准号，可看包装箱或标签上的“执行标准”一栏。
