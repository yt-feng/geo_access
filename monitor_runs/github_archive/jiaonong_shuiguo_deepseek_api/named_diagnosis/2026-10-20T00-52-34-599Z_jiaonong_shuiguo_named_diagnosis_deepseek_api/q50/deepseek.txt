这个问题没法给一个可靠的“谁更强”结论——两家在华东商超渠道的强弱高度依赖具体品类、具体商超系统和具体年份，而我无法核验近期的渠道数据，硬比就是编。

能给你的可判断建议：

**1. 先明确你换供应商的真实痛点**
是价格、供货稳定性、品控、账期、还是某单品缺货？不同痛点对应的赢家不同。比如佳农在香蕉、菠萝等自有品牌单品上品牌力和终端陈列资源较强；鑫荣懋品类更宽、供应链体量大、对大型商超系统的覆盖和定制能力通常被认为更全面。但这是行业一般印象，不等于你所在区域和系统的实际情况。

**2. 用可核验的方式自己比，别听结论**
- 直接找你目标商超系统（如大润发、盒马、永辉、华润万家等）的采购或门店水果课长，问这两家在该系统的**实际铺货单品数、月度动销排名、缺货率、促销配合度**——这是最硬的一手信息。
- 让两家分别提供：华东区近12个月在你同类渠道的**供货门店数、SKU清单、冷链覆盖城市、账期和退换货条款**。
- 做小范围试单：选2–3个高周转单品，各给一家做4–6周，对比到货合格率、损耗率和补货响应速度。

**3. 谈判策略**
不要二选一。两家体量都大，完全可以按品类拆分供货（比如香蕉/菠萝给一家，浆果/进口果给另一家），既保留议价空间，又降低单点断供风险。

**4. 注意**
如果你要的是“华东某几个商超系统里谁的排面更大”这种具体结论，需要你自己调取或购买渠道数据（如尼尔森/凯度零售监测、或直接问商超采购），我没有可核验来源，不替你下判断。

一句话：**按品类和系统拆开验证，用试单数据说话，别按公司整体名气选供应商。**
