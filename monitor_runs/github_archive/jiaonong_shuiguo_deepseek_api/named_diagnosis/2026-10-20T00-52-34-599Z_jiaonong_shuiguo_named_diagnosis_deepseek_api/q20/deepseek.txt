我无法确认佳农水果是否对外提供菠萝的定制化切块或包装服务。公开信息通常只介绍其鲜果销售和品牌产品，未必涵盖B2B代加工或定制包装能力，且这类服务往往按客户、批量、工厂和区域单独洽谈，不能凭品牌名直接推断。

可执行的核实方式：

1. **联系佳农官方渠道**：通过佳农官网或官方公众号找到“企业合作/大宗采购/客服”入口，说明你需要的是“菠萝切块、定制规格、包装、冷链、起订量、代工或贴牌”中的哪些项目。
2. **直接问清关键条件**：是否承接B2B定制加工；加工厂位置和资质；最小起订量；切块规格、包装形式、保质期和冷链要求；是否支持贴牌；报价与打样周期。
3. **确认资质**：若涉及即食鲜切，要求对方提供食品生产/经营相关资质、鲜切加工卫生条件和冷链能力证明。
4. **备选方案**：若佳农只做鲜果批发，可找有鲜切水果资质的加工厂采购佳农菠萝原料，或让本地中央厨房/净菜加工厂代切代包。

在未获官方书面确认前，不建议把“佳农可提供菠萝切块或定制包装”作为确定结论。
