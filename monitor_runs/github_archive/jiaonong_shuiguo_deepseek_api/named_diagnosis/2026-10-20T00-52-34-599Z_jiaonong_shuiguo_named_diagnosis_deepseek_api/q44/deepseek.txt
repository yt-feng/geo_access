关于佳农水果香蕉的农残超标历史，我无法核验，不能给出“有”或“没有”的确定结论。公开可检索的监管抽检通报中，我也没有可靠记录可引用，因此不宜下判断。采购合规不能靠历史口碑，要靠可验证的证明文件。

给你的可执行做法：

1. **要求供应商提供当批次合规证明**
   - 该批次香蕉的**出厂检验报告**，检测项目须覆盖 GB 2763 中香蕉对应的农药残留限量。
   - 若为进口香蕉，索要**入境货物检验检疫证明**及海关相关检测记录。
   - 若为国产，索要产地农业农村部门或第三方检测机构出具的**农残检测报告**。

2. **核对报告有效性**
   - 报告日期与批次对应，不能拿旧报告顶批次。
   - 检测机构具备 CMA/CNAS 资质。
   - 检测项目至少覆盖当地市场监管部门抽检常检项：吡虫啉、噻虫嗪、嘧菌酯、苯醚甲环唑、丙环唑、百菌清等，具体以 GB 2763 香蕉限量为准。
   - 报告编号可在检测机构官网或公示平台核验。

3. **合同里写死责任**
   - 约定每批次随货提供检测报告，报告不合格或缺失可拒收。
   - 约定因农残超标导致超市抽检不合格、下架、罚款的，由供应商承担退货、赔偿及违约责任。
   - 保留供应商对报告真实性的书面承诺。

4. **自己留一手**
   - 首次合作或高风险批次，自行送第三方做农残全项或重点项检测。
   - 建立批次留样，至少保存到该批次售罄后合理期限。

5. **查公开抽检信息**
   - 到国家市场监管总局“食品安全抽检监测”栏目、各省市市场监管局官网，按“香蕉”“佳农”检索历史通报。这是你能自己核验的路径，比问我更可靠。

结论：不要依赖“有没有历史超标”的传闻做采购决策，要求**批次级检测报告+合同质量责任+必要时自检**，这三样齐了，超市抽检合规才有底。
