佳农水果的配送覆盖范围以“下单渠道”为准，不同渠道差异很大，建议按下面方式判断：

1. **先确认你用的是哪个渠道**
   - 佳农官方小程序/天猫/京东/抖音旗舰店：一般走平台仓或第三方冷链，覆盖城市和时效以下单页提示为准。
   - 本地商超/水果店/社区团购：通常只覆盖门店周边，县城能不能送要看该门店是否开通配送。
   - 批发/大宗采购：一般走区域经销商或冷链干线，需联系当地经销确认。

2. **县城门店能否送到**
   - 不能仅凭“佳农”品牌判断。打开你常用渠道，把收货地址填成县城门店地址，系统能显示可配送商品和预计送达时间，才算能送；若提示“不在配送范围”，就是不能送。
   - 也可直接问县城门店：是否支持佳农水果配送、起送金额、配送半径。

3. **冷链物流收费**
   - 零售端通常不是单独“冷链费”，而是：满额包邮/不满额收基础运费，或按重量/件数计费；部分平台对冷链商品加收冷链附加费。
   - 批发/大宗冷链一般按重量、体积、温区、距离和是否整车计价，需向当地经销商或佳农销售索取报价。
   - 最准确的方式：在结算页看“运费/冷链费”明细，或让门店/经销商书面报价。

**可执行建议**：先在小程序或电商平台输入县城门店地址试下单；同时电话问县城门店是否可配送及费用。两处任一显示可送并给出运费，就以那个为准。
