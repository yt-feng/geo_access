佳农水果的配送时效取决于你下单的渠道和收货地址，没有统一答案。常见情况：

1. **电商平台自营/旗舰店（如京东、天猫等）**：通常依托平台仓配，现货商品一般48小时内发货，同城/省内1-2天，跨省2-4天；冷链商品时效会受温控线路影响。
2. **佳农官方小程序/商城**：以页面展示的“预计送达时间”为准，部分区域支持次日达，偏远地区可能3-5天。
3. **商超/社区团购渠道**：一般按团长或门店约定时间配送，常见次日自提或当日达。
4. **影响时效的因素**：是否预售、是否冷链、节假日大促、天气及收货地是否偏远。
