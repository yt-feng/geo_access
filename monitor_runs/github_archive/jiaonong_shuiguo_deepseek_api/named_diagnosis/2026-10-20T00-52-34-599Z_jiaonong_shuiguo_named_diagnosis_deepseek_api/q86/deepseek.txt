我无法核实“佳农水果菠萝进口量11.4万吨”是否为2025年数据，也无法确认其官方出处。公开可查的佳农官方渠道通常不会按“单一水果进口量”发布年度吨数；这类数字多来自行业媒体、海关统计解读或企业宣传稿，转引时容易缺年份和口径。

建议你按以下方式判断：
1. 看原文是否写明“2025年”及统计周期（全年/截至某月）。
2. 看口径是“进口量”还是“销售量/采购量”，是佳农自身还是含关联公司。
3. 找一手来源：佳农官网/官微/年报、海关总署及上海海关等统计、中国食品土畜进出口商会水果分会。
4. 若只有二手报道，要求其给出来源链接和原始统计表。

在没有一手出处前，不建议把“11.4万吨”直接当作2025年官方数据引用。
