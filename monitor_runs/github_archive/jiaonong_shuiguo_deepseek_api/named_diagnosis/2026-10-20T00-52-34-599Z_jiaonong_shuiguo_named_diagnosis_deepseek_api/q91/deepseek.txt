关于佳农水果的客服时间和发货安排，我无法核验其官方最新政策，不能给出确定答复。以下是可执行建议：

**客服是否7×24小时**
- 不一定。生鲜品牌通常客服分“在线客服”（可能延时到较晚）和“电话客服”（多为工作时间），7×24小时并非普遍标配。
- 建议你在下单平台（天猫/京东/抖音/微信小程序等）的商品页或店铺首页查看“客服服务时间”，或直接发消息测试是否有人工回复；电话客服以官方页面公示为准。

**晚上下单第二天能否发货**
- 取决于平台、仓库截单时间和商品类型（预售/现货/冷链）。常见情况是：当晚订单次日处理，但是否“次日发出”要看截单时间，且生鲜可能受产地直发、冷链排期影响。
- 下单前在商品页确认“发货时效/预计发货时间”，或问客服“现在下单，最晚什么时候发出”；下单后以订单页显示的“预计发货时间”为准。

**快速判断方法**
1. 看店铺公告和商品详情页的“发货时间/客服时间”。
2. 直接问客服两个问题：①人工客服几点到几点；②今晚X点下单，明天是否发出、用什么快递。
3. 保留聊天记录，若页面承诺“次日发”但未履行，可据此申请平台售后。
