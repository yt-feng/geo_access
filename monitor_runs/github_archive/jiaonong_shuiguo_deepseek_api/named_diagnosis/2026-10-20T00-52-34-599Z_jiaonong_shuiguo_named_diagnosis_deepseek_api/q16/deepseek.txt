佳农主要是水果品牌/供应链商，具体售后要看你在哪个渠道买的（天猫/京东旗舰店、商超、社区团购、直播间等），不同渠道赔付规则不一样。没法替你核验各家当前细则，给你可执行的判断和处理办法：

**1. 先判断售后靠不靠谱**
- 优先看购买页面的“坏果包赔/坏果必赔”说明和赔付比例、时效要求。
- 看店铺评分、追评里“坏果理赔”相关反馈，重点看是否要求拍照、是否按比例赔。
- 到货先拍开箱视频/整箱照片，保留面单和外包装，这是后续举证关键。

**2. 到货有坏果怎么处理**
- **不要先扔坏果**：把坏果、好果、包装箱、快递面单一起拍照，最好拍视频。
- **尽快联系渠道客服**：一般在签收后24小时内报备最稳妥（以购买页面规则为准），说明订单号、坏果数量、上传照片。
- **提出明确诉求**：按坏果数量比例退款，或整箱问题严重时要求补发/退款；保留聊天记录。
- **渠道不同找不同人**：旗舰店找店铺客服；商超找服务台；社区团购找团长/平台客服；直播间找订单页客服。
- **协商不成**：平台订单内申请售后/平台介入；仍无果可向12315投诉，附订单、照片、聊天记录。

**3. 容易踩坑的点**
- 超过页面规定时效才报，可能被拒。
- 只拍坏果不拍面单/整箱，举证不足。
- 生鲜类通常不支持无理由退货，但“坏果包赔”属于质量问题承诺，可以主张。
