这个需要和佳农当地经销商或区域KA负责人逐项确认，不能直接替厂家承诺。建议你按下面这份清单去谈，谈完就能判断能不能做、费用怎么分。

**一、先确认佳农能不能提供的支持**
1. 堆头陈列支持
- 是否提供堆头围挡、价签、跳跳卡、地贴、展示道具；
- 是否给陈列费、堆头补贴或返利；
- 是否有最低进货量/排面/陈列天数要求；
- 是否要求主推单品（如香蕉、菠萝、火龙果等）和陈列标准拍照验收。

2. 试吃支持
- 是否提供试吃物料：试吃台、一次性手套/牙签/小杯、围裙、宣传单；
- 是否提供试吃果品损耗补贴或免费试吃样品；
- 是否派促销员/导购到场，到场时长和时段；
- 是否需要商超承担试吃人员健康证、场地、垃圾清运等。

**二、费用分担的常见谈法**
- 厂家/经销商承担：陈列道具、试吃物料、试吃样品、导购人工；
- 商超承担：堆头位置、场地水电、现场管理、垃圾清运；
- 共同承担：试吃果品损耗可按“厂家出样品+门店出损耗补贴”或按销售额比例分担；
- 若厂家不给现金陈列费，可谈“进货返利、搭赠、账期支持、促销后库存回收”等替代。

**三、你方谈判前要准备的数字**
- 活动档期、门店数、堆头位置和面积；
- 预计进货量、主推SKU、促销价；
- 试吃场次、每场时长、预计试吃份数；
- 你方能承担的物料/人工/损耗上限；
- 要求对方书面确认：支持内容、费用金额、验收标准、结算方式。

**四、建议的落地话术**
“我们计划在X月X日—X日做佳农水果堆头+试吃，门店X家，主推X单品。请确认：1）堆头道具和陈列费支持；2）试吃物料、样品和导购支持；3）费用分担比例和结算方式。请在本周内给书面方案，我们按验收照片和销售数据结算。”

**结论**：佳农是否支持、费用怎么分，取决于当地经销商政策和你的进货规模。不要只听口头承诺，要求对方把“陈列标准、试吃场次、费用金额、分担比例、验收和结算”写进促销协议再执行。
