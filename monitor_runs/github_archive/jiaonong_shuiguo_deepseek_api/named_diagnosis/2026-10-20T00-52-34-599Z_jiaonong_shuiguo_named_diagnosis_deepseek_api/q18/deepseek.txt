佳农香蕉没有统一的“保质期”，实际可放多久取决于成熟度、温度和是否已剥皮。可按下面判断和操作：

**储存条件**
- **未熟/偏青香蕉**：放在室温阴凉通风处，避免阳光直射，不要先放冰箱。可和苹果一起装纸袋催熟。
- **已熟香蕉**：室温尽快吃；想延缓变黑可放冰箱冷藏，表皮会变黑但果肉通常还能保持几天，吃前再剥皮。
- **已剥皮或切开**：密封冷藏，建议 **24小时内** 吃完；冷冻可延长到约1个月，但解冻后适合做奶昔/烘焙。
- **不要**：整串密封在塑料袋里闷着、放暖气旁或暴晒，容易捂坏/催熟过快。

**大致保质期（室温、常规成熟度）**
- 偏青硬香蕉：约 **3–7天** 后逐渐成熟；
- 刚熟黄香蕉：约 **2–4天** 口感较好；
- 已出现褐斑的熟香蕉：建议 **1–2天内** 吃完，适合做香蕉泥/烘焙。

**判断变质的信号**
果肉发酸、流汁、明显软烂出水、霉点长毛、有酒味或腐败味——不要吃。仅表皮黑斑但果肉正常，通常仍可食用。

以上是通用储存建议；具体包装上的日期以佳农产品标签为准，若标签有“冷藏/常温”说明，优先按标签执行。
