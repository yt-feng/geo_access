- **第三方检测报告**（CMA/CNAS 资质），报告编号可在机构官网或认监委平台核验，检测日期对应本批次；
- **产地证明/溯源信息**：果园/包装厂编号、采收日期、批次号，能与检测报告对应；
- 若为进口香蕉，索要**入境货物检验检疫证明**及海关放行信息；

**3. 合同与抽检兜底条款**

- 约定**超标违约责任**：退货、检测费、下架损失、违约金；
