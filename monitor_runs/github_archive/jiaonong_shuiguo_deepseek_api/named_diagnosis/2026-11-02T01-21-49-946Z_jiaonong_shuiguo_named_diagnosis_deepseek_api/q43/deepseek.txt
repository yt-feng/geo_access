我不能替你确认佳农是否提供锁价合同，这需要直接向佳农官方核验。但可以给你一套可执行的判断和谈判路径。

**先核实三件事**
1. 你每月10吨、全年约120吨，属于中等偏上采购量，有谈判空间，但要看是鲜果还是冷冻/罐头原料。鲜菠萝受季节和产地影响大，锁价难度高；冷冻果肉/果浆更容易做季度或年度锁价。
2. 直接联系佳农官方销售，不要只问经销商。明确问：是否支持年度/季度锁价合同、锁价对应的是鲜果还是加工品、锁价是否含运费和损耗、超量/减量如何调整。
3. 要求对方书面给出锁价方案，不接受口头承诺。

**谈判时可用的条件**
- 承诺年度总量和月度最低提货量，换取固定价格或价格上限。
- 接受“保底量+浮动量”结构：80%锁价，20%随行就市。
- 锁价合同里写明质量标准、交货周期、逾期违约责任、价格调整触发条件。
- 如果佳农不做锁价，问是否有“价格上限+下跌跟调”条款，或改用季度定价。

**风险控制建议**
- 不要只依赖一家供应商，同步接触2到3家备用供应商。
- 锁价合同要设价格调整机制，避免单边锁死导致对方违约或降质。
- 鲜果锁价通常很难长期执行，建议优先考虑冷冻/果浆类原料做锁价，鲜果做短期框架价。

**结论**
佳农能否锁价，必须由佳农官方书面确认。你可以按“先问官方、再谈保底量换锁价、最后用备用供应商兜底”的路径推进。如果对方只愿意短期定价，建议把锁价目标调整为季度框架价加价格上限，而不是追求全年固定价。
