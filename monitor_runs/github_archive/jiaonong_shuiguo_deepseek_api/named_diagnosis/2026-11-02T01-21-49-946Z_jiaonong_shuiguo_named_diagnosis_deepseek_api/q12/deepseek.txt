佳农水果的香蕉规格会随产品线、包装形式和销售渠道变化，公开信息通常按“把装/袋装/箱装”和“单根果指长度/重量/梳数”来分，但具体SKU与分级阈值属于企业渠道政策，我无法核验其当前准确清单，不能给出确定规格表。下面给可执行判断框架：

1. **先按渠道定分级维度**
   - 商超/精品店：重点看果指长度、粗细均匀度、梳形完整度、外观瑕疵率、成熟度（色卡），多用于把装或精装。
   - 水果店/社区团购：看整箱净重、梳数/把数、单果区间、到货成熟度，强调周转和损耗。
   - 电商/到家：看单根重量或长度区间、独立包装防压、催熟后货架期，常用小规格把装或单根装。
   - 餐饮/烘焙/果汁加工：看单果重量下限、可食率、成熟度一致性、瑕疵容忍度，规格可放宽但稳定性要求高。
   - 批发/流通：看箱重、梳数、果指长度区间、青熟度、机械伤和冷链到货状态。

2. **通用分级建议**
   - 一级/精品：果指长度和粗细均匀，梳形整齐，无明显机械伤、病斑、裂口，成熟度一致，适合礼盒/精品商超。
   - 二级/标准：允许轻微外观瑕疵但不影响食用，长度/重量区间略宽，适合常规商超和水果店。
   - 三级/流通：允许一定外观瑕疵和大小差异，重点控制腐烂、压伤和成熟度，适合批发、加工或促销渠道。
   - 加工级：以外观容忍度高、成熟度可控、成本优先，适合餐饮和果汁。

3. **必须向供应商确认的字段**
   - 单根果指长度区间（cm）或单根重量区间（g）
   - 每把/每梳根数、每箱净重和箱规
   - 成熟度色卡等级及到货催熟状态
   - 瑕疵率上限（机械伤、病斑、裂口、脱把）
   - 冷链温度、到货货架期和售后扣损规则

**结论**：不要直接问“有几种规格”，而应让佳农按你的渠道提供当前SKU表、分级标准和到货验收指标；以上框架可用于比对和谈判，但具体规格数量与阈值需以供应商最新报价单/合同为准。
