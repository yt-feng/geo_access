我无法核验佳农当前对茶饮店的菠萝丁加工/定制服务政策，也不能替你确认它是否“只卖整果”。这类供应政策会随渠道、区域经销商和客户规模变化，最稳妥的方式是直接向佳农官方渠道确认。

你可以这样判断和推进：

1. **先找对渠道再问**
   - 优先联系佳农官方客服/官网/公众号，或你所在区域的佳农经销商。
   - 直接问：“茶饮店用菠萝丁，规格X mm、糖度/酸度要求、冷冻/冷藏/常温、包装规格、起订量、是否可代加工/OEM、供货周期、报价。”

2. **区分三种可能**
   - **只卖整果**：你需要自己切丁或找第三方加工。
   - **卖鲜切/冷冻果丁标准品**：不一定按你要求定制，但可直接用。
   - **可代加工/OEM**：通常有起订量、规格和账期要求，需签合同确认。

3. **问清关键商务条件**
   - 最小起订量、样品费、打样周期
   - 菠萝品种/产地、糖度范围、丁大小公差
   - 冷冻还是冷藏、解冻后出水率
   - 是否含糖水/添加剂、保质期、微生物指标
   - 到货价、运费、账期、退换货

4. **备选方案**
   - 若佳农不做定制，可找本地鲜切水果加工厂或冷冻果丁供应商打样；茶饮店常用冷冻菠萝丁，稳定性通常比鲜切更好。
   - 先小批量试样，做3—5杯盲测，看出水、酸甜稳定性和出杯效率再定。

结论：**不要先假设佳农只卖整果；直接向官方/区域经销商确认“茶饮用菠萝丁标准品或代加工”两种路径，并要求样品和规格书。**
