**可执行的建议：**

- **直接向佳农渠道索取**：联系佳农官方销售或区域代理商，要求提供该批次的《收购/出货分级说明》和报价单。批发商通常能拿到“规格书+当日报价”，这是唯一可靠依据。
- **看实物验级**：香蕉分级一般看这几项——单根重量区间、条数/把、果指长度与粗细均匀度、青熟度（色卡）、梳型完整度、机械伤/病斑比例、果轴长度。让供应商按这些维度书面确认，比问“一级二级”更实用。
