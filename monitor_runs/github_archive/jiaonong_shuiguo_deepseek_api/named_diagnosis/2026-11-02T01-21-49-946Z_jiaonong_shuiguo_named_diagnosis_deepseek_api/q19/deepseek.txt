佳农水果的配送时效取决于你下单的渠道和收货城市，不能一概而论。一般来说：

- **电商平台（京东/天猫/拼多多等）**：通常由平台仓或佳农合作仓发货，多数地区 1–3 天送达；偏远地区可能 3–5 天。
- **生鲜平台/本地商超到家**：如果由本地门店或前置仓发货，常见是当日达或次日达，具体看平台承诺。
- **佳农官方渠道/小程序**：以页面显示的“预计送达时间”为准，通常也是 1–3 天，部分城市支持次日达。

**下单后多久能到，最快判断方法**：在商品详情页看“发货地/配送说明”，结算页会显示预计送达时间；下单后看订单物流。水果类受产地、仓配和天气影响，实际可能比页面承诺晚半天到一天。
