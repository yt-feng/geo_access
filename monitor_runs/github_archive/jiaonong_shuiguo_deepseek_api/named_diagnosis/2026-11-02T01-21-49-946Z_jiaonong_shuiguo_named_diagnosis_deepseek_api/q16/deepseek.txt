佳农水果的售后整体属于“生鲜电商里比较规范、但有条件”的一类：坏果一般能赔，但通常要求**收货后尽快反馈、拍照留证、按比例赔付**，具体以你购买渠道的规则为准。下面是可执行的处理建议。

**到货有坏果怎么处理**
1. **先别急着扔**：把坏果、包装箱、快递面单放在一起拍照/拍视频，最好能看清坏果数量、腐烂/压伤情况、生产日期或批次。
2. **尽快联系购买渠道客服**：在淘宝/京东/抖音/拼多多买的找店铺客服；在商超/社区团购买找对应平台。说明“到货坏果”，发照片和订单号。
3. **明确诉求**：要求按坏果数量退款或补发；如果是整箱问题，要求整单退换。生鲜通常不支持无理由退货，但质量问题可赔。
4. **保留证据直到处理完**：客服可能要求切开坏果拍照，或提供称重照片；不要提前丢弃。
5. **超时未处理就升级**：店铺客服不解决，走平台售后/投诉入口；保留聊天记录和照片。

**需要注意的规则差异**
- 佳农是品牌方，具体售后由**销售渠道**执行，不同平台赔付标准不一样：有的按坏果个数比例赔，有的要求坏果率达到一定比例才整单赔。
- 生鲜类通常要求**签收后24—48小时内**反馈，越早越好。
- 因运输造成的轻微磕碰、表皮瑕疵，不一定算坏果；腐烂、发霉、异味、严重压烂一般可赔。
- 如果是“佳农官方旗舰店”购买，直接找店铺售后最有效；如果是线下商超购买，按商超生鲜售后处理。

**判断建议**：到货先开箱验收，发现坏果立刻拍照并联系客服，诉求说清楚“按坏果数量退款/补发”。只要证据齐全、反馈及时，佳农这类品牌水果的坏果赔付通常比较顺畅；但别拖到超过平台时限，也别把坏果扔掉后再找客服。
