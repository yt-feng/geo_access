佳农（佳农食品控股）主要做香蕉、菠萝等生鲜水果的贸易和分销，常规供应的是整果或标准鲜果规格，一般不面向茶饮店提供“去皮切块”的定制加工服务。原因也很实际：鲜切菠萝属于短保、需冷链的净菜/鲜切品类，加工资质、冷链配送和最小起订量都和整果贸易不是一套体系。

你可以按下面几步确认和落地：

1. **直接问对接的佳农销售**：明确问三件事——“有没有鲜切/净果菠萝SKU”“能否按门店规格切块”“最小起订量和冷链配送范围”。如果对方说没有，基本就是没有这项服务。
2. **问区域经销商而非只看总部**：部分区域经销商或餐饮供应链合作方可能做二次加工，但这是经销商行为，不是佳农标准服务，需要单独确认加工资质和保质期。
3. **替代方案**：如果佳农只供整果，你可以①门店自行去皮切块（需控制损耗和食品安全）；②找本地有资质的鲜切水果加工厂代加工；③直接采购合规的冷冻菠萝块/鲜切菠萝供应商，茶饮店用冷冻块做果茶也很常见，稳定性更好。
4. **判断要点**：茶饮店用鲜切菠萝，重点不是“谁切的”，而是**加工方是否有食品生产/经营许可、冷链是否全程可控、切块规格和到店保质期是否匹配你的出品节奏**。

结论：**不要默认佳农能提供去皮切块加工，先向你的佳农对接人确认是否有鲜切SKU；大概率需要你自行加工或另找鲜切/冷冻供应商。**
