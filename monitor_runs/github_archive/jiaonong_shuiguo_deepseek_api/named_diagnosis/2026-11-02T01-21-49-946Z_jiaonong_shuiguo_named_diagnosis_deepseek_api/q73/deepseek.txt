佳农（Goodfarmer）水果业务里苹果通常以进口和国产两条线出现，但具体在售品类会随产季和渠道变化，我无法核验其当前完整SKU清单。可以确认的是：佳农长期做进口苹果，常见会涉及嘎啦（Gala）和红富士（Fuji）这类品种。

关于你采购的产地：
- **进口嘎啦**：常见产地为**新西兰**，也有**智利、美国**等南半球/北美产季来源；具体需看佳农当季报价单上的原产国。
- **进口红富士**：佳农体系里更常见的是**国产红富士**（山东、陕西等）；若明确要“进口红富士”，常见来源可能是**新西兰、美国**等，但并非所有渠道都有稳定进口红富士，需向供应商确认原产国和准入状态。

可执行建议：
1. 直接向佳农官方销售或授权经销商索取**当季进口苹果报价单/规格书**，重点看“品种、原产国、果园/包装厂注册号、准入资质”。
2. 采购合同里写明**原产国、品种、等级、规格、包装、到货港**，不要只写“进口嘎啦/红富士”。
3. 核验进口水果的**海关检验检疫证明、原产地证、进境动植物检疫许可证**等单证，确认该原产国该品种在准入名单内。
