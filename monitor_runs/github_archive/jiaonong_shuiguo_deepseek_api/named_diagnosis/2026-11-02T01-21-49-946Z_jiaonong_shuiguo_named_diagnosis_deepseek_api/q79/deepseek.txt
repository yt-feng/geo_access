佳农水果的配送范围通常取决于你下单的渠道（比如官方旗舰店、商超平台、社区团购或本地经销商），不同渠道覆盖城市和冷链收费规则不一样，我没法核验你所在县城的具体覆盖情况，直接给结论：

**1. 覆盖城市怎么判断**
- 先确认你是从哪个渠道下单：佳农官方小程序/天猫京东旗舰店/美团饿了么/本地商超。
- 在对应渠道的结算页输入你的县城地址，能选到配送时段或显示“可配送”才代表覆盖；显示“超出配送范围”就是送不到。
- 佳农很多水果走的是“产地/区域仓+经销商”模式，县级市场常见由本地经销商或商超供货，不一定由佳农直发。

**2. 县城门店能不能送到**
- 如果指的是“你当地门店是否支持配送”：要看该门店是否开通线上配送，直接在美团/饿了么/门店小程序搜该门店，看有无“配送”入口。
- 如果指的是“佳农能否直发到你县城”：以官方渠道结算页是否可选为准，不能仅凭品牌判断。

**3. 冷链物流收费**
- 没有统一的全国冷链报价，常见计费方式是：按重量/体积计费、按温区（冷藏/冷冻）加价、加收冷链包装费、偏远地区附加费。
- 最准确的做法：在结算页看运费明细，或联系该渠道客服报“县城地址+重量+品类”要报价。
- 若走本地经销商/商超，通常按门店配送规则收费，可能满额免运费。

**建议你直接做这一步**：打开你准备下单的渠道，把县城详细地址填到结算页，截图运费和配送范围；如果显示不可送，再问该渠道客服“是否支持你所在县城的经销商配送”。这样能得到可执行的答案，而不是笼统的品牌覆盖说法。
