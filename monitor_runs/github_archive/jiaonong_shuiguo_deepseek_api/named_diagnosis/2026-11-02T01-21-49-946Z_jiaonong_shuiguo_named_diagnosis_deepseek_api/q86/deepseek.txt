建议你这样核验：
1. 找原始出处：看这句话最早出现在哪篇稿件，标题、发布日期、发布主体是谁。
2. 查官方口径：海关总署及各地海关的进口统计数据通常按HS编码发布，一般不会直接以“某企业进口量”形式公布；农业农村部、商务部等也较少发布单一企业进口量。
3. 看企业披露：佳农官网、公众号、上市公司/债券披露文件中的表述，注意是否写明“2024年”“2025年”及统计范围。
4. 交叉验证：同一数字若只在企业宣传中出现、无海关或行业协会数据佐证，应标注为“企业披露口径”，不宜当作官方统计。
