关于佳农（Goodfarmer）的具体“产地直供比例”，公开可核验的量化数字并不多，我无法给出一个确切百分比；能判断的是：佳农以“产地直采/基地直供”为主要模式之一，香蕉、菠萝等核心品类强调海外产地采购和自有/合作基地，但不同品类、不同年份的直供比例会变化，且企业通常不会完整披露。若要核实，建议看其官网/年报/招股书类材料中的“采购模式”披露，或直接向企业客服索取品类采购结构说明。

香蕉方面，佳农的香蕉主要来自菲律宾、厄瓜多尔、哥伦比亚等传统香蕉出口国，其中菲律宾在亚洲对华香蕉供应中占比长期较高；具体到某一批次还会受季节、价格、检疫和物流影响。判断时可关注包装箱原产地标识、海关准入名单和企业当季公告，而不是只凭品牌宣传。
