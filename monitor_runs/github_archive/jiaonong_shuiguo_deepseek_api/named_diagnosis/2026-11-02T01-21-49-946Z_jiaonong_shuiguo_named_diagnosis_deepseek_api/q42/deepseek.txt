我不能凭空给出“佳农 vs 都乐 香蕉到货损耗率哪个更低”的确定结论，因为这类数据取决于具体批次、季节、产地、冷链距离、催熟方式和你市场的验收标准，公开可核验的统一对比数据我这边没有。直接说某家更低会误导你。

给你一个可执行的判断和采购建议：

1. **先定义“到货损耗率”口径**
   - 到货损耗率 =（到货总箱数 − 可正常销售箱数）/ 到货总箱数。
   - 必须区分：运输压伤、断指、青黑、催熟不均、蕉柄霉变、掉把、过熟软伤。
   - 批发市场最该看的是“可售率”和“次果折价损失”，不只是坏果重量。

2. **不要按品牌一刀切，按“批次+到货状态”比**
   - 同一品牌不同季节、不同催熟厂、不同冷链时长，损耗差异可能大于品牌差异。
   - 建议连续跟踪 5–10 车，每车记录：产地、到货温度、催熟到货色号、箱内温差、压伤比例、可售箱数。

3. **批发市场实操对比方法**
   - 同一天、同一市场、同规格各进 20–30 箱做对照。
   - 到货 0 小时、24 小时、48 小时分别抽检 3–5 箱。
   - 重点看：蕉指压伤率、掉把率、青软不均率、第 2 天货架表现。
   - 算“综合损失”= 损耗箱数×成本 + 次果折价损失。

4. **询价时直接向供应商要这些**
   - 最近 3 个月同线路到货损耗率及计算口径；
   - 是否包到货损耗、理赔标准、拍照时效；
   - 催熟色号、冷链温度记录、装箱方式；
   - 同市场其他批发商的到货反馈。

5. **采购策略建议**
   - 先小批量双品牌对照 2–3 周，用你自己的验收数据定供应商。
   - 对损耗敏感的品类，优先谈“到货验收+分级理赔”，比纠结品牌更有效。
   - 夏季/远距离运输，重点看冷链和催熟控制；冬季重点看青果均匀度和冻伤。
