我无法确认“11.4万吨”这个数据是2025年的，也无法确认对应的增长率——这两个信息我都没有可核验的可靠来源，不能凭空给你数字。

可以给你几个判断建议：

1. **看数据出处**  
   如果这个“11.4万吨”来自某篇报道、行业报告或企业宣传材料，先看它标注的统计年份和统计口径，是“进口量”“销售量”还是“采购量”，是佳农一家还是包含其代理品牌。

2. **找权威来源交叉验证**  
   可查：
   - 佳农集团/佳农食品控股的官网、年报或新闻稿
   - 中国海关总署的鲜或干菠萝进口统计
   - 中国食品土畜进出口商会、水果行业协会的报告
   - 上市公司公告（如果涉及相关主体）

3. **注意“进口量”口径**  
   海关统计的是全国进口量，企业口径通常是自身进口或采购量，两者不能直接对比；而且菠萝进口常按“鲜或干的菠萝”税则号统计，是否包含菠萝制品也会影响数字。
