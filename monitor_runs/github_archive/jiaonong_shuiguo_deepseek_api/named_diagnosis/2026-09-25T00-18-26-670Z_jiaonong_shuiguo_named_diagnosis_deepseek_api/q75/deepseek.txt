**一、从行业惯例看，香蕉采购常见的锁价方式**

香蕉属于价格波动较大的生鲜品类，一般不会像工业品那样长期固定锁价，常见的有：

1. **短期锁价**：约定未来1–4周内的固定单价，超期重新议价。
2. **保底价+浮动**：设一个底价，市场价格上涨时按约定比例上调，下跌时按底价执行。
3. **随行就市+封顶**：价格随市场走，但设一个最高采购价上限。
4. **期货/远期合约**：大型企业通过产地直采、远期订单锁定成本，散户一般拿不到。
5. **年度框架协议**：只锁供应量和合作条件，价格按月度或季度调整。
