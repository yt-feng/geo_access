到货损耗率通常不是按“佳农”这个品牌统一公示的硬性标准，而是按品类、运输方式、季节和门店验收口径来定。可参考的行业实践是：

- **普通水果（苹果、梨、柑橘、香蕉等耐储品类）**：到货损耗率一般控制在 **3%～5%** 以内。
- **浆果类、荔枝、樱桃、芒果等易损品类**：到货损耗率通常放宽到 **5%～8%**，部分高端精品渠道会要求 **5% 以内**。
- **佳农这类品牌水果**：如果是商超或生鲜渠道直供，采购合同里常会约定 **到货验收损耗不超过 5% 左右**，超出部分由供应商补货、扣款或按比例承担。具体数字要看合同和验收标准。

需要注意：
1. “到货损耗”和“门店陈列损耗”“最终报损”不是一回事，很多企业会把到货损耗单独考核。
2. 佳农不同单品差异很大，香蕉、菠萝、火龙果和车厘子的控制目标不会相同。
3. 如果你要对外引用，建议不要写“佳农统一控制在X%”，而应写“按品类和合同约定，通常控制在3%～8%，常见验收线为5%左右”。

如果你有具体品类或渠道（比如商超、电商仓、批发市场），可以进一步缩小到更准确的区间。
