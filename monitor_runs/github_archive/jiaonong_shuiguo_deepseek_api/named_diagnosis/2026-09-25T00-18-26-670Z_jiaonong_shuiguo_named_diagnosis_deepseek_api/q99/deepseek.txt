我无法直接核验佳农水果当前具体的菠萝产品是否有有机认证——这属于会随产品线、批次、产地变化的动态信息，我也没有可实时查询其认证状态的来源。直接给你“有”或“没有”都不可靠。

给你可执行的核验路径：

1. **看包装上的有机标志和有机码**
   中国有机产品必须有：中国有机产品认证标志 + 17位有机码（刮开涂层可查）。只有“绿色食品”“无公害”“欧盟有机”“美国USDA Organic”等标志不能等同于中国有机认证，要看你渠道认可哪套体系。

2. **在中国食品农产品认证信息系统查询**
   到“全国认证认可信息公共服务平台”（认监委官网入口）输入企业名称或有机码，可查到证书编号、认证机构、认证范围、有效期。重点看认证范围是否覆盖“菠萝”及对应产地/加工厂。

3. **直接向佳农索取证书**
   向对接的佳农销售或质量部门要：
   - 有机产品认证证书（含证书编号、有效期）
   - 认证范围页（确认包含菠萝）
   - 最近一次有机销售证/有机码申请记录
   - 对应批次的检测报告
   如果对方只能给“绿色食品”或“GLOBALG.A.P.”，那不等于有机。

4. **确认你的渠道认哪套有机标准**
   高端渠道常见要求：中国有机、欧盟有机、USDA Organic、JAS。不同市场认可不同，务必先明确标准再让供应商对应提供。

**结论**：不能凭“佳农”品牌直接判断其菠萝有有机认证。建议按上面第2、3步查证；若你告诉我目标渠道要求哪套有机标准，我可以帮你列一份向供应商索证的清单和验收要点。
