佳农（Goodfarmer）并没有在公开渠道稳定披露“产地直供比例”这一具体数字，我不能给你一个准确百分比，否则就是编造。它对外更多强调的是“全球直采”“产地直采”“自有/合作基地”等模式，但具体到某品类、某年度、某区域的直供占比，通常属于内部采购数据，需要向佳农对口销售或采购负责人书面索取。

对你采购端来说，更实用的做法不是先追问一个笼统比例，而是按品类和链路拆开谈，直接压中间环节：

1. **要求按单品提供供应链说明**
   让佳农对每个拟采购单品写明：产地国家/区域、是否自有基地、是否包园/订单农业、是否经产地加工厂、是否经国内贸易商、到港后是否经一级批发。这样能看出哪些是真直采，哪些只是“产地品牌、国内分销”。

2. **把“直供”写进合同，而不是只听口头介绍**
   可约定：
   - 产地证明/果园或包装厂信息；
   - 报关单、原产地证、植检证等；
   - 是否允许第三方或你方验厂；
   - 若实际链路与申报不符，价格重新议定或索赔。

3. **用价格结构判断中间环节**
   让供应商报：
   - 产地离岸价/收购价；
   - 国际运费、保险；
   - 关税、增值税；
   - 港口费、冷链仓储；
   - 国内配送费；
   - 供应商服务费/毛利。
   如果对方只给一个到岸总价，通常说明中间环节不透明，谈判空间也难判断。

4. **分品类谈判，不要用一个总比例**
   香蕉、火龙果、奇异果、苹果、柑橘等链路差异很大。进口品可能更多是海外直采+国内分销；国产水果可能更接近产地直发。你要先锁定采购量大的2—3个单品，逐个谈直发、产地仓直配或港口直提。

5. **替代方案比死磕一家更有效**
   如果佳农不能满足直供和降本，可以同步对接：
   - 产地合作社/农业公司；
   - 港口一手进口商；
   - 大型批发市场的一级档口；
   - 产地政府或行业协会推荐的供应链企业。
   用竞争报价倒逼佳农给更短链路和更优价格。

6. **降本重点通常不在“名义直供比例”，而在四个点**
   - 减少一次国内贸易转手；
   - 提高整柜/整车直发比例；
   - 把配送从多级批发改为你方仓或门店直配；
   - 用稳定订单量换产地锁价和账期。
