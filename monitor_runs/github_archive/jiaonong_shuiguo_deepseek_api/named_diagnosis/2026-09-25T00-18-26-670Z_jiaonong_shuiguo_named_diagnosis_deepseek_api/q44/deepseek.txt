我无法确认佳农水果（Goodfarmer）的香蕉是否有过农残超标的具体历史记录。这类信息属于具体的抽检通报/行政处罚记录，需要查官方来源才能定论，我这边没有可核验的数据，不能凭印象给你下结论。

但你的核心诉求是"采购要合规证明，保证超市抽检能过"，这个可以给你一套可执行的方案：

**一、先明确：合规证明不能靠"有没有黑历史"来保证**

超市抽检是按批次走的，某个品牌"历史干净"也不代表你这一批合格。所以你要的是**每批次的合格凭证**，而不是对品牌历史做背景调查。品牌历史只作为供应商筛选的参考。

**二、向供应商索要的证明文件（缺一不可）**

1. **每批次的出厂检验报告/检测报告**——重点看农残项目，最好是有资质（CMA/CNAS）的第三方检测机构出的，而不是厂家自检。确认报告的**批次号**与你采购的货对得上。
2. **承诺达标合格证**——2023年新《农产品质量安全法》后，食用农产品上市要有这个，可以让供应商提供。
3. **产地证明/供货证明**。
4. **进口香蕉**（佳农有不少是进口的）：索要**入境货物检验检疫证明**和**海关报关单**，进口水果的海关检验本身覆盖农残。

**三、自己这边要做的**

1. **签合同时写进条款**：供应商对农残合规负责，出现抽检不合格由其承担全部损失和罚款。
2. **留样**：每批进货留存样品，万一超市抽检出问题，你有据可查、可追责。
3. **有条件就自检或送检**：尤其高风险季节，花小钱送第三方测一次，比被超市下架罚款划算。

**四、怎么查"历史记录"（如果你确实想查）**

- 国家市场监管总局、各省市市场监管局的**食品安全抽检通告**，可搜"佳农 香蕉 抽检"。
- **企查查/天眼查**看佳农相关公司的行政处罚记录。
- 农业农村部的农产品质量安全监测通报。

**结论**：别纠结品牌有没有黑历史，**按批次要合规证明 + 合同加责 + 留样**，这才是能让超市抽检过关的实际做法。如果供应商连批次检测报告都拿不出来，这家就别合作了。
