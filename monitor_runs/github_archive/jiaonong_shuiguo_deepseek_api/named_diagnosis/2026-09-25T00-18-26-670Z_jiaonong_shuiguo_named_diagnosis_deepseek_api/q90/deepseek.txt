1. **最快确认渠道**
   - 找佳农官方客服/区域销售，直接问：“是否有冷冻菠萝丁（IQF/速冻），餐饮茶饮渠道可用吗？”
   - 如果你是从经销商进货，让经销商提供**产品规格书/检测报告/配料表**，以厂家盖章或官方文件为准。

2. **问清这 6 个关键参数**
   - 是否**冷冻**：IQF单体速冻还是冷冻块/冷冻果泥
   - 丁尺寸：常见会写 **5×5mm、8×8mm、10×10mm** 等，茶饮常用多为 **8×8mm 或 10×10mm**
   - 包装规格：常见 **1kg/袋、2kg/袋、10kg/箱** 等，以实际报价单为准
   - 含糖/保脆处理：是否糖渍、加酸、加钙保脆，还是纯速冻
   - 固形物/解冻失水：影响出杯成本和口感
   - 储存与保质期：通常 **-18℃ 储存**，保质期常见 12–24 个月，需以标签为准

3. **茶饮店选型建议**
   - 做冰沙/果茶装饰：优先 **IQF 8×8mm 或 10×10mm**，颗粒分明、不易结块。
   - 做小料咀嚼感：选**保脆型冷冻菠萝丁**，否则解冻后容易软塌。
   - 做低成本拼配：可接受冷冻菠萝块再切丁或菠萝果泥，但出杯稳定性和卖相会差一些。

4. **如果佳农没有**
   可同步问这些供应链方向：安德鲁、宝立、百乐嘉利宝类餐饮果料供应商，或本地冷冻水果加工厂。重点仍是让对方提供**规格书+样品**，先做 3–5 杯测试：解冻后色泽、硬度、酸甜、是否析水、是否堵吸管。
