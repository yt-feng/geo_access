佳农（Goodfarmer，通常指佳农食品控股/佳农水果业务）的账期没有统一公开标准，一般按客户类型、采购规模、合作历史、渠道类型和授信审批结果单独确定。可以给你一个可执行的判断框架：

1. **常见账期区间**
   - 商超、电商、大型连锁、批发大客户：通常可能是 **30～60天**，部分强势渠道或长期大客户可能到 **60～90天**。
   - 中小批发商、餐饮、水果店、新客户：更常见的是 **现款现货、款到发货、周结或15～30天**。
   - 具体以合同、订单和授信额度为准，不同区域、不同品类、不同销售模式差异很大。

2. **新客户能不能申请账期**
   - **可以谈，但通常不容易直接给长账期。**
   - 新客户一般会先经历：
     - 现款现货或预付款；
     - 小额试单；
     - 短期账期，如7天、15天；
     - 稳定合作后再申请30天、60天。
   - 直接给新客户30～90天账期的概率较低，除非你有很强的渠道背书、采购量大、能提供担保或保证金。

3. **申请账期通常需要准备**
   - 营业执照、法人身份、开票信息；
   - 近半年到一年的采购/销售流水；
   - 下游客户合同或商超/电商入驻证明；
   - 财务报表或纳税证明；
   - 担保、保证金或法人连带责任担保；
   - 明确采购品类、月采购量、结算周期。

4. **实际建议**
   - 直接联系佳农当地销售或大客户经理，问三件事：
     1. 新客户首单结算方式；
     2. 做多久、做到多少量可以申请账期；
     3. 账期审批需要哪些材料、额度多少。
   - 如果对方要求先款后货，可以先争取“小额试单+短账期”，比如15天，再逐步谈30天。
   - 不要只听口头承诺，账期必须写进合同或对账单，明确起算日、逾期费用和停货条件。
