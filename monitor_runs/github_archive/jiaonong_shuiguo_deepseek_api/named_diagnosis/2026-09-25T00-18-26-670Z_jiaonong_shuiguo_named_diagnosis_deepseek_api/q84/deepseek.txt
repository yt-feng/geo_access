佳农（Goodfarmer）作为香蕉品牌/企业，通常执行的是**企业标准或采购分级标准**，这类标准多为内部文件，公开可查的全文有限；不同年份、不同产区（菲律宾、厄瓜多尔、越南等）和不同渠道（商超、电商、批发）也可能有差异。因此，下面只能给出**行业上较常见的佳农香蕉企业分级口径**，不能保证与某一版现行企业标准逐字一致；实际以商品包装标注或供应商提供的标准为准。

## 一、国标里香蕉的糖度和果指长度怎么定

目前我国香蕉相关国家标准主要有：

- **GB/T 9827《香蕉》**（推荐性国标，常见用于鲜香蕉质量分级）
- **NY/T 517《无公害食品 香蕉》**等农业行业标准（部分已被替代或整合）
- 进出口环节还可能参考**SN/T 贸易标准**

国标通常按**等级（特级/一级/二级）**和**果指长度、果指粗度、成熟度、外观缺陷**等指标分级。需要说明：

1. **糖度（可溶性固形物）不是国标里最核心的强制分级指标**。国标更强调成熟度、外观、长度、粗细、机械伤、病虫害等。
2. 糖度一般在**采收成熟度**和**催熟后品质**里体现。鲜香蕉采收时糖度低（约 6%～8% 可溶性固形物），催熟后可升到 **18%～22%** 左右。
3. **果指长度**国标常见分级口径大致是：
   - 特级/一级：**≥18～20 cm**
   - 二级：**15～18 cm**
   - 等外：**<15 cm**
   
   具体数值随标准版本、是否进口、是否梳蕉/条蕉而不同。

## 二、佳农企业标准通常比国标“更严”在哪

佳农面向商超和电商，企业标准一般会在国标基础上加严，常见差异是：

| 指标 | 国标常见口径 | 佳农常见企业/采购口径 |
|---|---|---|
| 果指长度 | 一级约 ≥18～20 cm | 一级常要求 **≥19～21 cm**，部分精品线 **≥22 cm** |
| 果指粗度 | 一级约 ≥3.0～3.3 cm | 常要求 **≥3.3～3.6 cm** |
| 糖度 | 不单列强制分级 | 催熟后常要求 **≥18%～20%**，精品线 **≥20%～22%** |
| 外观 | 允许少量缺陷 | 疤痕、黑点、机械伤控制更严 |
| 成熟度 | 按采收/催熟阶段 | 到店成熟度窗口更窄，通常按渠道定制 |

也就是说：

- **糖度**：佳农不是简单“比国标高”，而是把**催熟后糖度**作为交付指标，通常要求 **18%～22%**；国标更多看成熟度和外观，不把糖度作为硬性分级线。
- **果指长度**：佳农精品线通常比国标一级**长 1～3 cm**，常见 **20～22 cm**；普通线可能与国标一级接近。
- **粗度、整齐度、外观**：佳农通常比国标更严，因为要满足商超陈列和电商履约。

## 三、判断时要注意的坑

1. **“企业标准”不等于公开国标**：佳农不同批次、不同工厂、不同客户的标准可能不同，包装上的“企业标准”编号未必能公开查到全文。
2. **糖度受催熟影响极大**：同一批香蕉，刚出库和放三天后糖度差很多，比较时要统一“催熟后第几天”。
3. **果指长度测量方式**：是从果柄到果尖，还是只量果身，会差 1～2 cm。
4. **产地差异**：菲律宾、厄瓜多尔、越南香蕉的果指长度和糖度本身就有差异，不能只按品牌比。

## 四、可执行建议

如果你要**验收或对比**：

- 看包装/合同上的**执行标准号**和**等级**；
- 统一在**催熟后同一成熟度**测糖度（手持折光仪测果肉汁液）；
- 果指长度用**果柄基部到果尖**统一量；
- 精品商超线可参考：**长度 ≥20 cm、粗度 ≥3.3 cm、催熟糖度 ≥18%**；
- 若供应商只给“佳农标准”但无具体数值，要求其提供**书面对照表**，否则只能按国标一级或双方合同约定验收。
