佳农（Goodfarmer）作为国内较大的香蕉进口商，其香蕉分级标准通常依据外观、长度、饱满度、瑕疵等指标划分。但需要说明的是，**佳农的具体分级细则和一级果/二级果的实时差价属于其内部或渠道政策，外部无法给出官方精确数字**，以下是可以参考的行业通行做法和判断方法。

## 一、香蕉分级的常见维度（行业通行）

| 指标 | 一级果典型要求 | 二级果典型情况 |
|---|---|---|
| 果指长度 | 达到品种标准（如菲律宾/厄瓜多尔蕉通常≥18–20cm） | 偏短 |
| 果指粗细/饱满度 | 饱满、棱角不明显 | 略瘦、棱角较明显 |
| 外观 | 无黑斑、无机械伤、无虫害 | 有轻微斑点/擦伤 |
| 梳形/条数 | 每梳条数均匀、整齐 | 条数不均 |
| 成熟度 | 青度一致，便于催熟 | 青度不齐 |
| 疤痕/水锈 | 基本无 | 允许少量 |

## 二、一级与二级的价格差

- **行业一般幅度**：二级果通常比一级果低 **15%–30%**，具体看季节、产地、到货量和瑕疵程度。
- **旺季/到货集中时**：差价可能拉大到 30%–40%。
- **淡季/缺货时**：差价可能收窄到 10%–15%。
- 佳农这类品牌货，一级果溢价更明显，二级果有时走"电商/加工/催熟散货"渠道，价差受渠道影响大。

## 三、给批发商的可执行建议

1. **直接找佳农区域销售或一级代理**索取当期的《产品等级说明》和报价单，这是唯一权威口径。
2. **看实物验收标准**：要求对方明确"允许瑕疵比例、最低长度、条数要求"，写进合同。
3. **对比同期市场价**：用当地批发市场（如上海辉展、广州江南、北京新发地）的香蕉行情做参照，判断报价是否合理。
4. **按用途采购**：一级果走商超/精品店，二级果走催熟批发、加工、电商，避免用一级价买二级货。
