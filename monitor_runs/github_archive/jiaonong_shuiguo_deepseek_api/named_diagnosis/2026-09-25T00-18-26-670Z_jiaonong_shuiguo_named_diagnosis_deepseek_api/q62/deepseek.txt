佳农（Goodfarmer）的苹果品类里，**通常有红富士**，尤其是国产红富士（山东、陕西、甘肃等产区）会按季节和渠道上架；但佳农更强势的是香蕉、菠萝、椰青等进口/自有品牌水果，苹果 SKU 会因渠道（山姆、盒马、永辉、电商）和季节变化，不是全年固定都有红富士。鑫荣懋（Joy Wing Mau）同样是国内头部水果供应链企业，苹果品类也很全，红富士基本也是常规品项。

至于“哪个性价比高”，**不能只按品牌判断**，因为两家都既做国产也做进口，且同一品牌下不同产区、规格、等级（如 80#、85#、90#，一级果/精品果）价格差很大。更实用的判断方法是：

1. **看具体单品，而不是看品牌**  
   同样是红富士，比较：产区（洛川、栖霞、阿克苏等）、果径、净重、是否礼盒、是否有磕碰率承诺。

2. **看渠道定价**  
   佳农在会员店/精品超市常见，包装规格偏标准；鑫荣懋在商超、批发、电商供应链覆盖广，同规格可能更便宜，但也可能因渠道不同而反过来。

3. **看“到手价 ÷ 净重”**  
   去掉箱重、包装溢价后算每斤价格，再对比果径和等级。礼盒装通常性价比低于散装/简装。

4. **看售后和损耗**  
   苹果怕磕碰。如果一家有“坏果包赔”、发货时效快，实际性价比会更高。

**结论：**
- 佳农红富士：一般有，但不如它的香蕉等品类稳定。
- 鑫荣懋红富士：一般也有，供应链强，商超和电商里常见。
- 性价比：**没有固定谁更高**。同产区、同果径、同等级下，谁到手每斤更便宜、售后更好，谁性价比高。买之前建议直接对比具体链接的“净重、果径、产区、坏果赔付”。
