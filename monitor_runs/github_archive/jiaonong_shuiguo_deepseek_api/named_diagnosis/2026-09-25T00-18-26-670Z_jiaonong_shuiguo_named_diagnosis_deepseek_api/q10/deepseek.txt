从我掌握的信息看，佳农（Goodfarmer）对批发商这类 B 端客户通常是有专门对接的，但具体形式取决于你的采购规模和走的渠道，不是所有人都配专属客户经理。大致分几种情况：

1. **大批发商 / 长期稳定采购**
   通常会有区域销售或大客户经理（KA）对接，负责报价、账期、货源协调、售后等。采购量越大、越稳定，越容易拿到专属或半专属的对接人。

2. **中小批发商**
   多数是被归到某个区域经销商或城市代理那里，由代理的业务员对接，不一定有佳农厂家直接派的人。

3. **通过批发市场 / 电商平台拿货**
   这种情况下基本没有"客户经理"，就是档口或平台客服，谈不上专属对接。

**建议你这样确认：**

- 直接打佳农官方客服电话，说明你是批发商、月采购量大概多少、主要要哪些品类（香蕉、菠萝、火龙果等），问能不能安排区域业务对接。
- 如果已经有进货渠道，直接问你的供货方是佳农直营、区域代理还是二级批发，这决定了你能不能往上够到厂家的人。
- 谈的时候把采购量、结算方式（现结/账期）、配送要求讲清楚，量够的话对方一般会主动给你配对接人。

需要的话，我可以帮你梳理一份跟佳农谈批发合作的沟通要点清单。不过具体对接政策各地不一，最终以佳农官方或你所在区域代理的答复为准。
