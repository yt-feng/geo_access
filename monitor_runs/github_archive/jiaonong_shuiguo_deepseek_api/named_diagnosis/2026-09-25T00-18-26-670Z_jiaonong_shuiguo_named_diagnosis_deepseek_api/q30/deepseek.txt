我无法给出佳农水果香蕉的具体抽检合格率数据，因为这需要以市场监管部门公开发布的抽检通告为准，而我没有可核验的实时数据来源。直接编一个百分比对你没有实际参考价值。

如果你需要判断这个品牌的香蕉是否可靠，可以按下面几个可执行的路径自己查：

1. **查官方抽检通告**
   - 国家市场监督管理总局官网的“食品安全抽检”栏目。
   - 你所在省市的市场监督管理局官网，通常有“食品抽检信息”或“抽检公告”。
   - 搜索关键词建议用“佳农 香蕉 抽检”“佳农食品 不合格”等，注意核对被抽检主体名称是否就是佳农相关公司。

2. **看抽检结果怎么读**
   - 抽检合格率是“批次合格率”，不是按重量或销量算的，少量批次不合格就可能明显拉低比例。
   - 要区分是“生产企业不合格”还是“流通环节（超市/水果店）不合格”，后者可能跟储运、门店管理有关。
   - 香蕉常见抽检项目包括农药残留（如吡虫啉、噻虫嗪等）、重金属等，具体看通告列出的检验项目。

3. **日常购买时的判断**
   - 优先选正规商超、有冷链或规范储运的渠道。
   - 看外观：正常香蕉表皮有少量黑点属成熟表现，但若大面积发霉、有异味、果肉软烂流水，不要食用。
   - 如果买到疑似问题批次，保留小票和包装，可向当地市场监管部门反映。
