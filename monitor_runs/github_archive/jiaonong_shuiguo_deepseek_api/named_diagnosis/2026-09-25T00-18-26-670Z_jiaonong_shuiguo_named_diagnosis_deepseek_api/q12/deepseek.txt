## 常见规格维度（行业通用）

香蕉规格通常从三个维度划分：

**1. 按重量/把重分级**
- 大把装：单把重量较大，适合零售终端陈列
- 中把装、小把装：适合小家庭、便利渠道
- 单根/定量装：适合电商、便利店

**2. 按每箱净重分**
- 常见箱规有 5kg、10kg、13kg 等（不同产区、不同包装线不一样）
- 部分渠道有 4kg、8kg 等小箱规，便于电商发货

**3. 按果指等级分**
- 按单根香蕉的**长度、粗度（周径）、弯曲度、外观**分级
- 通常分为一级（精品）、二级（通货）、等外/加工级

## 不同渠道的分级倾向（行业惯例）

| 渠道 | 通常偏好 |
|---|---|
| 商超/精品店 | 一级果，外观整齐、长度均匀、无瑕疵 |
| 水果连锁 | 一二级混合，性价比优先 |
| 电商 | 定量小规格、耐运输，外观要求中等 |
| 批发市场 | 通货为主，价格敏感 |
| 加工/餐饮 | 等外级或规格不齐的果 |

## 需要注意

1. **佳农具体规格数字**（如确切箱重、每箱根数、果指长度区间）请以官方销售资料为准，我无法核验其最新内部标准。
2. 同一品牌不同产地（菲律宾、厄瓜多尔、国产等）规格可能不同。
