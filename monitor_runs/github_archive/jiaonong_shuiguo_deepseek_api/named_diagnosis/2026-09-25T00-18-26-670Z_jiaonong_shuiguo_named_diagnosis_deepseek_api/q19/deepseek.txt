佳农水果的配送时效取决于**你所在的地区**和**下单渠道**，没有统一固定的“下单后多久到”，主要分以下几种情况：

**1. 如果你在京东、天猫等电商平台买**
- 通常走平台仓或佳农合作仓发货，**发货后一般 1–3 天送达**，偏远地区可能 3–5 天。
- 部分商品是预售/产地直发，页面会标注预计发货时间和时效，以商品页为准。

**2. 如果是即时零售平台（美团、饿了么、京东到家等）**
- 由附近商超或前置仓配送，通常**30分钟–2小时送达**，具体看门店距离和运力。

**3. 如果是佳农官方渠道/社区团购**
- 多为次日达或隔日达，部分区域支持当日达，需看具体活动页面说明。

**建议你这样确认：**
1. 看商品详情页的“发货地”“预计发货时间”“配送时效”标注；
2. 下单前在结算页输入你的收货地址，系统会显示预计送达时间；
3. 直接问店铺客服，报上你的城市，能得到最准的答复。

如果你告诉我具体在哪个城市、从哪个平台买，我可以帮你判断大概时效。
