佳农（Goodfarmer）的苹果品类通常会随产季和进口批次变化，常见会涉及：

- **嘎啦（Gala）**：进口货源常见产地有**新西兰、美国、智利**等；国产/国内分选货源也可能有，但你要采购的是进口嘎啦，重点问新西兰、美国、智利产季。
- **红富士（Fuji）**：进口红富士常见产地有**美国、新西兰、智利**等；国内红富士则主要来自山东、陕西、甘肃、新疆等产区。若明确要进口红富士，要确认具体国家、果园/包装厂和到港批次。
- 其他可能品类：**皇家嘎啦、太平洋玫瑰、爱妃、爵士、青苹果（如澳洲青苹）**等，但不同年份佳农主推品类会调整。

采购建议你直接向佳农官方或其在当地的经销商确认这四项，避免被模糊报价：

1. **品类/品种**：是 Gala 还是 Royal Gala；是 Fuji 还是其他富士系。
2. **产地国**：新西兰、美国、智利、南非等分别对应不同产季和价格。
3. **规格**：果径（如 70/75/80/85/90）、箱规、净重、包装方式。
4. **单证与批次**：原产地证、植物检疫证、进口报关单、到港时间、冷库/柜号。

如果你要的是“进口嘎啦和红富士”，最稳妥的问法是：
**“请提供当前可发的新西兰/美国/智利嘎啦和红富士的产地、规格、包装、到港批次和报价。”**

我无法核验佳农当前实时品类和产地库存，具体以佳农官方渠道或其授权经销商最新报价为准。
