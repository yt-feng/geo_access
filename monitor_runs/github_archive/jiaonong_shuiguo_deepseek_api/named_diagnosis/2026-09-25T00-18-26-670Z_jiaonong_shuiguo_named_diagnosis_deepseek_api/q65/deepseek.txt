抱歉，我无法给出“谁更快”的确定结论——这取决于你们门店的具体位置、下单时间（是否赶上当日截单）、货量以及两家各自在成都的仓配模式，而且这类配送时效属于会变动的运营数据，我没有可核验的最新来源，不能凭空下判断。

给你一个能快速判断、当天就能用的办法：

**1. 直接问两家的成都/西南对接人这4个问题**
- 成都是本地仓直发，还是从重庆/昆明/总仓调拨？调拨通常慢1天以上。
- 成都门店的**当日截单时间**是几点？截单前下单能否当日达/次日达？
- 你们要的品类（香蕉、火龙果等）成都仓有没有现货？缺货要等调拨。
- 能不能给**最近30天成都门店的平均到货时效**或准时率？

**2. 用一单实测**
同一天、同一时段，给两家下同样的品类和量，记录“下单→到店”时长。这是最准的。

**3. 关键提醒**
- 佳农是品牌/供应链方，洪九是果品分销企业，两者在很多区域是**通过经销商或第三方仓配**落地，实际时效往往取决于**当地服务商**，而非品牌本身，所以“全国比”意义不大，要按成都本地实际承运方比。
- 急单优先确认**成都本地是否有现货仓**，这比品牌更能决定速度。
