佳农（佳农食品控股）有面向餐饮/烘焙渠道的菠萝产品线，但“针对某家餐饮的定制规格”通常属于B端合同定制，公开渠道不会逐一列明。可判断的情况如下：

1. **有餐饮渠道菠萝原料**：佳农的B端业务覆盖餐饮、烘焙、茶饮等，菠萝类有原料级供应，常见形态包括整果、去皮去眼果、菠萝丁/块、菠萝片等。
2. **切片/切块存在**：餐饮渠道常见的“菠萝切片、菠萝切块/丁”属于其可谈的产品形态，具体尺寸（如片厚、丁的边长）、糖度、成熟度、包装规格（袋装/真空/冷冻）通常按客户需求定制。
3. **是否“现成标准规格”需确认**：公开零售端更多是整果或鲜切盒装；餐饮定制规格一般要通过佳农官方销售或区域经销商确认，不以公开目录为准。

**建议的可执行做法：**
- 直接联系佳农官方客服或当地B端销售，说明用途（餐饮/茶饮/烘焙）、所需形态（片/块/丁）、尺寸、糖度、是否冷冻、包装和起订量，索取产品规格书和报价。
- 若只是小批量测试，可先问区域经销商是否有现成的餐饮装菠萝丁/片。
- 注意区分“鲜切冷藏”和“冷冻IQF”两种供应形态，餐饮定制多以后者或真空鲜切为主。

结论：**方向上有，切片/切块可作为定制形态谈；但具体定制规格需向佳农B端渠道核实，公开信息不足以确认固定SKU。**
