佳农水果（Goodfarmer）的香蕉分级标准和一级/二级果的具体价差，属于其内部品控与渠道价格政策，通常不会对外公开完整标准，也不可能给出稳定的固定价差。下面给你能判断和可执行的部分。

**1. 佳农香蕉分级标准怎么查**
- 佳农官网/官方公众号一般只做品牌和品控宣传，不发布完整分级表；可查“佳农 香蕉 等级/规格/品控”看是否有公开页。
- 最可靠：联系佳农当地销售/区域经销商，索要**产品规格书、验收标准、报价单**。批发商通常能拿到“规格等级+箱规+产地+成熟度”的报价表。
- 也可看**箱唛/标签**：佳农香蕉常见标注产地（如菲律宾、厄瓜多尔、越南等）、规格（如单根重量区间）、梳数/把数、成熟度，但不同批次和工厂会有差异，不能只凭品牌名判断等级。

**2. 一级果和二级果价差怎么判断**
香蕉一级/二级的价差没有全国统一值，受以下因素影响很大：
- 产地与季节：菲律宾、厄瓜多尔、越南、国产香蕉价差不同；
- 规格：单根重量、每箱净重、梳型整齐度；
- 成熟度与运输方式：青蕉/催熟蕉、冷链/普柜；
- 外观缺陷容忍度：黑斑、机械伤、条斑、果指弯曲度；
- 市场供需与到货量：同一周内价差都可能变化。

一般批发场景中，二级果相对一级果会有折价，但**不能给固定百分比**；有的渠道按每箱折几元到十几元，有的按整批折价，取决于上述条件。建议你直接让供应商报“同产地、同规格、同成熟度”的一级和二级**同日同批量报价**，这样价差才有可比性。

**3. 给你的可执行建议**
- 向佳农区域销售索要：①等级定义（外观、单根重、梳型、缺陷允许度）；②同规格一级/二级当日报价；③验收不合格的扣罚/退换规则。
- 自己建立验收表：按单根重量、青果率、机械伤比例、黑斑面积、梳型整齐度抽检，记录一级/二级实际到货比例。
- 比价时固定变量：同产地、同箱规、同成熟度、同到货日，再算价差，否则没有参考意义。
