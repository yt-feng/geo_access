佳农（Goodfarmer）水果的苹果品类通常以进口鲜苹果为主，常见会按品种和规格分，例如：嘎啦果、红富士、青苹果（部分年份/渠道）、以及礼盒装/箱装苹果等。具体在售品类会随产季和渠道变化，建议以佳农官方渠道或你对接的经销商当期报价单为准。

关于你关注的两个品种：
- **进口嘎啦（Gala）**：常见产地包括**新西兰、美国、智利、南非**等，具体取决于当季采购来源。
- **进口红富士（Fuji）**：佳农体系的进口红富士常见来源以**新西兰**等为主；也有渠道会做**国产红富士**，但“进口红富士”需确认具体报关产地。

采购建议：直接向佳农或其授权经销商索取**当季可供货清单**，重点核对三项：**品种/规格（果径、等级、箱规）、原产国/产区、报关单与检疫证明**。这样能避免“品类名相同但产地和等级不一致”的采购偏差。
