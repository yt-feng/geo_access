佳农是否提供锁价合同，我无法直接核验其当前商务政策，不能给你确定答案。但可以给你可执行的判断和操作建议：

**1. 先明确你需要的“锁价”类型**
每月10吨菠萝原料，年需求约120吨，属于中等规模。你要先区分：
- **固定价格锁量合同**：约定未来6-12个月单价，波动风险由供应商承担，通常供应商会加价或要求最低采购量。
- **价格区间/保底+浮动合同**：设上下限，超出部分双方分担。
- **期货/远期订单**：按约定月份交货，价格提前锁定。
- **年度框架+季度调价**：相对容易谈，但不是严格锁价。

**2. 直接向佳农确认这几点**
联系佳农销售或大客户渠道时，直接问：
- 是否支持菠萝原料的年度/半年度锁价合同？
- 锁价最小起订量、锁价期限、履约保证金或预付款要求？
- 锁价是否含运费、规格（鲜果/冷冻/果肉/果泥）、糖度/品种标准？
- 超量或不足量如何结算？违约条款是什么？
- 是否可做“保底量+浮动价”或“价格上限”方案？

**3. 商务上降低被拒概率**
- 你月需10吨、年120吨，可以提出**年度框架合同+月度提货**，而不是一次性锁全年价格。
- 接受**部分锁价**：例如60%-70%需求量锁价，剩余随行就市，供应商更容易接受。
- 明确规格和验收标准，减少供应商因质量争议不愿锁价。
- 如果佳农不做锁价，可同时询**二家以上供应商**做比价和备选，避免单一依赖。

**4. 判断结论**
佳农作为大型果蔬供应链企业，具备做框架合同和远期订单的能力，但是否给茶饮店客户做固定锁价，取决于其风控政策、你的采购规模和信用条件。**不要只听口头承诺，要求书面报价单和合同条款**。如果对方只愿做“随行就市+年度框架”，你可以把锁价目标调整为“价格上限+季度议价”，这是更现实的方案。
