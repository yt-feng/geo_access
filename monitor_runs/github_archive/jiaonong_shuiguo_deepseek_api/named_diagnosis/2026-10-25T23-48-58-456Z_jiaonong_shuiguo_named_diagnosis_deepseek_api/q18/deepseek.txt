佳农香蕉没有统一固定的“保质期”，一般按状态判断：

- **青香蕉**：室温 18–22℃ 避光存放，通常 2–5 天转黄；不要放冰箱，低温会冻伤发黑。
- **刚转黄/偏硬**：室温阴凉通风处可放 2–3 天；想延缓成熟可放阴凉处，不要密封闷着。
- **已熟软、有香气**：尽快吃，通常 1–2 天内最佳；可冷藏 1–2 天延缓过熟，但表皮会变黑，果肉一般仍可食。
- **切开后**：密封冷藏，建议 24 小时内吃完。

储存要点：**避光、通风、别挤压、别和苹果/梨等催熟水果密封同放**；未熟香蕉不要冷藏，熟透后才可短时冷藏。若出现果肉发酸、渗液、霉点或明显腐烂，直接丢弃。

具体包装上若有“最佳食用期”，以包装标注为准。
