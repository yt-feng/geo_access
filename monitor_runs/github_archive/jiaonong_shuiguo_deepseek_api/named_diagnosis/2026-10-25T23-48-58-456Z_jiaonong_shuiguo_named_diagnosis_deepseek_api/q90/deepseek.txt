1. **直接找佳农官方渠道确认**
   - 打佳农官网/公众号上的客服电话，问三件事：①是否有“冷冻菠萝丁/速冻菠萝丁”这个SKU；②规格（常见是1kg/袋、5kg/袋、10kg/箱，果丁尺寸常见10×10mm、15×15mm等）；③是否供餐饮/茶饮渠道、最小起订量和冷链发货条件。
   - 如果对方只做鲜果或罐头，就让其推荐经销商。

2. **向供应商要“规格书+检测报告”**
   - 确认：净重/箱规、果丁尺寸、糖度（°Brix）、是否加糖/糖水、解冻后出水率、是否有添加剂、保质期、储存温度（通常-18℃）。
   - 茶饮店重点看：**解冻后是否易出水、果肉是否易碎、酸甜度是否稳定**，这直接影响出杯口感和损耗。

3. **先小样测试再批量**
   - 要1–2kg样品，做三件事：自然解冻测出水率；按你店配方试做出杯；对比不同批次颜色和口感。
   - 样品合格后再谈箱规和价格。

4. **备选方案**
   - 如果佳农没有冷冻丁，可同步问：冷冻菠萝丁的餐饮供应链品牌、当地冷冻水果经销商、或大型批发市场冷链档口；也可考虑“冷冻菠萝块”到店再切丁，但要注意切丁损耗和卫生。
