结论先说：**佳农的水果香蕉能做到“批次/产区级”溯源，但能否落到“具体农场”要按批次看；GLOBALG.A.P.证书通常可以按供应商主体和产品范围提供，但证书上的农场/包装厂范围需要你核验是否覆盖你采购的那批货。**

### 1. 溯源能到具体农场吗？
- 佳农这类进口香蕉通常采用“**产区/加工厂/批次**”的溯源体系，商超常见可提供：原产国、产区、包装厂编号、采收/包装日期、批次号、入境报关及检验检疫信息。
- “**具体农场**”是否可查，取决于该批次是否来自**自有/合作农场且纳入其农场管理系统**。实操中：
  - 直采或基地直供批次：较容易追溯到具体农场/基地代码。
  - 多农场集货、经包装厂混批的批次：通常只能追到**包装厂+产区+批次**，难以唯一对应单一农场。
- 建议你直接向佳农索要该批次的：**农场代码/基地名称、包装厂注册号、批次号、采收日期**，看四者能否闭环。若只能给包装厂和产区，就不能算“到具体农场”。

### 2. GLOBALG.A.P.证书
- 可以要求供应商提供**GLOBALG.A.P.证书**，重点核验：
  1. **证书持有人**是否与合同供应商一致；
  2. **产品范围**是否包含香蕉（Fresh Bananas）；
  3. **农场/生产场所清单**是否覆盖该批次产地；
  4. **证书有效期**和认证机构；
  5. 证书编号可在GLOBALG.A.P.数据库核验。
- 注意：GLOBALG.A.P.是**农场认证**为主，包装环节通常看**GRASP/链式监管**或包装厂相关认证；商超若要求“证书覆盖到包装厂”，要确认是农场证书还是供应链证书。
- 若供应商给的是“集团证书”或“贸易商证书”，要确认**你采购的农场是否在附页范围内**，否则不能直接作为该批次合规依据。

### 给商超的实操建议
- 合同里写明：**每批次提供农场代码/包装厂号/批次号+GLOBALG.A.P.证书编号及覆盖范围**。
- 收货时做“**证书-批次-产地**”三对照，缺一项就要求补证。
- 若供应商只能提供产区级溯源，建议按“**包装厂级+批次级**”验收，并在合同中明确不等同于农场级溯源。
