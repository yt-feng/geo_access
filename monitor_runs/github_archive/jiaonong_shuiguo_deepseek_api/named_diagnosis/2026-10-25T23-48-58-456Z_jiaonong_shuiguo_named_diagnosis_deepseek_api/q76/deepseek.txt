**1. 定制logo和包装**
- **官方渠道**：通常支持企业团购定制，常见方式是外箱/礼盒加印logo、贴定制标签、换定制手提袋；部分水果单品可做腰封、封套、吊牌。一般不接受直接在水果本体或原厂内包装上改logo。
- **经销渠道**：更灵活的是“二次包装”，即用佳农水果+定制外盒/手提袋/贺卡，但原厂包装和品牌标识通常不能改动，且要避免侵权式宣传。

**2. 起订量**
没有统一标准，取决于品类、规格、包装形式和是否开版：
- 仅贴标/加印现有礼盒：常见**几十到几百盒**起；
- 定制外箱/礼盒开版印刷：常见**300—1000盒起**，部分单品更高；
- 多品类组合礼盒、异形包装或烫金/UV等工艺：起订量通常更高。

**建议你直接这样问供应商，便于拿到准确报价：**
1. 你们是佳农官方授权还是经销？能否提供授权证明？
2. 支持哪种定制：外箱加印、贴标、腰封、手提袋、贺卡？
3. 定制logo的起订量、开版费、打样费、打样周期各多少？
4. 礼盒规格、水果单品和克重是否可自选？破损和售后怎么算？
5. 报价是否含定制包装、物流和税？
