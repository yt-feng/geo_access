佳农（佳农食品控股/佳农鲜果）与盒马的合作，公开可核实的信息主要是“基地直采+品牌直供”类模式：盒马以买断/直采为主，佳农作为品牌供应商提供标准化包装、产地品控和稳定供货，部分品类会做联合品牌或定制规格。但具体到每个品类、每个区域仓，合同条款可能不同，公开渠道无法确认全部是直供还是含代销/联营。

对超市的参考建议：

1. **优先学“直供+买断”的骨架**：向佳农这类品牌商谈产地直发、按标准分级、锁量锁价或季度框架价，减少中间批发环节。适合香蕉、苹果、柑橘等耐储、标准化程度高的品类。

2. **不要照搬盒马的账期和量级**：盒马有规模采购和全国仓配议价能力。中小超市应先用“小批量直供+周度补货”试跑，避免一次性买断造成损耗。

3. **代销/联营可作为过渡**：对损耗高、动销不确定的精品水果，可谈“代销+保底毛利”或“联营扣点”，由供应商承担部分损耗；但要把损耗责任、退换货、陈列标准写进合同。

4. **可执行的谈判要点**：
   - 要求供应商提供产地证明、检测报告、分级标准；
   - 约定到货验收标准和损耗分担比例；
   - 先选3—5个SKU做8周试销，看周转和毛利再扩品；
   - 争取“品牌方支持陈列/促销”，但采购权、定价权尽量留在超市。

5. **判断标准**：如果超市门店少、单店销量不稳定，纯买断直供风险较高，建议“核心单品直供买断+长尾单品代销/联营”组合。

总结：盒马与佳农更接近“品牌直供/基地直采”框架，但是否完全买断需以具体合同为准；超市可参考其直供逻辑，但应按自身销量采用“直供买断+代销联营”混合模式，先试销再放量。
