可以，但先别把“3kg装香蕉”当成常规在售规格来定，因为佳农的便利店渠道小包装更多集中在单根/小份香蕉、袋装苹果/橙、小盒蓝莓等，3kg对便利店偏大，通常是批发或家庭装规格。建议你按下面方式快速确认和选品：

1. **向佳农当地经销商要“便利店渠道规格表”**  
   直接问：香蕉有没有1–1.5kg袋装、单根/3–5根装、小串装；苹果/橙有没有2–4粒装；蓝莓有没有125g小盒。不要只问“3kg有没有”，要问“便利店小包装SKU清单”。

2. **优先上架这些低面积占用规格**  
   - 香蕉：3–5根装或1–1.5kg小串装，陈列用挂架/小堆头。  
   - 苹果：2–4粒装托盘或小袋。  
   - 橙子：4–6粒小袋。  
   - 蓝莓：125g小盒。  
   - 奇异果：3–6粒小盒。  
   这些比3kg香蕉更适合小店周转。

3. **3kg香蕉不建议作为便利店常规SKU**  
   除非你有 nearby 团购/外卖爆单能力，否则损耗和陈列面积都不划算。可做“预售/团购自提”规格，不占货架。

4. **下单前做小测试**  
   先选2–3个SKU，每店首单少量，观察3–7天动销和损耗；香蕉重点看催熟度和日损耗，小包装毛利通常更高但损耗也更快。

结论：**有小型规格可谈，但3kg香蕉不是便利店首选；让经销商提供便利店小包装SKU表，优先上3–5根香蕉、2–4粒苹果/橙、125g蓝莓这类规格。**
