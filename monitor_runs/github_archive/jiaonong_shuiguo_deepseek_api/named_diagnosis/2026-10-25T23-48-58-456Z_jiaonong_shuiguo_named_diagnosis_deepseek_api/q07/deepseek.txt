佳农水果的配送覆盖城市没有统一固定的名单，会随销售渠道变化：  
- 如果是京东/天猫/抖音等旗舰店，通常按平台物流能到的地区发货，很多县城也能送到，但部分偏远地区可能不发货或需补运费。  
- 如果是佳农官方小程序/社群团购，覆盖城市往往更有限，通常集中在一二线和部分地级市，县城是否可达要看具体活动页提示。  

**判断方法：** 打开你准备下单的渠道，把收货地址填成你们县城，结算页如果能显示可配送时间和运费，就说明能送到；如果提示“不支持配送/无货”，就是不到。最准确的是直接问该店铺客服：“XX省XX市XX县能发货吗？”  

所以：**多数平台电商渠道县城有机会送到，但不是所有县城都覆盖，必须以你下单渠道的地址校验为准。**
