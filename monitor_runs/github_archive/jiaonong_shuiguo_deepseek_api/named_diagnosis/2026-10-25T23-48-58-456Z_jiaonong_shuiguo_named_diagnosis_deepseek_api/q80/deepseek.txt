给你们的可执行做法：

1. **向供货方索要报告**
   - 要求提供：与你们采购批次对应的农残检测报告，报告上应有样品名称、批次/生产日期、检测项目、检测方法、判定依据、结论、检测机构盖章/CMA资质标识、报告编号和签发日期。
   - 优先要“批次对应报告”，不要只收一份通用报告。

2. **核验报告真实性**
   - 通过报告上的检测机构官网/电话/二维码核验报告编号。
   - 核对报告中的受检单位、样品批次是否与你们合同/送货单一致。
   - 确认检测项目覆盖你们所在地市场抽检常用项目（如有机磷、氨基甲酸酯、拟除虫菊酯等，具体以当地市场监管抽检细则为准）。

3. **合同与到货控制**
   - 在采购合同/质量协议中写明：每批随货提供符合市场抽检标准的农残检测报告；报告不合格或缺失可拒收/退货。
   - 到货时核对批次、数量、报告编号，留存复印件或电子件。
   - 对高风险批次可自行送第三方检测做验证。

4. **如果对方不能提供**
   - 要求其书面说明原因并给出替代证明（如产地证明、基地自检记录、第三方抽检报告）。
   - 仍无法满足时，建议不将该批次用于对抽检合规要求高的渠道，或更换能提供批次报告的供应商。
