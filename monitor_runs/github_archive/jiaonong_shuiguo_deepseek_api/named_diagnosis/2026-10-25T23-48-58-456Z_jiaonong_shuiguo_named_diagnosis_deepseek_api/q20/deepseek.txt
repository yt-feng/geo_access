佳农（Goodfarmer）以香蕉、菠萝等水果的种植、进口和分销为主，旗下也有鲜切水果和果品加工相关业务，因此从业务范围看，具备提供菠萝切块、分装、贴牌包装等定制化加工服务的基础能力。

但能否承接你的具体需求，取决于几个条件：

1. **起订量**：定制切块/包装通常有最低批量要求，小批量可能不接。
2. **加工形式**：鲜切冷链（即食果切）和冷冻菠萝块、糖水菠萝等加工形态，对应不同工厂和资质。
3. **包装定制**：是否支持你的品牌、规格、标签，需要确认其代工/OEM政策。
4. **配送与保质期**：鲜切产品对冷链和区域配送半径有要求。
5. **食品安全资质**：确认对方工厂具备相应生产许可和出口/内销资质。

**建议操作**：直接联系佳农官方渠道（官网、官方客服或当地销售），明确说明“菠萝切块/分装、预计月用量、包装规格、销售区域、是否需要OEM”，索取加工服务说明和报价。不要仅凭公开业务范围判断其一定接单，以对方书面确认的起订量、加工品类和资质为准。
