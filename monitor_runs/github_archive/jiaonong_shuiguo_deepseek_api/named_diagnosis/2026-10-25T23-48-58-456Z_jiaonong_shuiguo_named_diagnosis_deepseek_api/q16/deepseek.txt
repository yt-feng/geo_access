佳农水果的售后整体属于生鲜电商里“规则清楚、但对证据要求较严”的类型，处理坏果的关键是**收货后尽快拍照留证、按平台流程申请**。具体建议：

1. **先看购买渠道**
   - 在京东、天猫、抖音、拼多多等平台买：售后按对应平台规则走，通常有“坏果包赔/腐烂包赔”入口，优先在订单页申请售后。
   - 在商超、水果店买：直接找门店退换。
   - 社区团购/团长处买：先联系团长，由团长走售后。

2. **到货发现坏果的处理步骤**
   - **不要先扔坏果**：保留坏果、包装、快递面单，和好果分开拍照。
   - **拍照/拍视频**：坏果切开或展示腐烂部位，最好把坏果放在包装或面单旁拍，证明是同一订单。
   - **尽快申请**：一般要求签收后24—48小时内反馈，越早越好；超过时限可能不受理。
   - **按比例赔付**：生鲜通常按坏果数量/重量比例退款或补发，不是整单全退，具体看商品页承诺和平台规则。
   - **保留沟通记录**：客服拒绝时，可在平台申请介入。

3. **注意事项**
   - 轻微磕碰、表皮瑕疵通常不算坏果；腐烂、发霉、明显变质才算。
   - 不要只拍一张模糊全景，最好坏果特写+订单信息同框。
   - 如果商品页写明“坏果包赔”，截图保存，售后时作为依据。
   - 到货先开箱验货再签收，尤其是整箱水果。

总体建议：**佳农售后可以走，但别拖、别扔坏果、证据拍清楚**。如果平台客服处理慢，直接走平台售后介入通常比只找品牌客服更有效。
