2. **限定渠道类型**：  
   - 商超/精品超市：佳农通常属于品牌蕉，价格往往**不低于**同货架普通散装蕉；

   - 电商到家：还要看是否含配送、满减、会员价。
3. **限定城市和时间**：同一城市不同门店差异可能很大，跨城市比较没有意义。
4. **快速取样**：同一天、同一城市，记录  
   - 佳农香蕉：单价（元/斤）、规格、门店；  
   - 同店或周边3家店的普通香蕉：单价（元/斤）；

5. **经验判断（仅作方向参考，不是实时数据）**：佳农是品牌化、标准化程度较高的香蕉，通常在同类货架上会带一定品牌/品控溢价，**更可能偏高或持平，不太可能明显低于同店普通散装蕉**；但遇到促销时可能低于精品超市均价。
