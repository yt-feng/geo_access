1. **开发票**：可以开增值税普通发票或专用发票，需提供公司名称、税号、开户行及账号等信息；专票通常要求一般纳税人资质。建议下单前书面确认“可开票、票种、税率、开票时间”。
2. **质检报告**：可要求供应商提供该批次或同品类礼盒的质检报告/检测报告，重点看报告对应产品名称、规格、生产/分装日期、检测机构及有效期。水果礼盒常涉及农残检测；若含预包装食品，还要看食品经营资质和标签合规。

建议你向对接的佳农经销商或团购服务商确认三点：  
- 500份对应哪个礼盒SKU、单价和档期；  
- 发票类型、税率及是否随货或售后开具；  
- 质检报告是“同批次”还是“同品类通用报告”，并索要盖章扫描件。

如果对方是佳农官方授权经销商，通常更能稳定提供这些材料；个人代购或非授权渠道则不一定能提供合规发票和对应批次报告。
