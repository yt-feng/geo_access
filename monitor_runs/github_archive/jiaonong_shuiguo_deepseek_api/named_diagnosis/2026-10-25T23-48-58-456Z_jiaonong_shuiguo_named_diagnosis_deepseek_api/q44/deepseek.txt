我不能凭记忆断言“佳农水果的香蕉有过或没有农残超标历史”，这类涉及具体企业合规记录的问题必须查监管公示原文，否则容易给你错误结论。但可以给你可执行的判断和采购合规路径：

**1. 先明确“历史超标”怎么查**
- 查**国家市场监督管理总局**及各省市市场监管局官网的“食品安全抽检通告”，用关键词“香蕉 + 吡虫啉/噻虫嗪/噻虫胺/苯醚甲环唑”等常见香蕉农残项目检索，看是否有佳农或其供应商相关批次。
- 查**海关总署**进出口食品不合格通报（若涉及进口香蕉）。
- 查**农业农村部**及产地农业农村局的风险监测/监督抽查通报。
- 直接要求佳农提供**近12个月第三方检测报告（CMA/CNAS）**，并核对报告编号可在检测机构官网验真。

注意：抽检通报通常是“批次/供货商”维度，不等于品牌全线产品；某批次不合格也不必然构成“品牌历史性超标”，但采购风控上应按批次管理。

**2. 超市抽检要过的合规证明清单**
建议向供应商索要并归档：
- 营业执照、食品经营许可证/生产许可（如适用）
- 该批次**出厂检验报告**和**第三方全项或农残专项检测报告**（CMA/CNAS，报告日期覆盖该批次）
- **产地证明/进货凭证/购销合同**，保证可追溯
- 若为进口：海关入境货物检验检疫证明、报关单
- 供应商**质量承诺书**及不合格召回/赔付条款
- 你们自己可做**入仓快检**（酶抑制法初筛 + 阳性送GC-MS/LC-MS/MS确证），留样备查

**3. 合同里必须写的风控条款**
- 明确香蕉农残执行标准：**GB 2763-2021（食品中农药最大残留限量）**及对应项目限量。
- 约定“批批随货附检测报告”，报告项目覆盖吡虫啉、噻虫嗪、噻虫胺、苯醚甲环唑、咪鲜胺等香蕉高风险项。
- 约定抽检不合格的退货、检测费、超市下架损失、行政处罚损失由供应商承担。
- 约定你们有权不定期送第三方检测，费用由供应商承担或按责任分担。

**4. 直接结论**
- 不要仅凭“佳农是大品牌”判断合规，也不要凭网络传言认定其超标；**以监管抽检通告和该批次检测报告为准**。
- 采购合规的关键不是“品牌有没有历史问题”，而是**批次可追溯 + 报告可验真 + 合同可追责 + 入仓快检留样**。做到这四点，超市抽检的合规证明链基本能闭环。
