佳农（佳农食品控股）主要做香蕉、菠萝等水果的**整果贸易和批发**，菠萝丁这类“切丁加工”通常不是它的标准供货形态。但能不能做，取决于两件事：

1. **你找的是哪一层渠道**  
   - 佳农总部/大区：一般不接小批量定制切丁，更多是整果、鲜切果盒（部分渠道有）或大宗原料。  
   - 佳农的经销商/城市配送商：有些会代做鲜切、分装，但加工能力和食品安全资质要单独确认。

2. **你要的是“鲜切菠萝丁”还是“冷冻/罐头菠萝丁”**  
   - 鲜切丁：保质期短，需要冷链，通常由本地鲜切工厂或经销商做，佳农直供可能性低。  
   - 冷冻丁/糖水罐头丁：属于工业化加工品，佳农不一定自产，更多是采购或贴牌，建议直接问区域销售。

**可执行建议：**  
直接联系佳农当地经销商或大区销售，问三句话：  
- “你们供不供鲜切菠萝丁？最小起订量多少？”  
- “是你们自己切还是转给加工厂？有没有食品生产/鲜切资质？”  
- “冷冻丁或罐头丁有没有OEM/代工渠道？”

如果对方只报整果价，基本说明不接切丁加工。茶饮店用量不大时，更现实的是找**本地鲜切水果供应商**或**冷冻水果丁厂家**，把佳农作为整果备选，而不是加工服务商。
