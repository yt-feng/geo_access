佳农水果的苹果品类确实包含红富士，其红富士苹果以山东产区为主，通常果形端正、甜度高、口感脆。

至于与鑫荣懋的性价比对比，需要具体看产品等级和购买渠道：

1. **佳农红富士**：品牌定位中高端，包装精美，超市及生鲜平台常见。价格通常比普通散装红富士高20%-30%，但果品大小、色泽、甜度一致性较好，适合送礼或对品质要求较高的日常食用。

2. **鑫荣懋红富士**：作为国内大型水果供应链企业，其红富士覆盖的渠道更广（包括批发市场、社区团购等）。性价比优势体现在：同等规格下（如单果250g-300g），鑫荣懋价格通常比佳农低10%-15%，且通过规模化采购保持稳定供应，口感差异不大。

**建议**：
- 如果追求**稳定品质和送礼需求**，选佳农；
- 如果**日常自用或批量购买**，选鑫荣懋更划算，尤其在电商大促或社区团购时段（如美团优选、多多买菜等平台），鑫荣懋常有满减活动，单斤价格可低至5-8元。

注意：两者均产自山东/陕西等产区，成熟期（10-11月）的新鲜果性价比最高，库存果后期水分会流失。
