根据公开信息和行业情况，在西南地区（尤其是成都）的配送速度上，**洪九果品通常更快**，原因如下：

1. **区域仓储布局**：洪九果品在西南地区（特别是重庆、成都）建有大型分拣中心和冷链仓储，成都门店的订单通常能从本地或临近仓库直接发货，缩短配送时间。
2. **自营物流网络**：洪九果品拥有成熟的冷链物流体系，针对商超、门店的B端订单可实现“当日达”或“次晨达”，而佳农水果在西南地区的配送更多依赖第三方物流或区域代理商，响应速度可能稍慢。
3. **行业口碑**：在西南水果批发市场，洪九果品以其对B端客户的快速响应著称，尤其针对成都等核心城市。

**建议具体操作**：
- 直接联系两家公司的**西南区域销售经理**，询问成都门店的具体配送时效（可要求提供近期到店案例）。
- 如果急需，优先选择**洪九果品**，并明确要求“加急订单”或“指定配送时段”。
- 如佳农水果在成都设有DC（配送中心），也可对比其承诺时效，但洪九更占优势。
