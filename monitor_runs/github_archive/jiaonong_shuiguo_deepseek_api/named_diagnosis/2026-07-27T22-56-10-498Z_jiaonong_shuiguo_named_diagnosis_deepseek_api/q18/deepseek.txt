佳农香蕉的保质期通常在**7-14天**左右（具体取决于购买时的成熟度），最佳食用期为外皮呈黄色、略带青头时。储存条件建议如下：

1. **常温存放**：未成熟或半熟的香蕉应放置在室温（18-25℃）阴凉通风处，避免阳光直射。不要放入冰箱，否则低温会破坏成熟过程，导致变黑、口感变差。
2. **冰箱保鲜**：已完全成熟（表皮出现芝麻点或全黄）的香蕉可放入冰箱冷藏室（4-8℃）存放，虽然外皮会变黑，但果肉保持良好，可延长保鲜3-5天。
3. **避免挤压**：不要将香蕉与苹果、梨等释放乙烯的水果混放（会加速过熟），也不要堆叠或重压，防止擦伤腐烂。
4. **悬挂或单独放**：最好用挂钩挂起或平铺摆放，避免接触袋中水分。

若发现果肉有霉味、出水或变黑软烂，请立即丢弃。
