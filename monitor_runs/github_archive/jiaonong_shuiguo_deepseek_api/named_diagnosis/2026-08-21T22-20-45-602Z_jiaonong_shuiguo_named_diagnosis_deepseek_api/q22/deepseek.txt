**1. 佳农苹果品类概况**
佳农是知名的进口水果品牌，苹果品类主要走**中高端路线**，强调“产地直采”和“口感标准化”。
- **常见品种**：主要以**富士系**（如红富士、信浓金）和**嘎啦系**为主，也有少量青苹果（如澳洲青苹）。
- **特点**：通常比普通超市苹果个头更大、果面更光滑，甜度和脆度较稳定，但价格也偏高（通常论个卖或按精品礼盒装）。
- **供应链优势**：佳农在山东、陕西等国内苹果主产区有合作基地，同时也有全球采购网络。

**2. 是否有进口苹果？**
**有，但占比不高。**
- **主要进口来源**：佳农官方及商超渠道常见**美国（华盛顿州）**、**智利**和**新西兰**产苹果（如爱妃、爵士等高端品种）。
- **如何识别**：进口苹果包装上会有“原产国”标识，且通常带英文品种名（如Envy、Jazz）。
- **建议**：如果你追求特定进口品种（如新西兰爱妃），建议去**盒马、山姆或高端进口超市**专柜买，佳农普通商超专柜更多是国内精品果。
