**1. 常见的规格分级（按单根重量/长度）**
行业内通常按每根香蕉的**单果重**或**梳把长度**进行分级，大致分为：
- **特级/精品果**：单根重量约200克以上，果形直、长度≥22厘米，果皮光滑无瑕疵。
- **一级果**：单根180-200克，长度约20-22厘米，允许轻微斑痕。
- **二级果**：单根150-180克，长度约18-20厘米，适合加工或低端零售。
- **等外果**：重量、长度不达标，或有机械伤、病斑，通常用于做果泥或淘汰。

**2. 适合不同渠道的分级方向**
- **高端商超/精品水果店（如盒马、山姆、Ole'）**：倾向特级果，要求**全黄或黄中带绿**（便于上架后成熟），单把整齐，无药残，通常采用**盒装或贴标散装**。
- **普通连锁超市（如永辉、大润发）**：一级果为主，要求成熟度在**7-8成熟**（催熟后销售），允许果柄轻微干燥。
- **电商/社区团购**：往往使用一级或二级果，需耐运输，成熟度控制在**6-7成熟**（防压坏），包装需泡沫防震。
- **餐饮/烘焙/果汁店**：对颜值要求低，更关注出肉率，可用二级果或加工专用果。

**3. 关键分级指标（非官方但行业内通用）**
- **成熟度**：以淀粉转化为糖分程度分1-7成熟（出口常用“熟度计”）。
- **果指长度**（从果顶到果柄基部）：≥22厘米为优。
- **完好率**：无黑斑、无压伤、无裂果，果皮黄绿色均匀。
