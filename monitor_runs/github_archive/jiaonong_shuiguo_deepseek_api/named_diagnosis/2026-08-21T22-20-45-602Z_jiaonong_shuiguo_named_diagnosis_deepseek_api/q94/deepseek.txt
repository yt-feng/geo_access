**1. 佳农（及行业通用）的香蕉分级标准（大致框架）：**
香蕉分级通常依据以下指标，一级果要求最严格：
- **外观**：果皮颜色均匀（金黄、无严重黑斑或擦伤）、果型饱满、无畸形。
- **成熟度**：通常按“饱满度”或“成熟度指数”（如7-8成熟为标准）划分，一级果要求成熟度一致，避免过熟或未熟。
- **果指长度和粗度**：一级果的果指通常更长、更粗（例如标准长度≥20cm，粗度≥3cm），排列紧密。
- **病虫害和损伤**：无病虫害痕迹，无机械损伤（如挤压、擦伤）。
- **整把/整箱重量**：一级果单把重量和箱重更均匀。

**二级果**通常允许存在轻微外观瑕疵（如轻微斑点、果皮颜色不均）、果指略短或粗细稍不均，但不影响食用和整体商品性。
