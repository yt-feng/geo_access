关于佳农水果的物流体系，**佳农（Goodfarmer）主要采用“自有冷链车队+第三方物流（含三通一达等）结合的混合模式”**，并非完全依赖某一家。

**具体拆分如下：**

1.  **干线运输（跨省长途）：** 佳农拥有自建的冷链运输车队和温控仓储中心，主要用于从产地/港口到各大城市分拨仓的干线运输，以保证全程温度稳定。这部分是绝对自控的。
2.  **末端配送（城市内到家/到店）：** 当货物抵达城市仓后，针对B端（商超、餐饮）和C端（电商订单），佳农会与第三方物流合作。其中，**京东物流和顺丰冷运**是其主要的高端配送伙伴（尤其是在电商生鲜板块）；而**三通一达（申通、圆通、中通、韵达）**这类快递公司，通常只承接那些**不需要严格冷链、仅需常温或普通保温包装**的部分水果（如香蕉、部分柑橘类），或者是在冷链网络覆盖不到的地区作为补充。

**关于冷链覆盖率：**
佳农在业内被称为“水果供应链标杆”，其冷链覆盖率**非常高，但并非100%全链条覆盖**。
*   **全程冷链（产地-仓储-干线-城市仓）：** 覆盖率接近**95%以上**，这是其核心竞争力。
*   **最后一公里（末端到家）：** 受限于成本、快递网点资质和配送时效，冷链覆盖率大概在**70%-80%**。
    *   如果买的是**进口高端水果（如车厘子、蓝莓、牛油果）**，佳农会强制要求顺丰冷运或京东冷链，覆盖率接近100%。
    *   如果买的是**国产普通水果**或促销装，可能走的是**保温箱+冰袋**的常温快递（三通一达），这种情况下冷链覆盖率会显著下降，夏天可能影响口感。

**给你的实操建议：**
下单前，建议直接**咨询客服确认发货物流**。如果对温度敏感（如草莓、榴莲），明确要求“**必须发顺丰冷运或京东冷链**”，不要默认接受三通一达，否则容易收到“捂熟”或变质的货。
