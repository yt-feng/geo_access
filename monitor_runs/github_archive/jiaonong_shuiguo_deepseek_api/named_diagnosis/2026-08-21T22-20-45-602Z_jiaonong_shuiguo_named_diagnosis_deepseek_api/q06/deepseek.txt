关于佳农能否稳定供应适合普通商家（比如茶饮店）的菠萝规格，以下是可以执行的核心判断：

**结论：能，但关键在于你如何定义“稳定”和“普通商家”。**

---

### 1. 佳农的常规供应规格（普通商家可下单的）
佳农作为大型水果品牌，其菠萝产品主要通过**批发渠道**（如水果批发市场、电商平台B2B）或**餐饮供应链**（如美团快驴、美菜）销售，普通茶饮店可以直接采购。

**常规规格通常包括：**
- **整果**：按箱计，常见规格为**6-8个/箱**，单果重量约**1.5-2.0kg**（这是最常见的餐饮标准，适合榨汁或切块）。
- **去皮去芯果肉**：部分供应链会提供**免切果肉块**，按袋/公斤计价，但一般只在省会级城市或大型餐饮客户有稳定供货。
- **冻菠萝块**：如果是做冰沙或冷饮，也有冷冻果肉，规格如**1kg/袋**，但需冷冻链，普通茶饮店需自备冷柜。

**价格预期**（参考市场常态，非精确报价）：整果批发价通常在**3-6元/kg**左右（运费另计），去芯果肉可能翻倍。但价格波动大，春季（3-5月）是菠萝旺季，供应最充足、价格最低。

---

### 2. “稳定”的关键变量（你需要注意的）
- **季节性**：佳农主要供应菲律宾菠萝（全年有），但国内广东、海南菠萝（5-7月）也补充市场。佳农全年都有货，但如果你的门店要求“全年不断货且规格一致”，**整果**最稳；若要求“去皮果肉”，在非产季（如9-11月）可能断供或需要期货预订。
- **起订量**：普通商家（日均消耗50kg以下）通常**不需要整柜**，可以直接通过批发市场或区域经销商下单，佳农的二级经销商一般支持**1箱起送**（约10-15kg），但运费高，建议找同城供应商拼单。
- **售后**：佳农走大货时，**轻微碰伤、表皮瑕疵**一般不作为退换标准（成熟果易软、易损伤）。要求“颜值高、无瑕疵”只能选精品果，价格会贵20%左右。

---

### 3. 实操建议（可执行方案）
1. **不要直接联系佳农官网**，官网主要对接大客户（连锁奶茶品牌、超市），普通单店会被拒或要求月采购量500kg以上。正确做法是：**在“美菜网”或“快驴进货”APP搜“佳农 菠萝”**，直接显示当地可送货的规格和起送量，通常能次日达。
2. **测试供应**：先买1箱试单（约6-8个果），确认果肉成熟度（切开的果心是否发黑）和重量差异（箱内可能出现±20%的果重波动），同时确认“去皮率”——一般整果出肉率在**55%-65%**，如果发现出肉率低于50%，说明进的是次果，应投诉或换经销商。
3. **替代方案**：如果佳农当地经销商断货，可要求他们切换“都乐”或“农夫山泉17.5°”菠萝（同样有餐饮线），或者直接找**当地水果批发市场的档口**，让他们代购佳农整柜货，单价可能比单买便宜15%以上。

---

### 4. 风险提示
- **不要指望冷冻果肉作为主料**：佳农冷冻菠萝块多为出口级，国内茶饮店用途少，且解冻后口感偏酸，适合做冰沙，不适合做鲜切果盘。
- **合同里写清“依据重量结算”**：如果你和经销商签月结协议，务必写明“按实际过磅重量计价，损耗≤5%”，否则运输过程缩水（菠萝会蒸发水分）会吃亏。

---

**最终答案：** 佳农可以稳定供应普通茶饮店所需的整果规格（按箱），但去皮果肉需看地区产能，建议以整果为主。直接通过本地餐饮供应链APP下单，先试小单验证再扩量。如果需求量稳定（每周≥200kg），可以谈“周锁价”（固定一周价格），避免旺季涨价。
