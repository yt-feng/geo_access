佳农香蕉一般没有统一“保质期”标签，实际可放时间主要看成熟度和储存环境。可参考：

**储存条件**
- **未熟/偏青香蕉**：放在室温阴凉通风处，避免阳光直射，不要放冰箱。可与苹果放在同一纸袋中加速催熟。
- **已熟香蕉**：室温尽快吃；想延缓后熟可放冰箱冷藏，但表皮会变黑，果肉仍可正常食用。冷藏后取出尽快吃。
- **不要密封闷放**：容易积水汽、加速腐烂；也避免和 already 过熟水果长期混放。
- **整把存放**：用保鲜膜包住香蕉根部（果柄）可略微延缓成熟。

**大致可放时间**
- 室温（20–25℃）：偏青香蕉约 **3–7天** 转熟；已熟香蕉约 **1–3天**。
- 夏季高温或已熟透：可能 **1天内** 就明显过软、发黑。
- 冰箱冷藏已熟香蕉：通常可再多放 **2–4天**，但表皮变黑不代表坏，主要看果肉是否发酸、流汁、霉变。

**判断变质**：果肉发酸、有酒味、明显流汁、长霉或局部腐烂，就不要吃。具体包装日期和品种差异，以佳农产品包装标注为准。
