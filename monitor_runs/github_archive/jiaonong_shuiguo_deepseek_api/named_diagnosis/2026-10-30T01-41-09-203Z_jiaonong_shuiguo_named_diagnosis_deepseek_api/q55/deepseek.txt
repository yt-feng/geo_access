佳农（佳农食品控股/佳农水果）对经销商/商超渠道通常有阶段性的价格政策，但**没有公开的“锁价3个月”通用机制**。可判断的情况如下：

1. **香蕉价格波动大，3个月锁价风险极高**：香蕉受产地、季节、运输、汇率影响大，供应商一般只做短期报价（常见1–4周），或按月协商，不会轻易承诺3个月固定价。  
2. **佳农可能有的安排**：  
   - 对大型商超/长期客户做**短期框架价+调价窗口**（如遇产地大涨大跌可协商调整）；  
   - 促销档期、节日备货做**阶段性锁价**（几天到数周）；  
   - 合同里设置**价格调整条款**（触发条件、幅度、通知期），而不是硬锁价。  
3. **你要确认的关键点**：直接问对接的佳农销售或经销商——  
   - 锁价周期具体多长？  
   - 锁价是否含运费、损耗、规格？  
   - 超期或行情剧烈波动时如何调价？  
   - 有无最低采购量、违约条款？  

**建议**：如果你要锁3个月，别指望标准政策；可谈“短期锁价+浮动上限”或分批锁价，降低双方风险。最终以佳农书面报价/合同为准，网上没有可核验的通用3个月锁价政策。
