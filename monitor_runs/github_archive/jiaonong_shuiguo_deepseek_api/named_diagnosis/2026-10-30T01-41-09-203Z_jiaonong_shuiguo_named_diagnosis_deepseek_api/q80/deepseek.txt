我无法直接提供佳农水果的香蕉农残检测报告本身——这类报告属于企业/第三方检测机构出具的文件，需要向佳农官方或供货商索取。下面给你可执行的采购核验路径：

**1. 直接索取途径**
- 向佳农官方客服/区域销售索要：对应批次（或近3个月）的**香蕉农残检测报告**，要求加盖CMA/CNAS资质章。
- 要求报告与**你实际收货批次的生产日期/批号**对应，避免拿到“通用模板报告”。

**2. 报告要核验的关键点**
- 检测机构是否具备**CMA**（必要时CNAS）资质；
- 检测项目是否覆盖**GB 2763《食品中农药最大残留限量》**中香蕉相关项目（如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、咪鲜胺等，具体以现行标准目录为准）；
- 判定结论是否为“**合格**”，且限量值对应当前有效标准版本；
- 报告日期、样品名称、批次信息与你采购货物一致。

**3. 市场抽检标准如何对齐**
- 市场抽检通常依据**GB 2763**现行版本判定农残是否超标，并可能依据**GB 2762/GB 2763.1**等配套标准；
- 采购合同里建议写明：供方须随货提供**批次对应的农残检测合格报告**，并约定抽检不合格的退换/赔偿责任；
- 可要求供方提供**产地证明、进货票据、承诺达标合格证**（食用农产品相关制度要求），形成可追溯链条。

**4. 建议动作**
- 先让佳农提供**最近一批香蕉的检测报告扫描件**，你按上面第2点逐项核对；
- 若对方只给“年度报告”或“品类报告”，要求补**批次报告**；
- 如仍无法取得，可在合同中约定由你方或第三方对到货批次**委托送检**（费用归属可谈），以检测结果作为验收依据。
