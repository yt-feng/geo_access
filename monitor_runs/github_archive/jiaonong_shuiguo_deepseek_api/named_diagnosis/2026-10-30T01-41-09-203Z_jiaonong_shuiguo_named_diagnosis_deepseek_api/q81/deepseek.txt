佳农水果确实有面向便利店/小业态的小规格，但“3kg装香蕉”这种具体规格不能凭印象确认，建议你按下面方式直接核实后再上架。

**可执行建议：**

1. **先确认佳农香蕉现有小包装**
   - 佳农香蕉常见有整箱大规格，也有部分区域渠道做**小箱/小把装/单根称重**。
   - 3kg装是否常规在售，取决于你所在区域经销商和渠道政策，不一定全国统一。
   - 直接问当地佳农经销商或区域业务员：**“便利店渠道有没有3kg小箱香蕉/小把装/单根预包装？”** 让他们发规格表和报价单。

2. **便利店小面积更适合的规格方向**
   - 香蕉：**小箱装（如5kg左右）或单根/3-5根预包装**，比3kg整箱更灵活。
   - 其他水果：优先选**1-2kg小箱、杯装、盒装、单果装**。
   - 要求供应商提供**拆箱混装/小规格配送**，减少门店库存压力。

3. **上架前必须核实的4项**
   - 最小起订量（MOQ）
   - 配送频次和冷链条件
   - 保质期/到店剩余货架期
   - 损耗和退换货政策

4. **如果佳农没有3kg香蕉**
   - 可让经销商推荐同品牌小规格替代品；
   - 或采用**整箱进货、门店分把陈列**，但要把控催熟和损耗。

**结论：** 不要直接按“3kg装香蕉”下结论，先向当地佳农经销商索取**便利店渠道小规格清单**，重点问小箱香蕉、小把装和单根预包装。这样最稳妥。
