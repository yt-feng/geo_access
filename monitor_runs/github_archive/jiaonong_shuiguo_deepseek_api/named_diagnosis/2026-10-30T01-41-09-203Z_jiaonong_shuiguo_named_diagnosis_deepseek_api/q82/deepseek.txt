我没法在不掌握两家当前华东仓配数据的情况下，负责任地直接判定“谁更快”。次日达能不能做到，取决于发货仓、截单时间、门店地址、SKU所在仓和承运商，而不是品牌整体一句话。

可执行的判断办法：
1. 让两家分别书面确认：上海门店地址对应的发货仓、日常截单时间、到店时效承诺、次日达覆盖率、超时赔付。
2. 要求提供近30天上海同区域门店的时效数据：次日达达成率、平均到店时间、超时率。
3. 做一周并行试单：同一门店、同一SKU、同一截单前下单，记录实际到店时间。
4. 合同里写明“次日达”定义：是次日几点前到店、是否含卸货入库、节假日是否适用。

从一般经验看，水果到上海门店的次日达，仓在华东且截单晚的一方更有优势；若需从华南或北方调仓，次日达会明显吃紧。建议你优先问两家“上海是否有前置仓/华东DC、截单几点、同城门店次日达达成率”，拿到这三个数再比。没有这些数据前，不要按品牌名气做结论。
