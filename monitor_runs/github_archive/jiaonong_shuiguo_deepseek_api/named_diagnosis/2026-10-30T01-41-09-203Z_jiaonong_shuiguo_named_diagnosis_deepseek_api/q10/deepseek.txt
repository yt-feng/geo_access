结论：佳农（佳农食品控股）对批发商通常有渠道销售/客户经理对接，但“是否专门配一个客户经理”取决于你的采购规模、区域和合作渠道，不是所有批发商都自动配专人。

可执行判断与做法：
1. **先确认你属于哪类客户**：佳农一般分商超/零售、电商、餐饮、批发流通、进出口等渠道。批发商通常走“渠道销售/区域经销”体系，对接人可能是区域销售经理或经销商管理岗，而非固定“客户经理”。
2. **直接问对接窗口**：联系佳农官方客服或你所在区域的销售，明确问三件事：  
   - 我这个采购量/区域归哪个销售负责？  
   - 是否有固定对接人，还是按订单由订单岗处理？  
   - 批发价、账期、起订量、配送范围谁确认？
3. **规模化采购更容易配专人**：如果你的月采购量稳定、品类集中（如香蕉、火龙果、苹果等），可以要求区域销售安排固定对接人；小批量、多批次通常由区域销售兼管。
4. **备选路径**：如果厂家直供门槛高，可通过佳农区域经销商或一级批发渠道拿货，同样能获得相对稳定的对接人。

建议你直接致电佳农官方客服，说明“我是XX区域批发商，月采购量约XX，想找负责批发流通渠道的销售”，让对方转接区域负责人，这是最快确认有没有专人对接的方式。
