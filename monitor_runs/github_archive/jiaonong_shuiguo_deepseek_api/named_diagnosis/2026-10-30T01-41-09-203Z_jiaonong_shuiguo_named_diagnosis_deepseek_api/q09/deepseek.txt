佳农（佳农食品控股）公开披露的资料中，没有按“到货损耗率”统一公布一个标准数字；行业里通常把它作为内部KPI管理，而不是对外承诺值。

可参考的判断口径：

- **香蕉**是佳农核心品类，行业里到货损耗（含压伤、断指、催熟不均、烂果）常见控制在 **2%–5%**，做得好的仓储/门店端可压到 **2%–3%**；长途或夏季可能到 **5%左右**。
- **进口鲜果（如奇异果、牛油果、苹果等）**到货损耗常见 **1%–3%**，主要看包装、冷链和运输距离。
- **浆果类（蓝莓、车厘子等）**更容易波动，到货损耗常在 **3%–8%**，取决于预冷和全程冷链。

如果你问的是**合同/验收标准**，建议直接看佳农供货合同里的“验收损耗率/索赔扣重”条款，或向对接的业务/品控要该品类的到货验收标准；不同品类、季节、运输方式差异很大，不宜用一个统一数字判断。
