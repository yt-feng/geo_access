佳农水果的售后总体属于“生鲜电商里比较规范”的一档，但体验取决于你从哪个渠道买：官方旗舰店/自营平台通常处理更顺，第三方店铺或社区团购则看商家执行。

**到货有坏果，建议这样处理：**

1. **先别急着扔，拍照留证**  
   - 坏果整体照 + 切开/局部特写照  
   - 快递面单、外箱、整箱合照  
   - 最好拍一段开箱视频（很多平台理赔需要）

2. **尽快联系购买渠道客服**  
   - 天猫/京东/抖音等平台：订单页申请售后，选“腐烂/坏果/质量问题”，上传照片  
   - 社区团购/团长：直接找团长登记  
   - 官方旗舰店：找店铺客服，说明坏果数量

3. **明确诉求**  
   - 少量坏果：一般按坏果数量比例退款或补发  
   - 坏果较多：可要求整单退款或补发  
   - 注意生鲜通常不支持“七天无理由”，但质量问题可以理赔

4. **保留证据直到处理完**  
   客服可能要求补充照片或视频，坏果先别丢。

**判断标准：**  
- 正规渠道一般 24 小时内响应，按坏果比例赔付较常见；  
- 如果客服拖延，可在平台发起售后并申请平台介入；  
- 到货先开箱检查，别放几天再找，生鲜理赔通常有时效要求。

一句话：**拍照留证、尽快找购买渠道、按坏果比例谈退款或补发**，比直接找品牌方更有效。
