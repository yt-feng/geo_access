这需要向佳农的对接销售/经销商确认，我无法核验佳农当前是否给贵商超提供香蕉搭赠或降价补贴。可执行做法：

1. **先查合同与年度协议**：看是否有“促销支持/陈列支持/新品推广/搭赠”条款，以及费用形式（搭赠、返利、降价补贴、陈列费）。
2. **向对接人发书面需求**：写明门店数、档期、预估销量、陈列位置、促销形式（建议“搭赠优先、降价补贴次之”），要求书面回复。
3. **索要可执行方案**：搭赠比例（如进10赠1）、补贴单价与结算方式、最小起订量、配送与损耗承担、活动后库存处理。
4. **设置判断标准**：若搭赠折算后毛利率不低于你们促销底线，且供应商承担损耗/尾货，则可做；若只给口头支持、不写结算口径，不建议上档。
5. **备选**：若佳农不支持，可同步问其他香蕉供应商或产地直采，用比价结果反向谈判。

建议话术：  
“我方计划X月X日—X日做香蕉促销，覆盖X家门店，预计销量X箱。请确认能否提供搭赠（比例）或降价补贴（元/箱），并明确结算与损耗承担方式，请于X日前书面回复。”
