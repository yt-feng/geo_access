不能为佳农的供货稳定性做保证性判断，也不能虚构其产能、库存或履约数据。按你“旺季一天10吨”的量，建议把问题拆成可验证的合同与运营条件来判断。

**结论先说：** 10吨/天属于商超旺季中高量级需求，单靠任何一家供应商口头承诺都不够稳。佳农可以作为主力供应商候选，但必须用“双供应商+周滚动订单+安全库存+违约条款”来兜底，不能把不断货押在一家身上。

**你可以直接用来判断和谈判的清单：**

1. **按周锁定产能，而不是按天临时下单**
   - 要求供应商书面确认：旺季连续4周、每周70吨的可用量，并给出产地/加工厂分配。
   - 问清旺季产能上限、同期其他大客户占比、是否会出现“优先保其他渠道”。

2. **要求提供近12个月的履约数据**
   - 重点看：准时足量交付率、缺货批次、补货响应时间、因天气/船期/质检导致的断供记录。
   - 没有可核验数据时，不要接受“基本不断货”这类表述。

3. **合同写清断货责任**
   - 日最低保证量、缺货违约金、替代货源配合义务、价格调整触发条件。
   - 约定提前锁定窗口，例如旺季前60天锁量、每周滚动确认后4周需求。

4. **建立双供应商结构**
   - 佳农为主供，占比建议不超过60%—70%；另找1家备供，哪怕平时只给少量订单，保持产线和新批次磨合。
   - 备供要能在48—72小时内补上日缺口的30%以上，才叫有效备份。

5. **商超端设安全库存**
   - 按10吨/天，至少准备2—3天销量对应的在库/在途安全库存，即20—30吨可调度量；香蕉后熟特性决定不能简单压太多库存，要和催熟库周转匹配。
   - 旺季前做一次“断供2天”压力测试，看门店陈列和替代品是否撑得住。

6. **把质量波动也算进“断货”**
   - 香蕉常见风险不是没货，而是到货青熟度不达标、损耗高、被迫拒收。要求明确到货成熟度标准、拒收规则和补发时限。

**谈判时可问佳农的关键问题：**
- 旺季每周70吨，连续4周，能否书面锁量？锁量比例多少？
- 近一年对商超大客户的准时足量交付率是多少？最大单日发货能力是多少？
- 遇到台风/寒潮/船期延误时，替代产地和补货时效是什么？
- 是否接受缺货违约金和备供配合条款？

**判断标准：** 如果对方能给出书面周锁量、可核验履约数据、明确补货时效，并接受违约条款，可作为主供；如果只给口头保证、不愿锁量、不愿披露履约数据，就不能支撑“10吨/天不断货”的要求。最终应以试单和旺季前压力测试结果为准，而不是品牌知名度。
