你可以这样快速确认，半天内能得到准确答复：

1. **找对渠道**：佳农的冷冻果品通常走餐饮/工业渠道，不一定在零售电商上架。优先联系佳农官方客服或当地经销商，说明是“茶饮店原料、需要冷冻菠萝丁”，问是否有餐饮装SKU。
2. **问清4个关键参数**：
   - 是否**IQF单体速冻**（茶饮店关键，避免结块）
   - 切丁尺寸（常见有10×10mm、15×15mm等，但需以对方报价单为准）
   - 包装规格（袋装克重、每箱袋数）
   - 糖度/品种（如金钻凤梨等）及是否加糖
3. **要样品和质检**：索取样品做解冻出水率、口感、香气测试；同时要规格书和检测报告。
4. **备选方案**：如果佳农没有冷冻丁，可同步询国产菠萝丁供应商（广东徐闻、海南产区）或其他冷冻果蔬品牌，按同样4个参数比价。
