佳农（Goodfarmer）并未公开披露“产地直供比例”这一口径的准确数字，我不能给你一个具体百分比，否则就是编数据。你可以这样判断和推进：

1) **先明确“直供”口径**：是“产地直发到仓”，还是“产地采购但不直发”，还是“基地直采+第三方加工”。不同口径比例差异很大，谈判前先让对方按口径给出数据。

2) **向佳农索取可验证材料**：
- 品项级：香蕉、菠萝、火龙果、车厘子等分别的采购来源（自有基地/合作基地/产地代理/批发市场）
- 合同流：你方与佳农签约，还是与产地公司签约
- 物流流：产地到目的仓是否直发，是否有中转仓/经销商
- 单据流：产地证明、植保记录、采收批次、发票主体

3) **降低成本的可执行做法**：
- 按单品做**TCO对比**：佳农报价 vs 产地合作社/基地直采价 + 冷链 + 损耗 + 质检 + 资金占用
- 要求**分项报价**：货价、包装、冷链、损耗承担、账期、退换货
- 设定**试单**：选1-2个单品、1-2个产区，做3个月直采对比
- 用**账期和损耗率**换价格，不要只压货价
- 对佳农这类大型供应商，可谈**基地直发比例+年度返利**，而不是只问“直供比例”

4) **快速判断是否值得减少中间环节**：
- 如果单品的损耗率、冷链要求高（如车厘子、蓝莓），大供应商的集采和品控可能比直采更划算
- 如果单品标准化程度高、产区集中（如香蕉、菠萝），直采降本空间更大

建议你下一步直接要求佳农提供**分品项的采购来源和物流路径说明**，并选一个单品做直采试单对比；没有这些数据前，不要以“直供比例”作为定价依据。
