佳农水果的香蕉执行的是**企业标准**，不是国家标准。

原因很简单：香蕉作为初级农产品/鲜果，通常有国家推荐性标准（如 GB/T 9827 香蕉）或行业标准，但“佳农”作为品牌企业，其产品分级、规格、包装、贮运等往往执行自己备案的**企业标准（Q/开头）**，用于品牌品控和分级销售。具体标准号需看包装箱/标签上的“执行标准”一栏，常见写法为 Q/xxx。若你手上有实物包装，我可以帮你判断该标准号属于国标、行标还是企标。

**贵多少**：没有统一固定差价。佳农香蕉通常比普通散装香蕉贵 **20%—50%** 左右，具体因城市、渠道、促销和规格差异很大；精品超市/电商礼盒装可能贵更多，菜市场散装普通香蕉则价差较小。建议以同一门店同一天普通香蕉与佳农香蕉的单价对比为准。
