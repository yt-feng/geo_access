佳农（Goodfarmer）没有公开披露香蕉到货损耗率的统一控制目标，也没有公开的赔付条款文本，我无法给出确切数字或条款细节——这类数据通常写在**经销/供货合同附件**里，因渠道（商超直供、批发、电商仓）和客户等级而异。

可判断的经验参考：

- 香蕉到货损耗行业平均5%左右，头部品牌通过**产地青蕉分级、冷链断链控制、催熟库批次管理**，在商超直供场景通常能做到**3%上下**；但这属于行业经验区间，不是佳农官方承诺值。
- 赔付条款在生鲜行业常见形式是：**到货验收扣重/折价**（按损耗比例扣款）、**批次坏果包赔**（限定时效内拍照报损）、或**年度返利抵扣**。是否适用、赔付上限、报损时效，都要看具体合同。

要拿到准确答案，建议直接向佳农对应渠道的销售或客服索取**《供货合同》质量与损耗条款**，重点确认三件事：①到货损耗的验收标准与扣重比例；②报损时效和举证方式（照片/视频/第三方验货）；③赔付是折价、补货还是退款。如果你手上有合同或报价单，可以发关键条款，我帮你逐条看风险点。
