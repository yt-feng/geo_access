无法确认佳农是否对茶饮店客户提供“去皮切块”的定制加工服务，这取决于你对接的是佳农哪个渠道（原果批发、餐饮渠道、经销商）以及当地加工能力。建议你按下面方式快速判断和落实：

1. **先问清对接主体**
   - 如果你是从佳农官方餐饮/茶饮渠道或区域经销商进货，直接问：是否支持 **去皮、切块、真空/冷链配送**，最小起订量、加工费、保质期、配送半径。
   - 如果是从批发市场拿货，通常加工服务由档口或第三方净菜厂提供，不是佳农统一服务。

2. **确认你要的是哪种“加工”**
   - **鲜切冷藏**：适合茶饮店，但保质期短，需冷链，通常有最小批量。
   - **冷冻果块**：更适合稳定出品，但风味和出汁与鲜果不同。
   - **仅去皮整果/半成品**：比鲜切块更常见。

3. **直接可用的询问话术**
   “我们茶饮店计划用佳农菠萝，需要去皮切块、冷链配送。请问你们是否提供鲜切加工？最小起订量、加工费、保质期、配送范围分别是多少？如果不提供，能否推荐合作的净菜加工厂？”

4. **备选方案**
   - 找当地**净菜加工厂/中央厨房**代加工，按你的规格切块并冷链配送。
   - 让经销商协调“原果+代加工”模式。
   - 先小批量测试鲜切块的出品稳定性，再决定是否长期合作。

结论：**不能直接假定佳农提供该服务，需向具体对接的佳农渠道确认；若官方不提供，优先找本地净菜加工厂或让经销商协调。**
