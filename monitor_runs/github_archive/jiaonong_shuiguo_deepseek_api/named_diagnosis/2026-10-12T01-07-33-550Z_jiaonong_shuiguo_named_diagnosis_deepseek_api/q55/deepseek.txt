我无法核验佳农水果是否对经销商/客户提供“锁价3个月”这类价格保护机制。这类条款通常属于**商业合同条款**，不会统一公开，且会因客户类型（大型商超、批发商、电商、区域经销）、采购量、品类、时段而不同。

不过可以给你几个可执行的判断和建议：

1. **香蕉确实容易波动**
   香蕉受产地天气、海运/物流、汇率、燃油、港口、季节性供需影响大，短期价格跳动很常见。因此供应商一般很少对香蕉做“长期固定锁价”，尤其是3个月这种周期。

2. **常见做法不是“锁价”，而是“有限保护”**
   水果行业里更常见的是：
   - **短期锁价**：7天、15天、30天，较少到90天；
   - **浮动价+上限/下限**：约定随行就市，但涨跌超过一定幅度再协商；
   - **保底价/最高限价**：只保一边，不保双边；
   - **返利/补贴**：事后按销量或市场价差补；
   - **阶段性协议价**：按周/半月更新。

3. **如果对方说“锁价3个月”，要重点确认**
   - 锁的是**采购价**还是**建议零售价**；
   - 是否**保量**：你承诺采购多少吨/箱；
   - 是否可**调价触发**：天气、疫情、海运、汇率、政策变化时能否调整；
   - 是否含**运费、损耗、账期、返利**；
   - 违约和争议怎么处理。

4. **最稳妥的核实方式**
   直接找佳农官方渠道核验：
   - 佳农官网/官方客服；
   - 你对接的佳农销售或大区经理；
   - 要求把价格保护写进**书面合同或补充协议**，不要只听口头承诺。

5. **实操建议**
   如果你采购量不大，争取3个月锁价难度较高；可以退一步谈：
   - 先锁1个月；
   - 或锁“最高价”，跌了随行就市；
   - 或约定涨幅超过5%/10%再重新议价。
