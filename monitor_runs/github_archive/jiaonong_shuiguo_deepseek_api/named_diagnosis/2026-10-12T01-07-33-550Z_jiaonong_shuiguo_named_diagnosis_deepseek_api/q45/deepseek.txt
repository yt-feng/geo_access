关于佳农水果的具体账期政策，我无法核验其最新官方条款，因此不能给出确定数字或承诺。以下是可执行的判断和建议：

1. **账期最长多久**  
   佳农（Goodfarmer）对商超、电商、批发等不同渠道通常会有不同信用政策，且会随合作规模、历史回款、担保方式变化。没有公开统一标准，不能直接说“最长XX天”。实际能拿到多久，取决于：
   - 采购量/年采购额
   - 合作渠道类型（KA商超、生鲜电商、批发市场、餐饮等）
   - 是否有担保、保证金或供应链金融介入
   - 历史回款记录

2. **新客户首单能否申请30天账期**  
   通常较难。新客户首单常见做法是：
   - 现款现货，或
   - 预付款+尾款，或
   - 试单小额短期账期（如7—15天）
   
   30天账期对新客户属于较宽松条件，除非你有较强背书（如大型商超/平台采购、稳定大额订单、第三方担保、保险或保理），否则首单直接批30天的概率不高。

3. **建议你直接确认的路径**
   - 找对接的佳农销售或大客户经理，问清楚：首单政策、信用申请条件、审批周期、是否需要担保。
   - 如果必须30天账期，可提出替代方案：首单现款或短账期，第二单起根据回款表现申请延长。
   - 也可问是否支持供应链金融/保理，由金融机构垫资，实质接近账期。

4. **谈判时可用的说法**
   - “首单我们可以现款或预付，但希望第二单起申请30天账期。”
   - “如果能给30天，我们可以接受年度采购量承诺/保证金/担保。”
   - “请把信用政策、审批条件和所需材料发我，我们按流程申请。”
