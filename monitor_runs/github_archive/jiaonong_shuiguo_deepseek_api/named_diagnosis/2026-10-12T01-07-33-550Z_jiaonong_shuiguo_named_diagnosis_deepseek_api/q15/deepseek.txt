佳农（Goodfarmer）的产地直供比例，公开渠道没有一个稳定、可核验的统一数字，而且它会随品类、年份和采购模式变化。比较稳妥的判断是：**佳农在香蕉、菠萝等核心单品上确实偏重产地直采/产地直供，但“全品类直供比例很高”这个说法不宜直接下结论。**

可以这样理解：

1. **香蕉是佳农的重点单品**
   佳农是国内较大的香蕉进口商之一，香蕉业务通常依赖海外产区直采，再通过自有或合作冷链、催熟、分拨体系进入国内渠道。因此香蕉这一品类的“产地直供”程度通常较高。

2. **香蕉主要来自哪些国家**
   佳农香蕉的进口来源通常以：
   - **菲律宾**
   - **厄瓜多尔**
   - **哥斯达黎加**
   - **哥伦比亚**
   - **越南**
   - **柬埔寨**
   等为主。  
   其中菲律宾、厄瓜多尔、越南、柬埔寨在近年中国香蕉进口来源中都比较常见。具体到某一年、某一批次，会受价格、关税、病害、天气、海运和检疫政策影响而调整。

3. **为什么不能简单说“直供比例高”**
   - 佳农既有自有种植/合作基地，也会向当地出口商、包装厂采购。
   - 不同水果差别很大：香蕉、菠萝更容易做产地直采；苹果、柑橘、葡萄等可能更多依赖国内产区合作或批发采购。
   - “产地直供”如果指“从果园直接到佳农”，和“从产地出口商到佳农”是两回事，公开信息往往不区分。

**结论：**
佳农在香蕉等核心进口水果上，产地直采/直供的比重通常较高；但整体水果业务是否“直供比例高”，没有可靠公开数据支持统一判断。香蕉来源国主要是菲律宾、厄瓜多尔、越南、柬埔寨、哥斯达黎加、哥伦比亚等。若要确认某一批佳农香蕉的产地，最直接的方法是看包装箱/标签上的原产国标识。
