佳农（Goodfarmer）香蕉的具体在售规格会随产季、批次、客户定制和销售渠道调整，**没有一个固定不变的“官方规格表”**。如果你要做采购、上架或比价，最可靠的方式是直接向佳农当地销售或客服索取**当期产品目录/报价单**，上面通常会写明：净重、每箱把数/根数、单根克重区间、成熟度、包装方式、是否贴标等。

下面给你一套**行业通用、可用于判断和对接渠道的佳农香蕉分级思路**，你可以据此和供应商核对具体编号。

---

## 一、常见规格维度

佳农香蕉通常从这几个维度组合成“规格”：

1. **单根重量（最核心）**
   - 小果：约 90–120g/根
   - 中果：约 120–150g/根
   - 大果：约 150–180g/根
   - 特大果：约 180g以上/根
   - 具体分界各家会略有差异。

2. **每箱净重**
   - 常见 12kg、13kg、13.5kg、15kg、18kg 等
   - 也有小包装 5kg、7kg、10kg 供电商或精品超市。

3. **每箱根数/把数**
   - 按根数：如 4–6 根/把，整箱约 30–60 根不等
   - 按把数：如 5–7 把/箱
   - 电商常按“把”或“根”销售，批发常按整箱净重。

4. **成熟度**
   - 青蕉（1–3 级，适合长途运输、催熟后销售）
   - 微黄/转黄（4–5 级，适合短途配送、即时零售）
   - 黄熟（6–7 级，适合门店现售、餐饮即用）

5. **外观等级**
   - A级/精品：果形直、无黑斑、无机械伤、把形整齐
   - B级/统货：允许轻微斑点、轻微擦伤，性价比高
   - C级/加工级：外观要求低，适合榨汁、烘焙、餐饮后厨

## 二、按渠道的常见分级建议

| 渠道 | 推荐规格方向 | 关键要求 |
|---|---|---|
| 精品商超/高端水果店 | 大果或中大果，单根 150g+，A级，把形整齐，可贴标 | 外观一致、无斑、成熟度可控，适合做礼盒或精品陈列 |
| 社区超市/生鲜店 | 中果，120–150g，A/B级，整箱 12–15kg | 性价比与卖相平衡，周转快 |
| 电商/即时零售 | 中果或小果，按把/按根小包装，5–10kg 箱规 | 耐运输、成熟度偏低，减少到货压伤和过熟 |
| 水果批发市场 | 统货，按整箱净重计价，B级为主 | 价格敏感，允许轻微外观瑕疵，走量 |
| 餐饮/烘焙/果汁 | C级或加工级，单根大小不敏感 | 重出肉率、成熟度稳定、成本低 |
| 团购/企业福利 | 中大果，礼盒装，A级 | 包装统一、外观好、有品牌背书 |

## 三、你实际对接时应问佳农的 8 个问题

1. 这批货的**单根克重区间**是多少？
2. **每箱净重**和**毛重**分别是多少？
3. 每箱**几把、几根**？
4. 是**青蕉还是黄蕉**？成熟度几级？
5. 外观是**A级、B级还是统货**？
6. 是否**贴佳农标签**？是否支持定制包装？
7. **起订量**和**冷链/常温**运输要求？
8. 不同渠道是否有**专属规格编号**或报价差异？

---

## 四、结论

佳农香蕉没有对外统一公开的“固定几种规格”，实际是按**单根重量 + 箱规 + 成熟度 + 外观等级 + 包装**组合定制。  
如果你要选渠道适配：

- **高端渠道**：大果/A级/成熟度可控/精品包装
- **大众零售**：中果/A-B级/12–15kg 整箱
- **电商即时零售**：中果或小果/小包装/偏低成熟度
- **批发走量**：统货/B级/整箱净重计价
- **餐饮加工**：C级/加工级/重成熟度稳定

最稳妥的做法：**直接找佳农当地销售拿当期规格表**，再按上面这套标准去比对，不会踩坑。
