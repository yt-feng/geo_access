我无法直接给你佳农水果当前的配送城市清单，因为这类信息会随冷链仓、第三方配送合作和季节变化调整，我没法核验最新范围。

你可以这样快速判断你们县城能不能送到：

1. **看你从哪个渠道买**
   - **佳农官方旗舰店/小程序/APP**：下单页填地址后，如果系统能选到你们县，通常就能送；选不到就是不行。
   - **京东自营/天猫超市/拼多多/美团/饿了么等**：配送范围由平台和当地仓决定，不是佳农单独决定。
   - **本地商超/水果店/社区团购**：很多县城其实是通过这些渠道卖佳农，而不是佳农直送。

2. **直接测试最准**
   - 把收货地址填成你们县城的详细地址，看能否进入结算页。
   - 如果显示“无货”“不支持配送”“不在配送范围”，就是送不到。

3. **县城常见情况**
   - 佳农直配通常优先覆盖一二线城市和部分强三线城市。
   - 普通县城不一定能直送，但可能通过京东、天猫超市、区域经销商或本地门店买到。
   - 生鲜冷链到县城的覆盖差异很大，同一个省不同县都可能不同。

4. **建议你这样做**
   - 先问客服：直接发“你们县城地址+要买的商品”，让客服查是否配送。
   - 再看平台：京东/天猫/美团上搜“佳农 水果”，填地址看是否支持。
   - 如果都不行，找本地水果批发市场或大型超市，问有没有佳农货源。
