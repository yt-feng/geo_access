佳农（Fresh Del Monte 旗下都乐/佳农体系，具体以你对接的公司主体为准）在 B 端原料上通常有两种合作方式，但**不是所有菠萝丁规格都由佳农自营加工**，需要按你的规格确认。

**一般情况：**
1. **他们能提供菠萝丁/菠萝块**：佳农给茶饮、烘焙、餐饮渠道供过冷冻或常温菠萝丁、菠萝碎，多数是代工或指定工厂加工，不一定是佳农自己工厂切丁。
2. **整果和加工品是两条线**：佳农强项是菠萝整果（金菠萝、都乐金菠萝等）种植和贸易；切丁、速冻、糖渍、罐头类更多走合作加工厂。
3. **能不能做“定制加工”要谈**：比如你要的尺寸（5×5mm、8×8mm）、糖度、是否速冻、是否糖水浸渍、包装规格（1kg/袋、5kg/袋）、保质期和冷链条件，这些属于定制，通常有起订量要求。

**建议你这样问佳农对接人，能快速判断：**
- 有没有现成的**冷冻菠萝丁**或**糖水菠萝丁**，规格和报价发一下；
- 如果没有现成规格，**能不能按我们尺寸和糖度代加工**，起订量多少；
- 是佳农自产还是指定代工厂，**工厂资质、检验报告、SC 证**能否提供；
- 样品多久能到，**样品是否收费**；
- 供货是**冷冻冷链**还是常温，到店解冻后状态如何。

**如果佳农只给整果或起订量太高，替代方向：**
- 找**冷冻水果丁专业加工厂**，广东、福建、广西、山东比较多；
- 找**菠萝罐头/糖水菠萝丁**供应商，开罐即用，适合茶饮；
- 找**本地水果批发商 + 中央厨房代切**，适合小批量但保鲜期短。

结论：佳农**大概率能供菠萝丁，但多为合作加工或特定规格，不一定接小批量定制**。最稳的做法是直接问对接业务员要“冷冻菠萝丁/糖水菠萝丁”的现成规格和代加工起订量，别只问“能不能加工”，否则容易被绕。
