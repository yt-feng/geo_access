**1. 专车配送**
- 香蕉属于易催熟、怕挤压、对温度敏感的水果，连锁餐饮若单次需求达到整车量或区域多店集中配送量，供应商通常可以安排专车。
- 如果单店需求量小、门店分散，供应商更可能是“干线冷链 + 城配”或“区域仓分拨”，未必每店专车直送。
- 你需要先确认：单次订货量、配送频次、门店分布、是否要求恒温/控温、是否需要按门店分拣。

**2. 专人对接**
- 对连锁餐饮客户，规模供应商一般会配销售负责人或大客户经理，但“专人”可能只是商务对接，不一定包含售后、品控、物流调度都专人。
- 建议在合同或服务确认单里写清：对接人姓名/职务、响应时间、异常处理时限、谁负责催熟度调整和到货验收。

**3. 向佳农核实时要问的关键问题**
- 是否承接餐饮连锁香蕉供应，最小起订量是多少？
- 能否专车配送？专车是整车直送还是区域仓中转？
- 配送温度、到货成熟度、损耗赔付标准是什么？
- 是否配置固定对接人？对接人权限和响应时效如何？
- 能否先做小批量试配，再签长期框架协议？
