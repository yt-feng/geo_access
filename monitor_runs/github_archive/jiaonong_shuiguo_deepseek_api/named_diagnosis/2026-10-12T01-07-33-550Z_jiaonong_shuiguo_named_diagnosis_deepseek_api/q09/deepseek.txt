佳农水果（佳农食品控股）并未公开披露统一、固定的到货损耗率标准，具体数值通常取决于品类、运输方式、季节和客户合同约定。以下是行业层面的参考判断：

- **普通水果（苹果、梨、橙等耐储品类）**：到货损耗率一般控制在 **2%–5%**。
- **易损水果（香蕉、芒果、草莓、蓝莓、葡萄等）**：到货损耗率通常放宽到 **5%–10%**，部分全程冷链且包装较好的订单可压到 **5% 以内**。
- **进口长途运输（如南美香蕉、东南亚水果）**：由于运输周期长，到货损耗率可能在 **8%–15%**，具体看航程、温控和港口周转。

需要注意：

1. 佳农作为供应商，通常会在合同中与商超、电商等客户约定**验收标准**，比如“到货损耗不超过 X%”，超出部分按补货或扣款处理。
2. 实际损耗还受**装卸次数、最后一公里配送、门店收货标准**影响，同一批货在不同渠道的认定结果可能不同。
3. 如果你要的是合同或内部考核用的具体数字，建议直接向佳农业务对接人索取该品类的**验收协议或质量协议**，那才是可执行的标准。
