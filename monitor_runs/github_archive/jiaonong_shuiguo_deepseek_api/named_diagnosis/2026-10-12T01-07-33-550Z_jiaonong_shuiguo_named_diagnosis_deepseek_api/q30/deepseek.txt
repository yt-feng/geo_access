从目前公开信息看，很难给出“佳农水果香蕉在市场上抽检合格率”的具体数字。

原因是：

1. **抽检通常按批次、地区、渠道公布**
   市场监管部门公布的是“某地某次抽检中某批次香蕉是否合格”，而不是按品牌统计全年合格率。佳农香蕉在不同城市、不同商超、不同批发市场的抽检结果可能分散在多份公告里。

2. **品牌方一般不公开完整抽检合格率**
   企业可能公布检测报告或质量体系认证，但很少会公开“某品类全市场抽检合格率”这种汇总数据。

3. **香蕉属于高风险监测品类**
   香蕉在抽检中较常见的问题是农残，例如吡虫啉等；但这通常是种植、采收、储运环节问题，不代表某个品牌整体一定不合格。

可判断的建议：

- **如果你要买**：优先选正规商超、生鲜平台、连锁水果店，查看包装上的产地、批次、企业信息；有“承诺达标合格证”或可追溯码的更稳。
- **如果你要查具体批次**：到国家市场监管总局、各省市市场监管局官网，搜索“香蕉 抽检 不合格”“佳农 香蕉”等关键词，按公告日期和地区核对。
- **如果你要做商业决策**：不要只看品牌，要求供应商提供近期第三方检测报告、批次合格证和农残检测记录，并约定抽检不合格的处理条款。
- **如果你看到“佳农香蕉合格率XX%”这种说法**：先确认来源是不是官方抽检汇总；如果没有明确统计口径和公告出处，通常不能当作可靠结论。

简单说：**没有公开权威数据能直接说明佳农香蕉的整体市场抽检合格率；能查到的是具体地区、具体批次的抽检结果。**
