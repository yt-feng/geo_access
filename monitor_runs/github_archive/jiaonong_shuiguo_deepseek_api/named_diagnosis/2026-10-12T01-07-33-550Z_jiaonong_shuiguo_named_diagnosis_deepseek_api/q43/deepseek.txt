我无法直接确认佳农是否提供锁价合同、锁价期限多久、是否接受10吨/月的体量——这些属于具体商务政策，需要直接问佳农官方渠道才能确认，我编不出来。

不过可以给你一套判断和谈判的实操思路：

**先确认你要的是哪种“锁价”**
- 固定价格合同：约定未来一段时间单价不变，风险全在供应商，通常只有大客户或长期合作才给。
- 价格区间/封顶价：约定最高不超过某价，跌了随行就市，供应商较容易接受。
- 基价+浮动公式：以某个公开指数或产地收购价为基准，加固定加工费，双方共担波动。
- 期货/远期锁价：通过期货市场对冲，适合标准化程度高的原料（菠萝原料如果是浓缩汁、果浆等较标准品，可行性更高）。

**跟佳农谈之前先准备好这些数字**
- 月度10吨、年度约120吨的稳定采购量，这是你最大的筹码，要明确告诉对方你能给的是“全年稳定量”而不是随时可能断。
- 你过去12个月的采购价区间、最高价、最低价，以及你能承受的价格上限。
- 你的替代方案：有没有第二家供应商、能不能接受进口菠萝或替代品种，这决定你谈判时腰杆硬不硬。

**直接去问这几个问题**
1. 你们对月采购10吨以上的客户，是否提供固定价或封顶价合同？期限是3个月、6个月还是1年？
2. 锁价是否需要预付定金、最低采购量或年度保底量？
3. 如果市场价格下跌，锁价合同能否重新议价？有没有价格调整机制？
4. 交货方式、品质标准、违约条款怎么定？

**现实提醒**
- 茶饮用的菠萝原料如果指鲜果，锁价难度很大，因为鲜果损耗、季节性、产地天气影响大，供应商一般不愿意长锁。
- 如果是菠萝浓缩汁、果浆、冷冻果肉这类加工品，锁价可能性明显更高，因为加工品标准化程度高、库存可调节。
- 别只盯一家。同时问2-3家（比如佳农、其他果蔬供应链企业、产地直采），拿到报价再回头谈，锁价成功率会高很多。
