佳农（Goodfarmer）主要做香蕉、菠萝等水果的种植、进出口和批发分销，通常以**整果、鲜果**形式供货，面向商超、批发市场和餐饮渠道。它一般**不提供面向茶饮店的去皮切块代加工服务**——这类定制化加工（鲜切、分装）更多是专业鲜切工厂或供应链服务商在做。

**建议你这样确认和解决：**

1. **直接问你的佳农供应商或区域销售**  
   明确问：是否有“鲜切菠萝”“去皮切块”的SKU，或能否做定制加工。不同区域、不同客户规模，政策可能不一样，只有对接人能给准信。

2. **如果没有，考虑两条路**  
   - **自己加工**：买整果，门店或中央厨房去皮切块。成本低，但要考虑人工、损耗和食品安全规范。  
   - **找鲜切供应商**：直接采购已经去皮切块的冷冻或冷藏菠萝块，省人工、标准化程度高，适合茶饮店稳定出品。

3. **注意两点**  
   - 茶饮用菠萝如果要**冷冻块**，口感和出汁和鲜切会有差异，建议先小批量测试。  
   - 鲜切水果涉及冷链和保质期，选供应商时要看对方的资质和配送稳定性。

简单说：**佳农大概率不直接做代加工，但可以问供应商有没有鲜切产品线；没有的话，就找专业鲜切厂或自己处理。**
