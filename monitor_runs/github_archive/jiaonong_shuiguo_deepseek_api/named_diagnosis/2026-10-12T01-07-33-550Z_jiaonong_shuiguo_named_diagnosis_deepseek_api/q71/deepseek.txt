这两家都是进口香蕉里做得比较大的品牌，但**佳农和都乐的价格关系并不是固定的“谁一定便宜”**，批发场景下尤其要看几个变量。

直接说结论：**多数常规情况下，佳农在同规格进口香蕉上比都乐略便宜，但一箱通常也就差几块到十几块，走量时这个差距会被规格、产地、熟度、到货批次、账期和返利放大或抹平。**

具体拆一下：

**1. 谁更便宜，不能只看品牌**
同样叫“佳农香蕉”“都乐香蕉”，实际可能来自不同产地（菲律宾、厄瓜多尔、越南等）、不同等级（一级/二级/散把/整把）、不同规格（如 12kg、13kg、18斤、20斤）。  
- 同产地、同规格、同等级对比，佳农通常有一定价格优势。  
- 但都乐在做促销、清柜、大客户返利时，可能反而比佳农便宜。  
- 如果都乐是菲律宾货源、佳农是越南或厄瓜多尔货源，价格差会更大，不能简单说品牌谁便宜。

**2. 一箱能便宜几块？**
按批发走量常见情况，粗略范围是：  
- 同规格同等级对比：**佳农比都乐便宜约 3～10 元/箱**比较常见。  
- 促销或大客户政策下：可能只差 **1～3 元/箱**，甚至打平。  
- 如果都乐有返利、账期、搭赠，实际到手价可能反超佳农。  
- 如果规格不同，比如一箱 12kg 对 13kg，单纯比“箱价”没意义，要折成**每公斤价**。

**3. 批发商真正要比的不是“箱价”**
你走量，建议按这个口径比：

**实际到手每公斤成本 =（含税进货价 - 返利 - 搭赠折算 - 账期资金成本）/ 实际净重**

重点看：
- 是否含税、是否开票
- 返利是月返、季返还是年底返
- 有没有搭赠、破损补损
- 账期多久，现款和账期价通常不一样
- 到货熟度，太生或太熟都会影响损耗
- 损耗率和出成率，香蕉批发损耗能差很多

**4. 实操建议**
你可以直接向两边供应商要同一口径报价：  
- 同产地  
- 同等级  
- 同规格净重  
- 同账期  
- 同到货市场  
- 含税/不含税分开报  
- 返利和搭赠写清楚

然后算每公斤到手成本，而不是只问“一箱便宜几块”。

如果只能给一个经验判断：**佳农在常规批发价上对都乐往往有优势，但一箱差距通常不大，走量时更可能体现在返利、账期和稳定性上，而不是单纯箱价便宜多少。**  
真正能便宜几块，必须拿你当地当周的两边报价单来核。
