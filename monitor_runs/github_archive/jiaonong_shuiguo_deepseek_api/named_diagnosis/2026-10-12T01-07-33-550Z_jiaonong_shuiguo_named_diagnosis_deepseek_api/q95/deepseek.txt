佳农（Goodfarmer）的产地直供比例属于其供应链内部经营数据，公开渠道通常不会披露精确百分比，我无法核验具体数字，不能给你一个可靠的“XX%”答案。直接对外宣称的比例也可能随品类、季节、港口/口岸和年份变化。

但你的核心目标是“减少中间环节、降低成本”，这个不依赖佳农披露比例也能推进，给你一套可执行的判断和谈判方法：

**1. 不要只问“直供比例”，改问可验证的供应链结构**
向佳农或任何供应商索取以下信息：
- 该品类的主要产区（国家/省份/农场/合作社）
- 是自有基地、合作基地，还是市场采购
- 从产地到你这边的完整链路：产地 → 加工厂 → 出口商/贸易商 → 进口商 → 批发/配送 → 你
- 每个环节由谁负责、开票主体是谁
- 是否支持产地直发、港口直提、区域仓直配

**2. 判断“中间环节能否砍掉”的硬指标**
- 你能否直接与产地加工厂或出口商签约，而不是只和国内贸易公司签
- 报价是否包含产地到港、清关、仓储、分拣、配送，能否拆分
- 起订量（MOQ）是否允许你绕过区域批发层
- 账期、汇率、关税、损耗由谁承担
- 是否可指定品牌包装/规格，避免二次分装加价

**3. 降本优先级（通常比“追求直供比例”更有效）**
- 集中品类和规格，提高单品类采购量，换更低的产地价
- 直接对接产地出口商或一级进口商，减少一层贸易加价
- 用港口直提/产地直发替代区域仓中转
- 锁定产季长约，平抑旺季溢价
- 统一包装规格，减少分拣和二次包装成本
- 对比“佳农直采”与“产地出口商直采”的到岸总成本，而不只是看采购单价

**4. 你可以直接向佳农提出的问题清单**
- 这个SKU的产地是哪里？是自有基地还是合作基地？
- 从产地到我们仓库经过几手？每一手的加价项是什么？
- 如果我们要做产地直发/港口直提，最小起订量和价格怎么变？
- 能否提供FOB/CIF/到仓价的多档报价？
- 哪些品类你们能真正做到产地直供，哪些必须经过市场采购？
- 能否把清关、仓储、配送拆开报价，让我们选择自营或外包？

**5. 务实结论**
佳农作为大型水果供应链企业，部分核心品类大概率有较强的产地直采/基地合作能力，但“产地直供比例”不会是一个统一数字，也不会轻易公开。你更应该用**链路透明度、报价拆分、MOQ、直发能力**来验证，而不是等一个比例。
