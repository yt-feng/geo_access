我不能直接核实佳农官方是否有“餐饮渠道专用”的菠萝切片/切块定制规格，因为这属于企业具体产品线和渠道政策，且会随区域、客户体量、季节变化。但你问的核心可以拆成两件事来判断：

**1）佳农有没有面向餐饮的菠萝产品？**
从公开常识看，佳农主营进口香蕉、菠萝等水果，确实有做批发、商超和部分餐饮供应链。菠萝本身也是餐饮常用原料。因此它大概率有面向B端的产品，但是否叫“餐饮渠道定制规格”、是否单列SKU，需要向当地销售确认。

**2）切片/切块这种定制是否可能？**
有可能，但通常分几种情况：

- **鲜切菠萝**：如果要做切片/切块，一般属于鲜切加工品类，对冷链、保质期、微生物控制要求高，不是所有水果贸易商都自己做。
- **冷冻菠萝块/菠萝丁**：餐饮渠道更常见，尤其是饮品、烘焙、披萨、炒饭等场景，规格通常按尺寸（如10mm丁、20mm丁、切片厚度）和包装（1kg/袋、10kg/箱）定。
- **整果+门店自切**：很多餐饮供应链其实只供整果，由中央厨房或门店自己切，这样成本更低、损耗可控。
- **定制规格**：通常有起订量门槛，比如按箱/按吨，且要签年度框架或区域经销协议，小客户未必能单独定制。

**建议你这样确认，最快最准：**

1. **找佳农当地餐饮渠道销售或经销商**，直接问三句话：
   - “有没有鲜切菠萝片/菠萝块，还是只有整果？”
   - “餐饮渠道最小起订量是多少？按箱还是按吨？”
   - “规格能不能定：切丁尺寸、切片厚度、包装克重、是否冷冻/冷藏？”

2. **要产品规格书**：让销售发PDF或图片，重点看：
   - 原料：鲜果还是冷冻果
   - 形态：整果/去皮整果/切片/切丁/碎块
   - 尺寸：厚度、边长
   - 包装：袋装/箱装、净重
   - 储存：冷藏/冷冻/常温
   - 保质期和冷链要求

3. **如果佳农没有合适规格**，可以同步问：
   - 佳农经销商能否代切
   - 当地中央厨房或净菜加工厂能否用佳农菠萝代加工
   - 其他餐饮供应链品牌（如鲜切水果供应商、冷冻果蔬供应商）是否有标准菠萝丁/片

**结论：**
不能确定佳农一定有“餐饮渠道菠萝切片/切块定制规格”，但这类需求在餐饮供应链里很常见，佳农或其经销商有可能提供鲜切或冷冻规格，也可能只供整果。最稳妥的方式是直接联系佳农当地B端销售，要求提供餐饮渠道产品规格书，并确认起订量和定制条件。
