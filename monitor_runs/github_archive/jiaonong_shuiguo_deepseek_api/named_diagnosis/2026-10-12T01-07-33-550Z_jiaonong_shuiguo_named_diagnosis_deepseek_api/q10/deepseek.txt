有的，佳农一般会对批发商这类客户安排客户经理或销售对接，但“专门”到什么程度要看你的采购规模和合作模式。

通常情况是这样：

- **大型批发商 / 连锁渠道 / 稳定大批量采购**：一般会有专门的客户经理或区域销售负责人对接，负责报价、订单、账期、售后、促销政策等。
- **中小批发商 / 新客户**：可能先是区域销售或渠道经理对接，合作稳定、量上来后再转为更固定的对接人。
- **零散采购或刚起步**：可能通过客服、区域销售电话或经销商体系对接，不一定一开始就配专属客户经理。

如果你想知道自己能不能拿到专门对接，建议直接这样问佳农官方渠道：

1. **“我们是批发商，月采购量大概多少，能不能安排固定客户经理？”**
2. **“负责我们区域的销售是谁？后续订单、售后找谁？”**
3. **“有没有批发客户专属政策，比如账期、返点、冷链配送、退换货？”**

最有效的方式是打佳农官方客服电话，或通过官网/公众号找“渠道合作”“批发采购”“区域销售”入口，直接说明你是批发商和大概采购量。这样对方通常会把你转给对应区域的客户经理。
