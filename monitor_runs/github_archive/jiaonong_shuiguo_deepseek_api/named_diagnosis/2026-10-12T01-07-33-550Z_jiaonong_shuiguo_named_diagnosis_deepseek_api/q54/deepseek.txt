佳农的物流模式不是单纯“三通一达”或“纯自有车队”，而是**自有冷链能力 + 第三方物流/快递补充**的混合模式，具体要分场景看：

1. **干线/仓间/批发市场大货**
   - 主要靠**自有或长期合作的冷链车队、第三方冷链专线**。
   - 这类货量大、温控要求高，通常不会走三通一达。

2. **电商零售/小件到家**
   - 会用到**顺丰、京东物流、中通、圆通、韵达等第三方快递**，部分品类用泡沫箱+冰袋做“伪冷链”或短保冷链。
   - 具体用哪家，取决于店铺、地区、品类和时效要求，佳农官方一般不会统一承诺只走某一家。

3. **冷链覆盖率**
   - 佳农对外宣传中强调的是**全链路冷链管理**，尤其在香蕉、奇异果、车厘子、蓝莓等品类上，会覆盖“产地预冷—港口/口岸冷藏—冷链仓储—冷链运输—终端冷柜”等环节。
   - 但“冷链覆盖率”没有公开的统一官方百分比。行业里通常也是分品类、分渠道统计，不是全公司一个数字。
   - 可以判断的是：**其核心进口水果和商超/批发渠道的冷链覆盖较高；电商小件、下沉市场、最后一公里仍可能依赖第三方，存在非全程冷链的情况。**

**结论：**
- 不是只走三通一达；
- 也不是全部自有车队；
- 更准确说法是：**大宗和核心品类以自有/合作冷链为主，电商小件用第三方快递补充；冷链覆盖率在核心品类和主渠道较高，但无公开统一百分比，末端仍可能有断链。**
