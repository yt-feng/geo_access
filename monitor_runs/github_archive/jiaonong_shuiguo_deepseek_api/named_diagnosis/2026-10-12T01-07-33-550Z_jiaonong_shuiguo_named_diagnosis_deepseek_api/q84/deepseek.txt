**1. 佳农企业标准怎么查**
- 企业标准通常以“Q/”开头，备案后可在**企业标准信息公共服务平台**（国家市场监管总局系统）按企业名称“佳农”或关联公司名称检索。
- 也可直接向佳农客服/供应商索取其执行标准号，包装或合同上一般会标注“执行标准：Q/***”。
- 只有拿到标准原文，才能比较糖度、果指长度等具体限值。

**2. 国标层面可确认的要点**
- 香蕉相关国家标准主要有 **GB/T 9827《香蕉》** 等（具体版本以现行有效为准）。
- 国标通常按**等级**（如优等、一等、二等）规定：
  - **果指长度**：不同等级有最低长度要求，等级越高要求越长；
  - **可溶性固形物/糖度**：一般设最低值，作为成熟度和品质参考；
  - **其他**：色泽、饱满度、缺陷、机械伤、病虫害等。
- 但国标的具体数值会随版本和等级变化，需查现行版本原文，不能凭记忆给准确数。

**3. 企业标准与国标常见的差异方向**
在能拿到佳农标准原文的前提下，通常从这几项判断：
- **糖度**：企业标准可能高于国标最低线，或按不同渠道/成熟阶段分档；
- **果指长度**：企业标准可能比国标更细，按规格分档（如不同果指长度对应不同包装/售价）；
- **综合指标**：企业标准往往还会增加外观、单果重、整齐度、到货成熟度等要求。
