**1. 香蕉中国的"国标"是什么**

国内香蕉相关标准主要有几类，容易混淆：

- **产品/质量标准**：如 GB/T 9827《香蕉》（推荐性国标，规定等级、外观、规格等）。
- **安全限量标准**：如 GB 2763《食品中农药最大残留限量》、GB 2762《食品中污染物限量》等，这些是**强制性**的，任何企业标准都不能低于它。
- **食品安全国家标准 水果类**：涉及农残、污染物、致病菌等强制指标。

注意：GB/T 是**推荐性**标准，企业可以选择执行或制定更严的企业标准；但只要涉及食品安全限量，**强制性国标是底线，企业标准不得低于**。

**2. 企业标准与国标的关系（法律规则）**

按《标准化法》：
- 企业可以制定严于国标、行标、地标的企业标准。
- 企业标准**不得低于强制性国家标准**的相关要求。
- 企业标准需在企业标准信息公共服务平台（qybz.sac.gov.cn 之类官方平台）自我声明公开。

所以理论上，佳农的香蕉企业标准**可能等同、也可能严于** GB/T 9827 这类推荐性标准（比如在糖度、果指长度、成熟度、外观缺陷容忍度、冷链时限上设更高要求），但**不可能低于**强制性的农残、污染物等安全标准。

**3. 怎么判断"是否比国标高"**

只看结论没用，要看具体维度。企业标准通常不会全面"高于国标"，而是**在个别商业化指标上更严**，例如：
- 果指长度、粗度、单果重区间更窄（利于统一包装）；
- 可溶性固形物（糖度）下限更高；
- 外观缺陷、机械伤、病虫害容忍比例更严；
- 成熟度/催熟后货架期要求；
- 冷链温度与时限规定更细。

这些属于**商品化/品质指标**，和国标比"高"要逐项对照，不能一句"比国标高"概括。
