佳农水果的配送时效取决于你下单的渠道和收货地址，没法给一个统一答案。可以按下面几种情况判断：

**1. 电商平台（京东、天猫、拼多多等）**
- 通常由平台仓或佳农合作仓发货，走快递。
- 一般 **1–3 天**送达，偏远地区可能 **3–5 天**。
- 具体时效以下单页显示的“预计送达时间”为准，这是最准的。

**2. 生鲜即时零售（美团、饿了么、京东到家等）**
- 如果附近有商超或前置仓有货，通常 **30 分钟–2 小时**送达。
- 取决于门店距离和骑手运力。

**3. 社区团购 / 预售**
- 多为次日达或隔日自提，按团购页面标注的到货日为准。

**4. 佳农官方渠道**
- 佳农主要是水果供应链品牌，直销配送较少，多数是通过商超和平台卖。若有官方小程序/旗舰店，以其页面承诺时效为准。

**怎么快速确认自己的单：**
1. 打开下单的 App，看订单详情里的“预计送达”。
2. 看发货方式：快递 vs 同城配送，时效差别很大。
3. 生鲜类通常对时效敏感，超过预计时间可联系平台客服催单或申请售后。
