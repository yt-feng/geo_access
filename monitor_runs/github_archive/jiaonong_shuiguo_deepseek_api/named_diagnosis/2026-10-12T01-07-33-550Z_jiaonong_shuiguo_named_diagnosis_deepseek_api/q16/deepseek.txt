不过生鲜类水果坏果的处理，一般可以按下面这套流程做，基本适用：

**1）先别急着扔，保留证据**
- 拍开箱视频或照片：外包装、快递单、坏果特写、整箱全景。
- 最好把坏果和好果分开摆，能看出坏的数量和比例。
- 保留快递单号和订单信息。

**2）尽快联系客服**
- 生鲜通常有“签收后24小时内反馈”的时效要求，越早越好，别拖到几天后。
- 通过购买平台的订单页找“申请售后/联系客服”，而不是只找快递。

**3）常见处理方式**
生鲜水果一般不支持无理由退货，但坏果通常按以下方式处理：
- **按坏果数量比例退款**：最常见，比如坏了几颗退几颗的钱。
- **补发**：部分店铺会补发坏掉的部分。
- **整单退款/重发**：坏得特别多（比如过半）时可能整单处理。
- 通常**不需要你把坏果寄回**，因为生鲜寄回没意义，但会要求你提供照片/视频证明。

**4）如果客服不处理**
- 在平台内发起“售后/投诉”，让平台介入。
- 电商平台一般偏向消费者，证据齐全时成功率较高。
- 保留聊天记录，必要时走平台官方客服。

**几个关键提醒**
- 时效最重要：多数生鲜售后要求签收后24小时内反馈，超时容易拒赔。
- 证据要全：没有开箱证据，客服可能以“无法确认是运输还是存放问题”为由少赔或不赔。
- 看渠道：京东自营、天猫旗舰店通常售后更规范；第三方店铺或低价拼团渠道，执行标准可能差一些。
