佳农（Goodfarmer）主要是水果供应链/品牌商，不是面向个人消费者的全国性生鲜配送平台。它的“配送覆盖”通常分两类，需要先确认你问的是哪一种：

1. **面向商超/门店/经销商的B端配送**
   - 一般通过区域经销商、批发市场、商超仓配体系覆盖。
   - 覆盖范围通常以城市或区域仓能力为准，不是按“全国每个县城都能直送”来承诺。
   - 你们县城门店能不能送到，取决于当地是否有佳农经销商、城市仓、配送商，或你从哪个B端渠道下单。

2. **面向消费者的C端购买**
   - 佳农在天猫、京东、抖音等平台有旗舰店/店铺时，通常走平台快递或平台冷链，不是佳农自己全国直送。
   - 是否送到你们县城，要看下单平台显示的可配送范围，以及该商品是否支持冷链到县。

关于“县城门店能不能送到”：
- 如果是你们自己的门店要进货：建议直接联系佳农官方客服或区域销售，问“是否有覆盖你所在县城的经销商/城市仓，起送量多少，能否冷链直送门店”。
- 如果是在电商平台买给个人：把收货地址填成你们县城，看结算页是否可选、是否显示冷链配送。显示能下单并承诺时效，通常就能送；显示“不支持配送”或只能普通快递，就说明该渠道不到或不做冷链。

关于冷链物流收费：
佳农没有公开统一的全国冷链收费标准，实际通常按以下方式计费：
- **按重量/件数计费**：如每公斤、每箱、每托收费。
- **按里程/区域计费**：同城、省内、跨省不同价。
- **按温层和车型计费**：冷藏车、冷冻车、保温箱+冰袋成本不同。
- **加收费用**：偏远地区、县城/乡镇、上楼、等待、卸货、返程空驶等可能加收。
- **B端常见**：达到一定起送量可免运费或包邮到仓；未达起送量收配送费。
- **C端常见**：平台包邮或满额包邮，冷链费已含在商品价或运费模板里。

给你一个可执行判断：
1. 先确认你是**门店进货**还是**个人购买**。
2. 门店进货：找佳农官方或区域经销商，报你所在**省+市+县+门店地址+需求量+是否需要冷藏/冷冻**，让对方给“能否送、几天到、起送量、运费”。
3. 个人购买：直接在京东/天猫/抖音等平台把地址填到你们县城，看结算页是否支持配送和冷链时效。
4. 如果对方只说“全国可发”但没写县城冷链，默认要追问：**到县还是到镇？是否冷藏车？是否送货上门？破损/化冻怎么赔？**
