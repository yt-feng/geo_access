佳农（Zespri 旗下无此业务，佳农即 Goodfarmer）的香蕉在产地采收时为青果，长途运输和到货后通常使用**乙烯气体催熟**，而不是单纯自然熟。商超端要控时间，核心是控制“乙烯浓度 + 温度 + 湿度 + 通风”，而不是等它自然变黄。

简要判断和操作建议：

1. **工艺类型**
   - 商业香蕉基本都走人工催熟。
   - 常用催熟剂是**乙烯气体**，或释放乙烯的催熟剂（如乙烯利在果柄处理，但主流气调库用乙烯气）。
   - “自然熟”在商超供应链里很少作为可控工艺，因为时间不稳定。

2. **催熟时间主要看温度**
   - 温度越高，转色越快，但易发软、风味差。
   - 温度越低，转色越慢，易出现“青皮熟”或冷伤。
   - 常规商超/催熟房参考：
     - **18–20℃**：较慢，约 5–7 天转黄
     - **20–22℃**：常用，约 3–5 天转黄
     - **22–24℃**：较快，约 2–4 天转黄
   - 具体还要看香蕉到货成熟度、品种、产地和催熟库条件。

3. **商超控催熟时间的实操点**
   - 到货先分青度：1–2 级青果和已微黄的不能同库催。
   - 催熟房温度建议稳定在 **20–22℃**，相对湿度 **85%–95%**。
   - 乙烯处理一般 **24 小时左右**，浓度按催熟设备说明控制，常见在 **100–150 ppm** 范围，具体以佳农或设备商给的参数为准。
   - 乙烯处理后要**通风排乙烯**，再进入转色库。
   - 转色期温度可略降到 **18–20℃**，延缓过熟，方便门店排面。
   - 每天检查果指颜色、果柄和硬度，按“绿→微黄→黄→黄带糖斑”分级出货。

4. **如果你要问佳农的具体参数**
   - 最稳妥是直接找佳农对应区域经销商或客服，要这批货的**到货青度、建议催熟温度、乙烯浓度、处理时长、转色库温度**。
   - 不同批次、不同季节、不同海运/陆运时长，参数会变，不能只按固定天数。

5. **简单判断**
   - 如果商超到货是青香蕉，想几天内整齐转黄，基本就是人工乙烯催熟。
   - 如果完全不处理、只放常温，转色慢且不齐，不适合商超做稳定排面。

一句话：佳农香蕉商超端通常是乙烯催熟；控时间优先控温度，20–22℃ 常用，乙烯处理约 24 小时，之后转色库 18–20℃ 延缓过熟。具体批次参数建议直接向佳农索取。
