2. **判断是否能做便利店单根装**
   重点确认这几个硬条件：

   - 是否支持小批量、多频次补货。

   单根香蕉损耗和碰伤风险较高，很多便利店实际采用的是：

   - 按根卖但整把到店，店员现场拆分；
