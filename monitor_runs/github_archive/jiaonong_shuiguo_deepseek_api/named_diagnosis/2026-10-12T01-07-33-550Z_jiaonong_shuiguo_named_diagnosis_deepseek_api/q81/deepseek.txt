抱歉，我无法核验佳农当前在你们区域实际供应的小包装规格，所以不能直接确认“有没有3kg装香蕉”这种具体SKU。这类信息变动快，且不同渠道/地区供货方案不同。

可以这样快速确认和落地：

1. **直接找佳农当地经销/业务确认**
   - 问清楚：香蕉、苹果、橙子等主力单品有没有 **2kg/3kg/5kg** 小箱或小包装。
   - 重点问：**最小起订量、是否可混搭、配送频次、损耗/售后**。

2. **优先考虑“便利店友好”规格**
   - 香蕉：常见有 **3kg、5kg** 左右小箱，但并非所有渠道都有。
   - 苹果/橙子：常见 **2kg、3kg、5kg** 小箱。
   - 小门店更适合：**小箱+高频补货**，而不是一次性压大货。

3. **如果佳农没有合适小包装**
   - 让经销商做 **拆箱分装** 或 **组合装**。
   - 先试销 **3kg香蕉+2kg苹果/橙子** 这类小组合，测动销。
   - 也可以同时对比其他品牌的小规格果品，避免被单一供应商限制。

4. **上架前先算清3个指标**
   - 毛利率：小包装通常单价高，但损耗也高。
   - 周转天数：香蕉最好 **1-3天** 内动销。
   - 损耗率：超过 **8%-10%** 就要谨慎。

建议你直接联系佳农当地业务，明确问一句：**“我们门店小，能不能供3kg香蕉和其他2-3kg小包装？最小起订量和配送频次是多少？”** 这样最快能拿到可执行答案。
