我不能直接提供佳农水果香蕉的农残检测报告，因为这属于厂商/供应商出具的质量证明文件，我这边无法调取或生成真实报告。

但针对你“采购需要符合市场抽检标准”的需求，可以给你一套可执行的做法：

1. **向谁要**
   - 直接找佳农官方销售/区域经销商/对接业务员。
   - 要求提供：**对应批次**的农残检测报告，而不是只给一份通用版或过期版。
   - 如果是进口香蕉，还要看是否附带入境货物检验检疫证明、海关相关单证。

2. **要什么内容**
   报告上至少要能对应：
   - 产品名称：香蕉
   - 供应商/生产商
   - **批次号/生产日期/采收或包装日期**
   - 检测项目：常见农残项目及限量要求
   - 检测依据：如 GB 2763 等适用标准
   - 检测结果：合格/不合格，具体数值
   - 检测机构：CMA/CNAS 资质更稳妥
   - 报告编号和签发日期

3. **怎么判断能不能用于市场抽检**
   - 报告必须能追溯到**你采购的那一批货**。
   - 检测项目要覆盖你当地市场监管抽检常查的农残指标。
   - 报告应在有效期内，且检测机构有资质。
   - 最好是第三方检测，不是供应商自己内部出的“自检单”。
   - 如果对方只能给“同款产品历史报告”，不能对应批次，风险较高。

4. **采购合同里建议加条款**
   - 供应商随货提供对应批次合格检测报告。
   - 如市场抽检不合格，供应商承担退货、赔偿及行政处罚相关损失。
   - 明确适用标准：GB 2763、GB 2762 等。
   - 明确异议复检机制和检测费用承担。

5. **如果对方不提供**
   - 要求书面说明原因。
   - 可自行送第三方检测，费用可在合同中约定由供应商承担或分摊。
   - 对高风险批次可先抽检再放行。
