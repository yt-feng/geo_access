关于佳农水果的配送时效，具体时间取决于**下单平台**（如佳农官方小程序、天猫旗舰店、京东自营等）、**收货地址**和**所选配送方式**。通常情况如下：

1. **一线及省会城市（顺丰/京东冷链）**：大多数订单在**下单后48小时内**发货，发货后**1-2天**送达（偏远地区3-5天）。
2. **普通快递（非冷链）**：如遇促销或非生鲜商品，可能2-4天发货，全程约**3-6天**。
3. **当日达/次日达**：极少部分大城市特定区域（如上海、北京）的佳农直营店或平台自营商品支持，需查看商品页是否标注“次日达”。

**建议操作**：请在购买页面的“配送信息”或“预计送达时间”栏查看实时预估，该处会因库存和物流政策实时变动，通常是最准确的。如果下单后系统未显示具体时间，可联系在线客服提供订单号查询。

**注意**：我无法实时查询具体订单状态，若遇延迟（如天气、疫情、节假日），建议以物流跟踪信息或客服答复为准。
