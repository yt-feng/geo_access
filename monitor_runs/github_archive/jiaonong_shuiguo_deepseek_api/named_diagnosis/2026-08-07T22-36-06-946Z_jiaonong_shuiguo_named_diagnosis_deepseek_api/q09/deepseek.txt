佳农水果作为大型水果供应商，其到货损耗率并没有一个统一的公开数值，因为损耗率会根据**水果品类**、**运输距离**、**季节温控**以及**仓储周转速度**有显著差异。

但根据行业通用标准和佳农的供应链管理能力，可以给出以下参考范围：

- **整体综合损耗率**：一般控制在 **3% - 8%** 之间（指从产地到客户仓库或门店的运输及短存损耗）。
- **高价值/易腐品类**（如草莓、蓝莓、车厘子、荔枝）：损耗率通常控制在 **5% - 10%**，在常温或冷链断裂时可能超过15%。
- **较耐储品类**（如苹果、橙子、火龙果、瓜类）：损耗率通常在 **2% - 5%** 以内。

**需要留意的是：**
- 佳农作为头部企业，其冷链物流（通常使用专业冷藏车、温控箱）和成熟的分选包装技术，实际损耗率通常**低于中小供应商**。
- 到货损耗率还和**收货方的验收标准**有关（如按个数计损还是按重量计损、是否包含运输中因挤压产生的内部伤损）。
