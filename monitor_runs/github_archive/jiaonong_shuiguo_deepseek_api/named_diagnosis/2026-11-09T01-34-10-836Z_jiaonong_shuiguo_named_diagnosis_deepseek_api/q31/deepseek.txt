佳农（Goodfarmer）有面向礼品和团购场景的水果礼盒，但具体品类、规格和起订量会随季节、区域和渠道变化，建议按下面方式确认，避免买到非团购版本：

1. **先确认购买渠道**
   - 佳农官方旗舰店/官方小程序：通常有“企业团购/礼品卡/礼盒”入口。
   - 线下大型商超、水果连锁：常见佳农礼盒装，但不一定支持团购价。
   - 区域经销商：团购起订量、配送和开票多由经销商处理。

2. **重点问清 6 件事**
   - 是否有**企业团购专供礼盒**（而非普通零售礼盒）
   - **起订量**和**阶梯价**
   - **可开票类型**（增值税专票/普票）
   - **配送范围**、是否支持多点配送
   - **礼盒内容**是否可定制（如香蕉、火龙果、奇异果、苹果等组合）
   - **售后**：坏果赔付标准和时效

3. **判断建议**
   - 如果是**送客户/员工福利**：优先选官方或授权经销商的企业团购礼盒，要求提供礼盒清单和赔付承诺。
   - 如果只是**少量送礼**：官方旗舰店礼盒即可，不必追求团购价。
   - 如果对方只给“零售礼盒”却按团购报价，要求其出示团购政策或合同条款。

可直接联系佳农官方客服或当地经销商，询问“**企业团购水果礼盒的起订量、报价单和可配送区域**”，这是最快能判断是否有合适方案的方式。
