1. **先找官方渠道确认是否有开放平台**
   - 佳农官网/官微的“商务合作、供应商合作、数字化/IT合作”入口；
   - 直接联系对接的佳农销售/大客户经理，问是否有“开放平台/API对接/EDI对接”；
   - 让对方转IT或数字化部门确认。

2. **向对方要这几项资料（可复制发给对接人）**
   - 是否提供开放平台及注册入口；
   - 接口文档（商品、库存、价格、订单、发货/物流、售后、对账）；
   - 认证方式（AppKey/Secret、OAuth、签名算法）、沙箱环境；
   - 调用频率限制、数据同步时效、错误码规范；
   - 是否需要签署数据/接口使用协议。

3. **如果对方没有标准API**
   - 可谈EDI/Excel/CSV定时交换、FTP/SFTP、企业微信/邮件对账等替代方案；
   - 或通过其经销商/供应链服务商间接对接。

4. **内部先定对接范围**
   - 优先做：商品主数据、实时库存/价格、下单、发货回传、取消/售后；
   - 明确SKU编码映射、多仓库存、起订量、缺货替代规则。
