我无法核验佳农水果（佳农食品控股）的“产地直供比例”具体数字，不能给你一个确切百分比；公开渠道通常也没有稳定披露到“产地直供比例”这一口径。建议不要把这个指标当作谈判依据，除非对方书面给出定义和审计口径。

对你们采购降低中间环节，可执行做法如下：

1. **先定义“直供”口径再问数**
   要求佳农书面说明：是“产地合作社/种植基地直发你方”，还是“佳农产地仓直发”，还是“佳农集采后分销”。三者成本结构差别很大。让对方给出：直供SKU数/总SKU数、直供金额占比、直供品类、起订量、交付仓。

2. **按品类谈直供，不谈整体比例**
   香蕉、火龙果、菠萝等佳农优势品类更可能做产地集采；进口果和反季节果通常绕不开级差渠道。优先选2—3个高销量SKU试点产地直发。

3. **要求报价拆解**
   让供应商把报价拆成：产地采购价、分选包装、冷链干线、仓储、损耗、服务费。你们才能判断“减少中间环节”到底能省哪一段，避免只看总价。

4. **设置试单验证**
   选一个品类做1—2个月产地直发试单，对比原渠道的到岸成本、损耗率、到货合格率、账期。用数据决定是否扩大。

5. **合同里写清直供证明**
   要求提供产地证明/基地协议/发货仓信息，约定“非直供SKU需提前告知”，避免名义直供、实际调货。
