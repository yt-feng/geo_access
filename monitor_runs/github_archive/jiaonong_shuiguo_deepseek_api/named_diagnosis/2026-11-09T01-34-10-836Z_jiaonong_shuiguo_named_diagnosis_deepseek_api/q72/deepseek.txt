佳农（佳农食品控股）主营业务是香蕉、菠萝等鲜果的贸易与分销，标准产品以整果鲜销为主，通常不向茶饮店这类小B客户提供“去皮切块”的定制加工服务。能确定的是：整果菠萝是他们的常规品类；但“佳农是否能给你做鲜切加工”属于具体商务事项，我没有可核验的公开信息能给出肯定答复，建议你直接向对接的佳农销售或客服确认以下要点：

1. **是否提供鲜切/去皮切块产品**：问清是“工厂鲜切预包装”还是“仅整果”。佳农有面向零售的鲜切水果产品线，但能否供餐饮渠道、最小起订量多少，需按区域确认。
2. **加工形态与规格**：块径、是否去芯、糖度区间、单袋重量、冷藏/冷冻状态。
3. **配送与保质期**：鲜切菠萝保质期短，确认冷链配送范围、到货温度、每批次检测报告。
4. **价格与起订量**：鲜切比整果有加工溢价，小批量可能不划算。

如果佳农不做小B鲜切，可替代方案：
- 找当地**净菜/鲜切水果加工厂**代加工，用佳农整果或本地菠萝作原料；
- 直接采购**餐饮渠道鲜切菠萝供应商**（很多冷冻/冷藏鲜切厂商有茶饮专供规格）；
- 门店自行去皮切块，需评估人工成本和出品标准化。

建议先让佳农销售书面回复“是否供鲜切、规格、起订量、冷链条件”，再对比本地鲜切厂的报价和账期做决定。
