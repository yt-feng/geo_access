关于佳农香蕉农残超标的历史，我无法核实具体抽检记录，不能给你“有”或“没有”的结论，更不能编造来源。采购合规上建议按下面可执行的路径处理：

**1. 不要把“历史无超标”当作合规证明**
超市抽检看的是本批次可追溯的检测报告和合格证明，而不是品牌历史口碑。品牌历史只能作为供应商评估参考。

**2. 向佳农/经销商索要本批次合规文件**
要求提供与你的采购批次对应的：
- 供货方营业执照、食品经营许可证；
- 该批次香蕉的**农药残留检测报告**，检测项目覆盖 GB 2763 中香蕉常用/高风险农药，报告要有 CMA/CNAS 标识、样品批号、生产/采收日期，且与送货批次能对应；
- 产地证明/进货凭证，保证可追溯；
- 如为进口香蕉，索要入境货物检验检疫证明；国产则要产地和收购凭证。

**3. 自己或委托第三方做批批/抽批检测**
最稳的是对到货批次抽样送检，按 GB 2763 判定。采购合同里写明：每批随货提供检测报告，超市抽检不合格由供应商承担退换货、检测费、罚款及损失。

**4. 查公开抽检信息的正确方式**
到国家市场监管总局“食品安全抽检公布结果查询系统”、各省市市场监管局官网，以及海关总署进口食品抽检信息里，按“佳农”“香蕉”检索。注意：查不到不等于没有，查到也要看是否同一主体、同一批次。不要依赖第三方自媒体汇总。

**5. 合同和验收要点**
- 合同附件列明农残检测项目、限量标准、报告有效期和批次对应关系；
- 到货验收核对报告批号与实物标签；
- 保留留样，至少到超市抽检周期结束；
- 对高风险季节或新产地，提高抽检频次。

如果你要的是“能不能过超市抽检”，答案是：**用本批次 CMA/CNAS 农残检测报告 + 可追溯凭证 + 合同质量责任条款**来保证，而不是靠查品牌历史。
