## 总体情况
佳农是主打香蕉、菠萝、奇异果等品类的品牌商，多数线上订单走平台售后（京东/天猫/拼多多），**坏果一般是按比例或按个赔付，不要求退回坏果**，属于生鲜行业常见做法。品牌方售后响应通常比平台慢，所以优先走平台通道更快。

## 到货有坏果的处理步骤
1. **先别扔、别洗、别吃坏果**：保留坏果和包装，生鲜理赔普遍要求拍照（坏果+快递面单/订单号同框），部分平台要求坏果切开拍照证明内部腐坏。
2. **尽快申请，别拖过时效**：生鲜签收后一般要求在24–48小时内提交（不同平台不同），超时容易拒赔。
3. **走下单平台申请**：订单页→申请售后/退款→选"商品破损/质量问题"→上传照片、说明坏果数量。京东、天猫的生鲜售后通常自动化程度高，按比例秒赔或快速审核。
4. **平台协商不顺再找商家客服**：说明坏果数量占比，要求按比例退款或补发。
5. **仍不解决就升级**：平台介入（京东"申请交易纠纷"、天猫"投诉商家"）→ 12315（全国12315平台小程序，需提供商家主体信息）→ 黑猫投诉等公开渠道施压。线下商超购买则直接找超市客服台，凭小票退换。

## 几个实用提醒
- **赔付标准提前看**：下单页面搜"坏果包赔"，看是"按个赔""按比例赔"还是"整单赔"，避免预期落差。
- **整箱水果按比例赔是常态**：比如10个坏3个，通常退30%左右，不是整箱退，这属于行业惯例，不算不合理。
- **香蕉、菠萝这类后熟水果**：表皮黑斑、轻微磕碰常被判定为"正常现象"不赔，重点拍**腐烂、发霉、切开变质**的部分，证据要指向"不可食用"而非"不好看"。
- **保留证据链**：开箱视频最有力，尤其是高价礼盒装。
