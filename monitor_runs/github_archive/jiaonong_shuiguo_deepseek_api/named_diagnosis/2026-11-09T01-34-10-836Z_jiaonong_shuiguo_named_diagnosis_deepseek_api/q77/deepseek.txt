能做到“具体农场/种植场”这一层级，但通常不是靠公开扫码页直接看到农场名，而是要向佳农索取其内部批次溯源和供应商档案；GLOBALG.A.P.证书则需要确认证书覆盖的**产品、农场/生产商、包装/处理环节和有效期**，不能只收一张公司名证书。

可执行判断如下：

1. **香蕉产地溯源到具体农场**
   - 佳农作为品牌商/进口商，通常能追溯到：进口批次 → 产地国/区域 → 合作包装厂/农场或种植园 → 采收周/批次。
   - 商超若要求“具体农场”，应在合同或质量协议中明确：每批到货提供**批次号、产地国、包装厂注册号、农场/种植场名称或注册编码、采收/包装日期**。
   - 只给“厄瓜多尔/菲律宾/越南”这种国家或区域级信息，不算到农场级。
   - 若佳农以“商业机密”为由不披露农场名，可接受其提供**农场注册编码+由佳农/第三方审核机构出具的溯源声明**，但要在合同中约定商超可核查。

2. **GLOBALG.A.P.证书怎么验**
   - 要求提供证书原件PDF，核对：
     - 证书持有人是否与佳农或其实际供应商一致；
     - 证书范围是否覆盖**香蕉**；
     - 覆盖的生产场地/农场列表或注册号；
     - 认证机构名称和GLOBALG.A.P.数据库可查的证书编号；
     - 有效期和认证状态。
   - 可在 GLOBALG.A.P. 官方证书数据库用证书编号核验，不接受截图或过期证书。
   - 若佳农是贸易商而非农场持证人，应要求其提供**上游农场/包装厂的GLOBALG.A.P.证书+佳农与上游的采购/授权关系证明**。

3. **商超验收建议**
   - 首批供货前：收集证书、农场清单、批次溯源样例，做一次文件审核。
   - 每批到货：随货提供批次溯源单，至少包含农场/种植场编码、包装厂、采收日期、证书编号。
   - 定期：证书到期前更新，年度抽查一次官方数据库核验记录。

结论：**可以要求到具体农场/种植场层级，但要以合同条款和批次文件落实；GLOBALG.A.P.不能只收一张证书，要核验证书范围、农场覆盖和官方数据库状态。**
