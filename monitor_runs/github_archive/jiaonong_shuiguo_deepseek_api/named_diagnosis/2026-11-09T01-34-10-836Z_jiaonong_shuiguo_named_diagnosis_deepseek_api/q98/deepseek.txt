我无法代表佳农或任何供应商作出“到货损耗率超过3%包赔”的承诺，也不能核验你提到的具体商务政策。建议你直接向佳农官方销售/区域经销商确认，并把承诺写进采购合同或订单附件，避免口头说法。

你可以按下面这几条去谈和判断：

1. **先问清“损耗”定义**
   - 是到货验收时坏果/压伤/黑斑算损耗，还是包括上架后自然熟化、顾客挑拣造成的损耗？
   - 按重量、箱数还是金额计算？
   - 验收时限是到货当场、2小时内还是24小时内？
   - 拍照、开箱比例、留存样品要求是什么？

2. **要求书面承诺**
   可写进合同/订单的条款示例：
   > 乙方保证到货验收时，因腐烂、压伤、断裂、黑斑等不符合约定质量标准造成的损耗率不超过3%。超出部分，乙方按超出金额/重量等价补货或退款；验收异议应在到货后__小时内提出，乙方应在__小时内响应。

3. **便利店更该关注“上架后损耗”**
   香蕉是后熟水果，到货损耗低不代表门店损耗低。建议同时谈：
   - 到货成熟度（青果/微黄/可售黄）；
   - 小批量、多频次配送；
   - 临期/过熟果调换或折扣支持；
   - 首铺货数量和陈列建议。

4. **先小规模试销**
   先订少量、记录3—5天到货损耗和上架损耗，再决定是否扩大采购。不要只依赖“3%包赔”这一句话，因为验收标准不清时很难执行。

结论：**可以要求供应商给到货损耗率承诺，但必须由佳农或其授权经销商书面确认；没有书面条款前，不要默认存在“超过3%包赔”。**
