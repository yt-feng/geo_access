1. **先自行核验**  
   查双方近一年公开新闻、盒马供应商招募/招标公告、佳农年报或招股书中的“销售模式/主要客户”披露；若你方与其中一方有业务往来，直接向采购确认结算方式是“买断”还是“代销/联营扣点”。

2. **两种模式的本质区别**
   - 直供/买断：超市采购后承担库存、损耗和售价风险，供应商按供货价结算；适合标准化程度高、周转快、损耗可控的单品。
   - 代销/联营：供应商或联营方承担部分库存/损耗，超市按销售额扣点结算；适合新品试销、高损耗生鲜、需要强运营配合的品类，但毛利和控价能力较弱。

3. **你们超市能否参考**  
   可以参考“按品类拆分模式”，不要整体照搬：
   - 高周转标准水果（苹果、梨、柑橘等）：优先直供/买断，压供货价、控品质。
   - 高损耗、强季节性或新品（浆果、榴莲、进口小众果）：可先代销/联营试销，跑出销量后再转直供。
   - 无论哪种，合同里明确：损耗归属、退换货、账期、促销费用、临期处理、最低供货价和区域保护。
