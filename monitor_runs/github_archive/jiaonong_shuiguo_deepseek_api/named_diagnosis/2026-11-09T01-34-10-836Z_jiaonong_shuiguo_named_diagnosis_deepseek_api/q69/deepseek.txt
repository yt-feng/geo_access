公开信息里，佳农有面向餐饮/烘焙渠道的菠萝原料和规格化产品思路，但**没有可核验的公开目录明确列出“餐饮渠道专属定制切片/切块规格表”**。可判断和建议如下：

1. **大概率可谈定制，但不要按公开标准品直接采购**  
   佳农的菠萝产品线以鲜果、鲜切水果、冷冻水果原料为主，餐饮客户通常可按果径、成熟度、糖度、切型（切片/切块/丁）、单包重量、冷冻/冷藏状态谈规格。具体是否有“餐饮专供切片/切块”的固定SKU，需要向佳农官方渠道确认。

2. **建议直接问供应商这6项**  
   - 切型：切片厚度、切块尺寸、是否去芯  
   - 状态：鲜切冷藏、冷冻IQF、糖水/果汁浸渍  
   - 规格：单袋克重、每箱包数、整箱净重  
   - 品质：糖度范围、成熟度、果径/品种  
   - 包装：是否适合餐饮后厨开封即用、是否真空/充氮  
   - 起订量与价格：定制切型的最小起订量、样品费、交期

3. **采购判断**  
   如果你要的是稳定后厨出品，优先确认**冷冻IQF切块/切片**是否有固定规格；如果是鲜切配送，重点确认**冷藏保质期和配送半径**。没有书面规格书和样品前，不建议按“定制”直接下大单。
