1. **行业5%是到货损耗参考值**：香蕉到货损耗受季节、产地、冷链、运输距离、成熟度、验收标准影响很大，不能直接拿来和单一供应商对标。
2. **佳农能控制在多少**：没有公开可核验的统一数据。佳农是香蕉进口/品牌化龙头企业，通常会有较严格的冷链和催熟管理，但“能控制在几个点”要以具体合同、批次、路线和验收口径为准。建议直接向佳农销售索要：
   - 近12个月同路线、同季节批次的到货损耗统计；
   - 损耗定义（是否含压伤、黑斑、断指、催熟不均、失水等）；
   - 验收标准和抽检比例。
3. **赔付条款**：是否有赔付、赔付比例和触发条件，属于合同条款，无法凭公开信息确认。谈判时可要求写入：
   - 到货损耗超过约定阈值（如5%）的部分按货值比例赔付或补货；
   - 明确责任归属（运输、冷链、催熟、产地包装）；
   - 索赔时限、举证方式（到货照片、视频、第三方验货）；
   - 赔付上限和免赔额。

**可执行建议**：先让对方书面提供“同路线近一年到货损耗分布+验收标准”，再谈赔付；不要只接受一个“平均损耗率”口头承诺。若你告诉我具体品类（如催熟蕉/青蕉）、运输方式和验收口径，我可以帮你列出更具体的合同条款要点。
