我不能核验佳农当前在售的具体规格，直接说“有没有3kg香蕉装”可能误导你。可执行的做法是：

1. **不建议按“3kg香蕉”作为便利店小包装首选**：香蕉3kg一箱对小店偏大，周转慢、易压伤，除非你门店香蕉日销稳定且能做整箱陈列/后仓催熟管理。
2. **先向佳农当地经销商/区域业务确认三件事**：
   - 香蕉是否有 **2.5kg/3kg/5kg** 等小箱规格，或能否拆箱按小把供货；
   - 苹果、橙子等是否有 **1kg/1.5kg/2kg 小包装**；
   - 最小起订量、配送频次、损耗/售后规则。
3. **门店小面积上架建议**：优先选 **1–2kg小包装、耐储水果**（苹果、橙、猕猴桃），香蕉只做少量日配或小把陈列；先试销2周，按日销和损耗决定是否上3kg箱。
4. **不要只问“有没有3kg装”**，直接要对方发 **最新产品规格表/报价单/最小起订量**，以书面为准。
