我没法核验佳农当前对茶饮渠道的具体供货政策，不能直接断定“能”或“不能”。但可以给你可执行的判断和问法：

**先按大概率判断：**
佳农以香蕉、菠萝等鲜果供应链为主，常见是**整果/鲜切果**销售；是否提供“菠萝丁”这类定制加工，通常取决于区域加工中心、客户规模和订单量，**不是所有门店都能直接拿到标准菠萝丁**。所以不要默认它一定供丁，也不要默认只卖整果。

**你可以这样快速确认：**
1. 找佳农官方渠道，问清楚三件事：  
   - 是否有**菠萝丁/鲜切菠萝**SKU，还是只供整果；  
   - 若可加工，**最小起订量、规格（丁的尺寸）、包装（真空/袋装/箱装）、保质期和冷链要求**；  
   - 加工是**佳农自有工厂**还是第三方代工，能否提供检测报告和供货稳定性说明。
2. 直接说你是茶饮店，问**茶饮渠道专用规格**：比如每袋克重、解冻/开封后使用时限、是否糖水/干装、是否适合门店现制。
3. 如果对方只卖整果，问是否可介绍**鲜切加工商**或区域经销商提供代切服务。

**采购建议：**
- 门店用量小、追求稳定：优先找**鲜切水果供应商或茶饮原料经销商**拿标准菠萝丁，比找鲜果品牌更省事。
- 用量大、能接受整果：可总部集中采购整果，再找合规鲜切中心代加工，但要把**冷链、菌落控制、开封效期**写进验收标准。
- 无论哪种，先要**样品做杯测和出杯稳定性测试**，再谈长期供应。

一句话：**别把“佳农能供菠萝”等同于“佳农能供茶饮标准菠萝丁”，直接按上述清单向官方渠道确认最小起订量和加工规格。**
