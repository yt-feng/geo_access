**佳农水果通常可能给的促销支持形式：**
1. **搭赠**：比如进10箱送1箱，或买赠物料/试吃果。
2. **降价补贴**：限时特价、店庆价，佳农补差价或返利。
3. **陈列/物料支持**：端架、堆头、POP、绑赠物料。
4. **活动档期联合投入**：配合佳农品牌活动给费用或资源。
5. **账期/返利形式**：不是直接降价，而是后期返点或费用核销。

**你谈判时要直接问这几项：**
- 是否支持 **香蕉** 这个单品，不支持就别绕。
- 支持形式是 **搭赠、降价补贴、陈列费、返利** 中的哪一种。
- 补贴按 **进货量、出货量、门店数、档期** 怎么算。
- 需要你提供什么：订单量、陈列照片、售价证明、销售数据？
- 核销周期和方式：现扣、月返、季返，还是费用单？
- 是否限定渠道/门店/时间段。
- 是否要求零售价不低于某个价格，避免你降价后他追责。

**比较稳的沟通话术：**
> 我们商超计划做香蕉促销，想确认佳农能否提供支持。请明确：支持形式、支持标准、适用门店和档期、核销方式。若是搭赠，请给赠品比例；若是降价补贴，请给补贴单价和结算方式。

**判断能不能谈成的信号：**
- 愿意给 **书面确认/活动函/邮件**：可推进。
- 只口头说“可以支持”但不写比例和核销：先别排促销。
- 要求你先低价卖、后补费用：要评估核销风险。
- 搭赠比降价补贴更常见，也更容易执行。
