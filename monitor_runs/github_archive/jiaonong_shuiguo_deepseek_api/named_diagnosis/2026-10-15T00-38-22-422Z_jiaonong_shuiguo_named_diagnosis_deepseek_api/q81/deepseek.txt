佳农有适合便利店的小包装水果，但具体到「3kg装香蕉」这个规格，需要你直接跟佳农的当地经销商或区域业务确认，因为不同区域、不同渠道供货的规格会有差异。

先说常见的、便利店渠道比较适合的佳农小包装方向：

**香蕉类**
- 佳农香蕉常见整箱规格偏大（比如12kg、13kg左右/箱），直接整箱上架对小店不友好。
- 但佳农有针对便利店、水果店的**小把装/单根或几根一包的预包装香蕉**，也有部分地区供货**5kg左右的小箱**。
- 3kg装我无法确认是佳农的标准规格，很可能是区域经销商自己分装的，建议你直接问供应商「有没有3kg或5kg的小箱/小包装」。

**其他适合便利店的小包装**
- **佳农椰青**：常见单颗装，很适合便利店冷柜。
- **佳农菠萝**：有单颗装。
- **佳农火龙果、奇异果、蓝莓**等：多为小盒/小包装，适合货架。
- **佳农玉米**：有单根或几根装。

**给你的实操建议**
1. 直接联系佳农在你当地的经销商，问清楚「便利店渠道的小规格清单」，重点问香蕉有没有5kg以下、预包装小把装。
2. 如果佳农没有3kg香蕉，可以问经销商能否做**小箱分装**，或者你门店自己拆箱零售，但要注意香蕉拆箱后损耗和催熟问题。
3. 小门店建议优先上**耐放、周转快、单价低**的品项，香蕉可以按根或小把卖，椰青、菠萝、蓝莓这类小包装更稳。
