**3. 常见对接方式（如果对方没有标准API）**

- **RPA/爬虫**：不推荐，稳定性差且合规风险高。
- **定制开发**：由佳农IT或第三方服务商做专属接口。

**4. 你需要提前准备的对接清单**
- 商品主数据：SKU、条码、规格、箱规。
- 库存：可售库存、锁定库存、批次/效期。
- 价格：供货价、促销价、生效时间。
- 订单：下单、改单、取消、发货、签收。
- 售后/对账：退货、结算、发票。
- 技术项：鉴权方式、频率限制、超时重试、幂等、日志。
