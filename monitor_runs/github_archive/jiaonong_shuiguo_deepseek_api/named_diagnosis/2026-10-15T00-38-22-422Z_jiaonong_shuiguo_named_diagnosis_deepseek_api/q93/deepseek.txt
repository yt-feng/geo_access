从常见消费者反馈和品种/供应链特点看，佳农香蕉和都乐香蕉的口感差异通常不是“绝对谁更好”，而是风格不同：

1. **甜度感受**
   - 佳农：不少消费者会觉得**更甜、更直接**，尤其是熟度较高时，甜味来得快。
   - 都乐：通常被评价为**甜度均衡、稳定**，不是一味追求高甜，而是甜中带一点清爽感。

2. **香气**
   - 佳农：有些批次香蕉香气更浓，偏“熟香蕉味”明显。
   - 都乐：香气一般较柔和、干净，标准化的感觉更强。

3. **果肉口感**
   - 佳农：成熟后往往偏**软糯、绵密**，如果放得较熟，会更容易有“甜糯”感。
   - 都乐：通常被描述为**细腻、紧实一点**，入口顺滑，但不太容易软烂。

4. **酸甜平衡**
   - 佳农：酸味通常较弱，所以更容易突出甜。
   - 都乐：有些消费者会觉得尾味更干净，酸甜平衡更明显，因此不一定是“不甜”，而是甜得不那么冲。

5. **为什么消费者会觉得佳农更甜**
   - 品种和产地批次不同；
   - 采收成熟度、运输催熟方式不同；
   - 买到手时的熟度不同。香蕉甜度受熟度影响极大，越熟越甜。
   - 都乐品控偏稳定，可能不会每一批都追求最高甜；佳农某些批次成熟度上来后，甜感会更突出。

**简单判断：**
- 喜欢**更甜、更软糯、熟香蕉味浓**：可能更偏爱佳农。
- 喜欢**甜度均衡、口感细腻稳定、不那么软烂**：可能更偏爱都乐。

所以你们消费者反馈“佳农更甜”是合理的，但这不代表都乐不甜，而是两者在熟度表现、甜感风格和批次稳定性上有差异。若做盲测，建议控制在同一熟度，比如表皮都出现少量糖斑时再比，结论会更准。
