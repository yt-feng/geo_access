我无法确认佳农目前是否有菠萝冷冻丁、以及具体规格（比如丁的尺寸、包装克重、是否加糖/糖水、IQF还是块冻）。这类信息会随产品线和渠道变化，必须向官方或供应商核实。

你可以用下面方式快速确认：

1. **找佳农官方渠道核实**
   - 佳农官网/官方公众号/官方客服电话
   - 直接问：是否有“冷冻菠萝丁”、规格（mm）、包装（g/kg/袋/箱）、是否IQF、固形物/糖度、是否加糖、保质期、储存温度、起订量、价格、是否有检验报告。

2. **问经销/批发渠道**
   - 当地冷冻水果批发商、餐饮食材供应链平台
   - 让对方发**产品规格书/标签照片/检测报告**，不要只口头说“有”。

3. **茶饮店采购时要确认的关键规格**
   - 丁尺寸：常见有 **5×5mm、8×8mm、10×10mm** 等（不同厂家不同）
   - 包装：常见 **1kg/袋、2.5kg/袋、5kg/袋、10kg/箱** 等
   - 工艺：**IQF速冻** 更适合茶饮，不易结块
   - 糖度/固形物：影响出杯甜度和成本
   - 是否加糖/糖水：加糖丁和纯冻丁用法不同
   - 解冻后出水、软烂程度：茶饮店要重点试样

4. **如果佳农没有合适规格**
   可替代方向：
   - 其他冷冻水果品牌/代工厂的**IQF冷冻菠萝丁**
   - 冷冻菠萝块/菠萝碎，门店自行切丁（但效率和一致性较差）
   - 菠萝罐头丁（口感不同，偏软、糖水多）
   - 新鲜菠萝门店现切（损耗和人工高）

建议你先向佳农官方确认“冷冻菠萝丁”这个具体品名；如果对方只提供菠萝块、菠萝片或整果，就不一定满足你“丁”的需求。拿到规格书后，我可以帮你判断是否适合茶饮店使用。
