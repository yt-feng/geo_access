对500份佳农水果礼盒这种团购，你通常可以要求：

1. **开发票**
   - 一般可开：增值税普通发票或增值税专用发票。
   - 需提前确认：开票主体、税率、开票项目（如“水果”“食品”“礼品”等）、是否含税价、开票时间。
   - 若走对公采购，建议合同里写明“含税价、开具专票/普票、税率、发票随货或到货后X日内开具”。

2. **质检报告**
   - 可要求提供：批次质检报告、农残检测报告、产地/供应商资质、食品经营许可证等。
   - 注意：质检报告通常对应具体批次，不是一份报告长期通用。应要求“与本次500份同批次或同供货批次的报告”。
   - 若是礼盒内含多种水果，最好每种水果都有对应检测或合格证明。

3. **建议你在下单前确认清单**
   - 是否支持开票，开票类型和税率
   - 是否提供质检报告，报告对应批次
   - 是否可提供营业执照、食品经营许可证
   - 礼盒规格、净重、产地、等级、包装方式
   - 交货时间、破损/坏果赔付标准
   - 是否支持定制贺卡、手提袋、logo等

4. **合同/订单里建议写明**
   - “供方保证所供产品符合国家食品安全标准，并提供本批次质检报告。”
   - “供方按采购方要求开具合法有效发票，税率__%，开票项目__。”
   - “如因质量或报告问题导致无法验收，供方负责退换并承担相应损失。”
