这类支持通常不是统一标准，而是按**供应商/经销商政策 + 单店/连锁采购谈判 + 本次促销档期**来定，佳农本身一般不会对所有商超给一套公开固定报价。能不能给堆头陈列、试吃支持，以及费用怎么分担，主要看以下几个判断点：

**1. 先确认你对接的是谁**
- 如果是**佳农直营/大区经销商**：堆头、试吃、促销员支持相对更可能有政策，尤其是香蕉、菠萝、火龙果等主力单品。
- 如果是**二级批发商/本地水果供应商**：支持力度通常弱一些，更多靠你和供应商单独谈。
- 如果是**连锁商超总部统采**：一般由总部与佳农谈年度框架，门店再申请档期资源。

**2. 堆头陈列支持常见形式**
可能包括：
- 提供堆头围挡、价签、跳跳卡、地贴、展架等物料；
- 提供指定陈列图或要求最小陈列量；
- 给堆头专项返利或陈列补贴；
- 由供应商业务员到店协助摆堆。

但“给堆头”不等于“免费给堆头”。很多供应商会要求：
- 门店给到主通道/端架/入口位置；
- 单店单次进货达到一定金额或件数；
- 促销档期不少于 7 天/14 天；
- 配合做特价，不能只是原价陈列。

**3. 试吃支持常见形式**
可能包括：
- 免费提供试吃果品，按进货量的一定比例核销；
- 提供试吃台、牙签、纸杯、手套、围裙等物料；
- 派促销员试吃，费用可能供应商承担、门店承担或双方分摊；
- 只给试吃果，不承担人工和场地费用。

试吃果一般有核销上限，比如按进货金额的 3%–8%，或按每店每天固定几公斤/几件，具体要谈。

**4. 费用分担通常怎么谈**
常见分担方式有这几种：
- **供应商全包**：你给好位置、保证进货量和档期，供应商出果、物料、人工。
- **门店出位置，供应商出果和物料**：人工由门店员工兼做。
- **双方分摊**：供应商出试吃果和物料，门店承担促销员工资或场地费用。
- **门店买断/自采**：供应商只给低价，堆头和试吃费用门店自己承担。
- **按销售返利抵扣**：先由门店垫付，后期按销量返点或陈列补贴抵扣。

实操里，商超更常见的是：**供应商出试吃果 + 物料，门店出场地和人员；或者供应商给陈列补贴，门店保证堆头位置和主推。**

**5. 你可以直接这样去谈**
跟佳农或经销商沟通时，直接问这 6 项：
1. 本次档期能不能给堆头物料和陈列补贴？
2. 试吃果按什么标准核销，比例多少，上限多少？
3. 是否派促销员，人工谁承担？
4. 堆头位置、面积、档期天数有什么要求？
5. 需要达到多少进货量或销售额才触发支持？
6. 费用是事前核销、事后返利，还是直接抵货款？

**6. 比较现实的预期**
- 佳农主力单品、连锁系统、档期量大：堆头物料和试吃支持比较容易谈。
- 单店、小量、临时促销：通常只能争取到少量试吃果或简单物料，堆头费用大多要门店自己承担。
- 如果你们采购量不大，建议把“堆头+试吃”打包成一次主题活动去谈，比单独要费用更容易通过。
