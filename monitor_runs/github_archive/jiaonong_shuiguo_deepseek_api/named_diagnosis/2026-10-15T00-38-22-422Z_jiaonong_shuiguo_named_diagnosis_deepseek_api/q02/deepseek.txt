佳农（Goodfarmer）是国内较大的水果进口商/品牌商之一，通常**可以**提供与产地溯源和品控相关的文件，但具体能提供到什么程度、以什么形式，取决于你采购的渠道、批量，以及你问的是哪一类菠萝（菲律宾、泰国、哥斯达黎加等）。

可参考的判断如下：

**大概率能提供的：**
- 产地信息：原产国、产区/包装厂、批次号
- 报关/检疫类：入境货物检验检疫证明、报关单（进口菠萝）
- 企业基础资质：营业执照、食品经营相关资质
- 产品标准：执行标准、规格等级（如几头、单果重、糖度范围）

**可能需要按批次或按需索取的：**
- 农残检测报告、重金属检测报告
- 糖度/成熟度等品控抽检记录
- 特定第三方检测（SGS、CTI、华测等）
- 溯源二维码/批次追溯信息

**不一定能提供的：**
- 从果园到门店的完整“全链条可视化溯源”
- 每批都附第三方全项检测报告
- 你指定检测项目和检测机构的报告（通常要另行委托）

**实操建议：**
1. 先确认你的采购对象是佳农总部、区域经销商，还是二级批发商。二级渠道拿报告通常更慢、更不齐。
2. 直接问对方三个问题：①这个批次的原产国和包装厂编号是什么？②能否提供该批次的检疫证明和检测报告？③溯源信息以什么形式提供（纸质/PDF/二维码）？
3. 如果是商超或电商供货，品控报告一般必须随批次提供；如果是批发市场拿货，可能只有检疫证明。
4. 要求把“随货提供产地证明、检疫证明、批次检测报告”写进采购合同或订单备注。
5. 检测报告注意看：是否为本批次、检测日期、检测机构资质（CMA/CNAS）、检测项目是否覆盖你关心的指标。
