**佳农能不能稳定供应？**
佳农是国内大型水果供应链企业，菠萝（尤其凤梨/金钻凤梨等）是其常见品类，通常能供餐饮、商超、批发渠道。对茶饮店来说，关键不是品牌大不大，而是它能不能按你的 **规格、频次、到货状态、价格** 稳定交货。

**普通商家听得懂的菠萝规格，一般看这几项：**

1. **品种**
   - 常见：金钻凤梨、甜蜜蜜凤梨、普通菠萝。
   - 茶饮店常用金钻/凤梨类，因为不用盐水泡、甜度高、酸低、出汁稳定。
   - 你要明确：是做果肉、果酱、鲜果茶，还是榨汁。

2. **单果重量**
   - 常见规格：1.2-1.5斤、1.5-2斤、2-2.5斤、2.5-3斤以上。
   - 茶饮店如果自己削果切块，通常选 **2斤以上** 更省人工；如果做整果装饰，可能选小果。

3. **成熟度**
   - 常见：青果、半熟、熟果。
   - 茶饮店要稳定出杯，一般要 **7-8成熟** 到店，太生酸、太熟易坏。
   - 必须问清楚：到店是即用型，还是还要催熟。

4. **加工状态**
   - 带皮整果
   - 去皮整果
   - 切块/切丁
   - 冷冻果肉/果浆
   - 罐头/果酱原料
   - 如果你量大又缺人工，优先谈 **去皮切块或冷冻果肉**，比整果稳定。

5. **包装**
   - 整果：10kg/箱、12kg/箱、15kg/箱等。
   - 冷冻/切块：1kg/袋、5kg/袋、10kg/箱。
   - 你要确认是 **净重还是毛重**，这直接影响成本。

6. **糖度/酸度**
   - 茶饮店要稳定，最好要求糖度范围，比如 14-18 Brix。
   - 但生鲜菠萝糖度会波动，供应商通常只能给大概范围，不能像糖浆一样绝对稳定。

7. **冷链和到货温度**
   - 鲜果：常温或冷藏运输。
   - 冷冻果肉：必须 -18℃ 冷链。
   - 到货温度不稳定，后面出品就会不稳。

8. **起订量和配送频次**
   - 问：多少箱起送？每周能送几次？能不能固定周二、周五？
   - 茶饮店最怕“今天有、明天没”，所以要看它能不能签 **月度/季度框架供应**。

9. **价格和结算**
   - 问：按箱、按斤、按净重还是按出成率？
   - 鲜菠萝出成率很重要：带皮整果削完可能只剩 40%-50%。如果按毛重报价，实际成本会高很多。

**你直接这样问佳农或经销商：**

> 我们茶饮店每月需要 XX 吨菠萝原料，想要金钻凤梨/凤梨果肉，规格 2-2.5斤/个，7-8成熟，去皮切块或冷冻果肉，糖度 14 以上，-18℃冷链，1kg/袋或5kg/袋，每周送2次，能不能稳定供？请报净重价、起订量、到货状态、出成率和账期。

**判断能不能合作，看4点：**
- 能不能连续 3 个月稳定供货，不是只供一批。
- 规格能不能写进合同，而不是口头说“差不多”。
- 到货糖度、成熟度、坏果率能不能抽检。
- 如果鲜果波动大，能不能用冷冻果肉/果浆兜底。

**结论：**
佳农通常有能力供，但“普通商家听得懂的规格”要你自己定清楚：**品种、单果重、成熟度、加工状态、包装、糖度、冷链、起订量、配送频次、净重价**。这些确认完，才能判断它是不是适合你们茶饮店的稳定供应商。
