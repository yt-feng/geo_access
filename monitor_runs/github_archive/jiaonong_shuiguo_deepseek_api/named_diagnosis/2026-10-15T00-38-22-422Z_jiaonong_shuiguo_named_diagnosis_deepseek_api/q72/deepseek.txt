佳农（Goodfarmer）主营香蕉、菠萝等水果的种植、进口和批发分销，其标准业务是**整果销售**，通常不直接向茶饮店这类中小客户提供定制化的去皮切块加工服务。

实际情况是：

- **佳农本身**：以整箱、整果出货为主，一般不接小批量代加工。
- **如果你量很大**（比如连锁品牌、中央工厂级别），可以联系佳农的B端/餐饮渠道业务，询问是否有预处理规格或能否对接其合作加工厂，但这需要单独谈，不是标准服务。
- **更常见的做法**：找当地水果加工厂或净菜/鲜切供应商，让他们采购佳农菠萝再代为去皮切块，或者直接采购已切好的冷冻/冷藏菠萝块。

**建议你按这个顺序判断：**

1. 先联系佳农官方客服或当地经销商，直接问“有没有面向茶饮店的去皮切块规格或代加工”，得到明确答复。
2. 如果不行，就近找鲜切水果供应商，说明你要的是佳农品牌原料+切块规格，很多供应商能提供。
3. 如果门店用量小，自己加工或买现成切块更划算，代加工通常有起订量门槛。

我没有佳农官方关于加工服务的公开承诺可核验，所以最终以你直接向佳农确认的结果为准。
