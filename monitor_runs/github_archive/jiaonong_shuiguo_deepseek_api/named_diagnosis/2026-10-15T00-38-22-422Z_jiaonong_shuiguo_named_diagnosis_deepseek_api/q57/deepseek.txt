1. **佳农的损耗控制水平**
   - 佳农作为国内头部香蕉进口商/品牌商，通常对外宣传的是全程冷链、催熟和品控能力，但**没有公开统一承诺“到货损耗率控制在X%”**。
   - 实际到货损耗会因运输方式（海运/陆运）、季节、港口/口岸、催熟阶段、客户验收标准不同而差异很大，行业里常见区间大致在3%–8%，做得好可以更低，但没有官方统一数字。

2. **是否有赔付条款**
   - **取决于具体采购合同，而不是品牌统一政策。**
   - 佳农与商超、批发客户、电商等签订的合同里，通常会有质量验收标准、损耗分担、退换货或扣款条款，但是否赔付、赔多少、按重量还是按金额，都要看合同约定。
   - 常见做法是：约定验收标准（如青蕉/黄蕉成熟度、条重、黑斑、机械伤比例），超出部分按比例扣款、补货或折价处理，不一定叫“赔付”。
   - 如果是通过经销商或批发市场拿货，很多情况下按市场规则“当面验收、离场不认”，未必有明确赔付。

3. **建议你怎么确认**
   - 直接向佳农业务或当地经销商索要：**质量验收标准 + 损耗处理条款 + 退换货/扣款规则**。
   - 合同里重点看：到货验收时限、抽检比例、损耗计算方式（按件/按重量/按金额）、免赔比例、超出后是补货还是扣款。
   - 如果对方只口头说“损耗很低”，要求写进合同或订单备注，否则很难追责。
