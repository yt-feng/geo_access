佳农官方并未公开披露“产地直供比例”这一具体数字，我无法给出准确百分比，也不建议采信任何未经其官方确认的比例数据。不过针对你“减少中间环节、降低成本”的目标，可以提供可落地的判断和做法：

**1. 先厘清“直供”在佳农这类企业里的实际含义**
佳农（Goodfarmer）核心模式是“产地采购+全国/全球分销”，主要品类包括香蕉、菠萝、火龙果、苹果等。它本身是大型贸易与供应链企业，通常不是终端零售商，所以“产地直供”一般指：
- 从自有或合作种植基地/产地合作社直接采购；
- 经其国内分选、催熟、仓储、配送后供给客户。
即便源头是产地，中间仍可能经过其区域仓、经销商或批发市场环节。

**2. 直接可问佳农的核验问题**
与其要一个笼统比例，不如按品类和履约链路追问：
- 该品类是自有基地、合作基地，还是市场收购？
- 从产地到我们仓库，经过几级主体（佳农总部→区域公司→经销商→批发市场）？
- 能否签订产地直发协议，跳过区域经销商？
- 报价中是否包含催熟、分选、仓储、配送，各占多少？
- 起订量、账期、损耗承担如何约定？

**3. 降低中间环节的实际路径**
- **按品类分别谈**：香蕉、菠萝等佳农强项品类，直采可行性高；反季或小众品类可能仍需多层分销。
- **要求工厂/产地代码可追溯**：通过包装箱产地码、批次号核实是否产地直发。
- **对比替代方案**：直接对接产地合作社、大型批发市场一级商、或区域性供应链公司，用实际到岸价对比佳农报价。
- **算总成本而非单价**：把损耗率、催熟费、配送费、账期资金成本一起计入，很多时候“多一层”反而综合成本更低。
- **小批量试单验证**：先小规模走一单，核对实际发货地、批次和到货损耗，再决定是否扩大。

**结论**：佳农没有公开的产地直供比例，无法核实。建议不要纠结这个数字，而是要求其按品类提供供应链层级、报价构成和直发可行性，并用试单和总成本对比来验证能否真正降本。
