佳农（Goodfarmer）的香蕉分级属于企业内部品控标准，通常不会完整对外公开，而且**同一等级在不同季节、不同产区（菲律宾、厄瓜多尔、越南等）、不同客户合同下，价格差也会浮动**，所以没有统一固定数字。下面给你能判断和操作的框架。

## 一、佳农香蕉常见的分级维度

佳农对香蕉的分级一般围绕这几项综合判定，而不是单一指标：

1. **条重（单根重量）**
   - 一级果：通常要求单根重量在较窄的优质区间（如 130–180g 左右，具体按合同）
   - 二级果：条重偏小或偏大，均匀度差

2. **梳形与条数**
   - 一级果：每梳条数整齐、梳形饱满、无明显缺条
   - 二级果：梳形松散、条数不齐、有断梳

3. **外观**
   - 一级果：无黑斑、无擦伤、无炭疽病斑、无药害、无裂口
   - 二级果：允许少量轻微瑕疵（小擦伤、轻微斑点），不影响食用

4. **成熟度/青度**
   - 一级果：青度统一，催熟后颜色一致
   - 二级果：成熟度不匀，催熟后色差明显

5. **长度与弯曲度**
   - 一级果：长度、弯度整齐
   - 二级果：长短不一、弯度杂乱

6. **包装与冷链**
   - 一级果：标准箱规、码放整齐、冷链稳定
   - 二级果：可能混装、箱规不统一

> 实际验收时，佳农多以“**条重 + 外观 + 梳形 + 青度**”四项综合定级，而不是只看一项。

## 二、一级果和二级果的价格差

**没有官方统一差价**，但批发市场上常见规律是：

- 正常行情下，**二级果比一级果便宜约 10%–25%**
- 行情差、走货慢时，二级果可能便宜 **25%–40%**，甚至更多
- 行情好、一级果缺货时，二级果折价会收窄到 **5%–15%**

举例说明（仅作量级参考，不是实时报价）：
- 若一级果批发价 100 元/箱，二级果可能在 75–90 元/箱
- 若一级果 120 元/箱，二级果可能在 85–105 元/箱

具体差价取决于：产区、到货季节、港口/冷库库存、你的采购量、是否长期协议客户。

## 三、给批发商的实操建议

1. **别只问“一级/二级”，要问清判定细则**
   - 条重区间是多少？
   - 允许瑕疵比例多少？
   - 是“佳农自有标准”还是“客户定制标准”？

2. **要求看实物或样品照片**
   - 重点看：条重、梳形、黑斑、擦伤、青度是否统一

3. **按你的下游客户倒推等级**
   - 做商超/精品店：必须一级果
   - 做水果店/社区团购：一级+二级搭配
   - 做加工/催熟后散卖：二级果性价比更高

4. **锁价方式**
   - 短期：按当日行情 + 等级差价谈
   - 长期：签协议时明确“等级判定标准 + 差价区间 + 验收争议处理”

5. **最可靠的做法**
   - 直接找**佳农当地销售或区域代理**要最新《产品等级标准》和当周报价单
   - 同时对比**都乐、洪九、鑫荣懋**等同类品牌的分级和价差，做横向参照
