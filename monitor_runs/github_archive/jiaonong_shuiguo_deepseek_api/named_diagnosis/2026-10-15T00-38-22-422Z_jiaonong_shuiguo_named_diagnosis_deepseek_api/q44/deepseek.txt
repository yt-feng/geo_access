我先把你最关心的两件事分开说：**佳农香蕉是否有农残超标公开记录**，以及**采购合规证明该怎么要、怎么验**。

## 1. 关于“佳农香蕉农残超标历史”

我无法凭记忆核验并给你一份“确有其事/绝无此事”的权威结论，如果我直接说有或没有，都是不负责任的。可靠做法是查官方公开信息，而不是听供应商口头保证：

- **国家市场监管总局**官网“食品安全抽检”栏目，以及各省市市场监管局官网的抽检公告，可按“香蕉”“佳农”检索。
- **海关总署**进出口食品安全相关公告，如果涉及进口香蕉。
- **农业农村部**农产品质量安全例行监测信息。
- 用“佳农 香蕉 抽检 不合格”“佳农 农残 超标”等关键词在上述官方渠道交叉检索。

需要注意：市场上叫“佳农”的主体不止一家，检索时要核对**具体生产/分装企业名称、批次、产地**，否则容易张冠李戴。

## 2. 超市抽检要过，采购端必须拿到这些文件

不要只要一张“合格证”，超市抽检看的是**可追溯+可检测**。建议按下面清单收：

1. **营业执照、食品生产/经营许可证**（供应商主体资质）。
2. **该批次产品的出厂检验报告**，重点看农残项目，报告要有 CMA/CNAS 资质标识、检验机构盖章、报告编号可查。
3. **第三方检测报告**，针对你采购的具体批次或近期批次，检测项目建议覆盖：
   - 有机磷类（如敌敌畏、毒死蜱、甲拌磷等）
   - 氨基甲酸酯类
   - 拟除虫菊酯类
   - 吡虫啉、噻虫嗪等常用烟碱类
   - 同时关注 GB 2763《食品中农药最大残留限量》对应香蕉的限量
4. **进货凭证和批次追溯信息**：产地、采摘/分装日期、批次号，能做到“这批货对应这份报告”。
5. **承诺书/质量保证协议**：写明若抽检不合格，供应商承担退货、赔偿及监管处罚连带责任。

## 3. 实操建议

- **不要接受“一份报告用全年”**。超市抽检按批次，报告必须能对应到批次。
- **自己抽检最稳**。对高风险批次，花几百元送第三方按 GB 2763 做香蕉农残套餐检测，报告直接作为合规证明，比供应商自证更硬。
- **合同里写清抽检不合格的处理条款**，包括检测费、下架损失、罚款承担。
- 如果供应商拿不出批次检测报告，或报告查不到编号，**建议直接换供应商**，这类货进超市风险很高。
