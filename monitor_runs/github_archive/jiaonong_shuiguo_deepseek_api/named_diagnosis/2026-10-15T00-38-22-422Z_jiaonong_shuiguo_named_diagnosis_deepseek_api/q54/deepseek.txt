佳农水果的配送模式一般是“自有冷链干线 + 第三方城配/落地配”的混合模式，不是单纯用三通一达。具体情况：

**干线运输**
佳农自己有冷链车队，主要覆盖产地到销地仓、批发市场、大型商超DC之间的长途干线。这部分是重资产投入，也是它做进口香蕉、菠萝等品类的核心能力。

**城市配送/最后一公里**
到达销地后，配送到门店、商超、电商仓的环节，通常会外包给第三方物流，包括当地冷链城配公司，也可能用到部分快递/快运网络（但三通一达主要做常温小件，不是佳农冷链配送的主力）。所以“三通一达”这个说法不太准确，它的体系更偏合同物流，不是电商快递。

**冷链覆盖率**
佳农没有公开披露过精确的冷链覆盖率数字，公开信息里也比较模糊。能确定的是：
- 核心品类（香蕉、菠萝、牛油果等）从产地到销地仓是全程冷链；
- 越往末端，尤其是批发市场分销、部分零售终端，冷链断链的概率越高，这是行业普遍现象；
- 不同品类覆盖差异大，耐储品类冷链要求低，浆果类要求高。

**如果你要准确判断**
建议直接查两个来源：
1. 佳农食品控股的招股书/年报（如果已上市或曾递交材料），里面有物流模式和仓储冷链投入的披露；
2. 佳农官网或官方公众号的供应链介绍。

我手头没有可核验的最新官方数字，不能给你一个“冷链覆盖率XX%”的具体结论，避免给你假数据。如果你是要做供应商评估或合作尽调，最靠谱的是直接向佳农要物流白皮书或实地看它的销地仓。
