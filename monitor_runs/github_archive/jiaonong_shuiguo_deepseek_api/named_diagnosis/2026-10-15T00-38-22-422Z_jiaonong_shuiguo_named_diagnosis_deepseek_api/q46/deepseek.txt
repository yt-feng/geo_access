香蕉催熟这块，佳农（Joyvio/佳农食品）主要是**自己掌控催熟环节**，而不是简单外包给第三方催熟商。它在全国多个销地建有催熟加工中心/配送中心，香蕉到港或到仓后，由佳农自己的催熟团队按批次做乙烯催熟、温湿度控制，再配送到门店。部分区域或特殊渠道可能会有合作加工点，但主体是自营催熟体系。

对你们便利店“到店即熟”的需求，关键不是纠结自营还是外包，而是把下面几件事在采购合同里锁死：

**1. 明确熟度标准**
不要只说“熟的”，要量化。常用的是：
- 色度：按香蕉催熟色卡，门店收货时达到 **5–6号色**（全黄、少量糖斑或刚好无青）。
- 硬度：手感微软但不塌。
- 糖斑：可接受少量糖斑，但不能发黑腐烂。
建议约定“到店色度5号以上，货架期不少于2–3天”。

**2. 要求“定时达熟”**
告诉供应商你们要的是 **D+到店即熟**，不是到店还要放2–3天。让他们按你们门店的销售节奏倒推催熟出库时间。比如：
- 周一、周四各送一次；
- 每次到店即5号色，能直接上架卖2天。

**3. 配送频次和批量**
便利店单店销量小，最怕一次来太多熟蕉卖不完。
建议：
- 小批量、多频次配送；
- 单店单次到货量控制在 **2–3天销量**；
- 如果佳农直送有起订量门槛，可以走它的经销商或区域配送商，但要求仍是佳农催熟体系出货。

**4. 验收和退换条款**
写清楚：
- 到店色度低于约定（太生）或高于约定（过熟、发黑）怎么处理；
- 是否支持拒收、补货、折价；
- 货架期内出现批量黑腐、催熟不匀谁负责。

**5. 先做小范围测试**
别一上来全店切换。选1–2家店，让佳农或经销商按“到店即熟”送2–3周，记录：
- 到店色度是否稳定；
- 上架后第1天、第2天、第3天的损耗；
- 顾客反馈和实际销量。
测试通过再扩店。

**结论：**
佳农主体是自营催熟，不是纯外包。但你们要“到店即熟”，核心是向佳农或它的区域配送商提出**按色度、按到店时间、按小批量频次**的定制催熟配送要求，并把验收标准写进合同。直接找佳农当地销售或经销商谈“便利店到店即熟专供”是最快路径。
