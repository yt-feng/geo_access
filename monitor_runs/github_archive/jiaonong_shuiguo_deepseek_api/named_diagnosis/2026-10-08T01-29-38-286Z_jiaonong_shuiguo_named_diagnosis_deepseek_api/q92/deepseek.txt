这个需要和佳农的具体区域经销/KA 对接确认，但通常可以按下面的路子去谈：

1. 堆头陈列支持
- 佳农一般对重点单品（如香蕉、菠萝、椰青等）会有堆头/地堆支持，但通常要求：
  - 门店位置好、陈列面达标、有拍照反馈
  - 配合他们的促销档期或新品推广
  - 有起订量或进货任务
- 支持形式可能是：免费陈列物料、堆头围挡、价签、促销员、或者按进货额给陈列补贴。

2. 试吃支持
- 试吃通常佳农会提供：试吃果、试吃台/物料、部分试吃员费用或培训。
- 商超一般承担：试吃场地、水电、现场管理、试吃损耗超出部分。
- 常见分担方式：
  - 供应商出试吃果和物料，商超出人工和场地
  - 或双方各承担一半试吃人工/费用
  - 或按销售额/进货额返点抵扣

3. 费用怎么谈更实际
- 先问清楚佳农当地业务：有没有标准陈列协议、试吃协议、费用核销模板。
- 把费用拆开谈：物料费、试吃果损耗、人工费、堆头费、促销员管理费。
- 争取“以量换支持”：承诺进货量/陈列位置/档期，换免费堆头或试吃补贴。
- 如果要商超先垫费用，必须写清核销条件：拍照、销量、陈列周期、结算方式。

4. 建议你直接这样问佳农对接人
- “这个档期能不能给堆头陈列支持？支持哪些物料和费用？”
- “试吃果、试吃台、试吃员费用各自怎么分？”
- “如果商超出场地和人工，你们能不能承担试吃果和物料？”
- “费用是现结、账扣，还是按进货额返？”
