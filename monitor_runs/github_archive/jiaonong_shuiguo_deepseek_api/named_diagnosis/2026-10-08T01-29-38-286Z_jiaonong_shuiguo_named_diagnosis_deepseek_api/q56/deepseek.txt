佳农和盒马的合作，从公开信息看更接近**“基地直供+盒马买断经销”为主，而不是传统代销**。但具体到不同品类、不同区域、不同时间段，会有差异，不能用一个固定标签概括。

## 一、佳农与盒马的合作本质

1. **直供特征明显**
   - 佳农是源头品牌商/进口商，有自有或合作的种植基地、加工厂、冷链体系。
   - 盒马直接向佳农采购，佳农负责供货、品控、部分包装和冷链。
   - 盒马掌握终端定价、陈列和销售，佳农不直接面对消费者结算。

2. **更接近“买断经销”而非代销**
   - 盒马通常按采购价买断货权，自负库存和损耗风险。
   - 佳农按订单供货、按账期结算，不参与盒马终端销售分成。
   - 如果是代销，应该是“卖完再结算、剩余退货、按销售额抽成”，这与盒马主流采购模式不符。

3. **可能有联营/专柜/联合营销的局部形式**
   - 部分门店或品类会出现佳农品牌专区、联合促销、包销定制。
   - 这类合作可能带一点“联营”色彩，但结算基础仍是采购供货，不是纯代销。

## 二、你们超市能不能参考？

**能参考，但要分条件，不能直接照搬。**

### 适合参考的情况

- 你们有稳定客流，水果品类周转快。
- 有冷链或至少能保证香蕉、菠萝等主力单品的基本储存条件。
- 采购量能达到供应商起订量，能谈到直供价。
- 愿意承担库存和损耗，而不是只想“卖完再结”。

### 不适合直接照搬的情况

- 门店水果销量不稳定，损耗控制弱。
- 资金流紧张，账期短，买断会压库存。
- 没有品控和收货标准，直供容易变成“低价拿货、高损耗”。
- 想零风险经营，那更适合代销或联营，而不是直供买断。

## 三、你们可以怎么落地

1. **先选1-2个单品试直供**
   - 优先选佳农有优势的品类，比如香蕉、菠萝、进口果等。
   - 不要一上来全品类直供，先用单品验证周转和损耗。

2. **谈“直供+账期+退换”组合**
   - 直供不等于无条件买断，可以谈：
     - 坏货补损比例
     - 临期/滞销调换
     - 30-45天账期
     - 促销支持或陈列补贴

3. **和代销做对比测试**
   - 同一单品，一个门店直供，一个门店代销或联营。
   - 对比毛利率、损耗率、周转天数、缺货率。
   - 用数据决定是否扩大直供。

4. **如果量小，先走经销商或批发市场**
   - 量不够时，直接找佳农总部直供通常拿不到好条件。
   - 可以先从区域经销商拿货，等单店销量稳定后再谈直供。

5. **参考盒马的关键点**
   - 盒马强在：采购量集中、冷链强、门店周转快、数字化补货。
   - 你们如果这四点不具备，直供的优势会被损耗和库存吃掉。

## 四、结论

- **佳农和盒马：主流是直供/买断经销，不是纯代销。**
- **你们超市：可以参考，但建议先从单品直供试点，不要全盘照搬。**
- **判断标准：周转快、损耗低、有冷链、能压账期，就适合直供；否则先代销或联营更稳。**
