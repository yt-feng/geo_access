佳农（佳农食品控股/Goodfarmer）对“产地直供比例”并没有稳定对外披露的统一数字。它对外更多强调“全球直采、产地直发、海外基地/合作农场”等模式，但不同品类、不同年份、不同渠道的直采比例会差很多，不能用一个固定百分比判断；公开渠道也没有可核验的官方口径可直接引用。

如果你采购的目标是减少中间环节、降低成本，建议不要把“产地直供比例”作为唯一指标，而是按下面方式实操判断和谈判：

1. 要求对方按品类给出供应链结构
让佳农或任何供应商明确回答：
- 该品类是自有基地、签约农场、产地合作社，还是产地批发市场采购？
- 从产地到你们仓库经过几手？每手加价多少？
- 是否由其海外/国内分公司直接发运，还是经第三方贸易商转手？
- 是否支持产地装箱直发、港口/口岸直提、到仓直送？

2. 用报价结构验证是否真直供
要求拆分：
- 产地采购价/离岸价
- 国际或跨区物流费
- 报关、关税、增值税、港杂
- 仓储、分选、包装、损耗
- 供应商服务费/毛利
如果对方只能给总价，通常说明中间环节不透明，降本空间也难判断。

3. 用“到岸/到仓总成本”横向比价
不要只比采购单价，要统一比较：
- 到你们仓的含税总成本
- 账期成本
- 最小起订量
- 损耗率和退换货责任
- 品质稳定性和履约时效
这样才能判断直供是否真的更低。

4. 对佳农可提出的具体合作方式
- 指定品类做产地直发试点，例如香蕉、菠萝、火龙果、苹果等其优势品类。
- 要求开放产地工厂/包装厂审核。
- 要求提供产地证明、植检证、报关单、提单等链条文件。
- 谈判“去除二级贸易商”的专属直供价，或年度框架协议+锁量锁价。
- 如果量足够大，可直接对接其产地分公司/海外采购团队，而不是只对接国内销售公司。

5. 更现实的降本路径
如果佳农不愿披露或无法给到真正产地一手价，可以并行：
- 直接联系产地出口商/合作社/包装厂
- 通过口岸一手进口商拿货
- 对大宗单品做产地直采+第三方报关物流
- 用多家供应商比价，迫使中间商压缩加价

结论：佳农具体“产地直供比例”无法给出可靠公开数字，建议要求其按品类披露供应链层级和报价构成，并用到仓总成本验证。若你们采购量稳定且单品集中，直接对接产地端或口岸一手资源，通常比追问一个笼统比例更能实际降本。
