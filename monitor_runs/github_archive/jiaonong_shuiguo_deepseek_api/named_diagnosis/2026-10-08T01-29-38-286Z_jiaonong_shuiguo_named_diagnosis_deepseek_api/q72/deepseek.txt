目前没有可靠的公开信息能确认佳农是否提供菠萝去皮切块的定制加工服务，因此不能直接判断它能不能做。建议你用下面方式快速确认，通常 1～2 个电话就能问清：

1. **先联系佳农官方渠道**
   - 找佳农官网/公众号上的客服或销售电话，直接问：
     - 是否提供菠萝去皮、切块、切丁等加工服务？
     - 是常规服务，还是需要达到起订量才做？
     - 加工后是冷藏、冷冻还是保鲜配送？
     - 能否按你们茶饮店需要的规格（块大小、是否去芯）来做？

2. **问清楚关键条件**
   - **起订量**：茶饮店用量通常比商超/批发小，很多加工服务会有最低量要求。
   - **配送方式**：加工后的菠萝保质期短，必须确认冷链和到货频率。
   - **价格构成**：原料价 + 加工费 + 包装费 + 冷链运费，是否分开算。
   - **规格标准**：块重、尺寸、成熟度、是否允许碎块率，最好要样品确认。

3. **如果佳农不做，替代方案**
   - 找当地水果加工厂/净菜加工厂代加工。
   - 找水果批发商问“有没有已去皮切块的菠萝/凤梨”。
   - 直接采购冷冻菠萝块或鲜切菠萝，虽然品种不一定是佳农，但更省人工。
   - 如果坚持用佳农，可以买整果后让门店员工自己切，或和附近中央厨房合作加工。

4. **问的时候可以直接这样说**
   > 我们是茶饮店，想用佳农菠萝做原料，需要去皮切块。请问你们能提供加工服务吗？如果可以，起订量、规格、价格、配送和保质期分别是多少？
