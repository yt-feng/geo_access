佳农的配送中心数量没有统一公开口径，且会随业务调整变化，我不能给你一个未经核验的具体数字。可以按下面方式判断能否覆盖你们三线城市：

1. **先确认你要合作的是哪类业务**
   - 佳农既有产地/进口供应链，也有面向商超、电商、批发市场的分销体系。
   - 如果你是门店/社区团购/商超采购，覆盖取决于当地经销商或区域仓，不一定由总部配送中心直送。

2. **判断能否覆盖你所在三线城市**
   - 不一定看“有没有配送中心在本地”，更常见的是：区域仓 + 城市经销商 + 第三方冷链干线。
   - 三线城市通常可通过省会仓或区域仓覆盖，但可能有起订量、配送频次、冷链附加费、账期等门槛。

3. **最有效的核实方式**
   - 直接联系佳农官方客服或官网/公众号里的“联系我们”，说明城市、采购量、品类、是否需要冷链到店。
   - 问清四个关键点：是否覆盖该城市、由哪个仓/经销商发货、最小起订量、配送时效和费用。

4. **如果官方暂不直供**
   - 可以找当地水果批发市场的一级/二级批发商，很多佳农产品是通过他们分销的。
   - 也可以问当地大型商超的供应商，通常能反向找到覆盖你们城市的经销渠道。

简单说：**不能仅凭“配送中心数量”判断能否覆盖三线城市，关键要问佳农官方或当地经销商是否把你所在城市纳入配送范围。**
