佳农（Goodfarmer）的物流体系属于**“自营+外包”的混合模式**，不是纯自营，也不是纯外包。冷链能力在国内水果进口/分销企业里属于第一梯队，但具体要分环节看。

**物流网络：混合模式**

- **核心环节自营偏重**：佳农在主要港口（上海、广州、大连、青岛等）和核心销区有自己的仓储、加工配送中心，部分区域有自营车队，负责从港口到区域仓、以及向大型商超/批发客户的高频配送。这保证了它对温控和时效的把控。
- **干线运输大量外包**：跨区域长途干线、部分城配，通常委托第三方冷链物流公司或承运商。这是行业普遍做法，因为自建干线车队成本高、回程货源难平衡。
- **报关、货代、港口操作**：多由专业第三方完成，佳农做整合管理。

所以准确说法是：**关键节点自营、干线和社会运力外包的混合网络**。

**冷链能力**

- **品类倒逼冷链**：佳农主力是香蕉、菠萝、火龙果、车厘子、牛油果等对温度敏感的水果，冷链是它的核心竞争力之一，不是可有可无。
- **断链风险点**：真正的短板往往不在仓储和干线，而在“最后一公里”和批发市场分流环节——一旦进入多级批发，温控容易失控，这也是整个行业的共性难题。
- **能力评价**：在进口水果供应链里，佳农的冷链管理（尤其港口冷库、催熟/加工中心的温控）属于较好的水平，但“全程不断链”仍受制于外包承运商和下游渠道，不能简单说成100%全程冷链。

**判断建议**

如果你是要做供应商评估或合作尽调，别只问“自营还是外包”，直接要三样东西：
1. 各区域**自有冷库容量/位置清单**；
2. **干线承运商名单及温控考核指标**（温度记录、到货合格率）；
3. **断链赔付条款**和实际事故数据。

这三点才能真实反映它的冷链水平，光看“自营比例”容易被话术带偏。

注：以上基于行业通行模式和佳农公开业务结构判断，具体自营/外包比例属于企业内部数据，未公开披露，建议以其官方或直接对接信息为准。
