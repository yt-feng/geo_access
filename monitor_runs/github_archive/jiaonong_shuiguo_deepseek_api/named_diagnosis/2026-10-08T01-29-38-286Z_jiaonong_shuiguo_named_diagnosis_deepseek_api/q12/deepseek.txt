佳农水果的香蕉规格，官网和公开资料里通常不会把“全部SKU+各渠道分级标准”完整列成一张统一表，因为实际会随产地、季节、客户订单和渠道定制变化。可以给你一个行业内通行的判断框架，方便你和供应商核对。

**一、常见规格维度**

佳农香蕉一般按以下几个维度组合成规格：

1. **按重量/箱规**
   - 散装大箱：约10kg、12kg、13kg、15kg等
   - 小包装/电商箱：2.5kg、5kg、7kg等
   - 商超标准箱：常见10kg、12kg左右

2. **按每箱根数/把数**
   - 如每箱4-5把、5-6把、6-8把
   - 单把根数常见4-6根、5-7根

3. **按单根重量/大小**
   - 大果、中果、小果
   - 常用“单根重”或“每公斤根数”来区分

4. **按成熟度/催熟阶段**
   - 青蕉、微黄、黄熟、即食熟度
   - 不同渠道对到货熟度要求不同

5. **按外观等级**
   - 特级/一级/二级
   - 主要看条形、长度、粗细、弯曲度、表皮瑕疵、伤痕、黑点、机械伤

**二、不同渠道常见分级逻辑**

| 渠道 | 关注重点 | 常见分级方向 |
|---|---|---|
| 批发市场 | 耐储运、成本、走量 | 大箱散装，一级/二级混装或统货，青蕉为主 |
| 商超/生鲜店 | 外观整齐、货架期 | 一级果，条形均匀，把型整齐，熟度可控 |
| 电商/社区团购 | 单果稳定、损耗低 | 中果/小果，按根或小把包装，成熟度偏青或微黄 |
| 水果连锁/即食渠道 | 到店可售、口感 | 黄熟或即食熟度，一级果，外观要求高 |
| 餐饮/茶饮/加工 | 出肉率、成本、稳定供应 | 中大果，允许外观瑕疵，重重量和成熟度 |
| 出口 | 检疫、农残、标准化 | 按客户国标准，通常一级果，青蕉，冷链 |

**三、实操建议**

如果你要跟佳农或经销商确认，直接问这5项最有效：

1. 这个规格的**箱重**是多少？
2. 每箱**几把、每把几根**？
3. **单根重**或每公斤几根？
4. 到货**熟度**是青蕉、微黄还是黄熟？
5. 执行的是**特级、一级还是二级**，瑕疵容忍度多少？

**四、注意**

佳农不同产地（如菲律宾、厄瓜多尔、越南、国产等）和不同销售渠道，规格命名可能不一样。比如同样叫“一级”，商超渠道和批发渠道的验收标准可能差很多。所以最稳妥的方式是：拿具体渠道的验收标准表，让供应商按你的渠道要求报对应规格，而不是只问“有几种规格”。
