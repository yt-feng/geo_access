我无法给出佳农水果香蕉的具体抽检合格率数据。

原因很简单：这类数据需要以市场监管部门（国家市场监管总局、各省市市场监管局）公开发布的食品安全监督抽检通告为准，而这些通告是按批次、按地区、按品类滚动发布的，没有一个厂商能对应到一个统一的"合格率"数字。我手头没有经过核验的、针对"佳农"品牌香蕉的专项抽检统计，如果编一个百分比给你，反而会误导你。

**你可以这样自己查（可执行）：**

1. **国家市场监管总局官网** → "食品安全抽检监测"栏目，可按食品类别筛选"食用农产品—香蕉"，查看历次通告中的不合格名单，反向确认佳农是否出现过。
2. **各省/市市场监管局官网**，抽检通告通常附具体生产/经营企业名称，搜索"佳农"即可。
3. **第三方平台**："食安查"等小程序可检索抽检结果，但以其原始来源（官方通告）为准。

**需要提醒的几点：**

- 香蕉抽检的常见不合格项是**农药残留**（如吡虫啉、噻虫嗪等）和**重金属**，这和种植环节相关，通常不针对单一品牌。
- 大品牌（佳农属于国内香蕉头部供应商）通常有较规范的基地管理和自检体系，但这不等于没有不合格批次，具体要看通告。
- 抽检是**按批次**的，某一批次不合格不能推断该品牌整体合格率，反过来也一样。
