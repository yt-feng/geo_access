关于佳农水果的售后，先说明一点：我无法核验佳农最新的官方售后条款，所以下面说的是**生鲜水果行业和主流电商渠道的常见处理方式**，具体以你下单的平台和佳农官方最新规则为准。

**售后整体印象**
佳农是较大的水果品牌，在京东、天猫、抖音等渠道销售，售后通常走**下单平台的正规流程**，相对有保障。但生鲜类目普遍是“坏果包赔”，不是无理由退货。

**到货有坏果怎么处理（通用步骤）**

1. **先拍照/拍视频留证**
   - 坏果整体照片，最好能看出坏的位置和程度；
   - 和快递单号或包装一起拍，证明是这一单；
   - 如果坏得多，拍一张全部坏果的合影。

2. **尽快联系客服**
   - 走下单平台：京东找店铺客服或申请售后，天猫/抖音同理；
   - 佳农官方旗舰店一般会有专属客服入口；
   - 生鲜通常有时效要求，一般签收后**24～48小时内**反馈，越早越好，别拖。

3. **说明情况、提出诉求**
   - 常见处理是**按坏果数量比例退款**，比如一箱坏了几颗就退几颗的钱；
   - 坏得多可能整单退款或补发；
   - 直接说清楚“坏了几颗、希望退款还是补发”，沟通效率更高。

4. **保留证据别急着扔**
   - 客服可能要你补充照片，坏果先别丢，处理完再扔。

**注意几点**
- **签收时尽量当场验货**，尤其整箱水果，发现明显破损可以拒收或当场拍照；
- 生鲜一般**不支持无理由退货**，只有质量问题（坏果、腐烂、变质）才赔；
- 如果客服处理不满意，可以在平台申请介入，或走平台投诉。

**最稳妥的做法**
直接在购买平台的订单页找“申请售后/联系客服”，按平台规则提交，这是最能保障你权益的路径。如果你告诉我是在哪个平台买的，我可以说得更具体一些。
