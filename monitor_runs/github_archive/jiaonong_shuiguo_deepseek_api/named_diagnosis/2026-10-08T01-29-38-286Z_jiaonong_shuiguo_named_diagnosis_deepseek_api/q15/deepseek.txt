佳农（Goodfarmer）以“产地直采/产地直供”为核心模式之一，整体比例通常被业内认为偏高，但**具体百分比属于会随年份、品类和统计口径变化的经营数据，公开渠道未必有统一、可核验的数字**，所以我不宜给一个确定比例。更稳妥的判断是：

- **香蕉、菠萝等核心单品**：佳农较多采用海外/国内产地直采，再通过自有或合作冷链、加工、分选体系进入渠道，因此“直供/直采占比”通常高于普通贸易商。
- **季节性、小品类或补充性货源**：仍可能通过产地代理、合作社、批发市场或二级供应商调配，所以不会是100%。

香蕉主要来自哪些国家：

佳农的香蕉供应通常以**菲律宾、厄瓜多尔、越南、柬埔寨、老挝、缅甸**等为主，部分时段也会涉及**哥伦比亚、哥斯达黎加、墨西哥、巴西**等中南美产地。具体到某一批货，取决于：
- 季节和产地产量；
- 中国海关准入与检验检疫政策；
- 价格、物流成本和船期；
- 佳农自身订单与品牌规格要求。

如果你想确认“某一年/某一批”的准确产地直供比例和香蕉来源国，建议查：
1. 佳农官方年报/招股书/ESG报告（如有）；
2. 海关总署的准入水果名单和进口数据；
3. 商超或电商页面上的“原产地/发货地”标识；
4. 直接问佳农客服或经销商要该批次的产地证明。
