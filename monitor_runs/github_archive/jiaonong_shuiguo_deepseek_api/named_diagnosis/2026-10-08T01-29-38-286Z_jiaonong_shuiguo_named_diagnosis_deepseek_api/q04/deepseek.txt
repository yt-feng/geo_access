佳农（Goodfarmer）是一家以香蕉、菠萝等进口水果为主的企业，主要做批发和商超渠道，其结算方式通常需要直接和对应的销售/大客户部门确认，公开渠道一般查不到统一的账期政策。

从行业惯例判断，针对长期合作客户，佳农**大概率会有账期方案**，但通常基于以下条件：

- **合作体量与稳定性**：年采购额、月度走量是否稳定，是能否谈账期的核心。
- **客户类型**：大型商超、连锁水果店、电商平台通常比小批发商更容易拿到账期。
- **信用与担保**：可能需要营业执照、对公账户、历史交易记录，部分情况要求保证金或担保。
- **账期形式**：常见为货到后 15/30/45/60 天，或“月结”，具体因品类和地区而异。
- **生鲜特殊性**：水果损耗和价格波动大，账期往往比标品短，且可能配合“先款后货→逐步放宽”的过渡。

**建议你直接这样确认：**
1. 联系佳农官方客服或你所在区域的销售负责人，说明你是长期采购方。
2. 提供预估年采购量、结算习惯、合作渠道。
3. 直接问：长期合作客户能否申请月结/账期，账期天数、起算方式、是否需要保证金或授信审批。
