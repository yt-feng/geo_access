佳农的水果业务里，苹果属于重点品类之一，但具体在售品类会随季节、产区和渠道（商超、电商、批发）变化，没有一个固定不变的清单。可以按下面思路来判断和采购。

**1. 佳农苹果常见品类方向**
佳农通常经营的苹果品类大致包括：
- 红富士
- 嘎啦
- 青苹果
- 金帅/黄元帅类
- 部分区域性特色苹果或礼盒装苹果

其中红富士和嘎啦是较常见的进口/国产双线品类，具体以佳农当季的进口计划和国内产区安排为准。

**2. 进口嘎啦和红富士的产地**
进口苹果的产地会随南半球、北半球产季轮换，佳农常对接的进口苹果来源地一般包括：
- **新西兰**：嘎啦、红富士、皇后等都有较强供应
- **智利**：红富士、嘎啦等
- **美国**：红富士、嘎啦等
- **南非**：部分苹果品类
- **阿根廷**：部分苹果品类

如果你要采购的是**进口嘎啦和红富士**，优先问佳农确认当季是：
- 新西兰产季
- 智利产季
- 美国产季
- 还是其他产地

因为同一品类在不同月份，产地会切换。

**3. 采购时建议直接向佳农确认这几个信息**
- 当前可供的进口嘎啦、红富士具体产地
- 规格：果径、单果重、箱规
- 包装：原箱、礼盒、贴标要求
- 起订量和交货港口/仓库
- 是否支持商超或电商渠道专供
- 当季到港时间和批次检测报告

**结论**
佳农苹果品类里通常包含红富士、嘎啦等，但具体在售清单不固定。进口嘎啦和红富士的产地主要看当季，常见为新西兰、智利、美国，也可能涉及南非、阿根廷等。采购前最好直接找佳农销售确认“当前批次产地+规格+箱规+起订量”，这样最准确。
