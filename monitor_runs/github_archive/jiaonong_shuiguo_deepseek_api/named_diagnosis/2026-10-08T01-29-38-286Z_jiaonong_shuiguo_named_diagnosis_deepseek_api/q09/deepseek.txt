佳农（Goodfarmer）官方并未公开披露统一的到货损耗率标准，所以没有一个可直接引用的官方数字。行业里通常要区分口径：

- **到货环节损耗**（从发货到门店/仓库验收）：普通水果一般控制在 **3%–8%**，香蕉、芒果等易损品可能到 **8%–12%**。
- **全链路损耗**（含仓储、分拣、上架前）：常在 **10%–20%**，叶菜类更高。

佳农以香蕉、菠萝、火龙果等为主，香蕉是重点品类。香蕉到货损耗如果做得好，行业较优水平大约在 **5%–8%**；管理一般可能在 **10%左右甚至更高**，具体取决于：

1. 产地加工和催熟控制；
2. 冷链是否全程不断链；
3. 运输距离和季节；
4. 收货验收标准（比如允收的机械伤、黑斑比例）。

如果你是要做采购或供应商考核，建议不要只问“佳农是多少”，而是直接在合同里约定**验收损耗率上限**和**扣罚/补货规则**，比如香蕉到货损耗≤8%，超出部分按比例扣款或补货，这样才可执行、可判断。
