我无法核验“佳农水果菠萝进口量11.4万吨”这个数据的具体年份。这个数字是否属于去年，需要看它出自哪里。

你可以用这几个办法快速判断：

1. **看原始出处**
   - 如果来自佳农官方新闻稿、年报、进博会/展会通稿，通常会写明“2023年”“2024年”或“截至某年”。
   - 如果来自媒体报道，注意看正文有没有“去年”“2023年”“2024年”等时间限定。

2. **看发布/release时间**
   - 2024年发布的稿子里说“去年”，一般指2023年。
   - 2025年发布的稿子里说“去年”，一般指2024年。
   - 但如果稿子本身是旧闻转载，发布时间就不能直接当作数据年份。

3. **和公开行业数据交叉验证**
   - 中国海关总署的进口数据按“鲜或干的菠萝”等HS编码统计，可以查年度总量。
   - 菲律宾、厄瓜多尔、泰国等主产国的对华出口数据也能侧面印证。
   - 如果11.4万吨接近中国全年菠萝进口总量的较大比例，再看佳农是否为头部进口商，逻辑上才更成立。

4. **直接问发布方**
   - 问佳农官方客服/公关，或问转载媒体：这11.4万吨对应哪个年度、是进口量还是销售量、是佳农自身还是含代理。
