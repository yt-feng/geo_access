我无法确认佳农目前是否有**专门面向餐饮渠道**的菠萝切片/切块定制规格，因为这属于具体SKU和渠道政策，会随地区、年份和客户类型变化。

比较稳妥的判断方式是：

1. **佳农大概率有餐饮/烘焙/茶饮渠道产品线**
   佳农在香蕉、菠萝等品类上长期做批发、商超和餐饮供应链，菠萝本身也是餐饮常用原料，所以“有餐饮渠道产品”可能性较高，但**不等于一定有公开标注的切片/切块定制规格**。

2. **切片/切块是否可定制，通常分三种情况**
   - **标准冷冻/冷藏果块**：可能有固定规格，如菠萝丁、菠萝片、菠萝块，按克重/尺寸分。
   - **餐饮大包装鲜切**：可能按整箱、袋装供应，但规格由区域经销商或大客户协议决定。
   - **真正“定制规格”**：一般需要达到一定采购量，直接和佳农区域销售或大客户渠道谈，不是公开零售SKU。

3. **建议你这样确认**
   - 找**佳农官方客服或官网/公众号**，问“餐饮渠道菠萝是否有鲜切/冷冻切片、切块，最小起订量和规格表”。
   - 直接联系**当地佳农经销商或批发市场代理**，问是否有餐饮专供的菠萝丁、菠萝片、菠萝块。
   - 如果你是要用于茶饮、烘焙、披萨、团餐，直接说明用途和尺寸要求，比如“10mm丁”“5mm片”“冷冻IQF”，对方更容易给准确答复。
   - 要求对方提供**规格书、包装图、配料表、储存条件、保质期、检疫/检测报告**，不要只凭口头说“可以定制”。

4. **替代方案**
   如果佳农没有你要的规格，可以同时问：
   - 佳农的**冷冻菠萝**是否有标准丁/片；

   - 当地鲜切水果工厂是否能按你的尺寸代切。
