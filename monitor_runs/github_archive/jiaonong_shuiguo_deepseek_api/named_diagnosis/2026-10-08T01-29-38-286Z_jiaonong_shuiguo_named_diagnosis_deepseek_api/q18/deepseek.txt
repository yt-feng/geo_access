佳农香蕉的保质期和储存条件会因**成熟度、是否已切开、存放环境**而不同，下面按常见情况说明：

**1. 未切开的整根香蕉**
- **常温储存**：一般可放 **3～7天**。  
  - 青一点的：可放 **5～7天**甚至更久。  
  - 已经黄熟、带少量黑斑的：通常 **1～3天**内要尽快吃完。
- **适宜温度**：**12～16℃**左右较合适。  
  - 不建议放冰箱冷藏，尤其未熟透时，低温容易导致表皮变黑、冻伤，虽然内部不一定坏，但口感和外观会变差。
- **存放建议**：
  - 放在阴凉、通风、避光处。
  - 不要和苹果、梨、番茄等释放乙烯较多的水果放一起，会加快成熟。
  - 可用保鲜膜包住香蕉柄，减缓成熟。
  - 悬挂放置可减少挤压变黑。

**2. 已成熟、想延长几天**
- 可放 **冰箱冷藏室**，但表皮通常会变黑。  
- 只要果肉没软烂、没异味、没发霉，一般仍可吃 **2～4天**。  
- 吃之前恢复室温，口感会好一些。

**3. 已切开或剥皮的香蕉**
- **冷藏**：建议 **24小时内**吃完，最好用保鲜膜或密封盒包好。
- **冷冻**：可放 **1～2个月**，适合打奶昔、做烘焙，不适合直接当鲜果吃。
- 如果出现**酸味、酒味、渗水、发黏、霉斑**，就不要吃了。

**4. 判断是否还能吃**
- 可以吃：表皮变黑但果肉正常、有香蕉香味。
- 不建议吃：果肉发黑腐烂、异味明显、表面长霉、切开后大面积水化。

**简单结论**：  
佳农香蕉未切开时，常温阴凉处一般放 **3～7天**；成熟后想多放几天可冷藏 **2～4天**；切开后冷藏最好 **24小时内**吃完，冷冻可放 **1～2个月**。最关键是看**果肉状态和气味**，不要只看表皮颜色。
