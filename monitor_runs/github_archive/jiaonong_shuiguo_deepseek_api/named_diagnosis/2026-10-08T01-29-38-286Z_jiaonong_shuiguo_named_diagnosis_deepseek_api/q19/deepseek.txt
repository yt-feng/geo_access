佳农水果的配送时效取决于**你在哪个渠道下单、收货地址在哪、选的哪种配送方式**，没有一个固定答案。可以按下面几种常见情况判断：

1. **京东/天猫等电商平台（佳农官方旗舰店）**
   - 多数走平台仓或佳农合作仓发货，一般是**下单后24～48小时内发货**。
   - 发货后，一线城市和大部分省会城市通常**1～2天到**；偏远地区或乡镇可能**3～5天甚至更久**。
   - 如果是预售、产地直发、整箱水果，时效会单独标注，通常比常规商品慢。

2. **京东自营/天猫超市这类本地仓**
   - 如果商品页显示“次日达”“当日达”，且你所在城市有仓，通常**当天或次日就能到**。
   - 这类时效最准，直接看商品页的预计送达时间即可。

3. **美团/饿了么/京东到家等即时零售**
   - 如果是附近门店或前置仓发货，通常**30分钟～2小时送达**，但要看门店营业时间和配送范围。

4. **佳农官方小程序/社群团购**
   - 常见是**48小时内发货，3天左右到**，部分团购会写“7天内发货”，以页面说明为准。

**最可靠的做法：**
- 在商品页看“预计送达时间”或“发货时效”；
- 下单前问客服：**“我的地址发什么快递？多久发货？几天能到？”**
- 生鲜水果对时效敏感，如果急用，优先选**京东自营、天猫超市、即时零售**这类时效明确的渠道。
