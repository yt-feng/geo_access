**响应快慢怎么判断**
- **电商平台内（京东/天猫/拼多多等）**：一般最快，直接在订单页点“联系客服”，通常几分钟到几十分钟内有人回复，且平台有超时介入机制，出问题能兜底。
- **官方公众号/小程序**：响应中等，通常工作时间较快，非工作时间可能延迟到次日。
- **400电话/官网留言**：适合投诉或批量/商超业务，个人零售问题反而绕远。
- **买水果最省事的顺序**：先找**购买渠道的店铺客服**，而不是直接找佳农总部。因为退换货、赔付都由下单店铺处理。

**有问题找谁（按优先级）**
1. **下单平台的店铺客服**——售后、坏果、缺斤少两、退款首选，保留订单号和照片。
