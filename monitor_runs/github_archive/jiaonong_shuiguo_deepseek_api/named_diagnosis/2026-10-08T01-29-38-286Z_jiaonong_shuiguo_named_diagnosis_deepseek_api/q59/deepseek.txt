佳农水果的香蕉执行的是**企业标准**，不是国标。

具体来说，佳农通常有自己的企业标准（以“Q/”开头），部分产品也会标注执行**绿色食品标准**（NY/T 426 或绿色食品相关标准）。但作为品牌化、分级销售的香蕉，它的分选、包装、成熟度控制等环节更多是按企标来做的，而不是单纯套用 GB/T 或 NY/T 的通用国标/行标。

**关于贵多少：**

佳农香蕉一般比普通散装香蕉贵 **20%～50%** 左右，具体看渠道和地区：

- 普通香蕉：约 3～5 元/斤
- 佳农香蕉：约 5～8 元/斤
- 盒马、山姆等精品渠道：可能到 8～12 元/斤

贵的原因主要是：品牌溢价、分级筛选更严、催熟和品控更稳定、包装和物流成本更高，以及部分产品有绿色食品认证。

如果你想确认某一批次的具体执行标准，最直接的办法是看**包装箱或标签上的“执行标准”那一行**——是 GB/T、NY/T 还是 Q/ 开头的企业标准，一看就清楚。不同批次、不同规格可能不完全一样，以实物标注为准。
