我无法确认佳农当前是否能提供产地溯源和品控报告。这类信息属于企业具体的供应链服务政策，会因产品线、采购渠道和合作模式不同而变化，我没有可核验的官方来源来给你确定答案。

不过可以给你一套**判断和核实的方法**，采购时按这个流程走，基本能弄清楚：

**1. 先明确你要的“溯源”到什么程度**
- 产地溯源：能否追溯到具体国家、产区、果园/合作社、批次
- 品控报告：农残检测、重金属、糖度/成熟度、外观分级等
- 常见形式：批次检测报告（COA）、第三方检测（SGS、华测、Intertek等）、产地证明、出口国植检证书

**2. 直接向对方要，不要只听口头承诺**
问清楚这几个问题：
- 每个批次是否随货提供检测报告？
- 报告是第三方还是自检？检测项目有哪些？
- 溯源是到“国家/产区”还是到“果园/批次”？系统能否扫码查？
- 出问题时的退换货和赔付标准是什么？

**3. 分渠道核实**
- 走**佳农官方/授权经销商**：直接要资质、检测报告模板、溯源样例，最可靠
- 走**批发市场/中间商**：要求提供上游授权和对应批次报告，谨防“借用”别家报告
- 走**电商/商超**：可看商品页是否标注产地和检测信息，但通常不如B2B直采详细

**4. 建议的采购动作**
- 先索要**一份历史批次的检测报告和溯源样例**，看格式和真实性
- 首单做**小批量试单**，自己送检或核对随货报告
- 把“随货提供对应批次检测报告、可溯源到产区/批次”写进采购合同

如果你告诉我你是**B2B批发直采**还是**电商/商超渠道**、大概采购量，我可以帮你把要问的问题清单和合同条款写得更具体。
