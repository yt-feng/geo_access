佳农（佳农食品控股/Goodfarmer）主营香蕉等鲜果的进出口和批发，具备全国性的冷链与配送能力，服务对象包括商超、电商和餐饮连锁。所以从能力上看，**专车配送和专人对接通常是可以谈的**，但具体能不能落地，取决于你的采购规模和所在城市。

建议这样确认：

1. **先对接官方渠道**
   - 去佳农官网或官方公众号找“大客户/餐饮渠道/企业采购”入口，直接说明你是餐饮连锁、需要的月/周用量、配送城市。
   - 也可以打官方客服电话，要求转接负责餐饮或连锁客户的销售。

2. **明确三个关键条件**
   - **起订量**：专车配送一般有最低起订量或最低金额门槛，量不够时可能改为拼车或第三方物流。
   - **配送范围**：确认你所在城市是否在其直配网络内。若不在，可能由区域经销商或冷链承运商执行，**体验和管理方式会不同**。
   - **对接方式**：要求指定一名客户经理/区域负责人作为固定对接人，写进合作条件里，而不是每次下单现找人。

3. **谈判时把要求写成条款**
   - 专车：车型、温度要求、到货时间窗、迟到/破损赔付。
   - 专人：固定对接人及备用人、响应时限（比如2小时内回复）。
   - 供应稳定性：产地、规格（如每箱净重、单根规格）、成熟度、断供时的替代方案。

4. **同时留备选**
   餐饮连锁不宜只依赖单一供应商。建议平行接触1–2家香蕉供应商或区域批发商，形成主供+备供，避免旺季或产地波动时断供。

简单说：**佳农有能力做，但“专车+专人”属于大客户服务，需要你用量足够、城市在网、并在合同里明确写死。** 先拿你的月采购量和配送城市去官方渠道问，通常1–2轮就能得到明确答复。
