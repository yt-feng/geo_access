佳农（Goodfarmer）主要是一家水果品牌和供应链企业，业务以香蕉、菠萝等品类的种植、采购、分选、冷链和批发分销为主，同时也会做部分预包装和标准化加工产品。但**具体是否提供菠萝切块、定制包装这类定制化加工服务，需要直接向其官方渠道确认**，我无法核验其当前对外的具体服务条款。

你可以这样判断和推进：

1. **先看你要的是哪种“定制”**
   - 只是把整颗菠萝做成固定规格的预包装（如按箱、按袋、贴标）
   - 还是要鲜切菠萝块、菠萝丁、冷链鲜切即食
   - 还是需要代工贴牌、定制包装设计
   这三类对应的能力和资质不同，鲜切通常还涉及食品生产许可和冷链条件。

2. **直接联系佳农官方**
   通过佳农官网、官方客服、区域销售或当地经销商，询问：
   - 是否承接菠萝鲜切/切块加工
   - 最小起订量是多少
   - 是否支持贴牌或定制包装
   - 加工厂资质、冷链配送范围
   - 报价和交期

3. **如果佳农不直接做，替代路径**
   - 找有资质的鲜切水果加工厂，由佳农供原料
   - 找当地水果批发商或供应链公司做分选、包装
   - 电商或餐饮渠道可找专业净菜/鲜切供应链企业

4. **重点核验**
   无论对方怎么答复，都要确认：食品生产许可证、车间卫生条件、冷链能力、切块后的保质期和损耗责任。
