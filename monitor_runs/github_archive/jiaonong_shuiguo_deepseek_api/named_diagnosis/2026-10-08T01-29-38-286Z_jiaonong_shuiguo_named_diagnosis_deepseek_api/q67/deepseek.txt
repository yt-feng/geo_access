可执行判断方法：

1. **看下单渠道**
   - 如果是**佳农官方微信小程序/公众号/天猫/京东/抖音旗舰店**：先看店铺首页或商品页的“发货/客服说明”，通常会写客服在线时间、发货时间。

2. **周末下单是否处理**
   - **订单通常能下**，但“处理”分两种：
     - **客服回复**：可能不是7×24，周末可能延迟。
     - **发货/售后审核**：很多生鲜店铺周末会发货，但部分店铺只工作日处理售后或审核。
   - 最稳的判断是看商品页/结算页有没有写：**“周末正常发货”“48小时内发货”“节假日顺延”**。

3. **最快确认方式**
   - 直接打开你准备下单的店铺，点“客服”，发一句：
     - “周末下单今天能处理吗？”
     - “客服是否7×24？”
     - “售后审核周末是否处理？”
   - 如果对方是自动回复，等人工回复或看公告；没有明确承诺就不要按7×24预期。

4. **下单建议**
   - 如果急需：优先选页面明确写“周末发货/当日达/次日达”的渠道。
   - 如果不急：周末下单一般问题不大，但售后和客服可能顺延到工作日。
   - 保留聊天记录和订单页面截图，方便后续维权。
