佳农香蕉的保质期和储存条件主要取决于购买时的成熟度以及存放环境，以下是一般性的参考：

**保质期**  
- 未开封、常温下（20℃左右）：通常在3~7天，具体看购买时的成熟度（如全绿较硬可放更久，全黄至有斑点则较短）。
- 冷藏（冰箱）后：可延长至7~10天，但果皮可能变黑，果肉仍可食用。
- 冷冻：若剥皮切块冷冻，可保存1~3个月（用于烘焙、奶昔）。

**储存条件**  
- **未成熟（偏绿）**：放在室温、避光、通风处，避免阳光直射和高温（不要放冰箱，会中断成熟过程）。
- **已成熟（全黄或有黑点）**：建议尽快食用；若需延长保存，可放冰箱冷藏（果皮变黑属正常，果肉不受影响）。
- **不要密封存放**：香蕉会释放乙烯气体，密封易加速过熟、发霉。
- **与其他水果分开**：避免与苹果、梨等同放，它们会催熟香蕉。
- **悬挂或平放**：减少受压，避免挤压损伤。

**特别提示**  
- 若果肉有异味、发黏、发黑或霉变，说明已变质，请勿食用。
- 冰箱保存时，最好用保鲜膜包裹香蕉柄部，可减缓成熟速度。

以上为通用建议，具体请以购买时的包装标签为准。如果包装上有明确标注，优先按标签执行。
