关于佳农水果香蕉的具体规格和分级标准，由于企业可能根据市场、产区和季节调整，且属于内部商业信息，我无法提供100%准确的官方数据。不过，根据国内香蕉行业通用标准及佳农的市场运作，可以给你以下参考信息：

**常见规格分类（按单根重量或梳把大小）：**

1.  **出口级/特级（高端渠道）**：单根香蕉重量约在 **180g-220g** 以上，果形笔直，色泽金黄，无斑无伤，梳把整齐，通常用于高端商超、精品水果店或礼品盒。
2.  **一级（主流商超）**：单根重量约 **150g-180g**，果指饱满，成熟度控制精准，适合商超货架、电商平台（如盒马、叮咚等）。
3.  **二级（批发/餐饮渠道）**：单根重量约 **120g-150g**，果形稍有弯曲或大小不均，但品质稳定，多用于水果拼盘、餐饮连锁、食堂供应。
4.  **工业级/次级**：重量低于120g，或有轻微瑕疵，通常用于加工（香蕉片、果泥）或特价促销渠道。

**分级核心维度（不限于重量）：**

-   **成熟度**：佳农通常按“催熟度”或“乙烯利处理”分档，例如4-5成（青果，运输用）、6-7成（上架后常温催熟）、8成以上（即食，保鲜要求高）。
-   **果指长度**：长度超过22cm为特级，18-22cm为A级，15-18cm为B级。
-   **外观瑕疵**：无黑斑、无压痕、无腐烂、果皮光滑度为硬性指标。
-   **糖度**：出口级通常要求糖度在20度以上（具体视采收期）。

**渠道适配建议（供你参考）：**

-   **高端商超/精品店**：选特级或一级，强调外观、品牌包装和单果重量。
-   **电商/社区团购**：一级为主，兼顾成本和到家损耗，通常按“5斤/9斤”组合。
-   **餐饮/批发**：二级或散装，看中性价比和量。
