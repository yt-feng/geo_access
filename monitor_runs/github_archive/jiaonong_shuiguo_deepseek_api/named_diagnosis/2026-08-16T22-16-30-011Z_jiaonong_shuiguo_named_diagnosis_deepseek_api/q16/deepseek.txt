关于佳农水果的售后政策和坏果处理方式，我可以给你一个基于常见情况的参考，但具体细节（如赔付标准、理赔时效）可能会随季节、购买平台（天猫、京东、拼多多、官方小程序等）及促销活动而调整。

**一、售后服务整体评价（基于公开反馈）**
佳农作为大型水果品牌，其售后体系相对正规：
- **响应渠道**：主要依托购买店铺的客服体系，同时官网/小程序通常也有“售后中心”。
- **赔付态度**：对“坏果”问题（运输挤压、腐烂）通常执行“坏果按比例赔偿”或“部分退款”，极少出现“整单免费重发”（除非整箱全坏且无法食用）。
- **关注重点**：理赔是否顺利，很大程度取决于你是否**在收货后24小时内**（核心条件）提供**清晰的坏果与快递单号合照**。

**二、如果到货有坏果，标准处理流程（务必按此顺序执行）**

1. **不要丢弃**：收到后请先**保留快递外箱、所有坏果及包装盒**，不要立刻扔进垃圾桶。
2. **拍照留证**：拍摄一组清晰照片/视频，必须包含：
   - **快递单号**（外箱贴纸清晰可见）；
   - **坏果特写**（尽量放大腐烂部分，能和手指或硬币对比大小）；
   - **整箱全景**（显示箱内剩余水果数量）。
3. **立即联系客服**：在**收货后12-24小时内**（越快越好），进入你购买的店铺（如天猫佳农旗舰店、京东自营等），点击“联系客服”，选择“人工”，直接发送上述照片，并告知“订单号+坏果数量”。
4. **等待审核**：客服会核验照片，若符合标准，通常会按“坏果数 ÷ 总个数 × 订单实付金额”计算退款，或提供相应金额的优惠券。
5. **协商确认**：如果对方要求你“先寄回坏果”（常见于整箱完全变质），请先确认**运费由谁承担**（一般应由商家承担），再决定是否操作。

**三、关键防坑提醒（务必注意）**
- **时效是生命线**：绝大多数生鲜水果明确拒绝“超时售后”（超过48小时基本不理赔）。
- **拒收不等于售后**：如果快递派送时发现外箱明显破损，建议**先拍照再签收**，签收后马上开箱检查；若外观完好但内部坏果，仍按上述流程处理。
- **不适用“七天无理由”**：水果属于生鲜易腐商品，除非有质量问题，否则不支持无理由退货，所以别考虑“不喜欢就退”。
- **若平台客服推诿**：可通过购买平台（如淘宝/京东）的“官方客服介入”渠道申诉，上传之前的聊天记录和照片，通常平台会介入仲裁。
