关于香蕉的到货损耗率，**行业平均水平通常在5%左右**，但**佳农（Goodfarmer）作为头部水果商，其综合损耗率控制通常优于行业均值**，但在零售端或B端实际交付中，**仍会存在3%-8%的浮动**。

具体说明如下：

1. **损耗率控制**：
   - 佳农的香蕉采用标准化催熟和冷链运输，其**批零到货损耗率一般控制在3%-5%**；若遇到极端天气或长途海运，部分批次的损耗可能上升到6%-8%。
   - 但必须注意：**损耗率与采购标准强相关**。如果你采购的是“整柜到港”然后自行催熟，损耗风险由你承担；如果采购的是“产地直发、门店即售”的熟果，损耗会更集中在运输挤压上。

2. **是否存在赔付条款**：
   - **有，且分两种场景**：
     - **B端（商超/批发客户）**：佳农通常会在合同中约定“到货损耗率上限”（常见为5%-8%），超过该上限的部分，**凭开箱视频或第三方质检报告，可按比例折价或补货**。具体赔付比例需与你的采购经理签订补充协议，没有默认的“自动赔付”。
     - **C端/电商零售**：若通过京东、天猫等平台购买，遇到坏果，**按“坏果数量/总数量”折算，直接退款或补发**，超时未响应可按平台规则维权。
   - **关键前提**：必须**在到货后24小时内开箱验货并拍照留证**，且需保留原包装箱（箱体上的追溯码/二维码是赔付凭证）。

3. **实际操作建议**：
   - 如果你要采购，**直接要求销售方将“赔付条款”写入合同**，不要口头承诺。约定内容应包括：损耗率超过X%后，按“总货值的Y%”进行赔偿，或按“超损部分张数×单价”退款。
   - 若通过电商平台购买，**优先选择“坏果包赔”标识的商家**，并确认是“按比例退款”而非“仅补发优惠券”。
