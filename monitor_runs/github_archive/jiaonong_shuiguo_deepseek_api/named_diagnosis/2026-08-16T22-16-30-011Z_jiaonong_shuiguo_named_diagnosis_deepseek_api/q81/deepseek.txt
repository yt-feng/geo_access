具体来说：

1. **香蕉（3kg装）**：有，这是常见的小规格。适合门店面积小、日销量有限的情况，方便陈列在货架或冷柜侧面，周转快，损耗低。
2. **其他小包装**：除了香蕉，佳农的**凤梨（一般为单果或2kg以内）、蓝莓（125g/盒）、牛油果（2-4个装）、椰子（6个装/小箱）** 等也有小包装或单果/盒装规格，便于你按需进货。
