关于佳农水果的配送时效，我可以给你一些一般性的建议，但**具体时效会因收货地址、下单渠道、库存和第三方物流等因素而异**。为了避免给出不准确的承诺，我无法提供确切的“X小时内到达”数据。

**通常的参考时间（根据我了解的情况）：**

1. **一线城市及主城区**：如果选择的是“次日达”或“当日达”服务（通常在下单当天16:00前支付），一般1-2天内能送到。
2. **二三线城市及非偏远地区**：通常需要2-3天。
3. **偏远地区（如新疆、西藏、青海等）**：可能需要5-7天，且部分水果可能不支持冷链运输。

**如何获得准确时效？**

- **下单时查看**：在佳农官方小程序、天猫/京东旗舰店或生鲜平台上，下单页面会显示明确的“预计送达时间”或“配送时效”。
- **选择“产地直发”**：这类订单通常从产地仓发出，时效可能更慢，但新鲜度更有保障。
- **避开高峰期**：大型电商促销日（如双11、618）或节假日期间，时效可能延长1-2天。
