佳农（Goodfarmer）确实有水果礼盒产品，且其定位中高端，尤其适合节日送礼或企业团购场景。

具体来说：

- **礼盒类型**：佳农常见的有**香蕉礼盒**、**菠萝/凤梨礼盒**、**牛油果礼盒**、**椰青礼盒**以及**混合水果礼盒**（例如搭配苹果、橙子、樱桃等）。部分礼盒会配有时令水果组合。
- **团购渠道**：你如果要做礼品团购，一般可以通过以下方式购买：
  1. **官方电商旗舰店**（天猫、京东的佳农官方旗舰店）中通常有“企业购”或“团购”入口，可以询价和批量下单。
  2. **线下经销商/批发市场**：佳农在一些城市有直营或授权经销商，直接联系本地区的销售代表，可以谈定制礼盒（比如更换水果配比、加印企业Logo等）。
  3. **大客户服务热线**：佳农官网或官方公众号通常留有企业团购联系方式。

**建议**：礼品团购最看重的是**新鲜度和配送时效**，如果你是对接企业客户，建议提前3-5天下单，并确认是否有冷链配送。此外，旺季（如中秋、春节）团购人数较多时，优先联系官方销售锁定库存。

如果你需要更具体的报价或当地经销商联系方式，建议你直接打开佳农官方微信公众号，在菜单里查找“企业团购”或“联系我们”，信息最准确。
