关于佳农香蕉的分级标准，目前**没有公开的统一官方价格表**，因为价格会随产地、季节、市场行情、采购量而实时波动。不过，根据行业通用的香蕉分级逻辑，可以给你提供参考框架：

**1. 分级标准（通常依据果指长度、外观、成熟度）**

- **一级果（出口级/品牌精选级）**：果指长度普遍在**18-22厘米**（甚至以上），果形直、饱满，无机械伤、无病斑、无药斑，果皮颜色均匀（青绿色），梳把整齐，成熟度一致（约7-8成熟采摘）。
- **二级果**：果指长度稍短（约15-18厘米），可能有轻微弯曲、轻度擦伤、果皮有少量斑点或颜色不均，成熟度略有差异，但果肉品质无实质影响。

**2. 价格差异**

- 批发市场通常**一级果比二级果贵15%-30%**，这是行业常见区间。
- 例如：若二级果批发价约2.5元/斤，一级果可能在2.9-3.25元/斤左右。
- **注意**：具体价差需以当天产地报价为准，建议直接联系佳农的区域经销商或采购平台获取当日报价单。

**3. 建议**

- 如果量大（如整车采购），可要求供应商提供分级检测报告（含果指长度、糖度等参数）。
- 佳农有部分渠道明确标注“特级果”和“精选果”等分档，可在合同或报价中明确对应标准，避免收货争议。

若需要具体价格，建议直接致电佳农客服或联系其华东、华南大区批发经理，价格会随行情波动，这里无法提供虚假数字。
