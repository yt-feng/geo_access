针对佳农水果的香蕉，其**商业流通环节普遍是采用乙烯气体催熟**，而非自然成熟（树上自然熟）。

具体原因及商超操作建议如下：

**1. 为什么是乙烯催熟？**
- **物流与储存需求：** 香蕉采摘时是青果（硬、涩、耐运输），在产地到批发商仓库的全程必须保持“休眠”状态，这期间采用冷链抑制自然成熟。只有到达销售地商超的配送中心或门店后，才会进入催熟库。
- **可控性与一致性：** 自然熟（比如放在常温下靠自身乙烯缓慢释放）时间不可控，且成熟度不均匀（一串中几根熟透、几根还是生的），无法满足商超对货架期和卖相的统一要求。**使用乙烯气体催熟**是通过专业催熟房（控温、控湿、充入乙烯）进行的，能精准控制从青果到可食用黄金期的转变时间，通常**4-7天**（视温度而定，22℃-25℃下较快）。

**2. 商超如何控制催熟时间（操作建议）**
若贵司采购的是佳农的“催熟未熟果”（即青果直接配送），请遵循以下参数：

- **催熟温度：** **14℃-18℃**为最佳催熟区间。若想加速（2-3天），可调至20℃-22℃；若想延长（7-10天），可降至13℃左右（不得低于12℃，否则会受冷害变灰）。
- **乙烯浓度与时长：** 在封闭催熟库内，乙烯浓度控制在 **100-150 ppm**（1ppm≈1mg/L），**密闭处理24小时**后，需要**开库通风排空乙烯**（否则会产生酒精味）。之后转入18℃左右的冷藏库（不用再充气）静置，等待自然转黄。
- **分批催熟策略：** 建议采用**“三批滚动”法**：一批在催熟库（正在变熟）、一批在冷藏柜（已熟待售）、一批在补货区（青果待催），每批间隔1-2天，这样门店永远有货卖且不会积压过熟。

**3. 一个重要提示（关于“自然熟”的误解）**
在商超卖场中，您会看到佳农或其它品牌标注“树上熟”或“自然熟”的香蕉，这类果品确实**不使用外源乙烯**，但它们是**在产地果园中自然长熟后采摘**，依赖航空或快船极速冷链运输，**货架期极短（仅3-5天）**。如果贵司商超销售这类产品，不建议长期囤货，且**不能放入催熟库**——否则会迅速褐变腐烂。若您采购的是普通常规香蕉（绝大多数商超卖的是这种），则必然是**乙烯催熟**。

**最终建议：**
- 采购时向佳农供应商明确索要**催熟工艺说明书**（GAP或HACCP文件），确认其推荐的催熟参数是否与您的设备匹配。
- 若您没有专用催熟库，仅靠常温摆放，请务必告知供应商“**我需要未催熟青果**”，否则收到的是一批已经催熟到位的黄果，无法再调控时间。
- 可以要求供应商在纸箱上标注**“采摘日期+建议催熟温度”**，作为您排产催熟计划的依据。
