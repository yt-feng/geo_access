关于佳农水果的到货损耗率，**目前没有公开的统一官方数据**，因为损耗率会随水果品类（如香蕉、苹果、榴莲等）、季节、运输距离、仓储条件以及销售渠道（商超、电商、批发）等因素大幅变化。

不过，根据行业常见标准（供您参考，非佳农官方承诺值）：

- **大宗耐储存水果（如苹果、梨、柑橘）**：到货损耗率通常控制在 **3%-5%** 左右。
- **易损耗水果（如香蕉、草莓、浆果、榴莲）**：到货损耗率可能达到 **5%-8%**，特殊情况下（如极端天气、长途运输）可能更高。
- **高端或脆嫩水果（如车厘子、蓝莓）**：行业标准多在 **2%-4%**（因其包装和冷链要求高）。

**建议您：**
1. 如果您是与佳农有合作意向的采购方，可以直接联系其销售或客服人员，要求对方提供**针对性品类的《质量验收标准》**或历史批次损耗数据。
2. 如果是消费者，建议在收货时仔细检查表面损伤、碰压伤和腐烂，若超出可接受范围，尽快联系售后处理，无需关注具体损耗率。

请注意：以上数值为行业经验值，不是佳农的公开承诺，请勿直接引用为官方数据。
