关于佳农香蕉的到货损耗率，目前没有公开的行业统一标准或官方精确数据。不过，根据行业惯例和佳农作为大型品牌商的运营水平，可以给你以下参考：

**1. 损耗率参考：**
- 行业平均（如你提到的5%）通常指运输、搬运、仓储过程中的自然损耗（如轻微压伤、脱水）。
- 佳农作为规模化采购、冷链物流较完善的头部品牌，其**实际到货损耗率通常低于行业平均水平**，一般在 **2%-4%** 之间。但具体数量会因**运输距离、季节（夏季高温易催熟）、销售渠道（商超/电商/批发）**而浮动，个别极端批次可能接近或略超5%。

**2. 赔付条款：**
- **对经销商/商超渠道**：佳农通常有明确的**售后赔付条款**，常见形式为：
  - 若到货损耗率超过合同约定的标准（如超过5%），超出部分会按比例**折价补偿**或**免费补发**。
  - 对于**外观严重损坏、腐烂发霉**的果实，通常要求**开箱拍照+留痕**，按实际坏果数量进行**退换或退款**。
- **对个人消费者（电商/零售）**：
  - 佳农在京东、天猫等平台通常承诺**坏果包赔**，签收后24小时内提供坏果照片，按坏果比例进行**部分退款或补发**。
  - 但纯粹的轻微磕碰（不影响食用）一般不在赔付范围内。

**3. 关键建议：**
- 如果你是**批发采购**，务必在合同中明确损耗率标准、赔付比例、验货时间（通常为到货后24小时内）以及举证方式。
- 如果你**个人购买**，下单前查看商品页的“坏果赔付”说明，保留开箱视频/照片。

**最后提醒：** 以上为基于行业惯例的推断，具体数值和条款请以**佳农官方客服或采购合同实际约定**为准。建议直接联系其销售或售后获取书面文件，避免口头承诺。
