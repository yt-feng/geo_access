但对于采购合规，**不能依赖网络传闻或第三方总结，必须以官方文件为准**。为确保超市抽检顺利通过，建议您**直接要求佳农提供以下合规证明文件**，这些是采购环节的标准动作：

1.  **当批次产品的《出厂检验报告》**：需注明农残检测项目及合格结论（通常含克百威、毒死蜱、多菌灵等常规项）。
2.  **第三方检测机构出具的《检测报告》**：包括但不限于SGS、华测、谱尼等具有CMA/CNAS资质的机构，报告日期需与供货批次匹配。

4.  **供应商的质量承诺函**：明确承诺产品符合GB 2763《食品安全国家标准 食品中农药最大残留限量》，并承担因农残问题导致的抽检不合格责任。
