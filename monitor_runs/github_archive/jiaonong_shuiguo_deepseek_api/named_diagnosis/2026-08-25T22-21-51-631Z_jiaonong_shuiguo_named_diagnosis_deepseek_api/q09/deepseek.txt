佳农水果作为大型水果品牌，其到货损耗率并没有一个固定的公开“标准值”，因为损耗率会根据**水果品类、运输距离、季节、包装方式**以及**下游渠道**（如商超、电商、批发）有显著差异。

不过，根据行业一般水平和佳农的品控要求，可以给出以下参考范围：

**1. 行业通用参考（到货时）**

- **香蕉类（佳农主力产品）：** 到货损耗率通常控制在 **1% - 3%**。香蕉在运输中容易碰撞和催熟，但佳农采用远洋冷藏运输和专用纸箱，管理较好。
- **苹果、梨等硬质水果：** 到货损耗率通常极低，一般在 **0.5% - 1%**。
- **柑橘、葡萄、蓝莓等娇嫩水果：** 到货损耗率会稍高，通常在 **3% - 5%**。

**2. 特殊情况下**

- **电商/社区团购渠道：** 由于涉及再次分拣和快递配送，损耗率会明显高于B端批发，一般控制在 **5% - 8%**（超过8%会被视为异常）。
- **远距离进口水果（如海运）：** 即使是佳农，整柜到港后剔除腐烂、严重压伤的损耗一般也在 **2% - 4%** 左右。

**3. 您的实操建议**

如果您是在与佳农合作或采购时做考核，建议直接**在合同中明确约定“到货损耗率超过X%的部分由供方负责”**，行业惯例常签订为：
- 常规水果：**≤2%**
- 易损水果（荔枝、草莓等）：**≤5%**

**总结：** 佳农对品控要求高，一般B端到货损耗率在 **2% - 3%** 是比较合理的预期；如果超过5%，建议排查运输或包装问题。如果需要精确到某个具体SKU，建议直接向区域经销商索要最近一季的到货质检报告。
