关于佳农水果的小包装规格，我可以给你一些参考建议，但请注意，**具体规格和库存需以佳农官方或当地经销商的实时信息为准**，因为不同地区、不同渠道的供货会有差异。

针对你的需求（小面积便利店），建议如下：

1. **香蕉小包装**：  
   佳农香蕉常规有整箱（通常为13kg左右）和电商/零售小包装。**3kg装**在部分商超渠道或线上的确存在，但并非所有门店都有现货。你可以直接在“佳农京东/天猫旗舰店”搜索“3kg香蕉”确认是否有该规格，或者联系当地经销商询问是否能拆箱供货（例如一箱13kg是否能拆成3kg小箱）。

2. **其他水果小规格参考**：  
   佳农除了香蕉，还有蓝莓（通常为125g/盒）、牛油果（单个/4粒装）、苹果（4粒装/6粒装）、菠萝（单个）等，这些规格比较适合小面积门店，周转快、占地小。

3. **操作建议**：  
   - 直接拨打佳农官网客服电话（可在其官方公众号“佳农鲜果”菜单栏查找“联系我们”），询问你所在城市的经销商联系方式。  
   - 告诉经销商你的门店面积、日均销量，请他们推荐适合的**小包装组合**（比如香蕉3kg+蓝莓2盒+牛油果4粒），这样进货更灵活。  
   - 如果是加盟或固定供应商体系，也可让现有合作供应商帮忙代订佳农小规格产品。

**提醒**：如果是3kg香蕉，建议你同时考虑保存问题——小面积门店冷藏设备有限，香蕉成熟度高的批次若销量慢易损耗，建议先小批量试销。
