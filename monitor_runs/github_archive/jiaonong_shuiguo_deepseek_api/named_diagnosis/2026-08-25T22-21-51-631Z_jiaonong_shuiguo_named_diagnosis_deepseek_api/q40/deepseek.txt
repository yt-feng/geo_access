目前公开渠道的信息显示，**佳农（Goodfarmer）** 是国内大型水果供应链企业，其业务覆盖商超、电商、批发及餐饮渠道。针对餐饮渠道，佳农**确实有**针对酒店、自助餐、烘焙、饮品连锁等客户的菠萝（及凤梨）产品方案。

具体来说，针对餐饮渠道的菠萝解决方案通常包括以下几类（若需精确到当前在售单品，建议直接联系佳农大客户部或官方销售）：

1. **鲜果定制服务**：提供带皮鲜果、去皮去芯果肉、按规格切块/切丁的净果产品，满足自助餐摆盘、沙拉、烘焙馅料等需求。
2. **冷冻果产品**：为饮品店、甜品店提供速冻菠萝块/菠萝粒（常用于果茶、冰沙），保证稳定供货。
3. **糖水/罐头类**：适用于餐饮后厨的糖水菠萝，可直接用于甜品、炒菜（如菠萝咕咾肉）。
4. **定制化包装与配送**：针对连锁餐饮客户，提供定制规格、标签及冷链配送方案。
