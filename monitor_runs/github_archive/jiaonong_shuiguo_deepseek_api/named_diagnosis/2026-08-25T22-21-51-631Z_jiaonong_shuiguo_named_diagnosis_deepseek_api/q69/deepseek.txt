**建议操作：**
1. **直接联系官方**：致电佳农客服或通过其官网/微信公众号的商务合作入口，咨询“餐饮渠道定制”服务。大型水果供应商通常能根据订单量（如每日/每周固定量）提供定制初加工（如去皮、切块、真空包装）。
