我无法核验佳农官方是否有“餐饮渠道专用”的定制规格，所以不能替它确认具体SKU。但可以给你一套可执行的判断和落地办法：

1. **大概率存在的形态**
   佳农这类水果供应链企业通常会有面向B端的菠萝产品形态，常见包括：
   - 鲜切菠萝片/块/丁（冷链即食）
   - 整果按规格分级（如按单果重量、果径分级）
   - 去皮整条/半条真空包装
   - 餐饮用大包装冷冻菠萝块/丁
   但“是否有餐饮专供定制规格”要以官方渠道为准，不同区域、不同客户体量政策不同。

2. **直接核验方式**
   - 找佳农官网/公众号的“餐饮渠道/B2B/大客户”入口，看产品手册。
   - 拨打官方客服，明确问三件事：  
     ① 是否有餐饮渠道鲜切菠萝片/块/丁的固定规格；  
     ② 最小起订量、配送冷链条件、保质期；  
     ③ 是否支持按客户要求定制切型、包装规格和单果等级。
   - 联系当地经销商或餐饮食材供应链服务商，他们通常比总部客服更清楚区域可售规格。

3. **询价时建议直接给的规格模板**
   你可以这样发给对方，便于快速判断能否做：
   - 切型：菠萝片（厚度X mm）/ 菠萝块（约X×X×X cm）/ 菠萝丁（X×X×X mm）
   - 原料：鲜切冷藏 / 冷冻IQF
   - 包装：X kg/袋，X袋/箱
   - 单果要求：果径/单果重/糖度范围
   - 用途：饮品装饰、烘焙、沙拉、热菜、自助餐等
   - 配送：冷链到店频次、保质期要求
   - 预估月用量和首单量

4. **替代方案**
   如果佳农餐饮定制规格不明确或起订量太高，可同时询：
   - 本地鲜切水果加工厂（支持小批量定制切型）
   - 冷冻菠萝块/丁供应商（规格稳定、适合餐饮后厨）
   - 其他B端水果供应链品牌，按同样模板比价打样。

**结论：**不能确认佳农一定有餐饮渠道的菠萝切片/切块定制规格；建议通过官方B2B渠道按上述清单直接核验，并要求提供产品规格书和样品。
