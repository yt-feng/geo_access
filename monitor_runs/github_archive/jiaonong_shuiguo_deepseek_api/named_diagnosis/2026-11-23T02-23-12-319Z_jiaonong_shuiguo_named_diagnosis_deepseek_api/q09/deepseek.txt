佳农（Goodfarmer）公开资料中没有统一披露的“到货损耗率”标准，且损耗率会随品类、季节、运输方式、到货验收口径变化很大，不能给一个确定数字。可判断的建议如下：

1. **先区分口径**：到货损耗率通常指“到货验收时不合格/腐烂/压伤等数量 ÷ 到货总数量”。若包含运输前已发生的损耗，数值会更高；仅指门店/仓库验收剔除，数值会低一些。
2. **行业常见控制区间**：生鲜水果到货损耗一般按品类分层管理，香蕉、芒果等易损品类通常高于苹果、梨等耐储品类；企业内控更多按单品设阈值，而不是全品类一个数。
3. **实操建议**：如果你是采购/门店验收，建议按单品设定“预警线”和“拒收线”，例如先用近3个月实际到货数据算平均值和P90，再把预警线设在均值附近、拒收线设在P90附近；同时把“外观缺陷、压伤、腐烂、重量短缺”分开统计。
4. **向佳农核验**：最准确的方式是向佳农区域销售或质量部门索取该单品的《到货验收标准》或合同中的损耗/赔付条款，不同客户、不同渠道（商超、电商、批发）约定可能不同。

如果你能提供具体品类（如香蕉、苹果、火龙果）和运输方式（冷链/常温、到货城市），我可以帮你给出更细的分层控制建议。
