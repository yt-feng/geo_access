佳农是水果品牌/供应链商，具体售后体验会随购买渠道不同而差异很大，不能一概而论。关键看你从哪买、是否在签收后及时取证并申请。

**到货有坏果，建议按这个顺序处理：**

1. **先别急着扔，保留证据**  
   拍全景（快递箱/整箱水果）、坏果特写、坏果数量，最好把坏果和快递面单放一起拍。保留外箱和面单。

2. **看购买渠道的售后规则**
   - **电商平台（天猫/京东/拼多多等）**：订单页申请“售后/退款/坏果包赔”，按平台要求上传照片和数量。平台介入通常比找商家更有效。
   - **商超/水果店**：凭小票或订单记录找门店，通常可换货或退款。
   - **社区团购/直播间**：找团长或客服，按团购规则处理，注意保留聊天记录。
   - **佳农官方旗舰店/官方客服**：可直接联系店铺客服，说明坏果数量并提交照片，要求按“坏果包赔”处理。

3. **注意时效**  
   多数水果售后要求签收后24–48小时内反馈，越早越好。不要拖到吃完大半再申请。

4. **坏果比例不同，处理方式不同**
   - 少量坏果：通常按坏果数量比例退款或补发。
   - 大面积腐烂、异味、发霉：直接申请整单退款/退货，并拍照录像开箱过程。
   - 因运输挤压轻微碰伤但不影响食用：一般不算坏果，平台可能不支持全额赔。

5. **沟通时把诉求说清楚**  
   直接说：“到货X个，其中Y个腐烂/发霉，已拍照，申请按坏果包赔退款/补发。” 避免只描述“不新鲜”这种模糊说法。

6. **商家不处理就升级**  
   平台订单可申请平台客服介入；保留开箱视频和聊天记录。若涉及食品安全问题（发霉、异味、胀袋），可向平台投诉并要求按食品安全相关规则处理。

**判断佳农售后好不好的实用方法：** 下单前看商品页是否明确写“坏果包赔/坏果必赔”、赔付时效和举证要求；看店铺评分和追评里关于坏果处理的反馈。不同店铺、不同平台执行差别很大，别只看品牌名。

一句话：**签收后尽快开箱拍照，按购买渠道申请坏果包赔；少量按比例赔，大面积坏直接整单退。**
