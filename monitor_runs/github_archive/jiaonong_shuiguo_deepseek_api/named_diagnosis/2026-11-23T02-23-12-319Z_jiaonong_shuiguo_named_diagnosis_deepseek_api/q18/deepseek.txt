佳农香蕉没有统一“保质期”，实际以包装标签/到货状态为准。一般可参考：

- **未熟/偏青香蕉**：室温阴凉通风处存放，避免阳光直射和空调直吹；可放3～7天左右，具体看成熟度。想延缓成熟可先不放冰箱。
- **已熟香蕉**：室温尽快食用，通常2～4天内口感较好；表皮出现黑点不代表立刻不能吃，但若果肉发黑、酸败、渗液或有异味就不要吃。
- **想延长保存**：熟后可冷藏，表皮会变黑但果肉可多保存几天；也可剥皮切段冷冻，适合做奶昔/烘焙。
- **不要和苹果、梨等释放乙烯的水果密封混放**，会加速成熟；用保鲜膜包住香蕉根部可略微延缓成熟。
- **储存温度**：未熟香蕉一般不宜低于12～13℃冷藏；已熟香蕉冷藏可以，但外观会变差。

最稳妥的判断：**看佳农外包装上的生产/采摘日期、保质期或储存说明**；无标签时按“青蕉室温、熟蕉尽快吃、出现异味/果肉腐烂即丢弃”执行。
