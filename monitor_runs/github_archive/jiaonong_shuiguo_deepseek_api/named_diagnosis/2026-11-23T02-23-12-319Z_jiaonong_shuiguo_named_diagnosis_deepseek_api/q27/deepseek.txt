佳农水果（佳农食品控股/佳农集团）对下游客户的账期没有公开统一标准，通常要按客户类型、采购规模、合作渠道和授信审批结果来定，不能一概而论。可参考：

1. **常规账期范围**
   - 商超、连锁零售、电商平台等企业客户：常见为 **30～60天**，部分大客户或长期合作客户可能谈到 **60～90天**。
   - 批发市场、中小经销商：多为 **现款现货、预付款或7～30天短账期**。
   - 餐饮、加工厂等B端客户：通常按合同约定，常见 **30天左右**，新客户往往更短或要求预付。

2. **新客户能否申请**
   - 一般可以申请，但新客户首次合作通常**很难直接拿到长账期**。
   - 常见做法是：首单现款或预付，合作稳定后申请授信；提交营业执照、经营流水、征信/财务资料、采购合同等，由佳农做信用评估后给额度。
   - 新客户较可能获得的是 **7～30天短账期** 或“部分预付+尾款账期”，大额长账期一般需要较长合作记录或强担保。

3. **建议直接确认**
   - 联系佳农当地销售/大客户经理，说明采购品类、月采购量、结算方式，询问授信政策。
   - 合同里明确账期起算日、对账日、逾期条款和授信额度。

以上为行业常见情况，不代表佳农官方固定政策；具体账期以其授信审批和合同为准。
