佳农水果的香蕉执行的是**企业标准（企标）**，不是国家标准（国标）。  
企业标准由企业自行制定并备案，通常会在包装或产品标签上标注“Q/”开头的标准号；国标则是“GB”或“GB/T”开头。佳农作为品牌商，其香蕉分选、规格、成熟度、外观等通常按自身企标或采购合同执行，具体标准号需看包装标注。

至于“比普通香蕉贵多少”，**没有统一固定差价**，会随城市、渠道、规格、促销和季节变化。一般可这样判断：  
- 佳农香蕉常按把/袋/整箱卖，普通香蕉常按斤卖，直接比价要先换算成**每斤单价**；  
- 同渠道同规格下，佳农通常贵**10%—30%**左右较常见，但并非固定；  
- 促销时可能接近普通香蕉价，精品超市差价可能更大。  

建议直接看货架价签：用“佳农单价 ÷ 净重”和“普通香蕉每斤价”对比，最准确。
