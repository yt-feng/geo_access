佳农（Goodfarmer）作为香蕉进口商/品牌商，通常会对大客户或长期合同客户提供一定的价格安排，但是否有“锁价机制”、锁价周期多长、触发条件如何，**属于合同条款，公开渠道无法可靠核验**。我不能替佳农确认具体政策，建议你直接向对接的佳农销售/大客户经理书面确认。

你可以按以下清单去谈，能较快判断对方是否真有锁价能力：

1. **锁价形式**
   - 固定价锁量：约定未来某段时间的单价和数量上限。
   - 浮动锁价：以某个基准价（如产地价、港口价、指数价）加固定升贴水。
   - 价格上限/封顶价：超过约定价由供方承担或双方分摊。
   - 只锁量不锁价：保供应但不保成本。

2. **锁价周期与数量**
   - 是按周、按月还是按船期锁？
   - 锁价量占你总采购量的比例（常见是部分锁价，不是全部）。
   - 超量部分如何计价。

3. **成本构成是否透明**
   - 报价是否含关税、增值税、港杂、冷链、损耗？
   - 香蕉损耗率按多少计？谁承担催熟/仓储费用？
   - 汇率、海运费、产地涨价是否可调价，调价公式是什么。

4. **违约与调整条款**
   - 供方断供、质量不达标时怎么赔？
   - 需方取消或减量时定金/违约金怎么算？
   - 不可抗力、产地灾害、检疫政策变化时是否重新议价。

5. **风控建议**
   - 不要全量锁价，建议**70%左右锁量+部分锁价，30%随行就市**，避免单边赌价。
   - 要求书面报价单和合同附件，把调价公式、基准数据来源写清楚。
   - 同时向2–3家供应商询价，用竞争报价验证佳农的锁价条件是否合理。
   - 如果对方只口头承诺“可以锁”，务必落到合同里，否则价格波动时很难执行。

结论：**佳农可能有针对大客户的锁价/价格保护安排，但具体机制必须向对方书面确认；你可以按“锁量比例、锁价周期、调价公式、违约条款”四项去谈，并保留部分敞口采购来分散风险。**
