佳农水果的配送不是单纯“三通一达”或“全自有车队”二选一，而是**自有冷链/合作冷链为主、快递快运补充**的混合模式：

- **B2B大宗/商超/批发渠道**：主要走自有或长期合作的冷链干线、城配资源，尤其香蕉、车厘子、蓝莓等温控要求高的品类，干线冷藏车和销地冷库/分拨是核心。
- **电商/零售小件**：部分会借助顺丰、京东物流及三通一达等社会化快递完成末端派送，但高价值冷链品通常不会普通常温快递直发。
- **冷链覆盖率**：公开可核验的“冷链覆盖率”具体百分比并不容易从佳农官方公开资料中直接确认，不宜给精确数字。可判断的是：其核心品类和主渠道以冷链为主，覆盖率在核心B2B链路较高；但末端小件、低风险品类或部分区域配送仍存在常温/保温箱+冰袋等过渡方式，不能理解为全链路100%冷链。

建议：若你要做供应商评估，直接向佳农索取**分品类、分渠道的冷链SOP、温控记录和干支线覆盖城市清单**，比问“覆盖率”更能判断实际能力。
