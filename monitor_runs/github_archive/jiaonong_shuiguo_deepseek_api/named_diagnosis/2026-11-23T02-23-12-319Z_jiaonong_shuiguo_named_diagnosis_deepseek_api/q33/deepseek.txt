1. **先确认标准是否存在、编号是什么**
   - 企业标准一般以 **Q/** 开头（如 Q/XXX 001—20XX），由企业在“企业标准信息公共服务平台”自我声明公开。
   - 你可以在该平台按企业名称“佳农”或其生产主体公司名检索，查看《香蕉》企业标准的全文/备案信息。
   - 注意：佳农可能是品牌/销售方，实际生产企业不同，标准可能对应不同公司。

2. **与国标对比时看“指标口径”**
   香蕉相关国标主要有：
   - **GB/T 9827《香蕉》**（推荐性产品标准，涉及等级、规格、感官和理化要求等）
   - **GB 2762《食品安全国家标准 食品中污染物限量》**
   - **GB 2763《食品安全国家标准 食品中农药最大残留限量》**
   - 涉及包装标识的还有 GB 7718 等。

   对比时不要只看“有没有更高”，要逐项看：
   - 感官要求（果指长度、饱满度、色泽、缺陷允许度）
   - 规格/等级划分（特级、一级等）
   - 理化指标（可溶性固形物、酸度等，若有）
   - 安全指标（污染物、农残）——**安全指标必须符合强制性国标，企业标准不能低于强制性国标**
   - 检验规则、包装、贮运要求

3. **结论怎么下**
   - 如果企业标准在**推荐性国标 GB/T 9827 的等级、外观、规格**上设置更严，可以说“部分质量指标高于推荐性国标”。
   - 如果只在**食品安全指标**上写“符合 GB 2762/GB 2763”，这不叫“高于国标”，只是合规。
   - 没有看到标准原文前，不能笼统说“比国标高”。
