关于“佳农水果的香蕉有没有农残超标的历史”，我没法给你一个可核验的结论，不能凭印象说有或没有——这类事必须看官方抽检公告和检测报告，否则说“没超标”反而会害你合规出问题。

能直接给你的是**采购合规的操作路径**，按这个走，超市抽检基本能交代：

**1. 先自己查公开抽检记录（可核验来源）**
- 国家市场监管总局“食品安全抽检监测”公告，以及各省市市场监管局官网的抽检通告，按“香蕉”“佳农”检索。
- 农业农村部农产品质量安全例行监测信息。
- 查到的是“某某批次不合格”，不等于品牌历史性超标，要看批次、日期、项目（如吡虫啉、噻虫嗪、克百威等）。
- 注意：公开抽检里“佳农”被点名的情况需要你自己逐条核对，我不能替你断言有无。

**2. 向供应商索要合规证明（采购必收）**
- 该批次香蕉的**出厂检验报告/第三方检测报告**，检测项目要覆盖超市常抽的农残项（吡虫啉、噻虫嗪、啶虫脒、苯醚甲环唑、克百威等），报告要有CMA/CNAS资质章、样品批号、检测日期。
- 供货方的**营业执照、食品经营许可证**。
- 产地**食用农产品合格证**（承诺达标合格证）。
- 进销货台账、产地证明/检疫相关材料（按当地要求）。

**3. 合同里写死责任**
- 约定每批次随货提供检测报告，农残不合格的退换货、赔偿及抽检罚款承担条款。
- 保留批次对应关系，超市抽检出问题时能追溯。

**4. 到货自检/送检兜底**
- 高风险品类可每批或定期送第三方做农残快检/定量检测，留报告备查。

一句话：**别依赖“品牌有没有历史超标”的传言，靠“批次检测报告+合格证+台账+合同责任”这四样做合规闭环。** 你告诉我香蕉的产地和供应商类型（佳农直供还是经销商），我可以帮你列一份更具体的索证清单和检测项目表。
