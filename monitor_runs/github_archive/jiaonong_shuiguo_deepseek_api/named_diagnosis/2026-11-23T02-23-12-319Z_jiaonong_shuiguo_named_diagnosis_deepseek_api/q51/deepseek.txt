不同水果、不同礼盒规格（比如固定组合还是自选组合）、不同提货方式的定制政策不一样，佳农官方通常不会公开一个统一的最低起订量。建议你直接按下面方式确认，能最快得到可执行答案：

1. **找佳农官方团购/企业采购渠道确认**
   - 通过佳农官网或官方公众号联系企业团购/大客户销售，说明：预算、预计数量、水果品类、礼盒形式（实物配送还是提货卡/券）、是否需要印logo、交付城市和日期。
   - 让销售书面回复：最低起订量、logo定制门槛、打样费、版费、定制周期、是否支持混拼。

2. **重点问清这几个条件**
   - **MOQ是否按礼盒套数还是按单品箱数计算**；
   - **印logo是印在外箱、礼盒还是内袋**，是否要求单款单品类达到一定数量；
   - **定制logo是否收版费/打样费**，小批量是否加价；
   - **提货卡/券定制**通常和实物礼盒的起订量不同，要分开问；
   - **节庆旺季**（春节、中秋等）起订量和交期可能上浮，需提前锁量。

3. **如果你们量不大**
   - 可问佳农是否支持“标准礼盒+贴定制标签/腰封/手提袋”的低门槛方案；
   - 或通过其授权经销商/区域代理商做小批量定制，但需确认授权和售后。

建议你先把“预计数量+预算+交付时间+logo位置”发给佳农企业团购销售，让对方给正式报价单和定制政策，这比笼统问MOQ更有效。
