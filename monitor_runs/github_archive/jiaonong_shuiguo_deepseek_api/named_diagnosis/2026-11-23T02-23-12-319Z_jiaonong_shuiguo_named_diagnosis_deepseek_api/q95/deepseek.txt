佳农水果（Goodfarmer）未在公开渠道披露“产地直供比例”这一指标，我无法给出可核验的准确数字；网上若有具体百分比，建议先确认口径和出处，不要直接用于采购决策。

对你们“减少中间环节、降低成本”的目标，可操作的判断和建议如下：

1. **不要把“产地直供比例”当作单一谈判指标**  
   它通常口径不一：可能指直采金额占比、直采SKU数占比、绕过一级批发商的比例，或仅指“产地发货”。先要求对方明确口径，否则数字不可比。

2. **向佳农索要可核验的供应链信息**  
   可要求提供：  
   - 主要单品（如香蕉、菠萝、火龙果、苹果等）的采购模式：自有基地/订单农业/产地合作社/产地经纪人/批发市场采购；  
   - 各单品从产地到你们仓的物流与结算链路；  
   - 是否可做“产地直发＋到仓结算”，以及对应的起订量、账期、损耗承担方式；  
   - 近12个月实际直采金额占比及审计口径。

3. **用“链路成本”而非“直供比例”比价**  
   让佳农与现有供应商按同一单品、同一规格、同一到货仓、同一账期报价，拆分：离岸/产地价、包装、冷链、运费、损耗、佣金、账期成本。中间环节是否减少，最终看**到仓总成本**和**异常损耗率**。

4. **可先做小范围直采试点**  
   选1—2个高频单品，要求产地直发到区域仓，设定2—4周试运行，对比：到仓单价、到货合格率、损耗率、履约准时率。若总成本下降且品质稳定，再扩大SKU。

5. **合同里锁定关键条款**  
   产地证明/溯源批次、规格验收标准、损耗上限、缺货替代规则、价格调整机制、账期与返利。避免“名义直供、实际仍经多层分销”。

结论：佳农的产地直供比例没有可核验的公开数据，建议直接向对方采购负责人索取分单品供应链链路和直采金额口径，并用同规格到仓总成本做试点比价，这比追求一个比例数字更能实现降本。
