佳农（Goodfarmer）香蕉的具体规格和渠道分级标准属于企业销售政策，通常会随年份、产地（如菲律宾、厄瓜多尔、越南等）和客户合同调整，公开渠道没有统一、可核验的完整清单。因此我不能给出“佳农官方有几种规格”的确定数字，但可以给你一套**可执行、可判断**的采购/选品框架，并说明如何拿到准确信息。

### 一、佳农香蕉常见的规格维度（按行业通用口径）

实际报价和合同里通常不是“一个数字”，而是几个维度组合：

1. **按重量/箱规**  
   - 常见有 12kg、13kg、18kg、20kg 等整箱规格，不同渠道和产地会有差异。
   - 单根重量通常按“条重”分级，如 120–150g、150–180g、180g 以上等。

2. **按梳/把规格**  
   - 整梳、半梳、单根散装；商超更偏好整梳或定量把装。
   - 电商/社区团购常见 1kg、2kg、5kg 等定量装。

3. **按成熟度/催熟阶段**  
   - 青蕉（适合仓储催熟）、微黄、黄熟（即食）；不同渠道对到货成熟度要求不同。

4. **按外观等级**  
   - 条形直度、长度、粗细、果指均匀度、表皮瑕疵、机械伤、病斑、青软比例等。
   - 行业内常分 A/B/C 或 一级/二级/三级，但**具体阈值以佳农合同或验收单为准**。

### 二、不同渠道的分级侧重点（通用可判断标准）

| 渠道 | 规格偏好 | 分级重点 | 可执行建议 |
|---|---|---|---|
| 大型商超/精品超市 | 整梳、条形均匀、单根 150–200g 左右 | 外观一致性、无机械伤、无病斑、到货成熟度可控 | 要求供应商提供“条重区间+梳重+瑕疵率上限”，按批次抽检 |
| 水果连锁/批发市场 | 整箱、大条重、耐储运 | 青蕉硬度、条形、箱规稳定、损耗率 | 重点看青软比例、机械伤和箱内温差；先小批量试销 |
| 电商/社区团购 | 定量小包装、即食或短催熟 | 单根大小一致、坏果率低、耐快递 | 明确“单果克重区间+坏果赔付比例”，优先微黄/黄熟 |
| 餐饮/茶饮 | 单根稳定、出肉率、风味 | 成熟度一致、无黑心、供应连续性 | 按“单根克重+到货成熟度+周供应量”签框架协议 |
| 出口/加工 | 按客户合同，青蕉为主 | 农残、果指长度、梳形、冷链 | 以合同验收标准为准，要求第三方检测报告 |

### 三、如何拿到佳农的准确规格

最可靠的方式是直接向佳农官方渠道索取**产品规格书/报价单/验收标准**，并确认以下字段：

- 产地与季节；
- 箱规（净重/毛重）；
- 单根克重区间；
- 每箱梳数/把数；
- 到货成熟度；
- 外观等级定义（瑕疵率、机械伤允许范围）；
- 冷链与损耗赔付条款。

如果你告诉我具体渠道（商超、电商、批发、茶饮）和目标市场，我可以帮你把验收标准写成一份可用的采购抽检表。
