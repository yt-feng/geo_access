佳农水果的配送时效取决于你下单的渠道和收货地址，不能一概而论：

1. **电商平台（京东/天猫等佳农官方旗舰店）**：一般走平台仓配。京东自营仓附近城市常见“次日达”，偏远地区2–4天；天猫旗舰店多为48小时内发货、3–5天送达（生鲜视线路而定）。
2. **佳农自有/小程序渠道**：通常按下单区域就近仓发货，城市核心区1–2天，周边及偏远地区2–4天。
3. **商超/社区团购渠道**：多为次日自提或按团购约定时间配送。

**判断建议**：下单前在商品详情页看“发货地/预计送达时间”，结算页会显示具体时效；香蕉、牛油果等对温度敏感，优先选有冷链标识且预计时效≤3天的渠道。若超过承诺时效未发货，可直接联系店铺客服催发或申请售后。

具体时效以你实际下单页面的显示为准，我无法核验各渠道的实时配送数据。
