佳农（Goodfarmer）公开渠道通常不会发布完整的香蕉分级细则和实时价差，我能确认的只有一般行业做法；具体到佳农某一批次，建议直接向佳农销售或你所在地的一级代理索取当批《分级验收标准》和报价单。不要依赖网上二手转述。

**可判断的通用情况：**

1. **香蕉分级通常看这些维度**
   - 果指长度、粗度（周径/横径）
   - 每梳/每把果指数量、整齐度
   - 条形弯曲度、饱满度
   - 表皮清洁度、机械伤、擦伤、日灼
   - 病害：条斑病、炭疽病潜伏感染、冠腐病
   - 青果成熟度（几成熟采收）、色泽均匀度
   - 梳形完整、无落梳、无断指
   - 冷链与到货新鲜度

2. **一级果和二级果的典型差异**
   - 一级果：果指长度和粗度达标且均匀，条形好，无可见机械伤和病斑，梳形整齐，成熟度一致。
   - 二级果：长度/粗度略低或均匀度差，允许轻微表皮瑕疵或少量机械伤，但不影响食用和货架期；病害感染、腐烂、严重擦伤通常不是二级，而是等外或拒收。

3. **价差不能给固定数**
   香蕉价差随产区、季节、规格（如进口菲律宾/厄瓜多尔 vs 国产）、包装、到货城市、是否催熟、订单量波动很大。一级与二级的批发价差常见是按“每箱/每件”谈，而不是简单固定百分比；有时二级果因外观差、货架期短，价差会明显拉大。没有当批报价时，给具体金额或百分比都不可靠。

**建议你直接问供应商这5项：**
- 当批执行的佳农分级标准文件（果指长度/粗度下限、允许瑕疵比例）
- 一级、二级分别是哪个规格段和包装规格
- 到货价是产地价、到岸价还是目的地批发价
- 二级果的允许缺陷清单和拒收条件
- 近3批一级/二级实际成交价，而不是挂牌价
