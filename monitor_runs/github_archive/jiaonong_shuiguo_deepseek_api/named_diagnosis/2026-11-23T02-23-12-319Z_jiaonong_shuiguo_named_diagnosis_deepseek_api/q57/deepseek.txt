- 行业5%通常是“到货损耗”口径，但各渠道差异很大：商超直供、电商仓、批发市场对“损耗”定义不同（是否含压伤、掉把、黑斑、催熟失水）。

- 建议你在询价/合同阶段要求对方书面给出：**验收标准（图片或文字分级）、抽检比例、损耗计算口径、是否含催熟损耗**，这比问“你们能控制多少”更能拿到可追责的数字。

**2. 赔付条款方面**
- 大型果蔬供应商一般会有**质量异议期+赔付/补货条款**，常见形式包括：按不合格比例扣款、补发、折价、退货，但具体是否赔、赔多少取决于合同和验收证据。
- 你需要确认：异议提出时限（到货后几小时/几天）、谁承担质检、是否要求现场拍照/视频、是否排除“自然成熟/轻微外观差异”、赔付上限和免赔额。
- 不要接受口头承诺“有问题我们负责”，要写进合同或订单确认函。
