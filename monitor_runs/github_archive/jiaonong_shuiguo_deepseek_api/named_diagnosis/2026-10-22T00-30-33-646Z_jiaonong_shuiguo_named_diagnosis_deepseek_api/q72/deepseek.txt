佳农（佳农食品控股）主业是香蕉、菠萝等水果的贸易与分销，常规出货以整果或标准鲜切/冷冻果为主，但**是否能为茶饮店做“去皮切块”的定制加工，需要直接向其确认**。我无法核验其当前是否提供这类服务，不能给你确定答复。

你可以这样判断和推进：

1. **先问对口渠道**：联系佳农官方客服或当地经销商，明确问三件事：
   - 是否有“鲜切菠萝块/菠萝丁”标准品（而非整果）；
   - 能否按你要求的规格（块大小、去芯与否、糖度范围）做定制加工；
   - 起订量、加工费、冷链配送和保质期。

2. **判断可行性**：茶饮店用量若不大，佳农这类贸易商通常更愿意卖标准整果或标准鲜切品，**小批量定制切块的概率较低**；若你门店多、用量稳定，才有谈定制加工的空间。

3. **备选方案**：如果佳农不提供，可考虑：
   - 采购佳农整果，由门店或中央厨房自行切配；
   - 找本地鲜切水果加工厂代加工（需确认其原料来源和食品安全资质）；
   - 使用合规的冷冻菠萝块/菠萝丁供应商。

4. **注意合规**：鲜切水果属即食加工，代加工方需有相应食品生产/经营资质，并明确冷链和保质期责任。

建议你直接向佳农当地销售确认“鲜切菠萝块”是否有现货标准品，这是最快能判断的路径。
