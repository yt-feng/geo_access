我没法核验佳农官方是否公开列出“餐饮渠道定制规格（切片/切块）”的明确目录，所以不能直接给出肯定或否定的官方结论。可执行判断如下：

1. **大概率有餐饮渠道产品，但“定制切片/切块”需按项目确认**  
   佳农在B端通常有餐饮/茶饮渠道供应能力，菠萝也常以鲜果、鲜切或冷冻等形式进入B端。但“切片/切块”的规格、厚度、大小、包装、冷链形态是否属于可定制项，需要向当地销售或大客户渠道确认。

2. **可直接向佳农确认的询价要素**  
   联系佳农官方客服或区域餐饮渠道销售时，建议一次性问清：
   - 产品形态：鲜切、冷冻切块/切片、糖水/罐头，还是仅整果；
   - 规格：切片厚度、切块尺寸（如2cm×2cm）、每袋/每箱净重；
   - 包装：真空袋、气调包装、冷冻袋装、餐饮大包装；
   - 起订量：是否支持定制规格、最小起订量、打样周期；
   - 供应方式：冷链鲜配还是冷冻配送，保质期和储存条件；
   - 价格与账期：定制规格是否加价、是否含运费。

3. **如果对方不提供定制切块，可替代路径**  
   - 采购佳农整果或标准鲜切，由中央厨房/门店二次切配；
   - 找佳农经销商询问是否已有餐饮标准切块SKU；
   - 对比其他餐饮供应链品牌的标准鲜切/冷冻菠萝规格。

建议你直接以“餐饮门店/中央厨房用途”向佳农区域销售询价，并要求提供**产品规格书和样品**，这样比看公开资料更可靠。
