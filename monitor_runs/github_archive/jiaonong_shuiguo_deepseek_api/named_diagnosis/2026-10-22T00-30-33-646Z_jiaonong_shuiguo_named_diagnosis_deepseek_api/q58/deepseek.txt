我无法核验佳农当前对茶饮门店的菠萝丁加工/定制服务政策，所以不能直接断言“能”或“只卖整果”。建议你用下面方式快速确认，避免被非官方信息误导：

**1. 先确认你要的是哪种“菠萝丁”**
- **冷冻菠萝丁**：茶饮店最常用，开袋即用、出杯稳定。
- **糖水/罐头菠萝丁**：偏甜品、果茶，需看糖度和固形物。
- **鲜切菠萝丁**：保质期短，配送半径要求高。
- **整果+门店自切**：成本低但人工和损耗高。

**2. 直接问佳农的3个关键问题**
联系佳农官方客服/当地经销商时，按这几句问：
1. “你们有没有**冷冻菠萝丁/鲜切菠萝丁**的SKU？规格、糖度、固形物、包装分别是多少？”
2. “是否支持**茶饮门店小批量订货**？起订量、配送城市、冷链条件是什么？”
3. “如果只有整果，是否提供**代加工/定制切丁**？加工费、最小批量、交货周期怎么算？”

**3. 判断话术**
- 对方说“有现成菠萝丁SKU”：要产品规格书和检测报告，先小批量试杯。
- 对方说“只卖整果”：问当地经销商是否有合作加工厂；没有就考虑整果自切或换供应商。
- 对方说“可定制加工”：必须确认**最小起订量、加工费、冷链、保质期、是否可混规格**，否则小门店容易踩坑。

**4. 备选方案**
如果佳农不直接服务小茶饮店，可同步找：本地冷冻水果经销商、餐饮供应链平台、区域水果加工厂。茶饮店用菠萝丁优先选**冷冻丁**，比鲜切更稳。
