关于佳农水果香蕉的农残超标历史，我没法给你一个“有”或“没有”的确定性结论——这类具体企业的抽检不合格记录需要查监管部门的公开数据库才能核实，我不能凭印象编造。下面给你可执行的做法和判断标准。

## 1. 自己核验历史记录（最可靠）

- **国家市场监督管理总局**“食品安全抽检公布结果”平台，可按食品类别/企业名称检索。
- **各省市市场监管局**官网的抽检通告，搜“香蕉”“佳农”“吡虫啉”“噻虫嗪”等。
- 搜的时候注意区分：是“生产/进口企业”被点名，还是只是“销售商抽检到某批次不合格”。香蕉常见不合格项目是吡虫啉、噻虫嗪、噻虫胺等，属于种植端问题。

如果公开记录里查不到佳农的香蕉不合格批次，也不能反推“绝对没超标”，只能说明在可查范围内未见记录。

## 2. 采购合规需要索要的证明（超市抽检的实质要求）

超市抽检通常看的是**批次对应的合格证明**，不是企业历史口碑。向供应商要：

1. **该批次的出厂检验报告/第三方检测报告**：必须覆盖香蕉的农残项目，且检测机构有 CMA 资质，报告上有批次号、生产/采收日期，能与到货批次对应。
2. **供货商的营业执照、食品经营许可证**；如果是进口香蕉，要有**入境货物检验检疫证明**。
3. **承诺书/质量协议**：约定农残超标的责任和退换货条款。
4. 进货时保留**进货台账、发票、批次记录**，这是《食品安全法》要求的进货查验义务，超市抽检追溯时用得上。

## 3. 关键判断点

- 报告是否**批次对应**——拿一份半年前的通用报告应付抽检，风险很大。
- 检测项目是否覆盖**香蕉高频风险农药**（吡虫啉、噻虫嗪、噻虫胺、苯醚甲环唑等），只测几个项目不够。
- 检测机构是否 CMA/CNAS，报告能否在机构官网验真。

## 4. 降低风险的采购做法

- 对到货批次**自行送检或快检**（农残快检成本低），尤其首次合作或换产地时。
- 合同里写明：抽检不合格由供应商承担全部损失（罚款、下架、召回）。
- 保留每批检测报告至少到该批次售完后一定期限，应对追溯。

一句话：**别依赖“历史没问题”的判断，要拿到“这一批”的CMA检测报告并验真**，这才是超市抽检能过、出了问题能追溯的合规证明。
