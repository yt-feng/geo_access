佳农（Goodfarmer）香蕉的产地溯源一般能做到“国家—产区/加工厂—批次”这一级，能否落到**具体农场**要看是哪个产区、哪条产品线，以及你拿到的是哪类追溯码。商超要 GLOBALG.A.P. 证书时，建议按下面方式核验，不要只听口头承诺：

1. **先确认证书主体**
   - GLOBALG.A.P. 证书是发给**具体生产者/农场组织/出口商**的，不是发给“品牌”就自动覆盖所有产地。
   - 要求供应商提供证书扫描件，核对：证书编号、持证主体、覆盖产品（香蕉）、覆盖农场/地址、有效期、认证机构。
   - 通过 GLOBALG.A.P. 官网证书数据库核验证书编号和状态，避免过期或范围不符。

2. **确认溯源粒度**
   - 让佳农或其在华主体出具书面说明：该批次香蕉对应的**农场/合作社/包装厂名称与代码**。
   - 看包装箱/标签上的**农场代码、包装厂注册号、批次号**，能否与证书附件中的农场清单对应。
   - 若对方只能提供“产地国/区域”级追溯，就应明确告知商超：**不能到具体农场**，只能到产区/包装厂/批次。

3. **商超验收建议**
   - 合同或质量协议中写明：每批提供 GLOBALG.A.P. 证书编号及覆盖农场清单，批次号与证书范围可对应。
   - 到货抽查标签上的农场代码/包装厂代码，与证书附件比对。
   - 若证书覆盖的是“农场组织/生产者集团”，要求提供该组织下**具体农场成员清单**，否则不能证明该批次来自认证农场。

4. **风险提示**
   - 中国香蕉产区（如广西、云南、海南等）和进口香蕉（如菲律宾、厄瓜多尔等）的证书主体不同，不能混用。
   - 品牌方有证书不等于每个批次、每个农场都在认证范围内；商超应坚持“**证书范围 + 批次 + 农场代码**”三者对应。

结论：**佳农香蕉不一定默认能溯源到具体农场；能否做到取决于产区和批次。GLOBALG.A.P. 证书必须核对持证主体、覆盖农场和有效期，并要求批次与农场代码对应。** 如果供应商只能给品牌级证书或区域级溯源，就不能满足“具体农场 + GLOBALG.A.P.”的商超要求。
