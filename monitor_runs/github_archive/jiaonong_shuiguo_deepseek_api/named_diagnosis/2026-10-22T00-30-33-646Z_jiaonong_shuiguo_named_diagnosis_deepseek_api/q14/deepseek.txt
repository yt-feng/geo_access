可以，但先分清“专供包装”能做到什么程度。

**通常可谈的专供包装**包括：
- 印你们超市Logo/门店名的箱装或袋装
- 指定规格：单根重量、每把根数、每箱净重
- 指定包装形式：纸箱、塑料袋、托盘+收缩膜、礼盒装等
- 指定标签：产地、等级、追溯码、门店专供标识
- 长期订单下的稳定箱规和到货标准

**一般不容易做到“只给你一家供货”的完全专供**，除非采购量很大且签长期框架协议。更现实的是“专供包装+稳定规格”，而不是“佳农只供你们”。

**建议你这样和佳农谈：**
1. 先报年度/月度预估采购量、门店数、配送频次、验收标准。
2. 明确要求：专供包装的最低起订量、包装打样费、版费、改版周期。
3. 问清是否收专版费、是否要求包材由他们统一采购、断供时包材如何处理。
4. 合同里写清：包装规格、到货净重、成熟度、瑕疵率、冷链要求、涨跌价机制。
5. 先小批量试单，验包装强度、保鲜效果和门店陈列适配。

**判断标准：**如果你们月采购量稳定、能接受最低起订量，佳农这类品牌商通常可以谈定制包装；如果量小，建议先做“贴标/套袋”而不是开专版箱。直接问对方业务：**“定制专供包装的最低起订量、版费、打样周期和年度采购量要求是多少？”** 这一句就能判断可行性。
