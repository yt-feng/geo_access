佳农香蕉的“保质期”通常按状态区分，没有统一固定天数，关键看包装标注和成熟度：

**储存条件**
- **未熟/偏青香蕉**：常温阴凉通风处存放，避免阳光直射和空调直吹；不要放冰箱，低温会导致表皮变黑、成熟不均。
- **已熟香蕉**：尽快食用；若想延缓过熟，可冷藏果肉或去皮冷冻，但表皮冷藏后会变黑，不影响果肉。
- **不要和苹果、梨等释放乙烯的水果混放**，会加速成熟。
- **避免挤压、潮湿**，悬挂或平放均可，减少机械伤。

**保质期参考**
- 常温下：青香蕉通常数天到一周左右逐渐转黄成熟；已熟香蕉一般再放1—3天口感较好，之后易过熟。
- 具体以包装上的**生产日期/保质期/储存说明**为准，不同批次、季节和运输成熟度差异较大。

**判断是否变质**：果肉明显发黑流汁、有酸腐味、霉斑或果柄发霉时不要食用。表皮少量黑点通常是成熟表现，不等于坏了。
