1. **企业标准通常不公开全文**  
企业标准（Q/开头）需在企业标准信息公共服务平台备案/自我声明公开，但不少食品企业只公开标准名称和编号，不公开完整技术指标；佳农香蕉的具体企标号我无法核验到，不能编造。

2. **“比国标高吗”不能一概而论**  
香蕉相关国标/行业标准主要包括：  
- GB/T 9827《香蕉》（产品分级、质量要求）  
- NY/T 517《无公害食品 香蕉》等农业行业标准  
- 食品安全国家标准（GB 2762污染物、GB 2763农残等，属强制底线）  

企业标准一般有两种情况：  
- **安全指标**：必须不低于强制性国标，不能“更低”；  
- **质量/分级指标**（果指长度、粗细、色泽、成熟度、缺陷率等）：企标可以比推荐性国标更严，也可能只是企业内部收货分级，未必全面“高于国标”。所以只能说“可能更严”，不能直接说“比国标高”。

3. **可执行的核验办法**  
- 看包装箱/标签上的“执行标准”编号，Q/开头即企标；  
- 到“企业标准信息公共服务平台”输入佳农公司名或标准号查自我声明；  
- 对比该企标文本中的感官、理化、安全指标与GB/T 9827及GB 2762/2763；  
- 若只看到“符合国家标准”而无企标号，说明其执行的是国标/行标，不存在可比较的企标。
