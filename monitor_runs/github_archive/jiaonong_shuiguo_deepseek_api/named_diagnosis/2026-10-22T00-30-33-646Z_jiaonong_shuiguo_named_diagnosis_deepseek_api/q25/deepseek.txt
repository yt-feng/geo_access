佳农水果的物流网络以**自营为主、外包为辅**的混合模式运作，冷链能力在国内水果进口商/品牌商中属于较成熟的一档。具体拆分如下：

**物流网络模式**
- **自营为主**：佳农集团（Goodfarmer）在进口香蕉、奇异果等核心品类上采用自建仓储和自有/租赁冷链车队，尤其在上海、广州、大连、青岛等主要口岸和销地仓有自营布局，以控制品质和交付时效。
- **外包补充**：干线运输、部分区域配送和末端落地配会外包给第三方冷链物流商（如顺丰冷运、京东冷链及区域冷链公司），用于覆盖自营网络难以经济触达的下沉市场。
- **判断依据**：公开资料显示佳农建立了覆盖主要口岸和销区的冷链仓储配送体系，但未宣称"全自营"，行业惯例也是核心节点自营+末端外包。

**冷链能力**
- **产地到口岸**：进口品类依赖海运冷链集装箱，并有到港后的快速查验、催熟（香蕉催熟库）和分拨能力。
- **仓储**：具备多温区冷库（冷藏/催熟/常温），支持香蕉等后熟水果的温控管理。
- **运输**：冷藏车温控运输覆盖主要干线，配合TMS/温控监控。
- **短板**：末端下沉市场和部分区域配送依赖外包，温控一致性可控性弱于全自营；具体冷库面积、车辆数量等数据需以官方披露为准，公开渠道未完整公开。

**建议**：若要评估其是否满足你的合作需求，直接向佳农索取最新《冷链网络覆盖图》和主要城市配送SLA，重点核对你目标销区的"自营覆盖 vs 外包覆盖"比例及温控记录能力，这比笼统判断"自营还是外包"更有决策价值。
