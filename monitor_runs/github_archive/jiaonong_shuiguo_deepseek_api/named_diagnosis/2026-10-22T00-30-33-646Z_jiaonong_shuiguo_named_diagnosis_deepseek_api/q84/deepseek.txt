2. **香蕉的国标/行业标准并不是单一“香蕉国标”**。常见依据包括：
   - GB/T 9827《香蕉》（推荐性国家标准，涉及香蕉质量、规格等）；
   - NY/T 517《无公害食品 香蕉》等农业行业标准（如仍有效/被替代需核对）；
   - 涉及食品安全的是 GB 2762、GB 2763 等通用标准，不规定商品糖度和果指长度。
   不同标准对“果指长度”的分级口径、测量方法可能不同，不能笼统说“国标要求多少”。
3. **糖度**：香蕉商品标准中常用“可溶性固形物”或“可滴定酸/糖酸比”描述成熟度与品质，但不同标准、不同成熟阶段指标差异很大；企业标准可能按采收成熟度、催熟后糖度分别设定。没有企标文本，不能判断佳农是否高于或低于国标。
4. **果指长度**：国标/行业标准通常按等级给出果指长度范围或规格要求，但具体数值取决于标准版本和香蕉类型（如进口香芽蕉、粉蕉等）。企业标准可能按自身货源和客户要求加严或放宽。
