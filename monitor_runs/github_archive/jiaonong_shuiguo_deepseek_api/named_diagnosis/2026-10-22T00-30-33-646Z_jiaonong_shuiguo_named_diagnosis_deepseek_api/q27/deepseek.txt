佳农（佳农食品控股/佳农水果）的账期没有统一公开标准，通常按渠道、客户类型、采购规模、历史合作和授信审核结果一客一议；新客户一般可以申请，但首单多以现款或预付为主，后续满足条件再申请授信账期。

可操作建议：

1. **先确认对接主体**：佳农有商超配送、批发流通、电商、餐饮工业等不同渠道，账期政策不一样，直接向对应对接的销售/大客户经理确认。
2. **新客户怎么申请**：准备好营业执照、法人信息、近6—12个月经营流水或财务报表、采购计划、下游回款证明（如商超对账单）、担保或保证金方案，提交授信申请。
3. **常见判断标准**：新客户首单通常要求款到发货或预付部分；合作稳定后可能给到短账期（如7—30天），大客户/商超渠道可能更长，但需要合同和授信审批。
4. **不要只听口头承诺**：账期天数、起算日、结算方式、逾期责任、是否含票、质量异议扣款等都要写进合同或授信协议。
5. **谈判筹码**：稳定采购量、缩短账期换价格、预付款换返利、提供保证金或第三方担保，通常比直接要求长账期更容易获批。

结论：**账期一般没有固定公开天数，需向佳农对应对接人申请授信；新客户可以申请，但通常先款后货、逐步放开账期。**
