关于佳农水果的物流，公开可核实的信息有限。就我了解的情况，可以分两点说明：

**1. 运输方式：并非单纯“三通一达”或“纯自有车队”，而是混合模式**
- 佳农是进口水果贸易商+品牌商，干线运输以**自有/长期合作的冷链车队和第三方冷链物流**为主（如港口到仓储、仓储到区域分拨），并非依赖三通一达这类以电商小件快递为主的网络。
- 三通一达主要承担**电商零售端的小件寄递**（如线上门店、社区团购发货时可能用到），属于末端配送环节，不是其主力物流。
- 具体到某条线路、某个渠道用谁，属于企业运营细节，公开资料不完整，**不宜断言“就是某某车队”**。

**2. 冷链覆盖率：没有公开的精确百分比**
- 佳农主营香蕉、菠萝、牛油果、蓝莓等生鲜，行业里这类企业的冷链是“**干线冷链 + 部分城市冷库/冷柜中转 + 末端温控配送**”的分层覆盖，而非全链路100%冷链。
- 其冷链覆盖程度会因**品类、区域、渠道**差异很大：一线城市和商超渠道冷链相对完善，下沉市场或部分电商末端可能用常温/保温箱+冰袋过渡。
- 官方没有披露过“冷链覆盖率XX%”这类具体数字，我无法给出可靠数值，**不建议采信网传的单一百分比**。

**可执行建议：**
- 如果你是**想合作/采购**：直接联系佳农官方客服或销售，问“某品类、某城市、到货温控标准和承运方”，拿到书面答复。
- 如果你是**做研究/写报告**：可查佳农官网、年报（若上市/发债主体）、海关与冷链物流行业报告，或通过天眼查/企查查看其物流子公司/合作方，但需注明“公开信息有限”。
- 别把“三通一达”当成佳农主物流来判断其冷链能力，二者不是一回事。
