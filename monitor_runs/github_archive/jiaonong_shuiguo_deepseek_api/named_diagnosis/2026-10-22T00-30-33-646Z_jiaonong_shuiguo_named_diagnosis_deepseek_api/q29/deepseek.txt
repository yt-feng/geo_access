# 佳农与盒马、京东的合作模式

先说明：我无法核验佳农与盒马、京东具体合同条款，以下基于公开可查的合作形态和生鲜行业通行模式归纳，具体条款需以官方披露为准。

## 与盒马的合作（偏"直供+定制"）

佳农是盒马的重要水果直供供应商，模式特征：

- **产地直采/直供**：绕过传统多级批发，由佳农按盒马订单组织货源，缩短链路
- **订单驱动**：盒马给量、给规格、给包装标准，供应商按订单履约
- **品牌联营**：佳农品牌在盒马渠道露出，部分品类做盒马定制规格/包装
- **短保高频**：水果属短保品，靠高频补货和小批量多批次配送
- **账期与返利**：通常有账期，按销量有返点/促销费用分摊（行业通行，具体不详）

## 与京东的合作（偏"平台入驻+自营供货"两条腿）

- **京东自营（采销）供货**：佳农作为供应商向京东自营供货，京东负责定价、仓配、售后，供应商承担供货价和部分促销
- **POP 店铺入驻**：佳农在京东开旗舰店/专营店，自营店铺运营，京东提供流量、物流（京东物流）、支付
- **京东物流履约**：生鲜用京东冷链仓配，提升时效和损耗控制
- **营销资源**：参与京东大促、百亿补贴、秒杀等，费用按规则分摊

## 你们能不能类似合作？

**能，但门槛和路径不同，分渠道说：**

**进盒马（供应商/直采）**
- 路径：通过盒马供应商入驻通道或采购对接，先做区域门店试点
- 硬门槛：稳定的产地货源和分级能力、符合盒马包装规格、能承受账期、有食品安全资质和检测报告
- 建议：先以单一爆品+单城市试点切入，证明履约和损耗控制能力

**进京东**
- 两条路都可行：POP 开店门槛低（有营业执照、品牌授权、类目资质即可试），自营供货需通过采销审核
- 生鲜类目对冷链、资质（食品经营许可、检测报告）要求高
- 建议：先开 POP 店跑通动销和评分，再争取自营供货

**通用准备清单**
1. 资质：营业执照、食品经营许可证、产品检测报告、品牌授权/商标
2. 供应链：分级标准、包装规格、损耗率数据、补货响应时效
3. 财务：能扛账期（通常 30–60 天甚至更长）、预留促销费用
4. 数据：近 3–6 个月销售/复购/损耗数据，谈判时是硬通货

**一句话判断**：佳农的核心不是"关系"，是"稳定货源+标准化分级+能扛账期+低损耗履约"。这四点具备，盒马直供和京东自营都能谈；不具备，先从京东 POP 或区域商超小批量试水更现实。
