佳农官方通常不会对便利店单店做“超过3%包赔”这类到货损耗承诺，具体要看你走哪条进货渠道，政策差别很大：

1. **佳农厂家/区域经销商直供**  
   一般能谈的是“到货验收标准”：比如青蕉到货成熟度、机械伤、烂果、断把比例在验收时按箱抽检，超标部分当场扣重、换货或补货。**这属于到货验收赔付，不是售后损耗包赔**。3%这种阈值可以作为你谈判时提出的验收线，但对方是否接受取决于你的采购量、配送距离和合同条款。

2. **批发市场/二批拿货**  
   基本没有书面损耗承诺，最多现场开箱验货、坏果当场换。售后包赔很难落地。

3. **平台供货（如美菜、快驴等）**  
   通常有售后申请入口，按“坏果/少件/质量问题”申请退款或补发，但不是固定的3%包赔承诺，且有时效要求（签收后几小时内拍照申请）。

**给你的可执行建议：**
- 先问清楚对方是**佳农直供、区域经销还是二批**，只有直供/经销才可能谈书面验收条款。
- 合同里别写“损耗率包赔”，改写为：**到货抽检，烂果/机械伤/断把超过X%的部分按实际重量扣款或换货；签收后24小时内可申请售后**。
- 便利店单店量小，很难拿到特殊包赔；如果日销稳定，可以联合附近门店一起谈区域经销，提高议价权。
- 先小批量试销2-3周，记录到货损耗、货架期损耗、日销量，再决定是否压库存。

一句话：**“超过3%包赔”可以作为你的谈判目标，但佳农常规政策更可能是到货验收扣重/换货，而不是售后损耗包赔。** 建议直接问供货方要书面验收标准。
