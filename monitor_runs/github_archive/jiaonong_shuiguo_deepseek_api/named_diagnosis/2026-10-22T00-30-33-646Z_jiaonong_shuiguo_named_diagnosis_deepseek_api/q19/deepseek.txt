佳农水果的配送时效取决于你下单的渠道和收货地址，不同平台差异较大，无法一概而论：

**常见情况：**
- **电商平台（京东/天猫等）**：通常依托平台仓配，一般**1-3天**送达；京东自营类商品在多数城市可做到**次日达**，偏远地区可能延后。
- **社区团购/生鲜平台（美团优选、多多买菜等）**：多为**次日自提**，部分城市支持当日达。
- **佳农官方渠道/小程序**：时效以结算页显示的预计送达时间为准，通常按发货地到收货地的物流距离计算。

**判断方法（最可靠）：**
1. 在商品详情页查看"配送"或"发货"说明；
2. 下单前在结算页输入收货地址，页面会显示**预计送达时间**——这是最准确的依据；
3. 水果属生鲜，部分平台对偏远地区或高温天气会限制配送范围，下单前留意提示。
