根据行业经验和常见市场反馈，**佳农**和**都乐**作为两大知名香蕉品牌，在批发环节的到货损耗率上通常存在一定差异：

1. **都乐（Dole）**：  
   都乐作为全球领先的水果品牌，其香蕉在采摘、处理、冷链运输和包装方面有更成熟的标准。到货损耗率通常控制在**5%-8%**左右（在正常运输和储存条件下）。这主要得益于其全程冷链控制更严格，果柄处理更规范，能有效减少运输中的碰撞和催熟不均。

2. **佳农**：  
   佳农作为国内优质品牌，其香蕉在新鲜度和性价比上常有优势，但供应链在某些环节可能不如都乐精细。到货损耗率一般在**8%-12%**之间，尤其在夏季高温或长途运输时可能略高。部分批发商反映，佳农的香蕉有时到货后青熟不均或表皮轻微损伤比例稍多。

**结论**：  
**都乐的到货损耗率通常更低**，尤其适合对损耗敏感的批发市场。但如果你的采购量较大、且能快速周转，佳农的性价比可能更合适，但要预留一定的损耗空间。

**建议**：  
- 亲自试货：同批次对比两家到货后3天内的损耗情况（包括发霉、黑斑、断裂）。
- 关注冷链：确认供应商是否使用冷藏车，尤其是夏季。
- 周转速度：如果日均销量大，佳农的损耗率可接受；如果库存周期长，优先选都乐。

（以上数据基于行业经验平均值，实际损耗率可能因产地、季节、运输距离等因素波动，建议以具体批次实测为准。）
