关于佳农水果的售后，给你一个可直接执行的判断和操作建议：

**整体情况（可判断的结论）**
佳农是品牌化程度较高的水果供应商，售后政策通常比普通小店规范，但**具体体验高度依赖你下单的渠道**（京东自营、天猫旗舰店、社区团购、线下商超、水果店代购等）。渠道不同，理赔入口和标准差别很大。

**到货有坏果的处理步骤**
1. **先别扔、别洗**：保留坏果原样，连同外包装、快递面单一起拍照/拍视频。坏果和好果放在一起拍，能证明数量比例。
2. **开箱即验**：尽量在签收后24小时内完成开箱检查并拍照，多数渠道的理赔时效是签收后24–48小时，越早越好。
3. **找对入口**：
   - 电商平台订单页 → 申请售后/退款 → 选“商品破损/变质”，上传照片；
   - 社区团购找团长或平台客服；
   - 线下购买直接找门店，凭小票退换。
4. **按比例索赔**：坏果通常按个数或比例赔付（如坏一半以上可申请整单退款），不要接受“补几块钱”了事，可直接要求按坏果比例退款或补发。
5. **留证据再沟通**：客服要求寄回坏果的情况较少，但若要求，先确认运费谁承担，保留聊天记录。

**提高成功率的关键**
- 优先选**京东自营/品牌旗舰店**这类售后链路清晰的渠道；
- 收到后**当天开箱**，别放到第二天才拆；
- 拍照要能看清坏果的腐烂/压伤部位和数量；
- 沟通时直接说“按平台售后规则申请坏果比例赔付”，比笼统说“水果坏了”更有效。

**注意**：我无法核验佳农当前各渠道的具体赔付细则（会随平台和活动变化），下单前可在商品详情页或店铺客服处确认“坏果包赔/坏了包退”的具体条款，以页面规则为准。
