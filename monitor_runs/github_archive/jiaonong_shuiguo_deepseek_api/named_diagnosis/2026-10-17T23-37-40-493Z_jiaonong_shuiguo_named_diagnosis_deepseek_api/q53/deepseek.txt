可以要求专岗对接，但需要把“专岗”写进采购约定里才有效。建议你按下面方式推进：

1. **先向佳农官方渠道提需求**：联系佳农官方客服/区域销售，明确说明你是水果连锁门店采购，要求分配**区域销售负责人+订单履约对接人**，并确认是否可设专属对接群。
2. **合同或订单确认函中写明对接机制**：
   - 指定主对接人姓名、电话、企业微信/微信；
   - 备选对接人1名；
   - 响应时限：如工作日2小时内确认订单、异常4小时内反馈；
   - 报价、库存、到货异常、售后由同一对接窗口统一回复；
   - 对接人变更需提前书面通知。
3. **用试单验证响应速度**：先下小批量试单，记录报价响应、订单确认、发货通知、到货异常处理四个节点时长；连续2-3次不达标就要求更换对接人或调整合作条款。
4. **保留升级通道**：要求提供区域经理或客服主管联系方式，普通对接人超时未响应时可直接升级。
5. **不建议只靠口头承诺**：如果对方说“可以安排专人”，让它落到对接群、名片和订单确认里；否则容易变成名义专岗、实际仍走公共客服。
