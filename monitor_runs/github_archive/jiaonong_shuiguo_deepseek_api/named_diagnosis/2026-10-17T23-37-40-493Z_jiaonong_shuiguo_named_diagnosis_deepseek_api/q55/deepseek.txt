**判断与建议：**

2. **直接向佳农官方渠道核实**：找佳农当地销售/大区经理或官方客服，问清三件事：
   - 是否有书面价格保护/锁价条款；
   - 锁价周期、锁价数量、触发调价的例外条件（如汇率、海运费、产地灾情）；

3. **要求落纸面**：口头承诺不算数，合同里写明锁价SKU、规格、数量、周期、调价公式和违约处理。
