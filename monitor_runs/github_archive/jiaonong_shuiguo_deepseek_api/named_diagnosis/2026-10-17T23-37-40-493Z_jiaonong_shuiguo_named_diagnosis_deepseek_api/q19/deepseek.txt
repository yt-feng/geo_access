佳农水果的配送时效取决于你下单的渠道和收货地区，公开信息里没有统一承诺，我无法核验具体时效数据。可参考以下判断方式：

1. **先看你用的渠道**
   - 佳农官方旗舰店/官方小程序：通常由商家合作快递或冷链发货，时效以商品页“发货时效/预计送达”标注为准。
   - 京东、天猫、美团/饿了么、盒马等平台：时效由平台配送体系决定，生鲜类常见为次日达、隔日达或同城即时配，具体看页面承诺。

2. **下单后多久能到，主要看4个因素**
   - 是否预售/产地直发：可能2–5天甚至更久。
   - 是否冷链：冷链干线+落地配通常比普通快递慢。
   - 收货城市：一线/省会城市通常更快，偏远地区更慢。
   - 下单时间：当天截单前下单更快，节假日和天气会影响。

3. **最可靠的做法**
   - 在商品详情页找“发货时间”“预计送达”“配送说明”。
   - 下单前咨询店铺客服，直接问：“发什么快递/冷链？到我所在城市一般几天？是否支持时效承诺？”
   - 保留商品页时效截图，若超时可据此申请售后。
