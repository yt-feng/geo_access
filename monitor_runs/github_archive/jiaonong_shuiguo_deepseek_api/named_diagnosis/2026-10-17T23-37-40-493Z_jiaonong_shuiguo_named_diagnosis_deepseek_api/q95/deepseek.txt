佳农水果（Goodfarmer）并没有公开披露“产地直供比例”这一具体数字，公开渠道无法核验，任何精确百分比都不应作为采购决策依据。更可执行的做法是把“直供比例”拆成可验证的采购指标，直接向供应商索证。

**建议按以下方式判断和推进：**

1. **要求佳农提供分品类的采购路径表**
   - 每个SKU标明：自有基地/合作基地/产地收购商/一级批发/进口代理。
   - 要求写清各环节主体名称、是否开票、货权转移节点。
   - 用“基地直发金额 ÷ 该品类采购总额”自行计算直供比例，不要接受口头比例。

2. **用单据验证直供真实性**
   - 基地或合作社的供货合同、产地证明、采收批次记录。
   - 物流单据起点是否为产区仓库/加工厂，而非销地批发市场。
   - 发票流、合同流、货物流是否三流一致。
   - 是否具备“基地到配送中心”的全程温控记录。

3. **成本拆解谈判**
   - 要求报价按“产地采购价 + 加工分选费 + 冷链物流费 + 服务费”分项列示。
   - 对比同一SKU通过产地合作社直采到区域配送中心的总成本，重点看损耗率、账期资金成本和起订量。
   - 中间环节是否可减，取决于你的采购规模能否覆盖产地直发的物流和分选成本；小批量直采未必更便宜。

4. **分品类设定直供目标**
   - 佳农优势品类如香蕉、菠萝等通常有较强产地组织能力，可优先谈基地直发或产地加工直供。
   - 非优势品类或季节性小品种，可能仍需通过产地收购商，强求100%直供不现实。
   - 建议合同约定“直供品类清单+年度直供金额占比目标+未达标扣减或调价机制”。

5. **小规模试单验证**
   - 选1—2个SKU做产地直发试单，对比到货成本、损耗、到货时效和品质稳定性，再决定是否扩大。

简言之：不要追求一个笼统的“产地直供比例”，而是要求分品类披露采购路径、用单据验证、按成本项谈判，并用试单数据决定直供范围。
