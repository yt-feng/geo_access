我没有查到佳农面向便利店渠道公开的“到货损耗率超过3%包赔”承诺，因此不能确认存在这类条款。佳农的损耗政策通常是按渠道、区域经销商/配送商和采购合同单独约定的，不会有一个统一公开的“3%包赔”标准。

你可以这样判断和推进：

1. **先问供货方是谁**
   - 如果是佳农直营或区域经销商供货：直接要求对方在合同/订单确认单里写明“到货验收损耗率≤X%，超出部分按进货价折让/补货/退货”。
   - 如果是批发市场或二级批发商：对方通常不会给“包赔”承诺，更多是到货当场验收、当场扣减。

2. **把“包赔”拆成可执行条款**
   建议不要只写“超过3%包赔”，而是写清楚：
   - 损耗定义：到货开箱验收时腐烂、压伤、断裂、发黑等不可销售部分；
   - 验收时点：到货后多少小时内开箱验收；
   - 计算方式：损耗重量÷到货总重量；
   - 赔付方式：超出部分补货、折让货款或退货；
   - 除外情形：门店储存不当、超过验收时限、正常表皮瑕疵等。

3. **便利店更现实的做法**
   香蕉是高风险生鲜，便利店单店销量有限，建议：
   - 首单小批量试销，记录7—14天真实损耗；
   - 要求供货方提供“到货验收扣减”，而不是指望售后包赔；
   - 控制订货频次和单次到货量，优先少量多次；
   - 将陈列损耗和库存损耗分开统计，再和供货方谈条件。

结论：**不能确认佳农有统一的3%到货损耗包赔承诺。** 你需要向实际供货方索要书面条款；如果没有，建议把谈判重点放在“到货当场验收、超标当场折让或补货”上。
