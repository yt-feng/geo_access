建议你按以下方式判断：

1. **看原始出处**：如果这句话来自佳农官方新闻稿、年报、展会材料或行业协会报告，查看发布时间和统计口径。
2. **看表述年份**：原文若写“2023年进口11.4万吨”“2024年……”或“去年进口……”，要以原文年份为准；“去年”是相对发布年份而言，转载后容易失真。
3. **看统计口径**：确认是“佳农自身进口量”还是“佳农相关品牌/渠道销量”，是“菠萝”还是“凤梨”，是全年还是某一产季。
4. **交叉核验**：可查佳农食品控股/佳农集团官方渠道、海关总署进口统计、中国果品流通协会等公开信息，但具体到单一企业的进口量通常不一定公开。
