1. **发票**
   - 佳农水果礼盒通常可由供货方开具发票，但能否开、开什么类型取决于你找的渠道。
   - 你需要确认：**增值税普通发票还是专用发票、税率/征收率、开票主体名称、是否可开明细/清单、开票时间**。
   - 500份属于团购批量，建议合同里写明“先票后款/款到开票/随货附票”以及发票不符时的处理。

2. **质检报告**
   - 可要求供货方提供该批次或近期批次的**农产品质量安全检测报告/农残检测报告**。
   - 要确认报告对应的是**同一品类、同一供应商、报告有效期和批次**，不能只给一份通用模板。
   - 水果礼盒若含多个单品，最好每个单品都有对应检测材料，或至少提供礼盒整体的供货方质检/验收标准。

3. **下单前必须书面确认**
   - 供货方营业执照、食品经营许可/相关资质；
   - 500份的**单价、规格、净重、单品清单、包装方式、生产/采摘日期、保质期、破损赔付**；
   - 发票类型和开票主体是否与合同一致；
   - 质检报告是随货提供还是签约前提供；
   - 送货时间、验收标准、坏果率赔付和补发方案。

4. **判断建议**
   - 如果对方能提供**与合同主体一致的发票**和**对应批次的质检报告**，可以推进；
   - 如果只能开票但不能提供批次质检，或质检报告与货品不一致，建议换渠道或把“提供对应批次质检报告”作为付款条件写进合同。

你可以直接让对方回复一句话确认：**“500份佳农水果礼盒可开具__类型发票，开票主体为__，并可提供对应批次质检报告，报告在__时间提供。”** 拿到这句再谈价格和账期。
