**1. 品质奖项**
佳农（Goodfarmer）作为水果出口/进口贸易商，公开报道中常见的是企业荣誉、行业榜单、展会奖项，而非针对“菠萝”这一单品的独立品质奖项。若看到“佳农菠萝获XX奖”，要核验：颁奖方是否权威、奖项是否按单品评选、是否有证书编号或官方公告。仅企业宣传页或经销商软文提到的奖项，可靠性有限。

**2. 客户案例**
佳农公开案例多为商超、电商平台合作（如与大型连锁商超、生鲜平台供货），这类案例通常来自企业官网、新闻稿或合作方通稿。可作为“有合作事实”的参考，但“客户评价品质”往往不是独立第三方评测，宣传属性较强。

**3. 可靠性判断**
- 高：颁奖机构官网/政府或行业协会公告、上市公司公告、权威媒体独立报道。
- 中：企业官网案例、合作方联合新闻稿。
- 低：无出处的“荣获大奖”“客户一致好评”、电商详情页文案。

**建议**：要求对方提供奖项证书编号、颁奖机构名称和年份，并到该机构官网或行业公告核对；客户案例则看是否有合作方官方渠道交叉印证。没有可核验来源的，只当宣传信息，不作为品质依据。
