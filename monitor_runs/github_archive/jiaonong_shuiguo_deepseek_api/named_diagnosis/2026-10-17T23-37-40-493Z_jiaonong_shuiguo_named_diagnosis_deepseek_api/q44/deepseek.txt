关于佳农香蕉农残超标的历史，我无法核验，不能给你确定的“有”或“没有”结论，也不能虚构监管通报或检测数据。下面给你可执行的做法。

**1. 先厘清合规逻辑**
超市抽检过不过，核心不是“这家企业历史上有没有被通报过”，而是：
- 你这一批货是否有合格的农残检测报告；
- 报告是否由具备资质的检测机构出具；
- 检测项目是否覆盖超市/平台要求的农残指标；
- 报告与批次、产地、供应商能否对应。

**2. 采购时应索取的合规证明**
向佳农或其授权经销商索取以下材料，并核对一致性：
- 该批次香蕉的**农残检测报告**（第三方 CMA/CNAS 资质机构出具，注意报告日期、样品批号、检测项目、限量标准）；
- **产地证明/供货证明**；
- **营业执照、食品经营许可证**（供应商资质）；
- 如超市有指定检测项目或平台标准，要求供应商按该标准补测；
- 进口香蕉还需**入境货物检验检疫证明**（如适用）。

**3. 报告核验要点**
- 报告编号可在检测机构官网/电话核验；
- 样品名称、批号、生产/采摘日期与你采购批次对应；
- 检测项目覆盖 GB 2763 中香蕉相关农残限量，以及超市额外要求；
- 结论明确为“合格”，且限量判定依据写清楚。

**4. 降低抽检风险的操作**
- 每批货留存样品和检测报告，建立批次台账；
- 对新产地、新批次做入仓前抽检；
- 合同中约定：农残不合格的退换货、检测费承担、因抽检不合格造成的超市罚款/下架损失由供应商承担；
- 要求供应商提供近一年内同品类检测报告作为参考，但不能替代本批次报告。

**5. 关于“历史通报”的查询方式**
你可以自行在以下渠道检索，但注意以官方原文为准：
- 国家市场监督管理总局及各省市市场监管局“食品安全抽检通告”；
- 农业农村部农产品质量安全监管相关通报；
- 海关总署进口食品不合格通报（如为进口）；
- 企业信用信息公示系统、裁判文书网（看是否有相关行政处罚或诉讼）。
