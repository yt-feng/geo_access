佳农水果（佳农食品控股/Goodfarmer）的苹果品类通常以“进口+国产”两条线出现，但具体SKU会随季节和渠道变化，建议以佳农官方渠道或你对接的销售确认当期在售清单。可参考的品类框架如下：

1. **进口苹果**
   - 新西兰苹果：嘎啦（Gala）、红玫瑰/爱妃等（爱妃通常为Envy，属不同品种）
   - 美国苹果：红富士（Fuji）、嘎啦（Gala）、蛇果等
   - 智利苹果：嘎啦、红富士等（南半球季节补充）
   - 南非/法国等：嘎啦、红富士等，视产季和采购线而定

2. **国产苹果**
   - 红富士：山东、陕西、甘肃等产区
   - 嘎啦：山东、陕西等产区
   - 其他如花牛、维纳斯黄金等，视渠道

关于你关心的**进口嘎啦和红富士产地**：
- **进口嘎啦**常见产地：**新西兰、美国、智利、南非**等，具体看佳农当季采购批次。
- **进口红富士**常见产地：**美国、智利**等；新西兰红富士相对少见，更多是嘎啦/爱妃/火箭果等品种。

采购建议：
- 直接向佳农销售索要**当季进口苹果SKU表+产地证明/原产地证+箱标照片**，以箱标上的“Product of …”为准。
- 合同里写明**品种、产地国、规格（果径/等级）、包装、到货港、允差和索赔条款**，不要只写“进口嘎啦/红富士”。
- 若你只要进口货源，注意嘎啦和红富士的**产季错位**：美国/新西兰/智利/南非的供应窗口不同，需按到货月份锁定产地，避免用“佳农有进口红富士”泛化判断。
