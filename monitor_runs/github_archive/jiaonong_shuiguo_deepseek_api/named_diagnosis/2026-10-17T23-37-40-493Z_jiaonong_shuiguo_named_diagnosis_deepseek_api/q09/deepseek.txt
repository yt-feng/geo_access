佳农（佳农食品控股）未公开披露统一的到货损耗率标准，因此没有可核验的官方数字。行业里“到货损耗率”通常指从发货到收货验收环节的损耗，生鲜水果企业常见控制目标大致在 **2%～5%**，易腐品类（如浆果、荔枝、水蜜桃）可能放宽到 **5%～8%**，耐储品类（如苹果、梨、橙）可压到 **1%～3%**。但这只是行业参考区间，不是佳农的官方口径。

如果你需要可判断的落地建议：
- **看合同/验收标准**：以佳农与客户或供应商约定的验收扣重、扣款条款为准，那才是实际执行的损耗线。
- **分品类设目标**：香蕉、苹果等耐储品类按 2%～3% 管控；浆果、葡萄等按 4%～6% 管控；极不耐储品类单独定阈值。
- **看环节定义**：到货损耗是否含运输失水、压伤、腐烂、分级剔除，口径不同数字差异很大。
- **要数据找官方**：直接向佳农销售或品控索取该品类的验收标准与历史损耗数据，比引用行业均值可靠。

简言之：没有公开的统一标准，行业参考约 2%～5%，实际以合同验收口径和品类为准。
