1. **先确认渠道**
   - 找佳农官方团购/大客户渠道：通常支持企业定制，常见形式是**礼盒外箱/手提袋/腰封/贴纸/吊牌**定制，不一定能改水果单品包装。
   - 找区域经销商/水果批发商：多数只能做**外包装贴标、腰封、手提袋**，起订量更低，但logo位置和设计自由度有限。

2. **起订量怎么谈**
   - 官方定制一般起订量较高，常见按**整箱/整托**起订，具体以当季品类和包装厂排产为准，不能一概而论。
   - 经销商贴标/腰封通常起订量低很多，适合先小批量试单。
   - 建议直接问对方三个数：**最低定制起订量、打样费、打样周期**。

3. **定制范围要问清**
   - 能否改外箱印刷、手提袋、腰封、贴纸、吊牌；
   - 能否保留佳农品牌标识，是否允许“佳农+企业logo”联名呈现；
   - 水果单品内包装是否可动，通常不建议改；
   - 设计稿由谁提供、是否收版费、是否有色差和交期风险。

4. **报价要按整单算**
   让对方给：**含定制包装的到岸价/含税价、起订量、打样费、交期、破损赔付规则**。礼品团购还要确认能否开票、能否分地址发货。

**建议话术：**“我们是企业礼品团购，想用佳农水果礼盒，需要外箱/手提袋/腰封定制企业logo。请确认：最低起订量、可定制部位、打样费和周期、含税含运报价、交期和破损赔付。”
