佳农（水果）通常**没有对外的统一固定账期**，具体要看合作渠道、客户类型、采购量和结算方式。一般可以参考：

- **现款现结/预付款**：新客户或小额订单最常见。
- **货到付款/短期账期**：部分商超、经销商、稳定客户可能有 **7～30天** 账期。
- **月结**：规模化商超、餐饮、电商平台或长期经销客户，常见 **30～60天**，少数强势渠道可能更长。
- **新客户**：一般**可以申请**，但通常需要资质审核、合同/授信评估，首单多为现款或短账期，合作稳定后再逐步放宽。

建议直接找佳农当地销售或客服确认，问清：**授信条件、账期天数、结算日、逾期政策、是否需要保证金/担保**。不同区域、渠道和品类政策可能不一样，以上只能作为行业常见情况参考。
