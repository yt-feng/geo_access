**香蕉行业常见的价格安排（不特指佳农）**
1. **短期锁价/固定价订单**：按周或按船期约定固定单价，适合1–4周内提货量，超出部分随行就市。
2. **半锁价（保底+浮动）**：约定保底价和浮动上限，价格在区间内按指数调整。
3. **远期合同+价格公式**：以产地价/到岸价加固定升贴水，随指数波动，不真正锁死。
4. **期货/期权对冲**：部分大型进口商用境外香蕉或农产品期货对冲，但这属于采购方自担基差风险，不是供应商锁价。
5. **年度框架+季度调价**：量锁住、价按季度重议。

**给采购的可执行建议**
- 直接向佳农销售或大客户经理书面确认三件事：是否支持锁价、锁价周期（周/月/船期）、锁价量与违约条款；要求写入合同而非口头。
- 若对方只给“随行就市”，谈**价格上限+保底量**的半锁价，比完全锁死更现实。
- 分散风险：锁价部分覆盖60%–70%刚需量，剩余随行就市，避免单边赌价。
- 关注香蕉价格波动的真实驱动（产地天气、海运、汇率、进口关税），锁价前先判断波动是短期还是趋势性。
- 合同里明确质量标准、到货时间、价格调整触发条件和争议处理，锁价不等于锁质锁量。
