**1）先确认你要的其实是哪一类**
便利店常见香蕉有三种：
- **单根裸卖**：门店自己拆把，按根卖，不是厂家单根包装。
- **单根独立包装**：每根套袋/贴标/装盒，适合直接陈列和扫码。
- **小把装**：2–4根一把，便利店更常见。

佳农在香蕉品类里主要是**整把/整箱**流通较多，是否针对便利店做“单根独立包装”通常取决于区域经销商和渠道定制，不是全国统一标准品。

**2）最快确认方式**
直接问佳农当地经销商或区域业务，问这4个问题：
- 有没有**单根独立包装**的便利店专供SKU？
- 起订量是多少？是按箱还是按托？
- 包装形式是套袋、贴标、装盒还是气调小包装？
- 是否支持**门店扫码销售**，条码是否一品一码？

**3）如果佳农没有，替代方案**
- 找当地香蕉批发商做**门店分装**：你定规格，他们套袋贴标。
- 用**都乐、进口蕉或本地品牌**问同类小包装。
- 自己门店做**单根分切+套袋+贴价签**，但损耗和人工会高。
- 鲜切水果供应商通常更愿意做**单根便利店包装**。

**4）你采购时要重点看的指标**
- 单根重量范围，比如120–160g
- 成熟度，便利店适合**3–4级**，太熟损耗快
- 保质期和到店剩余货架期
- 是否耐搬运、是否容易黑斑
- 单根成本 vs 按把拆卖成本

**结论**：不能确认佳农有现成的“单根包装便利店香蕉”。最稳妥的是直接联系佳农区域经销商问定制SKU；如果没有，就找本地分装商或鲜切供应商做单根包装，通常比等厂家标准品更快。
