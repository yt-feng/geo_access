**关于农残是否合格**

- 单个品牌名不能等同于"每批都合格"。农产品农残是否达标，取决于具体批次、产地、采收时间和检测报告。
- 佳农作为大型果蔬进口商（主要做香蕉、菠萝等），通常会有较完善的自检和供应商管理流程，但这类信息不会实时公开。
- 想确认某批香蕉是否合格，最直接的方式是看购买渠道的**批次检测报告**，或扫描包装上的追溯码。

**关于食品安全认证**

佳农公开宣称涉及的体系通常包括：

- **ISO 22000** 食品安全管理体系
- **HACCP** 危害分析与关键控制点
- **GlobalG.A.P.**（产地端，多为供应商持有）
- **BRC** 或类似零售商审核标准（视供货对象而定）

但这些认证**以企业实际持有的最新证书为准**，认证也有有效期和范围，需要通过官方渠道核验，不能只信宣传。

**建议的可执行做法**

1. 在**佳农官网或官方旗舰店**查询其资质证书公示。
2. 向购买平台的**客服索取该批次检测报告**（正规渠道一般能提供）。
3. 用包装上的**追溯码**在官方追溯系统查询产地和检测信息。
4. 如仍有疑虑，可向**当地市场监管部门**咨询，或在"国家企业信用信息公示系统"查看企业资质。
