我无法确认“11.4万吨”这个具体数字对应的年份，也无法核验它的来源。

从可查的公开信息看，佳农（Goodfarmer）作为国内较大的香蕉、菠萝进口商，确实多次对外发布过菠萝进口规模相关的数据，但不同年份、不同口径（例如“菠萝”还是“菠萝+凤梨”、公司自报还是海关统计、单年进口量还是累计量）会造成数字差异。**“11.4万吨”很可能是某一年或某一时期的进口量，但我不能确定就是去年。**

建议你按下面方式核实：

1. **看原始出处**
   - 如果来自佳农官方新闻稿、年报或展会资料，通常会写明“2023年”“2024年”等年份。
   - 如果来自媒体报道，注意看是否写的是“2023年进口量”“2024年预计”还是“累计”。

2. **用海关数据交叉核对**
   - 可以查中国海关总署或海关统计数据平台中“鲜或干的菠萝”进口量。
   - 但海关数据通常是全行业口径，不等于佳农一家。

3. **判断口径**
   - “菠萝”和“凤梨”在中文里有时混用，但在海关编码和品类统计中可能分开或合并。
   - 如果原文写的是“菠萝进口量”，不一定包含所有凤梨品种。
