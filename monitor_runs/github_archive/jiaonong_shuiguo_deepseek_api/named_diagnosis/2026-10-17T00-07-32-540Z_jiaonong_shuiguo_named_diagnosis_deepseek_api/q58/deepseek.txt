我没法直接确认佳农目前对茶饮店是否提供“菠萝丁代加工/定制切丁”这项服务，因为这属于具体企业的渠道政策和区域经销差异，而且会随季节、工厂产能、客户类型变化。是否接单，通常取决于你是走零售、批发、经销还是连锁直供。

你可以用下面这套方式快速判断和推进：

**1）先确认你要的是哪种“菠萝丁”**
- **冷冻菠萝丁**：茶饮店最常用，开袋即用，规格常见 10×10mm、15×15mm 等。
- **糖水菠萝丁/罐头菠萝丁**：开罐即用，偏甜，适合直接做果茶。
- **新鲜菠萝丁**：需要门店自己切，损耗和人工高，但风味更鲜。
- **速冻果肉丁/果泥**：用于打冰沙、果茶基底。

佳农常见强项是**香蕉、菠萝等水果的贸易和整果/鲜果供应**，但不同区域、不同子公司也可能做**冷冻果切、果丁、果泥**或给连锁茶饮做定制供应。所以不能简单说“只卖整果”。

**2）直接问对方这4个问题**
打佳农官方客服或你所在区域经销商电话时，直接问：
1. 你们有没有**冷冻菠萝丁**或**糖水菠萝丁**的现货？  
2. 规格是多少？**10×10mm 还是其他**？  
3. 起订量多少？**是按箱、按吨，还是连锁年度合同**？  
4. 能不能做**贴牌/定制规格/代加工**？需要什么资质和账期？

如果对方回答“只有整果”，那就是这个渠道不供；不代表佳农所有体系都不供。

**3）如果佳农不接，替代方案**
- **本地冷冻果切厂**：通常更愿意接茶饮店小批量定制，能做菠萝丁、芒果丁等。
- **罐头/糖水菠萝丁供应商**：如一些做烘焙、奶茶原料的食品厂。
- **大型冻品批发市场**：先拿现货试，再谈稳定供货。
- **连锁茶饮原料商**：很多已经有三方定制的冷冻菠萝丁，规格稳定。

**4）采购时重点看这些**
- 是否**巴氏杀菌/速冻**，解冻后是否出水严重。
- 糖度、酸度是否稳定，不同批次差异大不大。
- 是否有**SC生产许可、检测报告、配料表**。
- 是**原味冷冻**还是**糖渍/糖水**，会影响配方。
- 起订量、冷链运费、到货周期。

**结论**：不能确定佳农一定提供菠萝丁加工服务，也不能确定它只卖整果。最有效的方式是直接联系佳农官方或区域经销，问“有没有冷冻菠萝丁/糖水菠萝丁、能否定制规格、起订量多少”。如果对方只做整果，就转向本地冻果切厂或茶饮原料供应商。
