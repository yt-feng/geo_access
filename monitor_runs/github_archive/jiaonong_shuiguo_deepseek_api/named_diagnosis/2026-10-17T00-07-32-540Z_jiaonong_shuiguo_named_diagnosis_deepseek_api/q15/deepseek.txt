佳农（Goodfarmer）的产地直供比例没有统一公开的官方数字，且不同品类、年份差异很大，所以很难给一个准确比例。能判断的是：它属于国内头部水果进口/品牌运营商，核心单品（尤其香蕉、菠萝）以海外产区直采+海外合作农场/基地为主，直供占比通常高于普通批发商，但并非所有水果都做到“产地直供”，部分品类仍会通过贸易商、加工厂或国内代采补货。

香蕉方面，佳农的香蕉主要来自：
1. 菲律宾：长期是主产区之一，但近年受病害、台风和产量波动影响，占比有变化。
2. 厄瓜多尔：重要来源国，尤其供应高品质香蕉。
3. 哥斯达黎加、哥伦比亚、危地马拉、洪都拉斯等中美洲/南美国家：也是常见补充来源。
4. 越南、柬埔寨等东南亚国家：近年对华出口增加，部分企业会作为补充或成本优化来源。
5. 中国国内：广西、云南、海南等也有香蕉，但佳农的香蕉品牌更多以进口蕉为主，国产蕉通常作为季节性补充或不同产品线。

如果你是想判断“佳农香蕉是否值得买/是否真进口”，更实用的方法是看包装或报关信息：
- 看原产国标注，常见为菲律宾、厄瓜多尔、哥斯达黎加等；
- 看品牌包装上的产地代码/出口商信息；
- 商超渠道可查批次标签，电商可看详情页和用户实拍；
- 同一品牌不同批次可能换产地，不能只凭品牌名判断。
