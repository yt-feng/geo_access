我不能直接确认佳农当前对某家商超的香蕉促销支持政策，因为这属于厂商与渠道之间的商务政策，会随区域、客户级别、采购量、促销档期、合同条款变化，而且我无法核验佳农内部或最新对外政策。直接说“能”或“不能”都可能误导你。

你可以按下面方式拿到确定答案，并同时提高谈成概率：

**1）先确认找谁谈**
- 佳农在各地的经销/代理商，或你们系统总部对接的佳农KA/渠道经理。
- 如果是连锁商超，通常先走总部采购，再由区域厂商落地支持。

**2）直接问这4类支持，别只问“能不能”**
- **搭赠**：进货多少件赠多少件，赠品是否随货、是否限定门店/档期。
- **降价补贴**：厂商承担多少毛利损失，是返利、补差还是直接降供价。
- **陈列/端架/堆头费**：是否支持促销位费用或免费提供物料。
- **临期/损耗处理**：香蕉损耗高，要明确破损、黑斑、滞销是否可退换或补损。

**3）谈判时给对方可量化的方案**
例如：
- 档期：几月几日到几月几日
- 门店：全系统还是X家重点店
- 预估销量：平时日销多少，促销目标多少
- 采购量：预计进货多少箱/件
- 售价：原价多少，促销价多少，毛利缺口多少
- 资源：给端架/堆头/DM/社群/直播/试吃中的哪些
- 要求：搭赠比例、补差金额、费用承担方、结算方式

**4）常见可行支持形式（仅作谈判方向，不代表佳农一定提供）**
- 进货搭赠，如“进10箱赠1箱”
- 特价供价，限定档期和门店
- 促销补差，按实际销量返利
- 陈列费/堆头费/物料支持
- 损耗补贴或退换货支持

**5）建议你发的询问话术**
> 我们计划在X月X日—X月X日做香蕉促销，覆盖X家门店，预估进货X箱，目标日销从X提升到X。希望佳农支持以下一种或组合：搭赠、限时降供价、促销补差、陈列物料。请确认可支持形式、比例/金额、适用门店、档期、结算方式和申请截止时间。

**6）判断优先级**
香蕉是高频引流品，厂商通常更愿意给**有确定采购量、有陈列资源、能带来销量增量**的活动支持。你先拿到采购量和门店资源，再谈搭赠或补差，成功率更高。
