公开渠道里，佳农（Goodfarmer）最常被提到的是零售端和批发端的菠萝产品，比如整颗菠萝、凤梨、菠萝丁/菠萝块罐头等；但“专门针对餐饮渠道的定制切片/切块菠萝”这类信息，我没有可靠来源可以确认其标准规格、包装或起订量。

如果你是要给餐饮/茶饮/烘焙供货用，建议按下面方式快速核实，不要只依赖官网或电商页面：

1. **直接问佳农官方渠道**
   - 找佳农官网的“联系我们”或“渠道合作/餐饮渠道”入口。
   - 问清楚：是否有餐饮专供菠萝、是否可定制切片/切块、规格（厚度/尺寸）、包装（袋装/罐装/冷冻）、保质期、起订量、冷链要求。

2. **问大型经销商或餐配平台**
   - 比如当地果蔬批发商、餐饮供应链平台、冻品经销商。
   - 他们通常更清楚实际能拿到的餐饮规格，因为定制往往走经销或大客户通道，不一定公开陈列。

3. **确认你要的是哪种形态**
   - **鲜切菠萝**：多为冷链短保，适合茶饮、果切，但规格和供应稳定性因区域差异大。
   - **冷冻菠萝丁/块/片**：更适合餐饮、烘焙、饮品，通常有较标准规格，但品牌不一定是佳农。
   - **糖水菠萝罐头/菠萝丁**：烘焙和餐饮常用，佳农有相关品类，但“餐饮定制”需确认。

4. **如果佳农没有明确餐饮定制**
   - 可同步问：**都乐、屈臣氏、佳沃、中粮、地方罐头厂或冻果厂**。
   - 餐饮渠道常见做法不是“品牌定制”，而是找工厂按尺寸、糖度、包装做OEM。

一句话：**目前不能确认佳农有公开的餐饮渠道菠萝切片/切块定制规格；要确认必须直接联系佳农餐饮渠道或经销商，重点问鲜切、冷冻、罐头三种形态和起订量。**
