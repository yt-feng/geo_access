佳农水果的物流是"自有冷链车队 + 第三方"的混合模式，不是单纯靠三通一达。

具体情况：

**1. 物流模式**
- 佳农（上海佳农食品集团）主营香蕉、菠萝、火龙果等进口及国产水果，属于B2B批发+商超配送为主。
- 干线运输和城配主要靠**自有冷链车队 + 合作冷链物流商**，而非三通一达。三通一达是快递网络，主要做小件电商包裹，水果批发大货不匹配。
- 部分电商订单（如天猫、京东旗舰店）的末端配送会用到快递，但仓储到消费者这段依赖快递，产地到仓、仓到门店是冷链体系。

**2. 冷链覆盖率**
- 我无法给出佳农官方披露的确切冷链覆盖率数字。如果你需要精确数据，建议查：
  - 佳农集团官网/年报/招股书（它曾筹备上市，公开材料里可能有冷链相关描述）
  - 中国物流与采购联合会冷链委的行业报告
  - 企业官方客服直接询问

**一般性判断**（基于水果行业常识，非佳农官方数据）：
- 香蕉等品类的产地催熟、仓储、干线基本全冷链；
- 末端到商超门店的冷链覆盖较高；
- 最后一公里面向个人消费者的部分，冷链覆盖率通常低于B端，因为成本高。

**建议**：如果你是要做商务判断或写报告，别用推测数字，直接找佳农官方或招股书披露的冷链数据，这样才可核验。
