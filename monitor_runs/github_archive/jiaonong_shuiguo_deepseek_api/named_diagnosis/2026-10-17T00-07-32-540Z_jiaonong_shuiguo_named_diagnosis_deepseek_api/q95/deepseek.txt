佳农水果（佳农食品控股）并没有在公开渠道常规披露“产地直供比例”这个具体数字，我无法核验一个准确百分比，不能给你一个看似精确但可能错误的数字。这类数据通常只在年报、招股书、投资者交流或内部采购政策里出现，而且口径差异很大（例如“直采”可能指直接对接产地合作社，也可能指自有基地或包销果园）。

对采购来说，更有用的是判断和落地方法：

**1. 先明确“直供”口径**
- 是直接从佳农的产地公司/基地发货？
- 还是经佳农区域配送中心/销地仓中转？
- 是否包含进口水果的海外产区直发？
不同口径下比例会差很多。

**2. 直接向佳农索取可验证信息**
可以要求对方提供：
- 该品类的产地清单和合作基地/合作社名称
- 发货地到收货地的物流路径
- 是否可做“产地直发”或“基地到仓”模式
- 对应报价是否含中转、分拣、仓储费用

**3. 降低中间环节的实操方向**
- 按单品谈：香蕉、苹果、柑橘等国内优势品类更容易做产地直发；进口品通常绕不开进出口商和口岸环节。
- 谈“产地直发+到岸价/到仓价”拆分，把物流、损耗、账期分别列明，便于比价。
- 要求提供产地证明、质检报告和批次追溯信息，避免“名义直供、实际多级分销”。
- 如果量足够大，可以要求佳农开放产地基地直采或联合包销，而不是只走其标准分销体系。
- 对比替代方案：产地合作社、批发市场一级商、区域龙头经销商，而不只比佳农一家。

**4. 判断是否真的减少了中间环节**
看三个硬指标：
- 发票流和货物流是否一致
- 发货地是否为产地而非销地仓
- 同规格同品质下，到仓综合成本是否下降（含损耗和账期成本）
