佳农（佳农食品控股／Goodfarmer）主要做香蕉、菠萝、椰青、火龙果等水果的供应链和品牌分销，和商超合作通常是有陈列和促销支持的，但具体到“堆头+试吃+费用分担”，一般不是一口价公开政策，而是按单品、门店、档期、采购量单独谈。下面给你一个可执行的判断和谈法。

**能提供什么支持（常见方式）**

- **堆头陈列**：通常能给到堆头主题物料（围挡、跳跳卡、价签、海报），部分区域能给到陈列道具或地堆箱。是否额外付陈列费，看你是总部采购还是单店，以及他们的区域经销商政策。
- **试吃支持**：多数情况能提供试吃果、试吃台物料、一次性餐具、试吃员服装。但“试吃果”通常按档期和预估销量配比给，不是无限量。
- **人员支持**：大档期可能有促销员或督导巡店；日常多由门店员工执行，佳农给培训和物料。

**费用怎么分担（行业常见区间，供你谈判参考）**

费用分担一般分三块：陈列费、试吃物料/试吃果、促销人员。

- **堆头陈列费**：常见是供应商承担物料，商超承担位置；若商超收“陈列费/堆头费”，可能由供应商出，或按销售额扣点折算。也可以谈“以量换陈列”，比如承诺档期进货量，免收或减免陈列费。
- **试吃果和物料**：通常供应商出试吃果和物料，商超出场地和冰柜/操作台。试吃果比例常见按档期进货量的几个百分点配，或按门店每天固定份数配。
- **促销员**：供应商出人出费用居多；商超出工位和排班配合。若商超自己出人，可能要求供应商承担部分人工或按销量返点。
- **费用分担的常见结果**：供应商承担物料+试吃果+促销员，商超承担堆头位置和基础水电；或者双方各承担一半陈列/物料费，用销量返点找平。

**建议你这样去谈**

1. **先找对人**：佳农总部大客户部或你所在区域的经销商/代理商。单店直接找业务员往往权限有限。
2. **明确档期和量**：给出促销时间、参与门店数、预估进货量、堆头位置和面积。量越大，他们越愿意承担费用。
3. **把支持写成清单**：堆头物料数量、试吃果数量/频次、试吃台和餐具、促销员人数和时段、是否含冷链。
4. **费用分担用“三选一”谈**：
   - 方案A：供应商全包物料和试吃，商超免堆头费；
   - 方案B：商超收堆头费，供应商只出试吃果；
   - 方案C：双方各半，按档期销量返点找平。
5. **落到合同/确认单**：写清费用归属、物料到店时间、试吃果损耗承担、未达标是否补差。

**一句话结论**：佳农通常能给堆头陈列和试吃支持，但费用分担没有统一标准，取决于你的采购量、门店资源和谈判结果；常见是供应商出物料、试吃果和促销员，商超出位置，堆头费可谈减免或用销量返点抵扣。
