佳农（Goodfarmer）主要是水果品牌/供应商，很多消费者是通过电商平台（如天猫、京东、抖音、拼多多）或商超买到它的产品。因此“售后怎么样”通常取决于**你下单的渠道**，而不是佳农单方面统一处理。下面是可执行的判断和做法：

## 1）先看你从哪里买的
- **电商平台自营/旗舰店**：一般按平台规则走，坏果通常可申请“坏果包赔/退款/补发”，相对有保障。
- **第三方店铺/社区团购/直播间**：售后差异很大，有的包赔，有的只退部分，有的要求拍照举证。
- **线下商超**：通常拿小票和坏果去服务台，按超市退换货规则处理。

## 2）到货有坏果，建议这样处理
1. **先别急着扔**：把坏果、外箱、快递面单、订单信息放在一起拍照/录视频。
2. **拍清楚证据**：
   - 坏果切开或掰开的内部状态；
   - 坏果数量与整箱对比；
   - 包装箱上的批次/生产日期/物流单号。
3. **尽快申请售后**：多数平台要求签收后24–48小时内反馈，越早越好。
4. **选择诉求**：按坏果比例申请**部分退款、补发或整单退款**。如果是少量坏果，通常按比例赔；如果坏果多或整箱损坏，可要求补发/退款。
5. **保留沟通记录**：如果客服推诿，保存聊天记录，申请平台介入。

## 3）佳农这类水果的常见售后口径
水果属于生鲜，平台和商家通常会写“**坏果包赔**”，但一般有几个条件：
- 需在规定时间内申请；
- 需提供坏果照片/视频；
- 不 accept “口感不好、不甜、大小不符”作为坏果理由；
- 因物流延误导致的腐烂，通常也可赔，但要看是否在承诺时效内。

## 4）如果商家不处理
按这个顺序升级：
1. 找店铺客服 → 2. 申请平台官方客服介入 → 3. 如果是直播间/团购，找团长或平台 → 4. 金额大且拒不处理，可打12315投诉。

## 5）一句话建议
**先按购买渠道的规则申请“坏果包赔”，拍照留证、尽早提交；能补发就补发，不能补发就按坏果比例退款。**
