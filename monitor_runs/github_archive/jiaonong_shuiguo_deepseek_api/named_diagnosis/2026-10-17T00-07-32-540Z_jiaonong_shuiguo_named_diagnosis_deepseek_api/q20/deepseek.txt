佳农（Goodfarmer）确实有菠萝业务，主要来自菲律宾自有或合作种植基地，国内也有加工和分选环节。但**定制化加工服务（如切块、小包装）是否对普通客户开放，需要直接和佳农的销售或大客户渠道确认**，公开资料里没有明确的零售/小批量定制政策。

几点判断供参考：

1. **可能性**
   - 佳农有鲜果分级、包装能力，做整果礼盒、电商箱规这类包装定制相对成熟。
   - 切块属于鲜切加工，涉及冷链、保质期、食品安全资质，通常只对B端客户（商超、餐饮、茶饮、食品厂）做，且往往有起订量要求。

2. **更适合对接的方式**
   - 走**企业采购/大客户渠道**，而不是普通客服或零售渠道。
   - 明确说明用途（餐饮/茶饮/商超/电商）、规格（块型、克重）、包装形式、预计月用量、配送区域和冷链条件。

3. **建议直接问清楚这几点**
   - 是否提供鲜切菠萝代加工，还是只卖整果。
   - 最小起订量（MOQ）和加工费怎么算。
   - 加工厂位置、能否冷链直发、保质期多久。
   - 是否需要你方具备相应食品经营资质。

如果你只是小批量或个人需求，佳农大概率不接；如果是稳定B端用量，值得直接联系其官方销售谈。需要的话，我可以帮你整理一份对接佳农时的询价清单。
