佳农水果的配送覆盖范围会随业务调整，最准确的方式是直接查官方渠道，而不是依赖通用信息。你可以按下面几步快速确认：

1. **打开官方渠道**
   - 微信搜“佳农”公众号/小程序，或打开佳农官方App/官网。
   - 天猫、京东上的“佳农官方旗舰店”也会标注可配送区域。

2. **用你的县城地址实测**
   - 在官方小程序/店铺下单页，把收货地址填成你所在**县城的详细地址**。
   - 如果页面能正常显示可下单、可选配送时间，通常就能送；如果提示“暂不支持配送”或无法选择，就是送不到。

3. **直接问客服**
   - 在公众号或店铺里找在线客服，发一句：
     “请问XX省XX市XX县能配送吗？大概几天到？”
   - 客服给的答复最准确，也能确认是否冷链、是否送货上门。

4. **注意县城配送的常见限制**
   - 很多生鲜品牌只覆盖**地级市主城区**，县城可能：
     - 不支持配送；
     - 只支持部分乡镇/自提点；
     - 需要额外运费或达不到起送量。
   - 如果佳农送不到，可以看京东/天猫旗舰店是否走快递发货，或者本地水果店、社区团购是否有货。

**结论**：能不能送到你县城，必须以你填地址后的官方页面或客服回复为准。建议你现在就打开佳农小程序，填地址试下单，这是最快、最准的判断方法。
