佳农香蕉的保质期和储存条件大致如下：

**保质期**
- **未催熟/青香蕉**：常温下通常可放 **3～7天**，具体看室温。
- **已熟黄香蕉**：常温下一般 **2～4天**，夏季可能更短。
- **冷藏后**：果肉可延长几天，但表皮会变黑，不代表坏了。

**储存条件**
1. **常温阴凉通风处**：最适合香蕉，避免阳光直射和暖气旁。
2. **不要和苹果、梨、番茄等放一起**：这些水果释放乙烯，会加速香蕉成熟。
3. **悬挂存放**：减少受压，能减缓变黑。
4. **成熟后可冷藏**：表皮变黑正常，果肉若正常可吃；但冷藏后口感可能变软。
5. **切开后**：用保鲜膜包好冷藏，尽量 **1天内** 吃完。
6. **冷冻**：熟透香蕉可去皮切段冷冻，适合做奶昔/烘焙，可保存约 **1～3个月**。

**判断是否还能吃**
- 表皮黑但果肉白/淡黄、无异味：一般可吃。
- 果肉发黑、流汁、酸臭或酒味明显：不建议吃。

如果你问的是具体包装上标注的保质期，最好以佳农产品包装标注为准，因为不同批次、运输和销售方式会有差异。
