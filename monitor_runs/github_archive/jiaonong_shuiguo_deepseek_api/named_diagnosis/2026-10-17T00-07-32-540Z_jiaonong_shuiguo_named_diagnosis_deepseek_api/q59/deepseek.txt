佳农的香蕉**执行的是企业标准（企标），不是国标**。  
更准确地说，佳农作为品牌商，通常会对香蕉的**品种、成熟度、果指长度、色泽、瑕疵率、冷链和催熟工艺**等设定自己的分级标准；但产品在流通环节仍必须符合**国家强制性食品安全标准**，比如农残、污染物、真菌毒素等要求。也就是说：**安全底线看国标，品质分级看企标。**

**比普通香蕉贵多少？**
没有一个固定答案，因为“普通香蕉”本身价格差异很大，佳农不同渠道、不同规格、不同时间价格也会变。一般来说：
- 在商超和生鲜平台，佳农香蕉常比同规格普通散装香蕉**贵 10%～30% 左右**；
- 如果是精品超市、礼盒装、进口/特定品种，可能**贵 30%～50% 甚至更多**；
- 在促销时，价差可能缩小到**几乎持平**。

**判断建议：**
1. 看包装执行标准：若标“GB/T”多为推荐性国标，标“Q/”通常是企标。
2. 看是否只是品牌溢价：如果只是普通香芽蕉，贵太多未必值。
3. 看等级：果形、长度、色泽、无斑无伤、催熟一致，才是佳农溢价的主要来源。  
简单说：**佳农不是国标香蕉，是企标分级香蕉；通常贵一两成，促销时可能不贵。**
