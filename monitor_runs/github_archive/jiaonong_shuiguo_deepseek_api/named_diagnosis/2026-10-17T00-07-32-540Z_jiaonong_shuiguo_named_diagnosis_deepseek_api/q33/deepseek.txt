## 1. 先分清“企业标准”指什么

香蕉这类鲜果通常涉及几类标准，不一定是同一个：

- **国家标准**：如香蕉相关的鲜果质量、等级、检验、贮运标准（常见是 GB/T 或 NY/T 体系）。
- **行业标准**：农业、供销、商务等行业标准。
- **企业标准**：佳农如果自行制定并在企业标准信息公共服务平台备案，会有 Q/ 开头标准号。
- **采购/客户标准**：商超、电商、进出口客户要求的验收标准，可能比国标更细，但不一定叫“企业标准”。

所以“佳农香蕉企业标准”可能指：
1. 佳农备案的企业标准；
2. 佳农内部质量控制文件；
3. 佳农对供应商的采购验收标准。

这三者不是一回事。

## 2. 是否比国标高，不能一概而论

企业标准**可以**高于国标，尤其是外观、规格、成熟度、农残控制、冷链、到货合格率等指标。常见情况是：

- **可能更严的方面**：
  - 果指长度、粗细、弯度、色泽、瑕疵率；
  - 青蕉/黄蕉成熟度、催熟一致性；
  - 农残和重金属内控限值；
  - 冷链温度、运输时限、到货硬度/糖度；
  - 批次抽检频率和追溯要求。
- **不一定更严的方面**：
  - 食品安全基础指标通常必须符合国标，不能低于强制国标；
  - 有些企业标准只是把国标换一种写法，或侧重商业分级，不等于全面高于国标。

因此，正确说法是：**佳农香蕉的企业/采购标准在某些商业品质和供应链指标上可能高于国标，但是否整体高于国标，必须看具体标准号和条款。**

## 3. 你可以这样核验

1. 在**企业标准信息公共服务平台**搜索“佳农”或“佳农食品”，看是否有香蕉相关 Q/ 标准。
2. 向佳农客服/业务索要：
   - 标准编号；
   - 适用范围；
   - 感官、理化、安全、贮运指标；
   - 与 GB/NY 标准的对照表。
3. 对比时重点看：
   - 是不是**强制性国标**：如果是，企业标准不能低于；
   - 是不是**推荐性国标/行标**：企业标准可以更严，也可以只做商业分级；
   - 检测方法和抽样规则是否一致，否则数字不可直接比。
4. 如果是商超采购标准，直接查该商超的香蕉验收规范，往往比佳农企业标准更实际。
