给你一个可执行的确认路径：

**1. 先确认佳农是否有“冷冻菠萝丁”这个品类**
- 佳农公开产品里更常见的是**鲜菠萝、菠萝罐头、冷冻水果/冷冻果块**等方向。
- 是否能提供**冷冻菠萝丁**，要以佳农官方渠道或当地经销商报价单为准。
- 建议直接问：  
  “你们有没有**速冻菠萝丁/冷冻菠萝丁**？是**IQF单体速冻**还是整块冷冻后切丁？原料是**鲜果切丁速冻**还是**糖水菠萝丁**？”

**2. 茶饮店常用规格，重点问这几个**
即使佳农有货，不同渠道规格也可能不同，采购时要问清：
- **丁的大小**：常见有 **5×5×5mm、8×8×8mm、10×10×10mm**，也有不规则小丁。
- **包装规格**：常见 **1kg/袋、2kg/袋、5kg/袋、10kg/箱**，餐饮渠道常见是 **1kg×10袋/箱** 或 **2kg×5袋/箱**。
- **是否含糖/糖水**：茶饮店通常优先选**无糖速冻菠萝丁**，避免影响配方糖度。
- **状态**：IQF速冻、冻块、糖水罐头丁，使用和解冻后口感差别很大。
- **固形物/净含量**：如果是糖水型，要问固形物含量。
- **产地/品种**：如菲律宾、泰国、哥斯达黎加等，不同产地酸甜度和纤维感不同。

**3. 直接这样联系最快**
- 找**佳农官方客服/官网/公众号**，问当地餐饮渠道经销商。
- 或让供应商发：**产品规格书、配料表、包装图、检测报告、报价单**。
- 样品一定要试：  
  **解冻后是否出水、是否软烂、酸甜度、纤维感、是否适合做水果茶/奶茶小料**。

**4. 如果佳农没有合适冷冻丁，替代方向**
茶饮店用菠萝丁，通常还会看这些供应商类型：
- 专业**冷冻水果/IQF水果**厂家
- 果蔬加工厂
- 餐饮供应链平台
- 罐头菠萝丁厂家
