茶饮店大量用菠萝，通常看这几类规格：

1. **品种/产地**
   - 常见：菲律宾菠萝、泰国小菠萝、国产徐闻/海南菠萝等。
   - 佳农较常见的是菲律宾菠萝类产品，但不同批次、渠道会有差异，先确认具体品种和产地。

2. **形态规格**
   - **整果**：按个头、单果重、箱规卖。
   - **去皮整果/半果**：冷藏或冷冻，适合门店再切。
   - **菠萝丁/菠萝块**：冷冻或糖水罐头，最适合茶饮稳定出品。
   - **菠萝果泥/果酱/浓缩汁**：用于调饮，不是鲜果口感。
   - **冷冻菠萝片/串**：装饰或直接入杯。

3. **关键验收指标**
   - 单果重范围，比如 1.0–1.2kg、1.2–1.5kg。
   - 每箱净重、箱规，比如 10kg/箱、12kg/箱。
   - 果肉色泽、成熟度、酸甜度、纤维感。
   - 是否有黑心、烂心、冻伤、异味。
   - 冷冻品要看是否结块、解冻后出水率。
   - 罐头/糖水品要看固形物含量、糖度、pH。

4. **供应稳定性**
   - 佳农属于大型果蔬供应链企业，普通商家通常可以通过其经销渠道、批发市场档口、生鲜B2B平台或区域代理拿到货。
   - 但“稳定供应”取决于你所在城市、采购量、是否走冷链、是否签年度框架。
   - 小店少量拿货，往往不是直接找佳农总部，而是通过当地经销商/批发商。

5. **给茶饮店的实操建议**
   - 先要样品：整果、冷冻丁、果泥各拿一份做杯测。
   - 明确写进采购单：品种、产地、形态、单果重/固形物、箱规、冷链温度、验收标准。
   - 不要只问“有没有佳农菠萝”，要问：
     - 是鲜果还是冷冻？
     - 是整果还是去皮切块？
     - 单箱多少kg、几个果？
     - 糖度大概多少？
     - 能不能每周稳定送几次？
     - 坏果率怎么赔？
   - 如果门店出品要标准化，优先考虑**冷冻菠萝丁/果泥/糖水菠萝罐头**，比鲜果更容易稳定。

一句话：佳农能供应，普通商家也听得懂规格，但你必须把“品种、形态、重量、箱规、糖度、冷链、验收和赔付”写清楚，否则“稳定供应”只是口头承诺。
