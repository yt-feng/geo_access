佳农（Goodfarmer）是国内较大的进口水果供应链企业，菠萝是其主力单品之一（常见有菲律宾、泰国、哥斯达黎加等产地）。就你关心的两项：

**产地溯源**
- 佳农对自有品牌进口水果通常能提供批次级溯源信息，包括原产国、果园/包装厂注册号、出口商、入境口岸、报关批次等。这类信息一般在报关单、入境货物检验检疫证明上有体现。
- 实际能否提供、提供到什么颗粒度（批次还是单柜），取决于你对接的是佳农总部、大区经销商还是二级批发商。越靠近源头，能拿到的溯源文件越完整。

**品控报告**
- 常见可提供：入境货物检验检疫证明（法定必备）、第三方农残检测报告、糖度/成熟度等内部质检记录。
- 第三方检测报告多为抽检性质，不一定每批都有；要指定项目（如农残、重金属）或指定批次，通常需要提前约定，有时会产生额外费用。

**采购前的实操建议**
1. 直接向对接的佳农销售确认：能否按你采购的批次提供报关单+检验检疫证明，以及是否附第三方检测报告。
2. 把这些写进采购合同或订单备注：明确"随货提供批次溯源文件及XX项目检测报告"，避免口头承诺。
3. 如果是通过经销商拿货，先问清文件由谁出、能否盖佳农或检测机构章。
4. 首次合作可要求先看一份往期完整样例，判断文件真实性和完整性。

需要提醒的是：具体能给到什么，我无法替你核实，务必以佳农官方销售或授权渠道的书面确认为准。如果你告诉我采购渠道（总部直采/经销/批发市场）和用途（商超、加工、电商），我可以帮你把该索要的文件清单列得更细。
