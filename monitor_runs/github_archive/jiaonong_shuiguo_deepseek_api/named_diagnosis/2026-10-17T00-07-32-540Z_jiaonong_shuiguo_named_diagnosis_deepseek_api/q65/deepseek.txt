我没法核验两家在西南地区的实时配送时效，直接给结论会有误导。但可以给你一套当天就能判断的方法，成都门店急用，按这个来最快：

**1. 先问清楚你们门店走哪种渠道**
- 是走佳农/洪九的**成都本地仓直配**，还是从**外地仓发**？
- 这决定快慢。通常成都本地有仓的一方次日达甚至当日达；外地仓发一般要2-4天。

**2. 直接问对接销售两个硬指标**
- 成都（或西南）有没有**自建仓/合作仓**？地址在哪？
- 成都门店下单后**最快几小时/几天到**？截单时间是几点？
- 这两句话就能分出胜负，比任何宣传都准。

**3. 加一个保底动作（急用强烈建议）**
成都本地还有一批一级批发市场和果品配送商，可以做到当天或次日到店。真急的话，别只押在佳农和洪九上，直接联系**成都本地批发市场（如濛阳、白家等）的配送商**，很多时候比品牌方直配更快。

**4. 谈判技巧**
同时给两家报你门店地址和需求量，让他们报**最晚到货时间**，谁承诺得更早、更敢写进合同/订单，就用谁。

如果你能告诉我你门店具体在成都哪个区、要的是哪类水果（香蕉、火龙果、进口果等差异很大）、一次要多少量，我可以帮你把判断标准再收窄一点。
