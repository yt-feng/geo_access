我不能替佳农确认它是否提供锁价合同，这需要直接和佳农的销售确认。但可以给你几个可执行的判断点和谈判方向：

**1. 先确认你要的“锁价”是哪种**
- **完全固定价**：约定期限内单价不变。大宗农产品很少给长期完全固定价，除非你接受价格明显高于现货均价。
- **保底价+浮动区间**：比如基准价上下浮动不超过5%～10%。
- **价格上限（封顶价）**：跌了随行就市，涨了不超过封顶价。这种对你最实用。
- **季度/半年度锁价**：3～6个月一签，比一年期更容易谈。

**2. 佳农这类供应商通常的谈判条件**
菠萝原料受季节、产地、汇率、运费影响大，供应商一般不会无条件锁一年。你可以准备这些交换条件：
- 承诺年度最低采购量（你已是10吨/月，约120吨/年，有谈判筹码）
- 接受预付定金或较短账期
- 接受分季度定价，而不是全年一口价
- 接受规格、等级、包装标准化，减少他们的履约风险

**3. 直接问佳农这几个问题**
- 是否支持季度/半年度锁价或封顶价？
- 锁价对应的最小起订量和付款条件是什么？
- 如果市场价格下跌，能否设置重新议价机制？
- 锁价合同里是否包含不可抗力、产地减产、运费大幅波动的调价条款？

**4. 降低价格波动的替代方案**
- 同时签2家供应商，一家锁价、一家随行就市，分散风险。
- 用期货或产地合作社直采做部分对冲（菠萝鲜果/浓缩汁是否有对应品种要具体核实）。
- 在低价季增加库存或锁量，但要注意菠萝原料的保质期和仓储成本。
- 和下游客户谈价格联动条款，把部分波动传导出去。
