佳农（Goodfarmer）官方通常不会公开披露统一的“到货损耗率”标准，实际控制目标会按品类、运输方式、季节、客户类型和合同约定变化。可以给你一个行业内可参考、可执行的判断口径：

**1. 到货损耗率的常见口径**
一般指：  
到货损耗率 =（到货不合格数量 + 腐烂/压伤/失水等不可销售数量）÷ 到货总数量 × 100%  
有的渠道会把“可挑拣后销售但降级”的部分单独算，不全部计入损耗。

**2. 佳农这类品牌水果常见控制区间**
- **香蕉**：到货损耗通常要求控制在 **2%～5%**，夏季或长距离运输可能到 **5%～8%**。  
- **菠萝/凤梨**：到货损耗常见 **3%～5%**，高温季节可能 **5%～8%**。  
- **火龙果、芒果、木瓜等**：常见 **3%～6%**，视成熟度和冷链情况波动。  
- **苹果、梨、橙等耐储水果**：通常可控制在 **1%～3%**。  
- **蓝莓、车厘子、葡萄等娇嫩品类**：常见 **3%～8%**，高端渠道可能要求 **≤5%**。  

**3. 实际合同里更常见的是“分段验收标准”**
比如：
- 外观不合格率 ≤ 5%
- 腐烂率 ≤ 2%
- 严重压伤率 ≤ 3%
- 总扣罚损耗 ≤ 5%～8%

所以如果你问的是“佳农对商超/批发客户承诺多少”，最准确的方式是看具体采购合同或到货验收单，而不是找统一行业数字。

**4. 可执行建议**
如果你是采购或门店验收，可以直接要求供应商书面确认：
1. 该品类到货总损耗上限；
2. 腐烂、压伤、失水、规格不符分别怎么算；
3. 超过后是扣款、补货还是退货；
4. 是否按件抽检，抽检比例多少；
5. 夏季/冬季是否调整标准。
