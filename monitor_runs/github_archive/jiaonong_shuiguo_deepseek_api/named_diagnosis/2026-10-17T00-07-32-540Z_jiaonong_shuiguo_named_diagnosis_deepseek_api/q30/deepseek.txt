我无法给出“佳农水果香蕉”在市场上抽检合格率的具体数字，因为这类数据通常由各地市场监管部门按批次发布，公开渠道里不会形成一个统一、实时更新的“品牌合格率”。如果直接给一个百分比，很容易是编造或过时信息。

可以明确的是：

1. **香蕉这类水果的农残抽检合格率通常较高**
   各地市场监管部门对水果的监督抽检中，香蕉的合格率一般处在较高水平，但也确实出现过个别批次因农药残留（如吡虫啉、噻虫嗪等）不合格的通报。

2. **“佳农”作为品牌，并不等于每批货都来自同一产地**
   佳农的香蕉多来自菲律宾、厄瓜多尔、越南等进口产地，也有国内分选加工。不同产地、不同批次、不同季节，抽检结果会不一样。因此用“品牌”去概括合格率并不严谨。

3. **要查具体抽检结果，可以这样做**
   - 去**国家市场监督管理总局**“食品安全抽检监测”栏目，或“抽检结果公示”中按关键词搜“香蕉”+企业名称；
   - 去**各省/市市场监管局官网**搜“食品安全监督抽检信息通告”，再筛“香蕉”和“佳农”；
   - 在“全国12315平台”或地方“你点我检”活动中查询相关批次。

4. **如果你是要做采购或判断风险**
   建议不要只看品牌，而要看：
   - 该批次是否有**入境货物检验检疫证明**（进口香蕉）；
   - 是否有**农残检测报告**；
   - 到货后自己用快检或委托检测，重点看吡虫啉、噻虫嗪、多菌灵、咪鲜胺等香蕉常用农药。
