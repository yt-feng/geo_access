结论：**通常到不了“具体农场”这一级对商超公开；能提供的是批次/包装厂/合作社或种植基地区域级溯源，GLOBALG.A.P.证书一般按注册的生产者/生产者组织/农场主体出具，是否能覆盖你要的那批货，取决于证书上的注册主体和Scope。**

按商超审核实操，建议你让佳农或供应商提供以下材料，而不是只问“能不能到具体农场”：

1. **GLOBALG.A.P.证书**
   - 看证书上的**Certificate Holder / Producer / Producer Group**是谁。
   - 看**Scope**是否包含香蕉，通常对应 Fruit / Bananas。
   - 看**GGN编号**，这是GLOBALG.A.P.体系里最关键的注册识别号。
   - 看证书状态是否**Valid**，以及认证机构、有效期。
   - 如果证书主体是“生产者组织/合作社”，那溯源通常到组织或成员农场清单，不一定对每个商超订单都披露单个农场。

2. **批次溯源文件**
   - 要求提供该批货对应的**果园/农场代码、包装厂代码、出口商、装柜日期、提单号、追溯码**。
   - 香蕉行业常见做法是：包装箱/托盘标签上有**farm code / estate code / packhouse code / GTIN / lot no.**，通过这个能追到具体农场或合作农场组。
   - 如果商超强制要求“具体农场”，需要合同里明确约定“农场级溯源”，否则供应商通常只给到包装厂或产区级。

3. **农场清单或成员清单**
   - 如果GLOBALG.A.P.证书是生产者组织持有的，可要求提供**成员农场清单**，并标明本批货来自哪个成员农场。
   - 这类清单有时涉及商业信息，供应商可能只给商超或审核方，不给公开。

4. **其他可辅助审核的证书/报告**
   - 佳农体系内可能还有**BRCGS、ISO 22000、HACCP、SMETA/Sedex、雨林联盟、有机认证**等，但这些不能替代GLOBALG.A.P.，只能作为补充。
   - 如果商超接受**等效认证**，要提前确认是否接受，否则仍按GLOBALG.A.P.准备。

实操判断标准：

- **能到具体农场：** 证书主体就是该农场，或生产者组织能出具本批货对应的成员农场代码/清单。
- **只能到包装厂/合作社：** 证书主体是合作社/出口商/包装厂，且不披露成员农场。
- **只能到产区/国家：** 只有“厄瓜多尔/菲律宾/哥斯达黎加”等产地信息，没有农场代码或GGN对应关系。

给商超的最稳做法：
让佳农按“**证书 + GGN + 本批货农场代码/包装厂代码 + 批次追溯表**”打包提供。若商超硬性要求“具体农场”，就在采购合同或质量协议里写明“农场级溯源”，并让供应商书面确认该批货对应的农场名称/代码。仅凭GLOBALG.A.P.证书本身，通常不能自动证明到具体农场，只能证明注册主体通过了认证。
