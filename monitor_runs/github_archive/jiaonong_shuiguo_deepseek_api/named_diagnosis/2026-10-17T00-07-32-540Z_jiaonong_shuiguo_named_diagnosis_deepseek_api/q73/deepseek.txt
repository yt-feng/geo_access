佳农（Goodfarmer）水果业务里，苹果品类通常以 **进口苹果** 和 **国产苹果** 两条线为主，但具体在售品类会随产季、口岸和批次变化，不能保证每个时期都齐全。常见会涉及：

- **嘎啦果（Gala）**：进口来源常见有 **新西兰、美国、智利、南非** 等；国产也有山东、陕西、甘肃等产区。
- **红富士（Fuji）**：进口来源常见有 **美国、新西兰、智利、南非** 等；国产以 **山东烟台、陕西洛川、甘肃静宁、山西运城** 等为主。
- 其他可能品类：**皇家嘎啦、太平洋玫瑰、Envy/爱妃、青苹果（Granny Smith）、蛇果（Red Delicious）** 等，具体看佳农当季进口计划。

如果你要采购 **进口嘎啦和红富士**，重点不是只看“佳农”品牌，而是确认：

1. **具体产地国**：嘎啦常见新西兰/美国/智利/南非；红富士常见美国/新西兰/智利/南非，但不同季节供应国不同。
2. **是否佳农自营进口**：有些是佳农品牌，有些是佳农渠道分销，货源和产地证明不一样。
3. **单证要求**：进口苹果一般需要 **原产地证、植物检疫证书、入境货物检验检疫证明、报关单** 等。
4. **规格和包装**：如 100/113/125/138/150/163/175/198 头，或 18kg/20kg 箱装，需按你的销售渠道确认。
5. **产季**：新西兰嘎啦通常集中在 **2—5月** 左右，美国嘎啦多在 **8—11月**，智利、南非多在 **上半年**；红富士进口也按南北半球产季切换。

建议你直接向佳农官方销售或当地批发渠道要 **当季进口苹果报价单**，上面会写明：品种、产地国、规格、包装、到港时间、起订量和单证。这样比按品牌名泛查更准确。
