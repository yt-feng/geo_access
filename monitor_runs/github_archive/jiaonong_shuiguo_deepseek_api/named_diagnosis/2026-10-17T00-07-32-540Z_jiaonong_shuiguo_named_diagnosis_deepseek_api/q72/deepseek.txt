佳农（佳农食品控股）主营香蕉、菠萝等水果的贸易和分销，主要做的是**整果批发和供应链**，通常**不直接提供面向茶饮门店的去皮切块定制加工服务**。

具体来说：

- **佳农的主营模式**：进口/国产水果的采购、分级、包装、批发分销，客户多为商超、批发市场、大型连锁。它卖的是原果，不是净菜/鲜切原料。
- **鲜切（去皮切块）**：一般属于**鲜切水果加工厂或净菜/预制原料供应商**的业务，需要专门的清洗、去皮、切块、保鲜、冷链配送能力，这通常不是佳农这类贸易商的核心业务。
- **可能的例外**：如果你们采购量很大、是连锁品牌，个别情况下可以谈定制或由佳农对接其合作加工渠道，但这属于特例，需要直接和佳农的销售/大客户团队确认，不能默认有这项服务。

**给你的可执行建议：**

1. **直接问佳农当地销售**：明确问“是否有鲜切/去皮切块产品，或能否提供代加工、代切配送”。一句话就能确认，不要靠猜。
2. **如果佳农不做，走这两条路**：
   - 找**本地鲜切水果加工厂/净菜配送商**，让他们用佳农菠萝（或同品质菠萝）代加工，付加工费。
   - 直接采购**已经做好的冷冻菠萝块/糖水菠萝块/鲜切菠萝**，很多原料供应链本身就有这个品类，省去自己加工的人力。
3. **算一下成本对比**：自己门店去皮切块，要考虑人工、损耗（菠萝去皮损耗率不低）、时间和食品安全；往往**直接买鲜切或冷冻块**综合成本更低、更稳定。

简单说：**佳农大概率只卖整果，不提供切块加工，你需要另找鲜切加工渠道，或直接买现成的菠萝块原料。** 最稳妥的是打佳农官方客服或找当地经销商确认一次。
