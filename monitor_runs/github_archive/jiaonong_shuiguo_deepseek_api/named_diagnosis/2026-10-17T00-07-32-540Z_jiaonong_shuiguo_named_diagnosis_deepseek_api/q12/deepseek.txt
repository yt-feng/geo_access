佳农水果的香蕉规格会因**品类（国产蕉/进口蕉）、包装形式、销售渠道和批次**而不同，且其分级标准属于企业内部/行业通行规则，公开资料里通常不会给出固定不变的全规格表。可以给你一个可执行的判断框架，实际采购时以佳农当批次报价单、装箱单和质检单为准。

## 一、常见的规格划分方式

佳农香蕉通常按以下几类维度分规格：

1. **按重量/箱规**
   - 常见有：4.5kg、5kg、7kg、10kg、12kg、13kg、15kg、18kg、20kg 等箱规。
   - 进口蕉常见以整箱计，国产蕉常见按斤/公斤或整箱计。
   - 不同季节、产地、港口到货批次会有差异。

2. **按根数/把数**
   - 常见按“每箱几把、每把几根”标注，例如 4-6 把/箱、5-7 根/把等。
   - 商超更关注把型整齐、根数稳定；批发渠道更关注总重和单根粗度。

3. **按单根重量/粗度**
   - 常用“条重”“单根克重”“果指粗度”区分。
   - 例如大果、中果、小果，或按每根多少克划分等级。
   - 单根越重、果指越粗，通常等级越高，但也要看成熟度和外观。

4. **按成熟度/颜色**
   - 常见分为：青蕉、微黄、黄熟、全熟等。
   - 不同渠道对到货成熟度要求不同：批发可收青一点，商超和即时零售更偏黄熟或可控催熟。

5. **按外观等级**
   - 通常看：果指长度、粗细、弯曲度、整齐度、表皮瑕疵、机械伤、黑斑、药害、冷害等。
   - 行业里常分特级、一级、二级，但各企业命名不完全统一。

## 二、适合不同渠道的分级标准建议

下面是按渠道需求的实用分级逻辑，不是佳农官方固定标准，但可用于采购判断：

| 渠道 | 核心要求 | 建议规格/等级 |
|---|---|---|
| 高端商超/精品超市 | 外观整齐、大小均匀、卖相好 | 一级或特级；单根较重、果指粗长；把型整齐；成熟度可控；瑕疵少 |
| 普通商超/社区超市 | 性价比与卖相平衡 | 一级/二级；中等箱规；根数稳定；允许轻微表皮瑕疵 |
| 水果连锁/即时零售 | 周转快、成熟度合适、损耗低 | 黄熟或微黄；单根适中；小箱规或中等箱规；到货即可上架 |
| 批发市场 | 总重足、价格敏感、耐运输 | 二级或统货；青蕉或微黄；大箱规；对整齐度要求相对低 |
| 餐饮/茶饮/烘焙 | 出肉率、风味稳定、成本可控 | 按果肉率选；中果或大果；成熟度稳定；不强调外观 |
| 电商/社区团购 | 耐配送、规格统一、售后少 | 中小果；较青或微黄；抗压包装；单根重量均匀 |
| 加工厂 | 成本优先、可接受外观瑕疵 | 统货或二级；成熟度一致；无严重腐烂、冷害 |

## 三、采购时最该确认的 6 个字段

不管你面对的是佳农还是其他品牌，询价时直接问这 6 项，基本不会被规格绕进去：

1. **产地/品类**：国产蕉、菲律宾蕉、厄瓜多尔蕉等。
2. **箱规/净重**：毛重多少、净重多少、是否含箱。
3. **根数/把数**：每箱几把、每把几根、单根大约多少克。
4. **等级**：特级/一级/二级/统货，具体判定标准是什么。
5. **成熟度**：青蕉、微黄、黄熟，到货颜色和催熟要求。
6. **允许瑕疵率**：黑斑、机械伤、断指、冷害、腐烂比例的上限。

## 四、结论

佳农香蕉没有一份对外固定不变的“全规格表”。实际常见规格会按**箱规、根数/把数、单根重量、成熟度、外观等级**组合划分。  
不同渠道的核心分级逻辑是：

- **高端商超**：重外观和均匀度，选特级/一级。
- **普通商超和即时零售**：重成熟度和周转，选一级/二级、黄熟或微黄。
- **批发和加工**：重成本和耐储运，选二级/统货、青蕉或微黄。
- **餐饮茶饮**：重出肉率和风味稳定，选成熟度稳定的中果/大果。

如果你是实际采购，建议直接向佳农业务员索取**当批次规格书、质检报告和装箱单**，因为同一品牌不同产季、不同产地的规格都会调整。
