你可以用下面方式快速确认：

1. **看官方渠道**
   - 佳农官网、官方微信公众号、官方小程序、天猫/京东旗舰店首页
   - 重点找：客服服务时间、发货时间、周末及节假日发货说明

2. **直接问在线客服**
   - 发送：“请问客服是7×24小时吗？”
   - 再问：“周末下单会当天处理吗？还是顺延到工作日？”
   - 如果是生鲜类，还要问：“周末是否正常发货？冷链配送是否受影响？”

3. **下单前看商品页和结算页**
   - 很多店铺会在商品详情、运费说明、发货时效里写明：
     - 是否周末发货
     - 是否节假日顺延
     - 下单后多久处理
     - 生鲜品类是否支持指定日期

4. **电话确认**
   - 如果有官方客服电话，工作日拨打通常最稳。
   - 但具体号码和值班时间我无法核验，建议以官方页面显示为准。

**一般经验判断：**
- 大型生鲜品牌客服常见是**工作时间在线+部分渠道机器人24小时接待**，不一定真人7×24。
- 周末下单**可能能下单成功**，但处理速度常取决于仓库、店铺和配送商，有些会顺延到工作日。
- 生鲜水果受冷链和发货时效影响，周末安排通常比普通商品更谨慎。
