目前我没有查到“佳农水果香蕉进口量全国第一”这一排名由哪个机构发布、是否有证书的可靠公开信息，无法给你一个可核验的机构名称或证书结论。

可以这样判断和查证：

1. **企业宣传里的“全国第一”**  
   很多是来自企业新闻稿、行业峰会、协会颁奖或第三方咨询报告，表述可能是“进口香蕉量”“香蕉进口额”“某品类进口量”等，口径不同，结论也可能不同。

2. **可能涉及的发布方类型**
   - 海关总署及各地海关：通常发布的是进出口统计数据，不直接发布“某企业全国第一”的排名证书。
   - 中国食品土畜进出口商会、中国果品流通协会等行业协会：可能发布行业排名或奖项，但需要看具体年份、品类和统计口径。
   - 第三方咨询/数据机构：可能出具市场地位声明或证明，但权威性取决于机构资质和统计方法。
   - 企业自行发布：可能引用内部数据或海关数据整理，不一定有“证书”。

3. **是否有证书**
   如果有，通常是协会、展会、咨询机构或评选活动颁发的“市场地位证明”“行业排名证书”之类，不等同于海关官方认证。需要看证书上的：
   - 颁发机构
   - 统计年度
   - 统计口径，比如香蕉进口量、进口额、自营进口还是代理进口
   - 数据来源
   - 是否可公开验证

4. **建议直接核验的渠道**
   - 佳农官方渠道：官网、年报、新闻稿、品牌介绍页，看它自己写的“第一”依据是什么。
   - 颁发机构官网或公开报道：查是否有对应排名、公示或证书照片。
   - 海关总署/海关统计平台：查香蕉进口总量数据，但一般查不到“企业排名证书”。
   - 中国食品土畜进出口商会、中国果品流通协会等：查是否有相关行业排名发布。

如果你是要用于宣传、投标或合规审核，不能只凭“全国第一”这句话，建议要求对方提供**证书原件或复印件、数据来源、统计年度和口径说明**，再判断是否可用。
