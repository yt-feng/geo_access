佳农（佳农食品控股）主要做香蕉、菠萝等水果的贸易和分销，通常以**整果或初级分选/包装**形式供货，一般**不提供面向茶饮店的去皮切块定制加工服务**。原因和可行路径如下：

- **佳农的常规供货形态**：整颗菠萝、按规格分级的鲜果，部分渠道会有去皮菠萝（鲜切果）或冷冻菠萝块，但这属于特定 SKU，不一定覆盖你所在区域，也不是按你的门店需求现切。
- **鲜切水果的合规门槛**：即使有“鲜切菠萝”，也需要具备即食鲜切资质、冷链配送能力，不是普通水果批发能顺带做的。
- **更现实的做法**：
  1. **问当地佳农经销商/大区销售**：直接确认是否有“鲜切菠萝”或“冷冻菠萝块”SKU，以及最小起订量、配送温层。
  2. **找第三方鲜切工厂/中央厨房**：采购佳农整果，委托有即食鲜切资质的工厂按你的规格切块，冷链配送到店。
  3. **门店自行加工**：如果用量不大，买整果自己去皮切块，成本最低，但要控制损耗和人员工时。
  4. **考虑冷冻菠萝块**：茶饮用冷冻果块很常见，出品稳定、损耗低，但风味和鲜果有差异，需先做杯测。

**建议你先做一件事**：联系你所在区域的佳农销售，直接问“有没有鲜切菠萝或冷冻菠萝块 SKU、能否配送到店、起订量多少”。如果对方只供整果，就转向本地鲜切工厂代加工，或门店自切。
