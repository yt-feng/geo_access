佳农和盒马的合作，公开层面没有一个被双方正式确认的单一“直供”或“代销”标签，所以不能把它简单归为一类。比较接近实际情况的描述是：**以直供为主、混合多种条款的供应链合作**，具体到不同品类、不同批次、不同年份，结算和风险承担方式可能不一样。

可以这样拆开看：

- **直供特征**：佳农作为品牌方/产地供应商，直接向盒马供货，盒马负责终端零售。佳农承担种植、加工、品控、品牌和部分损耗；盒马承担门店/线上流量、履约和消费者服务。
- **代销/联营特征**：部分生鲜品类可能采用“账期结算+返点”“保底+分成”“联营扣点”等方式，滞销、损耗、退换货的责任在合同里另谈，不完全等同于买断。
- **实际合同通常比概念复杂**：比如有账期、有返利、有促销费用分摊、有损耗率约定、有最低采购量或保底销量。这些条款叠加后，既不像纯直供买断，也不像纯代销。

**你们超市能不能参考？能，但不要照搬，要按自己的规模改。**

可执行的参考路径：

1. **先判断你们适合哪种**
   - 如果你们门店少、现金流紧、怕压货：优先试“代销/联营扣点”，让供应商承担部分损耗。
   - 如果你们有稳定销量、想拿更低进价和独家资源：谈“直供买断”，但要能承受损耗和账期。
   - 如果介于两者之间：用“保底采购+超额返利”或“直供+部分联营”混合模式。

2. **谈判时重点锁定这6项**
   - 结算方式：买断、代销还是联营扣点
   - 账期：现结、7天、15天、30天还是更长
   - 损耗归属：谁承担，比例多少，怎么认定
   - 退换货：临期、破损、滞销能不能退
   - 价格保护：供应商降价时，你们库存怎么补差
   - 费用分摊：进场费、促销费、堆头费、损耗补贴谁出

3. **小范围试跑**
   - 先选1到2个高周转水果单品，跑1到2个月。
   - 记录毛利率、损耗率、周转天数、退货率。
   - 用数据决定是扩大直供，还是转回联营/代销。

4. **注意你们和盒马的差异**
   - 盒马有强流量、强履约、强数据能力，能压供应商接受复杂条款。
   - 中小超市如果没有同等采购量，直接谈“盒马同款条款”很难。
   - 更现实的做法是：先争取区域经销商或产地合作社的直供，再逐步往品牌直供走。

简单结论：**佳农和盒马不是纯直供，也不是纯代销，而是直供为主的混合模式。你们超市可以参考，但核心不是抄模式名称，而是把结算、损耗、账期、退换货这四件事谈清楚。**
