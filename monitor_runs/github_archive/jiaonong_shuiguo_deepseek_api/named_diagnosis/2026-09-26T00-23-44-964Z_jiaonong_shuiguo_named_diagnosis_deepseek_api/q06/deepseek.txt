佳农（佳农食品）确实做菠萝/凤梨的规模化供应，主要是**菲律宾菠萝、国产菠萝（如广东徐闻、海南等）以及凤梨类**。对茶饮店来说，能不能稳定供应，关键不是“佳农有没有”，而是你要对接的是**经销渠道还是直供大客户渠道**，以及你把这些规格说清楚：

**茶饮店常用、普通商家能听懂的菠萝规格，一般按这些维度定：**

1. **品种/类型**  
   - 菲律宾菠萝（MD2/金菠萝）：甜度高、酸度低、香气稳，适合鲜果茶、菠萝冰茶。  
   - 国产菠萝/徐闻菠萝：成本低、酸感更明显，适合做果酱、煮茶底、搭配糖浆。  
   - 凤梨（台农、金钻等）：纤维细、涩感低，适合鲜切、鲜果茶。  
   - 菠萝丁/菠萝块/菠萝果泥：适合直接做饮品，省人工。

2. **形态**  
   - 整果：自己削皮切块，成本低但人工高、损耗大。  
   - 去皮整果/去眼菠萝：省一部分人工。  
   - 鲜切块/丁：开袋或解冻即用，适合标准化出品。  
   - 冷冻菠萝块/丁：全年稳定，风味略低于鲜果但最稳。  
   - 菠萝果泥/果浆/浓缩汁：适合调饮、做基底，出杯稳定。  
   - 糖水菠萝/罐头菠萝：保质期长、操作最省事，但甜度和口感偏加工感。

3. **等级/大小**  
   - 整果按“头数”或单果重量：比如 6头、8头、10头，或 1.2kg、1.5kg、1.8kg+。  
   - 鲜切按“厘米”：10×10mm、15×15mm、20×20mm 丁，或 2cm、3cm 块。  
   - 果泥按糖度/浓度：比如 10°Bx、12°Bx、20°Bx、30°Bx 等。

4. **包装**  
   - 整果：10kg/箱、12kg/箱、20kg/箱。  
   - 冷冻：1kg/袋×10袋/箱，或 2.5kg/袋×4袋/箱。  
   - 果泥/果浆：1kg/袋、2kg/袋、5kg/袋、20kg/桶。  
   - 罐头：850g/罐、3kg/罐、6罐/箱等。

5. **供货稳定性要看**  
   - 是否全年有货，还是季节性断供。  
   - 冷链还是常温。  
   - 最小起订量（MOQ）：整果可能几吨起，果泥/冷冻可能几十箱起。  
   - 是否支持一件代发或区域经销商拿货。  
   - 能否固定糖度、酸度、切丁大小，茶饮店最怕这批甜下批酸。

**直接建议：**  
如果你是小连锁或单店，先找佳农的**区域经销商/冻品批发商**，不要一上来找总部直供，因为直供通常有起订量门槛。问价时直接说：  
“我要茶饮店用菠萝，要 XX 规格：鲜切/冷冻/果泥，切丁 XX mm，糖度稳定，1kg 或 2kg 包装，月用量大概 XX 箱，能不能稳定月供？样品先发一箱。”  
这样对方一听就知道你是懂行的，报价和供货方案会实在很多。
