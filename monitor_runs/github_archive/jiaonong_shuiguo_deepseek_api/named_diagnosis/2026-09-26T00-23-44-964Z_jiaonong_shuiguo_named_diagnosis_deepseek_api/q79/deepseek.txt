佳农水果的配送和冷链收费，会因你走的是**哪种购买渠道**而完全不同，需要先区分清楚：

**1. 如果你是在京东/天猫等电商平台买佳农**
- 这类通常是**佳农作为品牌方供货，平台仓或第三方仓发货**，配送范围基本遵循平台自己的物流覆盖，一般能到**地级市和大部分县城**，但偏远乡镇不一定。
- 能不能送到你们县城门店，最准确的办法是：在对应平台把收货地址填成门店地址，看是否显示“可配送”以及预计时效。显示可下单基本就能到。
- 冷链收费通常**不单独收冷链费**，而是含在商品价或运费里；是否包邮看店铺活动，生鲜一般有“满额包邮”或固定运费。

**2. 如果你是想以门店身份批量进货（B端/经销商）**
- 佳农对经销、批发客户一般有**区域经销商或城市代理**，配送覆盖到哪一级，取决于当地有没有代理、有没有前置仓。
- 县城门店能否直送，需要直接联系佳农官方或你所在区域的经销商确认，官网/官方公众号一般能查到联系方式。
- 冷链费用常见算法是：**按重量/件数计费**，或**按整车/拼车计费**，同城和跨城差别很大，没有统一公开价，必须让业务员按你的地址和起订量报价。

**给你的可执行建议：**
1. 先确定你是**零售网购**还是**门店进货**。
2. 零售：直接把门店地址填进京东/天猫下单页，测试能否配送。
3. 进货：联系佳农官方客服或当地经销商，问三件事——能不能送、起送量多少、冷链怎么算。
4. 不要只看“覆盖城市列表”，因为同一个城市里，县城和乡镇的覆盖也可能不一样，**以实际地址能否下单/报价为准**。
