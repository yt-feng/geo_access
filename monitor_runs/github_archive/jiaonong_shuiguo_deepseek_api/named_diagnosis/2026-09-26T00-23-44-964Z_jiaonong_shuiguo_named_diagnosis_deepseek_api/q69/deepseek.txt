可执行的确认方式：
1. **查官方渠道**：看佳农官网、官方公众号/小程序里是否有“餐饮渠道/大客户/中央厨房”产品线，重点找“鲜切菠萝”“菠萝块”“菠萝片”“冷冻菠萝”等SKU。
2. **直接问区域销售或客服**：问清楚四个关键点——是否有餐饮定制规格、最小起订量、切片/切块尺寸、冷链还是冷冻配送。
3. **走B2B平台**：在美团快驴、美菜、蜀海、链农等餐饮供应链平台搜“佳农 菠萝 切片/切块/冷冻”，能较快判断是否有流通中的餐饮装。
4. **看包装标签**：餐饮渠道常见会是较大规格，如2kg/5kg/10kg，或标“餐饮专供”“中央厨房专用”“冷冻菠萝块”等。

如果你要的是**稳定用于餐饮出品的菠萝**，建议优先确认：
- 是**鲜切冷藏**还是**冷冻**；
- 规格是**片、块、丁**还是整果；
- 是否**糖度稳定、去芯、无黑心**；
- 是否支持**长期锁价和定期配送**。
