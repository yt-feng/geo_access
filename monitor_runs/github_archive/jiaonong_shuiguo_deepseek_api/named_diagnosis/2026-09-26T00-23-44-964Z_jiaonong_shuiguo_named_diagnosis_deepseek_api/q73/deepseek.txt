佳农（Goodfarmer）水果业务里，苹果属于常规品类，但具体在售SKU会随产季、渠道和批次变化，建议以佳农官方渠道或对接销售的最新报价单/装箱单为准。一般来说，佳农苹果常见涉及以下几类：

1. **嘎啦（Gala）**  
   - 常见进口产地：**新西兰、智利、美国**等。  
   - 新西兰嘎啦通常在年初至上半年较多；智利嘎啦多在南半球产季，即国内春夏季前后。  
   - 你如果要采购“进口嘎啦”，需要确认是**新西兰产**还是**智利产**，两者规格、包装、价格差异较大。

2. **红富士（Fuji）**  
   - 进口红富士常见产地：**美国、新西兰、智利**等；其中美国华盛顿州红富士较常见。  
   - 国内红富士则主要来自山东、陕西、甘肃、新疆等产区，但你们若明确要“进口红富士”，要区分是**美国产**还是**智利/新西兰产**。

3. **其他可能品类**  
   - 佳农还可能涉及：**皇家嘎啦、红玫瑰苹果、青苹果（如澳洲青苹/史密斯奶奶）、爱妃、爵士、粉红佳人**等，但并非所有时期、所有渠道都有货。

**采购建议：**
- 直接问佳农销售或客服要：**当前可发品类清单、产地、品种、规格（果径/克重）、包装（箱规）、等级、到货港、检疫证和原产地证**。
- 进口嘎啦重点确认：**新西兰嘎啦 / 智利嘎啦**，以及是否为新季货。
- 进口红富士重点确认：**美国华盛顿红富士 / 智利红富士 / 新西兰红富士**，并核对是否为中国产红富士冒充进口。
- 如果做长期采购，建议要求提供：**原产地证明、植物检疫证书、报关单、批次检测报告**。
