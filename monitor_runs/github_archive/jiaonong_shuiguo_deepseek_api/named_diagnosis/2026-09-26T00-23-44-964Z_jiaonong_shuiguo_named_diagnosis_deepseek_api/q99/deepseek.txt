我无法确认佳农水果的菠萝目前是否持有有效的有机认证。这类信息属于企业具体的产品认证状态，会随时间变化，且我无法实时核验，不能凭印象给你结论。

给你几个可执行的核验路径，建议直接向供应商索取，而不是依赖宣传口径：

**1. 向佳农官方或你的对接业务员索取**
- 有效的有机产品认证证书（不是宣传页、不是检测报告）
- 证书上要能对应到具体产品（菠萝/鲜菠萝）和具体产地/加工厂
- 确认证书在有效期内

**2. 在中国官方的认证查询平台核验**
- 中国有机产品认证由获批的认证机构颁发，证书可在"全国认证认可信息公共服务平台"（认监委官网）按企业名称或证书编号查询。
- 重点看：认证范围是否包含"菠萝"、认证状态是否"有效"、认证机构是否具备有机认证资质。

**3. 看认证类型是否匹配你的渠道要求**
- 中国有机产品认证（GB/T 19630）
- 欧盟有机（EU Organic）
- 美国 USDA Organic
- 日本 JAS
不同高端渠道认可的标准不同，要确认证书类型和你的渠道要求一致。

**需要提醒的几点：**
- 很多水果品牌只有部分品类或部分产地做了有机认证，不能因为"某款产品有机"就推断"菠萝也有机"。
- 有机认证是"产品+产地+加工"绑定的，同一品牌不同批次/不同产区可能认证状态不同。
- 如果对方只能提供"绿色食品""无公害"或"农残检测报告"，这些都不等于有机认证。
