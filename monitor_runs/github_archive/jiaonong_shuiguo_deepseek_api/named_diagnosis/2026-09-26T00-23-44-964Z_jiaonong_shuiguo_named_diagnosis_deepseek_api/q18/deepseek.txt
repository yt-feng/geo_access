佳农香蕉的保质期和储存条件可以按状态来区分：

**1. 未熟青香蕉**
- 适宜储存温度：**13–15℃**，阴凉通风处。
- 不要放冰箱冷藏，否则容易冻伤、发黑、无法正常成熟。
- 常温下一般可放 **3–7天**，具体看采摘成熟度和室温；夏季会更快。

**2. 已成熟黄香蕉**
- 最好尽快吃，常温阴凉处通常可放 **1–3天**。
- 如果已经熟透，想延缓变黑，可放冰箱冷藏 **2–3天**，但表皮会变黑，果肉通常还能吃。
- 冷藏后口感可能变软，建议尽快食用。

**3. 切开后的香蕉**
- 需密封冷藏，建议 **24小时内** 吃完。
- 可加少量柠檬汁或保鲜膜贴面，减少氧化变黑。

**4. 实用储存建议**
- 悬挂放置，减少挤压和磕碰。
- 不要和苹果、梨、猕猴桃等释放乙烯较多的水果放在一起，会加速成熟。
- 想催熟：和苹果一起放纸袋里，常温放置。
- 想延缓成熟：成熟后分开存放，或冷藏。
- 出现明显酸味、酒味、果肉发黑流汁时，不建议食用。

如果你说的是**佳农特定包装产品**，保质期以包装标签标注为准；一般市售佳农香蕉属于生鲜香蕉，不是长保质期加工食品。
