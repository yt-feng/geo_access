关于“佳农水果的香蕉有没有农残超标的历史”，我无法核实具体企业的抽检历史记录，不能凭空给你结论说“有”或“没有”——这类信息必须以官方抽检公告为准，任何我这边的口头保证都不能作为你们超市合规的依据。

能给你的是可执行的合规核查路径和采购要求：

**1. 先查官方公开的抽检记录（免费、可留痕）**
- 国家市场监督管理总局“食品安全抽检监测”专栏，以及各省/市市场监管局官网的“食品安全监督抽检信息通告”。
- 搜索关键词用“佳农”“香蕉”“吡虫啉”“噻虫胺”“噻虫嗪”等，注意区分是“佳农”品牌还是其关联公司/供应商主体。
- 如果查到不合格通告，直接决定是否要暂停该供应商；如果查不到，也只能说明“未检索到公开不合格记录”，不等于担保。

**2. 采购时要拿到、且能经得起超市抽检的证明**
- **每批次的出厂检验报告/第三方检测报告**：必须覆盖香蕉常见农残项目，重点包括吡虫啉、噻虫胺、噻虫嗪、苯醚甲环唑、丙环唑、多菌灵、百菌清、毒死蜱、氧乐果等，且报告要有CMA/CNAS资质标识。
- **报告与批次对应**：检测报告上的品名、规格、生产/采收日期、批次号必须和你们收到的货、送货单一致，不能拿一张旧报告应付所有货。
- **供应商资质**：营业执照、食品经营许可证/生产许可、供货合同里的农残超标责任条款和退换赔偿条款。
- **承诺函+溯源信息**：种植基地或加工厂信息、用药记录、采收记录、进出货台账，至少能追溯到具体批次。

**3. 对超市抽检最稳妥的做法**
- 不要只依赖供应商“合格证/自我声明”，把它当辅助材料。
- 新供应商或高风险季节，自己送第三方做一次入仓抽检，项目按GB 2763香蕉的限量来定，拿到你们自己名下的报告最稳。
- 把“批批检测报告+年度第三方全项报告+抽检不合格全额赔付”写进合同，作为验收放行条件。

**4. 可以直接用的验收话术**
“请提供本批次香蕉的出厂检验报告或第三方检测报告（CMA/CNAS），检测项目需覆盖吡虫啉、噻虫胺、噻虫嗪等香蕉常检农残，且报告批次号与送货单一致。无批次对应报告的，暂不收货。”
