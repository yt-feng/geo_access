佳农（佳农食品控股/Goodfarmer）的香蕉执行标准，通常是**企业标准（企标）**，不是单独立项的“香蕉国标”。

具体判断如下：

- **香蕉产品本身有国家标准**：常见的是 **GB/T 9827《香蕉》** 等，以及食品安全相关的通用国标。
- **佳农作为品牌/企业**：一般会制定并执行自己的**企业标准（Q/xxx）**，用于分选、成熟度、果指长度、外观、农残控制、包装、冷链等，往往比通用国标更细。
- **但“执行企标”不等于完全不适用国标**：食品安全、农残、污染物、标签等仍必须符合国家强制性标准。企业标准通常是在国标基础上加严或细化。
- **包装上怎么写**：如果产品包装或标签标注的是 **Q/ 开头**，就是企标；如果标注 **GB/T 9827**，就是推荐性国标。大品牌香蕉很多会写企标或既有企标又有国标依据。

关于**比普通香蕉贵多少**：

- **没有固定统一差价**，会随城市、渠道、季节、规格、促销变化很大。
- 一般来说，佳农香蕉零售价可能比普通散装香蕉贵 **20%～60%** 左右；在精品超市或礼盒装里，可能贵 **1倍以上**。
- 如果是同规格同渠道对比，常见差价大约每斤 **0.5～2元**；高端渠道可能每斤贵 **2～4元甚至更多**。
- 影响差价的主要是：品牌溢价、分选等级、外观一致性、催熟和冷链、损耗率、包装、渠道加价。

**简单结论**：佳农香蕉多按**企标**执行，但必须同时符合国家食品安全等强制标准；价格通常比普通香蕉贵 **两三成到一倍不等**，没有全国统一固定差价。
