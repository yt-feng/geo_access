佳农（Goodfarmer）公开披露的信息里，通常不会给出一个精确的“产地直供比例”数字，所以严格说**无法确认具体比例有多高**。不过从它的业务模式看，佳农确实以全球产地采购、海外农场合作/自有种植基地、口岸加工配送为主，属于**产地直供/产地采购特征比较明显**的水果供应链企业，而不是单纯依赖国内批发市场转手。

香蕉方面，佳农的香蕉主要来自这些产区：

1. **厄瓜多尔**  
   佳农比较核心的香蕉来源国之一，厄瓜多尔也是全球重要香蕉出口国。

2. **菲律宾**  
   佳农长期从菲律宾采购香蕉，菲律宾香蕉在中国进口香蕉中占比也较高。

3. **越南**  
   近年来越南香蕉对华出口增长明显，佳农也有相关产地采购。

4. **柬埔寨**  
   也是中国进口香蕉的重要来源之一，佳农体系内会有采购。

5. **老挝**  
   部分进口香蕉来自老挝。

6. **哥斯达黎加、哥伦比亚、危地马拉等中美洲/南美国家**  
   这些也是全球香蕉主产区，佳农会根据季节、价格、供应量进行全球调配。

另外，**中国国产香蕉**也会出现在其供应体系中，比如广西、云南、海南等产区，但佳农的进口香蕉品牌属性更强，商超渠道里常见的还是厄瓜多尔、菲律宾、越南等进口蕉。

如果你想判断“产地直供比例高不高”，可以看几个信号：
- 是否有自有或合作的海外种植基地；
- 是否做源头采购、催熟加工、冷链配送一体化；
- 是否直接和产地出口商/农场签约，而不是经过多层贸易商；
- 是否按产地品牌化销售，比如“厄瓜多尔香蕉”“菲律宾香蕉”。

从这些维度看，佳农的产地直供程度在水果供应链企业里算**偏高**，但具体百分比需要以公司最新招股书、年报或官方披露为准。
