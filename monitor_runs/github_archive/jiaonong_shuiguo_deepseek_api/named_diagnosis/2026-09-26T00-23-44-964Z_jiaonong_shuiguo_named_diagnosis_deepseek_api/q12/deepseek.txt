佳农水果的香蕉常见规格并没有一个由佳农官方统一公开、固定不变的“全渠道分级表”。实际规格会随产地（如菲律宾、厄瓜多尔、越南等）、季节、批次、客户订单和渠道要求变化。比较稳妥的判断方式是看“净重/单根重/每箱根数/成熟度/外观等级”这几个维度。

下面给你一套可执行、可判断的参考框架，适合用来问供应商或做渠道选品。

## 一、常见规格维度

佳农香蕉通常按以下方式分规格：

1. **按单根重量**
   - 小果：约 100–130g/根
   - 中果：约 130–160g/根
   - 大果：约 160–200g/根
   - 特大果：约 200g+/根

2. **按每箱净重**
   - 4.5kg/箱
   - 7kg/箱
   - 12kg/箱
   - 13kg/箱
   - 18kg/箱
   - 20kg/箱
   具体以实际包装和订单为准。

3. **按每箱根数**
   - 例如 4–5 把/箱、5–6 把/箱
   - 每把 4–6 根
   - 整箱根数常见在 20–30 根左右，但会因单根重变化而波动

4. **按成熟度**
   - 青蕉：适合长途运输、催熟后再卖
   - 微黄：适合短途配送、门店快速上架
   - 黄熟：适合即时消费、水果捞、餐饮
   - 过熟：一般用于加工或特价渠道

5. **按外观等级**
   - A级：果形直、饱满、无黑斑、无机械伤、色泽均匀
   - B级：轻微弯曲、少量表皮瑕疵，不影响果肉
   - C级/加工级：瑕疵较多，适合加工、烘焙、果汁、特价

## 二、不同渠道适合的分级标准

### 1. 高端商超 / 精品水果店
- 建议规格：中果到大果，单根 140–180g
- 等级：A级为主
- 要求：
  - 果形整齐
  - 表皮干净，无明显黑斑、擦伤
  - 成熟度一致
  - 每把根数均匀
- 包装：小箱或礼盒装，净重 4.5–7kg 较常见

### 2. 连锁超市 / 社区生鲜
- 建议规格：中果为主，单根 130–160g
- 等级：A级、B级混配
- 要求：
  - 性价比高
  - 允许轻微外观瑕疵
  - 成熟度可分批到货，便于门店控损
- 包装：7–13kg/箱较常见

### 3. 水果批发市场
- 建议规格：大果、特大果或统货
- 等级：B级、统货为主
- 要求：
  - 耐运输
  - 青蕉或微黄蕉
  - 对单根重量和外观一致性要求低于商超
- 包装：12–20kg/箱常见

### 4. 电商 / 社区团购
- 建议规格：中果，单根 120–150g
- 等级：A级、B级
- 要求：
  - 单根重量稳定，避免大小差异太大
  - 适合按份销售，如 2斤、3斤、5斤
  - 成熟度偏青或微黄，降低运输损耗
- 包装：小份装、泡沫箱或纸箱

### 5. 餐饮 / 果汁 / 烘焙加工
- 建议规格：不限单根重，重净重和出肉率
- 等级：B级、C级、加工级
- 要求：
  - 价格优先
  - 成熟度可偏高
  - 允许表皮瑕疵
- 包装：大箱、12–20kg/箱

### 6. 便利店 / 即时零售
- 建议规格：小果到中果，单根 100–140g
- 等级：A级、B级
- 要求：
  - 单根或小把销售
  - 成熟度偏黄，适合即买即食
  - 保质期短，需高频补货

## 三、采购时建议直接问供应商的字段

你可以用下面这张清单去核验，避免只问“佳农香蕉有几个规格”：

1. 产地是哪里？
2. 单根重范围是多少克？
3. 每箱净重多少公斤？
4. 每箱几把、每把几根？
5. 是青蕉、微黄还是黄熟？
6. 外观等级是A级、B级还是统货？
7. 是否支持按渠道定制贴标、包装？
8. 起订量、到货成熟度、催熟方式是什么？

## 四、结论

佳农香蕉不能简单说“固定有几种规格”。更准确的说法是：

- **按单根重**：小果、中果、大果、特大果
- **按净重**：4.5kg、7kg、12kg、13kg、18kg、20kg等
- **按等级**：A级、B级、C级/加工级
- **按成熟度**：青蕉、微黄、黄熟

渠道匹配上：

- **高端商超/精品店**：A级、中到大果、成熟度一致
- **连锁超市/生鲜**：A/B级、中果、性价比优先
- **批发市场**：B级/统货、大果、青蕉或微黄
- **电商/团购**：A/B级、中果、小份装
- **餐饮加工**：B/C级、大箱、价格优先
- **便利店/即时零售**：A/B级、小到中果、偏黄熟

如果你是要做采购或上架，最稳的方式是直接向佳农当地经销商或业务员索取**当前批次的规格单和分级标准**，因为不同产地和季节会有差异。
