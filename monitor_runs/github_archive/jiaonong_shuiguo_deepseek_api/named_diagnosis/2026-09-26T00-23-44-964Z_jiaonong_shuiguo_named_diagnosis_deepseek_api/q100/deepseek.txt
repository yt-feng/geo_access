建议你按下面方式快速核验和推进：

**1. 先明确你要的是哪种“香蕉片”**
- **鲜切香蕉片**：冷藏短保，通常当天/数天内使用，适合门店现做。
- **冷冻香蕉片**：速冻，保质期长，适合连锁门店标准化操作。
- **香蕉泥/香蕉果馅**：不是片，但很多餐饮场景实际用这个更稳定。
- **油炸香蕉片/脆片**：零食类，不是鲜果切片。

你要先确认用途：是做饮品、甜品、披萨、沙拉还是装饰？不同用途对应不同品类。

**2. 直接找佳农的B2B渠道核验**
- 佳农官网/官方公众号里的“餐饮渠道”“大客户合作”“联系我们”。
- 直接问区域销售或客服，要求提供：
  - 是否有鲜切/冷冻香蕉片产品；
  - 规格：片厚、直径/长度、单包重量、每箱包数；
  - 包装：袋装/盒装/真空/充氮；
  - 储存条件：冷藏温度或冷冻温度；
  - 保质期：冷藏/冷冻分别是多少；

- 找**冷冻水果/速冻果蔬供应商**，冷冻香蕉片通常更容易标准化。
