佳农（佳农食品控股/Goodfarmer）通常是有商超渠道支持的，但能否给到“堆头陈列+试吃”，取决于你们的具体门店、采购渠道和当期档期，不是统一标准政策。下面是可执行的判断和谈法。

**一、佳农一般能提供什么**
- 堆头/地堆：常见支持形式，但是否免费、给多大位置，取决于单品、进货量和档期。
- 试吃：多数情况下可以做，但通常需要提前报备，且要满足门店的试吃合规（人员健康证、食品留样、垃圾处理等）。
- 物料：围挡、价签、爆炸贴、试吃台、一次性餐具等，可能由厂家提供，也可能双方分摊。

**二、费用怎么分担（常见做法）**
实际谈下来一般是这几种组合：
1. **厂家全包**：堆头物料+试吃人力+试吃损耗，商超只出位置。多见于主推大单品、冲销量档期。
2. **厂家出物料，商超出位置和人力**：试吃员由商超安排，厂家给试吃品和物料。
3. **双方分摊**：
   - 堆头费：商超免或减免，换取进货量/排面承诺；
   - 试吃品损耗：厂家承担，或按进货额比例核销；
   - 试吃人力：商超承担为主，厂家可给补贴；
   - 物料：厂家提供为主。
4. **纯商超自担**：厂家只给供货价，不支持堆头和试吃，这种多见于非重点门店或非档期。

**三、你该怎么谈（直接可用的条件）**
跟佳农业务或经销商谈时，把这几项写清楚：
- 档期时间、门店清单、堆头位置和面积；
- 主推单品、预估进货量、陈列排面；
- 试吃时间、试吃品数量、试吃员由谁出；
- 物料清单（围挡、价签、试吃台、餐具）由谁提供；
- 费用分担：堆头费、试吃损耗、人力补贴分别怎么算；
- 核销方式：按进货额、按销量，还是固定费用；
- 如果达不到销量，费用怎么调整。

**四、判断能不能成**
- 如果你们是连锁商超、有采购量、在重点档期，佳农大概率愿意给堆头和试吃支持，费用也倾向厂家多承担。
- 如果是单店、进货量小、非主推期，厂家通常只给部分物料，试吃品和人力要你们自己出。
- 最直接的办法：找佳农当地业务或经销商，要一份**当期促销支持政策**，上面一般会写明堆头、试吃、费用分担的标准。
