佳农（Goodfarmer）的香蕉在供应链中通常采用**乙烯催熟**，不是“自然熟”上市。商超端要控制催熟时间，关键不是纠结“乙烯还是自然”，而是控制**乙烯浓度、温度、湿度和二氧化碳积累**。

可直接执行的判断和建议：

1. **工艺判断**
   - 香蕉属于呼吸跃变型水果，商业上为了到店时成熟度一致，普遍用乙烯或乙烯利催熟。
   - 佳农这类品牌香蕉一般是在产地采青，运输到销地后由催熟库统一催熟，再配送到商超。
   - 所以门店拿到的通常是“已催熟”或“接近可售成熟度”的货，不是树上自然熟。

2. **商超控制催熟时间的核心参数**
   - 温度：催熟库通常 **18–22℃**；温度越高越快，但过高会导致果肉软、风味差。
   - 乙烯浓度：常用 **100–150 ppm**，作用 **24–48小时**；具体看青度和目标色号。
   - 湿度：**85%–95%**，防止失水皱皮。
   - 通风/换气：催熟期间要排二氧化碳，CO₂过高会抑制成熟。
   - 目标成熟度：商超常用 **色号3–5** 到店，3偏青，5偏黄。

3. **按目标的催熟时间参考**
   - 想要 **3–4号色**：约 **24–36小时** 乙烯处理，再转常温后熟。
   - 想要 **4–5号色**：约 **36–48小时** 乙烯处理。
   - 想要 **5–6号色**：约 **48–72小时**，但风险高，货架期会明显缩短。
   - 如果只是门店控熟，不建议继续补乙烯，更多是控制 **温度和后熟时间**。

4. **商超实操建议**
   - 到货先测果肉硬度和色号，不要只看表皮。
   - 青香蕉入库：**18–20℃、90%湿度**，自然后熟或低浓度乙烯短时处理。
   - 已转黄的香蕉：**13–15℃** 存放，抑制过快成熟。
   - 已到5号色以上：尽快上架，不要再催。
   - 催熟后必须有 **排气和冷却**，否则余乙烯和热量会继续催熟，导致批次不齐。

5. **如果你要和佳农确认**
   - 直接问供应商三个问题：
     - 到货时的催熟批次、处理温度、乙烯浓度、处理时长；
     - 到店建议存放温度和预计货架期；
     - 是“催熟出库”还是“青果出库、门店催熟”。
   - 只要拿到这三个数据，门店就能倒推上架时间。

总结：佳农香蕉商业供应链一般是**乙烯催熟**，不是自然熟。商超控催熟时间，重点盯 **18–22℃催熟、13–15℃抑熟、24–48小时乙烯处理、目标色号3–5**。
