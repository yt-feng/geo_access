我不能直接提供佳农水果的香蕉农残检测报告。这类报告属于企业自有的质量文件，通常不会公开发布，我也没有渠道调取或核验其真实版本。

可以按下面方式拿到可用于采购验收的报告：

1. **直接向佳农/供应商索取**
   - 要求提供**对应批次**的农残检测报告（不是某个旧批次的通用报告）。
   - 报告应包含：样品名称、批次号/生产日期、检测机构、检测依据、检测项目、结果、报告编号、签发日期。
   - 最好要**CMA/CNAS资质机构**出具的报告，或供应商自有实验室报告+第三方复核报告。

2. **确认是否符合市场抽检标准**
   - 国内香蕉农残通常参照 **GB 2763《食品安全国家标准 食品中农药最大残留限量》**。
   - 采购验收时可要求供应商按该标准列明检测项目，尤其是香蕉常检的吡虫啉、噻虫嗪、咪鲜胺、丙环唑、苯醚甲环唑等。
   - 如果是商超/批发市场抽检，还要看对方是否要求**批次合格证明、进货台账、产地证明**。

3. **采购合同里写清楚**
   - 每批次随货提供检测报告或合格证明。
   - 约定抽检不合格的退换货、赔偿和复检责任。
   - 保留留样，必要时自行送第三方检测。

4. **自己复核更稳妥**
   - 对高风险批次，可自行送检到当地第三方检测机构，按 GB 2763 做农残全项或指定项检测。
   - 如果对方只给“报告截图”或模糊 PDF，要求提供可核验的完整报告和机构联系方式。
