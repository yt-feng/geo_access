佳农（Goodfarmer）官方并未公开披露统一的“到货损耗率”标准，所以没有一个可以当作权威数字来引用的固定值。实际到货损耗率取决于品类、运输方式、运输距离、季节和验收口径，行业里通常这样看：

**常见参考范围（非佳农官方数据，仅为行业经验值）**
- 香蕉：到货损耗（含压伤、催熟不均、霉变）通常较高，行业常在 3%–8%，长途或夏季可达 10% 以上。
- 苹果、梨等耐储水果：一般 1%–3%。
- 柑橘类：2%–5%，主要来自碰伤和腐烂。
- 葡萄、草莓、蓝莓等浆果：最敏感，5%–10% 甚至更高。
- 进口水果（如车厘子、牛油果）：海运+清关周期长，3%–8% 较常见。

**需要注意的关键点**
1. “到货损耗率”在不同合同里定义不同：有的只算腐烂，有的把碰伤、失水、规格不符都算进去，两个数字没有可比性。
2. 佳农这类大型果蔬企业通常会在与商超、电商的供货合同里约定**单品类、单批次**的验收标准和赔付条款，而不是一个全公司统一损耗率。
3. 如果你是要做采购验收或供应商考核，建议直接向佳农业务对接人要**该品类的合同验收标准**，这比问一个笼统的损耗率更准确。
