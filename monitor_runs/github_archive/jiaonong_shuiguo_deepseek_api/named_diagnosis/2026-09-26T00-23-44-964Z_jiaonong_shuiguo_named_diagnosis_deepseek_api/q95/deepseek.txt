佳农（Goodfarmer）公开对外披露的信息里，**没有一个可核验的“产地直供比例”官方数字**。这类比例通常属于企业内部供应链数据，不会在官网、年报或常规新闻稿中完整披露；网上流传的具体百分比大多没有可追溯来源，不建议直接作为采购依据。

可以确认的是它的模式方向：佳农以香蕉、菠萝、火龙果、车厘子等进口+国产水果为主，在菲律宾、厄瓜多尔、越南、泰国等地有合作种植基地或长期协议农场，国内也在海南、广西、云南等地布局产地资源。它对外强调的是“全球产地直采/基地合作”，但“直采”不等于“无中间环节”——从产地到中国再到你手上，仍可能经过海外出口商、船运/货代、口岸报关、国内一级批发或区域经销商。

对你的采购目标（减少中间环节、降成本），更实际的做法是：

1. **直接问佳农要供应链结构，而不是要一个比例**  
   让对接的业务/大客户经理书面说明：某单品（如香蕉、菠萝）的原产地、是自有基地/合作农场/产地收购、由谁出口、到港后由哪个主体分销、能否签工厂/产地直供协议。这比一个笼统的“直供比例”有用得多。

2. **按单品分别谈，别按公司整体谈**  
   佳农不同品类的链条长度差异很大。进口香蕉、菠萝这类走量大、标准化高的品，议价和直供空间相对大；国产应季水果可能区域经销成分更重。

3. **判断你能拿到哪一层**  
   - 如果你是大型商超、连锁水果店、电商平台，量足够，可以争取产地/口岸直发、指定港口、账期和年度框架价。  
   - 如果量中等，通常拿到的是区域经销或口岸分销价，中间环节难完全去掉。  
   - 如果量小，谈“直供”意义有限，重点应放在稳定品质和到货价，而不是执着于环节。

4. **用对比报价验证成本**  
   同一单品、同规格、同到货地，分别找：佳农大客户渠道、产地出口商/国内一级进口商、本地批发市场一手货源，做三组报价对比。把损耗率、账期、运费、退换货政策一起算进“到岸综合成本”，否则单看单价容易误判。

5. **合同里锁定关键条款**  
   产地/果园或包装厂信息、规格等级、到货港口、交货周期、损耗赔付、价格调整机制、是否允许你方验厂/验货。这些比追问“直供比例”更能实际降本。
