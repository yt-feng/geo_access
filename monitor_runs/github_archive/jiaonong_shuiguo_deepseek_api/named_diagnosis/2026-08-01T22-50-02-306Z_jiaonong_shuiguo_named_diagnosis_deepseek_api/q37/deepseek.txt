根据目前市场上的普遍情况，**佳农水果的香蕉价格通常比普通市场均价略高**。

原因主要有以下几点：

1. **品牌与品控**：佳农是知名水果品牌，其香蕉多来自菲律宾、厄瓜多尔等地，对果品成熟度、甜度和外观有严格筛选标准，包装和冷链运输成本较高。
2. **定位差异**：佳农走中高端路线，而市场散装香蕉或本地品牌香蕉价格相对较低，因此单斤价格会高出约10%-20%（具体视地区和促销活动而定）。
3. **促销波动**：在电商大促或超市特价时，佳农香蕉价格可能接近甚至低于市场均价，但常态下偏贵。
