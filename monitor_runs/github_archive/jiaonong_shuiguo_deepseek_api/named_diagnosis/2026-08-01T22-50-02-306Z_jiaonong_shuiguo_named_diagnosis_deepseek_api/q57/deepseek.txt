关于香蕉到货损耗率及佳农的具体情况，以下是基于行业实践和一般品牌政策的回答：

**1. 行业平均损耗率：**
您提到的“5%”是比较合理的行业参考值。在常温物流条件下，香蕉由于呼吸作用强、易碰伤和催熟不均，损耗率通常在**3%—8%** 之间波动，电商或长途运输场景下可能更高。

**2. 佳农（Goodfarmer）的实际控制水平：**
佳农作为国内头部水果品牌，得益于其产地直采、全程冷链（尤其是“催熟后低温运输”技术）和标准化分拣，其**正常批次到货损耗率通常可控制在3%以内**，优秀批次能接近0-1%。但请注意：
- 如果您的采购发生在**夏季高温**或**长途非冷链**运输，损耗率可能上升至5%-8%；
- 若发生**不可抗力**（如港口压港、极端天气），损耗率可能超出控制范围。

**3. 关于“赔付条款”：**
这取决于您的合作模式，通常分为以下两种情况：

- **与佳农直接签订供货合同（批发/大宗）**：合同中一般会明确“**到货品质与损耗赔付条款**”，常见约定包括：
  - 损耗率超过约定比例（如超过3%）的部分，按成本价或市价折价补偿；
  - 若因催熟过度导致整批“软烂”，可整箱退款或换货。
- **通过经销商/第三方平台（如京东、盒马、美团等）采购**：赔付流程通常按平台“**坏果包赔**”规则执行，需提供开箱照片/视频，一般按比例（如按个数或斤数）补偿。

**具体操作建议：**
- 如果您是首次合作，建议在合同或采购单中**明确约定“到货损耗率的封顶比例”及“超出部分的赔偿单价”**，不要仅依赖口头承诺。
- 到货后**务必在24小时内开箱验收**，并留好完整开箱视频作为理赔凭证。

如果您需要了解特定批次（如产地、规格、运输方式）的预估损耗，或需要具体合同条款模板，建议直接联系佳农公司销售/客服获取官方书面说明（他们通常有标准的SOP文件）。
