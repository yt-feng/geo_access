关于佳农水果在商超促销中的堆头陈列和试吃支持，这是一个非常实际的渠道合作问题。我的建议如下：

**第一步：直接与佳农对接，明确供应商政策**

佳农（Goodfarmer）作为大型进口水果供应商，通常有标准化的终端推广费用支持政策。你需要直接联系佳农的区域销售经理或业务代表，询问他们是否有：

1. **堆头陈列支持**：是否提供免费堆头、陈列道具、围挡、价格牌等物料，或给予陈列补贴。
2. **试吃支持**：是否有专人促销员驻场、试吃品（切好的水果样品）免费供应，或者促销员人工费用由厂家承担。

**第二步：费用分担的核心原则**

商超和供应商的费用分摊通常遵循以下模式（具体情况以你的合同为准）：

- **堆头位费用**：这通常是超市的“广告位”费用，一般由商超收取，供应商通常不承担。但如果佳农有陈列补贴或费用包干，他们可能会把这部分费用纳入总价，或直接替你支付给商超。
- **物料费用**：陈列架、装饰、POP海报等，**常规是供应商承担**，因为这是品牌形象展示。
- **试吃费用（核心谈判点）**：
  - 水果是易损耗品，试吃品通常由供应商按**进货价或更低折扣**提供，这是很常见的。
  - 促销员人工费：如果佳农派自己的促销员，费用不用你出；如果需要商超代招，这部分人工费可能需要按小时或按天结算，除非佳农明确包含“试吃服务费”。
  - 建议你提出“厂家提供试吃品+厂家促销员”，这样你基本零成本。

**第三步：谈判策略建议**

1. 强调“以销定产”和“陈列位置决定销量”，争取佳农承担大部分直接成本（试吃品+促销员）。
2. 可以用多品牌竞争施压（例如对比其他供应商的政策），要求佳农提供同等或更优支持。
3. 明确谈费用时，要求对方出具**书面报价单**，注明哪些免费、哪些收费、结算周期。
4. 试吃损耗：建议约定**试吃损耗比例**（例如销售额的2%-3%），超出的部分由供应商承担，避免你亏本。

**第四步：合规提醒**

如果试吃品或陈列涉及费用分摊，务必在合同中写明“费用明细、支付节点、超耗责任”，并保留好票据。
