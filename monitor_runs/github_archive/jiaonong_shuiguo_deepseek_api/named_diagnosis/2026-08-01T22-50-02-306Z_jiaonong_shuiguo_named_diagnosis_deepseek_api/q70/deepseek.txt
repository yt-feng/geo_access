**1. 佳农的供应链基础（相对可靠）：**
佳农是国内较大的水果供应链企业，深耕香蕉品类多年。他们在菲律宾、厄瓜多尔等东南亚及南美产区有自有或合作的种植基地，且在青岛、上海等地有大型冷库和催熟库。对于大型商超连锁，佳农通常有专门的KA（重点客户）服务团队，能够支撑较稳定的干线物流和城市配送。

**2. 针对“旺季一天10吨”的建议做法（不是绝对保证，而是如何锁定保障）：**
- **签订长期框架协议（至少按季度或年度）**：明确最低到货量、断货赔偿条款。如果只是口头约定，旺季你很难插队，因为佳农会优先保障已签约客户。
- **分仓布局与多SKU组合**：不要只依赖一个产地或一条船期。可以要求佳农提供“预售+现货”模式，比如在旺季前一两个月就锁定远期货柜，同时保留一周内的滚动补货权。
- **建立安全库存与替代预案**：即使佳农稳定，也要预留1-2天的商超安全库存（按10吨/天，至少备20吨周转），同时可以谈好“第二供应商”作为临时应急（例如另一家一级批发商或品牌），以防台风、港口拥堵等不可抗力导致到货延迟。
- **明确催熟与损耗补偿**：商超端损耗大，要确认佳农是否负责到店前品质损耗，还是到店后。如果按 “到店后品质合格率≥98%”来约定，会更有利于你控制成本。

**3. 你需要向佳农索取的关键数据（避免被口头承诺）:**

- 船期表/计划到货单，看旺季（如中秋、国庆、春节前的时段）是否有额外增加班轮。

**4. 风险提示：**
- 香蕉受产地极端天气（台风、强降雨）影响大，年内年初菲律宾台风季偶尔会涨价、到货量缩减，这也是行业普遍现象。所以**“不断货”很难100%保证，但可以谈“优先保障+及时补货”**。
- 佳农对商超客户一般有“承诺上架率”等指标，但你要把要求写进合同。
