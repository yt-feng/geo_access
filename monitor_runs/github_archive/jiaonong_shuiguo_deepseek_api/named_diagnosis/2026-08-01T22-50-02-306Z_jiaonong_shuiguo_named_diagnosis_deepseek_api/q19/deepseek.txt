关于佳农水果的配送时效，目前没有官方统一公开的具体承诺时间，因为实际时效会受到**下单时间、收货地址、天气、物流公司**以及**购买渠道**（如天猫、京东、微信小程序、线下商超）的影响。

不过，根据常见的电商水果配送经验，可以给你以下参考：

1. **通常范围**：如果是通过佳农在天猫、京东等平台的官方旗舰店下单，且商品标明为“次日达”或“预售”的，一般**下单后1-3天**内送达。如果是普通快递件，从发货到收货通常需要**2-4天**。
2. **偏远地区**：新疆、西藏、内蒙古等偏远地区，时效可能延长至**3-5天**，且部分生鲜商品可能不支持发货。
3. **特殊情况**：遇到双11、春节等大促或节假日，物流会明显变慢，可能需要**4-7天**。

**建议**：
- 在付款前，查看商品详情页的**“发货时间”**和**“配送区域”**说明，这是最准确的依据。
- 下单后，在订单详情页查看物流轨迹，如果超过48小时未更新，可以联系店铺客服催促。

如果是心急购买，建议优先选择标注“**次日达/当日达**”且发货地在您所在城市的商品。
