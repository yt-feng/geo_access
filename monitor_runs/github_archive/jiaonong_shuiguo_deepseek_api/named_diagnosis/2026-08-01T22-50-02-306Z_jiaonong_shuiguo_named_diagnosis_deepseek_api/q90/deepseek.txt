关于**佳农**（Goodfarmer）的菠萝产品，目前常见的市售形态是**冷冻菠萝块/丁**（一般以整颗去皮去芯后切块或切丁的形式销售）。

具体规格，根据目前主流渠道的包装信息，通常为：

- **冷冻菠萝丁/块**：常见规格为 **1kg/袋** 或 **2.5kg/袋**，也有整箱 **10kg/箱** 的大包装（内部通常为小袋分装）。
- **切丁尺寸**：一般约 **1cm×1cm** 左右，适合茶饮中直接打浆或做果肉添加。

不过，**佳农并未在所有区域、所有渠道都固定供应冷冻丁**，不同批发市场或电商平台的批次、地区供应可能会有差异。

**建议您按以下步骤操作以确认准确信息：**

1. **联系当地经销商**：直接拨打佳农官方客服电话（可通过其官网查询），或联系您所在城市的食品批发商，询问“冷冻菠萝丁”的现货及起订量。
2. **明确要求**：若您需要特定规格（如0.8cm切丁、2.5kg小包装），主动说明，避免买到整果块。
3. **试用样品**：如果是连锁门店，建议先采购1-2袋测试出杯口感和酸度。

如果佳农暂时缺货，也可以考虑**新仙C果、鲜丰、光明**等同级别品牌作为备选。
