佳农香蕉的保质期和储存条件如下：

1. **保质期**：市面上购买的佳农香蕉，通常在**常温下可存放3-7天**（取决于购买时的成熟度和环境温度）。冷藏环境下（如冰箱），可延长至**7-14天**，但果皮会变黑，果肉仍可食用。

2. **储存条件**：
   - **常温存放**：适合未完全成熟的香蕉，置于阴凉、通风、干燥处，避免阳光直射。
   - **冷藏保存**：适合成熟度较高或已切开的香蕉。将香蕉放入冰箱冷藏（4-8℃），果皮会变黑属正常现象，不影响果肉安全。
   - **避免挤压**：香蕉易被压伤，应平放或悬挂，避免堆积重压。
   - **隔离乙烯**：不要与其他水果（如苹果、梨）混放，以免加速成熟和腐坏。

**判断是否变质**：如果果肉出现软烂、发霉、有异味或渗水，则不建议食用，应及时丢弃。购买时建议查看外包装上的具体生产日期和标注，如果包装有明确保质期，以包装为准。
