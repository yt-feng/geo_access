关于佳农水果的到货损耗率，**通常行业标准（含佳农在内的大型水果企业）一般控制在5%以内，具体视水果品类而定，佳农在仓储物流环节的控制目标通常在3%-5%之间。**

更精确的数据取决于品类和运输距离：

- **耐储存品类（如苹果、梨、柑橘类）**：损耗率通常在 **2%-3%** 左右。
- **娇嫩品类（如蓝莓、草莓、车厘子、榴莲等）**：损耗率可能达到 **5%-8%**，但佳农会通过冷链和包装控制，努力维持在上限以下。
- **香蕉等后熟型水果**：因催熟环节，到货损耗率会稍高，一般在 **4%-6%**。

注意：以上为行业通行参考值，并非佳农官方公布的具体财务数据（官方未公开发布精确数字）。如果你是与佳农合作的采购方，建议在合同中明确损耗率条款，并以实际到货验货标准为准，通常生鲜供应链的损耗标准为：**到货损耗（果腐、碰伤、软化）≤3%为合格，≤5%为可接受，超过5%需协商赔付。**
