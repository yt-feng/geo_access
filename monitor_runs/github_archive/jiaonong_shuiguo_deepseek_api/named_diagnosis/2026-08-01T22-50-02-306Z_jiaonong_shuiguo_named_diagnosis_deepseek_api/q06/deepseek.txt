关于佳农（Joywing）是否能稳定供应普通商家可理解的菠萝规格，答案是：**基本可以，但建议以“按箱/按个数+大小分级”的口径来对接，并主动要求对方提供“板箱规格单”**。

具体给你拆解成“普通商家能听懂”的说法：

**1. 佳农的菠萝通常走“整箱批发”而非“散称零售”**
- 最常见规格是：**22-24头/箱**（即一箱装22到24个菠萝），也有 **18头/箱** 的大果规格。
- 重量口径：通常一整箱净重约 **20公斤（40斤）**，但不同产季（菲律宾、泰国、云南等）可能略有浮动。
- 所以你跟供应商沟通时，直接说“我要 **22头/箱、每箱约40斤** 的菠萝”，对方马上能明白。

**2. 关于“稳定供应”**
- 佳农是大型水果供应链公司，全国主要城市（北上广深、成都、武汉等）基本有保鲜仓和冷链配送，**批发商、连锁茶饮店、餐饮客户**是其常客。
- **但要注意**：稳定供应≠永远有货。菠萝受海运船期、气候、产季（菲律宾产区基本全年，但冬季可能换产地）影响，**建议你要求佳农的销售经理给你一个“月度排产/到货计划”**，并锁定最低供货量。市面上一些中小供应商会拿佳农的货转手，你也可以直接找当地佳农授权经销商，级别更稳定。

**3. 普通商家最容易踩的坑（务必问清楚）**
- **“尺寸”≠“重量”**：有的业务员说“大果”，实际是18头/箱的“大”，有的说“中果”其实是24头。下单前，请对方发你一张**近期到货的纸箱实物照片（拍箱体上的规格贴纸）**，确认“XX头/箱”。
- **成熟度**：茶饮店做鲜榨/果肉，建议选 **“黄熟度7-8成”** 的（即微微泛黄、有香气），不要全青的（难催熟），也不要过熟的（易烂）。在订单备注里写清楚“要求7-8成熟，可催熟”。
- **损耗率**：一箱20公斤，到手去皮去芯后，可用于果肉的净料大约 **55%-65%**（约11-13公斤）。如果菠萝偏生或运输磕碰，损耗会更高。签收时一定要当场开箱抽检，有烂果拍照留证，按比例索赔。

**一句话总结**：你可以直接打电话给佳农当地业务，说“我是开茶饮店的，长期要 **22头/箱、净重20公斤、7-8成熟** 的菠萝，你们这边能否按这个规格给我报价和排期？”——这样对方知道你懂行，报价和供货都会实在很多。如果对方给你含糊其辞的“按吨/按车”，你就让他折算成“每箱多少钱”，这样最清晰。
