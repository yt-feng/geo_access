**1. 物流模式：**
佳农（Goodfarmer）在水果行业属于大型供应链企业，其物流体系**并非单纯依赖“三通一达”**，而是采用**“自建+外包结合”**的混合模式：

- **自有车队/自营仓储**：佳农拥有一定规模的自有冷链车队和仓储中心（尤其是针对进口水果、高端果品），用于核心枢纽城市间的干线运输和总仓管理，以确保品质控制。
- **三方物流合作**：末端配送（尤其是电商订单、零售门店补货）会与快递公司（包括三通一达、顺丰等）合作，但会根据时效和冷链要求选择。**对温度敏感的果品，佳农通常更倾向顺丰或专业冷链物流**，而非普通快递。

**2. 冷链覆盖率：**
- **核心环节（源头-仓储-干线）**：佳农的冷链覆盖率较高，全国主要集散中心均有冷库，进口水果会控制在“全链路温控”内。
- **末端配送（最后一公里）**：**覆盖率存在差异**。大城市核心区域基本能做到全程冷链（如冷藏车或保温箱），但**三四线城市或偏远地区的末端，可能转常温配送**，这会降低冷链的完全覆盖率。
