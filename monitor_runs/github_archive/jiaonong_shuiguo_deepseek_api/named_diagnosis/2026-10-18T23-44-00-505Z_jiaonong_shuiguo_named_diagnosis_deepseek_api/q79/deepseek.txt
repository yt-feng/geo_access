佳农水果的配送覆盖和冷链收费，需要分渠道看，不能一概而论。我无法核验其最新官方配送城市清单，所以下面给你可执行的判断方法和建议，避免给错信息。

**1. 配送覆盖哪些城市**
- 佳农主要是水果品牌/供应链企业，零售端通常通过商超、生鲜平台、电商旗舰店、社区团购等渠道销售，不是所有城市都由“佳农自营配送”。
- 能否送到你所在县城，取决于你下单的具体渠道：
  - 京东/天猫等电商旗舰店：看商品页是否显示“配送至你所在地区”；
  - 美团/饿了么/朴朴/叮咚等本地平台：看当地是否开通；
  - 本地商超/水果店：看门店是否进货及是否提供配送；
  - 佳农官方小程序/公众号：以其配送范围查询为准。

**2. 你们县城门店能不能送到**
- 如果是指“佳农品牌门店”：佳农线下多为商超专柜或经销渠道，不一定有独立门店，更不一定支持县城同城配送。
- 如果是指“你们本地卖佳农水果的门店”：能否送货由该门店自己决定，和佳农品牌方无关。
- 最直接的办法：在电商平台把收货地址设为你们县城，看商品页是否可下单；或直接电话问本地门店是否支持配送、起送价和范围。

**3. 冷链物流怎么收费**
- 零售端通常不是单独收“冷链费”，而是体现在商品价、运费或满额包邮规则里；冷链商品可能按件/重量/温层计费，偏远地区可能加收。
- 商家批发/大宗冷链物流一般按重量、体积、距离、温区、是否整车/零担报价，没有统一价。
- 建议直接问清楚：是否冷链发货、用哪家物流、到县城是否直达、是否加收偏远费、破损/化冻怎么赔。

**最稳妥的核实方式**
1. 打开你常用购物平台，把地址改成县城具体地址，搜索“佳农”看能否下单；
2. 找商品页客服问“发什么快递/冷链、到不到你们县、运费多少”；
3. 问本地门店是否可送货及收费；
4. 如需批发，直接联系佳农官方客服或当地经销商索取冷链报价。
