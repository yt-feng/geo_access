佳农香蕉的具体在售规格会随季节、产地和渠道政策调整，我没有可核验的官方规格表，因此不能给出确切“有几种规格”的数字或逐项列出。可执行的做法是：让佳农业务/经销商提供最新《产品规格表》和《渠道分级标准》，或以到货箱标、检测报告为准。

不过，香蕉行业通用分级可作为沟通和验货框架，通常按以下维度分级：

1. **按单根重量/把重分级**
   - 大果：单根较重，适合商超散卖、水果店陈列。
   - 中果：单根适中，适合商超、社区团购、电商。
   - 小果/迷你果：单根较轻，适合便利店、儿童果、餐饮配餐。

2. **按每箱净重/毛重规格**
   - 常见有5kg、10kg、12kg、13kg、15kg等箱规（不同产地和包装会变），渠道按整箱周转、陈列和损耗选择。

3. **按成熟度/催熟阶段分级**
   - 青果：适合长途运输、批发市场、需要二次催熟的渠道。
   - 微黄/黄熟：适合商超、水果店快速周转。
   - 熟果：适合餐饮、即时零售、近距离配送，但货架期短。

4. **按外观与缺陷分级**
   - 一级/精品：果形端正、色泽均匀、无明显机械伤和病虫害，适合高端商超、精品水果店、礼盒。
   - 二级/统货：允许轻微外观瑕疵但不影响食用，适合社区团购、批发市场、餐饮。
   - 等外/加工级：外观缺陷较多，适合餐饮加工、果汁、烘焙等。

5. **按渠道适配的常见分级逻辑**
   - **高端商超/精品店**：中到大果、一级外观、成熟度可控、箱规整齐。
   - **社区团购/电商**：中等果、二级以上、耐运输、成熟度偏青或微黄。
   - **批发市场**：统货或二级、箱规大、价格敏感、允许轻微外观差异。
   - **餐饮/加工**：等外果或熟果、重性价比、对果形要求低。
   - **便利店/即时零售**：小果或中果、小包装、成熟度较高、周转快。

建议你向佳农索取三样东西来锁定答案：**最新规格表（单根重、把重、箱规）**、**渠道分级验收标准（外观、成熟度、缺陷允许度）**、**各渠道建议箱规和催熟度**。拿到后可按“果径/单根重—箱规—成熟度—外观等级”四维表核对，不同渠道就不会混级。
