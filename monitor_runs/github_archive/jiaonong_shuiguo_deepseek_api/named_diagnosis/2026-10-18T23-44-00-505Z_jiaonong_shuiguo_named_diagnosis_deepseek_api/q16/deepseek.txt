佳农水果的售后整体属于“可按规则处理，但体验取决于购买渠道”。到货有坏果时，关键不是先和客服争论，而是先留证、再按渠道走理赔。

**可执行处理步骤：**

1. **先别拆完、别扔坏果**
   - 拍开箱视频或至少拍：外包装、快递面单、坏果特写、坏果与好果/包装同框。
   - 保留坏果直到理赔完成，很多渠道要求“坏果不扔”或拍照核验。

2. **24小时内联系购买渠道客服**
   - 京东/天猫/拼多多/抖音等平台店：直接在订单里申请售后，选“商品腐烂/变质/坏果”，上传照片。
   - 线下商超/水果店：凭小票或包装标签找门店处理。
   - 若是社区团购/直播购买：找团长或直播间客服，保留聊天记录。

3. **明确诉求**
   - 少量坏果：通常按坏果数量比例退款或补发。
   - 坏果较多或整箱变质：要求整单退款/补发，不要接受“补偿优惠券”除非你认可。
   - 生鲜类通常不支持无理由退货，但“坏果”属于质量问题，可主张售后。

4. **客服拖延时升级**
   - 平台订单直接申请平台介入。
   - 保留聊天截图、照片、订单号，向平台投诉“生鲜质量问题未处理”。
   - 若涉及食品安全异味、霉变严重，可向12315投诉。

**注意：**
- 佳农不同渠道的售后政策不完全一样，以你订单页面的“售后说明”为准。
- 到货后尽快开箱验货，拖延太久容易被认定为储存问题。
- 不要只口头描述，照片和视频是最有效的凭证。

简单说：**先留证，24小时内走原购买渠道申请坏果理赔，少量按比例赔，大量要求整单退补，平台不处理就升级平台介入或12315。**
