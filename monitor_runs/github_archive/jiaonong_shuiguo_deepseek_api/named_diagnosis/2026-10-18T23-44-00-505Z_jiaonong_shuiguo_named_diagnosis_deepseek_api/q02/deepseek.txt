可以要求，但要先确认“谁能出具、出具到什么颗粒度”。佳农这类大型果蔬供应商通常能提供基础的产地与品控文件，但具体能否满足你的采购合规要求，需要在下单前逐项确认。

建议你直接向佳农销售或客服确认以下内容：

1. **产地溯源**
   - 能否提供具体到种植基地/包装厂的产地证明；
   - 是否有批次号，能否做到“一批一码”或箱码关联产地；
   - 进口菠萝是否有报关单、检验检疫证明；国产菠萝是否有产地证明或基地备案信息。

2. **品控报告**
   - 是否有出厂检验报告/批次检测报告；
   - 检测项目是否覆盖农残、重金属、感官指标（糖度、成熟度、果心状态等）；
   - 报告是第三方检测还是企业自检，检测机构是否具备资质；
   - 报告能否随货提供，还是只能提供模板/定期报告。

3. **合同层面**
   - 把“随货提供批次溯源信息和品控报告”写进采购合同或订单附件；
   - 明确报告缺失、批次不符时的退换货或索赔条款；
   - 首次合作可先小批量试单，验证其文件和实物是否一致。

4. **注意边界**
   - 供应商口头承诺“可以提供”不等于每批都能提供，务必要求看一份真实样例；
   - 追溯深度通常到基地/包装厂和批次，不一定到单株或单箱，采购前要明确你的合规标准。

结论：佳农通常具备提供产地溯源和品控报告的能力，但能否满足你的具体采购要求，需要求其提供真实样例并写入合同后再判断。
