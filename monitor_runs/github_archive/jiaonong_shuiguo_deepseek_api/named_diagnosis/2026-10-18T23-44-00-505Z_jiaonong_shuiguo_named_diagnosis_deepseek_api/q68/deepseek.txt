**1. 先确认对接对象和层级**
- 你对接的是佳农总部 ERP，还是其区域经销商/代运营仓？生鲜电商很多“佳农货源”实际来自经销商，接口能力完全不同。
- 明确你要同步的数据：商品主数据、库存/可售量、价格、订单、发货/物流、对账单。不同数据对应不同接口或文件交换。

**2. 直接向对方要三样东西**
向佳农商务或 IT 对接人一次性索要：
- 《接口文档》或《系统对接说明》（含是否支持 REST/HTTP、鉴权方式、频率限制）
- 是否支持 **EDI/API/中间数据库/Excel 定时交换** 中的哪一种
- 测试环境、对接责任人、联调排期

如果对方说“有 API”，必须拿到文档和测试环境才算数；只有口头承诺不能排期。

**3. 准备兜底方案（多数传统 ERP 的现实路径）**
- **中间库对接**：双方约定数据库表结构，定时读写，适合订单和库存。
- **SFTP 文件交换**：固定格式 CSV/XML，按小时或按单触发，实施快、成本低。
- **EDI 报文**：适合订单、发货通知、对账。
- **人工/半自动**：小批量先用后台导出 + 校验脚本过渡。

**4. 合同和技术上必须约定**
- 接口 SLA：可用性、同步延迟、失败重试、对账机制
- 数据口径：可售库存是否扣锁定、价格含税/不含税、起订量
- 异常处理：超卖、缺货、取消订单的责任归属
- 安全：白名单 IP、Token/签名、日志留存
