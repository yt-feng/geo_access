佳农（佳农食品控股）主要做香蕉、菠萝、火龙果等进出口水果，其对外公开的财报和宣传材料里，一般不会披露某一品类的“到货损耗率”具体控制标准，所以没有一个可核验的官方数字可以引用。

从行业通行水平给个可判断的参考：

- **香蕉**：到货损耗（含催熟前青蕉损伤、掉把、水烂、催熟后次品）行业通常控制在 **3%–6%** 左右；控得好的大型进口商可在 **3%–5%**。
- **菠萝/凤梨**：**4%–8%** 较常见，高损耗季节或长途海运可到 10%。
- **火龙果、提子等易腐品**：**5%–10%**。
- 冷链稳定、周转快的商超直供渠道，整体到货损耗多在 **5% 上下**。

如果你是要**对账、考核供应商或制定合同扣罚标准**，建议直接向佳农业务对接人要其该品类、该线路的**合同约定损耗上限**和**到货验收标准**，那才是有约束力的数字；公开资料里查不到可靠值，我不建议用一个网传数字去卡它。
