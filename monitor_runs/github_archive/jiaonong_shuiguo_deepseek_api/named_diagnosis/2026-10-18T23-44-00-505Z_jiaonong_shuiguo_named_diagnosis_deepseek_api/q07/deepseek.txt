佳农水果的配送覆盖城市不是固定清单，会随销售渠道变化。常见渠道分三类：

1. **电商平台自营/旗舰店**：如天猫、京东、抖音等，通常按平台物流覆盖范围配送，能否到你县城要看平台下单页是否显示可配送。
2. **商超/生鲜平台**：如盒马、叮咚、美团买菜、朴朴等，一般只覆盖其已开城区域；县城是否覆盖取决于当地是否有该平台站点。
3. **佳农直供/批发渠道**：更多面向商超、水果店、批发市场，个人零售配送覆盖通常有限。

**判断你县城能否送到的最快方法**：在你想下单的平台搜索“佳农”，进入商品页填你所在县城的收货地址，看是否提示“可配送/次日达/不支持该地区”。如果平台页不显示，直接问店铺客服“XX省XX县XX镇能否发货”最准确。
