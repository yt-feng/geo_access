1. **先明确你要的是哪类香蕉片**
   - **鲜切香蕉片**：冷藏短保，通常按袋/盒，适合门店现用，保质期很短。
   - **冷冻香蕉片**：速冻单体，适合餐饮连锁中央厨房或门店解冻使用。
   - **香蕉干/脆片**：常温休闲食品，不是餐饮鲜切原料。

   - 找佳农官方客服或当地经销商，问三个关键点：**是否有鲜切/冷冻香蕉片、最小起订量、供货区域**。

3. **规格必须让对方书面确认**
