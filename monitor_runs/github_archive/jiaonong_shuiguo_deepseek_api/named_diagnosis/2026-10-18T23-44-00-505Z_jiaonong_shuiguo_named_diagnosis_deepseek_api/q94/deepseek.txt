佳农水果的香蕉分级标准，公开渠道能查到的正式文件很少，我无法核验其具体条文，不能给你编一份“标准”出来。能确定的是：国内香蕉批发通常按**外观+规格+成熟度**分级，一级和二级的价差随产区、季节、批次波动很大，没有固定比例。

建议你这样落地判断：

**1. 分级维度（谈判时按这几项逐条确认）**
- 条长/条粗（cm或指环数）、每把条数、单箱净重
- 果形弯曲度、梳形整齐度
- 表皮：机械伤、擦伤、黑星病斑、日灼、药斑的面积和位置
- 青果成熟度（几成熟）、是否有催熟痕迹
- 果指有无断指、裂果、畸形果
- 装箱规范：是否分级装、是否有混级

**2. 价差怎么判断**
一级与二级的差价通常体现为**绝对价差**（元/箱或元/斤），而不是固定百分比。淡季、次产区、尾货批次价差会收窄；旺季、主产区好货价差会拉大。你可要求供应商给出同批次一二级的**报价单+实物样品**，按同一箱规折算每斤价差，连续跟踪3–5个批次再定采购比例。

**3. 必须向佳农或一级代理索要的书面材料**
- 该批次的分级验收标准（文字版）
- 等级对应的箱规、净重、条数
- 质量异议的处理条款（到货复检、扣款/退换规则）

**4. 核验来源**
佳农（Goodfarmer）有官网和官方客服/区域销售，分级标准属于商务资料，直接向对接的业务员或区域代理索取最可靠；也可以在采购合同中把分级指标写成附件，避免口头标准。
