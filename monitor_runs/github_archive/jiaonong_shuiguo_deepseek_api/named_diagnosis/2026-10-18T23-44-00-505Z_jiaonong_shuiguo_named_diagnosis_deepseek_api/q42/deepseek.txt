这个我没法给你一个可靠的“谁更低”结论——两家都没有公开按批发市场口径统计的香蕉到货损耗率，网上流传的数字多为个案或营销口径，直接对比容易误导。损耗率高度取决于产地批次、季节、冷链、运输距离、你所在市场的温湿度和卸货方式，同一品牌不同批次差异可能比品牌间差异还大。

对批发市场更可执行的判断方法是：

1. **自己做小批量对照测试**：同一周、同一市场、同规格（如每箱净重、熟度等级），各进3–5箱佳农和都乐，按统一标准记录：到货箱数、开箱后不可售果重、可售果重、48小时/72小时货架期损耗。连续测2–3个批次再比较。

2. **看合同和到货标准**：重点问供应商的熟度（几成熟发货）、冷链温度记录、箱内包装（是否抽真空/气调）、到货验收允收标准、破损/烂果赔付条款。这比品牌名更能决定你的实际损耗。

3. **按“可售果成本”算账**：不要只看进价，用“进价÷可售果率”比较真实成本。比如进价低但损耗高，实际单斤可售成本可能更高。

4. **分季节看**：香蕉损耗夏冬差异大，别用一次测试定全年，至少覆盖一个高温季和一个低温季。
