佳农水果（佳农食品控股/Goodfarmer）公开对外强调“产地直采、全球供应链”，但**具体“产地直供比例”没有稳定公开的可核验数字**，不宜给出确定百分比。可以判断的是：它并非全部自营果园直供，而是“自有/合作基地直采 + 海外产区采购 + 进口分销”混合模式；香蕉、菠萝等核心品类的直采和产区绑定相对更强，但不同年份、品类差异较大。

香蕉方面，佳农是较大的香蕉进口商之一，主要来源国通常包括：

- **厄瓜多尔**
- **菲律宾**
- **越南**
- **哥伦比亚**
- **哥斯达黎加**
- **墨西哥**
- 部分年份也会涉及**泰国、柬埔寨、印尼**等

其中厄瓜多尔、菲律宾、越南是较常见的核心来源；具体占比会随产季、价格、检疫和航线变化。若你要判断“直供比例高不高”，建议看其招股书/年报、客户供应商集中度和“自有基地面积”披露；仅凭宣传口径不足以认定比例很高。
