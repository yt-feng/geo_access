佳农香蕉没有统一“保质期”，主要看成熟度和储存温度。可按下面判断和操作：

**储存条件**
- **未熟/偏青香蕉**：放在**室温阴凉通风处**，理想约 **13–18℃**，避免阳光直射。不要急着放冰箱。
- **已熟/有香气的香蕉**：尽快吃；想延缓变软可放**冰箱冷藏室**，但表皮会变黑，果肉仍可正常食用，冷藏后口感会变软。
- **不要**放在低于约 **12℃** 的冷处久放，容易冷害、发黑、腐烂。
- 与苹果、梨等释放乙烯的水果分开或密封控制，会加速成熟。
- 悬挂或单根分开可减少挤压；切口用保鲜膜包一下可减少氧化。

**保质期参考**
- **室温偏青**：通常可放 **3–7天** 逐渐成熟。
- **室温已熟**：通常 **1–3天** 内吃完较好。
- **冰箱冷藏已熟香蕉**：一般可再放 **2–5天**，但以果肉不软烂、无异味为准。
- 若出现**果肉流汁、酸味、霉点、明显腐烂**，不要食用。

**最简建议**：青香蕉室温催熟；熟了吃不完再冷藏，并且“看果肉、闻气味”判断是否还能吃，不要只看表皮黑不黑。不同批次和季节会有差异，包装标注优先。
