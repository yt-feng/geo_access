**有，佳农确实有适合小面积门店的小包装规格。**  
针对便利店的陈列和周转需求，佳农（特别是其“佳农优选”或“佳农果业”系列）通常提供以下几种常见的小规格（具体以您所在区域经销商的实际库存为准）：

1. **香蕉（3kg装）**：确实存在。这是佳农香蕉的常用小箱规格，约5-6把，适合单店日销5-8把的便利店。比大箱（10kg或13kg）更灵活，减少损耗。
2. **单果礼盒/小盒装**：如菠萝、蓝莓、牛油果等，常以1kg或500g左右的小盒出售，适合直接进冷风柜。
3. **袋装或网袋装**：比如苹果、橙子，有2-2.5kg的袋装（网袋），方便顾客提走。
4. **小箱混合**：如果实在找不到3kg单品，可向经销商要求拼箱（如香蕉2kg+苹果1.5kg），但通常需要和批发商谈。
