**1. 现行国家/行业通用标准**

国内香蕉鲜果（主要用于鲜食）目前主要依据以下标准：

- **国标/行标**：**GB/T 30467-2013《香蕉》**（适用于香蕉鲜果的商品等级）以及 **NY/T 1386-2007《香蕉》**（农业行业标准）。其中GB/T 30467-2013是最常用的等级划分依据。

**2. 国标中关于糖度和果指长度的规定**

- **糖度（可溶性固形物，Brix%）**：GB/T 30467-2013 **并没有规定统一的糖度数值**作为分等级硬性指标。它主要依据外观、成熟度（黄熟程度）划分等级。不过，行业普遍将香蕉可溶性固形物（糖度）分为三个范围：
  - 果肉糖度≥20%可视为优等品（高甜度）；
  - 18%~20%为中等；
  - 低于18%通常被认为口感偏淡，多见于未成熟或青蕉。
  
  实际上，国标更看重“成熟度”而非具体糖度值。

- **果指长度（单根蕉果长度）**：GB/T 30467-2013明确按果指长度分为**特级、一级、二级**：
  - **特级**：果指长≥**22cm**（不含果柄）；
  - **一级**：≥**19cm**；
  - **二级**：≥**16cm**。
  （注：该标准针对的是整梳或整把香蕉的果指平均长度，且通常要求同一把内均匀度好）

- **糖度**：佳农通常强调“香甜软糯”，企标可能要求成熟可食期糖度**≥20%~22%**，高于国标一般水平（国标未强制规定，但商业惯例是≥18%~19%即可销售）。
  
- **果指长度**：佳农对外宣传通常强调“大果形”，其企标有可能将**特级果指长度提升至≥24cm**（或一级≥21cm），比国标高1~2cm，以体现高端定位和更好的卖相。
