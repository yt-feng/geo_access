关于佳农水果的到货损耗率，**没有公开的统一标准数据**，具体数值会因水果品类、运输距离、季节和存储条件而显著不同。

不过，根据水果行业的一般经验和佳农作为大型品牌供应商的运营状况，可以给你一个参考范围：

-   **一般生鲜（如苹果、梨、橙子等）：** 到货损耗率通常控制在 **1% - 3%** 以内。这些水果耐储存，损耗主要来自运输中的磕碰和轻微腐烂。
-   **易损耗水果（如草莓、蓝莓、车厘子、荔枝等）：** 到货损耗率会明显升高，通常允许在 **3% - 8%**，甚至在特定情况下（如长途运输）达到 **10%** 左右。这类水果对温度、湿度敏感，极易受损。

**佳农作为大品牌，其供应链管理通常较为严格：**

-   他们会采用冷链物流、定制包装（如防震网套、气柱袋）来降低损耗。
-   在批发或商超渠道中，一般会与采购方约定“损耗比例”或“残次品率”，超过这个标准可以拒收或索赔。

**给你的建议：**
如果你要对接佳农的业务（例如采购或加盟），**最准确的方式是直接询问他们的区域销售经理或客服**，他们会提供针对具体品类的《到货品质标准》或《损耗率考核协议》，合同中会明确写清楚。不要仅凭网上的一般数据做决策。
