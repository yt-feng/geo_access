您好！关于佳农香蕉的到货损耗率承诺，我需要说明一下：

**目前我无法直接确认佳农官方或经销商的统一损耗赔付标准。** 这类政策通常由品牌方或区域经销商根据合作条款单独约定，不同渠道、不同采购量可能有差异。

不过，给您几个**实操建议**：

1. **直接问采购渠道**：如果是通过经销商或批发市场进货，务必在签合同时明确“到货损耗率”和“赔付标准”（例如：高于3%的部分如何补偿、是否按进价折损）。口头承诺不算数，最好落到合同或订单备注里。

2. **品牌官方渠道**：如果是通过佳农官方销售（如官网、官方小程序或授权平台），可以询问是否有“标准损耗补贴”政策。有些品牌对合作门店有固定支持，但可能要求整箱完好、无挤压等前提。

3. **物理损耗控制**：
   - 到货后第一时间开箱检查，拍照留证（损坏、霉变、压伤部分单独称重）。
   - 如果损耗率高，要区分是运输问题（物流责任）还是香蕉成熟度导致的自然损耗（通常不赔）。
   - 建议初次合作先小批量试单，观察质量与损耗，再谈长期条款。

4. **替代方案**：如果对损耗非常担心，可以考虑先找当地水果批发市场拿货，现场看货、按需拿货，减少仓储和运输环节的损耗。

最后提醒：**任何口头承诺都不可靠**，签合同或订单备注时把“损耗率＞3%部分包赔”写清楚，并明确赔付方式（现金、补货、抵扣货款）。如果对方拒绝写入，建议换供应商比较稳妥。
