### 二、物流成本怎么算？

水果一件代发的物流成本主要由**冷链仓配费用 + 包装费 + 快递费**构成。按常见模式，假设你发一箱5斤装的苹果：

| 费用项目 | 计算方式 | 参考金额（元） |
|---------|---------|-------------|
| 打包费（含纸箱、泡沫箱、保鲜冰袋） | 按件固定 | 2~5元 |
| 冷链运输（从产地/仓库到本地中转） | 按重量或件数 | 3~6元/件 |
| 末端快递（同城/跨省） | 按首重+续重 | 8~15元/件（跨省更贵） |
| 平台佣金/手续费 | 若走团购平台 | 订单金额的2%~10% |

**关键成本变量**：
- **距离**：同城发（如本地仓）成本低，跨省发则需加“冷链大件”费用。
- **重量**：佳农水果如金果、蓝莓等单价高但轻；香蕉、西瓜等重物则运费占比高。
- **售后损耗**：生鲜物流破损率约3%~5%，需预留2~3元/件的赔付成本。

**总成本估算（以5斤装、跨省发货为例）**：
- 打包费3元 + 冷链运输5元 + 末端快递12元 = **约20元/件**（不含平台佣金）。
- 如果是同城（如品牌本地仓发货），可降到 **10~12元/件**。
