佳农水果的产地直供比例相对较高，其核心策略是与海外农场直接合作，减少中间环节。具体来说，佳农的直供比例通常在**70%-80%**左右（因品类和季节略有浮动），尤其以进口水果为主。

关于香蕉，佳农的主要供应国包括：
- **菲律宾**（主产区，占比较大，品质稳定）
- **厄瓜多尔**（南美产区，供货期长，口感偏甜）
- **哥斯达黎加**（中美洲产区，用于补充特定季节需求）

此外，佳农也有部分来自老挝、柬埔寨等东南亚国家的货源，以应对不同市场的需求波动。整体上，香蕉是其直采体系中最成熟的品类之一，从种植到冷链运输的链条相对完善。如需更精确的实时数据，建议直接查阅佳农官方公告或渠道商信息。
