**1. 佳农香蕉分级标准（行业通用参考）**
佳农作为大型水果品牌，通常遵循国内香蕉行业标准（如GB/T 20159-2006《香蕉》）并结合自身品控，常按以下维度分级：
- **果指长度**：一级果单指长度通常≥19cm，二级果≥15cm。
- **果面完整度**：一级果要求无机械伤、无病虫害、无斑点；二级果允许轻微瑕疵（如少量黑点、轻擦伤）。
- **成熟度控制**：一级果成熟度均匀，色泽金黄；二级果允许成熟度稍不均或果柄有轻微变色。
- **重量与外形**：一级果每把重量更均匀，果形弯曲度标准；二级果允许稍短或略弯曲。
