关于佳农水果的配送时效，具体时间会因**下单渠道（如佳农官方小程序、天猫旗舰店、京东自营等）**、**收货地址**以及**所选快递**有所不同。

通常情况下的参考标准如下：

1.  **一线及新一线城市（如北上广深、杭州、成都等）：** 若商家承诺“次日达”或“当日达”，且你在当天截单时间（通常为下午14:00-16:00）前下单，一般**1-2天**内可以送达。
2.  **二三线城市及偏远地区：** 由于涉及更长的运输链路，通常需要**2-3天**，部分偏远地区可能**3-5天**。
3.  **生鲜冷链配送：** 佳农多数水果采用顺丰或京东冷链，如果仓库有现货且发出快件，时效会更有保障；但若遇到节假日大促或天气原因，可能会有**1天左右的延迟**。

**最准确的查询方式：**
建议你直接在**下单页面的“配送说明”**或**联系在线客服**时输入具体收货地址，系统会给出精确的预计送达时间。另外，支付前留意是否标注了“预售”或“48小时内发货”，预售商品通常需要等待更久。

如果你已下单，可以通过订单详情页的物流轨迹实时查看派送进度。若有急需，建议优先选择“京东自营”或“天猫超市”这类平台仓发货的链接，时效更稳定。
