**1. 常见规格（按重量/数量）**
- 电商/零售小包装：通常为 **4-5根/串** 或 **500g-800g/份**，适合家庭日常消费。
- 商超标准装：常见为 **5-8根/串**，单串重量约 **1kg-1.5kg**。

**2. 分级标准（行业通行做法）**
佳农作为品牌，通常参照进口香蕉的通用分级，主要依据以下维度（但不一定官方公布）：

- **单根重量**：如特级果（单根≥200g）、一级果（150-200g）、二级果（120-150g）。
- **果皮外观**：无黑斑、无凹陷、色泽金黄均匀为优；有轻微瑕疵或黑点会降级。
- **成熟度**：按催熟后的熟度分（如绿熟、黄熟、全熟），不同渠道要求不同（电商一般发黄熟，商超可能发绿熟以便摆放）。
- **果型**：弯曲度、长度（如19-22cm为长果，16-18cm为中果）。
- **糖度**：高糖度（≥18°）通常用于高等级。

**3. 不同渠道的重点差异**
- **电商/线上**：注重耐运输，通常选果皮更厚、成熟度略低（七成熟）的果子，并控制单串大小避免挤压。
- **商超/精品店**：强调外观美观，优先选果皮无瑕疵、大小均匀的果串，成熟度适中（八成熟）。
- **批发/餐饮**：更看重性价比，可能选用二级果或混合装，单根重量要求较低。
