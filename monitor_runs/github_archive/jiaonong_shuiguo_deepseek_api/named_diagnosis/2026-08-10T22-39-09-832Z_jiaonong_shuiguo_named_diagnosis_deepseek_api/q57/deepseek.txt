关于香蕉的到货损耗率，行业内通常有一个“自然损耗”的基准区间（一般在3%到8%之间，你说的5%是比较常见的行业平均值）。但具体到**佳农（JiaNong）**这家公司：

1.  **佳农的实际损耗率**：佳农作为国内头部的水果供应链企业，其香蕉品控标准通常比行业平均水平更严格。他们自有基地和冷链投入较大，在正常成熟度采收和物流条件下，**广州/上海/北京等主要销售区域的到货损耗率通常能控制在2%-4%之间**，具体取决于销售渠道（如商超直供、电商件或批发市场）和运输距离。如果走的是远途海运（比如东南亚产地到内地），损耗率会略高。

2.  **是否有赔付条款**：**有，但通常不是“损耗多少赔多少”的固定条款，而是采用“阶梯式赔付”或“质量等级条款”**。具体形式如下：
    -   **按批次赔付**：如果单批到货的“烂果率”“碰伤率”超过合同约定的阈值（例如超过3%或5%），超出部分会按采购价进行补偿或补发。这部分核心看你们签订的合作协议（采购合同），而非行业默认。
    -   **质量分级赔付**：如果到货成熟度过高（黄熟）导致无法售卖，或者出现黑心、水烂等问题，一般会做“折价处理”或“全额退换”。
    -   **电商/零售渠道**：如果你是在京东、盒马等平台购买，平台自带“坏果包赔”服务；水果连锁店（百果园等）则提供“不好吃三无退货”规则，但这是零售端承诺，不是针对B端批发客户的赔付条款。

**关键提示**：如果你是批发商或零售商，**赔付条款绝不是口头约定的，必须在采购合同中明确列出**（包括损耗率阈值、检测方法、赔付比例和赔付时限）。如果对方承诺“小于等于3%损耗”，建议在合同里写清楚“超过3%的部分按实际损失金额100%赔付”。
