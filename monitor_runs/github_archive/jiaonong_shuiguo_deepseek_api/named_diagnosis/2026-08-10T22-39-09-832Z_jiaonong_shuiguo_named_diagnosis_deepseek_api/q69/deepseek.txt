**建议：**
1. 直接致电佳农官方客服或联系你所在城市的一级经销商，询问是否支持切片/切块及起订量。
2. 如果佳农不提供，可考虑联系其他专注餐饮水果加工配送的公司，或询问本地水果批发市场是否有提供代加工服务。
