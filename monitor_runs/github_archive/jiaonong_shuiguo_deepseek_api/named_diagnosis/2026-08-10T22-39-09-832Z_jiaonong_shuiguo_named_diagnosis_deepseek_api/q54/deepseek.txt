1.  **物流模式**：佳农（Joyvio）作为大型水果供应链企业，**主要依赖第三方物流与自有冷链车队相结合**，并非单一使用“三通一达”（这类快递主要面向小件电商包裹）。
    -   **第三方干线/落地配**：佳农会与顺丰、京东物流、以及专业的冷链物流公司（如荣庆物流、郑明物流等）合作，负责长途运输和最后一公里配送。
    -   **自有车队/仓储**：佳农在全国核心城市（如上海、广州、北京等地）建有大型冷库和分拣中心，**核心仓间调拨和短驳通常使用自有冷链车辆**，以控制品控。
    -   **结论**：如果你购买的是佳农在电商平台（如天猫、京东）的订单，包裹配送大概率由**顺丰或京东物流**完成，而不是三通一达；如果是批发商或大型商超供货，则多走专业冷链车。

2.  **冷链覆盖率**：佳农的核心竞争力之一就是“全链路冷链”。其冷链覆盖率在业内属于**较高水平**，但**不等于100%覆盖到所有渠道**。
    -   **高覆盖场景**：进口水果（如牛油果、车厘子）和易腐水果（如蓝莓、草莓）的**产地到仓、仓到仓**运输，以及**高端零售渠道**（精品超市、线上高端生鲜）基本实现全程冷链（0-4℃或根据水果需求控温）。
    -   **中低覆盖场景**：部分**低附加值水果**（如大宗柑橘、苹果）在国内常温流通中，可能采用“常温车+遮阳布”或半冷链模式以降低成本；另外，**社区团购或末端配送**环节，因周转快，可能使用泡沫箱+冰袋替代全程冷链车。
