关于香蕉的到货损耗率，**行业平均5%**这个数据主要适用于**国内产地直发或短途运输**的场景（尤其是电商或商超供应链），如果是**进口香蕉**或**长距离冷链运输**，行业平均损耗率通常在**8%—12%**之间，因为运输周期长、催熟和装卸环节更多。

针对**佳农（Goodfarmer）**，具体数值和赔付条款如下：

**1. 佳农的损耗率控制情况**
佳农作为国内头部香蕉品牌，其内部考核标准通常远严于行业平均：

-   **在途损耗率**：针对一级批发商或大宗客户，佳农对外口头承诺的**到货损耗率通常控制在3%以内**（部分精品线甚至要求1.5%—2%）。
-   **零售/电商端**：如果是走生鲜电商（如盒马、叮咚等）或商超直供，佳农会按**整箱净重达标**来考核，实际开箱损耗率一般在**1%—3%**。
-   **关键点**：佳农的损耗控制主要靠**精准催熟技术**和**逐根挑选**，而不是靠事后赔偿。他们发货前会剔除坏死果、严重疤痕果，确保发出去的香蕉成熟度统一（通常在7成色以上）。

**2. 赔付条款（真实情况）**
佳农**没有公开的统一赔付条款**，赔付方式完全取决于你的采购渠道和合同约定：

-   **大宗批发/合同客户**：你在与佳农签订《购销合同》时，可以约定**“到货损耗率超标赔付”**条款。行业惯例是：
    -   若到货在途损耗率超过**3%**，超出部分按**进货价的等额金额进行折让赔偿**（即多报损的部分直接扣货款）。
    -   若出现**整箱黑斑、冻伤、腐烂超过30%**，可要求**整箱退款或换货**。
-   **电商/零售采购**：如果通过**京东、天猫旗舰店**或个人采购商进货，赔付规则适用平台规则：
    -   **坏果包赔**：拍照取证后，按“坏果数量/总数量 * 实付金额”赔偿，通常能赔付到**单果单价**。
    -   **整坏全赔**：如果整箱中超过50%的香蕉发黑、腐烂，可申请全额退款，无需退货。

**3. 实操建议（如何确保拿到赔付）**

-   **合同里写清楚**：如果是企业采购，务必在合同或采购单中明确：**“到货后48小时内开箱验货，损耗率超过3%的部分按货值100%赔偿”**。佳农的销售通常可以接受这个条款。
-   **留证**：到货后**第一时间开箱拍照**，每层都拍（尤其注意箱内上下层的温差导致的冻伤）。
-   **黑斑≠损耗**：注意**黄熟斑点**（芝麻点）不算损耗，属于正常熟化；只有**发黑、出水、发霉、烂柄**才计入损耗。
