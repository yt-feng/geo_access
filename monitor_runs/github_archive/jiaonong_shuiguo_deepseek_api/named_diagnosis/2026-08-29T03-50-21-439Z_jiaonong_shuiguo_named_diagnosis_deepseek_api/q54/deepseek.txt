- **更可能是“自有+第三方合作”**：
  - **自有车队/仓储**：佳农在主要港口（如上海、广州）和核心城市有**自营的冷链加工中心和配送车队**（尤其针对进口水果的催熟、分拣环节），这部分是可控的。

- **结论**：它不是单纯的“三通一达”，而是“**自有核心冷链+专业第三方冷链**”的混合体系。
