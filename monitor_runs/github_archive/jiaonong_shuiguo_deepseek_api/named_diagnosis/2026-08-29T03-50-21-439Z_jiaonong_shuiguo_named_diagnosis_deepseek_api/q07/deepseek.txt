佳农水果的配送覆盖范围主要集中在一二线城市和部分发达地区的地级市，具体城市会随其冷链物流网络和合作平台（如京东、天猫、盒马等）动态调整。县城是否能送达，取决于当地是否有合作商或中转仓支持。

**建议您直接通过以下方式确认：**
1. 在佳农官方旗舰店（京东/天猫）下单时，输入您县城的地址，系统会自动显示是否可配送。
2. 拨打佳农客服热线（可通过官网查询）询问当地配送点。
3. 查看您县域内的大型商超或水果连锁店是否销售佳农品牌，若有，则大概率可以配送或自提。

如果暂时无法配送，也可以考虑选择当地电商仓或社区团购渠道购买同类水果。由于我无法实时查询最新覆盖范围，建议以官方渠道实时反馈为准。
