- **方案A：系统直连（最推荐）** —— 双方开发团队对接API，实现订单实时推送、库存查询。

- **方案C：人工+文件同步** —— 每日定时导出订单CSV，上传到佳农的FTP服务器。
  - *优点*：最简单，绝对兼容。
