关于佳农水果与盒马的合作模式，目前公开信息中没有明确披露其是“直供”还是“代销”，但根据行业惯例和盒马的运营特点，**大概率是“直采+代销”或“联营+产地直供”的混合模式**，而非传统意义上的买断式经销。具体你需要向双方采购部门核实。

**为什么这样判断？**
1. **盒马生鲜标签**：盒马强调“日日鲜”和“产地直采”，通常对生鲜水果采取**基地直采**（绕过批发市场），但采购后不买断库存，而是以**代销**（按实际销售结算）或**联营**（毛利分成）为主，以降低损耗风险。
2. **佳农是品牌商**：佳农作为进口水果商，更倾向于控价和品牌露出。与盒马合作时，大概率是**盒马采购下单，佳农供货，结算按销量扣点**，或盒马为佳农提供档期促销位，双方分毛利。
3. **非独家**：盒马常与供应商签“多品类战略合作协议”，但不会只绑定一家，佳农也同时供货山姆、永辉等。
