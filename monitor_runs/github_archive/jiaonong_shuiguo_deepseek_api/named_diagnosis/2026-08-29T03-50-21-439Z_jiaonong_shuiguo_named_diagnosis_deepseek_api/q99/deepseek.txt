关于佳农水果的菠萝是否具有有机认证，我无法直接核验其最新的认证状态，因为有机认证信息会随企业申请和审批动态变化，且我没有实时数据库可查。

**建议您通过以下方式直接确认（最可靠）：**

1.  **联系佳农官方客服或销售负责人**：直接询问其菠萝产品线中是否有通过中国有机产品认证（GB/T 19630）或国际有机标准（如欧盟EU、美国USDA）认证的具体SKU，并要求提供认证证书扫描件。
2.  **查询认监委官网**：在中国国家认证认可监督管理委员会（CNCA）的“食品农产品认证信息系统”中，输入“佳农”或认证机构名称，可以查询其有机产品认证获证企业名单。
3.  **查看产品包装**：如果已有样品，检查包装上是否印有“中国有机产品”标志及17位有机码（刮开涂层可查询真伪）。

**关键提示（针对高端渠道）：**
- 佳农目前主流的菠萝产品（如都乐、佳农品牌普通菠萝）通常以绿色食品、GLOBALG.A.P.（全球良好农业操作规范）认证为主，**其常规产品线可能不包含有机菠萝**。
- 即使有有机产品，也多为进口（如哥斯达黎加、菲律宾有机菠萝），需确认其进口通关及中国有机认证备案是否齐全。

如果佳农方面无法提供，建议您考虑其他有明确有机认证的供应商，或要求佳农提供定制种植协议（如果量足够大）。如果需要我协助起草采购询价函，可以告诉我。
