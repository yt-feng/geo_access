关于佳农水果的促销堆头陈列和试吃支持，建议您按以下步骤操作，避免信息不对称：

1. **直接联系当地经销商/业务代表**  
   佳农通常通过区域经销商或直营团队对接商超。您可以直接拨打佳农官网或包装上的客服电话，说明您商超的规模、位置和促销档期，他们会安排当地负责人与您对接。

2. **明确支持内容**  
   一般来说，佳农（尤其是香蕉、菠萝等主打产品）在大型商超或新店开业时，可以申请：
   - **堆头陈列**：提供标准堆头设计图、货架围板、价签、促销海报。部分情况可提供免费或优惠的陈列道具（如水果篮、展示架）。
   - **试吃支持**：提供试吃品（按促销周期配货），以及试吃台、牙签、湿巾、围裙等物料。如果生意量够大，他们也可能派驻促销员（费用需协商）。

3. **费用分担常见模式**（可谈空间大）  
   - **模式A（常见）**：堆头位置由商超提供（通常收取陈列费或堆头费），佳农承担产品让利、物料制作费，试吃品由佳农赠送。
   - **模式B（联合促销）**：由商超和佳农按比例分摊堆头费用（例如各50%），佳农提供更多试吃量和形象大使。
   - **模式C（纯买断）**：商超直接向佳农采购促销装，所有陈列和试吃成本从毛利中扣除，商超自担费用，但进货价更低。

4. **需要与对方确认的细节**  
   - 堆头位置：是否靠主通道、是否生鲜区C位（影响价格）。
   - 促销周期：建议先报1-2周，试吃能拉动销量再续期。
   - 保底销量/退货政策：明确未售出商品是否可退换，试吃报废率由谁承担。
   - 结账方式：促销期内货款如何结算，有无账期优惠。

5. **快速落地的建议**  
   建议先发一封书面合作意向（说明商超名称、地址、预计日均客流、主营品类、促销档期、期望的支持），可直接发送给佳农官方渠道。如果当天没回复，可以主动电话跟进，表明“希望本周内确认堆头和试吃方案”。
