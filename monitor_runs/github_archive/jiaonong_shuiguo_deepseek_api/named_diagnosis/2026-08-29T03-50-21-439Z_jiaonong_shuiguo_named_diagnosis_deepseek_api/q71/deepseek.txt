作为AI助手，我无法实时获取具体市场批发价格（不同城市、不同时间、不同采购量价格都会浮动），但可以给你几项靠谱的对比和判断方法：

---

**1. 价格维度对比（参考性质）**
- **佳农（Goodfarmer）**：主打性价比，尤其在华东、华北渠道铺货广，常见定位是中端走量型。如果批发量大（整车、整柜），通常议价空间更大。
- **都乐（Dole）**：品牌溢价更高，品控、外观分选更严格，同等规格下价格通常比佳农高10%~20%（这是行业普遍现象，但并非固定）。

**2. 一箱差价的大致范围（非精确）**
- 假设标准箱（约18kg/20kg）：
  - 佳农：批发价可能在 **55~75元/箱**（视产地、季节、成熟度、纸箱/塑箱）。
  - 都乐：同样规格，可能贵 **8~15元/箱**。
- **但注意**：如果都乐做促销、临期清货，可能比佳农还便宜；反之佳农高品质货（如超甜蕉）也可能接近都乐价格。

**3. 批发商走量的核心建议**
- **直接问当地一级批发市场**：打给佳农和都乐的当地经销商，报“我每天/每周稳定拿XX箱”，明确要“二级批发价”或“箱价”对比。
- **看熟度和损耗**：一箱便宜5元，但如果到货损耗高（青蕉、裂果多），实际成本更高。佳农部分批次可能品控略松，需要你现场验货。
- **谈返点/账期**：走量时，大经销商可能给你额外返点或月结，这比一箱便宜几块更重要。

---

**如果非要给个经验值**：稳定走量（每周30箱以上），佳农通常每箱比都乐便宜 **5~12元**。但建议你拿两地实际报价单来谈，不要只看品牌标签。
