这个问题没法直接给出“哪家更快”的确定答案，因为**配送速度高度依赖具体门店位置、订单品类、仓库布点和当日运力**，而不是品牌整体承诺。

但基于两家公司的供应链和华东市场布局，可以给你一个判断框架和实操建议：

1. **看仓库位置**：  
   - **佳农**在华东（尤其上海、嘉兴、苏州）有自建冷链仓配网络，部分品类在上海市内可做到当日或次日达。  
   - **鑫荣懋**作为全国性头部果业，在华东也有区域配送中心（如上海、太仓），但具体时效取决于其上海DC（配送中心）到你门店的距离。  
   - **关键点**：先让两家销售提供“你所在区/街道”的**客户配送覆盖表**和**最近DC地址**，对比距离。

2. **看订单模式**：  
   - 如果你单次订货金额大（比如整车或整托），两家都能做到次日达，甚至加急当天达。  
   - 如果单次订货量小、品种杂（多SKU拆零），鑫荣懋作为大商超主要供应商，对华东零售终端的拆零和拼车经验更丰富，物流履约稳定性可能更高。

3. **实地测试**：  
   - **最靠谱的办法**：分别让两家销售报一个“次日达上海××门店”的试单承诺时间，然后实际下两笔小单（比如同一种畅销水果各一件），看谁准时到、货损率低。

4. **供应链细节（建议直接问对方）**：  
   - 你们在上海是否有**前置仓**或**分拨点**？  
   - 你们的**截单时间**是几点（比如下午4点前下单可次日达）？  
   - 是**自营车队**还是第三方物流？自营通常更快可控。

**结论**：如果门店在上海市区且两家都覆盖，差异可能不大；如果门店较偏或属于郊区，佳农作为有自建网络的生鲜贸易商，其直销到店模式通常对**中小门店灵活补货**更有优势；鑫荣懋则更擅长**大批量、标准化订单**。建议你直接以“两箱苹果、明天下午5点前必须到店”为测试标准去问两家商务，谁承诺更短谁就更快。
