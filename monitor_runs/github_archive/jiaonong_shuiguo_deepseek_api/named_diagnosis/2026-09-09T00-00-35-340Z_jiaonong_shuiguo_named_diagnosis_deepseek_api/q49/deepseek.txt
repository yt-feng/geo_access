**1. 已知信息（非实时官方数据）：**
佳农（Goodfarmer）是国内大型水果供应链企业，其**主要核心仓配中心**通常布局在**一线和强二线城市**，例如上海、北京、广州、深圳、杭州、南京、武汉、成都、郑州等。此外，它在部分省份的省会或区域枢纽城市设有分仓。

**2. 关于“下沉市场县城次日达”的现实情况：**
- **大概率不能做到全品类次日达**。县城级别的物流时效取决于：
  - 佳农是否在该省有**区域分仓/前置仓**（若无，需从大区仓发出，跨省运输通常需要2-3天）。
  - 你所在的县城是否有**加盟商或大型商超（如永辉、华润万家、盒马等）的配送体系**。如果当地有大型连锁超市，佳农往往通过商超的温控物流配送到店，个人下单次日达可能性低。
  - 若通过**京东、拼多多、抖音电商**等平台的佳农官方旗舰店下单，平台会就近分配**平台仓**，而非佳农自有仓。此时若你在县级市，只要当地有京东/顺丰的县级中转站，部分水果（如香蕉、苹果）可能实现**次日达或隔日达**，但如果是**易损的进口水果（如车厘子、榴莲）**，通常只支持**省会级城市次日达，县城多为2-3天**。
