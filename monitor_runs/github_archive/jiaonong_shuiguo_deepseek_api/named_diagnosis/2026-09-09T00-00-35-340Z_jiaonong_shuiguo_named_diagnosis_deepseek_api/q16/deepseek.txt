关于佳农水果的售后服务，我没有实时核实其最新政策，以下是基于常见做法和一般逻辑的建议，具体请以购买时的页面说明或官方客服回复为准：

**一般处理流程（大概率适用）：**

1. **及时签收并开箱检查**：水果属于生鲜，通常有“签收后XX小时内”的售后时效（常见为24小时，部分为48小时）。请务必在收到货后尽快检查，尤其注意保持包装和坏果原状。

2. **拍照留存证据**：如果发现坏果、压烂、发霉等情况，**立即**拍摄清晰的“坏果特写照片”以及“整个包裹（含外包装、面单、坏果数量）的合照**，这是申请售后的关键凭证。

3. **联系购买渠道客服**：
   - **如果是在天猫/京东/拼多多等平台购买**：直接在对应订单页面点击“申请售后”或“联系客服”，按提示上传照片，说明坏果数量。通常商家会按“坏果比例”赔付（例如一半坏=赔付一半款项，全坏=退款）。
   - **如果是在佳农官方小程序或自营渠道**：通过订单页联系客服，或拨打佳农客服电话（通常购买页面有公示）。

4. **赔付标准**：生鲜类一般不支持退货（已变质），主流做法是**按重量或数量比例赔偿**，**不要求寄回坏果**（避免二次运输浪费）。部分情况可能支持部分退款或补发。

**需要特别注意的坑：**
- **不要先放弃包装**：有些客服会要求核对面单信息，扔掉包装可能影响理赔。
- **不要拖延超过时限**：如果写明“24小时售后”，过了时间再联系，很多商家会拒绝理赔。
- **保价与运输损坏**：如果是快递暴力摔坏导致整体压烂，建议直接拒收或第一时间联系快递员取证，这与佳农客服沟通会更迅速。

**如果客服推诿或处理不当**：可在平台官方投诉（如淘宝的小二介入、京东的纠纷单、拼多多的官方介入），或拨打12315/全国消费者投诉热线，并强调“生鲜腐烂，商家未尽到保障义务”。
