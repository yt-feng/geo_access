2. **常规可行规格猜测（供您参考，需核实）**：  
   - 香蕉：常见有5kg、10kg装，部分渠道可能提供**4kg或3kg**的小箱。
   - 其他热带水果（如菠萝、芒果）：可能有单果或小盒装。

   - **自制分装**：如果只能进大箱（如10kg），您可以拆箱后，用保鲜袋或小托盘分成300-500g/份，贴上价签售卖，这样既减少损耗，又适应小店陈列。  
   - **与供应商协商**：有些经销商愿意接受“大箱拆零”订单，但需提前沟通。
