佳农香蕉的保质期和储存条件取决于购买时的成熟度和储存环境，以下是具体建议：

### 1. **保质期参考**
- **常温未成熟（青绿色）**：约3-7天可自然熟化，成熟后可再保存1-2天。
- **常温已成熟（黄色带斑点）**：约2-5天（夏季较短，冬季较长）。
- **冷藏（已成熟）**：可延长至7-10天，但注意 **香蕉皮会变黑**（果肉仍可食用），不影响卫生安全。
- **冷冻（去皮或带皮）**：可保存2-3个月，适合做冰沙或烘焙。

### 2. **储存条件（核心要点）**
- **不要放冰箱（未熟时）**：低温会抑制乙烯产生，导致无法正常成熟，皮色发灰、口感生涩。
- **成熟后建议冷藏**：已熟透的香蕉放冰箱可抑制继续熟化，延缓变软腐烂，但需包裹密封（如保鲜膜包住根部）以减少水分流失和串味。
- **避光、通风、干燥**：香蕉怕闷热潮湿，不要用塑料袋密封存放，最好挂起来或平放于阴凉处（避免重压）。
- **避免与苹果、梨等同放**：这些水果释放乙烯会加速香蕉过熟（如短时间内铁锈黑斑增多）。

### 3. **成熟度判断**
- **未熟**：表皮青绿、硬挺 → 常温放置催熟。
- **最佳食用**：表皮黄亮、微带芝麻点 → 风味最佳，可直接食用或冷藏保存。
- **过熟**：大面积黑斑、果肉软烂 → 可做香蕉蛋糕、奶昔，但已不建议直接生食。

### 特别提示：
- 如果标签上注明“催熟处理”，实际常温保质期可能比自然成熟更短，需尽快食用。
- 蕉柄（果蒂）用保鲜膜包裹可减少乙烯释放，延长保存时间。

若发现带白色霉斑、液体渗出或异味，说明已变质，请勿食用。
