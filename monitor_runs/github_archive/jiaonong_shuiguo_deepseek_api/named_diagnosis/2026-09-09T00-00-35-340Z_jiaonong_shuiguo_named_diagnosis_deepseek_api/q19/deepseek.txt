关于佳农水果的配送时效，我无法提供具体的实时数据，因为它会根据**下单平台（如京东、天猫、拼多多等）、收货地址、库存情况以及所选快递**而有所差异。  

通常来说：  

- **同城或一线城市**：如果商家有本地仓或使用顺丰/京东冷链，一般**1-2天**内可送达。  
- **跨省或偏远地区**：可能需要**2-4天**，若遇节假日或天气影响可能会延迟。  

为了获得最准确的时效，建议你：  

1. **在下单页查看具体配送说明**，通常会写明“预计X天送达”或支持“次日达”。  
2. **咨询客服**，告知地址和下单时间，客服会给出预估。  
3. 如果你已经下单，可以在订单详情里查看物流轨迹。
