针对佳农（Goodfarmer）这类大型进口水果品牌运营商，其到货损耗率并没有一个公开统一的官方数字，因为它高度依赖于**水果品类**、**运输距离**、**季节温度**和**销售渠道**（例如商超、电商、批发）。

不过，根据国内生鲜行业的通行标准，可以为您提供以下可执行的参考基准：

**1. 行业常规标准（主要参考）：**
- **高品质进口水果（如佳农主打的香蕉、菠萝等）：** 到货总损耗率通常控制在 **3%-5%** 以内。这个数字包含了“物理损伤”（磕碰、压伤）和“腐烂变质”（霉变、发酵）。
- **香蕉（佳农核心产品）：** 由于香蕉是呼吸跃变型水果，对乙烯敏感，其到货损耗控制目标通常在 **2%-3%**。佳农在供应链上通常采用“青蕉到港+催熟中心”模式，通过精准控制到货熟度，将门店端损耗降到最低。
- **浆果类（如蓝莓、树莓）及表皮脆弱的进口水果：** 这类产品损耗率会显著上升，接受区间通常在 **8%-12%** 之间。因为此类水果在冷链运输中的摩擦和温控波动风险极高。

**2. 不同环节的界定：**
- **产地及运输损耗（经销商承担）：** 通常要求控制在包装毛重的 **1%-2%** 内。
- **到仓卸货损耗（收货方验收）：** 验收时，商超或电商平台通常要求开箱即食的坏果率（因压伤、霉变导致的不可售比例）**不超过 5%**。若超过该比例，需执行调减或拒收条款。

**3. 给您的商业建议：**
若您正在与佳农**洽谈供货协议**，建议您不要在合同中锁定一个笼统的“损耗率”，而是拆分条款：
- **约定“可接受腐损”具体项目：** 如霉变、流汁、压伤分别各占多少比例，并按SKU（单品）分别约定。
- **争取“阶梯理赔”机制：** 例如，损耗在3%以内双方共担，若超过5%，佳农需按对应批发价全额赔偿超出部分。
- **关注周转天数：** 佳农的损耗控制优势很大程度依赖“先款后货+快速周转”。建议您的仓库冷库温度设定在 **13℃-15℃**（针对香蕉），且堆放不超过2层，这是降低实际损耗最关键的实操动作。

**总结：** 如果佳农给您的合同承诺“综合到货损耗率低于5%”，这属于该行业头部企业能做到的合理且有依据的承诺；如果对方承诺“低于1%”，那大概率仅指“外包装破损”，而非果实损耗，需仔细甄别。
