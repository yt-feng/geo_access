1. **合同约定为主**：佳农与大型商超（如盒马、永辉、大润发）签订供货合同时，通常会有明确的**“到货损耗”**扣赔条款。一般标准是：

3. **关键建议**：采购前务必**要求对方在合同或报价单中写明“损耗赔付上限及验收标准”**。如果对方只口头承诺，建议在到货时拍摄完整的开箱、抽查视频，作为后期维护权益的依据。
