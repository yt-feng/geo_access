佳农（佳农食品控股）的香蕉属于典型商品化催熟，主要采用**乙烯类催熟剂**，而不是“树上自然熟”。

对商超来说，可以按以下方式判断和控制：

1. **催熟方式**
   - 商业香蕉通常在产地采收青香蕉，运输到销地后，在催熟库中用**乙烯气体或乙烯利**处理。
   - 佳农作为品牌供应商，通常也是这套工业化催熟流程。
   - “自然熟”一般只适用于产地就地销售或少数特殊渠道，不适合商超大规模供货。

2. **商超需要控制的不是“是否用乙烯”，而是到店后的温湿度和上架节奏**
   - 到货后若还偏青：放在 **18–22℃** 环境中继续后熟，避免低于 13℃，否则容易冷害、发黑、不能正常软熟。
   - 若已开始转黄：尽快降到 **13–15℃** 左右销售，减缓后熟。
   - 湿度建议 **85%–90%**，避免失水发皱。
   - 不要和苹果、梨、猕猴桃等释放乙烯较多的水果混放，否则会加速香蕉过熟。

3. **控催熟时间的实操建议**
   - 青香蕉入库催熟：商业催熟库一般 **3–7天** 转黄，具体看温度、乙烯浓度和品种。
   - 商超自己二次控熟：通常把到货青蕉放在 **18–20℃** 下 **2–4天** 到可售黄度。
   - 目标上架成熟度建议：**3–4号色** 左右，即果身转黄、果尖仍带一点绿，货架期更稳。
   - 若要做“即食蕉”，可放到 **5–6号色**，但货架期会明显缩短。

4. **和佳农对接时建议直接问清**
   - 到货时是“未催熟青蕉”还是“已催熟半成品”；
   - 供应商给出的催熟完成度和建议销售温度；
   - 是否允许商超二次催熟，以及推荐乙烯浓度/温度曲线。

简单说：**佳农香蕉基本是乙烯催熟，不是自然熟。商超要控时间，重点控 13–22℃ 的分段温度和是否混放，而不是纠结乙烯本身。**
