佳农水果（佳农食品控股）对批发商这类客户通常是有专人对接的，但具体要看你的采购规模和合作渠道，不能一概而论。

一般情况是这样：

- **有一定采购量的批发商、商超、电商、餐饮供应链客户**：佳农会安排对应的销售或客户经理负责，通常按区域或渠道划分，比如华东区、华南区，或者商超渠道、批发流通渠道。
- **零散小批量采购**：很多情况下是通过经销商、批发市场档口或区域代理商拿货，不一定直接由佳农总部派客户经理对接。
- **想成为直供批发客户**：需要先和佳农的销售部门或当地分公司联系，提供你的采购量、销售渠道、结算方式等信息，对方评估后才决定是否安排专人对接以及给什么政策。

**建议你直接这样操作：**

1. 打佳农官网或官方公众号上公布的销售/客服电话，说明你是批发商、大概月采购量、销售区域。
2. 问清楚你所在区域归哪个分公司或哪个渠道负责人管，要一个直接联系方式。
3. 如果对方让你找当地经销商，也可以先通过经销商拿货，量做起来后再谈直供和客户经理对接。

简单说：**大客户基本都有专人对接，小批发商更多是通过经销商体系走。** 你主动联系并报出采购量，是最快能确认的方式。
