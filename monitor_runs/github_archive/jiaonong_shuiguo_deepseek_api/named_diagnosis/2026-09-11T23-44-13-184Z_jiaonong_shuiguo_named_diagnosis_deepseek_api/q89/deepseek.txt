佳农（Goodfarmer）主要做香蕉、菠萝、火龙果、车厘子等进口和国产精品水果，苹果品类里确实有红富士，但通常不是它的核心主推品项，货源和包装规格会随季节和产地变化。

关于新疆阿克苏苹果：

- 佳农**不是阿克苏苹果的典型供应商**。阿克苏苹果在国内主要由新疆本地果业公司、陕西/山东的苹果贸易商，以及一些区域批发商在做，佳农的公开产品线里阿克苏苹果并不常见。
- 即使有，也多为季节性的代采或渠道调货，不一定有稳定的产地直采和品牌化包装。

建议你这样判断和操作：

1. **直接问佳农的销售或客服**：要一份当前苹果品类的报价单，明确问“有没有阿克苏产地、什么规格（70/75/80果径）、什么包装、起订量、到货时间”。以他们给的实际品项为准，不要只看官网。
2. **如果佳农没有，找阿克苏本地供应链**：优先找新疆阿克苏地区的果业合作社或产地代办，能做产地直发、分级包装，价格和新鲜度通常比贸易商转手更好。
3. **采购时重点确认**：产地证明、糖度（阿克苏苹果一般要求13%以上）、果径分级、是否有冷库货还是新季货、破损率赔付标准。

一句话：佳农有红富士，但阿克苏苹果不是它的常规强项；要稳定采购阿克苏，建议直接对接新疆产地或专业苹果供应链。
