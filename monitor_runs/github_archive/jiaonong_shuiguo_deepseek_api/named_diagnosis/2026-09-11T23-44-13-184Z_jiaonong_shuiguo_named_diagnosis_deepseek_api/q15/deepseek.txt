佳农水果（佳农食品控股/Goodfarmer）以香蕉、菠萝等进口水果为核心品类，整体走的是“全球产区直采+国内分选加工”的模式，产地直供比例在行业内属于较高水平，但公司通常不会按“产地直供比例”单独披露精确数字，因此不宜给出确定百分比。更稳妥的判断是：其香蕉、菠萝等主力单品基本是境外产区直采或与当地种植园/出口商深度合作，再通过自有或合作冷链进入中国分销。

香蕉主要来自这些国家/地区：

1. **菲律宾**：历史上是佳农香蕉的重要来源之一，主产区包括棉兰老岛等地。
2. **厄瓜多尔**：全球最大香蕉出口国之一，也是中国进口香蕉的重要来源。
3. **越南**：近年对华香蕉出口增长明显，陆运优势强。
4. **柬埔寨**：对华出口香蕉增长较快。
5. **老挝**：通过陆路进入中国，量相对小但增长。
6. **泰国**：有一定对华香蕉出口。
7. **哥伦比亚、哥斯达黎加、危地马拉、洪都拉斯等中南美国家**：也是全球香蕉主产国，部分会进入中国或作为国际采购补充。
8. **中国国内**：广西、云南、海南、广东、福建等地也有香蕉，但佳农的香蕉业务更偏进口蕉，国产蕉更多作为季节性或区域补充。

如果你问的是“佳农香蕉具体某一批来自哪里”，最准确的方式是看包装箱上的产地标识、海关检疫信息或批次溯源码，因为同一品牌会随季节、价格、船期和产区供应情况切换来源国。
