佳农水果的售后整体口碑属于“看渠道、看品类、看证据留存”的类型：在大型商超和头部生鲜电商自营渠道购买时，售后通常较规范；如果是第三方店铺或社区团购，处理体验差异会比较大。

**如果到货有坏果，建议按下面顺序处理：**

1. **先别急着扔坏果**
   把坏果、外箱、快递面单、订单截图放在一起拍照或录视频。最好能拍到整体箱子和坏果局部，证明是同一单。

2. **尽快联系购买渠道的客服**
   - 京东自营/天猫超市/盒马/山姆等：直接在订单里申请售后，选“质量问题/腐烂变质”，上传照片。
   - 抖音、拼多多、社区团购：联系店铺客服，发照片和视频，说明坏果数量。
   - 线下商超：带小票和坏果去服务台，通常可以退换或补差价。

3. **明确诉求**
   常见处理方式包括：按坏果数量比例退款、整单退款、补发、赔付优惠券。你可以直接说：“这箱有几颗坏果，按比例退我多少钱”或“坏果超过一半，申请整单退款”。

4. **保留证据，别只口头说**
   客服一般会要求照片、视频，部分会要求“坏果和面单同框”。如果客服拖延，可以在平台内发起投诉或申请平台介入。

5. **注意时效**
   生鲜类售后通常要求在签收后24—48小时内反馈，越早越好。超过时限，平台可能以“保存不当”为由拒绝。

6. **区分“坏果”和“熟度问题”**
   有些水果到货偏生是正常的，放几天会熟；但发霉、流汁、异味、软烂出水，通常属于质量问题，可以售后。

**实用建议：**
- 优先在自营或大型商超买，售后更稳。
- 收货时当场开箱检查，有问题立刻拍视频。
- 如果坏果比例高，不要只接受“补偿几块钱”，可以要求按比例退款或补发。
- 如果商家拒绝，直接走平台售后入口，通常比和店铺客服拉扯更有效。

简单说：佳农水果本身是品牌供货，但售后由你下单的渠道负责。坏果处理的关键是**及时反馈 + 照片视频证据 + 走平台售后**。
