佳农水果的配送时效取决于你下单的渠道和收货地址，没有统一答案。常见情况如下：

**1. 佳农官方渠道（微信小程序/天猫/京东旗舰店等）**
- 通常由平台快递发货（顺丰、京东物流或普通快递），**发货后 1–3 天到货**，偏远地区 3–5 天甚至更久。
- 部分商品是预售/产地直发，页面会标注预计发货时间，可能下单后 2–7 天才发出。

**2. 商超/生鲜平台（如盒马、叮咚、美团买菜、京东到家）**
- 如果所在城市有前置仓或门店，一般是**当日达或次日达**，最快 30 分钟–2 小时（即时配送）。
- 具体时效在下单页面会显示“预计送达时间”，以下单时显示的为准。

**3. 影响时效的关键因素**
- 收货城市是否在发货仓覆盖范围；
- 是否节假日、大促（可能延迟）；
- 水果是否为预售、产地直发或冷链商品。

**建议**：直接看你下单页面的“预计送达/发货时间”标注，或咨询该店铺客服，因为不同渠道差异很大，无法一概而论。
