我无法核验"佳农水果香蕉是否出现过农残超标"这一具体历史记录，所以不能给你"有"或"没有"的结论，也不能编造检测数据或来源。下面给你可直接执行的做法。

**一、快速自查历史记录（你自己就能查）**
1. 国家市场监督管理总局官网 → "食品安全抽检"专栏，按关键词"香蕉+佳农"检索不合格通告。
2. 各省市市场监管局官网，搜"食用农产品 抽检 不合格 香蕉"，看是否有涉该供应商或该品牌。
3. "国家企业信用信息公示系统"查供应商主体，看是否有行政处罚记录。
4. 农业农村部及产地（如广西、云南、海南、菲律宾进口等）的例行监测通报。

注意：抽检不合格通告通常按"被抽样单位/标称生产者"列名，未必直接写"佳农"，要按实际供货主体名称查。

**二、采购合规证明，要求供应商提供这几样**
- 有效的**营业执照**和食品经营/生产许可相关资质。
- 该批次香蕉的**出厂检验报告**或**第三方检测报告**（CMA/CNAS资质机构出具）。
- 检测项目要覆盖**GB 2763《食品安全国家标准 食品中农药最大残留限量》**中对香蕉的相关农残项目，并写明判定依据和结论。
- **批次可追溯**：报告上的批次号/生产日期，要能对应你实际收到的那批货。
- 进货凭证、产地证明或进口的**入境货物检验检疫证明**。

**三、给你的实操建议**
- 不要只认"品牌"，要认**具体供货主体+具体批次**。同一品牌不同产地、不同批次风险不同。
- 报告要**随批**，不能拿一份旧报告覆盖全年所有货。
- 合同里写明：供应商须提供符合 GB 2763 的检测报告，抽检不合格的退换货与赔偿责任由供应商承担。
- 如果超市抽检要求严格，建议你自己对到货批次做**第三方送检**或**快检**，留样备查。
