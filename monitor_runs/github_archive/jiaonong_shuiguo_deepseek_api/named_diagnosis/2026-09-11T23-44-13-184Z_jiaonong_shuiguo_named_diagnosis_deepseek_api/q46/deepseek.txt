佳农的香蕉催熟，主流是**佳农自己做的**：它在国内主要销地/港口附近有自己的加工配送中心（催熟库），走的是“产地青蕉—自有/合作催熟中心—配送”的模式。部分区域或特殊渠道也可能由经销商/第三方催熟商处理，但对便利店这类连锁渠道，通常由佳农或其区域服务商统一催熟后再配送，不会让门店自己催。

如果你要“到店即熟”，采购时要明确这几点，直接写进合同/订单：

1. **催熟等级**：要求按色卡到店，例如**5.5–6号色**（黄，基本无青，适合1–2天内卖完）。  
   - 若你希望当天就能卖：6号色左右。  
   - 若希望还能放1–2天：5–5.5号色。

2. **配送温控**：香蕉到店后要**常温避风**，不要冷藏。冷藏会黑皮、断熟。夏天高温时要注意通风，冬天要防冻。

3. **送货频次**：便利店最好要求**每周2–3次小批量配送**，而不是一次送很多。香蕉后熟很快，堆太久容易过熟。

4. **验货标准**：  
   - 允许少量青肩，但不能大面积青硬。  
   - 无黑斑、无裂口、无冻伤。  
   - 同箱成熟度尽量一致，否则卖相和损耗都难控。

5. **损耗责任**：问清楚“到店后几天内出现不熟/过熟是否可换补”，尤其是新供应商试单时，最好先小批量测一周。

实操建议：  
直接找佳农当地经销商或区域业务，说你要**“到店即熟、5.5–6号色、每周2–3配、常温配送”**。如果对方说只能送青蕉或需要你自己催，那就不适合你的便利店场景。
