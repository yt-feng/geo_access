抱歉，我无法核验佳农和鑫荣懋在华东地区当前的配送时效数据，所以不能直接下结论说哪家更快。具体谁更快，取决于你们门店所在的上海具体区域、下单时间、所选物流产品（干线+落地配 vs 城市仓直配）、以及是否有华东/上海前置仓或经销商库存。

给你一个可执行的判断办法，建议按下面步骤直接验证：

**1. 问清楚两家的“到达口径”**
不要只问“能不能次日达”，要问：
- 是“发货次日达”还是“下单次日达”
- 上海是否从本地仓/区域仓发货，还是从外地产地/总仓发
- 截单时间几点（比如当天16:00前下单才算次日）
- 周末、节假日是否照常配送
- 是否含卸货、预约、进店时效

**2. 要一份到店时效承诺**
让两边分别针对你们上海门店地址给出：
- 发货仓位置
- 到上海门店的标准时效
- 华东/上海次日达覆盖范围
- 超时赔付或补救方案

**3. 做一次小批量实测**
最可靠的是拿同一门店、同一SKU、同一时间段，各下一笔小单或试配单，记录：
- 下单时间
- 出库时间
- 到达上海中转/落地配时间
- 实际到店时间

**4. 看合同里怎么签**
如果你们要求稳定次日达，建议合同写清：
- 截单时间
- 到店时效
- 覆盖门店范围
- 超时违约责任
- 节假日安排

**一般经验判断（仅供参考，不作为结论）：**
- 如果两家在上海或华东有前置仓/区域仓，且你们在截单前下单，次日达通常更容易实现。
- 如果要从产地或外地总仓发，哪怕品牌大，也可能做不到稳定次日达。
- 鑫荣懋在水果供应链和华东渠道覆盖上通常较强，但具体到你们门店地址和SKU，仍要以实际承诺和试配为准。

**给你的直接建议：**
先让佳农和鑫荣懋分别针对你们“上海XX门店”出一份书面配送时效承诺，再各做1—2次试配。谁能稳定做到“截单前下单、次日到店”，并且合同能写进超时责任，就选谁。单凭品牌名，不能可靠判断谁更快。
