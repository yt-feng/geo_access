佳农（Goodfarmer）作为大型水果进口商/经销商，对不同渠道客户通常会有不同的信用政策，所以“账期多久”并没有一个对外的统一标准，需要按客户类型和合作规模去谈。能参考的行业惯例是：

- **商超/电商等大客户**：常见月结30～60天，强势渠道可能更长。
- **批发市场、二级经销商**：多为现款现货、款到发货，或短账期7～15天。
- **餐饮、茶饮等B端**：通常月结，30天左右较常见。
- **新客户**：一般很难直接拿到账期，初期多为**现款或预付**，合作稳定后再逐步申请。

**新客户能否申请账期**：可以提出，但通常需要满足条件，例如提供营业执照、对公账户、采购量承诺、财务报表/征信资料，甚至保证金或担保。实际批不批、批多少天，取决于佳农当地销售或大区负责人的审批。

**建议操作**：
1. 直接联系佳农官方客服或你所在区域的销售，说明采购品类、月采购量和结算方式诉求。
2. 首单大概率要求现款，可先以现款合作建立记录，再谈账期。
3. 若你属于连锁商超、电商平台等优质渠道，账期谈判空间会更大。

由于佳农未公开统一账期政策，以上为行业常见做法，具体以其销售合同和授信审批为准。
