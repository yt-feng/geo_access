佳农（Goodfarmer）的苹果品类以进口和国产高端果为主，常见包括：

- **嘎啦（Gala）**：常见进口产地为**新西兰、澳大利亚**，国产也有陕西、山东等产区。
- **红富士（Fuji）**：进口常见为**新西兰、澳大利亚、智利**等；国产以**山东烟台、陕西洛川、甘肃静宁**等为主。
- **爱妃（Envy）**：多为**新西兰**进口。
- **爵士（Jazz）**：多为**新西兰**进口。
- **皇后（Queen）**：常见**新西兰**等。
- **帕克（Pink Lady/粉红佳人）**：常见**澳大利亚、新西兰**等。
- **青苹果（Granny Smith）**：常见**新西兰、智利、澳大利亚**等。
- **蛇果/花牛类**：国产甘肃等地较多。

关于你们想采购的：
- **进口嘎啦**：佳农常见货源一般来自**新西兰**，部分季节也可能有**澳大利亚**等。
- **进口红富士**：佳农常见进口货源一般来自**新西兰**，部分季节可能有**澳大利亚、智利**等。

但具体到某一批次，产地会随产季、船期和佳农实际采购计划变化。采购时建议直接向佳农销售或经销商确认这三项：
1. **具体品种名/商品名**：是嘎啦、红富士，还是其子品牌/规格；
2. **原产国及果园/包装厂代码**：以报关单、原产地证、箱标为准；
3. **当季可供规格**：果径、等级、包装、到港时间、冷链条件。

如果你们要做进口采购，最稳妥的判断依据是：**看原产地证 + 报关单 + 外箱产地标识**，不要只依赖“佳农品牌”判断产地。
