**能开什么发票**
- 佳农水果礼盒一般可开**增值税普通发票**或**增值税专用发票**，具体看供应商资质。
- 你要先确认：开票主体是“佳农官方/授权经销商”还是普通贸易商。
- 专票通常要求你提供：公司名称、税号、地址电话、开户行及账号。
- 发票内容常见为：**水果、农副产品、食品、礼盒**等，具体以供应商能开出的类目为准。
- 如果你要报销或走福利费，建议提前问财务：接受什么发票类目、是否要专票。

**质检报告**
- 正规供应商通常能提供：**批次质检报告、农残检测报告、产地证明/合格证**。
- 注意：质检报告一般是**按批次**的，不是一份报告永久通用。
- 你要明确要求：报告对应你这次500份的**生产批次或发货批次**。
- 如果是进口水果，还可能涉及：**入境货物检验检疫证明、报关单**等。
- 如果供应商只能给“通用报告”或“往年报告”，要谨慎，最好写进合同。

**建议你直接这样问供应商**
1. 500份佳农水果礼盒，能否开增值税专票？税率多少？开票类目是什么？
2. 能否提供本批次质检报告和农残检测报告？报告出具机构是谁？
3. 发票和质检报告是否随货提供？电子版还是纸质版？
4. 如果质检不合格，退换货和赔偿怎么处理？
5. 合同里能否写明：发票类型、开票时间、质检报告批次对应关系？

**关键提醒**
- 不要只听口头承诺，**发票类型、开票时间、质检报告批次**都要写进合同或订单备注。
- 500份属于团购大单，建议要求**先看样品和报告模板**，再付定金。
- 如果对方是中间商，要确认它能不能拿到佳农官方授权或正规进货凭证。
