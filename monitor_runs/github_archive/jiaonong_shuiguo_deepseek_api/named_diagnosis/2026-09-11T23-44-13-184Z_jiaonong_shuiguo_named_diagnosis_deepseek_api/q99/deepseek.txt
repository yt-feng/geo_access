关于佳农水果的菠萝是否有机认证，我无法直接核验其当前产品线的认证状态，不能给你确定答案。

**建议你这样确认（最可靠）：**

1. **直接问佳农官方/区域销售**
   - 明确问：这款菠萝是否有**中国有机产品认证（GB/T 19630）**，还是仅有**GLOBALG.A.P.、绿色食品、无公害**等其它认证。
   - 要求提供**有机认证证书编号、认证机构、有效期、认证产品范围**。

2. **上“中国食品农产品认证信息系统”核验**
   - 国家认监委的有机认证信息可公开查询。
   - 用**证书编号或企业名称**查，确认“佳农”相关主体和“菠萝/鲜菠萝”是否在认证范围内。

3. **看包装上的有机标志**
   - 中国有机产品必须有**中国有机产品认证标志**，并带**有机码**，可扫码或到“中国食品农产品认证信息系统”追溯。
   - 只有“绿色食品”“无公害”“GAP”标志的，**不是有机**。

**判断要点：**
- 有机认证是**按产品、按基地、按加工线**认证的，不是企业所有产品都自动有机。
- 即使佳农有有机香蕉/其它水果，也**不代表菠萝一定有机**。
- 高端渠道若必须有机，建议要求**每批次随货提供有机证书复印件+有机码**，并做入仓核验。
