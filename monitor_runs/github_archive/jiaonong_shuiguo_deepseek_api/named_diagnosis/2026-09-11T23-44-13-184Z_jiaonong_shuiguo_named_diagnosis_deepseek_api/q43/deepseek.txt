佳农这类大型水果供应链企业通常能谈锁价，但要看几个具体条件。直接给你可判断的框架：

**1. 能不能锁价，主要看这几个变量**
- **锁价周期**：月度采购10吨属于中等规模，佳农一般更愿意做**季度或半年度**锁价，一年以上的长协不一定接，或会加价。
- **菠萝品种和规格**：你用的是菠萝果肉、菠萝丁还是菠萝汁？鲜果（如金钻凤梨）受季节影响大，冷冻/罐头菠萝（原料）更容易锁价。
- **产地与季节**：国产菠萝（广东徐闻、海南）集中在2-6月，反季节要进口（菲律宾、泰国），进口原料锁价难度更高。
- **是否带量承诺**：10吨/月、120吨/年，量不算特别大，锁价议价空间有限，但比零散采购强。

**2. 现实中的两种做法**
- **真锁价（固定单价）**：佳农一般只对**冷冻菠萝、菠萝罐头、浓缩汁**这类标准化原料做，且要求你签年度框架+月度提货，可能收取保证金或预付。
- **浮动+封顶（更常见）**：约定基准价+波动区间，超出部分双方分担，或设价格上限。对鲜果原料这是主流方案。

**3. 你需要准备的谈判材料**
- 明确**规格书**（品种、糖度、形态、包装、冷冻/鲜果）
- **12个月滚动需求预测**，证明量稳定
- 能接受的**价格区间和调价机制**
- 是否接受**预付/保证金**

**4. 直接建议**
先问佳农（或其经销商）三个问题，就能快速判断：
1. 你们对**冷冻菠萝/菠萝丁**有没有年度锁价产品？
2. 锁价最短周期是多久，是否收保证金？
3. 如果做不了固定价，能不能做**价格上限+浮动**？

如果佳农锁价门槛高，可以同时谈**两家供应商**，一家锁基础量、一家做弹性补充，这样最抗波动。
