佳农的物流网络属于**自营为主、外包/第三方合作为辅**的混合模式，但这方面公开披露的细节不多，具体判断如下：

**自营部分**
- 佳农是国内少数自建冷链物流的水果企业之一，在主要口岸和销地设有自营冷链仓配中心，自有冷藏车负责核心干线和部分城配。
- 对香蕉、菠萝等主力进口单品，从港口到区域仓这一段的温控基本自营把控，因为这是品质和损耗的关键环节。

**外包部分**
- 末端城配、部分区域支线、电商快递件通常交给第三方冷链物流或快递（如顺丰冷运等），以覆盖自营网络到不了的区域。
- 一些非核心品类或季节性调货也会用外包运力。

**冷链能力**
- 核心能力在“进口口岸—区域冷链仓—销地”这条链路上，具备全程温控和一定的催熟、分拣能力（香蕉催熟是佳农的强项）。
- 相比顺丰冷运、京东冷链这类专业物流企业，佳农是**货主型冷链**，强在品类know-how和源头把控，而不是全国性公共冷链网络。

**需要注意**
- 以上是基于行业公开信息的概括，佳农没有完整对外披露物流自营/外包的具体比例和网络规模，确切数据建议以其官方或招股/财报类文件为准（如果可获取）。
