佳农香蕉的保质期和储存条件大致如下（具体以包装标注为准）：

**储存条件**
- **未熟/偏青香蕉**：常温阴凉通风处存放，避免阳光直射和冰箱冷藏，适宜温度约 **13–20℃**。
- **已熟香蕉**：可短期常温存放；若想延缓继续变熟，可放入冰箱冷藏，但表皮会变黑，果肉仍可食用。
- **避免**：高温、暴晒、潮湿、挤压，也不要和苹果、梨等释放乙烯的水果放一起，会加速成熟。

**保质期**
- **常温未熟状态**：通常可放 **3–7天** 慢慢变黄成熟。
- **常温已熟**：一般 **1–3天** 内食用较好。
- **冰箱冷藏已熟香蕉**：可延长到 **3–5天** 左右，但表皮易变黑。
- **冷冻**：去皮后密封冷冻可放 **1–2个月**，适合做奶昔、烘焙。

**判断是否还能吃**
- 表皮少量黑斑、果肉正常：通常还能吃。
- 果肉发软流汁、有酸味/酒味、霉变：不建议食用。

如果是佳农具体包装产品，建议以包装上的 **储存条件、保质期/最佳食用期** 为准。
