佳农（佳农食品控股）并没有对外统一公开一个固定的“到货损耗率”标准，实际控制水平会因品类、运输方式、季节、距离和渠道不同而差异较大。行业里通常按品类区分，而不是给一个全公司统一的数字。

可以给你一个可判断的参考范围：

- **香蕉**：到货损耗率通常控制在 **3%–8%**，做得好的可以到 **3%–5%**，夏季或长距离运输可能更高。
- **菠萝/凤梨**：一般在 **3%–6%**，冬季和夏季差异明显。
- **火龙果、芒果、木瓜等热带水果**：常见在 **5%–10%**，夏季或成熟度高时可能超过 10%。
- **苹果、梨、柑橘等耐储水果**：通常在 **2%–5%**。
- **进口水果整体**：海运+冷链条件下，行业较优水平大致在 **5%以内**；普通水平在 **5%–10%**。

如果是和佳农有实际业务往来，建议直接看合同或验收标准里的约定，因为不同客户、不同渠道（商超、电商、批发）对“损耗”的定义也不一样——有的只算腐烂，有的把压伤、变色、失水都算进去。

**判断建议：**
1. 先明确“损耗”口径：是仅指腐坏，还是包含外观降级。
2. 按单品分别约定，不要用一个总损耗率覆盖所有水果。
3. 佳农这类头部供应商，通常会把**香蕉、菠萝等核心单品**控制得较好，热带易损单品会明显放宽。
