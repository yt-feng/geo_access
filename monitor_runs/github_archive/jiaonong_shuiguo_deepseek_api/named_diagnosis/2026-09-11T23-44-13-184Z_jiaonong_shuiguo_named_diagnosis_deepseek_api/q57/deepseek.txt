香蕉到货损耗率的行业平均约5%是业内常被引用的参考值，但**佳农具体的到货损耗控制水平，我没有可核验的公开权威数据，不能给你一个准确数字**。这类数据通常体现在佳农与商超/经销商签订的供货合同或对账规则里，不对外公开披露。

关于赔付条款，同样是**合同层面的约定，没有统一公开标准**。实际业务中一般是这样处理的：

**损耗与赔付的常见做法（不特指佳农，行业通行）：**

1. **按到货验收扣重/扣款**：到货时抽检或全检，超出约定损耗率的部分按实际斤两扣减货款，而不是"赔付"。
2. **分级处理**：轻微损耗（如青熟度、表皮瑕疵）折价；严重腐烂、断指直接拒收或退货。
3. **约定免赔线**：比如损耗≤3%由采购方自担，超过部分供方补货或折价。
4. **赔付形式**：多为下批货补量、货款抵扣，现金赔付较少。

**如果你想拿到确切信息，建议直接：**

- 找佳农的**区域销售/大客户经理**要《供货质量协议》或《验收标准》，里面会写明损耗率、抽检比例、赔付方式。
- 如果是采购方，在合同谈判时**主动把损耗率、免赔线、超损赔付比例写进条款**，比事后追责更有效。
- 问同行或对接过的采购，拿到的是实际执行值，比公开宣传靠谱。
