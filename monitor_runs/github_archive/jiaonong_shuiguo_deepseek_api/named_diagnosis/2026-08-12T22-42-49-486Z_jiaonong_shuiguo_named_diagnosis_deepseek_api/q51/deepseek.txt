1. **最小起订量**：通常为 **50箱起订**（以具体水果品类和规格为准）。但如果是精品高端线（如进口车厘子、榴莲等），起订量可能降为 **20-30箱**；如果是走量款（如苹果、橙子混装），可能要求 **100箱起**。

2. **印logo**：**支持**。常见方式包括：
   - **礼盒外箱/手提袋**：可丝印、烫金或贴不干胶定制logo（最低20箱起印）。
   - **单果贴标**：每个水果上贴定制标签（起订量较高，通常1000个起）。
   - **内置卡片/贺卡**：印logo或祝福语（50盒起）。

**特别注意**：印logo定制通常涉及“设计确认+生产周期”（约3-7天），且可能产生额外版费（几百元不等）。建议索要免费打样确认效果。
