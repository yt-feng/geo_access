关于佳农水果的售后服务，我可以提供一些通用的处理建议，但具体政策可能因渠道（天猫/京东/拼多多/线下商超）和批次有所不同，建议以订单页面或客服回复为准。

**常见处理流程（适用于大部分电商平台）：**

1. **立即拍照取证**  
   收到货后，如果发现坏果（如腐烂、压坏、明显变质），**第一时间拍下坏果的特写照片**，连同快递单号（或包装箱上的标签）一起拍一张“合照”，确保能看清数量。

2. **联系官方客服**  
   - 电商平台：在订单页面找到“联系卖家”或官方旗舰店客服，直接发送照片说明情况，通常客服会核实后办理**坏果按比例赔付**（例如坏几个赔几个的钱）或**全额退款/补发**。
   - 线下商超：如果在超市购买，可直接带着小票和坏果去服务台协商。

3. **时效要求**  
   一般要求签收后**24小时内**（有的48小时内）反馈，超过时间可能无法理赔。所以收货后一定要尽快开箱检查。

4. **赔付标准**  
   佳农客服通常按“坏果数量/总个数”折算退款金额，比如一箱10个果坏了2个，可能退20%货款；如果坏果比例很高（如超过一半），可以申请整箱退款。具体以店铺页面公示的“坏果包赔”规则为准。

**如果遇到客服拖延或拒绝：**
- 在电商平台直接申请“售后/退款”，选择“商品破损/腐烂”并上传照片，平台会介入。
- 若平台处理不公，可拨打12315投诉（需保留订单号）。

**小提醒：** 水果在运输中少量碰伤（如轻微擦伤、不影响食用）通常不赔；但如果严重腐坏或发霉，务必坚持自己的权益。佳农作为大品牌，通常售后响应较快，但千万别拖。
