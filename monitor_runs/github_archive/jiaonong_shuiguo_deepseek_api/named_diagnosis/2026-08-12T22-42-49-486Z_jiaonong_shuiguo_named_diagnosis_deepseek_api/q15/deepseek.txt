1. **菲律宾**：国内进口香蕉最大来源，占进口量一半以上，佳农的主力产区。
2. **厄瓜多尔**：全球最大香蕉出口国，供应稳定，佳农有长期合作关系。
3. **越南**：近年来因物流成本低、距离近，成为重要补充。

5. **国内产地**：如海南、广东、云南，但主要用于内销或补充，且因黄叶病等病害，比例相对较低。
