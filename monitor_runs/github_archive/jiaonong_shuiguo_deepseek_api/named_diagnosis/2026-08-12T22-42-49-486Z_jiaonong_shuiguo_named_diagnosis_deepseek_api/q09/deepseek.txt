关于佳农水果的到货损耗率，**没有公开的统一标准数值**，因为损耗率会因水果品种、运输距离、季节、包装方式以及供应链管理水平不同而有显著差异。

不过，基于行业一般经验和佳农作为大型生鲜供应链企业的管理特点，可以给你以下参考：

1.  **行业常见范围**：在常温或冷链运输中，**一般水果到货的合理损耗率通常控制在 3%~8% 之间**。如果管理优秀，部分耐储存品类（如苹果、柑橘）可以控制在 **1%~3%**；而娇贵品类（如草莓、荔枝、山竹、樱桃）在长途运输中，即使有冷链，到货损耗率也可能达到 **8%~15%**，这是行业常态。

2.  **佳农的定位**：佳农作为规范化企业，其损耗控制通常优于行业平均水平。他们一般通过以下方式尽量压低损耗：
    -   采用**预冷处理**和全程冷链运输。
    -   使用**缓冲包装**（如珍珠棉网套、气柱袋）。
    -   到货时进行**严格的验收标准**（如水分、磕碰伤比例），超过约定的“合理损耗率”部分通常由供应商或物流方承担。

3.  **判断建议**：如果你是批发商或采购方，**建议不要单纯依赖一个固定数值**。在签订合同时，应明确约定“双方认可的到货损耗率上限”（例如约定不超过5%），并以**到货后的开箱检视**为准，对于超过合同约定损耗的部分进行扣减或退换。

**一句话总结**：佳农鲜果到货损耗率**一般控制在 5% 以内**（常规品类），**娇贵品类可放宽至 12% 左右**，但具体数据务必以你和佳农签订的**采购合同条款**为准。
