**1. 佳农香蕉的企业标准（推测性）**
佳农作为国内大型水果品牌商，其香蕉通常执行的是**高于国家标准**的“企业标准”或内部收购标准，主要针对**鲜食香蕉的分级、外观、成熟度、糖度、农残**等指标。企业标准一般会参考国标（如GB/T 9827-2017《鲜香蕉》或NY/T 1395-2007《香蕉等级规格》）但更严格。

**2. 与国标的差异（常见差异点）**
- **糖度（可溶性固形物）**：
  - **国标**：通常不强制规定具体糖度值，只要求“果实正常成熟，无明显异味”，但推荐值一般在**15-20°Brix**（可溶性固形物含量）之间。
  - **佳农等高端品牌**：企业标准可能要求糖度**≥18°Brix**（甚至更高），以确保甜度口感的稳定性。实际上市售佳农香蕉的糖度通常在17-22°左右。
- **果指长度**：
  - **国标**：一般规定单果指**长度≥13cm**（中果等级），大果要求≥16cm（参考GB/T 9827-2017的分级标准：特级≥16cm，一级≥14cm，二级≥12cm）。
  - **佳农**：其主打“佳农”品牌的香蕉通常要求**单指长度≥16cm**（特级大果标准），部分出口级或臻选产品可能要求**≥18cm**，且对果指均匀度、弯曲度有更严格筛选。
