关于香蕉的到货损耗率和佳农的赔付条款，建议分两点来看：

**1. 行业平均损耗率（5%）与佳农的实际情况**

- **5%是行业综合均值**，通常是指从产地到一级批发或大型商超总仓的**途损率**（包括自然失水、机械损伤、温控不当等）。
- **佳农（Goodfarmer）作为国内头部香蕉品牌**，其标准化程度较高，主要做产地直采和全程冷链，**常规到货损耗率通常在3%~5%之间**，甚至部分优质订单能控制在3%以内（尤其对一级果或特级果）。
- 但请注意：**损耗率与采购等级、成熟度要求、运输距离、季节（夏季高温损耗会显著升高）直接相关**。如果是远途海运（如菲律宾、厄瓜多尔），且要求收货时较黄，损耗可能接近或超过行业均值。

**2. 赔付条款（关键）**

- **佳农没有公开统一的“标准赔付条款”**，因为批发商、大型商超、电商平台（如盒马、永辉、叮咚）与佳农的合作合同各不相同。
- **对商超/连锁渠道：** 通常有**到货质检+损耗返利**条款，例如“到货损耗率超过X%的部分，按采购价折算退款”或“对于黑心、严重压伤等非可接受瑕疵，按比例退换”。
- **对批发/经销商：** 更常见的是**“以补代赔”**，即次批订单减量让利，而非直接现金赔付；且需保留开箱视频、物流单、现场照片，并在**48小时内**反馈。
- **对生鲜电商/社区团购：** 佳农会签订**售后协议**，一般会设置“损耗率上限（如6%），超出部分按件赔付”，但具体数字需以双方合同为准。

**建议的实操做法：**

- **不要依赖口头承诺**，要求业务员在合同或订单备注中写明“**到货损耗率≤X%，超出部分按采购价退款**”字样，并约定“**收货后48小时内提供视频/照片**”。
- 如果你是单次小批量采购，建议直接与佳农区域销售确认当季“途损率”和“售后政策”，不要默认5%就是他们的标准。
