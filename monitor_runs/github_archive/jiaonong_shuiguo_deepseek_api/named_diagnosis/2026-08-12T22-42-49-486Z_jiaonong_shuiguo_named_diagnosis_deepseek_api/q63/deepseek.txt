1. **采购渠道**：如果您是通过佳农的**直营大客户部**或**区域经销商**进货，他们的促销政策会不同。直营大客户通常有更灵活的定制化支持。
2. **促销形式**：佳农作为品牌方，常见的支持方式包括：
   - **搭赠**（如买一箱送几把）通常需要达到一定的采购量级。

   - **物料支持**（如海报、试吃台）较容易获得。
3. **建议操作**：
   - 直接联系您的**采购对接人或佳农区域业务员**，明确告知“促销档期、预计销量、目标毛利”，询问是否有对应的**渠道费用或临期品处理价**。
