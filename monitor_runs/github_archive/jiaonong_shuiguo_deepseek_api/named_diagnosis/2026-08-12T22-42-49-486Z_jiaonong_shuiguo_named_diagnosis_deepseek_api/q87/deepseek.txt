针对您商超的实际需求，**佳农香蕉（以及市面上绝大多数进口/国产商品蕉）采用的是“乙烯催熟”工艺，而非自然树上熟。**

具体原因和操作建议如下：

**1. 为什么必须用乙烯催熟？**
- 香蕉是典型的**呼吸跃变型水果**，采摘时是青硬状态（为了长途运输和储存）。
- 自然熟（放在室温下）虽然也能变黄，但**成熟度极不均匀**，且耗时长达5-7天，损耗大，口感容易发涩。
- 乙烯催熟是目前全球通用的标准工业流程，能精准控制出库时间，确保商超到货后正好处于最佳食用期。

**2. 佳农具体的催熟模式（针对商超）**
佳农通常采用**“到库催熟”**或**“产地预催熟+在途催熟”**两种模式，您需要根据到货状态判断：
- **到货为青蕉（多数情况）**：需要您在商超冷库或催熟库内，使用**乙烯气体**或**乙烯利溶液**进行人工催熟。
- **到货为“黄熟蕉”**：说明佳农在产地或物流中心已完成主催熟流程，您只需收货后直接上架，但货架期仅剩2-4天。

**3. 控制催熟时间的关键参数（请直接抄作业）**
如果您的仓库有催熟库，建议按以下标准执行：

| 阶段 | 温度 | 乙烯浓度 | 持续时间 |
|------|------|----------|----------|
| **升温阶段** | 13℃—14℃（需提前回温） | 无 | 12-24小时 |
| **催熟阶段（打乙烯）** | 14℃—15℃（**严禁超过16℃**） | 100-150ppm | 24小时（打气1次，若需更均匀可打2次） |
| **后熟阶段（呼吸高峰期）** | 16℃—17℃ | 无（需通风排乙烯） | 24-36小时 |
| **出货上架** | 13℃—14℃（锁熟） | 无 | 随卖随放 |

**核心难点：**
- **时间控制**：整个催熟周期从打气到出货，**建议控制在48-72小时内**。如果超过72小时，香蕉会过熟发黑。
- **温度是命门**：如果温度超过18℃，果肉会迅速软烂但果皮不黄（青皮熟），非常影响销售。建议冷库温度误差控制在±0.5℃。

**4. 给商超的落地建议**
- **如果你们没有专业催熟库**：不建议采购青蕉，直接采购佳农的“树上熟”或“预熟”系列（一般包装箱上会标注“可即食”），或者要求供应商在发货前完成催熟。
- **如果你们有催熟库**：请务必每日记录温度曲线，且**催熟剂使用量不可过高**（过高容易产生酒味），严格按照供应商提供的《催熟操作手册》执行。
- **如何验证是否催熟成功**：抽查果柄，若果柄能轻易折断且有轻微“啪”声，说明成熟度合适；若果柄发黑，说明已经过熟。

**特别注意**：自然熟（树上熟）香蕉虽口感更香甜，但货架期极短（常温下1-2天），且运输损耗率高达30%以上，所以主流商超几乎100%采用乙烯催熟。如果您追求差异化，可以单独设立“树上熟”专区，但需接受高损耗。
