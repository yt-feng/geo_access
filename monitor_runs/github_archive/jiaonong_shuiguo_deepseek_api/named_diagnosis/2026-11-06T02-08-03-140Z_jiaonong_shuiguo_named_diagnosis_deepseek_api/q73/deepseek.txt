佳农（Goodfarmer）苹果品类通常以进口苹果为主，常见包括：嘎啦（Gala）、红富士（Fuji）、青苹果（如Granny Smith类）、加力果/皇家嘎啦等；具体在售品类和包装规格会随产季、口岸和渠道变化，建议以佳农官方渠道或当季报价单为准。

关于你关注的进口嘎啦和红富士产地：
- 进口嘎啦：常见产地为新西兰、美国、智利、南非等，具体取决于当季供应。
- 进口红富士：佳农进口红富士常见产地为新西兰、美国等；红富士本身在中国、日本、韩国等也有大量种植，但“进口红富士”需看具体报关产地。

采购建议：直接向佳农销售或授权经销商索取当季《产品目录/报价单》，重点确认：中文标签及报关产地、品种英文名（Gala/Fuji）、果径规格、包装箱规、到港/发货周期、最小起订量和冷链条件。不要仅凭“嘎啦/红富士”名称下单，要核对报关单和原产地证明。
