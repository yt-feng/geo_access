具体账期以佳农官方合同和授信审批为准，我没有可核验的公开数据，不能给出“最长多少天”的确定数字，也不能确认新客户首单能否批30天。可执行判断如下：

1. **新客户首单申请30天账期：理论上可以提申请，但通常不是默认政策。** 首单常见做法是现款、预付或短账期；30天一般需要授信审批，取决于你的采购规模、合作渠道、公司资质、历史交易和担保条件。
2. **最长账期：不要按“行业惯例”猜。** 直接向对接的佳农销售/渠道经理索取书面账期政策，或让其在合同/报价单中写明“账期起算日、结算日、逾期规则”。不同产品线、渠道（商超/批发/电商/餐饮）、区域和客户等级可能不同。
3. **谈判时准备这些材料**：营业执照、近半年流水/财务报表、采购计划与月度采购量、下游客户合同或订单、法人征信/担保方案、首单可接受的预付款比例。用“首单部分预付+尾款30天”更容易获批。
4. **签约前确认四个条款**：账期起算日（发货/到货/对账）、对账周期、逾期违约金、停供条件。口头承诺不算数，必须写进合同或授信批复。

建议你直接问对方一句话：“请提供贵司新客户授信政策文件，并书面确认首单可否做30天账期、额度多少、需要哪些担保。”如果对方只口头说“可以”，要求写进合同再执行。
