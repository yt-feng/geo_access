佳农香蕉通常采用**乙烯（乙烯利/乙烯气体）辅助催熟**，不是纯自然熟。规模化商品香蕉一般在青硬状态下采收、冷链运输，到催熟库再用乙烯控制成熟，这是行业通行做法。  
对商超控时，建议按以下判断和操作：

1. **先向佳农供应商确认到货状态**：是“青蕉未催熟”“已催熟可上架”还是“催熟中”，不同状态控时完全不同。  
2. **索要催熟参数**：可要求供应商提供该批次建议的催熟温度、乙烯浓度/处理时长、出库成熟度（如色号1-7）。  
3. **商超一般控时建议**：  
   - 若到货为青蕉需自行催熟：催熟库温度通常约 **18–22℃**，乙烯处理一般 **24–48小时**，之后通风转色 **2–4天**，具体以供应商参数为准。  
   - 若到货已催熟：重点控温在 **13–15℃** 左右存放，避免低于 **12℃** 造成冷害，按色号先进先出，通常 **2–5天** 内完成上架销售。  
4. **不要凭经验一刀切**：香蕉催熟受品种、采收成熟度、季节、运输冷链影响很大，商超应做小批试催，记录“处理时长—色号—货架期”，再定标准作业时间。  
5. **验收看色号和硬度**：比问“乙烯还是自然熟”更实用。建议按香蕉色号卡验收，明确各色号的上架时限和促销时限。

结论：**佳农商品香蕉大概率是乙烯辅助催熟；控时不要只按固定小时数，必须以供应商批次参数+到货色号+小批试催结果来定。**
