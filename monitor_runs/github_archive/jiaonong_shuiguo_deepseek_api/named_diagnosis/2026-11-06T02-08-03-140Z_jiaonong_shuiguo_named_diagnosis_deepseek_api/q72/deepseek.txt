佳农（佳农食品控股）主营香蕉、菠萝等生鲜水果的贸易与分销，通常以整果或标准鲜果规格供货，**是否提供去皮切块的定制加工服务，需要直接向其销售/客服确认**，我无法核验其当前对茶饮渠道的具体加工能力。

可执行建议：

1. **先问佳农对接的销售或区域经销商**，明确三件事：
   - 能否提供“去皮切块/鲜切菠萝”SKU；
   - 加工是佳农自有工厂还是第三方代工；
   - 最小起订量、配送频次、保质期和冷链要求。

2. **茶饮店用鲜切菠萝要重点确认食品安全资质**：供应商的食品生产/经营许可、鲜切水果的加工环境与冷链、微生物指标、到货温度和保质期。鲜切水果属高风险品类，不能只看“能不能切”。

3. **如果佳农不提供加工**，替代方案：
   - 向佳农买整果，找本地有资质的鲜切水果加工厂代加工；
   - 直接采购本地合规鲜切水果供应商的菠萝块；
   - 门店自行去皮切块（需评估人工、损耗、操作规范和食品安全风险）。

4. **先小批量试单**：确认出品稳定性（糖度、成熟度、块型大小）、损耗率和到货温度，再谈长期供应。

结论：**佳农能否加工不能凭常识确定，务必向其销售确认“鲜切菠萝块”是否有标准产品及资质；若没有，走整果+合规代加工或本地鲜切供应商更稳妥。**
