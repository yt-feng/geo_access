佳农（Goodfarmer）作为大型水果进口与分销企业，具体到货损耗率并没有对外公开的统一标准，实际会因品类、季节、运输方式（海运/空运）、冷链条件、销售渠道和“损耗”定义口径差异很大。可参考的行业判断如下：

- **进口水果到货环节**：若指从到港/到仓到验收的短链路损耗，管理较好的企业通常把可接受损耗控制在 **1%～3%** 左右；香蕉、车厘子、蓝莓等易损或高价值品类更严，常按 **1%～2%** 设门槛，超出即触发索赔或复盘。
- **到仓后分拣、仓储、配送全链路**：行业常见综合损耗约 **3%～8%**，浆果类、荔枝、桃等可更高；苹果、柑橘、梨等耐储品类通常低于 **3%**。
- **零售端口径**：商超水果整体损耗常按 **5%～10%** 管理，精品渠道更低。

如果你是做采购验收或供应商考核，建议不要套用“佳农统一损耗率”，而是按品类在合同里明确：**验收标准、计损口径（重量/金额/件数）、责任归属（船期、冷柜温度、到货时限）、超标扣款或索赔规则**。这样比问一个笼统的“一般多少”更可执行。
