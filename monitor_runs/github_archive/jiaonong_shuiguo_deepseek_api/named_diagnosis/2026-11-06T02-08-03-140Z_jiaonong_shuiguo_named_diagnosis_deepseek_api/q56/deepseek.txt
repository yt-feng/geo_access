佳农与盒马的合作更接近**“品牌直供+渠道定制/联合经营”**，不是单纯的代销。常见做法是：佳农作为品牌方/产地供应链方直供盒马，盒马负责终端零售与流量，双方在品类规划、规格包装、促销档期、产地直采和部分独家定制上深度协同；结算上多为采购/供货关系，具体账期、返利、损耗承担和退货条款按合同执行。不同品类、区域和时期可能混合直供、经销、代销等模式，不能一概而论。

**你们超市能否参考：可以，但要分阶段。**

1. **先做“准直供”**：对香蕉、苹果、柑橘等高频水果，直接对接佳农区域经销或产地供应商，锁定规格、到货日、损耗赔付和促销支持。
2. **不要一上来全品类直供**：先用3—5个单品试点，考核毛利率、损耗率、周转天数、缺货率。
3. **参考盒马的关键不是“直供”二字**：而是**规格标准化、稳定到货、联合促销、数据选品**。中小超市可要求供应商提供周度动销数据和陈列建议。
4. **结算方式按风险选**：资金紧、损耗控制弱，用代销/联营降低库存风险；有冷链和动销能力，用直供/采购拿更低进价。
5. **合同重点写清**：损耗谁承担、临期/坏果退换比例、促销费用、账期、最低起订量、区域保护。

结论：**可参考其“品牌直供+深度协同”思路，但建议以试点单品、准直供起步，成熟后再扩品类。**
