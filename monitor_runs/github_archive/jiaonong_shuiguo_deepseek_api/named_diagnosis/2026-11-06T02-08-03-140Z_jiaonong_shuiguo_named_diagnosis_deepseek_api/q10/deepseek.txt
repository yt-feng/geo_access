大概率有：佳农（Goodfarmer）对批发/渠道客户通常采用“渠道销售+客户经理/区域经理”对接模式，尤其商超、生鲜批发、电商供应链等B端客户会有专人负责。但我无法核验其当前组织架构和具体对接政策，不能给你确定的人员配置结论。

你可按下面方式确认并拿到对接人：

1. **走官方渠道问“批发/渠道合作”**
   - 佳农官网/公众号找“联系我们/商务合作/渠道合作”，说明你是批发商、品类、月采购量、所在区域、配送方式。
   - 要求分配“区域客户经理”或“渠道经理”。

2. **直接问三个明确问题**
   - 我们这类批发商是否由专门客户经理对接？
   - 对接人是区域经理还是品类经理？覆盖哪个区域？
   - 首次合作需要哪些资质和起订量/账期政策？

3. **通过当地经销商/批发市场反向确认**
   - 问佳农当地经销商或一级代理，通常能最快知道你所在区域归谁管。

4. **沟通时准备信息提高匹配效率**
   - 公司名称、所在城市、批发市场/仓库、主营品类、预计月采购量、结算方式、是否要冷链配送。

判断标准：如果对方能明确给出**区域负责人姓名/联系方式、报价体系、起订量和账期规则**，基本就是专门对接；如果只让你找当地经销商，说明该区域可能走经销体系而非直营客户经理。
