配送时效取决于你下单的渠道、收货城市和商品类型（普通水果还是冷链品），没有统一答案。可以按这个方式判断：

1. **先确认渠道**：佳农在电商平台（京东、天猫、拼多多等）、商超到家（美团/饿了么/京东到家）和线下商超的履约主体不同，时效由对应平台或门店决定，不是佳农统一承诺。
2. **看页面承诺**：下单页通常会写“预计送达时间/发货时效”。**以结算页显示为准**，比客服口头说法更可靠。
3. **按城市粗判**：
   - 一线/新一线城市，平台自营或前置仓通常**当日达或次日达**；
   - 二三线城市多为**次日达~2-3天**；
   - 偏远地区、需冷链的进口水果可能**3-5天或更久**。
4. **冷链品要单独看**：如车厘子、蓝莓等，可能从产地/仓直发，时效会标注“预售/发货后X天送达”。
5. **下单前做两件事**：填好收货地址看结算页时效；截屏保存承诺时效，超时可据此找平台售后。
