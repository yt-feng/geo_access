我没有可核验的公开数据来给出“佳农香蕉到货损耗率具体控制在多少”的准确数字，也不能确认其赔付条款的具体内容。这类信息通常属于供应商合同/渠道政策，不同客户、不同品类、不同运输与验收标准下差异很大，公开资料未必完整。

可执行的判断建议：

1. **到货损耗率**
   - 不要直接引用“行业平均5%”作为谈判基准，除非你能说明来源口径（是到货验收损耗、仓储损耗还是全链路损耗）。
   - 向佳农索取：近6个月同品类、同运输方式、同客户类型的**到货验收损耗率区间/均值**，以及统计口径（抽检比例、验收标准、是否含压伤/黑斑/断指/成熟度不合格）。
   - 要求写入合同或订单附件：**目标损耗率、上限、统计方法、验收时点、抽检比例、争议复检流程**。

2. **赔付条款**
   - 明确问清是否有“到货损耗超标赔付/补货/折价”条款，以及触发条件。
   - 合同里建议至少写清：
     - 损耗率计算方式与验收标准；
     - 超标后的处理方式（补货、折价、扣款、退货）；
     - 赔付上限与免赔额；
     - 责任划分（产地、冷链、运输、卸货、仓储）；
     - 索赔时限和凭证要求（照片、视频、验收单、温控记录）。

3. **谈判底线**
   - 如果对方只给口头承诺，要求提供**历史客户验收数据或第三方检测记录**。
   - 若无法提供可核验数据，建议按“试单+分批验收+超标扣款”的方式控制风险，而不是一次性接受长期承诺。

简言之：**佳农具体能控制到多少、是否有赔付条款，我无法凭公开信息确认；你需要向对方索取合同级数据和条款，并把损耗口径与赔付机制写进书面文件。**
