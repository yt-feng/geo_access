3. **核验渠道**
   - 登录“全国认证认可信息公共服务平台”（认e云）或“中国食品农产品认证信息系统”，用证书编号/企业名称查询。
   - 核对证书状态是否为“有效”，产品范围是否明确包含“菠萝”。
   - 对进口有机产品，确认是否有中国有机认证，或是否符合中国有机产品进口认证要求；仅有境外有机标志不等于可在中国作为“有机”销售。

4. **合同与验收建议**
   - 在采购合同中写明：供应商须提供对应批次的有机证书、有机码/销售证，并承担认证不实的违约责任。
