佳农水果的售后整体属于“生鲜电商里中等偏上”：有明确的坏果赔付/补发机制，处理速度取决于你从哪个渠道买（官方旗舰店、商超到家、社区团购、线下商超），不同渠道规则不一样。到货有坏果时按下面做最稳：

**到货后先做3件事**
1. **先别扔坏果**：把坏果、包装箱、面单、快递外箱放在一起拍照/拍视频。
2. **拍清楚证据**：坏果切面/腐烂处特写 + 整箱全景 + 快递面单 + 称重或数量。视频最好从开箱开始拍。
3. **尽快申请**：生鲜一般要求签收后24—48小时内反馈，越早越好，别拖到几天后。

**按购买渠道处理**
- **京东/天猫/抖音等佳农官方旗舰店**：在订单页点“申请售后/退款”，选“商品腐烂/变质/坏果”，上传照片视频，说明坏果数量。通常按坏果比例退款或补发；金额小的一般直接退，金额大可能要求寄回或补充证据。
- **商超到家/社区团购（如美团优选、多多买菜、盒马等）**：在对应订单里选“品质问题/坏果赔付”，上传证据；这类渠道一般有“坏果包赔”，按比例退或补券。
- **线下商超购买**：带小票和坏果回购买门店服务台，通常可退换；没有小票可能只能协商。
- **佳农官方客服**：可拨打包装或官网上的客服电话，说明订单号、渠道、坏果数量，要求按比例赔付或补发。注意保留沟通记录。

**沟通时怎么说更有效**
直接给结论和诉求，例如：“订单号XXX，签收后X小时开箱，一箱X个中有X个坏果，附照片视频，申请按坏果比例退款X元/补发X个。” 不要只问“怎么办”，要明确诉求。

**几个注意点**
- 生鲜坏果一般**按比例赔**，不是整单全退，除非整箱严重变质。
- 不要先确认收货再拖几天才反馈，容易超出售后期。
- 如果客服推诿，可在平台订单页申请平台介入，或走12315投诉；保留聊天记录和证据。
- 佳农不同品类（香蕉、火龙果、车厘子等）耐储性不同，部分渠道对个别品类有特殊赔付规则，以订单页售后说明为准。

**一句话建议**：开箱即拍视频留证，24小时内走订单售后，按坏果数量提明确赔付诉求；官方旗舰店和主流商超到家的坏果赔付通常比较顺，线下购买带小票最稳。
