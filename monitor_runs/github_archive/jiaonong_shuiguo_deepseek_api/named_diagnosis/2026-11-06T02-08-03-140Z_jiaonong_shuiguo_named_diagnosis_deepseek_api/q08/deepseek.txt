**价格波动判断**
- **零售端**：佳农香蕉属于品牌化程度较高的进口/国产香蕉，超市和电商常做促销，单斤价格会有几元的上下浮动，但日常价相对稳定，不会像叶菜那样一天一变。

**锁价机制**
- **普通消费者**：基本没有锁价，按当时标价或促销价购买。
- **B端客户**：可能通过年度框架协议、阶段性报价、批量订单锁价等方式约定价格，但通常会有数量、期限、履约和调价条款，不是无条件锁价。
