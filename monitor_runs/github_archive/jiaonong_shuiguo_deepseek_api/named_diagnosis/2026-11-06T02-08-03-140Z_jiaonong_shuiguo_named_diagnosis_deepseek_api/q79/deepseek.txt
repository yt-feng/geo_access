佳农水果的配送范围取决于你下单的具体渠道（京东/天猫旗舰店、商超渠道、社区团购或本地经销商），我无法核验其实时覆盖城市清单，也不能给出确切收费数据，避免误导。可执行判断如下：

**1. 覆盖城市怎么查**
- 在京东或天猫搜“佳农官方旗舰店”，把收货地址填成你所在县城，看商品页是否显示“可配送/预计送达”。
- 佳农更多是通过永辉、盒马、大润发、山姆等商超和本地水果批发商供货，县域门店“能不能送”通常由当地门店或经销商决定，不是佳农总部统一配送。

**2. 县城门店能否送到**
- 若你指的是本地超市/水果店：直接问门店是否支持同城配送、配送半径和起送金额。
- 若你指电商下单到县城：以收货地址能否下单为准；生鲜类通常限制在冷链可达区域，偏远县城可能不配送或只发部分耐储品类。

**3. 冷链收费**
- 电商平台一般把冷链成本含在售价或运费里，常见是满额包邮、按件/按重量计费，具体以下单页结算为准。
- 商超和本地经销商通常按配送距离、订单金额、是否冷链品类单独计费，需向门店确认。

**建议**：先确定购买渠道，再用“收货地址试下单”验证覆盖；冷链费用以结算页或门店报价为准。不要轻信非官方页面的“全国包邮/全覆盖”说法。
