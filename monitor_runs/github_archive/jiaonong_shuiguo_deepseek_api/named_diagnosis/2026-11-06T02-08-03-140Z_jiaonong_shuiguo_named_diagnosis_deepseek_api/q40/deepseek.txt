   - 直接联系佳农官方客服或区域销售，询问是否有“餐饮渠道/B端大客户/饮品连锁”专用对接。
   - 关键词问清楚：是否有餐饮专供规格、是否支持定制切型、是否有稳定年度供应协议。

2. **餐饮渠道常见可谈的菠萝方案方向**
   可重点问以下几类，基本都是餐饮菠萝供应的核心需求：
   - **鲜果整果**：按门店用量分级供应，适合现切果盘、甜品。
   - **鲜切/预处理菠萝**：去皮、去眼、切块/切片/切丁，冷藏配送，适合连锁餐饮标准化。
   - **冷冻菠萝块/丁**：适合饮品、烘焙、果酱、批量稳定出品。
   - **浓缩菠萝汁/果浆**：适合茶饮、咖啡、甜品店调制。
   - **定制规格**：按克重、切型、糖度区间、包装规格做B端定制。

3. **向佳农确认时必须问的5个问题**
   - 是否有餐饮渠道专属SKU和报价体系？

   - 能否提供稳定糖度区间和批次一致性？
   - 是否支持门店端预处理（鲜切）或中央厨房配送？
   - 是否有样品测试和菜单应用支持？

4. **风险提示**
   - 不要仅凭“佳农有菠萝产品”就推断一定有成熟餐饮解决方案；餐饮渠道方案通常涉及冷链、切型、稳定供应和定制包装，需书面确认。
   - 如果是连锁餐饮或茶饮品牌，建议直接要求区域经理提供**餐饮渠道案例、SKU清单和供货协议模板**。
