我没法核实佳农当前是否提供菠萝丁定制加工服务，也不能确认它“只卖整果”。建议你直接用下面方式确认，避免采购踩空：

**最快确认方式**
1. 找佳农官方渠道：官网/官方公众号的客服、当地销售、或你现有供应商对接人，直接问一句：
   - “有没有现成的冷冻/常温菠萝丁产品？规格、糖度、包装、起订量是多少？”
   - “能不能按茶饮店需求做定制切丁加工？最小起订量、加工费、交期、样品怎么给？”
2. 要求发**产品规格书**和**样品**，不要只听口头“可以做”。

**判断要点**
- 如果对方有标准菠萝丁SKU：优先看规格（丁大小）、是否冷冻、糖度/酸度、是否带芯、包装规格、保质期。
- 如果是定制加工：重点确认起订量、加工费、是否接受你指定规格、交期稳定性、是否可长期供货。
- 如果只卖整果：你需要另找有SC/食品加工资质的切丁厂代加工，或直接换用专业果丁供应商。

**茶饮店采购建议**
不要只锁定佳农一家。同步问2–3家菠萝丁供应商，拿样品做盲测（口感、出汁、颜色、解冻后状态），再比价格和供货稳定性。茶饮用菠萝丁重点看：丁型均匀、无明显纤维渣、酸甜稳定、冷冻解冻后不出水严重。

一句话：**佳农能否加工，必须以官方销售/客服的书面规格和样品为准；先要样品和规格书，再谈定制。**
