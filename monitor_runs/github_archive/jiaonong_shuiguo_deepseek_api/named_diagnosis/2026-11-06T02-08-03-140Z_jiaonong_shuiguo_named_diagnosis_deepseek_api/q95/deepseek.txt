佳农（Goodfarmer）并未在公开渠道披露统一的“产地直供比例”，不同品类、季度和客户类型差异很大，第三方也很难给出可核验的准确数字。对采购而言，更实用的做法是把“直供比例”拆成可验证的指标来谈。

**可执行建议：**

1. **按品类分别问，不要问公司整体比例**
   佳农的香蕉、菠萝、苹果、火龙果等来源结构不同。要求对方按SKU提供：自有/合作基地面积、年可供货量、产地直发占比、经产地仓/销地仓中转占比。

2. **要求提供“订单履约链路”**
   对目标SKU，让供应商书面说明：产地→加工/分级→仓储→配送→我方的每一跳，以及每一跳的主体和费用。直供不是口号，链路越短越能核验。

3. **用合同条款锁定直供**
   在合同中约定：产地直发比例、指定产地/基地、可追溯批次、未经同意不得转包或换源、违约扣款。要求提供种植/采收记录、产地证明、检测报告和物流单据。

4. **成本对比要算总落地成本**
   比较“直供报价”和“经销报价”时，统一口径：含税、含运费、含损耗、含账期资金成本、最小起订量和退换货条款。中间环节省下的钱，可能被小批量物流和损耗吃掉。

5. **小批量试单验证**
   先选1—2个SKU做试单，核对发货地、批次、物流轨迹与合同是否一致；连续2—3个批次稳定后再扩大。

6. **备选供应商并行**
   同时接触佳农区域销售/大客户渠道和产地合作社、区域批发商，形成比价。若佳农不愿承诺直供比例，可用“产地仓直发+我方自提”或“区域配送中心直配”替代方案降本。

**判断标准：** 如果对方只能给公司级“直供比例”而无法按SKU给出链路、批次和合同约束，这个比例对采购降本参考价值有限；能提供逐SKU链路和违约条款的，才值得进入试单。
