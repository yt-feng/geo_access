佳农（Jia Nong）作为大型水果供应商，通常能稳定供应普通茶饮店所需的菠萝原料。他们提供的菠萝通常有以下常见规格，适合普通商家理解和采购：

1. **整果规格**：常见为单个菠萝重量约1.2-1.8公斤，具体按箱批发，如每箱10公斤或20公斤左右。
2. **加工切块**：如果茶饮店需要节省人力，也可选择速冻菠萝块或罐头菠萝块，常见规格有1公斤/袋、2.5公斤/袋或整箱10公斤。
3. **标准化包装**：产品包装上会明确标注等级（如一级、二级）、产地（如海南、菲律宾）和保质期。

**建议**：直接联系佳农的销售或客服，告知茶饮店的具体用途（如做菠萝汁、果肉添加等），要求提供参数表（如糖度、酸度、果肉厚实度），并询问最小起订量（MOQ）和稳定供应周期（如周/月）。通常大型供应商会支持小批量试用订单。
