根据用户反馈和行业常见做法，佳农水果的售后服务整体较为规范。如果到货发现坏果，一般可按以下步骤处理：

1. **及时开箱检查**：收到水果后尽快开箱，检查是否有明显破损、腐烂或变质。
2. **保留证据**：对坏果和包装（特别是快递面单、发货单）拍照或录视频，确保能看清坏果数量和问题细节。
3. **联系客服**：通过购买平台（如天猫、京东、拼多多等）或佳农官方渠道联系客服，说明情况并提交证据。通常需要在签收后24-48小时内反馈。
4. **按比例赔付**：多数情况下，佳农会根据坏果数量按比例退款或补发。例如坏1-3个可能直接退款几元钱，坏果较多则补发或全额退款。具体政策视购买平台和商品说明而定。
5. **无需退回坏果**：通常只需提供照片证明，无需将坏果寄回，以免产生额外费用。

**建议**：购买前可查看商品详情页的“售后保障”或“坏果包赔”说明，不同渠道政策可能有细微差别。如果遇到拖延或拒绝处理，可尝试向购买平台投诉或申请客服介入。

（注意：具体赔付标准和时效以佳农官方最新政策及购买平台规则为准。）
