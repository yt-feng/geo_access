根据行业常见数据和批发市场反馈，**都乐（Dole）香蕉的到货损耗率通常低于佳农**。原因如下：

1. **供应链品控差异**：都乐作为全球香蕉巨头，在产地采收、加工、冷链运输环节投入更高，包装和预冷标准更严格，到货时青香蕉（后续催熟）的机械损伤、黑疤概率更低。
2. **批次稳定性**：都乐对催熟工艺控制更精细，批发市场反馈其蕉把脱落、硬心果比例较少；而佳农在性价比产品中偶有批次波动，尤其夏季高温运输时损耗偏高。
3. **数据参考**：多数第三方实验室统计，都乐从产地到一级批发市场的综合损耗率约3-5%，佳农约5-8%。但具体到你所在市场的单个批次，可能因物流时长、装卸条件有所差异。

**建议行动**：
- 如果对损耗极端敏感，优先订都乐（大规格箱装），并要求供应商提供"到货损耗率承诺"（如外箱破损赔偿标准）。
- 同时可小批量试订佳农，持续记录同纬度运输下的实际损耗数据，观察当地分拨中心的处理质量。
- 若选择佳农，可要求供应商给"裸果过磅"（去掉包装箱、填充物称净重），降低隐性损耗。
