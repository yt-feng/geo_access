佳农水果的苹果品类中确实有红富士。至于与鑫荣懋相比哪个性价比更高，需要结合具体产品、购买渠道和价格波动来看：

1. **佳农红富士**：通常以果径较大（如80#以上）、甜度高、果肉脆爽为卖点，价格偏中高端。如果遇到促销或整箱购买，性价比会提升。
2. **鑫荣懋红富士**：常有不同规格（如75#、80#），价格覆盖面较广，尤其是基础规格的产品定价可能更亲民，适合日常食用。

**建议对比方法**：
- 查看同渠道（如超市、电商平台）同等级（如果径80#、礼盒装或散装）的实时价格。
- 关注产地：红富士主要来自陕西、山东、甘肃。佳农部分产地可能更集中在高端产区（如陕西洛川），鑫荣懋可能多源采购，性价比可能在中端规格上体现。
- 注意季节：每年10月-次年1月是新果上市期，此时性价比普遍高；春季后存储果价格可能上升。

**最终判断**：若偏好大果、稳定品质且预算充足，选佳农；若追求日常实惠、灵活规格，鑫荣懋可能更优。建议用具体规格的实时价格除以克重，计算单位成本对比。
