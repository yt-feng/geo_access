佳农香蕉没有统一“保质期”，主要看状态和储存温度。可按下面判断和操作：

**1. 储存条件**
- **未熟/偏青香蕉**：放在**室温阴凉通风处**，避免阳光直射，不要急着放冰箱。可和苹果一起放纸袋里加速催熟。
- **已熟香蕉**：尽快吃；想延缓变黑可放**冰箱冷藏**，但表皮会变黑，果肉通常还能保持几天。冷藏后口感会变软。
- **不要**：高温暴晒、密封塑料袋久放、和大量乙烯水果长期混放。

**2. 大致可放多久**
- **室温偏青**：约 **3–7天** 转熟，具体看室温。
- **室温已熟**：约 **1–3天** 内吃完较好。
- **冷藏已熟**：可再放 **2–5天**，但表皮会变黑，需看果肉是否软烂、有酒味。
- **切开后**：密封冷藏，建议 **24小时内** 吃完。

**3. 判断是否还能吃**
- 可以吃：表皮有少量黑点、果肉颜色正常、无异味。
- 不建议吃：果肉大面积软烂、流汁、有酒味/酸味、霉斑。

**4. 购买建议**
按“几天内吃完”来买；想放久一点，买**偏青、无磕碰**的，回家后常温催熟，熟后尽快吃或冷藏。包装上若标注了具体日期，以包装标注为准。
