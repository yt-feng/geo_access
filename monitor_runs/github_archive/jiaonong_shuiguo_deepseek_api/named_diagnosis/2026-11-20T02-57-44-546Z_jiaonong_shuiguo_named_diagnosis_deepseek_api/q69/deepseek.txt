公开信息无法核实佳农是否提供餐饮渠道的菠萝切片/切块定制规格。通常这类B2B定制（规格、切型、包装、冷链、起订量）需要直接对接佳农官方渠道确认：

**建议核实路径**
1. 佳农官网/公众号找“餐饮渠道/大客户/批发合作”入口，提交需求表单。
2. 拨打官方客服电话，明确问：餐饮渠道菠萝是否有切片/切块、真空包装或冷冻规格、单袋克重、箱规、起订量与供货区域。
3. 通过大型餐饮供应链平台或当地果蔬批发商询问佳农餐饮装菠萝的现货规格。

**沟通时可直接问的要点**
- 是否有鲜切菠萝片/块、冷冻菠萝块或糖水菠萝块；
- 切型尺寸（如片厚、块径）、单包克重、每箱包数；
- 是否支持按门店/菜单定制包装与标签；
- 最小起订量、配送频次、保质期与冷链要求；
- 报价是否含税运、样品政策。
