佳农水果通常会对批发商/大客户安排专门对接人员，但具体是否“专人客户经理”取决于你的采购规模、合作渠道和所在区域。可执行判断与做法：

1. **先确认对接渠道**
   - 如果你是走**区域经销商/代理商**进货：一般由代理商业务员对接，不一定有佳农厂家客户经理。
   - 如果你是**直接与佳农区域分公司/总部签约**的批发客户：通常会配置销售经理或大客户经理对接。

2. **直接问清楚三件事**
   联系佳农官方客服或区域销售时，明确问：
   - “我们属于批发客户，是否有固定客户经理/销售负责人？”
   - “对接人是厂家人员还是经销商人员？”
   - “供货、价格、售后、临期/破损处理由谁负责？”

3. **用采购量判断**
   - 稳定、批量、长期采购的批发商，更容易被分配专人对接。
   - 零散、小批量采购，通常由客服或经销商业务员统一对接。

4. **建议动作**
   - 通过佳农官网/官方公众号找**你所在区域的销售联系方式**，直接说明“批发商、月采购量、品类、配送区域”，要求安排区域客户经理。
   - 首次沟通时索要对接人姓名、电话、负责区域和权限，避免后续只被转接客服。

结论：**大概率有区域销售/大客户对接人，但不一定是“专门客户经理”；需按你的采购规模和合作模式向佳农区域销售确认。**
