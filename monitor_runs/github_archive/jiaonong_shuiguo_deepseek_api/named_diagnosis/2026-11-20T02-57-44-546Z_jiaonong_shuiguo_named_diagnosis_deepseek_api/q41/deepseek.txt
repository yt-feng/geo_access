佳农属于国内头部进口香蕉供应商之一，整体供货能力比多数区域批发商强，但“每天20吨、旺季不断货”不能只听品牌方口头承诺，需要按下面几点核实后再判断。

**结论先说：**  
佳农具备支撑单店/单系统商超旺季一天20吨的能力，但**任何供应商都不能仅凭品牌保证绝对不断货**。建议把它作为主供，同时保留1家备供，并用合同条款锁定缺口责任。20吨/天相当于约600吨/月，属于较大的稳定采购量，佳农通常会重视，但是否能“优先级保供”取决于你们所在区域、配送仓、合同量和旺季重叠程度。

**需要重点核实的6项：**

1. **区域仓配能力**  
   问清你们门店由哪个佳农区域仓/加工中心供货，到店配送半径、日配送频次、冷链车辆数量。香蕉催熟后周转要求高，仓配半径过长会放大断货风险。

2. **旺季排产与催熟产能**  
   佳农香蕉多为进口后在国内催熟加工。要确认旺季你们所在区域加工中心的日催熟产能、已签约商超占比，以及你们20吨/天能拿到多少固定配额。

3. **产地与船期稳定性**  
   香蕉受菲律宾、厄瓜多尔、越南等产地天气、病害、航运影响。要求供应商说明主要产地结构、是否多产地备份、船期延误时的替代方案。

4. **合同保供条款**  
   不要只签框架协议。建议明确：  
   - 旺季每日最低保供量，例如不低于18吨或20吨的90%；  
   - 缺货提前通知时限，如至少48小时；  
   - 缺口补偿方式：优先调货、承担紧急调货差价、违约金；  
   - 质量标准：单根重量、成熟度、青蕉/黄蕉比例、损耗率上限。

5. **历史履约数据**  
   要求佳农提供近12个月对同区域同量级商超的履约率、缺货次数、平均到货准时率。不能只看其自有报表，最好向其现有客户侧面了解。

6. **备供方案**  
   建议主供佳农占70%—80%，备供1—2家区域供应商占20%—30%。旺季前让备供也实际走单，避免临时找不到货源。

**可执行的谈判话术：**  
“我们旺季稳定需求20吨/天，按月约600吨。希望佳农作为主供，但需要合同约定每日保供下限、缺货预警和补偿机制。请提供你们区域仓的催熟日产能、近12个月履约率，以及旺季同区域其他客户的供货占比。”

如果佳农能明确区域仓、给出固定日配额并接受缺货补偿条款，可以认为供货稳定性较好；如果只愿意给“尽量保证”而不写量、不写预警、不写补偿，则不建议把旺季20吨/天完全押在它一家。
