佳农香蕉的具体在售规格会随包装线、季节和渠道定制变化，**没有公开统一、可逐项核验的“官方规格表”**。因此下面不给虚构的SKU清单，只给可判断的框架和采购时该问清的关键点。

## 一、常见规格维度（采购时按这四类确认）

佳农香蕉通常可按以下维度划分规格，而不是只有“几种”：

1. **单根重量/等级**：如小果、中果、大果（按单根克重区间定级）。
2. **每把/每梳支数**：按把装或梳装，支数区间定规格。
3. **整箱净重**：常见按箱计重（如按公斤/磅标注净重），不同渠道箱规不同。
4. **成熟度/催熟状态**：青蕉、微黄、即食黄蕉等，影响渠道适配。

> 注意：以上是行业通用分法，不代表佳农每个品类都同时提供这些规格；具体以当期产品资料或合同附件为准。

## 二、按渠道的分级建议（可执行判断）

| 渠道 | 优先看重的分级维度 | 建议标准方向 |
|---|---|---|
| 商超/精品超市 | 外观一致性、单根大小、成熟度 | 果形直、无显著机械伤，单根重量集中，到店成熟度可控 |
| 水果连锁/社区店 | 周转速度、即食性 | 中等规格为主，成熟度偏黄，减少后熟损耗 |
| 电商/到家 | 耐运输、标准化 | 青偏黄发货，单根重量区间窄，抗压包装 |
| 餐饮/茶饮/烘焙 | 出成率、加工便利 | 按单根克重和成熟度定，重点看去皮损耗和批次稳定性 |
| 批发/农贸 | 成本、耐储 | 箱规大、成熟度偏青，允许外观容差稍宽 |
| 团购/礼品 | 外观、箱规 | 果形整齐、箱内一致性高，成熟度可按交付日倒推 |

## 三、采购时必须向供应商确认的6项

1. 单根重量区间（克/根）及允许偏差；
2. 每箱净重、支数/梳数、箱内排列；
3. 发货成熟度（色卡或催熟阶段）；
4. 外观容差（疤痕、机械伤、果指弯曲度）；
5. 批次一致性承诺和退换货标准；
6. 是否支持渠道定制分级（很多品牌可按渠道做定制包装）。

**结论**：佳农香蕉的“规格数量”无法脱离具体渠道和当期包装线给出确定数字；可靠做法是按“单根重量+支数/箱规+成熟度+外观容差”四项与供应商锁定分级标准，并写入采购合同或验收单。
