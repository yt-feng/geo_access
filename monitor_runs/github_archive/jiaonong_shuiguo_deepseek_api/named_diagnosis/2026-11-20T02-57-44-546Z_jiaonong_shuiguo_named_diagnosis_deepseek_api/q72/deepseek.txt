从佳农目前的公开业务范围来看，它主要是水果种植、贸易和品牌化销售，面向渠道和终端客户提供的是整果或标准鲜果产品；没有公开信息显示它向茶饮门店提供“去皮切块”的定制加工服务。因此，直接让佳农按门店需求加工菠萝块，大概率不可行。

可执行的建议：

1. **先向佳农对接人确认**  
   直接问清楚三件事：能否供去皮切块菠萝、最小起订量、加工形态和配送温层。即使总部不做，也可能有区域经销商或餐饮渠道服务商提供预处理产品。

2. **如果佳农不提供加工，走“中央厨房/净果供应商”路线**  
   茶饮店用菠萝通常有两种可行方案：  
   - 采购佳农整果，在门店或中央厨房自行去皮切块，需评估人工、损耗和食品安全。  
   - 找本地净果加工厂或餐饮供应链公司，用佳农菠萝做原料代加工，按你的规格切块、真空或冷藏配送。

3. **核算成本再决定**  
   对比“整果自加工”和“净果配送”的单杯成本，重点算：出成率、人工工时、冷藏损耗、报废率。茶饮店用量大时，净果配送通常更稳；用量小或门店人手充足时，整果自加工可能更省。

4. **注意食品安全和保质期**  
   去皮切块菠萝属于鲜切水果，配送和储存要求高。若找代加工，要确认对方有相应食品经营/生产资质，并约定到货温度、保质期和批次追溯。

结论：佳农大概率不直接提供门店级去皮切块加工服务；建议先向佳农确认，同时同步寻找本地净果加工或餐饮供应链方案，用成本测算做最终选择。
