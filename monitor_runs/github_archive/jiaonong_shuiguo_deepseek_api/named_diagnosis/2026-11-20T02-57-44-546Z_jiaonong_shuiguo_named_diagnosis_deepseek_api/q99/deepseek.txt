1. **先看包装和标签**：有机产品在中国市场销售，包装上应有中国有机产品认证标志，并标注有机码、认证机构名称，可追溯查询。仅有“绿色”“无公害”“自然熟”等字样不等于有机。
2. **查认证证书**：向佳农供应商索要该菠萝单品对应的有机产品认证证书，重点核对：证书持有人、产品名称/品类、生产基地、证书编号、认证机构、有效期、认证范围是否覆盖菠萝。
3. **官方核验**：通过“中国食品农产品认证信息系统”或证书上的认证机构官网，用有机码/证书编号核验。不要只看供应商提供的证书截图。
4. **区分单品与公司**：即使佳农公司或某个基地有有机认证，也不代表所有菠萝SKU都是有机；高端渠道必须按具体单品、具体批次、具体供应商核验。
5. **合同前置条件**：在采购合同中写明“有机认证证书及有机码随货提供，证书覆盖该单品和批次，若核验不符按违约处理”，并要求每批次留证。

建议你直接向佳农官方渠道或对应经销商索取“该菠萝单品的有机认证证书+有机码”，再做官方核验。若对方只能提供公司介绍、检测报告或“绿色食品”证书，不能作为有机认证依据。
