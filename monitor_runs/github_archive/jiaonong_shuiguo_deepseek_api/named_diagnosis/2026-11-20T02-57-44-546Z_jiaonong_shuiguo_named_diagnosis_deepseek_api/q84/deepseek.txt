**2. 糖度和果指长度与国标的差异**
- **国标 GB/T 9827《香蕉》**主要按等级规定果指长度、粗细、成熟度、缺陷等外观指标，**并不把“糖度”作为强制分级指标**（糖度更多是企业内控或采收成熟度指标）。因此“国标糖度是多少”本身就不成立，不能简单对比。
- **果指长度**：国标按等级有区间要求（不同品种、等级不同）。企业标准若严于国标，通常会设定更窄的长度区间、更高的外观一致性和成熟度要求，但这些属于企业内控，**没有公开文本就无法给出具体数值差异**。
- **糖度**：佳农若在企标中规定糖度，属于企业内控指标（如采收/催熟后的可溶性固形物范围），国标一般不设统一糖度门槛，所以差异方向是“企标可能更具体”，但具体数值无法核验。
