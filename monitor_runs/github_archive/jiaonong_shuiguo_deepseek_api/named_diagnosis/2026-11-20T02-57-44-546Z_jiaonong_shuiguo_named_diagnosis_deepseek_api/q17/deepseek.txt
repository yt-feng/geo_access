3. **可主动询价的渠道**：佳农官方客服/区域销售、当地大型商超采购、社区团购团长、批发市场档口。问清是否针对县域市场有铺货支持、试吃促销或买赠。
4. **不要轻信“全国下沉市场统一优惠”说法**：若有人以此名义收费加盟或收保证金，建议先核实授权资质。
