佳农水果的“产地直供比例”没有公开、可核验的统一口径，我不能给出一个准确百分比。它通常按品类、季节、产地和渠道口径不同而变化：同一家公司对商超、电商、批发渠道的“直供”定义也可能不同（是公司直采、基地直采，还是配送中心直配）。

对你们采购降本，建议这样核实和推进：

1. **让对方书面定义口径**
   - 要求佳农说明：产地直供是按SKU、采购金额还是采购量计算。
   - 明确“产地”是自有基地、合作基地、产地加工厂还是产地代办。
   - 要求提供近12个月分品类的直供占比和主要产地清单。

2. **用合同条款倒逼透明**
   - 要求报价单拆分：产地采购价、加工包装费、冷链仓储费、干线运输费、配送费、服务费。
   - 约定“产地直发/直配”的SKU清单、起订量、到货时效和损耗责任。
   - 对中间环节设置审计权：可查产地证明、加工厂发货单、物流轨迹。

3. **先做小范围直采试点**
   - 选1—2个高频单品（如香蕉、苹果、柑橘类），对比“佳农直供价”与“产地合作社/加工厂直采价+物流成本”。
   - 用同一规格、同一包装、同一到货城市做30天总成本对比，重点算损耗率和账期成本，而不只看单价。

4. **多源比价**
   - 同时接触产地合作社、产地代加工厂和区域批发商，形成三家比价。
   - 如果佳农直供比例不高，可要求其开放“产地直发”专线，或把非直供SKU替换为直供SKU。

5. **判断是否值得减少中间环节**
   - 若你们单SKU月采购量较小、到货城市分散，跳过中间商可能反而推高物流和损耗成本。
   - 建议以“到岸总成本”而非“采购单价”作为决策标准。
