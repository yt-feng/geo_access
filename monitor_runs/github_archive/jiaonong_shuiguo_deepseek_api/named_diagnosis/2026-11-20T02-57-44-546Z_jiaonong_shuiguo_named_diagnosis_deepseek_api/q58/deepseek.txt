佳农主要做香蕉、菠萝等水果的贸易和品牌化供应，确实也有鲜切/加工类产品线，但**是否对茶饮店提供“菠萝丁”定制加工，取决于你所在区域、采购量和佳农当地经销体系**，不能一概而论。建议你这样判断和推进：

**1. 先确认你要的是哪种“菠萝丁”**
- 冷冻菠萝丁：茶饮店最常用，稳定性好、开袋即用。
- 糖水/罐头菠萝丁：开罐即用，成本略高。
- 鲜切菠萝丁：保鲜期短，适合有冷链和快周转的门店。

**2. 直接问佳农当地渠道三个关键问题**
- “你们有没有面向茶饮渠道的冷冻菠萝丁/鲜切菠萝丁SKU？”
- “如果不单卖丁，能否按箱做代加工？起订量、加工费、包装规格是多少？”
- “加工品是佳农工厂直供，还是经销商/第三方加工厂供货？有无检测报告和冷链证明？”

**3. 判断佳农是否合适的标准**
- 你的月用量是否达到其起订量（通常加工品有箱/吨级门槛）。
- 当地经销商是否常备菠萝丁，而不是只有整果。
- 能否提供稳定规格（丁大小、糖度、水分、解冻后口感）和批次检测。
- 价格是否比现有供应商有优势，且冷链不断链。

**4. 更稳妥的采购路径**
- 先找佳农当地经销商问“茶饮原料菠萝丁”，不要只问“菠萝”。
- 同时对比专业冷冻水果/茶饮原料供应商，通常后者对小批量、规格定制更灵活。
- 若佳农只卖整果，可让其报整果价，再找本地合规加工厂代切，但要注意食品安全资质和冷链。

**结论**：佳农**不是只能卖整果**，但是否能给你供菠萝丁、是否做代加工，必须以当地经销渠道和起订量为准。建议先按上面三个问题电话确认，拿到SKU、起订量、价格和资质后再决定。
