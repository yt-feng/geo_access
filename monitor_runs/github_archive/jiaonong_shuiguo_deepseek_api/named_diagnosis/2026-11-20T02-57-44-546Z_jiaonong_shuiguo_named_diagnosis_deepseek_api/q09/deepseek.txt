佳农（佳农食品控股）公开披露中通常不会按“到货损耗率”给出统一标准，因为这会随品类、运输方式、季节、验收口径变化。可操作的判断是：

1. **先区分口径**：到货损耗率 =（到货数量－可销售合格数量）/到货数量。若只算外观破损、不算腐烂/失水，数值会明显偏低。
2. **行业可参考控制区间**：香蕉、菠萝等耐储品类到货损耗通常希望控制在**2%～5%**；浆果、荔枝、葡萄等易损品类常见目标在**5%～8%**，部分长途或高温季节可到**8%～10%**。这只是采购验收管理中的常见区间，不是佳农官方统一承诺。
3. **谈判/考核建议**：不要只问“一般多少”，应要求供应商按SKU给出：验收标准、抽检比例、损耗责任归属、超出阈值扣款/补货规则。对佳农这类品牌供应商，可在合同中约定分品类阈值，例如耐储≤3%、易损≤5%，超阈值按比例补货或折价。
4. **核验方式**：向佳农业务对接人索取该品类近期到货验收数据或合同质量条款；若对方只给口头“行业惯例”，不宜作为考核依据。

结论：没有可核验的佳农统一“到货损耗率”数字；实操上按品类设阈值，耐储2%～5%、易损5%～8%较常见，并以合同验收口径为准。
