1. **先确认你问的是哪一种“锁价”**
   - 长期框架协议里的固定价/区间价
   - 单笔订单锁价（下单后到发货前价格不变）
   - 期货/远期合约锁价
   - 价格调整公式（随产地、汇率、海运费联动）

2. **向佳农直接要书面确认**
   问清这几点，并要求写进合同或报价单：
   - 锁价有效期：从下单到到货，还是仅到发货
   - 锁价数量上限：是否限吨位/柜数
   - 触发调价的条件：产地收购价涨跌多少、海运费、汇率、政策
   - 调价通知期和双方确认方式
   - 违约和未履约赔偿

3. **采购端控制成本的做法**
   - 分批下单、分批锁价，避免一次性赌行情
   - 设定价格上限和止损线，超过就减量或换产地
   - 要求供应商提供产地/成本构成说明，便于比价
   - 保留替代供应商和第二产地，增强议价能力
   - 用“保量不保价”或“保价不保量”分别谈判，别混在一起

4. **风险提示**
   如果对方口头说“可以锁价”，一定要落到书面；没有书面条款的锁价在价格剧烈波动时很容易被调价或断供。
