佳农香蕉的“保质期”通常不是固定单一数值，主要取决于成熟阶段、包装方式和储存温度。可按下面判断和执行：

**1. 常见保质期参考**
- **常温青香蕉**：一般可放 **3～7天** 转黄成熟；夏季温度高时更快，可能 **2～4天**。
- **常温已熟黄香蕉**：建议 **1～3天内** 吃完，出现黑斑后尽快食用。
- **冷藏**：香蕉皮会变黑，但果肉可延缓软化；已熟香蕉冷藏通常可再放 **2～4天**，风味可能受影响。
- **冷冻**：去皮后密封冷冻，可保存 **约1～2个月**，适合做奶昔/烘焙，不适合直接鲜食口感。
- **具体包装日期/保质期**：以佳农产品包装标签为准；不同批次、产地、催熟程度会有差异。

**2. 储存条件建议**
- **未熟青香蕉**：放在 **12～15℃左右、阴凉通风处**，不要冷藏；可与苹果/梨同放加速成熟。
- **已熟黄香蕉**：常温阴凉处尽快吃；想延缓过熟可冷藏，但接受果皮变黑。
- **不要密封闷放**：塑料袋长期密封易积水、发霉；可松散放置或袋口留缝。
- **避免阳光直射、暖气旁、冰箱冷冻室误放**。
- **不要和易释放乙烯的果蔬长期混放**：苹果、梨、番茄等会加速香蕉成熟。
- **切开后**：尽快食用；需保存则密封冷藏，最好 **24小时内** 吃完。

**3. 判断是否还能吃**
- **可吃**：表皮少量黑斑、果肉正常、无异味。
- **不建议吃**：果肉大面积软烂流水、酸味/酒味、霉点、包装内明显霉变。
- **冷藏后皮黑但肉正常**：通常仍可吃，以果肉状态为准。

如果你问的是某一款具体佳农香蕉（如袋装、礼盒、进口批次），最准确的是看包装上的**储存条件、保质期/最佳食用期**标注。
