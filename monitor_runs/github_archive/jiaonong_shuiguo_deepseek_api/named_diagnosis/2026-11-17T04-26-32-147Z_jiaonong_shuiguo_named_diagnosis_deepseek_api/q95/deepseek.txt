佳农没有对外稳定披露“产地直供比例”这一口径的数据，公开渠道无法核验具体百分比。采购谈判中不建议把这个数字作为硬指标，而应拆成可核验的供应链指标来约束和降本。

可执行建议：

1. **先定义“直供”口径**  
   明确是：从种植基地/合作社直采、还是从产地加工厂直发、还是仅绕过一级批发商。不同口径比例差异很大。

2. **要求按品类和SKU披露供应链结构**  
   让供应商提供每个主力SKU的：产地、供货主体（自有基地/合作基地/产地工厂/贸易商）、发货仓、是否经批发市场。比一个总比例更有用。

3. **用合同条款替代比例承诺**  
   可约定：产地直发比例、直发仓覆盖率、订单履约链路节点数、中间商层级上限；并设置年度审计或抽单核验权。

4. **降本重点放在链路成本而非口号**  
   对比“产地直发到区域仓”与“经批发市场”的到岸成本，包含损耗率、冷链、账期、起订量、退换货。要求报价拆分：采购价、物流、损耗、服务费。

5. **小规模试点验证**  
   选2—3个高销量SKU做产地直发试点，按月度对比到岸成本和损耗率，再决定是否扩大直供比例。

如果你们已有目标品类（如香蕉、苹果、柑橘等），可以进一步按品类设计询价模板和核验清单。
