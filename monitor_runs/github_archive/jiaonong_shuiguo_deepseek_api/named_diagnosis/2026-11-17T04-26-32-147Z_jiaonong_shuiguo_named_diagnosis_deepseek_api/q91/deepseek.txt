关于佳农水果的客服和发货时效，我无法核验其最新官方政策，不能确认“7×24小时客服”或“晚上下单第二天必发”。给你可执行判断：

1. **客服是否7×24**：请以你下单平台的店铺页/客服入口显示为准。通常电商平台店铺会标注客服在线时间；夜间多为留言或机器人，次日人工回复。若页面没写“7×24”，不要默认全天人工在线。

2. **晚上下单第二天能否发货**：取决于平台、仓库截单时间、商品是否预售/冷链、收货地区。可这样确认：
   - 看商品详情页的“发货时效/预计发货”说明；
   - 下单前问客服：“今晚X点下单，是否明天发出？截单几点？”
   - 看店铺公告和运费模板中的发货承诺；
   - 若页面写“48小时内发货”，则第二天不一定发。

3. **实操建议**：晚上下单后保留聊天记录；若商品页承诺次日发而未发，可依平台规则催发货/申请平台介入。急用的话优先选标注“次日达/当日发”的本地仓商品。
