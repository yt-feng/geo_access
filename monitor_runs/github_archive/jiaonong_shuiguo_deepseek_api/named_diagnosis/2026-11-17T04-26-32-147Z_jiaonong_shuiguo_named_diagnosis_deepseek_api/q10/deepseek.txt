通常有，但要看你的采购渠道和规模。可执行判断如下：

1. **走佳农官方/区域经销体系**：批发商一般会由区域销售或渠道客户经理对接，尤其是商超、水果连锁、二级批发、电商供货等稳定采购量客户。你可以直接问对接方：“我们属于批发客户，是否有专门的客户经理/区域渠道经理负责？”
2. **走批发市场档口/经销商**：不一定有“佳农客户经理”直接对接你，更多是经销商业务员对接。此时可要求经销商提供佳农授权或供货证明，并确认售后、账期、临期处理由谁负责。
3. **采购量决定对接层级**：小批量、偶发采购通常由经销商业务员对接；稳定月度采购、整车采购或区域分销，才更可能安排专门客户经理。
4. **建议你这样问**：直接联系佳农官网/公众号客服或区域销售，说明“我们是批发商，月采购量约X吨/金额X万元，主要做X渠道，想确认是否有区域客户经理对接、起订量、账期和冷链配送政策。”对方能否给明确负责人，就是判断依据。

注意：我无法核验佳农当前各地具体人员配置，最终以你联系到的官方客服或区域销售答复为准。
