佳农（Goodfarmer）是否有针对茶饮B端的菠萝锁价长约，我这边无法核验其当前报价和合同政策，不能替他们承诺。但可以给你一套可执行的判断和谈判路径：

**先确认能不能做锁价**
- 直接问佳农销售/大客户经理三个问题：①菠萝是否有季度/年度锁价合同；②锁价对应的是鲜果还是冷冻/果浆原料；③锁价挂钩的是哪个品种和规格（如金钻凤梨、普通菠萝，鲜切块/果泥/浓缩汁），因为不同形态价格波动逻辑不同。
- 茶饮店月用10吨（年约120吨）属于中小B端量，锁价资格通常看年度框架量、付款方式和提货节奏。你有120吨/年的稳定量，是可以谈年度框架+季度调价的。

**锁价合同要盯的条款**
1. 锁价标的写清楚：品种、等级、规格、包装、产地、是否含税含运费。
2. 调价机制：别接受“单方随时调价”，要约定挂钩指数（如产地收购价、批发市场价）和调价频率（季度或半年），设涨跌幅上限。
3. 量价绑定：承诺年度最低采购量，换取价格上限；未达量如何补差要写清。
4. 质量与验收：糖度、酸度、瑕疵率、农残标准，不合格的退换和扣款规则。
5. 违约与不可抗力：天气、减产、物流中断时双方怎么处理，避免对方以“不可抗力”随意毁约。
6. 付款与账期：锁价通常要求预付或缩短账期，评估你的现金流。

**降低风险的替代方案**
- 不要100%锁死：70%锁价+30%随行就市，或“保底量锁价+增量浮动价”。
- 锁价期限先做3–6个月试运行，跑顺再签年度。
- 同步找1–2家备选供应商（如都乐、地方菠萝加工厂），避免单一来源被卡。
- 如果鲜果波动太大，考虑冷冻菠萝块/果浆锁价，工业品价格稳定性通常更好，但要做风味测试和门店SOP调整。

**怎么推进**
先让佳农出书面报价和合同模板，重点看调价条款和量价绑定；同时用你的120吨/年量向2–3家供应商询锁价方案做横向对比。如果佳农明确不做锁价，就转向“季度框架价+价格上限”或冷冻原料替代，而不是硬等锁价。
