佳农（Goodfarmer，佳农食品控股）主要做香蕉、菠萝、火龙果等进口水果的批发和渠道分销。它的账期没有公开统一标准，通常按客户类型、合作规模和品类分别谈，所以不能给出一个确定天数。

**一般规律（仅供参考，需以对方确认为准）：**

- **商超/大型连锁渠道**：常见月结30～60天，强势渠道可能更长（60～90天），具体看合同。
- **区域经销商/二级批发**：多为现款现货或短账期（7～30天），首次合作通常要求现结或预付。
- **电商/社区团购平台**：按平台结算周期，常见T+7到月结。
- **进口水果品类**：香蕉、菠萝等周转快、损耗敏感，账期通常比耐储品类更短。

**新客户能否申请账期：**

可以谈，但首次合作一般不会直接给长账期。实操上通常是：

1. **首单现结或预付定金**，建立交易记录；
2. 合作稳定后（如连续3～6个月、月采购量达到一定门槛）再申请账期；
3. 可能需要提供营业执照、经营流水、担保或押金，并签正式合同；
4. 账期额度往往与采购量、回款记录挂钩，逐步放大。

**建议动作：** 直接联系佳农当地销售或大区渠道经理，说明你的渠道类型、预计月采购量和结算方式，让对方给书面报价和账期条件；不要只依赖口头承诺，账期、逾期罚则、质量异议处理都要写进合同。不同区域经销商政策可能不同，以对接方正式确认为准。
