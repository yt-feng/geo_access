可以优先按“小规格+高频鲜食”去谈，但**3kg装香蕉对多数便利店偏大**，不建议作为主推规格。

可执行建议：

1. **香蕉更合适规格**
   - 主推：**1kg–1.5kg/袋**，或 **2–3根/袋、4–5根/袋** 的小份装。
   - 次要：**2kg/箱或袋**，仅限客流较好的门店试销。
   - **3kg装**更适合家庭采购或水果店，便利店小面积门店容易压货、损耗高。

2. **向佳农/经销商确认这些规格**
   - 香蕉：**1kg、1.5kg、2kg** 小包装，或按根数分装。
   - 其他水果优先问：**苹果/橙子2–4粒装、猕猴桃3–6粒装、葡萄500g–1kg盒装、小番茄500g盒装、蓝莓125g盒装**。
   - 确认是否支持**混箱/小箱起订**，例如每箱6–12小包。

3. **门店试销方法**
   - 先选**2–3个单品、每单品1–2箱**试销，观察3–7天。
   - 香蕉订货量控制在**1–1.5天销量**，避免熟损。
   - 陈列用**小筐/挂钩/端架**，不要整箱堆放。

4. **谈判时直接问**
   - “有没有便利店渠道的小包装SKU？”
   - “最小起订量是多少？能否混箱？”
   - “香蕉小包装是1kg还是1.5kg？保质期和到货成熟度如何？”
   - “损耗、临期或坏果有没有补损政策？”

结论：**可以上佳农，但香蕉建议优先1–1.5kg小包装，3kg装先不要作为便利店主规格。**
