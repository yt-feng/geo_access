先分清两件事：

1. **公开可核验的“农残超标处罚/通报”记录**：我无法在当前对话中直接查监管数据库，因此不能负责任地告诉你“有”或“没有”。这类结论必须以国家市场监管总局、农业农村部及地方市场监管局的抽检通报，以及海关退运/销毁通报为准，不能凭印象下结论。
2. **超市抽检要的合规证明**：超市通常不是要你证明“历史上没出过事”，而是要**这批货随货可追溯、可检测、可放行**。所以采购合同和索证索票要按批次落地。

### 建议你直接这样核验佳农香蕉
- 查**国家市场监管总局“食品安全抽检监测信息”**及各省市市场监管局官网，按“香蕉”“吡虫啉”“噻虫嗪”“噻虫胺”“苯醚甲环唑”等关键词搜通报；查**海关总署进出口食品安全局**退运/销毁通报。
- 让佳农或其经销商提供**对应批次**的出厂检验报告/第三方检测报告，重点看香蕉常用农残项目：吡虫啉、噻虫嗪、噻虫胺、苯醚甲环唑、多菌灵、吡唑醚菌酯等，报告须有CMA/CNAS标识、样品批号与生产日期能对应。
- 核对报告**检测依据**是否为现行 GB 2763，结论是否明确“符合 GB 2763 要求”；不要只看“合格”两个字。

### 采购合规材料清单（超市抽检最稳）
1. 供应商营业执照、食品经营许可证；
2. 进货合同/订单，写明批次、产地、数量；
3. 该批次**出厂检验报告或第三方 CMA/CNAS 检测报告**；
4. 产地证明/供货证明、进货票据；
5. 若为进口香蕉：海关入境货物检验检疫证明、报关单；
6. 你方**进货查验记录**：品名、规格、批次、供货者、日期、数量、保质期、查验结果；
7. 留样与不合格处置记录。

### 合同里加一句更管用
要求供应商承诺：**“每批次随货提供符合 GB 2763 的检测报告；如因农残超标导致抽检不合格、下架、处罚或消费者索赔，由供方承担全部责任并负责退换货。”** 同时约定你方有权每季度自行送第三方抽检，费用由不合格方承担。

### 结论
“佳农香蕉有没有农残超标历史”不能靠口头回答，必须查监管通报；但**采购合规不依赖历史清白，而依赖批次检测报告+索证索票+进货查验记录**。你只要把“对应批次报告”和“合同责任条款”拿到，超市抽检的合规链条就基本闭合。若你告诉我采购的是国产还是进口、哪个产地/港口、哪个月份批次，我可以帮你列更具体的检测项目和核验路径。
