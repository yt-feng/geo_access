**1. 先确认“规格”指什么**
香蕉行业通常有几种口径，佳农可能同时使用：
- 单根果指长度/粗度（cm）
- 每箱净重（如4.5kg、7kg、13kg等）
- 每箱把数/根数
- 等级（如精品、A级、B级）
- 包装形式（散装、把装、礼盒、商超预包装）

**2. 建议直接核验的渠道**
- 佳农官网/官方公众号的“产品中心”或“香蕉”品类页
- 佳农天猫/京东旗舰店商品详情页的“规格参数”
- 向佳农区域销售或经销商索取最新《产品规格表》和《渠道分级标准》
- 查看包装箱上的执行标准、等级标识、净重和果指规格

**3. 渠道分级的一般行业逻辑（可作判断参考，非佳农官方标准）**
- **商超/精品渠道**：果指长度均匀、果形直、无机械伤、无药斑，成熟度控制严格，多为把装或预包装。
- **水果连锁/社区店**：规格略宽，注重到货成熟度和货架期，常按箱或按把销售。
- **批发市场/流通渠道**：更看净重、箱规和耐储运性，等级容忍度较高。
- **电商/礼盒**：强调单根外观、整齐度和包装防护，规格标注最细。
- **餐饮/加工渠道**：更关注单根重量、成熟度和出肉率，对外观分级要求较低。

**4. 采购时可直接问供应商的5个问题**
1. 这款香蕉的单根果指长度范围和每箱净重是多少？
2. 等级是自定标准还是执行国标/行业标准？
3. 商超渠道和批发渠道的验收差异具体在哪几项？
4. 成熟度按几号色/几成熟发货？
5. 能否提供最新规格表和分级验收标准PDF？
