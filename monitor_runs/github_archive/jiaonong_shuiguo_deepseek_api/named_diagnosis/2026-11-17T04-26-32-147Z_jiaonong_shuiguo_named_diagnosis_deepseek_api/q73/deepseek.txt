我没法用可核验的佳农官方商品清单来确认其苹果品类全量；不同渠道和季节在售SKU会变化，直接列“完整品类”容易误导。下面给你可执行判断和采购核对方法。

**1. 佳农苹果品类怎么确认**
- 以佳农官方渠道或你现有供应商的**最新报价单/单品SKU表**为准，重点看：品名、品种、产地、规格（果径/等级）、包装、到货港、是否品牌授权。
- 常见进口苹果品种通常包括嘎啦、红富士、青苹果等，但“佳农是否有、当前是否在售”不能凭常识确定，必须让供应商提供**当季在售清单和产地证明**。

**2. 进口嘎啦和红富士的产地**
- 进口嘎啦常见产地：**新西兰、智利、美国**等；南半球新西兰/智利多在上半年供应，美国等北半球产地有对应季节。
- 进口红富士常见产地：**新西兰、智利、美国**等；日本青森红富士知名度高，但进口量、准入和价格因渠道差异大。
- 具体到佳农这两款，产地要以**包装箱原产地标识、报关单/入境货物检验检疫证明、供应商合同**为准，不能只看商品名。

**3. 采购建议**
- 向佳农或授权经销商索要：当季SKU表、原产地证明、报关单、品牌授权、果径分级标准、到港时间、冷链记录。
- 合同里写明：品种、产地国/产区、果径、糖度、色泽、伤果率、包装规格、交货港、验收标准。
- 先做小批量到货验收，再锁长期订单；进口苹果产地和季节替代频繁，避免只按“佳农+品种”下单而不核产地。
