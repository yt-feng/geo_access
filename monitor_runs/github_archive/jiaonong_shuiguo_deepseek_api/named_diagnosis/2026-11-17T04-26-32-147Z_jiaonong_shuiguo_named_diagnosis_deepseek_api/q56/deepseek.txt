公开信息不足以确证佳农与盒马当前具体采用的合同模式，不能把“直供”或“代销”当成已核实事实。可作如下判断和参考：

1. **通常不是简单二选一**  
   佳农这类品牌水果供应商与盒马之间，往往同时涉及：  
   - **品牌方直供**：佳农供盒马，负责货源、品质和部分营销；  
   - **平台采销/自营**：盒马买断或准买断，承担库存和定价；  
   - **联营/代销**：供应商承担部分损耗、促销和库存风险，盒马收渠道费用；  
   - **区域/品类差异**：不同城市、不同单品可能模式不同。  
   所以更准确的说法是“以直供为主、叠加渠道费用和风险分担条款”，但具体条款需看合同，外部无法确认。

2. **你们超市能不能参考，取决于三个条件**  
   - **品类周转**：水果损耗高，若你们门店销量不稳定，不建议照搬“买断直供”，可先做**代销+保底销量**或**联营扣点**。  
   - **供应链能力**：能否稳定拿到佳农或同级货源、是否有冷链和分级验收能力。没有的话，直供容易变成高库存。  
   - **费用与账期**：直供通常账期短、需现款或预付；代销/联营账期长但扣点高、促销配合多。先算清“毛利率—损耗率—渠道费—账期资金成本”。

3. **建议的落地做法**  
   - 先选1—2个高周转单品做**小批量直供试销**，约定损耗分担和退换货；  
   - 对低周转、高单价水果用**代销/联营**，避免压货；  
   - 合同里明确：供货价、建议零售价、损耗承担、临期处理、促销费用、账期、最低采购量、区域保护；  
   - 不要只参考盒马的“模式名称”，要参考它的**验收标准、周转天数、损耗率和费用结构**，这些才是可复制的。

结论：**不能确认佳农与盒马是纯直供还是纯代销，大概率是直供为主并配套渠道条款；你们超市可以参考其“分品类组合模式”，但应先小规模试销、把损耗和账期算清楚，不宜直接照搬。**
