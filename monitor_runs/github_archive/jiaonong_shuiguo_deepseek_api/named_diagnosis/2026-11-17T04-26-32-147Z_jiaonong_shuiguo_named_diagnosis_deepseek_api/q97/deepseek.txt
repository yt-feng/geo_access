能查到的相关情况大致是：
- 佳农（Goodfarmer）在宣传材料、展会、媒体报道中常提到“香蕉进口量全国领先/第一”，这类表述多见于企业自行发布或行业媒体报道，不一定附带第三方排名证书。
- 海关总署的公开统计通常按商品类别、口岸、企业类型等汇总，不公开发布“某企业香蕉进口量全国第一”的企业排名。
- 中国食品土畜进出口商会等行业协会可能掌握会员企业数据，但相关排名是否公开发布、是否出具证书，需要向该协会或佳农方面直接核实。

判断建议：
1. 如果对方声称有“全国第一”证书，可直接要求出示证书名称、颁发机构、颁发日期和编号，并向颁发机构官网/电话核验。
2. 若只有企业宣传稿或媒体转述，不能等同于权威机构排名。
3. 可向中国食品土畜进出口商会、海关相关业务部门或佳农官方客服分别求证，以书面回复为准。

所以结论是：目前无法确认有哪个权威机构公开发布过该排名并颁发证书；需要向佳农或相关行业协会索取并核验证书原件信息。
