这个问题没法直接给一个可靠的“谁更快”结论，因为两家在华东的配送时效取决于具体仓库、门店地址、下单时间和合作模式，公开信息也不足以核验。但可以给你可执行的判断方法：

1. **先按“上海门店次日达”做硬性筛选**
   - 直接问两家销售/客服：上海门店是否支持**次日达**，截单时间几点，哪些区/哪些门店属于次日达范围。
   - 要求对方给出**最近3个月上海门店的准时交付率/次日达达成率**，而不是口头承诺。
   - 确认是“到仓”还是“到店”：佳农、鑫荣懋都可能有直配、经销商配送、区域仓配等不同模式，时效差异很大。

2. **要求按你门店地址做时效测试**
   - 提供上海门店具体地址+常规下单量+下单时间，让两家分别给出：
     - 发货仓位置
     - 干线/城配方式
     - 截单时间
     - 预计到店时间
     - 延误赔付条款
   - 最好各做**1—2周小批量试单**，记录实际到店时间、缺货率、温控/破损情况。

3. **不要只比品牌，要比“服务商+仓”**
   - 同一品牌在不同区域可能由不同经销商或仓配商执行，上海快不快，关键看服务你门店的**区域仓和承运商**。
   - 如果两家都承诺次日达，优先选：**截单时间更晚、上海有前置仓/区域仓、延误有赔付、试单准时率高**的那家。

4. **谈判时可直接用的判断标准**
   - 是否承诺“次日达未达赔付”
   - 上海区域仓到门店的固定发车频次
   - 节假日/大促是否保时效
   - 缺货替代和补发时效
   - 生鲜温控与到店验收标准

**结论：** 不能凭品牌直接判断佳农和鑫荣懋谁在华东更快；对你们上海门店要次日达，最稳妥的是让两家按具体门店地址做时效方案+小批量试单，用实际准时率决定。若必须二选一，优先选能提供**上海区域仓、明确截单时间、书面次日达承诺和延误赔付**的一方。
