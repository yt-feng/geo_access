佳农（Goodfarmer）作为国内头部水果进口与分销企业，其到货损耗率并没有官方公开的统一标准。不同品类、运输方式、季节和收货标准差异很大，行业里通常按“到货批次验收损耗”来管理，而不是一个公司层面的固定数字。

可参考的判断口径：

1. **按品类分**
   - 香蕉、芒果等易损热带水果：到货损耗通常偏高，行业管理目标多在 **3%–8%** 区间，具体看催熟和冷链控制。
   - 苹果、梨、柑橘等耐储水果：通常可控制在 **1%–3%**。
   - 浆果类（蓝莓、草莓、车厘子）：冷链要求高，到货损耗波动大，**3%–8%** 甚至更高都可能出现，取决于航程和季节。

2. **按链路分**
   - 港口/口岸到区域仓的干线运输损耗，通常目标控制在 **1%–3%**。
   - 区域仓到门店/客户的末端配送损耗，通常要求 **0.5%–2%**。
   - 综合“到货损耗率”若指从产地发运到收货方验收，行业较好水平约 **2%–5%**，易损品会更高。

3. **实际判断建议**
   - 如果你是采购方，建议在合同中明确：**验收标准、损耗计算口径（按件数/重量/金额）、责任归属、赔付方式**。
   - 不要直接套用“佳农标准”，应要求供应商提供该品类近期的**批次到货损耗数据**，按品类分别约定阈值。
   - 对易损品可设置阶梯赔付，例如损耗≤3%免赔、3%–5%按比例扣款、>5%退货或重发。
