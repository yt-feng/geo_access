佳农有面向礼品/团购场景的水果礼盒，但“有没有、有哪些、能否团购价”会随渠道和档期变化，建议按下面方式快速确认，避免买到非团购版或过期信息。

**1）先确认购买渠道**
- **官方渠道最稳**：佳农官方微信小程序/公众号商城、天猫/京东“佳农官方旗舰店”、抖音佳农官方直播间。团购通常在这些渠道的“企业采购/团购专区”或客服处能问到。
- **线下商超/水果连锁**：盒马、山姆、永辉、百果园等可能有佳农礼盒，但多为零售装，不一定支持团购价。
- **经销商/批发市场**：适合大批量，但要注意授权和售后。

**2）直接问团购的三个关键问题**
联系官方客服或团购负责人时，直接问：
- “目前有哪些**礼盒装**适合企业团购？给一份SKU和规格清单。”
- “**起订量**是多少？能否**定制贺卡/logo/外箱**？”
- “是否支持**开票、对公转账、分地址发货、破损包赔**？”

**3）常见适合团购的佳农礼盒类型**
佳农常见礼盒多围绕**香蕉、进口提子/葡萄、车厘子、蓝莓、奇异果、火龙果、椰青**等组合；具体以当期官方在售为准。企业团购通常更适合选**耐储运、规格统一、有独立包装**的品类。

**4）避坑建议**
- 别只看“礼盒”字样，确认是**原厂礼盒**还是商家自行打包。
- 团购大单先要**样品**，确认果径/甜度/成熟度和破损率。
- 合同写明**发货时效、冷链方式、破损赔付比例、发票类型**。
