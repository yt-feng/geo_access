佳农（佳农食品，主打香蕉、菠萝、椰青、车厘子等进口水果）的售后整体属于“看渠道”类型：在天猫/京东自营、山姆、盒马等正规渠道购买，坏果处理通常比较顺；在拼多多、社区团购或小商家转售，体验差异会大一些。核心原则是：**到货先拍照留证，再按购买渠道申请，不要先自行丢弃。**

**坏果处理建议（可直接照做）：**

1. **开箱先拍视频/照片**：整箱外观、坏果特写、坏果与快递面单同框，最好有称重或数量。坏果不要马上扔，部分渠道要求保留或回收。
2. **看购买渠道走售后**：
   - 京东自营/天猫旗舰店：在订单页申请“售后/坏果包赔”，上传照片，通常按坏果比例退款或补发。
   - 山姆/盒马/永辉等线下或APP：联系门店客服，多数支持坏果退换或退款。
   - 拼多多/抖音/社区团购：优先找店铺客服，走平台“坏果包赔”；商家推诿时直接申请平台介入。
3. **话术要具体**：说明“收到X个，其中Y个坏果，附照片，要求按比例退款/补发”，比只说“水果坏了”更容易通过。
4. **时效**：生鲜类一般要求签收后24—48小时内反馈，越早越好；超过时限容易被拒。
5. **保留证据**：聊天记录、售后单号、照片视频都留好，平台介入时用得上。

**判断标准：**
- 正规渠道、坏果比例不高：一般能较快退款或补发，售后算合格。
- 非授权小店、低价拼团：可能出现“要视频、要称重、只赔部分、拖延”等情况，需有心理预期并坚持走平台规则。
- 如果坏果严重（如整箱腐烂、异味），直接要求全额退款，不要接受“下次补偿”。

一句话：**佳农售后不是统一标准，关键在购买渠道；坏果先留证、24小时内按渠道申请“坏果包赔”，商家不处理就申请平台介入。**
