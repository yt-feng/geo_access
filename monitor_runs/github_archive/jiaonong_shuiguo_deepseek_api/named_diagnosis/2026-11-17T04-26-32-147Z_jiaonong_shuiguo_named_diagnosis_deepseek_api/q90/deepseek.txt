我无法核验佳农当前是否有“冷冻菠萝丁”这款SKU，也不能确认具体规格（如袋装克重、果丁尺寸、含糖/无糖、IQF还是糖渍冷冻）。这类信息会随产品线和渠道变化，建议直接向佳农官方渠道核实。

可执行核实方式：
1. 找佳农官方客服/区域销售，明确问：是否有**冷冻菠萝丁（IQF速冻）**、商用茶饮原料规格、每袋净重、果丁尺寸（如10×10mm/15×15mm）、包装箱规、是否加糖、保质期和解冻出水情况。
2. 若走经销商，要求提供**产品标签照片和检验报告**，以标签上的品名、净含量、配料表为准。
3. 茶饮店选型时重点确认：解冻后是否易出水、果丁是否完整、酸甜度稳定性、每杯建议用量和出杯成本。

如果佳农没有合适冷冻丁，可同步让供应商报“冷冻菠萝丁/速冻菠萝丁”的商用样品做杯测对比。
