佳农水果的配送时效取决于你下单的渠道、收货城市和配送方式，没法一概而论。可以这样判断：

1. **电商平台自营/旗舰店（如京东、天猫等）**
   - 一般由平台仓或佳农合作仓发货；
   - 一线/新一线城市通常 **次日达或隔日达**；
   - 偏远地区可能 **2–4天**，生鲜类有时不支持配送。

2. **社区团购/本地生活平台**
   - 通常 **次日自提**或 **当日/次日送达**，具体看团长或门店安排。

3. **商超/水果店线下配送**
   - 如果是门店周边配送，常见 **1–3小时达** 或当日达，范围有限。

4. **佳农官方小程序/直播间**
   - 以页面标注的发货时效为准，常见 **48小时内发货**，物流时效另算。

**下单前最准确的做法：**
- 在商品详情页看“发货时效/配送说明”；
- 下单页输入收货地址后看预计送达时间；
- 直接问店铺客服“发什么快递、几天到、是否冷链”。

生鲜水果受天气、节假日和冷链覆盖影响较大，建议以你下单页面的实时显示为准。
