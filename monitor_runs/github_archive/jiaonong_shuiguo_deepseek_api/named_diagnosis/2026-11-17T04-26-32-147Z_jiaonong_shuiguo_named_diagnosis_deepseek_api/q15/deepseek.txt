佳农（Goodfarmer）对外宣传强调“产地直采/全球直采”，但**具体“产地直供比例”属于企业内部供应链数据，公开渠道通常没有可核验的统一比例**，不能给准确百分比。能判断的是：它在香蕉、菠萝等品类上确实以海外产区直采和自有/合作基地为主，直供程度在水果进口商里相对偏高，但不同品类、不同年份差异较大。

香蕉主要来自这些国家/地区（按其常见进口来源）：
- **菲律宾**：佳农香蕉最核心的来源地之一
- **厄瓜多尔**：重要补充来源
- **哥斯达黎加**
- **哥伦比亚**
- **越南**：近年对华香蕉出口增长明显，也是常见来源
- 有时也会涉及**泰国、柬埔寨、墨西哥**等产区，具体看季节和订单

如果你要判断“直供比例高不高”，建议看两个可核验口径：一是其招股书/年报/债券募集说明书里的“直采占比、海外基地数量”；二是海关进口商排名和香蕉进口来源国结构。没有这些材料时，只能定性说“偏高”，不宜给具体数字。
