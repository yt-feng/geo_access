我无法核验佳农官方最新的规格表，所以不能给出“官方准确”的规格数量和渠道分级标准。下面给你一套**可执行、可判断**的方法和行业常见口径，避免你被不确定信息误导。

## 1. 先明确：佳农香蕉规格通常会按这几类维度分

不同渠道说的“规格”可能不是同一件事，通常包括：

1. **单根重量/单根级别**
   - 如：小果、中果、大果、特大果
   - 常见按单根克重或每箱根数控制

2. **每箱净重**
   - 如：4kg、5kg、7kg、10kg、12kg、13kg、15kg、18kg等
   - 不同工厂、不同季节、不同客户会变

3. **每箱根数**
   - 如：每箱20根、24根、28根、30根、32根、36根、40根等
   - 根数越少，通常单根越大

4. **梳/把规格**
   - 如：几梳装、每梳几根
   - 商超更看重“把型整齐”，批发更看重“总重和根数”

5. **成熟度/催熟阶段**
   - 如：青蕉、微黄、黄熟、即食熟度
   - 这不是大小规格，但渠道分级一定会看

6. **外观等级**
   - 如：A级、B级、统货、加工果
   - 主要看条形、长度、粗细、弯度、斑点、机械伤、疤痕、青黑点

所以，问“有几种规格”没有统一答案。**佳农香蕉不是固定只有几种，而是按客户订单和渠道做多规格组合。**

## 2. 适合不同渠道的分级标准，可按这个框架判断

### A. 商超/精品超市
重点：**外观一致、把型漂亮、熟度可控、货架期稳定**

建议标准：
- 单根大小均匀，同箱内差异小
- 条形直或微弯，无严重畸形
- 表皮干净，无明显疤痕、黑斑、机械伤
- 每把根数整齐，常见4–6根一把或按商超要求
- 熟度按门店周转定：通常偏青或微黄到货，门店催熟或直接上架
- 等级：以A级或商超专用级为主
- 规格：常见5kg、7kg、10kg、12kg、13kg等箱规，按门店订单定

判断要点：
- 如果同一箱里大小差距大、把型乱，不适合精品商超
- 如果到货太黄，货架期短，商超会拒收或压价

### B. 水果连锁/社区水果店
重点：**性价比、周转快、卖相过得去**

建议标准：
- 大小可以略有不齐，但不能太多
- 允许轻微表皮瑕疵，不能有腐烂、裂口、严重压伤
- 熟度可略高，方便直接销售
- 等级：A级偏下或B级、统货
- 规格：常见10kg、12kg、13kg、15kg、18kg等
- 根数/把型按门店陈列习惯定

判断要点：
- 这类渠道对“每箱净重是否足、烂果率是否低”比“单根是否完美”更敏感

### C. 批发市场/农贸批发
重点：**总重、价格、耐运输、出摊好卖**

建议标准：
- 允许外观一般，但腐烂率要低
- 条形不要求特别统一
- 熟度偏青，便于运输和二次分销
- 等级：统货、B级、加工级偏上
- 规格：大箱规更常见，如12kg、13kg、15kg、18kg
- 通常按“件”走，不特别强调每把精品度

判断要点：
- 批发最怕“上面好下面烂”和“净重不足”
- 如果要做长期批发，重点谈：净重、烂果率、青熟度、到货时间

### D. 电商/社区团购
重点：**图片好看、单根稳定、履约破损低**

建议标准：
- 单根重量相对统一，方便按根/按份售卖
- 表皮干净，无明显黑斑
- 熟度不能太高，否则快递易坏
- 等级：A级或电商专供级
- 规格：按份卖常见5–8根、1kg、2kg、3kg、5kg等
- 箱规可小箱化，减少压伤

判断要点：
- 电商不是只看箱规，更看“单份克重是否稳定”
- 如果同一份里大小差太多，差评会高

### E. 餐饮/茶饮/加工渠道
重点：**出肉率、成熟度、成本、稳定性**

建议标准：
- 外观要求低，允许斑点、轻微畸形
- 要求熟度合适，方便打泥、切片、做饮品
- 等级：加工级、B级、统货
- 规格：按净重和成熟度定价，常要大箱、便宜、稳定
- 关键指标：出肉率、坏果率、成熟度、到货批次稳定性

判断要点：
- 这类渠道可以不追求“漂亮”，但必须稳定
- 如果熟度忽高忽低，会影响出品

## 3. 你可以这样向佳农或供应商确认准确规格

直接问这8项，基本就能拿到可执行答案：

1. 你们当前在售的香蕉箱规有哪些？分别净重多少？
2. 每个箱规对应每箱根数是多少？
3. 单根重量范围是多少克？
4. 分几级？A级、B级、统货、加工级分别什么标准？
5. 每级允许的瑕疵比例是多少？
6. 到货熟度是几成熟？青蕉还是微黄？
7. 适合商超、批发、电商、餐饮分别推荐哪个规格？
8. 有没有最新报价单和规格书？能否提供样品或批次检测标准？

## 4. 最实用的结论

如果你要的是“佳农香蕉有几种规格”，准确答案应以佳农当期报价单/规格书为准，不能凭行业常识代替。

但按渠道选，你可以先按这个逻辑判断：

- **商超/精品店**：选外观好、把型整齐、A级、中小箱规、熟度可控
- **水果店/社区店**：选性价比高、A级偏下/B级、中箱规、熟度略高
- **批发市场**：选统货/B级、大箱规、偏青、耐运输
- **电商/团购**：选单根稳定、小份化、A级、耐履约
- **餐饮/加工**：选加工级/统货、大箱、熟度稳定、出肉率优先
