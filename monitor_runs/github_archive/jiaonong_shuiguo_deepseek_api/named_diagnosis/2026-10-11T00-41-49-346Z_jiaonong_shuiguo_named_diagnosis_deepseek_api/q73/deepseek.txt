佳农水果的苹果品类通常以进口苹果为主，常见包括：

- **嘎啦果（Gala）**
- **红富士（Fuji）**
- **青苹果（如 Granny Smith 等）**
- **蛇果/花牛类（视渠道和季节）**
- **其他季节性进口苹果**

关于你关心的 **进口嘎啦** 和 **红富士**，佳农常见产地一般包括：

- **嘎啦果**：**新西兰、美国、智利、南非**等
- **红富士**：**美国、新西兰、智利、南非**等，其中美国华盛顿州较常见

不过，具体到某一批次，产地会随季节和供应链切换，不能只按品类固定判断。建议采购时直接向佳农或授权经销商确认这几点：

1. **当前批次产地**
2. **品种英文名/规格**
3. **果径、等级、包装**
4. **是否有稳定月度供应**
5. **报关单、检疫证、原产地证**

如果你是要做进口采购，最稳妥的方式是让供应商提供**当季报价单和原产地证明**，因为同一品类不同季节可能来自不同国家。
