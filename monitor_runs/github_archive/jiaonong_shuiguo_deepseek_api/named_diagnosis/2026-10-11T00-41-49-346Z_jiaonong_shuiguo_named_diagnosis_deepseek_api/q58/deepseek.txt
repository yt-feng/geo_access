佳农（Goodfarmer）主要是水果供应链和品牌商，业务以**整果贸易、批发、商超配送**为主，同时也做部分**鲜切水果、冷冻水果、果浆/果泥类**产品，但是否能按你们茶饮店的需求提供**菠萝丁**（规格、糖度、杀菌/冷冻方式、包装、起订量、代加工），取决于具体区域分公司和工厂能力，不能一概而论。

给你一个可执行的判断路径：

1. **先明确你要的“菠萝丁”类型**
   - 冷冻菠萝丁（IQF）：茶饮店最常用，开袋即用，稳定性好。
   - 糖水菠萝丁/罐头菠萝丁：口感偏软，适合部分饮品。
   - 鲜切菠萝丁：保质期短，配送半径有限。
   - 果浆/果泥带果肉：如果只是调味，不一定要“丁”。

2. **联系佳农时直接问这 6 项**
   - 是否有**冷冻菠萝丁**或**鲜切菠萝丁**现货SKU？
   - 规格：丁径（如 8×8mm、10×10mm）、每袋克重、每箱袋数。
   - 工艺：IQF、糖渍、巴氏杀菌、是否加糖/加酸/保脆。
   - 起订量：按箱、按吨还是按托盘。
   - 是否支持**OEM/代加工**：贴牌、定制糖度、定制包装。
   - 配送：是否冷链到店，区域是否覆盖你们城市。

3. **如果佳农只卖整果或不匹配，替代方案**
   - 找**冷冻果蔬加工厂**做IQF菠萝丁，通常比品牌商更灵活。
   - 找**罐头/糖水菠萝丁**供应商，适合标准化出品。
   - 找**果浆/果泥厂**做带果肉菠萝浆。
   - 本地鲜切水果供应商，适合短保、高频配送。

4. **茶饮店选菠萝丁的重点**
   - 优先选**冷冻IQF菠萝丁**：出杯稳定、不易发酵、损耗低。
   - 确认**解冻后是否出水、是否发苦、是否软烂**。
   - 要样品做**3天冷藏/解冻测试**和**实际出杯测试**。
   - 确认是否有**SC资质、检测报告、批次稳定性**。

**结论**：佳农不一定只卖整果，但能不能给你做菠萝丁加工，需要直接问当地佳农分公司或客服确认。如果他们要的起订量太高或不做定制，建议同时找专业冷冻果蔬加工厂比价打样。
