可以这样判断和推进：

1. **佳农有餐饮/烘焙渠道产品线**
   佳农除了零售鲜果，也确实做餐饮、烘焙、茶饮等B端供应，菠萝/凤梨是其常见品类之一。但“是否提供切片、切块定制”通常属于客户定制，不一定公开列规格。

2. **餐饮渠道常见可能形式**
   菠萝类B端供应一般可能有：
   - 整果：按大小/糖度/品种分规格
   - 去皮整果：冷藏或冷冻
   - 菠萝丁/菠萝块：冷冻或冷藏，常用于茶饮、烘焙、餐饮
   - 菠萝片：圆片、半片、扇形片等
   - 菠萝果泥/果浆：用于饮品、酱料
   但这些是否由佳农提供、具体尺寸和包装，需要向佳农官方销售确认。

3. **建议直接问佳农销售这几个问题**
   - 餐饮渠道是否有菠萝切片、切块、菠萝丁？
   - 规格：每块/每片尺寸、厚度、克重范围？
   - 状态：冷藏鲜切还是冷冻？保质期和储存条件？
   - 包装：袋装、盒装、罐装、大包装？每箱重量？
   - 起订量：最小起订量、是否支持定制尺寸？
   - 产地/品种：菲律宾、泰国、国产凤梨等？
   - 是否供过茶饮/烘焙/团餐客户，能否提供样品？

4. **最快核验方式**
   - 找佳农官网/公众号里的“餐饮渠道”“B2B”“经销商合作”入口
   - 直接联系佳农官方客服，转餐饮事业部或当地经销商
   - 在大型餐饮供应链平台搜“佳农 菠萝 丁/块/片”，看是否有实际SKU
   - 如果是采购，直接要求对方发《餐饮渠道产品规格书》或报价单
