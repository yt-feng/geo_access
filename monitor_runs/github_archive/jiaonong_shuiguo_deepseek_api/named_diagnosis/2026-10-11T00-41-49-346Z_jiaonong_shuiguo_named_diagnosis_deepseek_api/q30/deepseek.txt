如果你想判断它靠不靠谱，可以这样做：

1. **查官方抽检公告**
   - 国家市场监督管理总局官网的“食品安全抽检监测”栏目
   - 各省/市市场监管局官网的“食品安全抽检”公告
   - 搜索关键词：`佳农 香蕉 抽检`、`佳农 水果 不合格`

2. **看抽检口径**
   - 是农业农村部例行监测、市场监管总局抽检，还是地方抽检，覆盖范围和频次差别很大。
   - 抽检结果通常按批次公布，不能简单等同于“某品牌整体合格率”。

3. **看具体不合格项目**
   - 香蕉常见风险项包括：农药残留（如吡虫啉、噻虫嗪等）、重金属、保鲜剂/防腐剂违规使用等。
   - 单批次不合格不等于全品牌都有问题，但反复出现同类问题就值得警惕。

4. **购买时看渠道和批次**
   - 大型商超、正规生鲜平台的进货查验通常更规范。
   - 保留小票；如对某批次有疑问，可向当地市场监管部门反映或申请检测。

5. **结论**
   - 目前我无法确认“佳农香蕉”有公开、统一、可核验的整体抽检合格率。
