关于佳农水果的堆头陈列和试吃支持，我无法直接确认他们当前的政策和费用分担方式，因为这属于厂商与商超之间的具体商务合作条款，会因地区、渠道、采购规模、合作阶段而不同。

建议你按以下方式推进：

**1. 先明确你方需求**
- 堆头位置、面积、陈列周期
- 试吃品类、场次、时间、预计用量
- 是否需要促销员、物料（价签、海报、围挡）
- 预计销量或订货量

**2. 直接联系佳农对接人**
优先找：
- 佳农当地经销商/代理商
- 佳农区域销售经理
- 你方采购对接的佳农业务

**3. 费用分担通常可谈的方向**
行业里常见做法包括：
- 厂商承担试吃果品和物料，商超承担场地和人力
- 厂商承担促销员费用，商超承担堆头位置
- 按订货量给予陈列补贴或返利
- 双方按比例分摊，或以保底销量换取支持
- 新品推广期厂商支持力度通常更大

**4. 谈判时可用的筹码**
- 门店客流量和位置优势
- 陈列面积和陈列时长
- 订货量承诺
- 是否配合线上宣传
- 是否长期合作

**5. 建议动作**
先向佳农对接人发一份简短需求，写清：门店、时间、堆头需求、试吃需求、预计订货量、希望你方承担的部分。让对方给出书面方案，再谈费用分担。
