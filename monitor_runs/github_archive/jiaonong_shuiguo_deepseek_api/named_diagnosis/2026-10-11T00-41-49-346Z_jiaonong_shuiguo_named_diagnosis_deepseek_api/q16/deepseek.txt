佳农（Goodfarmer）是国内较大的水果进口/经销商，主要走商超和生鲜电商渠道（如盒马、叮咚、京东、天猫等）。它的"售后"通常不是佳农直接对你，而是**由你下单的平台来处理**，所以体验好坏很大程度取决于平台，而不是佳农品牌本身。

## 关于售后口碑

整体反馈偏"因渠道而异"：

- **生鲜电商/即时零售**（盒马、叮咚、朴朴等）：这类平台普遍有"坏果包赔/不满意退款"政策，处理通常比较快。
- **传统电商**（京东、天猫店铺）：需要你拍照举证，走店铺客服或平台介入，时效取决于商家。
- **线下商超**：一般凭购物小票和小票+实物当场协商，能否退换看单个门店。

需要注意的是，佳农主要作为供货商，很多售后是第一道由平台兜底，所以"佳农售后好不好"这个问题，实际体验更多是"哪个平台买"决定的。

## 到货有坏果怎么处理（可执行步骤）

1. **先拍证据**：坏果单独拍 + 整箱/整袋一起拍，最好拍到外包装和数量。生鲜理赔基本都要求照片或视频，越清楚越容易通过。
2. **保留原包装和实物**：在理赔完成前别丢，部分平台会要求寄回或核验。
3. **尽快反馈，别拖**：生鲜类一般要求签收后 **24～48 小时内** 申请，超时可能被拒。具体时限看你下单平台规则。
4. **找对应对象**：
   - 电商/即时零售下单 → 直接在订单页点"申请退款/售后"，选"腐坏/质量问题"，上传照片。
   - 商超购买 → 带小票和实物找门店服务台。
5. **协商不成就升级**：商家不处理时，电商平台可申请"平台介入"；仍不行可打 12315 或在全国12315平台投诉。

## 判断建议

- 如果你想售后省心，**优先在承诺"坏果包赔"的即时零售或大平台下单**，比线下买更稳。
- 买整箱进口水果，收货当场开箱检查、拍照，是最能避免扯皮的一步。
- 单个坏果通常按比例赔，整箱严重变质一般可全额退，具体以平台规则为准。
