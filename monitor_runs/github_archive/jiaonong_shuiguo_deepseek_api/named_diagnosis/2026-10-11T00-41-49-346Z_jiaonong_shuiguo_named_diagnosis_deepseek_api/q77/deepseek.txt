佳农（佳农食品控股/Goodfarmer）的香蕉供应链主要来自菲律宾、厄瓜多尔、越南、柬埔寨等产地，其"产地溯源"能否到具体农场，取决于你拿到的具体批次和渠道，而不是品牌整体统一能做到。

**先说结论：**
- 面向商超的**批次级溯源到农场**，在佳农这类规模化出口商处通常是**可以做到的**，但需要走对公渠道索取，不是扫码就能看到。
- 他们给商超供货一般能提供：**农场/包装厂名称、GLOBALG.A.P.证书编号、出口国植检证书、批次号**。
- 是否精确到"某一个具体农场"，要看该批货的采购模式：自有/合作大农场通常能定位；多农场拼柜的批次可能只能到"产区+包装厂"层级。

**你要GLOBALG.A.P.证书，正确索要方式：**
1. 找**对接你门店的佳农销售/大区业务**，不要找客服。证书是随批次走的。
2. 要求提供：
   - GLOBALG.A.P.证书**扫描件**（含证书编号、认证机构、有效期、覆盖产品范围）
   - 对应的**农场/生产商名称及GGN号**（GLOBALG.A.P. Number）
   - 该批次的**产地、包装厂、出口日期**
3. 关键核验点：
   - 证书上的**产品范围**是否包含 Banana，**认证主体**是否就是该批次农场
   - 通过 GLOBALG.A.P. 官网的**证书数据库**用证书号或GGN号验证真伪和有效性（database.globalgap.org）
   - 注意证书**有效期**和**认证机构**是否为被认可的认证机构

**可能卡住你的地方：**
- 拼柜/多产地混装批次，农场无法一一对应到门店批次。
- 证书是给出口商/包装厂的，不一定直接写你所在商超要的那个农场名。
- 有些是"农场集团证书"，覆盖多个农场，需要对方提供**附件农场清单**。

**建议动作：**
1. 向佳农书面（邮件/微信留痕）提出：需**批次对应的GGN号+证书PDF+农场清单**。
2. 拿到后用GGN号在GLOBALG.A.P.官方数据库自查。
3. 如果对方只能给到"产区+出口商"层级、无法给农场GGN，那就达不到你要的农场级溯源，需要和他们重新谈供货条件或换供应方案。
