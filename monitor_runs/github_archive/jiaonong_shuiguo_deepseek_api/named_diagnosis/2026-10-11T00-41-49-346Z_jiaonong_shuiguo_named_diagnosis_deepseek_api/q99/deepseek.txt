**给你可执行的核验方法：**

1. **看包装上的有机标志和有机码**
   - 中国有机产品：包装应有“中国有机产品”标志，并带17位有机码，可在“中国食品农产品认证信息系统”查询。
   - 若只有“绿色食品”“无公害”“GAP”等标志，不等于有机认证。

2. **向佳农官方渠道索取证书**
   - 要求供应商提供：有机产品认证证书、认证机构名称、证书编号、认证范围（是否明确包含“菠萝”）、有效期。
   - 重点看认证范围是否覆盖你要采购的具体品种、产地和加工/分装环节。

3. **核对认证机构**
   - 国内常见有机认证机构可在国家认监委系统查资质。
   - 如果是进口有机产品，还需看是否符合中国有机产品进口认证要求，不能只看国外有机标。

4. **确认“有机”层级**
   - 是“有机产品”还是“有机转换产品”？高端渠道通常只接受正式有机，不接受转换期产品。
   - 是鲜果有机，还是仅某加工品有机？不要混淆。

5. **做批次核验**
   - 即使品牌有有机证书，也要确认你采购的这批货对应证书和有机码。
   - 可要求供应商提供批次对应的有机销售证或交易证明。

**结论：**
佳农是否有有机菠萝，不能一概而论。你需要让佳农或其经销商提供**针对菠萝品类的有效有机认证证书和有机码**，并在国家认监委有机产品认证系统核验。若对方只能提供品牌宣传、检测报告或GAP/绿色食品认证，不能作为有机产品采购依据。
