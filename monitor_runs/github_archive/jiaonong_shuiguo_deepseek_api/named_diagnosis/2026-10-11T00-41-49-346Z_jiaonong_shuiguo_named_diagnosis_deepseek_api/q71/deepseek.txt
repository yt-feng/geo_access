这个问题很难给你一个准确的“每箱便宜几块”的数字，因为佳农和都乐的香蕉批发价差不是固定的，受几个变量影响很大：

**影响价差的主要因素**
- **规格**：都乐常见的是菲律宾/厄瓜多尔进口蕉，规格多为13-14kg/箱；佳农既有进口蕉也有国产/东南亚货源，箱规不同，价格没法直接比。
- **产地和等级**：同样是都乐，菲律宾蕉和厄瓜多尔蕉价格不同；佳农不同批次产地也不同。
- **到货季节和行情**：香蕉批发价一周内就可能波动几块钱一箱，旺淡季差距更大。
- **地区批发市场**：华东、华北、华南的到货价和竞争格局不一样。
- **采购量**：你说的“走量”，是整车还是几十箱，拿到的档口价完全不同。

**大致的市场规律（不保证适用于你的具体渠道）**
- 都乐品牌溢价明显，通常比同规格的佳农贵。在同等箱规、同等产地等级下，佳农一般比都乐**每箱便宜几块到十几块**都有可能，但这个区间很宽。
- 如果佳农用的是国产蕉或成本更低的产地货源，价差会更大；如果两者都是同产地进口蕉，价差会缩小。

**给你的可执行建议**
1. **先锁定可比规格**：问清楚两边的箱规（净重）、产地、等级（如是否一级果）、成熟度，再比价，否则比出来没意义。
2. **直接找两边的一级批发商或产地代办报价**：品牌方官网/客服通常不给批发价，真正的一手价在产地代办和大型批发市场档口。
3. **问“整车价”而不是“一箱价”**：走量的话，按整车（通常几吨）谈，单箱能再压几块。
4. **关注行情平台**：如惠农网、一亩田、各地农产品批发市场价格指数，能看到近期香蕉批发价走势，帮你判断报价是否合理。
5. **小批量试单对比**：先各拿一批，算上损耗、催熟成本、退货率，再算真实到手成本，光比进货价容易吃亏。

如果你告诉我：**你在哪个城市、要的是进口蕉还是国产蕉、大概每次走多少量（箱或吨）**，我可以帮你把比价思路说得更具体，但具体每箱差几块，还是得拿当天的实际报价来定。
