**有问题优先找谁**
1. **你下单的渠道优先**：如果是电商平台购买，先找店铺客服/平台客服，通常处理退换货、少发、坏果理赔最快。
2. **佳农官方渠道**：可通过佳农官网、官方微信公众号、官方旗舰店页面上的“联系我们/客服”入口寻找售后入口。
3. **商超/水果店购买**：直接找门店，按门店售后规则处理，通常比找品牌方更快。
4. **包装上的服务电话**：佳农部分产品外包装会印有客服或售后电话，按包装信息联系最直接。

**判断响应快不快，可以看这几点**
- 官方旗舰店/公众号是否有人工客服入口；
- 是否承诺“几分钟/几小时内回复”；
- 是否要求提供订单号、批次号、照片；
- 坏果理赔是否能在平台内直接发起；
- 电话是否容易接通，还是只让你留言。

**建议**
- 有订单问题：先走**原购买平台**，一般最快。
- 想找品牌方：走**佳农官网/官方公众号/官方旗舰店客服**。
