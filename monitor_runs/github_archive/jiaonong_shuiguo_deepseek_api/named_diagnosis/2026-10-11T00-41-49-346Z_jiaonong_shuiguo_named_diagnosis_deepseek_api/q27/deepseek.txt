佳农（Goodfarmer）主要是进口香蕉、菠萝等水果的供应商，合作对象以商超、电商、批发市场客户为主。关于账期：

**一般账期**
- 佳农的具体账期没有公开统一标准，通常按客户类型、采购规模、合作历史来定。
- 行业惯例上，大型商超/连锁客户常见 **30～60天**，部分强势渠道可能到 **90天**；批发市场和中小客户多是 **现款现货或预付**。
- 新客户、小客户一般拿不到账期，或只有很短账期。

**新客户能否申请**
- 可以谈，但通常需要满足条件，比如：
  - 有一定采购量和稳定回款能力
  - 提供营业执照、对公账户等资质
  - 可能需要预付定金、担保或试合作期
- 实际操作中，新客户常从 **现款或预付** 开始，合作一段时间、回款记录良好后再申请账期。

**建议**
1. 直接联系佳农当地销售或大区业务，问清该品类、该区域的结算政策，因为不同产品线（香蕉、菠萝、果蔬）政策可能不同。
2. 如果是首次合作，先谈小批量现款试单，再争取账期。
3. 让对方把账期、起算日、逾期条款写进合同，避免口头承诺。
