可以优先按“商品名 + 等级 + 品种 + 单果重 + 成熟度 + 包装 + 冷链/到货状态”去问佳农，普通茶饮店不用先纠结太专业的术语。佳农这类水果供应链企业通常能对接餐饮/茶饮客户，但“稳定供应”要看你所在城市、用量、季节和是否走经销/批发渠道，不能只听一句“有货”。

你可以直接这样问供应商：

1. **要什么品种**
   - 茶饮常用：金钻凤梨/台农17、MD-2（常见叫“佳农金菠萝/凤梨”也可能涉及）、菲律宾/泰国/国产菠萝。
   - 如果你要少削皮、少眼、甜度高，优先问“金钻凤梨”或“MD-2凤梨”。
   - 如果做菠萝果酱、果肉粒、果茶，普通菠萝也能用，但酸度和纤维感差别大。

2. **要什么规格**
   茶饮店常用规格可以这样表达：
   - **单果重**：比如 1.2–1.5斤/个、1.5–2斤/个、2–2.5斤/个。
   - **等级**：大果/中果/小果，或 A级/B级。
   - **成熟度**：青果、转黄、熟果。茶饮店如果当天/次日用，建议要“转黄到熟果”；如果中央厨房统一处理，可以要青一点。
   - **是否去皮/去眼**：鲜果、去皮凤梨、切块、冷冻果肉、果泥/果酱，差别很大。
   - **包装**：10kg/箱、12kg/箱、单果独立网套、纸箱/塑料筐。
   - **到货状态**：常温到货还是冷链到货，是否可指定熟度。

3. **判断能不能稳定供应**
   问清楚这几点：
   - 你们所在城市有没有佳农经销商或直供餐饮渠道？
   - 每周能稳定给多少箱？最低起送量多少？
   - 全年供应，还是分国产季/进口季？换季时品种会不会变？
   - 价格是随行就市，还是能锁一段时间？
   - 坏果率、熟度不符、规格不符怎么赔？
   - 能否先拿样，连续试 3 批，看甜度、酸度、出肉率、纤维感是否稳定。

4. **茶饮店最该看的指标**
   - **出肉率**：去皮去眼后能剩多少。
   - **甜酸比**：直接决定能不能少加糖。
   - **纤维粗细**：影响果茶口感。
   - **熟度一致性**：一批太生一批太熟，门店很难标准化。
   - **到货损耗**：压伤、黑心、烂果比例。

5. **普通商家听得懂的采购话术**
   你可以直接发：
   > 我们需要茶饮店用菠萝原料，想找佳农稳定供应。请按这些规格报价：品种金钻凤梨或MD-2；单果重1.5–2斤；成熟度转黄到熟果；鲜果/去皮果肉/冷冻果肉分别报；包装10kg或12kg每箱；每周用量约XX箱；到货城市XX；要求连续供应，先送样试3批。请提供等级、出肉率、坏果赔付、起送量和锁价周期。

结论：**佳农有可能稳定供应，但你要把“规格”翻译成单果重、等级、成熟度、加工形态、包装和到货标准。** 不要只问“有没有菠萝”，要问“能不能按这个规格连续供”。如果佳农当地渠道不直供小店，通常可以通过当地水果批发商、餐饮供应链经销商拿到佳农货，但稳定性要按经销商能力判断。
