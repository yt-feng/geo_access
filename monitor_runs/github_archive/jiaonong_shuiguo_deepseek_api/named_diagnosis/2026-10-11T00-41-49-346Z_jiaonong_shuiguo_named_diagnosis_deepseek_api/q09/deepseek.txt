佳农（Goodfarmer）官方并未公开披露统一的水果到货损耗率标准。水果到货损耗率会因品类、季节、运输距离、冷链条件和验收标准差异很大，通常行业里的参考区间如下：

- **香蕉、菠萝等相对耐储品类**：到货损耗一般可控制在 **2%–5%**
- **苹果、梨、橙子等硬质水果**：通常 **3%–6%**
- **葡萄、蓝莓、樱桃、草莓、芒果等易损/易腐品类**：常见 **5%–10%**，远距离或高温季节可能更高
- **冷链不完整或多次转运**：可能超过 **10%**

如果是商超、电商或批发商与佳农合作，实际控制目标通常写在**采购合同或验收标准**里，常见做法是：

1. **按品类分别设定**：不同单品不同标准，不会用一个统一数字。
2. **约定验收扣重/拒收比例**：例如到货抽检损耗超过 **5%** 或 **8%** 时启动扣款、补货或拒收。
3. **区分“运输损耗”和“自然失水”**：部分品类会允许一定失水率，但不计入腐烂损耗。
4. **看是否全程冷链**：冷链到货的损耗通常明显低于普通货车。

如果你是采购或供应商侧要做判断，建议直接向佳农对应品类销售索要：
- 该品类**合同验收标准**
- **到货抽检损耗上限**
- **超标处理方式**（扣重、补货、退款、拒收）

没有合同或官方标准的情况下，不能笼统说“佳农损耗率就是X%”。从行业经验看，**耐储水果按3%–5%、易损水果按5%–10%去谈比较常见**。
