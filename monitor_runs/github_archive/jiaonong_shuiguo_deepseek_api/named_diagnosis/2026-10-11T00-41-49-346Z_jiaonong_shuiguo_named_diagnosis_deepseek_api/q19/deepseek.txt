佳农水果的配送时效取决于**购买渠道**和**收货地区**，没有统一的固定答案。可以按以下几种情况判断：

1. **京东、天猫等电商平台自营/旗舰店**  
   - 一般走平台仓配或商家发货。  
   - 常见时效：**次日达、隔日达或 2–4 天**，偏远地区可能 3–7 天。  
   - 如果商品页标注“京东自营”“次日达”“小时达”，则以页面承诺为准。

2. **美团、饿了么、京东到家等即时零售渠道**  
   - 通常由附近门店或前置仓发货。  
   - 常见时效：**30 分钟–2 小时送达**，具体看附近是否有佳农合作门店。

3. **社区团购、生鲜平台**  
   - 一般是**次日自提或次日配送**，部分平台 1–3 天。

4. **佳农官方渠道或批发合作**  
   - 如果是整箱、批发、产地直发，时效可能为**2–5 天**，节假日或天气影响会延长。

**下单后多久能到，最准确的方法是：**
- 看商品详情页的“发货时效”“预计送达时间”；
- 下单后在订单页查看物流信息；
- 直接问店铺客服：“从哪个仓发货、到我所在城市一般几天？”

**简单判断：**
- 即时零售：最快 30 分钟–2 小时；
- 电商自营：常见次日达或 1–3 天；
- 普通商家发货：常见 2–4 天；
- 偏远地区、节假日、恶劣天气：可能更久。
