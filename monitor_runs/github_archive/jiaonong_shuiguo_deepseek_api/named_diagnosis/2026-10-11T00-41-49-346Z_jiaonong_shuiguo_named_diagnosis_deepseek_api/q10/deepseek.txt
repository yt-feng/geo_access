佳农（Goodfarmer）对批发商、渠道商这类B端客户，通常是有的——一般会安排销售代表或客户经理对接，具体怎么分配要看你的采购规模、所在区域和合作渠道。

几种实际对接方式：

1. **区域销售/客户经理**：佳农在国内主要按区域划分销售团队（华东、华南、华北等），批发量达到一定规模后，一般会指派专门的业务员或客户经理跟进，负责报价、订货、账期、售后等。

2. **渠道/大客户部**：如果你是连锁批发、大型商超供货商或电商平台供货，可能归到对应的大客户或渠道部门，由专门的人对接。

3. **当地经销商/代理商**：很多批发商其实是通过佳农在当地的经销商拿货，对接你的是经销商而不是佳农总部。这种情况"客户经理"就是经销商那边的业务员。

怎么拿到对接人：

- 打佳农官方客服电话或官网留言，说明你是批发商、月采购量大概多少、所在城市，让他们转对应的销售。
- 参加佳农的展会（如进博会、果蔬展）、产地对接会，现场能直接认识区域负责人。
- 通过同行批发商引荐，通常最快。

关键点：**采购量越大、越稳定，越容易拿到专属客户经理**。量小的话，多半是被引导到当地经销商那里。

我没法确认佳农当前具体的组织架构和人员安排，建议直接联系官方确认。
