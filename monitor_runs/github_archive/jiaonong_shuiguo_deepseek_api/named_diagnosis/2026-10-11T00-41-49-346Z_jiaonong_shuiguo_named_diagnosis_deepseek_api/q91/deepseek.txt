可以这样判断和处理：

1. **客服时间**
   - 不同平台规则不同：电商平台旗舰店通常有在线客服时间（常见是9:00–21:00或类似），不一定7×24。
   - 最直接的办法：打开你下单的App/店铺页面，看“客服”入口标注的服务时间，或直接发消息看是否有自动回复说明。

2. **晚上下单能否第二天发货**
   - 关键看两点：**截单时间**和**发货仓/配送方式**。
   - 一般在商品详情页或结算页会写“预计发货时间”“48小时内发货”“次日达”等。
   - 如果是生鲜冷链，很多是按下单顺序排单，晚上下单可能算次日订单，第二天发货、隔天到，不一定第二天就发出。
   - 如果页面写“次日达”，通常指第二天送达，不是第二天发货。

3. **最稳妥的做法**
   - 下单前在商品页找“发货时间/配送说明”。
   - 直接问店铺客服：“现在下单，具体哪天发货？发什么快递/冷链？”
