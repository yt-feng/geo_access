**建议这样确认：**

1. **联系佳农官方**
   - 官网/官方客服：问“冷冻菠萝丁”是否有货、规格、包装、起订量。

2. **重点确认这几个规格参数**
   - 切丁尺寸：常见有 10×10mm、15×15mm 等，茶饮常用小丁或果粒

   - 糖度、是否加糖/糖水浸渍
   - 保质期、储存温度（通常 -18℃）
