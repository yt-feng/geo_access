佳农香蕉通常按“到货状态”和“食用阶段”来管理，不是单一固定保质期。一般可参考：

**储存条件**
- **未熟/偏青**：放在**室温、阴凉通风处**，避免阳光直射和暖气旁。适宜约 **13–15℃**。不要马上放冰箱。
- **已熟/表皮转黄**：尽快食用；想延缓继续变熟，可放**冰箱冷藏室**。冷藏后表皮会变黑，但果肉若未冻伤，仍可在短期内食用。
- **已切开**：密封冷藏，建议 **24小时内** 吃完；也可冷冻用于打奶昔。

**保质期参考**
- **室温偏青香蕉**：通常 **2–5天** 逐渐转黄成熟。
- **室温已熟香蕉**：通常 **1–3天** 内食用最佳。
- **冷藏已熟香蕉**：可延长 **3–5天**，但风味和口感会下降。
- **冷冻**：去皮密封可存 **1–2个月**，解冻后适合加工，不适合直接鲜食。

**判断是否还能吃**
- 可吃：表皮有黑点但果肉正常、无酸败味。
- 不建议吃：果肉发黑、流汁、有酒味/酸味、霉变，或切开后长时间常温放置。

**实用建议**
- 想催熟：和苹果/香蕉一起放纸袋里，室温放置。
- 想延缓成熟：成熟后冷藏，或去皮切段冷冻。
- 佳农不同批次、运输方式和包装可能不同，最准确的是看包装上的**储存说明和保质期/最佳食用期**。
