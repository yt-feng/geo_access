佳农（Goodfarmer）有红富士苹果，通常以“佳农红富士”出现在商超、电商和批发渠道，产地多为山东、陕西、甘肃等主产区，规格从单果 80#、85#、90# 到礼盒装都有。  
鑫荣懋（Joyvio）同样有红富士，且它本身是国内大型水果供应链企业，苹果品类覆盖也比较全。

**性价比不能简单说谁绝对更高，主要看这几点：**

1. **同规格对比**  
   比如都买 80# 或 85# 红富士，单果重、果径、净重是否一致。很多“便宜”其实是规格更小或净重更少。

2. **产地和等级**  
   红富士品质很看产地和分级。洛川、栖霞、静宁等核心产区通常更贵；普通产区或统货更便宜。两个品牌都会做多产地、多等级，所以不能只认品牌。

3. **渠道和促销**  
   佳农在商超、电商铺货广，促销时性价比可能不错；鑫荣懋在高端商超、会员店、礼盒渠道更强，日常价可能偏高，但品控和包装有时更稳定。

4. **口感预期**  
   如果你追求脆甜、汁多、果面好看，重点看具体链接的产地、糖度、果径和评价；如果只是日常吃，选同规格里单价更低的即可。

**简单结论：**  
- 有红富士：佳农有，鑫荣懋也有。  
- 谁性价比高：**同产地、同果径、同净重、同等级下比单价**。  
- 一般日常自吃：佳农促销款可能更容易买到低价；送礼或看重稳定品控：鑫荣懋高端线可能更合适。  
- 最稳妥的判断方法：把两个商品拉到一起，对比“单果克重/果径、净重、产地、等级、单价”，而不是只看品牌。
