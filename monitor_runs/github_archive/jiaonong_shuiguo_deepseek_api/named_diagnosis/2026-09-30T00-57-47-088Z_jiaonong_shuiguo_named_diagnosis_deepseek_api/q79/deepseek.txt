关于佳农水果的配送覆盖和冷链收费，我无法给出准确的官方信息，因为佳农的业务模式在不同渠道差异很大，且配送范围、收费标准会随地区和时间调整。以下是可以帮你判断的框架和核实方法：

**1. 先分清你面对的是哪种“佳农”渠道**

佳农主要有几类销售渠道，配送规则完全不同：

- **大型商超/生鲜平台**（如盒马、永辉、京东到家、美团买菜等）：你下单的其实是这些平台，配送范围由平台决定，通常只覆盖其门店周边几公里。县城能不能送，取决于当地有没有该平台的门店或前置仓。
- **佳农官方旗舰店/官方小程序**：如果是官方直发，一般走快递或冷链快递，覆盖范围看快递能否到县城。
- **本地经销商/批发商**：很多县城的佳农水果是通过当地经销商铺货的，这种情况下“配送”其实是经销商自己安排的，和佳农官方无关。

**2. 你县城门店能不能送到，怎么判断**

最直接的办法：

- 打开你常用的生鲜App（京东到家、美团、饿了么、盒马等），把收货地址设成你县城的地址，搜索“佳农”，看是否有可下单的店铺和配送时间。
- 如果有官方小程序或客服电话，直接问“XX省XX县XX镇能否配送”。
- 如果当地有水果批发市场或经销商，问他们是否做同城配送、起送量和范围。

**3. 冷链物流收费，没有统一标准**

冷链费用通常不是按“佳农”统一收，而是看谁发货：

- **平台配送**：一般含在商品价或按订单收固定配送费，不单独算冷链费。
- **经销商同城冷链**：常见按距离、重量、件数或订单金额收费，比如几公里内固定价、超区加价、满额免运费。
- **快递冷链**：按重量和目的地计费，县城通常比市区贵，且很多冷链快递不到乡镇。

3. 直接联系该渠道客服，问清：是否配送、起送金额、冷链是否加价、多久到。
4. 如果平台送不到，问本地经销商或批发市场，他们往往能覆盖县城甚至乡镇。
