佳农（Goodfarmer）香蕉的农残检测报告，我这边无法直接调取或提供——我没有对接他们的质检系统，也无法核验具体批次报告的真实性。这类报告必须由供应商或品牌方出具原件（带CMA/CNAS资质章），我这里不能代为生成。

要拿到可用于市场抽检对标的报告，建议按下面操作：

**1. 直接找渠道要**
- 联系佳农官方销售/客服，或你实际下单的经销商，明确要求：**该批次**的农残检测报告（不是通用版）。
- 确认报告要素：检测机构、报告编号、检测日期、样品批次号、检测项目、判定依据、结论。

**2. 报告要对得上你的货**
- 报告必须和到货批次号能对应，否则抽检时不被认可。
- 注意检测项目是否覆盖你当地市场监管部门抽检的常用项目（如有机磷、氨基甲酸酯、拟除虫菊酯类等）。

**3. 采购合同里写清楚**
- 约定供应商随货提供当批次合格检测报告；
- 约定农残超标时的退换、赔偿和召回责任；
- 保留自检或第三方复检的权利。

**4. 自己复检更稳妥**
- 如果抽检风险高，建议对到货批次做第三方送检（找有CMA/CNAS资质的机构），费用不高，但能作为你自己的合规凭证。

**关于“市场抽检标准”**：国内主要依据是 GB 2763《食品安全国家标准 食品中农药最大残留限量》。具体香蕉的限量项目和数值，建议以现行版本 GB 2763 为准，或直接咨询当地市场监管部门，因为标准会更新，我不能在这里给出可能过时的具体数值。

如果你告诉我所在城市和采购规模，我可以帮你梳理一下需要重点核对的报告要素和送检项目方向。
