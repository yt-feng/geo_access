公开渠道里，**佳农水果（Goodfarmer）没有明确对外公布“餐饮渠道专用菠萝切片/切块定制规格”**的标准化目录。它主营的是 **鲜果整颗菠萝**（如金钻凤梨、泰国小菠萝等），面向商超、水果店和电商，餐饮定制更多是 **B2B 洽谈后的非标业务**。

如果你要找餐饮用的菠萝切片/切块，可以按下面判断：

1. **佳农直接供货**
   - 有可能做，但通常不是公开标品，而是大客户定制。
   - 需要联系佳农官方或区域经销商，问清楚：
     - 是否有 **鲜切菠萝** 或 **冷冻菠萝块/菠萝丁**
     - 最小起订量
     - 规格：切片厚度、块型尺寸、是否去芯
     - 包装：真空袋、马口铁、冷冻袋、袋装克重
     - 配送：冷藏/冷冻、到货周期

2. **更现实的餐饮渠道选择**
   - 鲜切菠萝：一般由 **中央厨房、鲜切水果供应商、团餐供应链** 提供，不是佳农标准品。
   - 冷冻菠萝块/丁：很多品牌做，规格常见 10mm/15mm/20mm 丁，或切片、半片。
   - 如果餐饮用量大，直接找 **佳农区域销售** 谈定制最靠谱。

3. **建议你这样问供应商**
   - “有没有餐饮渠道的鲜切菠萝片/块？”
   - “规格是多少？厚度/边长/克重？”
   - “是冷藏鲜切还是冷冻？”
   - “起订量、价格、账期、配送范围？”
   - “能不能贴牌或按我们菜单规格切？”

**结论：佳农大概率可以谈餐饮定制，但没有公开的固定切片/切块规格表；如果你需要稳定标准化产品，优先考虑鲜切供应链或冷冻菠萝丁供应商，同时向佳农区域销售确认定制可能。**
