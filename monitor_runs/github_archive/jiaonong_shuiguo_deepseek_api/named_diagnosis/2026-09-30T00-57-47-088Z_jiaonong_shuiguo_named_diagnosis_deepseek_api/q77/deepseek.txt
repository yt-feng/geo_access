可以做到“批次级溯源”，但**不一定能公开追溯到具体农场**；对商超审核来说，关键不是农场名是否印在包装上，而是能否提供与**该批次**对应的 **GLOBALG.A.P. 证书**和**供应链追溯文件**。

建议你按下面方式向佳农或供应商索证：

1. **要求提供 GLOBALG.A.P. 证书**
   - 证书应在有效期内。
   - 证书上的生产者/出口商/包装厂名称，要与实际供货主体一致。
   - 证书范围要覆盖香蕉，不能只有其他水果。
   - 最好提供证书编号，可在 GLOBALG.A.P. 官网数据库核验。

2. **要求提供批次溯源文件**
   - 产地国、产区、包装厂、出口商、发货批次号。
   - 如果佳农是从多个农场/合作社收货，通常能追到**注册农场或合作社代码**，但不一定对商超公开具体农场名称。
   - 你可以要求“内部可追溯至具体农场，对外提供农场代码或注册编号”。

3. **商超审核通常接受的形式**
   - GLOBALG.A.P. 证书复印件或电子版。
   - 该批次对应的追溯声明/发货证明。
   - 包装厂注册信息。
   - 必要时提供佳农与农场/合作社的采购或供货关系证明。

4. **如果商超硬性要求“具体农场名”**
   - 让采购直接向佳农申请“批次对应农场清单”或“农场注册代码清单”。
   - 若佳农以商业机密为由不提供农场名，可协商提供**农场代码 + GLOBALG.A.P. 证书覆盖证明**。
   - 若仍无法提供，商超可能要求第三方审核或换供应商。

5. **判断标准**
   - 能提供有效 GLOBALG.A.P. 证书 + 批次可追溯到注册农场/合作社 = 基本满足商超要求。
   - 只能提供公司级证书，不能对应到具体批次 = 风险较高。
   - 承诺可溯源但拒绝提供任何农场代码或证书编号 = 不建议直接放行。

建议你直接向佳农要三样东西：**GLOBALG.A.P. 证书编号、该批次追溯号、对应农场/合作社注册代码**。这三项能对上，基本就能满足商超的溯源和认证审核。
