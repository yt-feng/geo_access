## 先分清两件事

1. **“有没有历史超标记录”**
   - 这属于企业/产品历史合规信息，需要查官方公开数据或向供应商索取证明。
   - 我没法凭记忆确认佳农是否有过香蕉农残超标处罚或抽检不合格记录。
   - 你应通过官方渠道核验，而不是只信供应商口头承诺。

2. **“超市抽检能不能过”**
   - 关键不是品牌历史，而是**这一批次香蕉是否有合格检测报告、是否可追溯、是否符合 GB 2763 农残限量**。
   - 超市抽检通常按现行食品安全国家标准判定，不是按“品牌过去有没有问题”判定。

## 采购必须拿到的合规材料

要求供应商提供以下材料，缺一项都可能影响超市抽检和进货合规：

1. **批次对应的农残检测报告**
   - 必须是第三方 CMA/CNAS 资质机构出具。
   - 报告要能对应你采购的**具体批次、生产日期/采摘日期、数量**。
   - 检测项目至少覆盖香蕉常见高风险农残，如：
     - 吡虫啉
     - 噻虫嗪
     - 噻虫胺
     - 苯醚甲环唑
     - 丙环唑
     - 百菌清
     - 毒死蜱
     - 甲拌磷等禁限用农药
   - 最好按 GB 2763 当前版本判定。

2. **承诺达标合格证或产地证明**
   - 农产品承诺达标合格证。
   - 产地证明、收购凭证、发货单。

3. **进货台账和可追溯信息**
   - 供应商名称、地址、联系方式。
   - 香蕉产地、果园/合作社、加工厂、批次号。
   - 运输和贮存记录。

4. **供应商资质**
   - 营业执照。
   - 食品经营许可证或食用农产品相关资质。
   - 若为进口香蕉，还需入境货物检验检疫证明、报关单等。

5. **企业自检或委托检测记录**
   - 供应商近批次自检报告。
   - 若超市有指定检测项目，要求按超市标准加测。
