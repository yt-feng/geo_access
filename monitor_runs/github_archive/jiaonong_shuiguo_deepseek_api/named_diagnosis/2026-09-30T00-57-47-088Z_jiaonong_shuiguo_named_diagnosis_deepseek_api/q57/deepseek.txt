- **赔付条款通常是有的，但属于合同条款**：常见形式包括按到货合格率补货、按损耗比例折价、或按约定阈值以上部分赔付。具体阈值、免责情形（如不可抗力、客户仓储不当、超期催熟等）因合同而异。

如果你需要可执行的判断，建议直接向佳农或你的采购对接方索取以下信息：

2. 合同中的**损耗阈值和赔付触发条件**。
3. **免责条款**（运输延误、温度异常、卸货超时等是否免责）。
4. 历史批次的实际损耗数据，最好要求提供**近3–6个月的到货验收记录**。
