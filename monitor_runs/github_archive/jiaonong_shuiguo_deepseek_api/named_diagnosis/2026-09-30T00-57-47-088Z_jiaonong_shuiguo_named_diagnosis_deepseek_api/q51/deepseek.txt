**1. 最小起订量（MOQ）**
- 佳农水果礼盒的定制通常不是单一标准，常见按**箱/套**计，且会区分：
  - **标准现货礼盒**：起订量较低，可能几十套起；
  - **定制礼盒（换外箱/内托/腰封/卡片）**：起订量明显更高，常见几百套甚至上千套；
  - **只贴标/挂吊牌**：起订量通常最低。
- 影响MOQ的关键因素：是否需要重新开版印刷、礼盒结构是否改动、水果品类是否当季、是否要求统一规格和成熟度。

**2. 能否印公司logo**
- 一般**可以**，但方式不同，门槛不同：
  - **外箱印刷logo**：最常见，通常需要达到一定起订量；
  - **礼盒腰封/贴纸/吊牌**：起订量较低，适合小批量；
  - **内托、果贴、独立包装印logo**：要求更高，可能涉及食品接触材料合规和额外开版费。
- 如果只是团购送礼，**腰封+手提袋+卡片印logo**通常是最容易落地的方式。

**3. 你直接问经销商这5个问题**
1. 这款礼盒的MOQ是多少套？标准版和定制版分别是多少？
2. 印我们logo是印在外箱、腰封、吊牌还是果贴上？要不要开版费？
3. 打样费多少？打样周期和大货周期各几天？
4. 报价是否含税、含运费？到我们城市怎么算？
5. 如果只要500套/1000套，能不能做？不能的话最低做到多少？

**4. 实操建议**
- 先定预算和数量，再选定制深度：数量少就选**贴标/腰封/吊牌**，数量大再考虑**外箱专版印刷**。
- 要求对方提供**同款定制案例图**和**书面报价单**，把MOQ、logo工艺、交期、售后坏果赔付写清楚。
- 如果对方说“都能做”，一定要追问：**具体MOQ、打样费、开版费、交期、是否含运费**，这四项不写进报价单就容易后期加价。
