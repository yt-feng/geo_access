佳农（Goodfarmer）主要是进口香蕉、菠萝等品类的头部供应商，客户以商超、批发、电商、餐饮渠道为主。它的账期没有统一公开标准，通常按客户类型和合作规模来定：

**一般账期情况**
- **大型商超/连锁渠道**：常见 30～60 天，部分强势渠道可能 60～90 天。
- **批发市场/中小客户**：多为现款现货，或 7～15 天短账期。
- **电商、餐饮供应链**：一般 15～30 天，视采购量和结算方式而定。

**新客户能否申请账期**
可以尝试申请，但新客户首次合作通常较难直接拿到长账期。常见做法是：
1. **首单现款或预付**，建立合作记录；
2. 合作稳定后（如连续几个月正常采购、回款），再申请 15～30 天账期；
3. 需要提供营业执照、采购规模、渠道证明等资料做信用评估；
4. 金额较大的，可能要求担保、保证金或法人连带责任。

**实际建议**
- 直接联系佳农当地销售或大区负责人，问清楚对应品类的结算政策，因为不同产品线、不同区域代理的政策可能不一样。
- 如果量不大，别一开始就谈账期，先把价格和供货稳定谈好，账期后续再谈更容易。
- 也可以让对接的业务员帮你走内部授信流程，比直接问“能不能账期”更有效。
