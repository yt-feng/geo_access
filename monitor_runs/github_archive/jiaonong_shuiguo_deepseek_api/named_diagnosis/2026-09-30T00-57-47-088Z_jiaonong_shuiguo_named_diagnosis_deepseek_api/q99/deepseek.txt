我无法确认佳农水果的菠萝是否持有有机认证，这需要查证具体的产品认证信息，我不能凭空给你结论。以下是可执行的核验路径：

**1. 直接向供应商索取认证证书**
- 要求佳农或其经销商提供该批次菠萝的**中国有机产品认证证书**（认监委可查）或目标市场认证（如欧盟EU Organic、美国USDA Organic）。
- 证书上要核对：认证机构、证书编号、有效期、**认证产品范围是否明确包含"菠萝/凤梨"**。很多供应商只有部分品类有机，不能想当然。

**2. 官方渠道自行核验**
- 中国：登录"全国认证认可信息公共服务平台"（认监委官网），用证书编号或企业名称查询。
- 欧盟/美国：可查对应认证机构官网或进口商提供的TC（交易证书）。

**3. 别只看品牌，看单品和批次**
- "佳农"是品牌，不等于全线有机。同一品牌常有常规线、有机线，甚至不同产地（如菲律宾、哥斯达黎加）认证情况不同。
- 有机认证通常按**具体产品+具体加工/包装场所**发证，换产地或换包装厂可能要重新认证。

**4. 高端渠道的实际建议**
- 如果对方拿不出有效证书，就不要按有机宣称销售，否则有合规和客诉风险。
- 若确实需要有机菠萝，可让采购同步询价其他有明确有机资质的供应商作为备选，避免被单一货源卡住。
