佳农（Goodfarmer）对批发商这块通常是**有对接机制的**，但具体是不是“专人客户经理”取决于你的采购规模、渠道类型和合作区域。

一般情况是这样：

1. **有批发/渠道销售团队**
   佳农做香蕉、菠萝、火龙果等进口水果起家，批发、商超、电商、餐饮供应链都是主要渠道，所以会有对应的销售对接人员。

2. **大批量/长期合作：大概率配专属客户经理**
   如果你有稳定月采购量、能走对公、有仓储配送能力，通常会给你安排区域销售或大客户经理，负责报价、排货、账期、售后。

3. **小批量/零散拿货：可能只是区域销售或经销商对接**
   如果你量不大，或者通过二级批发市场拿货，可能不是厂家直供，而是区域经销商在对接，不一定有“专属客户经理”。

4. **怎么确认最有效**
   - 打佳农官网/官方公众号上的客服电话，直接说：我是批发商，月采购量大概多少，想找区域销售对接。
   - 问清楚：是厂家直供还是经销商供货、有没有起订量、能不能对公、账期怎么算、冷链和售后谁负责。
   - 如果对方只给你一个经销商电话，基本说明你当前体量还不到厂家直客门槛。

5. **你可以直接这样问**
   “我们是XX市场的批发商，主要做XX品类，月采购大概XX吨，想问你们有没有区域客户经理对接？起订量、价格政策、配送和账期怎么定？”

如果你告诉我你所在城市、主要想拿什么水果、大概月采购量，我可以帮你判断更可能是厂家直供还是走经销商，以及谈判时该重点问什么。
