1. **发票**

2. **质检报告**
   - 正规渠道通常可提供：**批次质检报告/出厂检验报告**，部分可提供第三方检测报告。
   - 要确认是否**按你采购的这批货对应批次**提供，而不是只给一份通用旧报告。
   - 水果礼盒还建议一并索要：**产地证明、检疫合格证明、农残检测报告、供应商营业执照和食品经营许可证**（如涉及预包装/切果/加工果切，要求更严格）。

3. **500份团购建议你在下单前书面确认**
   - 是否支持开票，发票类型、税率、开票时间；
   - 是否随货或发货前提供对应批次质检报告；
   - 礼盒规格、果品等级、净重、坏果赔付标准；
   - 发货时间、冷链/物流方式、能否分批送；
   - 是否支持签收后24-48小时内售后理赔。

4. **最稳妥的做法**
   - 如果对方自称“佳农”，要求其提供**品牌授权书或经销证明**；
