佳农水果的产地直供比例整体较高，但具体数字会随年份、品类和渠道口径变化，官方一般不会持续公开统一比例。可以这样判断：

- **香蕉**：佳农是国内进口香蕉头部企业之一，香蕉主要来自**厄瓜多尔、菲律宾、哥伦比亚、哥斯达黎加、越南**等国家，其中**厄瓜多尔和菲律宾**通常是较核心的来源。
- **产地直供**：佳农强调“产地直采/直供”，在香蕉、菠萝、火龙果等进口水果上，很多是直接与海外产区、合作农场或包装厂对接，再通过自有或合作冷链进入国内。相比多级批发，直供比例较高。
- **但要注意**：不同水果差异很大。香蕉、菠萝等核心单品直供程度通常更高；一些季节性、小众或国内水果，可能仍会通过产地供应商、合作社或批发市场补充。
- **可执行判断**：如果你关心某一批货，最直接的是看包装箱/标签上的**原产国、果园/包装厂注册号、出口商、进口商**，或向佳农官方客服/业务员索要该批次的产地证明和直采说明。只看“佳农”品牌，不能推断所有单品都是同一比例直供。
