我无法确认佳农水果目前是否提供这类定制化加工服务，因为这属于具体企业的业务范围和服务条款，需要以官方渠道的信息为准，我不能凭空给出确定答案。

不过可以给你一些判断和操作建议：

**1. 这类服务在行业里通常存在，但分情况**
- 鲜果品牌/贸易商一般主营**整果批发、分销**，未必直接对接“切块、分装”这类加工。
- 切块、包装属于**鲜切加工（鲜切水果/净菜）**业务，通常需要专门的加工资质、冷链和卫生条件。
- 有些大型水果企业确实有鲜切产线，可对商超、餐饮、电商等 B 端客户提供定制；但并非所有品牌都开放。

**2. 建议这样核实（最有效）**
- 去**佳农官网**找“业务合作/B端服务/鲜切加工”板块，或看其招商、商超供应介绍。
- 直接联系**官方客服或大客户/渠道合作部门**，明确问：
  - 是否提供菠萝切块、鲜切、分装
  - 起订量（MOQ）是多少
  - 是否只对 B 端（商超、餐饮、电商）开放
  - 规格、包装形式、冷链与配送范围
- 如果是采购量较大，可问其**是否有代工/OEM 或定制包装**能力。

**3. 如果佳农不做，替代方案**
- 找专业**鲜切水果加工厂**，它们通常可做切块、真空/气调包装。
- 或找菠萝产地的**合作社/加工厂**做代加工。
