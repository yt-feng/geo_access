可以给你一套快速确认和替代判断的方法：

**1. 直接找佳农官方渠道确认**
- 佳农食品官网/官方公众号的“联系我们”或“经销商查询”
- 佳农在主要城市的冷冻水果经销商
- 问清楚这几点：  
  - 是否有**冷冻菠萝丁/IQF速冻菠萝丁**  
  - 规格：包装规格（如1kg/袋、10kg/箱）和**果丁尺寸**（如10×10mm、15×15mm）  
  - 是否**糖渍/无糖**、是否**巴氏杀菌**、是否**适合茶饮直接使用**  
  - 起订量、冷链发货、保质期和解冻后状态

**2. 茶饮店选菠萝丁时重点看**
- **尺寸**：茶饮常用约 **8–15mm 小丁**，太大不好吸、太小易碎成渣。
- **状态**：冷冻丁要颗粒分明、少结块、解冻后不出大量水。
- **糖度/酸度**：如果做果茶，优先选**糖渍或调酸**的，避免鲜果风味过淡或过酸。
- **耐热/耐泡**：如果要做热饮或长时间浸泡，需确认是否容易变软烂。

**3. 如果佳农没有合适规格，可替代方向**
- 其他冷冻水果供应商的 **IQF 菠萝丁**
- 茶饮原料商的 **糖渍菠萝丁/果酱型菠萝丁**
- 罐头菠萝丁（成本低，但脆度和鲜感通常不如冷冻/IQF）
