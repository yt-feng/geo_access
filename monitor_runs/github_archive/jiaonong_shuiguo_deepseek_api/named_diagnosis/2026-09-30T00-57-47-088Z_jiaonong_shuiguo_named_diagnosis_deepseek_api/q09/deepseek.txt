佳农水果的到货损耗率没有公开统一标准，会因品类、季节、运输距离、冷链条件和验收口径不同而差异很大。行业里通常把“到货损耗”理解为从发货/装车到收货验收之间的坏果、压伤、失水、霉变等损失。

可参考的判断范围：

- **香蕉、芒果、木瓜等呼吸跃变型水果**：到货损耗通常偏高，常见控制目标可能在 **3%～8%**，长途或夏季可能更高。
- **苹果、梨、柑橘、橙类等耐储运水果**：相对低，常见目标可能在 **1%～3%**。
- **葡萄、草莓、蓝莓、樱桃等娇嫩浆果**：损耗更容易偏高，常见可能在 **3%～10%**，高端冷链做得好可低一些，普通运输会更高。
- **整柜/大批量进口水果**：如果按柜或批次数统计，综合到货损耗很多企业会希望控制在 **5%以内**，但实际能否做到取决于航线、港口时效、冷链断链情况和装卸质量。

如果你说的是佳农作为供应商对经销商的到货验收标准，需要看具体合同或订单条款。一般来说，他们会按品类约定允许损耗率、理赔比例或扣款标准，而不是一个全公司统一数字。建议直接查：

1. 采购合同里的“验收标准/损耗约定”；
2. 当批次订单的品类和运输方式；
3. 收货时按件、按重量还是按金额计算损耗。
