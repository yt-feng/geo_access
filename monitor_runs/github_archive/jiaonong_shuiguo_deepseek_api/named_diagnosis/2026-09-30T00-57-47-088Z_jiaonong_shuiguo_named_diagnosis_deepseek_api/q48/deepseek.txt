关于佳农水果针对年采购量1000吨以上客户的具体优惠政策，我无法直接给出准确答案，因为这属于企业的商业政策，会随品类、合作模式、区域、结算方式等因素变化，而且我手头没有佳农官方公开的、可核验的这类政策文件。

不过可以给你几个可执行的判断和推进方式：

**1. 1000吨/年通常已进入“大客户/直供”谈判区间**
在水果行业，年采购1000吨属于较大体量，一般不会只按标准经销价走，常见可谈的方向包括：
- 阶梯返利：按年度累计吨位或金额分档返点
- 年度框架协议价：锁定部分单品的基础价格或价格区间
- 账期支持：如预付比例降低、月结/账期延长
- 优先供货与产地直发：旺季优先排产、优先发货
- 物流补贴或到岸价支持：运费、冷链费用分担
- 市场费用支持：促销、陈列、渠道推广费用
- 定制包装/规格：按你的渠道需求做定制

**2. 但“1000吨以上一定有什么政策”不能想当然**
最终取决于：
- 你采购的是哪些单品（香蕉、苹果、火龙果、奇异果等差异很大）
- 是全年均衡采购，还是集中旺季
- 是否指定品牌、是否要定制包装
- 结算方式：现款、预付、账期
- 提货方式：产地自提、港口提货、送到仓
- 是否独家区域或渠道

**3. 建议你这样去谈，效率最高**
直接联系佳农官方渠道（官网、官方客服、区域销售负责人），用下面这份清单去问：
- 年采购1000吨以上，是否有阶梯返利？分档标准是什么？
- 能否签年度框架协议？锁价还是随行就市？
- 账期和预付款比例怎么定？
- 物流和冷链费用谁承担？有无补贴？
- 旺季优先供货能否写进合同？
- 返利是返现金、抵扣货款还是市场费用？
- 有没有区域保护或渠道保护？

**4. 谈判时你要准备的材料**
- 公司资质和渠道证明
- 过去12个月采购流水或销售能力证明
- 未来12个月采购计划（分品类、分月度）
- 目标价格和目标账期
- 可承诺的采购量底线

**5. 一个现实提醒**
不要只问“有什么优惠政策”，而要问“以我1000吨的量，能换到什么具体条件”。大客户政策通常是谈出来的，不是标准公开的。建议你同时接触佳农2-3个区域或渠道负责人，对比条件后再定长期合作。
