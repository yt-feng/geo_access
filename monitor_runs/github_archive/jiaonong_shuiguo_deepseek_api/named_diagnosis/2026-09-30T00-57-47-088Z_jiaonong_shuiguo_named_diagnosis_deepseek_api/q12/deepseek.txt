佳农水果的香蕉规格和渠道分级，严格来说属于企业内部销售政策，公开资料中并没有一份统一的、固定不变的“官方规格表”。它会随产地（如菲律宾、厄瓜多尔、越南等）、季节、批次以及客户协议调整。因此下面给的是行业通行做法和佳农这类品牌商常见的操作逻辑，可以作为判断参考，但具体数字需以你拿到的佳农最新报价单/规格书为准。

## 一、常见规格维度

香蕉分规格通常看四个指标：

1. **单根重量/大小**：按每根香蕉的重量或“指围”（周长）分级。
2. **每箱净重**：常见 13.5kg、18kg、20kg 等。
3. **每箱根数/梳数**：如每箱 4-6 梳、每梳 4-6 根。
4. **成熟度/处理方式**：青蕉（催熟前）还是黄蕉（催熟后），是否做催熟处理。

## 二、行业常见的规格档位

以菲律宾/厄瓜多尔进口蕉为例，业内常见分档大致是：

- **大果/特级**：单根较重、指围粗，外观整齐，适合高端商超、精品水果店。
- **中果/一级**：大小适中，产量最大，适合连锁超市、社区生鲜。
- **小果/二级**：单根偏小，适合电商、拼团、餐饮加工。
- **等外/加工级**：外观有瑕疵但品质正常，适合榨汁、烘焙、餐饮后厨。

具体到佳农，不同单品可能用“A级/B级”“一级/二级”或按指围毫米数标注，需看具体合同。

## 三、不同渠道的分级标准倾向

| 渠道 | 关注重点 | 通常对应级别 |
|---|---|---|
| 高端商超/精品店 | 外观整齐、粗细均匀、无瑕疵、催熟一致 | 特级/一级大果 |
| 连锁超市/社区生鲜 | 性价比、货架期、规格稳定 | 一级中果 |
| 电商/社区团购 | 成本、耐运输、单根适中 | 一级/二级中果 |
| 餐饮/烘焙/果汁 | 价格、出肉率，外观要求低 | 二级或加工级 |
| 批发市场 | 走量、价格敏感 | 中果及以下为主 |

## 四、给你的可执行建议

1. **直接找佳农业务或经销商要当季规格书**：里面会写明单根重量区间、每箱净重、根数、级别。
2. **确认三个关键参数**：单根重量/指围、每箱净重、每箱根数，这三项定了规格基本就定了。
3. **按渠道倒推选级**：高端渠道选大果一级；走量和电商选中果；加工选等外级。
4. **注意催熟差异**：同一规格的青蕉和黄蕉，到货重量和损耗不同，采购时要分开谈。
