关于佳农水果（Goodfarmer）香蕉的具体分级标准，公开渠道没有一个统一对外的官方文件，而且佳农本身既有自有品牌也有代理/进口货源，分级规则会因产地（菲律宾、厄瓜多尔、越南等）和批次略有差异。所以下面说的是行业内通行做法+佳农通常执行的口径，具体报价仍需找佳农当地销售或经销商确认。

**一、香蕉分级的主要维度**

行业内分一级、二级，主要看这几项：

1. **条重（单根重量）**：一级果通常要求单根在120–160g以上，条形饱满；二级果偏小或偏大不均匀。
2. **条形与弯曲度**：一级果条身顺直、弯曲均匀、无畸形；二级果有弯扭、双条、连体。
3. **外观**：一级果无黑斑、无机械伤、无虫疤、无裂口、梳形整齐；二级果允许轻微瑕疵。
4. **成熟度/色泽**：一级果青度均匀、催熟后色泽一致；二级果青黄不均。
5. **梳把整齐度**：一级果每梳条数均匀、切口平；二级果大小混杂。
6. **规格一致性**：一级果整箱规格统一（如4-6把/箱，条数一致）；二级果允许混装。

**二、价格差**

没有固定数字，因为香蕉是随行就市、按周甚至按天变价的生鲜品。但可以给你一个行业参考区间：

- 同一货源、同一时间点，**二级果通常比一级果便宜10%–25%**。
- 品相差距大、或行情走弱时，二级果折价可能到**30%甚至更多**；行情紧俏、一级果缺货时，价差会缩到**5%–10%**。
- 二级果里还常分“二级A/二级B”，价差再往下拉。

**三、给你可操作的建议**

1. 直接找佳农在当地的销售代表或区域经销商，要**当批次的《品质规格书》或验收标准**，上面会写条重、条数、允许瑕疵比例——这是唯一权威依据。
2. 报价时让对方明确：产地、规格（条重区间）、每箱净重、把数/条数、是“一级”还是“二级A/二级B”，否则价差没法比。
3. 如果长期批发，可要求看**当批到货实拍或抽检样品**，因为分级争议大多出在“外观瑕疵”这一项，纸面标准执行松紧差别很大。
4. 比价时统一口径：同样产地、同样条重、同样箱规的报价才可比，否则一级和二级的价格差会被规格差异掩盖。
