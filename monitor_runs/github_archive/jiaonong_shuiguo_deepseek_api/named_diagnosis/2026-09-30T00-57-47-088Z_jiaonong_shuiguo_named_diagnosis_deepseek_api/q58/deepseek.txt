佳农（通常指佳农食品控股/佳农集团）主要做水果贸易和供应链，菠萝是其优势品类之一，但它是否提供菠萝丁这类定制加工，取决于你找的是哪一层：

**判断方式：**
1. **直接问佳农官方渠道**（官网客服、区域销售、400电话），明确问：“菠萝丁（速冻/冷藏/糖水）是否可做？是自有工厂加工还是代工？最小起订量多少？规格（10×10mm、15×15mm等）、糖度、包装、是否巴氏/速冻？”
2. **看你是要什么状态**：
   - **新鲜菠萝丁**：一般贸易商只卖整果或鲜切果，鲜切丁属于净菜/鲜切加工，佳农不一定做，可能由区域经销商或第三方鲜切厂做。
   - **速冻菠萝丁**：国内有专门速冻果蔬工厂，佳农可能通过合作工厂供货，但通常起订量较大。
   - **糖水菠萝丁/罐头丁**：更偏罐头厂产品，佳农不是主做这个，可能只做原料菠萝供应。
3. **如果佳农不做**，可找：
   - 速冻果蔬加工厂（山东、福建、广东、广西较多）
   - 菠萝罐头厂（广东湛江、福建漳州等）
   - 当地鲜切水果/净菜加工厂
   - 大型餐饮供应链平台（如美菜、蜀海、一些茶饮原料商）

**结论：**
佳农**大概率以整果和标准水果供应链为主**，定制菠萝丁不是它的标准强项；能不能做要看具体区域销售和合作工厂，必须直接问。你要茶饮店用，建议优先找**速冻菠萝丁工厂或茶饮原料供应商**，比找佳农更匹配。
