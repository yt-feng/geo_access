我不能给出佳农水果统一的配送时效承诺，因为佳农在不同渠道卖货，配送方和时效差异很大；具体时效要以你下单的平台/店铺页面显示为准。

可判断的情况大致是：

1. **在电商平台买（京东、天猫、拼多多、抖音等）**
   - 通常由平台仓或商家仓发货，页面会标“预计送达时间/发货时效”。
   - 生鲜水果一般会优先发冷链或航空件，但**城市、仓库距离、是否预售**影响很大；同城可能次日达，偏远地区可能要2—4天甚至更久。
   - 下单前重点看商品页的：**发货地、发货时效、预计送达、是否冷链、节假日公告**。

2. **在佳农官方旗舰店/官方小程序买**
   - 以结算页或订单页的“预计送达”最准；官方店通常会有发货规则说明。
   - 若页面只写“48小时内发货”，这**不等于48小时送达**，只是发货时限。

3. **在商超/即时零售平台买（美团、饿了么、京东到家等）**
   - 若有附近门店库存，通常**30分钟—2小时**送达；具体看门店覆盖。

**下单后多久能到，最准确的做法：**
- 看商品页“预计送达时间”；
- 下单后看订单详情里的物流/配送进度；
- 超过页面承诺时效未发货，直接联系店铺客服或平台客服催发/改约。

如果你告诉我具体是在**哪个平台/店铺**下单、收货城市，以及商品页写的发货时效，我可以帮你判断大概多久能到、是否正常。
