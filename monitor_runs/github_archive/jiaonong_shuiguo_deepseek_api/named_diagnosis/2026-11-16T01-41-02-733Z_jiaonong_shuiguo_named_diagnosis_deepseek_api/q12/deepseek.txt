可以判断的部分：香蕉常按“每箱净重 + 每根/每把果指数量 + 果指粗细长短 + 成熟度”做渠道分级，但**佳农具体在售规格和分级标准属于企业渠道政策，公开信息不足以逐条核验，不能给出确定清单**。建议按下面方式执行并自行向官方确认。

**可执行做法**
1. 先向佳农官方客服/区域销售索取三份资料：  
   - 最新产品规格表（净重、果指数、单果重区间、长度/粗度）  
   - 渠道分级标准（商超、水果店、电商、批发、餐饮）  
   - 各规格对应箱规、条码、保质期与到货成熟度
2. 不要只看“几斤装”，要同时确认：  
   - 净重 vs 毛重  
   - 每箱果指数/每把指数  
   - 单果重量或果指周长（决定分级）  
   - 到货成熟度（青蕉/微黄/黄熟）  
   - 允许的机械伤、黑斑、果指弯曲度等验收指标

**常见渠道分级逻辑（供谈判和验收参考，不是佳农官方标准）**
- **商超/精品店**：果指均匀、长度和粗度整齐、外观洁净、无明显机械伤，成熟度可控，按小箱/精装规格走。
- **电商/社区团购**：耐运输、箱规适中、成熟度偏青或微黄，重视到货一致性和破损率。
- **批发市场**：更看净重、果指饱满度和价格带，允许轻微外观差异，按大箱走。
- **餐饮/加工**：更关注出肉率、成熟度和成本，对外观分级要求相对低。

**判断建议**：如果对方只报“规格有几种”而不给净重、果指数、单果重和成熟度，不能作为采购分级依据；应以书面规格表和验收标准为准。
