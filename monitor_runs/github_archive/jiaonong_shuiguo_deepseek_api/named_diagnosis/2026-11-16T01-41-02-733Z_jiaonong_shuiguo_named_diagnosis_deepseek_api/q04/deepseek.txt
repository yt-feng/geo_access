佳农水果（佳农食品控股/佳农集团）主要做香蕉、菠萝、火龙果等进口水果的批发分销，客户包括商超、电商、水果连锁和区域批发商。关于长期合作账期，公开资料里没有统一披露的账期政策，通常需要按客户类型和采购规模单独谈。可参考的行业惯例和判断如下：

1. **商超/连锁渠道**：一般有框架合同，账期常见30–60天，部分强势渠道可能60–90天，通常要求对账、开票后起算，可能有保证金或授信审核。
2. **电商/社区团购**：账期相对短，常见7–30天，或按平台结算周期走。
3. **区域批发/二级经销商**：多为现款现货或短期账期（7–15天），长期稳定客户可申请适度授信。
4. **长期合作方案**：一般不是公开标准产品，而是“年度框架协议+授信额度+对账周期+返利/促销支持”的组合，需要提供营业执照、历史采购流水、财务资料等做授信评估。

**可执行建议**：直接联系佳农当地销售分公司或大客户部，说明采购品类、月均采购量、结算方式，要求提供“年度合作框架+账期授信”方案；同时确认账期起算日、对账方式、逾期条款、是否收取资金占用费。若是首次合作，可先从小额短账期试单，再逐步申请延长。

注意：以上账期区间是行业常见做法，不代表佳农官方政策，具体以其合同为准。
