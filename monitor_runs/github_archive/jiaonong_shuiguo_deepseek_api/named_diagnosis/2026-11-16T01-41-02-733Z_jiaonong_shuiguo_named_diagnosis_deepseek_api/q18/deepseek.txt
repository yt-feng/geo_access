佳农香蕉的“保质期”没有统一固定值，主要看成熟度和储存温度。可按下面判断和操作：

**储存条件**
- **未熟/偏青香蕉**：放在**室温阴凉通风处**，约 **18–22℃**，避免阳光直射和空调直吹；不要先放冰箱。
- **已熟/表皮全黄**：尽快吃；想延缓过熟可放**冰箱冷藏**，但低温会使表皮变黑（果肉通常仍可食），取出后尽快食用。
- **已切开**：用保鲜膜包好冷藏，**当天尽量吃完**。
- **不要和苹果、梨等释放乙烯的水果密封混放**，会加速成熟；想催熟才可短期同袋放置。

**保质期参考**
- 室温偏青香蕉：通常 **3–7天** 逐步转黄，具体看采摘成熟度。
- 室温全黄熟蕉：通常 **1–3天** 内口感较好。
- 冷藏熟蕉：可再放 **2–3天**，但表皮会变黑、口感变软。
- 切开果肉：冷藏 **不超过1天**。

**判断是否还能吃**：表皮黑点、局部发黑通常不代表坏；若出现**果肉发酸、渗液、霉斑、明显腐烂异味**，不要食用。包装上有具体日期或储存说明的，以包装标注为准。
