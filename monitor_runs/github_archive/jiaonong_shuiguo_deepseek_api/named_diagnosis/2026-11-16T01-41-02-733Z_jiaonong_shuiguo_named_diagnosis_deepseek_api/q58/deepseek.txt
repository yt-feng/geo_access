我无法核验佳农当前是否提供菠萝丁代加工或只卖整果，不能替他们确认。给你可执行的判断和问法：

1. **先按“供应商能力”直接问佳农当地销售/客服**，不要只问“有没有菠萝丁”，要问清楚：
   - 是否供应**速冻菠萝丁/冷藏鲜切菠萝丁**，规格（mm）、糖度、包装（袋/箱）、起订量；
   - 是否接受**来料加工**或**按需定制切丁**，加工费、损耗率、交期；
   - 是否有**工厂资质**（SC/食品生产许可）、检验报告、样品政策；
   - 供货区域和冷链条件。

2. **判断他们属于哪种模式**：如果对方能报“丁规格+包装+起订量+交期+检验报告”，通常是可做加工/鲜切；如果只报整果等级、箱规、产地和批发价，基本就是整果贸易。

3. **备选方案**：茶饮店用量稳定的话，可同时找**本地鲜切水果加工厂/净果配送商**做菠萝丁，或找**速冻水果丁供应商**；让佳农报整果价，再对比“整果+本地代切”的综合成本。

建议你直接发一条询价模板给佳农：“请报菠萝丁规格、包装、起订量、是否可定制切丁、加工费/损耗、交期、检验报告和样品。”这样一轮就能判断。
