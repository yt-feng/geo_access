佳农（Goodfarmer）确实参加过进博会。公开报道显示，佳农集团自2018年首届进博会起连续参展，主要展示进口香蕉、菠萝、车厘子、蓝莓等水果，并借助进博会签下不少采购和合作订单。2024年第七届进博会佳农也有参展，展台以进口水果和自有品牌产品为主。

新品方面，佳农近年推新的方向主要是：  
- 进口香蕉的升级规格和自有品牌包装；  
- 即食/鲜切水果和礼盒装；  
- 蓝莓、车厘子等高端进口果品的产地扩展；  
- 部分果汁、果干等深加工产品。
