我不能确认佳农当前是否供应冷冻菠萝丁，也不能凭空给规格，避免你按错误信息采购。

建议你按下面方式快速核验：

1. **直接问佳农官方渠道**  
   联系佳农官方客服/区域销售，明确问：  
   - 是否有“冷冻菠萝丁/速冻菠萝丁”这个SKU  
   - 是给茶饮/烘焙的B2B原料，还是只有鲜果  
   - 是否支持小批量试样和冷链配送

2. **要这组规格参数**  
   采购时让对方书面给：  
   - 丁的尺寸（如10×10×10mm等）  
   - 包装规格（如1kg/袋、10kg/箱）  
   - 是否IQF速冻、是否加糖/加水  
   - 解冻后出水率、可溶性固形物  
   - 保质期、储存温度、产地、批次检测报告

3. **茶饮店先做试样**  
   重点测：解冻后是否软烂、酸甜度、出汁/出水、与茶底搭配的香气，再决定是否上菜单。
