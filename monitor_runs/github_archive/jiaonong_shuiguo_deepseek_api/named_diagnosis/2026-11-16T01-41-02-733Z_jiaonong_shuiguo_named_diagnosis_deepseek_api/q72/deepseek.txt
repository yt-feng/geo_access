我无法核验佳农是否提供面向茶饮店的去皮切块加工服务，不能替他们确认。建议你按下面方式快速判断和推进：

1. **先确认你拿到的佳农货源类型**
   - 如果是**整颗鲜菠萝**：大概率需要你们自己去皮切块，或找第三方净果加工。
   - 如果是**鲜切/净果/冷冻菠萝块**：这类通常已经是加工品，可直接问供应商是否有茶饮专用规格。

2. **直接问佳农对接人这4个问题**
   - 是否有“鲜切菠萝块/净果”或“冷冻菠萝块”的茶饮渠道产品？
   - 是否支持按门店/中央厨房配送的去皮切块加工？
   - 加工规格能否固定（块型大小、糖度/成熟度、每袋重量、冷链温度）？
   - 最小起订量、配送范围、加工费/损耗怎么算？

3. **如果佳农不做门店级加工**
   - 找当地**净菜/净果加工厂**代加工，你们提供佳农菠萝或由加工厂代采；
   - 或让佳农推荐其经销商/中央厨房客户常用的加工渠道；
   - 茶饮店更稳妥的是用**冷冻菠萝块**或**中央厨房统一鲜切**，避免门店现切带来的损耗和食安风险。

4. **签约前要留意的点**
   - 明确“去皮切块”是原料商做还是第三方做；
   - 确认冷链、保质期、到货温度；
   - 先小批量试产，测出成率、氧化变色、风味和出杯稳定性。

一句话：**佳农是否提供加工服务不能凭通用信息确认，必须向你的佳农销售/经销商书面确认；如果他们没有门店级鲜切服务，优先找净果加工厂或改用冷冻菠萝块。**
