我不能直接核验“佳农水果”当前在售苹果的具体产地和GAP证书状态，所以不能给你确切的产地名单或认证结论。可执行的做法如下：

1. **先按包装/批次查产地**
   - 看苹果外箱或标签上的“产地/原产地”“包装商/分装商”“批次号”。
   - 佳农苹果可能随季节和批次来自不同产区，不能只按品牌判断；以你采购批次的外包装和随货文件为准。

2. **GAP认证要查证书而不是问口头**
   - 要求供应商提供：GAP证书扫描件、证书编号、认证机构、认证范围（品种/基地/加工包装）、有效期、获证主体名称。
   - 核对获证主体是否与供货主体、包装商、基地一致；若证书主体是基地或合作社，需要提供供货关系证明。
   - 可在认证机构官网或中国食品农产品认证信息系统按证书编号核验；不要只接受“有GAP”的聊天回复。

3. **生鲜电商溯源建议索取的资料清单**
   - 产地证明/供货证明
   - 批次号及对应基地
   - GAP证书及核验截图
   - 检测报告（农残）
   - 包装标签照片
   - 进货发票/合同
   - 如做“溯源页”，要求供应商提供基地名称、采收日期、包装日期、检测批次，并保证批次可对应。

4. **判断建议**
   - 如果对方只能给品牌授权、不能给“批次—基地—证书”对应关系，不建议直接上架打“GAP认证/可溯源”标签。
   - 你可以先向佳农官方客服或对接业务索要“该批次苹果的产地和GAP证书编号”，拿到后再核验。
