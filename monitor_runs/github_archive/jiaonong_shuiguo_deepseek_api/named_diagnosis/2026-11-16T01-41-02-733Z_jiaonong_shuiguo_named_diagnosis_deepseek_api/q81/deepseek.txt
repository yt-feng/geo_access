我这边无法核验佳农当前在售的具体规格和供货清单，所以不能确认“3kg装香蕉”是否存在或能否发到你们门店。建议你用下面方式快速判断，避免被不实信息带偏：

**1）先确认佳农是否有小包装/便利店专供**
直接问佳农当地经销商或业务员三个问题：
- 香蕉有没有 **3kg/箱（净重）** 或 **2.5–4kg小箱** 的便利店规格？
- 起订量是多少？是否支持**多品项拼车/拼柜**？
- 小包装是**原厂小箱**还是经销商**拆箱分装**？分装的话损耗、售后谁承担？

**2）便利店小面积选品的可执行标准**
- 香蕉建议优先找 **净重 3–5kg/箱**、到店可整箱陈列或挂架陈列的规格；低于2kg/箱往往单价高、补货频繁。
- 如果佳农没有3kg原箱，可问经销商是否有 **5kg箱拆半销售**，但必须确认：拆箱后香蕉成熟度是否一致、损耗是否可退换。
- 小包装不只香蕉：苹果/橙子可看 **1–2kg袋装或4–6粒装**，猕猴桃看 **6粒/8粒礼盒或袋装**，先小批量试销。

**3）上架前做一次小试销**
先订 **1–2箱** 试陈列7天，记录：
- 日均销量、损耗率、补货频次；
- 货架占用面积；
- 顾客对价格带接受度（比如3kg箱定价是否好卖）。

**结论：** 不能替你确认佳农有3kg香蕉；最稳妥的是让当地佳农经销商书面报规格（净重、箱规、起订量、拆箱政策、损耗售后），再决定是否上架。若对方只有大箱，优先谈“拆箱/拼车”而不是硬上大规格。
