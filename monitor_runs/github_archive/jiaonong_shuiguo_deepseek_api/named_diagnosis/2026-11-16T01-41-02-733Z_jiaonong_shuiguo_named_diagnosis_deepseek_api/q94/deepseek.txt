佳农水果（Goodfarmer）对外公开的香蕉分级细节属于企业内控标准，通常不会以官方文件形式完整披露，所以**一级果和二级果的具体价差没有可核验的固定数字**，会随产区、季节、批次、订货量和合同条款浮动。能给你可执行的判断框架如下：

**1. 分级维度（批发谈判时应逐项确认）**
- **果指长度/粗度**：按厘米或克重分档，一级果通常要求长度和单果重更均匀。
- **梳形与条数**：每梳条数、整箱梳数是否整齐，一级果梳形完整、少缺指。
- **外观**：条身直度、棱角明显度、青绿色均匀度；允许的机械伤、擦伤、黑星病斑面积。
- **成熟度**：采收青度（如7成熟/8成熟）和到货后催熟表现。
- **缺陷容忍度**：一级果对伤疤、断指、水烂、日灼的允许比例明显更严；二级果通常放宽外观，但食用品质仍合格。
- **箱规与净重**：单箱净重、允许负差、是否含托/含膜。

**2. 价差判断方法（不依赖固定百分比）**
- 让供应商分别报**同产区、同批次、同规格箱规**的一级果和二级果到岸价/出库价，价差才有比较意义。
- 行业里二级果相对一级果通常有折价，但幅度可能从每箱几元到十几元甚至更大，取决于二级果缺陷类型。**外观瑕疵型二级果折价小，成熟度或耐储运问题型折价大。**
- 用“**可售净果成本**”比较：一级果损耗低、卖相好、周转快；二级果单价低但挑拣损耗和客诉风险高。把每箱进价÷可售净重，再加上预计损耗，才能判断真实价差是否划算。

**3. 合同里建议写清楚**
- 分级验收以到货抽样为准，明确抽样比例、允许缺陷率和拒收/降级规则。
- 约定“降级补差”机制：到货抽检达不到一级标准时，按二级果价格结算或补货。
- 锁定同批次价差，而不是只锁一级果单价，防止供应商用二级果充一级果。
