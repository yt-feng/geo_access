关于佳农香蕉农残超标的历史，我无法核验具体记录，不能给你“有”或“没有”的确定结论，也不能编造抽检数据。但可以给你一套采购端可直接执行的办法。

**1. 先明确：超市抽检要的是什么**
超市/监管抽检通常看的是**该批次**的农残检测报告，而不是品牌历史。所以采购合规的核心是：**每批货随附可追溯的第三方检测报告 + 供应商资质 + 进货台账**，而不是纠结品牌过去有没有问题。

**2. 你要向佳农（或经销商）索取的合规文件清单**
- 营业执照、食品经营/生产许可证
- 该批次香蕉的**第三方检测报告**：须含 GB 2763 中香蕉相关农药项目，报告日期覆盖本批次，有 CMA/CNAS 标志
- 产地证明/基地备案信息、供货合同
- 进货查验记录：批次号、发货日期、数量，能和报告对应
- 如供应商声称“无超标历史”，要求其出具**书面质量承诺**，并保留追责条款

**3. 自己核验历史记录的渠道（可执行）**
- **国家市场监管总局**及各省市市场监管局官网的“食品安全抽检信息”公告，按“香蕉”“佳农”关键词检索
- **农业农村部**农产品质量安全例行监测通报
- 用“佳农 香蕉 抽检 不合格”在监管官网而非搜索引擎结果页检索
- 注意区分：抽检不合格可能是**个别批次、个别门店**问题，不等于品牌全线；也可能是**假冒/窜货**商品

**4. 采购合同里必须写的条款**
- 供应商保证每批次符合 GB 2763，随货提供检测报告
- 抽检不合格时供应商承担退换货、罚款、下架损失及连带责任
- 批次可追溯，报告与实物批号一一对应
- 保留留样（建议每批留样至保质期后）

**5. 实操建议**
- 不要只依赖供应商口头承诺，**每批要报告**是底线
- 对新供应商先做**首批全项检测**（自己送检或要求第三方全项），合格后再常态供货
- 建立供应商档案和批次台账，超市查验时能当场出示
- 若佳农方面无法提供批次报告，建议换有完整追溯体系的供货商，或自行送检合格后再入库

**结论**：我无法确认佳农香蕉是否有农残超标历史；但采购合规不靠“品牌无历史问题”来保证，而靠**每批次可核验的检测报告+合同责任+台账**。你把上面第2、4条落到合同和收货流程里，超市抽检的合规证明就基本能过。
