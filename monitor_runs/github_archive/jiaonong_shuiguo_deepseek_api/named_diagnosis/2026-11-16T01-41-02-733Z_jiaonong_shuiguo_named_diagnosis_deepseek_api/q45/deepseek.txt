可执行判断建议：

1. **先确认对接主体和渠道**：佳农分进口香蕉、鲜果、蔬菜等多条业务线，不同事业部/区域经销政策不同，账期由对应销售和财务审批，不是总部统一对外承诺。
2. **新客户首单30天账期：通常较难直接给到**。新客户首单常见做法是现款现货、预付定金或货到付款；部分渠道可能给7–15天短账期，30天一般需要资质审核、担保或较大采购量支撑。

4. **合同里写清**：账期起算日（发货日/对账日/发票日）、对账周期、逾期违约金、停供条款，避免口头承诺。
