公开资料里，佳农通常宣传“产地直采/直供”，但**具体到“产地直供比例”这种量化数字，外界很难核验**，不建议直接采信一个精确比例。能判断的是：佳农的香蕉业务确实以产地采购和供应链直采为主，属于其核心品类之一。

香蕉主要来源国通常包括：

- **厄瓜多尔**：佳农香蕉的重要来源地之一，佳农在厄瓜多尔有较强布局。
- **菲律宾**：传统香蕉出口大国，也是中国进口香蕉的重要来源。
- **越南**：近年对华香蕉出口增长明显。
- **柬埔寨**：也是中国进口香蕉来源之一。
- **哥伦比亚、哥斯达黎加、危地马拉**等中南美国家：常见香蕉出口国，部分会进入中国或国际市场。

如果你问的是“佳农香蕉具体从哪些国家采购”，最准确的方式是看具体产品包装上的原产国、批次标签，或向佳农官方客服/经销商确认；不同季节和批次来源会变化。
