### 1. 企业标准与国家标准（国标）的关系
- **国标（GB）**是强制性的最低门槛，比如《香蕉》（GB/T 19855-2005，注意该标准可能已更新）规定了香蕉的等级（优等品、一等品、合格品）、理化指标（如可溶性固形物、硬度）等。
- **企业标准（Q/）**必须**严于或至少不低于**国标，这是《标准化法》的基本要求。企业不能制定低于国标的标准。

### 2. 佳农香蕉的企业标准通常严于国标
作为国内头部香蕉品牌（主要从菲律宾、厄瓜多尔等进口），佳农的实际操作中，其企业标准通常在以下方面**高于国标**：
- **外观分级**：国标允许“果皮有轻微黑斑”，但佳农内部一般要求“果皮无斑点、无机械伤”，等级更严。
- **成熟度控制**：佳农有内部乙烯催熟和冷链参数标准，确保到店/零售时糖度、口感稳定，这远超国标仅对硬度和重量的基础要求。
- **农残与安全**：企业标准会参考进口国标准（如欧盟、日本）和国内绿色食品标准，在农残限量上比国标更严格（例如部分指标严于GB 2763）。
