**1. 佳农的业务模式决定了“能锁”**

**2. 谈判前，你必须明确的3个关键点**

- **锁价品类：** 是“去皮鲜果”还是“速冻菠萝丁/原汁”？速冻产品更好锁价（因为库存周期可控），鲜果锁价难度大。
- **锁价周期：** 建议不要直接问“全年锁价”，而是提出**“季度锁价+浮动上限”**模式。比如：每季度初锁定价格，但设定一个最高涨幅（如不超过上季度5%），这样双方风险都可控。
- **锁量底线：** 你必须接受“锁价就必须锁量”的条款。比如10吨/月，如果下月你没用完8吨，差额可能需要补差价或支付仓储费。

**3. 具体谈判话术（可直接用）**

> “我们目前月需求稳定在10吨，可以接受**季度锁价合同**。我们愿意支付合理的**预付款**或**保证金**来锁定供应，但需要贵司承诺：**在这个季度内，如果产地价格上涨，我们单价不超过合同价的X%；如果下跌，我们也按合同价执行。** 另外，请贵司明确：这个价格是否包含冷链物流到仓的费用？”

**4. 备选方案（防止谈崩）**
