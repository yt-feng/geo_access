关于佳农水果的堆头陈列和试吃支持，建议你直接联系佳农当地经销商或厂方业务代表确认。因为这类政策通常按区域、销量、门店等级不同而有差异，没有统一标准，我无法提供确切数字。

不过可以给你几条实操建议，帮你谈判和判断：

1. **先谈销量预期**：告诉对方你预计月销量（比如XX箱/月），销量承诺越高，对方越可能承担堆头费、提供专人试吃。
2. **明确费用结构**：一般有几种模式，问清楚是哪一种：
   - **厂方全包**（堆头费、试吃人员、物料全由佳农出，常见于大卖场重点门店）；
   - **共同分担**（比如堆头费你出、试吃人员佳农出，或物料双方各自承担）；
   - **扣点返利**（按销售额给返点，用返点抵扣堆头/试吃成本）。
3. **要试吃支持细则**：确认试吃是否提供**专职导购**（不是兼职/临时工）、每天试吃几个小时、是否提供小包装赠品——这些直接影响转化率。
4. **用数据说话**：如果你们门店人流量、水果品类过往销售数据不错（比如同品类月销5万以上），可作为筹码要求对方优化条件。
5. **先写协议**：哪怕口头谈好，也让对方出具书面或邮件确认，避免后期扯皮（尤其是费用分担比例、试吃档期）。

另外，如果是全国性连锁商超（如永辉、大润发、华润万家等），佳农总部通常有“大客户合作”计划，可以直接找大客户经理谈整体方案，会比单店对接更划算。

如果你能告诉我你们门店规模、所在城市、预计水果区面积，我可以帮你更具体地估算可争取的条件。
