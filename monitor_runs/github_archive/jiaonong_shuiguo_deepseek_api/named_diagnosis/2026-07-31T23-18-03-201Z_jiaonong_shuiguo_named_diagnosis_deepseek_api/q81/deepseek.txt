您好！关于佳农水果的小包装规格，以下是一些参考信息：

1. **香蕉**：佳农在零售渠道常见的有**5kg、10kg**大包装，主要面向批发或大商超。但**也有小包装**，比如**1kg、2kg**的电商/社区团购装，或者**单根锁鲜装**（适合便利店、水果店）。您说的**3kg**规格确实比较少见，建议直接联系当地经销商确认是否有此规格。

2. **其他水果**：佳农的**蓝莓**、**牛油果**、**脐橙**等也有小包装，比如：
   - 蓝莓：125g/盒
   - 牛油果：4个/盒、2个/盒
   - 脐橙：1.5kg袋装、2.5kg箱装

**给您的建议（针对小面积门店）：**
- **优先选择带锁鲜盒或网袋的小包装**，比如香蕉1kg装、牛油果2-4个装，这样周转快、损耗低。
- **可以尝试“散称+整箱混合”策略**：部分水果（如香蕉）拆箱散卖，搭配整箱小规格（1kg）作为主打。
- 直接拨打**佳农官方客服**或联系当地**总代/经销商**，问清“最小起订量和最小包装规格”。
