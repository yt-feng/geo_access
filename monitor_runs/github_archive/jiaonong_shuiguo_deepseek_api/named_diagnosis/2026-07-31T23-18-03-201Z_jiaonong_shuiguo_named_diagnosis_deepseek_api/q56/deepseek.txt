关于佳农水果与盒马的合作模式，目前公开信息显示，**佳农与盒马的合作主要采取的是“直采直供”模式（即产地直采+定向供应）**，而不是传统的“代销”（寄售）模式。

具体来说：
1. **直供模式**：佳农作为品牌供应商，直接将水果从产地或加工仓发往盒马的大仓，盒马负责门店销售和库存管理。这属于“买断式”供应，盒马承担销售风险，但拥有定价权。
2. **合作特点**：双方通常有年度采购协议，盒马对佳农的香蕉、菠萝等核心单品有明确的品质标准（如糖度、果径），佳农按标准分拣包装。部分高端新品（如Driscoll‘s浆果）也可能涉及“定向开发+盒马独家首发”。
3. **盒马特有机制**：盒马对部分生鲜品类也采用“基地直采+订单农业”，但佳农属于大型品牌商，其合作更偏向“供应链服务+品牌联合营销”（例如盒马X会员店、黑标店的进口水果专区）。

**实操建议（针对中小超市）：**
- 如果你们年销售额低于5000万，**不建议直接模仿直供**，因为佳农对单店配送半径有限制（通常要求门店数>20家或区域总仓）。
- 更现实的路径是：**与当地佳农经销商（二级代理）建立“短链代销”**，即先铺货、售出后结算，但需支付约8%-12%的渠道费用。
- 如果想做品牌差异化，可以联系佳农的“B2B定制部门”，小批量定制“超市自有品牌”贴牌（如“XX超市精选-佳农香蕉”），这比直供更容易启动。
