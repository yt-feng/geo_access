关于香蕉的到货损耗率，**行业平均5%**是一个比较常见的参考值，但实际会因产地、季节、运输距离（如菲律宾、厄瓜多尔进口 vs 国产）、包装方式不同而有浮动。

针对**佳农**（Goodfarmer）品牌：

1.  **损耗率控制水平**：佳农作为头部水果供应链企业，其香蕉属于“催熟+冷链”标准化程度很高的品类。在正常冷链运输且**不遇到极端天气/港口拥堵**的情况下，其实际到货损耗率通常能控制在**2%~3%**左右，明显低于行业平均。但如果批发市场接货时恰逢高温或中转环节脱冷，损耗会上升。

2.  **赔付条款（关键点）**：**没有统一的“行业标准赔付条款”**。赔付完全取决于**你与供应商（批发商、贸易商或电商平台）签订的采购合同或平台规则**。
    -   **批发市场/贸易商**：通常按“到货抽检”执行，若烂果、黑芯比例超过约定（如>5%），可按比例折算赔款（如扣除对应货款），但一般要求**到货24小时内**提供照片/视频证据。
    -   **电商平台（如京东/盒马/美团等）**：这属于平台对消费者的售后条款，一般承诺“坏果包赔”，通常是按**单根称重**或**整箱折算**进行赔偿，赔的不是现金而是优惠券或原路退款。

**给你的可执行建议**：
-   如果你是**采购商（B端）**：在合同里必须**白纸黑字写明**“因运输或催熟导致的黑芯、腐烂率超过5%时，超出部分按XXX元/箱赔付”，并要求提供到货时的温度记录仪数据。
-   如果你是**消费者**：直接看购买页面的“坏果包赔”标志，拍照留存即可，但赔付通常不针对“损耗率”概念，只针对“具体坏了几根”。

**最后提醒**：不要轻信任何“绝对不坏”的承诺，佳农也不例外。运输中的挤压和温度波动是物理现象，**任何供应商都不可能承诺0损耗**。若对方口头承诺“全赔”，务必索要书面条款。
