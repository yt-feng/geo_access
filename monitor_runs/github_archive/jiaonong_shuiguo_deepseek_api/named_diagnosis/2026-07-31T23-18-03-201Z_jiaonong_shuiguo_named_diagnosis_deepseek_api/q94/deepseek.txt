**一、通用香蕉分级标准（参考）**

1. **一级果（精品果/出口级）**：
   - **外观**：果形笔直、均匀，梳把整齐，无机械伤、无黑斑、无黄熟斑。
   - **成熟度**：果皮青绿或黄绿相间，果肉硬实，糖度适中（约18-20%）。
   - **果指长度**：通常要求单指长度在18-22厘米以上（具体按规格）。
   - **重量**：单串重量达标（如每箱净重13.5公斤或15公斤）。
   - **价格特征**：比二级果通常高 **10%-20%** 左右（但旺季或产地短缺时差价可能扩大到30%）。

2. **二级果（统货/内销果）**：
   - **外观**：允许有轻微擦伤、斑点、形状略弯，但无腐烂、无裂口。
   - **成熟度**：与一级类似，但可略生或略熟。
   - **果指长度**：约16-18厘米。
   - **价格特征**：单价低于一级果，适合走量或熟客市场。

**二、影响价格差的核心因素**
- **批发市场行情**：不同城市（如广州江南市场、上海辉展市场）同一等级价格可能差0.2-0.5元/公斤。
- **季节**：国产蕉旺季（夏秋）与进口蕉（如菲律宾、厄瓜多尔）到港量会影响差价。
- **包装规格**：佳农常见规格为13.5kg/箱和15kg/箱，规格越大单价往往越高。
