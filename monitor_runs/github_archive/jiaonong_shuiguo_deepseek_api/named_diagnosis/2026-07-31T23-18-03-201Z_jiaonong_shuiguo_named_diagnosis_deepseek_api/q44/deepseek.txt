关于佳农水果的香蕉是否曾出现农残超标的历史，我无法直接提供具体检测记录或官方通报，因为这类信息通常以国家市场监管总局、地方食药监部门的抽检公告为准，且可能涉及阶段性数据。

针对您的采购合规需求，建议您采取以下可执行操作：

1. **索要官方证明**  
   直接要求佳农或您的供应商提供**批次对应的《农产品质量安全检测报告》**（或第三方权威检测机构如SGS、华测检测的合格证明），并核对报告中的检测项目是否覆盖主要农残指标（如吡虫啉、百菌清、毒死蜱等）。

2. **核查公开抽检记录**  
   登录**国家市场监督管理总局官网**（或信用中国平台），搜索“佳农 香蕉”或“蕉类 农残”，查询近3年各地市场监管部门发布的食品抽检不合格公告。如无相关记录，说明暂无公开通报问题。

3. **合同约定兜底条款**  
   在采购合同中明确要求供应商承诺“符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》”，并约定若因农残超标导致抽检不合格，由供应商承担全部退货、赔偿及行政处罚责任。

4. **补充入库自检**  
   若采购量较大，可委托有CNAS资质的检测机构对每批次香蕉进行快速农残筛查（如胶体金法），费用约50-100元/样，确保入库前风险可控。

**特别提醒**：生鲜产品农残风险与产地、季节、仓储运输相关，即使历史无问题，也需坚持“批批索证、定期抽检”原则。若有具体年份或地域要求，可进一步细化查询范围。
