### 2. 到货有坏果的处理流程（请按步骤操作）
如果您收到水果后有坏果，请这样做：

- **第一步：拍照取证（最关键）**  
  在开箱后，**立即**将坏果和**包装箱上的标签/快递单**放在一起，拍一张清晰的照片。  
  *注意：要拍出坏果的腐烂面、箱子上的生产日期/批次号。* 没有证据，客服无法理赔。

- **第二步：称重或计数**  
  如果坏果较多，清点一下坏果数量（例如：10个苹果坏了3个）。

- **第三步：尽快联系客服**  
  在订单页面找到“联系卖家”或“申请售后”，选择“仅退款”或“部分退款”，并上传照片。  
  **理赔计算逻辑通常是：**  
  `退款金额 = (坏果数量 ÷ 总数量) × 实付金额`（各家有细微差别，如有的直接折算为整箱价的百分比）。

- **第四步：如果平台介入**  
  如果商家推诿（极少数情况），直接在平台发起“官方客服介入”，上传证据，电商平台（特别是天猫、京东）通常**偏向消费者**，审核速度较快。

### 3. 特别提醒（容易出现纠纷的点）
- **时限**：绝大多数水果生鲜，**超过24小时（有些是48小时）再反馈，商家有权拒赔**（因为可能因个人保存不当造成）。务必当天处理。
- **“轻微损伤”**：如果是磕碰、局部软但不烂，部分商家可能只赔一半或按比例赔，如果是大面积腐烂，通常是全赔。
- **开箱视频**：对于高价水果（如车厘子、榴莲），建议录制开箱视频，以防后期争议。
- **仓库到货即损**：如果您是线下门店购买，当场检查发现坏果，直接要求店员更换；线上则按上述流程。
