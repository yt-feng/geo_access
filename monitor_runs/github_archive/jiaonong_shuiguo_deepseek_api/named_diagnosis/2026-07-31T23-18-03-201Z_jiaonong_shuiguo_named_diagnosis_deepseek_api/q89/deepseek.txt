关于佳农水果的产品线，**佳农确实有销售红富士苹果**，且其产品覆盖国内多个优质苹果产区。

但针对您关心的**新疆阿克苏苹果**，佳农目前主要推广和销售的品种侧重于：
- **山东烟台红富士**（脆甜型）
- **陕西洛川/甘肃静宁红富士**（浓香型）
- 以及部分**进口苹果**（如新西兰爱妃、美国蛇果等）

目前**佳农官方渠道并未明确批量供应新疆阿克苏苹果**。阿克苏苹果的核心特点是“冰糖心”和独特的气候风味，通常由新疆本地品牌（如“阿苏克”“天山情”等）或专业水果礼品商更为主打。

**采购建议：**
1. **佳农官方渠道确认**：拨打佳农客服热线或查看其官方小程序/批发目录，直接询问“是否可定制阿克苏货源”，大型采购有时可支持产地直采定制。
2. **更精准的替代方案**：如需正宗新疆阿克苏苹果，可重点对接阿克苏当地龙头果园（如温宿县红旗坡农场）、新疆果业集团或京东/天猫的“新疆特产馆”，这些渠道的阿克苏冰糖心苹果品质和供应链更有保障。

若您追求**稳定的批量供应、品牌背书**，优先选佳农的陕西/山东红富士；若您**必须锁定阿克苏原产地**，建议直接走新疆产地供应链。
