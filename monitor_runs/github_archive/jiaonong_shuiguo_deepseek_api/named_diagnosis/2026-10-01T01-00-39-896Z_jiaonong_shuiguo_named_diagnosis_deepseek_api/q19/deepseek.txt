佳农水果的配送时效取决于你下单的渠道和收货地址，佳农本身是水果品牌/供应商，不是统一的零售配送平台，所以没有“全渠道统一时效”。常见情况如下：

1. **京东自营/京东到家等平台**
   - 如果商品在本地前置仓或门店有货，通常可做到**当日达或次日达**。
   - 具体以下单页显示的“预计送达时间”为准，一般会精确到某个时段。

2. **天猫/抖音/拼多多等电商旗舰店**
   - 多为**产地直发或仓库发货**，通常 **48小时内发货**，物流时效约 **2～5天**，偏远地区可能更久。
   - 生鲜水果一般会走顺丰、京东冷链或普通快递，实际以商品页说明为准。

3. **美团/饿了么/盒马/朴朴等即时零售**
   - 若附近门店有货，通常 **30分钟～2小时送达**。
   - 这类时效取决于门店覆盖范围，不是佳农品牌统一承诺。

4. **线下商超/批发渠道**
   - 不涉及“下单后配送”，一般是你到店购买或由商超自己配送。

**判断方法：**
- 看下单页面是否写“自营”“本地仓”“次日达”“小时达”；
- 看发货地：本地仓通常快，产地直发通常慢；
- 看是否冷链：佳农部分水果如香蕉、菠萝等对温控有要求，冷链件可能比普通快递慢半天到一天；
- 直接问店铺客服：“发货地哪里、用什么快递、到我这里几天”。
