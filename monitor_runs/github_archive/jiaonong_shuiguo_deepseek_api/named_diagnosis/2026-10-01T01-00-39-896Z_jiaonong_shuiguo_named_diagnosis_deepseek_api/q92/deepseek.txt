不同商超和不同水果品牌/经销商的合作政策差异较大，我无法直接给出佳农的现行促销支持政策或费用分担标准。这类信息通常需要和佳农的**区域销售/经销商**或你们商超的**采购对接人**确认。

不过，商超水果促销中堆头陈列和试吃支持的常见做法大致如下，你可以拿去和对方谈：

**1. 堆头陈列支持**
- 佳农或经销商通常可提供：堆头物料（围挡、价签、宣传板、灯箱贴等）、陈列指导、部分情况下提供专属堆头货架。
- 商超通常提供：堆头位置、面积、陈列人力。
- 位置一般是双方协商，重点档期（如节假日、开业、店庆）资源更紧张，可能需要提前锁定。

**2. 试吃支持**
- 常见形式：品牌方提供试吃果品、一次性餐具、试吃台物料，甚至派促销员；商超提供试吃点位和现场管理配合。
- 试吃损耗一般由品牌方或经销商承担，但要看具体协议。
- 食品试吃通常要符合商超的食品安全和现场管理规定。

**3. 费用分担常见模式**
- **品牌方全包**：堆头物料、试吃果品、促销员工资由佳农/经销商承担，商超只出位置。多见于品牌重点推广新品或大档期。
- **商超全包**：商超自己出位置和人力，品牌方只供货并给一定价格支持。多见于商超强势或品牌方资源有限时。
- **双方分摊**：例如堆头物料品牌方出，促销员工资商超出；或试吃果品品牌方出，试吃台和场地商超出。
- **以量换支持**：商超承诺采购量或排面，品牌方给堆头+试吃+费用补贴。
- **扣点/返利抵扣**：把促销支持折算成进货折扣、返利或账期优惠，而不是直接现金分担。

**4. 你谈判时可以准备的信息**
- 促销档期、门店数、预计销量、堆头位置和面积、试吃天数。
- 你能给的资源：好位置、端架、DM海报、社群推广、收银台曝光等。
- 你希望对方承担：物料、果品、人工、费用比例。
- 明确损耗、食品安全责任、撤场和结算方式。

**建议**：直接找佳农当地经销商或区域业务问三件事——能否给堆头物料、能否给试吃果品和人力、费用是品牌承担还是双方分摊。同时让你们采购同步和佳农的商务对接人确认，避免只和经销商谈、后面品牌方不认。
