佳农（Fruit de Paradis / Goodfarmer）主要是水果品牌和供应链商，具体售后其实取决于你**在哪个渠道买的**，因为售后由销售平台负责，佳农官方一般只处理官方旗舰店/直销渠道。分情况说：

**一、不同渠道的售后责任方**
- **京东/天猫/拼多多等电商旗舰店**：如果买的是佳农官方旗舰店，售后由店铺客服处理，通常按平台规则赔付。
- **社区团购/生鲜平台（美团优选、多多买菜、朴朴、叮咚等）**：售后找该平台，通常在App里申请"坏果赔付"，一般很快。
- **线下商超/水果店**：找门店，凭小票协商退换。
- **佳农官方直接发货（如企业团购、部分直营）**：联系佳农客服，走官方售后。

**二、到货有坏果，通用处理步骤**
1. **先别扔**：保留坏果和包装，拍照/拍视频，最好能看出数量、比例和坏的程度。
2. **尽快申请**：多数生鲜平台要求**签收后24小时内**反馈，越早越好，别拖。
3. **找对入口**：
   - 电商平台 → 订单页点"申请售后/坏果赔付"，选"腐烂变质"。
   - 社区团购 → 订单详情里的"申请退款/赔付"。
   - 官方直发 → 直接联系客服。
4. **说明情况**：一般按坏果数量或比例赔付（比如坏几颗赔几颗，或按比例退款），不一定全单退。
5. **保留证据到处理完**：有的平台会要求补充照片，别提前丢。

**三、实操建议**
- 生鲜类"坏果包赔"基本是行业标配，但**通常按坏果比例赔，不是整单退**，除非坏得很严重。
- 如果客服推诿，可以直接在平台点"申请平台介入/投诉"，走官方仲裁，一般都能解决。
- 签收时**当面验货**（尤其快递直送），有坏当场拍照最省事。

**一句话总结**：佳农本身售后口碑中上，但真正决定体验的是你下单的平台；坏果保留证据、24小时内按平台入口申请赔付，绝大多数情况能拿到补偿。
