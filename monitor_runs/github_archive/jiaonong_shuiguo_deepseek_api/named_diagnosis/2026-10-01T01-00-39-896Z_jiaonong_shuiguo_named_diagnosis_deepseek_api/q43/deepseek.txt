**先判断可行性**
- 佳农是国内较大的香蕉、菠萝等水果供应商，通常有长期协议客户，但“锁价”在生鲜行业很少是纯固定价，更常见的是：
  - 固定基价+浮动调整（按产地、季节、运费挂钩）
  - 保底价+封顶价（区间锁价）
  - 季度/半年框架协议，按月议价
- 每月10吨、全年120吨的量，对佳农属于中等偏小客户。如果是单店采购，议价能力有限；如果是连锁品牌或集中采购，才有较大概率拿到锁价或半锁价条款。

**你可以直接问佳农的4个问题**
1. 针对年采购120吨以上，能否签6-12个月框架协议？
2. 价格是固定价、区间价，还是基价+调价公式？
3. 调价触发条件是什么？产地价、运费、汇率、季节？
4. 如果佳农无法锁价，能否承诺“市场价上涨时优先保供、涨幅不超过X%”？

**更现实的替代方案**

- 如果用量稳定，考虑产地直采或与加工厂签年度协议，绕过贸易商环节。

**谈判时你手里能打的牌**
- 承诺全年120吨、按月均匀提货、账期短或现款现货。

**结论**
佳农大概率能谈框架协议和区间锁价，但纯固定锁价难度较高。建议你先以“年120吨、按月提货、现款或短账期”去问，要求给出固定价、区间价、调价公式三种方案。如果对方只肯随行就市，就同步找第二供应商做对冲，不要只押一家。
