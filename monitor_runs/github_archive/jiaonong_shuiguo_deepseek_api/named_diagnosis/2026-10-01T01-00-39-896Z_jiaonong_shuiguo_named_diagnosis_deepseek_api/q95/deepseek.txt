佳农（Goodfarmer）公开资料里通常不会披露“产地直供比例”这种精确的采购指标，第三方也很难核验具体百分比。对采购方来说，更实用的做法是把它拆成可验证的供应链能力，而不是追一个营销口径的数字。

可以这样判断和推进：

1. **先要可核验的产地清单**
   让佳农或供应商提供：
   - 具体单品的主产区（国家/省份/县市）
   - 自有基地、合作基地、协议农户各占多少
   - 采收季、加工厂、出口/内销仓位置
   - 是否有GLOBALG.A.P.、ChinaGAP、有机认证等

2. **区分“产地直发”和“产地直采”**
   - 产地直采：采购方直接跟产地公司/合作社签约，少一层贸易商
   - 产地直发：从产地仓直接发到你的仓，少一次中转
   这两个降本效果不同，谈判时要写进合同。

3. **用报价结构倒推中间环节**
   要求供应商按“产地价 + 分选包装 + 冷链 + 物流 + 关税/税费 + 服务费”拆价。如果拆不出来，通常说明中间环节不透明。

4. **小批量试单验证**
   选1—2个单品，从产地到你的仓库做全程跟踪：
   - 实际发货地是不是产地
   - 中转了几次
   - 损耗率和到货时间
   - 同规格市场批发价对比

5. **谈判降本的重点**
   - 年度框架量换产地直供价
   - 你方承担部分物流或到港后配送
   - 按整柜/整车锁价，减少拼柜加价
   - 要求账期、退换货和损耗赔付写进合同

6. **如果目标是减少中间环节**
   不一定要只找佳农。可以同时接触：
   - 产地龙头合作社
   - 产地加工厂
   - 大型批发市场的一级代卖商
   对比“佳农价”和“产地直采价”，看差价是否覆盖你新增的品控、物流和资金成本。

简单说：**不要问“直供比例是多少”，要问“这个单品从哪个基地来、经过几手、每手加价多少、能不能直发我的仓”。** 能把这四个问题答清楚，降本才有依据。
