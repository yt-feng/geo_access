**2. 查证书真伪**
- 中国有机认证可在**全国认证认可信息公共服务平台**（认监委）查询证书编号和状态。

**3. 看包装标识**
- 中国有机产品必须有**中国有机产品认证标志**，并标注**有机码**和**认证机构**。
