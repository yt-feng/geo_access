佳农水果的香蕉规格会随批次、产地（国产/进口）、包装形式和客户定制而变化，没有一个公开、固定、全渠道统一的“官方规格表”。如果你要做渠道分级或采购判断，建议按下面框架去核对，而不是直接套用某个固定数字。

## 一、常见规格划分维度

佳农香蕉通常按这几个维度分：

1. **按单根重量/大小**
   - 小果：单根约 100–130g
   - 中果：单根约 130–160g
   - 大果：单根约 160–200g
   - 特大果：单根约 200g 以上

2. **按每箱净重**
   - 常见有 4kg、5kg、8kg、10kg、13kg、15kg 等箱规
   - 进口蕉常见 13kg 左右/箱，国产蕉常见 5kg、8kg、10kg 等

3. **按每把/每串根数**
   - 4–6 根/把
   - 5–7 根/把
   - 6–8 根/把
   - 整串/整梳发货也有

4. **按成熟度/催熟阶段**
   - 青蕉（未催熟）
   - 微黄
   - 黄熟
   - 即食熟度

5. **按外观等级**
   - A级：果形整齐、无疤、无黑点、色泽一致
   - B级：轻微外观瑕疵，不影响食用
   - C级/加工级：外观差，适合加工、烘焙、餐饮

## 二、不同渠道适合的分级标准

### 1. 高端商超/精品超市
- 优先：A级大果或中果
- 单根重：150g 以上更常见
- 外观：无黑斑、无擦伤、果指饱满、把型整齐
- 熟度：到店后 2–4 天可售完的熟度
- 包装：小把装、托盘装、品牌袋装

### 2. 普通商超/社区超市
- 优先：A/B级中果
- 单根重：130–160g
- 外观：允许轻微瑕疵，但不能影响货架观感
- 熟度：青蕉或微黄到店，门店或配送中心催熟
- 包装：整箱、散装、把装均可

### 3. 水果连锁/生鲜电商
- 优先：A/B级中果
- 单根重：120–160g
- 外观：整齐度要求高，因为要拍照和标准化履约
- 熟度：按前置仓/门店销售速度定制，常见微黄或青蕉
- 包装：小规格把装、单根装、家庭装

### 4. 餐饮/烘焙/茶饮渠道
- 优先：B/C级或加工级
- 单根重：不严格，出肉率和稳定性更重要
- 外观：可接受黑点、擦伤、果形不齐
- 熟度：偏熟、高熟度，方便直接打泥、切片、烘焙
- 包装：大箱、冷冻香蕉泥、定制规格

### 5. 批发市场/流通渠道
- 优先：按箱规和单根重分级
- 常见：中果、大果整箱
- 外观：允许一定比例瑕疵
- 熟度：青蕉为主，便于运输和二次催熟
- 包装：标准箱、通风箱、纸箱

## 三、实操判断建议

如果你是采购或渠道运营，建议直接向佳农当地销售确认这 5 项：

1. **单根重量区间**
2. **每箱净重和根数**
3. **外观等级 A/B/C 的具体验收标准**
4. **到货熟度**
5. **是否支持渠道定制包装**

一句话总结：  
**佳农香蕉没有全网统一的固定规格，常见按单根重量、箱规、把型、熟度和外观等级分；高端渠道要 A 级中大果和好外观，电商要标准化中果，餐饮渠道可用 B/C 级或高熟度果。**
