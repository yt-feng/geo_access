佳农（Goodfarmer）的产地直供比例没有长期公开、可核验的统一数字，具体会因品类、年份和统计口径而变化。整体上，佳农属于国内头部水果进口与品牌运营商，核心品类高度依赖境外产区直采或产地合作，但“直供比例”若指从产地农场直接到佳农、跳过中间贸易商，通常不会低，但很难给出一个准确百分比。

香蕉方面，佳农的香蕉主要来自这些国家/地区：

- **菲律宾**：对华香蕉出口大国，也是佳农等中国进口商的重要来源。
- **厄瓜多尔**：全球重要香蕉出口国，常见于中国进口香蕉供应链。
- **越南**：近年对华香蕉出口增长明显，陆运和边贸优势较强。
- **柬埔寨**：也是中国进口香蕉来源之一。
- **老挝**：对华香蕉出口有一定规模。
- **哥伦比亚、哥斯达黎加、墨西哥等**：也会出现在国际香蕉供应链中，但在中国市场的日常占比通常不如菲律宾、越南、厄瓜多尔等突出。

如果你问的是“佳农自己宣传的产地直供”，通常会说与产地农场、合作社或包装厂合作，减少中间环节；但要判断比例高低，最好看其招股书、年报或官方公告里的分品类采购数据。仅凭公开宣传，不能可靠断定“高”或“不高”。
