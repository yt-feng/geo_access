我无法确认佳农水果香蕉是否有过农残超标的历史记录，也不应该凭印象给你下结论。这类信息必须以可核验的官方来源为准。下面是可执行的合规建议：

**1. 先明确超市抽检要什么**
一般超市/渠道要的是：
- 批次对应的检测报告（农残）
- 供货商资质（营业执照、食品经营许可证）
- 产地证明/进货凭证
- 必要时第三方检测报告（CMA/CNAS）

**2. 向佳农或经销商索取书面材料**
直接要求提供：
- 该批次的出厂检验报告或第三方检测报告
- 检测项目需覆盖香蕉常用农残（如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、咪鲜胺等，具体以国标和超市要求为准）
- 报告要有CMA/CNAS章、样品批次号、检测日期

**3. 自己送检最稳妥**
如果超市抽检压力大，采购方可对到货批次自行送检：
- 找有CMA/CNAS资质的第三方检测机构
- 按 GB 2763 食品中农药最大残留限量 检测
- 保留送检单、报告、批次对应记录

**4. 查历史记录的正确渠道**
- 国家市场监督管理总局、各省市场监管局官网的“食品抽检不合格通告”
- 农业农村部及地方农业农村部门的例行监测通报
- 用“佳农 香蕉 抽检 不合格”等关键词在官方平台检索，而不是只看自媒体

**5. 采购合同里加合规条款**
建议写明：
- 供方保证符合 GB 2763
- 每批提供合格检测报告
- 因农残问题导致下架、罚款、损失的赔偿责任
- 抽检不合格时的退换货和追溯条款
