我不能直接提供佳农水果的香蕉农残检测报告，因为这类报告属于企业针对具体批次出具的随货质检文件，我这边既没有留存也无法核验真伪。直接给你一份“报告”反而可能误导你的采购合规判断。

可以按下面路径拿到**可用于市场抽检应对**的有效报告：

**1. 向供应商索要（最直接）**
- 找佳农的对接业务/客服，明确要求提供：**该批次香蕉的农残检测报告**，最好是 **CNAS/CMA 资质检测机构**出具，报告上要有：样品名称、批号/生产日期、检测项目、限量标准、结论、报告编号、CMA/CNAS 章。
- 关键点：报告必须**对应你实际收货的批次**，不能只要一份“通用报告”。市场抽检是按批次追溯的，批次对不上等于没有。

**2. 核对报告是否“能用”**
- 检测机构有 **CMA**（必需，用于对外证明）；有 **CNAS** 更稳。
- 检测项目要覆盖香蕉常检农残，如：**吡虫啉、噻虫嗪、毒死蜱、氧乐果、克百威、甲拌磷、苯醚甲环唑、丙环唑、百菌清、多菌灵**等，并对照 **GB 2763** 的限量。
- 报告结论要明确“**符合 GB 2763 要求**”。

**3. 如果供应商给不出或只给旧报告**
- 要求**第三方抽检**：你自己或委托检测机构对该批次抽样送检，费用通常几百元/样，出 CMA 报告。
- 在采购合同里写明：**每批次随货提供对应农残检测报告，否则拒收/扣款**；并约定不合格的退换和赔偿。

**4. 市场抽检角度的提醒**
- 市场抽检以**现场抽样+法定检测**为准，供应商报告只能作为进货查验凭证，不能替代监管抽检。
- 你需要保留：**进货凭证、供应商资质、对应批次检测报告、进货台账**，这样抽检时能证明已履行查验义务。
