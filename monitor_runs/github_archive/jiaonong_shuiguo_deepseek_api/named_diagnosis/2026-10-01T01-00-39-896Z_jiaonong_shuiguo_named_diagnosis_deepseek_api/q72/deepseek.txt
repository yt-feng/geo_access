目前我无法核实佳农是否提供针对茶饮店的去皮切块代加工服务，这类信息需要以佳农官方最新政策为准。建议你按下面方式确认，避免采购后才发现加工不了：

1. **直接问佳农官方渠道**
   - 佳农官网/官方公众号的客服
   - 你所在区域的佳农销售或经销商
   - 当地水果批发市场里佳农代理商

   重点问清：
   - 是否提供菠萝去皮、切块、切丁服务
   - 是工厂加工还是仓库/档口加工
   - 加工后的规格（块大小、是否去芯、是否盐水处理）
   - 起订量、加工费、包装方式
   - 是否冷链配送、保质期多久
   - 能否稳定按你的门店用量供货

2. **如果佳农不直接做，常见替代方案**
   - 找当地净菜加工厂/中央厨房代加工
   - 找水果供应链公司买“鲜切菠萝块”
   - 自己在门店加工，但要做标准化：去皮、去眼、切块大小、盐水浸泡或糖渍时间、冷藏保存期限
   - 用冷冻菠萝块/菠萝丁，稳定性更高，但风味和口感要测试

3. **茶饮店使用建议**
   - 先小批量测试：佳农菠萝做出来的香气、酸甜度、纤维感、出汁率是否适合你的产品
   - 如果做果茶，建议测试“鲜切冷藏”和“冷冻”两种版本
   - 加工后如果当天用不完，要明确冷藏条件和废弃时间，避免食品安全风险

结论：**佳农能不能提供去皮切块加工，不能凭通用信息确定，必须问官方或区域经销商。** 如果他们要你做，优先确认规格、加工费、起订量、冷链和保质期这5项。
