佳农和盒马的公开合作信息里，能确认的是佳农是盒马的**水果直采/直供型供应商**——即佳农按盒马的标准供货，盒马采购后自行定价、自行销售、自负库存和损耗。至于具体合同是买断、联营扣点还是代销，属于未公开的商业条款，无法核实，不能替他们下结论。

不过对超市来说，关键不是"他们签的哪种"，而是**你要选哪种模式**。三种模式的实际区别：

| 模式 | 谁承担库存/损耗 | 结算方式 | 适合场景 |
|---|---|---|---|
| 直供/买断 | 超市 | 到货验收后付款 | 你有稳定客流、能消化批量、有冷链 |
| 联营/扣点 | 供应商（多半） | 按销售额扣点结算 | 你不想压货，但让出部分毛利 |
| 代销 | 供应商 | 卖出后结算，退未售 | 试新品、怕损耗 |

**能不能参考佳农-盒马？** 可以借鉴思路，但直接照搬意义不大，原因是：

1. **量级不对等**。盒马是万吨级采购，能拿到佳农的产地直发价和账期；中小超市单店采购量小，佳农这类品牌商通常只走经销商，未必直接对接单店。
2. **标准不对等**。盒马有完整的水果分级、糖度、农残检测标准，直供的前提是你有能力接货即验、当天上架。
3. **账期不对等**。直供往往要超市先款后货或短账期，压现金流。

**给你的可执行建议：**

- 先判断你店的水果**周转率**。周转快（叶菜类、应季爆品）→ 优先直供/产地直采，毛利高。
- 周转慢、怕损耗的品类（进口果、礼盒）→ 用联营扣点或代销，让供应商分担损耗。
- 想模仿盒马，先做一件小事：**挑1-2个单品做直采试点**（比如当季柑橘、苹果），从产地合作社或一级批发直采，跑通"验货标准+损耗率+毛利"数据，再决定要不要扩大。
- 别一上来就找佳农这类大品牌谈直供，先用本地合作社/产地代办起步，门槛低、灵活。

一句话：佳农-盒马是直供逻辑，但那是量级撑起来的；你店该用哪种，取决于你的周转速度和现金流，而不是照抄别人。
