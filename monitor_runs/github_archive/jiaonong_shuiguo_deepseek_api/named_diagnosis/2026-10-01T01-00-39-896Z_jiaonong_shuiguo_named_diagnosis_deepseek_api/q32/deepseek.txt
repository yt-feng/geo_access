如果你要核实，建议用以下方式判断：

1. **看原始出处**
   - 如果来自佳农官方新闻稿、年报、进博会/展会宣传材料，通常会写明“2023年”“2024年”或“截至某月”。
   - 如果只是媒体转述，可能省略年份，容易造成误读。

2. **看发布时间**
   - 若文章发布于2025年，说“去年”通常指2024年。
   - 若发布于2024年，说“去年”通常指2023年。
   - 但企业宣传里的“年进口量”有时指“上一产季”或“最近一个完整年度”，不一定等于自然年。

3. **找更权威来源**
   - 佳农官网、官方公众号、上市公司/母公司公告
   - 海关总署进口统计数据
   - 中国食品土畜进出口商会、水果行业协会报告
   - 进博会、链博会等官方展会新闻稿
