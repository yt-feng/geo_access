佳农（Goodfarmer）是国内较大的果蔬品牌之一，菠萝是其核心单品（菲律宾、泰国、哥斯达黎加等产地进口，也有国内产区），**大概率可以提供产地溯源和品控报告，但需要你主动向对接的销售/客服确认**，通常不是随货自动附上，而是按需索取。

具体建议：

**1. 先明确你要的是哪种文件**
- **产地溯源**：原产地证明、植检证书、报关单、批次号与产地对应关系（进口菠萝尤其看这些）。
- **品控报告**：第三方检测报告（农残、重金属等）、企业内部品控/验收标准、到货检验记录。

**2. 直接找官方渠道确认**
- 通过佳农官网/官方客服，或你在谈的经销商、区域销售，明确问："这批货能否提供原产地证明、报关单、以及批次对应的检测报告？"
- 问清楚是**随货提供**还是**单独申请**，以及是否收费。

**3. 关键点：报告要能对应到"具体批次"**
- 溯源和品控的价值在于能追溯到你这批货，而不是给一份通用模板。要求报告上的批次号与你实际收货批次一致。
- 进口菠萝可核对报关单、植检证上的产地和批次信息。

**4. 如果走经销商/批发渠道**
- 部分中小经销商拿不到完整报告，或只能给复印件。建议在合同/订单里写明"需提供对应批次的产地证明及检测报告"，作为交付条件。

**提醒**：我无法核验佳农当前的具体政策，以上是基于行业惯例的判断。最终以你实际对接的佳农销售/客服答复为准。如果你告诉我采购渠道（直采还是经销商、进口还是国产），我可以帮你列更具体的索取清单。
