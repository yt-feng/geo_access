佳农水果（佳农食品控股/佳农集团）主要做水果进出口和批发分销，客户以商超、电商、批发市场、餐饮等B端渠道为主。关于账期，公开渠道通常不会给出统一的“标准账期”，因为它属于一客一议的商务条款，会受客户类型、采购规模、合作历史、信用评估等影响。

**一般情况（行业惯例，非佳农官方统一政策）：**
- **新客户**：多数供应商会要求**现款现货、款到发货**，或先款后货；部分可能给很短账期（如7天、15天），但通常需要资质审核和担保。
- **老客户/大客户**：合作稳定后可能谈到**30天、45天、60天**，个别大型商超或平台可能更长（如月结30-60天），但需要合同约定。
- **账期不是自动给的**，需要经过信用评估、签订合同、有时还要保证金或担保。

**新客户能否申请账期：**
可以提出申请，但能否批下来取决于：
1. 你的采购规模和稳定性；
2. 公司资质、营业执照、过往交易记录；
3. 是否愿意提供担保、保证金或预付款比例；
4. 佳农内部对该客户的信用评级。

**建议做法：**
- 直接联系佳农官方销售或当地经销商，说明采购量、渠道和结算需求；
- 首次合作先按现款或短账期走，建立交易记录后再谈账期；
- 所有账期条件以**书面合同**为准，不要只依赖口头承诺。
