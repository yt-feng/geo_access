佳农（Goodfarmer）的水果业务里，苹果品类通常以进口和国产两条线为主，但具体到某一段时间在售的SKU会随产季和批次变化。可参考的常见情况如下：

1. **进口苹果常见品类**
   - **嘎啦（Gala）**：常见产地包括**新西兰、美国、智利、南非**等，具体看产季。
   - **红富士（Fuji）**：进口红富士常见产地包括**美国、智利、新西兰**等，但进口红富士的供应量和产季不如国产稳定。
   - 其他可能还有：**红玫瑰（Pacific Rose）、爱妃（Envy）、爵士（Jazz）、青苹果（Granny Smith）**等，具体以佳农当季报价单为准。

2. **关于你们要采购的进口嘎啦和红富士**
   - **进口嘎啦**：更常见的产地是**新西兰、美国、智利、南非**。其中新西兰嘎啦在产季内品质较受认可。
   - **进口红富士**：常见产地是**美国、智利、新西兰**，但进口红富士整体不如国产红富士普遍，采购时需确认当季是否有稳定货源。
   - 实际产地不能只看“佳农”品牌，必须看**原产国、果园/包装厂代码、批次标签**。同一品牌不同批次可能来自不同国家。

3. **采购建议**
   - 直接向佳农官方销售或授权经销商索取**当季进口苹果报价单和产地清单**。
   - 要求提供：**原产国、品种、规格（果径/克重）、包装、到港时间、检疫证、批次号**。
   - 如果你们要做稳定采购，建议同时确认**替代产地**，因为进口嘎啦和红富士受产季、海运、检疫影响较大，单一产地容易断供。
