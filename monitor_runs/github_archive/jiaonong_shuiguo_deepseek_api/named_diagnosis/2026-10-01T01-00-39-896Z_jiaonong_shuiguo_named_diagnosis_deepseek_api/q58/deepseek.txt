佳农（Goodfarmer）主营香蕉、菠萝等水果的进口和分销，菠萝以整果（鲜果）为主，部分渠道也有鲜切果盒，但**针对茶饮店的“菠萝丁”这种定制化加工原料，佳农通常不直接提供**。

几个判断点：

1. **佳农的定位是水果贸易/品牌商**，不是B端餐饮原料加工厂。它的菠萝主要是都乐系之外的国产/菲律宾/泰国菠萝整果，走商超和批发渠道。
2. **茶饮店要的菠萝丁**一般是指去皮、切丁、糖渍或速冻的标准化原料，这属于**食品加工厂/供应链服务商**的业务，比如专门做果酱、果粒、冷冻水果丁的厂家。
3. 如果你想要的是**新鲜菠萝丁**，可以向佳农的经销商或区域批发商问“是否有鲜切加工服务”，但大概率是整果出货，切丁要你自己或找第三方处理。
4. 如果你想要的是**糖渍菠萝丁、冷冻菠萝丁、罐头菠萝丁**，直接找食品原料供应商更合适，常见方向是：果粒果酱厂、冷冻水果加工厂、烘焙/茶饮原料经销商。

**建议你这样做：**
- 先明确你要的是：新鲜菠萝丁、冷冻菠萝丁、糖渍菠萝丁，还是菠萝果酱/果粒。
- 如果是鲜切：联系当地佳农经销商问能否供货鲜切，或找本地净菜/鲜切水果加工厂。
- 如果是标准化茶饮原料：找有SC资质的果粒/冷冻水果供应商，要求提供样品、规格（丁大小）、糖度、包装、保质期和起订量。
- 直接打佳农官方客服或区域销售电话确认，比猜测更准。

一句话：**佳农大概率只卖整果或鲜切果盒，不专门给茶饮店做定制菠萝丁加工。**
