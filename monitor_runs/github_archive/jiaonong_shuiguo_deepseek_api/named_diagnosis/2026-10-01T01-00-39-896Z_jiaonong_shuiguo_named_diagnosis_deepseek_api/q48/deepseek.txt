我无法核验佳农水果当前的官方销售政策，所以不能给出他们“1000吨以上客户具体优惠幅度”的准确条款。这类年采购量级通常要走**大客户/渠道客户合作谈判**，而不是公开标准价。

不过，如果你要和佳农或类似水果供应链企业谈“年采购1000吨以上”的长期合作，可以按下面这个框架去要政策，基本能判断对方能给到什么程度：

1. **价格政策**
   - 年度框架协议价：按全年预估量锁价，或按月/季度随行就市。
   - 阶梯返利：例如按实际完成量分档返利，1000吨、1500吨、2000吨分别对应不同返点。
   - 单品专项价：香蕉、菠萝、火龙果、苹果等不同品类毛利不同，优惠通常按单品谈。
   - 锁价与浮动机制：旺季保供价、淡季促销价、海运费/汇率波动是否可调。

2. **账期与资金政策**
   - 预付款比例、月结/批结账期。
   - 是否支持承兑、信用证、供应链金融。
   - 年度保证金或履约保证金要求。

3. **返利与奖励**
   - 年度采购返利：按实际采购吨数或金额返。
   - 新品推广奖励：主推单品达到约定销量给市场费用或返利。
   - 超额完成奖励：超过年度目标部分给额外返点。
   - 专供/定制包装支持。

4. **物流与交付**
   - 冷链干线运费补贴或到岸价。
   - 核心城市配送频率、起订量、损耗赔付标准。
   - 旺季优先分配货源。

5. **品质与售后**
   - 等级标准、糖度/规格/成熟度标准。
   - 到货不合格的扣款、补货、退货机制。
   - 损耗率上限和赔付方式。

6. **市场支持**
   - 陈列费、促销员、试吃、广告物料。
   - 区域保护或渠道授权。
   - 联合品牌推广费用。

7. **长期合作绑定**
   - 1-3年框架协议。
   - 年度保底量+超额阶梯。
   - 优先代理某品类或某区域。

如果你要直接去问佳农，建议不要只问“1000吨以上有什么优惠”，而是这样问：

> 我们计划年采购1000吨以上，想申请大客户年度框架合作。请提供：阶梯返利方案、账期政策、冷链到岸价、单品专供价、年度保底量对应的支持政策，以及是否可以签1-3年协议。

这样对方才会按大客户政策给你报价和方案。实际优惠幅度通常取决于：品类、规格、采购节奏、是否全年均衡提货、结算方式、运输距离、是否自有渠道。1000吨只是谈判门槛，不是统一折扣线。
