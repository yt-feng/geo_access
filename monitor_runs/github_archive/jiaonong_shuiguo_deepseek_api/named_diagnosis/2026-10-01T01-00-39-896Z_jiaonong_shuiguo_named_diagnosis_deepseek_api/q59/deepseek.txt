1. **标准类型**：佳农水果的香蕉执行的是**企业标准（企标）**，不是国标。  
   大型水果品牌通常会在国家标准（GB）基础上制定更细的企业内控标准，用于分级、成熟度、外观、农残、储运等要求。  
   但具体标准号（如 Q/xxx）会因公司主体、品类、包装规格不同而变化，需以包装箱/标签标注为准。

2. **比普通香蕉贵多少**：没有统一固定溢价，通常按**规格、渠道、产地、季节、是否品牌化**浮动。  
   - 常见情况：佳农香蕉比同渠道普通散装香蕉贵 **约 20%～50%**，部分精品超市/电商可达 **50%～100%**。  
   - 折算到每斤：普通香蕉若 3～5 元/斤，佳农常见在 **5～8 元/斤**左右；促销时可能接近普通价。  
   - 如果是进口/精品大果、礼盒装，单价会更高，不能直接和普通散装香蕉对比。

**判断建议**：  
看包装上的**执行标准号**：  
- 以 **GB** 开头：国家标准；  
- 以 **Q/** 开头：企业标准。  
佳农这类品牌香蕉通常标的是企标或企标+国标组合。
