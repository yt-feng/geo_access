**1. 直接找佳农官方渠道确认**

  2. 规格是**多少克/袋、每箱几袋、丁的尺寸（如10×10mm）**？
  3. 是**IQF单体速冻**还是整块冻后切丁？含糖/保水剂吗？

**2. 茶饮店选冷冻菠萝丁的关键判断点**
- **丁尺寸**：茶饮常用 8–12mm，太小易碎、太大影响出杯和吸管。
- **工艺**：优先 IQF 单体速冻，不结块、好分装。
- **配料表**：尽量选只有“菠萝”的，避免糖水、防腐剂影响配方。
- **解冻表现**：看是否大量出水、发软、纤维感过重。
- **包装**：常见 1kg/袋、10袋/箱，也有 500g 小袋；以实际报价为准。

- 本地冷冻水果加工厂：通常可定制丁尺寸和包装，起订量可能更低
- 冷冻菠萝丁常见产地：广东徐闻、海南、菲律宾等
