目前没有公开、统一的数据能直接给出“佳农水果香蕉”这一品牌在所有市场的抽检合格率。原因主要有两点：

1. **抽检数据按批次和地区分散**  
   市场监管部门（如国家市场监督管理总局、各省市市场监管局）会定期发布食品抽检通告，但通常按**批次、门店、产地、抽检项目**披露，不会专门汇总某个品牌某种水果的长期合格率。

2. **佳农是供应链品牌，不是单一种植主体**  
   佳农的香蕉来自多个产地和供应商，不同批次、不同季节、不同仓储运输条件下，抽检结果可能不同。因此即使有某几次抽检记录，也不能直接代表“佳农香蕉整体合格率”。

**可以这样判断和查询：**

- 到**国家市场监督管理总局**官网或“食品安全抽检公布结果查询系统”检索关键词“佳农”“香蕉”。
- 到**各省市市场监管局官网**检索当地抽检通告。
- 看具体通告中的**抽检项目**，香蕉常见风险项包括：  
  - 农药残留（如吡虫啉、噻虫嗪、苯醚甲环唑等）  
  - 重金属（如铅、镉）  
  - 保鲜剂/杀菌剂残留（如咪鲜胺等）
- 如果通告中写的是“合格”，说明该**批次**合格；如果写“不合格”，要看具体项目和限量标准。

**总体建议：**
- 不能简单说“佳农香蕉合格率很高”或“很低”，因为没有品牌维度的公开汇总数据。
- 正规商超、大型渠道销售的佳农香蕉通常有进货查验和批次检测，但消费者仍应关注具体批次抽检通告。
- 如果你要用于采购或合作评估，最可靠方式是：要求供应商提供**近期第三方检测报告**，并按批次核对农残和重金属项目。
