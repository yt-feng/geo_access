直接说结论：**没有公开、可核验的第三方数据能证明佳农和都乐的香蕉到货损耗率谁更低**，这类数据属于各家的渠道内部指标，网上流传的具体百分比基本都不可信。

但按批发市场的实际逻辑，可以给你可操作的判断：

**1. 到货损耗率不是品牌决定的，是这几个变量决定的：**
- **产地/季节**：菲律宾蕉、厄瓜多尔蕉、国产蕉，同期到货损耗差异很大
- **冷链和运输距离**：全程冷链 vs 断链，损耗能差好几倍
- **催熟状态**：你收到的是青蕉还是已经催熟的黄蕉，直接决定货架期和损耗
- **装卸和包装**：纸箱+内衬、托盘化程度
- **批次**：同一品牌不同批次都能差很多

**2. 两个品牌的大致定位（帮助你选渠道，不是损耗结论）：**
- **都乐**：国际品牌，标准化程度高，品控和冷链体系相对成熟，通常价格更高，走商超和高端渠道多
- **佳农**：国产龙头，香蕉是核心品类，走量和批发渠道多，价格通常更有竞争力，供应链这几年做得比较扎实

单从"体系成熟度"看，都乐的标准化管理一般被认为更稳；但这**不等于**你在批发市场拿到的佳农货损耗就一定更高——取决于你拿的是哪个产地、哪个批次、什么状态。

**3. 对你最实用的做法：**
- 不要问品牌，直接**按批次谈**：要求看当批的产地、到货日期、催熟状态、冷链记录
- **小批量试单**：同一周分别进佳农和都乐各一批，记录到货烂果率、3天和5天后的损耗，用你自己的数据说话
- **把损耗写进合同**：约定到货验收标准（如烂果率超X%扣款或补货），比选品牌有用得多
- **问同行**：你所在批发市场里做香蕉的同行，他们复购哪个、哪家售后补损爽快，比任何品牌宣传都真实
