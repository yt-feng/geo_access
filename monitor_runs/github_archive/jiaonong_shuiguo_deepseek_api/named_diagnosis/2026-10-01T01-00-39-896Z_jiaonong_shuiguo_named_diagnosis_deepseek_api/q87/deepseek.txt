佳农（Goodfarmer）的香蕉通常采用**乙烯（或乙烯利）人工催熟**，不是纯自然熟。原因是香蕉作为呼吸跃变型水果，商业供应链普遍在青果期采摘、冷链运输，到仓/到港后再集中催熟，以便商超按计划上架。

关于你商超要“控制催熟时间”，关键要区分两种做法：

1. **如果佳农到货已经是“催熟后黄蕉”**
   - 这属于供应商已完成催熟，你们主要做**后熟管理**，不是从头催熟。
   - 控制重点：温度、湿度、乙烯暴露、通风。
   - 一般建议：
     - 13–15℃：延缓后熟，适合短存；
     - 15–18℃：正常后熟推进；
     - 高于20℃：后熟明显加快，货架期缩短；
     - 低于12℃：易冷害，表皮发黑、果肉不熟。
   - 湿度：85%–90%较合适，过低易失水皱皮。
   - 已黄蕉不要和苹果、梨、番茄等释放乙烯的果蔬混放，否则会加速变黄变软。

2. **如果你们拿到的是佳农青蕉，需要自己催熟**
   - 商超一般不推荐自己用乙烯气体催熟，除非有专用催熟房。
   - 实操上更常见的是使用**乙烯利催熟**或专业催熟库乙烯熏蒸。
   - 参考节奏：
     - 乙烯利浸泡/喷洒后，通常 **3–6天** 转黄，取决于温度、浓度、蕉果成熟度和通风。
     - 专业乙烯熏蒸：在20–22℃、85%–90%湿度下，通常 **24–48小时** 熏蒸，之后 **2–4天** 转黄。
     - 温度越高转黄越快，但品质和货架期越差。
   - 若没有催熟房，建议直接采购佳农已催熟黄蕉，或让供应商按你们要求的到货成熟度供货。

**给商超的可执行建议：**
- 先向佳农业务确认：到货是“青蕉未催熟”“催熟中”还是“已催熟黄蕉”，这决定你们是否要自己催。
- 要求供应商提供：到货成熟度、催熟方式、催熟完成时间、建议存储温度。
- 如果你们要自己控时间，建议按目标上架日倒推：
  - 目标3天后黄：20–22℃、乙烯利/乙烯处理，转黄后降到15–16℃；
  - 目标5–7天后黄：18–20℃处理，转黄后13–15℃存放；
  - 已转黄后：尽快降到13–15℃，并单独存放，减少乙烯接触。
- 不要用“自然熟”来计划商超排面，因为自然熟时间不可控，且青蕉直接常温自然熟容易表皮先黑、果肉后熟，品相差。
