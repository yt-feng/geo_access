目前无法核实佳农水果是否针对餐饮渠道提供菠萝切片/切块的定制规格。建议你用以下方式快速确认：

1. **看佳农官方渠道**
   - 佳农官网/官方公众号/官方小程序里查“餐饮渠道”“B端产品”“鲜切水果”等栏目。
   - 直接找“餐饮/团餐/烘焙/茶饮”合作入口或客服。

2. **直接问关键问题**
   - 是否有餐饮专供菠萝？
   - 是否可做切片、切块、切丁？规格（厚度、尺寸、单袋克重）？
   - 是否冷冻/冷藏/常温？保质期和储存条件？
   - 起订量、配送范围、报价、是否贴牌？
   - 是否有SC/检疫/农残检测等资质？

3. **找当地经销商或批发渠道**
   - 佳农很多B端供货会走区域经销商、生鲜批发商、餐配供应链公司。
   - 问他们能不能按餐饮需求分切、分装。

4. **替代判断**
   - 如果佳农没有明确餐饮定制，通常可找专业鲜切水果工厂或餐配供应链做“菠萝切片/切块/切丁”代加工。
   - 茶饮、烘焙、团餐渠道常见的是冷冻菠萝丁、糖水菠萝块、鲜切菠萝片等。
