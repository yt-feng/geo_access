佳农香蕉（通常指佳农品牌销售的进口/国产香蕉）的保质期和储存条件，可以按“状态”来区分：

**1. 未熟/青香蕉**
- **储存条件**：常温、阴凉通风处，避免阳光直射和挤压。不要直接放冰箱冷藏，否则容易冻伤、发黑、无法正常成熟。
- **保质期**：常温下通常可放 **3～7天**，具体看气温和成熟度。夏天成熟快，冬天慢。
- **催熟方法**：想尽快吃，可和苹果/香蕉一起放进纸袋，常温放置1～3天。

**2. 已熟/黄香蕉**
- **储存条件**：常温阴凉处可放 **1～3天**；如果已经熟透，可放冰箱冷藏 **2～4天**，但表皮会变黑，果肉一般仍可食用。
- **注意**：冷藏后的香蕉口感会变软，适合直接吃或做奶昔、烘焙，不适合再长期存放。

**3. 切开后的香蕉**
- **储存条件**：必须密封冷藏，建议 **24小时内** 吃完。
- **防氧化**：可滴少量柠檬汁或包保鲜膜，减缓变黑。

**4. 冷冻保存**
- 熟透香蕉去皮后切段，密封冷冻，可保存 **1～2个月**，适合做冰沙、香蕉面包。

**简单判断**
- 青硬：常温放，别冷藏。
- 黄熟：尽快吃，吃不完冷藏1～3天。
- 黑斑多、发软：最好当天吃或冷冻。
- 有酒味、果肉发黑流汁：不建议吃。

如果你问的是具体某款佳农香蕉包装上的标注，最好以包装上的“保质期/储存条件”为准，因为不同批次、不同产地会有差异。
