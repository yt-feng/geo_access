佳农（Goodfarmer）并未在公开渠道披露统一的“到货损耗率”标准，行业里也没有一个固定数值。实际控制水平取决于品类、运输方式、季节和验收口径，大致可以参考：

- **香蕉**：到货损耗通常较高，行业里控制较好的水平约在 **3%–8%**，主要来自压伤、催熟不均、温控波动。
- **菠萝/凤梨**：相对耐储，控制较好约 **2%–5%**，主要是碰伤、黑心、腐烂。
- **火龙果、芒果、木瓜等热带水果**：约 **3%–8%**，对冷链和时效敏感。
- **苹果、梨、柑橘等温带水果**：约 **1%–3%**，耐储性强，损耗通常最低。
- **进口高端品类（如车厘子、蓝莓）**：约 **2%–6%**，但一旦冷链断链可能迅速放大。

需要说明的是，“到货损耗率”在不同公司口径不同：有的按件数、有的按重量、有的把外观降级也算损耗。因此即使是同一批货，不同验收标准下数字可能差一倍。

如果你是要做采购验收或供应商考核，建议直接向佳农区域业务或客服索取该品类的**验收标准（含损耗定义、抽样比例、扣重规则）**，这比问一个笼统的损耗率更有意义。如果你能告诉我具体品类和运输方式，我可以给一个更贴近实际的参考区间。
