佳农（佳农食品控股）对批发商这类B端客户，通常是**有专门对接的**，但具体形式取决于你的采购规模和合作渠道：

- **大批发商/连锁渠道/大型商超供应商**：一般会配专属客户经理或大区销售负责人，负责报价、账期、货源协调、售后等。
- **中小批发商**：可能由区域销售或经销商体系对接，不一定是一对一客户经理，更多是按区域或渠道分配业务员。
- **进口水果/单品线**：佳农部分品类走的是品牌方+经销商/代理商模式，你接触的可能不是佳农直属客户经理，而是其授权经销商的业务人员。

**建议你这样确认：**
1. 打佳农官网或官方客服电话，说明你是批发商、月采购量、品类和所在区域，直接问“有没有对应区域的B端客户经理”。
2. 如果你是从经销商拿货，直接问经销商能否升级为厂家直供或大客户对接。
3. 准备一个简单的采购量说明（月采购额、主销品类、结算方式），对方更容易判断是否给你配专属对接人。
