- 批发商代理一般分为：**独家代理**（该区域只授权一家）、**非独家代理**（多家共存）。佳农根据不同市场规模，很可能对一线城市或核心省份采用强保护，对地级市或外围市场可能放松保护以冲量。

**2. 判断是否会窜货，分别问对方几个关键问题**
你可以直接向佳农招商经理确认以下具体点，避免口头承诺模糊：
