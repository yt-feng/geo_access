**第一步：确认佳农是否支持一件代发（不要只听别人说）**

1. **直接询问官方渠道**：联系佳农的官网、官方客服，或通过“佳农食品”微信公众号/小程序找“商务合作”或“团购对接”入口，直接问“你们是否支持社区团购一件代发”。
2. **看他们的主营模式**：佳农主要给大型商超（如盒马、永辉、山姆）及批发市场供货，很多情况下是走大仓整车发货。如果对方告诉你“不支持一件代发”，通常是因为单件毛利覆盖不了分拣和快递成本，这种情况你可以：
   - **申请“起订量”**：比如按箱或按社区集中拼单，凑够一个最小起发量（如20件/30件），再让他们发快递。
   - **问是否有经销/分销渠道**：找本地有佳农代理权的批发商，他们往往会做一件代发，但价格可能稍高。

**第二步：物流成本怎么算（核心公式）**

一件代发的物流成本主要由以下三块构成：

- **包装成本**：水果易损，一般需要泡沫箱+冰袋/防震膜。佳农走代发单时包装费通常在 **3~8元/单**（看水果种类）。
- **快递费**：这取决于重量和地区。水果一般按续重计费，例如：
  - 1~3公斤：快递费约 **5~9元**（省内）或 **8~15元**（跨省）；
  - 3公斤以上每增加1公斤加收1~3元；
  - 偏远地区（新疆、西藏、内蒙等）不建议一件代发，运费会翻倍。
- **分拣/贴单服务费**：若对方工厂或仓库帮你打包贴单，通常会收取 **1~3元/单** 的服务费。

**最后的到手成本核算公式：**

> **单件总成本 = 进货价 + 包装费 + 快递费 + 服务费**
