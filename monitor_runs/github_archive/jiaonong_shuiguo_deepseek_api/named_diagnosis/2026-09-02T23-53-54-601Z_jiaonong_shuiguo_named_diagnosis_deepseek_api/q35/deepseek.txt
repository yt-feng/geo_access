---

### 1. **响应速度参考**
- **线上客服（电商平台/官方小程序）**：工作日白天咨询时，通常响应较快（如在5-15分钟内），但若遇到大促（如618、双11）或售后高峰期，等候时间可能延长。
- **电话客服**：一般接通速度较快（若非高峰时段），但高峰期需排队。
- **售后处理时效**：官方承诺**48小时内**给出处理结果（如退款、补发），但实际中，简单问题（如坏果退款）可能在24小时内解决；复杂问题（如涉及大批量或运输责任）可能需要更长时间。

---

### 2. **有问题该找谁？**

| 问题类型 | 优先联系渠道 | 备注 |
