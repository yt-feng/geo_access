关于“佳农水果”的售后政策，我可以基于常见水果电商行业的通用规则给你一个明确参考，但**具体处理方式请以你购买时的订单页面或客服回复为准**，因为不同渠道（比如天猫、京东、抖音、线下超市）的售后细则可能有差异。

**核心处理原则（绝大多数水果生鲜品牌都适用）：**
1.  **时效性要求**：通常需要在**签收后24小时内**（少数48小时）联系客服，并提供**坏果与快递单/外包装同框的照片**（证据必须清晰，能看到坏果的数量）。
2.  **赔付比例**：通常按**坏果比例**进行“按颗退款”或“部分退款”，而非整箱退款。除非全坏或拒收。
3.  **处理路径**：
    - 如果你是**线上旗舰店**买的（如天猫佳农旗舰店），直接联系店铺客服，发照片，客服会给你补偿方案（一般直接退现金到支付账户）。
    - 如果你是**第三方店铺或直播间**买的，优先联系该卖家客服，如果卖家不处理/拖延，可以申请平台介入（如淘宝的“小二介入”或京东的“纠纷单”）。
    - 如果你是**线下超市**购买的，需持有购物小票，去服务台咨询现场退换。

**针对你的问题，直接给出的实操建议：**

**第一步：立刻拍照取证**
- 不要扔掉坏果和包装箱。
- 将**所有坏果集中摆放**，旁边放上**当天的报纸或显示日期的手机时钟**，以及**快递单号面单**，拍一张清晰合照。
- 如果是腐烂渗液，拆开包装后立即拍内部状态。

**第二步：选对联系渠道（速度最快）**
- 优先打商品详情页显示的**官方售后电话**，或者直接用购物App的聊天联系（保留文字记录，避免电话无凭证）。说明“我收到XX（比如牛油果/蓝莓），有X个坏果，图片已发”，要求按比例赔偿。

**第三步：如果客服冷处理或拒绝**
- 向平台投诉。例如淘宝搜“我的淘宝-我的订单-申请售后-我要投诉商家”，京东用“申请售后-纠纷单”，选择“腐烂变质”，系统通常会自动开启快速退款通道（生鲜类有绿色通道，一般证据充足会秒退）。

**特别提醒：**
- 佳农作为大品牌，针对**整箱全烂**或**严重发货质量**（如发霉、异物）的情况，通常会**极速退款**，甚至“仅退款”（不用退货，因为生鲜退回没意义），但**部分腐烂**绝大多数是按个退钱。
- 如果你买的进口水果（如佳农的智利车厘子、泰国榴莲），若收货时**表皮轻微皱皮但果肉正常**，那不属坏果，无法理赔；只有**果肉变质、发黑出水**才算。

**总结给你一句话判断：**
如果坏果不严重，拍好照直接找卖家，按颗退钱；如果卖家拖延，直接走“平台假一赔三/生鲜绿色通道”投诉，2小时内基本解决。

如果你现在的坏果已经超过24小时甚至放干了，那就比较难理赔了，建议以后签收时尽量当面开箱验货（尤其是快递员在场时）。若你现在正在处理，可以告诉我具体购买渠道（比如是佳农官方旗舰店还是其他），我可以帮你推断更具体的处理话术。
