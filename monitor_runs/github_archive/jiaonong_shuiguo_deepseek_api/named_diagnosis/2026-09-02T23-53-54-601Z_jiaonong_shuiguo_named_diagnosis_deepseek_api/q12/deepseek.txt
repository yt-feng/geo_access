关于佳农水果（Goodfarmer）香蕉的具体在售规格和分级标准，由于产品线会随季节、客户需求和渠道策略调整，**我无法提供最新且绝对准确的官方分级表**。但根据佳农作为国内头部香蕉进口商和分销商的通行做法，以及行业内普遍采用的参考标准，可以为您整理出以下分类逻辑，供您参考和核验：

**一、 常见规格（按重量/包装箱）**

佳农香蕉在国内市场主要通过整箱（件）销售，具体规格以箱为单位，常见的有：

1.  **标准出口箱（18kg左右）**：这是大宗批发和商超主力规格，内部按把或按指数分装。
2.  **小包装/电商专供箱（5kg、8kg等）**：针对社区团购、线上生鲜平台或精品超市，通常为净重小箱，方便直接上架。
3.  **礼盒装**：节假日或高端渠道（如企业福利、精品水果店）常见，单箱净重在10kg-12kg，外观品相要求更高。

**二、 内部品质分级（决定果肉与耐储性）**

佳农在产地（如菲律宾、厄瓜多尔或国内海南基地）会进行预分级，重点考察：

*   **果指长度**：通常按每把果指的长度分级，如**长指（>22cm）**、中长指（18-22cm）作为高等级，短指多用于加工或低价渠道。
*   **饱满度（成熟度）**：农业上常用“成熟度百分比”表示，**7-8成熟**（果皮绿但棱角不分明）是长途运输的黄金采收标准，**9成熟**则用于本地短途或即食渠道。
*   **外观瑕疵**：黑斑、碰压伤、日灼疤的数量是硬性剔除标准。

**三、 渠道适配的分级逻辑（重点）**

不同渠道对香蕉的需求差异巨大，佳农会从同一批货源中做分拣：

| 渠道类型 | 核心诉求 | 对应的佳农产品偏好 |
| :--- | :--- | :--- |
| **大型商超（大润发、沃尔玛等）** | 货架期长、外观整齐、价格敏感度中等 | 首选**标准箱（18kg）**，**绿色但果皮饱满**，需具备7-10天催熟后的货架寿命。要求**果指均匀、无机械伤**。 |
| **电商/社区团购（美团、拼多多）** | 单件重量轻、适合快递、用户赔付率低 | 偏好**小规格（5-10kg）**，通常选择**中长指**最佳，必须**避免过熟**（因快递易压伤）。 |
| **水果生鲜连锁（百果园、鲜丰等）** | 强调自然熟、口感辨识度 | 倾向于**进口高甜度品种**（如佳农的特定A级果），可能要求**带把或单指包装**，分级标准更严，**果指长度和饱满度需达到头部10%级别**。 |
| **餐饮/烘焙/果汁店** | 成本优先、果肉利用率高 | 接受**二级果**（有轻微斑点但果肉无损），规格多为**大箱混装**，追求性价比。 |

**四、 给您的实操建议**

如果您是想**采购或批发**，最准确的信息来源是：

1.  **拨打佳农官方销售热线**或联系其**区域批发经理**，获取当季《产品质量规格书》（通常包含果指长度、净重、跌撞测试标准）。
2.  **查看箱体标签**：佳农正规产品外包装会印有**果品代码**（如PLU码，以4或5开头的进口蕉为A级）、生产批次号和产地。

**重要提示**：请勿轻信非官方渠道流传的“标准分级表”，因为**不同产季（雨季/旱季）的香蕉成熟速度和外观差异极大**，佳农会动态调整。若您需要用于合同签订，务必在询价时索取**正式的验收标准文件**。
