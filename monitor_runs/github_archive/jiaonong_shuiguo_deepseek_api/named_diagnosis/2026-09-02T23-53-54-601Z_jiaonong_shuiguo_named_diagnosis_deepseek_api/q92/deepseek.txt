关于佳农水果在商超促销中的堆头陈列和试吃支持，这属于供应商与零售商之间的**联合生意计划（JBP）**范畴。通常这类合作是可行的，但具体能否执行以及费用分担方式，主要取决于**门店的定位、佳农当地的经销商团队政策以及你所在商超的谈判筹码**。

为了帮你拿到最好的方案，我整理了几个关键点和谈判话术，供你参考：

**一、 佳农能提供什么支持？**
佳农作为头部水果品牌，通常具备以下市场费用或资源：

1.  **堆头陈列支持**：一般会提供**广告物料**（如KT板、插牌、价格签、生动化装饰）以及**特殊陈列费用（货架费/堆头费）**。佳农有固定的“年度陈列协议”预算，但他们倾向于把费用投在**重点门店（A类店）**或**大型促销档期**（如国庆、春节、中秋）。
2.  **试吃支持**：**促销员（导购）派驻**、**试吃果切损耗补贴**。厂家会承担促销员工资，并承担部分因切开试吃造成的损耗（通常以“赠品”形式冲抵，或者直接给门店报损耗额度）。

**二、 费用分担的模式（谈判筹码）**
费用分担没有固定比例，一般是“市场费用转移”。建议按以下三种方式去谈，从易到难：

-   **模式A（最推荐，最省钱）：费用补贴式**
    佳农直接支付给你商超一笔“促销服务费”或“堆头费”，购买黄金位置（如入口第一堆、生鲜区主通道）。这里关键是看佳农的年度预算是否到位。如果佳农压价，你可以强调“**配合整档促销海报、推头位置选在客流最旺处、保证堆头陈列量要求**”。

-   **模式B（双赢，降低库存风险）：**补贴+进货返利**
    如果佳农现阶段不愿出太多现金堆头费，你可以要求他们在**进货价上给予特价支持（比如满100件返5件）**，你把这部分返利直接作为堆头位和试吃损耗的补贴，这属于“羊毛出在羊身上”，对采购最有利。

-   **模式C（要求前置，锁定损耗）：**试吃费用实报实销**
    试吃支持方面，建议明确要求佳农提供：
    1. **派专人试吃**（人员费用由厂家承担）。
    2. **试吃果切损耗**：要求佳农提供“**试吃损耗补损**”。即每场试吃，佳农免费赠送多少个果切盒或等量商品作为补损。**绝不能让门店自己承担这个损耗**，否则毛利会被吃掉。

**三、 谈判战术建议（话术）**

当佳农的销售人员告诉你“我们总部今年没有这笔堆头预算”时，你可以这样回应：

> “王经理，我们这次搞的是**全门店大促**，这个位置在收银台必经之路，日均客流五千。如果你只提供物料不放堆头费，那我只能把这个位置给隔壁那个愿意出一半堆头费的品牌了。你看，我们能不能这样操作：堆头费按标准场地费打八折，但你得额外**支持2个专职试吃员和一个果切损耗的补损点数**。咱们签个协议，如果这档期你的销量冲到XX万，我们再给你加个二次返点。”

**四、 风险提示与注意事项**

1.  **签订书面协议**：所有谈妥的堆头位置、陈列面、促销员人数、试吃损耗补损量、费用金额及支付方式，**白纸黑字写进《促销服务协议》**，防止口头承诺落空。
2.  **明确费用票种**：向佳农收取的堆头费、促销服务费，要明确是否能开具**增值税专用发票（6%或3%现代服务）**，不要只给收据，否则财务不好做账。
3.  **价格保护**：谈促销的时候，要佳农保证促销期间**进货价锁定**且不高于周边其他卖场，防止他们给别的超市更低价导致你门店客流被分流。

**总结建议：**
如果你现在处于谈判初期，优先争取**“付费堆头 + 免费物料 + 厂家导购 + 试吃损耗全补”**。如果对方只愿意提供物料和人员，坚决要求他们承担试吃损耗，这是底线。一旦涉及价格和费用，建议直接拿到书面报价及总部的批准函再签约。
