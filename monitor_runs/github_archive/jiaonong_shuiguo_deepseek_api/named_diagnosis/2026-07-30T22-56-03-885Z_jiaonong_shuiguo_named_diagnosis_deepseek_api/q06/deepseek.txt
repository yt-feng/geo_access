佳农作为一家专注于水果供应链的企业，确实具备为餐饮商家提供稳定菠萝原料的能力。不过，为了确保你拿到的规格符合茶饮店需求，建议你在对接时明确以下关键信息：

**佳农能提供的常见菠萝规格（普通商家易懂）：**

1. **品种**：主要供应的是**巴厘菠萝**（也称“香水菠萝”或“Smooth Cayenne”），果肉黄白色，酸度适中，甜度高，适合做茶饮。
2. **重量**：标准单果重量为 **1.5-2.0 kg /个**（约3-4斤），个头均匀，方便人工处理。
3. **成熟度**：可采购 **7-8成熟（黄熟期）** 的菠萝，此时果肉已变黄，糖度约12-14%，适合直接榨汁或切块冷藏；也可选**6-7成熟（青熟期）**，需再放置2-3天软熟。
4. **包装**：通常为**箱装**，每箱净重 **10 kg /15 kg**（约5-10个菠萝），纸箱内衬泡沫网袋或塑料托盘，降低运输损耗。
5. **供应稳定性**：佳农在国内（主要产自海南、广东）和东南亚（菲律宾、泰国）都有种植基地，可实现**全年不断供**（热带产区轮作，避开国内菠萝淡季）。

---

**给你的3个建议（直接可操作）：**

1. **明确用途沟通**：对接佳农销售时，直接说：“我要做茶饮原料，需要**黄熟期、单果1.5-2斤、糖度12%以上**的菠萝”，他们会优先按照这个标准分拣批次。
2. **索取样品试单**：让佳农先寄送**3-5箱**小批量样品（通常付快递费即可），实际测试去皮、切块和打汁后的出汁率、口感是否符合你饮品配方。
3. **签署规格书**：正式合作时，让业务员出具**《菠萝供货规格确认单》**，写明“成熟度、单果重量、果径（如18-22cm）、包装方式、允许的瑕疵率（如≤5%有轻微压伤）”。这是以后对账、退换货的依据。

如果后续遇到对方说“统一规格不拆卖”，你可以要求他们提供**专供餐饮渠道的“B端定制包装”**（例如整箱15kg装，每箱内附成熟度卡片），佳农对于茶饮连锁客户通常有拆包服务。
