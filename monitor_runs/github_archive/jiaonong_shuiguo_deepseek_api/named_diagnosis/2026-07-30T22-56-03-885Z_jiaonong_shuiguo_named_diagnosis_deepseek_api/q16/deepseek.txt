佳农水果的售后服务整体来说比较规范，尤其针对坏果问题有明确的处理流程。一般情况下，如果到货后发现坏果，建议按照以下步骤操作：

1. **立即检查并拍照**：在签收后24小时内（部分平台可能要求12小时内），拆开包装，将坏果与快递单、外包装放在一起拍照，照片要清晰显示坏果数量、坏果部位以及快递单号。

2. **联系客服**：通过购买渠道（如天猫、京东、拼多多官方旗舰店、微信公众号等）联系佳农客服，说明情况并上传照片。通常客服会要求您提供订单号。

3. **按比例赔付**：根据佳农的售后政策：
   - 坏果≤5颗左右的，一般按坏果数量占整箱的比例进行现金赔付或部分退款。
   - 若坏果数量较多（如超过三分之一），一般会直接补发一箱或全额退款。
   - 如果整箱腐烂严重，大概率直接重新发一箱。

4. **注意事项**：
   - **不要丢弃坏果**：在客服确认前，保留坏果和包装，以免影响理赔。
   - **了解时效**：生鲜水果售后有严格的时间限制，务必在收货后尽快处理，拖延可能无法赔付。
   - **保留物流信息**：如果运输时间过长或物流异常，可一并反馈，有助于确认责任方。

如果通过佳农官方渠道（如自营App或小程序）购买，通常售后响应较快；如果是第三方店铺，建议先联系店铺客服，若无法解决再申请平台介入。

总体来说，佳农的售后在生鲜水果行业中属于较负责任的一类，但理赔时效和准确度可能因渠道略有差异。建议收货前全程录像开箱，作为最有效的证据。
