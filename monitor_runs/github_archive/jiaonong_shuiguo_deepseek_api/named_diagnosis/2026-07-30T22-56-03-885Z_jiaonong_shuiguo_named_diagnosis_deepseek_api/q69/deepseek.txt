目前佳农（Goodfarmer）确实有针对餐饮渠道的菠萝定制规格，主要包括不同形式的预处理产品以满足餐饮客户需求。常见的定制规格包括：

- **切片菠萝**：通常按厚度切片（如5mm或8mm），包装规格如1kg/袋或2kg/袋，适合用于披萨、沙拉或甜品摆盘。
- **菠萝块**：切成均匀的小块（如2cm×2cm），规格多为2.5kg或5kg袋装，适用于炒饭、果饮或烘焙馅料。
- **去芯菠萝圈**：整圈去芯，常用于装饰或烤制。

此外，佳农也提供**整果**（按重量或数量）和**速冻菠萝**（切块或切片后速冻）选项，餐饮渠道可联系其销售或客服咨询具体定制服务（如指定尺寸、包装形式或标签）。建议访问佳农官网或联系当地经销商确认区域供应情况。
