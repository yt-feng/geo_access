费用分担建议这样判断和谈判：

1. **堆头陈列**
   - 陈列位由商超提供，品牌方通常承担堆头物料和部分陈列费。
   - 可谈：品牌方出物料+陈列费50%，商超出位置和人力；或按进货量达到约定金额由品牌方全额承担物料。
   - 若商超收“堆头费/陈列费”，一般由供应商承担或双方按比例分摊，写进促销协议。

2. **试吃支持**
   - 样品：通常品牌方承担试吃样品，商超承担场地和基础水电。
   - 试吃台/物料：品牌方提供。
   - 试吃员：可品牌方派员，或商超员工执行、品牌方按天补贴人工。
   - 损耗和食品安全责任要在协议中明确。

3. **费用分担常见模式**
   - 品牌方承担：堆头物料、试吃样品、试吃台、促销赠品；
   - 商超承担：陈列位置、场地、基础人力、收银和动线支持；
   - 现金费用：陈列费/进场费按50:50或按销量阶梯分摊；
   - 以销量对赌：达到约定销量后品牌方返还部分陈列费。

4. **你需要向佳农确认的清单**
   - 是否支持你所在门店系统和区域；
   - 档期和最低进货量；
   - 堆头物料清单和到店时间；
   - 试吃样品数量、试吃员是否到场；
   - 陈列费/试吃费分担比例；
   - 是否需要签促销协议、谁承担食品安全和损耗。

建议你先让佳农区域业务出一份“促销支持确认单”，列明物料、样品、人力、费用分摊和销量目标，再报商超采购审批。没有书面确认前，不要对外承诺费用分担。
