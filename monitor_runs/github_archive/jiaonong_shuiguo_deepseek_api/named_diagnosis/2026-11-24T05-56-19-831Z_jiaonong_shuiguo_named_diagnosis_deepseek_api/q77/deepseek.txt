佳农香蕉要做到“具体农场”级溯源，取决于批次和供货模式，不能一概而论；GLOBALG.A.P.证书通常可以按供应商/包装厂/农场主体提供，但能否覆盖你这一批货，需要证书范围与批次对应核验。

**1）能否溯源到具体农场**
- 佳农进口香蕉多来自菲律宾、厄瓜多尔、越南等产地，通常采用“产地+包装厂/加工厂+批次号”的追溯体系。
- 商超要求“具体农场”时，需要看该批次是否来自佳农自有/合作庄园，或是否由多个小农场拼柜。拼柜模式下，单一批次可能对应多个农场，完整农场级追溯难度较大；自有庄园或专供基地则更容易做到。
- 可执行判断：让佳农提供该批次的**追溯码/批次号对应的农场清单、包装厂注册号、采收日期、出口商信息**，并核对箱标、唛头、报关单、卫生证书是否一致。

**2）GLOBALG.A.P.证书**
- 可以要求佳农提供**GLOBALG.A.P. IFA证书**，重点核验：证书持有人、认证范围（作物/产品）、覆盖的农场/生产站点、证书编号、有效期、认证机构。
- 证书常以“生产者组织/出口商/包装厂”为主体，不一定逐农场列名；若商超要求“具体农场证书”，需确认证书附件或GLOBALG.A.P.数据库中的生产站点是否包含该农场。
- 可执行判断：拿到证书后，在GLOBALG.A.P.官网数据库按证书编号或持有人核验有效性，并比对证书覆盖范围与批次农场是否一致。

**建议向佳农索取的资料清单：**
1. 该批次箱标/唛头照片、批次号、追溯码；
2. 农场清单及对应GLOBALG.A.P.证书编号；
3. GLOBALG.A.P. IFA证书及附件/生产站点列表；
4. 包装厂注册信息、出口国植物检疫证书、报关单；
5. 佳农出具的批次追溯说明（含农场—包装厂—批次对应关系）。

结论：**“具体农场级”溯源和GLOBALG.A.P.证书都可能提供，但必须按批次核验证书覆盖范围；拼柜批次不一定能做到单一农场对应，采购合同中应明确“农场级追溯+GLOBALG.A.P.覆盖该农场”的验收条件。**
