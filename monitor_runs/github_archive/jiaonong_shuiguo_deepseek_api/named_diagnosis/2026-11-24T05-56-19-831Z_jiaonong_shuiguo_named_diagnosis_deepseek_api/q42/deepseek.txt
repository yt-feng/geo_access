从公开可核验的信息看，没有权威数据能直接比较“佳农”和“都乐”香蕉的到货损耗率，我不能给你编一个具体数字。但对批发市场来说，可以按下面方法判断和压损耗。

**结论先说：**
- 两个品牌都是国内香蕉主流供应链品牌，单看品牌名不能断定谁损耗更低。
- 香蕉到货损耗主要取决于：产地/加工厂、催熟度（青蕉还是黄蕉）、冷链和运输距离、季节、你所在市场温湿度、到货后周转速度。
- 对你这种批发场景，建议用“同批次小规模对比 + 到货验收指标”来定，而不是听品牌口碑。

**可执行的对比方法：**
1. 同一周、同一市场、同一季节，各进一小批佳农和都乐，尽量同规格、同催熟度、同运输距离。
2. 记录到货时：青蕉比例、机械伤、果指脱落、水烂/霉变、果柄断裂、箱内温湿度。
3. 记录到货后第1/2/3/5天损耗：烂果率、掉把率、黄熟过快比例、可售率。
4. 连续做3—4批，取平均，才有判断价值。
5. 重点看“到货可售率”和“货架期”，不要只看到货烂果率。

**验收时建议卡这几个点：**
- 到货温度是否稳定，车厢有无冷凝水。
- 青蕉硬度和催熟均匀度，避免“外黄内青”或“到货即黄”。
- 箱内是否有压伤、闷伤、水烂。
- 果柄是否完整，掉把多会直接影响批发卖相。
- 同批次箱与箱之间差异大不大，差异大说明加工和冷链不稳定。

**采购建议：**
- 先各拿1—2板做对照，不要一次压大货。
- 要求供应商明确催熟度、发货温度、运输时长和到货责任。
- 合同里约定到货损耗上限和索赔方式，比如烂果率、掉把率超标怎么扣款。
- 夏季和冬季分开测，香蕉损耗季节差异很大。
