佳农（佳农食品控股/Goodfarmer）对商超、生鲜连锁、电商、餐饮等B端客户通常会有商务账期政策，但是否给“长期合作账期”取决于客户类型、采购规模、合作年限、信用资质和合同条款，并不存在公开统一的标准方案。可执行判断如下：

1. **一般规律**  
   - 大型商超/连锁客户：常见有月结、票到若干天、按账期结算等，具体天数由合同约定。  
   - 中小客户或新客户：多为现款、预付款或短账期，长期稳定后才可能申请延长。  
   - 经销/批发客户：通常结合授信额度、履约记录和担保条件谈账期。

2. **你要确认的关键点**  
   - 是否为首单/新客户，还是已有长期采购记录；  
   - 月采购额、品类（进口香蕉、菠萝、火龙果等不同品类政策可能不同）；  
   - 结算方式（月结/票到/货到）、账期天数、授信额度；  
   - 是否需要保证金、担保或合同锁定采购量。
