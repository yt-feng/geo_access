佳农水果（Goodfarmer）的香蕉，我不能给你“有没有农残超标历史”的确定性结论——这类抽检不合格记录分散在各地市场监管部门公告里，我无法逐条核验，也不能编造出处。但可以给你**可执行的合规采购做法**：

**1. 先分清你要的“合规证明”是什么**
超市抽检通常认这几类，向佳农或供应商索取：
- **承诺达标合格证**（食用农产品，现行《农产品质量安全法》要求开具）
- **第三方检测报告**：重点看是否覆盖 GB 2763 中香蕉的农残项目（吡虫啉、噻虫嗪、苯醚甲环唑、百菌清、多菌灵等常见项），报告需有 CMA/CNAS 资质、样品批次与你的到货批次对应、日期在有效期内
- **产地/基地信息**：香蕉多来自海南、云南、广西或进口（菲律宾、厄瓜多尔、越南等），进口需报关单+入境货物检验检疫证明

**2. 自行核验历史记录的正规渠道**
- **国家市场监督管理总局**“食品安全抽检监测信息”及各省市市场监管局抽检公告，按“香蕉”“佳农”关键词检索
- **海关总署**进出口食品不合格信息
- 用企业全称（上海佳农食品等）而非品牌名检索更准
注意：某批次不合格不等于品牌系统性超标，但采购方有权要求供应商对历史不合格批次作说明。

**3. 合同与到货控制（最实用）**
- 合同写明：农残符合 GB 2763，随货提供合格证+本批次检测报告，抽检不合格由供方承担退换及罚款损失
- 每批留样并记录批次号、产地、检测报告编号
- 对新供应商或高风险产地做**入仓前自检**（快检或送第三方），成本远低于超市抽检不合格的下架损失

**4. 判断建议**
如果佳农能提供**批次对应的 CMA 检测报告+合格证**，一般可满足超市索证索票要求；若只能给通用报告或拒绝批次对应，建议要求补充检测或换供应商。历史超标记录需你通过上述官方渠道按企业全称核查，我无法替你确认“有”或“没有”。
