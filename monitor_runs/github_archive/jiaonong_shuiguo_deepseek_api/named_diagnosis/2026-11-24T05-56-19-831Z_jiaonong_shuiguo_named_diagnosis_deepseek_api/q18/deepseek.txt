佳农香蕉的“保质期”要看状态：**未催熟的青蕉**和**已熟黄蕉**差别很大，且包装标签若标注了具体日期，以标签为准。

可执行判断：

1. **储存温度**
   - **13～15℃、阴凉通风**最适合延缓后熟。
   - 不要放冰箱冷藏：低于约12℃易冷害，果皮变黑、果肉变差。
   - 也不要暴晒、闷在密闭塑料袋里。

2. **青蕉/未熟蕉**
   - 室温阴凉处可放数天到一周左右，视采摘成熟度和气温而定。
   - 想慢熟：保持通风、避免和苹果/梨等催熟水果放一起。
   - 想快熟：和苹果放同一纸袋，室温下催熟。

3. **黄熟蕉**
   - 已熟后室温通常**2～4天**内口感较好；夏季高温更快，可能1～2天就过熟。
   - 表皮出现少量黑点仍可吃；若果肉软烂、有酒味/酸味则不要食用。
   - 吃不完可剥皮后冷冻保存，用于做奶昔；不建议带皮冷藏。

4. **已切开**
   - 密封冷藏，尽量**当天吃完**；最多不建议超过24小时。

5. **判断是否变质**
   - 可吃：表皮黑点、局部轻微磕碰但果肉正常。
   - 不建议吃：果肉大面积软烂、流汁、霉点、酸败或酒味明显。

总结：**青蕉阴凉通风13～15℃慢熟；黄蕉室温尽快吃，别冷藏；以包装日期和果肉状态为准。**
