大概率有，但要看你是“已合作批发商”还是“潜在批发商”，对接方式不一样：

1. **已有合作关系的批发商**
   - 通常会有**销售/客户经理**或**区域销售负责人**对接，负责订单、价格、账期、售后和促销支持。
   - 如果你现在只是通过经销商或市场档口拿货，不一定有佳农直属客户经理；需要先确认你的供货链路是不是佳农直供。

2. **潜在批发商/新客户**
   - 一般先由**区域销售**或**渠道招商**接触，评估采购量、品类、配送区域、结算方式后，再分配客户经理。
   - 大批发商、连锁渠道、区域代理更容易安排专人对接；小批量试单通常先由销售助理或区域业务跟进。

**建议你直接这样问对方，判断最快：**
- “我们做批发，月采购量大概X吨/柜，主要品类是香蕉/进口水果，能否安排区域客户经理对接？”
- “你们对批发客户是直供还是走经销商？客户经理是按区域还是按渠道划分？”
- “首批合作需要什么资质和起订量？账期和售后由谁负责？”

**注意：** 我无法核验佳农当前具体组织架构和人员安排，不能保证每个区域都有专属客户经理。最稳妥的是通过佳农官方客服或官网联系区域销售，说明你的批发规模，要求转接对应渠道负责人。
