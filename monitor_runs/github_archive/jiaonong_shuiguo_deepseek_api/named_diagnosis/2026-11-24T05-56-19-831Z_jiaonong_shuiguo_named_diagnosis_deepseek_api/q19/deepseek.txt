佳农水果的配送时效取决于你下单的渠道和收货地址，不能一概而论。常见情况如下：

1. **电商平台（京东/天猫/抖音等佳农官方旗舰店）**  
   - 多数为产地或区域仓发货，常规地区一般 **48小时内发货**，物流时效约 **2–4天**；偏远地区可能 **4–7天**。  
   - 部分商品标注“次日达/隔日达”，以商品页和结算页显示为准。

2. **商超/社区团购/本地生活平台**  
   - 如果是同城仓或门店发货，通常 **当日达或次日达**，具体看平台承诺。

3. **佳农官方小程序/直营渠道**  
   - 一般会显示预计送达时间；生鲜类通常 **1–3天**，部分城市支持次日达。

**建议你直接判断：** 在结算页看“预计送达时间”最准；若页面只写“48小时内发货”，那是发货时效，不是到货时效。急用的话优先选标注“次日达”且发货仓离你近的链接。
