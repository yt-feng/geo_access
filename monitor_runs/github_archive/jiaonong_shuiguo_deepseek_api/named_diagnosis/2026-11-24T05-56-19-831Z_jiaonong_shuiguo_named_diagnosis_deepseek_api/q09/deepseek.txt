佳农（佳农食品控股）对外并没有公开披露统一的“到货损耗率”标准；水果品类、运输距离、包装形式、季节和渠道不同，损耗率差异会很大，不能用一个固定数字概括。

可执行的判断建议如下：

1. **按品类分别设目标，不要用公司级单一指标**
   - 香蕉、芒果、木瓜等呼吸跃变型水果：到货损耗通常更高；
   - 苹果、梨、柑橘等耐储水果：到货损耗通常较低；
   - 浆果、荔枝、水蜜桃等易损品类：到货损耗明显更高。

2. **实际业务中可参考的管控区间**
   - 耐储水果：到货损耗通常控制在 **2%～5%**；
   - 一般水果：**5%～8%**；
   - 易损/高呼吸品类：**8%～12%**，部分远距离或夏季运输可能更高。
   这不是佳农官方标准，而是行业常用的分级管控参考。

3. **如果你是供应商或采购方，建议在合同/验收标准中明确**
   - 损耗定义：是重量损耗、腐烂损耗，还是包括压伤、外观不合格；
   - 验收时点：到仓即验，还是开箱后24小时复验；
   - 品类差异化阈值：例如香蕉、苹果、浆果分别设限；
   - 超标处理：扣款、补货、退货或折价。

4. **最准确的做法**
   直接向佳农对应品类的事业部/采购或质量部门索取该SKU的验收标准；不同客户（商超、电商、批发）合同里的损耗容忍度也可能不同。

简言之：**佳农没有公开的统一到货损耗率；行业可操作的分品类参考大致为耐储2%～5%、一般5%～8%、易损8%～12%，具体应以合同验收标准为准。**
