佳农（Goodfarmer）对外公开披露中，我没有可核验的“产地直供比例”统一数字，不能给你一个准确百分比。不同品类、季节、产区、渠道口径差异很大，采购谈判时也不宜直接引用未核实数据。

对你们“减少中间环节、降低成本”，可执行建议如下：

1. **不要先要一个总比例，按单品/产区要直供证明**
   - 要求供应商按SKU提供：果园/合作社/包装厂名称、产区、采收期、是否自有基地、是否产地包装直发。
   - 看合同流和货权流：合同主体是否产地公司/合作社；发票、检疫证、包装厂编码是否一致。
   - 看物流：是否产地仓直发你们DC，还是经销地批发市场/二级贸易商中转。

2. **用试单验证直供成色**
   - 选2—3个单品做小批量直采试单，对比“佳农直供价”与当地批发市场同规格价格、损耗率、到货时效。
   - 要求报价拆分明细：果价、包装、短驳、冷链、损耗、账期资金成本、服务费。中间环节通常藏在“综合服务费/代采费”里。

3. **谈判结构**
   - 阶梯量价+产地直发DC；明确包装厂、规格、糖度/农残标准。
   - 约定“产地证明/追溯码/包装厂备案号”随货，缺失可扣款。
   - 账期与价格联动：现结换更低产地价，或缩短账期换返点。
   - 对季节性单品采用“产地代采+你们指定物流”模式，砍掉销地中转。

4. **替代与比价**
   - 同一产区找2—3家产地合作社/包装厂直接询价，作为佳农报价的锚点。
   - 若佳农某单品直供比例不高，可保留其作为稳定供应+标准品来源，同时用产地直采做成本对标。

5. **可向佳农直接书面询问的口径**
   - “请提供近12个月我司拟采购SKU中，产地包装厂直发我司DC的货量占比及对应产区清单。”
   - “请说明各SKU的合同主体、货权转移节点和物流中转节点。”
   - 这样拿到的是可审计口径，而不是宣传口径。

总结：佳农产地直供比例没有可靠公开数字；采购上应以**单品级溯源+物流节点+试单比价**来判断和压降中间环节，而不是依赖一个总体比例。
