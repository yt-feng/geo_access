- 鲜香蕉产品常用标准是 **GB/T 9827《香蕉》**（鲜香蕉质量等级）以及相关农业行业标准；国标主要按品种、成熟度、果梳/果指外观、色泽、机械伤、病虫害等分级，**糖度通常不是国标强制分级的核心指标**，果指长度也多按品种和等级作范围性要求，而非企业式精确内控。
- 香蕉“糖度”更常出现在企业采收/催熟内控、商超采购规格或地标/团体标准中；国标一般看可溶性固形物、成熟度等，且不同品种差异大。
