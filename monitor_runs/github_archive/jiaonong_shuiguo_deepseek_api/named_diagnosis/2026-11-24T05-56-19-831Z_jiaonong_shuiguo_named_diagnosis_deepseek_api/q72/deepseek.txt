佳农（佳农食品）主营业务是香蕉、菠萝等水果的贸易与分销，通常以整果或标准鲜果规格出货，并不以“为茶饮店做去皮切块代加工”作为常规服务对外提供。是否能做定制加工，取决于你对接的具体渠道和采购量：

**可执行的判断路径：**

1. **先问你的供货渠道**：如果你是通过佳农经销商/区域批发商拿货，直接问对方“能否供去皮切块菠萝（鲜切）”，而不是问“佳农能不能加工”。鲜切水果涉及冷链和保质期，通常由当地鲜切工厂或经销商完成，而非品牌方统一提供。

2. **确认采购量门槛**：即使佳农体系内有鲜切业务，一般也会要求较高的日/周用量才愿意做定制规格。茶饮店单店用量通常达不到，可能需要通过当地鲜切供应商采购。

3. **替代方案更现实**：
   - 向当地**鲜切水果加工厂**采购去皮切块菠萝，指定用佳农菠萝原料；
   - 或采购佳农整果，在门店/中央厨房自行去皮切块（需控制损耗和食品安全）；
   - 也可考虑**冷冻菠萝块/菠萝果酱**等标准化原料，稳定性更好。

**结论**：不要默认佳农提供去皮切块加工服务，先向你的实际供货商确认；若没有，走“指定佳农原料+本地鲜切工厂代加工”的路径更可行。
