佳农（Goodfarmer）商超渠道的香蕉通常是**乙烯催熟**，不是“树上自然熟”。商业香蕉一般在青硬状态采收，到配送中心/催熟库后用乙烯气体（或乙烯利释放乙烯）在温湿度受控条件下统一催熟，这样才能批次稳定、货架期可控。

对你们商超控制催熟时间，可按以下执行判断：

1. **先确认到货状态**
   - 青硬蕉：需要催熟。
   - 微黄/转色蕉：可能已在产地或配送中心做过前段催熟，门店只需后熟，不要再按全青蕉催。

2. **催熟方式**
   - 催熟库常用 **乙烯气体浓度约100–150 ppm**，温度 **15–18℃**，湿度 **90–95%**，处理 **24–48小时**；之后通风并转至 **13–15℃** 后熟。
   - 若用乙烯利，按产品标签和供应商方案执行，不要自行加量。

3. **时间控制建议**
   - 目标3–4天转黄：乙烯处理24小时左右，后熟温度16–18℃。
   - 目标5–7天转黄：乙烯处理12–24小时，后熟温度14–16℃，并加强通风。
   - 夏季/库温偏高时缩短处理时间；冬季/库温偏低时适当延长，但避免低于13℃造成冷害。

4. **关键控制点**
   - 不要与苹果、梨等释放乙烯的水果混放，除非有意催熟。
   - 催熟后必须通风排乙烯，否则转色不均、货架期缩短。
   - 每天检查转色度、果指软硬和梅花点，按“绿→微黄→黄→黄带点”分级转架。
   - 商超门店不建议长期存放催熟库，最好由配送中心统一催熟到微黄/半黄再配送。

5. **向佳农索取**
   - 具体要求供应商提供该批次**催熟工艺说明、乙烯处理浓度/时长、出库转色度、建议后熟温度和货架期**。不同产地、季节和批次会有差异，以佳农书面参数为准。

结论：**佳农商超香蕉一般走乙烯催熟工艺；你们应按到货转色度决定是否二次催熟，乙烯处理控制在12–48小时，后熟13–18℃，并务必通风。**
