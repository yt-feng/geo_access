佳农水果的配送覆盖范围和冷链收费，取决于你下单的具体渠道（佳农官方小程序/京东/天猫/线下商超供货等），不同渠道差异很大，我不能凭空给你一个“覆盖城市清单”。

可执行判断方法：

1. **先确认购买渠道**
   - 如果你是在佳农官方小程序/APP下单：页面通常会在结算前校验地址，能选到你的县/区就说明可送，选不到就是不在配送范围。
   - 如果是京东/天猫等平台：看商品页的“配送至”和“运费说明”，以平台实时校验为准。

2. **县城门店能否送到**
   - “送到县城门店”一般不是佳农直送，而是平台物流送到门店地址，或门店自己进货。
   - 判断标准：结算页能否选择该门店地址并生成运费；不能选就是不到。
   - 如果是门店进货，需要联系当地经销商或佳农区域销售，不走零售冷链。

3. **冷链物流收费**
   - 零售端通常不是单独“冷链费”，而是运费规则：满额包邮、按件/按重量计费、偏远地区加价。
   - 具体金额以结算页显示为准；页面没显示冷链附加费，一般就按普通运费规则走。
   - 商家直发大货冷链，需要按城市、重量、温区、时效向佳农或承运商询价，没有统一公开价。

最稳妥的做法：把“渠道 + 收货地址（县/区）+ 商品重量”三项准备好，在结算页试地址；或直接联系该渠道客服确认是否覆盖你所在县城。
