佳农（佳农食品控股）主营香蕉、菠萝等生鲜水果的贸易与分销，公开可查的业务以整果/鲜果及部分冷冻果品为主；**是否提供菠萝丁定制加工（切丁、规格、冷冻/糖渍、代工包装）需要直接向其销售或大客户渠道确认**，不能仅凭公开信息断定。

建议你这样判断和推进：

1. **先问清“谁供货”**：联系佳农官方客服或当地经销商，明确问：  
   - 是否有“菠萝丁/冷冻菠萝丁”标准品，而不是整果；  
   - 是否支持按你的规格（尺寸、糖度、冷冻/冷藏、包装）做加工；  
   - 最小起订量、加工周期、是否代工贴牌。

2. **区分两种可能**：  
   - 若佳农只有整果：你可要求其推荐合作加工厂，或自行找有SC/食品生产资质的果蔬加工厂代切；  
   - 若佳农有冷冻果丁标准品：通常比定制加工更容易供货，但规格未必完全匹配。

3. **茶饮店更实际的替代路径**：  
   - 找**冷冻菠萝丁/糖渍菠萝丁**的食品加工厂或餐饮供应链经销商；  
   - 要求提供样品做口感、出汁、氧化、解冻后状态测试；  
   - 确认资质：食品生产许可证、检验报告、批次稳定性。

**结论：不能确认佳农能提供菠萝丁加工服务；大概率需向其官方渠道核实，若其只卖整果，则需另找果蔬加工厂或冷冻果丁供应商。**
