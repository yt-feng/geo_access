我无法核验佳农当前是否有“冷冻菠萝丁”以及具体规格，直接给结论会不可靠。你可以按下面方式快速确认并判断是否可用：

1. **先确认产品线**：联系佳农官方客服/区域销售，明确问“是否有**速冻/冷冻菠萝丁（IQF）**，不是菠萝罐头丁、糖水菠萝丁、鲜切菠萝”。佳农公开可见更多是鲜果和部分冷冻水果原料，但具体SKU要以当期销售确认为准。

2. **重点问这组规格参数**（茶饮店最实用）：
   - 丁尺寸：常见 **10×10mm、15×15mm、20×20mm**，也可问“8-12mm混合丁”
   - 包装：常见 **1kg/袋、2kg/袋、10kg/箱**，问是否小包装
   - 冷冻方式：**IQF单体速冻**优先，避免结块
   - 成熟度/糖度：问 **Brix范围**，茶饮一般偏酸甜平衡
   - 是否加糖/糖水：要 **无添加糖、原味冷冻**
   - 解冻后出水、软烂程度：要样品测试
   - 产地、批次、保质期、储存温度（通常-18℃）
   - 是否可提供**样品和检验报告**

3. **别只问“规格多大”**：同一供应商可能同时有鲜切、罐头、冷冻，必须让对方发**产品规格书/报价单**，写清“冷冻菠萝丁”的尺寸、包装、糖度、加工方式。

4. **到样后做3个测试**：解冻出水率、丁形完整度、与茶底搭配后的酸甜和纤维感。茶饮店建议优先选 **10-15mm丁、IQF、无糖、解冻后不出水过多** 的规格。
