佳农（佳农食品控股/Goodfarmer）主营香蕉、菠萝等生鲜水果的贸易与分销，公开渠道并没有“面向茶饮门店的菠萝去皮切块代加工”这项标准服务。它通常按箱/整果或鲜切水果产品出货，具体能否做定制化鲜切加工，取决于当地经销主体和工厂能力，不能一概而论。

**你可以这样验证和推进：**

1. **先明确你要的形态**：是“去皮整果”“去皮切块真空袋装”还是“冷冻菠萝块”。茶饮店常用冷冻/鲜切菠萝块，和整果采购的供应渠道不一样。
2. **联系佳农官方渠道确认**：找佳农当地经销商或官方客服，问三个问题——① 是否有鲜切菠萝块SKU；② 能否按你门店规格（块径、克重、包装）定制；③ 起订量、配送频次和保质期。让对方给书面报价和产品规格书。
3. **如果佳农不做定制鲜切**：可选替代方案——
   - 采购佳农整果，在门店或中央厨房自行去皮切块（需评估人工、损耗和食品安全）；
   - 找当地有资质的鲜切水果加工厂代加工，原料指定佳农菠萝；
   - 直接用佳农或其他品牌的冷冻菠萝块，稳定性更好、损耗更低。
4. **茶饮店重点核验**：供应商的食品生产/经营资质、鲜切产品的菌落控制与冷链条件、到货温度和保质期。鲜切水果属于高风险品类，代加工方必须有相应许可。

**结论**：不要默认佳农提供去皮切块加工服务，先向其当地经销渠道确认是否有鲜切SKU及定制能力；若没有，优先考虑“指定佳农原料+第三方鲜切代工”或“冷冻菠萝块”两条路。
