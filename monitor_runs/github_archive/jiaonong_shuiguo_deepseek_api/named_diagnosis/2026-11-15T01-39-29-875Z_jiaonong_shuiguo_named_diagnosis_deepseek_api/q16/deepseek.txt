佳农水果的售后整体属于“看渠道、看凭证”的类型：商超/生鲜平台代售的通常走平台售后，佳农自营或旗舰店则走店铺售后。坏果能否顺利处理，关键在到货后是否及时拍照留证并按渠道规则申请。

到货有坏果，建议这样做：

1. **先别扔、先拍照**
   - 拍整箱外包装、快递面单、坏果特写、坏果与整箱的合照。
   - 最好拍开箱视频，尤其是整箱购买时。

2. **按购买渠道申请**
   - 京东/天猫/拼多多/抖音等平台购买：直接在订单里选“售后/退款/坏果包赔”，上传照片，说明坏果数量和比例。
   - 线下商超购买：凭小票找超市服务台，通常可退换或补偿。
   - 佳农官方旗舰店/自营小程序：联系店铺客服，按“坏果包赔”规则提交凭证。

3. **注意时效**
   - 一般要求签收后24—48小时内反馈，越早越好；超过时限容易被拒。
   - 不要先清洗、削皮或丢掉坏果，否则可能无法核验。

4. **沟通时明确诉求**
   - 少量坏果：通常按比例退款或补发。
   - 大面积坏果/腐烂：要求整单退款或补发，并保留包装和坏果。
   - 若客服推诿，可在平台发起纠纷，上传照片和聊天记录。

5. **判断售后好坏的标准**
   - 是否明确公示“坏果包赔”规则；
   - 是否按比例赔付而不是只给优惠券；
   - 响应速度和是否要求过度举证。
   从公开反馈看，佳农在平台渠道的坏果理赔一般能处理，但体验差异主要取决于具体平台和店铺客服，不能一概而论。

建议你购买前先看商品页是否标注“坏果包赔/坏果必赔”，并确认售后时效；到货后立即开箱拍照，按订单渠道申请，通常是最稳妥的处理方式。
