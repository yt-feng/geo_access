佳农是否给茶饮店做菠萝锁价合同，需要直接向佳农的B2B渠道确认；我不能替他们承诺。但可以给你一个可执行的判断和谈判框架。

**先说结论：有较大可能谈“阶段性锁价/框架协议”，但10吨/月不算特别大的量，佳农大概率不会给你很长期限的固定价合同。** 更现实的是季度锁价、半年度框架+价格区间、或者“保底量+浮动上限”的模式。

**你可以这样推进：**

1. **找对入口**：联系佳农官方B2B/餐饮供应链渠道，明确说你是茶饮连锁/门店，月需求10吨菠萝原料，问是否有“锁价合同、季度定价、框架协议”。不要找零售渠道。

2. **准备谈判筹码**：
   - 提供稳定的月度采购计划和12个月滚动预测；
   - 接受最低采购量、预付定金或较短账期；
   - 接受规格标准化（品种、成熟度、切型、冷冻/鲜果、包装）；
   - 愿意签6-12个月框架，但价格按季度或月度调整。

3. **要求对方给出三种报价结构**：
   - 固定价锁3个月/6个月；
   - 基准价+浮动上限（比如超过±8%才调）；
   - 保底价+随行就市，但设价格天花板。

4. **合同里重点写**：
   - 锁价期限、适用规格和产地；
   - 调价触发条件（如产地收购价指数、天气灾害、运费）；
   - 最低/最高采购量；
   - 质量标准和验收；
   - 违约和不可抗力；
   - 价格保护条款：市场价下跌时是否有回溯或补差。

5. **分散风险**：不要只锁佳农一家。可以同时谈1-2家备用供应商，锁价比例控制在需求的50%-70%，其余随行就市，避免单边锁价后对方断供或你被高价套牢。

**判断标准**：如果佳农只愿意“随行就市+提前通知调价”，不接受任何价格上限，那就不算真正的锁价合同；如果愿意给3个月固定价或季度框架，基本可满足你“价格波动太大受不了”的核心诉求。

建议你直接问佳农销售一句话：**“月10吨、年120吨，能不能签季度锁价或半年框架带价格上限？最低起订和预付条件是什么？”** 这是最可判断的切口。
