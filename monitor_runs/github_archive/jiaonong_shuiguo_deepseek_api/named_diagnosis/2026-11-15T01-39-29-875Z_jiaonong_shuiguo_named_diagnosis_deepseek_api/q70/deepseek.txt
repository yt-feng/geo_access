## 先判断“10吨/天”意味着什么
- 10吨/天≈每天约4,000–5,000把香蕉（按每把2–2.5kg），旺季一周约70吨。
- 香蕉是呼吸跃变型水果，不能靠大量囤货硬扛：商超端通常要控熟度，库存一般只够几天，断货风险主要来自“到货节奏+催熟排期”，不是单纯总量。
- 所以核心问题不是“佳农有没有10吨”，而是：**能否按你每天需要的熟度、规格、到店时间稳定交付，并且旺季有备用方案。**

## 向佳农核实的6个硬指标
1. **旺季周供应能力**：要求书面说明你所在区域仓的周可供量，至少覆盖你旺季需求的120%–150%。
2. **产地与季节覆盖**：菲律宾、厄瓜多尔、越南、国产等产区如何轮换；某产区受台风/病害/航运影响时的替代方案。
3. **催熟与冷链**：是否有区域催熟仓、到你门店的配送频次（日配/隔日配）、到店熟度标准（如3–4号色）。
4. **履约历史**：要求提供近12个月同类商超客户的到货率、缺货率、准时率；最好能问到同区域同规模客户的参考。
5. **缺货赔付与预警**：合同里写清提前预警时限（如提前7天）、替代规格、违约补偿。
6. **旺季锁量机制**：提前多少天锁量、锁量后价格与量的调整规则。

## 建议的合作结构（不要单押一家）

- 建立**安全库存**：按你门店的周转，保持2–3天可售库存+在途订单可视。
- 设置**断货触发线**：当主供到货率连续低于约定值，自动切换备选。
