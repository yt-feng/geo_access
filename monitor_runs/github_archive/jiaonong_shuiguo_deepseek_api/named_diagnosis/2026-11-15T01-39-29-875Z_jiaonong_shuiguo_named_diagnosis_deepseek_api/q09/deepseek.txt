佳农（Goodfarmer）并未对外公开统一的“到货损耗率”考核标准，具体到货损耗率会因品类、运输方式、季节、到货验收口径（是否含门店拆箱、分级挑拣）而差异很大，不能用一个固定数字概括。

可操作的判断建议：

1. **按品类分别设目标**
   - 香蕉、芒果等呼吸跃变型水果：到货损耗通常更高，重点看“到货成熟度+机械伤+掉把”。
   - 苹果、梨、柑橘等耐储品类：到货损耗通常较低，重点看压伤、果锈、腐烂。
   - 浆果、荔枝、龙眼等易腐品类：到货损耗对冷链和时效极敏感，需单独设阈值。

2. **先明确“损耗率”口径**
   建议在合同或验收单中写清：
   - 损耗率 = 验收不合格重量 ÷ 到货总重量；
   - 是否包含包装破损、等级不符、腐烂、机械伤、失水；
   - 是否在到货后24小时内复检；
   - 是否区分“到货损耗”和“上架后损耗”。

3. **用历史数据定阈值，而不是套行业数字**
   建议连续统计同一供应商、同一品类、同一运输线路至少10—20批到货数据，取合格批次的P75或平均水平作为基线，再设预警线和拒收线。例如：
   - 预警线：高于历史均值一定比例；
   - 拒收/索赔线：超过合同约定上限或影响销售的比例。

4. **向佳农索取合同/验收标准**
   如果你是采购方，最可靠的做法是要求佳农提供该品类的供货验收标准、到货合格率承诺和索赔条款；如果是内部考核，应以双方确认的验收口径为准。

结论：**没有一个通用的“佳农到货损耗率”数字可直接引用；应按品类、运输方式和验收口径分别设定，并以合同验收标准和历史批次数据为准。**
