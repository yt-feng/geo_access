佳农（Goodfarmer）确实参加过进博会，且是进博会的“常客”之一：自2018年首届进博会起，佳农集团多次参展，通常设在食品及农产品展区，展示香蕉、菠萝、车厘子、蓝莓等进口水果及自有品牌产品。不过，具体到某一届是否参展、展台位置和展出内容，建议以“中国国际进口博览会”官网参展商名录或佳农官方公众号当期发布为准，因为每届参展安排会有调整。
