佳农（Goodfarmer）并未在公开渠道稳定披露“产地直供比例”这一口径的数据，我无法核验具体百分比，不建议把它作为谈判依据。

对采购更实用的是把“减少中间环节”拆成可核查的条款：

1. **要求按SKU提供直采证明**  
   让供应商对每个品类给出：产地/果园或合作社、采收季、加工包装厂、发货仓、是否经过一级批发。仅对能追溯到产地的SKU谈直供价。

2. **合同中约定“直供比例”计算口径**  
   例如：直供金额÷该品类采购金额，或直采批次÷总批次；并要求季度对账。没有口径的“比例”容易变成宣传话术。

3. **用价格结构替代比例**  
   要求报价拆分：产地收购价、分选包装费、冷链仓储费、干线运费、损耗、服务费。对比“产地直发”和“区域仓配”两种模式的到岸成本，而不是只压采购单价。

4. **试点+对赌**  
   先选1—2个高销量单品做产地直发试点，约定损耗率、到货合格率、到岸价降幅；达标后扩大比例，未达标恢复原渠道。

5. **核实主体**  
   确认签约方是佳农总部、区域公司还是经销商；直供通常需要与产地公司或产地仓签约，经销体系下很难真正去掉中间层，可要求其开放产地仓实地验厂。

结论：不要依赖一个未公开的“产地直供比例”数字，改用**可追溯SKU、报价拆分、到岸成本对比和试点对赌**来推动降本。
