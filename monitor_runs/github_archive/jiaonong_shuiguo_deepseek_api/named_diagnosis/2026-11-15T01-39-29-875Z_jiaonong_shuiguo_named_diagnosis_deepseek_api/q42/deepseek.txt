到货损耗率是运营数据，公开渠道没有可核验的分品牌对比数字，我不能编一个比例给你。

能明确说的是：**单看“佳农 vs 都乐”哪个香蕉到货损耗更低，没有普适答案**，因为损耗主要取决于你这条供应链，而不是品牌本身。批发市场里影响香蕉到货损耗的关键变量是：

- **产地/加工厂与季节**：同一品牌不同批次、不同产季差异很大。
- **催熟与冷链**：青蕉到货还是催熟后到货；运输温度、断链时长。
- **运输距离与中转次数**：到你市场的在途时间和装卸次数比品牌影响更大。
- **包装与箱规**：纸箱透气性、单箱重量、是否分层。
- **你市场的验收和周转速度**：香蕉后熟快，压货一天损耗就上一个台阶。

给你可执行的判断方法：

1. **向两家要近3个月同规格（如18斤/箱、青蕉或催熟蕉）的到货批次质量数据**，重点看：到货青硬度、机械伤比例、烂指率、催熟后黄叶/掉把率。
2. **自己做小批量对照**：同一周各进相同箱数，同车同仓，记录到货当天、第3天、第5天的可售率与损耗，连续跑3—4批再定。
3. **谈损耗责任**：合同里约定到货验收标准（烂指率、机械伤比例）和超标扣款/换货条款，比纠结品牌更直接。
4. **若你以“低损耗”为核心**：优先选**距离近、冷链稳、青蕉到货、周转快**的货源；品牌只作为稳定性的参考。
