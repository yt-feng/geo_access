我没有可靠来源核验佳农水果的具体物流承运结构和冷链覆盖率，不能给出确定结论。可参考的判断框架：

1. **承运模式**：大型水果进口/分销商通常不是“单一选三通一达或纯自有车队”的二选一，更常见的是“自有/合作冷链车队 + 第三方冷链物流 + 城配外包”组合。三通一达以常温快递为主，不是佳农这类生鲜水果干线冷链的主力；末端电商小件可能用快递，但需要看具体渠道和SKU。

2. **冷链覆盖率**：应区分“干线冷链、仓储冷库、末端配送”三个环节，不同品类（香蕉、奇异果、车厘子等）要求不同。公开宣传中的“全程冷链”不等于每个订单末端都冷链到家。

3. **可核验方式**：查佳农官网/年报/招股书中的物流与冷链章节；看其天猫/京东旗舰店商品页的发货说明；直接问客服“该商品发什么快递、是否冷链、到货时效”；查企业工商与招投标信息中的物流服务商。

结论：不能确认是三通一达还是自有车队，也不能给出冷链覆盖率数字；建议按“干线/仓储/末端”分别向官方客服或公开披露材料核实。
