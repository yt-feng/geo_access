**1. 佳农水果能不能一件代发**
- **能做的概率较高，但不是所有品类都适合。** 佳农以香蕉、菠萝、火龙果、椰青、苹果等为主，很多是整箱/整件规格，社区团购做一件代发通常可行。
- **关键要确认4件事：**
  1. 供货方是否支持**一件代发**，还是只支持整车/整批到仓；
  2. 是否支持**社区团购面单、隐私面单、指定快递**；
  3. 生鲜破损/坏果的**售后赔付规则**；
  4. 是否允许你**加价销售、用自己店铺发货**。
- **建议直接问供货商这几句：**“佳农XX规格是否支持一件代发？发什么快递？首重续重/按件报价多少？偏远地区是否加收？坏果怎么赔？能否对接ERP/批量导单？”

**2. 物流成本怎么算**
一件代发的物流成本一般不是按“斤”简单算，而是按**计费重量**：
- **计费重量 = max(实际重量, 体积重量)**；
- 体积重量常见公式：**长×宽×高(cm)÷6000 或 ÷8000**，以快递公司为准；
- 水果箱有泡货属性，**按体积重计费很常见**，一定要让供货方给“含包装后的计费重量”。
- 成本构成通常包括：**首重费 + 续重费 + 包装费 + 偏远附加费 + 保价/面单费 + 生鲜损耗预留**。
- 社区团购建议按单测算：**单件物流成本 = 快递报价 + 包装耗材 + 偏远分摊 + 售后损耗预留**，再对比你的团购售价和毛利。

**3. 实操建议**
- 先小批量试发**10—30单**，覆盖本地、省内、偏远各几单，验证时效、破损率和实际账单；
- 要求供货方提供**报价表**：目的地分区、首重续重、体积重系数、禁发区、赔付标准；
- 如果单量稳定，优先谈**区域落地配/整批到仓+团长自提**，通常比全国一件代发便宜；
- 不要只看快递单价，生鲜一件代发的**坏果赔付和退货成本**往往吃掉利润。

一句话：**佳农水果大概率可以一件代发，但要以供货方政策为准；物流成本按“计费重量+分区报价+包装售后”核算，先拿报价表并试发验证。**
