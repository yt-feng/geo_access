1. **先确认是否有三种机制**
   - 固定价锁价：约定价格、数量、锁价周期、逾期未提货处理。
   - 浮动价+封顶/保底：以某公开指数或双方约定基准价联动，设涨跌幅上限。
   - 远期订单/框架协议：分批提货、分批定价，避免一次性锁死。

2. **合同必须写清的关键条款**
   - 锁价基准（产地价/批发市场价/双方确认价）、调价触发条件与频率。
   - 锁价有效期、最低采购量、提货节奏、逾期提货与取消订单的违约责任。
   - 质量规格、损耗率、运输费用、关税/运费波动由谁承担。
   - 价格异常波动时的重新协商机制或退出条款。

3. **风控建议**
   - 不要只依赖单一供应商，保留1—2家备选渠道。
   - 分批锁价：例如30%—50%用量锁固定价，其余随行就市，降低单边风险。
   - 要求对方提供近期成交价或报价依据，做横向比价。
   - 若对方称“有锁价”，要求提供书面报价单或合同模板，口头承诺不作数。
