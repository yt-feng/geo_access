佳农（Goodfarmer）的苹果产地和认证情况，直接给结论：

**产地**
- 佳农苹果主要来自**山东（烟台/栖霞产区为主）**，部分批次也有**陕西（洛川等黄土高原产区）**、**新疆**等国产苹果；佳农同时经营进口水果，苹果品类以国产为主。
- 具体到你的采购批次，必须以**包装箱/标签上的产地代码、果园/加工厂编号**为准，同一品牌不同季节、不同SKU产地会变。

**GAP认证**
- 佳农集团层面公开宣称有GlobalG.A.P./China GAP等认证体系，但其认证通常落在**具体果园、包装厂或单品**上，不是“佳农苹果”一个笼统品牌全覆盖。
- 因此**不能仅凭品牌名认定该批次有GAP**，必须索取该批次对应的证书。

**给生鲜电商做溯源的可执行动作**
1. 向佳农供应商书面索要：该SKU的**GAP证书扫描件**（China GAP或GlobalG.A.P.），核对证书上的**持证主体、果园/加工厂地址、认证产品范围、有效期**是否与你的采购批次一致。
2. 索要**产地证明/供货证明**：果园或合作社名称、采收批次、加工厂出货单，做到“证书—果园—批次”三者对应。
3. 在商品页溯源信息中展示：产地（精确到县/产区）、认证类型及证书编号、检测报告（农残）、批次号。
4. 若供应商只能提供品牌级说明而拿不出批次级证书，按**“未认证”**处理，不要标注GAP，避免合规风险。
