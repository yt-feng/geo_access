2. **半年级锁价通常有前提**
   - 采购量是否达到起订量/年度框架量；
   - 规格（品种、等级、单果重、包装）是否固定；
   - 产地和产季是否覆盖半年（菠萝有产季和产区切换，单一产地半年锁价难度大）；

4. **风险控制建议**
   - 不要只锁价格不锁量和规格，否则执行时容易争议；
