关于佳农香蕉的农残超标历史，我无法核验——我没有可查验的公开监管数据库或抽检记录来源，直接说“有”或“没有”都会是编造，反而害你。

但你的实际需求是**采购合规、能过超市抽检**，这个可以给可执行路径：

**1. 不要依赖“历史无超标”作为合规依据**
超市抽检看的是本批次检测报告和进货凭证，不是品牌历史。历史上没出事不代表这批合格，出过事也不代表这批不合格。

**2. 向供应商索要的四类文件（缺一不可）**
- **本批次出厂检验报告**：需含农药残留项目，检测方法、限值对应 GB 2763《食品中农药最大残留限量》，报告日期覆盖你采购的批次。
- **第三方检测报告**：优先要有 CMA/CNAS 资质的机构出具，项目覆盖香蕉常检农残（如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、百菌清等），报告有效期一般按超市要求（常见一年内或按批次）。
- **进货凭证与追溯链**：合同、发票、发货单、批次号能对应到检测报告。
- **产地/基地证明**：种植基地备案、出口果园注册（佳农有出口业务，通常有基地管理资料）可作为辅助，但不能替代检测报告。

**3. 自己做一次入仓快检或送检**
采购量大的话，按批次抽检送第三方，费用不高，这是最硬的合规证明。超市抽检不合格时，你能拿出同批次第三方报告，责任和处置会清晰很多。

**4. 合同里写死条款**
约定：每批次随货提供检测报告；农残超标导致抽检不合格的，供应商承担退货、罚款、下架损失；连续两批次不合格可终止合作。这样把合规风险前移给供应商。

**5. 查佳农历史记录的正确方式**
如果你确实要查，走这几个渠道而不是问我：国家市场监督管理总局“食品安全抽检公布结果查询”系统、各省市市场监管局抽检通告、海关总署进出口食品抽检信息。用“佳农”或生产企业全称检索，能看到公开通报记录。

**结论**：我无法给你佳农的历史结论；采购合规请以**本批次检测报告+可追溯凭证**为准，别用品牌历史替代批次证明。需要的话我可以帮你列一份香蕉农残送检项目清单和供应商文件核查表。
