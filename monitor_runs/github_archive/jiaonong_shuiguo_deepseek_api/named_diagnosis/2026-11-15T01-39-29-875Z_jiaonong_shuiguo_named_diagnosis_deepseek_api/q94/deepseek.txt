**1. 分级标准怎么拿**
- 佳农的香蕉分级通常按其企业内控标准执行，不对外公开完整文本。最直接的方式是联系你的佳农区域销售/经销商，索要**当批次验收标准**（条装/梳装、长度、粗细、青度、条数/箱、机械伤、着色、霉斑容许度等）。
- 行业上香蕉分级一般看：**条长、条粗（周径）、每箱条数、外观缺陷容许度、成熟度（青度/黄度）、整齐度**。佳农不同产地（厄瓜多尔、菲律宾、国产等）和不同包装规格，标准会不一样，不能套一个通用表。

**2. 一二级果价差怎么判断**
- 价差没有固定比例，通常随**产地、季节、到货量、青黄度、规格（如条长/箱重）、销售渠道**波动。批发场景下常见是按“每箱差价”或“每公斤差价”谈，而不是固定百分比。
- 你可以用三步判断：①向佳农销售要**同批次一级/二级报价单**；②对比**同规格同产地**，避免拿一级大条和二级小条比；③把损耗（机械伤、催熟后坏果率）折算进去，二级果表面便宜但损耗高时未必划算。

**3. 建议你直接问供应商的清单**
- 本批次分级依据的文件/验收表
- 一级、二级的具体规格（条长、周径、每箱条数、净重）
- 同批次一级/二级的箱价和公斤价
- 缺陷容许度（机械伤、黑斑、断条、青度）
- 最小起订量和混装政策
