佳农香蕉一般按包装或标签上的“保质期/最佳食用期”为准；常见情况是未完全成熟的青香蕉在常温阴凉处可放数天到一周左右，成熟后通常建议2—3天内吃完。储存建议：

1. **未成熟青香蕉**：常温、阴凉、通风处存放，避免阳光直射和冰箱冷藏；可与苹果同放加速催熟。
2. **已成熟黄香蕉**：尽快食用；短期可放阴凉处，不要密封闷放，避免压伤。
3. **已切开**：冷藏并尽快食用，表面可覆保鲜膜减少氧化。
4. **不要整串冷藏**：低温易导致表皮变黑、口感变差；若已熟透想延缓过熟，可去皮切段冷冻用于制作奶昔。
5. **判断变质**：出现明显酸腐味、果肉流汁发黑、霉点或虫蛀时不要食用。

具体保质期请以佳农产品包装标注和购买渠道说明为准。
