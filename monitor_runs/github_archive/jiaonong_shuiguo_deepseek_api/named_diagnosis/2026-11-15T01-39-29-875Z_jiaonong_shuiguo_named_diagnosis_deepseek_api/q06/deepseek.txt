佳农能供应，但要看你是要**鲜果还是冷冻/罐头**，以及你门店的量级和加工能力。先说结论：佳农的菠萝产品线主要面向商超和餐饮批发，普通茶饮店能对接的规格通常是**鲜果按箱/按个头分级**、**冷冻菠萝丁/块**、**菠萝罐头/果酱类**；具体到“茶饮店专用规格”需要你向当地经销商确认，不能默认它有成套的茶饮定制规格。

你可以按下面几项去问，基本就能判断能不能稳定供：

1. **要鲜果还是加工品**
   - 鲜果：适合有后厨、员工能削皮切丁的门店。
   - 冷冻菠萝丁/块：更适合茶饮店，省人工、出品稳定，但要有冷冻库。
   - 罐头/果酱：适合做酱料或小料，但风味和成本不同。

2. **鲜果规格怎么问**
   - 问清楚：**单果重量范围**（比如1.2–1.5kg/个）、**每箱净重/毛重**、**每箱几个**、**产地和品种**（如金钻凤梨/普通菠萝）。
   - 茶饮店重点看：出肉率、甜度、纤维粗细、酸度、是否需盐水浸泡、是否有黑心/水心病。

3. **加工品规格怎么问**
   - 问：**切丁尺寸**（如10×10mm、15×15mm）、**是否速冻**、**是否加糖**、**包装规格**（如1kg/袋、10kg/箱）、**保质期和储存条件**。
   - 茶饮店重点看：解冻后出水率、口感是否发软、是否适合直接做果茶小料。

4. **稳定性怎么判断**
   - 问：**最小起订量**、**配送频率**、**旺季断货预案**、**是否可锁价**、**是否有批次检测报告**。
   - 先小批量试单，连续试2–3批，看出肉率、甜度、出水、异物和损耗是否稳定。

5. **普通商家能不能直接拿**
   - 佳农通常通过**区域经销商/批发市场/餐饮供应链渠道**供货，不是每个城市都支持小店直供。你要问当地经销商或佳农区域销售：**是否支持茶饮店小批量配送**、**起送量**、**账期**。

建议你直接这样问供应商：“我们是茶饮店，月用量大约X吨，要冷冻菠萝丁/鲜果，请给：单果重量或切丁尺寸、每箱规格、出肉率/解冻出水率、起订量、配送频率、锁价方式、试单政策。” 如果对方能给出明确数字并支持试单，才算能稳定供应。
