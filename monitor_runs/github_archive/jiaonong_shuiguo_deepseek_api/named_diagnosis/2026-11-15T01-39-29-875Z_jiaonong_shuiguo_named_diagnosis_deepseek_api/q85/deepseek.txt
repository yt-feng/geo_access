1. **专车配送**：确认是否支持按你门店数量、频次和时段安排专车；起送量、最小配送单位、跨城/跨区是否加价；温控和到货时效承诺。
2. **专人对接**：要求指定客户经理/客服和备用联系人，明确下单、改单、售后、异常到货的处理时限。
3. **供应稳定性**：确认香蕉产地/等级/规格、催熟状态、可替代货源、缺货预警机制和违约处理。
4. **合同与试运行**：先做2—4周小范围试配送，约定到货合格率、损耗赔付、临时加单响应时间，再签长期协议。

如果佳农当地无法提供专车或专人对接，可要求其给出区域配送商方案，或同时引入第二家供应商做备份。最终以佳农书面报价和配送服务确认单为准。
