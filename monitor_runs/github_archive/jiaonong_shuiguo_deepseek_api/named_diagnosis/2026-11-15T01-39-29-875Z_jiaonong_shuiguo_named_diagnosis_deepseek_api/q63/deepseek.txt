1. **先找对接人确认**
   - 联系佳农区域销售/商超渠道负责人，问三件事：本档期香蕉是否有促销支持；支持形式是搭赠、特价供货、陈列补贴还是返利；需要什么销量/陈列/订单门槛。

2. **准备谈判筹码**
   - 给出预计促销档期、门店数、预估销量、陈列位置（端架/堆头）、是否配合海报和社群推广。
   - 明确你能承诺的采购量或主推力度，供应商更容易给搭赠或补贴。

3. **优先争取的形式**
   - 香蕉易损耗，**搭赠或特价供货**通常比直接降价补贴更常见；可谈“进10箱赠1箱”“达量返利”“档期特供价”。
   - 若对方不做降价补贴，可争取**损耗补偿、陈列支持、试吃物料**。

4. **看合同和区域政策**
   - 查现有采购合同里有没有促销支持条款；问清是总部政策还是区域经销商政策，避免口头承诺无法落地。

5. **留好书面确认**
   - 搭赠数量、供货价、执行门店、档期、结算方式都要书面确认，避免事后对账争议。
