佳农（佳农食品控股/Goodfarmer）主要做进口水果和国产精品水果的供应链，很多是通过电商平台（京东、天猫、拼多多、抖音）、社区团购或商超渠道卖的。所以它的售后**先看你在哪个渠道买的**，渠道规则往往比品牌本身更关键。

## 总体规律

- **品牌方一般不在前台直接受理个人售后**，而是走你下单的平台的售后入口。
- **生鲜品类的通用规则是"坏果包赔"**，但各家对"坏果比例""是否要拍照""是否要原包装"要求不同。
- 佳农作为供货商，通常会给平台/团长一个赔付标准，由平台客服执行。

## 到货发现坏果，怎么处理

按这个顺序做，成功率最高：

1. **先拍照/拍视频留证**
   - 坏果和好果分开拍，最好能看出整箱情况和坏果数量。
   - 保留**快递面单、外包装箱、原包装**，很多平台要求一起拍。

2. **尽快联系购买渠道客服，别拖**
   - 京东：订单 → 申请售后/退换货，生鲜一般支持"坏果包赔"。
   - 天猫/淘宝：订单里联系卖家客服，走"仅退款"或"退运费"。
   - 拼多多：订单 → 申请售后，选"质量问题/坏果"。
   - 抖音/直播间：订单 → 申请售后，或联系主播/商家客服。
   - 社区团购/团长：直接找团长，由团长向平台报损。
   - 商超/线下：拿小票回店里处理。

3. **说明情况时给关键信息**
   - 订单号、到货时间、坏果数量或比例、照片。
   - 明确诉求：补发、退款、还是部分赔。生鲜一般**按坏果比例赔付**，不一定整单退。

4. **如果平台客服推诿**
   - 升级到平台官方客服（不是商家客服）介入。
   - 必要时在订单里发起"平台介入/投诉"。
   - 仍不解决可走 12315（全国12315平台小程序/网站），对象填实际卖家或平台。

## 要注意的坑

- **超时**：生鲜售后时效短，很多要求**签收后24小时内**甚至当天反馈，越晚越难赔。
- **证据不全**：只拍一张坏果、没有外箱面单，容易被拒。
- **拆开丢了包装**：有的平台要求原包装，扔了可能影响赔付。
- **"坏果"认定标准**：轻微磕碰、个别软化有时不算，严重腐烂、发霉、压烂一般算。

## 一句话建议

**先按要求拍照留证 + 24小时内找下单渠道申请售后 + 主张按坏果比例包赔**；渠道不理就申请平台介入，再不行打12315。
