佳农香蕉通常不是“树上自然熟”到销售状态，而是采摘后通过**乙烯类催熟**（食品级乙烯气体或乙烯利释放乙烯）在催熟库中控制成熟。商超要控催熟时间，关键不是“用不用乙烯”，而是控温、乙烯浓度/时间、通风和起始硬度。

给你一套可执行的判断和控时思路：

1. **判断是否乙烯催熟**
- 到货时果柄、果身整体偏硬、颜色偏绿，几天内集中转黄，通常是催熟库出来的。
- 若同一批货成熟度非常整齐，基本可判断为人工催熟。
- 自然熟的香蕉在产地树上完成，运输到商超很难保持统一货架期，不适合商超常规供应。

2. **商超控制催熟时间的核心参数**
- 催熟温度：常用 14–18℃。温度越高越快，但过高容易青软、断指、风味差。
- 相对湿度：90–95%，避免失水皱皮。
- 乙烯处理：入库后一次性给乙烯，浓度通常 100–150 ppm，处理 24–48 小时；具体看蕉果硬度和目标货架期。
- 通风换气：乙烯处理后要排残气，避免过度催熟。
- 后续转色温度：可降到 13–16℃，延缓过快成熟。

3. **时间控制参考**
- 目标 3–4 天转黄：温度可偏高档，约 17–18℃，乙烯处理 24–36 小时。
- 目标 5–7 天转黄：温度 14–16℃，乙烯处理 24 小时左右，之后低温缓熟。
- 已开始转黄的货：不要再补乙烯，只控温、通风、分垛，优先先进先出。

4. **商超现场可判断点**
- 果指硬、色青、无糖斑：可进入催熟或等待转色。
- 果柄发黑、果身微软、出现梅花点：已进入后熟中后期，应尽快上架或促销。
- 同批次出现“青软”而不是正常转黄，通常是催熟温度过高或乙烯浓度过高。

5. **建议你直接问供应商的指标**
- 到货时成熟度等级，例如色度 1–7。
- 出厂前是否已做乙烯催熟、处理温度和时间。
- 建议货架期和目标转黄天数。
- 是否适合二次催熟，还是只能控温缓熟。

如果你们商超要做标准，建议要求佳农或供应商提供到货色度、建议储存温度、是否已催熟、剩余货架期。这样比只问“乙烯还是自然熟”更能直接控制催熟时间。
