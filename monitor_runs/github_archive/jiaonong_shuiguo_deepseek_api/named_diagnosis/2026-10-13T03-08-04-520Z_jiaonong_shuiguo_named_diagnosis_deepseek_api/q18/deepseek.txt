佳农香蕉的“保质期”没有统一固定值，主要取决于**成熟度、储存温度、是否已催熟/是否冷藏**。可按下面判断和操作：

- **未完全成熟、表皮偏青的香蕉**：适合放在**室温阴凉通风处**，一般可放 **3～7天**。想延缓成熟，不要直接晒太阳，也不要放冰箱冷藏，否则容易表皮变黑、口感变差。
- **已经成熟、表皮变黄并出现少量糖斑的香蕉**：室温下通常还能放 **1～3天**。如果已经熟透，建议尽快吃或做奶昔、烘焙。
- **想延长几天**：成熟后可以**剥皮切段冷冻**，适合做冰沙/奶昔，通常可存 **1～2个月**；不建议整根带皮冷冻后直接当鲜果吃。
- **储存要点**：
  1. **常温阴凉通风**，避免阳光直射和暖气旁。
  2. **不要和苹果、梨、番茄等释放乙烯的水果放一起**，会加速成熟。
  3. 如果想催熟，可和苹果一起放在纸袋里；如果想延缓，尽量单独放。
  4. **不要清洗后存放**，吃前再洗/剥皮。
  5. 冷藏会让香蕉皮变黑，但果肉短时间未必坏；如果已经成熟又吃不完，可冷藏 **1～2天**，吃前回温。
  6. 出现**明显酸味、酒味、果肉发黑软烂、霉点**就不要吃了。

简单记：  
**青香蕉常温催熟，黄香蕉尽快吃，熟透剥皮冷冻。**  
如果是超市预包装佳农香蕉，包装上若有具体“保质期/储存条件”，以包装标注为准。
