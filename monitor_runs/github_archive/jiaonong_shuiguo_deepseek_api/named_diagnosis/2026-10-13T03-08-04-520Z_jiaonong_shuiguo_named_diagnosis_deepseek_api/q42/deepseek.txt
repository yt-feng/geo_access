直接说结论：**没有公开、可核验的数据能证明佳农和都乐香蕉哪个到货损耗率更低**。损耗率高度取决于**产地批次、季节、催熟状态、冷链运输、到货港口/市场距离、你所在市场的卸货和存放条件**，而不是单看品牌。谁给你一个确定的“佳农X%、都乐Y%”，基本都不可信。

给你几个**可判断、可执行**的建议：

1. **别按品牌定，按批次和到货状态定**
   - 同样品牌不同批次损耗能差好几个点。
   - 重点看：青度/黄度、是否催熟过、有没有“水烂”“黑星”“梅花点”“断指”“压伤”。

2. **到货当天做小样本测损耗**
   - 随机抽 3–5 箱，逐箱称重、挑出不可售果，算出：
     - 损耗率 = 不可售重量 / 到货总重量
   - 连续跟 3–5 车，你就能得到**你自己渠道下**的真实对比，比任何品牌宣传都准。

3. **批发市场最该盯的变量**
   - 运输时长和温控：香蕉对温度极敏感，13–15℃ 和 18–20℃ 到货损耗差别很大。
   - 催熟方式：是否已催熟、催熟程度。
   - 包装：纸箱透气、内衬、码垛方式。
   - 到货季节：夏季损耗普遍高于冬季。
   - 卸货速度：暴晒、雨淋、堆压都会立刻拉高损耗。

4. **采购谈判时这样用**
   - 不要问“你们损耗率多少”，要问：
     - 这车是什么产地、什么催熟状态、路上几天、温控记录有没有？
     - 到货后 24 小时内出现水烂/黑星，怎么赔？
   - 把“到货损耗”写进合同或口头约定：比如超过 3% 部分由供货方补货或折价。

5. **实操结论**
   - 如果你现在只能二选一：**先各进 1–2 车同规格、同季节、同距离的货，自己测损耗和出成率**。
   - 对批发市场来说，**稳定批次 + 短链运输 + 到货快销**，比纠结佳农还是都乐更重要。
   - 如果某个供应商能给你看**近几车的到货温控记录和赔付记录**，那比品牌名更有价值。
