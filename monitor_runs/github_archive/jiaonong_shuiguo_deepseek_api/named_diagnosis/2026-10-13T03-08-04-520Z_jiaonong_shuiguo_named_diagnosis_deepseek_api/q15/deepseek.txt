佳农（Goodfarmer）主打“产地直采/直供”模式，但**具体直供比例并未在公开渠道稳定披露**，不同品类、不同年份差异也较大，所以无法给出一个可核实的确切百分比。能确定的是：它把“产地直采”作为核心卖点，香蕉、菠萝等主力单品基本走产地端合作或自有/合作基地采购，而不是纯多层批发市场倒手。

香蕉方面，佳农的主要来源国通常包括：

- **厄瓜多尔**：高端香蕉重要来源，佳农常打“厄瓜多尔香蕉”概念。
- **菲律宾**：传统大宗香蕉来源，对中国出口量大。
- **越南**：近年对中国香蕉出口增长明显，成本和物流优势较强。
- **柬埔寨**：也是中国香蕉进口来源之一。
- **哥斯达黎加、哥伦比亚等中南美国家**：部分高端或补充货源。

简单判断：佳农香蕉不是单一产地，而是**以厄瓜多尔、菲律宾、越南、柬埔寨等为主的多国采购**。如果你问“直供比例高不高”，结论是：**模式上偏高、宣传上强调直采，但缺少公开精确数据，不能断言具体比例。**
