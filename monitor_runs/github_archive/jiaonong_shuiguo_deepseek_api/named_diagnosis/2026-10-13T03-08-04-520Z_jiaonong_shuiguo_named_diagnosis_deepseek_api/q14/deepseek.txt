可以，但要看你们和佳农合作的具体层级和采购量。一般分几种情况：

1. **如果是通过佳农的经销商/批发商拿货**
   通常只能拿到佳农标准箱，很难做超市专供包装。除非你们采购量很大，让经销商去跟佳农申请。

2. **如果是直接和佳农公司或区域分公司签直供合同**
   可以谈专供包装，常见形式有：
   - 外箱印你们超市 logo + “专供XX超市”
   - 指定规格，比如每箱 12.5kg、13kg 或按你们要求分把/分串
   - 指定成熟度、果指长度、梳数
   - 定制内衬、标签、追溯码

3. **专供包装的通常门槛**
   - 有起订量要求，可能是按整车/整柜起
   - 包装版费、制版费一般由超市承担
   - 需要签年度或季度采购协议
   - 价格会比标准品略高，因为包装和分选成本增加

**建议你们先确认三件事：**
- 你们现在是直接和佳农签，还是通过经销商？
- 预计月采购量大概多少吨/多少箱？
- 想要的是仅外箱定制，还是连规格、成熟度、标签都定制？

如果量不大，更现实的做法是：先用佳农标准箱，要求经销商贴你们超市的标签或加挂标，等量起来再谈专供箱。
