我无法给出一份“佳农官方在售全部香蕉规格 + 各渠道分级标准”的准确清单；这类信息通常随产区、季节、客户订单和包装线变化，且属于企业渠道政策，公开渠道未必完整、也未必实时。  
如果直接凭印象列数字，很容易误导你。下面给你一套**可核验、可落地的判断框架**，你可以据此去问供应商或做采购验收。

## 一、佳农香蕉常见规格，通常按这几类分

佳农属于品牌水果供应商，香蕉规格一般不会只有一种，常见会从以下维度组合：

### 1. 按单根重量/大小分
常见表述方式有：
- 小果：单根偏小，适合零售散卖、便利店
- 中果：最常规，适合商超、水果店
- 大果：单根偏大，适合批发、餐饮、加工
- 特大果：部分产区或特定订单才有

实际分级可能写成：
- 4-5把/箱、5-6把/箱
- 单根约120g以下、120-150g、150-180g、180g以上等  
但**具体克重区间要以佳农当批次送货单或质检单为准**。

### 2. 按每箱净重分
常见渠道包装会按净重做规格，例如：
- 4.5kg/箱
- 5kg/箱
- 10kg/箱
- 12kg/箱
- 13kg/箱  
不同渠道常见箱规不同，电商、商超、批发市场会分开做。

### 3. 按梳/把/条数分
香蕉常按“梳”或“把”计数：
- 4-6梳/箱
- 5-7梳/箱
- 单梳条数不同  
这种规格更影响陈列和损耗，而不是单纯重量。

### 4. 按成熟度/催熟阶段分
这是渠道分级里非常关键的一项：
- 青蕉：适合长途运输、批发、再催熟
- 微黄：适合商超、水果店，到店后继续转黄
- 黄熟：适合即时零售、便利店、餐饮
- 全熟/熟蕉：适合烘焙、饮品、加工

## 二、适合不同渠道的分级标准，通常这样定

### 1. 商超/精品超市
更看重：
- 外观整齐，果指长度均匀
- 梳形完整，无严重擦伤、黑斑
- 成熟度一致，便于货架统一转黄
- 单根大小适中，方便消费者按把购买

适合规格：
- 中果为主
- 5kg、10kg箱规常见
- 微黄到黄熟阶段

### 2. 水果店/社区店
更看重：
- 性价比
- 到店后2-4天能卖完
- 允许轻微外观瑕疵，但不能影响口感

适合规格：
- 中果、小果
- 4.5kg、5kg、10kg
- 青蕉或微黄蕉

### 3. 批发市场/二级批发
更看重：
- 耐运输
- 货架期长
- 分级稳定，不能一批一个样
- 价格敏感

适合规格：
- 青蕉为主
- 大箱规，如10kg、12kg、13kg
- 允许一定大小混装，但要求成熟度统一

### 4. 电商/即时零售
更看重：
- 单次购买量小
- 到家可立即吃或1-2天可吃
- 包装抗压
- 分量稳定

适合规格：
- 小规格：1kg、2kg、3kg、5kg
- 中果或小果
- 黄熟或微黄
- 独立缓冲包装

### 5. 餐饮/饮品/烘焙
更看重：
- 出肉率
- 成熟度稳定
- 成本低
- 对外观要求低

适合规格：
- 大果、熟蕉、次果
- 大箱规
- 全熟或高成熟度

## 三、你实际采购时，建议直接问佳农或经销商这8项

不要只问“有几种规格”，直接要一张规格表，重点确认：

1. 单根重量区间是多少克？
2. 每箱净重多少公斤？
3. 每箱几梳、每梳几根？
4. 果指长度、粗度标准？
5. 青蕉/微黄/黄熟分别是几号成熟度？
6. 允许的瑕疵率是多少？
7. 是否支持渠道定制箱规和标签？
8. 不同季节产区切换后，规格是否变化？

## 四、验收时最实用的分级判断

你可以用这张简表现场判断：

| 渠道 | 优先规格 | 成熟度 | 外观要求 | 箱规倾向 |
|---|---|---|---|---|
| 精品商超 | 中果、均匀 | 微黄 | 高 | 5kg/10kg |
| 社区水果店 | 中果、小果 | 青蕉/微黄 | 中 | 4.5kg/5kg/10kg |
| 批发市场 | 大果、混级可控 | 青蕉 | 中低 | 10kg以上 |
| 电商到家 | 小果、中果 | 黄熟/微黄 | 中高 | 1-5kg |
| 餐饮加工 | 大果、熟蕉 | 全熟 | 低 | 大箱 |

## 结论

佳农香蕉的具体规格数，**不能用一个固定数字回答**，通常按“单根大小 + 箱重 + 梳数 + 成熟度”组合出多种渠道规格。  
如果用于采购，最稳妥的做法是：**向佳农当地经销商索取当季规格表、成熟度标准和验收标准**，再按你的渠道选择“中果+微黄+5kg/10kg”这类常规组合；批发走“青蕉+大箱规”，电商走“小规格+黄熟/微黄”，餐饮走“大果/熟蕉+大箱规”。
