可以，但“专岗对接人”要先分清是佳农官方给，还是你们通过经销商/批发渠道拿到。佳农这种品牌香蕉通常走的是区域经销、商超配送或大型批发渠道，不一定每个水果连锁店都能直接拿到厂家专属对接人。

建议你按下面方式推进，最快能判断有没有专岗：

1. **先确认采购渠道**
   - 如果你们是直接找佳农当地分公司/办事处：可以要求区域销售负责人 + 订单客服双人对接。
   - 如果通过经销商拿货：要求经销商指定固定业务员，并给备用联系人。
   - 如果是批发市场档口：一般没有厂家专岗，只能要求档口固定对接人。

2. **直接提明确要求**
   联系时不要只问“有没有对接人”，直接发：
   - 我们门店数量、城市、预计月采购量、单次起订量
   - 要求：固定销售对接人 + 固定订单/售后对接人
   - 响应时限：询价/下单/到货异常分别多久回复
   - 缺货、跳票、质量问题处理时限

3. **用采购量换响应优先级**
   佳农这类品牌对稳定大客户才会配专人。你可以承诺：
   - 月度框架量
   - 固定下单周期
   - 集中配送地址
   - 按时结算
   这样更容易拿到专岗或优先响应。

4. **合同/订单里写进响应条款**
   比如：
   - 对接人姓名、电话、微信，变更需提前通知
   - 工作日询价2小时内回复，订单确认4小时内回复
   - 到货异常24小时内处理
   - 连续响应超时可有替换对接人或补偿机制

5. **如果佳农当地没有专岗**
   就找一级经销商，要求对方配专属业务。很多经销商为了锁客户，愿意给连锁店配固定对接人。
