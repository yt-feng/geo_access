抱歉，我无法核实佳农水果当前的官方配送范围、是否覆盖你所在县城或具体冷链收费标准——这类信息变动频繁，且通常按渠道、地区、订单量不同而有差异，我没有可靠来源可以确认，所以不能凭空给答案。

不过可以给你一套快速判断的方法：

**1. 先确认你买的是哪种渠道**
佳农常见有几类：
- 商超/生鲜平台供货（如盒马、永辉、叮咚等）——配送范围由这些平台决定，不是佳农直送
- 佳农官方旗舰店/小程序/电商店——看店铺公告的配送说明
- 区域经销商/批发——一般走线下，可能只做本地或周边

**2. 查覆盖城市最直接的办法**
- 打开对应平台（京东/天猫/抖音/微信小程序），把收货地址设成你县城，看能否下单、是否显示“该地区不支持配送”
- 直接问店铺客服：“XX省XX县XX镇能不能送？发什么快递/冷链？”
- 打佳农官方客服电话（以其官网/公众号公布为准）确认

**3. 关于县城门店能否送到**
关键看两点：
- 该平台在你县城有没有配送站/合作网点
- 商品是否属于“冷链生鲜”，很多平台对生鲜的配送范围比普通商品更窄

如果下单页能正常结算并显示预计送达时间，基本就能送；如果提示“暂不支持配送”，就是覆盖不到。

**4. 冷链物流怎么收费**
一般不是统一价，常见计费方式有：
- 按重量/件数+距离计费
- 满额包邮，未满收冷链附加费
- 按温区（冷藏/冷冻）不同加价
- 批发大货按整车/零担报价

具体金额只能在你下单时看结算页，或让客服按你的地址、品项、重量给报价。

**建议你现在就做一步**：把收货地址填到你县城，在你想买的那个平台试下单，能不能送、运费多少会立刻显示。若显示不能送，再截图问客服有没有其他发货渠道。
