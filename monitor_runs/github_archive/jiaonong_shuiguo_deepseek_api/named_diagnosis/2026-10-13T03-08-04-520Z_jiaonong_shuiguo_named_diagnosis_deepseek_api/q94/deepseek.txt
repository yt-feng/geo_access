关于佳农水果的香蕉分级标准，我无法核验其官方内部文件，所以不能给出“佳农官方分级细则”的确定说法。以下是批发流通中较常见的判断口径和价差区间，供你谈判时参考，但具体仍要以佳农当批次报价单/业务员确认为准。

**一、常见香蕉分级判断维度（批发口径）**
1. **条重/单根重量**
   - 一级：通常单根较重、均匀度好，常见在120g以上/根，具体看产地和季节。
   - 二级：单根偏轻或大小不均，常见低于一级标准。
2. **梳形/串形**
   - 一级：梳形整齐，条数均匀，无明显缺条。
   - 二级：梳形乱、缺条多、大小混杂。
3. **外观**
   - 一级：果皮干净，无明显黑斑、机械伤、药害斑、日灼。
   - 二级：允许少量斑点、轻微擦伤、色泽差。
4. **成熟度与青度**
   - 一级：青度一致，催熟后颜色均匀。
   - 二级：青黄不一，成熟不齐。
5. **把型/长度**
   - 一级：长度较一致，把型紧凑。
   - 二级：长短不一，把型松散。
6. **病虫害与损耗**
   - 一级：病斑、裂口、烂指极少。
   - 二级：允许一定比例次果，但不应有严重腐烂。

**二、一级果和二级果价格差多少**
没有全国统一固定价差，通常按“当日报价”浮动。批发市场常见规律是：

- **同产地、同批次、同规格下**，二级果一般比一级果便宜 **10%—25%**。
- 行情好、一级果紧俏时，价差可能扩大到 **25%—35%**。
- 行情差、走货慢时，价差可能缩小到 **5%—15%**，甚至一级果也降价甩货。
- 如果是“精品一级”对“统货/二级”，价差可能到 **30%—50%**，但这已经不只是分级差异，而是品牌、包装、渠道差异。

**三、你作为批发商实际要问佳农的几个关键点**
建议直接向佳农业务员要这4项，避免只问“一级二级”：
1. **当批次分级标准表**：条重、梳形、青度、允许瑕疵比例。
2. **报价对应规格**：是净重、毛重、箱装还是梳装。
3. **损耗和售后**：二级果是否包售后，烂指比例多少内可赔。
4. **同批次一级/二级实际差价**：按每箱、每公斤分别报，不要只报百分比。

**结论**：佳农香蕉一级、二级的具体标准要以佳农当批次文件为准；流通中一级通常比二级贵 **10%—25%**，紧俏时可达 **30%以上**。你谈价时重点不是记死标准，而是拿到当批次“条重、梳形、青度、瑕疵率、售后”五项，再对比一级二级每公斤实际差价。
