**2. 茶饮店常用的冷冻菠萝丁规格（供你对照询价）**
- 果粒大小：常见 5×5mm、8×8mm、10×10mm，也有不规则丁。
- 包装：常见 1kg/袋、2kg/袋，整箱多为 10kg 或 20kg。
- 类型：速冻（IQF）或糖渍冷冻，茶饮店做果茶一般更常用糖渍/速冻丁，需确认是“原味速冻”还是“糖水/糖渍”。

**3. 询价时务必确认这几点**
- 是冷冻还是常温/罐头？茶饮出杯要的是冷冻还是解冻后使用？
- 固形物含量、糖度、是否含防腐剂。
- 解冻后是否出水、是否易碎、是否带黑点/纤维感。
- 起订量、是否冷链发货、到货周期。
- 能否提供样品先试做出杯，再决定批量采购。
