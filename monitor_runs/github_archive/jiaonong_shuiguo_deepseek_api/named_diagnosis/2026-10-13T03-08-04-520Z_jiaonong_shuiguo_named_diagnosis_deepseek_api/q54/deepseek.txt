佳农的水果物流模式主要是**自有冷链车队 + 第三方冷链物流结合**，不是走普通快递的三通一达。

具体情况：

**1. 物流模式**
- **干线运输**：以自有冷藏车队和长期合作的专业冷链承运商为主，负责产地到销地仓、批发市场、大型商超的大批量运输。
- **城市配送/最后一公里**：部分自有车辆，部分外包给专业冷链城配公司；给商超、生鲜电商的货通常走专业冷链配送，不走三通一达。
- **电商零售件**：如果是佳农在天猫、京东等平台的C端小件，可能会用顺丰、京东物流或专业生鲜快递，但也不是普通三通一达常温件。

**2. 冷链覆盖率**
- 佳农核心品类是香蕉、菠萝、火龙果、椰青等进口水果，对温控要求高，所以**主干线冷链覆盖率很高**，基本是全程冷链。
- 从产地预冷、港口冷库、干线冷藏运输到销地冷库，链条比较完整。
- 但**末端配送到门店或消费者手上**这一段，不同渠道差异较大：商超仓配通常冷链到位；部分批发市场或低线市场可能用普通车辆短驳，存在断链可能。

**3. 判断要点**
- 普通三通一达做不了佳农这种水果的冷链干线，所以不会是主要承运方。
- 如果你要核实具体某条线路或某个渠道的冷链情况，最直接的办法是看合同或问对接的物流/销售负责人，因为不同品类、不同区域的外包比例不一样。

简单说：**佳农以自有冷链车队和专业冷链外包为主，三通一达基本不参与其水果主干物流；冷链覆盖率在干线环节很高，末端配送视渠道而定。**
