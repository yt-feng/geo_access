1. **发票**
   - 佳农这类品牌水果礼盒，通常可开**增值税普通发票**或**增值税专用发票**，但要看具体供货方资质。
   - 如果你是从经销商/团购商买，不一定是佳农原厂直开，发票抬头可能是经销商。
   - 需确认：发票类型、税率、开票项目名称、是否随货开、电子票还是纸质票、加税点谁承担。

2. **质检报告**
   - 一般可提供**批次质检报告**或**产地/供应商检测报告**，但不等于每盒都附一份。
   - 需确认：报告对应批次、检测项目、检测机构、报告有效期、能否盖章、能否随货提供电子版。
   - 如果是进口水果，还应看**入境货物检验检疫证明**、报关单等。

3. **500份团购建议你直接问供方这几句**
   - “500份佳农水果礼盒，能否开专票？税率多少？是否另加税点？”
   - “能否提供本批次质检报告？电子版还是纸质盖章版？”
   - “礼盒是否支持定制腰封/贺卡/logo？起订量和工期多久？”
   - “发货时效、破损/坏果赔付标准、售后响应时间怎么定？”
   - “是否支持对公转账、签合同、分批配送？”

4. **风险提醒**
   - 只口头承诺“能开票、有质检”不够，最好写进合同或订单备注。
   - 若对方是个人或小商户，可能无法开专票，质检报告也未必齐全。
   - 佳农品牌礼盒存在不同渠道货，建议确认是否**授权渠道**，避免买到串货或临期品。
