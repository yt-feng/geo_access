“佳农水果”通常指**佳农食品控股（集团）股份有限公司**及其关联公司，业务以香蕉、菠萝等进口水果为主。给商超、电商、批发市场的供货账期没有统一公开标准，通常按客户类型和合作规模谈判确定。

**一般账期情况（行业惯例，非佳农官方统一政策）：**
- 大型商超、连锁卖场：常见 **30–60 天**，部分强势渠道可能 **60–90 天**。
- 电商平台、社区团购：常见 **15–45 天**，视平台结算规则。
- 批发市场、区域经销商：常见 **现款现货、7–15 天或月结**，信用好的老客户才可能放账。
- 新客户、小客户：多数要求 **现款现货、款到发货或预付定金**，较难直接拿到长账期。

**新客户能否申请账期：**
可以尝试申请，但通常不是“一上来就给”。一般需要：
1. 提供营业执照、食品经营许可等资质；
2. 有稳定采购量和回款记录，先做几单现款；
3. 通过对方信用评估，可能要求保证金、担保或缩短账期；
4. 由业务员或区域负责人向公司申请授信。

**建议直接确认：**
佳农各区域、各渠道的销售政策不同，最准确的是联系对接的**佳农区域销售/大客户经理**，直接问：首单结算方式、是否支持账期、账期天数、授信条件。不要只按网上说法判断，因为生鲜行业账期弹性很大，最终以合同为准。
