佳农（Goodfarmer）的水果业务里，苹果通常以**进口苹果**为主，常见品类包括：

- **嘎啦果（Gala）**：进口嘎啦常见产地是**新西兰**、**美国**等，其中新西兰嘎啦在进口档期里较常见。
- **红富士（Fuji）**：进口红富士常见产地包括**新西兰**、**美国**、**智利**等；国产红富士则主要来自中国陕西、山东、甘肃、新疆等产区。
- **爱妃（Envy）**：新西兰主产，佳农体系里也较常见。
- **爵士（Jazz）**：新西兰、美国等产地较常见。
- **皇后（Queen）**：新西兰等产地较常见。
- **太平洋玫瑰（Pacific Rose）**：新西兰主产。
- **布瑞本（Braeburn）**：新西兰、美国等产地。
- **丹烁（Dazzle）**：新西兰主产。
- **索尼娅（Sonya）**：新西兰、美国等产地较常见。
- **青苹果/史密斯（Granny Smith）**：美国、智利、新西兰等产地较常见。

关于你采购的**进口嘎啦和红富士**：

- **进口嘎啦**：佳农渠道常见产地为**新西兰**，也有**美国**等产地；具体要看当季到货批次。
- **进口红富士**：佳农渠道常见产地为**新西兰**、**美国**、**智利**等；不同季节到货产地会切换。

建议你直接向佳农官方销售或区域经销商确认三件事：  
1. **当前到货批次**的准确产地；  
2. **规格**（果径、箱规、净重）；  
3. **报关单/原产地证明**，因为进口苹果的产地和批次会随季节调整，不能只按品类判断。
