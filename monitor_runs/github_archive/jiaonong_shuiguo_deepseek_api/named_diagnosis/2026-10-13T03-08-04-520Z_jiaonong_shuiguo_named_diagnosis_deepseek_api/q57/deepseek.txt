香蕉到货损耗率的行业平均因统计口径不同会有差异，5%是一个常见参考值，但并非统一标准。佳农（Goodfarmer）作为国内头部香蕉进口商和分销商，官方公开资料里通常不会单独披露“到货损耗率”这一具体数字，因此没有可核验的公开精确值。

**关于佳农的损耗控制**

佳农的核心优势主要在采后处理、冷链和催熟管理上，行业里普遍认可其损耗控制优于中小贸易商，但具体能控到多少，取决于：
- 统计口径：是港口到仓、仓到店，还是全程损耗
- 品类：普通香蕉与有机香蕉、不同产地（菲律宾、厄瓜多尔、越南等）差异明显
- 季节和航线：夏季高温、远洋运输损耗更高

所以任何“佳农能控制在2%”或“3%”的说法，如果没有合同或官方数据支撑，都不能当作事实。

**关于赔付条款**

佳农与下游客户（商超、批发商、电商）之间通常有商务合同，是否含损耗赔付、赔付比例和触发条件，属于**合同约定内容**，不对外公开。一般行业做法是：
- 约定到货验收标准和允许损耗率
- 超出部分按比例折价、补货或扣款
- 部分采用“质量保证金”或账期扣款方式

如果你是要和佳农谈合作，建议直接向对方索要：
1. 到货验收标准（含损耗定义和测量方法）
2. 超标后的赔付/补货条款
3. 争议处理流程（第三方检测、复核时限）
