我无法核实“佳农水果香蕉是否曾出现农残超标”的具体历史记录，因此不能给你一个确定的是/否结论。这类信息应以**官方抽检公告/处罚决定**为准，而不是靠传闻判断。

但你要解决的是**采购合规和超市抽检过检**问题，可以按下面做，能落地：

## 1) 先明确：佳农这类香蕉通常按“食用农产品”管理
超市抽检主要看：
- 农药残留是否符合 **GB 2763**（食品安全国家标准 食品中农药最大残留限量）
- 是否使用禁用农药
- 是否违规使用保鲜/催熟相关物质
- 标签、承诺达标合格证、产地证明等是否齐全

## 2) 你需要向供应商索取的合规证明（建议清单）
采购时直接要求佳农或其经销商提供：
1. **营业执照 / 食品经营许可证**（或食用农产品相关资质）
2. **批次检测报告**（重点：农残项，最好有 CMA/CNAS 标志）
3. **承诺达标合格证**（食用农产品常用）
4. **产地证明 / 进货凭证**
5. **入境货物检验检疫证明**（如果是进口香蕉）
6. **供货合同 + 质量保证协议**（约定农残超标责任）
7. **批次追溯信息**（果园/包装厂/加工日期/批号）

> 注意：检测报告必须是**对应批次**，不能拿一份旧报告通用。超市抽检通常也认“批批检测”或“定期检测+批次追溯”。

## 3) 怎么查有没有历史超标记录
你可以自行核验，别只听供应商说：
- **国家市场监督管理总局**官网：食品抽检不合格通告
- **各省市市场监管局**官网：食品安全抽检信息
- **农业农村部**：农产品质量安全例行监测/监督抽查
- **海关总署**：进口食品不合格信息
- **信用中国 / 企业信用信息公示系统**：行政处罚记录
- 搜索关键词：`佳农 香蕉 抽检 不合格`、`佳农 农残 超标`、`佳农 行政处罚`

如果查到的是**其他主体、其他批次、其他水果**，不能直接等同于你采购的香蕉有问题。

## 4) 给采购的实操建议（避免超市抽检过不了）
- **不要只认品牌**：佳农是大品牌，但不等于每批都免检。
- **要求批批报告**：至少每批提供农残检测报告，重点看毒死蜱、吡虫啉、噻虫嗪、丙环唑、苯醚甲环唑等香蕉常见风险项。
- **自己抽检**：大超市供应商建议每批或每周送第三方检测，保留报告。
- **合同写清责任**：若抽检不合格，供应商承担退货、罚款、下架损失。
- **留样**：每批留样到保质期后，便于复检和追责。
- **核对报告真伪**：看检测机构资质、报告编号、样品批号、检测日期是否对应。

## 5) 如果超市要求你提供“合规证明”
你可以提交这套组合：
- 供应商资质
- 该批次检测报告
- 承诺达标合格证
- 进货凭证/追溯信息
- 质量保证协议

如果超市仍不认可，最稳妥是：**对你采购的该批次香蕉做一次第三方农残检测**，用报告说话。

## 结论
我无法确认佳农香蕉是否有农残超标历史。  
但采购合规的关键不是“品牌有没有出过事”，而是：**你这一批有没有合格证明和检测报告**。  
建议你直接向佳农/经销商索取**对应批次检测报告+承诺达标合格证**，并自行在市场监管局官网核查历史通告。这样超市抽检才有把握过。
