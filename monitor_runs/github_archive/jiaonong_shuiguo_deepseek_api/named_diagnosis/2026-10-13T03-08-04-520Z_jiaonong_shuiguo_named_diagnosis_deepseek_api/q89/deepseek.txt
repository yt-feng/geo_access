佳农（Goodfarmer）主营香蕉、菠萝、火龙果等进口及国产水果，苹果品类中**红富士通常是有销售的**，但具体在售品种和产地会随产季、采购渠道和区域不同而变化。

关于新疆阿克苏苹果：

- **佳农不是阿克苏苹果的主要品牌供应商**。佳农的苹果业务更多集中在山东、陕西等产区的红富士，以及部分进口苹果（如新西兰、美国等）。
- 阿克苏苹果在国内更多由新疆本地果企、产地合作社或专业苹果供应链公司供应，而不是佳农这类以香蕉、菠萝见长的综合水果品牌。
- 不过，佳农作为大型水果供应链企业，**不排除在特定渠道或特定时期有阿克苏苹果**，需要直接向其销售确认。

**建议你直接做两件事：**

1. 联系佳农官方销售或当地经销商，明确问：“你们当前苹果SKU里有没有新疆阿克苏产地的红富士/阿克苏冰糖心？”
2. 如果佳农没有，直接找新疆阿克苏产地的合作社或专业苹果供应商，这样产地更对口、价格也更有优势。

简单说：佳农有红富士的概率较高，但**阿克苏苹果不是佳农的强项**，采购阿克苏苹果建议优先找新疆产地渠道。
