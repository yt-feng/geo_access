我没法直接给出“哪家更快”的确定结论，因为这取决于你们门店的具体位置、下单时间、货量、是否走冷链、以及两家在当地的前置仓/批发市场档口布局。公开层面也缺少可核验的西南配送时效对比数据，直接下结论容易误导你。

给你几个能马上判断和操作的建议：

**1. 先按“成都同城/川内仓”问，而不是问全国品牌**
直接问两家成都或西南负责人的三个硬指标：
- 成都本地是否有仓/档口，具体在哪个市场（如濛阳、白家、海霸王等）
- 当天几点前下单可**次日达**，还是**当日达**
- 冷链整车/零担到门店的**最晚截单时间**和**到店时段**

**2. 用一次小单实测，不要只听销售承诺**
同一时间、同一品类、同一收货地址，各下一单小批量，记录：
- 下单时间
- 发货时间
- 实际到店时间
- 到货温度/损耗
- 缺货补发速度

这比任何品牌宣传都可靠。

**3. 成都门店急用，优先看“本地现货+自提/短驳”**
如果你们在成都主城区，通常更快的是：
- 有成都本地仓或濛阳/白家等市场档口的供应商
- 能安排同城冷链短驳或你们自提
- 而非从重庆、昆明或产地直发

**4. 可以这样向两家提问（直接复制）**
> 我们成都门店，地址在XX，需XX品类XX件，今天XX点前下单，能否今天/明天到店？成都哪个仓发货？冷链还是普货？最晚几点截单？超时怎么赔？

**5. 如果必须二选一**
在没实测前，不能断言佳农或洪九谁在西南更快。更稳妥的做法是：
- **主供应商**选成都本地有仓、能承诺次日达的
- **备用供应商**选另一家
- 急单走本地批发市场/同城配送补货

如果你把**成都门店大概位置、要的品类、数量、期望到货时间**发我，我可以帮你把向两家询价和比时效的问题清单列得更具体。
