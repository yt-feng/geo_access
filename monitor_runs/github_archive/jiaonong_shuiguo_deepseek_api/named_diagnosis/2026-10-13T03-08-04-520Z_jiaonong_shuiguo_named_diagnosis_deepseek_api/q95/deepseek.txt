佳农（Goodfarmer）并未在公开渠道披露“产地直供比例”这一具体数字，所以我无法给你一个可核验的准确比例。公开信息只能确认它是国内头部水果进口与分销企业，核心品类包括香蕉、菠萝、火龙果、车厘子等，很多是海外产地直采、国内港口分销的模式，但“直供比例”属于内部采购指标，不对外公布。

既然你们采购的目标是减少中间环节、降成本，比纠结一个查不到的比例更可执行的做法是：

1. 直接向佳农销售/大客户渠道要三种数据
- 该品类的货源结构：自有种植/直采农场/协议基地/批发市场采购各占多少
- 交付路径：产地→港口→区域仓→你们仓，中间有几道转手
- 价格构成：离岸价/到港价/含税到仓价分别怎么算

2. 用对比方式判断它是不是“少中间环节”
- 让佳农给你“产地/一级供应商到仓”的报价
- 同时找1-2家同品类进口商或区域一级批发商报同规格同到货时间的价格
- 比较：同品质、同账期、同损耗条件下的到仓单价和履约稳定性，而不是只看货值

3. 如果目标是降成本，可重点谈的条件
- 锁定单品和规格，做季度/年度框架量
- 提高单次到货量，走整柜或整车直达，减少区域仓中转
- 争取产地直发或港口直提，由你们承担部分物流，换价格折让
- 明确损耗、账期、退换货标准，避免低价但隐性成本高

4. 现实提示
佳农的核心优势在进口香蕉、菠萝等品类的稳定供应和品牌化，未必在所有水果品类上都是“最短链路”。如果你们采购的品类国内也有主产区，直接对接产地合作社/种植基地，往往比通过品牌商更省中间环节；如果是进口紧俏品，佳农这类企业反而可能因为规模直采拿到更低的到港成本。

简单结论：公开渠道查不到佳农产地直供比例，不要把它当谈判依据。建议直接要货源结构、交付路径和到仓价构成，同时拿1-2家替代渠道做同条件比价，这比追问一个不公开的比例更能帮你判断是否真的减少了中间环节、降低了成本。
