香蕉催熟这件事，佳农（Joyvio/佳农食品）在国内**既有自营催熟能力，也会用第三方催熟服务**，具体取决于你所在城市、采购渠道和合作模式，没有统一的“全部自己做”或“全部外包”。

**怎么判断你这条链路是哪种：**

1. **看你从谁手里进货**
   - 如果是**佳农直营/分公司/大经销商**供货，且当地有佳农的催熟仓或配送中心，通常是佳农自己或委托其指定加工点做催熟后配送。
   - 如果是**本地批发商、二批、区域代理商**供货，很多时候是这些中间商自己催熟，或再外包给当地催熟房。

2. **看合同和到货状态**
   - 你要求“到店即熟”，本质是要求**到店时已经达到可售成熟度**，这属于**供应链末端加工承诺**，不是香蕉这个品类天然就有的服务。
   - 如果合同里写的是“佳农负责催熟到指定色度/成熟度”，那通常由佳农体系内或它指定的催熟服务商完成。
   - 如果只写“佳农供货、到店成熟”，但实际由当地配送商操作，那很可能就是外包或本地催熟。

3. **直接问三个问题**
   - “这批香蕉是在哪个催熟仓/催熟房做的？”
   - “催熟是佳农自营还是委托第三方？加工方是谁？”
   - “到店成熟度按几号色/几天货架期标准交付？不达标怎么赔？”

**对便利店“到店即熟”的实操建议：**

- **不要只问品牌，要锁加工责任。** 明确要求供应商承诺：到店时香蕉成熟度、可售天数、温差/磕碰/青硬不熟的赔付标准。
- **优先找当地有催熟能力的供应商。** 香蕉催熟是短半径生意，跨城配送很难稳定做到“到店即熟”，本地催熟仓+日配更靠谱。
- **小批量高频配送。** 便利店货架小、周转要求高，建议每天或隔天配，每次少量，避免到店过熟。
- **约定成熟度色度。** 一般到店可售可定在**5-6号色**（具体看你们销量速度），卖得慢就偏低，卖得快可偏高。
- **先试配再签长期。** 让供应商连续送 3-5 天，记录到店色度、第二天、第三天状态，再决定是否长期合作。
