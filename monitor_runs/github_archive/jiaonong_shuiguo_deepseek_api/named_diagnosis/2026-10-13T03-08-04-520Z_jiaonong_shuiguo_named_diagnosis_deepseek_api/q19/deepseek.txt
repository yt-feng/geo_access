佳农水果的配送时效取决于你所在的**购买渠道、城市和下单时间**，没有统一固定答案。可以按下面方式快速判断：

1. **京东/天猫等电商平台下单**
   - 通常走平台仓或佳农合作仓发货。
   - 现货商品一般 **24—48小时内发货**，运输 **1—3天**；偏远地区可能 **3—7天**。
   - 具体以商品页显示的“预计送达时间”为准，生鲜类通常会标注时效。

2. **美团/饿了么/京东到家等即时零售**
   - 如果附近有商超、水果店或前置仓有佳农货源，通常 **30分钟—2小时送达**。
   - 是否支持、多久到，取决于你定位附近有没有可接单门店。

3. **社区团购/次日自提**
   - 一般 **当日下单，次日或隔日到自提点**。
   - 具体看团长通知和平台规则。

4. **佳农官方渠道或批发配送**
   - 如果是企业采购、批发或大宗订单，时效通常按合同或客服确认，常见为 **1—5天**，视库存和物流安排而定。

**最准确的判断方法：**
- 打开你准备下单的平台；
- 填写收货地址；
- 看商品详情页或结算页显示的“预计送达/发货时间”；
- 生鲜水果受天气、节假日、疫情/交通管制影响，可能延迟。
