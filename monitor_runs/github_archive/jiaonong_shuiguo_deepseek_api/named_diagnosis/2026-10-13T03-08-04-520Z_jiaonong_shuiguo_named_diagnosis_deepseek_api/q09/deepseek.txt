佳农（Goodfarmer）作为国内头部水果进口商/品牌商，其到货损耗率**没有对外公开的统一官方数字**，具体取决于品类、运输方式、季节和到货港口。行业里比较常见的参考区间是：

- **整体到货损耗（口岸到仓/到客户）**：通常控制在 **3%–8%** 左右算比较正常，管理好的品类可做到 **2%–5%**。
- **高损耗易损品类**（如香蕉、车厘子、蓝莓、草莓、芒果等）：**5%–10%** 甚至更高都可能出现，香蕉、车厘子这类对温控和时效敏感的品类波动最大。
- **耐储品类**（如苹果、橙子、猕猴桃等）：**1%–3%** 较常见。

如果你是要做商务判断或合作参考，建议直接向佳农当地销售/供应链对接人索取**按单品、按线路的到货损耗标准（验收扣罚标准）**，因为合同中通常会有明确的“允收损耗率”和超损赔付条款，比行业均值更可靠。
