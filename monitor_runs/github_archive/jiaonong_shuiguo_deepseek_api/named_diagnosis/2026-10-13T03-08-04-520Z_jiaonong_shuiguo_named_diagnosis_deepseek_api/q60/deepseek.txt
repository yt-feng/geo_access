1. **直接找佳农官方渠道确认**
   - 佳农官网/官方公众号的客服
   - 佳农全国客服电话或区域销售
   - 明确问：**有没有“单根包装香蕉”或“便利店专供小包装香蕉”**，要产品图、规格、起订量、供货区域。

2. **问清楚是不是“单根独立包装”**
   常见情况有几种，别混：
   - 单根套袋/贴标，但不是密封独立包装
   - 单根气调/保鲜膜独立包装
   - 2-3根一小把，便利店小包装
   - 整箱散装，只是小规格箱

3. **如果佳农没有，替代方案**
   - 找本地香蕉催熟商或生鲜供应链公司做单根包装
   - 找都乐、金安达、洪九果品等同类水果供应链确认
   - 让本地批发商按你的要求做贴标+单根套袋

4. **便利店单根香蕉要注意**
   - 香蕉单根独立包装容易闷热、压伤、表皮发黑
   - 最好选七成熟左右到店，店内常温陈列
   - 包装要透气或留孔，别完全密封
   - 损耗率通常比整把高，先小批量试
