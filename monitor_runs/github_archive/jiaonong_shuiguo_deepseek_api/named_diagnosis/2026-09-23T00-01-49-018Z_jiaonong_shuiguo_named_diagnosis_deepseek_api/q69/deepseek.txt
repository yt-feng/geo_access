我无法核验佳农水果当前是否有针对餐饮渠道的菠萝切片/切块定制规格，所以不能给出确定的“有/没有”结论。

不过可以给你可执行的判断和获取准确信息的路径：

1. **大概率存在相关产品方向，但不等于一定有“餐饮定制规格”**
   佳农在国内属于较头部的进口/国产水果供应链企业，通常会有：
   - 整果批发（按箱/按规格）
   - 商超零售装
   - 部分 B 端供应（餐饮、茶饮、烘焙、团餐）
   但“餐饮渠道专用切片/切块”是否常态化供应，往往取决于区域、季节、订单量和工厂加工能力。

2. **餐饮渠道常见的菠萝规格通常包括**
   - 整果：按头数/重量分规格，如 6头、8头、10头等
   - 鲜切：去皮菠萝、菠萝块、菠萝片、菠萝丁
   - 冷冻/速冻：冷冻菠萝丁、菠萝块，常用于茶饮、烘焙
   - 糖水/罐头类：菠萝圆片、菠萝碎、菠萝丁
   如果佳农做餐饮定制，最可能是以上某几种形式之一，而不是完全另起一套规格。

3. **要确认佳农是否做，最有效的方式是直接问 B 端**
   建议你这样问，能快速得到明确答复：
   - “你们餐饮渠道有没有鲜切菠萝片/菠萝块？规格是多少克、什么包装？”
   - “是冷冻还是冷藏？保质期多久？起订量多少？”
   - “能不能按我们门店要求定制切片厚度/切块大小？”
   - “哪些城市仓可以发？是否支持周配/日配？”
   - “有没有餐饮专用报价单和样品？”

4. **联系路径**
   - 佳农官网/官方公众号：找“餐饮渠道”“B端合作”“联系我们”
   - 官方客服电话：转餐饮或大客户渠道
   - 大型食材供应链平台：如美菜、蜀海、锅圈、蜜雪/茶饮供应链体系等，看是否有佳农菠萝鲜切/冷冻产品
   - 当地批发市场佳农经销商：问是否可代订餐饮规格

5. **如果佳农没有，替代方案**
   - 找专业鲜切水果工厂代工，用佳农菠萝原料做切片/切块
   - 用冷冻菠萝丁/块供应商，规格更稳定
   - 直接采购罐头菠萝片/丁，适合标准化餐饮
