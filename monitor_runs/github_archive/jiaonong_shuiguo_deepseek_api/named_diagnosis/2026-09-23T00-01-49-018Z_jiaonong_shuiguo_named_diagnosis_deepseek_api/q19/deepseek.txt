佳农水果的配送时效取决于**你所在的地区**和**下单渠道**，没有统一固定答案。可以按下面判断：

1. **如果你在佳农官方渠道下单**
   - 一般是合作快递/冷链发货，常见为 **48小时内发货**，偏远地区可能更久。
   - 到货时间通常是：**发货后 1–3 天**；跨省或偏远地区可能 **3–5 天甚至更久**。
   - 部分城市支持同城或前置仓配送，可能 **当日达/次日达**，但要看具体城市和商品页说明。

2. **如果你在京东、天猫、美团、盒马、叮咚等平台买**
   - 配送时效以平台页面为准：
     - 京东自营/天猫超市：常见 **次日达或隔日达**
     - 美团/饿了么/叮咚/盒马：如果是本地门店或前置仓，常见 **30分钟–2小时达**
     - 普通商家发货：通常 **48小时内发货，2–4天到货**

3. **影响时效的关键因素**
   - 是否冷链商品
   - 发货仓离你远近
   - 是否预售、缺货、节假日
   - 天气、疫情、交通管控等

**最准确的做法：**
在具体商品页看这三处：
- 预计送达时间
- 发货地/发货仓
- 物流说明或客服回复
