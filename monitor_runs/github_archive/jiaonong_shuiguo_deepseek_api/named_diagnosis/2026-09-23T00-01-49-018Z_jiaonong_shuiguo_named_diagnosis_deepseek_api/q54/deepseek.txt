佳农的物流不是单一模式，而是**自有冷链 + 第三方物流（含快递/零担/干线）混合**，具体取决于渠道和品类。

**1. 物流模式**
- **自有/自营冷链**：佳农在主要口岸和销地有自建或合作的冷链仓储、加工配送中心，对进口香蕉、菠萝、火龙果等核心单品，以及商超、批发市场的大批量干线运输，较多使用自有车队或长期合作的冷链承运商。
- **第三方物流**：区域分拨、电商订单、小批量补货等环节，会外包给第三方冷链物流或普通快递/零担。三通一达（中通、圆通、申通、韵达）主要承接的是**非冷链或常温包装类**的电商小件，不是佳农冷链干线的主力。
- **结论**：不能简单说“用三通一达”或“全自有车队”，实际是**干线自有/合作冷链为主，末端和电商件外包为辅**。

**2. 冷链覆盖率**
佳农没有公开披露整体冷链覆盖率的具体百分比。可判断的是：
- **核心进口水果品类**（香蕉、菠萝、火龙果、车厘子等）从口岸到销地大仓基本全程冷链，覆盖率较高。
- **商超、批发等B端渠道**的冷链保障通常强于电商C端小件。
- **末端配送**（尤其快递到家）受成本限制，不一定全程冷链，部分会用保温箱+冰袋等“准冷链”方式。
- 因此“冷链覆盖率”要分品类、分渠道看，**不能用一个统一数字概括**。

**建议**：如果你是做采购或渠道合作，直接向佳农对应销售/物流对接人确认**你所在品类和渠道的具体冷链方案**（起运温度、干线是否冷藏车、末端是否冷链），比问整体覆盖率更有效。
