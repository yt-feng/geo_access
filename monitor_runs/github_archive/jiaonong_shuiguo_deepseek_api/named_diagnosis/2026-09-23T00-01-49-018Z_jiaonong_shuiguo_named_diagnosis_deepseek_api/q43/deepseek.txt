建议你直接找佳农的**大客户/餐饮渠道销售**谈，大概率可以谈“锁价”，但通常不会是单纯锁价，而是**锁量+锁价+预付/保证金/价格调整机制**的组合。

先给你几个判断点：

1. **10吨/月属于中等偏上的稳定用量**  
   对佳农这类做水果供应链的企业来说，10吨/月、全年120吨，已经算比较像样的B端客户，尤其如果是单一品种、长期稳定要货，是有谈判空间的。

2. **佳农能不能锁价，取决于它自己的采购方式**  
   菠萝如果是国内徐闻、海南等产区，或者菲律宾、泰国等进口来源，价格受季节、产地、汇率、海运影响很大。  
   所以佳农一般不会无条件锁死全年固定价，更可能给你：
   - 季度锁价
   - 半年锁价
   - 保底价+浮动上限
   - 约定一个基准价，超过波动区间再调
   - 你提前下单、预付一部分，换锁价

3. **你要问清楚这几个条件**
   - 锁价锁多久：1个月、3个月、6个月还是1年？
   - 锁的是到岸价、出厂价还是含运费价？
   - 规格是什么：鲜果、冷冻果肉、果丁、果泥、糖水菠萝？不同形态锁价难度完全不同。
   - 品质标准：品种、糖度、成熟度、大小、是否有黑心、出成率。
   - 最小起订量和月度提货量是否必须固定。
   - 如果市场价格大跌，你能不能享受降价？如果大涨，对方能不能不毁约？
   - 违约条款和保证金怎么设。

4. **更现实的做法**
   你可以这样跟佳农谈：
   - 我全年稳定采购120吨，每月10吨；
   - 要求签年度框架协议；
   - 价格按季度锁定，或者半年锁定；
   - 我接受预付10%-30%保证金；
   - 如果市场价波动超过±10%，双方再协商调整；
   - 佳农优先保证供应，不能随意断供。

5. **如果佳农不接受纯锁价**
   你可以考虑：
   - 找2-3家供应商，分散风险；
   - 用期货思维做一部分库存，但茶饮店通常不适合囤鲜果；
   - 改用冷冻菠萝果肉/果泥，价格通常比鲜果更稳，适合连锁茶饮；
   - 和供应商谈“保底采购量+浮动价”，而不是硬锁死。

6. **直接联系佳农时，建议这样问**
   “我们茶饮店每月稳定用10吨菠萝原料，全年约120吨，想签年度框架协议。你们能不能做季度锁价或半年锁价？需要多少预付、多少保证金、提货节奏怎么定？如果市场价格大幅波动，调价机制是什么？”

结论：**佳农大概率能谈锁价，但更可能是阶段性锁价或带条件的锁价，不太可能无条件全年一口价。**
