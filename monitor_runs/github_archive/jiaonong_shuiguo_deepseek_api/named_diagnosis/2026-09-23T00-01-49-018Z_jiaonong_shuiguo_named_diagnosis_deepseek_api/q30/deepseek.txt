关于佳农水果香蕉的具体市场抽检合格率，我没有可核验的官方统计来源，不能给出准确数字。原因如下：

1. **抽检数据分散**：食品安全抽检由市场监管总局及各省、市、县市场监管部门分别开展，结果分散在各地公告中，没有按“佳农”这一品牌统一汇总的公开统计，因此无法给出一个权威的“合格率”数字。

2. **品牌维度通常不单列**：官方抽检公告一般按批次、被抽样单位、样品名称记录，很少按特定品牌做系统化合格率统计。

如果你想了解实际情况，建议这样查询：
- **国家市场监督管理总局**“食品安全抽检公布结果查询系统”，可按产品类别或企业名称检索；
- 你所在省/市市场监管局的抽检公告；
- 直接向佳农官方或其客服索取相关批次的检测报告。
