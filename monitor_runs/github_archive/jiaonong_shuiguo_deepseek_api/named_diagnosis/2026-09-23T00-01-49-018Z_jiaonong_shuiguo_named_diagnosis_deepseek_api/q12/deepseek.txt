佳农水果的香蕉规格和分级标准并没有一个完全公开、固定的官方"渠道对应表"，实际执行会因产地（菲律宾、厄瓜多尔、越南、柬埔寨等）、季节、批次和客户合同而变化。下面给你一个可判断的框架，但具体数字需要以你手上的佳农报价单/装箱单或直接向佳农区域业务确认。

**一、常见规格维度**

佳农香蕉一般从几个维度定规格：

1. **按单根重量/等级**
   - 常见分级：大果、中果、小果，有的渠道用"号"或字母标注。
   - 每根重量区间会因产地不同，例如部分产品按约 150g 以上/以下分档，但不同批次差异大。

2. **按每箱净重**
   - 常见箱规：约 12kg、13kg、18kg 等（出口/批发常用）。
   - 小包装或电商渠道会有更小规格。

3. **按每箱根数/梳数**
   - 按"梳"（hand）或整箱根数计，方便终端陈列和损耗控制。

4. **按成熟度/催熟状态**
   - 青蕉（未催熟）用于批发、长途运输。
   - 催熟蕉或黄蕉用于商超、电商、即时零售。

**二、不同渠道的分级逻辑（通用经验）**

- **商超/精品超市**：偏好中到大果、外观整齐、无黑斑、梳型完整，成熟度可控，箱规规范。
- **批发市场**：更看重量和性价比，对单根外观容忍度高，常用大箱青蕉。
- **电商/即时零售**：偏好小到中果、单根独立或小包装，成熟度接近可即食，减少运输损伤。
- **餐饮/茶饮/加工**：对规格要求偏松，更看价格、出肉率和稳定供应，常用大果或次级果。
- **出口**：按目的国标准和客户合同，分级最严格，涉及农残、外观、成熟度、箱重等。

**三、建议你直接确认的方式**

1. 找佳农业务或经销商要**当季产品规格表/报价单**，上面通常列明等级、单根重、箱重、根数、成熟度。
2. 明确你要供的渠道，让业务推荐对应等级，而不是自己套通用标准。
3. 如果是长期采购，要求提供**分级验收标准**（外观、重量公差、成熟度、损耗率），写进合同。
4. 首批到货做实测：抽箱称重、数根、量单根重、记录成熟度和损耗，作为后续验收依据。
