佳农（Goodfarmer）以香蕉、菠萝等水果的**鲜果贸易和品牌化销售**为主，公开渠道通常没有“面向茶饮店的菠萝丁定制加工/代工”这类服务承诺。它更可能提供的是：

1. **整果**：如菠萝/凤梨鲜果，按箱或按规格供货。  
2. **部分标准化果品**：如鲜切水果、冷冻水果等，但是否有“菠萝丁”这个具体SKU、能否按你要求的规格（如 5mm/8mm/10mm 丁、糖度、冷冻/冷藏、灭菌方式）稳定供货，需要直接问区域销售或客服确认。

**建议你这样判断和推进：**

- **先问佳农官方渠道**：让销售明确回答是否有“菠萝丁”产品，还是只能整果；如果有，要规格书、配料表、储存条件、保质期、起订量、价格和是否支持定制。  
- **如果没有现成菠萝丁**：问是否接受“整果+代加工”模式。多数水果贸易商不一定自己做切丁，可能会介绍合作工厂，但这不等于佳农官方加工服务。  
- **更匹配的供应商类型**：茶饮店用菠萝丁，通常找**冷冻水果/鲜切水果/果蔬加工厂**更合适，尤其是需要冷冻菠萝丁、糖渍菠萝丁、罐头菠萝丁时。  
- **关键确认项**：丁的大小、冷冻还是冷藏、是否巴氏杀菌、糖度/酸度、是否加糖或护色剂、解冻后出水率、每批稳定性、食品安全资质（SC/出口备案等）。

**结论**：佳农大概率以卖整果或标准化鲜果为主，不一定提供茶饮店所需的菠萝丁加工服务。你要先向佳农官方确认是否有菠萝丁SKU；如果没有，就按“整果供应商”处理，另找专业果蔬加工厂做菠萝丁。
