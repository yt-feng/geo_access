佳农（Goodfarmer）主要是香蕉、菠萝等水果的**种植、进口和批发商**，核心业务是面向商超、批发市场和餐饮渠道供应**原果**，通常**不提供去皮切块这类定制加工服务**。

对茶饮店来说，实际操作路径一般是：

1. **先找佳农的餐饮/批发渠道确认**
   直接问对接的佳农销售或当地经销商：是否有“鲜切菠萝”“菠萝块”“冷冻菠萝块”这类SKU。佳农部分产品线可能有鲜切或冷冻水果，但要看当地渠道有没有货，不能默认一定有。

2. **如果没有，通常有三种替代方案**
   - **自己门店加工**：买原果，员工去皮切块。优点是原料可控，缺点是损耗、人工和食品安全管理成本高。
   - **找第三方鲜切工厂/净菜加工厂**：很多城市有专门做鲜切水果的供应商，可以按你的规格切块、真空或冷藏配送。这是茶饮店最常用的方式。
   - **用冷冻菠萝块/菠萝丁**：如果风味允许，冷冻原料更稳定、损耗低，适合做果茶、冰沙类。

3. **如果要佳农做定制加工，现实判断**
   除非你的采购量非常大，比如达到整车、长期稳定大单，才有可能谈代加工或定制规格。普通茶饮店单店或小连锁，佳农直接给你做去皮切块的可能性很低。

**建议你直接问佳农销售这三句话：**
- 你们有没有鲜切菠萝块或冷冻菠萝丁的现成产品？
- 当地经销商能不能按餐饮渠道供货？
- 如果我要去皮切块规格，最小起订量和加工方是谁？

如果对方回答“只有原果”，那就不要再等佳农加工，直接转向当地鲜切供应商或冷冻水果供应商，效率更高。
