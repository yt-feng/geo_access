佳农（Goodfarmer）是一家中国大型水果进口与品牌运营商，公开信息里通常不会披露“产地直供比例”这种精确运营指标，所以没有一个可核验的统一数字。能确定的是：它的核心模式高度依赖海外产地采购和自有/合作产区，香蕉是其主要进口单品之一。

关于香蕉产地：

- **厄瓜多尔**：佳农较早就做厄瓜多尔香蕉进口，这是其重要来源国之一。
- **菲律宾**：菲律宾香蕉在中国进口香蕉中占比长期较高，佳农也经营菲律宾香蕉。
- **越南**：近年越南香蕉对华出口增长明显，佳农也有相关采购。
- **柬埔寨、老挝、缅甸**：这些东南亚产地也有对华香蕉出口，部分会进入佳农等进口商的供应链。
- **哥伦比亚、哥斯达黎加等**：部分拉美产地也可能出现在其采购体系中，但公众报道不如厄瓜多尔、菲律宾集中。

如果你问“产地直供比例高吗”，更稳妥的判断是：

1. **对外宣传层面**：佳农会强调“产地直采”“全球供应链”，以突出品质和成本控制。
2. **实际运营层面**：大型水果进口商通常不是单一模式，而是“产地直采 + 当地合作包装厂 + 贸易商采购”混合使用，比例会随品类、季节、价格和产地政局变化。
3. **香蕉品类**：香蕉属于高度标准化、规模化的大宗进口品，头部进口商一般会尽量往产地端延伸，但具体直采比例没有公开可核验数据。

所以，不能简单说“很高”或“不高”。如果你需要判断某批佳农香蕉的产地，最直接的方法是看包装箱或标签上的 **原产国** 标识，通常比问品牌整体比例更准确。
