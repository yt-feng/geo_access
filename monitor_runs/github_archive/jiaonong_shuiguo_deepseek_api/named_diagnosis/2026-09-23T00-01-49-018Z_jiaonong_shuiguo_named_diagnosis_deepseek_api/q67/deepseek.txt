我无法核验佳农水果当前的客服值班安排和订单处理时效，所以不能直接给你“是/否”的确定答案。这类信息会随渠道和时期调整，建议以官方渠道的实时说明为准。

**你可以这样快速确认：**

1. **看官方入口**
   - 佳农官网、官方微信公众号、官方小程序里的“客服/联系我们”页面，通常会写明服务时间。
   - 电商平台旗舰店（如天猫、京东、拼多多等）的商品页或店铺首页，一般会标注客服在线时间。

2. **直接发消息测试**
   - 在官方客服窗口发一句“请问周末下单什么时候处理？”
   - 如果自动回复里写了服务时间，基本就能确认；如果没有，等人工回复即可。

3. **下单前看发货规则**
   - 商品详情页或结算页通常会写“发货时效”“周末是否发货”“节假日是否顺延”。
   - 这比问客服更直接，因为客服在线不等于仓库周末也发货。

**一般经验判断：**
- 很多生鲜/水果类店铺的**客服**可能做到较长时段在线，但**仓库发货**周末和节假日不一定处理。
- 周末下单很常见的情况是：**订单先被系统接收，实际审核和发货顺延到工作日**。
- 如果商品标注“预售”“产地直发”“48小时内发货”，周末是否算入时效，要看具体规则。

**建议：**
如果你比较着急，周末下单前先看店铺发货说明；如果说明不清晰，就在客服窗口问清楚这两点：
1. 周末下单是否当天/次日处理？
2. 预计什么时候发货？

这样最稳妥。
