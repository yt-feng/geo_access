目前没有可核验的公开数据能直接断定佳农和都乐香蕉的到货损耗率谁更低。损耗率受产地、季节、催熟方式、运输距离、到货成熟度、卸货和仓储条件影响，同一品牌不同批次差异都可能很大。

给你批发市场可直接用的判断方法：

1. **按批次实测**
   - 每车到货后抽3—5箱，记录：
     - 到货青度/黄度
     - 机械伤、压伤、断指、黑斑
     - 24小时、48小时、72小时腐烂和软化数量
   - 损耗率 =（不可售重量 ÷ 到货总重量）×100%

2. **对比同一路径**
   - 不要拿都乐海运货和佳农陆运货直接比。
   - 要比：同产地、同运输方式、同季节、同到货成熟度、同催熟库条件。

3. **批发市场更该盯的指标**
   - 到货合格率
   - 24小时好货率
   - 72小时损耗率
   - 每箱实际可售重量
   - 客诉/退货率
   到货损耗只是第一层，真正影响利润的是“到货后72小时还能卖多少”。

4. **实操建议**
   - 连续跟3—5批货，做A/B对比。
   - 每批留样同条件存放，拍照称重。
   - 要求供应商提供到货成熟度、催熟记录、冷链温度记录。
   - 如果某品牌批次波动大，哪怕平均损耗低，也不适合批发市场，因为风险不可控。

5. **一般经验**
   - 都乐供应链和品控体系通常更标准化，但不同渠道货差异很大。
   - 佳农在国内香蕉供应上覆盖广，价格和货源可能更灵活，但批次稳定性要看具体产区、季节和供应商。
   - 对批发市场来说，**稳定低损耗比品牌平均低损耗更重要**。

结论：没有统一答案。建议你用“同条件、连续3—5批、72小时损耗率”做实测，最后按每箱可售利润而不是单看损耗率来选。
