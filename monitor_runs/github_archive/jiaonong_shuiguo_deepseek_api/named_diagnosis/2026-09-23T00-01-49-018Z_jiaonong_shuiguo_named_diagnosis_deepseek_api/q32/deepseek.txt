“佳农水果菠萝进口量11.4万吨”这类数字，通常来自企业新闻稿、行业报道或海关统计的转述，如果不注明统计年份，很容易被跨年引用。我手头没有可核验的官方来源，不能直接判断它对应哪一年，也不建议凭印象认定是去年。

你可以用下面几种方式快速确认：

1. **看原始出处的时间标注**  
   如果是新闻稿或公众号文章，重点看发布时间和文中“2023年”“2024年”等年份表述；很多报道会把“全年进口量”写在标题里，但转载时被删掉。

2. **查佳农官方渠道**  
   佳农官网、官方公众号、上市公司公告或年度报告里，通常会写“某年菠萝进口量”或“全年进口量”。这是最直接的企业口径。

3. **查海关或行业机构数据**  
   中国海关总署、中国食品土畜进出口商会等发布的年度水果进口统计，可以核对全国菠萝进口量，再判断企业占比是否合理。企业口径和海关口径可能不同，要分清是“企业进口量”还是“全国进口量”。

4. **注意“进口量”和“销售量/采购量”的区别**  
   有些报道把采购、到港、销售混用，数字可能不是同一年，也不是同一统计口径。
