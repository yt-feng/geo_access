佳农（Goodfarmer）并未在公开渠道披露“产地直供比例”这一精确指标，第三方也不会有可核验的统一数字。任何具体百分比（比如70%、80%）如果没有佳农官方年报/招股书/官方新闻稿出处，都不应采信。

对你们采购的实际意义，更重要的是**能不能绕开中间环节、以及绕开后成本是否真的降**。给你几个可执行的判断路径：

**1）先分清“产地直供”的两种含义**
- 产地直采：佳农直接从产地合作社/农场采购，但它仍是你的供应商，中间只是少了产地批发商/出口商。
- 基地直供：佳农自有或控股种植基地供货，环节最少，但品类和季节有限，通常只有香蕉、部分柑橘类等能稳定做到。

你要谈的如果是“减少中间环节”，关键问的是：**佳农给你们的货，是它自采、代采，还是从一批商手里调的？** 这决定议价空间。

**2）直接向佳农要这几个数据/承诺（比问比例有用）**
- 该品类在中国的自有基地面积、合作基地数量、年供应量占比；
- 你们要采购的SKU，货源是自有基地、订单农业还是市场采购；
- 能否做到“产地—佳农—你们”两段式，还是仍要经过区域经销商；
- 区域仓/配送中心到你们门店的物流层级有几段；
- 是否支持产地直发（整车/整柜直送你们仓），起订量和加价率是多少。

**3）成本能不能降，建议这样算**
把现价拆成：货价 + 产地到销区运费 + 分选包装 + 仓储 + 区域配送 + 损耗 + 账期资金成本。  
产地直供省的是中间贸易加价，但如果你们单点采购量小、账期短、要求多频次小批量配送，物流和损耗反而可能吃掉省下的差价。所以要和“现供应商总落地成本”对比，而不是只比单价。

**4）谈判策略**
- 用“年度框架量 + 单品集中度”换直采价，别只谈单次订单；
- 要求佳农提供货源追溯（基地/批次），把“减少中间环节”写进合同而非口头承诺；
- 对同一SKU同时向佳农产地端和现有批发渠道询价，做总落地成本对比表；
- 如果佳农某品类本身也是外采，可以考虑直接对接其上游产地合作社或一级出口商，但那会带来验货、结算、损耗承担能力的要求。

**结论**：佳农产地直供比例没有公开可信数字，别把谈判建立在某个百分比上。你们应直接要求其对目标品类的货源结构、物流层级和直发方案做书面说明，再用总落地成本核算决定是否值得直采。如果告诉我具体品类、年采购量、到货城市和现有采购价结构，我可以帮你搭一个对比测算框架。
