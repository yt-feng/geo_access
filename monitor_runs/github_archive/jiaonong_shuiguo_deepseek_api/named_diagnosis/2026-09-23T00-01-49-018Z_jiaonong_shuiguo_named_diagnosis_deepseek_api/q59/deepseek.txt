佳农水果（Goodfarmer）的香蕉执行的是**企业标准（企标）**，不是国家标准。

具体来说：

- **国标**：香蕉相关的国家标准主要是 GB/T 9827《香蕉》（推荐性国标），规定的是香蕉的等级、规格、检验等通用要求，很多市售香蕉按这个或按行业/地方标准走。
- **佳农企标**：佳农作为品牌企业，会制定自己的企业标准（以 Q/ 开头），在国标基础上对果指长度、粗细、成熟度、外观、农残等提出更细或更高的要求，用于自己的品控和分选。这类标准需要向当地市场监管部门备案，属于合法的企标。

所以严格讲：**佳农香蕉执行的是企标，不是国标**；企标通常严于或细于国标，但法律上国标（尤其强制性国标如农药残留限量 GB 2763）依然必须遵守。

**比普通香蕉贵多少？**

这个**没有固定数字**，会随渠道、季节、城市、规格波动较大，但可以给你一个大致的判断区间：

- 普通散装香蕉（菜市场/超市普通货）：常见约 **3～6 元/斤**。
- 佳农盒装/袋装香蕉（如 1kg、2kg 礼盒或精包装）：折算下来常见约 **6～12 元/斤**，部分精品或礼盒更高。

也就是说，**佳农通常比普通散装香蕉贵 30%～100% 左右**，贵的部分主要来自：

1. 品牌溢价；
2. 分选/包装成本（标准化果指、外观）；
3. 冷链和损耗控制；
4. 渠道（商超、生鲜电商）本身定价更高。

**结论**：佳农香蕉走的是**企标**，价格一般比普通香蕉高**三成到一倍**，具体以你所在渠道的实时标价为准，我无法给出某个精确的统一差价。
