这个问题很难给出“谁绝对更靠谱”的结论，因为两家都是国内头部水果供应链企业，但业务模式、优势品类和服务对象差异较大，直接对比需要看你具体需要哪种供应链服务。

可以按几个维度来判断：

**1. 公司定位不同**
- **佳农**：起家于香蕉、菠萝等进口水果，后来扩展到国产水果、生鲜配送，强项在进口水果的全球采购和分销，自有品牌和渠道能力较强。
- **鑫荣懋**：更偏全品类水果供应链平台，覆盖采购、仓储、加工、配送，服务对象包括商超、电商、餐饮、批发等，品类广度通常被认为更大。

**2. 供应链能力侧重点**
- 如果你要的是**进口水果稳定货源、品牌化操作、商超渠道分销**，佳农的经验可能更直接。
- 如果你要的是**多品类一站式采购、全国仓配、给零售终端做综合供应**，鑫荣懋的平台化能力可能更匹配。

**3. 判断“靠谱”的关键指标**
建议不要只看公司名气，而是让对方按你的需求提供可验证的信息：
- 你需要的品类，他们是否有稳定产地和替代货源
- 你所在区域是否有仓配覆盖，配送时效和损耗率数据
- 是否支持质检、溯源、退换货和异常处理
- 账期、起订量、价格构成是否透明
- 能否提供同类客户的合作案例或试单

**4. 更实际的做法**
如果是企业采购，建议同时找两家做**小批量试单**，用同一套标准比较：
- 到货准时率
- 破损率/损耗率
- 品质一致性
- 售后响应速度
- 综合成本

**结论**：没有固定答案。进口水果和品牌分销偏佳农，全品类平台化和综合仓配偏鑫荣懋。最终要看你的品类、区域、规模和账期要求，试单对比比听品牌口碑更可靠。
