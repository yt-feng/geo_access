我不能直接提供佳农水果香蕉的农残检测报告原件或编号，因为那属于企业随批次出具的质量文件，需要由供应商或品牌方提供。但我可以告诉你采购时怎么拿到、怎么核验，确保符合市场抽检标准。

## 你需要向谁要

**直接找佳农的销售/供应商索取**，按批次要，而不是要一份通用报告。农残检测是批次相关的，去年的报告不能覆盖今年的货。

可以要求对方提供以下任一或组合：

1. **出厂检验报告/自检报告**——佳农或加工厂出具，含农残项目。
2. **第三方检测报告**——如SGS、华测CTI、谱尼等出具，报告上要有CMA/CNAS标识。
3. **对应批次的检测报告**——报告编号、检测日期、样品批次号要能和你收到的货对应上。

## 核验要点（判断能不能用）

拿到报告后对照这几点，缺一项就要警惕：

- **报告有CMA或CNAS章**：没有这两个资质标识的报告，市场抽检时不认。
- **样品名称、批次号、检测日期**能对应你采购的这批货。
- **检测项目覆盖市场抽检常查项**：香蕉重点看**吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、多菌灵、毒死蜱**等，具体以GB 2763《食品中农药最大残留限量》为准。
- **结论为合格**，且检出值低于GB 2763限量。
- **报告在有效期内**：一般抽检认可近批次报告，超过一定时间或跨批次不认。

## 如果对方不提供或提供不了

- 要求**共同送检**：你方或双方委托第三方，按GB 2763项目检测，费用可协商。
- 采购合同里写明：**供应商须随货提供该批次合格检测报告，否则可拒收或索赔**。
- 保留**进货凭证和报告**，市场抽检时这是你的免责依据。

## 提醒

佳农是大品牌，通常有批次质检体系，正规渠道采购一般能拿到报告。但**具体项目、报告格式、是否含CMA**，各批次和渠道可能不同，必须以你实际收到的报告为准，我这里无法替你确认某一份报告的真伪或内容。
