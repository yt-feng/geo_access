佳农香蕉的保质期和储存条件，通常可以按下面来判断：

**1. 保质期**
- **常温、未剥皮**：一般 **3～7天**，具体看购买时的成熟度。  
  - 青一点的：可放 **5～7天**  
  - 已经黄熟、有香气的：通常 **2～4天** 内吃完更好
- **冷藏**：香蕉皮会变黑，但果肉不一定坏。若已成熟，冷藏后 **2～3天** 内吃口感较好。
- **冷冻**：剥皮后密封冷冻可放 **1～2个月**，适合做奶昔、烘焙，不适合直接鲜吃。

**2. 储存条件**
- **最佳温度**：未熟香蕉适合 **13～15℃** 左右；成熟后短期存放可放阴凉处。
- **避免低温**：不要直接把未熟香蕉放冰箱，容易冻伤、发黑、难熟。
- **避光、通风、阴凉**：不要暴晒，不要放在暖气旁。
- **不要和苹果、梨、番茄等放一起**：这些会释放乙烯，催熟香蕉。
- **悬挂存放**：减少挤压，能延缓变黑。
- **已切开**：用保鲜膜包住切口，冷藏，**1天内吃完**。
- **想催熟**：和苹果一起放纸袋里，常温1～2天。
- **想延缓成熟**：成熟后单独放阴凉处；需要更久可冷藏，但皮会变黑。

**3. 判断是否变质**
出现以下情况不建议吃：
- 果肉发酸、发酒味、发霉
- 果肉软烂流水、颜色发暗褐
- 表皮大面积霉斑

简单说：**没熟别冷藏，熟了尽快吃；冷藏会黑皮但未必坏，冷冻适合加工。**
