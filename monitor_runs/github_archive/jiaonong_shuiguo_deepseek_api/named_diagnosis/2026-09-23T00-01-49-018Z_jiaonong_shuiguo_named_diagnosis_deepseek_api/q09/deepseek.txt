佳农（Goodfarmer）作为国内头部水果进口商/品牌商，其到货损耗率通常不会对外公开统一披露，行业内也不会有一个全公司通用的固定数字。能给出的判断是：

- **整体到货损耗率一般控制在 3%～8% 区间**比较常见，这是指从到港/到仓到验收完成这一段的损耗。
- 具体到品类差异很大：
  - **香蕉**：到货损耗偏高，通常 **5%～10%**，视催熟、运输温控和季节而定；
  - **苹果、梨、橙类**：较耐储运，一般 **2%～5%**；
  - **葡萄、蓝莓、樱桃、榴莲等**：易损或高值品，损耗可能 **5%～12%**，冷链不到位时更高；
  - **菠萝、火龙果等**：通常 **3%～6%**。
- 大客户合同里常会约定**验收标准**，比如“到货损耗不超过 X%”，超出部分由供应商承担或折价。这个 X 因客户、品类、季节、运输方式而不同，**不会统一是某个数**。

如果你需要的是可执行判断，建议：

1. 直接向佳农对应品类销售/供应链负责人索要该品类的**到货验收标准**；
2. 看合同里的**损耗责任条款**，那才是真正约束数字；
3. 若你做采购，可按品类分别设阈值，而不是全品类用一个数。

所以，准确说法是：**佳农没有公开的统一到货损耗率，行业实操中大体控制在 3%～8%，易损品可到 10% 左右，最终以合同验收标准为准。**
