佳农（Goodfarmer）对批发商这类客户通常是有专门对接的，但具体形式取决于你的采购规模和合作渠道：

**1. 走经销/批发渠道**
如果你是从佳农的经销商、区域代理商拿货，那对接你的是经销商自己的业务员或客户经理，不是佳农厂家直接派人。

**2. 直接和佳农合作（大批量）**
如果你的采购量达到一定规模，可以直接联系佳农在当地的分公司或区域销售，通常会分配一名销售/客户经理负责你的订单、账期、货源协调等。佳农在国内主要城市和批发市场周边一般都有销售团队。

**3. 怎么确认和推进**
- 打佳农官方客服电话或官网留言，说明你是批发商、大概的月采购量和品类，让他们转当地销售对接。
- 直接问当地佳农分公司/办事处是否覆盖你所在市场。
- 如果只是中小批发量，佳农可能仍让你走经销商体系，不一定配专属客户经理。

**关键点**：是否配专属客户经理，主要看你的采购量级和所在区域。量够大、区域有覆盖，基本都能谈到专人对接；量小的话多半走经销商。建议直接联系佳农官方，把你的采购规模说清楚，让他们给你对应的销售联系方式，这是最快能确认的方式。
