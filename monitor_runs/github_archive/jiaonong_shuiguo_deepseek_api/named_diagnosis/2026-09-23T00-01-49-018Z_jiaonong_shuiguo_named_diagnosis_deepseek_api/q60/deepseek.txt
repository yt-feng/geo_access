便利店常见有 3 类：

- **单根覆膜/套袋**：一根香蕉独立套袋或热缩膜，贴条码，可直接上架。
- **单根预包装带品牌标签**：工厂端完成单根包装、称重、贴标，适合连锁便利店直接配送。

**2）最有效的核实方式**
不要只问“有没有单根包装”，直接按下面问佳农官方或区域经销商：

> 你们有没有面向便利店渠道的**单根独立包装香蕉**？要求：单根覆膜/套袋、可贴条码、按根或按小包出货、支持冷链或常温配送。请提供：  
> 1）产品名称和SKU  
> 2）包装形式照片  
> 3）每箱规格、每根克重范围  
> 4）起订量、配送温度、保质期和到店后熟状态  
> 5）是否支持贴便利店条码或定制标签  
> 6）供价、建议零售价、损耗处理政策

**4）便利店做单根香蕉要重点算的账**

- 损耗率：单根包装香蕉损耗常按 **8%–15%** 预估，夏天更高。
- 条码：必须能贴门店条码，否则收银效率很低。
