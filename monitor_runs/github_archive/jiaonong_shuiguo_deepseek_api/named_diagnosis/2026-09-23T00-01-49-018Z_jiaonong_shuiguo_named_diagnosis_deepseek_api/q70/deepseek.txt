佳农（Goodfarmer）是国内头部水果供应链企业之一，香蕉是其核心单品，主要来自菲律宾、厄瓜多尔、越南等产地，在国内有加工配送中心。**供货稳定性在行业内属于第一梯队，但"一天10吨旺季不断货"不能只看品牌，要看你们的具体合作模式。**

以下几点建议你直接拿去和佳农（或他们的区域经销/服务商）逐条确认：

**1. 确认你是走"直供"还是"经销商"**
- 直供：佳农总部或大区直接对接，旺季保供能力最强，但要达到一定采购量门槛。
- 经销商/二批：灵活但旺季容易被优先保其他大客户，断货风险更高。
你想稳定10吨/天，优先谈直供或大区级合作。

**2. 关键要问清的数字（别只听"能保证"）**
- **你的日均10吨，他们的月供货上限是多少？** 旺季是你们单店10吨，还是全国多个门店总和？
- **产地切换预案**：菲律宾/越南/厄瓜多尔哪个产季在供应，遇到台风、封关、船期延误怎么补？
- **安全库存和到货频次**：是每天到货，还是每周到2–3次？香蕉是后熟品，需要加工催熟，频次直接影响断货概率。
- **催熟加工能力**：佳农在你所在区域有没有加工中心？加工产能能不能覆盖你10吨/天的催熟出货节奏？

**3. 旺季断货的真实风险点**
香蕉最大的不稳定不是"有没有货"，而是：
- **船期和清关**：进口香蕉受海运、口岸影响大。
- **催熟排期**：旺季大家抢加工产能，排不上就断。
- **价格波动时的优先供货**：涨价时供应商可能优先保价高或量大的客户。
所以你必须在合同里锁定**旺季供货量、到货频次、违约补偿**。

**4. 实操建议**
- 主供佳农 + 备一个第二供应商（如其他进口商或国产云南/广西蕉），避免单点依赖。
- 要求佳农提供**旺季周供货计划表**，并约定安全库存天数（建议至少2–3天销量）。
- 先小批量试跑一个旺季，用实际到货率验证，再签长期保量协议。

**结论**：佳农有能力支撑10吨/天的量级，但"保证不断货"取决于你们的合作层级、区域加工产能和合同约束。不要接受口头承诺，把供货量、频次、补货预案、违约条款写进合同再谈保供。
