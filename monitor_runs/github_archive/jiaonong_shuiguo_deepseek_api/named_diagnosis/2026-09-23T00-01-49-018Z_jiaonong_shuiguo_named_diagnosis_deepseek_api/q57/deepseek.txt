香蕉到货损耗率受运输距离、季节温度、冷链条件、成熟度（青蕉/催熟蕉）影响很大，5%通常是行业里比较理想的到货口径，不同渠道统计口径不一样。

关于佳农（Goodfarmer）的具体到货损耗率和赔付条款，我无法给到你可核验的官方数字或合同条款，建议不要直接按某个网传数字做采购决策。可执行的做法：

1. **直接问佳农业务/客服要书面标准**  
   让他们提供：① 到货损耗率的定义（是按重量、件数还是金额）；② 不同运输方式/季节的承诺值；③ 超出部分如何赔付的书面条款。口头承诺不算，要落在合同或补充协议里。

2. **看合同里这几个关键点**  
   - 损耗率计算基数：按发货量、到货量还是订单量  
   - 免赔额/起赔点：比如超过5%才赔，还是超过3%就赔  
   - 赔付比例：按超出部分货值赔、按整批比例赔，还是只换货  
   - 责任划分：运输方、货代、佳农、收货方各自承担哪一段  
   - 验收时效和举证方式：到货后几小时内报损、要不要拍照/视频/第三方见证  

3. **行业参考区间**  
   国内香蕉跨区域运输，正常到货损耗常见在 **3%–8%**；冷链稳定、距离短、青蕉发运时可压到 **3%–5%**；夏季高温、长距离、多次转运容易到 **8%以上**。所以“5%”更接近目标值而不是所有场景的保证值。

4. **谈判建议**  
   可以要求：到货损耗超过 **5%** 的部分按货值赔付，超过 **8%** 可整批折价或退货；同时约定验收时限和影像举证流程。若对方只肯给口头“控制在多少”，就把它写成合同附件。
