关于佳农水果的香蕉农残超标历史，我无法直接核实具体批次或历史抽检记录——这类信息应以官方抽检公告和你们实际拿到的检测报告为准，我不能凭印象给你结论。

给你可执行的合规采购方案：

**1. 先查官方抽检记录**
- 国家市场监管总局「食品安全抽检监测结果」查询系统
- 各省市市场监管局官网的「食品安全监督抽检信息通告」
- 搜关键词：佳农、香蕉、吡虫啉、噻虫嗪、腈苯唑（香蕉常检项目）

**2. 向供应商索要的合规证明（缺一不可）**
- 该批次**第三方检测报告**（CMA/CNAS资质机构出具），检测项目覆盖香蕉常检农残：吡虫啉、噻虫嗪、腈苯唑、苯醚甲环唑、多菌灵等
- 报告须与**到货批次号/生产日期对应**，不能用一张通用报告糊弄
- 供货商营业执照、食品经营许可证
- 产地证明/入境货物检验检疫证明（进口香蕉需要）
- 每批次的**承诺达标合格证**（农产品质量安全法要求）

**3. 合同里写死**
- 农残超标导致的抽检不合格、下架、罚款、赔偿由供应商承担
- 约定你们有权自行送检，不合格整批退货
- 要求供应商提供每批次的检测报告作为交货条件

**4. 自己抽检兜底**
超市抽检过不过，最终看的是**你手里这批货**，不是品牌历史。建议每批次到货后自行送第三方快检或抽检，留好报告备查。

**结论**：品牌历史只能作参考，真正能过抽检的是「批次对应的合格检测报告+你自己留存的抽检证据」。别依赖供应商口头保证，一切以书面报告和合同条款为准。
