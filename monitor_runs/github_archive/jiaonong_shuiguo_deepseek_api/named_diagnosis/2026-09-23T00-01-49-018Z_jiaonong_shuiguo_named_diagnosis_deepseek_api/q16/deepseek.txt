佳农（Goodfarmer）主要是做香蕉、菠萝、椰青、车厘子等进口/国产水果的品牌，在电商平台和商超都有销售。它的售后整体属于“看渠道、看凭证、看时效”，没有统一到所有订单都一样的固定标准，关键取决于你是从哪里买的。

**不同渠道的售后差异**

- **电商平台自营/旗舰店（京东、天猫、拼多多等）**：通常走平台售后规则。到货有坏果，一般要求在签收后24-48小时内拍照举证，坏果比例达到一定标准（常见是超过10%-30%，各店不同）可申请部分退款或补发。
- **社区团购/生鲜平台（美团优选、多多买菜等）**：售后入口在订单里，坏果一般按比例赔付，金额较小，流程相对简单。
- **线下商超/水果店**：直接找门店，通常凭小票或包装就能协商退换，灵活度看门店。
- **直播间/第三方店铺**：售后最不稳定，容易遇到“只赔运费不赔果”“要求提供开箱视频”等情况，下单前最好先看差评里关于售后的内容。

**到货有坏果的处理步骤**

1. **先别急着扔**：把坏果、好果分开，坏果不要丢，这是举证的关键。
2. **拍照/录视频**：拍清楚坏果的切口、霉变、软烂部位，最好同时拍到包装和快递面单，证明是这批货。
3. **尽快联系**：多数店铺要求签收后24-48小时内反馈，越早越好，超时可能不认。
4. **走订单售后入口**：在购买平台点“申请售后/退款”，选择“商品变质/损坏”，上传照片，说明坏果数量或比例。
5. **协商方案**：常见结果是按坏果比例部分退款、补发坏果、或整单退款（坏得特别多时）。如果店家只肯赔几块钱，可以要求平台客服介入。
6. **保留证据到处理完**：在退款到账前别把坏果和包装全扔了。

**几个实用提醒**

- 下单前先看该店铺的售后说明和差评，尤其是“坏果包赔”的具体条件，很多店写的是“按比例赔”而不是“全赔”。
- 生鲜类通常不支持无理由退货，坏果赔付是“质量问题售后”，不是七天无理由。
- 如果是整箱水果，建议开箱时录一段完整视频，能省很多扯皮。
- 佳农本身是供货品牌，具体售后由卖给你的那个商家负责，所以直接找卖家比找品牌方更有效。
