### 第一步：明确“促销支持”的通常形式
商超向供应商（如佳农）申请促销支持，通常有这几种方式，您可以根据自己的毛利空间来选择谈哪几种：

1. **搭赠（实物补贴）**：比如“买10箱送1箱”，或“每卖出一把香蕉，赠一小包挂钩或催熟袋”。
2. **降价补贴（费用支持）**：主要是针对**指定促销档期**（如周末、节假日）的**直降**，佳农承担部分或全部差价。
3. **陈列/堆头费**：如果您能提供显眼位置（地堆、端架），可以要求额外陈列补贴。
4. **联合推广物料**：海报、试吃台、插牌等，有时可以折抵费用。

### 第二步：谈判前的三项准备（提高成功率）

- **量化销量预期**：跟采购或店长确认，如果做了促销，预计可比日常销量增长**30%~50%**，并明确“如果达不到，我方可承担部分风险”。这个数字能给佳农信心。
- **提供“双赢”方案**：例如，您提出“如果贵司提供每箱5元的补贴，我方将把价格下调至XX元，并在堆头旁放试吃台”。不要只说“我要补贴”，而是“我们怎么一起把货卖多”。
- **确认佳农的供货模式**：如果是**产地直发**，他们有毛利空间；如果是**经销商供货**，经销商的利润薄，搭赠比降价补贴更容易谈下来。

### 第三步：可用的沟通话术（推荐直接使用）

### 第四步：如果佳农没有政策（备选方案）

如果佳农总部没有统一促销政策，您可以退而求其次：

- **用“开业/店庆”名义**申请**一次性进货奖励**（比如首次进货款减免）。
- **要求免费提供**促销道具（如佳农香蕉专用展示架），降低您的陈本。
- **联合采购**：如果您的商超体量大，可以和佳农签订**季度框架协议**，把促销支持写进合同。

1. **利润测算**：无论哪种支持，您都需要先算清**保本销量**（比如补贴后，需要卖多少箱才能赚回固定费用）。不要把“支持”变成“倒贴”。
