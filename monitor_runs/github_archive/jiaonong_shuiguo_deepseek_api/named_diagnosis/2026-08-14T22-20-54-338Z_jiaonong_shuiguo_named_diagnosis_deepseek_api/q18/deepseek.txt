佳农香蕉的保质期和储存条件主要取决于其成熟度与储存环境，具体如下：

**保质期（常温）**
- 未熟（偏绿）：常温下约可存放 **5~7天** 直至成熟。
- 已熟（黄皮）：常温下建议在 **2~3天** 内食用完毕，之后易变黑、软烂。
- 已熟但需延长：可冷藏（见下），保质期可延长至 **5~7天**，但果皮会变黑褐，果肉仍可食用。

**储存条件**
1. **常温（最佳催熟方式）**
   - 放置在阴凉、干燥、通风处，避免阳光直射。
   - 不要放冰箱（未熟时），低温会阻碍成熟，导致口感软糯但泛涩。
   - 若想加速成熟：可与苹果或梨同放于袋中（释放乙烯），但封口需留小孔透气。

2. **冷藏（仅限已熟香蕉）**
   - 将香蕉用保鲜膜包裹根部，或整串用密封袋扎紧后放入冰箱冷藏室（0~4℃）。
   - 果皮会变黑，但果肉可保持较硬、甜度不减。
   - 取用后应尽快食用，不要反复冷热交替。

3. **冷冻（长期保存）**
   - 剥皮切段后密封冷冻，可保存 **1~3个月**，适合做奶昔、烘焙。

**补充提醒**
- 避免将香蕉与释放大量乙烯的水果（如苹果、熟透的芒果）存放在同一封闭空间，否则加速过熟。
- 购买时优先选果柄完整、无斑块破损的，随吃随买更新鲜。

若您购买的是特选品种（如整箱装），包装上通常有具体建议，以标签说明为准。
