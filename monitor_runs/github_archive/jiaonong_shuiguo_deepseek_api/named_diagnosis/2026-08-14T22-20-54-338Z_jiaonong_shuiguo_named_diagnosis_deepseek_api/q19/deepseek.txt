关于佳农水果的配送时效，我无法提供实时的具体数据，因为配送时间会因**下单渠道（如京东、天猫、官方小程序或线下商超）、收货地址、天气、节假日**等因素而有所不同。

不过，根据通常情况，可以给你一些参考建议：

1.  **常见标准**：绝大多数生鲜电商（包括佳农合作的平台）在**大城市**一般承诺 **48小时内** 送达，部分核心城区或冷链发货地区可实现 **次日达**。
2.  **关键提示**：佳农很多产品（如香蕉、进口水果）是**原产地或总仓直发**，如果收货地址在偏远地区，可能需要3-5天。
3.  **查询方式（最准确）**：
    *   **下单时**：在结算页面，平台通常会显示预计送达时间，以这个时间为准。
    *   **下单后**：查看订单物流详情，里面有快递单号和承运方（如顺丰、京东物流），可直接查询实时轨迹。

**建议**：如果你急需，下单前请务必确认商品页面是否标注“次日达”或“极速达”标识；如果只是普通水果，建议提前2-3天购买，以留出缓冲时间。
