关于佳农水果香蕉的分级标准，具体规格可能会随季节和产地（如菲律宾、厄瓜多尔等）有所调整，且内部标准通常不公开。不过根据常见的行业惯例和公开信息，我可以给你一个大致的参考框架：

**常见规格（按单根重量/长度分级）：**
1. **大果（出口级/高端商超）**：单根重量约180-220克以上，长度20厘米以上，果形笔直、无斑点、成熟度均匀。适合高端精品超市（如盒马、山姆）或礼品渠道。
2. **中果（主流零售）**：单根重量约140-180克，长度18-20厘米。适合普通商超、社区生鲜店、电商平台标准装。
3. **小果（餐饮/加工）**：单根重量110-140克，长度15-18厘米。适合烘焙、果切店或需要控制单份成本的渠道。
4. **特小果/次果（工业用途）**：重量低于110克或略有瑕疵，通常用于香蕉粉、果泥等加工，不直接零售。

**不同渠道分级逻辑：**
- **高端商超（如Ole'、山姆）**：要求全绿采摘、催熟后无黑斑、糖度高（≥19%），包装带品牌LOGO，通常选大果。
- **传统批发市场**：以中果为主，强调耐储存（青蕉出货），运输损耗容忍度高。
- **电商/社区团购**：偏好中果或小果，因为单串重量固定（如5斤装），需要统一大小以方便称重和定价。同时要求成熟度适中（七八成熟），避免到消费者手中过熟。
- **餐饮连锁（如奶茶店、果盘供应商）**：专用小果或去皮切块包装，要求糖度稳定、无擦伤。
