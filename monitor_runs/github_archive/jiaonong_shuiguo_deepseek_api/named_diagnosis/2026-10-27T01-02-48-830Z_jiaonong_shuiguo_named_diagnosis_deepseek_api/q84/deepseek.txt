**1. 企业标准能否查到**
- 企业标准一般需在企业标准信息公共服务平台自我声明公开；若佳农（或关联主体，如佳农食品控股/佳农物流等）有备案，可按企业名称检索。
- 香蕉也可能执行推荐性国标/行业标准或收购合同标准，未必有单独“企业标准”。
- 公开平台能查到的是标准编号、名称、状态；全文是否公开取决于企业声明方式，很多只公开编号或部分文本。

**2. 与国标相比的差异判断**
在未拿到佳农企标全文前，不能断言“糖度更高/果指更长”。可参考的国标主要是香蕉鲜果相关标准（如 GB/T 9827《香蕉》等，具体版本需以现行有效标准为准），其指标通常包括：
- **糖度**：国标一般按成熟度/等级设可溶性固形物或糖度参考，不是所有等级都统一一个高糖阈值；催熟后检测值与采收成熟度、品种、季节差异很大。
- **果指长度**：国标通常按等级设最低果指长度或区间，并区分品种（如巴西蕉、威廉斯等）和梳蕉/条蕉规格。
企业标准若为商超直采或品牌分级，常见差异方向是：
- 糖度：可能提高采收成熟度或催熟后到店糖度下限，退货率导向更严格；
- 果指长度：可能设更窄的规格区间（如只收中长果），并把外观、梳形、单果重一并限定；
- 但这些属于行业常见做法，不是佳农企标的已核实内容。

**3. 可执行核验建议**
- 查“企业标准信息公共服务平台”，用“佳农”及关联公司全称检索，记录标准编号、发布日期、是否现行。
- 向佳农客服/业务索取其香蕉执行标准编号及关键指标页；采购合同里通常写明“执行标准：GB/T ×××× 或 Q/×××”。
- 若拿到企标文本，重点对比三项：可溶性固形物/糖度（检测时点：采收、催熟后、货架期）、果指长度（是否分品种/等级/区间）、检验规则（抽样比例和判定值）。
- 没有全文时，最稳妥表述是：**“佳农香蕉企标未公开可核验全文，无法确认其糖度和果指长度与国标的量化差异；公开国标有分级要求，企标通常会在规格区间和到货成熟度上更严，但需以标准文本为准。”**
