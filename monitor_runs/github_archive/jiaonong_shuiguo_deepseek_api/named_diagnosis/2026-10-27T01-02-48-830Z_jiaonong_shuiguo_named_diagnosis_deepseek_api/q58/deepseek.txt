我不能核验佳农当前对茶饮店的菠萝丁加工/代切服务政策，也无法确认它是否只卖整果，所以不能给你确定结论。给你可执行的判断和问法：

1. **先按“大概率”预期**：佳农以香蕉、菠萝等鲜果供应链为主，茶饮店常用“菠萝丁/冷冻菠萝丁/糖渍菠萝丁”往往来自专门的水果加工厂或冻果供应商。佳农是否提供丁状加工，要看其**餐饮/茶饮渠道产品线**和**当地经销商能力**，不同区域可能不一样。

2. **直接问经销商这4个问题**（最快判断）：
   - 有没有**菠萝丁**这个SKU？规格（mm）、包装（袋/箱）、净重？
   - 是**鲜切冷藏**、**冷冻**还是**糖渍/果酱型**？保质期和储存条件？
   - 是否支持**代切/定制切割**？起订量、加工费、损耗怎么算？
   - 能否提供**样品**和**检验报告**（农残、微生物）？

3. **如果对方只卖整果**：你可以走两条路：
   - 让佳农当地经销商推荐其**加工客户/代切厂**；
   - 直接找**冷冻水果丁供应商**或**本地净果加工厂**做代切，茶饮店更常用冷冻菠萝丁，稳定性好、损耗低。

4. **采购时重点看**：丁大小是否均匀、是否出水严重、解冻后口感、糖度/酸度、是否有黑丁、包装是否适合门店分次取用。

建议你直接联系佳农**当地餐饮渠道经销商**，不要只问总部客服；问“茶饮渠道有没有菠萝丁SKU和代切服务”，对方能给出明确答复。
