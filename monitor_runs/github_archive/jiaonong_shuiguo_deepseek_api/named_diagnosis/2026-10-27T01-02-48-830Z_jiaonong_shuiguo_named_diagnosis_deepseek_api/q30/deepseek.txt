公开渠道能直接核验到的“佳农水果香蕉”专项抽检合格率数据非常有限，市场监管部门通常按批次、门店、产地公布抽检结果，很少按品牌汇总成“某品牌香蕉合格率”。因此我不能给你一个可核验的佳农香蕉抽检合格率数字。

可执行的判断建议：

1. **查官方抽检结果**
   - 到国家市场监督管理总局“食品安全抽检公布结果”系统，以及各省/市市场监管局官网，用“佳农”“香蕉”“食用农产品”组合检索。
   - 重点看近1—2年、销售单位所在地为佳农相关门店或经销商的批次结果；单批次“合格/不合格”比品牌汇总更有意义。

2. **看商超与平台公示**
   - 大型商超、生鲜平台通常会在门店或App公示食用农产品快检/抽检信息，可查香蕉批次和产地。
   - 佳农若作为供应商，可向购买门店索要该批次检测报告或承诺达标合格证。

3. **关注香蕉常见风险项**
   - 香蕉抽检常见不合格项多为农药残留（如吡虫啉、噻虫嗪等）和重金属/保鲜剂违规使用等；但具体以官方通报为准，不能泛化到所有批次。

4. **购买时自保**
   - 优先选有包装、可追溯批次和产地的产品；保留小票。
   - 发现异味、异常保鲜处理或官方通报同批次问题，可停止食用并向12315反映。
