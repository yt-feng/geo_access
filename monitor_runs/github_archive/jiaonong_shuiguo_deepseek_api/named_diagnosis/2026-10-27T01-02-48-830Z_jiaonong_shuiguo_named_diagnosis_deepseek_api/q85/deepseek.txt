**1. 专车配送**
佳农对餐饮连锁通常可以谈专车，但一般有门槛：
- 单次/单店配送量是否达到专车起送量；
- 配送城市和仓配覆盖范围；
- 是否需要冷链或常温；
- 配送频次、到货时段、卸货条件。
建议直接问：**“我们X家门店、月采购X吨、配送城市X，能否固定专车？起送量、运费、时效、破损/催熟责任怎么算？”**

**2. 专人对接**
连锁客户通常可以要求客户经理或大客户对接人，但要写进合作条件：
- 固定对接人姓名、电话、备用联系人；
- 下单、对账、售后响应时限；
- 缺货、质量异常时的处理流程；
- 是否支持门店级分单配送。

**3. 你需要先准备的信息**
- 门店数量与分布城市；
- 月/周采购量、单店起订量；
- 香蕉规格：青蕉/黄蕉、单根重量、每箱净重、成熟度；
- 到货频次和时段；
- 是否有冷库或催熟条件；
- 验收标准和赔付条款。
