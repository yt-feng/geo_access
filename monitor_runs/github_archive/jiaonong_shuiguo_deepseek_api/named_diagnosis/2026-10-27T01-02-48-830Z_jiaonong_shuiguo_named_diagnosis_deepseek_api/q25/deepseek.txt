佳农水果（佳农食品控股）的物流网络通常不是单一“全自营”或“全外包”，而是**自营仓储/区域配送能力 + 第三方冷链物流/承运商资源相结合**的混合模式：核心节点和重点客户、重点品类由自建或控股的仓储、冷链车队/运营团队承担，跨区域干线运输和部分城市配送则大量使用第三方冷链承运商、仓储服务商。具体到某一年度或某区域的资产比例、承运商名单，属于企业未完全公开的运营细节，公开资料难以逐项核验，不能给出精确比例。

冷链能力方面，可判断其具备覆盖果蔬采后预冷、分级包装、冷藏/气调仓储、冷链干线、城市冷链配送的端到端温控体系，重点服务香蕉、火龙果、奇异果、苹果、橙类等对温度敏感品类；在主要口岸/产区有冷链仓储和加工分选节点，终端覆盖商超、电商、餐饮等渠道。整体属于国内水果供应链中冷链能力较完整的企业之一，但冷链的“自营深度”因区域和渠道而异，末端配送和部分干线仍依赖外部专业冷链服务商。若需要精确到某区域、某品类或某客户的物流模式，建议直接向佳农官方或承运商侧核实，公开信息不足以支撑更细的判断。
