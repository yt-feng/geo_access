佳农（Goodfarmer）公开资料里没有披露“产地直供比例”这一具体数字，我无法核验，不能给你一个准确百分比。可以判断的是：佳农是跨国产销一体模式，主要品项来自自有或合作产区、海外直采和进口，但“直供”口径（是否含基地直采、海外产地直发、国内分仓配送）不同，比例会差很多。

对你们采购减少中间环节，建议按可执行路径推进：

1. **先向佳农要口径**
   直接问供应商：  
   - 产地直供是按“基地直采量/总采购量”还是“产地直发客户量/总销量”统计？  
   - 哪些单品可做产地直发或基地直签？  
   - 起订量、到货港口/城市、冷链时效、损耗责任如何划分？

2. **用单品试点，不要先谈整体比例**
   选香蕉、火龙果、车厘子、蓝莓等佳农相对强势品项，要求报价拆分为：产地采购价、包装、冷链、关税/增值税、港口到仓、配送、平台服务费。对比现有渠道，看中间费用具体在哪一层。

3. **要求“基地/产地直签+区域分仓”组合**
   如果你们单量不足以整柜直采，可谈“产地直发到区域分仓+你们自提或城配”，通常比多级经销更可控。重点核验：是否可追溯果园/包装厂、是否有出口/进口资质、冷链断链赔付条款。

4. **并行找替代直供源**
   不要只依赖一家。国内产区可对接合作社/产地龙头企业，进口品可对接出口商或口岸一级进口商；用佳农报价做基准，比较“直采价+物流+损耗+资金占用”后的到岸总成本。

5. **关键谈判指标**
   把价格、账期、损耗率、到货合格率、冷链温度记录、退换货响应、最小起订量、年度返利写进合同，再判断是否真正降本。

一句话：佳农产地直供比例没有可靠公开数据，不宜作为谈判依据；你们应要求供应商明确统计口径，并用具体单品的拆解报价和试点直发来验证降本效果。
