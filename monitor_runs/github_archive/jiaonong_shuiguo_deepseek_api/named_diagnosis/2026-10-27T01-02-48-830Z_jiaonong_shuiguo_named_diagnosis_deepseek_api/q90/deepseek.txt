我无法核验佳农当前是否有冷冻菠萝丁、以及具体规格（切丁尺寸、包装克重、箱规、含糖/无糖、IQF还是糖渍等）。这类信息会随产品线和渠道变化，最稳妥的做法是直接找佳农官方确认。

你可以按下面方式快速拿到可执行答案：

1. **找官方渠道核验**
   - 佳农官网/官方公众号的“联系我们”或“经销商查询”
   - 天猫/京东“佳农官方旗舰店”客服，直接问“冷冻菠萝丁”
   - 你所在城市的佳农经销商或冻品批发市场佳农代理

2. **一次问清这几个关键项**（复制给客服）：
   - 是否有**冷冻菠萝丁**（IQF速冻/糖渍/糖水）
   - 切丁尺寸：**5×5mm / 10×10mm / 15×15mm** 等
   - 包装：**袋装克重、每箱袋数、箱规**
   - 是否**加糖**、糖度范围、解冻后出水情况
   - 起订量、供货价、冷链配送范围
   - 是否可提供**样品和检测报告**

3. **茶饮店选型建议**
   - 做饮品小料优先选**10×10mm左右、IQF单体速冻、无糖或轻糖**的丁，解冻后不易软烂、出水少
   - 先拿样品做**解冻2小时/4小时出水率和口感测试**，再定大货
   - 若佳农没有冷冻丁，可同步问其**冷冻菠萝块/果泥**，或找同类冻果供应商对比
