给你可执行的判断路径：

**1. 自己查官方记录（最可靠）**
- 国家市场监督管理总局"食品安全抽检监测"栏目，按"香蕉""佳农"关键词检索历史不合格通告。
- 各省市市场监管局官网的抽检通报，以及"信用中国"上的行政处罚记录。
- 香蕉农残高频关注项目是吡虫啉、噻虫嗪、噻虫胺、咪鲜胺（保鲜剂）等，重点看这些项目。
- 注意：抽检不合格通常记在生产商/供货商名下，不一定出现"佳农"品牌名，需按具体生产企业查。

**2. 向供应商索要合规文件（超市抽检真正认的）**
- 每批次的**出厂检验报告**或**第三方检测报告**（CMA/CNAS资质），检测项目需覆盖噻虫嗪、吡虫啉、噻虫胺、咪鲜胺等，且报告日期与到货批次对应，不能拿一份通用报告应付所有批次。
- 供货方的**营业执照、食品经营许可证**。
- 若为进口香蕉，需**入境货物检验检疫证明**。
- 与供应商合同里写明农残超标的责任与赔偿条款，并要求其提供**产地证明/基地备案**信息。

**3. 自己留一手**
- 到货批次自行送第三方做农残快检或全项检测，尤其换产地、换季节时。
- 建立批次台账，报告与批次一一对应，超市抽检时能当场出示。
