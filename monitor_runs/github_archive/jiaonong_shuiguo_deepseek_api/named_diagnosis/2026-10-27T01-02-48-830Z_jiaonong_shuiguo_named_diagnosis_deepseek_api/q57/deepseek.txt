我不能直接给出佳农（Goodfarmer）的到货损耗率控制值和赔付条款——这类属于具体企业商务条款，未经核验我不虚构数据。可以给你可执行的做法：

1）损耗率口径先对齐：问清是“到货验收损耗率”还是“全链路损耗率”，分母是发货量还是订单量，是否含压伤、黑斑、断把、催熟不匀，验收时限是到货后几小时，谁判定。口径不同，5%和3%不可比。

2）向佳农要的可核验材料：近12个月按品类/线路/季节的到货损耗统计（最好有第三方或客户签收单支撑）、香蕉验收标准文件、冷链温控记录样例。

3）赔付条款重点看五项：触发门槛（如单批次损耗>X%）、赔付计算基数（货值/重量/箱数）、免赔与除外（不可抗力、客户存储不当、超时未验收）、索赔时限与证据要求（照片、签收单、温控记录）、赔付形式（补货/折价/现金）。

4）合同写法建议：约定“到货验收损耗率≤X%”，超出部分按货值比例赔付；明确验收窗口（如到货24小时内）、判定人和影像留证；生熟度差异单独约定。

5）谈判前用你的历史数据反推可接受值：按线路和季节分别设阈值，别用一个全年通用数字。

如果你告诉我采购品类（如巴西蕉/国产蕉）、运输方式（冷链整车/零担）、到货周期和验收习惯，我可以帮你把验收与赔付条款写成可谈判的条款草案。
