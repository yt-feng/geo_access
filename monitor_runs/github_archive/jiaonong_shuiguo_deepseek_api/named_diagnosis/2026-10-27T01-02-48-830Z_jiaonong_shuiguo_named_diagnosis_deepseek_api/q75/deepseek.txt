1. **直接向佳农确认合同条款**
   - 问清楚：是否支持“周度/月度锁价”、锁价比例上限、锁价保证金或预付款要求、超量/减量违约条款。

2. **行业惯例判断**
   - 香蕉进口/批发环节常见的是“短期锁价（1–4周）+ 浮动补差”或“框架协议+分批定价”，长期全额锁价较少，因为受产地天气、海运、汇率影响大。

   - 分批下单，避免一次性锁长期；锁价比例控制在总需求30%–50%。

   - 锁价不等于零风险：需确认锁价是否含税、含运费、含损耗，以及违约后是否补差价。
