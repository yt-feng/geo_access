佳农（Goodfarmer）公开资料里没有统一披露“到货损耗率”的具体控制标准，不同品类、运输方式、季节和客户验收口径差异很大，无法给出一个可核验的官方数值。

可执行的判断建议：

1. **按品类分开管控**，不要用一个总损耗率：
   - 香蕉：到货损耗通常最敏感，行业中一般把明显机械伤、断指、过熟果合计控制在较低个位数到约5%量级，具体以合同验收标准为准。
   - 苹果、梨、柑橘等耐储水果：通常可控制在更低水平。
   - 浆果、荔枝、水蜜桃等易腐品：损耗容忍度明显更高，需单独约定。

2. **以合同验收标准为准**：到货损耗率应在采购合同中明确“验收时点、抽样方法、计入损耗的缺陷类型（腐烂、压伤、失水、成熟度超标等）”，否则不同口径不可比。

3. **向佳农索取批次质检/到货验收数据**：作为供应商，佳农通常会按客户和渠道提供到货验收记录；直接问其销售或品控要“该品类近3个月到货验收损耗率区间”比问行业通用值更可靠。

4. **内部设目标而非追求统一值**：建议先统计自己渠道连续10—20批的到货损耗，按品类设定基线，再与供应商约定阶梯扣罚或补货条款。
