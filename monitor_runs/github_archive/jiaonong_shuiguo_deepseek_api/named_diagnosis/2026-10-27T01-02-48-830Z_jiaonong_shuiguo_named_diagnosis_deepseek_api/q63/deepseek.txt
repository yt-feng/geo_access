1. **佳农通常可以提供香蕉促销支持，但一般不是无条件给。** 常见形式包括：  
   - **搭赠**：买赠、整箱搭赠、陈列搭赠（多见于批量进货或活动档期）  
   - **降价补贴**：特价补差、堆头/端架陈列补贴、档期促销返利  
   - **费用支持**：促销员、物料、陈列费等形式，直接现金降价补贴相对少

2. **你商超要拿到支持，建议按这个顺序谈：**  
   - 先找佳农当地销售或供货经销商，明确活动档期、门店数、预计销量、陈列位置  
   - 报活动方案：时间、售价、原价、预计进货量、陈列堆头/端架、是否配合DM/社群  
   - 明确要哪种支持：搭赠数量、补差单价、费用上限、结算方式  
   - 要求书面确认：活动价、补差条件、搭赠到货时间、核销凭证（进货单、陈列照、销售数据）

3. **谈判时最有效的筹码：**  
   - 集中档期进货量  
   - 好陈列位（端架/堆头/收银线）  
   - 门店数和活动天数  
   - 是否配合线上社群/小程序引流  
   - 后续持续采购承诺

4. **注意风险：**  
   - 香蕉损耗高，搭赠和补差要约定**到货品质、损耗承担、补差结算口径**

   - 不要只口头承诺，至少微信/邮件书面确认
