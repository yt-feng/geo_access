可以，但“稳定供应”要拆成两层看：规格能不能听懂、供应能不能稳定。

**1）规格是否听得懂**
佳农这类水果供应链企业通常会用行业规格表述，比如按单果重量分级、按箱规/净重装箱、按品种（如金钻凤梨/普通菠萝）、按成熟度或加工适配度区分。对茶饮店来说，你不需要追他们的内部编码，直接把自己能验收的指标写成采购语言即可：
- 单果重量区间（例如1.2–1.5kg/个）
- 每箱净重、单箱个数
- 品种与产地
- 成熟度/是否催熟
- 是否去皮切块、冷冻/冷藏/常温
- 果肉出成率、糖度范围、酸度接受范围
- 到货温度、保质期、破损率上限

这些是他们能对接、你也能验收的“商家听得懂”的规格。

**2）供应是否稳定**
不要只问“能不能稳定供”，要让他们给出可执行承诺：
- 常规月供应量上限、旺季锁量方式
- 提前下单周期和最小起订量
- 替代规格方案（缺大果时能否换小果/换品种）
- 到货频次、冷链/常温运输方式
- 价格联动机制和锁价周期
- 破损、不熟、过熟的赔付标准

**建议做法**
先让佳农按你茶饮店的用量给一份“规格报价单+供应保障条款”，用1–2周小批量试单验收：称重抽检、糖度抽检、出成率记录、破损率记录。试单稳定后再谈月度锁量。这样比只听“能稳定供应”可靠得多。
