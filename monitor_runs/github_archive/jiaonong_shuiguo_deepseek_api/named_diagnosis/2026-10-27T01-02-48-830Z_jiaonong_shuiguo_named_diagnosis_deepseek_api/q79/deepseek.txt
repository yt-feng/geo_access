佳农水果的配送覆盖和冷链收费没有全国统一标准，会根据你购买渠道（佳农官方小程序/电商旗舰店、商超O2O、社区团购、经销商）不同而不同，所以我无法直接核验你所在县城是否可达。可以按下面方式快速判断：

**1. 配送覆盖城市怎么查**
- 优先看佳农官方小程序/公众号或京东、天猫等旗舰店的“配送范围”说明，下单页输入你的县城地址，能选到具体门店/自提点或显示可配送时段，才算覆盖。
- 商超渠道（如盒马、永辉、大润发等）以该商超自己的门店半径为准，和佳农品牌覆盖不是一回事。
- 县城是否能送到，关键看是否有本地经销商/前置仓/合作门店；没有的话通常只到地级市或县城主城区，乡镇多不覆盖。

**2. 冷链物流收费**
- 品牌官方直营一般按订单金额包邮或收取固定冷链费，生鲜常设满额包邮门槛。
- 经销商/本地门店配送多按距离和重量计费，常见是城区内固定配送费、超出范围加价。
- 具体费用以你下单页面结算时显示的“冷链配送费/保温箱费”为准，客服报价仅作参考。

**3. 最省事的确认方式**
直接在你常用购买渠道把收货地址填成县城详细地址，看是否提示“超出配送范围”；或联系该渠道客服，问三个问题：是否配送到该县城、是否冷链、费用和起送门槛。这样得到的结论最可执行。
