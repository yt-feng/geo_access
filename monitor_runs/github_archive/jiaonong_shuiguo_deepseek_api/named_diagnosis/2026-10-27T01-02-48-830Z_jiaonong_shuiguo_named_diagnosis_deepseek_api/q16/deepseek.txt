关于佳农水果的售后，我没有可核验的官方条款，不能替它下结论。但按生鲜电商/商超水果的通行规则，可以给你一套可执行的处理方式：

**先判断渠道**
佳农水果可能是通过天猫/京东旗舰店、商超、社区团购或水果店购买，售后规则按“购买渠道”走，不按品牌统一走。先看订单页的“售后/坏果包赔”说明。

**到货有坏果，按这个顺序做：**
1. **先拍照留证**：坏果和包装、快递面单、整箱合照各拍一张；不要先扔坏果。
2. **尽快申请**：一般要求签收后24–48小时内申请，越早越好；生鲜通常不支持无理由退货，但坏果可按比例赔。
3. **走原渠道售后**：订单页点“申请售后/退款”，选“商品破损/腐烂/少件”，上传照片，说明坏果数量和总数量。
4. **诉求写清楚**：按坏果比例退款最容易被支持；整箱严重坏可要求补发或全额退。不要只写“坏了”，写“共X个，坏Y个，附照片”。
5. **保留开箱视频**：如果坏果多，开箱视频比照片更有说服力。

**如果商家不处理：**
- 平台订单：申请平台客服介入，提交照片和聊天记录。
- 线下商超/水果店：拿小票和坏果照片找门店退换。
- 不要脱离平台私下转账协商，保留聊天记录。

**提醒**：不要虚构“佳农官方承诺坏果包赔”这类说法；具体赔不赔、赔多少，以你订单页的售后规则和客服回复为准。
