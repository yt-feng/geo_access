结论先说：**佳农香蕉的产地溯源通常能到“产区/包装厂/批次”层级，但能否落到“具体农场”取决于具体单品和批次；GLOBALG.A.P.证书一般可以按包装厂或生产商提供，但是否覆盖你要的那批货，必须看证书上的生产者/地址/产品范围和有效期，不能只听口头保证。**

可执行建议：

1. **先向佳农要三类文件**
   - 该批次香蕉的**产地证明/溯源信息**：产区、包装厂名称地址、批次号、发货日期。
   - **GLOBALG.A.P.证书原件PDF**：看证书编号、持证主体、地址、认证产品范围、有效期、认证机构。
   - **证书与批次的对应关系**：如果证书持证主体是包装厂或出口商，要求其说明该批次来自证书覆盖的生产者/农场清单。

2. **判断能否到具体农场**
   - 如果佳农能提供“农场注册号/GGN号 + 农场名称 + 包装厂 + 批次”的对应表，就能到具体农场。
   - 如果只能提供“国家/产区 + 包装厂 + 批次”，那只能到包装层级，不能算具体农场溯源。
   - 商超审核时，建议把要求写成：**批次可追溯到GLOBALG.A.P.证书覆盖的生产农场，并提供GGN号与批次对应记录**。

3. **GLOBALG.A.P.证书核验**
   - 在GLOBALG.A.P.官网证书数据库用证书编号或GGN号核验，确认状态有效、产品范围含香蕉、持证地址与供货主体一致。
   - 注意证书可能覆盖“生产商+包装厂”多个地点，必须确认你采购批次对应的农场/包装厂在证书范围内。

4. **给商超的实操口径**
   - 可接受：证书PDF + 批次溯源单 + 持证主体出具的批次归属说明。
   - 不建议接受：只有一张证书截图、证书主体与发货主体不一致且无说明、证书产品范围不含香蕉、证书过期。

如果你们是商超验厂/准入，最稳的做法是让佳农按“**批次号—包装厂—农场/GGN—GLOBALG.A.P.证书编号**”出一张对应表，并附证书PDF和官网核验截图。这样既满足追溯，也能过GLOBALG.A.P.证书审核。
