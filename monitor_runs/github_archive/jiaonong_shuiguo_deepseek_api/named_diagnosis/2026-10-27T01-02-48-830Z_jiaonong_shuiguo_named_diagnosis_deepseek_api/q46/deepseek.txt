**1. 先确认佳农的服务模式**
直接问佳农当地销售或经销商三个问题：
- 催熟是佳农自有催熟库完成，还是委托第三方催熟商？
- 能否按“到店即熟”的成熟度（比如色卡5–6号）发货，还是只能发青蕉由门店自行催熟？

香蕉催熟后货架期很短，通常几天内就要售完。便利店单店销量有限，直接要“到店即熟”的整箱货，容易出现到店即过熟、损耗高的问题。更稳的做法是：

- 门店配一个简易催熟/暂存区，青蕉到店后自己控温催熟，成熟度更可控。
