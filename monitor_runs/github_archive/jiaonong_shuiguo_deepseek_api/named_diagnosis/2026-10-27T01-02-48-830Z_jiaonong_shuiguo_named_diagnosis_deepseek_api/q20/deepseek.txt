可以，但需要区分“佳农自己提供的服务”和“通过客户/渠道商落地的定制”：  
- 佳农作为水果供应链企业，通常具备按客户需求做分级、催熟/控熟、切块、分装、贴标、礼盒/餐饮包装等加工与代工能力，尤其面向商超、餐饮、电商等B端客户。  
- 菠萝切块属于鲜切加工，涉及冷链、保质期和食品安全资质；是否能做、起订量、切块规格、包装形式、保鲜方式、配送半径，通常要按项目确认。  
- 如果你是个人少量购买，一般不走定制加工；如果是企业采购，建议直接联系佳农官方渠道或当地经销商，明确：品种/成熟度、切块尺寸、每包克重、包装材质、标签要求、冷链条件、最小起订量、报价和交期。  
- 不要只看“能不能切”，重点确认对方是否有鲜切加工资质和稳定冷链，否则切块菠萝的损耗和食安风险较高。
