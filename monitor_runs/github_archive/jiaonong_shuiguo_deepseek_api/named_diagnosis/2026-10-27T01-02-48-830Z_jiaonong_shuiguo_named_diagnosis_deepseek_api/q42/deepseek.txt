这个具体数据我无法核验，不能给你一个“谁更低”的确定结论——香蕉到货损耗率高度依赖批次、季节、产地、冷链距离、催熟方式和你们市场的验收标准，公开也没有可靠的品牌级对比数据。直接说某家更低会是编造。

给你可执行的判断方法，批发市场自己测最靠谱：

1. **按批次抽样对比，不看品牌看批次**
   - 同一周内各进1-2车同规格（如厄瓜多尔/菲律宾、每箱净重、几成熟）的货，记录：到货总箱数、青黑/压伤/断指/霉变箱数、可售净重。
   - 损耗率 =（到货总重 − 可售净重）/ 到货总重，或按箱计不良箱率。连续测3-5批再比。

2. **重点看这几个变量，它们比品牌影响更大**
   - 到货成熟度（几成熟催熟）、运输时长和温控、是否带托盘/纸箱抗压、装卸次数。
   - 同一品牌不同季节差异可能大于两个品牌之间的差异。

3. **向供应商要可追责的承诺**
   - 合同里写明到货成熟度范围、允许损耗率/不良箱率上限、超标赔付或换货条款。
   - 要求提供该批次冷链记录和催熟出库时间。

4. **问同行但限定条件**
   - 只采信“同市场、同季节、同规格、同运输方式”的经验，否则参考价值很低。

如果你们量大，最稳的是做一次**双盲小批量对比**（各进少量同规格货，同条件存放3-5天），用你们自己的验收标准算损耗，再决定主供和备供。这样得出的结论比任何品牌口碑都可靠。
