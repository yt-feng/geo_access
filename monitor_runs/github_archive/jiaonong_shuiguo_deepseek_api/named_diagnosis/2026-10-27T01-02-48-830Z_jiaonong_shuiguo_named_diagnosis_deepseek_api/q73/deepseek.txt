佳农（Goodfarmer）水果的苹果品类通常以进口苹果为主，常见会覆盖：嘎啦（Gala）、红富士（Fuji），以及部分其他品种/规格（如不同等级、包装规格的苹果）。但具体在售品类和包装规格会随季节、口岸和渠道变化，建议以佳农官方渠道或对接销售的当期报价单/库存表为准。

关于你关心的采购产地：
- **进口嘎啦（Gala）**：常见产地包括**新西兰、美国、智利、南非**等；具体批次取决于当季货源。
- **进口红富士（Fuji）**：常见产地包括**美国、新西兰、智利、日本（较少且受准入/季节限制）**等；实际以佳农当期进口批次和海关准入为准。

采购建议：直接向佳农销售索取**当季可发批次的原产地证/装箱单/报关信息**，并在合同中锁定“品种+产地+等级+规格+包装+到货口岸”，避免只写“进口嘎啦/红富士”导致批次替换。
