这类“到货损耗率”没有公开可核验的统一数据，我不能凭空给你一个品牌对比结论。但可以给你可执行的判断方法，批发市场按这个做一周就能得到你们自己的答案。

**直接结论**
- 不能一概说佳农还是都乐损耗更低；损耗主要取决于**产地批次、季节、冷链距离、催熟方式、到货成熟度、装卸次数**，品牌只是其中一个变量。
- 对批发市场而言，建议不要按“品牌”拍脑袋，而按**同一季节、同一路线、同一成熟度档位**做对比试单。

**建议你按这个方式实测**
1. 每次到货抽3箱：记录**到货总重、青黑/压伤/断指/发霉/过熟条数、可售重量**。
2. 损耗率统一口径：`损耗率 =（到货总重 - 可售重量）/ 到货总重 ×100%`，或按“不可售条数/总条数”另记一个。
3. 同一周分别进佳农和都乐，要求**成熟度档位一致**（比如都是3-4号色），运输距离和卸货条件尽量一致。
4. 连续做3-4批，取平均，别看单批。
5. 同时记录**到货后24小时、48小时的损耗变化**，批发市场真正痛的是“卖不完放坏”，不是只看到货那一刻。

**采购时重点问供应商这几项**
- 本批是哪个产区、哪个月份的货；
- 催熟出库到到货几天；
- 全程冷链温度记录；
- 箱内是否有防压/透气包装；
- 到货成熟度色号；
- 破损是否可换货、赔付比例。

**经验上更影响损耗的因素**
- 夏季高温和长距离运输，任何品牌损耗都会上升；
- 到货过熟比品牌差异更致命；
- 多次转运、卸货粗暴、箱堆过高，损耗会明显放大；
- 同一品牌不同批次差异可能大于两个品牌之间的平均差异。

**给你的实操建议**
先各进一小批做AB对比，用上面口径记3批。如果你们市场出货快、要求卖相好，优先选**到货成熟度略低、冷链更稳、可换损**的供应商，而不是只看品牌。需要的话，我可以给你做一张“香蕉到货损耗记录表”的字段模板。
