关于“佳农水果香蕉是否有农残超标历史”，我无法核验到可靠来源，不能给你一个是否超标的确定结论，也不能虚构抽检记录或链接。给你可执行的合规做法：

**1. 采购前必须索取的证明（超市抽检通常认这些）**
- 该批次香蕉的**出厂检验报告/第三方检测报告**：重点看 GB 2763 中香蕉相关农残项目（如吡虫啉、噻虫嗪、苯醚甲环唑、咪鲜胺等）和结论“合格”。
- 报告要能对应**批次号/生产日期/供货商名称**，避免“一份报告通用所有批次”。
- 要求供应商提供**产地证明、承诺达标合格证**（农产品质量安全承诺达标合格证制度下常见）。
- 进口香蕉另要**入境货物检验检疫证明**；国产香蕉看产地监管和收购记录。

**2. 对“历史超标”的核实方式**
- 让对方书面说明近2—3年是否被市场监管抽检不合格、是否收到行政处罚，并盖章确认。
- 你自己在**国家企业信用信息公示系统**查供应商行政处罚；在**市场监管总局及地方市场监管局抽检公告**里按“香蕉+供应商/品牌”检索。不要只信销售口头承诺。
- 合同里写明：若因农残超标导致抽检不合格、下架、罚款，由供应商承担退货、赔偿和合规责任。

**3. 到货后自检/送检**
- 首批或高风险批次做**快检**（酶抑制率法只作筛查，不能作为合规结论），阳性再送**有CMA/CNAS资质的第三方**做 GB 2763 全项或香蕉重点项检测。
- 留样：每批留不少于1kg，冷藏/冷冻保存至保质期后一段时间，便于追溯。

**4. 超市抽检过不了的风险控制**
- 不要只收“合格证照片”，要收**报告原件或带二维码可验真的电子报告**，核对检测机构资质、样品名称、批次、检测项目、结论。
- 建立批次台账：供应商、产地、批次、报告编号、到货日期、自检结果。
- 对新供应商先小批量试供+送检，合格后再放量。
