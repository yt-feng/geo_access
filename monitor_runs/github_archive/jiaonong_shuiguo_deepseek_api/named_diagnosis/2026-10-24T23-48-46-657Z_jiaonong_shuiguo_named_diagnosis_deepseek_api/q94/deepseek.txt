我没有可核验的佳农官方分级标准文件，因此不能给出“佳农内部一级/二级香蕉”的准确定义和价差。可以给你可执行的做法和行业通用判断口径：

**1. 先确认口径**
- 佳农对商超/批发渠道通常按“规格+等级+外观”报价，不同产区、季节、批次、包装（箱/把/根）价差不同。
- 你需要的不是笼统“一级/二级”，而是对方报价单上的：品种（如巴西蕉/皇帝蕉）、单根重量区间、每箱净重、梳数/把数、成熟度、允许瑕疵率、冷链/催熟状态。

**2. 向佳农索取/核验的4份材料**
- 当批次《产品规格书》或《验收标准》：单根克重、长度、梳形、条数/箱、青度、机械伤/黑斑/疤痕允许比例。
- 报价单：同一品种同一规格下的一级、二级分别单价和箱规。
- 验收抽样规则：抽检比例、不合格判定、扣重/退换货规则。
- 近期成交样例：至少3个批次的实际结算价，避免只看挂牌价。

**3. 行业通用分级判断（仅作谈判参考，不等于佳农标准）**
- 一级果：果指饱满、长度和粗细均匀、梳形整齐、无明显机械伤/病斑/裂口，青度一致，单根重和每箱条数稳定。
- 二级果：允许少量外观瑕疵、粗细或长度略不匀、成熟度略不齐，但不影响货架期和食用。
- 价差通常按“同品种、同规格、同批次、同包装”比较；跨产区或跨季节比较没有意义。

**4. 价差怎么问才可判断**
直接让对方报：
> “同品种、同箱规、同成熟度，今天一级和二级的每箱净价分别是多少？二级的允许瑕疵率和单根克重下限是多少？”

拿到后按**每公斤净价**换算比较，而不是只比每箱价。一般二级果相对一级果会有折价，但具体幅度必须由当批次报价和验收标准决定，我不能给未经核验的百分比。

**建议**：先让佳农区域销售提供当批次规格书和报价单；若对方只口头说等级，要求写进合同附件，并约定抽检不合格的扣款/退换规则。
