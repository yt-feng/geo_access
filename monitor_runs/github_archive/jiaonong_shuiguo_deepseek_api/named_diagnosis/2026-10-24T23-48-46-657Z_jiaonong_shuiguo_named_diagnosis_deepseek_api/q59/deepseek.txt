佳农水果的香蕉执行的是**企业标准（企标）**，不是国家标准（国标）。

原因：佳农（Goodfarmer）作为品牌商，其香蕉产品通常标注的是自有企业标准（Q/开头的标准号），用于规范其产地、等级、外观、成熟度等分级要求；而普通香蕉（散装、无品牌或农贸市场的香蕉）一般执行的是国家标准（如 GB/T 或食品安全国标 GB 2762/GB 2763 等基础安全标准），两者定位不同。

**价格差**：佳农香蕉通常比普通散装香蕉贵约 **30%–80%**，具体因渠道和地区差异较大：
- 超市/生鲜电商：佳农香蕉常见约 5–9 元/斤，普通香蕉约 3–5 元/斤；
- 促销时差距会缩小，精品商超差距可能更大。

需要注意：以上价格为市场常见区间，实际以当地门店标价为准；不同批次、规格（如单根装 vs 整把装）也会影响单价。
