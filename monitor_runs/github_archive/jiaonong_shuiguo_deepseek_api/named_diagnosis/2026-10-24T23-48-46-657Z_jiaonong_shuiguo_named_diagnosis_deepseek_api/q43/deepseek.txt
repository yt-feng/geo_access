可以谈，但“锁价合同”通常不是佳农这类大宗水果供应商的标准现货条款，需要按年度框架+价格机制去设计。给你可执行的判断和谈法：

1. **先确认佳农是否接“年度锁价”**
   - 佳农有B2B餐饮供应链业务，10吨/月、120吨/年属于可以谈年度框架的量级，但是否能锁价取决于：菠萝品种（金钻/巴厘/MD2）、规格（鲜果/冷冻果块/果泥/糖水罐头）、产地季节、交付城市、账期。
   - 直接问销售三句话：“我们年需求120吨，能否签年度框架锁价？锁价周期是季度还是半年？超量/减量±20%怎么调？”

2. **锁价合同一般不会“一口价锁全年”**
   菠萝受产地季节、海运/陆运、台风、汇率影响大。常见可接受机制：
   - **季度锁价+年度框架**：每季度定一次价，季度内不变；
   - **保底量+浮动价**：承诺月10吨，价格随产区指数浮动，但设上下限；
   - **部分锁价**：60%-70%量锁价，30%-40%随行就市；
   - **价格保险/远期点价**：先锁量，交割前按约定窗口点价。

3. **你方要准备的谈判条件**
   - 明确规格：鲜果还是冷冻/果泥。茶饮店如果做稳定出品，**冷冻菠萝果块/果泥**比鲜果更容易锁价，损耗低、标准化高。
   - 明确全年分月需求，避免“说10吨/月但淡旺季差很大”。
   - 接受**保底采购量**和**提前下单周期**，这是供应商愿意锁价的前提。
   - 账期、运费、损耗赔付、品质不合格退换要写进合同。

4. **风险控制建议**
   - 不要只依赖一家锁价，保留20%-30%现货/备用供应商；
   - 合同写清：锁价有效期、调价触发条件（产区价涨跌超±10%）、品质标准、违约和赔偿；
   - 如果佳农只给短期锁价，可考虑“季度锁价+期货/指数参考”，比硬求全年一口价更现实。

**结论**：佳农大概率可以谈年度框架和季度/半年度锁价，但“全年固定价”不容易拿到；10吨/月有谈判筹码。你先让佳农销售书面报价并确认锁价周期，再决定是否签。
