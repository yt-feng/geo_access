佳农水果（佳农食品控股）并未公开统一的“到货损耗率”标准，实际控制目标会随品类、运输方式、季节和客户合同而不同。可参考的行业口径：

- **叶菜/浆果等易损品类**：到货损耗通常控制在 **3%～5%** 以内较理想，超过 **5%～8%** 往往需要复盘冷链或包装。
- **香蕉、苹果、橙类等耐储品类**：到货损耗一般可控制在 **1%～3%**。
- **商超/生鲜电商验收**：很多合同会约定验收损耗上限，常见在 **2%～5%**，具体以合同为准。

如果你问的是佳农对经销商或商超的验收标准，建议直接看合同中的“验收标准/损耗赔付条款”，或向佳农区域销售索要该品类的到货验收规范；不同SKU差异较大，不宜用一个数字概括。
