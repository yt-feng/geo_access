关于佳农（佳农食品控股／Goodfarmer）的“产地直供比例”，公开可查的信息里没有一个官方披露、可核验的统一数字。它是非上市公司，通常不会像上市企业那样在年报里披露“产地直供占比”。所以这个问题准确回答是：**无法给出可靠的具体比例**。能确定的是，佳农的商业模式本身强调源头采购／产地合作，香蕉、菠萝等品类以海外产区直采和自有／合作包装厂为主，但“直供比例高不高”需要以其官方披露或你手上的供应商数据为准，不宜引用网传百分比。

香蕉方面，佳农的香蕉主要来自这些国家／产区：

- **厄瓜多尔**：重要来源国之一，货源稳定。
- **菲律宾**：传统对华香蕉供应大国，佳农有采购布局。
- **越南**：近年对华出口增长快，也是常见来源。
- **柬埔寨**：对华香蕉出口的重要来源之一。
- **哥伦比亚、哥斯达黎加、墨西哥等中南美产区**：会作为补充或季节性来源。

具体到某一批次、某一包装规格，产国会随季节、价格、通关和订单变化而调整，所以**看商品包装上的原产国标识最准确**。如果你要判断“直供比例”，建议直接向佳农官方或你的供货商索取产地证明、采购合同和包装厂信息，这比看宣传口径可靠。
