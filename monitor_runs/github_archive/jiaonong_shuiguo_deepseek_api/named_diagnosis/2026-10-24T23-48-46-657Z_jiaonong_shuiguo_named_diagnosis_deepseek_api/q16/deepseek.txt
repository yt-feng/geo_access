佳农水果的售后整体属于“可正常维权、但依赖渠道”的类型，关键看你从哪里买：

**售后总体判断**
- 佳农是品牌方，售后通常由**销售渠道**（商超、生鲜电商、社区团购、直播间、经销商）先行处理；品牌直营/旗舰店渠道相对好沟通。
- 常见问题是运输磕碰、个别坏果、成熟度不符。正规渠道一般支持**拍照+订单号**申请部分退款或补发。
- 不建议只凭“品牌大”就认为售后一定快，实际体验差异主要在渠道客服和举证要求。

**到货有坏果怎么处理（按顺序做）**
1. **先别急着扔**：保留坏果、外包装、快递面单，最好和好果分开放。
2. **拍照/录像取证**：拍整箱全景、坏果特写、切开状态、面单和订单截图；有称重条件可称重。
3. **尽快联系购买渠道客服**：说明订单号、到货时间、坏果数量和诉求（补发/部分退款/退货退款）。一般要求在签收后24—48小时内反馈，越早越好。
4. **按比例主张**：少量坏果通常按坏果数量或重量比例退赔；大面积腐烂可要求整单退款或补发。不要接受“坏果正常”这种模糊说法。
5. **走平台售后入口**：电商平台直接申请“质量问题/腐烂变质”售后并上传凭证；商超购买找服务台或小票售后。
6. **协商不成再升级**：平台客服介入→品牌官方客服→12315投诉。保留聊天记录和凭证。

**注意**
- 不要先确认收货再慢慢沟通，容易失去平台售后入口。
- 生鲜类通常不支持无理由退货，但**质量问题**可以主张；坏果不属于“无理由”。
- 如果购买页有“坏果包赔”承诺，截图保存，按承诺执行。
