佳农水果的配送范围取决于你下单的具体渠道（如佳农官方小程序/商城、京东/天猫等电商平台、社区团购、当地经销商），不同渠道覆盖城市不一样，官方也没有一个固定不变的“全国城市清单”。

能不能送到你们县城，建议按下面方式快速判断：

1. **看你用的下单平台是否显示可配送**
   在结算页输入你们县城的详细地址，能选到“县/区+街道/乡镇”并出现可选配送时间，通常就能送；若提示“该地址不支持配送”，就是不到。

2. **区分“产地直发/冷链”与“本地仓发货”**
   佳农很多水果是平台仓或冷链发货，县城能否送达主要看平台在你们当地有没有覆盖；偏远县、乡镇可能只到县城自提点或不支持生鲜配送。

3. **直接问客服最快**
   在购买渠道的客服里发具体地址（省+市+县+乡镇/街道），问“这个地址佳农水果能否配送、是否冷链、时效几天”。这是最可判断的方式。

4. **替代方案**
   如果官方渠道不到，可看京东/天猫生鲜是否覆盖、当地大型商超/水果批发市场是否有佳农货源，或社区团购自提点。

总结：**不能仅凭“佳农水果”判断县城是否送达，要以你实际下单渠道的地址校验和客服确认为准。**
