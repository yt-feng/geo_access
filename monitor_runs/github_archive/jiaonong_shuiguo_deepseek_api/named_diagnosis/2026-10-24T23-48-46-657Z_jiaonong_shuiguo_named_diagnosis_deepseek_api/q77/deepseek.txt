从公开可核实的信息看，**佳农水果的香蕉溯源通常不能公开承诺“到具体农场”**，批量供货时一般能提供到**产区/国家/包装厂或供应商批次**层面的追溯信息；是否能细化到具体农场，要看具体品类、进口批次和佳农与上游农场的合作模式，需要向佳农业务或质量部门书面确认。

关于**GLOBALG.A.P.证书**，商超要求是合理的。建议你这样落地：

1. **向佳农索要该批次对应的GLOBALG.A.P.证书**
   - 不要只要一张“公司证书”截图，要求证书上的**生产者/农场名称、地址、证书编号、认证产品范围（香蕉）、证书有效期、认证机构**与供货批次匹配。
   - 若佳农是贸易商/分装商，确认证书持有人是**上游农场或生产商**，并让其提供**农场—包装厂—您商超收货主体**的关联说明。

2. **同时索要可追溯文件**
   - 批次号/柜号、包装日期、产地证明、植检证、装箱单、发票。
   - 要求提供**追溯链说明**：农场/产区 → 包装厂 → 出口商 → 佳农 → 商超。
   - 若对方只能给到“国家/产区”级，书面说明原因，并看商超是否接受“产区+包装厂+批次”追溯。

3. **核验证书真伪**
   - 用GLOBALG.A.P.证书编号在认证机构或GLOBALG.A.P.数据库核验；核对产品范围是否含香蕉、证书状态是否有效。
   - 证书地址与包装厂/农场地址不一致时，要求解释供应链关系。

4. **合同里写清楚**
   - 要求每批随货提供有效GLOBALG.A.P.证书及批次追溯文件；
   - 明确“证书覆盖产品含香蕉、覆盖实际供货农场/包装厂”；
   - 约定证书失效、范围不符或无法追溯时的退换货/违约责任。

**结论：**“到具体农场”不能默认保证，需按批次向佳农确认；GLOBALG.A.P.证书应索要**覆盖该供货农场/包装厂且含香蕉范围的有效证书**，并配合批次追溯文件核验。
