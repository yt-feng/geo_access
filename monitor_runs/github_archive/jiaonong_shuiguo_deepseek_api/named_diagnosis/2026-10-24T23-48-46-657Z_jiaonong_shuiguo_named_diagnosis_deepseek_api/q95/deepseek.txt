佳农并没有对外稳定披露“产地直供比例”这一指标，所以无法给出可核验的准确数字；公开口径里更多是“全球直采/产地直采”的定性表述，不等于可审计的直供占比。建议不要把该比例作为比价基准。

对你们采购降本，更可执行的做法是：

1. **按单品/产区要“链路证明”**：要求供应商提供果园或合作社名称、采收批次、加工包装厂、报关/检疫、物流节点，确认是否由佳农直接签约产地，而非经过多层贸易商。  
2. **拆分报价结构**：让报价单列明产地采购价、分选包装、冷链仓储、干线/海运、关税与清关、渠道服务费。中间环节是否多、费用是否合理，一看便知。  
3. **设定直供验证条件**：合同里约定“产地直采”的认定标准，例如产地合同或合作社协议、装运前验货、批次可追溯、发票流与货物流一致；不满足则按非直供价结算。  
4. **用替代供应商做对照**：同一单品同规格，向佳农、产地龙头/合作社、区域批发商分别询价，比较到岸/到仓总成本，而不是只看采购单价。  
5. **先小批量试点**：选1—2个高频单品做直供试点，考核到仓成本、损耗率、到货稳定性，再决定放量。  
6. **谈判抓手**：若对方无法证明直供，可要求剔除中间服务费、缩短账期或由你们指定一级代理/产地服务商。

一句话：不要追问一个不可核验的“直供比例”，改用**批次追溯+报价拆分+同规格对标**来核实中间环节并压成本。
