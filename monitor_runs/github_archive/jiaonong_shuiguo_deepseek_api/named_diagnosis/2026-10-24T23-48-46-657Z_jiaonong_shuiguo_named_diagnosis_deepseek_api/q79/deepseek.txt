1. **先确认购买渠道**  
佳农水果在不同渠道的配送范围不一样：  
- **佳农官方旗舰店/小程序/APP**：看商品页是否显示“配送至你所在地址”。  
- **京东/天猫/美团/饿了么等平台**：以平台收货地址能否下单为准。  
- **本地商超/水果店进货渠道**：佳农多为B端供货，县城门店是否“能送到”取决于当地经销商或批发商，不是全国统一零售配送。

2. **县城能否送达的判断方法**  
把你所在“县+乡镇+具体地址”输入下单页面：  
- 能显示预计送达时间并允许付款 → 通常可送；  
- 提示“不在配送范围”或无冷链选项 → 送不到；  
- 只有自提点/团长自提 → 属于社区团购或经销点配送，不是门到门。

3. **冷链物流收费**  
佳农对个人零售和门店批发通常不是同一套冷链报价。常见收费会按：  
- 配送距离/城市；  
- 订单金额是否包邮；  
- 冷链品类（冷藏/冷冻）；  
- 重量/件数；  
- 是否上楼、是否偏远乡镇。  
**没有统一公开价，需以下单页结算价或当地经销商报价为准。**
