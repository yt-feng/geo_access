佳农水果的香蕉常见规格可以按**重量/把型/等级**三个维度来分，但具体到某一批次、某一市场的SKU会随季节和订单变化，建议以佳农官方渠道或当期产品手册为准。下面给一个可执行的判断框架：

**1. 常见规格维度**
- **按单根重量/果指大小**：通常分为大果、中果、小果（例如单根约120g以上、90–120g、90g以下这类区间，具体数值需以品牌当期标准为准）。
- **按每把/每串根数**：常见有4–6根把、5–7根把、整串/整箱散装等。
- **按箱重**：常见有约5kg、10kg、12kg、13kg等箱规，商超和批发渠道偏好不同。
- **按等级**：一级果、二级果、统货；主要看果指均匀度、弯曲度、表皮洁净度、机械伤、成熟度。

**2. 不同渠道的分级建议**
- **高端商超/精品水果店**：选一级果，要求果指均匀、无斑点机械伤、把型整齐，单根大小一致，成熟度偏青或微黄，适合货架陈列。
- **社区团购/电商**：选一级或二级果，优先把型规整、耐运输，成熟度可略高以缩短催熟周期；箱规适中，减少压伤。
- **批发市场/农贸**：统货或二级果更合适，关注性价比和出成率，允许轻微外观瑕疵但不得有腐烂、严重压伤。
- **餐饮/果汁加工**：对果指外观要求低，可用二级果或加工果，重点看成熟度、可食率和成本。
- **便利店/即时零售**：小把装或单根装，选中小果、成熟度可控，便于即食。

**3. 可判断的验收要点**
- 果指长度和粗度是否均匀；
- 有无明显机械伤、裂口、黑斑、腐烂；
- 把型是否完整、切口是否洁净；
- 成熟度是否匹配渠道周转速度；
- 箱内是否有压伤、捂热、水汽。

如果你要对外发布或采购下单，建议直接向佳农业务人员索取**当期产品规格表/分级标准**，因为不同产地、季节和客户定制标准会有差异，以上只能作为通用参考。
