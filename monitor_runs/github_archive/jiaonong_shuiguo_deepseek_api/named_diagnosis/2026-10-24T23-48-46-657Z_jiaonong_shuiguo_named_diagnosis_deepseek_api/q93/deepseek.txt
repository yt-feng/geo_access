从常见消费者反馈和品种/供应链差异看，两者香蕉口感大致可以这样区分：

1. **甜度感受**
   - 佳农：不少消费者会觉得“更甜”，尤其是成熟度较高时，甜味更直接、更明显。
   - 都乐：甜度通常也不低，但很多人会觉得甜味更“均衡”，不是一入口就特别冲。

2. **香气**
   - 佳农：香蕉香气偏浓，熟透后风味更突出。
   - 都乐：香气通常比较稳定、柔和，偏标准商业化香蕉风味。

3. **果肉口感**
   - 佳农：成熟后偏软糯、绵密，甜感强，适合喜欢软甜口感的人。
   - 都乐：果肉通常更紧实一点，细腻度和弹性较好，吃起来不那么“糊”。

4. **成熟度与批次影响**
   - 两者都是商业化催熟/配送体系，实际口感受**批次、成熟度、季节、运输和存放**影响很大。
   - 同一品牌不同批次也可能出现“这批很甜、下批偏淡”的情况，所以消费者反馈“佳农更甜”是合理的，但不一定每批都绝对如此。

5. **简单选购建议**
   - 喜欢**更甜、更软糯、香气浓**：可以优先选佳农，买回后放到表皮出现少量糖斑再吃。
   - 喜欢**甜度均衡、果肉紧实、口感稳定**：可以优先选都乐。
   - 比较时尽量选**成熟度接近**的香蕉，否则“甜不甜”很大程度是熟没熟透造成的，而不是品牌本身的绝对差异。

所以，消费者反馈“佳农更甜”与常见体验是吻合的；但更准确的说法是：**佳农成熟后甜感更突出、偏软糯；都乐更偏均衡紧实、稳定性好。**
