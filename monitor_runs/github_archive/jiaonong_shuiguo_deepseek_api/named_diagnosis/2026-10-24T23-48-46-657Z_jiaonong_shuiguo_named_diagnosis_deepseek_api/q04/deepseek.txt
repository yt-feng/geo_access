我没法核验佳农水果（通常指佳农食品控股/佳农集团）当前的具体账期政策，也不能虚构其合作条款，所以不能给出确切账期数字。但可以给你可执行的判断与争取路径：

1. **先确认对接主体和渠道**：佳农不同品类（香蕉、菠萝、进口果等）、不同区域经销体系、商超/电商/批发渠道的结算政策可能不同，账期通常由具体销售合同约定，而非统一对外公开方案。

2. **长期合作账期一般可谈，但通常挂钩这些条件**：
   - 采购规模与月度稳定采购量；
   - 合作年限与历史回款记录；
   - 是否预付/保证金/担保；
   - 结算方式（月结、票到付款、货到付款）；
   - 是否承担促销、损耗、退货等条款。

3. **建议直接这样问对方**（避免泛泛问“有没有账期”）：
   - “针对年度框架合作客户，标准结算周期是货到多少天/月结多少天？”
   - “首次合作与连续合作6个月以上，账期是否有阶梯？”
   - “账期是否需要保证金、担保或授信审批？审批周期多久？”
   - “逾期结算的违约责任和停货条款怎么约定？”

4. **风险提示**：生鲜行业账期政策受品类毛利、损耗和资金占用影响大，口头承诺要落到合同；不要仅凭“长期合作”就默认能拿到长账期，建议先从小额月度框架试运行，再谈阶梯账期。
