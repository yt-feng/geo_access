1. **先确认对接对象**
   - 佳农（Goodfarmer）通常通过其销售/大客户/电商渠道对接，ERP接口不是公开自助开放平台。
   - 你要对接的可能是：佳农ERP、其WMS/OMS、或他们委托的第三方供应链系统，接口权限和模式不同。

2. **直接问佳农对接人这5个问题**
   - 是否提供API/EDI/文件交换？支持哪些协议：HTTP/HTTPS REST、WebService、SFTP、EDI？
   - 接口清单和字段文档能否提供？包括商品、库存、价格、订单、发货、对账、售后。
   - 鉴权方式：AppKey/Secret、OAuth、IP白名单、证书？
   - 环境：有无测试环境、沙箱、联调窗口？
   - 时效：库存/价格同步频率，订单下发和回传时效，异常重试机制？

3. **商务合同里写清楚**
   - 接口范围、SLA、数据归属、对账口径、失败重试、变更通知、联调责任人和上线验收标准。
   - 若对方无标准API，要求提供SFTP批量文件或EDI方案，并约定文件格式和频率。

4. **你方技术准备**
   - 建适配层，不要把佳农接口写死到业务系统。
   - 做幂等、重试、签名验签、日志留痕、库存防超卖、订单状态机。
   - 先小品类灰度联调，再全量。
