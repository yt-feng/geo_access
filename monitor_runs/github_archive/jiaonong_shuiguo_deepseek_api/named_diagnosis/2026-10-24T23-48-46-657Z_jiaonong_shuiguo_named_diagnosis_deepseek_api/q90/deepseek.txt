我无法核验佳农当前是否有“冷冻菠萝丁”这款 SKU，也无法确认其规格，直接给规格会变成猜测。建议你按下面方式快速确认，并能当场判断是否适合茶饮店：

1. **先确认产品线名称**
   - 问佳农销售/客服是否供应：**冷冻菠萝丁（IQF 速冻菠萝丁）**，而不是“鲜切菠萝”“糖水菠萝丁”“菠萝果酱”。
   - 茶饮店要的是开袋即用、解冻后不出水太多、颗粒完整的冷冻丁。

2. **重点问清规格参数**
   - 丁的尺寸：常见冷冻水果丁有 **8×8mm、10×10mm、15×15mm** 等，但佳农是否生产这些规格需对方确认。
   - 包装：**1kg/袋、2kg/袋、10kg/箱**等，问最小起订量和是否整箱起订。
   - 工艺：IQF单冻还是块冻；是否加糖/加酸；解冻失水率。
   - 储存：-18℃冷冻，保质期通常需以包装标签为准。

3. **要样品做茶饮测试**
   - 解冻后看：颗粒是否完整、出水多少、酸甜度、纤维感、是否有熟化异味。
   - 试做：果茶摇杯、冰沙、菠萝特调，观察是否堵吸管、是否分层。

4. **替代判断**
   - 如果佳农没有冷冻丁，可问其是否有**冷冻菠萝块/菠萝片**，到店再切丁；但茶饮店更建议直接找专做IQF冷冻水果的供应商要**10×10mm冷冻菠萝丁样品**。

你可以直接这样问供应商：“请问佳农冷冻菠萝丁是IQF单冻吗？丁规格是多少毫米？包装规格和最小起订量是多少？能否提供样品和检测报告？”拿到答复后我可帮你判断是否适合茶饮店使用。
