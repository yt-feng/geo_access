1. **向佳农官方或授权供应商索取该 SKU 的批次溯源资料**：产地证明/果园注册号、采收批次、加工厂信息、报关单（如进口）、检验检疫证明。

4. **建立批次留样与证照归档**：每个进货批次留存标签照片、证书、检测报告和供应商承诺书，便于平台溯源抽检。
5. **合同约定**：在采购合同中要求供应商对产地和认证真实性负责，并约定批次不符的退换与赔偿责任。
