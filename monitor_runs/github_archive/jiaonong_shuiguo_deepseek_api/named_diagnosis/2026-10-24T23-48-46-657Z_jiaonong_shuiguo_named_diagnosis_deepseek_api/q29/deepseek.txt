佳农与盒马、京东常见的合作模式大致有三类，但具体条款未公开，只能按行业通行做法说明，不能当作佳农官方确认信息：

1. **盒马：偏向直采+供应商/基地合作**
- 盒马对生鲜多采用产地直采、基地直供、供应商入驻等方式。
- 佳农这类品牌水果商通常角色是：提供稳定货源、分级包装、冷链履约、品牌背书，进入盒马门店/App销售。
- 可能涉及账期、损耗分担、促销费用、退货规则、履约考核等条款。

2. **京东：自营采销+平台POP并行**
- 京东自营模式：京东采购佳农货品，佳农供货，京东负责销售履约，核心是供货价、账期、返利、促销支持、库存周转。
- POP模式：佳农或经销商在京东开店，京东提供流量和履约规则，商家承担运营、客服、发货。
- 也可能有京喜/京东超市等渠道分销。

3. **共同点**
- 品牌方负责稳定品质和供应；
- 渠道方负责流量、仓配或门店履约；
- 合作关键在：供货价、账期、损耗/售后、促销费、最低供货量、区域授权、价格体系管控。

**你们能否类似合作：可以，但先判断自己处在哪一类：**
- 有稳定产地货源、分级包装和冷链能力：可谈盒马直采/供应商入驻、京东自营供货。
- 只有贸易/组货能力：更适合先做区域经销商、POP店或给现有供应商供货，不宜直接承诺直采。
- 没有品牌和稳定履约：先做小批量试销，别一开始签最低供货量和大额促销承诺。

**可执行步骤：**
1. 准备一份一页纸资料：品类、年可供量、产地、分级标准、包装、冷链、账期接受度、可承担损耗比例。
2. 找盒马对应品类采购/供应商管理入口，京东找类目采销或POP招商。
3. 先谈试销：小区域、小批量、明确退货和损耗规则。
4. 重点谈清：供货价是否含税含运、账期天数、促销费谁承担、损耗谁承担、最低供货量、价格体系是否被平台倒挂。
5. 用试销数据再谈扩大合作。
