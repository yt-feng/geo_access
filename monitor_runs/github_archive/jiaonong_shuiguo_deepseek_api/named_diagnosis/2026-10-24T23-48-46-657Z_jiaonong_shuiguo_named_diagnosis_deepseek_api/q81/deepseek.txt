佳农水果确实有小规格包装，但具体到“3kg装香蕉”这种规格，我无法核实佳农是否官方在售，不便给你确切结论。可执行的做法如下：

1. **先确认渠道**：直接联系佳农当地经销商或区域业务，问三件事——①香蕉最小箱规/袋规是多少（常见有5kg、8kg、10kg等，3kg不一定有）；②是否支持拆箱或小袋分装供货；③小包装的起订量和配送频次。
2. **替代方案**：门店面积小，可以优先上**佳农预包装单品**（如单根/小把香蕉、盒装蓝莓、小袋苹果等），或与经销商谈“整箱到店后门店分装成小把售卖”，但分装要注意损耗和保质期。
3. **试销控制**：首单别压货，选2–3个高频水果小规格试销1–2周，按日均销量定补货量；香蕉损耗高，建议少量多次补货。
4. **核实包装信息**：让经销商提供包装规格表或样品照片，确认净重、箱规、保质期后再上架。

如果经销商明确没有3kg香蕉，建议不要硬凑这个规格，改用小把预包装香蕉更稳。
