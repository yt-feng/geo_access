佳农（Goodfarmer）有面向礼品和团购场景的水果礼盒，但具体品类、规格和起订量会随季节、区域和渠道变化，建议按以下方式确认和操作：

1. **先确认渠道**
   - 企业团购/大批量：联系佳农官方销售或当地经销商，询问“企业团购/节庆礼盒”报价单。
   - 零售小批量：看佳农天猫/京东旗舰店、盒马/山姆等商超是否有节庆礼盒装。

2. **重点问清4项**
   - 是否有**礼盒装/手提箱/定制贺卡**；
   - **起订量**和**是否支持混搭**（如香蕉、菠萝、猕猴桃组合）；
   - **冷链配送范围**和到货时效；
   - **发票、售后坏果赔付**规则。

3. **节庆节点提前订**
   中秋、春节、端午前后礼盒需求集中，建议提前2–4周询价锁货，避免临时缺规格。
