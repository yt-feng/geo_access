佳农（佳农食品）主要做香蕉、菠萝等生鲜水果的种植、进口和批发分销，其标准产品通常是整果或鲜切水果，但**是否能为茶饮店提供“按需去皮切块”的定制加工服务，需要直接向其当地销售或客服确认**，我无法核验其当前服务范围，不能替你下结论。

你可以这样判断和推进：

1. **先确认你需要的形态**  
   - 是“鲜切菠萝块”成品，还是“去皮整果/去芯块”冷链配送？  
   - 每天用量、块型尺寸、是否需要去芯、包装规格（袋装/盒装）、保质期要求。  
   茶饮店通常更适合采购**冷链鲜切菠萝块**，而不是自己大量去皮。

2. **直接问佳农销售三个关键问题**  
   - 你们是否有“鲜切菠萝/去皮切块”的SKU，还是只卖整果？  
   - 能否按我们要求的块型和包装规格供货？起订量多少？  
   - 配送是冷链还是常温？到货保质期和损耗怎么算？

3. **如果佳农不提供定制切块**  
   可考虑：  
   - 采购佳农整果，找本地净菜/鲜切水果加工厂代加工；  
   - 直接找本地鲜切水果供应商，要求原料为佳农菠萝；  
   - 门店自行切配，但需评估人工、损耗和食品安全（切配间、冷藏、当天用完）。

4. **务必确认食品安全资质**  
   若对方提供切块服务，要求其具备**鲜切水果/净菜加工相关许可**，并确认冷链温度、生产日期、保质期和微生物控制。茶饮店用鲜切水果，食品安全风险比整果高。

**建议**：先联系佳农官方客服或你在当地的经销商，明确问“有没有鲜切菠萝块产品、能否定制切块、起订量和冷链配送”。如果对方只做整果批发，就转向本地鲜切加工厂，并指定用佳农菠萝作为原料。
