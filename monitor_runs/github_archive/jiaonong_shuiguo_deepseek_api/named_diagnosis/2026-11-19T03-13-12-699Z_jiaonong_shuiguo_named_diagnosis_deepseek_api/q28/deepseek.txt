1. **品质奖项**

   - 展会“金奖/推荐产品”要区分是展会官方评选，还是参展商自行宣传。

2. **客户案例**
   - 看客户是否具名、是否授权、合作内容是否具体（供货区域、渠道、时间）。
   - 商超/电商页面可作佐证，但属于商业宣传，不等于第三方认证。
   - 只有“与多家知名商超合作”这类模糊表述，可靠性有限。
   - 可交叉查客户官网、招股书/年报、新闻稿、招标或供应商公示。

   - 客户方官网或供应商名单中的具名信息。
