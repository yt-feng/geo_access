佳农是否提供锁价合同，需要以对方书面报价/合同条款为准，我无法核验其当前政策。但按你月10吨菠萝原料的量，可以按下面方式推进并判断可行性：

1. **先确认你要锁的是什么**
   - 锁“原料果”还是“加工果/果肉/果酱/冷冻菠萝”？
   - 锁“单价”还是“保底价+浮动上限”？
   - 锁“每月10吨固定量”还是“年度总量120吨、月度可调”？
   茶饮店更常见的是锁“规格化加工原料”的价格，而不是鲜果，因为鲜果受季节和产区影响大。

2. **向佳农要4个明确报价方案**
   让对方书面对比：
   - 月度锁价：每月定一次价，适合短期；
   - 季度锁价：锁3个月，价格通常含风险溢价；
   - 年度框架+月度议价：保量不保价；
   - 保底价+上限浮动：例如基准价上下浮动不超过5%—10%，超出部分双方分担。
   你重点问清：锁价是否含运费、损耗、税、最小起订量、月度提货偏差容忍度、违约和补差价条款。

3. **判断能不能接受**
   锁价合同本质是供应商承担价格风险，通常会通过三种方式收回：报价上浮、设置浮动区间、约定超量/减量罚则。你月10吨不算特别大，单独定制锁价难度较高，更现实的是“季度锁价+浮动上限”或“年度框架价”。

4. **降低风险的执行建议**
   - 同时询2—3家供应商，拿到可比的锁价条款；
   - 先签3个月试运行，不要一上来锁一年；
   - 约定月度提货量可在±10%—15%内调整；
   - 明确质量标准和到货损耗赔付；
   - 如果鲜果波动太大，优先考虑冷冻菠萝/果肉/果酱的锁价，稳定性更好。

**直接可问佳农的一句话：**
“我们茶饮门店每月稳定需求10吨菠萝原料，年度约120吨，能否提供季度或年度锁价合同？请书面说明锁价规格、含税含运价、浮动机制、月度提货偏差范围和违约条款。”

如果对方只给月度报价、不愿锁价，说明你的量级或品类不适合锁价，建议转向“框架协议+浮动上限”或找加工原料供应商。
