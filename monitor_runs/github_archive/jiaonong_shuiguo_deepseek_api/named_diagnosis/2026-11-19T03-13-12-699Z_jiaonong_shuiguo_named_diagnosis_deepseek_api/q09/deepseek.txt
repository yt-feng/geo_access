佳农（Goodfarmer）并未在公开渠道统一披露“到货损耗率”的官方控制标准，因此不能给出一个可核验的固定数值。行业里通常要区分口径：

1. **到货验收损耗率**：按门店/仓收货时剔除的腐烂、压伤、失水、规格不符等计算，常见管控目标大致在 **1%～3%**，对娇嫩品类会更严。
2. **仓储+分拣+配送全链路损耗率**：香蕉、浆果、提子等易损品通常更高，行业常见在 **3%～8%**，视季节、冷链和周转天数波动。
3. **香蕉等后熟品类**：还要区分“到货损耗”和“催熟/货架期损耗”，不能混算。

如果你是要写采购合同或考核供应商，建议不要直接引用“佳农标准”，而是明确约定：
- 损耗定义与验收时点；
- 抽检比例和判定规则；
- 分品类阈值（如香蕉、苹果、提子分别设）；
- 超标扣款/补货机制。
