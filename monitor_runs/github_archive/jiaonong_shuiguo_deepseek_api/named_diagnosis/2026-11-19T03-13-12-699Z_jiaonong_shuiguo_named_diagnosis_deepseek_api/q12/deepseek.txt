佳农水果香蕉的常见规格，通常按**净重、每箱把数/根数、单根果指长度与粗度、外观等级**来分；不同渠道再叠加“熟度、伤损容忍度、包装形式”的要求。由于佳农并未公开一套全网统一、可逐条核验的规格表，下面给的是行业通行且与其常见供货形态一致的分级框架，具体以采购合同/供应商报价单为准。

## 一、常见规格维度

1. **按净重**
   - 小箱：约 4–5 kg/箱，常见于精品超市、水果店、电商小家庭装
   - 中箱：约 8–10 kg/箱，常见于商超、社区团购
   - 大箱：约 12–13 kg/箱或 18–20 kg/箱，常见于批发市场、餐饮/加工渠道

2. **按果指长度（行业常用分级）**
   - 大果：约 20 cm 以上
   - 中果：约 16–20 cm
   - 小果：约 12–16 cm
   - 迷你果/宝宝蕉：约 10–12 cm 或更短
   
   实际按“果指长度+粗度+均匀度”综合定级，不单看长度。

3. **按外观等级**
   - **特级/精品级**：果形端正、弯曲一致、色泽均匀、无机械伤和病虫斑，果指均匀度高
   - **一级/标准级**：允许轻微表皮瑕疵，果形基本一致
   - **二级/流通级**：允许少量擦伤、色差、大小不均，适合快周转渠道

4. **按熟度**
   - 青蕉（1–3 号色）：适合长途运输、批发、催熟后分销
   - 微黄/半熟（4–5 号色）：适合商超、社区团购
   - 黄熟（6–7 号色）：适合即时零售、水果店现售
   
   熟度通常用香蕉色卡编号控制，是渠道分级的关键指标。

5. **按包装**
   - 散装大箱
   - 把装/梳装
   - 单根覆膜或气调小包装
   - 礼盒装

## 二、不同渠道的分级建议

| 渠道 | 推荐规格 | 分级重点 |
|---|---|---|
| 精品商超/高端水果店 | 中果至大果，4–5 kg 或 8–10 kg 箱，把装/梳装 | 特级或一级；果指均匀、无伤、色卡 4–5 号到店，货架期可控 |
| 普通商超/社区团购 | 中果为主，8–10 kg 箱 | 一级为主；允许轻微表皮瑕疵；按到货时间控制熟度 |
| 批发市场/二批 | 大箱 12–13 kg 或 18–20 kg，青蕉或微黄 | 流通级/一级；更看重耐运输、催熟一致性和出成率 |
| 即时零售/前置仓 | 小规格把装或单根装，4–5 kg 箱 | 一级以上；熟度偏黄（5–6 号色），减少到店后催熟环节 |
| 餐饮/加工/果汁 | 大箱、二级果或规格不齐果 | 重出肉率和成本，外观要求低，但需控制腐烂和异味 |
| 电商家庭装 | 4–5 kg 小箱，把装或分层保护 | 一级；强调运输抗压、到货熟度稳定、少压伤 |

## 三、采购时可执行的判断标准

1. **先定“果指长度区间+每箱净重+把数”**，不要只写“大果/中果”。
2. **熟度按色卡写进合同**，例如“到仓 4–5 号色，允许 ±0.5 号”。
3. **外观验收写清容忍度**：例如单箱允许轻微机械伤果不超过 5%，腐烂果为 0。
4. **渠道匹配**：远距离批发选青蕉+耐压大箱；即时零售选微黄至黄熟+小包装；精品渠道选均匀度高的中大果。
5. **要求供应商提供当批次规格单**：净重、果指长度、粗度、把数、色号、等级、产地、包装方式。

如果需要精确到佳农某一批次或某一包装SKU的规格，建议直接索取该批次的**产品规格书或报价单**，因为同一品牌不同产地、季节和客户定制包装会有差异。
