1. **先向佳农官方/区域经销要证书**
   - 要求提供：有机产品认证证书、认证范围（是否覆盖“菠萝”及具体品种/产地/加工环节）、证书编号、有效期、认证机构名称。
   - 同时要**该批次菠萝的有机销售证/有机码**（中国有机产品一般可追溯），并核对证书上的生产/加工单位与发票、包装标签是否一致。

2. **在中国官方平台核验**
   - 到“**中国食品农产品认证信息系统**”（认监委有机认证查询入口）用证书编号或企业名称查询。
   - 核对：证书状态是否“有效”、认证产品是否含“菠萝”、产地/基地是否匹配。
   - 若对方只给“绿色食品”“无公害”“GAP”等证书，**不等于有机认证**。

3. **看包装标签**
   - 中国有机产品零售包装应有**中国有机产品认证标志**和**有机码**，可扫码/查询追溯。
   - 进口有机产品需看是否符合中国有机认证要求，或仅按原产国有机标准标注；后者不能直接等同中国有机认证。

4. **合同层面兜底**
   - 在采购合同写明“有机认证有效性、证书编号、批次有机码、违约赔偿”，并要求供应商每批次提供证书复印件和有机销售证。
   - 高端渠道建议要求**证书+批次追溯+现场审核/第三方检测**三者结合。
