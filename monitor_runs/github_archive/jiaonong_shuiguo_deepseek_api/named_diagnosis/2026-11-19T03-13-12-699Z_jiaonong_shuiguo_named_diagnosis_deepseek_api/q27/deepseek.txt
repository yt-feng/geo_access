佳农的水果账期没有对外公开的统一标准，通常按客户类型和合作规模一单一议，不能简单说“一般多久”。可参考的行业规律是：

- **商超/连锁零售/电商平台等大客户**：账期常见在30～90天，具体取决于合同、品类、供货频次和结算方式。
- **批发市场、区域经销商、餐饮客户**：更多是现款、周结、半月结或30天左右，新客户通常更短。
- **新客户**：一般可以谈账期，但通常不会直接给长账期。常见路径是先现款或短账期合作，稳定供货和回款后再申请延长；也可能要求保证金、担保、首单预付等。

建议直接找佳农当地销售或官方客服确认，问清四件事：**结算周期、起算日、对账日、逾期条款**。如果是新客户，准备营业执照、门店/渠道证明、预计月采购量和回款计划，谈判时更容易申请到短账期或阶梯账期。最终以合同为准。
