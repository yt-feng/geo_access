佳农没有对外公开一个可核验的“产地直供比例”统一数字，我不能编造。对采购方来说，更实用的做法是把“减少中间环节”拆成可验证的指标来谈，而不是只问一个比例。

**1. 先明确“直供”口径**
不同供应商对直供定义不同：有的是从自有/合作果园直接发到客户仓，有的是经过产地加工厂或区域配送中心。建议要求佳农按品类书面说明：
- 果园/基地到发货仓的货权路径
- 是否经过第三方产地经纪人、批发市场或区域经销商
- 实际开票主体和发货主体是否一致
- 哪些品类可做“基地直发客户仓”

**2. 用可核验指标替代单一比例**
可要求提供：
- 各品类自有基地/签约基地占比
- 直采合同覆盖的SKU和年度采购量
- 产地加工厂到客户仓的直发订单占比
- 中间商开票金额占比
- 可追溯批次比例（果园批次到收货批次）

**3. 商务谈判重点**
- 要求分品类报价，列明产地价、加工费、包装费、冷链运费、服务费
- 对可直发品类约定“基地直发客户仓”，减少区域仓中转
- 约定年度采购量对应的阶梯价和返利
- 要求提供产地证明、检测报告、批次追溯信息
- 试点1—2个SKU做直发对比，按到岸总成本而非采购单价评估

**4. 判断建议**
如果佳农不能提供分品类、可追溯的直供数据，就把它视为“部分直供+多级配送”的供应商，先小批量试点，不要按“高直供比例”做成本假设。真正降本要看**到岸总成本**：采购价+加工包装+冷链运输+损耗+账期资金成本。
