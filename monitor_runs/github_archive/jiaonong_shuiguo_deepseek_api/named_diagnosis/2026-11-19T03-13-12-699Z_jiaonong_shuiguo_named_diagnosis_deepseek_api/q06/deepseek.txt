**普通商家能听懂的规格，通常按这几项确认：**
1. **品种**：金钻/巴厘/香水等，先确认是否适合你们做茶饮的酸甜度和香气。
2. **形态**：整果、去皮整果、切块、果丁、果泥/果浆、冷冻果肉。茶饮店大量用，优先问**冷冻果肉/果浆/切块**，比整果稳定。
3. **单果重量**：如1.2–1.5kg/个、1.5–2kg/个，按箱定级。
4. **箱规**：每箱几粒、净重多少公斤，例如“每箱6粒、净重约10kg”。
5. **成熟度/糖度**：如七成熟、八成熟，或糖度范围；茶饮店要明确酸甜比。
6. **加工规格**：切块尺寸如10×10mm、20×20mm；冷冻果肉是否去芯、是否带汁。
7. **包装**：整果纸箱/泡沫箱；果肉袋装×箱，每袋1kg或2kg。
8. **冷链与保质期**：冷冻品要问-18℃、保质期12/18个月；鲜果问运输温度和到货成熟度。
9. **起订量与价格**：按箱/吨报价，是否含运费，是否支持长期锁价。
10. **质检与退换**：农残、微生物、异物标准，坏果率/短重怎么赔。

**建议你直接这样问佳农：**
“我们要长期做茶饮，月用量约X吨。请报：①冷冻菠萝果肉/果浆的规格（品种、切块尺寸、糖度、是否去芯）；②每箱净重和袋装规格；③-18℃保质期；④起订量、含运费价格、锁价周期；⑤坏果率/异物/微生物标准和退换货条款；⑥能否先寄样品做饮品测试。”

如果对方只能给“普通菠萝、按箱卖”，说不出糖度、切块尺寸、冷冻还是鲜果、箱规和赔付标准，那就不算能稳定服务普通商家。先要**样品+规格书+报价单**，再小批量试单。
