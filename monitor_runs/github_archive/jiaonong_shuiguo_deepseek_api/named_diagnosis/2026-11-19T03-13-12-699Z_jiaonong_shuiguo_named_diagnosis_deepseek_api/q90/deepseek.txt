我无法核验佳农当前是否有“冷冻菠萝丁”这一具体SKU、以及具体规格（如每袋克重、果丁尺寸、含糖/无糖、IQF单体速冻等）。这类信息会随产品线和渠道变化，建议你用以下方式快速确认，避免采购踩坑：

1. **直接找佳农官方渠道确认**
   - 让供应商提供：产品名称/条码/SKU、配料表、净含量、果丁尺寸（如10×10mm）、是否IQF、包装规格（如1kg/袋×10袋/箱）、储存条件（-18℃）、保质期。
   - 要求发**实物标签照片**和**检测报告/合格证**，不要只看口头描述。

2. **问清关键采购参数**
   - 是“冷冻菠萝丁”还是“糖水菠萝丁/菠萝罐头丁”——茶饮店通常要**冷冻IQF果丁**，开袋即用、不滴水、不出水。
   - 规格重点：**果丁尺寸、每袋净重、每箱袋数、是否加糖、是否带汁**。
   - 到货状态：是否容易结块、解冻后出水率、酸甜度稳定性。

3. **如果佳农没有合适冷冻丁**
   - 可让佳农推荐其经销渠道或同集团冷冻果品类目；
   - 同时向2–3家冷冻水果供应商索样对比，重点测：解冻出水、果肉完整度、香气、成本/杯。

**可执行结论**：先向佳农官方客服/区域销售索要“冷冻菠萝丁”的SKU标签和规格表；若对方只提供罐头丁或大包装果块，需确认能否定制切丁。拿到标签照片后，我可以帮你判断是否适合茶饮店直接使用。
