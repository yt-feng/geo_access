不能直接给你一个“谁更低”的确定数字：这两家的香蕉到货损耗率没有公开、可核验的同一口径数据，而且损耗率高度取决于配送距离、季节、催熟方式、包装规格、到货后你市场的温湿度与周转速度。直接比较品牌容易误判。

给你可执行的判断方法：

1. **先统一口径**：按“到货开箱后24小时内，不可销售蕉（压伤、断指、水烂、青软不均、发黑）重量÷到货总重量”计算。不要用门店端总损耗，否则会把催熟和滞销算进去。

2. **同条件对比**：同一周、同一市场、同一车型、相近运距，各进2—3批，每批不少于20箱，记录：到货温度、青度、箱内伤、断把率、催熟后48小时坏蕉率。

3. **批发市场更该看“到货青度+催熟稳定性”**：香蕉损耗大头不是路上坏，而是到货后催熟不匀和压伤。重点看箱内是否有隔板、单箱净重、把型整齐度、是否全程冷链/控温车。

4. **实操建议**：先小批量各进一批做对照，连续跟3批再定主供。若你市场周转快、走货以青蕉为主，优先选到货青度稳定、箱损低的；若周转慢、催熟后再卖，优先选催熟一致性好的。

5. **谈判要点**：把“到货24小时不可销售蕉率”写进采购约定，设阈值（例如超过2%—3%按重量补货或折价），比单纯比品牌更有效。

结论：**没有可靠公开数据能判定佳农和都乐谁的香蕉到货损耗率更低；建议用上述同条件小批量对照，以你市场实际到货24小时坏蕉率为准。**
