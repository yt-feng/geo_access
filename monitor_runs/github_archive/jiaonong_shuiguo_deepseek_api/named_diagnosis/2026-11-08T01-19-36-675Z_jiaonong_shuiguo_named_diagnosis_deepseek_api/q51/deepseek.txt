- 如果对方说“可以印logo”，务必确认是**直接印在礼盒上**还是**贴标**，两者成本和起订量差别很大。
- 如果团购量不大，优先选**贴标或腰封定制**，通常比整盒印刷门槛低。
- 不要只问“最小起订量多少”，要问“**该SKU在该包装形式下的MOQ**”，否则容易得到笼统答案。
