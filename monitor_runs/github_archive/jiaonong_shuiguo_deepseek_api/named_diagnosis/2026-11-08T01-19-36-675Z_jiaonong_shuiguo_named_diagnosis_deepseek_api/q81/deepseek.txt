结论：不能直接确认“佳农有3kg装香蕉”这个具体规格。小包装方向是可行的，但需要按品类跟佳农经销商/区域业务确认SKU，而不是按整箱进货再拆分（拆分会涉及标签、保质期和损耗责任）。

可执行建议：

1. **先明确你要的是“零售小包装”还是“小规格箱装”**
   - 便利店适销的是：单根/单盒/小袋装香蕉、小盒蓝莓、小袋苹果/橙子、单颗火龙果等。
   - 3kg香蕉对便利店偏大，除非是整箱陈列或家庭装；更常见的是1kg左右或按根/把售卖。

2. **向佳农区域经销商索要“便利店/小业态SKU清单”**
   直接问三件事：
   - 香蕉有没有1kg、1.5kg、2kg、3kg箱装或把装？最小起订量多少？
   - 是否有预包装、带条码、可直接上架的单品？
   - 配送频次、损耗赔付、临期/坏果处理政策是什么？

3. **门店面积小，优先选“高频、小规格、周转快”的品类**
   建议先试：香蕉按把/按根、蓝莓小盒、苹果/橙子小袋、即食水果杯（如有冷链）。不要一次上太多SKU。

4. **如果佳农没有合适小包装，备选方案**
   - 找本地水果批发商做小规格分装（需确认标签合规和条码）；
   - 选其他品牌的小包装SKU；
   - 香蕉按整把进货、门店按根/把定价售卖，但要注意称重和标签合规。

5. **上架前做两周试销**
   记录日均销量、损耗率、毛利、缺货率。便利店水果损耗高，建议先小批量、多频次补货，不要压库存。
