佳农香蕉的“保质期”通常分两种情况：**青香蕉（催熟前）**和**黄熟香蕉（可食状态）**，耐放程度差别很大。

## 储存条件
- **未熟青香蕉**：放在**室温、阴凉通风处**，避免阳光直射和冷风；不要放冰箱。可整串平放或悬挂，减少挤压。想加快成熟可与苹果/梨同放纸袋中。
- **已熟黄香蕉**：**室温阴凉处**尽快吃；夏天可放**冰箱冷藏**延缓继续变软，但**表皮会变黑**（果肉通常仍可食），口感也可能受影响。
- **不要密封闷放**，尤其青香蕉，易积水汽、发霉；纸箱/塑料袋保存需留通风口。
- **避免与已腐烂水果混放**，会加速变质。

## 保质期（常温、普通家庭条件）
- **青香蕉**：约 **5–10 天**开始转黄，具体看采摘成熟度和室温；夏季更快，冬季更慢。
- **黄熟香蕉**：约 **2–5 天**为较好食用期；出现大面积黑斑、果肉发软发酸或有酒味即为过熟/变质，不建议食用。
- **冷藏黄香蕉**：可延长 **2–4 天**左右，但表皮变黑属正常冷害外观，判断以果肉状态为准。

## 判断变质的要点
果肉**发黑、流汁、有酸味/酒味、霉点** → 丢弃；仅表皮黑斑但果肉正常 → 可尽快食用。

佳农香蕉包装上若标注了具体“保质期/储存条件”，以包装标注为准；不同批次、规格和季节会有差异。
