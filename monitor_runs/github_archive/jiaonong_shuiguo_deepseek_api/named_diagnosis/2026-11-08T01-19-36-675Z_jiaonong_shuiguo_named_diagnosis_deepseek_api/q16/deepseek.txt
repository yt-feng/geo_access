佳农（Goodfarmer）主要是香蕉、菠萝、车厘子、蓝莓等生鲜水果品牌，售后规则通常取决于你**在哪个渠道购买**，而不是只看品牌本身。可执行判断如下：

1. **先确认购买渠道**
   - 京东自营/天猫旗舰店/抖音旗舰店/线下商超：各渠道售后政策不同。
   - 佳农官方旗舰店一般会按平台规则处理坏果、烂果、缺斤少两等问题。
   - 如果是社区团购、生鲜店、水果摊购买，优先找该销售方，而不是直接找佳农品牌。

2. **到货有坏果的处理步骤**
   - **先拍照/录像留证**：拍外包装、快递面单、整箱全貌、坏果特写，最好把坏果和面单放在同一张图里。
   - **不要急着扔**：部分平台要求保留坏果或按比例退款，扔掉可能影响审核。
   - **尽快联系销售渠道客服**：说明订单号、坏果数量、总数量，上传照片，提出补发/退款/赔付诉求。
   - **按比例索赔**：常见处理是按坏果数量占总数量比例退款，或协商补发；整箱严重损坏可要求整单退换。
   - **超过售后时效前处理**：生鲜一般签收后24—48小时内反馈，越早越好，具体看平台规则。

3. **和客服沟通时建议这样说**
   “订单号XXX，X月X日签收，共X个/斤，发现X个坏果，已拍照上传。请按坏果比例退款/补发，请在售后时效内处理。”
   这样比只说“水果坏了”更容易快速通过。

4. **如果客服处理不满意**
   - 平台内申请售后/平台介入。
   - 京东可走“交易纠纷”或平台客服；天猫/抖音可申请平台介入。
   - 保留聊天记录、照片、订单截图。
   - 生鲜类通常不支持无理由退货，但**质量问题**可以主张退款或补发。

5. **总体评价**
   佳农作为品牌方，通常有生鲜售后流程，但是否顺畅主要看销售渠道和证据是否完整。**京东自营、天猫/抖音官方旗舰店一般更有保障；非官方渠道维权难度更大。** 到货坏果的关键是：**及时拍照、保留实物、尽快找购买渠道客服、按比例索赔**。
