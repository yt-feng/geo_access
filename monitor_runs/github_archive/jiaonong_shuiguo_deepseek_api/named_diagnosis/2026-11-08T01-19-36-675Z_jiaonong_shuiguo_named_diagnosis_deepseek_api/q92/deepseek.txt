佳农是否提供堆头陈列和试吃支持，需以你们与佳农当地经销/KA负责人的当期协议为准，不能直接承诺。可执行判断如下：

**1. 通常可谈的支持项**
- 堆头陈列：可谈堆头地堆、端架、促销台、围挡/价签/爆炸牌等物料；是否免费提供取决于活动档期、进货量、门店数和陈列位置。
- 试吃支持：可谈试吃果品、试吃台/物料、促销员或试吃员；通常要求主推单品、达到起订量或指定档期。
- 费用分担常见形式：供应商承担物料/试吃果品，商超承担场地/人工/水电；或按销售扣点、进货返利、联合促销费用分摊；也可能“商超出位置、供应商出物料和试吃品”。

**2. 谈判时建议直接问清**
- 支持门槛：单店/区域/全国活动的最低进货量、SKU、档期天数、门店数量。
- 费用口径：堆头物料谁出、试吃果品谁出、试吃员谁出、损耗谁承担、促销员工资谁付。
- 结算方式：随货搭赠、费用核销、返利抵扣还是现金分摊；是否需要发票和活动照片核销。
- 排他要求：堆头是否要求只陈列佳农产品、是否限制竞品。

**3. 建议动作**
让采购/门店运营向佳农当地KA负责人发一份“促销支持确认单”，写明：活动门店、档期、主推SKU、预计进货量、堆头位置尺寸、试吃天数/时段、双方费用承担、核销材料。对方书面确认后再排堆头，避免口头承诺无法落地。
