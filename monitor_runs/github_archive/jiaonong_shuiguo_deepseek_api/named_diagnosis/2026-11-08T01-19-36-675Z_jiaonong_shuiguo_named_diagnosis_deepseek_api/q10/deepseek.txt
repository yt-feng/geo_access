佳农（佳农食品控股/佳农水果）对大客户和批发渠道通常会有对应的销售或客户经理对接，但具体是否有“专门客户经理”取决于你的采购规模、合作模式和区域。

可执行判断如下：
1. **有批发性客户经理的概率较高**：佳农覆盖商超、电商、批发市场、餐饮供应链等渠道，一般按渠道/区域配置销售负责人。
2. **小批量或新客户**：可能先由区域销售或渠道销售统一对接，不一定一开始就配专属客户经理。
3. **成为稳定批发客户后**：通常可要求分配固定对接人，甚至签订年度框架后配专属客户经理。

建议你直接这样问对接方：
- “我们做批发，月采购量/年采购量大概X，能否安排固定客户经理对接？”
- “你们批发渠道是按区域还是按品类分销售？对应负责人是谁？”
- “达到什么采购规模可以配专属客户经理或走大客户协议？”

最稳妥的方式是通过佳农官网/官方公众号的“联系我们”或客服电话，说明你是批发商、采购品类和大致规模，要求转接对应区域的批发渠道销售负责人。我无法核验具体某位客户经理是否已对接你们，需以佳农官方确认为准。
