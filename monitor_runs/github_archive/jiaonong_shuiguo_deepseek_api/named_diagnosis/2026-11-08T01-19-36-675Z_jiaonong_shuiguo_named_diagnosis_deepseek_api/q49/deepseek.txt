**1）先确认你问的是哪类配送中心**
佳农业务分 **香蕉/进口水果催熟加工与配送**、**产地直发**、**商超/渠道供货** 几条线。真正对零售/小B端做“次日达”的，通常是区域经销商仓或平台仓，不一定是佳农自有配送中心。这个区别决定了你能否次日达。

**2）县城能否次日达，按这个规则判断**
- 你所在县城若在 **地级市主城区 50–80 公里内**，且当地有佳农经销商或大型水果批发商仓，次日达概率较高。
