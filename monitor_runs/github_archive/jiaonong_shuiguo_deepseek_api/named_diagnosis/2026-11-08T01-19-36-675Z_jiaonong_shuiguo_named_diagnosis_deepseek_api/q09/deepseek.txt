佳农（Goodfarmer）作为生鲜水果供应链企业，其到货损耗率并没有对外公开的统一标准。实际控制水平通常取决于品类、运输方式、季节和验收口径。可参考的行业经验是：

- **香蕉等耐储品类**：到货损耗一般控制在 **2%–5%** 左右。
- **苹果、梨、柑橘等较耐储水果**：通常 **3%–8%**。
- **浆果、荔枝、水蜜桃等易损品类**：到货损耗可能 **8%–15%**，冷链不到位时更高。
- **全程冷链、直采直发**的标准化程度较高的品类，企业内控目标往往会压到 **5%以内**。

如果是要做供应商考核或采购验收，建议不要直接套用“佳农标准”，而是明确：
1. **损耗定义**：是重量损耗、腐烂损耗，还是含外观降级；
2. **验收时点**：到仓、到店还是上架前；
3. **品类和季节基准**：不同单品分开设阈值；
4. **索赔线**：例如超过5%按比例扣款或补货。

需要更准确的数据，应向佳农官方或对应品类采购负责人索取合同验收标准；公开渠道没有可靠的统一数值可引用。
