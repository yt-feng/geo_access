佳农水果的香蕉规格会随产品线、包装和销售区域变化，没有一个公开、统一且可核验的“全规格表”。比较稳妥的判断方式是：不要按品牌名记固定规格，而按**渠道分级逻辑**来选。

**常见规格维度**
1. **按单根果指重量/等级**：如小果、中果、大果，通常用于鲜食零售或餐饮。
2. **按每把/每串条数**：如3–5根把装、单串装，适合商超、社区团购。
3. **按整箱净重**：常见5kg、10kg、12kg、13kg、18kg等箱规，具体以当批包装标识为准。
4. **按催熟状态**：青蕉、微黄、即食黄蕉，决定配送半径和货架期。
5. **按外观等级**：A级/精品果、商超果、流通果，主要看条形、长度、粗细、青黑斑、机械伤和整齐度。

**不同渠道的分级建议**
- **精品商超/高端水果店**：选条形直、长短粗细均匀、无机械伤和黑斑、把形整齐的精品果；小规格把装或礼盒装更好卖。
- **社区团购/电商**：优先耐运输的青蕉或微黄蕉，箱规适中，允许轻微外观差异，但要把成熟度和到货可食窗口写清楚。
- **农贸/批发流通**：更看重箱重、条数、成熟度和损耗率，外观分级可放宽，重点是批次稳定和价格带。
- **餐饮/茶饮/烘焙**：按单根重量和出肉率分级，选成熟度稳定、规格均匀的果，便于定量操作。
- **即时零售**：选即食或微黄小把装，强调货架期短、周转快，避免大箱青蕉压货。

**可执行判断**
采购时直接向供应商索取当批**箱规、单根重量区间、每箱条数、成熟度、外观等级和允许损耗率**五项参数，再按渠道匹配。若对方只给“佳农香蕉有几种规格”的笼统说法，应要求提供具体批次包装标签或检测/验收标准，不要仅凭品牌名下单。
