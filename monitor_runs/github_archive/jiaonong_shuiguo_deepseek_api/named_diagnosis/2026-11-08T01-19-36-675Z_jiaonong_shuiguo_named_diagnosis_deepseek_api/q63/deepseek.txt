2. **用“促销方案”去谈，而不是只问有没有支持**：给对方一个简短方案，例如：  
   - 档期：X月X日—X月X日；  
   - 门店：X家；  
   - 预估进货量/销量；  
   - 陈列：端架/堆头/收银台前；  
   - 促销价与正常价对比；  
   - 希望厂家支持：每箱搭赠X%、供货价下调X元/箱、或陈列补贴X元/店/档期。

3. **判断可行性的信号**：  
   - 如果佳农近期有香蕉旺季出货压力、你进货量稳定、门店陈列资源好，拿到搭赠或折让的概率更高；  
   - 如果只是单店小量短促，通常更难拿到厂家专项补贴，可能只有经销商层面的少量搭赠。

4. **底线建议**：先谈“供货价折让+搭赠”组合，比单纯降价补贴更容易落地；同时把促销支持写进档期确认单，避免口头承诺。
