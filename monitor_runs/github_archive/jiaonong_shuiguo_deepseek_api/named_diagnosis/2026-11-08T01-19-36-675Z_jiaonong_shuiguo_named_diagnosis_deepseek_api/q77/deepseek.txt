结论先说清：**佳农香蕉的产地溯源通常能到“产地/加工厂/批次”层级，但一般到不了“具体农场地块”对商超公开；GLOBALG.A.P.证书通常可以按供应商主体/产品范围提供，但需确认证书覆盖的具体农场、产品和有效期。** 建议你把商超要求拆成“溯源粒度”和“认证文件”两件事分别索证。

**1. 溯源能否到具体农场**
- 佳农属于大型香蕉进口商/品牌商，通常具备“国家—产区—包装厂/加工厂—批次—发货单”的追溯链，部分批次可追到合作农场或农场组。
- 但“具体农场”是否对商超开放，取决于：该批次是否来自自有/直采农场，还是多农场拼货；农场信息是否属于供应商商业信息；证书是否按农场逐一列明。
- 实操上，商超可要求供应商提供：**批次号对应的产地证明、包装厂注册号、出口商/进口商信息、采收/包装日期、冷链记录**。若必须到农场，应在合同或采购标准中明确“农场级追溯”，并要求供应商提供农场清单及批次映射。

**2. GLOBALG.A.P.证书怎么要**
- 先确认你要的是**GLOBALG.A.P. Integrated Farm Assurance（IFA）**证书，而非仅体系手册或自我声明。
- 要求供应商提供证书原件/扫描件，并核对：**证书持有人、认证机构、认证范围（产品：香蕉；环节：种植/采收/处理）、覆盖农场/生产场所清单、证书编号、有效期、状态**。
- 可在GLOBALG.A.P.官方数据库用证书编号核验有效性；不要仅接受截图。
- 若佳农作为贸易商/品牌方不是证书持有人，应要求其提供**上游农场/包装厂的证书及授权供货关系说明**，并确认证书覆盖该批次产地。

**3. 给商超的可执行索证清单**
- 批次级追溯表：批次号、产地国/产区、农场或农场组、包装厂注册号、采收日期、出口日期、进口日期。
- GLOBALG.A.G. IFA证书：证书编号、持有人、认证机构、产品范围、农场清单、有效期、官方核验结果。
- 若证书持有人与供货主体不一致：提供上游供应商与佳农/供货商的采购或授权关系文件。
- 质量与食品安全补充：出口国植物检疫证书、入境货物检验检疫证明、农残检测报告、冷链温度记录。

**4. 谈判建议**
- 不要笼统写“提供GLOBALG.A.P.证书”，要写“提供覆盖本批次香蕉产地的GLOBALG.A.P. IFA证书及农场清单，证书在有效期内并可官方核验”。
- 溯源要求写“可追溯至农场或农场组，并提供批次映射”；若供应商只能到包装厂层级，要求其书面说明原因并增加批次检测/审核频次。
