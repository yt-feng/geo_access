佳农水果（Goodfarmer）的香蕉分级属于企业/行业收货标准，公开渠道通常拿不到完整的“官方分级文件”，外部也很难核验具体条款和实时价差。可以这样处理：

**1. 分级标准怎么判断**
批发商实际收货时，佳农及多数香蕉品牌/产地收货标准一般围绕以下维度，但具体数值要以合同、收货单或供应商确认单为准：
- **条长/条粗/单条重量**：按规格段分级，如大条、中条、小条；
- **把形与梳形**：把型整齐、梳数均匀、无散条；
- **外观**：果指饱满度、弯曲度、棱角明显程度、青绿均匀度；
- **机械伤与病斑**：擦伤、压伤、裂口、黑星病/叶斑病斑、药害；
- **成熟度**：青蕉硬度、饱满度、催熟适应性；
- **病虫害与异味**：腐烂、霉变、虫害、异味直接降级或拒收；
- **包装与到货状态**：箱规、净重、烂耗率、到货温度。

**2. 一级果和二级果价差**
没有统一公开价差，通常受产区、季节、规格、到货城市、是否催熟、账期和当批质量影响很大。批发端常见规律是：
- 同一批次内，二级果比一级果**低一档报价**，价差往往按“每箱/每件”谈，而不是固定百分比；
- 旺季、到货量大、二级果比例高时，价差会拉大；
- 缺货或催熟蕉紧俏时，价差收窄；
- 若二级果主要是外观瑕疵而非口感/催熟问题，价差通常小于腐烂、病害导致的降级。

**3. 可执行建议**
- 直接向佳农区域销售/收货负责人索要**当批次验收标准单**和**等级价目表**，要求写明条长、单条重、允许瑕疵比例、烂耗率；
- 合同里约定“一级果/二级果”的判定以到货抽检为准，并约定降级差价公式；
- 让供应商提供近3批同规格的一级、二级成交价，按“元/箱、元/公斤”对比，而不是只问百分比；
- 到货时按固定抽样比例拍照留证，重点记录条长、青度、机械伤和病斑。
