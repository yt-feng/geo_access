佳农水果的配送覆盖城市会随销售渠道不同而变化，没有统一固定的“全国城市清单”。要判断你们县城能不能送到，最稳妥的做法是按你实际下单的渠道查：

1. **佳农官方旗舰店/小程序/APP**  
   在收货地址里填你们县城的详细地址，系统会直接提示是否可配送、预计时效和运费；这是最准确的判断方式。

2. **京东/天猫/抖音等平台店铺**  
   进入对应店铺，把地址设为你们县城，看商品页是否显示“可配送至该地址”。不同平台、不同仓配覆盖范围可能不一样。

3. **社区团购/本地商超/生鲜平台**  
   佳农也供货给商超和生鲜渠道，这类通常看本地门店或团长是否覆盖，和佳农官方直配不是一回事。

**结论：** 不能仅凭“佳农水果”判断县城一定送不送；请以你下单平台的地址校验结果为准。若地址校验显示不可配送，可以再查附近地级市仓、平台次日达/隔日达范围，或联系店铺客服确认是否支持县城配送。
