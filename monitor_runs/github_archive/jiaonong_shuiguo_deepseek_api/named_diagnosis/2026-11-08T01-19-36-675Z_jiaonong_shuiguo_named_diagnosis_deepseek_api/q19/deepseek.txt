佳农水果的配送时效取决于你下单的渠道和收货地址，不能一概而论。按常见情况判断：

1. **京东/天猫等电商平台**：通常是仓库发货，常温/冷链视品类而定。一般下单后 1–3 天发出，物流时效 2–5 天不等；偏远地区更久。
2. **社区团购/生鲜平台（如美团优选、多多买菜等）**：多为次日达或隔日自提，具体看所在小区是否在配送范围。
3. **线下商超/水果店配送**：同城即时配一般 1 小时内或当日达。
4. **佳农官方小程序/旗舰店**：以页面标注的“预计送达时间”为准，冷链水果可能额外增加 1–2 天。

**下单前最可靠的做法**：在商品详情页看“发货地/预计送达”，结算页输入收货地址后会显示具体时效；急用建议优先选同城或标注“次日达”的渠道。
