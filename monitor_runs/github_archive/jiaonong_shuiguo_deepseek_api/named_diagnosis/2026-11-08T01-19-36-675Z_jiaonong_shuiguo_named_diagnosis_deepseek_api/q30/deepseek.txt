公开渠道能查到的分产品、分年度抽检数据，通常只在市场监管部门抽检通告或企业质量公告里零散出现；我无法核验后就给出“佳农香蕉抽检合格率”的具体百分比，也不想编一个看起来精确的数字。

可以这样判断和获取可信信息：

1. **看属地市场监管抽检通告**：在销售地（省/市市场监管局官网、“抽检信息”栏目）按“香蕉”“佳农”检索；注意抽检对象是门店/批次，不是品牌整体合格率。
2. **看国家企业信用信息公示系统/品牌方公告**：佳农食品相关主体是否有质量处罚、召回、抽检不合格记录。
3. **看批次而非品牌**：香蕉农残（如吡虫啉、噻虫嗪等）抽检不合格多为单批次/单门店问题，不能直接推成“品牌合格率”。
4. **购买时看检测/溯源信息**：大型商超通常可查批次检测报告；没有批次信息时，优先选果皮完整、无异常药斑、来源可追溯的产品。
