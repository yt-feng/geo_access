关于佳农水果（Goodfarmer）的苹果品类及进口嘎啦、红富士的采购信息，以下供你参考：

**1. 佳农苹果品类概览**
佳农作为大型水果品牌，苹果品类主要覆盖普通消费市场和精品商超渠道，常见品种包括：
- **红富士（含普通红富士、精品礼盒装）**
- **嘎啦（含皇家嘎啦、太平洋嘎啦等变种）**
- **其他进口品类**：如青森水蜜桃苹果、爱妃（Envy）、爵士（Jazz）等高端品种。

**2. 进口嘎啦和红富士的产地**
- **进口嘎啦（Gala）**：
  - 主要来自**新西兰**、**美国（华盛顿州）**、**智利**。其中，新西兰嘎啦果型端正、甜度高，市场接受度较好。
  - 需要注意，嘎啦是早中熟品种，进口果季一般集中在**每年4-9月**（南半球为主错峰上市）。

- **进口红富士（Red Fuji）**：
  - 主要来自**日本（青森、长野）**、**美国（华盛顿州）**、**智利**。日本红富士口感酥脆、糖度高，但价格较高；智利红富士则果味酸甜平衡，果季在**5-11月**。
  - 中国自产的红富士（如山东、陕西、新疆）也是主流，但你说的“进口”应指上述海外产地。

**3. 采购建议**
- **确定果季**：进口嘎啦和红富士的上市时间有重叠也有差异，建议结合你的需求时间（例如：采购国内反季水果时选南半球的智利/新西兰货源）。
- **联系官方渠道**：佳农的进口水果通常由其上海总部或区域分公司对接，可通过其官网、客服电话或微信公众号“佳农好水果”查询具体采购部门。
