3. **定制服务**：对于大批量团购，通常支持印LOGO或定制包装。
4. **获取方式**：建议您直接拨打佳农官方客服热线（可通过其官网或官方公众号“佳农食品”查询），或联系您当地的佳农经销商/批发市场，询问当季在售的团购礼盒目录和起订量。

**建议：** 如果您是个人小批量购买，可以直接去线下水果店或线上生鲜APP（如美团、京东）搜索“佳农礼盒”；如果是公司团购，务必提前联系官方以确认当季货品和价格。
