**具体说明：**

1. **佳农的主营业务与渠道**  
   佳农是国内较大的水果品牌商，主要面向高端商超（如盒马、山姆、永辉）、大型连锁餐饮（茶饮、烘焙）以及电商平台。他们的菠萝（包括都乐/凤梨品种）通常以**整果、大包装（如10kg/箱）或去皮切块（冷冻/鲜切）**为主。  
   **关键点**：他们更习惯对接KA客户（大客户），普通小店的散单可能不是他们的优先项。

2. **“普通商家听得懂的规格”**  
   - **农业行业的规格一般指**：单果重量（如1.2-1.5kg）、甜度（Brix>13）、成熟度、果形疤痕、包装要求（如网套个数/箱）。  
   - **对普通茶饮店而言**，你需要的是**去皮后的果肉净重**、**切块大小（如2x2cm）**或**打浆后的果汁浓度**，以及**每箱的可直接使用比例（出肉率）**。  
   - **建议**：不要直接问“有菠萝吗？”，而是明确说：“我需要每周固定供应 **去皮切丁凤梨（果肉净重5kg/袋）** ，要求甜度Brix 14以上，酸度低，出肉率≥55%”。如果你能提供这个具体参数，佳农的销售或经销商可以更快速给你报价和排期。

3. **稳定供应的风险点**  
   - **季节性**：菠萝（尤其是都乐金菠萝）有产期，佳农通常从菲律宾、泰国或国内海南基地采购。你需要问清楚**你的城市是否有当地分仓**，否则跨区冷链配送会导致成本上升或断货。  
   - **最低起订量**：普通小店如果一次只订几十公斤，佳农直供可能不划算。**更现实的路径是找他们的区域授权经销商**（例如你所在城市的果品批发商），他们可以拆箱、打散后按小规格卖给你，且价格更灵活。

4. **实操建议（按优先级）**  
   - **首先**：打佳农官方400客服或官网留资，直接问：“我的茶饮店月需500kg去皮菠萝丁，坐标XX市，能否提供区域经销商的联系人？”
