关于佳农水果的到货损耗率，我无法提供精确的官方数据，因为该数值会因**水果品类**（如香蕉、菠萝、蓝莓等）、**运输距离**、**包装方式**、**季节温度**以及**终端渠道**（商超、电商、批发）的不同而有显著差异。

不过，基于国内生鲜水果行业的一般标准，可以给你一个参考范围：

- **行业平均损耗率**：对于生鲜水果（尤其是易腐坏的品类），从产地到终端仓库的**到货损耗率**（指运输及卸货过程中产生的损坏、腐烂）通常在 **2% - 8%** 之间。
- **佳农作为头部企业**：由于其在供应链管理（冷链运输、预冷处理）和包装标准化方面投入较大，其**报损率通常控制得比行业平均值更低**，在大宗批发和商超渠道中，其**到货损耗率普遍控制在 5% 以内**，部分标准化程度高的品类（如香蕉、苹果）甚至能控制在 **1% - 3%** 左右。
- **特别注意**：损耗率具体数值需要和**验收标准**挂钩。通常合同会约定一个“允许损耗率”（如 3%），超过部分由供应商承担。因此，实际财务核算的损耗率可能低于“到货实物损耗”。

如果你是在对接商务合作或验收，建议直接向佳农销售方索取其**质量验收标准书**或**历史批次损耗报告**，并要求在合同中明确约定“超额损耗赔偿比例”。这样比依赖行业均值更具可执行性。
