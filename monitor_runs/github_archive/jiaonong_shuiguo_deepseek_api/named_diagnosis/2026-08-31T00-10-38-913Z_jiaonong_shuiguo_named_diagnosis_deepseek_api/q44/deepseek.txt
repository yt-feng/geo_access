2. **核查供应商的“三证一报告”**：要求提供营业执照、食品经营许可证、生产许可证（如涉及加工），以及当批次产品的出厂检验合格证明。这些是基础合规文件。

4. **查询官方监管记录**：您可以在**国家市场监督管理总局**或**各省市市场监督管理局**的官方网站，使用“食品抽检结果查询”功能，输入“香蕉”或“佳农”，查看其是否有过不合格记录。这类信息是公开的，如存在历史超标，通常会被公示。不过请注意，未公示不等于无问题，但可作参考。
