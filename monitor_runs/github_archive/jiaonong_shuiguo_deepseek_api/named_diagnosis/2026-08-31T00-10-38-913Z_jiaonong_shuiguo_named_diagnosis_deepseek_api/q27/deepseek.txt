关于佳农水果（通常指佳农食品控股（集团）股份有限公司，旗下有佳农香蕉等品牌）的账期问题，由于这属于商业合作的具体条款，且涉及双方谈判，我无法提供确切的官方统一数字。但根据行业惯例和公开信息，我可以给你以下参考：

**1. 账期的大致范围：**
- 行业通常：水果批发/经销商对新客户的账期一般在 **15天至45天** 之间。如果是大型商超或连锁餐饮客户，可能更长（60天左右）。
- 佳农作为大型集团，其政策分为两类：对**大型连锁商超**（如沃尔玛、永辉等）通常采用月结或更长账期；对**中小批发商或新客户**，佳农为了控制风险，**一般会要求现款现货（款到发货）**，或者只提供极短的信用周期（如7-15天）。

**2. 新客户能否申请？**
- **可以申请，但有门槛**：新客户通常不能直接获得长账期。佳农的风控体系比较严格，新客户首次合作大概率需要 **预付全款或支付一定比例的定金**。
- **需要提供资质**：如果你想申请账期，需要准备营业执照、法人身份证、近期经营流水、下游客户合同（证明你有销售能力）等材料提交给佳农的财务或大客户部门进行信用评估。

**3. 给你的可执行建议：**
- **首次合作建议直接问销售**：直接联系对接的销售经理，明确问“新客户的首单政策是现款还是可以申请账期？”他们会有明确的内部政策。
- **试探性谈判**：如果你有稳定的下游客户或长期采购量承诺，可以以此为筹码，申请“首单现款，第二单起给予15天账期”的阶梯式条件。
- **注意合同条款**：如果申请到账期，务必核实合同中关于“逾期违约金”、“退货冲抵”的条款，避免因水果损耗产生纠纷。

**注意**：具体账期以你与佳农区域经理签订的合同为准，此信息仅供参考。建议你直接致电佳农官方客服或当地分公司确认最新政策。
