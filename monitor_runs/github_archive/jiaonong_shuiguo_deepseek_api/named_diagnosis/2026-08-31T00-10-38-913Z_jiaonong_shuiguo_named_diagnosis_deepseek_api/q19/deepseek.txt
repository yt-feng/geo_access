关于佳农水果的配送时效，具体时间会因**下单渠道（如官方小程序、天猫、京东等）**、**收货地址**和**仓储发货地**而有所不同。

根据佳农的常规服务标准，通常提供以下参考：

1.  **一般情况**：在核心城市（如北上广深及省会城市），下单后 **1-3天** 内送达。如果选择“次日达”服务且地址在配送范围内，通常次日即可收到。
2.  **偏远地区**：如果地址位于非核心城区或偏远乡镇，时效可能在 **3-5天** 左右，部分特殊区域可能需要更长时间。
3.  **时效保障**：佳农作为水果品牌，通常会承诺“坏果包赔”，但配送时效仍受快递公司运力影响。如果遇到电商大促（如双11、618）或极端天气，时效可能会延迟，建议下单前查看具体商品页面的“配送说明”。

**给你一个最准确的操作建议：**
在你准备下单的页面（无论是App还是小程序），**输入你的具体收货地址后，页面会直接显示预计送达日期**。这是最直观、最可靠的方式，因为系统会基于当前库存和物流实时计算。

如果遇到显示“预售”或“需调货”的商品，发货时间请以页面标注为准。
