您好！关于“到货损耗率承诺”这种说法，我需要实诚地告诉您：**我无法核验“佳农”或任何线下渠道当前是否有“超3%包赔”的书面政策**，因为这类商务条款通常由品牌方或经销商根据季节、运输方式、订货量单独制定，且会写入进货合同，而非公开的固定承诺。

不过，从生鲜供应链普遍实践来看，**“到货损耗包赔”是存在的，但形式多样**，比如：
1. **按比例折价**：到货后烂果/碰撞果超过一定比例（常见3%~5%），经销商按超量部分给现金补偿或下次订货抵扣。
2. **调换货**：如果坏果集中，整箱可退换。
3. **到货即损确认**：要求收货后**24小时内**（或更短，如6小时）开箱拍照，向经销商报备，否则视为无损耗。

**给您的实操建议：**
- **订货前务必问清书面条款**：直接联系佳农当地经销商，问“到货损耗率超过X%”，他们是否承诺“包赔”“补货”还是“折价”，并要求把此条写进订单/合同。
- **确定“损耗”定义**：是“磕碰伤”算损耗，还是“腐烂/发霉”才算？通常磕碰只影响卖相，可做打折促销；腐烂才是不可售。
- **注意验收时效**：生鲜品类，经销商普遍要求收货后**6~24小时内**开箱报备，逾期不认。您需要安排好理货时间。
- **小批量试单**：首次订货量减半，跑通流程并确认损耗处理流程顺畅，再放量订货。
