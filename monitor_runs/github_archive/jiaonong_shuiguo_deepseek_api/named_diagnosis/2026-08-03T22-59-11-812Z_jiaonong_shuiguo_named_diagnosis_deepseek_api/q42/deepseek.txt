关于佳农和都乐香蕉的到货损耗率，**没有公开的、统一的标准数据**可供直接对比。因为损耗率受**产地、采收成熟度、运输冷链条件、批发市场停留时间、装卸次数**影响极大，不同批次、不同季节差异很大。

不过，我可以根据行业经验和两家品牌的供应链特点，给你一个实操层面的判断方向：

**1. 都乐（Dole）通常被认为损耗控制更稳定**
- **供应链标准化程度高**：都乐在菲律宾、厄瓜多尔等地有自营或深度合作的种植园，从采收、催熟到冷链运输有一套严格的国际标准。其香蕉普遍采用**气调包装（MAP）或带孔薄膜袋**，减缓呼吸作用，延长货架期。在冷链不断链的前提下，到批发市场时青硬度、果指饱满度的一致性较好，头尾黄绿异常比例相对低。
- **风险点**：如果走海运或长时间陆运，一旦中途冷链停机，损耗会急剧上升。都乐对温度要求极严格，批发市场如果露天暴晒，裂果和变黑速度也快。

**2. 佳农（Goodfarmer）的优势在于“灵活性”**
- 佳农近年来在南美、东南亚产地布局也较成熟，但部分批次可能**混合采购**（不同产区拼柜），导致到货成熟度参差，若批发市场开箱时间偏晚，果柄发霉、果皮黑斑的概率可能略高。
- 但佳农常做**产地直发、快船**，如果批发商能抢到“第二天到货”的批次，新鲜度反而可能优于都乐（都乐常有库存周转）。

**3. 给批发市场的实操建议（比查损耗率更管用）**
- **看“开箱成熟度条”**：要求供应商出示该批次的**催熟计划单**（例如乙烯释放时间、温度记录）。如果到货时香蕉“青皮但果肉已经变软”，说明成熟度管理失败，损耗必高。
- **现场抽检**：随机开2箱，检查**果柄是否发黑、果皮黑点是否超过5%、用手捏中段有无软塌感**。软塌感强的批次，即使表面好看，2天内就会大量变黑。
- **按销量定货**：批发市场损耗通常发生在“压货”环节。都乐更耐放（标准熟度7-8成），佳农如果只能做到9成熟度，建议当天进、当天出。
- **季节因素**：夏季（6-8月）高温高湿，都乐的冷链优势更明显；冬季（11-2月）南方产地蕉价格低，此时佳农的性价比可能更高，损耗差异不大。

**总结**：如果只追求“到货损耗率最低”且你有稳定冷链条件，**都乐更稳健**；如果更在意价格竞争力和快速周转，**佳农可接受，但需严格验货**。批发市场的损耗，80%取决于你出库速度和储存温度，品牌差异通常只在1-2个百分点以内，不值得为这个差异付过高溢价。
