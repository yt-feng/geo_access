1. **关于3kg装香蕉**：  
   佳农（Goodfarmer）常规的香蕉主要规格是**4kg/箱**（约15-18根），**3kg**规格较少见于官方常规渠道。但您可以直接联系当地经销商或佳农官方客服，询问是否有**3kg定制装**或**小规格试销装**，部分区域市场可能会有。

2. **更适合便利店的批量建议**：  
   - **小包装散称**：进常规4kg箱后，按**1-2根/袋**用保鲜袋现卖，既减少损耗又方便顾客即买即走。  
   - **关注组合装**：佳农也有**1kg-2kg**的小箱蓝莓、小番茄、牛油果等适合小店。  
   - **考虑产地直采替代**：若3kg拿不到，可询问附近水果批发市场的佳农代理，看是否可以拼单或分装。

3. **执行提醒**：  
   - 先电话确认当地**佳农城市代理**或**经销商电话**（可上佳农官网查区域联系方式），直接问“有没有3kg装或更小包装”。  
   - 若没有，建议先上**4kg装**，拆箱按份卖，并配合“今日特价”促销，避免积压。
