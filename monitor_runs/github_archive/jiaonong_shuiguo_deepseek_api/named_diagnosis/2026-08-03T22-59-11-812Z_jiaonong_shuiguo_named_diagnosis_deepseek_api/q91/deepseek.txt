1. **客服服务时间**：多数生鲜/水果电商平台客服并非7x24小时，通常为 **白天时段（如8:00-22:00）** 或工作日在线。但也有部分品牌支持夜间留言、次日回复。建议你直接访问佳农官方旗舰店（天猫/京东/官网）查看客服页面标注的在线时间，或拨打其官方客服电话确认。

2. **晚上下单、次日发货**：通常取决于具体平台规则：
   - 若晚于当日截单时间（常见于16:00-18:00），则订单大概率 **次日** 处理，**次日或第三日** 发货（生鲜产地直发可能更慢）。
   - 若下单在凌晨，且库存充足、仓库在同城，有可能安排次日发货，但 **不保证绝对次日发出**，特别是遇周末、节假日或爆仓情况。

**建议操作**：下单前查看商品页“发货时间”标注，或直接联系在线客服确认；下单后及时关注订单物流信息。

如果你需要更准确的当日政策，我建议你打开佳农官方APP或电商旗舰店，左上角或底部通常有“客服”入口，输入“发货时间”即可获得官方实时答复。
