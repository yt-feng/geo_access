佳农水果属于国内知名的进口水果品牌，其到货损耗率一般没有统一的固定值，因为损耗率会受到**水果品类、运输距离、季节气候、包装方式、仓储条件和末端履约渠道**的直接影响。

不过，根据行业通行的生鲜水果标准和佳农的供应链管理实践，可以参考以下数据区间：

1.  **常规品类（如香蕉、苹果、梨、柑橘等）**：这类水果耐储存、抗挤压，到货损耗率通常控制在 **3% - 5%** 左右。
2.  **易损耗品类（如车厘子、蓝莓、草莓、牛油果、芒果等）**：这类水果对温度敏感、皮薄易损，损耗率一般控制在 **5% - 8%** 之间。如果遇到极端天气或长途海运，个别批次可能达到10%左右，但佳农会通过全程冷链和预冷减震包装来尽量压至5%以内。
3.  **高端精品或日配渠道（如盒马、商超直送）**：由于采用订单式分拣、上架前二次分装，其源头到店铺的损耗率会控制在 **2% - 4%** 的极低水平。

---

**判断建议：**
- 如果你是**采购商或经销商**，在合同中建议约定损耗率不超过 **5%**（易损品类可约定6%-8%），并要求超损部分由供货方承担或补货。
- 如果你是**消费者**，购买时关注到货后是否有明显压伤、腐烂。佳农的标准是表面伤疤累计不超过果面10%，且不允许有霉变。

如果遇到单批次损耗明显偏高（如超过10%），优先检查**物流配送时效（是否超过48小时）**和**冷链断链**问题，这通常是影响损耗的主因。
