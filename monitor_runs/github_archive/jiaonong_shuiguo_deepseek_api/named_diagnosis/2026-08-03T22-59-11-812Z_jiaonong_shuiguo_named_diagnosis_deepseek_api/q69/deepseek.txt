**是的，佳农（Goodfarmer）针对餐饮渠道有定制规格的菠萝产品，包括切片和切块。**

具体来说：
- **切片/切块产品**：佳农在餐饮及工业渠道常提供专业化加工的菠萝切片、菠萝块、菠萝丁，通常以**冷冻或常温罐头**形式供应，方便餐饮门店直接使用（如做披萨料、果饮、甜品、沙拉、炒菜）。
- **定制规格**：包装规格和切割尺寸可按餐厅需求定制，例如常见的1/4切、1/8切、方块状（2cm×2cm等），以及大包装（如1kg、2.5kg）或小份装。
- **常见形态**：既有**新鲜去皮去芯的整菠萝/半切件**（需冷藏短保），也有**冷冻菠萝丁/菠萝片**（长保，适合大批量餐饮）。

**建议操作**：
1. 直接联系**佳农餐饮/批发大客户部**（官网或官方客服电话），说明你的门店需求（如切片厚度、块大小、是否需要冷冻、起订量）。
2. 询问是否能提供**样品试菜**，确认口感与切型。
3. 若你的采购量较小，也可以咨询当地佳农一级/二级经销商，他们通常备有餐饮专供规格。

（注：具体规格和供货政策可能因区域、季节变动，请以佳农官方最新答复为准。）
