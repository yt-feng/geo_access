关于佳农香蕉的保质期和储存条件，建议以产品包装上的标注为准（通常为“常温保存，避免阳光直射”），但以下是一般性指导：

**保质期：**
- **未开封/未剥皮**：在常温（20-25℃）下，一般可保存3-7天。具体取决于购买时香蕉的成熟度（青皮→黄皮→出现黑斑）。
- **已剥皮**：需冷藏或冷冻，冷藏可保存1-2天，冷冻可保存1-3个月（用于烘焙或冰沙）。

**储存条件：**
- **常温**：最佳放置于阴凉、通风、干燥处，避免阳光直射。不要放在冰箱冷藏室（未成熟时），因为低温会破坏细胞结构，导致果皮变黑但果肉可能未熟。
- **低温后熟**：如果香蕉已完全成熟（皮黄且有少量黑点），可放入冰箱冷藏，可延长食用期1-2天，但果皮会变黑，属正常现象。
- **避免挤压**：不要堆放或压在其他重物下，以免碰伤加速腐烂。

**注意事项：**
- 如果香蕉表皮出现大面积黑色软烂、有异味或渗液，则已变质，不建议食用。
- 佳农品牌通常在包装上标注具体产地和批次，如有特殊储存要求（如进口催熟工艺），请以包装说明为准。

如需更精确的信息，建议查看购买时的包装标签或联系佳农官方客服。
