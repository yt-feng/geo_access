关于佳农水果的物流模式：

**1. 物流主体：以第三方为主，叠加部分自有资源**
佳农（Goodfarmer）是一家以进口和高端水果为主的企业，其物流主要依赖**第三方冷链物流公司**，并非完全依靠“三通一达”（圆通、申通、中通、韵达这类常温快递），因为水果对温控要求高，三通一达的标准快递一般不适用于大宗或高价值生鲜。在实际操作中，佳农更多与**顺丰冷运、京东物流（冷链）** 以及国内专业冷链运输公司（如鲜生活、九曳供应链等）合作，同时在全国主要分仓配有自己的**冷链仓储和干线车队**（含冷藏车），用于城市配送和门店补货。简单说：**干线运输多用自有或长期包租冷链车，末端配送委托专业冷链快递。**

**2. 冷链覆盖率：较高，但非100%**
- **产地/进口端**：佳农在泰国、智利、新西兰等源头有预冷处理和冷藏集装箱运输，覆盖率接近100%。
- **仓储端**：在国内重点城市（如上海、广州、北京等）建有自营冷库，覆盖率主要覆盖一、二线城市。
- **末端配送**：在核心城市实现了“全程冷链”（冷库到冷柜），但三四线及以下城市，常因成本原因转为“泡沫箱+冰袋”的常温快递模式，冷链覆盖率会下降。总体而言，其一二线城市冷链覆盖率约在90%以上，全国综合覆盖率预估在70%-80%之间。

**建议**：如果你在购买或考核其供应链，最可靠的判断方式是直接查看**单笔订单的物流轨迹**（是否显示“冷链运输”）以及**到货时的包裹温度**。若需准确数据，可致电佳农客服或查阅其上市信息披露（佳农曾递交IPO材料，招股书中有冷链物流详细数据）。注意，不要轻信网络宣传的“100%冷藏”，实际末端常有降级。
