佳农水果（Goodfarmer）目前在国内的主要配送中心/仓配枢纽集中在一二线城市及部分区域中心城市，例如：

- **华东区**：上海（总部，大仓）、苏州、宁波、杭州等；
- **华南区**：广州、深圳、佛山；
- **华北区**：北京、天津、青岛、济南；
- **华中区**：武汉、长沙、郑州；
- **西南区**：成都、重庆；
- **西北区**：西安（部分区域仓储）；
- **东北区**：沈阳、大连等。

*以上为常见区域布局，具体仓点可能随业务调整，建议以佳农官方客服或当地经销商为准。*

**关于下沉市场县城次日达：**

能否实现“次日达”取决于**县城距最近配送中心的距离、当地冷链/物流网络、以及佳农在该县是否设有合作经销商或前置仓**。

一般情况如下：

1. **有合作经销商/前置仓的县城**：在核心物流干线附近，可实现次日达或隔日达（尤其省会周边县）。
2. **一般县城**：通常需要2～3天，甚至更久，尤其非冷链干线末端。
3. **偏远县域**：可能只能发快递常温或部分冷链，生鲜水果时效不稳定。

**建议操作：**
- 先在**佳农官方小程序/天猫旗舰店**输入你的县城地址测试下单，系统会直接显示预计送达时间。
- 或联系佳农客服（400热线），询问你所在县城是否有专线配送。
- 如果测试显示时效太长，可优先选择**当地连锁商超（如大润发、永辉等）的佳农专柜**，或社区团购平台（美团优选/多多买菜）中的佳农分销，这些通常本地仓发货，能达到次日或更短时效。

**总结**：一二线城市大概率次日达；下沉县城需测试具体地址，可能性偏低，建议提前查单验证。
