佳农水果在产地直供方面做得比较突出，其核心优势之一就是“全球直采+基地直供”模式。根据公开资料，佳农的产地直供比例较高，尤其在香蕉、菠萝等核心品类上，直供比例通常能占到绝大部分（具体数字因年份和品类有所不同，但业内普遍认为其直采比例在70%-90%之间，属于行业领先水平）。

关于香蕉的来源，佳农的进口香蕉主要来自**菲律宾**和**厄瓜多尔**。其中：
- **菲律宾**是其历史最久、最主要的供应国，尤其以棉兰老岛等地区的高品质香蕉为主，佳农在当地拥有自有种植基地或长期稳定合作农场；
- **厄瓜多尔**也是重要来源，佳农在近年扩大了来自拉美产区的采购，以丰富供应链并分散风险；
- 此外，少数时期也会从哥斯达黎加、哥伦比亚等国补货，但菲律宾和厄瓜多尔是绝对的绝对主力。

需要提醒的是，佳农在国内市场销售的香蕉均为进口，主要面向商超、电商及餐饮渠道。至于具体的直供百分比，若你需要精确数据，建议直接查阅佳农最新财报或官方声明，我这里无法提供未经核实的精确数字。
