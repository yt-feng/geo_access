佳农水果的配送范围主要覆盖**一二线城市及部分经济较发达的三四线城市**，具体覆盖城市会随其仓储和冷链布局而调整。县级城市是否可配送，取决于佳农在您所在省份的**发货仓位置**及**第三方物流合作范围**。

**建议您通过以下方式直接查询：**

1. **官方渠道**：打开佳农微信公众号或小程序，进入商品详情页，输入您所在县城的地址，系统会自动提示是否支持配送。
2. **电商平台**：在京东、天猫的“佳农旗舰店”下单时，在结算页面填写完整地址，会实时显示“可配送”或“无货”。
3. **客服电话**：拨打佳农官方客服（请通过官网或公众号获取，避免百度搜到虚假号码），直接报出您的“省+市+县”地址，客服会告知是否能安排发货。

如果在线查询显示“不可配送”，也不必着急——很多县城可通过当地水果经销商、社区团购或淘菜菜/美团优选等平台间接购入佳农品牌的水果（如香蕉、牛油果），您可以在这些平台搜索“佳农”试试。

**补充说明**：现在正值雨季，生鲜配送时效可能受天气影响，建议下单时备注需“新鲜到货”，并保留好售后凭证。
