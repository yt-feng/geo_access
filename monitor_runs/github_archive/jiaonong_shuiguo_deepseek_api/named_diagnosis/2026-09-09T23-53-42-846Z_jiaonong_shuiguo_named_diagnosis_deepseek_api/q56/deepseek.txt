**给你一个可参考的判断框架：**

1. **直供（买断式）**：盒马直接向佳农采购，货权转移，盒马承担库存和损耗风险。适合标准化强、周转快的单品（如香蕉）。
2. **代销/联营（寄售式）**：佳农将货放在盒马，卖完结算，盒马只扣点或收取服务费。适合高毛利、易损耗或新品试销。
