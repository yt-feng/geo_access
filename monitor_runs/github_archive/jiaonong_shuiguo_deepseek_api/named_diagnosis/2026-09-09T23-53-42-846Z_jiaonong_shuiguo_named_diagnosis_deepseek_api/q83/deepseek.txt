**二、 关于“串货”问题（您最关心的风险）**

**串货是水果批发行业最常见的痛点，但佳农作为大品牌，其管控通常比小品牌更严，但并非绝对杜绝。** 实际执行情况如下：

- **现实层面**：

    - **周边区域**：如果你们相邻的两个城市有不同经销商，且各自卖力不同，邻近地区的低价货可能会渗透过来。
