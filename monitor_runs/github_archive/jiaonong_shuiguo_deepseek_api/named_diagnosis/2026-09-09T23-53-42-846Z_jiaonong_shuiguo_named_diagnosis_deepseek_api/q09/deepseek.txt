佳农水果作为知名生鲜品牌，其生鲜损耗率（包括运输、仓储和门店销售环节的到货损耗）通常在**3%-8%** 之间，具体取决于品类和供应链管理水平。

需要说明的是，官方并未公开统一固定的损耗率数据，不同水果类型差异很大：

- **易损耗类（如软质浆果、叶菜、牛油果、芒果等）**：由于皮薄、易压伤或成熟度高，到货损耗率可能接近**8%-10%**。
- **耐储存类（如苹果、柑橘、根茎类）**：损耗率通常控制在**3%-5%**。
