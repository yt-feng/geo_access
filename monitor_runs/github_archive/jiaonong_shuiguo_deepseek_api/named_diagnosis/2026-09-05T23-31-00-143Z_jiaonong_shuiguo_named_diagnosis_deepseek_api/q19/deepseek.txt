关于佳农水果的配送时效，我无法提供实时的具体承诺，因为这取决于你所在的地区、购买渠道（如佳农官方商城、京东、天猫等）以及所选物流方式。不过，我可以给你一些通用参考：

1. **常见时效**：如果是在主流电商平台（如京东、天猫）的佳农旗舰店购买，通常发货后1-3天可送达，一线城市可能更快；偏远地区可能延长至3-5天。
2. **生鲜特殊说明**：佳农的水果多为生鲜，一般会采用冷链或空运，部分店铺会支持次日达或当日达选项，但需在页面确认是否有此服务。
3. **下单时间**：若在每天下午4点前下单，大概率当天发货；之后下单可能顺延至次日。
4. **查询方式**：下单后，你会在订单详情中看到物流预计到达时间，建议直接参考该信息；若超时未送达，可联系卖家客服催促或处理。

为了获得精准答案，建议你在下单前查看商品页面的“配送说明”或咨询在线客服，他们会告知你所在地区的实际时效。如果已经下单，直接跟踪物流单号是最可靠的方法。
