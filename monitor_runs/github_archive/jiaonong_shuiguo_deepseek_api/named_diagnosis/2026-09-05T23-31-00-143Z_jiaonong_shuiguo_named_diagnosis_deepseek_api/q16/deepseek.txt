关于佳农水果的售后服务和坏果处理，以下是一些关键点供你参考：

**1. 售后服务政策（常见情况）**
佳农作为大型水果品牌，通常提供“坏果包赔”或“售后无忧”政策。但具体政策可能因购买渠道（天猫、京东、拼多多、超市线下等）或活动有所不同。一般要求提供**坏果照片**（需包含坏果和快递单号在同一画面，证明是运输问题或到货质量问题）。

**2. 到货有坏果的处理步骤（通用流程）**
- **第一时间拍照取证**：保留坏果外观、内部腐烂情况，以及完整包装箱或单号的照片。
- **联系购买渠道**：
  - 如果是电商平台（淘宝/京东等），直接联系店铺客服，发送照片，说明“到货坏果”。
  - 如果是线下商超购买，回门店或拨打包装上的客服电话。
- **明确要求**：通常商家会按坏果比例退款（如坏3个退30%），或补发等价水果。**优先选择退款**，避免补发后再次出现坏果。
- **时效要求**：多数平台要求到货后24-48小时内反馈，请尽快处理。

**3. 需要注意的例外情况**
- 如果坏果是因个人存放过久、或已削皮切开后才坏，一般不在赔付范围。
- 如果水果是“特价处理”或注明“轻微碰伤不赔付”的，可能无法全额赔偿。
- 高峰季节（如双11）物流延误可能导致部分损坏，建议优先签收，若拒收需与卖家确认规则。

**4. 如果客服推诿怎么办？**
- 保存好聊天记录、订单编号，向平台官方客服投诉（如天猫小二、京东维权）。
- 若购买的是官方旗舰店，可拨打佳农官网/包装上的400客服电话反馈。

**总结操作顺序**：拍照（含单号）→ 当天联系客服 → 提出按坏果比例退款 → 若不处理则升级至平台投诉。多数情况下佳农处理及时，但极端情况需耐心沟通。

如果购买渠道较特殊，建议直接提供订单截图咨询该渠道客服最准确。
