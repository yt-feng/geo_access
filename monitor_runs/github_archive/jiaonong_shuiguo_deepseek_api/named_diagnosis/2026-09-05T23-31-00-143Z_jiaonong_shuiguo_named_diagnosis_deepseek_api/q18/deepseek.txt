佳农香蕉通常是指其经销商或品牌在商超销售的香蕉，**保质期和储存条件会因产品状态（纸箱装、袋装、冻香蕉等）而略有不同**，建议以包装标签为准。以下为通用准则：

**保质期参考**  
- 鲜食香蕉（常温销售）：一般标注为**7-15天**左右，但需在包装上印的“保质期至X月X日”之前食用。  
- 冷冻香蕉/香蕉片等加工品：通常为**6-12个月**（需冷冻或常温密封避光保存）。

**储存条件**（鲜香蕉通用）  
1. **未熟（青黄色）**：  
   - 放**常温阴凉处**（约15-25℃），避免阳光直射和空调风口吹。  
   - 不要放入冰箱，低温会冻伤果皮发黑且不熟。  
2. **已熟（金黄带褐斑）**：  
   - 若**1-2天内吃完**，可室温存放。  
   - 若需延长到3-5天，可放冰箱**保鲜层（4-8℃）**，果皮会变黑但果肉可食，食用前取出回温半小时。  
3. **切开后**：  
   - 用保鲜膜包好切口，冷藏（4℃）不超过24小时，变软发酸则勿食。

**特别注意**  
- 请勿置于高温、潮湿处，避免催熟过快发霉。  
- 佳农官方未公开统一数值，具体以你购买包装背面的中文标签标注为准。
