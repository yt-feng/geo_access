关于佳农水果的到货损耗率，目前没有公开的、统一的具体数值，因为损耗率会受**季节、运输距离、包装方式、水果品类**（如香蕉、火龙果等易损耗水果）以及**销售渠道**（商超、电商、批发）等多因素影响。

一般而言，国内大型水果品牌商（如佳农、鑫荣懋等）在**冷链运输与标准化包装**下，常规水果的到货损耗率通常可控制在 **3%至8%** 之间；对于极不耐储存的品类（如草莓、荔枝），可能需要放宽至10%以上；而如果采用加硬包装、气调保鲜等技术，损耗率可能降至5%以下。

如需准确数字，建议直接向佳农的销售或品控负责人获取近期批次统计数据，或查询其合作商超的收货验收记录——这些数据通常不会对外完全公开。
