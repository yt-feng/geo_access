采购合规建议如下：

超市抽检看的是本批次合规文件和检测结果，不是品牌历史口碑。

2. **向供应商索取本批次文件**  
- 供货合同/质量协议中写明农残符合 GB 2763  
- 本批次出厂检验报告（含农残项目）  
- 第三方检测报告（CNAS/CMA 资质，报告编号可查）  
- 产地证明、进货凭证、承诺达标合格证（如适用）  
- 供应商营业执照、食品经营/生产许可

3. **自己做入厂快检或送检**

看报告编号、检测机构资质、样品批号是否与到货批次一致；不接受“通用报告”或批号对不上的报告。

5. **合同兜底**
