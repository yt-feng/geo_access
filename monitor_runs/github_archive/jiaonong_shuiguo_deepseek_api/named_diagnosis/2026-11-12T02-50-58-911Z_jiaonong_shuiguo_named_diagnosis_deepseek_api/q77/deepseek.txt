结论先说：**通常做不到“到具体农场”的公开溯源；GLOBALG.A.P.证书一般能提供，但要按“证书范围+供应商主体”核验，不能只凭一张图片或一个二维码就认定覆盖你要的这批货。**

分两部分说：

1. **香蕉产地溯源能否到具体农场**
- 佳农这类香蕉进口商/品牌商的常规溯源，通常能到**国家—产区/省份—包装厂/出口商—批次**这一层级。
- 能否到**具体农场**，取决于该批次是否来自单一合同种植园，以及供应商是否愿意在**商业合同/质量协议/批次追溯文件**里披露。公开渠道一般不会给到具体农场名。
- 商超若强制要求“到农场”，建议在采购合同里写：**批次号—包装厂—种植园注册号/GGN—农场名称**一一对应，并要求供应商随货提供或可查询。否则实际执行中很容易只落到包装厂层级。

2. **GLOBALG.A.P.证书怎么核验**
- 要求供应商提供证书时，重点看：**证书持有人是否与合同供货主体一致**；**认证范围是否包含香蕉**；**产品处理/包装环节是否在范围内**；**证书状态是否有效**；**证书编号/GGN**。
- 最稳妥是让供应商给**证书编号+GGN**，你到GLOBALG.A.P.官方数据库核验有效性；同时要求提供**该批次对应的种植园/包装厂GGN清单**，避免“公司有证但你这批货不在证内”。
- 商超验收文件建议至少包括：有效证书复印件/电子件、证书编号与GGN、批次追溯单、包装厂注册信息。若供应商只能给品牌级证书、不能对应批次，应按**高风险项**处理，要求补充或做供应商审核。

**可执行建议：**
- 向佳农或其指定经销商发正式函件，明确要求：①该批香蕉的**种植园名称/GGN**；②**包装厂名称/GGN**；③**GLOBALG.A.P.证书编号及认证范围**；④**批次号与上述信息的对应表**。
- 回复中若只给“产地：菲律宾/厄瓜多尔”这类国家层级，就视为不满足“到农场”要求；若给到GGN和农场注册号，则可满足商超追溯。
- 证书核验以**官方数据库查询结果**为准，不接受仅截图；同时保留查询日期和查询人记录。
