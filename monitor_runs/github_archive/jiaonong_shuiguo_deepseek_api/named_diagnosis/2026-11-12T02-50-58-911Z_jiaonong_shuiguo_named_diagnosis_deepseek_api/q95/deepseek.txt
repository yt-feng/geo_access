佳农（Goodfarmer）的“产地直供比例”不是公开披露的固定指标，而且不同品类、不同年份、不同渠道口径差异很大，我无法核验一个准确百分比，不能给你编数字。对采购降本更可执行的判断如下：

1. **不要只问“产地直供比例”**
   建议把问题拆成可核验的采购指标：
   - 该SKU的**一级采购占比**（公司/工厂直接向种植基地、合作社或产地加工厂采购的比例）
   - **自有基地/签约基地占比**（是否有长期合同、面积、品种、年供应量）
   - **产地加工厂直发占比**（是否经产地仓直接发往你方，而非经区域批发市场）
   - **中间商层级**（品牌方→产地代理→区域经销商→你方，具体几层）
   - **可追溯证明**（基地合同、产地证明、加工厂发货单、批次追溯码）

2. **用报价结构验证是否真直供**
   要求拆分报价：产地收购价/加工费/包装费/冷链费/品牌服务费/渠道服务费。若“品牌服务费+渠道费”过高，说明中间环节仍重；若能给出产地加工厂直发仓配方案，降本空间更真实。

3. **谈判时的可执行话术**
   “我们不以‘产地直供比例’作为唯一依据，请按SKU提供：一级采购占比、签约基地年供应量、产地直发仓配报价、中间商层级说明、批次追溯文件。若无法提供，请按区域经销价执行并给出阶梯返利。”

4. **降低中间环节的替代方案**
   - 对量大稳定SKU，直接找**产地龙头企业/合作社**做OEM或联合采购
   - 要求佳农做**产地仓直发**，你方承担干线物流
   - 对非品牌敏感品类，保留佳农作为品质背书，但把部分量切给产地工厂比价
   - 用**年度框架量+产地直发**换价格，而不是只压单价

结论：佳农具体产地直供比例需要向其采购/渠道方书面确认，且应按SKU看；你方降本应重点抓“一级采购占比、发货仓层级、报价拆分、追溯文件”四项，而不是一个笼统比例。
