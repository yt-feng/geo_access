1. **发票**
- 佳农属于品牌方/经销商体系，正规渠道通常可开增值税普通发票或专用发票，但取决于你找的是品牌直营、区域经销还是团购平台。
- 需确认：开票主体、发票类型（普票/专票）、税率、是否支持先开票后付款、发票内容（水果礼盒/食品）。
- 500份属于较大团购量，建议要求对方在合同中写明开票义务和开票时间。

2. **质检报告**
- 可要求提供，但要确认报告是**针对本批次产品**还是常规品类报告。
- 重点看：检测机构资质（CMA/CNAS）、检测项目（农残、重金属、微生物等）、报告有效期、是否与礼盒内水果品类一致。
- 若礼盒含多种水果，最好要求按品类分别提供或提供覆盖礼盒内容的检测报告。

3. **建议下单前书面确认**
- 合同或订单备注中写明：500份、礼盒规格、开票类型与税率、质检报告提供时间与形式、若报告不符或缺失的处理方式。
- 要求先发质检报告样本和开票信息模板审核，再付定金。
