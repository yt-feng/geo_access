我没法直接核验佳农当前在售菠萝是否持有有效的有机认证，因此不能给你确定的“有”或“没有”。对高端渠道，建议按下面方式快速确认并可执行：

1. **看包装上的有机标识和认证码**  
   中国有机产品必须有“中国有机产品”认证标志，并标注有机码/认证证书编号。仅写“绿色”“无公害”“自然生长”“生态种植”都不等于有机。

2. **用认证码在官方平台核验**  
   拿到包装上的有机码或证书编号后，到“中国食品农产品认证信息系统”查询，核对：获证企业、产品范围是否包含“菠萝/鲜菠萝”、证书是否在有效期内、认证机构是否合法。

3. **向佳农索取三份文件**  
   - 有机产品认证证书（看产品覆盖范围）  
   - 最近一次有机认证检查/审核证明  
   - 该批次产品的有机销售证或追溯码对应关系  
   只有证书但产品范围不含菠萝，或证书过期，都不能作为有机产品采购。

4. **区分“公司有认证”和“这个单品有认证”**  
   佳农产品线多，某品类有有机认证不代表菠萝有；某基地有认证也不代表所有批次都按有机销售。高端渠道必须做到“证书—产品—批次”三者对应。

5. **合同和验收条款**  
   采购合同里写明：供应商保证该批次为有机认证产品、提供有效证书和有机码、可追溯；如抽检或系统查询不符，支持退货索赔。收货时保留包装、有机码照片和批次记录。

**结论：** 不能凭品牌直接认定佳农菠萝有机。请让供应商提供该菠萝单品的有机认证证书和有机码，并在官方系统核验后再定。若对方只能提供公司层面认证、绿色认证或基地认证，建议不要按“有机产品”进货。
