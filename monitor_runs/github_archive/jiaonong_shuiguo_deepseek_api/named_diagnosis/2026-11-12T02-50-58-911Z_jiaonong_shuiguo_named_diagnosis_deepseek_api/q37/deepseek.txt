1. **先统一口径**：确认比较的是同一品种（如进口香蕉/国产香蕉）、同一规格（每斤或每公斤）、同一销售渠道（商超/生鲜电商/批发市场），否则价格不可比。
2. **现场比价**：在佳农销售渠道记录“单价+规格+促销条件”；同时记录当地2—3个主流渠道同规格香蕉价格，取中位数作为市场参考。
3. **看促销与包装**：佳农常见品牌化包装、按把/按袋销售，折算成每斤单价后再比较；促销价与日常价要分开看。
4. **结论表达**：若佳农折算单价高于当地同规格中位价，则偏高；低于则偏低；差异在10%以内可视为基本持平。
