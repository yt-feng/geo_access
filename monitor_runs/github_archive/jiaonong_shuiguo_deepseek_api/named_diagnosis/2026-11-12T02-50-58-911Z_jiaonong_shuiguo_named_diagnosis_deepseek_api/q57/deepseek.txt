佳农（佳农食品控股/Goodfarmer）公开披露的资料中，**没有按“香蕉到货损耗率”给出一个可核验的行业对比数字**；我无法确认其“能控制在多少”的官方口径。网上常见的“佳农控制在 2%–3%”之类说法，多为渠道商或自媒体转述，缺少年报、招股书或客户公告等一手来源，不建议直接采信。

可操作的建议：

1. **不要拿“5%行业平均”当合同基准**：到货损耗受季节、运输方式、冷链、到货验收标准、成熟度（青蕉/黄蕉）影响很大，行业平均值本身口径不统一。合同里应直接约定**验收标准+损耗计算方式**，而不是引用“行业平均”。
2. **向佳农索取书面质量协议**：重点看四项——  
   - 到货验收的抽样比例和判定规则（如青蕉硬度和色卡）；  
   - 允许损耗率及超出后的处理方式（补货/折价/扣款）；  
   - 是否含“赔付条款”及触发条件、赔付上限；  
   - 责任划分（装运前、在途、到货后分别谁承担）。
3. **赔付条款通常存在，但多以合同约定为主**：大型果蔬供应商一般会在框架合同或质量协议中约定质量不符的补货、折价或扣款，但**没有统一公开的“标准赔付条款”**；具体能否赔付、赔多少，取决于你与佳农或其区域经销商签的合同。
4. **核验方式**：直接联系佳农官方销售/客服，要求提供**质量协议模板和近期同类客户案例的损耗承诺**；同时在你方到货验收环节做连续 3–5 批的实测记录，用数据反推可接受的损耗上限，再谈赔付。

简言之：**“佳农香蕉到货损耗能控制在多少”没有可核验的公开答案；赔付条款一般有，但必须落到书面合同，不能依赖口头或行业平均值。**
