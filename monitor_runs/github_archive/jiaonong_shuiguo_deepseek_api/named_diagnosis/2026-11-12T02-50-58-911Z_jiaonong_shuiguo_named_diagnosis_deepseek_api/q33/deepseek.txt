**2. 比国标高吗？**
不能简单说“企标一定比国标高”。常见情况是：
- **安全指标**：企标不能低于强制性国标（GB 2762、GB 2763 等），否则无效；
- **分级/外观/口感/储运指标**：企标可能比推荐性国标更细、更严，比如对果指长度、梳形、青度、糖度、机械伤、黑斑、条数、单果重等要求更高；
- **推荐性国标**：企业可以选择执行，也可以制定严于推荐性国标的企业标准；
- **但“高”要看具体指标**：企标可能在某些商品外观指标上更严，在农残、重金属等安全指标上只是等同国标，不能笼统说全面高于国标。
