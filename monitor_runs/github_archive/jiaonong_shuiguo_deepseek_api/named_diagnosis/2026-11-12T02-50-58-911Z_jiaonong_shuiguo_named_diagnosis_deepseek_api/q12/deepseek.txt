佳农香蕉的具体在售规格会随销售渠道、季节和批次变化，公开且可核验的稳定分级清单有限，因此我不能直接给你一份“官方固定规格表”。下面给你可执行、可判断的框架，并说明如何拿到准确信息。

**一、佳农香蕉常见规格维度（按行业通行做法）**
佳农香蕉通常按以下维度组合定规格，而不是单一“几种”：

1. **单根重量/果指等级**：如小果、中果、大果、特大果，常见以单根克重区间区分。
2. **每把/每梳根数**：如3-5根、6-8根、整梳等，商超和生鲜电商常见。
3. **整箱净重**：如4.5kg、7kg、10kg、13kg等，批发和商超配送常见。
4. **果指长度与粗度**：出口/商超常按长度和周长分级。
5. **成熟度/催熟阶段**：如青蕉、微黄、黄熟，对应不同渠道周转。
6. **外观等级**：A级/一级果、二级果、加工果，按条斑、机械伤、梳形整齐度区分。

**二、不同渠道的分级标准建议（可执行判断）**
- **大型商超/精品超市**：优先一级果，单根重量均匀、长度一致、梳形整齐、无机械伤和明显条斑；成熟度偏黄熟，按把或小规格包装，周转快。
- **生鲜电商/社区团购**：一级或二级果均可，强调单根重量稳定、每把根数固定、耐运输；成熟度略青，减少到货损耗。
- **批发市场/农贸**：按整箱净重和单根等级混级销售，二级果占比可高，重点看货架期和价格带。
- **餐饮/加工渠道**：对果形整齐度要求低，可用二级果或加工果，重点看成熟度、出肉率和批次稳定性。
- **出口渠道**：通常要求果指长度、粗度、梳形、青熟度高度一致，按出口标准分级，具体以目的国和客户合同为准。

**三、如何拿到佳农的准确规格**
1. 看佳农官方旗舰店/官方小程序商品页的“规格参数”，以在售SKU为准。
2. 直接联系佳农区域经销商或销售，索取当批次《产品规格书》或报价单。
3. 商超采购可要求供应商提供到货验收标准，通常包含单根克重、每箱净重、成熟度、缺陷率。
4. 注意区分“品牌标称规格”和“渠道定制规格”，同一品牌在不同渠道的箱规和果指等级可能不同。

**结论**：佳农香蕉没有公开统一的“固定几种规格”可直接核验；实际按单根重量、每把根数、整箱净重、成熟度和外观等级组合定规格。不同渠道的分级核心是：商超重外观均匀和成熟度，电商重耐运和固定根数，批发重箱规和货架期，餐饮加工重出肉率和成本。准确规格应以当批次官方商品页或经销商规格书为准。
