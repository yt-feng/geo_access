佳农（Goodfarmer）香蕉的分级标准和一级/二级果的价差，**属于企业内部或渠道政策，公开可核验的统一标准并不对外发布**。我无法凭空给出具体分级参数或价格差，否则会误导你。可执行的做法如下：

**1）先拿到“合同级”的分级口径**
直接向佳农区域销售/渠道经理索取：
- 香蕉验收分级标准（文字或图片版）
- 一级果/二级果的判定项：果指长度、粗度、条数/箱、单果重区间、梳形整齐度、青熟度/催熟后色号、机械伤/病斑允许比例、果轴长度、断指率、冷害/水烂等缺陷容忍度
- 包装规格（箱重、每箱把数/条数、内衬、托盘）
- 到货验收的抽检比例和扣罚规则

**2）价格差不要问“差多少”，要问“按什么条件差”**
影响价差的核心变量：产地（厄瓜多尔/菲律宾/越南/国产等）、季节、到货港口、规格（如每箱12kg/13kg、条数）、青蕉还是催熟蕉、账期与结算方式、是否含税含运费、起订量。价差在不同月份和不同港口可能明显不同。

**3）让供应商给“同批次报价单”**
要求同一批次、同一规格下的一级果与二级果分别报价，并注明：
- 单价（元/箱或元/公斤）
- 规格与净重
- 缺陷允许范围
- 是否含税、运费、卸货费
- 账期/现结折扣
这样你才能算出真实价差，而不是听到一个笼统百分比。

**4）批发商侧建议的谈判动作**
- 用“二级果做促销/加工/食堂渠道”的走量能力换一级果价格
- 要求按周或按月锁价，减少季节性波动
- 明确降级扣款规则：到货抽检不合格时，是按二级果结算还是扣重/退货
- 先小批量试单，记录到货合格率，再谈年度框架价
