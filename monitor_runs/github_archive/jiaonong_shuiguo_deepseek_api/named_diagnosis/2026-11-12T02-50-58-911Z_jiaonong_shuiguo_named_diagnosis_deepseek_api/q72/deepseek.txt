佳农一般以鲜果贸易和标准化鲜果供应为主，是否能按茶饮店要求提供“去皮切块”的定制加工，需要看具体区域仓配和产品线，不能一概而论。建议你按下面方式快速确认，避免影响上新：

1. **先问采购/经销商是否提供“鲜切菠萝”或“定制加工”**
   - 直接问：能否供应去皮切块的佳农菠萝？规格（块重/厚度）、包装（真空袋/托盘）、冷链配送频次、最小起订量、保质期和到店验收标准。
   - 如果对方只供整果，通常会推荐当地鲜切加工商，而不是品牌方直接加工。

2. **区分“原厂加工”和“本地鲜切”**
   - 佳农若没有全国统一鲜切服务，常见做法是：整果到当地中央厨房/鲜切厂加工，贴不贴佳农品牌要看授权。
   - 茶饮店要重点确认：原料是否确为佳农菠萝、加工方资质、冷链温度、当天/次日配送能力。

3. **没有加工服务时的替代方案**
   - 找本地有资质的鲜切水果中央厨房代加工，按你的块型标准出样；
   - 或门店自行切配，但需评估人工、损耗、冷藏空间和食品安全操作；
   - 也可对比佳农整果与本地鲜切供应商的到店成本（含损耗和人工），不只看单价。

4. **谈判时建议锁定这些条款**
   - 规格：每块克重范围、去眼是否彻底、成熟度/糖度范围；
   - 包装与冷链：真空/气调、冰袋/冷藏车、到店温度；
   - 损耗与售后：变色、出水、异味、短重如何处理；
   - 起订量与价格：按日/周用量谈，先小批量试产试饮。

结论：**不要默认佳农一定提供去皮切块服务，先向你的佳农采购渠道确认是否有鲜切产品或当地代加工资源；若没有，优先找本地合规鲜切中央厨房，并明确原料品牌和加工标准。**
