这属于具体企业的内部品控数据，公开渠道没有可靠、可比的“到货损耗率”口径，我无法给出谁更低的确定结论，也不应编造数字。

但针对批发市场对损耗敏感的场景，给你可执行判断方法：

1. **不要比“品牌平均损耗率”**，要按同一批次、同一运输方式比：
   - 同产地/同等级（如一级蕉、青蕉转黄蕉）
   - 同运输距离与冷链方式（常温车/冷链车）
   - 同到货季节（夏季与冬季差异很大）
   - 同验收时点（到场即验 vs 放熟后验）

2. **建议用这4个指标做7—10批对比**：
   - 到场次品率：机械伤、压伤、断指、黑斑比例
   - 催熟后损耗率：转黄后3天内的坏果率
   - 货架期：达到可售状态后能维持几天
   - 赔付响应：到货异常时供应商补损/换货速度

3. **实操建议**：
   - 先各进1—2车小批量同规格香蕉，按统一验收表记录；
   - 重点看“催熟后损耗”而不是只看到场外观，香蕉很多损耗在转黄后才暴露；
   - 把损耗折算成每箱/每斤综合成本，而不是只看进货价；
   - 要求供应商明确到货标准、赔付标准和冷链责任。

4. **结论口径**：
   - 若你要我判断“哪个更低”，需要你提供近几批的验收记录；
   - 没有数据时，最稳妥的是：**以你市场实测的催熟后损耗率和赔付速度定供应商，不采信品牌宣传的平均损耗率。**
