佳农香蕉没有统一“保质期”，主要看成熟度和包装形式；市售常见为青香蕉或黄香蕉，按以下方式判断和储存更实用：

**储存条件**
- **未熟/偏青香蕉**：室温阴凉通风处存放，避免阳光直射和暖气旁；可与苹果同放加速催熟。
- **已熟黄香蕉**：尽快食用；想延缓变黑可冷藏，但表皮会变黑、果肉仍可正常，取出后尽快吃。
- **切开后的香蕉**：密封冷藏，建议当天吃完。
- **不要**：整把香蕉装进密闭塑料袋久放，容易闷坏、发霉。

**保质期参考**
- 室温青香蕉：通常 **3～7天** 转黄成熟，具体看气温和成熟度。
- 室温已熟黄香蕉：一般 **1～3天** 口感较好。
- 冷藏熟香蕉：可延长 **2～4天**，但表皮会变黑。
- 冷冻香蕉泥/切片：密封冷冻可放 **1～2个月**，适合做奶昔、烘焙。

**判断变质**：果肉发酸、出水、发黏、有酒味或霉点，就不要吃。最准确的是看包装上的生产日期/保质期和储存说明；不同批次、不同包装（整把、单根、礼盒）会有差异。
