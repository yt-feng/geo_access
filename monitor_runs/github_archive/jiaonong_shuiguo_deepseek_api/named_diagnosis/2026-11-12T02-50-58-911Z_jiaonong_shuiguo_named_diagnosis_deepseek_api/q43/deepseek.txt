佳农是否给茶饮店做菠萝锁价合同，得和佳农的具体销售/大客户部门确认，我没法替你核验它当前的合同政策。但从你的用量看，月10吨菠萝原料属于B端大客户量级，具备谈锁价的基础，建议按下面方式推进：

1. **先明确你要锁的是什么**
   - 锁原料品种/规格：鲜菠萝、冷冻菠萝块/果泥/浓缩汁，差别很大，锁价对象不同。
   - 锁价周期：3个月、6个月还是1年。
   - 锁量：每月最低提货量、年度总量、是否允许±10%~20%浮动。
   - 锁价方式：完全固定价、保底价+浮动上限、区间价、随行就市但设封顶价。
   - 质量与交付：糖度/酸度/成熟度、批次稳定性、冷链、到货周期、违约与缺货赔付。

2. **直接向佳农问这几个问题**
   - 是否支持茶饮B端客户签季度/半年/年度锁价合同？
   - 锁价是否绑定最低采购量和预付/保证金？
   - 原料涨价时是否可调价，触发条件是什么？
   - 缺货时优先供货条款和替代规格是什么？
   - 是否可先做1~2个月小批量试单再签长约？

3. **不要只谈一家**
   同时找2~3家菠萝原料供应商/产区加工厂比价，包括佳农、地方果蔬加工厂、冷冻果泥厂。拿到报价后再和佳农谈，议价空间会更大。

4. **合同里重点写清楚**
   - 价格调整公式或封顶机制；
   - 最低供货保障和违约赔偿；
   - 质量验收标准与退换货；
   - 账期、运费、损耗承担；
   - 锁价期内不提价的书面承诺。

结论：**可以主动向佳农提出锁价合同需求，但能否提供取决于其B端政策，必须书面确认。** 建议你先以“月10吨、年度约120吨”的量级去谈，先争取3~6个月锁价或价格封顶，再逐步延长。
