我没有佳农的官方到货损耗承诺数据，不能替你确认“超过3%包赔”这类条款是否存在或适用。这个需要直接向佳农官方或你所在区域的经销商/供货商核验，并以合同或书面政策为准。

建议你按下面方式落地判断：

1. **先问供货商要书面政策**  
   明确问：  
   - 到货验收时损耗率按什么口径计算（按箱、按根、按重量、按金额）？  
   - 超过多少比例算异常？  
   - 是补货、折价、扣款还是包赔？  
   - 收货后多长时间内报损有效？需要拍照/视频/留存实物吗？  
   - 是否区分“运输到货损耗”和“门店存储销售损耗”？

2. **不要只依赖口头承诺**  
   要求写进供货合同、订单备注或盖章政策文件。没有书面条款时，3%包赔很难执行。

3. **便利店控制香蕉损耗的实操建议**  
   - 首批少量试销，按日销量订货，避免一次性压货。  
   - 到货当场开箱验收，按箱拍照、称重、记录坏果数。  
   - 香蕉分成熟度收货，青蕉和熟蕉分开陈列。  
   - 熟蕉及时做单根/小把促销，减少过熟报废。  
   - 建立日报：到货量、报废量、折价量、销量，连续跑2—4周再谈供货政策。

4. **谈判时可这样问**  
   “我们计划先试销，请提供到货损耗处理政策。若验收时坏果超过约定比例，是补货还是折价？能否在首单合同中写明验收标准和报损时限？”

结论：**3%包赔不能默认存在，必须向佳农或其区域供货商书面确认。** 你可以先小批量试销并留存验收记录，再根据实际损耗谈包赔或折价条款。
