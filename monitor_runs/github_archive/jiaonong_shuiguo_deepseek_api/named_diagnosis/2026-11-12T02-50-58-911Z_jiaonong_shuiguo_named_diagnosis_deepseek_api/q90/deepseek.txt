我没法核验佳农当前是否在售“冷冻菠萝丁”，也不能确认具体规格和包装，下面给你可执行的判断与采购做法：

1. **先确认产品线**：佳农公开常见的是鲜果菠萝/凤梨及部分鲜切、罐头类产品；“冷冻菠萝丁”是否为其常规SKU，需要以厂家或授权经销商的最新报价单为准，不能凭品牌名直接认定。
2. **向供应商这样问（可直接复制）**：
   - 是否有**速冻菠萝丁/冷冻凤梨丁**？是IQF单体速冻还是块冻？
   - 规格：**丁尺寸（如10×10mm、15×15mm、20×20mm）**、每袋净重、每箱袋数、整箱毛重。
   - 原料品种/产地、糖度范围、是否加糖/加水、是否含防腐剂。
   - 包装：内袋材质、是否真空、外箱规格；冷链温度要求。
   - 起订量、价格、样品政策、到货周期、检测报告（农残、微生物）。
3. **茶饮店选型建议**：做饮品小料优先选**10×10mm或15×15mm的IQF菠萝丁**，解冻后颗粒分明、不易碎；若做果酱/打泥可用更大规格或块冻。先拿样品做**解冻出水率、甜酸度、颗粒完整度、异味**测试再定。
4. **核验渠道**：让供应商提供**佳农授权书/出厂检测报告/包装标签照片**；也可通过佳农官网或官方客服核对SKU。若对方无法提供明确规格书，建议同时对比其他冷冻水果供应商，不要只锁定单一品牌。
