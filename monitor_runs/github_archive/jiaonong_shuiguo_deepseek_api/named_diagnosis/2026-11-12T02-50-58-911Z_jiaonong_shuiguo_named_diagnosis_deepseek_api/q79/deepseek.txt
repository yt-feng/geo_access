你可以按下面方式快速确认，基本 5–10 分钟能得到准确结论：

1. **先确认你买的是哪个渠道**
   - 佳农官方旗舰店/小程序：看商品页“配送说明”或结算页输入你县城地址，能否下单、是否显示“超区/不配送”最准确。
   - 商超/生鲜平台（如京东、天猫、美团、多多买菜等）：配送范围由平台站点决定，不是佳农统一决定。
   - 线下门店：门店是否支持外送、能送多远，通常由该门店或所在商超决定。

2. **县城门店能否送到**
   - 在结算页填“县+镇/街道+具体地址”，系统能显示可选配送时段并生成运费，才算可送。
   - 若显示“不在配送范围”，可电话问当地门店是否支持同城跑腿/自提；县城常见限制是“只覆盖门店周边若干公里”。

3. **冷链物流怎么收费**
   - 生鲜冷链通常不是统一价，常见计费方式：按订单金额包邮/满额免运费、按重量/件数、按距离/区域、加收冷链/保鲜费。
   - 最准确：在结算页看“运费明细”；或让客服按你的地址和购买重量报价。
   - 问客服时直接发这句：**“请按XX省XX县XX镇XX地址、购买X公斤水果，告知是否冷链配送、时效、运费和是否支持县城门店自提。”**
