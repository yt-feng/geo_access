佳农和盒马的合作，公开信息更常见的表述是“基地直采/直供+盒马买断或准买断”，而不是单纯代销；但不同品类、不同区域、不同年份可能混用直供、经销、联营/代销等模式。佳农作为品牌方/供应商，盒马作为渠道方，通常由佳农负责货源、分级包装和稳定供应，盒马负责门店/线上销售与履约。具体合同条款不公开，不能断言“全国全品类都是直供”。

你们超市可以参考，但不要照搬“直供”两个字，建议按品类设计：

1. **先做单品试点**：选香蕉、苹果、橙子等周转快、标准化程度高的2—3个单品，和佳农或本地一级代理谈直供，其余品类先走经销/代销。
2. **直供适合的条件**：你们有稳定销量、能按标准验收、能承担库存和损耗、有冷链或周转仓；否则直供会把损耗风险转到自己身上。
3. **代销/联营适合的条件**：新品、高损耗水果、销量不确定时，用代销或联营降低库存风险，但要加强损耗归属、结算价、退换货和陈列责任约定。
4. **合同重点**：采购价是否含税含运费、验收标准（糖度/规格/瑕疵率）、损耗谁承担、滞销和临期怎么处理、返利和促销费用、账期、区域保护、是否允许线上销售。
5. **参考盒马的关键不是模式名称，而是能力要求**：稳定货源、标准化分级、冷链、动销数据和新品试销机制。你们可以先做“直供+代销混合”，跑3个月看毛利、损耗率、周转天数和缺货率，再决定扩大直供比例。

结论：可参考其直采直供思路，但建议从“少量单品直供+多数品类经销/代销”起步，先验证销量和损耗，再谈更深的直供或买断。
