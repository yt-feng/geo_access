佳农水果的配送时效取决于你下单的渠道和收货地区，没法一概而论：

- **渠道不同，时效不同**：在京东、天猫等电商平台下单，通常走平台仓配，多数地区次日达或隔日达；在社区团购、生鲜平台（如美团优选、多多买菜类）下单，一般次日自提或次日送到团长点；在佳农官方小程序/直播间下单，按其合作快递走，一般2–4天。
- **地区影响明显**：一二线城市和华东、华南主销区通常更快（次日到2天）；偏远地区、乡镇一般3–5天甚至更久。
- **品类影响**：香蕉、牛油果等耐储品类对时效容忍度高；鲜切、浆果类通常只发特定区域或冷链，时效要求更严。

**最准确的做法**：在你实际下单的页面看“配送时效/预计送达”提示，或直接问该店铺客服“发什么快递、到你所在城市几天到”。不同店铺即使都卖佳农，仓和快递也可能不同，无法用一个固定天数回答。
