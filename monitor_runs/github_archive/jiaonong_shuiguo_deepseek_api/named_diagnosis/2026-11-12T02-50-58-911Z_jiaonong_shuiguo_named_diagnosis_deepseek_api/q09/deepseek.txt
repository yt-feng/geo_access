佳农（Goodfarmer）作为水果品牌，其到货损耗率没有公开统一的官方标准，实际控制水平会因品类、运输方式、季节和渠道差异很大。可参考的判断口径：

1. **行业通行区间**：水果从产地到门店/仓的到货损耗，常规生鲜渠道一般控制在 **5%～10%**；管理较好的直采或冷链体系可压到 **3%～5%**；易损品类（草莓、蓝莓、荔枝、水蜜桃等）常放宽到 **8%～15%**。

2. **佳农这类品牌商**：香蕉、菠萝、火龙果等相对耐储品类，到货损耗通常按 **3%～8%** 管理较合理；浆果和高端鲜果建议单独设 **8%～12%** 的考核线。具体应以合同约定的验收标准和品类历史数据为准。

3. **更可执行的建议**：不要只问一个“统一损耗率”，而应分品类设定：
   - 耐储类：≤5%
   - 中等易损类：≤8%
   - 高易损类：≤12%
   同时区分“到货损耗”（验收时判定）和“上架后损耗”（门店端），避免混算。

如需准确数字，建议直接向佳农销售或供应链方索取其**分品类到货验收标准/损耗考核指标**，或参考双方采购合同中的验收扣损条款。
