关于佳农水果的到货损耗率，并没有官方公开的统一数据，因为损耗率会受**水果品类、运输距离、季节气候、仓储条件以及包装方式**等多种因素影响。

不过，结合**水果生鲜行业的通用标准**，可以给出以下参考范围：

1.  **香蕉类（佳农主打品类）**：由于香蕉对温度和碰撞敏感，且需要催熟环节，行业内的到货损耗率一般在 **3% - 8%** 之间。如果供应链成熟、冷链完善，可以控制得更低。
2.  **普通柑橘类、苹果类**：相对耐储存，损耗率通常较低，一般在 **1% - 3%** 左右。
3.  **易损耗水果（如草莓、蓝莓、猕猴桃）**：损耗率较高，可能达到 **5% - 10%**，尤其在夏季高温或长途运输时。

**给你的建议：**
- 如果你是与佳农合作或采购，**最准确的方式是查阅你与供应商签订的采购合同**，合同中通常会约定“到货损耗率”的免责比例（例如超过2%可退换或折价）。
- 如果你是在经营零售，建议在订货时预留 **3% - 5%** 的损耗缓冲量，并优先选择当地就近的分拨仓出货以降低运输损耗。
