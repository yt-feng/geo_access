在茶饮行业，菠萝原料的**规格稳定性**直接关系到出杯一致性和成本控制。针对您问的“佳农”品牌，我先直接给结论，再解释您能听懂的规格逻辑：

**1. 短期（1-3个月）稳定，但需锁定“级别”**
佳农（FreshCo）是国内大型的水果供应链企业，主要做**进口水果**（如都乐菠萝、菲律宾菠萝）。他们给餐饮客户（B端）提供的是**标准化分选**的菠萝，通常按**果重**和**糖度**分等级销售。

- **您能听得懂的规格**：他们最常见的供应规格是 **“5-6头/箱”**（即一箱净重约20KG，里面装5-6个菠萝，单果约1.1-1.3KG）或 **“6-7头/箱”**（单果约0.9-1.0KG）。
- **针对茶饮**：如果您的饮品需要**果肉丁**或**原汁**，建议直接要求 **“去皮去芯菠萝肉”** 或 **“菠萝丁”** 的预加工规格（如5KG/袋装冷冻丁）。这类规格比整果更稳定，因为已经剔除了大小不均的损耗。

**2. 季节波动要注意**
菠萝（尤其菲律宾菠萝）虽然全年有产，但**果酸和糖度**在夏季（5-9月）最稳定，冬季（11-2月）容易出现**芯硬、肉白、酸度高**的情况。如果您需要全年口感一致，必须和供应商约定**糖度基线**（比如要求糖度≥13°Brix），否则冬季鲜果切出来会酸得难以下咽。**这是普通商家最容易踩的坑。**

**3. 给您的采购建议（可执行）**
- 如果您是**单店试水**：先在批发平台（如美菜、快驴）或直接联系佳农当地经销商，要**整箱样品**，切丁后测**出肉率**（一般整果出肉率约55%-60%，去皮去芯后更高）。
- 如果您是**连锁门店**：直接和佳农的**餐饮渠道大客户部**签季度框架协议，明确写明 **“单果克重范围”** 和 **“损坏率赔偿标准”**（例如：单箱破损超过5%可拒收）。
- **替代方案**：如果觉得进口菠萝贵，可以问他们是否有**国产徐闻菠萝**的供货线，价格通常低30%，但香型偏淡，需要您自行测试是否匹配配方。

**最终结论**：佳农能稳定供应，但**一定要用“糖度+果重+加工形态”三重规格锁定**，不要只说“我要菠萝”。如果您把您的城市和月采购量发我，我可以帮您具体判断找谁对接最划算。
