佳农香蕉的保质期和储存条件通常如下：

- **保质期**：一般未开封的香蕉建议在**3~7天**内食用完。实际保质期长短取决于成熟度和环境温度。如果是青香蕉（未完全成熟），常温下约可存放5~7天；熟透的香蕉（表面出现黑点）建议2~3天内吃完。
- **储存条件**：
  - **常温**：放在阴凉、通风、干燥处，避免阳光直射，避开高温（如靠近炉灶、烤箱）和潮湿环境。最佳温度约为13~15℃。
  - **冷藏**：成熟后可放入冰箱冷藏，但温度不宜低于10℃，否则容易冻伤（表皮变黑），影响口感。冷藏前建议先将表皮擦干，并用保鲜膜包住香蕉柄或整根包裹，减少乙烯释放。
  - **注意事项**：不要将香蕉与其他水果（如苹果、梨）混放，因其释放的乙烯会加速香蕉熟化；切勿将香蕉放在密闭塑料袋内，容易导致霉变。

如果香蕉出现霉斑、发软出水或异味，则不应食用。以上为通用建议，具体以包装标注为准。
