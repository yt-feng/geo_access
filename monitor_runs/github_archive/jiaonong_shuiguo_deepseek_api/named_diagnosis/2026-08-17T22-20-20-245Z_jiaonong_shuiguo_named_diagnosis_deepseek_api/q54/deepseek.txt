关于佳农水果的物流体系，目前公开信息显示，**佳农（Goodfarmer）主要采用“自有车队 + 第三方物流（含三通一达等）结合”的混合模式**，并非完全依赖单一快递。

具体解答如下：

**1. 物流模式（不是单纯三通一达）**
- **自有冷链车队**：佳农在核心产地（如泰国、智利、国内云南等）及主要销地（上海、广州等）拥有自有冷链运输车辆和仓储设施，尤其是针对整柜进口水果和大型商超配送（如盒马、永辉、批发市场），这些通常由自有车队完成，以保证时效和控温。
- **第三方快递合作**：对于电商小件（如消费者购买的整箱水果快递到家），佳农会与**顺丰**、**京东物流**以及三通一达（中通、圆通、韵达、申通）中的部分快递合作。但鉴于水果易损性，**佳农在电商渠道更倾向于顺丰或京东**，因为时效和赔付更有保障。三通一达在其电商业务中更多作为备选，并非主力。

**2. 冷链覆盖率（相对较高，但有边界）**
- **上游与干线**：从果园到分拣中心的“最初一公里”及跨省干线运输，佳农的**冷链覆盖率接近100%**，全程使用冷藏车或保温车，温度控制在0-4℃（温带水果）或更高（热带水果）。
- **末端配送**：这是冷链的薄弱环节。
    - 如果你购买的是**高端进口水果**（如车厘子、蓝莓），佳农通常要求顺丰冷链（含冰袋+保温箱），覆盖大部分一二线城市。
    - 如果你购买的是**普通国产水果**（如苹果、橙子），且在偏远地区，则可能采用**常温快递**配送（三通一达），此时冷链覆盖率会降至**30%-50%**左右，具体取决于配送时效。
- **仓储环节**：佳农在全国主要城市建有冷库，覆盖率高，但二三线城市的“预冷+暂存”能力参差不齐。

**3. 给你的可执行建议**
- **购买时确认发货方式**：在电商平台（如淘宝、京东）下单前，**直接询问客服“本单发什么快递？是否全程冷链？”**，如果客服回复“顺丰冷链”或“京东冷链”，那质量有保障；如果回复“三通一达”且未说明冰袋，大概率是常温配送。
- **看水果品类**：对温度敏感的水果（如草莓、智利车厘子、荔枝）务必要求冷链；对耐放的（如柚子、苹果）可接受常温快递。
- **验货签收**：无论快递是哪家，**收到货后当场开箱查验**，如有腐烂、软化，立即拍照联系客服索赔（佳农对运输损坏一般承诺包赔）。

**总结**：佳农有自建冷链车队用于大宗业务，但零售端电商目前**以顺丰/京东为主，三通一达为辅**。整体冷链覆盖率在**干线运输约100%，末端派送约60%-80%**（视地区和天气而定）。如果你对冷链有硬性要求，建议优先选择顺丰或京东渠道，并在下单前与客服确认。
