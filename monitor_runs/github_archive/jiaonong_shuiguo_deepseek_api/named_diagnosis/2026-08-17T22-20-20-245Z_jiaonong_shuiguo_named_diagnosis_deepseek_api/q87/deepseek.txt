针对商超采购需求，关于佳农香蕉的催熟工艺，答复如下：

**结论：佳农水果的香蕉采用乙烯利催熟工艺，而非纯自然熟。**

**具体说明：**

1. **工艺本质**：佳农作为规模化、品牌化的香蕉供应商，其香蕉从产地（如菲律宾、厄瓜多尔等）以“青蕉”状态冷链运输至国内。青蕉不能直接上市，必须经过人工催熟，以统一成熟度、缩短上市周期并保证货架期。**纯自然熟（树上自然黄熟）无法满足其批量供应和运输损耗控制，因此商业标准流程必然使用乙烯气体或乙烯利溶液进行催熟。**

2. **催熟剂类型**：常见做法是在催熟库中通入微量乙烯气体（食品级），或使用乙烯利稀释后喷洒/浸泡青蕉，利用其释放乙烯来启动生理成熟。**这是全球香蕉行业的通行标准，也是商业必用手段，并非“不健康”或“违规”。**

3. **时间控制（针对商超）**：
   - **标准催熟周期**：在专业催熟库（温度14-18℃，湿度85-95%）中，从青蕉到可售的黄熟状态一般需要 **3-5天**（具体视果柄、初始成熟度、季节而定）。
   - **您需要控制的环节**：商超通常购入的是“已从催熟库出库、成熟度在7-8成”的香蕉（果体黄绿相间、果皮微黄）。此时**到达商超后的自然后熟时间约为2-3天**。
   - **关键控制点**：若您需要精确到货架期，应要求供应商提供“催熟完成后发货”的批次，而非“催熟前”批次。**到货后建议立即检查果面颜色、硬度及果柄切口状态**，若果柄鲜绿、果体硬挺，说明催熟未完成，需在常温（18-22℃）下放置1-2天再上架；若已黄熟且果皮有褐斑，则应优先促销，避免过熟损耗。

**操作建议**：
- 与佳农业务人员明确沟通“需要催熟后发货，目标成熟度为商超即售状态”，并要求其在发货单上标注“催熟完成日期”。
- 若您需要自行二次催熟（非必要），可用成熟苹果/香蕉或乙烯利按说明稀释后密封催熟24-48小时，但**不推荐商超自行操作**，因为浓度、温度控制难度高，易造成果肉软化不均或早衰。
