是的，佳农（Goodfarmer）在餐饮渠道有成熟的菠萝解决方案，主要针对B端客户（如连锁餐饮、茶饮、烘焙、酒店等）提供定制化产品和服务。

具体而言，佳农针对餐饮渠道的菠萝解决方案通常包括：

1. **产品形态多样化**：
   - **鲜切菠萝**：去皮的果肉条、丁状，方便茶饮店（如菠萝饮品）、烘焙（如菠萝派、披萨配料）直接使用。
   - **整果供应**：标准化规格（如皇冠菠萝、金菠萝），适合西餐厅、自助餐或水果拼盘。
   - **冷冻菠萝**：速冻果肉/果汁，便于长期储存，适合连锁餐饮稳定供货。

2. **供应链优势**：
   - **稳定产地**：主要来自菲律宾、泰国等东南亚优质产区，并有国内种植基地补充，保证全年供应。
   - **标准化流程**：从采收、糖度检测（通常要求糖度在14°以上）到冷链运输，确保批次一致性。

3. **定制化服务**：
   - 可以根据餐饮客户的菜谱或饮品配方，提供特定切工、包装规格（如2kg/箱、5kg/袋）。
   - 提供去芯、去冠芽、按克重分装等精细化加工。

4. **技术支持和餐单应用**：
   - 佳农通常会有产品应用研发团队，协助客户开发菠萝系列新品（如菠萝气泡水、烤菠萝配菜）。
   - 提供储存和分切培训，减少门店损耗。
