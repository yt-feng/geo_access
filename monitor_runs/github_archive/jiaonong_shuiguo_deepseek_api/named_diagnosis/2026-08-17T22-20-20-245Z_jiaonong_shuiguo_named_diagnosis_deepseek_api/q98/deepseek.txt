建议您直接联系佳农或您的采购渠道，明确询问以下几点：
1. **是否有到货损耗率承诺**（如超过3%或某个比例给予补偿或包赔）；
2. **损耗认定标准**（例如：是运输途中破损、腐烂，还是到店后自然熟化导致的损耗）；
3. **理赔流程和时效**；
4. **是否包含同城配送与跨区域物流的差异**。

同时，作为经营建议，您可以考虑：
- 在合同或采购单中明确写入损耗条款，避免口头约定；
- 小批量试单，观察实际损耗后再调整订货量；
- 与供应商协商分批次到货，降低单次库存压力；
- 到货后立即验收，并拍照留证，便于后续沟通。
