针对您的问题，**佳农（Jumbo）通常以整果批发为主，一般不会直接提供“去皮切块”这类深加工服务**。但您的需求并非无解，我可以为您提供三种可落地的替代方案：

**1. 直接询问经销商（最可行）**
佳农有区域经销商或生鲜供应链合作伙伴。很多面向餐饮B端市场的经销商，会额外提供“代加工”服务（例如帮您去皮、去芯、切块、真空包装），只是加工费需要另算。
建议您直接联系佳农官方客服或当地经销商，明确说：“我们是茶饮连锁/单店，需要佳农菠萝的定制切块（如1.5cm立方体），能否走你们的B端加工渠道？”

**2. 选择“预加工冷冻菠萝”**
如果佳农无法加工，您可以考虑采用行业内的成熟替代品：
- **佳农及同类品牌的冷冻菠萝丁**：很多品牌（如Dole、或国内头部果业）提供IQF（单体速冻）菠萝丁，开袋即用，出杯稳定，损耗低（不需要人工去皮）。
- 注意：冷冻菠萝在茶饮中通常用于制作果茶、气泡水，风味和新鲜菠萝无异，但在口感脆度上略逊于鲜切。

**3. 自行小型加工（最保险）**
如果量不是特别大（比如单店），建议您采购整果后在店内后厨完成去皮切块。因为茶饮店损耗可控，且新鲜度最高。
- **省事技巧**：购买一台小型“菠萝去皮机”（约300-800元）或带波纹刀的切块模具，1分钟内可处理一个菠萝。

**综合建议：**
- 如果您的门店每日用量超过20颗菠萝，建议联系佳农当地B端经销商，询问额外加工服务（可接受加价5-10%）。
- 如果用量较小，建议优先选择“冷冻菠萝丁”或自行加工，避免因等待代工而影响出杯时效。

**提醒**：如您需要合作，谈判时请务必确认加工后的菠萝**糖度、纤维感以及切块大小（用于茶饮一般建议1-1.5cm）**，并要求对方提供样品试做。
