根据目前的信息，**佳农（Goodfarmer）** 主要经营新鲜水果（如菠萝、香蕉等）的分销与零售，但在其公开的产品线中，**并未明确显示有“冷冻菠萝丁”这一工业原料品类**。

如果你需要**冷冻菠萝丁**作为茶饮店的原料，建议通过以下途径直接核实：

1. **联系佳农官方或区域经销商**：直接询问是否有该产品，或是否能按需定制（部分B端供应商可接受规格定制）。
2. **询问规格**：如果对方有，常见的冷冻菠萝丁规格一般是 **1kg/袋** 或 **2.5kg/袋**，粒径通常在 **1cm × 1cm** 左右（适合做水果茶或果酱）。
3. **替代方案**：若佳农不提供，可考虑其他专业冷冻水果原料商（如“鲜丰”、“恒都”或本地冻品批发市场），其冷冻菠萝丁规格多为 **1kg×10包/箱**，价格更具竞争力。
