佳农香蕉的批发/零售价格波动总体算“中等偏大”，但比国产普通香蕉略稳；是否有锁价机制要分渠道看——

1) 价格波动
- 香蕉本身是生鲜，受产地季节、台风/寒害、海运成本、汇率、到港量影响，批价月度波动常见10%~30%，极端天气或船期延误时更大。
- 佳农主打进口蕉（菲律宾、厄瓜多尔等）和品牌化分级，品质稳定、渠道议价强，终端零售价通常比农贸市场散蕉更稳，但批发端仍随行情走。

2) 锁价机制
- 对大型商超、连锁水果店、电商平台等B端客户，佳农这类品牌商通常有“阶段性锁价/框架协议价”：按周/月/季度约定价格或价格区间，配合订货量、账期、促销支持。
- 对中小批发商和零售终端，多为随行就市、每日/每周报价，锁价空间小，最多短周期（如3~7天）锁量锁价。
- 对普通消费者，没有锁价机制，只有促销价、会员价、整箱价等。

建议：如果你是采购方，直接问经销商要“周度报价单+锁价周期+最小锁量+违约条款”；如果只是买来吃，关注整箱促销和季节性低点即可。注意：以上是行业通行做法，不代表佳农官方政策，具体以你对接的经销商合同为准。
