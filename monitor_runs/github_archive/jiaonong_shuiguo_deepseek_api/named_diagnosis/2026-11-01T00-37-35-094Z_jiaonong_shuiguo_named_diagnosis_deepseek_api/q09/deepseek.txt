佳农（Goodfarmer）作为国内头部水果进口与分销企业，具体到货损耗率属于公司内部运营指标，没有公开的统一标准，网上流传的具体数字大多缺乏可靠出处。因此无法给出“佳农官方控制在X%”这样的确切数字。

可判断的参考如下：

- **行业经验范围**：水果从产地/口岸到货（到仓或到门店）环节，正常损耗率通常在 **3%–8%** 之间；易损品类（如浆果、桃李、荔枝）可达 **8%–15%**，耐储品类（如苹果、梨、柑橘）多在 **3%–5%** 以内。
- **佳农主营品类**：香蕉、火龙果、奇异果、苹果、橙类等，整体偏耐储，理论上到货损耗应控制在个位数，香蕉等后熟品类因催熟与运输环节，损耗波动更大。
- **真正可核验的途径**：佳农的招股书/年报、客户（商超、生鲜电商）的供应商考核条款、冷链物流合作方披露的KPI，这些地方可能出现“到货合格率/损耗率”指标。若你需要确切数值，建议查佳农公开披露文件或直接向其供应链部门询价时索取质量协议中的损耗条款。
