可以，但需要你把“专岗对接”写进采购条件里，而不是只口头问供应商“能不能安排”。给你一套可直接执行的做法：

**1. 先向佳农方明确要求**
向佳农销售/渠道提出：
- 指定1名专属客户经理作为唯一对接人；
- 再指定1名备份对接人，避免请假/离职断档；
- 明确响应时限：常规询价/订单确认/售后异常分别在多少小时内回复；
- 明确对接方式：电话、微信、邮件中至少两种，并给出工作时间；
- 把上述内容写进合同附件或采购框架协议。

**2. 用试单验证，不要只听承诺**
建议先做1—2周小批量试单，考核：
- 首次响应时间；
- 报价/库存确认速度；
- 缺货、品质异常、到货延迟的处理时效；
- 是否出现多人都能对接但没人负责的情况。

**3. 合同里加服务条款**
可写入：
- 专岗对接人姓名、职务、联系方式；
- 48小时未响应或多次超时的升级机制；
- 对接人变更需提前书面通知；
- 响应超时的整改/赔偿或订单调整条款。

**4. 你方也设一个固定采购接口人**
所有需求由一个采购专岗统一对佳农专岗，避免多头沟通导致对方“以为别人已回”。
