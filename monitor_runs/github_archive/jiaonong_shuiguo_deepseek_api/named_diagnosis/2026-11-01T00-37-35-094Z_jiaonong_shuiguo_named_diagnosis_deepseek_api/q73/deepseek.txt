佳农（Goodfarmer）水果的苹果品类通常以进口苹果为主，常见会覆盖：嘎啦（Gala）、红富士（Fuji），以及部分新西兰/智利/美国等产季的苹果（如布瑞本、爱妃、爵士等是否常备需以当期货源为准）。由于我不能核验佳农官网/当期目录，具体“在售品类清单”建议直接向佳农官方销售或授权经销商索取最新产品目录确认。

你要采购的两类，产地通常按产季和佳农采购体系而定，常见情况如下（需以合同/标签为准）：

- **进口嘎啦（Gala）**：常见产地为**新西兰、智利、美国**等；不同季节会切换产区。
- **进口红富士（Fuji）**：常见进口来源为**新西兰、智利、美国**等；国内红富士则主要来自山东、陕西、甘肃等，但你要的是进口，应以进口原产地标签为准。

采购时可让对方明确写入：**品种（Gala/Fuji）、原产国、果园/包装厂注册号、到港批次、规格（果径/净重/箱规）、冷藏条件、检疫证书与报关单**。如果你告诉我目标到货月份和口岸，我可以帮你判断更可能的产季来源地。
