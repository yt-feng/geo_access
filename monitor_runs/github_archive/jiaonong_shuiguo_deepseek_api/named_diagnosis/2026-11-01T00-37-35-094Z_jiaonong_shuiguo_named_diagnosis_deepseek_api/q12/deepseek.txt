公开渠道能查到的佳农香蕉规格信息并不完整，且会随批次、季节和客户合同变化，所以我无法给出“官方全部规格清单”。下面给的是**可执行判断框架 + 你如何核实**，避免编造具体克重和渠道分级表。

## 1. 佳农香蕉常见规格维度
水果香蕉的“规格”通常不是单一数字，而是几个维度组合：

- **单根重量/等级**：如小果、中果、大果、特大果（具体克重区间需以佳农当季报价单或包装标签为准）
- **每箱净重**：常见有散装大箱、小箱、礼盒装等（不同渠道不同）
- **每把/每梳根数**：如4-6根把、整梳、单根装
- **包装形式**：散装、保鲜袋装、托盘覆膜、礼盒、电商独立包装
- **成熟度/催熟状态**：青蕉、微黄、即食黄蕉
- **产地/品牌线**：不同产地和品牌系列可能有不同分级

## 2. 按渠道的分级思路（通用可执行标准）
佳农这类品牌香蕉通常按“**外观+单根重+成熟度+包装**”做渠道适配，而不是只按大小分。可参考以下判断：

| 渠道 | 优先分级维度 | 关键要求 |
|---|---|---|
| 商超/大卖场 | 单根重均匀、梳形完整、色泽一致 | 耐摆放、卖相好、损耗低；一般中大果为主 |
| 水果连锁/生鲜店 | 成熟度可调、把型适中 | 到店后可控催熟，周转快 |
| 电商/社区团购 | 独立包装、抗压、成熟度偏青或可即食 | 减少运输碰伤，规格标注清晰 |
| 餐饮/茶饮/烘焙 | 单根重稳定、出肉率、批次稳定 | 更看重加工出成率和供货稳定性，外观要求低于零售 |
| 批发市场 | 大箱净重、等级统一、价格带清晰 | 走量，允许外观略次但等级不能混 |
| 礼品/礼盒 | 外观无瑕疵、梳形漂亮、单根大小一致 | 包装和卖相优先，成本敏感度低 |

## 3. 你可以这样核实具体规格
1. 向佳农业务员索要**当季产品规格表/报价单**，重点看：单根重区间、每箱净重、每箱根数、成熟度、包装方式。
2. 看**外箱标签和内袋标签**：通常标有等级、净重、产地、催熟批次。
3. 问清**渠道专供规格**：同一渠道不同客户也可能有定制箱规，不能只按品牌名判断。
4. 用“**单根重合格率+外观合格率+到货成熟度**”三项验收，比只问“几种规格”更可执行。

**结论**：佳农香蕉的具体规格数量无法在不核验当季资料的情况下准确回答；但分级应按“单根重、箱规、把型、成熟度、包装、外观”六维判断，渠道适配的核心是：商超看卖相和均匀度，电商看抗压和成熟度，餐饮看出成率和稳定性，批发看箱规和等级统一。
