佳农（Goodfarmer）香蕉商品化催熟通常采用**乙烯/乙烯利类催熟**，不是“自然熟”到货。商超要控时间，可按“到货青蕉→催熟库→转黄销售”的节奏管理；但具体工艺参数以佳农供货批次随货说明和其对接业务确认为准，我不能替你核验其内部工艺文件。

可执行建议：

1. **先确认到货状态**：问清是“青蕉未催熟”“催熟中”还是“已转黄可售”。这决定你是否还要二次催熟。
2. **商超自控催熟时间**：常用做法是恒温催熟库，温度约 **15–18℃**，湿度 **85%–95%**，用乙烯气体或乙烯利处理；转黄后降到 **13–14℃** 存放，避免过熟。具体浓度和时长必须按批次、房体大小和供应商SOP定，不能套一个固定值。
3. **控时看色卡**：按香蕉色卡分级（1–7级）判断，不要只看天数。目标销售色一般控制在 **3–5级** 到店，留1–2天货架转黄。
4. **分批到货、分批催熟**：每次只催一批，记录“入房时间、温度、乙烯处理时长、出房色级、货架期”，用2–3批数据校准你的商超节奏。
5. **合同上写清楚**：要求佳农提供该批次的催熟状态、建议货架期、推荐储存温度和是否已用乙烯类催熟剂。商超内部把“催熟时间”写成色级+温度+天数三要素，而不是只写天数。

如果你们是直接采购佳农“已催熟转黄”香蕉，商超端主要是**控温控湿和先进先出**，不要再重复乙烯处理；如果是青蕉到货，则按上述催熟库流程做，并先向佳农索取该批次操作建议。
