**结论：** 佳农香蕉的溯源一般只能到“国家/产区/包装厂/批次”这一级，普通商超拿不到“具体农场”级溯源；GLOBALG.A.P.证书通常可以按包装厂或供货主体提供，但不等于每根香蕉都能对应到具体农场。你要做的是“证书+批次追溯+供应商声明”三件套，而不是追求农场级单证。

**分点判断：**

1. **产地溯源能到哪一级**
   - 佳农这类进口香蕉通常来自菲律宾、厄瓜多尔、越南、柬埔寨等产区，行业通行追溯粒度是：**原产国 → 产区/注册果园群 → 包装厂 → 出口批次 → 国内到货批次**。
   - “具体农场”级追溯在香蕉进口链里很少对商超开放，原因包括：多果园拼货、包装厂混批、海外供应商商业信息保护。除非合同特别约定并做全程批次绑定，否则一般做不到单农场对应。

2. **GLOBALG.A.P.证书怎么拿**
   - 向佳农或你的供货商索要：**GLOBALG.A.P.证书编号、认证主体、认证范围（作物/环节）、有效期、认证机构**。
   - 重点核对：证书上的**认证主体**是否与供货合同主体、包装厂或注册果园一致；**认证范围**是否覆盖香蕉；证书是否在有效期内。
   - 商超验收通常接受“包装厂/供货主体持证+批次追溯文件”，不要求每批附农场级证书。若商超坚持“农场级”，需在采购合同里提前约定，否则临到验收很难补。

3. **建议你直接向供应商要的文件清单**
   - GLOBALG.A.P.证书复印件/电子版（含编号可官网核验）
   - 该批次的**产地证明/植物检疫证书/报关单**
   - **包装厂注册号或出口商信息**
   - 供应商出具的**溯源声明**：写明原产国、产区、包装厂、批次号、对应证书主体
   - 若商超要求农场级：要求供应商提供**果园注册号清单+批次绑定说明**，并确认是否额外收费或能否做到

4. **风险提示**
   - 不要接受“证书是别家主体的”或“证书范围不含香蕉”的材料，商超审核容易被打回。
   - 农场级溯源若供应商口头承诺但合同没写，后续无法追责。建议在采购合同里明确追溯粒度和证书提供义务。

**可执行动作：** 先让佳农/供货商发GLOBALG.A.P.证书和该批次报关、检疫、包装厂信息；拿到后核对认证主体和范围；同时书面确认“能否提供农场级绑定”，不能的话让商超按“包装厂级+批次追溯”验收。
