可以谈，但需要先确认“专供包装”的具体范围和供应商政策。建议你按下面步骤推进：

1. **先向佳农区域销售/经销商确认是否支持定制专供包装**  
   明确问四项：
   - 是否支持超市专供包装（印你们超市LOGO/门店信息/规格）
   - 最小起订量（MOQ）和单店/单仓配送要求
   - 包装规格：整箱、单把、单根、礼盒、净重、保鲜膜/气调袋等
   - 是否额外收版费、制版周期、包装成本分摊

2. **确认合作模式**  
   佳农通常通过区域经销商或直营渠道合作。你要问清：
   - 是佳农直供还是经销商供货
   - 长期合作是否签年度框架协议
   - 价格是否随行就市、是否有保底量
   - 专供包装是否绑定采购量/合作期限

3. **准备你们的合作条件**  
   谈专供包装时，供应商会看你们的稳定性。建议准备：
   - 预计月采购量/年采购量
   - 门店数量、配送仓位置、收货频次
   - 结算方式（账期/现结）
   - 损耗和售后处理标准

4. **小批量试单**  
   先做1—2个SKU的专供包装试单，验证：
   - 包装是否耐运输
   - 香蕉成熟度与货架期
   - 条码/标签是否合规
   - 门店陈列效果

**结论：可以提出专供包装需求，但是否能做取决于佳农区域渠道政策、起订量和费用分摊。** 建议先联系佳农官方客服或当地销售，拿到明确答复后再谈年度合作。不要先承诺大量采购。
