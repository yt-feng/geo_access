我无法核验佳农当前是否有冷冻菠萝丁、以及具体规格，不能给你确定的规格和报价。建议你按下面方式快速确认，避免被不准确信息误导：

1. **直接找佳农官方渠道确认**  
   联系佳农官方客服/当地经销商，问清三件事：  
   - 是否有“冷冻菠萝丁”这个SKU，还是只有冷冻菠萝块/果肉/果泥；  
   - 规格：包装净重（如1kg/袋、10kg/箱）、果丁尺寸（如10×10mm、15×15mm）、是否IQF单体速冻；  
   - 供货条件：起订量、冷链配送、到货价、是否有检测报告和样品。

2. **向对方索要产品规格书和样品**  
   让供应商发**产品规格书/标签照片/检测报告**，并用样品做两项测试：  
   - 解冻失水率和出成率；  
   - 做成饮品后的口感、酸度、香气和是否易碎。

3. **茶饮店选菠萝丁的硬性判断项**  
   优先确认：是否IQF速冻、丁尺寸是否均匀、是否有糖渍/无糖、解冻后是否发软出水、包装是否适合门店分次取用。若做果茶，通常小丁更易入口；若做装饰或果肉感，需选更大丁并测试吸管通过性。

4. **备选方案**  
   如果佳农没有合适冷冻丁，可同步问：安德鲁、鲜活、盾皇等果酱/果肉供应商，或当地冷冻水果批发商；但同样要求提供规格书和样品，不要只凭口头描述下单。
