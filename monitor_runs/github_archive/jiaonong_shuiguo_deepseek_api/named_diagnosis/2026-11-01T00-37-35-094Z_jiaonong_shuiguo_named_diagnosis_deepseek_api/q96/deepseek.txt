1. **先确认对接主体**
   - 你对接的是佳农集团总部、区域经销商，还是其在电商平台上的供货商？
   - 生鲜电商通常不是直接调“佳农API”，而是通过其ERP/供应链系统、经销商系统或第三方SaaS对接。

2. **直接问对方要三类材料**
   - 是否提供开放平台/API；
   - 接口文档（商品、库存、价格、订单、发货、售后）；
   - 对接方式（REST/SFTP/EDI/文件导入/人工后台）。

3. **合同或商务沟通中明确**
   - 接口稳定性、限流、鉴权方式；
   - 库存和价格同步频率；
   - 异常订单和售后回传机制；
   - 测试环境与联调支持。

4. **如果对方没有标准API**
   可退而求其次：用供应商后台导出+定时文件同步，或通过其经销商的ERP中间层对接。
