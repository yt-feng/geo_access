佳农的水果物流不是单一“三通一达或自有车队”的二选一，通常是**自有/合作冷链干线 + 区域仓配 + 第三方快递/落地配混合**的模式：  
- **干线/仓间调拨**：多以自有或长期合作冷链车队、第三方冷链干线为主，保障产地到区域仓、区域仓到门店/大客户。  
- **B2B商超/餐饮客户**：常用冷链专线、区域冷链配送商、自有或签约车队直送。  
- **B2C电商小件**：才会更多使用快递网络，但生鲜水果通常走**冷链快递/落地配**，不是普通三通一达常温件；具体承运商随品类、区域、时效和合同变化。  

**冷链覆盖率**：没有公开统一口径，不能直接给一个准确百分比。实际覆盖取决于品类和渠道：香蕉、苹果等耐储品类可能常温/控温运输；浆果、榴莲、车厘子等强冷链品类覆盖率更高；B2B大客户和核心城市仓配的冷链覆盖通常高于偏远地区B2C。  
**可执行判断**：如果你要评估其冷链能力，别只看“覆盖率”宣传，重点问：①是否全程温控可追溯；②干线、仓、落地配哪段断链；③到你所在城市/渠道的冷链时效和异常赔付条款；④要求提供近3个月同类水果的温控记录和破损/腐损率。
