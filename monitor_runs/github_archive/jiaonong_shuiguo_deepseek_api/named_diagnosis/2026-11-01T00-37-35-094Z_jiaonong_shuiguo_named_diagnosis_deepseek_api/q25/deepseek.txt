佳农的水果物流通常不是单一“全自营”或“全外包”，而是**自营核心节点 + 外包运力/区域配送的混合模式**。可以这样判断：

1. **物流网络模式**
- **核心仓储、分拣、品控、干线调度通常自营或强管控**：佳农做进口香蕉、奇异果等品类的全国分销，对催熟、温控、库存周转要求高，核心DC和关键环节一般不会完全交给第三方。
- **干线运输和末端城配多采用外包/合作运力**：冷链干线、区域仓配、电商快递、商超门店配送通常会整合第三方物流、冷链承运商和快递资源。
- **结论**：更像“核心自营+运力外包+全程管控”，而不是纯自营或纯外包。具体到某条线路、某区域仓，可能随业务和承运商合同变化。

2. **冷链能力**
- 佳农主营香蕉、奇异果、苹果、牛油果等生鲜水果，具备**产地预冷/催熟库、冷藏仓储、冷链干线、温控配送**等能力，尤其香蕉催熟和温控是其重点。
- 冷链覆盖通常是**分段温控**：产地/港口—区域DC—商超/门店/电商仓，不同品类温区不同，不是所有水果全程同一温度。
- 强项在**进口水果和大单品供应链的温控与周转**；但末端到消费者、低线区域配送仍可能依赖合作方，实际冷链完整性要看区域和渠道。
- 如果你要评估合作风险，建议重点核验：区域DC是否自有、干线是否温控车、末端是否冷链箱/冷藏车、是否有全程温度记录和异常追溯。
