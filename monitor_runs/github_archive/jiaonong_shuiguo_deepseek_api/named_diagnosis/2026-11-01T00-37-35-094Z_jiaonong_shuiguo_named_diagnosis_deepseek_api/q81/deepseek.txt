1. **先向佳农当地经销/业务确认三个信息**
   - 该区域可供的**最小销售规格**：按箱、按把、按袋分别是什么重量；
   - 是否支持**拆箱/拆袋供货**，以及拆箱后的结算价；
   - 香蕉是否有**3kg左右的小箱/小袋**，以及到店成熟度（青蕉/黄蕉）和损耗处理政策。

2. **便利店更现实的规格方向**
   - 香蕉：优先问**2.5–3kg小箱**或**按把/按袋**供货，不建议整大箱压在店里；
   - 苹果、橙子等：优先**2–3kg小箱**或**独立小包装**；
   - 若佳农没有小规格，可问经销商是否有**二级分装小箱**，但要注意分装后品控和责任归属。

3. **下单前做小测试**
   - 先订**1–2箱小规格**试销7–10天；
   - 记录日销量、损耗率、毛利；
   - 香蕉成熟度控制在到店后**2–3天可售完**的量，避免小门店压货。

4. **谈判点**
   - 要求小规格、可拆箱、短周期补货；
   - 明确损耗/售后：坏果、过熟、到货成熟度不符怎么换补；
   - 先小批量试供，再谈陈列和价格支持。
