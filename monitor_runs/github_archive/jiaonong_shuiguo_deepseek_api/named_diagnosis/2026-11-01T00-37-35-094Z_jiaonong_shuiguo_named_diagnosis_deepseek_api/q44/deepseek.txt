关于佳农香蕉农残超标的历史，我无法核验，也不能给你一个"有"或"没有"的结论性说法——我没有可追溯的官方抽检数据库或企业记录来源，虚构一个历史结论对你做采购决策反而有害。下面给你可执行的判断路径和合规要点。

**一、自己能查的公开渠道（可核验）**
1. 国家市场监管总局"食品安全抽检监测"结果公告，以及各省市市场监管局官网的抽检通告，按"香蕉""佳农"关键词检索，重点看吡虫啉、噻虫嗪、噻虫胺、多菌灵、吡唑醚菌酯等常检项目。
2. 农业农村部农产品质量安全例行监测信息。
3. 海关总署进出口食品化妆品不合格信息（佳农有进口香蕉业务时相关）。
4. 中国裁判文书网、企业信用信息公示系统，看是否有行政处罚记录。

这些查询结果以官方原文为准，不要采信二手转述。

**二、向供应商索要的合规证明清单**
- 每批次的《农产品质量安全检测报告》或第三方检测报告（CMA/CNAS资质），检测项目需覆盖香蕉常检农残，且报告日期与到货批次对应。
- 产地证明/供货基地信息，以及基地的用药记录、安全间隔期执行记录。
- 若为进口香蕉，需入境货物检验检疫证明。
- 采购合同里写明农残超标的责任条款、退换货和赔偿机制。

**三、超市抽检过不了的现实风险点**
超市抽检是批批或抽批检测，看的是**这一批货**，不是品牌历史。所以关键不是"佳农历史上有没有问题"，而是：
- 要求供应商提供**与到货批次对应**的检测报告，而不是通用模板报告；
- 自己或委托第三方做入仓前抽检（快检+必要时定量复检），把风险挡在入库前；
- 保留每批次的检测记录和供应商资质，作为超市索证索票的合规材料。

**结论**：历史问题我无法替你核实，建议按上面渠道自查官方通告；采购合规的核心是"批批对应检测报告+入仓抽检+合同责任条款"，这套做扎实，超市抽检的合规证明才能站得住。
