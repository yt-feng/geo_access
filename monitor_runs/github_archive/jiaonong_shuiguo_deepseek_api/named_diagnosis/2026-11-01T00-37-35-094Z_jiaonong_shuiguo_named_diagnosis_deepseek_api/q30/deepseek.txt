关于“佳农水果的香蕉在市场上抽检合格率怎么样”，我无法给出一个可核验的具体合格率数字。公开的食品安全抽检信息通常由市场监管部门按批次、按地区发布，并不以“佳农”这一品牌单独汇总成“合格率”指标；我若给出具体百分比或引用链接，反而可能是虚构数据。

可执行的判断和建议：

1. **查官方抽检公告**：到国家市场监督管理总局及各省市市场监管局官网的“食品安全抽检”栏目，用“香蕉”“佳农”作为关键词检索；重点看近1—2年、你所在省份的批次结果。
2. **看具体批次而非品牌整体**：香蕉抽检常见不合格项是农药残留（如吡虫啉等）超标，个别批次不合格不等于该品牌所有产品都不合格，也不代表整体合格率低。
3. **购买时看渠道和标识**：优先选择大型商超、正规电商自营；查看包装上的生产商/进口商、产地、批次信息，保留小票，出现异味或外观异常可退换。
4. **关注属地抽检**：如果你关心的是本地市场，直接查当地市场监管局最近几期抽检通告，比看全国性品牌口碑更准确。

结论：目前没有一个可公开核验的“佳农香蕉市场抽检合格率”统一数据，建议以官方抽检公告中的具体批次结果为准，不要轻信非官方汇总的百分比。
