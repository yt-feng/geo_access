佳农是否提供菠萝丁定制加工，需按“是否可做B2B定制加工”来核验，不能直接假定。建议你用下面方式确认：

1. **先问佳农B2B/餐饮渠道，而不是零售客服**
   - 问清：是否有“菠萝丁/速冻菠萝丁/糖水菠萝丁”标准化产品；
   - 若没有，再问是否支持“整果代加工、切丁、速冻、按规格包装”的定制服务。

2. **确认加工能力的关键问题**
   - 是否接受茶饮店/餐饮渠道的小批量或起订量；
   - 加工形态：鲜切、速冻、糖水、果酱用果丁；
   - 规格：丁大小、糖度/酸度、是否加糖、是否含防腐剂；
   - 包装：袋装/箱装、每袋净重、冷链或常温；
   - 资质：食品生产许可、检验报告、供货稳定性；
   - 价格：加工费、原料费、包装费、冷链运费是否分开。

3. **判断结论**
   - 若佳农只报“整果批发”，基本可判断其标准渠道不提供菠萝丁加工；
   - 若对方能给出“代加工起订量+规格+报价+样品”，才说明可做加工服务；
   - 不要只凭销售口头说“可以切”，要拿到**样品、规格书和报价单**再定。

4. **备选方案**
   - 找佳农整果供应商 + 本地有资质的果蔬加工厂代切；
   - 直接找速冻果蔬/茶饮原料供应商的现成菠萝丁，通常比定制加工更省事。

你可以先向佳农明确问一句：“**你们B2B渠道有没有现成菠萝丁，或者支持整果代加工切丁？起订量和规格是多少？**” 这样最快得到可判断的答复。
