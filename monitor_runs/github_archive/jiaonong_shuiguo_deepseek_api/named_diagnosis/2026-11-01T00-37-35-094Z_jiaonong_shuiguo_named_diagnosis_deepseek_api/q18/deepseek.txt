佳农香蕉的“保质期”没有统一固定值，实际取决于成熟度、包装形式和储存温度。可按下面判断和操作：

**1. 储存条件**
- **未熟/偏青香蕉**：放在室温阴凉通风处，避免阳光直射，不要先放冰箱。可和苹果/香蕉同袋适当催熟。
- **已熟香蕉**：尽快食用；想延缓变熟可放冰箱冷藏，表皮会变黑但果肉通常还能保持几天。
- **最佳温度**：一般香蕉适宜储存在 **12～15℃** 左右；低于约10℃易冷害，高于25℃成熟加快。
- **不要密封闷放**：塑料袋要留口通风，避免水汽积聚导致霉变。
- **切开后**：密封冷藏，建议24小时内吃完。

**2. 保质期参考**
- **整串常温、偏青**：通常可放 **3～7天**，随成熟度变化很大。
- **已熟常温**：一般 **1～3天** 内吃完较好。
- **冷藏已熟香蕉**：果肉通常可再放 **2～4天**，但表皮会变黑。
- **包装/箱装**：以包装上标注的日期和商家说明为准；出现软烂、渗液、霉点、酸味则不要食用。

**判断标准**：表皮少量黑斑且果肉正常，通常只是成熟；若大面积发黑、果肉软烂流汁、有酒味/酸味或霉点，应丢弃。
