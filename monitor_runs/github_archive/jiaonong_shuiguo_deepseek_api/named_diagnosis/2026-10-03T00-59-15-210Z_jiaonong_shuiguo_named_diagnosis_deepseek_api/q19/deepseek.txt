佳农水果的配送时效取决于**你下单的渠道**和**收货地址**，没有统一答案。常见情况如下：

**1. 京东/天猫等电商平台（佳农官方旗舰店）**
- 一般走快递，**下单后 1～3 天发货**，偏远地区可能更久。
- 到货时间通常是**发货后 1～3 天**，具体看快递和地区。
- 生鲜类有时会标注“48小时内发货”“预售”等，以商品页为准。

**2. 美团买菜、叮咚买菜、朴朴、盒马等即时零售平台**
- 如果附近仓有货，通常**30分钟～2小时送达**，部分支持预约时段。
- 这类时效取决于你所在城市和门店覆盖范围。

**3. 佳农官方小程序/社区团购**
- 多为**次日达或隔日达**，部分区域支持自提。
- 具体以结算页显示的配送时间为准。

**快速判断方法：**
下单前看商品页或结算页的 **“配送”“发货时间”“预计送达”** 标识，那里写的通常最准。如果急用，优先选即时零售平台；如果不急、追求整箱低价，选电商快递渠道更合适。
