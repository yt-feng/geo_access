我无法直接确认佳农目前是否提供菠萝丁代加工/切丁定制服务，因为这类业务政策会随客户类型、采购量、工厂排期和区域经销体系变化。可执行的做法是：

1. **先联系佳农官方渠道确认**
   - 打佳农官网/公众号上的客服或销售电话，直接问：  
     “是否有菠萝丁/速冻菠萝丁/糖水菠萝丁产品？能否按茶饮店规格做切丁代加工？最小起订量、规格、包装、价格、交货期是多少？”
   - 如果你所在城市有佳农经销商，让经销商帮你对接区域销售，通常比总部客服更快拿到实际报价。

2. **问清“加工服务”可能分两种**
   - **标准品**：佳农已有菠萝丁、速冻菠萝丁、菠萝果酱等产品，直接卖给你，不算定制加工。
   - **代加工/OEM**：按你的尺寸、糖度、包装、杀菌方式等定制，通常要求起订量较大，可能是吨级或整柜级，小店未必能直接满足。

3. **如果佳农不接小批量定制，备选方案**
   - 找本地水果加工厂/中央厨房做鲜切菠萝丁，按日配或周配。
   - 找冷冻果蔬供应商买速冻菠萝丁，规格更稳定，适合茶饮店。
   - 找罐头/糖水菠萝丁供应商，开罐即用，适合连锁或标准化出品。
   - 如果你们只要鲜果，也可以买佳农整果后让门店或第三方切丁，但要注意保鲜和损耗。

4. **联系时建议直接问这 6 项**
   - 是否有现成菠萝丁产品
   - 能否定制切丁尺寸
   - 最小起订量
   - 是鲜切、冷冻还是糖水/罐头
   - 配送范围和频次
   - 样品和报价
