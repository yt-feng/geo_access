佳农（佳农食品控股/Goodfarmer）对批发商这类B端客户，通常是**有专门对接的销售/客户经理**的，但具体怎么分配要看你的采购规模和渠道类型。

一般情况是这样：

1. **有B端销售团队**
   佳农主营业务就是水果进出口和批发分销，客户包括商超、电商、餐饮、批发市场档口、区域经销商等，这类客户基本都由销售负责对接，不是纯客服模式。

2. **是否配“专属”客户经理，取决于采购量**
   - 采购量稳定、金额较大：一般会分配固定的客户经理/区域销售，负责报价、订货、账期、售后等。
   - 采购量小或刚接触：可能先由区域销售或客服统一对接，合作稳定后再转专属。

3. **对接方式**
   通常需要通过官方渠道先建立联系，比如：
   - 佳农官网的“联系我们/商务合作”
   - 官方客服电话
   - 行业展会（如进博会、果蔬展）
   - 通过你所在区域的经销商或批发市场渠道引荐

4. **建议你直接问清楚这几点**
   联系上之后，可以直接确认：
   - 是否有固定客户经理对接
   - 起订量和价格阶梯
   - 账期政策
   - 配送范围和冷链条件
   - 售后（坏果、损耗）怎么处理
