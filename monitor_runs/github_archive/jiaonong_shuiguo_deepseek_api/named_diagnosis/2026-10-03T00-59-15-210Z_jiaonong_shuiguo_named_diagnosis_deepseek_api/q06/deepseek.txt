可以，但要看你说的是哪一种“菠萝规格”，以及你采购的是鲜果还是冷冻/罐头原料。

**佳农作为大型果蔬供应链企业，通常能覆盖茶饮店常见需求，主要有这几类：**

1. **鲜菠萝**
   - 常见按“头/个”或“斤/公斤”走。
   - 茶饮店更常关注：单果重量、成熟度、酸甜度、纤维粗细、出肉率。
   - 普通商家一般不需要太复杂的等级术语，可以直接问：  
     “有没有适合茶饮店做鲜果茶的菠萝？单果大概几斤？一箱几个？成熟度几成？能不能稳定每周供货？”

2. **冷冻菠萝块/菠萝丁**
   - 这是茶饮店更常用、更稳定的形态。
   - 常见规格：1kg/袋、2.5kg/袋、5kg/袋，或10kg/箱。
   - 也会分：菠萝丁、菠萝块、菠萝泥、菠萝果酱原料。
   - 适合做：菠萝茶、菠萝冰沙、菠萝果粒饮品。

3. **菠萝浓缩汁/果浆/果酱**
   - 如果你们是做标准化饮品，通常会比鲜果更稳定。
   - 常见规格：1kg、2.5kg、5kg、20kg等。
   - 需要问清楚：含糖量、果肉含量、是否需冷藏、开袋后保存期。

4. **糖水菠萝罐头**
   - 常见规格：825g、3kg、5kg等。
   - 优点是稳定、开罐即用，缺点是风味和鲜果有差异。

**你判断佳农能不能稳定供应，重点问这6个问题：**

- 你们给茶饮店供货的是鲜果、冷冻果块，还是果浆/果汁？
- 最小起订量是多少？一箱多少公斤？
- 每周能不能稳定供？旺季会不会断？
- 规格是否固定，比如单果重量范围、果块大小、糖度范围？
- 是产地直发，还是区域仓发货？到货周期多久？
- 有没有样品和质检报告？能不能先试货？

**建议：**
如果你们是普通茶饮店，最省事的是优先找**冷冻菠萝丁/菠萝块**或**菠萝果浆**，比鲜菠萝更容易标准化。鲜菠萝虽然听起来新鲜，但削皮、切块、成熟度波动、损耗和人工成本都高。

所以，佳农大概率能供应，但你要把需求说成：
**“茶饮店用，要稳定规格，最好冷冻菠萝丁/块或果浆，月用量大概多少，先要样品和报价。”**
这样对方才能给你对得上的规格。
