佳农水果的配送覆盖和冷链收费，取决于你走的是哪种购买渠道，不同渠道差别很大：

## 1. 先说结论
- **佳农本身主要是水果供应商/品牌方**，不是像京东、美团那样面向个人的全国零售配送网络。
- 所以“能不能送到你们县城门店”，**不能一概而论**，要看你具体是在哪个平台下单、门店是什么类型。
- **冷链收费通常没有全国统一标准**，一般由实际承运方或平台按重量、体积、距离、温区报价。

## 2. 配送覆盖怎么看
你要先确认自己属于哪种情况：

**A. 你在电商平台买（京东、天猫、拼多多等）**
- 覆盖范围以**该平台的配送网络**为准，不是佳农自己定。
- 能不能到你们县城，取决于平台在你所在地区有没有冷链仓/配送站。
- 下单时输入详细地址，系统会直接显示“是否可配送”，这是最准的判断方式。

**B. 你想给县城门店进货（批发/经销）**
- 佳农通常通过**经销商、区域代理、批发市场、商超供应链**铺货。
- 县城门店能不能送到，要联系**当地经销商或区域业务**，看是否在配送半径内。
- 很多县城是“经销商覆盖”，不是佳农厂家直送。

**C. 你在本地商超/水果店看到佳农**
- 那是门店自己进货，不代表佳农能直送你家或你店。

## 3. 冷链物流怎么收费
没有统一价，常见计费方式有：
- **按重量**：元/公斤，或按整箱/整托
- **按体积/泡货**：轻抛货按体积重算
- **按距离**：同城、省内、跨省不同价
- **按温区**：冷藏、冷冻、恒温价格不同
- **附加费**：提货费、送货费、上楼费、等待费、偏远地区附加费
- **起步价**：小单通常有最低消费

县城配送通常比市区贵，因为：
- 线路少、回头车少
- 可能需要中转
- 单趟货量小，摊薄成本高

## 4. 你可执行的三步
1. **确认渠道**：你是个人买，还是门店进货？在哪个平台/找哪个经销商？
2. **直接问配送范围**：电商下单页输入地址；门店进货就联系当地佳农经销商或区域代理，问“到不到XX县、起送量多少”。
3. **要冷链报价**：让对方按“品名、重量/体积、温区、起止地、是否上楼”给书面报价，别只问“多少钱一斤”，否则很难比价。
