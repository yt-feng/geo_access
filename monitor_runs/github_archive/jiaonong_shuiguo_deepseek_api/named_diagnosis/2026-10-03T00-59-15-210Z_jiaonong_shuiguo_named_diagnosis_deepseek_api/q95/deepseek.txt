佳农（Goodfarmer）的**具体产地直供比例没有公开、可核验的统一数字**，不同品类、不同年份差异很大，所以不能给你一个准确百分比。公开信息只能确认：佳农主打“产地直采/全球直采”模式，在香蕉、菠萝、火龙果、车厘子等品类上较多采用产地端合作或自有/合作种植基地，但这不等于所有品类都直供，也不等于“直供比例”有官方披露。

对你采购降本，更实用的判断方式是：

1. **不要只问“直供比例”**
   直接问供应商：
   - 这个SKU是产地直采，还是经产地贸易商/出口商/进口商？
   - 从产地到你们仓库一共经过几手？
   - 报价对应的是FOB、CIF、到港价还是到仓价？
   - 是否含报关、冷链、损耗、账期成本？

2. **按品类分别谈**
   佳农不同水果供应链差异很大。香蕉、菠萝等大宗品类更可能接近产地直采；反季节、小众、进口高端品类中间环节通常更多。要求对方按SKU给出供应链路径，而不是给一个公司级比例。

3. **要“链路成本拆解”而不是“直供口号”**
   让供应商提供：
   - 产地采购价/离岸价
   - 国际物流与保险
   - 关税、增值税、报关费
   - 冷链仓储与分拣
   - 损耗率
   - 配送费
   - 账期资金成本
   这样你才能判断中间环节到底贵在哪。

4. **减少中间环节的可执行做法**
   - 对稳定大单品：尝试产地直采、产地包销、基地合作协议。
   - 对多品类采购：用“产地直采+口岸直发+区域仓配”组合，而不是全部要求直供。
   - 对进口水果：可直接对接出口商或产地合作社，但要有报关、检疫、冷链能力。
   - 对国内水果：直接对接县域合作社、产业带基地，减少批发市场环节。
   - 用年度框架协议换价格，但把品质分级、损耗上限、账期写清楚。

5. **向佳农这类供应商提问的清单**
   - 你们各品类中，产地直采SKU占比是多少？请按品类列。
   - 每个SKU的完整链路和经手方数量？
   - 如果我们要绕开中间环节，你们能否做产地直发/口岸直发？
   - 直采后价格能降多少？对应起订量、账期、损耗谁承担？
   - 能否提供产地证明、检疫证、报关单、批次检测报告？
