佳农水果的香蕉规格和分级标准，公开可查的信息比较有限，我无法给出其官方确切的规格表。以下只能按行业通行的香蕉规格分级逻辑来说明，佳农作为国内主要香蕉品牌之一，大体也遵循这套框架，但具体到某个批次、某个产季，建议直接向佳农官方或当地经销商索取规格书确认。

**一、按重量/条数分（最常见）**

国内香蕉行业最通用的分级是按"每箱净重 + 每根大概重量"来定：

- 大果：单根约160–200g以上，整箱通常标18–20斤或按条数如4–5条/斤
- 中果：单根约120–160g
- 小果：单根约90–120g
- 也有按"条/箱"标的，比如每箱80条、100条、120条

佳农常见的包装规格一般集中在18斤、20斤、25斤等整箱规格，具体条数因产季和产地（菲律宾、厄瓜多尔、云南、广西等）会有浮动。

**二、按外观品级分（渠道分级核心）**

行业通常分特级、一级、二级：

- **特级/精品**：果形整齐、弯曲度好、无机械伤、无黑斑、青度均匀。主要供高端商超、精品水果店、电商礼盒。
- **一级**：允许轻微表皮瑕疵，果形基本整齐。供大型连锁商超、生鲜电商日常销售。
- **二级/加工级**：有明显疤痕或大小不均，供批发市场、餐饮、加工（香蕉片、果泥等）。

**三、按渠道的实际分级逻辑**

- **高端商超/精品店**：要特级，强调催熟后的卖相和货架期
- **连锁商超/生鲜电商**：一级为主，兼顾性价比
- **批发市场/社区店**：一二级混装或二级，价格敏感
- **餐饮/加工**：二级或统货，看重量不看外观

**四、催熟成熟度也是分级维度**

香蕉还按到货成熟度（青蕉、微黄、催熟后黄蕉）区分，不同渠道要的熟度不同：商超要可控催熟，电商偏好微黄即食，批发要青蕉自行催熟。

**建议**：如果你是要做采购或渠道对接，直接找佳农当地销售要一份"产品规格书/装箱标准"，里面会写清净重、条数、果指长度、品级定义和验收标准，这比通用说法准确。
