佳农（Goodfarmer）香蕉在供应链中通常采用**乙烯催熟**，不是纯自然熟。商超拿到的大多是“青香蕉/催熟前半成品”，到仓或到店后再做可控催熟。

要点如下，便于你们控时间：

- **催熟方式**：行业主流是**乙烯气催熟**，常见为**乙烯气体**或**乙烯利释放乙烯**。大型品牌供应链一般用标准催熟房，温湿度+乙烯浓度+通风排CO₂一起控制。
- **自然熟**：如果完全不干预，香蕉也能后熟，但时间长、批次不一致，商超很难做稳定陈列和损耗控制，所以一般不用。
- **控时间关键因素**：
  - **温度**：催熟房通常 **15–18℃** 左右，温度越高转色越快，但过高易发软、风味差。
  - **乙烯浓度/时间**：一般 **100–150 ppm** 左右，处理 **24–48 小时**；具体看到货成熟度、品种和季节。
  - **湿度**：**85%–95%**，太低易失水、果皮发暗。
  - **通风/CO₂排放**：催熟过程要排CO₂，否则抑制乙烯作用，转色不齐。
  - **到货成熟度**：青硬、微黄、已起糖点，处理时间差别很大。
- **商超建议**：
  - 如果目标是 **3–5 天销售期**：到货后先进 **15–17℃** 催熟房，乙烯处理 **24–36 小时**，再转 **13–15℃** 暂存，按转色分批上架。
  - 如果目标是 **2–3 天内卖完**：可缩短到 **18–24 小时**，但要加强巡检，避免过熟。
  - 如果佳农到货已经是 **微黄/黄绿**：通常只需 **12–24 小时** 低浓度补催或直接转色，不必再长时间乙烯处理。
  - 上架后建议 **13–15℃**、避免冷风直吹，能延缓后熟。
- **注意**：
  - 不同批次、产地（菲律宾、厄瓜多尔、越南等）和季节差异大，**不能只按固定小时数**，要以“转色度”为准。
  - 商超若没有催熟房，不建议在常温下硬等自然熟，损耗和一致性会差。
  - 具体乙烯浓度、温湿度和处理时长，最好向佳农供应商索取该批次的**催熟建议卡**，或让其在到货单上标注“建议催熟参数”。

如果你们要一个可执行模板：**到货青硬→15–17℃、90%湿度、乙烯100–150ppm处理24–36小时→转13–15℃→按转色分批上架**。这个区间对多数商超比较稳。
