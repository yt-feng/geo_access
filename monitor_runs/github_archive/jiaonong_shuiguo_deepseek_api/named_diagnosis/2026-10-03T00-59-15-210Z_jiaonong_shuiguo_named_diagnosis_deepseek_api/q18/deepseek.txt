佳农香蕉通常指佳农品牌销售的进口/国产香蕉，市面常见为黄熟香蕉或青香蕉。它的“保质期”不是一个固定天数，主要取决于成熟度和储存温度。

**一、保质期（常温下的大致参考）**

| 状态 | 常温放置（约20–25℃） | 冷藏（约10–12℃） |
|---|---|---|
| 青香蕉 | 3–7天逐渐转黄 | 可放1–2周，但易冻伤变黑 |
| 黄熟香蕉 | 2–4天，之后出现糖斑 | 2–3天，表皮易发黑 |
| 已出现黑斑 | 1天内尽快吃完或加工 | 不建议再久放 |

如果是冷链运输到家的青香蕉，常温催熟一般需要3–6天；商家标注的保质期常见为“7–15天”，通常指未完全成熟、通风阴凉条件下的储存时间。

**二、储存条件建议**

1. **温度**
   - 未熟青香蕉：13–15℃最理想，可缓慢均匀成熟。
   - 已熟黄香蕉：10–12℃可稍微延缓，但低于10℃容易冻伤发黑。
   - 家用冰箱冷藏室通常4℃左右，不适合长期放香蕉，只适合短期1–2天。

2. **湿度**
   - 相对湿度85%–90%较好，但家庭环境不必刻意加湿，重点是通风、避免闷在塑料袋里。

3. **摆放方式**
   - 不要平放压着，最好悬挂或用支架架空，减少受压部位发黑。
   - 避免和苹果、梨、西红柿等释放乙烯的水果放在一起，否则会加速成熟。
   - 如果想让青香蕉快点熟，可以和苹果一起放进纸袋，室温放置。

4. **是否清洗**
   - 吃之前再洗，储存时不要水洗，表皮有水容易滋生霉菌。

5. **切开后**
   - 剥开或切开的香蕉应冷藏，并用保鲜膜包住切口，最好24小时内吃完。

**三、判断是否还能吃**

- 可以吃：表皮有少量黑点、果肉仍乳白或淡黄、气味正常。
- 谨慎吃：表皮大面积发黑但果肉尚好，可尽快食用或做香蕉奶昔、香蕉饼。
- 不要吃：果肉发黑、发酸、有酒味、流汁、长霉，说明已变质。

简单说：**青香蕉放阴凉通风处催熟，黄香蕉尽快吃；短期可放10–12℃环境，家用冰箱只适合短存，不建议久放。**
