佳农（Goodfarmer，主要做香蕉、菠萝、火龙果等进口水果）的账期没有统一公开标准，通常按客户类型、采购量、合作历史、信用评估来定，属于“一户一议”，所以下面说的是行业常见情况，不是佳农官方承诺：

**1. 账期大概多久**
- 新客户：一般是**现款现货或款到发货**，很少直接给账期。
- 老客户/稳定渠道：常见**30天、45天、60天**，部分大客户或长期合作的可能到**90天**。
- 具体还要看品类：香蕉、菠萝这类周转快、价格波动大的水果，账期通常偏短；大宗稳定订单可能略长。

**2. 新客户能不能申请**
- **可以申请，但通常不会马上批**。多数供应商对新客户会先要求现款，合作几个月、回款正常后再谈账期。
- 申请时一般需要提供：营业执照、开票资料、采购规模、下游渠道、历史流水或征信，有的还要求担保、保证金或法人连带责任。

**3. 实际建议**
- 直接找对接的佳农销售或区域经销商问，因为账期是销售政策，公开渠道查不到准确数字。
- 新客户可以先谈“首单现款、后续按月结”这种过渡方案，比一上来就要60天更容易通过。
- 如果对方要求先交保证金或签担保，要看清合同里的逾期利息和追偿条款。

简单说：新客户能申请，但基本先现款；账期要等合作稳定后才可能给，常见30–60天，大客户可到90天，最终以佳农实际审批为准。
