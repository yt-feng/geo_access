佳农（Goodfarmer）主要是水果品牌/供应链商，具体售后通常取决于你**从哪个渠道购买**（抖音/天猫/京东/拼多多/商超/社区团购等），因为退款、补发、赔付标准一般由销售平台和店铺售后规则决定，而不是佳农统一对消费者直接处理。整体来说：

- **正规电商自营或旗舰店**：售后相对规范，坏果一般可申请**按比例退款/补发**。
- **第三方店铺/团购**：差异较大，有的爽快赔，有的要求照片、视频、称重，甚至拖延。
- **生鲜普遍规则**：坏果通常不要求退回，但必须提供证据，且一般要求在签收后**24–48小时内**反馈。

如果到货有坏果，建议按下面步骤处理：

1. **先别急着扔**
   把坏果、好果分开，保留外包装、快递面单、装箱清单。

2. **拍照/录视频取证**
   最好拍：
   - 整箱全景
   - 坏果特写
   - 坏果切开后的状态
   - 快递面单和包装
   如果是多个坏果，建议摆在一起拍，能看出数量。

3. **尽快联系购买渠道客服**
   进入订单页，找“申请售后/退款/理赔”，选“腐烂/坏果/变质”。
   话术可以直接说：
   > 收到货后发现其中X个坏果，已拍照留存，请按坏果比例退款或补发。

4. **明确诉求**
   常见处理方式：
   - 按坏果数量比例退款
   - 补发同等数量
   - 全额退款（坏得特别多时）
   - 补偿优惠券（不建议优先接受，除非你认可）

5. **如果客服拖延或拒绝**
   - 在平台内申请“平台介入”
   - 找平台官方客服投诉
   - 保留聊天记录、照片、订单截图
   - 若是直播间/团购购买，可向主播客服和平台同时施压

6. **注意时效**
   生鲜类售后通常有时效限制，很多店铺要求**签收后24小时内**或**48小时内**反馈，越早处理越有利。

7. **不要轻易确认收货后再拖**
   如果还没确认收货，先别确认；已经确认了也仍可在售后期内申请。

判断佳农售后好不好，关键看这几点：
- 是否旗舰店/自营
- 是否承诺“坏果包赔”
- 是否要求过苛证据
- 赔付是否按比例、是否爽快
- 是否补发而不是只给小额补偿
