我无法给出佳农香蕉具体的抽检合格率数字，因为这类数据需要以市场监管部门或权威检测机构的公开通报为准，我没有可核验的来源可以引用。

不过可以给你几个可判断、可操作的结论和建议：

1. **没有公开统一“按品牌统计”的抽检合格率**
   各地市场监管局抽检通常按批次、门店、产地公布，很少按“佳农”这种品牌汇总成年度合格率。所以你看到的“某品牌合格率XX%”如果没有官方出处，基本不可信。

2. **香蕉抽检主要看哪些风险项**
   常见检测项包括：
   - 农药残留（如吡虫啉、噻虫嗪等）
   - 重金属（铅、镉等）
   - 保鲜/催熟相关违规使用
   - 感官和腐烂变质情况

3. **佳农属于大型水果供应链企业**
   这类企业通常有较稳定的基地、分选和品控体系，整体合格率一般不会差，但“企业规模大”不等于“每批次都合格”，仍可能有个别批次被通报。

4. **你可以这样自己核验**
   - 到**国家市场监督管理总局**官网“食品安全抽检”栏目查
   - 到各省/市市场监管局官网查“食品安全监督抽检信息通告”
   - 搜索关键词：`佳农 香蕉 抽检`、`佳农 不合格 通告`
   - 看通报里是否明确写了品牌、批次、门店、不合格项目

5. **购买建议**
   - 优先选正规商超、连锁水果店
   - 看外观：果皮正常黄/青，无大面积黑斑、霉变、异味
   - 买回后常温催熟，吃前清洗果皮，虽然不吃皮，但可减少手部污染
