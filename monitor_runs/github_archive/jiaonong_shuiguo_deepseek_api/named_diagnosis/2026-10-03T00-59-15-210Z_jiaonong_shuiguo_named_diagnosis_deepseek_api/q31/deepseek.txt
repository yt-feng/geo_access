**1）常见礼盒类型**
佳农比较常见的礼盒方向包括：
- **进口水果礼盒**：如香蕉、奇异果、车厘子、蓝莓、牛油果等组合或单品礼盒。
- **高端单品礼盒**：车厘子、蓝莓、阳光玫瑰葡萄等，适合节日送礼。
- **企业团购定制礼盒**：部分渠道支持按预算、数量、包装需求做组合。
- **节庆礼盒**：春节、中秋、端午等节点会推出对应主题包装。

**2）怎么确认当前有没有货**
最稳妥的方式是按渠道核实：
- **佳农官方渠道**：官网、官方公众号、官方旗舰店，看是否有“团购/企业采购/礼品卡”入口。
- **电商平台**：京东、天猫等搜索“佳农 礼盒”“佳农 团购”，看当前在售SKU和发货区域。
- **线下商超/批发市场**：山姆、盒马、永辉等有时会有佳农礼盒，但团购政策要问门店。
- **直接联系佳农**：通过官网客服或公众号留下企业采购需求，问是否有区域团购负责人对接。

**3）团购时要问清的关键点**
- 起订量是多少
- 是否支持定制包装/LOGO
- 能否指定水果品种和规格
- 发货时效、冷链方式
- 破损和售后规则
- 是否开票、能否对公付款
