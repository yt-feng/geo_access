佳农（上海佳农食品集团）主要做香蕉、菠萝等水果的**贸易和批发**，通常以整果或鲜切果形式供货，但**是否提供去皮切块这类定制加工，需要分情况看**：

**1. 常规渠道（批发市场/经销商）**
一般不提供定制加工服务，只卖整果或标准规格鲜切产品。你拿到的是整只菠萝，需要自己处理。

**2. 直接与佳农对接（大客户/连锁采购）**
佳农旗下有鲜切水果业务（如给商超、餐饮供货的鲜切菠萝），如果你采购量足够大、有长期合作意向，**可以谈定制规格的鲜切菠萝块**，但这属于单独洽谈的业务，不是标准服务。能否做取决于：
- 你的采购量是否达到他们的起订门槛
- 加工规格、包装、配送半径是否匹配他们的产能
- 是否有冷链条件

**3. 更实际的做法**
如果佳农不直接给你加工，可以考虑：
- 找当地的**鲜切水果代工厂**，采购佳农菠萝后委托加工
- 直接采购佳农的**鲜切菠萝成品**（如果有对应规格）
- 自己店内加工（茶饮店菠萝用量大的话，人工去皮切块成本其实可控）

**建议你先做两件事：**
1. 直接联系佳农官方或你在当地的经销商，明确问“是否有鲜切菠萝块/定制加工，起订量多少”
2. 同时对比本地鲜切代工厂的报价，因为即使佳农能加工，跨区域冷链配送成本可能不划算

一句话：**佳农能供菠萝，但定制去皮切块要看采购量和对接渠道，大概率需要你主动谈，且更适合大批量长期合作。**
