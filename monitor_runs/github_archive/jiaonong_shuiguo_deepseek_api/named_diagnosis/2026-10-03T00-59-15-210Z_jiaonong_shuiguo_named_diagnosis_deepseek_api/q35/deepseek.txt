**响应快慢取决于渠道**
- **电商平台旗舰店/自营店**（天猫、京东、拼多多等）：优先走平台在线客服，通常有“几分钟内首响”的平台考核，最快。
- **商超/生鲜平台**（盒马、永辉、美团买菜等）：找该平台的售后入口，而不是直接找佳农，平台介入更快。
- **佳农官方渠道**（官网、公众号、400电话）：适合批量采购、经销商或平台解决不了的问题，响应通常比平台慢一些。

**有问题找谁（按优先级）**
1. **先找卖家**：谁卖给你的就找谁，保留订单号、照片/视频（坏果、缺斤少两、包装破损）。
2. **平台售后入口**：订单页点“申请售后/退款”，生鲜一般有“坏果包赔”，按要求上传凭证。
3. **佳农官方**：可通过佳农官网或微信公众号查找客服电话/在线客服；具体号码和入口请以官网公示为准，我不确定最新号码，不便直接给。

**提高处理速度的做法**
- 收到货尽快开箱拍照，生鲜售后有时限（常见24–48小时内）。
- 一次性说清：订单号＋问题＋诉求（退款/补发/赔付）。
- 平台客服拖沓时，直接申请平台介入或升级投诉。
