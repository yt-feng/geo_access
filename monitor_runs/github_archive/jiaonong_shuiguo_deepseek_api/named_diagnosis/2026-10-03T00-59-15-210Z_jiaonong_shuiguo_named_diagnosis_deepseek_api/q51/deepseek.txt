定制佳农水果礼盒通常可以印公司logo，但最小起订量和是否能印，取决于你走的是哪类渠道：

1. **佳农官方/大区经销商**
   - 一般会要求企业团购达到一定金额或箱数，常见门槛可能是几十箱到几百箱不等，具体看城市、礼盒型号和档期。
   - logo印刷多数可以做，但通常需要额外制版费/印刷费，且有最低数量要求。
   - 建议直接问：起订量、可否印logo、制版费、打样费、交货周期、能否混搭水果。

2. **电商平台/团购平台上的佳农授权店**
   - 有些支持“企业定制”，但往往只支持贴标、腰封、卡片定制，不一定能直接在礼盒上印logo。
   - 起订量可能更低，但定制灵活度也低。

3. **本地礼品公司/生鲜团购服务商**
   - 他们通常不是佳农直营，而是采购佳农水果再组合礼盒。
   - 起订量可能更灵活，logo印刷也更容易谈，但要确认水果是否为正品佳农、是否支持验货。

**判断建议：**
- 如果你要“佳农原厂礼盒 + 印logo”，直接联系佳农官方客服或当地经销商最稳。
- 如果你更看重“能印logo、起订量低”，找本地礼品团购商更现实，但要让他们明确佳农水果来源。
- 询价时直接发需求：预算、数量、水果品类、礼盒规格、logo文件、交货城市和日期，让对方给一口价方案。

我无法核验当前具体起订量和价格，因为不同地区、不同礼盒、不同时间政策会变。最可靠的方式是让供应商书面确认：
- 最小起订量
- logo印刷位置和工艺
- 是否含制版费
- 打样时间和费用
- 佳农正品证明或授权来源
