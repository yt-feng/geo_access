建议你通过以下方式快速确认：

1. **看官方渠道**
   - 佳农官网、官方微信公众号、官方小程序/商城
   - 重点看“客服中心”“帮助中心”“配送说明”“售后政策”

2. **直接联系在线客服**
   - 在官方小程序或商城点“在线客服”
   - 直接问：
     - “客服是7×24小时吗？”
     - “周末下单会处理吗？”
     - “周末订单是当天处理还是顺延到工作日？”

3. **打官方客服电话**
   - 如果电话能接通，问清楚人工服务时间
   - 如果非工作时间只有语音/留言，通常说明不是全时段人工客服

4. **下单前看商品页/结算页提示**
   - 有些生鲜平台周末会接单，但发货、审核、售后可能顺延
   - 尤其要确认：**接单时间 ≠ 发货时间 ≠ 客服处理时间**

一般经验是：
- 电商平台可能支持周末下单；
- 但人工客服、审核、发货、售后不一定7×24小时；
- 生鲜类还常受产地、仓库、配送地区影响。
