佳农是否提供堆头陈列和试吃支持、以及费用怎么分担，**需要直接和佳农当地的经销商或厂家业务对接确认**，不同区域、不同渠道、不同促销档期的政策差异比较大，没有统一标准。

不过可以给你一个比较实用的判断和谈判框架：

## 1. 通常可能拿到的支持
佳农这类品牌水果（香蕉、菠萝、椰青等）在商超渠道，常见支持形式包括：

- **堆头/地堆陈列支持**
  - 提供陈列物料：围挡、价签、跳跳卡、海报等
  - 提供堆头搭赠或特价供货，支撑陈列量
  - 部分区域可给陈列补贴

- **试吃支持**
  - 提供试吃果品（按活动量核销）
  - 提供试吃台、一次性用品、试吃员服装等物料
  - 大档期可能派促销员，但一般要求门店有量

## 2. 费用分担的常见模式
| 项目 | 常见分担方式 |
|---|---|
| 堆头位置费 | 商超承担为主，供应商可用搭赠/特价补偿 |
| 陈列物料 | 供应商承担较多 |
| 试吃果品 | 供应商提供，按核销量结算 |
| 试吃人工 | 双方协商，大档期供应商可能出人 |
| 促销让利 | 双方各让一部分，或供应商给特价供货 |

实际谈判里，**“费用分担”往往不是直接对半，而是用货补、特价、搭赠来折算**。

## 3. 你谈判时可以这样问对方
直接问清楚这几点，基本就能判断能不能做：

1. 这个档期有没有堆头/试吃专项支持政策？
2. 支持是给物料、给果品，还是给费用？
3. 试吃果品怎么核销、按什么量给？
4. 堆头陈列有没有最低订货量或陈列天数要求？
5. 费用是供应商全额承担，还是门店承担位置、供应商承担物料和试吃？
6. 能不能签书面促销协议，明确双方投入？

## 4. 建议
如果你要的是**可执行结果**，最好直接联系：
- 佳农在你所在区域的经销商
- 佳农厂家对应商超渠道的业务员
- 或者通过你的采购对接佳农供应商

让他们给一份**当档期的促销支持方案**，里面写清楚：堆头形式、试吃方式、费用分担、核销条件。没有书面方案，口头承诺后面容易扯皮。
