佳农香蕉通常按“到货/购买时的成熟度”决定可放多久；没有统一固定保质期，常见参考如下：

- **未完全成熟（偏青/微黄）**：室温阴凉通风处放置，通常 **2–5天** 逐渐转黄成熟；夏季可能更快。
- **已成熟（黄熟、适合直接吃）**：室温 **1–2天** 内吃口感较好；想延缓可冷藏，但表皮会变黑，果肉一般还能放 **2–4天**，具体看成熟度和冰箱温度。
- **已切开**：密封冷藏，建议 **24小时内** 吃完；出现明显变软、酸味、渗液就不要吃。

储存建议：
1. **不要先放冰箱**：未熟香蕉冷藏会停止成熟、表皮变黑，果肉也可能发硬发涩。
2. **室温悬挂/平放，避免挤压**，放在阴凉通风处，避免阳光直射和靠近暖气。
3. **不要和苹果、梨等大量催熟水果密封混放**，会加快变熟。
4. **成熟后可冷藏延缓过熟**，吃前回温；表皮发黑不等于一定坏了，主要看果肉是否软烂、有异味。
5. **不要用密封塑料袋长期闷放**，容易积水汽、加速腐烂。

判断能否吃：表皮少量黑斑通常正常；若**果肉大面积软烂、发酸/酒味、渗液、霉点**，建议丢弃。以上是通用储存建议，具体包装上若标注了保质期或储存条件，以包装标注为准。
