我不能核验佳农水果香蕉是否有农残超标的历史记录，也不应替你编造“无超标”结论。建议按以下方式做可落地判断：

1. **要求供应商提供合规证明**
   - 近批次的 **农残检测报告**（第三方CMA/CNAS资质，报告编号可查，检测项目覆盖GB 2763对应香蕉项）。
   - **产地证明/供货证明**、批次号、采收/包装日期，确保报告与到货批次对应。
   - 如为进口香蕉，另要**入境货物检验检疫证明**；国产要产地准出或合格证。

2. **自己做入市前抽检**
   - 每批或高频批次送第三方检，项目按GB 2763香蕉相关农残；超市抽检通常看报告+现场抽样，保留留样和检测原始记录。
   - 内部验收记录：供应商、批次、检测报告编号、到货日期、留样照片。

3. **合同里写清责任**
   - 约定“每批随货提供合格检测报告；抽检不合格由供应商承担退换货、检测费、下架损失”。
   - 要求供应商书面声明近12个月无因农残不合格被市场监管处罚；但声明不能替代检测报告。

4. **关于“历史”**
   - 可查**国家企业信用信息公示系统、市场监管总局/地方市场监管局抽检公告**，用“佳农”+“香蕉”检索；也可让供应商提供抽检记录。公开信息未必完整，所以不能据此认定“绝对无历史”。

结论：采购合规不能靠口头承诺，**以到货批次对应的第三方检测报告+合同责任+自检留样**为准；没有报告就不要放行。
