佳农（Goodfarmer）属于生鲜/水果供应链企业，具体账期通常不是统一公开标准，而是按客户类型、采购规模、合作渠道和合同约定来定。可给你一个可判断的参考框架：

1. **账期常见情况**
   - 商超、连锁零售、电商平台等大客户：常见 **30–60 天**，部分强势渠道可能 **60–90 天**，以合同为准。
   - 中小批发商、区域经销商：常见 **现款现货、7–15 天或月结30天**，新客户通常更短。
   - 出口或大额长期订单：可能按信用证、预付款+尾款或分阶段结算。

2. **新客户能否申请账期**
   - 通常可以谈，但**新客户首次合作一般较难直接拿到长账期**，更常见的是：
     - 首单现款或预付定金；
     - 小批量试单后给短期账期（如7–15天）；
     - 提供营业执照、经营流水、担保或保证金后申请月结。
   - 最终取决于佳农当地销售/大客户部门对信用和采购量的评估。

3. **建议你直接确认**
   - 联系佳农官方客服或对应区域销售，问清：**“新客户首单结算方式、可申请账期区间、需要哪些资质材料”**。
   - 不要只问“账期多久”，要问“**按我们这种客户类型和采购量，能给到什么结算条件**”。

结论：佳农账期没有公开统一值，常见 **30–60 天**，新客户可申请但首单通常偏现款或短账期，需按合同和信用审核确定。
