**一、常见规格维度（佳农及同类香蕉供应商通用）**
1. **按重量分**：单根重量档（如约120–150g、150–180g、180g以上）；整箱净重档（如4kg、7kg、10kg、12–13kg、18–20kg等）。
2. **按果指数量/梳型分**：每箱果指数、每梳条数、单梳/双梳包装。
3. **按成熟度分**：青蕉（催熟前）、微黄、黄熟即食；不同渠道对到货成熟度要求不同。
4. **按外观等级分**：果形直度、长度、粗细、色泽均匀度、机械伤/斑点容忍度。
5. **按包装分**：散装大箱、梳装、袋装、礼盒/精品小包装。

**二、不同渠道的分级逻辑（建议按此对接供应商）**
- **商超/精品超市**：重外观与一致性。要求果指长度、粗细均匀，色泽一致，无明显机械伤和药斑；常用中到大果、梳装或小包装，成熟度按门店周转设“微黄到黄熟”。
- **水果连锁/社区店**：重周转和性价比。中等果型、整箱散装或梳装为主，允许轻微外观瑕疵，成熟度可略青以延长货架期。
- **电商/社区团购**：重耐运输和标准化。偏好青蕉或微黄发货，单根重量区间稳定，箱规统一，减少压伤；常做按根/按斤的定量装。
- **餐饮/茶饮/烘焙**：重出成率和风味稳定。偏好大果或特定成熟度（如七到八成熟用于后续加工），对长度和单根重量有明确下限，外观要求低于商超。
- **批发/农贸**：重价格和耐储。青蕉大箱为主，分级较粗，允许果形不齐和少量瑕疵，按箱重和果指大小分档。
- **礼盒/企业团购**：重外观和包装。精选大果、果形直、色泽好，单根或小梳精装，成熟度偏黄熟即食。

**三、如何拿到准确答案**
1. 让佳农销售/客服提供**当前产品规格表**和**渠道分级验收标准**（通常按果指长度、单根重、每箱净重、成熟度、缺陷容忍度列明）。
2. 索要**最新报价单/订货目录**，上面一般列有箱规、果指数、等级代码。
3. 若你是渠道采购，直接按你的验收指标（单根重区间、长度、成熟度、允许缺陷率、箱规）向供应商要对应等级，而不是只问“有几种规格”。
