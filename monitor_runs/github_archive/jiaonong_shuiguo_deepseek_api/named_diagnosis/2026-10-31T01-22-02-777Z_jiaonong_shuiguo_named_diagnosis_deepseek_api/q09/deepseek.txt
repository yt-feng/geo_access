佳农（Goodfarmer）作为生鲜水果品牌，其到货损耗率并没有对外公开的统一标准，具体数值会因品类、运输方式、季节和渠道（商超、电商、批发）差异较大。可以给出行业参考判断：

- **普通水果（苹果、梨、柑橘等耐储品类）**：到货损耗通常控制在 **3%～5%** 以内。
- **浆果、葡萄、桃李等易损品类**：到货损耗常见在 **5%～10%**，冷链和包装条件好时可压到 5% 左右，条件差时可能超过 10%。
- **香蕉、芒果等后熟型水果**：到货损耗受催熟和温控影响大，通常按 **5%～8%** 评估。

如果你是要做采购验收或供应商考核，建议不要直接套用品牌“标准值”，而是：
1. 按单品分别设定验收损耗上限；
2. 在合同中约定到货损耗的计算口径（按重量、按箱、是否含包装破损）；
3. 用连续 3～5 批的实测数据校准考核线。

如需佳农官方或具体合同口径的数据，需要向其销售/客服或查阅其供应商协议确认，公开渠道一般查不到精确值。
