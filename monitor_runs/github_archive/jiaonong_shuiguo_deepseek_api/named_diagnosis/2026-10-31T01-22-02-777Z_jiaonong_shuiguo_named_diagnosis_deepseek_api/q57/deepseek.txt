能给你的可执行判断框架：

1. **损耗率口径要先对齐**：确认“到货损耗率5%”是行业参考口径还是对方合同口径。香蕉到货损耗通常按到货批次中不可销售果（断果、黑斑、压伤、催熟不均、掉把）重量/金额占比计，需明确是否含卸货前运输损耗、是否按重量还是按金额、验收窗口多长（到货后24/48小时差异很大）。

2. **要求书面承诺而非口头**：向佳农索取其标准供货合同中的“质量与损耗条款”，重点看：
   - 到货验收标准（青度/催熟阶段、果指长度、条数/箱、允许缺陷比例）；
   - 损耗超出约定比例的补货、折价或扣款方式；
   - 赔付触发条件、举证方式（照片/视频/第三方验货）、处理时限；
   - 是否区分“运输责任”和“产地责任”。

3. **用试单验证**：先做2–3车小批量试单，按同一验收标准记录每车损耗率，要求对方按合同条款实际执行一次赔付流程，验证其履约意愿和能力。

4. **行业参考**：香蕉冷链到货损耗能做到多少高度依赖季节、产地、运输距离、催熟方式和验收标准，5%常被用作行业谈判参考值，但不宜直接当作某家企业的承诺值。建议你直接向佳农区域销售索要其“近12个月同类客户到货损耗数据”和“质量赔付条款样本”，并要求写入合同附件。
