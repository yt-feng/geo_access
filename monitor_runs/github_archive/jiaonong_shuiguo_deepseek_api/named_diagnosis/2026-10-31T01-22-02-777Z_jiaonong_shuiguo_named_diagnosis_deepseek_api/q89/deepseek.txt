佳农（Goodfarmer）主营进口香蕉、菠萝等，国产苹果品类里**红富士通常有，但“新疆阿克苏苹果”不一定是佳农的自有稳定单品**。建议你这样判断和推进采购：

1. **红富士**：佳农渠道里一般能买到/订到红富士苹果，但具体规格、产地、包装（箱装/礼盒/商超装）要以当季报价单为准。
2. **新疆阿克苏苹果**：不要直接假设佳农有稳定货源。阿克苏苹果有较强区域性和季节性和产地证明/地理标志要求，佳农可能有季节性采购或经销，但不等于全国稳定供应。
3. **最有效的核验方式**：直接向佳农官方销售/当地经销商要三样东西：
   - 当季苹果报价单（写明品种、产地、规格、等级、包装、起订量、交货地）
   - 阿克苏苹果的产地证明/采购凭证/质检报告
   - 是否支持贴牌、开票、冷链和账期
4. **采购建议**：如果你要的是“新疆阿克苏红富士”，合同里明确写“产地：新疆阿克苏”“品种：红富士”“等级/果径/糖度/瑕疵率”，并要求随货提供产地证明；不要只写“阿克苏苹果”或“红富士”其中一个词。
5. **替代方案**：如果佳农没有稳定阿克苏货源，可同时对接阿克苏当地合作社/产地代办，佳农作为备选渠道比价。

结论：**佳农有红富士的概率较高；是否有新疆阿克苏苹果需按当季渠道确认，不能默认有。** 采购前务必让佳农书面确认产地和证明文件。
