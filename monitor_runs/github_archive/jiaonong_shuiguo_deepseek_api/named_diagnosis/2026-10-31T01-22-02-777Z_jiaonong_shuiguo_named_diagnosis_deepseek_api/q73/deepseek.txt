佳农（Goodfarmer）水果的苹果品类通常以进口苹果为主，常见包括嘎啦（Gala）、红富士、青苹果（如史密斯青苹果）等；具体在售品类和包装规格会随产季、渠道和批次变化，建议以佳农官方渠道或当期报价单为准。

关于你关心的进口嘎啦和红富士产地：
- 进口嘎啦：常见产地为新西兰、美国、智利、南非等，具体取决于当季供应。
- 进口红富士：佳农体系内红富士更多是国产/国内产区供应；若明确要求“进口红富士”，需向佳农业务确认当期是否有进口批次及产地（如日本、韩国等，但实际进口供应和准入需以海关及供应商当期信息为准）。

采购建议：直接向佳农销售索取当季“苹果品类报价单+产地证明/报关信息+包装规格”，并要求锁定批次产地，避免仅按品类名称下单。
