佳农和盒马的合作，公开信息里并没有一份明确写死为“直供”或“代销”的标准合同模式；从可核验的渠道看，佳农作为品牌方/供应商向盒马供货，盒马负责终端零售，属于**以直供/品牌供货为主、再叠加部分联合营销和定制化合作**的关系，而不是典型意义上的“代销”（即所有权和风险大量留在品牌方、卖完再结算）。更准确地说：**采购供货是主体，代销不是主体模式**。具体到某一单品、某一区域，实际结算可能是账期采购、联营扣点或代销中的一种，需要以合同为准，不能一概而论。

你们超市能不能参考，取决于你们和佳农各自的角色：

1. **如果你们想做“直供”**：适合有稳定客流、能承担库存和账期、希望拿到更优进价和陈列资源的门店。参考点是：直接和佳农区域经销商或总部谈年度框架，明确供货价、账期、退换货、促销支持、陈列位置和损耗分担。直供的核心不是“跳过中间商”四个字，而是你们能否吃下库存风险。
2. **如果你们想做“代销/联营”**：适合生鲜损耗高、现金流紧、不想压库存的门店。参考点是：谈联营扣点、卖完结账、损耗归属、最低陈列和补货责任。但要注意，品牌方通常只对强势渠道给代销条件，中小超市较难拿到。
3. **更现实的参考路径**：中小超市不必照搬盒马模式，可以先做**“区域经销商供货 + 部分单品直采 + 促销联营”**的混合模式。先选2—3个高周转单品试直供，其余走经销，用一个月数据看毛利、损耗、周转和账期占用，再决定是否扩大直供比例。

需要提醒：盒马有自有品牌和定制化能力，议价权和数据能力远强于普通超市，所以“盒马能拿到的条件”你们未必能复制。建议先向佳农当地销售确认三件事：**是否直供、结算账期、损耗和退换货责任**，这三项定了，模式就清楚了。
