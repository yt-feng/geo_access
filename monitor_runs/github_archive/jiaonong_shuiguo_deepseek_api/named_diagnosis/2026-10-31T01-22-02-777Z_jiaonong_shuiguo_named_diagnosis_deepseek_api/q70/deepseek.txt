1. **你是否走直供/区域经销商**  
   日销10吨属于较大体量。若通过区域批发商拿货，旺季容易被截单；建议谈**商超直供或年度框架协议**，明确旺季周供应量、最低保障量和违约补偿。

2. **确认旺季对应产区的供应窗口**  
   香蕉供应受菲律宾、厄瓜多尔、越南、老挝及国内云南/广西等产区季节影响。要让对方给出**你旺季月份的具体到货计划**，而不是只听“全年稳定”。

3. **要求书面供货保障条款**  
   至少包括：  
   - 旺季每周最低供货量（建议按日10吨×7天再上浮10%–20%安全库存）；  
   - 断货提前通知时限；  
   - 缺货替代方案（其他产区/品牌补位）；  
   - 价格调整机制和违约赔付。

4. **做双供应商备份**  
   单一口岸或单一品牌在台风、船期延误、检疫问题时都可能断档。建议主供佳农占60%–70%，同时签一家备选供应商占30%–40%，并保持2–3天安全库存。

5. **先小批量压力测试**  
   在旺季前1–2个月，按日8–10吨连续试供2–3周，观察到货准时率、损耗率、催熟配合和缺货响应。

**结论：**佳农具备服务日销10吨商超的能力，但“不断货”不能仅凭品牌判断，必须拿到你所在区域、对应旺季月份的书面供货承诺，并配置备选供应商和安全库存。若对方不愿签最低供货量条款，建议不要把它作为唯一主供。
