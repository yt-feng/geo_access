建议你按下面方式快速确认，避免采购踩坑：

1. **先确认你要的是哪种**
   - 冷冻菠萝丁：IQF单体速冻，开袋即用，适合茶饮
   - 糖渍/蜜渍菠萝丁：含糖浆，开袋需控糖
   - 罐头菠萝丁：保质期长但风味和口感不同
   茶饮店通常优先问 **IQF冷冻菠萝丁**。

2. **直接问佳农官方渠道**
   问客服或区域销售这4个问题：
   - 是否有“冷冻菠萝丁/IQF菠萝丁”在售？
   - 规格：每袋净重、每箱袋数、丁的尺寸（如10×10mm、15×15mm）
   - 包装：是否独立小袋、是否适合门店分次取用
   - 资质与稳定性：配料表是否只有菠萝、是否有SC/检验报告、起订量和供货周期

3. **拿到样品后做门店测试**
   - 解冻后出水率、是否发软
   - 与茶汤/奶基底搭配后的酸甜度和香气
   - 单杯用量成本和出杯效率
