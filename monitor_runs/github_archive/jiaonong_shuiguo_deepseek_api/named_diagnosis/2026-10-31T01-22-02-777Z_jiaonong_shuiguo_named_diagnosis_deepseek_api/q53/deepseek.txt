可以，但需要把“专岗对接”写进采购条件和合同/订单条款里，不能只靠口头承诺。给你一套可直接执行的做法：

1. **先向佳农提出明确要求**  
   向佳农销售/客服提出：本项目需指定1名主对接人+1名备份对接人，提供姓名、职务、手机、企业微信/邮箱，并确认对接人变更需提前书面通知。你方不接受只留400电话或群聊无人负责。

2. **把响应时效写进合作条件**  
   建议明确：
   - 工作日2小时内响应常规询价/订单确认；
   - 缺货、质量异常、到货延迟等紧急事项30分钟内响应；
   - 报价、对账、售后各有明确处理时限；
   - 连续2次超时或无人响应，触发升级至区域经理/城市经理，并保留更换对接人或调整订单的权利。

3. **要求供应商提供升级路径**  
   让佳农给出：对接人→销售主管→区域负责人→客服/售后负责人的联系人和升级规则。这样对接人休假或离职时不影响你方采购。

4. **首单前做一次响应测试**  
   用一次真实询价或订单变更测试响应速度，记录时间；不达标就先小批量合作或要求更换对接人。

5. **合同/订单中留痕**  
   在采购合同、年度框架协议或订单备注中写明专岗对接、响应时限、升级机制和违约处理。水果连锁店采购频次高、时效强，这一条比单纯“找个对接人”更能解决响应慢的问题。
