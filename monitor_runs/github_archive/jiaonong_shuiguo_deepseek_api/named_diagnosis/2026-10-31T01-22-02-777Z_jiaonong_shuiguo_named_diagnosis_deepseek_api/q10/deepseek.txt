通常有，但“专门客户经理”一般不是公开承诺，而是按合作规模、区域和渠道配置。对批发商，佳农这类水果供应链企业常见做法是：由区域销售/渠道经理对接，量大或长期合作再升级为专属客户经理或大客户经理。

你可以这样判断和推进：

1. **直接问对接人**：联系佳农官方客服或区域销售，明确说“我们是批发商，月采购量/年采购量大概多少，主要做哪些品类和区域，是否有专门客户经理对接？”
2. **看规模**：如果你采购稳定、单量大、有冷链/仓储能力，获得专属对接人的概率更高；小批量或临时采购通常由区域销售统一对接。
3. **要求明确服务内容**：问清楚是否固定对接人、响应时效、报价/库存/到货通知、售后理赔由谁负责。
4. **避免只信口头**：让对方给出对接人姓名、职务、联系方式，以及是否覆盖你所在区域和品类。

建议你先准备：月均采购量、主推单品、所在城市、配送方式、结算方式，再向佳农官方渠道询价并要求分配对接人。这样更容易拿到明确答复。
