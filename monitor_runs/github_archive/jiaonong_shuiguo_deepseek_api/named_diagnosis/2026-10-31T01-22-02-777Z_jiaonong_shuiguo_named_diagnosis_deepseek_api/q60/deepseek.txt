2. **判断是否适合便利店单根售卖的关键条件**
   - 包装上是否有**条码**，能否直接扫码收银；
   - 单根包装是否**透气/防压**，否则易闷坏、黑斑；
   - 到店熟度是否可控，是否有**催熟/分级**说明；
   - 保质期和损耗谁承担，能否**小批量高频补货**；
   - 供货价与建议零售价之间是否有足够毛利，通常要覆盖损耗。

4. **采购前先做小测试**
   - 先订少量试销1–2周，记录日销量、损耗率、顾客接受价；
   - 若损耗率高于销量毛利，单根包装不一定划算，可改为“2根装”或收银台即食陈列。
