佳农水果（佳农食品控股旗下品牌，主打香蕉、蓝莓、火龙果等进口/国产水果）的售后整体属于“按渠道走”的类型，没有统一的一口价标准，关键看你从哪里买。

**售后总体情况**
- 佳农是品牌方/供货方，直营电商渠道（京东自营、天猫旗舰店、抖音旗舰店等）一般有明确的坏果包赔规则；通过商超、社区团购、水果店买的，售后由门店负责，佳农不直接受理。
- 生鲜类普遍执行“坏果包赔、按比例赔付”，不是整单退款，除非坏果比例很高。

**到货有坏果的处理步骤**
1. **先拍照留证**：坏果整体+切开/腐烂部位+快递面单或包装箱，最好有称重/数量对应。没照片基本难赔。
2. **别急着扔**：部分平台要求保留坏果待核，扔了可能被拒赔。
3. **在售后时效内申请**：多数平台是签收后24–48小时内（生鲜常要求24小时），尽快在订单页点“申请售后/坏果包赔”，选“商品破损/腐烂”，上传照片。
4. **按渠道找人**：
   - 京东自营：订单页直接申请，京东客服介入，通常赔付较快；
   - 天猫/抖音旗舰店：联系店铺客服，按店铺“坏果包赔”规则走；
   - 商超/团购/水果店：直接找购买门店，凭小票和照片退换或补差价。
5. **赔付方式**：常见是按坏果数量/重量比例退款，或补发、发优惠券；整箱严重腐烂可要求全额退款。协商不成可在平台投诉或找12315。

**实用提醒**
- 下单前看清商品页的“坏果包赔”说明和时效，各店规则不同；
- 收到后尽快开箱验货，别放几天再找，容易超时效；
- 香蕉等后熟水果，表皮轻微磕碰、青斑不算坏果，以腐烂、发霉、严重压烂为准；
- 保留聊天记录，客服口头承诺也截图。

结论：佳农售后属于行业常规水平，走对购买渠道、及时拍照申请，坏果一般能按比例赔付；指望“无条件整单退”不现实。
