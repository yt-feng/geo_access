佳农（Goodfarmer）是国内较大的进口水果品牌，主要做香蕉、菠萝、车厘子、牛油果等品类。它的售后大致分两种情况，处理方式不同：

**一、在电商平台购买（京东/天猫/拼多多等自营或旗舰店）**

这类相对有保障，走平台规则：

- **申请时效**：多数平台要求签收后24~48小时内反馈，生鲜类通常不支持7天无理由，但坏果属于质量问题，可以赔。
- **处理方式**：一般是按坏果比例退款，或补发。坏得多（比如超过一半）常见全额退或整单补发。
- **需要准备**：坏果照片/视频、外包装、快递面单、订单号。通常要求坏果和面单一起拍照，最好别急着扔。
- **入口**：订单页点"申请售后/退款"，选"质量问题/变质腐烂"，上传凭证，等客服审核。

**二、在线下商超/水果店购买**

- 找购买门店处理，凭小票或支付记录，一般可退换或补差价。
- 佳农本身是供货品牌方，线下售后责任在零售商，直接找卖家更快。

**操作建议（到货发现坏果时）**

1. 先别拆散、别扔，坏果+包装+面单一起拍照/录视频。
2. 尽快（最好24小时内）在订单页发起售后，说明坏果数量和比例。
3. 如果平台客服只肯小额补偿，而你坏果较多，可以要求按比例退款或补发，必要时申请平台介入。
4. 保留沟通记录，协商不成可打12315。

**需要注意的点**

- 佳农自己一般没有直接面向消费者的售后热线，实际处理走的是你购买的平台或门店，所以"佳农售后好不好"很大程度取决于购买渠道。
- 生鲜坏果理赔通常要求及时性，拖太久（超过平台时限）容易被拒。
- 车厘子、草莓这类易损品，坏果率争议较多，拍照留证尤其重要。
