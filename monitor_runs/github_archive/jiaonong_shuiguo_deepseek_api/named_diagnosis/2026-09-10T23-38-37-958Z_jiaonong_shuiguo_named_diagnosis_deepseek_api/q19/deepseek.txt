佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个统一答案。可以按下面几种情况判断：

**1. 如果你是在电商平台买（京东、天猫、拼多多等）**
- 一般走平台仓或佳农合作仓发货，**下单后 1–3 天发货**，物流时效看平台：
  - 京东自营/次日达覆盖区：常见**次日或隔日到**；
  - 普通快递：**2–5 天**，偏远地区更久。
- 具体以商品页标注的“预计送达时间”为准，那个最准。

**2. 如果是社区团购/生鲜平台（美团优选、多多买菜、盒马等）**
- 通常**次日自提或次日达**，部分城市支持当日达/半日达。

**3. 如果是佳农官方渠道或经销商直发**
- 多为产地/区域仓直发，**发货后 2–4 天**常见，节假日、大促、天气（高温、台风）会延迟。

**快速判断方法：**
- 看商品详情页的“发货地 + 预计送达”；
- 下单前问客服：**从哪个仓发、用什么快递、到你所在城市一般几天**；
- 生鲜水果对时效敏感，优先选**自营/次日达/本地仓**的链接。
