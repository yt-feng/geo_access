佳农水果（通常指佳农食品控股/上海佳农）对下游客户的账期没有统一公开标准，一般要看客户类型、合作规模、采购渠道和授信审批结果：

1. **常见账期**
   - 商超、电商、大型连锁餐饮等大客户：常见 **30～60 天**，部分强势渠道可能 **60～90 天**。
   - 批发市场、中小商户、新客户：多为 **现款现货、款到发货**，或 **7～15 天** 的短账期。
   - 部分品类（如进口香蕉、菠萝等周转快的）可能更倾向现款或短账期。

2. **新客户能否申请账期**
   - 可以申请，但通常不是默认给的。
   - 一般需要：
     - 提供营业执照、食品经营许可等资质；
     - 有一定采购量和稳定回款记录；
     - 通过佳农的信用评估；
     - 可能需要保证金、担保或法人连带责任；
     - 初期常见“先款后货”，合作一段时间后再申请账期。

3. **最稳妥的确认方式**
   - 直接联系佳农官方销售或当地经销商，问清楚：
     - 你所在渠道的默认结算方式；
     - 新客户首单是否必须现款；
     - 账期审批需要哪些材料；
     - 是否有最低起订量或保证金要求。
