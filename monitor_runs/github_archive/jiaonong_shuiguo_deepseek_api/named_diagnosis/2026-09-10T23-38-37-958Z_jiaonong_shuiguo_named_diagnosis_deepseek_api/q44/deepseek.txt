我无法核验“佳农水果香蕉农残超标”的具体历史记录，也不能凭空给你一个“有/没有”的结论。农残是否超标要以官方抽检公告、处罚决定、检测报告为准，企业品牌历史也不等于每一批货都合规。对你们采购来说，关键不是追品牌传闻，而是把**批次合规证明和到货检测**做扎实。

给你一套可执行的采购合规方案：

1. **要求供应商提供每批次合规文件**
   - 产地证明/供货证明
   - 该批次《农药残留检测报告》，最好带 CMA/CNAS 标识
   - 检测项目要覆盖香蕉常用农药和 GB 2763 对应限量，不要只给“合格”两个字
   - 报告上的品名、批次号、生产/采摘日期、供货单位要能和实物对应

2. **核对报告真伪和时效**
   - 报告编号可在检测机构官网/电话核验
   - 检测日期要覆盖该批次，不能用几个月前或别的批次报告顶替
   - 如果是供应商自检报告，只能作参考，不能完全替代第三方报告

3. **到货抽检或送检**
   - 每批做快速农残筛查，定期送第三方做定量检测
   - 重点检测香蕉常见风险项：吡虫啉、噻虫嗪、嘧菌酯、苯醚甲环唑、丙环唑、百菌清等，具体以 GB 2763 和当地监管要求为准
   - 保留留样，至少到该批次售罄后一段时间

4. **合同里写清责任**
   - 供应商保证符合 GB 2763 和超市验收标准
   - 因农残不合格导致抽检失败、下架、罚款、赔偿，由供应商承担
   - 出现不合格时，有权拒收、退货、换货、索赔并终止合作

5. **查公开信息**
   - 国家市场监管总局、各省市市场监管局官网“食品安全抽检公告”
   - 农业农村部及地方农业农村部门例行监测/监督抽查信息
   - 信用中国、企查查/天眼查里的行政处罚记录
   - 搜索时用“佳农 香蕉 抽检 不合格”“佳农 农药残留 处罚”等关键词，但要以官方原文为准

6. **如果超市抽检要求严**
   - 优先选择能提供“批批检”或“批批带第三方报告”的供应商
   - 对佳农这类品牌，不要只认品牌，要求其经销商或产地供应商出具该批次报告
   - 如果对方只能给品牌方通用报告，不能对应你们采购批次，合规风险仍然高
