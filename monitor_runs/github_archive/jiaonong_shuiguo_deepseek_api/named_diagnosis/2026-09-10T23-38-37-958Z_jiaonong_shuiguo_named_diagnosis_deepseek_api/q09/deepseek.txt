佳农（Goodfarmer）并未公开披露统一的“到货损耗率”标准，具体数值会因品类、运输方式、季节、距离和客户验收口径而差异很大，所以很难给一个官方数字。

按生鲜水果行业的一般情况，可作如下参考（注意这是行业经验区间，不是佳农官方标准）：

- **香蕉**：到货损耗通常较高，行业常见在 **3%–8%**，夏季或远距离运输可能更高。
- **菠萝/凤梨**：相对耐储，常见 **2%–5%**。
- **火龙果、芒果、木瓜等热带水果**：常见 **3%–8%**，视成熟度和冷链情况波动。
- **苹果、梨、柑橘等耐储水果**：常见 **1%–3%**。
- **浆果类（如蓝莓、葡萄）**：常见 **5%–10%** 甚至更高。

如果是与佳农做采购或验收，建议直接看合同或验收单里的约定，通常会写明：

1. **损耗定义**：是重量损耗、数量损耗，还是不合格品比例；
2. **验收标准**：允许的次品率、腐烂率、失水率；
3. **扣重/赔付方式**：超出部分如何扣款或补货；
4. **是否含途损**：到仓前损耗由谁承担。

所以，如果你问的是“佳农对经销商的到货损耗控制目标”，更准确的做法是向佳农业务或客服索取该品类的**验收标准**，而不是套用统一损耗率。
