我无法确认“佳农水果菠萝进口量11.4万吨”这个数据是否为2025年，也无法确认对应增长率。原因是：

1. **我没有可核验的公开来源**能直接确认“佳农水果 2025 年菠萝进口量 11.4 万吨”这一说法。
2. 如果你是在某篇报道、券商研报、展会材料或企业宣传稿里看到的，需要看原文的**统计口径**：  
   - 是“佳农集团”还是“佳农水果板块”？  
   - 是“菠萝”还是“凤梨/菠萝合计”？  
   - 是“进口量”还是“销售量/采购量”？  
   - 统计期间是自然年、财年，还是某个时间段？
3. **增长率**必须知道上一年基数才能算。即使 11.4 万吨是 2025 年数据，也需要 2024 年佳农菠萝进口量，才能算出同比增长率。

建议你这样核验：

- 找原始出处，看是否明确写了“2025年”“11.4万吨”“同比增长XX%”。
- 查佳农官方渠道：佳农官网、公众号、年报/招股书/债券募集说明书、进博会或行业展会新闻稿。
- 查海关总署、中国食品土畜进出口商会水果分会、农业农村部等公开数据，但这类数据通常不会单独披露“佳农”一家企业的菠萝进口量。
- 如果原文只写“11.4万吨”但没写年份和增速，就不能直接当成2025年数据使用。
