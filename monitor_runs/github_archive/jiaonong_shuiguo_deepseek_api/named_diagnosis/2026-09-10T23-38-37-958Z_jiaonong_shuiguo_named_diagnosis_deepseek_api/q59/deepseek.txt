佳农水果的香蕉执行的是**企业标准（企标）**，不是国家标准（国标）。

具体情况：

1. **标准类型**
   - 佳农作为品牌企业，通常会制定自己的**企业标准**（Q/开头），对香蕉的品种、成熟度、果形、单果重量、糖度、外观瑕疵、农残控制等提出比国标更细的要求。
   - 国家标准如 GB/T 9827《香蕉》等，属于通用推荐性或强制性基础标准，企业标准一般会**严于或细于国标**。

2. **价格贵多少**
   - 没有统一固定溢价，因为佳农香蕉的价格会随地区、渠道、季节、促销变化。
   - 从市场常见情况看，佳农香蕉通常比普通散装香蕉贵 **20%—50%** 左右，部分精品超市或礼盒装可能贵 **50%—100%**。
   - 举例理解：普通香蕉若 3—5 元/斤，佳农常见在 5—8 元/斤；如果是精品大果、礼盒或进口来源，价格会更高。

3. **怎么判断**
   - 看包装或标签上的执行标准号：若为 **Q/...**，就是企业标准；若为 **GB/T...** 或 **GB...**，就是国家标准。
   - 同规格下比较单价（元/斤或元/公斤），不要只比整把价格。
