佳农香蕉的保质期和储存条件，关键取决于**是否已催熟、当前成熟度以及存放温度**。通常可以参考以下判断：

**1. 常温储存（最常见）**
- **未完全成熟/青香蕉**：放在阴凉通风处，约 **3～7天** 逐渐变黄成熟。不要直接放太阳下或暖气旁。
- **已变黄、刚成熟**：常温下一般 **2～4天** 内吃完口感较好。
- **出现芝麻点/黑斑**：说明已很熟，最好 **1～2天内** 吃完，适合直接吃或做奶昔、烘焙。

**2. 冷藏储存**
- 香蕉**不建议在未成熟时冷藏**，容易冻伤、发黑、难以正常成熟。
- **已经成熟的黄香蕉**可以冷藏，能延长 **2～4天**左右，但表皮会变黑，果肉通常仍可食用。
- 冷藏前建议用保鲜膜包住香蕉根部，或整根/切段密封，减少水分流失和串味。

**3. 冷冻储存**
- 熟透吃不完的香蕉可去皮、切段、密封后冷冻，通常可保存 **1～3个月**。
- 适合做冰沙、香蕉奶昔、烘焙，不适合解冻后直接当鲜果吃。

**4. 判断是否还能吃**
- 可以吃：表皮变黑但果肉正常、有香蕉香、无酸败味。
- 不建议吃：果肉发黏、出水、有酒味/酸味、霉变，或切开后明显腐烂。

**5. 实用建议**
- 想催熟：和苹果/梨一起放纸袋里，常温放置。
- 想延缓成熟：成熟后尽快冷藏，并减少挤压。
- 佳农香蕉如果是整把购买，按包装上的储存说明为准；若包装标注了具体保质期，以包装日期和条件为准。
