这个需要直接找佳农的对接渠道确认，我无法核实他们当前的促销政策。不过可以给你一套判断和推进方法：

**佳农通常可能提供的支持形式**
- **搭赠**：进 N 箱送 M 箱，常见于香蕉这种走量品类
- **降价补贴**：厂家承担部分降价差额，或给特价供货价
- **陈列/堆头费用**：配合促销位置给费用或货补
- **损耗补贴**：香蕉易损，有时按比例补损耗

**但具体给不给、给多少，取决于几个因素**
1. 你的采购量和门店规模（量大才好谈）
2. 是否配合他们的品牌陈列/主推要求
3. 促销档期是否在他们的市场计划内
4. 是跟佳农直签还是通过经销商（经销商政策常不同）

**建议你这样做**
- 直接联系佳农区域业务或你的供货经销商，明确问：本次档期能否给搭赠或价补、比例多少、有无陈列要求
- 谈的时候带上预估销量和档期时间，筹码更足
- 如果佳农不给，可同步问其他香蕉供应商比价，形成谈判压力

如果你告诉我你是直采还是走经销商、大概采购量多少，我可以帮你把谈判话术和要问的条款列得更具体。
