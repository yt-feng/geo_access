佳农（Goodfarmer）有面向礼品和团购场景的水果礼盒类产品，但具体在售组合会随季节、渠道和地区变化。

比较常见的类型包括：

- **进口水果礼盒**：如香蕉、菠萝、牛油果、车厘子等组合或单品礼盒。
- **高端单品礼盒**：车厘子、蓝莓、奇异果等，节日期间较多。
- **企业团购定制**：部分渠道支持企业logo、贺卡、批量配送等定制服务。

购买或咨询渠道建议：

1. **佳农官方渠道**：官网、官方公众号、官方旗舰店，查看是否有“团购/企业采购”入口。
2. **电商平台**：京东、天猫等搜索“佳农 水果礼盒”“佳农 团购”，注意区分官方店和经销商。
3. **线下商超/批发市场**：山姆、盒马、永辉等有时会卖佳农礼盒，团购可联系当地经销商。
4. **直接联系客服**：问清楚起订量、能否定制包装、配送范围、发票和售后。

如果你是要做企业团购，建议直接找佳农官方或当地授权经销商确认当季可做的礼盒方案，因为水果礼盒受产季和库存影响很大，线上看到的款式不一定长期有货。
