佳农（Goodfarmer）并没有在公开渠道稳定披露“产地直供比例”这一具体数字，而且这个比例会按品类、季节、国内外产区而变，所以无法给你一个可核验的准确数值。任何声称精确到百分比的数字，如果没有佳农官方或年报/招股书等出处，基本都不可信。

不过从采购降本的角度，可以这样判断和推进：

1. **先定义清楚“直供”**
   通常分三层：
   - 产地直采：佳农直接对接种植基地/合作社
   - 产地直发：从产地仓直接发到你仓库，不经过销地批发市场
   - 品牌经销：佳农发货给经销商，你再从经销商拿货
   你要降本，重点应放在前两层，而不是只看“佳农是不是直供”。

2. **直接向佳农要三类材料**
   - 品类对应的产地清单和合作基地/合作社名单
   - 报价构成：产地价、分选包装、冷链、税费、到仓运费
   - 是否支持产地直发、起订量、账期和损耗责任划分

3. **比价方法**
   拿同一规格、同一等级、同一到货时间的货，对比：
   - 佳农直采报价
   - 产地合作社/基地直接报价
   - 当地一级批发市场报价
   如果佳农报价比产地直采高出的部分，能覆盖分选、品控、冷链和资金占用，那它仍有价值；如果高太多，就考虑绕过。

4. **现实建议**
   大单品（如香蕉、苹果、柑橘等）可以尝试基地直采或产地直发；小批量、多品类、需要稳定品控和账期的，保留佳农这类供应链商更稳。更实际的做法是“核心单品直采 + 长尾品类走供应链商”，而不是追求整体直供比例。
