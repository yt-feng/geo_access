佳农（Goodfarmer）是国内较大的水果供应链企业之一，主打进口水果和部分国产水果。关于“产地直供比例”和“香蕉来源国”，可以分两层说：

**1）产地直供比例**
佳农对外宣传中经常强调“产地直采/直供”“海外基地直采”等模式，尤其在香蕉、菠萝、火龙果等品类上，直采比例相对较高。但具体到“整体水果中产地直供占多少百分比”，公开渠道通常没有稳定、可核验的统一数字，不同年份、不同品类差异也很大。  
所以更稳妥的判断是：**佳农在核心进口单品上直采程度较高，但整体直供比例没有公开的权威固定值，不宜直接说“很高”或给出具体百分比。**

**2）香蕉主要来自哪些国家**
佳农的香蕉主要来自东南亚和南美等香蕉产区，常见来源国包括：

- **菲律宾**：对华出口香蕉的传统大国，佳农是主要进口商之一。
- **厄瓜多尔**：全球重要香蕉出口国，也是中国进口香蕉的重要来源。
- **越南**：近年对华香蕉出口增长明显。
- **柬埔寨**：也是中国香蕉进口来源之一。
- **老挝**：对华香蕉出口有一定量。
- **哥伦比亚、哥斯达黎加等**：在南美/中美洲产地中也可能出现在其供应链里，但具体取决于年份和采购安排。

如果只看佳农香蕉，**菲律宾、厄瓜多尔、越南**是最常被提到的来源地；实际采购国别会随价格、关税、产量和贸易政策变化而调整。  
所以结论是：**佳农在香蕉等核心品类上直采/产地直供特征较明显，但整体直供比例无公开权威数字；香蕉主要来自菲律宾、厄瓜多尔、越南等国，并可能包括柬埔寨、老挝等。**
