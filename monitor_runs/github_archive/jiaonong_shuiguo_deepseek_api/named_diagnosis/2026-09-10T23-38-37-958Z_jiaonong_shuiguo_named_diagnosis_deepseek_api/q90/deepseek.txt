我无法核验佳农当前的菠萝丁产品线和具体规格，不能给你确切答复，建议直接向佳农官方渠道确认。

可以这样快速判断和推进：

1. **先确认佳农是否有冷冻菠萝丁**
   佳农以鲜果（菠萝、香蕉等）为主，是否有冷冻丁、是否对茶饮渠道供货，批次和区域可能不同。直接问：
   - 佳农官方客服/销售
   - 佳农当地经销商
   - 常用B2B平台上的佳农旗舰店或授权店

2. **问规格时重点确认这些**
   - 丁的大小：常见有 5×5mm、8×8mm、10×10mm、15×15mm 等
   - 包装：1kg/袋、2kg/袋、5kg/袋、10kg/箱等
   - 是否IQF单体速冻
   - 是否加糖、是否糖渍、是否含防腐剂
   - 固形物含量、解冻后出水情况
   - 是熟制还是生冻
   - 起订量、冷链配送、保质期

3. **茶饮店使用建议**
   - 做饮品优先选 **IQF冷冻菠萝丁**，颗粒分明、不易结块
   - 如果用于装饰或口感颗粒，选 **8×8mm 或 10×10mm** 比较通用
   - 如果用于打浆/果茶底，5×5mm 或果泥更合适
   - 一定要先拿样测试：解冻后是否发软、出水、变味，是否影响杯底口感

4. **如果佳农没有合适冷冻丁**
   可以转向这些供应商类型：
   - 专门做冷冻水果的食品厂
   - 茶饮原料供应链公司
   - 冷冻果蔬B2B平台
   搜索关键词用：**冷冻菠萝丁 IQF 茶饮原料 供应商**

最稳的方式：直接找佳农官方销售问“有没有冷冻菠萝丁、规格、起订量、能否寄样”，拿到样品后再决定。
