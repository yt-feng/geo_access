通常会有，但要看你的采购规模和合作渠道。佳农这类大型水果供应链企业，一般对批发商/渠道客户会安排对应的销售或客户经理对接，尤其是：

- **有稳定批量采购**的批发商、档口、商超供应链、电商仓配客户
- **已经签过年度框架、月结账期或区域代理**的客户
- **通过总部或区域分公司开户**的客户

如果你只是零散拿货、通过二级批发市场或平台下单，可能不会配专属客户经理，而是由区域销售/客服统一对接。

**你可以这样确认：**
1. 直接联系佳农官方客服或你所在区域的销售负责人，说明你是批发商、月采购量大概多少、要什么品类。
2. 问清楚：是否配专属客户经理、对接人是销售还是客服、能否给批发价和账期。
3. 如果对方说“没有专属”，可以要求转到**区域渠道销售**，通常比普通客服更能处理批发合作。

**判断标准：**
- 月采购量稳定且有一定规模：大概率能配客户经理。
- 采购量小或刚起步：一般是区域销售兼管，不会专人对接。
- 想拿更优价格和政策：直接谈“开户+年度采购量”，比只问“有没有客户经理”更有效。
