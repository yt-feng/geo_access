佳农（Goodfarmer）主要是香蕉、菠萝等水果的**种植、进口和批发商**，常规业务是整果或鲜切水果供应，**一般不为茶饮店提供按需去皮切块的定制加工服务**。具体来说：

- **标准品**：佳农有鲜切菠萝/菠萝块产品（部分渠道有售），但规格、包装是固定的，不是按你的配方定制。
- **定制加工**：像"按你的要求去皮、切特定大小块、按门店用量分装"这类服务，通常需要**中央厨房、净菜加工厂或第三方果蔬加工商**来做，佳农这类品牌商一般不接。

**建议你可以这样推进：**

1. **直接问佳农当地经销商或销售**：确认是否有"鲜切菠萝块"标准品可直供，以及规格（块径、包装、保质期）。这是最快能确认的。
2. **如果佳农只有整果**：找**本地的果蔬加工厂/净菜配送商**做代加工，或自己门店后台处理。整果自己切成本更低，但要考虑人工和损耗。
3. **算一笔账**：整果采购价 vs 鲜切菠萝块采购价，把去皮损耗（菠萝出肉率约50%-60%）、人工、储存成本都算进去，再决定哪种更划算。

一句话：**佳农大概率只能给你整果或标准鲜切块，定制去皮切块得找加工商或自己做。** 建议先打电话问佳农当地销售确认，再对比本地加工方案。
