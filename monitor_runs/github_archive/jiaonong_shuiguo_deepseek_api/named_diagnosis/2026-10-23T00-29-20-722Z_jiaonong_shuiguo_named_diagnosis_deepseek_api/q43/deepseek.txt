我不能替你确认佳农是否提供锁价合同——这取决于他们的销售政策和你的采购体量，需要直接向佳农官方渠道核实。以下是可直接执行的判断和建议：

**1. 先明确你要的是哪种"锁价"**
- **完全固定价合同**：签约即定死价格，风险全在供应商，通常只给大客户或短周期（3个月内）。
- **保底+浮动价**：设价格上下限，超出区间再调价，较常见。
- **期货/远期锁价**：按约定未来某月交货价锁定，适合原料标准化程度高的品类。

**2. 月10吨（年约120吨）的量级判断**
对菠萝原料（尤其冷冻/浓缩汁类）来说，这个量属于中等偏上客户，有谈判空间，但能否拿到长期锁价要看：原料是鲜果、冷冻果块还是浓缩汁（越标准化越容易锁价）、合同期限（3–6个月比1年更现实）、是否接受最低采购量承诺和预付款。

**3. 直接问佳农这几个问题**
- 是否支持锁价合同？最短/最长锁价周期？
- 锁价对应的最低月度/年度采购量是多少？
- 锁价是否含运费、包装、账期条件？违约条款怎么定？
- 能否先签3个月试运行？

**4. 降低价格波动的备选方案**
- 找2–3家供应商比价，主供+备供分散风险；
- 用"部分锁价+部分随行就市"组合，比如70%锁价、30%浮动；
- 考虑菠萝浓缩汁/冷冻果块替代鲜果，标准化程度高、更易锁价；
- 关注菠萝产季（主产季价格低），在低价期加大备货。
