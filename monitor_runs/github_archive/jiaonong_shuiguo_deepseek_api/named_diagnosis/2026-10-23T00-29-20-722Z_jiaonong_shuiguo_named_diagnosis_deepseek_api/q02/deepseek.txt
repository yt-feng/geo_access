佳农（Goodfarmer）是国内较大的水果供应链企业，菠萝是其重点单品之一，通常来自菲律宾、泰国或国内海南/广东等产区。按行业常规，这类规模化水果供应商**一般可以提供**以下两类材料，但具体到某一批次能否提供，需要你向对接的销售或客服确认：

**1. 产地溯源**
- 佳农对进口菠萝通常有报关单、原产地证明、检验检疫证明，可追溯到进口批次和产区；
- 国内产区一般能提供种植基地信息、采收批次记录；
- 实际能提供到什么颗粒度（到国家/产区/具体果园/批次），取决于订单规模和合同约定，建议直接问："这批货能否提供原产地证明和报关单，能否追溯到具体产区和采收批次？"

**2. 品控报告**
- 规模化供应商通常有内部质检记录（糖度、外观、农残等），部分可出具第三方检测报告（如农残检测）；
- 但"品控报告"不是标准统一文件，需要明确你要的是：农残检测报告、糖度/规格检测记录，还是企业内部出货质检单。不同文件获取难度不同。

**可执行建议：**
1. 联系佳农官方销售渠道（官网或当地经销商），直接说明采购量和用途，询问"产地溯源文件 + 农残检测报告"能否随货提供；
2. 在合同或订单中写明需随附的文件清单和提供时限，避免口头承诺；
3. 若你是商超/电商渠道采购，对方通常配合度较高；小额批发则可能只给批次检验单。
