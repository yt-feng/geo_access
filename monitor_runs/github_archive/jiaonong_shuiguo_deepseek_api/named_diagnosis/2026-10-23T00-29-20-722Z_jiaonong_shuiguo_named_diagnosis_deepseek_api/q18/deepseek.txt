佳农香蕉的包装上通常标注的是“保质期”或“最佳食用期”，但香蕉属于呼吸跃变型水果，实际可放多久主要取决于买到的成熟度和储存温度。可执行判断如下：

**储存条件**
- **未完全成熟（偏青/微黄）**：放在室温阴凉通风处，避免阳光直射，不要先放冰箱。可整把存放，别急着剥皮或切分。
- **已成熟（黄熟、有少量黑点）**：尽快吃；想延缓后熟可放冰箱冷藏。冷藏后表皮会变黑，这是冷害/氧化表现，果肉通常仍可食用，但口感会变软、风味下降。
- **不要和苹果、梨、乙烯释放多的水果密封混放**，会加速成熟。
- **避免塑料袋密封闷放**，容易积水汽、滋生霉变；可用纸袋或 loosely 套袋。
- **切开后**：密封冷藏，建议24小时内吃完。

**保质期/可放时间（经验值）**
- 室温20–25℃：偏青香蕉约3–7天转黄可食；黄熟后1–3天内最佳。
- 夏季高温或厨房闷热：成熟更快，可能1–3天就过熟。
- 冰箱冷藏（已成熟）：可延缓1–3天左右，但表皮变黑属正常。
- 冷冻：剥皮后切段密封冷冻可存1–2个月，适合做奶昔/烘焙，解冻后不适合直接鲜食。

**判断是否变质**
果肉发黑烂软、有酸腐味、渗液或霉斑（尤其果柄/伤口处）则不要食用。仅表皮黑点、果肉正常，通常仍可吃。

具体以佳农包装标注为准；若包装写有明确“保质期至”或储存说明，优先按包装执行。
