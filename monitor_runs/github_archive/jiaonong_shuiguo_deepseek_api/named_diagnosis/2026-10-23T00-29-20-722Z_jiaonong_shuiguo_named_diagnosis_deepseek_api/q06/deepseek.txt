**1. 佳农是否适合普通茶饮店**
佳农属于大型水果供应链企业，通常能做稳定供货、分级和冷链，但普通单店或小店未必能直接拿到最优条件。更现实的方式是通过当地经销商、批发市场档口或区域代理拿货；连锁或月采购量较大的门店，可以尝试直接对接区域销售。

**2. 普通商家能听懂的菠萝规格**
茶饮店采购菠萝，不建议只问“大果、中果”，而要用可验收的指标：
- **品种**：金钻/香水菠萝/普通鲜食菠萝，先确认是否适合鲜切和榨汁。
- **单果重量**：例如 1.0–1.2kg、1.2–1.5kg，按箱标注范围。
- **箱规**：每箱几果、净重多少，例如 6–8 果/箱、净重 10kg。
- **成熟度**：到店时青黄比例、是否可即切、催熟要求。
- **果形与出肉率**：果眼深浅、芯大小、去皮损耗率。
- **加工适配**：鲜切果块、果肉浆、冷冻果肉是否可做，出汁率或出肉率大概范围。
- **验收标准**：黑心、水心、烂果、碰伤、异味允许比例，以及到货温度。
- **供货稳定性**：每周可供量、最低起订量、提前下单天数、缺货替代方案。

**3. 建议你直接这样问供应商**
“请给我茶饮店用的菠萝规格表：品种、单果重量范围、每箱净重和果数、到货成熟度、鲜切出肉率/出汁率参考、坏果赔付标准、每周稳定供应量和起订量。”  
如果对方只能回答“中大果、按箱卖”，不能给可验收指标，就不适合作为长期稳定原料。

**结论**：佳农具备稳定供货能力，但普通商家能否拿到“听得懂的规格”，取决于你是直供还是经销渠道。采购时不要只认品牌，要拿到书面规格和验收标准再下单。
