佳农（佳农食品控股）是国内头部进口香蕉玩家之一，供应链能力在行业里算靠前的，但“一天20吨、旺季不断货”能不能保证，要看几项具体条件，不能只凭品牌名气下结论。

**先说判断结论：**
- 20吨/天 ≈ 600吨/月 ≈ 7200吨/年。这个量级对佳农这种体量是接得住的，属于中大型商超客户的常规量级，不是天花板。
- 但“不断货”的保证不取决于它有没有货，而取决于**合同怎么签、产地季节性、以及你对缺货的容忍度**。旺季断货风险真实存在，任何供应商都不敢拍胸脯100%不断。

**需要向佳农核实并写进合同的关键点：**

1. **分货源季节的供应能力**
   - 佳农香蕉主要来自厄瓜多尔、菲律宾、越南、柬埔寨及部分国产（云南/广西/海南）。不同季节主力产地不同，菲律宾台风季、厄瓜多尔物流、国产冬季低温都可能造成波动。
   - 要求对方给出**按月的可供量承诺**，尤其覆盖你的旺季月份，明确哪几个月是紧平衡。

2. **安全库存与备货机制**
   - 明确佳农为你这个客户**预留的周备货量**、你的仓库/配送中心到货频次（每天到还是隔天到）。
   - 旺季是否支持**提前锁量**（比如旺季前1-2个月按周锁量），锁量后缺货的违约责任。

3. **缺货条款**
   - 合同里写**到货率指标**（如月度到货率≥98%）和**缺货赔付/补货时限**，而不是口头承诺。
   - 约定不可抗力（台风、罢工、港口拥堵）之外的断货如何赔偿、如何优先保供。

4. **单一供应商风险**
   - 20吨/天不建议只压一家。可以佳农做主供（比如60-70%），再配1家二供（如其他进口蕉商或国产蕉基地）做补充，旺季切换。这是商超保供的常规做法。

5. **品控与损耗**
   - 香蕉是呼吸跃变型水果，旺季高温下到货成熟度、催熟衔接、货架期都会影响“实际可售量”。确认佳农的催熟/冷链配合能力，以及到货成熟度标准（如青蕉色号）。

**给你一个可执行的动作清单：**
- 让佳农出具**过去12个月对你同量级客户的月度实际发货数据**（可脱敏），看旺季是否真稳。
- 谈**旺季锁量+到货率KPI+缺货赔付**三件套写进年度框架合同。
- 同步启动二供询价，把二供作为旺季保险，哪怕平时不用。
- 先做1-2个月试供，用实际到货率验证再放量。

一句话：佳农有能力供20吨/天，但“不断货”要靠合同条款和双供应商机制来兜底，不能只靠供应商口头保证。
