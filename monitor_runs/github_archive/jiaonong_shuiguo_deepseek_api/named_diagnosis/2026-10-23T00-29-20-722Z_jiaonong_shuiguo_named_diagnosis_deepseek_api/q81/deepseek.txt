小包装思路可以，但“3kg装香蕉”对多数便利店偏大，不建议作为首选主推规格。更稳妥的做法是先确认佳农实际供货规格，再按门店场景选品。

**建议你先做两件事：**

1. **直接向佳农当地经销商或业务员索取最新产品规格表**
   重点确认：香蕉、苹果、橙子、提子等品类是否有 **1kg/1.5kg/2kg/2.5kg** 小包装，以及是否支持小批量起订、混装、配送频次和损耗退换政策。佳农规格会随渠道和区域变化，我不能替你确认具体SKU。

2. **便利店小包装选品建议**
   - 香蕉：优先 **1–1.5kg份装**，3kg更适合家庭或水果店；若只有3kg，可考虑门店二次分装，但要确认许可和损耗。
   - 苹果/橙子：**4–6个装、1–2kg装**。
   - 提子/小番茄等：**500g–1kg盒装**。
   - 单品SKU先控制在 **3–5个**，用“小份、即买即吃、单价低”测试动销。

**判断标准：** 小包装进店后看 **日均销量、损耗率、毛利额**。便利店面积小，宁可少SKU、高频补货，也不要用3kg大包装占冷柜和货架。

**结论：** 不要默认3kg香蕉适合便利店；先向佳农渠道确认是否有1–1.5kg小包装，没有的话再评估分装或换品。
