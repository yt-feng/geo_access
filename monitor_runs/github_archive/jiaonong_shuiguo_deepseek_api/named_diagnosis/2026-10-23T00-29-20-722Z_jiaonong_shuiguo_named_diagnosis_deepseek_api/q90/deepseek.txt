我无法核验佳农当前是否有“冷冻菠萝丁”这款SKU，也无法确认具体规格，直接给结论容易误导你采购。建议按下面方式快速确认，通常当天能得到准确答复：

1. **先查官方渠道**  
   - 佳农官网/官方公众号的“产品中心”或“餐饮渠道/工业原料”栏目，看是否列有“冷冻菠萝丁/速冻菠萝丁”。  
   - 天猫/京东“佳农官方旗舰店”搜“冷冻菠萝丁”“速冻菠萝丁”，看商品页规格；注意区分“鲜切菠萝”和“冷冻果丁”。

2. **直接问销售，问清这5项**  
   联系佳农官方客服或当地经销商时，按茶饮店原料要求问：  
   - 是否有**冷冻菠萝丁**（IQF速冻）产品，还是只有鲜切/糖水菠萝；  
   - 规格：**每袋净含量（如1kg/2kg/5kg/10kg）**、箱规；  
   - 果丁尺寸：**边长或筛网规格（如10×10mm、15×15mm）**；  
   - 包装形式：**单体速冻还是结块冻**、是否适合门店分次取用；  
   - 供货条件：**起订量、冷链配送、保质期、产地/批次**。

3. **要样品做门店测试**  
   茶饮用菠萝丁重点看：解冻后出水、酸甜度、纤维感、是否发软、与茶底适配。先要小样，确认后再定箱规和补货周期。

如果佳农没有冷冻丁，可同步问其经销商是否有**速冻菠萝丁代工/餐饮装**；没有的话再考虑其他专注冷冻水果的B端供应商。采购时务必让对方提供**产品规格书和检验报告**，不要只凭口头规格下单。
