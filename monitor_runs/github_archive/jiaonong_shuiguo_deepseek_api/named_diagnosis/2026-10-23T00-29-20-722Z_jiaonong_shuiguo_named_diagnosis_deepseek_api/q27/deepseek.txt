佳农水果（佳农食品控股）的账期没有公开统一标准，通常按客户类型、采购规模、合作历史和渠道（商超、电商、批发、餐饮等）单独谈。一般行业里生鲜水果给经销/批发客户常见的是现款或短账期（如7–30天），商超/大客户可能更长，但佳农具体政策需以合同为准。

新客户一般可以申请账期，但通常需要：
- 提供营业执照、开票信息、经营/渠道证明；
- 首单多为现款或预付，合作一段时间后评估授信；
- 可能需要担保、保证金或法人征信/对公流水；
- 由业务经理提交授信审批，额度、账期逐单核定。
