佳农（佳农食品控股/Goodfarmer）的物流体系更接近“自营+外包混合”，不是纯自营，也不是全外包：

1. **物流网络模式**
- **核心节点自营为主**：在主要口岸、销地仓、加工配送中心等关键环节，佳农通常自建或自营团队管理仓储、加工、分拣、温控和干线调度，以掌握香蕉、菠萝、车厘子等品类的品质和交付。
- **干线运输和区域配送大量外包**：长途冷链干线、部分区域城配、临时运力通常采购第三方冷链物流服务商，按线路/项目合作，属于轻资产+关键节点控制模式。
- **判断依据**：公开资料和行业报道中，佳农强调“全球供应链+国内分销网络”，但未宣称拥有全国性自有车队；其能力更多体现在产地采购、口岸加工、销地仓配和渠道分销，而非纯物流公司式自营网络。

2. **冷链能力**
- **品类决定冷链强度**：香蕉、车厘子、蓝莓、牛油果等对温控要求高，佳农在口岸和销地通常具备冷藏仓储、催熟/加工、温控分拣能力；苹果、橙类等相对耐储品类冷链要求较低。
- **关键环节较强**：产地预冷/冷藏、海运冷藏柜、口岸冷链查验与仓储、销地冷藏配送等环节有较成熟管理经验。
- **末端配送不一定全程冷链**：到商超、批发市场、电商仓的干线/城配可控性较高；到终端门店或消费者的“最后一公里”更多依赖客户或第三方，未必全程冷链。
- **总体评价**：冷链能力在水果进口商和品牌商中属于较强水平，强在“关键节点温控+品类经验+口岸资源”，弱在“全国自有冷链网络全覆盖”和“末端全程冷链”。

**可执行判断**：如果你要评估其物流合作价值，重点看其口岸仓、销地仓是否自营及温控记录；如果是采购方，要求其提供具体线路的承运商、温控标准和异常处理机制，比问“自营还是外包”更有意义。
