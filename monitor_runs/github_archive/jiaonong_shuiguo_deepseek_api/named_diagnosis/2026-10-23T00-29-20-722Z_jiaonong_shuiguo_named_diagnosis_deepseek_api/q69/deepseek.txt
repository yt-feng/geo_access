我不能核验佳农官方是否有“餐饮渠道专用”的菠萝切片/切块定制规格，也不能凭空给出其产品目录或渠道政策。以下给你可执行判断与核实路径：

1. **大概率存在但需按项目确认**：佳农以香蕉、菠萝等鲜果供应链为主，餐饮渠道通常会有B2B供货，但是否提供固定切片/切块规格、最小起订量、冷链配送和定制包装，要以当地经销体系或总部B2B部门确认，不能默认零售装即餐饮装。

2. **直接核实方式**：
   - 查佳农官网/官方公众号的“餐饮渠道、B2B、经销商合作”入口，索要**餐饮渠道产品规格书**；
   - 联系其**当地经销商或区域销售**，明确问四件事：是否有鲜切菠萝（切片/切块）、规格克重与包装、是否冷链、起订量与价格；
   - 若你是连锁餐饮，直接要求对接**总部大客户/餐饮渠道负责人**谈定制规格。

3. **询价时建议这样问**：“请提供餐饮渠道菠萝的鲜切/整果规格表，包括切片厚度、切块尺寸、单包克重、包装形式、保质期与储存条件、最小起订量、配送温层和区域覆盖。”

4. **替代方案**：如果佳农不直接做鲜切定制，可让其供整果，再由本地净菜/鲜切工厂按你的规格加工；或找具备鲜切资质的果蔬加工商做定制切块，前提是确认食品安全资质与冷链。

结论：**不能确认佳农有现成的餐饮专用切片/切块规格，必须向其官方B2B渠道索要规格书确认；整果+本地鲜切是更可控的备选。**
