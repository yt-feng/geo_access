对你们采购更实用的做法：

1. **先定义口径再问供应商**：让对方明确“产地直供”指自有基地直发、合作基地直发，还是仅一级代理。要求按品类给出直发SKU占比、基地名单和发货仓。
2. **按品类做直采可行性排序**：香蕉、菠萝等佳农优势品类更可能基地直发；进口杂果、季节性小单品往往仍经口岸/经销商。
3. **要求报价拆解**：出厂价、包装、冷链、口岸/仓储、配送、账期成本分开报，才能判断中间环节成本。
4. **小批量试单验证**：选2—3个高量SKU做基地直发试单，对比到岸成本和损耗率，再谈年度框架。
5. **备选源头**：直接对接产区合作社/出口商或口岸一级进口商，用佳农报价做对标。
