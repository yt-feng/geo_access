佳农水果的售后整体属于“生鲜电商常规水平”：坏果、烂果、压伤一般可以赔，但关键看你从哪里买，处理渠道不一样。

## 先分清购买渠道

- **电商平台自营/旗舰店（京东、天猫、抖音等）**：直接走平台售后，通常最顺。拍坏果照片+称重/个数，申请“坏果包赔/部分退款”。
- **社区团购/团长**：先找团长，通常按“坏果拍照上报—补发或退款”处理，平台介入较慢。
- **线下商超/水果店**：按门店规定，一般凭小票当场换或退。
- **佳农官方小程序/直播间**：走其客服，保留订单号和开箱照片。

## 到货有坏果怎么处理（可执行步骤）

1. **先别扔，也别急着全切开**：把坏果单独挑出，和好果分开放。
2. **拍照取证**：整箱外包装、快递面单、坏果特写、坏果与好果同框、能看出数量的全景。最好拍一段开箱视频。
3. **称重或数个数**：多数生鲜售后按坏果比例赔，比如坏3个/整箱12个，就申请25%退款；按重量则称坏果重量。
4. **尽快申请**：一般要求签收后24—48小时内反馈，越早越好，别拖到超过平台时限。
5. **选售后类型**：坏果少选“部分退款”，坏得多选“补发”或“全额退款”；商家拒绝就申请平台客服介入。
6. **保留原包装**：有些商家要求退回或拍照核验，别马上丢。

## 判断与注意

- **正常范围**：少量碰伤、表皮瑕疵通常不算坏果；发霉、流汁、腐烂、异味才算。
- **容易扯皮的点**：签收太久、无开箱证据、坏果已扔、只拍局部看不出数量。这几种情况赔付会打折甚至被拒。
- **佳农的特点**：它是品牌供应链，品控相对稳定，但水果是生鲜，运输损耗难免；售后政策跟随销售平台，不是全国统一一套标准。

**建议**：下单前先看该店铺商品页有没有“坏果包赔”标识和时限；到货当天开箱拍照，有问题24小时内提交，基本都能拿到部分退款或补发。
