佳农香蕉的具体规格会随包装形态、销售区域和客户定制变化，公开可核验的固定“全国统一规格表”并不透明。比较稳妥的判断方式是按“包装形态 + 单根重量/条数 + 渠道用途”来分级，而不是记某几个固定数字。

**常见规格维度（需以实际订单/门店标签为准）**
1. **按包装形态**
   - 整箱散装香蕉：常见按箱重计，如约10kg、12kg、13kg、18kg等箱规，具体随产地和季节浮动。
   - 梳蕉/把蕉：按把或按重量分装，适合商超散卖。
   - 单根预包装：适合便利店、水果店、即时零售。
   - 礼盒装：适合节庆、团购、电商礼赠。

2. **按单根重量/果指大小**
   - 大果：单根较重，适合家庭采购、水果店散卖。
   - 中果：通用性最强，商超和电商都常用。
   - 小果/迷你蕉：适合儿童、便利店、小份量场景。
   佳农不同批次会按果指粗细、长度、单根重量做内部等级，但具体克重区间要以到货批次标签为准。

3. **按成熟度/催熟状态**
   - 青蕉：适合长途运输、商超后熟。
   - 微黄/黄熟：适合即时零售、便利店、水果店快速周转。
   - 即食熟度：适合社区团购、餐饮、烘焙。

**不同渠道的分级建议**
- **商超/大卖场**：优先中果、果形整齐、梳蕉完整、成熟度偏青或微黄，便于门店后熟和陈列；箱规以标准整箱为主。
- **水果店/农贸**：中果和大果均可，重视单根重量和卖相，散装或梳蕉更灵活。
- **便利店/即时零售**：小份量单根或小把装，成熟度偏黄、即食性强，减少损耗。
- **电商/社区团购**：按份量标准化，优先耐运输的微黄蕉，明确单根重量区间和总净重，减少售后。
- **餐饮/烘焙/果汁**：更看重出肉率、成熟度和成本，规格可放宽，常用大果或熟度较高的批次。
- **礼赠/团购**：礼盒装，强调果形均匀、外观无瑕疵和品牌包装。

**可执行判断**
采购时不要只问“有几种规格”，而应要求供应商提供：箱规净重、单根重量区间、每箱条数/把数、成熟度、果指长度粗度、允许瑕疵率、到货温度。以这些字段做验收标准，比记规格名称更可靠。若需要佳农官方当前规格，建议直接查其官网产品页或向区域经销商索取最新产品目录。
