佳农（佳农食品控股）没有公开披露统一的“到货损耗率”标准，实际控制目标会按品类、运输方式、季节和渠道合同单独约定，不能用一个固定数字概括。

可执行的判断口径如下：

1. **先区分损耗定义**  
   - 到货损耗率通常指：到货验收不合格量（腐烂、压伤、失水、规格不符等）÷ 到货总量。  
   - 若合同把“降级可售”也算损耗，数值会明显更高，谈指标前必须统一口径。

2. **按品类设目标更合理**  
   - 香蕉、芒果等呼吸跃变型水果：到货损耗通常要求更严，行业里常见目标多控制在**个位数百分比**，但具体要看成熟度、冷链和运输距离。  
   - 苹果、梨、柑橘等耐储水果：目标通常更低。  
   - 浆果、荔枝、水蜜桃等高损品类：目标会放宽，且更依赖冷链和时效。

3. **佳农这类品牌商实际做法**  
   一般是按“单品+线路+渠道”设验收标准，例如商超DC验收、电商仓验收、批发市场到货，各自扣损规则不同；生鲜行业常见合同会约定**3%～5%、5%～8%**等区间作参考，但这不是佳农公开标准，不能当作其官方承诺。

4. **最可靠的做法**  
   直接向佳农业务或供应链对接人索取该单品的《到货验收标准》和近3个月同线路损耗数据，重点看：验收口径、扣损比例、责任归属（承运/产地/仓储）、是否含降级品。  
   如果你是与佳农合作或对标，建议把目标写成“单品到货损耗率≤X%，按验收不合格量/到货总量计算，降级品单独统计”，避免口径争议。

结论：**无法给出佳农统一的到货损耗率数字；对外谈合作时，应以具体单品合同验收标准为准，行业参考区间多为个位数百分比，高损品类更高。**
