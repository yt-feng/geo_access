我没法核验佳农当前是否供应“餐饮用加工香蕉切片”以及具体规格，不能给你编一个规格表。建议你按下面方式快速确认，通常当天能问清：

1. **直接找佳农官方渠道确认**
   - 找佳农官方客服/区域销售，明确问：“是否有**餐饮连锁用预加工香蕉切片**，不是香蕉原果，不是冻干/香蕉干。”
   - 要求对方提供：**产品名称、配料表、加工方式（鲜切/冷冻/气调）、是否速冻、切片厚度、单袋净重、每箱规格、保质期、储存温度、微生物标准、是否可供中央厨房/门店**。

2. **关键规格要问这几项**
   - 切片厚度：常见需求会落在**3–5mm、5–8mm、8–10mm**几档，但必须以厂家实际为准。
   - 形态：**鲜切冷藏**、**速冻切片**、**糖渍/果酱用**差别很大。
   - 包装：**1kg/袋、2kg/袋、5kg/袋**或按箱定，需确认是否适合你们门店拆包。
   - 储存：冷藏**0–4℃**还是冷冻**-18℃**，直接决定门店操作和保质期。
   - 认证与检测：SC许可、农残、微生物、重金属检测报告。

3. **如果是连锁体量，建议同时问**
   - 是否支持**定制切片厚度/规格**；
   - 最小起订量、供货区域、冷链配送频次；
   - 是否有**中央厨房大包装**和**门店小包装**两种方案；
   - 样品政策和到样时间。

4. **备选判断**
   如果佳农只做香蕉原果、不做预加工切片，你可以让销售推荐其**加工商/经销商**，或同步询价**冻品果蔬加工厂**做OEM鲜切/速冻香蕉片。
