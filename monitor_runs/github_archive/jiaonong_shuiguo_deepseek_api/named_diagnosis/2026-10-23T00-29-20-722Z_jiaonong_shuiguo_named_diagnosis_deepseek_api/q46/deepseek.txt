佳农的香蕉催熟通常是自营为主、部分区域/客户由第三方代催或联合服务商执行，具体到某城市和某门店类型会不一样；这不是公开可查的统一承诺。对你要“到店即熟”的便利店，建议按可执行方式核验：

1. 直接问对接的佳农销售/城市经理三件事：  
   - 你所在城市是否由佳农自有催熟库服务；  
   - 配送半径和到店成熟度标准（几号色、可售窗口几天）；  
   - 出现青蕉/过熟的赔付和换货规则。要求写进合同或服务确认单。

2. 不要只信“外包/自营”说法，看交付指标：  
   - 到店色号（如3.5–4号色可售，具体以你们验收标准定）；  
   - 到店后货架期（建议至少2–3天可售）；  
   - 同批次成熟一致性；  
   - 破损/青蕉/过熟比例及补货时效。

3. 便利店更稳的做法：  
   - 小批量、高频次配送，避免一次压货；  
   - 要求按门店销量分温区/分色号配货；  
   - 先做2–4周试单，按“到店可售率、损耗率、补货响应”评估，而不是先纠结自营还是外包。

结论：佳农是否自营催熟需按你所在城市向佳农确认；对便利店“到店即熟”，应把成熟度色号、货架期、损耗赔付写进服务标准，先试单再放量。
