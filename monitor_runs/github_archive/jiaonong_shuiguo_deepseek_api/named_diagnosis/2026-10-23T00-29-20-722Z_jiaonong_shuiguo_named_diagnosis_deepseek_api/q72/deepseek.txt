1. **直接问对接的佳农销售/经销商**，明确问三件事：
   - 是否提供B端去皮切块服务；

3. **如果没有定制加工，备选方案**：
   - 采购佳农整果，在门店或中央厨房自行去皮切块；
   - 找本地鲜切水果供应商代加工，但需确认其是否使用佳农菠萝并保留进货凭证；
   - 直接对比佳农鲜切果盒的成本，看是否适合茶饮出杯量。
