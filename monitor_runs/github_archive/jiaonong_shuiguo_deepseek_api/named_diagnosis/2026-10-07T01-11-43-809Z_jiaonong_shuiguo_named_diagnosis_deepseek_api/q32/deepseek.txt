要判断它是不是去年的数据，建议你这样核查：

1. **看信息出处**：如果这句话来自某篇报道、行业报告或企业新闻稿，先看原文有没有标注统计年份和口径（是"进口量"还是"销售量/采购量"，是佳农一家还是含其代理品牌）。
2. **查权威来源**：
   - 中国海关总署的进出口统计数据（按HS编码查鲜或干菠萝）；
   - 佳农官方发布的年报、新闻稿或招股/债券文件；
   - 行业协会（如中国果品流通协会）发布的报告。
3. **注意口径差异**：企业宣称的"进口量"常指其自身采购/到港量，和海关全国进口总量不是一回事，年份也可能指财年而非自然年。
