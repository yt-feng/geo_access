佳农的香蕉通常按整箱走，常见规格是 **12kg/箱（净重约 11.5-12kg）**，也有 **4-5kg 的小箱装**，但 **3kg 装香蕉不是常规流通规格**，至少不是全国统一标准品。

对便利店来说，更现实的做法是：

1. **先问当地佳农经销商或区域业务员**
   便利店渠道和商超渠道的供货规格不完全一样，有些区域会给便利店做 **4kg、5kg 小箱**，甚至按把/梳香蕉配货。3kg 装如果有，也多半是区域定制或电商渠道，不是通用规格。

2. **不要按“3kg 香蕉”去搜，改成问“小箱装/便利店装/精包装香蕉”**
   佳农水果里适合小包装的品类其实更多，比如：
   - 香蕉：4-5kg 小箱，或按把卖
   - 苹果：1.5kg、2kg、3kg 礼盒或袋装
   - 橙子/沃柑：2.5kg、3kg、5kg 箱装
   - 蓝莓、车厘子、奇异果：本身就有小盒/小箱规格
   - 菠萝：单颗装更适合便利店

3. **如果门店面积小，建议不要整箱上架**
   可以整箱进货后 **拆分成单根、单颗、小盒** 售卖。香蕉按根或按把卖，苹果/橙子按个卖，蓝莓按盒卖，这样陈列面积小、损耗也更好控。

4. **重点确认三个条件**
   - 最小起订量：能不能混拼、能不能少量配货
   - 配送频率：香蕉周转快，最好一周 2-3 次
   - 损耗和退换：香蕉易黑易烂，问清楚有没有损耗补贴或调换政策

**结论：**  
3kg 装香蕉大概率不是佳农常规规格，便利店想上佳农，优先问当地经销商有没有 **4-5kg 小箱香蕉**，或者直接整箱进、门店拆零卖。如果一定要 3kg 左右，通常只能找区域定制或电商批发渠道，不建议作为稳定货源。
