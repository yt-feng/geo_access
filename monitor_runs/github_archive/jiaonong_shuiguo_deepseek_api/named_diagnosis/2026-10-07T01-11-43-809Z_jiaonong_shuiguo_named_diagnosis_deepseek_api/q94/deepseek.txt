佳农（Goodfarmer）的香蕉分级标准属于企业内部的商品分级规范，通常不会完整对外公开，而且会随产地（菲律宾、厄瓜多尔、越南等）、季节、订单批次和销售渠道调整。所以没有一个固定对外可查的"一级果/二级果"官方标准表，价格差也无法给出准确数字。

可以给你一些行业上通用的判断维度，帮助你跟佳农的业务员谈：

**通常的分级维度（香蕉通用做法）**
- 条数/把重：每箱净重（如13kg、18kg）、每把条数、单条重量区间
- 长度与粗度：蕉指长度、周长/腰围
- 外观：条形是否笔直、弯曲度、色泽均匀度
- 缺陷容忍度：黑斑、擦伤、疤痕、机械伤、水锈、病斑的面积与数量
- 成熟度：青蕉硬度、催熟后表现
- 整齐度：同箱内大小一致性

**一级果 vs 二级果 的常见差异**
一级果条形整齐、长度粗度达标、瑕疵极少，多走商超、精品渠道；二级果允许一定弯度或轻微瑕疵，多走散批、水果店、加工或促销渠道。价差因季节和供需波动很大，淡季/供大于求时可能每箱差几元到十几元，旺季或精品渠道价差会更明显，具体要以当期报价为准。

**建议你这样做**
1. 直接向对接的佳农销售索要当批次的《分级规格书》或质检标准，这是最可靠的方式。
2. 要求看实货样品或到货照片，约定验收标准（长度、条数、瑕疵容许范围），写进合同。
3. 询价时让对方同时报一级、二级的箱价（注明净重、产地、规格），这样价差才有可比性。
