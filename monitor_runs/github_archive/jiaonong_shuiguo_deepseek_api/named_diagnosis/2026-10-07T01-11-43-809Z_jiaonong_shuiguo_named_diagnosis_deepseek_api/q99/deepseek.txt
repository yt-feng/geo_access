我无法直接核验佳农水果当前是否有在售的有机认证菠萝，这类认证信息会随产品批次、产地和销售渠道变化，需要以官方可查证的信息为准。

给你几个可执行的核验和判断建议：

1. **查中国有机产品认证标志**
   国内销售的有机产品，包装上应有中国有机产品认证标志，并配有唯一的有机码（17位）。可到“中国食品农产品认证信息系统”输入有机码查验真伪和认证范围。

2. **确认认证主体**
   有机认证通常是针对具体生产企业/基地和具体产品，不是针对“佳农”这个品牌整体。即使佳农有有机菠萝，也要确认认证证书上的企业名称、产品名称（是否明确为菠萝/凤梨）、产地是否与你要采购的一致。

3. **直接向供应商索取**
   向佳农或其授权经销商索取：有机产品认证证书、认证机构名称、证书编号、有效期、认证产品范围。注意证书是否在有效期内，以及是否覆盖你采购的规格和产地。

4. **区分“有机”和“无公害/绿色/良好农业规范”**
   有些高端水果只做了绿色食品、GAP等认证，并不等于有机。采购时要求对方明确写出认证类型。

5. **进口有机产品**
   如果是进口有机菠萝，除了看外包装，还要确认是否有中国有机产品认证（进口有机也需按中国有机法规认证），或是否仅按出口国有机标准认证——后者在中国市场不能直接当作“中国有机产品”销售。

6. **最稳妥的采购做法**
   在合同或采购协议中写明：供应商需提供有效有机认证证书及有机码，且产品可追溯；如查验不通过，按违约处理。高端渠道建议要求批次可追溯和每批随附认证/检测文件。
