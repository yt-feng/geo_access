佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个固定答案。常见情况如下：

**1. 京东/天猫等电商平台（佳农官方旗舰店）**
- 一般走快递发货，非预售商品通常 48 小时内出库。
- 到货时间看快递：一线/江浙沪等地区常见 1–3 天；偏远地区 3–7 天甚至更久。
- 生鲜类部分商品会标“次日达”或“隔日达”，但仅限特定城市和仓配范围。

**2. 商超/生鲜平台（如美团、饿了么、京东到家、盒马等）**
- 如果你所在城市有佳农合作门店或前置仓，通常 30 分钟–2 小时送达。
- 这类时效取决于门店覆盖，不是所有地区都有。

**3. 社区团购/预售**
- 多为“次日自提”或 1–3 天到自提点，按团购规则走。

**判断你实际能多久到的办法：**
- 看商品详情页的“发货时效”和“预计送达”字样；
- 下单前在结算页填地址，系统会显示预计到达时间；
- 问客服确认发货仓和快递公司。

**提醒：** 水果是生鲜，节假日、恶劣天气、疫情等会影响时效；如果页面没写“次日达”，就不要默认很快到。
