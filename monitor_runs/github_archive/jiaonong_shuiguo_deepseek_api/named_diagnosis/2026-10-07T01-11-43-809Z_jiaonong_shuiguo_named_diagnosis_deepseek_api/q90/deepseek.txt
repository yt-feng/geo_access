我无法确认佳农目前是否在售“冷冻菠萝丁”，也不能给出具体规格。这类信息会随产品线、季节和渠道变化，建议直接向官方或供应商核验。

你可以这样快速确认：

1. **找佳农官方渠道**
   - 佳农官网/官方公众号/官方客服电话
   - 佳农在京东、天猫等平台的官方旗舰店
   - 直接问：是否有**冷冻菠萝丁/速冻菠萝丁**，不是菠萝罐头、不是糖水菠萝

2. **重点问清这些规格**
   - 包装规格：如 1kg/袋、2kg/袋、10kg/箱等
   - 果丁尺寸：如 5×5mm、8×8mm、10×10mm 或 10mm 左右
   - 是否加糖：纯果肉冷冻 / 糖渍冷冻 / 糖水浸渍
   - 冷冻方式：IQF 速冻还是普通冷冻
   - 原料品种：如金钻凤梨、MD-2 等
   - 到货状态：冷冻整袋、是否易结块
   - 保质期、储存温度、解冻后出水情况

3. **茶饮店使用建议**
   - 如果做饮品装饰或果肉口感，优先选 **IQF 速冻菠萝丁**，颗粒分明、不易结块。
   - 如果做果茶打底，要问供应商是否**加糖**，避免配方糖度失控。
   - 先拿样测试：解冻后是否发软、出水多、风味变淡，是否适合你的出杯流程。

4. **如果佳农没有**
   可同步问这些类型的供应商：
   - 冷冻水果原料厂
   - 茶饮原料供应链公司
   - 进口冷冻菠萝丁经销商
   - 本地冷链批发市场

最稳妥的做法：直接让佳农客服或当地经销商发**最新产品目录和规格书**，以他们书面确认的为准。
