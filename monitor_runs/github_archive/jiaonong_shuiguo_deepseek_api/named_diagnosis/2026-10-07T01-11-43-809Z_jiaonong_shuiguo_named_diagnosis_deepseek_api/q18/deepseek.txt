佳农香蕉属于生鲜香蕉，包装上通常不会标一个固定“保质期”，而是给“最佳食用期/成熟度”参考。实际能放多久，主要看买到时是青香蕉还是已经发黄的香蕉。

**一般参考**
- **青香蕉**：室温下通常 3～7 天逐渐变黄。
- **已发黄但没黑斑**：室温下约 2～4 天口感较好。
- **出现芝麻黑斑**：通常 1～2 天内最甜，之后容易过熟。
- **冷藏后**：果肉可能还能放几天，但香蕉皮会很快变黑，不代表一定坏，主要看果肉。

**储存建议**
1. **未熟青香蕉**
   - 放在室温、阴凉通风处。
   - 不要放冰箱，低温会打断后熟，导致变黑、口感差。
   - 想催熟，可和苹果或熟香蕉一起放进纸袋里。

2. **已经成熟发黄**
   - 尽快吃。
   - 想延缓过熟，可放冰箱冷藏，但皮会变黑，果肉仍可食用。
   - 也可剥皮后冷冻，用于打奶昔、做香蕉泥。

3. **不要做的事**
   - 不要密封在塑料袋里，容易闷坏、发霉。
   - 不要洗后存放，表面有水容易腐烂。
   - 不要和已经腐烂的水果放一起，会加速变质。

**判断是否还能吃**
- 可以吃：表皮发黑但果肉正常、气味正常。
- 不建议吃：果肉发酸、发黏、渗水、有酒味或霉点，或整根软烂腐烂。

简单说：**青香蕉室温催熟，黄香蕉尽快吃，吃不完冷藏或冷冻；香蕉怕闷、怕水、怕冻太早。**
