我没有可核验的“佳农水果香蕉”专项抽检合格率数据，不能直接给你一个具体百分比或“合格/不合格”结论。

能确定的是：

1. **“佳农”香蕉整体上属于正规品牌水果**
   佳农是国内较大的水果供应链企业之一，香蕉是其核心品类之一，通常有相对稳定的产地、催熟、仓储和品控流程。正规商超、电商平台销售的佳农香蕉，一般会经过进货查验和平台抽检。

2. **但“品牌合格率”不是公开固定指标**
   市场监管部门抽检通常按地区、批次、项目公布，例如某地某批次香蕉的吡虫啉、噻虫嗪、腈苯唑等农药残留是否合格。它不会长期公布一个“佳农香蕉抽检合格率”。

3. **香蕉抽检常见风险点**
   主要是农药残留，尤其是：
   - 吡虫啉
   - 噻虫嗪
   - 腈苯唑
   - 多菌灵等
   这类问题更多和具体批次、产地、季节、储运有关，不能简单等同于某个品牌所有产品。

4. **如果你要判断具体一批佳农香蕉是否可靠**
   可以看：
   - 包装上的批次号、产地、供应商
   - 商超或平台是否有当批检测报告
   - 当地市场监管局官网/公众号的食品安全抽检通告
   - 是否有“食用农产品承诺达标合格证”

5. **实际建议**
   如果你只是日常购买，佳农香蕉在正规渠道购买，总体风险通常低于无来源散装香蕉；但如果用于采购、招标、给孩子吃等要求较高的场景，最好向销售方索要**该批次检测报告或合格证明**，而不是只看品牌。
