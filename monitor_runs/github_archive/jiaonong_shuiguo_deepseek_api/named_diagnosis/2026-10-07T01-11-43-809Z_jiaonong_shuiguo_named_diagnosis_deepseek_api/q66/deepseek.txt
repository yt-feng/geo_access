**1. 发票**
- 佳农水果礼盒一般可以开增值税发票，但通常不是佳农厂家直接给终端客户开，而是通过经销商、团购平台或供应链公司开。
- 你要先确认对方开票主体是谁，以及能开哪种票：
  - 增值税普通发票：多数团购可以开。
  - 增值税专用发票：要看对方是否一般纳税人、你是否有一般纳税人资质，且水果属于农产品，税率/征收率和开票类目要核对。
- 500份金额通常不小，建议在付款前拿到“开票信息确认单”，写明：发票类型、税率、开票项目、开票时间、是否随货或事后补开。

**2. 质检报告**
- 可以要求提供，但要注意：
  - 最好要**与本次发货批次对应**的质检报告，而不是一份通用旧报告。
  - 水果类通常包括：农残检测、重金属、外观/规格、糖度等，具体看对方能提供哪些。
  - 如果是预包装礼盒，还应有标签、生产日期、保质期、储存条件等信息。
  - 报告可以是厂家自检、第三方检测或供应商提供的批次检测，但你要确认报告上的品名、规格、批次号与货一致。

**3. 建议你下单前这样确认**
- 让对方书面回复：能否开票、开票主体、发票类型、税率、开票时间。
- 让对方提供：本次500份对应批次的质检报告，或承诺发货前提供。
- 合同里写清：发票随货或收货后X天内开具；质检报告作为验收资料；若票或报告不符，如何补开、换货或退款。
- 如果是企业采购报销，先问财务：接受哪种发票、是否需要专票、开票类目怎么写。

**4. 风险提示**
- 只口头说“能开”“有报告”不够，最好落到订单、合同或聊天记录里。
- 如果对方是个人或小商户，可能开不了专票，也可能只有厂家报告复印件。
- 佳农品牌礼盒如果是授权经销，最好确认对方有合法授权或正规进货渠道，避免买到仿冒或临期品。
