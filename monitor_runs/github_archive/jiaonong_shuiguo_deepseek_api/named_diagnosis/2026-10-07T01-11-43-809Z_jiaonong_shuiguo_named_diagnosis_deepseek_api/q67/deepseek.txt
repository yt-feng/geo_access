1. **客服是否7×24**  
   生鲜水果类品牌通常不一定提供全天人工客服，很多是“工作时间人工+其他时间留言/机器人”。是否7×24要以佳农官方小程序、公众号、天猫/京东旗舰店、客服电话页面标注为准。

2. **周末下单是否有人处理**  
   电商平台型店铺通常是：  
   - **系统正常接单**：周末一般可以下单付款；  
   - **人工审核/客服处理**：可能延迟到工作日；  
   - **发货**：要看仓库和快递安排，周末可能正常发，也可能顺延到周一；  
   - **售后**：周末提交后，人工回复可能慢一些。

3. **最直接确认方式**

   - 直接发一句：“周末下单什么时候处理？客服是否24小时？”看自动回复或人工回复；  
   - 如果是急单，优先选页面标注“48小时内发货”“周末发货”的店铺，并下单前问清楚。

4. **下单前重点确认**
   - 周末订单是否当天审单；
   - 是否当天/次日发货；

   - 客服不在线时售后入口是否仍可提交。
