目前公开可查的信息里，佳农（Goodfarmer）主打的是商超零售和批发流通渠道的鲜果供应，并没有一个被广泛宣传、专门命名为"餐饮渠道菠萝解决方案"的标准化产品包。

不过从它实际的产品线和业务模式看，餐饮渠道大概率是能对接的，主要是这几块：

**1. 鲜菠萝/凤梨的规格化供应**
佳农有菲律宾、哥斯达黎加等产地的菠萝/凤梨，包括金菠萝、MD2等品种。餐饮客户通常需要的是稳定的规格（比如固定单果重量、成熟度一致、去皮或带皮），这类批量分级供货它是有能力做的，关键是要跟销售直接谈定制规格。

**2. 冷冻/加工类菠萝产品**
如果是饮品店、烘焙或连锁餐饮，可能更需要冷冻菠萝丁、菠萝块、菠萝果酱或浓缩汁。这类产品佳农体系内有涉及，但具体到某个SKU是否对餐饮开放、起订量多少，需要向官方确认。

**3. 定制化服务**
连锁餐饮常见的做法是找供应商做"锁规格、锁产地、锁成熟度"的长期供货协议，甚至贴牌。佳农作为大型果蔬供应商，接这类B端定制是常规操作。

**建议你这样落地：**

- 直接联系佳农官方（官网或客服），说明你是餐饮/连锁渠道，问是否有B端事业部或餐饮专线。
- 明确告诉对方你的需求：品种、规格、去皮与否、冷冻还是鲜果、月用量、配送区域、是否要贴牌。
- 要样品做实际测试（出汁率、甜度、稳定性），别只看目录。
- 如果佳农餐饮线不成熟，可以同时对比：都乐（Dole）、鑫荣懋、以及本地水果加工厂，后者在定制和价格上往往更灵活。
