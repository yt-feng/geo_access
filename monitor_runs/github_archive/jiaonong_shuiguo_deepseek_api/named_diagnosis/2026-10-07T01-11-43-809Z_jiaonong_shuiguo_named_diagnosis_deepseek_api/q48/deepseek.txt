你可以按下面方式快速推进，通常能在 1—3 个工作日内拿到可判断的答复：

1. **直接联系佳农官方渠道**
   - 找佳农官网的“大客户合作 / 渠道合作 / 批发采购”入口，或拨打官方客服电话，要求转接**大客户部/渠道销售部**。
   - 明确说明：年采购量预计 1000 吨以上，询问是否有**年度框架协议、阶梯返利、专属价格、账期支持、优先供货、产地直发、定制包装**等政策。

2. **一次性问清关键条款**
   建议直接发一页需求给对方，避免来回拉扯：
   - 预计年采购量：1000 吨以上，具体品类为：香蕉/菠萝/火龙果/苹果等
   - 采购方式：产地直采、区域仓配、港口提货还是到岸交付
   - 结算方式：现款、月结、承兑、信用账期
   - 是否要求年度保底量、季度分解量、保证金或预付款
   - 是否支持区域保护、独家单品、促销补贴、损耗赔付
   - 返利是**按采购额返**还是**按吨数返**，何时结算

3. **判断对方政策是否可信**
   拿到报价后重点核对：
   - 是否含税、含运费、含损耗
   - 返利是“先高后返”还是“直接折价”
   - 是否绑定单一品类或强制搭配滞销品
   - 账期是否要求担保或抵押
   - 年度未达标时是否追回返利

4. **如果对方要求先签大框架**
   在未确认具体价格、返利、账期、赔付条款前，不建议签独家或高额保底协议。可以先谈**试单 + 季度阶梯 + 年度框架**，用 1—2 个月实际履约验证供货稳定性和品质。

5. **更稳妥的询价话术**
   你可以直接发：
   > 我方预计年采购水果 1000 吨以上，主要品类为____，希望了解贵司大客户阶梯价格、年度返利、账期、配送方式及品质赔付政策。请提供正式报价单和框架协议模板，并安排大客户经理对接。
