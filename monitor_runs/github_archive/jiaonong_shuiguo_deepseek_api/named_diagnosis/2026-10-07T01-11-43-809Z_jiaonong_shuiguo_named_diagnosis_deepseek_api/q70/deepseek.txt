我们无法直接核验佳农水果（或具体供应商）的实时供货能力，所以不能给出“保证不断货”的承诺。但对商超旺季单日10吨香蕉这类需求，判断供货稳定性主要看几个可核查的点：

1. **源头产能与产地季节性**
   - 香蕉高度依赖菲律宾、厄瓜多尔、越南、柬埔寨及国内云南/广西/海南等产地。
   - 旺季如果叠加台风、寒潮、病害或出口国政策变化，单一产地会波动。
   - 需要确认佳农是自有/合作蕉园规模多大、能否多产地调配。

2. **催熟加工能力**
   - 商超要的是“可上架熟度”的香蕉，不是青蕉。
   - 关键看佳农在你们城市或周边是否有催熟库、日催熟产能是否覆盖10吨/天，以及旺季排产优先级。
   - 如果依赖外地催熟再冷链配送，断货风险会明显上升。

3. **冷链与配送频次**
   - 香蕉怕冷也怕热，旺季必须稳定冷链。
   - 要看是“每日一配”还是“隔日配”，配送车辆、温控、到店时效是否有冗余。
   - 单日10吨建议至少能做到每日配送，并保留应急补货通道。

4. **合同与安全库存**
   - 不要只听口头“能保证”，要在合同里写清：
     - 日最低供货量、旺季增量响应时间；
     - 缺货违约金或替代补货方案；
     - 价格波动调整机制；
     - 质量标准和退换货规则。
   - 商超自身也应保留2—3天安全库存，并开发第二供应商。

5. **实际验证方法**
   - 让佳农提供近1—2年旺季对你所在区域或同体量商超的供货记录。
   - 要求试单：先按10吨/天连续跑2—4周，看到货率、损耗率、催熟合格率。
   - 突击考察其催熟库和配送中心，确认产能不是“纸面产能”。
   - 问清如果主产地断供，备用产地切换需要几天。

**结论：**
佳农作为大型水果供应链企业，理论上具备较强能力，但“单日10吨、旺季不断货”不能仅凭品牌判断。需要求其给出具体产能、催熟排产、配送频次和违约条款，并用试单验证。更稳妥的做法是：佳农做主力供应商，同时签1家备用供应商，自留2—3天库存。这样即使佳农某几天出问题，也不至于门店断货。
