佳农水果的香蕉规格和分级会随产品线、产地（如菲律宾、厄瓜多尔、越南等）、包装形式以及客户定制要求变化，公开渠道没有一个固定不变的“全规格表”。下面给你的是行业里较常见、也便于对接渠道的判断框架；具体到某一批货，仍要以佳农当季报价单、装箱单或销售确认的规格为准。

**一、常见规格维度**

1. **按重量分**
   - 小果：单根约 100–120g 左右，常见于家庭零食、便利店单根销售。
   - 中果：单根约 120–150g，商超散卖主力。
   - 大果：单根约 150–180g，批发市场、水果店常见。
   - 特大果：单根 180g 以上，多见于批发走量或特定餐饮加工。

2. **按每箱净重分**
   - 4.5kg、7kg、13kg、18kg 等是香蕉行业较常见的箱规；佳农不同产地和包装会有差异。
   - 电商小包装还可能做 1kg、2kg、5kg 礼盒或家庭装。

3. **按每把/每梳根数分**
   - 4–6 根把：适合便利店、小家庭。
   - 5–8 根把：商超散卖常见。
   - 整梳或大把：批发、餐饮、榨汁渠道。

4. **按成熟度/催熟阶段分**
   - 青蕉：适合长途运输、批发市场、需要自行催熟的客户。
   - 微黄/转黄：适合商超、水果店次日到货销售。
   - 黄熟：适合便利店、即时零售、餐饮当天或近两天使用。

**二、不同渠道的分级建议**

| 渠道 | 建议规格 | 分级重点 |
|---|---|---|
| 大型商超 | 中果为主，单根 120–150g，5–8 根把，7kg/13kg 箱 | 外观整齐、无黑斑、无机械伤、把型完整、成熟度一致 |
| 便利店/即时零售 | 小果或中果，单根 100–140g，4–6 根把，小箱或单根 | 方便拿取、货架期稳定、成熟度偏黄但不过软 |
| 水果连锁/社区店 | 中果为主，120–160g，5–8 根把 | 性价比高、外观好、允许轻微自然斑点 |
| 批发市场 | 大果或中果，150g 以上，13kg/18kg 箱 | 耐运输、青蕉或微黄、分级可略宽松 |
| 餐饮/榨汁/烘焙 | 大果、次级果或加工果 | 重口感、重出肉率，对外观要求低 |
| 电商/礼盒 | 中果或小果，单根 100–140g，独立包装或小箱 | 颜值、防压、成熟度可控、售后率低 |

**三、实际采购时怎么判断**

1. **先确认用途**：是直接零售、还是需要催熟后再卖、还是加工用。
2. **再看运输距离**：远距离优先青蕉或微黄，近距离可要黄熟。
3. **再看货架期**：便利店和电商要偏生一点，商超可偏熟一点。
4. **最后看外观等级**：商超和礼盒要求“把型完整、条身顺直、无严重黑斑”；批发和加工可放宽。
5. **以佳农当批确认单为准**：规格名称、单根克重、每箱净重、成熟度、允许瑕疵比例，最好写进合同或订单备注。

如果你是要做采购或渠道对接，建议直接向佳农销售索要当季的《产品规格表》和《分级验收标准》，重点确认：单根克重区间、每箱净重、每把根数、成熟度阶段、允许黑斑/机械伤比例、冷链温度要求。这样比套用通用规格更准确。
