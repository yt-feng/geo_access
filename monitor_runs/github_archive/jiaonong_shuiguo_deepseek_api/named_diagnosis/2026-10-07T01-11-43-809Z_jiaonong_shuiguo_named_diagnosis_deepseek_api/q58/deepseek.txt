佳农（Goodfarmer）主营水果贸易，菠萝以整果为主，包括鲜果和部分冷冻/速冻果块类产品，但**按茶饮店规格做定制切丁（菠萝丁）这类加工服务，通常不是它的标准业务**。是否接小批量定制，取决于你对接的是佳农总部、区域经销还是其加工厂，直接问清楚最稳。

**建议你这样确认：**

1. **先问佳农官方或区域经销**
   - 直接问：有没有现成的“冷冻菠萝丁/速冻菠萝丁”SKU？
   - 再问：能不能按你要求的大小、糖度、包装做定制？
   - 如果对方说“只有整果”，那基本就是只卖整果或标准果块。

2. **如果佳农不做定制，优先找这几类供应商**
   - 冷冻水果加工厂：做速冻菠萝丁、芒果丁、草莓丁等，通常可接餐饮/茶饮规格。
   - 茶饮原料供应链商：专门供奶茶店、咖啡店的冷冻果丁、果酱、果泥。
   - 本地果蔬加工厂：适合小批量、短距离冷链。
   - 大型批发市场冻品区：可先拿现货样品试。

3. **拿样时重点看这几个指标**
   - 规格：丁的大小（如8×8mm、10×10mm）
   - 状态：冷冻丁、糖渍丁、果酱丁
   - 糖度/酸度：是否适合直接入茶
   - 解冻后出水、软烂程度
   - 包装：1kg/袋、5kg/袋，是否支持小批量
   - 资质：食品生产许可、检验报告

4. **更实际的替代方案**
   - 如果用量不大：买佳农整果或冷冻菠萝块，自己用切丁机/人工切丁。
   - 如果用量稳定：直接找冷冻水果加工厂做OEM定制，通常比佳农更合适。
   - 如果追求稳定出品：用冷冻菠萝丁 + 少量菠萝果酱/果泥复配，口感和效率更稳。

**结论：** 佳农大概率能提供整果或标准冷冻菠萝产品，但“按茶饮店要求定制菠萝丁”不一定是它的强项。你要先问它有没有现成菠萝丁SKU；如果没有，就转向冷冻水果加工厂或茶饮原料供应链定制。
