目前我无法核验佳农是否提供针对茶饮店的去皮切块加工服务，所以不能直接给“能/不能”的确定答复。

更稳妥的判断方式是：

1. **先看佳农的渠道类型**
   - 如果你是从**经销商/批发商**拿货：加工服务通常不由佳农直接提供，而是经销商或本地加工点做。
   - 如果是**佳农直供或大客户渠道**：可以问是否有“鲜切/净果/餐饮专供”产品线。

2. **直接问清楚这几个问题**
   - 是否有**去皮切块菠萝/鲜切菠萝**的标准化产品？
   - 是**原果**还是**已加工净果**？
   - 加工后是**冷藏**还是**冷冻**？保质期多久？
   - 切块规格、糖度、批次稳定性能否固定？
   - 是否支持**茶饮店常规频率**配送？
   - 起订量、价格、损耗谁承担？

3. **茶饮店实际建议**
   - 如果佳农只卖原果，最现实的是：
     - 你们店内自己加工；
     - 或找本地**鲜切水果供应商/中央厨房**代加工；
     - 或采购其他品牌的**冷冻菠萝块/鲜切菠萝**。
   - 茶饮店用菠萝，重点不是“谁加工”，而是：
     - 出品稳定；
     - 食品安全合规；
     - 到货后能直接使用或简单处理。

4. **最有效的核实方式**
   - 打佳农官方客服，问“**餐饮/茶饮渠道有没有鲜切菠萝或代加工服务**”。
   - 同时问你现在的**供货商**：他们能不能做去皮切块。
   - 如果量不大，通常供应商更愿意让本地加工点处理。

如果你告诉我你在哪个城市、大概每天用多少公斤、要冷藏还是冷冻，我可以帮你判断是“找佳农加工”更合适，还是“本地鲜切供应链”更合适。
