## 2. 超市抽检要过的核心，不是"历史清白证明"

超市/监管抽检（如市场监管总局、地方市监局）判定依据是**当批次检测报告 + 国标限量**，不是品牌历史。你要准备的是：

1. **当批次出厂检验报告 / COA**（第三方或供应商自检）
2. **农药残留检测报告**，检测项目覆盖 GB 2763《食品中农药最大残留限量》中香蕉对应项
3. **入境货物检验检疫证明**（进口香蕉必备）
4. **供货商资质**：营业执照、食品经营许可证
5. **进货台账 / 索证索票**（这是超市和监管查的重点）

## 3. 关键：检测项目要盯对

香蕉常被抽检的农残项目包括（以 GB 2763 现行版为准）：
- 吡虫啉、噻虫嗪、噻虫胺
- 苯醚甲环唑、丙环唑、戊唑醇
- 多菌灵、百菌清
- 毒死蜱、甲拌磷等禁限用农药

**建议**：直接要求供应商提供**近期（3个月内）覆盖上述项目的第三方检测报告**，并注明检测方法（如 GB 23200 系列、NY/T 761 等）。
