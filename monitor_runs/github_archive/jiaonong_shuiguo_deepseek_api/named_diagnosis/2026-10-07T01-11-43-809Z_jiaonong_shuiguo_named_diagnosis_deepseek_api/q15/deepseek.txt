佳农（Goodfarmer）是国内较大的水果进口与分销企业之一，但“产地直供比例”属于公司具体经营数据，公开渠道通常没有持续、精确披露。**能确认的是：佳农以进口水果见长，香蕉是其核心单品之一，供应链模式偏向“海外产区合作/自有加工+国内分销”，但这不等于全部都是严格意义上的产地直供。** 如果要判断某批货是否产地直供，更可靠的是看包装、报关单、品牌溯源信息或直接问经销商。

香蕉方面，佳农的香蕉主要来自以下几类国家：

1. **菲律宾**  
   这是中国进口香蕉的传统主要来源国之一，也是佳农较早、较重要的香蕉供应地。

2. **厄瓜多尔**  
   全球重要香蕉出口国，佳农也有从厄瓜多尔采购或合作供应。

3. **越南**  
   近年对中国香蕉出口增长明显，地理近、物流快，也是常见来源。

4. **柬埔寨**  
   也是中国进口香蕉的来源之一，但量级通常不如菲律宾、越南突出。

5. **老挝、缅甸等东南亚国家**  
   部分时段和渠道也会进入中国市场，但更多属于区域性、季节性补充。

如果简单概括：  
**佳农香蕉不是只来自一个国家，主要看产季、价格、检疫和订单，常见来源包括菲律宾、厄瓜多尔、越南，柬埔寨等东南亚国家也会出现。**  
至于“产地直供比例高不高”，不能一概而论；它更像是“海外直采+产区合作+国内分销”的混合模式，比例会随年份和品类变化。
