关于佳农水果的堆头陈列和试吃支持，我无法直接确认他们当前的具体政策——这属于厂商与商超之间的渠道合作协议，各区域、各经销商、各时段的政策都可能不同。

但可以给你一个可执行的判断框架和谈判要点：

**一、先确认你对接的是谁**
- 佳农总部直营：通常只对大卖场/连锁总部谈年度框架
- 区域经销商/代理商：地方商超多数是和他们签，堆头、试吃、费用都好谈
- 先问清楚对方是哪种身份，政策权限差别很大。

**二、堆头陈列支持，常见合作形式**
1. 厂商提供堆头物料（堆头围挡、价签、POP、地贴）
2. 厂商付费买堆头位置（陈列费/地堆费）
3. 商超出位置、厂商出赠品或搭赠冲销量
4. 按进货量给陈列补贴（达到约定陈列面/时长返费用）

**三、试吃支持，常见分担方式**
- 试吃果品：通常厂商承担（用促销装/滞销品做试吃）
- 试吃人工：厂商派促销员，或商超出人、厂商给补贴
- 试吃台、一次性餐具、手套：多数厂商出
- 场地和档期：商超提供，通常不额外收费，但要换销量承诺

**四、费用分担的常见比例（供参考，非佳农官方）**
- 厂商全包：多见于新品推广、厂商冲业绩时
- 商超出场地、厂商出人出物料：最常见
- 双方按比例分摊：商超承担部分陈列费，厂商承担奖品和人工
- 纯买断陈列：商超收固定陈列费，其他厂商自理

**五、你可以直接用的谈判话术**
> “我们计划X月X日到X日做佳农专场，能给到一个端头/地堆位置，预计日均客流X。想确认三点：堆头物料你们能不能出？试吃果品和促销员怎么安排？陈列费和试吃费用大家怎么分？”

**六、落地前一定要写进协议的**
- 堆头位置、尺寸、陈列时长
- 物料由谁提供、何时到位
- 试吃果品数量、损耗谁承担
- 促销员归属、工时、是否需商超培训
- 费用金额、结算方式、核销凭证（照片/销量数据）

建议你直接联系负责你们门店的佳农业务或经销商，把上面几个问题一次性问清楚，比猜测政策更靠谱。如果你告诉我所在城市、门店类型（大卖场/社区超市）和对接的是总部还是经销商，我可以帮你把谈判清单再细化。
