佳农水果（佳农食品控股）并未公开披露统一的“到货损耗率”官方指标，因此无法给出一个可核验的确切数字。行业里这个指标通常按**品类、运输方式、季节和验收口径**差异很大：

- **冷链条件较好的品类**（如香蕉、部分进口提子、蓝莓等）：到货损耗常见控制在 **1%–3%** 左右。
- **普通冷链或周转较慢的品类**（如苹果、梨、柑橘）：常见在 **3%–5%**。
- **易损品类**（如浆果、荔枝、水蜜桃、部分热带水果）：可能到 **5%–10%**，旺季或长途运输时更高。

如果你需要佳农的具体数据，建议直接看：
1. **合同或采购协议中的验收标准**（通常写明了允许损耗率）；
2. **到货验收单/质检报告**里的实际扣重比例；
3. 直接问佳农的区域销售或供应链对接人，按你采购的**单品和线路**要历史损耗数据。
