## 怎么判断农残是否合格

1. **看批次检测报告**
   - 佳农（Goodfarmer）作为大型果蔬进口商，一般会做批次农残自检或委托第三方检测。
   - 最可靠的做法：向销售方（超市、生鲜平台、佳农官方客服）索取**该批次的检测报告**，重点看检测项目是否覆盖 GB 2763《食品安全国家标准 食品中农药最大残留限量》里的香蕉相关农残指标。

2. **查监管抽检公告**
   - 国家市场监管总局、各省市市场监管局会定期发布食品安全监督抽检通告，可搜"香蕉 农残 抽检 + 地区/年份"，看是否涉及佳农或相关批次。
   - 这类官方通告才是权威结论来源。

3. **看进口来源**
   - 佳农香蕉多为进口（菲律宾、厄瓜多尔、越南等），正规进口会经过海关检验检疫，有入境货物检验检疫证明。

## 常见的相关认证

大型果蔬企业通常涉及以下几类，但**具体到佳农持有哪些、有效期到何时，需要以其官方公示为准**：

- **GlobalG.A.P.（全球良好农业规范）**：种植端常见认证，与农残管理相关。
- **ISO 22000 / HACCP**：食品安全管理体系认证。
- **绿色食品 / 有机认证**：如果某产品线主打这类卖点，会有对应证书。
- **BRCGS**：部分供应链会做，偏加工/流通环节。

## 实操建议

- 如果你手上有具体批次（包装上的批次号、日期、产地），可以拿这个去问卖家要检测报告。
- 想要权威结论，优先查**市场监管部门抽检公告**，而不是只看商家宣传。
- 对"是否有认证"这类问题，认准**证书编号 + 发证机构 + 有效期**，光看包装上印的logo不够。
