佳农水果的售后整体评价是：**大平台/官方旗舰店购买通常有明确理赔规则，但需要按流程留证、及时申请**；如果是第三方小店或社区团购，售后体验差别会很大。

**到货有坏果，一般这样处理：**

1. **先别急着扔**
   把坏果、外包装、快递面单放在一起拍照或拍视频，最好能看出坏果数量和整体到货情况。

2. **尽快联系购买渠道客服**
   在订单页面找“申请售后/退款/理赔”，或直接联系店铺客服。说明“收到坏果，申请按比例赔付或补发”。

3. **按坏果比例申请赔付**
   生鲜类常见规则不是坏一个赔整单，而是：
   - 坏果较少：按坏果数量/重量比例退款；
   - 坏果较多：可能整单退款或补发；
   - 具体以你下单页面的售后说明为准。

4. **注意时效**
   生鲜通常要求**签收后24小时内、最晚48小时内**反馈，超时可能不受理。收到后尽量当天开箱检查。

5. **保留证据**
   常见需要：坏果特写、坏果和好果对比、整箱合照、快递面单、订单截图。没有照片，客服可能难判责。

6. **如果客服不处理**
   - 在平台内申请“平台介入”；
   - 电商平台可找官方客服投诉；
   - 如果是直播间/社群购买，找主播或团长协调；
   - 仍不解决，可走12315投诉。

**购买前建议：**
优先选佳农官方旗舰店、大型商超或平台自营；下单前看售后说明和评价里的“坏果理赔”反馈。第三方低价店虽然便宜，但坏果理赔往往更麻烦。

简单说：**佳农不是“没售后”，而是生鲜售后讲证据和时效。坏果别扔，拍照，24小时内找客服，按比例赔。**
