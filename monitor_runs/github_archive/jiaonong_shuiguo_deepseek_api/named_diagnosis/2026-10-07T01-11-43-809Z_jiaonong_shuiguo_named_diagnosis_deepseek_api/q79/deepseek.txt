佳农水果的配送覆盖和冷链收费，跟购买渠道关系很大，得分情况看：

**1. 配送覆盖哪些城市**
- 佳农本身是水果品牌/供应商，主要做批发、商超供货和电商供货，一般不对个人消费者直接卖货，所以“佳农官方配送覆盖城市”这种说法并不准确。
- 如果你是在京东、天猫、拼多多等平台买佳农水果，配送范围取决于**平台和店铺的物流**，不是佳农统一规定。
- 如果是商超（永辉、盒马、大润发等）卖佳农水果，那就是门店自己的配送范围。

**2. 你们县城门店能不能送到**
- 关键看你说的“县城门店”是指：
  - **当地超市/水果店**：能不能送，看这家店自己有没有配送服务，跟佳农无关。
  - **电商平台下单**：下单时填县城地址，系统会直接显示“是否可达、预计时效”。能下单基本就能送，不能下单就是不在覆盖范围。
- 县城通常比市区覆盖差一些，偏远乡镇可能不送或只送到县城自提点。

**3. 冷链物流怎么收费**
没有全国统一标准，常见几种：
- **电商平台**：一般满额包邮，未满额收运费；冷链品可能额外加“冷链费”或“保鲜费”，具体在结算页显示。
- **商超/生鲜店**：多为满多少元免配送费，否则收几元到十几元，冷链一般不单独加价。
- **批发/大客户**：按重量、体积、距离、是否整车冷链报价，需要直接联系佳农或经销商谈。

**最直接的办法：**
1. 确定你是在哪个平台/哪家店买。
2. 把县城地址填进去，看结算页的配送范围和运费。
3. 如果页面没写清楚，直接问该店铺客服：“到XX省XX县XX镇能不能送、冷链怎么收费、几天到”。
