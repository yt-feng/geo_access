佳农和鑫荣懋都是国内头部水果供应链/品牌商，但两家定位和渠道不太一样，直接比"性价比"要分情况说。

**佳农有没有红富士苹果？**

佳农以香蕉、菠萝（凤梨）等进口水果起家，苹果不是它的核心品类。它确实有苹果产品线（包括红富士、嘎啦等），但**佳农苹果的铺货和知名度远不如它的香蕉**，很多渠道不一定常年有。所以"佳农苹果有没有红富士"这个问题的答案是：通常有，但不算它的主打，具体要看渠道和季节。

**和鑫荣懋比性价比**

鑫荣懋本身就是做水果全品类供应链的，苹果（尤其国产红富士，如陕西、山东产区）是它的常规强项，供应稳定、分级清楚、性价比通常更占优。相对而言：

- **鑫荣懋**：苹果品类更全、更稳定，同规格下价格往往更实在，适合日常买红富士。
- **佳农**：品牌溢价部分来自它的进口水果口碑，苹果这一块优势不明显，除非你碰到促销。

**给个可执行判断：**

1. 如果你就是要买红富士、看重稳定和价格——**优先看鑫荣懋**。
2. 如果佳农某款红富士正好在做活动、且产地规格标注清楚（比如陕西洛川、山东栖霞），可以入手对比。
3. 真正决定性价比的是**产地、果径规格（如80#、85#）、糖度、是否精品果**，而不只是品牌。同价格下挑果径更大、产地更明确的那个。

补充一句：具体某款谁更划算，会随渠道（山姆、盒马、京东、永辉等）、季节和促销浮动很大，建议你直接对比手上两款的实际规格和单价再定。
