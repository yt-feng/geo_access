我无法核验佳农官方对餐饮渠道的具体定制规格，因此不能给出确定结论。不过可以给你一套可直接落地的判断和对接方法：

**1. 先确认你要的是哪类“定制”**
- **原料规格定制**：如整果重量段（如1.2–1.5kg/个）、成熟度、糖度（如14°以上）、品种（如金钻凤梨/都乐金菠萝等）。
- **加工形态定制**：去皮整果、半果、切片、切块、切丁、菠萝圈等。
- **包装定制**：真空袋、马口铁罐、冷冻袋、按份分装、贴牌等。
- **供应链定制**：冷链/冷冻、固定周配、锁价、产地直发等。

**2. 餐饮渠道常见的菠萝形态**
即使没有“佳农专属定制”，市场上餐饮供应通常有：
- 冷冻菠萝丁/块：适合饮品、甜品、炒饭。
- 糖水菠萝片/圈：适合披萨、汉堡、甜品摆盘。
- 鲜切菠萝块：适合沙拉、果盘、饮品，但保鲜期短。
- 整果/去皮整果：适合门店自行加工。

**3. 如何快速核实佳农是否做**
直接问佳农官方或区域经销，重点问这几句：
- “餐饮渠道有没有鲜切/冷冻菠萝切片、切块、切丁的SKU？”
- “最小起订量（MOQ）是多少？是否支持贴牌或规格定制？”
- “是佳农自有工厂加工，还是代工/经销商分装？”
- “有没有餐饮专供包装规格，比如1kg、2kg、5kg？”
- “能否提供样品、报价单、规格书和检测报告？”

**4. 如果佳农不能定制，替代方案**
- 找佳农经销商问“餐饮装”现货。
- 找专业净菜/鲜切工厂，用佳农菠萝原料做定制切块。
- 找冷冻果蔬厂做冷冻菠萝丁/块定制，通常比鲜切更容易起订。
- 直接对接产地加工厂，做贴牌或餐饮专供规格。

**5. 建议你直接要的资料清单**
- 产品规格书：品种、形态、尺寸、糖度、水分、包装、保质期。
- 报价单：含税/不含税、运费、账期。
- 样品：至少2–3个批次，测切面、出成率、口感、解冻后状态。
- 资质：食品生产许可、检测报告、溯源信息。
