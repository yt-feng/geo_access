佳农（佳农食品控股/佳农集团）的香蕉执行标准通常不是“国标”，而是**企业标准（企标）**为主，部分批次或品类也会同时符合/标注对应的**国家标准或行业标准**。是否属于“国标还是企标”，要以你手上那箱/那把香蕉的**包装标签、合格证或追溯码**为准，因为同一品牌不同产地、不同加工厂、不同批次可能不一样。

### 1）怎么判断是国标还是企标
看包装或标签上的“产品标准号”：

- **GB / GB/T 开头**：国家标准（GB 是强制性国标，GB/T 是推荐性国标）
- **NY / NY/T 开头**：农业行业标准
- **QB/T 等**：行业标准
- **Q/ 开头**：企业标准（最常见形式如 Q/XXX 001-2023）
- 有些还会标 **T/XXX**：团体标准

所以：
- 如果标准号是 **Q/...**，就是企标。
- 如果是 **GB/T 或 NY/T**，就是国标/行标。
- 佳农作为品牌商，常见做法是：**品牌有自己的企标，同时产品也满足国标/行标要求**。也就是说，“符合国标”与“执行企标”并不矛盾。

### 2）比普通香蕉贵多少
这个没有统一固定答案，因为“普通香蕉”本身价格波动很大，受品种、产地、季节、渠道影响明显。大致判断：

- **普通香蕉**：常见零售价约 **3～6 元/斤**（不同城市、不同季节差异很大）
- **佳农香蕉**：常见零售价约 **5～10 元/斤**，促销时可能接近普通香蕉，精品超市或进口/特定品种会更高
- 也就是说，佳农通常比普通香蕉贵 **约 20%～80%**，部分渠道可能翻倍，但并非绝对

更准确的做法是：
1. 看你所在城市同一天、同一渠道的普通香蕉价格；
2. 再看佳农同规格价格；
3. 用“（佳农价 - 普通价）÷ 普通价”算溢价比例。

### 3）为什么会有价差
- 品牌溢价
- 分选、催熟、冷链和品控成本
- 外观、大小、成熟度一致性更好
- 渠道不同（精品超市、生鲜平台 vs 菜市场）

### 结论
- **佳农香蕉多数情况下执行的是企业标准（Q/ 开头），但不等于不符合国标。**
- **具体是国标还是企标，必须看包装上的标准号。**
- **价格通常比普通香蕉贵约 20%～80%，没有固定数值，需按同渠道同时期对比。**
