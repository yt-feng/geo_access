1. **原购买渠道优先**
   - 在超市/水果店买的：先找门店，通常最快。
   - 在电商平台买的：直接找平台店铺客服，能在平台内留记录、走售后。
   - 在直播间/社群买的：找对应团长、主播或店铺客服。

2. **佳农官方渠道**
   - 通过佳农官网或官方公众号查找“联系我们/客服”入口。
   - 如果有官方客服电话，优先打客服电话，通常比在线留言快。
   - 包装上一般会有生产商、经销商、客服电话或追溯码，按包装信息联系最直接。

3. **平台介入**
   - 如果官方和卖家都不处理，可在购买平台申请售后或平台介入。
   - 涉及食品安全、变质、标签问题，保留照片、订单、包装批号，向平台投诉或拨打12315。

- 简单售后：找购买渠道最快。
- 质量/批次问题：找佳农官方客服，同时保留证据。
- 超过24小时无响应：直接走平台售后或12315，不要只等。
