佳农水果的售后在不同购买渠道（如京东自营、天猫旗舰店、抖音直播间、社区团购、线下商超）政策不完全一样，但整体可以给你一个比较实用的判断和处理办法。

**总体口碑**
佳农属于国内做进口水果和品牌水果比较大的商家，品控和供应链相对成熟，售后一般比个人小商家规范。常见评价是：正常坏果、少发、烂果，客服基本会认，但**赔付速度和处理体验取决于你下单的平台**。平台自营或官方旗舰店通常更顺，第三方代发或低价团购可能扯皮多一点。

**到货有坏果，按这个顺序处理**

1. **先拍照/拍视频留证**
   - 坏果和快递面单一起拍，最好拍开箱视频。
   - 坏果单独拍特写，能看出腐烂、发霉、压伤、数量。
   - 不要急着把坏果全扔掉，很多客服会要求保留或按比例拍照。

2. **尽快联系客服**
   - 一般要求签收后 **24小时内** 反馈，部分生鲜要求 **12小时内**，越早越好。
   - 走购买平台内的官方客服入口，不要只找快递。

3. **说明诉求**
   - 常见处理方式：**按坏果比例退款**、**补发**、**补偿优惠券/红包**。
   - 如果坏得比较多，通常可以要求整单退或大部分退。
   - 生鲜类一般**不支持无理由退货**，但“坏果包赔”是常见承诺，坏果部分该赔。

4. **如果客服不处理**
   - 平台内申请售后/投诉，选“质量问题”“坏果腐烂”。
   - 平台介入通常比和商家单独拉扯有效。
   - 京东自营可走京东售后，天猫可走天猫介入，抖音可走平台仲裁。

**注意几个坑**
- **别超时**：生鲜售后时效很短，拖到第二天可能就不认了。
- **别只拍一堆烂果**：要能对应订单和数量，否则容易被说“无法核实”。
- **特价/秒杀/团购**：有些会写“坏果不赔”或只赔少量，下单前看清。
- **运输压伤 vs 腐烂**：轻微压伤可能只算瑕疵，腐烂发霉一般必须赔。
- **整箱坏一半以上**：可以直接要求整单退款，不用接受只赔几块钱。

**一句话建议**
如果你是在京东自营、天猫旗舰店这类正规渠道买的，坏果基本能赔，按比例退款最常见；到货先拍视频留证，24小时内找平台客服，谈不拢就申请平台介入。买之前最好看清该链接有没有写“坏果包赔”和具体时效。
