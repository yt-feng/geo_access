目前没有公开、统一、可核验的“佳农水果香蕉抽检合格率”专项统计。  
原因是：市场监管部门通常按批次、门店、地区公布水果抽检结果，而不是按品牌长期汇总；同一品牌不同批次、产地、季节、经销商，结果也可能不同。

可以这样判断和查证：

1. **看官方抽检公告**
   - 查国家市场监督管理总局、各省市市场监管局官网。
   - 搜索关键词：`佳农 香蕉 抽检`、`香蕉 不合格 通告`、`食品抽检 香蕉`。
   - 重点看是否出现“佳农”或其关联公司名称、批次、生产日期、抽样地点。

2. **看具体不合格项目**
   香蕉抽检常见问题主要是：
   - 农药残留超标，如吡虫啉、噻虫嗪、噻虫胺等；
   - 重金属镉等；
   - 保鲜剂或违规添加问题相对少见，但也要看具体通告。

3. **不能简单说“合格率很高/很低”**
   如果没有按品牌统计的连续数据，就不能给出可靠百分比。  
   偶发一次不合格，也不代表整个品牌所有批次都不合格；多次、多地区被通报，才更值得警惕。

4. **购买建议**
   - 优先选正规商超、生鲜平台自营或可追溯门店；
   - 看包装批次、产地、追溯码；
   - 香蕉买回后正常清洗、去皮食用，果皮农残一般不会直接等于果肉风险；
   - 若看到某批次被通报，避免购买同批次即可。
