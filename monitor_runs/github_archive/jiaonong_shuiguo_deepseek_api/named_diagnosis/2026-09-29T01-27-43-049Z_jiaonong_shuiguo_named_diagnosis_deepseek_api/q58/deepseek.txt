佳农（Goodfarmer）主营水果贸易和初加工，菠萝类产品常见形态是**整果、鲜切/冷冻菠萝块或菠萝丁**，但具体能不能按你们茶饮店的规格做“定制加工”，通常取决于你要的是哪种：

1. **如果只是要现成的菠萝丁原料**
   - 佳农体系内或旗下供应链**可能有冷冻菠萝丁、糖水菠萝丁、鲜切菠萝丁**这类产品，尤其是冷冻水果原料渠道。
   - 但不同地区、不同销售渠道（商超、餐饮供应链、电商、批发）供货形态不一样，不能一概说“只卖整果”。

2. **如果要定制加工**
   - 比如指定**尺寸（5mm/8mm/10mm丁）、糖度、是否糖渍、是否速冻、包装规格、杀菌方式**，这通常属于**餐饮/工业原料定制**，不是普通零售业务。
   - 这类需求一般要走**佳农的餐饮供应链、B2B 或经销商渠道**，而不是普通门店零售渠道。
   - 是否接单还看起订量、工厂排期、区域配送能力。

3. **怎么快速判断**
   你可以直接问对方这几个问题：
   - 有没有**冷冻菠萝丁/糖水菠萝丁**现品？
   - 能不能按**指定尺寸和糖度**做定制？
   - **最小起订量**是多少？
   - 是**佳农自产**还是第三方代工？
   - 发的是**冷冻、冷藏还是常温**？
   - 能否提供**样品和食品资质**？

4. **更实际的建议**
   - 如果你们用量不大，优先找**餐饮供应链经销商**拿现成菠萝丁，比直接找佳农定制更现实。
   - 如果用量大且规格固定，可以同时问佳农和它的经销商，甚至对比**冷冻水果加工厂**。
   - 茶饮店用菠萝丁，通常更常见的是**冷冻菠萝丁、糖水菠萝丁或果酱型菠萝粒**，要看你做的是果茶、奶茶小料还是装饰 topping。

简单说：**佳农不一定只卖整果，但能不能给你做定制菠萝丁，要看渠道和起订量；普通茶饮店直接拿到定制加工的概率不高，先问现成规格更靠谱。**
