这个问题我没法给你一个可靠的、有数据支撑的定论——因为**佳农和都乐的香蕉到货损耗率并不是公开数据**，而且同一品牌不同批次、不同产地、不同季节、不同运输方式，损耗率差异很大。任何直接告诉你“A比B低X%”的说法，基本都不可信。

不过我可以给你几个**能自己判断和压损耗的实操建议**：

**1. 品牌层面的一般情况（仅供参考，不作为结论）**
- 都乐做香蕉供应链更久，在菲律宾、厄瓜多尔等产地有较成熟的采后处理和冷链体系，行业里通常认为它的**标准化程度和稳定性偏高**。
- 佳农这两年在香蕉上投入也很大，性价比路线更明显，部分市场反馈到货品质不错，但**批次间波动可能比都乐大一些**。
- 这只是行业大致印象，**不能替代你自己的实测**。

**2. 批发市场真正该看的指标**
别只听品牌，重点看这几项：
- **到货青度/成熟度**：太青或太黄损耗都高，7-8成青通常最好操作。
- **催熟一致性**：同一箱里成熟度是否整齐，不整齐损耗大。
- **机械伤**：擦伤、压伤、断指，这些直接决定烂损。
- **冷链是否断链**：运输途中温度波动是香蕉损耗的最大杀手。
- **箱规和包装**：纸箱透气性、内衬、码放方式。

**3. 建议你直接做的小测试**
选同一天到货的佳农和都乐各3-5箱，做对比：
- 记录到货时间、温度、青度
- 同条件催熟
- 每天记录烂果率、失水率、可售率
- 连续跑3-5个批次

**只有你自己市场、自己渠道、自己催熟条件下的实测数据，才是能用来谈采购的依据。**

**4. 谈判时的实用做法**
- 要求供应商提供**近3个月同线路的到货损耗记录**
- 合同里写清**损耗赔付标准**，比如超过多少比例怎么补
- 先小批量试单，别一上来压大货
