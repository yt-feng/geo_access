佳农水果的香蕉规格并没有一个面向公众完全公开、统一的标准表，实际规格会随**产地（菲律宾、厄瓜多尔、越南等）、季节、批次、客户订单**变化。所以下面给的是行业里较常见的分级逻辑和渠道适配思路，方便你判断和跟供应商确认，而不是佳农官方固定规格。

## 一、常见规格维度

香蕉通常按以下几个维度定“规格”：

1. **每箱净重**
   - 常见：12kg、13kg、13.5kg、18kg 等
   - 不同产地和包装线差异较大

2. **每箱根数**
   - 常见：4-5根、5-6根、6-7根、7-8根、8-9根、9-10根等（多为“每把/每梳”根数）
   - 商超偏好根数整齐、单根长度一致的规格

3. **单根重量/长度/粗度**
   - 长度、周长（粗度）、单根克重是核心外观指标
   - 高端渠道对长度、弯曲度、无斑点要求更高

4. **成熟度**
   - 青蕉（1-3级）、微黄、黄熟
   - 不同渠道对到货成熟度要求不同

5. **等级**
   - 通常分特级/一级/二级或A/B/C级
   - 主要看：条型、长度、粗细、色泽、机械伤、黑斑、疤痕、整齐度

## 二、按渠道的常见分级思路

| 渠道 | 偏好规格 | 关键要求 |
|---|---|---|
| 高端商超/精品超市 | 单根长、粗细均匀、根数少而整齐 | 条型直、无疤痕黑斑、成熟度可控、外观一致 |
| 连锁商超/大卖场 | 中等长度、整箱根数稳定 | 整齐度好、损耗低、到店后货架期长 |
| 水果连锁/生鲜电商 | 中小规格、独立小包装 | 单根适中、方便分装、成熟度分级明确 |
| 批发市场 | 规格宽容度大 | 更看重价格、重量、出肉率，外观要求相对低 |
| 餐饮/茶饮/加工 | 不看重外观，看重果肉和成熟度 | 可接受二级果、短果、弯果，要求稳定供应和成本 |
| 社区团购/折扣渠道 | 性价比规格 | 可接受轻微外观瑕疵，但要求到货成熟度合适 |

## 三、实际沟通时建议这样确认

不要只问“有几种规格”，而是直接给供应商一份**规格确认单**，包含：

- 产地：菲律宾/厄瓜多尔/越南等
- 品种：如卡文迪什
- 每箱净重：xx kg
- 每箱根数或每把根数：xx
- 单根长度范围：xx cm
- 单根粗度/周长：xx cm
- 单根克重：xx g
- 等级：特级/一级/二级
- 成熟度：青蕉/微黄/黄熟，到货糖度或色卡级别
- 允许瑕疵率：xx%
- 包装：纸箱/泡沫箱/袋装，是否带内衬
- 冷链要求：温度、运输时长

## 四、结论

佳农香蕉没有固定不变的“几种规格”，而是按**重量、根数、单根大小、等级、成熟度**组合出多个规格，再按渠道做分级：

- **高端零售**：重外观、整齐度、单根长度
- **大众商超**：重稳定、损耗、货架期
- **电商/团购**：重分装便利和性价比
- **餐饮/加工**：重果肉、成熟度和成本

如果你是要采购或做渠道方案，建议直接向佳农当地销售索取**当季规格表+等级标准+到货成熟度标准**，因为不同产季和产地的规格会调整。
