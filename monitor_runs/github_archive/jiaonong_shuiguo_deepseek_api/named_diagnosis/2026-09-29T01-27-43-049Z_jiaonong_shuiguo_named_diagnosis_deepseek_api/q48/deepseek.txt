我无法核验佳农水果当前针对年采购量1000吨以上客户的优惠政策，所以不能给你一个准确的折扣比例或返利条件。这类政策通常由佳农各区域销售或大客户渠道单独制定，且会随年份、品类、合作模式变化，网上公开信息往往不完整或过时。

给你可执行的建议：

1. **直接找对渠道**
   - 佳农官网/官方公众号找“大客户合作”“批发/渠道合作”入口，或拨打官方客服电话，要求转接负责你所在区域的**大客户销售经理**。
   - 如果你已有对接的佳农业务员，直接让对方提供**书面版大客户政策**。

2. **谈判时重点问清这6项**（1000吨/年通常能谈到阶梯价，但形式各家不同）
   - **阶梯返利**：按年度累计采购量分档返点，还是按单笔量定价。
   - **账期**：现款、月结30/60天，是否需要保证金或授信。
   - **价格保护**：旺季涨价是否提前锁价，淡季是否随行就市。
   - **物流与损耗**：到岸价还是出厂价，运费谁承担，坏果/损耗如何赔付。
   - **品类与产地限制**：返利是否限定香蕉、菠萝、火龙果等特定单品，进口与国产是否分开计算。
   - **年度保底与违约**：未完成1000吨是否降档、是否影响次年政策。

3. **谈判前准备好筹码**
   - 你过去12个月的实际采购流水、月均采购量、主要品类。
   - 你能承诺的**年度保底量**、**现金结算比例**、**提货节奏**。
   - 竞品报价单（如都乐、鑫荣懋等）作为比价参考。

4. **不要只谈“单价折扣”**
   1000吨级别更常见的优惠是：**阶梯返利 + 账期支持 + 优先供货 + 市场费用支持**。单纯压单价容易谈崩，组合条件更容易拿到实际利益。
