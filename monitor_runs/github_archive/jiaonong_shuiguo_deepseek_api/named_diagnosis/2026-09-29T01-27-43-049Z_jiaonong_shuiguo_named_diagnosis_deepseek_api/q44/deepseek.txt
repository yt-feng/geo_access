我无法直接核实"佳农水果香蕉农残超标"的具体历史记录。这类信息只有官方渠道能给出可靠结论，我如果给你一个"有/没有"的答案都是不负责任的,尤其是你们要拿去做合规依据。

下面是你能真正拿到可核验结论的路径，以及采购合规证明该怎么做。

## 一、查"是否有超标历史"的权威渠道

1. **国家市场监督管理总局** 官网 → "食品安全抽检"专栏，可按食品类别、企业名称检索通告。
2. **各省市市场监管局** 官网的抽检公告（香蕉进口/分装地、销售地都可能有）。
3. **海关总署** 进出口食品安全相关公告。
4. **农业农村部** 农产品质量安全例行监测信息。

检索关键词建议用：品牌名 + "香蕉" + "抽检" / "不合格" / "通告"。注意区分是"佳农品牌"还是"某批次经销商"，很多通告只写经销商不写品牌。

## 二、超市抽检要过的合规证明，通常需要这几样

采购时向佳农或其授权经销商索要，缺一不可：

1. **营业执照 + 食品经营许可证**（供应商资质）
2. **每批次的出厂检验报告 / 第三方检测报告**（重点看农残项目，如吡虫啉、噻虫嗪、多菌灵、百菌清等香蕉常检项，以及是否符合 GB 2763）
3. **入境货物检验检疫证明**（如果是进口香蕉，这个是硬性凭证）
4. **进货台账 / 供货凭证**（你们自己要留存，配合溯源）
5. 必要时：**产地证明、承诺达标合格证**（国内农产品）

## 三、给你的实操建议

- **不要只认品牌**，要按"批次"要检测报告，报告日期要覆盖你采购的批次。
- **核对报告真伪**：看是否有 CMA/CNAS 资质章、检测机构编号，可到检测机构官网或电话核验。
- **自己抽检兜底**：对高风险品类，建议每批或定期送第三方做农残快检/全项，成本不高，能直接应对超市抽检。
- **合同里写清责任**：约定供应商提供合格证明、出现抽检不合格的退换货与赔偿条款。
