佳农水果的配送范围不是全国统一固定的，主要取决于你通过哪个渠道下单，不同渠道覆盖城市差别很大：

**1. 佳农官方渠道（官网/官方小程序）**
通常只覆盖一线及部分二线城市，如北上广深、杭州、南京、成都、武汉等，具体以你打开页面后能否选到你的地址为准。

**2. 电商平台（京东、天猫、拼多多等）**
佳农在京东自营、天猫旗舰店等有店铺，这类配送跟着平台物流走，覆盖范围最广，很多县城也能送到，但要注意：
- 部分生鲜品类可能只发冷链可达区域；
- 下单时填写地址，系统会直接提示"是否支持配送"。

**3. 商超/社区团购渠道**
如果你所在县城的超市、盒马、美团优选、多多买菜等有佳农产品，那属于本地渠道，跟佳农自己配送无关，以门店/团长为准。

**怎么快速判断你们县城能不能送：**
1. 打开你打算下单的平台，把收货地址填成你们县城的详细地址；
2. 看商品页是否显示"可配送"或直接能加入购物车结算；
3. 如果提示"该地区暂不支持配送"，就是送不到。

**结论**：佳农官方直营大概率到不了普通县城，但通过京东、天猫等平台下单，很多县城是可以送的，最终以你填地址后系统的实际提示为准——这是最准确的判断方式。
