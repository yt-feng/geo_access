我无法确认佳农目前是否有“加工好的香蕉片”这个餐饮供应SKU，也不能给出可靠规格。佳农的主要香蕉业务以**鲜果**为主，常见是整把/整箱鲜香蕉，面向商超和水果渠道；“切片香蕉片”通常分两类，供应逻辑不同：

1. **冷冻香蕉片/速冻香蕉片**
   - 常见规格：1kg/袋、2kg/袋、10kg/箱；片厚约5–10mm；有的会做IQF单冻。
   - 用途：饮品、烘焙、甜品、果昔、餐饮后厨。
   - 这类一般由冷冻果蔬加工厂供应，不一定是佳农品牌。

2. **香蕉脆片/烘干香蕉片**
   - 常见规格：500g、1kg、5kg、10kg/箱；片厚约2–4mm。
   - 用途：零食、烘焙装饰、酸奶配料。
   - 这类多来自食品加工厂，和鲜香蕉供应链不是一回事。

3. **鲜香蕉现场切片**
   - 如果你们门店只是要“切片使用”，更现实的是采购佳农鲜香蕉，门店或中央厨房自行切片。
   - 鲜香蕉规格常见按重量/根数分级，比如每箱约12–13kg、每根约110–150g等，但具体批次和渠道差异较大。

- 要求提供：产品名称、配料表、是否速冻/IQF、片厚、单袋重量、箱规、储存温度、保质期、是否含糖/添加剂、起订量、配送温度。
