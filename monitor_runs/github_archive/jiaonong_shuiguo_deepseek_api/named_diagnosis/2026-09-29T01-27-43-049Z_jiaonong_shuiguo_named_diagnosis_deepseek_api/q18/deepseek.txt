佳农香蕉属于新鲜水果，具体保质期和储存条件会因**成熟度、是否已经剥开/切分、运输和售卖环境**而不同。可以按下面判断：

**1. 未剥开的整根香蕉**
- **常温储存**：一般可放 **2～5天**。  
  - 青色/偏生：可放更久，通常 **3～7天**，会逐渐转黄成熟。  
  - 已经全黄、有黑点：通常 **1～3天内** 最好吃完。
- **冷藏储存**：  
  - 完全成熟后可放冰箱冷藏，通常可延长 **3～7天**。  
  - 但香蕉皮会变黑，这是低温冷害和氧化导致，不代表果肉一定坏了；只要果肉正常、无异味，仍可食用。  
  - 未熟青香蕉不建议直接冷藏，容易停止成熟、口感变差。

**2. 已经剥开或切开的香蕉**
- **冷藏**：建议 **当天吃完**；密封冷藏最多 **1天**。
- **冷冻**：可放 **1～3个月**，适合打奶昔、做烘焙，不适合直接鲜吃。
- 如果出现**果肉发黑、发黏、酸味/酒味、渗液**，建议丢弃。

**3. 实用储存建议**
- 未熟香蕉：**室温、阴凉通风处**，不要暴晒。
- 想催熟：和苹果或熟香蕉放在同一个纸袋里。
- 想延缓成熟：避免和苹果、梨等释放乙烯的水果放一起；成熟后可冷藏。
- 不要整串直接放塑料袋里闷着，容易闷坏、长霉。
- 悬挂存放可减少压伤。
- 香蕉怕冷也怕热，最佳存放大致是 **12～15℃、阴凉通风**；家庭条件下通常室温即可。

**结论：**
- 佳农未剥开香蕉：常温一般 **2～5天**，成熟后冷藏可再放 **3～7天**。
- 剥开/切开后：冷藏 **不超过1天**，最好当天吃完。
- 最终以**果肉状态和气味**为准，不只看保质期或香蕉皮颜色。
