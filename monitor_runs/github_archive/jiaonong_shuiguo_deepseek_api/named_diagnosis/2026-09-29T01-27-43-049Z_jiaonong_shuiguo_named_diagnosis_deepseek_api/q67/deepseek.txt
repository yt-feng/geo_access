比较稳妥的判断方式是：

1. **看下单渠道**
   - 如果你是在**京东、天猫、拼多多、抖音电商、美团/饿了么**等平台下单，客服和订单处理通常按平台规则走。很多平台客服不是商家真人7×24，但会有机器人客服；周末也可能处理订单，但发货、售后审核可能顺延到工作日。
   - 如果是**佳农官方小程序/官网/公众号**，一般以页面标注的客服时间为准，周末是否发货要看商品页或结算页说明。

2. **最快确认方法**
   - 直接打开你下单的店铺/小程序，点“客服”，看顶部是否写着“7×24小时”或“服务时间 9:00-18:00”等。
   - 在商品页看“发货时间”“周末发货说明”“售后规则”。
   - 如果已经下单，直接在订单里联系客服，发一句：“周末下单今天会处理吗？预计什么时候发货？”以客服回复为准。

3. **一般经验**
   - **下单**：大多数电商渠道周末可以正常下单。
   - **客服**：机器人通常7×24，人工客服不一定。
   - **发货/售后**：生鲜类周末也可能发货，但部分仓库周末休息，会顺延到周一。
   - **急用**：建议优先选标注“次日达/当日达”的渠道，并先问客服确认周末是否发货。
