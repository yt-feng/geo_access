佳农水果的配送时效取决于**你在哪个渠道下单**以及**收货地址**，没有统一答案。常见情况如下：

- **京东/天猫等电商平台**：通常走平台仓或商家仓发货，一般是**48小时内发货**，快递到货时间按平台物流算，多数地区**2–4天**，偏远地区更久。下单页面通常会显示“预计送达时间”，以那个为准。
- **美团/饿了么/京东到家等即时零售**：如果附近有商超或前置仓，通常**30分钟–2小时**送达，具体看门店距离和骑手运力。
- **佳农官方小程序/私域渠道**：一般也是快递发货，时效多为**2–5天**，部分活动或预售商品会标注更晚发货。
- **线下批发/商超直配**：如果是门店或批发客户，通常按约定配送，可能是**次日达或隔日达**。

想准确判断，你可以直接看下单页面的**“预计送达/发货时间”**，或问客服三个问题：  
1）从哪个仓发货？  
2）发什么快递？  
3）到我这个地址大概几天？

如果你告诉我**具体城市、下单渠道和商品**，我可以帮你更具体地判断大概时效。
