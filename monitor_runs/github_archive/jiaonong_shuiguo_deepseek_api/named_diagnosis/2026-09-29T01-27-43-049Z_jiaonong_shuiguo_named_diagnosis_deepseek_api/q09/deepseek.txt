佳农水果的到货损耗率没有公开统一的标准，具体取决于品类、运输方式、季节和渠道类型。不过可以给你一个行业参考区间来判断：

- **耐储水果**（如苹果、梨、橙子）：到货损耗通常控制在 **1%–3%**
- **中等易损水果**（如香蕉、葡萄、猕猴桃）：通常 **3%–8%**
- **高易损水果**（如草莓、蓝莓、樱桃、荔枝）：通常 **8%–15%**，运输距离远或夏季可能更高

如果是佳农这类做品牌化、标准化供应链的企业，内部对重点单品一般会设定更细的分品类考核指标，但具体数值属于企业运营数据，外部通常拿不到准确数字。

**如果你是要做采购或供应商管理，建议这样判断：**
1. 按品类分别设定损耗上限，而不是用一个统一数字
2. 在合同里写明到货验收标准和损耗超出后的扣款/补货机制
3. 要求供应商提供近3个月的分品类到货损耗数据，用实际数据谈判
