可以做到“到具体农场/种植场”这一级，但通常不会在零售包装上直接印到单个小农户或地块，而是通过**批次号/追溯码 + 供应链档案**能追到注册的种植场或合作农场。至于你要的 **GLOBALG.A.P. 证书**，关键不是佳农“有没有”，而是**该批次对应的生产/包装主体是否在证书覆盖范围内**。商超要求时，建议按下面方式核验和索证。

## 1. 佳农香蕉能否溯源到具体农场？
**可以，但一般是“企业级追溯系统里可追到农场”，不是消费者扫码就显示农场名。**

常见做法是：
- 包装箱/托盘标签上有**批次号、生产日期、包装厂代码、产地代码**；
- 佳农或供应商内部系统可对应到：
  - 国家/产区（如菲律宾、厄瓜多尔、越南、柬埔寨、中国等）
  - 注册种植场/合作农场
  - 包装厂
  - 出口批次
- 对商超客户，通常可提供**产地证明、追溯说明、供应链清单**，必要时能到农场级。

但要注意：
- 若香蕉来自**多个小农户收购后混装**，追溯可能只能到**收购站/包装厂/合作社**，不一定能拆到每家小农户；
- 若商超要求“每根香蕉对应一个农场”，这在香蕉大宗贸易里通常不现实，也不符合行业惯例。

## 2. GLOBALG.A.P. 证书怎么要、怎么看？
商超要 GLOBALG.A.P.，应要求佳农提供**与你这批货直接相关的有效证书**，而不是一张泛泛的公司证书。

重点核对：
1. **证书持有者**是谁：是种植场、合作社、包装厂，还是贸易公司？
2. **证书编号**和 **GGN编号**；
3. **认证范围**是否包含：
   - 产品：Banana / 香蕉
   - 活动：Production / Handling / Packing 等
   - 地点：具体农场或包装场
4. **有效期**是否覆盖生产和发货日期；
5. **认证机构**是否被 GLOBALG.A.P. 认可；
6. 证书状态是否在 GLOBALG.A.P. 数据库可查。

最好让佳农提供：
- GLOBALG.A.P. 证书 PDF；
- 对应农场的 GGN；
- 该批次与证书的关联说明；
- 包装厂/出口商信息；
- 如商超要求，提供**CoC 或可追溯性声明**。

## 3. 给商超的实操建议
你可以这样向佳农或供应商提要求：

> 请提供本批次香蕉对应的 GLOBALG.A.P. 证书，证书需覆盖实际种植农场和包装环节，并标注 GGN、证书编号、有效期、认证产品范围。同时提供批次号与农场/包装厂的追溯关联说明。

如果对方只给一张贸易公司证书，通常**不够**，因为 GLOBALG.A.P. 核心是农场/生产环节认证。除非证书范围明确覆盖了相关生产主体。

## 4. 结论
- **能溯源到具体农场吗？** 通常可以，至少到注册农场/合作社/包装厂级；但零售端不一定公开到农场名。
- **GLOBALG.A.P. 证书能满足商超吗？** 可以，但必须是**覆盖该批次实际生产农场的有效证书**，并能在 GLOBALG.A.P. 数据库核验。
- **最稳妥做法：** 要证书 + GGN + 批次追溯关联 + 包装厂信息，四者对上再收货。
