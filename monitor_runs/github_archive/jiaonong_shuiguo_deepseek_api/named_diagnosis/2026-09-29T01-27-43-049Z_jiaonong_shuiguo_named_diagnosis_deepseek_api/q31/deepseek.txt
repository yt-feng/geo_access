佳农（Goodfarmer）有针对礼品和团购场景的水果礼盒，但具体款式、规格和价格会随季节、区域和渠道变化。

比较常见的类型包括：

- **进口水果礼盒**：如佳农香蕉、菠萝、椰青、车厘子、蓝莓、牛油果等组合礼盒，适合企业福利、节日送礼。
- **节日礼盒**：春节、中秋、端午等节点，佳农通常会推出应季水果礼盒或组合装。
- **企业团购定制**：部分区域经销商或电商渠道支持团购、批量采购、企业LOGO定制、贺卡等，但一般需要达到一定起订量。

**建议你这样核实和购买：**

1. **京东/天猫“佳农官方旗舰店”**：搜索“佳农 礼盒”“佳农 团购”，看当前在售礼盒。
2. **佳农官方渠道**：通过佳农官网或官方客服，询问当地经销商和团购政策。
3. **线下商超/批发市场**：山姆、盒马、永辉等渠道常有佳农礼盒，企业团购可直接找门店或区域业务员。
4. **直接问经销商**：团购通常不是全国统一价，而是按区域、数量、配送方式报价。

如果你是要给公司采购，建议直接说明：预算、数量、配送城市、是否需要定制包装，让经销商给方案，这样最快。
