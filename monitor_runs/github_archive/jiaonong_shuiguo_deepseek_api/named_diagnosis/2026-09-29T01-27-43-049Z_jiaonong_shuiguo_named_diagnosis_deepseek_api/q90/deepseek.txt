**1）先确认佳农是否做冷冻菠萝丁**
- 找**佳农官方渠道**：官网、官方公众号/小程序、官方客服电话，或你在当地的佳农经销/代理商。
- 直接问三个关键点：
  1. 有没有**速冻菠萝丁/冷冻菠萝丁**这个SKU；
  2. 是**生鲜冷冻**还是**糖水/蜜渍**类（茶饮店通常要分清）；
  3. 能不能提供**样品和质检报告**。

**2）茶饮店常用规格要问清**
即使有货，也要确认这些参数，否则拿到货可能不适合门店：
- **果丁尺寸**：常见有 5×5mm、8×8mm、10×10mm 等；茶饮店常用 **8×8mm 或 10×10mm**，太小易碎、太大不好吸。
- **包装规格**：常见 **1kg/袋、2kg/袋、5kg/袋、10kg/箱** 等，按你门店用量选。
- **冷冻方式**：IQF（单体速冻）通常比整块冻更好分装，不易结块。
- **糖度/是否加糖**：原味冷冻、糖渍、糖水型，会影响饮品配方。
- **固形物含量**：如果是糖水型，要问固形物占比。
- **保质期与储存**：通常 -18℃ 冷冻，保质期 12–24 个月不等，以实际标签为准。

**3）如果佳农没有，替代方向**
- 找**冷冻水果原料供应商**或**茶饮原料供应链**，要 IQF 菠萝丁；
- 常见产地：菲律宾、泰国、哥斯达黎加、中国广东/海南等；
- 重点看：**果丁完整度、解冻后出水、纤维感、酸甜稳定性**。

**4）给供应商的询价话术**
你可以直接发：
