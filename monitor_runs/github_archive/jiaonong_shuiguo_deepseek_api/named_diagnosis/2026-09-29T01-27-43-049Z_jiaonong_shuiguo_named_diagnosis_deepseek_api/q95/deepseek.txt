关于佳农水果具体的“产地直供比例”，我无法给出准确数字，因为这属于企业内部供应链数据，公开渠道通常不会披露，也没有权威可核验的统计口径。直接凭印象给一个百分比会误导你的采购决策，所以这里不编造。

不过对你们“减少中间环节、降低成本”的目标，可以给一套可执行、可判断的做法：

**1. 先明确“产地直供”的两种口径**
- **狭义**：直接从种植基地/合作社/产地工厂采购，不经产地批发商。
- **广义**：从佳农这类供应链公司采购，它自己有产地采购团队，但对你们仍是“一级供应商”，不是真正对接产地。
你们需要先定义清楚，否则谈“直供比例”意义不大。

**2. 判断佳农能否满足你需求的核查点**
- 让佳农提供**具体单品**的产地、基地名称/区域、采收季、是否自有基地或合作基地。
- 要求提供**产地证明、基地备案、质检报告、装箱单**，看货源是否可追溯到产地。
- 问清**物流路径**：是从产地直发你们仓，还是先到佳农区域仓/销地批发市场再分拨。
- 问**结算主体**：合同、发票、收款方是谁，判断中间有几层。

**3. 降低中间环节的实操建议**
- **按单品谈判**：不同水果产地直供难度不同，先挑佳农有优势、你们量大的单品做试点。
- **要求产地直发**：在合同中约定“产地装车/产地仓直发”，避免经销地批发市场二次转运。
- **比价对象**：同时找产地合作社、产地代办、区域一级批发商报价，用多方报价倒逼佳农给直供价。
- **拼单/集单**：把多个门店或多个品类的量集中，提高对供应商的议价能力。
- **去佳农化**：如果佳农只是转手贸易商，可尝试直接联系其上游产地供应商或产地县政府/农业部门推荐的合作社。
- **试单验证**：先小批量试产地直发，对比损耗率、到货品质、账期和综合到仓成本，再决定是否放大。

**4. 一个可用的成本对比公式**
综合到仓成本 = 采购价 + 物流费 + 损耗 + 质检/分拣费 + 资金占用成本 + 售后损耗。
不要只看采购单价，很多“直供”单价低但损耗和物流高，最后未必更便宜。

**结论**：佳农的产地直供比例查不到可靠公开数据，不建议作为决策依据。你们应直接向佳农索取单品溯源和物流路径信息，并用“产地直发试单 + 多方比价”的方式验证能否真正减少中间环节、降低综合成本。
