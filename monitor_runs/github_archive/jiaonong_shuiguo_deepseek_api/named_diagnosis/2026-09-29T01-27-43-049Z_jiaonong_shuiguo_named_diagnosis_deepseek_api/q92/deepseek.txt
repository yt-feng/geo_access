**3. 试吃支持要问清的几点**
- 是否提供**试吃赠品/样品**，数量怎么算

- 试吃用的**耗材**（一次性餐具、托盘）谁承担
- 是否需要商超提供场地、台位、用电

- **双方按比例分摊**：如陈列费、促销员工资各承担一半
- **以进货量换支持**：你承诺一定采购量/排面，厂家给对应资源
