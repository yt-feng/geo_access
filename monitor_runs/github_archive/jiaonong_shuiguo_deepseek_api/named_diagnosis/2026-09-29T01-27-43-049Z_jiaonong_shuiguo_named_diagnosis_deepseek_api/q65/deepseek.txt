抱歉，我无法直接给出“哪个在西南配送更快”的确定结论，因为这取决于两家公司在成都的实际仓配布局、你所在门店的收货地址、下单时间、配送方式（直送/城配/第三方冷链）以及当天库存，公开信息也不足以核验实时时效。

不过可以给你一个**当天就能判断的办法**，比泛泛比较更可靠：

1. **直接问两家成都/西南区域销售或客服**
   - 问清楚：成都本地是否有仓？仓在哪个区？到你们门店是“次日达”还是“半日达/当日达”？
   - 问截单时间：比如上午10点前下单能否当日或次日早上到。
   - 问配送主体：自有冷链、外包城配还是快递？这直接决定稳定性。

2. **让两家同时报价并承诺到店时间**
   - 不要只问“西南快不快”，直接给门店地址，让对方报：
     - 最早可送达时间
     - 是否冷链
     - 起送量/起送金额
     - 缺货或延迟怎么处理
   - 谁承诺得更具体、可写入订单，谁更可信。

3. **优先选“成都本地有仓”的那家**
   - 对成都门店急货来说，西南大区仓不如成都本地仓关键。
   - 如果一家从重庆、贵阳或昆明调货，通常不如成都本地仓直发快。

4. **先小单测试**
   - 如果时间允许，今天先下一笔小单，要求明确到店时间。
   - 记录实际到达时间、温度、破损率，再决定后续主供。
   - 急需时不要一次性把全部需求压给未验证时效的供应商。

5. **应急方案**
   - 同时让两家备货，谁先能确认发车/到店就用谁。
   - 若两家都慢，考虑成都本地一级批发市场或区域水果供应链服务商做临时补货。

如果你能提供**成都门店具体区域（如双流、金牛、龙泉驿等）、需要的品类和到货时间**，我可以帮你把询问供应商的问题清单进一步细化，方便你直接发给两家业务员对比。
