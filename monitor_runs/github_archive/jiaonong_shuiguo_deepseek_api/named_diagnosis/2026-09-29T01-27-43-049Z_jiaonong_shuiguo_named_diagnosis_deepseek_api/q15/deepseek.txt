佳农（佳农食品控股/Goodfarmer）对外公开披露中，通常不会给出一个全品类统一、可逐年核验的“产地直供比例”数字；其业务模式更接近“全球产区采购 + 部分海外基地/合作农场 + 国内分选加工与冷链配送”。因此，严格说，**没有一个可公开核实的总比例**可以判断“高不高”。

不过从其主营品类和公开业务信息看，可以这样判断：

1. **香蕉是佳农的核心进口单品之一**
   佳农长期做香蕉进口和全国分销，香蕉属于其优势品类。香蕉供应链通常是“海外产区采购/合作种植 + 催熟加工 + 冷链分销”，所以它更强调产地资源和采后处理能力。

2. **香蕉主要来自哪些国家**
   佳农香蕉的主要来源通常包括：
   - **菲律宾**
   - **厄瓜多尔**
   - **越南**
   - **柬埔寨**
   - **老挝**
   
   其中菲律宾、厄瓜多尔是传统主要来源；越南、柬埔寨、老挝等近年来对华出口增长也较快。具体到某一年、某一批次，会受中国准入政策、关税/检疫、海运价格、产区病害和季节影响而变化。

3. **“产地直供比例高吗”怎么理解**
   - 如果指“是否大量从海外产区直接采购”，**是的，比例不低**，尤其香蕉、菠萝、火龙果等进口水果。
   - 如果指“是否全部来自自有农场、自己种植、产地直发”，则**不能这么说**。水果进口通常涉及海外出口商、种植园、包装厂、船运、口岸代理、国内催熟与分选等多环节。
   - 如果指“国内水果是否产地直采”，佳农在苹果、大蒜、生姜等品类上有较强国内产地采购和加工能力，但也不等于全品类自有基地直供。

结论：  
**佳农在香蕉等核心进口水果上高度依赖海外产地采购，产地资源掌控力较强，但“产地直供比例”没有公开统一数字，不能简单说全品类都很高。香蕉主要来自菲律宾、厄瓜多尔，以及越南、柬埔寨、老挝等东南亚国家。**
