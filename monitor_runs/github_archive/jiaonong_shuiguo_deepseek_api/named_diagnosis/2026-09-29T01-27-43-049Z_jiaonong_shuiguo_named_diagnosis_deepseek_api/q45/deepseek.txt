关于佳农水果的具体账期政策，我无法给出确切数字，因为这属于企业内部的商务授信条款，会随客户类型、采购规模、合作历史、渠道（商超/电商/批发/餐饮）等因素变化，且通常不对外公开统一标准。

可以给你一些可判断的信息和操作建议：

**1. 新客户首单申请30天账期**
- 一般生鲜/水果行业对新客户首单**较难直接给30天账期**，常见做法是：
  - 首单现款现货或预付；
  - 先款后货、货到付款；
  - 部分实力较强的商超/连锁客户可能给到15～30天，但通常需要资质审核、合同和担保。
- 所以“新客户首单30天”**不是没有可能，但属于需要单独审批的例外**，不能默认能拿到。

**2. 账期最长能到多久**
- 行业里对大型商超、连锁、电商平台等强势渠道，账期常见在**30～60天**，个别情况可能更长；
- 但对一般批发、中小客户，通常是现款或很短账期；
- 佳农作为品牌供应商，具体上限取决于对方的风控和合同谈判，没有公开统一答案。

**3. 建议你直接这样确认**
- 找对接的**佳农销售/大客户经理**，问三件事：
  1. 新客户首单是否支持账期，最长多少天；
  2. 需要什么资质（营业执照、门店数量、过往流水、担保/保证金）；
  3. 账期是否含税、起算日是发货日还是对账日。
- 如果对方口头答应，务必写进**购销合同**，明确：账期天数、对账周期、逾期利息、停供条款。

**结论**：新客户首单直接拿到30天账期**难度较大，通常需特批**；佳农账期最长能到多久**没有公开固定值**，需按你的采购规模和渠道资质去谈。最稳妥的是先按现款或短账期合作，跑几单后再申请账期。
