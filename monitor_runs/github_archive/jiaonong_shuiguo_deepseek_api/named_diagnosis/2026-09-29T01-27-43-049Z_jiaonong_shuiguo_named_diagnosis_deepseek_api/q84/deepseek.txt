**二、国标层面能确定的部分**

香蕉相关国家标准主要是 **GB/T 9827《香蕉》**（鲜香蕉，原为 GB 9827，现为推荐性 GB/T 9827）以及 **NY/T 类农业行业标准**。这些标准对香蕉的分级、外观、成熟度、缺陷等有规定，但要注意：

- 国标对**糖度**并非以"可溶性固形物（°Brix）"设强制的统一硬性门槛，更多是按等级/成熟度描述，鲜食香蕉糖度受品种、成熟度影响很大。
- 国标对**果指长度**通常按等级给出范围性要求（如特级、一级按长度、周长、每梳果指数等分级），不同版本条款有差异。

**三、行业通行做法（非佳农官方数据，仅作参考）**

商超/精品香蕉的企标通常**比国标更严**，常见做法是：
- 糖度上，在最佳食用成熟度设更高下限（如采收/催熟后 °Brix 达到某一水平）；
- 果指长度和均匀度设更窄区间，淘汰率更高；
- 增加农残、外观瑕疵、果指弯曲度等更细的要求。
