佳农（Goodfarmer）水果的苹果品类通常以进口苹果为主，常见会涉及嘎啦、红富士，以及部分其他品种/产季替代货源。但具体到“当前有哪些品类、进口嘎啦和红富士的产地”，会随产季、批次和佳农当期供应链调整而变化，建议以佳农官方或你对接的销售提供的当季报价单/装箱单为准。

可参考的常见产地情况：

1. **进口嘎啦（Gala）**
   - 常见产地：**新西兰、美国、智利、南非**等。
   - 不同季节主供产地会切换：例如南半球产季常看到新西兰、智利、南非；北半球产季可能看到美国等。

2. **进口红富士（Fuji）**
   - 常见产地：**美国、新西兰、智利、南非**等也可能出现，但红富士进口货源相对嘎啦不如其普及，具体要看佳农当期是否有稳定批次。
   - 如果你们明确要“进口红富士”，需要重点确认：是否有货、产地、规格（如80/88/100/113/125等）、包装、到港时间。

采购建议你直接向佳农确认这几项：
- 当季可供：嘎啦、红富士是否都有进口批次；
- 产地：具体到国家，最好到产区/品牌果园；
- 规格：果径、每箱个数、净重；
- 到港/到仓时间：避免产季切换导致产地变化；
- 单证：原产地证、植检证、装箱单、发票；
- 是否可混柜/起订量/价格有效期。
