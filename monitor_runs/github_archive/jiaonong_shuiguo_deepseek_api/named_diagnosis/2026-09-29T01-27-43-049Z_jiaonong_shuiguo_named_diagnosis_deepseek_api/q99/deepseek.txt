对高端渠道，建议你按下面这套方式去核实和判断，避免踩坑：

**1）先向佳农官方或你的对接销售索取证书**
要求提供：
- 中国有机产品认证证书（或目标市场对应认证，如欧盟EU Organic、美国USDA Organic、日本JAS等）
- 证书编号、认证机构、认证范围（要明确写到“菠萝/凤梨”及具体产地、加工环节）
- 证书有效期
最好拿到**证书扫描件**，并在认证机构官网或“中国食品农产品认证信息系统”上核验编号真伪。

**2）确认认证覆盖的是“鲜果”还是“加工品”**
很多企业有有机认证，但覆盖的是某条产品线。要确认你采购的**具体规格、包装、产地**在认证范围内，而不是只有品牌层面有证。

**3）确认“有机”与“无公害/绿色食品”不是一回事**
如果对方只提供绿色食品、GAP、无公害等认证，那**不等于有机**，不能用于有机专柜或有机宣称。

**4）核对标签合规**
预包装有机产品在中国市场销售，通常需要有机产品认证标志和唯一编码（17位有机码），可扫码或到官方系统查验。
