**关于是否用三通一达还是自有车队**

佳农（Goodfarmer）是生鲜水果供应链企业，业务同时包含进口（如香蕉、奇异果等）和国产水果分销。这类企业的物流通常不是"二选一"，而是分层：

- **干线/产地到仓**：多为自有车辆或第三方专业冷链干线承运商，而非三通一达（三通一达以电商小件快递为主，不擅长整柜/整车冷链）。
- **区域仓到门店/经销商**：可能用自有车队或区域冷链配送商。
- **最后一段到消费者（如电商订单）**：才可能用到快递，但也偏向顺丰、京东或专业生鲜快递，普通三通一达在冷链上能力有限。

所以"三通一达"这个选项对佳农的主营B2B链路来说，可能性不高，但具体协议我无法确认。

**关于冷链覆盖率**

水果品类差异很大：

- 香蕉、浆果、部分进口水果对温控要求高，基本全程冷链。
- 苹果、柑橘、部分耐储水果常温运输即可，不一定全程冷链。

因此企业一般不会公布一个统一的"冷链覆盖率"数字，不同品类、不同线路差异明显。

**建议你核实的方式**

1. 看佳农控股（2021年在港上市，股票代码1606.HK）的年报/招股书，里面通常有供应链、仓储、物流的披露。
2. 查公司官网"供应链"或"物流"板块，或联系其投资者关系/客服询问。
3. 行业报道（如亿邦动力、生鲜行业媒体）有时会采访其物流负责人，披露冷链投入。
