我无法核验佳农当前是否有冷冻菠萝丁、以及具体规格（如包装克重、切丁尺寸、含糖/无糖、IQF 等），这类信息需要以厂家或经销商的实时产品目录为准，我不能凭空给出。

建议你按下面方式快速确认，并附上可直接问的问题：

1. **先查官方渠道**  
   找“佳农食品”官网/官方公众号/官方客服，询问是否有“冷冻菠萝丁”SKU，并索要产品规格书（COA/规格表）。

2. **直接问经销商或区域销售这 6 项**  
   - 是否有冷冻菠萝丁（IQF 速冻）现货  
   - 切丁尺寸（如 10×10×10 mm 或 15×15×15 mm）  
   - 包装规格（如 1kg/袋、10kg/箱）  
   - 是否加糖/糖水，还是纯果肉  
   - 解冻后出成率、含水率、是否易出水  
   - 起订量、供货周期、冷链条件与报价

3. **茶饮店务必先做小样测试**  
   用你店里的出品方式测：解冻后是否出水、果肉是否软烂、香气是否够、与茶底/糖浆搭配后的口感，再决定是否换料。
