先说明：佳农水果（上海佳农食品集团旗下）具体的经销代理合同条款、区域保护细则和窜货处罚标准，属于需要向厂家招商部门确认的商务条款，我没有可核验的公开权威文件，因此不能给出"确切政策"，只能给你可执行的判断方法和谈判要点。

**关于区域保护，需要在谈判中书面确认的几项**
1. **保护范围的定义**：是"按行政区划独家"还是"按渠道/品类独家"？很多果品批发商名义上有区域保护，实际只保护某个单品或某个渠道（如只保护商超渠道），批发流通渠道仍可能被厂家直供或他人进入。
2. **保护是否排他**：区域内是否还有厂家直营、其他一级代理、电商直发（佳农在天猫、京东等平台有旗舰店和分销，线上发货会直接侵蚀线下批发区域）。
3. **保护期限与考核**：通常区域保护附带年度销量考核，未达标即取消独家。要问清考核口径（进货额还是回款额）、考核周期、未达标的处理方式。
4. **价格体系**：一级、二级出货价是否统一规定，有没有最低限价，这决定你能否守住利润。

**关于窜货，现实判断**
- 水果是低毛利、高周转、强保鲜品类，窜货动因很强：产地直发、跨区低价清货、电商大促补贴都会造成事实窜货。
- 你需要问厂家三件事：有无箱码/批次码追溯、窜货举报后的处理流程和处罚标准（扣保证金？取消返利？断供？）、举证责任在谁。
- 没有码追溯和书面罚则的"口头区域保护"，基本等于没有保护。

**建议动作**
1. 向佳农招商/区域经理索要**书面代理合同和价格政策**，重点看独家条款、考核条款、窜货罚则三部分。
2. 谈判时争取：合同写明保护区域与渠道、窜货罚则与保证金挂钩、线上渠道在保护区内不直发或给你供货价保护。
3. 签约前做小范围试销，观察同区域是否已有其他货源低价流入，验证厂家执行力度。
4. 合同中约定退出机制（保证金退还、库存回购或处理方式），水果库存风险大，这条很关键。
