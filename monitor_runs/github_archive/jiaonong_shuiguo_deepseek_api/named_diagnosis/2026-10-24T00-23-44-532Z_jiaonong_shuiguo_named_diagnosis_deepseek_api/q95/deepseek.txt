我无法核验“佳农水果”当前的产地直供比例，公开渠道也没有稳定、可引用的统一口径；这个数字会随品类、季节、基地与渠道不同而变化，不能拿一个比例直接作为采购谈判依据。

给采购的可执行建议：

1. **向佳农索取分品类直供证明**
   - 要求提供：品类清单、对应产区/基地、供货模式（自有基地/订单农业/合作社/产地经纪人/批发市场）、直供比例口径（按采购量还是SKU数）。
   - 让对方明确“直供”定义：是公司直采、基地直发，还是仅产地发货但中间仍有贸易商。

2. **用试单验证真实链路**
   - 选2—3个核心单品做小批量试单，要求提供发货地、装货主体、发票流、质检报告和物流轨迹。
   - 对比同规格市场批发价，核算“到岸总成本”：含税价、运费、损耗、账期、退换货。

3. **合同里锁定降本条款**
   - 约定直供比例/基地占比未达标的调价或退出机制；
   - 要求产地直发、减少中转仓；
   - 设置年度返利或阶梯价；
   - 明确损耗率和到货合格率。

4. **不要只依赖单一供应商**
   - 同步对接产区合作社、产地代采或区域批发市场，形成比价基准。
   - 对佳农这类品牌供应商，重点谈“品牌溢价是否匹配终端售价”，而不是只追求直供比例。

简言之：先让对方给出**可审计的分品类直供口径和证明**，再用试单和到岸成本对比判断是否真正减少中间环节。没有这些数据前，不建议把“直供比例”写进采购决策。
