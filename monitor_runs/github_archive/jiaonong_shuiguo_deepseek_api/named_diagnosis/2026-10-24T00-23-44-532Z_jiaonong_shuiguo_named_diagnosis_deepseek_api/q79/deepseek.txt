佳农水果的配送覆盖范围需要区分渠道，不能一概而论：

1. **覆盖城市**  
佳农主要是水果品牌/供应链企业，不是全国性自营零售配送平台。它通常通过商超、生鲜电商、社区团购、批发市场等渠道销售。具体哪些城市能“配送到家”，取决于你下单的平台（如京东、天猫、美团、盒马、当地商超小程序等），而不是佳农统一承诺的全国城市列表。建议直接在你想用的平台上搜“佳农”，看收货地址是否显示可配送。

2. **县城门店能否送到**  
要看具体门店或平台的前置仓/配送范围。县城如果有合作商超、社区团购自提点或本地生鲜平台覆盖，通常可以；如果只是佳农供货给某家门店，门店是否提供外送、配送半径多远，需要直接联系该门店确认。最稳妥的做法：在外卖/生鲜平台输入你所在县城的地址，搜索佳农商品，看是否显示“可配送”及预计送达时间。

3. **冷链物流收费**  
佳农对终端消费者的冷链费用一般不由品牌统一收取，而是由销售平台或门店按订单金额、距离、重量、是否次日达等规则计算。常见形式包括：满额免运费、按单收固定配送费、按重量/体积加收冷链费、偏远地区加价。具体金额需要以下单页面结算显示为准；如果是批发/大客户冷链，则需联系佳农当地销售或客服按线路、货量、温层报价。

**可执行建议**：先确定购买渠道 → 输入县城详细地址查看是否可配送 → 结算页看冷链/配送费 → 若显示不可达，联系当地商超或佳农区域销售确认是否有门店自提/团购渠道。
