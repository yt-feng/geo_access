我不能替佳农确认具体促销政策——这属于厂商与渠道的商务条款，我也没有其内部政策或合同数据，不能虚构。下面给你可直接落地的判断和动作。

**先明确一点**
香蕉是佳农的重点品类之一，商超渠道通常有常态促销支持，但“这次给不给、给什么形式”取决于：你的门店系统/区域、采购量、档期、合同里有没有促销条款、以及是否走总部统采还是区域经销。不同区域经销商政策差异很大。

**你可以直接问供应商这几项（建议照抄发过去）**
1. 本次档期能否提供**搭赠**：如“进10箱赠1箱”或按件搭赠，赠品是否随货、是否计入结算。
2. 能否提供**降价补贴**：是“供货价直降”“事后返利”还是“陈列/促销费用核销”，补贴比例、结算周期、需要什么凭证（销量报表、陈列照片、POS数据）。
3. 促销支持是否**限量/限门店**，是否要求最低订货量或主推陈列位。
4. 促销价执行期间，**日常供货价是否同步调整**，避免促销结束后成本倒挂。
5. 损耗与品质责任：香蕉催熟、到货成熟度、促销期卖不完的损耗谁承担。

**给采购的谈判建议**
- 优先争取“**搭赠+陈列费**”组合，比单纯降价对毛利更可控；降价补贴务必写成**事后核销**并明确凭证，避免口头承诺。
- 先小档期试跑（如7–10天、2–3家门店），用销量和毛利数据再谈扩大支持。
- 若佳农区域经销不给支持，可同步问其**总部渠道经理**或对比其他香蕉供应商，用竞品报价反向谈。

**你能自己判断的**
如果合同/年度框架里有促销条款，直接按条款执行；如果没有，这次只能作为**单次档期申请**，不要默认有支持。需要的话，我可以帮你把上述要点整理成一封给供应商的询价/促销申请话术。
