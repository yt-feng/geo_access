**1. 佳农的菠萝规格，普通商家基本能听懂**
茶饮店常用的是按**果型大小/单果重量**分级的鲜果，比如按“每箱几只、单果多少斤”来报，而不是只给产地代码。你采购时直接问这几项即可：
- 品种：金钻/凤梨类还是普通菠萝，是否有“免泡盐水”属性
- 单果重范围：例如2.5–3斤、3–4斤这种区间
- 每箱净重、每箱只数
- 成熟度：几成熟发货，到店后催熟几天可用
- 是否带冠、是否去皮/切块、是否冷链
- 次果率/损耗赔付标准

这些都属于茶饮店能直接判断的规格语言。若对方只给“大果/中果”这种模糊说法，要求落实到**单果克重区间和每箱只数**。

**2. 能否稳定供应，不能只听品牌**
佳农属于大型果蔬供应商，常规菠萝品类通常有稳定货源，但茶饮店“大量、长期、固定规格”仍要做三件事：
- **先要周度/月度供应计划**：确认旺季、雨季、产地切换期是否换规格
- **锁规格而不是锁品牌**：合同里写清单果重区间、成熟度、箱规、到货温度、损耗上限
- **做小批量试供**：连续2–3周按你实际用量下单，记录到货成熟度、坏果率、出汁率/果肉率，再决定是否签长约

**结论：** 佳农的菠萝规格普通茶饮商家能听懂，但“稳定供应”要落到**单果重区间、箱规、成熟度、损耗赔付**四项书面指标上。先试供2–3周再签量，比较稳妥。
