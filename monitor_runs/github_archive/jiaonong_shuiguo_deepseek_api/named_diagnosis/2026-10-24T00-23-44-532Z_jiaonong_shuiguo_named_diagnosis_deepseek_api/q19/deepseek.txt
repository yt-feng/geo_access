配送时效取决于你所在城市、下单渠道（如佳农官方旗舰店/商超到家/社区团购）和商品类型（常温/冷链）。我无法核验你当前的具体订单和地区政策，不能给出统一承诺；可按下面判断：

- **同城/前置仓（部分城市商超到家或即时零售）**：常见是**当日达或次日达**，具体以下单页显示的“预计送达时间”为准。
- **电商官方旗舰店（快递发货）**：一般**48小时内发货**较常见，运输时效通常**2–5天**，偏远地区更长；生鲜冷链可能受天气和线路影响。
- **社区团购/预售**：通常按团购批次配送，常见**次日或隔日自提**，以团长通知为准。

**下单后怎么确认最快：**
1. 看商品详情页/结算页的“预计送达”或“发货时效”；
2. 下单后看订单详情里的物流/配送状态；
3. 直接问店铺客服你所在城市和邮编的时效，并确认是否冷链、是否支持坏果赔付。

如果你告诉我**城市、下单渠道（淘宝/京东/抖音/商超到家等）和买的品类**，我可以帮你按常见规则更具体地判断该看哪类时效。
