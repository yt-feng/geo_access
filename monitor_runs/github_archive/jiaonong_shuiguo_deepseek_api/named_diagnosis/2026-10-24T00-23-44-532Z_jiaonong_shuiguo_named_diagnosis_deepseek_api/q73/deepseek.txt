佳农（Goodfarmer）的水果业务里，苹果品类通常以进口和国产分开运作。**我没法核验佳农当前在售的完整苹果SKU清单**，所以不能给你一份“官方品类表”。但就你提到的采购方向，可以按下面判断：

**1. 品类层面**
佳农苹果常见会覆盖：
- 嘎啦（Gala）
- 红富士（Fuji）
- 有时还会有青苹果/格兰尼史密斯、爱妃、爵士等小众品类（是否在售随季节和渠道变化）

**2. 进口嘎啦的产地**
进口嘎啦主要来自：
- **新西兰**（常见，南半球反季节供应）
- **美国**（华盛顿州等）
- **智利**（南半球季节）
- 南非、法国等也可能有，但要看具体批次和渠道。

**3. 进口红富士的产地**
进口红富士相对少，常见来源：
- **新西兰**
- **美国**
- **智利**
- **日本**（量少、价高，商业采购不常见）

**采购建议：**
- 直接向佳农官方销售/区域经销询价时，要求提供**当季可供货的产地、品种、规格、包装、到港/到仓时间**，因为进口苹果产地随季节切换很明显。
- 嘎啦重点问**新西兰/美国/智利**；红富士重点问**新西兰/美国/智利**，并确认是“进口红富士”还是“国产红富士”。
- 要求提供**原产地证、植检证、报关单**，以核验进口身份和产地。
