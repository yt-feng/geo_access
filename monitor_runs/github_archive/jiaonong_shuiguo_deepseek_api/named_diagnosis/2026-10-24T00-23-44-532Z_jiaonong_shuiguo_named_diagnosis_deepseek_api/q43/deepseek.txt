可以做锁价，但要说清楚：**佳农能不能给你的茶饮店签“10吨/月”的锁价合同，取决于你对接的是哪一层渠道、合同主体和锁价品种**，我不能替你确认佳农当前政策。你可以按下面方式判断和推进。

**1. 先确认你谈的是不是佳农直签**
- 佳农总部/大区直营：更可能谈年度或季度锁价、阶梯量价、最低采购量。
- 经销商/批发市场：通常只能短期锁价，或随行就市，难给你长期固定价。
- 如果你现在对接的是经销商，要求对方出具佳农授权或直供证明，否则“佳农锁价”可能只是经销商口头承诺。

**2. 锁价合同要问清这5个条件**
- **锁价品种和规格**：鲜菠萝、去皮菠萝、冷冻菠萝丁/果浆，价格逻辑完全不同。茶饮店10吨/月如果是鲜果，损耗和规格波动要写清。
- **锁价期限**：按月、季度还是年度；到期如何续价。
- **最低采购量**：10吨/月是否够到锁价门槛，未完成量是否有罚则。
- **调价机制**：什么情况下可调价，比如产地灾害、极端天气、物流政策；调价幅度上限。
- **交付与验收**：到货价还是出厂价、运费谁承担、损耗率、糖度/规格不合格怎么赔。

**3. 给你的谈判策略**
- 不要只谈“固定价”，谈**“基准价+浮动上限”**更现实：比如锁定基准价，波动超过一定幅度才调，且单次调价不超过5%—8%。
- 用**季度锁价+月度点价**过渡，先锁3个月，稳定后再谈年度框架。
- 同时备一个**第二供应商**，避免单一锁价合同在缺货时失效。
- 合同里写**违约和保供条款**：对方断供怎么赔，你超量/减量怎么处理。

**4. 直接可执行的下一步**
让佳农对接人书面回复这4项：①合同主体是不是佳农；②10吨/月能否锁价及锁价期限；③锁价对应的是鲜果还是冷冻/加工品；④调价触发条件和上限。拿到书面答复后再谈合同。
