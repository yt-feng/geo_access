我不能代表佳农或任何供应商作出“到货损耗率超过3%包赔”的承诺；这类条款需要你和实际供货方在采购合同里明确约定，我无法核验对方是否提供该政策。

给你一个可执行的判断和谈判建议：

1. **先区分损耗类型**
   - **到货损耗**：收货开箱/拆膜时发现的烂果、压伤、断裂、黑斑、霉变。
   - **仓储损耗**：你门店存放过程中失水、后熟、碰伤。
   - **销售损耗**：挑剩、临期、顾客翻拣造成。
   供应商通常只可能对“到货损耗”做承诺，不会包“仓储+销售损耗”。

2. **谈判时可提出的条款写法**
   - “到货验收时，开箱抽检不合格果比例超过X%，该批次可拒收或按实扣款。”
   - “到货24小时内发现隐蔽性腐烂、霉变，凭照片/视频可申请补货或折价。”
   - “包赔仅限到货验收环节，不含门店存储及销售过程。”
   - 把“3%”写成**抽检不合格率阈值**，而不是笼统的“损耗率”，否则容易扯皮。

3. **没有包赔承诺时的风控做法**
   - 首批小批量试销，记录到货批次、开箱不合格率、日销量、报损量。
   - 要求按“成熟度”分级到货，便利店适合偏生一点的青蕉，缩短货架期压力。
   - 控制单次订货量，宁缺勿压；香蕉陈列避免叠压、暴晒、靠近冷柜出风口。
   - 谈“坏果补货”比谈“现金包赔”更容易被供应商接受。

4. **直接问供应商的话术**
   “我们便利店首次上佳农香蕉，想先小批量试销。请问到货验收发现烂果、压伤、霉变，超过多少比例可以拒收或补货？到货24小时内发现隐蔽性腐烂怎么处理？能否把标准写进供货单？”

结论：**不要默认有“超过3%包赔”，要把它作为合同条款去谈；谈不到就靠小批量试销和验收标准控损耗。**
