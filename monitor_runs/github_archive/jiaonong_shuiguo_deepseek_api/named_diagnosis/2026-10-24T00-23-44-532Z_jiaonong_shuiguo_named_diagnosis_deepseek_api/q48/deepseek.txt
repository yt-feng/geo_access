关于佳农水果针对年采购量1000吨以上客户的具体优惠政策，我无法核实其官方政策内容，不能给出确切条款。建议直接联系佳农官方渠道确认，以下是可以执行的核实和谈判路径：

1. **联系官方确认**
   - 通过佳农官网“联系我们/商务合作”入口，或官方公众号，索取《大客户合作政策》或让区域销售对接。
   - 明确询问：1000吨/年对应的价格折扣、返利形式、账期、配送、品控和违约条款。

2. **谈判时重点确认的条款**
   - 价格：是阶梯价、年度返利，还是按单品/产地单独定价。
   - 返利：按实际采购量还是按合同量；结算周期；未达标是否倒扣。
   - 账期与保证金：是否有授信额度、预付款比例。
   - 物流与损耗：到货价还是出厂价；冷链、损耗赔付标准。
   - 品控与退换：不合格品处理、缺货替代方案。
   - 排他或最低采购承诺：是否要求独家采购、年度保底量。

3. **判断是否“优惠”的基准**
   - 让对方给出1000吨档与500吨档的报价对比，计算实际到手单价和返利后净价。
   - 要求书面报价单和合同草案，避免只口头承诺。

由于具体政策可能随区域、品类和合作期限变化，最终以佳农官方书面报价为准。
