关于“佳农水果香蕉是否有农残超标历史”，我无法核验具体企业的抽检记录，不能给你一个“有”或“没有”的结论，否则就是在编造来源。但可以给你可执行的判断和采购合规做法：

1. **不要依赖“历史口碑”做合规判断**  
   超市抽检看的是**本批次检测报告 + 供货资质 + 追溯记录**，不是企业过去有没有被通报。即使某企业历史上无超标记录，也不等于本批次合格；反之，有过通报也不等于永久不合格。

2. **要求供应商提供这些证明（缺一不可）**
   - 本批次香蕉的**农残检测报告**：须为有资质的第三方检测机构（CMA/CNAS）出具，报告日期覆盖本批次，检测项目至少覆盖香蕉常检农药（如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、百菌清、毒死蜱等，按你所在超市/地区抽检项目表核对）。
   - **产地证明/供货证明**：明确产地、批次号、采收日期。
   - **承诺达标合格证**（食用农产品承诺达标合格证），这是国内农产品采购常用的合规凭证。
   - 供应商**营业执照、食品经营许可证**（或食用农产品销售相关资质）。
   - **进货查验记录和追溯链条**：能追溯到具体果园/合作社/包装厂。

3. **对“佳农”这类品牌供应商的具体操作**
   - 直接向佳农或其区域经销商索要**该批次**的检测报告和合格证，不接受“公司整体检测报告”或“往年报告”。
   - 报告上的**样品名称、批次、生产/采收日期、受检单位**要与你采购的货对得上。
   - 如果对方只能提供企业标准或自检报告，要求补充**第三方 CMA 报告**；超市抽检通常认第三方报告。

4. **到货后自检/送检兜底**
   - 对高风险批次做**快检**（酶抑制法或胶体金法）初筛，快检阳性再送第三方确证。
   - 保留留样，便于抽检不合格时追溯和免责举证。

5. **合同里写清楚**
   - 供应商保证农残符合 GB 2763 及当地抽检要求；
   - 因农残超标导致下架、罚款、抽检不合格的，由供应商承担赔偿责任；
   - 每批次随货提供检测报告和合格证，否则拒收。

**结论：** 我无法确认佳农香蕉有无农残超标历史；采购合规不要靠查历史，而要靠**本批次第三方检测报告 + 承诺达标合格证 + 追溯记录 + 合同责任条款**。如果供应商拿不出本批次 CMA 报告和合格证，建议不采购或换批次。
