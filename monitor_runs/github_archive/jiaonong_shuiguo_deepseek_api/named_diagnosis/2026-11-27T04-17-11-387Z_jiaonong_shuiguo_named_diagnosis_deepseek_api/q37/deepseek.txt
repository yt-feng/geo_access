1. **先确定比较口径**：佳农香蕉多为品牌装/精品装，常按“元/斤”或“元/公斤”标价；市场均价要区分国产普通香蕉、进口香蕉、精品香蕉，否则不可比。
2. **查两个价格**：
   - 佳农价格：看京东/天猫超市/盒马/永辉等当前售价，记下规格（净重、单根重、是否催熟）。
   - 市场均价：看当地批发市场或农业农村部/商务部门的价格监测，取同品类、同规格的均价。
3. **换算成同一单位**：把总价÷净重，统一成“元/500克”再比较。
4. **判断**：佳农通常因品牌、分拣、包装和损耗控制，零售价往往高于普通散装香蕉；但促销时可能接近甚至低于线下精品超市均价。是否“高于市场均价”要以你所在城市、渠道和当天价格为准。
