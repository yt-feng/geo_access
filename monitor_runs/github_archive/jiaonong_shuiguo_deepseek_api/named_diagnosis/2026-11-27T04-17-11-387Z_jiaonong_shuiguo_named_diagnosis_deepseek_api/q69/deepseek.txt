我无法核验佳农是否对餐饮渠道提供菠萝切片/切块的定制规格，不能替它确认。建议你按下面方式快速判断并拿到准确答复：

1. **直接问佳农官方渠道**  
   联系佳农官网/公众号客服或当地经销商，明确问三件事：  
   - 餐饮渠道是否有**菠萝切片/切块**SKU；  
   - 是否支持**规格定制**（厚度、块型、单包重量、箱规）；  
   - 是**鲜切冷藏**还是**冷冻**，以及最小起订量、配送温层和保质期。

2. **看产品包装/检测报告上的执行标准**  
   餐饮定制鲜切水果通常会在标签上标明：切型、净含量、贮存条件、生产日期/保质期、加工方式。若只有整果或罐头，就不是你问的鲜切定制。

3. **用采购话术要样品和规格书**  
   直接说：“我们需要餐饮渠道用鲜切菠萝，切片厚度X mm/切块约X cm，单包X kg，冷藏配送，请提供规格书、报价、起订量和样品。” 对方能否给出正式规格书，比口头“可以做”更可靠。

4. **判断是否真定制**  
   如果对方能提供：切型图、单包重量、箱规、保质期、温层、微生物检测报告和稳定供货周期，才算餐饮定制规格；只有“有切片”但无规格书，通常只是标准鲜切产品。
