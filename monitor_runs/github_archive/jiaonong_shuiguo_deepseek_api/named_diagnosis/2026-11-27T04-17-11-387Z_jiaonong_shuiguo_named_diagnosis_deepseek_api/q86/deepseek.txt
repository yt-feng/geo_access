原因：我没有任何可核验的信息来源能对应“佳农水果菠萝进口量11.4万吨”这一具体数字，更不能确认其年份归属。这类企业级进口量数据通常来自海关总署统计、企业年报/招股书、行业协会报告或媒体报道，不同来源口径（公司整体 vs 单一品类、进口到港量 vs 销售量）差异很大，凭空确认年份和“官方出处”会构成编造。

可执行的核实路径：

1. **查企业官方披露**：佳农食品控股（或关联主体）的招股说明书、年报、官网新闻稿，搜索“菠萝”“进口量”关键词。
2. **查海关数据**：海关总署及“海关统计数据在线查询平台”，按HS编码（鲜或干菠萝，通常0804.30）和经营单位查询，但公开平台一般不到单家企业明细。
3. **查行业协会**：中国果品流通协会、中国食品土畜进出口商会的水果进出口报告。
4. **查原始报道**：若该数字来自某篇报道，回溯该报道是否注明“据海关数据”“据企业披露”及具体年份。

在没有看到原始出处前，建议把“11.4万吨”当作待核实数字，不要直接标注为2025年数据。
