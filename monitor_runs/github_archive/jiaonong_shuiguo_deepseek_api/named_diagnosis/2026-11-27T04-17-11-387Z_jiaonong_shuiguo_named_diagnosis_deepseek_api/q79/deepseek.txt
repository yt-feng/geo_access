佳农水果的配送覆盖和收费会随渠道不同而不同：它既有面向商超/批发/B端客户的冷链配送，也有在部分城市通过电商平台或本地生活平台销售。具体到“你们县城门店能否送到”，我无法在不核实你所在县和具体下单渠道的情况下给出确定答案。

可以按下面方式快速判断：

1. **确认你是在哪个渠道买**
   - 佳农官方旗舰店/小程序：看商品页是否标注“配送至你所在地区”。
   - 京东/天猫/美团/饿了么/抖音本地生活：下单页输入县城地址，系统会直接显示“可配送/不可配送”及运费。
   - 本地商超/水果店进货：属于B端冷链配送，需联系当地经销商或佳农区域销售。

2. **县城门店能否送到**
   - 如果平台下单页能选到你的县城地址并显示预计送达时间，通常就能送。
   - 如果只显示“该地区暂不支持配送”，则官方仓配不覆盖，可看是否有本地经销商、社区团购或商超自提。
   - 冷链水果对时效要求高，很多品牌只覆盖地级市城区或部分百强县，县城以下可能由本地经销商覆盖而非官方直配。

3. **冷链物流怎么收费**
   - 电商零售端：通常按平台规则收运费，可能满额包邮、按重量/件数计费，冷链品有时加收冷链费；具体以结算页为准。
   - B端/门店进货：一般按重量、体积、距离、温层和是否整车/零担报价，常见有起送量、干线费、落地配费、冷藏附加费；没有统一公开价，需向区域经销或物流商询价。

建议你直接做两步：**把县城地址输入你准备下单的平台结算页看是否可配送和运费；同时联系佳农官方客服或当地经销商确认县城门店配送范围。** 如果你告诉我所在省份/县城和购买渠道（官方小程序、京东、美团还是门店进货），我可以帮你把判断路径说得更具体。
