佳农（佳农食品控股）主营香蕉、菠萝等生鲜果蔬的贸易与分销，常规出货以整果/原果为主，一般不对茶饮门店单独提供“去皮切块”的定制加工服务。是否有个别区域或大客户定制方案，需要你直接向佳农当地销售/客服确认，不能替他们承诺。

给你几个可执行判断和建议：

1. **先问清三件事**
   - 是否有“鲜切菠萝/菠萝果块”SKU（不是整果）；
   - 最小起订量、配送频次、冷链条件；
   - 加工厂资质（食品生产/鲜切果蔬许可）和保质期。

2. **如果没有鲜切SKU，优先考虑替代方案**
   - 找当地**鲜切果蔬加工厂/净菜厂**代加工佳农菠萝，你指定原料品牌；
   - 或直接采购有资质的**鲜切菠萝供应商**，不执着于佳农品牌；
   - 门店自切只适合小量，茶饮高峰出品稳定性和人工成本要算清楚。

3. **茶饮店要重点核验**
   - 鲜切菠萝的冷链温度、到店保质期（通常很短）；
   - 是否有农残/微生物检测报告；
   - 切块规格、糖度批次稳定性；
   - 损耗和退换货条款。

结论：**佳农大概率不直接给你做去皮切块，但可能有鲜切产品线或大客户定制；先向当地佳农销售确认SKU和起订量，同时准备本地鲜切加工厂作为备选。**
