关于“佳农水果产地直供比例”，公开渠道没有可核验的统一官方数字；这类比例通常按品类、季节、渠道和统计口径变化，不建议直接引用某个固定百分比。若你们采购要减少中间环节、降低成本，可按下面方式推进。

**1. 先向佳农方面确认口径**
直接问供应商或对接业务员，要求书面说明：
- “产地直供”定义：是产地直采到佳农仓，还是产地直发客户，或仅指一级代理？
- 分品类直供比例：香蕉、菠萝、火龙果、苹果、葡萄等分别多少；
- 分渠道比例：商超、电商、批发市场、餐饮客户分别多少；
- 统计周期：年度、季度还是产季；
- 是否含进口水果海外产地直采。

没有这些口径，“直供比例”数字很容易被营销化。

**2. 采购降本的可执行做法**
- **要求分品类报价拆解**：产地价、加工包装费、冷链仓储费、干线运输费、损耗、服务费、账期成本分别列明。
- **尝试产地仓直发**：对耐储品类如苹果、梨、柑橘、土豆等，谈“产地仓—区域 DC”或“产地仓—门店”直发，减少一级批发。
- **集中单品做规模**：不要全品类同时压价，选1—2个高销量单品做直采试点，用实际数据谈年框。
- **对比替代渠道**：同步询产地合作社、区域一级批发商、大型连锁商超自有供应链，形成比价基准。
- **把损耗和账期算进总成本**：直采若损耗高、起订量大、账期短，名义采购价低也可能不省钱。
- **设置试单指标**：到货合格率、损耗率、缺货率、平均到岸成本、周转天数，试单1—2个月再决定是否扩大。

**3. 判断是否真的减少了中间环节**
看合同和货流，而不是听“直供”说法：
- 发票流：谁开票、什么税率、是否产地公司直开；
- 货流：发货地是否为产地仓或佳农区域仓；
- 资金流：是否经过多级经销商；
- 质检与售后：谁承担产地质检和到货售后。

**建议话术**：  
“我们希望按品类了解贵司产地直采/直发比例及统计口径，并请对目标单品提供从产地到我们仓的全链路成本拆解和直发方案。若直供比例无法提供，请提供产地仓发货证明、分品类供货链路和试单报价。”
