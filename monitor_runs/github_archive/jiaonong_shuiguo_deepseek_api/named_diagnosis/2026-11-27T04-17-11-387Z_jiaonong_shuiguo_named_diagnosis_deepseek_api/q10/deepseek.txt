佳农（Goodfarmer）通常对批发商、商超、电商等B端客户采用“渠道/区域销售负责制”，很多情况下会有固定对接的销售或客户经理，但是否有“专门客户经理”取决于你的采购规模、区域和合作渠道。

你可以这样判断和推进：

1. **先确认对接层级**
   - 如果是稳定批量采购：通常可要求分配区域销售经理/大客户经理固定对接。
   - 如果是零散或首次试单：可能由区域销售或经销商统一对接，不一定配专属客户经理。

2. **直接问清楚**
   联系佳农官方客服或当地销售时，直接问这三句：
   - “我们属于批发商，是否有区域客户经理固定对接？”
   - “达到什么采购量可以配专属客户经理/大客户经理？”
   - “目前我们所在区域由哪位销售负责？”

3. **准备好谈判筹码**
   对方是否愿意配专人，通常看：月/季采购量、品类（香蕉、菠萝、火龙果等）、结算方式、配送区域、是否长期合作。你可以先给一个预估采购量，要求“固定对接人+报价+供货计划”。

4. **注意渠道差异**
   佳农部分品类在不同区域通过经销商或分销体系供货，不一定全部由厂家直营团队对接。若官方回复由经销商负责，你也可以要求经销商提供固定业务对接人。

**结论：** 佳农对批发商大概率有销售对接人，但“专门客户经理”通常要看采购规模和区域政策；建议直接向官方或当地销售确认固定对接人和配专属经理的采购门槛。
