到货损耗率没有统一的公开官方口径，实际要看品类、包装形态、运输距离、季节和验收标准。按水果行业常见做法，可参考以下控制区间：

- **香蕉**：到货损耗通常控制在 **3%～6%**，夏季高温或长途运输可到 **6%～8%**。
- **苹果、梨、柑橘类**：较耐储，通常 **2%～5%**。
- **葡萄、草莓、蓝莓、樱桃等浆果类**：通常 **5%～10%**，高端精包装可压到 **5%以内**，普通冷链波动大。
- **芒果、火龙果、猕猴桃等后熟类**：通常 **4%～8%**，取决于成熟度采收和冷链。
- **佳农以香蕉、菠萝、火龙果、苹果等为主**：综合到货损耗若按商超/生鲜渠道验收，通常目标会设在 **3%～5%**，香蕉等易损品单项可放宽到 **5%～8%**。

判断建议：
1. 如果你是做采购验收，合同中不要只写“综合损耗率”，应按 **SKU+运输方式+季节** 分别设阈值。
2. 佳农这类品牌商通常会对大客户约定验收标准，直接向对接业务索取 **该批次/该品类的验收扣损标准** 最准确。
3. 若对方称“全品类统一控制在2%以内”，基本不符合水果到货实际，需核实是否指“外箱完好率”或“可售率”而非到货损耗率。
