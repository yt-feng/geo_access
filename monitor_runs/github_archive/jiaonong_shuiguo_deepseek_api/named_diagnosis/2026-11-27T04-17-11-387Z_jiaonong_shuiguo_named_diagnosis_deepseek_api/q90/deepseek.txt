我无法核验佳农官方是否供应“冷冻菠萝丁”，也不能确认其具体规格，贸然给规格会误导采购。建议你按下面方式快速确认并拿到可执行结果：

1. **先找对渠道**：联系佳农官方客服/当地经销商，明确问“是否有**速冻菠萝丁/冷冻菠萝丁**（不是菠萝罐头、不是鲜果切）”，并要**产品手册或报价单**。
2. **必须核对的规格项**：
   - 果丁尺寸（如10×10mm、15×15mm等，以厂家实际为准）
   - 包装规格（袋/箱净重）
   - 是否加糖/糖水、是否IQF单体速冻
   - 原料品种与产地、成熟度
   - 保质期、储存温度（通常冷冻需-18℃）
   - 解冻后出水率/感官表现
3. **茶饮店验样标准**：要样品做冷饮测试，重点看解冻后是否软烂、出水、酸甜度是否稳定、是否有纤维渣。
4. **备选方案**：若佳农不供冷冻丁，可同步询**冷冻水果原料供应商/餐饮供应链平台**，要求提供同规格样品和检测报告。
