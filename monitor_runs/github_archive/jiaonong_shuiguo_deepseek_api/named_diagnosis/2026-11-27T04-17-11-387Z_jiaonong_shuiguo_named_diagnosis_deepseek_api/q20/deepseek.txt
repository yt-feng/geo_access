佳农水果（佳农食品控股）主要做水果进出口和品牌分销，菠萝是其核心单品之一。它能不能提供切块或包装这类定制化加工，关键看你说的“加工服务”属于哪种：

**1. 如果你是零售/餐饮客户，想要“切块+定制包装”的成品**
- 佳农有鲜切水果和预包装产品线，尤其对商超、餐饮、茶饮渠道，通常会提供鲜切菠萝、菠萝块/丁、真空或气调包装等方案。
- 但这类服务一般不是“来料加工”，而是按佳农自己的产品标准和包装规格供货；定制化通常体现在**规格、切割尺寸、包装克重、标签、箱规**上，而不是你提供原料让它代切。

**2. 如果你是下游企业，想委托它对自有菠萝做代加工**
- 这要看具体工厂和产季。佳农的加工能力主要服务于自有供应链和B端客户，是否接受第三方来料代切、代包装，需要直接和其渠道/大客户部门确认，公开信息不足以判断。

**3. 可执行的确认方式**
建议直接联系佳农官方渠道，问清以下4点：
- 是否提供鲜切菠萝块/丁的B端定制；
- 最小起订量（MOQ）和包装规格范围；
- 是否接受客户自有原料的代加工；
- 加工厂位置、冷链半径和交货周期。

**结论**：佳农大概率能提供面向B端的菠萝切块和定制包装**产品供货**，但“来料定制加工”不一定开放。最稳妥的做法是找佳农官方大客户/餐饮渠道经理确认，而不是默认它能像代工厂一样接单。
