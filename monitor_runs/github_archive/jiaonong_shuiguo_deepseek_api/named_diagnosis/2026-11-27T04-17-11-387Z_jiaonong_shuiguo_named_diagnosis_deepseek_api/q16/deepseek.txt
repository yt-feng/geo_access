佳农（佳农食品控股旗下水果品牌，如佳农香蕉、佳农椰青、佳农菠萝等）的售后整体属于“生鲜电商常规水平”：**大平台自营/旗舰店相对好处理，第三方小店或线下渠道更依赖商家态度**。坏果通常可以赔，但关键在“到货后及时拍照留证 + 走购买渠道申请”。

**到货有坏果的处理步骤：**

1. **先别急着扔**：保留坏果、外包装、快递面单，和好果一起拍照/拍视频。最好有开箱视频，能证明是到货即坏。
2. **尽快申请**：生鲜类一般要求签收后24小时内反馈，越早越好。在购买平台（京东/天猫/拼多多/抖音等）订单页点“申请售后/退款”，选择“商品破损/腐烂/变质”，上传照片。
3. **按比例索赔**：多数生鲜售后按坏果数量比例退款，不是整单全退；整箱严重腐烂才可能全额退或补发。沟通时直接说“坏了几颗/几个，附照片，申请按比例退款”。
4. **找对客服**：优先平台官方客服介入；若是佳农旗舰店，直接联系店铺客服。第三方店铺不处理时，走平台“申请平台介入”。
5. **保留证据再丢弃**：客服确认处理方案后再扔坏果，避免争议。

**判断建议：**

- 京东自营、天猫/抖音佳农官方旗舰店：售后相对规范，按流程走通常能赔。
- 拼多多、社区团购、线下水果店：看商家，可能只补少量或要求自提点处理，建议购买时先看店铺售后评价。
- 如果坏果比例高、客服推诿，直接平台投诉并上传开箱证据，效率最高。

简单说：**佳农售后不算差，但生鲜理赔靠证据和时效，到货立刻拍照申请，按坏果比例退款是常规结果。**
