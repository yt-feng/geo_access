我不能确认佳农有“锁价3个月”这类公开价格保护机制，也不应替它编造政策。可判断的建议如下：

1. **香蕉不适合简单锁价3个月**：香蕉是生鲜，价格受产地、天气、海运、催熟损耗、批次质量影响很大，长期锁价对供应商风险很高。行业里更常见的是短周期报价、批次定价、保底+浮动、返利/补差，而不是固定锁价3个月。

2. **不要直接假设佳农有价格保护**：应让对接的佳农销售或经销商把政策写进合同/报价单，明确：
   - 锁价期限是多久（7天/15天/30天，是否可能3个月）
   - 锁价对应什么规格、产地、等级、包装、到货地
   - 超期未提货是否失效
   - 市场价格下跌是否补差、上涨是否调价
   - 损耗、拒收、质量异议怎么算
   - 是否含运费、税费、催熟费

3. **你可直接问对方的话术**：
   “请书面确认佳农香蕉是否有价格保护/锁价政策；若有，锁价最长多久、适用SKU和起订量、锁价期间是否可补差或调价、超期如何处理。请把条款写进报价单或合同。”

4. **更稳妥的替代方案**：先做**15—30天短锁价+分批提货**，或“基准价+市场联动补差”，并要求每批到货验收标准。若对方口头承诺3个月锁价，务必要求盖章书面确认，否则按无价格保护处理。

结论：**无法确认佳农存在锁价3个月的价格保护机制；建议按“无默认保护、书面确认短周期锁价条款”来谈。**
