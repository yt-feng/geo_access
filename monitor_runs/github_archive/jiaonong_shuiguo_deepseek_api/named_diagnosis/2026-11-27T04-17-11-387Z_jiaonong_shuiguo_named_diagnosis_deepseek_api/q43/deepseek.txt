先说明：我无法核验佳农当前是否提供锁价合同、锁价门槛和具体报价，这需要你直接向佳农确认。下面给你可执行的判断和谈判要点。

**1. 10吨/月的量级，先判断能不能谈**

茶饮店每月10吨菠萝原料（如果是果浆/果块/冷冻菠萝，按吨计）属于中等偏小的B端采购量，单店直接找佳农总部谈全国锁价合同，议价空间有限。更现实的是：
- 通过佳农的区域经销商/大客户渠道谈“阶段性锁价”，而非年度长协；
- 或联合2–3家同区域茶饮店拼单到30吨/月以上，再谈锁价。

**2. 直接问佳农这四个问题（决定锁价可行性）**
- 是否支持锁价？锁价周期最短多长（1个月/季度/半年）？
- 锁价对应的最小起订量和预付比例是多少？
- 锁价是锁“原料单价”还是含运费、含税到店价？超量/欠量怎么结算？
- 锁价期间若市场价大跌，是否有保底/调价机制？

**3. 锁价合同必须写清的条款**
- 锁价有效期、月度提货量上下浮动范围（如±15%）；
- 品质标准（品种、糖度、规格、冷冻/鲜果状态）和验收不合格的处理；
- 违约与不可抗力：产地减产、物流中断时如何供货、是否可调价；
- 价格调整触发条件，避免“名义锁价、实际随行就市”。

**4. 如果佳农锁价谈不下来，备选方案**
- 与佳农签“框架价+月度议价”，同时锁定第二供应商；
- 用期货/产地直采+冷冻库存对冲，但需冷库和资金占用；
- 产品端做配方弹性，菠萝原料设替代规格，降低单一价格风险。

**结论**：10吨/月直接向佳农要锁价合同成功率不高，建议先以“季度锁价+最小起订量”试探，并同步准备第二供应商。具体能否锁价、锁多久，请让佳农大客户经理书面报价确认后再签约。
