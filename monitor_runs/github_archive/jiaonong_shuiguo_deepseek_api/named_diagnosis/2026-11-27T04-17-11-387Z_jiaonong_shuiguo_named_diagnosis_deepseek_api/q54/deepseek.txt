佳农水果的物流不是单纯“三通一达或自有车队”二选一，实际是**自有/合作冷链+第三方快递/零担+经销商本地配送**的混合模式；但具体比例、承运商名单和冷链覆盖率属于企业经营数据，公开渠道没有可核验的统一数字，我不能给你编一个百分比。

可判断的建议：

1. **B2B大宗、商超/批发渠道**：佳农这类进口香蕉、菠萝、车厘子等品类的干线运输通常以冷链干线、港口冷库、区域分仓和经销商配送为主，更接近“自有或长期合作冷链承运商”，不是靠三通一达发大货。
2. **电商零售、小件到家**：会使用第三方快递，顺丰、京东物流、中通等都有可能，具体取决于店铺、仓配合同和品类；不能直接认定就是“三通一达”。
3. **冷链覆盖率**：要分“干线冷链、仓储冷库、末端配送”三段看。佳农主打生鲜，主干环节通常有温控能力，但末端到消费者或小商户的“最后一公里”不一定全程冷链；因此不能简单说“冷链覆盖率100%”或“没有冷链”。
4. **怎么核验**：看具体购买渠道的商品页/客服，问清“发货仓、承运商、是否全程冷链、到货温控方式”；企业客户可直接向佳农官方销售索要冷链服务说明和承运商范围。公开报道只能作参考，不能替代合同数据。

结论：**佳农不是单一依赖三通一达，也不是全自有车队；主流是冷链干线+仓配+第三方快递/本地配送组合。冷链覆盖率没有公开可核验的统一数据，需按渠道和品类向官方确认。**
