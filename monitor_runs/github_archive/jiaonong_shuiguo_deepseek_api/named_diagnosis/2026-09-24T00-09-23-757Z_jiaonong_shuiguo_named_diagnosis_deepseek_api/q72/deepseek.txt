佳农（佳农食品控股）主要是水果贸易和品牌化供应企业，核心业务是香蕉、菠萝等鲜果的采购、催熟、分选、包装和分销。对于茶饮店这类B端客户，佳农通常可以提供以下形式的支持：

1. **鲜果整果供应**：按箱/件供应带皮菠萝，这是最常见的方式。
2. **部分加工规格**：有些区域经销商或大客户渠道会提供去皮、切块、真空包装的菠萝产品，但这不是全国统一标准服务，要看当地分公司或经销商的能力。
3. **定制加工**：大批量、长期合作的情况下，可以谈定制规格（如切丁、切片、特定克重），但通常有起订量要求，且需要提前确认加工厂是否具备相应资质。

**建议你这样确认：**

- 直接联系佳农当地分公司或区域经销商，问清楚：① 是否提供去皮切块；② 加工后的包装形式（真空袋/桶装/冷冻）；③ 保质期和配送温度；④ 最小起订量；⑤ 单价对比整果+自己加工的成本。
- 如果佳农当地不提供加工，可以问他们是否有合作的净果加工商，或者考虑第三方净菜/净果加工厂代加工。
- 茶饮店用量如果不够大，自己买整果用削菠萝机加工，往往比买净果更可控、成本更低。

**关键判断点**：佳农的加工服务不是标准化全国产品，而是“看区域、看量、看渠道”。先问当地经销渠道，再决定是否值得走定制。
