我无法核验佳农水果当前是否有“单根包装、专供便利店”的香蕉产品。这类 SKU 会随区域、渠道和季节调整，最可靠的是直接找当地经销商或佳农官方渠道确认。

你可以按下面方式快速判断和推进：

1. **先确认你要的形态**
   - 单根独立包装香蕉：通常是单根套袋/贴标/装盒，不是整把。
   - 便利店常见规格：1 根装、2 根装、3 根装；其中 1 根装更多见于鲜食即买即走场景。
   - 是否要求催熟到位、可即食、货架期 2–3 天，这比品牌更重要。

2. **直接问佳农当地渠道**
   - 问法建议：
     - “有没有面向便利店的单根装香蕉 SKU？”
     - “最小起订量是多少？”
     - “是产地直发还是区域仓配？”
     - “是否支持贴便利店标签/定制包装？”
     - “到店成熟度是几级？货架期几天？”
   - 如果当地经销商说没有，通常不是全国都没有，而是该区域没铺这个规格。

3. **如果没有佳农单根装，替代方案**
   - 找区域香蕉催熟商或生鲜配送商做单根包装，很多便利店实际走的是这种本地供应链。
   - 采购进口香蕉或国产香蕉后，让供应商按单根套袋、贴标、装盒。
   - 也可以先做 2 根装试销，单根装损耗和包装成本通常更高。

4. **便利店采购时重点看**
   - 单根重量：建议 120–160g 左右，太小没价值感，太大吃不完。
   - 成熟度：到店最好 4–5 级，能直接卖 1–2 天。
   - 损耗：单根包装容易压伤，要看供应商是否用硬盒或防压托盘。
   - 毛利：单根装溢价高，但包装和损耗也会吃掉利润，先小批量测。
