佳农（佳农食品控股/Goodfarmer）主业是香蕉、菠萝等水果的种植、进口和批发，公开对外常见的是**整果、鲜果及部分冷冻/鲜切水果类产品**，并不是典型的“来料代加工”服务商。所以如果你要的是**茶饮店用的菠萝丁原料**，更现实的情况是：

1. **佳农大概率不做“按你配方代加工菠萝丁”的服务**  
   它更偏向水果供应链上游，卖整果或标准化水果原料，而不是给茶饮品牌做定制化分切、糖渍、冷冻丁这类代工。

2. **可能能买到的是“菠萝相关原料”，但形式有限**  
   比如：
   - 整果菠萝
   - 鲜切菠萝/菠萝块（部分渠道）
   - 冷冻菠萝丁/速冻菠萝（要看具体渠道和区域）
   - 菠萝果浆/浓缩汁类（通常不是佳农强项，或由别的原料商做）

3. **茶饮店更常用的采购路径**  
   如果你要的是稳定规格的菠萝丁，建议直接找：
   - 冷冻水果原料供应商
   - 茶饮原料供应链公司
   - 罐头/糖水菠萝丁厂家
   - 冷冻菠萝丁代工厂  
   这些更可能提供：
   - 规格：5×5mm、8×8mm、10×10mm等
   - 状态：冷冻、糖水、无菌袋装
   - 包装：1kg、2kg、5kg、10kg
   - 是否可定制糖度、固形物、杀菌方式

4. **怎么快速判断佳农能不能做**  
   你可以直接问对方这几个问题：
   - 你们有没有茶饮用的菠萝丁/冷冻菠萝丁？
   - 是自有品牌标准品，还是可以按客户规格代加工？
   - 最小起订量是多少？
   - 是鲜切、冷冻、糖水还是罐头？
   - 能否提供样品、检测报告和稳定供货？
   - 加工厂在哪里，是否支持OEM？

**结论：**  
佳农更可能提供的是**菠萝整果或标准化菠萝原料**，而不是专门给茶饮店做定制化“菠萝丁代加工”。如果你要的是稳定规格的茶饮菠萝丁，建议同时询价佳农和专业的冷冻水果/茶饮原料供应商，重点确认“是否有现成菠萝丁”和“是否支持OEM代工”。
