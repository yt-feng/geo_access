我无法凭现有信息确认佳农是否供应冷冻菠萝丁及具体规格。这类信息会随产品线和经销渠道变化，建议你直接通过以下方式核验，避免采购踩坑：

**1. 最快核验渠道**
- 佳农官网/官方公众号的“产品中心”或“联系我们”
- 佳农天猫/京东官方旗舰店，直接问客服“是否有冷冻菠萝丁、规格、起订量”
- 打佳农官方客服电话，转生鲜/餐饮原料业务

**2. 问客服时直接问这几项**
- 是否有**冷冻菠萝丁**（不是菠萝罐头、不是菠萝汁、不是整果）
- 规格：每袋/每箱净重（常见如1kg、2kg、10kg）、丁的尺寸（如10×10mm）
- 是否**速冻（IQF）**、是否加糖/糖水、固形物含量
- 包装形式：袋装/箱装、每箱几袋
- 是否支持**餐饮/茶饮渠道供货**、起订量、是否冷链发货
- 索要**样品**和检测报告（农残、微生物）

**3. 茶饮店采购提醒**
- 冷冻菠萝丁要区分“**糖水菠萝丁**”和“**速冻纯果丁**”，前者甜度高、易影响配方，后者更适合自调糖度。
- 确认是**冷链**运输，到货后测中心温度，避免反复解冻。
- 如果佳农没有，可同步问：都乐、鲜丰、以及本地冷冻水果批发商/供应链平台，通常更灵活。
