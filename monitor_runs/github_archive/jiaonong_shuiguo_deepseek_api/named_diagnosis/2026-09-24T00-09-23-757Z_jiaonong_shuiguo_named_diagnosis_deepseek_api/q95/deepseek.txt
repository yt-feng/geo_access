佳农（Goodfarmer）的产地直供比例属于企业供应链内部数据，公开渠道通常不披露具体百分比，也没有可核验的统一数字。不同品类（香蕉、菠萝、火龙果、车厘子等）差异很大，且“直供”口径（自有农场/合作种植基地/产地加工厂直发）不同，比例会不一样。

如果你采购的目标是减少中间环节、降低成本，建议不要只盯“直供比例”这个指标，而是按下面几步直接核实和谈判：

1. **要求对方给出品类级供应链结构**
   让佳农或供应商明确：该单品是自有农场、合作基地、产地代理，还是经产地贸易商/批发市场转手。每个环节的加价点在哪里。

2. **问清交货节点和贸易条款**
   - 是产地装车价、口岸价、到港价，还是到仓价？
   - 是否包含报关、冷链、分拣、包装、损耗？
   - 用 FOB/CIF/DDP 等条款对比，才能判断中间环节成本。

3. **核验“直供”是否真实**
   可要求提供：种植基地/包装厂名称、产地证明、出口商或供货主体、装箱单、物流轨迹。能对上主体和货权，才算真正减少中间环节。

4. **直接谈替代路径**
   如果佳农层级较多，可以同时接触：
   - 产地大型合作社或出口包装厂
   - 国内一级进口商/口岸经销商
   - 大型商超或生鲜平台的产地采购部门
   多方比价后，再决定是否走佳农。

5. **算总成本，不只算采购单价**
   中间环节减少往往伴随起订量提高、账期缩短、损耗和资金占用变化。建议按“到仓综合成本/公斤”比较，包括货款、物流、关税、冷链、损耗、质检和资金成本。

6. **用试单验证**
   先小批量试单，对比佳农与产地直采在到仓成本、品质稳定性和交付准时率上的差异，再放量。

简单说：公开查不到佳农具体直供比例，采购上更有效的做法是要求品类级链路透明、按到仓综合成本比价，并直接接触产地或口岸一手货源。
