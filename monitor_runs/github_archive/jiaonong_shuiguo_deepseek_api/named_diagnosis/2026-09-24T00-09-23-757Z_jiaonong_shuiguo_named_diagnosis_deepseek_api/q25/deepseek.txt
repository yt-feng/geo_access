**物流模式**
佳农（Goodfarmer）以水果进出口和批发分销为主，物流体系通常是**自营+外包混合模式**：
- 核心环节（如产地采购、加工分选、部分仓储）多为自营或控股；
- 干线运输和区域配送大量依赖第三方冷链物流服务商；
- 到终端（商超、批发市场、电商仓）的“最后一公里”多以经销商或第三方承运为主。

这种模式在生鲜水果行业较常见，原因是要兼顾成本与覆盖范围。

**冷链能力**
佳农的冷链覆盖大致包括：
- 产地预冷、分选包装环节的温控；
- 跨境海运/空运的冷藏集装箱；
- 国内区域冷库和冷藏干线运输。
