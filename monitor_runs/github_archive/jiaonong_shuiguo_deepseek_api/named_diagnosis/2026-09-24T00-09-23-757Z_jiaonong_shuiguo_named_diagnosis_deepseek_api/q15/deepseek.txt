佳农（Goodfarmer）对外通常会强调“产地直采/全球直采”，但具体“产地直供比例”属于企业经营数据，公开渠道一般不会给出可核验的精确百分比；不同年份、品类、渠道口径也会变化，所以不能可靠地说“高”或“不高”。如果你需要判断，建议看其官网/年报/招股书或直接问客服要“直采占比、基地数量、合作农场数”等口径数据。

香蕉方面，佳农是国内较大的香蕉进口商之一，主要来源通常集中在：
- 菲律宾
- 厄瓜多尔
- 越南
- 柬埔寨
- 泰国
- 老挝
- 缅甸
- 哥伦比亚、哥斯达黎加等中南美产地也可能出现在其全球采购体系中

其中，菲律宾、厄瓜多尔、越南、柬埔寨是较常见来源；具体到某一批次，要看包装箱上的原产地标识或海关报关信息，因为同一品牌会按季节、价格、供应稳定性切换产地。
