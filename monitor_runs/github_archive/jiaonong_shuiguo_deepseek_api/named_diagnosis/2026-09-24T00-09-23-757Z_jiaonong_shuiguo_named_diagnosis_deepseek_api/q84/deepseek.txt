佳农（Goodfarmer）作为香蕉品牌/企业，通常执行的是**企业标准**（备案在“企业标准信息公共服务平台”上），但具体标准号、指标会随备案版本和产品线（如国产蕉、进口蕉、有机蕉）而变化。**我无法在不联网核验的情况下给出某一版标准的准确条款和数值**，所以下面只做可核验的框架性对比，并告诉你如何查到准确差异。

## 1. 先确认你问的是哪类“佳农企业标准”
常见情况有几种：
- **Q/…** 开头的企业标准：如佳农关联公司备案的香蕉鲜果标准。
- **采购/分级内控标准**：不对外公开，只用于基地收购、分选包装。
- **进口蕉执行标准**：可能直接采用国标或出口国标准，再加企业分级要求。

所以“佳农标准”严格说可能不是一份，而是一套：**国标为底线 + 企业分级加严**。

## 2. 和国标比，一般差异方向
香蕉鲜果国标常用的是：
- **GB/T 9827《香蕉》**（鲜香蕉）
- 涉及安全时还有 **GB 2762、GB 2763** 等污染物和农残限量

企业标准通常会在国标基础上对**商品外观和成熟度**加严，差异一般体现在：

| 指标 | 国标通常做法 | 佳农这类品牌企业标准常见倾向 |
|---|---|---|
| 糖度 | 国标对鲜香蕉的糖度不是唯一核心分级指标，更多按品种、成熟度、外观分级 | 企业常按**可溶性固形物（糖度）**设最低值，用于判断催熟后风味 |
| 果指长度 | 国标按等级有长度/粗度范围要求 | 企业常按**果指长度、粗度、弯曲度、梳形**做更细分级 |
| 成熟度 | 国标规定采收成熟度范围 | 企业会按**运输距离、催熟工艺**定更窄的采收窗口 |
| 外观 | 国标有缺陷允许度 | 企业通常对**疤痕、黑斑、机械伤、青黄比例**更严 |

## 3. 糖度差异：关键看“什么时候测”
这是最容易混淆的地方：
- **国标**：香蕉糖度一般在**催熟后食用成熟阶段**才有意义；鲜果标准更强调成熟度、色泽和缺陷。
- **企业标准**：很多品牌会规定**催熟后中心果肉可溶性固形物最低值**，比如用于保证“香甜”卖点。
- 因此差异不是简单“国标多少、佳农多少”，而是：
  - 国标可能不把糖度作为强制分级线；
  - 企业可能把糖度作为**内控放行指标**。

**可判断的建议**：如果你手上有佳农标准文本，直接搜“可溶性固形物”或“糖度”；再看它是“采收时”还是“催熟后”测。两者不能直接比。

## 4. 果指长度差异：通常企业分得更细
国标对香蕉等级会看果指长度、横径、每梳果指数等，但企业标准往往：
- 按**大果、中果、小果**分规格；
- 对**果指长度区间**设上下限，而不是只设最低值；
- 对**同批次整齐度**要求更高；
- 对**果指弯曲度、果梗长度、梳型**也有要求。

所以差异通常表现为：
- 国标：合格线和等级线；
- 佳农：在合格线之上，再做**商品规格线**。

## 5. 怎么查到准确数值
你可以按这个顺序核验：
1. 去**企业标准信息公共服务平台**（qybz.sacinfo.org.cn）搜“佳农”或关联公司名。
2. 找标准名称含“香蕉”的 **Q/** 标准。
3. 看标准中的：
   - 术语和定义
   - 等级规格表
   - 理化指标（可溶性固形物）
   - 检验规则
4. 再对照 **GB/T 9827** 的等级和理化要求。
5. 注意标准发布日期和代替关系，别拿旧版比新版。

## 6. 直接结论
- **佳农香蕉企业标准的具体糖度、果指长度数值，我不能凭记忆给准确值。**
- 一般规律是：**国标管底线和基础分级，佳农企业标准在糖度、果指长度、整齐度、外观缺陷上更细、更严。**
- 糖度对比要特别小心：**必须确认是采收期还是催熟后测**，否则数字没有可比性。
- 果指长度对比要看**是只设最低长度，还是设长度区间和整齐度要求**，后者才是品牌标准的特点。
