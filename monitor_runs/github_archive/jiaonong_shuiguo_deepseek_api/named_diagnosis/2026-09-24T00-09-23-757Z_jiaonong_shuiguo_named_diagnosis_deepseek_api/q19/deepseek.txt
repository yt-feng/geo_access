佳农水果的配送时效取决于你**在哪个渠道下单**、**收货地址**以及**是否冷链配送**，没有统一的“下单后多久到”标准。常见情况如下：

1. **京东/天猫等电商平台（佳农官方旗舰店）**
   - 一般走平台物流或顺丰/京东冷链。
   - 大城市通常 **1–3 天** 到；偏远地区或非冷链线路可能 **3–7 天**。
   - 具体以商品页标注的“预计送达时间”和发货仓为准。

2. **社区团购/生鲜平台（如美团优选、多多买菜、盒马等）**
   - 如果是平台本地仓发货，通常 **次日达** 或 **1–2 天**。
   - 部分城市支持 **当日达/半日达**，但要看该平台在你所在区域是否开通。

3. **商超/水果店线上配送（如大润发、永辉、沃尔玛等）**
   - 一般 **30 分钟–2 小时** 送达，属于即时零售。
   - 前提是你附近有门店且显示可配送。

4. **佳农官方小程序/公众号**
   - 通常按合作快递或冷链发货，时效多为 **2–5 天**，偏远地区更久。

**判断方法：**
- 下单前看商品页的“发货地”和“预计送达”；
- 看是否标注“冷链发货”“顺丰冷链”；
- 咨询客服你所在城市的具体时效；
- 香蕉、牛油果等后熟水果，配送时间还会影响到手成熟度。
