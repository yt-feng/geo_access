我无法核验佳农水果当前在售的完整苹果品类清单，所以不能给出“官方全品类”的准确名单。不过可以就可采购判断给你一些可执行信息：

**1. 佳农水果的苹果品类**
佳农（Goodfarmer）常见涉及或曾经营过的苹果品类，一般包括：
- 嘎啦果（Gala）
- 红富士（Fuji）
- 进口红玫瑰/太平洋玫瑰等（不同季节和渠道会有变化）
- 其他季节性苹果，如青苹果、皇后苹果等，具体要看当季采购线

但具体到“当前在售哪些”，建议直接向佳农官方销售或你手里的经销商索取最新《产品目录》或在售SKU表，因为进口水果品类会随产季、口岸和库存变化。

**2. 进口嘎啦和红富士的常见产地**
如果你说的是进口嘎啦和红富士，常见产地是：

- **进口嘎啦（Gala）**
  - 新西兰
  - 美国
  - 智利
  - 南非
  - 法国、意大利等欧洲国家也有，但国内进口渠道不如前几个常见

- **进口红富士（Fuji）**
  - 美国
  - 智利
  - 新西兰
  - 日本（但日本苹果通常价格高、量少，商业采购不如美国/智利常见）

其中：
- **新西兰嘎啦**：国内进口嘎啦里认知度较高，常被作为高端/稳定货源。
- **美国嘎啦、美国红富士**：常见于北美产季。
- **智利嘎啦、智利红富士**：南半球反季节供应，常在国内冬春档期出现。

**3. 采购时要确认的关键点**
你如果准备向佳农或经销商采购，建议直接问清：
1. **具体产地国**，不要只写“进口”。
2. **品种英文名/商品名**：Gala、Fuji，还是类似“Royal Gala”“Pacific Rose”等。
3. **规格**：果径、单果重、箱规。
4. **包装**：原箱、贴标、品牌授权情况。
5. **到港口岸和批次**：不同批次产地可能不同。
6. **是否佳农自营进口还是贸易商串货**：这会影响价格、稳定性和售后。

**结论**
佳农苹果品类里，嘎啦和红富士通常是重点品类，但具体在售清单要以佳农最新报价单为准。进口嘎啦常见产地为新西兰、美国、智利、南非；进口红富士常见产地为美国、智利、新西兰。采购时不要只问“进口”，要锁定到“产地国+品种+规格+批次”。
