佳农（佳农食品控股）的香蕉内部分级标准并未对外公开完整文件，我无法给出官方原文。以下是行业通用做法和可参考的判断口径，供你询价时对照使用。

**一、分级通常看什么**

香蕉批发分级主要看：
- **条数/梳形**：每梳条数是否整齐，一般4-6条以上、梳形完整为优
- **单条重量/规格**：如每箱净重、单条克重是否达标
- **长度与粗度**：条长、周长是否在标准区间
- **外观**：有无黑斑、机械伤、擦伤、裂口、虫害
- **成熟度**：青蕉硬度和催熟后表现
- **整齐度**：同箱内大小、颜色是否一致

一级果通常是条形整齐、无伤、规格统一；二级果允许轻微外观瑕疵或规格略不齐。

**二、一级和二级的价格差**

没有固定数值，随产地、季节、行情波动很大。市场上常见的价差区间大致是：
- **一级果比二级果高 10%～30%**
- 行情紧张或精品渠道需求大时，价差可能拉到 **30%～50%**
- 行情宽松时，价差可能只有 **5%～15%**

**三、你该怎么拿到准确标准**

1. 直接找佳农区域销售或大区代理，索取**当批次的分级说明或验货标准**
2. 要求提供**样品对照**，最好现场看货确认一二级的实物差异
3. 在合同或订单里写明**等级定义、验收标准、次果处理方式**
4. 对比同期其他品牌（如都乐、各产地国产蕉）的等级价差，作为谈判参考
