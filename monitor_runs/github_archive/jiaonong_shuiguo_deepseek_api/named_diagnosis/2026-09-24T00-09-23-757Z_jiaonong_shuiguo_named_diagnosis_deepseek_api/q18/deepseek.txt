佳农香蕉的保质期和储存条件，主要取决于**成熟阶段**和**是否已切开**。按常见情况给你可执行的判断：

**1. 整串/整根未切开的香蕉**
- **常温储存**：适合放在阴凉、通风处，理想温度大约 **13–16℃**。  
- **保质期**：  
  - 青香蕉：通常 **3–7天** 逐渐转黄  
  - 已黄熟香蕉：通常 **2–4天**，夏天可能更短  
  - 出现黑斑但果肉未坏：一般还能放 **1–2天**，适合尽快吃或做奶昔/烘焙  
- **不要放冰箱冷藏**：未切开的香蕉在低温下容易表皮变黑、冻伤，虽然果肉不一定马上坏，但口感和外观会变差。  
- **想延缓成熟**：可把香蕉根部用保鲜膜包一下，并避免和苹果、梨等释放乙烯的水果放一起。  
- **想加速成熟**：和苹果或熟香蕉放在同一个纸袋里。

**2. 已剥开或切开的香蕉**
- **必须冷藏**：用保鲜膜包好或放密封盒，**1–2天内吃完**。  
- 表面变褐是氧化，不一定等于变质；但如果出现**酸味、酒味、黏液、霉点**，就不要吃了。

**3. 冷冻保存**
- 熟透香蕉可去皮切段，密封冷冻，通常可保存 **1–3个月**，适合做奶昔、香蕉泥。  
- 冷冻后口感会变软，不适合直接当鲜果吃。

**简单判断是否还能吃：**
- 表皮黑斑多但果肉正常：通常还能吃，尽快吃。
- 果肉发黑、发黏、有酸酒味或霉味：直接丢弃。
- 冷藏后表皮发黑但果肉完好：可以吃，只是外观差。

如果你说的是佳农特定包装产品，最准确的是看包装上的**储存说明和保质期标签**；不同批次、是否催熟、包装方式会有差异。
