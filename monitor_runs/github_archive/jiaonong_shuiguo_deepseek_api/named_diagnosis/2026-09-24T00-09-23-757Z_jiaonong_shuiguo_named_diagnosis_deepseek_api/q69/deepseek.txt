我无法核验佳农官方是否提供这类定制规格，所以不能给出确定答案。建议你直接向佳农确认，渠道如下：

- 佳农官网/官方公众号的客服或“联系我们”入口
- 佳农在京东/天猫等平台的官方旗舰店客服（可问到餐饮/批发渠道对接人）
- 如果你所在城市有大型农产品批发市场，问佳农经销商是否有餐饮专供SKU

问的时候可以直接说清楚这几点，方便对方快速判断能不能做：

1. 用途：餐饮/茶饮/烘焙/沙拉等
2. 形态：菠萝切片、菠萝切块、菠萝丁、整果去皮
3. 规格：每片/每块尺寸、每袋克重、每箱袋数
4. 工艺：鲜切冷藏、冷冻、糖水罐头、速冻果块
5. 包装：真空袋、马口铁罐、冷冻袋、配送箱规
6. 需求量和配送频次：试单量、月用量、到货城市
7. 资质要求：是否需要检疫证、检测报告、SC/食品生产许可等

补充一点：鲜切菠萝和冷冻菠萝块通常属于不同供应链，前者保质期短、配送半径有限，后者更适合跨区域餐饮连锁。如果佳农没有对应定制，也可以考虑其经销商、其他果蔬加工厂或餐饮供应链平台，按同样清单去询价。
