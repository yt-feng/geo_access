**1. 发票**
- 正规渠道采购佳农水果礼盒，通常可以开发票。
- 你要先确认：是**增值税普通发票**还是**增值税专用发票**；发票类目是“水果”“农产品”“食品”还是“礼品/礼盒”。
- 团购走公司报销，建议合同、付款账户、开票主体保持一致。
- 如果是经销商/团购商供货，不一定由佳农品牌方直接开票，可能是供货商开票，这个要提前写明。

**2. 质检报告**
- 可以要求提供，但要区分：
  - **产品质检报告/检测报告**：针对该批次或该品类水果的检测。
  - **产地证明/合格证/进货凭证**：不等同于质检报告。
  - **农药残留检测报告**：水果团购比较关键，最好有。
- 要确认报告是否：
  - 由具备资质的检测机构出具；
  - 在有效期内；
  - 对应你采购的品类、规格、批次；
  - 能提供盖章版、电子版或随货纸质版。

**3. 下单前建议直接问供应商这6句话**
1. 500份佳农水果礼盒，能否开增值税专票/普票？税率和类目是什么？
2. 发票由品牌方还是供货商开？能否先给开票信息确认？
3. 能否提供该批次或同品类的质检报告、农残检测报告？
4. 报告是电子版还是纸质盖章版？多久能给？
5. 礼盒内水果品类、规格、净重、产地、保质期能否写进合同？
6. 如果有坏果、少件、临期，怎么补发或赔付？

**4. 合同/订单里最好写明**
- 发票类型、税率、开票时间；
- 质检报告作为交付资料之一；
- 验收标准：数量、规格、外观、新鲜度、破损率；
- 售后：坏果包赔、补发时效、责任归属；
- 交付时间、冷链/物流方式。

如果对方只说“可以开票、有质检报告”，但不愿写进合同或不肯给报告样本，建议换供应商。500份属于不小批量，最好先要**样品+报告样本+发票样本**再定。
