结论先说：**佳农水果的香蕉通常做不到“追溯到具体农场”这一级；GLOBALG.A.P.证书一般也不能按“具体农场”直接给你，更多是按供应商/包装厂/集团层面提供。** 你们商超如果硬性要求“具体农场级溯源 + 对应GLOBALG.A.P.证书”，需要提前和佳农确认，否则大概率卡住。

分点说明：

1. **产地溯源层级**
   - 佳农的香蕉主要来自厄瓜多尔、菲律宾、越南、柬埔寨等产地，通常能提供到：**国家 → 区域/产区 → 供应商/包装厂 → 批次**。
   - 到“具体农场”这一级，通常只有部分自有基地或核心合作基地能做到。
   - 商超渠道常见的可提供文件是：**产地证明、植检证、装箱单、批次号、供应商声明**，而不是每个农场一张溯源证明。

2. **GLOBALG.A.P.证书**
   - GLOBALG.A.P.通常由**生产商/出口商/包装场/供应商**持有，不是由佳农统一给每个农场出证。
   - 佳农作为贸易商/品牌方，通常能提供其**上游供应商的GLOBALG.A.P.证书**，但证书上的主体名称、地址、覆盖范围要和实际供货来源对得上。
   - 如果你们要求“证书必须对应到具体农场”，那就要看该农场是否单独持证，以及佳农是否愿意披露该农场信息。

3. **你们商超要落地，建议这样操作**
   - 先向佳农明确三点：
     1. 本批次香蕉的**具体产地、包装厂、供应商名称**；
     2. 该供应商是否持有**有效GLOBALG.A.P.证书**，证书编号、有效期、认证范围；
     3. 能否提供**农场级信息**，还是只能到供应商/包装厂级。
   - 如果佳农只能给到供应商级，你们可接受的话，就按“**供应商级GLOBALG.A.P. + 批次溯源**”放行。
   - 如果你们制度必须到农场级，就要求佳农提前书面确认哪些批次能做到，避免到货后补不齐。

4. **判断标准**
   - 能做到农场级：证书主体 = 农场，或证书附件/范围明确覆盖该农场，且批次能对应。
   - 只能做到供应商级：证书主体 = 出口商/包装厂/供应商，批次能对应到该供应商，但无法精确到农场。
   - 风险点：证书主体和实际供货主体不一致、证书过期、认证范围不覆盖香蕉、批次对不上。
