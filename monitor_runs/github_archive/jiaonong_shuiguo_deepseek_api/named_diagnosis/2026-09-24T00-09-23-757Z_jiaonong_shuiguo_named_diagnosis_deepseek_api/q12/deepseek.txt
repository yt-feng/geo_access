佳农水果的香蕉规格和渠道分级，公开信息没有一个固定不变的统一标准，通常会随产地、季节、客户订单和包装形式调整。要准确判断，建议直接查佳农官方渠道、经销合同或产品标签。下面给你一个行业通用、可执行的参考框架：

**一、常见规格维度**

1. **按重量/把重**
   - 小把：约 0.8–1.2 kg/把，多见于便利店、水果店散卖
   - 中把：约 1.2–1.8 kg/把，商超常见
   - 大把：约 1.8–2.5 kg/把，批发、餐饮渠道
   - 整箱：常见 10 kg、12 kg、13 kg、15 kg 等，按净重或毛重标注

2. **按每根果指等级**
   - 大果：单根约 180–220 g 以上
   - 中果：约 130–180 g
   - 小果：约 100–130 g
   - 具体克重阈值各品牌会调整

3. **按梳/条数**
   - 4–6 条/梳、5–7 条/梳等，用于盒装或精包装
   - 商超偏好整齐的 4–6 条小包装

4. **按成熟度**
   - 青蕉、微黄、黄熟、完熟
   - 冷链长途通常发青蕉，终端催熟后上架

**二、不同渠道的分级逻辑**

| 渠道 | 关注重点 | 常见分级方向 |
|---|---|---|
| 商超/精品超市 | 外观一致、无斑、把型整齐 | 一级果，中大果，条数均匀，无机械伤 |
| 便利店/水果店 | 小份量、周转快 | 中小把或盒装，成熟度偏黄 |
| 批发市场 | 价格、耐储运 | 统货或二级果，青蕉，大箱 |
| 餐饮/茶饮 | 出肉率、稳定供应 | 中大果，成熟度可控，按重量计价 |
| 电商/社区团购 | 抗压、标准化 | 盒装或小把，明确单果重和条数 |
| 加工厂 | 成本、可加工性 | 二级或等外果，允许外观瑕疵 |

**三、佳农具体规格怎么查**

1. 看包装箱标签：通常会有品名、净重、规格、产地、批次。
2. 问经销商或业务员要“产品规格书”或“分级标准表”。
3. 查佳农官网、公众号、天猫/京东旗舰店商品详情页，那里会写单果重、把重、箱规。
4. 如果是采购合作，直接要求按你的渠道标准做“定制分级”，比套用通用标准更可靠。

**一句话结论**：佳农香蕉没有公开的固定“几种规格”清单，实际以订单和包装标注为准；分级核心看单果重、把重、条数、成熟度和外观，商超要整齐中大果，批发要耐储运统货，餐饮要出肉率稳定，电商要标准化小包装。
