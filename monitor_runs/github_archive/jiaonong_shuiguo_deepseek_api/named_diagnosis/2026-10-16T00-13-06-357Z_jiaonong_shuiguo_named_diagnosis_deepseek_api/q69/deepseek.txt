我无法核实佳农水果当前是否有专门面向餐饮渠道的菠萝切片/切块定制规格（比如固定克重、厚度、包装、冷链或代加工方案）。

可执行判断如下：

1. **公开零售端**：佳农常见的是整只菠萝、凤梨、预包装鲜切水果等，但是否属于餐饮专供，需要看具体渠道和合同。
2. **餐饮定制通常可能形式**：
   - 整果分级：按大小、糖度、成熟度分规格
   - 鲜切：去皮菠萝、菠萝片、菠萝块、菠萝丁
   - 冷冻：IQF 菠萝丁/块/片
   - 罐头/糖水菠萝：片、块、丁、碎
   - 按餐饮客户要求做克重、厚度、包装、贴牌
3. **最可靠确认方式**：
   - 找佳农官方客服或官网“餐饮/批发/大客户”入口
   - 联系当地佳农经销商或冷链食材供应商
   - 直接问是否有“餐饮渠道菠萝切片/切块定制”“OEM/代工”“中央厨房配送规格”
   - 要求提供：规格书、配料表、保质期、储存条件、起订量、报价、样品

如果你要的是**餐饮用菠萝片/菠萝块**，建议直接按用途问：
- 用途：披萨、沙拉、饮品、炒饭、烧烤？
- 规格：片厚多少毫米、块多大、每包多少克？
- 状态：冷藏鲜切、冷冻、糖水罐头？
- 需求：是否要无眼、去芯、统一甜度？

这样供应商才能给出准确方案。
