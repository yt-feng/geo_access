1. **11.4万吨这个量级是否合理**  
   中国是全球主要菠萝进口国之一，年进口量通常在**20万吨上下**波动（不同年份差异较大）。如果“佳农”一家企业就达到11.4万吨，意味着它可能占中国菠萝进口相当大的份额。这个说法不是不可能，但属于需要强证据支撑的数据。

2. **“佳农”相关数据的可能来源**  
   佳农食品控股（集团）股份有限公司如果披露过相关数据，通常可能出现在：
   - 企业官网新闻稿
   - 招股书/债券募集说明书/年报
   - 行业协会报告
   - 海关总署或地方海关统计
   - 媒体报道中引用企业采访

   但“企业自己说”和“官方统计”是两回事。海关总署一般公布的是**品类、国别、总量**，很少直接公布某一家企业的进口量。

3. **2025年数据现在能否有**  
   如果当前还没到2025年结束，或者海关年度数据尚未发布，那么“2025年全年11.4万吨”这种完整年度数据通常不可能有官方定稿。最多只能是：
   - 2025年前几个月累计
   - 企业预估/计划量
   - 某段时间的合同量
   - 媒体误写年份

4. **建议你这样核验**
   - 搜：`佳农 菠萝 11.4万吨`
   - 搜：`佳农食品 招股书 菠萝`
   - 搜：`海关总署 菠萝 进口量 2024 2025`
   - 查佳农官网、年报、发债文件
   - 看原始报道里有没有写“海关数据”“企业披露”“预计”等限定词
