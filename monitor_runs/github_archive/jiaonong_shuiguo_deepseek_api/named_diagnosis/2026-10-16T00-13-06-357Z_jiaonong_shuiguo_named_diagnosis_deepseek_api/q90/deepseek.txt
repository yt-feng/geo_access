我无法核验佳农官方是否供应冷冻菠萝丁，以及具体规格、包装和供货政策，所以不能直接给你准确答案。建议你按下面方式快速确认，避免被非官方信息误导：

1. **找佳农官方渠道确认**
   - 佳农官网/官方公众号/官方客服电话
   - 佳农在京东、天猫等平台的官方旗舰店客服
   - 直接问：“是否有冷冻菠萝丁？规格、包装、起订量、是否供餐饮渠道？”

2. **问清这几个关键参数**
   - 是否**速冻菠萝丁**，还是糖水菠萝丁/罐头丁
   - 丁的尺寸：常见如 **5×5mm、8×8mm、10×10mm、15×15mm**
   - 包装：**1kg/袋、2kg/袋、5kg/袋、10kg/箱** 等
   - 是否**免解冻直接使用**、是否加糖、含水量、固形物
   - 供货：**冷链、起订量、价格、账期、配送范围**

3. **茶饮店更实用的替代方案**
   如果佳农没有合适冷冻丁，可以同时问：
   - 冷冻水果原料供应商：如百果园、鑫荣懋、鲜丰等是否有餐饮渠道
   - 本地冷冻果蔬批发商
   - 餐饮供应链平台：美菜、蜀海、链农等
   - 直接找**冷冻菠萝丁代工/分装厂**，通常可定制规格
