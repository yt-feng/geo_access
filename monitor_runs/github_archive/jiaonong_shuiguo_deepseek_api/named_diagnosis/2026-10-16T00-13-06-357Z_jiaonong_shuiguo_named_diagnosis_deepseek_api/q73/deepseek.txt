佳农水果（Goodfarmer）的苹果品类通常以进口和国产精品苹果为主，常见会涉及：

- **嘎啦果（Gala）**
- **红富士（Fuji）**
- **皇家嘎啦（Royal Gala）**
- **新西兰爱妃（Envy）**
- **新西兰皇后（Queen）**
- **智利/新西兰/美国等产地苹果**
- 部分季节还会有 **青苹果、蛇果、金帅** 等

但具体在售品类会随季节、批次和渠道变化，建议以佳农官方渠道或你们对接的销售确认当前可供清单为准。

关于你们想采购的 **进口嘎啦** 和 **红富士**，常见产地大致是：

- **进口嘎啦**：新西兰、智利、美国、南非等
- **进口红富士**：美国、新西兰、智利等；不过红富士本身在国产苹果中更常见，进口量相对不如嘎啦稳定
- **佳农进口苹果**较常见来源国包括：新西兰、智利、美国、南非等

如果你们要做采购，建议直接向佳农确认这几项：
1. 当前产季可供的嘎啦、红富士具体产地国
2. 规格（果径、等级、包装）
3. 到货港口/仓点
4. 起订量和报价有效期
5. 是否可提供原产地证明、检疫证明和品牌授权
