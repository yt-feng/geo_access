以下是我能提供的**可判断框架**和**获取准确信息的办法**，供你作为批发商直接对接使用。

## 一、行业通行的香蕉分级维度

佳农作为品牌商，实际执行的标准一般围绕以下几项，你可以用这些指标去核对其规格书：

1. **条重/单果重**：按每根香蕉重量分档（如大果、中果、小果），进口蕉常见以“条/箱”“每箱净重”约定。
2. **每梳条数（指/梳）**：如5-6指、7-8指等，决定装箱规格。
3. **果指长度与粗度**：长度(cm)和周长/粗度分级。
4. **外观**：果皮色泽、有无疤痕、黑斑、机械伤、日灼。
5. **成熟度/青度**：采收时的饱满度（如3/4、4/5饱满），影响催熟结果。
6. **整齐度与瑕疵容忍度**：一级果对色泽均匀、无瑕疵要求更严；二级果允许一定比例的瑕疵或规格偏差。

**判断要点**：一级与二级的差价，本质来自“规格达标率 + 外观瑕疵率 + 整齐度”三项，而不是单一维度。所以你谈价时要盯住这三项的具体容差数字。

## 二、价差大概的量级（仅供估算，非佳农报价）

香蕉一级与二级的价差**没有全国统一数**，通常表现为：
- 同一批次内，二级果比一级果**低约 10%–30%**，具体取决于当季该品级货源的稀缺程度。
- 行情紧俏时差价收窄，滞销或瑕疵货集中时差价拉大。

这个区间只能用于你内部的粗略测算，**不能作为与佳农结算的依据**。

## 三、获取准确标准与报价的可靠途径

1. **直接向佳农对接的销售/大区经理索取**：要《产品规格书》《分级验收标准》和当季《报价单》，这是唯一权威来源。
2. **看合同附件的验收条款**：里面通常会写明各等级的容差比例和扣罚规则，价差也常以此体现。
3. **向你的上游一级经销商或口岸代理询价**：同品级同产地的到岸/出货价，可比性最强。
4. **参考批发市场同期同品级成交价**：用于交叉验证，但要注意产地和成熟度差异。
