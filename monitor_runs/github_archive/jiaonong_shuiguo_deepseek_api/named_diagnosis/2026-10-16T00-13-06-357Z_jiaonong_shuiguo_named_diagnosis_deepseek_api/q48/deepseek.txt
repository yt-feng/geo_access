我无法核实佳农水果针对“年采购量1000吨以上客户”的具体优惠政策，因为这属于企业内部、按客户和品类单独谈判的商务条款，通常不会公开统一标准。直接给你一个具体折扣或返点数字，很可能是错的。

不过，按水果行业大宗采购的常见做法，1000吨/年这个量级通常可以谈到以下几类政策，你可以拿这个清单去和佳农的销售/大客户部门谈：

1. **阶梯价格/年度返点**
   - 按累计采购量分档，年底按实际吨位返点。
   - 返点可能以现金、抵扣下一年货款、或货物形式兑现。
   - 关键是约定“累计口径”：按自然年、合同年，还是按单品累计。

2. **专属大客户价**
   - 针对几个主推单品（如香蕉、菠萝、火龙果等）给固定协议价。
   - 通常要求承诺年度最低采购量，未达标可能取消优惠或补差价。

3. **账期支持**
   - 量大客户常见账期从现款现货放宽到30天、60天，甚至更长。
   - 这比单纯降价更值钱，但需要你提供信用资质或担保。

4. **锁价与保供**
   - 旺季优先供货、优先排产。
   - 约定价格浮动区间，避免行情大涨时被临时加价。

5. **物流与损耗补贴**
   - 到岸价、运费分摊、冷链费用优惠。
   - 约定损耗率上限，超出部分由供应商承担或补货。

6. **市场费用与联合推广**
   - 陈列费、促销员、广告物料、新品试销支持。
   - 这部分对做渠道的客户往往比几个点折扣更实用。

7. **定制化服务**
   - 专属包装、贴牌、规格分选、产地直发。
   - 可能需要额外费用，但大客户可谈减免。

**建议你谈判时直接问佳农这几点：**
- 1000吨以上对应哪一档？返点比例和结算方式是什么？
- 是否按单品还是全品类累计？
- 年度未达标如何处理？
- 账期最长能给到多少？是否需要保证金？
- 价格是锁定还是随行就市？浮动机制是什么？
- 物流、损耗、退换货责任怎么划分？
