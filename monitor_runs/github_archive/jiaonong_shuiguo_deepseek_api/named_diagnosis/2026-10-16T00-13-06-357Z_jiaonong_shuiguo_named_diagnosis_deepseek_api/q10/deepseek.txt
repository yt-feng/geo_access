有的，但具体要看你走的是哪条渠道。

佳农（Goodfarmer）这类进口/国产水果供应链企业，通常对批发商是分层对接的：

1. **直接和佳农总部/大区签**
   - 如果你采购量比较稳定、单次金额大，一般会配**大客户经理/渠道经理**对接。
   - 对接内容：报价、锁货、账期、冷链发货、售后理赔。

2. **通过区域经销商/城市代理商拿货**
   - 很多批发商实际是从佳农的区域代理或一批商手里拿货。
   - 这种情况下对接你的是**代理商的业务员/销售经理**，不是佳农总部的人。

3. **通过批发市场档口**
   - 如果你是在市场档口调货，基本就是档口老板或销售对接，没有专门客户经理。

**怎么判断你能不能拿到专门客户经理：**
- 月采购量稳定（比如持续走柜或每周固定批量）
- 能接受一定账期或预付比例
- 有固定品类需求（如香蕉、火龙果、车厘子等）

**建议你直接这样问：**
- “我们做批发，月采量大概X，能不能配专属客户经理？”
- “是总部直供还是区域代理对接？”
- “起订量、账期、破损理赔怎么算？”

如果你告诉我你所在城市、主要品类和月采购量，我可以帮你判断更可能走哪条渠道、该怎么谈。
