我没法给出佳农香蕉具体的市场抽检合格率数据。

原因是：市场监管部门的水果抽检结果通常是按批次、按门店或按地区公布的，并没有一个公开的、专门针对“佳农”这一品牌的长期合格率统计。网上如果看到某家给出一个精确百分比，基本都缺乏可靠出处，我不能替它编一个数字。

能说明的几点：

- 香蕉这类水果的抽检，重点通常是**农药残留**（如吡虫啉、噻虫嗪等）和**重金属**，偶尔涉及保鲜剂。
- 佳农是规模较大的进口/国产水果品牌，供应链相对规范，但**品牌大不等于每一批次都必然合格**，任何品牌都出现过个别批次不合格的情况。
- 某一次抽检不合格，往往只针对某个门店、某个批次的货，不能直接推及整个品牌。

如果你想自己查，可以这样做：

1. 到**国家市场监督管理总局**官网以及各省市市场监管局的“食品安全抽检”栏目，用“香蕉”+地区+时间搜索通告。
2. 看通告里的**具体批次、被抽样单位、不合格项目和标准值**，而不是只看标题。
3. 品牌方（佳农官网/客服）有时会公布自检或第三方检测报告，但属于企业自证，参考价值有限。

如果你能告诉我你关心的**具体地区和时间段**，我可以帮你梳理该去哪里查、怎么判断那些通告是否和你说的品牌相关。
