我不能直接代表佳农水果给你确认政策，因为这类堆头陈列、试吃支持、费用分担属于厂家/经销商和商超之间的**年度框架协议或单店促销协议**，不是公开统一标准。不同区域、不同经销商、不同门店系统（永辉、大润发、华润万家、区域连锁等）条件都会不一样。

不过可以给你一个可执行的判断和谈判思路：

**1. 佳农通常能提供的支持类型**
- 堆头/地堆陈列：一般可以谈，但通常要求门店给到主通道、生鲜入口、水果区端头等位置，并保证陈列周期。
- 试吃支持：香蕉、菠萝、火龙果、蓝莓等单品较常见，但需要门店配合试吃台、人员、垃圾处理。
- 物料支持：围挡、价签、海报、吊旗、地贴、试吃盒、牙签等，部分由厂家提供。
- 促销员/导购：大促或新店开业可能支持，日常不一定。
- 价格支持：特价、第二件半价、买赠等，通常比纯陈列费更容易谈。

**2. 费用分担常见方式**
- 厂家全投：多见于新品推广、重点门店、大促节点，但会要求陈列位置和销量。
- 商超全投：多见于常规堆头，厂家只给货和物料。
- 双方分摊：例如厂家出物料+试吃果，商超出试吃人工和场地；或厂家承担部分堆头费，商超给折扣。
- 以量换支持：商超承诺进货量/陈列周期/门店数，厂家给堆头费或试吃补贴。
- 从货款中扣：部分经销商接受“陈列补贴”“试吃补贴”在后结货款里抵扣。

**3. 你谈判时可以直接问这几个问题**
- 这次促销是单店还是区域多店？
- 佳农是厂家直营还是当地经销商供货？
- 堆头位置、面积、周期分别是多少？
- 试吃由谁出果、谁出人、谁负责食品安全？
- 费用是现金、货款抵扣，还是以赠品/物料形式？
- 如果销量未达标，费用是否返还或调整？

**4. 建议你准备的谈判条件**
- 给出具体门店、档期、陈列位照片和客流数据。
- 明确预计进货量、促销价、毛利空间。
- 提出两个方案让佳农选：
  - 方案A：佳农承担堆头费+试吃果，商超给主通道堆头7天。
  - 方案B：商超承担堆头，佳农给特价+试吃物料+导购1人。
- 如果佳农不直接支持，就找当地经销商谈，因为执行通常在经销商。

**5. 最快落地办法**
直接联系给你供货的佳农业务员或经销商，发一条明确需求：
“某门店某档期，需要佳农某单品堆头陈列+试吃，预计进货X件，要求厂家支持堆头费、试吃果和物料，请确认能提供哪些支持、费用怎么分担。”

如果你告诉我：**城市、商超系统、佳农是厂家还是经销商供货、想做哪个单品、几家店、档期几天**，我可以帮你把谈判话术和费用分担方案写得更具体。
