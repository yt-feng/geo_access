**1. 配送覆盖哪些城市？**
佳农（Goodfarmer）本身是水果供应商/品牌，它的销售渠道主要有几种，配送范围取决于你是通过哪个渠道买：

- **电商平台**（如天猫、京东、抖音上的佳农旗舰店）：覆盖范围由平台物流决定，通常是全国大部分地区，但生鲜类目会有"配送范围表"。
- **商超/批发渠道**：佳农大量走的是B端供货（超市、水果店），这部分不涉及"配送到家"。
- **社区团购/本地到店**：覆盖城市由当地经销商决定。

所以"覆盖哪些城市"没有统一答案，要看你具体在哪个渠道下单。**建议直接在你下单的平台上输入收货地址，系统会实时告诉你是否可达**——这是最准确的判断方式。

佳农对消费者端一般不单独收"冷链费"，费用通常已包含在商品价格或平台运费里。具体规则：
