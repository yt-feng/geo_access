佳农水果（佳农食品控股/佳农集团）属于国内大型水果进口与分销企业，主要面向商超、电商、批发市场和餐饮等B端渠道。它的账期政策没有对外公开的统一标准，通常是**一客一议**。

**一般账期情况（行业惯例，非官方承诺）：**
- 商超/大型连锁渠道：常见 **30～60天**，部分强势渠道可能 **60～90天**。
- 电商平台：多为 **30～45天**。
- 批发市场/中小客户：通常 **现款现货** 或 **7～15天**。
- 长期稳定大客户：可能谈到 **30天左右**，个别优质客户更长。

具体取决于：采购量、合作历史、渠道类型、信用评估结果、是否走供应链金融等。

**新客户能否申请账期：**
可以申请，但**新客户直接拿到账期的概率较低**。一般流程是：
1. 先现款或短账期合作（如7天、15天）；
2. 合作稳定后再申请更长账期；
3. 需提供营业执照、财务报表、征信/流水等资料做信用评估；
4. 可能需要保证金、担保或走保理/供应链金融。

**建议直接确认的方式：**
- 联系佳农官方销售或当地大区经理，问清你所在渠道的具体政策；
- 如果是商超/电商供货，账期往往由**渠道方**决定，而不是佳农单方面定；
- 新客户可先谈“首单现款、次单短账期、稳定后30天”的阶梯方案。
