佳农（佳农食品控股/Goodfarmer）是国内较大的香蕉进口与分销商之一，其香蕉规格通常按**重量、每箱根数、单根粗细/长度、成熟度处理方式**来分。具体规格会随产季、产地（菲律宾、厄瓜多尔、越南、柬埔寨等）和客户定制而变化，所以下面是行业通用的分级逻辑，供你判断和对接时使用；精确到“每箱几根、多少公斤”的现行目录，需要以佳农当季报价单/产品手册为准。

## 一、常见规格维度

**1. 按单根重量/大小**
- 大果：单根约 180–220g 以上，条型粗长
- 中果：单根约 140–180g
- 小果：单根约 100–140g
- 迷你/小蕉：单根 100g 以下或特定品种

**2. 按每箱净重**
- 常见 13kg、12kg、10kg、8kg、5kg 等
- 也有按“件”计，如 4.5kg、7kg 小包装

**3. 按每箱根数**
- 如 4–6 根/把、5–7 根/把，整箱 20–30 根不等
- 高端渠道常用“定根数、定把数”方式

**4. 按成熟度/处理方式**
- 青蕉（未催熟，适合长途、批发、再催熟）
- 催熟蕉（黄蕉，适合商超、水果店直接上架）
- 不同催熟等级（1–7 级色卡）

## 二、按渠道的典型分级标准

### 1. 商超/精品超市
- 偏好中大果，条型均匀、无黑斑、无机械伤
- 单根重量稳定，通常 160–200g
- 催熟到 3–4 级黄，到店即可售卖
- 包装多为 5kg、8kg 小箱或托盘化
- 对农残、外观、冷链要求高

### 2. 水果连锁/社区店
- 中果为主，性价比优先
- 单根 140–180g
- 可接受青蕉或半熟蕉，店内自行催熟
- 常用 10kg、12kg、13kg 箱

### 3. 批发市场/农贸
- 规格跨度大，大果、中果、小果都有
- 更看重耐运输、货架期，外观要求相对宽松
- 青蕉比例高，价格敏感
- 常见 13kg 大箱

### 4. 电商/社区团购
- 小规格、标准化、家庭装
- 单根 120–160g，按根或按把售卖
- 5kg 以下小箱、独立包装
- 需要较好成熟度控制，减少售后

### 5. 餐饮/烘焙/加工
- 可能用等外果、小果、次果
- 更关注出肉率、价格、供应稳定性
- 规格不追求外观统一

## 三、判断与对接建议

1. **先确认产地和产季**：菲律宾、厄瓜多尔、越南蕉的条型、单根重量差异明显。
2. **锁定三个核心参数**：单根重量、每箱净重、成熟度等级。
3. **渠道匹配**：商超要“均匀中大果+催熟”，批发要“耐运青蕉+大箱”，电商要“小规格+稳定熟度”。
4. **索要当季规格表**：佳农不同客户、不同港口、不同月份规格会调整，直接找其销售要最新报价单和分级标准最可靠。
