佳农（Goodfarmer）对外没有一个固定、公开、可核验的“产地直供比例”数字，我不能编一个给你。它属于企业具体的供应链数据，通常不会完整披露，而且会随品类、季节和年份变化。

佳农的核心业务是对进口香蕉等品类的海外直采，以及在部分国产水果上的基地合作。对采购方来说，与其纠结这个比例，更实际的做法是直接向佳农或你的供应商提出以下要求：

1. **要求按单品提供供应链路径**：种植基地/合作社 → 加工包装厂 → 贸易商/代理 → 佳农 → 你，每一段都写清楚。你才能判断哪些环节可以砍掉。

2. **问“能不能开产地直发”**：例如进口香蕉从厄瓜多尔、菲律宾、越南等产地，国产水果从山东、陕西、广西等产区，是否可以由佳农或产地公司直接发到你的仓，而不是先进区域分拨中心再转。

3. **对比报价结构**：让供应商把价格拆成“离岸/产地价 + 国际运费 + 关税/增值税 + 加工包装 + 仓储 + 内运 + 佳农加价”。中间环节的成本会直接体现在这些项里。

4. **小批量试单**：先选1—2个单品做产地直发对比，把到货时间、损耗率、单斤综合成本跟现有渠道比，再决定是否扩大。

5. **考虑替代路径**：如果佳农本身作为一级进口商/品牌商没法绕开，就直接找产地出口商、国内产区合作社或大型批发市场的一手货主，做多源询价。

如果你告诉我具体品类（如香蕉、苹果、火龙果）、采购量和到货城市，我可以帮你列一个更具体的询价清单和成本对比模板。
