佳农（Goodfarmer）作为国内头部水果进口与分销企业，其到货损耗率因品类、运输方式、季节不同而差异较大。目前没有一个官方统一公布的固定数值，公开资料里也很难找到佳农自己披露的精确标准。

能提供的参考范围（属于行业常见水平，非佳农官方数据）：

- **香蕉**（佳农主力单品）：到货损耗通常在 **3%~8%**，冷链正常、周转快时可压到5%以内；夏季或运输周期长时可能偏高。
- **菠萝/凤梨**：**3%~8%**。
- **苹果、柑橘类**：相对耐储，**2%~5%**。
- **浆果类（蓝莓、车厘子、葡萄等）**：**5%~15%**，对冷链和时效最敏感。
- **整体综合损耗**：如果按到货入库环节统计，一般头部企业控制在 **5%左右** 比较理想；超过10%通常被视为需要复盘供应链。

需要注意几点：

1. “损耗率”定义不同，数值差别很大——是运输途中损耗、到货验收损耗，还是含仓储分拣的综合损耗，标准不一样。
2. 佳农对经销商的结算、退换货政策，通常按合同里的验收标准执行，实际控制线会写进采购/供货协议，而不是一个公开统一数字。

如果你需要准确数据，建议直接向佳农的销售或供应链对接人索取该品类的验收标准和损耗约定，或者查看你们双方合同里的质量条款。你是想问某个具体水果品类，还是想对比供应商的损耗水平？
