   - 以佳农官方渠道公示为准：官网、官方微信公众号/小程序、天猫/京东旗舰店、客服电话页面。

2. **周末下单是否有人处理**
   - **下单本身**：大多数电商/小程序周末可以正常下单，系统会接单。
   - **人工处理**：周末是否有客服、仓库、售后人工处理，取决于平台和仓库排班。生鲜类通常会在商品页或结算页标注“发货时间”“周末是否发货”“客服时间”。
   - 如果页面写了“48小时内发货”或“工作日发货”，周末可能顺延到下一个工作日。

3. **最稳妥的确认方式**
   - 在你要下单的具体平台（佳农官方旗舰店/小程序）点开“客服”，看自动回复里的服务时间。

   - 如果急用，优先选页面明确写“周末发货/当日达/次日达”的店铺或商品。
