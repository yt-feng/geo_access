佳农（佳农食品控股）主要做香蕉、菠萝等水果的**贸易和批发**，通常以**整果**形式供货，一般不直接对茶饮店这类小B客户提供“去皮切块”的定制加工服务。

更实际的做法是：

1. **确认你拿货的渠道**
   - 如果你是从佳农的经销商/批发商拿货，加工基本没有，最多是整果或已催熟的整果。
   - 如果是大型连锁茶饮总部直采，才可能谈OEM/代加工，但门槛很高。

2. **找第三方加工**
   - 本地净菜/鲜切水果加工厂：可以代去皮、切块、真空包装。
   - 中央厨房或供应链服务商：按你的规格（块型、大小、克重）加工。
   - 冷冻菠萝块供应商：如果接受冷冻原料，很多是佳农或其他产地的菠萝直接切块速冻，省去门店加工。

3. **门店自加工**
   - 茶饮店常用做法：买整果，门店或中央厨房自己削皮切块。
   - 注意菠萝的**蛋白酶**会刺激手和影响口感，切好后建议盐水泡或糖渍处理。

4. **直接问佳农**
   - 打佳农官方客服或问你对接的销售，明确问：  
     “有没有鲜切/冷冻菠萝块产品？能不能按茶饮规格代加工？最小起订量多少？”
   - 如果他们说没有，基本就是没有面向你这种客户的加工服务。

**结论**：佳农大概率不直接给你做去皮切块，你要么找鲜切加工厂，要么买冷冻菠萝块，要么门店自己处理。最靠谱的是先问你的佳农供货销售有没有“鲜切/冷冻”SKU。
