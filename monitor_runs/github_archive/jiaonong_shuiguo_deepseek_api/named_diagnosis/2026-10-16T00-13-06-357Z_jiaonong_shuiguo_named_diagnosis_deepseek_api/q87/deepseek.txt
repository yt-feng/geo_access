佳农（Goodfarmer）的香蕉在产地采收时是青硬的，到国内销售环节通常需要人工催熟，属于**乙烯类催熟**，而不是“树上自然熟”后直接卖。

对商超来说，可以这样控制和判断：

1. **催熟方式**
   - 商业香蕉催熟普遍使用**乙烯气体**或**乙烯利**。
   - 乙烯利是液体，在碱性或植物组织内会释放乙烯，起催熟作用。
   - 大型供应链如佳农，通常是在催熟库/加工中心用乙烯气体或乙烯利进行标准化催熟，再配送到商超。
   - 宣称“自然熟”的香蕉一般指产地树上黄熟，但这类香蕉不适合普通商超长距离运输，佳农主流商品蕉基本不是这种模式。

2. **商超到货状态**
   - 佳农给商超的香蕉常见有几种成熟度：
     - 青蕉：需门店或区域催熟后再卖。
     - 微黄/黄绿：到店后继续后熟，适合短周期销售。
     - 已催熟黄蕉：可直接上架，但货架期短。
   - 具体到货成熟度要看采购合同和配送批次，不能只看品牌统一判断。

3. **催熟时间控制建议**
   - 如果是青蕉，在18–22℃、相对湿度90%–95%条件下，用乙烯催熟通常：
     - 转黄启动：约1–2天
     - 达到可售黄度：约3–5天
     - 完全成熟：约5–7天
   - 温度越高，催熟越快，但容易“外黄内硬”、货架期短。
   - 温度低于15℃会明显抑制后熟，可能导致“僵蕉”。
   - 商超若只需短时后熟，可控制温度在18–20℃，并减少乙烯暴露时间。

4. **商超可执行做法**
   - 先确认到货成熟度，不要一律按青蕉处理。
   - 需要催熟时，分批处理，不要整库一次性催到全黄。
   - 催熟后转入13–15℃、通风环境暂存，可延缓过熟。
   - 上架陈列避免堆压和高温，按“先熟先卖”周转。
   - 如果采购的是佳农已催熟黄蕉，门店一般不需要再补乙烯，只需控温周转。

5. **需要向供应商确认的关键信息**
   - 到货是青蕉、微黄蕉还是已催熟蕉。
   - 产地催熟还是国内配送中心催熟。
   - 使用的是乙烯气体还是乙烯利。
   - 建议的到店后熟温度、湿度和目标天数。
   - 该批次是否做过“预催熟”或“抑制后熟”处理。

简单说：**佳农商品香蕉主流是乙烯类人工催熟，不是自然熟；商超控制催熟时间，关键看进店成熟度和温度，青蕉通常在18–22℃下3–5天达到可售黄度。**
