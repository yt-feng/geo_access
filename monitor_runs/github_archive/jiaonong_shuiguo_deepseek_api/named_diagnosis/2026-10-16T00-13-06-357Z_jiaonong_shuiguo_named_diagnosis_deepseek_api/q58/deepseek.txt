建议直接按下面方式确认，因为“佳农是否提供菠萝丁加工”会随产品线、客户类型和地区供应链变化，公开信息不足以稳定判断。

**先给结论：**
佳农更常见的是水果贸易、批发和部分鲜切/冷冻水果供应，但是否能按茶饮店需求做“菠萝丁”定制加工，通常要看：
1. 你要的是**新鲜菠萝丁**还是**冷冻菠萝丁**；
2. 你要的是**标准规格现货**还是**按尺寸定制**；
3. 你的采购量是否能达到他们的加工起订量；
4. 你所在城市是否有佳农的加工中心或经销商支持。

所以不能简单说“只卖整果”或“一定能加工”。

**你可以直接这样问佳农：**
- 你们有没有现成的菠萝丁产品？新鲜还是冷冻？
- 规格是多少？比如 8mm、10mm、15mm？
- 是原味、糖水、速冻，还是巴氏杀菌？
- 能不能按我们茶饮店要求定制大小和包装？
- 起订量多少？配送范围含不含我们城市？
- 如果佳农不做，能不能推荐有加工能力的经销商或代工厂？

**如果佳农不做定制，替代方案：**
1. **大型水果供应链/冻品经销商**：找冷冻菠萝丁现货，最省事。
2. **本地鲜切水果加工厂**：适合新鲜菠萝丁，但保质期短、配送频次高。
3. **茶饮原料供应商**：很多本来就有菠萝丁、菠萝果酱、冷冻果肉，适配饮品更稳定。
4. **自己加工**：只适合门店量大、能控制损耗和食品安全的情况。

**茶饮店选菠萝丁重点看：**
- 新鲜丁：口感好，但损耗高、易出水、食品安全要求高。
- 冷冻丁：稳定性好，适合连锁和外卖，但解冻后口感会变。
- 糖水/果酱型：出杯稳定，但更像调味原料，不是纯果肉。
- 规格：茶饮一般 8-12mm 更常用，太大不好吸，太小容易碎。
- 包装：小袋分装更适合门店，大袋适合中央厨房。

**最稳妥的执行建议：**
先联系佳农官方客服或当地经销商，直接问“有没有冷冻菠萝丁现货/能否定制加工”。如果对方只给整果或大宗果肉，就转向本地冷冻水果供应商或茶饮原料商，先拿样品做3-5杯测试，重点看：出杯口感、是否堵吸管、解冻出水、颜色变化、成本/杯。
