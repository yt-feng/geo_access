我无法确认“佳农水果菠萝进口量11.4万吨”这个数据的具体年份和增长率。

原因是：这类企业级进口量数据通常来自佳农官方发布、海关统计、行业报告或媒体报道，不同来源口径（公司自报、集团合计、单品项、进口国别）差异很大，我手头没有可核验的权威出处，不能直接判定它是否为2025年数据，更不能给出准确的同比增长率。

建议你按下面方式快速核验：

1. **看原始出处**
   - 如果来自新闻稿/公众号/展会材料，看标题或正文是否写明“2025年”“2024年”“2024/25产季”等时间口径。
   - 如果写的是“2024/25产季”，那它通常不是自然年2025年数据，而是跨年水果产季。

2. **区分口径**
   - 是“佳农集团菠萝进口量”，还是“佳农水果某公司”？
   - 是“鲜菠萝”还是包含菠萝制品？
   - 是“中国口岸进口”还是“全球采购/销售量”？
   口径不同，11.4万吨对应的年份和增长率会完全不同。

3. **查官方来源**
   - 佳农官网、官方公众号、上市公司公告（如涉及）。
   - 中国海关总署统计数据、海关信息网。
   - 中国食品土畜进出口商会、水果行业协会报告。
   - 新华社、央视、第一财经等主流媒体报道。

4. **如果只想要增长率**
   需要同时拿到：
   - 2025年进口量：11.4万吨？
   - 上一年同期进口量：比如2024年是多少万吨？
   公式是：  
   **增长率 =（本期数 - 上期数）÷ 上期数 × 100%**
