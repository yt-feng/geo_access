可以帮你梳理判断路径：

**关于损耗率**
- 行业平均5%是常见口径，但要注意统计口径差异：是"到货环节损耗"（卸货验收时扣重），还是"全程损耗"（含运输、仓储、催熟、门店）。口径不同，数字差很多。
- 佳农主打高端香蕉（如进口蕉、都乐等竞品对标），理论上到货损耗会优于行业平均，可能控制在2%~3%量级，但这是基于行业经验的推测，不是核实数据，仅供参考，不能当事实引用。
- 真正准确的做法是直接向佳农销售/大客户经理索要：①损耗定义与统计口径，②历史批次的实际到货扣重数据（可要求提供3~6个月样本）。

**关于赔付条款**
需要区分两种情况：
- **你是经销商/采购方**：以合同为准，通常会在采购合同中约定"到货验收标准+损耗超标赔付/补货条款"，比如超出约定损耗率的按比例退款或补货。这需要看具体签约文本。
- **佳农作为供货方对下游**：是否主动承诺赔付，取决于其商业政策和客户等级，大客户通常可谈。

**建议直接问佳农的3个问题**
1. 到货损耗按什么口径统计，基准值是多少？
2. 超出基准的部分如何赔付——按金额退、按重量补货，还是下批抵扣？
3. 验收争议（如腐烂、机械伤、青熟度不达标）的判定标准和时限是什么？
