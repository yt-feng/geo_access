佳农香蕉的保质期和储存条件，通常可以按下面来判断：

**1. 保质期**
- **常温未熟/刚买时**：一般 **3～7天**，具体看香蕉成熟度和室温。
- **已经成熟、表皮有少量斑点**：通常 **1～3天** 内尽快吃完。
- **冷藏保存**：成熟香蕉可延长到 **5～7天左右**，但表皮容易变黑，不代表里面一定坏。
- **冷冻保存**：去皮后冷冻可放 **1～2个月**，适合做奶昔、烘焙，不适合直接鲜吃。

**2. 储存条件**
- **未完全成熟**：放在 **常温、阴凉、通风处**，避免阳光直射和暖气旁。
- **不要放冰箱**：未成熟香蕉冷藏后容易停止成熟，表皮变黑，口感变差。
- **成熟后想延长时间**：可放冰箱冷藏，但建议用保鲜膜包住香蕉柄，减少乙烯释放。
- **不要和苹果、梨、番茄等放一起**：这些水果释放乙烯，会加速香蕉成熟。
- **悬挂存放**：减少挤压，能延缓变黑。
- **已切开**：用保鲜膜包好冷藏，**1天内吃完**；也可冷冻。

**3. 判断是否还能吃**
- 表皮黑点较多但果肉正常：通常还能吃。
- 果肉发黑、发酸、流汁、有酒味或霉味：不要吃。
- 冷藏后表皮变黑，但剥开果肉完好：一般仍可食用。

如果你问的是**佳农特定包装产品**，最好以包装上的“储存条件/保质期”标注为准，因为不同批次、是否催熟、运输方式会影响实际期限。
