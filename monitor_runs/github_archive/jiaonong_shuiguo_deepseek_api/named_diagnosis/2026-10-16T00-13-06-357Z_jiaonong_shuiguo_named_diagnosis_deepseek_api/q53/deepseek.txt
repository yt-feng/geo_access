可以，但需要先确认你找的是哪一层“佳农”：

1. **佳农食品控股（集团）/佳农水果业务**  
   这类品牌方通常不会给单店或小连锁直接配“专岗对接人”，一般走区域经销、渠道商或重点客户经理。  
   如果你要的是稳定专岗，通常要满足：  
   - 有固定月度采购量  
   - 多门店统一配送  
   - 账期/结算稳定  
   这样区域销售才可能给你配**客户经理/渠道经理**做固定对接。

2. **区域经销商/一批商**  
   更容易配专岗，因为他们靠门店复购吃饭。  
   你可以直接要求：  
   - 固定业务对接人  
   - 固定客服/订单群  
   - 缺货、压货、售后谁负责  
   - 响应时限写进合作确认

**建议你直接这样提要求：**
> 我们是水果连锁，门店数__家，月采购佳农香蕉约__箱/__吨，配送城市__。需要固定对接人，负责报价、下单、到货异常、售后。请提供姓名、电话、微信，并确认响应时间：工作时间内__分钟回复，缺货__小时内给替代方案。

**如果对方还是响应慢，采购上做3件事：**
- 不要只留一个业务员，必须拿到**主管/区域经理**电话
- 所有订单走微信群或邮件，避免口头扯皮
- 同时备一个替代供应商，佳农可以主推，但不能唯一依赖
