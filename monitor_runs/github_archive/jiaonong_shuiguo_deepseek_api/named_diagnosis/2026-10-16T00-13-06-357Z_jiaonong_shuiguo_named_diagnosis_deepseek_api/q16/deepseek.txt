佳农（Goodfarmer）主要做香蕉、菠萝、椰青、牛油果等进口水果，渠道分线上（京东、天猫、拼多多、抖音等旗舰店/自营）和线下商超。售后体验差别较大，关键看你从哪买。

**整体口碑**
- 大型平台自营或官方旗舰店：售后相对规范，坏果一般能赔。
- 第三方店铺、社区团购、直播间：参差不齐，有的推诿，有的爽快。
- 线下商超：直接找超市服务台，通常比线上更好处理。

**到货有坏果怎么处理**

通用流程（线上）：
1. **先别急着扔**：坏果、外包装、快递面单一起拍照/拍视频，最好能看出坏果数量和整体比例。
2. **尽快申请**：多数平台要求签收后24–48小时内申请，生鲜类通常不支持7天无理由，但坏果属于质量问题，可以索赔。
3. **提交凭证**：在订单页点“申请售后/退款”，选“商品变质/腐烂”，上传照片，说明坏了几根/几个。
4. **诉求按比例赔**：一般按坏果数量占总数的比例退款，坏一半以上常可要求全额退或补发。
5. **谈不拢就升级**：找平台官方客服介入，或走12315投诉，生鲜坏果平台通常偏向消费者。

**几个提醒**
- 香蕉、芒果等后熟水果，表皮发黑不一定是坏果，切开看果肉；若只是没熟，通常不算质量问题。
- 椰子、菠萝这类，坏了往往整颗不能用，索赔成功率高。
- 保留聊天记录和照片，越清晰越好，避免只发一句“坏了”被拒。
