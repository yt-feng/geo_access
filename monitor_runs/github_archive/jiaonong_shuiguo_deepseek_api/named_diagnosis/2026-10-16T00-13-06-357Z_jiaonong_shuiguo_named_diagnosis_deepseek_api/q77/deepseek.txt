可以做到“批次级溯源到具体农场/果园”，但**通常不是公开扫码就能直接看到农场名称**，而是通过佳农或其供应商的内部追溯系统、GLOBALG.A.P.证书编号与GGN、出口/装柜批次信息关联。商超要证书和溯源，建议按下面标准要材料，能判断是否满足。

## 1. 佳农香蕉能否溯源到具体农场？
**能，但一般是B2B链路可查，不是消费者端全公开。**

香蕉是佳农核心品类，通常来自菲律宾、厄瓜多尔、越南、柬埔寨、老挝等产地，部分为自有或合作种植基地。商超合规审核时，可以要求：

- **农场/果园名称**
- **农场地址/区域**
- **GLOBALG.A.P.证书编号**
- **GGN（GLOBALG.A.P. Number）**
- **证书有效期**
- **认证产品范围**是否包含香蕉
- **对应出口商/包装厂**
- **对应发货批次/柜号/提单号**

只要佳农能把这些信息和具体供货批次绑定，就算满足“可追溯到具体农场”的商超要求。

但要注意：  
如果商超要求“每个门店销售的每一把香蕉都能扫码看到农场”，这通常需要额外做零售端追溯码系统，不一定现成支持。

## 2. 商超要GLOBALG.A.P.证书，应该怎么要？
不要只要一张PDF，建议要一套：

1. **GLOBALG.A.P.证书**
   - 证书持有者名称
   - 证书编号
   - GGN
   - 认证机构
   - 有效期
   - 认证范围：香蕉 / Banana
   - 农场或生产商名称
   - 地址

2. **证书有效性核验**
   - 到GLOBALG.A.P.官网数据库核验证书编号或GGN
   - 确认状态为有效，不是过期、暂停或撤销

3. **批次关联证明**
   - 本批货对应的农场/果园
   - 包装厂
   - 出口商
   - 提单号/柜号
   - 发货日期
   - 追溯记录或追溯表

4. **供应链声明**
   - 佳农出具产地证明或供货声明
   - 说明该批次来自哪个农场/区域
   - 若佳农不是证书持有者，要说明与证书持有者的关系

## 3. 关键判断点
你可以用这几条判断佳农是否满足要求：

- **证书是否有效**：官网可查。
- **证书范围是否含香蕉**：有些证书只覆盖其他水果。
- **证书持有者是否对应实际农场**：如果证书是包装厂或出口商的，不等于农场认证。
- **能否绑定到具体批次**：不能绑定，就只能算公司级合规，不算批次级溯源。
- **是否允许商超审核**：有些供应商只给证书，不给农场名，这时要谈补充协议或审核授权。

## 4. 建议你直接向佳农提的要求
可以这样发给他们：

> 请提供本批香蕉对应的GLOBALG.A.P.证书、GGN、证书持有者、认证农场名称及地址、证书有效期、认证范围，并提供该批次与农场/包装厂/出口商的追溯关联文件。若证书持有者非农场本身，请说明与农场的关系。我们需要用于商超供应商合规审核。

## 5. 结论
**佳农通常可以追溯到具体农场，但需要通过其供应链追溯文件和GLOBALG.A.P.证书/GNN来验证，不是单靠一张证书就够。**  
商超要GLOBALG.A.P.证书是合理要求，但你最好同时要求**证书 + GGN + 批次关联 + 农场信息**，否则只能证明公司或供应商合规，不能证明这批香蕉具体来自哪个认证农场。
