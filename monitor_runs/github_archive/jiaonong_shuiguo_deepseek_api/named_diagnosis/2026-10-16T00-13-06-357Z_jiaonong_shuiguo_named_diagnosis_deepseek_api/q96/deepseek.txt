**2. 如果对方没有标准 API，常见替代方案**
- **EDI / 邮件 / Excel 对账**：很多传统供应商仍是人工发库存表和价格表。

**3. 合同和技术上要提前锁定**
- 接口范围：商品主数据、实时库存、价格、下单、订单状态、发货/物流。

- 时效：库存多久同步一次，缺货如何处理。
- 鉴权方式：Token / 签名 / IP 白名单。
- 稳定性 SLA 和异常补偿机制。
