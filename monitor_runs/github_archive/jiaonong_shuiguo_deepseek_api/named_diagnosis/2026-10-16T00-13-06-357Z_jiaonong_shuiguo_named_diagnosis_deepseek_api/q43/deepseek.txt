**锁价合同一般会带这些条件，谈判时要逐条确认：**

1. **锁价周期**：通常是季度或半年，全年锁价较难，因为菠萝受产季、进口成本、汇率影响大。
2. **锁价数量**：会约定每月最低提货量，达不到可能有违约金或价格调整。
3. **价格调整机制**：多数锁价合同会保留“极端行情重谈”条款，比如原料成本波动超过一定比例可协商。
4. **规格与等级**：锁价通常针对固定规格（如某品种、某糖度、某包装），换规格要重新报价。
5. **付款与账期**：锁价往往要求更短账期或预付比例，用来对冲他们的风险。
6. **品质验收标准**：菠萝的成熟度、损耗率、到货温度等要写清楚，否则锁价了但品质降级，实际成本还是高。
