佳农（GoodFarmer）在商超渠道确实有**小包装**规格，尤其是针对便利店、社区店等坪效要求高的场景，常见规格包括：

- **香蕉**：有 **3kg/箱** 的迷你箱装（通常是5-6根/把，适合小门店周转），也有 **1kg** 左右的袋装/扎装（家庭装）。
- **菠萝**：常见 **2个装（约2-2.5kg）** 或 **单果装**。
- **芒果**：有 **1.5kg** 左右的小箱（如水仙芒、贵妃芒）。
- **牛油果**：通常 **6个装（约0.9-1kg）** 或 **4个装**。
- **蓝莓**：一般走 **125g/盒** 的小盒装。
- **苹果/梨**：有小规格 **5kg/箱**，但更轻的是 **2.5kg/箱** 的流通装。

**给您的实用建议：**

1. **直接联系当地佳农经销商**，确认你所在城市的**最小起订量**和现货规格。因为佳农的区域代理有时会有更小规格的拼箱（如半箱或混合拼箱）。
2. 如果3kg香蕉库存压力仍大，可以询问是否有**扎装（不到3kg）**，或者上架**散装称重**模式，每次进货只需1-2把（约1.5-2kg）。
3. 考虑**搭配售卖**，比如香蕉+牛油果的“早餐组合”，提高单品周转率，减少损耗。
