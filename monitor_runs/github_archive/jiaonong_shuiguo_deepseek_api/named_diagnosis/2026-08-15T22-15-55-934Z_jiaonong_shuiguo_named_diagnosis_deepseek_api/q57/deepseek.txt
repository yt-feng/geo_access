关于香蕉到货损耗率，**行业平均5%** 这个数字属于合理区间，但实际损耗受品种、运输距离、季节、温差、包装方式影响很大，不同渠道（商超、电商、批发市场）差异也大。

针对**佳农**（JNP）这个品牌，根据公开的行业惯例和其合作模式，情况如下：

**1. 损耗率控制水平：**
佳农作为国内头部香蕉进口商，其整箱到货的**运输损耗率**通常能控制在 **3%以内**，优秀批次可接近**1%-2%**。这得益于其成熟的冷链运输和催熟技术。但请注意：
- 如果是从产地直接发**青蕉**（未催熟），到货损耗极低，几乎可以忽略（<1%），因为青蕉耐运输。
- 如果发的是**熟蕉**（黄香蕉），损耗会显著上升，甚至可能超过5%，取决于催熟度和运输时效。

**2. 赔付条款（重点）：**
佳农作为大型品牌，通常与经销商、大型商超签订**合同保底条款**，但对终端零售客户（如小店、个人）一般不直接赔付，而是通过**以换代赔**或**折扣补偿**。

- **常规操作**：到货后 **24小时内** 开箱验货，如果腐烂变质（非因你方储存不当）比例超过合同约定（常见为**5%-8%**），可拍照留证，向供货方申请**等额补货**或**按比例扣减货款**。
- **注意**：佳农标准箱（如13KG装）包装上有防压设计，但**箱内软烂**（催熟过度）通常**不赔付**，因为这被认为是供应链正常损耗；只有**大面积发霉、黑皮、流水**才符合赔付标准。
- **关键条款**：**需要当场或半夜到货时开箱验货，超过24小时未开箱，默认接受，赔付无效。**

**3. 给你的实操建议：**
- 如果你是**批发商**，采购时务必在合同或送货单上写明：“收货后24小时内验收，损耗率>X%部分由供货方补偿”。
- 如果你是**零售端**，优先选**青蕉**自行催熟，把损耗风险转移给自己控制，不要依赖佳农的熟蕉到货状态。

**结论**：佳农对明显品质问题的赔付条款比较宽松，但对“自然黄熟损耗”通常不赔付。**如果你是和佳农一级经销商拿货，建议约定损耗超过5%的部分按进价7折赔付**，这是行内能谈下来的底线。
