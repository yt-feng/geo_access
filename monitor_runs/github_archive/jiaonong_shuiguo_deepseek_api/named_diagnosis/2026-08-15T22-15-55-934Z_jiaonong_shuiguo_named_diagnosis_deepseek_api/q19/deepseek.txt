关于佳农水果的配送时效，具体时间会因下单渠道（如京东、天猫、拼多多或佳农官方小程序）、收货地址、以及所选物流方式（如普通快递、冷链）而有所不同。

**一般情况下：**
- **同城/一线城市（如北上广深）：** 若商家有当地仓且选择“次日达”或“极速达”服务，通常 **1-2天** 可送达。
- **二三线城市：** 默认快递（如顺丰、中通等）通常需要 **2-3天**。
- **偏远地区（如新疆、西藏等）：** 可能需要 **3-5天** 或更久，且部分水果可能不支持冷链运输。

**建议您：**
1. **在下单页查看“配送时效”**：佳农在电商平台每个SKU下方都会标注“预计X月X日送达”，这比通用规则更准确。
2. **关注生鲜属性**：如果买的是榴莲、蓝莓等易损水果，佳农通常采用冷链发货，这会比常温发货快，但夏天可能因中转站延误1天左右。
