**分级标准**（根据行业通用及佳农公开信息整理）：
1. **一级果（A级）**：果形均匀，长度约18-22厘米，无机械伤、无病虫害，表皮无黑斑或极轻微（不超过1%），成熟度一致，单把重量通常在1.5-2.5公斤，糖度高（18°Bx以上）。
2. **二级果（B级）**：长度可稍短（15-18厘米），允许少量轻微表皮擦伤、水渍或斑点（不超过5%），果形允许轻微畸形，成熟度可略不均，但须保证食用品质。

**价格差异（重要提示）**：
