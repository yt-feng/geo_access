以下是根据行业通用标准和佳农常见做法整理的参考信息，**建议你在采购或咨询时，直接联系佳农官方销售或查看其最新产品手册，以确保准确性**：

### 1. 常见规格（按包装箱）
- **净重规格**：常见为 **13.5公斤/箱（30磅）** 或 **18公斤/箱（40磅）** 两种标准出口箱。
- **果指数量**：按每把（梳）果指数量分，例如 **5-7个/把**（大果）、**8-9个/把**（中果）、**10个以上/把**（小果）。通常大果单价更高。

### 2. 分级核心标准（推测/通用）
香蕉分级主要看**长度（果指长度）** 和 **成熟度（色卡等级）**。

- **长度分级（果指从外弯到内弯的最长直线距离）**：
  - **特级（Super）**：果指长度通常在 **20厘米以上**，外观无瑕疵，适合高端零售或礼盒装。
  - **一级（Class I）**：果指长度在 **18-20厘米**，允许轻微生理性斑点，是主流超市货架标准。
  - **二级（Class II）**：果指长度在 **15-18厘米**，外观允许明显疤痕但无腐烂，适合餐饮、加工或低价促销。

- **成熟度分级（色卡Stage）**：
  - **Stage 1-2（全绿）**：适合远途运输，长期存储，发往仓储冷库。
  - **Stage 3-4（绿转黄）**：适合批发市场、生鲜电商，到店后自然催熟。
  - **Stage 5-7（全黄或带斑）**：即食状态，适合便利店、水果店、餐饮店直接售卖。

### 3. 不同渠道的分级对应建议
- **商超/高端零售（如盒马、山姆）**：优先选择**特级或一级果**，果指长、色泽均匀，成熟度建议Stage 4-5，需冷链到店后上架。
- **生鲜电商（美团买菜、叮咚等）**：通常选**一级果**，需耐受打包运输，成熟度控制在Stage 5左右，避免过度成熟导致损耗。
- **餐饮/果汁店**：多选**二级果**（成本较低），成熟度可到Stage 6-7，口感软糯但外观要求不高。
- **批发市场/社区团购**：混级或二级为主，按重量售卖，对成熟度要求不严格。
