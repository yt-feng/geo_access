关于佳农水果（Goodfarmer）的**到货损耗率**，并没有一个公开的、统一标准的官方固定数值。因为损耗率受**水果品类、运输距离、季节、包装工艺、以及供应链管理水平**等多种因素影响。

不过，从行业经验和水果批发/零售的常规标准来看，可以给你以下参考范围：

**1. 行业一般水平（非官方）：**

-   **品质较好的水果（如佳农香蕉、苹果、橙子等）：** 从产地到终端零售（如商超、电商仓），**到货损耗率通常控制在 3% - 8%** 之间。如果全程冷链和包装到位，这个数字可以压低到 **3% - 5%**。
-   **易腐或娇贵水果（如蓝莓、草莓、车厘子、芒果等）：** 损耗率会相对较高，一般允许在 **5% - 10%**，甚至在极端天气下可能达到 **10% - 15%**。

**2. 佳农的优势（公开信息可查）：**

佳农在行业内以**全产业链管理和自有冷链**著称。他们在香蕉等核心品类上，通过产地标准化采摘、催熟库精准控制以及减震包装，能将损耗降到远低于行业平均水平。部分公开报道或行业交流中，佳农高管曾提到其香蕉的端到端损耗率可以控制在 **3% 左右**，这属于行业内非常优秀的水准（普通散装香蕉批发损耗率可达10%以上）。

**给你的建议：**

-   **如果你是采购方（批发/电商）：** 不要单看一个比例，务必要在采购合同中**约定“到货损耗赔付标准”**，例如“允许损耗≤5%，超出部分按成本价补偿”。佳农通常支持到货即时抽检，发现问题可走售后流程。
-   **如果你是消费者：** 你在超市买到的佳农水果，如果出现个别坏果，那属于终端陈列损耗，不在“到货损耗”范畴。你有权依据超市售后政策（通常“坏果包赔”）进行换货或退款。

**如果你需要精确数据用于商业决策，建议直接联系佳农区域销售经理，索要其在该品项、该季度的质检报告（通常合同中会有“允许损耗条款”的具体数字）。**
