佳农香蕉的保质期和储存条件取决于购买时的成熟度以及储存方式，以下是具体建议：

**保质期：**  
- 常温（未开封冷藏）：一般3~7天，具体看香蕉的成熟阶段（青绿色比黄色更耐放）。  
- 冷藏：切开或去皮后保质期较短，约1~2天；整根香蕉不建议冷藏过久（皮会变黑，但果肉可食，不影响食用安全）。  

**储存条件：**  
- **未成熟（青皮）**：置于室温（18~25°C）、通风干燥处，避免阳光直射，可自然催熟，通常2~5天变黄。  
- **已成熟（黄色带斑点）**：室温下尽快食用，可放入冰箱冷藏，但皮会变黑，果肉质地可能变软，建议在1~3天内吃完。  
- **切开后**：用保鲜膜包裹切口，放入冰箱冷藏（4°C左右），当天或次日食用完毕。  
- **不宜**：不要放在高温、高温潮湿（如厨房水汽重处），也不要和苹果、梨等会释放乙烯的水果混放（会加速过熟）。  

**注意事项：**  
- 若香蕉出现霉斑、异味或果肉变黑腐烂，请丢弃，勿食用。  
- 冷藏的香蕉皮变黑是正常「冷害」现象，不代表变质，可剥皮检查果肉是否完好。  

如您是指佳农特定包装（如即食香蕉片、香蕉干等），保质期和储存请以包装标签为准。
