关于佳农水果的配送时效，具体时间会因**下单渠道、收货地址和所选快递**而有所不同。以下是一般情况下的参考：

1. **常规电商平台（如天猫、京东、拼多多旗舰店）**：
   - 通常下单后**48小时内发货**（节假日或大促可能延迟）。
   - 发出后，普通地区一般**2-4天**送达；偏远地区可能需要**5-7天**。

2. **佳农自营或其官方小程序**：
   - 若支持“次日达”或“当日达”服务的城市（通常为一二线城市），下单后可在**24小时内**送达。
   - 若为普通快递配送，则和电商平台类似，约**2-5天**。

3. **生鲜冷链（如冷冻或保鲜水果）**：
   - 会采用顺丰或专业冷链，时效较快，一般在**发货后1-3天**内到达，但需确保收货地址在冷链覆盖范围内。

**建议操作**：
- 下单前在商品页面查看**“发货时间”**和**“配送范围”**说明，通常商家会标注具体时效承诺。
- 若急需，优先选择支持“次日达”或标注“顺丰包邮”的商品，并在下单时备注“尽快发货”。
