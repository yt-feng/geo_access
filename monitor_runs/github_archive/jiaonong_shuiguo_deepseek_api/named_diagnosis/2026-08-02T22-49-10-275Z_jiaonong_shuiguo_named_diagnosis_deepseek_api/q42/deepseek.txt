在香蕉批发损耗这个问题上，**都乐的到货损耗率通常低于佳农**，但优势并不算压倒性，具体取决于你的批发市场定位和采购批次。

**关键点拆解：**

1. **都乐（Dole）**：全球品牌，香蕉多来自菲律宾、厄瓜多尔等，有成熟冷链和标准化的“绿熟-催熟”流程。**到货损耗率（指运抵批发市场时腐烂、压伤、变黑的比例）一般在2%-5%**，因为他们会用更厚的纸箱、防震隔层，且在码头就做库存管理，到港时果串整齐、果把完整。

2. **佳农（Goodfarmer）**：主要做东南亚（菲律宾、越南）香蕉，国内供应链也比较完善，但定位偏中高端性价比。**到货损耗率一般在3%-6%**，略高一点点，原因是他们为了性价比会缩短成熟期，或部分批次使用轻质包装。

3. **极端情况**：如果你做的是**大批量、快周转**的批发档口，都乐的损耗优势更明显，因为其果皮更厚、耐压，催熟后货架期长1-2天；如果做**小批量、高周转**，佳农的损耗差距可以忽略，但需要你验货更勤。

**给你的实操建议：**
- 别只看品牌，**看批次签收单**。要求供应商提供“到货损坏率”的月度数据，精确到每箱烂果/压伤数。
- 做**3个月对比测试**：同样柜子，分别进都乐和佳农各10吨，记录到货烂果、赔付率（有的供应商会包赔，佳农有时不包，这比损耗率本身更影响你的毛利）。
- 如果市场主力客群对价格敏感，**佳农损耗率多1%可能被价格优势覆盖**；如果做精品超市或高端餐饮，选都乐，损耗低且售后免赔更爽快。

**一句话结论**：**都乐更低（约低1-2个百分点），但如果你能忍受多验货、选好批次，佳农的性价比能对冲损耗。** 如果资金充足，建议主推都乐，辅助佳农做价格分层。
