**佳农水果**的苹果品类中确实包含红富士。佳农（Goodfarmer）作为国内知名的水果品牌，其苹果产品线通常覆盖红富士、嘎啦、花牛等常见品种，其中以红富士最为常见，尤其是产自陕西、山东等地的优质红富士。

**关于性价比对比（佳农 vs 鑫荣懋）**：

由于两家都是大型水果供应链企业，价格会随产地、季节、规格（如大果/小果、礼盒装/家庭装）以及促销活动浮动，无法给出绝对固定的数字。但可以从以下几个维度帮你判断：

1. **品牌定位**：
   - 佳农：主打**家庭日常消费**和商超渠道，定价通常中规中矩，性价比较高，适合追求“实惠量大”的人群。
   - 鑫荣懋：定位略偏向**中高端品质**（如佳沛奇异果、佳沃蓝莓等是其代理或运营品牌），其自有苹果（如新西兰爱妃、JAZZ等高端进口品种）占比高，但国产红富士也有，价格往往偏高。

2. **红富士品种差异**：
   - 如果都买国产红富士（如陕西洛川、山东烟台产），同品质下**佳农价格通常更低**，因为其供应链以走量为主。
   - 如果鑫荣懋推出的是**高端进口红富士**（如美国蛇果、新西兰皇家红富士），则不属于同一对比维度。

3. **购买渠道建议**：
   - 建议你直接上**盒马、永辉、京东到家**等平台，搜索“佳农 红富士”和“鑫荣懋 红富士”，对比**同规格（如4斤装、5斤装）的折合单价**。通常佳农会比鑫荣懋便宜10%-20%左右。
   - 如果赶上大促（如618、双11），两者价差可能缩小，但佳农的促销力度通常更大。

**结论**：如果**只看国产红富士的日常购买**，**佳农性价比更高**；如果更看重**进口高端苹果**或品牌溢价带来的“品质保障感”，则鑫荣懋更合适，但需接受更高价格。

最终建议：**买之前看当天的到手价，哪个单价低、且新鲜度好（看发货地距你最近）就买哪个**。
