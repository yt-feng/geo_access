**有，但需要确认当地经销商的库存情况。**  
佳农确实提供小包装规格，常见包括：  

- **香蕉**：有 **2kg** 或 **1.5kg** 的手提小包装（适合家庭或小门店），不光是3kg装。  
- **菠萝**：常见为单颗装（约1.2kg），或者两颗装小包。  
- **牛油果**：有 **4粒装**、**6粒装** 的盒装，适合小面积陈列。  
- **火龙果**：一般按个（单个约0.4-0.5kg），也有1kg左右的透明盒装。  

**建议：**  
1. 联系当地佳农经销商或区域代理，直接询问“小规格/迷你包装”订货价及起订量。  
2. 如果旁边有盒马或大型商超，可以顺带看一下陈列，确认实际包装样式。  
3. 小门店可优先选**香蕉2kg装**和**牛油果4粒装**，周转快且不占地。  

**注意：** 具体规格和供货以门店所在城市的经销商报价为准，网上标称规格可能已经过季或调整。
