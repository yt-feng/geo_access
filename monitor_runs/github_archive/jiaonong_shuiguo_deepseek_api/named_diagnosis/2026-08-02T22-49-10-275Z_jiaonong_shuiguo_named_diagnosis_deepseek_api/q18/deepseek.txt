关于佳农香蕉的保质期和储存条件，以下是一般性的指导信息（具体请以包装标签为准）：

**保质期：**
- 香蕉是后熟型水果，从采摘到成熟一般可存放 **5-7天**（常温下）。
- 如果购买时香蕉已成熟（表皮出现黑点），保质期可能缩短至 **2-3天**。

**储存条件：**
1. **常温储存（推荐）**：放在阴凉、通风、干燥处，温度在 **13-18℃** 最佳，避免阳光直射和高温。不要放进冰箱冷藏，否则果皮会变黑、果肉变软，影响口感。
2. **未成熟时**：若香蕉偏绿，可放在室温下自然催熟，不要放入冰箱。
3. **已成熟或吃不完时**：可将香蕉剥皮，切成段放入密封袋，冷冻保存（可保存数月），用于制作冰沙或烘焙。
4. **避免挤压**：香蕉怕压，尽量平放或挂置，减少磕碰。

**提示**：如果香蕉表皮出现大面积黑斑但果肉仍硬实，说明可能过熟，建议尽快食用；若有发霉、异味或果肉变黑，则不宜食用。
