关于香蕉到货损耗率，行业平均确实在5%左右（通常指运输、卸货及终端存储过程中的自然水分蒸发和磕碰损耗）。**佳农作为头部香蕉品牌，其品控标准通常要求到货损耗率控制在3%-5%之间**，具体数值会因产地、成熟度、运输距离（国内冷链或海南/云南产地直发）以及季节有所不同。

**关于赔付条款，你需要重点确认以下三点（以采购合同或平台规则为准）：**

1.  **“到货损耗”的判定标准**：佳农一般按“净重”结算，损耗超过约定比例（如2%）的部分，会按单价扣减结算款；如果是电商或商超渠道，通常有“坏果包赔”承诺，客户收到坏果可在48小时内凭照片申请赔付。
2.  **赔付触发条件**：赔付通常只针对**运输过程中造成的明显霉变、大面积压伤**，而非单纯的“自然失水”或“表皮黑点”（香蕉自然成熟会释放乙烯导致表皮变黑，属正常现象，不赔）。
3.  **单据要求**：收货时必须当面对数量，如有大量破损需拍照留存，并在48小时内向供应商提交“到货异常报告”，否则可能按无问题处理。

**给你的实操建议：**
- **如果是从批发市场进货**：合同里明确写“损耗超3%部分按成本价退款”，并要求“到货时开箱抽检”，不要全凭口头承诺。
- **如果是电商平台采购（如盒马、京东）**：详情页一般有“坏果包赔”标签，直接按平台售后规则操作，但注意保鲜期（通常发货后7天内的问题才算）。

**无法替你确认的是**：佳农具体给到你的经销合同中的“绝对值”（因为针对KA客户、批发商、线上渠道条款不同）。建议你直接查看采购协议中的“品质与数量验收”“违约责任”章节，或咨询佳农官方客服（400电话）。若对方只口头承诺，务必要求补充书面补充协议。
