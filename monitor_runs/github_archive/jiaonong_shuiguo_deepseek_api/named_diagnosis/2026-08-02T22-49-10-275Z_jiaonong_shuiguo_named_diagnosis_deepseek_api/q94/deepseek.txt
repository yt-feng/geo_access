**佳农香蕉分级标准（行业通用参考）**  
佳农作为品牌香蕉供应商，其分级通常参考国际标准（如欧盟或国内行业标准），主要依据果指长度、粗细、饱满度、表皮完好度、成熟度及外观瑕疵进行划分：

- **一级果（A级/特级）**：  
  - 果指长度通常在18-22厘米或以上（按品种不同，如国产蕉和进口蕉有差异）。  
  - 果形笔直、粗细均匀，无弯弓畸形。  
  - 表皮光亮、无黑斑、无机械伤、无病虫害痕迹。  
  - 成熟度一致（催熟后色泽金黄，无青黄混杂）。  
  - 整把果（手）排列整齐，柄部完好。

- **二级果（B级/普通）**：  
  - 果指长度稍短（如15-18厘米），粗细不均。  
  - 允许少量轻度表皮瑕疵（如轻微黑点、撞伤但未伤及果肉）。  
  - 成熟度可能不完全一致（部分稍青或稍熟）。  
  - 允许有轻微弯曲或畸形，但不影响食用。

**价格差异（参考范围）**  
批发市场价格波动大，且受季节、产地（如菲律宾进口蕉 vs 海南/广西国产蕉）、运输成本、供需关系影响。根据近年行业常见行情：

- **一级果**较**二级果**批发价通常高**15%-30%**。  
  例如：若二级果批发价为每箱（约13公斤/箱）60元，一级果可能在70-80元/箱左右（具体看单箱净重和品质）。
