关于佳农水果的到货损耗率，目前没有公开的官方统一标准数值（具体数值通常属于企业内部管理数据，且会因水果品类、运输距离、季节和仓储条件不同而有较大差异）。

不过，根据生鲜水果行业的普遍运营经验，可以给你一个参考范围：

- **一般行业水平**：对于香蕉、苹果、橙子、梨等耐储存的常规水果，到货损耗率通常控制在 **3% - 5%** 以内。
- **高端或易损耗品类**：对于草莓、蓝莓、车厘子、芒果、榴莲等娇贵或熟度敏感的水果，损耗率会更高，通常控制在 **5% - 8%** 左右，部分极端情况下可能超过10%。
- **仓储与门店端**：如果指的是仓库到门店或门店到货的损耗，通常会比产地直发的长途运输损耗控制得更低，一般要求 **1% - 2%**。

**建议：**
如果你是在做采购预算或门店管理，建议按 **5%** 作为一个参考基准来预留损耗成本；如果是特殊时令（如高温夏季或长途海运），建议按 **8%-10%** 预留。同时，影响损耗的实际因素（如冷链是否到位、包装是否完好、收货验收是否严格）往往比一个固定数字更重要。

如果你需要更精确的数据，建议直接联系**佳农官方客服或区域销售经理**，他们可以提供针对具体品种和发货地的实际到货损耗率参考。
