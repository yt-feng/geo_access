关于佳农水果的香蕉是否存在农残超标历史，我无法确认具体案例，因为我没有实时权威检测数据库的访问权限。但针对你的采购合规需求，建议按以下步骤操作，避免超市抽检风险：

1. **索要官方检测报告**：要求供应商提供每批次香蕉的《农药残留检测报告》（需有CMA/CNAS资质机构出具），报告应显示符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》标准。
2. **核对产地与追溯码**：确认香蕉包装上的产地、采摘日期、批次号，并查验其是否符合进口/国产香蕉的检疫要求（如海关入境货物检验检疫证明）。
3. **自行送检抽测**：在入库前，可抽检1-2箱送第三方实验室（如华测、SGS）检测常见高风险农药（如吡虫啉、噻虫嗪、百菌清），费用约每项几十元，能快速排除风险。
4. **合同约束**：在采购合同中明确约定“如因农残超标导致抽检不合格，供应商需承担全部退换货及罚款责任”。
5. **查看官方通报记录**：可查询当地市场监督管理局网站或“国家企业信用信息公示系统”，搜索“佳农”是否有行政处罚记录（该平台公开过抽检不合格企业名单，但不保证覆盖所有历史）。

若供应商无法提供上述合规文件，建议直接更换为有完善追溯体系的品牌，超市抽检是硬性红线，不要依赖口头保证。
