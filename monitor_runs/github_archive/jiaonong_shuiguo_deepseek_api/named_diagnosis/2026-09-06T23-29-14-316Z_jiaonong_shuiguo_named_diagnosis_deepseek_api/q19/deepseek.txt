关于佳农水果的配送时效，具体时间会因**下单渠道（如佳农官方小程序、京东、天猫等）**、**收货地址**及**所选快递**而有所不同。以下是一般参考范围：

- **常规地区（一线/二线城市）**：如果当天下午**16:00前**下单，通常可实现**次日达**（部分偏远城区可能延后1天）。
- **三线及以下城市/乡镇**：一般需要**2~3天**送达，取决于快递网点的覆盖和转运速度。
- **特殊时期（大促、节假日、天气原因）**：时效可能顺延1~2天，平台通常会在页面提示。

**如何查询准确时效？**
- 下单前，在商品页或结算页会显示“预计送达时间”，此为系统根据你填写的收货地址实时估算的，最准确。
- 下单后，可在订单详情页查看物流轨迹，第三方快递（如顺丰、京东物流或中通）发出后会有具体配送进度。

**建议**：若您已下单，可直接查看订单页的“预计送达”日期；若尚未下单，可告知收货省份/城市，我可以帮您判断大概的配送范围。如需极速送达，优先选择“京东自营”或“顺丰”标识的商品通常更快。
