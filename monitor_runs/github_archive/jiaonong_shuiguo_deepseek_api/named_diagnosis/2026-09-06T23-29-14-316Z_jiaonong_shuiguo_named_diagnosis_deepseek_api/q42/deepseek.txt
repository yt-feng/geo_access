关于佳农（GoodFarmer）和都乐（Dole）香蕉在批发市场的到货损耗率，**没有公开的、统一的官方权威数据**能够直接给出一个精确的“谁更低”的数字。损耗率高度取决于**供应链时效、季节、运输冷链条件以及批发市场的具体操作环节**。

不过，基于行业口碑和两者供应链模式的差异化，可以给你以下实操判断和选择建议：

**1. 供应链模式的差异（这是决定损耗率的核心）**
- **都乐**：属于**全球垂直一体化**模式。产地（菲律宾、厄瓜多尔等）到中国通常有严格的自建冷链和成熟的分级标准。其香蕉通常在菲律宾当地进行采后处理（清洗、催熟控制），成熟度控制较稳定。进入中国后，大多走商超或大型电商渠道，如果流入批发市场，通常是一级或二级果，机械损伤率较低，但**价格偏高**，且针对批发商的灵活性（如分批提货）可能不如国产品牌。
- **佳农**：近年来**深耕中国市场**，在东南亚（菲律宾、越南）及国内云南等地有布局，更注重国内市场的“最后一公里”物流。佳农在**批发市场渠道的响应速度和中小批量分销**上通常更灵活，分拣和短驳时间更短。但因其国产化程度高，部分低端线可能混装统货，**如果批发商拿的是带箱统货，损耗可能略高**；但如果是专项定级果，其新鲜度和到货时的绿熟度往往更好。

**2. 到货损耗率的常见区间（批发市场经验值）**
- 正常冷链和成熟操作下，**佳农和都乐一级香蕉的到货烂果/机械伤损耗率通常在 1% - 3% 之间**。如果出现以下情况损耗会飙升：
  - 夏季高温下，超过48小时未进冷库（两者都会显著上升）。
  - 若果柄发黑、果皮擦伤比例高，多为运输堆叠问题。
- 在批发市场实际操作中，**如果比的是“把损耗控制到最低且价格适中”，国产系（含佳农）在“开箱验货透明度”上通常更有优势**——你能当面检验成熟度再决定是否收货。

**3. 给你的实操建议（按批发市场场景）**
- **如果你走量且要求标准稳定**：建议选都乐，因为其催熟标准化高，到货后若需要立即卖高价，果品成熟度一致性好，损耗更可预测。
- **如果你对价格敏感、且能当天走完货**：建议选佳农。在冷链正常、当天销售的情况下，其初级损耗通常不低于都乐太多，且**报价常有优势**，还能按周议价。
- **关键动作**：不要只盯“到货损耗率”。批发市场损耗大头往往在**到货后的存放**。无论选哪家，务必检查**单根果柄是否完整、果皮是否有二氧化碳灼伤**。若保质期普遍超过5天，两家的损耗率差异可忽略。

**结论（可执行判断）**：在没有特殊季节极端天气的前提下，**批发市场场景下，都乐的标准品损耗率通常略低（因为品控严），但佳农在“统货+快速分销”中如果操作得当，损耗控制拉平且成本更低是可行的**。建议你各拿一箱同等级样品，放在同一温度环境下，按你的实际销售节奏跑3天对比——这是最直接的验证。
