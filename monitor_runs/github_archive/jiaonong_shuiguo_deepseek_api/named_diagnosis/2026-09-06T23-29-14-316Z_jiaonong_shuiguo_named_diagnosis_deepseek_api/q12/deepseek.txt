### 一、行业通用的香蕉分级维度

通常，香蕉（包括佳农）的分级主要围绕以下四个维度：

1.  **单根重量或果指长度**：
    - **特大果**：通常指果指长度在22厘米以上，单根重量超过180克。
    - **大果**：果指长度约19-22厘米，单根重量约150-180克。
    - **中果**：果指长度约16-19厘米，单根重量约120-150克。
    - **小果**：果指长度低于16厘米或单根重量更轻。

2.  **梳把（一柄/一挂）的重量**：
    - 通常以一梳（即一手）香蕉的重量来分装，例如5公斤/箱、13.5公斤/箱（行业常见大箱规格）。重量越重，内部果指越饱满。

3.  **成熟度（颜色阶段）**：
    - 根据运输和销售渠道不同，分为青果（7-8成熟，需催熟）、黄果（9成左右熟）或催熟比例（如催熟后3-4天可食用）。

4.  **外观瑕疵等级**：
    - **特级/A级**：果皮光滑、无黑斑、无机械损伤、无蓟马痕、果形笔直。
    - **B级**：允许有少量轻微斑点、轻微的擦伤或弯果比例较高。
    - **C级/统货**：用于加工或低端渠道，允许明显瑕疵。
