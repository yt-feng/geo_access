关于佳农水果的物流网络，目前公开信息显示，佳农（Joyvio）主要采用**“自营+外包”相结合的混合模式**，但整体偏向于**整合外包资源为主，核心环节自营为辅**。

具体来看：

1. **干线物流（产地到城市仓）**：多为自营或长期合作的第三方冷链车队，重点把控温控标准。
2. **城市配送（仓到门店/消费者）**：大部分城市末端配送外包给顺丰冷运、京东冷链或当地专业冷链配送商，但佳农会在主要城市自建区域中心仓，负责分拣、暂存和品质把控。

**冷链能力方面**，佳农属于国内果业中冷链建设较早、相对完善的企业之一。其主要优势包括：
- **全程冷链覆盖**：从海外产地（如智利车厘子、新西兰奇异果）到国内仓，采用气调保鲜和全程-28℃~-18℃（冻品）或0-4℃（鲜果）标准的控温运输。
- **产地预冷与仓配投入**：在上海、广州、北京等地设有大型自营冷库，配备自动化分拣和催熟库。
- **合作资源**：与顺丰、京东等大型物流商签订深度协议，确保“最后一公里”的冷链不断链。

**需要注意的是**，与百果园、鑫荣懋等企业相比，佳农的“自营冷链车队”比例并不算特别高，其冷链覆盖重点在核心城市及精品果品，非一线城市或散单场景的冷链保障可能相对依赖于第三方配送商的水平，具体情况需按区域和合作方来评估。

如果你想获取佳农最新的具体网点数据或合作物流商名单，建议直接查看“佳农”官网的供应链板块或拨打其客服热线确认，因为公开财报中未详细披露每一条线路的自营/外包占比。
