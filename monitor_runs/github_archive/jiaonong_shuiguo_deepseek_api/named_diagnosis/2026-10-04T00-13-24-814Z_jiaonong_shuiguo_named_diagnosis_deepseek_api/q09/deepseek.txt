佳农（Goodfarmer）作为国内头部水果进口与分销企业，其到货损耗率并没有对外统一公布的官方标准，具体要看品类、运输方式（海运/空运/陆运）、季节和到货港口。所以下面给的是行业通行区间和判断口径，而不是佳农的官方承诺值：

**按品类大致可参考的到货损耗率区间**

- **香蕉**：到货损耗通常控制在 **3%~8%**。这是佳农的主力单品，全程冷链和催熟管理较成熟，正常批次可以压到5%以内，但夏季或港口压港时可能超过8%。
- **苹果、梨等耐储品类**：到货损耗一般在 **2%~5%**。
- **柑橘类（橙、柑、柚）**：通常在 **3%~7%**，取决于产地和是否打蜡保鲜。
- **葡萄、提子**：较敏感，**5%~10%**属正常，冷链断链会明显升高。
- **浆果类（蓝莓、车厘子/樱桃等）**：损耗最高，**5%~15%**都可能，车厘子海运到货并分选后，可售率衰减尤其明显。
- **热带水果（火龙果、芒果、山竹等）**：**5%~10%**较多见。

**注意区分几个概念**

1. **到货损耗率**：卸货、入库、分选前的损耗。
2. **分选/加工损耗率**：剔除烂果、次果后的损耗，这部分会额外叠加。
3. **可售损耗率**：从到货到门店/客户签收全过程损耗，通常高于"到货损耗"。

所以如果你拿到的是"到货损耗率2%"，未必等于整批只损2%，后面分选和配送还会再损一部分。

**实际判断建议**

- 如果你是要和供应商约定标准，不要问"一般多少"，而要按**单品+运输方式+季节**分别写进合同，比如"智利车厘子海运到上海港，卸货前到货损耗≤5%，超过部分由供方承担"。
- 行业里常用的验收口径是：**以卸货时抽检或全检的烂果、软果、霉变果占比计算**，需要在合同里明确抽检比例和判定标准。
- 佳农这类企业通常还会用"好果率/可售率"而不是单纯"损耗率"来考核，因为对下游客户更直观。
