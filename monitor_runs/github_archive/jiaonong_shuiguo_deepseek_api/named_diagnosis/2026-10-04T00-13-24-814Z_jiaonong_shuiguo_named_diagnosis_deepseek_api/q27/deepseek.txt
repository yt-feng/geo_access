佳农（Goodfarmer，佳农食品控股）主要是进口香蕉、菠萝等水果的供应链企业，合作对象通常是商超、电商、批发市场和餐饮连锁等 B 端客户。账期并不是公开统一的固定标准，通常按客户类型、采购规模、合作历史和信用评估来定。

**一般账期情况（行业常见做法，非佳农官方统一政策）**
- 新客户或小额合作：多为**现款现货、款到发货**，或先款后货。
- 稳定中小客户：常见**15～30 天**。
- 大型商超、电商平台、连锁餐饮：可能谈到**30～60 天**，个别强势渠道更长。
- 部分生鲜供应链对核心大客户会有**月结**，比如“月结30天”或“月结60天”。

**新客户能否申请账期**
可以谈，但通常门槛较高。新客户一般较难直接拿到账期，除非满足以下条件：
- 有稳定的采购量和持续订单；
- 能提供营业执照、财务报表、征信或银行流水等资信材料；
- 有担保、保证金或预付款比例；
- 通过佳农的信用评估和内部审批。

实际操作中，新客户往往是先现款合作一段时间，建立交易记录后再申请账期，账期长度也会从短到长逐步放开。

**建议**
如果你是要和佳农合作，最直接的方式是联系佳农当地销售或大客户部，说明采购品类、月采购量、结算方式和信用情况，让对方给出具体账期方案。不同区域、不同品类、不同销售渠道的政策可能不一样，网上没有统一答案。
