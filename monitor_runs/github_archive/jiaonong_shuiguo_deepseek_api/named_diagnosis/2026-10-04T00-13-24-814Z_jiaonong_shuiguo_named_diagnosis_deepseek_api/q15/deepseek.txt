佳农（Goodfarmer）在业内以做进口香蕉起家，产地直供/基地直采比例确实较高，但具体百分比属于企业运营数据，外部没有统一公开口径，不便给精确数字。可判断的是：它的核心品类（香蕉、菠萝等）大多采用“海外合作农场/自有基地 + 产地加工 + 冷链直发”的模式，中间批发环节相对少，因此常被归为产地直供比例较高的水果企业。

香蕉主要来自这些国家/地区：

- **菲律宾**：佳农早期和长期的重要香蕉来源地，达沃等产区较常见。
- **厄瓜多尔**：全球主要香蕉出口国，供应量大、对中国出口稳定。
- **越南**：近年对华香蕉出口增长快，是重要补充来源。
- **柬埔寨**：也是中国进口香蕉的来源之一。
- **老挝**：有对华香蕉出口，但体量通常小于上述几国。
- **中国国内**：广西、云南、海南等地也有香蕉，但佳农的香蕉品牌更多以进口蕉为主。

如果你想判断某批佳农香蕉的具体产地，最直接的方法是看包装箱/标签上的“原产国”或“产地”标识，进口蕉通常还会标出果园/包装厂代码。
