**常见可团购/送礼的佳农礼盒方向**
- **进口水果礼盒**：如佳农常做的香蕉、菠萝、奇异果、车厘子（季节性强）等组合或单品礼盒。
- **高端单品礼盒**：车厘子、蓝莓、牛油果等，礼盒装更适合送礼。
- **组合礼盒**：多种水果搭配，适合企业福利、节日送礼。
- **企业定制**：部分渠道支持加印LOGO、贺卡、定制包装，适合团购。

**怎么确认是否有货、能不能团购**
1. **看官方渠道**：佳农官网、官方公众号/小程序、天猫/京东旗舰店，通常会标注“礼盒”“团购”“企业采购”。
2. **问电商客服**：直接问“有没有礼品团购水果礼盒”“能否定制LOGO/贺卡”“多少箱起订”“能否开票”。
3. **找当地经销商**：佳农在多地有经销商和批发渠道，企业团购往往走当地经销更灵活。
4. **看节日档期**：春节、中秋、端午等节点礼盒最全，平时可能以单品为主。

**团购前重点确认**
- 起订量、配送范围、是否冷链
- 能否开发票、能否定制包装
- 礼盒内容是否可替换
- 到货时间和售后破损赔付规则
