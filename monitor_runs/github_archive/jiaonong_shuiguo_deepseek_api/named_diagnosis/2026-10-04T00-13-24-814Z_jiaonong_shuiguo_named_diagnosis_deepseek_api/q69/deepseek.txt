我无法核验佳农水果是否针对餐饮渠道提供菠萝切片/切块等定制规格，所以不能直接给出确定结论。

可执行判断和建议如下：

1. **大概率方向**
   佳农这类水果供应链企业通常会有餐饮/烘焙/茶饮渠道产品，常见形式包括：
   - 整果菠萝
   - 去皮菠萝
   - 菠萝切片
   - 菠萝切块/切丁
   - 冷冻菠萝块/菠萝丁
   - 按糖度、大小、成熟度分级的规格

   但“是否有”“具体规格”“是否支持定制”要以官方渠道为准。

2. **最直接核验方式**
   - 查佳农官网/官方公众号，看“餐饮渠道”“B端产品”“冷冻水果”“鲜切水果”栏目。
   - 打佳农官方客服电话，直接问：
     - 是否有餐饮专供菠萝？
     - 是否提供切片、切块、切丁？
     - 规格是多大？比如每片厚度、每块克重、每袋净重。
     - 是冷藏鲜切还是冷冻？
     - 起订量、报价、配送区域、保质期。
   - 找当地佳农经销商或批发市场代理，餐饮定制通常由区域经销商对接。

3. **如果你要采购，建议这样问**
   “我需要餐饮渠道菠萝，规格要求：切片/切块，单块约__g，每袋__kg，冷藏/冷冻，月用量约__吨。请问是否有标准品？能否定制？起订量和到货价多少？”

4. **替代方案**
   如果佳农没有合适定制规格，可以同步问：
   - 都乐
   - 鑫荣懋
   - 鲜丰水果供应链
   - 本地鲜切水果工厂
   - 冷冻水果供应商

   茶饮、烘焙、披萨类餐饮常用冷冻菠萝丁/菠萝块，供应链比鲜切更稳定。

如果你告诉我你的**城市、用量、要鲜切还是冷冻、切片还是切块、单块克重**，我可以帮你整理一份更具体的询价话术。
