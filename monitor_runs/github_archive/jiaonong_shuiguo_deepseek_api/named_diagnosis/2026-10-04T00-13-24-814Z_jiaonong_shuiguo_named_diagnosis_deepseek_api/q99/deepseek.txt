**1）先看包装/标签上的有机标识**
中国大陆销售的有机产品，正规标识通常包括：
- 中国有机产品认证标志（“有机”字样+认证标志）
- 有机码（17位，可在中国食品农产品认证信息系统查询）
- 认证机构名称
- 生产者/加工者名称

如果包装上只有“绿色食品”“无公害”“自然熟”“生态”等字样，**不等于有机认证**。

**2）向佳农索要三份文件**
对高端渠道，建议直接要求供应商提供：
- 有机产品认证证书（在有效期内）
- 认证范围是否覆盖“菠萝/鲜菠萝”这个具体品类
- 该批次产品的有机销售证/有机码或追溯信息

注意：认证证书可能覆盖某基地或某品类，但不一定覆盖你采购的这个规格、包装厂或批次。

**3）核验认证真伪**
拿到有机码或证书编号后，到“中国食品农产品认证信息系统”或认证机构官网核验。重点看：
- 证书状态是否“有效”
- 认证产品是否包含菠萝
- 生产基地/加工厂是否与供货一致
- 证书是否被暂停、撤销或过期

**4）区分“有机菠萝”和“有机加工产品”**
如果是鲜菠萝，按鲜果有机认证判断。  
如果是去皮菠萝、冷冻菠萝、菠萝罐头等加工品，要看加工有机认证，不能只看鲜果证书。

**5）高端渠道建议的合同条款**
如果对方声称有机但无法提供完整文件，建议不要按有机产品采购。可在合同里写明：
- 供应商保证产品符合有机认证要求
- 提供有效证书、有机码、批次追溯文件
- 如认证不实或无法追溯，承担退货、赔偿及渠道损失
