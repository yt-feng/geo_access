我无法核实佳农水果当前的配送城市清单，所以不能直接告诉你你们县城是否在配送范围内。这类信息会随季节、仓库和合作渠道变化，最可靠的做法是下面几种：

1. **看官方渠道**  
   在微信搜“佳农水果”公众号/小程序，或看天猫、京东上的“佳农官方旗舰店”，商品页通常会写“配送范围”或下单时输入地址会提示能否送达。

2. **直接问客服**  
   在官方小程序或电商店铺里联系客服，发你的**完整收货地址（省+市+县/区+乡镇）**，问是否支持配送、发什么快递、是否冷链、几天到。

3. **用地址试下单**  
   把县城地址填进结算页，如果系统能选到你的乡镇/街道并显示运费和时效，一般就是能送；如果选不到或提示“不支持配送”，就是送不到。

4. **注意“县城能到”和“乡镇能到”是两回事**  
   很多生鲜水果只送到县城城区或指定自提点，乡镇、村组可能不送，或者只送到镇上的快递点。你最好把地址写到具体乡镇，再问客服。
