公开渠道没有一个可核验的“佳农水果产地直供比例”统一数字，佳农在不同品类、渠道、年份的做法不一样，不能直接引用一个固定百分比。对采购来说，更实用的做法是把“产地直供”拆成可验证的指标，而不是盯一个来源不明的比例。

**你可以这样推进：**

1. **要求供应商明确口径**
   让对方说明“产地直供”指哪种：
   - 从种植基地/合作社直接发到你们仓；
   - 从产地加工厂/包装厂直接发；
   - 仍经过一级批发商或配送商。
   口径不同，成本差异很大。

2. **索要可验证材料**
   - 具体基地/合作社清单及地址；
   - 采购合同或订单流；
   - 发货地、加工地、物流轨迹；
   - 批次检测报告和溯源码。

3. **直接谈去中间环节的采购模式**
   可要求：
   - 产地直发你们指定仓库；
   - 按单品、按产季签直采协议；
   - 由产地做分级、包装、冷链，你们减少二次分拣；
   - 对比“产地出厂价 + 物流 + 损耗”与当前到仓价。

4. **用总成本而不是只看到仓价**
   水果直采的真实成本包括：采购价、包装、冷链、损耗、账期、质检、退换货。中间环节减少后，如果损耗和资金占用上升，未必真降本。

5. **小批量试点验证**
   选1—2个单品、1—2个产地做试采，对比：
   - 到仓综合成本；
   - 损耗率；
   - 到货合格率；
   - 交付稳定性。
   跑通后再扩大。

**结论：**佳农的产地直供比例没有可靠公开数据可确认。建议不要按“比例”谈判，而是要求对方提供具体单品的供应链路径和直采方案，用试采数据验证能否真正减少中间环节、降低成本。
