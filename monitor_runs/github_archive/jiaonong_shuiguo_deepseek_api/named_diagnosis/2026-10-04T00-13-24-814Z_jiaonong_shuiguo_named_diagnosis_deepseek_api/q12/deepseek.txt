佳农水果（佳农食品控股旗下品牌，以香蕉进口分销为主）的香蕉规格，通常会按“重量/条数/成熟度/外观等级”交叉划分。但我无法核验其官网或内部文件的具体编号，所以不能给出确切的官方SKU清单。下面按行业通行做法给你一套可判断、可执行的规格与渠道分级建议，你可以据此对照佳农实际报价单或产品手册。

**一、常见规格维度**

1. **按单根重量（最常用）**
   - 小果：约110–130g/根
   - 中果：约130–160g/根
   - 大果：约160–200g/根
   - 特大果：200g以上/根

2. **按每箱净重/条数**
   - 4.5kg、7kg、13kg、18kg等箱规
   - 每箱条数：如6–8条、9–12条、13–16条等

3. **按成熟度**
   - 青蕉（催熟前）
   - 微黄/转黄（催熟中）
   - 黄熟（即食）

4. **按外观等级**
   - A级：果形端正、无擦伤、无黑斑、色泽均匀
   - B级：轻微擦伤或果形略弯，不影响食用
   - C级：明显擦伤、斑点较多，适合加工或特价渠道

**二、不同渠道的分级建议**

| 渠道 | 推荐规格 | 分级重点 |
|---|---|---|
| 商超/精品超市 | 中果至大果，A级，黄熟或微黄 | 外观整齐、无斑点、条数一致 |
| 水果连锁/社区店 | 中果，A/B级，微黄 | 性价比高、耐摆放 |
| 电商/到家 | 中果，A级，青蕉或微黄 | 抗运输、到货后催熟 |
| 批发市场 | 大果/特大果，B级，青蕉 | 耐储运、价格敏感 |
| 餐饮/加工 | 中果以下，B/C级 | 出肉率、成本优先 |
| 特价/团购 | B/C级，黄熟 | 快速周转、低价 |

**三、判断建议**

如果你要确认佳农的具体规格：
1. 直接看佳农报价单或装箱单上的“规格编号/净重/条数/等级”。
2. 问经销商要“产品分级标准表”，通常会有果指长度、粗度、单根重、允许瑕疵比例。
3. 以到货实测为准：抽检10–20根，称单根重、量果指长度、数斑点面积。
