关于佳农水果（佳农食品控股/Goodfarmer）是否提供“锁价3个月”这类价格保护机制，我无法给出确定的官方政策结论，公开信息里也没有一个稳定、可核验的“锁价3个月”条款。

可以分几个层面判断：

1. **一般生鲜行业惯例**
   香蕉属于典型的高波动生鲜品，产地、汇率、海运、天气、港口、催熟损耗都会影响价格。绝大多数水果品牌或供应商不会对下游客户做“锁价3个月”这种长期固定价格承诺，因为上游采购成本本身就在变。更常见的是：
   - 短期锁价：7天、15天、30天；
   - 阶段性报价：按周/按月更新；
   - 保底价+浮动价；
   - 返利、补贴、价差补偿；
   - 大客户年度框架协议，但价格随行就市。

2. **佳农可能的做法**
   佳农作为大型水果供应链企业，通常会和商超、电商、批发客户签框架协议。里面可能有：
   - 约定报价周期；
   - 价格调整提前通知；
   - 促销补贴；
   - 质量赔付；
   - 账期和返利。
   但“锁价3个月”是否适用，取决于客户类型、采购量、合同条款、品类和区域，不是统一公开政策。

3. **如果你是要和佳农谈合作**
   可以直接问对方销售或渠道经理这几个问题：
   - 报价有效期是多久？
   - 是否支持锁价？锁价周期最长多少？
   - 锁价期间如果产地涨价，是否仍按锁价执行？
   - 如果跌价，是否有价差补偿或返利？
   - 锁价是否要预付、保证金或最低采购量？
   - 锁价适用于哪些规格、等级、包装和到货地？
   - 异常天气、船期、汇率波动是否属于不可抗力调价情形？

4. **现实建议**
   如果你担心香蕉价格波动，不要只追求“锁价3个月”。更稳妥的是：
   - 短周期锁价，比如15—30天；
   - 分批采购，摊平成本；
   - 约定价格调整公式，而不是一口价；
   - 设置最高限价和最低保底；
   - 用返利或补贴代替长期锁价；
   - 把质量、损耗、到货时间一起写进合同。

简单说：**佳农不一定有公开统一的“锁价3个月”机制；即使有，也大概率是针对特定大客户、特定合同谈出来的，不是标准政策。** 如果你要确认，最可靠的方式是直接找佳农官方渠道或你的对接销售要书面报价条款。
