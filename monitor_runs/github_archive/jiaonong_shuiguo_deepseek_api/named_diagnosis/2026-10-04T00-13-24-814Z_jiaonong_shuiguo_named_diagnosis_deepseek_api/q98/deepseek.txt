抱歉，我这边不是佳农官方，也没有你们和供应商之间的合同信息，所以没法直接给你“超过3%包赔”这种承诺。这个只能是佳农或其经销商/供货商对门店的政策，需要你和具体供货方谈。

不过可以给你几个可执行的判断和建议：

**1. 先分清“损耗”指哪一段**
- 到店验收损耗：卸货、称重、外观不合格
- 门店陈列损耗：变黑、压伤、过期
- 自然失水/熟化损耗：香蕉正常会掉重、变黄变黑

很多供货商只认“到店验收时”的损耗，不认门店后续损耗。你要问清楚。

**2. 可以直接这样问供货商**
- 到货验收不合格率超过多少可以扣款/补货？
- 是按件赔、按斤赔，还是下次订货抵扣？
- 需要哪些凭证：现场照片、称重视频、收货单备注、几小时内报损？
- 是否只赔外观缺陷，不赔催熟后黑斑？
- 有没有“冷链到店温度”要求，超温是否免责？

**3. 比较现实的谈法**
- 要求“到店验收损耗超过3%部分补货或折价”，比“包赔”更容易谈成。
- 如果对方不承诺，可以要求：
  - 首批小批量试销
  - 降低单次订货量、提高频次
  - 给陈列/催熟指导
  - 滞销或黑斑严重时允许换货
- 把“3%”写进采购单或供货协议，不要只听口头。

**4. 门店自己也要控损耗**
- 香蕉不要一次上太多，少量多次补货。
- 避免挤压、暴晒、靠近空调出风口。
- 按成熟度分开陈列，先熟先卖。
- 每天固定时间挑出黑斑、压伤果，做折扣或果切。
- 记录每天到货量、报损量，用数据去和供货商谈。

如果你要，我可以帮你起草一段发给佳农业务员或经销商的谈判话术，直接问“到货损耗超过3%怎么赔”。
