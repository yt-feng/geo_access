佳农（Goodfarmer）主营香蕉、菠萝等水果的**种植、进口和批发分销**，其标准业务是整果贸易，面向商超、批发市场和部分餐饮渠道。**没有公开信息显示佳农提供菠萝丁这类定制加工服务**，通常这类鲜切/切丁加工是由下游的净菜加工厂、中央厨房或食品加工厂完成的。

不过实际情况可能因区域和渠道而异，建议按下面方式确认：

1. **直接问佳农当地经销商或大区销售**：问的是"能否提供鲜切菠萝丁/速冻菠萝丁"，而不是"卖不卖菠萝"。有些经销商手里会有合作的加工资源，甚至能帮你对接。
2. **区分你要的形态**：如果是**糖水菠萝丁罐头**或**速冻菠萝丁**，那属于食品加工品，找罐头厂或速冻食品厂更对口，佳农一般不直接做。
3. **备选方案**：茶饮店用量稳定的话，常见做法是——买佳农整果自己门店切，或者找专门的**鲜果切配供应商/净菜厂**按规格供货（比如1cm见方），后者更省人工、规格也统一。

简单说：**佳农大概率只卖整果，不接切丁加工**，菠萝丁建议找鲜切或速冻加工厂。是否要我再帮你列一下找这类供应商时该问的参数（规格、糖度、是否糖渍、冷冻还是冷藏、保质期）？
