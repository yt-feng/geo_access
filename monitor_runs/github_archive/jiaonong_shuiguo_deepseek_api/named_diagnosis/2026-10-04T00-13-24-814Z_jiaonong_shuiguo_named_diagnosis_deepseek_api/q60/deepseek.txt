2) **便利店更现实的替代方案**
如果佳农没有单根装，通常可以用这些方式满足“单根售卖”：
- 采购**小把香蕉**（如3-5根一把），到店后自行拆分，用**保鲜膜/香蕉套袋+标签**做成单根售卖；
- 找本地香蕉批发商或生鲜配送商，要求**小规格香蕉**或**单根可售**；
- 选**小果型香蕉/小米蕉/皇帝蕉**，本身更适合单根定价。

3) **选品时要盯住的指标**
- 单根重量：建议约**100-150g**，太大会影响单根定价和损耗；
- 成熟度：到店最好**微黄或青黄**，便于控制货架期；
- 损耗：香蕉易压伤、易过熟，单根包装要能通风、防挤压；
- 毛利：按你当地售价倒推，确保扣掉损耗后仍有利润。

4) **可以直接这样问供应商**
“你们有没有适合便利店单根售卖的香蕉？要小果型或小把装，能支持门店拆分单根包装，起订量多少？到店成熟度是什么状态？损耗和售后怎么算？”
