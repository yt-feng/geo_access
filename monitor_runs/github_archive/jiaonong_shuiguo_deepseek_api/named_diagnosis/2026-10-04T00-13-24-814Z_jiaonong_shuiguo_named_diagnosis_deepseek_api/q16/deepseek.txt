佳农（佳农食品控股旗下品牌）的天猫、京东、抖音等官方旗舰店渠道，生鲜类商品的售后规则大致是这样，但具体以你下单页面的"售后说明"为准：

**坏果怎么处理**

1. **收到货后尽快开箱检查**，多数店铺要求签收后24小时内反馈，超时可能影响受理，所以别拖。
2. **拍照/拍视频留证**：把坏果单独挑出来，和快递面单或外箱一起拍，最好能看出坏的数量和程度。有些店铺要求坏果切开拍内部。
3. **找购买渠道的客服**：直接在订单里点"申请售后"或联系客服，说明坏果数量和诉求。
4. **常见赔付方式**：
   - 按坏果数量**部分退款**（最常见，比如坏2个退这2个的钱）；
   - 坏得多可能**整单退款或补发**；
   - 部分店铺给**优惠券补偿**而非退现金——如果你想要现金退款，要明确跟客服提。
5. 生鲜一般**不支持无理由退货**，但**质量问题（腐烂、变质、霉变）属于卖家责任**，正常都该赔，"坏果包赔"是这类店铺的常见承诺。

**几个能提高成功率的点**

- 下单前先看该商品页/店铺的售后条款，不同渠道、不同水果规则不一样（比如车厘子、榴莲这类贵价果往往有专门的坏果比例标准，比如坏果超过一定比例才整单赔）。
- 保留外箱和面单，别扔太快。
- 客服第一次答复不满意，可以继续申请或找平台介入（天猫/京东都有平台仲裁通道）。
- 走的是官方旗舰店或平台自营，维权更顺；如果是第三方小店或直播间个人链接，规则可能缩水，要提前确认。

**注意**：以上是这类生鲜电商的通行做法，佳农各渠道的具体时限、赔付比例、是否补发，我无法逐一核实到最新细则。建议你下单前直接问客服一句"坏果怎么赔、多久内反馈"，并把聊天记录截图，这是最稳妥的判断依据。
