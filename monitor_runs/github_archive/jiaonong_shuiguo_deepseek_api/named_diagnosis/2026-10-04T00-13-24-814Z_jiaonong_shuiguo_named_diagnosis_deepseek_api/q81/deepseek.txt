佳农（Goodfarmer）确实有适合便利店的小包装产品线，但具体规格会因品类、区域和经销商不同而有差异，我没法给你一份准确的“全品类规格表”。不过可以给你几个可执行的判断方向：

**1. 香蕉：3kg装是存在的，但不一定是最小规格**
- 佳农香蕉常见有 **1.5kg、2kg、3kg、5kg** 等箱装/袋装规格，具体看当地经销商和季节。
- 便利店如果面积小，**1.5kg～2kg** 往往比3kg更好卖，因为香蕉后熟快，小包装能减少损耗。
- 3kg装更适合客流稳定、周转快的门店；如果日销不到2～3串，3kg容易压货变黑。

**2. 其他佳农水果的小包装方向**
佳农比较常见的小规格品类包括：
- **菠萝**：单颗装、2颗装
- **牛油果**：2粒装、4粒装
- **蓝莓**：125g、125g×4盒
- **车厘子/樱桃**：500g、1kg、2kg礼盒
- **提子/葡萄**：500g～1kg袋装或盒装
- **苹果/橙子**：4粒、6粒、8粒小盒装
- **椰青**：单颗装、2颗装

**3. 最直接的办法：问当地佳农经销商要“便利店渠道规格表”**
你可以直接这样问经销商：
> “我们门店面积小，主要做便利店渠道，请给我一份适合便利店的小包装SKU清单和最小起订量，包括香蕉1.5kg/2kg/3kg、牛油果、蓝莓、菠萝这些。”

同时确认三件事：
- **最小起订量**：有些小规格反而有起订箱数要求。
- **配送频率**：香蕉、蓝莓这类短保品，能否一周2～3配。
- **损耗/售后**：到货烂果、黑香蕉是否可补损。

**4. 给你的门店建议**
如果面积小、没有冷藏后仓：
- 香蕉优先试 **1.5kg或2kg**，先试销一周看日销。
- 蓝莓、牛油果选 **小盒装**，放冷柜或靠近收银台。
- 菠萝、椰青选 **单颗装**，不占仓。
- 车厘子这类高客单、礼盒装，节日再上，平时慎上。

简单说：**3kg香蕉有，但便利店更建议从1.5kg～2kg试起；佳农小包装规格要直接找当地经销商拿最新清单和起订量。**
