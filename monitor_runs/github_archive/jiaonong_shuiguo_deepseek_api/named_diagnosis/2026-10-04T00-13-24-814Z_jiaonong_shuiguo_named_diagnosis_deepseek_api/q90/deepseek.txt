**2. 建议直接问渠道的确认话术**
联系佳农官方客服/区域销售时，直接问这几点：
- 是否有**冷冻菠萝丁**（IQF或冷冻块），不是菠萝罐头、不是糖水菠萝、不是鲜切；

- 包装形式：袋装/箱装、是否独立小包；
- 工艺：IQF单体速冻还是整块冻后切；
- 糖度/是否加糖、是否含防腐剂；
- 起订量、供货周期、储存条件（-18℃）；
- 是否可提供样品和检测报告。

**3. 对你的茶饮店更实际的选型建议**
茶饮用菠萝丁通常要求：
