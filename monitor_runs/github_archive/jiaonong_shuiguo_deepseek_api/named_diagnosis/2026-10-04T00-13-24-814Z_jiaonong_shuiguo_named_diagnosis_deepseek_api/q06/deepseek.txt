建议你直接按下面问佳农或它的经销商：

1. **要什么形态**
   - 整颗鲜菠萝：问品种、单果重、成熟度、是否可指定酸甜度。
   - 去皮菠萝/菠萝块：问是冷藏鲜切还是冷冻，规格多大，是否带芯。
   - 菠萝果泥/果浆/浓缩汁：如果你们做饮品标准化，这个比鲜果更稳。

2. **规格怎么说商家才听得懂**
   - 鲜果：直接说“单果几斤到几斤”“一箱几颗”“净重多少斤”。
   - 鲜切/冷冻：说“每袋几公斤”“果块尺寸多少厘米”“一箱几袋”。
   - 果泥/果汁：说“糖度多少”“固形物多少”“一桶多少公斤”“是否需冷藏/冷冻”。

3. **稳定性要问死**
   - 能不能长期每周固定送？
   - 缺货时有没有替代规格？
   - 不同批次的酸甜度、颜色、出汁率是否稳定？
   - 最小起订量、配送频次、冷链还是常温？
   - 坏果/化冻/变色怎么赔？

4. **茶饮店最该优先选的**
   如果你们量大、要标准化，优先考虑：**冷冻菠萝块、菠萝果泥、菠萝浓缩汁/果浆**。  
   如果主打“鲜果感”，再考虑鲜菠萝或冷藏鲜切，但一定要接受它批次波动更大。

5. **先做小测试**
   不要一上来签大量。让佳农先供 1～2 批样品，按你们实际配方做 3 款饮品，记录：出杯风味、糖度调整、损耗率、员工处理时间。测试稳定后再放量。

一句话：佳农大概率能供，但你要把需求从“菠萝”改成“什么形态、什么规格、什么糖度、多久送一次、不合格怎么赔”，这样普通商家也能听懂并验收。
