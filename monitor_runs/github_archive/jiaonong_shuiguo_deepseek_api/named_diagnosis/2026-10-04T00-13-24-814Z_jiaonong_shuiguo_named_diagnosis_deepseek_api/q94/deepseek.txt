佳农（Goodfarmer）的香蕉分级主要按“条/梳/箱”的规格、外观、成熟度和瑕疵控制来分。不同产地（菲律宾、厄瓜多尔、越南等）、不同季节、不同客户协议都会影响具体标准，所以没有一份全国统一的固定分级表。以下给你批发商能直接用的判断框架和价差参考。

## 一、常见分级维度

**1. 规格（每箱条数/单条重量）**
- 一级果：条形均匀，单条重量集中，通常按每箱4-5梳、每梳5-7条，或按单条克重分档（如大果、中果）。
- 二级果：条形略不均，单条重量跨度大，梳数或条数不整齐。

**2. 外观**
- 一级果：果指饱满、弯曲弧度一致、棱角不明显（“五棱”转“圆”），无黑斑、无机械伤、无疤痕。
- 二级果：允许轻微擦伤、少量黑点、轻微棱角，弯曲度不齐。

**3. 成熟度与色泽**
- 一级果：青果阶段颜色均匀，转黄后色泽一致，无“青肩”或“花皮”。
- 二级果：允许少量青肩、色泽不均。

**4. 瑕疵率**
- 一级果：病斑、虫伤、裂果、日灼等基本为零，或极低比例。
- 二级果：允许一定比例（常见5%-10%以内）的轻微瑕疵。

**5. 包装与到货状态**
- 一级果：箱规统一、码放整齐、到货硬度和温度控制好。
- 二级果：箱规可能混装，到货成熟度不齐。

## 二、一级果和二级果的价差

价差不是固定的，通常按“同产地、同时间、同规格”对比：

- **常规行情下，二级果比一级果低约10%-25%。**
- 行情紧、一级果缺货时，价差可能拉大到**25%-35%**。
- 行情松、二级果走量快时，价差可能收窄到**5%-15%**。

按绝对金额看，如果一级果批发价是**每箱80-120元**（视规格和产地），二级果通常低**8-30元/箱**。

## 三、给批发商的可执行建议

1. **先确认产地和规格**：菲律宾、厄瓜多尔、越南的佳农货，分级口径不同，不能直接比价。
2. **索要当批质检单**：重点看条重、梳数、瑕疵率、青肩比例、到货温度。
3. **按用途谈价**：
   - 走商超、精品店：要一级果，价差可接受。
   - 走水果店、摊贩、加工：二级果性价比更高。
4. **合同里写清验收标准**：比如“瑕疵率≤5%”“单条重≥XX克”“青肩比例≤X%”，避免到货扯皮。
5. **比价时锁定同一批次**：不同船期、不同冷库的货，价差没有可比性。
