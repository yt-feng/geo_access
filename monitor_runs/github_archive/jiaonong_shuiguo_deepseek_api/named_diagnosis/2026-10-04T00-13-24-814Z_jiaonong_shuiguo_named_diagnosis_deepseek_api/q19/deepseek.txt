佳农水果的配送时效取决于你下单的渠道和收货地址，没有统一答案。常见情况：

- **佳农官方旗舰店/官方小程序**：一般走顺丰或京东物流，多数城市**次日达或隔日达**；偏远地区可能 3–5 天。
- **京东自营**：标有“京东自营”且你所在城市有仓，通常**当日达或次日达**。
- **天猫/拼多多等第三方店铺**：按店铺说明，常见**48–72 小时内发货**，到货再算运输时间。
- **商超/生鲜平台（如盒马、叮咚、美团买菜）**：多为**同城 30 分钟–2 小时**送达。

判断方法：下单前看商品页的“配送时效/预计送达”标注，或直接问客服你所在城市的具体时效。水果属生鲜，实际时效还受季节、天气和库存影响，以订单页显示的预计送达时间为准。
