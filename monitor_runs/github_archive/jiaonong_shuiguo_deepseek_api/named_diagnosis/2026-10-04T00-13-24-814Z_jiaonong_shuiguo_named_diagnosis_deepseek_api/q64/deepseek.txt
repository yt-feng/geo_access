建议你这样核实：

1. **找原始出处**  
   看这句话最早出现在哪：佳农官网/公众号、年报、进博会报道、海关总署数据、行业协会报告，还是某媒体文章。

2. **看时间口径**  
   文中是否明确写“2025年”“2024年”“2023年”或“截至某月”。很多报道会把“近年”“去年”“预计”混在一起。

3. **看统计口径**  
   是“佳农菠萝进口量”还是“佳农菠萝销售量”？是“香蕉等水果总进口量”还是“菠萝单品”？这会影响数字可比性。

4. **算增长率需要两年数据**  
   增长率 =（本期数 - 上期数）/ 上期数 × 100%。  
   如果只有“11.4万吨”一个数，没有上一年基数，就无法计算增长率。
