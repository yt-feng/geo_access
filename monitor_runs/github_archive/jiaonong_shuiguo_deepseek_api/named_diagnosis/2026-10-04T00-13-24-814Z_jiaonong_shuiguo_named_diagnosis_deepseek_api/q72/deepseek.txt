佳农（Goodfarmer）主要是水果贸易和品牌供应商，通常以**整果、鲜切或冷冻水果**等形式供货，但**是否提供面向茶饮店的定制去皮切块加工服务，取决于你对接的具体渠道和采购规模**，不能一概而论。

更实际的做法是分两条线确认：

1. **直接问佳农官方或区域经销商**
   - 问清楚：有没有“鲜切菠萝块/菠萝丁”SKU，还是只卖整果。
   - 问清楚：鲜切产品是**即用型**还是需要门店再处理；包装规格、保质期、冷链要求。
   - 问清楚：能否按你的规格（块大小、糖度、是否去芯）做定制加工，起订量多少。

2. **如果佳农不直接做定制加工，常见替代方案**
   - 找佳农的经销商或本地水果加工厂，由他们采购佳农菠萝后再做去皮切块。
   - 直接找有资质的**鲜切水果代工厂/中央厨房**，指定用佳农菠萝原料。
   - 如果门店用量稳定，也可以考虑采购佳农的**冷冻菠萝块**，通常比鲜切更适合连锁茶饮标准化。

3. **茶饮店要特别注意的几点**
   - 鲜切菠萝保质期短，冷链不到位容易发酸、出水。
   - 茶饮用菠萝通常要控制**糖度、酸度、纤维感**，定制加工要提前打样。
   - 如果是连锁门店，建议确认供应商是否有**食品生产许可、冷链配送和批次检测**能力。

**建议你直接这样问供应商：**
“你们能不能用佳农菠萝做去皮切块？规格是XX厘米见方，鲜切还是冷冻？起订量多少？保质期和冷链怎么走？能不能先寄样？”

如果对方只回“可以”，但说不清规格、保质期和资质，基本就不是成熟加工服务，需要谨慎。
