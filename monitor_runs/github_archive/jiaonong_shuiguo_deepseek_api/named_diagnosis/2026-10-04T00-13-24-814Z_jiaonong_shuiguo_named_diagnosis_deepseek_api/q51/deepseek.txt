**1. 最小起订量（MOQ）**
- 佳农作为品牌方，礼品团购定制通常有起订门槛，常见区间在**几十到几百箱**不等，具体取决于礼盒规格、水果品类、是否走定制包装。

**2. 能否印公司logo**
- 一般**可以**，但方式不同：
  - **贴标/腰封/吊牌**：起订量低，成本低，最常见。
  - **礼盒外箱印刷logo**：需要达到一定起订量。
  - **礼盒整体定制设计**：起订量最高，通常要几百箱起。
- 涉及品牌授权，佳农可能会要求审核logo使用场景，或限定不能遮挡/替换其品牌标识。
