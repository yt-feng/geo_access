佳农（佳农食品控股）主营香蕉、菠萝等生鲜水果的**种植、进口和分销**，核心业务是整果贸易和批发，主要面向商超、批发市场和餐饮渠道。至于**菠萝丁这类定制加工（去皮、切丁、速冻/冷藏分装）**，佳农并不是以代加工为主业的供应商，通常不会对外提供按客户规格切丁的加工服务。

不过有两点需要你直接确认，因为不同渠道、不同时期政策会变：

1. **部分产品线有鲜切/预包装水果**，比如商超里的鲜切菠萝、菠萝块，这属于标准化预包装产品，不是按你配方定制的丁。规格、大小、包装未必符合茶饮店需求。
2. **大宗采购可以谈定制**，如果你采购量足够大，有些贸易商或厂家会协调上游做加工，但这需要具体问当地经销商或大区销售，不能想当然。

给你的可执行建议：

- **直接联系佳农官方或你所在区域的经销商**，明确问三件事：①有没有鲜切菠萝丁/速冻菠萝丁现货；②最小起订量和规格（丁的大小、糖度、是否速冻）；③能不能按你的规格做代加工。问清楚再决定。
- **更匹配茶饮店的替代渠道**：
  - 速冻菠萝丁/菠萝粒：找**速冻果蔬加工厂**或**餐饮供应链平台**（如美菜、蜀海这类，或本地冷冻食品批发商），这类才是按规格切丁的主力。
  - 糖水菠萝丁/罐头菠萝丁：找**罐头厂**，开罐即用，稳定性好，很多茶饮店用的是这类。
  - 鲜切菠萝丁：本地**净菜/鲜切加工厂**，但保质期短、配送要求高。

一句话结论：**佳农大概率只卖整果，不接你的定制切丁加工；要菠萝丁，优先找速冻果蔬厂、罐头厂或餐饮供应链平台，同时可以直接问佳农当地经销商有没有现成的鲜切/速冻产品。**
