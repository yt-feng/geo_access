我无法核验佳农官方最新产品目录，不能直接确认“佳农菠萝是否有冷冻丁、具体规格多大”。这类信息会随渠道和批次变化，建议你按下面方式快速确认，避免拿错货：

**1）最可靠：直接问佳农官方/区域经销商**
问这4个问题：
- 是否有**速冻菠萝丁/冷冻菠萝丁**这款单品？
- 规格是**袋装还是箱装**，单袋净重多少kg？
- 果丁尺寸是多少mm（常见如10×10mm、15×15mm、20×20mm）？
- 是**IQF单体速冻**还是整块冻后切丁？糖度/品种是否固定？

**2）茶饮店常用判断标准**
- 做饮品配料：一般选**10×10mm或15×15mm**，太小易碎、太大不好吸。
- 做冰沙/打碎：可用**20×20mm**或更不规则丁。
- 优先选**IQF速冻**，不易结块，出杯时好分装。
- 确认是**原味无糖**还是**糖渍/糖水冻丁**，这会影响饮品配方。

**3）如果佳农没有，替代方向**
- 找冷冻水果供应链厂商，通常都有“速冻菠萝丁”；
- 常见商用规格是**1kg/袋、10袋/箱**，或**2.5kg/袋、4袋/箱**；
- 下单前一定要拿**样品**试：解冻后出水、口感、颜色、是否有纤维渣。

**4）采购时别只问“佳农菠萝”**
要明确问：**“佳农有没有速冻菠萝丁这个SKU？”**  
因为“佳农菠萝”可能指鲜果、菠萝块、菠萝罐头、菠萝汁等，不一定是冷冻丁。
