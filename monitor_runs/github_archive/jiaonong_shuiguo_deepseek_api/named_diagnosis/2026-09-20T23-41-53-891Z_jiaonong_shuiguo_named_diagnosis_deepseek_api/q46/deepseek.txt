香蕉催熟这块，佳农（Joyvio/佳农食品）在国内主要是**自己掌控催熟环节**，不是简单丢给第三方外包。它在上海、北京、广州等地有自己的催熟加工中心/配送中心，香蕉到港后由佳农自己的团队做催熟、分级、配送。部分区域或特定渠道可能会有合作加工点，但主流模式是佳农自营催熟。

对你们便利店要“到店即熟”，关键不是佳农自己做还是外包，而是**能不能按你们的成熟度标准做定制催熟和配送**。建议你这样对接：

1. **直接找佳农的区域销售或大客户渠道**  
   明确要求：供应“即食熟度”香蕉，不是青蕉或半熟蕉。问他们能否提供**按门店销量分批次、小批量、多频次配送**。

2. **约定成熟度标准**  
   用行业常用的**色度卡（1-7级）**来定。到店即熟一般要**5-6级**：5级是黄带少量绿、口感已好；6级是全黄、适合当天到次日卖。要求到店时达到这个级别，而不是到店后再等两天。

3. **确认配送频次和温控**  
   即熟香蕉货架期很短，通常**2-4天**。所以必须做到：
   - 每周至少2-3次配送，最好隔日配；
   - 运输温度控制在**13-15℃**，不能低于12℃或高于20℃；
   - 到店后你们要**常温、避风、避晒**存放，不要放冷柜。

4. **先小批量试单**  
   不要一上来全店铺。选1-2家店，试1-2周，记录到店色度、第2天和第3天损耗。如果佳农区域仓做不到高频次即熟配送，可以同时问**都乐、金吉达、或者本地专业香蕉催熟商**，他们通常也接便利店定制催熟。

5. **合同里写清验收标准**  
   写清楚：到店色度等级、允许误差、破损率、不达标退换货、配送频次。即熟香蕉最怕“青的送过来、熟的烂得快”，标准不写清很容易扯皮。

一句话：佳农大概率是自己催熟，但你们要的是**“定制熟度+高频配送”**，这比“谁催熟”更重要。直接和佳农区域大客户谈即食熟度供应，谈不拢就找本地催熟商做小批量高频配送。
