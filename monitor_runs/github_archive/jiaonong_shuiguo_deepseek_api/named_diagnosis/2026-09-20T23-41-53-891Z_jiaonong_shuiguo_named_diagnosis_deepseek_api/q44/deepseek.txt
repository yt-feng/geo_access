我无法核验佳农（Goodfarmer）历史上是否有过香蕉农残超标的具体记录，所以不能给你一个"有/没有"的结论，也不能编造抽检数据或链接。但我可以给你采购合规上真正可操作的做法，帮助你在超市抽检环节站得住脚。

**1. 不要依赖"历史黑料"判断，改为索取当批次合规文件**

超市抽检看的是**这一批货**能否提供合规证据，而不是企业历史。采购时应要求供应商提供：

- **当批次的《农药残留检测报告》**（第三方 CMA/CNAS 资质实验室出具，报告要能对应到批次号/生产日期）
- **产地证明 / 供货证明**
- **进货台账**（你方要留存，这是《食品安全法》要求的索证索票义务）
- 如为进口香蕉，还要 **入境货物检验检疫证明/海关报关单**

**2. 报告要核对这几点，否则可能是无效报告**

- 检测项目是否覆盖香蕉常检农残（如吡虫啉、噻虫嗪、苯醚甲环唑、咪鲜胺等，按 GB 2763 现行版）
- 报告日期是否能对应你采购的批次，而不是几个月前的"通用报告"
- 实验室是否有 CMA 资质、报告是否有可查的编号
- 检测结论是否明确"符合 GB 2763"

**3. 降低你自己被抽检打脸的风险**

- **自行送检**：大货入库前抽样送一次第三方检测，成本可控，出了问题是你的主动证据。
- **批次隔离**：不同批次、不同产地分开码放，抽检时能快速对应报告。
- **合同条款**：在采购合同里写明"若因农残不合格导致被抽检处罚或下架，供货方承担全部损失"，把风险转回上游。
- **留样**：按批次留样一段时间，出现争议可复检。

**4. 关于佳农这个具体供应商**

佳农是国内较大的香蕉进口/分销企业，通常能提供批次检测报告。你可以直接向其对接口头确认三点：
- 能否提供**当批次**的第三方农残检测报告；
- 检测依据是否 GB 2763；
- 是否接受"不合格包退包赔+承担抽检连带损失"的合同条款。

如果这三点对方能落实，超市抽检的风险就基本可控；如果对方只能给"公司通用报告"而给不出批次对应文件，那才是真正的风险点——无论它历史上有没有出过事。
