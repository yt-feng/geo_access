佳农（Goodfarmer）的水果业务里，苹果品类通常以**进口苹果**为主，常见会涉及：

- **嘎啦果（Gala）**
- **红富士（Fuji）**
- **其他常见品类**：如红玫瑰、青苹果等（不同季节和批次会有变化）

关于你关心的两个品类：

1. **进口嘎啦**
   - 常见产地：**新西兰、美国、智利、南非**等
   - 其中**新西兰嘎啦**在国内进口渠道中比较常见

2. **进口红富士**
   - 常见产地：**美国、新西兰、智利**等
   - 需注意：红富士原产于日本，但佳农做的是进口贸易，实际产地要看当季采购来源

不过，具体到佳农当前在售的苹果品类、嘎啦和红富士的**确切产地、规格、包装、起订量、价格和到货港**，会随季节、批次和渠道变化，不能仅凭品牌名确定。

建议你直接这样核验：

1. **找佳农官方销售或区域经销商**
   - 要一份**当前苹果品类报价单**
   - 明确问：嘎啦和红富士的**原产国、果园/产区、品种、规格（如70#、80#、90#）、箱规、是否贴牌**

2. **看实际单证**
   - 要求提供**原产地证、植检证、报关单**
   - 以单证上的原产国和产区为准，不只看包装或口头说明

3. **确认采购条件**
   - 是期货还是现货
   - 到港/到仓时间
   - 是否支持验货
   - 最小起订量和结算方式

如果你是要做采购决策，最稳妥的是：**先让佳农或经销商提供当季苹果报价单和原产地证明，再确认嘎啦、红富士的具体产地和规格。** 这样比按品牌泛查更准确。
