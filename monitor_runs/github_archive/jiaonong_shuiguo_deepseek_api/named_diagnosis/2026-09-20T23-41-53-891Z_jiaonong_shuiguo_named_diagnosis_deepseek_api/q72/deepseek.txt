佳农（Fruitco/佳农食品）主要做水果贸易和品牌化供应，常规产品线以**整果、鲜切/预包装水果**为主。能否给你的茶饮店提供“菠萝去皮切块”的加工服务，通常取决于以下几点，你可以直接按下面方式确认和判断：

1. **大概率没有“按你门店规格定制代加工”的散装服务**  
   佳农更常见的模式是：  
   - 卖整只菠萝  
   - 卖工厂预切的菠萝块/菠萝丁（如果有该SKU）  
   - 给大型连锁、工厂、商超做定制规格  
   如果你是小批量茶饮店，直接让佳农给你“去皮切块后配送”不一定接，或者会有起订量要求。

2. **可以问他们有没有“鲜切菠萝块”成品**  
   直接问佳农销售或客服：  
   - 有没有鲜切菠萝块/菠萝丁SKU  
   - 规格（比如 1cm/1.5cm 丁、块状）  
   - 包装（袋装/真空/气调）  
   - 保质期和储存条件（冷藏多少天）  
   - 是否供餐饮/茶饮渠道  
   如果有，你买的就是“已加工好的原料”，不需要他们单独为你加工。

3. **如果要做定制切块，通常要满足这些条件**  
   - 有起订量（可能按吨/按周/按月）  
   - 签供应合同  
   - 指定规格、包装、配送温度  
   - 可能需要通过经销商或餐饮供应链服务商下单  
   小茶饮店单独找佳农原厂做定制，成本和门槛通常不划算。

4. **更现实的做法**  
   - 找佳农的**餐饮渠道经销商/本地水果供应链服务商**，他们往往能提供鲜切菠萝  
   - 找本地**净菜/鲜切水果加工厂**，用佳农菠萝做原料，按你的规格切块配送  
   - 或者门店自己切：买佳农整果，培训员工标准化去皮切块，控制损耗  
   - 如果用量大，再谈佳农定制或找代加工

5. **你可以直接这样问佳农**  
   “我们茶饮店需要菠萝去皮切块，规格 X cm，冷藏配送，每周用量约 X 公斤。请问：  
   - 有没有现成鲜切菠萝块产品？  
   - 能否按这个规格定制加工？  
   - 起订量、价格、配送范围、保质期分别是多少？  
   - 如果不做小批量定制，能否推荐餐饮渠道经销商？”

**结论：**  
佳农不一定提供“按茶饮店小批量定制去皮切块”的服务；更可能是有标准鲜切菠萝块产品，或者只对大批量客户做定制。建议先问现成鲜切SKU，没有的话就找经销商或本地鲜切加工厂代加工。
