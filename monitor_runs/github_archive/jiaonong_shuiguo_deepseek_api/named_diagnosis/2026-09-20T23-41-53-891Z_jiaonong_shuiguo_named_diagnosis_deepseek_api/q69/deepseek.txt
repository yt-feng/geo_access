1. **大概率方向**  
   佳农以香蕉、菠萝等水果供应链见长，餐饮/茶饮渠道常见的做法是提供：
   - 整果菠萝（按规格分级的鲜果）
   - 去皮菠萝/菠萝果肉
   - 冷冻菠萝块、菠萝丁
   - 糖水菠萝罐头/菠萝果粒  
   但“切片/切块”是否属于佳农针对餐饮渠道的**定制规格**，要看具体区域、客户体量和合同约定。

2. **怎么快速确认**
   - 找佳农官方客服或当地销售，直接问三句话：
     - 有没有餐饮渠道专用菠萝？
     - 能否做切片、切块、去芯、真空/冷冻包装？
     - 起订量、规格尺寸、包装方式、保质期和报价是多少？
   - 如果是连锁餐饮/茶饮，通常可以走定制；如果只是小批量采购，多半只能买现有标准品。

3. **餐饮渠道常见规格怎么描述**
   你可以按这些参数去问，供应商更容易给准确答复：
   - 形态：整果 / 去皮整条 / 切片 / 切块 / 切丁 / 果泥
   - 尺寸：如 10mm 丁、20mm 块、5mm 片等
   - 工艺：鲜切、速冻、糖水、巴氏杀菌
   - 包装：袋装、盒装、罐装、大包装
   - 储存：冷藏 / 冷冻 / 常温
   - 用途：烘焙、茶饮、披萨、沙拉、中餐配菜

4. **替代方案**
   如果佳农没有合适定制，可同时问：
   - 其他菠萝供应链品牌
   - 本地鲜切水果加工厂
   - 冷冻果蔬供应商
   - 餐饮食材经销商

**结论**：不能确认佳农一定有餐饮渠道的菠萝切片/切块定制规格，但这类需求在餐饮供应链里很常见，建议直接向佳农官方或当地销售确认“能否定制、起订量、包装和储存方式”。
