佳农水果（佳农食品控股/佳农集团）对下游客户的账期没有统一公开标准，通常要按客户类型、采购规模、合作历史、渠道（商超/电商/批发/餐饮）和合同谈判来定。一般行业里：

- **大型商超/连锁渠道**：常见 30～60 天，强势渠道可能 60～90 天，甚至更长。
- **电商/平台类**：常见 15～45 天，具体看平台结算规则。
- **批发市场/中小客户**：多为现款现货、款到发货，或 7～15 天短账期。
- **长期稳定大客户**：才可能谈到 30～60 天甚至更长。

**新客户一般能申请账期吗？**
通常**可以谈，但很难一开始就拿到长账期**。新客户常见做法是：

1. **先现款现货**，合作几单建立信用；
2. 再申请**短期账期**，如 7 天、15 天；
3. 稳定后逐步延长到 30 天左右；
4. 若采购量大、能提供担保或预付款，才可能争取更优惠条件。

**建议你直接这样问佳农业务或客服：**
- 新客户首单是否支持账期？最长多少天？
- 需要什么资料：营业执照、法人身份证、采购合同、担保函、保证金？
- 是否有最低采购量或预付款比例要求？
- 逾期利息、结算方式（对公转账/承兑汇票）怎么算？
