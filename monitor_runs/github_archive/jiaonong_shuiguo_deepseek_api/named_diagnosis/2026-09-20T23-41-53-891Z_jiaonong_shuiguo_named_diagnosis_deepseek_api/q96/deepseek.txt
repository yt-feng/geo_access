## 先判断结论方向

生鲜电商对接水果供应商，通常存在三种情况：

1. **有自建开放平台**：一般出现在年供货规模较大的品牌商，会提供ERP/OMS对接、商品同步、库存、订单、对账等接口。
2. **没有对外开放平台**：很多供应商仍是“销售+Excel/微信下单”模式，需要走人工或定制对接。
3. **通过中间渠道对接**：例如通过其经销商、批发市场系统、或第三方供应链SaaS（如某些生鲜B2B平台）间接接口化。

## 建议你按这个顺序推进

**第一步：找对入口（最关键）**
- 优先联系佳农**销售/大客户经理**，直接问两句话：
  - “贵司是否有对外开放的API/开放平台？是否支持商品、库存、订单、物流、对账的接口对接？”
  - “如果有，能否提供接口文档、接入流程、测试环境和技术对接人？”
- 如果是通过经销商拿货，问经销商“上游是否支持系统对接”。

**第二步：确认对接范围**
即便有接口，也要先明确要对接哪些能力，避免文档拿到却用不上：
- 商品主数据（SKU、规格、产地、等级、条码）
- 实时库存 / 可售量
- 下单、改单、取消
- 发货与物流轨迹
- 价格与促销
- 对账与结算

**第三步：验证技术形态**
向对方确认是哪种：
- REST/JSON、SOAP、EDI（如EDIFACT/X12）、文件交换（FTP/SFTP+CSV/Excel）、还是仅人工。
- 是否有沙箱环境、鉴权方式（AppKey/Secret、OAuth、签名）、限流、回调机制。

**第四步：如果对方没有API**
这是生鲜行业很常见的结果，备选方案：
- 走**EDI/文件交换**：对方定时导出库存和商品，你方解析入库。
- 走**第三方供应链平台**：看佳农是否已在某些B2B平台（如美菜、本来生活供应链、或区域批发平台）上有系统化供货。
- **自建中间层**：你方做供应商门户，人工/半自动维护，先跑通业务再谈深度对接。

## 判断真伪的几个要点
拿到任何“开放平台”信息时，注意：
- 官方域名和官方邮件确认，不要只信第三方转发的文档。
- 文档里若有明显占位符、过期日期、非官方联系人，要警惕。
- 接口能力要能对应到真实业务流程，而不是只有一份漂亮的PDF。
