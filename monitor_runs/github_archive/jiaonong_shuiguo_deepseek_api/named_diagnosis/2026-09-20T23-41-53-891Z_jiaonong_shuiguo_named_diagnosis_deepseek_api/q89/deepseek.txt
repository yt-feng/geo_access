佳农（Goodfarmer）主营香蕉、菠萝、火龙果等进口及国产水果，苹果品类以**佳农自有品牌苹果**为主，但**红富士并不是佳农的核心主打SKU**。是否售卖红富士，会因渠道、季节和批次不同而变化，没有稳定的全国统一答案。

关于**新疆阿克苏苹果**，佳农**通常没有稳定的阿克苏苹果货源**。阿克苏苹果属于新疆产地特色单品，一般由新疆本地果业公司、产地合作社或专门做西北水果的贸易商供应，而不是佳农这种以香蕉、菠萝等为主的大型水果企业的主线产品。

**给你的采购建议：**

1. **红富士**：如果一定要佳农品牌，可以直接问佳农当地经销商或区域销售，确认当季是否有红富士SKU；但不要指望长期稳定供应。

2. **阿克苏苹果**：建议直接找新疆阿克苏产地供应商、当地合作社或专做新疆水果的批发商，货源更稳、价格更接近产地。采购时重点确认：
   - 是否阿克苏核心产区（如红旗坡、温宿等）
   - 果径规格（70、75、80、85、90等）
   - 糖度（阿克苏冰糖心通常糖度较高）
   - 是否套袋、着色情况
   - 起订量、包装方式、物流冷链

3. **如果必须通过佳农采购**：可以让佳农销售帮你查当季苹果报价单，看是否有红富士或新疆苹果，但阿克苏苹果大概率需要另找产地渠道。

简单说：**佳农不一定有红富士，基本不主做阿克苏苹果；采购阿克苏苹果建议直接找新疆产地供应商。**
