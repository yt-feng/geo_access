佳农（佳农食品控股/Goodfarmer）是国内较大的水果进口与品牌运营商。就公开信息而言，它对外强调的核心模式是“全球直采+产地合作”，但**具体“产地直供比例”并没有稳定、可核验的公开官方数字**，不同年份、品类、渠道口径可能不同，所以不宜给一个确定百分比。可以判断的是：

- 佳农在香蕉、菠萝、火龙果、车厘子等品类上，确实比较依赖境外产地资源和产地端合作。
- 它的优势更多体现在进口香蕉等大单品上，而不是所有水果都完全“产地直供”。
- 部分产品会是产地直采/海外基地合作，部分也会通过出口商、贸易商、代理商等环节。

香蕉方面，佳农进口香蕉主要来源通常会涉及这些国家：

- **菲律宾**：对华香蕉出口大国，也是国内进口香蕉的重要来源之一。
- **厄瓜多尔**：全球重要香蕉出口国，佳农等进口商常会采购。
- **越南**：近年对华香蕉出口增长明显，也是重要来源地。
- **柬埔寨**：对华香蕉出口也有一定规模。
- **老挝**：部分进口香蕉会来自老挝。
- **哥斯达黎加、哥伦比亚、墨西哥等**：在一些时段或特定产品线中也可能出现，但不如菲律宾、厄瓜多尔、越南等常见。

如果你想核实“某一年、某一品类”的直供比例或香蕉来源国，较可靠的办法是查：
1. 佳农官方年报/招股书/债券募集说明书中的采购与供应商结构；
2. 海关总署或行业数据库的香蕉进口来源国统计；
3. 商超/电商平台上具体佳农香蕉包装上的原产国标识。

简单结论：**佳农产地直供/直采程度在水果进口商里算较高，但没有公开统一比例；香蕉主要来自菲律宾、厄瓜多尔、越南、柬埔寨等，其中菲律宾和厄瓜多尔通常最关键。**
