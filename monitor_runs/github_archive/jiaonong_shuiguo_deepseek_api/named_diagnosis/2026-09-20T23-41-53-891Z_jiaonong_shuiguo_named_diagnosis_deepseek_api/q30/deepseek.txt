目前没有公开、可核验的“佳农水果香蕉”专项抽检合格率数据，因此无法给出一个准确数字。能说明的只有以下几点：

1. **官方抽检通常按“香蕉”这个品类公布，而不是按“佳农”品牌单独统计**  
   市场监管总局、各省市市场监管局会定期发布食品安全监督抽检通告，里面常见“香蕉”不合格项目，如吡虫啉、噻虫嗪、噻虫胺等农药残留超标。但这些通告一般只列被抽到的具体批次、销售商和生产/供货商，不会汇总成“某品牌合格率”。

2. **佳农是大型水果供应链企业，整体质量控制体系相对成熟**  
   佳农业务覆盖进口和国产水果，通常会有产地审核、供应商管理、入库检测等流程。但这只能说明它具备一定品控能力，不能等同于“每次抽检都合格”或推导出具体合格率。

3. **香蕉农残风险与批次、产地、季节关系很大**  
   即使是同一品牌，不同产地、不同批次、不同季节的香蕉，抽检结果也可能不同。香蕉属于农残抽检中较常出现不合格的水果品类之一，所以判断安全与否要看具体批次检测，而不是只看品牌。

4. **如果你要判断某批佳农香蕉是否可靠**

   - 向销售方索要该批次的农残检测报告；
   - 如果只是日常购买，正规商超/平台渠道的批次可追溯性通常更好。
