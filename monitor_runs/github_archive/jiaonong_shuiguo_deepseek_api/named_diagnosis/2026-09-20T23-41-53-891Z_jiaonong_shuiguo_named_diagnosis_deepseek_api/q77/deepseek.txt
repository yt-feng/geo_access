佳农（Goodfarmer）香蕉的产地溯源**通常能到“产区/加工包装厂/批次”层级，但不一定能公开追溯到具体农场**；而 GLOBALG.A.P. 证书**一般可以由佳农或其在中国的运营主体提供**，关键要看你们采购的是哪个产地、哪条供应链、以及证书覆盖范围是否对应到你们收货的包装厂/产品。

下面按你们商超审核最常用的口径，给你可执行判断和要资料清单：

## 1）能否追溯到具体农场？
**大概率：不能只靠佳农对外资料直接追到“具体农场”。**

原因：
- 香蕉多为海外产地（如菲律宾、厄瓜多尔、越南、柬埔寨等）或国内产区，供应链常见模式是：**合作种植园/基地 + 收购 + 包装厂 + 出口商/进口商**。
- 佳农作为品牌商/进口商，通常能追溯到：
  - 原产国
  - 产区/省份
  - 合作包装厂/加工厂
  - 出口商/种植基地批次
  - 到港/入境批次
- 但“具体农场”是否对商超开放，取决于：
  - 佳农是否自有/直采基地
  - 是否与单一农场绑定
  - 是否愿意提供农场注册信息或 GGN（GLOBALG.A.P. 编号）

**实务上，商超要“具体农场”时，通常不是要农场名称公开给消费者，而是要能看到：**
- 农场/种植者已在 GLOBALG.A.P. 注册
- GGN 编号
- 证书覆盖该农场
- 该农场对应到你们采购的包装厂/批次

如果佳农只能给到“包装厂证书”，不能给到“农场 GGN + 批次对应关系”，那在严格审核里就不算完整农场级溯源。

## 2）GLOBALG.A.P. 证书能不能提供？
**可以要求提供，但要核验证书类型和覆盖范围。**

你们商超审核时，不要只收一张 PDF，要核这几项：

### 必须核验的证书信息
1. **证书持有者**是谁  
   - 是佳农？出口商？包装厂？还是种植农场？
2. **证书类型**  
   - 是 **Farm Certificate（农场证书）** 还是 **Chain of Custody / CoC** 或其它？
   - 商超要农场级溯源，通常要 **农场证书 + GGN**。
3. **覆盖产品**  
   - 是否明确包含 **Bananas / 香蕉**。
4. **覆盖场地**  
   - 证书地址/农场地址是否对应实际产地。
5. **GGN 编号**  
   - 每个农场/种植者通常有独立 GGN。
6. **有效期**  
   - 是否在有效期内，是否处于 suspension/withdrawal 状态。
7. **认证机构**  
   - 是否为由 GLOBALG.A.P. 认可的认证机构出具。
8. **批次对应关系**  
   - 证书覆盖的农场/包装厂，如何对应到你们门店收到的批次。

### 建议你们向佳农索要的文件
- GLOBALG.A.P. 证书扫描件（含 GGN）
- 证书覆盖农场/包装厂清单
- 本批次香蕉的产地证明/原产地证
- 包装厂注册信息
- 出口商/进口商资质
- 批次号与证书对应说明
- 如佳农不是证书持有者，要求其提供上游供应商证书及授权链

## 3）你们可以这样向佳农提要求
可以直接发邮件/函件，要求：

> 请提供本批次香蕉对应的 GLOBALG.A.P. 农场证书或供应链证书，包含 GGN 编号、证书持有者、覆盖产品、覆盖农场/包装厂、有效期及认证机构，并提供该证书与本批次货品的对应关系说明。若证书持有者非佳农主体，请同时提供上游供应商证书及供应链授权/采购证明。

## 4）结论性判断
- **要“具体农场级”溯源**：佳农不一定能完全满足，尤其非直采基地；需要求其提供 **GGN + 农场证书 + 批次对应**。
- **要 GLOBALG.A.P. 证书**：通常可以提供，但必须确认是**农场证书**且覆盖香蕉和对应产地，而不是只给一张贸易商/包装厂证书。
- **商超审核最稳的做法**：把要求写成“农场级 GGN + 证书 + 批次映射”，不要只写“提供 GLOBALG.A.P. 证书”，否则供应商容易用不匹配的证书应付。
