能确定的是国标层面的东西，可以给你作参照：

**现行国标**：GB/T 9827《香蕉》（推荐性国标，非强制）。它对香蕉的感官、规格、理化指标有分级要求。其中：
- **果指长度**：按等级划分，优质果一般要求果指长度达到一定厘米数（不同等级门槛不同），并配套要求果指弯曲度、饱满度、无机械伤等。
- **糖度**：国标对可溶性固形物（大致对应糖度）有分级要求，通常以成熟度/可食状态下的可溶性固形物百分比衡量，高等级要求更高。

具体数值请直接查 GB/T 9827 现行版本，网上和标准查询平台能查到，我这边不逐条背数字以免记错。
