可执行的判断和建议：

1. **不要按公开信息推断**
   账期属于商务政策，通常不会在官网公开完整标准。网上“最长60天/90天”之类的说法，除非来自合同或官方书面确认，否则不可靠。

2. **新客户首单30天账期：有可能，但不是默认**
   生鲜/水果行业对新客户常见做法是：
   - 首单预付或款到发货；
   - 首单部分预付 + 尾款短账期；
   - 先做几单现结，再申请15/30天账期；
   - 有抵押、担保、平台背书或大渠道订单时，才可能给到30天。
   所以“首单直接30天”通常需要较强资质或特殊审批，不能默认可以。

3. **直接问对口人，问这4项**
   - 新客户首单是否支持账期，最长多少天；
   - 账期起算日：发货日、到货日、对账日还是发票日；
   - 是否需要保证金、担保或预付比例；
   - 逾期后的停供、违约金和信用降级规则。

4. **如果要提高审批概率**
   准备：营业执照、近半年流水、下游销售合同/渠道证明、采购量预测、预付款比例、法人担保或保证金。先从小额现结或15天账期试起，比一上来要30天更容易通过。
