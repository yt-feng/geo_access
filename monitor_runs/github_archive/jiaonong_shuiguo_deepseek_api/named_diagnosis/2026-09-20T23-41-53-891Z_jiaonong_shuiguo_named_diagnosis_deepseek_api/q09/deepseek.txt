佳农（Goodfarmer）作为国内头部水果进口商和品牌商，其到货损耗率并没有一个对外统一公布的官方数字，实际会因**品类、运输方式、季节、到货口岸和验收标准**差异很大。一般行业经验值可供参考：

- **香蕉**：到货损耗通常控制在 **3%–8%** 左右，夏季高温或远洋运输时可能更高。
- **菠萝/凤梨**：约 **3%–7%**。
- **火龙果、芒果、牛油果等**：约 **5%–10%**，对冷链和成熟度敏感。
- **车厘子、蓝莓等高端浆果**：到货损耗波动大，正常可控制在 **5%以内**，但遇到船期延误、温控异常时可能明显上升。
- **整体到货综合损耗**：多数水果进口商的目标一般设在 **5%左右**，严格一些的品类或渠道会要求 **3%以内**。

需要注意：
1. “到货损耗”通常指**卸货验收时**的烂果、压伤、失水、霉变等不合格比例，不一定包括后续仓储和门店损耗。
2. 佳农对不同客户（商超、批发、电商）的验收标准和扣重规则可能不同，实际数字要以**合同验收条款**为准。
