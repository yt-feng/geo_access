## 一、佳农与盒马、京东的合作模式(行业通行版)

**1. 与盒马:典型的"直采 + 供应商"模式**

- 盒马主打"产地直采",对供应商实行买断或联营。
- 佳农作为品牌供应商(尤其香蕉、菠萝、进口水果),向盒马供货,盒马负责到店/到家销售。
- 结算方式常见有三类:
  - **买断式**:盒马按约定价采购,盈亏自负,供应商风险小但价格被压。
  - **联营/扣点式**:供应商供货并承担部分损耗,按销售额扣点分成(生鲜常见 15%–25%)。
  - **代销**:卖完结款,滞销退货。
- 佳农这类有品牌、有稳定货源的企业,通常能谈到买断或较优扣点。

**2. 与京东:两条线并行**

- **京东自营(1P)**:京东采销买断,佳农供货入京东仓,京东负责物流和销售。这是京东生鲜的主力形态。
- **京东POP(3P)**:佳农自己开店,用京东平台和仓配(京东物流),自主定价、自负盈亏,向平台付佣金+物流费。
- 大品牌往往 1P 和 3P 都做,1P 走量、树品牌,3P 控利润、做差异化。

**3. 共同点**

- 都是**以销定采 + 账期结算**(通常 30–60 天账期)。
- 都对**供货稳定性、品控标准、损耗率**要求高。
- 账期和损耗是供应商最大的资金压力点。

## 二、你们能否类似合作?关键判断

先问自己三个问题:

1. **你们是产地/种植方,还是贸易/批发商?**
   - 产地直供(自有基地、合作社)议价能力最强,最容易进直采。
   - 纯贸易商没有货源优势,平台更愿意绕过你直接找产地。

2. **单品是否有规模?**
   - 平台直采看的是"一个单品能不能持续、稳定、大批量供应"。零散、多品类、量小的,基本进不了直采。

3. **有没有品牌和品控能力?**
   - 有分级、包装、冷链、稳定品质的,能进供应商名录;没有的,只能做低端代供。

## 三、可执行路径(按门槛从低到高)

| 路径 | 门槛 | 适合谁 |
|---|---|---|
| 京东POP开自营店 | 低,注册公司+开店 | 中小供应商起步 |
| 给平台供应商/服务商做二级供货 | 中 | 量做不大但品质稳 |
| 盒马/京东产地直采 | 高 | 有基地、有规模、有品牌 |
| 自有品牌进盒马NB/京东自有品牌代工 | 高 | 有产能和成本优势 |

**落地建议:**

1. 先入驻**京东POP**或**多多买菜/美团优选**这类门槛低的渠道跑通流程、验证品控和履约能力。
2. 积累 6–12 个月的稳定供货记录和单品数据(如某品类月供 X 吨、损耗率 Y%)。
3. 拿这份数据去谈盒马/京东的**采销**(京东找对应品类采销,盒马找品类采购),直采谈的是数据不是关系。
4. 谈的时候重点确认:**结算方式、账期、损耗承担、退换货规则**——这四项决定你能不能活下来。
