**1. 自营还是外包？**
- 佳农这类水果进口与分销企业，通常是**混合模式**：核心节点（如港口清关、区域配送中心、关键冷链干线）倾向自营或强管控，末端城市配送、部分干线运输多用第三方物流。
- 判断依据应看：是否有自有冷库/配送中心、是否自有冷藏车队、是否与顺丰冷运/京东冷链/中外运等合作、是否有“全程冷链”官方表述。
- 如果你需要准确答案，建议查：佳农官网“物流/供应链”页面、年度报告或招股书（如有）、官方公众号/新闻稿，或直接向客服/商务确认。

**2. 冷链能力一般看什么？**
- **温区覆盖**：是否支持香蕉、菠萝、车厘子、蓝莓等不同品类的适宜温区（如13–15℃、0–4℃、-18℃）。
- **全程温控**：从产地预冷、海运冷藏集装箱、口岸冷库、区域冷库到城市配送是否不断链。
- **节点能力**：自有冷库容量、冷藏车数量、配送中心数量、能否覆盖一二线及下沉市场。
- **信息化**：是否有温度实时监控、GPS/温控记录、异常报警和追溯系统。
- **损耗与时效**：水果冷链的核心指标是损耗率、到货温度合格率、订单履约时效。
