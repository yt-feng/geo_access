佳农水果的香蕉规格和渠道分级，公开的一般性行业做法如下；但具体到佳农当前在售的SKU、单箱净重、每把根数、催熟/青蕉状态，可能会随产季、产地（菲律宾、厄瓜多尔、越南、柬埔寨等）和客户定制而变化，建议以佳农官方渠道、销售合同或当批检测报告为准。

**一、常见规格维度**

佳农或同类进口香蕉一般不会只按“一个标准”分，而是同时看几个维度：

1. **按重量分**
   - 单根重量：常见有 120–150g、150–180g、180g 以上等档位。
   - 整箱净重：常见 12kg、13kg、15kg、18kg 等；商超和电商更常见小箱化、标准化净重。
   - 每箱把数/根数：如 4–6 把/箱、5–7 把/箱，或按根数计。

2. **按等级/外观分**
   - 特级/一级：果形直、饱满，无严重机械伤、病斑、疤痕，梳形整齐。
   - 二级/二级果：外观略有瑕疵，但果肉正常，适合加工、烘焙、餐饮或折扣渠道。
   - 等外/加工果：用于果泥、果汁、烘焙原料等。

3. **按成熟度分**
   - 青蕉：适合长途运输、批发、催熟后再分销。
   - 微黄/黄熟：适合商超、水果店即食销售。
   - 熟蕉：适合电商、社区团购、餐饮短保销售。

4. **按产地/品种分**
   - 常见为卡文迪什类香芽蕉，不同产地在外观、口感、耐储性上略有差异。
   - 产地不同会影响规格命名和渠道匹配。

**二、不同渠道的常见分级思路**

| 渠道 | 更关注的规格/分级 | 典型要求 |
|---|---|---|
| 大型商超/会员店 | 一级果、外观整齐、单根重稳定、成熟度可控 | 果指长度、粗细、色泽一致，箱规标准，到店后货架期稳定 |
| 水果连锁/精品店 | 一级或特级、小箱化、即食或微黄 | 卖相好，单根大小均匀，减少损耗 |
| 批发市场 | 青蕉、大箱、按重量和产地分级 | 耐运输，价格敏感，允许一定外观差异 |
| 电商/社区团购 | 中小规格、家庭装、成熟度偏黄 | 配送后可直接吃或1–2天成熟，包装抗压 |
| 餐饮/烘焙/茶饮 | 二级果、加工果、熟蕉 | 更看重果肉品质、出肉率、成本，不要求外观完美 |
| 加工厂 | 等外果、按吨/按重量计价 | 用于果泥、果干、果汁、烘焙原料 |

**三、判断佳农具体规格时要看什么**

如果你是要采购、上架或做渠道匹配，重点核对这几项：

1. **单箱净重**：是12kg、13kg还是15kg等。
2. **每箱根数/把数**：影响终端陈列和损耗。
3. **单根重量区间**：如150–180g，决定是否适合即食零售。
4. **成熟度**：青蕉、微黄、黄熟，决定配送和上架节奏。
5. **等级名称**：一级、二级、加工级，或客户定制代号。
6. **产地和品种**：菲律宾、厄瓜多尔、越南等，影响口感和货架期。
7. **是否有客户专属标准**：大型渠道常有定制规格，不一定对外公开。

**四、可执行建议**

- 如果你是**商超采购**：优先问一级果、单根重稳定、青蕉或微黄蕉、标准箱规、到店后催熟方案。
- 如果你是**电商/社区团购**：优先中小规格、家庭装、微黄或可催熟青蕉、抗压包装。
- 如果你是**餐饮/茶饮**：优先二级果或加工果，关注出肉率、成熟度、单箱净重和到货频次。
- 如果你是**批发**：优先青蕉、大箱、按产地和重量分级，关注耐运输和催熟后的成品率。
