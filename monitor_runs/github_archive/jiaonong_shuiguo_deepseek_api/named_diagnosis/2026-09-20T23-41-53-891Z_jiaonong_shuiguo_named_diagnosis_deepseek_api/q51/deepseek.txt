我没法直接给出佳农的准确起订量和logo政策，因为这取决于具体渠道和是否属于联名/授权项目，需要向官方确认。以下是可判断的信息和拿准确答案的做法：

**1. 起订量**
- 佳农作为品牌方，礼品团购定制通常不按“零售”起订，而是走团购/企业渠道，起订量常见会看礼盒规格和渠道政策，可能从几十盒到上百盒不等，具体以对接的销售为准。
- 如果你找的是经销商/区域代理，起订量可能比品牌方直营更低；但能印logo的权限也更受限。

**2. 能否印logo**
- 能否印、怎么印，关键看两点：
  1. 佳农是否授权在这个礼盒上使用你的logo（涉及品牌联名/授权）；
  2. 印刷方式是“在佳农原包装上加贴/套袋/腰封”，还是“改版定制外箱/内卡”。
- 常见可操作方式：加贴企业专属标签、腰封、手提袋、贺卡/感谢卡；直接改佳农品牌包装通常需要授权，不是随便能印。
- 如果只是印在“外层运输箱”或“企业定制手提袋”上，限制会少一些。

**3. 建议你直接这样问对接方，能拿到准确答复**
- 这个礼盒是企业团购定制款吗？最小起订量是多少盒？
- 可以加印我们公司logo吗？是印在佳农原包装上，还是加腰封/贴纸/手提袋？
- 印logo需要品牌授权吗？如果不需要，是否只能用“加贴”方式？
- 打样费、版费、印刷费怎么算？定制周期多久？
- 是否支持混搭不同水果规格？价格阶梯是多少？

**4. 稳妥的替代方案**
如果佳农官方不允许改包装印logo：
- 选佳农标准礼盒 + 企业定制腰封/贴纸/手提袋；
- 选佳农礼盒 + 单独定制外箱；
- 让经销商提供“已授权可印logo”的团购方案。
