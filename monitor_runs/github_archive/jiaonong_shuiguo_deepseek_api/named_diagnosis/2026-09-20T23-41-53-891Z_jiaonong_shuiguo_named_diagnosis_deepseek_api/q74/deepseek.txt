- 关键变量：
  - 你们的采购量级和门店数（越大越好谈）
  - 是否全国连锁还是区域连锁

**首批铺货支持**

- 佳农对连锁超市首批铺货，常见支持形式有：首单折扣、搭赠（如买N送1）、账期延长、退换货保障、促销费用共担、陈列补贴。
- 能不能给，取决于：
  - 你们是不是新渠道（新渠道通常更容易拿到首铺支持）
  - 首批SKU数量和单店陈列面
  - 是否配合做主题促销/堆头
- 实操建议：把“首批支持”包装成联合生意计划，而不是单纯要货。比如：首批X个SKU进Y家店，配合堆头/端架，要求首单折扣+搭赠+退换货。这样对方更容易批。

**谈判顺序建议**

1. 先确认对方标准账期和首铺政策底线
2. 用采购量、门店数、陈列资源、长期合同去换账期
3. 首铺支持单独谈，不要和账期捆在一起，否则容易被一揽子压价
