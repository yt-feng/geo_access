公开渠道通常查不到佳农对普通经销商的“锁价3个月”这类标准政策，**不能确认佳农有面向所有客户的香蕉价格保护机制**。香蕉属于生鲜品，价格受产地、汇率、海运、天气和供需影响很大，长期锁价对供应商风险极高，一般不会作为常规条款。

更常见的是这几类安排：

1. **短期锁价**
   - 可能只锁 1～2 周，或按单船/单批次锁价。
   - 大客户、长期合同客户才可能谈到更长周期。

2. **区间价/保底价**
   - 约定价格上下限，超出区间再调价。
   - 比固定锁价3个月更常见。

3. **随行就市 + 返利/补贴**
   - 先按市场价结算，跌价时给部分返利或费用支持。
   - 涨价时也可能设封顶价。

4. **大客户定制协议**
   - 商超、连锁、电商大客户可能有一对一协议。
   - 是否锁价、锁多久，取决于采购量、账期、履约能力和历史合作。

如果你是想和佳农或类似供应商谈锁价，建议直接问清楚这几点：

- 锁价周期是多久：7天、15天、30天还是按批次？
- 锁价是否含运费、关税、催熟费、损耗？
- 超量或减量怎么处理？
- 市场价大跌时，你是否仍按锁定价提货？
- 市场价大涨时，对方是否有权调价或减量？
- 违约、延迟提货、质量异议怎么算？

**结论：**
“锁价3个月”对香蕉这种高波动生鲜品来说不常见，除非你是超大体量客户且有长期合同。佳农是否有此机制，需要以其官方销售或合同条款为准，公开信息不足以确认。
