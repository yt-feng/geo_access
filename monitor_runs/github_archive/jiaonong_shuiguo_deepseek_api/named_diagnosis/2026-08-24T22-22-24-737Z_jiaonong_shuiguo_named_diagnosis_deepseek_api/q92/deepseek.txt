您好！关于佳农水果在商超的促销支持（堆头陈列和试吃），**可以明确的是：佳农（以及大多数大型水果品牌）在正规商超渠道是支持这类活动的**，但具体规则、费用和可行性取决于**合作模式、商超规模、合作等级和区域经理权限**。

以下是实操建议和费用分担的常见情况，供您参考：

**一、能否提供堆头陈列和试吃支持？**
- **能**。佳农通常对重点商超客户（KA）或活动档期（如中秋、春节、榴莲季）有专项市场费用支持，包括端架/堆头费用、促销员费用（含试吃人员）和试吃物料（如盘子、牙签、垃圾袋）。
- **前提**：您的商超需与佳农有**直接的经销或直营合作**（而非通过批发市场进货）。如果没有，建议先联系当地佳农经销商或区域销售经理建立合作。

**二、费用怎么分担？（行业惯例）**
费用通常分为**硬性费用**和**软性费用**，分担模式如下：

| 费用项目 | 常见分担方式（行业普遍） |
|---------|--------------------------|
| **堆头/端架陈列费**（给商超的进场费、位置费） | **大概率双方共担**：佳农承担部分（如50%或按销量返点抵扣），商超承担剩余。或者佳农按“买断”方式支付，但要求保底销量。 |
| **试吃人员（促销员）** | 通常**佳农负责**（或双方各出一半）。佳农更愿意出人，因为试吃能直接拉动销量。 |
| **试吃品损耗/样品成本** | **佳农全额承担**（提供试吃装或按实际消耗核销）。 |
| **活动物料（试吃台、海报、桌布）** | 佳农通常**免费提供**品牌物料；若需要商超定制化装饰，可能协商分担。 |
| **活动档期广告/店内广播** | 一般**商超自有资源**，若需佳农付费买位，则按合同约定。 |

**三、如何谈更有利？（执行建议）**
1. **先明确销量预估**：佳农的投入通常与**预期业绩挂钩**。您给出一个合理的销售目标（如“堆头期间销量提升40%”），谈判时更容易获批费用。
2. **争取“按效果付费”**：可提议“费用先由佳农垫付，按活动期间销售业绩从货款中抵扣”，降低您的现金压力。
3. **要求书面合同**：明确堆头位置（主通道/生鲜区）、面积（如1.2米*1米）、档期（如3天/7天）、试吃人数和时间段、费用明细及发票。
4. **本地化沟通**：不同区域经理权限差异大，谈判时先找**片区经理**而非总部，往往能更快拿到支持。

**四、如果不支持，替代方案**
- 若佳农近期无费用预算，可协商**“以货抵费”**（用水果抵扣堆头费）或**“联合促销”**（佳农提供折扣，商超负责试吃人员成本）。

**五、行动步骤**
1. 联系您现有的佳农对接业务员，索要《年度合作计划》或《档期活动申请单》。
2. 提前1-2个月申请，大型节日档期（如春节）通常需要提前锁定位置。
3. 提供您商超的客流数据、同类水果销售数据，增加说服力。

**需要注意**：佳农对试吃和堆头并非“无条件支持”，尤其对中小型门店，可能要求**最低采购量**（比如首次订货满X箱）才配给物料。
