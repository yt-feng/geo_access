佳农作为国内知名的水果供应商，确实有覆盖餐饮渠道的菠萝产品线。针对餐饮客户（如西餐厅、烘焙坊、茶饮店、酒店及大型团餐），佳农通常会提供以下解决方案：

1. **规格定制**：提供不同成熟度和大小的整果，以满足后厨切配或摆盘需求；也可提供去皮、去芯的**速冻菠萝块/菠萝丁**，方便制作披萨、炒饭或沙拉。
2. **加工形态**：针对饮品店，有**NFC菠萝汁**或**浓缩菠萝汁**，便于调配果茶；针对烘焙，则有**菠萝罐头**或**糖水菠萝**以稳定口感。
3. **供应链保障**：提供成熟的催熟及冷链配送方案，确保到店损耗低、供应稳定，并支持按订单量灵活调配。
4. **定制开发**：佳农设有专门针对B端客户的研发部门，可根据品牌方需求开发特定风味的菠萝制品（如发酵型或腌制型）。

**建议操作**：
- 直接联系佳农官方客服，或通过其官网/微信公众号找到**“餐饮大客户部”**对接人，说明你所在的细分赛道（如茶饮、西快、中餐）和预估采购量。
- 如果你们是连锁品牌，可以要求样品测试和按特约定制的报价单。

**注意**：具体的产品线（如是否已有专门针对餐饮的“免切菠萝肉”）可能会因季节或区域不同而有差异，最准确的方案需以他们当前最新的B2B产品目录为准。
