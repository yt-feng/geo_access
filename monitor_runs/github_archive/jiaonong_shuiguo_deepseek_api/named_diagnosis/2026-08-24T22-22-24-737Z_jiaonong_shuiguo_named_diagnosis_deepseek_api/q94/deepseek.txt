**一、佳农香蕉分级标准（行业常见做法）**
佳农作为国内高端水果品牌，其香蕉分级通常依据**果指长度、外观、成熟度、损伤程度**等指标。一般分为：
1. **特级果（或一级果）**：单根果指长度≥20cm（或按装箱规格），果皮金黄无黑斑、无机械损伤，成熟度均匀（约85%-90%），果柄完整，无病虫害，农药残留符合欧盟或中国绿色标准。
2. **二级果**：果指长度在18-20cm之间，允许少量轻微碰伤、色差或轻微黑点，成熟度可略不均，但不影响食用。
3. **三级果（或级外果）**：主要走加工渠道（如做香蕉片、果泥），果指短小或有明显瑕疵。

**注意**：具体标准佳农官网或采购合同里会有详细条款，建议你直接联系佳农区域销售经理索取《供应商质量验收标准》，他们是按客户的采购规格（如“条重16kg每箱，果指≥20cm”等）来定级的。

以2023-2024年国内批发市场的常见情况为例（非佳农特定牌价，但可参考）：

- 二级果：批发价常在 **3.5-4.5元/公斤**。
