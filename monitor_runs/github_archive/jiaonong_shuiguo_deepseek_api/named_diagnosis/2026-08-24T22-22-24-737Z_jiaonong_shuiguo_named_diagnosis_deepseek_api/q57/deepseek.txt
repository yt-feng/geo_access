关于香蕉的到货损耗率，行业平均水平确实在**5%左右**（视运输距离、季节和包装不同，短途可能低于此，长途或高温季节可能达到8%）。佳农作为国内头部水果供应商，其香蕉业务通常能做到**低于行业平均**，一般控制在**2%-3%** 左右，特别是其自有基地或长期合作的菲律宾、厄瓜多尔等产区，品控和冷链管理较严格。

不过，这**不意味着佳农承诺固定损耗率**。行业惯例是：

- **到货损耗率**通常指运输及卸货过程中的自然失水、碰撞导致的表皮破损等，不属于“质量腐败”。
- **赔付条款**方面，佳农的合同一般会约定**“到货时若出现腐烂、发霉、严重黑心等质量问题，可按比例赔付”**，但**对表皮轻微压伤、擦伤等“外观瑕疵”通常不赔付**，因为这不影响食用。

具体赔付标准通常为：
- **腐烂变质**：例如霉变、发黑、流水、异味等，按损坏重量对应的货值全额赔付（上限通常为合同总货款）。
- **重量损耗**：如果因包装或运输问题导致净重短少，按短少重量赔偿。
- **注意**：若因收货方延迟卸货、冷藏温度不当等自身原因造成损耗，佳农不予赔付。

**建议您**：
1. 采购时，务必在合同或订单中**书面明确**“到货验收标准、质量问题认定标准、赔付比例（如实重比例或单价）”。
2. 收货时当场开箱抽检（建议抽检比例不低于10%），保留影像和签收单作为索赔依据。
3. 若批量较大，可要求佳农提供**第三方检测报告**或**到货损耗率承诺函**（部分大客户可谈）。
