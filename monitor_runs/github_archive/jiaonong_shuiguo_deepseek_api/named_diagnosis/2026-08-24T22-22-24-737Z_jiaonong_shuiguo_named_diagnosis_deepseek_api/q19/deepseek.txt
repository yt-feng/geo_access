关于佳农水果的配送时效，通常取决于**下单平台（京东、天猫、官方小程序等）、所在城市、仓库距离以及所选快递**。一般情况如下：

1. **主流电商平台（京东/天猫旗舰店）**：多为**次日达或隔日达**（偏远地区3-5天）。如果购买的是佳农自营且由京东物流配送，一线城市通常下单后24小时内发货，48小时内送达；非自营店铺则视第三方物流速度。
2. **官方小程序/微信商城**：一般在下单后**24-48小时内发货**，使用顺丰或京东冷链快递，本地配送约1-2天，跨省约2-3天。
3. **特殊水果（如进口香蕉、牛油果等）**：为控制成熟度，部分商品可能需**统一采摘后集中发货**，时效可能延长至3-5天。

**建议操作**：
- 下单前查看商品详情页的“**发货时间**”和“**配送区域**”提示；
- 若需加急，优先选择标注“**京东物流**”或“**顺丰冷链**”的商品；
- 收货后如遇延迟，直接联系对应平台客服或佳农官方客服（400-820-xxxx）查询物流单号。

（具体时效会因促销活动、天气等因素变动，请以订单页面动态信息为准。）
