关于佳农水果的产地直供比例，目前公开资料中没有给出一个具体的统一数字（该数据可能随季节和品类变化，且属于公司内部运营数据）。不过，佳农作为国内领先的果蔬商贸企业，其业务模式以海外基地直采和国内产区直采为主，整体直供比例在行业内属于较高水平。

至于香蕉的主要来源国家，佳农的香蕉主要来自以下国家和地区：
1. **菲律宾**（传统核心供应国，以卡文迪什品种为主）；
2. **厄瓜多尔**（因产量大、品质稳定，近年占比提升）；
3. **越南、柬埔寨**（近年来因地理优势和成本因素，供应量逐步增加）；
4. 此外，国内产区如云南、海南、广西也有一定量的本土蕉供应，但更多用于补充国内市场日常需求。
