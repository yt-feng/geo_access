佳农作为全国性品牌，通常实行的是**“指定区域经销商”**模式。也就是说，你代理的合同上会明确写明授权区域（比如“XX省XX市”），并限制你在未经允许的情况下向区域外批发或供货给区域外零售商。

**2. 关于窜货的现状（必须主动防范）**
- **现实情况：** 水果品类存在**保质期短、规格多、价格波动大**的特点，窜货几乎是行业顽疾。佳农虽在管控，但无法做到100%杜绝（尤其是电商平台、社区团购等新渠道的窜货）。
- **关键要看两点：**
  - **赔付机制：** 合同里是否有明确的窜货处罚条款（如罚金、取消返点、甚至终止代理权）。
  - **追溯码：** 佳农部分高端产品（如佳沃蓝莓、香蕉）箱体上是有二维码追溯体系的。如果你们当地市场发现来自你区域的货，厂家能否通过扫码精准定位是哪一批次、哪家经销商出的货。如果能，说明管控系统较完善。

- **线上渠道允许范围：** 你的货能否发往全国？如果能，厂家是否对线上渠道的最低零售价有严格限制？（防止你的线上货品冲击其他区域的线下渠道）
