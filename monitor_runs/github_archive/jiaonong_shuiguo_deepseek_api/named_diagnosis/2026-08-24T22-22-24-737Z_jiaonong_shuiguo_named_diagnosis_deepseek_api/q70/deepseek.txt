- 佳农是国内头部水果贸易商，以进口香蕉（主要来自菲律宾、厄瓜多尔等）和国内基地联动为主，有成熟的冷链和分销体系。

**2. 但“一天10吨”属于超大批量需求**
- 10吨/天对单一商超来说非常重（相当于一整天销量约2万根香蕉），这放在全国商超体系中属于**Top级“大客户”**。

**3. 核心风险点（你需要重点确认）**
- **产地天气/港口物流**：香蕉是鲜活品，台风、船期延误会导致短期断货。
- **库存周转**：旺季你一天卖10吨，意味着你的冷库至少要备3-5天安全库存（30-50吨），否则上游即使有货，你的门店也接不住。
- **佳农的产能上限**：佳农日供货能力通常在数百吨级，理论上10吨/天占比不高，但若当地分仓缺货，跨区调拨可能产生延迟。
