关于佳农水果的售后服务，整体口碑在生鲜电商和商超水果品牌中属于中等偏上，但具体体验会因购买渠道（天猫、京东、拼多多、线下超市等）和发货批次有所不同。

如果您收到的水果有坏果，处理标准流程如下：

1. **24-48小时内拍照取证**：这是最关键的一步。您需要在签收后尽快（通常要求在24小时内，部分平台放宽至48小时）将坏果和快递单号放在一起拍照，照片要清晰显示坏果数量、单号和包裹外观。如果是整箱严重损坏，最好加上开箱视频。

2. **联系客服并附上照片**：不区分购买渠道，您直接联系佳农官方旗舰店客服或您购买时的卖家客服。客服核实照片后，一般会按“坏多少赔多少”原则处理，即按坏果重量/数量折算退款，而不是整箱退款。少数情况会提供补发，但更多是现金赔付。

3. **快速响应承诺**：佳农官方客服一般承诺在1-3个工作日内处理完赔付申请，如果超时未处理，您在电商平台（如淘宝、京东）后台申请“仅退款/售后”，平台客服会介入强制处理，因为生鲜类商品平台对坏果赔付有倾斜保护。

**需要注意的坑**：
- 如果水果在运输中因包装破损导致大量挤压，请第一时间拒收或拍清外箱破损状况，这更有利于全额或大额赔付。
- 部分渠道（尤其线下超市）购买后没有售后保障，请您务必保留小票，但线下售后通常只接受当场调换，不支持远程理赔。
- 不同批次水果质量有波动，但多数用户反馈佳农对坏果赔付比较爽快，不会故意拖延。

**建议**：您下单前查看该商品的“问大家”或追评，筛选最近一个月内购买者的售后体验；到货后务必当场开箱检查，记住**拍照>联系客服>平台介入**的顺序。如果客服推诿，直接在小程序“全国12315平台”投诉佳农品牌方，效果立竿见影。
