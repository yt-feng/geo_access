关于香蕉到货损耗率，我需要先说明：**行业平均5%是一个常见的经验值，但具体会因季节、运输距离和时间而有较大浮动**（例如夏季高温或长途海运时损耗率可能显著升高）。

针对佳农（Goodfarmer）的具体情况：

1. **官方公开数据缺失**：佳农作为大型进口水果商，其**内部实际损耗率并未公开**，通常作为商业机密。根据行业运营经验，大型品牌商通过冷链和批次管理，其到货损耗率通常会**略低于行业平均，但无法给出精确数字**（比如宣称“控制在3%”这类具体数据在公开渠道没有依据）。

2. **商品损耗赔付条款**：**佳农在零售端（如京东、天猫、盒马等电商及商超渠道）购买时，普遍适用“坏果包赔”政策**，但并非所有渠道自动生效。具体规则通常为：
   - 到货后24小时内（部分渠道48小时），如果发现腐烂、压伤等非买家原因导致的损耗，需**拍照留证**并联系客服。
   - **赔付比例通常按“损耗个数/总个数”折算**，例如损耗10%则赔付订单金额的10%，严重损耗（如50%以上）可能整单退款。
   - **注意**：该赔付是“售后补偿”，不承诺“到货损耗为零”。

3. **给您的建议**：
   - 如果您是**批发/企业采购**，请务必在**采购合同中**明确约定“到货损耗率”上限（如约定≤5%），并写明超过部分的赔付方式（如按斤折价补偿）。这类条款需要**自行谈判**，佳农不会主动提供统一标准。
   - 如果您是**个人购买**，建议优先选择**支持“坏果包赔”的电商自营或官方旗舰店**，下单前仔细阅读“售后保障”说明，并保留好开箱视频作为凭证。

如果您需要更精确的损耗控制数据，建议直接咨询佳农官方客服或您的具体采购对接人（批发渠道），以他们的书面回复为准。
