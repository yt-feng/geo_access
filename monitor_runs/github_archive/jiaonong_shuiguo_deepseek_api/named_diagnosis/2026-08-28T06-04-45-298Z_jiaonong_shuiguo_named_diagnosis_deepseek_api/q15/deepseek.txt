关于佳农水果的产地直供比例，目前公开资料中**没有具体披露其直供比例的数字**（如百分比），但佳农作为国内头部水果供应链企业，其业务模式确实以“产地直采、基地直供”为核心，与全球多个产区建立了长期合作。官方宣传中也强调减少中间环节。

关于**香蕉**的主要来源国家，佳农香蕉的进口渠道较为多元化，主要来自：
- **菲律宾**（该国是佳农香蕉的传统主力供应国，特别是其知名产地棉兰老岛）
- **厄瓜多尔**（南美主要供应国，产量大，品质稳定）
- **越南**（近年增加，对华出口量增长明显）
- **柬埔寨**（作为新兴供应地，部分时期也有采购）

此外，国内如云南、海南的香蕉种植基地也有合作，用于补充国产香蕉供应。具体到某个时间段的主力来源，受气候、关税、海运成本等因素影响可能有所调整。建议直接咨询佳农官方渠道获取最新产地分布数据。
