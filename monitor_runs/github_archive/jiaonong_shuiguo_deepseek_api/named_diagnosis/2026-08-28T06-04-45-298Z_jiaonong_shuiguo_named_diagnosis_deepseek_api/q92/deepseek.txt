关于佳农水果的堆头陈列和试吃支持，我可以给你一个参考性的操作方案，但**具体费用和条件需以佳农当地经销商或大客户经理的书面合同为准**，因为不同区域、门店规模、合作模式差异很大。

**一、 通常能提供的支持（按合作深度递增）**
1. **基础支持（通常免费或低成本）**：  
   提供品牌形象物料（如插牌、围裙、爆炸贴）、标准陈列图纸、当季主推品的试吃装（小规格包装）。
2. **进阶支持（需协商费用）**：  
   派专职促销员（试吃员）驻场，承担**堆头陈列费**（进场费/堆头费，按周/月计费）或**陈列达成奖励**。
3. **深度合作（可谈费用抵扣）**：  
   若你的商超承诺“买断式”采购量（比如单月保底销售额），佳农可能用**陈列费折抵进货折扣**，或由对方承担堆头费但要求你的超市给予**黄金位置**（如主通道端架、生鲜区入口）。

**二、 费用分担的常见模式（参考）**
- **模式A：费用全包型**  
  你方只出场地（堆头位置、电源），佳农承担：堆头费（付给商场）、促销员工资、试吃品损耗。  
  前提：你的门店日均客流高，且佳农在区域内有活动预算。
- **模式B：费用分摊型**  
  堆头费按比例分摊（如商超承担30%，佳农承担70%）；试吃品由佳农免费提供，**促销员工资由你方承担**（或按工时补贴）。
- **模式C：无现金费用**  
  不需要直接付堆头费，但佳农要求你方**采购量达到指定金额**（如月采购5万元），或**承诺堆头档期≥2周**，费用直接在货款中扣减。

**三、 关键谈判点（务必落到合同）**
1. **堆头位置**：明确具体位置（如生鲜区第二排端架）、面积（长*宽）、陈列层数（是否高于1.2米）。
2. **试吃支持**：明确试吃品规格、每日供应量、是否含一次性餐具（通常佳农提供试吃装但不含牙签/小杯）。
3. **费用明细**：写明“堆头费”是含税价还是净价，是否包含电费、清洁费；促销员工资是“底薪+提成”还是“固定日薪”。
4. **违约条款**：若佳农未按约提供试吃或促销员，可否扣减费用。

**四、 建议下一步动作**
1. **直接联系佳农当地业务员**：拨打400客服索要“大客户活动方案”模板，或让你的采购经理联系佳农区域销售，索要《促销活动合作意向书》。
2. **提供门店数据**：带上你的日均客流、生鲜区销量占比、同类水果（如百果园、都乐）的动销数据，谈判更有利。
3. **短期试水**：先申请**2周档期**试合作，评估坪效后再签长期合同。

**最后提醒**：如果你从非官方渠道（如批发商）拿货，对方可能不具备提供陈列支持的能力，务必核对**佳农官方授权资质**。若无法核实对方身份，不要轻易支付堆头费用，避免被骗。
