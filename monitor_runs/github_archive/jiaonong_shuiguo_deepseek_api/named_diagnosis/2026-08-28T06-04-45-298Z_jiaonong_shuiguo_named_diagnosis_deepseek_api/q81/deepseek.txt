有的，佳农在商超渠道确实有出小规格包装，适合面积不大的便利店。比如：

- **香蕉**：常见有 **3kg/箱** 的小包装（也有更小的1.5kg或2kg真空贴标装），具体要看当地经销商库存。
- **其他水果**：佳农的菠萝、蓝莓、牛油果等通常也有小份装，但规格不一，一般蓝莓是125g/盒，菠萝多为单个装。

**建议你这样做：**
1. 直接联系你所在区域佳农的经销商或业务代表，报“便利店渠道、小面积门店”的需求，让他们提供当地有货的小包装SKU清单。
2. 初次订货量不宜大，先试3kg香蕉和几盒蓝莓，看动销情况。
3. 如果经销商说没有小包装，可以问能否拆箱供货（比如一箱香蕉拆成2-3份卖）。
