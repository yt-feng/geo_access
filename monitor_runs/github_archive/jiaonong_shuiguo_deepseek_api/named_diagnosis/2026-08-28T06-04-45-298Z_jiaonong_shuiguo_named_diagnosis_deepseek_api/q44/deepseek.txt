关于佳农水果香蕉的农残超标历史，我无法提供直接、确凿的公开记录，因为这类具体企业的历年抽检结果通常由市场监管部门或企业自身发布，且我无法实时核验所有来源。但我可以给你如下实用的合规建议，帮助你推进采购工作：

1. **要求供应商提供权威检测报告**：  
   直接让佳农或其经销商提供近3个月内、由具备CMA/CNAS资质的第三方检测机构出具的香蕉农残检测报告（含多菌灵、吡虫啉、毒死蜱等常见指标）。这是超市抽检最直接的合规依据。

2. **查询公开抽检信息**：  
   你可以通过以下途径核实历史记录：  
   - 国家市场监督管理总局官网的“食品安全抽检公布结果查询系统”；  
   - 各省市市场监管局（如上海、山东等佳农主要产区/销售地）发布的月度/季度抽检通告；  
   - 中国裁判文书网（如果曾有诉讼涉及农残问题，会留有记录）。

   注意：目前我无法确认其是否曾出现超标，但查阅上述官方渠道是最权威的方式。

3. **合同条款约束**：  
   在采购合同中明确约定：供应商须提供每批次农残自检报告，并承诺若因农残问题导致抽检不合格，由供应商承担全部损失（包括罚款、下架、赔偿等）。

4. **预判风险点**：  
   香蕉属于高风险水果，常见风险项为杀菌剂（如苯醚甲环唑）残留。建议在收货时增加快速农残检测试纸（如胶体金法），或委托第三方检测，成本可控且能显著降低超市抽检不通过的概率。

5. **补充建议**：  
   如果佳农无法提供合规文件，可考虑同时备选2-3家有出口资质或自有检测实验室的香蕉供应商（如都乐、鑫荣懋等），交叉询价并对比检测能力，以保障供应链稳定。
