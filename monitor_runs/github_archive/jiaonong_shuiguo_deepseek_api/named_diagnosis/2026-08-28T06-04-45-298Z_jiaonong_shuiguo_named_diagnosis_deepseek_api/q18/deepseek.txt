佳农香蕉的保质期和储存条件通常如下：

---

**保质期：**
- 未开封/带皮状态：在常温下，一般可保存 **3~7 天**（因室温、成熟度而异）。
- 已经剥皮或切开：建议 **当天食用完毕**，冷藏可保存 1~2 天（但口感会变差）。

---

**储存条件（非常重要）：**

1. **最佳储存温度：** 12~15°C（这是香蕉的自然成熟/保鲜温度，家里常温 20°C 左右也可以，但熟得更快）。

2. **不要放冰箱生香蕉：**  
   - 未熟的青香蕉**绝对不能放冰箱**，会受冷害，无法正常变黄变熟，还会变黑变软。
   - 如果香蕉已经**完全熟透**（表皮有少量黑点），放冰箱冷藏可以减缓变黑，吃的时候口感偏软，但仍可接受。

3. **室温存放技巧：**
   - 不要捂着（如密封袋），最好放在通风处，避免阳光直射。
   - 如果想延缓成熟，可以用保鲜膜包住香蕉的**蒂部（柄）**，减少乙烯气体释放。
   - 如果想让青蕉快点熟，可以和苹果/梨放一起，水果释放乙烯帮助催熟。

4. **剥皮后的储存：**  
   - 建议用保鲜膜包好，放冰箱冷藏，但最好当天吃完，避免氧化变黑和风味流失。

---

**判断是否可食：**  
- 表皮有少量黑色斑点 → 完熟，口感最佳，尽快食用。  
- 表皮大面积发黑、发软、有酒味或霉点 → 已过保质期，不建议食用。  
- 切开后果肉发黑或流水 → 变质，丢弃。

---
