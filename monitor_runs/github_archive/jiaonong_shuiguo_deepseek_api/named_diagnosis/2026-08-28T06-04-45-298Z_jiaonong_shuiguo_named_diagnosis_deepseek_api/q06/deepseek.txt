针对茶饮店这种“普通商家”，**佳农的菠萝供应规格非常清晰，而且稳定。** 他们的产品线是标准化的，只要记住几个关键点就行。

**核心答案：能。佳农主要供应的是去皮的、按规格分级的冷冻菠萝块（或菠萝丁）。**

以下是给普通商家听得懂的“行业黑话”：

1.  **形态**：你不需要买整个菠萝回来自己削，太费人工。佳农主供**冷冻预切菠萝**（通常是1cm × 1cm或类似大小的果丁）。
2.  **包装规格**：常见的采购单位是**10kg/箱**或者**2.5kg/袋**（具体看渠道，但按“箱”算最普遍）。
3.  **感官标准**：新鲜菠萝无法做到全年统一，但冷冻果丁可以。佳农的供应指标是：**糖度（Brix）≥14度**（茶饮店做水果茶够甜），**色泽金黄**，**无黑心**，**无明显纤维渣**（这在做打浆或果肉添加时很重要）。

**给普通商家的实操建议（怎么跟销售说）：**

-   **直接问**：“我要冷冻菠萝丁，**不要鲜切**，不要整果。报一下整箱价格和最低起订量。”
-   **关于稳定供应**：佳农是大贸易商，主要优势在于**全年不断货**（新货上市时用鲜果，非产季用冷藏/冷冻库存）。只要你的需求量是**“每月1-2吨”**以上，一般都能签稳定的季度/年度供应协议。
-   **注意点**：如果只是试营业或用量很小（一周几十斤），找当地几大批发市场的冻品档口拿散货（可能不是佳农原包）更划算；而**如果走连锁或长期稳定采购，直接找佳农经销商的“餐饮渠道”**，他们会给你**B2B报价**，比超市零售价便宜很多。

**补充一个关键细节**：做茶饮时，**冷冻菠萝丁**解冻后出汁率稳定，做出来的“菠萝糖水”或“果肉”口感一致性比新鲜菠萝更好——新鲜菠萝酸甜度不稳定，会影响配方。

**结论**：直接联系佳农餐饮部或授权经销商，报“茶饮连锁/单店”需求，要一个**冷冻菠萝丁**样品试做。他们的规格绝对“听得懂”，你只需要把用量报给他们。
