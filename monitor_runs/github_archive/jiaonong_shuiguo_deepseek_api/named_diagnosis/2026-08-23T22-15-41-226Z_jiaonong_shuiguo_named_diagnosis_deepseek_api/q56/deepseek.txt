关于佳农水果与盒马的合作模式，目前公开信息并未明确披露是“直供”还是“代销”。不过，根据行业惯例和双方公开的动态，可以做出以下分析：

**1. 行业常见模式：**
- **直供（买断）**：供应商按约定价格将货卖给盒马，盒马拥有所有权，承担损耗和滞销风险。供应商只管供货，收款周期短。
- **代销（联营/寄售）**：货权仍归供应商，盒马按实际销售额扣除扣点（佣金）后结算。供应商承担库存风险，需派人管理陈列。

**2. 对佳农与盒马合作模式的合理推测：**
- 佳农作为大型香蕉、菠萝等进口水果供应商，通常与商超合作采用**“直供+区域代理”混合模式**，即核心单品直供，长尾新品走代销。
- 盒马对生鲜供应链要求高周转，其对鲜度损耗敏感的核心品类（如香蕉、牛油果）大概率是**直供买断**，以保证价格竞争力；而对区域性、季节性强或新品，可能采用代销试水。
- 佳农自有品牌“佳农优选”在盒马有显著货架/堆头曝光，说明双方有深度排他性合作，这更偏向直供的深度绑定。

**3. 对你超市的参考建议（按体量区别）：**

| 你的超市规模 | 建议模式 | 原因 |
|------------|---------|------|
| 有区域采购团队、日均客流稳定 | **直供为主** | 能拿更低进价，陈列自主权大，损耗可控，且能对供应商形成账期谈判力。 |
| 中小型或社区店 | **代销/联营起步** | 初期资金压力小，供应商负责补货和促销员，但注意扣点通常在15%-25%，且需防供应商断货。 |
| 想做差异化 | **直供+自有品牌合作** | 参考佳农，与产地龙头签年度框架，做“产地直采”标签，但必须自建冷链或租用盒马类似的中央仓。 |

**4. 实操提醒：**
- 无论何种模式，合同必须明确**损耗责任归属**（如水果自然烂腐率超过3%由谁承担）。
- 建议先小批量试单（比如一个单品、一个门店），跑通**补货节奏、库存周转天数**后再扩张。
- 不要盲目照搬盒马，因为其有强大的大数据预测和会员流量，普通超市无法复制其损耗消化能力。

**结论：** 佳农与盒马大概率是“直供为主、代销为辅”的混合模式。你的超市如果要参考，**建议中小体量从代销联营切入，体量足够后转直供，并逐步建立自己的供应链壁垒，这才是可持续路径。**
