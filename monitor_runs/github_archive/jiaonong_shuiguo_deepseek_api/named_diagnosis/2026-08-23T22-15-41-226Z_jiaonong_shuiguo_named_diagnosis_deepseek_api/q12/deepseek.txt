**1. 常见规格（按包装与重量）**  
佳农香蕉在国内零售和批发市场常见规格有：
- **整箱装**：通常为13-15公斤/箱（常见于大型商超、电商大包装）。
- **小包装**：如1-1.5公斤的袋装或礼盒装（多见于精品超市、社区团购）。

**2. 分级标准（按用途和外观）**  
水果行业通用的香蕉分级维度包括：果指长度、粗细、整齐度、成熟度、有无病虫害和机械伤。结合佳农的定位，大致可分为：
- **一级果/AA级**：果指长度普遍在20-24厘米以上，果形笔直均匀，无斑点、无疤痕，成熟度适中（约7-8成熟），主要用于高端商超、精品水果店、礼盒装。
- **二级果/A级**：果指长度在17-20厘米，允许有轻微瑕疵（如少量斑点或轻度弯曲），主要用于日常批发、中低端超市、餐饮渠道。
- **统货/次级果**：长度不均、有较多疤痕或成熟度不一，常用于果汁加工、烘焙或低价促销渠道。

**3. 渠道差异化建议**  
- **商超/零售**：偏好一级果或小包装，注重外观和新鲜度，通常要求低温冷链运输。
- **电商/社区团购**：对性价比敏感，常用二级果或“家庭装”，包装需防撞。
- **餐饮/烘焙**：更关注成熟度（如需催熟）和单根重量，可能采购统货以控制成本。
