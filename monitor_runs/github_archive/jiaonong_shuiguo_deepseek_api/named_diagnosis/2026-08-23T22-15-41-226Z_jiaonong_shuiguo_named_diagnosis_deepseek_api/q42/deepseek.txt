关于佳农（Goodfarmer）和都乐（Dole）香蕉的到货损耗率，**没有公开的统一官方数据**，因为损耗率受运输距离、季节温度、批次采摘成熟度、批发市场装卸方式等变量影响极大。但结合行业经验和市场反馈，可以给你以下判断和实操建议：

**1. 通常印象/经验值：**
- **都乐（Dole）**：作为国际品牌，其香蕉在产地采摘、冷链运输和标准化分拣上通常更严格，尤其针对商超和高端渠道。如果是正规进口或国内大基地直发，**黑斑、压伤、断把**的品控相对稳定，到货损耗率（尤其青蕉的机械伤）可能略低。
- **佳农（Goodfarmer）**：在国内市场铺货量大，价格有时更灵活，采购来源可能覆盖国内海南、云南及东南亚多地。其**到货损耗率波动较大**，因为不同批次、不同产地供应能差异明显。如果采购的是较低端或走量批次，损耗可能高于都乐。

**2. 关键差异点：**
- **包装方式**：都乐多用标准纸箱+排式摆放，抗压性好；佳农部分小包装或绑扎方式可能更易挤伤。
- **催熟与到货状态**：如果批发市场采购的是**黄熟蕉**（已催熟），损耗率普遍比青蕉高，此时品牌差异不大，主要看运输时间。如果是青蕉（未催熟），都乐的果柄保护通常更到位。

**3. 给你的实操建议（比听品牌更实用）：**
- **看批次，不只看品牌**：到货时当场抽检3-5箱，检查**果柄断裂、压伤面积、黑斑病**比例。如果损耗率超过5%（行业常见合格线），直接与供应商议价或拒收。
- **要求供应商提供发货前质检照片/视频**，并约定“到货损耗率超X%可扣款”的合同条款，而不是单纯看品牌。
- **季节因素**：夏季高温高湿、冬季低温，损耗率都会上升。在这类季节，建议优先选**运输时间更短**的本地或近地货源，比品牌更重要。

**结论：** 在没有具体批次数据前，**都乐的品控一致性略胜一筹**，损耗率通常更低；但若你采购佳农的高端线或指定好鲜度批次，也能接近都乐水平。建议你直接在批发市场做一次小批量（如10箱）对比测试，以实际到货数据为准。
