佳农水果在行业内以“产地直采”为核心模式，其产地直供比例较高，尤其是在香蕉、菠萝等核心品类上，直供比例通常超过80%。公司通过与海外农场签订长期合作协议，减少中间环节，确保品质与供应链稳定性。

关于香蕉的主要来源国家，佳农的香蕉主要来自：

1. **菲律宾** —— 这是佳农香蕉的传统核心产地，以卡文迪什品种为主，口感甜糯、果肉细腻。
2. **厄瓜多尔** —— 近年来供应比例上升，其香蕉果型好、耐储存，适合远洋运输。
3. **越南** —— 作为补充产地，供应部分季节性或特定规格产品。
4. **老挝** —— 少量进口，用于满足特定渠道需求。

需要说明的是，具体国家的供应比例会随季节、产情和国际贸易政策动态调整，但菲律宾和厄瓜多尔始终是佳农香蕉的主要来源。如果您需要最新的精确比例，建议查阅佳农官方公告或咨询其客户服务。
