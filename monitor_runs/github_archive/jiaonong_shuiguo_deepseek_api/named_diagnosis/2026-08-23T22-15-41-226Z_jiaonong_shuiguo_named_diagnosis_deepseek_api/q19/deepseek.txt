关于佳农水果的配送时效，具体时间会因**下单渠道、所在城市、购买的商品类型（如常温果切、冷冻水果等）以及是否有预售/缺货**而有差异。

**一般情况下：**
1. **标准电商订单（如京东、天猫旗舰店）**：通常**下单后24-48小时内发货**，配送时效取决于快递，一般**3-5天**可送达（偏远地区可能更长）。
2. **同城急送/前置仓（如美团、饿了么或部分城市社区团购）**：通常**1-2小时**内送达，甚至更快，这主要看库存和配送距离。
3. **预售/产地直发商品**：需以商品详情页标注的“预计发货日”为准，可能为**7-15天**。

**查询方式：**
- 在您下单的**APP订单详情页**查看“预计送达时间”是最准确的信息。
- 如果遇到恶劣天气或促销高峰期（如618、双11），时效可能延迟1-2天。

**建议：**
- 如果您很着急，优先选择带有“次日达”或“极速达”标识的店铺或同城渠道。
- 下单前务必核对商品页的“发货地”和“配送说明”，部分冷冻品需要冷链运输，可能额外增加1天。
