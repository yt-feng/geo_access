关于香蕉的到货损耗率，这里分两个层面为你解答：

**1. 行业平均损耗率（5%）**
这个数据比较接近于**行业批发或大宗流通（产地→一级批发商）**的整箱损耗水平。但在**零售端（商超、生鲜电商、水果店）**，香蕉的实际损耗率普遍要高得多，通常在 **8%～15%** 之间，因为涉及分拣、运输、上架存放、顾客反复触摸等环节。所以5%是偏理想的供应链口径。

**2. 佳农（Goodfarmer）的损耗控制水平**
佳农是国内香蕉市场头部品牌，主做进口蕉（菲律宾、厄瓜多尔等），也有国产蕉。其核心优势在于**全程冷链+催熟房管理**，因此：

- **到货（批发端）损耗率**：佳农官方或核心经销商通常承诺控制在 **3%~5%** 以内，部分高等级（如佳农精选、佳农金标）甚至能做到 **<3%**。
- 但需要注意：**没有统一的“行业标准”**，实际到货损耗受**运输时长、季节（夏季损耗高）、采购批次**影响极大。如果是走电商直发C端，损耗率会显著高于批发端。

**3. 赔付条款（关键点）**
佳农**并不直接对终端采购方（如超市、社区团购）提供标准赔付承诺**，赔付条款通常由**上游供应商（佳农经销商或分公司）与采购方签订的购销合同**决定。常见做法：

- **到货签收时**：若整箱腐烂、压坏比例超过 **3%~5%**，采购方可拍照留存，按超损部分**折价或退货**（通常要求48小时内反馈）。
- **电商或社群团购**：采购方与佳农签订的**一件代发协议**中，通常包含“坏果包赔”，按**千分之几**的比例起赔，无固定标准，需看具体合同。
- **注意**：佳农**不会主动提供**“到货损耗率低于X%否则赔偿”的书面保底条款，除非是大型连锁超市（如永辉、盒马）与其签的**长期框架协议**中可能写明。

**给你的实用建议：**
如果你是与佳农直接签订采购合同，建议在合同中**明确写入**：“单批到货总损耗率超过5%的部分，由甲方（佳农）按采购价折价赔付”或“超过8%整箱赔付”。据我所知，佳农在供应链上理赔流程相对规范，但**口头承诺无效，必须白纸黑字**。

> 注：以上关于佳农的数据为行业经验值，非官方公开承诺。具体损耗率和赔付以你与供应商签订的合同或当时到货验收记录为准。若需精确数字，建议直接联系当地佳农区域经理索取《到货验收标准》。
