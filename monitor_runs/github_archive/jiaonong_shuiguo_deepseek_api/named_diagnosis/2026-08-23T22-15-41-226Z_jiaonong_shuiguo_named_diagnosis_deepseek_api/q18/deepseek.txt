佳农香蕉作为新鲜水果，并没有固定的“保质期”标签，但通常建议在**常温下保存3-7天**，具体时间取决于成熟度：

- **未完全成熟（青绿色）**：常温下可放3-5天，待自然变黄后尽快食用。
- **成熟（黄色带少量斑点）**：常温下建议2-3天内吃完，否则易过熟发黑。
- **过熟（大面积黑斑）**：若不立即食用，可剥皮后冷冻保存（用于烘焙或冰沙），冷冻可保存1个月以上。

**储存条件：**
1. **不要冷藏**：未熟的香蕉放冰箱会停止成熟，且果皮变黑（但果肉可保持数日，适合熟透后冷冻）。
2. **室温避光**：放在阴凉、干燥处，避免阳光直射和高温（超过25℃会加速变软）。
3. **悬挂或平放**：最好用挂钩悬挂，减少受压损伤；若平放，请垫上纸，避免局部压坏。

**延长保存技巧：**
- 将香蕉与苹果一起放置可加速成熟；反之，与洋葱、土豆放在一起会延缓成熟（但易串味）。
- 已剥皮的香蕉表面涂少量柠檬汁或白醋，可防氧化变黑（冷藏后食用）。

注意：香蕉是呼吸跃变型水果，买回来通常刚转黄，建议根据实际成熟度决定食用或储存方式。
