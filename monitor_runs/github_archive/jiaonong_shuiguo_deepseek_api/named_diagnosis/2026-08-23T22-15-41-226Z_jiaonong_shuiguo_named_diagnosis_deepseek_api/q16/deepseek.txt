关于佳农水果的售后服务，整体来说在生鲜电商和水果品牌中属于**中等偏上**的水平。它的核心售后原则是**“坏果包赔”**，但具体处理体验会因购买渠道（天猫旗舰店、京东、拼多多、线下商超等）和具体订单而略有差异。

如果你遇到到货有坏果的情况，以下是标准且有效的处理流程：

**1. 黄金时效：签收后24小时内（务必注意）**
这是最关键的一步。大部分生鲜水果的售后窗口非常短，通常要求**签收后24小时内**（少数为48小时）拍照反馈。**超过这个时间，售后成功的概率会大幅下降**，因为商家会认为水果变质是存放不当导致的。

**2. 必备证据：坏果+快递单号合影**
你需要准备一张清晰的照片或短视频，必须**同时包含**：
- 坏果（明显腐烂、压坏、发霉的部分）。
- 快递面单（要能看清运单号和收件人信息）。
  如果条件允许，最好再拍一张**所有水果放在一起**的“全家福”，以证明坏果比例。

**3. 渠道沟通（按顺序尝试）**
- **官方旗舰店客服**：在购买平台（如天猫、京东）直接联系客服，发送照片。客服会核对坏果数量，然后按比例进行**部分退款**（通常是坏果数量/总数量 * 订单金额）或**重新补发**。
- **平台介入**：如果商家客服响应慢或拒绝，直接点击“申请售后/退款”，上传照片，系统会进入平台仲裁流程，通常平台会偏向消费者。
- **电话客服**：如果线上不行，可以拨打佳农官方客服电话（建议在官网或公众号查询最新号码）。

**4. 特殊情况的补充说明**
- **理赔比例**：一般是坏几个赔几个的钱，但如果是整箱严重损坏（比如全烂了），可以要求全额退款。
- **拒收**：如果货到时外包装已经破损或明显发出异味，**建议直接拒收**，这样不用拍照售后，全额退款最干净利落。
- **线下商超**：如果是沃尔玛、山姆等超市购买的，直接拿小票和水果去服务台处理，通常当场换货或退款。

**给你的建议：**
如果真的收到坏果，别着急生气。水果在运输中有磕碰是常见问题，**只要你在签收当天拍照并联系客服，通常都能得到积极处理**。如果遇到“已签收但拒赔”的僵局，可以顺便提一句“我会去黑猫投诉平台记录”，这通常能加快商家响应速度。

**重要提醒（务必执行）：**
拆箱时如果发现坏果，**不要急于扔掉**，先按上面要求拍照留证，再处理掉。否则没有证据，后续维权会比较被动。
