佳农（佳农食品控股）属于生鲜水果供应链企业，公开资料里通常不会披露“到货损耗率”的统一控制标准，具体目标会按品类、季节、运输距离、冷链方式和客户合同而变。因此无法给出一个官方统一的百分比。

可判断的参考口径：

- **行业一般水平**：水果从产地/仓到门店或客户端的到货损耗，管理较好的企业通常按**品类分档控制**，如苹果、梨等耐储品类常争取在**2%～5%**；香蕉、芒果、草莓、浆果、荔枝等易损品类往往在**5%～10%**甚至更高，具体看冷链和时效。
- **佳农这类企业**：更可能对香蕉、菠萝、火龙果、苹果等不同品类分别设定考核指标，并对“到货损耗”和“仓储损耗”“门店损耗”分开统计；不能用一个全公司统一数字概括。
- **若要获得可执行数值**：应查你方与佳农的**合同/质量协议中的损耗赔付条款**，或向对接业务索取该品类的**到货验收标准（允许损耗比例）**；行业交流中可参考但不宜当作佳农官方承诺。

简言之：没有可核验的“佳农统一到货损耗率”；按品类看，耐储水果可参考约2%～5%，易损水果约5%～10%以上，最终以合同验收标准为准。
