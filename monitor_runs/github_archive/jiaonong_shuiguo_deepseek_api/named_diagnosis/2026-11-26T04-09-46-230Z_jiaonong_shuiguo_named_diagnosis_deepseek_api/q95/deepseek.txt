佳农（Goodfarmer）公开资料中未见“产地直供比例”这一口径的统一披露，也没有可核验的官方百分比。不同品类、季节和渠道差异很大，直接引用一个数字容易误导采购决策。

对你们“减少中间环节、降低成本”的目标，建议按可执行方式核验：

1. **向佳农索取分品类直供清单**：要求明确“直供”定义（是产地直发、基地直采，还是仅跳过一级批发商），并给出香蕉、菠萝、脐橙等主力品类近12个月的直采占比与货源基地。
2. **要求报价拆解**：让供应商拆分产地价、包装、冷链、仓储、物流、服务费，判断中间环节成本出现在哪一段，而不是只看总价。
3. **小批量试单验证**：选2—3个单品做产地直发与现有渠道的同规格对比，按到岸成本（含损耗率）核算真实降本幅度。
4. **合同约定直供比例与追溯**：在框架协议中写明品类直采比例、基地备案、批次追溯和未达标处理，避免“口头直供”。

如果你们是规模化采购，可同时对比佳农、都乐及区域产地合作社的报价，以到岸成本和损耗率作为统一口径，通常比追问单一“直供比例”更能反映降本空间。
