佳农水果的售后整体属于“生鲜电商常规水平”，但实际体验取决于你在哪个渠道购买（自营App、京东/天猫旗舰店、商超、社区团购等），不同渠道售后规则差异很大。

**一般处理逻辑**
1. **到货先验货**：坏果、烂果、压伤、霉变，第一时间拍照/拍视频，保留外包装、面单和坏果原状，不要急着扔。
2. **尽快联系购买渠道客服**：佳农通常不是直接面对消费者的售后主体，而是由销售平台处理。比如京东自营找京东客服，天猫旗舰店找店铺客服，商超找门店服务台。
3. **按平台规则申请**：多数渠道支持“坏果包赔/按比例赔付”。常见处理是补发、退款或按坏果比例赔付，通常要求提供坏果照片和数量。
4. **注意时效**：生鲜类售后一般要求签收后24—48小时内反馈，越早越好；超过时限可能不受理。
5. **保留证据**：开箱视频、坏果特写、整箱合照、快递面单，能明显提高处理效率。

**实际体验判断**
- 在京东自营、天猫旗舰店等正规渠道，坏果售后通常比较规范，按比例赔付较常见。
- 社区团购、低价拼团渠道售后参差不齐，可能只给少量补偿或要求自行承担。
- 佳农主打香蕉、菠萝等品类，运输中压伤、冻伤、过熟较常见，建议收货后尽快检查。

**建议**
到货有坏果时，不要先和快递员争执，直接走购买平台售后入口，上传证据并说明坏果数量，要求按平台“坏果包赔”规则处理。如果客服推诿，可要求平台介入。购买前也可先看该店铺近期的售后评价和赔付规则。
