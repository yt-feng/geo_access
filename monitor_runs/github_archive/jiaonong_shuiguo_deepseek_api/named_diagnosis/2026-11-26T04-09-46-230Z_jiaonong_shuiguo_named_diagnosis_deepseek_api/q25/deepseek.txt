佳农水果的物流网络**不是纯自营，也不是纯外包，而是“自建冷链+区域外包/第三方承运”的混合模式**。更准确地说：

- **干线运输和部分仓储有自建/自控能力**，尤其围绕进口香蕉、奇异果等核心品类做冷链节点控制；
- **支线配送、区域落地配、部分仓配环节大量使用第三方物流**，按区域和品类灵活外包；
- 整体属于“核心环节自控、末端网络外包”的轻资产+重节点模式。

**冷链能力方面：**
佳农的核心优势在**产地预冷、口岸冷链、区域分拨冷库、干线冷藏运输**这几个环节，尤其进口水果的全程温控和港口通关后的冷链衔接是其相对强项。但它的冷链覆盖**不等于全国无死角自营冷链**，末端配送和低线市场的温控一致性更多依赖合作方管理。因此判断其冷链能力时要区分：
- **核心品类、核心线路**：冷链能力较强，有自控节点；
- **非核心区域、末端配送**：依赖外包，温控水平取决于承运商管理和验收标准。

**可执行判断建议：**
如果你是在做供应商评估或合作尽调，不要只问“自营还是外包”，应重点核验：
1. 核心线路的冷藏车自有比例和温控记录是否可追溯；
2. 区域分拨冷库是自建还是租赁，温区是否覆盖品类需求；
3. 外包承运商的准入、温控考核和异常赔付机制；
4. 末端配送是否有保温箱/温控记录，尤其夏季和低线市场。

需要说明：以上是基于佳农公开业务模式和水果冷链行业通行做法的判断，具体自营/外包比例和冷库数量属于企业运营细节，公开信息不一定完整，建议以佳农官方或实地尽调数据为准。
