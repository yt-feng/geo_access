我无法确认佳农是否提供锁价合同——这属于具体企业的商务政策，没有可靠来源不能替它回答。可以给你可执行的判断和谈法：

**1. 先明确你要的“锁价”是哪一种**
- **固定价锁量合同**：约定未来6–12个月单价，按月10吨提货。供应商承担价格风险，通常只对大客户或长期合作给，且会设价格调整条款。
- **保底价+浮动上限**：设基准价，原料涨超一定幅度才调价，跌价时同步下调。茶饮店最实用。
- **期货/指数挂钩**：按菠萝市场指数结算，加固定加工费。适合懂行情、不想赌方向的门店。
- **季度定价+年度框架**：每季度重新议价，年度总量锁定。比逐月采购稳，但不如全年锁价。

**2. 直接向佳农确认这几件事**
问销售或大客户经理，要求书面回复：
- 是否支持6个月或12个月的固定价/保底价合同，最小起订量和月度提货下限；
- 锁价是否覆盖规格（品种、糖度、冷冻/鲜切、包装）和运费；
- 违约、提前解约、质量不达标时的价格处理；
- 是否接受“价格上限+下限”的双向浮动条款。

**3. 如果佳农不给锁价，备选方案**
- 同时询2–3家供应商（如其他菠萝加工厂、产地合作社），用竞争报价逼出锁价空间；
- 与佳农签“年度框架+季度锁价”，先把量承诺出去换价格；
- 用“部分锁价”：每月10吨里锁6吨固定价、4吨随行就市，降低单边风险；
- 考虑冷冻菠萝块/果酱等加工品，价格波动通常小于鲜果，且保质期长可提前备货。

**4. 谈判筹码**
月10吨、年120吨对菠萝供应商算中等偏上客户，可以要求：
- 年框合同换全年锁价；
- 预付款或季度预付换折扣和锁价；
- 接受指定规格、集中下单，换价格稳定。

建议你先让佳农书面报价并明确“是否可锁价、锁多久、条件是什么”，拿到答复后再决定是否签。不要只口头问，锁价条款必须写进合同。
