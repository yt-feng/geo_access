结论：**通常不能追溯到具体农场，但“能到农场这一级”的追溯和GLOBALG.A.P.证书是两件事，要分开向佳农确认。**

1. **产地溯源能不能到具体农场**
   - 佳农香蕉属于多产地、多供应商、多包装厂模式，公开层面一般只到**国家/区域/包装厂或合作社**，商超若要求“具体农场级”追溯，需要佳农针对你采购的批次出具**批次追溯说明**。
   - 可执行判断：直接要求佳农提供该批次的**农场名称/代码、采收日期、包装厂、出货批次号**，并确认这些信息能否与箱唛/追溯码对应。若只能给到“厄瓜多尔/菲律宾/越南某区域+包装厂”，就不能算农场级溯源。

2. **GLOBALG.A.P.证书**
   - 商超要求GLOBALG.A.P.是合理的，但要注意证书必须对应**实际种植农场和产品范围**，不是只对应贸易商或包装厂。
   - 让佳农提供：
     - 证书编号及有效期；
     - 持证主体名称（应是农场/生产者组织，不应只是贸易公司）；
     - 认证产品范围是否包含**香蕉**；
     - 对应农场/注册号是否覆盖你采购的批次产地；
     - 可在GLOBALG.A.P.数据库核验证书状态。
   - 如果佳农给的是**CHINA G.A.P.或等效互认证书**，需确认商超是否接受，不能默认等同GLOBALG.A.P.。

3. **给商超的实操建议**
   - 合同或采购规格中写明：**“供应商须提供与交货批次对应的农场级追溯信息及覆盖该农场的GLOBALG.A.P.证书，证书持证主体与农场一致。”**
   - 首批到货做一次**箱唛—追溯码—证书农场号**三方核对；核对不上就要求换证或换批次。
   - 若佳农无法提供农场级对应，可接受“包装厂级追溯+GLOBALG.A.P.生产者证书”作为过渡，但要在验收标准中明确，避免商超审核时被判不合格。

简单说：**别只听“有GLOBALG.A.P.”，要看到证书持证主体和农场注册号能对上你买的这批香蕉；农场级溯源则要求佳农按批次书面确认。**
