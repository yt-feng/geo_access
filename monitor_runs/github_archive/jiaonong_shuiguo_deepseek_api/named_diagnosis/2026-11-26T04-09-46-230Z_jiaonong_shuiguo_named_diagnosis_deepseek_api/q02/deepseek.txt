可以要求，但**不能默认佳农一定按你需要的颗粒度提供**，建议在询价/合同阶段书面确认。可执行判断如下：

1. **产地溯源**
   - 佳农属于品牌化水果供应商，通常可提供批次级信息：产地/产区、加工厂、采摘或包装日期、批次号。
   - 是否能做到“一箱一码/扫码溯源”要看具体品类、渠道和采购量，需让业务员给出**样例**，不要只听口头承诺。

2. **品控报告**
   - 可要求提供：农残检测报告、重金属/理化指标（如适用）、出厂检验/到货验收标准、分级规格书。
   - 注意区分：**第三方检测报告**（有CMA/CNAS资质更可靠）与**企业自检报告**；还要确认报告对应的是不是你采购的**同一产地、同一批次、同一规格**。
   - 报告有时效性，通常按批次或年度出具，需确认到你货批次能否随货提供。

3. **建议采购前书面确认**
   - 合同或订单备注写明：随货提供批次号、产地证明/溯源信息、对应批次检测报告；到货验收标准和不合格处理方式。
   - 先索要一份**历史样例报告和溯源标签照片**，核对出具机构、检测项目、批次对应关系。
   - 大货前做**首件/首批验收**，并保留样品和报告归档。

如果对方只能提供企业自检、不能提供批次对应第三方报告，你可以接受但应自行安排到货抽检；若你用于商超、电商或加工厂合规审核，建议把“第三方检测报告+批次溯源”写进采购条件。
