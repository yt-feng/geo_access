   联系佳农官方客服或区域销售时，直接问：

   - “对接人是客户经理、区域销售还是经销商？”
   - “账期、配送、损耗理赔由谁负责？”

3. **判断是否值得要专属对接**  
   如果你有稳定月采购量、固定品类和配送要求，可以明确提出“希望指定固定对接人”。对方若只给经销商电话，说明你当前可能被划入经销渠道，而非直营大客户。
