1. **先明确你要的是“鲜切”还是“冷冻/速冻”**
   - 餐饮渠道常见定制形态：整果、去皮整果、1/4切、切片、切块、菠萝丁、菠萝条。
   - 鲜切菠萝保质期短，通常走冷链、区域配送；冷冻菠萝块/丁更适合跨区域和稳定供应。

2. **直接问佳农的餐饮渠道/大客户渠道**
   联系时按这组问题问，能快速判断是否支持：
   - 是否有餐饮专供菠萝SKU？
   - 是否支持切片/切块/切丁定制？最小起订量、规格（克重/尺寸）、包装（袋装/真空/箱装）？
   - 鲜切还是冷冻？保质期、储存温度、配送范围？
   - 是否需要提前预订、交期多久、是否支持样品？
   - 是否有食品安全/资质文件（如SC、检验报告）？

3. **看包装和标签判断**
   若拿到样品或报价单，重点看：产品类型（鲜切/冷冻）、净含量、规格尺寸、储存条件、保质期、生产商/委托方、SC编号。餐饮定制规格通常会在报价单或合同里写明，而不是只靠口头。

4. **替代验证路径**
   - 让当地水果批发商/餐饮食材配送商问佳农区域业务员；
   - 在佳农官网/公众号找“餐饮渠道/大客户/联系我们”入口；
   - 参加餐饮供应链展会时直接问区域负责人。
