**发票**
- 佳农水果礼盒一般可由销售方开具增值税发票；需确认是**增值税普通发票还是专用发票**、税率/征收率、开票主体是否与合同收款方一致。
- 下单前让对方提供：营业执照、开票信息确认单、发票样张或开票项目名称（如“水果礼盒/农产品”）。
- 合同里写明：500份、单价、总价、开票类型、开票时间（建议付款后/发货前明确）、发票不符可退换。

**质检报告**
- 要求提供**与本次批次对应的**质检报告或产地/农残检测报告，不接受只给一份过期通用报告。
- 核验报告上：产品名称、规格、生产/包装日期或批号、检测项目（农残等）、检测机构、报告编号、结论。
- 水果属生鲜，通常还需到货验收标准：外观、重量、坏果率、赔付规则。建议合同写明“坏果/破损按比例补发或退款”。
