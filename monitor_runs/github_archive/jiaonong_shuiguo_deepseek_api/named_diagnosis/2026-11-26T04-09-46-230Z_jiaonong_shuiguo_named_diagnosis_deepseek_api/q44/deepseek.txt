**1. 先明确你要的合规证明清单**
向佳农（或其在当地的经销商/分公司）书面索取以下材料，缺一不可：
- 供货批次对应的**出厂检验报告**（含农残项目、检测方法、判定依据、批次号）
- 第三方**CMA/CNAS资质检测机构**出具的农残检测报告（报告编号可在机构官网或全国认证认可信息平台核验）
- **产地证明 / 基地备案信息**（出口或商超渠道通常有备案基地）
- **承诺书/质量保证协议**（明确农残符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》）
- 如走进口香蕉，另要**入境货物检验检疫证明**

**2. 关键核验动作（别只看盖章）**
- 报告必须与你**实际到货批次**对应，不是“同品类通用报告”
- 核对检测项目是否覆盖香蕉常检农药（如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、百菌清等），以及报告日期是否在有效期内
- 用报告编号向出具机构**电话或官网反查真伪**
- 要求供应商提供**近12个月同品类抽检合格记录**，并写进合同附件

**3. 把风险前置到合同和验收**
- 合同约定：到货抽检不合格的退货、赔偿、检测费承担条款
- 超市抽检前，你自己按批次送一次**快检+定量复检**（成本可控，能兜底）
- 建立**批次留样**制度，留样至少到保质期后一段时间，抽检争议时可复检

**4. 关于“历史超标”怎么查**
不要依赖供应商口头保证。可自行核查：
- **国家市场监督管理总局**及各省市市场监管局官网的“食品安全抽检通告”，按“香蕉”“佳农”检索
- **海关总署**进口食品不合格信息（如为进口）
- 让供应商书面说明近三年是否被抽检不合格、是否被处罚，并加盖公章
