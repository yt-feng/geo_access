佳农水果的香蕉执行的是**企业标准（企标）**，不是国标。佳农作为品牌商，其香蕉产品通常标注的是企业自定的质量标准（如佳农自己的香蕉产品标准），而非直接套用 GB/T 或 GB 系列国标。国标如 GB/T 9827（香蕉）是推荐性行业/产品标准，企业可以自定更严格或不同的企标并备案执行。

关于“比普通香蕉贵多少”：**没有统一固定比例**，因为普通香蕉价格随地区、季节、渠道（商超/菜市场/电商）波动很大。一般经验是佳农品牌香蕉比同规格散装普通香蕉**贵约 20%–50%**，促销时差距缩小，高端商超差距可能更大。建议以你所在地同一天、同规格（如每斤或每把）的佳农香蕉与普通香蕉标价直接对比，这个差价才可判断。
