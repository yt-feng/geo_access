我没法核验佳农当前对茶饮店的菠萝丁加工/代切服务政策，不能替你确认“能或不能”。建议你直接按下面方式问，最快得到可执行答案：

1. **问佳农官方渠道**：佳农官网/公众号客服、当地经销商或区域销售，明确问三件事：
   - 是否提供**菠萝丁/果块加工**（不是整果）；
   - 规格：丁的尺寸、糖度/成熟度、是否冷冻/冷藏、固形物、包装规格；
   - 起订量、加工费、配送温层、批次稳定性。

2. **让对方给样品和报价单**：茶饮店用菠萝丁重点看**出杯稳定性**（大小均匀、汁水、酸甜度、是否易碎、解冻/开封后保存）。没有样品和规格书就不要定。

3. **备选路径**：如果佳农只卖整果或不接小批量加工，可找**本地净果加工厂/中央厨房代切**，或直接采购**冷冻菠萝丁供应商**；整果自行切丁则要评估人工、损耗和食品安全。

一句话：**先向佳农官方确认“是否卖菠萝丁成品或接代切”，同时按茶饮规格要样品和报价；不要默认它只卖整果。**
