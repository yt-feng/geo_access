1. **先明确你的需求门槛**

   - 是否需要冷链、到店时间窗、拆零还是整箱、退货和损耗标准

2. **向佳农确认四个关键点**

   - **质量与损耗**：到货成熟度标准、破损/黑斑/掉把的赔付规则、抽检方式。

3. **要求试用期和SLA**
   - 先签1个月试供或小区域试配，约定准时率、缺货率、损耗赔付、异常响应时限。
