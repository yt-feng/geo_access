佳农（上海佳农食品）主要做香蕉、菠萝等鲜果的贸易和分销，通常以整果或标准鲜果规格供货，一般不直接向茶饮店提供“去皮切块”的定制加工服务。能提供这类服务的通常是：

1. **鲜切水果加工厂/中央厨房**：可做去皮、切块、真空包装，按门店配送。
2. **佳农的经销商或当地果蔬加工商**：部分区域经销商有鲜切能力，可问佳农当地销售是否对接。
3. **第三方净菜/鲜果供应链公司**：茶饮连锁常用这类供应商做标准化鲜切菠萝。

建议你直接向佳农当地销售确认两点：①是否供“鲜切菠萝块”SKU；②能否对接有资质的鲜切加工商。若没有，就找当地有SC/食品经营资质的鲜切工厂，要求提供农残检测、冷链配送和保质期标准。注意：门店自行去皮切块可以，但若由外部加工后配送，需确认加工方资质和冷链条件。
