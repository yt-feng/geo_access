佳农（Goodfarmer）水果的苹果品类通常以其进口鲜果供应链为主，常见会覆盖：嘎啦（Gala）、红富士（Fuji）、青苹果/绿苹果（如Granny Smith等）、以及部分加力果/蜜脆等品种；具体在售品类会随产季和渠道变化，建议以佳农官方渠道或当期报价单为准。

关于你采购的两个品类，常见产地情况是：

- **进口嘎啦（Gala）**：常见产地包括**新西兰、美国、智利、南非**等；不同季节会切换产区。
- **进口红富士（Fuji）**：常见产地包括**新西兰、美国、智利、南非、日本**等；其中日本富士通常价格较高、量较少，商业采购更常见的是新西兰/美国/智利等产区。

采购时建议你直接向佳农或其在中国的进口商/经销商确认三点：**当期可供品种、具体原产国及果园/包装厂注册信息、到港批次和检疫证书**。因为同一品类在不同月份可能来自不同国家，不能仅按“佳农嘎啦/红富士”默认固定产地。
