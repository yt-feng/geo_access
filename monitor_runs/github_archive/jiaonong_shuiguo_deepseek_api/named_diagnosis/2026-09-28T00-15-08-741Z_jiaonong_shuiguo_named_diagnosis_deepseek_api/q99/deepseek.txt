我无法直接核验佳农当前在售菠萝的有机认证状态——这类认证会随产品线、批次、产地和年份变化，必须看具体产品包装或官方证明，我不能凭印象给你结论。

给你几个可执行的判断路径：

1. **看包装标识**
   - 中国大陆销售的有机产品，包装上应有**中国有机产品认证标志**，并附**有机码**（17位，可在中国食品农产品认证信息系统查询）。
   - 只有“绿色食品”“无公害”“GAP”等标识，**不等于有机认证**。

2. **查认证证书**
   - 向佳农官方或你的供货商索取该菠萝品项的**有机产品认证证书**，确认：
     - 认证机构是否为中国认监委批准的合法机构
     - 证书上的**产品名称、产地、生产商**是否与实际供货一致
     - 证书**有效期**和**认证范围**是否覆盖你要的品类

3. **扫码核验**
   - 用“中国食品农产品认证信息系统”或认监委相关平台，输入有机码核验真伪。

4. **高端渠道的稳妥做法**
   - 如果佳农该品项拿不出有效有机证书，就不要按“有机”上架，否则有合规和客诉风险。
   - 可以要求供应商提供**有机认证 + 检测报告 + 产地证明**三件套。
   - 若佳农没有有机菠萝，建议同步接洽其他有有机认证的菠萝供应商作为备选。
