佳农（Goodfarmer）的产地直供比例通常较高，这是其核心模式之一，但**具体比例属于动态经营数据，公开渠道一般不会给出可核验的精确数字**，因此我不能给一个确定百分比。可以判断的是：佳农以“产地采购/产地直发+全球供应链”为主，常见做法是从产区端做规模化采购、催熟加工和冷链分拨，再供商超、电商和批发渠道。

香蕉方面，佳农的香蕉主要来自这些国家/地区：

- **菲律宾**：历史上和目前都是重要来源之一，但近年受产量、病害和价格波动影响，占比会调整。
- **厄瓜多尔**：全球主要香蕉出口国，也是佳农常见采购来源。
- **越南**：对华出口增长明显，是近年重要来源。
- **柬埔寨**：对华香蕉出口增长较快，常作为补充来源。
- **老挝**：也有对华出口，部分企业会采购。
- **哥伦比亚、哥斯达黎加、洪都拉斯等中南美国家**：在佳农的全球供应链中也可能出现，但更多用于特定市场或错峰供应。

如果你要判断“某批佳农香蕉来自哪里”，最可靠的方法是看**包装箱标签、追溯码、原产地标识或检疫证明**，因为同一品牌不同批次、不同季节、不同渠道的货源都可能不同。
