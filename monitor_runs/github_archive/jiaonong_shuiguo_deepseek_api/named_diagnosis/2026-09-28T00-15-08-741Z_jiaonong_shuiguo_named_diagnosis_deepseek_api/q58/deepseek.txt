我无法直接核实佳农目前的加工服务政策，因为他们对B端客户的具体方案（是否提供菠萝丁代加工、起订量、规格）可能会随渠道和区域变化。不过可以给你一些判断路径和替代方案：

**1. 先明确你要的是哪种“菠萝丁”**
- 冷冻菠萝丁（IQF）：茶饮店最常用，开袋即用，稳定性好
- 糖水菠萝丁/罐头：偏甜品、部分饮品
- 新鲜菠萝切丁：门店自己切，损耗和人工高

**2. 佳农大概率是什么模式**
佳农以水果贸易和品牌化生鲜为主，常见供货形态是整果（如菠萝、凤梨）、部分鲜切/冷冻水果。是否给茶饮渠道做定制菠萝丁，通常要看：
- 你是不是通过他们的B端经销体系拿货
- 有没有达到起订量
- 当地是否有对应的加工厂或合作工厂

**3. 建议你这样确认（最有效）**
直接问佳农的**餐饮/茶饮渠道销售**，不要问零售客服。问清楚这4点：
1. 有没有**冷冻菠萝丁**这个SKU，规格是多少（比如10mm/15mm）
2. 是**自有工厂加工**还是**代工/经销**
3. **起订量、价格、是否含糖/无糖**
4. 能否提供**样品和检测报告**

**4. 如果佳农不做，替代方向**
- 找**冷冻水果代工厂**：很多专门做IQF菠萝丁，可贴牌
- 找**罐头/糖水菠萝丁供应商**：适合甜品线
- 找**本地水果批发商+中央厨房**：自己切丁冷冻，但品控要自己扛

**5. 茶饮店选菠萝丁的关键指标**
- 大小均匀、不碎
- 解冻后不出水、不发酸
- 微生物和农残报告齐全
- 供货稳定，不是季节性断货
