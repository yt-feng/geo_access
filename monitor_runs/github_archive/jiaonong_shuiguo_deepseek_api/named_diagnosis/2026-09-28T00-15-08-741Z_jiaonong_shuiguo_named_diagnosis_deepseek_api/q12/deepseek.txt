我无法核验佳农官方最新的完整规格表和分级标准，所以不能给出“官方有几种规格”的确定数字或逐条标准。下面给你一套**可执行、可判断**的通用分级框架，并说明如何快速拿到佳农的准确口径。

## 先说结论

佳农香蕉通常不是按“一个固定规格数”卖，而是按**渠道需求**分成几类规格维度：

1. **按重量/单根大小分**  
   常见如：小果、中果、大果、特大果；对应单根重量或每箱净重不同。

2. **按每箱净重分**  
   常见如：4.5kg、7kg、10kg、13kg、18kg、20kg 等箱规；出口和商超常见不同箱重。

3. **按梳/把规格分**  
   常见如：3-5根/把、5-7根/把、整梳、单根散装。

4. **按成熟度/催熟阶段分**  
   常见如：青蕉、微黄、黄熟、即食熟度；不同渠道对到货熟度要求不同。

5. **按外观等级分**  
   常见如：A级/一级、B级/二级、加工级；主要看条长、粗细、弯曲度、伤痕、黑点、青斑、机械伤。

6. **按品牌包装分**  
   常见如：佳农自有品牌箱、商超定制箱、电商箱、批发大箱。

所以如果你问“有几种规格”，更准确的说法是：**按渠道和用途组合后，会有多套规格，而不是固定一个数字。**

## 不同渠道适合的分级标准

下面给的是行业通用判断逻辑，不是佳农官方标准，但你可以直接拿去对照采购或验收。

### 1. 高端商超/精品超市
适合：
- 单根大小均匀
- 条长、粗细一致
- 外观干净，无明显机械伤、黑斑、裂口
- 熟度可控，到店后 2-4 天进入最佳售卖期
- 多采用小箱规或精包装，如 4-5 根/把、独立袋装、礼盒装

分级重点：
- 外观优先
- 均匀度优先
- 熟度稳定优先

### 2. 连锁商超/社区超市
适合：
- 中大果为主
- 允许轻微外观瑕疵，但不能影响食用
- 箱规适中，便于门店上架和周转
- 熟度分批到货，避免集中过熟

分级重点：
- 性价比
- 货架期
- 损耗可控

### 3. 电商/社区团购
适合：
- 单根重量稳定
- 抗压、耐运输
- 到货熟度偏青或微黄，给履约留时间
- 包装抗摔，常见 5 斤、10 斤、整箱装

分级重点：
- 运输耐受
- 到货一致性
- 售后率低

### 4. 批发市场/农贸渠道
适合：
- 大箱规、整梳或散装
- 对外观要求相对宽松
- 更看重价格、重量和周转速度
- 熟度可偏青，便于二次催熟

分级重点：
- 成本
- 重量足
- 周转快

### 5. 餐饮/烘焙/果汁加工
适合：
- 加工级或二级果
- 允许外观瑕疵、弯曲、大小不均
- 更看重出肉率、成熟度、价格
- 常按大箱或吨位采购

分级重点：
- 出成率
- 供应稳定
- 成本低

### 6. 出口渠道
适合：
- 条长、粗细、弯曲度、色泽高度一致
- 青蕉或特定催熟阶段
- 农残、检疫、冷链、包装标识要求严格
- 箱规和码放方式按目的国标准执行

分级重点：
- 标准化
- 合规性
- 冷链一致性

## 怎么拿到佳农的准确规格

最可靠的方式是直接问佳农官方或授权经销商，索要这几份文件：

1. **产品规格书**
2. **各渠道分级标准**
3. **箱规和包装清单**
4. **催熟到货标准**
5. **验收标准和损耗责任**

你可以直接这样问对方：

> 请提供佳农香蕉目前对商超、电商、批发、加工渠道分别执行的规格分级标准，包括单根重量、每箱净重、梳把规格、熟度阶段、外观等级和验收允收范围。

如果对方只给一个模糊说法，你可以要求：
- 按渠道分别列表
- 给出允许误差范围
- 给出到货熟度区间
- 给出不合格判定标准

这样你就能把“佳农有几种规格”变成一套可采购、可验收、可追责的标准。
