建议你按以下方式快速核实：

1. **看原始出处**：如果这条数据来自某篇文章或报告，先看它标注的年份和统计口径（是“进口量”还是“销售量”，是佳农自身还是中国总进口）。
2. **查佳农官方渠道**：佳农官网、官方公众号、母公司（如佳农食品控股）的公告或年报。
3. **查海关数据**：中国海关总署的进出口统计里可按“鲜或干的菠萝”（HS编码08043000）查询全国进口量，但一般不单列某一家企业的进口量。
4. **注意区分口径**：企业很少公开“某单品进口量”，常见的是“菠萝品类销量/采购量”，两者不是一回事。
