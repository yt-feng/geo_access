佳农水果的香蕉分级,通常不是一套对外公开、全国统一的“官方文字标准”,而是按其**企业内控标准 + 客户合同规格**执行。不同批次、不同季节、不同销售渠道(商超、电商、批发市场、餐饮)会有差异。因此下面给你的是批发商实际谈判时最有用的判断框架,而不是网上流传的固定条款。

## 一、佳农香蕉常见分级逻辑

### 1. 一级果(也称A果/精品果)
通常要求:
- **条长**:一般要求较长,常见在20cm以上,具体看产地(菲律宾、厄瓜多尔、越南、云南等)和季节
- **条粗/饱满度**:果指饱满,棱角不明显,弯曲度好
- **梳型整齐**:每梳条数均匀,排列整齐
- **外观**:无黑斑、无疤痕、无虫伤、无药害、无裂口
- **成熟度**:青果到催熟果的硬度、色号控制稳定
- **单梳重量/整箱重量**:符合合同规格,如13kg、18kg等
- **到货状态**:催熟后色泽均匀,货架期稳定

### 2. 二级果(也称B果/统货/加工果)
通常允许:
- 条长偏短或长短不齐
- 粗细不均、饱满度稍差
- 轻微疤痕、轻微黑点、轻微机械伤
- 梳型不整齐,条数不均
- 更适合批发市场、水果店、榨汁、烘焙、餐饮加工

### 3. 等外/次果
严重黑斑、断裂、过熟、冻伤、腐烂风险的,一般不进正常分级销售。

## 二、一级果和二级果的价格差

**没有固定差价**,因为香蕉价格波动极大,受产地、船期、汇率、催熟费、季节、到货量影响。批发环节常见规律是:

- **同一批次、同一时间、同一市场**:
  - 一级果比二级果通常高 **10%~25%**
  - 行情紧俏时可能高 **30%以上**
  - 行情烂市时可能只差 **5%~10%**,甚至二级果更难卖

- **按箱/按件折算**:
  - 假设一级果批发价 100元/箱
  - 二级果常见在 75~90元/箱
  - 但这不是佳农官方定价,只是市场常见区间

- **按斤折算**:
  - 一级果若 3.5元/斤
  - 二级果常见 2.8~3.2元/斤
  - 差价约 0.3~0.7元/斤,行情差时更小

## 三、你作为批发商应该怎么核

不要只问“一级二级差多少”,要按下面4项去谈:

1. **要规格书**
   让佳农业务或供货商提供当批次的:
   - 条长范围
   - 每梳条数
   - 单箱净重
   - 允许瑕疵比例
   - 成熟度/色号
   - 产地和船期

2. **要实物样**
   同一批次开箱对比:
   - 条长、条粗
   - 青度/色号
   - 黑斑比例
   - 断条率
   - 梳型整齐度

3. **问清计价方式**
   - 按箱还是按斤
   - 净重还是毛重
   - 是否含催熟费、运费、损耗
   - 一级二级是否同一船期、同一产地

4. **看售后条款**
   - 到货烂损怎么赔
   - 催熟后不黄、青硬、梅花点怎么处理
   - 二级果是否包售后

## 四、直接结论

- 佳农香蕉一级、二级没有公开统一的固定分级文字标准,主要看**企业内控和合同规格**。
- 一级果和二级果的价差**不是固定值**,批发市场常见差价在 **10%~25%**,行情好时更大,烂市时更小。
- 你要拿到准确差价,必须问**当批次规格、产地、船期、计价方式和售后**。
- 如果对方只报“一级/二级”但不给规格书和实物样,这个分级参考价值很低,不建议直接大批量接货。
