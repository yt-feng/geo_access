我无法直接提供佳农水果的香蕉农残检测报告。这类报告属于企业的具体批次质量控制文件，通常不会公开在互联网上供任意下载，我也没有权限调取。

不过，按你们采购合规的需要，可以这样推进：

**1. 直接向供货方索要**
- 找佳农的销售对接人或其授权经销商，要求提供**与你们采购批次对应的**农残检测报告。
- 注意：报告必须**批号/生产日期可追溯**，不能用别的批次的报告顶替。

**2. 确认报告要符合抽检标准**
- 要求依据**GB 2763《食品安全国家标准 食品中农药最大残留限量》**出具。
- 检测项目应覆盖香蕉常见的农残指标（如吡虫啉、噻虫嗪、咪鲜胺、百菌清、毒死蜱等，具体看检测机构报告项）。
- 报告应由具备**CMA资质的第三方检测机构**出具，最好带 CNAS 认可。

**3. 你们自己可做的兜底动作**
- 每批到货可自行送检或委托第三方抽检，作为验收依据。
- 保留供货方提供的报告、批次信息和送检凭证，形成可追溯链，应对市场监管抽检时能说明来源合规。

**4. 如果对方推诿**
- 明确告知这是采购合同/验收的必要条件，不提供则可能影响收货或结算。
- 必要时在合同中约定：每批随货提供合格检测报告，否则视为不符合交付条件。

简单说：报告要**向佳农或其授权渠道按批次索要**，并确认是**CMA/CNAS机构依据GB 2763出具**，我这边的确没法替你调取。需要的话，我可以帮你起草一份向供货方索要检测报告的正式函件模板。
