我无法核验佳农当前是否在售“冷冻菠萝丁”、具体规格和供货状态，不能凭空给你规格数字。建议按下面方式快速确认，避免采购踩坑：

1. **先确认渠道**
   - 找佳农官方客服/区域销售，问是否有**冷冻菠萝丁（IQF速冻菠萝丁）**，还是只有**菠萝罐头丁、糖水菠萝丁、鲜果**。
   - 同时问清楚是**佳农自产**还是**贴牌/经销**，茶饮店用最好要稳定批次。

2. **茶饮店常用规格重点问这几项**
   - 丁大小：常见会问 **5×5mm、8×8mm、10×10mm** 等，但佳农是否供这些规格必须以对方报价单为准。
   - 包装：常见有 **1kg/袋、2kg/袋、10kg/箱** 等，也要以实际为准。
   - 是否加糖：**纯冻果丁**还是**糖渍/糖水**，这会影响饮品甜度和成本。
   - 是否IQF：要问**单体速冻**，否则容易结块，出杯不方便。
   - 固形物/含水：如果是糖水型，要问固形物含量。
   - 保质期与储存：通常冷冻 **-18℃**，保质期常见12–18个月，但以包装为准。

3. **让供应商直接发这些资料**
   - 产品规格书
   - 配料表
   - 检验报告/检疫证
   - 样品
   - 报价单（含起订量、运费、是否含税）

4. **到样后这样判断能不能用**
   - 解冻后是否严重出水、发软、发酸。
   - 丁形是否完整，是否大量碎渣。
   - 是否有明显纤维渣，茶饮里会不会堵吸管。
   - 与你的茶底、糖浆搭配后风味是否被盖住。
