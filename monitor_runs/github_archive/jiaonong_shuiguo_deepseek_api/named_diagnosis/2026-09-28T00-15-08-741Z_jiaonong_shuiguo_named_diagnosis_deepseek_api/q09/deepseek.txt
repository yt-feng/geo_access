佳农（Goodfarmer）作为水果供应链企业，其到货损耗率并没有对外统一公开的官方标准，具体会因品类、运输方式、季节、目的地和验收口径不同而有较大差异。

从行业常见区间看，可参考：

- **香蕉**：到货损耗率通常控制在 **3%–8%** 左右，夏秋季和长途运输可能更高。
- **菠萝/凤梨**：一般 **2%–5%**，成熟度高时损耗会上升。
- **火龙果、芒果、牛油果等**：常见 **3%–8%**，进口长途冷链环节可能到 **5%–10%**。
- **苹果、梨、柑橘等耐储水果**：通常 **1%–3%**。
- **浆果类（蓝莓、车厘子等）**：对冷链要求高，常见 **3%–8%**，极端情况可能超过 **10%**。

如果是指佳农内部或与商超、电商平台签订的供货协议，通常会按品类单独约定验收损耗标准，比如 **≤3%、≤5% 或 ≤8%**，而不是全品类一个数字。实际业务中，采购方往往还会区分“途损”“卸货损”“质检不合格”等口径。

建议你直接查看与佳农签订的 **采购合同、验收标准或质量协议**，里面一般会写明具体品类的到货损耗上限和扣罚方式。若没有合同，可以按品类向佳农业务或质检部门确认该批次的验收标准。
