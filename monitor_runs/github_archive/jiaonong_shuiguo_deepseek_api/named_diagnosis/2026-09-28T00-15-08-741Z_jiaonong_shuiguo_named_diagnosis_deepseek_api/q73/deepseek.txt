佳农（Goodfarmer）水果在苹果品类上通常以进口和国产精品苹果为主，常见会涉及：

- **嘎啦果（Gala）**
- **红富士（Fuji）**
- **皇后苹果/爱妃苹果等高端品种**（不同渠道、季节会有差异）
- **青苹果/史密斯奶奶等**（部分渠道）
- **爵士苹果、太平洋玫瑰等**（视进口季和供应情况）

但具体到某一年、某一批次，佳农实际在售的苹果品类会随季节、产地和渠道变化，建议以佳农官方渠道、销售经理或当季报价单为准。

关于你提到的采购：

**1. 进口嘎啦（Gala）**
佳农进口嘎啦常见产地通常包括：
- **新西兰**
- **美国**
- **智利**
- **南非**
- 部分时段也可能有 **法国、意大利** 等欧洲产地

其中，新西兰嘎啦在中国进口市场认可度较高；智利、南非多用于南半球反季节供应。

**2. 进口红富士（Fuji）**
佳农进口红富士常见产地通常包括：
- **美国**
- **新西兰**
- **智利**
- **日本**（但日本苹果对华出口量较少，商业采购中不如美国、新西兰常见）
- 部分时段可能有 **韩国、澳大利亚** 等

如果你们要做稳定采购，实际更常见的是：
- **美国红富士**
- **新西兰红富士/嘎啦**
- **智利红富士/嘎啦**（反季节）

**采购建议：**
- 直接向佳农索要 **当季可供苹果品类表 + 产地 + 规格 + 包装 + 到港/到仓时间**。
- 明确你们要的是 **进口原箱** 还是 **佳农贴牌/分装**。
- 嘎啦和红富士的产地不能只按品牌判断，必须按 **批次和报关单** 确认。
- 若你们要长期采购，建议同时问：**新西兰、美国、智利三个产季的切换时间**，这样能保证全年供应。

简单说：**佳农苹果品类以嘎啦、红富士及部分高端品种为主；进口嘎啦常见新西兰、美国、智利、南非；进口红富士常见美国、新西兰、智利。具体产地要以当季批次和佳农官方报价为准。**
