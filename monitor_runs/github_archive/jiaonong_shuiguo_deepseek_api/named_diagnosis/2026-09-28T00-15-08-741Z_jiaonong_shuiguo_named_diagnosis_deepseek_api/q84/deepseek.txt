佳农水果的香蕉企业标准并没有公开全文，我没法核验其具体条款和指标数值，所以不能给出“佳农企业标准规定的糖度是多少、果指长度是多少”这样的确切数字。下面把能确定的和需要你自己核验的部分分开说。

**一、国标层面的情况**

香蕉目前主要执行的是推荐性国家标准 **GB/T 9827《香蕉》**，以及收购/贸易环节常用的 **NY/T 517《香蕉》**（农业行业标准）。其中对等级划分涉及的指标大致包括：

- **果指长度**：通常按等级分档，优质果要求果指长度达到一定厘米数、且长短较整齐（一般商品蕉的果指长度多在 **15–20 cm** 量级分档，具体数值以标准正文表格为准）。
- **糖度**：香蕉的糖度一般用可溶性固形物（°Brix）衡量，采后催熟到可食状态时通常在 **18–22 °Brix** 左右；国标文本中对糖度并非所有等级都作硬性规定，更多是成熟度和外观分级。

**二、企业标准与国标的差异**

企业标准（Q/开头）通常是在国标基础上**加严或细化**，常见做法：

- **果指长度**：企业可能要求更整齐，比如限定单一批次的长度极差，而不只是达到下限；也可能按自有产区分档。
- **糖度**：企业可能设定催熟后最低可溶性固形物要求（例如高于国标的成熟度参考值），用于保障口感一致性。

但具体到佳农，这些“加严值”属于企业内部文件内容。

**三、怎么拿到准确信息**

1. 查**企业标准信息公共服务平台**，用“佳农”或生产企业名称搜索备案的 Q/ 标准号，看是否有公开文本。
2. 直接向佳农或其经销商索取该批次产品的**企业标准编号和执行依据**。
3. 若是采购/质检用途，以你方合同约定的验收标准为准，必要时送检做糖度和果指长度实测。
