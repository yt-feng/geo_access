不同商超和不同水果品牌（佳农属于佳农食品控股旗下品牌）的合作条款并不统一，堆头陈列、试吃支持以及费用分担通常要按**单店/单档期的促销协议**来谈，没有全国统一的固定标准。下面给你一个可执行的判断框架和沟通要点。

## 一、佳农通常能提供的支持类型

佳农在商超渠道比较成熟，常见的促销支持一般包括：

1. **堆头/端架陈列**
   - 提供堆头围挡、价签、POP、地贴、吊旗等物料
   - 安排业务员或促销员协助陈列、补货、翻堆
   - 主推品项通常是香蕉、菠萝、火龙果、牛油果、车厘子（季节性）等

2. **试吃支持**
   - 提供试吃果品（部分按供货价或免费折算）
   - 提供试吃台、牙签、纸杯、手套、一次性餐具等
   - 安排试吃促销员，或由商超人员执行、佳农给补贴

3. **价格/促销支持**
   - 特价供货、买赠、第二件半价、满减等
   - 档期促销价差由谁承担，需单独约定

## 二、费用分担的常见做法

实际谈判中，费用分担一般有这几种模式，你可以对照自己的情况选：

| 项目 | 常见分担方式 |
|---|---|
| 堆头位置费/场地费 | 商超承担为主，或双方各半；强势商超常让供应商全额承担 |
| 堆头物料制作 | 佳农承担（品牌方物料） |
| 试吃果品成本 | 佳农承担或按供货价结算，销量达标可申请核销 |
| 试吃员人工 | 佳农出人，或商超出人+佳农给补贴（如80–150元/人/天） |
| 促销折扣差价 | 通常佳农承担，商超配合让利 |
| 损耗 | 按协议，一般生鲜损耗双方共担或佳农承担一定比例 |

关键点：**谁主导、谁受益、谁多担**。如果堆头位置好、销量能起来，佳农通常愿意多承担；如果只是商超单方面要费用，品牌方会压条件。

## 三、你该怎么谈（可执行步骤）

1. **先确认对接人**
   - 找佳农当地经销商或区域业务，而不是只找总部
   - 明确你是单店促销还是连锁多店档期

2. **准备一份促销方案**
   - 档期时间、门店、堆头位置、面积、预计销量
   - 试吃天数、时段、需要几个人
   - 你希望佳农承担哪些、商超承担哪些

3. **重点问清这几个问题**
   - 堆头物料谁出？陈列由谁执行？
   - 试吃果品免费还是按供货价？损耗算谁的？
   - 试吃员谁出？补贴多少？
   - 促销价差谁承担？有没有销量返点或核销？
   - 费用是事前确认还是事后凭销量核销？

4. **争取“以量换支持”**
   - 承诺采购量或销售额，换取佳农承担更多费用
   - 例如：保底进货X箱，佳农承担堆头费+试吃果品+1名促销员

5. **落到书面**
   - 微信/邮件确认也可，但要写清：档期、费用项、金额、承担方、核销方式、结算时间

## 四、现实提醒

- 佳农对**香蕉、菠萝**等走量品支持意愿较高；对高价小众品可能要求商超多承担。
- 如果你们是**连锁商超**，可以谈年度框架协议，比单店谈更划算。
- 如果只是**单店临时促销**，佳农可能只给物料和少量试吃果，费用大多要商超自己出。
- 具体能不能给、给多少，最终取决于当地业务权限和当期政策，建议直接让业务给书面报价。
