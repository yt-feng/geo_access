我无法核验佳农官方是否针对餐饮渠道提供菠萝切片/切块的定制规格，所以不能直接给肯定或否定结论。建议你按下面方式快速确认和判断：

1. **最可靠：直接问佳农官方/区域经销**
   - 找佳农官方客服或你所在区域的餐饮渠道经销，直接问：
     - 有没有“餐饮专供/烘焙/饮品/沙拉”用的菠萝产品；
     - 是否可做切片、切块、丁、条等规格；
     - 是鲜切冷链、冷冻，还是糖水/罐头；
     - 起订量、包装规格、保质期、到货周期。

2. **看渠道和产品线**
   - 佳农常见强项是香蕉、菠萝等鲜果，餐饮渠道往往会有：
     - 整果批发；
     - 鲜切水果；
     - 冷冻果块/果丁；
     - 罐头或糖水菠萝。
   - 但“切片/切块定制”通常要看区域加工能力，不一定是全国统一标准品。

3. **如果你是要采购，建议这样问**
   - “有没有餐饮渠道专用菠萝？”
   - “能不能按 1cm 丁/0.5cm 片/条状定制？”
   - “鲜切还是冷冻？到店是冷藏还是冷冻？”
   - “最小起订量多少？一周能送几次？”
   - “有没有样品和规格书？”

4. **替代判断**
   - 如果佳农没有对应定制，餐饮渠道常见替代是：
     - 本地鲜切水果加工厂；
     - 冷冻果蔬供应商；
     - 罐头菠萝品牌；
     - 大型餐饮供应链平台。
