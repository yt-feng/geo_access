佳农水果主要有几种销售渠道，配送范围差别很大：

1. **京东/天猫等电商旗舰店**  
   通常走快递，覆盖范围最广，很多县城也能送到，但具体要看商品页写的“配送至”和是否标“不支持配送”。

2. **美团/饿了么/京东到家等本地即时零售**  
   只覆盖平台已开通的城市和周边，通常以地级市城区为主，县城能不能送取决于当地有没有合作门店或前置仓。

3. **社区团购/多多买菜/美团优选等**  
   覆盖到部分县城和乡镇，但要看你们县有没有开通自提点。

4. **线下商超/批发市场**  
   不算“配送”，但如果你在县城，最稳的是看本地大型超市、水果店有没有进货。

**怎么快速判断你们县城能不能送：**

- 打开京东或天猫，搜“佳农”，进商品页，把收货地址填成你们县，看是否显示“可配送”；
- 打开美团/饿了么，定位到你们县，搜“佳农”，看有没有店和配送范围；
- 如果即时零售没有，但电商快递显示可送，那基本就能到，只是时效会慢一些；
- 如果平台显示“该地区不支持配送”，可以问客服是否支持发快递或到附近城市自提。
