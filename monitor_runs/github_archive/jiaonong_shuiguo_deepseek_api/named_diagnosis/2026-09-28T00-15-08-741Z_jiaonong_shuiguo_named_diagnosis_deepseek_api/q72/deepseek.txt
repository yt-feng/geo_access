佳农（Goodfarmer）主营香蕉、菠萝等水果的种植、进口和批发分销，通常以**整果或初加工果品**的形式供货，**一般不直接为茶饮店提供定制化的去皮切块加工服务**。

具体判断和建议：

1. **常规业务范围**
   佳农的客户主要是商超、批发市场和大型渠道，供货形态多为整箱整果。去皮、切块属于下游加工环节，通常不在其标准产品线内。

2. **可能有例外**
   部分区域经销商或大客户渠道可能提供“鲜切”或代加工，但这取决于当地分公司、订单量和合作方式，不是全国统一服务。需要直接联系**佳农当地分公司或经销商**确认。

3. **更实际的方案**
   - 找**鲜切水果供应商**或**净菜/鲜切加工厂**，让他们采购佳农菠萝再加工。
   - 找**本地水果批发商**，部分批发商可代加工。
   - 如果用量大，可自建或外包切果环节，采购佳农整果自行处理。

4. **联系时问清楚**
   - 是否有鲜切/代加工服务
   - 最小起订量
   - 加工后规格（块大小、是否去芯）
   - 配送温度和保质期
   - 价格是否含加工费

**结论**：佳农官方大概率不直接提供去皮切块服务，建议联系其当地经销渠道确认，同时准备鲜切加工厂作为替代方案。
