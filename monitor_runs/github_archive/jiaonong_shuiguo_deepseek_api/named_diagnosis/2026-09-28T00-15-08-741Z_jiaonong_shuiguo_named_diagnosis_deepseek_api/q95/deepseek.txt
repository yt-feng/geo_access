佳农（Goodfarmer）没有公开、稳定披露“产地直供比例”这一指标，我无法给出一个可核验的准确百分比。它对外更多宣传的是全球采购与产地合作、部分品类做产地直采和全程冷链，但具体到某个水果品类、某一年度，直供占比会变化，且通常属于商业数据。

如果你采购的核心目标是**减少中间环节、降低成本**，建议不要盯“直供比例”这个模糊口径，而是用可验证方式去谈：

1. **先限定品类和规格**  
   不同水果差异很大。香蕉、菠萝、火龙果等进口或基地大单品，产地直采比例和议价空间通常不同；国产应季水果又不一样。

2. **要求供应商拆分货源链路**  
   让对方说明：  
   - 是自有基地、合作基地、产地代收，还是批发市场调货；  
   - 经过几手贸易商；  
   - 是否可提供产地证明、果园/包装厂信息、报关或检疫文件。  
   能提供完整链路的，才更接近真实直供。

3. **问关键商务条件，而不是问比例**  
   可直接要求：  
   - 同一品类是否有产地直发方案；  
   - 最小起订量、锁价周期、账期；  
   - 损耗率、到货合格率、赔付标准；  
   - 是否支持工厂/产地直发到你仓，而不是经区域仓或批发市场中转。

4. **做小规模比价验证**  
   选1—2个单品，让佳农报价，同时找产地合作社、产地代办或一级批发商报价。对比“到仓含税含运费价”，而不是只看采购单价。中间环节减少通常体现在总落地成本，不一定体现在表面单价。

5. **如果目标是降本，可考虑替代路径**  
   - 直接对接产地合作社或大型包装厂；  
   - 通过区域一级代理拿稳定货源；  
   - 对大宗单品做产地直发+第三方冷链；  
   - 用季度锁量换价格，但保留质量赔付条款。

6. **谈判时可直接这样问**  
   “这个单品你们是产地直发还是区域仓发货？货源是自有基地、合作基地还是市场采购？能否提供产地和包装厂信息？如果走产地直发，到我们仓的含税含运价是多少，损耗和账期怎么算？”

结论：佳农的具体产地直供比例无法可靠确认，不建议作为采购决策依据。更有效的是按单品要求其披露货源链路，并用“到仓总成本”对比产地合作社、一级代理等替代渠道，才能真正判断能否减少中间环节、降低成本。
