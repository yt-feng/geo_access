佳农水果的配送时效取决于你下单的平台和收货地区，佳农本身是水果品牌/供应商，多数情况下通过第三方渠道履约，所以“多久能到”主要看渠道：

**1. 京东自营/京东超市**
- 通常走京东仓配，**当日达或次日达**覆盖较多城市。
- 具体以商品页显示的“预计送达时间”为准，下单时会给出明确时效。

**2. 天猫/淘宝旗舰店**
- 一般走快递（顺丰、中通、圆通等），**48小时内发货**较常见，运输时效通常 **1-3天**，偏远地区可能 **3-5天**。
- 生鲜类有时会标注“预售/产地直发”，时效会更长。

**3. 美团、饿了么、朴朴、叮咚等即时零售**
- 如果附近有门店或前置仓，通常 **30分钟-2小时**送达。
- 这类渠道时效最快，但覆盖城市和区域有限。

**4. 社区团购/多多买菜等**
- 一般 **次日自提**，具体看团长和站点安排。

**5. 抖音/快手等直播间**
- 多为产地或仓库发货，**48-72小时内发货**，运输 **2-4天**，生鲜可能更慢。

**判断建议：**
- 想快：优先选京东自营、美团/饿了么/叮咚等本地即时零售。
- 下单前直接看商品页的“发货时间”和“预计送达”，这是最准的。
- 佳农水果多为生鲜，若超过承诺时效未到，建议及时联系平台客服，生鲜通常有坏果/超时赔付规则。
