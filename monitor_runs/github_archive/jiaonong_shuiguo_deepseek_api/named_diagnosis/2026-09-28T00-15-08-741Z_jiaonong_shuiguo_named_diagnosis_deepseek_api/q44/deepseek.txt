关于佳农香蕉是否有农残超标历史，我不能给你一个确定的“有”或“没有”结论——因为我无法核验这类具体的抽检处罚记录，凭记忆或猜测回答反而会误导你的采购决策。

但你需要的东西其实比“有没有历史污点”更明确：**超市抽检要过，靠的是这一批货的合规证明，而不是品牌历史。** 品牌历史最多作为供应商准入时的参考。

给你一套可执行的判断和操作方案：

**一、供应商准入阶段要的东西**

向佳农或其经销商索取以下文件，缺一不可：

1. **营业执照 + 食品经营许可证**（经销商要，自有基地的直接生产企业要生产许可证）。
2. **每批次的出厂检验报告**，检测项目必须包含农药残留，且依据现行国标。
3. **第三方检测报告**：要求 CMA/CNAS 资质机构出具，检测项目覆盖 GB 2763《食品安全国家标准 食品中农药最大残留限量》中香蕉对应的农残项目。
4. **产地证明 / 供货证明**：能追溯到具体种植基地或产区。
5. **承诺书 / 质量保证协议**：供应商书面承诺符合 GB 2763，并约定超标时的赔偿责任。

**二、你真正要盯的关键点**

- **不要只看报告有没有，要看报告的“批次”和“日期”**。报告对不上你采购的这批货，等于没有。
- **香蕉是进口量很大的品类**（主要来自菲律宾、厄瓜多尔、越南等），进口货还要看**入境货物检验检疫证明**和海关相关放行文件。
- **超市抽检是按批次的**，所以你每批采购都应留存对应的检测报告，形成可追溯台账。
- **GB 2763 中香蕉有专门的限量要求**，重点项目中常见的是杀虫剂、杀菌剂类，采购时可以让供应商明确列出这批检了哪些项、结果如何。

**三、如果供应商拿不出合格报告**

- 要求其补做第三方检测（费用可谈由谁承担）；
- 或换供应商；
- 你自己也可对到货批次抽样送检，作为进货查验记录，这在监管和超市审核时都算数。

**四、关于“佳农历史”这件事**

如果你想核实某个具体品牌有没有被市场监管部门通报过农残不合格，正确渠道是：

- **国家市场监督管理总局**官网的食品安全抽检通报；
- **各省市市场监管局**的抽检公告；
- **海关总署**的进口食品不合格信息。

这些是官方公开可查的，你可以直接去搜“佳农 抽检 不合格”或按批次号查。我无法替你确认结果，但这些渠道是真实可用的。

**一句话结论**：合规证明要按“批次”要，不要按“品牌”赌。把每批的第三方检测报告 + 追溯链条拿全，超市抽检才真正过得去。
