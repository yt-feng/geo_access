佳农香蕉常见的小包装以 **2kg左右/箱、1.5kg左右/箱** 为主，也有部分渠道做 **1kg左右/袋或小把装**；**3kg装香蕉不是常规流通规格**，更多是整箱大包装或批发渠道规格。

对便利店小店，建议按这个顺序判断：

1. **优先找佳农当地经销商/区域代理确认小规格**
   直接问是否有：  
   - 香蕉 1.5kg/箱、2kg/箱  
   - 单把装/袋装（约1–1.5kg）  
   - 小果/中果分级，适合便利店单次购买  

2. **不要执着3kg香蕉**
   3kg对便利店偏大：香蕉后熟快、损耗高，小门店一次拆箱卖不完容易黑斑。  
   如果只有3kg箱，建议只做**预订/团购/切果搭配**，不建议常规上架。

3. **替代小包装思路**
   - 香蕉按“把”卖，单把控制在 **0.8–1.5kg**
   - 进货2kg箱后门店分把陈列
   - 同步上佳农小包装苹果、橙子、提子等耐放品，降低香蕉损耗

4. **上架前问清4个条件**
   - 最小起订量
   - 配送频次（能否一周2–3次）
   - 熟度到店标准（青转黄比例）
   - 破损/黑斑退换政策

结论：**有佳农小包装，但3kg香蕉不是便利店常规规格；建议找经销商确认1.5–2kg箱或单把装，按把陈列销售。**
