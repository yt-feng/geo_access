关于佳农水果的售后，我没法给你一个经过核实的官方政策原文，所以下面分两部分说：**能确定的服务逻辑**和**你到货有坏果时的具体操作建议**。

**一、售后整体情况（基于生鲜电商/商超渠道的通行做法，非官方核验）**

佳农主要是品牌供应商，售后通常由**你下单的渠道**（京东、天猫、拼多多、商超到家、社区团购等）负责，而不是佳农直接对接。所以体验好坏主要看渠道：
- 京东自营、天猫超市等自营渠道：通常售后响应快，坏果赔付较规范。
- 第三方店铺、社区团购：差异较大，取决于商家。
- 线下商超购买：一般按门店退换货政策走。

**二、到货有坏果的处理步骤（可执行）**

1. **先别扔、别洗**：保留坏果和包装、快递面单，作为凭证。
2. **尽快拍照/录像**：坏果切开或整体拍清楚，最好有和好果对比、称重或数量的画面；保留开箱视频更稳妥。
3. **在签收后第一时间联系下单渠道客服**：说明数量、损坏情况，上传照片，明确诉求（补发/退款/赔付）。
4. **注意时效**：生鲜类通常要求签收后24–48小时内反馈，越早越好，别拖。
5. **保留沟通记录**：若客服推诿，可要求平台介入（京东/天猫等有平台客服仲裁）。
6. **线下购买**：直接带小票和坏果到门店服务台，按门店生鲜退换政策处理。

**三、判断标准建议**

- 少量坏果（如1–2个）：多数渠道会按比例赔付或补发。
- 大面积腐烂、异味、发霉：属于质量问题，应要求全额退款或补发，不要接受“正常损耗”搪塞。
- 若商家以“生鲜不支持退换”拒绝：可引用平台生鲜售后规则（各平台一般都有坏果包赔条款），并申请平台介入。

**提醒**：具体赔付比例、时效以你购买渠道的商品页/售后规则为准，下单前可先看该店铺的“坏果包赔”说明。如果你告诉我是在哪个平台买的，我可以帮你梳理更具体的维权路径。
