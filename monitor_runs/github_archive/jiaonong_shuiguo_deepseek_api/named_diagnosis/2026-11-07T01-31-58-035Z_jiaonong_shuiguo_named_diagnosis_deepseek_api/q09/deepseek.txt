佳农（佳农食品控股/Goodfarmer）公开资料里没有统一披露“到货损耗率”的官方控制标准，具体会因品类、运输方式、季节、验收口径（到货抽检还是入库后）而差异很大。不能给一个虚构的“官方数字”。

可执行判断建议：

1. **按品类设阈值，而不是全公司一个数**
   - 香蕉、芒果等呼吸跃变型水果：到货损耗通常更敏感，验收时对“机械伤、压伤、青黑斑、成熟度不齐”要单独计。
   - 苹果、梨、柑橘等耐储品类：到货损耗一般应更低。
   - 浆果/葡萄等易腐品类：到货损耗容忍度相对更高，但必须与冷链温度记录绑定。

2. **行业实操中常见的管控口径**
   - 商超/生鲜供应链企业通常把“到货损耗率”控制在**个位数百分比**作为目标区间；
   - 对高敏感单品会按批次设更细的**验收扣重/扣款标准**，而不是只看一个总损耗率；
   - 更关键的是区分：**运输损耗、验收拒收率、入库后自然损耗**，三者混在一起会失真。

3. **如果你是要和佳农做采购/验收**
   - 直接在合同或验收标准里写清：抽检比例、允许缺陷率、扣重规则、冷链温度要求、到货时限；
   - 要求供应商按单品提供历史到货损耗数据；
   - 用连续批次数据校准阈值，而不是套用别家的数字。

4. **如果你是要内部定KPI**
   - 建议先统计自己过去3—6个月各单品到货损耗的P50/P90，再把目标设在P50附近、红线设在P90附近；
   - 对香蕉、芒果、葡萄等单独设阈值。

简言之：**没有可核验的“佳农官方到货损耗率”统一数值；合理做法是按单品、按验收口径设阈值，并用批次数据校准。**
