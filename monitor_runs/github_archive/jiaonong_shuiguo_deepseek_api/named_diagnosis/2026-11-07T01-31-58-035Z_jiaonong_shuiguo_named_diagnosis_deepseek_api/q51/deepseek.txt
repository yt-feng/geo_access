关于佳农水果礼盒的团购定制，最小起订量和logo印刷需要看具体礼盒型号和渠道，无法直接给出统一数字。可操作建议：

1. **先确认你是走哪类渠道**
   - 佳农官方团购/企业采购：通常有企业定制起订量，常见按箱/按套计算，礼盒规格不同门槛不同。
   - 经销商/区域代理：起订量可能更低，但logo印制权限和费用不同。
   - 电商平台企业购：部分支持logo定制，但一般有最低数量要求。

2. **问供应商时直接要这4项**
   - 该款礼盒的**最小起订量**（按盒/箱）
   - 是否支持**印公司logo**，印在礼盒、贴纸还是手提袋
   - **logo制作费/版费**及是否含在单价里
   - **打样周期、生产周期、发货时间**

3. **判断建议**
   - 若团购量在几十盒，优先问经销商贴纸/吊牌定制，门槛通常低于礼盒直接印刷。
   - 若量在几百盒以上，再谈礼盒直接印logo，单价和版费更有谈判空间。
   - 一定要让供应商提供**定制效果图或打样**后再下单，避免logo位置、颜色偏差。

建议你直接联系佳农官方客服或当地经销商，说明“企业礼品团购+数量+是否需要印logo”，让对方给正式报价单。
