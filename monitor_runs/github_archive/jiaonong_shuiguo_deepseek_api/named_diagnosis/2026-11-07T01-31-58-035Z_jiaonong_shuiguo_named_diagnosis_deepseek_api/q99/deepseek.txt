我无法核验佳农水果菠萝是否持有有效有机认证，不能给你确定的“有/没有”结论。对高端渠道，建议按可执行方式核实并要求证据：

1. **看包装有机标识与有机码**：中国有机产品应有“中国有机产品”认证标志、认证机构名称、有机码；可在中国食品农产品认证信息系统按有机码/企业名查询证书状态、覆盖产品和有效期。
2. **向佳农官方索取证书**：要求提供对应菠萝品项、种植/加工场所、证书编号、有效期、认证机构、认证范围（是否覆盖“菠萝/鲜菠萝”）的证书扫描件；仅品牌宣称不算。
3. **核对证书与批次一致性**：确认证书主体是生产/加工企业，产品范围含菠萝，且供货批次在证书有效期内；如为贸易商供货，要求提供上游证书及购销链。
4. **合同条款**：写明“有机认证有效、证书随货、批批可追溯、抽检不合格责任”，并约定违约与召回责任。
5. **到货验收**：查有机码、包装标识、证书复印件/电子证照，必要时送检农残并留存批次证据。

如果佳农无法提供覆盖菠萝的有效有机证书，就不能按有机产品进入高端有机渠道；可要求其提供常规产品并明确非有机，或另行寻找有证供应商。
