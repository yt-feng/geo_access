佳农香蕉属于鲜果，保质期受成熟度、温度、包装和是否已切开影响很大，无法给出一个固定天数。可按下面判断和操作：

**储存条件**
- **未熟/偏青香蕉**：放在室温阴凉通风处，约 **18–22℃** 为宜，避免阳光直射和暖气旁。不要先放冰箱，低温会抑制成熟并导致表皮变黑。
- **已熟香蕉**：室温尽快吃；想延缓后熟，可放阴凉处，或成熟后短期放入冰箱冷藏。冷藏后表皮变黑是冷害/氧化表现，果肉若仍正常可尽快食用。
- **已切开香蕉**：密封冷藏，建议 **24小时内** 吃完；出现明显变软、发酸、渗液或霉点则丢弃。
- **不要与苹果、梨等释放乙烯较多的水果紧密混放**，会加速成熟。

**保质期判断**
- 偏青香蕉室温下通常可放 **数天到一周左右** 逐步转黄，具体看采摘成熟度。
- 已全黄、无磕碰的香蕉，室温通常 **2–4天内** 风味较好；夏季高温会更快。
- 表皮少量黑点通常代表成熟，不一定坏；但若**大面积发黑、果肉软烂、有酒味/酸味、霉变或渗液**，不要食用。

**实用建议**
买回后保留果柄、不要清洗表皮；成串香蕉可分开或包裹果柄减少乙烯影响；按“先熟先吃”排序。若包装上有具体储存说明或保质期，以包装标注为准。
