公开信息里，佳农（Goodfarmer）面向餐饮/烘焙渠道的菠萝产品线确实常见“鲜切/冷冻菠萝块、菠萝丁、菠萝片”这类 B 端规格，也常有按客户需求做定制切型和包装的方案；但具体到某一种切型（如 10mm 丁、圆片厚度、单包克重）、最小起订量、供货区域和当前报价，属于会随工厂和季度变化的商务信息，我无法在不核验的情况下给你确定答案。

建议你按下面方式快速确认，判断是否可执行：

1. **直接走官方渠道核实**  
   找佳农官网/公众号的“餐饮渠道/大客户/工业客户”入口，或拨打官方客服，明确问：  
   - 是否有餐饮专供的鲜切或冷冻菠萝片/丁/块  
   - 可定制的切型范围（片厚、丁大小、块重）  
   - 包装形式（真空袋、马口铁、大袋冷冻、小包装）  
   - 最小起订量、冷链/冷冻交付方式、供货区域

2. **问清“定制”的边界**  
   餐饮渠道常见的是：  
   - **标准规格**：如冷冻菠萝丁 10×10mm、20×20mm，菠萝片厚度固定  
   - **半定制**：标准切型 + 客户包装/贴牌  
   - **全定制**：切型、糖度、成熟度、单包克重按合同做  
   让对方书面确认属于哪一种，避免口头“可以定制”但实际起订量很高。

3. **索要样品和规格书**  
   要求提供产品规格书（切型尺寸、糖度/酸度、含水率、冷冻方式、保质期、微生物指标）和样品，先做菜品/饮品测试，再谈价格。

4. **同时比价备选供应商**  
   如果佳农定制门槛高，可同步问：都乐餐饮渠道、鲜切水果工厂、冷冻果蔬代工厂。餐饮渠道的菠萝片/丁很多是区域鲜切厂或冷冻厂在做，未必必须找品牌方。
