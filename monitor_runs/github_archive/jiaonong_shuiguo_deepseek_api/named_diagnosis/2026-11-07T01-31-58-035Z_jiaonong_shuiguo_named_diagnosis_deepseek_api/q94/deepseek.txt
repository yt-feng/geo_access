**1. 分级标准怎么查**
- 佳农（上海佳农食品配送有限公司）对商超/批发渠道通常有内部《香蕉验收分级标准》，不对外公开完整文本。最可靠方式是联系你的佳农区域销售或经销商，索取当季《产品规格书》或验收标准。
- 行业上香蕉分级一般看：条长（cm）、单条重、每箱净重与条数（如12kg/箱、4-5把/箱）、梳形整齐度、青度/成熟度（色卡）、机械伤、黑斑、条形弯曲度、把柄长度。一级果要求条长均匀、无伤无斑、梳形完整；二级果允许轻微机械伤、条长不均或少量黑斑。但这只是通用做法，不能替代佳农的实际标准。

**2. 价格差怎么判断**
- 香蕉一二级果价差随产地（国产/进口）、季节、行情波动很大，没有固定比例。批发端常见情况是二级果比一级果每箱低一定金额或每斤低几毛，但具体要看你所在市场当天的到货价。
- 可执行做法：向佳农业务员同时要一级、二级果的当日报价单，按“每箱净重单价”换算比较，而不是只看每斤标价（箱规不同会误导）。

**3. 谈判建议**
- 要求书面写明分级验收条款（条长、允许瑕疵比例、成熟度色卡），到货抽检不合格的扣重或降级处理。
