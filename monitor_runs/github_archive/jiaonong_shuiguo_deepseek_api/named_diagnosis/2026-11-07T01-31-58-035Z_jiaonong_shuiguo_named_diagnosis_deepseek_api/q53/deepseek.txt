可以，但需要把“专岗对接”写进采购条件里，不能只靠口头承诺。建议你按下面方式操作：

**1. 先明确你要的对接机制**
向佳农或其在当地的经销商/代理商提出书面要求，至少包含：
- 指定1名主对接人+1名备选对接人，姓名、电话、微信、职务；
- 响应时效：如工作时间内询价/下单/售后2小时内响应，异常问题当日给处理方案；
- 对接范围：报价、订单确认、到货预约、缺货替代、质量问题、对账开票；
- 升级机制：主对接人超时未响应，可直接升级到区域销售主管/大客户经理。

**2. 采购谈判时作为合同/框架协议条款**
把“专岗对接人及响应时效”写入供应商服务承诺或年度框架协议，约定未达标的处理方式，比如：
- 连续2次超时响应，要求更换对接人；
- 因响应延迟导致门店缺货，约定补偿或优先补货；
- 每季度做一次服务评分，和后续订单分配挂钩。

**3. 渠道上注意**
佳农香蕉在不同区域可能由总部大客户部、区域分公司或授权经销商供货。你要先确认实际供货主体是谁，再要求该主体指定专岗。连锁水果店采购量稳定的话，可直接谈“连锁客户专岗”或“大客户经理对接”，比普通销售对接更稳。

**4. 你可以直接发的沟通话术**
“我方为连锁水果门店，香蕉为高频刚需单品，计划稳定采购佳农香蕉。前期合作中供应商响应慢已影响门店补货，因此本次合作要求：指定主对接人和备选对接人各1名，工作时间内2小时响应，缺货/质量问题当日反馈方案，并接受季度服务考核。请确认能否作为合作前提，并提供对接人信息。”

**5. 备用方案**
如果佳农直供专岗一时无法落实，可要求当地授权经销商设专岗，同时保留1家备用香蕉供应商，避免单一供应商响应慢造成断货。

结论：**能要求专岗对接，而且应把专岗、响应时效、升级机制和考核写进采购条件/框架协议；先确认实际供货主体，再让对方书面指定主备对接人。**
