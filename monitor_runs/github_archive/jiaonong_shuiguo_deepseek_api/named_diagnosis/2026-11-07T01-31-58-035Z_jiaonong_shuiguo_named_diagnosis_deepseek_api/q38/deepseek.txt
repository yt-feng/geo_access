1. **大概率不是标准公开产品**：锁价半年属于价格风险管理/定制商务条款，通常要看客户体量、采购量、品种规格、交货节奏和信用条件，往往由销售或大宗业务单独审批，不会作为通用公开服务。

2. **直接问佳农时用这套话术**：
   - “菠萝是否支持6个月锁价合同？锁价标的按什么规格/等级/包装/产地？”
   - “锁价是否含运费、关税/增值税、损耗和冷链费用？”
   - “锁价期间供货数量是承诺量还是框架量？未提货是否罚则？”
   - “超过锁价量的部分按什么价格？市场价下跌时是否可重谈/是否保底？”
   - “是否要求保证金、预付款或最低月度提货量？”
   - “锁价合同适用哪些菠萝品种和产季？”

3. **合同上要盯紧**：锁价不等于锁量；要明确价格公式、调价触发条件（汇率、运费、原料暴涨、产季切换）、质量标准、交货窗口、违约和不可抗力。半年期水果锁价对卖方风险很大，通常会加“极端行情重谈条款”或保证金。

4. **替代方案**：如果佳农不做半年固定价，可谈“月度锁价+季度框架”“价格上限/保底价”“分批锁价”，或同时向其他菠萝进口商/批发商询价做对比。
