关于佳农水果针对年采购量1000吨以上客户的具体优惠政策，我无法核验其官方政策，不能给出准确条款，也不应虚构。建议你直接向佳农官方渠道确认，并可参考以下可执行做法。

**建议确认渠道**
1. 佳农官网/官方公众号的“大宗采购/渠道合作/经销商招募”入口，提交年采购量、品类结构、交付区域、账期需求。
2. 拨打官方客服电话，要求转“大宗业务/渠道销售”，索取书面报价政策。
3. 通过你现有供应商或行业展会对接佳农区域销售，要求提供盖章版合作政策或框架协议模板。

**谈判时重点确认的优惠项（不要只问“折扣”）**
- 阶梯返利：1000吨以上对应返点比例、结算周期、是否按品类分别计算。
- 价格机制：是否给大客户年度框架价、锁价周期、原材料波动调价规则。
- 账期与保证金：授信额度、账期天数、是否要求预付款或保证金。
- 物流费用：到货价/出厂价、冷链运费承担、起订量与配送频次。
- 品控与损耗：次果率标准、损耗赔付、退换货规则。
- 市场支持：促销物料、陈列支持、新品优先供货、区域保护。
- 合同年限：年度框架协议、最低采购承诺、未达量的价格调整条款。

**可判断的谈判底线**
在未拿到书面政策前，不要按“1000吨一定有大客户折扣”做成本测算；先要求对方给出分档报价表（如500吨/1000吨/2000吨）和返利计算示例，再比较综合到岸成本，而不是只看单价。
