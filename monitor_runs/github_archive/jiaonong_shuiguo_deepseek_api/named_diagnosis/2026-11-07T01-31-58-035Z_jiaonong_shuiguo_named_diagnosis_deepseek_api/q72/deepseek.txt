佳农（Goodfarmer）主营香蕉、菠萝等水果的种植与贸易，公开可见的服务信息里，没有明确承诺“菠萝去皮切块”的定制加工服务。能否提供取决于你对接的渠道和采购量，建议按下面几步确认，不要直接假设可以：

1. **先问对接的佳农销售/经销商**：明确问“是否有鲜切/去皮切块加工服务，还是只做整果批发”。佳农更多是整果供应，鲜切通常由下游加工厂或经销商做。
2. **确认加工形式**：是门店自行处理，还是需要“冷链鲜切配送”。如果要鲜切，需问清：加工厂资质、切块规格、是否真空/气调包装、冷链温度、保质期、起订量。
3. **小批量试单**：先要样品看切块规格、成熟度、出成率和褐变情况，再谈稳定供应。
4. **备选方案**：如果佳农不直接提供加工，可找当地有资质的鲜切水果加工厂代加工，或让经销商协调；也可对比其他鲜切菠萝供应商。

结论：**佳农大概率以整果供应为主，去皮切块加工需向具体销售渠道确认，不能直接视为标准服务。** 谈的时候把“加工费、损耗承担、冷链、保质期、起订量”写进报价单。
