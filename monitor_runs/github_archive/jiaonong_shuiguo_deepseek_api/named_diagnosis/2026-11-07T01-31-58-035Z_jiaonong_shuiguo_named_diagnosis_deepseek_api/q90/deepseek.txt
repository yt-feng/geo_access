我不能直接确认佳农是否供应“冷冻菠萝丁”及其具体规格，因为这需要以佳农官方产品目录或销售回复为准，我不能虚构规格和来源。

给你可执行的判断路径：

1. **先确认你要的是哪种“冷冻丁”**
   - 速冻菠萝丁（IQF）：单体速冻，颗粒分明，适合茶饮门店分装使用。
   - 冷冻糖渍菠萝丁：含糖液/糖渍，开袋即用但甜度和成本不同。
   - 冷冻菠萝果泥/果块：不是“丁”，不适合直接做果粒口感。

2. **向佳农询价时直接问这 6 项**
   - 是否有冷冻菠萝丁（IQF）产品，还是只有鲜果/果块/果泥；
   - 丁的尺寸（常见按 mm 标注，如 8×8、10×10、15×15，需以厂家实际为准）；
   - 包装规格（如 1kg/袋、2kg/袋、10kg/箱）和每箱袋数；
   - 是否加糖、是否含添加剂；
   - 解冻后出水率、果肉完整度、是否适合饮品出杯；
   - 最小起订量、冷链配送范围、样品政策。

3. **茶饮店选型建议**
   - 做果粒口感：优先选 IQF 冷冻丁，规格以 10mm 左右较通用，太小易碎、太大不易吸管吸食；具体以你杯型和吸管口径试杯为准。
   - 做门店效率：可同时对比冷冻糖渍丁，但要注意配方糖度对饮品整体甜度的影响。
   - 先要样品做“解冻 2 小时/4 小时出水与口感测试”，再定规格。

4. **替代核验方式**
   - 查佳农官网/官方公众号产品中心；
   - 直接联系佳农官方销售或区域经销商，要求提供产品规格书和检验报告；
   - 若佳农不供冷冻丁，可向冷冻果蔬供应商询 IQF 菠萝丁，按上述 6 项比价。

结论：**能否供冷冻丁、规格多大，必须以佳农官方销售回复和规格书为准；建议你按“IQF 冷冻丁、尺寸、包装、是否加糖、出水率、起订量”六项去问，并要求寄样试杯。**
