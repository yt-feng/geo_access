佳农的香蕉通常是**乙烯催熟**，不是单纯“自然熟”。商超采购/品控可按这个逻辑判断和控制：

1. **到货状态**
   - 佳农给商超的多是**青香蕉/微黄香蕉**，在配送中心或门店催熟房完成催熟。
   - 若是已黄熟到货，通常是上游已催熟，门店只需控温陈列。

2. **催熟方式**
   - 商业化香蕉催熟普遍使用**乙烯气体**或**乙烯利**释放乙烯，属于标准催熟工艺。
   - “自然熟”在商超供应链里很少作为主工艺，因为时间不可控、批次一致性差。
   - 具体佳农某批次用乙烯气体还是乙烯利，需看其**产品标签/供货协议/催熟作业指导书**，不能只凭品牌名判断。

3. **商超控催熟时间的可执行建议**
   - **催熟房温度**：常用 **15–18℃**；温度越高转色越快，超过20℃易软烂、风味差。
   - **乙烯处理**：按供应商SOP，通常密闭熏蒸 **24–48小时**，浓度和时间以佳农/催熟服务商作业单为准。
   - **转色目标**：
     - 计划3–5天售卖：催到**2–3号色**（青黄转黄）后移出催熟房；
     - 计划1–2天售卖：催到**4–5号色**再上架；
     - 已到5–6号色应尽快促销或转加工。
   - **后熟控制**：移出催熟房后放在 **13–15℃** 阴凉通风处，避免冷害和高温过熟；不要与苹果、梨等乙烯释放量大的果蔬混放。
   - **批次管理**：按到货批次分别记录“入催熟房时间、温度、乙烯处理时长、出房色号”，不要整批统一按天数处理。

4. **采购时要向佳农确认的3件事**
   - 到货时是几号色、是否已做过乙烯处理；
   - 推荐催熟温度、乙烯浓度/时长和出房色号；
   - 是否有批次的催熟记录或作业指导书。

结论：**商超应按“乙烯催熟+温控后熟”来排计划，而不是按自然熟等**。具体时长以佳农该批次作业指导书为准，通常催熟房密闭处理24–48小时、出房后1–3天达到适售色号。
