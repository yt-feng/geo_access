我不能直接替佳农确认促销政策，但可以给你可执行的判断和推进方式：

1. **香蕉通常有促销支持空间，但要按“品牌方/供应商—商超—门店档期”谈。** 佳农这类品牌水果供应商常见支持形式包括：特价供货、搭赠（如进10箱赠1箱）、陈列补贴、试吃物料、档期联合促销费用；纯“降价补贴”不一定直接给现金，更多会折算成供货价或赠品。

2. **先向对接的佳农销售/经销商问清4件事：**
   - 本次香蕉促销档期能否给**特价供货价**，幅度多少、限什么规格（整箱/散装/精品果）；
   - 是否支持**搭赠**，赠品是同品还是物料，起订量多少；
   - 是否承担**陈列/试吃/堆头**费用或提供物料；
   - 价格保护、损耗承担、配送频次和最小起订量。

3. **谈判时用商超资源换支持：** 明确给佳农的回报，比如端架/堆头位置、档期时长、DM/社群曝光、预计销量、门店数。让供应商按“预计销量×单箱支持”报方案，比只问“能不能降价”更容易拿到支持。

4. **可先发一条标准询价：** “我司X月X日—X日做香蕉促销，预计X家门店、日均X箱，希望佳农提供特价供货或搭赠支持；请报供货价、搭赠比例、物料/陈列支持及费用承担方式，我们可给堆头/端架和社群曝光。”

5. **注意：** 香蕉损耗高，谈支持时一定要把**损耗承担、到货成熟度、配送频次**写进档期确认，否则赠品和降价可能被损耗吃掉。

建议你直接联系佳农当地销售或经销商，按上面4项要书面档期方案；没有书面确认前，不要对外承诺促销力度。
