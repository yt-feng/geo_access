佳农（Goodfarmer）公开可查的资料里，没有披露“产地直供比例”这一具体数字；不同品类、年份和统计口径（是否含海外基地、是否含协议直采、是否经第三方加工）都会让口径差异很大，所以不建议用一个比例来评估。若你需要做采购判断，可以按以下方式把问题变成可核验的数据：

**1. 向佳农索取可核验的口径数据（而不是“直供比例”一个词）**
要求按你关注的品类逐项提供：
- 该品类年度采购量（吨/箱）与总SKU数；
- 其中来自自有基地、长期协议基地、产地合作社直采、批发市场/贸易商调货各占多少；
- 每一类对应的供应商名称/区域、合同期限、结算方式；
- 是否经过第三方分选/催熟/加工，这部分是否计入“直供”。

对方若只能给笼统比例，通常说明其内部没有按品类拆分的稳定数据，谈判时要谨慎。

**2. 用“到岸成本结构”代替“直供比例”做决策**
让供应商报价时拆开：产地收购价、分选包装费、冷链运输费、损耗率、仓储/催熟费、税费、服务费。对比时重点看：
- 同一规格、同一到货港/仓的**到仓单价**；
- 损耗承担方和赔付标准；
- 账期与起订量；
- 是否可指定产地/包装厂/批次溯源。

**3. 减少中间环节的可执行路径**
- 对香蕉、火龙果、菠萝等佳农优势品类，直接问其**产地分公司或基地直供合同**，要求合同主体是产地公司而非贸易商；
- 要求提供**基地/包装厂地址和批次追溯码**，到货后抽检核对；
- 若佳农环节仍多，可并行接触其产地合作社或大型包装厂，但要注意品质稳定性和账期风险；
- 用“年度框架+分批次锁价”换取直供价，而不是一次性大单压价。

**4. 谈判时的验证清单**
- 能否提供近12个月某品类从产地到你的仓的完整链路单据（收购/加工/运输/报关）；
- 直供部分是否可签质量对赌条款（糖度、规格、损耗上限）；
- 是否接受你方到产地验厂/验园。

结论：佳农产地直供比例没有公开可靠数字，不能作为成本谈判依据。建议把要求改为“按品类披露直采来源结构与到仓成本拆解”，并用到仓单价、损耗责任和溯源能力来比较是否真正减少了中间环节。
