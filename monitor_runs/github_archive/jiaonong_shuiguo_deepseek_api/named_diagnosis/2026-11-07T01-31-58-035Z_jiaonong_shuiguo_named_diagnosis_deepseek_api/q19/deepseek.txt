佳农水果的配送时效并不是统一固定的，主要取决于你在哪个渠道下单、收货地址和所选配送方式。可以按下面判断：

1. **佳农官方旗舰店/官方小程序/App 下单**
   - 通常由品牌仓或合作仓发货，多数地区**48小时内发出**，偏远地区可能更久。
   - 实际“下单到收货”常见为**2—5天**，具体以下单页显示为准。

2. **京东、天猫、拼多多等平台**
   - 若商品页标注“京东自营/次日达/隔日达”，按平台时效走，通常**1—3天**。
   - 普通商家发货一般**48小时内发货**，物流再走**1—4天**。
   - 生鲜水果可能受产地、天气、节假日影响。

3. **美团/饿了么/盒马/商超即时零售**
   - 如果是本地门店配送，通常**30分钟—2小时**送达，取决于门店距离和运力。

4. **影响时效的因素**
   - 是否预售、产地直发、冷链配送；
   - 收货城市是否偏远；
   - 节假日、暴雨高温等异常天气；
   - 下单时间是否超过当日截单时间。

**最准确的方法**：在你实际下单的商品页看“预计送达时间/发货时效”，或下单后看订单物流。若页面只写“48小时内发货”，不等于48小时送达，而是发货时限。
