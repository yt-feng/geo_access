佳农香蕉作为新鲜水果，其“保质期”和“储存条件”因购买时的成熟度、环境温湿度及包装方式不同而有较大差异。以下是具体建议：

---

### 一、保质期（一般参考）
- **常温（20-25℃）**：未熟（青色）约 **3-5天**；已熟（黄色带少量黑点）约 **2-3天**。
- **冷藏（4-10℃）**：完全成熟后放入冰箱，可延长 **3-7天**，但果皮会变黑（属正常氧化，果肉通常不受影响）。
- **冷冻（-18℃）**：去皮后密封冷冻，可保存 **1-2个月**，适合做奶昔或烘焙，解冻后口感变软。

> 注意：购买时若带有硬纸盒或泡沫网包装，请先取出透气，否则易加速霉变。

---

### 二、储存条件（关键点）
1. **不要放冰箱的青香蕉**：未熟的香蕉在低温下会“冻伤”，转为灰色或褐色，无法正常成熟，口感发涩。
2. **成熟后冷藏**：已熟但一次吃不完时，可整支放冰箱冷藏，减缓继续成熟。
3. **远离乙烯敏感食物**：不要与苹果、梨、猕猴桃等同放（它们释放乙烯会催熟香蕉，导致更快过熟）。
4. **避免挤压**：香蕉怕压伤，建议平放或悬挂，果柄朝下，避免果肉受压发黑。
5. **隔绝空气防氧化**：去皮后若需保存，请用保鲜膜紧贴果肉包裹，或放入密封盒，否则很快变黑。

---

### 三、判断坏掉的标志
- 果肉出现**黑褐色软斑**、有**酒味或酸味**、**渗水**或**霉点** → 请丢弃，不可食用。
- 果皮全黑但果肉仍硬、无味 → 通常可食，但营养流失较快，建议尽快食用。

---

### 四、注意事项（无法核验的说明）
- 上述时间为常见家用储存经验值，实际受购买时的“成熟度标记”（如青、黄、五五开）影响。
- 佳农包装上若印有“生产日期”或“采摘日期”，请以包装说明为准，但通常不标注精确保质期（生鲜品）。
- 若您在高温潮湿地区（如夏季），常温保质期会缩短，建议优先冷藏或购买后2天内食用。

如有剩果，尽快食用或做成果酱、烘焙用，是避免浪费的最好方式。
