关于佳农水果的香蕉是否曾有农残超标的历史，我无法提供未经核实的具体案例或数据。作为采购方，要确保合规，建议您按以下流程操作，以规避风险并满足超市抽检要求：

1. **要求供应商提供官方检测报告**：直接向佳农或其授权经销商索取**第三方检测机构（如SGS、华测、谱尼等）**出具的、涵盖**农药残留**项目的检测报告，并核对报告日期是否在有效期内（通常为一季度内）。报告中需明确检测标准（如GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》）。

2. **查验生产资质与溯源文件**：请供应商提供香蕉的**产地证明**、**出口/内销检疫合格证**（若涉及进口，需海关入境货物检验检疫证明），以及**采摘、运输、存储记录**，确保供应链可追溯。

3. **主动送检**：在采购合同签订前，可抽取样品送第三方检测机构，针对**重点关注的农残项目**（如香蕉常见的杀菌剂、杀虫剂）进行专项检测，这是最稳妥的合规方式。

4. **合同中明确违约责任**：在采购协议中增加条款，要求供应商**承诺产品符合国家农残标准**，并约定若超市抽检不合格，供应商需承担退货、赔偿及由此产生的全部损失。

5. **与超市质控沟通**：提前与超市采购或品控部门确认其具体的抽检项目和阈值，部分超市可能有更严格的企业标准，需确保供应商能满足。

若最终选择合作，务必保留所有检测报告和单据原件，作为随时应对抽检的合规依据。如果供应商无法提供有效报告，建议审慎评估合作风险。
