关于佳农水果的产品线，我可以给你一个明确的参考：

**佳农水果**主要经营进口水果和部分国产高端水果，其苹果品类中确实有**红富士**，但需要说明的是：

1. **红富士**是佳农常见的苹果品种之一，通常来自国内优质产区（如山东、陕西等），也有进口货源（如智利、新西兰等），但**不一定每个批次都有**。

2. **新疆阿克苏苹果**（特别是“冰糖心”红富士）是国产高端苹果的代表，**佳农目前没有稳定的新疆阿克苏苹果供应**。佳农的核心优势在进口水果（如香蕉、菠萝、牛油果等），国产苹果并非其主打品类。
