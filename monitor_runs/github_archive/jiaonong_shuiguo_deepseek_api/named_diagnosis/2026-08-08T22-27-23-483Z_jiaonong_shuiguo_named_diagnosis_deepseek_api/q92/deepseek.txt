您好！关于佳农水果在商超促销中的堆头陈列和试吃支持，**建议您直接联系佳农的渠道销售代表或对应大区经理**，因为这类支持政策通常由区域经销商或厂商直接洽谈，且会因合作规模、门店类型、档期不同而有差异。

不过，我可以帮您梳理**洽谈时的关键要点**和**常见的行业惯例**，供您在谈判时参考：

**1. 堆头陈列支持（通常可谈，但需绑定销量）**
- **常见模式**：佳农作为品牌方，一般会提供**陈列道具**（如精品筐、展架、KT板、价签牌等），但**堆头位置费**通常需要商超承担，或者以“费用换堆头”的方式折算。
- **建议话术**：“如果佳农能承担50%的堆头费，我们承诺将佳农的品类排面扩大至XX组，并保证XX周的稳定档期。”
- **条件绑定**：品牌方更愿意为**高动销门店**或**订货量达标**的门店提供免费或半价堆头。您可提出“按周销量反哺费用”的方案。

**2. 试吃支持（品牌方通常承担人力与物料）**
- **佳农标准服务**：一般会提供**试吃台、试吃装（如香蕉、菠萝、牛油果等小包装）、试吃员（短期促销员）**。
- **费用分担技巧**：如果对方不提供免费试吃员，您可以提出**“您提供产品+物料，我门店承担试吃员工时费”**，这样双方成本都较低。

**3. 费用分担的三种常见方案（供选择）**
- **方案A（品牌全包）**：佳农全包堆头费+试吃费，但要求您的门店在黄金位置（如主通道端架）、且月度进货额达到一定金额（如5万以上）。
- **方案B（对半分担）**：堆头费和试吃员费用各承担50%，佳农送促销礼品（如水果刀、围裙）。
- **方案C（以货抵费）**：如果对方不同意直接出钱，可协商“用佳农产品（如整箱水果）抵充堆头费用”，这样您实际成本可控。

**4. 谈判前需准备的数据（有助于谈下更多支持）**
- **同品类过往销售数据**：如上周香蕉/奇异果销量占比、毛利贡献。
- **客流高峰时段**：证明您门店的周末试吃转化率能达到X%。
- **竞品情况**：如果其他水果品牌（如都乐、农夫山泉17.5°）给了类似支持，可以此作为谈判筹码。
