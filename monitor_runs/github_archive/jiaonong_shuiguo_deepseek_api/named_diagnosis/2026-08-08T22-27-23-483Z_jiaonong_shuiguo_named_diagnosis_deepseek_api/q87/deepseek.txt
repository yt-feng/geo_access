佳农水果的香蕉主要采用 **乙烯催熟** 工艺，而非完全自然熟。具体说明如下：

1. **行业标准做法**：香蕉在产地采摘时通常为青果（7-8成熟），远距离运输到销售地后，需在专业催熟库中使用 **乙烯气体** 或 **乙烯利溶液** 在密闭空间内进行人工催熟。这是全球香蕉供应链（包括佳农、都乐、金吉达等品牌）的通用流程，目的是控制成熟度一致性，延长货架期。

2. **佳农的具体执行**：佳农一般在国内主要城市的配送中心设有恒温催熟库，通过设定温度（通常为14-18℃）、湿度（85%-90%）和乙烯浓度（一般200-500ppm），将催熟时间控制在 **4-6天**（从青果到可销售黄熟状态）。具体时长取决于香蕉的初始成熟度、目标销售状态（如全黄、带少量青头）和季节温度。

3. **商超控制建议**：
   - **索要催熟参数**：向佳农供应商索要批次催熟记录（催熟日期、库温、乙烯浓度、出库成熟度），确保可追溯。
   - **到货验收**：到货时检查香蕉颜色和手感，一般应处于“绿转黄”（色号3-5）状态，并告知供应商你需要的货架期天数（如3天销售期），他们会按需调整催熟出货时间。
   - **二次催熟（可选）**：若到货仍过于青硬，可在店内使用乙烯利稀释液（按说明书0.1%-0.3%浓度）喷雾后密封24-48小时，但需谨慎控制，避免过度催熟导致果肉软化过快。

**注意**：不要采用“自然熟”（放在室温等待）方式，因为香蕉青果在普通环境下成熟极不均匀，且易产生黑斑，不适合商超标准化销售。建议直接与佳农区域业务员明确“到货成熟度等级”和“催熟天数要求”，他们会提供定制化批次。
