**1. 一般账期（行业参考）**

- **商超/连锁客户**：通常为**月结30-60天**（即货到后次月对账，第三个月打款）。
- **批发/分销商**：可能为**现款现货**（先款后货）或**短期账期（7-15天）**，具体看单次订单金额。
- **电商/新零售平台**：通常也要**45-60天**，且可能涉及平台账期占用。

**2. 新客户能否申请？**

- **可以申请，但门槛较高**。新客户通常缺少历史交易记录，佳农风控会严格审核。
- **一般要求**：
  - 提供营业执照、法人身份证、经营流水（或纳税证明）。
  - 首次合作多为**现款现货**或**小额授信**（比如首单5-10万以内）。
  - 部分渠道（如社区团购）可能要求预付款。
- **申请方式**：联系佳农官方销售代表或区域大客户经理，提交资质材料，由其内部风控审批。

**3. 建议操作**

- 若你是**批发商**：优先谈现款后批量给折扣，更容易达成。
- 若你是**商超**：准备好采购合同和财务报表，提出“首单现款，次单起月结30天”的方案，成功率更高。
- **注意**：佳农可能要求客户购买**产品质量保险**或支付**保证金**（约订单金额的5%-10%），作为违约保障。

**提示**：行业账期受市场行情波动影响，例如旺季（如春节前）供货紧张时，账期可能缩短甚至要求预付。建议直接咨询对接业务员，并做好首单小批量试单的准备。
