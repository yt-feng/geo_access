关于“佳农水果”的香蕉规格及分级标准，目前公开渠道（如官网、主流电商平台）并没有一个全网统一、官方明文发布的“分几种规格”的完全列表。不同销售渠道（商超、电商、批发、餐饮）对香蕉的规格要求差异很大，且佳农作为经销商/品牌商，其分级通常遵循行业通行的国家标准或企业采购标准。

以下基于行业通用标准和佳农在市场上的常见操作，为您提供可参考的分级逻辑（注意：这并非佳农官方100%精确的内部文件，但可作判断依据）：

### 1. 按“梳”和“把”的规格（常见于批发/商超）
香蕉通常不以“个”论，而以“梳”（指带有果柄的一小串）或“把”（指一大串）为单位。行业内常用“**梳数/把**”和“**单梳重量**”来区分。

- **大把/整把（批发渠道）**：一箱（约13-14公斤）中通常有3-5“把”。主要供水果店、菜市场、餐饮后厨。
- **中梳（商超精品装）**：一箱中分成6-8梳，每梳约6-8根，单梳重量约800克-1.2公斤。适合超市散装售卖。
- **小梳（电商/礼品装）**：一梳仅4-6根，单梳重量约500克以下，主打按份销售，适合小家庭或线上“份装”。

### 2. 按果实发育阶段（成熟度分级）
这直接决定渠道选择，是佳农内部管理的关键：

- **绿熟期（未催熟）**：香蕉果皮全绿，淀粉含量高，硬度大。**适合长距离运输和批发市场**，由下游拿货后自行催熟或上架。
- **黄熟期（已催熟，按色号区分）**：行业用“色号”表示，佳农及各大品牌通常用1-7号（国际通用），**号越大越黄**：
  - **2-4号（黄绿混合）**：适合超市卖场，货架期长（约3-5天），消费者买回家可放置2-3天。
  - **5-6号（近全黄）**：适合水果店、精品超市即食档口，开箱即卖，货架期短（1-2天）。
  - **7号（全黄带斑点）**：通常用于餐饮连锁做果切或甜品，需当天售完。

### 3. 按果指长度和外观（分级标准）
行业内普遍参考**国家标准《香蕉》（GB/T 32778-2016）**（若佳农自有企业标准，只会更严）。常见等级划分：

- **特级果（精品果）**：
  - 果指长度：**25厘米以上**（中大型果）。
  - 外观：果形直，弯度小，无刷伤、无病斑、无虫眼、无裂口、果皮细腻。
  - 适合渠道：高端超市（如Ole'、盒马）、精品水果店、礼盒装。
- **一级果（标准商品果）**：
  - 果指长度：**20-25厘米**。
  - 外观：允许轻微轻微碰压伤（单个伤斑直径小于0.5厘米）、允许轻微果皮斑点。
  - 适合渠道：普通连锁超市（永辉、大润发等）、电商平台标准件。
- **二级果（经济果）**：
  - 果指长度：**15-20厘米**，或粗细不匀。
  - 外观：允许明显机械伤、允许轻微干疤，但果肉完好。
  - 适合渠道：水果店促销装、水果捞原料、学校/单位食堂。

### 4. 按品牌营销分级（电商常见）
在佳农的天猫、京东旗舰店，您会看到以下命名，这对应了销售端的“规格”：

- **“佳农云南高山蕉”**：主打单果重量在180-250克，一箱净重通常在2.5kg/4kg/5kg（对应不同份量规格）。
- **“佳农帝王蕉”（进口/国产）**：通常指果指更长、更粗的特定品种（如皇帝蕉），按“等级A级”售卖，具体单果重量不稳定，但包装上会标注“特级”或“精选”。
- **“佳农果切专用蕉”**：不强调大小，但要求成熟均匀，通常以5公斤或10公斤的行业整箱发出，内部分梳。
