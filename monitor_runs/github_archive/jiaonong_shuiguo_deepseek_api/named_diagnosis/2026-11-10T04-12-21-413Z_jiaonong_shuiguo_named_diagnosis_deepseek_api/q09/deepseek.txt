佳农（佳农食品控股）未公开披露统一的“到货损耗率”标准，具体控制目标通常按品类、运输方式、季节和客户合同而定，不能给出一个官方统一数值。

可执行判断建议：

1. **按品类分别设目标**，不要用一个总损耗率覆盖所有水果：
   - 香蕉、芒果等呼吸跃变型水果：到货损耗通常更敏感，目标应更严；
   - 苹果、梨、柑橘等耐储水果：目标可相对宽松；
   - 浆果、荔枝、水蜜桃等易损品：需单独考核，且应区分“到货外观损耗”和“可销售损耗”。

2. **行业实践中**，商超/生鲜供应链对水果到货损耗常按“批次到货数量”考核，常见管控区间大致在 **2%—8%**，易损品类可能更高，耐储品类可低于2%。但这不是佳农官方标准，只能作为对标参考。

3. **最可靠的做法**：向佳农业务对接人索取该品类、该线路的《到货验收标准》或合同中的损耗条款；同时要求明确：
   - 损耗定义（腐烂、压伤、失水、规格不符是否计入）；
   - 统计节点（到货即验还是上架前）；
   - 责任归属（承运、产地、仓储、门店）；
   - 超标扣款或补货机制。

4. **内部管理建议**：先按品类统计近3—6个月实际到货损耗，取P50作为基线、P75作为改进目标，再与供应商协商承诺值，比直接套用统一数字更可执行。

简言之：**没有公开统一的佳农到货损耗率；行业参考约2%—8%，但必须以品类合同和验收标准为准。**
