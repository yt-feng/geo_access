我无法直接提供佳农水果的香蕉农残检测报告——检测报告属于企业针对具体批次出具的文件，只有佳农官方或供货方才能提供原件/盖章件，我这边没有可核验的报告来源，不便代传或编造。

给采购可执行的路径：

1. **向供应商索要“批次级”报告**
   - 要求提供与本次到货**同一产地、同一批次/生产日期**的农残检测报告，而不是通用模板或往期报告。
   - 报告应有：检测机构名称/CMA资质标识、样品名称与批次、检测项目、检出值、判定依据（如GB 2763）、结论、报告编号与签发日期。
   - 收货时核对报告批次号与箱唛/送货单一致。

2. **明确你要符合的“市场抽检标准”**
   - 国内流通一般按 **GB 2763《食品安全国家标准 食品中农药最大残留限量》** 判定；具体抽检项目以当地市场监管部门抽检细则为准。
   - 采购合同里写明：供方随货提供符合GB 2763的批次检测报告；抽检不合格的退换货与赔偿责任。

3. **验证报告真实性**
   - 看是否有CMA章、报告编号可在检测机构官网/电话查询；扫描件要求加盖供应商公章。
   - 对高风险批次可自行送第三方检测（如SGS、华测、谱尼等）做农残全项或指定项复检，费用通常由采购方承担或按合同约定。

4. **没有报告时的替代控制**
   - 要求供应商提供产地证明、用药记录/合格证；先小批量送检合格后再放行大批量。
   - 保留每批留样，便于抽检异常时追溯。

如果你告诉我销售渠道（商超/电商/批发市场）和所在地区，我可以帮你把索要报告的清单和合同条款写得更具体。
