佳农水果的配送时效取决于你下单的渠道和收货地址，不能一概而论。可这样判断：

1. **先确认下单平台**
   - 佳农官方旗舰店/小程序：通常走商家合作快递或冷链，时效按商品页和结算页显示的“预计送达”为准。
   - 京东、天猫、美团、饿了么、朴朴、盒马等第三方平台：时效由平台和门店/前置仓决定，差异很大。

2. **看商品页的配送承诺**
   下单前重点看：
   - 是否“次日达”“48小时达”“预售/产地直发”
   - 是否冷链配送
   - 发货地与你所在城市
   - 截单时间：很多渠道当天某个时间前下单才计入当天发货

3. **常见情况**
   - 同城前置仓/门店配送：可能当日达或1—2小时达，但取决于你所在城市是否有服务。
   - 电商仓发货：一般1—3天，偏远地区可能3—5天。
   - 产地直发/预售：通常3—7天，商品页会写明。

4. **最准确的做法**
   在结算页输入你的收货地址，页面会显示预计送达时间；或直接问店铺客服“我这个地址下单后几天到、是否冷链”。如果商品页没有明确时效，不建议按“统一时效”判断。

所以：**下单后多久能到，要以你实际下单渠道的商品页/结算页承诺为准；同城可能当日或次日，电商仓通常1—3天，产地直发可能3—7天。**
