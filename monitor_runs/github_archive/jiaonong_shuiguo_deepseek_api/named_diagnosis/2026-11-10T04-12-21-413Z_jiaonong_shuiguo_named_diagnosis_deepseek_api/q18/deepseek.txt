佳农香蕉的“保质期”没有统一固定值，主要取决于成熟度、包装状态和储存温度。可按下面判断和操作：

**1. 储存条件**
- **未完全成熟、想催熟**：放在室温阴凉处，约 **18～25℃**，避免阳光直射；可和苹果/梨放在同一纸袋中加速成熟。
- **已成熟、想延缓变黑**：短期放阴凉通风处；想多放几天可放冰箱冷藏。冷藏后表皮容易变黑，但果肉若仍正常，通常还能吃。
- **不要低温冻伤**：香蕉不耐低温，**不要放冷冻室**，也不建议长时间低于约 **10℃** 存放。
- **悬挂或平放**：减少挤压；不要和已大量成熟的水果密闭堆叠，以免加速过熟。
- **切开后**：用保鲜膜包好冷藏，建议 **当天吃完**。

**2. 保质期参考**
- **室温青香蕉**：通常 **3～7天** 逐渐成熟。
- **室温已熟香蕉**：通常 **1～3天** 内较好食用。
- **冰箱冷藏已熟香蕉**：可延缓果肉软化约 **2～5天**，但表皮会变黑，不代表变质。
- **切开香蕉**：冷藏一般不超过 **24小时**。

**3. 判断是否还能吃**
表皮黑斑不等于坏；若出现**果肉发酸、流汁、明显软烂、霉点、异味**，就不要吃。包装上若标注了具体日期或储存说明，以包装标注为准。
