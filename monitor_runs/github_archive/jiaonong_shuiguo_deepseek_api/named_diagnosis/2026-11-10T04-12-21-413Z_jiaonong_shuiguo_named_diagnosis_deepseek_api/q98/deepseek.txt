我们这边没有“到货损耗率承诺”或“超过3%包赔”这类政策可以给你确认。你要是向佳农或经销商进货，损耗赔付要看合同/供货协议里的验收标准和售后条款，不能默认有3%包赔。

给你可执行的做法：
1. 先问供应商要书面承诺：到货验收标准、允许损耗比例、超标怎么赔（补货/折价/退款）、报损时限和取证要求。
2. 首单别压量：先小批量试销2-3周，按门店日均销量定订货量，记录到货损耗、货架期损耗、日销量。
3. 验收当场做：开箱抽检、拍照称重、记录批次和温度，超标当天报备，避免事后扯皮。
4. 合同写清楚：损耗率按“到货验收”还是“上架前”算，是否含表皮瑕疵，赔付触发线和结算方式。
5. 门店控损：先进先出、分级陈列、熟度分开卖、临期折价或做果切/饮品，别等全损再处理。
