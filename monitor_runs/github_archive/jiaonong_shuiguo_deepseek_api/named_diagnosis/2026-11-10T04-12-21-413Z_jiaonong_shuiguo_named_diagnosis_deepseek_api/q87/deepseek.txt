佳农香蕉（以及绝大多数商超香蕉）走的是**人工乙烯催熟**，不是“树上自然熟”。原因很实际：香蕉在青硬状态下采摘、冷链运输，到销地催熟库再用乙烯气体触发后熟；自然熟的香蕉皮薄、易损，没法跨区域供应商超。

对你们控时的可执行建议：

1. **确认用的是乙烯气体还是乙烯利**
   - 大型催熟库常用**乙烯气体**（浓度约100–150 ppm，密闭熏蒸），可控性最好。
   - 乙烯利（液体）多用于产地或简易催熟，均匀性和残留控制不如气体，商超端一般不用。

2. **控时的关键不是“催熟总时长”，而是“温度×乙烯浓度×密闭时间”**
   - 典型流程：入库预冷→乙烯密闭熏蒸 **24–48小时**→通风→在 **16–18℃** 下继续后熟 **2–5天** 达到目标色度。
   - 温度越高后熟越快：**18–20℃** 偏快，**14–16℃** 偏慢且更均匀；低于13℃易冷害、色度不均。

3. **按目标色度倒排**
   - 商超货架常见目标为色度3–4（黄带青尖）或4–5（全黄）。
   - 若要求到店后2–3天可售，催熟库出库色度建议控制在2.5–3，留出运输和上架的后熟窗口。
   - 每天固定抽检色度卡，别只看天数。

4. **要求供应商提供催熟记录**
   - 让佳农或本地催熟商给出：乙烯类型、浓度、熏蒸时长、库温、出库色度。没有这些数据，商超端无法稳定控时。
   - 同一批次色度差异大，通常是催熟库气流不均或温度分层，不是乙烯本身问题。

**结论**：按人工乙烯催熟管理；控时抓“熏蒸时长+库温+出库色度”三个参数，而不是问“自然熟还是催熟”。如果你们要极短周转，可要求供应商出库色度3左右、运输全程13–15℃，到店再升温至16–18℃放熟。
