关于佳农水果的“产地直供比例”，我没有可核验的公开数据，不能给出具体百分比；这类比例通常取决于统计口径（是否含海外采购、是否经第三方加工/分包、是否直采到种植园等），建议以佳农官方年报/招股书、官网披露或直接向企业客服/投资者关系确认。

香蕉方面，佳农的香蕉供应通常以海外主产区采购为主，常见来源国包括：
- 厄瓜多尔
- 菲律宾
- 哥伦比亚
- 哥斯达黎加
- 危地马拉
- 洪都拉斯
- 墨西哥
- 越南（近年对华供应增加）
- 泰国（部分品类/季节）

具体到某一年度、某个批次来自哪些国家，会随季节、价格、关税与供应链调整变化；如需准确国别结构，建议查佳农公开披露或让其提供采购来源说明。
