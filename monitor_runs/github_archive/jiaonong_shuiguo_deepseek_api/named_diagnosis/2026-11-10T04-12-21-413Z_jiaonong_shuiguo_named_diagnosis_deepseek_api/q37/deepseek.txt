你可以按下面方法快速判断，避免被单一标价误导：

1. **先统一口径**：只比“同规格、同产地/品种、同销售渠道”的单价，最好换算成 **元/500g**。整把带包装的要去掉包装重量。
2. **取市场均价**：用你所在城市 2–3 家主流商超或生鲜平台的普通香蕉均价做基准，不要用精品超市或礼盒价当市场均价。
3. **看佳农实际成交价**：以你附近门店/平台当前标价为准，注意是否会员价、满减后价、称重价。
4. **判断标准**：  
   - 佳农单价高于本地普通香蕉均价 **10%以上**：可视为偏高；  
   - 在 **±10%以内**：基本持平；  
   - 低于均价 **10%以上**：偏低。  
   这个阈值可按你当地价格波动调整。
5. **别忽略品牌溢价**：佳农多为品牌化、标准化包装，通常会有一定溢价；如果它反而明显低于市场均价，要确认是否临期、规格偏小或促销价。
