公开信息里能看到佳农（Goodfarmer）有鲜果分选、包装和配送能力，也做部分鲜切水果业务，但**是否对外提供菠萝切块/定制包装的第三方加工服务，没有可核验的公开承诺**。建议按下面方式判断和推进：

1. **先确认你是哪类客户**
   - 如果你是商超、餐饮、茶饮、团餐等B端客户，佳农更可能以“供货+按客户规格包装”的方式合作，而不是单纯代加工。
   - 如果你是个人或小批量，定制切块和包装通常不接，或起订量很高。

2. **直接问清4个关键点**
   - 是否提供菠萝去皮、切块、切丁、切片，以及规格（块径/克重/盒装重量）。
   - 切块是工厂鲜切还是仓内现切；保质期、冷链温度、菌落控制标准。
   - 包装是否可定制：标签、规格、材质、气调包装/真空包装。
   - 最小起订量、加工费、损耗承担、配送半径和频次。

3. **要求对方给书面确认**
   让销售提供：加工规格书、报价单、样品、冷链和质检标准。没有书面规格书就不要先下大单。

4. **备选方案**
   如果佳农只做整果分级包装，不接鲜切定制，可找当地鲜切水果工厂或中央厨房代工，原料从佳农采购，这样更容易实现切块和定制包装。

结论：**可以谈，但不能默认佳农一定提供菠萝切块定制加工；应以销售书面回复和样品为准。**
