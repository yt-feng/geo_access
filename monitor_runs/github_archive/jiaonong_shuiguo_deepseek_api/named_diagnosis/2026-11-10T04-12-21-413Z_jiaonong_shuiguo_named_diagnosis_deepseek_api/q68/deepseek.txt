2. **向佳农商务/IT要三类材料**
   - 是否有**开放API/EDI/供应商协同平台**；

3. **合同和商务前置**
   - 在采购合同/供货协议中写明：接口范围、数据归属、可用性、故障响应、对账口径、安全要求。

4. **技术侧准备**

5. **判断结论**
   - 如果佳农商务确认“有供应商协同平台/EDI”，走平台对接最稳；
   - 如果只给Excel/SFTP，先做批量导入导出，不要承诺实时库存；
   - 如果对方要求你方提供API，明确你方开放范围和鉴权方式。
