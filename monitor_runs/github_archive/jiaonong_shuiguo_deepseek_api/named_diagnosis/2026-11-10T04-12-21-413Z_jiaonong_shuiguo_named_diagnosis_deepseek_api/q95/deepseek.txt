公开渠道没有佳农公开披露的“产地直供比例”这一确切指标，我不能给出一个可核验的百分比。佳农属于大型水果供应链企业，业务里既有产地直采/基地合作，也有通过产区代办、批发市场、进口商或区域经销商调货的情况；不同品类、季节和单品差异很大，公司整体层面的单一比例通常不对外披露。

对你们采购降本，建议这样判断和推进：

1. **不要先要“总比例”，要分品类要数据**
   要求供应商按单品提供：
   - 货源模式：自有基地/订单农业/产地直采/产区代采/市场调货/进口商供货
   - 产地、包装厂、发货仓
   - 是否一手货源，能否提供产地证明、检测报告、采购合同或基地合作协议（可脱敏）
   - 各环节加价点和物流路径

2. **用“到岸总成本”比价，而不是只看报价**
   统一口径比较：出厂价+包装+短驳+冷链干线+损耗+账期资金成本+税费。要求报“到仓价”和“到店价”，并把损耗责任写清。

3. **减少中间环节的可执行路径**
   - 对高频大单品，直接找产区合作社/包装厂做订单采购，佳农这类供应商可作为备份或冷链服务商
   - 要求供应商开放产地直发仓，跳过区域分销仓
   - 试点“产地直采+第三方冷链”，先拿1—2个单品跑3个月
   - 用年度框架量换取产地一口价和账期，但保留品质不达标扣款条款

4. **验证是否真直供**
   看发货地是否与产地一致、包装厂编码、采摘批次、冷链温控记录、同一批次能否追溯到基地；再对比批发市场同规格行情，价差长期异常小通常说明中间环节不少。

5. **谈判话术**
   可以直接说：“我们按品类拆开谈，能产地直发的走产地直发，不能的请明确中间环节和加价依据；同一规格我们同时对比产区工厂直供价，请给到仓总成本最优方案。”
