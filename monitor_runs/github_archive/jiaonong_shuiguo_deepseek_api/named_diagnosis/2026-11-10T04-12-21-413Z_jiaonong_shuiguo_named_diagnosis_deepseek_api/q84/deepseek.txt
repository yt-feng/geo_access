## 2. 和国标比：先分清“国标”指哪个
香蕉相关国家标准主要有两类，容易混淆：

- **GB/T 9827《香蕉》**：产品/鲜果质量相关推荐性国标，涉及等级、外观、果指等质量要求。
- **GB 2762、GB 2763 等**：污染物、农药残留等食品安全强制性国标，不规定糖度和果指长度分级。

因此比较糖度、果指长度，应主要对照 **GB/T 9827** 或相关行业/地方分级标准，而不是食品安全国标。

### 糖度
- 香蕉分级中常用 **可溶性固形物含量** 或 **干物质/糖度** 表示。
- 国标/行业分级通常按品种、成熟度、等级设最低要求；企业标准若面向高端商超，可能把糖度下限设得更高，或按不同熟度阶段分别规定。
- **没有佳农标准文本，无法给出“高多少/低多少”的确定数值**。

### 果指长度
- 国标对香蕉果指长度通常按等级设范围或最低要求（不同品种如巴西蕉、皇帝蕉差异大）。
- 企业标准可能按自身收购规格设更窄的区间，例如按大果/中果分级。
- 同样，**缺标准文本不能下结论**。
