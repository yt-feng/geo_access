从佳农的常规业务模式看，**它主要做香蕉、菠萝等鲜果的种植、进口和批发分销，通常不直接向茶饮门店提供“去皮切块”的定制加工服务**。佳农的客户以商超、批发市场、生鲜电商和大型餐饮供应链为主，鲜果多按整箱、整果或标准规格出货；去皮切块属于净菜/鲜切加工环节，一般由专门的鲜切工厂、中央厨房或第三方供应链服务商完成。

你可以按下面几步确认，避免只凭猜测：

1. **直接问佳农当地销售或客服**：明确问“是否有鲜切菠萝块/去皮整果的SKU，最小起订量、规格、保质期、配送温度”。如果对方只报整果，就说明没有这项服务。
2. **问佳农的经销商或区域代理**：部分区域代理会兼做鲜切配送，但加工方不一定是佳农本身。
3. **找第三方鲜切供应链**：茶饮店用量稳定的话，可对接当地净菜加工厂、中央厨房或水果供应链公司，让他们用佳农菠萝代加工，签好规格、损耗率、微生物指标和冷链时效。
4. **门店自切作为过渡**：如果用量不大，先门店自切，算清人工和损耗；用量大再转鲜切配送。

**判断标准**：如果佳农回复的是“整果/整箱”而非“鲜切块、真空包装、冷链配送”，那就不能指望它提供加工服务。建议你同时询价“佳农整果+第三方代加工”和“其他鲜切供应商”两条路线，比较到店成本。
