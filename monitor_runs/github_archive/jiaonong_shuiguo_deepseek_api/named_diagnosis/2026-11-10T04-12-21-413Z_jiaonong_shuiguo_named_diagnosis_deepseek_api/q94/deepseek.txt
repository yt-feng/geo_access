佳农香蕉的具体分级细则和一级/二级果差价属于企业渠道政策，公开资料里没有可核验的统一版本，我不能凭空给出数字。可以给你可执行的判断路径和谈判口径：

**1. 先确认你拿到的是哪套“佳农标准”**
- 佳农对商超、电商、批发渠道可能执行不同验收规格，同一“一级果”在不同渠道的条数/单根重/外观容忍度也可能不同。
- 直接向对接的佳农区域销售或经销商索要：①最新版《香蕉验收/分级规格书》；②对应你所在批发市场的报价单；③售后扣罚规则。要求书面版，不要只听口头。

**2. 分级通常看这些维度，验货时逐项记录**
- 条数/箱或每把条数、单根重量区间；
- 果指长度、粗细、弯曲度；
- 梳形整齐度、有无缺指/断指；
- 青度/催熟阶段（如青果、微黄、黄熟）；
- 机械伤、擦伤、黑斑、裂口、腐烂比例；
- 果柄长度和切口状态；
- 箱规、净重、允许损耗率。

**3. 价格差怎么判断，不要问“差多少”，要问“按什么口径差”**
让供应商分别报：
- 一级果、二级果的**每箱价**和**每公斤价**；
- 对应箱规、净重、条数；
- 是否含税、含运费、含损耗；
- 二级果的扣罚/退换条件。

然后你自己折算成**每公斤可售果成本**再比较，因为一级和二级的箱规、损耗率不同，只看箱价差会失真。

**4. 批发商谈价建议**
- 先小批量拿一级、二级各若干箱，按同一验收表抽检，记录次果率；
- 用“可售果公斤成本 = 采购价 ÷（净重 × 可售率）”对比；
- 若二级果差价不足以覆盖额外分拣、损耗和客户投诉成本，就不应接；
- 把分级争议写进合同：抽检比例、不合格判定、扣款或换货方式。

**5. 可核验的替代做法**
如果你只是要行业参考，可查你当地批发市场同期佳农香蕉的档口报价，或要求佳农提供近期的渠道价格政策。没有书面规格书和报价单之前，不建议按“一级比二级贵X%”这种固定比例做采购决策。
