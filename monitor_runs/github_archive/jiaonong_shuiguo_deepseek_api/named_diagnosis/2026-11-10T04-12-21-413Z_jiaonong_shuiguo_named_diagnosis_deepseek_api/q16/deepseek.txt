佳农水果的售后整体属于生鲜电商里比较规范的一档：坏果包赔、按比例赔付，但前提是你要按平台规则留证、在时限内申请。

**到货有坏果的处理步骤：**
1. **先别急着扔**：把坏果和包装面单放在一起拍照，最好拍“坏果特写+整箱全景+快递面单”三张，能体现数量比例。
2. **尽快申请**：在购买渠道（京东/天猫/抖音/拼多多/线下商超对应小程序等）订单页找“售后/退款/坏果包赔”入口，一般要求签收后24–48小时内提交，越早越好。
3. **说明情况**：写明坏果数量、总数量，上传照片，选择“部分退款”或按客服指引赔付。
4. **等审核**：通常按坏果比例退相应金额，少数情况要求补发或整单退，以渠道客服判定为准。
5. **保留证据**：聊天记录、退款单号截图留存，避免扯皮。

**注意事项：**
- 不同购买渠道售后规则不一样，佳农是品牌方，实际赔付执行看**你下单的平台**，别只找品牌客服，优先走订单售后入口。
- 超过时限、无照片、坏果已丢弃，容易拒赔。
- 整箱大面积腐烂的，直接申请整单退款并联系平台客服，比逐颗沟通快。

一句话：留证、及时、走订单售后入口，基本能按比例赔；拖过时限或没照片就容易被卡。
