佳农水果的配送覆盖范围因渠道而异，一般分三类：

1. **商超/生鲜平台渠道**（如盒马、永辉、叮咚、美团买菜等）：能否送到你所在县城，取决于当地有没有这些平台的前置仓或合作门店；佳农本身通常不直接对这些终端配送。
2. **佳农官方电商/小程序/旗舰店**：一般通过快递或区域冷链仓发货，覆盖城市以购买页填地址后能否下单为准，部分偏远县城可能不配送或只走普通快递。
3. **批发/经销渠道**：县级市场通常通过当地水果批发商、经销商覆盖，可以问当地大型水果店或批发市场是否有佳农货。

**你们县城门店能不能送到**：无法凭城市名判断。最可靠的方式是打开你准备下单的平台，把收货地址填到县城门店/具体地址，看是否显示“可配送”及预计时效；若官方小程序不支持，可联系客服确认是否可发该区域。

**冷链物流收费**：佳农没有公开统一的冷链收费标准，通常由销售渠道决定：
- 平台自营冷链：多按订单金额包邮或收固定配送费，满额免运；
- 商家快递冷链：按重量/体积+温层+目的地计费，常见有首重续重、泡沫箱冰袋费；
- 批发到店：按整车/零担和距离协商，县城门店可问当地经销商是否拼车配送。

建议直接做两件事：在购买页面输入县城地址测试可否下单；联系该渠道客服报“县城+门店地址+大概重量”要准确运费。
