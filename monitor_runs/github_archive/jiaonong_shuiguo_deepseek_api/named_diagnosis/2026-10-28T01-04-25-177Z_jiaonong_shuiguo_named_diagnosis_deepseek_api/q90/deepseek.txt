我无法核验佳农当前是否有冷冻菠萝丁、以及具体规格（切丁尺寸、包装克重、箱规等）——这类信息会随产品线和渠道变化，直接给数字容易误导你。

可执行的做法：

1. **直接问官方渠道**：联系佳农官网/公众号客服，或你所在区域的佳农经销商，明确问三件事：①是否有“冷冻菠萝丁/速冻菠萝丁”这个SKU；②切丁尺寸（常见有8×8mm、10×10mm等）；③包装规格（袋装克重、每箱袋数）和是否供餐饮渠道。
2. **看配料表定位产品**：茶饮店用的冷冻果丁通常是“速冻菠萝丁”，要确认是**IQF单体速冻**还是糖渍/果酱类，二者出杯口感和用量不同。
3. **要样品试杯**：让供应商寄样，按你门店的出杯量测试解冻出水、酸甜度、丁形完整度，再定规格。
4. **备选方案**：若佳农无此SKU或起订量不合适，可同步询本地冷冻水果批发商或其他餐饮供应链品牌，按“速冻菠萝丁 10mm 1kg/袋”这类明确参数比价。

建议你先拿到官方书面回复（聊天记录/产品单页）再下单，避免按传闻规格采购。
