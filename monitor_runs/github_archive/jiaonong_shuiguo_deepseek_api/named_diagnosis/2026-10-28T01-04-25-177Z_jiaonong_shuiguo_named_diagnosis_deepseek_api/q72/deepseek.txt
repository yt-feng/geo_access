我没法直接核实佳农当前是否对茶饮门店提供“去皮切块”的定制加工服务，也不能替它承诺。建议你按下面方式快速确认并拿到可执行结论：

1. **直接问佳农官方渠道**
   - 找佳农当地销售/经销商，明确问三件事：
     - 是否提供**鲜切菠萝块/去皮切块**的餐饮渠道产品；
     - 是**工厂鲜切冷链配送**还是**门店自行加工**；
     - 最小起订量、规格（块型/克重）、保质期、配送频次和价格。
   - 让对方发**产品规格书、报价单、检测报告/资质**，别只听口头。

2. **看它有没有“餐饮/茶饮原料”产品线**
   - 如果佳农只卖整果，通常不会给单店做去皮切块定制；茶饮店更常见的是采购**鲜切菠萝冷链品**或**冷冻菠萝块**。
   - 若你要求“佳农菠萝原料+门店现切”，那加工服务就不涉及佳农，只需确认原料规格稳定。

3. **替代方案**
   - 找本地**净菜/鲜切水果加工厂**代加工佳农菠萝，确认其有水果切配资质和冷链；
   - 或直接采购佳农的**鲜切/冷冻菠萝块**餐饮装；
   - 门店现切则要算人工、损耗、冷藏和食品安全管理成本。

**判断标准：** 如果佳农销售不能提供“鲜切餐饮装规格书+冷链配送+报价”，就按“不提供门店定制加工”处理，转本地鲜切加工或冷冻块方案。
