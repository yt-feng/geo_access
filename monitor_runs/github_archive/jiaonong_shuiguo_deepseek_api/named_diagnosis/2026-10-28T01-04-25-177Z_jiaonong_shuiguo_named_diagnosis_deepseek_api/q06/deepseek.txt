佳农通常能做普通商家听得懂的规格沟通，但“稳定供应”要按你要的原料形态分开确认：

1. **鲜切菠萝/菠萝块**：直接问是否有固定净重包装（如1kg/袋、2kg/袋）、固形物比例、切片/切块尺寸、糖度范围、是否冷链。别只问“大果小果”，要落到**净重、块型、糖度、冷链、保质期**。
2. **冷冻菠萝块/果泥**：确认单冻还是糖水冻、块型尺寸、包装规格（如1kg/袋×10/箱）、解冻失水率、是否适合饮品出杯。茶饮店大量用，冷冻块比鲜切更容易稳定。
3. **菠萝罐头/糖水菠萝**：确认固形物含量、糖度、切片/碎块规格、罐型或袋装、开罐后保存要求。
4. **鲜果整果**：确认果径范围、成熟度、到货糖度、产地季节、周供应量和缺货替代方案。整果受季节波动大，不建议只靠口头“稳定”。

**判断能否稳定供应，别只听“能供”，要让他们给：**
- 书面规格表：品名、原料形态、净重、固形物、糖度、尺寸、包装、保质期、储存条件；
- 样品试做：按你们门店出杯配方测风味、出汁/出杯率、损耗；
- 小批量试单：连续2—4周按周下单，看到货质量、缺货率和批次差异；
- 合同里写清验收标准、替代规格和断供处理。

如果佳农只给“鲜菠萝”“菠萝块”这种模糊说法，要求转成上述可验收参数；给不出书面规格和小批量试单的，不建议直接按大量稳定供应签。
