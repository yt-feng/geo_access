**1. 先确认佳农能否满足你的两个条件**
- **专车配送**：问清是“整车专车”还是“固定线路拼车”。餐饮连锁要明确：是否只装你的货、是否固定车辆、是否温控、到店时间窗、迟到/破损/温差异常怎么赔。
- **专人对接**：要求指定客户经理+履约调度+售后对接人，写明响应时效，比如下单确认、异常反馈、到货差异处理分别在多少小时内响应。

**2. 要求佳农提供可核验的服务方案**
让对方书面给出：
- 配送城市/门店覆盖范围、起订量、配送频次；
- 车辆类型、温控标准、是否可追踪；
- 各门店到货时间窗和卸货要求；
- 缺货、短装、品质不达标、迟到时的补货和赔付机制；
- 报价是否含专车费、卸货费、偏远门店附加费。

**3. 建议先小范围试运行**
选3—5家门店、2—4周试配送，重点看：到货准时率、香蕉成熟度一致性、短装率、异常响应速度。试运行达标后再签长期框架协议。

**4. 合同里必须写死的点**
- 专车定义和车辆保障；
- 指定对接人及替补机制；
- 服务时效和违约赔付；
- 品质规格（等级、果指、成熟度、青黄比例）；
- 价格调整机制和锁价周期。

**结论**：佳农作为大型香蕉供应商，通常具备专车和专人对接的服务能力，但能否对你的具体门店网络稳定做到，必须以书面方案+试运行数据为准。建议先让对方按你的门店清单和日需求量出一份“专车配送+专人对接”报价与服务承诺，再决定是否放量。
