佳农水果的香蕉规格会随产品线、包装形式和销售区域变化，公开资料里没有一个稳定、可核验的全量规格表；渠道分级标准也属于企业内部标准，通常不完全公开。下面只给可执行判断，不编造具体克重和条数。

**1. 规格维度**
佳农香蕉常见按以下维度区分，而不是单一“几种规格”：
- 按单根果指重量/粗度分级：如大果、中果、小果/迷你蕉等，具体阈值需以当期产品标签或供应商报价单为准。
- 按每把/每串条数：常见有单把装、整串装，条数随批次变化。
- 按整箱净重：如常见箱装净重档位，需看具体SKU和渠道定制包装。
- 按包装形式：散装、袋装、礼盒装、电商箱装、餐饮/烘焙大箱等。
- 按成熟度：青蕉、催熟蕉、即食蕉，属于状态分级而非大小规格。

**2. 不同渠道的分级思路**
企业标准通常围绕“外观、大小均匀度、成熟度、损伤率、货架期”设定，可参考以下渠道逻辑，但具体数值需向佳农销售或索取样册确认：
- 商超/精品超市：重视果指均匀、无机械伤、无黑斑、成熟度一致，偏向中大果和外观整齐的批次。
- 水果连锁/社区店：重视性价比和周转，规格可略宽，但要求成熟度批次稳定、损耗可控。
- 电商/社区团购：重视耐运输和标准化装箱，通常选青蕉或半熟蕉，控制单箱净重和条数一致。
- 餐饮/烘焙/果汁渠道：更看重出肉率、成熟度和成本，对外观要求相对低，可用大箱或特定成熟度批次。
- 批发市场：按产地、果指大小、成熟度、损伤率分档，价格敏感，规格跨度较大。

**可执行建议**
- 向佳农官方销售索取“当期产品规格表/报价单”，重点确认：单根重量区间、每箱净重、每箱条数或把数、成熟度、允许损伤率。
- 渠道分级谈判时，把验收指标写成可测条款：果指长度/粗度范围、青黄比例、机械伤比例、黑斑允许度、到货成熟度。
- 不要仅凭“大果/中果”名称采购，要求以样品和抽检标准锁定。
