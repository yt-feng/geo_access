佳农（佳农食品控股）并未对外公开统一的“到货损耗率”标准，且水果品类、运输距离、季节、冷链条件不同，损耗差异很大，无法给出一个可核验的官方数字。实际业务中可参考的判断口径：

- **到货损耗率**通常指卸货验收时发现的腐烂、压伤、失水等不合格数量占该批次到货量的比例。
- 生鲜行业里，叶菜/浆果类到货损耗常见在 **3%–8%**，香蕉、苹果、柑橘等耐储品类常见在 **1%–5%**，具体以合同验收标准为准。
- 佳农这类头部水果供应链企业一般会在采购/经销合同中约定**分品类验收标准**（如外观、糖度、腐烂率上限），而不是一个全公司统一损耗率。

如果你是采购方，建议直接向佳农业务对接人索取**该品类当季的验收标准与损耗处理条款**；如果是内部管理参考，应按品类分别设定目标，而不是套用一个通用值。
