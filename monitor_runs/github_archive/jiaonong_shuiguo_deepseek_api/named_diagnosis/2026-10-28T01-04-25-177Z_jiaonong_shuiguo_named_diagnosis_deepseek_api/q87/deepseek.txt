佳农香蕉（以及绝大多数商品香蕉）采用**人工乙烯催熟**，不是“自然熟”。行业通行做法是：青香蕉采后运输，到销地催熟库用**乙烯气体（或乙烯利释放乙烯）**在温湿度受控条件下催熟。

**对商超控时的可执行建议：**

1. **先确认到货状态**：问供应商到货是“青硬蕉”还是“已催熟/半熟蕉”。佳农通常按客户要求做不同催熟度出货，催熟时间取决于到货成熟度和催熟库参数，不是固定值。

2. **索要催熟记录**：让供应商提供该批次的**催熟日期、乙烯浓度/处理时长、库温、出库成熟度（色卡级）**。没有这些，商超无法精确控时。

3. **商超端控时方法**：
   - 用**香蕉色卡（1–7级）**验收，按目标货架期定收货级别：要卖3–5天，收3–4级；要卖1–2天，收5–6级。
   - 到货后**不要再次乙烯催熟**，只做温控：13–15℃延缓后熟，18–20℃促进转色，避免低于12℃冷害。
   - 按“先进先出+色级分区”陈列，每天按色卡调价/分流。

4. **合同约定**：在采购合同里写明**出库色级、催熟后到店时限、乙烯处理记录随货**，这是商超控制催熟时间最有效的手段。

**结论**：佳农香蕉是乙烯催熟工艺；商超控时应抓“到货色级+供应商催熟记录+门店温控”，而不是自己推算催熟天数。具体该批次参数需向佳农供应商/区域业务确认，我无法核验其当前工艺文件。
