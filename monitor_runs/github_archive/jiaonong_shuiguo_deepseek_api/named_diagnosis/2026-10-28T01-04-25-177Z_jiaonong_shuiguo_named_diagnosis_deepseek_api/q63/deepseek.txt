我无法核实佳农当前是否有针对商超的香蕉促销支持政策，所以不能直接给“有/没有”的结论。你可以按下面方式快速确认并推进：

**1）先确认对接对象**
- 找佳农的**区域销售经理/商超渠道负责人**，而不是只问门店送货业务员；促销搭赠、降价补贴通常要走渠道政策审批。
- 同时让商超采购把需求整理成一页：门店数、档期、预估销量、促销形式、费用承担方式。

**2）直接问清4个关键问题**
- 香蕉是否参加本次档期促销？可支持**搭赠**还是**降价补贴**，或两者只能选一？
- 支持门槛：起订量/进货量、单店最低陈列、档期时长、是否要求端架/堆头/海报。
- 费用核销方式：随货搭赠、返利、发票折扣还是活动后核销？需要哪些凭证（陈列照、销售数据、签收单）。
- 价格保护：促销期间供货价是否锁定，活动后是否影响正常价盘。

**3）给对方的谈判话术**
> 我们计划X月X日—X月X日在X家门店做香蕉档期促销，预估进货X箱、日均销量X。希望佳农支持搭赠X%或降价补贴X元/箱，我们承担端架陈列、海报和社群推广，活动后提供陈列与销售数据。请确认可否申请及核销流程。

**4）如果佳农不支持**
可改谈替代方案：**随货搭赠、阶梯返利、免费陈列物料、试吃推广支持、账期支持**；或联合经销商做“买赠+陈列”组合，而不是只盯降价补贴。

**判断建议**：先让对方书面确认“支持形式、门槛、核销凭证、档期”四项，再决定是否把香蕉作为引流品上档；没有书面确认前，不建议在促销方案里预设补贴。
