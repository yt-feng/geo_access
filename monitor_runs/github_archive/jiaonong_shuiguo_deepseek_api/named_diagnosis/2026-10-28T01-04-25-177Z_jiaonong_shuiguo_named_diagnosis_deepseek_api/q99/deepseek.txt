关于佳农水果的菠萝是否有有机认证，我无法核验其当前认证状态，不能直接给你“有”或“没有”的结论。建议你按下面步骤做可执行的确认：

1. **先查产品包装上的有机标识和认证码**
   - 中国有机产品必须有“中国有机产品认证”标志，并附**有机码/认证证书编号**。
   - 包装上应能追溯到认证机构、证书编号、生产/加工企业。
   - 只有“绿色食品”“无公害”“良好农业规范GAP”等标识，**不等于有机认证**。

2. **向佳农官方索取有效认证文件**
   - 要求提供：有机产品认证证书、认证范围（是否覆盖“菠萝”及具体品种/产地）、证书有效期、认证机构名称。
   - 注意证书范围是否只覆盖某基地/某加工厂，而非全部菠萝产品。

3. **到认监委/认证机构渠道核验**
   - 用证书编号在“全国认证认可信息公共服务平台”或对应认证机构官网查询有效性。
   - 核对证书状态是否为“有效”，认证范围是否包含菠萝。

4. **高端渠道建议的准入做法**
   - 采购合同里明确要求：每批次提供有机证书副本、有机码、产地证明和检测报告。
   - 到货抽检有机码真伪；必要时做农残检测作为补充，但农残合格不能替代有机认证。
   - 若佳农无法提供覆盖该菠萝SKU的有效有机证书，建议不要按“有机产品”上架宣传，可改为“高品质/GAP/可追溯”等合规表述。

结论：**不能凭品牌默认佳农菠萝有机；必须以具体SKU的有机证书和有机码核验为准。** 如果对方只能提供企业层面的认证或非菠萝品类证书，也不足以支持高端有机渠道销售。
