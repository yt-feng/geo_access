**总体判断**
佳农属于品牌化水果供应商，售后通常比无品牌散货更有保障，但体验强依赖购买渠道：  
- **京东自营/天猫旗舰店/抖音品牌店**：一般走平台售后，坏果拍照理赔较规范。  
- **社区团购/生鲜平台/线下商超**：按该平台规则处理，佳农品牌方不一定直接介入。  
- **个人微商/拼团**：风险最高，尽量别买。

**到货有坏果，按这个顺序处理**
1. **先别扔，先拍照取证**：坏果整体+切开面+快递面单+整箱合照，最好拍视频。  
2. **24小时内联系购买渠道客服**，不要只找佳农品牌客服；说明“坏果数量/总数量”，要求按比例退款或补发。  
3. **明确诉求**：少量坏果通常按比例赔；大面积腐坏可要求整单退换。不要接受“削掉还能吃”这类话术。  
4. **保留原包装和坏果**至少到理赔完成，别急着丢弃。  
5. **客服不处理就升级**：平台订单页申请售后/投诉，京东可走“交易纠纷”，天猫走“售后维权”，抖音走订单投诉；仍无果可拨12315。  
6. **注意时效**：生鲜类售后窗口通常很短，越早提交越好，别拖过48小时。

**避坑提醒**
- 下单前看清商品页的“坏果包赔”规则：赔比例、是否需开箱视频、时效多久。  
- 收到后尽快开箱验货，别放几天再说坏。  
- 如果坏果比例高，直接要求退全款或补发，不要只拿几块钱补偿。
