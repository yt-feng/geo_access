- 佳农集团官网、官方公众号通常会披露“中国果品流通协会”等行业组织颁发的奖项、展会金奖、以及商超/电商合作案例（如与山姆、盒马、永辉、京东等渠道的合作）。

- 部分奖项可在颁奖机构官网或公告中交叉核对。

**2. 可靠性判断标准**
- **高可信**：奖项由正规行业组织或展会主办方颁发，且能在该机构官网/公告中找到对应记录；客户案例有双方（或至少渠道方）公开表述。
- **中等可信**：仅见于佳农自己官网/宣传物料，未见第三方独立记录。这类信息不一定假，但属于“企业自述”，应视为宣传口径。
- **低可信**：只有二手转载、无颁奖机构名称、无具体年份和奖项全称，或“客户案例”只有模糊表述（如“某大型连锁商超”）而无从核实。

**3. 注意事项**
- 企业宣传中的“金奖”“品质奖”需看清颁发主体和年份，很多是展会评选或行业协会评选，含金量与“国家质量奖”不同。
- 客户案例若涉及具体采购量、复购率等数据，通常只有企业单方披露，建议以渠道方公开信息为准。
