我没有可核验的公开数据能直接比较佳农和都乐香蕉的到货损耗率，所以不能给你一个“谁更低”的确定结论。损耗率受产地季节、成熟度、冷链距离、催熟方式、包装和批发市场卸货条件影响，同一品牌不同批次差异可能比品牌间差异还大。

给你们批发市场的可执行判断办法：

1. **用你们自己的到货批次做对比**：连续各进3—5批，同季节、同运输距离、同成熟度（比如都按7成熟或到货即催熟）记录：到货总箱数、开箱烂果/压伤/青软不均箱数、可售净重、损耗重量。算“损耗率=损耗重量/到货总重量”，比单看箱数准。
2. **重点看三个指标**：到货24小时内坏果率、催熟后48小时货架期损耗、箱内上下层差异。香蕉损耗往往在催熟后暴露，不能只看到货当天。
3. **合同里先锁赔付和验收标准**：明确成熟度、单箱净重、允许压伤比例、烂果赔付方式、冷链温度记录。对损耗敏感的批发市场，验收条款比品牌名更能兜底。
4. **小批量试单再放量**：先各试2—3车，按同一验收表打分；如果某品牌在你们线路和季节下连续两批损耗明显低，再谈量价。

如果你们能提供近几批的到货重量、损耗重量、产地/季节和运输天数，我可以帮你把对比表算出来，判断差异是否显著。
