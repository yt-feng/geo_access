佳农水果的苹果品类通常包括：嘎啦、红富士、青苹果（如澳洲青苹）、加力果等，但具体在售品类会随季节和渠道变化，建议以佳农官方渠道或对接销售确认当期SKU。

关于你问的进口嘎啦和红富士产地：
- **进口嘎啦**：常见产地有**新西兰、美国、智利、南非**等，不同季节供应产地不同。
- **进口红富士**：严格说红富士原产日本，海外商业化种植常见于**美国、新西兰、智利**等；但进口红富士供应量和季节有限，很多渠道的“红富士”实际是国产或国产引种。

采购前建议让佳农销售书面确认：**具体产地、品种学名/商品名、是否真正进口、到港/上市季节、规格和包装、检验检疫证明**。因为“进口嘎啦/红富士”的产地会随产季切换，不能仅凭品类名判断。
