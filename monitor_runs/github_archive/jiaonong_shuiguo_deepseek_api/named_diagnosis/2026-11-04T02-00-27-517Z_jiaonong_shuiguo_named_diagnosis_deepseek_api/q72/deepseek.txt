我无法核验佳农当前是否提供面向茶饮店的去皮切块加工服务，所以不能直接给出“能/不能”的确定答案。建议按下面方式快速判断和推进：

1. **先确认你需要的形态**
   - 鲜切菠萝块（冷藏短保，门店直接使用）
   - 速冻菠萝块/丁（冷冻长保，适合备货）
   - 糖水菠萝/罐头菠萝（开罐即用，稳定性高）
   茶饮店若追求鲜感和出品稳定，通常要明确“鲜切冷藏”还是“速冻”，两者供应链完全不同。

2. **直接问佳农销售/客服这4个问题**
   - 是否有面向茶饮/餐饮渠道的**鲜切菠萝块**或**速冻菠萝丁**产品？
   - 是否支持**去皮切块定制**？最小起订量、规格（块/丁尺寸）、包装规格是多少？
   - 加工方式是**工厂鲜切冷链**还是**门店附近仓配鲜切**？保质期和到货温度要求？
   - 是否提供**样品、报价、质检报告和稳定供货周期**？

3. **判断是否可行的硬标准**
   - 若对方只能提供整果或罐头，不能提供鲜切/速冻切块，就不能满足你“去皮切块”的需求。
   - 若提供鲜切，必须确认**冷链到店温度、保质期、次日可用性**；茶饮店鲜切菠萝通常损耗和食品安全风险较高。
   - 若起订量远高于你门店用量，即使能做也不经济。

4. **备选方案**
   - 找当地**净菜/鲜切水果加工厂**代加工佳农菠萝，但需确认对方有果蔬加工资质和冷链。
   - 直接采购**速冻菠萝丁**或**糖水菠萝**，出品更稳定，适合茶饮标准化。
   - 若坚持鲜切，可让佳农当地经销商推荐其餐饮渠道加工商。

最稳妥的做法：联系佳农官方客服或你所在区域的经销商，明确问“**有没有茶饮渠道的鲜切/速冻菠萝切块产品，是否支持去皮切块定制**”，并索要样品和规格书。不要只问“能不能加工”，要落到产品形态、起订量、冷链和保质期上。
