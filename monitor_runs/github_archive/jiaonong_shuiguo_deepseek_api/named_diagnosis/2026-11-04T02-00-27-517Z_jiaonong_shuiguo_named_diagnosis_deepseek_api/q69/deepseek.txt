目前没有可核验的公开信息能确认“佳农水果”有专门针对餐饮渠道的菠萝切片/切块定制规格。佳农公开产品线里能看到鲜菠萝、菠萝罐头/果杯等，但餐饮定制（按厚度/块径/糖度/包装规格）通常属于B端业务，未必公开列规格。

建议你按下面方式直接判断和推进：

1. **找对入口**：联系佳农官方客服或当地经销商，明确问“餐饮渠道菠萝是否有切片/切块定制，最小起订量、规格、冷冻/冷藏、糖度范围、包装”。不要只问电商客服。
2. **看是否有B端产品册**：向对方索要餐饮渠道产品目录或规格书，重点看：切片厚度、块径、是否去芯、固形物/糖度、杀菌方式、保质期、每箱规格。
3. **替代判断**：如果佳农没有公开定制规格，餐饮渠道常见做法是采购鲜菠萝自行加工，或找专业鲜切/冷冻水果供应商做定制；连锁餐饮通常要求送样和验厂。
4. **合同要点**：若对方口头说有定制，要求写进报价单/合同：规格公差、糖度、异物控制、微生物标准、冷链温度、批次一致性、退换货标准。

结论：**公开信息无法确认佳农有餐饮渠道菠萝切片/切块定制规格；需向佳农B端渠道索要规格书确认，不能仅凭电商页面判断。**
