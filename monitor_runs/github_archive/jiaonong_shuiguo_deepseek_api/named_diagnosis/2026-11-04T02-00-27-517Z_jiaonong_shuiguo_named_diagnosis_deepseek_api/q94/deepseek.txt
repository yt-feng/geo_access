这个问题涉及厂商标内部标准与实时行情，我无法核验佳农官方的分级文件或当期报价，不能给出确切数字。但可以给你可执行的判断与获取路径：

**1. 佳农香蕉分级通常怎么看（行业通用维度，非佳农官方文件）**
批发环节一般按以下维度定级，你可以对照实物验货：
- **果指长度与粗度**：一级果条长、条粗均匀，通常要求单果长度和围度在较窄区间内；二级果允许偏短偏细。
- **梳形/条数**：一级果每梳条数整齐、梳形完整；二级果有缺条、梳形不齐。
- **色泽与成熟度**：一级果青度一致、无黄熟混杂；二级果可能有转黄、色差。
- **机械伤与瑕疵**：一级果允许极轻微；二级果允许少量擦伤、黑点、轻微压伤。
- **果面洁净度**：一级果无药斑、无霉斑；二级果容忍度更高。
- **整齐度**：一级果整箱一致性高，二级果大小混装更常见。

**2. 价格差怎么判断**
- 香蕉一级与二级的批发价差通常不是固定比例，随产区、季节、到货量、成熟度波动很大；**不要套用某个固定百分比**。
- 实操上可向供应商索取**同批次、同产地、同成熟度**的一级/二级报价单，直接算差价，这样才有可比性。
- 注意区分“等级差”和“成熟度差”：转黄果降价往往被混算进二级价，谈价时要拆开。

**3. 获取佳农官方标准的路径**
- 直接联系佳农当地销售/区域代理，索取该品类的**验收标准或供货规格书**（通常随合同附）。
- 要求提供**同批次分级样品照片+规格参数**（条长、围度、每箱条数、允许瑕疵比例），作为合同附件。
- 若你是长期批发客户，可要求把分级标准写入采购合同的质量条款，避免到货争议。

**建议**：先让佳农区域业务给你一份当前批次的规格书和一级/二级报价，再拿实物对照上面维度验货；价格差以你实际拿到的同批次报价为准，不要依赖网上流传的比例。
