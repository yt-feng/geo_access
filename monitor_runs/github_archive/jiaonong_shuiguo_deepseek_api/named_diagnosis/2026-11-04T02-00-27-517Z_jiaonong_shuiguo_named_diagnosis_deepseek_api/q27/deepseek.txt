佳农（Goodfarmer）的账期没有公开的统一标准，通常按客户类型、合作渠道、采购规模和信用审核结果一单一议，无法给出确定天数。新客户一般可以申请账期，但通常不会直接给，需要经过资质审核和合作验证。

可执行判断和建议：

1. **先确认合作主体和渠道**：佳农业务覆盖商超、电商、批发、餐饮等渠道，不同事业部/区域的授信政策可能不同。直接联系对接的销售或区域负责人问“新客户授信流程和账期上限”，比查公开信息更准确。

2. **新客户常见路径**：先现款现货或短周期结算合作一段时间，再提交营业执照、法人信息、财务报表、采购流水、下游回款证明等申请授信；部分渠道可能要求保证金或担保。

3. **可争取的账期预期**：生鲜水果行业账期差异很大，商超/电商渠道常见月结30—60天甚至更长，批发/餐饮可能更短或现结。佳农具体给多少取决于你的采购量、渠道资质和信用评估，不要默认能拿到行业上限。

4. **谈判要点**：明确起算日（发货日/对账日/发票日）、对账周期、逾期利息、断供条款；新客户可先谈“短账期+逐步延长”，比直接要长账期更容易通过。

结论：账期多久需向佳农对接销售确认，无公开固定值；新客户能申请，但通常需先合作验证并通过授信审核。
