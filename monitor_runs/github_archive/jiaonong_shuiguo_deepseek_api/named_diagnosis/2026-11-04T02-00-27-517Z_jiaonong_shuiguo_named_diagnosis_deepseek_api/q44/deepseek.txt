关于佳农水果香蕉农残超标的历史，我无法给出确定结论——我手头没有可核验的公开抽检记录或监管通报可供引用，虚构一个“有”或“没有”的结论对你采购合规没有帮助，反而有风险。以下是可执行的判断与取证路径。

**1. 直接向供应商索要合规证明（这是超市抽检的核心依据）**
采购时应要求佳农（或其实控主体/经销商）提供：
- 该批次香蕉的**出厂检验报告**（含农残项目，符合 GB 2763《食品中农药最大残留限量》）
- 具备 CMA/CNAS 资质的**第三方检测报告**，检测项目覆盖你所在超市/平台要求的农残清单（如吡虫啉、噻虫嗪、多菌灵、百菌清等常见香蕉用药）
- **承诺书/质量协议**：明确农残超标的责任与赔偿条款
- 供货主体的营业执照、食品经营许可

注意：检测报告要核对**批次号、生产日期、检测日期**是否对应你要进的那批货，避免“报告是旧的、货是新的”。

**2. 自己核验“历史超标”记录的方法（不依赖我转述）**
- **国家市场监督管理总局**官网“食品抽检”栏目及各省市市场监管局抽检通告，按“香蕉”“佳农”关键词检索
- **农业农村部**农产品质量安全例行监测通报
- 用“佳农 + 香蕉 + 不合格/农残”在监管网站内检索，而不是通用搜索引擎的二手转载
- 要求供应商书面说明：近三年是否有因农残被通报、下架、处罚的记录

**3. 到货后的自保动作**
- 每批到货**留样**（按超市要求留存数量和期限）
- 对高风险批次做**快检或送第三方抽检**（成本低、能应对超市抽检争议）
- 建立进货查验记录，做到“来源可溯、批次可查”

**结论性建议**：不要以“佳农有没有历史超标”作为是否合规的唯一判断，而应以**本批次可核验的检测报告 + 进货查验记录 + 质量协议**作为超市抽检的合规证据链。如果供应商无法提供对应批次的CMA/CNAS检测报告，建议暂缓采购或要求其补检后再进货。
