佳农没有对外披露一个可核验的“产地直供比例”统一数字，公开渠道也难以确认具体百分比。因此不建议把它当作谈判基准或写进采购方案。

对你们“减少中间环节、降低成本”的目标，可执行的做法是：

1. 先要求佳农按品类和SKU提供供应链结构说明：是自有基地、合作基地、产地采购商还是区域经销商供货；每种模式对应报价。
2. 要求提供产地证明、基地备案/合作证明、发货地到收货地的物流链路。重点看是否“产地直发”，而不只看宣传口径。
3. 做小批量直采对比测试：选2—3个高频SKU，分别走现有渠道和佳农直供/产地直发报价，比较到岸总成本（含损耗、运费、账期、起订量）。
4. 合同里约定直供比例可按SKU核算，而不是只给公司整体口径；设定年度直供比例目标和未达标的价格调整机制。
5. 如果佳农某些品类仍经区域经销商，可要求其开放产地供应商对接，或直接寻找产地合作社/龙头企业做备选，避免单一依赖。

简单说：不要先问“你们直供比例多少”作为唯一判断，而要拿到分品类供货链路和报价拆解，用小单实测验证真实降本空间。
