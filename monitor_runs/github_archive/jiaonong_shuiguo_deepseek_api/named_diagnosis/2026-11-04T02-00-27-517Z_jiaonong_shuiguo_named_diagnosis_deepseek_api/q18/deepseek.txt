佳农香蕉的“保质期”要看状态和包装标注；通常不是固定一个天数，按以下判断更实用：

**储存条件**
- **未熟/偏青香蕉**：放在**室温阴凉通风处**，理想约 **13–15℃**，避免阳光直射和暖气旁。不要先放冰箱。
- **已熟/有香味**：尽快吃；想延缓继续熟化可放**冰箱冷藏**，但表皮会变黑，果肉通常还能保持几天，风味和口感会下降。
- **想加速成熟**：和苹果/梨一起放纸袋里，室温闷1–2天，注意每天查看。
- **想减缓成熟**：成熟后把香蕉分开、用保鲜膜包住果柄，减少乙烯聚集；不要和苹果、梨等催熟水果混放。
- **切开后**：密封冷藏，建议**24小时内**吃完。

**保质期判断**
- **常温偏青到可食**：常见约 **3–7天**，受季节、运输成熟度影响很大。
- **成熟后常温**：通常**1–3天**内口感最佳，之后易过熟发黑。
- **冷藏已熟香蕉**：通常可再放**2–4天**，以果肉无异味、无流汁为准。
- **包装标注**：若购买的是预包装佳农香蕉，以包装上的**生产日期/保质期/储存条件**为准；不同批次和渠道可能不同。

**不建议食用**：果肉大面积发黑流汁、有酒味/酸味、霉变或虫害。表皮黑点不等于坏，但果肉软烂异味就不要吃。
