**可执行判断步骤（今天就能做）**：
1. 同时向佳农和洪九的成都区域销售/客服要三项书面信息：

   - 你门店地址到该仓的**配送时效承诺**（当日/次日/隔日，截单时间）；

4. 急需单品可做**双源小批量试单**：同一SKU各下最小起订量，记录下单到到店小时数，再定主供。
