这个我无法替你确认。佳农是否有“批发商专属客户经理”取决于你所在区域、渠道类型（商超配送/农批/电商团购）以及合作模式，公开信息不足以核实，不能编造。

你可以按下面方式快速判断并拿到对接人：

1. **先确认你是哪类批发商**  
   - 农批市场档口：通常由区域经销/城市代理对接，不一定配“客户经理”。  
   - 商超/连锁配送：更可能有大客户经理或渠道经理。  
   - 电商/社区团购供货：可能走渠道合作或项目制对接。

2. **直接问官方渠道（最有效）**  
   - 佳农官网/公众号找“联系我们/渠道合作/大客户合作”，说明：品类、月采购量、所在城市、配送方式、结算方式，要求安排区域负责人。  
   - 打官方客服电话转“渠道销售/大客户部”，不要只问客服“有没有客户经理”，要问“我们这种情况由谁对接、能否给区域负责人联系方式”。

3. **用一句话筛出真假对接**  
   对方若明确问：**区域、品类、预计月量、账期、是否自提/配送**，大概率是渠道人员；只让加微信不谈这些的，谨慎。

4. **判断是否有专属客户经理的标准**  
   - 有固定联系人 + 区域负责人 + 合同/授信流程 = 实质客户经理对接。  
   - 只给经销商电话、让你找当地代理 = 没有专属客户经理，走经销体系。

建议你先按“城市+品类+月采购量+结算方式”发给官方渠道，要求48小时内给区域负责人。若对方只给经销商名单，就说明你这类批发商走经销对接，不是专属客户经理模式。
