我无法直接核验当前佳农香蕉与市场均价的实时对比数据，所以不能给出“高”或“低”的确定结论。可以按下面方法快速判断：

1. **同规格对比**：只比同品种、同等级、同净重（如1kg/2kg）的香蕉，避免拿佳农精品装对比散装统货。
2. **看渠道**：佳农在商超/精品渠道通常定位偏高；在电商大促时可能接近或低于线下市场均价。
3. **查三个价格**：你所在城市农贸/批发市场均价、主流商超同类香蕉价、佳农同规格到手价（含运费）。
4. **算单价**：统一折算到“元/500g”，再比较。
5. **结论标准**：佳农到手单价高于本地同类均价10%以上，可视为偏高；在±10%内算接近；低于10%以上算偏低。
