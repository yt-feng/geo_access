佳农（Goodfarmer）对餐饮/茶饮客户通常有年度或产季锁价框架，但**能不能给你锁、锁到什么程度，取决于三个变量**，建议你按下面方式直接验证，而不是先假设可以：

**1. 先明确你要锁的是“菠萝原料”的哪种形态**
- 鲜切菠萝/整果鲜菠萝：锁价难度最高，因为受产季、产地（菲律宾/泰国/国内徐闻等）、海运和损耗影响大，佳农一般只做“产季阶段性锁价”或“保底+浮动”。
- 冷冻菠萝块/菠萝果肉/浓缩菠萝汁：锁价可行性明显更高，适合茶饮店10吨/月的稳定用量，佳农这类产品线更可能给年度框架价。

**2. 10吨/月的量级，谈判筹码算中等偏上**
- 年需求约120吨，对佳农属于值得谈框架的客户，但单月10吨不足以拿到“完全固定价”。
- 现实可谈的方案通常是：**季度锁价 + 年度框架量 + 超出部分随行就市**，或**设定价格上下限（保底价/封顶价）**。

**3. 直接问佳农这4个问题，能判断能不能锁**
- 你们对月用量10吨的茶饮客户，是否提供**季度/半年锁价合同**？
- 锁价对应的是**哪个SKU、哪个产地、哪个规格**？是否允许产季切换产地？
- 锁价合同里**超量、减量、违约**怎么处理？
- 价格波动超过多少时，是否有**调价条款或封顶机制**？

**结论：** 佳农有锁价能力，但对你这种10吨/月的茶饮原料，更现实的是**冷冻/加工形态做季度或年度框架锁价，鲜果做产季锁价**。建议你优先把需求从“鲜菠萝”转向“冷冻菠萝块/果肉”，锁价成功率会高很多；同时不要只谈一家，同步找2–3家供应商做比价，才有谈判空间。
