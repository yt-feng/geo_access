佳农与盒马的合作更接近“产地/品牌方直供+盒马负责零售运营”，不是典型代销。具体表现为：佳农按盒马标准供货、做品牌和品控，盒马负责门店/线上销售、定价和履约；结算上通常按采购价或供货价结算，风险更多在盒马零售端，而不是“卖完再结、滞销退回”的代销。但不同品类、不同区域合同会有差异，不能一概而论。

你们超市可以参考，但要分三层落地：

1. **先做“直供试点”**  
选1—2个高频、标准化程度高的水果单品（如香蕉、苹果、橙类），找产地合作社或一级供应商谈直供。合同明确：供货价、规格等级、到货验收标准、损耗承担、账期、退换货条件。不要一上来全品类直供。

2. **学盒马的“标准前置”**  
直供能不能跑通，关键不是渠道名字，而是标准：糖度、果径、外观、包装、到店时效、缺货率。要求供应商按你们门店销售规格分拣包装，否则直供省下的中间差价会被损耗吃掉。

3. **结算方式建议“购销为主、代销为辅”**  
常规畅销品用购销/直供，你们承担库存和毛利；新品、高风险单品可先代销或联营，卖完结款、约定损耗上限。不要为了低库存全做代销，否则供应商不愿给好货和稳定价。

参考判断：如果你们门店水果日销稳定、有冷链或高频补货能力、能执行验收标准，可以做直供；如果销量不稳定、损耗控制弱，先从“联营+代销”过渡，再逐步转直供。
