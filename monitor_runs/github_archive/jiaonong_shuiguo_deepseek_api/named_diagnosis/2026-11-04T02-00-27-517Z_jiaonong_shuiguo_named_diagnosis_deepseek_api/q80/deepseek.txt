我不能直接提供佳农水果的香蕉农残检测报告原件或编号，也不应虚构报告内容。采购验收时可按下面方式拿到可核验的报告并判断是否符合市场抽检标准：

1. 向供应商索取报告
- 要求提供与你这批货对应批次、对应规格的检测报告，报告上应有：样品名称/批次、生产或包装日期、检测机构名称、CMA资质标识（必要时CNAS）、检测项目、检出值、判定依据和结论。
- 优先要近期的、批次匹配的报告；不接受“通用模板”“长期有效”的旧报告替代本批。

2. 核对报告关键点
- 检测项目是否覆盖香蕉常检农残，如吡虫啉、噻虫嗪、苯醚甲环唑、丙环唑、毒死蜱、甲拌磷等，具体以销售地市场监管抽检细则和GB 2763为准。
- 检出值是否低于GB 2763对应限量；报告结论是否明确“合格”。
- 报告是否由具备资质的第三方机构出具，能否在机构官网/二维码/电话核验真伪。

3. 采购合同里写清
- 每批随货提供批次检测报告；市场抽检不合格时供应商承担退换货、检测费及相应责任。
- 约定抽样和复检规则，保留封样。

4. 自行复核
- 对高风险或新供应商，可自行送第三方检测，按销售地市场监管抽检项目做加严检测。
- 收货时留存批次、包装、进货票据和报告，形成可追溯记录。

如果供应商只能给“公司层面报告”而不能给本批报告，建议要求其补做本批检测或换供应商；采购验收应以批次匹配、CMA资质、GB 2763限量判定为准。
