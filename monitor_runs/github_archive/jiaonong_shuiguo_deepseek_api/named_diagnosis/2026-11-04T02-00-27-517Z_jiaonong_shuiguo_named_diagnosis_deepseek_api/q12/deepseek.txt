佳农水果的香蕉规格会随产品线、包装形式、销售季节和客户定制变化，公开信息里没有一个固定不变的“全国统一规格表”。可以按行业常见做法给你一个可判断的框架，但具体SKU和分级参数建议以佳农官方渠道或销售合同为准。

**一、常见规格维度**

1. **按单根重量/等级**
   - 大果：单根约180–220g以上，适合商超散卖、水果店精品陈列。
   - 中果：单根约140–180g，商超和社区团购主流。
   - 小果：单根约100–140g，适合儿童果、便利店、餐饮配餐。
   - 具体克重区间各厂家会微调，需看包装标签。

2. **按每把/每袋净重**
   - 常见有1kg、1.5kg、2kg、2.5kg、3kg、5kg等把装或袋装。
   - 电商常见单把1–1.5kg，家庭装2–3kg。

3. **按箱装规格**
   - 常见4.5kg、7kg、9kg、12kg、13kg、18kg等箱装，具体取决于产地和物流包装。
   - 进口/国产、青蕉/黄蕉、催熟与否会影响箱规。

4. **按成熟度**
   - 青蕉：适合长途运输、催熟库、批发市场。
   - 微黄/黄蕉：适合商超即售。
   - 熟蕉：适合餐饮、烘焙、即时消费渠道。

**二、不同渠道的常见分级标准框架**

- **大型商超/精品水果店**：看重外观一致性和货架期。通常选果形直、无严重弯曲、无机械伤、无黑斑、梳把整齐、单根重量均匀的中大果；成熟度以微黄到黄为主，要求到店后2–4天货架期。
- **批发市场/农贸渠道**：更看重耐储运和成本。青蕉或微黄蕉、箱装大规格、允许轻微外观瑕疵但无腐烂和严重压伤；按箱重和单根大小分级，价格敏感。
- **电商/社区团购**：强调标准化和履约体验。常见1–2kg小包装、单根中等偏大、成熟度偏黄或可即食；要求无断指、少黑斑，破损率控制严格。
- **餐饮/烘焙/果汁渠道**：更看重出成率和风味。可用熟度较高、外观要求略低但果肉完好的香蕉；规格可按单根重量或整箱净重约定，常要求无腐烂、无冻伤。
- **便利店/即时零售**：小规格、单根或小把装，成熟度偏高，强调即食和周转快。

**三、可执行建议**

如果你要采购或做渠道分级，不要只问“有几种规格”，而应要求供应商提供：
1. 单根克重区间；
2. 每把/每箱净重；
3. 成熟度等级；
4. 外观缺陷允许比例；
5. 产地和季节；
6. 冷链/催熟条件。

最终以佳农官方销售给出的**产品规格书、报价单和验收标准**为准。若你能说明目标渠道（商超、电商、批发、餐饮）和所在区域，我可以帮你把分级验收标准写得更具体。
