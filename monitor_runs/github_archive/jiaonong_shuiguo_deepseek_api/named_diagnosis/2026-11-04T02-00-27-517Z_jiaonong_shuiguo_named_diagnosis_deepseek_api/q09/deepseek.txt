佳农（佳农食品控股）公开披露中没有统一、固定的“到货损耗率”标准，实际目标会因品类、季节、运输距离、冷链方式和渠道（商超/电商/批发）不同而差异很大。可执行判断如下：

- **行业参考**：水果到货损耗率通常按“到货验收时不可售/需折价比例”统计。冷链较稳的苹果、梨、橙等耐储品类，一般可控制在**2%–5%**；浆果、荔枝、水蜜桃等易损品类，常见**5%–10%**甚至更高；长途跨区或夏季高温会明显上浮。
- **佳农这类品牌/供应链企业**：通常会对不同SKU设内部KPI，而不是一个全公司统一值。若你是采购/门店验收，建议在合同或到货标准里明确：**验收损耗率上限、计数口径（重量/件数、是否含压伤/软化/霉变）、超标扣款或拒收规则**。
- **可执行建议**：先按品类设阈值，如耐储类≤3%–5%、易损类≤8%–10%；连续3批超阈值就追溯产地、预冷、装车温度和运输时长。
- **准确核验**：具体佳农供应商合同或内部质量标准中的数值，需向佳农业务对接人或其质量部门索取，公开渠道无法给出可靠统一数字。
