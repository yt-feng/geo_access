这个我没有可靠的公开数据可以核验，不能给你编一个具体损耗率。就批发市场的实际判断，可以给你一个可执行的结论和方法：

**结论：不能简单说佳农和都乐谁更低，取决于你所在市场、到货季节、催熟和冷链方式、具体批次。** 对损耗敏感的批发商，不能只看品牌，要看“到货成熟度+批次一致性+售后”。

**实操建议：**

1. **小批量对比测试**：同市场、同季节、同样运输距离，各进1车（或各2-3批），记录：
   - 到货青硬度/成熟度
   - 开箱后24h、48h、72h的软化、黑斑、断指、掉把比例
   - 可售率和降价处理率

2. **看关键指标而不是品牌名**：
   - 到货成熟度是否适合你档口的周转速度
   - 批次一致性（同批香蕉成熟度是否整齐）
   - 冷链接力（催熟房到档口温度是否稳定）
   - 包装（箱内衬、分层、透气）
   - 售后赔付条款

3. **批发市场经验口径**：香蕉损耗高发点通常是“催熟过度+到货后温差大+周转慢”。如果档口周转在2-3天内，选到货偏青、批次整齐的更稳；如果周转快，可接受稍熟。

4. **问供应商要数据**：直接向佳农和都乐的区域经销/厂家业务要“近3个月你所在城市同规格香蕉的到货损耗率/客诉率”，要求按批次给，不要只听口头。

5. **谈判条款**：先签短期试销，约定到货损耗超过约定比例（比如3%-5%，按你实际测试定）由供方补货或折价。
