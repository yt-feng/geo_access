佳农香蕉通常采用**乙烯（或乙烯利）人工催熟**，不是单纯自然熟。商超要控制催熟时间，建议按以下操作：

1. **先确认到货状态**  
   向佳农业务或包装箱标注确认：是“青蕉/催熟前”还是“已催熟可售”。同一品牌不同批次、不同季节可能不同。

2. **商超端催熟控制要点**  
   - 温度：一般 **15–18℃** 催熟较稳，低于13℃易冷害，高于20℃成熟过快。  
   - 湿度：**85%–90%**，避免果指失水。  
   - 乙烯处理：若到货为青蕉，按供应商SOP使用乙烯催熟，通常分次、低浓度处理，不要自行高浓度密闭。  
   - 通风：乙烯处理后及时通风，避免二氧化碳积累。  
   - 时间：青蕉到可售通常需 **3–7天**，取决于青度、温度、乙烯方案；已催熟蕉一般 **1–3天** 内转黄，需按色卡分级上架。

3. **可执行判断标准**  
   用香蕉色卡控制：目标上架色号通常为 **3–4号**（黄多于绿），促销可到5号；每天记录温度、色号、乙烯处理时间。  
   若出现“青硬不变黄”，先排查冷害和乙烯浓度；若“黄快但果肉生”，多为温度过高或催熟过快。

4. **最稳妥做法**  
   要求佳农提供该批次的**催熟工艺说明和到货成熟度**，商超只做后熟管理，不重复催熟。这样催熟时间可控，也能减少货损。
