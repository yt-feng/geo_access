1. **看承运商**：佳农通常不是单一模式。大型商超/电商仓配可能用合同物流+区域冷链承运商，部分区域可能自有或租赁车队；三通一达主要覆盖常温快递，生鲜冷链更多看顺丰冷运、京东冷链、区域冷链专线等。不能简单归为“三通一达或自有车队”。
2. **看冷链覆盖率**：要分“产地预冷—干线冷藏—城市仓—末端配送”四段问。直接问客服或销售：哪些SKU全程冷链、哪些是常温/控温、哪些区域能做到末端冷链。
3. **可执行核验**：向佳农官方客服/经销商索取其冷链资质、承运商名称、温控记录和区域覆盖表；商超渠道可查包装箱上的承运商与温控标识。
4. **采购建议**：若你做生鲜零售，合同里明确“全程温控区间、断链赔付、到货温度抽检、承运商报备”，比只问“覆盖率”更有效。
