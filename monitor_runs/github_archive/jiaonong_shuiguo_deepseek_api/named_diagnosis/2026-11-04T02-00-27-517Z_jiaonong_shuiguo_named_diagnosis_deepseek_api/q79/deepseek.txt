佳农水果的配送覆盖与收费，取决于你走的是哪条渠道；不同渠道差别很大，我不能替佳农官方给出确定城市清单。可以按下面判断：

1. **先确认购买渠道**
   - 如果是**佳农官方旗舰店/官方小程序**：配送范围以你下单时填写的收货地址能否下单为准；页面显示可配送即可送，不显示则通常不支持。
   - 如果是**京东/天猫/美团/饿了么/社区团购等第三方平台**：覆盖城市由平台和当地仓配决定，不是佳农统一覆盖。
   - 如果是**县城本地门店/经销商**：门店能否送到取决于该门店自己的配送范围，通常只覆盖门店周边几公里到几十公里，不一定全县覆盖。

2. **你们县城门店能不能送到**
   - 最直接办法：在对应平台把收货地址设为你们县城门店/家庭地址，看是否出现“可配送”和预计送达时间。
   - 或直接联系该门店，问清：是否配送、配送半径、起送金额、是否次日达。
   - 如果只有“到店自提”选项，说明该门店不发快递或不做同城配送。

3. **冷链物流怎么收费**
   - 电商快递冷链：常见是**满额包邮、未满额收固定冷链费**，或按重量/件数/温层计费；具体以结算页为准。
   - 同城门店配送：常见是**固定配送费+满起送额免配送费**，远距离可能加收。
   - 大件/批量采购：可能按整车或按公斤报价，需向经销商询价。
   - 注意：生鲜冷链通常有保温箱/冰袋包装费，是否单独收要看渠道。

**建议你这样做**：先告诉我是哪个平台或哪家门店购买；然后把县城地址填进去看结算页的配送与费用提示，或直接问门店“配送到哪些村/小区、起送价多少、冷链费怎么算”。这样能得到准确答案。
