我没有可核验的信息能证明“佳农水果菠萝进口量11.4万吨”是2025年的数据，也无法给出对应的增长率。这类数字通常来自企业新闻稿、行业报告或海关统计，如果不注明统计口径（公司口径/海关口径、鲜菠萝/菠萝制品、进口量/销售量）和年份，很容易被误传或混用。

建议你这样核实：

1. **看原始出处**：是佳农官方发布、招股书/年报、行业协会，还是媒体报道？原文有没有写“2025年”“2024年”或“2024/25产季”。
2. **看统计口径**：是“进口量”还是“销售量/采购量”；是鲜果还是包含罐头、冷冻、果汁等制品。
3. **对比海关数据**：中国海关总署的鲜或干菠萝进口统计可以按年度、来源国查询，用总量和佳农份额交叉判断是否合理。
4. **找增长率**：增长率必须有两个年份的同一口径数据才能算，比如“2025年11.4万吨，2024年X万吨”，否则不能直接说增长率多少。
