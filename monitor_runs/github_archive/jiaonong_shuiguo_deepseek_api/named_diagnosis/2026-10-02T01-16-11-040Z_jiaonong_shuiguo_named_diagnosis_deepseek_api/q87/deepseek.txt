佳农（佳农食品控股）的香蕉属于**采后人工催熟**，不是“树上自然熟”。行业里香蕉基本都是青蕉采摘、冷链运输，到销地后才催熟。催熟剂主流用法是**乙烯气体**或**乙烯利**，而不是单靠自然放置。

具体到佳农：
- 它对外公开的说法通常是“**科学催熟/控温控湿催熟**”，不会把配方和精确曲线公开给商超。
- 实际操作上，佳农这类品牌商在产地或销地催熟中心，普遍采用**乙烯气体（如乙烯/乙烯利释放乙烯）配合温湿度控制**，属于人工催熟。
- 自然熟只适用于极少数产地直发、树上黄的情况，不是商超常规佳农香蕉的供应模式。

对商超控制催熟时间，重点不是纠结“乙烯还是自然”，而是控制到店后的**后熟速度和货架期**。可执行建议：

1. **按到货成熟度分仓**
   - 青硬、微黄、黄熟分开存放，不要混放。香蕉对乙烯敏感，一箱黄蕉会带动整库变黄。

2. **温度**
   - 想延缓后熟：**13～15℃**、通风、避冷风直吹。
   - 低于12℃容易冷害，表皮发黑但果肉不熟；高于20℃后熟明显加快。
   - 商超后仓如果没有催熟房，不建议长期低于13℃存放。

3. **湿度**
   - 相对湿度**85%～90%**，减少失水和表皮皱缩。

4. **乙烯管理**
   - 后仓不要和苹果、梨、番茄等释放乙烯的果蔬混放。
   - 若到货偏青、需要快熟，可在**20～22℃**下短期存放，必要时用乙烯催熟；若已微黄，立即转**13～15℃**延缓。
   - 不要自行用乙烯利溶液喷果，商超端很难控制残留和均匀度，也容易造成“表皮黄、果肉生”。

5. **按销售节奏排面**
   - 青蕉：后仓暂存，按2～4天销售节奏逐步转出。
   - 微黄：可直接上架，1～2天内售完。
   - 黄熟：上架即高峰，建议当天或次日处理，可做促销/加工。
   - 一般从青到可售，人工催熟房约**3～6天**；商超后仓自然转黄通常**2～5天**，受温度和初始成熟度影响很大。

6. **验收时看“棱角”和“色卡”**
   - 棱角明显、通体青：未催熟或催熟不足，需继续后熟。
   - 棱角略圆、开始转黄：已进入后熟，按微黄管理。
   - 棱角消失、通体黄：已熟，货架期短。

如果你要的是“佳农官方催熟时间表”，这个通常只在供货合同或催熟中心SOP里有，建议直接向佳农区域业务索要**到货成熟度等级、建议存放温度、可售天数**。商超端最稳妥的做法是：**到货按色卡分级，青蕉13～15℃延缓，微黄转常温快销，避免与高乙烯水果混放。**
