一般来说，像佳农这种做水果供应链和批发业务的公司，对批发商客户通常会有渠道销售或客户经理对接，但具体有没有“专门”的客户经理，取决于你的采购规模和合作方式。

你可以这样判断和推进：

1. **如果你已经是稳定批发客户**
   - 月采购量较大、品类集中、账期或长期合作，通常会有对应销售经理或渠道负责人对接。
   - 可以直接问现在对接你的业务员：是否由专人负责你们，还是统一走区域销售。

2. **如果你还没正式合作或量不大**
   - 可能先由区域销售、渠道专员或客服统一对接，不一定会立刻配专属客户经理。
   - 等采购量上来后，再申请专属对接人更现实。

3. **怎么找到对接人**
   - 通过佳农官方客服、官网、公众号或当地分公司，说明你是批发商，提供：所在城市、采购品类、预计月采购量、是否自提/配送、结算方式。
   - 要求转接“批发渠道销售”或“区域客户经理”。

4. **对接时直接问清楚**
   - 是否有专属客户经理
   - 响应时间
   - 报价和账期政策
   - 缺货、售后、退换货由谁负责

简单说：**大概率有销售对接，但“专门客户经理”通常看采购量。量够大，可以主动要求配专人。**
