佳农的售后整体算比较规范，但具体体验取决于购买渠道。核心判断：**官方旗舰店/自营渠道最有保障，第三方店铺和线下渠道差异较大。**

## 到货有坏果怎么处理

一般流程是这样：

1. **拍照留证**：坏果和包装箱/快递面单一起拍，最好拍清楚数量。多数平台要求有图才能受理。
2. **尽快申请**：生鲜类通常有明确时效（常见是签收后24小时内，部分48小时），越早越好，别拖。
3. **走对应渠道**：
   - 天猫/京东旗舰店、抖音旗舰店：直接在订单里申请"售后/退款"，上传照片，说明坏果数量。
   - 社区团购、商超、水果店：找购买门店处理，规则各不同。
4. **结果通常是**：按坏果比例部分退款，或补发。坏得多的可能整单退。

## 需要注意的几点

- **佳农不同渠道售后不是一回事**。品牌方对授权渠道的售后有支持，但你在第三方小店买的，执行标准可能完全不一样。
- **成功率高的关键**是证据清晰、及时、数量对得上。模糊照片或拖延容易被拒。
- **生鲜一般不支持无理由退货**，只针对质量问题（腐烂、压坏、变质）赔付，这点要有预期。
