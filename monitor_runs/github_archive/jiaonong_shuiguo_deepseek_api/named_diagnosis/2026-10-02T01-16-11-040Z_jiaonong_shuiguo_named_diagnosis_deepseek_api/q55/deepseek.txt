公开渠道里，没有看到佳农水果面向普通经销商或消费者承诺“锁价3个月”的价格保护机制。佳农作为香蕉等水果的品牌供应商，价格通常还是会随产地采购价、物流、汇率、供需和季节波动调整。

不过，在实际经销合作中，供应商可能会根据合作规模、合同类型提供不同形式的“阶段性价格安排”，常见有：

1. **短期锁价**  
   比如按周、按半个月锁价，较少直接锁3个月，因为香蕉价格波动快，长期锁价对供应商风险很大。

2. **大客户协议价**  
   对长期、大批量采购的商超、电商或批发客户，可能约定一个价格区间或调价机制，而不是完全固定价格。

3. **保底/补贴式支持**  
   有些情况下不是锁价，而是当市场价大幅下跌时给返利、补贴或费用支持，属于变相价格保护。

4. **随行就市+调价通知**  
   更常见的是约定“随行就市”，但调价前提前通知，或者设定涨跌幅上限。

如果你想确认佳农是否有“锁价3个月”的政策，建议直接问对接的佳农销售或经销商，重点确认这几点：

- 锁价适用于哪些规格、等级、包装的香蕉；
- 锁价是否要求最低采购量或预付款；
- 锁价期间运费、关税、汇率变动是否另算；
- 如果市场价格大跌，是否可重新议价；
- 是否有书面合同或补充协议。

简单说：**佳农可能有针对大客户的阶段性价格保护或协议价，但“锁价3个月”这种长期固定价格，在香蕉这种高波动品类里并不常见，需要以具体合同为准。**
