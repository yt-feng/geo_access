佳农（包括佳农食品控股/佳农鲜果）**有没有锁价合同，取决于你谈的是鲜果还是冷冻/罐头/果浆类原料，以及签约主体和采购量**。我不能替你确认佳农当前的具体政策或报价，但可以给你一套可执行的判断和谈判路径。

## 先分清你买的是哪类菠萝原料

不同形态，锁价可行性差别很大：

- **鲜菠萝（整果）**：受产季、产地、天气、海运影响大，长期锁价难度最高，通常只能锁一个产季或几个月的价格，且会设量、等级、供货窗口等条件。
- **冷冻菠萝/菠萝丁/果浆/浓缩汁**：相对容易做阶段性锁价或“基价+调价机制”，因为可囤货、可提前加工。
- **罐头/糖水菠萝**：标准化程度高，锁价相对可行，常见按季度、半年或年度框架+分批下单。

你每月10吨，年需求约120吨。这个量在佳农体系里不算特别大，但如果是单一SKU、稳定月度提货，是有谈判空间的；如果分散在多个规格、多个产地、临时追加多，锁价意愿会明显下降。

## 佳农这类供应商通常不会“无条件锁死价格”

现实中更常见的是这几种合同形式，你可以主动提：

1. **固定价+固定量+固定提货节奏**
   - 例如锁6个月，每月10吨，价格固定。
   - 但通常会要求你承担最低提货量，未提货也按约付款或扣保证金。

2. **基价+浮动条款**
   - 约定基准价，再挂钩某个公开指标（如产地收购价、汇率、海运指数）。
   - 涨跌超过一定幅度才调价，比如±5%以内不调。

3. **区间锁价/封顶价**
   - 约定一个价格上限，市场跌了你按市场价，市场涨了不超过封顶价。
   - 对采购方比较友好，但供应商可能要求你接受略高的基准价。

4. **期货/远期+现货补充**
   - 一部分量锁价，一部分随行就市。
   - 适合你这种每月10吨、又怕波动的店，建议锁70%–80%，留20%–30%灵活补货。

## 你可以直接这样去谈

联系佳农时，不要只问“能不能锁价”，要带着条件问：

> 我们茶饮店每月稳定采购菠萝原料10吨，年度约120吨，规格是XXX，提货地是XXX，账期是XXX。希望签6个月或12个月框架合同，其中70%–80%的量做固定价或封顶价，剩余随行就市。请确认你们能不能做、按哪个主体签、锁价对应哪个产地和规格、最小起订量和违约条款是什么。

同时要求对方书面给出：

- 锁价对应的是**哪个具体产品规格**，不是笼统“菠萝”；
- 锁价有效期；
- 月度最低提货量和未完成提货的处理；
- 质量等级、糖度、包装、解冻/出成率标准；
- 如果产地歉收，供应保障和替代方案；
- 调价触发条件；
- 付款方式和保证金要求。

## 更稳妥的做法

不要只依赖佳农一家锁价。建议：

- **主供应商锁量锁价70%–80%**；
- **备用供应商拿现货或短约**，防止断供；
- 如果你们有冷库，可在菠萝低价季适度囤冷冻原料；
- 如果用量稳定，可以考虑和加工厂直接签年度框架，而不只是贸易商。

## 结论

佳农**有可能谈成锁价合同，但通常不是简单“一口价锁死”**，更可能是阶段性固定价、封顶价或基价+浮动。你每月10吨、年度120吨，具备一定谈判基础，但关键要看你是鲜果还是冷冻/加工品、规格是否统一、能否接受最低提货量和保证金。

建议你先向佳农要一份**框架合同草案或报价条款**，再拿这个去对比第二家供应商。这样你才能判断它给的锁价是不是真能帮你扛住波动。
