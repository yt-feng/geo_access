佳农（Goodfarmer）并未在公开渠道披露统一的“产地直供比例”，我无法给出可核验的准确数字。这类比例通常按品类、季节、销售渠道和年份变化，且属于企业供应链内部数据，公开资料里一般不会写。

对你们采购来说，更实际的做法不是追一个总比例，而是按单品把中间环节拆开核算。可执行建议如下：

1. **按品类分别问**
   香蕉、菠萝、火龙果、车厘子、蓝莓等供应链差异很大。
   香蕉、菠萝这类佳农优势品类，产地直采/基地合作比例通常较高；进口水果和反季节水果可能仍要经过出口商、进口商、口岸经销商。

2. **要求供应商提供链路说明**
   直接问：
   - 是佳农自有基地、合作基地，还是市场采购？
   - 国内产地发货，还是进口后分销？
   - 经过几手？每一手加价多少？
   - 能否提供产地证明、报关单、检疫证、装箱单、发票流。

3. **对比三种采购模式**
   - **产地直发**：价格可能低，但起订量大、履约波动大、售后责任要写清。
   - **区域配送仓**：加价少一些，适合多门店、小批量、高频补货。
   - **批发市场/经销商**：灵活但中间环节最多，价格通常最高。

4. **用成本公式判断是否值得直供**
   不要只看采购单价，要算：
   `综合成本 = 采购价 + 物流 + 损耗 + 账期资金成本 + 质检 + 售后 + 缺货风险成本`
   如果直供价低 5%，但损耗和物流高 8%，实际并不省钱。

5. **谈判时设定可验证指标**
   可以要求佳农或供应商承诺：
   - 单品直采比例或基地来源比例；
   - 每批次可追溯到具体产地/加工厂；
   - 年度阶梯返利、账期、损耗赔付；
   - 旺季优先供货和锁价机制。

6. **先做小范围试单**
   选 1—2 个单品、1—2 个区域，试 1—2 个月，对比直供、区域仓、经销商三种渠道的到岸成本和履约率，再决定是否扩大。

如果你们的目标是“减少中间环节、降低成本”，最有价值的动作是：**让佳农按单品给出供应链链路和报价构成，而不是只问一个总体直供比例。** 如果你告诉我你们主要采购哪些单品、月采购量和收货城市，我可以帮你列一份具体的询价和谈判问题清单。
