佳农水果（上海佳农食品集团）主要做香蕉、菠萝、火龙果等进口水果的批发和供应链业务，客户以商超、电商、水果连锁和二级批发商为主。

关于账期，我只能给你一般性的行业参考，无法保证是佳农官方的现行政策：

**账期一般是多久**
- 水果批发/供应链行业对新客户通常以**现款现货、款到发货**为主，这是最常见的起步方式。
- 合作稳定后，常见账期在**7天、15天、30天**之间，具体看客户类型、采购规模和公司政策。
- 商超、大型电商等渠道因为本身结算周期长，上游给的账期也可能相应拉长，但会配套合同和信用评估。

**新客户能不能申请**
- 理论上是**可以谈的**，但新客户一般很难直接拿到长账期。
- 通常路径是：先现款合作一段时间 → 建立采购记录和信用 → 再逐步申请短账期（如7天/15天）。
- 能否批下来，主要看：公司资质、注册资本、采购量、历史合作记录、是否有担保或抵押。

**最靠谱的做法**
直接联系佳农的**销售或大客户部**，问清楚：
1. 新客户的首单结算方式；
2. 达到什么条件可以申请账期；
3. 账期具体天数和是否需要保证金/担保。

因为账期属于商业信用政策，会随客户情况、时间、区域变化，网上搜到的数字不一定准。建议以佳农官方业务人员给的答复为准。
