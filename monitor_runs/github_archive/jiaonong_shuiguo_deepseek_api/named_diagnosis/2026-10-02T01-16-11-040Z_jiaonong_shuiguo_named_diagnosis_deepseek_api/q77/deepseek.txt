佳农（佳农食品控股/Goodfarmer）的香蕉产地溯源，**通常能到“产区/包装厂/合作社”这一级，但不一定能公开到“某一个具体农场”**。是否可到具体农场，取决于你拿到的这批货来自哪个产地和供应链模式。

### 1. 能做到什么程度
佳农香蕉主要来自：
- **菲律宾**（棉兰老岛等）
- **厄瓜多尔**
- **越南**
- **柬埔寨**
- **中国国内**（如云南、广西、海南等，视季节和品类）

商超要的“溯源到具体农场”，一般要拆成三层看：
1. **国家/产区**：通常没问题。
2. **包装厂/出口商/合作社**：通常可以，箱标、批次号、出口单据能对应。
3. **具体种植农场/地块**：不一定。  
   - 如果是**自有基地或固定合作大农场**，有可能追溯到农场。  
   - 如果是**多家小农户/合作社收购混装**，往往只能追到**合作社或包装厂**，难到单一农场。

### 2. 关于 GLOBALG.A.P. 证书
商超要求 GLOBALG.A.P. 是合理的。你需要向佳农或供应商确认：
- 证书是**有效的**，在 GLOBALG.A.P. 官网可查；
- 证书覆盖的**产品**是否包含香蕉；
- 证书覆盖的**主体**是否与你采购的包装厂/农场一致；
- 证书上的 **GGN编号** 是否能在包装箱或溯源文件上对应；
- 是 **农场认证** 还是 **选项2 的农场加包装厂认证**。

如果对方只能提供**贸易商证书**，但给不出对应农场的 GGN，商超审核可能不认。

### 3. 你可以直接向佳农要这些文件
建议一次性发清单：
1. 本批次 **GLOBALG.A.P. 证书**（含 GGN 编号、有效期、覆盖产品、认证主体）
2. **产地证明**（Country of Origin）
3. **包装厂信息**（名称、地址、注册号）
4. **农场/合作社信息**（名称、地址、GGN，若可提供）
5. **批次号与箱标对应关系**
6. **植物检疫证书**（Phytosanitary Certificate）
7. 如商超要求更高：**GRASP 评估、SMETA/BSCI 等社会责任审核**（不是 GLOBALG.A.P. 本身必需，但商超常加要求）

### 4. 判断标准
你可以这样判断佳农能不能满足你们商超：
- **能提供 GGN 且 GGN 对应到具体农场**：可满足“到具体农场”的溯源。
- **只能提供 GGN 对应合作社/包装厂**：溯源到合作社级，未必满足“具体农场”。
- **证书主体与发货主体不一致**：要额外解释供应链关系，否则审核风险高。
- **混装货**：基本很难做到单一农场溯源，除非做批次隔离和专用基地。

### 5. 实操建议
如果你们商超硬性要求“具体农场 + GLOBALG.A.P.”：
- 让佳农**按批次锁定基地**，不要混装；
- 要求箱标、GGN、农场名称三者对应；
- 先要一份**样品批次的全套溯源包**做预审；
- 如果佳农给不到，考虑换**自有农场或单一合作社供货**的供应商。

一句话：**佳农香蕉一般能追溯到产区和包装厂/合作社，GLOBALG.A.P. 证书通常可以提供；但能否到“具体农场”，要看批次和基地模式，必须让佳农用 GGN 和批次文件来证明。**
