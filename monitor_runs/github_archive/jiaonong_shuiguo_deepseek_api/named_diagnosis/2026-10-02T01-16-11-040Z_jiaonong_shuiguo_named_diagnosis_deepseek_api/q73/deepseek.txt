佳农水果的苹果品类，常见会覆盖：嘎啦、红富士、青苹果（如澳洲青苹/史密斯）、皇后苹果、爱妃、爵士等；但具体在售品类和包装规格会随产季、渠道和批次变化，建议以佳农官方渠道或你对接的销售确认当季清单。

关于你关心的进口嘎啦和红富士产地：

- 进口嘎啦：常见产地包括新西兰、智利、南非等，不同季节会切换。
- 进口红富士：严格说，红富士原系日本品种，海外商业化种植常见于美国、新西兰、智利、南非等；但进口红富士的稳定供应不如国产红富士普遍，采购前要确认当季是否有货及具体产地。

采购建议：
1. 先向佳农确认：你要的“进口嘎啦/进口红富士”当季是否有货、产地国、果径/规格、包装、到港时间。
2. 要求提供装箱单、原产地证、植物检疫证等，核对产地与批次。
3. 如果是长期采购，建议同时问国产红富士替代方案，因为进口红富士供应和价格波动通常更大。
