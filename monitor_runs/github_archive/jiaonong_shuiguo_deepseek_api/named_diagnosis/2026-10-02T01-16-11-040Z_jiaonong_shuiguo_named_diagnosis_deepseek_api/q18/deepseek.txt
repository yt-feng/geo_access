佳农香蕉的包装或官方渠道通常不会给出一个固定的“保质期天数”，因为香蕉是呼吸跃变型水果，保质期主要取决于**买到时的成熟度**和**储存温度**。可以按下面判断和执行：

**常见储存条件**
- **未熟/偏青香蕉**：放在**室温、阴凉通风处**，约 **18–22℃** 最合适，避免阳光直射和暖气旁。通常可放 **3–7天** 逐渐转黄。
- **已熟/全黄香蕉**：室温下通常还能放 **1–3天**；如果已经出现糖斑，建议 **1–2天内** 吃掉或加工。
- **想延缓成熟**：成熟后可放冰箱**冷藏室蔬果层**，约 **4–8℃**。冷藏后香蕉皮会变黑，但果肉通常还能保持几天，建议 **3–5天内** 吃完。不要冷冻整根带皮香蕉，除非准备做冰沙/烘焙。
- **想加速成熟**：和苹果或已熟香蕉一起放进纸袋，室温放置。

**关键注意**
- **不要放进密闭塑料袋**，容易闷坏、发霉。
- **不要和苹果、梨等释放乙烯的水果长期混放**，会加速香蕉成熟。
- 出现**明显酸味、酒味、渗液、霉点、果肉发黑软烂**就不要吃了。
- 佳农如果是**整串原包装**，按包装上的储存说明优先；若是已切开的鲜切香蕉，必须冷藏并尽快食用，通常当天到次日吃完。

**一句话建议**：青香蕉室温催熟，黄香蕉尽快吃；吃不完的熟香蕉冷藏可多撑几天，但皮黑不代表坏，重点看果肉和气味。
