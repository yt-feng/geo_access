佳农水果的配送和冷链收费，需要分情况看，我直接给你可操作的判断方法：

**1. 配送覆盖城市**
佳农（佳农食品控股）主要是水果供应链企业，业务分两块：
- **B端批发/供应链**：给商超、生鲜店、电商仓配货，覆盖全国大部分一二三线城市，但具体到某个县城要看当地有没有经销商或配送商。
- **C端零售**：佳农在部分城市通过自有渠道或合作平台（如京东、美团、盒马、叮咚等）卖货，但**没有统一的“全国县城直达”配送网络**。

**2. 你们县城门店能不能送到**
不能一概而论，关键看：
- 你的门店是**加盟/合作门店**还是普通消费者下单；
- 当地有没有佳农的**经销商、城市仓或合作物流**；
- 你走的是**佳农官方渠道**还是**第三方平台**。

最直接的办法：打佳农官方客服电话（可在其官网或包装上找到），报你的**县城名称+门店地址**，问是否在配送范围。或者问对接的业务员/经销商，他们最清楚当地能不能送、起送量多少。

**3. 冷链物流怎么收费**
佳农没有公开统一的冷链收费标准，通常按这几种方式计费：
- **按重量/件数**：比如每公斤或每箱加收冷链费；
- **按里程/区域**：同城、跨市、跨省价格不同；
- **按订单金额**：达到一定金额免冷链费，否则加收；
- **整车/零担**：量大走整车，量小走零担拼车，单价更高。

具体费用要问当地经销商或佳农业务，因为冷链成本受距离、温度要求（保鲜/冷冻）、货量、是否需装卸影响很大。

**建议你这样做：**
1. 先确认你是**门店进货**还是**个人购买**；
2. 打佳农官方客服，报县城和门店地址，问配送和冷链报价；
3. 如果官方不直达，问当地有没有经销商或批发市场能供货；
4. 对比第三方冷链（如顺丰冷运、京东冷链）的报价，看哪个更划算。
