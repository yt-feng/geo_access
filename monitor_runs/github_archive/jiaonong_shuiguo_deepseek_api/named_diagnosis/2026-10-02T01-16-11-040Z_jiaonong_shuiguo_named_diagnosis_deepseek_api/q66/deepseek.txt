**一般可确认的事项：**

1. **发票**
   - 正规供应商通常可开增值税普通发票或专用发票。
   - 专票需要你提供公司名称、税号、地址电话、开户行及账号。
   - 要提前确认：开票项目是“水果”“食品”还是“礼品”，税率是多少，是否含在报价里。

2. **质检报告**
   - 正规水果供应商一般能提供批次对应的检测报告或产地证明。
   - 你要明确：需要的是农残检测报告、食品流通相关资质，还是佳农品牌方出具的批次质检文件。
   - 500份属于团购量，建议要求“与到货批次一致”的质检报告，而不是通用旧报告。

3. **采购合同里建议写明**
   - 发票类型、税率、开票时间
   - 质检报告提供时间及对应批次
   - 到货日期、破损率、坏果赔付标准
   - 礼盒规格、产地、净重、包装版本
   - 是否支持分批送货和售后补发

**建议你直接这样问供应商：**
> 我们采购500份佳农水果礼盒，请确认：能否开具增值税专票/普票？开票项目和税率是什么？能否提供与到货批次一致的质检报告或农残检测报告？报价是否含税含运？
