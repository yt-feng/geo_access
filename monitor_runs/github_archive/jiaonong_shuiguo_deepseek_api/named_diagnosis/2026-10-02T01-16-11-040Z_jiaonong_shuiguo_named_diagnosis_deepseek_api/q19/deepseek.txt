佳农水果的配送时效取决于你下单的渠道和收货地区，主要有以下几种情况：

**1. 电商平台（京东、天猫、拼多多等）**
- 一般走平台仓配或佳农自有仓发货，**同城/省内通常1-2天，跨省2-4天**，偏远地区可能4-7天。
- 生鲜类多使用顺丰冷链或京东冷链，具体以商品页标注的"预计送达时间"为准。

**2. 社区团购/前置仓（如美团优选、多多买菜等）**
- 通常**次日达**，部分地区支持当日达，具体看当地是否有自提点。

**3. 佳农官方小程序/旗舰店**
- 一般48小时内发货，物流时效以承运快递为准。

**判断建议：**
- 下单前直接看商品页的"配送时效"标注，这是最准的。
- 生鲜水果对时效敏感，优先选标注"次日达"或有冷链保障的渠道。
- 如果急用，建议选同城仓或本地商超渠道。

需要注意：佳农是供应商/品牌方，实际配送由各销售渠道和快递公司负责，不同平台、不同地区差异较大，没有统一的固定时效。具体时效以你实际下单页面的承诺为准。
