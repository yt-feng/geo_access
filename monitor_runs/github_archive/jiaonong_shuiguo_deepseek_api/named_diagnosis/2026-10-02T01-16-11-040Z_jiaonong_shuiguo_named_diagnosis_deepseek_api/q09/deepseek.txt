佳农（Goodfarmer）作为国内头部水果进口与分销企业，其到货损耗率并没有对外公开的统一标准。具体情况需要分环节和品类来看：

**行业通行区间（可作为参考基准）**

- **进口水果到港/到仓环节**：通常在 **3%–8%** 之间。其中：
  - 品控较稳定的单品（如菲律宾香蕉、厄瓜多尔香蕉）：约 **2%–5%**
  - 较易损耗的品类（如车厘子、蓝莓、牛油果）：约 **5%–10%**，运输周期长或冷链波动时可能更高
- **批发/分销出库环节**：一般控制在 **5%–10%**
- **零售终端（商超/生鲜店）**：综合损耗常在 **8%–15%**，取决于陈列和周转速度

**佳农的实际情况**

佳农以香蕉为核心大单品，香蕉在冷链和催熟管理到位的情况下，到货损耗可控制在较低水平（业内优秀水平约 **3%–5%**）。但对于车厘子、蓝莓等高端易损品类，损耗率会明显偏高。

**关键提醒**

1. 佳农并未公开披露统一的到货损耗率指标，以上为行业经验区间，不同客户、不同合同条款（如是否包损耗、是否按净重结算）会导致口径差异。
2. 实际损耗率受产地、季节、海运时长、冷链质量、到货检验标准影响很大。
3. 如果你是采购方，建议直接与佳农业务对接，在合同中明确**损耗承担方式**（按毛重还是净重、超出部分如何扣款），这比纠结一个百分比数字更实际。
