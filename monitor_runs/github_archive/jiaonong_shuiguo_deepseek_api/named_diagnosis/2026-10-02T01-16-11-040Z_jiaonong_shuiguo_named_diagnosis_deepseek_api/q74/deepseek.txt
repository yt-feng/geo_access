**账期45天**

佳农（主要做香蕉、菠萝、火龙果等进口/产地水果）给商超的常规账期一般在**15–30天**，新客户首签往往更短（现款或7–15天）。要拉到45天，通常需要满足其一：

- 年采购额足够大（单品类达到区域大客户级别）
- 有历史合作记录、回款无逾期
- 能提供担保、保证金，或接受"阶梯账期"——比如前3个月30天，稳定回款后再延到45天

所以别一上来死磕45天，可以先谈**30天起、达标后自动升到45天**，成功率更高。同时问清对方结算方式（现结/月结/承兑），承兑本身占用的资金成本也要算进去。

**首批铺货支持**

首单支持一般不是白给，常见几种形式，你可以组合着谈：

- **首单账期延长**（比如首单60天，之后回归正常）
- **搭赠**：进10箱送1箱之类的铺底
- **铺市费用/陈列费**：用于端架、堆头、促销
- **滞销调换**：首单滞销可换货，降低你的试错风险
- **联合促销**：佳农出部分费用做开业或档期活动

对供应商来说，新客户首单风险最大，所以他们更愿意给"货的形式"支持，而不是直接降价或放账期。你可以优先争取搭赠+滞销调换，这两个对他们成本可控、对你也实在。

**谈判建议**

1. 先报一个体量预期（门店数、单店月销、年采购额），这是你唯一的筹码，越具体越好。
2. 账期和支持分开谈，别绑一起，否则容易被整体压。
3. 准备好你的回款能力证明（流水、其他供应商合作记录）。
4. 争取把"达标升账期"写进合同，别只停留在口头。
