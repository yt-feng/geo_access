我无法核实佳农当前是否有“冷冻菠萝丁”这一具体SKU及其规格，不能凭空给结论。建议你按下面方式快速确认，通常10分钟内能问清：

**1）直接找佳农官方渠道确认**
- 佳农官网/官方公众号/官方客服电话
- 佳农在当地的经销商或冷链食材批发商
- 如果你在 B2B 平台（如美菜、蜀海、锅圈供应链等）看到“佳农菠萝丁”，也要让供应商提供**品牌授权或进货凭证**

**2）问供应商时必须确认这6项**
1. **是否冷冻菠萝丁**：冷冻 IQF 还是冷冻糖水菠萝丁，两者用途不同  
2. **规格**：丁径常见有 5×5mm、8×8mm、10×10mm、15×15mm 等；问清是**边长**还是**筛网规格**  
3. **包装**：1kg/袋、2.5kg/袋、10kg/箱等  
4. **固形物/糖度**：是否加糖、糖水浓度、解冻后出水情况  
5. **产地与品种**：是否为佳农品牌、原料产地、加工厂  
6. **起订量、价格、冷链、保质期**

**3）茶饮店选品建议**
- 做**果茶小料**：优先选 **8×8mm 或 10×10mm IQF 冷冻丁**，颗粒感明显，出杯稳定  
- 做**冰沙/打碎饮品**：可选 **5×5mm 或更小**  
- 如果用于**装饰或咀嚼感**：选 **10×10mm 以上**
- 重点测试：**解冻后是否软烂、是否出水、是否发酸、是否有纤维渣**

**4）替代方案**
如果佳农没有冷冻丁，可以找：
- 佳农的**冷冻菠萝块/菠萝片**，到店后自己切丁
- 其他冷冻水果供应链品牌：如百果园供应链、鑫荣懋、鲜丰、蜀海、美菜等渠道的冷冻菠萝丁
- 直接找**冷冻水果加工厂**定制规格，通常可做 5×5、8×8、10×10、15×15mm

**一句话结论：**佳农可能有冷冻菠萝相关产品，但“是否有冷冻丁、具体规格”必须以官方或授权供应商书面报价为准。你采购时直接问：**“有没有佳农冷冻菠萝丁，丁径多少mm，IQF还是糖水，包装规格，起订量，样品和质检报告。”**
