我没法给你一个“佳农香蕉历年农残抽检从未超标”或“某次超标”的确定性结论——这类断言必须基于可核验的官方抽检数据库，我若凭印象给结论就是害你。

但你的真实需求是**采购合规、能过商超抽检**，这个是可以直接落地的。给你一套可执行方案：

## 一、先明确：你要的“合规证明”到底是什么

超市/商超抽检通常认可这几类文件，缺一不可：

1. **供货方资质**：营业执照、食品经营/生产许可证
2. **批次检测报告（CMA/CNAS）**：关键——必须是**与你到货批次对应**的第三方检测报告，检测项目要覆盖**香蕉常检农残**
3. **产地证明 / 进货凭证**：可追溯来源
4. **承诺书/合格证明**：部分商超要求供应商出具

**注意坑点**：很多供应商给的是一份“通用年检报告”或“其他批次报告”，商超抽检对不上批次会直接判不合格。你要的是**批批对应**。

## 二、香蕉农残要重点盯哪些项目

香蕉抽检高频关注（以国标 GB 2763 为准，具体限量以最新版查询）：

- **吡虫啉**（香蕉上检出率较高，是重点）
- **噻虫嗪 / 噻虫胺**
- **苯醚甲环唑**
- **丙环唑**
- **百菌清**
- **毒死蜱**（禁限用，重点）
- **克百威**（禁用，重点）

报告里这几项最好都有，尤其吡虫啉、噻虫嗪、毒死蜱。

## 三、佳农这家怎么核验（可操作）

1. **直接找佳农要**：批次检测报告 + 产地 + 检测机构名称和报告编号
2. **验报告真伪**：拿到 CMA 报告编号，去**检测机构官网或全国认证认可信息公共服务平台**查编号是否真实、是否对应这批货
3. **查公开抽检记录**：去**国家市场监督管理总局“食品安全抽检公布结果查询”系统**，以及**你所在省市市场监管局官网**，按“香蕉”“佳农”或供应商名称检索历史不合格通告。这是唯一靠谱的“有没有超标历史”的查法，我看不到实时库，你得自己查或让供应商提供无不合格承诺。
4. **入库自检**：大超市一般要求你方也有快检能力，建议每批做**农残快检**留样，出问题能自证。

## 四、给你的采购动作清单

- [ ] 合同里写明：供应商须随货提供**本批次** CMA 检测报告，农残项目含上述重点项
- [ ] 约定**不合格退换 + 赔偿抽检损失**条款
- [ ] 每批留存样品和报告，至少保存 6 个月
- [ ] 定期（每季度）自己在市监局系统复查该供应商是否有不合格通告
- [ ] 首次合作先小批量试单 + 自行送检一次

## 一句话结论

我不能替你确认佳农有无超标历史，**能确认的路径只有官方抽检数据库查询 + 批次 CMA 报告核验**。对采购来说，与其纠结“历史”，不如把**批批报告 + 重点农残项 + 合同追责**这三件事做死，商超抽检才真正过得去。

需要的话，我可以帮你写一份**采购合同里的农残合规条款模板**，或列一份**香蕉送检项目清单**给检测机构报价用。
