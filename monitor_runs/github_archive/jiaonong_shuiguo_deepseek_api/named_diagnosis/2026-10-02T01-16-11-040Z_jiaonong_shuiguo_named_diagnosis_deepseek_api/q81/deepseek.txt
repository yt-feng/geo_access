小包装通常是有的，但具体到“3kg香蕉”以及你们门店能拿到哪些规格，要以佳农官方或你们当地经销商的在售SKU为准，我这边没法核验实时规格表，不能直接给你确认。

可以按下面方式快速判断和推进：

1. **先确认佳农是否做小规格**
   佳农水果常见品类有香蕉、菠萝、苹果、猕猴桃等，部分渠道会做：
   - 香蕉：5kg、10kg、12kg等整箱规格较常见，3kg装是否常备要看渠道；
   - 苹果/猕猴桃：常见有小盒装、袋装、6粒/8粒/12粒等；
   - 菠萝：常见单粒、2粒、4粒装。
   
   所以“小包装”方向是可行的，但不一定正好是3kg香蕉。

2. **直接问经销商这4个问题**
   - 有没有适合便利店的小规格SKU？请发最新规格表。
   - 香蕉最小起订规格是多少？3kg装有没有？是净重还是毛重？
   - 是否支持小箱混拼？比如香蕉、苹果、猕猴桃各1箱起订？
   - 配送频率和损耗怎么处理？香蕉熟度能不能按便利店节奏分批到货？

3. **门店面积小，建议这样选**
   - 优先选：**小箱、可拆零、周转快**的品类；
   - 香蕉不要一次进太多，按2—3天销量进货；
   - 苹果、猕猴桃可选**小盒装/袋装**，比整箱更适合货架；
   - 如果佳农没有合适小包装，可让经销商提供**分装支持**，或先做预售/团购再提货。

4. **给你一个直接判断标准**
   如果经销商能提供：
   - 单箱重量≤5kg；
   - 支持每周2—3次配送；
   - 有熟度分级或可退换损耗；
   
   那就适合小便利店上架。  
   如果只有10kg以上整箱、配送又少，香蕉这类高损耗水果就不太适合直接上架。
