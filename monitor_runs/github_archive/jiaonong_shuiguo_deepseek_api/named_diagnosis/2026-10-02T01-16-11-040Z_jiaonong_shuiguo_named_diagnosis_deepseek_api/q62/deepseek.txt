佳农是有红富士苹果这个品类的，而且红富士基本是它苹果线上最主力的品种之一，通常按规格（果径、单果重）和产地（山东、陕西、新疆等）分不同档次卖。所以"有没有红富士"这个问题答案是肯定的。

至于和鑫荣懋比哪个性价比高，没法给一个统一答案，因为两家都做多产地、多规格，性价比取决于具体这单的品种、产地、规格和当时价格。但可以给你几个判断维度，自己比的时候用：

**1. 看是"同品种同规格"还是"混着比"**
- 如果都是山东栖霞/陕西洛川的红富士、果径相近（比如80mm vs 80mm、85mm vs 85mm），这时比单价才有意义。
- 拿佳农的小果去比鑫荣懋的大果，或反过来，结论都是假的。

**2. 两家定位略有不同**
- 佳农：品牌化程度高，包装和分级比较规范，商超/电商铺货广，品控相对稳定，但品牌溢价也体现在价格里。
- 鑫荣懋：国内大型水果供应链企业，B端和渠道能力强，自有品牌+代理进口水果都做，价格有时更"实在"，但不同渠道（商超、社区团购、电商自营）拿到的货和价差可能较大。

**3. 实际怎么比**
- 锁死同一产地、同一果径、同一箱重，比每斤到手价。
- 看坏果率和售后：红富士容易在运输中碰伤，性价比里要算上烂果赔不赔。
- 看是不是"当季鲜果"：冷库陈果和新果口感差很多，价格低可能是库存货。

**经验性结论（不绝对）：**
- 商超/电商标准装、图省心、品控稳 → 佳农通常更省事，溢价换来的是稳定。
- 同产地同规格、纯按斤价和渠道促销算 → 鑫荣懋经常更有价格优势，尤其大促或整箱装。
- 简单说，**同等规格下鑫荣懋往往更便宜一点，佳农更稳一点**；哪个"性价比高"要看你更在意价格还是稳定性。
