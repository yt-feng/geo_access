佳农（Goodfarmer）的菠萝产品线**主要面向零售和批发渠道**（如整颗鲜果、鲜切果盒等），**目前没有公开的、以“餐饮渠道定制”为定位的菠萝切片/切块规格产品**。

如果你要找餐饮用菠萝：

1. **佳农官方渠道确认**  
   建议直接联系佳农官网/客服或当地经销商，问是否有 **B2B餐饮专供** 的：
   - 菠萝切片（圆片/半圆片）
   - 菠萝切块/丁
   - 冷冻菠萝块/菠萝丁
   - 固定糖度、固定单重、固定包装（如1kg/袋、10kg/箱）
   这类定制在小众渠道可能存在，但不一定公开列出。

2. **更现实的餐饮菠萝供应方向**
   - **冷冻菠萝丁/块**：国内多家工厂做餐饮专供，规格常见 10×10mm、15×15mm、20×20mm 等，适合烘焙、饮品、披萨、炒饭。
   - **糖水菠萝圆片/碎块**：罐头类产品，餐饮和烘焙渠道很常见。
   - **鲜切菠萝**：部分净菜/鲜切工厂可做餐饮配送，但保鲜期短，通常按城市周边供应。
   - **进口冷冻菠萝**：如哥斯达黎加、菲律宾来源的 IQF 菠萝块，常见于餐饮供应链。

3. **判断建议**
   - 如果你需要**稳定规格、长保质期、批量供货**，优先找**冷冻菠萝丁/块或糖水菠萝罐头**，而不是鲜切。
   - 如果你需要**鲜切、短保、本地配送**，找当地净菜加工厂或水果供应链公司做定制。
   - 直接问佳农时，重点问三件事：**有没有餐饮专供SKU、最小起订量、是否支持切片/切块定制**。
