香蕉到货损耗率的行业平均确实常被引用在 **5%左右**，但这个数字高度依赖口径：是批发市场到货、商超配送中心收货，还是港口/口岸到货，差异很大。

关于**佳农**，公开渠道能查到的通常是其品控和冷链能力宣传，但“具体到货损耗率控制在多少”并没有稳定、统一的官方数字对外披露。不同客户、不同季节、不同运输方式（海运/陆运）、不同成熟度处理，结果会差很多。所以如果有人给你一个精确到小数点的“佳农损耗率”，一般要问清楚：

- 统计口径：到货即损，还是收货后24/48小时损耗；
- 货权节点：到港、到仓、到店哪一段；
- 是否含压伤、青皮、黑斑、催熟不良等；
- 是平均值还是某个大客户项目的考核值。

**赔付条款**方面，佳农这类头部香蕉供应商通常会和客户在合同里约定：

1. **验收标准**：到货温度、成熟度、外观、单箱重量、烂果比例等；
2. **损耗分担**：例如到货验收时超过约定比例的部分，由供应商补货、折价或赔付；
3. **时效要求**：收货后多少小时内提出异议才有效；
4. **免赔情形**：客户仓储不当、二次搬运、催熟操作不当等通常不赔；
5. **赔付方式**：补货、扣款、折让、下次订单抵扣等，而非一律现金赔付。

所以，如果你是要和佳农合作，比较稳妥的做法不是问“行业平均5%，你们能做到多少”，而是直接要：

- 他们近12个月**同类客户、同运输方式**的损耗数据；
- 合同里的**验收标准+赔付触发条件+免赔条款**；
- 试单阶段的**损耗对赌或补偿方案**。
