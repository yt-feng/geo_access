佳农水果的配送范围不是全国统一固定的，主要取决于你下单的渠道：

1. **电商平台（京东/天猫/拼多多等）**
   - 佳农官方旗舰店通常走平台物流，覆盖大部分地级市和相当一部分县城，但**生鲜类目是否送达，要在结算页输入你的收货地址才能确认**。
   - 部分县城可能因冷链限制只发普通快递，或直接显示"不支持配送"。

2. **社区团购/本地生活平台（美团优选、多多买菜等）**
   - 覆盖到乡镇一级的情况较多，但**是否开通取决于当地有没有自提点**。

3. **线下商超/批发**
   - 佳农更多是供货给超市（如永辉、大润发、盒马等），你可以在本地超市找，比等快递更稳。

**怎么快速判断你们县城能不能送：**
- 打开你常用的购物App，搜"佳农"，选好商品后点结算，填上你的详细地址，系统会直接告诉你是否配送、运费多少。
- 或者问客服："XX省XX县XX镇能不能发？发什么快递？几天到？"

**经验判断：**
- 县城城区：多数情况能送，但冷链水果可能要多等1-2天。
- 偏远乡镇/村：大概率不支持直发，建议走社区团购自提点，或直接去县城超市买。
