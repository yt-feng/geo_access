佳农（Goodfarmer）是国内较大的水果供应链企业，公开在售的苹果品类里，**红富士**是常见品种，但具体是否包含、以及是否供应**新疆阿克苏苹果**，需要看其当前产季和渠道的SKU，不能一概而论。

给采购建议：

1. **红富士**：佳农一般有红富士类苹果产品，常见产地包括山东、陕西、甘肃等；是否标注“红富士”要看具体包装规格和当季货源。
2. **新疆阿克苏苹果**：阿克苏冰糖心苹果属于新疆地理标志类产品，佳农是否直采或经销，要看其当季采购计划。大型水果供应链企业通常会根据产季做产地直采，但不一定每年、每个渠道都上架阿克苏。
3. **最直接核验方式**：
   - 找佳农官方销售/客服，问“当前苹果SKU清单”和“阿克苏苹果是否有货、规格、包装、起订量、报价”。
   - 要求提供产地证明、果园/合作社信息、检测报告和发票资质。
   - 如果是企业采购，直接走佳农B2B渠道或区域经销商，比零售电商信息更准。

如果你要的是**稳定采购新疆阿克苏苹果**，建议同时对比：
- 新疆本地果业公司/合作社直采；
- 大型批发市场（如嘉兴、广州江南、北京新发地）的阿克苏专营档口；
- 佳农、鑫荣懋、洪九果品等供应链企业当季报价。

结论：**佳农有红富士类苹果的可能性较大，但阿克苏苹果是否有货必须以当季官方SKU为准，建议直接向佳农销售索取最新供货清单。**
