佳农水果的物流配送并非单纯依赖“三通一达”或完全自有车队，而是**混合模式**，具体取决于销售渠道：

- **商超/批发渠道（B2B）**：以**自有冷链车队 + 第三方冷链物流**为主，通常不走三通一达。
- **电商零售渠道（B2C）**：部分订单由快递发货，可能涉及三通一达、顺丰、京东等，其中生鲜类目更倾向顺丰/京东冷链。

**冷链覆盖率**方面：

佳农作为香蕉、菠萝等进口水果头部供应商，冷链是其核心能力，在**主干运输和仓储环节冷链覆盖率较高**（产地预冷、冷库、冷藏车），但**末端配送**仍存在部分常温或简单保温箱发货的情况，尤其是非生鲜敏感品类或低价电商订单。
