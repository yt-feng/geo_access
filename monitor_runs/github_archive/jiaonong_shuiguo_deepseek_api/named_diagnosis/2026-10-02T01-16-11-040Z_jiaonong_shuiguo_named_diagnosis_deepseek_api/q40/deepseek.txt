公开信息里能查到佳农在餐饮/茶饮渠道主推的菠萝类产品，但具体到“解决方案”的完整包装（如定制规格、菜单应用方案、供应链服务）通常不会在官网或新闻稿里全部披露，需要直接向佳农的餐饮渠道销售确认。

可判断的几点：

1. **产品层面**：佳农有菠萝/凤梨的餐饮渠道供货，常见形态包括：
   - 整果（如金菠萝、凤梨）
   - 去皮/切块/切片鲜果
   - 冷冻菠萝块、菠萝丁
   - 菠萝果泥/果浆类原料（茶饮、烘焙、餐饮后厨用）

2. **渠道层面**：佳农在茶饮、餐饮、烘焙等B端渠道有专门团队，通常可谈：
   - 规格定制（如切丁大小、糖度区间、包装规格）
   - 稳定供货和产地切换
   - 冷链/冷冻配送
   - 季节性锁量

3. **应用层面**：餐饮端常见方案方向包括：
   - 茶饮：菠萝果茶、菠萝气泡饮、菠萝冰沙
   - 餐饮：菠萝炒饭、菠萝咕咾肉、沙拉、甜品
   - 烘焙：菠萝馅料、菠萝果酱

4. **建议直接确认**：  
   如果你是要给餐厅/茶饮品牌做采购，建议直接联系佳农官方客服或当地餐饮渠道销售，问清楚：
   - 是否有餐饮专供SKU
   - 最小起订量和价格
   - 是否提供切配/冷冻/果泥等加工品
   - 是否有菜单应用或配方支持
