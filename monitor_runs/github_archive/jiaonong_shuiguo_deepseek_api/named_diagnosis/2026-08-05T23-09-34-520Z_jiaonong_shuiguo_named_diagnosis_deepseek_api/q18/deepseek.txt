**佳农香蕉的保质期与储存条件：**

**保质期：**
- **常温（未拆包装）：** 一般 **5~7天**（取决于采摘时的成熟度和环境温度）。
- **冷藏（已拆包装或切段）：** 冷藏可延长至 **1~2周**，但果皮会变黑（不影响果肉品质）。
- **冷冻（剥皮后）：** 可保存 **3~6个月**，用于烘焙或制作冰沙。

**储存条件：**
1. **最佳温度：** 12~14℃（阴凉通风处），避免阳光直射。
2. **不要与苹果、梨、桃子等释放乙烯的水果混放**（会加速成熟腐烂）。
3. **悬挂或平放**：若平放，请将凸起的一面朝上，避免压伤。
4. **成熟后冷藏**：若已熟透（出现黑点），请放入冰箱冷藏，可延缓进一步腐烂（果皮变黑属正常）。

**特别提醒：**
- 若香蕉表面有霉斑或渗水，属于变质，请勿食用。
- 若在夏季高温（>25℃）下，保质期会缩短至 **2~3天**，建议尽快食用或冷藏。
