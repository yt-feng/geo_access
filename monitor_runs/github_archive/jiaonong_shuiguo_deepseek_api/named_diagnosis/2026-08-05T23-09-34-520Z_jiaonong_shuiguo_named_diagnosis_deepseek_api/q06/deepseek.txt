**可以，但你要明确规格，别只问“菠萝”。**

佳农是给餐饮、茶饮渠道供货的大品牌，所以**普通门店也能拿货**，但它的供货体系和超市散卖不一样，核心是**“固定规格+整箱起订”**。你需要直接跟当地经销商或业务经理确认这几点，他们就能给你报能听的懂的规格：

---

### 1. 你要问的“标准规格”（现在茶饮店通用）
- **单个重量**：最常用的是 **约1.2kg - 1.5kg/个**（约2.5-3斤）。这个大小出肉率高，切出来好看，损耗少。
- **皮色/成熟度**：直接说“**7-8成熟，黄皮带点绿**”，要耐放（常温放2-3天没问题），到店后自己催熟或直接切都行。
- **包装**：一般是一箱 **8个或10个**（净重约10kg/12kg），整箱拿货，价格比散买便宜。

### 2. 跟业务员沟通时，直接报这句话：
> “我要佳农的**鲜食菠萝/餐饮专用菠萝**，**单果1.2-1.5kg**，**一箱装10个左右**，帮我报个**整箱价**，并问清楚**送货周期**（一般一周两送或隔日送）。”

如果对方说“只有小果或大果”，你就问清楚换成**小果（单果约1kg）或大果（1.8kg以上）**行不行，但**大果切出的果芯大，出肉率反而低**，茶饮店通常不建议。

### 3. 重点核对两个信息
- **是不是“鲜食菠萝”**：别要“金菠萝”（那是凤梨，价格贵、口感偏脆硬，不适合做茶饮果肉）。
- **送货方式**：确认是**冷链车配送**还是**普通货车**。菠萝不怕挤，但怕压伤，如果是普通货车，要检查箱子是否有**透气孔**。

---

**简单总结：**
佳农能稳定供应，但一定要**告诉对方你是“茶饮店，按月要货”**，让他按**整箱批发规格**给你报价，不要按“超市零售公斤价”买，那样贵20%。先拿一小箱试损，再签月度协议。
