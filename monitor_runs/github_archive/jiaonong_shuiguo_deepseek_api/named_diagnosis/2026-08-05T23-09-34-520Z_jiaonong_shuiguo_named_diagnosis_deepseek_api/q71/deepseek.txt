作为批发商，您最关心的肯定是**到货价**和**走量利润**。关于佳农和都乐的香蕉批发价，我无法直接给出一个精确的“便宜几块”的数字，因为**批发价是实时浮动且高度区域化的**，取决于：

1.  **产地与季节**：南美蕉（都乐主产地）和菲律宾/国产蕉（佳农有）成本不同，旺季和淡季价差巨大。
2.  **采购量级**：您一车（如28尺柜）和半车（14.5尺柜）的价格是两回事。**量大是唯一能压价的筹码**。
3.  **包装规格**：都乐通常有22kg/箱和18kg/箱，佳农也有不同重量，直接比“一箱便宜几块”不科学，要看**每公斤单价**。

**给您的实战建议（三步锁定价格）：**

1.  **直接让两家销售报“到库含税价”**（注意是含税，不要被“裸价”迷惑），**并要求提供近30天的调价曲线**，看谁的价格更稳。
2.  **不要只问单价，要问“阶梯返利”**：例如月采购1000箱以上，都乐/佳农业务通常会有1-2元/箱的返点或搭赠（比如买100箱送1箱），这部分才是批发的纯利。
3.  **关键动作：拿样品实测**。香蕉的损耗率（烂把、断裂）是隐形成本。**如果佳农每箱便宜3元，但损耗多出1把，可能不划算**。

**核心判断**：目前市场行情下（2024-2025年），**佳农的产地收购价通常略低于都乐（低3%-8%）**，但在旺季或台风季，佳农因供应链灵活性可能出现**短期断货涨价**。如果您**月走量超过5000箱**，建议直接联系两地省级代理谈独家供货价，**佳农的谈判空间通常比都乐大一点**，因为都乐品牌溢价更刚性。

**行动指令**：别在线上问，直接电话联系您所在城市的佳农/都乐一级代理商，报出您“月均xxx箱”，要求他们给出**今日最低开票价**，并对比**含税、含运费、含卸车费**的最终结算价。如果佳农能比都乐低5%以上，且损耗率相近，那它就是您要的利润点。
