**一般香蕉分级标准（业内通用，佳农可能略有调整）：**

- **一级果（A级/精品果）：** 
  - **外观**：果形直、粗细均匀，无机械损伤，果皮金黄、无黑斑或极少黑点，果柄完整。
  - **成熟度**：七至八成熟，适合长途运输和货架期储存。
  - **大小**：单根长度较长（通常按“梳”或“把”称重，比如每把净重≥18公斤，单根长度≥18厘米）。
  - **瑕疵**：无磕碰、无霉变、无虫眼。
- **二级果（B级/通货）：** 
  - 允许有轻微弯曲、少量黑斑、轻微擦伤或果形不匀，但不影响食用。
  - 成熟度可能稍高或稍低，适合快速销售或加工。
- **三级果（C级）：** 通常用于榨汁、烘焙或快餐店使用，瑕疵更多。

**价格差异参考：**
- 同一批货中，一级果与二级果的批发价差通常在 **每箱（约18-22公斤）5-15元人民币** 之间，折合约 **每公斤0.3-0.8元** 的差距。
- 若遇供应紧张或精品需求高，一级果可能比二级果贵 **10%-20%**；若市场低迷，价差可能缩小至5%以内。
- 注意：佳农品牌通常主打高品质，其一级果可能对标高端超市或餐饮，二级果可能走商超促销渠道，实际差价建议直接联系佳农区域销售经理或查看其发给经销商的报价单。
