关于佳农水果的苹果品类，佳农（Goodfarmer）以香蕉、菠萝等为主打，但也有苹果产品线，其中确实包括红富士苹果（主要在山东、陕西等地采购）。不过，佳农的红富士苹果在其整体业务中占比不大，主要面向商超和电商渠道。

关于性价比对比，需要结合具体市场情况：

1. **佳农红富士**：通常走中高端路线，注重产地直采和品控，包装较精致，价格相对较高。如果购买渠道是精品超市或线上旗舰店，单价可能比普通渠道贵10%-20%。

2. **鑫荣懋（Joyvio）**：作为国内头部水果分销商，苹果品类更丰富，红富士是其核心品类之一，供应量大，价格区间更宽。线上促销或批发渠道常见中低端性价比款，单位价格普遍低于佳农同类产品。
