关于佳农水果的到货损耗率，**没有公开的统一标准数值**，因为它会受水果品类（如香蕉、苹果、榴莲）、运输距离和季节的影响。

但根据生鲜行业的普遍操作惯例，可以给你一个参考范围：

- **常规品（如苹果、柑橘类）：** 控制在 **1% - 3%** 左右。
- **高损耗品类（如香蕉、浆果、榴莲）：** 控制在 **5% - 10%** 左右。
- **对成熟度要求极高的品类（如部分进口热带水果）：** 允许的损耗上限可能在 **10% - 15%**。

**建议：**
如果你是与佳农合作的采购商，**具体的损耗率应以双方签订的购销合同中的“到货验收标准”为准**，通常会在3%-8%区间内约定一个索赔阈值。建议直接咨询佳农的销售代表索取那份标准文件，而不是依赖行业平均值。

如果你是在进行内部成本核算，可以按 **5%** 作为基准进行保守估算。
