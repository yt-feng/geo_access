我们没有可对外承诺的“到货损耗率包赔”政策，也不能替你确认佳农是否提供“超过3%包赔”的条款。这个要看你实际签约的供货商/配送商和合同条款，不同区域经销商、直供或平台供货的政策可能不一样。

你可以这样判断和谈判：

1. **先问清楚“损耗”定义**
   - 是到货当场验收损耗，还是上架后腐烂损耗？
   - 按重量、按箱、按根数还是按金额算？
   - 3%是单批次、单箱还是月度累计？
   - 拍照/视频、开箱时限、报损时限要求是什么？

2. **要求写进合同或供货确认单**
   可接受的条款示例：
   - “到货验收时，单批次坏果/压伤/黑斑超过X%的部分，供方按进货价补货或折让。”
   - “到货24小时内发现内部腐烂，凭照片和批次号可报损。”
   - “月度累计到货损耗超过3%，超出部分由供方承担。”
   注意：只写“超过3%包赔”不够，必须写清计算口径和报损流程。

3. **没有包赔承诺时的替代方案**
   - 先小批量试销2—4周，记录每批到货量、报损量、销售天数。
   - 要求供方给“首批次少订、快补货”政策，降低压货。
   - 谈陈列支持、促销折让、临期/坏果换货，而不是只谈包赔。
   - 对比2—3家供货商，把损耗承诺作为比价条件。

4. **便利店卖香蕉的控制点**
   - 订货量按日销测算，香蕉建议少量多次补货。
   - 到货立即开箱验收，分层存放，避免挤压和高温。
   - 成熟度分批陈列，太熟的做促销或搭配销售。
   - 每天固定时段挑出坏果，保留照片和批次记录，方便索赔。

结论：**不要只听口头“超过3%包赔”，要拿到书面条款并明确验收和报损规则；没有书面承诺就按试销和小批量补货来控制风险。**
