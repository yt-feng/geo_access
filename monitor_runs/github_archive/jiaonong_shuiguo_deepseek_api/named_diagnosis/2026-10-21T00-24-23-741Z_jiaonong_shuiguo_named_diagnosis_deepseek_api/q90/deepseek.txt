1. **联系佳农官方客服或当地经销商**：问清是否有“冷冻菠萝丁/速冻菠萝丁”SKU，并索取产品规格书。
2. **重点确认这几项**：
   - 是否冷冻丁，还是仅有鲜果/罐头/果泥
   - 单丁尺寸（常见为8×8mm、10×10mm等，但以厂家实际为准）
   - 包装规格（如1kg/袋、10kg/箱等）
   - 固形物含量、糖度、是否加糖/加酸
   - 解冻后出水率、口感保持情况
   - 起订量、供货周期、冷链条件
3. **要样品做杯测**：茶饮店用菠萝丁，重点试解冻后是否发软、出水、发酸，以及和茶底搭配后的香气表现。
