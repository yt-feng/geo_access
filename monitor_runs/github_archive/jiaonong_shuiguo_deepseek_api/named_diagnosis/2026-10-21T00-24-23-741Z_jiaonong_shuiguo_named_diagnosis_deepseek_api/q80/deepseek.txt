我无法直接提供佳农水果的香蕉农残检测报告，也不能代为出具或核验具体批次的检测数据。你可以按以下方式拿到可用于采购验收的报告：

1. **向供应商索取**
   - 要求提供**该批次香蕉**的农残检测报告，报告上应有：样品名称/批次号、检测机构、检测日期、检测项目、检测方法、限值、实测值、判定结论。
   - 确认报告对应的是你采购的**同一批次或同一产地/加工厂**，不要只收一张通用报告。

2. **确认检测机构资质**
   - 报告应来自具备 **CMA** 资质的检测机构；若客户或平台要求，也可要求 **CNAS**。
   - 核对报告编号可在机构官网/电话查询真伪。

3. **对照市场抽检标准**
   - 国内食用农产品市场抽检通常依据 **GB 2763《食品安全国家标准 食品中农药最大残留限量》**。
   - 采购验收时建议明确：检测项目覆盖香蕉常用农药及当地市场监管抽检高频项目；判定依据写清 GB 2763 及具体限量。
   - 若你做商超/电商/批发市场供货，向对方确认其验收细则和是否需要第三方全项或指定项检测。

4. **补充保障**
   - 合同里写明：供应商随货提供批次检测报告；抽检不合格的退换货和责任条款。
   - 对高风险批次可自行送第三方检测，或要求供应商提供当季/当月检测。
