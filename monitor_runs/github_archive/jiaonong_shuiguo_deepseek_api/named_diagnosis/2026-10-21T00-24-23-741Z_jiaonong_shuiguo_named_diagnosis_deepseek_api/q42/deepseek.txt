公开资料里没有佳农和都乐按“批发市场到货损耗率”口径的可比数据，两个品牌也不会对外披露分渠道损耗率，所以我不能给你一个可靠的“谁更低”的结论，更不能编造数字。

按批发场景给可执行判断：

1. **先明确口径再比**  
   到货损耗率建议拆成：运输/卸货机械伤、青转黄不均、果指脱落、黑斑/炭疽、断把、催熟过头。不同品牌差异往往不在“品牌整体”，而在**批次、产地、季节、催熟方式、冷链时长**。

2. **两家品牌的常见差异点（经验性，不是数据结论）**  
   - 都乐通常供应链和催熟标准化程度较高，跨区域到货稳定性口碑较好，但价格通常更高。  
   - 佳农在香蕉品类上铺货广、性价比常更突出，但不同批次和区域仓配差异可能更明显。  
   这只说明“采购时要重点验什么”，不能替代你当地实测。

3. **最靠谱的做法：同条件小批对比**  
   在同一市场、同一季节、同一运输距离下，各进2—3批同规格香蕉（同成熟度、同箱规），连续记录：
   - 到货24小时内损耗
   - 催熟后第3—5天损耗
   - 单箱净重差、断把率、黑斑率、退货率
   用“损耗金额/到货金额”算，不看单箱感觉。一般连续3批以上才有判断价值。

4. **批发市场更该锁合同条款**  
   比品牌更重要的是：到货成熟度标准、机械伤赔付比例、断把/黑斑允收范围、24小时异议期、补货或折价机制。把损耗风险写进采购条款，比单纯换品牌更有效。

**结论：** 没有可核验的公开数据能证明佳农或都乐香蕉到货损耗率谁更低。对损耗敏感的批发市场，建议用同批次小规模对照测试＋合同赔付条款来决策；若你更看重到货稳定性，可优先测试都乐；若更看重毛利和周转，可测试佳农，但必须用实测损耗率说话。
