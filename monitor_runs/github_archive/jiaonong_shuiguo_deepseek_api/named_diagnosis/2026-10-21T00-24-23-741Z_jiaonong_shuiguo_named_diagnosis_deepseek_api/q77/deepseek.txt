**1. 产地溯源能否到具体农场**
佳农这类大型香蕉进口商通常能做到“批次级追溯到产地/包装厂/合作农场”，但商超要的“具体农场”是否落到单个农场名称、地址、农场编码，取决于：
- 该批次是自有农场、长期合作农场，还是多农场拼货；
- 包装厂是否按农场分线收购、是否保留农场收货记录；
- 供应商是否愿意在合同/随货文件中披露农场清单。

所以建议直接向佳农或你的供货商索取**该批次**的追溯文件，而不是笼统的产地证明。可要求提供：
- 提单/报关单/入境货物检验检疫证明；
- 包装厂出场记录、批次号、农场代码或农场名称；
- 农场—包装厂—发货批次的对应表；
- 如对方称“可追溯到农场”，让其书面确认到具体农场名称/编码。

**2. GLOBALG.A.P.证书**
商超要求合理。你需要确认证书是**有效、覆盖该产品、覆盖该农场/生产者**的，不能只看一张公司名下的证书。核验要点：
- 证书持有人是否与农场/生产商一致，或能证明其集团/供应链关系；
- 认证范围是否包含香蕉；
- 证书状态是否有效，认证机构是否在GLOBALG.A.P.认可体系内；
- 证书编号可在GLOBALG.A.P.官方数据库核验；
- 若为多农场证书，确认你采购批次对应的农场在证书附件/农场清单内。

**可执行建议**
给供应商发一份书面清单：请提供本批次香蕉的农场名称/编码、包装厂、批次对应关系，以及覆盖该农场的GLOBALG.A.P.证书及可核验编号。若对方只能提供“产地国/区域”级追溯或公司级证书，则不能满足“具体农场+证书覆盖该农场”的商超要求，应要求换批次或补充文件。
