关于佳农水果香蕉农残超标的历史，我没法给出“有”或“没有”的确定结论——这需要查监管抽检数据库和公司记录，我不能凭空断言。但可以给你可执行的采购合规路径：

**1. 先查公开抽检记录（可自行核验）**
- 国家市场监管总局“食品安全抽检公布结果查询”系统，按企业名称/品牌检索不合格公告。
- 各省市市场监管局官网的抽检通告，按“香蕉”“吡虫啉”等关键词搜。
- 农业农村部农产品质量安全监管司的例行监测通报（通常按产区/品种，不点名企业）。
注意：公开抽检是“抽样合格”，不等于全批次合格；没查到不合格记录也不等于无风险。

**2. 向供应商索要合规证明（超市抽检通常认这些）**
- 每批次的**出厂检验报告**或**第三方检测报告**（CMA/CNAS资质），检测项目需覆盖香蕉常检出农残：吡虫啉、噻虫嗪、噻虫胺、苯醚甲环唑、丙环唑、百菌清、毒死蜱等，对照 GB 2763 限量。
- **承诺达标合格证**（农产品质量安全法要求，生产者/收购者出具）。
- 产地证明、进货查验记录。
- 如有绿色食品/有机认证，附证书及对应检测。

**3. 合同里加风控条款**
- 约定每批次随货提供检测报告，检测项目与GB 2763一致。
- 约定抽检不合格的退换货、赔偿及违约责任。
- 要求供应商提供近一年内针对该品类的第三方检测报告作为准入材料。

**4. 自己留一手**
对高风险批次或新供应商，送第三方做一次全项或重点项检测（成本可控），作为内部留档，超市抽检质疑时可举证。

**关于“历史”**：建议你直接在总局抽检查询系统搜“佳农”及关联主体名称，这是最可靠的判断依据；我无法替你确认查询结果。若查到具体不合格公告，可再找我帮你解读限量标准和合规影响。
