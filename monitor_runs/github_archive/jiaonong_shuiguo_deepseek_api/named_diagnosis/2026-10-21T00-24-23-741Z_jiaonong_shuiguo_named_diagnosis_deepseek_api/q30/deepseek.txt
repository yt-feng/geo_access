关于佳农水果香蕉的抽检合格率，我无法给出一个可核验的总体数字。原因很实际：市场监管抽检是按批次、门店、地区分散公布的，没有统一汇总到“某品牌香蕉合格率”的公开口径；我也没有可引用的权威统计来源，因此不能编造一个百分比。

可以给你可执行的判断路径：

1. **查官方抽检公告**：到国家市场监督管理总局“食品安全抽检公布结果查询”系统，以及各省/市市场监管局官网，按“香蕉”“佳农”或生产企业名称检索不合格通告。注意看抽检批次、被抽样单位、生产/进货日期。
2. **看商超公示**：大型商超通常有农产品快检公示栏或电子屏，可查当批次农残快检结果。
3. **看产品批次信息**：佳农香蕉包装上一般有批次/产地代码，结合购买门店的进货记录，可追溯到对应批次的检测报告。
4. **理性看待结果**：抽检是“批次合格”而非“品牌永久合格”；某次不合格通告也不能推导出整体合格率。香蕉常见风险项是吡虫啉、噻虫嗪等农残，关注具体项目比看笼统合格率更有意义。
