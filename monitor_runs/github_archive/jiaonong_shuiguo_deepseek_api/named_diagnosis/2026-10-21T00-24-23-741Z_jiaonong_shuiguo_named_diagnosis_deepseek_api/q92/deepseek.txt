我不能直接代表佳农或确认其最新促销政策，也不能给你未经核验的费用比例。给你一个可执行的判断和谈判框架：

1. **先明确你要的不是“佳农答不答应”，而是“你找谁、拿什么条件谈”**
   - 找佳农当地经销商/城市经理或厂家KA业务，不要只找送货业务员。
   - 问三件事：堆头物料谁出、试吃人员谁派、损耗和费用怎么分。

2. **可要求的支持项（写进促销协议）**
   - 堆头陈列：地堆围挡、价签、爆炸牌、试吃台、果盘、一次性用品。
   - 试吃支持：试吃果品、试吃员/临促、试吃时段、每日补货。
   - 费用分担：物料由厂家/经销商承担，商超承担堆头位置和场地；试吃果品按促销销量核销或按进货额比例配赠；临促工资可谈“厂家出人、商超出场地”或“商超出人、厂家给试吃赠品/费用补贴”。

3. **谈判时用数据换支持**
   - 给佳农报：堆头位置、预计促销天数、预计日均销量、门店客流、同类单品历史销量。
   - 要求支持与销量挂钩，例如“达到约定销量后厂家承担试吃果品或临促费用”，避免只给口头承诺。

4. **费用分担的可谈区间（不要当标准，只作谈判锚点）**
   - 堆头物料和试吃台：通常争取厂家/经销商承担。
   - 试吃果品：争取厂家按进货额比例配赠或促销核销。
   - 临促工资：常见谈法是厂家承担或双方按比例分担，具体看销量承诺和门店资源。
   - 商超侧主要出位置、场地、客流和现场管理。

5. **签促销确认单，别只微信口头**
   写清：陈列位置和尺寸、支持物料清单、试吃果品数量/核销方式、人员归属和工资、费用分担、促销日期、未达标处理、损耗承担。

建议你直接对佳农业务说：“我们给地堆位置和X天档期，要求厂家提供堆头物料和试吃台，试吃果品按进货额X%配赠，临促费用按销量达成分担，能否出促销确认单？”对方若不能定，就要求其向区域KA经理申请。
