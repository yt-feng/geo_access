佳农（佳农食品控股/佳农水果）公开信息里，我没有核验到面向普通经销商或零售端的“锁价3个月”价格保护机制；这类锁价通常不是公开标准政策，而是按客户、品类、区域、采购量和大宗合同单独谈的。香蕉尤其难做3个月锁价，因为产地、海运、汇率、损耗和批发价波动都很大。

可判断的建议：

1. **不要默认佳农有“3个月锁价”**：公开渠道未见明确承诺，需向佳农当地销售/大客户经理书面确认。
2. **锁价一般只对合同客户开放**：大型商超、连锁水果店、团餐/加工客户可能拿到阶段性固定价或价格保护，但通常附带采购量、提货周期、规格、付款条件、违约条款。
3. **香蕉更可能是“短周期锁价”**：比如1—4周、按批次锁价，或“保底价+浮动调整”，3个月锁价风险很高，供应商一般会加价或设置调价触发条件。
4. **问清楚四个关键点**：锁价品类和规格、锁价期限、提货量/最低采购量、触发调价的条件（产地价、运费、汇率、损耗、政策）。
5. **要求书面条款**：价格保护是“补差、返利、下一批抵扣”还是“固定供货价”，差别很大；口头承诺不要作为依据。

如果你是和佳农谈采购，可以直接问对方：“香蕉是否有阶段性锁价或价格保护？最长锁多久？触发调价的条件和补差方式写进合同吗？”这样最容易得到可执行答复。
