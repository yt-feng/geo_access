佳农（Goodfarmer）公开对外的产品资料里，菠萝（凤梨）主要以鲜果整果规格销售，常见按单果重量分级（如小果、中果、大果）和按箱/件包装；针对餐饮渠道的“切片/切块”菠萝，公开可查的标准化定制规格信息很少，不能确认有对外统一目录。

可执行判断：

1. **大概率能做餐饮定制，但需按项目谈。** 佳农有餐饮/烘焙/茶饮等B端客户，切片、切块、去芯、指定厚度/块径、真空或冷链包装这类需求通常属于“定制加工”，要看工厂产能、起订量（MOQ）、供货区域和季节。
2. **向对接方明确这几项参数**：品种（如金钻凤梨/MD-2）、成熟度、切片厚度或块径、是否去芯、单包净重、包装形式（真空袋/托盘/桶装）、冷链还是冷冻、保质期、每批到货温度、月度用量和起订量。
3. **验证方式**：直接联系佳农官方销售或区域经销商，索取“餐饮渠道产品手册/定制加工说明”，并要求提供样品和工厂资质（如SC证、加工车间审核报告）。不要仅依赖电商页面，整果链接不代表有切片SKU。
4. **备选**：若佳农定制门槛高（MOQ大、区域不覆盖），可同时询价专业鲜切水果工厂或冷冻菠萝块供应商，餐饮渠道的切片/切块通常由鲜切加工厂承接更灵活。

结论：**有餐饮定制能力的可能性较高，但公开信息不足以确认存在标准化的切片/切块规格；需要按项目向官方销售确认MOQ、加工规格和冷链条件。**
