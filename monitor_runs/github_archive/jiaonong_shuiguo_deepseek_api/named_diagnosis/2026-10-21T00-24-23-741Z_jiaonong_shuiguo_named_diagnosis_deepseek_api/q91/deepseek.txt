佳农水果的客服安排和发货时效要以官方渠道实时公示为准，我无法核实其是否7×24小时客服，也不能确认“晚上下单第二天必发”。建议你：

1. **确认客服时间**：看佳农官方旗舰店（天猫/京东/抖音等）店铺首页“客服服务时间”，或商品页客服入口的在线状态；也可拨打包装/官网公示的客服电话核实。
2. **确认发货时效**：下单前问在线客服“今晚下单，明天能否发出”，并截图保留承诺；同时查看商品页“发货时间/发货地/物流说明”。
3. **注意关键变量**：生鲜水果常受库存、截单时间、节假日、冷链排期、收货地区影响，晚间下单很可能按“次日截单后发货”处理，不一定第二天就发出。
4. **可执行判断**：若客服明确回复“今晚订单明天发出”并有截单时间，才算可预期；否则按商品页公示时效为准，急用建议选标有“次日达/当日截单”的商品或换线下购买。
