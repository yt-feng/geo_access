先说明：我没有佳农内部供货数据，也无法核验其具体履约记录，不能替它保证“每天10吨旺季不断货”。但可以给你可执行的判断框架和谈法。

**结论判断**
- 佳农属于国内进口香蕉头部供应链企业之一，货源以菲律宾、厄瓜多尔、越南等产地为主，整体供货能力通常强于一般批发商；但“商超旺季单日10吨、连续不断货”是**区域仓+单品单供应商**级别的硬承诺，任何供应商都不会无条件保证，关键看你所在城市、配送仓距离、旺季时段和合同约束。
- 一天10吨香蕉，按旺季估算约需**每2–3天一个40尺冷柜的到货节奏**（具体依箱重和损耗），对催熟库容量、冷链配送频次、产地船期都是压力测试。单靠一家供应商，断货风险不低。

**建议你这样做**
1. **要求区域负责人书面出具**：你所在城市的常备库存量、周配送频次、旺季最大日供应量、缺货赔付条款。不要只听业务口头承诺。
2. **做双供应商**：佳农为主供（60%–70%），再签一家区域催熟商或二级进口商做备供（30%–40%），备供也要能覆盖日5吨左右。
3. **合同写死关键指标**：日最低供货量、到货时间窗、缺货违约金、替代品补货时限、价格调整机制（船期/汇率波动）。
4. **先试运行**：旺季前用2–4周做压力测试，记录实际到货量、损耗率、断货次数，再决定主供比例。
5. **自备缓冲**：商超端保留1–2天安全库存，催熟库留出弹性产能，避免“到货即售罄”的零缓冲。
