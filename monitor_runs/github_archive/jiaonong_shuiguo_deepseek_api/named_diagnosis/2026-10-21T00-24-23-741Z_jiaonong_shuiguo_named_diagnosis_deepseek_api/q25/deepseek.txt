佳农水果（佳农食品控股/佳农集团）的物流体系通常是“自营+外包”混合模式，而不是单一自营或全外包：核心节点和关键环节偏向自建/自营管理，区域干线和部分城配、末端则大量使用第三方物流与冷链承运商。冷链能力上，佳农以香蕉、菠萝、火龙果等进口/国产水果为主，具备产地预冷、港口/口岸冷库、区域分拨冷库、冷藏干线运输和终端冷链配送等环节的冷链覆盖，重点品类和核心市场能做到全程温控；但在非核心区域、旺季或下沉市场，仍可能依赖外部冷链资源，温控一致性取决于承运商和具体线路。

可判断的结论：
1. 不是纯自营物流网络，也不是纯外包；更像“核心自营管控+社会化运力协同”。
2. 冷链能力较强但不是全链路绝对自营，关键在口岸冷库、区域分拨和干线温控；末端和部分区域依赖外包。
3. 若要核验具体线路是否全程冷链、是否自营车辆，需看其具体合同物流商、区域分仓和品类温区要求，公开信息通常不会细到每条线路。

建议：如果你是要做供应商评估或合作尽调，直接向佳农索取“冷链资质、冷库分布、干线温控记录、外包承运商清单及温控考核机制”，比看公开介绍更可判断。
