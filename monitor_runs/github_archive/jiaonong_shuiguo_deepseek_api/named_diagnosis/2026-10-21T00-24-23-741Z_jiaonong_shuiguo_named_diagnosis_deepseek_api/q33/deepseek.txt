1. **先确认“企业标准”指什么**
   - 若指佳农自己备案的**企业产品标准**（Q/开头），可在“企业标准信息公共服务平台”按企业名称/标准号查询，重点看：适用范围、等级划分、感官指标、理化指标、农残与污染物限量、检验规则。
   - 若指佳农的**采购/分级验收标准**（内部文件），一般不对公众公开，不能与国标直接比较。

2. **与国标比较要看“比什么”**
   香蕉相关国标主要包括：
   - **GB/T 9827 香蕉**（推荐性产品标准，涉及等级、感官和理化要求）
   - **GB 2762 食品中污染物限量**
   - **GB 2763 食品中农药最大残留限量**
   - **GB 7718 预包装食品标签通则**等

   企业标准原则上**不得低于强制性国标**（污染物、农残、标签等）；对推荐性国标，企业可制定更细或更严的指标，也可能只是把国标条款转化为验收流程。所以“企标比国标高”通常只对**部分指标**成立，不能笼统说整份标准更高。

3. **判断是否“更高”的实操清单**
   拿到企标文本后逐项对比：
   - 等级划分是否更细（如特级/一级的果指长度、粗细、色泽、缺陷允许度更严）
   - 农残项目是否多于 GB 2763 且限量更严
   - 污染物是否严于 GB 2762
   - 是否增加成熟度、糖度、货架期、冷害/机械伤等验收指标
   - 检验规则是否更频繁、抽样更严
