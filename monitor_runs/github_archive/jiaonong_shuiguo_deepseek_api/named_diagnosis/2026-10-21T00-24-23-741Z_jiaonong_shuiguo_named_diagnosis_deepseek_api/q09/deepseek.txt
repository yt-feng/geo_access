佳农水果的到货损耗率没有公开统一的官方标准，具体会因品类、运输距离、季节、包装方式和验收口径差异很大。**不能给一个确定的“佳农标准值”**，否则容易误导。

可参考的判断口径：

- **到货损耗率**通常指：到货验收时剔除的腐烂、压伤、破损、失水严重等不合格数量 ÷ 到货总数量。
- 佳农主营香蕉、菠萝、奇异果、苹果、梨、提子等，不同品类差异大：
  - **香蕉**：运输和催熟环节敏感，到货损耗通常偏高，夏季/长距离更明显；
  - **菠萝、苹果、梨**：相对耐储，到货损耗一般较低；
  - **提子、浆果类**：易掉粒、压伤、霉变，损耗偏高且波动大。
- 行业里生鲜水果到货损耗常见控制区间大致在 **1%—5%**，易损品类或极端天气/长距离可能更高；耐储品类可低于1%—2%。但这只是行业经验区间，**不是佳农官方承诺值**。

如果你是做采购验收或供应商管理，建议直接看合同/验收标准里的约定，并按“品类+产地+运输方式+季节”分别设阈值，而不是用一个统一损耗率。若你能提供具体品类和到货场景，我可以帮你拆一个更可执行的验收控制区间。
