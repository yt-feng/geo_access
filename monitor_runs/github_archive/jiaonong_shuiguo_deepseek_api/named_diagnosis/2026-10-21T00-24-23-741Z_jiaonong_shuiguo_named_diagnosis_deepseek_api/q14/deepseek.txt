**1. 先向佳农确认能否做“渠道专供包装”**
直接问对接业务员或区域经销商：
- 是否支持超市渠道**专供包装/专版包装**；
- 最小起订量、单店配送还是统仓配送；
- 包装费用谁承担、是否收版费/制版费；
- 换版周期、供货稳定性、损耗和售后标准；
- 是否允许包装上出现你超市名称/LOGO/“专供XX超市”字样。

**2. 明确你要的专供形式**
常见有几种，成本差别很大：
- **贴标专供**：佳农标准箱加你超市标签，门槛最低；
- **外箱专版**：纸箱印超市名称/LOGO，通常有起订量；
- **内袋/单把标签专版**：适合精品陈列，成本更高；
- **规格专供**：如固定单把重量、每箱把数、成熟度，属于更有价值的“专供”。

**3. 合作前必须写入合同/供货确认单**
建议明确：
- 专供包装仅限你方渠道销售；
- 包装版面需双方书面确认；
- 起订量、价格、版费、交期；
- 包装质量标准和破损责任；
- 若停止合作，剩余专供包装如何处理；
- 不得混入非专供货或窜货。

**可执行建议：**先让佳农提供“商超专供包装方案+报价+起订量+打样周期”，同时你方准备门店数量、预计月销量、配送仓/门店清单和包装版面需求。对方能提供打样和书面起订量后，再谈长期合作。若对方只口头说“可以”，不要直接签长期协议。
