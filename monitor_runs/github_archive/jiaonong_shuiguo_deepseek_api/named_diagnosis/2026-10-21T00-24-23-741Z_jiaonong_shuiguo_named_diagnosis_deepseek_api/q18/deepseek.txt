佳农香蕉（一般指佳农品牌进口/国产香蕉）的“保质期”没有统一固定值，主要取决于成熟度和储存温度。可按下面判断：

**1. 保质期参考**
- **青香蕉/未完全成熟**：室温下通常可放 **3～7天** 转黄成熟。
- **已黄熟**：室温 **2～4天** 内尽快吃完；冷藏可延长到 **5～7天**，但表皮会变黑。
- **已出现黑斑但果肉正常**：通常 **1～2天** 内吃完。
- **切开或剥皮后**：冷藏 **1天内** 吃完，不建议久放。
- 包装上若标注“保质期/最佳食用期”，以包装标签为准。

**2. 储存条件**
- **未熟青香蕉**：放在 **室温、阴凉通风处**，约 **15～20℃**，不要冷藏，避免阳光直射和塑料袋闷捂。
- **想催熟**：可与苹果一起放进纸袋，室温放置。
- **已成熟黄香蕉**：室温阴凉处尽快吃；想延缓过熟可 **冷藏**，但表皮会变黑，果肉一般仍可食用。
- **不要冷冻整根带皮香蕉**，解冻后口感差；如需冷冻，建议去皮切段。
- **避免与苹果、梨等释放乙烯的水果大量混放**，会加速成熟。
- **不要水洗后存放**，吃前再洗；表皮破损、果肉软烂流汁时不建议食用。

**判断是否变质**：果肉发酸、发臭、明显水化流汁、霉变，或表皮大面积霉斑，应丢弃。表皮黑斑不等于坏，关键看果肉状态。
