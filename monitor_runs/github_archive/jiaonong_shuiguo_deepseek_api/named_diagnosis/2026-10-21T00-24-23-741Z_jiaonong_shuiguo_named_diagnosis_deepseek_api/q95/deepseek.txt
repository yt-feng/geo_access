我无法核验“佳农水果产地直供比例”的具体数字，公开渠道也少见企业按比例披露，直接给数字容易误导。对采购更实用的做法是：把“产地直供比例”拆成可核验的合同指标来谈。

**1. 先定义什么叫“直供”**
建议在询价文件中明确口径，例如：
- 直采：合同主体直接与种植基地/合作社/产地加工厂签约；
- 产地直发：由产地仓或加工厂直接发往我方指定仓，不经销地批发市场；
- 基地直供：有明确基地清单、地块/果园编码、采摘批次可追溯。

不同口径比例差异很大，必须先统一。

**2. 向佳农或任何供应商索取的核验材料**
- 近12个月该品类SKU的直采/基地采购金额占比、数量占比；
- 产地供应商清单（可脱敏）、基地合作协议或采购合同关键页；
- 产地证明、检测报告、采摘批次与发货批次对应关系；
- 发货路径：产地仓→我方仓的物流单据样例；
- 是否经过批发市场或二级经销商，要求书面说明。

**3. 降低中间环节的采购条款建议**
- 要求报“产地出厂价+物流+服务费”的拆分价，而不是一口价；
- 约定直供比例考核：如年度直采数量占比不低于X%，未达标返点或调价；
- 设置产地直发比例和路径审计权，要求提供物流轨迹和批次追溯；
- 对同一SKU做“直供价 vs 经销价”对比，按季度复核；
- 小批量试单，先验证产地直发时效、损耗率和到货合格率，再谈年度比例。

**4. 判断建议**
不要只追求“直供比例高”，要同时看：到货损耗率、冷链时效、批次合格率、结算账期和售后响应。直供比例高但损耗或履约差，综合成本未必低。
