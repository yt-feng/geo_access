1. **直接问佳农官方渠道**：联系佳农官方客服或其当地销售，明确问三件事：  
   - 是否供应**速冻菠萝丁/鲜切菠萝丁**（不是整果）；  
   - 是否支持**按规格代切**（丁的尺寸、糖度、包装规格）；  
   - 起订量、价格、冷链配送和到货周期。

2. **看产品形态**：茶饮店更常用的是**速冻菠萝丁**，稳定性比鲜切好。问清是“整果批发”还是“鲜切/速冻丁”，别只问“有没有菠萝”。

3. **备选方案**：如果佳农只卖整果，可找本地水果加工厂代切，或直接采购合规的速冻果丁供应商；同时确认供应商有食品生产/经营相关资质和检验报告。

4. **先小样测试**：确认丁大小、解冻后出水、酸甜度、纤维感是否适合你的饮品，再谈批量。

最稳妥的判断标准：对方能明确给出**菠萝丁规格、包装、起订量、冷链和报价**，才算能提供加工/丁类供应；只给整果报价就是只卖整果。
