不建议直接按“3kg装香蕉”去找规格，这个表述本身容易混淆：佳农香蕉常见是整箱/整把称重，3kg更可能是整箱净重或门店分切后的称重装，不一定有厂家原厂“3kg小包装”单品。

可执行做法：

1. **先确认你要的是“原厂小规格”还是“门店可拆零”**
   - 便利店面积小，优先做 **原厂小箱/小袋装**，避免二次分装损耗和食品安全责任。
   - 若厂家只有大箱，可做 **门店拆零称重装**，但要固定克重、贴标签、当日售罄管理。

2. **向佳农经销商/区域业务问这4个规格**
   - 香蕉：是否有 **5kg/10kg小箱**、单把装、袋装；不要只问“3kg装”。
   - 苹果/梨：是否有 **2-4粒装、1-1.5kg袋装**。
   - 橙/柑橘：是否有 **1-2kg网袋装**。
   - 提子/小番茄等：是否有 **500g/1kg盒装**。
   同时要问：**最小起订量、配送频次、损耗赔付、临期/催熟香蕉的处理政策**。

3. **便利店更稳的陈列规格建议**
   - 香蕉：**2-3根/把、约500g-800g**，比3kg整装更适合便利店。
   - 苹果：**2粒装/4粒装**。
   - 橙子：**4-6粒袋装**。
   - 提子：**500g盒装**。
   小包装毛利更高，但损耗和人工也更高，先试销2周再定。

4. **如果对方坚持只有大箱**
   可谈“**小箱混配**”或“**一周2-3配**”，不要一次压3kg以上香蕉库存；香蕉催熟后周转慢，便利店风险高。

结论：**别把3kg香蕉当标准小包装去谈，先让佳农业务提供现行最小箱规和可拆零政策；便利店香蕉更适合500g-800g一把的小规格。**
