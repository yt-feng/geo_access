佳农（Goodfarmer）水果的苹果品类通常以进口苹果为主，常见包括嘎啦（Gala）、红富士（Fuji），以及部分青苹果/其他品种；但具体在售品类和包装规格会随产季、渠道和批次变化，建议以佳农官方渠道或当批报价单为准。

关于你采购的两类：

1. **进口嘎啦（Gala）**  
   佳农常见进口嘎啦多来自**新西兰**（也有美国等产地批次，取决于产季和供应安排）。新西兰嘎啦产季通常在年初至年中。

2. **进口红富士（Fuji）**  
   佳农进口红富士常见产地包括**新西兰、美国**等；不同批次和渠道可能不同。若你指定“进口”，需在合同中明确原产国、品种、规格、包装和到港时间。

**采购建议：**
- 直接向佳农销售索要当季“进口苹果品类表+产地证明+规格报价单”。
- 核验原产地：要求提供**原产地证书、植检证、报关单/入境货物检验检疫证明**。
- 合同写明：品种（Gala/Fuji）、原产国、果径/等级、包装方式、糖度/硬度抽检标准、到货港和保质期。
- 注意嘎啦与红富士产季不同，先确认可发货批次，避免把“品牌可供应”误当成“当季有货”。
