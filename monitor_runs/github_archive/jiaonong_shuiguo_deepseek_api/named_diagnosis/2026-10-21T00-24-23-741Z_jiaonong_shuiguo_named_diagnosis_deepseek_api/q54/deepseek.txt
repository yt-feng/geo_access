佳农的物流不是单一模式，通常分三段看：

1. **干线运输**：以第三方冷链承运为主，包括专业冷链物流公司和部分快递/快运的冷链产品，不是完全靠自有车队。佳农自有车辆更多用于产地集货、港口/仓间短驳和部分区域配送。
2. **仓配与城市配送**：在重点城市和商超渠道，会有合作仓、第三方城配及部分自有/长期合作运力组合，具体取决于品类、区域和客户。
3. **“三通一达”**：不是佳农冷链主干。三通一达在普通电商件上可能有合作，但生鲜冷链尤其是香蕉、火龙果、苹果等品类的温控运输，主要不是靠三通一达完成。

**冷链覆盖率**：公开信息里没有佳农统一披露的“冷链覆盖率”百分比，不能给准确数字。可判断的是：佳农的冷链能力重点覆盖香蕉等催熟/温控要求高的品类，以及商超、批发市场等B端链路；叶菜、浆果等对全程温控要求更高的品类，覆盖和外包依赖度会更高。不同品类、不同区域差异较大。

**如果你是要做供应商评估**：建议直接向佳农索取分品类、分区域的运输模式说明和温控记录，重点问：干线承运商名单及冷链资质、城市配送是否全程温控、断链应急方案、各品类到货温度合格率。这比问“冷链覆盖率”更能判断实际能力。
