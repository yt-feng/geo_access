给你一套可直接执行的核验路径：

1. **看包装标识**：有机产品必须印有中国有机产品认证标志，并标注有机码和认证机构名称。只有“绿色食品”“无公害”标志不算有机。
2. **查有机码**：到“中国食品农产品认证信息系统”（认监委官方平台）输入有机码，核对产品名称、生产企业、认证机构、证书状态和有效期。重点确认证书是否覆盖“菠萝/鲜菠萝”这一品类，以及是否在有效期内。
3. **向供应商索证**：要求佳农或其经销商提供该SKU对应的有机产品认证证书扫描件、证书编号、认证范围、有效期，以及本批次产品的有机销售证（中国有机认证实行“一品一证、一批一证”管理，销售证能对应到具体批次）。
4. **确认进口属性**：若为进口菠萝，需看是否符合中国有机认证要求或按相关规定获得等效认可；仅有境外有机认证（如EU Organic、USDA Organic）不等于自动获得中国有机认可，高端渠道上架前要让供应商书面说明。
5. **合同兜底**：在采购合同里约定“如无法提供有效有机证书及批次销售证，供方承担退货及违约责任”，并要求每批次随货附证。
