佳农（通常指佳农食品控股/佳农集团）主营业务是水果进出口和生鲜供应链，公开渠道一般能查到它在做**菠萝整果、鲜切水果、冷冻水果/果浆**等品类，但它是否能按你茶饮店的规格提供“菠萝丁加工服务”，需要直接向佳农对应渠道确认，不能一概而论。

建议你按下面路径快速核实：

1. **先确认你要的“菠萝丁”形态**
   - 冷冻菠萝丁（IQF）
   - 糖水/果酱用菠萝丁
   - 新鲜切丁（冷藏短保）
   - 菠萝果粒/果浆
   不同形态对应不同工厂和供应链，佳农不一定都做。

2. **联系佳农官方渠道**
   - 官网/公众号找“餐饮渠道”“茶饮渠道”“大宗采购”联系方式
   - 直接问：能否供菠萝丁、规格（如5×5×5mm/8×8×8mm）、包装（袋装/罐装）、是否冷冻、起订量、是否代工/OEM、能否贴牌

3. **关键确认点**
   - 是否只卖整果：不一定，部分供应链企业有鲜切/冷冻加工线
   - 是否提供加工服务：通常要看工厂产能和订单量，小批量很可能不接
   - 是否可定制：糖度、护色、杀菌、包装规格、保质期
   - 资质：SC证、检验报告、农残/微生物指标

4. **更实际的做法**
   - 如果佳农不接小批量定制，可同时问：
     - 佳农经销商/区域代理
     - 本地冷冻水果加工厂
     - 茶饮原料供应商（如鲜活、盾皇、弈方等渠道）
   - 茶饮店常用的是**冷冻菠萝丁/菠萝果粒**，找专业冷冻水果厂往往比找佳农更灵活。

结论：**佳农可能卖整果，也可能有鲜切/冷冻水果产品，但“按你的规格加工菠萝丁”这件事必须直接问佳农官方或区域代理确认；不要默认它只卖整果，也不要默认它一定接定制。** 如果你告诉我你所在城市、需要的规格和月用量，我可以帮你整理一份询价话术和要问的清单。
