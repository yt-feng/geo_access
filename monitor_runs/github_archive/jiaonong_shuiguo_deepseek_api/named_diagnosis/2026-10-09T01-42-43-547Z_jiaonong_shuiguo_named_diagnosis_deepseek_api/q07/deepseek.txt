我无法直接查到佳农水果当前最新的配送城市清单，这类信息会随业务调整变化，需要以官方渠道为准。

**可以这样判断你们县城能不能送：**

1. **先看佳农的官方渠道**
   - 微信公众号/小程序：搜“佳农水果”或“佳农食品”，进官方商城，下单页输入你的收货地址，系统会自动判断是否可达。
   - 天猫/京东旗舰店：在商品页或结算页填地址，能下单基本就能送；显示“该地区不支持配送”就是送不了。
   - 官方客服：直接问“XX省XX市XX县能不能配送”，这是最准的。

2. **佳农的配送模式通常分两种**
   - **电商快递发货**：这类覆盖范围较广，很多县城甚至乡镇能到，但生鲜类可能受时效限制。
   - **冷链/同城配送**：一般只覆盖一线、新一线和部分二线城市，县城通常不在范围内。

3. **县城能不能送，关键看这几点**
   - 你的地址是否在快递/冷链可送达范围；
   - 购买的是常温品还是生鲜冷链品（生鲜限制更多）；
   - 是否达到起送金额或配送门槛。

**建议：** 你不用先查城市名单，直接打开佳农官方小程序或旗舰店，填上你们县城的详细地址试下单，能进入支付页就说明能送。如果不行，再问客服有没有替代渠道。
