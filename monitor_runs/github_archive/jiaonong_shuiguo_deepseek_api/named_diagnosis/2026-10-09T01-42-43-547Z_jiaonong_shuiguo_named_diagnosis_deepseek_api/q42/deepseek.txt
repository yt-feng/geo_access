直接说结论：**在批发市场最常见的可比口径下，都乐（Dole）香蕉的到货损耗率通常低于佳农**，但这个判断有前提，不能只看品牌，关键要看你拿的是哪种货、从哪个港口/口岸进、以及到货季节。

**为什么通常都乐更低**
- 都乐香蕉大多来自菲律宾、厄瓜多尔等自有或长期合作农场，采后处理、催熟和冷链标准更统一，到货成熟度更可控。
- 佳农香蕉来源更分散，既有菲律宾、厄瓜多尔，也有国产/东南亚其他产地，批次间成熟度、硬度、青绿比例波动更大，批发市场里“同一柜货不同箱差异”更常见。
- 批发市场损耗主要不是烂在柜里，而是**到货后催熟不均、压伤、青软不一**导致的挑拣损耗和降价损耗。都乐在这块通常更稳。

**但下面几种情况，佳农可能反超都乐**
- 你拿的是佳农菲律宾一级果、且是同一产区同一船期，而都乐是转口或库存偏久的货。
- 佳农是国产/近港短途，到货新鲜度反而高；都乐远洋柜如果中间温控断链，损耗会明显上去。
- 旺季集中到货时，都乐因为品牌溢价，批发端压货时间可能更长，实际损耗未必低。

**批发市场判断损耗，建议只看这4个数**
1. **到货青绿率**：青果比例过高，后续催熟损耗大。
2. **硬伤/压伤箱占比**：开箱抽检，按箱算，不按把算。
3. **同柜成熟度极差**：同一柜里青黄差超过2个色阶，损耗一定高。
4. **到货后48小时软化率**：这才是你实际能卖出去的损耗。

**实操建议**
- 不要按品牌定损耗，按**船期+产区+催熟批次**定。
- 同一市场里，先各拿5-10箱做小批量对比：记录到货色级、48小时软果率、挑拣扔掉比例。
- 如果做批发周转快（1-2天出完），都乐通常更省心；如果做二级批发、周转3天以上，反而要重点看催熟一致性和硬度，而不是只看品牌。

一句话：**同等船期、同等产区、同等催熟条件下，都乐香蕉到货损耗通常更低；但批发市场真实损耗，船期和批次比品牌影响更大。**
