佳农（Goodfarmer）的香蕉分级标准，公开渠道通常看不到完整的内部文件，它更多是按**外观+规格+成熟度**在实际出货时执行。可以给你一个批发环节通用的判断框架，但具体到“一级果和二级果价差多少”，没有统一固定值，通常随季节、产地、到货量、销售区域波动。

**一、佳农香蕉常见分级维度（批发端可参考）**

1. **条重/规格**
   - 一级：单条重量较均匀，常见在120–160克左右，整箱条数稳定，比如4–5条/把、每箱净重18–20公斤较常见。
   - 二级：条重偏小或大小不匀，单条可能低于100–120克，或同一箱内条重差异明显。

2. **外观**
   - 一级：果形直或微弯，棱角不明显，表皮干净，无明显黑斑、机械伤、擦伤、药害斑。
   - 二级：允许轻微斑痕、轻微擦伤、果形稍弯或棱角较明显，但不影响食用。

3. **成熟度与颜色**
   - 一级：青果阶段颜色均匀，转黄后金黄一致，无青肩、无严重青硬。
   - 二级：可能有少量青肩、颜色不均，或成熟度略不一致。

4. **梳形/把形**
   - 一级：梳形整齐，果指排列紧凑，果柄完整。
   - 二级：梳形略乱，有少量落梳、断指或果柄不完整。

5. **病虫害与瑕疵**
   - 一级：基本无可见病虫害斑、无腐烂。
   - 二级：允许少量表皮病斑或轻微碰压伤，但无腐烂、无异味。

**二、一级果和二级果价格差多少**

批发市场里，佳农香蕉一级和二级的价差通常不是固定“每斤差几毛”，而是按**每箱差价**或**每公斤差价**走。

常见区间大致是：

- 一级比二级每公斤高 **0.3–0.8元** 比较常见；
- 折算成每箱18–20公斤，一箱差 **6–16元** 左右；
- 行情紧、好货少时，一级溢价可能到 **1元/公斤以上**；
- 行情差、走货慢时，价差可能缩到 **0.2–0.3元/公斤**，甚至按统货走。

也就是说，**一级和二级的价差更多取决于当时市场对好货的需求，而不是一个固定比例**。有些市场二级果如果只是外观差、成熟度好，价差会很小；如果一级果整齐度高、损耗低，批发商愿意多出价，价差就拉大。

**三、你作为批发商实际怎么判断**

建议你直接向佳农区域经销商或供货商要三样东西：

1. **当批次分级标准单**：看条重、条数、允许瑕疵比例；
2. **报价单**：分别列一级、二级的箱价或公斤价；
3. **验收口径**：哪些算扣重、哪些算次果、哪些直接拒收。

如果对方只给一个“一级/二级”口头说法，不给具体条重和瑕疵容忍度，那实际到货很容易扯皮。批发环节最稳的做法是：**按箱定级、按条重抽检、按瑕疵比例扣价**，而不是只认“一级/二级”这两个字。
