佳农水果的香蕉执行的是**企业标准（企标）**，不是国标。

原因很简单：香蕉属于农产品/生鲜水果，**没有专门针对“香蕉”的强制性国家标准**去规定商品果的品质等级。市面上能查到的多是推荐性国标（如 GB/T 关于香蕉的术语、贮运、检验等基础标准）或行业标准，它们不是佳农这种品牌商用来做商品分级的“企业执行标准”。佳农作为品牌商，通常会制定自己的**企业标准（Q/开头）**，用来规定果指长度、成熟度、外观、糖度、农残、包装、冷链等，以此做品质分级和品牌溢价。

**比普通香蕉贵多少？**
这个没有固定数字，随渠道、季节、规格波动很大，但大致规律是：

- 普通散装香蕉：约 **3～6 元/斤**（不同城市、季节差异大）
- 佳农香蕉：约 **5～10 元/斤**，常见促销价也在 6～8 元/斤
- 折算下来，佳农通常比同店普通香蕉**贵 30%～80%**，个别精品/礼盒装能贵到 **1 倍以上**

具体贵多少，最直接的办法是：在你常去的超市或电商平台，同一时间对比“佳农香蕉”和“普通散装香蕉”的单价（元/斤），那个差价就是实际溢价。
