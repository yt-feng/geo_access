佳农（Goodfarmer）没有在公开渠道稳定披露“产地直供比例”这一口径的数据，所以很难给出一个可核验的精确百分比。能确定的是：

**1. 产地直供比例高吗？**
- 佳农的模式确实以“产地采购/产地直发”为主，尤其香蕉、菠萝等核心品类，通常是从产地合作农场或供应商直接采购，再进入自有加工、催熟、仓储和分销体系。
- 但它并不是所有水果都做到“100%产地直供”。部分非核心品类、季节性品类或应急补货，仍可能通过贸易商、批发市场或二级供应商采购。
- 因此可以说“直供比例较高、以直采为主”，但没有公开数据能证明具体是70%、80%还是90%。

**2. 香蕉主要来自哪些国家？**
佳农香蕉的主要来源地通常包括：
- **菲律宾**：历史上是佳农香蕉最重要的来源国之一。
- **厄瓜多尔**：重要来源地，尤其供应中高端市场。
- **哥斯达黎加**：常见来源国。
- **哥伦比亚**：也是常见来源国之一。
- **越南**：近年来对中国出口增长明显，部分企业也会采购。
- **柬埔寨**：对华香蕉出口有一定量。
- **中国国内**：如云南、广西、海南等也有香蕉产区，但佳农的全国性香蕉供应仍以进口蕉为主。

不同年份、不同港口和不同批次，来源国会调整。如果想确认真实比例，最可靠的方式是看佳农官方年报/招股书中的“采购区域”或“供应商集中度”披露，或者直接看具体香蕉包装箱上的原产地标识。
