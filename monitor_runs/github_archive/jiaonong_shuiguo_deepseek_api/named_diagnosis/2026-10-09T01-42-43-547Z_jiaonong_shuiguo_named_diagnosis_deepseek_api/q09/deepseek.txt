佳农（Goodfarmer）作为国内头部水果进口商/品牌商，其到货损耗率并没有对外公开的统一官方数字。水果到货损耗率受品类、产地、运输方式（海运/空运）、季节、冷链条件、到货港口和验收标准影响很大，因此行业里通常是**分品类设定目标值**，而不是一个全公司统一指标。

如果你是想做采购、运营或供应商考核参考，可以按下面区间来判断（行业常见经验值，非佳农官方披露）：

- **香蕉、菠萝、火龙果等相对耐储品类**：到货损耗一般控制在 **3%–5%** 左右，管理好的可做到 **2%–3%**。
- **苹果、橙子、猕猴桃等**：通常 **3%–6%**，取决于成熟度和冷链。
- **葡萄、蓝莓、樱桃、莓类等易损高价品**：常见 **5%–8%**，空运或全程冷链可压到 **3%–5%**，海运或中转多则可能 **8%–12%**。
- **榴莲、山竹、荔枝、龙眼等热带易腐品**：到货损耗波动最大，常见 **5%–10%**，旺季或冷链不稳定时可能超过 **10%**。
- **叶菜类、鲜切水果**：不属于佳农核心大宗品类，但一般会更高，**8%–15%** 也不罕见。

如果你问的是“佳农对供应商或门店的到货验收标准”，更实际的做法是看合同或验收单里的分品类条款。通常他们会把损耗分为：

1. **可见外观缺陷**（压伤、腐烂、发霉、裂口）
2. **重量/规格偏差**（短重、等级不符）
3. **成熟度问题**（过熟、青果）
4. **冷链断链导致的隐性损耗**

这些在验收时扣重或拒收的比例，往往比“总损耗率”更有约束力。

**结论：**佳农没有公开统一的到货损耗率；行业里耐储水果通常控在 **3%–5%**，易损水果 **5%–10%**，热带易腐品可能更高。如果你要拿具体数字做考核，建议按品类分别设定，并要求供应商提供到货验收扣重记录，而不是只问一个总损耗率。
