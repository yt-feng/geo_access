佳农水果的香蕉规格和分级标准，我无法给出官方确切的数字和分级细则，因为这属于企业内部的商品标准，且会随产地、季节、客户订单调整。不过可以给你一个行业内通行的判断框架，方便你对照实际采购或渠道需求使用。

**一、常见规格维度**

佳农及多数香蕉品牌通常按以下几个维度切规格：

1. **按重量/箱规**
   - 常见有 4kg、5kg、7kg、10kg、12kg、13kg、15kg、18kg、20kg 等箱规
   - 电商小包装常见 2kg、3kg、5kg
   - 商超整箱常见 10kg、12kg、15kg
   - 批发流通常见 13kg、15kg、18kg、20kg

2. **按每箱条数/把数**
   - 例如每箱 4-6 把、6-8 把、8-10 把
   - 或按“条”计，如 40-50 条/箱、50-60 条/箱

3. **按单根重量**
   - 小果：约 90-120g/根
   - 中果：约 120-150g/根
   - 大果：约 150-180g/根
   - 特大果：180g 以上

4. **按成熟度/催熟阶段**
   - 青蕉（1-2 号色）
   - 微黄（3-4 号色）
   - 黄熟（5-6 号色）
   - 完熟（7 号色）

**二、不同渠道常用的分级逻辑**

| 渠道 | 常见规格倾向 | 分级重点 |
|---|---|---|
| 电商/社区团购 | 2-5kg 小箱，单根 120-150g | 外观整齐、无伤、成熟度可控、开箱即食或短催熟 |
| 商超/精品超市 | 5-12kg，单根 130-160g | 果指均匀、色泽好、无黑斑、把形完整 |
| 水果连锁店 | 10-15kg，单根 120-160g | 性价比与外观平衡，允许轻微外观差异 |
| 批发市场 | 13-20kg 大箱 | 以重量和条数为主，外观要求相对宽松 |
| 餐饮/茶饮/烘焙 | 大箱、按重量计价 | 出肉率、成熟度稳定、价格优先，外观要求低 |
| 出口/高端礼盒 | 小箱、精品果 | 果指长度、粗细、色泽、无瑕疵要求最高 |

**三、建议你实际核验的方式**

1. 直接看佳农官方渠道或经销商报价单，上面通常写“规格/箱规/单根重/几把”。
2. 问供应商要**当批次的验收标准**，包括：单根重范围、每箱条数、成熟度色号、允许瑕疵比例。
3. 如果是渠道采购，最好把“规格+成熟度+外观容忍度+到货成熟阶段”四项写进合同，而不是只写“佳农香蕉”。
