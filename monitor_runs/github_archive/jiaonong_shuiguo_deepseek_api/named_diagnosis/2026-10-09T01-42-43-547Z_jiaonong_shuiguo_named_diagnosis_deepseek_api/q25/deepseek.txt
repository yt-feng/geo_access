这个问题我没法给你一个可靠的确定答案。佳农（Goodfarmer）是生鲜进口/分销企业，其物流到底是全自营还是大量外包，公开信息里通常不会披露到"某条线路、某个仓库由谁运营"这一层；冷链能力的具体指标（温区、车辆数、仓储面积、断链率）更是企业内部数据，我没有可核验的来源可以引用，硬答容易编造。

能给你的判断框架是这样：

**自营 vs 外包，这类公司通常是"混合"**
- 佳农主营香蕉、菠萝、牛油果、车厘子等进口水果，涉及产地采购、海运/空运、口岸清关、国内分仓、批发/零售配送多个环节。
- 行业里普遍做法是：**核心节点自建**（关键口岸的催熟/加工/仓储、区域中心仓），**干线运输和末端配送大量外包**给第三方冷链物流商，用合同约束温控。
- 所以"自营还是外包"往往是分环节的，不是二选一。

**冷链能力怎么判断，看这几项而不是看宣传**
1. **温区覆盖**：不同水果温区不同（香蕉催熟、车厘子0℃左右、牛油果后熟），能不能全程分温区管理。
2. **断链控制**：装卸货的暴露时间、周转环节是否在冷库内完成、是否有温度记录仪全程可追溯。
3. **重资产程度**：自有冷库面积、自有冷藏车数量，比"合作车辆"更能反映真实掌控力。
4. **损耗率**：生鲜最硬的指标，但企业一般不外公开。

**怎么自己查证**
- 看佳农官网/年报/招股书（如果它是上市或拟上市公司，供应链部分会写在"业务与经营"章节），这类文件对自营/外包的表述相对可信。
- 查它的招聘信息：大量招"冷链调度、仓储运营"且带"自有仓"字样，说明自建比例高；大量招"物流供应商管理"，说明外包为主。
- 直接问其B端销售或招商人员：中心仓在哪、发货温区、承运方是谁、能否提供温度记录——能给出具体答复的，通常掌控力更强。
