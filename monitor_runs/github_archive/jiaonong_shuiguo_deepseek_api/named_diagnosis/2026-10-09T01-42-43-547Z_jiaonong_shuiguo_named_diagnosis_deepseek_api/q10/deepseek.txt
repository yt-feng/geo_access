佳农（佳农食品控股）对大客户/批发渠道一般是有专门对接的，但具体到你这家批发商是否已经分配客户经理，取决于你目前的合作层级和采购规模：

1. **如果你已经和佳农直接签约或走直供**
   - 通常会有对应的销售代表/客户经理负责。
   - 对接人可能是区域销售、渠道销售或大客户经理。
   - 你可以直接问现有对接人：“我的专属客户经理是谁？后续订单、价格、售后由谁负责？”

2. **如果你是通过经销商/批发市场档口拿货**
   - 这种情况下不一定有佳农厂家的客户经理直接对接你。
   - 你对口的通常是经销商或档口老板，佳农只对接他们的渠道商。

3. **如果你想申请专门客户经理**
   - 可以联系佳农官方客服或区域销售，说明：
     - 你是批发商
     - 每月/每季度大概采购量
     - 主要采购品类（香蕉、菠萝、火龙果等）
     - 希望直供或稳定供货
   - 采购量达到一定规模后，通常会安排销售经理对接。

**建议你直接问对方一句话：**
> “我们这种批发商，后续是固定客户经理对接，还是走渠道/经销商？如果采购量上来，能不能申请直供和大客户经理？”

如果对方说“没有专门客户经理”，那基本说明你目前走的是经销/档口渠道，还不是佳农直营大客户。
