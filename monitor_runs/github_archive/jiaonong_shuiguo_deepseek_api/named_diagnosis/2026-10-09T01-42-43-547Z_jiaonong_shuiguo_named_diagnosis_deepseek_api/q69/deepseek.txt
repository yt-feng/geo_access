2. **直接问销售或客服这几个关键问题**
   - 有没有餐饮渠道专供的菠萝切片/切块？
   - 规格是：厚度多少mm、每片多少g、每袋多少kg、每箱多少袋？
   - 是冷冻、冷藏还是常温？
   - 是否支持贴牌/定制包装？
