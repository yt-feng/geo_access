佳农（佳沃/佳农集团）**有可能谈锁价合同，但通常不会对单一门店直接给“长期固定一口价”**，尤其是菠萝这种受产季、气候、海运、汇率影响较大的鲜果/冷冻果原料。更现实的做法是：**框架协议 + 阶段性锁价 + 量价联动 + 价格调整机制**。

你可以按下面几个点去判断和推进：

1. **先确认你要的原料形态**
   - 鲜菠萝：锁价难度最高，产季、品质、损耗波动大。
   - 冷冻菠萝块/菠萝丁/菠萝果酱：锁价可行性更高，因为加工品库存周期长、标准化程度高。
   - 菠萝浓缩汁/果浆：也相对容易做季度或半年锁价。

2. **10吨/月的量，对佳农算什么级别**
   - 对茶饮连锁不算特别大，如果是单店或小连锁，佳农未必愿意单独开锁价合同。
   - 如果你能集合多个门店、区域加盟商或年度总量，比如做到**120吨/年以上**，谈判空间会明显变大。
   - 如果只是单店10吨/月，更可能拿到的是**年度框架价、季度锁价、保底量返利**，而不是全年固定价。

3. **佳农一般可能接受的锁价方式**
   - **季度锁价**：一个季度内固定单价，下季度随行就市重谈。
   - **半年锁价 + 浮动上限**：约定涨幅不超过3%–5%。
   - **保底量 + 阶梯价**：每月10吨保底，超过部分给更低价格。
   - **原料成本联动**：比如参考菠萝产地价、海运价、汇率，设一个调价公式。
   - **锁价但不锁量**：价格固定，但供应量按产季和工厂排产调整。

4. **你真正要防的是价格波动，不是非要固定价**
   可以谈这些条款：
   - 价格有效期：3个月/6个月。
   - 最大涨幅限制：比如不超过5%。
   - 跌价同步下调：市场明显下跌时，采购价跟随下调。
   - 保供条款：缺货时优先给你。
   - 质量稳定条款：糖度、规格、水分、包装、解冻损耗。
   - 违约和赔偿：断供、质量不达标怎么赔。

5. **谈判前你要准备的数字**
   - 每月10吨，年度120吨。
   - 你能接受的最高价、目标价。
   - 你能承诺的保底采购量。
   - 付款方式：现款、月结30天、预付比例。
   - 是否接受冷冻替代鲜果。
   - 是否愿意签1年框架协议。

6. **直接判断**
   - 如果你要**鲜菠萝全年固定价**：佳农大概率不会轻易签，或者价格会加很高风险溢价。
   - 如果你要**冷冻菠萝/果浆季度或半年锁价**：可行性较高。
   - 如果你只是**单店10吨/月**：大概率只能拿到短期锁价，不是全年锁价。
   - 如果你能**联合采购、年量上百吨、预付或现款**：可以争取到较好的锁价条件。

建议你直接这样问佳农销售：

> 我们茶饮店每月稳定采购10吨菠萝原料，年度约120吨，想签年度框架协议。希望按季度锁价，或者半年锁价并设置涨幅上限。请提供：鲜果、冷冻果块、果浆三种形态的锁价方案、最小起订量、价格有效期、调价机制和保供条款。

如果对方只肯给“随行就市”，你可以退一步谈：**季度锁价 + 最大涨幅5% + 保底量返利**。这比追求全年一口价更现实。
