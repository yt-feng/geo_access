佳农（Goodfarmer）的香蕉通常不是“树上自然熟”到门店状态，而是**采后人工催熟**。行业里香蕉催熟主流用**乙烯气**或**乙烯利**，因为香蕉是典型呼吸跃变型果实，采后需要人为启动后熟。

**对你商超控时的直接建议：**

1. **先确认佳农到货形态**
   - 如果到货是**青蕉/硬绿蕉**：基本可以判定是采后未催熟或只做了“启动处理”，需要你们或配送中心继续催熟。
   - 如果到货是**黄绿、微黄、已有香气**：多已在产地/加工中心完成催熟，你只需控温、控乙烯、控时间做“后熟管理”。

2. **商超常见控制方式**
   - **乙烯催熟**：在催熟房用乙烯气体，温度一般 **15–18°C**，湿度 **85–95%**，根据目标颜色和货架期安排 **2–5天**。
   - **乙烯利催熟**：药液/浸果或喷洒，常用于部分产地和批次，起效也快，但残留和均匀性要关注。
   - **自然熟**：不额外加乙烯，只靠自身释放乙烯，速度慢、批次差异大，商超批量管理一般不作为主工艺。

3. **你要控“催熟时间”就抓这几个变量**
   - **温度**：越高越快，但超过 **20°C** 容易过快、发酸、货架期短；低于 **13°C** 易冷害、催不熟。
   - **乙烯浓度/暴露时间**：浓度越高、暴露越久，启动越快。
   - **通风与CO₂排出**：催熟房要换气，CO₂积累会抑制后熟。
   - **果实成熟度**：到货青硬度决定基础时间，不能只按固定天数。
   - **目标色号**：按你商超要的“几号色”倒推时间，不要等全黄再出库。

4. **实操判断**
   - 想**快出**：温度取上限、乙烯足、催到 **3–4号色** 就转冷藏/卖场。
   - 想**延长货架**：催到 **2–3号色** 就结束，后续在 **13–15°C** 条件下缓慢转黄。
   - 如果佳农到货已经是 **4号色以上**：不要再催，直接控温销售，否则很快过熟。

5. **最稳妥的做法**
   - 向佳农供应商要**该批次催熟状态、到货色号、建议后熟温度和时间**。
   - 自己做小批测试：同温同湿下，记录 **24h/48h/72h** 的色号和硬度，形成你们商超自己的催熟曲线。
   - 不要默认“佳农=自然熟”。多数商品香蕉是**人工催熟或采后处理**，自然熟只适合少量特定渠道。
