佳农有部分小规格/精包装产品，但具体到“3kg装香蕉”是否常备、能否供你所在区域，需要以佳农当地经销商或区域业务给的报价单为准，我这边无法核验其当前在售规格。

给你几个可执行的判断方向：

1. **香蕉这类鲜果，3kg装不太常见**
   - 便利店更适合的是：**1kg–2kg小把装、单根/两根装、即食小盒装**。
   - 3kg装通常偏水果店/社区团购/餐饮渠道，放便利店容易压货、熟得快、损耗高。

2. **佳农常见小包装方向**
   - 香蕉：小把装、袋装、盒装，部分区域有 **1kg、1.5kg、2kg** 左右规格。
   - 其他水果：椰子、菠萝、蓝莓、车厘子、苹果、猕猴桃等，往往有 **单果装、小盒装、礼盒装**。
   - 但不同城市、不同渠道政策不同，不能只看品牌，要看当地供货商实际SKU。

3. **你上架前直接问经销商这4个问题**
   - 有没有 **3kg以内** 的香蕉/水果小包装？
   - 最小起订量是多少？可否混搭？
   - 供货价、建议零售价、毛利大概多少？
   - 破损、催熟、临期能不能换货或补损？

4. **小店更建议的选品策略**
   - 先上 **1–2kg小包装香蕉** 试销，不要一上来上3kg。
   - 优先选 **即食、小份、周转快** 的规格。
   - 如果门店没有冷藏/控温条件，香蕉、蓝莓、车厘子这类损耗要特别谨慎。
   - 可以要求经销商先给 **小批量试销政策**，卖得动再扩规格。
