目前没有佳农官方公开信息能确认它提供“去皮切块”这类定制加工服务，而且这类服务通常要看**采购渠道、采购量、区域和产品线**，不能一概而论。

对茶饮店来说，建议你直接这样确认：

1. **问采购对接人/经销商**
   明确问：  
   - 有没有“鲜切菠萝块/去皮菠萝”产品？  
   - 能不能按你们需要的规格切块？  
   - 是佳农工厂加工，还是经销商/第三方加工？  
   - 冷链配送还是冷冻配送？

2. **确认产品形态**
   佳农常见更多是**整颗鲜菠萝、菠萝罐头、冷冻菠萝、菠萝果浆/果汁**等。  
   如果它没有鲜切块，你可以考虑：
   - 买佳农整果，自己门店加工；
   - 找本地净菜/鲜切水果供应商代加工；
   - 用冷冻菠萝块或菠萝果浆替代，稳定性更高。

3. **算成本和食品安全**
   茶饮店用鲜切菠萝，重点不是“能不能切”，而是：
   - 加工后保质期很短，通常冷藏也就1–3天，具体看工艺和包装；
   - 需要供应商有相应食品生产/经营资质；
   - 切块规格、糖度、成熟度是否稳定；
   - 配送频率能不能匹配你们门店用量。

4. **更现实的方案**
   如果你用量不大，通常佳农或大型经销商不会单独给你做定制去皮切块。  
   如果用量大，可以谈“鲜切菠萝块”代工或找专业鲜切工厂，用佳农菠萝作为原料。

**结论：**  
不能直接假设佳农提供去皮切块服务。最快的方法是联系你的佳农采购渠道，问是否有“鲜切菠萝块”或“定制加工”产品。如果没有，建议找本地鲜切供应商代加工，或改用冷冻菠萝块/果浆。
