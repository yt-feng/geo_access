佳农（尤其是其香蕉、菠萝等核心品类）对外公开的具体“产地直供比例”没有稳定的公开权威数字，而且这个比例会按品类、年份和渠道口径变化，所以我无法给你一个可核验的准确百分比，不建议直接拿某个网传数字做采购依据。

从采购降本的角度，更可执行的做法是直接向佳农索取可核验的口径和报价结构。你可以要求对方提供：

1. **按品类的直供占比定义**
   - 是指“自有/合作种植基地直发”，还是“产地采购后经佳农仓配到门店”？
   - 佳农很多操作是产地采购+全国仓配，不等于你理解的“基地到店零中间环节”。

2. **报价拆解**
   - 产地收购价/基地结算价
   - 分选、包装、冷链、仓储、干线运输、配送
   - 佳农服务费/毛利
   - 损耗承担方和结算方式
   只有拆开看，才能判断降本空间在哪里。

3. **可否绕开佳农做产地直采**
   - 对香蕉、菠萝这类标准化程度较高、产地集中的品类，直采可行性相对高；
   - 但你需要自己承担催熟、冷链、损耗、账期和产地关系，实际总成本未必低于佳农。

4. **谈判筹码**
   - 要求按品类给“产地直发价”和“经仓配价”两套报价；
   - 要求年度采购量对应的阶梯价；
   - 要求开放产地/加工厂验厂；
   - 对比其他产地直采服务商或产地合作社。

如果你要的是“佳农官方披露的直供比例”，建议直接向其销售或官网/年报渠道索取；如果是“我们想降本，直供比例到底重不重要”，结论是：**比例本身参考价值有限，报价拆解和实际履约成本更重要。**
