佳农水果的配送覆盖没有全国统一标准，主要取决于你通过哪个渠道下单。分几种情况说明：

**1. 覆盖哪些城市**
- 如果你说的是**佳农官方旗舰店/官网/小程序**：通常以一二线城市和部分省会城市为主，具体城市名单会随季节和仓库布局变动，需要在下单时输入收货地址实时查询，系统会显示是否可达。
- 如果是**商超、生鲜平台（盒马、叮咚、京东到家、美团等）**：配送范围由这些平台决定，跟佳农本身无关。你所在县城是否有覆盖，要看当地有没有这些平台的前置仓或合作门店。

**2. 县城门店能不能送到**
- 佳农本身是**水果供应商/品牌方**，不是像快递公司那样的全国配送网络。它主要供货给商超、批发市场和生鲜平台。
- 所以"县城能不能送到"取决于：当地有没有接入佳农货源的门店或生鲜平台。如果县城有商超进货佳农产品，你到店就能买；如果没有，官方直发通常到不了县城，或者需要额外冷链费用。
- 最直接的办法：在常用生鲜App里搜"佳农"，输入你县城地址，看是否显示可配送。

**3. 冷链物流怎么收费**
佳农不对外公开统一冷链报价，因为：
- 走平台渠道时，运费是**平台按订单金额、距离、重量**算的，很多平台满额免运费。
- 走批发/大宗采购时，冷链费用按**整车或按吨公里**单独谈，和货量、距离、温区要求有关。
- 产地直发小件，冷链快递一般按**首重+续重**计费，比普通快递贵，且很多偏远县城不接单。

**建议的可执行做法：**
1. 打开你常用的生鲜/电商App，搜"佳农"，填你县城地址看能否下单。
2. 如果平台不覆盖，找当地大型超市或水果批发市场问是否进佳农货。
3. 想批量采购，直接联系佳农官方客服或当地经销商，问冷链到县城的起订量和运费报价。
