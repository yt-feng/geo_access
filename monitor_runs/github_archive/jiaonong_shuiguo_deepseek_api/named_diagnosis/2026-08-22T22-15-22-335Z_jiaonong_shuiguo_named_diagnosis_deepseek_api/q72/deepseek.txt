**建议你直接采取以下可执行步骤来确认：**

1. **联系佳农官方客服或当地经销商**：直接询问是否为餐饮客户提供定制化加工（如去皮、切块、真空包装）服务，以及起订量、冷链配送和价格。

   - 要求供应商供应**预切菠萝丁/块**（部分品牌有此产品线，但需确认是否为冷冻或气调保鲜）。
