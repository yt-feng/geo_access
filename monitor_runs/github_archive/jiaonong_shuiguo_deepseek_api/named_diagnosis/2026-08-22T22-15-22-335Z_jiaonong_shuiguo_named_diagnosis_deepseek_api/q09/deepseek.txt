佳农作为大型水果供应链企业，其到货损耗率会根据品类、运输距离、包装方式及渠道（商超/电商/批发）有所不同。通常行业内的参考标准如下：

1. **常规大宗水果（如香蕉、苹果、柑橘类）**：到货损耗率一般控制在 **3% - 8%** 之间。如果是短途或冷链完善的订单，可控制在 **5%以内**。
2. **易损耗水果（如草莓、蓝莓、荔枝、葡萄等）**：由于皮薄或呼吸作用强，到货损耗率通常相对较高，一般在 **8% - 15%** 之间，部分极端情况下（如远途或夏季）可能达到20%。
3. **精品/进口水果（如车厘子、牛油果）**：通常控损要求严格，一般控制在 **5% - 10%**。

需要说明的是，**上述数据为行业经验值，并非佳农官方公开的固定指标**。佳农内部通常按“到货鲜度合格率”和“售后赔付率”双重考核，实际损耗还与收货方的验收标准、温控执行情况高度相关。

如果你需要采购或商务洽谈，建议以该批次合同中的“到货损耗率”条款为准，一般会注明“超过约定比例部分由供货方承担”。如果你需要更精确的数据，可咨询佳农官方客服或业务代表。
