佳农香蕉的**保质期**通常为**7-10天左右**（从包装日期起算），但具体时长取决于成熟度和储存环境。

**储存条件建议：**

1. **未成熟（青皮）** ：常温（18-25℃）下放置2-4天，待皮变黄、果肉变软后即可食用。不要放入冰箱，低温会抑制成熟，导致无法变甜。
2. **已成熟（黄皮，无斑点）** ：常温下保存约2-3天。若想延缓衰老，可放入冰箱冷藏室（4-8℃），但**不要清洗**，放入保鲜袋并扎紧袋口，可存5-7天（皮会变黑属正常，果肉不受影响）。
3. **已过熟（有黑色斑点/软烂）** ：尽快食用，或切片冷冻保存（可存1个月，用于烘焙或冰沙）。

**注意：**
- 香蕉**不宜与苹果、梨等同放**，它们释放乙烯会加速香蕉成熟。
- 整串香蕉建议**用保鲜膜包住根部**，可减少乙烯聚集。
- 如需长期储存，可剥皮后切段冷冻。

如果你买到的佳农香蕉有具体生产日期，建议以包装上标注为准。以上为通用建议。
