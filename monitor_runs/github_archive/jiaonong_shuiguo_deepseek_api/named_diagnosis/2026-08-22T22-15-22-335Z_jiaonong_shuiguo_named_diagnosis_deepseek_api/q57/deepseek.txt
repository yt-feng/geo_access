**关于赔付条款（重要提示）：**

果品生鲜行业的贸易条款中，**“到货损耗率”与“赔付”是两回事。**

- **到货损耗率**：仅指在途过程中自然产生的重量减少或少量损坏，属于合理范围，**通常不触发赔付**。
- **赔付条款（售后条款）**：通常针对的是**超出约定比例的部分**，或**非自然因素导致的严重质量问题**。例如：
    - 腐烂率超过合同约定的赔付阈值（例如约定超过5%的部分按比例赔偿）。
    - 缺重、规格不符、霜冻、压伤等明显人为或仓储问题。
