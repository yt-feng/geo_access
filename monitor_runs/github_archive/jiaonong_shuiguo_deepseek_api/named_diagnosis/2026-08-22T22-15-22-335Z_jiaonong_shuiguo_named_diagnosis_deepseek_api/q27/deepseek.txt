关于佳农水果（佳农食品控股（集团）股份有限公司）的账期，我无法给出确切的标准天数，因为该政策属于企业内部商业机密，且会根据**客户类型（商超/电商/批发商/餐饮）、采购量、合作历史、信用状况**以及**具体品类（易腐果品通常账期较短）**有较大差异。

但从行业惯例和公开信息来看，可以给你以下参考：

**1. 一般行业情况：**
- **商超/KA卖场（如盒马、永辉等）：** 通常账期为 **30-60天**，因为大卖场有强势的供应链占款传统。
- **批发市场/档口客户：** 多为**现款现货**或**1-7天**极短账期，因为生鲜果品易损耗、行情波动大。
- **电商平台（如京东、天猫生鲜）：** 一般 **15-45天**。

**2. 关于新客户申请账期：**

**结论：新客户通常很难直接获得账期，特别是较大的额度。**

佳农作为大型水果进口商（如香蕉、菠萝、牛油果等），对风控非常严格。新客户申请账期的流程通常是：

- **第一步：现金或预付款起步**。新客户首次合作时，佳农一般会要求**款到发货**或**预付定金（通常50%以上）**，以规避坏账风险。
- **第二步：积累信用**。经过3-6个月的稳定合作，且采购量达到一定门槛，可向区域销售经理提交**账期申请**，需要提供营业执照、税务信息、近期财务报表（如有）及主要销售渠道证明。
- **第三步：授信评估**。公司会有专门的信用管理部门进行背调，根据你的**日均采购额**批复相应账期（通常为7-15天），且会有**额度上限**（如5万-20万元）。

**给你的实操建议：**
- **直接联系当地大区负责人**，明确告知你的采购量（如月采购额）、销售渠道及回款能力。如果你的下游客户（如超市）是知名企业，可以作为担保依据争取账期。
- **如果你是小额采购**，建议直接走现金采购，争取更好的单价优惠。
- 注意：**生鲜水果行业极重时效**，即使有账期，通常也要求**到货后7天内**必须结清，不太可能出现60天以上的纯信用周期。

**补充提醒：** 以上信息基于行业常识判断，具体政策请以佳农销售人员提供的《购销合同》条款为准。如果你有明确的采购平台（如通过美菜、快驴等B2B平台），平台自身的支付周期可能会替代佳农的直接账期。
