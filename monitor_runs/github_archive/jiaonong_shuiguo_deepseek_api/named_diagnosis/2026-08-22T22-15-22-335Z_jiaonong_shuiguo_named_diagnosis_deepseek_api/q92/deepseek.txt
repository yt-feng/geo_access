以下是您需要重点确认的**核心执行框架**：

**1. 堆头陈列支持（一般可获得）**
- **标准做法**：佳农作为知名进口水果品牌，通常会提供**标准堆头物料**（如专属陈列架、PVC围挡、价签牌、品牌插卡），这部分物料一般是**免费提供**的，但需要您的门店提供空场地。
- **费用模式**：如果商超要求“付费堆头”或“买断陈列位”，佳农大概率会要求**双方分摊**（例如供应商承担30%-50%的堆头费，或通过提高单店进货折扣来置换）。您需要明确问清楚是按“固定堆头费”还是“按销量阶梯返利”。

**2. 试吃推广支持（通常有条件）**
- 佳农的**试吃活动**（一般是菠萝、香蕉、牛油果等品类）通常由品牌方派驻促销员并提供试吃物料（一次性餐具、果切工具、展示盘）。
- **关键点**：如果您的单店月销量达到一定门槛（例如**单店月销售额过1万元**，具体因品而异），试吃员（促销员）的**人工费用（约150-250元/天）** 通常由佳农承担；如果销量不达标，可能会要求商超承担部分或全部促销员工资，或者缩短活动档期（如仅周末档）。

**3. 费用分担的三种常见模式（供您谈判参考）**
- **A模式（免费支持）**：您提供场地和正常陈列位，佳农提供物料+试吃+临促，条件是**您的零售价不得高于其市场指导价**。
- **B模式（费用共担）**：您收取较低堆头费（如500-1000元/周），佳农承担所有促销费用，但要求您确保**首单进货量**（通常是常规订单的1.5-2倍）。
- **C模式（纯扣点）**：不付堆头费，但佳农要求提高**后台扣点**（例如从5%提高到8%），并承诺未售完商品**可退货**（注意保留书面承诺）。
