关于佳农水果的配送时效，我无法提供确切的实时数据，因为这主要取决于**下单平台**（如京东、天猫、拼多多、官方小程序等）、**收货地址**以及**所选物流**（顺丰、京东物流等），不同地区和订单类型的时效差异较大。

不过，我可以给你一些参考性的通用建议：

1.  **查看商品页标注**：在结算页面或商品详情页，通常会显示“预计发货时间”或“预计送达时间”，这是最准确的依据。
2.  **生鲜配送特点**：佳农作为生鲜品牌，通常使用冷链快递。一般**下单后24小时内发货**（部分边远地区可能延迟），发货后**同城或周边城市通常1-2天送达**，跨省一般**2-3天**（偏远地区可能需要3-5天）。
3.  **高效渠道**：如果你在京东或天猫超市购买，且仓配一体（比如所在城市有前置仓），通常能实现**次日达**甚至**当日达**；如果是从品牌产地直发，则时效会稍长。
