**1. 配送覆盖城市（权威核实渠道）**
佳农主要覆盖**一线及新一线城市**（如北上广深、杭州、成都、武汉等），县级市场通常**不直接配送**。具体以官方为准：
- **微信小程序/公众号**：搜索“佳农食品”或“佳农水果”，进入“配送查询”或下单页面，输入你的县城地址，系统会实时显示是否支持配送。
- **电商平台店铺（京东/天猫旗舰店）**：商品详情页通常会标注“配送范围”或“偏远地区不发货”，你可以直接咨询客服你的具体县名。

**2. 县城门店能否送到（核心判断）**
**大概率不能直接送达**，原因有二：
- 佳农的配送网络以**区域仓（大城市仓）**为核心，县城一般需通过第三方快递转运，而不是自有冷链。
- 如果你在**国家乡村振兴重点县、偏远省份的县城**，冷链物流成本极高，佳农通常不接单。
- **例外情况**：若你的县城属于**华东、华南经济发达县（如昆山、义乌、晋江等）**，可能有合作经销商或前置仓覆盖，可以尝试在拼多多官方店下单，看是否显示“县内可配送”。

**3. 冷链物流收费标准（无法统一报价，但给你范围）**
佳农水果的冷链费用**不是固定价格**，取决于**重量、距离、是否保温箱**：
- 同城（市区内）：约 **8-15元/单**（满额可能包邮）。
- 跨省/较远地区：按**每公斤3-8元**加收，且**可能强制加收泡沫箱保温费5-10元**。
- 县城订单：**通常不适用标准收费**，因为需二次转运（转邮政/顺丰冷运），费用可能翻倍（变相导致不配送）。
