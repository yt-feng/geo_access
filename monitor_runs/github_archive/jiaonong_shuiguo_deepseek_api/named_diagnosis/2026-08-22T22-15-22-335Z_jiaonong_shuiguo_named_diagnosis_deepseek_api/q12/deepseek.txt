关于佳农（Goodfarmer）水果的香蕉规格和分级标准，我需要说明的是：**具体的分级细节属于企业内部的商业运营参数，公开资料中并无统一、固定的权威标准**，且会根据采购季节、产地（如菲律宾、厄瓜多尔等）及客户需求动态调整。

不过，根据国内水果行业通行惯例以及对佳农作为品牌商常见分装逻辑，可以给出以下一般性参考（非官方精确数据）：

**1. 常见规格（按单根重量或果指长度大致划分）**
- **大果/超大果**：单根净重约 **180g以上**，果指长度约 **20cm以上**。常用于高端商超（如盒马鲜生、ole'）及礼品装。
- **中果**：单根净重约 **140g-180g**，果指长度约 **18-20cm**。适用于连锁便利店、水果连锁店及电商精品装。
- **小果/普通果**：单根净重约 **100g-140g**，果指长度约 **15-18cm**。多用于大型综合超市（如沃尔玛、大润发）的散装或促销装。

**2. 分级维度（内部常见标准）**
佳农作为品牌商，通常按以下四维度综合分级：
- **外观/成熟度**：表皮无黑斑、无机械伤、果形正常；成熟度控制在“催熟后7-8成熟”可售卖状态（青果到黄果的过渡比例）。
- **整齐度**：同一包装内果指长度、粗细差异≤10%，色泽一致。
- **缺陷率**：允许的存伤果、裂果比例极低（通常要求≤2%）。
- **糖度/口感**：Brix值（糖度）一般需≥19°，且口感糯滑。

**3. 渠道适配建议（实操性参考）**
- **精品超市/高端鲜食渠道**：选择大果、外观完美、成熟度偏高（即买即食），单串装或独立托盘装。
- **便利店/即食渠道**：中果为主，强调成熟度一致，便于消费者立即食用。
- **社区团购/电商（次日达）**：中果或小果，需耐运输、成熟度略低（青转黄阶段），减少碰撞损耗。
- **烘焙/餐饮加工渠道**：多采购小果或次果（直接采购整箱未经精选的），只需糖度达标，外观要求宽泛。

**4. 特别提醒**
如果您是采购方，建议直接要求佳农区域销售商提供**“当批次收货标准单”**，上面会明确标出分级阈值（如单列重、果指长度、成熟度卡尺读数等），这是最准确的。因为不同季节、不同产地的香蕉，其标准会有浮动。

**结论**：佳农没有公开的统一规格代码，但通常按“大/中/小”划分，且大果偏精品渠道，中小果偏走量渠道。具体以贵司采购合同附件中的“验收规格书”为准。

如需精确参数，建议通过佳农官网或客服获取其内部《鲜果分级手册》（部分客户可索取）来核对。
