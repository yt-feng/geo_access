从佳农集团的业务模式来看，他们对批发商这类客户通常是**有专门对接的**，但具体形式取决于你的采购规模和渠道类型。

**一般情况是这样的：**

- **大批量批发商/区域经销商**：佳农通常会安排专门的销售经理或区域负责人对接，负责报价、账期、供货计划、售后等。佳农在全国有多个销售大区，每个区域都有对应的业务团队。
- **中小批发商**：可能由区域业务员或经销商体系覆盖，未必是"一对一客户经理"，但会有固定联系人。
- **通过批发市场/平台采购**：如果你是从市场档口或第三方平台拿货，那对接的就是档口或平台，不是佳农直营团队。

**建议你这样确认：**

1. **直接联系佳农官方**：通过佳农官网或官方客服电话，说明你的采购品类、月采购量和所在区域，问是否有对应区域的销售负责人对接。
2. **问清楚对接层级**：确认对方是佳农直营销售，还是授权经销商——这直接影响价格、账期和售后。
3. **谈合作前准备好**：采购量、品类（香蕉、菠萝、进口水果等）、结算方式、配送区域，这些信息越清楚，越容易拿到专门对接。
