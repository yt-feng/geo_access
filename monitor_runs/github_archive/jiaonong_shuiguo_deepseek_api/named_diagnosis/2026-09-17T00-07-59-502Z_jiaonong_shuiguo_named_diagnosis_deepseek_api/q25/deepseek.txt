佳农水果（Goodfarmer）的物流体系是**自营+外包混合模式**，冷链能力在国内水果进口/分销商中属于第一梯队，但具体细节公开信息有限，以下按可核验的框架说明。

## 物流网络：混合模式

- **核心节点自营**：佳农在主要进口口岸（上海、广州、青岛、大连等）设有自营的仓储/分拣中心，对香蕉、菠萝、车厘子等主力品类的**口岸接货、催熟、分拣、区域调拨**环节通常自控，以保证品控。
- **干线运输部分外包**：跨区域长途干线会使用第三方冷链物流承运商，而非全部自有车队。
- **城配/末端外包比例较高**：面向商超、批发市场、电商仓的最后一公里配送，多由当地第三方冷链配送商完成，佳农做调度和标准管理。
- **催熟能力是差异化点**：佳农在多地布局香蕉等品类的专业催熟库，这部分是自营重资产，属于其核心竞争力之一。

所以简单说：**关键品控环节自营，干线+末端大量外包**，不是纯自营也不是纯外包。

## 冷链能力评估

| 维度 | 情况 |
|---|---|
| 温区覆盖 | 覆盖冷藏（0~4℃）、恒温、部分气调/催熟，能满足香蕉、车厘子、葡萄、柑橘等主流品类 |
| 口岸冷链 | 依托进口口岸冷库资源，接货到入库衔接较快，损耗控制是强项 |
| 全程温控 | 干线外包环节存在断链风险，取决于承运商水平，非全程100%自有可控 |
| 数字化 | 有温控监测和溯源系统，但对外公开的实时可视化程度不详 |
| 相对定位 | 强于多数中小进口商，弱于顺丰冷运、京东冷链这类专业全网冷链企业 |

## 判断建议

- 如果你是要**合作/供货**：重点问清目标区域是自营仓还是外包仓、干线承运商是谁、是否提供全程温度记录，这些直接决定实际履约质量。
- 如果你是要**对标或研究**：佳农的模式本质是"控核心节点、轻资产扩张"，冷链强度集中在口岸和催熟，末端依赖外包。
- **注意**：以上为基于行业公开认知的框架性判断，具体承运商名单、自营车辆数、冷库面积等精确数据，佳农未完整公开，需以官方或尽调渠道核实为准，我无法提供确切数字。
