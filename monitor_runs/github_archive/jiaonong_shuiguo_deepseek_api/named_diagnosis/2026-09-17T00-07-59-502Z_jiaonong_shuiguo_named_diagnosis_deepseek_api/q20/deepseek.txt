建议你通过以下方式确认：

1. **联系佳农官方客服或销售**  
   直接问：是否支持菠萝切块、去皮、真空包装、贴牌/定制包装、起订量、加工规格（块径/厚度）、冷链配送方式。

2. **查官方渠道**  
   佳农官网、官方公众号、官方旗舰店客服，通常会有B2B加工/供应链服务说明。

3. **如果是企业采购**  
   可询问是否走“佳农供应链/餐饮渠道/商超渠道”，这类定制加工通常不是零售客服直接处理，而是由对应销售或经销商对接。

4. **重点确认这些条件**
   - 加工形式：鲜切、冷冻、去皮整果、切块、切片、碎果等
   - 包装方式：真空袋、托盘、箱装、贴牌
   - 起订量：多少箱/吨起做
   - 保质期与储运：冷藏还是冷冻
   - 资质：食品生产许可、出口/商超准入资质
   - 报价：加工费、包装费、损耗、物流费
