茶叶店常用菠萝原料，佳农是果蔬供应链里比较知名的品牌，能给普通商家提供相对标准化的规格。实际采购时，你直接问经销或业务员这几项就能判断是否适合：

- **品种**：常见是金钻凤梨/台湾凤梨类，也有普通菠萝。凤梨一般不需要挖眼、盐水泡，出肉率更高，适合茶饮。
- **规格**：按单个重量分，比如 1.2–1.5 斤、1.5–1.8 斤、1.8–2 斤以上；也有按箱标，如 8–10 个/箱、10–12 个/箱。
- **成熟度**：问是几成熟发货，茶饮店通常要 7–8 成熟，到店后 2–3 天用完，太生太熟都不稳。
- **形态**：鲜果、去皮菠萝块、冷冻菠萝丁/果泥。茶饮店大量用，冷冻果泥或果丁往往比鲜果更稳定，出品一致。
- **包装与冷链**：冷冻品看每袋克重、每箱袋数；鲜果看是否冷链、到货温度。
- **供货稳定性**：问产季、替代产地、最小起订量、到货周期、坏果赔付标准。

对茶饮店来说，你不需要问“高大上”的等级，只要锁定：**品种、单果重或袋装克重、成熟度/冷冻状态、包装规格、到货周期、赔付规则**。如果佳农当地经销能提供这些明确参数，就属于商家能听懂的稳定规格；如果只报“大果/中果”但不给具体克重和成熟度，就要谨慎。
