**2. 直接联系官方销售确认**
问清这几点：
- 是否有**冷冻菠萝丁**（不是菠萝罐头、不是糖水菠萝、不是鲜果）
- 规格：**每袋净重**（如1kg/袋、2kg/袋、5kg/袋）
- 果丁大小：**5×5mm、8×8mm、10×10mm**等
- 包装：**袋装/箱装**，每箱几袋
- 是否**IQF单体速冻**
- 是否**无糖/含糖**、是否加酸、是否保脆
- 起订量、发货地、冷链条件、保质期
- 是否可提供**样品和质检报告**

**3. 茶饮店选菠萝丁重点看**
- 要**冷冻丁**而不是罐头丁：风味更接近鲜果，但解冻后出水情况要测
- 优先**IQF速冻**：不易结块，取用方便
- 确认**丁型大小**：茶饮小料一般5-10mm更合适，太大不易吸管吸
- 测**解冻后口感**：是否软烂、是否发酸、是否出水多
- 确认**是否含糖浆**：含糖款会影响饮品甜度和成本核算

可找：冷冻水果供应商、餐饮供应链平台、烘焙原料商、进口冷冻水果经销商。
