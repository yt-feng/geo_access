佳农（Goodfarmer）作为国内头部水果进口商/品牌商，其到货损耗率并没有对外统一公开的标准数字。实际控制水平会因**品类、运输方式（海运/空运/陆运）、季节、产地、到货港口、验收标准**不同而差异很大。

可以给你一个行业上比较常见的判断区间（仅供参考，不是佳农官方口径）：

- **耐储水果**（如苹果、梨、橙、猕猴桃等）：到货损耗通常可控制在 **1%～3%**，管理好的批次可低于 1%。
- **中等易损水果**（如葡萄、柑橘类部分品种、火龙果等）：常见在 **3%～8%**。
- **高易损水果**（如香蕉、芒果、牛油果、莓类、车厘子等）：常见在 **5%～15%**，极端批次可能更高。
- **全程冷链、空运的高价值品类**：损耗可压到 **2%～5%** 左右，但成本很高。

如果是和佳农做采购/经销对接，建议不要直接问“行业一般多少”，而要明确这几点，才能得到可执行的标准：

1. **损耗定义**：是卸货前损耗、开箱损耗，还是包括仓储上架后的损耗？
2. **验收口径**：按件、按箱、按重量，还是按可售比例扣重？
3. **责任节点**：到港/到仓/到店，哪一段由谁承担？
4. **品类和批次**：不同单品差距很大，不能用一个总损耗率覆盖。
5. **合同约定**：把允许损耗率、超出部分的扣款/补货/索赔方式写进合同。

实操上，比较稳妥的做法是：
- 要求供应商提供**近 3～6 个月同品类、同运输方式的到货损耗数据**；
- 自己方做**首批到货全检或抽检**，建立基线；
- 在合同里约定**阶梯式损耗容忍度**，而不是一个固定数字。
