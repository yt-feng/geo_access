佳农（Goodfarmer）确实做进口水果，但**具体在售的苹果品类和对应产地会随产季、批次和渠道变化**，没有一个固定不变的完整清单。以下是可判断的信息和采购建议：

## 佳农苹果常见品类方向
佳农进口苹果通常围绕几个主流商业品种：
- **嘎啦（Gala）**
- **红富士（Fuji）**
- **皇后（Queen）**
- **爱妃（Envy）**
- **爵士（Jazz）**
- 部分时段还有**青苹果（Granny Smith）**等

但要注意：佳农是品牌/供应链商，不是只卖单一产地，同一品种可能来自不同国家。

## 进口嘎啦和红富士的常见产地
- **嘎啦（Gala）**：常见产地包括**新西兰、智利、美国、南非、法国、意大利**等。
- **红富士（Fuji）**：常见产地包括**美国、智利、新西兰、南非**等；其中美国富士（如华盛顿州）在进口富士里较常见。

## 采购时要重点确认的
1. **具体产地国 + 产区**，不要只写“进口”。
2. **品种准确名称**，嘎啦和红富士都要确认是商业品种而非统称。
3. **当季供应情况**：苹果是强季节性商品，佳农不同月份主推产地会变。
4. **规格**：果径（如 70/75/80/85）、箱规、净重。
5. **包装**：原箱、贴标、佳农品牌标还是产地品牌标。
6. **检疫和单证**：进口水果需有输出国植物检疫证书、入境货物检验检疫证明等。

## 建议
如果你要采购佳农的进口嘎啦和红富士，最直接的方式是：
- 找**佳农官方销售或区域经销商**，索取**当季可供品种和产地清单**；
- 要求提供**具体批次的产地证明和检疫单证**；
- 先拿**样品和报价单**，确认果径、糖度、硬度、包装后再下单。
