香蕉属于价格波动较大的生鲜品类，佳农作为水果品牌/供应商，通常**不会对普通经销客户提供“锁价3个月”这种长期固定价格机制**。原因很直接：香蕉从产地采购、催熟、冷链到终端销售，成本受产地行情、汇率、海运、天气、供需影响很大，长期锁价会让供应商承担巨大风险。

不过，实际业务中可能存在一些**有限度的价格保护或变相锁价**，常见形式包括：

1. **短期锁价**  
   比如按周、按批次、按单船/单柜锁价，常见是7天、15天，少数大客户能谈到30天左右。3个月非常少见。

2. **大客户协议价**  
   如果采购量很大、合作稳定，佳农可能给一个“基准价+调整机制”，而不是完全固定价。比如约定随行就市，但给予一定折扣或优先供货。

3. **价格保护条款**  
   有些合同会写：若市场价下跌超过一定幅度，给予部分返利或补差；若上涨超过一定幅度，双方再协商。这不是硬锁价，而是风险共担。

4. **促销/活动锁价**  
   针对特定档期、特定渠道，可能短期锁定促销供货价，但通常有量、有期限、有附加条件。

5. **区域代理或包销**  
   极少数深度合作方可能谈到较长期稳定价格，但一般也会附带销量承诺、保证金、结算方式等条件，且仍可能保留调价权。

**判断建议：**
- 如果你是采购方，想锁3个月，直接找佳农区域销售或大客户经理谈，但要做好被拒绝或附加条件的准备。
- 如果对方口头承诺“锁价3个月”，一定要写进合同，明确：锁价品类、规格、数量、交货期、调价触发条件、违约处理。
- 更现实的做法是：**短期锁价+价格调整机制+返利补差**，而不是追求长期硬锁价。
