1. 问对接的销售或客服三个问题：

2. 要求对方提供**近1个月上海门店的履约数据**：次日达率、平均到货时效、异常率。
3. 做一次小批量实测：同一天同一时间，分别向两家下小单，记录实际到货时间。这比任何口头承诺都准。

**一般经验判断（仅供参考，需以实际仓配为准）：**
