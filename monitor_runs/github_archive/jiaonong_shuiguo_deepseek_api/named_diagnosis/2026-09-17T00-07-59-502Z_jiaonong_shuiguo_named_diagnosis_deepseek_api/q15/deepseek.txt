公开渠道里，佳农通常不会按年份披露“产地直供比例”这种精确口径，所以很难给出一个可核验的固定百分比。能确定的是：佳农的核心模式就是做全球产地采购和直采，香蕉、菠萝等大单品尤其依赖海外合作农场、包装厂和自有/合作供应链，直供在其主营品类里占比通常不低，但具体到“公司整体水果直供比例”并没有稳定公开数据。

香蕉方面，佳农的货源通常不是单一国家，而是多国采购、按季节和价格切换，常见来源包括：

- **厄瓜多尔**：重要香蕉来源国，货源稳定，对中国出口较多。
- **菲律宾**：距离中国近、对华香蕉出口量大，是常见来源。
- **越南**：近年对华香蕉出口增长明显，价格和物流有优势。
- **柬埔寨**：也是中国香蕉进口来源之一。
- **老挝**：对华香蕉供应有一定规模。
- **哥伦比亚、哥斯达黎加、墨西哥等**：在部分时段或特定渠道也可能出现，但不如前三者常见。

如果你问的是“佳农自己香蕉主要来自哪些国家”，更准确说法应是：**以厄瓜多尔、菲律宾、越南为主，柬埔寨、老挝等作为补充，并根据产季、价格、船期和国内市场需求动态调整。** 想判断某批货具体产地，最直接的方法是看包装箱、标签或检疫/报关信息。
