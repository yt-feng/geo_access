佳农水果的售后整体属于“看渠道”的类型，不同购买渠道处理方式差别较大：
- 如果是京东自营、天猫超市、盒马、山姆等大型平台购买，通常可以直接走平台售后，坏果一般能按比例退款或补发。
- 如果是抖音、拼多多、社区团购或第三方店铺购买，售后主要看商家，体验参差不齐。

到货有坏果时，可以按这个流程处理：

1. **先别急着扔坏果**
   把坏果和好果放在一起，或者单独保留坏果，拍清楚照片/视频。

2. **保留证据**
   建议拍：
   - 整箱水果的全景
   - 坏果特写
   - 快递面单或订单信息
   - 如果有称重条件，可以拍一下坏果数量/重量

3. **尽快联系售后**
   在签收后第一时间联系购买渠道客服。大多数平台要求24小时内或48小时内反馈，越早越好。

4. **明确诉求**
   常见处理方式有：
   - 按坏果数量比例退款
   - 补发坏果
   - 整单退款或部分退款
   - 补偿优惠券

   你可以直接说：“到货发现X个坏果，已拍照，申请按比例退款/补发。”

5. **如果商家不处理**
   - 平台内申请售后或投诉
   - 找平台官方客服介入
   - 保留聊天记录和照片，必要时申请平台仲裁

6. **注意几个坑**
   - 有些商家要求“坏果和快递单同框”，提前拍好更省事。
   - 生鲜类通常不支持无理由退货，但坏果属于质量问题，可以要求赔。
   - 如果坏果比例很高，比如超过三分之一，可以直接要求整单退或补发。
   - 不要只跟快递员说，快递一般不负责水果品质，还是找商家或平台。

简单说：**佳农水果本身售后没有统一标准，关键看你从哪个渠道买。到货有坏果，第一时间拍照留证、联系客服、按比例索赔，通常都能处理。**
