佳农（上海佳农食品集团）主营业务是香蕉、菠萝等水果的种植、进口和批发分销，通常以整果形式供货，面向商超、批发市场和餐饮渠道。**佳农一般不自带"去皮切块"这类二次加工服务**，尤其是针对茶饮店这种小批量、定制化切块的需求，基本不会做。

原因很简单：鲜切水果属于即食加工品，需要专门的清洗、消毒、切配车间和冷链配送体系，佳农的供应链是围绕整果周转设计的，做鲜切对他们来说是另一套业务。

**你可以考虑的替代方案：**

1. **本地鲜切水果供应商**——很多城市有专门做餐饮配送的鲜切工厂，可以按你的规格（块大小、克重）供货，冷链送达。
2. **自己门店加工**——如果用量不大，买整果自己在店里去皮切块，成本反而更低，只是要安排人手。菠萝去皮其实不难，买个菠萝刀或让供应商送"已削皮整果"也行。
3. **找佳农的经销商谈**——部分区域经销商可能提供简单分切，但要看具体合作方，不是佳农官方标准服务，需要直接问。
4. **用冷冻菠萝块**——如果对口感要求没那么高，冷冻菠萝块（IQF）有现成的标准品，开袋即用，省人工，很多茶饮店在用。

**建议先确认一件事**：你的用量是每天几公斤还是几十公斤？量小的话自己切更划算，量大再去找专业鲜切供应商谈。另外菠萝切好后容易氧化、出水，鲜切品保质期短，冷链和当天用完是关键，这点要在选供应商时问清楚。
