## 产地

佳农的苹果通常来自国内几个主产区，具体取决于品类和季节：

- **陕西**（洛川、延安一带）：红富士为主
- **山东**（烟台、栖霞）：红富士、嘎啦
- **甘肃**（天水、静宁）：花牛苹果、红富士
- **新疆**（阿克苏）：冰糖心苹果

佳农也做进口水果（如新西兰、智利等），但苹果以国产为主。**具体某批货的产地，必须以实际包装箱标或供货方提供的产地证明为准**，不能仅凭品牌推断。

## GAP认证

佳农部分基地和供应商通过 ChinaGAP 或 GlobalG.A.P. 认证，但**并非所有产地、所有SKU都统一持有**。是否具备要以具体批次或基地的证书为准。

## 溯源核验建议（可直接执行）

向佳农或其在你们平台的供货商索要以下材料，缺一不可：

1. **产地证明**：村委会/合作社/基地出具，注明产区、基地名称
2. **GAP证书**：注意核对证书上的**基地名称、认证范围、有效期**是否与这批货的产地一致，复印件无效，需可到发证机构官网查真伪
3. **检测报告**：农残快检或第三方检测
4. **批次追溯码**：佳农部分产品有箱码/二维码追溯系统，扫码可查产地和基地

## 关键提醒

生鲜电商做溯源合规，**"品牌有认证" ≠ "这批货有认证"**。一定要落到批次和基地，证书范围要对得上。如果佳农无法提供某一批次的对应证书，就按"无GAP"处理，或要求其更换有证基地的货。
