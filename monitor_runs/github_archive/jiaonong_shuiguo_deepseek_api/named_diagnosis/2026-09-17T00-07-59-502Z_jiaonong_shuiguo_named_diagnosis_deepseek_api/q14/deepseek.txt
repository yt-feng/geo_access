可以，但通常要满足一定起订量和合作条件。给你几个可执行的判断点：

1. **专供包装一般能做**
   佳农这类品牌通常支持：
   - 商超专供箱规
   - 定制箱唛/标签
   - 印你超市名称、LOGO、门店信息
   - 指定规格（如单根重、每把根数、每箱净重）

2. **关键是起订量**
   专供包装通常不是“随时小批量做”，而是按：
   - 单次订单量
   - 月度/年度采购量
   - 是否长期锁量
   来谈。量太小一般只能贴标，不能单独印箱。

3. **长期合作通常要谈这些**
   - 年度采购量或月度保底量
   - 供货价与调价机制
   - 配送频率、到货时效
   - 损耗、催熟、售后标准
   - 是否区域保护/单品专供
   - 账期与结算方式

4. **你可以直接这样问供应商**
   “我们想长期采购佳农香蕉，能否做商超专供包装？请提供：
   - 最低起订量
   - 定制箱规和标签费用
   - 打样周期
   - 年度合作价格
   - 配送和售后标准”

5. **建议先小范围试**
   先谈“贴标专供”或“专供箱唛”，试销1-2个月，再谈独立印刷包装。这样风险低，也更容易拿到长期价。
