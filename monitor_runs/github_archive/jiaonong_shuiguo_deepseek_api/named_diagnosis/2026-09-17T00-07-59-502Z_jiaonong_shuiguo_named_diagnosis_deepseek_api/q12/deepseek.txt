佳农水果的香蕉规格和分级标准属于其具体的商品管理信息，我无法核验其当前在售的准确规格表（不同产地、季节、客户定制都会调整），所以不能给你一份“官方规格清单”。下面给你一个**可执行、可判断**的通用框架，你可以据此对照佳农的报价单/装箱单/合同去确认。

## 一、香蕉常见的规格维度

市面上的香蕉规格，通常不是只看“一种”，而是几个维度组合：

1. **按根数/箱（把数）**
   - 常见：4-5把/箱、5-6把/箱、6-8把/箱等
   - 佳农这类品牌商超渠道常见的是按“把”或“根”计，箱重多为 **13.6kg、18kg、20kg** 左右（具体以实际包装为准）

2. **按单根重量/等级（条重）**
   - 大果：单根约 180g 以上
   - 中果：单根约 130-180g
   - 小果：单根约 100-130g
   - 这些数字是行业常见区间，不是佳农官方标准，需以其验收单为准

3. **按长度/粗度**
   - 长度：如 18cm+、20cm+、22cm+ 等
   - 粗度：按周径或直径分档

4. **按成熟度/催熟阶段**
   - 青蕉（未催熟，适合长途、批发、再催熟）
   - 微黄/转黄（适合短途配送、门店）
   - 黄熟（适合即食、零售）

5. **按外观等级**
   - 精品/一级：无疤、无黑点、条型直、色泽均匀
   - 二级：轻微花皮、轻微弯曲，不影响食用
   - 加工级：外观差但可用于烘焙、果切、果汁

## 二、按渠道的分级建议（你可套用的判断逻辑）

| 渠道 | 更看重的规格 | 建议分级方向 |
|---|---|---|
| 高端商超/精品店 | 条型、色泽、长度、单根重 | 一级/精品，单根重偏大，长度整齐，成熟度可控 |
| 连锁超市/社区店 | 性价比、稳定供货 | 一级或二级，按箱重和把数稳定，允许轻微外观瑕疵 |
| 水果店/批发市场 | 价格、周转 | 二级为主，按箱/按件走，成熟度偏青便于存放 |
| 电商/社区团购 | 耐运输、标准化 | 按根或按把标准化，成熟度偏青或微黄，减少压伤 |
| 餐饮/果切/烘焙 | 出肉率、成本 | 加工级或二级，不追求外观，追求单根重和成熟度 |
| 出口/长途 | 青蕉、耐储 | 青蕉，按长度/粗度/条重分级，严格控温 |

## 三、怎么拿到佳农的准确规格

要确认佳农香蕉的**真实规格和分级**，最直接的办法是：

1. **要一份最新产品规格书/报价单**  
   看：箱重、把数、单根重、长度、成熟度、等级、产地、包装方式。

2. **看装箱单和验收标准**  
   上面通常会写：等级、条重范围、允许瑕疵比例、成熟度。

3. **问清楚是“品牌标准”还是“渠道定制”**  
   佳农给不同渠道（如山姆、盒马、永辉、批发市场）的规格可能不同，甚至同一渠道不同季节也会调整。

4. **用“三看”快速判断**
   - 看箱重和把数是否稳定
   - 看单根重和长度是否在合同区间
   - 看成熟度和外观瑕疵是否匹配你所在渠道

## 四、一句话结论

佳农香蕉没有固定不变的“几种规格”，而是按**箱重/把数、单根重、长度、成熟度、外观等级**组合分级；不同渠道的核心区别是：**高端渠道看外观和整齐度，批发看价格和耐储，电商看标准化和耐运输，加工渠道看出肉率和成本**。要准确数据，直接向佳农业务或供应商索取最新规格书和验收标准。
