佳农（Goodfarmer）是国内较大的水果供应链企业，菠萝（尤其是菲律宾、泰国等进口菠萝）是其重点品类之一。就你关心的两点，可以这样判断：

**1. 产地溯源**
佳农通常具备产地溯源能力，尤其是进口菠萝：
- 包装箱/果贴一般会标注原产国、果园/包装厂注册号（如菲律宾菠萝常见的 PS 或 PH 编号）
- 可提供入境货物检验检疫证明，上面有原产国、批次等信息
- 部分客户可拿到装箱单、提单等贸易单据，实现批次级溯源

**2. 品控报告**
佳农作为规模化供应商，一般可提供：
- 第三方检测报告（农残、重金属等，按国标或客户要求）
- 自有品控的到货验收/抽检记录
- 特定客户可协商定制品控标准并出具对应报告

**但要注意：**
- 这些通常**不是公开标配**，而是按采购量、合作方式、合同约定来提供。小批量零采未必给全。
- 报告一般是**批次对应**的，注意核对报告上的批次号/生产日期是否与你收到的货一致，避免“一报告多用”。
- 溯源和检测报告的**具体范围**（农残项目、检测机构、是否每批都做）建议在合同或订单里写明。

**建议你这样推进：**
1. 直接联系佳农官方销售或当地经销商，明确问：“这批货能否提供入境检验检疫证明、产地注册号、以及对应批次的第三方检测报告？”
2. 要求把“随货提供XX报告、批次需对应”写进合同/订单条款。
3. 首次合作先小批量试单，验货时核对果贴、箱标、报告批次是否一致。
