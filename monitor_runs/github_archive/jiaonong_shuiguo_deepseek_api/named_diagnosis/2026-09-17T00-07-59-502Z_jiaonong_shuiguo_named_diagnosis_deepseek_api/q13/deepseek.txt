这两家都是国内头部水果供应链企业，但“更靠谱”取决于你要的是哪种服务。直接给结论：

**总体：如果看全链条供应链能力、稳定性、规模和标准化，鑫荣懋通常更强；如果看特定品类（尤其香蕉、菠萝等佳农优势品）和产地直采灵活性，佳农在部分环节更有优势。**

具体对比：

**1. 规模与覆盖**
- 鑫荣懋：长期是国内水果供应链龙头之一，服务商超、电商、批发多渠道，仓储物流网络和全国分销体系较成熟，B端服务经验更完整。
- 佳农：也是头部，尤其在香蕉、菠萝等进口/国产优势单品上很强，自有品牌和产地资源突出，但整体供应链服务的“平台化”程度通常不如鑫荣懋全面。

**2. 品控与标准化**
- 鑫荣懋：更偏体系化、标准化运作，适合对交付稳定、批次一致、对账规范要求高的大型渠道。
- 佳农：在核心单品上品控和成本控制很强，但如果是多品类组合、全国多仓协同，鑫荣懋的稳定性通常更占优。

**3. 仓储物流与履约**
- 鑫荣懋：全国多仓布局、冷链和配送体系相对更成熟，适合需要“全国铺货+稳定履约”的客户。
- 佳农：在优势品类和重点区域履约能力强，但跨品类、跨区域的全国一体化服务，通常不如鑫荣懋均衡。

**4. 服务对象**
- 大型商超、电商平台、连锁餐饮、需要多品类一站式供应链：优先考虑鑫荣懋。
- 以香蕉、菠萝等单品为主，或需要强产地直采、成本优势：佳农可能更合适。

**5. 风险点**
- 鑫荣懋：体系大，流程相对重，小客户或特殊定制需求响应可能没那么灵活。
- 佳农：优势品类强，但如果你要的是全品类、全国性综合供应链服务，覆盖和协同可能弱一些。

**建议**
如果你是做商超、电商、连锁门店，要的是**多品类、全国履约、稳定交付**，选鑫荣懋更稳。
如果你聚焦**香蕉、菠萝等佳农强势单品**，或者更看重产地直采和成本，佳农值得优先谈。

最终还是要看你的具体需求：品类结构、覆盖区域、日均单量、是否要冷链、账期和结算方式。可以拿同一套需求分别让两家报价和出履约方案，重点比：**到货准时率、损耗率、缺货率、异常处理时效、账期**，这五项比品牌名气更能判断谁靠谱。
