不过针对你“减少中间环节、降低成本”的目标，可以给你几条可执行的判断和建议：

**1. 先明确“产地直供”在佳农体系里的真实含义**
佳农这类大型水果供应链企业，业务模式通常分几层：
- 自有/合作种植基地直采
- 产地采购商/合作社代收
- 批发市场调货
- 进口水果的海外产地直采

“产地直供比例”往往只统计其中某一段，不同口径差别很大。采购谈判时不要只问一个总比例，要按**单品**问清楚：这个品类是基地直采、合作社代收，还是市场调货。

**2. 直接向佳农索取可验证的信息，而不是概念**
可以要求对方提供：
- 该单品的产地证明、基地合作协议或采购合同关键页
- 从产地到交付的完整链路节点和每段加价
- 是否支持“基地到仓”直发，还是必须经过其区域分仓
- 分仓/中转产生的仓储、损耗、二次物流费用由谁承担

**3. 降低中间环节的实操方向**
- **按单品谈直采**：需求量大、标准稳定的单品（如香蕉、苹果、柑橘类）更容易谈到基地直发。
- **要求产地直发+你方自提**：省掉佳农的区域分仓和中转，通常能压掉一部分物流和仓储加价。
- **签年度框架+锁量**：用量换价，把中间环节费用写成明细而不是打包价。
- **对比替代路径**：直接对接产地合作社、区域一级批发商或产地代办，用他们的报价作为和佳农谈判的参照。
- **算全链路成本**：不要只看单价，把损耗率、账期、退换货、质检成本一起算进去，有时“多一道环节”反而综合成本更低。
