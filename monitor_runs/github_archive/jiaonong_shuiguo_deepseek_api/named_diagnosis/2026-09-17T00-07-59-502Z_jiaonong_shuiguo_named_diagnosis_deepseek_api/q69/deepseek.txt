我无法核验佳农水果是否针对餐饮渠道提供菠萝切片/切块的定制规格，所以不能直接给出肯定或否定的确认。

更稳妥的判断方式是：

1. **直接查官方渠道**  
   看佳农官网、官方公众号/小程序、或其在电商/批发平台上的“餐饮供应/餐饮渠道”页面，重点找：  
   - 鲜切菠萝  
   - 菠萝切片/切块  
   - 餐饮专供规格  
   - 冷冻菠萝/速冻菠萝  
   - 按 kg/袋、片厚、块径、糖度等标注的规格

2. **直接问销售或客服**  
   问清楚这几个关键点：  
   - 是否有餐饮渠道专供 SKU  
   - 是鲜切还是冷冻  
   - 切片厚度/切块尺寸  
   - 包装规格（如 1kg/袋、5kg/箱）  
   - 是否支持定制贴牌或按需分切  
   - 起订量、配送温层、保质期

3. **看是不是“定制”而非“标准品”**  
   很多水果供应链企业会给餐饮客户做定制分切，但通常不是公开零售 SKU，而是 B2B 订单制。也就是说，即使官网看不到，也可能通过餐饮渠道业务员询价定制。

4. **替代判断**  
   如果佳农没有公开的餐饮定制菠萝规格，餐饮端常见替代方案是：  
   - 找专业鲜切水果供应商  
   - 找冷冻菠萝/速冻菠萝丁供应商  
   - 找中央厨房或净菜加工厂代切  
   - 直接采购整果后门店/中央厨房自行分切

**结论：** 目前不能确认佳农一定有餐饮渠道的菠萝切片或切块定制规格；最可靠的方式是直接联系佳农官方餐饮渠道销售，询问是否有“餐饮专供鲜切/冷冻菠萝片、菠萝块”及定制分切服务。
