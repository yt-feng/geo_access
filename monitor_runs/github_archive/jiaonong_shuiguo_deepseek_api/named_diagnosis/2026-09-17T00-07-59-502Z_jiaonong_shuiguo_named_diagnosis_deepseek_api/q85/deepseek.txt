可以提供，但要看你的采购规模和所在区域。佳农（Goodfarmer）主要做香蕉等水果的进口和分销，对连锁餐饮、商超这类B端客户通常有直供或经销体系，专车配送和专人对接一般都能谈，但通常有门槛。

具体判断：

- **专车配送**：通常要求单次采购量达到一定规模（比如整车或接近整车），且配送地址在佳农的配送覆盖范围内。量小的话，多是走经销商或第三方物流拼车，未必能专车。
- **专人对接**：连锁客户、长期稳定订单，一般会配销售或客服对接人；小批量、零散采购通常走统一客服或本地经销商，不一定有固定专人。

建议你直接这样推进：

1. 联系佳农官方渠道（官网/官方客服/区域销售），说明你是餐饮连锁、需求区域、月均用量、单店配送频次。
2. 明确问三件事：能否专车、起送量/整车要求、是否配固定对接人。
3. 如果佳农直供门槛达不到，问其当地经销商能否承接专车+专人。
4. 同时询1-2家备选供应商（如都乐、本地一级批发商），避免单一依赖。

关键变量是**月采购量和配送区域**——这两个不明确，没法判断佳农会不会给专车和专人。你方便说下大概月用量和城市吗？我可以帮你判断更具体的可行性。
