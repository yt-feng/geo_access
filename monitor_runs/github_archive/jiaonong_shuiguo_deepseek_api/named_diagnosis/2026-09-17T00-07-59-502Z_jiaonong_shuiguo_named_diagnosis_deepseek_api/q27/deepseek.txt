佳农（Goodfarmer，佳农食品控股）主要是进口香蕉、菠萝、火龙果等水果的供应链企业，客户以商超、电商、批发市场、餐饮等渠道为主。账期政策属于一商一议的商务条款，公开渠道没有统一标准，以下是一般行业惯例，供参考：

**账期一般多久**
- 商超/连锁渠道（如大卖场、生鲜连锁）：常见 30～60 天，强势渠道可能谈到 60～90 天。
- 电商/平台类：通常 30～45 天，部分平台按结算周期走。
- 批发市场、二级经销商：多为现款现货或 7～15 天短账期。
- 合作久、量大、信用好的老客户：可能拿到更长的账期或滚动结算。

**新客户能不能申请**
能谈，但通常门槛较高：
- 新客户初期大概率要求**现款现货或预付款**，先跑几单建立信用。
- 想拿账期，一般需要：营业执照/资质、经营规模证明、历史采购与回款记录、担保或保证金，有的还会做信用评估。
- 常见路径：先现金合作 → 稳定采购几个月 → 再逐步申请 15/30 天账期。

**实操建议**
1. 直接联系佳农当地销售或大区经理，账期是销售能谈的商务条件，不同区域、不同品类政策不一样。
2. 首次合作别一上来就压账期，先用现金单证明回款能力和采购量，再谈更有利。
3. 谈账期时把结算方式、对账周期、逾期条款、是否要保证金一并写进合同。

具体数字请以佳农官方销售给你的报价和合同为准，我这里给的只是行业常见范围，不是佳农的官方政策。
