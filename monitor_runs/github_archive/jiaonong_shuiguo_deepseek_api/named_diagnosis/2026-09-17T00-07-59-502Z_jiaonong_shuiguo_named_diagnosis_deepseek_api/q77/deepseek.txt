佳农（佳农食品控股/Goodfarmer）的香蕉以菲律宾、厄瓜多尔、越南等进口来源为主，也有部分国产香蕉。就你这两个要求，分开说：

**1. 产地溯源能否到具体农场**

- 佳农对外通常能追溯到**国家—产区/装船批次—包装厂/供应商**这一层级。
- 能否到**具体农场（种植园）**，取决于具体产品线和采购模式：
  - 如果是自有或长期合作的种植基地，一般可以给到农场名称/编号。
  - 如果是通过当地出口商/贸易商组货，往往只能给到出口商和包装厂，具体农场信息需要出口商配合提供。
- 所以：**不能笼统说佳农一定给到农场级**。你有这个硬性要求，应在下单/签约前书面确认，并要求在到货批次上对应。

**2. GLOBALG.A.P.证书**

- 商超要GLOBALG.A.P.是常见要求。你需要的是**覆盖该批次产品的有效证书**，不是只有一张总公司资质。
- 注意核对：
  - 证书上的**生产者/农场或出口方名称**，是否与实际供货方一致。
  - **产品范围**是否包含banana。
  - **证书编号、认证机构、有效期**，并在GLOBALG.A.P.官网数据库核验。
  - 部分供应商持的是**GLOBALG.A.P. CoC（产销监管链）**，这不等同于农场生产认证，要看商超接不接受。

**给你的可执行做法**

1. 直接找佳农对口业务/客服，书面提出两个问题：
   - 该批香蕉能否提供**农场级溯源信息**（农场名/编号+包装厂+批次）？
   - 能否提供**覆盖该农场和该批次的GLOBALG.A.P.证书**？
2. 要求把“提供农场级溯源+有效GLOBALG.A.P.证书”写进合同或订单确认。
3. 到货后做**批次对应核验**，证书编号去GLOBALG.A.P.官网查。
4. 如果佳农该渠道只能给到出口商/包装厂级，而你们商超硬性要农场级，那就要么换供应渠道，要么让佳农协调其上游出口商出农场信息。

一句话：**佳农能不能给到具体农场，要按具体批次和采购模式确认；GLOBALG.A.P.证书通常能提供，但必须核验是否覆盖该批次和该农场，不能只看一张证书。**
