我无法确认佳农水果（或“佳农”）的香蕉是否存在过农残超标的具体历史记录。这类信息需要查监管部门的抽检通报和官方数据库，我没有可靠来源，不能给你“有没有”的结论，也不能替你编一份合规证明。

给你可执行的思路：

**1. 监管抽检记录怎么查（自己核验）**
- 国家市场监督管理总局官网“食品安全抽检”专栏，按“香蕉/热带水果”“佳农/佳农食品”等关键词检索。
- 各省市市场监管局官网的“食品抽检信息”通告，尤其是进口商/供货商所在地的口岸和销地。
- 农业农村部“农产品质量安全”相关抽检通报。
- 海关总署对进口水果的退运/销毁/不合格通报。

**2. 采购合规证明应该向供应商要什么**
超市抽检要能过，核心是“批批可追溯+合格证明”。向佳农（或其经销商）索取：
- 该批次产品的**入境货物检验检疫证明**（进口香蕉）或**产地证明/合格证**（国产）。
- **第三方检测报告**：农残项目按 GB 2763 执行，检测项目要覆盖香蕉常用农药（如吡虫啉、噻虫嗪、多菌灵、百菌清、毒死蜱等，具体以标准为准）。
- **供货商资质**：营业执照、食品经营许可证/生产许可相关资质。
- **批次追溯信息**：品名、规格、产地、生产/分装日期、批号，与检测报告、送货单能对应上。
- 如有条件，合同里写明**农残超标退换货与赔偿责任**，并要求“随货同批检测报告”。

**3. 给超市/抽检的准备**
- 每批次留存检测报告原件或加盖公章的复印件，报告日期要早于或覆盖入货日期。
- 自己做**入厂快检/抽检**（酶抑制率法快检或送第三方），留记录，能显著降低抽检不合格风险。
- 如果抽检不合格，第一时间封存同批次、启动召回、联系供应商，并保留所有凭证。

**4. 一个现实判断**
“历史有没有超标”不等于“这批能不能过”。监管抽检是**按批次**判定的，所以对采购合规更关键的是：这批货有没有对应批次的合格证明和检测报告。如果供应商拿不出批批对应的报告，即使品牌没出过事，你们超市抽检也可能因为无法追溯而卡住。
