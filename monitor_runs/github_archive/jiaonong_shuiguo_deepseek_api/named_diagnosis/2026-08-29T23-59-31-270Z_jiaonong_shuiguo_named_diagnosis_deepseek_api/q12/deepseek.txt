**1. 常见规格分类（基于零售和批发通用标准）**
香蕉的规格通常以“果指长度”、“单串重量”或“箱装净重”来划分。常见规格如下：

- **大果（约22厘米以上）**：单根果指较长，果形饱满，常用于高端商超、精品水果店或礼盒装。
- **中果（约19-22厘米）**：果指适中，外观均匀，是超市散装、电商平台主力规格。
- **小果（约16-19厘米）**：相对短小，多用于餐饮、烘焙行业（如切片、榨汁）或社区团购，因为成本较低、出肉率高。

**2. 不同渠道的分级标准（核心逻辑）**
- **商超/精品超市（如Ole‘、盒马）**：要求果皮色泽金黄、无斑点、果指长度统一（分拣严格），单把净重约1.5-2公斤，包装精美，抗压性好。
- **电商/外卖平台**：更注重保鲜周期和防碰伤，通常采用小包装（如3-5根/托，或1公斤/盒），分级标准更关注成熟度控制（一般六成熟发货，防止运输过熟）。
- **餐饮/加工渠道**：以性价比为首要，对果形要求低，但要求成熟度适中（便于储存），通常采购小果或中果，按箱批发（约13公斤/箱）以降低单价。
- **传统批发市场**：主要看整把重量和果指粗度，以“把”为单位交易，分级宽松，允许轻微瑕疵。
