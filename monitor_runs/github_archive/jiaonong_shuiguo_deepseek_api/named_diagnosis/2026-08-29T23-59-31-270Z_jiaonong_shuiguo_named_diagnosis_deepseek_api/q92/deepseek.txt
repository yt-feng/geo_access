关于佳农水果在商超促销的堆头陈列和试吃支持，以及费用分担问题，建议您按以下步骤操作，以获得最准确、可执行的条件：

**1. 直接联系佳农区域销售/经销商（最优先）**
佳农（一般指佳农食品，主营香蕉、菠萝、牛油果等进口水果）的促销政策通常由**区域销售经理**或**当地经销商**执行。您需要做的是：

-   **找到对接人**：佳农官网或商超采购系统里找到您所在区域的业务负责人电话或微信。
-   **明确问询**：直接询问“针对本商超的季度/节日促销，贵司能否提供**独立堆头**（端架/地堆）的免费或优惠支持？以及**试吃台**（含促销员、试吃装）的资源配置。”

**2. 费用分担的常见行业惯例（供您谈判参考）**
在商超渠道，水果供应商参与促销的费用分担通常分为以下几种模式：

-   **最理想（供应商全包）**：佳农如果正处新品推广期（如新季菠萝、佳沛奇异果的佳农代理品项），或该门店销量特别大，他们可能**全权承担**堆头费、促销员工资及试吃果损耗。
-   **平均分摊（常见）**：商超承担**场地费**（堆头陈列费），供应商承担**人员和物料**（试吃台、围裙、切果刀具、POP海报）。通常试吃果损耗由供应商按进货价或折扣价结算。
-   **商超补贴模式**：如果您的商超处于竞争核心位置，为了吸引客流，您可主动承担部分堆头位费用，换取佳农提供**长周期保底供货**和**独家试吃补贴**。

**3. 必须确认的关键细节（避免后期扯皮）**
无论费用如何谈，务必在书面协议或公司邮件中确认以下几点：

-   **堆头规格**：是1.2米×1.2米的地堆，还是端架？合同周期多久（如2周/1个月）？
-   **试吃标准**：每天试吃果的定额（如香蕉2件/天），超出部分损耗算谁的？
-   **促销员配置**：佳农是否派驻专职促销员？是否承担其管理、工装及社保费用？
-   **费用结算方式**：堆头费是否直接冲抵货款，还是单独打款？是否有促销返利（如进货满X箱返堆头费）？

**4. 备选方案（如果佳农不支持）**
如果佳农区域不提供支持，可退而求其次：

-   询问能否提供**割箱陈列**（简易地堆，成本低）。
-   要求提供**试吃果折扣价**（比如按市场价7折结算试吃损耗），商超自己出人力和堆头。

**执行建议**：今天即可致电您的佳农采购对接人，话术参考：“李经理，我们X月X日至X月X日有个周末大促，想申请佳农的黄金堆头+试吃，您看贵司这边通常能承担哪些费用？如果全包有困难，我们能否对半承担促销员费用？”

这样沟通，您能最快拿到明确答复，并据此制定促销预算。
