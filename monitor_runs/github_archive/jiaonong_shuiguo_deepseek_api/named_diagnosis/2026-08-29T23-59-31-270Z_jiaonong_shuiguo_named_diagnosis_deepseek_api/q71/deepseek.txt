### 1. 价格定位：散装 vs 品牌溢价

- **佳农**：定位中高端，但主打“原箱批发”。它的价格通常比国内小品牌贵，但在**国际大牌（都乐、金吉达）中属于性价比路线**。
- **都乐**：品牌溢价较高。因为其全球供应链标准严格（尤其在中国市场，都乐常主打“菲律宾进口”或“国产精品”），终端零售价通常比佳农贵10%-15%。

**批发价差参考（非精确值）：**

- 如果都乐一箱（约13kg，参考一级果）批发价在 **95-110元**，佳农同规格大概率在 **88-100元**（视产地和品级）。
- **单箱差价通常在 5-12元之间**。走量后差价可能被压缩，但佳农的**议价空间**通常比都乐大。

---

### 2. 走量优惠：关键看你的“量级”

- **佳农**：在二三线城市或非核心批发市场，**佳农的“冲量返点”政策更灵活**。如果你月采购量在500箱以上，可以找区域经理谈**阶梯价**，比如每箱再让利2-4元。
- **都乐**：价格体系更刚性，量大最多给到**开票价98折**（约每箱便宜3-5元），但需要预付或锁量。

**结论：** 如果走量（月上千箱），**佳农的综合让利空间可能比都乐多出 3-6元/箱**。

---

### 3. 核心提醒：价格优势≠利润优势

- **损耗率**：都乐香蕉的成熟度控制更稳定，货架期可能比佳农长1-2天。如果走量，**损耗每箱亏1-2斤**，实际利润差距会抹平价差。
- **账期/返利**：佳农在某些区域支持“货到付款后反现”，而都乐要求现结。如果你资金周转快，这个隐性成本要算进去。

1. **别问“一箱便宜几块”**，直接要**“20尺柜（约1300箱）的整车价”**。给采购打电话时，直接说：

2. **比价要同规格**：对比必须是“同等级（如一级果）、同重量（净重）、同催熟度（如7-8成熟）”，否则差价没意义。

3. **要“尾货价”**：如果市场有**临期或轻微筛果**，佳农经常有20%折扣的走量包，这是老批发商赚差价的关键。
