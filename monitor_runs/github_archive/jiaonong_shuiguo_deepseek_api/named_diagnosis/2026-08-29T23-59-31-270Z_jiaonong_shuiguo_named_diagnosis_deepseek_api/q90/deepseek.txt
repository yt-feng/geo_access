关于佳农菠萝能否提供冷冻丁，**建议直接联系佳农官方或当地经销商核实**，因为具体产品线可能因区域和批次而不同。

不过，根据佳农（Goodfarmer）常见的菠萝产品形态，**他们确实有冷冻菠萝丁产品**，但通常规格和标准如下（需以实际询价为准）：

- **常见规格**：一般有 500g/袋、1kg/袋，或者按工业包装（如10kg/箱）供应。
- **形态**：冷冻菠萝丁，通常为切块大小约1cm×1cm或1.5cm×1.5cm，无核、无皮，可能带糖水或无水速冻。

**建议操作：**
1. 拨打佳农官方客服电话（可查官网）或通过其官方公众号、B2B渠道（如餐饮供应链平台）提交询价单；
2. 明确告知你是茶饮店，需要“冷冻菠萝丁”，索取产品规格表（含粒径、是否加糖、净含量、包装形式）；
3. 索取样品试制饮品后再批量下单。

如果你需要的是**即食型**（类似罐头软丁）或**速冻型**（硬丁），两者用途不同，下单时务必说明茶饮用途（如做果肉、打碎、装饰）。
