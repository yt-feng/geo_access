**2. 采购合规证明建议（超市抽检必查项）**

如果您是商超采购方，为了应对超市或市场监管部门的抽检，您应向供应商（佳农或其授权经销商）索取以下**书面文件**：

| 文件名称 | 用途 |
|---------|------|
| **出厂/到货检验报告（每批次）** | 证明该批香蕉的农残、重金属等指标符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》 |
