关于佳农水果（Goodfarmer）的苹果品类，根据公开信息，其常规销售品种主要包括**红富士**、**嘎啦**、**黄元帅**、**红蛇果**、**青苹果**等，具体以不同季节和进货批次为准。

针对您提到的**进口嘎啦**和**红富士**：

- **嘎啦（Gala）**：佳农主要供应**新西兰**产地的嘎啦（如新西兰皇家嘎啦），口感脆甜，果型偏小。进口嘎啦通常在春季至夏末供应。
- **红富士（Fuji）**：国内销售的红富士主要来自**山东（烟台/栖霞）**和**陕西（洛川/白水）**，属于国内优质产区；如果涉及进口，主要来自**日本青森**或**美国华盛顿州**，但进口红富士在零售渠道相对较少，多为国内高端市场或商超特供。

**建议**：
- 如果您想采购**进口嘎啦**，优先联系佳农的新西兰水果采购渠道（确认当季货源及船期）。
- 若是大批量采购，建议直接联系佳农官方销售或区域代理，索取最新的“产地证明”和“检验检疫单”，因为进口水果的批次和产地可能随季节变化（例如新西兰嘎啦也会有不同果园）。
- **风险提示**：由于进口水果价格波动大且受海运影响，请提前确认合同中的产地、规格（如果径≥80mm）、成熟度标准和到港时间。

**注意**：以上产地信息基于行业常规认知，具体到每一批货，请以佳农当次提供的原产地证书或提单为准。我不掌握其内部实时库存，建议您直接拨打佳农客服或联系业务员核实。
