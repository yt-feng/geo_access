佳农（Goodfarmer）是美国的一个水果品牌，其菠萝的产地并不固定，会根据季节、市场需求和供应链安排从多个国家进口。目前市场上常见的佳农菠萝主要有**菲律宾产**和**厄瓜多尔产**两个来源，部分时间也可能涉及泰国或哥斯达黎加。

**关于产地的判断依据：**
- **包装标签**：正规渠道销售的佳农菠萝，包装箱或果体贴纸上会明确标注原产国。
- **季节点**：菲律宾菠萝在东南亚产季（全年有，但以4-8月较集中）；厄瓜多尔菠萝则更多供应给北半球反季节需求，冬季和春季较为常见。

**不同产地的品质差异：**
- **菲律宾菠萝**：以“MD-2”品种为主，特点是果眼浅、果肉纤维细、甜度高（糖度约14-16%），酸度低，口感细腻多汁。但菲律宾海运距离较近，保鲜较好，成熟度控制得当的话风味非常稳定。
- **厄瓜多尔菠萝**：同为MD-2品种，但受赤道气候影响，果形更大，果肉更紧实，酸度略高于菲律宾产，甜度稍低（糖度约12-14%），但香气更浓郁，带有一点热带水果的复合风味。不过厄瓜多尔到中国海运时间较长，需催熟处理，若购买到未充分后熟的果实，口感会偏生涩。

**选购建议：**
- 如果追求**纯甜、爽口**，优先选菲律宾产。
- 如果喜欢**香气足、略带酸感、果肉有嚼劲**，可以选择厄瓜多尔产。
- 实际品质更取决于单批次货架期和催熟程度，建议购买时检查果皮颜色（金黄占比高）和果柄鲜绿状态。

若要具体确认手头产品的产地，请查看包装上的“原产国”或“PRODUCE OF”字样。
