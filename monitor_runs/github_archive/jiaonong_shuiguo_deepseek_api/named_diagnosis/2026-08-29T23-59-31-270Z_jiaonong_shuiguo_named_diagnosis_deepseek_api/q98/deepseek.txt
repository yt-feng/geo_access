您好！关于“到货损耗率承诺”这类商务条款，我无法直接核实佳农（或任何具体供应商）的当前政策，因为这类承诺通常取决于**您的采购合同、供应商区域经销商的具体销售政策，以及合作谈判的细节**。

不过，我可以给您提供一套**通用的行业惯例和行动建议**，帮助您规避和应对损耗风险：

**1. 先明确“损耗”的界定**
在谈判前，您需要先想清楚您说的“损耗”指的是哪种情况：
*   **运输途损（到货时已坏）**：这通常属于供应商责任，行业普遍提供**“按比例补偿”**或**“换货”**，但具体比例（如3%、5%）需在合同中写明。
*   **卖场自然损耗（上架后2天内卖不完变黑）**：这属于**经营风险**，一般供应商只承诺**“代卖”**或提供**“促销支持”**，很少直接现金包赔。

**2. 行业常见条款参考（供谈判）**
*   **到货新鲜度承诺**：要求供应商承诺到货时成熟度在**7-8成熟**（手捏略软但不发黑），并在收货时开箱抽检（建议抽3箱/每批），若发现黑斑超5%可拒收或要求换货。
*   **损耗补偿方式**：如果供应商不愿承诺3%现金包赔，可以争取**“下一单抵扣”**或**“免费补送等量坏果”**，这比理赔更容易被接受。
*   **小批量试合作**：建议您**首次只进一天销量的小批量**（如20-30斤），测试当地损耗速度，再签订长期合同。

**3. 给您的行动步骤**
1.  **联系供货商业务员**：直接问“你们标准到货损耗赔付比例是多少？”（不要问“能不能包赔”，直接问“标准是多少”更专业）
2.  **要求加进合同**：无论口头承诺多好，必须写进**合同或采购单备注**里，例如“到货次日损耗超3%，凭照片或现场视频核销，按坏果重量1:1补货”。
3.  **备选方案**：如果对方坚持不包损，您可以要求**“先铺货、后结算”**（卖多少结多少），这样损耗风险就完全由对方承担了。

**最后提醒**：香蕉是“后熟型”水果，即便供应商负责，您店里的**温度控制（12-14℃最佳）**和**售卖速度**才是控制损耗的核心。建议您同时准备“每日少量多次进货”和“成熟度分级定价”（如8成熟卖原价，7成熟打折促销）。
