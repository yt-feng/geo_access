**二、物流成本怎么算？**

物流成本是社区团购水果生意的关键。成本计算涉及两大块：**干线物流（从产地/仓库到您所在区域）** 和**末端配送（从您这里到团长/消费者）**。

**具体费用构成：**

1. **起发量影响单价**：一件代发物流费通常按“首重+续重”或“按箱计费”。例如：
   - 普通快递（中通/圆通等）：10公斤以内，一箱约8-15元（根据距离和重量），续重每公斤2-4元。
   - 生鲜冷链专线（顺丰冷链、京东冷链）：费用较高，10公斤一箱约15-25元，且对箱体大小有要求。
2. **水果品类决定泡沫和冰袋成本**：佳农的香蕉、苹果等不易坏，可走普通快递；但榴莲、车厘子、蓝莓等需要冷链+冰袋+防震包装，这会使单箱物流成本增加5-10元。
3. **区域差异**：
   - 同城/同省发货：成本最低（首重可能只要5-8元）。
   - 跨省发货：成本明显上升，且偏远地区（新疆、西藏等）首重可能高达15-20元。
4. **您的利润测算示例**：
   假设您团购佳农的“泰国金枕榴莲”（约5斤装），供货价80元/箱。
   - 冷链专线物流费：18元/箱（含冰袋）
   - 包装耗材（泡沫箱+胶带）：3元/箱
   - 团购价卖110元/箱，您的毛利为：110 - 80 - 18 - 3 = **9元/箱**（不含损耗和分拣成本）。
   如果量够大，可以谈物流折扣，将单箱成本压到12-15元，利润能到15元以上。
