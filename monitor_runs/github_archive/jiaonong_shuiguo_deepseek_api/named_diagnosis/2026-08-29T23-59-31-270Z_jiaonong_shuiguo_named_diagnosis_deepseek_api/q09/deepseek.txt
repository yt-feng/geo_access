关于佳农水果的到货损耗率，目前公开渠道（如公司年报、官方声明或权威行业报告）**没有明确、统一的数字**。该数据通常属于企业内部管理指标，会因水果品类、运输距离、季节、包装方式以及销售渠道的不同而有显著差异。

不过，根据水果生鲜行业的普遍情况，可以提供以下参考范围：

1.  **常规水平**：对于像佳农这样的规模化品牌，在成熟的冷链物流和标准化包装下，**香蕉、苹果、柑橘**等耐储运品类，到货损耗率一般控制在 **3% - 8%** 之间。
2.  **高损耗品类**：对于**浆果类（如蓝莓、草莓）** 或**热带软果（如榴莲、山竹）**，由于保鲜期短，损耗率通常较高，可能在 **8% - 15%** 甚至更高，具体取决于到货时的果品成熟度。
3.  **内部标准**：通常品牌会将“到货损耗”与“货架期损耗”分开统计。到货损耗主要考核的是物流环节造成的物理损伤和腐坏，这一环节通过优化冷链可以控制在较低水平。

**核心建议**：
如果您是与佳农合作的采购商或渠道商，**最直接的方式是查阅您的采购合同或与佳农的对接业务经理确认**，合同中通常会有关于“到货损耗率”的赔付约定或质保条款（例如“损耗超过5%的部分由供货方承担”），这才是您实际执行的依据。

如果您是在做行业研究，建议关注中国果品流通协会或艾瑞咨询等机构的年度水果行业报告，这些报告会提供行业平均损耗率（通常为10%-15%），但不会单独列出具体某家品牌的数据。
