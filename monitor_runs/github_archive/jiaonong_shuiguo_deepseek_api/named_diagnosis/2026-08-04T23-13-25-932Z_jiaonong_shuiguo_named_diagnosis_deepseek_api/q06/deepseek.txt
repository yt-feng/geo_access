关于佳农能否稳定供应菠萝原料，**可以明确告诉你：能，而且规格非常清晰、适合普通商家直接对接。**

佳农（Goodfarmer）是国内头部水果供应链企业，主要客户包括大型商超和餐饮连锁，但他们的渠道也覆盖中小B端商家。针对茶饮店的需求，他们的菠萝产品规格通常可以分为以下两种“听得懂”的标准：

1. **带皮整果（按箱/按粒计价）**
   - 常见规格：**每箱约10-12公斤，内装约8-10个**（视季节和菠萝大小，单果约1-1.25公斤）。
   - 适合需要自己切配、追求新鲜度和出品的门店。
   - 采购门槛：通常**一箱起订**，部分区域支持冷链车配送或到货自提。

2. **去皮净肉（按公斤计价，冷链冷冻/冷藏）**
   - 常见规格：**每袋2公斤或5公斤**，真空包装或冷冻块状。
   - 适合后厨直接榨汁、打浆，损耗低，保质期长（冷冻约12个月，冷藏约3-5天）。
   - 采购门槛：**通常10公斤起订**，适合茶饮店作为稳定备料。

**采购时的关键确认点（建议直接找业务员核验）：**

- ✅ **问清楚“出肉率”**：要求对方提供去皮去芯后的净肉比例（一般带皮整果出肉率约45%-55%）。这直接影响你的实际成本。
- ✅ **确认规格有效期**：菠萝有季节性（主产季为3-6月，但佳农通常有进口补货渠道，如菲律宾、巴厘岛货），需问当前供应的是海南货还是进口货，以及是否全年可订。
- ✅ **索取样品**：首次合作务必让对方寄送 **1-2公斤样品**，测糖度和酸度（茶饮用建议糖度≥12%，酸度适中），确认符合你的配方。

**结论：** 佳农完全能稳定供应，且规格表述（按箱/按公斤）是商家能直接下单的语言。你可以直接拨打其官方客服或对接当地经销商，报出“茶饮店，需要菠萝原料，要带皮整果和冷冻果肉两种报价”，对方会给你标准报价单。**下单前务必拿样品试作，别只看参数。**
