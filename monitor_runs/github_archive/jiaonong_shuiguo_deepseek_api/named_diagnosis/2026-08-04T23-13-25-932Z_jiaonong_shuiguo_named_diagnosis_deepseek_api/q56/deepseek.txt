关于佳农水果和盒马的合作模式，目前公开信息中没有明确公开的、可确认的“直供”或“代销”官方合同条款。根据行业惯例和公开报道，**更主流的情况是“基地直采 + 买断/代销混合”模式**，具体因品类和产地而异。

**几个可判断的行业事实：**

1. **直供模式（买断式）**：佳农作为大型进口和国内水果供应商，通常会与盒马签订年度框架协议，对部分核心单品（如香蕉、菠萝、牛油果）采取**一级果**的直供买断，盒马承担库存跌价风险。
2. **代销/联营模式**：对于部分高损耗、价格波动大的水果（如瓜类、浆果），盒马可能采用**联营代销**，按实际销售额扣点结算，佳农负责品质和补货，盒马不承担死货损失。
3. **“盒马村”模式**：2023年后，盒马更多推动与产地合作社（非中间商）的“订单农业”，而佳农更多作为**供应链服务商**提供仓储、分拣和冷链支持，这个环节更接近代运营而非买断。

**给您的可执行建议（按优先级）：**

1. **初期放弃“直供”幻想**：盒马能直供是因为其日均销售量大且数字化库存管理强。您先做 **“供应商代销+按周结算”** ，并约定**滞销品48小时无条件退货**条款。
2. **“联营”协议关键条款**：参考盒马的抽成逻辑，但您要加**后台费用（如进场费、陈列费、促销费）**，否则利润会被生鲜损耗吃掉。
3. **轻资产“拼单”模式**：如果没有佳农的供应量，可以联合周边超市，通过**当地农批市场或合作社**拼单直采，但只做大单品（如香蕉、柑橘），不做全品类。

**核心结论**：佳农和盒马本质是**供应链效率合作**，不是单纯的买卖关系。您超市可以先从 **“代销+后台费”** 起步，年销售额过3000万后再考虑对部分单品进行直供买断。**不要盲目模仿直供，否则生鲜损耗会在3天内击穿毛利。**
