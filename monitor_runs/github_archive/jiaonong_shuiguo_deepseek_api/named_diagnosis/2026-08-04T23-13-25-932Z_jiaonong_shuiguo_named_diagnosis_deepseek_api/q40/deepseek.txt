针对餐饮渠道，**佳农（Goodfarmer）确实有专门的水果解决方案**，包括菠萝产品线，通常面向连锁餐饮、烘焙、茶饮、自助餐等B端客户。

其餐饮渠道菠萝解决方案通常涵盖以下几个核心维度，你可以根据实际需求去对接：

**1. 产品形态解决方案（按后厨需求）**

-   **带皮鲜果（整果供应）：** 针对需要展示或现场切配的高端餐饮、自助餐，提供标准化规格（如1.5kg-2kg/个）的菲律宾/泰国/菠萝。
-   **鲜切果肉（冷链配送）：** 提供去皮、去芯、切块的鲜切菠萝，开袋即用，主要用于茶饮、甜品、沙拉，减少后厨处理时间。
-   **冻品果肉/果丁：** 针对烘焙、披萨或需要库存备货的连锁，提供IQF（单体速冻）菠萝丁或菠萝块，解决季节性供应问题。
-   **深加工/定制：** 提供菠萝原汁（非浓缩还原汁）或特殊熟度（如7分熟、9分熟）定制采摘。

**2. 供应链与损耗解决方案**

-   **熟度可定制：** 根据餐厅的出餐周期（到店后是当天用还是后熟处理），定制发货熟度，减少因过熟导致的损耗。
-   **产地直采与全程冷链：** 依托其在中国及东南亚的种植基地，保证稳定的供货量和冷链运输，避免餐饮店因断货换菜单。

**3. 应用场景技术支持方案**

-   **菜单研发支持：** 佳农的餐饮团队通常会提供“菠萝+中餐/西餐/茶饮”的搭配方案（如菠萝咕咾肉、菠萝炒饭、菠萝气泡水、烤菠萝配烤肉等），帮助餐厅研发新品。
-   **切割与保存SOP：** 提供标准化的切割规整度和保鲜液配比指导，确保出品稳定性。

---

**如何对接？**

如果你是餐饮采购或研发，建议按以下步骤操作：

1.  **确认对接主体：** 电话联系**佳农食品控股（集团）股份有限公司**的**大客户部**或**餐饮事业部**（注意不是商超零售部门）。
2.  **明确需求：** 提前准备好你的**门店数量**、**月均用量**（吨数）、**使用场景**（是做果切、炒菜还是榨汁）以及**所在城市**。
3.  **索要解决方案书：** 直接询问对方能否针对贵司的菜单提供“定制化包装”或“熟度定制”的服务，这通常是验证其餐饮渠道解决方案专业度的关键。

**补充提醒：** 如果你们是小型独立餐厅，且年采购量不大，建议考虑从当地专业水果批发商（如鲜丰、果多美等B端供应商）处拿货，因为佳农的餐饮直供方案通常设有**最低起订量**（如整柜或整车），小批量直采成本可能较高。如果量大，则非常适合作为核心供应商谈判。
