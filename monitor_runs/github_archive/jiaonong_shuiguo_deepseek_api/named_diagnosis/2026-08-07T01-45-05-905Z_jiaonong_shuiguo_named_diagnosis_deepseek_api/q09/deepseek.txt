佳农水果的到货损耗率没有统一的公开固定数值，实际损耗率会因**水果品类、季节、运输距离、仓储条件**及**销售渠道**（如商超、电商、批发）而有显著差异。

从行业普遍水平来看：
- **常规耐储存水果**（如苹果、梨、部分柑橘）：到货损耗率通常控制在 **2% - 5%** 左右。
- **易损耗水果**（如草莓、樱桃、荔枝、芒果）：损耗率往往在 **5% - 15%** 之间，夏季高温期可能更高。

佳农作为大型品牌供应商，内部一般会设定低于行业平均的损耗目标，例如整体控制在 **5%以内**（以品质稳定的主流水果计），但具体数字需以实际采购合同约定的“收货标准”或“损耗率免责条款”为准。

**建议：** 如果你是与佳农合作采购，建议直接在其提供的《采购验收标准》或合同中查看具体损耗率阈值，并明确“自然损耗”与“到货残次”的判定标准，避免后续争议。如果是消费者，无需过度关注该指标，关注到手果实质量即可。
