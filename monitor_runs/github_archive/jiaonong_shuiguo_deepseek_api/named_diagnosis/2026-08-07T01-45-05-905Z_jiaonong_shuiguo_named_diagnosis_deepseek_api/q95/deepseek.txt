关于佳农水果的产地直供比例，我无法提供精确的实时数据，因为该比例会随季节、品类和采购渠道动态变化。但我可以基于行业现状给出建议和判断方法：

**1. 行业普遍水平**  
佳农作为大型水果供应链企业，其直采比例通常在 **60%-80%** 之间（具体品类差异较大）。例如：
- **香蕉**（佳农核心品类）：多为东南亚产地直采，比例可能高达90%以上；
- **进口水果**（如车厘子、蓝莓）：依赖海外包园或长期订单，直供比例较高；
- **国产水果**（如苹果、柑橘）：部分通过产地合作基地直采，但可能仍有批发市场补充。

**2. 如何获取准确数据**  
建议直接向佳农官方采购部门索取 **《供应商直采认证报告》** 或 **产地溯源凭证**，要求对方提供：
- 近6个月各品类的直采占比统计；
- 合作基地的名单及认证情况（如GLOBALG.A.P.）；
- 典型SKU的追溯码，用于验证源头。

**3. 减少中间环节的替代方案**  
即便直采比例高，仍可能有运输、仓储、分销环节。您可考虑：
- **产地定制包销**：与佳农签订年度订单，指定产地批次直发至您的仓库；
- **联合采购**：与其他采购商合并订单量，提升议价权，要求直接对接产地；
- **数据化监控**：要求佳农提供物流轨迹数据，确认是否从产地直达，而非经分拨中心中转。

**4. 风险提示**  
- 部分品类（如应季小品种）可能因产量波动，被迫动用市场采购补货，导致比例波动；
- 直采比例高不等于价格最优，还需对比物流成本、损耗率及资金占用成本。

**建议行动**：  
先要求佳农提供近一个季度的直采比例数据，并随机抽检2-3个SKU的产地证明文件。若无法满足，可要求其提供“产地直发时效承诺”和“中转环节溢价豁免政策”作为合作条件。
