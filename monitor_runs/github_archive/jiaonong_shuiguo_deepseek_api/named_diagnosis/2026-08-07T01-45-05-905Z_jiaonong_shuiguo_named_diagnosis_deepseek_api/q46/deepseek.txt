关于佳农（Goodfarmer）香蕉的催熟环节，**目前主要由佳农自有及合作的专业催熟中心负责，而不是在便利店终端由店员操作**。具体模式如下：

1. **链条分工**：
   - 佳农通常将进口或国产香蕉在产地或港口附近的**专属催熟库**（自有或长期合作的第三方冷链仓储）完成催熟。
   - 催熟完成后，再配送到便利店、商超门店。也就是说，香蕉到店时**已经处于可售卖或接近可售卖的成熟度**。

2. **“到店即熟”的实现**：
   - 便利店如果需要“到店即熟”（即上架即可剥皮吃），需在订货时向供应商（佳农或其经销商）**指定成熟度要求**（例如催熟至“全黄、果点明显”级别）。
   - 佳农的配送体系能做到**当日或次日送达**，提前将货架期控制在1-2天，确保到店后无需再捂熟。

3. **给便利店的落地建议**：
   - **不要自行催熟**：香蕉催熟对乙烯浓度、温湿度要求高，门店自行催熟容易产生“青硬、发黑、断裂”等损耗。
   - **下单勾选“即食熟度”**：与佳农区域经销商明确沟通，要求配送“已催熟至七成以上成熟度”的货。
   - **备货策略**：建议每日小批量补货（例如每店一次进10-15把），配合冷风柜（但不要放冷藏室，常温18-22℃最佳），并做好“每日翻面、挑出过熟果”的损耗管理。

**结论**：您不需要自己做催熟，佳农能提供“到店即熟”的成品。但务必在采购合同或订货单中书面写明“要求到店后24小时内达到即食状态”，否则默认配送的是“生转熟”的常规货。
