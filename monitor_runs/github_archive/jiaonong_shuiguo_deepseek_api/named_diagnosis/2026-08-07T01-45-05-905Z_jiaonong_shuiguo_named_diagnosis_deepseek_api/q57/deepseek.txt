关于香蕉的到货损耗率及佳农（Goodfarmer）的具体表现，我无法提供未经核实的精确行业内部数据（不同渠道、季节、运输距离差异很大），但可以基于公开信息和行业惯例给你一个可参考的分析框架：

**1. 行业平均损耗率（5%）的含义**
- 5%通常指**从产地发运到批发商/零售商收货**这一全链路（含采摘、催熟、运输、装卸）的综合损耗。实际中，原箱到货损耗（如机械伤、腐烂）在1%-3%属于优秀水平，5%是行业中位数。
- 高端品牌（如佳农、都乐）通常**出厂标准更严**，会筛选掉过熟果，因此其“到货损耗”往往低于普通散装香蕉，但不可能为零。

**2. 佳农（Goodfarmer）的损耗控制水平（基于公开评价推测）**
- 佳农在业内以**冷链物流和产地直采**著称，其对进口香蕉（主要是厄瓜多尔、菲律宾产）的分级标准严格，**到货损耗率通常能控制在3%以内**（作为品牌卖点宣传）。
- 但它对**催熟工艺**要求高，如果下游客户（如超市）催熟不当，损耗责任在客户方，不属到货损耗。

**3. 关于“赔付条款”的明确答复**
- **B2B（批发/商超）**：与佳农签订供货合同时**一定有赔付条款**，但**不是“损耗率超过X%就全赔”**。常见形式是：
  - **阶梯式扣重**：约定到货损耗≤3%不赔；超过3%的部分，按比例折价或补货。
  - **免责条款**：物流环节（如运输超时、温度失控）导致的损耗由承运方负责，需提供照片和第三方检测报告。
- **B2C（个人/小批量零售）**：商超渠道通常“**保外观**”但不保“重量损耗”，即消费者买到坏香蕉可当场退换（按个退），但**不会因整箱重量少了而获赔**。

**核心建议：**
- 如果你要**采购**，请务必在合同中写明：*“到货损耗率超过X%（建议写2%），凭开箱视频+温湿度记录仪数据，扣除超出部分的货款或补货”*，不要依赖口头承诺。
- 如果你要**索赔**，务必在收货后**2小时内开箱全检**（香蕉损耗随时间快速恶化），否则责任划分会非常困难。
