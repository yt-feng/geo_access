### 1. 佳农是“大贸”玩家，规格基本是“整柜/整车”起的
- **普通商家（比如单店、小型连锁）想零买几箱**：佳农官方一般不接这种单，因为分拣、物流成本不划算。但他们的**经销商/批发市场档口**会拆箱卖，规格通常是**5kg/箱（约6-8个）**或**10kg/箱（约10-12个）**。
- **大量采购（比如一天消耗几十公斤以上）**：可以走整柜（约20-25吨）或者整车，他们能稳定供应，但你要提前预付定金、锁定档期（尤其是菲律宾或泰国产季）。

### 2. 你“听得懂的规格”具体指什么？
- **按个头分**：常见规格是**“2头/箱”到“6头/箱”**（指一箱几个果）。比如10kg箱里装5个，就是“2kg/个”的大果；装8个，就是“1.25kg/个”的中果。**你说清楚需要多大的果**，他们能按等级供。
- **按成熟度分**：佳农做的是**催熟果**（青色运到国内，再催熟发黄）或**即食果**（到岸已黄香）。你要做饮品，通常要**7-8成熟**（青皮微黄）方便后熟保存，这点要说清楚。

### 3. 稳定性取决于你的“用量稳定性”
- 如果你每天用量稳定（比如每天50kg以上），签订**年度框架协议**，他们能稳定供（主力是菲律宾MD2品种，品质稳定）。
- 如果你是**季节性大用量**（比如夏天波动大），他们也能供应，但你要接受**价格随行就市**，旺季可能会涨。
