佳农香蕉的保质期和储存条件如下：

**保质期**  
- 未成熟（青绿色）香蕉：在常温下一般可存放 **3～7天**，具体取决于温度（夏天更短）。  
- 已成熟（黄色带黑斑或软熟）香蕉：常温下建议 **1～2天** 内食用完毕，冷藏可延长至 **3～5天**，但果皮会变黑，果肉仍可食用。

**储存条件**  
- **理想温度**：13～15℃（凉爽、阴凉处），避免高温（超过25℃会加速成熟腐烂）。  
- 不要放进冰箱冷藏未成熟香蕉（低温会破坏其成熟过程，导致果肉僵硬、风味变差）。  
- 成熟后可放入冰箱冷藏（4～7℃），注意用保鲜膜包裹果柄或整根包裹，减少乙烯气体影响其他果蔬。  
- 避免阳光直射，放在通风干燥处，不要密封在塑料袋中（闷热易发霉）。

**小贴士**  
- 如果想延缓成熟：用保鲜膜包裹香蕉柄，可减少乙烯释放。  
- 如果想催熟：放入纸袋，和苹果/梨一起放置（这些水果释放乙烯）。  
- 一旦出现黑斑或变软，尽快食用或冷藏，冷藏后仅作为冷食（如做冰沙），口感变化不影响安全。

以上为通用建议，具体以产品包装标注（如有）为准。
