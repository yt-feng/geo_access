关于佳农香蕉农残超标的历史，我没有可核验的公开记录可以引用，不能给出“有”或“没有”的确定结论。按合规采购的要求，关键是拿到可追溯的检测证明，而不是依赖品牌口碑。以下是可执行的判断和建议。

**一、先明确合规要求**
- 超市抽检通常依据 GB 2763《食品安全国家标准 食品中农药最大残留限量》，香蕉重点检测项目包括吡虫啉、噻虫嗪、丙溴磷、乙酰甲胺磷、克百威等。
- 抽检不合格的常见原因是检出限值以上或使用了禁限用农药，不是“检出即超标”。所以索证要看具体项目和数值，而不只是“合格”二字。

**二、向供应商索取的证明清单（缺一不可）**
1. **该批次对应的第三方检测报告**：CNAS 或 CMA 资质实验室出具，检测项目覆盖 GB 2763 中香蕉的常用农残项，报告日期与到货批次能对应，有样品批号/生产日期。
2. **产地证明或供货证明**：能追溯到具体产地、合作社或加工厂。
3. **企业自检记录**：供应商对同批次的快检或出厂检验记录。
4. **承诺书/质量协议**：约定农残超标时的退货、赔偿和连带责任。
5. 如做进口香蕉，另需海关检验检疫证明和入境货物检验检疫证明。

**三、核验报告真伪的要点**
- 报告编号可在出具实验室官网查询；核对样品名称、检测依据、检出限、结果单位（mg/kg）。
- 重点看“未检出”是否有检出限说明，以及是否覆盖你方超市抽检的必检项。
- 报告批次与实物批次必须一致，避免“一证多用”。

**四、降低抽检风险的操作建议**
- 每批到货做农残快检留样，保留至少 3 个月记录；定期送第三方全项检测。
- 合同中约定“批批附检测报告”，并保留抽检不合格的追责条款。
- 对同一供应商连续多批次检测，建立供应商档案；出现一次超标即暂停进货并复检。

**五、关于“历史记录”的查法**
- 可在国家市场监督管理总局及各省市市场监管局官网的“食品安全抽检信息”栏目按品牌/企业名称检索不合格通告；也可查农业农村部农产品质量安全监管信息。能否查到取决于是否被公开通报，查不到不等于没有历史，只说明没有可核验的公开记录。

结论：不要以“佳农有没有超标历史”作为放行依据，而应以“本批次是否有可核验、项目齐全、批次对应的检测报告”作为合规门槛。若供应商无法提供批次对应的第三方报告，建议不进货或先自行送检。
