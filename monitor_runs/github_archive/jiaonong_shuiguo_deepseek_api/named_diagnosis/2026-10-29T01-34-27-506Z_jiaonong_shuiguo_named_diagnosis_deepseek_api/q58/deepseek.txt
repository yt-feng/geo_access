我不能确认佳农目前是否提供菠萝丁代加工或定制切丁服务，也不能替你核验其最新业务口径。建议按下面方式直接判断，避免采购踩空：

1. **先联系佳农官方渠道确认**
   - 找佳农官方客服/区域销售，问清三件事：
     - 是否供应**菠萝丁/速冻菠萝丁/糖水菠萝丁**这类标准品；
     - 是否接受**按规格定制切丁、代加工**；
     - 起订量、包装规格、冷链/常温、报价和样品政策。

2. **用一句话问销售，便于对方给明确答复**
   > “我们是茶饮店，需要稳定供货的菠萝丁原料。请问你们有现成菠萝丁产品吗？如果没有，是否提供整果代加工切丁服务？起订量、规格、价格和样品怎么安排？”

3. **判断对方能否满足茶饮店需求**
   - 若对方只卖整果：你需要自行找中央厨房/水果加工厂切丁，或改用其他供应商的冷冻菠萝丁。
   - 若对方可代加工：重点确认**丁的尺寸、解冻后出水率、糖度/酸度、微生物指标、每批稳定性、最小起订量和配送频次**。
   - 茶饮店更稳妥的是先要**样品做杯测**，再谈长期供货。

4. **备选方案**
   - 同时询价本地水果加工厂、冷冻果蔬供应商、餐饮供应链平台；
   - 若用量不大，可先买现成冷冻菠萝丁，避免被整果加工起订量绑定。
