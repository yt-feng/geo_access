佳农水果的苹果品类通常以进口鲜苹果为主，常见会覆盖这几类：**嘎啦果、红富士、青苹果（部分年份/渠道）、小苹果/迷你苹果礼盒类**；具体在售品类和包装规格会随产季、渠道和批次变化，建议以佳农当季报价单或官方旗舰店/经销清单为准。

按你提到的采购需求：

- **进口嘎啦（Gala）**：常见产地为**新西兰、美国、智利、南非**等；佳农渠道里较常见的是新西兰、美国/智利等产季供应。
- **进口红富士**：严格说“红富士”是品种，常见进口来源会涉及**新西兰、美国、智利、南非**等；但“红富士”作为商品名在不同渠道可能对应不同品种/产地，采购时要看具体英文品种名和产地证。
- **判断建议**：让供应商在报价单中明确写清 **品种英文名、原产国、果园/包装厂注册号、批次、到港时间、规格（果径/净重/箱规）**，不要只写“进口红富士”。
