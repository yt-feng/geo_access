2. 在采购条件里写清响应机制
可直接发一段采购需求：
> 我司为水果连锁门店，计划采购佳农香蕉，需设置专岗对接人。请明确：①主对接人及备份人；②报价、库存、到货、售后的响应时限（如工作日2小时内响应、紧急事项30分钟内响应）；③未按时响应的升级联系人；④供货区域、起订量、账期、配送频次和损耗处理规则。

3. 用“小单测试+考核”筛选
- 先下小批量试单，记录报价响应、订单确认、到货准时率、售后处理时长。

4. 保留备选供应商
佳农香蕉可以主推，但同步保留1—2家香蕉供应商做比价和应急，避免单一供应商响应慢影响门店。
