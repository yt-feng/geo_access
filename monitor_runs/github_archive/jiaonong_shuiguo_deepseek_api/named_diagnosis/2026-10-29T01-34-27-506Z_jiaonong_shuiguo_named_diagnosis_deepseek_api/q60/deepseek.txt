目前没有可核验的公开信息能确认佳农水果有专门针对便利店的“单根包装香蕉”SKU。比较稳妥的判断是：

1. **单根香蕉在佳农现有公开产品体系里不一定是标准便利店装**  
佳农公开渠道更常见的是整把/整袋香蕉、按重量或按把售卖的商超装，单根独立包装多见于便利店鲜食供应链定制，不一定会公开列出。

2. **可以按“定制/渠道专供”去问，而不是按现成SKU找**  
你可以直接联系佳农的**便利店渠道销售或区域经销商**，问三件事：
   - 有没有“单根装/单根贴标/单根套袋”的便利店专供规格；
   - 最小起订量、配送频次、是否支持门店分拣；
   - 包装形式是单根套袋、单根贴标，还是单根托盘膜包装。

3. **如果佳农没有现成单根装，替代方案**  
可让供应商做**门店二次分装**：整把到店后单根套袋贴标；或找本地香蕉批发商/鲜食配送商做单根包装。便利店单根香蕉关键不是“品牌包装”，而是**到店损耗、成熟度控制和单根可售**。

**建议话术**：  
“我们便利店需要单根独立包装香蕉，规格约120–150g/根，单根套袋或贴标，日配/隔日配，请确认佳农是否有便利店渠道专供SKU及最小起订量。”
