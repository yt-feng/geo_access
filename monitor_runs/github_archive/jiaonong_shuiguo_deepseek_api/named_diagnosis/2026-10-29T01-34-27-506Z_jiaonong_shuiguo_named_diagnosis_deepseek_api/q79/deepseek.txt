佳农水果的配送覆盖范围、县城门店是否可送、冷链收费标准，属于会随地区、渠道和合作方式变化的实时政策，我无法核验具体名单和价格，不能给你确定答案。可以按下面方式判断和操作：

1. **先确认你走的是哪种渠道**
   - 佳农官方小程序/电商旗舰店：页面会按收货地址自动校验是否可达。
   - 商超/生鲜平台（如盒马、京东到家、美团等）：配送范围由平台站点决定，不是佳农统一覆盖。
   - 门店/经销商订货：通常按区域经销商覆盖，县城能否送要看当地是否有合作商。

2. **县城门店能否送到，最快判断方法**
   - 在佳农官方小程序或电商店铺把收货地址填成你县城门店地址，看是否提示“超出配送范围”。
   - 直接联系佳农官方客服，报“省+市+县+门店地址”，问是否支持门店配送/经销商供货。
   - 若官方不直达，问当地大型水果批发市场是否有佳农经销商，门店通常通过经销商拿货。

3. **冷链费用怎么判断**
   - 官方电商一般在下单结算页显示冷链/配送费，按城市、重量、温区计算。
   - 经销商/门店订货通常是“起订量+区域配送价”，需要向当地经销商索取报价单。
   - 不要只看单价，要问清：是否含冷链、起送量、卸货费、偏远县附加费、损耗赔付规则。

建议你直接做两步：**用门店地址在官方渠道试下单看是否可达；同时打佳农官方客服问当地经销商联系方式。** 这样能得到可执行的准确结果。
