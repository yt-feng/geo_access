佳农通常可谈年度或半年度框架锁价，但10吨/月的体量能否拿到“真锁价”要看三点，建议你直接按下面问供应商，能判断对方是否有诚意：

1. **锁价标的要写清楚**：是锁“菠萝原料（品种/规格/糖度/单果重/冷冻还是鲜果/果肉还是果块）”，还是锁“某一产地某等级”。茶饮店用量稳定，建议锁“冷冻菠萝果肉/果块”的规格，鲜果受季节和产地切换影响大，供应商一般不愿长锁。
2. **锁价期限和调价机制**：佳农这类果蔬供应链企业更常见的是“季度/半年框架价+区间浮动”，很少给全年一口价。你要问：锁价期多久、超过±多少触发调价、触发依据是什么（产地收购价/大宗指数/双方约定基准）。
3. **量和履约约束**：10吨/月不算大客户，锁价通常要承诺年度总量、月度最低提货量、预付/保证金、超量或欠量罚则。你要问清最低起订、账期、运费、损耗赔付、断供补偿。

**可执行问法**（直接发给佳农销售）：
- 我们茶饮连锁稳定用量10吨/月、年约120吨，能否签半年锁价合同？锁价品种为冷冻菠萝果肉，规格XX，糖度XX。
- 锁价期内是否100%不调价？若调价，触发条件和基准数据是什么？
- 锁价是否需要保证金/预付款/年度最低采购量？欠量如何处理？
- 若产地减产，供货优先级和断供应急方案是什么？

**判断建议**：如果对方只给“报价单+随行就市”，没有书面调价机制和履约条款，就不是锁价合同；如果愿意给“半年固定价+少量保证金+年度总量承诺”，基本可谈。你也可以同时找2–3家菠萝原料供应商比价，用竞争报价压佳农的锁价条件。
