佳农水果（Goodfarmer）的香蕉催熟，通常是在产地采收青蕉后，在销地催熟库用乙烯气体（或乙烯利释放乙烯）进行人工催熟，不是树上自然熟。商超如果直接采购佳农催熟蕉，催熟时间主要由供应商的催熟库工艺决定；如果是采购青蕉自行催熟，可按以下控制。

**商超可执行的催熟控制建议：**

1. **确认采购状态**
   - 问清是“已催熟黄蕉”还是“青蕉/微黄蕉”。已催熟蕉到店后只需控温转黄，不再补乙烯。
   - 要求供应商提供催熟批次、催熟日期、目标到店成熟度（如色度3-4号）。

2. **青蕉自行催熟参数**
   - 温度：15–18℃，不要超过20℃，避免高温软烂、风味差。
   - 乙烯：用乙烯气体浓度约100–150 ppm，或按乙烯利产品说明处理；密闭12–24小时。
   - 湿度：85%–90%。
   - 通风：乙烯处理结束后通风换气，之后在15–18℃下转黄。
   - 转黄时间：一般乙烯处理结束后2–5天达到可售色度，具体看初始青度和品种。

3. **商超控时要点**
   - 按“色度卡”收货和排面：目标色度3号左右上架，避免一次催到5号以上。
   - 少量多批催熟，不要整库一次性催到全黄。
   - 到店后13–15℃冷藏会抑制转黄但可能造成冷害，香蕉一般不建议低于12℃长期存放。
   - 催熟库和卖场分开，卖场高温会加速过熟。

4. **关于“自然熟”**
   - 商超渠道的佳农香蕉基本不是树上自然熟，因为香蕉需青采运输。所谓“自然熟”多为不补乙烯、靠自身乙烯缓慢转黄，时间不可控，不适合商超精确控时。

**结论：** 按人工乙烯催熟工艺管理催熟时间；具体乙烯浓度和密闭时长以佳农供应商的批次说明为准，不要自行套用其他品牌参数。
