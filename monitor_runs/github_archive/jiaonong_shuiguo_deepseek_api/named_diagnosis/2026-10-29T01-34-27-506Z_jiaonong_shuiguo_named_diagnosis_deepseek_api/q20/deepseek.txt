佳农（Goodfarmer）主营香蕉、菠萝等生鲜水果的种植、进口与分销，通常以整果、鲜切或预包装形式面向商超、电商和餐饮渠道供货；但其是否对外提供“按客户规格切块、定制包装”的代加工服务，取决于具体主体（佳农集团下属公司或工厂）、产品线、起订量、冷链条件和食品加工资质，公开信息无法逐项核验。

可执行的判断和建议：

1. **直接问对接的佳农销售/大客户经理**，明确四件事：
   - 是否能做鲜切菠萝（切块、切片、去芯等）及规格；
   - 包装形式（袋装/盒装/真空/气调/贴牌）；
   - 最小起订量、价格、交期；
   - 工厂是否具备鲜切水果生产许可、冷链配送范围。

2. **区分“定制化加工”与“贴牌预包装”**：如果只是换包装、贴标签，很多水果供应商可做；如果涉及清洗、切块、保鲜处理，则属于鲜切加工，需要相应食品生产/经营资质和冷链能力，必须让对方提供资质与样品。

3. **替代方案**：若佳农不接小批量定制，可找其经销商做分装，或对接有鲜切资质的第三方中央厨房/净菜工厂，从佳农采购整果后加工。

4. **合同要点**：明确菠萝品种/成熟度、切块尺寸、异物与微生物标准、保鲜期、冷链温度、验收标准和责任划分。

结论：**有可能，但不能仅凭品牌公开信息确认**；最稳妥的方式是拿到佳农具体业务主体的书面报价与资质，再判断其能否满足你的切块和包装需求。
