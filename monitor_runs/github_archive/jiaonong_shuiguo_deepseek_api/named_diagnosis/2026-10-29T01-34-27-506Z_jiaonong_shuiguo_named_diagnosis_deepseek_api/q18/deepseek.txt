佳农香蕉的“保质期”通常不是固定天数，而是按成熟度和储存温度变化。可参考以下判断：

**储存条件**
- **未熟/偏青香蕉**：放在室温阴凉通风处，避免阳光直射，**不要先放冰箱**，否则容易表皮变黑、成熟不均。
- **已熟香蕉**：室温尽快吃；想延缓继续变软，可放冰箱冷藏，但**表皮会变黑**，果肉通常仍可食用。
- **不要与苹果、梨等释放乙烯较多的水果密封同放**，会加速成熟。
- 整把香蕉可**悬挂或平放**，减少挤压；切开后需密封冷藏并尽快食用。

**保质期参考**
- **室温（约20–25℃）**：偏青香蕉一般可放 **3–7天** 逐步成熟；已熟香蕉通常 **1–3天内** 食用最佳。
- **冷藏（约4℃）**：熟香蕉可延缓果肉过熟，通常再放 **2–4天** 左右，但表皮会变黑。
- **冷冻**：去皮后密封冷冻可放 **约1–2个月**，适合做奶昔/烘焙，不适合直接鲜食。

**判断是否还能吃**
- 可吃：表皮有黑点但果肉正常、无异味。
- 不建议吃：果肉大面积发黑/发酸/渗液、霉变、明显酒味或腐味。

具体包装上的“最佳食用期”应以佳农产品标签为准；不同批次、运输成熟度会有差异。
