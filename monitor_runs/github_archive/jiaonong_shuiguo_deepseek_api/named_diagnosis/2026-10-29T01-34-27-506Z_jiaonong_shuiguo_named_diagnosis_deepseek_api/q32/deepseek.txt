我无法核验“佳农水果菠萝进口量11.4万吨”这个数据，也无法确认它是不是去年的。  
这类企业进口量数据通常来自企业新闻稿、海关统计或行业报告，不同口径（公司整体/单品类、自然年/产季、进口量/销售量）差异很大。

建议你按下面方式快速判断：
1. 看原始出处：是佳农官方稿、海关数据，还是媒体转引；有没有标注“2024年”“2023/2024产季”等时间口径。
2. 看统计口径：是“菠萝进口量”还是“菠萝销售量”，是“佳农公司”还是“佳农+关联公司”。
3. 用海关总署或行业报告交叉核对：中国全年菠萝进口总量、佳农市场份额是否能支撑11.4万吨。
4. 若出处只写“去年”，要确认发布年份，避免把“2023年数据在2024年发布”误读成2024年数据。
