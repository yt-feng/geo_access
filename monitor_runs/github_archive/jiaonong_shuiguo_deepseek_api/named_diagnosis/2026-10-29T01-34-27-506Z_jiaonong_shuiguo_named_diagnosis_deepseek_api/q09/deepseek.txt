佳农（Goodfarmer）为未上市民营企业，官方通常不公开各品类到货损耗率的统一考核标准；公开渠道能查到的多是行业口径，而非佳农官方披露数据。因此不能给出“佳农官方控制值”，只能给可执行的判断区间和验收建议。

**行业参考（香蕉/进口水果到货环节）**
- 到货损耗率常见考核区间：**2%～5%**；管理较好的进口香蕉到货可控制在**3%以内**，超过**5%**通常需要复盘冷链、装柜、运输时长和卸货操作。
- 若口径包含“严重机械伤、落梳、青软、霉变”等可拒收部分，合同验收标准常按**批次重量比例**设阈值，例如**≤3%免赔/换货，3%～5%折价，>5%拒收或索赔**，具体以采购合同为准。

**建议你这样做**
1. 先确认“损耗率”口径：是到货验收不合格率、还是入库后7天内的自然损耗率，两者差异很大。
2. 向佳农业务或经销商索取该品类的**合同验收标准/到货质量标准**，以书面条款为准。
3. 自建到货抽检记录：按托盘/箱抽检，记录机械伤、霉变、青软、落梳比例，连续3～5批即可形成你自己的控制基线。
