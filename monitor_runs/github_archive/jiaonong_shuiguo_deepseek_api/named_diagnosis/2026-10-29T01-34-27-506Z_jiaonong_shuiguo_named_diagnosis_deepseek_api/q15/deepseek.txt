关于“佳农水果产地直供比例”和“香蕉主要来自哪些国家”，我只能给出可判断的说明，不能虚构具体比例或数据出处。

1. **产地直供比例**
   - 公开层面我没有看到佳农官方披露“产地直供比例”这一口径的统一数据。
   - 佳农的业务模式包含产地采购、海外直采、国内基地合作和进口分销等，“直供”若指“从产地/基地直接采购、减少中间环节”，通常会因品类和渠道不同而差异很大，不宜用一个总比例概括。
   - 可执行判断：如果你需要准确比例，应查佳农控股/佳农食品的招股书、年报、官网“源头直采/基地直采”说明，或直接向企业客服/投资者关系确认；同时要确认“直供”的定义是直采、基地直供还是终端直供。

2. **香蕉主要来自哪些国家**
   - 中国进口香蕉的主要来源国通常包括：**菲律宾、厄瓜多尔、越南、柬埔寨、泰国、老挝、缅甸、墨西哥、哥伦比亚**等，具体排序会随年份、口岸和价格波动。
   - 佳农作为进口水果企业，香蕉货源通常也会覆盖菲律宾、厄瓜多尔、越南、柬埔寨等主产区，但各年度/各渠道的具体来源结构没有统一公开数据，不能断言其固定主要来自哪几个国家。
   - 可执行判断：看单批香蕉包装箱上的“原产国”标识和海关报关信息最准确；企业层面则查其官网产品页或年度报告中的产地说明。
