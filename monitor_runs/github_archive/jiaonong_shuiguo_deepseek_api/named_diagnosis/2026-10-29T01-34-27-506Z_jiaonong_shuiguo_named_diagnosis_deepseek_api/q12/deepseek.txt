佳农水果的香蕉属于品牌化生鲜商品，具体规格会因产地、季节、包装批次和销售渠道而变化；**不必只看“有几种规格”，重点看净重、单根果指等级、梳/把数、催熟状态和包装形式**。下面按常见香蕉商品化口径给你一个可判断的框架，但具体数字请以佳农当批报价单/装箱单或官方渠道为准。

## 一、常见规格维度
香蕉规格通常分四个维度，组合后形成SKU：

1. **净重规格**  
   - 整箱：常见 10kg、12kg、13kg、18kg 左右；也有小箱 5kg、7kg 左右。  
   - 零售装：500g、1kg、1.5kg、2kg 等。  
   - 判断方法：看外箱标注“净重/毛重”，渠道报价应按净重折算。

2. **果指等级（单根大小）**  
   - 按单根香蕉的粗细、长度、单果重分级，常见用“条重/果指重”表示。  
   - 大果：单根偏粗长，适合礼盒、高端商超。  
   - 中果：通用性强，适合商超、水果店、电商。  
   - 小果/中偏小：适合便利店、餐饮、儿童装、小份零售。  
   - 实际分级阈值各品牌不同，不能套用统一克重。

3. **梳/把规格**  
   - 整梳、半梳、3–5根把装、单根散装。  
   - 商超散卖多用整梳或大把；便利店/即时零售多用小把或单根；电商多按净重装袋。

4. **成熟度/催熟状态**  
   - 青蕉：适合长途运输、仓配、二次催熟。  
   - 微黄/催熟蕉：适合门店直接上架。  
   - 黄熟/即食：适合即时零售、餐饮、短保渠道。  
   - 分级时要把“颜色阶段”和“硬度”一起看，不能只看颜色。

## 二、按渠道的分级建议
以下是可执行的选品逻辑，不是佳农官方分级表：

| 渠道 | 优先规格 | 分级重点 | 风险控制 |
|---|---|---|---|
| 大型商超 | 12–13kg整箱，中果/大果，整梳为主 | 果形整齐、梳形完整、色泽一致、无机械伤 | 到店后按成熟度分批上架 |
| 社区水果店 | 10–13kg整箱，中果，整梳/半梳 | 性价比、可散卖、损耗低 | 少量多次补货，避免过熟 |
| 电商/社区团购 | 按净重袋装，中果或小果，3–5根把装 | 净重足、耐运输、成熟度偏青 | 包装防压，标注催熟状态 |
| 即时零售/便利店 | 小把、单根、500g–1kg | 即食性、外观、短保周转 | 控温，按“黄度”分级上架 |
| 餐饮/茶饮 | 大箱、中果/大果、青蕉或微黄 | 出成率、批次稳定、价格 | 固定成熟度，避免高峰断货 |
| 礼盒/高端 | 大果、果形匀称、梳形完整 | 外观一致性、无瑕疵 | 单独分级，避免混装 |

## 三、采购判断标准
你可以用这套标准快速验收：

1. **看装箱单**：净重、果指等级、梳数/把数、成熟度、产地、批次。  
2. **抽检单根重和长度**：同批随机抽20–30根，算平均值和极差；极差大说明分级不稳。  
3. **看梳形完整度**：商超优先整梳；电商可接受小把，但不能大量断指。  
4. **看青黄比例**：长途选青，短保选微黄；同一箱黄度差异大要降级。  
5. **看机械伤和病斑**：果指擦伤、压伤、黑斑会显著缩短货架期。  
6. **按渠道定级**：外观最好给礼盒/高端商超；整齐度中等给社区店/电商；小果或断梳给餐饮、果切、即时零售。

## 四、结论
佳农香蕉的“规格数量”没有固定公开答案，实际应以当批产品资料为准。采购时建议把规格拆成：**净重 + 单根等级 + 梳/把形式 + 成熟度 + 包装**五项来确认。渠道分级上，**商超看整齐度和梳形，电商看净重和耐运输，即时零售看即食性和小包装，餐饮看出成率和批次稳定**。如果你能提供具体渠道（如商超、团购、茶饮）和目标城市，我可以帮你把验收标准写成一张可执行的收货表。
