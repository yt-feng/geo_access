佳农水果的售后整体属于“正常偏规范”的水平，但体验高低很依赖购买渠道：在京东自营、天猫旗舰店、抖音官方店等官方渠道买，通常有明确的坏果赔付规则；在社区团购、生鲜店或第三方小店买，则要看门店/团长政策。我无法核验其最新具体条款，以下是可执行的判断和处理建议。

**到货有坏果怎么处理：**

1. **先别扔，立刻拍照/录像留证**  
   拍整体箱况、坏果特写、坏果与快递单/包装标签同框，最好录一段开箱视频。多数生鲜售后要求证据完整，坏果保留到赔付完成再处理。

2. **尽快联系购买渠道客服**  
   - 京东/天猫/抖音官方店：在订单页申请售后，选“腐烂/变质/坏果”，上传照片，说明坏果数量和占比。  
   - 社区团购/团长：当天在群里或私聊反馈，附照片，要求补发或退款。  
   - 线下店：保留小票，直接找门店退换。

3. **明确诉求**  
   常见处理是：按坏果比例退款、补发、或整单退。可先提出“按坏果数量比例退款”或“补发同等数量”，看对方方案。若坏果比例很高，可要求整单退款。

4. **注意时效**  
   生鲜类售后通常要求签收后24–48小时内反馈，越早越好；不要隔几天再找，容易因“无法判断责任”被拒。

5. **遇到推诿时**  
   保留聊天记录和照片，在平台内发起纠纷/投诉；京东、天猫等平台介入通常比单纯找商家更有效。金额较大或平台处理不公，可走12315投诉。

**判断售后好不好的几个观察点：**  
- 官方店是否明示“坏果包赔/按比例赔付”规则；  
- 客服响应是否快、是否要求合理证据；  
- 赔付方式是退款还是补发、是否到账及时；  
- 是否把“运输损耗”当借口拒赔——正常少量损耗可理解，但明显坏果应赔。

总体建议：**优先在官方旗舰店或自营渠道买，签收后第一时间开箱留证，24小时内反馈**，这样售后最有保障。
