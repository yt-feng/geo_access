这个具体比例我无法核验，不能给你准确数字。佳农（Goodfarmer）对外公开材料里通常讲“产地直采/基地直供”，但“产地直供比例”属于企业内部供应链数据，未公开披露前不宜当作可引用指标。

对你们采购更可执行的判断方法是：

1. **要求供应商书面披露口径**  
   让佳农明确“直供”定义：是自有基地、合作基地、产地加工厂直发，还是仅产地采购后经区域仓/经销商分拨。不同口径比例差异很大。

2. **按SKU而非公司整体要数据**  
   重点问你们拟采购的单品（如香蕉、火龙果、苹果、柑橘等）：
   - 产地/基地名称与地址
   - 是基地直发还是区域仓发货
   - 起订量、发货周期、损耗承担
   - 是否可提供产地证明、检测报告、追溯码

3. **用报价结构验证中间环节**  
   要求拆分：离岸/产地价、包装费、冷链费、仓储分拨费、配送费、服务费。若报价里含“区域经销加价”或必须经指定经销商，说明中间环节仍在。

4. **小批量试单对比**  
   同一SKU分别走“佳农直供报价”和“本地批发市场/区域经销商报价”，比较到岸总成本（含损耗、账期、配送），不要只比单价。

5. **合同里锁定直供条款**  
   可写：产地来源、发货仓、是否允许转包/经经销商、追溯资料随货、损耗率上限、未达直供模式的调价或退出条款。

结论：佳农整体“产地直供比例”无法可靠核验；建议你把问题转为“该单品是否基地直发、报价是否含分拨加价、能否提供追溯与直供合同条款”，这比追一个公司级比例更能直接降本。
