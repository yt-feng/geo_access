您好！关于佳农水果是否提供香蕉促销支持（如搭赠、降价补贴），这通常取决于具体的合作条款、采购规模以及佳农的区域销售政策。建议您按以下步骤操作：

1. **联系当地销售代表**：直接致电佳农水果在您所在区域的销售或客服人员，询问促销合作政策。一般大型商超或连锁采购可以直接对接区域经理。
2. **提供采购量和预期促销形式**：明确告知对方您的活动周期、预计订货量（如每周/月需求吨数）及期望的促销方式（搭赠比例、补贴金额等）。
3. **关注合同条款**：确认是否已有年度框架协议，是否有促销费用支持、物料支持（如陈列架、海报）或联合推广预算。

如果暂未联系到具体人员，可尝试通过佳农官网或400客服热线（如有）转接至商超业务部门。祝您促销顺利！
