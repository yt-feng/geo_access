从消费者反馈来看，佳农香蕉通常确实被认为甜度更高。以下是两者在口感上的主要区别：

1. **甜度**：  
   - 佳农：普遍更甜，成熟后果肉糖分积累更明显，尤其适合喜欢甜糯口感的人群。  
   - 都乐：甜度稍低，但更均衡，部分消费者会形容为“清甜”。

2. **软糯程度**：  
   - 佳农：果肉通常更软糯，熟透后细腻绵密，咬下去几乎没有纤维感。  
   - 都乐：质地相对紧实，即便完全成熟也能保持一定韧性，咀嚼时略带弹性。

3. **风味层次**：  
   - 佳农：甜味主导，香气浓郁但单一，类似传统“油蕉”的风味。  
   - 都乐：酸度略明显（尤其未完全熟透时），带有更复杂的果香，后味清爽。

4. **成熟速度与口感变化**：  
   - 佳农：从微青到全熟过渡较快，一旦表皮出现黑斑，甜度会大幅上升，但后期容易发软。  
   - 都乐：成熟过程更缓慢，可在较长时间内保持“适合即食”的硬度，不容易一下子变得过软。

**总结**：若偏好纯粹的高甜度和软糯口感，佳农更合适；若喜欢清甜、带一定脆度且风味更有层次，都乐可能更符合需求。你的消费者反馈“更甜”这一特点确实与佳农的产品特性吻合。
