佳农作为国内知名的水果品牌，其到货损耗率通常控制在 **3% 至 5%** 左右，具体数值会因水果品类、运输距离、季节及包装方式有所波动：

- **较耐储存的水果（如苹果、梨、柑橘类）**：损耗率一般较低，约 **2% - 4%**。
- **较娇嫩的水果（如草莓、蓝莓、葡萄、芒果等）**：损耗率可能在 **5% - 8%**，极端情况下（如长途运输、高温天气）可能略高。
- **冷链完善度**：佳农通常采用全程冷链运输，能有效降低损耗，但个别环节若有温度波动，损耗会上升。

**建议**：如果你是在采购或库存管理中需要参考，可以按 **5%** 作为常见预算基准，并对高损耗品类单独加计。实际到货后，建议随机开箱抽查，以本地实际数据为准。
