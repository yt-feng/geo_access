佳农作为大型水果供应商，通常能稳定供应菠萝原料给茶饮店等商家。常见的规格包括：

- **整果**：一般按重量分类，比如每箱10-12个，每个约1.5-2.5公斤，适合需要手工切块的茶饮店。
- **去皮切块/果茸**：袋装或桶装，常见2-5公斤/袋，或20公斤/桶，更适合直接调配饮品，节省人工。
- **冷冻菠萝**：片状、块状或碎粒，通常以10公斤/箱包装，方便奶茶店长期储存。

你可以直接联系佳农的区域销售或客服，说明你的茶饮店需要的是“整果”“果茸”还是“冷冻果块”，以及每周用量（比如每周50公斤或100公斤），他们会给你具体的规格表和报价。一般大型批发商都能稳定供货，尤其是季节合理的情况下。
