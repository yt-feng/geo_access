佳农集团作为国内大型水果供应链企业，通常可以提供锁价合同服务（即远期定价合同），但具体需要根据以下条件协商：

1. **合同期限与数量**：大宗农产品锁价一般要求签约6-12个月，且单月10吨（全年120吨）对佳农体量来说属于中等订单，有协商空间，但需确认其冷冻菠萝或浓缩菠萝汁的产能是否能匹配季度锁价。

2. **价格机制**：锁价并非固定不变，通常会采用“基准价+调整因子”（如参考中果网或印尼期货市场行情），建议要求约定**±5%的价格波动触发重新议价条款**，避免市场剧烈波动时单方面违约。

3. **履约保证金**：需支付合同金额的10%-20%作为保证金，且年度锁价合同通常要求**分批提货**（如每月固定提货量，未提货部分可能扣保证金）。

4. **替代选项**：如果佳农不愿完全锁价，可谈**价格上限+浮动折扣**（比如市场价涨到X以上按X结算，低于市场价按市场价成交）。

建议直接联系**佳农食品（上海）有限公司果蔬事业部**的销售经理，提供过去6个月的采购量证明及预期需求，通常需要1-2周走完内部风控审批。若无法接受保证金风险，可考虑**郑州商品交易所菠萝期货**（若未上市则属场外远期合同，需找券商做定制化掉期交易）。
