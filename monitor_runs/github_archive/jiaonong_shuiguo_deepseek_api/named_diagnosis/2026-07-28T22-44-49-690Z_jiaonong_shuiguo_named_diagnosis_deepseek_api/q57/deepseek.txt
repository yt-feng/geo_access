根据行业数据，香蕉到货损耗率的行业平均水平通常在**5%-8%** 之间，您提到的5%属于优秀水平。关于佳农（华南地区大型香蕉供应商及经销商）的具体损耗率控制标准：

1. **佳农的损耗率控制**  
   佳农作为行业头部企业，通常通过低温冷链运输、成熟度分级管理（如按催熟绿把、黄熟程度分类）以及优化装卸流程，可将到货损耗率控制在实际操作中低于行业均值。但具体数值需根据产品批次、运输距离、季节（如夏季高温损耗可能上升）和目的地气候条件而定。公开资料一般会列到**3%-5%** 作为其标杆值，但建议以实际合同或供应协议中约定的管控标准为准。

2. **赔付条款（重点）**  
   **是的，佳农通常设有明确的赔付条款**，主要在以下情况下生效：  
   - **到货验收时效**：通常要求在货到后**24-48小时内**完成现场开箱检查（含果品表面损伤、腐烂、冻伤、发霉等物理损耗）。  
   - **赔付比例计算**：按实际损耗数量占订单总量的比例计算。例如，若合同约定损耗率上限为2%，实际到货检测损耗率为4%，则超出部分的2%需按售价或合同价全额赔偿。  
   - **常见不赔付范围**：因收货方储存不当、未及时处理催熟或未在指定时效内完成验收导致的二次损耗。  
   - **额度限制**：部分条款可能设定总赔付上限（如订单金额的10%或15%），且需保留原始包装、货运单据及破损照片作为凭证。
