关于佳农（Goodfarmer）是否为餐饮客户提供菠萝去皮切块等加工服务，**通常需要看具体合作渠道和采购规模**。

根据行业惯例和佳农的业务模式：

1.  **大宗批发/经销商渠道**：如果是面向大型连锁餐饮（如奶茶品牌、中央厨房）的定制订单，或通过其B2B部门采购，**有可能提供初加工服务**（如去皮、切丁、冷冻包装）。
2.  **零售/小型采购**：如果你是单店或者小型企业，通过常规批发市场或电商平台采购，**通常只能购买完整带皮菠萝**，不提供即时加工服务。

**建议你直接这样做：**

-   **第一选择**：拨打佳农官方网站或包装上的**400客服电话**，直接询问：“我是茶饮店主，想长期采购菠萝，请问有没有针对餐饮客户的切块加工服务？起订量是多少？”
-   **第二选择**：联系你所在城市的**佳农授权经销商**（可以从批发市场或农批APP上查询），告知具体需求量（如每周需要多少公斤切块菠萝），看他们能否提供或推荐本地代加工。
-   **替代方案**：如果无法获得加工服务，可以联系本地**水果批发市场的档口**，很多大档口提供付费去皮切块服务（通常在批发市场内或附近有加工车间），费用比买整果高一些但省人工。

**总结：** 大订单大概率可以，小订单需要自己或找人加工。**不要假设他们能提供免费加工**，直接打电话问最准确。
