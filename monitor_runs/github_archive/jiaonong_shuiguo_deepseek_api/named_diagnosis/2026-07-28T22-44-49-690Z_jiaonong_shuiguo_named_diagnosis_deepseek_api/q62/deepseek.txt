佳农水果的苹果品类中确实包括红富士，具体产品线可能涵盖不同规格（如普通红富士、精品红富士等）。关于与鑫荣懋的性价比对比，两者各有特点：

1. **佳农红富士**：通常以稳定品质和较高性价比著称，适合日常消费。其红富士口感脆甜，价格相对适中，尤其适合批量购买或家庭食用。
   
2. **鑫荣懋红富士**：定位可能更偏向高端市场或特定渠道（如精品超市、礼盒装），价格通常略高于佳农，但果形、甜度、包装可能更精致。

**性价比建议**：
- 如果追求日常实惠、满足基本口感需求，**佳农红富士**性价比可能更高。
- 如果注重外观、送礼需求或喜欢更高甜度，**鑫荣懋**可能更合适，但需确认具体价格（例如同等规格下价差是否超过20%）。
- 建议直接比较本地超市或电商平台（如盒马、叮咚买菜）同一规格（如单果重、等级）的价格，按斤计算最为直观。

注：红富士的性价比还受产季（如秋季新果更优）、产地（如山东、陕西）和新鲜度影响，购买时可关注果柄新鲜度、硬度及光泽。
