1. **产地判断**
- 佳农苹果通常不止一个供货产区，具体批次可能来自山东、陕西、甘肃等苹果主产区，也可能有进口苹果线。**不能按品牌一概而论，要以你采购批次的包装箱/标签上的“产地”“加工厂/包装厂注册号”为准。**
- 生鲜电商溯源要求下，应让供应商提供**该批次**的供货证明：产地证明、包装厂信息、采摘/加工日期、批次号。

2. **GAP认证核验**
- 要求供应商提供**GAP证书扫描件**，重点看：证书持有人是否与供货主体一致、认证范围是否覆盖“苹果”、认证基地地址是否与你采购批次产地一致、证书是否在有效期内。
- 国内常见为**China GAP（中国良好农业规范）**，国际为**GLOBALG.A.P.**。二者不是一回事，平台若要求GAP，需明确接受哪种。
- 可在认证机构或发证机构渠道核验证书编号；仅凭供应商口头说明或品牌宣传页不够。

3. **给供应商的溯源清单**
可要求其提供：
- 批次号及对应产地
- 包装厂/合作社名称与地址
- GAP证书编号、发证机构、有效期、覆盖品类和基地
- 检测报告（农残）
- 进货发票/合同与批次对应关系
