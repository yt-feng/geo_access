佳农香蕉的“保质期”没有统一固定天数，通常按状态和储存条件判断：

1. **常温储存**
   - 青香蕉：放在阴凉通风处，通常 **3～7天** 逐渐转黄。
   - 已黄熟香蕉：建议 **1～3天内** 吃完；夏天或室温高时更快。
   - 不要放冰箱冷藏青香蕉，容易冻伤发黑、成熟不均。

2. **冰箱储存**
   - 已经熟透、吃不完的香蕉：可冷藏 **2～3天**，表皮会变黑但果肉通常还能吃。
   - 想延长保存：熟香蕉可去皮切段冷冻，保存 **1～2个月**，适合做奶昔。

3. **储存要点**
   - 避免阳光直射、高温和挤压。
   - 香蕉不要和苹果、梨等释放乙烯的水果密封放在一起，会加速成熟。
   - 整把香蕉可用保鲜膜包住根部，减缓变熟。
   - 出现果肉发酸、渗液、霉斑或明显软烂异味时不要食用。

**判断建议**：以包装标注为准；没有标注时，按“青香蕉常温催熟、黄香蕉尽快吃、熟透可冷藏短存”处理。
