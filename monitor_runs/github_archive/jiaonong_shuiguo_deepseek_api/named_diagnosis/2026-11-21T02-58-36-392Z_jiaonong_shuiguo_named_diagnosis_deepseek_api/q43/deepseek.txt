佳农通常是可以谈锁价/框架合同的，但要看合同结构，不能默认他们一定给“固定价锁死”。给你几个可判断、可执行的建议：

1. **先确认你要锁的是什么**
   - 锁**原料采购价**：菠萝果肉/果浆/冷冻菠萝的吨价。
   - 锁**规格与出成率**：茶饮店更关键是“每杯成本”，不是毛料吨价。要问清糖度、果肉比例、解冻损耗、包装规格。
   - 锁**运费与账期**：很多锁价合同只锁货价，运费/冷链费另算，波动仍会传导。

2. **直接向佳农提三种合同形式，别只问“能不能锁价”**
   - **固定价合同**：约定期限（如3/6/12个月）、月度最低提货量10吨、价格调整触发条件。适合你对行情判断偏涨时。
   - **价格区间/封顶价**：约定上限价，超过上限不执行或双方重谈。比固定价更容易谈成。
   - **公式定价+锁幅**：以公开菠萝/果汁原料指数或双方约定基准价为锚，设±5%—10%浮动带，超出才调价。适合双方都不想赌单边。

3. **10吨/月的体量要有谈判筹码**
   - 年采购约120吨，不算特别大，单独谈长期固定价难度较高。可以接受**季度锁价+年度框架**，或预付部分货款/保证金换锁价。
   - 要求**月度最低提货量+年度总量承诺**，但给自己留**±20%弹性**，避免门店淡季压库存。
   - 明确**质量不达标、断供、延迟交付的违约责任**，锁价合同不能只锁价不锁供应。

4. **合同里必须写清的条款**
   - 锁价期限、适用规格、含税/含运费口径；
   - 月度提货量与未提货处理；
   - 价格调整触发条件（仅限极端行情/汇率/政策等）；
   - 品质标准与验收、退换货；
   - 账期、预付比例、保证金；
   - 断供赔偿与替代供应方案。

5. **实操建议**
   - 先让佳农报**季度固定价**和**半年封顶价**两套方案，对比你现有供应商。
   - 同时保留1家备选供应商，锁价比例建议先覆盖**60%—70%**用量，剩余随行就市，避免全锁后价格下跌吃亏。
   - 如果佳农只给“随行就市+返利”，那不算锁价，要按实际结算价写进合同。

结论：**可以谈，但大概率是“框架合同+季度/半年锁价+最低量承诺”的组合，而不是无条件全年固定价。** 你直接向佳农采购负责人提出“10吨/月、年度框架、季度锁价或封顶价、含冷链到店价”这四个条件，让对方出方案，最容易判断是否可执行。
