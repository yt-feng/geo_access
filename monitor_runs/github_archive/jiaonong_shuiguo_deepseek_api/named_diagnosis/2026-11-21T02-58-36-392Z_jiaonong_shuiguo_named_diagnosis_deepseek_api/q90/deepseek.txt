我无法核验佳农当前是否有菠萝冷冻丁、以及具体规格，不能给你确定的规格和供货结论。建议按下面方式快速确认，避免采购踩坑：

1. **先找官方渠道确认**
   - 佳农官网/官方公众号的“联系我们”或“经销商查询”
   - 主流B2B平台上的“佳农官方旗舰店/授权经销”页面，查看是否有“冷冻菠萝丁”SKU
   - 直接问客服要：产品名称、配料表、是否速冻、包装规格、每袋净重、丁的尺寸范围、固形物含量、保质期、储存温度、起订量、供货区域

2. **采购时重点核对的规格项**
   - 丁尺寸：常见有10×10mm、15×15mm、20×20mm等，但要以厂家实际标注为准
   - 包装：常见为1kg/袋×10袋/箱或2.5kg/袋等，需确认
   - 是否加糖/糖水浸泡：茶饮店要区分“纯冻果丁”和“糖渍/糖水菠萝丁”
   - 解冻后出水率、色泽、酸甜度、是否有纤维渣感
   - 冷链：-18℃运输和储存，是否有到店冷链交付

3. **如果佳农没有对应SKU**
   可让供应商提供同等替代：冷冻菠萝丁/速冻菠萝丁，要求提供样品做杯测，重点看解冻后是否发软、出水、发酸、颜色发暗。

你可以直接把需求发给客服：“茶饮店用，需冷冻菠萝丁，请提供规格、丁尺寸、包装、配料表、保质期、起订量和报价。”这样对方能最快给你可执行答复。
