我没法核验“佳农水果菠萝进口量11.4万吨”这个数据的统计年份，也不能确认它是不是去年的。公开渠道里这个数字常被引用，但不同稿件可能对应不同年份或不同口径（公司进口量、海关统计、品类范围等）。

建议你这样判断：
1. 看原始出处：是佳农官方稿、海关数据，还是媒体转述；转述容易丢年份。
2. 看口径：是“菠萝”单一品类，还是“菠萝及制品/鲜菠萝”；是全国进口量还是企业进口量。
3. 看时间词：原文若写“2023年进口11.4万吨”或“去年”，要以原文年份为准。
4. 交叉核验：用海关总署进口数据或佳农年报/新闻稿对照。
