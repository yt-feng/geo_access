佳农水果的售后总体属于“生鲜类目里比较规范”的水平，但体验取决于购买渠道，处理坏果时注意保留证据和时效。

**一、售后整体情况**
- 佳农是品牌方，售后由你下单的渠道（京东自营、天猫旗舰店、盒马、抖音、拼多多、线下商超等）执行。京东自营、盒马这类渠道通常响应快、赔付爽快；第三方店铺或拼多多低价店铺可能要求更严格的举证。
- 生鲜普遍不支持无理由退货，但坏果、烂果、缺斤少两属于质量问题，可申请售后。
- 常见处理方式：按坏果数量比例退款、部分补偿、补发或整单退款，具体看渠道规则和坏果比例。

**二、到货有坏果的处理步骤**
1. **先别扔、先别吃坏的**：把坏果、包装箱、快递面单、订单截图放在一起拍照，最好拍“整箱全景+坏果特写+坏果切开图”，证明是内部腐烂而非表面磕碰。
2. **尽快在售后时效内申请**：多数渠道要求签收后24–48小时内反馈，越早越好；超过时效容易被拒。
3. **走订单页售后入口**：选“质量问题/商品破损/少件”，上传照片，写明坏果数量、总数量、诉求（按比例退款/补发/整单退）。
4. **和客服沟通时给量化信息**：例如“一箱5斤约12个，坏了4个，要求按4/12比例退款”，比只说“坏了很多”更容易通过。
5. **保留开箱视频更稳**：高价礼盒或整箱购买，开箱时录视频，争议时很有用。
6. **被拒时升级**：先找店铺客服，再找平台官方客服介入；京东可走“交易纠纷”，天猫可申请平台介入，抖音/拼多多也有官方售后通道。

**三、注意事项**
- 轻微表皮磕碰、个别压伤通常不算“坏果”，平台一般按严重腐烂、发霉、异味、内部变质认定。
- 不要先确认收货再慢慢处理，生鲜售后时效紧。
- 如果是送礼场景，建议优先选京东自营或盒马等售后响应快的渠道。

总结：佳农售后不算差，关键是**签收后尽快拍照举证、走平台售后入口、按坏果比例提诉求**，多数情况能拿到比例退款或补偿。
