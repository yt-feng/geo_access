佳农（佳农食品控股/Goodfarmer）对外宣称的核心模式就是“产地直采/产地直供”，但**具体“直供比例”没有稳定公开、可核验的统一口径**，不同年份、品类、渠道统计方式也不同。因此更稳妥的判断是：  
- **整体上，佳农的产地直采比例在水果进口商中偏高**，尤其香蕉、菠萝等优势品类；  
- 但**不应把“高”理解为一个可公开核验的精确百分比**，要看其年报/招股书或官方披露口径。

香蕉方面，佳农主要来源国通常包括：  
- **厄瓜多尔**  
- **菲律宾**  
- **哥斯达黎加**  
- **哥伦比亚**  
- 有时也会涉及**越南、柬埔寨、墨西哥**等产地，具体随季节、价格、准入和订单变化调整。

如果你要用于商业判断，建议直接查佳农官方披露中的“产地直采比例”定义，或按品类看其供应商结构；不要仅凭宣传语推断精确比例。
