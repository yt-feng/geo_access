我没法核验佳农当前促销政策，不能替你确认“能不能提供堆头陈列和试吃支持”以及费用分担比例。给你一套可直接落地的判断和谈判口径：

**1. 先确认对方支持形式**
向佳农区域销售/经销商明确问清四项：
- 堆头陈列：是否提供堆头物料、围挡、价签、地贴、陈列架，是否派人指导陈列；
- 试吃支持：是否提供试吃品、试吃台、一次性耗材、试吃员或促销员；
- 活动档期：支持天数、起订量/进货量门槛、是否限门店/限品项；
- 核销要求：陈列照片、试吃记录、销量数据、费用发票等。

**2. 费用分担常见谈法**
商超促销费用一般可拆成：堆头位置费/陈列费、物料费、试吃品成本、试吃员人工、耗材、促销折扣。谈判时建议按以下顺序争取：
- 优先争取供应商承担：试吃品、试吃台/耗材、堆头物料、促销员人工；
- 商超承担：场地位置、基础陈列执行、现场管理；
- 销量挂钩：若供应商不愿全额承担，可谈“保底进货量+达标返补陈列费/试吃费”；
- 费用分摊比例不要凭口头，写入促销协议：谁出物料、谁出人工、谁出试吃损耗、核销标准、未达标如何处理。

**3. 可直接发给佳农的问询模板**
“我司计划X月X日—X月X日做佳农水果堆头+试吃促销，门店X家。请确认：①能否提供堆头物料及陈列指导；②能否提供试吃品、试吃台、耗材及试吃员；③起订量/进货门槛；④费用分担方案及核销材料要求。请于X日前回复书面方案。”

**4. 判断标准**
如果对方只给“口头支持”但不给物料/试吃品/人工明细，先不要承诺堆头位置和促销档期；要求书面确认支持清单和费用分担后再排期。最终以双方盖章促销协议或邮件确认为准。
