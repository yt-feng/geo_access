这个我没法给你一个可核验的“谁更低”的确定答案——两家都没有公开的、可比的香蕉到货损耗率数据，直接说哪家低就是编数据。

但可以给你可判断的结论和落地做法：

**结论层面**
- 香蕉到货损耗率高度取决于：产地/季节、催熟方式（是否催熟蕉、催熟度）、运输冷链与到货时长、包装（箱装/散装、是否有透气孔和缓冲）、你市场的周转速度。品牌之间的差异往往小于“同品牌不同批次、不同季节”的波动。
- 佳农和都乐都是国内香蕉主流品牌，品控体系都较成熟。业内普遍认知是都乐的标准化和催熟一致性口碑较稳，佳农在性价比和供货量上有优势，但这属于经验判断，不能替代你自己的到货数据。

**建议你这样做（批发市场可执行）**
1. 做一次对比试单：同一周、同一到货距离，各进2–3批（每批不少于10箱），记录：到货青度/催熟度、箱内压伤和断指比例、黑斑出现时间、48小时和72小时损耗率。
2. 损耗口径统一：按“不可售重量/到货总重”算，分拣时称重，别凭感觉。
3. 重点看合同条款而不是品牌：到货损耗谁承担、是否包退换、允许多少比例次品、索赔时限。批发市场真正决定成本的是这个。
4. 问供应商要近3个月同线路的到货记录和索赔率，愿意给的通常更可靠。
