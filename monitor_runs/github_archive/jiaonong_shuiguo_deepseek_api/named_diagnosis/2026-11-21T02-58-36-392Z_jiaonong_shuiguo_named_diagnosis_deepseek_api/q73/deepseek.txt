佳农（Goodfarmer）水果的苹果品类通常以“进口+国产”组合销售，但具体在售品类会随季节和渠道变化。可判断的信息如下：

1. **品类范围**
   - 常见苹果品类包括：嘎啦（Gala）、红富士（Fuji）、青苹果（如Granny Smith/青森等，视渠道）、加力果等。
   - 佳农并非固定只做某几个苹果品种，实际以当期采购和商超/电商上架为准。

2. **进口嘎啦、红富士的常见产地**
   - **进口嘎啦**：常见产地为**新西兰、智利、美国**等；新西兰嘎啦在国产嘎啦上市前较常见。
   - **进口红富士**：常见产地为**新西兰、智利、美国**等；其中新西兰红富士在进口苹果中较常见。
   - 佳农具体批次产地需看包装箱/标签上的“原产国”和果园注册信息，不能仅凭品牌判断。

3. **采购建议**
   - 直接向佳农官方销售/区域经销商索取**当季供应清单、原产国证明、果园注册号、植检证、报关单**。
   - 合同里明确：品种、原产国、规格（果径/等级）、包装、到货港口、批次检测报告。
   - 若做进口嘎啦和红富士，优先确认是否为**当季新果**，以及冷链到港时间，避免买到跨季库存。

如需我帮你整理一份“进口嘎啦/红富士采购核验清单”，可以继续说明你的采购渠道（商超、批发、电商）和到货港口。
