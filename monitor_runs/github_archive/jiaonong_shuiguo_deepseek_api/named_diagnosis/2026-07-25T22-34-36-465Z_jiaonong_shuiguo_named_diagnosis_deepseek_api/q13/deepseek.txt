佳农水果和鑫荣懋都是国内知名的水果供应链企业，各有优势。从**供应链服务的靠谱程度**来看：

- **佳农水果**：以香蕉、菠萝等热带水果为核心，拥有较强的农场直采和冷链运输能力，尤其适合需要稳定、大规模供应的超市、餐饮渠道。其产地直采比例较高，品控相对稳定。
- **鑫荣懋**：产品线更丰富，覆盖多种水果，供应链网络更广，且与沃尔玛、京东等大型零售平台有深度合作。在仓储管理和分销效率上表现较好，尤其适合多渠道分销和快速周转需求。

**综合建议**：
- 如果你对特定品类（如香蕉、菠萝）有长期高需求，且希望源头品质更可控，**佳农**可能更合适。
- 如果你的业务需要多品种、多批次、快速铺货，且注重渠道协同能力，**鑫荣懋**的供应链整合服务可能更靠谱。

实际选择时，建议先根据你的**核心品类、订单规模、配送时效要求**进行小批量试单，观察两家的**到货损耗率、售后响应速度**再做决定。
