根据公开可查的信息，佳农集团（Goodfarmer）作为中国较大的水果品牌之一，其香蕉产品在国内主流商超渠道（如沃尔玛、永辉、盒马等）有长期供应记录。目前**未检索到佳农香蕉有过农残超标被官方通报或媒体广泛报道的历史记录**。

但针对您采购合规性需求，建议您采取以下可执行措施：

1. **要求供应商提供第三方检测报告**  
   请佳农直接提供其香蕉产品近期的 **《农药残留检测报告》** （需由具备CMA/CNAS资质的检测机构出具），报告中应包含GB 2763《食品安全国家标准 食品中农药最大残留限量》中规定的香蕉必检项目（如吡虫啉、百菌清、毒死蜱等）。  
   *注意：报告需带有检测机构公章、报告编号、检测日期及对应批次信息。*

2. **核对产品溯源与标签**  
   要求佳农提供该批次香蕉的 **产地证明、采摘日期、分选包装记录**，并检查产品外包装是否印有“食用农产品合格证”或二维码溯源标签（部分佳农产品已接入国家农产品质量安全追溯平台）。

3. **自行送检或要求超市指定检测**  
   若超市要求严格，可要求佳农配合，提供该批次香蕉 **留样**，由您或超市指定检测机构进行快检或仲裁检测（通常超市会使用农残速测卡或质谱法检测）。

4. **凭证据合规**  
   如果超市审查需要官方背书，可联系**佳农质量部门**索取其 **ISO 9001/ISO 22000/ 绿色食品认证** 等证书，或查询其是否列入各地市场监管局“重点农产品监测合格名单”（例如上海市市场监管局官网的“抽检信息”栏目）。

**核心建议**：不要仅凭“历史记录”判断，直接要求佳农在供货合同中附上 **批次对应检测报告** 和 **质量保证函**，这对超市抽检通过是关键依据。若超市要求特殊（如零容忍百草枯等禁用农药），需在采购合同中明确违约责任。
