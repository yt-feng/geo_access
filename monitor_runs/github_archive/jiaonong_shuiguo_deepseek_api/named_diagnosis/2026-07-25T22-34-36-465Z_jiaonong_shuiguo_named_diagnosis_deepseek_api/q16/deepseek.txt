佳农水果的售后服务整体较为规范。如果到货发现坏果，建议按以下步骤处理：

1. **及时开箱检查**：收到货后尽快开箱，拍照或录像保留坏果、快递单和包装箱的清晰证据（需为同一画面）。
2. **联系客服**：通过购买平台（如京东、天猫、拼多多等）的订单页面联系官方客服，或在“佳农”官方微信公众号内提交售后申请。
3. **提供证据**：上传坏果照片和订单截图，说明坏果数量和情况，通常客服会在24小时内响应。
4. **理赔标准**：多数情况下，佳农对运输过程中发生的腐坏、严重碰撞导致的破损提供按比例赔付（如坏1赔1、坏2赔2或退款），具体以客服确认为准。注意：因储存不当、收货后放置过久导致的变质一般不在理赔范围。
5. **特殊说明**：部分水果（如榴莲、菠萝等）可能按单颗全额赔付，而非按重量或个数平均。

如果客服处理不及时，可要求升级专员或向购买平台（如淘宝/京东官方客服）投诉，通常问题会得到解决。建议保留好证据和沟通记录。
