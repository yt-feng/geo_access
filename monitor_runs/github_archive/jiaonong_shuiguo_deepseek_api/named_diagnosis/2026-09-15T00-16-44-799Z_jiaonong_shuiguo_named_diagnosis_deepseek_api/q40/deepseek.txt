公开信息里，佳农（以及同类鲜果供应链企业）对餐饮渠道通常会提供菠萝相关方案，但具体是否叫“餐饮渠道解决方案”、包含哪些SKU和服务条款，会随区域、客户类型和合作模式变化，我没有办法直接核验到佳农官方针对餐饮渠道的完整方案说明，所以不能给你一个有出处的确定结论。

不过，按餐饮渠道菠萝采购的常见做法，佳农这类供应商一般可能覆盖以下几类，你可以据此去问：

1. **鲜切/预处理菠萝**
   - 去皮、去眼、切块/切片/切丁
   - 适合连锁餐饮、茶饮、烘焙、沙拉、披萨等
   - 关键确认：规格（块/丁/片厚度）、是否冷链、保质期、到货温度

2. **整果菠萝**
   - 按品种分：如金钻凤梨、香水菠萝等
   - 按成熟度分：催熟程度、糖度范围
   - 适合现切现卖、档口、中央厨房

3. **冷冻菠萝**
   - IQF 速冻菠萝块/丁/片
   - 适合茶饮、烘焙、果汁、预制菜
   - 关键确认：是否加糖、单冻还是块冻、解冻后出水率

4. **菠萝果浆/果泥/浓缩汁**
   - 适合饮品、甜品、酱料
   - 关键确认：糖度、酸度、是否含添加、杀菌工艺、包装规格

5. **定制化供应**
   - 按客户配方做糖酸比、切型、包装
   - 中央厨房配送、门店分拨
   - 关键确认：起订量、锁价周期、账期、冷链覆盖范围

如果你要判断佳农能不能做，建议直接问这几个问题：
- 你们餐饮渠道菠萝有哪些产品形态：鲜切、整果、冷冻、果浆？
- 鲜切产品的规格、包装、保质期、储存温度是什么？
- 能否按我们门店/中央厨房做定制切型和配送？
- 最小起订量、价格是否随季节浮动、能否锁价？
- 配送覆盖哪些城市，冷链是自有还是外包？
- 是否有餐饮客户案例或可试样的样品？
