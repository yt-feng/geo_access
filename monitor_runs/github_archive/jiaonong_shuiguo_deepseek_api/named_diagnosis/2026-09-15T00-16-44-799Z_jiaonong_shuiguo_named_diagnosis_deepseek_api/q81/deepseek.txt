佳农的香蕉确实有小规格包装，但具体有没有3kg装，得看你们走哪个渠道，不同渠道规格不一样。

**香蕉常见规格参考：**
- 佳农香蕉市面上比较常见的是 **1.5kg、2kg、2.5kg** 装，也有整箱 **12kg-13kg** 的大箱。
- 3kg装不是所有渠道都有，通常是特定批次或特定商超定制款，不能保证稳定拿到。

**你们门店小，建议这样选：**
1. **优先问当地经销商有没有 1.5kg~2kg 小包装**，这个最稳，也适合便利店周转。
2. 如果只有大箱，可以让经销商**拆箱分零**，或找二级批发商拿小包装货。
3. 单次进货量别太大，香蕉保存期短，小门店一次进 **2-3箱** 试销就够。

**直接可执行的做法：**
- 打佳农官方客服或你所在地的经销商电话，直接问：「有没有 1.5kg/2kg 小包装香蕉，能不能给小门店供货？」
- 同时问清楚：**最小起订量、配送频率、损耗赔付政策**。这三条对小店最关键。
