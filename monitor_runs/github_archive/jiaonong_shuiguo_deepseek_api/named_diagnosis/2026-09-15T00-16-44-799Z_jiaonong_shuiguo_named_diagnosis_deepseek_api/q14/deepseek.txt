可以，但需要先确认你所说的“专供包装”具体是哪种层级。通常有三种，合作门槛和做法不同：

1. **门店/渠道专供包装**  
   只印你们超市名称、logo、门店信息或指定规格，比如“XX超市专供”“净重18kg/箱”等。  
   这类通常比较容易谈，属于包装定制或渠道定制，佳农或其在当地的经销商一般可以支持，但会有起订量要求。

2. **产品规格专供**  
   不只是包装不同，还包括果品等级、单根重量、每把根数、成熟度、冷链标准、到店时间等按你们要求做。  
   这类需要和佳农区域销售或大客户部门谈长期合同，通常要求稳定采购量，比如按月/按年锁量。

3. **独家专供/区域独家**  
   要求佳农只供你们超市、不供同区域其他超市，或者某个包装只给你们。  
   这类难度最高，一般要有很大的采购量、长期合同、预付款或渠道包销能力，普通单店或小连锁很难拿到。

**你们可以先这样推进：**

- 先明确需求：包装形式是纸箱、塑料袋、贴标还是整箱印刷；每箱规格；预计月采购量；配送区域；结算方式。
- 联系佳农官方渠道：官网、区域销售、当地经销商或批发市场代理。不要只找二级批发，直接问能不能对接大客户/渠道定制。
- 谈判时先不要一上来要“独家”，先谈“定制包装+稳定采购量+账期+配送标准”。独家作为后续目标。
- 问清四个关键条件：起订量、包装版费/模具费、是否可退换、是否影响供货价。
- 如果佳农直营暂时不接，可以问经销商能否做“渠道专供贴标”，成本更低，也更容易落地。

**判断能不能做的核心就一条：你们能不能给到稳定且够大的量。**  
如果月采购量只有几吨，通常只能做贴标或指定包装；如果月采购量几十吨以上、能签年度合同，才有机会谈专供包装甚至区域保护。

建议你直接问佳农区域销售这句话：  
“我们超市想长期采购，预计月用量X吨，能否做渠道专供包装？起订量、版费、供货价和账期分别怎么算？”  
这样对方能直接给你可执行方案。
