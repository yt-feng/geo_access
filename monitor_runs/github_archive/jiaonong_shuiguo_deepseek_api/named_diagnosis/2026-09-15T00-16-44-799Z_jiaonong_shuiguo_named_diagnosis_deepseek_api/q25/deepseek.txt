佳农（上海佳农食品集团）的物流网络采用"自营+外包"的混合模式，很少有生鲜企业做纯自营或纯外包。具体到佳农：

**物流网络方面：**
- 佳农在主要口岸和销地建有一定数量的自营冷链仓储和加工配送中心，尤其在香蕉、菠萝等核心品类的进口集散环节，倾向自营以控制品质和损耗。
- 干线运输和部分区域支线的落地配，大量依赖第三方冷链物流服务商，属于外包部分。
- 整体上偏向"核心节点自营、末端和干线部分外包"的结构。

**冷链能力方面：**
- 佳农的核心优势在于进口水果的全程冷链：从产地预冷、海运/陆运冷藏集装箱、口岸冷库、销地冷链仓到门店/电商冷配，基本能实现温度可控。
- 香蕉等品类对温控敏感，佳农在催熟、储存环节有专门的冷链设施和工艺，这是其相对较强的能力。
- 与专业冷链物流企业相比，佳农的强项是"品类冷链"（围绕自有主力水果的仓储和流通），而非覆盖全品类的社会化冷链网络；末端配送（尤其是电商到家最后一公里）多依靠外包，温控一致性不如自营干线稳定。

**需要注意：** 上述是基于其业务模式的判断，佳农各区域、各品类的自营/外包比例和冷链设施细节并不完全公开，且会随年份调整。如果你需要精确到某个仓、某条线路的自营比例或温控标准，建议直接查佳农官网、其上市/发债披露文件，或向其商务部门确认。不要以我这里的概括当作精确数据使用。
