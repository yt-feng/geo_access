佳农（佳农食品控股/Goodfarmer）公开资料中通常不会披露一个统一的“产地直供比例”数字，因为这类比例会随品类、季节、产地和客户类型变化很大。我无法核验到一个可引用的官方统一比例，所以不建议把它当作谈判或决策的硬指标。

对采购来说，更实际的做法是：

1. **按品类分别要数据**
   - 香蕉、菠萝、火龙果、苹果、柑橘等，直供比例差异很大。
   - 要求供应商提供：产地、加工/包装环节、是否经第三方贸易商、物流路径。

2. **看“直供”的定义**
   - 是自有基地直供？
   - 还是产地合作社/包销基地直供？
   - 还是仅由产地仓发货，但中间仍有贸易商？
   这三种成本结构完全不同。

3. **要求报价拆解**
   让对方把报价拆成：采购价、分选包装、冷链仓储、干线运输、损耗、关税/税费、服务费。
   这样能判断中间环节到底在哪，而不是只问一个笼统比例。

4. **用试单验证**
   选1-2个单品做小批量试单，对比：
   - 到岸/到仓成本
   - 损耗率
   - 规格达标率
   - 交付准时率
   再决定是否扩大合作。

5. **谈判方向**
   - 要求指定产地/包装厂
   - 要求可追溯批次
   - 约定直发比例或产地仓发货比例
   - 把“减少中间环节”写进合同附件，而不是只听口头承诺
