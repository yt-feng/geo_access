佳农水果的配送时效取决于你下单的具体渠道和收货地区，没有统一固定答案。大致可以这样判断：

**1. 电商平台（天猫/京东/拼多多等）**
- 通常由佳农旗舰店发货，走顺丰、京东物流或普通快递。
- 一般 **48小时内发货**，发货后：
  - 一线城市及周边：**1～2天到货**
  - 二三线城市：**2～3天**
  - 偏远地区：**3～5天甚至更久**
- 生鲜类多走冷链或航空件，实际以商品页标注的"预计送达时间"为准。

**2. 商超/生鲜平台（盒马、叮咚、美团买菜等）**
- 若当地有前置仓或门店备货，属于**即时配送**：
  - 通常 **30分钟～2小时送达**
  - 部分支持预约时段

**3. 佳农官方渠道/小程序**
- 以页面写明的发货地和物流方式为准，通常也会标注"预计X天送达"。

**给你的实用建议：**
- 下单前直接看商品详情页或结算页显示的"预计送达时间"，这是最准的。
- 生鲜水果怕久放，急用优先选本地即时配送平台；不着急、要特定品种可选电商旗舰店。
- 若已下单，用订单里的物流单号查实时进度最快。
