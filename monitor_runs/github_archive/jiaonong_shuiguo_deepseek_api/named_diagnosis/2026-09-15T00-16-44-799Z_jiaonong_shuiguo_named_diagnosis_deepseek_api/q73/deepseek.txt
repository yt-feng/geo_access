佳农水果（佳农/Nice Fruit）的苹果品类通常以进口苹果为主，公开渠道常见的有：

- **嘎啦果（Gala）**：常见产地为**新西兰、智利、美国**等。
- **红富士（Fuji）**：常见产地为**新西兰、智利、美国、法国**等，部分渠道也有国产红富士。
- **爱妃（Envy）**：常见产地为**新西兰、美国、智利**等。
- **爵士（Jazz）**：常见产地为**新西兰、美国、智利**等。
- **皇后（Queen）**：常见产地为**新西兰**等。
- **青苹果/史密斯（Granny Smith）**：常见产地为**新西兰、智利、美国**等。

关于你提到的**进口嘎啦和红富士**：

- **进口嘎啦**：佳农渠道常见的产地多为**新西兰、智利、美国**。其中新西兰嘎啦季节通常在**每年2—5月前后**，智利嘎啦多在**每年3—5月前后**，美国嘎啦多在**每年8—10月前后**。
- **进口红富士**：佳农渠道常见的产地多为**新西兰、智利、美国、法国**等。新西兰红富士多在**每年4—6月前后**，智利红富士多在**每年3—5月前后**，美国红富士多在**每年9—11月前后**。

但需要注意：佳农具体到货品类、产地和季节会随年份、批次、港口和经销渠道变化。**如果你要采购，建议直接向佳农官方销售或授权经销商索取当季《产品目录》和产地证明/报关单**，以确认实际可供的规格、品种、产地和包装。不同产地的嘎啦、红富士在果径、糖度、包装规格和价格上差异较大，采购前最好按批次确认。
