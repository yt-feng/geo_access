佳农水果的物流体系并非单一模式，而是**自有冷链车队 + 第三方冷链物流 + 普通快递**并存的混合结构，具体取决于渠道和产品类型：

**1. 物流模式**
- **自有/合作冷链车队**：佳农在主要港口城市和区域配送中心之间，以及向大型商超（如盒马、永辉、沃尔玛）、批发市场的大宗配送，主要使用自有或长期合作的冷藏车队，这是其冷链主干。
- **第三方冷链**：部分区域配送会外包给专业冷链物流公司（如顺丰冷运、京东冷链等），而非三通一达。
- **三通一达/普通快递**：主要用于电商零售端（如天猫、京东、拼多多店铺）的**常温或短保耐储产品**（如部分进口香蕉催熟后、苹果、橙子等），以及非冷链需求的订单。生鲜易腐品一般不走三通一达。

**2. 冷链覆盖率**
佳农官方未公开精确的冷链覆盖率数字。根据其公开资料和行业报道：
- 核心品类（如进口香蕉、车厘子、蓝莓等高端水果）从产地到区域仓基本实现**全程冷链**。
- 区域仓到终端门店的大宗配送冷链覆盖较高。
- 但**最后一公里到消费者**环节，冷链覆盖率明显下降，取决于购买渠道——商超自提/门店购买冷链有保障，电商快递到家则常为常温或简易保温箱，并非严格冷链。

**总结**：三通一达只是其电商末端的一种配送方式，不是主力；冷链覆盖率在B端和干线环节较高，C端到家环节较弱。如需精确数据，建议直接咨询佳农官方或查阅其IPO/年报披露（如有）。
