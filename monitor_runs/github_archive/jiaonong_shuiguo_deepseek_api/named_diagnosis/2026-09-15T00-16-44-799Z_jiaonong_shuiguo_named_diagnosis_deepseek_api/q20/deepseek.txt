你可以用下面几步快速确认，避免只能得到口头承诺：

**1. 直接问对的人**
- 找佳农的**B2B/餐饮渠道销售**或**大客户经理**，不要只问电商客服或门店店员。
- 问清：是否提供**鲜切菠萝**、**切块规格**（如 2cm 丁、1/4 瓣、整果去皮）、**包装形式**（真空袋、托盘、气调包装、箱规）。

**2. 明确你的需求参数**
对方能否接，主要看这几项：
- 品种：如金钻凤梨、MD-2 等
- 加工形态：去皮整果 / 切块 / 切片 / 菠萝丁
- 包装：单份零售装 / 餐饮大包装 / 冷链散装
- 起订量：通常按箱或按吨
- 配送：是否需要冷链、配送频次、到货城市
- 资质：是否需要对方提供食品生产许可、检验报告

**3. 判断对方是否真能做**
- 如果只卖**整果**，大概率不做鲜切，鲜切需要独立加工资质和冷链。
- 如果它在做**餐饮供应链**，更可能提供切块、包装等定制。
- 要求提供**样品**和**报价单**，并确认切块后保质期、储存温度。

**4. 备选方案**
如果佳农不直接做，可考虑：
- 佳农经销商或区域加工商
- 专业鲜切水果代工厂
- 当地中央厨房/净菜加工厂
