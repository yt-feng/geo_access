关于佳农水果香蕉的具体在售规格和渠道分级标准，公开渠道能核验到的信息有限，我无法给出精确、完整的官方清单。可以确定的是：佳农（Goodfarmer）的香蕉业务通常按**单根重量/整箱净重**和**外观等级**两个维度做规格划分，渠道分级也主要围绕这两个维度展开。下面给出行业通行做法和可执行的判断框架，具体数值请以佳农官方或对接业务员的最新报价单为准。

**一、常见规格划分维度**

1. **按单根重量（条重）分级**
   - 小条：约 90–120g/根
   - 中条：约 120–150g/根
   - 大条：约 150–180g/根
   - 特大条：180g 以上
   这是香蕉最核心的分级依据，直接决定整箱重量和终端售价带。

2. **按整箱净重**
   - 常见有 10kg、12kg、13kg、15kg、18kg、20kg 等箱规，不同产地（菲律宾、厄瓜多尔、越南、国产）和不同季节会有差异。

3. **按外观等级**
   - 特级/一级：果形端正、无黑斑、无机械伤、色泽均匀
   - 二级：允许轻微瑕疵，不影响食用
   - 三级/加工级：外观瑕疵较多，用于加工或特价渠道

**二、不同渠道的分级标准（通行逻辑）**

| 渠道 | 通常匹配等级 | 核心要求 |
|---|---|---|
| 高端商超/精品水果店 | 特级、一级，中条到大条 | 果形一致、无斑、码放整齐、外观卖相优先 |
| 普通商超/社区生鲜 | 一级、二级，中条为主 | 性价比与卖相平衡，允许轻微瑕疵 |
| 电商/社区团购 | 一级/二级，规格标准化 | 单根重量稳定、箱规统一，便于履约和售后 |
| 批发市场 | 二级、三级，规格宽松 | 价格优先，走量为主，外观要求较低 |
| 餐饮/加工/果汁 | 三级、加工级 | 只要求成熟度和出肉率，不看外观 |
| 出口/高端礼盒 | 特级，大条或特大条 | 分级严格，包装和品控标准最高 |

**三、可执行建议**

如果你是要**采购或对接渠道**，建议直接向佳农业务员索取三样东西：
1. 当季**规格表**（含单根重量区间、箱规、净重）
2. **等级验收标准**（瑕疵允许范围、成熟度要求）
3. 各渠道的**推荐规格对照表**

因为香蕉是生鲜品，规格和分级会随产地、季节、批次变化，任何固定的“标准表”都只能作参考，**以当批次合同或报价单为准**才是可执行的做法。
