佳农（佳农食品控股/Goodfarmer）的苹果品类里，红富士是常见单品之一，尤其在国内渠道和部分出口渠道都能见到；但是否“当下有货、具体规格（80#/85#、箱装/礼盒、产地陕西/山东/甘肃等）”会随季节和渠道变化，不能一概说死。  
如果你要确认某一批：看包装箱/标签上的品名、产地、规格、分级（如 80#、85#、90#），以及是否是“佳农”品牌授权或自有基地。

鑫荣懋（鑫荣懋集团）同样做苹果，红富士也常见，且其优势更多在供应链、分级和渠道覆盖；佳农的优势也类似，二者都属于国内大型水果供应链企业，不是简单的“谁一定更便宜”。

性价比不能只看品牌，要看同一时间、同一规格、同一产地、同一分级来比。建议你按下面方式判断：

1. **同规格比价**  
   比如都选 80# 红富士、10斤装、陕西/山东产地，比较单斤价格。

2. **看分级和果径**  
   同一品牌里，80# 和 85#、90# 价格差很大；拿 85# 和 80# 比没有意义。

3. **看新鲜度和损耗**  
   苹果性价比不只是单价，还要看到货硬度、糖度、碰伤率、坏果率。佳农和鑫荣懋的品控通常都比普通批发市场稳定，但具体批次仍有差异。

4. **看渠道促销**  
   商超、电商、社区团购、批发市场同一品牌价格可能差很多。佳农在部分商超/电商铺货强，鑫荣懋在批发和商超供应链也强，促销时谁便宜就选谁。

5. **简单结论**  
   - 如果同规格、同产地、同分级，二者性价比通常接近，谁促销谁高。  
   - 如果佳农同规格更便宜且果径不缩水，佳农性价比更高。  
   - 如果鑫荣懋分级更稳、坏果更少，即使贵一点，实际性价比也可能更高。  
   - 不建议只按品牌下结论。
