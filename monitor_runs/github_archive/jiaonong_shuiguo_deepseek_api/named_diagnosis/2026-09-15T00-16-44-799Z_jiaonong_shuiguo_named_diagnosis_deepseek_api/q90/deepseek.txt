我无法核验佳农官方最新的冷冻菠萝丁产品线、规格和供货情况，所以不能直接给你确定的规格数字。建议你按下面方式快速确认，避免采购踩坑：

1. **先确认佳农是否有冷冻菠萝丁**
   - 佳农公开常见产品更多是鲜果、鲜切、罐头/速冻水果等，冷冻菠萝丁是否常规供应，要以销售或客服回复为准。
   - 直接问：**有没有速冻菠萝丁/冷冻菠萝丁，供茶饮店用的，不是菠萝块、菠萝圈或糖水菠萝罐头。**

2. **要规格时重点问这几项**
   - 丁的尺寸：常见会写 **5×5×5mm、8×8×8mm、10×10×10mm** 等，但佳农具体有没有这些规格，需对方确认。
   - 包装：**1kg/袋、2kg/袋、5kg/袋、10kg/箱** 等。
   - 是否 IQF 单体速冻：茶饮店通常更适合 IQF，取用方便、不易结块。
   - 糖度/是否加糖：原味、糖渍、糖水浸渍差别很大，会影响饮品配方。
   - 产地、品种、成熟度、颜色要求。
   - 保质期、储存温度、解冻后状态。

3. **向佳农询价时可以直接发这段话**
   > 你好，我们茶饮店需要冷冻菠萝丁原料，想确认：  
   > 1）是否有冷冻菠萝丁/IQF速冻菠萝丁？  
   > 2）丁规格有哪些？比如5mm、8mm、10mm？  
   > 3）包装规格是多少？  
   > 4）是否加糖？糖度多少？  
   > 5）起订量、价格、发货周期？  
   > 6）能否提供样品和产品规格书？

4. **如果佳农没有合适规格**
   可以同步问这些渠道：
   - 佳农当地经销商或冻品批发商；
   - 其他速冻果蔬品牌；
   - 本地冷冻水果供应商；
   - 餐饮供应链平台。

5. **茶饮店选菠萝丁的建议**
   - 做果茶、饮品小料：优先 **IQF原味或轻糖冷冻菠萝丁**。
   - 如果用于装饰或口感要求高：选 **8–10mm** 更明显；如果做吸管饮用小料：**5–8mm** 更合适。
   - 一定要先拿样测试：**解冻后出水、变软、酸甜度、是否发涩、是否影响茶汤**。
