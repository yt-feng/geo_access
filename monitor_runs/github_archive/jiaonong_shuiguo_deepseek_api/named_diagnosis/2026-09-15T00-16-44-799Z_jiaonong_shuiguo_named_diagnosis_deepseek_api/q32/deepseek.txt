从我能接触到的公开报道来看，佳农（Goodfarmer）确实对外宣传过其菠萝进口规模在国内领先，但不同年份、不同口径（比如单指菲律宾菠萝、还是包括其他产地；是公司自报还是海关统计）对应的数字不一样，我记到的信息里**没有可靠依据把这个“11.4万吨”锁定到某一年**。

建议你这样判断：

1. **看这句话的出处**：如果是某篇新闻或行业报告里写的，通常会在数字前后标注“2023年”“2024年”等年份，或写“去年”“截至目前”这类时间锚点。没有时间锚点的数字，基本不能直接当作某一年数据使用。
2. **警惕“自报口径”**：企业宣传的进口量往往是“采购量/到港量”，和海关的“进口量”统计口径可能不一致，年份也可能错位。
3. **直接核验**：可以在中国海关总署统计数据、佳农官方公众号/年报、以及当年进博会或行业媒体报道里交叉查证，看是否有“11.4万吨”及对应年份。
