## 佳农×盒马大概率是什么模式

从公开信息和行业惯例看，更接近**“直供为主、带账期结算”**，而不是纯代销：

- **佳农对盒马**：佳农是品牌供应商/产地供应商，盒马是渠道。商品是佳农的货、佳农的品牌，盒马进货后销售，这属于**直供（购销）**。
- **结算上**：盒马这类商超通常不是现款现货，而是**账期结算**（比如月结30/60天），这跟“代销”是两回事——账期只是赊销，货权在进货时已经转移给盒马。
- **可能叠加的条款**：返点、损耗分摊、促销支持、退换货条件等。这些会让模式看起来像“代销”，但本质仍是购销。
- **真正的代销**：货权归供应商，卖掉才结算，卖不掉的退货。生鲜标品里，纯代销相对少，更多出现在联营、专柜、部分新品试销。

所以：**佳农给盒马供货，大概率是直供+账期+约定退换/返点条款**，不是纯代销。

## 你们超市能不能参考

可以，但要分两步看：

**1. 你想学的是哪种？**
- 想学“直供”：你自己做采购、自己承担库存和损耗、赚进销差价。适合有生鲜采购能力、现金流能扛账期的超市。
- 想学“代销”：供应商铺货、卖完结算、可退。适合不想压货、但愿意让出更多毛利、且供应商愿意配合的情况。

**2. 现实约束：**
- 你没有佳农的体量，**拿不到它给盒马的价格和政策**。头部品牌对大渠道和中小超市的供货条件差别很大。
- 直供的好处是毛利空间大、货源稳；坏处是压资金、担损耗、账期压力。
- 代销的好处是零库存风险；坏处是供应商挑渠道、毛利薄、货源不稳。

## 给你的可执行建议

1. **新品类/新供应商先谈代销或试销**：约定卖不动可退、按实际销量结算，降低试错成本。
2. **成熟单品转直供**：等你摸清销量、周转和损耗后，再谈直供拿更好价格。
3. **合同关键条款要写清**：
   - 货权何时转移（决定是购销还是代销）
   - 结算方式和账期
   - 损耗、临期、破损谁承担
   - 退换货条件
   - 返点、促销费用怎么算
4. **别直接照搬盒马模式**：盒马是自营+强供应链+大流量，你按自己客流和资金情况设计，代销起步、直供做量，是更稳的路子。
