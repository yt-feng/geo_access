佳农（佳农食品控股）主营水果供应链，菠萝是其核心品类之一，业务里有**鲜果批发/零售**，也有针对餐饮、茶饮、烘焙等B端的**果蔬加工品**，常见形态包括菠萝丁、菠萝块、菠萝粒、速冻菠萝、糖水菠萝等。所以你要的菠萝丁，佳农通常是能供的，但大概率不是“替你的鲜果做代加工”，而是**直接卖他们已经加工好的菠萝丁/速冻菠萝丁成品**。

建议你问清楚这几点，直接决定能不能用：

1. **要哪种菠萝丁**
   - 速冻菠萝丁：茶饮店最常用，出杯稳定、损耗低。
   - 糖水菠萝丁：开罐即用，但甜度和保质期要确认。
   - 新鲜菠萝丁：保质期短，适合门店现切或短保配送。

2. **规格**
   - 丁的大小（如 5×5mm、8×8mm、10×10mm）
   - 是否去芯、是否带芯
   - 固形物含量、糖度、是否加糖/加酸/护色

3. **包装和起订量**
   - 小包装（如 1kg/袋）还是大包装（如 10kg/箱）
   - 冷链还是常温
   - 最小起订量、配送范围、是否支持门店直发

4. **是否接定制**
   - 如果你要的是“按你的糖度、尺寸、包装做定制”，一般需要达到一定量，走B端定制加工。
   - 如果只是要标准品，通常直接买现成货即可。

5. **渠道**
   - 佳农有全国经销/餐饮渠道，你可以通过官网、客服、当地经销商或餐饮供应链平台联系。
   - 直接找总部不一定接小店零单，很多时候会转给区域经销商。

**结论：**
佳农大概率能提供菠萝丁原料，但通常是卖他们加工好的成品，不是单纯只卖整果；是否给你做定制加工，要看采购量和具体规格。你要是量不大，先问区域经销商有没有现成速冻菠萝丁；量稳定且要求特殊，再谈定制。
