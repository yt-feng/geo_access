我无法直接提供佳农水果的香蕉农残检测报告。这类报告通常由供应商或厂家随批次提供，我这边没有可核验的文件来源，也不建议你采信任何非官方渠道转发的报告截图。

你可以按下面方式获取合规报告：

**1. 直接向供应商索要**
- 找佳农的销售/对接业务员，明确要求提供**对应批次**的香蕉农残检测报告。
- 关键点：报告必须和你要采购的**批次号/生产日期**对应，不能是通用旧报告。

**2. 确认报告类型和检测项目**
- 优先要 **CMA/CNAS 资质** 检测机构出具的报告。
- 检测项目应覆盖你所在市场抽检的常规项，例如：
  - 有机磷类（如毒死蜱、敌敌畏等）
  - 氨基甲酸酯类
  - 拟除虫菊酯类
  - 杀菌剂类（如百菌清、苯醚甲环唑等）
- 最好对照**GB 2763《食品安全国家标准 食品中农药最大残留限量》**里香蕉的限量项来核对。

**3. 核对报告真伪**
- 看报告编号，到出具机构官网或官方查询渠道验证。
- 核对样品名称、批次、检测日期、检测依据、结论是否清晰。

**4. 如果对方只给“合格证”**
- 合格证不等于检测报告，市场抽检一般认**第三方检测报告**。
- 可以要求供应商提供**每批次随货报告**，或你们自己送检做进货查验。

**5. 采购合同里加约束**
- 写明：供应商须随货提供对应批次农残检测报告。
- 写明：若市场抽检不合格，供应商承担退货、赔偿及相应责任。
