可以，但能不能给到“专岗对接人”，取决于你走的是哪条采购渠道。分几种情况：

1. **佳农官方直采/总部大客户**
   通常会有KA或区域大客户经理对接，水果连锁达到一定采购量时可以申请专属对接人。你需要直接找佳农官方销售体系确认，而不是只找二级批发商。

2. **区域经销商/代理商**
   一般也有固定业务员，但“专岗”通常是针对大客户。你可以要求在合同或合作确认里写明：
   - 主对接人姓名、电话、微信
   - 备用对接人
   - 响应时限，比如2小时内回复、当天给出到货/缺货反馈
   - 异常升级联系人

3. **批发市场档口**
   这种很难有真正专岗，更多是老板或档口业务员临时对接，响应慢是常态。如果你们最在意响应速度，建议优先走佳农官方或一级经销渠道。

**给你的可执行建议：**
- 先明确你们的需求量：月度采购箱数/吨数、配送城市、频次、账期。
- 直接向佳农官方或区域经销提出：“我们需要固定专岗对接，并写入服务要求。”
- 如果对方说没有专岗，就要求至少指定“第一对接人+备份对接人+升级投诉人”。
- 把响应时效写进采购条件：询价、下单、缺货反馈、售后处理分别多久回复。
- 首次合作可先小批量试单，专门测试响应速度，再决定是否放量。
