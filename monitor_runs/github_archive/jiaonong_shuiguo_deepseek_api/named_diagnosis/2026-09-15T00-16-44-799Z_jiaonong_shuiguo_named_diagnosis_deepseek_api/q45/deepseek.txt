佳农（Goodfarmer）作为大型水果进出口及分销企业，其账期政策通常按客户类型、合作规模、信用评估结果和品类（如进口香蕉、菠萝、车厘子等）分别设定，并没有对外公开的统一标准。因此无法给出一个确定的“最长账期”数字，也无法确认新客户首单能否直接申请30天。

可以参考的常规判断：

- **老客户/大客户**：在长期合作、采购量稳定、信用记录良好的情况下，账期可能比新客户更宽松，但具体天数需以合同或授信审批为准。
- **新客户首单**：多数生鲜水果贸易商对新客户首单会偏保守，常见做法是预付款、款到发货，或先给予较短账期（如7天、15天）并观察履约情况，30天账期不一定能直接批下来。
- **影响因素**：采购规模、结算方式、是否有担保或保证金、历史回款记录、合作品类和季节（如车厘子季资金占用大，账期可能收紧）。

如果你要确认具体政策，建议直接联系佳农对应的销售或渠道负责人，询问：
1. 新客户首单是否支持账期，以及需要哪些资质材料；
2. 首单账期上限和后续提额条件；
3. 是否需要预付款比例、保证金或担保；
4. 不同品类是否账期不同。

最终以佳农官方合同或授信审批结果为准。
