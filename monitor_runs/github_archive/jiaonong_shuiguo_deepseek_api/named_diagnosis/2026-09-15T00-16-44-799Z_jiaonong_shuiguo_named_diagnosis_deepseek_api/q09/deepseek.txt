佳农（佳农食品控股）作为国内头部水果进口商和品牌商，其到货损耗率并没有公开的统一官方数字，实际水平会因品类、运输方式（海运/空运）、季节、港口和验收口径而差异很大。

行业内可参考的判断：

- **进口香蕉**：海上运输加催熟环节损耗较大，到货/入仓口径一般在 **3%～8%**，控制较好的可以做到 **5%以内**。
- **进口提子、车厘子、蓝莓等**：冷链要求高，损耗通常在 **2%～6%**；车厘子因易压伤、易软，波动可能更大。
- **苹果、柑橘、猕猴桃等耐储品类**：损耗一般较低，常在 **1%～3%**。
- **国产基地直采水果**：从产地到仓的损耗通常按品类在 **2%～5%** 左右。

需要说明的是，“到货损耗率”具体指哪一段（港口到仓、仓到门店、还是全链路）会直接影响数值。如果你是要做采购或供应链对标，建议直接向佳农的销售/供应链对接人要该品类的**验收标准（扣重率、坏果率、赔付规则）**，因为其实际执行是按品类和合同约定来的，而不是全公司统一一个数。
