关于佳农的产地直供比例，我无法给出确切数字。这类数据通常只在公司年报、招股书或官方披露中出现，公开渠道能查到的往往笼统，不同年份也会变动，所以我不能凭印象编一个比例给你。可以判断的是：佳农属于国内头部水果进口与品牌运营商，香蕉是其核心单品，采购模式以海外产地直采/基地合作 + 国内仓储分销为主，"直供"色彩比较强，但具体占比需要以其官方或权威披露为准。

香蕉的进口来源，中国市场上的主流产地大致是：

- 菲律宾：对华香蕉出口量长期居前，是佳农等企业的重要来源之一。
- 厄瓜多尔：全球最大香蕉出口国之一，对华供应较多。
- 越南：近年对华香蕉出口增长明显，价格有竞争力。
- 柬埔寨：对华出口增长较快，常作为补充来源。
- 其他还有哥伦比亚、哥斯达黎加、墨西哥等，但进入中国市场的量相对小一些。

另外，国内也有香蕉产区（如云南、海南、广西、广东），不过国产香蕉和进口香蕉在上市季节和品种上各有分工，佳农的香蕉货源以进口为主。

如果你要确切数据，建议查两个方向：一是佳农官方渠道或上市/融资相关披露文件里的采购与产地说明；二是中国海关总署的香蕉进口统计，能按国别看到实际进口量。需要的话我可以帮你梳理怎么查这些口径。
