**客服是否7×24小时**
- 如果你是在**电商平台（天猫/京东/拼多多等）**购买，客服通常是平台店铺客服，一般不是7×24小时，多为早9点到晚9点或类似时间；平台官方客服可能24小时在线，但店铺客服通常有休息时间。
- 如果你是通过**佳农官方渠道（官网/小程序/公众号）**购买，需要看其官方页面标注的服务时间。
- 最直接的办法：在购买页面或店铺首页找“客服服务时间”说明，或直接发消息测试是否有自动回复/人工响应。

**晚上下单，第二天能否发货**
- 这在生鲜水果类目里通常**不保证**。常见情况是：当天下午某个时间点（比如16:00或18:00）前的订单当天或次日安排发货，之后的订单顺延到下一个工作日。

- 生鲜类还可能受产地采摘、冷链排期影响，不是标准电商的“次日必发”。

1. 在下单页面找“发货时间”“预计发货”说明，这是最准的。

3. 如果对时效要求高，优先选页面标注“次日达”“48小时内发货”的商品，或选择有明确时效承诺的渠道。
