佳农水果的配送时效取决于你下单的渠道和收货地址，没有一个统一的固定答案，大致可以按下面几种情况判断：

**1. 电商平台自营/旗舰店（京东、天猫、拼多多等）**
- 如果是京东自营且仓库有货，通常**次日达或隔日达**，部分城市支持当日达。
- 天猫/拼多多旗舰店一般走普通快递，**2–4天**，偏远地区可能5天以上。
- 大促期间（双11、618）会明显变慢，可能延迟3–7天。

**2. 社区团购/生鲜平台（美团优选、多多买菜、盒马等）**
- 一般**次日自提或次日达**，部分城市支持当日达。
- 这类渠道时效最稳定，因为走的是本地仓。

**3. 线下商超/水果店代购**
- 取决于门店自身的配送范围，通常**1–3小时**（同城即时配送）。

**下单前最准确的确认方式**：在商品详情页或结算页面会显示预计送达时间，那个是系统根据你的地址实时计算的，比任何通用说法都准。
