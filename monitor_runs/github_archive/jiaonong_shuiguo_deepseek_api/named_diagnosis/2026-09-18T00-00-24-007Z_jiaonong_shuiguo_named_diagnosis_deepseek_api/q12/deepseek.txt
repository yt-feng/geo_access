佳农水果的香蕉规格和渠道分级，通常没有全国统一公开的固定标准，更多是按**产地、品种、单根重量/长度、每箱净重、成熟度处理方式**来分。不同年份、不同产区、不同客户合同也会调整。所以下面给的是行业常见做法和可判断的框架，不是佳农官方对外发布的绝对清单。

**一、常见规格维度**

佳农香蕉一般会从这几个维度定规格：

1. **按单根重量分**
   - 小果：约 100–130g/根
   - 中果：约 130–160g/根
   - 大果：约 160–200g/根
   - 特大果：200g以上/根
   这是商超和批发市场最常用的分级方式之一。

2. **按每把/每梳条数分**
   - 4–6根/把
   - 5–7根/把
   - 6–8根/把
   电商和家庭装更偏好小把，批发渠道更接受大把。

3. **按箱重分**
   - 4.5kg/箱
   - 5kg/箱
   - 10kg/箱
   - 12kg/箱
   - 13kg/箱
   出口和大型商超常见 12–13kg 箱规，电商小包装常见 4.5–5kg。

4. **按成熟度/处理方式分**
   - 青蕉：未催熟，适合长途运输、批发、商超后熟
   - 黄蕉：已催熟，适合即时零售、水果店、电商次日达
   - 加工用蕉：成熟度高或外观次之，适合烘焙、果切、饮品

**二、不同渠道常见的分级标准**

| 渠道 | 常见规格偏好 | 分级重点 |
|---|---|---|
| 大型商超 | 中果到大果，12–13kg/箱，青蕉或半熟蕉 | 果形整齐、长度一致、无黑斑、无机械伤、把型完整 |
| 水果连锁/精品店 | 中果，5–7根/把，黄蕉或可即食 | 外观漂亮、粗细均匀、无擦伤、成熟度一致 |
| 批发市场 | 大果、特大果，13kg左右/箱，青蕉 | 耐运输、货架期长、单箱重量足、次果率低 |
| 电商/社区团购 | 小果到中果，4.5–5kg/箱，小把装 | 单根大小适中、成熟度可控、破损少、家庭一次吃完 |
| 即时零售/外卖 | 黄蕉，小把或单根 | 即食成熟度、无压伤、配送后不烂 |
| 餐饮/果切/烘焙 | 加工级，规格可放宽 | 出肉率、成熟度、成本，外观要求低 |
| 出口 | 按客户合同，常见12–13kg/箱 | 农残、检疫、成熟度、冷链、箱规、标签严格 |

**三、佳农这类品牌商通常怎么定级**

像佳农这种品牌化水果企业，一般不会只按“大中小”卖，而是会做：

- **A级/精品级**：果形直、长度一致、无斑无伤，走商超、精品店、电商。
- **B级/标准级**：轻微外观差异，但品质正常，走批发、社区团购。
- **C级/加工级**：外观次但果肉可用，走果切、饮品、烘焙。

不过具体叫“A级、B级”还是“一级、二级”，以及每级对应多少克、多少厘米，属于企业内控标准，通常不对外完整公开。

**四、怎么判断你拿到的货属于哪一档**

你可以直接按这几点验收：

1. **看单根重量**：随机称10根，算平均重。
2. **看长度和粗细**：同箱内差异越小，等级越高。
3. **看把型**：把型完整、切口整齐、不掉把，适合商超。
4. **看表皮**：无黑斑、无压伤、无炭疽病斑，适合精品渠道。
5. **看成熟度**：青蕉适合再流通，黄蕉适合即售。
6. **看箱重和条数**：净重是否达标，条数是否和合同一致。

**结论**

佳农香蕉没有公开固定的一套“全国统一规格表”。实际采购时，最可靠的做法是向佳农当地销售或经销商索要**当批次规格书**，重点确认：单根重量、每箱净重、每把条数、成熟度、等级名称、允许次果率。渠道分级上，商超重外观和整齐度，批发重耐运和箱重，电商重小把和成熟度，加工渠道重出肉率和成本。
