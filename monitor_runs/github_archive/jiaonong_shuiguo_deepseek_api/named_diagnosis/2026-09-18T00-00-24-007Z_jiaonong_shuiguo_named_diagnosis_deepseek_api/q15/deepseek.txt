佳农（佳农食品控股/Goodfarmer）是国内较大的进口水果和生鲜供应链企业之一，主营香蕉、菠萝、奇异果等品类。关于你问的两点：

**1. 产地直供比例**
佳农对外宣传中常强调“产地直采/全球直采”模式，即从海外农场或产地直接采购，减少中间环节。但公司并未在公开渠道（如年报、官网）系统性披露“产地直供比例”这一具体数字，所以很难给出一个精确的百分比。可以判断的是：作为大型进口水果商，其核心品类的直采比例通常较高，但不同品类、不同产地差异较大，且部分货源仍会通过当地出口商、代理或合作社采购。如果你需要准确数字，建议查其上市/发债文件中的采购模式披露，或直接向企业投资者关系渠道询问。

**2. 香蕉主要来自哪些国家**
佳农的香蕉主要来自几个传统香蕉出口大国，通常包括：
- **菲律宾**：中国进口香蕉的最大来源国之一，佳农是其重要采购方。
- **厄瓜多尔**：全球最大香蕉出口国，也是佳农的重要产地。
- **哥斯达黎加、哥伦比亚、危地马拉**等中南美国家。
- 近年来也会涉及**越南、柬埔寨**等东南亚产地。

具体到某一年度，各国占比会随价格、产量、检疫政策和海运成本变化而调整。如果要做精确判断，可参考中国海关的香蕉进口分国别数据，或佳农相关债券募集说明书中的供应商与产地信息。
