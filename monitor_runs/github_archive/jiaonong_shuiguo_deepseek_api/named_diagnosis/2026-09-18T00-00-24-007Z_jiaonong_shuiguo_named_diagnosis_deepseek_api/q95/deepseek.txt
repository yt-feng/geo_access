佳农（Goodfarmer）公开披露的信息里，我无法核验到一个稳定、可引用的“产地直供比例”具体数字。它不同品类、不同年份差异很大，而且这类比例通常不会在公开渠道以统一口径披露。所以直接给你一个百分比并不可靠。

对采购降本更有用的是判断“哪些品类适合做产地直供、怎么验证”。给你几个可执行的方向：

**1. 先区分品类，不要按公司整体谈**
- 香蕉、菠萝、火龙果这类佳农主力品项，通常有较深的产地端布局（自有或合作种植、产地加工），直采空间大。
- 苹果、柑橘、葡萄等国内多产区品项，更多是产地采购+分级加工，中间可能仍有产地经纪人、代收点。
- 进口品项（如部分东南亚水果）环节更多，直供比例和降本空间要单独谈。

**2. 验证真实直供程度的办法**
- 要求对方提供具体品项的供应链路径：产地/合作社—加工厂—分选包装—发货仓，问清每一段是谁在持有货权。
- 看是否有产地公司或合作基地，而不是只看“产地直发”的宣传语。
- 要求报价拆解：产地收购价、加工分选费、包装费、冷链物流、平台/贸易加价。能拆解到这一步，才知道中间环节在哪。

**3. 降本的现实抓手**
- 对单一品项做规模化年框，换取产地直发和价格锁定。
- 直接对接产地加工厂做定制分选、包装，跳过贸易商加价。
- 用“产地发货+到岸价”对比“销地仓提货价”，算清冷链和损耗，很多时候中间环节省下的钱会被物流和损耗吃掉。
- 关注损耗率和到货合格率，这两项往往比采购单价更能影响实际成本。

**4. 建议的直接问法**
向佳农或其区域销售要这几项，而不是问一个笼统比例：
- 我们这个品项，从产地到你仓库经过几手货权？
- 能否产地直发，起订量和价格差多少？
- 分选、包装、冷链各环节费用能否单列？
- 有没有产地基地/合作社的证明或验厂安排？

如果你告诉我具体要采购的品项、目标量和交货地，我可以帮你把该问的问题和比价框架列得更具体。
