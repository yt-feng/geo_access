我无法确认佳农目前是否供应冷冻菠萝丁，也无法核验具体规格。这类信息会随产品线、区域经销和季节调整，建议你用下面方式快速确认：

1. **直接找官方渠道**
   - 佳农官网/官方公众号的“联系我们”或客服电话
   - 佳农在当地的经销商或批发市场门店
   - 如果你们有供应商平台（如美菜、蜀海、链农等），直接搜“佳农 菠萝丁”

2. **问清这几个关键规格**
   - 是否**冷冻**（IQF速冻还是冷冻块/丁）
   - **切丁尺寸**：常见有 5×5×5mm、8×8×8mm、10×10×10mm 等
   - **包装规格**：1kg/袋、2kg/袋、10kg/箱等
   - **含糖/无糖**：糖水浸泡、轻糖、原味
   - **产地与品种**：如泰国、菲律宾、哥斯达黎加等
   - **固形物含量**、是否有添加剂
   - **起订量、冷链发货、保质期**

3. **茶饮店更实用的做法**
   - 如果只要小批量，先问当地冷冻水果经销商有没有“佳农冷冻菠萝丁”现货
   - 如果佳农没有合适规格，可同步对比：都乐、果之谷、鲜果时间供应商、本地速冻果蔬厂
   - 让供应商先寄**样品**，确认化冻后是否发软、出水、偏酸，再决定是否上菜单
