佳农（Goodfarmer）主要做进口水果和自有品牌水果，售后走的是“平台规则优先、品牌兜底”的模式，所以处理坏果的体验和你在哪个渠道买关系很大。

**分渠道看售后**

- **京东自营 / 天猫旗舰店 / 抖音官方店**：这类平台本身有生鲜售后规则，一般支持“坏果包赔”。你需要在**签收后 24–48 小时内**拍照申请，通常按坏果数量比例退款，不用寄回。
- **盒马、永辉、山姆等线下/即时零售**：一般直接找门店或平台客服，凭小票和照片，坏果多的话可以退款或补发，效率取决于门店。
- **社区团购 / 第三方店铺**：售后最不稳定，完全看商家，建议下单前先看评价里关于售后的内容。

**到货有坏果怎么处理**

1. **先别急着扔**，把坏果、包装、快递面单一起拍照，最好拍一张整体照+坏果特写照。
2. **尽快申请**，生鲜类普遍要求签收后 24 小时内，越早越好，超时容易被拒。
3. **在购买渠道内提交**，选“坏果/腐烂/变质”原因，上传照片，说明坏果数量。
4. **按比例索赔**，多数是按坏果金额退，严重的整单退。如果商家只肯补几块钱，可以申请平台客服介入。
5. **保留证据**，聊天记录、退款记录都留着，方便二次申诉。

**几个注意点**

- 生鲜一般不接受“无理由退货”，但**质量问题（坏果）是必须赔的**，这是平台规则。
- 如果是你自己放太久导致坏了，通常不赔；所以到货当天最好开箱检查。
- 佳农本身是品牌方，具体赔付执行在销售平台，遇到推诿直接找平台官方客服比找品牌更快。

简单说：**在正规电商/商超买，坏果基本能按比例赔；在杂牌第三方买，售后就看运气。关键是拍照 + 24 小时内申请。**
