佳农水果的配送覆盖和收费，取决于你具体通过哪个渠道下单，不能一概而论。可以按下面几种情况判断：

**1. 如果你是在电商平台买（京东/天猫/拼多多等）**
- 通常走的是平台自营或第三方店铺的快递，覆盖范围按平台物流能到的地址来算，一般是全国大部分地区，包括很多县城。
- 下单时在结算页填你的具体地址，系统会直接提示“是否可配送、预计几天到”，这是最准确的判断方式。
- 冷链类生鲜通常只发部分区域，偏远地区、部分县城可能不送或需要加运费。

**2. 如果你说的是佳农给商超/门店供货**
- 佳农主要是做批发和商超供应链的，配送对象是经销商、超市、水果店等B端客户，不是直接送到个人家里。
- 这种覆盖是按区域经销商和仓配网络来的，具体你所在县城有没有覆盖，需要联系佳农当地经销商或区域销售确认。

**3. 关于“县城门店能不能送到”**
- 如果你指的是佳农自己的门店，佳农主要以供货品牌为主，直营门店并不多，具体得看你县城的那家店是不是授权经销点。
- 如果是本地水果店/超市在卖佳农，那属于门店自己进货，能不能送货上门要看那家店自己的服务，跟佳农总部无关。

**4. 冷链物流收费**
- 佳农官方一般不对外公布统一的冷链收费标准，因为B端是按客户、货量、距离、温区单独报价的。
- 电商端的话，冷链费用一般已经含在商品价里，或者结算时按平台规则收运费，不会单独列“冷链费”。
- 如果你是商家想走佳农冷链，需要直接联系其销售/客服谈合作报价。

**最直接的两个办法：**
1. 电商下单：把你家详细地址填进结算页，看能不能选、运费多少，一目了然。
2. B端合作/确认覆盖：打佳农官方客服电话，或找当地水果批发市场问佳农经销商，问“XX县能不能配送、起送量多少、冷链怎么算”。
