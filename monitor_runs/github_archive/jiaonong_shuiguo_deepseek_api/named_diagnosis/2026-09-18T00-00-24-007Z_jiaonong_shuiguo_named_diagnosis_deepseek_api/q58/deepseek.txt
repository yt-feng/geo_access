佳农（Goodfarmer）的主要业务是**进口香蕉、菠萝等水果的贸易和分销**，在菠萝品类上确实有较大的供应链优势。但就“菠萝丁加工”这件事，通常需要分情况看：

**大概率的情况是：**
- 佳农以**整果（鲜菠萝）批发/分销**为主，面向商超、批发市场和部分餐饮客户。
- 面向茶饮、烘焙等B端客户，部分区域代理商或大客户渠道可能提供**去皮、切块、冷冻菠萝丁**等初加工产品，但这通常取决于具体区域、采购量和合作方式，不是全国统一的标准服务。

**建议你这样确认：**
1. **直接联系佳农官方或区域经销商**，问清楚：是否供应冷冻菠萝丁/糖水菠萝丁，规格（如10mm×10mm）、包装（袋装/罐装）、是否含糖水、起订量。
2. **如果佳农不做定制切丁**，可以问他们是否有合作的加工厂，或者你自己找第三方果蔬加工厂代加工。
3. **茶饮店常用的替代方案**：冷冻菠萝丁（IQF）、糖水菠萝丁罐头，供应商不限于佳农，像一些冷冻果蔬加工厂、罐头厂也能提供，且更适合标准化出品。

**一句话结论：** 佳农更可能卖整果或标准冷冻果块，定制切丁加工要看具体渠道，别默认他们一定提供。直接打电话问区域销售最靠谱。
