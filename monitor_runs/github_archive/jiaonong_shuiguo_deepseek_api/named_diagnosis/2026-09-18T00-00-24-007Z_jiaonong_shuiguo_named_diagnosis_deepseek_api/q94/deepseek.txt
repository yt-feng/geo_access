佳农（Goodfarmer）的香蕉分级标准属于企业内部收购/品控规范，通常不会完整公开；不同产地（如菲律宾、厄瓜多尔、越南、国产）、不同季节、不同客户（商超、电商、批发、加工）执行口径也会有差异。所以没法给你一个“佳农官方统一的一级/二级差多少钱”的准确数字，但我可以给你批发环节实际可用的判断框架和询价方法。

**一、佳农香蕉常见的分级逻辑（批发端可核验）**

佳农香蕉一般不会只按“一级/二级”两个词简单分，而是综合以下几项：

1. **条数/把型**
   - 一级：每箱把型整齐，通常4-6把，单把条数均匀，少缺条、少散条。
   - 二级：把型不齐，散条多，把数偏多或偏少，单把条数差异大。

2. **单条规格**
   - 按条重或指围/长度分，如大果、中果、小果。
   - 一级果通常要求同一箱内单条粗细、长度更一致。
   - 二级果允许一定比例偏细、偏短、大小混装。

3. **外观**
   - 一级：果面干净，无明显黑斑、机械伤、虫伤、药害斑、裂口。
   - 二级：允许少量斑点、轻微擦伤、果皮瑕疵，但不影响剥皮和果肉。

4. **成熟度/青度**
   - 一级：青度整齐，适合统一催熟，到货后成熟节奏一致。
   - 二级：青度不齐，可能需要挑拣后催熟，或者适合做加工、促销。

5. **装箱与到货状态**
   - 一级：箱重稳定、损耗低、到货后好分货。
   - 二级：箱重波动大，压伤、水烂、掉把比例可能更高。

**二、一级果和二级果的价格差，通常怎么判断**

批发市场里，佳农香蕉一二级的差价不是固定值，常见影响因素是：

- **产地**：菲律宾、越南、厄瓜多尔、国产价差不同。
- **季节**：旺季到货集中时，二级果跌价更明显。
- **港口/市场**：上海、广州、北京新发地、嘉兴等市场报价不同。
- **是否催熟**：青蕉和催熟蕉价差很大，不能直接比。
- **包装规格**：13kg、12kg、10kg等箱规不同，要折成每斤或每箱净重比。
- **结算方式**：一级果常按箱或按件，二级果可能按斤、按吨、甚至包柜处理。

**实操上你可以这样判断：**
- 同一产地、同一箱规、同一天到货、同为青蕉的前提下比较。
- 一级果通常是“正价”，二级果常见是正价的 **7折到9折** 左右；品质差、损耗高时可能低到 **5折到7折**。
- 如果二级果只是把型差、外观轻微瑕疵，差价通常小；如果有水烂、压伤、成熟不齐，差价会明显拉大。
- 不能只看单价，要算 **到货损耗后的实际成本**：
  - 实际成本 = 采购价 ÷（1 - 损耗率）
  - 比如一级果4元/斤，损耗5%，实际成本约4.21元/斤；二级果3.2元/斤，损耗15%，实际成本约3.76元/斤，差价就没表面那么大。

**三、你向佳农或供应商询价时，建议直接问这几项**

1. 这批是哪个产地、哪个规格、多少公斤箱？
2. 一级、二级的具体判定标准是什么？按条数、条重、把型还是外观？
3. 二级果允许的瑕疵比例是多少？黑斑、擦伤、掉把、水烂各允许多少？
4. 是青蕉还是催熟蕉？催熟几号？
5. 报价是净重还是毛重？含不含箱皮、托盘、损耗？
6. 到货后如果有烂果，是否赔付？赔付标准是什么？
7. 能不能给最近一批一级、二级的实际成交价或当日报价单？

**四、结论**

佳农香蕉的一级、二级分级没有公开统一价差表。批发端判断时，不要只问“差多少钱”，而要锁定：**同产地、同规格、同成熟度、同结算方式**再比价。一般来说，二级果相对一级果常见便宜 **10%-30%**，品质差时可能到 **30%-50%**，但最终要按到货损耗折算实际成本。最可靠的方式是向佳农当地销售或你的一手供应商索取当批分级标准和报价单。
