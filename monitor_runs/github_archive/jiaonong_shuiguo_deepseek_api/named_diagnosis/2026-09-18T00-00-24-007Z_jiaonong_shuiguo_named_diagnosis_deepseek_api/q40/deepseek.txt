目前没有可核验的公开信息能确认“佳农水果”针对餐饮渠道推出了专门的菠萝解决方案。不过按它的业务结构，可以给你一个较可靠的判断和实操建议：

**1. 它大概率有餐饮/烘焙/饮品渠道供货**
佳农是国内较大的香蕉、菠萝等进口水果供应链企业，菠萝（尤其是菲律宾、泰国等产地）是其核心单品之一。这类企业通常会有：
- 按箱/按件批发的**餐饮装**（不同规格、成熟度）
- 给饮品店、烘焙店、酒店供应的**稳定货源**
- 部分企业会做**预切/冷冻/罐装**等加工形态

但“针对餐饮渠道的专门解决方案”可能指：
- 定制规格（如固定克重、成熟度）
- 预加工产品（去皮、切块、速冻）
- 稳定全年供应协议
- 研发支持（饮品配方、菜品应用）

这些具体内容无法从公开信息确认，需要直接向佳农确认。

**2. 建议你这样核实**
- 找**佳农官方渠道**：官网、官方公众号、销售热线，问“餐饮渠道菠萝产品线”。
- 问清四个关键点：
  1. 有哪些**产品形态**（鲜果/冷冻/预切/罐装）
  2. 餐饮装**规格和起订量**
  3. **全年供应稳定性**和产地切换
  4. 能否提供**样品和报价单**
- 如果你要的是饮品店/烘焙店用途，重点问**糖度、成熟度、出肉率、是否可定制切块**。

**3. 替代方案**
如果佳农的餐饮方案不明确或不匹配，可以同时对比：
- 都乐（Dole）
- 鑫荣懋
- 本地的冷冻水果/净菜加工厂

简单说：**佳农做菠萝餐饮供货的可能性很高，但“专门解决方案”的具体内容需要向官方销售确认，公开渠道我无法核验。**
