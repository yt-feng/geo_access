佳农（佳农食品控股）并未对外公开披露统一的到货损耗率标准，因此没有一个官方确认的固定数字。行业里通常说的到货损耗率，需要先区分口径：

- **运输到仓损耗**：从产地/港口到经销商仓库，一般按重量或件数计算。
- **到店/到货验收损耗**：配送到门店或客户签收时，按验收差异计算。
- **仓储+分拣损耗**：入库后因腐烂、压伤、失水等造成的损耗。

从生鲜水果行业的一般经验值看：

- **香蕉、菠萝等相对耐运输品类**：到货损耗通常可控制在 **2%–5%** 左右。
- **葡萄、草莓、樱桃、蓝莓等易损品类**：到货损耗常见在 **5%–10%**，部分长途或高温季节可能更高。
- **冷链和包装较好的情况下**：部分企业会把整体到货损耗目标设在 **3%–5%** 以内。

如果你是要做采购合同、供应商考核或内部KPI，建议不要直接引用“佳农的损耗率”，而是：

1. 明确口径：是到仓、到店还是验收差异。
2. 按品类分别设阈值，而不是全品类一个数。
3. 在合同中约定验收标准、扣罚方式和举证流程。
4. 向佳农当地销售或经销商索取该品类的实际到货验收标准，因为不同产地、季节、运输距离差异很大。

简单说：**佳农没有公开的统一到货损耗率；行业参考值通常耐运水果约2%–5%，易损水果约5%–10%。**
