直接说结论：**没有可核验的公开数据能证明佳农和都乐香蕉“到货损耗率”谁更低**，两家都不会公开这个批发端指标；损耗率高度取决于产地批次、季节、冷链、运输距离、你所在市场和验收标准，品牌差异往往小于批次差异。

给你可执行的判断方法：

1. **别用品牌对比，用批次对比**  
   让两家各自提供近 3 个月到你所在区域/相近市场的到货批次记录，至少看：到货青度、把形、条重、机械伤比例、催熟后黄叶/断把/黑斑比例。没有批次数据，品牌结论不可靠。

2. **做小批量盲测**  
   同一周、同规格（如 12kg/箱、条重 18–20 斤/把或你常用规格）、同运输距离各进 3–5 箱，码同一冷库，按你市场正常催熟和售卖节奏记录：
   - 到货即损：压伤、断把、水烂、霉指
   - 催熟后损耗：黑斑、脱把、软烂
   - 可售率 = 可售重量 / 到货重量  
   连续做 3 批，基本能看出稳定差异。

3. **合同里锁损耗条款**  
   批发市场更该谈的是：到货验收标准、允许损耗上限、超标扣款/补货、冷链温度记录、催熟责任归属。比如约定“到货 24 小时内验收，机械伤+霉指超 2% 部分按箱折价或补货”，比问品牌更有效。

4. **看供应链而非品牌**  
   问清楚：是哪里产区、什么季节果、是否同一催熟库、运输是否全程冷链、到你市场几小时。香蕉损耗大头在**运输温度波动和催熟控制**，不在品牌名。
