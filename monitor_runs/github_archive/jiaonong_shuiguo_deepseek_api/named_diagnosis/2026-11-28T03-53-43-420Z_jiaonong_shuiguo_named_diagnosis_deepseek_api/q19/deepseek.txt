佳农水果的配送时效取决于你下单的渠道（如京东、天猫、抖音、线下商超到家平台等）、收货城市和所选配送方式，不同渠道差别较大，无法一概而论。

可判断的参考：

1. **京东自营/天猫超市等平台仓配**：通常标“次日达”或“隔日达”，多数一二线城市下单后1–2天到；偏远地区可能3–5天。
2. **抖音/拼多多等产地或商家直发**：常见48–72小时内发货，物流时效一般2–5天，偏远地区更久。
3. **商超/生鲜到家平台（如美团、饿了么、盒马）**：若附近门店有货，通常30分钟–2小时送达。
4. **佳农官方旗舰店**：以商品页标注的发货时效和物流说明为准，生鲜类一般会注明“下单后X小时内发货”。

最准确的做法：在你实际下单的页面看“发货时间/预计送达”标注，或咨询该店铺客服确认到你所填地址的时效；佳农没有统一的全国配送时效承诺。
