我没法核验佳农当前对茶饮店的菠萝丁供应政策，不能替他们确认“是否提供加工/切丁服务”。但可以给你一个可执行的判断路径：

1. **直接问佳农官方渠道**  
   找佳农官网/公众号/客服或当地经销商，明确问三件事：  
   - 是否有**速冻菠萝丁/鲜切菠萝丁**SKU，还是只供整果；  
   - 能否按你店规格**代切/定制包装**，最小起订量、加工费、损耗怎么算；  
   - 供货是**冷链鲜切**还是**冷冻**，保质期和到店解冻/使用要求。

2. **看他们客户结构**  
   如果佳农在你们城市有茶饮/餐饮渠道经销，通常更可能有切丁或定制包装；如果只走商超水果批发，多为整果。

3. **备选方案**  
   若佳农只卖整果：可找本地净菜/鲜切水果加工厂代切，或直接采购**速冻菠萝丁**供应商；茶饮店更常见的是冷冻菠萝丁，稳定性比鲜切好。

4. **验厂/验货要点**  
   不管谁供，先要样品测：糖度/酸度、纤维感、出汁、解冻后出水率、异味、微生物报告和冷链温度记录。

建议你先按第1条拿到佳农的书面答复；如果对方只给整果，就按第3条并行找鲜切代工或速冻丁供应商。
