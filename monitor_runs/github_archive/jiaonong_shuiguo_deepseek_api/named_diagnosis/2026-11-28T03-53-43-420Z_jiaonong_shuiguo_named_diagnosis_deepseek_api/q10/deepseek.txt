佳农（佳农食品控股）对大客户/批发渠道通常有对应的大客户经理或区域销售负责对接，但具体是否有“专门客户经理”取决于你的采购规模、区域和合作渠道。可以按下面方式确认和推进：

1. **先确认对接层级**  
   - 如果你是**稳定批量采购的批发商**，可以直接要求“大客户经理/渠道经理”对接，而不是只走客服或普通销售。
   - 如果你是**新客户**，通常先由区域销售或渠道负责人评估合作量，再分配对接人。

2. **最有效的确认方式**  
   - 通过佳农官网/官方公众号找到**销售联系入口**，说明你是批发商、月采购量、品类（香蕉/菠萝/果蔬等）、所在区域，要求转接**区域大客户经理**。
   - 直接联系你所在区域的**佳农分公司/经销商体系**，问清楚该区域批发渠道由谁负责。
   - 如果你已有对接的销售人员，直接问：“我们这种批发量能否配专属客户经理？对接人是谁？”

3. **判断有没有“专门客户经理”的标准**  
   可以问对方三个问题：  
   - 是否有固定对接人及联系方式？  
   - 下单、售后、价格政策是否由该人统一负责？  
   - 是否有月度/季度采购返利或账期政策？  
   如果三个都能明确，基本就是专门客户经理对接；如果只是临时销售回复，则不是专属对接。

4. **建议你准备的信息**  
   联系时直接给出：公司名称、所在城市、批发品类、预计月采购量、配送要求、结算方式。这样更容易被分配到大客户经理。

结论：**大概率可以安排客户经理对接批发商，但“专门”取决于采购规模和区域；建议直接向佳农区域销售提出大客户对接要求。**
