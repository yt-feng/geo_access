我们这边是通用AI助手，不是佳农或你当地经销商的商务人员，无法替他们给出“到货损耗率承诺/超过3%包赔”这种合同条款。直接说结论：**这类承诺只能由供货方书面确认，不能靠口头或行业惯例默认；你采购前要把“到货损耗”定义、验收时限、赔付方式和责任边界写进订单/合同。**

给你一套可执行的判断和谈判要点：

1. **先区分两种损耗**
   - **到货损耗**：从装车到门店收货期间发生的烂果、压伤、断裂、青黑、霉变等。这个才适合谈“到货包赔”。
   - **货架期损耗**：收货后因成熟度、温度、陈列、售卖速度造成的损耗。供应商通常不愿全包，最多给成熟度标准或调换支持。

2. **“超过3%包赔”必须写清口径**
   建议合同写：
   - 以每批次到货总箱数/总重量为基数；
   - 收货后**2小时内**开箱抽检/全检并拍照留证；
   - 抽检比例、判定标准（如明显腐烂、压伤面积、霉变、断裂）；
   - 超出3%部分按**进货价折算退款/补货/下批抵扣**，而不是只赔“超出部分重量”；
   - 赔付时限（如3个工作日内补货或对账抵扣）。

3. **别只盯3%，要算真实损耗**
   便利店卖香蕉关键不是到货损耗一个数，而是：
   - 到货成熟度：建议要求**青黄适中、可3—5天售卖**，不要到货即熟；
   - 包装：纸箱+内衬，避免挤压；
   - 配送频次：少量多次比一次压货更稳；
   - 门店陈列：避晒、避冷柜出风口、悬挂或分层陈列；
   - 日盘：每天挑出熟果做折扣或加工，别等到烂。

4. **谈判话术**
   你可以直接问经销商：
   > “这批佳农香蕉到货验收标准是什么？到货损耗超过3%的部分，能否按进货价折算补货或下批抵扣？请把验收时限、抽检比例和赔付方式写进供货单。”

5. **如果对方不承诺**
   不要硬压“3%包赔”作为唯一条件，可改为：
   - 首批小批量试销；
   - 要求到货成熟度分级；
   - 约定“到货损耗超5%可拒收/换货”；
   - 先做2—4周实测，再谈包赔比例。
