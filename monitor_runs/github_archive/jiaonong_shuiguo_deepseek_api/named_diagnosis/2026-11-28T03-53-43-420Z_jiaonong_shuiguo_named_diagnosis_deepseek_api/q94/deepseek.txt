佳农（Goodfarmer）的香蕉分级属于企业内控标准，通常不会完整对外公开；批发端能拿到的是大区/渠道商口头或合同附件里的“验收口径”，而不是官方公开文件。所以下面给你可判断、可执行的结论和询价方法：

**1. 佳农香蕉常见分级维度（批发验收口径）**
- **外观**：果形周正、弯曲度一致；梳形整齐、无散把；果指长度和粗度均匀。
- **色泽**：青果以青绿均匀、无黄化斑为佳；催熟后要求转色均匀。
- **机械伤/病虫**：一级果基本无擦伤、压伤、裂口、黑星病斑；二级果允许轻微表皮瑕疵但不影响果肉。
- **果指规格**：按每箱净重、每梳果指数、单果指长度/粗度分档，不同产地（菲律宾、厄瓜多尔、越南、国产）和季节口径会变。
- **成熟度**：青果硬度、催熟后货架表现是分级关键，一级果通常要求催熟一致性更好。

**2. 一级果和二级果价格差**
- 没有全国统一价差。香蕉批发价随产地、季节、到货量、催熟状态、包装规格、结算方式（现款/账期）波动很大。
- 实操中，**同一批次、同一产地、同一规格下，二级果通常比一级果低一档报价**，常见是每箱低几元到十几元，折合每公斤低约 **0.3～1.5 元**；行情差、二级果瑕疵多时价差会拉大，紧俏时价差收窄。这个区间只能作询价参照，不能当佳农官方价差。
- 更稳妥的判断方式：让供应商报“同产地、同规格、同成熟度、同到货日”的一级/二级同箱价，再按每箱净重折算每公斤价差。

**3. 你可以直接执行的询价话术**
> 请提供本批次佳农香蕉的分级验收标准附件：果指长度/粗度范围、每箱净重、允许瑕疵比例、青果硬度/成熟度要求；并分别报一级果和二级果的同规格箱价、起订量、账期价和现款价。

**4. 合同里建议写清**
- 分级以“到货验收标准”为准，附照片样例和允许瑕疵比例；
- 一级果/二级果分别计价，降级扣款规则；
- 催熟后出现批量不转色、果肉软化等问题的责任归属。
