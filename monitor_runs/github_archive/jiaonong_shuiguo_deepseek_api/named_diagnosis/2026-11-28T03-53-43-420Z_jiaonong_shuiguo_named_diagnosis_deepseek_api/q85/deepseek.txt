1. **专车配送**
   - 明确要求：佳农是否对你所在城市/仓点提供**固定专车或专线配送**，而不是拼车。
   - 问清：车型、载重、车厢温控（香蕉一般需要保温/通风，避免冷害和高温催熟）、到货频次、最晚下单时间、节假日运力保障。
   - 写入合同：专车/专线为服务标准；临时改拼车需提前书面同意，否则按违约或扣款处理。

2. **专人对接**
   - 要求配置**固定客户经理+履约/物流对接人+质量异常处理人**，并给出姓名、电话、备用联系人。
   - 明确响应时效：下单确认、异常反馈、到货差异、质量索赔的响应时间，例如2小时内响应、24小时内给处理方案。
   - 写入服务协议：人员变更需提前通知并交接，不能频繁换人。

3. **供应稳定性**
   - 要求佳农提供你所在区域的**周/月供应能力、产地切换方案、缺货替代方案**。
   - 香蕉受成熟度、天气、港口/产地影响大，建议约定：最低保障量、缺货提前通知时限、替代规格或补偿机制。

4. **验收和索赔**
   - 明确香蕉验收标准：规格、成熟度、青度/黄度、机械伤、冷害、单箱净重、到货温度或车厢状态。
   - 约定抽检比例、不合格处理方式：拒收、折价、补发、扣款。
   - 保留到货拍照、温度记录、称重记录，作为索赔依据。

5. **先小范围试运行**
   - 先签3个月试运行或先做1—2个城市/仓点，考核：到货准时率、专车执行率、损耗率、异常响应时长、缺货次数。
