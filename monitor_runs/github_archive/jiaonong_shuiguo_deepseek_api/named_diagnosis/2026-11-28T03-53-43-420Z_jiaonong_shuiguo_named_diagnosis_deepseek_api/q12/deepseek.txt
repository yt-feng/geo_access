佳农香蕉的规格会随年份、产地（菲律宾/厄瓜多尔/越南等）、包装线和客户定制变化，公开渠道没有稳定、完整的“官方全规格表”。可以按行业通行口径给你一个可判断的框架，但具体SKU和分级限值要以佳农当季报价单/装箱单为准，不要直接当作官方标准引用。

### 一、常见规格维度
佳农及同类进口香蕉通常从4个维度定规格，而不是只有“几种”：

1. **单根重量/条重**
   - 小条：约110–130g/根
   - 中条：约130–160g/根
   - 大条：约160–190g/根
   - 特大条：约190g以上/根
   （不同客户会设不同区间，且以整箱平均条重或抽检条重计。）

2. **每箱净重**
   - 常见12kg、13kg、13.5kg、18kg等纸箱装；
   - 也有按把/梳包装、电商小包装、餐饮大箱装。

3. **每箱条数/把数**
   - 按“条数/箱”或“把数/箱”报规格，如4–6把/箱、5–7把/箱等；
   - 商超更关注把型整齐度，批发更关注条重和箱重。

4. **成熟度与颜色**
   - 青蕉（1–2号色）、微黄（3号色）、黄熟（4–5号色）；
   - 不同渠道对到货颜色和催熟后货架期要求不同。

### 二、按渠道的分级建议
以下是可执行的渠道分级逻辑，不是佳农官方分级：

| 渠道 | 重点规格 | 分级关注点 |
|---|---|---|
| 大型商超/精品超市 | 中条至大条，条重均匀，把型整齐 | 外观洁净、无机械伤、无黑斑、梳把整齐、长度一致；到货颜色可控；箱规稳定 |
| 水果连锁/社区生鲜 | 中条为主，性价比优先 | 条重中等、成熟度略高以便快速周转；允许轻微外观瑕疵但无腐烂 |
| 电商/前置仓 | 小中条或小包装 | 单根大小适中、耐运输、成熟度偏青；减少压伤；按份量而非纯条重 |
| 批发市场/农贸 | 大条或混合条，重箱重 | 条重和箱重足、价格敏感；外观分级可放宽，但青蕉硬度、整齐度要稳定 |
| 餐饮/茶饮/烘焙 | 大条或指定加工规格 | 出肉率、成熟度稳定、批次一致；对表皮外观要求低于商超 |
| 催熟配送商 | 青蕉硬果 | 硬度、色号统一、无早期熟斑；按催熟计划分批 |

### 三、实操判断
- 询价时直接问佳农业务员要三样：**当季规格表、装箱单、抽检分级限值**。
- 合同中把“条重区间、每箱净重、允许青/黄比例、机械伤率、腐烂率”写清楚，比记“几种规格”更有用。
