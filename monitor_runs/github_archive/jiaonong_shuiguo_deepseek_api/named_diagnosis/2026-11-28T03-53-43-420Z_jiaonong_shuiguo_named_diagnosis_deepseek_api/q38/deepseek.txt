从公开信息无法确认佳农是否提供“菠萝锁价合同”，更不能虚构其合同政策。但可以给你可执行的判断路径和谈判要点：

1. **先确认对方合同主体和业务口**
   - 佳农体系内做水果进口/分销的主体不止一个，先让对方明确：签约主体、供货区域、菠萝品类（如金钻凤梨/普通菠萝）、规格、产地、包装、交货仓。
   - 直接问对接销售：“是否支持6个月锁价？锁价是锁采购价、到岸价还是到仓价？超量/减量如何处理？”

2. **菠萝半年锁价通常难度较高**
   - 菠萝受产季、产地天气、海运/陆运成本、汇率、包装和人工成本影响，半年固定价对供应商风险较大。
   - 常见替代方案：
     - **价格区间锁**：设上下限，超出区间再议；
     - **月度调价公式**：以产地收购价/运费指数为基准；
     - **部分锁价**：锁基础量+浮动量随行就市；
     - **预付款/保证金换锁价**：支付定金或保证金锁定产能和价格；
     - **最低采购量承诺**：用半年总量换价格稳定。

3. **要求书面报价单和合同条款**
   至少写清：锁价期限、适用规格、数量/最低提货量、交货地点与时效、质量标准与损耗赔付、价格调整触发条件、违约与保证金、汇率/运费异常处理。

4. **可替代验证方式**
   - 让佳农销售出具“锁价合同模板”或“框架协议+价格确认单”；
   - 同时询价2—3家同类进口商/一级批发商，判断半年锁价的市场可行性；
   - 若对方只口头承诺，要求写入合同并明确违约赔偿。

**结论：** 不能确认佳农一定提供半年菠萝锁价合同；建议按“锁价+浮动机制+最低采购量+保证金”去谈，先要合同模板和书面报价，再判断可行性。
