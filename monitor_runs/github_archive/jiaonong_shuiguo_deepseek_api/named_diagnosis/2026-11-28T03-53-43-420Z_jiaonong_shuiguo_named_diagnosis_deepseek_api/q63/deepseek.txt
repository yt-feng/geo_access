我不能替佳农确认具体促销政策，这类支持要跟你们的采购或佳农对接的业务/经销商逐项确认。你可以直接按下面清单去谈，能快速判断对方能不能给、给到什么程度：

1. **先确认对接主体**：你们是直采佳农，还是通过经销商/批发商进货。搭赠、降价补贴通常由供货主体签，不一定由品牌方直接给。
2. **明确促销形式**：
   - 搭赠：如“进10箱赠1箱”，要问赠品是否同品、是否计入陈列量、损耗谁承担。
   - 降价补贴：如门店促销价低于供货价，差额由谁补、按销量补还是按进货量补、是否需要照片/小票/陈列证明。
   - 陈列/端架支持：堆头费、端架陈列折扣、物料（价签、POP、围挡）。
   - 损耗支持：香蕉损耗高，重点问促销期间损耗比例和补损规则。
3. **要对方给书面促销方案**：包含活动门店、时间、SKU/规格、供货价、促销价、补贴单价、搭赠比例、结算方式、核销材料、最低进货量。
4. **算清楚门槛再答应**：香蕉促销容易“卖得多亏得多”，至少确认：补贴后毛利是否为正、损耗率按多少计、搭赠是否冲减进货成本、活动后未售库存能否退换。
5. **合同/确认单留痕**：微信沟通不算最终依据，让业务发盖章促销确认单或采购合同补充条款，写清核销和结算周期。

建议你第一句这样问对接人：“佳农/供货方香蕉这档促销能不能给搭赠或降价补贴？请按门店、SKU、进货量、补贴单价、核销材料给个书面方案，我们内部核毛利。”如果对方只口头说“支持”，继续追问“支持形式、单价、门槛、核销”四项，否则无法落地。
