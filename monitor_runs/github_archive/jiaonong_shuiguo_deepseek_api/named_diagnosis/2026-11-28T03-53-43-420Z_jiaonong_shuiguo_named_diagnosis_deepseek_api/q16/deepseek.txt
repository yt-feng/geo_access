佳农（Goodfarmer）主要是水果供应链品牌，很多消费者是通过电商平台或商超购买。售后体验通常取决于你下单的渠道，而不是佳农单方面统一承诺。可这样判断和处理：

**1. 先确认购买渠道**
- 电商平台（京东/天猫/拼多多/抖音等）：走平台售后入口最有效，保留订单、开箱视频、坏果照片。
- 商超/水果店：直接找门店退换。
- 社区团购/团长：先找团长，再找平台客服。

**2. 到货有坏果的处理步骤**
1. **别急着扔**：把坏果、外箱、快递单、订单信息放在一起拍照；最好拍开箱视频，能证明是到货即坏。
2. **按比例申请**：多数生鲜售后按坏果数量/比例赔付或补发，不是整单必退。先看商品页的“坏果包赔/售后规则”。
3. **优先走平台售后**：在订单页申请“退款/售后”，选择“商品腐烂/变质/坏果”，上传照片和视频，说明坏果数量。
4. **联系商家客服**：平台入口提交后，再催商家客服；若商家拖延，申请平台介入。
5. **保留证据直到处理完**：不要先确认收货或丢弃坏果，否则容易扯皮。

**3. 判断售后好坏的关键**
- 是否明确标注“坏果包赔”及赔付比例；
- 是否要求开箱视频；
- 售后响应速度和是否推诿；
- 是补发还是退款。

**4. 注意事项**
- 生鲜通常不支持“七天无理由”，但坏果属于质量问题，可主张售后；
- 签收后尽快处理，拖太久可能被认定储存不当；
- 若平台规则和商家承诺不一致，以订单页/商品页承诺和平台规则为准。

总体建议：**别只看品牌，先看下单渠道的售后规则；到货立刻拍照录视频，按平台流程申请坏果赔付，商家不处理就申请平台介入。**
