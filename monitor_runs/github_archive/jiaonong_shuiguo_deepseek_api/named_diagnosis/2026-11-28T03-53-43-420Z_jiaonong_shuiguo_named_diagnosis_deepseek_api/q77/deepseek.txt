结论先说：**一般到不了“具体农场”这一级；多数是按产地/包装厂/供应商批次追溯。GLOBALG.A.P.证书可以要求提供，但证书通常覆盖的是“生产商/农场组织/包装处理单位”，不必然对应你这一批货的具体农场。** 商超要审，建议按下面做。

### 1. 佳农香蕉的溯源层级
佳农这类进口香蕉通常的链是：
**出口国产区 → 合作农场/种植园或农场组织 → 包装厂 → 出口商 → 进口商/国内分装 → 商超**

实际能提供的一般是：
- 原产国、产区/省份
- 包装厂编号/注册号
- 出口商/进口商
- 批次号、采收/包装日期
- 有时能到“合作农场/种植园名称或编号”

但**“这一箱香蕉对应哪一个具体农场”通常做不到单箱级一一对应**，尤其是多农场混收、集中包装的情况下。能做到的是**批次级追溯到包装厂和供货农场范围**。如果对方声称能到具体农场，要让他们提供“批次-农场对应表”和包装记录，否则只能算产区/包装厂级追溯。

### 2. GLOBALG.A.P.证书怎么要
你可以这样向佳农或供应商提要求：
- 要**证书原件PDF**，不要只给截图
- 核对证书上的**GLOBALG.A.P. Number（GGN）**
- 核对**证书持有人**是否与供货主体/包装厂一致
- 核对**产品范围**是否包含香蕉（Bananas）
- 核对**证书有效期**和**认证机构**
- 核对**覆盖场所**：是农场、农场组织，还是包装处理单位
- 要**证书与本次供货批次的关联说明**：如包装厂注册号、批次号、供货农场列表

注意：GLOBALG.A.G.证书是**管理体系/生产认证**，不是“这一批货的检测报告”。商超如果既要认证又要批次合规，还应另要：
- 批次号及包装日期
- 原产地证明/植物检疫证书（进口香蕉）
- 农残检测报告（按商超标准）
- 供应商与包装厂对应关系说明

### 3. 给商超的实操建议
采购合同或质量协议里写清楚：
1. 供应商须提供有效GLOBALG.A.P.证书，证书范围含香蕉，证书持有人与供货链一致；
2. 每批次提供包装厂编号、批次号、采收/包装日期；
3. 能追溯到“包装厂+供货农场范围”，不承诺单箱到具体农场；
4. 如商超坚持“具体农场”，要求供应商提供**批次-农场对应表**，并在合同中约定不能提供时的处理方式。

### 4. 判断话术
你可以直接问佳农三句话：
- “这批次香蕉的包装厂编号和批次号是什么？”
- “GLOBALG.A.P.证书持有人是谁，覆盖哪些农场/包装厂，证书范围是否含香蕉？”
- “能否提供本批次对应的供货农场清单或批次-农场对应表？”

如果对方只能给证书和产地证明，给不了批次-农场对应表，那**溯源到具体农场就不成立**，只能按“产区+包装厂+批次”验收。
