能谈，但**不能把“佳农能提供锁价合同”当成确定事实**——这需要你和佳农当地销售/大客户渠道直接确认。按你每月10吨、全年约120吨的量，属于可以谈年度框架+锁价的体量，但茶饮原料锁价通常不是简单“一口价全年”，而是有条件的。

**可执行判断：**

1. **先确认对接主体**：找佳农官方渠道，问清楚是总部大客户部还是区域经销/供应链公司在做菠萝原料，避免拿到的是二级报价。
2. **锁价要问清五个条件**：
   - 锁价品种和规格：鲜菠萝、冷冻菠萝块/果肉、果酱/浓缩汁？不同品类锁价逻辑完全不同。
   - 锁价周期：3个月、6个月还是12个月；茶饮店建议先谈6个月，全年锁价供应商通常要求更大体量或保证金。
   - 价格调整机制：是否只锁“基准价”，运费、包装、糖度/规格升贴水另算。
   - 履约量：月度最低提货量、年度总量、未达量补偿。
   - 质量与验收：糖度、酸度、出成率、农残、冷冻品的解冻失水率，写进合同。
3. **不要只锁一家**：同时找2—3家菠萝原料供应商比价，佳农之外看产地加工厂/冷冻果肉厂。锁价合同要保留“质量不达标可拒收/换货”和“不可抗力/大幅行情偏离重谈”条款。
4. **价格波动对冲组合**：对每月10吨，可做“60%—70%锁价+30%—40%随行就市”，既控成本又保留灵活性；如果供应商要求全年锁价，先谈季度锁价试运行。
5. **合同必须写清楚**：锁价不含税/含税、运费承担、账期、逾期交货违约金、品质不符处理、年度未完成量的处理方式。

**结论**：你的采购量有谈判空间，佳农大概率可以谈框架合作和阶段锁价，但“能否锁、锁多久、锁什么价”必须以对方书面报价和合同为准。建议先让对方出**6个月锁价+月度10吨保供**的方案，再拿另一家报价压价。
