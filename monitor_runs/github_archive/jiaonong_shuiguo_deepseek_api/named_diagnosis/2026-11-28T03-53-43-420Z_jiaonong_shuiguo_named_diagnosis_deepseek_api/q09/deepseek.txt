佳农（Goodfarmer）作为水果进口和分销企业，其到货损耗率没有对外公开的统一官方标准，具体数值会随品类、季节、运输方式、冷链条件和验收口径变化很大。可以给你一个可判断的参考框架：

1. **到货损耗率的定义要先明确**  
   是指“到仓验收时的不合格/腐烂/压伤比例”，还是“入库后仓储+分拣+配送全链路的综合损耗”。两者差异很大，后者通常明显更高。

2. **行业常见参考区间**  
   - 香蕉、菠萝、火龙果等相对耐储品类：到货验收损耗通常可控制在**2%～5%**左右；  
   - 葡萄、蓝莓、樱桃、草莓等易损品类：到货损耗常见在**5%～10%**，冷链不稳定或长途海运时可能更高；  
   - 若按全链路综合损耗（含仓储、分拣、门店/客户退货），很多水果企业会按**5%～15%**做品类分级管理，易损品更高。

3. **不能直接套用“佳农标准”**  
   佳农不同产品线、不同客户（商超、电商、批发）和不同合同条款下的验收标准并不一致。比较可靠的做法是：  
   - 查你手上的采购合同/质量协议中的“到货验收标准”和“损耗赔付条款”；  
   - 向佳农对接的销售或品控索取该品类近期的到货验收数据；  
   - 用同一口径（同品类、同运输方式、同验收时点）做批次对比，而不是跨品类比较。

如果你能说明具体水果品类、运输方式（海运/空运/陆运）和验收口径，我可以帮你把合理损耗区间估得更细。
