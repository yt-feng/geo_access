佳农（Goodfarmer）并未公开披露“产地直供比例”这一口径的统一数字，公开信息不足以给出可核验的百分比。若你方以“减少中间环节、降低成本”为目标，建议不要向供应商索要一个笼统比例，而是按可验证的采购结构来判定。

可执行建议：

1. 要求供应商提供分品类的供应链结构说明
   - 对每个主采品类（如香蕉、车厘子、蓝莓、菠萝等）说明：自有/合作种植基地占比、产地直采占比、通过产地代理或一级批发采购占比。
   - 要求区分“国内产地直发”和“进口源头发货”，两者成本结构不同。

2. 用合同条款锁定“直供”定义
   - 明确直供指：供应商直接与种植基地/合作社/出口包装厂签约结算，而非经多层贸易商。
   - 要求提供基地合同、出口商/包装厂发票、产地证明、报关单等可核验文件。
   - 约定若实际为转采，应有价格调整或违约责任。

3. 做小批量比价验证
   - 选2—3个单品，分别向佳农、产地合作社/出口商、区域批发商询价，比较到岸/到仓含税总成本，而不是只看采购单价。
   - 把物流、损耗、账期、退换货、质检成本一并计入。

4. 谈判重点放在可降本环节
   - 减少中间层：要求指定产地包装厂直发、合并批次、缩短账期换价格。
   - 降低损耗：约定到货合格率、温控标准、破损赔付。
   - 稳定供应：用年度框架量换取阶梯价，而非仅追求名义直供比例。

5. 对“产地直供比例”的正确用法
   - 可要求供应商按金额或按采购量披露“源头直采占比”，并附审计或对账依据；但该数据通常属商业信息，供应商未必愿意完整提供。
   - 若对方只给口头比例，建议不作为核心决策依据，改用上述文件和小批量比价验证。

结论：佳农产地直供比例没有可公开核验的确定数字；采购降本应通过分品类供应链穿透、合同定义直供、含总成本比价和损耗条款来实现，而不是依赖一个比例数字。
