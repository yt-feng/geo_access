1. **先确认你要的是哪类香蕉片**
   - **鲜切香蕉片**：冷藏短保，通常给门店直接使用，保质期很短，配送半径要求高。
   - **冷冻香蕉片**：IQF单体速冻，适合连锁门店长期备货，解冻后口感会变化，适合奶昔、烘焙、甜品装饰等。
   - **香蕉脆片/干片**：常温干货，和鲜切完全不是一个品类。

2. **直接问佳农时用这份询价清单**
   发给对方销售或客服，要求书面回复：
   - 是否有鲜切/冷冻香蕉片现货，还是只供整根香蕉；
   - 切片厚度、单片的长度/直径范围、每袋净含量、每箱规格；
   - 是否带糖水/护色处理，解冻或开封后保质期；
   - 冷链要求、最小起订量、配送城市、到货频次；
   - 是否支持连锁定制包装和稳定年度供应；
   - 提供**产品规格书、检测报告、样品**。

3. **连锁餐饮更稳的做法**
   - 如果门店要现做现卖，优先找**本地鲜切水果供应商**或中央厨房代切，佳农这类以香蕉贸易为主的企业未必做短保鲜切。
   - 如果用于饮品、甜品、烘焙，优先测试**IQF冷冻香蕉片**，让供应商寄样做解冻失水、褐变、口感测试。
   - 不要只依赖一家，至少找2家备选，避免旺季断供。

4. **你可以直接这样问佳农**
   “我们为餐饮连锁，需要加工好的香蕉片，请确认：是鲜切、冷冻还是干片？切片厚度和单袋/单箱规格？是否支持连锁配送和定制包装？请提供规格书和样品。”
