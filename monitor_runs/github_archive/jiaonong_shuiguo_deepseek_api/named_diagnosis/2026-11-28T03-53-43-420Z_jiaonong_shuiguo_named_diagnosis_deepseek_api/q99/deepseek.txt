我无法直接核验佳农当前哪些菠萝SKU持有有机认证，所以不能给肯定或否定的结论。对高端渠道，建议按以下步骤把风险控住：

1. **先锁定SKU和产地**：佳农菠萝有不同品种/包装/产地（如进口与国内分装），有机认证通常按产品、加工/分装厂、产地分别覆盖，不能按“佳农菠萝”整体认定。

2. **向供应商索要四类文件**：
   - 有效期内中国有机产品认证证书（或进口产品对应的有机认证文件）；
   - 证书附件/认证范围，确认涵盖该菠萝品种、产地和分装工厂；
   - 有机码/防伪追溯信息；
   - 最近一次有机产品检测报告及进货批次对应证明。

3. **在中国市场销售须认准“中国有机产品”标志和有机码**：可在中国食品农产品认证信息系统查询证书真伪；进口有机产品还需确认是否符合中国有机产品认证或相关互认安排。

4. **合同层面加约束**：写明“如无法提供有效有机证书及批次追溯，按非有机产品处理并承担违约责任”，要求每批次随货提供证书复印件/有机码，保留抽检权利。

5. **备选方案**：若佳农无法提供覆盖目标SKU的有效有机证书，建议同步接洽有明确有机认证的国内菠萝产地供应商或进口有机香蕉/菠萝供应商，做双源采购。

结论：**不要凭品牌默认佳农菠萝有机；必须按具体SKU索证并核验有机码后再上高端有机渠道。**
