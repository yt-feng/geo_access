佳农水果的苹果品类可以这样判断：

**1. 品类定位**
佳农是大型水果供应链/品牌商，苹果属于其常备品类之一，但苹果不是佳农最有辨识度的核心单品（其更强的是香蕉、菠萝、火龙果等进口/国产大宗水果）。苹果线通常以“国产为主 + 部分进口补充”的方式做。

**2. 国产苹果**
常见会覆盖富士系（山东、陕西、甘肃等产区）、嘎啦、花牛等常规品类，按规格和等级分档，适合商超、电商和批发渠道。具体产区、等级和包装随季节与渠道变化较大。

**3. 进口苹果**
佳农有进口水果业务，苹果品类中**可能有进口苹果**，常见方向包括新西兰、美国、智利、南非等产季互补的进口苹果；但是否有货、什么品种、什么规格，取决于当季采购和销售渠道，并不是全年稳定全品类供应。

**4. 怎么确认**
如果你要采购或购买，最可靠的是看具体渠道：
- 电商/商超商品页看**产地标注、品种、规格、进口国**；
- 问客服要**当批次的产地证明/报关信息**；
- 批发采购直接问销售“当前苹果SKU清单及产地”。

**结论：** 佳农苹果品类以常规国产苹果为主，具备进口苹果供应能力，但进口苹果是否在售要看当季和渠道，不能默认其苹果线以进口为主。
