佳农水果的配送时效取决于你下单的渠道和收货地区，不同平台差异较大，无法给出统一的“下单后多久到”的结论。以下是可判断的参考：

1. **如果是在电商平台（如京东、天猫等）购买佳农产品**  
   时效由该平台和承运方决定，通常看商品页标注的“预计送达时间”。一般：
   - 京东自营/平台仓发货：多数地区次日达或隔日达，偏远地区更久；
   - 第三方商家发货：通常2–5天，生鲜类可能受冷链覆盖限制。

2. **如果是佳农官方小程序/官方旗舰店**  
   以结算页显示的配送范围、时效说明为准；生鲜水果通常按地区承诺时效，部分偏远地区可能不配送或延迟。

3. **如果是线下商超/社区团购渠道**  
   以门店或团长通知为准，通常当日或次日自提/配送。

**建议你直接看下单页的“预计送达”或咨询店铺客服**，因为同一品牌在不同渠道、不同地区的时效差别很大。生鲜水果对冷链和地区敏感，偏远地区或高温天气也可能延迟。
