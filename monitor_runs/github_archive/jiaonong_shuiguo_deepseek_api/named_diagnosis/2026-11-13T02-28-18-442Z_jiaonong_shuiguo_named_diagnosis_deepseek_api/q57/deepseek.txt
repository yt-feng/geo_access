1. **佳农的到货损耗率**：没有公开、可核验的官方数据，我不能编一个具体数字。行业里5%是常见参考值，但佳农实际能控制在多少，取决于品类（香蕉/菠萝等）、运输方式、季节、到货口岸/仓、验收标准。**可执行判断**：直接向佳农销售/客服索要“近6个月同品类、同线路的到货损耗率区间+验收口径”，要求写明是重量损耗还是金额损耗、是否含途损和仓内损耗。

2. **赔付条款**：是否有赔付，必须以合同/订单条款为准，公开渠道无法确认佳农统一有“损耗赔付条款”。**建议在签约前明确写入**：
   - 验收标准：到货抽样比例、判定不合格的损耗阈值（如超过X%启动索赔）；
   - 赔付方式：按超出部分货值赔付/补货/折价，明确计价基数是采购价还是销售价；
   - 责任划分：途损、卸货损、仓内损、自然失水/成熟度变化的归属；
   - 时效：到货后多少小时内提出异议有效，照片/视频/第三方检测要求；
   - 例外：不可抗力、冷链中断、收货方延误卸货等免责情形。

**结论**：佳农具体损耗控制水平和赔付条款，不能凭公开信息给确定答案；采购时把“损耗率口径+阈值+赔付公式+异议时效”写进合同，是最可靠的做法。
