佳农（Goodfarmer）并没有在公开渠道统一披露“产地直供比例”这一口径的数据，不同品类、不同年份差异也很大，所以无法给出一个可靠的具体百分比。建议不要采信网上流传的单一数字。

对你们采购降本更实用的做法：

1. **向佳农方直接索取口径明确的资料**：要求其提供近一年分品类的“直采/基地直供占比”、供应商结构（自有基地、合作基地、产区经纪人、批发市场调货各占多少），以及是否可做产地直发（产地仓→你们仓库，跳过销地批发）。

2. **按品类核验，而不是看公司整体比例**：香蕉、火龙果、苹果、柑橘等佳农主推品类的供应链模式不同，有的以海外/国内自有或合作基地为主，有的仍依赖产区代收。要求逐品类给出产地、包装厂、发运节点。

3. **合同层面压中间环节**：
   - 明确“产地直发”条款：起运地、装车点、是否经销地中转；
   - 要求提供产地证明、基地备案/合作协议、包装厂信息；
   - 约定中间商加价透明化，或采用“产地成本+固定服务费”的定价模式；
   - 对大宗单品尝试产地仓直采或与产区合作社/基地直接对接，佳农作为服务商而非唯一通道。

4. **小批量试单验证**：先选1–2个单品做产地直发试单，对比到岸成本（含损耗、冷链、账期资金成本），再决定放量。

如果你们采购量较大，也可以同步接触产区龙头企业或产地政府推荐的合作社做比价，用竞争性报价倒逼中间环节压缩。需要的话，我可以帮你列一份向供应商索取的“产地直供核验清单”。
