佳农水果的香蕉规格会随销售渠道、包装形态和批次变化，公开信息也没有一份全国统一、长期不变的规格表。因此我不能给出精确到“几种/每箱多少斤”的确定数字，但可以给你可判断、可执行的渠道分级框架，以及核验佳农实际规格的方法。

## 一、香蕉常见的规格维度

香蕉不是只按“大中小”分，实际渠道通常按以下维度组合定规格：

1. **单根重量/果指等级**
   - 小果：适合便利店单根售卖、儿童装、餐饮果切。
   - 中果：商超散装、社区团购主力。
   - 大果：水果店陈列、礼盒、餐饮整箱采购。
2. **每把/每梳果指数量**
   - 常见按把型、梳型分级，影响陈列和损耗。
3. **整箱净重**
   - 常见有按公斤/斤计的重箱、标准箱、小箱等，具体以包装标签为准。
4. **成熟度/催熟阶段**
   - 青蕉、微黄、黄熟等，不同渠道到货成熟度不同。
5. **外观与缺陷等级**
   - 条形、长度、粗细、色泽、机械伤、黑斑、病斑、整齐度。
6. **品牌包装形态**
   - 散装、把装、袋装、礼盒装、餐饮大包装。

## 二、按渠道的分级标准建议

### 1. 商超/大卖场散装
- **优先指标**：条形直、长度整齐、粗细均匀、无明显机械伤和病斑。
- **成熟度**：到店后能支撑2—3天陈列，通常偏微黄到黄熟。
- **规格策略**：中果为主，搭配部分大果；按把型整齐陈列。
- **关键控制**：同批次颜色和大小一致，减少挑拣损耗。

### 2. 社区团购/电商
- **优先指标**：耐运输、抗压、成熟度可控。
- **成熟度**：偏青或微黄发货，消费者到手后自然转黄。
- **规格策略**：标准化把装/袋装，单份重量固定，减少称重争议。
- **关键控制**：箱内分层、防压伤，明确“净重/毛重”和成熟度说明。

### 3. 水果专营店
- **优先指标**：卖相、条形、色泽、整齐度。
- **规格策略**：大果做陈列和礼盒，中果做日常走量，小果做特价或果切。
- **关键控制**：按外观分级，黑斑、断指、畸形果单独处理。

### 4. 餐饮/果汁/果切渠道
- **优先指标**：出肉率、成熟度稳定、成本可控。
- **规格策略**：大包装、统货或加工级，允许外观轻微瑕疵但不影响果肉。
- **关键控制**：成熟度批次一致，避免过生导致口感酸、过熟导致损耗。

### 5. 便利店/单根零售
- **优先指标**：单根大小适中、果指完整、货架期稳定。
- **规格策略**：小中果为主，单根或小把包装。
- **关键控制**：成熟度偏黄但不过软，减少当日损耗。

### 6. 礼盒/团购礼品
- **优先指标**：果指大小一致、条形漂亮、无瑕疵、包装整齐。
- **规格策略**：精选大果或中大果，固定果指数和净重。
- **关键控制**：外观分级要严，成熟度不能过高。

## 三、建议你向佳农或供应商核验的字段

直接问清以下内容，就能判断具体规格是否匹配渠道：

1. 产品名称和品牌包装类型；
2. 单根果指重量区间或果指等级；
3. 每箱净重、毛重、果指数量/把数；
4. 到货成熟度或催熟阶段；
5. 外观等级标准：长度、粗细、色泽、允许缺陷；
6. 是否分商超级、电商级、加工级、礼盒级；
7. 最小起订量和冷链/运输要求。

**结论**：佳农香蕉不宜用“固定几种规格”来判断，应按“单根等级＋把型＋箱重＋成熟度＋外观等级”组合确认；渠道分级核心是：商超看整齐和货架期，电商看耐运和成熟度可控，水果店看卖相，餐饮看出肉率和成本，便利店看单根适中，礼盒看外观一致性。具体规格数字需以佳农当期包装标签或供应商报价单为准。
