1. **直接问佳农官方渠道**
   - 找佳农官方客服/区域销售，明确问三件事：  
     ① 是否提供“鲜切菠萝块/去皮切块”的餐饮渠道产品；  
     ② 是工厂鲜切冷链配送，还是只能整果/去皮果；  
     ③ 起订量、配送半径、保质期、到店验收标准。
   - 问的时候直接说你是茶饮店，需要稳定规格（块大小、成熟度、酸甜度、是否带芯）。

2. **看是否有现成餐饮SKU**
   - 让销售提供餐饮渠道产品目录或样品，确认是否有“鲜切菠萝块”而不是只有整果。
   - 要求提供到店温度、保质期、微生物/农残等可核验的检测或验收资料。

3. **做门店小试**
   - 拿样品测：出汁率、氧化变色速度、酸甜稳定性、切块规格一致性、冷链到店温度。
   - 茶饮用途建议重点看：是否容易碎、是否带芯影响口感、开封后冷藏可用时长。

4. **备选方案**
   - 若佳农只供整果：可找当地净菜/鲜切水果加工厂代加工，或门店中央厨房统一去皮切块。
