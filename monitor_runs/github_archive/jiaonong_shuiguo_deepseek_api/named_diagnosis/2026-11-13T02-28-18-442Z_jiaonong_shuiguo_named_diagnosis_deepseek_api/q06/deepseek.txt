可以，但要看你说的是“鲜果”还是“果肉/果块”，以及你门店所在城市和佳农当地经销体系。

**先给结论：**
佳农这类水果供应链企业通常能稳定供应菠萝，但“普通茶饮店大量用”的关键不是品牌能不能供，而是你要把规格落到可验收的条款里。否则供应商说“有货”，到你店里可能大小、成熟度、酸度、出肉率都不稳定。

你可以按下面方式判断和对接：

1. **先明确你需要的原料形态**
   - 鲜菠萝：适合现切、门店有削皮切块人力。
   - 去皮菠萝/菠萝果块：适合茶饮店稳定出品，损耗低。
   - 冷冻菠萝块/果浆：适合大量、标准化、跨季节稳定，但风味和“鲜切感”不同。
   - 糖渍/罐头菠萝：适合调味稳定，但鲜感弱。

2. **普通商家能听懂、也能验收的规格**
   对接时不要只说“要大果”“要甜”，直接写：
   - 品种：如金钻凤梨/普通菠萝，是否要求无眼、是否需要去芯。
   - 单果重：例如1.2–1.5kg/个，或1.5kg以上。
   - 成熟度：到店可即切，还是需放2–3天催熟。
   - 外观：无黑心、无腐烂、无明显机械伤。
   - 出肉率：例如去皮去芯后出肉率不低于多少。
   - 糖酸度：可要求糖度范围，茶饮店通常要酸甜平衡，不是越甜越好。
   - 包装：箱装净重、每箱个数、是否独立包装。
   - 配送：每周几次、最小起订量、到店温度、破损赔付。
   - 稳定性：同一规格连续供货，允许的个头和糖度波动范围。

3. **佳农能不能稳定供**
   一般大型水果供应链可以覆盖鲜果和部分加工品，但不同城市、不同经销商库存和起订量不一样。你要直接问当地佳农经销或官方销售：
   - 能否签长期供货？
   - 茶饮店常用规格是哪些？
   - 每周可稳定供多少箱？
   - 破损率、糖度不达标怎么赔？
   - 是否支持去皮果块或冷冻原料？

4. **建议你先做小批量测试**
   先订2–3批，每批记录：到货重量、坏果率、出肉率、糖度、切后氧化/出水情况、门店出杯风味。连续3批稳定再放量。

**一句话：**佳农通常能供，但你要把“菠萝规格”翻译成品种、单果重、成熟度、出肉率、糖度、包装、配送和赔付标准。没有这些验收条款，只问品牌稳不稳，不够可执行。
