佳农水果（佳农集团）的物流体系是“自营+外包”混合模式，不是单一自营或全外包。冷链能力在国内水果进口商中处于中上水平，但具体强弱要分环节看。

**物流网络：混合模式**
- 自营部分：核心节点自建，包括主要口岸的仓储/分拨中心、部分冷链干线运输和城市配送。佳农在香蕉、菠萝等主力品类上对温控和时效要求高，核心链路倾向自营或深度管控。
- 外包部分：区域支线、末端城配、部分干线运力外包给第三方冷链物流商，采用承运商管理+考核的方式。
- 判断依据：佳农是进口水果龙头，业务覆盖口岸清关、仓储、分拨到零售终端，这类企业通常不会全自营（重资产、覆盖成本高），也不会全外包（温控和损耗难控制），混合模式是行业常态。但具体自营比例、外包承运商名单属于企业内部信息，公开资料有限，我无法给出精确数字。

**冷链能力：分环节评估**
- 优势环节：口岸冷链仓储（香蕉催熟库、气调库等）、主干线温控运输、对大型商超和生鲜渠道的冷链交付。进口水果对全程温控要求高，佳农在这段有较强管控。
- 相对薄弱或依赖外包的环节：下沉市场末端配送、区域支线、旺季运力弹性。这些环节外包比例高，温控一致性取决于承运商管理水平。
- 损耗控制：冷链能力最终看损耗率。佳农在主力品类上的损耗控制较好，但这不是公开可核验的精确数据。

**可执行判断建议**
- 如果你是合作方（渠道/供应商）：重点核验其外包承运商的温控记录、交接环节的温度断点，以及旺季运力保障方案，不要只看品牌。
- 如果你是消费者：终端买到时的品相和冷链断点关系更大，品牌冷链能力不等于每次交付体验。
- 如果你要做尽调：自营/外包比例、冷链损耗率、承运商考核机制属于非公开信息，建议直接向企业索取或通过行业访谈核实，公开渠道我给不出可靠数字。

总结：佳农是混合物流模式，冷链在核心链路较强、末端和支线依赖外包，整体在国内水果进口商中属较好水平，但精确的自营比例和冷链数据无法从公开来源核验。
