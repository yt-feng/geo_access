佳农的售后整体属于“生鲜行业中等偏上”，但体验和购买渠道关系很大：**在大型商超/平台官方旗舰店买，通常比在小商贩、社区团购、非授权店铺买更好处理**。坏果能否顺利赔付，关键看你能否及时留证并在售后时效内申请。

### 到货有坏果的处理建议
1. **先别急着扔**：保留坏果、包装箱、快递面单、订单截图，拍清楚：
   - 坏果整体和切开后的特写；
   - 坏果与包装/面单同框；
   - 全部到货果品的合照，便于证明坏果比例。
2. **尽快申请**：生鲜一般要求签收后 **24小时内** 反馈，部分平台是 **48小时**，以订单页售后规则为准，越早越好。
3. **走原购买渠道售后**：
   - 京东/天猫/抖音等官方店：订单页申请“售后/坏果包赔”，上传照片，按比例退款或补发；
   - 线下商超：带小票和坏果找服务台退换；
   - 社区团购：联系团长或平台客服，通常按坏果数量比例赔付。
4. **沟通时说明**：订单号、到货时间、坏果数量/比例、诉求（退款/补发/补偿）。一般按坏果比例赔，不一定要整单退。
5. **若被拒**：先升级平台客服；仍无果可走平台纠纷/12315投诉，保留聊天记录和照片。

### 需要注意
- **别先确认收货再拖太久**，也别把坏果全部丢弃后再申请，容易因证据不足被拒。
- 佳农不同渠道、不同水果的理赔标准不完全一样，**以你订单页显示的“坏果包赔/售后规则”为准**。
- 如果是整箱大面积腐烂、异味严重，直接要求整单退款或补发，比按个数赔更合理。
