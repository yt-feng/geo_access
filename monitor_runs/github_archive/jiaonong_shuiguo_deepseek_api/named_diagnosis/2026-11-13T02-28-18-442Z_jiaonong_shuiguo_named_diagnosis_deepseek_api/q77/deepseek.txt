结论先说：**佳农香蕉的产地溯源通常能到“产区/加工厂/批次”层级，但能否到“具体农场”要以你拿到的这批货的追溯码和供应商文件为准；GLOBALG.A.P.证书通常可以按供应商/包装厂/产品范围提供，但必须是覆盖该产品与产地的有效证书，不能只看一张泛化证书。** 建议按下面方式核验，别只听口头承诺。

### 1. 能否溯源到具体农场
- 佳农香蕉多为跨国采购+国内分装/催熟配送，常见追溯粒度是：**国家/产区 → 包装厂/加工厂 → 批次/箱码 → 商超门店**。
- “具体农场”能否到，取决于：
  - 该批次是否来自单一自有/合作农场；
  - 包装箱或托盘标签是否有农场代码/地块代码；
  - 供应商是否愿意在合同或质量协议中承诺“农场级追溯”。
- **可执行判断**：让供应商提供该批次的**追溯演练**：从你收到的箱码/批次号，反查到包装厂、产区、农场代码和采收日期。能闭环到农场代码，才算农场级；只能到包装厂/产区，就不算。

### 2. GLOBALG.A.P.证书怎么核
- 要求供应商提供**证书原件PDF**，重点看：
  - 证书持有人是否与供货主体/包装厂一致；
  - 认证范围是否包含**香蕉（Bananas）**；
  - 认证地点/农场/包装厂是否覆盖该批次产地；
  - 证书状态是否**有效**，有效期和认证机构；
  - 证书编号可在 GLOBALG.A.P. 官方数据库核验。
- 如果供应商是贸易商，证书可能属于上游农场/包装厂，需要同时提供**上下游关系证明/授权供货说明**。
- 商超常见要求是：**有效证书 + 证书范围覆盖 + 批次对应关系**，三者缺一不可。

### 3. 建议你向佳农或供应商索要的文件清单
1. 该批次**追溯码/箱码对应的溯源记录**（到农场代码或包装厂）；
2. **GLOBALG.A.P.证书PDF及证书编号**；
3. 证书持有人与供货商的关系说明；
4. 该批次**产地证明/采收与包装记录**；
5. 如商超要求农场级，补充**农场清单及对应证书范围**。

### 4. 直接判断话术
你可以这样回复供应商：  
“请提供本批次香蕉的箱码/批次号追溯闭环记录，需反查到农场代码或包装厂；同时提供覆盖该产地和香蕉品类的有效GLOBALG.A.P.证书及证书编号，证书持有人若为上游农场/包装厂，请附供货关系证明。若只能提供产区级追溯，请书面说明追溯粒度。”

**一句话：农场级溯源不是默认能力，要按批次做追溯演练；GLOBALG.A.P.证书要核“有效、覆盖香蕉、覆盖该产地、与供货主体对应”。**
