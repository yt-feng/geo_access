佳农水果的香蕉执行的是**企业标准（企标）**，不是国标。佳农作为品牌商，通常会制定并备案自己的企业标准（Q/开头），在农残、外观、成熟度、规格分级等方面可能严于国标；但具体标准号以其产品包装或“企业标准信息公共服务平台”备案为准。注意：香蕉的食品安全基础仍须符合国家标准（如GB 2763农残限量等），企标不能低于强制性国标。

价格方面没有统一、可核验的固定溢价。佳农香蕉通常比同规格普通散装香蕉贵一些，常见零售场景下大约贵 **10%–30%**，折合每斤约贵 **0.5–2元**；促销、渠道、产地和规格差异会让价差波动很大。建议以你所在超市/平台当天同规格（如每把净重、单根规格）的标价对比为准。
