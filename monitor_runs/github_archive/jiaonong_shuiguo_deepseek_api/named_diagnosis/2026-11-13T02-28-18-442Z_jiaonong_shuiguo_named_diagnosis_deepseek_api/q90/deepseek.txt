1. **先查官方渠道**  
   - 佳农官网/官方公众号/官方客服，问“冷冻菠萝丁”是否有货、是否面向餐饮渠道。
   - 让销售提供：产品名称、配料表、净重、包装规格、丁粒尺寸（mm）、是否加糖/糖水、冷冻方式（IQF单体速冻还是整块冻）、保质期和解冻出水情况。

2. **茶饮店重点确认的参数**  
   - **丁粒尺寸**：常见冷冻果丁有 8×8mm、10×10mm、15×15mm 等，但佳农具体是否有这些规格需以厂家回复为准。茶饮吸管/果肉口感一般偏 8–10mm 更稳，做果肉顶料可用 10–15mm。
   - **是否加糖**：纯冻果丁和糖渍冻丁影响配方糖度，优先选无添加糖或明确糖度款。
   - **包装规格**：餐饮常用 1kg/袋、2kg/袋、10kg/箱等，但需厂家确认。
   - **解冻表现**：茶饮店要看出水率、是否软烂、是否易堵吸管。
   - **供货稳定性**：能否长期稳定供货、最小起订量、冷链配送范围。

3. **如果佳农没有或规格不合适**  
   可同步问：佳农鲜切菠萝丁（冷藏短保）、其他餐饮供应链品牌冷冻菠萝丁、本地冷冻水果经销商。先要样品做3件事：解冻出水测试、加冰摇杯测试、吸管通过测试。
