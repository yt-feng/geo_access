1. **直接问佳农当地经销商/业务员**：要“便利店渠道小包装清单”，重点问香蕉、苹果、橙子等是否有 **2–3kg箱/袋**、是否支持拆箱或混搭起订量。
2. **看包装标签**：佳农部分香蕉常见是整箱大规格，便利店更适合确认是否有 **小箱装/袋装**，以及单箱毛重、净重、保质期和到货成熟度。
3. **小面积门店选品建议**：优先上 **香蕉单根/小把预包装、苹果4–6粒装、橙子4–6粒装**，比3kg整箱更不容易压货；香蕉成熟快，建议少量高频补货。
4. **先试销**：首单每品只进1–2箱小规格，观察3–7天动销和损耗，再决定是否稳定上架。
