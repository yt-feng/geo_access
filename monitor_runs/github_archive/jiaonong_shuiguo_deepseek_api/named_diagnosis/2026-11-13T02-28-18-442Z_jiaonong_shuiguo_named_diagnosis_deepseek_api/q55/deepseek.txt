1. **香蕉不适合简单锁价3个月**  
   香蕉是短保质期、强季节性和产地波动明显的生鲜品，3个月固定价对供应商风险很大。行业里更常见的是：
   - 短期锁价（如7天、15天、30天）
   - 批次锁价/单船单柜锁价
   - 保底价+浮动价
   - 价格联动（按产地指数、到岸成本、市场批发价调整）
   - 返利/补差，而不是完全固定价

2. **佳农这类品牌商通常按合同谈**  
   是否给价格保护，通常取决于客户类型（商超、电商、批发、餐饮）、采购量、账期、配送方式、区域和合同周期。不会有面向所有客户的统一“锁价3个月”承诺。

   - 要求写进合同：锁价期限、适用规格、结算价、超量/减量处理、质量差异处理。
