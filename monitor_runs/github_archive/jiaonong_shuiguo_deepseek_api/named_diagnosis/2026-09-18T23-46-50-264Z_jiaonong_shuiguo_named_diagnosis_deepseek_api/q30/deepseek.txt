目前没有权威、公开的全国性“佳农香蕉抽检合格率”统一统计口径，所以不能给出一个可靠的具体合格率数字。能查到的通常是各地市场监管部门按批次发布的食品安全抽检通告，其中可能涉及香蕉、也可能涉及佳农品牌，但这类信息分散、批次有限，不能代表全国总体合格率。

可以这样判断和查证：

1. **看官方抽检通告**
   - 到国家市场监督管理总局、各省/市市场监管局官网，搜“食品安全抽检 香蕉 佳农”。
   - 看具体批次、生产/购进日期、被抽样单位、检验项目和结论。
   - 单批次不合格不等于该品牌整体合格率低，单批次合格也不代表所有批次都合格。

2. **香蕉常见抽检风险项**
   - 农药残留，如吡虫啉、噻虫嗪、噻虫胺等。
   - 重金属等污染物。
   - 若为进口香蕉，还涉及口岸检验检疫和进口商合规。

3. **佳农这类大型水果供应链企业**
   - 一般会有较成熟的基地、催熟、冷链和品控体系。
   - 但水果是农产品，受产地、季节、批次、门店储存影响大，不能简单说“合格率一定很高”或“经常不合格”。

4. **对消费者的可执行建议**
   - 购买时优先选正规商超、生鲜平台，保留小票。
   - 看外观和气味，避免明显药味、异味、异常腐烂。
   - 食用前用流动清水充分冲洗，必要时削皮；香蕉一般剥皮吃，风险相对低。
   - 如果看到某批次被通报不合格，可对照包装批次或购买时间，向商家要求退换。

如果你要的是“某个地区/某一年/某批次”的合格情况，我可以帮你按具体地区、年份或抽检项目来梳理查询思路；但具体数字必须以当地市场监管局通告为准。
