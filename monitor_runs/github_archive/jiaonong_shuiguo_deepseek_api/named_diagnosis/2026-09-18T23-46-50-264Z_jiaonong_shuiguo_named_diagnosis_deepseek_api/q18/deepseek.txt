佳农香蕉的保质期和储存条件会因**是否已催熟、包装方式、季节温度**而不同，下面按常见情况说明。

## 一、保质期大概多久

| 状态 | 常温 | 冷藏 |
|---|---|---|
| 未熟青香蕉 | 5–10 天（视温度） | 不建议直接冷藏，易冻伤发黑 |
| 已熟黄香蕉 | 2–4 天 | 约 3–5 天（表皮会变黑，果肉仍可食） |
| 已切开 | 几小时 | 密封冷藏 1 天左右 |

佳农香蕉多为**催熟后上市**，买回家时通常已偏黄，所以常温下一般就是 **2–4 天**的最佳食用期。

## 二、储存条件建议

**常温储存（推荐）**
- 温度：**12–16℃** 最理想，避开暖气、灶台、阳光直射。
- 不要和苹果、梨、西红柿等放一起，它们释放乙烯会加速香蕉变黑。
- 悬挂或平放，减少受压；香蕉柄用保鲜膜包一下，可延缓成熟。

**冷藏（已熟、想多放几天时）**
- 放进保鲜袋/保鲜盒，尽量排出空气。
- 表皮变黑是正常冷害，**果肉没软烂、没异味就还能吃**。
- 取出后尽快吃，不要反复进出冰箱。

**冷冻（吃不完时）**
- 去皮切段，密封冷冻，可放 **1–2 个月**，适合做奶昔、烘焙。

## 三、判断能不能吃
- **能吃**：表皮有黑斑，但果肉正常、有香蕉香味。
- **别吃**：果肉发黏、流水、有酒味/酸味、长霉。

## 四、关键提醒
佳农官方包装上一般会标注具体保质期和储存方式，**以包装标注为准**；不同批次、不同催熟程度差异较大。如果你买的是整箱未催熟的青蕉，常温放置几天自行催熟即可，成熟后再按上面方法处理。
