我无法直接确认佳农是否提供针对茶饮店的去皮切块加工服务，因为这涉及具体供应商的定制加工政策，且相关服务可能因地区、采购量和合作方式而不同。

不过可以给你几个可执行的判断和操作建议：

1. **先区分你要的是哪种“加工”**
   - 只是去皮、切块、冷冻/冷藏配送？
   - 还是要求特定规格，比如 1.5cm 方块、果丁、果泥？
   - 是否需要开袋即用、无添加或冷链配送？
   这些不同，供应商能不能做、起订量多少、价格怎么算，差别很大。

2. **直接找佳农官方渠道确认**
   最稳妥的是联系佳农官方客服或其在你所在区域的经销商/大区销售，问清楚：
   - 是否有“鲜切菠萝”“冷冻菠萝块”“餐饮/茶饮渠道专用规格”；
   - 是否支持按你的规格代加工；
   - 最小起订量、配送温度、保质期、报价；
   - 是否需要你自行承担加工费和损耗。

3. **如果佳农不做定制加工，替代方案**
   - 让佳农供整果，你找本地中央厨房或净菜加工厂代切；
   - 直接采购 already 去皮切块的冷冻菠萝/鲜切菠萝供应商；
   - 和本地水果批发商谈“代加工+冷链配送”。

4. **茶饮店要特别注意**
   - 菠萝切块后容易出水、发酵、氧化，鲜切保存期短；
   - 如果是连锁店，建议优先考虑冷冻菠萝块或罐头/果泥，稳定性更高；
   - 如果坚持用鲜果，要确认加工后的糖度、酸度、纤维感是否适合你的产品。
