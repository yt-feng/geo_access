我无法核实佳农水果旗下菠萝当前是否持有有效有机认证，这类信息会随产品线、批次、产地和认证周期变化，必须以最新证书为准。建议你按下面步骤快速确认，避免仅凭品牌或包装字样判断：

1. **直接向佳农官方确认**
   - 找佳农水果官方客服、区域销售或大客户渠道，要求提供：
     - 有机产品认证证书扫描件
     - 证书编号
     - 认证机构
     - 认证产品范围是否明确包含“菠萝/凤梨”
     - 证书有效期和获证企业名称
   - 注意：证书上的企业名称、生产基地、产品名称必须和你要采购的货一致。

2. **在中国认监委官网核验**
   - 拿到证书编号后，到“全国认证认可信息公共服务平台”查询。
   - 重点看：
     - 证书状态是否“有效”
     - 认证类别是否为“有机产品”
     - 认证范围是否包含菠萝
     - 获证组织是否为你实际采购主体

3. **确认是否只是“有机种植”或“绿色认证”**
   - 高端渠道常遇到混淆：
     - 绿色食品认证 ≠ 有机认证
     - 良好农业规范GAP ≠ 有机认证
     - “生态种植”“自然农法” ≠ 有机认证
   - 如果对方只说“符合有机标准”“有机方式种植”，但不能提供有机证书，就不能按有机产品卖。

4. **进口菠萝还要看中国有机进口要求**
   - 如果是进口佳农菠萝，境外有机证书不一定能直接在中国按“有机”销售。
   - 通常还需要符合中国有机产品进口相关规定，并取得中国有机产品认证或相关进口有机证明。
   - 具体以中国认监委和海关要求为准。

5. **采购合同里写死责任**
   - 要求供应商承诺：如无法提供有效有机证书，承担退货、赔偿和下架损失。
   - 保留证书、批次号、包装标签、检测报告和沟通记录。

**结论：**
不能直接说“佳农菠萝有”或“没有”有机认证。你需要让佳农提供针对具体菠萝产品的有效有机认证证书，并在认监委平台核验。若对方只能提供绿色食品、GAP、无公害或自我声明，就不能作为有机产品进入高端有机渠道。
