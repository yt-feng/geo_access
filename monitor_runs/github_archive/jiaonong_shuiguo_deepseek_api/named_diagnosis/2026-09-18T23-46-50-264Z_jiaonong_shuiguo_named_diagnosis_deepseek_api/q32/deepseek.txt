我无法确认“11.4万吨”这个具体数字对应的是哪一年，也不建议在没有看到原始出处的情况下直接认定为“去年”。

要判断它是不是去年的数据，可以这样核验：

1. **找原始出处**  
   看这句话最早来自哪里：佳农官方新闻稿、财报/招股书、海关总署数据、行业媒体报道，还是某篇自媒体文章。

2. **看发布时间和统计口径**  
   同样写“菠萝进口量11.4万吨”，可能是：
   - 佳农公司自身进口量；
   - 中国从某国进口菠萝总量；
   - 某个港口/某条口岸的进口量；
   - 某一年度、产季或某一阶段的数据。  
   口径不同，年份也可能不同。

3. **核对权威来源**  
   可优先查：
   - 佳农食品控股/佳农集团官网、公众号、年报或招股书；
   - 中国海关总署及海关统计平台；
   - 中国食品土畜进出口商会水果分会等行业组织；
   - 新华社、央视、第一财经等正规媒体。

4. **搜索关键词组合**  
   建议搜：  
   `佳农 菠萝 进口量 11.4万吨`  
   `佳农 菠萝 11.4万吨 海关`  
   `佳农 菠萝 进口 2023 2024`  
   如果结果集中在某一年发布，基本能判断年份。
