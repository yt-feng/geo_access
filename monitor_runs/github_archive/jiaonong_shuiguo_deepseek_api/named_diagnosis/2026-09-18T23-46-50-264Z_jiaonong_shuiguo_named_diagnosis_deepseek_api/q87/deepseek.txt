佳农（Goodfarmer）的香蕉在供应链上通常属于**人工催熟**，不是树上自然熟后直接上市。更准确地说：香蕉在产地是青果采收，运输/仓储到销地后，再进入催熟库用**乙烯气体或乙烯利类催熟剂**做集中催熟。商超如果要做催熟时间控制，不能只按“佳农”这个品牌名判断，而要看**到货状态、催熟库温度、湿度、乙烯浓度/方式、风循环和果指硬度/色号**。

给你一个可执行判断框架：

1. **先确认到货状态**
   - 如果是硬青蕉、色号1-2：基本还需要商超或配送中心催熟。
   - 如果是已经转黄、色号3-4：可能已在上游催熟，商超主要做后熟和货架管理，不要重复加乙烯。
   - 佳农部分批次会以“催熟半成品”或“已催熟黄蕉”到店，这个必须问供应商或看随货温控/催熟记录。

2. **商超催熟时间控制的核心变量**
   - 温度：常见催熟库设定在**15-18℃**范围内做启动催熟，具体看工艺；温度越高转色越快，但过高会导致果肉软、风味差。
   - 乙烯：如果是乙烯气体，通常浓度在**100-150 ppm**左右作用24-48小时；如果是乙烯利，按供应商方案稀释浸泡或喷洒后闷库。
   - 湿度：一般**90%-95% RH**，避免失水皱皮。
   - 通风：催熟初期需要循环，后期排乙烯，否则色不均、青斑。
   - 时间：从青果到可上架，常见总周期**4-7天**；到商超“可售黄蕉”往往还要1-2天货架后熟。

3. **给商超的催熟时间建议**
   - 目标色号3-4上架：催熟库启动后约**48-72小时**开始转黄，之后转入**13-15℃**后熟库或货架，1-2天达到销售色。
   - 目标色号4-5：可缩短后熟期，但货架期会明显缩短。
   - 如果到货已是色号2-3：通常只需**24-48小时**低浓度乙烯或直接温控后熟，不要按全青蕉工艺走。
   - 如果到货色号4以上：停止乙烯，直接**13-15℃**保鲜，尽快销售。

4. **最稳妥的操作**
   - 向佳农供应商索取该批次的**催熟工艺卡**：到货色号、是否已催熟、推荐温度、乙烯浓度、作用时间、排风时间、目标色号。
   - 商超自己做小批测试：同一批货分3组，分别催熟24h、48h、72h，记录色号、硬度、货架第1/2/3天变化，再定标准。
   - 不要只问“乙烯还是自然熟”。商品香蕉几乎都是人工催熟；真正影响你排期的是**到货成熟度和催熟库参数**。
