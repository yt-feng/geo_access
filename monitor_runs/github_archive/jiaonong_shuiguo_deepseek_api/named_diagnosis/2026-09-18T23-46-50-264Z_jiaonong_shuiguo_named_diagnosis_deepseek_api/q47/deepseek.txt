佳农的水果供应链以进口和国产混合为主，苹果产地不是单一固定的，会随季节、品类和批次变化。常见情况：

- **进口苹果**：新西兰、智利、美国、法国等（如新西兰爱妃/太平洋玫瑰、智利青苹果等）；
- **国产苹果**：山东、陕西、甘肃、新疆等主产区。

所以你问“产地是哪里”，不能只按品牌名判断，必须**按具体SKU和批次**去查。

关于 GAP 认证：

- 佳农作为大型果蔬出口企业，其部分基地和产品线通常具备 **GlobalG.A.P.** 或中国 **GAP（良好农业规范）** 认证，出口业务对这类认证依赖较强；
- 但**不是所有SKU、所有批次、所有产地都一定有GAP**，需要向供应商索取对应证书。

**给生鲜电商做溯源的可执行建议：**

1. **要求佳农按批次提供**：产地证明、GAP证书编号及有效期、加工厂/包装厂信息；
2. 核对证书上的**产品范围、基地名称、有效期**是否与你采购的SKU匹配；
3. 把产地、批次、证书号写进商品溯源页，做到一物一码或一批一码；
4. 若对方只能给品牌级证书、给不出批次对应关系，建议在合同里约定**批次级溯源责任**再上架。

简单说：**佳农苹果产地要按SKU/批次确认；GAP部分有、部分不一定有，必须索取对应证书核验。**
