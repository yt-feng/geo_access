佳农（Goodfarmer，通常指佳农食品控股/上海佳农）的生鲜水果业务，账期没有公开统一标准，属于“按客户、按品类、按合作规模、按渠道”一单一议的商务政策。因此无法给出一个对外可核验的固定“最长账期”数字。

**能确定的是：**
- 佳农以B2B批发、商超、电商、餐饮等渠道为主，账期通常由销售/大客户部门根据客户资质审批，不是公开申请制。
- 生鲜品类资金占用大、损耗和价格波动高，供应商对账期普遍偏谨慎，新客户尤其如此。

**关于“新客户首单30天账期”：**
- 直接申请30天账期，首单通过的概率通常较低。很多生鲜供应商对新客户首单要求**款到发货、现款现货或预付定金**，合作稳定后才逐步给账期。
- 如果新客户是大型商超、连锁餐饮、头部电商平台等强信用主体，30天账期是有可能谈下来的，但一般需要走合同、授信和风控审批，不是默认政策。
- 中小新客户首单拿到30天账期的可能性较小；更常见的是先款后货，或首单短账期（如7天、15天），再根据回款记录和采购量调整。

**如果你想推进，建议这样问和谈：**
1. 直接联系佳农对应品类/区域的销售负责人，问清该客户类型当前的授信政策。
2. 准备能证明资质的材料：营业执照、近半年流水、其他供应商合作账期记录、采购量预测。
3. 谈判时不要只提“30天”，可以给方案：首单现款或部分预付，第二单起15天，稳定后30天。
4. 如果对方坚持首单现款，可以争取“首单现款+次单起账期”或“预付30%+货到30天付尾款”。

**结论：**
- 佳农水果的“最长账期”没有公开答案，需向其对口的销售/大客户部门确认，取决于客户资质和合作规模。
- 新客户首单直接申请30天账期，**不是标准政策，成功率偏低**；若是强势渠道客户可以谈，中小客户更可能被要求现款或短账期。
