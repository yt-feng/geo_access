**1. 佳农大概率具备的基础能力**
佳农是国内大型香蕉进口商/供应商之一，通常有产地、催熟、冷链和全国分仓体系。对连锁餐饮客户，**专人对接（客户经理/大客户经理）**在达到一定采购量后一般是可以谈的；**专车配送**则取决于区域仓、距离、单次吨位和配送频次，不一定默认提供。

**2. 是否能给你专车+专人，关键看这几个条件**
- **月采购量/单次采购量**：专车通常有最低起送吨位，比如单次几吨到十几吨不等，低于这个量往往走共同配送。
- **配送区域**：如果你在佳农有仓或合作物流覆盖的城市，专车更容易；偏远区域可能加价或无法承诺。
- **配送频次**：每天/隔天固定班次比临时补货更容易谈到专车。
- **温控要求**：香蕉对温度敏感，专车是否能带温控、是否和别的货混装，要写清楚。
- **催熟状态**：你们要的是青蕉、微熟还是即用熟蕉，这会影响它从哪个仓、用什么车发。

**3. 你直接去谈时，建议这样问**
不要只问“能不能专车专人”，要让它给明确承诺：
- 我们月用量约 __ 吨，单次约 __ 吨，配送城市是 __，能否固定专车？
- 专车是否温控？温度区间多少？混装还是单独？
- 专人对接是销售还是客服？响应时间多久？缺货/质量异常谁处理？
- 是否签保供协议？断供、延误、成熟度不达标怎么赔？
- 报价是否含专车费？起送量多少？临时加单怎么算？

**4. 更稳的做法**
如果佳农不能在所有区域都给专车，建议：
- **主供佳农 + 备选一家区域香蕉催熟商**，避免单一依赖。
- 要求佳农在**核心城市仓**做专车，边缘门店走区域分拨。
- 先小范围试跑 2-4 周，重点看：到货成熟度一致性、破损率、迟到率、专车是否真的专车。
