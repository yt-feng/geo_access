**2. 可靠性要分等级看**
- **最可靠**：企业年报/招股说明书、官方公告、双方联合发布的签约新闻，这类有法律责任约束。
- **较可靠**：行业协会官网、政府或展会主办方公示的获奖名单。
- **需谨慎**：企业官网和公众号的自我宣传、经销商转发、短视频文案，常有“最佳”“金奖”等模糊表述，未必能对应到具体产品和年份。
- **基本不可靠**：来源不明的自媒体榜单、无主办方、无评选标准的“十大品牌”之类。

**3. 你可以这样核验**
- 看到奖项，先查**颁奖机构**是否真实存在、是否有评选公示；
- 看到客户案例，看是否有**客户方同步发布**的信息，而不是只有佳农单方面说；
- 核对**时间、产品规格、具体渠道**，越具体越可信；
- 用企业信用信息公示系统、行业协会官网、主流财经媒体交叉验证。
