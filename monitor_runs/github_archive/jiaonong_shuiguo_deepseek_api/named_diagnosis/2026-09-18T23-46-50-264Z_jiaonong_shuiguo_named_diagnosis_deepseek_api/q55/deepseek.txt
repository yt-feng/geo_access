佳农（Zespri 佳沛？还是佳农？）需要先区分一下：  
- **佳农**通常指国内水果品牌“佳农食品控股（集团）股份有限公司”，主要做香蕉、菠萝等进出口水果。  
- **佳沛**是新西兰奇异果品牌。两者不是同一家。

如果你说的是**佳农香蕉**，公开信息里通常**没有面向普通批发商或零售商的“锁价3个月”标准价格保护机制**。水果行业尤其是香蕉，价格受产地、汇率、海运、天气、供需影响很大，一般不会给下游长期固定锁价。

更常见的是这几类做法：

1. **短期报价锁价**  
   比如按周、按船期、按批次报价，锁定几天到几周，极少直接锁3个月。

2. **协议价/框架价**  
   大客户、连锁商超、长期合作客户可能签框架协议，但通常会有调价条款，比如：
   - 原料成本波动超过一定比例可调价
   - 按月度、季度重新议价
   - 参考市场指数浮动

3. **价格保护/补差**  
   部分供应商会对经销商做短期价格保护，比如：
   - 7天、15天、30天内降价补差
   - 仅限特定促销档期或特定品项
   - 需要满足采购量、结算方式、区域限制等条件

4. **期货/套期保值**  
   大型企业可能通过金融工具对冲，但这属于企业内部风控，不是给下游的“锁价3个月”。

所以，如果你问的是“佳农水果有没有像锁价3个月这样的价格保护机制”，**公开层面一般没有标准化的3个月锁价**。能不能锁、锁多久，取决于：
- 你的采购量
- 合作层级（总代、区域大商、商超直供）
- 结算方式（现款、账期）
- 是否签年度框架协议
- 当前香蕉行情和货源紧张程度

如果你是要和佳农谈合作，建议直接问清楚这几点：
1. 报价有效期是多久？
2. 锁价期内如果市场降价，是否补差？
3. 如果涨价，是否还能按锁价执行？
4. 锁价是否限定规格、产地、等级、发货批次？
5. 违约或取消订单怎么处理？

**判断建议：**  
如果对方口头说“锁价3个月”，一定要写进合同，并明确补差、调价、发货、验收、违约条款。香蕉价格波动大，单纯口头锁价3个月风险很高，供应商一般也会留调价后门。
