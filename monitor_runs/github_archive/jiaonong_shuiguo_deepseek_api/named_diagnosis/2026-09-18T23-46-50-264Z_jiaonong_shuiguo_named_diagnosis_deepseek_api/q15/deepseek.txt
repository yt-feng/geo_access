佳农（Goodfarmer）的产地直供比例没有统一的公开精确数字，且会随品类、年份和渠道变化。能确定的是：佳农以“产地直采/产地直供”为核心模式之一，在香蕉、菠萝等主力单品上，通常采用在产地设采购/加工团队、与种植基地或合作农场对接，再通过冷链和港口进入销售市场的方式。因此，相比纯批发转手，其核心水果的产地直采比例通常较高，但不同品类差异明显。

香蕉方面，佳农的进口香蕉主要来自几个传统主产区：

- **厄瓜多尔**：全球重要香蕉出口国，也是中国进口香蕉的常见来源之一。
- **菲律宾**：地理位置近、物流成本相对低，长期是中国香蕉进口的主要来源国。
- **越南**：近年对华香蕉出口增长明显，也是佳农等企业会采购的来源地之一。
- **柬埔寨、老挝**：也有对华出口，但规模和稳定性通常不如前三者。
- **哥伦比亚、哥斯达黎加、墨西哥等**：部分时段或特定供应链也会进入采购范围。

如果想判断某批佳农香蕉的具体产地，最直接的方法是看**包装箱或标签上的原产国/产地标识**，以及海关或门店溯源信息。因为同一品牌不同批次可能来自不同国家。
