佳农（Goodfarmer）作为国内头部水果进口与分销企业，其到货损耗率**并没有一个对外统一公布的官方标准**。公开渠道能查到的通常是行业惯例和企业内部考核指标，而非佳农官方披露的确切数字。因此需要把"行业区间"和"佳农情况"分开看，避免把行业值当成佳农的确切数据。

**行业通常的参考区间**

到货损耗率（从产地/港口到国内仓库或配送中心这一段的损耗）因品类差异极大：

- **耐储品类**（如苹果、橙、猕猴桃、火龙果等）：一般在 **2%–5%**，管理好的水平可压到 3% 以内。
- **易损品类**（如香蕉、葡萄、草莓、车厘子等）：到货损耗常在 **5%–10%**，运输或温控出问题时更高。
- **全链路损耗**（含仓储、分拣、门店）通常高于单纯到货损耗，综合可达 **8%–15%**，易损果更高。

**关于佳农的判断**

佳农主营香蕉、菠萝、火龙果、猕猴桃等，其中香蕉是核心品类。作为规模化企业，其内部到货损耗考核通常比行业平均更严，香蕉这类品类一般希望控制在**个位数偏低的水平（大致 3%–7% 区间）**，但这是基于行业惯例的推断，不是官方数字。

**建议**

如果你需要准确数字用于合同、采购或考核：

1. 直接向佳农的业务对接人索取其**内部质量/损耗考核标准**；
2. 或按你实际对接的**具体品类**去谈，因为香蕉和苹果的合理损耗目标完全不同；
3. 在合同里约定**到货验收的损耗计算口径**（按重量、按箱、按金额），否则"损耗率"这个词双方理解可能不一致。
