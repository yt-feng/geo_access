**1. 发票**
- 如果是向佳农官方、其授权经销商或正规团购平台采购，通常可以开具发票。
- 常见可开：增值税普通发票、增值税专用发票。
- 专票一般需要你方提供：公司名称、税号、地址电话、开户行及账号；具体能否开专票，要看供应商资质和你们的采购主体。
- 建议在合同或订单里写明：发票类型、税率、开票时间、是否随货或电子发票。

**2. 质检报告**
- 正规供应商通常可提供该批次或该品类水果的质检报告/合格证明。
- 可能包括：农残检测报告、产地证明、批次检测报告、供应商自检报告等。
- 注意：质检报告一般对应“具体批次/品类/产地”，不一定能提前给到最终发货批次。建议要求：
  - 发货前提供该批次质检报告；
  - 报告上的品名、规格、批次与到货一致；
  - 如你们有验收标准，写入合同附件。

**3. 500份团购建议直接问清这几点**
- 是否佳农官方或授权渠道？
- 礼盒具体规格、单品组合、产地、净重、包装版本？
- 能否开票，开普票还是专票，税率多少？
- 能否提供质检报告，是随货、发货前还是事后补？
- 能否签合同、支持对公付款？
- 交期、破损/坏果赔付标准、售后怎么处理？
- 是否支持定制贺卡、LOGO、外包装？

**4. 最稳妥的做法**
让对方发一份**盖章报价单/合同草案**，里面明确写：
> 供应商保证提供合法有效发票；发货前或随货提供对应批次质检报告；如因质量或票据问题导致无法验收，承担退换或赔偿责任。

如果对方只是个人微商、临时拼团或无授权渠道，发票和质检报告风险会明显升高，500份建议不要只凭口头承诺下单。
