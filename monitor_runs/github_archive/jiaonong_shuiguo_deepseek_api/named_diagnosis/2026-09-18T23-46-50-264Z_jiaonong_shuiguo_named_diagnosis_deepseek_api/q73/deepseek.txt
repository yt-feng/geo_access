佳农水果的苹果品类通常以进口和国产精品苹果为主，常见会覆盖红富士、嘎啦、青苹果等，但具体在售品类和包装规格会随产季、批次和渠道变化，建议以佳农官方渠道或当期报价单为准。

就你提到的两个品类，常见产地情况是：

1. **进口嘎啦**
   - 常见产地：**新西兰、智利、南非、美国**等。
   - 其中新西兰嘎啦在南半球产季较常见，智利、南非也常作为进口嘎啦来源。

2. **进口红富士**
   - 红富士本身起源于日本，但商业化进口红富士常见产地包括：**新西兰、美国、智利、南非**等。
   - 如果是“进口红富士”，需要确认对方报的是原产国还是仅品牌/发货地；有些渠道会把国产红富士与进口红富士混在一起销售。

采购时建议你直接向佳农或授权经销商确认这四项：
- **原产国**：具体是新西兰、智利、美国还是其他国家；
- **品种名**：是 Gala、Fuji 还是其他商业名称；
- **规格**：果径、单果重、箱规、等级；
- **产季与到港批次**：进口水果同一品种不同产季产地会切换。

如果你要的是稳定采购，建议让供应商提供：原产地证明、报关单、植检证和当期包装标签照片，这样能准确判断是不是你要的进口嘎啦和进口红富士。
