建议你按下面方式快速确认，基本 10 分钟内能有结论：

1. **找官方渠道确认**
   - 佳农官网/官方公众号/官方客服电话
   - 京东/天猫“佳农官方旗舰店”客服
   - 直接问：有没有**速冻菠萝丁/冷冻菠萝丁**，是**IQF单体速冻**还是整块冷冻。

2. **重点问清这几个规格**
   - 丁径：常见有 **5×5×5mm、8×8×8mm、10×10×10mm** 等，茶饮多用 **8mm 或 10mm**
   - 包装：常见 **1kg/袋、2.5kg/袋、10kg/箱** 等
   - 是否加糖：**原味无糖 / 糖渍 / 糖水**
   - 固形物含量：如果是糖水型，要问固形物比例
   - 成熟度/糖度：Brix 大概多少
   - 解冻后状态：是否易碎、出水多不多
   - 保质期和储存：-18℃ 冷冻，保质期一般 12–24 个月
   - 起订量和供货：最小起订箱数、是否冷链到店

3. **茶饮店使用建议**
   - 优先选 **IQF 速冻、无糖或轻糖、8–10mm 丁**
   - 如果做冰沙/果茶，8mm 更合适；如果做装饰或嚼感，10mm 更明显
   - 先拿样测试：解冻出水、风味、是否发酸、是否有纤维渣

4. **如果佳农没有**
   可以同步问这些渠道：
   - 安佳、雀巢等餐饮供应链经销商
   - 本地冷冻水果批发商
   - 欢乐家、田野、鲜果 time 等冷冻果料供应商
   - 1688 上搜“冷冻菠萝丁 IQF”，但一定要先要检测报告和样品
