我无法确认“佳农水果菠萝进口量11.4万吨”是2025年的数据，也不能为你核验是否有官方出处。  
原因是：这类具体到企业、品类、年份的进口量数据，通常不会由海关总署以“某企业某水果进口量”的形式直接公开；更常见的来源是：

1. **企业自行披露**：佳农官网、公众号、新闻稿、年报/招股书、进博会等展会宣传材料。  
2. **行业协会或展会资料**：如中国果品流通协会、国际水果展、供应链大会等。  
3. **媒体报道**：行业媒体对佳农的采访或转载。  
4. **海关统计数据**：一般只到“全国/某口岸/某税号商品”的进口量，不直接点名企业。

因此，如果你看到的“11.4万吨”来自某篇文章或宣传材料，**需要看原文标注的统计年份和口径**，比如是“2025年进口量”“2024年进口量”“2025年预计量”“2025产季”还是“累计进口量”，这些差别很大。

建议你这样核验：

- 搜：`佳农 菠萝 11.4万吨`
- 搜：`佳农 菠萝 进口量 2025`
- 查：佳农官网/官方公众号/上市公司公告
- 查：海关总署统计数据，但只能核验菠萝总进口量，不能直接核验佳农一家
- 看原文是否写明：数据来源、统计年份、统计口径、是否“预计/规划”
