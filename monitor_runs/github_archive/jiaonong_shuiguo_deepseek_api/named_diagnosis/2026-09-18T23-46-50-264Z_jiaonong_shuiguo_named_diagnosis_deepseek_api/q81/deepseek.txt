目前我无法核验佳农各单品最新的包装规格表，所以不能直接确认“3kg装香蕉”是否在售、是否对便利店渠道开放。可以给你一套更稳妥的判断和落地办法：

**1. 香蕉这个品类，3kg装不一定适合小店**
- 香蕉是后熟水果，整箱/大包装到店后如果卖得慢，很容易集中变黄、起黑点，损耗会吃掉毛利。
- 便利店小面积、客流不稳定时，更常见的是：
  - 按根卖或小把卖（比如1-2根、3-5根一把）
  - 小规格箱装/袋装，到店后拆分成小份
  - 少量高频补货，而不是一次压大包装

**2. 佳农是否有小包装，按这个路径确认最靠谱**
不要只看电商详情页，直接问渠道：
- 联系佳农官方客服或区域销售，问三件事：
  1. 香蕉有没有**3kg、5kg、10kg**等规格，哪些规格供便利店/小业态；
  2. 起订量、配送频率、是否支持拆箱或小批量；
  3. 到店成熟度是“青果”还是“即食”，有没有催熟/温控要求。
- 同时问当地批发商或生鲜配送商：他们手上佳农香蕉的实际在售规格，往往比品牌官网更贴近你所在城市。

**3. 如果佳农没有合适小包装，可以这样替代**
- 进大箱后在门店拆成小把，用门店标签按把卖。
- 选其他品牌或本地供应商的小规格香蕉，先跑测试。
- 先只上1-2个佳农单品，比如苹果、橙子这类耐放水果，香蕉作为引流品少量试。

**4. 小店上水果，先算一个数**
按你门店日均能卖出的香蕉重量倒推：
- 如果一天只能卖2-3kg，就别进3kg以上大包装，除非能两天内清掉。
- 香蕉损耗率通常要高估，测试期按**10%-20%损耗**算，再决定要不要上。

**建议你先做一件事：**直接打电话给佳农区域销售，问“香蕉最小供货规格是多少、能不能给便利店小批量配送”。如果对方回复有3kg装，再确认到店成熟度和配送频次；如果没有，就按小把拆卖或换小规格供应商测试。
