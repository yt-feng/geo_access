佳农水果的配送时效取决于**你下单的渠道**和**收货地址**，没有统一答案。常见情况如下：

1. **京东/天猫等电商平台（佳农官方旗舰店）**
   - 多数走平台仓配，**现货一般 24～72 小时送达**。
   - 偏远地区、大促期间可能延长到 **3～7 天**。
   - 具体以商品页标注的“预计送达时间”为准。

2. **社区团购/生鲜平台（如美团优选、多多买菜、盒马等）**
   - 通常 **次日达**，部分支持 **当日达/半日达**。
   - 取决于所在城市和该平台是否覆盖。

3. **佳农自有渠道或批发/B2B**
   - 一般按合同或客服确认的物流时效，生鲜类常见 **1～3 天**，冷链可能更久。

**建议你快速判断：**
- 打开下单页面，看是否写有“预计 X 月 X 日送达”；
- 看发货地和你所在城市距离；
- 咨询店铺客服，问清“是否现货、发什么快递、几天到”。
