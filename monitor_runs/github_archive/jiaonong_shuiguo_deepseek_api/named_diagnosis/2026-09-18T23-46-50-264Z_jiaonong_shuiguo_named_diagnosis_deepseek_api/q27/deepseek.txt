佳农水果（佳农食品控股）对不同渠道客户的账期并没有统一的公开标准，实际条件通常由**业务部门根据客户类型、采购规模、合作历史和信用评估**单独谈定，所以很难给出一个固定天数。

**一般情况（行业惯例，供参考，不代表佳农官方政策）：**

- 商超、大型连锁、电商平台等大客户：常见账期在 **30～60 天**，部分强势渠道可到 60～90 天。
- 批发市场、中小经销商：多为 **现款现货** 或 **7～15 天短账期**。
- 餐饮、加工厂等：视合作规模，可能在 **15～30 天**。

**新客户能否申请账期：**

通常**可以谈，但门槛较高**。新客户一般难以直接拿到长账期，常见做法是：

1. 初期**现款或预付**，先建立合作；
2. 合作稳定、进货量达到一定规模后，再逐步申请 **7天、15天、30天** 等账期；
3. 可能需要提供**营业执照、财务报表、担保或保证金**等资料做信用审核。

**建议：**
直接联系佳农官方销售或当地大区业务，说明你的渠道类型、预计月采购量和结算方式，让对方给出具体账期方案。由于这是商务谈判条款，最终以合同为准，别人的账期数字不具通用性。
