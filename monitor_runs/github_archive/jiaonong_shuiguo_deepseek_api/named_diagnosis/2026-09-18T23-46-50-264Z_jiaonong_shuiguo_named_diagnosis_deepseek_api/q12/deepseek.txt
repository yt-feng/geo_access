佳农水果的香蕉规格和渠道分级，通常按**重量/根数、成熟度、外观等级、包装形式**来分，不同年份、不同产地（菲律宾、厄瓜多尔、越南等）和不同客户定制会有差异。下面给你一套**行业通用+佳农常见做法**的参考框架，方便你判断和对接。

## 一、常见规格维度

### 1. 按单根重量/条重
- **小条**：约 90–120g/根  
- **中条**：约 120–150g/根  
- **大条**：约 150–180g/根  
- **特大条**：180g以上/根  

佳农出口和内销常按“条重区间”分级，而不是单纯按长度。

### 2. 按每箱净重
- **4.5kg/箱**
- **5kg/箱**
- **7kg/箱**
- **10kg/箱**
- **13kg/箱**
- **18kg/箱**（多见于批发流通）

### 3. 按每箱根数
- **18–20根/箱**
- **20–24根/箱**
- **24–28根/箱**
- **28–32根/箱**
- 也有按“把”或“梳”包装的，如 **5–6把/箱**

### 4. 按成熟度
- **青蕉**：适合长途运输、催熟后销售
- **微黄**：适合短途配送、门店催熟
- **黄熟**：适合即食、电商、水果店当日销售

## 二、按渠道的常见分级标准

### 1. 高端商超/精品水果店
- 要求：条重均匀、果形直、无黑斑、无机械伤、无药害
- 常见规格：**中条/大条，5–7kg/箱，20–24根**
- 成熟度：青蕉或微黄，到店后统一催熟
- 等级：通常相当于 **一级/精品级**

### 2. 电商/社区团购
- 要求：耐运输、成熟度可控、单根外观整齐
- 常见规格：**4.5–5kg/箱，小条到中条，18–24根**
- 成熟度：青蕉或微黄，避免运输中过熟
- 等级：**一级或二级**，允许轻微外观瑕疵但不影响食用

### 3. 批发市场/农贸流通
- 要求：性价比高、耐存放、损耗低
- 常见规格：**10–18kg/箱，中条到大条，根数不严格**
- 成熟度：青蕉为主
- 等级：**二级/统货**，允许轻微擦伤、果形不齐

### 4. 餐饮/烘焙/果汁加工
- 要求：成熟度高、糖度稳定、成本低
- 常见规格：**大条或统货，10–18kg/箱**
- 成熟度：黄熟或过熟
- 等级：**加工级**，不强调外观

### 5. 出口渠道
- 要求：符合进口国农残、检疫、冷链标准
- 常见规格：**13kg/箱、18kg/箱，按条重和根数分级**
- 成熟度：青蕉，冷藏运输
- 等级：通常分 **Class I / Class II**，或客户定制标准

## 三、佳农常见的分级逻辑

佳农作为品牌供应商，通常会按以下顺序分级：

1. **产地初选**：按条重、果形、病虫害、机械伤初分  
2. **加工厂复选**：去劣、修把、定重、定根数  
3. **按渠道定级**：
   - 商超/精品：一级，外观优先
   - 电商：一级/二级，耐运优先
   - 批发：二级/统货，成本优先
   - 加工：加工级，成熟度优先
4. **包装标识**：箱体标注净重、根数、产地、等级、成熟度

| 渠道 | 推荐规格 | 条重 | 成熟度 | 等级 |
|---|---|---|---|---|

| 电商团购 | 4.5–5kg/箱，18–24根 | 小/中条 | 青蕉/微黄 | 一级/二级 |

## 五、注意
- 佳农不同批次、不同产地的规格会调整，**没有全国统一固定表**。
- 如果你是要采购或做渠道对接，最稳妥的是直接向佳农当地销售索要 **当季产品规格书/报价单**，上面会有净重、根数、条重、成熟度、等级和包装方式。
- 如果是做门店分级，建议以 **条重+外观+成熟度** 三项为主，净重和根数作为辅助。
