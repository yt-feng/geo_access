## 1. 香蕉相关的“国标/行标”是什么
香蕉在国内主要参照的不是一个单一“国标”，而是这几类：

- **食品安全基础**：GB 2762（污染物）、GB 2763（农药残留）等，这是强制底线，任何企业标准都不能低于它。
- **产品分级/质量**：如香蕉的农业行业标准（NY/T 类）、鲜果等级规格类标准，规定外观、成熟度、果指长度、缺陷允许度等。
- **流通/贮运**：采收成熟度、催熟、冷链、贮藏条件等。

也就是说，“国标”是**底线要求**，企业标准通常是**在底线之上叠加更细、更严的质量和分级要求**。

## 2. 企业标准“比国标高”通常体现在哪
如果佳农确实有备案的企业标准，它高一般高在这些方面（也是判断依据）：

- **农残限量更严**：不少出口导向/品牌企业对某些农药设的自控限量低于 GB 2763。
- **分级更细**：果指长度、单果重、梳型、色泽、成熟度均匀度，按更高等级收。
- **缺陷允许度更低**：机械伤、疤痕、黑点、青黄比例卡得更死。
- **一致性和溯源**：批次一致性、产地/基地、催熟工艺、冷链温度记录。
- **采后处理**：催熟剂使用、预冷、包装、运输时限有明确SOP。

这些确实可能“高于国标”，但**高的是产品质量和商品性，不等于食品安全一定更安全**——食品安全这块是国家强制底线，企业再高也是加分。

## 3. 怎么自己核验（最可靠）
1. 上**“企业标准信息公共服务平台”**（qybz.sacinfo.org.cn），搜“佳农”或“上海佳农”等主体名称，看备案的香蕉/鲜果标准号。
2. 找到标准号后，看它的**技术指标表**，逐项对比：
   - 农残：对比 GB 2763
   - 污染物：对比 GB 2762
   - 分级/外观：对比相应 NY/T 或等级规格
3. 看标准发布主体是不是佳农关联公司，注意区分“佳农食品”“佳农果蔬”等不同法人。

## 4. 我的直接结论
- **标准是什么**：无法核实，不能给你具体编号。
- **是否比国标高**：如果存在备案企标，通常是“在企业自控的质量/分级/农残内控上高于国标底线”，但**不能一概说所有指标都比国标高**。
- **买香蕉时更该看**：外观、成熟度、无异味霉变，以及是否有可追溯渠道；企业标准高低和最终到手品质不完全划等号。
