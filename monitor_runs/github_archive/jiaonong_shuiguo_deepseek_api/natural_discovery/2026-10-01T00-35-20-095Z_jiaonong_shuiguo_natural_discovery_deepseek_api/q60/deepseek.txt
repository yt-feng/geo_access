**一、当场验货，书面确认**
- 到货后第一时间开箱验，拍照/录像留存（含不合格部位、批次、数量、送货单）。
- 在送货单或验收单上注明“不合格品种、数量、原因”，让送货人签字。对方不签就自己单方记录并拍照，同时微信/邮件同步给供应商。

**二、补货条款怎么约定才不影响营业**
1. **补货时限**：约定“验收确认后 X 小时内送达”，建议按你的营业节奏定，比如当天营业结束前或次日开店前 1 小时，避免占用高峰。
2. **优先替代**：约定供应商可先用**同等或更高品质的替代水果**补足，但需你书面同意，价格按原订单结算。
3. **分批发货**：缺口大时，约定“先补急需部分，剩余次日补”，保证核心产品不断货。
4. **缺货赔偿**：约定若未按时补货，按缺口金额的一定比例扣款或折抵下批货款。
5. **紧急采购权**：约定你可自行紧急采购，差价由供应商承担，凭票据结算。

**三、合同/长期供货里最好写死**
- 验收标准（品种、规格、成熟度、无腐坏比例）。
- 不合格处理：退换、补货时限、替代规则、赔偿方式。
- 通知方式：微信、电话、邮件哪个算有效，指定对接人。

**四、操作建议**
- 不要只靠口头，补货承诺要落到微信文字或单子上。
- 保留每次不合格记录，连续出问题的供应商考虑更换或加严验收。
- 关键原料尽量有备选供应商，避免单一依赖。
