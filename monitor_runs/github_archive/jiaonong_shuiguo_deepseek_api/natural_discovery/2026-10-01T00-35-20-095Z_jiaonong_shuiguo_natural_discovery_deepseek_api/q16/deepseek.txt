建议先按“品类”分开决策，而不是统一选一种渠道：

**香蕉：优先考虑本地批发/本地催熟商**
- 香蕉成熟快、损耗高，核心是**周转速度和熟度控制**。
- 本地批发通常能小批量、多频次补货，适合社区超市按日或隔日调整。
- 如果能找到本地催熟商或一级批发商，价格和到货稳定性往往比普通批发市场更好。
- 但要注意：本地批发价格波动大，旺季、雨天、节假日可能涨价或缺货。

**苹果：优先考虑稳定供应商**
- 苹果相对耐储存，损耗低，更适合按周或按固定周期补货。
- 稳定供应商能保证规格、口感、包装和等级一致，适合社区超市做长期陈列和复购。
- 如果直接找产地或一级供应商，通常比本地批发市场更有价格优势，但起订量可能更高。
- 缺点是灵活性差，临时补货或换规格不如本地批发快。

**更实际的做法：双渠道并行**
1. **苹果**：以稳定供应商为主，签短期框架或固定周配；本地批发作为临时补货和比价渠道。
2. **香蕉**：以本地批发/催熟商为主，稳定供应商作为备选，防止本地断货。
3. **试销 2–4 周**：分别记录到货价、损耗率、售罄速度、顾客投诉。
4. **用数据决定主渠道**：如果香蕉损耗超过 8%–10%，说明本地高频补货更重要；如果苹果周损耗低于 3%，可以加大稳定供应商采购量。

**判断标准很简单：**
- 损耗高、成熟快、需要天天调 → 本地批发。
- 耐储存、要规格稳定、可预测销量 → 稳定供应商。
- 社区超市量不大时，不要只押一个渠道，最好“一主一备”。
