餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找**稳定、能小批量、能按你的时间送、坏果能赔**的渠道。可以按下面优先级选：

1. **本地水果批发市场里的固定档口**
   - 适合：每天用量不大，但要求新鲜、品种可调。
   - 做法：找2-3家档口，固定一家主供、一家备用。
   - 谈清楚：几点前下单、几点送到、起送量、坏果怎么补、临时加单能不能接。
   - 优点：比平台便宜，能看货，能换品种。
   - 缺点：需要你早起或专人对接，档口质量波动要盯。

2. **本地生鲜配送公司/餐饮供应链公司**
   - 适合：最省心，想要线上下单、定时配送、开票。
   - 关键词：本地生鲜配送、餐饮供应链、食堂配送、果蔬配送。
   - 优点：有小程序/APP，售后相对规范，能开发票。
   - 缺点：价格通常比批发市场高5%-15%，起送门槛要看。
   - 适合每天少量但不想自己跑市场的店。

3. **美团快驴、美菜、锅圈等餐饮B2B平台**
   - 适合：有稳定菜单、用量可预估。
   - 优点：下单方便，配送稳定，售后有流程。
   - 缺点：小店少量可能起送不够、价格不一定低、品质看区域仓。
   - 建议：先试一周，重点看准时率、坏果率、缺货率。

4. **周边水果店/精品超市长期合作**
   - 适合：每天只要几斤，急用补货。
   - 做法：和店长谈长期价，固定时间送。
   - 优点：灵活、近、临时补货快。
   - 缺点：成本偏高，品种受店内库存限制。

5. **产地/一级批发直供**
   - 适合：单品用量大，比如只做西瓜、柠檬、金桔。
   - 不适合：每天少量、品种杂的店，因为起订量高、物流损耗大。

**最省心的组合建议：**
- 主供应商：本地生鲜配送公司或批发市场固定档口。
- 备用供应商：周边水果店或第二个档口。
- 下单方式：前一天晚上发清单，第二天早上固定送到。
- 验收标准：重量、成熟度、坏果率、品种规格写清楚。
- 结算方式：月结或周结，留好对账单。

**筛选供应商时重点问这7个问题：**
1. 最少起送多少？每天少量送不送？
2. 几点下单、几点到店？
3. 坏果、烂果、缺斤少两怎么赔？
4. 临时加单或减单截止到几点？
5. 能不能固定品种和成熟度？
6. 能不能开票？
7. 价格是随行就市，还是每周报价？

**建议先试跑2周：**
- 第1周同时试2家，每天记录：到货时间、坏果率、缺货次数、实际单价。
- 第2周把主供留给最稳的，另一家做备用。
- 不要只盯单价，算上损耗和人工后，稳定供应商往往更省钱。
