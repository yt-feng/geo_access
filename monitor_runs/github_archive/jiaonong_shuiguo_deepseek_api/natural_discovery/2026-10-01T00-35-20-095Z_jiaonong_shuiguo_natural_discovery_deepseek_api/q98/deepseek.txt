判断水果供应商的合规和稳定性，可以从下面几个维度入手，建议把它们做成一套可核查的清单，每次评估供应商时逐项打分。

## 一、合规性核查（资质与法律风险）

1. **主体资格**
   - 营业执照经营范围含"食品销售/农产品销售"，且在有效期内。
   - 若涉及预包装或分装，需《食品经营许可证》；只卖初级农产品（未经加工的鲜果）通常只需营业执照，但以当地市场监管口径为准。
   - 要求提供许可证原件扫描件，并在"国家企业信用信息公示系统"核对真伪。

2. **食品安全相关**
   - 有农残检测报告（自检或第三方），能提供批次对应的报告，而不是一张通用报告长期复用。
   - 有进货查验记录和索证索票制度，能追溯每一批水果的来源。
   - 若供应的是"无公害/绿色/有机"产品，需有对应认证证书，并核对证书编号。

3. **信用与涉诉**
   - 查"中国执行信息公开网"看是否是被执行人。
   - 查企业信用信息公示系统看是否有行政处罚、经营异常。
   - 有条件可查裁判文书网，了解是否有食品安全相关诉讼。

4. **合同合规**
   - 合同里明确：质量标准、验收方式、不合格退换货、食品安全责任、违约金。
   - 约定抽检不合格时的赔付与终止条款，把风险写进合同而不是口头承诺。

## 二、稳定性评估（供货能力与抗风险）

1. **货源基础**
   - 是否有稳定的产地或一级批发渠道，还是纯粹"倒手"。
   - 是否自有或长期合作的冷库、运输车辆。
   - 旺季、淡季、极端天气时能否保证供应。

2. **履约历史**
   - 要求提供近半年服务过的同类客户（尤其是医院、学校、养老院等集体食堂）作为参考，并可电话回访。
   - 看合作时长，合作超过1-2年且续约的，稳定性通常较好。

3. **配送能力**
   - 有无冷链或保鲜运输；水果对温度敏感，尤其夏季。
   - 配送频次、到货时间是否稳定，能否应对临时加单。
   - 是否具备分拣、按需定量包装的能力。

4. **财务与经营**
   - 注册资本、成立年限、是否频繁变更法人或地址，这些是稳定性的信号。
   - 是否过度依赖单一客户（可侧面了解）。

## 三、可执行的落地做法

1. **建立供应商准入档案**：每户一档，放齐营业执照、许可证、检测报告、合同、回访记录。
2. **首批小批量试供**：先试1-2周，观察到货准时率、损耗率、退换货响应。
3. **设定量化考核**：到货准时率、验收合格率、退换货及时率、投诉次数，按月打分，连续不达标即约谈或淘汰。
4. **准备备选供应商**：至少保留2家合格供应商，避免单一依赖导致断供。
5. **定期复审**：每半年或每年重新核验资质和检测报告，资质过期要提前提醒更新。

## 四、需要特别提醒的坑

- **只有一张"合格证"或口头承诺**，不能替代批次检测报告。
- **报价明显低于市场价**，往往在质量或计量上找补，食堂场景风险更大。
- **资质借用、挂靠**：签约主体和实际供货人不是同一家，出问题难以追责，签约时要核对送货人身份。
- **检测报告张冠李戴**：报告上的品名、批次、日期要和实际到货对应。

如果场景是养老院或医院，老人和患者属于敏感人群，建议在合同里额外约定更高的农残标准和更严的退换货时限，并把供应商纳入食堂的食品安全追溯体系。
