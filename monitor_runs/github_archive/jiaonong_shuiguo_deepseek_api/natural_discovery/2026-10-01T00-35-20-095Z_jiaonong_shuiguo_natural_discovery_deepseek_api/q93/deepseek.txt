核心结论：**先保安全与合规，再谈配送频次；三者中“保质期管理”优先级最高，“包装”决定保质期能否成立，“配送频次”是支撑前两者的运营手段。**

便利店卖菠萝切块（鲜切水果）属于高风险短保食品，判断优先级如下：

1. **保质期（最高优先级）**
   - 鲜切菠萝通常建议冷藏，保质期很短，很多便利店按 **当天制作、当天售完** 或 **24小时内** 管理。
   - 必须明确标注：制作时间、保质期截止时间、贮存条件。
   - 超过时限必须下架报废，不能靠“看起来没坏”继续卖。
   - 这是食品安全和监管风险的核心，出问题最严重。

2. **包装（第二优先级）**
   - 包装直接影响氧化、汁液渗漏、微生物污染和保质期。
   - 应使用食品级、密封性好的容器或覆膜，冷藏陈列。
   - 包装上要有标签：品名、制作日期时间、保质期、贮存条件、售价等。
   - 如果包装不当，即使配送再频繁，也容易出现发酸、变色、出水、污染。

3. **配送频次（第三优先级，但影响损耗和鲜度）**
   - 配送频次决定门店补货节奏和库存周转。
   - 频次高，可以少备货、降低过期损耗，但增加物流成本。
   - 频次低，容易一次配太多，卖不完就报废，或者为了少报废而冒险延长售卖。
   - 所以配送频次是“运营优化项”，不是第一安全项。

**可执行建议：**
- 先定标准：冷藏温度、制作后保质期、下架时间。
- 再定包装：密封、防漏、标签齐全。
- 最后定配送：根据门店销量做小批量、多频次补货，比如每天1—2次，销量小的店甚至按需制作。
- 门店执行关键：先进先出、定时检查、到点下架，不要靠感官判断。

一句话：**保质期是红线，包装是保障，配送频次是降损提效手段。顺序不能反。**
