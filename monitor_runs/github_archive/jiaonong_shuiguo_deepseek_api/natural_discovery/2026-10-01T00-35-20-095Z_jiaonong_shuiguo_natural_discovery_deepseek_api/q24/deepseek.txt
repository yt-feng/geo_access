如果超市采购担心水果农残抽检，向供应商要资料时，建议按“资质证明 + 检测报告 + 批次溯源 + 承诺文件”四类准备，重点看**是否覆盖你实际采购的品种、批次和日期**。

**一、供应商基础资质**
1. 营业执照  
2. 食品经营许可证或食品生产许可证（视供应商类型）  
3. 若供应商是农产品生产企业/合作社：产地证明、种植基地信息、统一社会信用代码等  
4. 若为进口水果：入境货物检验检疫证明、海关报关单等

**二、农残检测报告**
要求供应商提供：
1. **第三方检测机构出具的农残检测报告**  
   - 最好有 CMA 或 CNAS 标识  
   - 报告中的检测项目应覆盖常见农残，如有机磷、氨基甲酸酯、拟除虫菊酯等  
2. **报告对应批次**  
   - 报告上的样品名称、生产日期/采摘日期、批次号，要与你采购的批次一致  
3. **报告时效**  
   - 不要只看一份长期通用报告，最好按批次或按供货周期提供  
   - 叶菜、浆果等高风险品类，建议每批次或高频次提供  
4. **检测结论**  
   - 明确写“合格”或“符合 GB 2763 食品中农药最大残留限量”  
   - 有检出但未超标的，也要看数值是否在限量内

**三、批次溯源资料**
1. 供货单/送货单：写明品种、数量、产地、采摘或包装日期、批次号  
2. 产地信息：具体到县/乡镇/基地，不要只写“某省”  
3. 包装标识或标签照片  
4. 若供应商从批发市场采购，要求其提供上游进货凭证和对应检测信息

**四、承诺与责任文件**
1. 质量安全承诺书：承诺不销售农残超标水果  
2. 供货合同中的质量条款：明确农残超标责任、退换货、赔偿、抽检不合格处理  
3. 若供应商无法提供批次检测报告，可要求其签署“批批检”或“先检后供”承诺，并把检测费用和责任写清

**五、采购现场可操作的判断标准**
- 报告日期太早、批次对不上：视为无效  
- 只有复印件且模糊、无检测机构章：要求重新提供  
- 报告项目太少，只测 1—2 项：风险较高，要求补测  
- 供应商拒绝提供批次报告：建议不纳入合格供应商或降低采购优先级  
- 高风险水果：草莓、葡萄、豇豆、芹菜、韭菜、柑橘类等，建议提高抽检频次

**六、建议你直接向供应商发的清单**
可以这样写：
1. 营业执照、食品经营/生产许可证  
2. 本批次水果的第三方农残检测报告（CMA/CNAS，含批次号）  
3. 本批次送货单、产地证明、采摘/包装日期  
4. 质量安全承诺书  
5. 若为进口水果，提供入境货物检验检疫证明  
6. 后续供货能否做到“批批附检测报告”或“定期送检”

核心原则：**不要只要一份“通用报告”，要能对应到你采购的具体品种、具体批次、具体日期。** 这样农残抽检时，你才有可追溯、可举证的资料链。
