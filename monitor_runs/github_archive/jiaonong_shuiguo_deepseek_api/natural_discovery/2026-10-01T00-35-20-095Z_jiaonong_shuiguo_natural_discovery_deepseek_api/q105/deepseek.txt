水果采购锁价，实际能锁多久，没有统一标准，主要看品类、供应商类型和当时的行情。大致可以这样判断：

**常见锁价周期**
- **鲜果、时令水果**：一般 **1～4周**，最长通常不超过 **1个月**。因为采摘期、天气、到货量变化快，供应商很少愿意长期锁。
- **进口水果**：通常 **2周～2个月**，取决于船期、汇率、产地行情。海运周期长，部分供应商可配合做月度或季度框架。
- **大宗/耐储存品类**（如苹果、梨、橙、部分冻果）：**1～3个月** 较常见，行情平稳时能谈到季度。
- **冻果、果浆、罐头类原料**：**3～6个月**，甚至更长，因为受鲜果短期波动影响小。

**影响锁价时长的关键因素**
1. **行情趋势**：预期涨价时，供应商不愿长锁；预期跌价时，供应商反而愿意锁。
2. **采购量和稳定性**：量大、长期稳定拿货，议价能力强，能锁更久。
3. **付款方式**：预付、现款现货比账期更容易换到长锁价。
4. **品类标准化程度**：规格、等级、糖度、产地越明确，越容易锁。
5. **是否有保底量或浮动机制**：纯固定价难，带条件的锁价更容易谈成。

**实操建议**
- 不要追求“一价锁到底”，更现实的是 **锁基价 + 浮动条款**，比如：
  - 价格锁定，但数量有保底；
  - 超过一定涨跌幅（如±5%～10%）再重新议价；
  - 锁价期内分批次提货，约定提货节奏。
- 锁价协议里写清楚：**规格等级、产地、包装、交货期、提货量、涨跌处理、违约条款**。
- 对鲜果类，建议 **短周期滚动锁价**（如按周或按半月），比一次性锁几个月更稳。
- 可以同时锁 **2～3家供应商**，分散行情波动和断供风险。

**结论**
一般鲜果谈 **2～4周** 比较现实；耐储或冻品可谈 **1～3个月甚至更长**。真正能锁多久，取决于你的采购量、付款条件和当时的行情走势，不是固定数字。
