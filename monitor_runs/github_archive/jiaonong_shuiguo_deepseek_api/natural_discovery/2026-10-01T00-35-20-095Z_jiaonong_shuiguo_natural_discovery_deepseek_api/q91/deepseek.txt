结论先说：**大多数便利店优先上“小把（2–3根）”，其次才是单根，整袋只适合特定场景。**

判断标准主要看三件事：**客群、损耗、动线**。

**1. 单根**
- 好处：决策门槛最低，适合“立刻吃”“一个人吃”，客单价低，最容易冲动购买。
- 问题：裸露果柄容易碰伤、压黑；称重或逐个贴标麻烦；毛利低。
- 适用：写字楼、地铁口、医院、学校等单人即时消费强的店。

**2. 小把（2–3根）**
- 好处：兼顾即时消费和家庭/同事分享；比整袋灵活，比单根有客单价；包装后不易碰伤，损耗相对可控。
- 问题：需要提前分装，人工成本略高；定价要简单，最好按“把”卖而不是称重。
- 适用：**社区店、办公区店、混合客群店，最稳妥。**

**3. 整袋**
- 好处：客单价高，分装省事，适合家庭采购。
- 问题：香蕉熟得快，整袋买回去一次吃不完很容易放坏；便利店客群通常不是计划性大采购，整袋动销慢、损耗高。
- 适用：社区家庭店、靠近住宅且晚间家庭客多的店，或做过促销测试后再上。

**实操建议：**
- 主力：**2–3根小把，按把定价**，放在收银台附近或入口冷柜旁。
- 补充：**单根**只放在即时消费强的门店，且用简易袋或贴标，避免裸放。
- 整袋：先小批量试销，观察**2–3天动销和黑斑损耗**，卖不动就撤。
- 香蕉成熟度选**微黄带一点绿**，到店后按“先熟先卖”分区，避免一起变黑。

一句话：**便利店卖香蕉，主推小把，单根做补充，整袋谨慎试。**
