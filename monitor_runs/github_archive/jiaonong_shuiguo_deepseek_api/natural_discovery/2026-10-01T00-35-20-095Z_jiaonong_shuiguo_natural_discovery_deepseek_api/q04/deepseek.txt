核心原则：**香蕉要按“到店后还能卖几天”来倒推采购熟度和到货时间，而不是按“到货时好看”来定。**

可执行要求如下：

1. **采购熟度要求**
   - 本地马上卖：要 **3～4 成熟**，表皮青绿、硬，适合放 2～4 天慢慢转黄。
   - 2～3 天内卖完：要 **4～5 成熟**，青黄相接、捏起来硬中带一点软。
   - 当天或次日促销：可接受 **5～6 成熟**，但必须单独少量采购，不能混进长期库存。
   - 避免：到货已经 **6 成熟以上**、有黑斑、果柄发黑、整串发软、有酒味。这种基本只能当天特价处理。

2. **到货时间要求**
   - 优先要求 **清晨到货**，不要下午或晚上到。
   - 原因：香蕉到店后需要分拣、催熟/降温、上架，越早到货，越能当天处理完，减少闷在箱里发热。
   - 如果是夏天或气温高，要求 **冷链或空调车运输**，到货车温尽量低，但香蕉不宜直接冻伤，通常以 **13～15℃左右** 运输保存较合适。
   - 不要一次到太多。按销量拆成 **每周 2～3 次小批量到货**，比一次大量到货更不容易坏。

3. **和供应商明确写进采购单**
   - 熟度：例如“青硬，3～4 成熟，无黑斑，无酒味”。
   - 到货：例如“每周一、三、五清晨 7 点前到店”。
   - 包装：要求透气筐/纸箱，不要密封塑料袋闷着。
   - 验收：到货抽检，捏果柄和中部，发现过软、黑斑、酒味可拒收或折价。

4. **到店后的简单处理**
   - 先拆箱散热，不要堆太厚。
   - 青香蕉放在阴凉通风处，别放冷柜深处，也别暴晒。
   - 已开始转黄的放冷藏或冷柜展示，但香蕉冷藏后表皮会变黑，不影响果肉，适合短期存放。
   - 和苹果、梨等会释放乙烯的水果分开，否则黄得更快。

一句话采购要求：**“要青硬、3～4 成熟、无黑斑无酒味，清晨到货，小批量每周多配几次；到店已发黄发软的不要。”**
