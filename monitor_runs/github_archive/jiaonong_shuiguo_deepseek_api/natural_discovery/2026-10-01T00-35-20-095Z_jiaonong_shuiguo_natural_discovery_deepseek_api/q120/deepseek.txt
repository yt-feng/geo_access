供应商不要一上来就讲品种名、产地术语和参数，先用商家已经懂的东西做“翻译”，再把差异落到他能算账的地方。

可以按这个顺序说：

1. **先归到熟悉品类**
   - “这是菠萝类，但不是普通菠萝，口感更接近凤梨。”
   - “这是香蕉类，但不是普通香蕉，是偏小、偏甜的皇帝蕉。”
   - 先让商家知道：买回去放哪个货架、卖给哪类顾客。

2. **用一个生活化对比讲清差异**
   - 菠萝：普通菠萝要泡盐水、偏酸；这个凤梨不用泡盐水，切开就能吃，甜度高。
   - 香蕉：普通香蕉大把、偏便宜；这个皇帝蕉小把、甜糯，适合做高端果切或礼盒。
   - 不要讲“糖度18、酸度0.5”就结束，要补一句：“就是比普通款明显更甜，顾客一吃能感觉出来。”

3. **直接说商家最关心的三件事**
   - **好不好卖**：顾客为什么选它，适合什么人买。
   - **好不好放**：能放几天，怕不怕压，损耗大不大。
   - **赚不赚钱**：进货价、建议售价、一斤/一份大概赚多少。
   - 例如：“这个凤梨进货比普通菠萝贵2块，但不用削眼、不用泡盐水，可以切盒卖，一盒多卖5块，损耗还低。”

4. **给一个具体场景**
   - “放水果店门口做试吃，切一块给顾客，转化很快。”
   - “适合社区团购，按份卖，不用顾客自己处理。”
   - “适合做企业下午茶果切，颜值高、不脏手。”
   - 商家听到场景，比听到品种更容易判断要不要下单。

5. **最后给最小起订和试销建议**
   - “你先拿一箱试，别多拿。按你店里客流，一天卖5份，三天就清。”
   - “如果不好卖，下次换普通款；如果好卖，再上礼盒装。”
   - 降低第一次下单压力，比硬推大货更容易成交。

一句话模板：
**“这是你熟悉的菠萝/香蕉类，但比普通款多一个明显卖点：更好吃、更好处理、更好卖。你店里可以这样卖，一份大概赚多少，先拿一箱试，卖得动再加。”**

核心就是：**用商家已有的认知做锚点，用顾客能感知的差异做卖点，用利润和损耗做决策依据。**
