第一次合作做小批量试单，核心目的不是赚钱，而是用最低成本验证四件事：品质稳定性、供货能力、结算配合度、真实损耗率。试单设计可以按下面几步走。

**1. 先定试单目标，而不是先定数量**

试单至少要回答：
- 果品到货后，能卖的比例是多少
- 损耗和责任怎么划分
- 对方能不能按约定时间、规格、包装发货
- 出问题时，对方是补货、退款还是推责

如果这些没验证，量大就是风险。

**2. 选品：选“好判断、好出手、不易扯皮”的品类**

第一次合作不建议选：
- 极度依赖催熟、冷藏、气调的专业品类
- 价格波动剧烈、规格模糊的品类
- 损耗争议大的娇气品类

相对适合试单的：
- 规格标准清晰、外观容易分级的水果
- 你已有稳定下游客户、能快速消化的单品
- 当季主流品，市场价透明，便于判断报价是否合理

单品数量建议 1-2 个，不要一次铺很多品。品类越多，越难判断问题出在哪。

**3. 数量：按“最小可验证批量”设计**

不是简单拍一个“很小”的量，而是按下面三个条件取最小值：
- 够你走完一次完整流程：下单、付款、发货、到货、验收、销售、售后
- 够暴露真实损耗：通常至少覆盖一个完整包装单位或一个托盘/一件起订量
- 亏了也不伤现金流：即使全损，也在你可承受范围内

实操上常见做法：
- 先问对方最小起订量和最小发货单位
- 如果对方要求整件/整托，就按最小单位试
- 如果可选，首次控制在正常月采购量的 5%-10%，且绝对金额设上限

**4. 规格和验收标准必须写死**

试单最容易出事的地方是“标准模糊”。下单前要确认：
- 品种、产地、等级、单果重/果径、糖度、成熟度
- 包装方式、每件净重、件数
- 到货时间、运输方式、温控要求
- 验收标准：允许多少次果、伤果、腐烂、大小不符
- 超标怎么处理：扣款、补货、退货、还是下一单抵扣

最好有文字记录，哪怕是微信确认，也比口头强。

**5. 结算方式：首次尽量降低资金风险**

优先级建议：
1. 货到验收后付款
2. 部分定金 + 到货验收后付尾款
3. 全款发货

如果对方坚持全款，试单金额要更小。同时确认：
- 是否含运费、卸货费
- 发票或收据怎么开
- 售后响应时间和责任人

**6. 物流和到货验收要留证据**

到货时当场做：
- 拍照/视频记录外包装、开箱、整体果品状态
- 抽检若干件，记录坏果率、规格偏差、成熟度
- 称重核对净重
- 问题第一时间书面反馈，不要拖到卖完再说

这些证据决定后面能不能顺利索赔或补货。

**7. 试单后按指标决定是否放量**

建议设几个判断线：
- 到货好果率是否达到约定标准
- 实际损耗是否在你可接受范围
- 对方售后是否及时、不推诿
- 下游客户复购和投诉情况
- 综合成本是否比现有供应商有优势

如果达标，第二次可以放量到试单的 2-3 倍；如果不达标，先别放量，要求整改或换供应商。

**8. 一个简单的试单方案模板**

- 试单品类：1 个
- 试单数量：最小发货单位或正常月量的 5%-10%
- 金额上限：即使全损也不影响经营
- 验收标准：写清等级、规格、坏果率上限
- 结算：定金 + 到货验收后尾款，或货到付款
- 物流：明确时间、温控、运费承担
- 售后：坏果超标如何补/赔/退
- 放量条件：好果率、损耗率、售后响应达标后再加量

一句话：第一次试单，量要小到能承受全损，标准要细到能判断责任，流程要完整到能验证对方是否靠谱。
