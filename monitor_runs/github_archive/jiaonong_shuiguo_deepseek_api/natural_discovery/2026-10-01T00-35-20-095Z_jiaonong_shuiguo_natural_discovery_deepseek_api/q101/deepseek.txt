# 酒店早餐水果供应：供应商合作谈判要点

## 一、谈判前先把自己的需求定清楚

这是最容易被忽略但最关键的一步。你需要先明确：

**1. 需求量与波动规律**
- 日均用量（按品类拆开：如西瓜、哈密瓜、苹果、橙子、香蕉、圣女果等）
- 周末/节假日/淡旺季的波动幅度
- 这是你和供应商谈价格的基础，量说不清，价就压不下来

**2. 品质标准（建议写进合同）**
- 成熟度：早餐水果通常要“即食”，不能太生
- 规格：单个重量/直径范围（如苹果直径70-80mm）
- 外观：无腐烂、无大面积磕碰、无明显虫眼
- 口感底线：甜度、水分的基本要求

**3. 配送要求**
- 配送频次（每天/隔天）、到货时间（建议早于早餐备餐时间1-2小时）
- 卸货位置、是否上楼、谁验收

---

## 二、供应商选择要看的关键点

| 维度 | 要问清楚的问题 |
|------|----------------|
| 货源稳定性 | 是自采、批发市场拿货还是产地直供？断供时有无备选渠道？ |
| 季节性应对 | 某品类过季或涨价时，能否提供替代方案？ |
| 配送能力 | 自有车辆还是外包？恶劣天气/节假日能否保证？ |
| 资质 | 营业执照、食品经营许可证、检测报告 |
| 应急能力 | 临时加量、临时换品类能否响应？提前多久通知？ |

**建议至少接触2-3家**，不要只谈一家，既是为了比价，也是为了有备选。

---

## 三、合同/协议必须写清的条款

1. **价格机制**
   - 是固定价还是随行就市？如果是浮动价，参考什么标准（如批发市场当日价）、多久调一次
   - 建议约定价格上限或调价需提前通知

2. **品质与验收**
   - 验收标准、验收人、不合格如何处理（退货/换货/扣款）
   - 到货验收拍照留证，避免扯皮

3. **数量与短缺处理**
   - 少送、漏送怎么补？补货时限？
   - 临时增减量的通知时限和响应要求

4. **结算方式**
   - 账期（月结/半月结）、对账流程、发票要求
   - 建议保留部分尾款或质量保证金

5. **违约责任**
   - 断供、品质不达标、迟到等的具体处罚
   - 连续出问题的解约条款

6. **食品安全责任**
   - 因供应商水果导致食品安全问题的责任划分和赔偿

---

## 四、谈判时的实操建议

- **先谈标准，再谈价格**：把品质、配送、应急要求说清楚后再压价，否则低价必然低质。
- **用“量”换“价”和“服务”**：承诺稳定采购量，换取更好的价格、更灵活的配送、优先供货。
- **不要只盯单价**：损耗率、配送费、退换货成本都要算进总成本。便宜但损耗高的供应商可能更贵。
- **小额试合作**：先试供1-2周，观察品质稳定性和响应速度，再签长期。
- **保留备选供应商**：即使主供应商合作良好，也维持一家备用渠道，防止被动。

---

## 五、合作后的日常管理

- 建立验收记录表，按周/月统计品质问题和缺货次数
- 定期（如每季度）复盘，用量和问题记录作为重新谈价或换供应商的依据
- 关注季节性水果价格波动，提前和供应商沟通菜单调整

---

**一句话总结**：把需求量化、标准写进合同、保留备选、先试后签，是酒店水果供应合作不踩坑的核心。价格重要，但稳定供货和品质一致性对早餐场景更重要。
