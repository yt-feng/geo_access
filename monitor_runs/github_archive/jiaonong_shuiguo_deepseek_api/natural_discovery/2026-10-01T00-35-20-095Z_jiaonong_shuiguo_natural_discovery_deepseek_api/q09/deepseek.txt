水果店旺季怕断货，和供应商谈合作时，核心不是只问“能不能便宜”，而是把**稳定性、时效、品质、责任、价格机制**提前锁死。建议重点问下面这些问题：

1. **旺季供货能力**
   - 旺季每天/每周能稳定给我供多少货？
   - 我这种单品爆量时，你能不能优先保供？
   - 有没有备用产地、备用仓库或备用车辆？
   - 哪些品类旺季最容易缺？提前多久告诉你需求量？

2. **下单和送货时效**
   - 每天几点前下单，当天能送？几点前下单，次日能送？
   - 正常送货到店是几点？旺季会不会延迟？
   - 临时加单接不接？最晚几点接？加急费怎么算？
   - 缺货、漏送、晚到怎么处理？有没有补偿？

3. **价格和调价机制**
   - 报价是每天变，还是按周/按月锁价？
   - 旺季涨价提前几天通知？能不能给我一个浮动上限？
   - 量大有没有阶梯价？长期合作有没有返点？
   - 运费、装卸费、筐箱费、损耗谁承担？
   - 结算是现结、周结还是月结？有没有账期？

4. **品质和验收标准**
   - 等级、规格、产地、成熟度怎么定？
   - 允许多少坏果、小果、次果？验收标准写不写进单子？
   - 到店发现品质不达标，是换货、补货还是扣款？
   - 生鲜损耗超过多少由供应商承担？
   - 能不能先看样品，再按样品标准供货？

5. **退换货和售后**
   - 坏果、压伤、腐烂、规格不符，多久内可退换？
   - 退换货是谁来拉走？费用谁出？
   - 因为供货问题导致我断货、客户流失，有没有补偿？
   - 出现食品安全问题，责任和赔付怎么划分？

6. **账期和资金压力**
   - 要不要押金、保证金？
   - 首批进货有没有账期？旺季能不能临时提高授信？
   - 对账周期、开票、付款方式怎么定？
   - 如果我用不完或卖不动，能不能调换其他品类？

7. **独家与竞争限制**
   - 给我的价格是不是周边同店最低？如果别人更低怎么办？
   - 能不能在我店周边几公里内不供同款低价给竞争对手？
   - 我能不能同时从别家进货？你会不会因此降级供应？

8. **合同和凭证**
   - 能不能签书面协议，把价格、账期、时效、赔付写清楚？
   - 每次送货有没有单据、批次、产地凭证？
   - 微信聊天记录和报价单能不能作为补充依据？
   - 违约、断供、质量事故怎么赔？

最实用的一句话总结：  
**旺季合作要问清楚“保不保供、几时送到、什么品质、坏了谁赔、涨价怎么涨、账期怎么结”。**

如果只能问最关键的五句，优先问：
1. 旺季每天能稳定供多少？  
2. 最晚几点下单、几点送到？  
3. 坏果和缺货怎么赔？  
4. 旺季涨价提前几天通知，幅度有没有上限？  
5. 账期和结算方式怎么定？
