大型超市对水果供应商的要求，通常比普通批发市场高很多，核心不只是“能供货”，而是能稳定提供**安全、可追溯、低损耗、按标准交付**的水果。一般必须具备以下几类能力：

**一、食品安全能力**

1. **合法资质齐全**
   - 营业执照、食品经营许可证或相关备案。
   - 若为种植基地，还需产地证明、种植备案等。
   - 涉及进口水果时，需有入境货物检验检疫证明、报关资料等。

2. **农残与污染物控制**
   - 有稳定的农残检测能力或第三方检测报告。
   - 能按超市要求提供批次检测报告。
   - 对重金属、霉菌毒素、保鲜剂、蜡、二氧化硫等风险有控制措施。

3. **追溯体系**
   - 能追溯到批次、产地、采收时间、加工包装时间。
   - 最好能做到“从基地到门店”的批次追溯。
   - 出现质量问题时能快速召回、隔离、说明原因。

4. **采后处理与保鲜合规**
   - 清洗、分级、打蜡、催熟、保鲜处理必须符合国家标准。
   - 使用的保鲜剂、催熟剂、包装材料必须合法合规。
   - 不能违规使用防腐剂、色素、甜味剂等。

5. **加工与包装卫生**
   - 分选、包装场所要符合食品卫生要求。
   - 人员健康证、工服、手套、消毒、虫害控制要到位。
   - 包装材料要符合食品接触材料标准。

6. **质量分级标准**
   - 能按超市标准做大小、色泽、糖度、成熟度、瑕疵率分级。
   - 对碰伤、腐烂、畸形、病虫害果有明确分选标准。

**二、物流与供应链能力**

1. **冷链或温控能力**
   - 不同水果对温度要求不同，如浆果、荔枝、车厘子、热带水果差异很大。
   - 需有冷藏车、冷库、预冷设备、温控记录。
   - 能提供运输温度记录，避免断链。

2. **预冷与快速周转**
   - 采收后能尽快预冷，降低呼吸热。
   - 从产地到门店的时效要稳定，尤其是高损耗水果。

3. **仓储与库存管理**
   - 有分区、分温、分品类存储能力。
   - 先进先出，避免积压和过期。
   - 能应对促销、节假日、突发订单的备货。

4. **配送时效与履约能力**
   - 能按超市要求送到配送中心或门店。
   - 准时率、缺货率、订单满足率要稳定。
   - 能处理临时加单、减单、退换货。

5. **包装与运输保护**
   - 包装要抗压、透气、防震，减少运输损耗。
   - 周转筐、托盘、冷链箱要清洁并可循环管理。
   - 避免与化学品、异味物品混装。

6. **损耗控制能力**
   - 能统计并控制运输损耗、仓储损耗、门店拒收率。
   - 对易损水果有专门方案，如草莓、蓝莓、樱桃、芒果等。

**三、超市通常还会重点考察的能力**

1. **稳定供应能力**
   - 多产地、多季节调配，避免断供。
   - 有备用基地或备用供应商。

2. **标准化与信息化**
   - 能对接超市订单系统、对账单、追溯系统。
   - 能提供批次码、条码、质检报告等电子资料。

3. **应急与召回能力**
   - 发生食品安全事件时，能快速定位批次并召回。
   - 有应急预案和责任人。

4. **合规与审核通过能力**
   - 能通过超市验厂、飞行检查、第三方审核。
   - 对整改项能快速闭环。

**简单判断标准：**
如果一家水果供应商只能做到“有货、能送”，但做不到**批次检测、冷链温控、追溯召回、分级包装、稳定履约**，通常很难进入大型超市体系。大型超市最看重的是：**食品安全不出事、质量稳定、损耗可控、供应不断、出了问题能追责。**
