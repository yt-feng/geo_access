判断供应商售后响应是否稳定，不能只听口头承诺，要在合作前和合作中用几个可验证的动作去测。

**合作前：先做压力测试**

- **问具体流程，不问态度**：直接问“到货发现菠萝黑心、香蕉青硬不熟，多久内可反馈？谁负责？怎么补？”让对方说出时限、责任人、处理方式。回答含糊的，大概率售后不稳。
- **要历史处理记录**：让对方举最近1-2次实际售后案例，包括问题类型、响应时间、最终结果。能说清细节的更可信。
- **试单验证**：先小批量采购，故意在到货后按正常流程提一次小问题（比如个别压伤、成熟度不均），看对方实际响应速度和解决意愿，而不只是答应得爽快。
- **查合同条款**：把售后响应时限、赔付/补货标准、责任划分写进合同，口头承诺不算数。

**合作中：持续观察几个信号**

- **首次响应时间**：报问题后，对方多久给出明确回复，而不是“我问问”“稍等”。
- **是否主动跟进**：稳定的供应商会主动问处理结果，而不是等你催。
- **换人是否断档**：对接人请假或离职后，售后是否还能正常运转，这能看出是个人关系还是公司机制。
- **旺季表现**：节假日、台风季等供应紧张时，售后是否还保持同样响应，很多供应商平时还行，一忙就失联。

**生鲜品类要特别注意**

菠萝和香蕉都是易损、后熟型水果，售后争议多集中在到货成熟度、黑心、压伤、腐烂。建议在合同里明确：

- 验收标准和时限（比如到货后几小时内可提异议）
- 不同问题的处理方式（补货、折价、退货）
- 菠萝黑心、香蕉催熟异常等典型问题的责任归属

**简单判断标准**

如果对方能做到：报问题后当天明确回复、给出可执行方案、按合同兑现，且换人后流程不断，基本算售后稳定。如果经常拖延、推责、靠个人关系维持，就要谨慎。
