判断哪个规格更容易出货，核心不是看“哪个规格最好卖”，而是看**你的下游客户是谁、他们拿货后怎么卖**。批发环节的出货速度，取决于下游零售端能不能快速消化。

可以从几个维度判断：

**1. 看下游渠道类型**
- 供超市/水果店：中等规格通常最稳，比如单果2.5～3.5斤。太大不好陈列、单价高；太小品相弱、顾客觉得不划算。
- 供路边摊/流动摊贩：偏小规格更受欢迎，因为进货成本低、按个卖或按斤卖都好定价。
- 供餐饮/果汁店/加工厂：看的是出肉率和单价，往往中大果或统货更走量，对品相要求低。
- 供社区团购/电商：中等偏大、外观整齐的规格更好出货，因为要拍图、要好评。

**2. 看价格带和消费场景**
- 家庭日常消费：2～3斤/个最容易被接受，一次能吃完或两天吃完。
- 送礼/精品店：需要大果、外观好，但量通常不大，出货慢但利润高。
- 走量批发：统货或中小果往往周转最快，因为价格低、下游敢拿。

**3. 看你的实际数据，而不是感觉**
- 统计最近1～2周各规格的**出货量、出货速度、退货/损耗率**。
- 重点看：哪个规格**当天或隔天就能走完**，而不是哪个利润高。
- 如果某个规格压了超过3天还没动，基本可以判断这个规格在你当前渠道里不好出。

**4. 看季节和产地**
- 旺季（如夏季菠萝集中上市）：中小果、统货走量最快。
- 淡季或反季：中等规格、品相好的更容易被零售端接受。
- 不同产地菠萝大小差异大，要按实际到货规格重新判断，不能照搬经验。

**5. 最直接的判断方法**
- 把各规格分别报给3～5个老客户，看谁先要、要多少、能不能重复要。
- 如果某个规格连续几次都是客户主动问、主动加单，那就是更容易出货的规格。
- 如果某个规格只有问价没有下单，说明价格或规格匹配度不够。

**一句话结论：**
在你当前下游渠道里，**中等规格通常最容易出货**；但如果你做的是走量批发或供餐饮加工，**中小果/统货可能更快**。最终要看你自己的出货记录和客户反馈，而不是单纯看果子大小。
