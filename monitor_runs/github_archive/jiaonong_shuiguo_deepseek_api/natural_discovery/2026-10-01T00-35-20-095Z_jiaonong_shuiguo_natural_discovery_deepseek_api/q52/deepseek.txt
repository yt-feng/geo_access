要避免香蕉到店后很快变黑，核心是控制乙烯、温度、机械损伤和湿度。可以按下面做：

1. **采购时选成熟度合适的香蕉**
   - 不要买已经全黄、带黑点、软塌的香蕉，这种到店后很快会继续变黑。
   - 优先选 **7成熟左右、青黄交接、手感硬实** 的香蕉。到店后还能放1–3天，适合做甜品。
   - 如果当天就要大量用，可以少量搭配已熟香蕉，但不要整批都熟。

2. **运输和搬运减少磕碰**
   - 香蕉变黑很多时候不是“放坏”，而是 **压伤、擦伤、摔伤** 后局部快速氧化变黑。
   - 用周转筐或纸箱装，不要堆太高；轻拿轻放，避免和硬物混装。
   - 到店后先检查，把有伤、已经软熟的香蕉挑出来优先用。

3. **到店后不要直接放冷藏**
   - 未完全成熟的香蕉放冰箱容易冻伤，表皮会快速变黑。
   - 如果香蕉还偏青，放在 **阴凉、通风、避免阳光直射** 的地方，室温大约18–22℃。
   - 如果已经成熟、当天或第二天要用，可以放冷藏，但表皮仍可能变黑，主要看果肉是否还正常。

4. **隔离乙烯来源**
   - 香蕉自身会释放乙烯，苹果、梨、猕猴桃、牛油果等也会释放乙烯，放一起会加速成熟变黑。
   - 到店后尽量 **单独存放**，不要和以上水果混放。
   - 如果空间有限，至少用纸箱或塑料袋稍微隔开，但不要完全密封闷住。

5. **适当通风，但避免风吹直吹**
   - 完全密封会积累乙烯和湿气，容易发黑、发霉。
   - 保持通风能带走部分乙烯，但不要让空调或风扇直吹，否则表皮容易失水变黑。

6. **控制湿度，避免凝水**
   - 香蕉怕太湿，表面有水珠容易长霉、变黑。
   - 如果从冷库或冷链车出来，先不要立刻拆袋，等温度回升一点再拆，避免表面结露。
   - 纸箱受潮要及时换掉。

7. **按使用节奏分批采购**
   - 甜品店最有效的方法不是“一次买很多再想办法保存”，而是 **少量多次采购**。
   - 比如每天或隔天送一次，按预估用量买，留半天到一天缓冲即可。
   - 如果必须一次买多，把香蕉分成：
     - 当天用：成熟度高的
     - 明天用：黄中带青的
     - 后天用：偏青的

8. **已经变黑的处理**
   - 如果只是表皮变黑，果肉正常、无异味，可以尽快用于香蕉奶昔、香蕉蛋糕、香蕉酱等加热或打碎类甜品。
   - 如果果肉发软、发酸、有酒味或霉点，直接丢弃，不要用于售卖。

简单记：**买青黄硬实的，别磕碰，别冷藏未熟蕉，别和苹果梨混放，通风不闷，少量多次采购。**  
对甜品店来说，最稳的是 **按1–2天用量分批进货**，而不是靠后期保存。
