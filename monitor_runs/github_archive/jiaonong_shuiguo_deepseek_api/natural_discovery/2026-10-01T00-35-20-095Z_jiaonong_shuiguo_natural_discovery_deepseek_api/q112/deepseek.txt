水果采购合同里，**没有统一的法定“坏果率超过多少必须赔付”标准**，关键看合同约定、验收标准、水果品类和交易习惯。实务中可按下面判断：

1. **合同有约定，优先按合同**
   - 如果合同写明“坏果率超过3%/5%/8%由供方赔付”，就按约定执行。
   - 常见约定方式包括：
     - 超过约定比例部分按重量扣款；
     - 整批按比例折价；
     - 超过一定比例可拒收、退货、换货；
     - 严重时解除合同并索赔。

2. **合同没约定，通常可参考行业惯例和验收标准**
   - **易损水果**：如草莓、樱桃、荔枝、葡萄、水蜜桃，坏果率容忍度较低，常见在**3%—5%**左右就可能提出扣款或索赔。
   - **一般水果**：如苹果、橙子、梨、香蕉，常见可接受范围可能在**5%—10%**，超过后通常可要求按比例赔付或折价。
   - **耐储运水果**：如西瓜、柚子、菠萝等，若外观和内部质量要求明确，超过**5%—8%**也常可主张赔付。
   - 但这不是固定标准，具体要看等级、包装、运输距离、季节和验收时点。

3. **更稳妥的合同写法**
   建议不要只写一个比例，而是写清楚：
   - 验收时间、地点、方法；
   - 抽样比例和抽检方式；
   - 坏果定义：腐烂、霉变、压伤、冻伤、虫害、异味等是否都算；
   - 赔付方式：按坏果重量扣款、按整批比例折价，还是退货换货；
   - 超过多少可拒收；
   - 超过多少可解除合同；
   - 运费、仓储费、分拣费由谁承担。

4. **一个可操作的参考写法**
   - 坏果率≤3%：正常验收；
   - 坏果率3%—5%：超过3%部分按重量扣款；
   - 坏果率5%—10%：整批按比例折价，或供方补货；
   - 坏果率＞10%：采购方有权拒收、退货，并要求供方承担运费及损失。

5. **如果已经发生争议**
   你可以按这个顺序判断：
   - 先看合同有没有明确比例；
   - 没有就看双方之前交易习惯；
   - 再看是否符合该品类通常质量标准；
   - 最后看坏果是否因供方采摘、包装、运输造成；
   - 保留验收照片、视频、抽样记录、过磅单、聊天记录。

简单说：**不是“超过多少就一定赔”，而是合同约定优先；没约定时，易损水果常见3%—5%，一般水果常见5%—10%可作为谈判参考。** 如果你把具体水果品类和合同条款发我，我可以帮你判断更具体的赔付线。
