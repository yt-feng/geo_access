小水果店做附近小区团购，水果供应商至少要支持这些服务，否则你很容易被“售后、损耗、配送”拖死：

1. **稳定供货与每日报价**
   - 能每天或提前1-2天给报价单：品名、规格、等级、产地、净重、箱规、单价、起订量。
   - 价格波动大的水果要能提前通知涨跌，不然你团购价刚发出去就亏。
   - 最好能按你的团购周期备货，而不是临时缺货。

2. **按团购规格分拣、打包**
   - 支持按份/按袋/按箱分装，比如“5斤装”“家庭装”“尝鲜装”。
   - 能贴标签：品名、规格、日期、保存方式，最好能贴你的团购标签。
   - 这点很关键：小区团购不是批发市场拿货，分拣人工你自己做会很累。

3. **质量分级与验货标准**
   - 明确什么是A级、B级、统货，大小、甜度、外观标准要说清。
   - 支持你抽检、试吃、坏果拍照反馈。
   - 最好有“坏果包赔”或“售后补损”条款，而不是一句“水果生鲜不退不换”。

4. **售后与损耗赔付**
   - 坏果、烂果、压伤、少斤两，能按比例赔、补发或下次抵扣。
   - 赔付流程要简单：拍照/视频+数量+订单号，多久内反馈有效。
   - 生鲜损耗最好控制在你能承受的范围，比如约定超过3%-5%由供应商承担。

5. **配送时效与到店/到小区能力**
   - 能送到你店里，或直接送到小区自提点。
   - 支持定时达：比如团购截单后第二天上午到货。
   - 冷链水果如蓝莓、草莓、车厘子，要有冷藏车或保温箱。
   - 如果供应商能帮你直接配到多个小区自提点，会省很多事。

6. **起订量与补货灵活**
   - 小水果店单量不稳定，供应商最好低起订、可混批。
   - 支持临时加单、减单，尤其是爆品。
   - 不要只做大客户，愿意接你这种小批量团购单。

7. **结算方式灵活**
   - 支持现结、周结、月结，或押金+账期。
   - 能开收据/发票更好，方便你算账。
   - 价格最好含税含运费，避免后面加价。

8. **退换货与滞销处理**
   - 团购剩货、没人取、品质争议，能不能退？怎么退？
   - 有些供应商支持“未拆箱可退”或“换其他品”。
   - 滞销品能否帮你调换，决定你敢不敢做新品类。

9. **营销与素材支持**
   - 提供水果图片、视频、卖点、产地故事、保存方法。
   - 能配合你做爆品文案，比如“今日到货”“甜度实测”。
   - 最好能给你团购价和零售建议价，避免你乱价。

10. **数据与对账支持**
   - 每单有明细：品种、数量、单价、金额、运费、赔付款。
   - 能按小区/团购批次对账。
   - 方便你算毛利、损耗和复购。

你选供应商时，重点问这8个问题：
- 起订量多少？能不能混批？
- 能不能按份分装？分装费怎么算？
- 坏果怎么赔？多久内反馈？
- 送到店还是送到小区？运费谁出？
- 每天几点报价？多久能到货？
- 支持哪些结算方式？
- 临时加单/减单行不行？
- 能不能给图片文案和售后标准？

简单说：**小水果店做小区团购，供应商不能只是“供货”，还要能帮你分拣、配送、售后、控损、给素材。** 其中最重要的是：稳定报价、分装能力、坏果赔付、定时配送。这四项缺一个，团购都很难长期做。
