提高客单价的关键不是“便宜”，而是让顾客从“买一样”变成“买一组”。香蕉、菠萝、苹果这三个品项可以做三种组合促销，按门店位置和客群选。

1. **家庭果盘组合**
   - 组合：香蕉1把 + 菠萝1个 + 苹果4个
   - 定价：原价合计约18-22元，组合价15.9或16.9元
   - 话术：**“回家切一盘，早餐/下午茶都够”**
   - 作用：把低频的菠萝带进高频的香蕉、苹果里，提升整体客单。

2. **早餐能量组合**
   - 组合：香蕉2根 + 苹果2个 + 小菠萝1个
   - 定价：9.9元或10.9元
   - 位置：收银动线前、早餐时段入口
   - 话术：**“一周早餐水果，顺手带走”**
   - 作用：降低决策成本，适合上班族、学生，容易加购。

3. **切果/果切引流组合**
   - 组合：香蕉1根 + 菠萝块1盒 + 苹果1个
   - 定价：12.9-15.9元
   - 场景：下午茶、加班、亲子
   - 话术：**“现切三拼，开盒即吃”**
   - 作用：果切毛利更高，能明显拉客单，但要注意损耗和食品安全。

4. **阶梯满减，而不是直接打折**
   - 买香蕉+苹果满15元，加5元换购菠萝1个
   - 或满25元送香蕉1把/苹果2个
   - 作用：顾客本来只想买苹果，为了换购会加香蕉和菠萝，客单自然上去。

5. **陈列组合**
   - 把香蕉、菠萝、苹果放在同一端头，标“组合更划算”
   - 菠萝提前削好一部分，降低处理门槛
   - 香蕉按“把”卖，苹果按“4个装”卖，减少称重犹豫

6. **注意损耗**
   - 香蕉熟得快，组合里别放太多
   - 菠萝切果当天卖完，不隔夜
   - 苹果耐放，可以承担“凑单”角色
   - 组合价要比单买便宜，但不能低于整体毛利底线

如果只选一个最稳的方案：**做“香蕉+苹果+菠萝”家庭组合，定价15.9元，放在主通道端头，配“一盘搞定”的标语。** 这个最容易执行，也最容易把客单从单买5-8元拉到15元以上。
