小面积便利店做水果，核心逻辑就一句话：**少品类、小批量、高频补、快周转**。下面按可执行的方式拆开说。

## 一、品类控制：先做减法

小店面水果区通常只有1–2个货架或一个冷柜，SKU建议控制在**8–15个**，不要超过20个。

**选品原则：**

1. **只留“刚需+高频+好走量”的**
   - 香蕉、苹果、橙子、梨——日常刚需，耐放，复购高
   - 应季爆款选1–2个：夏天西瓜/葡萄，冬天砂糖橘/草莓
   
2. **砍掉三类**
   - 太娇贵、损耗高的：水蜜桃、蓝莓、切好的果切（除非当天能清）
   - 单价太高、周转慢的：进口车厘子、山竹按需少量试
   - 需要挑拣、顾客爱翻的：容易越翻越烂

3. **按角色分配，而不是按品种堆**
   - 引流款1–2个（香蕉、应季特价），不指望赚利润
   - 利润款3–5个（苹果、橙子、葡萄）
   - 尝鲜款1–2个，小批量试，卖不动立刻撤

**判断标准：** 一个单品如果连续3天动销差、每天都在扔，就下架，不要舍不得。

## 二、采购控制：小批量高频

1. **少量多次**
   - 宁可每天补、隔天补，也不要一次囤一周
   - 叶菜类/莓果类：当天进当天清
   - 苹果橙子香蕉：可2–3天一次

2. **按“预估日销”下单，不按“感觉”**
   - 记录每个单品每天卖多少，按近3–7天平均销量×1.1–1.2倍下单
   - 新品先按最小起订量试，卖得好再加

3. **建立稳定供应渠道**
   - 找本地批发市场或二级批发商，支持小批量、可退换最好
   - 谈“次日补货”“滞销可换”，比压价更重要

4. **采购时间**
   - 早上进货，当天上架，减少在库时间
   - 避开周末前大量囤货，除非确认周末走量

## 三、损耗控制：从收货到出清

1. **收货就分级**
   - 好果正常价，轻微瑕疵果立刻打折区，别混在一起等它烂

2. **陈列要“少而满”**
   - 每次只摆一层到两层，卖完再补，避免堆压
   - 香蕉、苹果等会互相催熟的，分开摆

3. **温度管理**
   - 有条件用冷柜/冷藏展示，叶菜、莓果、葡萄必须冷藏
   - 香蕉、芒果、牛油果不要冷藏

4. **每天两次挑拣**
   - 早上开门、下午高峰后各挑一次，把软伤果挑出
   - 挑出的立即处理：打折、做果切、或员工内购

5. **临期出清机制**
   - 当天17点后：轻微瑕疵8折
   - 20点后：5折或打包特价
   - 闭店前：能处理的处理，不能的果断报损，别留到第二天

6. **记录损耗**
   - 每天记：进货量、销售量、报损量
   - 一周复盘：哪个单品损耗最高，直接砍或减量

## 四、一个小店可落地的配置示例

- **常备（6个）：** 香蕉、苹果、橙子、梨、应季柑橘、葡萄
- **应季（2–3个）：** 按季节轮换，西瓜/草莓/砂糖橘等
- **试销（1–2个）：** 小批量，3天不动销就撤
- **总SKU：** 10个左右
- **补货：** 香蕉2天一次，苹果橙子3天一次，应季每天看情况
- **出清：** 每天下午设一个折扣时段

## 五、最关键的判断指标

盯住三个数：
1. **动销率**：多少单品当天能卖完
2. **损耗率**：报损金额÷进货金额，小店面控制在**5%–10%**以内算正常
3. **周转天数**：水果平均在店不超过2–3天

**一句话总结：** 品类少而精，采购勤而少，陈列薄而勤，出清快而狠。小店面拼的不是品种全，而是“不压货、不烂货、天天新鲜”。
