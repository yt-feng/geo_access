生鲜水果到货后出现坏果，责任划分通常不能一概而论，要看到货时的状态、坏果比例、包装和配送情况、顾客收货后的处理是否及时等因素。实务中一般按下面几个层次判断：

**1. 先看“坏果”发生在哪个环节**
- **采摘/分拣/打包环节**：如果同批次很多顾客都反馈坏果，或者坏果有明显挤压、腐烂、发霉、虫害，通常是商家或供应商的品控、包装责任。
- **冷链/仓储环节**：如果水果怕冻怕热，因仓储温度不当导致冻伤、发酵、快速腐烂，属于商家或仓库责任。
- **配送环节**：如果是配送中摔坏、挤压、暴晒、超时配送导致变质，通常由商家先对顾客负责，再按合作协议向配送方追责。顾客一般不需要直接找配送方。
- **顾客收货后环节**：如果顾客签收后放置太久、未按要求冷藏、自行二次搬运导致损坏，这部分责任通常由顾客承担。

**2. 常见责任划分方式**
- **商家全责或主要责任**：到货即坏、坏果比例高、同一批次集中投诉、包装明显不合格、冷链断链。
- **商家和顾客按比例承担**：少量坏果，且顾客也有延迟取货、未及时冷藏等情况，可按坏果数量或金额协商部分退款/补发。
- **顾客责任为主**：签收时完好，之后因顾客存放不当、超过合理食用期导致腐烂。
- **配送方责任**：有明确证据证明配送延误、暴力装卸、温控失败，商家可向配送方追偿，但对外通常仍由商家先处理顾客投诉。

**3. 判断时重点看这些证据**
- 开箱照片/视频，最好能拍到快递面单、整箱状态、坏果特写。
- 坏果数量、比例、是否集中在某一层或某一侧。
- 到货时间、签收时间、投诉时间。
- 商品页面是否承诺“坏果包赔”“坏果率低于多少”“冷链配送”等。
- 是否有同批次其他顾客的类似反馈。
- 配送记录、温控记录、分拣打包记录。

**4. 比较合理的处理原则**
- **对外先赔后追**：顾客从商家买，商家一般先按售后规则处理，再向供应商或配送方追责。
- **按坏果比例赔**：不是整单全赔还是全不赔，通常按坏果数量、金额比例退款或补发。
- **设置合理时限**：一般要求顾客在签收后一定时间内，如24小时内，拍照反馈；超出时限且无证据，商家可降低责任。
- **生鲜特性要说明**：轻微外观差异、自然成熟斑点不一定算坏果；但腐烂、发霉、异味、严重压伤通常应赔。

**5. 建议的规则写法**
如果是平台或商家制定规则，可以写成：
- 签收后24小时内凭开箱视频/照片申请售后；
- 坏果率低于5%可协商部分补偿，超过10%可补发或退款，超过30%可整单退；
- 因顾客延迟取货、未冷藏导致的坏果，商家不承担或只承担部分；
- 配送原因导致的坏果，商家先赔，再向配送方追偿。

**一句话总结**：谁导致坏果，谁承担主要责任；但顾客面对的是商家，商家通常应先处理售后，再向供应商或配送方追责。少量坏果且顾客有过失的，可按比例分担。
