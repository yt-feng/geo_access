结论：**优先买冷冻菠萝果丁，其次鲜果，不建议常规用果泥（除非做冰沙/奶昔类）。**

**怎么选：**

- **鲜果**  
  适合：门店有稳定人手、能当天处理、追求“现切”卖点。  
  缺点：成熟度不稳定、损耗高、出杯一致性差、旺季切果占用人工。  
  如果买鲜果，建议选**都乐/佳农等商业品种**，要求“7-8成熟”，到店后1-2天内用完。

- **冷冻菠萝果丁**  
  最适合茶饮店。  
  优点：甜酸稳定、开袋即用、损耗低、出杯标准统一、四季供应稳定。  
  用途：果茶、水果茶、捣果肉类饮品都能用。  
  注意：选**IQF单体速冻、无糖水浸泡或轻糖保护**的，避免解冻后软烂出水。

- **菠萝果泥**  
  适合：冰沙、奶昔、酸奶、果酱基底，或需要快速标准化但不需要果肉感的饮品。  
  不适合：主打“吃得到果肉”的果茶，因为口感糊、分层差、容易沉底。  
  如果要用，选**巴氏杀菌或冷冻果泥**，不要用罐头糖水菠萝打泥。

**采购建议：**
1. 菜单有“果肉感” → 冷冻果丁为主，鲜果做点缀。
2. 菜单是“菠萝冰茶/气泡茶” → 冷冻果丁或鲜果。
3. 菜单是“菠萝冰沙/奶昔” → 冷冻果泥或果丁+果泥复配。
4. 先小批量测试：同一配方下对比鲜果、冷冻果丁、果泥的**出杯速度、口感、成本、损耗**，再定主力原料。

**简单记：**  
要果肉 → 冷冻果丁；要现切卖点 → 鲜果；要顺滑冰沙 → 果泥。
