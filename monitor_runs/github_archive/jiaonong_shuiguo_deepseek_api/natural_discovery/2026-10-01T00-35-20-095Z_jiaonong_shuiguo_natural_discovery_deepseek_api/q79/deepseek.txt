优先问**售后**，其次问**配送**，最后再谈**价格**。原因是团购团长最怕的不是“进货贵一点”，而是**坏果、烂果、缺斤少两、售后扯皮**，这会直接损害你在群里的信任。

更实用的判断顺序是：

1. **先问售后**
   - 坏果怎么赔：按个数、按重量，还是按整单比例？
   - 多久内反馈有效：收货当天、24小时还是48小时？
   - 需要什么凭证：照片、视频、称重图？
   - 赔付方式：补发、退款、下次抵扣，还是直接现金？
   - 生鲜损耗率大概多少，谁承担？

2. **再问配送**
   - 到货时间是否稳定，能不能按你要求送到自提点？
   - 是冷链、普通货车还是快递？水果最怕闷坏、冻伤、压伤。
   - 破损、延误、少送怎么处理？
   - 起送量、配送费、临时加单怎么算？

3. **最后谈价格**
   - 价格低但售后差，最后你赔钱又赔信任。
   - 要问清楚：报价是否含运费、包装费、损耗赔付。
   - 对比“到手可售成本”，不是只看进货价。

一句话建议：  
**先筛售后敢兜底的，再筛配送稳的，最后在同档里选价格低的。**  
如果供应商售后含糊、配送不稳，价格再低也不建议做主力供应商，最多少量试单。
