判断的核心不是“苹果多大、橙子多大”，而是**门店客群、售卖方式、损耗承受和定价带**是否匹配。可以按下面这套标准现场判断。

## 一、先定用途，再定规格

同一个水果，散卖、礼盒、切果、榨汁要求完全不同。

| 用途 | 苹果 | 橙子 |
|---|---|---|
| 散称日常销售 | 中等偏大，单果 180–250g 较稳 | 单果 180–300g 较稳 |
| 家庭装/促销 | 150–220g，数量感强 | 150–250g，便于装袋 |
| 礼盒/精品 | 220–350g，外观一致 | 220–350g，果形周正 |
| 切果/果切 | 大果出成率高，250g 以上 | 大果好剥好切，250g 以上 |
| 榨汁 | 大小要求低，但出汁率和新鲜度重要 | 中果即可，重点看皮厚和出汁率 |

如果门店主要做社区日常消费，优先选**中等规格、大小均匀、价格带好卖**的货，不要盲目追大果。

## 二、现场看苹果规格

苹果重点看：

1. **单果重量**
   - 用小电子秤抽 20–30 个，算平均单果重。
   - 同批次波动最好控制在 ±15% 以内。
   - 如果 150g 和 300g 混在一起，散卖时顾客会挑，剩下小果难卖。

2. **果径**
   - 用卡尺或分级圈抽测。
   - 散卖常见可接受：70–85mm。
   - 礼盒精品：80–90mm 或以上。
   - 低于 65mm 的小果，除非做促销装或儿童果，否则门店利润和体验都差。

3. **外观和硬度**
   - 大小合格但伤果多、软果多，实际可售率低，不适合正常货架。
   - 抽检磕碰、黑点、裂口、软伤比例。
   - 可售率低于 85% 要谨慎，低于 80% 基本不适合做主推。

4. **箱规与陈列**
   - 看一箱净重、个数、层数。
   - 如果一箱里大小分层明显，要问供货商是否混级。
   - 门店货架层高、周转筐、保鲜柜决定你能不能陈列，不是越大越好。

## 三、现场看橙子规格

橙子重点看：

1. **单果重量**
   - 散卖常用：180–300g。
   - 小于 150g 偏小，顾客觉得不划算。
   - 大于 350g 的大果可以卖，但价格通常要高，否则毛利被压。

2. **果径**
   - 常见散卖：65–80mm。
   - 精品礼盒：75–85mm。
   - 大小要均匀，一袋里不要明显一大一小。

3. **皮厚、出汁率、口感**
   - 同样大小，皮厚、干水、酸度高的不适合门店复购。
   - 现场可随机切 2–3 个，看皮厚、汁水、籽量、化渣程度。
   - 如果皮太厚，按重量卖会吃亏，顾客体验也差。

4. **果形和表皮**
   - 果形周正、表皮干净、无严重药斑和软腐。
   - 软果、烂果、发霉果比例高，说明储运或批次有问题。

## 四、用“三率”判断是否适合门店

采购时不要只看外观，要算三个率：

1. **可售率**
   - 可售率 = 能正常上架销售的重量 ÷ 采购总重量。
   - 苹果、橙子正常应在 90% 以上。
   - 低于 85% 就要重新谈价或拒收。

2. **损耗率**
   - 包括挑拣损耗、试吃、顾客翻拣、临期处理。
   - 门店日常销售，苹果橙子损耗最好控制在 5% 以内。
   - 如果预计超过 8%，规格再漂亮也不适合。

3. **毛利空间**
   - 采购价 + 损耗 + 包装 + 人工后，是否还能覆盖门店目标毛利。
   - 大果进价高，如果周边顾客只接受低价，大果反而难卖。

## 五、快速判断口诀

**苹果：**
- 散卖看 180–250g、70–85mm、大小均匀、硬度好。
- 太小难卖，太大压价，混级最麻烦。

**橙子：**
- 散卖看 180–300g、65–80mm、皮薄汁多、大小一致。
- 太大未必好，皮厚干水最伤复购。

**通用原则：**
- 同批次大小差异越小，越适合门店。
- 可售率低于 85%，谨慎。
- 损耗预计超过 8%，谨慎。
- 不符合门店客单价和陈列条件，再好的规格也不要。

## 六、建议的实操抽检流程

1. 随机抽 20–30 个，称重、量果径。
2. 记录最大、最小、平均、均匀度。
3. 随机切 2–3 个看内部品质。
4. 翻箱看底层，判断是否有压伤、烂果、大小分层。
5. 算可售率和预估损耗。
6. 对比门店售价，算毛利。
7. 符合再收，不符合就谈分级、降价或换货。

一句话：**适合门店销售的规格，是大小均匀、可售率高、损耗可控、价格带匹配，而不是单纯越大越好。**
