茶饮店使用的水果（尤其是鲜果、冷冻果、果浆）属于食品原料，供应商需要提供的证明可分为**资质类、检验类、批次类**三个层面。

## 一、供应商主体资质

| 证明 | 说明 |
|---|---|
| 营业执照 | 经营范围需含食品/农产品销售 |
| 食品生产许可证（SC） | 若供应商是加工厂（果浆、冷冻果、果干） |
| 食品经营许可证 | 若供应商是贸易商、经销商 |
| 仅销售预包装食品备案 | 部分地区对预包装食品经营者适用 |

**关键点**：鲜果若属于食用农产品，农民自产自销可豁免许可证，但必须有身份证明和产地信息；一旦经过分拣、包装、加工的，通常需要相应许可。

## 二、产品检验证明

- **型式检验报告 / 全项检测报告**：由第三方CMA/CNAS机构出具，一般一年内有效，覆盖农残、重金属、微生物等。
- **出厂检验报告 / 委托检验报告**：针对具体产品。
- **农残检测报告**：鲜果重点，必查项目包括有机磷、氨基甲酸酯类等。
- **进口水果**：需**入境货物检验检疫证明** + 海关报关单。

## 三、批次随货证明（每批必查）

- **出厂检验合格证 / 质量合格证明**
- **送货单 / 销售凭证**：注明品名、规格、数量、生产日期/批号
- **食用农产品**：需**产地证明**或**购货凭证**（《食品安全法》对食用农产品进货查验的要求）

## 四、建议茶饮店建立的动作

1. **索证索票台账**：每批留存上述证明 + 发票/收据，保存期限不少于产品保质期满后6个月，无明确保质期的不少于2年。
2. **签订质量协议**：明确农残、微生物、异物等标准及违约责任。
3. **到货验收记录**：感官检查（色泽、气味、霉变、虫害）+ 温度记录（冷冻/冷藏品）。
4. **定期审核**：每年要求更新检测报告，必要时实地审核供应商。

## 优先级排序（实操）

**必须拿到**：营业执照 + 食品经营/生产许可证 + 每批合格证明/送货单 + 农残检测报告（鲜果）。

**建议拿到**：年度全项第三方检测报告 + 质量协议 + 进口检疫证明（进口果）。
