为公司下午茶采购水果，选择适合批量配送的供应商，关键是把“品类稳定性、配送能力、结算与售后”三件事验证清楚。下面给一套可直接执行的筛选和判断方法。

**一、先明确需求，再去找供应商**
1. **人数与份量**：按每人200–300克净水果估算，100人约需20–30公斤；品种多时每种少量，避免浪费。
2. **场景**：办公室即食，优先选易分装、不易压坏、无需切配的品类，如香蕉、橘子、圣女果、葡萄、蓝莓、苹果、梨。
3. **频次**：每周1次还是每月几次，决定供应商是否愿意给稳定账期和价格。
4. **预算**：按“人均5–15元”常见区间定档，再让供应商按档配货，而不是先看报价。

**二、优先考虑的供应商类型**
- **本地大型水果批发商**：价格低、品类全，适合量大；但需确认是否支持小批量分拣和送货上楼。
- **生鲜B2B平台**：如美菜、快驴等（以当地实际服务为准），配送稳定、有票据，适合固定周期采购。
- **连锁水果店/精品果切店**：服务好、可做果切和拼盘，但单价偏高，适合小规模或高要求下午茶。
- **企业团餐/下午茶服务商**：能连带零食、饮品一起配送，省对接成本，但水果可能不是其强项，要单独验品。

**三、筛选供应商的5个硬指标**
1. **批量配送能力**：问清最小起送量、配送时段、是否可指定上午/下午送达、是否送楼层。
2. **分拣与包装**：是否支持按部门/人数分袋、独立包装、标注品种；易损水果是否有防压措施。
3. **品控与退换**：到货坏果率标准是多少，坏果是否包赔、怎么赔、多久内反馈有效。
4. **价格与账期**：是否含税、能否开票、是否支持月结；报价是否随行就市，调价是否提前通知。
5. **应急能力**：临时加单、改时间、换品种能否处理，旺季是否保证供应。

**四、实操建议**
- 同时找2–3家供应商，先各试一次小单，重点看准时率、坏果率、包装和售后。
- 固定“主供应商+备选供应商”，避免单一渠道断供。
- 签简单框架协议：写清品种范围、参考单价、配送时间、坏果赔付、账期。
- 每次收货留照片和称重记录，作为对账和索赔依据。

**五、快速判断标准**
如果一家供应商能做到：**准时送到、坏果率低于5%、坏果包赔、能开票、可月结、临时加单能响应**，基本就适合长期批量配送。反之，如果价格很低但经常迟到、不包赔、不能开票，不建议作为主供应商。
