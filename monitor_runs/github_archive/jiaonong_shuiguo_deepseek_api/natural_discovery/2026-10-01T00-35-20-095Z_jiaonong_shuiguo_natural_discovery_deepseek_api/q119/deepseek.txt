做水果生意，供应商选择最容易被忽视的，往往不是价格和品种，而是那些“平时不痛、出事就致命”的细节。按重要性排，主要有这几类：

**1. 供应稳定性与产地分散度**
- 只盯一个产区、一个果园：遇到霜冻、暴雨、病虫害或当地疫情封控，直接断供。
- 要问：同一品种你有几个产区/几个基地？换季时能否平滑过渡？
- 长期稳定靠的是“多点备份”，不是单点便宜。

**2. 分级与品控标准是否可执行**
- 口头说“精品”“一级”，但没有书面分级标准（果径、糖度、着色、瑕疵率）。
- 忽视“到货合格率”和“批次一致性”——同一供应商这批好、下批差，损耗全在你这边。
- 建议约定：抽样比例、糖度/硬度指标、允许瑕疵率、不合格如何处理。

**3. 采后处理与冷链能力**
- 很多问题不是种出来的，是采后烂的：预冷是否及时、分选是否规范、冷链是否全程。
- 忽视“从采摘到装车的时间”和“断链风险”。这直接决定货架期和损耗率。
- 要实地或视频看：预冷库、分选线、冷藏车。

**4. 结算方式与账期背后的风险**
- 只谈单价，不谈账期、押金、退换货、运费谁承担。
- 账期越长，供应商越可能把资金成本加进价格，或在旺季优先供别人。
- 要明确：现结/月结、滞纳责任、缺货赔偿。

**5. 信息透明度**
- 不愿提供产地证明、检测报告、农药使用记录。
- 长期合作必须能追溯批次，否则一旦出食品安全问题，你无法自证。
- 至少要有：产地、批次、检测、采收日期。

**6. 旺季优先权**
- 平时合作好，旺季却拿不到货——因为没约定优先供应条款。
- 要谈：节前/旺季的保供量、锁价机制、违约补偿。

**7. 损耗与售后责任划分**
- 到货后烂果谁承担？运输途中损耗算谁的？
- 忽视“验收时限”和“举证方式”，容易扯皮。
- 建议：到货X小时内验收，拍照留证，按比例扣款或补货。

**8. 供应商的财务与经营健康**
- 只看货好，不看对方是否资金紧张、是否快撑不住。
- 突然低价抛货、要求预付大额货款，往往是危险信号。

**落地建议（可直接执行）：**
1. 每个核心单品至少备2家供应商，主次分明。
2. 签书面协议，写清分级标准、合格率、账期、损耗责任、旺季保供。
3. 每月统计：到货合格率、损耗率、缺货次数、客诉归因。
4. 每季度实地看一次产地或加工厂，别只靠微信图片。
5. 新供应商先小批量试3批，再放量。

一句话总结：**价格决定你赚多少，供应稳定性、品控标准、冷链和权责划分决定你能不能长期活下去。** 最容易忽视的，正是这些“没写进合同、但天天影响损耗”的细节。
