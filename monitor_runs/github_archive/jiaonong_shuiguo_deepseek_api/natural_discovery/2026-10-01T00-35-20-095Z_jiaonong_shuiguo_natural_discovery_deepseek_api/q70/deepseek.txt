批发商要防“货到损耗高”，合同里不能只写一句“坏果由谁负责”，而要同时锁定**验收标准、责任归属、扣款/拒收机制、举证方式**。可以按下面思路写。

**一、先定义什么叫“坏果”**
不要只写“坏果”“损耗”，要列明判定标准，例如：
- 腐烂、发霉、流汁、异味；
- 严重压伤、裂口、破损导致无法销售；
- 冻伤、日灼、病害斑面积超过约定比例；
- 规格不符：单果重量、直径、成熟度、色泽、糖度等低于约定标准；
- 包装不符合约定导致挤压、受潮、变质。

建议写成：
> “坏果包括但不限于腐烂、霉变、异味、严重压伤、裂口、冻伤、病害、规格不符或包装不当导致无法正常销售的水果。”

**二、明确责任划分**
关键是把“装车前后”和“运输责任”切开：
1. **装车前**：卖方对采摘、分选、包装、预冷、装车质量负责。
2. **运输中**：谁安排运输，谁对运输条件负责；若买方自提或买方指定承运人，通常运输风险由买方承担，但卖方包装不合格除外。
3. **到货后**：买方应在约定时间内验收，逾期视为合格或按约定处理。
4. **卸货后**：因买方储存、搬运、销售不及时造成的损耗，卖方不负责。

可写：
> “货物装车并交付承运人前，因卖方采摘、分选、包装、预冷不当造成的坏果，由卖方承担责任；运输过程中因承运人管理不当造成的坏果，由承运人承担责任；买方自提或指定承运人的，运输风险由买方承担，但卖方包装不符合约定或隐瞒质量问题的除外。”

**三、约定验收期限和方式**
没有验收期限，坏果责任很难认定。
建议写：
- 到货后 **2—6小时**内完成外观验收；
- **12—24小时**内完成开箱/切开抽检；
- 逾期未提出异议，视为验收合格；
- 验收时应拍照、录像、保留温度记录、称重记录、抽检记录；
- 双方可约定第三方检测或共同抽样封存。

**四、约定坏果比例和扣款/拒收机制**
常见写法有三种：
1. **按比例扣款**：坏果率≤3%免赔；3%—10%按比例扣款；超过10%可拒收或协商降价。
2. **按重量扣款**：实际结算重量=到货总重量－确认坏果重量。
3. **按等级降价**：部分坏果不影响整体销售的，降级计价。

示例：
> “到货验收时，坏果率在3%以内的，买方不得拒收，按实际合格重量结算；坏果率超过3%的，超出部分按当日市场价或合同价的120%从货款中扣除；坏果率超过10%的，买方有权拒收该批货物，卖方应在24小时内退款并承担往返运费。”

**五、明确举证和通知义务**
买方发现坏果后，应在约定时间内书面通知卖方，并附：
- 到货时间、车牌、承运人；
- 现场照片/视频；
- 抽检数量、坏果数量、坏果率；
- 温度记录、装卸记录；
- 第三方检测报告（如有）。

可写：
> “买方应在到货后6小时内以微信、短信或邮件方式通知卖方，并保留现场证据；未在约定时间内通知或未保留证据的，视为货物验收合格。”

**六、加上包装、运输和保险条款**
如果损耗主要来自运输，合同里最好同时写：
- 包装标准：纸箱、泡沫箱、冷藏箱、冰袋、通风要求等；
- 运输温度、湿度、时限；
- 承运人由谁指定；
- 是否购买货物运输险；
- 保险受益人是谁。

**七、建议直接写进合同的条款模板**
可以写成：

> **坏果责任条款**
> 1. 本合同所称坏果，指腐烂、霉变、异味、严重压伤、裂口、冻伤、病害、规格不符或包装不当导致无法正常销售的水果。
> 2. 卖方应保证交付货物符合约定规格、成熟度和包装标准。装车前因采摘、分选、包装、预冷不当造成的坏果，由卖方负责。
> 3. 买方自提或指定承运人的，运输途中风险由买方承担；卖方安排运输的，运输途中因承运人原因造成的坏果，由卖方先行向买方承担责任，再向承运人追偿。
> 4. 买方应在到货后____小时内完成验收，并在____小时内书面通知卖方坏果情况；逾期未通知或未保留证据的，视为验收合格。
> 5. 坏果率≤____%的，按实际合格重量结算；超过____%的，超出部分按合同价的____%扣款；超过____%的，买方有权拒收，卖方应在____日内退款并承担相应运费。
> 6. 双方对坏果原因有争议的，可共同抽样封存并委托第三方检测，检测费用由责任方承担。

**八、给批发商的实操建议**
1. 不要只写“坏果包赔”，要写**比例、时限、扣款方式**。
2. 最好约定“**先验收后结算**”，至少保留部分尾款。
3. 运输自己控不了时，尽量让卖方负责运输和保险。
4. 每次到货都按合同留证：拍照、视频、温度记录、抽检单。
5. 长期合作也要每批签确认单，避免口头扯皮。

简单说，核心就一句：**把坏果定义清楚，把验收时间卡死，把扣款比例写明，把证据要求写实，把运输责任切开。**
