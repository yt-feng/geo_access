三者不是同一维度的“选一个”，而是有优先级和底线关系：

**最需要先关注的是食品安全，其次是配送准时，最后才是价格。**

原因很简单：

1. **食品安全是底线，不能妥协**  
   食堂面对的是企业员工群体，一旦水果农残超标、腐烂霉变、来源不明，可能引发群体性肠胃问题、食物中毒或投诉事件。  
   对企业食堂来说，食品安全出问题，不是“买贵了”或“晚到了”能比较的，而是责任事故。

2. **配送准时是保障运营的关键**  
   水果通常是按餐次或每日供应，配送不准时会导致：
   - 当天水果无法供应；
   - 临时采购成本更高；
   - 食堂排班和员工体验受影响。  
   所以准时是仅次于安全的硬指标。

3. **价格重要，但不是第一优先级**  
   价格当然要控制预算，但水果采购如果只看低价，容易遇到：
   - 品质差、损耗高；
   - 以次充好；
   - 来源和检测不透明；
   - 实际可食用率低，综合成本反而更高。

更合理的判断顺序是：

**先卡食品安全准入 → 再筛配送履约能力 → 最后比价格和综合成本。**

实际采购时建议这样执行：

- **食品安全**：要求供应商提供营业执照、食品经营许可、批次检测报告或承诺书；能追溯产地；验收时检查新鲜度、霉变、异味。
- **配送准时**：约定送达时间、迟到处理、缺货补送机制，比如“晚于约定时间30分钟扣款或补送”。
- **价格**：不要只比单价，要比“可食用部分成本”。比如同样10元/斤，损耗30%和损耗10%，实际成本差很多。

如果必须用一句话总结：  
**食品安全是一票否决，配送准时是运营保障，价格是在前两者合格后的优化项。**
