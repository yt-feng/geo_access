针对“门店多、单店量小”的超市，核心矛盾是：**总采购量不小，但单店单次需求分散，导致物流成本高、损耗难控、供应商不愿直供**。适合的供货模式要解决“集单、共配、降损”三个问题。

下面按优先级给可执行方案：

## 1. 首选：区域集配中心 + 本地批发市场补货
**适合大多数中小连锁超市。**

- **操作方式**：设1个区域集配仓，各门店提前1天报量，总部汇总后统一向产地/一级批发商采购，再由集配仓分拣、配送到店。
- **优点**：把“多店小单”变成“大单”，拿到更好价格；减少每店单独进货的物流和损耗。
- **注意**：集配仓要控制库存周转，水果保质期短，建议只囤耐储品类（苹果、橙子、瓜类），叶菜、浆果类走“次日达”或本地补货。

## 2. 次选：与本地水果批发商签“统采分送”协议
**适合门店集中在同一城市、单店日均水果销量低于3000元的情况。**

- **操作方式**：找1-2家本地一级批发商，谈定“总部统一采购价 + 按门店分送”，由批发商负责配送到各店。
- **优点**：不用自建仓配，利用批发商现有物流；价格比门店单独去市场拿货低。
- **关键条款**：
  - 分送起订量按“整车/整线”算，不是按单店算；
  - 损耗责任划分：到店前损耗由供货方承担；
  - 允许门店间调货，避免单店压货。

## 3. 补充：产地直采 + 区域分仓
**适合水果品类占比高、有稳定销量的连锁。**

- **操作方式**：对苹果、柑橘、香蕉等耐储大单品，直接对接产地合作社或大型基地，发到区域分仓，再分店配送。
- **优点**：毛利空间最大。
- **缺点**：需要资金和仓储能力，且只适合少数大单品，不能覆盖全部水果。
- **建议**：先用1-2个单品试跑，不要全品类直采。

## 4. 可考虑：第三方生鲜供应链平台
**适合不想自建采购团队、门店数在10-50家之间的超市。**

- 如美菜、快驴、蜀海等（具体以当地实际服务为准），它们本身做集采和共配。
- **优点**：起订量低、配送频次高、品类全。
- **缺点**：价格通常高于自采，且品质稳定性依赖平台。
- **适合定位**：作为补充渠道，而不是唯一渠道。

## 5. 不建议的模式
- **各店自行去批发市场采购**：价格不统一、品质不稳定、无法形成规模优势。
- **找多个小供应商分别直送各店**：物流成本高、对账复杂、损耗扯皮多。
- **完全依赖一个全国性供应商**：水果地域性强，单一供应商很难覆盖所有品类和季节。

## 落地建议（按顺序做）
1. **统计各店水果日均销量和品类结构**，算出总单量和单店起订量。
2. **确定1个区域集配点**，哪怕只是租一个冷库+分拣区。
3. **把水果分为三类**：
   - 耐储大单品：产地直采或集配中心统采；
   - 常销中单品：本地批发商统采分送；
   - 易损短保品：门店周边小批发商每日补货。
4. **谈合同时重点锁定**：分送起订量、损耗承担、退换货规则、配送频次。
5. **先试跑2-4周**，看各店损耗率和缺货率，再调整品类和供应商。

**一句话结论**：门店多但单店量小，最现实的是“**区域集配中心统采 + 本地批发商分送 + 易损品本地补货**”的组合模式，而不是让每家店单独找货源。
