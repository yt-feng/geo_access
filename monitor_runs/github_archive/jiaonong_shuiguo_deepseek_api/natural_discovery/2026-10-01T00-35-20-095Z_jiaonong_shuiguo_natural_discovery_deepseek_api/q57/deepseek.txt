结论先说：**大多数餐饮连锁，水果应优先“中央厨房/配送中心统一收货”，但要做分级例外。** 少数保鲜要求极高、周转极快、门店有强验收能力的品类，才适合门店直收。

判断标准不是“哪种更好”，而是看这四点：**损耗率、品控一致性、物流成本、结算复杂度**。

### 统一收货更适合的情况

适合：门店数量多、跨区域、水果用于标准化产品（果切、沙拉、饮品、甜品装饰）、供应商集中。

优点：
- **品控标准统一**：糖度、成熟度、规格、农残检测由中央统一把关。
- **采购议价更强**：总部集量，价格和账期更优。
- **减少门店舞弊和收货差异**：门店自行收货容易出现缺斤少两、以次充好、人情验收。
- **便于溯源和索赔**：批次、检测报告、温控记录集中管理。
- **门店操作简化**：门店只负责签收和储存，不承担复杂验收。

缺点：
- **二次分拣和配送损耗增加**：水果易碰伤，多一次装卸就多一次损耗。
- **成熟度控制更难**：统一发货到门店时，可能过熟或过生。
- **配送频次要求高**：水果周转慢会压库存，周转快又考验冷链和路线。

### 门店分开收货更适合的情况

适合：高端鲜果、门店现切现卖、每日高频补货、区域供应商本地配送强、单店销量大且验收能力成熟。

优点：
- **鲜度和成熟度更可控**：门店可按当天客流和陈列状态收货。
- **减少中转损耗**：本地供应商直送门店，少一次装卸。
- **补货灵活**：临时加单、换品、处理临期更方便。

缺点：
- **品控容易不一致**：不同店长标准不同，顾客体验波动。
- **采购成本更高**：单店采购量小，议价弱。
- **管理成本高**：总部要管很多供应商、单据、对账、食安。
- **舞弊风险高**：收货、报损、退货环节容易失控。

### 推荐做法：混合模式

1. **主力品类统一收货**：苹果、橙子、柠檬、冷冻果、罐头水果、标准化果切原料。
2. **高损耗鲜果区域直收**：草莓、蓝莓、芒果、牛油果、鲜切西瓜等，可由区域配送中心或授权本地供应商直送。
3. **设门店验收红线**：温度、外观、糖度、重量、批次检测报告，缺一项可拒收。
4. **总部统一供应商准入和价格框架**：即使门店收货，也不能门店自由选供应商。
5. **用数据决定**：连续看各品类损耗率、客诉率、到店成熟度、单店日均销量。若某品类统一收货损耗明显高于直送，就转直送；若直送客诉和价格失控，就收回统一收货。

### 简单决策表

- 门店多、要标准化、要控食安：**统一收货**
- 易损、短保、成熟度敏感：**区域配送中心 + 门店直收结合**
- 单店采购量小、无专业验收：**不要门店分开收货**
- 本地供应链成熟、单店量大：**可授权门店直收，但总部控供应商和标准**

所以，最优答案通常是：**总部控标准、控供应商、控结算；中央厨房或区域配送中心统一收大部分水果；高鲜度易损品类做授权直送例外。** 纯门店分开收货只适合少数条件成熟的门店，不适合作为连锁主模式。
