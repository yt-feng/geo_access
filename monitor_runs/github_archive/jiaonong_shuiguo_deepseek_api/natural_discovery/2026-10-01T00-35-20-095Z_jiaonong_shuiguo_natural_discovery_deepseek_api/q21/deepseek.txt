超市采购水果时，供应商通常需要提供以下几类证明和检测报告（具体要求会因超市、地区监管及水果品类不同而有差异）：

**一、主体资质与进货证明**
1. **营业执照**：供应商合法经营主体证明。
2. **食品经营许可证**（或食品生产许可证，视业态而定）。
3. **供货合同/采购订单**：明确品名、数量、批次、价格、责任。
4. **进货凭证/销售单据**：发票、送货单、出库单等，能追溯批次和来源。
5. **上游来源证明**：如从批发市场、产地合作社、进口商采购，需提供相应采购凭证。

**二、产品合格与检测报告**
1. **食用农产品合格证**（承诺达标合格证）：国内食用农产品常用，由生产者或收购者出具。
2. **农药残留检测报告**：常见重点，尤其是叶菜、草莓、葡萄等高风险品类；可为供应商自检或第三方检测。
3. **重金属及污染物检测报告**：视品类和产地风险而定。
4. **食品添加剂/保鲜剂检测**：如涉及打蜡、防腐处理等。
5. **第三方检测报告（CMA/CNAS）**：超市通常更认可有资质的第三方报告，按批次或定期提供。

**三、进口水果额外需要**
1. **海关进口货物报关单**。
2. **入境货物检验检疫证明**。
3. **中文标签**：符合预包装食品标签要求。
4. **输出国/地区官方植物检疫证书**（视品类和协议要求）。

**四、超市端常见管理要求**
1. **批次追溯**：报告或合格证要与具体批次对应。
2. **定期更新**：检测报告通常按批次或按周期（如每季度/每年）更新。
3. **快检配合**：超市可能自行或委托快检，供应商需配合。
4. **冷链/储运证明**：部分易腐水果需提供温控记录。

**实操建议**
- 先向超市索要《供应商准入清单》或质量协议，按清单准备最稳妥。
- 国内普通水果：至少准备营业执照、食品经营许可证、食用农产品合格证、对应批次农残检测报告、送货单。
- 进口水果：再加报关单、入境检验检疫证明、中文标签。
- 高风险品类或大型连锁超市：优先提供 CMA/CNAS 第三方检测报告，并确保批次可追溯。
