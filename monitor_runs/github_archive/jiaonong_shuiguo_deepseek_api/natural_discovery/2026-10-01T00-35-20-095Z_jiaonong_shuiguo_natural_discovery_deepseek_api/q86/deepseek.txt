生鲜平台做水果一件代发，供应商的仓配能力要按“**能不能稳定发、发出去坏不坏、坏了能不能兜住**”三层来判断。核心不是有没有仓库和快递账号，而是能否支撑**小单、多SKU、高频、易损、时效敏感**的发货模型。

### 一、基础仓配能力

1. **产地或销地仓**
   - 能按平台订单量设置仓：产地仓适合单品爆量，销地仓适合多SKU、时效要求高的区域。
   - 仓库要具备水果分区：常温、冷藏、催熟/后熟、暂存、次品隔离。
   - 要有日处理能力数据：日均单量、峰值单量、爆单响应时间。

2. **分拣打包能力**
   - 支持按单拣货，不是只支持整车/大批发。
   - 能处理多规格：按斤、按箱、礼盒、混搭装。
   - 有水果专用包材：蛋托、珍珠棉、气柱、冰袋、保温袋、吸水纸、防压隔板。
   - 能按温层打包：常温、冷藏、冷冻、冰鲜。

3. **库存与订单系统**
   - 能对接平台ERP/OMS，支持订单自动抓取、回传发货、库存同步。
   - 支持批次管理、效期管理、先进先出。
   - 能区分可售库存、锁定库存、残次库存。
   - 最好有WMS，至少要有扫码出入库，避免错发漏发。

4. **快递与物流资源**
   - 有稳定合作的快递/专线，能发全国或指定区域。
   - 能提供时效分层：次日达、隔日达、经济件。
   - 生鲜件要能走生鲜专线或航空/高铁资源，不是普通快递随便发。
   - 能处理拦截、改址、拒收、退回。

### 二、生鲜水果特别需要的能力

1. **温控与保鲜**
   - 采后预冷：浆果、荔枝、樱桃等需要快速预冷。
   - 冷藏/冷链车、冷库、保温发货。
   - 能根据品类设定温区，而不是所有水果一个温度。

2. **品控与分级**
   - 收货验货：糖度、硬度、大小、色泽、成熟度、病斑。
   - 发货前二次分选，剔除软果、裂果、霉果。
   - 能按平台标准做等级：特级、一级、二级、次果。
   - 有留样和批次追溯。

3. **损耗控制**
   - 能给出品类损耗率，如浆果、荔枝、桃、芒果损耗不同。
   - 有催熟管理能力，如香蕉、芒果、猕猴桃。
   - 能控制装卸次数，减少挤压和温差。

4. **售后兜底**
   - 能接受坏果包赔、按比例赔付、补发。
   - 有照片/视频取证流程。
   - 能区分责任：物流延误、温度失控、包装不当、果品本身问题。
   - 有售后预算或保险方案。

### 三、平台方要重点核验的指标

- **发货时效**：订单生成后几小时出库，几点前截单。
- **揽收时效**：出库后多久有物流轨迹。
- **48小时/72小时签收率**：不同区域能否达标。
- **破损率/坏果率**：按品类看，不只看平均值。
- **错发漏发率**：低于千分之几。
- **售后响应**：几小时内处理，是否支持补发。
- **峰值能力**：大促、节日、爆品日能否翻倍发货。
- **系统对接**：是否支持API、Excel、手动导入，回传是否及时。
- **结算与对账**：运费、包材、赔付、补发如何计费。

### 四、不同模式的供应商要求

- **产地直发**：要求产地仓、预冷、分级、快递资源强，适合单品爆量。
- **销地仓发**：要求多SKU库存、区域时效、冷链短驳，适合城市群。
- **云仓/第三方仓**：要求系统对接、多平台发货、标准化售后，适合平台轻资产。
- **供应商自己发**：要求全链路能力，平台要重点控品控和售后。

### 五、最简单的准入判断

供应商至少要做到：

1. 能对接平台订单，自动或半自动发货；
2. 有水果专用打包和温控方案；
3. 能承诺发货时效和坏果赔付；
4. 有批次追溯和售后取证流程；
5. 峰值单量能扛住，不是只能发几百单。

如果只满足“有仓库、能发快递”，通常不够。水果一件代发真正卡人的是：**保鲜、分级、包装、时效、售后**。平台选供应商时，建议先小批量试发3-5个品类、3个区域，跑两周数据，再决定是否放量。
