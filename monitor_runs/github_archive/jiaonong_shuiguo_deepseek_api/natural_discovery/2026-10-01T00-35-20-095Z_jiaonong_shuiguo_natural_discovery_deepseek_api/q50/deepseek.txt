**结论：对大多数茶饮店，出汁率优先级略高于甜度；但真正上线时，应该先卡“稳定供货+风味阈值”，再在两者之间做平衡。**

分场景说更清楚：

**1. 如果你做的是菠萝果茶、菠萝冰茶、菠萝气泡水**
- **出汁率更重要。**
- 因为这类产品里菠萝主要是提供果肉感、果香和体积感，甜度可以靠糖浆、果酱、冷冻菠萝汁或调整糖度补。
- 出汁率低会直接导致：同样克重出不了多少汁，单杯成本上升；果肉少、口感空；备料时间变长。

**2. 如果你做的是菠萝特调、菠萝奶盖、菠萝冰沙**
- **甜度稳定性更重要。**
- 这类产品配方固定，菠萝本身甜度波动大，会直接让整杯饮品风味忽甜忽酸，顾客复购感受差。
- 出汁率可以通过搭配菠萝汁、果泥来补，甜度不稳则很难每杯临时校准。

**3. 如果你做的是“鲜切菠萝片/菠萝块”装饰型产品**
- **甜度更重要，出汁率其次。**
- 因为顾客会直接吃，酸涩、甜度低的菠萝片会拉低体验，出汁率反而不是核心。

**实操判断标准：**

- **出汁率底线：** 同样压榨/捣碎条件下，出汁率低于你现有供应商或配方基准的 **10%以上**，就不建议换。
- **甜度底线：** 可溶性固形物（糖度）波动超过 **2°Brix**，就要么换货，要么在配方里预留糖浆调节空间。
- **综合优先级：**
  1. 供货稳定、批次差异小
  2. 出汁率达到配方要求
  3. 甜度在可调节范围内
  4. 香气、纤维感、酸度匹配产品

**建议你直接做一个小测试：**
拿同一配方，用两款菠萝原料各做3杯，记录：
- 每100g出汁量
- 糖度
- 单杯所需糖浆调整量
- 员工备料时间
- 顾客盲测偏好

如果一款出汁率高但偏酸，可以用糖浆补；如果一款甜但出汁少，成本会明显变高。对茶饮店来说，**出汁率影响成本和效率，甜度影响口味稳定；先保出汁率底线，再选出甜度最稳的那款。**
