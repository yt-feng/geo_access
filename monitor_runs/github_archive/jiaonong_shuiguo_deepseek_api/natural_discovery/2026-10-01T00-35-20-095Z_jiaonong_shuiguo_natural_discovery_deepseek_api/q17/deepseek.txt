社区超市做水果，核心就一句话：**按“销”定“进”，用“快”保“鲜”**。水果毛利看着高，但损耗和压货吃掉利润最快。下面给你一套可以直接用的方法。

## 1. 先解决“进多少”：小批量、多频次

水果最大的坑是一次进太多。

- **主力品种每天进，隔天补**：苹果、橙子、香蕉这类耐放的可以2-3天一次；草莓、葡萄、荔枝、桃这类娇气的必须每天进或隔天进。
- **首次进货宁少勿多**：新品类先拿最小起订量试销，卖动再加量，别听批发商“多拿便宜”。
- **按销量倒推**：比如上周苹果日均卖30斤，今天就进30-35斤，留一点安全库存，不要按“感觉”进。
- **跟批发市场错峰**：早市拿货新鲜但贵，傍晚收市可能便宜但品相差。社区店建议早市拿主力鲜货，收市补耐放货。

## 2. 再解决“怎么卖快”：陈列和定价逼着货动

库存压不压，很多时候不是进多了，是卖慢了。

- **先进先出**：新货放后面/下面，旧货放前面，每天开门先翻堆。
- **分级卖**：好果正价，稍有瑕疵的立刻打折做“特价盒”或“切果盒”，别等烂了再扔。
- **动态降价**：设定时间节点，比如下午5点后叶菜、草莓、葡萄打8折，晚上8点后打6折，第二天早上还没卖完的直接下架处理。
- **捆绑销售**：香蕉+苹果、草莓+蓝莓做果篮或套餐，加快周转。
- **试吃引流**：切一小盘试吃，社区店很吃这套，能明显带动当天销量。

## 3. 库存控制：设红线，别靠感觉

给每个品类设三个数：

| 指标 | 作用 | 例子 |
|---|---|---|
| 安全库存 | 保证不断货 | 苹果保持20斤 |
| 补货点 | 降到这个数就进 | 剩15斤就补 |
| 最大库存 | 超过就停进 | 不超过50斤 |

- **每天闭店盘点**：剩多少、烂多少、卖多少，记一周就有规律。
- **按天看损耗**：某品类连续3天损耗超10%，要么减量，要么换供应商，要么停卖。
- **季节调整**：夏天叶菜、浆果类库存砍半，冬天苹果、橙子可适当多备。

## 4. 保鲜：不同水果不同对待

- **怕冷的**：香蕉、芒果、火龙果别放冷柜，室温阴凉处。
- **怕热的**：草莓、蓝莓、葡萄、荔枝必须冷藏，但别冻伤。
- **会催熟的**：苹果、香蕉、猕猴桃会释放乙烯，别和叶菜、草莓放一起。
- **易压伤的**：桃、葡萄、草莓用浅筐，别堆高。
- **切开的**：必须冷藏，当天卖完，别过夜。

## 5. 最实用的一个动作

**每天只做一件事：闭店前把“明天必须卖掉”的货挑出来，单独放一个区，标特价。**

这样第二天一开门，员工和顾客都知道先卖这些，压货和损耗会明显下降。
