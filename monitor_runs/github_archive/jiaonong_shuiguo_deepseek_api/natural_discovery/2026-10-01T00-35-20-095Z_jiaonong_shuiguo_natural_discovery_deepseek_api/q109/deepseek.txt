优先谈 **账期**，其次 **售后**，最后 **配送**。

更具体地说，顺序取决于你的经营阶段，但对大多数长期合作的水果采购方，建议这样排：

1. **账期最优先**
   - 水果是高频、易损耗、现金流占用大的品类。
   - 账期直接决定你的现金流压力和资金周转效率。
   - 长期合作里，账期一旦谈下来，是持续性收益，比单次配送快慢、单次售后补偿更值钱。
   - 重点谈：账期天数、起算时间、结算方式、逾期责任、是否随采购量递增优化。

2. **售后第二优先**
   - 水果非标、易损，售后规则不清，长期一定会扯皮。
   - 售后谈的是“风险怎么分”，直接决定你实际采购成本和损耗率。
   - 重点谈：坏果率标准、赔付比例、补发还是扣款、拍照留证时限、拒收条件、节假日报损是否同样适用。

3. **配送第三优先**
   - 配送重要，但通常更容易通过换供应商、加价、临时补货解决。
   - 除非你是连锁门店、餐饮、团购履约，配送时效直接决定营业，否则它不如账期和售后影响大。
   - 重点谈：到货时间窗、迟到处理、冷链要求、临时加单、缺货替代规则。

一句话判断：

- **现金流紧、采购量大**：先谈账期。
- **损耗高、纠纷多**：先谈售后。
- **门店时效要求极高、断货损失大**：先谈配送。

如果只能选一个先谈，选 **账期**。因为账期谈崩了，合作很难长期；账期谈好了，售后和配送通常还有优化空间。
