批发档口退货纠纷，八成出在“收货时没验清、事后说不清”。收货验货要做到三点：**当场验、留证据、写规则**。下面给你一套可落地的做法。

## 一、验货前先定规则

- **验货时限**：货到后要求当天或 24 小时内验完，超时视为合格。写进送货单或合同。
- **验货方式**：大货抽检 + 关键货全检。抽检比例可定 10%–30%，贵重或易碎品全检。
- **合格标准**：把“什么算不合格”写清楚，比如破损、色差、尺寸偏差范围、功能不良。
- **责任划分**：运输破损谁承担、厂家质量问题谁承担、档口自己挑货失误谁承担，提前说清。

## 二、验货时按流程走

1. **先对单**：核对送货单的品名、规格、数量、批次，和订单是否一致。
2. **再查外包装**：看有无破损、受潮、挤压、拆封痕迹。外包装异常先拍照再开箱。
3. **开箱验实物**：
   - 数量：点清总数，缺件当场记。
   - 外观：破损、污渍、色差、做工问题。
   - 规格：尺寸、型号、颜色、材质是否对版。
   - 功能：能试的当场试，不能试的注明“待检”。
4. **抽样要有代表性**：不同批次、不同箱分别抽，别只翻最上面一层。
5. **当场记录**：合格多少、不合格多少、具体问题是什么，写进验货单。

## 三、证据怎么留

- **照片/视频**：外包装、开箱过程、问题部位、整体货堆，都要拍。
- **验货单**：写明日期、送货方、批次、数量、问题、处理意见，双方签字。
- **沟通记录**：微信、短信、通话录音，涉及退换货承诺的都要留存。
- **异常件单独放**：不合格品隔离存放，别和合格品混在一起，避免二次纠纷。

## 四、发现问题怎么处理

- **当场能定的**：直接拒收、要求补货、折价接收，写进单据。
- **当场定不了的**：标注“待检”，约定复检时间和责任人。
- **已经收下的**：尽快书面通知对方，附证据，提出退换或赔偿方案，别拖。
- **反复出问题的供应商**：提高抽检比例，甚至改为全检，或换供应商。

## 五、给档口的简化版口诀

**对单 → 看包装 → 开箱 → 抽检/全检 → 拍照 → 填单 → 签字 → 隔离不合格品。**

做到“**单货一致、当场确认、有据可查**”，退货纠纷会明显下降。核心不是验得多细，而是**验的时间点要早、责任要当场划清、证据要留得住**。
