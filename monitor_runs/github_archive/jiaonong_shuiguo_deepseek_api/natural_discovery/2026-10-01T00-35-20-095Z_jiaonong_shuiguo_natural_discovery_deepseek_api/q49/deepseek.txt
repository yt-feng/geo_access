旺季菠萝用量突然变大，临时补货的关键是**提前把“加急规则”写进合作框架里**，而不是等到断货了才去求供应商。可以按下面几步操作：

**1. 先锁定需求：给供应商一个可执行的预估**
- 不要只说“最近用量大”，要给：预计未来7天/14天每天需要多少公斤、需要什么规格（去皮/带皮、切片/切块、成熟度、糖度要求）。
- 说明是短期峰值还是持续到几月，方便供应商排产和调车。

**2. 约定“临时补货”的触发和响应机制**
和供应商补签一份旺季补充协议，写清楚：
- **触发条件**：比如日常订单量超过基础量20%，或提前24小时通知即可启动加急。
- **响应时效**：例如“收到加急订单后24小时内到货，最迟不超过48小时”。
- **最小起订量**：加急单可以低于常规起订量，但价格可能上浮。
- **加急费用**：明确加急运费、分拣费谁承担，避免到货后扯皮。

**3. 价格和账期要单独谈**
- 临时补货通常单价会高于常规价，可以约定“按当日产地价+固定加工费”或“上浮X%”，避免临时坐地起价。
- 如果用量大且稳定，可以谈阶梯价：达到某个量后加急费减免。
- 账期建议：加急部分现结或缩短账期，提高供应商配合意愿。

**4. 准备备选方案，别只押一家**
- 同时接触2-3家供应商，把临时补货协议也签一份，哪怕平时不用。
- 和本地批发市场、水果连锁店建立应急渠道，作为最后兜底。
- 如果菠萝用于招牌产品，可提前测试冷冻菠萝、罐头菠萝的替代配方，断货时不至于停售。

**5. 合同里写清楚违约和验收**
- 供应商未按时到货的赔偿条款，比如按缺货金额的X%扣款。
- 验收标准：规格、成熟度、坏果率，不合格怎么退换。
- 保留聊天记录、订单截图，作为后续对账依据。

**一句话总结**：旺季临时补货，本质是**用提前签好的加急条款换供应商的优先排产权**。你给他确定的需求和加急费，他给你优先发货，双方都不吃亏。
