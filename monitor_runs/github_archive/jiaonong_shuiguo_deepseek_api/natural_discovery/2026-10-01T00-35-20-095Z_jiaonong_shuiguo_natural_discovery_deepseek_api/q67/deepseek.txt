批发商在谈水果品牌代理时，区域保护和串货问题必须在签合同前问清楚，且最好落到书面条款。可以按下面几个方向逐条问：

## 一、区域保护

1. **我的独家代理区域具体是哪些？**
   - 是按省、市、县，还是按具体渠道（如商超、水果店、电商）划分？
   - 边界要写清楚，避免“周边地区”“辐射区域”这种模糊表述。

2. **在这个区域内，品牌方还授权了其他代理吗？**
   - 现有几家？分别做什么渠道？
   - 我是不是唯一代理？如果不是，我的权限边界在哪？

3. **区域保护期限是多久？**
   - 合同期内是否保证不再新增代理？
   - 续约时区域范围会不会调整？

4. **品牌方自己会不会在区域内直营或供货？**
   - 比如品牌方直供大型商超、电商平台，是否算绕过我？
   - 这部分业绩算不算我的？有没有补偿？

5. **线上销售归谁管？**
   - 品牌方旗舰店、直播带货、社区团购是否覆盖我的区域？
   - 我能不能做线上？如果能，平台和价格怎么约束？

## 二、串货问题

1. **串货的定义和判定标准是什么？**
   - 是看货物流向、销售区域，还是看价格体系？
   - 跨区销售多少算串货？有没有例外，比如自然流客、临时调货？

2. **发现串货后怎么处理？**
   - 品牌方有没有稽查机制？谁负责查？
   - 对串货方的处罚是什么？罚款、扣保证金、取消返利、终止代理？

3. **我被串货冲击时，品牌方怎么补偿我？**
   - 有没有价格保护、库存回收、返利补偿？
   - 处理时限是多久？

4. **我的货如果被认定串货，申诉流程是什么？**
   - 谁来举证？我能不能申辩？
   - 处罚前是否要书面通知？

5. **电商平台低价乱价算不算串货？**
   - 品牌方有没有控价措施？
   - 如果平台卖家从其他区域拿货低价卖，品牌方管不管？

## 三、价格与返利配套

1. **供货价、建议零售价、最低限价分别是多少？**
2. **返利、账期、退换货政策是否和区域保护挂钩？**
3. **如果品牌方给其他区域更低供货价，我怎么维权？**
4. **促销活动、特价品是否允许跨区销售？**

## 四、合同里必须写清楚的条款

建议要求写入合同或补充协议：

- 独家代理区域、渠道、期限；
- 品牌方不得在区域内另行授权或直供的承诺；
- 串货认定标准、稽查方式、处罚措施；
- 被串货方的补偿机制；
- 线上销售权限和控价责任；
- 争议解决方式、违约金、退出机制。

## 五、谈判时的问法示例

可以这样直接问：

> “我这个区域是独家还是非独家？合同期内品牌方会不会再授权别人，或者自己直供商超和电商？如果出现其他区域货串到我这里低价卖，你们怎么查、怎么罚、怎么补我？这些能不能写进合同？”

> “线上旗舰店、直播、社区团购如果卖到我区域，算不算我的业绩？如果不算，价格冲突怎么处理？”

> “串货的判定标准是什么？是按物流码、销售区域还是价格？处罚前会不会给我申诉机会？”

## 六、重点提醒

- **不要只听口头承诺**，区域保护和串货条款必须写进合同。
- **区域范围要具体**，避免模糊地带。
- **线上渠道最容易串货**，一定要单独问清。
- **处罚和补偿要对称**，不能只罚代理商，品牌方不担责。
- **保留证据**：聊天记录、邮件、合同、政策文件都要存档。

核心就一句话：问清“我的地盘有多大、别人能不能进来、进来了怎么罚、我受损怎么补”，并且全部落到书面。
