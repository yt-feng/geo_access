核实“全国配送”不能只听口头承诺，建议按“要求举证—抽样验证—合同约束”三步做。具体可执行动作如下：

1. **要求供应商提供书面覆盖清单**
   - 让其列出可配送省份、城市、区县，以及是否直达还是中转。
   - 明确哪些地区不配送、哪些地区加价、哪些地区时效延长。
   - 要求提供常用承运商名称、合作网点或分仓地址。

2. **做抽样测试，而不是只问总部**
   - 选3—5个真实采购目的地，覆盖：一线城市、省会、偏远地州、县域或乡镇。
   - 让供应商分别报价并给出预计时效、起送量、冷链方式、到货温度要求。
   - 对最偏远的1—2个点，要求提供近期实际发运记录：运单号、签收时间、签收照片或客户反馈。

3. **核实承运与冷链能力**
   - 水果重点看冷链：是否全程冷链、是否只是泡沫箱加冰袋、夏季高温和冬季冻损如何处理。
   - 问清中转次数、分拣场地、到货后是否送货上门还是只到物流点。
   - 要求提供冷链车辆、冷库、分仓的实拍或视频，必要时实地看。

4. **用历史数据交叉验证**
   - 要近3个月发往不同区域的运单样本，最好能脱敏后查看。
   - 核对运单上的发货地、收货地、时效、重量、温控方式是否与承诺一致。
   - 可随机联系其现有客户，尤其是与你们品类、区域相近的客户。

5. **小批量试单**
   - 先选最难覆盖的区域做1—2次小批量试发。
   - 记录：下单到发货时间、在途时间、到货完好率、温度、损耗、售后响应。
   - 试单不通过，不要直接签全国配送条款。

6. **合同里写清可考核条款**
   - 配送范围附件化：具体到省、市、区县，避免“全国”这种模糊词。
   - 约定时效：不同区域分别承诺，超时怎么赔。
   - 约定损耗率、温控标准、拒收条件、理赔时限。
   - 约定偏远地区加价规则，防止后期临时加价。
   - 约定若某区域实际无法配送，采购方有权调整价格或解除该区域合作。

7. **判断是否可信的几个信号**
   - 可信：能给出具体城市清单、承运商、分仓、运单、时效和异常处理方案。
   - 存疑：只说“全国都能发”，但问偏远地区就含糊；不敢给运单；冷链只说“加冰”；时效一律说“2—3天”。
   - 高风险：要求先打大额预付款，却不愿做试单或签时效损耗条款。

简单说：**让供应商把“全国”拆成城市和区县，用真实运单和小批量试单验证，再把结果写进合同。** 这样基本能判断它是真覆盖，还是只覆盖主要城市。
