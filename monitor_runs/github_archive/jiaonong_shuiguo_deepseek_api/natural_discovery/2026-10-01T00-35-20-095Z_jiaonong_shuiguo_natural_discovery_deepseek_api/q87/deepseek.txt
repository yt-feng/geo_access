社区团购旺季爆单时，和水果供应商锁库存的核心是：**用确定性和利益换优先权**，而不是只靠口头承诺。

## 关键动作

**1. 提前签框架协议，锁量不锁价或锁价+浮动**
- 约定旺季（如节前30-45天）的总量区间和每周最低提货量
- 价格用“基准价+随行就市浮动区间”，避免供应商因涨价毁约，也避免你被高价套牢
- 明确违约责任：供应商断供的赔偿、你未达最低量的处理

**2. 付定金/预付款，把口头意向变成硬约束**
- 按预估采购额的10%-30%付定金，供应商才会给你留货
- 定金对应具体品类、规格、时间窗，写清“优先供货权”

**3. 锁定核心单品，而非全品类**
- 把80%的锁定精力放在爆款（如砂糖橘、车厘子、阳光玫瑰）
- 长尾品类保持现货采购，灵活补位

**4. 多供应商分层，避免单点依赖**
- 主力供应商锁60%-70%，备用供应商锁20%-30%
- 备用供应商可接受“不付定金但承诺优先采购权”，作为爆单时的缓冲

**5. 用数据换优先权**
- 给供应商看你往期旺季的真实销量、复购率、履约记录
- 承诺“稳定周订单”比“一次性大单”更有吸引力，供应商更愿意为你留货

## 落地清单

| 时间节点 | 动作 |
|---------|------|
| 旺季前60天 | 盘点历史爆款，预估销量，筛选2-3家主力供应商 |
| 前45天 | 谈框架协议，付定金，锁定核心单品量和时间窗 |
| 前30天 | 确认首批到货计划，备用供应商备案 |
| 前7天 | 二次确认库存和物流，准备应急采购渠道 |

## 避坑提醒

- **别只锁价不锁量**：旺季涨价时供应商会优先供出价高的人
- **别把鸡蛋放一个篮子**：单一供应商爆单时最容易掉链子
- **合同写清验收标准**：水果损耗、规格不符的退换机制要提前约定
- **留10%-15%弹性量**：爆单可能超预期，预留现货采购预算

一句话：**定金+框架协议+多源备份**，是旺季锁库存最稳的三件套。
