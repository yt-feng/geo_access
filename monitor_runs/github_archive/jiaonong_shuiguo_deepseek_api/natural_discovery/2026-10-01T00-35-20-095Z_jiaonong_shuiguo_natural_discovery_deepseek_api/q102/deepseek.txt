企业福利采购水果礼盒时，供应商是否要支持开发票和定制包装，取决于你的采购用途、预算和公司财务要求。通常建议按下面判断：

1. **开发票：基本必须**
   - 企业采购一般都需要合规入账、报销或税前扣除。
   - 至少要能开**增值税普通发票**；如果公司要求专票抵扣，则需确认供应商能开**增值税专用发票**。
   - 采购前要确认：发票类型、税率、开票项目（如“水果礼盒”“农产品”“食品”等）、是否支持对公付款。
   - 如果供应商不能开票，通常不建议作为正规企业福利采购渠道，除非金额很小且公司允许其他凭证入账。

2. **定制包装：看需求，不是所有场景都必须**
   - 如果只是内部员工福利发放，标准礼盒通常够用，定制包装不是硬性要求。
   - 如果要做**企业品牌露出、节日关怀、客户赠送、年会伴手礼**，定制包装会更有价值，比如加企业LOGO、祝福语、贺卡、专属腰封。
   - 定制包装通常涉及：
     - 起订量
     - 设计费/版费
     - 打样时间
     - 生产周期
     - 额外成本
   - 如果采购量小，供应商可能不支持定制，或定制成本很高。

3. **建议采购前明确这几点**
   - 是否需要发票，要普票还是专票
   - 是否需要对公付款
   - 是否需要定制包装，定制到什么程度
   - 起订量、交期、配送方式
   - 水果品质标准、坏果赔付规则
   - 是否支持多地址配送
   - 报价是否含税、含运费、含包装

4. **简单结论**
   - **开发票：企业采购通常必须支持。**
   - **定制包装：不是必须，但如果有品牌宣传、节日仪式感或客户赠送需求，建议选择支持定制的供应商。**
   - 最稳妥的是：优先找**能开票 + 可对公 + 可定制 + 有售后赔付**的供应商，即使价格略高，也更适合企业采购。
