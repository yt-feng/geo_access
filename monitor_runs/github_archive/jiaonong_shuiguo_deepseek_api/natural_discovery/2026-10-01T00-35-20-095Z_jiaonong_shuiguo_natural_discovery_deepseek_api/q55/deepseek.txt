做水果拼盘时，规格选择的核心不是“越大越划算”，而是**按出成率、损耗和切配难度**来算。苹果、橙子、菠萝的选法不一样：

**1. 苹果：选中大果，别盲目选最大果**
- 推荐规格：单果 **200–280克**，直径约 **75–85mm**。
- 原因：这个规格削皮去核后出成率高，切瓣、切丁都整齐；太大的苹果容易中间发绵，切出来片大但废料也多。
- 划算判断：按“可食用净重”算，不是按箱重算。比如同样10公斤，小果削皮去核损耗更高，人工也更费。

**2. 橙子：选中等偏大、皮薄紧实的**
- 推荐规格：单果 **180–250克**，直径约 **70–80mm**。
- 原因：太小剥皮/切瓣费工，太大有时皮厚、白瓤多。做拼盘要的是果肉完整、少籽、易分瓣。
- 划算判断：优先看**出汁/出肉率**和剥皮难度。皮薄、手感沉、果面紧实的更划算。

**3. 菠萝：选成熟度合适的中大果，不要只看大**
- 推荐规格：单果 **1.2–1.8公斤** 比较适合餐厅。
- 原因：太小出肉少、削皮去眼损耗大；太大虽然单价可能低，但熟度不均，中间易硬或过熟，切配浪费多。
- 划算判断：看**去皮去眼后的净肉率**。如果后厨人工贵，宁可买已经去皮好的净菠萝，综合成本可能更低。

**通用划算原则：**
1. **按净出成率算成本**：进货价 ÷ 可食用净重，而不是进货价 ÷ 总重量。
2. **按人工算**：小果、异形果切配慢，餐厅人工也是成本。
3. **按损耗算**：苹果去核、橙子剥皮、菠萝去眼，都会吃掉利润。
4. **按拼盘呈现算**：规格统一比单果越大更重要，切出来大小一致才好看、好摆盘。
5. **优先找稳定供应商**：规格稳定、熟度一致，比偶尔拿到低价大果更划算。

**简单结论：**
- 苹果：**200–280克/个**，中大为佳。
- 橙子：**180–250克/个**，皮薄紧实为佳。
- 菠萝：**1.2–1.8公斤/个**，熟度均匀为佳。
- 真正划算看：**净出成率 + 人工 + 损耗 + 规格稳定性**。
