判断水果报价波动是否合理，核心不是看“涨了还是跌了”，而是看**波动有没有对应的驱动因素、幅度是否匹配、频率是否异常**。可以按下面几步操作。

## 1. 先建一个“基准价”体系，而不是每天从零判断

对每个单品建立三层价格锚：

- **历史同期价**：去年同月/同周的价格区间
- **近7天/30天移动均价**：判断今天偏离均值多少
- **产地/批发市场公开价**：如农业农村部批发市场价格、主要销地批发市场行情

判断标准可以是：

| 偏离幅度 | 初步判断 |
|---|---|
| 日波动 ±3% 以内 | 正常 |
| ±3%~8% | 需要看原因 |
| ±8%~15% | 明显异常，要求解释 |
| ±15% 以上 | 高风险，暂停或比价 |

具体阈值按品类调整：叶菜、草莓、荔枝等易腐品波动天然大；苹果、橙子、土豆等耐储品波动应较小。

## 2. 看波动是否有“可验证的原因”

合理波动通常能对应到具体事件：

- **天气**：产地暴雨、寒潮、台风、持续高温
- **季节切换**：尾季货少、新季刚上市
- **节日效应**：春节、中秋前需求集中
- **运输**：油价、运费、封路、冷链紧张
- **供需**：产地集中上市导致跌价，或某产区减产导致涨价

不合理波动的特征是：**只有报价变，没有原因；或者原因很笼统，比如“市场都涨了”。**

## 3. 用“比价”验证，而不是只听一家

至少拿3个来源交叉验证：

1. 当前供应商报价
2. 备用供应商报价
3. 批发市场/产地公开行情

如果别家没涨、批发市场没涨，只有这家涨，基本可判定为不合理。

## 4. 看频率和模式

异常模式包括：

- 一周内连续多次上调，但每次幅度不大，累积涨幅明显
- 每次都在你下单前临时涨价
- 涨价后过几天不回调，而市场价已回落
- 同一单品不同供应商价差突然拉大

合理波动通常是**有涨有跌、随行就市**；不合理波动往往是**单边上涨、只涨不跌**。

## 5. 用合同和规则提前约束

最有效的方法不是每天吵，而是事前约定：

- **报价有效期**：比如当日有效或24小时有效
- **调价触发条件**：只有公开市场价波动超过X%才可调
- **调价依据**：必须提供产地价、批发市场价或书面说明
- **比价机制**：采购方有权每周抽检市场价
- **异常处理**：偏离基准价超过X%时，可暂停下单或切换供应商

## 6. 实操判断流程

每天收到报价后，按这个顺序走：

1. 对比昨天、上周同期、近7日均价
2. 看偏离幅度是否超过品类阈值
3. 查产地天气、批发市场行情、节假日
4. 问供应商具体原因，要求给依据
5. 拿1~2家备用供应商比价
6. 原因成立且比价接近 → 接受
7. 原因不成立或只有一家涨 → 谈判、压价、换供应商

## 一句话结论

**合理波动 = 有外部原因 + 幅度匹配 + 多家同步 + 可验证；不合理波动 = 无原因 + 单边涨 + 只此一家 + 频率异常。**  
采购方最该做的，是建立基准价、保留比价渠道、在合同里写清调价规则，而不是每天凭感觉判断。
