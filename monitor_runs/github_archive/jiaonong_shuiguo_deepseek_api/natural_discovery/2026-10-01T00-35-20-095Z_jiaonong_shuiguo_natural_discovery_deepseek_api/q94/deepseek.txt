很重要，而且往往是便利店能不能把水果做起来的关键条件之一。

原因在于，便利店水果和大型商超、水果专营店是两种生意：

1. **便利店单店销量小、波动大**
   门店面积、客流、周边人群差异很大，同一款水果在不同店可能一天卖几盒，也可能一天卖几十盒。供应商如果只按大箱、大规格发货，门店要么压货损耗，要么干脆不敢上。

2. **水果损耗高，试错成本高**
   水果保质期短，尤其是切果、浆果、即食水果。不能小批量试卖，门店一次进货太多，卖不掉就报损，直接吃掉毛利。小批量试卖能让门店先用低成本验证“这个店、这个时段、这个价格能不能卖动”。

3. **小批量试卖能验证真实需求**
   比如先试 3—5 盒、1—2 个 SKU，观察 3—7 天的动销、损耗、复购和客诉。数据好再放量，数据差就换品或停掉。没有这个机制，门店只能靠猜。

4. **供应商支持小批量，等于帮门店控风险**
   理想的支持不只是“少发货”，还包括：
   - 小规格包装；
   - 多频次、小批量补货；
   - 临期或滞销调换；
   - 按门店分组配货；
   - 提供建议零售价和陈列方式；
   - 对试卖期给出退换或损耗分担。

5. **但也要看条件**
   如果供应商的小批量导致物流成本过高、单价明显上涨，门店也要算账。比较可行的方式是：
   - 首单小批量试卖；
   - 动销达标后转为稳定小批量补货；
   - 多家门店拼单，降低供应商配送成本；
   - 对高损耗品类设置更严的试卖周期和淘汰线。

所以，供应商能不能支持小批量试卖，不只是“重要”，而是便利店水果能不能低风险起步、逐步找到稳定畅销品的前置条件。没有小批量试卖，很多门店不是不会卖水果，而是不敢卖。
