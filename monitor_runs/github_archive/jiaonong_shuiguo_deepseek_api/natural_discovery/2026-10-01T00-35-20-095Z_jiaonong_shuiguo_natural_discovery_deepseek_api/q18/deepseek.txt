关键是先分清“你打算什么时候吃”，再按成熟度挑。

**1. 看用途定成熟度**
- **当天/1天内吃**：选已经黄透、带少量黑点（糖斑）的，闻起来有香蕉香。
- **2～3天后吃**：选整体黄色、两端还略绿、没有黑点的。
- **4～6天后吃**：选黄绿相间、果柄偏绿、捏起来硬的。
- **更久再吃**：选偏绿、很硬的，但别选完全青绿发亮的，可能熟得慢或口感差。

**2. 到店快速判断**
- **看颜色**：全绿太生；全黄带黑点偏熟；黄中带绿是中间档。
- **看果柄**：果柄绿且硬，通常更生；果柄发黄、发褐，通常更熟。
- **轻捏中部**：硬=生，略软=适口，明显软=熟，软塌=过熟。
- **看棱角**：棱角分明偏生；圆润饱满偏熟。
- **闻气味**：有淡淡果香=可吃；酒味/发酵味=过熟。

**3. 如果到店发现不合适**
- 太生：别放冰箱，室温放1～3天；和苹果/梨装同一袋可加速催熟。
- 太熟：马上冷藏，能多撑1～2天；适合做奶昔、香蕉面包。
- 已经切开：冷藏并尽快吃，别常温放。

**4. 最稳的做法**
如果你不能确定几天内吃完，**买黄中带绿、捏着硬中带一点弹的**，回家室温放；想快点熟就套袋加苹果，想慢点熟就单根挂起来、别挤压。
