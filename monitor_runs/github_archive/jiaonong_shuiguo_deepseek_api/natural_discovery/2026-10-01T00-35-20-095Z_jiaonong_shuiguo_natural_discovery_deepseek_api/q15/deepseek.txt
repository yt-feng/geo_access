水果店遇到坏果，结算或赔付方式主要看**采购模式、合同约定、坏果比例和发现时间**。下面按常见情况给你一套可执行的处理原则。

## 一、先分清是哪种采购模式

1. **一批一结、当场验收**
   - 当场挑出的坏果，直接不计入结算数量，或按净重结算。
   - 常见做法：扣重、扣款、补货三选一。
   - 如果已经付款，可要求下批抵扣或退款。

2. **长期合作、账期结算**
   - 通常按合同或口头约定处理：坏果率在约定范围内由水果店承担，超出部分供应商赔。
   - 常见约定是：**3%～5%以内自担，超出部分按实赔付**，但这不是法定统一标准，要看你们约定。

3. **代销、联营、配送平台**
   - 如果是代销，坏果通常由供应商承担，水果店只结算实际售出部分。
   - 如果是平台配送，按平台售后规则走，通常拍照上传后从货款扣减。

## 二、正常结算或赔付的几种方式

1. **扣重结算**
   - 收货时挑出坏果，按实际好果重量结算。
   - 适合当场验收、坏果明显的情况。

2. **扣款**
   - 已按总数结算的，按坏果数量×进货单价扣减货款。
   - 例如：进100斤，坏8斤，单价3元/斤，扣24元。

3. **补货**
   - 供应商下次补同等数量好果，或按坏果金额补货。
   - 适合长期合作、坏果批次性问题。

4. **退货退款**
   - 坏果比例很高、整批质量不达标时，可要求整批退回并退款。
   - 生鲜易腐，通常要**及时通知并保留证据**，否则可能被认定为你保管不当。

5. **折价销售后差额赔付**
   - 坏果还能降价处理，可按实际售价与正常售价差额，让供应商补差。
   - 例如正常卖5元/斤，坏果只能卖2元/斤，差额3元/斤由供应商承担。

## 三、实操上建议这样处理

1. **收货时当场验**
   - 尽量当着送货员面抽检、拍照、拍视频。
   - 让送货员在送货单上注明坏果数量并签字。

2. **保留证据**
   - 到货时间、批次、数量、坏果照片、视频、聊天记录、送货单。
   - 坏果不要马上全扔，至少留到和供应商确认完。

3. **及时通知**
   - 生鲜坏果有保鲜期，发现问题当天或约定时间内通知。
   - 拖太久，供应商可能不认。

4. **先协商，后扣款**
   - 最好先和供应商确认赔付方式，再在货款里扣。
   - 如果合同允许“直接扣款”，也要把扣款明细发给对方确认。

5. **写清结算单**
   - 结算单上写明：进货数量、坏果数量、扣款金额、补货数量、结余应付。
   - 双方微信或签字确认，避免下次扯皮。

## 四、如果没有合同，通常怎么谈

可以按这个顺序谈：

1. 坏果比例低：扣重或下批补货。
2. 坏果比例中等：按坏果金额扣款。
3. 坏果比例高：退货退款或整批折价。
4. 长期合作：约定一个坏果率，超出部分供应商赔。

常见行业做法是：**少量坏果双方分担，大量坏果供应商承担**。但具体比例没有统一法律标准，关键看你们事先怎么约定。

## 五、一句话总结

**当场验收的，直接扣重或扣款；已结算的，按坏果金额退款、补货或下批抵扣；整批质量差的，退货退款。核心是：及时通知、保留证据、按约定处理，没约定就按坏果比例协商。**
