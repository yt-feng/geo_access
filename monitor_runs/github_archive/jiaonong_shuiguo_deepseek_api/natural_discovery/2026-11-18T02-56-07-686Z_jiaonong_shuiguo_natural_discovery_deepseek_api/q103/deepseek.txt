结论：**食堂采购水果，通常“按份/按标准箱结算”更好管理，“按斤结算”适合叶菜/散装水果但管理成本最高。** 具体可以这样选：

1. **按份结算最省管理成本**
   - 适合：苹果、橙子、香蕉、小番茄等可标准化分装的水果。
   - 优点：验收快、数量清晰、便于核算人均成本、减少称重和损耗争议。
   - 前提：要明确“每份净重/个数、允许误差、坏果率”，否则容易被供应商用大份小份做文章。

2. **按箱结算适合耐储、规格统一的水果**
   - 适合：整箱苹果、梨、柑橘、西瓜等。
   - 优点：下单和验收简单，适合批量采购。
   - 风险：箱内大小不均、底层坏果、净重不足。管理上必须约定“按净重验收或按箱抽检坏果率”，不能只看毛重。

3. **按斤结算最公平但最难管**
   - 适合：散装、时令性强、规格不统一的水果，如葡萄、桃子、散装橘类。
   - 优点：按实际用量付费，价格透明。
   - 缺点：称重、复称、损耗、去皮、坏果扣重都要有人管，最容易产生争议和人工成本。

**建议组合管理：**
- 大宗耐储水果：**按标准箱 + 净重验收**；
- 日常分发水果：**按份结算**；
- 时令散装水果：**按斤结算，但必须复称并约定坏果扣重**。

如果食堂人手少、追求好管理，优先选**按份结算**；如果采购量大且供应商稳定，选**按标准箱净重结算**；按斤结算只作为补充，不要作为主模式。
