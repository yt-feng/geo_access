优先看你的门店类型、客流结构和损耗管理能力，不能一概而论。给你一个可执行的判断框架：

**1. 先看门店场景**
- **社区生鲜店/水果专营店**：整果更适合做主销，切果做补充。社区客流复购高，整果耐放、可挑、价格敏感，整果毛利和损耗更可控。
- **商超卖场/大店**：整果和切果可以并行，但切果要放在动线入口或试吃区附近，承担“即买即吃、冲动消费”的角色。
- **写字楼/商圈便利店型**：切果更适合，整果需求弱，切果满足即时消费。
- **学校、医院、交通枢纽**：切果明显更有优势，整果可以少量做低价引流。

**2. 再看菠萝品类特点**
菠萝整果有“挑、削、泡盐水”的门槛，很多年轻顾客不会处理，切果能降低购买阻力，但切果损耗高、保质期短、人工成本高。整果则客单价低、耐储、适合家庭采购，但需要现场服务能力。

**3. 用数据做决策**
建议你先做2周小测试：
- 整果和切果分两个陈列位，记录**销量、毛利、损耗率、人工耗时、客单价**。
- 判断标准：切果如果**损耗率超过15%—20%**，或人工耗时明显挤占高峰人手，就不要主推；整果如果**动销慢、顾客反复问“能不能削”**，就说明切果有需求。
- 更稳的做法是：**整果做主销，切果做试吃和小份装**，切果用“半个/小盒”降低损耗，而不是一开始就大盒切好。

**4. 推荐组合**
多数商超更稳妥的是：
- **整果为主**：家庭客群、价格带完整、可现场提供削皮服务。
- **切果为辅**：小盒装、当日现切、限时折扣清货，放在收银台或试吃区。
- **不要同时大量备货**：切果按预估销量的70%备货，整果按正常周转备货，切果卖不完及时转试吃或打折，避免损耗失控。

**结论**：如果你门店家庭客群为主、有现场服务能力，**整果为主、切果为辅**更合适；如果商圈即时消费强、年轻客群多，**切果为主、整果少量补充**。先用两周小批量测试，按损耗和动销数据定比例，不要凭感觉全押一边。
