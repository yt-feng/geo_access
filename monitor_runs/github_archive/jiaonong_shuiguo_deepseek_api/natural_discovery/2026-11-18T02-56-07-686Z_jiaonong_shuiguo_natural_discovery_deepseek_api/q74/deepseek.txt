做餐饮客户，菠萝和香蕉要按“用途场景”分规格备货，而不是只按大小分级。下面给你可直接落地的规格组合。

## 一、菠萝（餐饮客户）

餐饮用菠萝主要分三类用途，规格按用途配：

| 用途场景 | 建议规格 | 采购要点 |
|---|---|---|
| 鲜切果盘/自助餐 | 单果1.2–1.5kg，果形端正、冠芽完整 | 成熟度7–8成，耐放、切面好看 |
| 炒菜/咕咾肉/菠萝饭 | 单果0.8–1.2kg，可略偏生 | 酸度够、纤维适中，耐高温 |
| 榨汁/饮品店 | 单果1.5kg以上大果或次果 | 出汁率高，可接受外观瑕疵，成本优先 |

**备货比例建议**：鲜切类40%、烹饪类40%、饮品/加工类20%。餐饮客户初期先各备少量试单，别一次性压大果。

**关键提示**：菠萝餐饮客户最在意“去皮损耗率”和“稳定供应”，建议固定2–3个产地/品种轮换，避免单一品种断档。

## 二、香蕉（餐饮客户）

香蕉餐饮用途相对集中，规格按“成熟度+单根重量”配：

| 用途场景 | 建议规格 | 采购要点 |
|---|---|---|
| 果盘/自助/酒店 | 单根120–150g，梳形整齐 | 到货7成熟，可催熟分批出 |
| 烘焙/甜品/饮品 | 单根150g以上大果 | 成熟度高、香气足，可接受表皮斑点 |
| 员工餐/食堂 | 中果100–130g，性价比款 | 耐储运，成熟度6–7成 |

**备货比例建议**：果盘类50%、烘焙饮品30%、食堂类20%。

**关键提示**：餐饮客户对香蕉最大痛点是“成熟度不可控”。建议按客户用量做“青果+催熟果”分批到货，或提供7成/8成/9成三种成熟度选项，让客户自己排期。

## 三、给你的实操建议

1. **先做客户画像再备货**：餐饮客户分酒店自助、连锁快餐、饮品店、食堂四类，规格需求差异大。先问清客户主要用途，再定规格。
2. **小批量多规格试单**：每个规格先备1–2箱，跑2–3周看动销，再放量。
3. **标注损耗率**：给餐饮客户报价时，菠萝按“去皮净重”报、香蕉按“可食根数”报，比按毛重报更容易成交。
4. **固定分级标准**：自己定一套简单的A/B/C级（按单果重量+外观），写进报价单，避免每次扯皮。
