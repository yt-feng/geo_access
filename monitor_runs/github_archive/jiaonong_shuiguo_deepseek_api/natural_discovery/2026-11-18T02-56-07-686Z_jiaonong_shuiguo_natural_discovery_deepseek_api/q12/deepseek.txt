判断菠萝采购熟度，核心不是“越熟越好”，而是按**预计卖出速度**定熟度档位，并把门店损耗控制在可接受范围。可以这样操作：

1. **按周转天数定采购熟度**
   - 当天或1天内能卖完：可采**七八成熟到近熟**，香气明显、果眼略软，适合现切现卖。
   - 2～3天卖完：主采**七成熟左右**，外观转黄但果身还较硬，室温回熟后分批上架。
   - 超过3天：主采**六至七成熟**，青黄交界、果身硬，少量搭配近熟果做当日销售。

2. **现场看外观**
   - 果皮由青转黄、黄色面积约1/3～1/2，通常适合做2～3天周转。
   - 全黄或大面积深黄，适合当天促销，不适合大量压货。
   - 避免果眼发黑、渗汁、底部霉斑、果皮明显皱缩。

3. **闻香气**
   - 果底有淡淡甜香：可回熟，适合短期周转。
   - 香气浓烈、带发酵味：已偏熟或过熟，只适合少量当日卖。
   - 完全无香且很青：回熟时间长，适合做储备但不适合马上陈列。

4. **按压和手感**
   - 轻按果身略硬、有弹性：较安全。
   - 一按就软、局部塌陷：过熟，损耗风险高。
   - 果身过硬且无香：偏生，需较长时间回熟。

5. **看果眼和底部**
   - 果眼浅、饱满、间距均匀，通常可食率高。
   - 底部切口新鲜、干爽、无酸味；有酒味或湿腐味不要采。
   - 冠芽青绿挺拔说明较新鲜；冠芽枯黄不一定代表果肉熟，但要结合果身判断。

6. **采购结构建议**
   - 不要把同一批全采成一个熟度。可按 **6成偏生、3成七至八成熟、1成近熟** 搭配，先卖熟果、后卖生果。
   - 夏季高温回熟快，采购熟度整体下调半档；冬季或冷柜存放可略高半档。
   - 到店后分级陈列：近熟果放显眼位置优先卖，偏生果放后区回熟，过熟果立即切果盒或做促销。

简单记：**看黄色面积、闻底部香气、轻按果身硬度，再按2～3天周转选七成熟为主。** 如果门店销量稳定，最好连续记录几天“到店熟度—售完天数—损耗率”，两三轮后就能定出最适合自己店的采购熟度。
