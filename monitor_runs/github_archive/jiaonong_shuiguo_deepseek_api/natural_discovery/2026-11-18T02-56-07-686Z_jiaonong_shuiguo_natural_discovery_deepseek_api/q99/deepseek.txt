选下午茶水果供应商，关键不是“哪家便宜”，而是先锁定批量配送里最容易出问题的环节，再按可核验标准筛。下面给你一套可直接执行的采购判断框架。

## 一、先明确自己的约束条件
采购前先写清这5项，供应商筛选才有依据：
1. **人数与份量**：多少人、每人约多少克、是否需要按部门分装。
2. **配送时间窗**：下午茶通常要求14:00—15:30送达，能否接受提前30分钟到。
3. **配送地址与卸货条件**：是否有电梯、前台是否代收、能否进楼层。
4. **预算区间**：按人均算，如8—15元/人，便于比较。
5. **水果形态**：整果、切果拼盘、果切盒。批量下午茶优先选**易分食、不易氧化、不需要现场加工**的品类。

## 二、适合批量配送的水果选择
优先选：**香蕉、橘子/沃柑、圣女果、葡萄（无籽）、苹果、梨、冬枣**等耐运输、易分发的水果。
谨慎选：**切开的西瓜、哈密瓜、火龙果、牛油果**，易出水、氧化、需要冷藏和现场处理。
如果选果切，必须确认：**冷链配送、切配时间、保质期标注、是否含冰袋**。

## 三、供应商筛选的硬标准
按优先级核验：

1. **批量配送能力**
   - 是否有固定配送车辆和冷链能力；
   - 是否能承诺送达时间窗，迟到如何处理；
   - 是否支持分装到部门/楼层，包装是否便于分发。

2. **品控与损耗承诺**
   - 是否允许到货抽检；
   - 坏果、烂果、缺斤少两的赔付规则；
   - 是否按“净重”还是“毛重”计价，包装是否计入重量。

3. **资质与票据**
   - 营业执照、食品经营相关资质；
   - 能否开票，发票类型和税率；
   - 是否有食品安全责任险（有则加分，非必需）。

4. **报价透明度**
   - 要求报“含配送费、包装费、税费”的到货总价；
   - 同一规格、同一净重下比价，避免用低价毛重吸引、到货缩水。

5. **应急能力**
   - 临时加量能否当天补送；
   - 配送延误或品质问题的响应时间；
   - 是否有备用供应商。

## 四、建议的采购流程
1. **先小单试配**：选2—3家各下一单，同一时间、同一品类，实际比较到货品质、重量、准时率和包装。
2. **到货验收**：当场称重、抽检坏果率，拍照留证；坏果率超过约定比例（如5%）按规则扣款或补送。
3. **合同/订单写明**：送达时间窗、净重标准、坏果赔付、迟到处理、分装要求、发票类型。
4. **固定主供+备供**：主供承担日常，备供应急，避免单一供应商临时掉链子。

## 五、快速判断口诀
**能准时送到、净重不缩水、坏果有赔付、能分装好分发、能开票**——满足这5条再谈价格。价格低但毛重计价、无赔付、无时间承诺的，不适合批量下午茶。
