小批量试单的核心目标不是“赚钱”，而是用最低成本验证四件事：品质稳定性、履约可靠性、账期与结算可信度、售后可追责性。建议按下面设计。

## 1. 试单规模怎么定
- **单品小批量、多品类验证**：不要一次押一个爆品。选 3～5 个计划长期做的品类，每品 1～2 个 SKU，单 SKU 试单量控制在“你 2～3 天能消化掉”的量，避免压货。
- **总量参考**：试单总金额控制在你单周水果采购额的 10%～20%，或首次合作不超过你愿意承担的“可损失金额”。
- **分两批下单**：第一批极小量验货，合格后第二批略放大。不要一次把量给足。

## 2. 先谈清楚再下单
下单前书面确认（微信文字也算，但要留痕）：
- 品种、规格、等级、单果重/果径范围、糖度底线、成熟度、允许瑕疵率
- 包装方式、箱规、净重与毛重、是否含耗材
- 单价、是否含税/含运费、卸货费谁承担
- 发货时间、运输方式、预计到货时效、温控要求
- **损耗与售后规则**：到货验收时限、拍照留证要求、坏果/短重/规格不符怎么赔、补货还是退款
- 结算方式：首次合作建议**货到验收合格后付款**或少量定金+到货结清，不建议首次就给长账期或大额预付

## 3. 验收标准要可量化
到货当场做验收记录：
- 抽检比例：每批至少抽 3～5 箱，记录坏果率、规格达标率、糖度（有条件的用糖度计）
- 称重核对净重，拍照留存开箱、称重、坏果
- 设定红线：如坏果率超过约定值、规格达标率低于约定值、到货延迟超过约定小时数，即触发扣款/补货/终止后续放大
- 验收单双方确认，作为后续结算依据

## 4. 试单期间重点观察
- **品质稳定性**：同一 SKU 两批货是否一致，比单批好坏更重要
- **履约**：是否按约定时间发、是否临时换规格/换产地、沟通响应速度
- **问题处理**：出现坏果/短重时，对方是痛快解决还是推诿——这比价格更决定能否长期合作
- **隐性成本**：损耗率、退货率、分拣人工、客户投诉，算“到岸可用成本”而不是只看报价

## 5. 试单后的决策
- 设一个明确的放大条件：如连续 2～3 批坏果率低于约定值、准时到货率达标、售后响应及时，再逐步把单量提到正常采购的 30%～50%
- 试单不合格就换供应商，不要因为“价格便宜”迁就品质不稳
- 保留 2 家备选供应商，首次合作不要独家依赖

一句话：**小批量、多品类、短周期、严验收、到货结、看售后**。试单是买“信息”和“可信度”，不是买低价。
