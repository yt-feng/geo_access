社区超市卖小包装香蕉，采购时重点抓“包装适配小份量、损耗可控、周转快”三件事。下面按可执行要点说。

**一、包装选择**
1. **按售卖单位选规格**：主推2—3根/袋，重量约300—500克；再配少量4—5根家庭装。不要一开始上太多规格，先测2—3个SKU。
2. **优先透气包装**：香蕉呼吸强，袋装必须打孔或选网袋、透气膜袋；全封闭塑料袋容易结露、发黑、长霉。
3. **避免过度密封和挤压**：袋口不要完全热封死，留透气孔；托盘+收缩膜要注意不要勒伤果指。
4. **标签位置**：价签贴袋面中部，不要直接贴果皮；贴果柄附近易撕破果皮。
5. **陈列包装**：小包装适合挂条、浅筐平铺或层架前端，避免堆叠压伤。包装上可印“即食/需放熟”提示，减少顾客误判。

**二、采购时的果品与批次控制**
1. **成熟度分批**：门店当天卖的和后两天卖的不要同一成熟度。采购时要求“青黄搭配”：一部分微黄可即食，一部分偏青可放1—2天。
2. **按销量定采购量**：香蕉损耗高，首单宁少勿多。按日销量1—1.5倍备货，先跑一周数据再调。
3. **看果柄和棱角**：果柄完整、果指饱满、棱角不明显但不过软；有裂口、水烂、黑斑连片的不进小包装。
4. **要求产地/批次一致**：小包装最好同批次同成熟度，避免一袋里有的已熟有的还青，顾客体验差。
5. **运输防护**：采购运输用周转筐，内垫软纸或珍珠棉，不要直接压箱；香蕉怕冷，避免和冷藏品混装。

**三、损耗控制要点**
1. **到店快分装**：到货当天完成挑拣分装，别整箱闷放。分装时剔除伤果、断柄果，伤果可转特价散卖，不进正价小包装。
2. **控温控湿**：香蕉适宜13—15℃，不要进冷库低温区；夏季避免空调直吹和阳光直射，湿度高时加强通风。
3. **先进先出**：小包装标注分装日期，货架每日翻检，先卖黄度高的。
4. **分级处理**：微斑果可做“熟香蕉特价袋”；过熟果及时下架做果切/烘焙原料或报损，不要留在正价区。
5. **建立损耗台账**：按SKU记录日进货、日销量、报损量，连续一周看哪个规格损耗高，及时砍规格或调采购量。

**四、采购谈判时可提的要求**
- 要求供应商按“小包装适用果”供货，明确不要水烂、裂口、机械伤；
- 争取小批量多频次配送，比如一周2—3次，降低门店库存压力；
- 先小批量试销，约定残次果退换或折价规则。

**建议起步方案**：先做2根装和3根装两个规格，透气打孔袋+挂条陈列，首周每日采购量按预估日销的1.2倍，记录损耗后再扩规格。
