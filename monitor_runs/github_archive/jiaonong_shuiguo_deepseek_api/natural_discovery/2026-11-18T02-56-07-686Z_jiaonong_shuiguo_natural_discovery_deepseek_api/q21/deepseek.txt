超市采购水果时，通常需要供应商提供以下资料（以中国大陆常规商超/生鲜采购为背景，具体以当地监管和超市内控为准）：

1. **营业执照、食品经营许可证/仅销售预包装食品备案**（供应商主体资质）
2. **产地证明或供货证明**：如产地村委会/合作社/基地证明、收购凭证、购销合同、发货单、进货台账等，证明来源合法可追溯
3. **食用农产品承诺达标合格证**：很多地区对蔬菜水果等食用农产品要求随附，属于常见进货查验材料
4. **农药残留检测报告**：供应商自检或委托第三方检测的报告；超市常要求批次对应，重点项目如有机磷、氨基甲酸酯类等
5. **第三方检测报告**：针对农残、重金属等项目的委托检测报告，通常要求在有效期内并覆盖相应品类/批次
6. **进货票据/随货同行单**：发票、送货单、销售单等，便于超市建立进货查验记录
7. **进口水果**：还需海关入境货物检验检疫证明、报关单等；标签应符合进口食品相关要求
8. **绿色食品/有机/地理标志等认证**：如宣称相应认证，需提供有效认证证书
9. **包装标签/合格证明**：预包装水果需符合标签标识要求；散装水果应有品名、产地、供货者等信息

建议超市在合同中明确：每批次随货提供合格证/检测报告/送货单，定期提供第三方检测报告，并保存进货查验记录。具体检测项目和证明形式，应按当地市场监管部门要求和超市自身食品安全制度执行。
