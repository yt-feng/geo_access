# 水果到货品质不一致的验收与售后处理

## 一、到货前先定标准（最关键）

品质争议多半是"验收标准没写清"。采购合同/订单里最好明确：

- **规格等级**：果径/单果重范围、糖度（如可测）、成熟度、色泽
- **允许偏差**：例如"同批次不符合规格的果品不超过 5%"，超出即视为整批不达标或按比例扣款
- **包装与损耗**：净重还是毛重、允许损耗率（如 2%–3%）
- **验收时限**：到货后多少小时内提出异议有效（生鲜常用 2–24 小时）
- **售后条款**：不合格部分退换、补发、折价或扣款的具体方式

## 二、到货验收怎么做

1. **当场开箱抽检**：按批次随机抽箱（如每 10 箱抽 1 箱），不要只验最上面一层。
2. **分层检查**：上层、中层、底层各抽，重点看底层是否有压伤、烂果、以次充好。
3. **拍照录像留证**：开箱全过程、问题果品特写、称重照片，最好带时间水印。
4. **称重核对**：净重与订单比对，扣除包装和合理损耗。
5. **分类记录**：合格数、规格不符数、腐烂/压伤数、缺斤少两量，逐项登记并由送货人签字确认。
6. **不合格处理**：明显腐烂变质的当场拒收或单独隔离，避免污染合格品。

## 三、售后怎么谈

- **先按合同条款走**：有约定按约定（退换/补发/折价/扣款）。
- **分级处理**：
  - 少量瑕疵：折价接收，按不合格比例扣款
  - 比例较大或影响使用：要求补发或整批退换
  - 腐烂变质：坚决退换，费用由供应商承担
- **书面确认**：售后结果用微信/邮件/验收单书面确认，写明数量、金额、补发时间，避免口头扯皮。
- **保留追责依据**：多次出现品质问题的供应商，记录在案，作为后续合作或更换依据。

## 四、给单位的实操建议

- 固定 1–2 名验收人，配电子秤、糖度计（可选）、拍照手机。
- 建立简易验收单模板：批次、品种、数量、抽检比例、不合格数量、处理意见、双方签字。
- 首次合作供应商先小批量试单，稳定后再放量。
- 生鲜到货尽量安排在上班时间，便于当场验收，避免"下班到货、次日才发现问题"。

核心一句话：**标准写进合同、抽检覆盖底层、全程拍照留证、售后书面确认**。
