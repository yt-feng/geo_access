更划算的核心不是“单价最低”，而是**按出品率、损耗和出盘效果选规格**。按餐厅水果拼盘常用场景，建议这样选：

1. **苹果：选中等偏大果，80–85mm 或 75–80mm**
   - 太小的苹果切块少、削皮去核后出品率低，拼盘显得碎。
   - 太大的苹果单价高，但切块数量不一定明显增加，且切开后易氧化，剩半果损耗大。
   - 更划算的做法：选**75–80mm、果形端正、硬度高**的规格，适合切瓣或切块；如果拼盘以整片摆盘为主，再升到80–85mm。

2. **橙子：选70–75mm左右的中大果，优先看皮薄和出汁率**
   - 橙子规格过大，皮厚、白瓤多的情况常见，切瓣后不好看，出肉率未必高。
   - 规格过小，切瓣数量多但每瓣小，摆盘费工。
   - 更划算：选**70–75mm、皮薄、无籽或少籽**的脐橙/甜橙类，按“出肉率”和“切瓣数”算，不只看箱价。

3. **菠萝：选1.2–1.5kg左右的中果，优先成熟度稳定**
   - 菠萝太大，单果处理时间长，一次用不完冷藏后风味下降，损耗高。
   - 太小，削皮去眼后净肉少，出品率低。
   - 更划算：选**1.2–1.5kg、成熟度7–8成、果眼浅**的规格；如果拼盘量大且当天能用完，可适当上到1.5–1.8kg压单价。

**采购判断公式：**
- 先算净料率：苹果约70%–80%，橙子约55%–65%，菠萝约45%–55%，具体随品种和刀工变。
- 用“每份拼盘净料成本 = 毛料单价 ÷ 净料率 × 每份用量”比较，而不是只比每斤/每箱价格。
- 拼盘水果建议**规格中等、成熟度一致、果形均匀**，比追求大果更划算，因为切配损耗和摆盘人工更低。

**简单结论：**
- 苹果：75–80mm 中果优先。
- 橙子：70–75mm 中果优先，看皮薄少籽。
- 菠萝：1.2–1.5kg 中果优先。
- 若拼盘走高端大块摆盘，苹果可升到80–85mm、菠萝可到1.5–1.8kg，但必须当天用完。
