判断哪个规格更容易出货，不要凭感觉，建议用下面这套可执行的方法，一周到两周就能得出结论。

**1. 先给规格定清楚**
按重量/个头/成熟度把菠萝分成明确档位，例如：
- 小果：1.0–1.3斤
- 中果：1.3–1.8斤
- 大果：1.8–2.5斤
- 特大：2.5斤以上
再区分成熟度：青果、微黄、熟果。规格不统一，后面数据没意义。

**2. 用“出货速度”而不是“卖了多少”判断**
每个规格每天记录：
- 到货量
- 当天出货量
- 剩余库存
- 出货天数（清完一批用几天）
- 损耗/坏果率
- 成交价和让价幅度

核心指标：
- **周转天数 = 平均库存 ÷ 日均出货量**
- **动销率 = 当天出货量 ÷ 当天可售库存**
- **损耗率 = 坏果重量 ÷ 到货重量**

周转天数短、动销率高、损耗低、让价少的规格，就是更容易出货的规格。

**3. 分渠道看，不要混在一起算**
同一规格在不同渠道表现可能相反：
- 批发市场大货：中果、大果通常走量快
- 商超/水果店：中果、外观均匀的规格更稳
- 社区团购/路边摊：小果、便宜规格更容易出
- 餐饮/果汁店：大果、次果可能更受欢迎

按渠道分别统计，才能知道“对谁好出货”。

**4. 做小规模对比测试**
连续7–10天，每个规格保持相近到货量，固定价格策略，记录每天出货。不要同时大幅调价，否则分不清是规格好卖还是价格便宜。

**5. 看利润，不只看速度**
容易出货不等于赚钱。算每个规格的：
- 毛利 = 售价 − 进价 − 损耗 − 运费/人工分摊
- 单位时间毛利 = 毛利 × 出货速度

有些小果出得快但毛利薄，大果出得慢但单件利润高，要结合库存风险判断。

**6. 简单判断标准**
优先主推同时满足以下条件的规格：
- 周转天数最短
- 动销率最高
- 损耗率最低
- 让价幅度最小
- 单位时间毛利不低于其他规格

如果两个规格冲突，比如小果出得快但损耗高、大果出得慢但利润高，就看你的资金和仓储压力：怕压货选快周转，仓容足、资金稳可搭配高毛利规格。

**7. 实际操作建议**
- 先连续记录10天，不要只凭一两天
- 每天固定时间盘点库存
- 把“询价次数”和“实际成交”分开记，询价多但成交少说明价格或质量有问题
- 每周复盘一次，调整主推规格和采购比例

结论：**用周转天数、动销率、损耗率、让价幅度四个指标分渠道对比，连续记录7–10天，出货最快且综合毛利不差的规格，就是更容易出货的规格。**
