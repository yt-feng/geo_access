连锁门店跨城市分布时，评估水果供应商仓配覆盖要按“仓—线路—时效—损耗—成本”逐层看。

## 1. 评估维度

1. **仓网覆盖**
   - 供应商有几级仓？产地仓、区域中心仓、城市配送仓分别覆盖哪些城市？
   - 每个城市门店能否由固定仓直配，还是需要中转？
   - 中转次数越多，水果损耗和到店品质风险越大。

2. **配送半径与时效**
   - 明确各门店到最近仓的公里数、承诺送达时效。
   - 区分常温、冷藏、冷冻或控温水果的运输要求。
   - 重点看次日达、隔日达覆盖率；水果连锁建议门店补货以次日达为主，长线要评估前置仓。

3. **线路与频次**
   - 是否固定线路、每日发车，还是凑单发车？
   - 门店订货频次与供应商配送频次是否匹配。
   - 跨城线路要考虑节假日、天气、高速限行对到店时间的影响。

4. **损耗与品质保障**
   - 运输时长、装卸次数、温控能力直接影响损耗。
   - 要求供应商提供分品类历史损耗率，并约定到店验收标准。
   - 高损耗品类如浆果、叶菜类，优先选择短半径、少中转的仓配方案。

5. **成本结构**
   - 比较运费、起订量、配送附加费、退换货成本。
   - 不要只看单价，要算“到店成本 = 采购价 + 运费分摊 + 损耗成本 + 缺货损失”。

6. **应急能力**
   - 某城市临时缺货时，供应商能否跨仓调拨？调拨时效多久？
   - 是否有备用承运商和备用仓。

## 2. 可执行的评估方法

- **画覆盖地图**：把全部门店按城市标注，叠加供应商仓位置，标出直配、中转、超距门店。
- **做门店分层**：A类高销量店、B类常规店、C类偏远店，分别设定时效和成本要求。
- **设覆盖率指标**：
  - 次日达门店覆盖率；
  - 单程配送半径内门店占比；
  - 中转门店占比；
  - 分品类到店损耗率；
  - 订单满足率与缺货率；
  - 每店每月仓配成本。
- **试运行验证**：选3—5个代表城市，跑2—4周真实订单，记录到店时间、损耗、缺货和费用。
- **合同约定**：把时效、损耗上限、缺货赔付、临时调拨响应时间写进服务条款。

## 3. 判断标准

供应商仓配覆盖是否合格，建议至少满足：

- 核心城市门店次日达覆盖率≥90%；
- 偏远门店有明确的中转或隔日达方案；
- 高损耗品类运输时长可控，损耗率可量化；
- 仓配成本占门店水果采购额比例在可接受范围内；
- 突发缺货能在约定时间内调拨补位。

如果供应商只在少数城市有仓、跨城依赖长途中转，且无法承诺时效和损耗，就不适合作为全国主供，最多做区域补充或单品补充。
