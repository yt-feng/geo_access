先别按“供应商推荐量”下，建议用**最小可验证试卖量**：以你能在**7～10天内卖完、且损耗可承受**的量下单。没有品类数据时，可先按下面规则定：

1. **首次试卖量 = 预计单店/单渠道日均销量 × 3～5天**
   - 新水果、未验证口感：取3天量；
   - 有类似品类销售基础、供应商稳定：取5天量；
   - 只做陈列测试，不做主推：取1～2天量。

2. **设置上限，避免压货**
   - 叶菜类水果、浆果、熟度高易损品：单店首单不超过**2～3天销量**；
   - 苹果、柑橘、梨等耐储品：可到**5～7天销量**；
   - 多门店测试时，先选**1～2家代表性门店**，不要全渠道铺开。

3. **用金额兜底**
   - 首单金额控制在**该品类日销售额的3～5倍**以内；
   - 新品首单占总水果采购额建议不超过**5%～10%**，小店取低值。

4. **试卖前先定验收和止损线**
   - 到货抽检：规格、糖度/口感、坏果率、成熟度；
   - 3天内看动销：若日均销量低于预期**50%**，立即促销或调拨；
   - 损耗率超过**5%～8%**（易损品可放宽到10%），暂停追加；
   - 复购/顾客反馈差，直接停止二次采购。

5. **最稳的做法**
   先向供应商要**小规格试销装/混装小箱**，首单按“**1家店 × 3天预估销量**”试卖；卖得动再按周补货，连续两周动销稳定后再扩店。这样损失可控，也能验证真实复购。
