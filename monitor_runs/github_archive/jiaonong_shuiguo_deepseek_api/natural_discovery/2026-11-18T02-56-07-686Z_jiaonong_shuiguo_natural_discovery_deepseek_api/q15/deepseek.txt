水果店遇到坏果，结算或赔付通常按“先止损、再定责、后扣款/换货”的顺序处理。可执行做法如下：

1. **到货当场验货**
   - 开箱拍照/录像：坏果整体、坏果切面、箱唛/批次、称重数量。
   - 当场分拣：好果、可折价果、坏果分开，坏果单独存放别混卖。
   - 在送货单上注明坏果数量、品种、批次，让司机/供应商签字确认；对方不签就拍照留证并当天发微信/邮件确认。

2. **按合同或行规定赔付方式**
   优先看采购合同/订单约定；没有约定时常见处理：
   - **换货**：坏果补发同等数量好果，运费由责任方承担。
   - **扣款**：按坏果实际数量×进货单价扣减货款；也可按“坏果率”折算整批扣款。
   - **折价接收**：轻微瑕疵但可销售，协商降价后自行处理。
   - **退货**：坏果比例高或整批不合格，整批退回并拒付该批货款。
   - 注意：一般只赔坏果本身，不默认赔“卖不出去的机会损失”；若合同有约定或能证明供应商明知故犯，可另谈。

3. **扣款要有依据**
   - 扣款金额=坏果数量×进货单价（或合同约定比例）。
   - 在结算单上写明：批次、到货日期、坏果数量、扣款金额、依据（合同条款/验货记录/照片）。
   - 保留聊天记录、验货照片、送货单签字、转账记录，至少留到该批结算完成后一个账期。

4. **沟通话术**
   “X月X日批次XX，到货开箱发现坏果X斤，已拍照并单独存放，送货单上已注明。按进货价X元/斤，本批应扣X元，剩余货款X元结算。请确认，或安排补发同等数量好果。”

5. **预防下次**
   - 合同写明验收标准、坏果率上限（如超过3%可整批退货）、赔付时限（到货24小时内提出）、运费承担。
   - 固定验收流程，司机在场时完成抽检/开箱。
   - 对新供应商先小批量试单，避免大额压货。

如果对方拒赔：先书面催告并暂停该供应商后续订货；金额较大可依合同走调解/诉讼，小额通常以扣货款和换供应商更划算。
