可以直接把采购要求写成“熟度分级 + 到货窗口 + 验收动作”三条，别只说“要青一点”。

1. **熟度要求**
   - 香蕉按色泽/成熟度分级采购：日常零售主推 **2～3级（偏青、微黄）**，到店后还能卖3～5天；不要一次性进大量4级以上（明显黄熟）的货。
   - 给供应商明确比例：例如 **70%偏青、30%微黄**，微黄用于当天和次日走量，偏青用于周转。
   - 要求“同一批次熟度尽量一致”，避免一箱里有的已黄、有的还很青。

2. **到货时间要求**
   - 优先要求 **清晨到货或开店前1～2小时到货**，避开中午高温和闭店前到货。
   - 缩短在途和卸货时间：要求供应商 **冷链/遮阳运输**，到店后立即入阴凉通风处，不堆在太阳下或闷热仓库。
   - 订货频率改为 **小批量、多频次**，例如旺季隔天到、淡季每周2次，而不是一次压一周货。

3. **采购合同/订单里写清验收标准**
   - 到货抽检：青蕉比例、黄蕉比例、机械伤、受冷/受热、发黑霉点。
   - 明确拒收条件：熟度超过约定、箱内温度过高、明显水烂/黑斑/断指过多。
   - 要求供应商按“到货后预计可售天数”供货，而不是只按价格供货。

4. **店内配合动作**
   - 到货后先拆箱通风，青蕉与黄蕉分开存放；黄蕉及时上架或冷藏延缓后熟。
   - 先进先出，微黄货优先促销/做果切。
   - 记录每批到货熟度和坏损率，连续两次不达标的供应商减少订单。

一句话采购话术：**“只要2～3级偏青蕉为主，微黄不超过三成；清晨到货、遮阳运输、小批量多频次；熟度超标和黑斑水烂按验收标准拒收。”**
