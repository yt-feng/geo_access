选水果供应商，核心不是“找最便宜的”，而是先定验收标准，再比谁能稳定达标。建议按下面做。

**1. 先定采购与验收标准**
- 按品类写清：品种、产地/等级、单果规格、成熟度、色泽、允许瑕疵率、农残检测要求、包装方式、到货时间。
- 香蕉：查青熟度、果指饱满度、无黑腐/机械伤，明确催熟责任和到货成熟阶段。
- 苹果：查果径、硬度、糖度、碰伤/苦痘病比例，避免“外观好但口感差”。
- 橙子：查果径、皮厚、可溶性固形物、汁水感，明确酸度接受范围。
- 每批抽检：数量、重量、坏果率、规格偏差、农残合格证明；不合格退换和扣款写进合同。

**2. 供应商来源优先级**
优先顺序建议：
1. 本地一级批发市场里有固定档口、能做学校配送的果商；
2. 产地合作社/种植基地直供，适合量大且品类集中；
3. 有冷链和分拣能力的食材配送公司，适合多品类、小批量、天天送；
4. 大型商超供应链或区域生鲜平台，作为应急备选。
不建议只找二道贩子或临时摊贩，价格可能低但稳定性和追溯差。

**3. 必须核验的资质**
- 营业执照、食品经营许可/相关备案；
- 农残检测报告或承诺达标合格证；
- 供货来源证明、产地证明或采购凭证；
- 配送车辆和仓储卫生条件；
- 食品安全责任险、退换货和应急补货能力；
- 学校要求高时，做现场考察：分拣场、冷库、检测环节。

**4. 比价不要只比单价**
按“到货可食用净重单价”比较，把坏果率、损耗、运费、退换货成本算进去。比如报价低但坏果率5%，实际成本可能高于报价高但坏果率1%的供应商。要求供应商按固定格式报价：品名、规格、产地、单价、起送量、配送频次、结算账期、涨跌价机制。

**5. 试供和小批量验证**
先选2—3家试供2—4周，重点看：
- 到货准时率；
- 抽检合格率、坏果率；
- 规格是否稳定；
- 缺货时补货速度；
- 对账和票据是否规范。
试供通过后再签框架合同，保留1家备选供应商。

**6. 合同关键条款**
写清质量标准、验收方法、不合格处理、价格调整机制（比如按批发市场周均价联动）、食品安全责任、追溯要求、配送时间、违约责任、账期和退出机制。香蕉这类后熟水果，还要写清到货成熟度和催熟责任。

**简单判断标准：**能提供稳定规格、检测凭证、冷链配送、坏果退换、价格联动机制，并愿意先小批量试供的供应商，优先合作；只靠口头承诺低价、无法追溯来源的，不选。
