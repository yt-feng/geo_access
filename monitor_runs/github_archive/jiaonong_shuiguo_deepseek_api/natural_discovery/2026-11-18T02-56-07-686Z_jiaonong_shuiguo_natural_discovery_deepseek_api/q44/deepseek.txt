判断供应商售后响应稳不稳定，不能只听承诺，建议用“事前问清、事中试用、事后留证”三步做可验证的筛选。

**1. 事前问清，要求可核验的承诺**
- 直接问：售后联系人是谁、电话/微信是否7×12小时可接、到货后出现烂果/催熟不均/重量短缺，多久内响应、多久内给处理方案。
- 要求写进合同或订单备注：响应时限（如2小时内回复）、处理时限（如24小时内补货或折价）、责任界定标准（按到货批次抽检、拍照留证）。
- 问清是否支持“到货验收异议期”，比如签收后4小时内可提质量异议，避免卸完货就不认。

**2. 事中做小单测试，看真实反应**
- 先下一笔小批量试单，故意在正常工作时间提一个售后问题（如个别菠萝黑心、香蕉青熟不均），记录对方首次回复时间、是否推诿、是否给明确方案。
- 再在非工作时间或周末发一次售后消息，看是否有人接、是否次日才回。商超生鲜售后常发生在早间到货，周末响应能力很关键。
- 观察补货或折价是否按承诺兑现，而不是只口头答应。

**3. 事后留证，建立简单考核**
- 每次售后记录：问题描述、提报时间、首次回复时间、解决时间、结果。
- 合作1—2个月后看数据：平均响应时长、超时次数、是否反复出现同类问题。连续两次超时或推诿的，降低采购份额或换备选。
- 合同里留备选供应商，避免单一依赖。

**快速判断信号：** 有固定售后对接人、合同写明响应时限、愿意小单试售后、历史客户可回访——相对可靠；只说“放心，有问题找我”、不写时限、试单售后就拖延——风险较高。
