最应该先问**售后**，其次配送，最后才是价格。

原因是团购团长卖的不只是水果，是“邻里信任”。水果非标、易损耗，一旦坏果、缺斤少两、延迟到货，团长要直接面对邻居投诉；价格再低，售后兜不住，团长会用自己的口碑和赔付来填坑。

建议按这个顺序判断：

1. **售后（一票否决项）**
   - 坏果、烂果、压伤怎么赔：按比例赔、拍照秒赔，还是必须整单退？
   - 赔付时效：到货后几小时内反馈有效？超过谁承担？
   - 缺斤少两怎么处理：补差、补发还是退款？
   - 是否要求团长先垫付赔付？垫付周期多长？
   - 有没有书面规则，还是口头承诺？

2. **配送（决定履约稳定性）**
   - 到团时间是否固定，误差多大？
   - 是送到小区点位还是只到城市仓/自提点？
   - 破损、延误、漏送谁负责？
   - 临时改量、加单的截止时间和费用？
   - 夏季/雨季有没有冷链或保鲜措施？

3. **价格（最后谈，但要看总成本）**
   - 不要只比进货价，要算：损耗率 + 赔付成本 + 团长人工 + 配送费。
   - 问清楚阶梯价、起订量、账期、押金、退换货是否影响返点。
   - 低价但售后差的供应商，通常总成本更高。

一句话判断：**售后规则不清楚的供应商，价格再低也不要选；配送不稳定的，只能小批量试；价格放到最后谈，用试团数据压价。**

实操上，先拿小批量试团一次，重点记录坏果率、到货准时率、赔付响应速度，再决定是否长期合作。
