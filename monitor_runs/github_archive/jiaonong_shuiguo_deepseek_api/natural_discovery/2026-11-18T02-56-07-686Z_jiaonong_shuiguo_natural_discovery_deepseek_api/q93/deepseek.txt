三个都要管，但优先级和管控重点不同：**鲜切菠萝的关键风险是微生物和汁液流失，所以第一优先是“保质期+温度”，第二是“包装与操作卫生”，配送频次是保障前两者的手段。**

按便利店场景给你一个可执行判断：

1. **保质期（最高优先）**
   - 鲜切水果属于高风险即食食品，必须明确标注：切分时间、保质截止时间、贮存条件。
   - 便利店冷柜销售建议保质期很短，通常按门店到货/切分后数小时到当天管理，不要跨天售卖；具体时限以当地监管和供应商标准为准。
   - 到货即贴签，先进先出，临近截止时间下架，不做“打折续命”。

2. **包装（第二优先，但直接决定保质期能否成立）**
   - 必须用食品级密封盒/袋，防汁液渗漏、防交叉污染；标签不能被汁液浸花。
   - 检查封口完整、无胀袋、无渗漏；冷藏陈列温度要稳定，不能频繁开关柜导致结露。
   - 包装上要能追溯：切分日期/时间、保质期、批次或门店信息。

3. **配送频次（保障手段，不是越频繁越好）**
   - 鲜切菠萝更适合**小批量、高频次、冷链配送**，减少门店库存和临期损耗。
   - 但频次必须配合冷链温度和到货验收：到货测中心温度、查包装和标签，不合格拒收。
   - 如果配送频次低但冷藏链稳定、销量可预测，也可以；反之高频但断冷链，风险更大。

**一句话决策：** 先定死“切分后多久必须下架”的保质期规则和冷藏温度，再用合格包装封住，最后用配送频次和订货量保证门店不压货。三者中，保质期和温度是红线，包装是防线，配送频次是调节阀。
