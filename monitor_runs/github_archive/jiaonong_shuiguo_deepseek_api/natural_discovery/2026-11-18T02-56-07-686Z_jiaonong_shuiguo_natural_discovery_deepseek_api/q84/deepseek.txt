家庭水果礼盒建议按“2个耐放主果 + 1个香甜果 + 1个应季/亮点果 + 香蕉少量点缀”来组合，最稳。

**推荐组合：苹果 + 橙子 + 菠萝 + 香蕉**
- **苹果 4个、橙子 4个、菠萝 1个、香蕉 1小把（5-6根）**
- 适合3-4口家庭，总重约5-6斤，价位容易控制。
- 苹果、橙子耐放，菠萝有“礼盒感”，香蕉负责香甜和家里老人小孩都容易吃。
- 香蕉容易催熟其他水果，建议**单独装袋或放在最上层**，并选稍微青一点的。

**如果更偏性价比，改成：**
- 苹果4个 + 橙子6个 + 菠萝1个 + 香蕉4根
- 减少香蕉，避免家庭一次吃不完。

**如果更偏“礼盒好看”，改成：**
- 苹果4个 + 橙子4个 + 菠萝1个 + 香蕉5根
- 苹果选大小均匀、红度好的；橙子选表皮亮的；菠萝选中等偏小但饱满的。

**不建议：**
- 香蕉放太多，家庭吃不完且容易坏。
- 菠萝太大，占盒子且处理麻烦。
- 苹果和橙子混太杂，礼盒看着乱。

**包装建议：**  
苹果、橙子垫底，菠萝侧放或单独隔开，香蕉用纸袋/网套固定在上层；盒内放一张“香蕉先吃、菠萝尽快处理”的小提示卡，减少售后。
