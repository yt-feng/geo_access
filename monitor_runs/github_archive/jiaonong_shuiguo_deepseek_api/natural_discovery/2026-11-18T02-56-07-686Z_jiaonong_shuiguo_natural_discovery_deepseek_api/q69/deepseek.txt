可以按“品类+等级+规格+单价单位+起批量/箱规”做成一张报价表，口头和微信报价都用同一套口径，最清楚。香蕉和菠萝不要混用同一分级逻辑，建议分开。

**一、香蕉分级报价**
香蕉主要看：品种、条数/把重、长度、粗细、成熟度、表皮瑕疵、箱规。

| 等级 | 判断标准 | 报价口径 |
|---|---|---|
| A级 | 果指长、粗细匀，条形直，无黑斑/机械伤，成熟度统一，适合水果店陈列 | 元/箱，注明每箱净重、把数/条数、几成熟 |
| B级 | 轻微花皮、少量斑点或条形略弯，不影响食用 | 元/箱，注明瑕疵类型和比例 |
| C级/处理级 | 黑斑较多、压伤、成熟不匀，适合促销或加工 | 元/箱或元/斤，注明损耗和当日处理价 |

报价示例格式：
“香蕉A级，净重18斤/箱，约5-6把，7成熟，XX元/箱，5箱起；B级同规格XX元/箱，允许10%以内花皮。”

**二、菠萝分级报价**
菠萝主要看：品种、单果重、果形、成熟度、冠芽完整度、黑心/烂果率、箱规。

| 等级 | 判断标准 | 报价口径 |
|---|---|---|
| A级 | 单果重均匀，果形正，冠芽完整，成熟度一致，无软烂黑心 | 元/箱，注明每箱几个、单果重区间、净重 |
| B级 | 果形略偏、单果重不匀或轻微表皮瑕疵，不影响果肉 | 元/箱，注明单果重区间和瑕疵比例 |
| C级/加工级 | 小果、偏形、表皮瑕疵多或成熟偏高，适合削卖/加工 | 元/箱或元/斤，注明当日处理原因 |

报价示例格式：
“菠萝A级，XX品种，每箱6个，单果2.5-3斤，净重约16斤，8成熟，XX元/箱，3箱起；B级每箱8个，单果1.8-2.5斤，XX元/箱。”

**三、让报价更清楚的执行规则**
1. 所有价格标明：等级、品种、箱规/净重、单果重或条数、成熟度、起批量、是否含运费、是否包售后。
2. 香蕉按“箱+净重+条数/把数”报；菠萝按“箱+个数+单果重区间”报，避免只写“一箱多少钱”。
3. 明确损耗售后：香蕉允许花皮比例、菠萝允许烂果/黑心比例，超出部分怎么赔或补。
4. 每天或每批更新价格时，只改价格和成熟度，分级标准固定，发给小店时用同一张表。

最简单的做法：做一张微信报价单，上半部分香蕉、下半部分菠萝，每行写“等级—规格—成熟度—单价—起批量—售后标准”，小店老板一眼就能对比下单。
