优先看你要卖的“线上场景”是即时零售/次日达到家，还是社区团购/预售自提。结论先说：

**大多数生鲜电商起步，优先选“整果”做主品；切配适合做高客单/即时达的补充；冷冻原料不建议作为普通生鲜电商的主力，除非你做B端、烘焙/饮品原料或长保冻品频道。**

### 1. 整果：最适合线上主销
适合原因：
- **损耗可控**：菠萝耐运输，整果比切配抗压，退换货争议少。
- **履约成本低**：不需要冷链切配环境，常温/普通仓配即可，适合次日达和团购。
- **毛利与定价空间大**：可按规格、产地、品种做差异化。
- **售后边界清楚**：坏果包赔容易界定。

注意点：
- 要控制成熟度，线上发货别发过熟果，否则到家易烂。
- 规格要统一，避免“大小果混发”引发差评。
- 菠萝有“黑心”“水心病”等风险，采购要抓批次验收。

**判断：整果是线上生鲜最稳的主力SKU。**

### 2. 切配：适合补充，不适合无冷链小商家做主品
适合原因：
- **便利性强**：即食菠萝、果切拼盘客单价高，适合即时零售、办公室下午茶。
- **差异化好做**：可做去皮切块、盐水浸泡、拼盘组合。

不适合做主力的原因：
- **保质期极短**，切配后需冷藏，履约窗口窄。
- **损耗和食安风险高**：切配环境、人员卫生、冷链断链都会放大投诉。
- **退货争议多**：出水、氧化、口感变化容易差评。
- **需要冷链仓/前置仓能力**：没有即时达网络，不建议铺。

**判断：有前置仓、即时达、果切运营能力时，切配可做利润补充；否则先别碰。**

### 3. 冷冻原料：不适合普通生鲜电商主力
适合原因：
- **保质期长、损耗低**，适合冻品频道、B端餐饮/饮品店、烘焙原料。
- **标准化程度高**，适合做长期SKU。

不适合普通生鲜电商的原因：
- **家庭C端认知弱**：普通消费者买菠萝更偏向鲜食，冷冻菠萝原料使用场景有限。
- **需要冷冻仓储和冷链履约**，成本高。
- **客群不同**：B端、饮品店、烘焙店才是更匹配的客户。
- **复购逻辑不同**：不是“今天吃水果”的需求。

**判断：除非你做B端供应链、冻品专营或饮品原料，否则不要作为线上生鲜主推。**

### 建议的组合策略
- **主品：整果**，做引流和稳定复购。
- **补充：切配**，只在有冷链/即时达能力时上，做高客单。
- **冷冻原料：单独渠道**，面向B端或冻品频道，不和鲜果混卖。
- **SKU节奏**：先用整果测产地、规格、成熟度和售后率；数据稳定后再上切配；冷冻原料作为独立业务验证。

**一句话：线上卖菠萝，整果最稳、切配看履约能力、冷冻原料看客群。普通生鲜电商优先整果。**
