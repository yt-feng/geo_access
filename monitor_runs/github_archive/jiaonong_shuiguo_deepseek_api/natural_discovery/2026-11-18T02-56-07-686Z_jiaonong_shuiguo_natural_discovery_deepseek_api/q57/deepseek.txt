建议优先采用**中央厨房统一收货**，但前提是水果品类、冷链和配送体系能支撑；门店只保留少量本地化、易损或应急采购权限。对多数餐饮连锁，这不是二选一，而是“总部统采+中央厨房收货为主，门店有限补充”的模式。

**判断标准**
- 水果是否标准化程度高、耐储运：苹果、橙子、西瓜、香蕉等适合统收；草莓、蓝莓、鲜切水果、成熟度高的即食水果更适合短链配送或门店少量验收。
- 门店是否有足够验收能力：门店人员忙、缺乏品控经验时，分开收货容易标准不一、损耗和舞弊增加。
- 冷链和配送频次是否匹配：中央厨房到门店配送频次低，易损水果会增加周转损耗；配送频次高则统收优势明显。
- 采购规模是否足以议价：统收能集中量、统一等级和价格，分开收货会削弱议价和供应商管理。
- 食品安全追溯要求：统收更利于供应商准入、批次留样、农残检测和追溯；门店分散收货追溯链条更长。

**中央厨房统一收货的优势**
- 集中议价、统一规格和验收标准，降低采购成本和品质波动。
- 农残检测、批次追溯、供应商考核更容易标准化。
- 减少门店验收人力、收货时间和腐败风险。
- 便于中央厨房统一清洗、分切、配送，提高出品一致性。

**门店分开收货的优势**
- 对草莓、蓝莓、鲜切水果等易损品，缩短链路、减少中转损耗。
- 可灵活应对门店临时缺货、本地特色水果和配送不及时。
- 门店最接近销售端，能快速反馈品质和销量变化。

**推荐落地方式**
1. 将水果分为A/B/C类：A类耐储统采统收；B类统采、中央厨房验收后高频配送；C类易损或本地特色品，总部定供应商和价格，门店按标准收货并上传验收记录。
2. 建立统一验收标准：等级、成熟度、糖度、规格、损耗率、农残检测、拒收规则。
3. 中央厨房设水果专用冷藏/催熟/分拣区，控制配送频次和温控。
4. 门店保留应急采购额度，但必须走总部备案供应商，禁止随意采购。
5. 用数据考核：损耗率、到货合格率、缺货率、单店水果成本，按季度调整品类归属。

**结论**：如果水果采购量大、门店多、品质和食安要求高，选中央厨房统一收货更好；如果水果以高易损鲜切品类为主且配送半径长，采用“中央厨房统采统收+门店少量短链补充”更稳。单纯让门店全部分开收货，通常不利于成本、标准和食安管控。
