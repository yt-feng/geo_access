可以按“提高每次购买件数/搭配金额”来做，而不是只打折。给你一套可直接落地的组合促销方案。

## 1. 主推组合：做“果篮/果盒套餐”提升客单
**组合A：日常家庭装**
- 香蕉1把 + 苹果4个 + 菠萝1个
- 定价：单买合计约X元，套餐价设为X-3~5元
- 话术：**“一周水果组合，省5元”**
- 目的：让只买香蕉的人顺带买苹果、菠萝

**组合B：周末果切/果盒组合**
- 香蕉2根 + 苹果2个 + 菠萝半个
- 做成预包装果盒或“自选果切组合”
- 定价：比单买略低，但毛利靠加工和便利性补回
- 适合：年轻人、上班族、带娃家庭

**组合C：早餐水果包**
- 香蕉3根 + 苹果3个
- 定价：整包优惠2~3元
- 菠萝单独做“加购价”：买早餐水果包，菠萝半个加购价优惠
- 目的：用高频香蕉、苹果带低频菠萝

## 2. 用“加购”提高客单价
在香蕉、苹果堆头旁放标识：
- **买香蕉1把，菠萝立减2元**
- **买苹果满10元，香蕉半价加购1把**
- **买任意两款，第三款8折**

注意：加购价要算清毛利，别把高频引流品做成亏损。

## 3. 做“阶梯满额”而不是单品直降
- 满15元：送香蕉1根或小苹果1个
- 满25元：菠萝切片盒立减3元
- 满35元：送果切盒/环保袋

这样顾客为了凑满额，会自然多拿苹果、菠萝。

## 4. 陈列组合要配合
- 香蕉放端头引流，旁边紧挨苹果和菠萝套餐；
- 套餐用统一托盘/网袋/果篮打包，标“原价/套餐价/省多少”；
- 菠萝可提前削皮切盒，降低购买门槛；
- 苹果按大小分级，套餐用中果，避免拉低整体毛利。

## 5. 建议先跑7天小测试
选一家门店做A/B：
- A区：单品原价
- B区：组合套餐 + 加购价 + 满额赠
每天记录：客单价、套餐销量、香蕉/苹果/菠萝动销、损耗率。

**判断标准：**
- 客单价提升≥8%，且综合毛利不降，可全店推；
- 若菠萝损耗上升，改为“半个菠萝/切片盒”参与组合；
- 若套餐卖不动，先降组合门槛，不要直接大幅打折。

**推荐优先执行：**
1. 先上“香蕉+苹果+菠萝家庭装”；
2. 同步做“买香蕉加购菠萝半价/立减”；
3. 周末加“满25元菠萝切片立减3元”。

这三步最容易执行，也最能拉动客单。
