判断水果供应商的合规与稳定性，可以从“资质文件、实地/抽检、履约记录、合同约束”四条线交叉验证，不要只看报价。

**一、合规性核验（先排除硬伤）**

1. **主体资质**
   - 营业执照经营范围含“食品销售/食用农产品销售”；若供应商是合作社或农户直供，确认其能提供产地证明或自产自销证明。
   - 要求提供法定代表人/负责人身份证明、开票信息，避免个人账户收款无凭据。

2. **食品安全资质**
   - 食品经营许可证（如当地对食用农产品销售有要求）；仅销售初级食用农产品通常可豁免，但采购方应留存说明。
   - 近期的**农产品质量安全检测报告**：重点看农残项目（如有机磷、氨基甲酸酯类）和检测机构资质（CMA/CNAS）。
   - 若供应商声称“绿色/有机”，查验对应认证证书及有效期，证书编号可在认监委或相关认证机构官网核对。

3. **冷链与运输能力**
   - 水果若涉及切配或冷链配送，确认冷藏车/保温箱、温度记录；养老院和医院对即食水果、切果的微生物风险更敏感，冷链不合规应一票否决。

4. **人员与场所**
   - 配送人员健康证（接触直接入口食品时必要）；仓储场所卫生条件、防鼠防虫设施。
   - 现场查看或视频验厂：分拣区、冷藏库、退货区是否分区，是否有明显交叉污染。

**二、稳定性判断（看持续供货能力）**

1. **供货历史与客户结构**
   - 要求提供近6—12个月同类客户（医院、养老院、学校、企事业单位食堂）供货合同或验收单，重点看是否有连续供货记录，而非只有一两张发票。
   - 询问其日均供货量、峰值供应能力，以及主要产地/批发市场来源。单一产地、单一品种依赖度高的供应商，价格和断供风险更大。

2. **履约与应急机制**
   - 合同中明确：缺货替代方案、到货时限、质量不合格退换货时限、节假日和极端天气保供措施。
   - 要求供应商说明上游货源：是否有多个产地/批发商备份，是否有冷库周转库存。

3. **财务与经营稳定性**
   - 通过国家企业信用信息公示系统查经营异常、行政处罚、严重违法失信记录；查司法涉诉情况（重点看买卖合同纠纷、食品安全相关处罚）。
   - 对成立时间短、注册资本低但承诺大量供货的供应商保持谨慎，可要求履约保证金或缩短账期。

**三、用“小批量试供+验收数据”验证**

- 先签1—3个月试供合同，按批次验收：到货重量、规格、新鲜度、农残快检（食堂可配快检设备或委托第三方）、损耗率、退货响应时间。
- 建立评分表：合规文件完整性、到货准时率、验收合格率、异常处理速度、价格波动幅度。连续2—3个周期不达标即淘汰。
- 保留每批次检测报告、送货单、验收记录，既是管理依据，也是监管检查时的追溯材料。

**四、合同里必须写清的条款**

- 食品安全责任：因供应商水果导致食源性事件的赔偿与追责。
- 质量标准：品种、规格、成熟度、新鲜度、农残限量依据（如GB 2763）。
- 退换货：不合格批次无条件退换，费用由供应商承担；连续不合格可解除合同。
- 价格机制：约定调价周期和参考依据，避免随口涨价。
- 保密与廉洁条款：防止采购人员与供应商利益输送。

**实操建议：** 先做资质审查表（营业执照、许可证、检测报告、健康证、保险），再做现场或视频验厂，然后小批量试供1个月，用验收数据决定是否进入年度供应商名单。对养老院和医院，优先选择有同类机构供货经验、能提供批次检测报告、有冷链能力的供应商，价格不是第一权重。
