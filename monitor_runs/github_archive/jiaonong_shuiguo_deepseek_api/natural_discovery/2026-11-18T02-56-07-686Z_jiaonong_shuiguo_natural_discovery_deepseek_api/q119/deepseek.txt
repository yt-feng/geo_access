水果供应商选择中，最容易被忽视的往往不是“价格贵不贵”，而是影响长期稳定性的隐性细节。重点看这几类：

1. **同等规格下的稳定性，而不是单次样品好坏**
   - 样品好不代表批量稳定。要问：同一规格的糖度、果径、成熟度、色泽波动范围是多少？
   - 要求连续看3—5批货，而不是只看一批。
   - 关键指标：次果率、损耗率、到货成熟度是否一致。

2. **产地与季节切换能力**
   - 只靠单一产地，遇到天气、病虫害、集中上市结束就会断供。
   - 要确认供应商是否有替代产区、冷库周转、跨季供应方案。
   - 问清楚：某个单品下市后，他能否稳定供替代规格或替代品种。

3. **采后处理与冷链细节**
   - 预冷是否及时、分选是否规范、包装是否适配运输距离。
   - 很多损耗不是水果本身差，而是采后处理不到位。
   - 重点看：采摘到预冷的时间、运输温度记录、包装抗压性。

4. **分级标准是否可执行**
   - “大果”“精品”这类模糊说法最容易扯皮。
   - 要落到可检验标准：果径范围、糖度下限、外观缺陷允许比例、成熟度区间。
   - 最好有书面验收标准，而不是口头承诺。

5. **缺货和涨跌价时的履约表现**
   - 行情好时谁都愿意供货，行情紧时是否优先保老客户，才是长期合作关键。
   - 了解供应商在缺货时是提前告知、替代供货，还是临时涨价、断供。
   - 可问：过去一年有没有因行情毁约或临时加价的情况。

6. **损耗责任与售后边界**
   - 到货后多长时间内可反馈？坏果怎么赔？是按比例补货还是折价？
   - 运输途中损耗、自然失水、成熟度差异，责任怎么分。
   - 这些不提前写清楚，长期合作最容易积累矛盾。

7. **供应商的客户结构**
   - 如果它主要供商超、批发市场还是电商，标准不同。
   - 客户太集中或太分散都有风险：太集中可能优先保大客户，太分散可能服务不稳定。
   - 了解它对你这个采购量级别的重视程度。

8. **资金和结算承受力**
   - 账期、押金、临时资金周转能力，会影响旺季能否持续供货。
   - 供应商资金链紧张时，往往在旺季暴露问题。

9. **信息透明度**
   - 是否愿意提供产地、批次、采摘时间、农残检测等信息。
   - 不要求每次全提供，但长期合作应能追溯到批次。

10. **替换成本**
   - 不要只看眼前供应，要看换供应商时重新磨合分级、包装、物流的成本。
   - 长期稳定合作应逐步建立“主供应商+备用供应商”结构，避免单一依赖。

实操建议：先小批量试3—5批，记录每批的到货损耗、糖度、规格偏差、售后响应；同时保留一个备用供应商。选择供应商时，把“稳定履约、分级可执行、损耗责任清楚”放在价格之前，长期看更省钱。
