判断商超采购香蕉的催熟能力是否稳定，关键不是看“这一批黄不黄”，而是看供应商/批次在相同催熟条件下能否重复达到目标色阶和货架期。可执行判断如下：

1. **看到货成熟度是否一致**
   - 同一批次青蕉的“饱满度、棱角、条长、粗细、青度”应基本一致。
   - 随机抽3—5箱，每箱抽5—10把，记录青蕉色阶分布。若同箱内差异大、箱与箱差异大，催熟稳定性通常差。
   - 重点看是否有“大小混装、老嫩混装、受冷/受热果”，这些会导致催熟不齐。

2. **要求供应商提供催熟记录**
   - 看最近3—5批的催熟曲线：入催熟房色阶、温度、湿度、乙烯浓度/处理方式、出房色阶、达到目标色阶所需天数。
   - 稳定供应商的批间差异应小：同目标色阶所需天数波动小，出房后黄熟均匀，货架期稳定。
   - 不要只看“催熟后好看”，要看“从青到目标色阶的可重复性”。

3. **做小批对比试验**
   - 每批到货留样：同条件、同房、同药剂/乙烯处理，记录第2、3、4、5天色阶变化。
   - 用固定色阶卡或拍照比对，至少连续跟3批。
   - 判断标准：达到目标色阶的天数批间差不超过1天；同批果指色差不超过1个色阶；软腐、青条、僵果比例低且稳定。

4. **看催熟后的一致性指标**
   - 出房时整箱黄熟均匀，无“青头、青尾、半边黄”。
   - 果指软硬一致，果柄脱落正常，无大量断指。
   - 催熟后24—48小时货架表现稳定，不出现突然发黑、软烂、梅花点异常增多。

5. **追溯产地与季节因素**
   - 同一产区、同一果园、同一采收季的稳定性通常更好。
   - 雨季、低温季、远途运输、冷藏受冷果，催熟稳定性会明显下降。
   - 采购时要求供应商标明产区、采收周、运输温度记录，避免混批。

6. **看供应商的催熟设施与管理**
   - 是否有独立催熟房、温湿度记录、乙烯浓度控制、通风换气记录。
   - 是否按饱满度、来源、到货时间分房催熟，而不是混装一房催。
   - 是否有人工记录和异常处理记录，这比口头承诺可靠。

7. **用数据建立验收标准**
   - 建议每批记录：到货色阶、饱满度、催熟天数、出房色阶、均匀度、损耗率、货架期。
   - 连续3批以上数据稳定，才可判定该供应商/该产区催熟能力稳定。
   - 若批间催熟天数波动超过1—2天、同批色差明显、损耗率忽高忽低，应降量或换源。

**简单结论：**看“同批一致性 + 连续批次可重复性 + 催熟记录 + 小批试验数据”。只凭单批外观或供应商口头保证，不能判断催熟能力稳定。
