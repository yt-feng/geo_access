# 多门店、单店量小：适合的水果供货模式

## 先判断你的真实需求

单店量小意味着：**你缺的不是低价，而是稳定、少批量、多频次、有人兜底的供货。** 因此选供货模式的核心标准应是：

- 最小起订量（MOQ）能不能压到你单店能吃下的量
- 配送频次能否一周 3–5 次，而非一次压一周的货
- 损耗和退换能不能分摊（水果最大的成本是烂掉）
- 品类能不能一站配齐，避免你向 5 家供货商各订一点点

## 几种模式，按适配度排序

**1. 城市二级批发商 / 本地配送商（最推荐起步）**
从一级市场拿货、再分送给小门店的中间商。特点：起订量低、可拼车配送、品类相对全。代价是加价率比一级市场高 5–15%，但省下你自采的人工和损耗，通常划算。适合门店在 5–30 家、单店日销水果几百到一两千元的阶段。

**2. 产地/一级市场“拼单集采 + 第三方城配”**
把多家门店需求汇总成一张单，直接向产地或一级市场采购，再委托城配或自建小冷链分拨。**关键前提：你必须有中央汇总订单的能力**（哪怕用微信群+表格）。量不够时不要硬做，起订量吃不下就是压货烂果。

**3. 区域水果供应链公司 / 餐配平台的生鲜线**
这类公司做“多品类、小批量、定时达”，通常有系统下单、有售后。适合你想减少选品和采购人力、愿意让出一部分毛利换省心。注意谈清：缺货替代规则、损耗赔付比例、账期。

**4. 产地直采（暂不建议为主）**
单店量小做直采，起订量、冷链、分拣、损耗全压在自己身上，除非某个单品（如应季爆款）能凑够整车，否则只做补充。

**5. 批发市场自采（保留为调节手段）**
用于补货、抓行情、买应急爆品，不建议作为主供，人力成本太高。

## 建议的组合打法

**主供 1 家本地配送商（保底、保频次）+ 1 家区域供应链公司（补品类/做促销品）+ 批发市场自采（抓应季和补缺）**，三家并行、按单品比价分配，避免被单一供货商卡脖子。

## 谈供货时要盯死的 5 个条款

1. **最小起订量与配送门槛**：按店还是按总仓？能否隔日达？
2. **损耗与退换**：到货坏果谁承担、比例多少、多久内可退。
3. **缺货替代**：断货时是同价替代还是退款，别让它悄悄换成差货。
4. **价格机制**：是随行就市日报价，还是锁周期价；涨价提前几天通知。
5. **账期与结算**：现结还是账期，直接影响你的现金流。

## 一句话结论

**单店量小、门店多的阶段，优先找“本地二级配送商 + 区域生鲜供应链”做小批量高频配送，自己保留批发市场自采做调节；等门店汇总订单量够起订量了，再往“集采+城配”升级。** 不要一上来就追求产地直采，那是有量之后的事。
