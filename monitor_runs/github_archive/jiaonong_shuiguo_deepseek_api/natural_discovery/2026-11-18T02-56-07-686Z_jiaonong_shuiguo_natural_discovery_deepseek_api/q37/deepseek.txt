商超会员日水果活动，供应商要提前配合的重点不是“到时候送货”，而是把**货量、品质、价格、陈列、补货、售后**六件事在活动前锁定。可按下面清单准备：

1. **活动方案与货量预估提前确认**
   - 提前确认会员日主题、促销品项、促销价、活动时段、限购规则、预估销量。
   - 供应商按门店/区域拆分备货量，预留10%—20%安全库存，尤其是引流爆品。
   - 明确断货、超卖、天气影响的应急预案和替代品项。

2. **价格与费用提前锁定**
   - 促销供货价、原供货价、毛利空间、费用承担方式提前书面确认。
   - 明确是否含运费、损耗补贴、陈列支持、赠品、试吃物料。
   - 避免活动前临时涨价或减少促销支持。

3. **品质标准与验收标准前置**
   - 约定果径、糖度、成熟度、色泽、瑕疵率、包装规格、农残检测要求。
   - 会员日客流大，成熟度要略控，避免“上午好看、下午软烂”。
   - 明确拒收标准和异常处理时限。

4. **到货计划与补货机制**
   - 给出分批次到货计划，不要一次性压货到店。
   - 爆品安排活动前1天和活动当天早间补货，设置二次补货窗口。
   - 明确紧急补货响应时间、最小补货量、配送车辆和联系人。

5. **包装、分拣与陈列物料**
   - 提前完成分级分拣、预包装、称重贴标，减少门店现场加工压力。
   - 提供陈列道具、价签、爆炸贴、试吃台、试吃果品等物料。
   - 包装规格匹配会员日动销，避免大包装导致客单过高或损耗。

6. **人员与现场支持**
   - 安排供应商业务员或督导活动当天巡店，重点看陈列、品质、库存。
   - 明确门店对接人、供应商对接人、异常处理电话。
   - 试吃活动需提前准备试吃果、一次性用品、人员健康证等。

7. **损耗与售后规则**
   - 提前约定活动期损耗分担、临期果处理、质量问题退换货规则。
   - 对易损耗品项设置日清或折价机制，避免活动后集中退货扯皮。

8. **物流与门店收货协调**
   - 确认各门店收货时间窗、卸货条件、冷链要求。
   - 活动前一天完成重点门店首配，活动当天早高峰前完成补货。
   - 预留备用车辆和司机，防止堵车、车辆故障影响上架。

**最关键的判断标准：**活动前3天，供应商应能给出“品项—门店—数量—到货时间—补货联系人”的明细表；活动前1天，重点门店首配到店并完成陈列；活动当天早间有二次补货能力。做不到这三条，会员日水果活动就容易出现断货、品质下滑和门店抱怨。
