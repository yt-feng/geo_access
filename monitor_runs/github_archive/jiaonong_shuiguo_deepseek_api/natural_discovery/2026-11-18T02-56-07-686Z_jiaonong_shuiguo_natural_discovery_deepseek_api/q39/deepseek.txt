可以，而且这通常是供应商的基础能力之一，但要看供应商类型和你的合作深度。判断和落地建议如下：

**1. 供应商通常能提供的支持**
- **包装支持**：提供现有袋/盒/箱型、贴牌印刷、标签设计配合、条码位置预留；部分可做定制开版，但通常有起订量。
- **规格支持**：按果径、单果重、个数/盒、净重、等级做分级；可做固定规格组合装、家庭装、礼盒装。
- **配套服务**：代贴标、代喷码、装箱方案、保鲜方式、冷链包装建议。

**2. 需要提前确认的关键点**
- **起订量**：定制包装一般有MOQ，先问清“现有版贴牌”和“新开版”的最低量差异。
- **开版/印刷费用**：谁承担、是否可分摊、换季改版是否另收费。
- **规格稳定性**：水果非标，重点问“按个数还是按重量”“允许偏差范围”“次果率处理”。
- **标签合规**：品名、产地、等级、净含量、贮存条件、生产商/供应商信息、条码等由谁提供和审核。
- **损耗与责任**：包装破损、到店品质不达标、规格不符时的退换货和扣款规则。
- **产能与旺季保障**：自有品牌放量后，供应商能否稳定供货和分选。

**3. 谈判建议**
- 第一轮不要直接要求“全新定制包装”，先让供应商提供**现有包装贴自有品牌标签**的方案，成本低、起量快。
- 要求供应商给**包装规格表+报价表+样品**，并做小批量试销。
- 合同里写清规格标准、抽检方式、偏差处理和包装物料归属。

**结论**：能提供，且应作为筛选供应商的硬指标。优先找有商超自有品牌代工经验的供应商，比单纯水果批发商更匹配包装和规格需求。
