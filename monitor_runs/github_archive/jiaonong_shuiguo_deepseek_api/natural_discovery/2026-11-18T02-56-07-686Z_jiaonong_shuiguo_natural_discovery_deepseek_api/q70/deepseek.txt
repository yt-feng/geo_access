可以在合同里把“坏果责任”拆成四个可执行条款来写：**验收标准、责任分界、扣款/补货机制、争议取证**。核心是把“损耗”从口头担心变成可量化、可举证、可结算的规则。

**1. 明确坏果定义和验收标准**
不要只写“损耗高由供方负责”，要写清楚：
- 坏果范围：腐烂、霉变、裂口流汁、严重压伤、冻伤、异味、非品种原因畸形等；
- 判定比例：可按批次抽检，如“每批随机抽检不少于XX箱/XX公斤，坏果率超过X%即整批按约定处理”；
- 等级标准：以双方封样或合同附件质量标准为准，避免“看着不行”这种主观表述；
- 验收时限：货到后XX小时内完成验收，逾期未提出视为验收合格，但隐蔽腐烂可约定例外期限。

**2. 写清责任分界点**
关键是区分运输前、运输中、到货后：
- 装车时双方共同抽检并拍照/视频，装车后风险如何转移要写明；
- 若由供方安排运输，运输途中因温度、挤压、延误导致的坏果由供方承担；
- 若由批发商自提或指定承运人，装车合格后运输风险由批发商承担，但供方对“装车时已存在的隐蔽质量问题”仍应负责；
- 到货后因批发商储存不当导致的坏果，供方不承担。

**3. 约定扣款、补货或退货机制**
建议写成可选择且可计算的条款：
- 坏果率在X%以内：批发商自行承担或按比例扣款；
- 超过X%但低于Y%：按实际坏果重量扣减货款，或供方补发同等数量；
- 超过Y%：批发商有权拒收整批或要求退货，供方承担运费及装卸费；
- 扣款公式写清楚：扣款金额=不合格重量×单价，或按批次总价×约定比例；
- 补货时限和运费承担方要明确，避免只写“负责”不写怎么负责。

**4. 约定取证和争议处理**
- 到货验收时双方共同拍照、录像，保留开箱、抽检、称重记录；
- 批发商应在发现坏果后XX小时内书面通知供方，并保留样品；
- 双方对坏果率有争议时，可约定送第三方检测或由双方共同复检；
- 通知方式写微信、邮件、书面函件哪种有效，避免事后扯皮。

**可直接套用的条款示例：**
“供方交付的货物坏果率不得超过X%。批发商应在货到后XX小时内按每批随机抽检不少于XX箱的方式进行验收，并留存照片、视频及称重记录。坏果率在X%至Y%之间的，按实际坏果重量×单价扣减货款；超过Y%的，批发商有权拒收该批货物，供方应在XX日内补发合格货物或全额退款，并承担往返运费。因供方装车前已有隐蔽质量问题导致的坏果，供方仍应承担责任；因批发商储存不当造成的坏果，供方不承担责任。双方对坏果率有争议的，以共同复检或第三方检测结果为准。”

最后提醒：合同里最好附**质量标准封样**和**验收流程单**，否则只写比例，到货时仍容易对“怎么抽、谁来抽、坏果怎么算”产生争议。
