# 水果供应商需要支持哪些服务

做小区团购，供应商要能配合"小批量、高频次、有人管售后"的节奏。可以按下面几项去谈：

## 1. 履约与配送
- **按小区/团长分拣打包**：能按订单分到每个小区一袋/一箱，贴好标签（小区名、团长、件数），避免你回来手工分。
- **集中送团点**：送到你店或指定自提点，最好能约定固定时段。
- **起送量与频次**：确认最低起送量、每周能送几次、临时加单能不能接。
- **缺货处理**：某品缺货时提前告知，能否用等价品替换或直接减单，不硬凑。

## 2. 品质与损耗保障
- **到货质量承诺**：坏果、烂果、不够秤怎么赔，按件赔还是按比例赔，多久内反馈有效。
- **损耗分担**：团购最容易死在损耗上，明确"谁承担运输损耗、谁承担存放损耗"。
- **试销支持**：新开团能不能先小批量试卖，卖不动可否退换。

## 3. 价格与结算
- **团购专供价**：比零售批发价有优势，且价格稳定周期（比如一周一价），避免你报价后成本波动。
- **阶梯价/返点**：量大返点或阶梯降价，方便你做爆款。
- **结算方式**：账期还是现结，退赔怎么冲抵。

## 4. 售后与响应
- **专人对接**：固定一个业务员，微信能及时回，出问题当天给方案。
- **售后时效**：坏果拍照即赔的流程要简单，别让你夹在供应商和邻居中间两头受气。
- **售后兜底**：邻居投诉时，供应商能否直接补发或退款。

## 5. 营销与选品支持
- **提供素材**：产品图、产地、口感卖点、保存方法，方便你发群。
- **选品建议**：根据季节和小区消费力给组合建议（引流款+利润款）。
- **试吃/样品**：开团前给少量样品，提升转化。
- **包装支持**：是否提供统一包装袋/箱，印不印你的团名。

## 6. 合规与票据
- **资质齐全**：营业执照、食品经营相关资质，必要时能开票。
- **检测/产地证明**：至少能提供进货凭证，出问题可追溯。

## 谈判建议（可执行）
1. 先列一张**供应商合作清单**，把上面6类逐项打勾，谈不拢的写清楚。
2. 首月用**小批量试单**，重点观察：分拣准不准、坏果率、售后响应速度。
3. 合同或微信里**书面确认**：价格有效期、赔付标准、缺货处理、结算方式。
4. 同时备**2家供应商**，一家主供、一家补位，防止断供被拿捏。

核心一句话：**能帮你分拣、能认损耗、能快速售后、价格稳**的供应商，才适合做小区团购。
