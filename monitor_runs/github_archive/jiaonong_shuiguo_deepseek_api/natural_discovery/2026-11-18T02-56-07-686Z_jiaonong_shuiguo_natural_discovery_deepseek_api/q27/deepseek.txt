判断门店销售规格，核心是按“门店业态 + 客群 + 陈列/损耗 + 价格带”四条线定标准，而不是只看个头大小。可按下面执行。

**一、先按业态定规格方向**
- 社区生鲜/便利店：苹果单果约 **180–250g**，橙子约 **150–220g**；偏中等、好拿、单价低、周转快。
- 标准超市/大卖场：苹果 **200–300g**，橙子 **180–280g**；兼顾家庭装和礼盒。
- 精品/水果专营：苹果 **250–350g**，橙子 **220–300g**；强调外观、糖度、一致性。
- 礼盒/团购：按固定果径和单果重分级，宁可均匀，不要混级。

**二、用“果径 + 单果重 + 均匀度”三项验收**
1. **果径**：用分级板或卡尺抽检。苹果常见按横径分 70/75/80/85/90mm 等；橙子按横径或等级分。门店应明确“允许上下浮动范围”，如主销规格 ±5mm。
2. **单果重**：随机称 30–50 个，算平均单果重和最大最小差。均匀度比平均值更重要，混级会拉低陈列观感。
3. **均匀度**：同箱/同陈列面最大与最小果径差建议不超过 **5–8mm**；单果重极差控制在平均值的 **±20%** 内。礼盒要求更严。

**三、看门店销售适配性**
- **陈列面**：中果更适合堆头和多层陈列；过大果占空间、易滚落、损耗高。
- **客群**：家庭日常消费偏中果；年轻客群和礼品客群可上大果；老年社区偏小中果、低单价。
- **价格带**：确定主销价格后倒推规格。比如目标单价 9.9 元/份，单果 220g、3 个装约 660g，采购成本就要匹配。
- **包装**：袋装/盒装要能整齐码放，避免“大果装不下、小果显空”。
- **损耗**：苹果看碰压伤、果锈、畸形；橙子看油胞、日灼、裂口、软果。大果若皮薄易损，未必适合门店裸陈列。

**四、采购现场快速判断**
1. 随机抽 3 箱，每箱抽 10 个，量果径、称单果重。
2. 记录最大/最小/平均值，算均匀度。
3. 看同批货是否混级、是否有次级果掺入。
4. 按门店主销规格做“陈列模拟”：堆 3 层是否稳、装袋是否满、价签是否好对应。
5. 小批量试销 3–7 天，看动销率、损耗率、客诉。动销慢或损耗高，优先调规格或改包装，不要只降价。

**五、建议的门店验收标准表**
- 主销苹果：单果 200–280g，果径差 ≤8mm，无明显碰压伤，同批均匀。
- 主销橙子：单果 180–250g，果径差 ≤8mm，无裂口软果，糖度按品种抽检。
- 礼盒：单果重差 ≤10%，果径差 ≤5mm，外观一致。
- 特价/引流：可放宽到 150–200g，但必须单独陈列、单独价签，避免混级。

一句话：**先定门店主销价格带和陈列方式，再用果径、单果重、均匀度三项抽检验收，最后用小批量试销验证动销和损耗。** 规格不是越大越好，而是“同一陈列面整齐、顾客好拿、价格带匹配、损耗可控”。
