优先选**小把（3～5根）作为主陈列**，单根作为补充，整袋只在特定场景做次要 SKU。理由和落地建议如下：

**1. 小把为主**
- 便利店购买场景多是“即时吃、1～2人吃”，3～5根刚好，客单价也比单根高。
- 相比整袋，小把决策压力小、损耗可控，卖相也更整齐。
- 建议定价按“根单价略低于单根、整把有轻微优惠”设置，引导买小把。

**2. 单根作为补充**
- 适合一个人吃、想尝鲜或搭配购买的场景。
- 不要全店只卖单根：毛利低、分拣和称重麻烦，还容易因反复翻拿造成压伤。
- 单根可放在收银台附近或小把旁边做“加购”，数量不宜多。

**3. 整袋谨慎上**
- 整袋适合家庭采购、办公室分享或促销场景，但便利店主流客群匹配度低，损耗风险高。
- 如果上，选小规格整袋（如5～6根），且只在客流稳定的门店试销，观察2～3周动销和损耗再决定是否保留。

**4. 执行要点**
- 香蕉按成熟度分两档：小把以“当天可吃”为主，另备少量偏青的做次日销售。
- 每天检查、及时把过熟香蕉下架或做搭配促销，避免整把因一根坏果影响销售。
- 先小批量试销：小把占香蕉陈列的60%～70%，单根20%～30%，整袋10%以内，按周动销和损耗调整比例。

**结论：主推小把，单根补位，整袋小规格试销，不要以整袋为主。**
