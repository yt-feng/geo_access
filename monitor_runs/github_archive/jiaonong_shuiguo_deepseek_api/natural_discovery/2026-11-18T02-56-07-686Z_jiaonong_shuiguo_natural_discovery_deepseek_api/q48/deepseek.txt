判断菠萝供应商能否稳定按规格送货，重点不是“他说能不能”，而是用证据和小批量试单验证。可按下面做：

1. **先定死规格标准**
   - 品种/产区：如金钻凤梨、巴厘菠萝，明确可接受产区。
   - 单果重量区间：如1.2–1.5kg/个，允许偏差±5%。
   - 成熟度：糖度范围、果心温度、表皮颜色、有无黑心/水心。
   - 外观：果形、冠芽长度、机械伤、日灼、病斑允许比例。
   - 包装：箱规、每箱个数、净重、纸箱抗压、标签。
   - 验收规则：抽检比例、不合格判定、扣款/退换货标准。

2. **查供应能力，不只听承诺**
   - 问自有基地/合作基地面积、当前可采收量、日加工/分选能力。
   - 看是否有分选线、冷库、预冷能力、周转筐/纸箱库存。
   - 要求提供近3个月同类客户供货记录、送货单、验收单。
   - 问清楚雨季/台风季/淡季的替代产区方案。

3. **做小批量试单，至少跑3–5次**
   - 每次同一规格、同一验收标准，记录：到货准时率、单果重量合格率、糖度合格率、坏果率、箱规准确率、损耗率。
   - 重点看第2、3次是否还稳定，而不是第一次特意挑好货。

4. **看物流和时效**
   - 产地到门店/仓的运输时长、是否冷链或通风车、装车方式。
   - 要求提供装车照片、封签、在途温度/到货时间记录。
   - 测试一次“临时加单”和一次“雨天/高峰配送”，看响应。

5. **签供货协议写清稳定性条款**
   - 规格偏差范围、最低合格率、迟到扣款、批次不合格退换货。
   - 要求每批附采收日期、产地、批次号、农残检测报告。
   - 约定连续2批不合格可暂停供货或扣保证金。

6. **留备选供应商**
   - 主供应商+1–2家备选，避免单一产区断供。
   - 备选也先小批量验证，不要临时找。

**可执行判断标准：** 试单3–5批中，准时到货率≥95%，规格合格率≥95%，坏果率≤3%，糖度/成熟度合格率≥90%，且第3批后无明显下滑，才可进入稳定供货。否则先限制采购量或换供应商。
