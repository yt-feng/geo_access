按“出品稳定性、人工、损耗和风味”四个维度看，茶饮店做菠萝果茶通常优先选**冷冻果丁/果肉**，其次鲜果，最后果泥。具体分场景：

1. **鲜果**
- 适合：强调“现切鲜果”卖点、客单价较高、门店有稳定切配人力、菠萝周转快的店。
- 优点：卖相好、香气自然、可做装饰。
- 风险：菠萝批次甜酸差异大，削皮切丁耗人工，损耗和食品安全风险较高；果茶里如果只用鲜果，酸甜和出杯一致性较难控。
- 建议：鲜果只做“装饰+部分果肉”，不要承担全部风味。

2. **冷冻果丁/果肉**
- 最适合多数茶饮店：风味稳定、开袋即用或简单解冻、出杯一致、损耗低。
- 适合做果肉感明显的菠萝果茶，可搭配少量鲜果装饰。
- 注意：选无糖或轻糖渍、果肉完整度高的规格；解冻后不要反复冻融，按门店日用量分装。

3. **果泥**
- 适合：做冰沙、果昔、浓稠型果茶，或需要快速标准化甜酸底味的门店。
- 优点：出杯快、风味稳定、便于定量。
- 缺点：果肉感弱，容易“像酱不像果茶”；部分果泥含糖和胶体，会掩盖茶香。
- 建议：果泥更适合做基底或与果丁复配，不建议单独作为菠萝果茶主料。

**采购建议：**
- 主料选**冷冻菠萝果丁/果肉**，占风味和果肉主体；
- 少量**鲜果**做顶部装饰或现切卖点；
- 需要浓稠口感或冰沙产品时，用**果泥**做辅助基底；
- 先小批量拿样做盲测：比较同一茶底下的甜酸平衡、香气、果肉口感、出杯速度和24小时内的风味变化，再定供应商。

一句话：**多数茶饮店买冷冻果丁最稳；鲜果做卖点，果泥做辅助。**
