香蕉和菠萝的售后失控，本质不是“赔不赔”的问题，而是**损耗在哪个环节发生、由谁承担、能不能提前拦截**。给你一套可落地的控制框架：

## 一、先改选品和规格，从源头降损

**香蕉**
- 不做“全熟即食”团，默认发**7–8成熟**，页面明确写“收货后1–3天转黄，属正常”。
- 按**把/串**卖而不是按斤卖，减少称重争议和挑拣损耗。
- 单团限量，香蕉不耐压，混装大箱损耗极高，宁可小批量高频。

**菠萝**
- 优先选**凤梨类/免削皮品种**，或直接卖**已削皮真空装**，把“削皮难、酸、黑心”这类主观售后挡在前面。
- 整果团必须标注品种、成熟度、是否需催熟，避免“以为能直接吃”。

## 二、把售后规则前置成“可判断标准”

不要等客户来吵，团购页面就要写清：
- 香蕉：表皮黑斑、轻微压痕不赔；**断裂超过1/3、整把发黑腐烂**才赔。
- 菠萝：**黑心、明显腐烂、切开有异味**赔；外观青皮、偏酸不赔（可给催熟/食用建议）。
- 赔付方式统一为**按个/按把比例赔或补券**，不做全额退款，降低扯皮成本。

## 三、到货环节做“分级拦截”

- 到货当天**抽检+分级**：能卖的、需催熟再卖的、直接报损的三类分开。
- 高损耗品**不压库存**，到货即分拣，坏的当场拍照留证，避免责任说不清。
- 自提点设置**验货提醒**：客户取货时当面看，减少“回家才发现”的争议。

## 四、用“团长动作”替代事后赔偿

- 团长取货时**统一拍照发群**：整批状态、成熟度说明，形成共识。
- 香蕉配**催熟说明卡**，菠萝配**切开判断图**，把售后问题转成使用指导。
- 对高频售后客户做标记，后续高损耗品建议其**到点自提验货**或改买低损耗品。

## 五、算清售后预算，别用“无限赔”换口碑

- 给香蕉、菠萝单独设**售后率上限**（如3%–5%），超了就复盘选品/物流，而不是继续赔。
- 赔付优先**补券/下次抵扣**，现金退款只用于严重质量问题。
- 每团记录：到货量、报损量、售后量、赔付金额，连续两团超标的供应商直接换。

**核心判断：** 高损耗品的售后控制，靠“成熟度标准+到货分级+规则前置+有限赔付”，而不是靠团长现场和客户讲道理。先把香蕉做成熟度分级、菠萝做成免削皮/真空装，售后量会立刻降一截。
