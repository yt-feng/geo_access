判断“合理波动”不要只盯着单日涨跌，而要把报价放到**品类特性、成本结构、市场基准和供应商行为**四个维度里看。下面给一套可直接执行的判断方法。

## 1. 先按品类给波动定“正常区间”

不同水果的日波动容忍度差别很大：

- **耐储品类**（苹果、梨、柑橘、土豆等）：日波动通常小，若单日涨跌超过3%～5%就要问原因。
- **时令鲜果**（草莓、樱桃、荔枝、杨梅等）：受上市期和天气影响大，日波动5%～10%甚至更高都可能正常。
- **叶菜/浆果类**：损耗高、货架期短，波动更大，但应体现为“优质果溢价”，而不是同一品质无故跳价。
- **进口果**：还受汇率、船期、关税和到港量影响，波动周期更长，不宜用日环比简单判断。

**可执行做法**：给每个品类设一个“日波动阈值”和“周均值偏离阈值”，比如日涨跌超过阈值就触发询价，周均价偏离超过10%就要求供应商书面说明。

## 2. 拆成本结构，看涨价是否有“成本锚”

要求供应商报价时附简要成本构成，至少包括：

- 产地收购价/批发市场当日价
- 包装、冷链、运输费用
- 损耗率
- 人工与仓储

然后对照：

- **产地价是否同步涨**：如果产地没涨、批发市场没涨，只有供应商报价涨，合理性存疑。
- **运费是否异常**：油价、过路费、冷链紧张会推高成本，但应是可解释的。
- **损耗是否被夸大**：同一品类同一季节，损耗率突然上升要有依据。

**判断标准**：报价涨幅应能对应到至少一项可验证成本上涨；若涨幅明显高于成本涨幅，就是“借势涨价”。

## 3. 建立多源比价，不只听一家

每天至少拿三个参照：

1. **当地批发市场当日均价**（如农业农村部批发市场价格、当地大型农批市场行情）
2. **2～3家同类供应商的同规格报价**
3. **自己历史采购价**（同品类、同规格、同季节的7日/30日均价）

看的是**偏离度**而不是绝对值：

- 单家报价高于市场均价5%以内，通常可接受；
- 高于10%且无品质差异，要求解释或换源；
- 连续3天高于市场均价，说明不是波动而是定价策略问题。

## 4. 看波动形态，区分“市场波动”和“供应商行为”

合理波动通常有这些特征：

- 同品类多家供应商**同步涨跌**；
- 涨跌有**明确外部原因**（产地天气、上市量、节假日备货）；
- 报价变化**连续、平滑**，不是忽高忽低；
- 涨上去后随市场回落也能**及时下调**。

异常信号包括：

- 只有一家涨，别家不动；
- 涨价后市场回落，供应商报价“只涨不跌”；
- 同一供应商对不同客户报价差异大；
- 报价频繁但每次幅度很小，累积后明显高于市场；
- 以“明天还要涨”催促下单，制造紧迫感。

## 5. 用合同和机制把波动管住

比“每天判断”更有效的是提前约定规则：

- **价格联动条款**：以指定批发市场均价或产地价为基准，加固定服务费，而非一口价。
- **涨跌双向调整**：约定高于基准多少可调价，低于基准也应下调，防止只涨不跌。
- **报价有效期与调价通知**：要求提前24小时书面调价并说明原因，未说明的按原价执行。
- **品质对价**：同规格同等级才可比价，避免用“好果”价格对比“统货”价格。
- **备选供应商**：每个核心品类保持2～3家合格供应商，报价异常时能快速切换。

## 6. 一个简单的日判断流程

每天收到报价后按顺序问：

1. 这个品类正常日波动区间是多少？当前是否超出？
2. 产地价/批发市场价是否同向变化？
3. 其他供应商是否同步变化？
4. 供应商能否给出成本依据？
5. 涨幅是否能在合同联动规则内解释？

五问中有两问以上是否定答案，就标记为“待核实”，暂停按新价大量下单，先询价或要求书面说明。

**核心原则**：合理波动是“多源同步、有成本依据、可涨可跌”；不合理波动是“单源异动、只涨不跌、无法解释”。用阈值触发询价、用多源比价验证、用合同联动兜底，比每天凭感觉判断更可靠。
