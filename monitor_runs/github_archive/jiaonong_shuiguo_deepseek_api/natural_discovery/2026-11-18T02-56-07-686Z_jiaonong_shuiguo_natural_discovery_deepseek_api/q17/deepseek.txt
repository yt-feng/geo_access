# 社区超市水果：控鲜 + 控库存的实操办法

核心思路一句话：**少进、快转、按天卖完，用“订货量”和“当天处理”两个开关控制损耗**。水果不像标品，压货就是烂货，宁可少卖也不要多进。

## 一、订货：按“日销”而不是按“感觉”订

1. **先记两周数据**：每个单品每天卖多少、剩多少、扔多少。没有数据，后面全是拍脑袋。
2. **订货量公式**：`次日订货 ≈ 近7天同时段日均销量 × 系数 − 现有库存`。系数按品类给：
   - 易坏（草莓、葡萄、荔枝、桃）：0.8～0.9，宁缺勿剩
   - 中等（苹果、橙子、梨）：1.0
   - 耐放（柚子、西瓜整只、土豆类）：1.1～1.2
3. **每周固定两次主订货 + 少量补货**：主订走大单品，补货只补“昨天卖断”的，别补“看着快没了”的。
4. **天气和节假日是最大变量**：下雨天客流降三成，订货直接砍；周末、发薪日、社区活动提前加量。把这些写进订货本，形成自己的经验表。

## 二、控鲜：从到货到货架全流程管

1. **到货验收**：当场开箱抽检，软烂、渗水、异味直接拒收或折价，别“先收下再说”。
2. **分级上架**：同一单品分“当天卖”“次日卖”两批，先进先出，新货放里层、旧货放外层。
3. **陈列量控制**：每次上架只摆半天到一天的量，卖完再补。堆得越多，翻动越少，坏得越快。
4. **温湿度**：叶菜、浆果冷藏；香蕉、芒果别进冷柜；苹果和叶菜分开（苹果释放乙烯催熟）。小超市至少配一台冷藏柜专放高损耗品。
5. **每天两次巡检**：早开门前、下午高峰后各挑一遍，软的先挑出来，别等烂了再扔。

## 三、库存：把“压货”变成“当天清”

1. **设安全库存上限**：每个单品定一个“最多摆多少”，超过就停订。易坏品库存周转目标 **1～2天**，耐放品 **3～5天**。
2. **傍晚降价清货**：下午5点后对当天易坏品做阶梯折扣（8折→6折→打包价），损失的是毛利，不是全损。
3. **临期处理三条路**：打折、做果切/拼盘、员工内购或联系周边餐饮/果汁店。果切能救回一部分，但当天必须卖完。
4. **每周盘点一次损耗**：记“卖了多少钱、扔了多少钱”，算出损耗率。生鲜损耗率控制在 **5%以内** 算健康，超过就查是订货多了还是陈列/温度问题。

## 四、几个容易踩的坑

- **别为“品种齐全”硬进**：小社区店单品控制在20～30个，卖不动的品直接砍。
- **别迷信“低价多进”**：便宜进的货卖不掉，等于用损耗吃掉了差价。
- **别只砍订货不看陈列**：货摆得乱、不新鲜，越没人买，越压货，形成死循环。
- **和供应商谈少量多次配送**：能一周送三次就别一次送一周，配送成本换损耗成本通常划算。

## 落地起步（一周内能做的）

1. 建一张表：单品 / 日销量 / 剩余 / 损耗，连记14天。
2. 给每个单品定“订货系数 + 库存上限”。
3. 定死两个动作：每天下午5点清货折扣、每天早晚两次挑拣。
4. 一周后看损耗率，先砍损耗最高的3个单品订货量。

坚持一个月，订货会越来越准，压货自然下来。关键是**用数据订、当天清、每周复盘**，别靠感觉。
