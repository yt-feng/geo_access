社区超市选每日配送水果供应商，重点看“稳定日配能力+损耗可控+结算清晰”，建议按下面条件逐项核：

1. **配送能力**
- 是否支持每天固定时段送达，最好早上营业前到店。
- 起送量、配送范围、节假日是否照常。
- 临时补货/加单的截止时间和响应速度。
- 是否有冷链车或保温箱，夏天叶菜、浆果类是否控温。

2. **货源与品类结构**
- 是否有稳定产地或一级批发渠道，避免二手倒卖。
- 常供品类是否覆盖你的主力：苹果梨橙等耐储、叶菜、浆果、时令爆品。
- 能否按你的销售结构做小批量多品种，而不是强行整箱压货。

3. **品质与验收标准**
- 明确等级、规格、净重、成熟度、瑕疵率。
- 约定验收扣损标准：坏果率、缺斤少两、成熟度不符怎么退换。
- 是否允许开箱验货、当场拍照留证。
- 连续出现品质问题是否有替换或赔偿机制。

4. **价格与结算**
- 报价是否含运费、包装费、卸货费。
- 价格随行就市时，提前多久通知调价。
- 账期、押金、起订金额、退换货结算方式写清楚。
- 对比“到店净成本”，不要只看单价。

5. **损耗与售后**
- 是否接受临期/滞销少量换货或调货。
- 售后响应时限，比如2小时内答复、次日补送。
- 是否愿意先小批量试配1—2周，再签长期。

6. **资质与风险**
- 营业执照、食品经营相关资质、检测报告是否齐全。
- 是否有固定分拣场地和备用车辆，避免单司机单线路。
- 合同里写清违约、断供、食品安全责任。

**实操建议：**先找2—3家同时试配一周，每天记录到货时间、坏果率、缺货率、售后响应。用“日配准时率≥95%、坏果率≤3%、缺货提前通知、售后2小时响应”作为淘汰线，再谈账期和价格。优先选能小批量、多品类、愿意签验收标准的供应商，而不是单纯报价最低的。
