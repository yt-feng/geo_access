旺季菠萝用量突增，和供应商约定临时补货，核心是把“临时”变成有规则、可执行、能追责的补货机制，而不是靠口头打招呼。建议按下面几步做：

1. **先算清缺口和节奏**
   - 用近7天实际用量推算未来7—14天需求，叠加门店活动、天气、节假日因素。
   - 明确：每天需要多少公斤、什么规格（去皮/带皮、单果重量、成熟度）、到货时间（如每天7点前）、可接受的最低起订量和最大日供应量。
   - 区分“保底量”和“弹性量”：例如基础日供50kg，旺季可提前24小时追加至80kg。

2. **和供应商签一份简短的临时补货条款**
   至少写清：
   - **补货触发方式**：提前多少小时下单（如当日14点前下单，次日早到；紧急单提前4小时）。
   - **响应时限**：供应商确认时间、最迟到货时间。
   - **价格机制**：临时补货是否加价、加价上限、运费谁承担，避免坐地起价。
   - **质量与验收标准**：规格、成熟度、坏果率上限（如不超过5%），到货抽检不合格可拒收或扣款。
   - **供应上限与断供责任**：供应商每日最大供应量；因供应商原因断供，需提前告知并承担替代采购差价或违约金。
   - **结算方式**：临时补货单独对账，按周或按批结算，保留送货单和验收记录。

3. **建立“主供应商+备用供应商”双轨**
   - 主供应商负责保底量，备用供应商负责弹性缺口，避免旺季被一家卡住。
   - 备用供应商也提前谈好临时补货价和响应时间，哪怕平时少量走单维持关系。

4. **日常执行用简单表单留痕**
   - 每次临时补货用微信/邮件下单，写明品名、数量、规格、到货时间、价格。
   - 到货验收记录坏果率、重量、温度，双方签字或拍照留存。
   - 每周对账一次，异常及时书面确认。

5. **谈判时给对方合理预期**
   - 明确旺季持续时间、预计总增量、付款周期是否可缩短。
   - 可以承诺“保底采购量+优先续约”换取临时补货优先权和价格稳定。
   - 不要只压价，要给供应商留合理利润，旺季才愿意优先保你。

一句话：**把临时补货写成“提前报量、限时响应、价格封顶、质量可退、断供有责”的简短协议，并保留备用供应商。**
