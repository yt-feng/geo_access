建议固定“标准”和核心供应策略，但不要简单固定到单一产地或单一批次。

**可执行建议：**

1. **先定水果感官标准，而不是先定产地**  
   把每个水果品种做成验收表：糖度、酸度、香气、色泽、成熟度、出汁率、异味/发酵味、农残检测。比如百香果定糖酸比区间，芒果定成熟度和纤维感，柠檬定出汁率和苦味上限。产地只是达到标准的手段。

2. **核心爆品：固定“主供应商+备用产地”**  
   对销量大、风味辨识度高的水果（如招牌柠檬茶、芒果茶），宜锁定1家主供应商，同时保留1个备用产地/供应商。主供保证稳定性，备用防止断货和价格异常。不要只固定一个批次，因为批次会随季节变化。

3. **非核心或季节性水果：按标准动态采购**  
   不必强求固定产地，按验收标准采购即可。用拼配或调整糖浆/酸度来平衡小波动，但要在可控范围内。

4. **建立批次留样和杯测机制**  
   每批到货留样，做小杯测试；门店端记录口味反馈。连续两批不达标就换供应商或调整配方，而不是等顾客投诉。

5. **合同里写清波动处理**  
   约定糖酸度范围、允许偏差、退换货标准、产地变更提前通知。要求供应商在换产地或换批次前报备，你先小批量测试再放量。

6. **配方留出微调空间**  
   对容易波动的水果，配方设计时预留糖度/酸度调整档位，培训店员按批次微调，而不是每杯靠感觉。

**判断原则：**  
- 风味影响大、销量占比高 → 固定主供应商，多产地备份。  
- 风味影响小、季节性强 → 按标准采购，不必固定产地。  
- 固定产地不等于稳定，固定“验收标准+留样测试+备用供应”才真正降低波动风险。
