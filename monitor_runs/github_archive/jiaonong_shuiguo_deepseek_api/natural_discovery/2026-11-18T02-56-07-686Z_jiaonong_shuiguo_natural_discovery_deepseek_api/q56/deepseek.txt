茶饮店控制水果供应商的食品安全风险，建议把证明分成“资质、检测、过程、承诺”四类，并在进货时逐批核对。可执行清单如下：

**1. 主体资质证明**
- 营业执照（经营范围含水果种植/销售/批发等）
- 食品经营许可证或食品生产许可证（如供应商从事分切、鲜切、预包装水果加工；仅销售初级农产品一般按当地要求核验）
- 若为进口水果：海关报关单、入境货物检验检疫证明

**2. 产品合格与检测证明**
- 每批水果的产地证明或采购凭证（证明来源可追溯）
- 农残检测报告：优先要第三方检测报告；至少要有供应商自检或快检记录，报告应覆盖该品种和批次
- 若为鲜切水果：微生物检测报告（菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等）
- 检测报告注意有效期和批次对应关系，不能只收一份年度报告长期使用

**3. 过程与储运证明**
- 供货商冷链/储运记录（温度记录、运输车辆卫生情况）
- 鲜切水果供应商的加工场所卫生证明、从业人员健康证
- 进货查验记录：品名、规格、批次、数量、生产日期/采摘日期、供货者名称及联系方式

**4. 合同与承诺文件**
- 食品安全承诺书/质量保证协议
- 明确农残、重金属、微生物等指标要求和违约责任
- 不合格品退换货、召回配合条款

**操作建议：**
- 建立供应商档案，一供应商一档，证照到期前提醒更新。
- 每批到货做感官验收（腐烂、霉变、异味、虫害），并保留快检或验收记录。
- 对高风险水果（如直接鲜食、不加热的草莓、葡萄、柠檬等）提高抽检频次。
- 鲜切水果风险高于整果，尽量要求供应商提供加工环节的卫生和微生物检测材料；若门店自行分切，则门店自身也要有切配间卫生、工具消毒、人员健康证和操作记录。

具体证照要求可能因地区监管口径不同，建议以当地市场监管部门要求为准。
