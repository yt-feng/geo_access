提前锁库存的核心是：把“口头预留”变成“有约束的协议库存”，同时用分批锁量和动态补货降低压货风险。

可执行做法：

1. **先做需求预测再谈锁量**
   - 按过去4周销量、旺季增幅、天气/节日因素，算出未来2周每个SKU的预计销量。
   - 把预测拆成“保底量+弹性量”：保底量是必须锁的，弹性量是提前约定供应商可追加的上限。
   - 不要只给供应商一个总数，要给“分周、分品类、分规格”的锁量计划。

2. **和供应商签“锁量不锁价”或“锁量锁价”的简短协议**
   - 明确锁定量、锁定期、交货批次、到货时间、验收标准。
   - 约定定金或预付款比例，通常10%—30%，让供应商有动力留货。
   - 约定违约条款：供应商缺货怎么赔、你方取消怎么处理。
   - 价格条款要写清楚：是固定价，还是随行就市但有上限价。

3. **用“分批锁+滚动补”代替一次性全锁**
   - 旺季前先锁第一周保底量，第二周只锁50%—70%，剩余按周滚动确认。
   - 对易腐水果尤其要分批，避免一次锁太多导致损耗。
   - 和供应商约定每周固定时间确认下周追加量，形成节奏。

4. **多供应商备份，不把鸡蛋放一个篮子**
   - 主供应商锁60%—70%，备选供应商锁20%—30%，留10%机动。
   - 备选供应商也要提前谈好“优先供货权”，哪怕量小也要保持合作。

5. **把锁库存和社区团购的预售节奏绑定**
   - 先开预售再锁量，用真实订单校准库存。
   - 爆单后追加的弹性量，提前和供应商约定“48小时/24小时响应补货”机制。
   - 对爆款水果设置“售罄预警线”，达到预警线立即触发追加锁量。

6. **到货和质检要提前定规则**
   - 约定验收标准：糖度、大小、损耗率、包装要求。
   - 约定到货时间窗口和卸货责任，避免旺季物流卡住。
   - 留好质检记录，作为后续索赔和调整锁量的依据。

7. **用合同和沟通记录固定证据**
   - 微信沟通后补一份简短确认函或订单确认单，写明锁量、价格、交期。
   - 预付款走对公账户，备注“XX水果旺季锁量预付款”。
   - 保留供应商产能证明、采摘计划等材料，防止临时被高价截胡。

一句话总结：**先预测、再分批锁、付定金、签短协议、留备份、绑定预售滚动补货**。不要一次性全锁死，也不要只靠口头承诺。
