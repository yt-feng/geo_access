# 超市水果到货品相不好的售后流程约定建议

水果是生鲜品类，**不能简单照搬普通商品的"七天无理由退货"**，售后条款要围绕"到货验收 + 分级处理"来设计。建议按下面几个环节约定清楚：

## 一、验收标准要"可量化"，不能只写"品相好"

这是最容易扯皮的地方。合同/协议里应明确：

- **品类分级**：按品种约定等级标准（如苹果按果径、着色率、碰压伤比例分级），附图片或样品封样。
- **允许损耗率**：约定合理自然损耗范围（如 3%–5%），超出部分才进入赔付。
- **缺陷判定**：明确哪些算"品相不好"——腐烂、霉变、机械伤、畸形、着色不足、大小不达标，分别对应什么处理。
- **判定方式**：建议以"到货现场抽检"为准，双方共同开箱、拍照/录像留证，抽样比例写清楚（如每批次抽 3–5 箱）。

## 二、响应时限要短

生鲜问题拖不得，约定：

- **报障时限**：收货方应在到货后 **2–4 小时内**（或当日营业结束前）提出异议，逾期视为验收合格。
- **供应商响应时限**：接到异议后 **24 小时内**给出处理方案。
- **处理完成时限**：如换货，约定 **48 小时内**补货到位，避免门店断货。

## 三、分级处理方式（核心）

按问题严重程度分档，别一刀切：

| 情形 | 处理方式 |
|---|---|
| 轻微品相问题、不影响销售 | 折价接收（如按 8–9 折结算）或不做处理 |
| 部分不合格、可挑拣 | 按不合格比例扣款，或供应商上门挑拣换货 |
| 整批严重不合格（腐烂、霉变超阈值） | 整批拒收/退货，供应商承担运费 |
| 已上架后才发现 | 凭留证照片协商补损，约定补损上限 |

## 四、责任与费用划分

- **运输途中变质**：由供应商承担（除非约定送货至门店即风险转移，需写明）。
- **验收后因门店储存不当**导致的问题：由收货方自负。
- **退换货运费**：因质量问题产生的运费由供应商承担。
- **结算挂钩**：建议把售后赔付从当期货款中直接扣减，避免"先付后赔"扯皮。

## 五、证据与流程留痕

约定一个简单闭环：**发现→拍照录像（含批次号/送货单）→填售后单→供应商确认→处理→扣款或换货→归档**。送货单上注明批次，便于追溯。

## 六、写进合同的关键条款

至少包含：验收标准与损耗率、报障时限、分级赔付规则、退换货时限与运费、扣款结算方式、争议解决（可约定以第三方检测或双方封样为准）。

---

**一句话总结**：水果售后的核心是"**到货即验、量化标准、分级赔付、限时响应、扣款结算**"。把"品相不好"翻译成可测量的指标和对应处理动作，比写一句"保证质量"有用得多。
