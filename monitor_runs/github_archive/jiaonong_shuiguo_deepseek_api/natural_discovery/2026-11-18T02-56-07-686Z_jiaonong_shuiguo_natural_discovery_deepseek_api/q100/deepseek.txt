# 学校食堂采购香蕉防过熟浪费的实操建议

核心思路：**控制采购节奏 + 按成熟度分用途使用 + 储存隔离**。

## 1. 采购环节

- **按周用量倒推采购量**：统计近2–4周香蕉实际消耗量（含损耗），按“日均用量×到货间隔天数×0.9”下单，留出安全余量但不过量。
- **要求供应商按成熟度分级供货**：不要一次全要“黄熟”的，可搭配少量青黄（7–8成熟）和即食黄熟（9成熟），让熟度错峰。
- **缩短到货间隔**：宁可小批量、多频次到货，也不要一次囤一周的量。

## 2. 到货验收

- 验收时按成熟度分筐：**青黄、黄熟、过熟**三档分开，过熟少量可当天做香蕉牛奶/烘焙，大量则拒收或退回。
- 与供应商约定验收标准（如允许青黄比例、过熟上限），写入采购合同。

## 3. 储存与催熟管理

- 香蕉**不宜冷藏**（低温会黑皮），应放在阴凉通风处，避免阳光直射和挤压。
- **不要和苹果、梨等释放乙烯的水果混放**，会加速成熟；需要催熟时才利用这一点。
- 青黄香蕉可单独放纸箱，按需取出少量放在室温下催熟，形成“分批熟成”。
- 每天检查一次，把最先熟的挑出来优先用。

## 4. 使用端配合

- 食堂窗口**按成熟度调整供应顺序**：先供黄熟，青黄留后。
- 熟透香蕉可转做**香蕉牛奶、香蕉面包、香蕉粥、水果沙拉**等加工品，减少直接丢弃。
- 建立“临期香蕉”快速处理机制，当天未售完的熟蕉优先用于加工或员工餐，而不是留到第二天。

## 5. 建立记录与复盘

- 记录每批到货日期、数量、成熟度、损耗量，每周复盘，逐步校准采购量和供应商分级供货比例。
- 把“香蕉损耗率”纳入食堂日常管理指标，连续观察2–3周即可找到合适的采购节奏。

**一句话总结**：少量多频采购、按成熟度分级验收、青黄与黄熟分开储存、熟透的转加工用途，基本能把香蕉过熟浪费压到很低。
