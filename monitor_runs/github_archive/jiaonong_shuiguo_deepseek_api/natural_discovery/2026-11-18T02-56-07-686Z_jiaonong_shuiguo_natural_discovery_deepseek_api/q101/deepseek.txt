和水果供应商谈长期合作，重点抓这几件事：

1. **先定供应标准，再谈价格**
   - 明确品类清单：常用水果（苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等）和季节替换规则。
   - 写清等级、单果规格、成熟度、外观瑕疵容忍度。早餐水果要“稳定好切、出品好看”，不是越便宜越好。
   - 约定验收标准：农残检测报告、新鲜度、无腐烂、到货温度（切果/浆果类冷链）。

2. **锁量和锁价机制**
   - 给出日均/周均用量区间，让供应商按“保底量+浮动量”报价。
   - 价格别只谈一个固定价：约定随行就市调价周期（如月度参考当地批发市场均价），设涨跌幅上限。
   - 旺季、节假日、极端天气的保供条款要单独写。

3. **配送与应急**
   - 明确送货频次、到货时间窗（早餐前必须到位）、卸货入库责任。
   - 写缺货/延时的处理：替代品方案、赔偿或扣款、连续违约解约权。
   - 要求供应商有备用产地或备用仓，避免单一来源断供。

4. **质量与损耗责任**
   - 验收当场抽检，不合格拒收或降级计价。
   - 明确损耗承担：到货前损耗归供应商，入库后归酒店；切果出品率可约定参考值。
   - 保留留样和检测报告，食品安全责任写进合同。

5. **账期与结算**
   - 谈清账期（如月结30/45天）、对账方式、发票类型。
   - 新供应商可先小批量试供2—4周，再签长期框架。

6. **合同关键条款**
   - 合作期限、独家/非独家、最低采购量、违约与退出机制。
   - 食品安全事故的责任和赔偿。
   - 价格调整触发条件、通知期限。
   - 不可抗力下的保供与免责边界。

7. **现场考察与比价**
   - 至少看两家：产地/分拣仓、冷链能力、检测资质、服务过哪些酒店。
   - 比价时统一按“可食部分成本”算，不只看毛重单价。

实操建议：先整理近3个月早餐水果用量和品类结构，做成一张需求表；让供应商按表报价并附服务方案；选一家主供、一家备供，试供一个月后再定长期合同。
