# 商超水果采购压价且不降品质的谈判思路

核心逻辑：**压价不靠“砍单价”，靠改变交易结构和风险分担**。单看单价硬砍，供应商只能在品质、规格、账期上找回来。所以谈判要把议题从“一斤便宜几毛”转到“整条链路省下的钱怎么分”。

## 一、谈判前先做三件事（决定你有多大筹码）

1. **摸清成本结构**：主推单品至少问清产地/产区、包装规格、损耗率、运输方式、结算账期。你知道他每箱的包装费和运费占比，才知道哪里能压。
2. **掌握替代货源**：同产区其他供应商、批发市场同规格报价、产地直采可能性。没有替代方案就不要谈价，容易被“你随便”顶回来。
3. **算清自己的真实成本**：进价只是其中一项，损耗、退货率、账期资金占用、配送频次都要算。**目标是综合成本最低，不是单价最低。**

## 二、可用的压价杠杆（按对品质伤害从小到大排序）

**优先用：**

- **改结算方式**：现结/缩短账期换 2%–5% 折扣，这是供应商最愿意让的。
- **改规格和包装**：大箱改标准箱、减少过度包装、分级销售（A 级做精品、B 级做促销），降低无效成本。
- **增量和稳定性**：承诺月度/季度采购量或包销某产区，换阶梯价。供应商要的是确定性。
- **改物流**：自提、集中到货、减少配送频次，运费让出来。
- **错峰和尾货**：应季集中采购、尾期低价锁量，但要明确品质标准和验收线。
- **产地直采/联合采购**：跳过中间环节，或与兄弟门店拼单。

**慎用：**

- 单纯压单价、压到低于市场价——必然在品质、规格、成熟度上找回来。
- 延长账期当压价手段——供应商资金成本会转嫁到报价里，且优质货源会优先给别人。

## 三、谈价格时把品质写进合同（这是“不影响品质”的关键）

不要口头承诺，落到条款上：

- **明确验收标准**：糖度、果径、色泽、成熟度、坏果率上限（如坏果率≤3%），写清抽检比例和判定方法。
- **明确拒收和扣款规则**：超标怎么退、怎么扣、运费谁承担。
- **价格与品质挂钩**：设“达标价”和“不达标处理”，而不是一刀切低价。
- **锁价机制**：约定价格有效期和调价触发条件（如产地行情波动超 5% 重新议价），避免低价锁死后供应商以次充好。
- **损耗分担**：明确运输损耗、到店损耗的分担比例。

## 四、话术原则

- 不说“你太贵了”，说“我们算了下，如果改成现结+自提+月度锁量，你这边能给我什么价”。
- 把压价包装成“帮你降成本、给你稳定单量”，而不是单方面挤压。
- 留出供应商合理利润。**压到对方没利润，品质一定出问题**，这是生鲜的铁律。

## 五、判断标准

谈完后自问：供应商还有没有合理毛利？验收标准是否可执行？出问题时扣款规则是否清晰？如果三条都成立，这个价格就是“压下来了但品质守得住”的价格。
