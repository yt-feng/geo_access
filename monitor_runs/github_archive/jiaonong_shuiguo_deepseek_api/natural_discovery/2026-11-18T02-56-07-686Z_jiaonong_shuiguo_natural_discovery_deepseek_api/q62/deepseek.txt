# 判断香蕉批次熟度与坏果风险

## 一、先看“整体成熟度”（决定还能放几天）

**看颜色（最直观）**
- **全绿硬果**：未熟，适合长途/囤货，但要注意有没有“假绿”（低温抑制后催不熟）。
- **绿中带黄（黄绿）**：开始转熟，通常 2–4 天进入销售期。
- **黄多绿少、棱角还明显**：适合 1–2 天内出货。
- **全黄、棱角消失、出现少量糖斑**：已到最佳食用期，必须快出，风险最高。
- **大面积黑斑/发褐**：过熟或已受伤，坏果率会快速上升。

**看棱角**：香蕉越熟，横截面越圆、棱线越不明显；棱角分明说明还生。

**看“果指”饱满度**：饱满但不过分膨胀为佳；局部鼓包、软塌要警惕。

## 二、判断坏果风险（重点查这几处）

1. **果柄与果轴**：发黑、发霉、渗液、变软，说明切口感染或已开始腐烂，整把/整箱风险高。
2. **果面机械伤**：压痕、擦伤、裂口。香蕉一旦破皮，后面很容易转黑腐。
3. **黑斑性质**：
   - 少量芝麻点状糖斑＝正常成熟；
   - 大块不规则黑斑、边缘渗水、按下去软烂＝坏果/即将坏。
4. **霉变**：果柄、果轴、箱内纸板有白色/青色霉点，说明湿度大、通风差，整批隐患大。
5. **气味**：有酒味、酸味、霉味，说明已过熟或内部发酵。
6. **温度史**：摸箱体是否异常凉/有冷凝水。冷害香蕉表皮灰暗、催不熟、心硬；运输中“热捂”则易发软发黑。

## 三、抽样方法（别只看表面）

- **按箱抽、按层抽**：每批随机抽 5%–10% 箱，每箱查上、中、下三层，不能只翻最上面。
- **重点查箱底和靠边**：压伤、闷热、冷凝水多在这两处。
- **切开查内部**：抽几个可疑果横切，看果心是否发黑、褐变、空心。
- **称重/手感对比**：同规格明显偏轻＝失水；明显偏软＝过熟或内伤。

## 四、快速决策参考

| 状态 | 熟度 | 坏果风险 | 建议 |
|---|---|---|---|
| 全绿硬、柄绿 | 生 | 低（但要防冷害） | 可囤，注意催熟条件 |
| 黄绿、棱角明显 | 转熟 | 低–中 | 2–3 天内出 |
| 全黄、棱角变圆 | 适销 | 中 | 优先出，别压货 |
| 黄带糖斑、局部软 | 偏熟 | 中–高 | 当天/次日清 |
| 大黑斑、柄黑渗液、酒味 | 过熟/坏 | 高 | 拒收或大幅折价快清 |

## 五、谈货时的实操建议

- **问清“催熟/未催熟、运输温度、采摘天数”**，再对照现场表现，避免“看着绿其实冷害”。
- **合同里写明坏果率标准**（如抽检坏果率超过 3%–5% 可扣重/退货），并约定开箱时限。
- **到货先通风散湿**，别闷在箱里；过熟批次单独放、优先出。
- **别被表面颜色骗**：整箱外表漂亮但柄黑、箱底软、有酒味，往往内部坏果已不少。

一句话：**看颜色定熟度，看果柄/伤口/黑斑性质定风险，抽样要翻箱底和切开验证。**
