核心思路：把“补货不影响营业”写进约定条款——要求供应商**边补货边保留不合格品作证据、按营业时段分批到货、缺货即赔**，而不是等整批退换完再补。

**一、合同/订单里要写死的条款**

1. **验收与补货时限**
   - 到货后当场验收（或2小时内），不合格品拍照、称重、留存，供应商签字确认。
   - 补货时限按品类写：易坏水果（草莓、芒果、西瓜等）要求**当日或次日营业前**补到；耐储水果24–48小时内。
   - 明确“补货不影响正常营业”：供应商须在**开店前1小时**或**非高峰时段**送达，不能占用来货验收之外的操作时间。

2. **分批补货机制**
   - 不合格批次不必整批退回再等新货：约定“先补合格量、后处理不合格品”，即供应商当天先补足营业所需数量，不合格品另行退换或折价。
   - 按门店日销量约定最小补货批量，避免补太少不够卖、补太多损耗。

3. **缺货违约责任**
   - 补货超时或补货量不足，按缺货金额的1–3倍或固定金额/小时赔付，并允许门店自行就近采购、差价由供应商承担（保留采购凭证）。
   - 连续两次补货不合格，门店有权换供应商且不承担违约金。

4. **质量标准和验收方法**
   - 写清品种、规格、成熟度、糖度、外观（无腐烂、无压伤、无虫害）、农残检测要求。
   - 验收以门店现场标准为准，附照片/视频作为证据，避免扯皮。

**二、操作层面的配合**

- **安全库存**：对易坏核心水果保留1–2天用量，避免单一批次出问题就断货。
- **备用供应商**：每个核心品类至少备1家，合同里写明“紧急调货权”。
- **到货时间表**：和供应商约定固定送货窗口（如每日8:00前），补货走同一窗口，减少对备料和出杯节奏的干扰。
- **证据留痕**：不合格品拍照、称重记录、沟通记录（微信/邮件）都保留，作为扣款和索赔依据。

**三、一句话总结**

约定要同时做到三点：**补货时限明确到小时、补货方式为“先补后处理”、违约可自行采购并索赔**。这样水果不合格时，门店先用补货维持出品，再慢慢处理和供应商的退换账。
