超市和水果供应商的账期没有统一标准，常见区间大致如下：

- **本地/产地直采、叶菜和易腐水果**：多见 **现结、周结（7天）或10～15天**。这类货损耗快，供应商议价能力弱但风险高，超市若压太长账期，容易拿不到好货或被迫涨价。
- **普通水果批发商/区域供应商**：常见 **15～30天**，这是商超渠道里比较主流的区间。
- **大型连锁超市、长期稳定供应商**：常见 **30～45天**，部分强势连锁会到 **60天**，但通常伴随返点、促销支持、损耗承担等条款。
- **新供应商首单**：建议 **7～15天** 或部分预付，稳定后再拉长。

判断是否合理，重点看四点：**损耗由谁承担、价格是否含账期成本、是否有最低采购量/返点、逾期付款违约金**。水果损耗高，账期每拉长15天，供应商通常会把资金成本折进报价，超市未必真占到便宜。

实操建议：新合作先做 **15天账期+部分预付**，稳定3个月后谈到 **30天**；对叶菜、草莓、荔枝等易腐品单独做 **7天或周结**，不要一刀切。合同里明确对账日、付款日、质量扣款规则，避免“账期30天、实际拖到45天”。
