# 降低坏果与口感不稳定的采购做法

核心思路：**把“坏果”和“口感”从售后问题前置成采购标准**。分四层落地：

## 1. 先把标准写进采购单（可验收）
- **按用途定规格**：不同品类/渠道分开定标准，例如“单果重区间、糖度下限、酸度上限、软硬度、着色率、可食率”。
- **量化口感**：至少定 **糖度（Brix）下限** 和 **糖酸比区间**，比“甜”这种主观描述更能验收。
- **坏果容忍度**：约定“到货抽检坏果率≤X%”“单箱坏果超过N个整箱退/换”，并写清判定口径（腐烂、压伤、裂口、霉变是否都算坏果）。

## 2. 选对供应源和采摘节奏
- **优先产地直采/合作社+分级打包**，减少中间多次倒手。
- **按成熟度分批采**：七八成熟采后运输、近熟果走短链；不要一次采全熟果发远途。
- **要求采后预冷**：叶菜类、浆果类尤其关键，采后尽快降温能显著减少软烂和霉变。
- **避开雨季/高温时段采收**，霉变和裂果风险高。

## 3. 包装和物流要匹配品类
- **易压伤果**：单果网套/托盘+分层隔板，箱内留缓冲，不堆高。
- **浆果/娇嫩果**：小盒+透气孔，避免密封闷出水汽。
- **控制运输温度**：能冷链的走冷链，不能冷链的缩短在途时间，夏季避免暴晒车厢。
- **到货即抽检**：每批抽箱检查底层和边角（坏果最爱藏的地方），记录批次。

## 4. 用数据管供应商（这是减少波动的关键）
- 建**批次台账**：供应商、产地、采摘日、到货日、糖度抽检、坏果率、客诉关键词。
- **按批次评分**，连续两批不达标就降权或换源；好批次锁定复购。
- **客诉归因**：把差评拆成“坏果/不甜/酸/软烂/大小不符”，对应回采购标准逐条修。

## 一个可立即执行的动作
先对你销量前3的品类，各写一张**验收卡**：糖度下限、坏果率上限、单果规格、包装方式、到货抽检比例。采购按卡收货，不达标当场拍照留证并拒收/换货。
