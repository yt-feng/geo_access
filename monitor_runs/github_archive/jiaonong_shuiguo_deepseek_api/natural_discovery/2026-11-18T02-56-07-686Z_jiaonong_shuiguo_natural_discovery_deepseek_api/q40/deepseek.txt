节假日水果需求暴增，核心是**提前把“量、价、质、到货时间”四件事锁死**，而不是等到节前一周才去市场抢货。建议按下面做：

1. **提前做需求预测，按单品拆量**
   - 用过去2—3年同节假日的销售数据，按门店、单品、规格拆出日均销量和峰值销量。
   - 重点锁“节前3天+节日当天+节后1天”的峰值，不要只锁节日当天。
   - 对礼盒果、进口果、时令爆品单独预测，这类最容易断货。

2. **提前与核心供应商签“保量保价”协议**
   - 节前30—45天锁定主供应商，签明：锁定数量、锁价周期、最低供货量、缺货违约金、替代规格。
   - 不要只依赖一家，主供应商占60%—70%，备选供应商占30%—40%。
   - 对价格波动大的单品，可采用“部分锁价+部分随行就市”，避免供应商因涨价毁约。

3. **向上游基地/产地直采锁货**
   - 对苹果、柑橘、梨等耐储果，提前到产地或一级批发市场锁货，约定分批发货。
   - 对草莓、车厘子、荔枝等易损/时令果，锁“采摘窗口+冷链车位+到店时间”，而不是只锁数量。
   - 要求供应商提供备货证明、冷库库存照片或产地装车计划，防止口头锁货。

4. **锁冷链和物流运力**
   - 节前运力紧张，提前锁定冷链车、司机和到货时段，按门店分组排线。
   - 对易损果设置“到货验收标准”：糖度、硬度、果径、坏果率、温度记录，不合格拒收或折价。
   - 至少准备一条备用物流线路，防止主干线延误。

5. **分仓备货，不要全压总仓**
   - 总仓锁大货，区域仓/门店锁周转量，节前2—3天把高频爆品前置到门店或前置仓。
   - 耐储果提前7—10天入仓，易损果控制在节前1—2天到店。
   - 设置安全库存：峰值日销量的1.5—2倍，易损果适当下调。

6. **用“预售+锁客”反向锁定需求**
   - 节前10—15天开水果礼盒、整箱果预售，先收订单再锁货源，降低盲目备货。
   - 对企业团购、社区团购设截止时间，按订单向供应商二次补锁。

7. **合同里写清楚风险和替代方案**
   - 明确缺货赔付、品质不达标处理、价格异常时的调价机制。
   - 每个爆品准备1—2个替代规格或替代品种，断货时能快速切换。
   - 节日期间每天跟踪到货率、坏果率、动销率，发现缺口立即启动备选供应商。

**最可执行的动作清单：**
- 节前45天：完成销量预测和供应商谈判；
- 节前30天：签保量保价协议，锁产地和冷链；
- 节前15天：启动预售，分仓铺货；
- 节前7天：确认装车计划，检查备用供应商；
- 节前3天：每日盯到货和库存，缺货即补。

关键原则：**主供应商锁量锁价、备选供应商保底、耐储果提前入仓、易损果锁时效、礼盒果先预售。**
