判断香蕉供应商能否全年稳定供货，不能只看“有没有货源”，而要看它是否具备全年跨产区调配、冷链和计划供应能力。建议按以下顺序核查：

1. **问清产区组合，而不是只问产地**
   - 要求供应商列出全年各月份的供货产区，例如国内主产区与进口来源如何衔接。
   - 重点看是否只有单一产区：单一产区遇到台风、寒害、病害或雨季，断供风险高。
   - 让供应商说明“淡季/灾年”的替代方案，不能只说“没问题”。

2. **看供应计划与合同承诺**
   - 要求提供12个月月度可供量、最小保证量、最大可供量。
   - 合同中约定年度框架量、月度滚动订单、缺货违约金或替代方案。
   - 区分“意向量”和“保证量”，只写意向量的稳定性不可靠。

3. **核查基地与货源控制力**
   - 是自有基地、长期合作基地，还是临时市场调货。
   - 自有/长期基地比例越高，全年稳定性通常越强。
   - 要求提供基地清单、合作年限、种植面积、可追溯证明；必要时实地或视频核验。

4. **看加工与冷链能力**
   - 香蕉需要催熟、分级、预冷和冷链运输。问清加工厂位置、催熟库容量、冷链车辆数量。
   - 是否具备旺季压货、淡季调配能力，是否能在台风/寒害后快速切换产区。
   - 要求提供近几个月的发货记录、质检记录和冷链温控记录。

5. **用历史履约数据验证**
   - 要求提供过去12—24个月对其客户的月度供货记录，至少看是否出现断供、延迟、质量波动。
   - 向同行或现有客户侧面了解履约情况。
   - 对关键供应商做小批量试单，连续跑3—6个月，观察淡季和异常天气时的表现。

6. **做压力测试**
   - 问三个问题：主产区遭遇台风/寒害时怎么办？春节或旺季运力紧张时怎么保供？香蕉价格大幅波动时是否优先履约？
   - 回答越具体、越有替代产区和预案，越可信；只承诺“保证供应”的要谨慎。

7. **分散风险**
   - 不建议把全年供应押在一家供应商上。至少保留“主供应商+备用供应商”，备用供应商也要有实际试单。
   - 对连锁超市，可要求供应商提供产区天气、病害和物流预警机制，并约定提前通知义务。

**简单判断标准：**能拿出12个月分月产区与可供量、有长期基地和冷链、有历史履约记录、合同里有保证量和缺货责任的供应商，才基本具备全年稳定供货能力；只有口头承诺或单一产区的，风险较高。
