酒店采购水果盘原料时，建议把“可验收”的标准写进采购单或合同附件，至少覆盖以下几类：

1. **品种与产地/等级**
   - 明确品种、规格（如大果/中果/小果）、等级（特级/一级）。
   - 同一批次品种、成熟度、口感尽量一致，避免混级。

2. **外观标准**
   - 果形端正，无明显畸形、裂口、机械伤、压伤、虫眼、病斑、霉点。
   - 表面清洁，无泥土、药斑、异物；允许的轻微瑕疵要写清比例上限。
   - 色泽符合品种正常成熟色，不过青、不过熟、不褪色。
   - 果蒂新鲜，无干枯、脱落或腐烂迹象。

3. **成熟度与口感**
   - 到货成熟度适合酒店当日或短期使用：即食水果盘应“可立即切配”，不能过硬或过软。
   - 切开后无明显空心、褐变、纤维粗、异味；糖酸度符合品种正常范围。
   - 需要后熟的品种，应约定到货成熟度和可存放天数。

4. **规格与均匀度**
   - 单果重量/直径/长度范围明确，例如“单果重180–220g，横径75–85mm”。
   - 同批次大小均匀，允许偏差范围写清，如±5%–10%。
   - 果盘切配用果应便于标准化出成，避免过大过小造成损耗。

5. **新鲜度与货架期**
   - 采收/发货时间、到货时限、剩余货架期要约定。
   - 到货时无萎蔫、失水、软化、发酵味；冷藏品全程冷链，温度记录可查。
   - 明确拒收条件：腐烂、霉变、异味、严重压伤、冻伤、过热。

6. **安全与合规**
   - 农药残留符合国家限量标准，供应商提供检测报告或承诺书。
   - 无非法添加、无催熟剂滥用；包装材料食品级。
   - 可追溯批次、产地、采摘/加工日期。

7. **包装与运输**
   - 包装牢固、透气/防压，单箱重量合理，内衬保护到位。
   - 标签写明品名、规格、产地、批次、日期、供应商。
   - 运输车辆清洁、无污染，冷藏品温控达标，避免与异味物品混装。

8. **验收与赔付**
   - 约定抽样比例、验收方法、不合格判定和拒收/换货/扣款规则。
   - 外观瑕疵、规格偏差、成熟度不符分别设容忍上限。
   - 到货异常时供应商响应时限和补货责任写清。

实操上，最有效的是做一份**《水果盘原料验收标准表》**：每个品种列明“品种等级、单果规格、色泽、成熟度、瑕疵上限、农残要求、包装冷链、拒收条件”。这样采购、厨房、库管验收时都能直接对照，减少扯皮。
