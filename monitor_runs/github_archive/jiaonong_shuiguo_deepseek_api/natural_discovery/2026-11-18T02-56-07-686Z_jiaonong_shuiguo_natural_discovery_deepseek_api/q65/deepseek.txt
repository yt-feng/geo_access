## 结论先说
- **多数水果批发商更适合“基准价+浮动条款”的混合定价**，而不是纯每天议价或纯长期锁价。
- **易腐、短保、行情波动大的品类**（如叶菜类水果少、浆果、荔枝、樱桃等）更偏**每日/短周期议价**。
- **耐储、标准化程度高、走量稳定的品类**（如苹果、梨、橙、部分进口果）更适合**签一段时间价格+调价机制**。
- 如果你下游是商超、团餐、长期大客户，**锁价+浮动条款**更稳；如果下游是散批、农贸小贩，**每日议价**更贴近市场。

## 怎么判断：看四个变量
1. **保鲜期/损耗率**
   - 保鲜期短、损耗高：价格必须快速传导，偏每日或3天议价。
   - 耐储：可签7–30天，降低交易成本。

2. **价格波动来源**
   - 产区天气、到货量、节日需求导致的短期波动：用**每日基准价+当日浮动**。
   - 季节性趋势明显：可签**周均价或半月均价**，避免一天一价伤客户。

3. **客户结构**
   - 大客户要预算稳定：给**锁价区间+超幅调价条款**（如基准价±5%内不调，超出按比例调）。
   - 小散客户：每日议价更灵活，但可设“当日统一价”减少扯皮。

4. **你的资金与库存能力**
   - 资金厚、能囤货：可适度锁价赚趋势。
   - 资金紧、周转快：少锁价，避免赌行情。

## 推荐落地模式：混合定价
**“基准价 + 浮动条款 + 短周期重签”**
- 每周或每3天定一次基准价；
- 合同写明：当产区收购价/市场批发价波动超过±5%–8%时，双方按约定公式调整；
- 设置最低采购量或定金，防止锁价后客户跑单；
- 对易腐品保留“当日到货品质差异调价”条款。

## 什么情况选每天议价
- 品类损耗快、行情一天一变；
- 下游客户接受度高、交易习惯就是随行就市；
- 你没有仓储和资金能力承担锁价风险。

## 什么情况选签一段时间
- 下游是商超、食堂、长期稳定大客户；
- 品类耐储、标准化强；
- 你能通过产地直采、冷库或订单农业对冲波动；
- 合同必须带**调价机制**，不要签死固定价。

## 关键提醒
- **不要纯锁死价格**：水果批发最大风险是锁价后行情暴涨或暴跌，单方违约成本高。
- **每天议价也有成本**：谈判时间、客户流失、价格不透明带来的信任问题。
- 最稳的是：**短周期基准价+波动调价+定金/最低量约束**。
