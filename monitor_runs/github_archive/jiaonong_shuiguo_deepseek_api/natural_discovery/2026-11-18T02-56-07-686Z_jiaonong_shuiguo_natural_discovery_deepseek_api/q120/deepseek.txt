先说结论：供应商介绍产品时，不要一上来就讲品种名、产地故事、行业黑话（比如“金钻凤梨”“Brix值”“A级果”），而要用商家熟悉的品类做锚点，按“对标什么—差别在哪—卖得动吗—赚多少—风险多大”这五步说。

具体可以这样做：

**1. 先用大品类锚定**
一句话说清“这是什么、跟商家认识的什么最像”。
- 例：“这是菠萝，但比普通菠萝更甜、更软、不用泡盐水，切开就能吃。”
- 例：“这是香蕉里偏小的一类，口感更糯，适合做高端水果摊的尝鲜款。”

**2. 只讲三个差异点，且每个都对应消费者感知**
不要列品种特性，要翻译成顾客能感知的好处：
- 甜不甜 → “不用挑，基本个个甜”
- 麻不麻嘴 → “不泡盐水也不扎嘴”
- 好不好放 → “常温能放几天，损耗低”
- 好不好卖 → “小份装适合白领，走量快”

**3. 直接回答“卖给谁、怎么卖”**
商家最关心能不能动销。供应商要主动给出场景：
- “适合放收银台做顺手买”
- “适合切盒做果切”
- “适合做礼盒，节日走量”
- “适合社区团购做9.9引流款”

**4. 用一单账讲清利润**
不要只报价，要给“进货价—建议零售价—毛利—损耗后大概赚多少”。比如：“一箱进价X元，按份卖建议Y元，正常损耗下每箱能赚Z元。”数字要保守，别夸大。

**5. 主动说风险和起订门槛**
小商家最怕压货。要讲清：最小起订量、保质期、坏果怎么赔、卖不动能不能少补。这比夸产品更能促成下单。

**6. 准备一个“试吃+试卖”方案**
对只认大品类的商家，最有效的是小批量试卖：“先拿一箱试，卖得动再补。”降低决策压力。

一句话模板可以这样用：
“这是跟普通菠萝同一类的水果，但更甜、不扎嘴、切开就能卖；适合放收银台或做果切，一箱大概能赚X元，坏果包赔，先拿一箱试卖就行。”

关键原则：**别教育商家认识新品种，而是帮他把新品种挂到他 already 熟悉的货架和利润账上。**
