先给结论：**小水果店进香蕉，最该看重的是“熟度可控”，其次是坏果率，再到送货速度，价格排最后。**

原因是香蕉和其他水果不一样：它不是“买回来放着卖”的品，而是**买回来还要继续后熟、必须按天卖完的品**。所以判断顺序应该是：

1. **熟度最重要**
   - 香蕉利润来自周转，不是单斤进价。
   - 进太青：占货架、回熟慢、顾客不买；
   - 进太黄：当天卖不完就起黑点，损耗极快。
   - 小水果店理想状态是：**一次进两档熟度**，一档当天卖，一档隔天卖。能按你要的熟度供货的供应商，比便宜几毛钱更重要。

2. **坏果率第二**
   - 香蕉常见问题是压伤、水烂、把伤、催熟不均。
   - 坏果率高，表面进价低，实际每斤可售成本反而更高。
   - 小店的议价能力弱，所以要看**开箱可售率**，不要只看报价。

3. **送货速度第三**
   - 香蕉周转快，送货慢会打乱熟度安排，尤其夏天。
   - 但送货速度通常可以通过提前订货解决，不如熟度和坏果率那么致命。
   - 小店更应关注：**是否固定时间送、是否可临时补少量、破损是否认赔**。

4. **价格最后**
   - 香蕉是引流品，毛利本来就薄，单斤便宜一两毛常常被损耗吃掉。
   - 更该算的是：**进价 + 损耗 + 催熟等待 + 卖不完折价**后的实际成本。
   - 如果供应商便宜但熟度不可控、坏果不认，实际更贵。

**可执行建议：**
- 先定供应商标准：**能按你要求给7成熟/8成熟/9成熟，坏果率低于约定值，固定隔天送。**
- 每次到货做三件事：看把型是否均匀、摸是否有软烂、开箱抽查坏果。
- 小批量高频进，宁可每次少进，也不要一次压太多。
- 价格只在熟度、坏果率、送货都达标后再谈。

一句话：**小水果店进香蕉，先买“好卖完的熟度”，再买“少损耗的稳定”，最后才买“便宜”。**
