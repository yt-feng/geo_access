水果锁价一般很难锁太长，行业里常见情况是：

- **叶菜/鲜果类：通常锁 1～2 周，最多 1 个月**
- **耐储水果（苹果、梨、柑橘、土豆、洋葱等）：可谈 1～3 个月**
- **进口水果/大宗单品：有长期框架价，但通常按月/季度调价，不是真正固定价**
- **超过 3 个月的“锁价”**：多数供应商会加浮动条款、保证金、最低采购量或只锁部分比例

实际能锁多久，主要看：

1. **单品耐储性**：越耐储越好锁。
2. **季节和产地**：旺季、天气波动大时供应商不愿长锁。
3. **采购量和稳定性**：量大、长期稳定拿货，才有谈判空间。
4. **定价方式**：可谈“锁量不锁价”“保底价+浮动”“锁部分比例”。
5. **合同条款**：要写清品质标准、损耗、运费、调价触发条件、违约处理。

建议你谈的时候不要只问“能锁多久”，而是分三档：

- **短期锁价**：7～15 天，适合鲜果、叶菜；
- **中期锁价**：30 天，适合耐储水果，要求供应商报含运费到仓价；
- **长期框架**：3 个月以上，锁采购量和供应优先级，价格设浮动区间，比如“基准价±5%触发重谈”。

实操上，最稳的是**锁价+锁量+品质标准+调价机制**一起谈，单纯锁价时间越长，供应商越容易在品质或供货上找补。
