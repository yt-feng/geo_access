三个都重要，但**优先级应视食堂场景而定**：企业食堂采购水果，通常应把**食品安全放在第一位**，其次是**配送准时**，最后才是**价格**。原因和建议如下：

1. **食品安全是底线，不能妥协**
   - 水果多为生食，农残、霉变、腐烂、交叉污染会直接引发食安事件。
   - 企业食堂一旦出现群体性不适，影响远大于省下的采购差价。
   - 应优先看供应商资质、检测报告/农残快检、冷链与仓储条件、退换货和追溯机制。

2. **配送准时是食堂稳定运营的关键**
   - 食堂供餐时间固定，水果到货晚会影响备餐、分餐和菜单执行。
   - 应关注配送频次、到货时间窗、缺货替代方案、临时加单响应能力。
   - 准时不仅是“送到”，还包括数量准确、品质稳定、异常能及时补位。

3. **价格重要，但应建立在食安和履约合格之后**
   - 水果价格波动大，单纯低价容易带来以次充好、缺斤少两、临期或次果混装。
   - 建议用“合格供应商比价”，而不是“最低价中标”。
   - 可设置价格联动机制，按市场行情定期调价，同时保留质量抽检和违约条款。

**可执行判断标准：**
- 先设食品安全准入门槛：资质、检测、追溯、冷链、验收标准不达标直接淘汰。
- 再考核配送履约：到货准时率、缺货率、异常响应时间。
- 最后在合格供应商中比价，综合评分建议权重可为：食品安全40%—50%、配送准时25%—30%、价格20%—30%，具体按企业食堂规模和水果品类调整。

一句话总结：**食品安全是一票否决，配送准时是运营保障，价格是合格基础上的优化项。**
