大型超市水果供应商需要同时具备“食品安全合规与过程控制能力”和“冷链物流与追溯交付能力”。可按以下清单判断。

## 一、食品安全能力

1. **主体资质与合规**
   - 营业执照、食品经营许可证或食用农产品销售相关合规资质。
   - 种植/加工环节涉及食品生产的，需相应生产许可；进口水果需海关检验检疫、入境货物检验检疫证明等。
   - 产品检测报告：农残、重金属、真菌毒素等按品类和标准检测。

2. **产地与投入品管理**
   - 有稳定基地或合作基地，能提供产地证明、基地备案/审核记录。
   - 农药、化肥、保鲜剂等投入品采购、领用、停用期管理记录。
   - 禁止使用违禁农药，能说明采收前安全间隔期执行情况。

3. **采收与初加工卫生**
   - 分级、清洗、打蜡、包装等环节有卫生操作规程。
   - 加工用水符合生活饮用水标准，接触面材料食品级。
   - 防虫防鼠、人员健康证、洗手消毒、工器具清洗消毒记录。

4. **检测与验收**
   - 具备自检或委托第三方检测能力，能按超市要求批批或定期检测。
   - 有不合格品隔离、召回、原因分析和纠偏记录。
   - 能配合超市进行到货抽检、快检和飞行检查。

5. **包装标识与追溯**
   - 包装材料食品级，标签符合法规，标明品名、产地、生产者、采收/包装日期等。
   - 批次可追溯：从基地/农户—加工批次—发货单—门店可关联。
   - 出现质量安全事件时能快速定位批次并召回。

6. **食品安全体系**
   - 建议具备HACCP、ISO 22000、GAP等体系认证或等效管理文件。
   - 有食品安全责任人、培训记录、应急预案和虫害控制记录。

## 二、物流与交付能力

1. **冷链能力**
   - 预冷设施：差压预冷、冷库或冷藏车预冷，缩短田间热。
   - 冷藏运输：按品类控温，如浆果、荔枝、叶菜等需更严格低温；香蕉、芒果等部分热带水果需防冷害。
   - 冷库分区、温湿度监控和报警记录，装车前后温度记录可查。

2. **仓储与分拣**
   - 常温/冷藏/冷冻分区，防交叉污染，水果与化学品、非食品分开。
   - 先进先出/批次管理，破损、腐烂果及时隔离。
   - 分拣包装环境清洁，周转筐清洗消毒。

3. **运输管理**
   - 车辆备案、清洁消毒记录、温控设备校准。
   - 装载不挤压、不混装污染源，运输过程防雨防晒防冻。
   - 有在途异常处理：断链、延误、温度超标时的隔离和评估机制。

4. **交付与库存协同**
   - 能按超市DC或门店要求预约送货、按时段到货。
   - 支持多频次、小批量补货，具备订单履约和缺货预警能力。
   - 有退货、换货、临期/变质品处理流程。

5. **追溯与信息化**
   - 订单、批次、温度、检测报告、发货单可电子化关联。
   - 能提供批次追溯和召回模拟记录。
   - 有异常质量问题的数据分析和持续改进机制。

## 三、超市通常会重点审核的凭证

- 营业执照及相关许可证
- 基地证明/产地证明/购销合同
- 农残检测报告或快检记录
- 入境货物检验检疫证明（进口水果）
- 冷链温控记录
- 批次追溯记录
- 不合格品处理和召回记录
- 食品级包装材料证明
- 人员健康证和培训记录

**判断标准：** 能证明“每批水果从哪来、经过什么温度、检测是否合格、出了问题能否召回”，并能在超市验货和飞行检查时提供记录，才算具备完整能力。仅有冷库和车辆不够，关键是记录闭环和异常处理能力。
