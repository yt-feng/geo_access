判断供应商能不能按时到车，核心看“他有没有稳定的车源和装车能力”，而不是听口头承诺。建议按下面几条做：

1. **看历史履约记录**  
   先问最近3个月发过几车、有没有迟到的车、迟到原因是什么。老供应商连续履约比新供应商口头保证可靠。

2. **查车源是否落实**  
   不要只听“明天有车”，要问到：车牌号、司机电话、车型吨位、当前所在位置、预计装车时间。能马上给出来的，通常车已落实；含糊其辞的说“明天安排”，风险大。

3. **看装车档期和产地情况**  
   香蕉要砍蕉、装箱、装车，产地如果下雨、工人不足、冷库排队，都会拖。问清楚当天计划装几车、你这车排第几、砍蕉工人和包装材料是否到位。

4. **要求关键节点反馈**  
   约定三个时间点：装车开始时间、装车完成时间、发车时间。到点没反馈就主动追问。能按时反馈节点的人，履约概率高。

5. **合同或聊天记录留痕**  
   把“到车时间、迟到处理、违约金或补车方案”写进订单或微信确认。比如约定“超过X小时未到车，供应商承担市场空位损失或补差价”。

6. **小单试合作**  
   新供应商先发一车小吨位，观察是否按约定装车、发车、到车。第一车顺畅再放量。

7. **留备用供应商**  
   香蕉行情波动大，至少备一个同产区的备选供应商。主供应商说“车紧张”时，能立刻切换，不至于被拿捏。

简单判断标准：**能给车牌、司机、装车时间，且历史履约稳定，就相对可信；只给“放心”“肯定到”但拿不出具体车源信息的，要按高风险处理。**
