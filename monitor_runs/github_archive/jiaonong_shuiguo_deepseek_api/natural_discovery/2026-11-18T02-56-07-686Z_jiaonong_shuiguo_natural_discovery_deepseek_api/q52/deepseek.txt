采购时按“七成熟、硬身、无机械伤”标准挑，能明显延缓到店后变黑。可执行要点：

1. **看成熟度**：选表皮黄中带一点绿、果身硬挺的。全黄、有黑点、果柄发黑的不要，到店后基本很快变黑。
2. **摸硬度**：轻按果身有弹性但不软塌；整串果指饱满、棱角不明显但没软斑。
3. **查果柄和切口**：果柄青绿、切口新鲜；发黑、发霉、流汁的整串不要。
4. **查损伤**：避开压伤、擦伤、裂果、虫眼。香蕉皮一旦破损，乙烯和氧化会从伤口加速变黑。
5. **分串采购**：不要买整把特别大的，按2—3天用量分小串，成熟度分批，先熟先用。
6. **运输避压避热**：平放，不要堆压；避免暴晒和高温车厢，温度高会加速后熟。
7. **到店后处理**：拆掉塑料袋/纸箱，通风存放；不要和苹果、梨、番茄等释放乙烯的果蔬混放；未切开的挂起或平放，减少受压面。
8. **冷藏策略**：香蕉不宜低温冷藏，皮会变黑。若甜品店只取果肉，可等果肉达到使用成熟度后剥皮、切段冷冻；带皮香蕉放阴凉通风处即可。
9. **先进先出**：到店当天标注到货日和成熟度，优先用最熟的；每天挑出已软熟的单根先做果泥、奶昔等，避免整串互相催熟。

简单判断：**买“黄带绿、硬挺、无伤、果柄青”的香蕉，分小串、通风、不混放、先进先出**，到店后变黑速度会慢很多。
