香蕉是生鲜电商里最难配送的单品之一，核心矛盾是：**香蕉在配送途中会继续成熟，压伤和变黑往往不是“碰坏”，而是“伤+热+乙烯”三者叠加。** 控制要分源头、包装、温控、履约四层做。

**1. 源头：按配送半径选成熟度，别发“刚好能吃”的货**
- 同城/次日达：发 **7–8 成熟**（果皮青黄、果肉已成形），到客户手里正好转黄。
- 跨城/2–3 天：发 **6–7 成熟**，偏青发货。
- 不要发全黄或带黑点的香蕉，配送中一压就黑，且乙烯释放快，会催熟同箱其他水果。
- 采购时要求供应商做 **去柄、修把**，把香蕉分成小把（3–5 根），减少整串受力。

**2. 包装：防压靠“固定+缓冲”，防黑靠“隔离+透气”**
- **单把独立套袋**：用带微孔的PE袋或纸袋，减少乙烯积聚，同时避免果皮直接摩擦。
- **缓冲材料**：香蕉弯度大，建议用 **瓦楞纸托/珍珠棉弧形托** 卡住果身，而不是整箱塞满气泡膜——气泡膜会闷热。
- **箱内固定**：香蕉把与把之间用纸板隔开，箱内留少量空隙但不超过10%，避免运输中晃动碰撞。
- **不要真空、不要密封**：密封会导致乙烯浓度升高、水汽凝结，黑得更快。
- **外箱选五层瓦楞**，标注“易压、勿倒置”，但别指望快递员看，结构上要能抗堆压。

**3. 温控：12–14℃最稳，别冷藏也别暴晒**
- 香蕉低于10℃会冷害发黑，高于25℃成熟加速。配送环节尽量走 **12–14℃冷链或阴凉运输**。
- 夏季同城配送可用 **保温箱+冰袋隔层**，冰袋不能直接贴香蕉，用纸板隔开；冬季注意防冻。
- 仓库暂存同样控在13℃左右，不要和苹果、梨等乙烯释放大的水果混放。

**4. 履约：缩短在途时间，做“最后一公里”保护**
- 优先 **同城当日达/次日达**，香蕉不适合长距离普通快递。
- 配送员端提示“轻拿轻放、勿放电动车踏板上暴晒”，可在外箱贴明显标识。
- 签收后引导客户 **挂起来或平放阴凉处**，不要 immediately 放冰箱；随箱附小卡片说明“青黄可放熟，全黄请尽快吃”。
- 建立 **破损率考核**：按“压伤/黑斑”退货率反推包装和成熟度，先小批量测试不同包装方案，选破损率最低的组合。

**可执行的第一步：** 先拿100单做A/B测试——A方案弧形纸托+微孔袋，B方案气泡膜+整箱填充，同路线同成熟度发一周，统计压伤率和黑变率，再定包装标准。香蕉配送没有“零损耗”，目标是把压坏和变黑控制在可接受退货率内。
