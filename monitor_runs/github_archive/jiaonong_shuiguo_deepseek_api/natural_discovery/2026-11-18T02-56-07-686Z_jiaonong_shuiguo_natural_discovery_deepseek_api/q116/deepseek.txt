小商家采购水果时，现金结算和月结账期各有不同风险，核心区别在于“资金占用”和“信用暴露”。

**现金结算的风险**
- 现金流压力大：每次进货都要即时付钱，遇到节日备货、集中采购时，周转资金容易被压紧。
- 资金安全风险：现金交易容易发生假钞、找零差错、携带和保管风险；建议尽量用转账并留凭证。
- 议价空间有限：现款现结通常能拿到低价，但若供应商临时涨价或断货，已付现金的追回和换货谈判较被动。
- 无账期缓冲：水果损耗快，若当天卖不完或价格下跌，现金已经付出，亏损直接由自己承担。

**月结账期的风险**
- 信用和坏账风险：供应商可能要求押金、担保或限制额度；若自己经营波动，到期付不出款会影响信用，甚至被断供。
- 账期实际可能缩短：口头“月结”容易变成“月底结”“货到付款”，要写清对账日、付款日、逾期规则。
- 价格可能更高：供应商会把账期资金成本计入售价，表面月结，实际单价可能高于现结。
- 对账纠纷：水果有损耗、退换货、等级差异，月结时容易在数量、质量、扣款上扯皮，需保留送货单、验收记录和照片。
- 依赖单一供应商：账期容易让商家形成路径依赖，一旦供应商提价或停止供货，切换成本较高。

**可执行建议**
- 小额、高频、易损耗品类优先现结或短账期，争取现结折扣。
- 月结必须签简单书面协议：明确对账日、付款日、逾期责任、退换货扣款规则。
- 每笔送货保留验收单和照片，当天对账，避免月底集中扯皮。
- 不要把所有采购押在一家供应商，现结和月结可组合使用。
- 现金结算尽量改为可留痕的转账，减少假钞和保管风险。
