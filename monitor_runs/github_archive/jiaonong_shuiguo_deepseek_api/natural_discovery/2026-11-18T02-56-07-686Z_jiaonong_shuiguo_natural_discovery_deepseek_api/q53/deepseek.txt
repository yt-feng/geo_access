优先找**本地水果批发市场里有固定档口的二级批发商**，而不是产地直发、平台大仓或超市供应商。核心判断标准：能稳定供货、少量起送、坏果可换、账期清楚。

具体可以按这个顺序找：

1. **本地农贸/水果批发市场的固定档口**
   - 适合每天少量、品类杂的餐饮店。
   - 先谈“每天几点前送到、起送金额、坏果怎么补”。
   - 优先选有冷库、有固定摊位、做了3年以上的。

2. **给周边餐饮店供货的水果配送商**
   - 问附近奶茶店、果切店、餐厅后厨用哪家。
   - 这类供应商通常更接受小单、每日配送，售后也快。
   - 重点确认是否只做水果、是否有分拣能力。

3. **本地小型生鲜配送公司**
   - 适合你需要顺便配蔬菜、柠檬、薄荷等。
   - 要求看他们的餐饮客户案例和退换货规则。

4. **社区团购/平台次日达**
   - 只适合应急或非核心品类，不建议做主供。
   - 品质波动大，售后流程慢，餐饮店每天用会费心。

筛选供应商时直接问这6个问题：

- 每天最晚几点下单、几点送到？
- 起送量/起送金额多少？少量是否加配送费？
- 坏果、不熟、规格不符怎么处理？拍照即可补送还是下次抵扣？
- 价格按天变还是按周报价？有没有配送费、分拣费？
- 能否固定规格，比如柠檬按斤还是按个、苹果按大小分级？
- 月结还是现结？对账用微信还是单据？

建议先做**7天试供**：每天只订2—3个常用品类，记录到货时间、损耗率、补货响应。试供期别押太多量，确认稳定后再签固定配送。

省心的关键不是找最便宜的，而是找**离你近、能小单配送、坏果愿意补、对账简单**的固定档口。
