优先找产地或品牌方直供，区域经销商只适合做补充。

**1. 产地直采——最合适作为主渠道，但有门槛**
- 适合：单品量大、能稳定走货、自己有仓储/冷链/分拣能力。
- 优势：去掉批发市场和经销商加价，价格和货源可控，可做产地分级、定制包装。
- 风险：产地供应商资质参差、品质批次不稳、账期和售后弱；小批量采购物流成本高，反而贵。
- 可执行判断：先小批量试单2—3个产地供应商，看烂果率、到货损耗、批次一致性；能承受20%—30%的到货波动再加大直采。

**2. 品牌方——适合做品质稳定和溢价品类**
- 适合：标准化程度高的水果，如品牌化的橙子、苹果、猕猴桃、蓝莓等；你需要稳定规格、包装、售后和品牌背书。
- 优势：品质和规格更稳，有质检和售后，适合做线上、商超、礼盒。
- 风险：品牌方通常有起订量、区域保护、建议零售价限制；价格未必比产地便宜。
- 可执行判断：先确认能否小批量试销、是否控价、破损赔付标准，再谈账期。

**3. 区域经销商——不建议作为主渠道，但适合补缺口**
- 适合：临时补货、小批量多品种、需要快速到货和账期。
- 优势：起订量低、配送快、可混装、售后方便。
- 风险：中间环节加价、货源不透明，长期依赖会压缩毛利。
- 可执行判断：只把经销商当“应急仓”，控制在采购量20%—30%以内。

**建议组合：**
- 核心大单品：产地直采为主，品牌方为辅；
- 品牌化/礼盒/线上稳定款：品牌方直供；
- 小批量、临时缺货、多品类试销：区域经销商补位。

先别一上来全砍中间商。先用1—2个月做小批量对比：同一单品分别从产地、品牌方、经销商各拿一批，比较到货价、损耗率、规格达标率、售后响应和账期，再决定各渠道占比。
