应该优先关注成熟度，价格放第二位。更准确地说：**按用途分别定成熟度标准，再在同等级成熟度里比价**，不要为了低价牺牲成熟度。

可执行判断：

1. **做香蕉蛋糕/磅蛋糕/马芬**
   - 首选：**表皮大面积出现黑点、果肉软但仍能剥皮**的香蕉。
   - 甜度高、香气足、含水更稳定，成品风味明显更好。
   - 全黑软烂、流汁、有酒味或霉味的不要用。

2. **做香蕉泥夹馅、慕斯、奶油类**
   - 用**熟透但未过熟**的香蕉，避免水分过多影响结构。
   - 过熟香蕉要减少配方中液体量，或先加热浓缩。

3. **做装饰片、表面摆盘**
   - 选**七八成熟、表皮黄少量斑点**的香蕉，切片成型好。
   - 太熟容易氧化发黑、软塌。

4. **采购策略**
   - 设定成熟度验收标准：颜色、黑点比例、手感、气味。
   - 同成熟度等级内比较**单价 + 出成率 + 损耗**，不要只看每斤价格。
   - 便宜但偏生的香蕉需要催熟占库存、时间不可控；便宜但过熟的损耗和风味风险高。
   - 可与供应商约定分批到货：一批即用熟蕉，一批稍生蕉短期催熟。

5. **成本判断公式**
   - 实际可用成本 ≈ 采购单价 ÷ 可用果肉出成率 + 催熟/损耗成本。
   - 价格低但出成率低或损耗高，往往更贵。

结论：**先定用途和成熟度标准，再比价；同等成熟度下选性价比最高的。**
