判断香蕉一手货源是否稳定，别只听对方说“自己有基地/常年有货”，重点用下面几项去核验。香蕉是生鲜，稳定性核心看**产地控制力、加工催熟能力、资金和物流履约**，不是看报价最低。

**1. 先分清对方是哪种“一手”**
- 真一手：自有/包园基地，或长期包销合作果园，自己有或深度绑定加工催熟库。
- 半一手：产地代收、合作社、经纪人，能组织货源但受天气和行情影响大。
- 二手倒货：批发市场调货、拼车发货，价格可能低，但断供和品质波动最大。
让对方明确说清：基地在哪个产区、面积/合作果园数量、日均可发几条柜/几车、催熟库在哪、是否自有。**说清不了一手链条的，基本不是稳定一手。**

**2. 要“可持续的供货证据”，不要单次照片**
- 看近3—6个月连续发货记录：发货单、装车视频、物流单号、回单，最好能对应到不同日期。
- 问淡旺季供应方案：主产区换季时从哪补货，青蕉/黄蕉比例怎么控。
- 要求视频看基地和加工库，视频里让对方现场报当天日期、展示库内香蕉数量。只发精修图、拒绝实时视频的要警惕。

**3. 用“小单+多批次”试稳定性**
先下小批量，连续试3—5批，不要一次压大单。重点记录：
- 是否按约定时间发车，延误是否提前告知；
- 到货青度/熟度是否一致，单批次品率和损耗；
- 催熟后色泽、口感、货架期是否稳定；
- 缺货时是主动协调补货，还是临时加价或消失。
**能连续多批次稳定交付，比任何口头承诺都可靠。**

**4. 查履约和抗风险能力**
- 是否签购销合同：明确规格、青度、数量、发货时间、验收标准、损耗赔付、断供违约责任。
- 付款方式：优先小比例定金+到货验收尾款；对方坚持全款大额预付，风险高。
- 看有没有固定加工催熟库、冷库和稳定车队；香蕉怕断冷链和压车，临时找车的外包型供应商波动大。
- 问行情大涨时是否保价保量、行情跌时是否强行压价；能给出明确规则并写进合同的更稳。

**5. 交叉验证口碑**
问同市场同行、物流司机、包装材料商，重点问：是否经常临时断货、是否拖欠司机运费、到货质量是否前后不一。比只看对方朋友圈可靠。

**快速判断口诀：**  
说不清产区、拿不出连续发货记录、拒绝实时视频、只催大额预付、试单两批就出现延误或品质跳变的，不要当稳定一手货源。  
**先小批量连续试3—5批，再谈长期合作和账期**，这是批发档口最稳的筛选方式。
