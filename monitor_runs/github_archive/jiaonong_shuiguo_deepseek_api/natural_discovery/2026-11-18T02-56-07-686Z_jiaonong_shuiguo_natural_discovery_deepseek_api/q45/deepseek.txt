年度水果采购合同最容易踩坑的地方，集中在“价格随行就市、品质靠口头、损耗算不清、账期拖死供应商、违约只罚一方”这几类。下面按条款给你一份可直接拿去逐条核对的风险清单。

**1. 价格与调价机制**
- 坑：只写“随行就市”，没有基准、没有调价触发条件、没有通知期、没有上限。
- 建议写清：基准价（如某批发市场日均价/产地收购价）＋浮动区间；调价需提前多少天书面通知；单次涨幅上限；旺季/灾年异常波动的重新协商机制。别接受“供方有权随时调价”。

**2. 品质标准与验收**
- 坑：只写“新鲜、无腐烂”，验收凭收货员肉眼，争议时无标准可依。
- 建议：按品类附质量规格表（品种、规格、糖度、色泽、成熟度、农残检测要求）；明确抽检比例、不合格判定、整车拒收还是折价接收；农残检测报告随货或定期提供，责任归供方。

**3. 损耗与退货**
- 坑：损耗率、自然损耗、运输损耗谁承担没写；退货只写“可退”但没写运费和时限。
- 建议：分环节约定损耗承担（装车前/运输中/到店后）；明确可退情形、退货时限、退货运费由谁承担；生鲜短保品要写清“到货后多少小时内提出异议有效”。

**4. 供货量与最低采购量**
- 坑：只写年度总量，没写分月/分周计划；或反过来给供应商下“最低采购量”却不给自己下“最低提货量”，旺季压价、淡季甩锅。
- 建议：年度量拆成月度滚动计划，允许±一定比例调整；明确计划外增量如何定价、供方是否有优先保障义务；不可抗力缺货的免责边界。

**5. 账期、结算与对账**
- 坑：账期长且起算点模糊（“验收后”还是“开票后”），对账无周期，扣款无依据。
- 建议：写明结算周期、起算日、付款日、逾期付款责任；建立月度对账机制；质量扣款、返利、促销费用必须凭双方确认单扣，禁止单方扣款。

**6. 返利与费用条款**
- 坑：进场费、条码费、节庆费、返利层层叠加，返利基数（含税/不含税、是否含退货）不清。
- 建议：所有费用列明项目、金额、计算基数、支付方式；返利写清阶梯和结算时点；拒绝“其他费用按实际发生”这类开口条款。

**7. 违约责任是否对等**
- 坑：只罚供应商断货、质量不合格，超市逾期付款、无故拒收却无责任。
- 建议：双向违约条款；断货违约金要有上限且与缺货比例挂钩；超市逾期付款同样约定违约金；明确合同解除条件和过渡期供货义务。

**8. 独家/排他条款**
- 坑：要求供应商对某区域或某品类独家，却没有对应采购承诺，供应商被锁死。
- 建议：排他必须绑定最低采购量或最低采购额，否则不签排他；明确排他范围和期限。

**9. 不可抗力与价格异常**
- 坑：把“市场价格上涨”当不可抗力，或灾年供方直接断供无协商义务。
- 建议：不可抗力限定为法定情形；约定极端行情下的协商程序和临时替代方案，而不是单方停供。

**10. 食品安全责任与追溯**
- 坑：出问题只写“供方负责”，但没写追溯、召回、赔偿范围。
- 建议：明确供方提供产地证明/检测报告、配合召回、承担因质量问题导致的消费者赔偿和行政处罚；约定责任上限时注意食品安全类不设过低上限。

**实操建议：** 签约前让采购、财务、法务三方各过一遍上述条款；品质规格表和价格机制作为合同附件；所有口头承诺（如“卖不完可以退”）写进合同。最容易被忽略、事后扯皮最多的三处是：**验收标准、损耗承担、账期起算日**，优先把这三条写死。
