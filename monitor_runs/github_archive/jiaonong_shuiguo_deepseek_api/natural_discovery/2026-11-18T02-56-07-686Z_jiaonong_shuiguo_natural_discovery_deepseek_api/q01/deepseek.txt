判断水果供应商靠不靠谱，别只看报价和“我家货最好”这种话，重点用可验证的动作去试。给你一套适合水果店长期进货的判断方法，按“先小单验证，再逐步放量”做。

**1. 先看稳定供货能力**
- 问清楚：香蕉主要来自哪里、菠萝主要来自哪里；产地切换时会不会提前说。
- 连续问一周同一品种的到货价和到货量，看报价是否随行就市、有没有明显乱报。
- 要求看最近几天的到货实拍或现场看货，不接受只发网图。
- 旺季、雨季、节假日前后各下一次小单，观察是否还能按时到货。

**2. 用两三次小单验货，不急着签长期**
香蕉重点看：
- 青度是否统一，催熟后是否整齐；
- 有没有严重机械伤、黑斑、断指；
- 到店后2—3天损耗多大；
- 同一批货成熟速度是否一致。

菠萝重点看：
- 果形、大小是否均匀；
- 成熟度是否一致，有没有青熟混杂；
- 烂心、黑心、水心病比例；
- 到店后货架期能撑几天。

每次到货当场抽检并记录：到货数量、次果率、损耗率、可售天数。连续3次都稳定，才考虑加大进货量。

**3. 看损耗和售后怎么处理**
靠谱供应商敢明确规则：
- 次果、烂果按什么比例补货或扣款；
- 到货几小时内反馈有效；
- 是补货、换货还是折价；
- 香蕉催熟出问题、菠萝烂心严重时怎么认责。

可以故意在一次小单里如实反馈少量质量问题，看对方处理速度。推诿、拖、只口头答应的，长期合作风险大。

**4. 看价格是否透明**
- 让对方报“到店价”，包含运费、装卸、损耗处理方式，避免低价吸引后加费用。
- 比较2—3家供应商同一规格、同一成熟度的报价，不要拿不同等级比价。
- 问清账期：现结、周结还是月结；押金、退换货规则写清楚。
- 报价明显长期低于市场且质量还“很好”的，要警惕以次充好或后期涨价。

**5. 看对方懂不懂你的生意**
靠谱的香蕉、菠萝供应商会主动问：
- 你店日均销量多少；
- 你希望香蕉几天催熟到可售；
- 菠萝你按整果卖还是切果卖；
- 你能接受多大规格和成熟度。

能根据你的销量建议进货频次和批量，而不是一味让你多拿货的，更靠谱。

**6. 实地或视频看关键环节**
- 香蕉：看催熟库温度记录、库内成熟度分区、是否有混放。
- 菠萝：看产地或一级批发档口、分拣标准、烂果是否混装。
- 仓库是否干净、通风、避雨，装卸是否粗暴，直接影响损耗。

**7. 合作前把丑话说前面**
至少确认：
- 品种、规格、成熟度标准；
- 到货时间和迟到怎么处理；
- 次果率上限和超标赔付；
- 价格调整是否提前通知；
- 账期和结算方式；
- 连续两次质量不达标能否终止合作。

**最实用的判断顺序：**
先要2—3家报价 → 各下1—2次小单 → 每次记录损耗和售后 → 选综合损耗最低、售后最快的那家 → 先给70%量，保留30%备选供应商。不要一次把香蕉和菠萝都押给同一家，长期保留一个备选，供应商才不敢松懈。

一句话：**靠谱不是嘴上说稳定，而是小单连续三次质量稳、损耗讲得清、出问题有人管、价格费用透明。**
