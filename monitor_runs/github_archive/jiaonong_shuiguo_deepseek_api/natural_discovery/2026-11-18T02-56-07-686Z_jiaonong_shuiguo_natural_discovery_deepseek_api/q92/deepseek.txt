小面积便利店做水果，核心不是“品类齐全”，而是**少SKU、快周转、强控损**。建议按下面执行：

## 1. 品类控制：先做“便利店水果”而不是“水果店水果”
优先选**高频、易识别、耐放、单果小、可即食**的品类。

**建议保留的核心品类：**
- 香蕉：高频、引流，但损耗可控，按成熟度分批上架
- 苹果/梨：耐放，适合做基础款
- 柑橘类：橙子、砂糖橘、丑橘，季节性强、周转快
- 提子/葡萄：小包装销售，避免散放挤压
- 小番茄：即食属性强，适合便利店场景
- 季节性单品：夏天西瓜切盒、冬天砂糖橘，最多1-2个爆款

**建议少做或不做的：**
- 草莓、蓝莓、樱桃等高价易损品，除非有稳定客流和冷链
- 榴莲、菠萝蜜等大果整卖，占空间、动销慢
- 多品种散装混卖，增加挑拣和翻动损耗
- 叶菜型水果、熟度难控的热带果，新手店慎碰

**SKU数量建议：**
- 20㎡以内：水果SKU控制在**8-12个**
- 30-50㎡：控制在**12-18个**
- 每个品类只留**1-2个规格**，比如苹果只做“3个装/袋”和“单果”，不要同时上5个品种

## 2. 采购控制：小批量、多频次、按销定采
- **日采或隔日采**：小门店不要一次囤3-5天量，尤其香蕉、提子、小番茄
- **按“预估日销×1.2”订货**：首周先少量试销，记录每个单品日销
- **ABC分层**：
  - A类引流品占销量60%：香蕉、柑橘、苹果，保证不断货
  - B类利润品占30%：提子、小番茄、季节果
  - C类试销品占10%：每周只试1个新品，7天不动销就下架
- **采购标准写死**：成熟度、单果重量、包装规格、到店时间，避免采购员凭感觉拿货

## 3. 损耗控制：从收货到出清全流程
- **收货验货**：当场翻箱，拒收压伤、过熟、霉变；香蕉按“青果+黄果”分批到店
- **小包装销售**：苹果3个装、提子小盒装、小番茄盒装，减少顾客翻拣
- **先进先出**：新货放里侧，旧货放外侧；每天早晚两次翻检
- **分级出清**：
  - 轻微瑕疵：做“特价盒”或切盒，当天清
  - 过熟香蕉：做香蕉奶昔原料或特价单根卖
  - 当天未售完的切盒水果：闭店前打折，不留到次日
- **温控**：香蕉常温避风，提子/小番茄/切盒冷藏；切盒必须冷藏且当天售完
- **损耗记录**：每天记录报损品类、数量、原因，连续3天报损高的单品直接减量或下架

## 4. 简单可执行的指标
- 水果整体损耗率控制在**5%-8%**以内，超过10%说明订货或品类有问题
- 单品动销：**7天不动销就淘汰**
- 香蕉、柑橘类保证**日清或隔日清**
- 每周复盘一次：销量前3保留，后3减量或下架

**一句话原则：小门店水果只做“少、快、小包装、勤出清”，不要追求品类全，先追求周转快。**
