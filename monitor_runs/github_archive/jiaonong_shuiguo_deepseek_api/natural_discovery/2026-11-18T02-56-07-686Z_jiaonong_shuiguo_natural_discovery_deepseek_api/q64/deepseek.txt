批发档口的退货纠纷，八成不是货不好，而是“验货标准没对齐”。建议按下面四步做，当天就能落地。

**一、收货前先定标准，别等货到了才吵**
- 和供货方、客户各确认一份书面验收标准：品类、规格、颜色色差范围、允许瑕疵比例、破损如何认定。
- 关键指标量化：比如“色差以自然光下目测不超一个色阶”“每箱允许≤2%轻微瑕疵，超出的按件补”。
- 把标准写进订单或送货单备注，双方签字/微信确认都算数。

**二、收货现场固定动作**
1. **先点总数再抽检**：外箱数量、件数当面点清，异常当场拍照。
2. **按比例抽检**：大批量抽10%～20%，小批量全检；抽检发现超标就扩大抽检或全检。
3. **三类问题分开记**：数量短少、外观瑕疵、功能/规格不符，分别拍照并标注箱号、件号。
4. **当场出结论**：合格入库；不合格当场在送货单上注明问题、数量，双方签字，别拖到第二天。

**三、留证据，降低扯皮**
- 每批货拍：整批外观、开箱过程、问题特写、箱唛/批次号，视频比照片更有说服力。
- 建立简单验收记录表：日期、供货方、批次、抽检数、问题数、处理结果、签字。
- 问题货单独隔离存放，贴标签，避免混入正常库存后被客户退回来时说不清。

**四、对下游客户也前置规则**
- 发货前随货附“验收提示”：到货24～48小时内验货，超期视为数量无异议；外观问题需提供开箱视频。
- 明确可退换范围：质量问题和错发漏发全责；客户主观选款、色差在约定范围内不退。
- 退货必须走登记：原因、照片、批次，能追溯到具体进货批次，方便向上游索赔。

**一个判断标准**：如果同一类退货一个月出现3次以上，说明不是偶发，而是验收标准或某家供货方有问题，要重新谈标准或换供应商。
