**搭配比例建议（按成本算）**

**实操避坑**
- 香蕉和菠萝都会释放乙烯，催熟苹果橙子，**装箱时香蕉根部包保鲜膜，菠萝套袋**，别让它们直接贴苹果。
- 菠萝叶子会扎破包装，**剪掉叶冠或套网套**。
- 礼盒里放一张“食用顺序”小卡：先吃香蕉、再吃菠萝、苹果橙子耐放，减少售后。
