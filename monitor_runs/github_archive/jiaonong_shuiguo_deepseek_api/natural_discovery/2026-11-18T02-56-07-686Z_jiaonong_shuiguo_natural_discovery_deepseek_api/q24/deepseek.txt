建议先向供应商要“可核验、能和这批货对得上”的资料，重点不是收一堆证书，而是能追溯到批次并判断风险。通常要以下几类：

1. **批次检测报告（农残）**
   - 要**与本次到货批次对应的检测报告**，不是只给一张年度报告。
   - 看：检测机构、报告编号、样品名称、采样/收样日期、检测项目、检出值、判定依据、结论。
   - 优先要**CMA/CNAS资质**机构出具的报告；至少确认报告可查、编号可核验。
   - 对高风险水果（如草莓、葡萄、柑橘、豇豆类蔬菜等）要求更严，必要时每批要报告。

2. **产地/供应商资质与溯源信息**
   - 供应商营业执照、食品经营许可证或食用农产品销售相关资质。
   - 产地证明、种植基地信息、合作社/农户信息、采收日期、批次号。
   - 包装标签、送货单、随货同行单，确保**批次号、品名、数量、日期**能和检测报告对应。

3. **承诺书/质量保证协议**
   - 供应商书面承诺：所供批次符合农残限量标准，出现问题承担退换货、检测费、监管处罚连带责任。
   - 明确抽检不合格的处理流程、召回和赔偿条款。

4. **进货查验与自检记录**
   - 供应商的进货查验记录、快速检测记录（如有）。
   - 若供应商从批发市场进货，要求其提供上游供货凭证和快检合格记录。

5. **包装与储运信息**
   - 包装日期、保质期/最佳食用期、储存条件、运输温湿度记录（对易腐水果）。
   - 防止“报告是A批次，货是B批次”。

**实操建议：**
- 在采购合同里写明：**每批随货提供批次检测报告或快检合格证明；无法提供的，超市有权拒收或批批自检。**
- 到货时做“三对”：**对品名、对批次号、对日期**，报告与实物不一致就不收。
- 对无报告或高风险品种，用超市快检设备做农残快检，留样备查。
- 不要只收“合格证”照片，要留存原件或清晰扫描件，并建立供应商档案。

一句话：**要“这批货的农残检测报告+批次溯源信息+质量承诺”，并确保报告和实物批次对得上。**
