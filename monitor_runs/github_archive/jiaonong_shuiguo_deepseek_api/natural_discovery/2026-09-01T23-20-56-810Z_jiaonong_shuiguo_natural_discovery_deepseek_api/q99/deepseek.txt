选择适合批量配送的水果供应商，建议按以下步骤操作，兼顾质量、成本和配送效率：

### 一、核心筛选标准（先定硬指标）
1. **资质合规**：要求供应商提供《食品经营许可证》、营业执照，水果类还需核查是否有**农产品合格证明**（农残检测报告）。
2. **配送能力**：重点确认：
   - 能覆盖你司下午茶时间（如提前一天晚上或当天早晨配送）
   - 配送车辆是否冷链/保温（避免夏季融化和磕碰）
   - 是否支持**固定周期订单**（如每周二、四固定送）
3. **损耗承诺**：明确“坏果包赔率”（如每箱超过10%损坏免费补发），以及退换货流程。

### 二、批量采购的3种主流渠道及适合场景
| 渠道类型 | 适合情况 | 注意点 |
|---------|---------|-------|
| **本地水果批发市场**（如新发地、江南市场） | 单次量大（百人以上）、追求最低价 | 需自行提货或另谈配送，品质参差，需现场验货 |
| **区域连锁生鲜配送商**（如美菜、快驴） | 中小规模、需要标准化配送 | 价格中等，适合固定周期自动补货，建议先试单 |
| **原产地/果业公司直供**（如百果园、本来生活企业版） | 重视品质、需定制水果拼盘 | 价格较高，但售后好，可提供节日礼盒方案 |

### 三、落地动作（按顺序操作）
1. **锁3家候选**：在本地批发市场找1家档口（看实物），在生鲜平台注册企业账号领试用价，再联系1家品牌果业企业客户经理。
2. **试单测试**：每家先下最小批量（如20份），重点考察：
   - 配送准点率（误差±30分钟内）
   - 水果新鲜度（切开测糖度、看表皮损伤）
   - 售后响应速度（拍坏果照片后多久补发）
3. **谈账期与合同**：批量后要求“月结”或“货到付50%”，合同中明确**价格锁定周期**（如水果价格波动大，可约定“周报价”制度）。

### 四、避坑提醒
- **避免只比价格**：批发市场低价水果可能混入次级果，建议要求“整箱开箱抽检”。
- **注意配送时间**：设定“送达时间窗口”（如上午10:30前必须到），超时扣款。
- **留好质检凭证**：每次收货拍视频留证，尤其是整箱水果的封条和箱体完整度。

如果公司预算充足且需要长期稳定品质，优先考虑连锁果业直供；如果预算有限且人数多，选择本地批发+自备小厢货（或谈好固定司机配送）最划算。
