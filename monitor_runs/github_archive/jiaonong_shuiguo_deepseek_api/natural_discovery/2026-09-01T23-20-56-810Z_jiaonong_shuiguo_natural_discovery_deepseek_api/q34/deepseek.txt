这是一个非常经典且重要的零售经营问题。直接说结论：

**在大多数情况下，“损耗低”对最终毛利的影响更大，且更可控。** 但“价格低”决定的是毛利的上限，而“损耗”决定的是毛利的下限（甚至决定了是否亏损）。

为了让你更清晰地做决策，我们可以用两个具体的模型来拆解：

### 1. 计算模型：为什么损耗的“杀伤力”是价格的2倍以上

假设一款水果（如车厘子）：

- **方案A（高价格低损耗）**：进货价 50元/斤，定价 80元/斤，损耗率 5%。
- **方案B（低价格高损耗）**：进货价 40元/斤，定价 70元/斤，损耗率 20%。

*我们先看销售额（按进货100斤算）：*
- A方案：卖出95斤，销售额 95×80 = 7600元
- B方案：卖出80斤，销售额 80×70 = 5600元

*再看毛利（收入 - 成本）：*
- A方案毛利：7600 - （50×100）= 2600元，**毛利率 = 2600 / 7600 ≈ 34.2%**
- B方案毛利：5600 - （40×100）= 1600元，**毛利率 = 1600 / 5600 ≈ 28.6%**

**核心差异：**
B方案虽然进价便宜了20%（50→40），损耗却高了15%（5%→20%），最终**毛利绝对值少了1000元（约38%），毛利率低了近6个百分点**。

**关键逻辑：**
损耗不仅是丢失了“销售重量”，还丢失了“利润空间”。在零售定价中，毛利 = 售价 - 真实成本。真实成本 = 进价 ÷ （1 - 损耗率）。损耗每提高1个百分点，相当于进价成本被**放大**了1/(1-损耗率)倍。当损耗从5%升到20%，真实的单位成本从52.6元涨到了50元÷0.8=62.5元——**进价便宜了10元，但真实成本反而高了10元**。

### 2. 实操判断：什么情况下“价格低”更重要？

虽然损耗重要，但**如果你能通过“低价+快速周转”把损耗压下来**，价格低就是优势。判断条件如下：

- **当水果是“走量型”**（如当季西瓜、香蕉、柑橘）：这类水果价格透明，消费者对价格极敏感。此时**价格低带来的客流和销量**，会摊薄单位损耗。如果低价能引发抢购，损耗可能不到3%，那低价策略胜出。
- **当水果是“高毛利型”**（如进口提子、阳光玫瑰、榴莲）：这类水果本身价格高，一盒损耗就相当于十箱香蕉的利润。此时**宁可单价高一点，也要选品控好、耐存放的货源**，损耗控制是生死线。

### 3. 财务上的“损耗陷阱”警告

很多采购只算“进价”便宜，忽视了两个隐性成本：

- **折价损失**：损耗水果不可能全扔掉，往往打折销售（如5折）。这时损耗带来的毛利损失是**双倍的**——既丢了原价利润，又产生了额外折价损失。
- **机会成本**：高损耗意味着你会频繁处理烂果、清理货架、重新上架，占用人力时间。这些时间本可以用于提升其他高毛利商品的陈列。

### 4. 最终结论与采购策略建议

**采购决策矩阵（优先级排序）：**

1. **第一优先：看“货架寿命”和“到货品质稳定性”**。如果A货源到货后能放7天，B货源只能放3天，即使B便宜20%，大概率选A。因为3天之后全是损耗。
2. **第二优先：看“损耗控制能力”**。如果你商超的冷库、冷链、分拣能力强，可以通过技术手段（如预冷、分装）把损耗压到5%以内，那么价格低可以成为竞争优势。
3. **第三优先：看“坪效”**。如果这个柜台面积有限，高损耗会占用空间且影响顾客购物体验（看到烂果会嫌弃），反而拖累其他商品销售。

**一句话总结：**
**“价格低”是让你赚得多，但“损耗低”是让你不亏本。**
在生鲜行业，**先保证不亏（损耗可控），再去追求赚得多（价格低）**。建议采购时，优先考察供应商的分拣标准、冷链物流、到货新鲜度，**把“损耗率”作为谈判的核心指标**，而不是只盯着批发价。如果供应商能承诺“到货损耗低于3%”，即便单价贵5%-8%，长期算总账往往是赢家。
