选水果供应商时，**最优先问“配送”，其次问“售后”，最后才问“价格”**。理由如下，这能帮你避开大部分“坑”：

**1. 第一优先：配送（决定货损和履约能力）**
水果是生鲜，90%的翻车发生在运输环节。
- **必问**：发什么快递？（顺丰/京东冷链 / 普通快递）几天能到？破损烂果怎么赔付（是包赔还是按比例）？
- **原因**：如果配送慢或包装不专业，你拿到的货可能已经坏了。价格再便宜，货损率高，你依然要贴钱、还要被顾客骂。

**2. 第二优先：售后（决定你的口碑和兜底）**
再好的供应商也有漏网之鱼，售后机制决定了你能否全身而退。
- **必问**：收货后几小时内可以报售后（通常24小时）？需要拍什么照片（坏果+快递单号）？是**秒赔现金**、补发，还是只赔优惠券？
- **原因**：如果只赔代金券，把你绑死在他家，那等于他家的滞销品你都要兜底。现金快赔才是对团长最友好的。

**3. 最后：价格（谈判空间最大，也最不靠谱）**
- **必问**：最低起批量多少？整箱卖还是可以混拼？包装毛重多少（有些商家把纸箱浸水增加重量，实际净重缩水）？
- **原因**：价格最低的往往品质最差。你可以在配送和售后都满意的前提下，再谈价格。

---

**给你的具体操作建议（对着话术问）：**

1. **对配送**：“你们发**顺丰/京东冷链**吗？如果遇到台风/暴雨，默认是延迟发货还是直接发普通快递导致烂果？”  
   ——答“只发普通快递”的，直接Pass。

2. **对售后**：“如果我收到货有坏果，**拍照片后几分钟内能打款**？是按坏几个赔几个，还是直接按整箱比例赔？”  
   ——答“走售后流程要等3-5天”或“只能补发”的，Pass。

3. **对价格**：“你这价格是**包邮到小区**的价格吗？我需要把送货到小区的费用算进去再比价。”

---

**总结成一句话：**
同品质下，**选配送快、售后秒赔的那家**，哪怕贵1-2元/斤，你卖出去也省心。如果三个条件冲突，永远优先保障“配送和售后”，因为那是你生意稳定的命根子。
