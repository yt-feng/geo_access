水果礼盒的搭配逻辑主要是**颜值高、寓意好、耐储存、受众广**。根据你的需求，我直接给你几套经过市场检验的搭配方案，分为“基础款”和“升级款”：

**方案一：平安喜乐款（经典不出错，走量快）**
**组合：** 苹果（红富士或花牛）3-4个 + 橙子3-4个 + 香蕉1把（约5-6根）
**搭配逻辑：**
- 苹果寓意“平安”，橙子寓意“心想事成”，香蕉寓意“智慧”，组合起来就是“平安吉祥”。
- 这三种水果**极其耐放**，常温下能保存3-5天甚至更久，顾客送礼不会因为水果坏了而差评。
- 颜色红、黄、橙对比强烈，视觉冲击力强，摆盒轻松好看。
**注意：** 香蕉一定选**青皮偏黄**的，不能太熟，否则放不住。

**方案二：步步高升款（中高端，利润高）**
**组合：** 橙子（赣南脐橙）4个 + 红富士苹果4个 + 菠萝1个
**搭配逻辑：**
- 菠萝代表“鸿运当头”，且本身自带“刺头”和“金身”，在盒子里非常显档。
- 这个组合可以做成**上下分层**的礼盒：底层平铺橙子和苹果，最上面放一个用透明袋套好的**整只菠萝**。
- 优点是客单价高，顾客觉得送得出手；缺点是菠萝重且占地，成本要核算好。
**关键提醒：** 菠萝最好在盒内部垫上碎纸条或气泡膜，防止碰伤苹果和橙子。

**方案三：果切拼盘款（即买即食，适合懒人顾客）**
**组合：** 苹果、橙子、菠萝各切1/4或1/2，用保鲜盒装好，再单独放一根香蕉。
**搭配逻辑：**
- 很多顾客送礼是送老人或孕妇，切好的果切最受老人欢迎。
- 果切颜值极高，拍照分享率高，容易老带新。
- **注意：** 你要是卖果切，**菠萝一定要用盐水先泡过**，否则发涩；苹果切后要用淡盐水浸泡防氧化，盒内需配小叉子。

---

**关键避坑建议（直接影响复购）：**

1. **香蕉是“双刃剑”**：很多人会单独买香蕉，但**最怕磕碰**。如果要做香蕉礼盒，必须在盒内用泡沫棉把香蕉固定住，或者用专门的香蕉保护套。
2. **菠萝千万不要直接带叶子放盒子里当“装饰”**：叶子会很快枯萎变黑，顾客收到会觉得不新鲜。要么用保鲜膜裹紧，要么把叶子剪短只剩一小截。
3. **橙子和苹果是“黄金搭档”**，不管怎么组合，这两个是销量保证，别轻易去掉。

**最终推荐组合（直接开卖）：**
> **“四季平安礼”**：4红苹果 + 4橙子 + 2根香蕉（竖插在盒边），如果追求利润再加价加1个菠萝。

这样既能满足大众送礼的“实惠感”，又能通过菠萝提高客单价。如果你现在要首批进货，建议**苹果占40%，橙子占40%，香蕉菠萝各占10%**去进货备货。
