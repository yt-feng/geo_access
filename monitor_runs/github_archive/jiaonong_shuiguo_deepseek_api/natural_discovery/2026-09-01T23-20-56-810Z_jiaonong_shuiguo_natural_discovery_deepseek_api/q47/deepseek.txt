采购香蕉用于茶饮或甜品时，熟度控制是决定成品风味、质地和保存周期的核心环节。以下是具体的分阶段建议：

**1. 明确你的目标用途，再定熟度标准：**

- **做香蕉奶昔、冰沙、果泥、布丁：** 需要**完全成熟（软熟）**。标准是表皮出现芝麻状黑点（即“芝麻蕉”），手感捏起来有明显的软弹感，果肉呈淡黄色或半透明状，甜度最高，香气浓郁，便于打碎且口感顺滑。
- **做烤香蕉、香蕉厚切吐司、固体甜品装饰：** 需要**微熟（黄中带绿）**。表皮基本全黄，按压时略有弹性但不软塌。这种熟度烤制后不易烂，能保持形状，且甜度适中。
- **做香蕉片、香蕉果酱（需长时间熬煮）：** 建议**中熟（全黄但未变软）**。既方便切片不碎，又有自然甜味。

**2. 采购时的现场检查技巧：**

- **看颜色分层：** 不要只买一个色号的香蕉。建议分批采购：** 70% 为当天或第二天可用的“硬熟”**（全黄，微硬），**30% 为“软熟”**（芝麻点）。这样可以确保2-3天内的轮转供应。
- **试手感：** 轻轻捏香蕉的**中段**，不要捏两头（两端软代表存放过久）。理想状态是：捏上去能回弹，但指印不会明显凹陷。
- **闻香气：** 成熟的香蕉有独特的清甜果香；如果有酒精味或发酵酸味，说明过熟变质，坚决不取。
- **看果柄：** 果柄翠绿、干燥为新鲜；果柄发黑或出水，表示内部已开始褐变。

**3. 到店后的管理策略：**

- **分温度区存放：** 成熟的（芝麻蕉）放入冷藏（4℃左右）延缓后熟，最多可保存2天，但表皮会变黑（不影响内部，但影响外观，适合打浆）。微熟的（绿黄色）放在室温阴凉处催熟，不要放冷藏，否则停止变熟且口感变涩。
- **制定“先熟先用”制度：** 每日检查，将最软的优先用于打浆类产品，将偏硬的用于切片类产品。严禁将不同熟度混放，以防全部被催熟。

**4. 常见误区提醒：**

- **不要迷信“越软越好”：** 全黑的香蕉果肉虽甜但质地过软，打浆时容易出水，且氧化发灰，影响饮品色泽。
- **不要一次买太多：** 茶饮店周转快，建议按3天用量采购，宁缺毋滥。如果某天卖出少，优先将成熟香蕉做成2天内的库存（如冷冻果泥）。
- **冷链注意：** 如果供应商已冷藏运输，拿回来后不要立即放回冷库，先在室温回温20分钟，否则香蕉内部会“冻伤”变黑，口感发硬。

**总结执行口诀：** “打浆选芝麻蕉，切块选黄硬蕉，当天到货先按熟度分筐，先打软、后切硬。” 每天早晨花1分钟检查熟度并以当天产品结构决定使用顺序。
