和酒店早餐水果供应商谈合作时，要注意以下几点，以确保供应稳定、成本可控、品质达标：

**一、明确核心需求，而非只谈“水果”**
- **品种与规格**：具体到每日需要的种类（如苹果、香蕉、橙子、西瓜、提子等）、每份克重/数量、切配标准（整果、切片、拼盘）。
- **稳定供应量**：预估月度/季度用量，明确波动范围（如旺季增加30%），要求供应商承诺在突发情况下有备用供应渠道。
- **配送时效**：明确每日配送时间（建议早餐前1小时到位）、冷链要求、验收标准（如无碰伤、无腐烂、温度达标）。

**二、合同中的关键条款（重点防坑）**
- **价格机制**：
  - 签订**季度/半年度固定价**，或约定“基准价+浮动百分比”条款，防止水果季节导致价格暴涨。
  - 明确**含税、含配送费**，避免后期隐形加价。
- **质量违约条款**：
  - 约定**不合格品率**（如超过5%整批赔付或折扣）。
  - 写明“若因缺货导致酒店客人投诉，供应商需承担相应损失赔偿”。
- **付款方式**：建议**月结30-45天**，但要求供应商提供送货单+发票，并保留10%质保金（1个月后无质量问题付清）。

**三、考察供应商真实能力（不要只听报价）**
- **实地考察**：查看供应商的分拣/仓储场地是否卫生，是否有冷库，是否有固定产地合作。
- **要求试供期**：先签3个月试供合同，用实际数据检验其稳定性和品控。

**四、建立日常管理机制（保证执行）**
- 每天收货时**留样拍照**，核对数量、质量，签字确认。
- 每月做一次**成本核算对比**，看损耗率是否能控制在3%以内。
- 保持**备选供应商**（至少2家），但不要轻易更换主供应商，以防货源混乱。

**五、特别注意两点（易被忽略）**
- **水果季节性问题**：提前在合同中约定“季节性替换方案”，例如冬季用柑橘类替代部分西瓜，避免供应商随意以“季节原因”涨价。
- **食品安全合规**：要求供应商提供**食品经营许可证、产地证明、质检报告**，并明确若因水果问题导致食物中毒，由供应商承担全部法律责任。

如果觉得信息量大，可以按“价格/质量/配送/违约”四维度做一张对比表，现场与两家供应商谈判后比对选择。
