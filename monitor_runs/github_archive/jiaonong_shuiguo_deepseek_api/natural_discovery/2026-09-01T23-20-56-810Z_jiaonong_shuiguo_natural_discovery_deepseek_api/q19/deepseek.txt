在超市挑选菠萝时，**核心原则是“卖相与损耗并重，甜度靠经验，大小看用途”**。具体优先级建议如下：

1. **切果损耗（最重要，应最先考虑）**  
   - **判断依据**：观察菠萝果眼（表皮上的小黑点）深浅。果眼越浅，切肉时的损耗越少；果眼深且密，切下来会浪费很多肉。  
   - **实操技巧**：用手轻按压果实中部，如果果肉发软且有弹性，通常熟度刚好、果肉多；如果硬邦邦，切开后可能果肉少或发白。  
   - **损耗控制**：尽量选果体饱满、圆锥形（上下直径接近）的，这种形状切出的果肉完整，而瘦长形或畸形果在削皮时损耗更大。

2. **外观（次重要，直接反映新鲜度）**  
   - **看颜色**：选金黄或黄中带绿的（果皮颜色越黄，成熟度越高，但全黄的可能是过熟，易软烂）。避免有黑斑、霉点或明显软化凹陷的。  
   - **看叶子**：顶部叶子翠绿、挺拔，说明采摘后时间短，水分足；叶子发蔫或干枯则可能放置过久。  
   - **闻气味**：底部有浓郁菠萝香（无酸馊味）为佳，无香味可能未熟。

3. **甜度（参考性中等，无法直接判断）**  
   - **替代判断**：按压时微微发软的通常更甜；果皮越黄，糖分积累越多。但请注意，菠萝的甜度受品种影响大（如“香水菠萝”偏甜，“菠萝蜜”则偏酸），且超市中很难准确预测。  
   - **建议**：如果采购需要，可现场切开试吃一小块，或询问供应商该批次的品种特性，避免单看外观造成误判。

4. **大小（优先级最低，看需求）**  
   - **需求取向**：若按个卖，选大果更划算；若按斤卖，中小果可能更划算（因为大果水分含量比例可能略高）。家庭食用选中等大小即可。  
   - **注意**：不要盲目追求大，大而不饱满的菠萝往往纤维粗、水分少。

---

**给超市采购/陈列的具体建议**：
- **采购时**：带上水果刀，切开一个样品查看果肉厚度和颜色（橙黄透明为上），同时记录该批次的果眼深度，直接量化损耗率。  
- **陈列时**：将颜色金黄、叶片新鲜的放在显眼处优先售卖，避免长时间堆放导致过熟变质。  
- **促销策略**：如果发现某批菠萝果眼深、损耗大，可以考虑按个低价销售（而非按斤），并建议顾客“先吃皮、后吃肉”，减少售后抱怨。

**一句话总结**：先用手摸硬度和看果眼深浅控制损耗，再看颜色和叶子新鲜度，甜度靠切开试吃或品种经验，大小最后根据定价灵活处理。
