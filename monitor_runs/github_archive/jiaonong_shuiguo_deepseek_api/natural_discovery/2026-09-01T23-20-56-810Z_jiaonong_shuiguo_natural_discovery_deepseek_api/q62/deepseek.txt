判断一批香蕉的熟度和坏果风险，主要看外观、手感、气味和温度。以下是具体判断方法和风险提示：

**1. 熟度判断（按需选择）**
- **催熟前（青果）**：皮色青绿、果身硬挺、棱角分明，成熟度低，适合长期存放或远途运输。
- **半熟**：皮色黄中带绿，果身略软但仍有弹性，棱角稍平，适合1-3天内销售。
- **熟透**：全黄、果柄微黑、果皮出现少量褐色芝麻点（梅花点），果肉软糯，适合立即销售，不宜久存。
- **过熟**：大面积黑斑、果皮易裂、果肉发软甚至流水，基本不能作为商品果销售。

**2. 坏果风险快速排查**
- **看果柄**：果柄新鲜、切口湿润为佳；若果柄发黑、干枯或发霉，内部可能已变质。
- **按压果身**：轻按果腰，若局部明显凹陷、发软或出水，说明该处已烂；全果均匀微软为正常成熟。
- **闻气味**：有酒味、酸味或发酵味，说明内部已过熟或开始腐烂；淡清香味为正常。
- **翻箱检查**：整箱逐层抽查（至少抽上、中、下三层），重点看箱底是否有烂果汁液、黑斑或虫蛀。
- **检查碰撞伤**：香蕉极怕压伤，箱内若压紧或堆叠过高，表面有褐黑色凹痕的，坏果风险高。

**3. 附加风险提示**
- 香蕉是呼吸跃变型水果，一旦受热或挤压会迅速成熟，**夏天拿货风险最高**，务必确认冷链或夜间运输。
- 若货是催熟好的，问清楚**催熟剂用量和时间**；催熟过度的货，表面好看但内部易烂，需当场切开观察果肉颜色（正常应为淡黄，发灰或透明说明已变质）。
- 拿货时尽量**拆箱抽查**，不要只看表面一层，避免“上层好果、下层烂果”的情况。

**一句话总结**：拿货时抽三层检查外观和硬度，闻气味，看果柄，优先选果柄新鲜、无凹陷、无发酵味的货；夏天要格外重视冷链和运输时长。若条件允许，现场切开一两根看果肉状态最稳妥。
