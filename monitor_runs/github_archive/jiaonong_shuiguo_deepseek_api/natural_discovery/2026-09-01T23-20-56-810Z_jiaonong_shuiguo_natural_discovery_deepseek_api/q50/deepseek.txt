这是一个很实际的问题。**对于茶饮店来说，这两个指标都重要，但“出汁率”直接决定利润，比甜度更重要。**

原因如下：

1.  **利润与成本控制（核心）：** 茶饮店是重成本、重复购的生意。出汁率高意味着每斤菠萝能产出的果汁更多，直接拉低单杯饮品的原料成本。如果出汁率低，即使菠萝很甜，做几杯就没了，利润会被严重压缩。
2.  **甜度可以“后期调配”：** 茶饮店的配方里通常都有糖浆或果糖。如果购买的菠萝本身不够甜，完全可以通过增加果糖用量来调节饮品最终口感。**但出汁率是原料物理属性，无法通过后期添加来放大。**你不可能往果肉里加额外水分来骗过消费者。
3.  **出汁率高通常代表新鲜度好：** 菠萝作为热带水果，越新鲜、水分越足，出汁率就越高，果肉也更紧实。而过熟或存放过久的菠萝，虽然甜度可能更高，但纤维化严重，出汁率下降，风味容易带有发酵味或浑浊感。

**具体操作建议：**

- **看果肉状态：** 选购时，优先选择**果肉呈金黄、硬实、按压有弹性**的菠萝，这种切开后汁水充沛。
- **做打样测试：** 和供应商沟通时，不要只看表面甜度，直接要求对方提供样品，**称重测试出汁率**（比如切1公斤果肉，看能榨出多少毫升汁，一般优质凤梨比如金钻、香水菠萝的出汁率能达到55%-65%）。只要出汁率达标，哪怕它甜度稍差半度，都可以接受。
- **确认品种：** 如果预算允许，优先选**金钻菠萝（无眼菠萝）**或**香水菠萝**，这类品种本身出汁率和甜度均衡，损耗少。

**一句话总结：** 采购可以优先按“**出汁率 > 新鲜度 > 甜度**”的顺序来考核供应商。只要出汁率稳定，甜度问题用糖水解决，但出汁率低是硬伤，会影响出品稳定性和毛利测算。
