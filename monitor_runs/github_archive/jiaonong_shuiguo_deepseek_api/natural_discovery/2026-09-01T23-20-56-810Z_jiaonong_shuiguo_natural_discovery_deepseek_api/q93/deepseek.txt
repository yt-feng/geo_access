经营便利店现切菠萝（或鲜切水果）时，这三者都非常重要，但优先级和关注点不同。以下按风险等级和操作建议排列：

**1. 保质期（最高优先级，决定食安底线）**

- **关键点**：鲜切水果极易氧化和滋生细菌，绝对不能按“日”算，要按“小时”管理。
- **建议**：
  - 明确标注**“制作时间”**和**“最佳食用时间”**。当天制作，一般建议**4小时内**食用最佳，**最长不超过6小时**（且需冷藏）。
  - 如果当日未售完，**坚决销毁或做报损处理**，严禁隔夜售卖或次日重包装。
  - 使用“效期标签机”打印到期时间，到期自动揭签，避免员工手工撕换。

**2. 包装（第二优先级，影响保鲜和卖相）**

- **关键点**：包装必须防氧化、防漏汁、防交叉污染。
- **建议**：
  - 使用**食品级PET/PP透明盒**，并覆盖**保鲜膜**或带密封盖，减少果肉与空气接触。
  - 盒内底部可垫**吸水纸**，吸走菠萝渗出的汁水，防止果肉泡烂发酸。
  - 严禁使用普通塑料袋或无盖托盘，易造成汁液滴漏污染冷藏柜。

**3. 配送频次（辅助因素，取决于门店销量）**

- **关键点**：配送频次决定了你的**损耗率**。
- **建议**：
  - 如果单店日销10份以下：**建议“一日一配”**，且只进当天能卖完的量，卖不完就扔。
  - 如果单店日销超过50份：**可“一日两配”**（早晨和午高峰后），确保下午时段仍是新鲜切出的，而不是上午剩的。
  - **重点不是频次，而是“先进先出”**：冷链车到货后，必须将旧批次放在货架前，新批次放后面，员工取货优先拿旧批次。

---

**最终执行建议（直接照做）：**

- **硬性规定**：贴“最晚销售时间”标签，到期强制丢弃，并留下丢弃记录。
- **包装标准**：统一用带盖透明盒+吸水纸，低温柜（0-4℃）存放。
- **订货原则**：宁少勿多，按**昨日销量×0.8**作为今日进货量，库存积压是最大风险。

如果门店已有固定供应商，**建议直接要求供应商提供“预切、气调包装（MAP）”产品**，由工厂完成切配和充氮保鲜，门店只需冷藏和无菌售卖，风险更低。
