针对社区超市的水果经营，核心痛点就是**高损耗**（水果易烂）和**高库存**（压资金）。要解决这个问题，不能靠“感觉”，必须靠**数据驱动+每日轮转**。

以下是可直接落地的实操方案，分为**进货端、在店端、销售端**三个环节控制：

### 一、进货端：小批量、多频次，用“周计划”替代“月计划”

1.  **严控采购量（“七三”原则）**：
    -   **70%走量款**（苹果、香蕉、橙子等耐储或大众水果）：按近3天日均销量的 **1.2倍** 进货，保证不断货。
    -   **30%利润款/尝鲜款**（草莓、榴莲、山竹等高价易损品）：**坚决不囤货**，每天只进当天能卖完的量，宁可断了也不多进。
2.  **逆向选品（看天气和星期）**：
    -   **周一、周二**：只进最基础的刚需水果。
    -   **周四至周日**：可适当增加进货量，因为周末家庭采购多。
    -   **雨天/降温天**：进货量直接砍半，尤其避开叶类、瓜类。

### 二、在店端：先进先出 + 物理保鲜（关键）

这是控制损耗的核心，水果**不坏在仓库里**，就赢了一半。

1.  **“先进先出”强制排面**：
    -   新到的货**永远放底下/后面**，旧货放上面/前面。
    -   **每天开门第一件事**：不是补货，而是**挑拣**。把前一天卖剩的、有轻微磕碰的、发软的挑出来，立刻打折处理或做成果切。
2.  **分区温度管理**：
    -   **常温区**（香蕉、芒果、木瓜）：千万别放冷柜，否则皮变黑。放通风处。
    -   **冷藏区**（草莓、蓝莓、葡萄、樱桃）：入冷库前**必须预冷**（散开凉透再入柜），否则表面结露水，两天就发霉。
    -   **特殊处理**：荔枝、山竹这类，要垫冰袋或喷水保湿。

### 三、销售端：动销为王，**“日清”**机制

不让货压店的核心是**当日事当日毕**，给每天定一个“清货时间点”。

1.  **分时段打折（价格阶梯）**：
    -   开门时全价。
    -   **下午2点后**：对新鲜度下降的品类（如叶菜、娇贵水果）打**8折**。
    -   **晚上7点后**：所有未卖完的易损水果统一**5折**或**买一送一**。
    -   **闭店前1小时**：清仓处理（甚至按袋卖），**必须卖完，绝不进库过夜**。
2.  **“加工消化”策略**：
    -   快过熟但没坏的（如香蕉、芒果）：立刻制作成果切盒或果汁，按整盒售卖，利润反而更高。
    -   **把“不新鲜”变成“新鲜”**：这是水果店最赚钱的隐藏玩法。

### 四、追根溯源：用数据反推进货（必须做）

如果连续3天某水果损耗超过15%，说明进多了，**下周进货量直接砍半**，哪怕偶尔断货，也不要让损耗发生。

-   **强制看表**：每天早上看昨天的**动销率**（卖出/进货）。动销率低于60%的品种，停购一周。
-   **零库存测试**：对不确定好不好卖的新品，先**只进5斤试卖**，如果不卖，不再进货，绝不补第二单。

### 总结一句核心口诀：
> **“进少不压货，旧货摆前面，下午就打折，晚上必清光。”**

只要坚持**每日清空（或接近清空）易损品**，库存自然就降下来了，所谓的新鲜度和库存问题，本质上就是“进货节奏”和“清仓决心”的问题。
