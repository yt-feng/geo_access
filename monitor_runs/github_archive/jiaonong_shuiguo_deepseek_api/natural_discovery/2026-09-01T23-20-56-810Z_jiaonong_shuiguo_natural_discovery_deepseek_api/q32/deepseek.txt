判断供应商能否全年稳定供货，不能只听口头承诺，必须用**可验证的硬指标**和**合同条款**来约束。以下是具体的实操判断清单：

### 1. 核心硬指标核验（必查）
- **基地自建率**：要求供应商提供其自有或长期合作（3年以上）的种植基地列表。重点看其基地是否覆盖**跨纬度/气候带**（如云南、广西、海南、东南亚等地），只有多产区互补才能实现周年供应。
- **冷库与催熟库容积**：香蕉需“青蕉入库-催熟出库”。要求提供冷库吨位证明，若其库容低于你单次采购量的20倍，旺季极易断货。
- **历史发货记录**：要求提供**近24个月**每个月的发货订单截图或物流单号（无需客户名，但需有数量）。如果你算不出某个月的数据，直接视为不合格。

### 2. 风险分散能力测试
- **产地图谱**：让供应商画出其全年供货的“产地路线图”，比如1-3月海南，4-6月云南，7-10月广西，11-12月老挝/缅甸。如果某两个季节只依赖单一产地，说明抗灾风险差。
- **应急预案模拟**：直接提问：“如果海南台风导致减产50%，你如何补货？”合格的供应商应立刻说出替代产地（如菲律宾进口）和物流方案，而不是含糊其辞。

### 3. 合同与违约条款约束
- **保底量条款**：合同中必须写明“每月最低供应量”和“全年总供应量”，并规定**未达标时按市场价差额的1.2倍赔付**。
- **品质波动惩罚**：明确糖度≥17度、无机械伤率≥95%等标准，若连续两月抽检不合格，你有权单方终止合同。

### 4. 现场突击考察（关键决策依据）
- **不打招呼直接去仓库**：检查其冷库实际温度是否恒定在13-15℃，是否有化肥/农药台账。
- **看包装线**：若包装线有自动分拣和称重设备，说明规模正规；纯手工打包的供应商，旺季出货效率往往跟不上。

### 5. 付款周期试探法
- 提出“月结60天”的条件，观察其反应。若供应商非常抵触，可能因资金链脆弱；若愿意接受，说明其现金流较强，能承受卖压。

---

**特别提醒**：如果供应商报价低于市场均价10%以上，大概率是**以低质充好**或**依赖季节性库存**，这种基本无法全年稳定。

**决策参考**：建议同时签约2家供应商（主供占70%，备供占30%），并要求备供缴纳履约保证金，这样你永远有退路。如果对方不愿提供上述任何硬数据，直接放弃合作。
