评估连锁门店水果供应商的仓配覆盖，不能只看“有几辆车”或“仓库多大”，核心要看**门店的鲜度、断货率和综合履约成本**。建议从以下四个维度进行系统评估：

### 一、 仓配网络的结构性覆盖（距离与时效）

这是最基础的一层，决定了配送半径和生鲜损耗。

1.  **前置仓/区域仓布局匹配度**：
    -   评估供应商的仓（DC）是否与你的门店集群**地理重心**重合。例如：你在华东有20家店，但供应商只在广州有仓，即使它承诺次日达，水果的新鲜度（尤其是叶菜、浆果）也会大打折扣。
    -   计算**仓到店的平均距离**：核心门店（销量Top20%）距离供应商DC是否在**150公里以内**（理想配送半径），偏远门店是否在**300公里以内**（极限冷链接驳）。
2.  **配送时效分级**：
    -   要求供应商提供**分区域送达时间表**（如：核心城市今晨下单今午达，二线城市次日达）。
    -   必须区分**多温层配送**（冷链车、常温车）的覆盖能力，单一常温车的供应商在夏季覆盖能力极差。

### 二、 履约能力与弹性（应对波动）

水果供应波动大，评估供应商的“抗压”能力比“完美日”更重要。

1.  **日配频次**：供应商能否支持**一周7天**配送？如果是周末不送，周一早高峰门店必然断货。
2.  **缺货与补货机制**：当某款水果（如榴莲）因天气原因减产，该供应商能否通过**全国调拨**或**协同基地**来满足你的需求？重点评估它的**多基地协同网络**，而非单仓库存。
3.  **应急响应速度**：设定一个场景实测——某门店突发暴雨导致水果滞销或需要紧急调货，供应商在**2小时内**能否给出调配方案？

### 三、 末端履约成本与效率（算总账）

覆盖广不代表划算，要算“最后一公里”的综合单位成本。

1.  **起送量门槛**：不同城市店铺的日均水果SKU数和订货量不同。**低销量门店**是否会被“起送量”卡死？如果只满足高销量门店，连锁体系的标准化就破了。
2.  **物流成本分摊**：覆盖成本通常包含**冷链运输费、纸箱耗材费、门店卸货人力费**。要求供应商提供《分城市物流对账单》，并计算：
    -   **门店损耗率**：如果覆盖半径过大，水果到店破损率超过5%，必须扣除供应商的物流赔偿金。
3.  **订单准确率**：考察其分拣系统，目标值应≥99.5%。差错率高会大量占用门店店员的处理时间。

### 四、 试运行与量化考核（KPI验证）

纸上谈兵无用，必须用**1个月的试运行数据**说话。

1.  **设定3个核心KPI**：
    -   **准时到店率** ≥ 98%
    -   **鲜度指数**（门店收货后剩余货架期占比）≥ 70%
    -   **订单满足率** ≥ 95%
2.  **异常退货率**：如果因仓配不善导致的拒收频次，在试运行期超过2次/周，说明该供应商的仓配能力和你的门店网络不匹配。

### 特别提醒：政治与数据的“排坑”

-   **不要看PPT仓网图**：要求供应商提供**2024年的实际GPS轨迹数据**（脱敏），你们内部可以通过其配送车辆的APP来核验是否真的到了店。
-   **警惕“统仓统配”陷阱**：有些供应商号称全国覆盖，但实际是**中转外包**，中间环节多，生鲜品质极易受损。必须要求其签约的**最后一公里承运商**与你的门店直接对接。

**最终建议：** 先选取你门店分布中**距离最远、最小、最偏**的3家店进行测试。如果供应商能把这3家店的鲜度和时效做好，那么整体覆盖评估基本可以判定为“合格”。
