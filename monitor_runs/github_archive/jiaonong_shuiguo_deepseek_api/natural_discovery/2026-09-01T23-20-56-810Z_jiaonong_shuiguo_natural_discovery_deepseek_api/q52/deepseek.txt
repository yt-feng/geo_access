甜品店采购香蕉时，想避免到店后很快变黑，核心是**控制乙烯气体**和**低温（但不过低）**，同时关注**采购源头**。

以下是针对甜品店场景的实操建议：

**1. 采购源头控制**

-   **不要买全黄**：采购时，香蕉表皮应**大部分呈青绿色或黄中带绿**，略带青色最佳。全黄的香蕉在运输到店的过程中就已经开始后熟，到店后赏味期极短。
-   **选硬度**：用手轻轻捏，选择**手感坚实、有弹性**的，不要选捏起来发软或表皮有黑斑的。
-   **看果柄**：果柄（把）要完整、干燥。果柄断裂处发黑或发霉的，会加速整串的衰老。

**2. 门店储存关键步骤（最重要）**

-   **挂起来，别平放**：香蕉怕压。到店后第一时间**拆袋、拆箱**，用挂钩把整串香蕉**悬挂**起来（模拟树上状态），或者用网兜兜着吊起来。这能极大减少受挤压和接触面积，减缓黑斑生成。**千万不要堆在纸箱里**，纸箱内的乙烯会快速催熟。
-   **避免冷藏（除非用专用冷库）**：**常温下不要放进普通冰箱**。普通冰箱（4℃）会破坏香蕉细胞壁，导致表皮迅速变黑（冻伤），而果肉可能还是硬的。如果必须降温，只能用**专用恒温冷库（13-15℃）**，且只能存放一天。
-   **绝对避开口袋**：不要用塑料袋或保鲜膜完全密封。如果需要包装，请**用透气网袋或纸袋**。

**3. 物理隔离**

-   **远离苹果、梨、哈密瓜、牛油果**：这些水果会散发大量乙烯，会加速香蕉变黑。甜品店果切台如果同时放多种水果，香蕉必须单独存放。

**4. 到店后的即时处理**

-   **包住果柄**：用**保鲜膜**将香蕉的**果柄（蒂把）**紧紧包裹住。这是乙烯的主要释放点，包住能显著延缓自身催熟。
-   **清洗表面（可选）**：如果香蕉表面有催熟剂残留，到店后可用清水**轻轻冲洗**表皮，然后**彻底擦干**（注意擦干，不要留水珠，否则易腐烂发霉）。这能去除部分催熟成分。

**5. 采购与配送建议**

-   **要求每日小批量配送**：宁可每天送一次，也不要一次囤一周的量。
-   **明确“青熟度”标准**：给供应商提出明确标准：“送货时表皮须带绿，不得有黑点或软斑”，并建立退货/换货机制。

**总结一句口诀：**
到货拆袋**挂起来**，果柄裹膜**放阴凉**，远离苹果**避乙烯**，采购带青**不买熟**。

这样操作，香蕉在甜品店的常温货架期通常可以从1-2天延长至3-5天。
