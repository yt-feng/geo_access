社区超市寻找**每天配送**的水果供应商，不能只盯着“便宜”，核心是看**履约稳定性**和**损耗控制**。以下是按重要程度排序的筛选条件：

**1. 硬性履约能力（最优先）**
- **配送时间窗口**：能否承诺每天在**早晨6:00-8:00**（或你指定的营业前高峰）到货？误差超过30分钟就算不合格。
- **缺货赔付机制**：合同是否写明“缺货按当日市价120%赔付”？这能筛掉大量小贩。
- **应急响应**：如果早上突发暴雨、水果在车上翻车，供应商能否在2小时内调货补送？要有实体仓库或备选基地。

**2. 损耗与新鲜度控制（决定毛利）**
- **冷链车比例**：问清楚是否全链条冷链（产地-分拣-配送），还是普通厢式货车。夏季叶菜类、草莓、蓝莓混装不冷链，到你店损耗会到15%-30%。
- **到货验收标准**：剔除多少算“烂果”？建议在合同约定：**磕碰伤超过3%、腐烂超过1%整箱拒收**，而不是按“个数”算。
- **退货政策**：当天卖不完的损耗，供应商是否允许按比例返款或补换货？（例如：批发市场代卖模式通常不退货，但稳定基地供可谈）。

**3. 品类与品质稳定性**
- **SKU数量**：确保能覆盖每天至少**20-30个**常规单品（苹果、香蕉、橘子、葡萄、梨、应季瓜类），不要只供单一品种。
- **产季切换能力**：问“冬天哪来西瓜？夏天哪来青枣？”——如果回答是“本地大棚/储备库”，说明有产地资源；如果只说“去市场拿货”，稳定性差。
- **A级果率**：现场开箱抽查，要求整箱果径差异不大（±2mm内），颜色均匀。

**4. 结算与价格透明**
- **日结还是月结**：日结价格通常高5%-8%，但能拿现金；月结可以压价，但需要对方有正规发票和资质。
- **价格随行就市机制**：要求每天报价单，并注明**当天产地收购价**（例如“烟台苹果收购价3.2元，我供3.8元”），防止中间商乱加价。
- **最低起送量**：很多供应商要求每日起送100斤，社区超市如果销量只够80斤，要么加配送费，要么改隔天送——要确认灵活性。

**5. 资质与对账**
- **证照**：营业执照、食品经营许可证必须有；如果做进口水果，还要看报关单及检疫证明。
- **对账周期**：确认每日送货单上有**编码、重量、单价、总价**，月底能拉出明细账单，防止糊涂账。

---

**一个实操建议**：
不要只签一家。**同时试供2家**，A家负责北区店，B家负责南区店，试跑30天，对比：
- 30天平均损耗率（好控制在5%以内）
- 平均缺货补货响应时长（好控制在4小时内）
- 实际到货时间误差（好控制在30分钟内）

然后留下表现好的那家，把另一家作为备选应急——这样既保证每天供货，又防止一家独大后涨价或降质。如果试供期表现都一般，果断换掉。

另外，可以要求供应商提供**最近一周的电子送货单**给你看，判断他们是否真的是天天在给其他超市发货，还是偶尔接零单的倒爷。
