在茶饮店旺季遇到菠萝用量突然变大，临时补货的关键在于**“提前沟通+锁量保价+快速响应”**。以下是一套可执行的沟通与合同约定方案：

**第一步：立即电话/微信口头锁定（当天）**
- 直接联系供应商负责人，说明当前爆单情况，明确告知“我需要从X月X日起，每天追加X公斤/箱菠萝，至少持续X天”。
- 明确问清楚：**“现在库存够不够？明天能否到货？如果不够，最快何时能补？”** 这是判断供应商紧急响应能力的关键。

**第二步：书面确认关键条款（当天下午或次日）**
需要约定以下核心内容，并留下记录（微信文字或邮件）：

1. **数量与到货时效**：固定每日追加数量（如每日追加20公斤），并约定“我司下午X点前下单，次日X点前必须送达”，如未及时送达，供应商需承担由此造成的营业额损失（可约定按缺货部分货款的1-2倍赔偿）。
2. **价格与波动条款**：旺季菠萝价格易波动。建议约定“本轮追加订单**单价锁定7天**，若市场价上涨超过X%，需提前24小时书面告知，经我确认后生效；若下跌，自动按低价结算。”
3. **品质与验收标准**：旺季量大，要防止供应商混入次级果。明确“到货需无黑心、无烂斑、成熟度8-9成（手捏微软），如出现损耗，按比例当场扣重或退换”。
4. **应急预案**：要求供应商提供“兜底方案”，如指定第二备选供应商，或由其协调周边冷库库存，确保在你缺货时能应急调拨。

**第三步：话术参考（可直接用）**
> “老板，最近菠萝卖爆了，我们每天要追加XX箱。明天必须到货，我先跟你口头锁一下量。咱们按长期合作来，这批价格能不能按老价格走？如果市场涨了，我们接受小幅上调，但需要你提前说一声。到货品质不能降，我会安排人严格验收。要是你这儿缺货，你得提前告诉我，我自己找备选，不然断货损失得你担。你先确认下能不能供，我下午发个微信订单给你。”

**第四步：风险提示（重要）**
- 优先找**长期合作或供货稳定**的供应商谈临时补货，临时找的散户和二级批发商在旺季容易坐地起价或断供。
- 如果菠萝是核心爆款，建议同步联系1-2家备选供应商（哪怕价格贵10%），以防供应商刁难。
- 补货合同无需太复杂，但**“到货时间+品质验收+价格锁定+违约补偿”**这四点必须白纸黑字写进聊天记录或补货协议，避免口说无凭。

如果供应商不接受锁价或赔偿条款，你可以退一步：“价格跟着行情走可以，但至少保证每天到货和品质，断供的话我找别家，你懂的。” 保持谈判弹性，确保货能到位是第一优先级。
