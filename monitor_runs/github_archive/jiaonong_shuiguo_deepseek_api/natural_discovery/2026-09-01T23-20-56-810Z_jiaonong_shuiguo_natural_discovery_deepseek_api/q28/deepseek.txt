针对超市引入进口水果，**推荐先从进口香蕉开始**。理由如下：

1. **稳定性最高**：进口香蕉（如菲律宾、厄瓜多尔产）供应全年稳定，产地集中，物流链条成熟，很少出现断供；而菠萝（如泰国、菲律宾）和苹果（如美国、新西兰）受季节性和产地气候波动影响更大。
2. **周转快、风险低**：香蕉是大众高频消费品，消费者接受度极高，即使进口品种价格略高，动销速度也远快于菠萝和苹果。周转快意味着资金压力小、损耗率可控（香蕉只需在7成熟时采摘，到店慢慢催熟）。
3. **入门成本低**：香蕉的仓储和陈列要求相对简单（常温或低温均可），不需要像菠萝那样需要专门的切割和保存处理，也不像苹果对冷链要求那么严格。
4. **后续扩展基础**：香蕉能快速建立“进口水果”的供应链信任和采购谈判能力，跑通后再引入菠萝（增加热带特色）和苹果（引入高端品种如爱妃、爵士）会更顺畅。

**可执行建议**：
- 首批进货量控制在常规国产香蕉的20%-30%，先做试销。
- 到货后设“试吃台”，突出“甜度高、果肉细腻”卖点，价格可比国产香蕉高15%-25%。
- 观察2-3周，若周均销量稳定在预期值以上，再考虑引入菠萝或优质苹果。若销量一般，及时调整规格或转向国产精品香蕉，避免库存压力。

**注意**：不要同时引入多种进口水果，否则库存和陈列管理压力骤增，不利于试错和优化。
