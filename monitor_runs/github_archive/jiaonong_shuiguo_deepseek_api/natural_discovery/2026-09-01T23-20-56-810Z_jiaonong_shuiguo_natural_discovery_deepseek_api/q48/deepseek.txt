判断茶饮连锁的菠萝供应商能否稳定按规格送货，核心在于**“标准可量化、过程可追溯、异常有预案”**。不要只听口头承诺，要设计几个可验证的动作。以下是实操性建议：

### 1. 合同与SOP的硬约束（前置门槛）
-   **规格书必须量化**：不能写“成熟度适中”，要写具体指标（如：单果重量900-1100g，去皮后芯径≤Xcm，果眼深度≤Xmm，糖度≥12°Brix，表皮无机械伤/黑斑面积≤1%）。把规格书作为合同附件。
-   **分级与溢价挂钩**：明确“按规格送货”的收货标准。提供**分级价格**（A级/B级），允许供应商在非旺季偶尔降级，但降级需提前报备并下调结算价，而不是临时换货。

### 2. 试运行期考核（用数据说话）
-   **设置1-2个月的试单期**：至少连续下单4-6批（每批不少于50箱），重点看**“准时率”**（约定时间前24小时到货）和**“达标率”**（每批抽检10箱，计算不合格箱数）。
-   **关键指标**：整体合格率≥95%，且**连续两批不合格或延误，则冻结订单**。这是淘汰不靠谱供应商的最快方式。

### 3. 供应链深度探访（看源头能力）
-   **问清产地和采收窗口**：询问其菠萝来自哪个产区（如徐闻、海南、菲律宾等），**是否自有基地或与基地有保底合同**。如果供应商说“随时能供货”，反而要警惕，因为菠萝有季节性，不可能全年稳定。
-   **看分拣设备**：实地或视频看其加工厂是否有**重量分级机、糖度计、冷链预冷设备**。有自动分级线的供应商，规格稳定性远高于人工手选。
-   **验证冷链能力**：对接单后，要求提供**装车温度记录仪**或随车温度单据，确保全程冷链8-10℃。若对方没有冷链车，基本可以排除。

### 4. 异常处理机制（应急预案测试）
-   **主动“测试”其危机反应**：在旺季或台风季前，故意告知“明天要加急加量”，看其响应速度。优质供应商会给出明确调货方案（从哪个市场调、预计延迟几小时），而劣质供应商只会说“没办法”。
-   **明确赔付条款**：合同写清“断货或规格不符，按货值200%赔付”或“免费补货”，且赔付金额从月结款中直接扣除，**不要等账期后催款**，因为催款耗时太长。

### 5. 动态数据库管理（长期跟踪）
-   为每个供应商建立**档案表**，记录每次到货的：批次号、到货时间、抽检合格率、客诉次数。
-   **设置月度红黄牌**：连续3个月合格率低于阈值，直接列入黑名单；同时，建议**保留备用供应商**（至少1家），避免单一来源风险。

### 核心提醒：
-   **不要买“包办”**：不要迷信“长期合作”口头承诺。菠萝是生鲜，稳定性取决于其**基地面积、冷库容量和物流车队**，这三个硬资产比任何关系都重要。
-   **最后防坑底线**：首次大批量采购时，**押金或预付款比例不要超过30%**，防止对方收了钱后因规格不达标而拖延扯皮。

**简记口诀**：规格写进合同，试单连续四批，检验看自动线，赔付写在账期前，备胎至少一个。
