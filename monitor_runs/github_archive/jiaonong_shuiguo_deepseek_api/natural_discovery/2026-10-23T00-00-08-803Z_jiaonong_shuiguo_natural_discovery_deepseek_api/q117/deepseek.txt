先试卖多少，没有统一数字，关键看**损耗速度、客单价、试卖周期、门店/渠道数量**。给你一个可执行的判断框架：

**1. 先定试卖周期**
水果新品建议试卖 **7～14 天**。叶菜/浆果类损耗快，7 天左右；耐储水果可 10～14 天。

**2. 用“单店单日预估销量 × 试卖天数 × 安全系数”算首批量**
- 安全系数建议 **1.2～1.5**，易损耗品取低值。
- 例：预计单店每天卖 20 斤，试卖 7 天，系数 1.2 → 首批约 **168 斤/店**。
- 没有历史数据时，先按同类水果销量的 **30%～50%** 预估新品销量。

**3. 分批次进货，比一次压货更稳**
首批只进预估量的 **60%～70%**，卖 2～3 天看动销和损耗，再补第二批。这样即使判断失误，损失也可控。

**4. 设止损线**
试卖期内出现以下情况就减量或停采：
- 日损耗率超过 **8%～10%**（浆果类可放宽到 12%）
- 第 3 天动销低于预估的 **50%**
- 顾客复购/询问明显少
- 售价打折后仍走不动

**5. 多门店试卖时分散风险**
选 **2～3 家代表性门店**，每家按上述单店量试卖，不要所有门店同时铺满。对比不同门店的动销后再决定是否全面上架。

**简单结论：**
首批按“单店 7～10 天预估销量的 60%～70%”进货，单店试卖量通常控制在 **几十斤到一两百斤**，卖 2～3 天补一次货；动销好再放量，损耗高就及时停。具体数字用你同类水果的历史日销来套，最稳。
