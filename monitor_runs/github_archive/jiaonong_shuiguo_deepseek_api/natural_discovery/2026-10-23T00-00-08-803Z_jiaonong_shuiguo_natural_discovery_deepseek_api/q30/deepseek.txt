# 超市水果到货品相不好的售后流程约定建议

核心思路：**把“什么情况算不合格、怎么报、谁判定、多久处理、怎么赔”写进合同或采购协议，避免到货后扯皮。** 具体可以按以下几条约定：

## 一、验收标准要量化（最关键）
- **等级与规格**：按品种写明等级（如一级果）、单果重量区间、果径、着色度、成熟度、允许的瑕疵比例（如碰伤、裂口、霉点、软烂各不超过X%）。
- **抽样规则**：约定抽检比例（如每批次随机抽3箱/5%），以抽样不合格率推算整批。
- **判定方式**：现场开箱验货，拍照/录像留证，双方签字确认；有条件可约定“到货2小时内完成初验”。

## 二、分级处理机制
按问题严重程度分档，对应不同处理，写清楚：

1. **轻微瑕疵（在约定容忍比例内）**：正常收货，可协商折价。
2. **部分不合格（超出容忍比例但可挑拣）**：挑拣后按实际合格数量结算，不合格部分退货或折价。
3. **整批严重不合格（如霉变、腐烂超阈值、明显以次充好）**：整批拒收或退货退款，运费/损耗由供货方承担。

## 三、报备与举证时限
- 到货后**X小时内**（生鲜建议2–4小时，易腐品更短）提出异议，逾期视为验收合格——这条对双方都重要，超市要守时限，供应商也要接受合理时限。
- 异议需附**照片/视频、抽样记录、过磅单**，约定举证材料清单，避免口头争议。

## 四、处理时限与方式
- 供应商应在收到异议后**24–48小时内**响应，给出补货、换货、折价或退款方案。
- 明确**补货/换货的到货时限**，以及期间超市的临时处置权（如先行降价处理，损失从货款扣）。
- 退款/折价的**结算方式**：从当批货款中直接扣减，或约定账期抵扣。

## 五、责任与费用划分
- 运输途中损耗、因包装不当导致的品相问题，责任方写清楚（一般由供货方承担到验收合格前）。
- 退货产生的运费、装卸费、销毁费用由责任方承担。
- 约定**违约金或质量保证金**：如按批次货款的X%扣罚，或预留5%–10%质保金，验收合格后返还。

## 六、争议解决
- 约定第三方检测或双方共同复检机制（如对判定有争议，送约定机构检测，费用由责任方承担）。
- 明确适用法律和管辖地。

## 落地建议
把以上内容做成**一页纸的《到货验收与售后细则》作为采购合同附件**，每次下单随附批次质量标准，验收单双方签字。这样到货出问题时，直接对照条款执行，不用临时谈判。

如果你能说明是**超市向供应商采购**还是**消费者向超市购买**，以及水果品类（叶菜类/浆果类/柑橘类耐储性差异大），我可以帮你把时限和瑕疵比例写得更具体。
