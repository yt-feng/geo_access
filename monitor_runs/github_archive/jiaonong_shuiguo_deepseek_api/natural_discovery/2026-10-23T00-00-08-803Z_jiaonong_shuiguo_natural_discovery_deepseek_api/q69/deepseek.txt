# 香蕉、菠萝分级报价的做法

**核心思路：先定“分级标准”，再定“等级差价”，最后把报价单做成能直接对照的表格。** 让小店老板一眼看出“多花钱买的是哪一档”，减少扯皮。

## 一、分级维度（供货环节最实用）

**香蕉**（按“成熟度+果指外观+梳形”分）

| 等级 | 外观标准 | 适用场景 |
|---|---|---|
| A级（精品） | 果指饱满、长度均匀（如18–22cm）、无机械伤/黑斑、梳形整齐、青转黄均匀 | 水果店陈列、零售主推 |
| B级（统货） | 轻微擦伤或个别短指、成熟度略不齐 | 社区小店、走量 |
| C级（处理） | 明显碰伤、过熟或偏小，适合即卖/加工 | 特价、榨汁、熟食店 |

成熟度单独标注（如“7成熟”“黄熟”），因为它直接决定货架期，比单纯大小更影响小店进货决策。

**菠萝**（按“果重+外观+成熟度”分）

| 等级 | 外观标准 | 适用场景 |
|---|---|---|
| A级 | 单果重达标（如1.2–1.5kg）、果形端正、无裂口/日灼、冠芽完整 | 零售陈列、礼盒 |
| B级 | 果重略小或轻微外观瑕疵、成熟度适中 | 日常走量 |
| C级 | 小果、畸形、裂口，适合即削即卖 | 特价、加工 |

## 二、报价方式（建议两种并行）

1. **按件/箱报价**：最通用，标注“每箱净重、果数、等级、单价”，例如“A级香蕉 13kg/箱 约XX梳 单价XX元/箱”。小店按箱算账最省事。
2. **按斤报价**：适合小店灵活拿货，但要注明“毛重/净重”和“是否含箱”，避免称重争议。

**等级差价怎么定**：以B级统货价为基准，A级通常上浮10%–25%，C级下浮20%–40%，具体按当地行情和损耗率调。关键是把“差价对应什么品质”写清楚，而不是只给三个价。

## 三、报价单落地要点

- **一表一品种**：列“等级 / 规格（重量·果数·成熟度）/ 单价 / 起订量 / 损耗说明”。
- **写明验收口径**：如“允许5%以内的轻微瑕疵”“黑斑超过X处降级”，这是减少纠纷的关键。
- **标清价格有效期**（如“本周有效”），生鲜价格波动大，避免小店拿旧价压你。
- **配实物图或样品**：第一次合作给每级拍标准样图，比文字描述管用。

## 四、一句话总结

**分级看“外观+规格+成熟度”三个维度，报价用“按箱为主、按斤为辅”，A/B/C三级差价拉开，并把验收标准和有效期写进报价单**——清楚的关键不在价格表本身，而在“等级标准可对照、验收口径可执行”。
