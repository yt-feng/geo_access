结论：**优先按箱结算，其次按斤结算，尽量不用按份结算。** 前提是水果以整箱入库、食堂自己分拣上桌；如果确实需要按份直接发给就餐者，再把“份”作为内部发放单位，而不是采购结算单位。

**三种方式的管理特点：**

| 结算方式 | 优点 | 管理难点 | 适用场景 |
|---|---|---|---|
| 按箱 | 验收快、单据简单、单价稳定、易对账；整箱有固定规格，盘点方便 | 箱内可能有坏果、大小不均；需要定箱规、抽检标准；拆箱后库存要另记 | 大宗常规水果，如苹果、橙子、香蕉、西瓜 |
| 按斤 | 最公平，按实际可用量付费；损耗和短缺容易反映 | 称重耗时，水分损耗、去皮去筐争议多；每天价格波动，对账繁琐 | 价格高、规格差异大、需要精确控制成本的水果 |
| 按份 | 发放方便，适合直接售卖或配餐 | 份量标准难统一，采购价与份量脱钩，容易虚增份数；验收和库存都不好核 | 只适合内部配餐发放，不适合作为采购结算主方式 |

**建议做法：**
1. **采购合同按箱定价**，明确每箱净重范围、品种等级、坏果率上限（例如不超过3%—5%）、缺重扣款规则。
2. **验收按箱点数 + 抽检称重**：每批抽几箱称净重、查坏果，异常整批扣款或退货。
3. **入库后按斤或按份做内部领用账**：仓库记净重，窗口按份发放，两套单位分开，避免采购和发放混在一起。
4. **高频小批量水果**（如草莓、葡萄）可改按斤结算，因为箱规不统一、损耗大，按箱容易扯皮。

一句话：**对外采购按箱最省管理成本，内部发放按份最方便，称重只作为验收抽检手段。**
