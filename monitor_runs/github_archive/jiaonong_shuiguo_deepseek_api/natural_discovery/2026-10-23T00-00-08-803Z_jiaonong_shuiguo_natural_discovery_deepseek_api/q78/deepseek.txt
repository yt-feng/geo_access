香蕉和菠萝的售后控制，核心不是“出了问题再赔”，而是把损耗前移到选品、到货验收、提货节奏和售后规则四个环节。下面按可执行的顺序说。

**1. 选品和到货标准先定死**
- 香蕉：团购尽量选“青转黄”七成熟发货，别选全黄到货。到货验收看：果指饱满、无大面积黑斑、无裂口、果柄不发黑发霉。全黄或已有明显黑斑的批次不进团。
- 菠萝：选成熟度中等、叶片新鲜、果皮无软塌、无渗液、无酒味。到货切开抽检2-3个，看黑心、水心病、烂心比例；抽检不合格整批退，别靠售后兜。
- 和供应商约定“到货坏果率上限”和“超出部分按比例补货或扣款”，把赔付责任往上游压。

**2. 到货验收和分拣做记录**
- 每批到货拍照/录像：整批外观、抽检切开图、称重记录、坏果数量。
- 分拣时把明显损伤、过熟、裂口的挑出来，不进提货点，直接走“内部处理/员工消化/折价群”，不混进正常订单。
- 香蕉按串分装，避免挤压；菠萝单果套网套，竖放不叠压。分装环节的二次损伤往往比运输还多。

**3. 提货节奏控制**
- 香蕉到货当天通知提货，别拖到第二天；提货点避免阳光直射和闷热，香蕉别放冷藏。
- 菠萝到货后24小时内提完，提货点保持通风，不堆叠。
- 设置“当日未提提醒”，超时未提的主动电话/私信，减少因存放导致的售后扯皮。提货点可以贴简单提示：香蕉常温悬挂、菠萝通风竖放、切开尽快吃。

**4. 售后规则前置公示**
- 开团页面写清楚：坏果包赔的判定标准（如香蕉黑斑面积超过多少、菠萝黑心/烂心可退）、赔付方式（退款/补发/下批抵扣）、申请时限（提货后24小时内、带图）。
- 设定“小额快赔”机制：单果问题直接退该果金额或补券，不要求退回实物，降低沟通成本；批量问题才走整批核查。
- 明确不赔情形：个人存放不当（香蕉冷藏变黑、菠萝切开隔夜变质）、超时未提、已切开后非品质问题。规则越具体，争议越少。

**5. 用数据复盘**
每团记录：到货总量、分拣剔除量、售后申请量、赔付金额、主要问题类型（黑斑/裂口/黑心/过熟）。连续两团某供应商坏果率超标就换供应商或改规格。香蕉和菠萝的损耗率如果长期高于行业常见水平，优先查到货成熟度和提货时效，而不是加售后预算。

一句话：**把“全黄香蕉、软塌菠萝”挡在团外，把提货时间压短，把赔付标准写在前头，售后量自然下来。**
