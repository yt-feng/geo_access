优先做“整果为主、切果为辅”的组合，不要二选一。判断顺序如下：

1. **先看客群和动线**
   - 社区店、家庭采购为主：整果更适合，客单低、损耗小、顾客可自行判断成熟度。
   - 商圈店、写字楼店、年轻客群、即食需求强：切果更适合做增量，但必须冷藏陈列、当日清货。
   - 靠近学校、医院、交通枢纽：切果更容易动销。

2. **看损耗承受能力**
   - 整果损耗主要来自磕碰、过熟和滞销，可控性较强。
   - 切果损耗来自去皮去眼、氧化、出水、保质期短，操作和冷链要求高。
   - 如果门店没有冷藏陈列、没有稳定客流、没有专人频繁打理，切果不要做主力。

3. **看毛利结构**
   - 整果毛利通常较低，但损耗低、周转稳，适合做引流和家庭装。
   - 切果有加工溢价，但扣除损耗、人工、包装后未必更高。建议先小批量试销，按“日切日清”核算真实毛利。

4. **看菠萝本身特性**
   - 菠萝成熟度不一致，整果让顾客自己挑，售后压力小。
   - 切果能解决“不会削、嫌麻烦”的问题，但成熟度把控不好容易酸、出水、变色。
   - 建议整果按成熟度分级陈列，切果只选成熟度合适的果，不要用滞销果加工。

5. **可执行的门店策略**
   - 主力陈列整果，设“帮忙削皮/代切”服务，兼顾即食需求。
   - 切果做小份试销，放在冷藏区，明确标注切制时间，当日未售完及时折价或停做。
   - 先试 1～2 周：记录整果销量、切果销量、切果报损率、顾客询问次数。
   - 判断标准：切果连续一周报损率明显偏高或动销慢，就退回“整果+代切”；切果复购稳定、下午断货，再逐步增加切果比例。

**结论：大多数商超门店更适合“整果主销+代切服务+小份切果试销”。** 切果不是不能做，而是更适合客流快、冷链稳、能日清的门店；没有这些条件，整果更稳。
