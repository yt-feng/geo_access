做水果生意想长期稳定，选择供应商时最容易忽视的往往是和“稳定性、损耗、账期”相关的细节，而不是价格和品种。常见盲点有以下几类：

1. **只看大货样，不看连续到货质量**  
   样品好不等于每批都稳。要连续看 3～5 批货的到货表现：大小是否均匀、成熟度是否一致、次果率多少、冷链是否有断点。长期生意最怕“这批好、下批差”。

2. **不核实产地和季节替代能力**  
   问清楚是自有基地、合作社还是贩子转手；同一品种在不同产区、不同月份品质差异很大。要确认供应商在淡季或主产区受灾时有没有替代货源，否则你会被迫断货或高价补货。

3. **忽视损耗责任和验收标准**  
   合同里最容易漏的是：到货后多久内可验收、烂果/压伤/冻伤怎么算、超出约定次果率谁承担、退货还是折价。没有明确标准，长期合作中损耗会反复扯皮。

4. **不看过往供货对象和履约记录**  
   问同行、看其长期客户类型，比听供应商自夸可靠。重点看是否经常延迟发货、临时涨价、以次充好。长期稳定供应商的价值在履约，不在报价最低。

5. **忽视账期和资金占用**  
   水果周转快，账期差几天就可能压垮现金流。要明确结算方式、账期、是否押款、涨价通知提前量。低价但要求现款或频繁变价的供应商，长期未必划算。

6. **不确认冷链和运输细节**  
   问清楚装车温度、运输时长、是否混装、到货时间窗口。很多损耗不是货不好，而是运输环节失控。长期合作要把冷链责任写进约定。

7. **没有备选供应商**  
   只依赖一家最危险。至少保持“一主一备”，主供应商占七成左右，备选随时能补位。这样在涨价、断货、质量波动时有谈判空间。

8. **忽视售后响应速度**  
   出问题时能不能当天处理、补货或折价，比平时客气更重要。可以先用小批量试合作，观察其处理售后问题的态度和速度。

建议做法：先小批量试 3～5 批，记录次果率、到货准时率、损耗责任处理速度；再谈长期账期和价格机制。选供应商的核心不是“最便宜”，而是“质量波动小、履约稳、出了问题能兜底”。
