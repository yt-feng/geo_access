通常先看“损耗口径”：如果只算门店端损耗，直接买成品果丁往往更低；如果算全链条损耗（含供应商端、运输、退货、品质不达标），鲜果切配不一定更差，但门店操作要求更高。

**可判断的建议：**

1. **小门店、销量不稳定、人工紧张**：优先买成品果丁。门店损耗低，省切配人工，品质稳定；劣势是单价高、保质期短、开袋后必须尽快用完。
2. **中大型甜品店、菠萝用量大且稳定、有标准切配流程**：鲜果切配通常更可控，综合成本可能更低。前提是：到货验收严格、成熟度分级、冷藏管理、边角料能用于熬酱/装饰/员工餐。
3. **损耗关键不在“买哪种”，而在“周转”**：成品果丁主要损耗来自开袋后氧化、出水、过期；鲜果主要损耗来自成熟度不均、削皮去眼、切配不合格和存放过久。
4. **简单测算**：
   - 成品果丁有效成本 = 采购单价 ÷ 可用率 + 开袋报废成本；
   - 鲜果有效成本 = 鲜果单价 ÷ 出成率 + 切配人工 + 未售报废成本。
   分别连续记录1—2周的实际报废重量，再比较，不要只凭经验。

**结论**：若销量小、波动大、人手少，直接买成品果丁的门店端损耗更低；若用量大、周转快、管理规范，鲜果切配更可能降低综合成本。先用两周实际数据算“有效成本”，再定采购方式。
