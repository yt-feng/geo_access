第一次试单，核心不是“找到最便宜的”，而是用最小成本验证三件事：**货稳不稳、损耗大不大、结账和售后靠不靠谱**。常见货建议这样试。

## 一、试单前先定好验收标准

对夫妻店来说，香蕉、苹果、橙子是最适合试单的三类，因为它们分别代表三种风险：

- **香蕉**：催熟和运输损耗风险最高，考验供货商是否懂熟度、会不会按你卖货节奏配货。
- **苹果**：相对耐放，主要看等级、大小、碰伤和口感稳定性。
- **橙子**：看皮厚、酸度、水分、大小均匀度，也考验产地和季节判断。

试单前自己先定几条硬标准，比如：

- 香蕉到货熟度：不要太青也不要太黄，最好是可以2～3天内逐步卖完的熟度。
- 苹果：大小基本均匀、无明显碰伤、口感不能太面或太酸。
- 橙子：果面干净、无明显干疤、切开水分足、酸甜能接受。

标准越具体，后面越好判断是否继续合作。

## 二、第一次试单怎么下

建议**小批量、多品种、少频次**试。

- 每个单品先拿**1～2箱**，不要一上来压货。
- 品种选店里最好卖的常规规格，不要试稀奇品种。
- 第一次可以要求供货商**送货上门**，看他准时不准时、装卸是否规范。
- 如果对方有批发市场档口，也可以自己去拿一次货，现场看货、看库存周转、看其他客户拿什么规格。

试单时重点问清楚：

1. 能不能固定送货时间？
2. 坏果、烂果、熟过头的怎么处理？是补货、换货还是扣款？
3. 结账方式：现结、周结还是月结？第一次通常现结可以接受。
4. 价格是否含运费？有没有起送量？
5. 香蕉熟度能不能按你的销售速度调整？

## 三、到货后怎么验

**香蕉：**
- 看整体颜色是否均匀，有没有大面积青硬或已经发黑。
- 摸果指是否饱满，果柄有没有霉。
- 不要只看表面，翻箱看底层有没有压伤、闷熟。

**苹果：**
- 随机拿几个看大小是否一致。
- 看有没有碰伤、虫眼、裂口。
- 切开尝口感，脆度、甜酸是否稳定。

**橙子：**
- 看果面、大小、皮厚。
- 随机切一个看水分和籽多少。
- 尝酸甜度，判断顾客复购接受度。

验货时**拍照留证**，尤其是坏果、压伤、熟度不均，方便后面谈售后。

## 四、试单后怎么判断要不要继续

建议连续试**2～3次**，不要一次就定长期合作。观察这几个指标：

- **到货准时率**：说好几点到，是否稳定。
- **损耗率**：比如一箱香蕉坏了几根、苹果碰伤几个，自己算一下真实成本。
- **售后响应**：有问题时对方是痛快补换，还是推诿。
- **价格稳定性**：第二次、第三次是否随意涨价。
- **是否适合你的销量**：给你配的熟度、数量是不是正好卖得动。

如果第一次货不错但第二次开始掺次货，也要警惕。

## 五、夫妻店最实用的试单策略

可以同时找**2家**供货商小量试，不要只押一家：

- A家：批发市场档口，自己去拿，看货直观。
- B家：送货上门，省时间，看服务稳定性。

试单期控制在**1～2周**，用真实销售和损耗数据比较。最后选那家**货稳、损耗低、售后痛快、结账清楚**的，而不是单纯报价最低的。

一句话：**第一次试单，少量拿、当面验、拍照留、连续试三次再定长期。**
