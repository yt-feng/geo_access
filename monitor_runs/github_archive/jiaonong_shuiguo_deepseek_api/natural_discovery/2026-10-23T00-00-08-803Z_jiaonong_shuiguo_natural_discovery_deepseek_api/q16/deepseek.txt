建议优先选**稳定供应商为主、本地批发为辅**，不要二选一。

判断标准可以按这4点执行：

1. **香蕉：优先稳定供应商**
   - 香蕉易催熟、怕温差、损耗高，需要稳定成熟度和补货频率。
   - 如果本地批发市场每天能稳定供同规格香蕉，可以作为补充，但要有备用供应商。
   - 关键看：到店成熟度、断货率、坏果率、是否支持少量多次补货。

2. **苹果：可本地批发为主**
   - 苹果相对耐储，适合按品种、规格、口感做本地批发比价。
   - 但要固定2家左右货源，避免单一市场涨价或断货。
   - 关键看：分级是否稳定、糖脆度、表观瑕疵、同规格价格波动。

3. **用“试销两周”做决策**
   - 各选1个本地批发和1个稳定供应商，分别记录：
     - 进货价与到店成本
     - 损耗率
     - 缺货次数
     - 顾客复购/投诉
     - 最小起订量和配送频率
   - 两周后按“综合到店成本+损耗+稳定性”定主供，不只看报价。

4. **最终组合建议**
   - 香蕉：稳定供应商主供，本地批发应急补货。
   - 苹果：本地批发主供，稳定供应商做价格和断货备份。
   - 两家都要求可退换坏果、固定规格、明确账期或现结规则。

对社区超市来说，**稳定供货比单次低价更重要**，因为水果毛利很容易被损耗和断货吃掉。
