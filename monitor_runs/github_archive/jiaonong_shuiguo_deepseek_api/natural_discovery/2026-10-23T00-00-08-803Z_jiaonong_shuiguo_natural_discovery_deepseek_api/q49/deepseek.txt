旺季菠萝用量突然变大，和供应商约定临时补货，关键是**提前把“临时”变成有规则的机制**，而不是每次临时求人。建议按下面几步做：

1. **先估缺口，再谈补货**
   - 用近7天实际用量推算旺季日均用量，结合未来7天销量预估，算出缺口。
   - 把缺口拆成“常规订单增量 + 应急补货量”，不要一开口就说“越多越好”。
   - 明确规格：品种、单果重量区间、成熟度、去皮/切块要求、包装方式。

2. **和供应商签一份“旺季临时补货补充协议”**
   重点约定：
   - **补货触发条件**：比如日库存低于X公斤或销量超预估20%时启动。
   - **提前通知时限**：普通补货提前24小时，紧急补货提前6—12小时。
   - **响应时限**：供应商确认订单后多少小时内送达。
   - **价格机制**：临时补货是否加价、加价上限、是否随行就市但需提前报价确认。
   - **最低起订量**：避免小单被拒或运费过高。
   - **品质与验收**：坏果率、成熟度不达标怎么退换。
   - **违约与替代方案**：供应商无法供货时，提前多久告知，是否协助调货。

3. **设置“阶梯补货”而不是单次大单**
   - 常规日订单上浮10%—20%作为安全库存。
   - 设一个“应急补货池”，比如供应商为你预留每日X公斤优先供货量。
   - 旺季前支付少量定金锁定优先供货权，比临时加价更稳。

4. **用微信/邮件留痕，别只口头约定**
   每次补货发标准格式：
   “需X月X日送达：品种X，规格X，数量X公斤，单价X，验收标准X，请回复确认。”
   供应商回复确认即形成订单记录。

5. **准备备选供应商**
   主供应商保日常和优先补货，备选供应商保极端缺口。旺季前让备选供应商送一次小样，确认品质和配送能力。

6. **付款和账期提前谈清**
   临时补货是否现结、是否影响月结账期，提前写进协议，避免旺季被断供。

一句话：**用“预估缺口+补充协议+阶梯订单+备选供应商”四件事，把临时补货变成可执行的供应规则。**
