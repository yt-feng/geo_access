# 香蕉采购的熟度和到货要求

## 一、熟度：按卖完的时间倒推采购

香蕉熟度看表皮和手感，水果店常用“几成熟”描述：

| 熟度 | 外观/手感 | 适合的销售节奏 |
|---|---|---|
| 7成熟 | 全绿、硬 | 可放3–5天，适合提前囤货、慢慢转黄卖 |
| 8成熟 | 绿中带黄、稍硬 | 约2–3天到最佳食用期，日常主力 |
| 9成熟 | 黄带少量绿尖、微软 | 1–2天内要卖完，适合旺销日 |
| 10成熟 | 全黄有黑点、很软 | 当天必须清完，否则次日易烂 |

**采购要求建议：**
- 主力货选 **8成熟**（黄中带绿、捏着偏硬），到店后1–2天进入最好卖的状态；
- 只少量进 **9成熟**，留给当天和次日的高峰销售；
- **不要进10成熟**，除非当天做促销/做果切；
- 一次不要只按“一箱整批”进，尽量**分两批不同熟度**（如7成+8成），错开上架，避免同一天全部集中转熟、集中坏。

## 二、到货时间：避开高温、缩短库外时间

- **要求早晨到货（开门前或营业初）**，当天就能上架、当天开始计算货架期；避免下午到货后压在仓里过夜。
- 明确**到货熟度一致性**：要求整批熟度接近，别一箱里混着全绿和带黑点的。
- 若有冷链条件，要求**运输中避免高温暴晒**，香蕉怕闷热，夏天闷在车厢里会加速转熟。

## 三、写进采购单的几句话说清楚

可以直接对供应商这样说：

> “主货要8成熟、黄里带绿尖、手感偏硬，整批熟度要一致；早上开门前送到。再搭一小批7成熟的。不要给9成熟以上，除非我提前单独要。到货如果熟度超标或有黑点，我按不合格收。”

## 四、到店后的配套动作

采购只能管一半，另一半靠店内：
- 香蕉**不要和苹果、梨等催熟水果堆一起**；
- 悬挂或单层摆放，减少压伤；
- 每天按熟度**分批挑出快熟的做促销或果切**，别等全批一起黄；
- 夏季可适当减少单次进货量、提高进货频率，比一次进大量更能减少损耗。

**一句话原则：采购按“预计几天卖完”定熟度，按“越早到越好”定到货时间，整批不要单一熟度、宁可少量多次。**
