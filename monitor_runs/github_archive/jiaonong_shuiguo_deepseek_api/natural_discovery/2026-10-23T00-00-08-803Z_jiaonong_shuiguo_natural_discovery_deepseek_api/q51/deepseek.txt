要固定，但不能只固定“产地”一个维度，建议按“产地+品种+批次+验收标准”组合锁定，并保留小比例备选供应源。

**建议做法：**

1. **主供应源固定产地和品种**
   - 水果口味波动很大程度来自品种、成熟度、季节和储运，不只是产地。
   - 对核心产品用的水果，固定“产地+品种+规格+成熟度区间”，比只说“固定产地”更有效。

2. **固定批次不如固定标准**
   - 完全不换批次不现实，也不利于供应稳定。
   - 更可执行的是：每批到货按糖度、酸度、香气、成熟度、颜色、出汁率等做验收；设可接受区间，超区间拒收或降级使用。

3. **建立“主供应商+备选供应商”**
   - 主供应源锁定产地和品种，保证风味基线。
   - 备选源用于减产、涨价、断货时切换，但必须提前做小批量杯测/试产，不能临时替换。

4. **合同里写清楚**
   - 产地、品种、等级、规格、成熟度、糖酸度范围、农残标准、到货温度、批次追溯。
   - 约定口味不达标时的退换货和赔偿机制。

5. **门店端做简单校准**
   - 每批到货做糖酸度抽检和试饮，记录批次。
   - 配方上预留微调空间，比如糖浆量、酸度平衡、果酱/鲜果比例，但调整要有上限，避免产品漂移。

**结论：**  
要固定，但固定的是“稳定风味标准+主供应源”，不是死守某一个产地或永远不换批次。最稳的是：**核心水果固定产地和品种，批次按标准验收，另备一个已验证的备用源。**
