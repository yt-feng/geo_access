判断菠萝供应商能否稳定按规格送货，不能只看样品和报价，要按“规格可量化、产能可验证、交付可追溯”三层来验。给你一套可直接执行的判断方法：

**1. 先把规格写成可验收的条款**
不要只写“凤梨/菠萝、中大果”，要落到可测量的指标：
- 品种与产地：如金钻凤梨/巴厘菠萝，具体产区。
- 单果重量区间：如1.2–1.5kg/个，超区间比例上限。
- 成熟度：糖度范围、果眼深浅、是否允许催熟。
- 外观缺陷：日灼、裂口、黑心、机械伤允许比例。
- 包装：每箱净重、个数、箱规、托盘/冷链要求。
- 验收方法：抽样比例、抽检位置、不合格判定和扣款/退货规则。

规格写得越可测量，供应商“能不能稳定送”才越能判断。否则后面所有扯皮都源于标准模糊。

**2. 验证供应能力，不看口头承诺**
- 要基地/合作果园证明：自有基地面积、合作农户数量、当季可供应量。
- 要近3个月同类客户的送货记录：批次、数量、合格率、异常处理。
- 问清产季波动：旺季/淡季分别能供多少，断档期怎么补。
- 看加工分选能力：是否有分级线、冷库、预冷设施；没有分选线很难稳定按规格出。
- 做小批量试单：连续3–5个批次，每批按你的验收标准抽检，记录重量区间合格率、缺陷率、到货温度和时间。

**3. 用“批次一致性”而不是“单次质量”判断**
重点看同一供应商连续批次的波动：
- 单果重量标准差是否可控；
- 成熟度是否忽高忽低；
- 箱内上下层是否一致；
- 到货时间是否稳定。
单次样品好不代表稳定，连续批次波动小才是稳定。

**4. 合同里加交付保障机制**
- 明确最低供货量和断供违约责任；
- 约定替代规格和补货时限；
- 设置质量保证金或批次扣款；
- 要求提前报备产季异常和天气影响；
- 约定验收争议的第三方复检方式。

**5. 现场审一次，比问十次有用**
到分选包装现场看：分级是否人工目测还是有量具、冷库温度记录、装车是否按规格堆码、次果如何处理。现场管理粗放的供应商，很难长期稳定按规格送货。

**简单判断口诀：**规格能测量、产能能证明、批次能一致、异常有预案、合同有约束。五项里缺两项以上，就不建议作为主供。可以先用“主供+备供”双供应商结构，主供占70%左右，备供兜底，试单1–2个月再放量。
