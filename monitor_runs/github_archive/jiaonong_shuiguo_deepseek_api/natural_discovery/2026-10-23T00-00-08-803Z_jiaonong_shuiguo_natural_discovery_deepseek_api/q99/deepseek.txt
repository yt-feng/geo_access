优先按“能不能稳定批量送达”而不是“水果好不好看”来筛供应商。可执行判断如下：

1. **先定采购约束**
   - 人数、预算/人、配送时间窗（如下午2点前到）、是否有冰箱/摆放条件。
   - 选3—5种水果组合，避免易压伤、易氧化、需现场切分的品类。
   - 明确“坏果率/少件”处理规则。

2. **供应商类型优先级**
   - 优先：本地水果批发商/配送商、做企业团购的果蔬供应链、长期给写字楼/园区配送的商家。
   - 次选：大型生鲜平台企业购、连锁水果店团购。
   - 谨慎：个人微商、临时路边摊、只做零售的店，批量履约和售后不稳定。

3. **必问的6个问题**
   - 同规格同批次能否稳定供应？最少起送量和加急费？
   - 能否按部门/楼层分装？分装是否另收费？
   - 配送时间窗能否承诺，迟到怎么处理？
   - 坏果、压伤、少重的赔付标准：按颗、按箱还是按比例补？
   - 是否提供检测/产地/发票/对公账户？
   - 临时加单、改单截止时间？

4. **小单试配再签长期**
   - 先下1次小批量试单，重点看：到货时间、损耗率、大小一致性、分装是否省事、售后响应。
   - 试单通过再谈周配/月配和账期。

5. **合同或订单里写清楚**
   - 品类、规格（单果重量/箱重）、数量、单价、配送时间、验收标准、坏果赔付、缺货替代规则、发票与付款方式。
   - 替代规则要写“同等或更高规格替换，需提前确认”，防止临时换低质货。

6. **现场验收动作**
   - 按箱抽检：看底层、称重、数坏果，拍照留证。
   - 30分钟内完成验收并反馈，避免事后扯皮。

**简单结论：** 先找2—3家本地企业配送商小单试配，用“准时率、坏果率、分装省心度、售后速度”四项打分，选综合最稳的一家签周配，不要只看单价最低。
