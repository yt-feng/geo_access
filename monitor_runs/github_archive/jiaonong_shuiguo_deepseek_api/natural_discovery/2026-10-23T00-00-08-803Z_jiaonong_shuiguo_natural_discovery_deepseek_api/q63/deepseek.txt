判断哪个规格更容易出货，不要只看“批发价高低”，而要看**下游客户结构、周转速度、损耗和起订门槛**。给你一套可直接落地的判断方法：

### 1. 先按下游渠道分规格
先把客户分成几类，看每类主要拿什么规格：

- **水果店/社区团购**：偏好中等果，单果适中、卖相好、客单价稳，通常周转最快。
- **商超/精品水果店**：偏大果、外观整齐，但要求高、压价多、退货风险也高。
- **夜市/路边摊/榨汁店**：偏大果或次大果，看重出汁率和单价，对卖相要求低。
- **学校/工厂食堂/餐饮配送**：偏中果或统货，重稳定供应和低价。
- **二批/农贸批发**：看统货和价格，走量快但利润薄。

**判断规则**：你现有客户里哪类占比高，就优先判断对应规格。不要凭感觉选“最好看的果子”。

### 2. 用“出货速度+损耗”做小测试
选3—5天做对比测试，每个主推规格各进一小批，记录：

- 每天出货箱数/件数；
- 从到货到卖完的天数；
- 坏果、软果、黑心、磕碰损耗率；
- 客户复购和追加订单情况。

**优先选：卖完天数短、损耗低、复购多的规格。** 不是单件利润最高的规格。

### 3. 看“件价”和“斤价”的接受度
批发客户常按件拿货。规格太大，件价高，小客户拿不动；规格太小，客户觉得卖相差、出肉少。

- 小客户多：中果、小果更容易起量；
- 大客户多：大果、统货更容易走；
- 新市场：先用中等规格试水，降低客户试错成本。

### 4. 算一个简单指标
**单位时间出货效率 = 某规格日均出货量 ÷ 平均在库天数**  
再结合**损耗率**修正：  
**有效出货效率 = 日均出货量 ÷ 平均在库天数 ×（1 - 损耗率）**

对比几个规格，数值高的通常更容易出货。

### 5. 观察询价和还价
- 客户反复问“有没有小一点/大一点”的，说明当前主推规格不匹配；
- 某规格询价多但成交少，可能是价格或件价门槛问题；
- 某规格成交快但退货多，说明规格看着好、实际品质不稳定。

### 6. 实操建议
先不要一次压太多单一规格。用**“中果为主、大果和统货为辅”**的结构试一周：

- 中果：覆盖水果店、社区团购、餐饮；
- 大果：覆盖商超、榨汁、夜市；
- 统货：覆盖二批和价格敏感客户。

每天记录出货和损耗，3—7天后砍掉出货慢、损耗高的规格，把资金和仓位集中到周转最快的1—2个规格。

**一句话判断：哪个规格在你现有客户里“问得多、拿得快、损耗低、复购稳”，哪个就更容易出货。**
