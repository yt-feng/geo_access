# 水果店遇到坏果的结算与赔付处理

## 一、先明确责任归属（决定谁承担损失）

坏果原因不同，处理方式完全不同：

| 原因 | 责任方 | 处理方式 |
|------|--------|----------|
| 运输途中碰撞、挤压、冻伤 | 供应商/物流 | 供应商承担，可索赔 |
| 到货时已腐烂、发霉 | 供应商 | 供应商承担，拒收或索赔 |
| 到货时完好，店内存放变质 | 水果店自己 | 自行承担 |
| 到货时成熟度不符约定（如要7成熟给了全熟） | 供应商 | 按约定协商 |

## 二、关键动作：到货验收

坏果赔付的核心证据在**收货环节**，事后扯皮很难赢：

1. **当场开箱抽检**，不要签收后再验；大批量货按比例抽检（如每10箱抽1箱）。
2. **拍照/录像留证**：坏果特写、整箱状态、箱号/批次、称重记录。
3. **在送货单上注明**坏果箱数、比例，让送货人签字确认；对方不签就拍照记录并当场拒收该部分。
4. **保留坏果实物**至少到结算完成，必要时作为协商依据。

## 三、常用结算方式（按合同/惯例选一种）

1. **拒收**：坏果比例高（如超过10%~20%，看约定）或整批不可用，直接拒收，不计入结算。
2. **扣重/扣款**：按坏果实际重量或箱数从应付货款中扣除，等价折算。
3. **折价接收**：坏果不影响销售（如轻微碰伤可特价处理），与供应商协商按折扣价结算该部分。
4. **换货补货**：供应商下次送货时补足数量，本次按好果结算。
5. **索赔**：坏果已造成实际损失（如整批报废、错过销售期），可要求供应商按约定赔付，通常以货款抵扣形式实现。

## 四、建议的合同/长期合作约定

事前约定比事后扯皮省事，建议在采购协议或微信记录中明确：

- **验收标准**：坏果率上限（如≤5%不扣，超过部分全额扣减）。
- **赔付比例**：如坏果率超10%，该批货款按坏果比例双倍扣减或整批退货。
- **响应时限**：到货后24小时内提出异议有效，超时视为验收合格（对双方都公平）。
- **结算抵扣**：赔付以下次货款抵扣为主，避免现金追讨。
- **留痕方式**：明确以送货单签字+照片为凭证。

## 五、实操要点

- **别先签"货已收妥无损"再验货**，签收单措辞要看清。
- **小额高频供货**（如每日送菜）建议建立固定扣款台账，月底统一对账抵扣，别每单现金纠缠。
- **首次合作的供应商**加强抽检比例，稳定后再放宽。
- 协商不成时，保留送货单、聊天记录、照片，可作为后续维权依据；金额较大可走合同约定途径。

**一句话原则**：验收当场定责、书面留证、按约定比例扣款或拒收，赔付优先用货款抵扣而非事后追讨。
