判断供应商能不能按时到车，核心不是听口头承诺，而是看他有没有“可验证的履约能力”。可以从这几个方面看：

1. **看产地和货源是否稳定**
   - 问清楚是自有基地、长期合作基地，还是临时调货。临时调货的供应商，按时到车风险最高。
   - 香蕉有催熟和青蕉差异，要确认他报的是“已砍下/在库/在途”哪一类货。没有现货、靠临时收的，容易拖。

2. **要求提供装车计划**
   - 具体到：哪天砍蕉、哪天装车、装车地点、车牌号、司机电话、预计发车时间。
   - 能给出明确装车计划并愿意写进订单的，履约概率高；只说“大概几天后”的要警惕。

3. **核实车辆和司机**
   - 要车牌号、司机姓名和电话，自己或让跟车人直接联系司机确认。
   - 问清是自有车、长期合作车队还是临时找车。临时找车在旺季最容易放空。

4. **看历史履约记录**
   - 问同行、市场档口、老客户，重点问“最近三个月有没有迟到、放空、临时加价”。
   - 新供应商先小批量试单，不要第一次就压大单。

5. **合同和违约条款要具体**
   - 写明装车日期、到车日期、车型/吨位、货品规格、价格。
   - 约定迟到或放空的处理：比如超过几小时怎么赔、司机放空费谁承担、是否可取消。
   - 付款方式上，尽量不要全额预付；可留部分到车验收后付。

6. **盯关键节点**
   - 砍蕉当天确认是否开砍；
   - 装车当天要装车视频或照片；
   - 发车后要定位或司机电话确认；
   - 到车前半天再确认一次。
   - 任一节点对不上，立刻启动备选供应商。

7. **旺季和天气因素要提前留余量**
   - 香蕉主产区遇雨、台风、节假日运力紧张时，到车延迟概率明显上升。要提前问替代方案：如果这车走不了，他能不能调第二车。

简单判断标准：**能说清货在哪、车是谁、几点装、违约怎么赔的供应商，才值得信；只说“没问题、放心”的，不要押大单。** 第一次合作建议小单试履约，再逐步放量。
