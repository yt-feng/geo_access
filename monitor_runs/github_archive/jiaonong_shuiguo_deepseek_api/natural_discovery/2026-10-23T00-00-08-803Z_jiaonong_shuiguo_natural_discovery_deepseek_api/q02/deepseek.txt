对香蕉这个品类，优先级建议是：**熟度 > 坏果率 > 送货速度 > 价格**。原因是香蕉货架期短、成熟度直接决定当天能不能卖、卖几天，价格便宜但熟度不对或坏果多，反而更容易亏。

具体判断可以这样执行：

1. **熟度第一**
   - 小水果店客流有限，最好进“青黄之间、能放1—3天逐步转黄”的货。
   - 如果当天就要卖，选微黄带青头；如果第二天做促销，可略青；不要大量进已经全黄、带黑点的货，除非当天能低价走量。
   - 香蕉熟度不对，价格再低也可能来不及卖完。

2. **坏果率第二**
   - 看整箱/整把的压伤、断指、黑斑、霉点、果柄腐烂。
   - 小批量进货时，坏果率超过5%—10%就要压价或换货；坏果多会直接吃掉毛利。
   - 别只看表面，翻看底层和箱内温度，香蕉怕闷热和挤压。

3. **送货速度第三**
   - 香蕉周转快，送货慢会导致到店后熟度已过、损耗增加。
   - 优先选能稳定隔日或当日送到、且冷藏/通风条件正常的供应商。
   - 但送货速度不能弥补熟度和坏果率的问题。

4. **价格第四，但不是不重要**
   - 价格要在“熟度合适、坏果可控、送达及时”的前提下比较。
   - 小水果店不宜单纯因低价大量进香蕉，香蕉毛利薄、损耗高，低价货如果熟得快、坏得多，综合成本更高。

**实操建议：**每次进货少量多次，先固定1—2家供应商；到货当场抽检熟度、坏果和重量；记录“到货熟度—卖出天数—损耗率—毛利”，连续记2—3周，就能判断哪家供应商综合最划算。价格只在同等熟度和坏果率下比。
