采购香蕉做茶饮/甜品，关键不是“越熟越甜”，而是**按用途分批采购、按熟度分级使用**。香蕉从生到过熟变化很快，茶饮店最好把熟度当成一个可执行的验收标准来控。

### 1. 先按用途定熟度
- **做果泥/奶昔/冰沙/香蕉牛奶**：用 **7～8成熟**，果肉软、甜度起来但还没发黑，打出来香气足、颜色也不容易发暗。
- **做甜品装饰、切片、顶料**：用 **6～7成熟**，外形完整、切面不易塌，甜度稍低但卖相好。
- **做香蕉泥夹心、烘焙、松饼、蛋糕**：可用 **8～9成熟**，表皮有少量黑点，甜度和香气最好。
- **不建议采购已大面积发黑、果肉水化、有酒味的香蕉**，做饮品容易发酸、发涩、颜色差。

### 2. 采购验收看“表皮+手感+果柄”
不要只看颜色，建议三看：
- **表皮**：青黄转黄、无明显大面积黑斑；允许少量芝麻点，但不能成片黑。
- **手感**：轻捏有弹性、不硬也不软烂；果指饱满。
- **果柄/切口**：果柄新鲜、不发黑霉变；切口无渗液、无异味。
- **整串状态**：优先选成熟度相对一致的整串或整把，避免一串里生熟差太大。

### 3. 采购策略：少量多次、分批到货
香蕉后熟快，茶饮店不建议一次囤太多。
- **每天/隔天少量补货**，按 1～3 天用量采购。
- **同一批货分两种熟度**：一部分 6～7成熟做装饰，一部分 7～8成熟做果泥。
- **夏季或室温高时缩短库存周期**，香蕉成熟速度明显加快。
- 供应商稳定的话，可要求**按指定熟度供货**，并在收货时抽检。

### 4. 到店后的熟度管理
- **未熟香蕉**：室温阴凉通风处存放，不要直接冷藏，否则容易黑皮、后熟不均。
- **已到使用熟度**：尽快用完；需要延缓时，可放冷藏，但表皮会变黑，果肉仍可用，适合去皮后做果泥。
- **过熟香蕉**：立即去皮、分装冷冻，做冰沙/奶昔可用，但当天要判断是否有酒味、酸败味。
- **先进先出**：按到货批次和熟度贴标，先熟先用。

### 5. 给店里一个简单可执行标准
可以设三级：
- **A级 6～7成熟**：表皮黄、手感稍硬有弹性，做装饰切片。
- **B级 7～8成熟**：通体黄、轻捏软，做果泥、奶昔。
- **C级 8～9成熟**：少量黑点、香气浓，做烘焙/香蕉泥，当天优先用完。

**核心建议：不要只按“香蕉”采购，要按“用途熟度”采购；少量多次、分级验收、先熟先用。** 这样既能保证饮品甜香和卖相，也能减少损耗。
