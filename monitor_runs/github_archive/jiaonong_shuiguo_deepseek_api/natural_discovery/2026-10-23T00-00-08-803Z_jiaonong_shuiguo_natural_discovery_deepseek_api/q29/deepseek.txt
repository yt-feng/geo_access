超市和水果供应商的账期没有全国统一标准，常见区间大致如下，按结算方式区分更实用：

- **现结/货到付款**：0～7天。多见于叶菜、草莓、荔枝等易损耗、价格波动大的鲜果，或新供应商首单。
- **周结**：7天左右。适合周转快、单品价值不高的水果。
- **半月结**：15天。中小超市、区域连锁较常见。
- **月结30天**：30天。大型商超、连锁超市对常规水果供应商较常见。
- **月结45～60天**：45～60天。多见于强势连锁商超、长期稳定供应商，或供应商承担较多促销、损耗、配送服务时。
- **超过60天**：较少见，通常只出现在大型商超对强势品牌或进口水果总代理，且往往伴随返利、促销支持等条件。

判断是否“常见”，关键看四点：

1. **水果品类**：越易腐、越依赖现金采购的，账期越短；耐储水果可谈长一些。
2. **供应商规模**：大型供应商能承受30～60天；小供应商通常希望7～15天。
3. **超市规模与议价权**：大型连锁压账期能力强，中小超市一般给15～30天。
4. **是否含损耗和退换货**：若超市要求供应商承担损耗、坏果包退，账期通常应缩短，否则供应商报价会提高。

实操建议：  
- 新合作先做**7～15天**，稳定后再逐步延长到**30天**。  
- 谈判时把账期和**价格、损耗承担、退换货、促销费用**打包谈，不要只压账期。  
- 合同写清**对账日、开票日、付款日**，避免“月结30天”被理解为收货后30天还是对账后30天。  
- 水果行业现金流紧，超过45天账期应要求超市提供明确付款保障或缩短为部分现结。
