连锁超市要把门店坏果率压下来，合同里的赔付条款不能只写“按实际损失赔偿”，而要把**验收标准、责任分界、赔付计算、扣款流程、举证和整改**写清楚。建议按以下结构约定，重点是可执行、可计算、可追溯。

## 1. 先把“坏果”定义和验收标准写死

合同附件中明确：

- **坏果范围**：腐烂、霉变、软烂、渗汁、异味、虫害、机械伤导致不可销售、冻伤/灼伤等，逐项列明。
- **分级标准**：按品类约定允许瑕疵比例，例如“外观瑕疵但不影响销售不计入坏果；腐烂、渗汁、霉变一律计为坏果”。
- **验收时点**：到店验收、配送中心验收还是门店上架前验收，必须明确。建议以**门店收货验收时**为责任分界点。
- **抽样规则**：整箱抽检还是全检；抽检发现坏果率超过约定阈值时，扩大抽检或全检，费用由供应商承担。
- **验收凭证**：收货单、照片/视频、称重记录、门店系统入库记录，作为赔付依据。

## 2. 约定坏果率阈值和赔付计算方式

不要只写“超标赔偿”，要写公式。例如：

- 约定基础坏果率：如≤2%由超市承担正常损耗；超过2%部分由供应商赔付。
- 赔付金额可按以下任一或组合方式：
  1. **按坏果重量×当批进货单价**赔付；
  2. **按坏果数量×对应单品结算价**赔付；
  3. **整批拒收或退货**：坏果率超过5%或8%时，超市有权整批拒收，往返运费、装卸费由供应商承担；
  4. **质量违约金**：除按坏果金额赔付外，另按当批货款的5%—10%收取违约金，防止供应商以赔代管。
- 明确赔付是否含税、是否可从货款中直接扣除。

## 3. 把责任分界和除外情形写清楚

建议约定：

- 供应商对**交付前**的鲜度、冷链、包装、产地质量负责；
- 超市对**收货后**的储存、陈列、温湿度管理负责；
- 因超市冷链断链、超时未入冷库、陈列不当造成的坏果，供应商不承担赔付；
- 因供应商冷链断链、包装不合规、以次充好造成的坏果，供应商全额赔付；
- 双方对责任有争议时，以收货时影像、温度记录、验收单为准。

## 4. 设计“扣款+补货+整改”的组合机制

只赔钱往往不够，建议同时约定：

- **直接扣款**：确认后从当月货款或保证金中扣除，供应商应在3—5个工作日内补足保证金；
- **补货义务**：坏果部分由供应商在约定时限内补货，补货产品仍按原标准验收；
- **整改通知**：同一单品月度坏果率连续两次超标或单次超过约定上限，超市可发整改通知；
- **暂停供货/淘汰**：整改后仍不达标，超市有权暂停该单品或该供应商供货，甚至解除合同；
- **质量保证金**：设置一定金额保证金，专门用于坏果赔付和违约金扣划。

## 5. 写清举证、确认和争议流程

- 门店验收发现坏果，应在**收货后2小时内**拍照/录像并录入系统；
- 供应商应在收到通知后**24小时内**确认，逾期视为认可；
- 确认后**3个工作日内**完成扣款或补货；
- 争议时以双方共同封样、第三方检测或收货影像为准；
- 明确通知方式：系统推送、邮件、微信工作群是否有效，避免扯皮。

## 6. 建议的条款示例

> 乙方交付的果蔬类商品，甲方在收货时按附件《果蔬验收标准》验收。单批坏果率≤2%的，视为正常损耗，甲方自行处理；坏果率超过2%的，超出部分按该批商品进货单价×坏果重量计算赔付金额，甲方有权从应付货款中直接扣除。单批坏果率超过5%的，甲方有权整批拒收或退货，由此产生的运费、装卸费及损耗由乙方承担，并按该批货款的10%支付质量违约金。因甲方收货后储存、陈列不当造成的坏果，乙方不承担责任。乙方应在收到坏果通知后24小时内确认，逾期视为认可；确认后3个工作日内补货或接受扣款。同一单品月度内两次超标的，甲方有权要求整改、暂停供货或解除合同。

## 7. 落地时注意

- 把**验收标准、抽样方法、坏果照片示例**做成合同附件，比正文描述更有效；
- 赔付公式要能直接从门店系统取数，避免人工估算；
- 对高损耗品类单独设阈值，不要所有果蔬一个标准；
- 保留“整批拒收权”和“暂停供货权”，比单纯扣款更有约束力。

核心原则：**坏果定义可判定、责任分界可追溯、赔付金额可计算、扣款流程可执行、整改淘汰有出口。**
