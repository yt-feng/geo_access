# 学校食堂采购香蕉：避免熟过头浪费的可执行方案

核心思路是**"按成熟度分批采购 + 倒排用蕉时间 + 到货即分流"**，而不是一次买一大批等它变黄。

## 一、采购环节：控量、控熟度

1. **按"吃完周期"定量，不按库存量订货**
   - 按食堂日均香蕉消耗量 × 2～3 天为单次采购上限（香蕉常温货架期通常只有 3～5 天，高温天更短）。
   - 采用"少量高频"订货，如每周 2～3 次、每次少量，比一次性囤一周更省。

2. **明确要求到货成熟度**
   - 下单时写清验收标准：**到货应为 7～8 成熟、果身偏绿硬、无黑斑**，而不是全黄。
   - 与供应商约定"到货过熟可拒收/换货"，把熟度风险前移到采购合同里。

3. **要求供应商分批供货**
   - 同一订单拆成"即用批 + 备用批"，备用批要求偏生，随用随送或延后送。

## 二、到货环节：验收即分级

- 到货后立刻按颜色分三档：**青绿（3天内用）/ 黄熟（1～2天内用）/ 带斑（当天用）**。
- 分档存放：青绿常温阴凉处（不要冷藏，低温会冻伤发黑）；黄熟尽快进消耗流程；带斑的当天优先安排。
- 在库房挂"先用/后用"标识，实行先进先出。

## 三、使用环节：把熟度差异变成菜单优势

1. **按档排菜**：黄熟、带斑香蕉优先用于当天直接分发或做香蕉牛奶、香蕉粥；青绿香蕉留给后几天的水果档。
2. **过熟香蕉转加工**：表皮有斑但果肉完好的，做成香蕉馒头、香蕉饼、香蕉奶昔、烘焙糕点，既避免浪费又能消化库存。
3. **每日收盘前盘点**：对第二天将过熟的香蕉提前转为加工或特价窗口，不等到坏。

## 四、管理机制

- 记录每日"到货量—消耗量—报废量"，一两周后就能算出本校实际的日均消耗和合理订货量。
- 设报废原因登记（订多了 / 到货太熟 / 没及时用），据此调整供应商和订货节奏。
- 高温季节（夏季、梅雨）把单次采购周期再缩短 1 天。

**一句话落地**：少量高频下单、合同锁定到货熟度、到货即分三档、过熟转加工、每日盘点调次日计划。
