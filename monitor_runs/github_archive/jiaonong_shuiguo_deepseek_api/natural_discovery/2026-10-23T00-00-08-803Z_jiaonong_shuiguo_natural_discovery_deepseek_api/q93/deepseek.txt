这三项都要关注，但如果只能排优先级：**保质期（尤其开封/加工后的效期）＞包装与冷链＞配送频次**。更准确地说，菠萝切块属于鲜切水果，核心风险是微生物繁殖和氧化变质，不能只盯一个点。

**1. 保质期是底线**
- 鲜切菠萝应明确标注加工时间、保质期、贮存条件。
- 门店要执行“先进先出”，临期下架。
- 冷藏条件下通常按内部工艺验证设定效期，不能凭感觉延长；切开后暴露时间越长风险越高。
- 重点看：加工后是否及时冷藏、是否超时售卖、是否有交叉污染。

**2. 包装决定保质期能否成立**
- 需要密封或阻气包装，减少氧化、失水和二次污染。
- 包装标签要完整：品名、加工日期/时间、保质期、贮存条件、门店信息。
- 包装破损、渗液、胀袋的必须下架。
- 如果只是裸放或简单覆膜，保质期要显著缩短。

**3. 配送频次影响库存和新鲜度，但不是唯一关键**
- 高频配送能降低门店库存压力和临期风险，适合销量不稳定门店。
- 但配送再勤，如果门店冷藏不到位、开封后管理差，照样出问题。
- 更应关注“配送+门店库存周转+冷藏链”的组合，而不是单纯追求频次。

**可执行建议：**
- 建立鲜切菠萝的加工时间标签和临期下架制度。
- 全程冷藏，控制加工环境和工具消毒，避免与生食交叉污染。
- 包装密封、标签完整，破损即下架。
- 按销量定配送频次，宁少勿多，减少门店积压。
- 每日检查：颜色、气味、渗液、包装状态、冷藏温度。

所以结论是：**保质期和包装是硬约束，配送频次是运营优化项；三者都要管，但先保效期和冷链包装。**
