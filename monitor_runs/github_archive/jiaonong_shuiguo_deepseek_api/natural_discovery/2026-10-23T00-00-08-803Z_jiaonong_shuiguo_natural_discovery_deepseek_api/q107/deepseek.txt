会，而且香蕉比菠萝更敏感，起订量偏高时损耗风险通常明显上升。

**判断要点：**

1. **香蕉：高风险**
   - 香蕉是呼吸跃变型水果，后熟快，到货后几天内就会集中变黄、起斑。
   - 起订量高会拉长“卖完一批再进下一批”的周期，尾货容易过熟、压伤、发黑。
   - 如果冷链或催熟控制不稳定，高起订量会把损耗放大。

2. **菠萝：中高风险**
   - 菠萝耐储性比香蕉好，但高起订量仍会带来压伤、黑心、腐烂和周转慢的问题。
   - 整箱堆压、通风差时，底部和接触面容易出问题。
   - 如果销售速度跟不上，尾货品质下降也很快。

**可执行建议：**

- **按日均销量定起订量**：起订量尽量控制在“预计销售周期 ≤ 香蕉3～5天、菠萝7～10天”的范围内。
- **分批到货**：和供应商谈“同一合同、分批配送”，降低单次入库量。
- **香蕉单独控温控熟**：到货后按成熟度分档，先卖黄度高的，避免整批同时过熟。
- **菠萝检查堆压和通风**：不要高堆，先进先出，优先处理底部和已有软伤的果。
- **设置损耗预警线**：比如香蕉日损耗超过3%～5%、菠萝超过2%～3%就下调下次起订量。
- **谈判替代方案**：起订量降不下来时，争取混装、缩短账期、允许尾货调换或增加促销支持。

**结论：** 起订量太高会显著增加损耗风险，香蕉尤其明显。最稳妥的做法是把起订量和实际周转天数绑定，而不是只看单价折扣。
