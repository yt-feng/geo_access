结论：合同里不要只写一个“坏果率超过X%就赔”，更稳妥的是写“验收标准+分级处理+拒收/赔付触发线”。实务上可参考：

1. **轻微瑕疵**：坏果率≤3%，一般按正常验收，不单独赔付，但可要求扣重。
2. **一般超标**：坏果率＞3%但≤5%，可要求按坏果重量扣款，或按超标部分折价赔付。
3. **明显超标**：坏果率＞5%但≤10%，可要求整批折价、按比例赔付，并保留退货权。
4. **严重超标**：坏果率＞10%，可约定买方有权拒收整批、要求退货退款，并由卖方承担运费/损耗。

更建议合同写成：
- “以抽样验收为准，抽样比例不低于__%，坏果率=坏果重量/抽样总重量×100%。”
- “坏果率≤3%为合格；3%＜坏果率≤5%，按坏果重量双倍扣款；5%＜坏果率≤10%，整批按__%折价或赔付；＞10%，买方有权拒收并退货。”
- 明确“坏果”定义：腐烂、霉变、虫蛀、严重压伤、异味、不符合约定规格等。
- 明确验收时限、抽样方法、复检规则和赔付计算方式。

所以，**建议把赔付触发线设在坏果率超过3%—5%**，其中**超过5%可要求较明确赔付/折价，超过10%可拒收**。具体数值还要结合水果品类、运输距离和验收标准调整。
