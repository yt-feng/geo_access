优先建议：**整果陈列、让顾客自己挑，现场按需去皮/切块作为增值服务**。不建议提前大批去皮好摆卖。

原因很直接：

1. **整果更耐放、损耗低**  
   菠萝整果比去皮果耐储存，表皮能保护果肉，减少氧化、流汁、压伤和细菌污染。水果店最怕高损耗，提前去皮会明显缩短售卖窗口。

2. **让顾客自己挑，接受度更高**  
   菠萝成熟度差异大，顾客通常愿意按外观、香味、手感自己选。自己挑能减少“买回去不熟/过熟”的争议。

3. **去皮服务比去皮现货更稳妥**  
   顾客挑好后现场去皮、切块、装盒，既方便又新鲜，还能带动客单价。比提前去皮摆着卖更安全，也更容易让顾客觉得值。

4. **提前去皮只适合特定场景**  
   比如高峰时段、果切盒、办公室团购、外卖切片，可以少量预处理，但要冷藏、限时、明示加工时间，并优先消化成熟度高、当天必须处理的果。

实操建议：

- **主陈列：整果**，按成熟度分区，标注“即食/放1—2天”。
- **提供免费或少量收费的现场去皮切块服务**。
- **少量做果切盒**，只处理当天预估能卖完的量，冷藏陈列，标注加工时间。
- **顾客自己挑为主，店员辅助判断**：教顾客看香味、按压回弹、底部新鲜度。
- **不建议把去皮果当默认主销形态**，除非你店里的果切周转非常快。

一句话：**整果卖、顾客挑、现场加工，少量果切补充；不要提前大批去皮。**
