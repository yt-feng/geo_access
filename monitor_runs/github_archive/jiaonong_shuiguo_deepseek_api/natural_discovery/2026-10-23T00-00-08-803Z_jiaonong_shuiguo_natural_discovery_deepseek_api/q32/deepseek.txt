判断香蕉供应商能否全年稳定供货，建议用“产地能力+硬件设施+合同约束+试单验证”四条线交叉验证，不要只看报价和口头承诺。

**1. 先问清货源结构，而不是只问“有没有货”**
- 要求供应商写清楚：自有基地面积/合作基地数量、分布在哪些产区（如云南、广西、海南、老挝、越南、菲律宾、厄瓜多尔等），各产区上市月份。
- 关键判断：单一产区通常做不到全年稳定，必须有多产区轮换或进口补充。让对方给一张“月份—产区—预计可供量”表，能填得具体可信的才靠谱。
- 问清台风、寒潮、雨季等历史断供情况，以及他们当时怎么补货。

**2. 看硬件和处理能力**
- 是否有催熟库、冷库、分拣包装线，催熟库容量能否匹配你的日销量。
- 运输方式：产地到门店的冷链/常温运输安排，长途是否用冷藏车或保温车。
- 香蕉是呼吸跃变型水果，催熟和温控能力直接决定全年能不能稳定交付合格成熟度的货。

**3. 用合同把“全年稳定”变成可追责条款**
- 约定月度最低供货量、缺货违约金、替代产区补货义务。
- 约定质量标准和验收规则：成熟度、青条比例、伤疤、单把重量、到货损耗率上限。
- 约定价格调整机制，避免旺季坐地起价或淡季压货。
- 要求供应商提供食品安全相关资质和检测报告，并约定抽检不合格的处理方式。

**4. 试单验证，别一次签全年**
- 先做3个月试单，覆盖至少一个淡季或风险月份，按月统计到货率、损耗率、成熟度合格率、缺货次数。
- 同时保留1—2家备选供应商，哪怕量小，作为断供时的缓冲。
- 试单期间突击考察一次产地或加工厂，核对他说过的基地、冷库、催熟库是否真实存在。

**快速判断信号：**
- 可靠：能说清多产区月份表、有催熟冷库、接受最低供货量和违约条款、愿意试单。
- 谨慎：只强调“关系硬”“全国都能发”、拒绝写最低供货量、报价明显低于市场、没有固定加工场地。

最后提醒：香蕉全年稳定供应的核心不是“供应商认识多少产地”，而是“淡季和灾害月份他从哪里补货、补货成本谁承担”。把这两点写进合同，比任何口头保证都有效。
