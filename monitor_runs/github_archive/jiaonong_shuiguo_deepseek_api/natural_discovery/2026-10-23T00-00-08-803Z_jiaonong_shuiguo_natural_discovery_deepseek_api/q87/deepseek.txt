旺季爆单时想锁住水果库存，核心不是“打个招呼预留”，而是**用确定性和利益把供应商的产能绑住**。给你一套可执行的打法：

## 一、先算清楚要锁什么
- 按历史同期销量×今年增长系数×爆款集中度，倒推未来3-4周**分SKU、分周**的需求量。
- 区分两类：**核心爆品**（必须锁量锁价）和**引流/长尾品**（随行就市，少锁）。
- 水果有损耗和成熟期，锁量要留10%-15%缓冲，但别把缓冲量也写死成采购义务。

## 二、锁库存的4个硬手段
1. **预订金/保证金**：对核心SKU付10%-20%预订金，约定“保底采购量+阶梯价”，供应商违约或你弃单都有罚则。这是最有效的绑定方式。
2. **签订周度框架协议**：锁定未来4周的**最低供应量、最高价上限、到货时间窗**，价格按周随行调整但设封顶，避免旺季被临时涨价。
3. **包园/包棚**：对主推单品直接对接产地合作社，提前包下某片果园的产出，派人或委托代办驻点看货，减少中间商截胡。
4. **产能预留费**：对加工类（切果、礼盒）付少量预留费，让供应商优先排你的单。

## 三、把履约风险写进合同
- 明确**到货合格率、损耗率上限、缺货赔付**（如缺货按货值20%赔付或下季度扣款）。
- 约定**价格调整机制**：只跟产地批发价指数联动，设涨跌幅上限。
- 约定**优先供货条款**：同价位下你享有优先提货权。
- 付款节奏和锁量挂钩：预付定金+到货验收后尾款，避免全款压死现金流。

## 四、多供应商对冲
- 每个核心单品至少**2-3家供应商**（主供+备供），主供锁70%，备供锁30%，防止一家受灾或跳单。
- 备选产地错开（如不同省份/不同成熟期），降低天气和集中上市风险。

## 五、提前2-4周启动，别等爆单
- 旺季前**2-4周**完成谈判和打款，水果供应商的产能和冷库位是抢的，越晚越被动。
- 同步把你的**预估销量数据**给供应商看，让对方敢为你备货——信息透明本身就是锁定手段。

## 六、内部配套
- 仓储冷链提前扩容，否则锁了货也接不住。
- 设置**锁量看板**：每周核对锁定量、实际到货、动销，动态调整下周锁量。

**一句话总结**：用“预订金+框架协议+包园+多供应商对冲”四件套，把口头预留变成有罚则的合同义务，提前2-4周动手。先锁核心爆品，别全面铺开。
