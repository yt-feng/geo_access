和品牌方谈区域保护和串货，核心不是听对方口头承诺“我们管得很严”，而是把规则、证据、违约后果、执行机制问到可落地。建议按下面几组问题逐条问，并要求写进合同或附件。

**一、区域保护**
1. 我代理的区域边界具体是什么？按省、市、区县还是按渠道（商超/水果店/批发市场/电商）划分？边界能否附地图或客户名单？
2. 这个区域内，品牌方直营、其他代理、线上店铺、社区团购、直播带货是否也算在内？他们能不能直接向我的区域内供货？
3. 区域保护是独家还是非独家？如果是独家，考核指标是什么（年进货额、首批打款、铺货率、动销要求）？未达标是降级、缩小区域还是直接取消？
4. 保护期多长？续约条件是什么？品牌方能否单方面调整我的区域？调整前提前多久通知、如何补偿？
5. 品牌方在我的区域内新开直营店或新增代理，是否需要我同意？有没有补偿机制？

**二、串货定义与边界**
1. 什么算串货？请给出明确定义：跨区域销售、线上低价销售、向非授权客户供货、跨渠道供货，哪些算、哪些不算？
2. 我作为批发商向区域内下级客户供货，下级客户再卖到区域外，责任怎么算？是我担责还是品牌方追下级？
3. 电商平台、社区团购、直播间的货算不算串货？品牌方自己线上卖的产品和我区域冲突时怎么处理？
4. 尾货、临期货、清仓货的处理规则是什么？能否在指定渠道处理，怎么报备？
5. 赠品、样品、促销品流出算不算串货？

**三、追溯与证据**
1. 产品有没有批次码、区域码、箱码或一物一码？我进货时能否拿到可追溯的编码记录？
2. 发现串货时，品牌方靠什么取证？是我举证还是品牌方举证？举证周期多长？
3. 我举报串货后，品牌方多久内响应、多久给处理结果？有没有书面反馈？
4. 品牌方能否提供串货查处记录或历史案例？不用给具体客户名，给处理结果和频率即可。

**四、违约与执行**
1. 品牌方对串货方具体怎么处罚？罚款金额、扣保证金、停货、取消代理资格，分别适用什么情形？
2. 处罚是否对品牌方直营和线上渠道同样适用？不能只罚代理商、不罚自己。
3. 我因他人串货受损，品牌方是否赔偿？赔偿标准是什么（价差损失、销量损失、调查费用）？
4. 品牌方处理串货有没有时限？超时未处理，我能否暂停进货、要求补偿或解约？
5. 保证金怎么收、怎么退？因串货扣保证金时，谁认定、能否申诉？

**五、合同落地**
1. 以上区域范围、串货定义、处罚标准、响应时限、赔偿机制，能否写进合同正文或附件？
2. 合同里争议解决方式是什么？发生串货纠纷时，能否约定由我所在地法院管辖或仲裁？
3. 品牌方销售政策、价格政策调整时，是否提前通知？能否单方变更合同附件？

**谈判时可直接用的问法：**
“请把区域边界、串货定义、查处流程、处罚标准、响应时限写成附件，我们双方签字确认。另外请明确：品牌方自营线上和直营渠道是否同样受这套规则约束。”

**判断对方是否靠谱的三个信号：**
- 愿意把规则写进合同，而不是只说“放心，我们很规范”；
- 能说清追溯手段和查处流程，而不是含糊说“发现了就处理”；
- 对自营渠道和代理商一视同仁，而不是只约束代理、不约束自己。

最后提醒：区域保护和串货条款一定要和进货任务、返利政策、退换货政策一起看。有些品牌用高任务压货，再用串货条款扣保证金，实质是把风险转给批发商。谈的时候把“任务未完成时库存怎么处理”也一并问清。
