需要，且建议把这两项写进采购条件，而不是仅口头确认。

**发票**
- 企业福利采购通常需要增值税发票用于入账、报销和税前扣除；应明确发票类型（专票/普票）、税率、开票项目（如“水果礼盒”或“农副产品”）、开票时间及是否支持先票后款。
- 水果属于农产品，供应商可能是一般纳税人，也可能是小规模纳税人或合作社，税率和可开票类型会不同，采购前要确认其开票资质，避免到货后无法开票。

**定制包装**
- 企业福利通常有品牌露出、节日主题、员工关怀信息等需求，定制包装能提升福利感知，也便于统一发放和区分档位。
- 需明确起订量、定制内容（Logo、贺卡、外箱、手提袋）、设计确认流程、打样费及周期、包装成本是否含在报价内、最小起订量不足时如何处理。
- 食品类定制包装还要确认包装材料符合食品接触安全要求，避免异味或污染水果。

**建议的采购条件写法**
1. 供应商须具备合法经营资质，并能按采购方要求开具合规增值税发票。
2. 报价须含定制包装费用，明确起订量、打样周期和设计确认节点。
3. 因供应商开票资质或包装定制能力不满足导致无法履约的，应约定退换货或违约责任。

如果供应商只能二选一，优先保留“能开合规发票”的供应商；定制包装可通过贴标、腰封、通用礼盒加贺卡等低成本方式替代。
