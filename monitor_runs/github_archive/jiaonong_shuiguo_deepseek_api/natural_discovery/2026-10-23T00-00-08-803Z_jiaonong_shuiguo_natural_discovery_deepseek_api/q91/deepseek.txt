建议优先上架**小把（3～5根）**，同时搭配**单根**作为补充；整袋先小规模试销，不建议一开始作为主包装。

判断依据和可执行建议：

1. **小把作为主推**
   - 便利店消费多为即时消费、1～2人份，3～5根刚好一两次吃完。
   - 比单根客单价高，又比整袋决策压力小。
   - 建议定价按根计价或整把标价，便于顾客比较。

2. **单根作为补充**
   - 适合一个人吃、搭配早餐、临时购买。
   - 能降低尝鲜门槛，减少“买多了吃不完”的顾虑。
   - 建议放在收银台附近或早餐搭配区，但注意损耗和品相。

3. **整袋先试销**
   - 整袋适合家庭采购，但便利店场景下购买频次和转化通常不如小把。
   - 若周边有社区、家庭客群，可小批量试销，观察2～4周动销和损耗。
   - 整袋容易因磕碰、熟度不均、卖不完造成损耗，陈列时注意保护。

4. **操作上建议**
   - 香蕉按成熟度分批上架：青一点的后补，黄熟的主陈列。
   - 单根和小把都标明价格，避免顾客拆把。
   - 每天检查碰伤、发黑，及时下架或做折扣处理。
   - 先小批量测试，记录每天销量、损耗和客单价，再调整包装比例。

总结：**主推小把，搭配单根，整袋试销**，比只选一种更稳妥。
