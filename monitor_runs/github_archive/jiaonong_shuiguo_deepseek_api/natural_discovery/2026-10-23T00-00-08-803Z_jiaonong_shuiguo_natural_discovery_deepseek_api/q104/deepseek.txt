# 单位采购水果：到货品质不一致的验收与售后处理

核心原则：**先固定证据、再按标准验收、最后凭合同条款谈售后**。水果是生鲜，验收窗口很短（通常到货当场或当天），拖过时间点就很难主张权利。

## 一、到货前先立规矩

品质不一致的纠纷，八成源于合同没写清楚。采购时就该把以下内容落到订单或合同里：

1. **验收标准可量化**：不要只写"新鲜、无腐烂"。按品种写清楚：果径/单果重区间、成熟度（几成熟）、糖度范围、色泽、允许的次果率（如不高于5%）、机械伤和病斑面积上限、农残检测要求。
2. **抽样方法**：从不同箱/不同层随机抽（如每批抽5%~10%，不少于3箱），避免只抽表面好果。
3. **验收时限与地点**：写明"到货后X小时内完成验收"，明确是在收货现场验收还是入库后验收。
4. **售后条款**：品质不达标的处理方式是补货、换货、折价还是退货；折价比例怎么算；响应时限（如24小时内答复）；运费和损耗由谁承担。
5. **留样**：约定双方各留样品，封存签字，作为争议依据。

## 二、到货验收怎么做

**第一步：先拍照录像，再动手。**
- 拍整车/整批全景、外包装和标签、开箱后的箱内实况、问题果特写（带尺度参照物，如硬币或标尺）。
- 视频记录随机抽样的全过程，保证"抽的不是挑出来的"。
- 留好送货单、磅单、车牌和司机信息。

**第二步：分品类、分层抽样。**
- 不要只看最上面一层，从不同垛位、不同箱随机取样。
- 按合同标准逐项检查：外观、大小、成熟度、有无霉变/虫害/冻伤/压伤、气味。
- 对疑似问题批次可做简单检测（糖度计测糖度、手感判断软硬），必要时送第三方检测农残。

**第三步：量化记录，形成验收单。**
- 用表格记录：总件数、抽检件数、不合格件数、不合格类型和比例。
- 关键动作：**不合格品单独隔离、拍照称重、暂不处置**，避免混入合格品后无法举证。
- 让送货方在验收记录上签字确认（或至少拍照发对方业务员并在聊天记录中确认）。

**第四步：当场分类处理。**
- **轻微不一致**（如大小略偏、少量次果在约定容忍范围内）：正常收货，记录备注。
- **部分不达标**：合格部分收货，不合格部分拒收或按约定折价，在送货单上注明"部分拒收/折价"并由司机签字。
- **整批严重不符**（如大量腐烂、品种错误、成熟度严重偏差）：整批拒收，出具书面拒收单，拍照留证，同时通知供应商。

## 三、售后怎么谈

1. **第一时间书面通知**：到货发现问题后立即（最好当天）通过微信/邮件/正式函件通知供应商，附照片、视频和验收单，明确诉求（补货/换货/折价/退货）和期限。口头沟通后一定补一条文字记录。
2. **按合同主张，按比例算钱**：折价按不合格比例或约定公式计算，不要笼统"少给点"。例如次果率超标准10个百分点，按合同约定的阶梯折价执行。
3. **区分责任**：运输途中压伤、冷链断裂导致的品质下降，要判断是供应商发货问题还是物流问题，在合同中事先约定损耗由谁承担，避免互相推诿。
4. **保留追责证据链**：送货单、验收单、照片视频、沟通记录、留样、必要时第三方检测报告，缺一不可。
5. **升级处理**：供应商不认账时，先发书面催告；仍不解决的，按合同违约条款处理（扣款、暂停合作、列入供应商黑名单），金额较大可走法律途径。

## 四、几个容易踩的坑

- **先签收后验货**：司机一走、单据一签"数量无误"，再提品质问题就很被动。签收时务必注明"已签收，品质待验"或直接当场验。
- **只看不记**：口头说"这批不行"没用，必须有照片、比例、签字。
- **混放**：不合格品和合格品混在一起，事后无法证明比例。
- **拖时间**：水果一天一个样，隔两天再投诉，对方一句"是你储存不当"就能挡回来。

**一句话总结**：合同里把标准写死，到货时先拍照再抽样、量化记录并让对方签字，发现问题当天书面通知、按比例主张补换货或折价，全程留证据链。
