买香蕉想避开“太生/太熟”，关键不是记一句口诀，而是**按你打算几天吃完，倒推该挑什么颜色**。到店后先定用途，再按下面选。

**1. 先按食用时间选颜色**
- **当天或第二天吃**：选**通体黄色、少量小褐斑**的，甜度正好。
- **2～4天内吃**：选**黄中带一点青肩**（果柄附近略青）的，放家里会继续熟。
- **4天以上才吃**：选**偏青、青黄相间**的，别选已经全黄带斑的。
- **要做奶昔/香蕉泥/烘焙**：可以选**黄皮带较多褐斑**的，但当天就用。

**2. 到店快速判断**
- **看果柄**：果柄青绿说明刚熟不久；果柄发黑、干缩说明放久了。
- **看棱角**：香蕉太生时棱角明显、手感硬；成熟后棱角变圆润。
- **轻捏中部**：能微微按下、有弹性是好状态；一捏就软塌说明过熟；硬得像石头就是太生。
- **看表皮**：少量芝麻状褐斑正常且甜；大面积黑斑、破皮、渗液不要。
- **看整把**：一把里如果已有几根发黑，其他也会很快熟，除非你马上吃，否则别拿。

**3. 超市里容易踩的坑**
- **别只看整把颜色**：翻看被遮挡的那几根，尤其底部和内侧。
- **别买冷藏区或明显受冻的香蕉**：表皮发暗、发灰、手感软烂的，熟得不正常。
- **别买破皮、裂口、有酒味**的，已经过熟或开始变质。
- **想要放久一点，买整把偏青的**；想要马上吃，买单根黄带斑的。
- **如果家里温度高**，香蕉熟得快，按上面时间再选生一点。

**4. 买回家后的小调整**
- 想催熟：和苹果一起放纸袋里，室温避光。
- 想减速：分开单根、果柄包一下，放阴凉处；**不要放冰箱冷藏**，表皮会变黑、口感变差。已经熟透吃不完的，可以剥皮冷冻做奶昔。

一句话：**当天吃选黄带斑，几天内吃选黄带青肩，想放久选青黄相间；捏着有弹性、果柄不黑、破皮黑斑少，就不会踩坑。**
