和水果供应商谈合作，重点不是只把单价压下来，而是把“稳定供应”拆成可考核的条款。建议重点抓以下几项：

1. **明确水果品质标准**
   - 按品种写清规格：大小、成熟度、甜度范围、外观瑕疵容忍度、产地要求。
   - 约定“可接受/拒收”标准，最好附图片或样品封样。
   - 明确坏果率上限，比如每批次不超过多少，超出如何扣款或补货。

2. **供应稳定性条款**
   - 约定常规送货频次、最低供货量、旺季/节假日保供方案。
   - 要求供应商提供替代品种方案：某品种断货时，提前多久通知、用什么替代、价格如何调整。
   - 设置缺货违约责任，避免“今天没货明天再说”。

3. **价格与调价机制**
   - 不要只锁死单价，水果价格波动大，可约定“基准价+周期性调价”，但设涨跌幅上限。
   - 明确报价是否含税、含运费、含卸货到指定冷库/厨房。
   - 约定临时加急订单的价格规则，防止急单被加价。

4. **验收与退换货**
   - 到货后多长时间内完成验收，不合格批次如何处理：拒收、换货、补货时限。
   - 明确称重方式：毛重还是净重，包装箱/筐是否扣重。
   - 留样和记录制度，方便追溯。

5. **食品安全与资质**
   - 要求提供营业执照、食品经营许可、检测报告或承诺书。
   - 明确农残、霉变、异物等问题的责任和赔偿。
   - 送货车辆和人员卫生要求写进合同或附件。

6. **配送与应急**
   - 送货时间要配合早餐备餐，比如早于几点到货。
   - 约定节假日、恶劣天气、交通管制时的应急预案。
   - 要求供应商提供备用联系人，不能只有一个业务员。

7. **结算与账期**
   - 明确对账周期、发票类型、付款账期。
   - 约定质量扣款、缺货扣款如何从货款中扣除。
   - 避免口头承诺，所有调价、补货、扣款走书面确认。

8. **合同期限与退出机制**
   - 先短周期试合作，比如1—3个月，考核稳定后再签长期。
   - 设置考核指标：到货准时率、合格率、缺货次数、投诉响应时间。
   - 明确连续不合格或多次缺货时，酒店可终止合作。

实操上，建议先让对方按你酒店早餐常用水果列一份“周供应清单+报价+替代方案”，再用小批量试供两周，重点看准时率、坏果率和断货处理。合同里把“稳定”写成数字，比写“保证供应”有用得多。
