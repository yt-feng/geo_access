采购香蕉时，重点是“买对成熟度 + 减少机械伤 + 控制到店后的温湿度与乙烯”。具体可执行做法：

1. **按用途选成熟度**
   - 当天/次日做甜品：买**表皮微黄、果柄仍偏绿**的，别买全黄带黑点的。
   - 需要2–3天用完：买**青黄、果柄绿色明显**的，到店后自然转熟。
   - 不要一次采购“全黄+黑点”的，黑点后很快软烂发黑。

2. **采购时避免机械伤**
   - 选**整把/整串**，少买散装单根。
   - 搬运时不要压、摔、摩擦；香蕉皮一受伤，后熟和变黑会明显加快。
   - 检查果柄和果皮有无裂口、压痕、水渍。

3. **到店后不要冷藏未熟香蕉**
   - 未熟或半熟香蕉放**阴凉通风处**，适宜约**13–15℃**；低于约12℃易冷害，表皮更快变黑。
   - 已熟香蕉若要延缓过熟，可放**冷藏**，但表皮可能变黑、果肉仍可短时使用；甜品店最好按当天用量分开放。

4. **减少乙烯积聚**
   - 香蕉不要和苹果、梨、番茄等释放乙烯的果蔬混放。
   - 整串悬挂或平放通风，不要闷在塑料袋里；袋内水汽和乙烯会加速变黑。
   - 可把果柄用保鲜膜包一下，减少乙烯从果柄释放，但别整根密封。

5. **分批采购、先进先出**
   - 按“当天用、次日用、后日用”分三批买，不要一次全买同一成熟度。
   - 到店后标记日期，先用熟的，青的继续放熟。
   - 夏季高温或雨天湿度大时，采购量再保守一点。

6. **切开后的香蕉**
   - 去皮后尽快使用；暂存可加少量柠檬汁/维C液防褐变，并冷藏密封，但口感会下降，不建议久放。

简单判断：**买青黄整串、不压伤、不闷袋、不混放乙烯水果、按成熟度分批用**，基本能明显延缓到店后很快变黑。
