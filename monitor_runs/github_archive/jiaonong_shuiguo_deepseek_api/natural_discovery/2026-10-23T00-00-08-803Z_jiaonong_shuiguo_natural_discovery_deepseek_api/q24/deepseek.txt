超市采购要防水果农残抽检问题，核心不是“多要一堆文件”，而是要到**能对应批次、能追溯、能验证承诺**的资料。建议按下面清单提前向供应商要，并写明在采购合同/质量协议里。

**一、每批到货必须随货提供的资料**
1. **批次检测报告**
   - 要求：与本次到货的**品种、产地、批次/采收日期、检测日期**对应。
   - 项目：至少覆盖有机磷、氨基甲酸酯、拟除虫菊酯等常见农残项目；最好有**CMA/CNAS资质**检测机构出具的报告。
   - 注意：不接受“一年一份”“一品一份”的通用报告替代批次报告；报告日期应早于或接近发货日期。
2. **承诺达标合格证/产地证明**
   - 食用农产品承诺达标合格证、产地检疫/产地证明等，能证明来源和供应商对质量的承诺。
3. **送货单/购销凭证**
   - 写明品种、规格、产地、批次、数量、发货日期，便于出问题时反向追溯。

**二、供应商资质类资料（首次合作或年度更新）**
1. 营业执照、食品经营许可证/食品生产许可证（按供应商性质）。
2. 供货来源证明：自产证明、合作基地协议、产地采购合同或合作社证明。
3. 种植/基地管理资料：农药使用记录、休药期执行记录、投入品管理记录；有条件的要**绿色食品/有机认证/GAP良好农业规范**等证书。
4. 供应商质量管理制度、农残自检能力说明；若供应商自检，要求提供自检记录和快检设备/人员情况。

**三、合同和质量协议里要写清楚的条款**
1. **批批随货附检测报告或合格证**，否则超市有权拒收。
2. **抽检不合格的处理**：退货、销毁、赔偿、暂停供货、列入黑名单。
3. **追溯义务**：供应商应在规定时限内提供产地、批次、检测、用药记录等信息。
4. **飞检/抽检配合**：超市或第三方可到基地/仓库抽检，费用和不合格责任写清楚。
5. **报告真实性责任**：供应商对报告真实性负责，发现伪造承担违约责任。

**四、采购实操建议**
1. **高风险品种加严**：叶菜类、草莓、豇豆、韭菜、芹菜等农残风险相对高，要求批批报告或提高抽检频次。
2. **报告要验真**：看检测机构资质、报告编号、样品名称和批次是否对得上，必要时向检测机构或监管平台核验。
3. **快检不能替代法定检测**：超市自建快检可用于筛查，但抽检应对以有资质机构的法定检测为准。
4. **建立供应商档案和批次台账**：每批报告、合格证、送货单归档，保存期限按当地监管要求执行，一般不少于6个月，建议保存更久。
5. **新供应商先小批量试供**：连续几批合格后再放量，降低抽检风险。

**一句话总结**：提前要的是“**资质 + 批次检测报告/合格证 + 来源追溯资料 + 合同责任条款**”，并且每批货证对应、能追到产地和批次，而不是只收一份供应商质量承诺书。
