小面积便利店做水果，核心原则是：**少品类、高频补、只做周转快的单品，把水果当引流品而不是利润品。** 具体控制方法如下：

## 一、品类控制：先做“减法”

**1. SKU数量严格控制**
- 30㎡以下：水果SKU控制在 **5～8个**
- 50㎡左右：控制在 **10～15个**
- 超过15个基本管不过来，损耗必然上升

**2. 选品按“三优先”**
- **优先常温耐放**：苹果、梨、橙子、香蕉（香蕉按成熟度分批上）
- **优先高频刚需**：苹果、香蕉、橘子、西瓜（夏季切盒）
- **优先小规格**：单果小、单价低的品种，降低单次购买门槛

**3. 果断砍掉三类**
- 易损娇贵品：草莓、蓝莓、葡萄、荔枝（除非有稳定冷链和高周转）
- 大规格整果：大西瓜、整箱装，卖不动就烂
- 长尾小众品：进口稀有水果，动销慢、占资金

**4. 只留1～2个“引流爆品”**
比如应季西瓜切盒、9.9元香蕉，用来带客流，不指望赚钱。

## 二、损耗控制：从“进货到出清”全链路

**1. 采购端**
- **小批量、多频次**：每天或隔天补货，单次进货量按“预估日销×1.5天”算
- **按个/按份进货**，不整箱压货
- 和批发商谈**可退换或次日调换**，降低尾货风险

**2. 陈列端**
- 水果陈列面积不超过门店 **10%～15%**
- 少量多次上架，**先进先出**，下面垫周转筐
- 易熟水果（香蕉、芒果）单独放阴凉处，不堆叠

**3. 定价与出清**
- 设置**阶梯折扣**：下午5点后9折，晚8点后7折，闭店前打包特价
- 品相下降的立刻转**切盒/果切**，或做“买一送一”
- 每天记录**报损数量**，连续3天卖不动的品直接下架

**4. 数据管理**
- 每天记3个数：进货量、销售量、报损量
- 每周复盘：**损耗率超过8%的品就砍掉**
- 便利店水果综合损耗率控制在 **5%～10%** 算正常

## 三、可执行的一周动作清单

1. 列出当前在售水果，按“销量/损耗”打分，砍掉后30%
2. 确定5～8个核心SKU，固定供应商和补货频率
3. 设一个水果专职责任人，每天早晚各查一次鲜度
4. 建立报损登记表，坚持两周就能看出该砍谁
5. 晚市折扣规则贴在收银台，员工照做

**一句话总结：小门店水果不求全，只求周转快；宁可少卖一个品，不让一个品烂在店里。**
