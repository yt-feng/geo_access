判断商超生鲜供应商的售后响应是否稳定，不能只听口头承诺，建议用“把承诺变成可验证的条件”的方式去查。可以按下面几步做：

1. **先明确售后范围**  
   采购前把菠萝、香蕉常见问题写进合同或询价单：到货腐烂率、黑心病/水心病、香蕉青熟不一致、催熟不达标、缺斤少两、到货延迟等，分别对应补货、换货、扣款、退货的时限。比如“到货24小时内提出异议，供应商48小时内补换或确认扣款”。

2. **要求书面响应机制**  
   看供应商是否有固定售后对接人、电话/微信/邮件响应时限、异常处理流程、补货周期。只给业务员个人电话、没有替补联系人的，稳定性偏弱。

3. **查历史履约记录**  
   要求提供近3—6个月同类商超客户的售后记录或合作证明，重点看：异常发生率、平均处理时长、是否有拒赔/拖延记录。可让对方提供脱敏的补换货单、扣款确认单。

4. **做小批量试单验证**  
   先下2—3次小单，故意在合同中约定较短异议期，观察其响应速度。试单中记录：报障后多久回复、多久给方案、补货是否按时到、补货质量是否达标。

5. **看仓储与货源稳定性**  
   菠萝、香蕉对催熟和温控要求高。问清是否有自有/固定催熟库、冷链车、备用货源。售后稳定的前提是货源和物流可控；纯转手贸易商响应通常更慢。

6. **设置售后考核条款**  
   合同里加月度考核：响应超时扣款、补换货不及时按比例扣款、同一问题重复发生可终止合作。把“售后响应”变成可扣款、可退出的条款，比口头承诺可靠。

7. **交叉验证**  
   向其现有商超客户侧面了解，或到其档口/仓库看实际发货和售后登记台账。没有台账、只靠微信口头处理的，稳定性要打折扣。

简单说：**看书面机制、看历史记录、做小单测试、写进合同考核**。四样都做到，基本能判断其售后响应是否稳定。
