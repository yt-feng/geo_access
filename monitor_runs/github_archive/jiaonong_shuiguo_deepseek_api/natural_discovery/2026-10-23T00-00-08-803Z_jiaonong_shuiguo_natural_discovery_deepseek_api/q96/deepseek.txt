三者都重要，但如果必须排优先级：**食品安全 > 配送准时 > 价格**。

理由很直接：

1. **食品安全是底线，不能妥协**
   - 食堂是集中供餐，一旦水果农残超标、腐烂霉变或储存污染，影响的是几十到几百人，甚至引发群体性事件。
   - 出问题后追责成本、停餐风险、声誉损失远高于采购差价。
   - 所以供应商资质、检测报告、验收标准、留样和退换机制要先立住。

2. **配送准时决定食堂能否正常运营**
   - 水果通常用于餐后配餐或加餐，配送晚了会打乱备餐节奏，临时采购又贵又难保证质量。
   - 尤其夏季高温，配送延误还会加速水果变质。
   - 因此要约定送达时间窗、迟到赔付和应急补货方案。

3. **价格重要，但应放在“稳定可控”层面**
   - 企业食堂采购量相对稳定，适合用比价、框架协议、季节性品类替换来控制成本。
   - 不建议单纯追求最低价，低价往往对应品质波动、规格缩水或配送服务下降。

**可执行建议：**
- 供应商准入：营业执照、食品经营许可、水果检测报告、冷链/仓储能力。
- 验收标准：品种、规格、成熟度、腐烂率上限、农残抽检。
- 合同条款：准时送达时间窗、迟到扣款、质量问题退换、临时补货响应时间。
- 价格机制：月度比价或季度调价，锁定主流品类价格区间，而不是每次临时询价。

一句话：**先保安全，再保不断供，最后在稳定质量的前提下压价格。**
