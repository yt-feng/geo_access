建议先从**香蕉**开始，其次菠萝，苹果放最后。判断依据是超市最关心的四件事：供应稳定性、损耗可控性、消费者接受度、操作门槛。

1. **香蕉：最稳**
   - 进口香蕉供应链成熟，厄瓜多尔、菲律宾、越南等产地多，全年可供应，价格波动相对可管理。
   - 消费者接受度最高，属于高频刚需水果，试错成本低。
   - 但要注意：香蕉是呼吸跃变型水果，对催熟和温湿度要求高。超市如果没有催熟库或稳定冷链，建议先做“到店即售”的熟蕉，或与有催熟能力的供应商合作，不要自己从青蕉开始做。

2. **菠萝：次选**
   - 进口菠萝（如菲律宾、哥斯达黎加）供应也较稳定，但季节性比香蕉明显。
   - 损耗风险高于香蕉，主要来自运输磕碰、成熟度不一致和店内陈列期短。
   - 适合作为差异化单品，但不宜作为第一个“稳定进口水果”主力。

3. **苹果：不建议先做**
   - 国产苹果供应充足、价格有优势，进口苹果（如新西兰、美国、智利）在普通超市里竞争压力大。
   - 消费者对进口苹果的溢价接受度有限，动销慢会拉高损耗和库存成本。
   - 除非超市定位高端或已有稳定进口苹果客群，否则不建议作为首个进口水果品类。

**执行建议：**
- 先小批量引入进口香蕉，选1—2个稳定供应商，测试4—6周动销、损耗率和毛利。
- 同步记录顾客反馈和复购情况，再决定是否增加菠萝。
- 苹果暂缓，等进口水果区形成稳定客群后再考虑作为补充品类。
