找“每天配送”的水果供应商，核心不是只看价格，而是先看**稳定性、配送能力和损耗责任**。建议按下面条件筛选，并现场验证。

## 一、先看能不能稳定每天送
1. **配送频次与时段**  
   明确是否每天可送、几点前到店、节假日是否照常。社区超市最好要求上午开店前送达。
2. **配送车辆与线路**  
   是否冷链车或保温箱配送，是否在你所在区域有固定线路。线路覆盖不到，低价也不可靠。
3. **起送量与加单规则**  
   每天起送金额多少、临时补货是否加运费、少订是否仍配送。
4. **缺货处理**  
   某单品缺货时，是否提前通知、能否替换、替换价怎么算。

## 二、看水果品质与损耗责任
1. **到店验收标准**  
   约定糖度、大小、成熟度、破损率、腐烂率。比如到店腐烂破损超过多少比例由供应商承担。
2. **损耗赔付方式**  
   是当场换货、下次补货抵扣，还是退款。要写进供货单或合同。
3. **成熟度控制**  
   社区超市周转慢，香蕉、芒果、猕猴桃等要看供应商是否能按销售节奏控制成熟度。
4. **退换货时效**  
   当天发现坏果能否当天换，次日是否认账。

## 三、看价格与结算
1. **报价方式**  
   是按固定价、随行就市，还是每日报价。每日报价要约定报价时间，避免临时涨价。
2. **是否有隐性费用**  
   运费、装卸费、筐箱押金、退换货运费谁承担。
3. **账期与结算**  
   现结、周结还是月结；能否开发票或提供销售单据。
4. **价格对比**  
   不要只比单价，要比“到店可售成本”：进价+运费+损耗+退换货成本。

## 四、看供应商资质与货源
1. **经营资质**  
   营业执照、食品经营相关证照、供货来源是否可追溯。
2. **货源稳定性**  
   是产地直采、批发市场档口还是二级贩子。二级贩子价格可能低，但断货和品质波动大。
3. **单品能力**  
   不要只看“什么都有”，要看他擅长的品类。社区超市常卖的苹果、香蕉、柑橘、应季水果是否有稳定优势。
4. **检测与农残**  
   能否提供农残检测报告或批次信息，至少要有可追溯记录。

## 五、实地验证方法
1. **先小批量试供7—14天**  
   每天记录到货时间、损耗率、缺货次数、退换货响应。
2. **凌晨看一次分拣/装车**  
   看是否混装、是否有冷库、坏果是否挑出。
3. **问周边商户**  
   问同区域便利店、水果店、餐饮店，重点问“断货多不多、坏果认不认”。
4. **对比2—3家**  
   至少保留一家备选，避免单一供应商卡脖子。

## 建议你直接问供应商的8个问题
1. 每天几点能送到？节假日送不送？
2. 到我这里起送量多少？临时加单怎么算？
3. 坏果、烂果到店怎么赔？当天还是下次抵扣？
4. 缺货提前多久通知？能否换货？
5. 报价每天几点给？价格波动怎么定？
6. 运费、筐箱、装卸费谁承担？
7. 能不能先试供两周？
8. 有没有固定冷库和分拣场地，能否去看？

**优先级建议：** 先卡“每天准时送+坏果认赔+试供两周”，再谈价格。社区超市水果毛利薄，配送不稳和损耗不认账，比进价贵一点更伤利润。
