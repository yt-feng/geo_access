多店、单店量不大的水果零售，核心矛盾是：**总采购量不小，但单店单次要货少、频次高，直接对接产地或大批发商不划算，容易被起订量、账期、配送门槛卡住**。建议按“先保底、再优化”的顺序选模式：

## 1. 优先起步：本地批发市场代采 + 集中分货
适合刚起步、没仓没配的阶段。

- **做法**：总部或指定门店每天凌晨到本地一级果批集中采购，按各店预估销量分货，用面包车/小货车跑店。
- **优点**：起订门槛低、品种全、当天可调、损耗可控。
- **关键控制**：
  - 只设1个采购口，避免各店自己乱采、价格不透明；
  - 用“昨日销量+今日天气/促销”做订货系数，别按经验拍脑袋；
  - 定死分货时间窗，水果早到比晚到值钱。
- **适合**：门店10家以内、日销总额不大、周边有成熟果批市场。

## 2. 中期主力：区域水果供应商“统采统配”
找本地做超市/生鲜店配送的二级供应商，按周报价、按店配送。

- **合作方式**：总部谈框架价和账期，供应商按门店订单次日配到店或配到中转点。
- **要谈清楚的4件事**：
  1. **起订量**：按“整车/整筐”还是“按店拆零”，拆零加价多少；
  2. **配送频次与门槛**：隔日配还是每日配，单店最低起送额；
  3. **损耗与退换**：到店验收标准、坏果率上限、当日退换规则；
  4. **价格机制**：随行就市还是周定价，涨跌提前几天通知。
- **优点**：省人力、品类稳定、适合多店复制。
- **风险**：供应商加价后毛利被压缩，且容易“什么都有、什么都不精”。建议**主力品类自采、长尾品类交给供应商**。

## 3. 提毛利：单品产地直采/产地代发，只做爆品
不要全品类直采，只对**周转快、耐储、单品量大**的2—3个品类做产地或基地直发。

- **适合品类**：苹果、梨、柑橘、西瓜、哈密瓜等耐储或整件走量的单品。
- **做法**：产季集中锁量，发到城市中转仓，再由现有配送体系分店；或产地按件代发到仓。
- **判断标准**：单品类全部门店日销能凑够“整车/整板”才做，否则不如走供应商。
- **注意**：产地直采省的是中间价，但会新增仓储、分拣、损耗和资金占用，算账时要按**到店成本**比，不是按采购价比。

## 4. 补充模式：城市共享仓/生鲜集配中心
如果门店分散、自建仓不划算，可租用本地生鲜集配仓的“分拣+配送”服务。

- 供应商送货到仓，仓内按店分拣，第三方配送跑店。
- 适合**20—50家店、单店量小但总单量够**的阶段，能把多供应商的货合并配送，降低单店配送成本。
- 重点看：分拣费/件、配送费/店、截单时间、损耗责任划分。

## 建议的组合打法
**本地果批代采保底 + 区域供应商做长尾 + 2—3个爆品产地直采提毛利 + 条件成熟后用共享仓合并配送。**

## 选择时重点算3笔账
1. **到店成本**：采购价+运费+分拣+损耗，不是只看进货价；
2. **单店最小起送/起订**：别让配送费吃掉毛利；
3. **损耗率**：水果毛利再高，损耗失控就白做。多店模式下，**统一定价、统一订货、统一验收标准**比找更便宜的货更重要。

如果门店在10家以内，先用“集中代采+隔日配”跑顺；超过20家再考虑共享仓或自建中转仓。不要一上来就做全品类产地直采，单店量小会被起订量和损耗拖垮。
