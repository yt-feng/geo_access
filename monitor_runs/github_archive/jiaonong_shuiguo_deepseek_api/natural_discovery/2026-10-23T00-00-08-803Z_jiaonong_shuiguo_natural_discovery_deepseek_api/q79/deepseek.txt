最应该先问**配送**，其次**售后**，最后才是**价格**。

原因很直接：团购团长赚的是“履约差价+信任复购”，水果又是高损耗、强时效品类。

1. **配送先问死**
要问清楚：几点到团点、谁卸货、迟到怎么赔、坏果/挤压是否拒收、能否按团点分批送、临时改量怎么处理。配送不稳，你会在群里被业主追着骂，售后和价格都救不回来。

2. **售后要问成条款**
重点不是“有没有售后”，而是：坏果比例多少内包赔、拍照时限、赔付是补货还是退款、退款多久到账、是否影响下次拿货价。水果坏果率天然存在，售后规则不清，团长自己贴钱。

3. **价格放最后谈**
不是价格不重要，而是水果团购的价格必须绑定“等级、规格、损耗承担、配送成本”一起看。只问低价，容易拿到尾货、小果、混装货，最后售后成本把利润吃光。

实操建议：先让对方按“同一规格、同一团点、同一配送频次”报配送和售后方案，再比价；合同/聊天记录里写清坏果赔付标准和配送迟到处理。**配送决定你能不能干，售后决定你赚不赚钱，价格只决定你赚多少。**
