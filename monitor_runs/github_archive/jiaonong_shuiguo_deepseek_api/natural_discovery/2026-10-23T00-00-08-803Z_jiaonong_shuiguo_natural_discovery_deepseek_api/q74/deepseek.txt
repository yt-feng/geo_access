先按餐饮客户的用途倒推规格，不要先按批发市场习惯备货。

**菠萝**
- **鲜切/果盘/饮品店**：主备 **1.0–1.2kg/个的中果**，成熟度7–8成，果眼浅、去芯损耗小；再配少量 **1.5kg以上大果**给整果展示或高档果盘。
- **后厨切块/炒饭/咕咾肉**：用 **1.2–1.5kg/个**，对糖度稳定性和出肉率要求高于外观。
- **果汁/茶饮**：固定品种和产地批次，按“去皮去芯出肉率”报价，不要只报斤价；备 **小果做低价引流**可以，但餐饮端通常不愿为小果多付人工。
- **到货形态**：可提供整果、去皮去芯真空袋、切丁盒装三档；餐饮客户最在意的是**规格稳定、批次糖度稳定、开箱坏果率低**。

**香蕉**
- **餐饮/茶饮/甜品**：主备 **单根110–130g、每把5–7根**的中等规格，成熟度按客户用途分：果切用7–8成熟，直接出品用8–9成熟。
- **烘焙/甜品台**：偏好 **单根130–160g**，要求长度整齐、无严重碰伤。
- **快餐/食堂**：可用 **单根100–120g** 的性价比规格，但要控制催熟均匀度。
- **到货形态**：整把、单根分装、7–8成熟青蕉和即食黄蕉分开备；餐饮客户通常要求**按需催熟、分批到货**，不要一次压太多熟蕉。

**备货建议**
- 首轮不要铺全规格：菠萝先做 **中果1.0–1.2kg为主、大果少量**；香蕉先做 **110–130g/根、7–8成熟为主**。
- 给餐饮客户报价时，菠萝按“个+出肉率+切配形态”，香蕉按“根重区间+成熟度+到货频率”报，比只报箱价更容易成交。
- 先找3–5家目标客户试单，记录他们实际要的**单果重、成熟度、切配形态、每周频次**，再定固定规格。餐饮客户要的是稳定复购，不是一次规格最全。
