选供应商别只看报价，按“能不能稳定供货、能不能验收、出了事找不找得到人”三条线来筛。给你一套可直接落地的做法：

**1. 先定采购标准，再找供应商**
- 香蕉：按根/把定规格，要求无黑腐、无严重机械伤，成熟度可分批到货（青转黄），避免一次全熟。
- 苹果：定品种、果径、糖度区间和外观标准，允许轻微果锈但不允许腐烂、虫眼。
- 橙子：定品种、果径、酸甜度，要求无霉变、无破皮流汁。
- 写进采购单：品种、规格、等级、允许损耗率、到货时间、验收方法、退换货时限。

**2. 供应商来源优先级**
- 本地批发市场大户：响应快、可小批量，适合起步；但要查营业执照和固定档口。
- 产地合作社/家庭农场：价格和新鲜度有优势，适合苹果、橙子等耐储品；要确认能否稳定供量和开具票据。
- 食材配送公司：能一站式配送、有冷链和售后，适合食堂品类多、人手少；重点看是否只做转包。
- 学校周边大型商超/供应链平台：应急补货可用，长期成本偏高。

**3. 必须核验的资质和条件**
- 营业执照、食品经营许可证（或食用农产品销售相关资质）。
- 固定经营场所、仓储和运输条件；水果是否冷链或通风运输。
- 能否提供进货凭证、产地证明或检测报告（按学校当地监管要求）。
- 有没有对公账户、能否开票、配送车辆和人员是否固定。

**4. 用“小批量试用+评分”选，不靠感觉**
让2—3家同时试供2—4周，按同一标准打分：
- 质量合格率（腐烂、破损、规格不符比例）
- 到货准时率
- 缺货/临时加单响应速度
- 报价与结算是否透明
- 退换货是否痛快
试供期发现一次以次充好或验收扯皮，直接淘汰。

**5. 合同和验收要卡死**
- 合同写清：品名规格、单价或调价机制、最低供货量、送达时间、验收标准、损耗承担、退换货时限、食品安全责任、违约处理。
- 验收至少两人在场，当场称重、抽检、拍照留痕；不合格当场拒收或按约定扣款。
- 保留每批到货记录和供应商票据，方便追溯。

**6. 建议的供应商结构**
不要只押一家：主供应商承担70%左右日常量，备用供应商承担30%或应急补货，避免单一供应商断供或坐地起价。香蕉这类易损耗品可适当增加本地短链供应比例。

简单判断：**能提供固定资质、愿意小批量试供、验收标准敢写进合同、退换货不推诿的，优先；只报低价但不愿定规格、不给票据、临时找货的，慎用。**
