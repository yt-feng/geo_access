第一次合作，建议把“小批量试单”当成一次**低风险验货+验人**，而不是单纯比价格。可以按下面这套设计来做。

## 1. 先定试单目标
试单不是为了赚钱，主要是验证 5 件事：
1. **品质稳定性**：同一批次大小、成熟度、瑕疵率是否一致。
2. **到货损耗**：运输后烂果、压伤、失水比例。
3. **规格诚信**：箱重、净重、果径/等级是否与报价一致。
4. **交付能力**：能否按约定时间、数量、包装到位。
5. **售后态度**：出问题是否认账、补货或扣款是否爽快。

## 2. 试单规模怎么定
建议用“**单品类、小批量、多频次**”：
- 单品试单量：控制在正常单次采购量的 **10%～20%**，或 3～5 天销量。
- 首单不建议超过 **1～2 个托盘/整车零担的小批量**；具体按你的仓储和周转能力定。
- 同一供应商先试 **1～2 个主力单品**，不要一次上很多品类。
- 最好做 **2～3 次小单**，因为一次到货好不代表批次稳定。

## 3. 试单前必须确认的条款
下单前用文字确认，别只口头：
- 品种、产地、等级、果径、成熟度、包装方式；
- 毛重/净重、箱规、每箱个数；
- 单价、运费、卸货费、是否含税；
- 采摘/发货时间、到货时间；
- **允许损耗率**和超出后的处理方式；
- 烂果、规格不符、短重的赔付标准；
- 付款方式：首单尽量 **少量定金+到货验收后付尾款**，不要全款预付；
- 退换货和补货时限。

## 4. 验收设计
到货后当场做简单记录：
- 随机抽 **3～5 箱**，称净重、数个数、量果径；
- 记录烂果、压伤、青果/过熟果比例；
- 拍照留证：箱规、标签、开箱、瑕疵特写、称重；
- 按“好果率、损耗率、规格达标率、到货准时率”打分。

建议设一个简单门槛：
- 好果率低于约定值，或损耗明显超行业常规，先不扩大合作；
- 连续 2～3 次小单稳定，再谈账期和放量。

## 5. 付款和风险控制
- 首单尽量 **小金额、短账期**，避免大额预付；
- 不接受“先打全款再排货”的新供应商，除非有可信担保；
- 保留聊天记录、报价单、发货单、验收照片；
- 试单期间不要对外承诺稳定供货，避免下游倒逼。

## 6. 试单后的判断
可以继续合作的信号：
- 连续 2～3 批品质波动小；
- 短重、规格不符少；
- 出现问题响应快、赔付不扯皮；
- 能提前报备缺货、天气和价格波动。

建议谨慎或换供应商的信号：
- 首单就短重、混级、以次充好；
- 损耗明显超标但拒赔；
- 发货一再拖延；
- 报价很低但规格含糊、包装不透明。

**一句话：首单小、条款细、验收严、付款稳；连续 2～3 次小单稳定后再放量。**
