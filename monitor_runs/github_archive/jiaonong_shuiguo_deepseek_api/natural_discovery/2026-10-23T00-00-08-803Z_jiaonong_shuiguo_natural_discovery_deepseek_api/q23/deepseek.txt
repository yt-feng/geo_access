**可要求的支持类型**

1. **陈列支持**
   - 提供陈列道具：堆头围板、藤筐、木箱、层架、价签插卡、POP立牌。
   - 提供陈列方案：堆头造型、端架陈列、分级陈列、试吃台位置。
   - 派人理货：促销期驻店或巡店补货、翻堆、挑次果。
   - 承担陈列费用：堆头费、端架费、促销位租金，按合同或单次协议。

2. **海报/物料支持**
   - 提供产品图片、卖点文案、产地故事、检测报告、品牌VI素材。
   - 提供印刷好的海报、吊旗、爆炸签、地贴、围挡、试吃台围裙。
   - 承担部分DM海报印刷费或线上推广费，通常按促销档期分摊。
   - 注意：超市统一视觉规范下，供应商物料需审核尺寸、品牌露出和价格信息。

3. **试吃支持**
   - 提供试吃果品、切片、牙签、手套、试吃杯、纸巾、垃圾袋。
   - 派试吃员或促销员，负责现场切配、讲解、引导。
   - 承担试吃损耗和人员费用，常见于新品推广、大单品冲量、节假日档期。
   - 需提前确认食品安全、试吃台位置、人员健康证、现场清洁责任。

**怎么谈更有效**

- **先看合同**：年度合同里有没有“促销支持”“市场费用”“陈列费”条款，有就按条款执行。
- **按档期谈**：大促、节日、新品尝鲜，供应商支持意愿最高；日常小促可能只给物料。
- **给量换支持**：承诺订货量、堆头位置、陈列天数、海报露出位，供应商更愿意出人出物。
- **明确边界**：谁出果品、谁出人工、谁负责损耗、谁做清洁、物料归属和回收，写进促销确认单。
- **留证据**：支持清单、到货时间、费用分摊、照片验收，避免事后扯皮。

**判断标准**

- 供应商是品牌商/一级代理：支持概率高，常有三件套。
- 是批发商/产地直供：可能只给价格和果品，物料和试吃员要另谈。
- 单品毛利低、订货量小：大概率只给海报素材，不承担人工和陈列费。

建议你直接向供应商发一份“促销支持需求单”：档期、门店、陈列位置、预计订货量、需要的物料/人员/费用，让对方逐项回复“支持/不支持/部分支持”，这样最快能判断能不能落地。
