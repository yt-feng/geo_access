# 小商家水果采购：现金结算 vs 月结账期风险对比

## 一、现金结算的风险

**1. 资金占用压力大**
水果是高频、短周转品类，每天/每批都要付现，现金流被持续占用。旺季备货、节日前囤货时，一次性现金支出可能压垮周转。

**2. 采购规模受限**
现金有限时只能小批量拿货，拿不到大批量的价格优惠，也难在行情低点囤货套利。

**3. 质量与数量纠纷的追偿难**
水果损耗、缺斤少两、等级不符很常见。现金已付后，让供应商补货、退款、换货的谈判筹码弱，容易出现"钱货两清、概不负责"。建议至少保留验货记录、称重单、照片，并在付款前完成验收。

**4. 假币、找零、现金保管与安全风险**
现金交易有收假币、找零错误、现金存放被盗等操作风险，尤其批发市场环境复杂。

**5. 无账期等于无信用记录**
纯现金交易不积累供应商信用，日后想谈账期反而没有合作基础。

**6. 缺票据、税务与对账隐患**
现金采购容易拿不到正规发票，进项抵扣缺失；手工记账易漏记、错记，月底对不上账。建议每笔现金采购都要收据/送货单签字。

**7. 采购人员舞弊风险**
现金结算环节多、可操作空间大，采购员虚报价格、吃回扣较难发现。

## 二、月结账期的风险

**1. 供应商信用风险（反向风险）**
你欠供应商的钱，供应商可能因自身资金链断裂突然断供，或在旺季优先供给现结客户，导致你缺货。水果供应断档对小商家是致命的。

**2. 价格与账期绑定，隐性成本高**
月结客户往往拿不到最低现价，供应商会把资金占用成本折算进单价。需核算：账期带来的资金便利是否大于单价上浮。

**3. 对账纠纷与"糊涂账"**
水果每天到货、损耗、退货、调价频繁，月结时容易出现对不上数量、价格争议、退货未冲减等问题。必须做到：每批送货单双方签字、当日验收、退货当场冲单，月底对账单逐笔核对后再确认。

**4. 集中付款的现金流冲击**
月底一次性付大额货款，若当月销售不佳或回款慢，会出现集中挤兑式资金压力。建议约定分次付款（如月中、月末各付一次）或按周对账。

**5. 逾期违约与关系恶化**
水果损耗高、退货多，若对账不清导致逾期，可能被停供、加收滞纳金，甚至影响后续合作与行业口碑。

**6. 依赖单一供应商的风险放大**
账期通常建立在长期合作上，容易形成单一供应商依赖。一旦对方提价、降质或断供，你切换成本高。

**7. 财务纪律松弛**
有账期容易"先拿货后算账"，采购量失控、库存积压、损耗上升，月底才发现亏损。

## 三、可执行的建议

- **混合策略**：核心畅销品用现金结算换取低价和优先供货；常规品用短账期（7–15天）平衡现金流，避免纯月结。
- **书面约定**：账期必须写清对账日、付款日、逾期条款、退货冲减规则、质量异议期限（如到货24小时内提出）。
- **单据闭环**：送货单、验收单、退货单三单齐全并双方签字，当日记账。
- **供应商分散**：至少保留2家可替代供应商，避免断供。
- **现金流红线**：账期付款额不超过当月预估回款的固定比例（如50%–60%），留足缓冲。
- **定期复盘**：每月对比"现结低价"与"账期高价"的实际总成本，动态调整结算方式。

一句话：**现金结算的风险在"钱出去后没保障"，月结的风险在"货进来后账算不清、钱集中压顶"**。小商家最稳的做法是短账期+严单据+多供应商，而不是二选一。
