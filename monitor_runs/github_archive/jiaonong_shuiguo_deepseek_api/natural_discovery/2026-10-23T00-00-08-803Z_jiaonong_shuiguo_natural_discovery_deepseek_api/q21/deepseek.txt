# 超市采购水果：供应商需提供的检测报告与进货证明

**一句话结论：** 超市索证索票的核心是“证照齐全 + 合格凭证 + 可追溯凭证”，水果属于食用农产品，法定最低要求是**营业执照、产地证明或购货凭证、合格证明文件（承诺达标合格证、检测报告或产地检疫等）**；检测项目和频次按风险自定，不必每批都全项检测。

## 一、法定必须索取的凭证（依据《食品安全法》第五十三条、食用农产品相关规定）

1. **供应商主体资质**
   - 营业执照（经营范围含食用农产品销售）
   - 若供应商是生产企业：食品生产许可证（水果制品才需要，鲜果一般不需要）
   - 若为进口水果经销商：还需海关/检验检疫相关证明

2. **进货凭证（证明来源合法、可追溯）**
   - 进货发票、送货单、购销合同或购货凭证（任选其一，需含品种、数量、日期、买卖双方）
   - 产地证明：如产地村委会/合作社出具的产地证明、种植基地证明

3. **合格证明文件（法定要求“合格证明文件”，形式可多样）**
   - **承诺达标合格证**（当前食用农产品最主要、最常见的合格凭证）
   - 供应商自检报告或委托第三方检测报告
   - 产地农业农村部门出具的检疫/合格证明（如柑橘类产地检疫证）

## 二、检测报告：按风险分级索取，不必一律全项

| 水果类型 | 建议索取 | 频次建议 |
|---|---|---|
| 常规鲜果（苹果、梨等） | 农残快检或定量检测报告 | 每批次或每月抽批 |
| 高风险品种（草莓、葡萄、叶菜类水果如圣女果） | 农药残留定量检测（GB 2763） | 每批或每季度 |
| 进口水果 | 入境货物检验检疫证明 | 每批 |
| 有投诉/抽检不合格历史的供应商 | 全项农残 + 重金属 | 加严频次 |

**检测项目重点：** 农药残留（按 GB 2763）、重金属（铅、镉等）、必要时真菌毒素。检测报告须由有 CMA/CNAS 资质的机构出具，且在有效期内、对应具体批次或品种。

## 三、超市内部要留的“票”

- 每批进货建立**进货查验记录**：供货者名称、联系方式、品种、数量、进货日期、凭证编号
- 凭证保存期限：**不少于产品保质期满后6个月；无保质期的不少于2年**（食用农产品按2年保存）

## 四、可执行的判断标准

- ✅ 能拿出“营业执照 + 进货凭证 + 承诺达标合格证/检测报告”三件套 → 基本合规
- ⚠️ 只有送货单、没有任何合格凭证 → 要求补，否则不建议进货
- ❌ 检测报告无资质章、批次对不上、过期 → 视为无效
- 进口水果无入境检验检疫证明 → 直接拒收

**提示：** 各地市场监管部门对食用农产品索证索票的具体格式（如承诺达标合格证样式、快检要求）可能有细则，建议以当地市场监管局最新要求为准，并可要求供应商随货附电子版凭证便于归档。
