供应商介绍时，少讲品种名和行业术语，多讲“你店里怎么用、卖给谁、能赚多少”。可按这个顺序说：

1. **先对位：替代你熟悉的哪个大品类**
   - “这个可以理解成‘菠萝的升级款/替代款’，吃法、切法差不多。”
   - 不要一上来讲品种名，先让商家有参照物。

2. **说清三件事：怎么卖、卖给谁、赚多少**
   - 怎么卖：整箱规格、单个克重、损耗、保存期、要不要冷藏、切开后能放多久。
   - 卖给谁：适合做果切、甜品店、火锅店免费水果、社区团购，还是高端礼盒。
   - 赚多少：给一个简单算账，例如“一箱多少个、进货价多少、按现在菠萝零售价卖，毛利大概多少”。

3. **用对比代替形容**
   - 不说“口感很好”，说“比普通菠萝甜、不扎嘴、不用泡盐水，顾客复购更稳”。
   - 不说“品质高”，说“坏果率多少、大小是否均匀、到店后挑果时间省多少”。

4. **主动说风险和适不适合**
   - 直接讲：“第一次别多拿，先拿一箱试卖；适合果切和甜品，不适合只做低价引流。”
   - 商家更信敢说缺点的供应商。

5. **给一张极简试卖卡**
   - 品名/对标品类
   - 规格：箱重、个数、单果重
   - 进货价、建议零售价、预估毛利
   - 保存方式和损耗
   - 适合场景
   - 最小起订量和试卖建议

一句话模板：  
“王老板，这个您就当‘更好卖的菠萝’来理解。一箱X个、每个X斤，进价X，按您现在菠萝的卖法，一个能多赚X块；不用泡盐水，适合果切和甜品店。先拿一箱试，卖不动我教您怎么调陈列。”

核心原则：**用商家已有认知做锚点，用算账和场景替代品种介绍，用小起订量降低决策压力。**
