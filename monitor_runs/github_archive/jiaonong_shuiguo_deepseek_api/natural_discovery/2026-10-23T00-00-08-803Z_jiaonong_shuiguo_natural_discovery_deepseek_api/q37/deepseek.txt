商超会员日水果活动要供应商提前配合，重点抓“货、价、陈列、履约、风险”五件事。可按下面清单推进：

**1. 提前锁定活动货量与货源**
- 按会员日预估销量给出分品项备货量，生鲜按日拆量，避免一次性压货。
- 确认产地/批次、到货时间、补货频次，明确“主推品+引流品+利润品”结构。
- 对易缺货单品准备替代规格或替代品种，防止断货影响活动。

**2. 价格与费用提前确认**
- 活动价、供货价、毛利空间、促销费用承担方式提前书面确认。
- 明确会员价/限时价/满减/买赠规则，避免收银端和价签不一致。
- 确认损耗、退货、临期处理的责任边界。

**3. 品质标准与验收标准**
- 提前给出糖度、规格、色泽、成熟度、瑕疵率等验收标准。
- 会员日流量大，建议适当提高到货成熟度可控性，避免“到店即软烂”。
- 明确拒收、换货、补货响应时限。

**4. 陈列与物料配合**
- 供应商配合提供堆头、端架、试吃台所需物料和陈列建议。
- 主推品提前做好分级包装，减少门店现场分拣压力。
- 价签、POP、试吃物料、溯源/产地信息提前到位。

**5. 物流与履约保障**
- 确认活动前1—2天到货窗口，避开门店补货高峰。
- 明确冷链/常温运输要求，水果防压、防冻、防闷。
- 准备应急补货车辆和联系人，会员日当天保持通讯畅通。

**6. 人员支持**
- 主推品安排促销员或试吃人员，提前培训话术和食品安全要求。
- 供应商业务员活动当天巡店，及时处理缺货、品质异议。

**7. 风险预案**
- 天气、交通、产地涨价、到货延迟的替代方案提前报备。
- 明确活动未达预期时的库存消化方案，避免节后集中退货扯皮。
- 食品安全资质、检测报告、进货票据提前备齐。

**建议落地节奏：**
- 活动前7—10天：确认品项、货量、价格、费用。
- 活动前3—5天：确认到货计划、物料、人员。
- 活动前1—2天：首批到货、陈列搭建、验收标准复核。
- 活动当天：供应商驻店/巡店，补货和异常处理。
- 活动后1—3天：复盘销量、损耗、缺货和退货。

最关键的是把**货量、价格、验收标准、补货响应、损耗责任**五项写成书面确认，避免会员日当天临时扯皮。
