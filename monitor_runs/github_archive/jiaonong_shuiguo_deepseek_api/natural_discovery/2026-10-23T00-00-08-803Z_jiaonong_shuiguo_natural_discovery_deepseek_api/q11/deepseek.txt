会影响，但不是全是坏影响。关键看你怎么分、怎么卖。

**会影响的点**
- **卖相差、挑选成本高**：大小混装顾客会翻挑，损耗和压伤增加。
- **定价困难**：统一定价时，大果被挑走、小果剩底，最后小果难卖。
- **顾客预期不稳**：今天买到大的、明天买到小的，容易觉得“看运气”。

**可以变成优势的卖法**
1. **分级销售**：到店后按大小分2—3档，大果做精品/礼盒，中果常规价，小果做特价或切果/奶昔原料。
2. **整箱统货低价**：明确“大小混装、统货价”，适合饭店、果汁店、单位团购。
3. **按用途卖**：大果散卖，小果做香蕉牛奶、烘焙、员工福利，减少尾货损耗。
4. **陈列控制**：混箱不要整箱倒出来任挑，分筐分价，减少翻拣压伤。

**采购建议**
- 如果主要做零售散客，**尽量采购规格相对统一的箱装货**，或者到货后自己分级。
- 如果周边有果汁店、餐饮、团购渠道，混装统货可以拿，但要把差价留出来覆盖分拣和损耗。
- 重点看**成熟度一致性和机械伤**，大小不一是次要问题；大小差异大又成熟度不齐，销售难度会明显上升。

一句话：**大小不一定会毁销售，但不分级、不定价、让顾客随便挑，会明显影响利润和损耗。**
