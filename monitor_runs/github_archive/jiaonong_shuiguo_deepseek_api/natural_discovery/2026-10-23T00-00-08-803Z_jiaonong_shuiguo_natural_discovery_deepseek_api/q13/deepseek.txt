做小区团购，水果供应商至少要能支持下面这几类服务，你可以按这个清单去谈：

1. **小批量、多频次供货**
   - 支持小起订量，最好能日配或隔日配。
   - 能按团购节奏分批次补货，避免一次压太多货。
   - 允许临时加单、减单，有明确的截单时间。

2. **分级与品控**
   - 能按规格分级供货，比如大小果、精品果、普通果分开报价。
   - 有坏果率承诺和售后赔付规则，比如坏果包赔、到货24小时内拍照理赔。
   - 能提供稳定样品，先试卖再放量。

3. **包装与分装支持**
   - 支持按团购份量预包装，比如5斤装、3斤装。
   - 能贴标签、按小区或团长分袋。
   - 包装成本、分装费要提前谈清楚。

4. **价格与账期**
   - 给团购专门报价，不是零售价简单打折。
   - 支持阶梯价：量小一个价，量大一个价。
   - 账期灵活：现结、周结、押一批结一批都可以谈，小水果店现金流紧，尽量别压太多押金。

5. **配送与履约**
   - 能送到店，最好也能支持送到小区自提点或团长处。
   - 明确配送时间、迟到怎么处理、损耗谁承担。
   - 节假日和旺季能不能保供，要提前确认。

6. **售后与损耗处理**
   - 坏果、烂果、缺斤少两的赔付标准要写清楚。
   - 支持补货、换货或直接退款。
   - 最好有专人对接售后，不要每次找不同的人。

7. **营销与素材支持**
   - 提供水果图片、产地信息、卖点文案、检测报告等素材。
   - 能配合做试吃、促销活动、爆品推荐。
   - 有新品或尾货时能提前通知，方便你做团购预告。

8. **结算与对账**
   - 每批货有清晰的对账单：品名、规格、数量、单价、金额、损耗。
   - 支持微信、支付宝、对公转账等常见方式。
   - 退换货和赔付能直接在货款里抵扣。

9. **稳定性与替代方案**
   - 主推品种断货时，能提前告知并提供替代品。
   - 有多个产地或备选供应商，避免单一品种断供。
   - 旺季能锁量，淡季不强制压货。

谈供应商时，重点先确认四件事：**小批量能不能送、坏果怎么赔、能不能按份分装、账期怎么结**。这四条谈清楚，小区团购的基本盘就稳了。
