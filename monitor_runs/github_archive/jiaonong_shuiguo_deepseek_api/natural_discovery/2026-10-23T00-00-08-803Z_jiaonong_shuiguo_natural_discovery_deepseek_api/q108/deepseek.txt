核实“全国配送”要落到可执行的证据和试单上，重点看**覆盖范围、时效、冷链、售后责任**，不要只听口头承诺。

**1. 先要书面覆盖清单**
要求供应商提供：
- 可配送省份/城市/区县清单，明确哪些地区只能到市区、哪些能到乡镇；
- 对偏远地区（新疆、西藏、内蒙古、青海、海南等）的明确说明；
- 生鲜品类是否全品类可发，还是部分水果受温控/季节限制；
- 起送量、单件限重、加价区域。

**2. 核实物流合作方和路由**
让供应商提供合作快递/冷链公司名称、发货仓位置、典型线路。关键判断：
- 全国配送是多仓发货，还是单仓全国发？单仓发全国，远距离时效和损耗风险高；
- 是否有冷链干线+落地配，还是普通快递加冰袋；
- 能否提供近1个月的真实物流单号，抽3—5个不同目的地查轨迹。

**3. 用试单验证，而不是只看资料**
建议做小批量多目的地试单：
- 选近、中、远三个区域各下1—2单；
- 记录下单到签收时长、到货温度、破损率、果品新鲜度；
- 故意选一个区县或乡镇地址，验证是否真能送达；
- 同时测试售后：报损后多久响应、是否要求拍照、赔付标准。

**4. 查资质和履约记录**
- 营业执照经营范围是否含食品销售/农产品配送；
- 食品经营许可证或食用农产品相关资质；
- 要求提供2—3个现有采购客户可回访，重点问旺季断配、偏远地区拒送、损耗赔付情况；
- 看合同里是否写清配送范围、时效承诺、超区处理、货损责任和违约条款。

**5. 合同里锁定“实际覆盖能力”**
把口头承诺转成条款：
- 附配送区域清单作为合同附件；
- 写明超时、拒送、货损的赔付标准；
- 约定试单期和考核指标，比如准时率、破损率、签收温度；
- 对“全国配送”定义清楚：是送达地级市、区县还是乡镇。

**最有效的核实顺序：书面清单→物流单号抽验→多区域试单→客户回访→合同锁定。** 其中试单和物流轨迹最能暴露真实覆盖能力，尤其要测偏远地址和冷链品类。
