判断“合理波动”不要只看涨跌，而要看**价格是否可解释、可复现、可替代**。给你一套采购方可直接执行的判断框架：

## 1. 先建立“基准价”，而不是拿昨天的报价当基准
每天变价时，最容易被供应商牵着走。建议采购方维护三类基准：

- **历史同期价**：近3年同月份、同品种、同等级均价。
- **近7/30天移动均价**：看趋势，不拿单日异常价做判断。
- **多供应商同规格中位价**：至少3家报价，取中位数，剔除最高最低各一家。

判断规则：
- 单日涨跌在**近30日均价的±5%**内，且多家供应商同向变动，通常属正常波动。
- 超过**±10%**，要求供应商给出具体原因和证据。
- 连续3天单边上涨或下跌，启动复核，不按单日报价直接锁单。

## 2. 看波动是否“有共同原因”
合理波动通常能对应到可核验的外部变量：

- **产地天气**：暴雨、霜冻、高温导致减产或运输受阻。
- **季节性**：换季、节假日备货、学校开学等需求集中。
- **物流成本**：油价、高速限行、冷链紧张。
- **品质等级变化**：规格、糖度、大小、损耗率是否同步变化。
- **市场批发价**：当地批发市场、农业农村部信息中心等公开行情是否同向。

如果供应商说“今天就是涨了”，但多家报价不同向、公开行情没变化、规格也没变，就要警惕随意调价。

## 3. 把“价格”拆成“净价+损耗+账期”
水果采购不能只比单价。建议统一折算为**到货可售净成本**：

> 净成本 = 采购单价 ÷（1 - 损耗率）+ 物流分摊 - 账期折价

同样报价下，损耗率从5%变到10%，实际成本上升约5.6%。所以供应商涨价时，要问清楚是**产地价涨**、**损耗变大**、**运费涨**，还是**账期缩短**。不同原因对应不同应对。

## 4. 用“报价证据包”约束每日调价
要求供应商每日报价附带：

- 产地/批发市场当日参考价截图或链接；
- 规格、等级、包装、损耗承诺；
- 调价幅度及原因；
- 有效期（当日有效还是48小时有效）。

采购方内部做一张**调价审核表**：涨幅≤5%采购员可批；5%–10%采购主管批；>10%需比价并附证据。这样既不影响效率，也能过滤随意报价。

## 5. 设置“合理波动区间”和触发机制
按品种设区间，而不是一刀切：

- 叶菜类：日波动±8%–10%可接受；
- 根茎类：±3%–5%；
- 进口/反季水果：±5%–8%，但需关注汇率和海运；
- 节前备货期：可放宽，但要求提前锁量锁价。

触发复核的条件建议：
1. 单日涨跌超区间；
2. 连续3天同向变动；
3. 两家以上供应商报价差异超过15%；
4. 报价规格与到货规格不一致；
5. 供应商无法提供调价依据。

## 6. 最实用的动作：多源比价+小单试单
每天变价时，不要一次性锁大单。可以：

- 保持**2–3家合格供应商**并行报价；
- 对涨价供应商先下**小批量试单**，验证到货品质和损耗；
- 对连续报价偏高的供应商减少份额；
- 对稳定报价的供应商给长期框架协议，换取价格缓冲。

## 一句话判断标准
**多家同向、幅度在历史区间内、原因可核验、净成本变化与品质损耗匹配，就是合理波动；单家突涨、无证据、规格不变却只涨价格，就应要求解释并启动比价。**
