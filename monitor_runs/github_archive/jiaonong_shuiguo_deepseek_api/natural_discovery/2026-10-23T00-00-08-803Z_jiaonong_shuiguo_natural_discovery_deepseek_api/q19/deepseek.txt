如果只选一个作为**经营上最该先关注的指标，是切果损耗**；但正确做法不是四选一，而是按“损耗→甜度→外观→大小”的优先级管理。

1. **切果损耗：第一优先**
   - 菠萝是典型的“带皮、带冠、去眼”后净果率差异很大的水果。进价看起来便宜，若净果率低、坏心多、熟过头，实际毛利会被吃掉。
   - 应重点看：整果到净果的出成率、黑心/水心/烂眼比例、切果报废率、当天切果售罄率。
   - 判断标准：同样售价下，净果成本低、报废少，才是真赚钱。损耗高的“大果便宜货”往往不如稳定中等果。

2. **甜度：第二优先，但要和成熟度、货架期平衡**
   - 甜度直接影响复购和试吃转化，但超市不是水果摊现切现卖，太熟会推高损耗。
   - 建议用糖度抽检+成熟度分级：即食切果用高熟度高糖度；整果销售用略低熟度、耐放批次。
   - 不要只追求“最甜”，要追求“在可售窗口内稳定够甜”。

3. **外观：第三优先，主要用于分级和减少客诉**
   - 外观影响陈列和选购，但不是越漂亮越好。重点看：果形端正、无明显烂斑、冠芽新鲜、果眼不过深、无机械伤。
   - 外观差但内部好的可转切果或促销；外观好但黑心风险高的批次要慎进。

4. **大小：最后优先，按客群和场景定**
   - 大小影响单价、客单和切果出成，但不是核心质量指标。大果不一定净果率高，小果不一定差。
   - 建议按场景分级：家庭整果偏中等、切果盒控制单盒克重、促销用大果引流但必须核算净果成本。

**可执行结论：**
- 采购验收：先看出成率和黑心率，再看糖度抽检，再看外观分级，最后按大小定售价和用途。
- 经营看板：每天盯“净果出成率、切果报废率、糖度合格率、外观客诉率”四个数。
- 如果只能改一个动作：**把菠萝按批次做出成率测试和用途分流**——好果整卖，熟果切果，外观差但内质好的做促销/切果，烂心高的批次直接拒收或降级处理。
