判断超市采购的苹果、橙子规格是否适合门店销售，核心不是看“大不大”，而是看**目标客群、陈列方式、定价带和损耗**是否匹配。可按下面执行。

## 1. 先定门店销售场景
先明确这批货卖给谁、怎么卖：

- **社区超市/生鲜店**：偏中等规格，家庭一次买几个，过大单价高、动销慢。
- **精品超市**：可接受中大果、外观一致性要求高。
- **水果专营/档口**：可分规格卖，大小差异容忍度更高。
- **线上到家/团购**：更看重单果重量稳定、份量标准化。
- **散称还是按个/盒装卖**：散称对大小容忍度高；按个卖必须规格整齐。

## 2. 苹果规格判断
不要只问“70、75、80”，要同时看**横径、单果重、果形和整齐度**。

可执行判断：

- **横径**：用分级板或卡尺抽检，记录主要区间，如70–75mm、75–80mm、80–85mm。
- **单果重**：随机称20–30个，算平均单果重和最大最小差。门店散称常见中等果更稳妥；礼盒/精品可选中大果。
- **整齐度**：一箱内最大最小横径差最好控制在5mm左右；超过10mm混装，散称可以，按个/礼盒不适合。
- **外观**：看果形是否端正、着色是否均匀、有无碰压伤、日灼、药斑、果锈。门店销售中，外观一致性比单纯大果更重要。
- **硬度与新鲜度**：抽切或手感判断，过软不适合长陈列。
- **等级匹配**：一级果做精品陈列，二级果做特价或散称，不要用二级果冒充精品规格。

适合门店销售的苹果，建议满足：**同一陈列批次横径集中、单果重稳定、无明显病伤、硬度可支撑计划陈列天数**。

## 3. 橙子规格判断
橙子要看**横径、单果重、皮厚、可食率、糖酸和果面**。

可执行判断：

- **横径**：用分级圈或卡尺抽检，记录主流区间。散称常见中果更利于家庭购买；礼盒可选中大果。
- **单果重**：随机称20–30个，看平均单果重和离散度。按个卖必须单果重稳定。
- **皮厚与可食率**：皮过厚、空壳感明显的不适合做高毛利精品；可抽几个切开看果肉饱满度。
- **果面**：看伤疤、油斑、青果、裂果、霉蒂。橙子表皮瑕疵在散称中可容忍一部分，但精品陈列要严控。
- **手感与新鲜度**：过轻可能失水，过软可能过熟或内部损伤。
- **糖酸口感**：抽样品尝，酸度过高不适合直接鲜食主推，可转促销或加工用途。

适合门店销售的橙子，建议满足：**同批次横径和单果重集中、果面干净、皮不过厚、无明显失水、口感可支撑定价**。

## 4. 到货抽检方法
每批到货按以下动作做，不要凭感觉：

1. **随机抽样**：每批至少抽3箱，每箱抽10–20个，避免只拿上层。
2. **测横径**：苹果用分级板/卡尺，橙子用分级圈，记录区间分布。
3. **称单果重**：算平均、最大、最小，判断是否适合按个卖。
4. **看整齐度**：最大最小差过大，降级为散称或促销。
5. **查伤损**：记录碰压伤、腐烂、裂果比例，估算损耗。
6. **对照陈列和定价**：若目标售价要求单果成本可控，过大果可能导致单价过高、动销下降。
7. **试销小批量**：新规格先小批量上架，观察2–3天动销、客诉和损耗，再决定复购。

## 5. 适合门店销售的简单标准
可以用这张判断表：

| 维度 | 适合门店 | 不适合门店 |
|---|---|---|
| 横径 | 同批次集中，符合目标陈列 | 大小混杂严重 |
| 单果重 | 稳定，适合散称/按个 | 同箱差异过大 |
| 外观 | 无明显病伤，整齐 | 碰压伤、裂果多 |
| 硬度/新鲜度 | 能支撑计划陈列期 | 过软、失水 |
| 定价 | 目标客群能接受 | 大果导致单价过高 |
| 损耗 | 可预估且可控 | 伤损比例高 |

最终建议：**先按门店销售方式定规格带，再用抽检数据验证整齐度、单果重、伤损和口感；新规格先小批量试销，用动销和损耗决定是否放量。**
