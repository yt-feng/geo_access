# 大型超市水果供应商的核心能力要求

## 一、食品安全能力

**1. 资质与认证**
- 营业执照、食品经营许可证（或食用农产品销售备案）
- 种植端：产地证明、农业投入品使用记录（农药、化肥）
- 优先具备：GAP（良好农业规范）、绿色食品/有机认证、ISO 22000 或 HACCP 体系认证
- 出口或高端渠道常要求 GlobalG.A.P.

**2. 农残与污染物管控**
- 具备或委托第三方检测能力，按 GB 2763（农药最大残留限量）批批检测或抽检，出具检测报告
- 重金属、霉菌毒素（如苹果展青霉素）等风险项目监控
- 建立农药安全间隔期管理和采收前检测放行制度

**3. 追溯体系**
- 从地块/批次→采收→加工→运输→门店的可追溯链条，能做到"一批一码"或批次台账
- 出现问题时能快速定位并召回（模拟召回演练）

**4. 采后处理与仓储卫生**
- 分选、清洗、打蜡（如允许）、包装环节的卫生控制
- 冷库温湿度监控、防虫防鼠、交叉污染防控
- 包装材料符合食品接触材料标准

**5. 人员与制度**
- 食品安全管理员、员工健康证、培训记录
- 供应商审核、不合格品处置、投诉召回流程文件化

## 二、物流能力

**1. 冷链能力（关键）**
- 预冷设施（差压预冷/水冷）——采收后快速降温是保鲜核心
- 冷藏车/保温车，全程温控记录（可导出温度曲线），不同品类分温区（如 0–4℃、8–12℃、常温）
- 冷库库容与周转能力匹配超市订单量

**2. 仓储与分拣**
- 具备分拣加工中心，能按门店/品类做标准化包装（如定量装、贴标）
- 先进先出（FIFO）和效期管理，减少损耗

**3. 配送时效与覆盖**
- 能满足超市要求的配送频次（如每日/隔日配）和到店时间窗
- 覆盖门店网络，具备多温区同车配送或分区配送能力
- 应对节假日、促销高峰的运力弹性

**4. 信息化与订单协同**
- 与超市系统对接（EDI/API），支持订单、库存、批次、温控数据回传
- 配送单据、检测报告随货同行或电子化

**5. 损耗与应急管理**
- 明确损耗率控制目标和责任划分
- 断货、质量异常、疫情/灾害等应急预案与替代货源

## 三、快速判断清单（尽调时可问）
1. 能否提供近 3 个月农残检测报告和批次追溯样例？
2. 冷链车是否有实时温度记录并可导出？
3. 预冷能力、冷库容量、日均配送门店数？
4. 是否有召回流程并做过演练？
5. 系统能否与超市订单/库存对接？

> 说明：以上为行业通行要求框架，具体门槛以各超市（如永辉、沃尔玛、盒马等）的供应商准入标准和国家/地方监管规定为准，签约前应索取其书面审核清单核对。
