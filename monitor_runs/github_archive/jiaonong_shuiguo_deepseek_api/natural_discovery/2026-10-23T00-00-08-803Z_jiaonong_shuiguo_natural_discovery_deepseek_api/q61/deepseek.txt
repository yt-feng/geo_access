判断香蕉批发供货方是否稳定，不能只看报价和口头承诺，建议按下面几项做可验证的筛选。

**1. 先确认对方是“一级”还是“二手”**
- 问清产地：是海南、云南、广西、老挝、越南、菲律宾还是厄瓜多尔；具体到县/合作社/包装厂。
- 问装货地点：是产地包装厂直发，还是某批发市场档口转手。能说出包装厂名称、装车地址、代办关系的，更接近一手。
- 要求看近期装车视频/照片：包装厂现场、装车单、车牌、装箱规格。只发网图的要警惕。

**2. 用“小单+多频次”测试稳定性**
- 先下2-3车小批量，不要一上来签长期大单。
- 观察是否连续按时到货、规格是否一致、损耗是否可控。
- 稳定供货的核心不是“有货”，而是**同一规格能持续复供**。青蕉/黄蕉、每箱净重、梳数、条数、催熟程度要写清。

**3. 查履约能力，不查嘴**
- 要求提供近1个月装车记录：日期、车牌、目的地、数量。能连续提供且可交叉核对的更可靠。
- 问高峰期（节假日、台风季、寒潮）怎么保供，有没有备用产地/冷库/车队。
- 问违约处理：延迟到货、规格不符、烂损超标怎么赔，能否写进简易合同或微信确认。

**4. 看资金和结算方式**
- 一手货源常见产地预付/装车付尾款；如果对方要求大额长期预付，风险高。
- 优先选“小定金+装车验货后付尾款”或“到货验收后结”的方式。
- 对公账户、营业执照、固定档口/冷库地址要核验；个人收款且频繁换号的慎用。

**5. 现场或视频验货**
- 看包装厂是否正常开工、冷库温度、香蕉成熟度、箱规是否统一。
- 随机抽箱称重、数条数，别只看上层。
- 问清运输方式：常温车/冷链车、到货时间、途中催熟风险。

**6. 看售后响应**
- 出现烂损、短斤少两时，对方是否愿意补货/扣款/下次抵扣。
- 稳定供货商通常敢给明确赔付标准；只推给司机或催熟房的要谨慎。

**简易判断标准：**
- 能说清产地包装厂、装车地址、近期装车记录；
- 愿意小批量试单并接受验收；
- 规格、损耗、赔付能写清；
- 结算不要求大额长期预付；
- 高峰期有备用货源和车队。

满足这5条，基本可视为“可测试的稳定供货方”；连续3-5次小单履约一致，再谈长期合作。不要仅凭“我是产地直发”“价格最低”判断。
