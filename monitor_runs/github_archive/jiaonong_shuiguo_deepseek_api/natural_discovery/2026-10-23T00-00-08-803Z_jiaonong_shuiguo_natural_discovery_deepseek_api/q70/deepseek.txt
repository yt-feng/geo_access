# 批发合同里的坏果责任条款写法

核心思路：**把"谁承担损耗、按什么标准判定、怎么赔、怎么举证"四件事写死**，不要只写一句"损耗由某方负责"。

## 一、先明确责任划分方式（二选一，别含糊）

**方案A：到货验收前风险归供方（推荐给批发商）**
> 货物在到达约定交货地点并经买方验收合格前，因腐烂、变质、挤压、冻伤、病虫害等造成的损耗，由供方承担。验收合格后风险转移至买方。

**方案B：约定合理损耗率，超出部分由供方赔**
> 双方确认本批货物合理自然损耗率为___%（按重量计）。到货验收时，损耗在合理损耗率以内的，由买方承担；超出部分由供方按超出数量的货款金额予以补偿/补货。

注意：鲜果类目合理损耗率一般按品类、季节、运输距离单独约定，别用一个数字套所有货。写"以双方书面确认的品类损耗率表为准"并附表格更好。

## 二、判定标准要可操作

- **验收时限**：写明"货到后___小时内完成验收"，超期未提出异议视为验收合格（保护供方，也倒逼批发商及时开箱）。
- **抽检方法**：约定抽检比例（如每车随机抽___箱/___%），按抽检不合格率推算整批，避免逐箱争议。
- **判定依据**：写明以什么为准——目测标准（霉变、软腐、裂口、明显压伤的面积/比例）、还是第三方检测。**最好附一份"坏果判定图示或标准表"作为合同附件**，这是最容易被忽略、也最能减少扯皮的一步。
- **争议时**：约定共同委托第三方（如当地质检机构/行业协会）鉴定，费用由责任方承担。

## 三、赔偿方式写具体

三种可选，建议组合：
1. **扣款**：按坏果重量×该品类合同单价从货款中扣除；
2. **补货**：供方在___日内补发等量合格货，运费由供方承担；
3. **退货**：坏果率超过___%（如10%）时，买方有权整批拒收或退货，供方承担往返运费及因此产生的仓储、滞销损失。

## 四、举证与通知

> 买方发现坏果应在验收期内以拍照/视频+书面（含微信、邮件）方式通知供方，说明数量与情形；供方应在___小时内到场或委托确认，逾期视为认可买方记录。

## 五、几条容易漏的补充

- **包装责任**：若因供方包装不合规（如未用透气箱、未加冰袋/保温）导致损耗，责任归供方，与运输环节无关。
- **运输责任衔接**：若由第三方承运，写明"运输途中损耗由___方先行向买方承担，再自行向承运人追偿"，避免供方和物流互相推。
- **不可抗力与温差**：极端天气、疫情管控等导致的大批量变质，单独约定处理方式，别混进一般损耗条款。
- **结算挂钩**：写明"损耗扣款在本次货款结算时直接抵扣"，否则事后追讨很难。

**一句话建议**：批发商立场，优先争取"到货验收前风险归供方 + 明确坏果率阈值 + 扣款/补货/拒收三选一 + 附判定标准附件 + 验收时限和通知程序"。这五条齐全，绝大多数坏果纠纷在合同层面就能定性。
