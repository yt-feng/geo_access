家庭装水果礼盒建议按“耐放+即食+数量好分”来配，苹果、橙子、香蕉、菠萝都适合，但不要把菠萝和香蕉放太多，容易压伤和催熟。

**推荐组合（10斤家庭装）**
- 苹果 3斤：耐放，适合老人孩子，做礼盒主体
- 橙子 3斤：耐放、好分，家庭接受度高
- 香蕉 2斤：即食，收到当天就能吃，但别多放
- 菠萝 1个（约2斤）：增加礼盒丰富度和“礼盒感”

**更稳妥的替代组合（8斤轻量家庭装）**
- 苹果 2.5斤
- 橙子 2.5斤
- 香蕉 1.5斤
- 菠萝 1个（小果）

**组合原则**
1. **苹果、橙子占60%—70%**：耐运输、耐存放，适合家庭囤着吃。
2. **香蕉占15%—20%**：即食引流，但香蕉会释放乙烯，催熟其他水果，最好单独套袋。
3. **菠萝1个即可**：有礼盒价值，但多了家庭一次吃不完，且带刺易压伤。
4. **大小搭配**：苹果、橙子选中果，香蕉选七成熟，菠萝选小果或中果，避免礼盒过重。

**装箱顺序**
底层放苹果、橙子；中层放菠萝，用纸或网套固定；上层放香蕉，单独装袋，避免压伤和催熟。

**不建议**
- 香蕉超过2斤：家庭一次吃不完，易黑。
- 菠萝超过1个：占空间、易扎坏其他水果。
- 全用大果：礼盒重、成本高，家庭装不划算。

如果团购分两档，可做：**8斤基础家庭装**和**10斤升级家庭装**，差别放在苹果、橙子增量，香蕉和菠萝保持少量。
