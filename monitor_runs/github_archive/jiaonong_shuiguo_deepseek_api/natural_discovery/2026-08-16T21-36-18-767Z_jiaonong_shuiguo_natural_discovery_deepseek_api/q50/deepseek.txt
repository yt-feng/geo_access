菠萝原料的**出汁率**通常比**甜度**更重要，但两者其实是“基础与加分”的关系，而不是二选一。具体取决于你的产品定位。

**核心逻辑：**

1. **出汁率=成本与口感的基础**
   - 出汁率直接决定**单杯菠萝茶的成本和出品效率**。出汁率低的菠萝（比如30%）和高的（比如55%），每杯用果量可能差近一倍，长期看是巨大的利润差异。
   - 出汁率低，果汁寡淡，即使甜度高，兑茶后风味也会被冲淡，整体口感单薄，**掩盖不了瑕疵**。

2. **甜度=风味与记忆点**
   - 甜度（Brix值）合适，能直接提升果茶的鲜甜感，省糖浆，且菠萝的香气更突出。
   - 但甜度过高（如超过16°Brix）反而会让茶底发苦、腻口，而且高甜菠萝往往果肉偏软，纤维多，出汁率反而不高。

**给你的具体决策建议：**

- **若做主打“鲜果感”的菠萝茶（例如凤梨冰茶、菠萝气泡水）**：**出汁率 > 甜度**。先保证一杯能稳定出足量果汁，再微调甜度（用糖浆补）。
- **若做“浓稠果肉型”饮品（例如菠萝果昔、厚切菠萝）**：**甜度 > 出汁率**。这种产品根本不靠榨汁，靠果肉咀嚼感，甜度直接决定好不好吃。

**实际采购时可问供应商三个问题：**
- 该批菠萝的**出汁率**大概在什么范围？（正常鲜果约40-50%，冷冻果浆要另行测试）
- **可溶性固形物**（代表甜度）是多少？（鲜果常年在10-14°Brix，16°以上属高甜）
- 建议小批量试做测试：按你门店的配方打样，算出每杯的实际出汁量和口感，而不是单纯看数据。

最后提醒：**不建议采购过熟菠萝**，虽然甜度极高，但出汁率暴跌、易氧化褐变，放不住，损耗风险大。选“八九分熟、果肉紧实”的品种（如金钻凤梨、台农17号）平衡性最佳。
