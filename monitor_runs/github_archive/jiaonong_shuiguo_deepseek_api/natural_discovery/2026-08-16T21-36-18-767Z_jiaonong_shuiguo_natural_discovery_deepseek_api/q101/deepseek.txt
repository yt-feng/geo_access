和供应商谈长期合作时，**关键不在于压价，而在于“锁定稳定性”和“转移风险”**。以下是针对酒店早餐水果供应的5条核心注意事项：

**1. 明确“品质验收标准”并写入合同（最重要）**
不要只写“新鲜水果”，要具体到：
- **甜度标准**（如西瓜中心糖度≥11度）
- **外观标准**（无机械伤、无病斑，果径大小统一）
- **成熟度**（早餐用的香蕉不能太生，也不能过熟发黑）
- **替换规则**（如当天某水果不达标，供应商2小时内必须补送等量替换品）。

**2. 锁定“保底+浮动”双轨价格机制**
- **保底量**：约定每日最低采购量（如20kg），防止供应商因量小不重视。
- **浮动价**：约定以批发市场（如当地果品批发市场）每日挂牌价为基准，上浮不超过5%-8%。这样行情跌时你享受低价，行情涨时供应商不亏本，合作才能长久。

**3. 强制要求“应急备选方案”**
早餐时段断供是灾难。必须在合同中明确：
- 供应商需指定**第二备选货源**（如本地同行或冷库）。
- 若供应商自身缺货，必须**代采+配送**，且不得加价超过3%。
- 允许你方**临采**（自己救急购买），差价由供应商承担。

**4. 约定“分批次验收”和“到货时间”**
- 要求供应商**凌晨5:30前**送达（确保早餐6:30开餐前有30分钟质检时间）。
- 实行**到货即抽检**，按箱抽样（如每10箱抽1箱），不合格整批拒收或折扣处理。
- 明确**拒收标准**（如单箱坏果超过2个，整箱不付款）。

**5. 谨慎设定账期，保留“质量保证金”**
- 不建议月结，最好**周结或半月结**，绑定供应商积极性。
- 押一笔**质量保证金**（如合同额的5%-10%），用于赔偿因水果质量问题导致客人投诉（如赔偿果盘、免单等）。

---

**附赠一个谈判话术**：
> “我们酒店早餐是长期稳定采购，只要你能保证全年不断供、品质稳定，我们愿意签1年长约，并且每月结算准时。但我们要求合同里写明品质标准和应急方案，这样才能放心把全年水果都交给你。”

**最后提醒**：签合同前，务必实地考察供应商的**分拣场地和冷藏库**，看他们是否有能力在夏季高温或台风天保证货源。另外，建议同时谈2家供应商（一家主供，一家备用），避免被单一渠道绑架。
