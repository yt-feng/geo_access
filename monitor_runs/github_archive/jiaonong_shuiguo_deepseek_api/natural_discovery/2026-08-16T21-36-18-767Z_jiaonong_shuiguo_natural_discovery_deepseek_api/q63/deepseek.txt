判断批发商卖菠萝时哪个规格更容易出货，**核心原则是“效率优先 + 损耗最小 + 匹配客户群体”**，而不是单纯看价格或大小。可以从以下几个维度精准判断：

### 1. 看你的下游是谁（渠道决定规格）
- **水果店/社区团购（零售终端）**：通常走**“小果或中果”**（单果重1.5-2.5斤，带冠或者免冠）。因为零售客户通常一次买一个，小果单价低，试错成本低，损耗小，出货快。
- **餐饮连锁/果汁店/食堂**：走**“大果”（单果重3斤以上）**。因为出肉率高，榨汁或做菜划算，且这些渠道一次采购量大，不在乎单个大小。
- **批发市场档口（同行调货）**：走**“统货”（大小混合）**或**“中果为主”**。因为批发商自己回去会分级，统货价格低，利润薄但走量大。

**判断口诀：零售要小甜，餐饮要大肉，同行要统货。**

### 2. 看损耗速度（水果的特殊性）
菠萝是**呼吸跃变型水果**，常温下2-3天就会过熟变质。判断规格时，先看你手头的库存周转天数：

- 如果**周转快（3天内能清完）**：所有规格都可以大胆进，主打**中果**（因为中果受众最广）。
- 如果**周转慢（超过5天）**：坚决只进**小果**。因为小果单个损耗金额低，即使卖不完扔掉，损失也可控。**大果一旦烂心，单果损失是大果的2倍以上**。

### 3. 看季节和行情（市场风向）
- **旺季（4-6月）**：菠萝大量上市，价格低，消费者追求“吃个新鲜”，**小果和中果出货最快**，大果反而滞销。
- **淡季/反季（秋冬）**：菠萝价格高，消费者更愿意买大果“有面子”或“划算”，此时**大果更好走**。

### 4. 实操验证法（最快判断方法）
**不要凭感觉，直接做小范围测试：**
- 同一批货，分两筐：一筐以**小果和特小果为主**，一筐以**大果为主**。
- 定价策略：小果价格低2-3毛/斤，大果价格高2-3毛/斤。
- **观察24小时内的翻单率**：如果小果筐先见底，说明市场接受小规格；如果大果筐先走，说明走大果。

**特别提示：** 菠萝的“冠”（顶部叶子）是最大的隐藏损耗，很多批发商会选择**“去冠发货”**（切掉顶芽）来增加单箱净重和出肉率。如果你的客户是餐饮，强烈建议只进“去冠大果”；如果是零售水果店，保留“带冠小果”反而更有卖相，因为顾客喜欢看叶子新鲜度。

---

**最终结论**（按概率排列）：
1. **中果（2-2.5斤）是万金油**，除非你有明确的餐饮大客户，否则优先做这个规格。
2. 如果你手里有大量餐饮客户，直接做大果（3斤以上）去冠。
3. 如果不是旺季，且你资金有限，宁可只做小果保周转，不要囤大果赌行情。
