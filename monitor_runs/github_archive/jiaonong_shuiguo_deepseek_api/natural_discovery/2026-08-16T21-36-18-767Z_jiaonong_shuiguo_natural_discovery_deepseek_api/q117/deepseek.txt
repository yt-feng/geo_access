对于水果新品，建议采用**“小批量试卖”**策略，具体数量根据门店/渠道规模和受众风险来定。以下是实操建议：

**核心原则：以周为单位，按日销量预估，少量多次。**

**1. 门店/档口试卖（线下）：**
- **起步量**：**1-2箱**（约10-20公斤，视单品大小而定）。目的不是赚钱，而是测试**口感、损耗、顾客反馈**。
- **测试周期**：**3-7天**。如果3天内复购率低或损耗超15%，及时止损。
- **补货节奏**：如果周销量稳定在**日均5-10份**以上，可加量至3-5箱；否则维持原量。

**2. 电商/社群/小程序（线上）：**
- **预售模式**：**先预售，后采购**。设定**50-100份**（小规格装）作为测试上限，避免压货。
- **数据指标**：看**转化率**（浏览→下单）和**退货率**。转化率<2%或退货率>5%，暂不追加。

**3. 多门店/连锁（区域性）：**
- **选择2-3家代表性门店**（如人流高、低各一），每家投放**20-30份**。
- **对比测试**：同时上架，比竞品价格低10%-15%，观察**周转天数**（最好<3天）。

**4. 关键硬指标（低于任一即停）：**
- **毛利贡献**：试卖期间毛利至少覆盖**损耗+促销费用**。
- **动销率**：线下**>70%**（7天内卖完7成）；线上**>60%**。
- **售后率**：因品质问题产生的退款/换货<**5%**。

**风险提醒：**
- 如果供应商表示“必须整批采购才给批发价”，**坚决拒绝**。应争取“试单不享受优惠，但可分批发货”的条款。
- 如果新品是**进口/反季高价品**，试卖量再砍半。

**总结建议计划：**
> 首周：线下1箱 / 线上50份预购
> 第二周：根据动销率决定**翻倍、持平或清仓**
> 第三周：若连续两周动销>70%，可签正式购销协议。

**一句话：先卖一周，卖不动就撤，至少不会压死现金流。**
