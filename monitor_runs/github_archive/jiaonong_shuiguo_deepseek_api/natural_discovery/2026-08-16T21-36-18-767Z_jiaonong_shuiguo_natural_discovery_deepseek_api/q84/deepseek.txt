针对家庭水果礼盒，**建议以“耐放+好吃+颜值高”为标准**。下面给出一套实用组合方案和搭配逻辑，您可以直接拿去用。

**一、推荐组合（4选3或4选全）**

- **经典家庭款（实惠耐放）：** 苹果（4-6个，红富士/花牛）+ 橙子（4-5个，赣南脐橙）+ 香蕉（1把，约6-8根）。
  - 理由：苹果和橙子常温可放一周，香蕉散装（不闷盒）提鲜，成本低，人人爱吃。

- **颜值升级款（适合送礼）：** 苹果（2-3个，带红润）+ 橙子（3-4个，颜色亮）+ 菠萝（1个，带叶）+ 香蕉（半把，折着放）。
  - 理由：菠萝顶部绿叶能撑起整个礼盒的视觉效果，一看就贵；但注意菠萝需当天吃，且会催熟其他水果，要单独用纸隔开。

**二、家庭组合的三个“雷区”及处理**

1. **香蕉必须“露头”** — 不要密封在礼盒里，否则闷两天就发黑。建议香蕉单独用保鲜膜裹柄部，斜放在最上层，或者礼盒开透气孔。
2. **菠萝别生切** — 如果盒子里放菠萝，顾客回家需要自己削皮，容易劝退。可以提前帮顾客削好切块（用保鲜盒分装），或者明确标注“需自行处理”。
3. **苹果橙子“垫底”** — 重的放底层，菠萝放中层固定，香蕉/盒装切块放最上层，防止压坏。

**三、给您的团购定价参考（可自行调整）**

- **基础家庭装（3种）：** 苹果2斤 + 橙子2斤 + 香蕉2斤，定价在 **49-69元** 比较好卖（看您的进货价）。
- **豪华家庭装（4种：含菠萝）：** 上面基础上加1个菠萝和1个切块拼盘，定价 **79-99元**，适合走量或节日档。

**四、运营小建议（针对团购）**

- 在详情页写清“**香蕉需冷藏？不需要，阴凉处即可**”，减少售后咨询。
- 如果菠萝是整果，务必送手套和小刀纸条，或者直接提供“**代切服务**”，预约自提时免费切。
- 主推“**一周家庭食用周期**”：苹果橙子能放，香蕉先吃，菠萝最后吃（熟透了更甜）——这样好吃且不浪费。
