给批发商供货时，香蕉和菠萝的分级报价建议按“品质等级”和“包装规格”分开列，避免含糊。以下是具体建议框架，可直接套用：

---

### 一、香蕉分级报价（按成熟度和外观）
| 等级 | 标准 | 参考报价示例（元/斤） |
|------|------|----------------|
| **一级果（A级）** | 果形直、无斑、无黑头、成熟度适中（七成熟），单把整齐，无机械伤 | 2.8 - 3.2 |
| **二级果（B级）** | 略弯曲、有少量花皮（不影响食用），成熟度偏差，允许轻微擦伤 | 2.2 - 2.6 |
| **次果/尾货果** | 有严重粘连或黑斑，但果肉完好，可降级批发 | 1.5 - 1.8 |

**报价补充说明：**
- 如果按“箱”报价，请注明每箱净重（如18斤/箱），并说明是否含纸箱重量（通常除皮）。
- 成熟度必须写清楚，例如“七成熟，约3天后软熟”“全熟，需当日销售”，因为小店对成熟度非常敏感。

---

### 二、菠萝分级报价（按个头和损伤）
| 等级 | 标准 | 参考报价示例（元/个） |
|------|------|----------------|
| **特级果** | 单果重1.5-2斤，果眼平整，无裂痕、无软烂，顶部绿叶完整 | 3.5 - 4.0 |
| **一级果** | 单果重1.2-1.5斤，允许1-2处轻微碰伤（不腐烂），绿叶有磕损 | 2.8 - 3.2 |
| **二级果** | 单果重1斤以下，或果眼过深、有轻微褐变，可去皮销售 | 2.0 - 2.5 |

**报价补充说明：**
- 菠萝按“个”报价比按斤更常见，因为小店方便零卖定价（如每个卖6元）。
- 注明“带叶”还是“去叶”，带叶重更重，但小店往往要求带叶（美观），损耗算批发商还是零售店需提前约定。
- 如果按“件”发货（如每件9个），需说清件内允许有几个二级果，避免扯皮。

---

### 三、报价单模板（可直接发给小店）
```
【今日香蕉报价】
A级香蕉 3.0元/斤（18斤装，550克/把，约7成熟）
B级香蕉 2.4元/斤（散装，可隔天熟）
尾货香蕉 1.6元/斤（需当日处理）

【今日菠萝报价】
特级菠萝 3.8元/个（带叶，平均1.6斤/个）
一级菠萝 3.0元/个（轻微碰伤，次日卖需削皮）
二级菠萝 2.2元/个（需加工，或可切块卖）

价保：当日到货48小时内，如全黑/腐烂按数量退差价。
```

---

### 四、关键提醒
1. **避免“统货价”**：统货价容易导致小店对好坏果闹矛盾，建议至少按两个等级。
2. **注明“干心”/“黑心”**：菠萝在产季末期容易黑心，报价时必须写明“无黑心”或“有黑心风险降价”。
3. **每日报价更新**：香蕉菠萝价格波动大，建议每天上午发一次报价，附实物图（拍一张分级对比图片），信任度更高。
4. **退换条款**：明确“当场验货，离店不换”，避免因成熟度问题反复纠缠。

如果小店量小，可简化为“现货两挑”：A级当前价、B级当前价，不再细分，但一定要配上照片。
