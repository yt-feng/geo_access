判断水果批发市场里香蕉的熟度和坏果风险，主要靠**看、摸、闻、问**四个动作。以下是具体的执行建议：

**一、判断熟度（催熟程度）**

香蕉在产地一般是青皮硬果（7成熟）采摘，到批发市场时，通常已经过催熟库处理。判断标准如下：

1. **看颜色（最直观）**：
   - **全青皮**：未催熟或刚出库，放几天才能熟，适合零售备货（如果自己单次拿货量少，需要等3-5天才能卖）。
   - **青黄相间（果柄泛黄）**：正合适，约7-8成熟，常温下2-3天会全黄，适合拿去做日常销售。
   - **全黄无斑**：9成熟，当天或次日就要卖完，否则容易熟透烂果。
   - **起黑斑（梅花点）**：熟度已高，口感最甜，但保质期极短（1天内），除非有稳定快销渠道，否则不建议批发拿。

2. **摸硬度（辅助）**：
   - 用手轻捏香蕉**中段**（不是两头），如果硬实且有弹性，说明内部淀粉未完全转化，比较抗放。
   - 如果捏起来发软、发面团感觉，说明内部已熟透，风险高。

**二、判断坏果风险（核心看“果柄”和“擦伤”）**

批发市场里坏果主要来自**炭疽病（黑星病）**和**机械损伤**，这两类最致命：

1. **重点检查果柄（香蕉把头）**：
   - 拿起一把香蕉，看**果柄切口**是否发黑、发霉、渗水。健康的果柄切口是白绿色或淡褐色，干燥的。
   - 如果果柄发黑且潮湿，说明已经开始腐烂，会迅速传染整把。

2. **翻看内层果（最容易被骗）**：
   - 批发市场的外层香蕉通常光亮，但内层（贴着纸箱或泡沫的）容易积压受损。**必须让老板翻开两把重叠处**，或者自己抽查底下几层。
   - 重点看有没有**压伤**（褐色凹陷）、**裂口**（表皮裂开，极易招细菌）。

3. **闻气味**：
   - 正常香蕉是淡淡的清香味。
   - 如果闻到**酒味**或**酸腐味**，说明果肉已发酵变质，坚决不拿。

**三、关于风险的执行建议**

- **优先选“青黄相间”的**：这是最稳妥的选择，留有余地，卖不完还能放2天。
- **不要贪图便宜拿“处理价”**：很多特价香蕉是挑出来的尾货、掉把货，坏果率极高，看似便宜，实际损耗吃掉利润。
- **切开抽查法（对超大订单）**：如果你拿货量大（几百箱），可以要求老板开1-2箱，**随机抽一串，用刀对半切开香蕉中部**，看果肉颜色。如果果肉发白、发硬，说明成熟度不够；果肉发黑、透明、流水，说明内部已坏。
- **确认冷链和到货时间**：问老板这批货是**昨天到**还是**今天早上到**，拿货时间越靠近到货时间，内部热损伤越小（香蕉怕闷热，箱内温度高会加速催熟）。

**最终决策公式**：
- 熟度 = （颜色70% + 硬度30%）
- 坏果风险 = 果柄状态 50% + 内层压伤 30% + 气味 20%

**如果时间紧，只看一个指标**：**翻开最底下的两箱，摸里面的果柄是否发黑、捏果实是否过硬/过软**。这一项基本能看出整批货的状态。
