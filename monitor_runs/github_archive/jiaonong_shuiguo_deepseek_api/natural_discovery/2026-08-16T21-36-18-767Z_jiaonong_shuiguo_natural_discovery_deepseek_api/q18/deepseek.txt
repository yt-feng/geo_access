在超市采购香蕉时，想避开“太生”或“太熟”的情况，可以参考以下实用方法：

**1. 看颜色梯度（最直接）**
- **太生**：表皮整体是**深绿色**、硬度很高，捏起来像石头，几乎没有香味。这种一般是刚下树，淀粉未转化为糖，买回家需放3~5天才能熟透。
- **太熟**：表皮出现**大面积黑斑**（俗称“芝麻点”）、果肉已经软塌甚至流水、有酒味。这种口感过软，且可能内部发酵变质。
- **适中目标**：挑选**黄中带许青绿色**（边缘或尖端微绿）、整体**黄亮**的香蕉。这种在常温下1~2天刚好成熟，适合当天或隔天食用。
- 若想**多放几天**：选黄中带绿、摸起来微微发硬的；若想**今天吃**：选全黄、表皮有**零星小褐点**的（此时甜度最高，但需当天吃完）。

**2. 摸硬度（辅助判断）**
- 轻轻捏香蕉中部（避开两端）：
  - 太生：硬实，按压无凹陷。
  - 太熟：过度软塌，指甲轻轻一按就陷进去。
  - 适中：有轻微弹性，按下去能回弹，但不会立刻凹陷。

**3. 看柄部（不要忽略）**
- 香蕉柄部（连接果串的地方）如果**发黑、干枯**，说明存放较久，内部可能过熟；如果**绿色且湿润**，较新鲜。
- 同一串香蕉，**中间部分通常比头和尾更生**，可结合需求选择位置。

**4. 闻气味（辅助）**
- 凑近闻香蕉柄部：有浓郁香蕉果香的，通常已接近成熟；几乎无香味的，偏生。

**5. 避坑技巧（关键）**
- **不要买外表无伤但两端挤压变形**的，内部可能已淤伤。
- 如果是**盒装或装袋密封**的香蕉，避免购买（透气差，容易擦伤并快速熟烂）。
- 优先挑**单个散装**、让人可以直接拿的香蕉，而不是提前装好的礼盒（礼盒常混入过熟或生果）。

**6. 如果买回后仍需调整**
- 太生：放到室温，与苹果/熟番茄放一起（释放乙烯），1~2天催熟。
- 太熟：当天吃完，或剥皮冷冻做冰沙/烘焙，不要继续常温存放。

**总结口诀**：
> **买黄中带绿，按着有弹性；**
> **不选全青硬，不选黑斑软；**
> **当天吃选带小点，久放选微绿。**

注意：超市里颜色均匀黄亮的香蕉有时是人工催熟，可能甜度不足，但只要按你所需存放时间选即可。
