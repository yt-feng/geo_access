超市与水果供应商之间的账期（即从收到货到付款的时间）常见天数因超市规模、采购模式、水果品类及地区而异。以下是一般情况：

1. **大型连锁超市（如沃尔玛、家乐福、永辉）**：通常账期为 **30天至60天**，部分大卖场甚至可延至90天，但需供应商有较强资金实力或长期合作基础。
2. **中型超市或区域连锁**：常见账期为 **15天至30天**，更灵活，但水果易腐烂，有时会缩短至7-15天以换取价格优惠。
3. **小型超市、社区店或生鲜电商**：账期可能仅 **7天至14天**，或采用“货到付款”、“隔日结”模式，因水果保质期短，风险高。
4. **季节性水果（如荔枝、樱桃）**：可能采用“预售制”或“现结”，账期极短，甚至当天结算，以保障新鲜度。

**建议**：
- 若您是超市方，初次合作可先谈30天账期，后续根据供货质量、销量和退货率调整。
- 若您是供应商，提出15-20天账期较合理，或要求“月结15天”（即次月月中付款），并争取预付定金以降低风险。
- 务必在合同中明确“定期对账、退货条件、逾期利息”等条款，避免纠纷。

具体天数需结合双方议价能力、水果入仓损耗率及市场行情灵活协商，不用拘泥于固定值。
