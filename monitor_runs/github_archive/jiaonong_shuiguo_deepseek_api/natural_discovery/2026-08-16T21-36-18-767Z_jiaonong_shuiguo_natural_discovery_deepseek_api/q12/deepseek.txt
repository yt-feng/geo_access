在水果店经营中，菠萝损耗高主要是两个原因：**买回来太生（放不熟、酸涩）** 或 **买回来太熟（容易烂）**。

采购时判断熟度的核心目标是：**到店后能放置2-3天，刚好达到最佳食用期**。以下是根据实操经验的判断标准：

**1. 看外观颜色（最直观）**
- **太生（别买）**：表皮整体呈青绿色或淡黄色。这种菠萝内部糖分未转化，买回来放冰箱会僵掉，放常温也很难变甜。
- **刚好（推荐）**：表皮从底部向上呈**橙黄色或金黄色**，但顶部叶丛附近还带点青绿色。这表示成熟度约7-8成，到店放2天刚好全熟。
- **太熟（不要囤）**：表皮全部深黄甚至发红，果眼（菠萝钉）凹陷明显，按下去发软。这种当天不卖完必定烂。

**2. 闻气味（重点技巧）**
- 拿起菠萝，**凑近果柄底部闻**。如果闻到浓郁、甜蜜的果香，说明糖度已上来，适合零售。
- 如果没有任何香味，说明成熟度不够；如果有**酒味或发酵味**，说明已经开始变质，果断放弃。

**3. 按果肉硬度（判断损耗速度）**
- 用手轻按菠萝中部（避开果眼）：
  - **硬邦邦**：太生，顾客买了可能投诉“酸”。
  - **微微有弹性，按下去能回弹**：这是最佳进货状态。
  - **一按一个坑**：过熟，进回来很可能当天切开来就已经发软、流水。

**4. 看底部果心（判断新鲜度）**
- 翻过来看底部的“果脐”（切开的小圆点）：
  - 干燥、颜色白或淡黄 → 新鲜。
  - 发黑、发软、有水渍 → 内部可能已开始溃烂，买回去损耗极高，哪怕表面好看也别拿。

**5. 重量感（辅助判断）**
- 同等大小，**拿起来手感沉的**水分足，口感好；**轻飘飘的**可能是放置时间久、水分流失，切开后肉质干柴。

---

**给水果店老板的采购建议：**
- **不要只买一种熟度**。建议混搭采购：**20%偏生（7成熟）、60%刚熟（8-9成）、20%全熟（当天必卖）**，这样可以错开销售节奏，减少积压。
- **到货后立即分级**：全熟的放冷藏展示柜（4℃左右）不影响口感，生一点的放常温通风处催熟。
- **如果店里有切果服务**，收购偏熟或微瑕疵的菠萝（只要没碰伤），去皮切块卖，利润更高且损耗可控。

**一句话口诀：买黄中带青、底部闻香、按着微弹、底部果脐干燥的。**
