为社区超市选择每日配送的水果供应商，建议重点考察以下六个方面，优先选择能直接签约、有稳定货源、且服务响应快的合作方。

**1. 果品新鲜度与分拣标准（核心）**
- **看分拣环节**：供应商是否在产地或批发市场有分拣仓，能否按“次日到店”标准（如7-8成熟）发货，避免全熟果在运输中损耗。
- **要求试供**：先签3-5天试供，每天到货后抽检坏果率，建议控制在**3%以内**（高档水果1%以内）。
- **关注品类结构**：应包含每日刚需的**基础品类**（苹果、香蕉、橙子）和2-3款**高毛利引流品**（如草莓、阳光玫瑰），且能随季节调整。

**2. 配送时效与稳定性**
- **明确到货时间**：必须承诺**每日固定时段**（如早6：30前）到店，避免影响早市陈列。
- **确认冷链接力**：从产地/分拣仓到店全程冷链记录是否可查，夏季尤其重要。
- **应急响应**：要求提供**2小时补货机制**（追加订单）或坏果“次日赔付”条款。

**3. 价格与结算模式**
- 对比**批发市场价**（如北京新发地、广州江南市场）作为基准，要求日价随行就市，且**剔除包装箱重量**（业内常按净重结算）。
- 优选**周结或月结**合作，避免压款；警惕明显低于市场价20%以上的“促销陷阱”（可能混入次级果）。

**4. 资质与合规（硬性门槛）**
- 要求提供**营业执照、食品经营许可证**（含水果批发）、**产地证明**（如农产品合格证）。
- 进口果需有**海关检疫单**，国产果有**农残检测报告**（至少每月更新）。

**5. 售后与损耗承担**
- 明确**到店验收标准**：当场开箱抽检（每箱抽3-5个），次品当场折价或拒收，拍照留证。
- **损耗率协议**：按日配送的常规损耗（碰伤、软烂）由供应商承担，人为损耗（积压过期）由超市负责。

**6. 实地与口碑验证**
- **看仓库**：检查其分拣仓是否整洁、库存周转快慢（周转快说明新鲜）。
- **问老客户**：索要2-3家合作超过半年的社区超市联系方式（可公开的），直接电话问“配送迟到率、换货效率”。

---

**落地建议（可执行步骤）：**
- **第1步**：本地**批发市场**主动找2-3家有“日配送”服务的档口，谈判能力更强。
- **第2步**：在**美团/京东买菜**等平台的供应商后台看“产地直供”合作入口（部分有B端）。
- **第3步**：加入本地“社区超市老板群”问同行口碑，优先选“同行推荐”的供应商。

⚠️ **重要提醒**：不要只看“最低价”，每日配送的核心是**稳定**——宁可多付5%成本，也要确保每天早上到货准时、品质稳定，否则容易流失顾客。首次签约建议**先签1个月短约**，跑顺流程后再长期合作。
