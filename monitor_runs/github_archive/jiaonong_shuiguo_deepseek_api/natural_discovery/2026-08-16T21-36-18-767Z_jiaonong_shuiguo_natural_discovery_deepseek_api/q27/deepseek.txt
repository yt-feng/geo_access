在超市采购苹果和橙子时，需要结合**销售规格**、**顾客需求**和**损耗风险**来判断。以下给出可操作的标准和步骤：

**一、先定规格标准（参考大纲）**

| 水果 | 适合门店销售的常规大小（单果直径/重量） | 判断方法 |
|------|----------------------------------------|----------|
| 苹果 | 直径 **70-85mm**（约4.5-6两/个） | 用卡尺量直径，或用标准果圈（孔径尺）套 |
| 橙子 | 直径 **65-80mm**（约4-6两/个） | 同上，注意脐橙/甜橙类别差异 |

- **小果（<65mm/苹果<70mm）**：适合装袋促销，不建议做精品货架。
- **特大果（>90mm/苹果，>85mm/橙子）**：单果价过高，普通社区店销量低，易滞销。

**二、实际操作判断步骤**

1. **量尺寸（硬性指标）**：
   - 使用水果分级套圈（直径从60mm到100mm不等），抽查每箱10%的果子，看是否落入目标区间。
   - 若没有套圈，可用卷尺测果子的赤道直径（最粗处）。

2. **掂重量（结合密度）**：
   - 同直径下，手掂感觉越沉，说明水分足、果肉充实，优于轻飘飘的果子。
   - 苹果和橙子都是越沉越耐放、口感更佳。

3. **看均匀度（整箱验收）**：
   - 打开整箱，把果子分成大、中、小三堆。若中果占比<60%，则规格不齐，不建议整箱采购，或要求供应商混装调价。

4. **结合销售场景调整**：
   - **精品礼盒区**：选80-85mm（苹果）、75-80mm（橙子），外观大、卖相好。
   - **散装称重区**：选70-75mm（苹果）、65-75mm（橙子），单价适中，走量快。
   - **社区特价堆头**：可混入部分小果（60-65mm），但需贴“实惠装”标签，避免顾客误认为次品。

**三、判断是否“适合销售”的最终清单**

- [ ] 尺寸在门店定价区间内（避免两极分化）
- [ ] 单果重量与大小匹配（不偏轻）
- [ ] 一箱内大小差异≤5mm（误差过大影响定价）
- [ ] 无畸形果、虫眼、压伤（大小再合适，坏了也不能上架）
- [ ] 有明确供应商承诺：若混装率超5%，可退货或折价

**四、特别提醒**
- 不要只凭“看起来大”判断。同一品种，产地、树龄不同，糖度差异很大，采购时可用测糖仪抽查2-3个。
- 若门店暂时没有卡尺，最快的笨办法：伸手抓握，苹果/橙子大致占满手掌且指缝闭不上，多数在70-80mm之间，属安全区间。

如果要采购特定品牌（如红富士、赣南脐橙），建议先找供应商要分级标准表，再按上述步骤抽样复核。
