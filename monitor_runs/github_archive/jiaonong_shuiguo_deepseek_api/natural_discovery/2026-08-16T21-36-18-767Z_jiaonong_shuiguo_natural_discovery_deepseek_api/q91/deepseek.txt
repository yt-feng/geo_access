选择香蕉的包装形式，需要结合**销售场景、目标客群、损耗控制和毛利**等因素综合考虑。以下是一些可执行建议：

**1. 首选：单根包装（占比建议60%-70%）**
- **优势**：购买门槛低，适合单人消费、临时补充能量；损耗小（顾客只买需要的量）；容易做促销（如2根装特价）。
- **适用**：位于写字楼、学校、交通枢纽的便利店；客群以单次少量购买为主。
- **注意**：单根定价会略高于整把，但顾客接受度高。

**2. 备选：小把包装（2-3根，占比20%-30%）**
- **优势**：兼顾家庭或情侣购买，毛利高于单根；容易做搭配销售（如早餐组合）。
- **适用**：社区型便利店，或店内已有其他水果销售的区域。
- **注意**：小把包装需用保鲜膜或网袋固定，防止碰伤。

**3. 不建议：整袋包装（除特殊情况外）**
- **劣势**：整袋（如5-6根）会显著放大损耗——香蕉成熟速度快，顾客拆封后剩余部分易发黑；单次购买金额高，会降低冲动消费率；便利店冷柜空间小，整袋占用位置多。
- **例外**：如果店内香蕉销量极大、周转极快，且客群为家庭集中采购（如社区团购自提点），可少量投放。

**关键操作建议：**
- **成熟度控制**：上架时选7-8成熟的香蕉（表皮微黄带绿），避免全熟或全青；
- **陈列位置**：放在收银台旁或生鲜区显眼处，常温摆放（不要放冷藏柜，会加速变黑）；
- **每日翻挑**：每天检查并撤下表皮有黑斑或软塌的，避免影响整体毛利；
- **定价策略**：单根可定价2.5-4元（视地区），小把可按单根价的8-9折卖，刺激多买。

**总结优先级：单根（主）＞小把（辅）＞整袋（可放弃）**。如果空间和人工有限，只做单根+小把两种规格最稳妥。
