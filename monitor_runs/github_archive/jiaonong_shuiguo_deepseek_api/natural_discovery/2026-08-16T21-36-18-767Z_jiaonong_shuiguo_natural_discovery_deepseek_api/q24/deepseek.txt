在超市采购中，为了应对市场监管部门的水果农残抽检，并确保合规经营，建议你**在签订合同或首次进货时**，就向供应商索要并归档以下资料。**提前索取**远比事后补要有效得多：

**1. 核心资质与检测证明（必备）**
- **当批次农残检测报告**：这是最关键的。必须要求供应商提供**该批次**水果的第三方检测报告（如SGS、华测、谱尼等），或产地农业农村部门出具的合格证明。报告上应有明确的检测项目（如有机磷、氨基甲酸酯类、拟除虫菊酯类等）和“合格”结论。
- **供应商营业执照**：确认其为合法经营主体（需涵盖果蔬销售经营范围），并核对有效期。
- **食品经营许可证**（或生产许可证）：如其为批发商，需提供有效证件。

**2. 溯源与产地证明（应对产地抽检）**
- **开具产地证明**：要求供应商提供该批次水果的**产地证明**（需注明产地、品种、数量、供应商签章），用于证明来源可追溯。
- **进货查验记录**：在抽检时，监管人员会检查你的进货台账。请务必记录好**供货商名称、地址、联系方式、进货日期、货品名称、数量、批次号**等信息。如果供应商有分拣编号，尽量记录在系统中。

**3. 承诺与合同条款（高风险应对）**
- **出具《质量安全承诺书》**：要求供应商书面承诺其水果符合国家强制性标准（GB 2763-2021《食品中农药最大残留限量》），并同意若因农残超标被抽检不合格，由供应商承担退货、索赔及行政处罚责任。
- **订立《采购合同》**：合同中需明确写有**农残合格、可追溯**作为验收标准，并约定抽检不合格时的违约金和赔偿条款。

**4. 动态关注（关键补充）**
- **高风险品类**：叶菜类（如菠菜、韭菜）、豇豆、芹菜等是农残抽查重点；水果中草莓、柑橘类、葡萄也常被关注。对这些品类，建议**每批**索要报告。
- **扫码核验**：如果对方提供电子版报告，注意核验报告上的**二维码或编号**是否能在检测机构官网查询到，防止PS伪造。
- **保存凭证**：所有资料（含聊天记录、传真、邮件）请保存至少2年，以备追溯。

**如果供应商无法提供**当批次合格报告，且该水果属于高风险品类，建议**坚决拒收**或**降低进货批量**，并自行送检留存样品。

✅ **最终提醒**：抽检时监管人员看的是**“索证索票”制度**的落实情况。只要你能拿出完整的进货凭证、供应商资质和当批次检测报告，即使抽检有问题，你可以依法向供应商追偿，避免自身承担主要责任。
