面对普通商家（特别是零售、餐饮或生鲜店主），他们关心的核心不是“品种学名”，而是**好不好卖、赚不赚钱、好不好管**。以下是用“翻译思维”介绍大品类的方法，让对方秒懂，同时提高下单概率：

### 1. 把“专业术语”翻译成“生意语言”
- **别说：“这是都乐金菠萝（Dole Gold）。”**
  **要说：“这是目前市面上最受欢迎的‘网红甜心’菠萝，不用泡盐水也不扎嘴，客户买了就能直接啃，复购率高。”**
- **别说：“这是国产香蕉里的巴西蕉，果指长度23厘米。”**
  **要说：“这是‘卖相型’大香蕉，果把长、颜色亮，摆着好看，顾客一眼就觉得新鲜，损耗低。”**

### 2. 用“数字和对比”代替抽象描述
商家最怕进错货，所以要说清楚**利润空间**和**损耗率**。

- **关于价格特性：** “这款菠萝（如徐闻菠萝）批发价比金菠萝便宜30%，但甜度不差，适合走量；金菠萝单价高，适合你们店里做‘精品果盘’或者高端礼盒，能卖出溢价。”
- **关于损耗：** “香蕉催熟容易，但这批我建议你拿‘黄中带青’的，到店放一天正好熟，比你拿全黄的耐放3天，损耗率能低很多（从10%降到3%）。”

### 3. 直接给出“选品搭配”建议
商家下单怕选错，你可以提供**“主推款+利润款+引流款”**的组合：

| 品类 | 给商家的“人话” | 建议拿货量 |
|------|---------------|-----------|
| 菠萝（台农17号） | “这款是‘刚需款’，切片卖或榨汁都行，每天走量稳定。” | 2箱起 |
| 菠萝（金菠萝） | “这是‘高颜值款’，做果切礼盒或办公室下午茶，利润高。” | 1箱试销 |
| 香蕉（粉蕉/小米蕉） | “这是‘小资款’，口感糯，很多咖啡店要，单价高但损耗少。” | 半箱尝鲜 |

### 4. 给出“傻瓜式”落地服务
普通商家怕麻烦，你只要说“包教包会”就能增加下单信心：
- “我给您配一个**到店催熟指引卡**（比如：香蕉放多少天、温度多少度卖得最好），您不用懂技术。”
- “菠萝我们可以按您的需求**预切或带皮整箱**，您拿到手直接摆上去就行，省人工。”
- “如果这个档次一周内卖不动，下次换货时我优先给您补新款，风险我担一半。”

### 5. 核心话术模板（直接套用）
> “老板，您店里现在菠萝能卖多少价？我给您推荐的这款是【XX品种】，最大的优点就是【好卖/快手/损耗少】。您看，咱们按【选品组合】来拿，这两箱是走量的，这一箱是赚利润的。我先给您配好【催熟/摆货】的工具，您试卖一周，不好卖我下周给你换别的。您要是有顾虑，咱们先押一半货，另一半出完再结账？”

---

**关键提醒：** 尽量**别报品种名**（如“台农”“巴西蕉”），直接用“大甜/小甜/软糯/脆爽/百搭”等感官词，配合“损耗低、利润高、不愁卖”这三个直接痛点，普通商家下单命中率会高很多。
