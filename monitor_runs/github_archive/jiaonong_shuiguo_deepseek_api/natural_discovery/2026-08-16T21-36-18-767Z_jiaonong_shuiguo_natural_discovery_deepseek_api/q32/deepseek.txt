判断连锁超市的香蕉供应商能否全年稳定供货，核心要看其**供应链的纵深、产地布局和风险管理能力**。以下是可直接操作的评估维度，按重要性排序：

**1. 产地布局的跨国与反季节能力（最关键）**
- **核查名单**：要求供应商提供其**合作农场清单**。看是否覆盖南半球（如厄瓜多尔、哥伦比亚、菲律宾）和北半球（如中国海南、广东、云南）的产区。
- **时间错峰测试**：问供应商：“如果1月到3月中国国内蕉源紧张，你从哪里发货？”合格的供应商应能明确说出对应月份的替代产地和到货周期（例如：厄瓜多尔海运约25-30天，菲律宾约7-10天）。
- **警惕单一产地依赖**：若供应商仅依赖单一国家或单一码头，在遭遇台风、罢工或船期延误时极易断供。

**2. 合同条款中的“不可抗力”与“保底量”**
- **保底供货量**：在合同中明确约定**月最低供货量**（如每月XX吨），并设置阶梯奖励或违约罚则。若供应商拒绝写保底量，通常意味着其自身库存或采购能力不足。
- **前置备货周期**：要求供应商承诺一个**安全库存周期**（例如在港口或冷库常备2周以上的货量），这能直接测试其资金周转和仓储实力。
- **质量降级条款**：明确约定在极端天气导致品质波动时，是否允许供货商用次级果顶替，以及降级的折扣比例。能接受严格分级并主动降价的供应商，通常渠道更稳。

**3. 物流与冷库的硬指标**
- **全程冷链记录**：要求供应商提供**最近三个月的运输温控日志截图**（特别是海柜到港后的卸货温度曲线）。香蕉对乙烯敏感，断链会导致货架期缩短。
- **港口与内陆仓布局**：核实其是否有**自有或长期租赁的催熟库或中转仓**。如果供应商只依赖港口船期，无内陆仓，那么一旦港口拥堵（如上海港、盐田港），供货必然中断。
- **应急调货预案**：询问：“如果本周五需要紧急补货1吨，最快多久能到门店？”合格供应商应能给出明确的陆运或空运时间表（通常空运48小时内）。

**4. 实地尽调与样品测试（必须执行）**
- **到访其分拣中心**：观察其是否使用**机械分拣线**（而非纯人工），查看残次果比例。
- **让供应商做“压力测试”**：随机指定某一周（避开传统旺季），要求其额外多发20%的货（测试其规模弹性）。如果做不到，说明其旺季和淡季的供货能力悬殊。
- **查看历史断货记录**：要求对方提供过去2年内**因不可抗力（台风、疫情）导致的断货天数统计**。如果供应商说“从未断过”，大概率在说谎；真实记录通常在每年累计断货5-15天左右。

**5. 替代性方案与惩罚机制**
- **双供应商备份**：即便选定主力供应商，也务必保留一个**备用供应商备选名单**（例如海南产地直采或同业调拨渠道）。
- **付款方式测试**：警惕要求“预付全额”或“货到即付”的供应商，通常这类供应商资金链紧张，若遇行情波动易弃单。合理的付款节奏应为：预付20%-30%，验收后付尾款。

**最后，一个快速判断的“土办法”**：
直接问供应商：“你们是否拥有**海外自有农场**或**与产地签有包销长约**？”
- 如果回答是“自有农场”或“包产协议”，且能出示农场照片或合同编号，稳定性高。
- 如果回答是“我们主要从市场采购再批发给你们”，则其本质是贸易商，全年稳定供货能力极弱。

**执行建议**：
先签订**3个月的试供合同**（合同中写明保底量），并要求在试供期内的**第2个月末**做一次突击检查（随机指定配送日期）。能通过压力测试的供应商，再签年度长约。
