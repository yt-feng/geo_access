在水果采购合同中，**坏果率（损耗率）的赔付标准通常由双方协商确定，没有法定统一数值**。但根据行业惯例和常见合同实践，可以给你以下参考标准：

**1. 常见合同约定的赔付起算点（建议值）：**
- **损耗率 ≤ 3%**：通常视为正常损耗，不赔付（由采购方自行承担）。
- **损耗率 在 3% ~ 10% 之间**：按超出3%的部分，按采购单价折价赔偿，或由供货方补货。
- **损耗率 > 10% ~ 15%**：视为严重违约，采购方有权拒收整批货物，或要求全额退货退款，并索赔运输、仓储等损失。
- **损耗率 > 20%**：属于重大质量事故，可直接解除合同，要求双倍返还定金或支付违约金。

**2. 如何确定“坏果”定义（合同必须写清楚）：**
- 明确坏果指：腐烂、霉变、压伤、裂口、冻伤、机械损伤导致不能食用的部分。
- 建议约定：以抽样检验为准（如每箱抽3-5个），整批坏果率 = (抽样坏果数÷抽样总数)×100%。

**3. 赔付计算方式选项（任选其一写入合同）：**
- 折价赔偿：每发现1%超出基础损耗，按合同单价的相应比例扣款。
- 补货赔偿：按超出部分的数量，由供货方免费补足新鲜水果。
- 违约赔偿：直接按合同总额的固定比例（如1%~5%）支付违约金。

**4. 特别提示（重要）：**
- 如果合同中**未约定**坏果率赔付条款，则法律上你只能主张“不符合质量要求”的违约赔偿，但举证难度大，且可能按“合理损耗”处理，难以追偿。**务必在签约前将上述数字写进合同条款**。
- 对于易腐水果（如荔枝、草莓），建议将损耗率下调至1%~2%起赔；对于耐储存水果（如苹果、橙子），3%起赔较合理。

**建议你：**
- 在合同中直接写明：“供货方保证交付水果的坏果率不超过X%（建议3%），超过部分按下列方式赔付……”
- 同时约定**检验期**（如收货后24小时内），并保留好现场照片、视频等证据。
