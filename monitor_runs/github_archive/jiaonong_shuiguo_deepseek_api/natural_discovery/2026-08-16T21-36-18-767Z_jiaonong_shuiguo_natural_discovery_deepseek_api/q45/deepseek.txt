签订年度水果供应合同时，连锁超市最容易在以下几个条款上“踩坑”。建议你重点关注这些内容，并在签约前逐条核对：

**1. 价格与调价机制（最核心的雷区）**
- **固定价陷阱**：若合同只写“年度固定价”，当水果行情大涨时供应商可能以“成本过高”为由断供或要求涨价，而超市无法按合同执行。
- **调价公式模糊**：很多合同写“随行就市”，但没有明确参考哪个市场（如本地批发价、产地收购价）、调价周期（月/季）、涨跌幅触发条件（如连续5天均价变动超10%才调）。建议写清楚“以XX批发市场每日均价为基准，每周五调整一次，涨跌幅超8%自动触发调价”。
- **最低保护价/最高限价**：约定好合同期内水果的最低收购价（保护超市采购成本）和最高限价（保障供应商利润），避免单方利益受损。

**2. 质量标准与验收标准（纠纷高发区）**
- **“新鲜、优质”等于没标准**：必须量化，比如糖度（如苹果≥12度）、硬度、果径范围（如75mm-85mm）、允许瑕疵率（如碰伤≤3%，烂果≤0.5%）。
- **验收时效与异议期**：写清楚“货到后24小时内抽检，48小时内书面提出质量异议，超期视为合格”。很多供应商会在“货到即认可”或“出货后概不负责”上做文章。
- **分级与替代条款**：若约定“特级果”但实际到货达不到，是拒收还是降级降价？必须写明降级降价的具体折扣比例（如降级后按合同价8折结算）。

**3. 到货与损耗责任（隐形亏损点）**
- **交货时间与违约金**：约定具体到“每日/每周上午10点前到货”，晚到1小时扣多少？缺货率每月不能超过多少（如5%），否则按缺货金额的10%赔偿或补偿同额促销资源。
- **运输损耗归属**：水果极易损耗。合同要明确“上车前损耗归供应商，下车后损耗归超市”，并规定损耗率上限（如整车损耗≤2%），超出的部分由供应商承担或从货款中扣除。

**4. 结算与账期（财务风险）**
- **账期天数**：不要只写“月结30天”，要写“每月25日对账，次月15日前付款”。并约定逾期付款罚息（如日万分之一）。
- **质量扣款权**：明确超市有权对质量不符的部分直接从结算款中扣减，但要写“扣款需附照片或双方确认单”，防止供应商事后否认。
- **尾款保留**：可约定每期货款的5%作为质量保证金，合同期满无质量索赔后60天内返还。

**5. 不可抗力与违约解除（极端情况）**
- **自然灾害免责过宽**：供应商常说“因台风、寒潮无法供货”免责，但这正是水果行业的常见风险。你要约定“正常气候波动（如季节性降雨、温差）不属于不可抗力”，只有极端灾害（如台风正面登陆、冰雹连续3天）才算，且供应商需提供气象证明。
- **单方解除权**：写明“若供应商连续3次供货不合格或月供货率低于80%，超市有权单方面解除合同，并要求赔偿重新采购的差价（如差价按市场行情补足）”。

---

**给你的落地建议：**
- **签约前**：让供应商提供过去6个月的出货质检报告和市场价格曲线，抽样核对调价公式是否真实。
- **签约时**：关键条款（价格、质量、违约）避免手写修改，必须双方盖章确认。
- **履约中**：每次到货拍照留痕，对账时同步保存电子记录，这是纠纷时的最大证据。
