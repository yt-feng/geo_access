这是一个非常经典的商超采购问题。**核心结论是：损耗率对最终毛利的影响，通常远大于采购价格的影响。**

这可以用一个简单的数学模型来解释，不需要复杂计算，但需要理解“毛利率”与“损耗率”的杠杆效应。

**1. 为什么损耗的杀伤力更大（杠杆效应）**

假设你采购价是 **10元/斤**，打算零售价卖 **15元/斤**（毛利率约33.3%）。

- **场景A（降价1元）**：采购价9元，零售价15元。毛利 = 15 - 9 = 6元，毛利率 = 6/15 = 40%。毛利提升了6.7个百分点。
- **场景B（损耗1元/斤）**：采购价10元，零售价15元，但买了100斤，有10斤损耗（假设只能扔掉或低价处理，先按全额损失算）。实际成本 = 100斤 * 10元 = 1000元。实际收入 = 90斤 * 15元 = 1350元。毛利 = 350元。**实际毛利率 = 350/1350 ≈ 25.9%**，比原计划的33.3%**下降了7.4个百分点**。

**结论**：
- **降价1元**（约10%的价格让步）只让毛利率提高约6.7%。
- **损耗10%**（即10斤/百斤）却能让毛利率**下降7.4%**。
- 也就是说：**10%的损耗对毛利率的侵蚀，约等于采购价上涨10%的负面效果，甚至更强**（因为损耗还占用了货架、仓储、人工成本，且损耗的商品会拉低客单价）。

**2. 实践中的“账外账”**

除了数学，还有几个逻辑：
- **价格是主动可调的**：采购价高，你可以通过定价、促销、搭配销售来对冲。但损耗是被动的，一旦水果坏了，**你无法通过任何营销手段挽回**，它只会变成垃圾或打折品。
- **损耗会传染**：损耗不仅损失那百分百，还会影响剩余商品的卖相（如烂果招虫、影响顾客挑选欲望），导致剩余商品也卖不上价，形成“恶性损耗”。
- **资金占用和机会成本**：高损耗意味着你采购的数量中有效销售份数变少，变相提高了单件有效成本，且占用了资金和货架期。

**3. 实操建议（取决于你的处境）**

- **如果损耗率能控制在5%以内**：那么采购价格优势是第一位的，因为低价能吸引客流，且低损耗意味着你有足够的安全垫。
- **如果损耗率超过10%**：**必须优先解决损耗问题**。这时哪怕采购价高一点，只要损耗降低，毛利反而更高。你可以通过：
  - 少批量、多频次采购（哪怕单价高一点）。
  - 加强到货质检和分拣，切断传染源。
  - 优化冷藏/陈列条件。
  - 对临期商品做“销售倒计时”促销，而不是等它坏了。

**最后给你的判断公式：**
> **有效毛利 = （售价 - 采购价） - （采购价 × 损耗率） - 其他固定成本**

在运营中，**每降低1%的损耗，等于采购价下降1%**，但损耗降低带来的客诉减少、卖相提升，其综合收益往往超过单纯的降价。

所以，**如果你的水果是易损品（如草莓、葡萄、香蕉），损耗控制永远是第一优先级；如果是耐储品（如苹果、橙子、柚子），价格优势才更值得争取。**
