在超市水果区设计组合促销，核心目标是**提升客单价**（即让顾客买得更多、花得更多），同时**带动高毛利或易损耗商品**的销售。

针对香蕉、菠萝、苹果这三个品类，我建议按“**引流稳价 + 利润冲刺 + 连带搭售**”的策略来组合，给你几套可直接落地的方案：

---

### 方案一：居家能量套餐（最稳妥，适合工作日）
- **组合内容**：香蕉1把（约500g） + 苹果3个 + 菠萝半只（现场去皮切块装盒）。
- **定价逻辑**：
  - 香蕉定为**特价引流品**（比如原价5.9元，组合内按4.9元/斤），吸引客流。
  - 苹果选**中等价位**（如红富士，单价8-10元/斤），在组合里打9折，赚毛利。
  - 菠萝作为**高毛利+增值服务**（切块/装盒收2-3元加工费，或直接打包卖12元/盒），提升客单。
- **建议售价**：整套定价 **“29.9元家庭装”**（原价约38元，让顾客感觉省了8元以上）。
- **执行细节**：菠萝必须提前切好并用保鲜膜+托盘封装，标注“已去芯、免切”，减少顾客决策成本。

---

### 方案二：现切果盒“盲盒”组合（适合周末/下午时段，清库存）
- **组合内容**：将熟透的香蕉（卖相稍差）、切块的菠萝、切好的苹果丁，混合装成 500g/700g 的现切果盒。
- **定价逻辑**：
  - 平日单买果切按12-15元/斤，组合果盒直接定价 **“450g组合装9.9元”**。
  - 这套的核心是**消化损耗**：香蕉熟得快、菠萝易烂，苹果切块抗氧化处理（泡盐水），全部拼进盒里。
- **组合话术**：“每日鲜切，三种水果一次吃遍，比单买省5元。”
- **执行细节**：
  - 在果盒顶部贴“今日现切，建议2小时内食用”。
  - 现场放一次性叉子，旁边立小牌：“买一盒送小叉子，两盒送迷你水果叉套装”。

---

### 方案三：健康轻食搭子（提升连带率，适合搭配酸奶/零食区）
- **组合内容**：香蕉1根（散装） + 苹果1个 + 菠萝切块（150g小份） + 超市自有品牌酸奶1杯。
- **定价逻辑**：
  - 香蕉按**个卖**（1元/根），苹果选**小果**（6-8元/斤，每个约1.5元），菠萝小份装卖3.9元。
  - 酸奶原价5.5元，组合内按**3.9元**，整套定价 **“10元轻食组合”**（原价约13.5元）。
- **执行细节**：
  - 把菠萝切好后，小份用透明杯装好，和酸奶并排放在冷柜。
  - 在组合区放一块立牌：“健身/代餐推荐，10元搞定维生素+蛋白质。”
  - 这套特别适合**中午12:00-14:00**和**晚上18:00后**的时段，目标人群是白领和健身族。

---

### 关键执行建议（比定价更重要）：
1. **不要三个水果都是平卖**：必须有1个引流（便宜/特价），1个利润（中等价），1个增值（加工后卖高毛利）。
2. **组合价必须比单买便宜10%-15%**，否则顾客没动力凑单。
3. **位置摆放**：将组合装放在水果区**入口或通道转角处**，用黄色爆炸贴写“今日特惠组合”，同时**在收银台附近放一套**做冲动消费。
4. **连带策略**：组合区旁顺手贴一张小提示——“买组合加5元换购百香果/柠檬2个”，把客单价再往上拉5元。
