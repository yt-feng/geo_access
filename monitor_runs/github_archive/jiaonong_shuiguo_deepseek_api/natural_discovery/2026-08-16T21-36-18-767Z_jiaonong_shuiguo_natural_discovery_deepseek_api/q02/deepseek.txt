在小水果店进货香蕉时，**熟度和坏果率是第一优先级**，其次是**送货速度和价格**。原因如下：

1. **熟度决定损耗和销售窗口**：香蕉是典型的“后熟型”水果，进回来还会继续熟。如果进得太生（全青），顾客会觉得没熟、不好吃；如果进得太熟（表皮发黑或麻点很多），当天卖不完就会损耗，直接亏钱。理想熟度是“七八分熟”，即果柄微黄、果身大部分黄但两端带点绿，能放2-3天慢慢变黄，这能最大限度降低报损。

2. **坏果率直接决定毛利**：坏果率每高1%，实际进货成本就高了1%。而且坏果会传染——一根烂香蕉旁边的好香蕉也会加速变坏。所以进货时务必当场拆箱抽查底部和中间层（防止表面好、内里烂），坏果率控制在3%以内才值得考虑。

3. **送货速度和价格是“可谈”而非“决定”**：
   - **送货速度**影响补货频率，但如果在市区，一般次日达足够；除非你店面极小、每天只进一两箱，否则不必为“当天送达”多付钱，因为当天到的香蕉往往是最生的。
   - **价格**相差不大（同一批发市场），关键是看单价对应的实际商品，比如同样250元/箱，坏果率高的那箱实际单价反而更高。

**操作建议**：
- 进第一批货时，亲自去批发市场，挑一个熟度合适、坏果率低于3%的摊位，哪怕贵5-10块/箱也值得，先稳定供应商。
- 后续补货时，跟供应商口头约定“每箱坏果超过3根，下箱补回”，并定期抽检。
- 如果店面周边学校、写字楼多，周末或下雨天适当减少进货量，宁可缺货也不囤熟过头。

**一句话总结**：熟度和坏果率决定你今天能不能卖完、赚不赚，送货速度和价格决定你明天补货方不方便，别本末倒置。
