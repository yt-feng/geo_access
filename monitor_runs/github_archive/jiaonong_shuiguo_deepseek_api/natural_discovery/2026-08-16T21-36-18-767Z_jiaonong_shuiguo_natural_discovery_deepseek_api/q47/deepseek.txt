采购香蕉用于茶饮店或甜品时，熟度控制非常关键，因为太生会涩、太熟会烂，直接影响出品口感和颜值。以下是分场景的可执行建议：

**一、按用途区分成熟度标准**

1. **做香蕉奶昔/冰沙/果汁（需搅打）**：建议采购**全熟或稍过熟**的香蕉（表皮出现大面积黑点，手感软糯）。此时甜度最高、淀粉完全转化为糖，搅打后口感顺滑、无需额外加太多糖。
2. **做香蕉切片装饰/摆盘/分层甜品**：建议采购**八成熟**香蕉（表皮金黄、略带青头，按压微弹）。此时果肉成型好、不易氧化断裂，切面美观。
3. **做香蕉蛋糕/烤制类**：**过熟**香蕉（皮全黑、内部软烂）最佳，能提供天然黏合和浓郁风味。

**二、采购验收时的硬性指标**

- **颜色**：表皮以亮黄为主，避免大面积青色（未熟）或全黑湿软（过熟）。
- **触感**：轻捏果身，微有弹性且不塌陷为佳；若按下去凹陷不回弹，则过熟。
- **气味**：应有明显香甜味，无异味或发酵酸味。
- **整梳香蕉**：采购时最好选整梳（带柄），比散装更耐存放，成熟度更均匀。

**三、到店后的熟度调控方案**

- **催熟**：若买回来偏生（青皮），放在室温下，用报纸包裹或与苹果/梨同放纸袋，1-2天可催熟。
- **延缓**：若买回来偏熟，立即冷藏（约12°C），可抑制继续熟化，但注意冷藏后皮会变黑，取用时看果肉判断，不影响内部品质。
- **急用处理**：如果急需过熟香蕉做烘焙，可放在微波炉高火加热10-15秒（剥皮后），或烤箱150°C烤5分钟，能快速软化和增甜。

**四、库存与损耗管理**

- 每天按预计销量只采购3-4天用量，**先进先出**。
- 对过熟但未坏的香蕉，立刻剥皮冷冻（密封袋），冷冻后适合做冰沙，可保存1个月，避免浪费。
- 熟度判断以**果肉状态**为准，不要只看表皮颜色（冷库催熟的香蕉皮绿但肉已熟，可用手折果柄测试：易折断即熟）。

**总结一句话**：奶昔类买“黑点软蕉”，装饰类买“黄亮弹性蕉”，烘焙类直接用“黑壳软肉蕉”；到货后根据当天用量分批催熟或冷藏来控制节奏。如果有具体产品（例如主打香蕉拿铁或香蕉布丁），可以再细化配方要求。
