做水果拼盘选规格，核心不是“单价最低”，而是**按出成率、损耗、人工和卖相算实际成本**。简单说：苹果选大小适中、脆度稳定的；橙子选皮薄、易剥/易切的；菠萝选成熟度一致、出肉率高的。

下面按品类说可执行的选择标准：

**1. 苹果**
- **规格建议**：选单果 180–250g 的中果，别一味追大果。
- **原因**：大果单价常更高，但拼盘里通常切块/切片，顾客感知差异不大；中果切出来块型更均匀，边角料也更好控制。
- **品种**：优先选脆度高、切开不易快速氧化的，如红富士、嘎啦等。若切后放置久，需配盐水或柠檬水防氧化。
- **划算判断**：比较“每公斤净果肉成本”。公式：  
  **净肉成本 = 采购单价 ÷ 出成率**  
  苹果出成率通常约 80%–90%，看削皮去核损耗。

**2. 橙子**
- **规格建议**：选中等果，单果 150–220g，皮薄、果形端正。
- **原因**：太小剥肉费工，太大可能皮厚、白瓤多。拼盘常用橙瓣或橙片，皮薄、瓣膜薄的更省人工。
- **品种**：脐橙、血橙、沃柑等都可，但要做橙瓣的话，选易剥、瓣大、汁水适中的。
- **划算判断**：橙子看“可食率”和人工。皮厚、白瓤多的，虽然单价低，但净肉少、修整耗时，实际更贵。

**3. 菠萝**
- **规格建议**：选单果 1.2–1.8kg 的中等果，成熟度 7–8 成，香气明显但不软烂。
- **原因**：太小出肉少、削皮去眼损耗大；太大一次用不完，切开后易变质。中等果出肉率和操作便利性较平衡。
- **品种**：优先选“金钻”“台农”等眼浅、甜度高、纤维少的，削皮去眼更省工。
- **划算判断**：菠萝出成率通常约 50%–65%，要重点算净肉成本，而不是整果单价。眼深、皮厚的实际成本会高很多。

**通用选规格原则**
- **按用途选**：切块选中等果；切片选果形端正的；做造型可选大小一致的小果。
- **按损耗算**：采购价低但出成率低的，往往不如贵一点但净肉多的。
- **按人工算**：餐厅高峰时段，省 5 分钟削切比省几毛钱更重要。
- **按稳定性选**：同一批规格、成熟度一致，才能保证拼盘出品稳定。
- **按季节选**：当季果通常更便宜、风味更好，反季果再便宜也可能口感差。

**最实用的比价方法**
对每种水果统一算：  
**每份拼盘成本 = 单份净重用量的采购成本 + 损耗分摊 + 人工分摊**  
例如苹果净肉成本 = 采购价 ÷ 出成率；菠萝净肉成本 = 采购价 ÷ 出成率。  
最后比较“每份拼盘成本”和“卖相/口感”，而不是只看整箱或整果单价。
