水果店旺季怕断货，和供应商谈合作时最怕“口头承诺得好、真缺货时没人管”。建议你按下面几类问题逐条问清楚，最好写进合同或订单确认里，不要只听口头保证。

**一、供货能力与优先级**
1. 旺季你每天/每周能稳定给我供多少量？最大供货量是多少？
2. 如果同时有好几个客户要货，我的订单优先级怎么排？
3. 你们自己的货源是基地直采、批发市场还是调货？旺季会不会也断？
4. 遇到天气、物流、产地减产，你们通常怎么保供？
5. 能不能给我看最近几个月同类水果的供货记录或出货能力证明？

**二、价格与调价机制**
1. 旺季价格怎么定？是固定价、随行就市，还是按等级报价？
2. 涨价前提前几天通知我？会不会我订了货又临时加价？
3. 不同规格、等级、包装的价格差多少？
4. 量大有没有阶梯价？长期合作有没有返点或账期？
5. 运费、装卸费、损耗谁承担？到店价还是产地价？

**三、质量与验收标准**
1. 果径、甜度、成熟度、颜色、瑕疵率按什么标准？
2. 坏果、烂果、压伤比例超过多少算不合格？
3. 到货后多久内可以验货？发现问题怎么赔、怎么补？
4. 是包退包换，还是只补下一车？补货时效多久？
5. 能不能先发样品或小批量试单？

**四、订单与交付**
1. 我提前多久下单？当天订能不能当天送？
2. 每天几点截单、几点到店？旺季会不会延迟？
3. 起送量多少？能不能混装？临时加单接不接？
4. 配送是你们自己的车还是第三方？冷链还是常温？
5. 如果迟到、少送、送错品种，怎么处理？

**五、缺货与违约处理**
1. 如果你们断货，提前多久通知我？
2. 断货后能不能从别的渠道帮我调货？差价谁承担？
3. 有没有备用供应商推荐，或者你们能不能帮我紧急补位？
4. 违约怎么赔？是按订单金额比例，还是补差价？
5. 连续断货几次，我可以无条件换供应商吗？

**六、结算与账期**
1. 是现结、周结还是月结？需要押金或保证金吗？
2. 支持微信、支付宝、对公转账还是现金？
3. 发票怎么开？税点谁承担？
4. 退货、补货、扣款怎么对账？多久核对一次？

**七、旺季专项保障**
1. 旺季能不能签保供协议，明确最低供货量？
2. 能不能提前锁量锁价？锁多久？
3. 节假日前要不要提前备货？你们仓库能帮我存吗？
4. 如果我预估销量上涨，提前几天报计划最稳？
5. 有没有应急联系人？半夜或凌晨能联系到谁？

**八、合作与退出**
1. 合作期限怎么定？能不能先签旺季三个月？
2. 试合作期多久？不满意能不能随时停？
3. 终止合作要提前几天通知？有没有违约金？
4. 我能不能同时跟两家供应商合作，避免被一家卡脖子？

**谈的时候重点抓三件事：**
- **保供量写清楚**：旺季每天最少给多少，断货怎么赔。
- **价格机制写清楚**：涨跌怎么调，提前多久通知。
- **质量问题写清楚**：坏果率、验货时间、补货时效。

**最实用的做法：**
不要只谈一家。旺季至少保持“一主一备”，主供应商拿70%量，备用供应商拿30%量。这样主供断货时，你马上能补上，不至于旺季眼睁睁看着货架空了。
