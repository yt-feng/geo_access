卖香蕉最容易踩的坑，是把它当普通水果发。香蕉在配送途中压坏和变黑，本质是**机械损伤 + 后熟失控**两件事叠加，要分开治。

**一、先解决压坏**

- **别用软纸箱单层堆**。香蕉怕挤压，尤其怕局部受力。用带分隔的**瓦楞纸箱 + 珍珠棉/气泡膜隔层**，每根或每小把独立缓冲。
- **整把卖比单根卖稳**。单根香蕉没有相互支撑，反而更容易被压出黑斑；整把用保鲜膜裹住果柄，再套网套。
- **装箱留空隙但别晃**。空隙用填充物塞实，运输中晃动造成的磕碰比静压更致命。
- **控制堆码层数**。香蕉箱不要超过 5~6 层，底层加托盘，避免整个重量压在下面几箱上。

**二、再解决变黑**

香蕉变黑主要是**乙烯催熟 + 低温冷害 + 呼吸热**共同作用：

- **七成熟左右发货**。全黄发货到用户手里基本已经过熟。按配送时长倒推：同城 1 天发 7 成熟，跨省 2~3 天发 6 成熟。
- **果柄包住**。乙烯主要从果柄释放，用保鲜膜把整把的果柄缠紧，能明显延后变黑。
- **别冷藏运输**。香蕉低于 12℃ 会冷害，表皮发黑更快。常温阴凉运输，夏天用冰袋要隔开，不能让香蕉直接贴冰。
- **加乙烯吸收剂**。箱内放一小包高锰酸钾乙烯吸收剂，成本很低，对延缓后熟有效。
- **通风别闷**。密闭箱内呼吸热散不掉，会加速变软变黑。纸箱打透气孔，或不要完全密封。

**三、配送和售后要配套**

- **时效优先**：同城当日达、跨城次日达，超过 48 小时香蕉品质很难保证。
- **明确标注**：页面写清"收到可能带青，常温放 1~3 天转黄"，降低因颜色不符的差评。
- **轻微黑斑不算坏**：香蕉表皮少量黑点是糖化表现，不是变质，客服话术要提前统一，避免过度赔付。
- **到货即验**：让用户签收时检查明显压伤，压伤严重的直接补发，比事后扯皮成本低。

**一句话判断标准**：如果用户收到时整把能立住、果柄不霉、表皮黑斑少于 1/3，就属于合格；大面积发黑发软，说明发货成熟度太高或运输温度出了问题，要回去调采摘成熟度和包装。
