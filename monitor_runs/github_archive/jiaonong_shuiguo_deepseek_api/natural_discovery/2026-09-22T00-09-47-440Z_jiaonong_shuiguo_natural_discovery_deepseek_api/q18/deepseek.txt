想避免买到太生或太熟的香蕉，关键是**先明确你打算几天内吃完**，再按成熟度挑选。

可以直接按这个标准判断：

1. **当天或第二天吃**  
   选**通体金黄、少量褐斑**的。  
   褐斑越多越甜，但超过几处大面积黑斑就可能过熟。

2. **2～3天内吃**  
   选**金黄为主、两端略青、没有褐斑**的。  
   这种到家用一两天会刚好进入适口期。

3. **3～5天后吃**  
   选**黄中带青，尤其果柄和两头还偏绿**的。  
   完全青硬的香蕉通常要更久，冬天可能一周以上才熟。

4. **想放更久**  
   选**整体偏青、硬、无压伤**的，回家后按需要催熟。  
   不要选已经有裂口、渗汁、明显黑斑的。

到店挑选时重点看：

- **看颜色分布**：整串成熟度通常不完全一致，挑中间状态的更稳。
- **看果柄**：果柄发绿说明还偏生；果柄发黑、干缩说明偏熟。
- **摸硬度**：轻捏有弹性、不软塌最好；硬得像木头就是生，一按一个坑就是熟。
- **看棱角**：香蕉棱角明显通常偏生；圆润饱满通常更熟。
- **避开损伤**：有压伤、裂口、发霉、酒味的不要买，熟得会特别快。
- **别只看斑点**：少量芝麻斑是甜，大片黑斑和凹陷是过熟或损伤。

如果你买回家后想控制成熟速度：

- **想快点熟**：和苹果或梨放在同一个纸袋里，室温放。
- **想慢点熟**：拆开分散放，别闷在塑料袋里；成熟后可冷藏。  
  冷藏会让香蕉皮变黑，但里面果肉通常还能保持几天。
- **已经太熟**：直接吃、做奶昔、香蕉面包，或者去皮冷冻。

最实用的买法：**如果计划当天吃，买带少量褐斑的；如果计划几天内吃，买金黄无斑或轻微带青的；如果要放一周，买青黄相间、硬挺无伤的。**
