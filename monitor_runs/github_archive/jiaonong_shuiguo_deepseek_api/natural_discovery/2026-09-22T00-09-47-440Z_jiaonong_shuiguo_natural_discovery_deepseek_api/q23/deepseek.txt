常见支持形式：

- **陈列支持**：提供堆头、地堆、端架、冷链陈列物料，或派促销员/理货员协助。部分供应商给陈列补贴、陈列返利，条件是占据指定位置和面积、保持一定天数。
- **海报支持**：提供单品海报、爆炸贴、吊旗、价签模板，或承担部分印刷费。如果是超市统一 DM/APP 海报，供应商可能以“海报费/促销服务费”形式出钱。
- **试吃支持**：提供试吃样品、试吃台，或派试吃员。生鲜水果试吃涉及食品安全和损耗，通常需要明确谁备货、谁承担损耗、谁负责人员健康证。
- **价格与费用支持**：除物料外，还可能有特价供货、折扣补贴、买赠、满减、损耗补贴等。

落地时建议明确：

1. **责任与费用**：物料制作费、人员工资、试吃损耗由谁承担。
2. **位置与期限**：堆头/端架位置、面积、陈列天数、排面标准。
3. **销量与返利**：是否绑定销量目标，未达标是否扣减补贴。
4. **食品安全**：试吃样品来源、保质期、操作规范、人员健康证明。
5. **结算方式**：费用是直接减免货款、返利，还是单独开票支付。

实际操作中，强势品牌或大供应商支持更多，小供应商可能只给货或少量物料。采购量越大、账期和合作越稳定，拿到的支持通常越多。
