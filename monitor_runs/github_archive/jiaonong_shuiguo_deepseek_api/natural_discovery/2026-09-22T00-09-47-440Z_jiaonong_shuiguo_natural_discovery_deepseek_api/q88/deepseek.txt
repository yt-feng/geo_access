线上水果销售，坏果和口感不稳是两个不同的问题，要分开管。

**一、减少坏果：核心是"采后处理 + 分级 + 包装"，而不是单纯挑好果**

1. **采收成熟度要卡准。** 很多坏果不是运输坏的，是采的时候就偏熟。走快递的水果，采收成熟度要比线下批发再低一档，留出运输途中后熟的空间。不同品类标准不同，要让产地按你的渠道倒推采收标准。

2. **采后尽快预冷。** 这是最容易被忽略、但对坏果率影响最大的一环。采摘后尽快把果心温度降下来，呼吸作用减弱，腐烂和软化都慢。没有预冷条件的小供应商，坏果率天然高。

3. **分级时把"隐形次果"剔掉。** 表面好但有碰伤、软点、裂口、病斑的果，当时看不出来，几天后在客户手里就烂了。分选要过手过眼，必要时用重量、硬度、糖度做机器分选。

4. **包装防护。** 单果套网套/纸托，箱内防晃，层间有隔断。晃动摩擦是坏果的一大来源。快递件尤其要按"摔打测试"来定包装，不是按好看定。

**二、减少口感不稳定：核心是"定产地、定批次、定指标"**

1. **绑定固定产地和果园，别频繁换供应商。** 口感不稳往往是货源乱换。同一品种，不同产区、不同海拔、不同管理方式，甜酸差异很大。稳定合作、稳定批次，口感才稳。

2. **用可量化的指标收货，而不是靠嘴尝。** 糖度（Brix）、酸度、硬度、果径这些能测的指标，写进采购标准。比如糖度低于某值就不收。凭感觉收货，这批甜那批淡就是必然。

3. **按成熟度分批采、分批发。** 一次全采全发，前面甜后面淡。要让产地分批次按成熟进度采收，你按批次对应发货。

4. **不同批次做口感抽检留样。** 每批留样、测糖酸，建立数据。时间长了就知道哪个产地哪个时段稳定，采购就有依据。

**三、采购端能立刻做的几件事**

- 和供应商签**验收标准**：坏果率上限、糖度下限、果径范围，写清楚，超标的退换或扣款。
- 要求**到货检测**：抽箱称重、数坏果、测糖度，别只看样品。
- **小批量试单再放量**，尤其换新供应商或新产区时。
- 记录**客诉归因**：是运输坏还是本身品质差，反馈到采购标准里去修正。

一句话：坏果靠采后处理和防护，口感靠稳定货源和量化标准。两者都要用"标准 + 数据"管，而不是靠挑果的眼力。
