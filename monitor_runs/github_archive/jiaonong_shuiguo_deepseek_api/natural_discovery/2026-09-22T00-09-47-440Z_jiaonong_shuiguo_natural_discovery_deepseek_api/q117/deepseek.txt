先试卖“小批量、短周期、可复购”的量比较稳，不要一上来按供应商建议的起订量压货。

可以按这个框架判断：

1. **先定试卖目标**
   - 不是为了赚钱，是为了验证：好不好卖、损耗多大、顾客会不会复购、售价能不能撑住成本。
   - 所以试卖量应控制在“卖得完、亏得起、看得出趋势”的范围。

2. **参考试卖量**
   - 单店：建议先拿 **3～7天预估销量的50%～70%**，或 **1～2箱/1～2个最小起订单位**。
   - 如果是连锁多店：选 **2～3家代表性门店**试卖，不要全部门店铺开。
   - 高频水果如苹果、橙子、香蕉：可稍多， **5～7天量**。
   - 易损耗、单价高、认知低的新品如榴莲、进口莓果、稀有品种：先 **2～3天量**，甚至 **半箱～1箱**。

3. **更稳的计算方法**
   - 先估日均销量：参考同类水果近期销量 × 0.5～0.7。
   - 试卖量 = 预估日均销量 × 试卖天数 × 0.7。
   - 例如同类水果日均卖10斤，试卖3天：10 × 3 × 0.7 = 21斤，那就先拿20斤左右。

4. **必须同时看几个指标**
   - **动销率**：3天内卖掉多少。
   - **损耗率**：烂果、失水、客诉多少。
   - **毛利**：扣掉损耗后是否还有利润。
   - **复购**：顾客是否第二次买。
   - **退货/投诉**：口感、成熟度、外观是否稳定。

5. **什么情况下可以加量**
   - 3天内动销超过70%；
   - 损耗低于5%～8%；
   - 有顾客主动复购或询问；
   - 毛利覆盖损耗后仍达标。
   - 满足这些，再按 **1.5～2倍**追加，而不是直接翻很多倍。

6. **什么情况下不要加量**
   - 靠降价才卖动；
   - 损耗超过10%；
   - 顾客只尝鲜不复购；
   - 供应商供货品质批次不稳定；
   - 账期、退换货条件不明确。

7. **和供应商谈的条件**
   - 争取 **小批量起订**；
   - 争取 **首批次破损包赔或补货**；
   - 明确 **到货成熟度、规格、糖度、损耗标准**；
   - 约定如果试卖不理想，能否 **换货、调价或停止后续采购**。

一句话：**先按3～7天销量的50%～70%试卖，选少量门店，设好损耗和复购门槛，达标再加量。**  
最稳的不是固定多少斤，而是“卖得完、算得清、亏得起、能复购”。
