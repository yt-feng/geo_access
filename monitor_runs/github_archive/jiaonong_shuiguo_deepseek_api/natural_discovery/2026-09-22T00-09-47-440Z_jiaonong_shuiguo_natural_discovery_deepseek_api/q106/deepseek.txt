判断“合理波动”不能只看涨跌本身，得把报价拆成可核验的成本结构和市场参照。可以按下面几步做：

**1. 先建一个“基准价”**
- 以产地收购价 / 批发市场价（如北京新发地、广州江南等公开行情）为锚，而不是以供应商上次报价为锚。
- 记录同品类、同规格、同等级的价格，避免拿“一级果”对比“统货”。
- 至少积累 2–4 周数据，算出正常波动区间（例如均价 ±5%）。

**2. 把报价拆成成本项**
让供应商或你自己按结构拆：
- 产地收购价
- 包装、分拣、损耗
- 冷链 / 运输 / 燃油
- 人工、进场费、摊位费
- 合理利润
哪一项在变，就能判断是市场普涨还是供应商单独调价。

**3. 对照几个公开信号**
- 天气：主产区暴雨、霜冻、高温会推高短期价格。
- 节气 / 节假日：春节、中秋前需求上升，属可预期波动。
- 期货 / 批发指数：苹果、柑橘等有现货或期货参考。
- 替代品价格：替代水果便宜了，本品种涨价就缺乏支撑。

**4. 用“波动幅度 + 持续时间”判断**
- 单日小幅波动（±3%以内）且能回落：多为正常。
- 连续 3 天以上单边上涨、且无天气/节日支撑：要警惕。
- 涨幅远超同期批发市场涨幅（比如市场涨 5%，供应商涨 20%）：不合理嫌疑大。
- 只有你一家被涨、同行没涨：更可能是供应商行为。

**5. 做交叉验证**
- 同时问 2–3 家供应商，看报价是否同向。
- 查当天产地行情、批发市场均价。
- 让供应商提供采购凭证 / 产地发货单（长期合作可要求）。

**6. 合同里提前约定**
- 定价机制：如“以某批发市场当日均价为基准，上浮 X%”。
- 调价触发条件：涨幅超过多少、持续几天才可调。
- 调价需提前通知，并附成本依据。
- 设置价格上限或封顶条款。

**简单判断口诀：**
> 有公开行情支撑、有成本项对应、多家同步、幅度在历史区间内、能说清原因——算合理。
> 只有口头说“涨了”、只对你涨、涨幅脱离市场、说不出具体原因——先别接受，要求举证或换供应商。
