通常能，但要看你是“跟谁采购、采购量多大、合作多久、促销是不是对供应商也有利”。

一般情况：
- **价格支持**：可能有，但常见不是直接降价，而是周末促销价、限时返点、满额补贴、特价单品、搭赠。中小水果店如果不从产地/一级批发直采，而是从二级批发市场拿货，价格支持通常很有限，更多是“今天这个品便宜点”。
- **物料支持**：比价格支持更容易拿到。比如纸箱、贴纸、海报、吊旗、价签、试吃盒、手提袋、展架。供应商如果有品牌或固定包装，通常愿意给一点。
- **账期支持**：周末促销如果走量，部分供应商可能给短期账期或先货后款，但这对小水果店不一定容易谈。

关键判断：
1. **你有没有量**：周末两天能不能稳定走几十箱、几百斤，是谈判核心。
2. **你是不是长期客户**：长期稳定采购比单次压价更容易拿到支持。
3. **促销品是不是供应商主推品**：如果正好是他想推的货，支持概率高。
4. **你是不是帮他清库存**：应季、易损耗、库存大的品，供应商更愿意给特价或搭赠。
5. **你是不是能帮他做曝光**：门店海报、社群、朋友圈、短视频带上供应商品牌，物料支持更容易谈。

可以直接这样谈：
- “这周末我准备做两天的爆款促销，主推你家XX，预计走XX箱/XX斤。价格上能不能给个周末促销价，或者满XX箱返点？”
- “物料上能不能支持一批价签、海报、试吃盒？我店里和社群都帮你推这个品。”
- “如果量起来，下周我继续从你这拿，能不能这次先给支持？”

更现实的预期：
- 从**二级批发市场**拿货：价格支持少，物料可能有一点，主要靠当天议价。
- 从**一级批发/产地/品牌供应商**拿货：价格支持、返点、物料、账期都更可能谈。
- 如果供应商本身不做品牌、不做促销，基本只能谈价格，物料别期待太高。

建议你周末促销不要等供应商给支持才做。先定1-2个引流爆品，自己把价格打下来，再拿预计销量去找供应商谈“补差、返点、搭赠”，成功率会高很多。
