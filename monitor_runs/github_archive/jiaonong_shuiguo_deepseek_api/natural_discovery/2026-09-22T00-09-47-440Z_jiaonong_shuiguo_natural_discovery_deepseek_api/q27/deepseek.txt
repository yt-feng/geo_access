判断苹果和橙子的规格是否适合门店销售，核心看**一致性、可陈列性、损耗率、客群匹配**四件事。下面按品类给可执行标准。

## 一、先定门店定位，再定规格

不同业态对规格要求完全不同：

| 门店类型 | 苹果常见规格 | 橙子常见规格 |
|---|---|---|
| 社区生鲜/夫妻店 | 中果为主，75-80mm | 中果，65-75mm |
| 精品超市/水果店 | 大果/精品，80-90mm | 75-85mm |
| 商超散卖 | 70-85mm混级也可 | 60-80mm |
| 礼盒/团购 | 85mm以上，果形端正 | 80mm以上 |

所以第一步不是问"多大算好"，而是问**你的主力客群买回家干什么**：日常吃、送礼、还是给孩子零食。

## 二、苹果判断要点

1. **横径（不是纵径）**  
   用卡尺量果子最宽处。常见分级：
   - 70-75mm：中小果，适合散卖、家庭日常
   - 75-80mm：主流中果，最好卖
   - 80-85mm：大果，适合精品
   - 85mm以上：礼盒级

2. **看整齐度**  
   同一批货里，最大和最小差超过10mm，陈列会乱，顾客挑拣多，损耗上升。

3. **看果形和表皮**  
   - 果形偏斜、畸形多，不适合精品陈列
   - 表皮有压伤、日灼、锈斑，要按损耗扣价
   - 果梗新鲜度反映采摘和储运时间

4. **试硬度与口感**  
   硬度过低说明过熟，货架期短；过硬可能未成熟，口感差。抽样切开看果肉是否发绵。

## 三、橙子判断要点

1. **横径为主，结合重量**  
   橙子同样量最宽处：
   - 60-65mm：小果，适合榨汁或低价引流
   - 65-75mm：中果，日常销售主力
   - 75-85mm：大果，精品或礼盒
   - 85mm以上：少见，需确认品种是否正常

2. **手感重、皮薄**  
   同样大小，越重说明水分足、皮薄肉厚。轻飘飘的通常皮厚、干瘪。

3. **看表皮和油胞**  
   - 表皮细腻、油胞均匀，卖相好
   - 粗皮、浮皮、青斑多，影响陈列和复购
   - 脐橙要看脐部是否完整，避免裂口

4. **测糖酸比**  
   有条件用糖度计，橙子可溶性固形物一般要≥10%-12%才好卖。酸度过高，顾客尝一次不回头。

## 四、门店实操判断流程

1. **抽样**：每批随机抽20-30个，量横径、称重、看外观。
2. **算整齐度**：合格率低于80%，不建议按精品价卖。
3. **算损耗**：把压伤、腐烂、畸形挑出来，损耗超过5%-8%要重新谈价或拒收。
4. **看陈列**：能否码成稳定堆头？大小混放会不会顾客翻乱？
5. **试销**：先小批量上架3-5天，看动销和顾客反馈，再决定是否放量。

## 五、直接可用的验收线

- **苹果**：横径75-80mm、大小差≤10mm、无严重压伤、硬度适中、果梗新鲜。
- **橙子**：横径65-75mm、手感重、皮薄光滑、糖度≥10%、无浮皮裂口。
- **通用**：同批整齐度≥85%， visible损耗≤5%，否则降级或拒收。

一句话：**规格不是越大越好，而是和你门店客群、售价、陈列方式匹配，且同一批货足够整齐、损耗可控。**
