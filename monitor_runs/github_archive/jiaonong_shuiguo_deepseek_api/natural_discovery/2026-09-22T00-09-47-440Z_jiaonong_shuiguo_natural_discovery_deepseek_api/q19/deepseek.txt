如果只选一个最该盯的，答案取决于你卖的是**整果还是切果**，但大多数超市最该关注的是：**切果损耗**。

原因很简单：

- **甜度**：顾客复购的关键，但超市很难逐个测糖，通常只能靠品种、产地、季节和到货批次判断。
- **大小**：影响定价和陈列，但不是决定赚钱的核心。
- **外观**：影响第一次购买，过度追求好看会推高采购成本。
- **切果损耗**：直接决定毛利。菠萝皮厚、冠芽大、去眼深，出肉率差几个点，利润就没了。

更实用的判断顺序是：

1. **先看切果损耗和出肉率**  
   同样进货价，出肉率高的菠萝才是真便宜。  
   重点看：去皮后净重、去眼深度、黑心/水心比例、熟度是否适合切盒。

2. **再看甜度和成熟度稳定性**  
   菠萝不甜，切盒也卖不动。  
   重点看：批次糖度、是否催熟均匀、有没有酸涩、酒精味。

3. **然后看外观和大小**  
   外观决定陈列吸引力和整果销售；大小决定定价带和顾客感知。  
   但这两项不能压过损耗和口感。

4. **最后按渠道分重点**  
   - 卖整果为主：甜度 > 外观 > 大小 > 切果损耗  
   - 卖切果/果切为主：切果损耗 > 甜度 > 大小 > 外观  
   - 做促销引流：外观和大小更显眼，但仍要算损耗，否则越卖越亏。

一句话：**整果生意看甜度和外观，切果生意看损耗和甜度；如果只能抓一个经营指标，先抓切果损耗。**
