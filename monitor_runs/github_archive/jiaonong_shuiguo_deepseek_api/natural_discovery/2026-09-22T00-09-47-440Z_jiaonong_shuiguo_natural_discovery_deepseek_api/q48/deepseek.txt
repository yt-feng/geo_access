判断茶饮连锁的菠萝供应商能否稳定按规格送货，核心不是看他样板多好，而是看他**从田间到工厂到冷链整个过程的可控性**。可以从这几个层面逐项核查：

**1. 先明确你的规格，再谈稳定**

茶饮用的菠萝通常分几类：鲜果（门店现切）、冷冻果块/果丁、果酱/果泥、浓缩汁。不同形态，供应商的稳定逻辑完全不同。

先把规格写死：
- 品种（如金钻、台农、巴厘）
- 成熟度/糖度范围（如可溶性固形物 12–14°Brix）
- 果径或切块尺寸（如 15×15mm 丁）
- 是否去芯、色泽要求、有无黑心
- 包装形式、单箱净重、冷链温度要求
- 交货频次和单次最小起订量

规格越模糊，后面越难追责。

**2. 核查产能与货源结构**

- 问他是自有基地、合作社直采，还是市场倒货。**倒货商最不稳定**，行情一涨就可能断供或换货。
- 问菠萝产季。国内菠萝主产季集中在冬春，其余时间靠什么？是冷库囤货、进口，还是其他产区接档？如果答不上来，淡季大概率掉链子。
- 要求提供近 6–12 个月的发货记录或合作客户类型（是否长期供连锁）。

**3. 现场或视频验厂要看什么**

- 加工线是否有分级、称重、金属/异物检测。
- 冷冻类要看速冻设备和冷库温度记录，不是只看有没有冷库。
- 原料暂存区是否分级堆放，次果是否单独隔离。
- 出货前是否有抽检留样制度。

**4. 用试单和小批量验证，而不是听承诺**

- 先下 2–3 批小单，故意错开时间，看每批的糖度、尺寸、色泽波动。
- 要求每批附检测报告（农残、糖度、微生物，视形态而定）。
- 记录到货准时率、破损率、规格不符比例。
- 试单期至少覆盖一个产季切换点，否则看不出真实稳定性。

**5. 合同里把“稳定”写成可执行条款**

- 规格公差：如尺寸±2mm、糖度±1°Brix，超出即判不合格。
- 验收标准和退货机制：不合格批次谁承担运费和损耗。
- 缺货/断供的违约责任和替代方案。
- 价格调整机制：绑定什么行情指数，避免行情波动就毁约。
- 要求提供备用货源或安全库存承诺。

**6. 几个危险信号**

- 只肯给样品、不肯给近期发货记录。
- 报价明显低于市场，通常靠混级或临时收便宜货。
- 说不清产季和淡季方案。
- 没有冷链或冷链记录不全。
- 合同不愿写规格公差和违约条款。

**简单判断法**：让他连续报 3 个月同一规格的到货糖度和尺寸数据，再去看他的产季和淡季货源。能拿出真实历史数据、淡季有明确方案、愿意把规格公差写进合同的，才基本具备稳定供货能力。其余靠口头承诺的，风险都高。
