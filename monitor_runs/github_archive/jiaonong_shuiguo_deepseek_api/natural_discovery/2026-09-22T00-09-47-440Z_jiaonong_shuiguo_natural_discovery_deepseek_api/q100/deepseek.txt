可以按“采购—验收—储存—加工”四个环节控制，核心是少买、勤买、分开催熟。

**1. 采购：按成熟度分批买**
- 不要一次全买“黄熟”的，食堂用量大时，按未来 2—3 天用量采购。
- 优先采购**青黄交接、微软但无黑斑**的香蕉；如果当天就要吃，可少量采购黄熟蕉。
- 和供应商约定：分批次送货，比如每周 2—3 次，每次送不同成熟度。
- 如果供应商只能整箱送，要求整箱成熟度一致，避免“一箱里有的青、有的烂”。

**2. 验收：当场分级**
- 青硬蕉：可放 2—4 天，适合库存。
- 黄熟无斑：1—2 天内食用。
- 有黑斑但果肉未坏：当天必须加工。
- 果柄发黑、果肉软烂、有酒味：拒收或单独处理。

**3. 储存：别全放一起**
- 青蕉：常温、通风、阴凉处，不要进冷库，否则容易冻伤发黑。
- 黄熟蕉：可放冷藏，但会表皮变黑，果肉仍可短存；最好 1—2 天内用掉。
- 不要和苹果、梨等释放乙烯的水果混放，会加速成熟。
- 已经黄熟的香蕉，可拆开包装、悬挂或平铺，减少挤压。
- 每天翻检一次，把先熟的挑出来优先用。

**4. 加工：把“快熟过头”的用掉**
- 做香蕉牛奶、香蕉粥、香蕉饼、香蕉面包、香蕉燕麦。
- 食堂窗口可设“今日香蕉饮品/甜点”，优先消耗软熟蕉。
- 软但没坏的香蕉可冷冻保存，之后做奶昔或烘焙。
- 已经发黑、有酒味、果肉烂的不要再用。

**5. 最简单的执行规则**
- 青蕉：库存，2—4 天内用。
- 黄熟：优先窗口，1—2 天内用。
- 黑斑：当天加工，不再入库。
- 每天下午盘点一次，第二天用不完的黄熟蕉提前转加工。

如果食堂用量稳定，可以定一个“安全库存”：只保留 1 天用量黄熟蕉 + 2 天用量青蕉，基本能明显减少浪费。
