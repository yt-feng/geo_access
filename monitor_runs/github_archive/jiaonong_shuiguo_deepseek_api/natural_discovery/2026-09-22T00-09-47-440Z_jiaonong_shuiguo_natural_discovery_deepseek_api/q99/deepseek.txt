选择下午茶水果供应商，核心是抓住三条：**能稳定批量供货、配送时效可控、损耗和售后有兜底**。下面按可执行步骤说。

## 一、先明确自己的需求（定标准再找供应商）
1. **人数与规格**：多少人、每人份量（常见按 200–300g/人 配）。
2. **预算**：人均 8–15 元是常规档，20 元以上可上精品果切或进口果。
3. **形式**：整果（便宜、耐放）还是果切拼盘（方便但贵、保质期短）。
4. **频次**：一次性活动还是每周固定，固定频次更容易谈价。
5. **配送时间**：必须卡在下午茶前 1–2 小时到，太早不新鲜、太晚耽误。

## 二、供应商类型对比
| 类型 | 优点 | 风险 |
|---|---|---|
| 本地水果批发市场商户 | 价格低、可议价 | 配送和售后弱，需自己盯 |
| 生鲜 B2B 平台（如美菜、蜀海类） | 标准化、可开票、有配送 | 起送量、品类受限 |
| 本地果切/烘焙配送商 | 开箱即食、省事 | 单价高、需看卫生资质 |
| 连锁水果店团购 | 品质稳定、就近配送 | 批量折扣有限 |
| 电商平台企业购 | 开票方便 | 时效和新鲜度不稳定 |

**批量配送优先选：本地 B2B 生鲜平台 + 本地果切商**，兼顾价格和时效。

## 三、筛选供应商的硬指标
1. **配送能力**：是否有冷链车/冷藏箱，能否承诺具体送达时段。
2. **起送量与加急**：是否设最低金额，临时加量能否补。
3. **损耗与售后**：坏果怎么赔（按比例退还是补送），多久内反馈有效。
4. **资质**：营业执照、食品经营许可（果切必须要有）。
5. **结算**：能否开增值税发票、支持月结还是现结。

## 四、实操建议
1. **先小批量试单**：第一次只订一次下午茶的量，重点看准时率、新鲜度、坏果率。
2. **要样品报价单**：让 2–3 家按同一规格报价，横向比。
3. **合同写清**：送达时间、坏果赔付比例、临时增减量规则。
4. **固定 1 主 1 备**：主供应商日常用，备选应对临时加量或断供。
5. **选当季水果**：当季果便宜又新鲜，反季果贵且品质不稳。

## 五、避坑
- 别只比单价，算上坏果损耗和配送费才是真实成本。
- 果切务必确认冷链和制作时间，夏天风险高。
- 口头承诺不算，写进订单或合同。
