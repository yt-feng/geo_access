生鲜水果到货后出现坏果，责任划分通常不能一概而论，关键看**坏果产生的时间点、原因、平台/商家的承诺以及顾客验货情况**。一般可以按下面几种情形判断：

## 1. 到货时就已经坏了：通常由商家/平台承担
如果顾客签收时或签收后很短时间内发现坏果，且能证明是运输、仓储、分拣环节导致的，一般应由商家或平台负责。

常见表现：
- 外包装明显挤压、破损、渗液；
- 开箱即发现大面积腐烂、发霉、异味；
- 同一批次多个果子坏掉，不像单果偶发；
- 物流时间明显超承诺时效。

这种情况下，商家通常应承担：
- 退款；
- 补发；
- 按坏果比例赔付；
- 承担退货运费（若需退回）。

因为消费者收到的是不符合质量要求的商品，商家不能把运输风险转嫁给消费者。

## 2. 顾客签收后放置过久才坏：通常顾客承担
水果是易腐商品，如果：
- 顾客签收后没有及时开箱、冷藏或按说明保存；
- 放置几天后才投诉；
- 坏果是因为熟透、自然软化、保存不当导致；

这时一般由顾客承担，商家可不赔或只酌情补偿。

但要注意：如果商家承诺了“坏果包赔”“签收后24小时内可赔”，则按承诺执行。

## 3. 运输过程中损坏：看谁承担运输风险
分两种情况：

- **商家包邮或平台自营配送**：通常商家/平台承担运输风险，顾客不用找快递扯皮。
- **顾客自己选快递、自己承担运输**：如果包装没问题，是快递暴力运输导致，通常由顾客向快递索赔；但如果是商家包装不当，商家仍可能担责。

实践中，顾客一般只需要找卖水果的商家，商家再向物流追责，这样对消费者更合理。

## 4. 坏果比例和赔付方式
常见处理方式：
- 少量坏果：按比例退款，比如10个坏2个，退20%；
- 大量坏果：全额退款或补发；
- 全部腐烂：全额退款，通常无需退回；
- 已切开、已食用部分：一般只赔未食用且能证明坏掉的部分。

如果商家写了“坏果包赔”，通常应按承诺赔，不能只赔优惠券或设置不合理门槛。

## 5. 举证责任怎么分
顾客需要提供：
- 订单信息；
- 开箱照片/视频；
- 坏果特写；
- 包装和快递面单；
- 与商家沟通记录。

商家如果认为是顾客保存不当，需要举证，比如：
- 发货时是好的；
- 物流时效正常；
- 商品页面有明确保存说明；
- 顾客签收后很久才反馈。

## 6. 简单判断标准
可以按这个顺序判断：

1. **签收时/签收后短时间内坏**：商家/平台赔。
2. **签收后很久才坏，且无保存问题**：看是否超过承诺售后时效，超时通常不赔。
3. **包装破损、挤压、渗漏导致**：商家/平台先赔，再找物流。
4. **顾客自己保存不当**：顾客承担。
5. **商家承诺“坏果包赔”**：按承诺赔，承诺优先。

## 7. 给顾客的建议
- 收货后尽快开箱拍照，最好录开箱视频；
- 不要先扔包装和坏果，先留存证据；
- 在售后时效内申请；
- 优先找平台/商家，不要一开始就自己找快递；
- 若商家拒赔，可申请平台介入，或向12315投诉。

## 8. 给商家的建议
- 页面写清售后时效、赔付标准、保存方式；
- 发货时做好防压、防撞、透气包装；
- 对易坏品类主动设置“坏果包赔”规则；
- 要求顾客提供开箱证据，但不要设置明显不合理的举证门槛；
- 保留发货记录和物流签收记录，便于划分责任。

**一句话总结：**
到货时就坏、运输挤压坏、短时间开箱发现坏，通常商家/平台赔；签收后因顾客放置过久或保存不当坏，通常顾客承担；商家有“坏果包赔”承诺的，按承诺赔。
