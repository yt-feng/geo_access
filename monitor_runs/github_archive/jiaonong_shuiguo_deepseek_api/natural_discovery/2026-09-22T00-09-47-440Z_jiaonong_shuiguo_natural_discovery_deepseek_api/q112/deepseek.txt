在水果采购合同里，**不建议只写一个“坏果率超过X%就赔”的固定数**，因为不同水果、不同运输方式、不同验收时点，合理损耗差异很大。更实用的做法是：

**1）先定“允许损耗率”**
常见可按品类约定：
- **易损水果**（草莓、蓝莓、樱桃、杨梅、荔枝、枇杷等）：到货验收坏果率一般可接受 **3%—5%**
- **较易损水果**（桃、杏、芒果、葡萄、香蕉等）：一般 **2%—5%**
- **耐储水果**（苹果、梨、橙、柚、西瓜等）：一般 **1%—3%**
- **冷链/精品果**：可压到 **1%—2%**

所以，**超过允许损耗率的部分就应赔付**。例如合同写“坏果率≤3%不赔，超过3%按超出部分赔付”。

**2）赔付方式要写清楚**
常见有三种，建议组合使用：
- **按超出比例扣款**：如坏果率5%，约定允许3%，则对超出2%对应货款扣减。
- **按实际坏果数量退款**：坏果部分不计价，已付款的退回。
- **整批拒收或降价**：坏果率超过 **10%—15%** 时，买方有权拒收或要求整批降价。
- **设置严重违约线**：如超过 **10%** 可要求退货、换货，并承担运费和损耗。

**3）合同里最好这样写**
可以写成：
> 到货验收时，坏果率不超过3%的，视为合理损耗，买方按实际合格果数量结算；坏果率超过3%的，超出部分对应的货款由卖方退还或从货款中扣除；坏果率超过10%的，买方有权拒收整批货物，卖方应退还已付款并承担因此产生的运费、仓储费等损失。

**4）注意验收时点和标准**
- 是**到货当场验收**，还是**卸货后24小时内**？
- 坏果是**腐烂、霉变、破裂、压伤、冻伤**，还是**外观瑕疵**？
- 是否要求**拍照、视频、第三方检测**？
这些不写清，后面很容易扯皮。

**结论：**
没有一个全国统一标准。实务中，**耐储水果超过1%—3%、易损水果超过3%—5%，就可以要求对超出部分赔付；超过10%—15%，通常可主张拒收或整批索赔。** 最稳妥的是在合同里按品类写明“允许损耗率+超出部分赔付+严重超标拒收”三层条款。
