夫妻店第一次试单，核心原则是：**少量多批次、先验货后放量、用可量化标准筛人，而不是凭感觉聊得来就长期合作。**

下面按品类和流程给你一套可直接执行的做法。

## 一、试单前先定好三条底线

1. **单次试单量控制在 1～2 天的销量**，宁可卖断也别压货。
2. **每种单品只找 2～3 家同时试**，横向比，不要一上来就独家。
3. **当场验货、当场记录**，坏果率、规格、到货时间都写下来，别靠记忆。

## 二、三个常见单品怎么试

### 香蕉
- 最容易出问题的是**熟度**和**压伤**。
- 试单要点：明确要几成熟（比如到店后 2～3 天能卖完的熟度），要求看**整箱底层和中间**，不只是表面。
- 记录：到货时青/黄/黑比例、断把率、磕碰黑斑数量。
- 建议：先试半箱到一箱，观察 2～3 天货架表现，再决定是否加量。

### 苹果
- 看**规格一致性**和**硬度、糖度口感**。
- 试单要点：要求大小分级（比如 75、80），当场随机抽 5～10 个切开或咬开看内部是否有糠心、黑心。
- 记录：大小是否整齐、表皮伤痕比例、口感是否稳定。
- 建议：苹果耐放，可以一次试 1～2 箱，但重点比“同一规格不同供货商”的稳定性。

### 橙子
- 看**皮厚薄、水分、酸甜比、有无软烂**。
- 试单要点：随机抽几个切开看水分和籽情况，捏一下有没有软果。
- 记录：软烂率、干水率、大小是否均匀、表皮是否打蜡或催色过度。
- 建议：橙子损耗多出在“看着好、里面干”，一定要切开验。

## 三、试单流程（直接照做）

1. **先要报价单**：写明品种、规格、产地、包装、起送量、结算方式、售后规则。
2. **小批量下单**：每个单品 1～2 天销量，要求当天或次日清晨到货。
3. **到货当场验**：
   - 随机抽 3～5 箱/件
   - 称重、数个数、查坏果
   - 拍照留证
4. **上架观察 2～3 天**：记录实际损耗、顾客反馈、能卖几天。
5. **算综合成本**：不只看进价，要算“进价 + 损耗 + 退换 + 配送时间”。
6. **再决定加量或换人**：同一单品保留 1 家主供 + 1 家备选。

## 四、判断供货商靠不靠谱的硬标准

- 坏果率能不能控制在约定范围内，比如 3%～5% 以内。
- 出问题是否**愿意补货或退款**，而不是只口头道歉。
- 到货时间是否稳定，夫妻店最怕早市前不到货。
- 报价是否透明，有没有临时加价、以次充好。
- 能不能接受小批量试单，不愿意试的通常后面也难配合。

## 五、给你的实操建议

- 第一次别签长期独家，先按**周**合作。
- 每次试单只重点测 1～2 个指标，比如这次测损耗，下次测到货时间。
- 建一个简单表格：日期、单品、供货商、进价、到货量、坏果量、损耗率、售卖天数、是否续单。
- 连续 2～3 次稳定达标，再逐步把主力单品交给它。

一句话：**试单不是试价格，是试“到货质量 + 损耗 + 售后 + 稳定性”。** 先用小单把这几项跑通，再谈长期和账期。
