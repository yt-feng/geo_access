超市和水果供应商之间的账期没有全国统一标准，主要看**超市规模、水果品类、供应商议价能力、是否冷链/易损耗、结算方式**。常见区间可以这样判断：

1. **大型连锁商超 / 全国性卖场**
   - 常见账期：**30～60天**
   - 强势渠道可能做到：**60～90天**
   - 部分生鲜、水果类为了保供应，会单独谈成：**15～30天**

2. **区域连锁超市 / 中型商超**
   - 常见账期：**15～45天**
   - 更常见的是：**30天左右**
   - 如果供应商是本地果园或批发商，可能接受：**7～15天**

3. **社区超市、生鲜店、小型连锁**
   - 常见账期：**现结、周结、7～15天**
   - 能做到 **30天** 已经算比较长
   - 很多小超市更倾向：**货到付款、半月结、月结**

4. **水果品类差异**
   - **易损耗、时令性强、冷链要求高**：账期通常更短，**7～15天**甚至现结更常见。
   - **耐储存水果，如苹果、梨、橙子、进口果**：可能谈到 **30～45天**。
   - **长期稳定供货、量大、品牌化供应**：有机会谈到 **30～60天**。
   - **新供应商或小供应商**：通常先现结或短账期，合作稳定后再拉长。

5. **实操建议**
   - 如果你是**超市方**：先按 **30天** 作为谈判起点，优质大供应商可争取 **45～60天**，但生鲜水果不建议压太久，否则容易影响供货质量。
   - 如果你是**供应商**：优先争取 **7～15天**或**周结**；如果对方要求 **30天以上**，要把资金成本算进报价，或约定逾期利息。
   - 合同里最好写清：**对账日、开票日、付款日、逾期违约金、质量问题扣款规则**。因为水果损耗和退换货争议多，账期之外更要明确结算口径。

简单说：  
**大超市常见30～60天，中小超市常见7～30天，水果生鲜类更偏向7～15天或月结。**  
真正谈判时，账期往往和采购量、价格、损耗承担、促销支持绑定，不是单独一个天数问题。
