要减少香蕉放坏，采购时要按“销售节奏”分批控熟度，而不是统一要熟或要青。

**1. 按销量定到货频率**
- 日销快：每天或隔天到货，减少库存积压。
- 日销慢：每次少进，优先小批量、多频次。
- 不要一次进大量同熟度香蕉，否则会集中变黄、集中坏。

**2. 对供应商明确要求熟度**
建议按用途分开：
- **当天/次日主推**：要“微黄转色、果皮偏黄但两端带一点绿”，约3—4成熟转色，适合1—2天卖。
- **2—3天后卖**：要“青黄相间、果身硬、无黄斑”，约2成熟，适合后熟销售。
- **特价/加工用**：可要“已转黄、适合当天卖完”的，但必须单独少量。

不要只说“要熟的”，要具体说：
> “要青黄相间、果身硬、无黑斑、无裂口、把儿不流水；发黄比例不超过两成。”

**3. 到货时间要求**
- 最好要求**清晨到货**，当天上架，避免白天高温运输和久放。
- 避开中午、下午高温时段到货。
- 夏季可要求**冷链或空调车运输**，到店后立即拆箱、通风、分拣。
- 冬季避免冻伤，要求运输温度不要过低。

**4. 验收标准**
到货时直接抽检：
- 果皮：无大面积黑斑、无软烂、无裂口。
- 果柄：不流水、不发黑。
- 手感：微黄的可稍软，青黄的应硬挺。
- 温度：不烫手、不冰手。
- 箱内：无大量水汽、无压伤、无催熟剂异味。

**5. 采购话术示例**
> “我要分两批：一批青黄相间、硬身，2—3天卖；一批微黄、无黑斑，1—2天卖。请早上7点前到货，夏天走冷链，箱内不要闷水。发黄超过两成、有压伤或黑斑的不要。”

**6. 到店后管理**
- 先卖微黄的，青黄的放通风处后熟。
- 不要整箱堆压，拆箱散放。
- 香蕉怕冷也怕闷，别直接放冷库深处；夏天可放阴凉通风处，必要时空调房。
- 每天挑出黄斑多的，及时特价或做果切，避免传染整批。

核心要求一句话：**分批采购、按销售天数定熟度、早上到货、夏季冷链、验收拒收黑斑软烂。**
