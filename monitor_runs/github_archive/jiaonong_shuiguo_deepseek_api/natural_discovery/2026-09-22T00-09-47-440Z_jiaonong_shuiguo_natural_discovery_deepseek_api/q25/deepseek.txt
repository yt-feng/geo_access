# 多店小量场景下的水果供货模式建议

## 先明确你的核心矛盾

- **门店多**：需要统一标准、统一配送、统一结算，管理成本高
- **单店量小**：单次采购量上不去，拿不到大批发价，且水果损耗风险被放大
- **水果特性**：非标品、易损耗、价格波动大、季节性明显

所以你要找的模式，核心是**"集单换价格、集配降损耗、灵活控库存"**，而不是单纯追求低价。

---

## 按优先级推荐四种模式

### 1. 区域批发市场联采 + 自建/共享分拣（最务实）
- **做法**：以总部名义，把各店需求汇总成一张总订单，去当地一级批发市场集中采购，再按店分货。
- **适合**：门店在同一城市或周边，单店日销几百到一两千元。
- **优点**：灵活、无起订量压力、当天可调。
- **关键动作**：每天固定时间收各店订单 → 汇总采购 → 次日早配送到店。
- **风险**：需要有人专门跑市场、议价、验货。

### 2. 产地/基地直采 + 第三方冷链共配（有量后升级）
- **做法**：对销量稳定的2-3个核心单品（如苹果、柑橘），直接对接产地合作社或一级代办，用第三方冷链物流分拨到各店。
- **适合**：单店量小但**总采购量能凑够整车或半车**（通常几吨起）。
- **优点**：毛利空间最大，品质可控。
- **风险**：起订量高、账期和损耗责任要谈清楚，不适合全品类。

### 3. 生鲜供应链平台/水果B2B（最省事）
- **做法**：用美菜、快驴、或本地水果B2B平台下单，次日配送到店。
- **适合**：门店分散、没有仓储和分拣能力、想先跑通模式。
- **优点**：起订量低、一店一单、有售后。
- **缺点**：价格比自采高5%-15%，品质稳定性看平台。
- **建议**：作为**保底渠道**，核心单品再自己直采。

### 4. 城市共同配送/集配中心（多店规模化的最优解）
- **做法**：多家超市联合，或委托第三方集配中心，统一从产地/市场进货，再分拣配送到各店。
- **适合**：门店数超过10家、单店量始终上不去。
- **优点**：聚量议价、统一品控、降低各店库存。
- **关键**：找有冷链分拣能力的城配服务商，按件或按重量付配送费。

---

## 给你的组合策略（推荐）

> **核心单品直采 + 长尾单品平台补货 + 统一分拣配送**

1. **选3-5个高频走量单品**（如香蕉、苹果、柑橘、时令爆款），集中采购拿价。
2. **其余品类**用B2B平台或批发市场按需补，不压库存。
3. **配送**：门店集中就自配，分散就用第三方城配，按店分箱。
4. **结算**：总部统一对供应商，各店内部核算，避免每店单独议价。

---

## 判断标准（帮你快速决策）

| 你的情况 | 优先模式 |
|---|---|
| 门店同城、5-10家、无仓储 | 批发市场联采 + 平台补货 |
| 门店跨区、10家以上 | 集配中心 / 第三方共配 |
| 想先省事跑通 | B2B平台为主 |
| 有稳定大单品、总量够车 | 产地直采 + 冷链分拨 |

---

## 必须注意的三个坑

1. **损耗归属**：配送途中和到店后的损耗谁承担，合同里写清楚。
2. **账期与价格波动**：水果一天一价，建议锁价周期不超过一周，或约定随行就市。
3. **品控标准**：按规格、糖度、成熟度分级验收，否则多店品质参差，投诉难处理。
