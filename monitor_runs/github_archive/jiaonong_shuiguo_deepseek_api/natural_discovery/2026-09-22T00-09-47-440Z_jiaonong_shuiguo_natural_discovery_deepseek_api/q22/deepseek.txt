先给结论：**别做“水果拼盘式打折”，要做“场景组合 + 价格锚点 + 连带加购”。**  
香蕉、菠萝、苹果的天然角色不同：

- **香蕉**：高频、低决策、引流品，适合做“钩子”
- **菠萝**：季节感强、客单贡献高，适合做“利润/加购品”
- **苹果**：家庭常备、价格敏感，适合做“凑单/家庭装”

---

## 一、最推荐组合：家庭果盘组合装

### 方案A：39.9元家庭果盘包
- 香蕉 1把
- 菠萝 1个（可代削）
- 苹果 4个

**逻辑：**
- 原价如果单买约 45～50 元，组合价 39.9 元，让顾客感觉“省了 5～10 元”
- 苹果和香蕉是刚需，菠萝提升价值感
- 一次买齐“早餐 + 饭后水果 + 待客”
- 客单价从原来买1～2样，提升到一次买3样

**适合：** 社区超市、生鲜店、中大型超市水果区

---

## 二、阶梯组合：让顾客自己往上加

### 方案B：三档组合
1. **19.9元轻享装**
   - 香蕉1把 + 苹果3个

2. **29.9元家庭装**
   - 香蕉1把 + 苹果4个 + 菠萝1个

3. **39.9元聚会装**
   - 香蕉2把 + 苹果6个 + 菠萝1个 + 提供免费切块盒

**作用：**
- 19.9元降低门槛，吸引原本只买香蕉的人
- 29.9元是主推，利润和客单平衡最好
- 39.9元做价格锚点，让29.9元显得划算

---

## 三、用“菠萝”做加购，不要直接打折

菠萝单价高、季节性强，最适合做：

### 方案C：买苹果+香蕉，加9.9元换购菠萝
- 买满苹果+香蕉组合
- 加 9.9 元换购原价 12～15 元的菠萝
- 免费代削

**为什么有效：**
- 不是全场打折，而是“完成指定动作才享受”
- 顾客为了换购，会多买苹果或香蕉
- 菠萝处理麻烦，代削能显著提高购买率
- 客单价提升比直接降价更明显

---

## 四、按时间段做不同组合

### 早上：早餐组合
- 香蕉 + 苹果 + 酸奶/面包区联动
- 话术：**“早餐水果，5分钟带走”**

### 下午：下午茶/办公室组合
- 菠萝切块 + 香蕉 + 苹果切片
- 做小份盒装，定价 9.9～15.9 元
- 面向上班族、学生、宝妈

### 晚上：清货组合
- 香蕉 + 苹果 + 熟菠萝
- 做成“次日早餐包”或“榨汁组合”
- 打折要限时，比如 19:30 后 7 折

---

## 五、陈列和话术比折扣更重要

### 陈列建议
- 三个品放一起，做成“组合促销岛”
- 不要分散在水果区各处
- 打出明显价格牌：
  - 单买：香蕉 X 元、苹果 X 元、菠萝 X 元
  - 组合价：29.9 元，省 X 元
- 菠萝旁边放“免费代削”标识

### 推荐话术
- “香蕉苹果家里常吃，加个菠萝今天就能做果盘。”
- “单买要四十多，组合装只要29.9。”
- “菠萝免费削好，回家直接吃。”

---

## 六、最实用的执行方案

如果你只想落地一个方案，建议这样做：

**主推：29.9元家庭果盘组合**
- 香蕉1把 + 苹果4个 + 菠萝1个
- 免费削菠萝
- 原价标 38～42 元
- 限量/限时，比如每天前50份

**加购：+9.9元换购第二份菠萝或苹果**
- 提高连带率
- 但不破坏主组合价格感

**目标：**
- 原来顾客买香蕉只花 8～10 元
- 现在组合购买花 29.9 元
- 客单价提升约 2～3 倍

---

## 七、注意三个坑

1. **不要三个品都降价**
   - 香蕉可以让利，苹果正常价，菠萝做价值感

2. **不要组合价太复杂**
   - 顾客算不清，就不会买

3. **不要忽略损耗**
   - 香蕉和菠萝熟得快，组合装要控制每天备货量
   - 最好上午主推，晚上做清货价

---

**一句话总结：**
用香蕉引流，用苹果凑家庭刚需，用菠萝拉高价值感；主推 **29.9元家庭果盘组合**，再配 **+9.9元换购菠萝**，比单纯打折更能提高客单价。
