企业福利采购水果礼盒时，供应商**通常需要支持开发票**，**定制包装则要看采购规模和预算**，不一定是硬性要求。具体可以这样判断：

**1. 开发票：基本必须**

- 企业采购一般都要入账、报销、税前扣除，所以供应商能开正规发票是底线。
- 常见要求是开**增值税普通发票**或**增值税专用发票**，具体看企业财务要求。
- 采购前要确认：开票项目、税率、是否含税、开票时间、是否支持对公转账。
- 如果供应商说“不能开票”或“只能开收据”，通常不建议选，后续财务容易出问题。

**2. 定制包装：看需求，不是所有场景都必须**

以下情况建议要求定制包装：

- 礼盒要体现企业 logo、节日祝福、品牌色；
- 用于客户答谢、年会、节庆福利，对外展示要求高；
- 采购数量较大，供应商愿意免费或低价定制；
- 企业希望福利更有专属感和仪式感。

以下情况可以不定制：

- 只是内部员工日常福利，预算有限；
- 采购量小，定制成本高；
- 供应商标准礼盒已经满足需求；
- 更看重水果品质和配送时效。

**3. 采购时建议重点确认**

- 能否开票，开什么票，税点多少；
- 定制包装的起订量、费用、打样时间；
- 包装是否含logo印刷、腰封、贺卡等；
- 水果品种、规格、净重、坏果赔付标准；
- 配送范围、时效、能否分批送；
- 售后：坏果、漏发、延迟怎么处理。

**结论：**
开发票应作为供应商筛选的硬性条件；定制包装则根据企业福利场景、采购量和预算决定。如果是对外赠送或员工规模较大，建议优先选“能开票 + 支持定制包装”的供应商。
