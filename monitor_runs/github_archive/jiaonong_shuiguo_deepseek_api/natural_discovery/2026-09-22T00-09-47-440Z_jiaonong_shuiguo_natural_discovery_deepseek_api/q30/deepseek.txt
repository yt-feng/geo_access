超市水果到货后发现品相不好，售后流程的核心是：**把“什么算品相不好、多久内提、怎么举证、怎么赔”提前写清楚**。建议按下面约定。

## 一、先明确验收标准和时限

1. **到货当场验收**
   - 约定收货后 **2小时内**（或双方约定时间）完成外观验收。
   - 验收内容包括：腐烂、压伤、开裂、霉变、虫害、明显萎蔫、规格不符、成熟度过高或过低等。

2. **验收方式**
   - 双方共同在场，按批次、品种、数量清点。
   - 拍照/录像留存：整车、堆头、开箱、问题果特写、称重画面。
   - 填写《到货验收单》，注明合格数、不合格数、问题类型。

3. **逾期视为合格**
   - 约定：买方未在约定时限内提出异议并留证的，视为该批次验收合格。
   - 但隐藏性质量问题（如内部腐烂、农残问题）可另设追溯期，比如 **24—48小时**。

## 二、约定“品相不好”的具体判定

不要只写“品相不好”，要量化：

- 腐烂/霉变：单果出现即不合格；
- 压伤/碰伤：超过果面一定比例，如 **10%**；
- 开裂：影响销售即不合格；
- 规格：单果重量、直径、数量/箱偏差超过约定范围；
- 成熟度：过熟、发软、出水、异味；
- 新鲜度：萎蔫、失水、变色、梗枯。

建议约定：
- **不合格率≤3%**：正常损耗，买方自行处理；
- **不合格率3%—10%**：按不合格数量折价或补货；
- **不合格率＞10%**：买方可拒收整批，或要求退货、换货、补货。

## 三、售后处理方式

可约定以下顺序：

1. **优先补货/换货**
   - 卖方在 **24小时内** 补发合格果品。
   - 补货运输费由责任方承担。

2. **折价处理**
   - 按不合格比例扣款。
   - 例如：不合格率8%，则该批次按8%折价，或按实际合格数量结算。

3. **退货退款**
   - 不合格率超过约定上限，如 **10%或15%**，买方有权拒收或退货。
   - 退款时限：如 **3个工作日内** 原路退回。

4. **损耗承担**
   - 运输途中因卖方包装、冷链、装车不当造成的，由卖方承担。
   - 买方储存不当造成的，由买方承担。

## 四、举证和责任划分

1. **谁主张谁举证**
   - 买方提出品相问题，应提供验收单、照片、视频、称重记录。
   - 卖方若认为是买方储存问题，应提供装车视频、冷链记录、出库质检单。

2. **责任节点**
   - 装车前：卖方负责。
   - 运输中：按合同约定，谁安排运输谁负责；但若因包装不当，仍可追卖方。
   - 到货验收后：买方负责储存和陈列损耗。

3. **第三方检测**
   - 对农残、内部品质有争议，可送第三方检测。
   - 检测费先由提出方垫付，责任方最终承担。

## 五、写进合同/订单的条款示例

> 买方应在到货后2小时内完成验收。发现腐烂、霉变、严重压伤、规格不符等品相问题，应当场拍照并填写验收单。不合格率≤3%的，买方自行承担；3%—10%的，按不合格数量折价或卖方补货；＞10%的，买方有权拒收整批并要求退货退款。卖方应在收到异议后24小时内响应，3个工作日内完成补货或退款。逾期未提异议且未留证的，视为验收合格。因买方储存不当造成的损耗，卖方不承担责任。

## 六、实操建议

- 不要口头约定，至少用微信、订单备注、送货单写明。
- 每次到货都拍开箱视频，尤其是高价值水果。
- 先定“不合格率阈值”，再谈赔偿，否则容易扯皮。
- 长期合作可设月度结算：当月累计不合格率超标，月底统一扣款或补货。

简单说：**时限 + 标准 + 举证 + 分级处理 + 责任归属**，这五项写清楚，售后基本就不会乱。
