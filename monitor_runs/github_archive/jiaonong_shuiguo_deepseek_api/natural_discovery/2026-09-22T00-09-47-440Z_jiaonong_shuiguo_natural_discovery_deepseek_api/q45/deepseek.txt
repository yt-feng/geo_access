连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是围绕“价格怎么变、品质怎么定、损耗谁来担、账期怎么结”这几类条款。下面按风险高低说清楚。

**1. 价格与调价机制**
- 坑：只写年度框架价，没写随行就市规则。水果价格波动大，写死价格供应商可能断供，完全随行就市超市又控制不住成本。
- 建议：约定基准价+调价触发条件（如果价指数、产地价、季节），明确调价频率、申请与确认流程、生效时间。最好设价格上限或双方协商不成的处理方式。

**2. 品质标准与验收**
- 坑：只写“新鲜、无腐烂”这类模糊词，验收时各说各话。
- 建议：按品类写清规格（果径、重量、糖度、成熟度、色泽）、等级、允许瑕疵比例、农残检测要求。明确验收地点、时限、抽检比例、不合格处理（拒收、扣款、退货、换货）和复检机制。

**3. 损耗与退货**
- 坑：没区分“到店前损耗”和“到店后损耗”，超市把门店损耗也算供应商头上，或供应商把运输损耗推给超市。
- 建议：约定交付验收前的损耗由供应商承担，验收合格后的门店损耗由超市承担；对易腐品可约定合理退货比例和时限。生鲜损耗率要写具体数字，别只写“合理损耗”。

**4. 账期与结算**
- 坑：账期过长、对账流程不清、扣款无依据。超市常以“损耗扣款”“促销扣款”直接抵账。
- 建议：明确账期天数、对账日、开票要求、付款方式；所有扣款须有书面确认或合同依据，禁止单方随意扣款。逾期付款可约定违约责任。

**5. 供货量与独家/排他**
- 坑：约定最低采购量但没写未达量后果，或要求供应商独家供货却没给保底。
- 建议：最低采购量要结合历史销量设定，并写明未达标是否补偿、能否调整。排他条款需谨慎，通常应换取价格或账期优惠，并设退出机制。

**6. 违约金与解约**
- 坑：违约金过高或过低，解约条件单方有利。
- 建议：违约金与可预见损失挂钩，避免畸高被认定无效。明确重大违约情形（如连续断供、农残超标、长期质量问题）和解除权、通知期、库存处理。

**7. 食品安全与责任**
- 坑：只写“符合国家标准”，没写检测责任、追溯和赔偿。
- 建议：要求供应商提供检测报告、产地证明、可追溯信息；约定农残或食品安全事件的责任归属、召回费用、赔偿范围，必要时要求保险或保证金。

**8. 不可抗力与季节风险**
- 坑：把天气、疫情、运输管制都算不可抗力，供应商借此免责断供。
- 建议：限定不可抗力范围，约定替代供货、减量供货或顺延履行，而不是直接免责。

**9. 合同期限与续约**
- 坑：自动续约条款隐藏，或到期前未通知就默认续签。
- 建议：写清期限、续约条件、提前通知期，避免被动续约。

**10. 争议解决**
- 坑：管辖地约定在对方所在地，维权成本高。
- 建议：约定对超市较便利的管辖法院或仲裁机构，明确适用法律。

**一句话总结**：水果年度合同的核心是“标准可量化、调价有机制、损耗分边界、扣款有依据、违约可执行”。签之前最好用历史数据测算保底量和损耗率，并把验收标准做成附件，避免口头承诺。
