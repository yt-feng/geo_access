茶饮店用香蕉，采购熟度不能一刀切，要先明确用途，再按“到货熟度 + 后熟节奏”来控。

**1. 按用途定熟度**

- **做冰沙、奶昔、香蕉牛奶、果泥基底**：用**7—8分熟**，表皮黄、略带一点青肩，捏起来微软但有弹性。太生会涩、粉感重；太熟会发黑、发酵味重。
- **做香蕉甜品、蛋糕夹心、布丁 topping、捣泥淋酱**：用**8—9分熟**，通体黄、带少量糖斑，香气足、甜度高。
- **做烤香蕉、焦糖香蕉、油炸香蕉**：用**6—7分熟**，太熟一加热就烂，太生又不够甜。
- **做装饰切片、摆盘**：用**6—7分熟**，硬度够、切面整齐，不容易氧化发黑。

**2. 采购时看这几个硬指标**

- **颜色**：青肩少、黄底为主，按用途选糖斑多少。
- **手感**：轻捏有弹性，不软塌，不硬邦邦。
- **果柄**：干燥但不变黑发霉，发黑通常过熟或存放久。
- **气味**：有清香，不能有酒味、酸味、发酵味。
- **表皮**：允许少量斑点，但大面积黑斑、裂口、渗液不要。

**3. 到货后要分批管理**

- 到货别全部常温堆一起，按熟度分三批：
  - **马上用**：已到8—9分熟。
  - **1—2天用**：7—8分熟，常温催熟。
  - **3—5天用**：6—7分熟，阴凉通风。
- **催熟**：和苹果、乙烯利包或成熟苹果放一起，能加快后熟。
- **延缓后熟**：未熟香蕉不要放冰箱；已熟香蕉可冷藏1—2天，但表皮会变黑，果肉仍可用，适合做泥、酱，不适合摆盘。
- **剥皮后**：加少量柠檬汁或维C水防氧化，尽快用完。

**4. 采购量建议**

- 按“日用量 × 1.5—2天”备货，不要一次压太多。
- 如果门店没有稳定后熟管理，宁可采购偏生一点，到店再催熟。
- 夏季后熟快，采购熟度要比冬季低半档到一档。

**5. 简单判断标准**

- 今天做饮品：选**黄、微弹、无酒味**。
- 今天做甜品泥：选**黄、糖斑少、香软**。
- 明天用：选**黄中带青、硬一点**。
- 三天后用：选**青肩明显、硬实**。

一句话：**饮品和果泥用偏熟，装饰和油炸用偏生；采购按用途分熟度，到店按批次催熟和冷藏，别混放。**
