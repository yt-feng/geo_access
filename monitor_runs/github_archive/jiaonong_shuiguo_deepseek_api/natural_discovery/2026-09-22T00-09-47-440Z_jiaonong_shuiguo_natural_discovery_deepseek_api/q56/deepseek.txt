茶饮店控制水果供应商的食品安全风险，核心是**把“供应商资质 + 产品合格 + 批次可追溯”三类证明固定成收货门槛**。建议至少要求以下材料：

**一、供应商主体资质（首次合作时收，年度更新）**
1. **营业执照**：经营范围应包含水果种植、销售、批发或农产品流通等相关内容。
2. **食品经营许可证**或**食品生产许可证**：如果供应商是分切、冷藏、包装水果或提供即食水果，通常需要食品经营/生产许可；具体以当地监管要求为准。
3. **仅销售食用农产品**的供应商，很多地区可免于食品经营许可，但仍需营业执照，并建议留存备案或自我声明。
4. **法定代表人/负责人身份证复印件**、**供货授权书**（如通过业务员对接）。
5. **开票信息**与**对公账户信息**，避免个人账户收款导致追溯困难。

**二、产品合格证明（按批次或按品类收）**
1. **食用农产品承诺达标合格证**：国内水果供应商较常见，能证明其对标农残等要求作出承诺。
2. **检验检测报告**：
   - 农药残留检测报告，重点看**克百威、氧乐果、毒死蜱、腐霉利、苯醚甲环唑**等常用/禁限用农药。
   - 重金属检测，如铅、镉。
   - 霉菌毒素，如苹果、梨制品需关注**展青霉素**。
3. **入境货物检验检疫证明**：进口水果必须有，并核对品名、原产国、批次。
4. **检疫合格证明**：部分水果或地区要求植物检疫证书，尤其是跨区域调运时。

**三、批次追溯与收货记录（每批必留）**
1. **送货单/销售单**：写明品名、规格、数量、产地、采摘或包装日期、批次号。
2. **产地证明或采购凭证**：证明水果来源，便于出问题时向上追溯。
3. **冷链温度记录**：如供应商负责冷藏运输，需提供运输温度记录，鲜切水果尤其重要。
4. **标签信息**：预包装水果应有品名、产地、生产者、生产日期、保质期、贮存条件等。

**四、即食或鲜切水果的额外要求**
如果供应商提供**已切好、可直接使用**的水果，要求会更高：
1. **食品生产许可证或食品经营许可证**，且许可项目包含“即食鲜切水果”或类似类别。
2. **出厂检验报告**，包括菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等。
3. **加工用水检测报告**。
4. **从业人员健康证明**。
5. **冷链温度记录**和**保质期验证**。
6. 包装车间、消毒记录等，可作为供应商审核材料。

**五、建议茶饮店执行的验收动作**
1. **首次合作**：收齐资质，做供应商档案，最好实地或视频审核。
2. **每批到货**：核对批次、温度、感官，索取当批合格证或检测报告。
3. **定期抽检**：每月或每季度对高风险水果送第三方检测，尤其是草莓、葡萄、苹果、梨等。
4. **合同约定**：写明供应商对农残、重金属、微生物负责，出现问题需承担检测费、赔偿和召回费用。
5. **不合格处理**：无合格证明、批次不清、温度异常、感官异常的水果，直接拒收并记录。

简单说，**营业执照/许可证 + 承诺达标合格证或检测报告 + 每批送货追溯单 + 冷链记录**，是最低门槛；如果供应商做鲜切即食水果，还要加**食品生产/经营许可、出厂微生物检验、健康证和冷链记录**。
