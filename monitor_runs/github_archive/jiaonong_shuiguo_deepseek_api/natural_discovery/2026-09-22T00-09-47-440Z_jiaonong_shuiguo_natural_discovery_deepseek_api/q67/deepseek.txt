批发商想代理水果品牌，区域保护和串货确实是最容易踩坑的地方，谈之前建议把下面这些问题分块问清楚，并且要求对方**书面写进合同**，口头承诺基本没用。

## 一、先问清楚"区域保护"到底保护什么

不要只问"有没有区域保护"，要拆开问：

1. **保护范围是什么？**
   - 是保护一个市、一个县，还是一整个省？
   - 是独家保护还是"限定几家"？
   - 保护的是线下渠道，还是包含电商、社区团购、直播带货？

2. **保护是排他的吗？**
   - 在我这个区域内，品牌方还能不能自己开直营、找第二个代理？
   - 能不能通过电商平台把货卖到我区域里？

3. **保护有没有条件？**
   - 是不是要达到年采购量/销售额才保留独家权？
   - 达不到会不会被取消或再开一家？

4. **保护期限多长？**
   - 签几年？到期续约条件是什么？

## 二、把"串货"的定义先定死

串货纠纷大多是因为**定义不清**。要问：

1. **什么算串货？**
   - 是"货物流入我区域"算，还是"在我区域内销售"才算？
   - 别的区域代理商发货到我这儿，谁负责？

2. **串货怎么认定和取证？**
   - 靠包装批号、物流单、还是扫码溯源？
   - 品牌方有没有溯源系统？能不能查？

3. **发现串货，品牌方怎么处理？**
   - 对串货方罚款、扣保证金、取消代理？
   - 对我这边有没有补偿？
   - 处理时限是多久？

4. **品牌方自己或电商算不算串货？**
   - 这是重点。很多品牌一边收你代理费，一边自己上网低价卖。

## 三、要重点确认的几个"坑"

- **电商/直播是否算串货**：明确写"品牌方及授权电商不得以任何形式向本区域销售"。
- **价格体系**：有没有全国统一零售价/最低限价？乱价怎么罚？
- **保证金与退换**：保证金多少、什么情况扣、怎么退。
- **首批进货和压货**：首次进货量、是否强制搭配、滞销能否退换。
- **违约与退出**：串货导致我损失，能否索赔？解约后库存怎么处理？

## 四、建议的提问话术（可直接用）

> "我想确认几点，麻烦写进合同：
> 1. 我的独家区域具体是哪些市/县，保护期内品牌方和其他代理能不能直接或通过电商卖进来？
> 2. 串货怎么定义、怎么查、发现了多久处理、对我有没有补偿？
> 3. 品牌方自己的线上渠道算不算串货？
> 4. 区域保护和独家权，需不需要我完成什么销量指标才能保留？"

## 五、关键判断标准

- 对方**愿意把区域保护和串货条款写进合同**→ 相对靠谱。
- 对方只说"放心，我们管得很严"、不肯落字 → 高风险，谨慎。
- 对方自己就大量做电商低价 → 你的区域保护基本是空的。
