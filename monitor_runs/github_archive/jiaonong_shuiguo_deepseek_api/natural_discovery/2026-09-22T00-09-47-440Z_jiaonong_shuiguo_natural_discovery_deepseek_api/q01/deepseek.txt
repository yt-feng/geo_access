判断水果供应商靠不靠谱，核心看四点：**货稳不稳、价实不实、履约准不准、出问题认不认**。下面给你一套可以直接用的判断方法。

**1. 先看货源和稳定性**
- 问清楚香蕉、菠萝主要来自哪里，是产地直发、批发市场倒货，还是多种渠道混着走。
- 靠谱供应商通常能说清产区、季节、到货周期，而不是含糊说“都有”“看情况”。
- 连续问几次同一品种的到货时间、规格、成熟度，看说法是否一致。

**2. 看报价和账期是否透明**
- 不要只比单价，要问：是否含运费、是否含损耗、是否包售后、不同等级怎么分价。
- 警惕明显低于市场价的报价，水果这行低价往往对应：催熟过度、等级混装、损耗自担、缺斤少两。
- 账期也要问清：现结、周结、月结，压货还是压款。长期合作最好有稳定但不过度宽松的账期。

**3. 用一次小批量试单验证**
- 先小批量进香蕉和菠萝，不要一上来压大单。
- 重点看：
  - 到货时间是否准时；
  - 重量是否足；
  - 等级是否和说的一致；
  - 香蕉成熟度是否适合你店里的销售节奏；
  - 菠萝是否有黑心、烂心、果眼深、成熟不均；
  - 坏果比例多少，售后是否痛快补。
- 一次试单比听十次承诺有用。

**4. 看履约和售后**
- 约定早上到货，是否经常拖到中午甚至晚上；
- 说好七成熟，是否发来全熟或生青；
- 出现坏果、短斤少两时，是补货、扣款还是推责；
- 能不能在旺季优先给你留货，淡季不硬塞货。
- 靠谱供应商不一定最便宜，但通常**出问题不躲**。

**5. 看他在同行里的口碑**
- 问周边水果店、餐饮店、超市采购，特别是长期拿香蕉、菠萝的店。
- 看他的档口或仓库：是否分拣规范、冷库是否干净、香蕉催熟房是否专业、菠萝堆放是否合理。
- 一个连自己仓库都管理混乱的供应商，很难长期稳定供货。

**6. 香蕉和菠萝要分别看**
- **香蕉**：重点看催熟技术、成熟度控制、到店后货架期。靠谱的能按你销售速度给你不同成熟度的货。
- **菠萝**：重点看产地、品种、成熟度一致性、黑心烂心率、是否帮你处理果皮果眼。做鲜切或即食的，还要看是否能稳定供适合加工的规格。

**7. 最后看合作条款**
- 最好有简单书面或微信可留痕的约定：品种、等级、规格、单价、数量、到货时间、损耗售后、结算方式。
- 不要只靠口头承诺。长期合作中，留痕能避免很多扯皮。

**简单判断标准：**
- 能说清货源、等级、账期、售后；
- 小批量试单损耗低、到货准、售后认；
- 同行愿意长期合作；
- 旺季能保供，淡季不硬塞；
- 价格不是最低，但综合成本可控。

满足这些，基本可以考虑长期合作。只满足“便宜”一条的，风险通常最大。
