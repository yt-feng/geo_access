第一次合作最怕两件事：**货不对板**和**账期/售后扯皮**。所以小批量试单的核心不是“便宜拿货”，而是**用最低成本验证对方的真实供货能力**。建议按下面这几步设计。

## 一、先定试单目标

试单不是走个过场，要能回答4个问题：

1. **品质稳不稳**：同一规格是否批次一致，还是“样品一个样、大货一个样”
2. **供货能力**：能不能按约定时间、数量发得出
3. **损耗/售后**：坏果谁承担、怎么赔、赔多少
4. **配合度**：沟通响应、包装、单据、账期是否靠谱

## 二、试单规模怎么定

- **金额**：控制在你能承受全损的范围，比如总货值的 **0.5%~2%**，或单独一笔“验证预算”
- **品种**：选 **1~2个主打单品**，不要一次上多品
- **数量**：够铺满1~2个销售渠道即可，宁可少不可多
- **分批发**：如果条件允许，**同一批订单分2次发**，看稳定性

关键：**试单量要小到即使全赔也不影响你，但大到能看出真实问题。**

## 三、合同/约定必须写死的点

1. **规格标准**
   - 品种、等级、果径/重量、糖度、成熟度、色泽、允许瑕疵率
   - 最好附**照片/样品封样**，双方确认

2. **包装与运输**
   - 箱规、单箱净重、包装材质、是否带托盘
   - 运输方式、温度要求、到货时效

3. **验收标准**
   - 到货后**多久内验货**（通常24~48小时）
   - 抽检比例、抽检方法
   - 合格率/损耗率阈值

4. **售后与赔付**
   - 坏果、烂果、规格不符、缺斤少两怎么赔
   - 是补发、扣款还是退货
   - 赔付比例和凭证要求（照片/视频/称重）

5. **付款方式**
   - 首次合作建议 **货到验收合格后付款**，或 **小比例定金+尾款**
   - 尽量不做全款预付

## 四、执行流程

1. **先要样品**：看样品，封样留存
2. **签试单协议**：哪怕一页纸，把规格、数量、价格、交期、售后写清楚
3. **小批量下单**：明确发货时间、到货时间
4. **到货即验**：按约定抽检，拍照、称重、记录
5. **复盘打分**：品质、时效、售后、沟通各打分
6. **决定是否放量**：合格再谈第二批，逐步加量

## 五、试单验收的硬指标

建议设几个“一票否决”项：

- 规格严重不符（比如约定80#发来60#）
- 损耗率超过约定（比如超过5%~10%，按品类定）
- 交期严重延误且无提前沟通
- 售后推诿、不认账

出现以上任意一条，**不建议直接放量**。

## 六、几个实用建议

- **不要只看价格**：第一次合作，低价往往对应品质或售后风险
- **留证据**：聊天记录、合同、样品照片、到货视频都要存
- **多问一句**：问对方“最近给哪些客户供货、能不能提供参考”，侧面验证
- **试单后别急着压价**：先确认稳定，再谈量和账期
- **准备备选供应商**：试单期间同步接触1~2家，避免被单一供应商拿捏

一句话总结：**试单要小、标准要细、验收要严、付款要后、证据要留。** 目的是用最小代价判断这个供应商能不能长期合作。
