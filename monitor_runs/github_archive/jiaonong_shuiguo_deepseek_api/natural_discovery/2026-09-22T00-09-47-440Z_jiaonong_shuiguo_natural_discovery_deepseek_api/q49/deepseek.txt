旺季菠萝用量突然放大，和供应商临时补货，核心不是“让对方优先给我”，而是**提前把临时补货的规则写清楚**，否则真到缺货时，口头承诺基本没用。建议按下面做：

**1. 先定“临时补货”的触发条件**
和供应商约定清楚：
- 提前几天通知算临时补货，比如提前 24 小时、48 小时；
- 每次补多少箱/多少公斤起送；
- 一周最多补几次；
- 哪些时段可以补，比如每天上午 10 点前下单，次日到货。

**2. 锁量不锁价，或锁价不锁量**
旺季价格容易波动，最好二选一写进约定：
- **锁量不锁价**：供应商保证每天/每周给你留多少货，但价格按到货当天市场价；
- **锁价不锁量**：价格固定一段时间，但供应商不保证无限量，只保证优先供应。
如果你最怕断货，选第一种更稳；如果最怕成本失控，选第二种。

**3. 约定优先供应权**
可以写：
- 供应商现有库存先满足你的日常订单，再安排其他客户；
- 你临时加单时，供应商应在 X 小时内确认能否满足；
- 若无法满足，需提前 X 小时告知，并推荐替代货源。

**4. 用“预付款+滚动结算”换优先权**
旺季想拿到临时补货，最有效的方式通常是：
- 提前打一笔旺季备货保证金；
- 或者每周先预付部分货款；
- 约定补货到店后 3～7 天结清。
供应商更愿意把货留给付款快、量稳定的客户。

**5. 把验收和损耗写清楚**
菠萝容易有成熟度、黑心、烂果问题，临时补货更要写：
- 到货验收标准：成熟度、单果重量、坏果率；
- 坏果超过多少比例，怎么补、怎么扣款；
- 当天验收，过期不认。

**6. 留一个备用供应商**
不要只谈一家。旺季至少准备两家：
- A 供应商保日常和优先补货；
- B 供应商做应急，哪怕价格高一点。
这样谈判时你也有底气。

**7. 最简可执行版本**
你可以直接和供应商这样约定：
> 旺季期间，我每天基础用量 X 箱。若需临时补货，我提前 24 小时下单，你优先安排，最多 48 小时内到货。每周临时补货不超过 X 次，每次不低于 X 箱。价格按到货当日市场价结算，我预付 X 元保证金。坏果率超过 5% 按实扣款。若你无法供应，需提前 12 小时通知，我可自行外采。

**关键提醒：**
临时补货约定一定要落到**微信文字、订单备注或简单协议**里，别只靠电话。内容至少包括：数量、时间、价格机制、优先权、验收标准、违约处理。这样旺季真缺货时，你才能追责和调货。
