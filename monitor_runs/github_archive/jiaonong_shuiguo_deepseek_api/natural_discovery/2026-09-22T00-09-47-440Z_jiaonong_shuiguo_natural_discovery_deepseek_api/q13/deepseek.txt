对小水果店来说，做附近小区团购，供应商最好能提供以下几类服务。你可以按“必须支持”和“加分支持”来判断：

## 一、必须支持的服务

1. **稳定供货**
   - 每天或隔天能稳定供货，不能今天有、明天没。
   - 团购最怕爆单后缺货，所以供应商要有一定库存和补货能力。

2. **按团购价供货**
   - 能给你比普通批发更低的团购供货价。
   - 最好能按量阶梯报价，比如 50 份、100 份、300 份不同价格。

3. **支持小批量起送**
   - 小水果店刚开始团购，单量不会很大。
   - 供应商最好能接受小批量起送，比如几十斤、几箱也能送。

4. **配送到店或指定自提点**
   - 能送到你的店里，或者送到小区自提点。
   - 送货时间要稳定，最好能配合你设定的团购截单和到货时间。

5. **质量稳定、坏果包赔**
   - 水果团购最怕品质不稳定。
   - 供应商要能承诺坏果、烂果、缺斤少两的处理方案，比如补货、退款或下次抵扣。

6. **提供图片、价格和文案素材**
   - 做小区团购需要在微信群里发图、发价格、发接龙。
   - 供应商最好能提供实拍图、规格、产地、口感描述、保存方法等素材。

7. **支持售后**
   - 如果顾客收到坏果，供应商要能配合处理。
   - 不能把售后全部压给你这个小店。

8. **账期或灵活结算**
   - 刚开始做团购，现金流紧张。
   - 能支持现结、周结、押一批结一批，都会更轻松。

## 二、加分服务

1. **支持一件代发或分拣打包**
   - 供应商直接按份打包好，你到货就能发，省人工。

2. **支持定制团购套餐**
   - 比如 19.9 元水果组合、39.9 元家庭装、应季尝鲜装。

3. **提供爆品建议**
   - 告诉你最近什么水果好卖、适合做引流、适合做利润款。

4. **支持退换货和临期处理**
   - 卖不完或品质有问题的货，能退换或协助处理。

5. **支持区域保护**
   - 同一个小区或附近区域，不随便给其他团购供货，避免价格战。

6. **能开发票或提供正规凭证**
   - 如果后面要做大、做企业团购，会需要。

7. **有冷链或保鲜运输**
   - 夏天送草莓、樱桃、葡萄、荔枝等，冷链很重要。

## 三、你筛选供应商时重点问这几句

可以直接这样问：

1. 团购价怎么算？多少量能再便宜？
2. 多少起送？送到店里还是小区？
3. 今天下单，明天能不能到？
4. 坏果怎么赔？缺斤少两怎么处理？
5. 能不能提供图片、文案和规格表？
6. 能不能按份打包？打包费怎么算？
7. 能不能支持周结或压一批结？
8. 同一个小区你还供货给别家吗？

## 四、最适合小水果店起步的模式

优先找这种供应商：

- 本地批发市场档口
- 本地水果种植基地
- 同城生鲜供应链
- 支持小批量、同城配送、坏果包赔的供应商

不要一开始就找要求大批量、全款压货、售后不管的供应商。

一句话总结：  
**小水果店做小区团购，供应商最关键的是：稳定供货、团购价、小批量配送、坏果包赔、素材支持、售后配合。**  
这六点能满足，基本就能开始做。
