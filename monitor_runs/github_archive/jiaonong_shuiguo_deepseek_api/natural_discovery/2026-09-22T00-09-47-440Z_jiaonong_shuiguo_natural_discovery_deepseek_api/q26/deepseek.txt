社区超市卖小包装香蕉，核心矛盾是：**香蕉后熟快、怕压怕冻，小包装又会放大损耗和人工**。采购时重点盯这几类问题：

**1. 包装形式**
- 优先选**透气打孔保鲜袋/网套+托盘**，不要完全密封。香蕉会释放乙烯，密封后容易闷黄、发黑、出水。
- 小包装建议按**2–3根或3–5根**一份，单份重量控制在300–600g，方便家庭一次吃完。
- 如果做“即食小包”，可以用**透气袋+标签**；如果做“家庭量贩小包”，可用**托盘+收缩膜但必须打孔**。
- 避免用太薄的塑料袋直接扎口，容易压伤蕉指，也会让水汽积聚。

**2. 采购成熟度**
- 不要只采购全黄蕉。小包装周转慢，建议采购**微黄或青黄交接**的香蕉，回店后自然转黄。
- 如果门店客流快，可以少量搭配**已熟黄蕉**做即时销售；客流慢就多拿偏青的。
- 明确让供应商按**几成熟**发货，比如“3–4成黄”“5–6成黄”，不要只说“熟一点”。

**3. 损耗控制**
- 香蕉损耗主要来自：**压伤、冻伤、闷烂、过熟发黑、脱柄**。
- 运输和上架都要**单层摆放**，不要叠压；小包装之间留空隙。
- 门店温度低于12℃容易冻伤，夏天空调口、冬天门口冷风都要避开。
- 不要一次包太多，建议**少量多次包装**，按半天或一天销量来包。
- 已经过熟、发黑的香蕉不要硬包进小包装，可以转做**特价散卖、香蕉奶昔原料、烘焙合作**，减少报损。

**4. 采购谈判要点**
- 问清供应商：**品种、产地、成熟度、单根重量、到货温度、是否打孔包装、是否支持退换残次**。
- 要求**箱内分层、加垫纸或珍珠棉**，减少运输压伤。
- 先小批量试销，记录**到货成熟度、上架后第几天开始出黑点、每天报损量**，再决定采购量和成熟度。
- 如果供应商只能发全熟蕉，建议压价或改做即食特价，不要按正常小包装毛利去算。

**5. 简单可执行标准**
- 采购：偏青黄、单根均匀、无裂口、无大面积压伤。
- 包装：打孔透气、单层、每份2–5根、标签写清“即食/放1–2天再吃”。
- 上架：阴凉通风，避免冷柜和暴晒，先进先出。
- 报损：每天挑出黑斑多的，先特价再下架，不等到全黑。

一句话：**小包装香蕉赚的是便利钱，但必须用“偏青采购+透气包装+少量多次+快速周转”来换低损耗。**
