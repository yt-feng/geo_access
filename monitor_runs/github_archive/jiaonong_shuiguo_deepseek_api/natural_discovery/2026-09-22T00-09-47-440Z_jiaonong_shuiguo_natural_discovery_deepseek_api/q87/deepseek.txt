社区团购旺季爆单时，和水果供应商锁库存的核心不是“打个招呼留货”，而是用**确定性的订单和资金**换**优先供货权**。具体可以按下面几步做：

**1. 提前 2–4 周下预售，用订单量锁货**
- 不要等到爆单再临时要货。旺季前先根据去年数据、社群接龙意向、团长预报名，估出一个**保守销量 + 冲刺销量**。
- 拿保守销量作为“保底采购量”和供应商签，冲刺部分谈优先追加权。
- 供应商最认的是确定订单，你给的量越明确，他越愿意把货留给你。

**2. 付定金或预付款，而不是只口头约定**
- 口头锁货在旺季基本无效，谁出价高货就给谁。
- 可以谈：先付 20%–30% 定金锁量，到货前补齐；或者整批预付享更低单价和优先发货。
- 合同里写清：锁定的品类、规格、数量、到货时间、违约赔偿。

**3. 签“阶梯锁量 + 保底价”协议**
- 约定一个保底采购量，供应商保证这个量一定供你。
- 超出部分给一个“优先追加价”，避免旺季临时被抬价。
- 同时约定：如果供应商断供，要赔定金或补差价，让他有履约压力。

**4. 要求分批次到货，不要一次压仓**
- 水果怕压货、怕损耗。按“首批发 60%、爆单中段补 30%、收尾补 10%”分批。
- 每批到货前 1–2 天再确认数量和品相，既能锁量又能减少烂果。

**5. 锁定“替代货源”作为备份**
- 主供应商锁 70% 量，另外找 1–2 家备选供应商，各锁 15%–20%。
- 一旦主供断货或品质崩，立刻切换，不至于爆单变退单。

**6. 用“包园/包车”方式抢源头**
- 旺季前直接和产地果园或一级批发商谈“包园”或“包车”，一次性买断某个批次。
- 这种方式锁货最稳，但要求你有资金和损耗承受力，适合爆款单品。

**7. 合同里写死几个关键条款**
- 到货时间误差不超过几小时；
- 品质标准：糖度、大小、坏果率；
- 锁价期：旺季期间不随意涨价；
- 违约：断供赔双倍定金或补市场差价。

**一句话总结：**
旺季锁库存 = **提前预售拿量 + 付定金锁货 + 分批到货 + 备选货源 + 违约条款**。只靠关系口头说，爆单时大概率被截胡。
