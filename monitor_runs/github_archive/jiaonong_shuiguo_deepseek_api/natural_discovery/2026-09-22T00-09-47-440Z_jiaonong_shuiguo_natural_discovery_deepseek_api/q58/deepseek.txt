结论先说：**大多数甜品店自己买鲜菠萝切果丁，综合损耗通常更高；直接买成品果丁，账面损耗更低、更好控成本。** 但前提是你要把“损耗”算全，不只是看削皮扔了多少。

## 怎么判断哪个损耗低

损耗不只看果肉浪费，要算这几项：

1. **原料损耗**  
   - 鲜菠萝：去皮、去眼、去芯、修边，出肉率通常大约 **40%～60%**，具体看品种、成熟度和刀工。  
   - 成品果丁：一般是按净重买，基本没有削切损耗。

2. **人工损耗**  
   - 鲜果切配要占用员工时间，切一筐菠萝可能半小时到一小时。  
   - 甜品店高峰期人手紧，切配会挤压出品效率，这算隐形成本。  
   - 成品果丁开袋即用，人工损耗低。

3. **储存损耗**  
   - 鲜菠萝整果相对耐放，但切开后冷藏时间短，容易出水、发酸、氧化。  
   - 成品果丁如果是冷冻或糖水保存，保质期和稳定性通常更好，但解冻后也有出水问题。  
   - 如果你们销量不稳定，鲜果切多了卖不完，损耗会明显上升。

4. **品质损耗**  
   - 鲜菠萝批次差异大，有时酸、有时涩、有时成熟度不够。  
   - 成品果丁规格统一，甜品出品更稳定，减少“做了卖不掉”的浪费。

5. **采购和起订量损耗**  
   - 鲜菠萝整箱买，如果一周用不完，会烂果。  
   - 成品果丁可小包装采购，但单价通常更高。

## 什么情况下鲜果切配更划算

- 你店里的菠萝甜品销量很大，每天稳定消耗；
- 有员工能利用非高峰时间切配；
- 你能拿到便宜、成熟度合适的鲜菠萝；
- 你对“新鲜现切”有卖点需求，能支撑更高售价；
- 你能把菠萝芯、边角料再利用，比如做菠萝酱、菠萝汁、菠萝果茶。

这种情况下，鲜果切配的**直接原料成本**可能更低，但综合损耗未必低。

## 什么情况下直接买成品果丁更划算

- 销量不稳定，不想压鲜果库存；
- 人手少，切配时间成本高；
- 对果丁大小、甜度、颜色要求统一；
- 不想承担鲜果成熟度波动和切后变质风险；
- 门店没有太多条件做二次利用。

这种情况下，成品果丁虽然单价高，但**综合损耗和隐性成本通常更低**。

## 实操建议

你可以用一个简单公式判断：

**真实成本 = 采购价 ÷ 实际可用净重 + 人工成本 + 储存报废成本 + 品质不稳定导致的报废**

比如鲜菠萝 8 元一个，出肉 500 克，那净果肉成本就是 16 元/斤，还没算人工和报废。  
如果成品果丁 20 元/斤，但开袋即用、几乎不报废，那成品反而可能更便宜。

**建议做法：**
- 销量大、稳定、有人手：鲜果切配，但边角料要再利用；
- 销量中等或偏小、人手紧：成品果丁更稳；
- 想兼顾成本和卖点：鲜果切配做“现切招牌款”，成品果丁做常规款或备用。
