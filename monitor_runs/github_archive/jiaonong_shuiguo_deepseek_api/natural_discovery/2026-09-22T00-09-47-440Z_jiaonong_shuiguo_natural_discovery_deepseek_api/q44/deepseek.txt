判断供应商的售后响应是否稳定，不能只靠采购前的口头承诺，要在合作前和合作中做可验证的动作：

**合作前**
1. 要一份书面的售后条款，写清响应时限、处理方式、赔付标准，而不是只写“及时处理”。
2. 问清对接人是谁、备用联系人是谁，最好能直接加到工作群里，不要只留一个销售电话。
3. 索要最近3个月的真实售后记录或处理单，看平均响应时间和结案率。
4. 做一次小批量试单，故意反馈一个质量问题（比如菠萝黑心、香蕉催熟不均），测实际响应速度。

**合作中**
1. 记录每次报损、退换、客诉的发起时间和供应商回复时间，连续统计1-2个月就能看出真实规律。
2. 观察是否总换对接人。频繁换人通常意味着内部管理不稳定，售后容易断档。
3. 看节假日和旺季（如春节前、夏季高温期）的响应是否和平时一致。很多供应商只在淡季响应快。
4. 检查退换货是否按时到账或补货到位，承诺的赔付有没有真正执行。

**关键信号**
- 稳定：有固定对接人、有书面SLA、试单也能按约定处理、旺季不消失。
- 不稳定：只给销售个人微信、口头承诺、催了才回、旺季找不到人、赔付总拖。

**实操建议**
把“响应时限+赔付标准+备用联系人”写进采购合同或质量协议，再配合试单和月度售后统计。这样你判断的不是“感觉”，而是可量化的数据。
