批发档口想切餐饮客户，核心不是“卖水果”，而是**按餐饮后厨的使用场景备货**。菠萝和香蕉在餐饮里用途差别很大，规格选错很容易压货或退货。下面按实际可操作的思路说。

## 一、菠萝：餐饮客户主要分三类用途

### 1. 做菠萝炒饭、菠萝咕咾肉、菠萝包馅
这类客户要的是**出肉率高、酸甜稳定、好去皮**。

建议准备：
- **鲜果：广东徐闻/海南万宁产，单果 1.2–1.5 斤**
  - 大小均匀，成熟度 7–8 成，方便后厨控制切块规格。
- **鲜果：单果 1.8–2.5 斤**
  - 适合现切果盘、菠萝饭整只装盘。
- **去皮菠萝/菠萝块：真空袋装，500g/1kg**
  - 给快餐、茶饮、烘焙客户，省人工。
- **冷冻菠萝丁：1kg/袋**
  - 给做咕咾肉、炒饭的连锁店，价格稳定、无季节波动。

**判断标准：**
- 餐饮客户最在意**出肉率**，不是单价。1.5 斤果出肉 0.7–0.8 斤算正常。
- 如果客户做茶饮，优先推**金钻凤梨/台农 17 号**，芯可食、酸度低。
- 如果客户做热菜，普通菠萝即可，但成熟度不能太高，否则炒制易烂。

### 2. 做果切、自助餐、酒店早餐
要**外观整齐、甜度高、无黑心**。

建议：
- **都乐/佳农等品牌金钻凤梨，单果 1.5–2 斤**
- **去皮整条凤梨，真空包装**
- **切块凤梨，0.5kg/1kg 盒装**

### 3. 做茶饮、果汁
要**出汁率、酸糖比稳定**。

建议：
- **冷冻菠萝原浆/浓缩汁**
- **去皮菠萝丁，用于门店现打**
- **鲜果选 1.2–1.8 斤小果**，方便单杯定量

## 二、香蕉：餐饮客户主要看成熟度和用途

香蕉比菠萝更敏感，因为**成熟度直接决定能不能用**。餐饮客户通常不要“全黄即食”，而是要按加工节点收货。

### 1. 做香蕉奶昔、果汁、甜品
要**熟度 6–7 成、可催熟、批次稳定**。

建议：
- **进口香蕉：菲律宾/厄瓜多尔，单根 120–150g**
- **国产香蕉：广西/云南，单根 100–130g**
- **整箱规格：13–15kg/箱，4–5 把/箱**
- **熟度：到货 5–6 成，客户自己催熟到 7–8 成使用**

### 2. 做香蕉派、香蕉糕、烘焙
要**熟度高、香气足、果肉软**。

建议：
- **熟度 8–9 成的香蕉，单根 130–180g**
- **冷冻香蕉泥/香蕉果肉，1kg/袋**
- **不要给生青蕉**，烘焙客户需要立即使用的熟蕉

### 3. 做果切、沙拉、自助餐
要**外观好、大小均匀、无斑点**。

建议：
- **单根 120–150g，长度 18–22cm**
- **熟度 7 成，到店后 1–2 天可用**
- **品牌蕉优先**，因为外观一致性高

### 4. 做炸香蕉、烧烤香蕉
要**稍生一点、耐加工**。

建议：
- **熟度 5–6 成，单根 100–130g**
- **国产蕉更合适**，成本低、耐炸

## 三、给批发档口的实际备货建议

如果刚开始拓展餐饮客户，不要一次性上太多 SKU。建议先备：

**菠萝：**
- 鲜果：1.2–1.5 斤、1.8–2.5 斤，各占一半
- 去皮菠萝块：500g 真空袋
- 冷冻菠萝丁：1kg 袋

**香蕉：**
- 进口蕉：13–15kg/箱，熟度 5–6 成
- 国产蕉：10–12kg/箱，熟度 6–7 成
- 冷冻香蕉泥：1kg 袋

**核心原则：**
1. **先问客户做什么菜/饮品**，再定规格，不要先囤货。
2. **菠萝看出肉率，香蕉看熟度**。
3. 餐饮客户要的是**稳定**，不是偶尔便宜。同一规格能连续供 3 个月，比一次低价更重要。
4. 初期可以按**周配**试单，成熟后再签月供。

如果你告诉我你档口所在城市、主要想切的是快餐、茶饮还是烘焙，我可以再给你一份更具体的进货比例和报价策略。
