学校食堂采购水果，选供应商的核心不是“找最便宜的”，而是找到**能稳定供货、质量可控、票据齐全、出了问题能追责**的渠道。针对香蕉、苹果、橙子这类大众水果，可以按下面的框架来选。

## 一、先明确学校食堂的特殊要求

1. **票据要齐**：营业执照、食品经营许可证、每批次的检测报告/合格证，缺一不可。学校属于重点监管对象，一旦出问题追责很严。
2. **稳定性优先**：宁可单价贵一点，也要保证每天/每周按时到货，不能今天有明天没。
3. **可追溯**：能说清货源产地、批次，出问题能召回。
4. **账期和结算**：学校一般月结，要确认供应商能接受账期。

## 二、常见的供应商渠道及优劣

| 渠道 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 本地农产品批发市场商户 | 价格灵活、品类全 | 质量波动大、票据可能不全 | 小额补充 |
| 专业果蔬配送公司 | 配送稳定、票据规范、可追溯 | 单价略高 | **主渠道首选** |
| 产地合作社/基地直供 | 价格好、新鲜 | 单一品类、配送能力弱 | 大批量单品 |
| 大型商超/生鲜平台B端 | 规范、省心 | 价格偏高 | 应急或小量 |
| 线上生鲜B2B平台 | 比价方便 | 质量参差、需验货 | 辅助 |

**建议组合**：1家主供应商（配送公司或合作社）+ 1家备选，避免单一依赖。

## 三、具体筛选步骤

**第1步：资质审查**
- 营业执照、食品经营许可证
- 近3个月水果农残检测报告
- 是否有对公账户、能否开票

**第2步：实地考察**
- 看仓储条件（香蕉怕冻、苹果橙子要通风冷藏）
- 看分拣流程、是否有烂果混装
- 看是否有其他学校/单位客户（可侧面打听）

**第3步：试供期（2–4周）**
- 小批量试供，重点看：到货准时率、烂果率、规格是否一致
- 记录每次到货的损耗，一般香蕉损耗≤5%、苹果橙子≤3%算正常

**第4步：比价**
- 不能只比单价，要算**到货净重单价**（扣除损耗）
- 要求报价包含运费、税费

## 四、合同里必须写清楚的条款

1. **规格标准**：如香蕉每根≥120g、苹果直径≥75mm、橙子≥65mm，写进合同，避免扯皮。
2. **验收标准**：烂果率超标如何处理（退货/折价/换货）。
3. **退换货机制**：到货当天验收，不合格几小时内响应。
4. **食品安全责任**：因供应商原因导致食安问题，由供应商承担全部责任。
5. **价格调整机制**：水果价格波动大，约定调价周期（如每月一次），避免临时涨价。
6. **违约与终止**：连续几次不合格可终止合作。

## 五、日常管理要点

- **每次到货验货**：称重、抽检、拍照留证
- **建立供应商档案**：记录每次质量、准时率，作为续约依据
- **定期评估**：每学期评估一次，末位淘汰
- **留样**：重要批次留样，便于追溯

## 快速判断口诀

> **证件齐、能开票、送得稳、烂果少、可追溯、肯担责** —— 满足这6条，基本就是合格供应商。
