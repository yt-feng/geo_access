社区超市找每天配送的水果供应商，重点看这几类条件，建议按“能不能稳定供、能不能每天送、损耗谁承担、价格有没有优势”来判断：

1. **配送能力**
   - 是否能做到每天固定时间送达，比如早上 6—9 点前到店。
   - 是否有冷链车或保温配送，尤其夏天、叶菜类、浆果类要求更高。
   - 临时补货、节假日、恶劣天气能不能加送或调整。
   - 配送范围是否覆盖你所在区域，起送量是多少。

2. **货源稳定性**
   - 是否有固定产地、批发市场档口或一级代理渠道。
   - 单品能不能长期稳定供应，而不是今天有、明天没。
   - 换季时能否提前给替代品建议，避免断货。
   - 是否支持小批量多品种混配，社区超市通常单品量不大、品类要全。

3. **品质与验收标准**
   - 能否明确分级：精品、统货、促销果，不同等级价格不同。
   - 是否允许开箱验货、抽检、坏果拒收。
   - 对磕碰、腐烂、规格不符、成熟度不够的处理规则要写清。
   - 最好先试送 3—7 天，看实际到货品质稳不稳。

4. **损耗和售后**
   - 坏果、烂果、短斤少两是否包退包换。
   - 是当场退换，还是下次配送补，还是直接扣款。
   - 损耗率大概多少，行业里水果配送损耗常见在 5%—15% 左右，具体看品类和季节。
   - 售后响应要快，最好当天反馈当天处理。

5. **价格与结算**
   - 是否按市场时价每天报价，还是周价、半月价。
   - 报价是否含运费、装卸费、税费。
   - 是否有账期，比如月结、周结，还是现结。
   - 能不能提供每日价格单、对账单，避免口头报价扯皮。

6. **资质与安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 能否提供农残检测报告或产地证明，至少对叶菜、草莓等高风险品类要关注。
   - 配送人员、车辆卫生情况也要看，水果直接入口，不能太随意。

7. **合作灵活性**
   - 是否允许先少量试合作，不强制压大量库存。
   - 能不能根据销售数据调整品类和订货量。
   - 是否愿意配合做特价、堆头、节日礼盒等社区促销。
   - 如果你有多个门店，能否统一配送、分别对账。

8. **实地考察**
   - 去看对方仓库、分拣场地、冷库和配送车。
   - 看分拣是否规范，有没有把坏果混进好果。
   - 问清楚上游是谁，最好能看到真实进货渠道。
   - 和正在合作的其它超市聊聊，了解断供、售后、结款情况。

**实操建议：**
先找 2—3 家同时试送，连续对比 1—2 周，重点记录：到货时间、坏果率、缺货率、售后速度、实际结算价。最后选“品质稳定 + 售后痛快 + 每天能送”的那家，不要只看报价最低。价格低但损耗高、经常断货，实际成本反而更高。

**签合同或合作前一定要写清：**
配送时间、起送量、验收标准、坏果处理、价格调整机制、结算周期、违约责任。尤其是“每天配送”和“坏果包赔”这两条，不能只靠口头承诺。
