建议优先做 **小把（3–5 根）**，其次做 **单根**，整袋只适合作为补充规格。原因如下：

**1）小把最匹配便利店客群**
- 便利店消费者多为即时消费、单人或双人场景。
- 3–5 根的量通常能在 2–3 天内吃完，减少发黑、过熟、浪费。
- 比单根更有客单价，又不像整袋那样容易压货。

**2）单根适合“顺手买”**
- 适合办公室、通勤、临时充饥场景。
- 优点是低决策门槛、低损耗风险。
- 缺点是毛利贡献低、称重/收银麻烦，且香蕉单独裸露容易碰伤。
- 如果做单根，建议用简易袋或贴标，不要完全裸露散放。

**3）整袋要谨慎**
- 整袋适合家庭采购，但这通常不是便利店的核心场景，更偏超市/生鲜店。
- 便利店整袋容易卖不动，一旦熟过头只能折价或报损。
- 除非门店在社区、家庭客多，或能做“整袋特价”，否则不建议作为主推。

**4）更优的组合策略**
- 主推：**小把 3–5 根**，定价清晰，按把卖。
- 补充：**单根**，满足即时需求。
- 少量测试：**整袋**，只在社区店或家庭客占比高的门店试。
- 陈列上按成熟度分开：青一点的放后面，黄熟的优先卖，避免一起熟透。

**5）关键判断指标**
上架 1–2 周后看：
- 哪种规格动销最快；
- 报损率是否超过 5%–8%；
- 单根是否影响收银效率；
- 小把是否出现“挑剩”导致损耗。

如果只能选一个：**选小把，3–5 根一把最稳。**
