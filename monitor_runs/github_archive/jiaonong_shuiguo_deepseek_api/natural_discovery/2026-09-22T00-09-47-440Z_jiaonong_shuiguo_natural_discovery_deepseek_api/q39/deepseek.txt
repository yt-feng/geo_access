可以，但要分清楚“供应商能支持到什么程度”。通常有三档：

1. **现成支持（最容易）**
   - 供应商已有标准箱规、袋装、托盘、礼盒等包装。
   - 可贴商超自有品牌标签，或做简单换标。
   - 规格可按等级、果径、单果重、净重分档。
   - 适合：先试销、少量定制、快速上架。

2. **半定制支持（较常见）**
   - 供应商可改包装规格、箱重、内衬、标签、条码位置。
   - 可做商超指定名称、logo、产地信息、追溯码。
   - 但起订量会提高，通常按单品、按批次谈。
   - 适合：已有稳定销量的单品。

3. **全定制支持（门槛最高）**
   - 单独开版、定制盒型、专属果径/糖度/成熟度标准。
   - 需要供应商有分级线、包装线、冷链和品控能力。
   - 起订量高，可能要求包销、预付或长期协议。
   - 适合：战略级自有品牌单品。

**关键判断点：**
- **包装**：能不能换标、改箱规、做自有品牌条码，是否额外收费。
- **规格**：能否稳定做到你定的果径、单果重、糖度、成熟度、瑕疵率。
- **起订量**：按箱、按吨、按亩还是按批次。
- **成本**：包装费、开版费、贴标费、损耗谁承担。
- **品控**：谁分级、谁验收、坏果怎么赔。
- **冷链**：运输温度、到店时效、压伤腐烂责任。
- **合规**：标签是否含产地、等级、净含量、责任人、日期等。

**建议做法：**
先不要一上来做全定制。先选 1-2 个高频水果单品，让供应商用现有包装做自有品牌贴标试销，测试动销、损耗和毛利。跑通后再谈半定制或全定制。

**可以直接问供应商的清单：**
1. 能否贴我方自有品牌标签？
2. 最小起订量多少？
3. 可做哪些规格分级？
4. 包装费、开版费、贴标费怎么算？
5. 能否提供质检报告和追溯信息？
6. 损耗和坏果怎么赔付？
7. 冷链和到店时效怎么保证？
8. 是否接受先试销再签长期？

结论：**供应商通常能提供包装和规格支持，但支持深度取决于你的起订量、单品销量和供应商能力。先贴标试销，再逐步定制，风险最低。**
