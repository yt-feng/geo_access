结论先说：**大多数生鲜电商，优先做“整果”，其次做“冷冻原料”，最后才是“切配”。**  
但如果你的平台定位、履约能力和客群不同，答案会变。

**1. 整果：最适合线上卖**
- **优势**：标准化相对容易，耐运输，损耗可控，客单价可高可低，适合家庭直接消费。
- **适合场景**：社区团购、前置仓、次日达、产地直发。
- **关键点**：选耐储运品种，控制成熟度，做防撞包装，按大小/糖度分级。
- **风险**：消费者收到后仍需自己处理；成熟度不一致会影响复购。

**2. 切配：线上最难做，通常不建议作为主力**
- **优势**：方便，适合即时消费、果切、餐饮小商户。
- **劣势**：保质期短、冷链要求高、损耗大、食品安全风险高、售后纠纷多。
- **适合场景**：本地即时零售、前置仓、写字楼/校园等高密度区域，且订单量足够大。
- **关键点**：必须冷链、当日达/半日达，切配后尽快售完，包装要控氧控水。
- **判断**：如果履约半径超过 30 分钟到 1 小时，或做不到全程冷链，切配基本不划算。

**3. 冷冻原料：适合特定渠道，不适合普通家庭主力**
- **优势**：保质期长，损耗低，适合 B 端、烘焙、饮品、餐饮、冰沙、果酱等场景。
- **劣势**：家庭消费者接受度有限，解冻后口感不如鲜果，物流仍需冷链。
- **适合场景**：餐饮供应链、饮品店、食品加工厂、B 端批发。
- **关键点**：要明确是 IQF 速冻、果块、果泥还是果汁，规格和用途决定价格。

**简单决策表：**
- 面向家庭、次日达/快递：**整果优先**
- 面向本地即时消费、果切店：**切配可做，但只做短半径**
- 面向餐饮/饮品/B 端：**冷冻原料优先**
- 想兼顾：**整果做流量和复购，冷冻做 B 端利润，切配只做本地补充**

**最稳的组合建议：**
主线卖**整果**，用**冷冻原料**开发 B 端或深加工产品，**切配**只在核心城市、高订单密度、强冷链条件下试跑。先小范围测试损耗率、售后率和复购率，再决定是否放大。
