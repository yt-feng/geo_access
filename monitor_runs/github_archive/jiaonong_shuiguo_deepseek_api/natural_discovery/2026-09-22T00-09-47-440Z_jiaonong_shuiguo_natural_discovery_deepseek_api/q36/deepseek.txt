结论先说：**多数商超应以“整果为主、切果为辅”，把切果当提升客单价和降低损耗的补充品，而不是主销形态。** 但具体要看你的门店类型、客流结构和菠萝品种。

## 一、两种卖法的核心取舍

| 维度 | 整果 | 切好（鲜切/去皮） |
|---|---|---|
| 毛利 | 较高，损耗可控 | 加工、包材、人工成本高，需加价覆盖 |
| 损耗 | 卖不掉会烂，但可促销处理 | 切开后保质期短，当天卖不掉基本报废 |
| 客群 | 家庭、价格敏感、会自己削 | 单身、上班族、即食、怕麻烦 |
| 转化 | 单价低，冲动购买一般 | 即买即吃，冲动购买强，客单价高 |
| 运营 | 简单 | 需冷链、洁净操作、当日清货 |

## 二、什么情况主推整果

- 社区超市、菜市场型门店：顾客买菜顺带买水果，回家削果是常态。
- 菠萝单价敏感、竞品多：整果价格战更灵活。
- 人手不足、没有合规加工间：切果卫生和损耗风险反而更大。
- 菠萝当季、量大价低：整果冲量，靠促销走货。

## 三、什么情况值得做切果

- 商圈店、写字楼店、地铁口店：即食需求强，顾客愿意为“免削”付费。
- 年轻客群、单身/小家庭占比高。
- 有冷藏陈列和当日清货能力。
- 可以作为果切拼盘的引流单品，带动其他高毛利水果。

## 四、实操建议（可直接落地）

1. **整果做基本盘**：保证2–3个价格带（普通、精品、促销），满足家庭采购。
2. **切果做增量**：只做小份（如半只/一盒），定价=整果成本×（1.5–2倍）覆盖加工损耗。
3. **时段化出品**：切果集中在上午和傍晚两个高峰前加工，避免全天暴露。
4. **当日清零**：切果闭店前打折或转做拼盘，绝不隔夜。
5. **用整果兜底损耗**：卖相稍差的整果转切果，反而减少报废。
6. **看数据再定比例**：连续2–3周记录整果/切果的销量、毛利、报损，按“毛利额/坪效”调整，而不是凭感觉。

## 五、一句话判断

- **社区、家庭客为主 → 整果为主。**
- **商圈、即食客为主 → 切果比例可提高，但仍需整果做价格锚点。**
- **没有冷链和当日清货能力 → 先别大规模做切果。**
