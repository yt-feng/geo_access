餐饮店每天少量水果，最省心的选择不是“找最便宜的批发商”，而是找 **稳定、可小批量、能按你的菜单/出品标准固定供货** 的渠道。按省心程度从高到低给你排一下：

1. **本地生鲜配送平台/食材供应链公司**
   - 比如做餐饮供应链的生鲜配送商、区域食材配送公司。
   - 优点：可每天/隔天送，起送量低，能开票，售后相对规范，缺货、坏果一般能补退。
   - 适合：每天用量不大、但要求稳定的小店。
   - 注意：要确认是否支持“少量多品”，有些平台只做大单品起订。

2. **本地水果店/精品水果店长期合作**
   - 找离店近、经营稳定的水果店，谈固定供货价和每天送货。
   - 优点：沟通快、量小也愿意送、临时加单方便。
   - 缺点：价格波动大，品控看老板，旺季可能优先大客户。
   - 适合：每天只要几斤、几种水果的店。

3. **农贸批发市场固定摊位**
   - 找一两个靠谱摊位，固定每天早上去拿或让对方顺路送。
   - 优点：价格通常比零售低，品类全，可以自己挑。
   - 缺点：要早起、要自己控品，量太少时对方不一定愿意送。
   - 适合：离市场近、店里有人能早上去采购的。

4. **产地/基地直供或合作社**
   - 适合有单一水果长期大量需求时。
   - 对“每天少量、多品种”的餐饮店通常不省心，因为起订量高、配送不灵活。
   - 不建议小店作为主渠道，可作为某个爆品的补充。

5. **社区团购/线上批发平台**
   - 优点：下单方便，偶尔有低价。
   - 缺点：品质不稳定、配送时间固定、售后慢，不适合每天依赖。
   - 适合：临时补货，不适合做主供应商。

**最省心的组合建议：**
- 主供应商：本地生鲜配送商或附近水果店，签固定账期和送货时间。
- 备用供应商：批发市场固定摊位或另一家水果店，防止断供。
- 每天只订 1-2 天用量，避免压货；叶类、莓类等易坏水果少量多次。
- 固定验收标准：品种、规格、成熟度、坏果率、送达时间、缺货补送规则。
- 先试供 1-2 周，重点看：是否准时、坏果多不多、临时加单是否配合、月底对账是否清楚。

**一句话：**
小店每天少量水果，最省心的是 **附近水果店长期合作 + 本地生鲜配送商做备用**；如果附近有靠谱的餐饮食材配送公司，优先用它。不要一开始就找大批发商或产地直供，量小反而不省心。
