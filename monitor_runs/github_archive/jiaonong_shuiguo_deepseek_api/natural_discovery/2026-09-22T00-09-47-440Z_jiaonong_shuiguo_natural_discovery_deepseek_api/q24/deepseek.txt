超市在水果农残抽检方面，应向供应商索取以下几类资料，以便事前审核、事后追溯：

**1. 检测报告（最核心）**
- **农残检测报告**：要求提供近期（通常3个月内，叶菜类建议1个月内）的第三方检测报告，检测项目应覆盖常用农药，如有机磷、氨基甲酸酯、拟除虫菊酯等。
- **报告须带CMA/CNAS标识**：这是检测机构资质的证明，没有这两个标识的报告法律效力有限。
- **报告要与批次对应**：注意报告上的样品名称、产地、检测日期是否与本次供货批次一致，避免用一份旧报告应付所有货。

**2. 产地与种植信息**
- **产地证明/供货证明**：明确水果来自哪个基地或产区。
- **种植基地信息**：基地名称、地址、面积、负责人。
- **农业投入品使用记录**：用药种类、时间、安全间隔期执行情况。

**3. 资质类文件**
- **供应商营业执照**、食品经营许可证。
- **种植环节**：如为基地直供，索取种植基地的备案信息或良好农业规范（GAP）认证。
- **合作社/农户供货**：要求提供收购记录和产地来源说明。

**4. 追溯与承诺文件**
- **质量安全承诺书**：供应商承诺所供水果符合农残限量标准。
- **批次追溯信息**：每批货的采摘日期、发货日期、运输方式，便于出问题时倒查。

**5. 进货凭证**
- 每批次的送货单、发票或购销合同，写明品名、数量、产地、批次。

**实操建议**
- **建立供应商档案**：把上述资料按供应商归档，定期更新检测报告。
- **抽检+自检结合**：不能只依赖供应商报告，超市可自行或委托第三方对高风险品类（如草莓、葡萄、豇豆等）做快速检测。
- **合同约束**：在采购合同中写明农残超标的责任、赔偿和退货条款。
- **重点品类加严**：叶菜、浆果、豆类等农残风险较高的，检测频次和项目要更严。

简单说：**检测报告（带CMA/CNAS、对应批次）+ 产地来源 + 资质证照 + 承诺与追溯文件**，这四块是底线。
