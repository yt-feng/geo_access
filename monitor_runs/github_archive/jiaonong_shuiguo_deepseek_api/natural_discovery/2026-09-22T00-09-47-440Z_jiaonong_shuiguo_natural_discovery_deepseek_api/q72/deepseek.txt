做稳定大客户，核心不是“把账期谈长”，而是把账期、额度、价格、履约绑定成一个可执行的交易结构。下面按可操作顺序说。

## 一、先明确你能给什么、要什么

谈之前先算清三笔账：

1. **你的资金成本**：如果供应商给你30天账期，相当于你占用他的资金。你要知道自己的年化资金成本，比如8%、10%、12%，才能判断账期值多少钱。
2. **你的周转速度**：水果保质期短，正常7-15天周转。如果账期超过你的销售回款周期，供应商风险会陡增。
3. **你的采购集中度**：你能否承诺每月固定采购量、固定品类、固定提货节奏。这是你换账期的筹码。

## 二、账期怎么谈：分层给，不要一口价

建议用“阶梯账期”而不是单一账期：

| 合作阶段 | 建议账期 | 触发条件 |
|---|---|---|
| 首单/试单 | 现款或3天 | 建立信任 |
| 稳定1-3个月 | 7天 | 月采购额达到约定值 |
| 稳定3-6个月 | 15天 | 连续履约、退货率低于约定 |
| 核心大客户 | 30天 | 月采购额、品类集中度、保证金或担保到位 |

谈判话术可以这样：

> “我计划把你们作为主力供应商，每月固定走X个品类、X万采购额。前期我可以现款，证明我的提货和回款能力。做到连续3个月稳定采购后，我希望账期逐步到15天，再到30天。作为交换，我可以接受比市场价高1-2个点的采购价，或者承担部分物流。”

关键点：
- **不要一上来就要60天、90天**，水果供应商最怕这个。
- **账期要和采购量挂钩**，量不到就回调。
- **账期起算点要写清**：是发货日、到货日还是对账日。水果易腐，建议按到货验收日算。
- **节假日、春节前**供应商资金紧，账期往往收紧，要提前谈。

## 三、额度怎么谈：按“可承受坏账”倒推

额度不是越大越好，而是供应商能承受的最大敞口。你可以这样设计：

1. **初始额度**：月采购额的30%-50%，或相当于7-10天货款。
2. **提额条件**：连续3个月按时付款、退货率低于5%、无质量纠纷。
3. **额度上限**：不超过你月均采购额的1倍，或供应商单月利润的3-5倍。
4. **动态调整**：每月对账后重新核定，旺季可临时上调，需提前申请。

你可以主动提出**担保措施**来换额度：
- 付保证金，比如额度10%-20%；
- 提供银行保函或第三方担保；
- 用房产、车辆等抵押；
- 接受“部分现款+部分账期”的组合。

## 四、把价格、账期、额度打包谈

单独谈账期，供应商一定 defensive。你要打包：

**方案A：低价现款**
- 现款现货，价格最低。
- 适合你资金充足、想压采购成本。

**方案B：中价短账**
- 7-15天账期，价格上浮1-3%。
- 适合大多数稳定批发商。

**方案C：高价长账**
- 30天账期，价格上浮3-5%，或接受部分尾货。
- 适合你下游回款慢、需要现金流缓冲。

你可以让供应商选，而不是你单方面提要求。这样他感觉是合作，不是被压榨。

## 五、合同里必须写死的条款

1. **账期起算和截止**：到货验收后X天，遇节假日顺延。
2. **额度触发**：超过额度部分现款，或需提前申请。
3. **质量与退货**：水果损耗、等级不符怎么扣款，退货是否冲抵账期。
4. **逾期责任**：逾期利息、暂停供货、额度冻结。
5. **价格调整机制**：市场价波动超过X%时怎么调。
6. **排他或优先权**：你承诺主力采购，供应商承诺优先供货、优先处理售后。
7. **退出机制**：合作终止后未结货款怎么处理。

## 六、实际谈判节奏

1. **第一次见面**：只谈合作意向和试单，不急着要账期。
2. **试单期**：现款或3天账期，重点证明你的提货量和回款速度。
3. **第二次谈判**：拿3个月数据说话，提出15天账期+初始额度。
4. **稳定期**：每季度复盘，用采购增长换账期和额度提升。
5. **旺季前**：提前1个月谈临时额度和账期，避免断供。

## 七、给你的底线建议

- 如果供应商坚持现款，你可以接受，但要求**价格折扣或优先供货**。
- 如果账期低于7天，意义不大，不如换价格。
- 如果账期超过30天，供应商通常会把风险加到价格里，你要算总成本。
- 不要同时向多家供应商要长账期，容易被视为资金链紧张。
- 稳定大客户的核心是：**你让他赚钱、让他省心、让他风险可控**。账期和额度只是结果，不是起点。

一句话：先用现款和小单建立信任，再用稳定采购量换阶梯账期和动态额度，最后用担保和打包条件锁定长期合作。
