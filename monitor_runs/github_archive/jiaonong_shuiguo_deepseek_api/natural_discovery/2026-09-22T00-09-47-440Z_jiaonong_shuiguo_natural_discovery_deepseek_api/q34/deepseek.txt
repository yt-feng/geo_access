结论先说：**在商超水果品类里，损耗低通常比采购价格低更影响最终毛利，但两者不是二选一，真正决定毛利的是“低进价 + 低损耗 + 合适售价”的组合。**

如果必须排序，多数商超水果场景下：

**损耗控制 > 采购价格**

原因如下。

### 1. 水果毛利不是只看进价
水果最终毛利大致可以理解为：

**毛利 = 销售额 - 采购成本 - 损耗成本 - 运营成本**

采购价格低，只影响“采购成本”这一项。  
损耗低，影响的是“采购成本”和“销售额”两头：

- 损耗高，等于你买回来的货有一部分没卖出钱；
- 损耗高，还会拉低陈列品相，导致顾客不愿买；
- 损耗高，往往意味着一部分销售额直接消失；
- 损耗高，还会增加理货、折价、报损、人工处理成本。

所以损耗是直接吃掉毛利的，而且常常比进价差几个点更致命。

### 2. 一个简单算账
假设一批水果采购 1000 元。

- 如果损耗 10%，实际可售成本变成：1000 ÷ 90% = 1111 元；
- 如果损耗 20%，实际可售成本变成：1000 ÷ 80% = 1250 元；
- 如果损耗 30%，实际可售成本变成：1000 ÷ 70% = 1429 元。

也就是说，**20% 的损耗，相当于进价变相上涨 25%；30% 的损耗，相当于进价变相上涨约 43%。**

而采购价格通常很难长期比竞争对手低 20%、30%。  
所以很多时候，进价便宜 5%，但损耗高 10%，最后毛利反而更差。

### 3. 什么时候“低价采购”更重要？
也不是低价不重要。以下情况，采购价格影响会更大：

- 水果耐储存、损耗天然低，比如苹果、橙子、柚子、部分瓜类；
- 你已经有很强的冷链、周转和控损能力；
- 采购量很大，进价差 5% 就是很大金额；
- 是做引流款、爆款，靠低价冲销量；
- 产地直采、提前锁价，品质稳定；
- 售价敏感，顾客对价格非常敏感。

这种情况下，低进价能直接扩大毛利空间。

### 4. 什么时候“低损耗”更重要？
以下情况，损耗几乎决定生死：

- 叶菜类、浆果类、荔枝、樱桃、桃子、葡萄等易腐水果；
- 门店客流不稳定，预测不准；
- 冷链弱、陈列条件差；
- 员工控损能力弱；
- 促销和订货节奏混乱；
- 损耗率长期高于 10%。

这类水果里，进价再低，卖不出去、烂得快，最后都是亏。

### 5. 真正该看的关键指标
不要只盯“进价低不低”，而要看：

1. **损耗率**
2. **毛利率**
3. **周转天数**
4. **动销率**
5. **残次率**
6. **折价销售占比**
7. **报损金额占销售额比例**
8. **品类毛利贡献，而不是单品进价**

更实用的判断公式是：

**真实采购成本 = 采购价 ÷ 可售率**

可售率 = 1 - 损耗率。

比如：

- A 水果进价 5 元，损耗 5%，真实成本约 5.26 元；
- B 水果进价 4.5 元，损耗 20%，真实成本约 5.63 元。

虽然 B 进价更低，但真实成本更高。

### 6. 实操建议
如果你做商超水果采购，优先级建议这样排：

1. **先控损耗，再谈进价。**
2. **易腐品优先找稳定品质和周转能力，不要只找最低价。**
3. **耐储品可以更积极压进价。**
4. **用“真实成本”而不是“采购价”做对比。**
5. **对高损耗品类，宁可进价高一点，也要品质稳、周转快。**
6. **对低损耗品类，可以把进价作为核心竞争点。**
7. **最终看品类综合毛利，不只看单品进价。**

### 一句话总结
**大多数商超水果经营中，损耗低比价格低更影响最终毛利。**
因为损耗会直接吃掉销售额和利润，而低进价只是改善成本端。  
但最赚钱的做法不是二选一，而是：**在可接受的损耗范围内，尽量压低进价；在高损耗品类里，优先保品质和周转。**
