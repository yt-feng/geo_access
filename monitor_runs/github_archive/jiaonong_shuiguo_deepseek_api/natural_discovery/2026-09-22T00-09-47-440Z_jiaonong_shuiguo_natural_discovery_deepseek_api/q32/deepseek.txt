判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要围绕**货源结构、产地轮换、硬件能力、历史履约、风险预案**五个方面做核验。下面给你一套可直接执行的判断方法。

**一、先问清货源结构，不看单一产地**

香蕉是典型的热带作物，单一产地一定会有季节性空档。所以重点问：

1. **有几个产地？**  
   国内主要是海南、云南、广西、广东；进口主要是菲律宾、越南、柬埔寨、老挝、厄瓜多尔等。  
   如果对方只报一个产地，全年稳定供货基本不可信。

2. **不同产地的上市时间是否衔接？**  
   要求供应商给出全年逐月的产地供应表，比如几月主供海南、几月转云南、几月靠进口补位。  
   关键看空档期有没有替代产地顶上。

3. **进口比例和渠道是否稳定？**  
   如果依赖进口，要问清是直接对接境外农场/出口商，还是通过一级批发市场拿货。  
   通过批发市场拿货的，价格和货源波动都大，全年稳定性弱。

**二、看硬件和加工能力**

全年供货不只是有香蕉，还要能持续出合格商品。重点看：

1. **有没有催熟库？**  
   香蕉通常要催熟后上架。没有催熟能力的供应商，很难稳定按你的销售节奏供货。

2. **冷库和冷链能力**  
   问冷库容量、温控范围、冷链车数量。  
   全年供货意味着旺季要囤、淡季要调，没有冷库就很难平衡。

3. **加工分拣能力**  
   能否按你的标准做分级、去把、包装？  
   如果只是整车统货，门店损耗和断货风险都会高。

**三、查历史履约记录**

不要只听“我们做了很多年”，要具体验证：

1. **要过去12个月的供货记录**  
   看每月实际供货量、断货次数、到货合格率。

2. **找现有客户交叉验证**  
   最好找同区域、同规模的连锁超市或生鲜渠道，问三个问题：  
   - 有没有出现过旺季断货？  
   - 淡季能不能按量供？  
   - 质量问题处理及不及时？

3. **看合同履约率**  
   如果对方愿意提供历史合同中的履约率数据，比口头承诺可信得多。

**四、做压力测试和试单**

在正式签全年合同前，建议做三步：

1. **淡季试单**  
   在香蕉供应相对紧张的月份下单，看对方能不能按时按量到货。  
   这比旺季试单更能检验真实能力。

2. **突发增量测试**  
   比如临时增加30%—50%要货量，看对方能否在24—48小时内响应。  
   连锁超市促销时经常需要这种能力。

3. **多批次质量抽检**  
   连续抽检几批，看规格、成熟度、损耗率是否稳定。  
   全年稳定不仅是“有货”，还是“货稳”。

**五、看风险预案和合同条款**

真正稳定的供应商，一定有预案。你可以直接问：

1. **如果主产地受灾减产，替代货源在哪里？**  
2. **如果物流中断，有没有备用冷链和路线？**  
3. **如果市场价格暴涨，是否还按合同价供？**  
4. **断货怎么赔？**  
   合同里要写清：最低月供量、到货时效、质量标准、断货违约金、价格调整机制。

**六、给你一个快速判断清单**

满足以下多数条件，才算具备全年稳定供货能力：

- 有2个以上产地或进口渠道，且上市期能衔接；
- 有自有或长期合作的催熟库、冷库、冷链；
- 能提供过去12个月真实供货数据；
- 有同规模连锁超市的长期合作案例；
- 淡季试单和突发增量测试都通过；
- 合同里有最低供货量、断货赔偿和替代货源条款。

**结论：**  
判断香蕉供应商能否全年稳定供货，核心不是看他说有多少货源，而是看**多产地轮换能力 + 冷链催熟硬件 + 历史履约数据 + 淡季实测 + 合同约束**。这五项都过关，才值得签全年供货协议。
