重要，而且往往是多门店水果品质能不能统一的前置条件。

原因很直接：

1. **门店执行只能“按标准收货”**
   - 水果是非标品，同一品种不同批次、产地、季节差异很大。
   - 如果没有统一分级标准，门店验收只能靠个人经验，必然出现A店收得松、B店收得严。
   - 采购再努力，也会变成“同一供应商，不同门店拿到不同品质”。

2. **分级标准影响的不只是大小**
   - 真正有用的水果分级，至少要覆盖：品种、产地、规格（单果重/直径）、成熟度、糖度、色泽、果面瑕疵、机械伤、腐烂率、包装方式。
   - 只分大小不分成熟度和瑕疵，门店端仍然会出现“看起来一样，吃起来不一样、放两天就坏”的问题。

3. **统一标准才能谈供应商考核**
   - 没有分级标准，就无法判断退货、扣款、换货是否合理。
   - 有标准后，才能按批次抽检、记录合格率，做供应商排名和淘汰。
   - 否则采购和门店会长期扯皮：门店说货差，供应商说验收太严。

4. **多门店场景下，标准还要能落地**
   - 标准不能只写在合同里，要转成门店可执行的验收卡：图文对照、规格尺、糖度抽检规则、允收比例。
   - 最好统一由配送中心或区域仓做一级验收，门店只做二级抽检，减少门店差异。

所以，供应商的分级标准不仅重要，而且是统一品质的基础设施。  
但要注意：**标准必须和验收流程、抽检机制、退换货规则绑定**，否则只是一份好看的文件，门店端仍然统一不了。
