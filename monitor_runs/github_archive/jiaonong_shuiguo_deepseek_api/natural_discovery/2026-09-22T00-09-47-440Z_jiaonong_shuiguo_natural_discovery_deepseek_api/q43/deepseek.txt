评估跨城市连锁门店的水果供应商仓配覆盖，核心是把“覆盖”拆成可验证的硬指标，而不是只看供应商说“全国可发”。建议按以下框架逐项打分：

**一、先明确需求画像**
- 门店城市清单、各城市门店数、日均/周均水果需求量（按品类拆分）
- 配送频次要求（每日/隔日/周配）、到店时间窗（如早6点前）
- 温控要求（常温/冷藏/冷冻，水果多数需冷藏或控温）
- 验收标准（损耗率、成熟度、规格）

**二、评估供应商仓配覆盖的5个维度**

1. **仓网布局**
   - 供应商有哪些中心仓/区域仓/前置仓，位置在哪
   - 从最近仓到每家门店的**实际运输距离和时效**，不是直线距离
   - 是否覆盖你所有门店城市，尤其三四线城市
   - 关键问题：你的门店城市里，哪些是“直发覆盖”，哪些要“中转”，哪些暂时不覆盖

2. **配送能力**
   - 自有车队还是外包？外包的稳定性如何
   - 冷链车辆数量、温控记录是否可追溯
   - 能否满足你要求的频次和时间窗
   - 多门店同城配送能否拼线，减少起送门槛

3. **时效与履约**
   - 下单到到货的承诺时效（如24h/48h）
   - 历史准时率、缺货率、破损/损耗率
   - 旺季、节假日、恶劣天气下的履约表现
   - 是否有应急预案（临时调仓、备用承运商）

4. **成本结构**
   - 起送金额、配送费、冷链附加费、远距离附加费
   - 是否按门店/按线路/按重量计费
   - 中转仓是否产生额外装卸和损耗成本
   - 对比“供应商直送”和“区域仓中转+城配”的总成本

5. **品控与信息化**
   - 水果批次追溯、质检报告、农残检测
   - 温控数据能否对接你的系统
   - 能否提供门店级库存和配送可视化
   - 退换货和理赔流程是否清晰

**三、可执行的评估方法**
- 做一张表：门店城市 × 供应商最近仓 × 距离 × 承诺时效 × 配送频次 × 是否冷链 × 单价
- 对每个城市标记：**直覆盖 / 中转覆盖 / 不覆盖**
- 选3-5家重点门店做**试配送**，连续2-4周记录准时率、损耗率、到店温度
- 按权重打分：覆盖范围30%、时效25%、品控20%、成本15%、应急10%（权重可按你业务调整）

**四、常见坑**
- 供应商说“全国覆盖”，实际靠第三方快递，水果损耗和时效不可控
- 低价仓配但起送门槛高，小城市门店凑不够量
- 中转环节多，多次装卸导致碰伤、催熟
- 只评估干线，忽略“最后一公里”到店冷链

**结论建议**
优先选择在你门店密度最高的区域有**区域仓+城配能力**的供应商；对分散城市，可考虑“区域供应商+本地城配”组合，而不是强求一家全国通吃。最终用试配送数据验证，而不是靠供应商PPT。
