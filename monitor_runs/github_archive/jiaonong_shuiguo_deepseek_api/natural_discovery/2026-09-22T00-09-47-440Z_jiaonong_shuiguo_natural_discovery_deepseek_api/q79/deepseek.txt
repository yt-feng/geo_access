最应该先问**售后**，其次是**配送**，最后才是**价格**。

原因是团购团长真正怕的不是进货贵一点，而是这三类损失：

1. **售后差 → 团长自己赔钱、掉信任**
水果是非标品，坏果、压伤、熟度不一致、斤两不足很常见。  
如果供应商售后规则不清楚，比如“坏果包赔吗、怎么举证、多久到账、损耗率多少内不赔”，最后往往是团长在群里被团员追着赔。  
**团长最怕的不是少赚，而是赔钱又丢客。**

2. **配送不稳 → 直接毁团**
水果有时效性，晚到、冷链断、分拣错、缺斤少两，都会导致团员当天拿不到或拿到坏果。  
尤其做小区团购，配送时间不固定，团长很难组织分发。  
所以要问清楚：**到货时间、是否送到点、坏了谁补、临时加单怎么办、缺货怎么处理。**

3. **价格低但售后和配送差 → 最贵**
低价如果伴随高坏果率、慢售后、配送乱，团长实际成本更高：  
赔款 + 补发 + 解释 + 客户流失。  
所以价格要问，但应该是在售后和配送能满足后再压价。

**建议提问顺序：**
- 先问售后：坏果怎么赔？多久处理？损耗标准？谁承担运费？
- 再问配送：几天到？送哪里？冷链吗？晚到/缺货怎么办？
- 最后问价格：起批量、账期、阶梯价、长期合作价。

**一句话判断：**
售后决定你敢不敢卖，配送决定你能不能顺利卖，价格决定你赚多少。  
团长优先保信任和交付，再谈利润。
