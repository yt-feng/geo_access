对餐饮连锁来说，绝大多数情况下 **中央厨房统一收货更好**，但前提是你的品类、损耗、仓储和配送能力匹配。更准确地说：**水果适合“中央厨房统采统收 + 门店只做最终验收/急配补货”的混合模式**，而不是简单二选一。

下面给你一个可判断的决策框架。

**一、中央厨房统一收货的核心优势**

1. **品控标准统一**
   - 水果的成熟度、糖酸比、规格、外观标准可以由总部统一制定。
   - 避免各门店收货标准不一，导致出品不稳定。

2. **采购议价能力更强**
   - 集中采购量更大，更容易拿到产地直采、分级价、账期。
   - 减少门店各自找供应商带来的价格不透明和灰色空间。

3. **食品安全与追溯更可控**
   - 农残检测、批次记录、索证索票集中在中央厨房，追溯链更短。
   - 门店分散收货时，证照和检测报告容易缺失或过期。

4. **减少门店操作负担**
   - 门店人手有限，水果验收需要专业判断，交给中央厨房更现实。
   - 门店只负责签收数量、温度、外观异常，不承担主要品质责任。

5. **便于加工和标准化**
   - 如果水果需要清洗、切配、分装、去皮、去核，中央厨房统一处理更高效。
   - 门店只做开封或简单摆盘，降低损耗和食品安全风险。

**二、门店分开收货的适用场景**

门店分开收货不是完全没价值，它适合以下情况：

1. **极短保、易损水果**
   - 如草莓、蓝莓、杨梅、荔枝、樱桃等。
   - 从中央厨房再中转一次，可能增加碰撞、温度波动和时效风险。

2. **门店密度低、配送成本高**
   - 如果中央厨房到门店距离远、冷链覆盖差，统一配送反而不经济。

3. **门店有独立加工需求**
   - 比如高端门店现切果盘、鲜榨果汁，对成熟度和即时性要求高。
   - 门店直接对接本地供应商可能更灵活。

4. **区域差异大**
   - 不同城市消费者偏好不同，统一采购可能造成滞销或不适配。

**三、建议采用的混合模式**

比较稳妥的做法是：

- **中央厨房统一收货**：苹果、橙子、西瓜、哈密瓜、柠檬、牛油果等耐储、标准化程度高的水果。
- **门店本地直收或急配**：草莓、蓝莓、荔枝、樱桃、杨梅等极短保、高损耗水果。
- **总部统一供应商池和价格框架**：即使门店收货，也必须从总部认证供应商采购，执行统一质量标准。
- **门店只做“到货验收”**：检查数量、温度、外观、批次，不自行决定降级使用。
- **建立异常反馈机制**：门店收货异常 2 小时内上报，中央厨房或总部采购追责供应商。

**四、判断时重点看这 5 个指标**

1. **损耗率**：统一收货后综合损耗是否下降。
2. **配送时效**：从中央厨房到门店是否能在要求时间内完成。
3. **冷链能力**：中央厨房和配送车辆能否全程控温。
4. **门店操作能力**：门店是否有条件做专业验收和暂存。
5. **总成本**：采购价 + 仓储 + 加工 + 配送 + 门店损耗，算总账而不是只看采购价。

**五、结论**

- 如果追求 **标准化、食品安全、议价能力、总部管控**：中央厨房统一收货更好。
- 如果水果 **极短保、易损、配送半径大、门店有即时加工需求**：门店分开收货或本地急配更合适。
- 最推荐的是：**中央厨房统采统收为主，门店本地急配为辅，总部统一供应商和标准。**

一句话：**耐储标准品走中央厨房，极短保高损耗品走门店或区域配送，但标准和供应商必须由总部统一管。**
