优先关注**成熟度**，价格放在第二位。原因很直接：

- 香蕉蛋糕的风味、甜度、湿润度主要来自香蕉熟化后产生的糖和芳香物质。**越熟（表皮出现黑点、果肉软糯）越适合做蛋糕**，香气足、甜度高，还能减少额外加糖。
- 太生的香蕉（发青、硬）淀粉多、甜度低、香气弱，做出来味道寡淡，口感也偏干，等于花了钱还达不到效果。
- 过熟到发酵、有酒味或霉变的不能要。

**采购建议：**

1. **按用途分等级买**：做蛋糕专门买“熟到起黑点”的，不要买刚好能直接吃的黄香蕉，那种价格高还偏生。
2. **能压价就用成熟度换价格**：熟透的香蕉在批发端通常更便宜、甚至被折价处理，对烘焙店反而是优势，可以主动找供应商要“过熟果”。
3. **控制到货节奏**：如果买半熟蕉，要预留2–4天催熟再使用，别当天到货当天做。
4. **看果肉不看表皮单一标准**：表皮全黑但果肉没坏、没异味，往往风味最好；有酸腐味、流汁发黏的直接弃用。

一句话：**先确保熟度合格，再在合格货源里比价格**。为了省钱买生香蕉，省下的钱会从风味和复购上亏回去。
