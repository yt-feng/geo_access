供应商在介绍时，不要先讲品种和产地，要先讲清楚三个问题：**这个货到你手里赚多少钱、卖给谁、好不好卖。**

## 1. 先说“卖给谁、怎么卖”

不要讲“这是金钻凤梨，台农17号”，而要讲：

> “这个货适合做水果店中高端散卖，也可以做果切。顾客一看叶子小、没眼、不用泡盐水，现场切一块试吃，接受度很高。”

商家脑海里要先出现一个具体场景：摆在哪个货架、卖给什么顾客、怎么推销。听不懂品种，但一定听得懂顾客。

## 2. 再说“你赚多少”

商家最关心的是毛利，不是农产品知识。直接算账：

> “我发价一箱 XX 元，大概 X 斤，你卖 X 元一斤，一箱能卖 XX 元，毛利大概 XX 元。损耗按 X% 算，也还有 XX 元。”

如果能说清：**进价、建议售价、毛利空间、损耗率**，商家基本就能判断要不要试。

## 3. 对比他熟悉的品类

用菠萝、香蕉做锚点，最省沟通成本：

> “跟你现在卖的普通菠萝比，这个进货贵 X 元，但卖价能高 X 元，不用削眼、不用泡盐水，损耗少很多。”  
> “香蕉是走量的，这个是拉客单价的。你香蕉旁边放一箱，顾客顺手就买。”

不要贬低他现有品类，而是说明“这个货补什么位”。

## 4. 说清风险和退路

商家不下单，很多时候不是不感兴趣，是怕压货。可以直接给他安全感：

> “第一次不用拿多，先拿两箱试。卖不动我教你做果切、做试吃。这个货放 X 天没问题，比普通菠萝耐放。”

有条件的，可以支持少量混拼、坏果包赔、次单补差。这比讲十句“品质很好”都有用。

## 5. 一个可以直接照着说的模板

> “老板，这个不是普通菠萝，是凤梨。你店里现在菠萝卖 X 元，这个可以卖 X 元。顾客不用泡盐水，切开就能吃。你拿一箱试试，毛利大概 X 元，损耗比菠萝低。卖的时候切一盘试吃，基本一上午能走半箱。第一次少拿点，卖好了再补。”

## 核心原则

**少讲品种，多讲场景；少讲品质，多讲利润；少讲产地，多讲怎么卖。**

商家不是不想懂产品，而是没时间懂。供应商要做的是把农产品翻译成“货架语言”和“算账语言”。他听得懂赚钱，就听得懂产品。
