在水果店采购菠萝时，判断熟度需要结合**外观、气味、手感**和**采购场景**（采购后是立即卖还是存放几天再卖）来综合判断。以下是具体建议：

### 1. 区分“采购成熟度”与“售卖成熟度”
- **采购时**：不宜买全熟（当天卖不出去会烂），也不宜买全生（口感酸涩，顾客不买）。
- **最佳采购状态**：八成熟左右，即**果皮由青转黄、但仍有少量青绿色**，这样的菠萝放一两天后自然成熟，销售期宽裕且损耗低。

### 2. 五大判断指标（按重要性排序）

| 指标 | 八成熟特征（适合采购） | 全熟/过熟特征（不建议采购） |
|------|------------------------|----------------------------|
| **颜色** | 果皮整体淡黄，底部黄多，顶部带青 | 全黄甚至橙黄，果眼凹陷明显，底部发软发暗 |
| **硬度** | 按压果皮有韧性，略微软但能回弹 | 按压明显凹陷，或整体软塌塌 |
| **果眼（菠萝钉）** | 果眼饱满，表面平滑，无明显干裂 | 果眼干瘪、发皱，或有小裂口 |
| **底部切口** | 切口呈白色或淡黄色，新鲜湿润 | 切口变棕、发干或有霉斑 |
| **气味** | 靠近底部闻，有淡淡清香 | 浓烈甜香（过熟）或酒精味（发酵变质） |

### 3. 关键操作技巧
- **不要只看颜色**：有些品种（如台湾凤梨）外皮青时内部已熟，要结合**果眼间距**——果眼间距越宽，说明果肉越饱满成熟。
- **掂重量**：同样大小，挑重的，含水量高，果肉更脆甜。
- **避开“徒长”果**：果柄太粗、形状不规则（如细腰、歪果）的菠萝，成熟度不均匀，损耗高。

### 4. 采购场景调整
- **如果采购后当天直接零售**：选九成熟（几乎全黄、微香），当天卖完不压货。
- **如果采购后要存放2-3天**：选七至八成熟（青黄各半），到店后摆通风处，每天翻动底部，避免压伤。

### 5. 减少损耗的额外建议
- 采购时**按销售速度定量**，不要一次性囤多，菠萝是呼吸型果实，采后仍会继续成熟。
- 到店后**竖放**（果蒂朝下），减少受压面积。
- 若有轻微碰伤，切块试吃后降价促销，而不是等全坏。

如果批量采购（整箱），可以抽查箱中上、中、下层各2-3个果，按上述标准快速判断整批成熟度，避免只挑表面好看的。
