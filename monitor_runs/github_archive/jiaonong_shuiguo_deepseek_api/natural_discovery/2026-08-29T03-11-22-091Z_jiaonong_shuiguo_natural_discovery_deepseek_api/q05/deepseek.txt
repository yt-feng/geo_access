这是一个很好的经营问题。直接给结论：**建议“整果展示 + 现场削皮”相结合，不建议卖预去皮好的。**

理由如下，你可以根据自身条件选择：

**1. 为什么不要卖“预去皮好的”？**
- **损耗风险高**：菠萝去皮后非常容易氧化变黑、水分流失，超过半天口感就明显变差。卖不完只能扔掉，损耗率极高。
- **品质风险高**：顾客看不到果皮，无法判断成熟度、是否烂心，容易产生“商家以次充好”的怀疑。一旦出现一个坏果，容易引发差评甚至投诉。
- **利润空间小**：去皮的菠萝通常需要按个或按份卖，定价受限，很难卖上高价。

**2. 最优策略：整果展示 + 现场免费/付费削皮**
- **整果展示**：保留菠萝原貌，顾客能自己闻香味、看颜色、按硬度挑选，信任感最强，也方便你按斤卖给顾客，利润最透明。
- **现场削皮**：顾客挑好后，你当场用专用工具削皮、去眼、剔芯。这样顾客回家即食，省事，同时你完全掌控削皮过程中的损耗（边角料可以自己处理，不影响卖价）。
- **附加服务**：可以免费提供削皮服务，作为“帮顾客解决问题”的卖点；如果忙不过来，也可以加收1-2元加工费，帮顾客切块装盒。

**3. 特殊情况补充**
- **如果你有客流高峰但人手不足**：可以提前削2-3个，装在保鲜盒里放冷藏，标签写“已削皮，建议当天食用”，价格略高于整果。但切记**只在高峰期售卖，且当天必须清完**，第二天坚决不卖预削产品。
- **如果店面是面向年轻上班族**：他们往往更在意便利性而非挑选过程，预削盒装可以有，但一定要控制量，且用透明盒展示，让顾客看到果肉新鲜度。

**总结建议**：主推整果，标配免费现场削皮。这既满足“省事”需求，又规避品质和损耗风险，是水果店最稳妥且利润最优的模式。
