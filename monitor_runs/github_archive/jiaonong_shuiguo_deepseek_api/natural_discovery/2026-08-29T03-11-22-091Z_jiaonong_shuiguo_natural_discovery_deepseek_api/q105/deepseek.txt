水果采购中，供应商锁价的时间长短没有统一标准，主要取决于**水果品类、季节、市场行情、供应商实力以及双方合作关系**。一般来说，可以参考以下区间：

1. **常规大宗水果（如苹果、梨、柑橘）**：如果是在产地丰收期，且市场供应充足，供应商通常愿意锁价 **1-2周**。这个周期内价格波动较小，供应商风险可控。
2. **应季水果（如西瓜、芒果、葡萄）**：这类水果价格波动大，且随上市量变化快，通常只能锁价 **3-7天**。若遇到天气突变或采摘量骤减，供应商往往只接受当天定价。
3. **进口水果或反季节水果**：由于涉及海运/空运周期，且市场行情受汇率、关税影响，锁价期较短，一般 **1周以内**，或只做”预售锁价“（即按到港日市场价+固定加价）。
4. **长期稳定合作客户**：如果你的采购量稳定、付款及时，且供应商有库存能力，可以协商 **锁价1个月**，但这种情况下，价格通常不是最低点，而是给一个“中间价”，以对冲双方风险。

**实操建议：**
- 锁价前，先明确锁的是**产地价**（含包装、运费）还是**到仓价**（含损耗、配送），避免后续歧义。
- 在合同中注明**锁价失效条款**，例如“若产地收购价涨幅超8%，双方重新议价”，这样既防止供应商违约，也避免自己被动。
- 如果遇到价格快速上涨期（比如春节前），供应商通常不愿长锁，可以考虑**分批锁价**（比如每次锁5天，连续签3次），这样既稳定了短期价格，又给了自己调整空间。

最后提醒：锁价锁的是“采购成本”，但别忘了将**残次率、规格波动、到货时间**一并写入合同，这些才是稳定采购总成本的关键。
