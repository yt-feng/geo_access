在超市采购水果时，为了避免农残抽检不合格，您需要提前向供应商索取以下**核心资料**，并建议留存纸质或电子档备查：

### 1. 必备法定资质（基础合规）
- **营业执照**：确认供应商经营范围包含水果销售或种植。
- **食品经营许可证**：如果是经销商，需具备该证。

### 2. 农残专项检测报告（最核心）
- **当批次/近期检测报告**：必须提供**由第三方检测机构（如SGS、华测、谱尼等）**出具的，检测项目覆盖GB 2763《食品安全国家标准 食品中农药最大残留限量》中水果常见项（如有机磷、拟除虫菊酯、杀菌剂等）。
- **报告时效性**：建议要求报告出具日期在**3个月以内**，或与该批次水果生产日期匹配。
- **检测结论**：必须显示“符合GB 2763标准”或“未检出”等字样。

### 3. 食用农产品合格证（产地证明）
- **承诺达标合格证**：由种植户或合作社开具，需注明品名、产地、生产者、开具日期，并承诺农残合规。
- **产地证明/检疫证明**：如来自专业种植基地，可要求提供县级农业农村部门的产地准出证明。

### 4. 内部质量控制文件
- **供应商自检记录**：其自有农残快检记录（如胶体金法、酶抑制法）的原始台账。
- **种植或供货批次记录**：包括农药使用记录（虽很难给全，但可要求其提供“用药合规承诺书”）。

### 5. 商品信息文件
- **商品条码/追溯码**：如有“农产品质量安全追溯标签”，应提供扫码信息。
- **物流运输/贮存温度记录**：防止运输中二次污染。

---

### 关键操作建议（防拒收）
1. **抽检频率**：与供应商签订合同时，明确约定“每批次交付前提供检测报告”，并规定**未提供报告可拒收或延迟付款**。
2. **现场验证**：收到报告后，**电话核实检测机构真伪**（或扫描报告上的二维码/编号），防止PS造假。
3. **留样对比**：抽检时保留同批次样品封存，若后续市场监管抽检不合格，可立即追溯供应商责任。

### 特别注意
- 如果是**进口水果**，还需额外索要《入境货物检验检疫证明》和海关通关单。
- 对于**高风险水果**（如草莓、樱桃、葡萄、芒果等），建议要求供应商增加“多菌灵”“吡虫啉”“高效氯氟氰菊酯”等特定项目的检测。

**一句话总结**：不给“当批次农残检测报告”的供应商，坚决不收货，这是最硬性指标。
