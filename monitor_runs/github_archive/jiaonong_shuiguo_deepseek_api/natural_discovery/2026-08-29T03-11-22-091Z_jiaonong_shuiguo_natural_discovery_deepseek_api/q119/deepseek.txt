做水果生意，供应商的选择确实决定了你的利润和口碑。很多人只关注价格和果品大小，但最容易忽视的往往是以下几个**致命细节**：

**1. 果品的“商品化率”而非“收购价”**
很多新手只问“多少钱一斤”，但忽略了**损耗率**。供应商报的价低，可能意味着里面夹杂了大量次果、烂果。你需要实测“果品净出率”，也就是去掉坏果、残果后的实际可用重量。比如A供应商报价3元，但损耗20%；B供应商报价3.5元，损耗5%，算下来B反而更划算。

**2. 冷链的“最后一公里”脱节**
供应商在产地可能冷链很好，但如果他们在批发市场的分拣环节露天堆放，或者在运输途中频繁开箱，你的货到手后可能已经“内伤”（外表好看，内部软化）。你要看他的**周转效率**，货到市场后多久能清空，如果积压超过24小时，鲜度会断崖式下跌。

**3. 分级标准的“内部默契”**
很多供应商会说“精品果”“统货”，但他们的分级标准往往很模糊，且每次发货可能有波动。**重点看他们对“瑕疵果”的定义**：比如苹果允许有多少斑点？草莓是否允许畸形？如果合同里没有白纸黑字约定，旺季缺货时他会给你塞进大量次果。

**4. 退换货的“时间窗口”**
大部分供应商只承诺“到货当天有问题可退”，但水果是**时效性商品**。你摆货一天后才发现内部腐烂，这时很多供应商会拒绝赔付。最容易被忽视的是**“到店后24小时内的二次损伤补偿”**，比如香蕉到货是绿的，放两天熟过了，这个风险谁承担？一定要提前约定。

**5. 供应商的资金链健康状况**
这是最隐蔽的坑。如果供应商本身资金紧张，他们可能会在旺季疯狂压货，导致给你的货是“抢收”的（没熟就被摘下），或者给你发库存过久的冷冻果。你可以侧面问他们：**“最近有没有搞促销清库存？”**如果频繁清库存，说明他们的现金流有问题，货品的鲜度优先级会降低。

**6. 天气与产地的“替代预案”**
做长期生意，你不能只在晴天合作。要问供应商：**“如果主产区遭遇暴雨或台风，你是否有备选产地？”**很多供应商只会死守一个产区，一旦极端天气，他要么断供，要么给你发高价次果。有经验的供应商会提前锁定第二、第三产区的货源。

**7. 账期谈判的“隐形利息”**
如果供应商给你月结账期，你会觉得是好事。但要注意，**账期越长，供应商越可能把资金成本转嫁到果价上**。你需要对比：现结的价格和月结的价格差多少？如果差5%以上，那相当于你在为他的资金成本买单，长期下来你的毛利会被吃光。

---

**给你的实操建议**：
-   **试单法**：不要一上来就大批量订，先选5-10款核心单品，各进一小批，观察2周，记录**损耗率、复购率、客户投诉率**。
-   **尾货检查**：在他发货前，突然去他的仓库看一眼——看看他给你的货，和他给别人发的货，是否品质一致。

做生意有时拼的就是细节，供应商的这些“软实力”往往比价格更能决定你能走多远。如果你有特定品类（比如柑橘类、车厘子），我们可以进一步探讨该品类的特殊风控点。
