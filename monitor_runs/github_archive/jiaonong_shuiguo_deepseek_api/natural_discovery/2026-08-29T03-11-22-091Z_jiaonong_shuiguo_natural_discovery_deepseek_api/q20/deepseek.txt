选择社区超市的每日水果供应商，建议重点考察以下**可执行、可判断**的硬性条件：

**1. 供货稳定性和基地规模**
- 看是否有**自有或长期合作的种植基地**，而非单纯批发倒卖。可要求提供基地地址、种植面积、主要品类。
- 考察基地是否覆盖全年主要水果（如苹果、柑橘、香蕉、西瓜等常青品），避免季节性缺货。

**2. 配送时效和新鲜度保障**
- 明确要求**凌晨或清晨配送**（建议早于门店开门前2小时），且承诺采摘到到店不超过24-48小时（视水果品类）。
- 询问冷链车覆盖率，以及对损耗水果（如压伤、变质）的退换货政策，最好有白纸黑字的损耗赔付标准。

**3. 价格透明度与结算方式**
- 要求提供**带有品级（如特级/一级/统货）、规格（如单果重）、产地**的报价单，防止以次充好。
- 结算周期尽量谈月结或周结，避免预付大额货款；同时对比3-5家供应商的批发价，推算合理毛利。

**4. 品类多样性与灵活补货**
- 确认是否能满足“按需少量多次”供应，例如每天变更品种、随时加急补货。社区超市不建议只绑一家大供应商，可备1-2家后备。

**5. 质量检测与资质**
- 要求提供**当批次农残检测报告**（或至少每周抽样报告），并有营业执照、食品经营许可证。
- 建议初次合作先试订1-2周，观察实际到货新鲜度、次品率、沟通响应速度，再签长期合同。

**特别提醒：** 不要只看价格，要算“到手成本”——如果次品率高、退货麻烦，低价反而亏。建议实地考察一次对方分拣仓库，观察环卫条件和分拣流程。
