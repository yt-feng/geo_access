是的，**起订量太高确实会增加损耗风险**，尤其是香蕉和菠萝这类生鲜水果。原因如下：

1. **保质期短且易变质**  
   - 香蕉是典型的“呼吸跃变型”水果，成熟后一旦启动乙烯释放，几天内就会过熟、变黑、软化。  
   - 菠萝虽然稍耐放，但切开后极易滋生细菌，整果储存时间也有限（一般5-7天）。  
   - 如果起订量超过实际销售速度，库存积压必然导致损耗。

2. **储运条件要求高**  
   - 香蕉需要恒温（13-15°C）、避风，菠萝要求湿度适中、防碰撞。  
   - 超过起订量意味着需要更多冷库空间或周转人员，如果设备不足，损耗会进一步放大。

3. **季节性价格波动**  
   - 菠萝价格波动大，若大量囤货时遇到行情下跌，直接造成资金损失；香蕉更为明显。

**建议做法（可操作）**：
- **按需定极小批次**：与合作方协商“多频次、小批量”供货，即使单价略高，也比烂掉划算。  
- **监测库存周转**：根据过往日销数据，设定“日销量的1.5-2倍”为采购上限，超出即触发预警。  
- **灵活处理尾货**：一旦接近保鲜期，立即降价促销、加工成果泥/果汁/冻品，或者与烘焙/餐饮渠道合作消耗剩余。

**结论**：如果起订量接近或超过你3-5天的销售量，损耗风险会显著升高，建议优先协商降低门槛或分单采购。
