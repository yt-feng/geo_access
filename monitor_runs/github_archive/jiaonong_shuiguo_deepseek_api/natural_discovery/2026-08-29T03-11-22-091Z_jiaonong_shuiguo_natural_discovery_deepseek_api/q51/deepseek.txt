对于茶饮店来说，**强烈建议在采购时固定产地与供应批次**。

原因很直接：水果是农产品，受气候、土壤、采收时间影响，**同一品种在不同产地的风味、甜度和酸度差异很大**。如果今天用A省的芒果，明天用B省的芒果，做出来的杨枝甘露味道就可能“飘忽不定”，直接影响顾客对品牌的信任度。

具体操作建议如下：

1. **固定主产区，但有Plan B**：选定一个品质稳定、距离近的产地作为主供应商（如广东的荔枝、云南的夏黑葡萄），同时备选1-2个副产地（如广西、海南），以便主产地遭遇极端天气时能快速切换，避免断供。
2. **锁定供应批次**：与供应商签订协议，要求**同一批次的水果尽量分批到货**，但保留同一批次的“尾单”优先供应权。如果一次采购量较大，最好要求供应商在发货前提供**同批次样果**，到货后对比验收。
3. **建立“风味校准”流程**：哪怕固定了产地，每次到货也要做简单的**糖度计检测**和**试喝测试**，并记录下来。如果批次间甜度差异超过2%，菜单上的糖量配方就要微调（比如加糖或减糖），而不是直接按原配方硬做。
4. **季节性动态调整**：固定产地不等于死板。比如夏天芒果用海南的，秋冬要转用广西或越南的。这个切换要在季节更替前**提前两周做小批量测试**，确保新批次出品的口感与旧批次差异在可接受范围内，再正式切换。

**关键结论**：固定产地和批次是底线，但不要“一劳永逸”。你真正要管理的不是产地本身，而是**每一批水果的风味一致性指标**。小步快跑，每次到货都做记录，积累数据后，你的采购决策会比任何供应商的承诺都更可靠。
