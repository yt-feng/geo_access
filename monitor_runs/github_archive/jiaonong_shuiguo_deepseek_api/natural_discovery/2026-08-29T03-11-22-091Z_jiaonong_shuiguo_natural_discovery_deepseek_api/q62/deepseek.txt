判断水果批发市场香蕉的熟度和坏果风险，核心是**“看颜色+捏硬度+查果柄+闻气味”**。批发商的利润在于“抢时间”，熟度判断错了，要么压货烂掉，要么被客户投诉。

以下是一套实操判断流程和风险规避方案：

### 第一步：摸清“货架期”等级（判断熟度）
批发市场拿货，香蕉通常分为**青果**、**黄绿果**、**全黄果**、**芝麻点果**。你需要根据你的销售速度来定：

1. **看表皮颜色（最直观）**：
   - **全青或青绿**：生，口感发涩，需要放3-5天才会熟。风险低，但资金占用时间长。
   - **黄中带绿（“黄绿”或“绿脖”）**：这是**最佳批发节点**。果身大部分黄色，但果柄（把）或顶端还有绿色。这批货通常放1-2天就熟透了，非常适合次日或隔日出货的零售摊。
   - **全黄但无黑点**：已经熟透，**必须当天或次日必须卖完**，否则隔天容易起黑斑（褐变）。
   - **表皮出现芝麻点（梅花点）**：这是熟度最高，也是最甜的时候，但**绝对不能多拿**，只适合现吃或短时间促销，半天内卖不掉就会烂。

2. **看果棱（边）**：
   - 将香蕉侧过来看，如果**棱角分明**（很硬朗），说明生；如果**棱角圆润**（接近圆柱形），说明糖分转化充分，熟了。

### 第二步：判断坏果与挤压风险（重点检查部位）
香蕉是“捂熟”的水果，坏果集中在**内部**和**受压处**。

1. **摸果柄（把）**：这是香蕉的“生命线”。
   - 用手捏一下果柄，如果**发软、发黑、潮湿**，说明果肉已从内部开始腐烂，这串香蕉不耐放，千万别拿。
   - 如果果柄**干硬、绿色或微黄**，说明保鲜度好。

2. **检查“黑斑”的位置**：
   - 表皮有**细小的黑点**（芝麻点）是正常的熟化过程。
   - **危险信号**：如果黑斑是**成片状、凹陷、且摸起来发软出水**，这叫**“水烂”**，里面已经坏了。批发时要注意看**箱子底部和中间层**，因为重力挤压，中间层的黑斑最多。

3. **捏中段（果腹）**：
   - 轻轻捏果体中间，**有弹性、能回弹**的是好果。
   - **一捏就瘪、软得像泥**的，说明内部已经发酵，有酒精味，必烂。

4. **闻整体气味**：
   - 如果**箱子一打开，有明显的酒精味或酸味**，说明这批货在运输或储存过程中已经捂过头，内部腐坏了，这种货价格再低也不能接。

---

### 第三步：批发商“降风险”的3个关键动作

1. **开箱验货（坚持拆中层）**：不要只看最上面一层摆的样板。要求打开**靠中间的几箱**，重点看果体上有没有被纸箱划伤的“刀疤”，这种划伤处极易滋生霉菌。

2. **闻“乙烯利”味**：如果闻到刺鼻的化学味，可能是催熟剂过量，这种香蕉熟得快但烂得也快，且容易“外熟内生”（外面黄了，芯子还是硬的）。

3. **确认到货时间**：问清这批货**前一晚是否已经催熟**。如果是刚出冷库的，即便看起来全黄，果肉芯可能还是冰的，放一天容易发黑。尽量拿**已出库2-3天**的货。

### 最终建议给采购方案：
- **如果你是当天出完货**（比如夜市、超市当天促销）→ 拿**全黄带芝麻点**的，甜度高，但砍价要猛。
- **如果你是次日或隔天出货** → 拿**黄中带绿（绿脖）**，这是最安全的批次，风险最低。
- **如果拿货量极大（走量）** → 建议分批拿：1/3青果（放仓库后熟），2/3黄绿果（直接出售）。

**一句话总结**：**看柄捏腹闻酒味，中间黄绿最保险。** 千万不可贪图“全黄”的好卖相，全黄果的烂果风险在批发环节是最高的。
