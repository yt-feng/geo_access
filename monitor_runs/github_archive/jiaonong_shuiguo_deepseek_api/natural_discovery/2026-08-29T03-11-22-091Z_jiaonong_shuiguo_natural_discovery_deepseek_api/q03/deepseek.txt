第一次做水果店，直接大批量进货风险很高。给你一套**低风险试单流程**，照着做基本不会亏太多：

**第一步：核心原则——每样只进“半箱”或“最小包装”**
- 香蕉：**不要进整把青的**，让供货商给你拿**已经转黄、但稍带绿蒂**的，最多进10-15斤。如果拿整箱（约25斤），新手大概率会催熟过度。
- 苹果：常见货利润薄，但损耗低。试单**就近拿一箱（约20斤）**，只挑一个最热卖的品种（如红富士），别进多种。
- 橙子：国产橙（如赣南脐橙）进**半筐（约30斤）**即可，进口橙（如新奇士）先别碰，价高且走量慢。

**第二步：主动要求“试吃果”**
跟供货商说：“我试单，每样给我留2-3个品相普通的‘试吃果’”，**这个钱要包含在货款里，但一定要拿**。原因：你第一次批，保不齐托盘的果子是上面大、下面小（埋雷），试吃果能帮你判断整体甜度。

**第三步：查“果柄”和“硬度”**
- **香蕉**：用手摸一下中间那段，如果发软但皮是青的，说明打过催熟药，**这单不要**。正常香蕉是皮黄、肉硬。
- **苹果**：看果柄是否翠绿，绿=新鲜，发黑=冷库货。**用手指轻掐果皮**，能掐出印子的太绵，太硬的带酸。
- **橙子**：拿一个**肚子（脐部）朝下**放桌上，能立住=皮厚老果，立不住一般皮薄水多（仅限国产脐橙）。

**第四步：谈账期和退换条款（最重要）**
第一次试单，付款前问清楚三句话：
1. “这批要是3天内有个别烂的，**可以拿来换**吗？”（能换的，说明是自家档口货；不能换的，多半是二道贩子）。
2. “**尾款能不能压一部分**？比如押200元，卖完这批马上结清。”（愿意压的，说明货品有信心）。
3. 主动要求加微信，**让他在包装箱上留电话**，下次补货直接打电话，省得你跑批发市场。

**第五步：试单后3天内必须做决定**
- 卖得动（日销超过半箱）：马上联系供货商，**锁定价格 + 加量但别加倍**（比如加50%）。
- 卖不动：优先检查是不是你定价高了，**别急着退货**，先降价促销或做成果切，**试单的目的就是允许犯错**，亏几十块无所谓，别亏几百。

最后一条**心法**：第一次试单，**宁可货不够卖，绝不多进货**。水果店死掉的原因十有八九是“压货”——你少进一点，哪怕明天缺货去市场补，也就多跑一趟而已。
