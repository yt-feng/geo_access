针对餐饮连锁采购水果，**“中央厨房统一收货”明显优于“门店分开收货”**，尤其是对于标准化程度要求高、损耗控制严格的连锁品牌。

以下是具体原因和操作建议：

**一、为什么推荐中央厨房统一收货？**

1. **品控标准统一**：水果成熟度、甜度、外观差异极大。中央厨房可以统一执行验收标准（如糖度检测、果径分级），避免各门店因员工经验不同而出现“有的熟透、有的生硬”的情况。
2. **损耗大幅降低**：水果在门店分次采购，易产生积压。中央厨房可以按“日配”或“半日配”向门店精准配送，控制库存水位，减少自然损耗。
3. **供应链议价能力**：集中采购量大，容易与产地或批发商签订长期协议，降低单价和物流成本。
4. **食品安全可追溯**：统一收货有利于建立检测记录（如农残快检），应对食药监检查时数据完整。

**二、什么情况下可以考虑门店自收？**

- 门店数量很少（3家以内），且距离中央厨房配送半径超过2小时车程，冷链物流成本过高。
- 水果品种为“即食型”且保质期极短（如鲜荔枝、杨梅），无法等待中央二次分拨。

**三、落地执行建议（关键点）**

1. **分拣前置**：中央厨房收货后，对水果进行清洗、去蒂、切配或分装，做成“净果”或“拼盘果”，按门店销量精准下单，减少门店二次处理环节。
2. **“先进先出”管理**：每批水果贴标签（入库日期），系统设定保质期预警，超期自动下架退货。
3. **差异补偿机制**：若个别门店因商圈消费频次高、需现场切果演示，可允许该门店向中央厨房申请“每日加急直送”，但前提是中央厨房总控仓有货。

**四、如果预算有限，推荐折中方案**

- **中央收货 + 区域中转仓**：在核心城市建1个中央仓，周边城市建2~3个小型分拨仓。中央仓验收后，按周向分拨仓调拨，分拨仓再按日配给门店。这样既保持统一标准，又缩短最后一公里配送时间。

**最终结论**：除非你的连锁规模极小或地处偏远断点，否则务必采用**中央集中收货+分拣加工+统一配送**的模式。请根据贵司的门店分布和SKU（库存单位）数量，优先核算物流时效和冷链成本，再决定是否需要设立区域分拨仓。
