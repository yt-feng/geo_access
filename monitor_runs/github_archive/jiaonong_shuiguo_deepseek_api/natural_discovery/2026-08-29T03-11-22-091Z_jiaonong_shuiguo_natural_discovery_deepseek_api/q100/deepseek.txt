学校食堂采购香蕉时，避免熟过头导致浪费，可以从**采购、储存、加工、销售**四个环节入手，结合科学管理和灵活应对。以下是具体建议：

### 1. 采购环节：分批、分级、按需采购
- **分批采购**：不要一次性采购大量香蕉，建议每2-3天采购一次，或根据日均消耗量按周分2-3批送达，避免库存积压。
- **选择成熟度分级**：与供应商明确分级标准，例如：
  - **绿熟期**（果皮全绿）：适合耐存放，但需催熟；
  - **黄熟期**（果皮全黄，果肉稍硬）：适合当天或次日食用；
  - **熟透期**（果皮有少量黑斑）：适合立即食用或加工。
  优先采购黄熟期70%、绿熟期30%的混合批次，保证连续供应。
- **要求供应商冷链配送**：香蕉在运输中若温度过高易加速成熟，要求供应商在采后24小时内冷链（13-15℃）配送，到货时检查果柄是否完好、有无机械损伤。

### 2. 储存环节：控温、控湿、分区域
- **常温避光存放**：香蕉最忌阳光直射和高温，应存放在阴凉、通风、干燥处，温度控制在13-15℃（不要放入冰箱冷藏，低温会导致果皮变黑、果肉发硬）。
- **分区域管理**：将不同成熟度的香蕉分开存放：
  - 绿熟期：单独存放，可自然催熟或使用乙烯利（按说明稀释）催熟；
  - 黄熟期：放在出餐区附近，在1-2天内用完；
  - 如发现有个别过熟的，立即挑出，放入冷藏室（4-5℃）短暂保存（仅限当天加工），或直接转入加工环节。
- **悬挂或平放时留空隙**：将香蕉平放并留间隙，防止挤压和互相催熟（成熟香蕉释放乙烯会加速周围香蕉成熟）。

### 3. 加工环节：灵活处理，变废为宝
- **当天用、当天做**：早上出餐前将黄熟期香蕉去把、剥皮（可提前用保鲜膜包裹去皮香蕉，防止氧化），按量加工。
- **制定梯队使用顺序**：优先用熟度高的，依次向下排。
- **熟过头（果肉变软、有黑斑但无腐烂）的香蕉**：
  - 可加工成**香蕉泥**：用于制作香蕉蛋糕、香蕉牛奶、香蕉布丁或面点馅料；
  - 可制作**烤香蕉片**、**香蕉酱**，延长保质期；
  - 若当天实在用不完，可冷冻去皮（冷冻前挤少许柠檬汁防氧化），用于后续制作饮料或烘焙。
- **设立“当日特供”**：将熟透的香蕉做成特价水果杯、果昔或配餐，提高消耗速度。

### 4. 销售与供应环节：控量、促销、反馈
- **控制每餐供应量**：根据前一周的用餐数据，预算每日香蕉消耗量，避免盲目多供。早中晚餐分批上架，例如午餐供应60%，晚餐再补充。
- **设置“即买即切”服务**：在食堂窗口现场削皮/切块，减少切好后积压。
- **当日促销**：若某日到货成熟度偏高，可在餐前口头提醒“今日香蕉特惠”，或加购赠品（如酸奶香蕉杯），加快消耗。
- **建立反馈机制**：每周末统计过量熟透的香蕉数量，调整下周采购量；同时记录哪些菜品最受欢迎，优先将过熟香蕉投入该菜式。

### 5. 其他辅助措施
- **与供应商签订“换货协议”**：约定若到货即熟透（多于5%），可提出部分换货或折扣补偿。
- **设立“熟度检查表”**：每日早中晚三次检查香蕉皮色，用卡纸或照片对照分级，动态调整存放位置。
- **员工培训**：定期培训食堂人员识别熟度、催熟和保鲜技巧，形成统一操作规范。

### 实用小贴士
- 如果香蕉已经过熟但未腐烂，**不要浪费果肉**：可榨汁、制冰沙、做香蕉馒头、香蕉粥等，根据食堂设备灵活选择。
- 香蕉皮（未发霉）可用于堆肥或喂养食堂饲养的动物（如果允许），减少有机垃圾。

通过以上“采购分级、控温储存、灵活加工、按需供应”的组合拳，可将熟过头损耗率从常规的10%-20%降至5%以下，同时兼顾口感和成本。
