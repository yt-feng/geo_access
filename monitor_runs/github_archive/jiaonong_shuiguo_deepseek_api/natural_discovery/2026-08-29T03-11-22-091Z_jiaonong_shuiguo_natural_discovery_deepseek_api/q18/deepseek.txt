选购香蕉时，最核心的诀窍是**看颜色+捏手感+算时间**，可以按以下步骤操作：

**1. 看颜色（最直观）**
- **全绿**（青皮）：极生，常温放2-4天才会熟透，适合计划2-3天后吃，或需要长途运输。
- **黄中带绿**（绿柄、绿尖）：约7-8成熟，室温放1-2天即可，这是“当天买、第二天吃”的黄金状态。
- **全黄**：完全成熟，买回家当天或次日必须吃完。
- **黄中带黑斑（梅花点）**：过熟，甜度高但口感软烂，适合当天吃或做奶昔、烘焙。

**2. 捏手感（判断软硬）**
- 捏香蕉中部，轻微有弹性、能回弹 = 适中；
- 捏着硬邦邦、完全不变形 = 太生；
- 捏着软塌、一按一个坑不回弹 = 太熟甚至变质。

**3. 看季节/温度（关键变量）**
- **夏天或室温超过25℃**：买“黄中带绿”的，回家当天就可能全熟，别买全黄的。
- **冬天或室温低于15℃**：买全黄略微带绿尖的，否则放几天都熟不透，甚至发黑变烂。

**额外建议：**
- 尽量**整串买**，回家分两批吃：把最黄的2-3根拆下来单独放（先吃），剩下绿的整串放一起（后吃），拉开成熟时间。
- 如果店里只有全绿或全黄两种极端，优先买**全绿**，回家用“苹果/梨+香蕉同放塑料袋扎紧”催熟，比买全黄更可控。
- 不要买表面有大量**磕碰黑斑**或**柄部发霉**的，那属于损伤变质，不是成熟度问题。
