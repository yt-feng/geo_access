第一次与水果供应商合作，采用小批量试单是非常正确的风险管理策略。设计试单的核心目的是：**验证供货稳定性、品质一致性、物流损耗率以及售后响应速度**，而不仅仅是买到便宜货。

以下是针对水果批发试单的实操设计方案，分为四个关键维度：

### 1. 品控标准前置（避免“货不对板”）
-   **明确规格书**：不能只写“苹果”，要写明品种（如红富士）、单果重（如80-85mm）、糖度（如≥13%）、瑕疵率（如磕碰伤不超过3%）、成熟度（如8-5分熟）。
-   **寄样确认**：在付款前，要求供应商寄送**实体样品**（非照片），并附带该批次的农药残留检测报告（或自费送检）。
-   **告知包装要求**：明确规定外箱材质（如五层瓦楞纸）、内衬（网套、格挡）以及单箱净重，这直接决定损耗率。

### 2. 试单量与品类策略（控制风险敞口）
-   **采购量设计**：总金额控制在**500-2000元**或**1-2个标准托盘**以内（视单品价格而定）。这个量级足以测试物流，又不会造成过大积压。
-   **品类选择**：优先测试**1个单品**（最好是当季硬通货，如柑橘类或苹果），不要混搭多个品类。因为不同水果的成熟度和保鲜要求不同，混试会干扰你对核心问题的判断。

### 3. 物流与到货验收（核心风险控制点）
-   **指定物流与时效**：明确约定“X日内必须到达”（如冷链车48小时），并在合同中写明**延迟到货的扣款比例**。
-   **到货开箱预案**：货到后，**不要直接入库**。必须当场随机抽取3-5箱进行“开箱核验”：
    -   **测重**：实际净重是否足斤。
    -   **测糖/测硬**：使用便携糖度计抽查。
    -   **挑损**：计算坏果、软果比例。**建议标准**：试单批次损耗率超过8%，可视为不合格，并要求对方补发或核减货款。

### 4. 结算与售后条款（测试合作诚意）
-   **对公账户结算**：首单坚决走公户，并要求提供发票（或收据），避免私账交易，为后续大额采购留底。
-   **售后兜底承诺**：在付款前，明确要求供应商书面（微信记录即可）承诺：“试单若出现品质不符，运费由供方承担，且全额退款或重发。”
-   **付款节点**：建议采用“**货到验收合格后24小时内结清**”的方式，而非预付全款。若对方坚持预付，建议控制在20%以内。

---

### 附加建议：试单后的评估表
试单结束后，不要只看“赚没赚钱”，请针对以下三个问题打分（满分10分）：
1.  **品质稳定性**（箱与箱之间差异是否大？）
2.  **沟通响应**（遇到问题是否推诿，还是积极解决？）
3.  **发货时效**（是否拖延？）

**如果总评分低于6分，建议果断放弃该供应商，不要因为价格便宜而“养虎为患”。**
