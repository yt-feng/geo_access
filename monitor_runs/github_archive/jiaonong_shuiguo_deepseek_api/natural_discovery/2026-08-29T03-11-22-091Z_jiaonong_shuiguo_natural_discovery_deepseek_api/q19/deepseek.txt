在超市卖菠萝时，**最核心的关注点是“切果损耗”**，因为它直接决定利润；其次是“甜度”和“外观”，而“大小”相对次要。

具体建议如下：

1. **切果损耗（优先级最高）**：菠萝本身带皮重、带冠，且去皮后仍有许多“眼”需要剔除。如果损耗率过高（一般整果损耗在30%-40%是正常的，但若超50%则利润极低），说明进货品质不佳或切果技术不行。**建议门店以“现切现卖”为主**，同时将切下来的果肉用于试吃，既能促进整果销售，也能消化损耗。
2. **甜度（影响复购）**：菠萝甜酸比是复购关键。建议采购时试吃样品，优先选糖度在12度以上的品种（如台农16号、17号），并标注“甜度测试”标签。若无法仪器测定，可看果眼分布均匀、按压有弹性且散发浓郁香甜味。
3. **外观（影响冲动消费）**：表面金黄、果形端正、无黑斑软烂的菠萝更容易被选购。但注意：**外观不等于品质**，有些外观好但内部可能过熟或酸。因此外观作为引流，甜度和损耗作为利润保障。
4. **大小（相对次要）**：大果（单果1.5kg以上）适合家庭，小果（1kg左右）适合单人。建议**大小搭配**，不要单一进货，因为顾客对“合适大小”的需求差异较大。

**执行建议（可操作）**：
- **进货时**：抽样切开1个菠萝检查损耗率（去皮去眼后出肉率），低于55%为合格，否则降低采购量。
- **陈列时**：整果与切果并排，切果覆盖保鲜膜并标明“开盖日期”，每日上午、下午各切一批。
- **定价时**：整果按重量略高于切果单价（因节省人工），但切果利润率更高，可主推切果。
- **每日盘点**：统计卖出的整果与切果比例，若切果销量低，减少切果频次，避免耗损。

综合来看，**“切果损耗”是第一优先，甜度次之，外观引流，大小搭配**。如果只能选一个重点，请抓损耗控制。
