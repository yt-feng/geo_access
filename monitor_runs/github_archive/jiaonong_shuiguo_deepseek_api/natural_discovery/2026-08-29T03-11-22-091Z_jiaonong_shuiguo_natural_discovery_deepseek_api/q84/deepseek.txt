针对家庭水果礼盒，建议以 **“耐放+均衡+色彩丰富”** 为原则，推荐以下几种组合方案：

**方案一：经典永不出错（推荐）**
- 组合：苹果 + 橙子 + 香蕉（各3-4个）
- 理由：苹果耐放、橙子维C高、香蕉孩子老人爱吃，覆盖全年龄。重点：**不要放菠萝**，菠萝熟得快，放一起会催熟其他水果，容易烂。

**方案二：颜值高、适合送礼或晒图**
- 组合：红苹果 + 橙子 + 菠萝（1个）+ 青提少量（或草莓，仅限当日组装）
- 理由：红黄绿撞色好看，但必须**当天团、当天送**，菠萝需要切好或提醒买家尽快吃。

**方案三：实用性价比家庭装**
- 组合：苹果 + 橙子 + 香蕉 + 小米蕉（或小台芒替代菠萝）
- 理由：去掉菠萝，因为菠萝皮厚占地方且不好分份，用香蕉类替代更实惠，小孩爱吃。

**避坑提醒：**
1. **菠萝不要和香蕉、苹果混放**，它释放乙烯会催熟加速变质，除非你承诺“上午团、当天达”。
2. 如果一定要加菠萝，建议**只放半个，并用保鲜膜包好切口**，提醒买家2天内吃完。
3. 家庭自吃建议“苹果+橙子”各半，再配一小把香蕉，总重控制在4-5斤，性价比最高。
