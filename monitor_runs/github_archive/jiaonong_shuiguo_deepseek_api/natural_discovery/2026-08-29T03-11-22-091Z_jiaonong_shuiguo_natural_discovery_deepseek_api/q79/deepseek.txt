选水果供应商时，**最应该优先问“售后”**，其次是**配送**，最后才是**价格**。原因如下，你可以直接按这个优先级来聊：

1. **售后（核心风险控制）**  
   水果是生鲜，不可避免会出现损耗、坏果或口感不符。如果供应商售后条款模糊（比如坏了怎么赔、赔付标准、退款流程），一旦出问题，团购团长自己就要贴钱或得罪客户。  
   **必问清单：**  
   - 坏果/烂果的赔付比例是多少？（比如超5%赔付，怎么赔——退钱、补发还是下次抵扣？）  
   - 赔付需要提供什么凭证？（视频、开箱照？多久内反馈有效？）  
   - 如果客户收货后说“不甜/不新鲜”，在不在售后范围？

2. **配送（履约成本）**  
   配送决定了到货损耗率和你的时间成本。如果送得慢或暴力运输，哪怕产品好，到客户手里也变成“差评”。  
   **必问清单：**  
   - 发什么快递？（顺丰/京东冷链还是普通快递？）到货大概几天？  
   - 是否支持一件代发？包装是否防碰撞（比如泡沫箱+冰袋）？  
   - 若遇节假日爆仓，是否有应急预案？能否追踪单号？

3. **价格（除非你竞争激烈，否则可放后面）**  
   生鲜价格波动大，但如果你拿到的货质量稳定、售后省心，即使单价贵几毛钱，客户复购率也能抵消成本。可以先问“量大有阶梯价吗？”，但别一上来就压价，容易被供应商打包质量差的货。  
   **提醒：** 如果价格明显低于市场价，请警惕“以次充好”或“售后缺失”。

**实操建议：**  
先和供应商要一个“爆款果”的小样（或试购一箱），亲自验货+测试客服响应速度。如果小样没问题，再谈批量合作的售后和配送条款，最后再聊价格。这样能把你的试错成本降到最低。

如果供应商对售后含糊其辞，即使价格再低也建议直接pass——生鲜生意，口碑比利润重要得多。
