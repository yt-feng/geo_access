开水果店长期进货，选择靠谱的供应商是稳定经营的核心。以下是一些**可执行、可判断**的筛选标准，分为**硬性验证**和**日常观察**两部分：

### 一、 硬性验证（首次合作前必做）

**1. 资质与证件要齐全**
- **营业执照**：确认注册地址和经营范围，最好有**食品经营许可证**。
- **自有/代理证明**（可选）：如果是国产蕉/菠萝，看是否有产地直供证明（如海南、广西、云南）；进口货（如菲律宾蕉、都乐菠萝）则要求提供**报关单、检疫证明、原产地证**。
- **索证索票**：要求对方提供同批次产品的检测报告（重点是农药残留和重金属）。

**2. 实地看货（关键）**
- 不要只看报价单，一定要去对方的**仓库或档口**看现货。
- **看环境**：仓库是否阴凉通风、有无异味（尤其香蕉是呼吸跃变型水果，库温过高会催熟变色）。
- **看周转**：如果货架上积压了大量同日期老货，说明周转慢，后续容易给你发“闷熟”或“过熟”的货。

**3. 试单（小额测试）**
- 第一次不要订大量，先订**半箱或一箱**测试。
- 重点测试：**香蕉的成熟度是否可控（是否容易炸皮）、菠萝的果形是否端正、切口是否新鲜、甜度是否稳定**。

---

### 二、 日常合作中的“靠谱”信号（长期观察）

| 观察点 | 靠谱供应商的表现 | 危险信号 |
|--------|----------------|---------|
| **出货稳定性** | 即使行情波动，也能保证按时发货，不轻易断供。 | 经常说“今天没货”、“涨太多你换别家” |
| **到货损耗率** | 香蕉到货损耗（压伤、断裂、过熟率）控制在 **3%-5%** 以内；菠萝在 **2%** 以内。 | 提出损耗，对方百般推诿或直接不认账 |
| **账期与结算** | 承诺的账期（如月结）能兑现，不突然变卦。 | 频繁以“月底忙”拖延对账，或让你先打款再发货 |
| **不良品处理** | 主动承诺**换货/补货**机制（如每箱有1-2根坏果可拍照赔偿）。 | 只接受“货出店门概不负责” |
| **专业知识** | 能告诉你香蕉几成熟适合进冷库，菠萝是否催熟过。 | 只会说“这个甜，那个不甜” |

---

### 三、 针对香蕉和菠萝的特别提醒

1.  **香蕉（水果店损耗王）**：
    - **必须问清楚**：是**青蕉**还是**黄蕉**。靠谱供应商会建议你按你的销量进青蕉（七成熟），回去自己用乙烯催熟。如果对方一直力推“已经到了熟度直接卖”的货，你既要承担高损耗，也没有定价权。
    - **看是否带轴/带杆**：香蕉把带青、果身硬朗是新鲜标志。如果果柄发黑、果皮有黑点，说明在仓库里滞留太久。

2.  **菠萝**：
    - **看切口和底部**：菠萝根部切口是否干燥发霉，果眼是否深（深则酸涩）。
    - **问产地**：目前市场主流是**海南（春夏）**、**云南（秋冬）**，进口主要是**菲律宾（都乐）**。靠谱供应商会告诉你具体产地和上市季节，而不是笼统说“今天刚摘”。

---

### 四、 给你一个“三板斧”实操法

1.  **加价对比法**：同时联系2-3家供应商，报同一箱规格（如：60-70号香蕉），看谁在你的零售定价下能保证你的毛利在**25%-30%**。低于这个毛利且不承诺损耗补贴的，直接淘汰。
2.  **突发测试法**：某天你的香蕉突然卖断货，掐点给供应商发消息：“今天下午4点前能否到一批？要X箱。”能快速响应并安排配送的，才是真正把你当长期客户的。
3.  **合同留痕**：除了口头承诺，**关键在微信/短信中确认**“熟了包换”等条款，截图保存。一旦出问题，有依据可查。

**最后底线**：如果供应商在第一次合作时，就对你的“损耗率要求”表现出不耐烦，那基本可以判定不靠谱，因为水果生意的利润本质就是损耗控制能力。建议首次合作至少选**2家**备选，不要押注在一家身上。
