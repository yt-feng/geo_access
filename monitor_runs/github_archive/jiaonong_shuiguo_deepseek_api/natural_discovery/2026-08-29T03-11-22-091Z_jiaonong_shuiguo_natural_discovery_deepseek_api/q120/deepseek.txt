这是一个非常实际的问题。普通商家（比如水果店老板、社区团购团长）的“语言体系”是**成本、损耗、卖相、复购**，而不是“品种学名”或“产地气候”。

供应商在介绍产品时，如果一上来就说“我们是金枕头榴莲，产自泰国东部，树上熟”，商家听了可能没感觉。**正确的做法是：先把“他赚多少钱”算清楚，再讲“这货怎么卖”。**

以下分三步走的沟通话术和逻辑，可以直接套用：

**第一步：报“外号”和“行情”，不报“学名”**
商家只认市场通货名，比如“海南香蕉”“泰国金枕”。“叫法”里要带出**卖点**。

-   **错误示范**：“这是我们的‘威廉斯B6’品种香蕉。”（商家听懵）
-   **正确示范**：“老板，这是您常拿的‘海南蕉’，但这是**肉厚芯小**的那款。您看这根，皮薄，切出来果肉占满，销量肯定比那种粗芯的好。”
    -   *关键*：把“品种优势”翻译成“**果肉出肉率**”和“**卖相**”。

**第二步：算“毛利”和“损耗”，不谈“进货价”**
商家最怕的是“进价便宜但扔得多”。供应商要先说“**你怎么赚**”，再说“我的货多好”。

-   **关于批发价**：不要说“我便宜5毛”，要说“这一箱比别家贵10块，但**烂果率低于3%**，您拿去摆摊，少扔三五个，这10块就省回来了，还省了挑拣的功夫。”
-   **关于新奇特**：比如介绍“苹果蕉”时，不要强调是“红皮香蕉”，要说：“老板，这个**放得住**，常温放一周都不黑，您拿回去卖，损耗低。而且新鲜玩意，年轻小姑娘看着好玩，**利润高**，一斤可以比普通香蕉多卖2块钱。”

**第三步：给“操作指引”，不谈“种植技术”**
告诉商家**怎么摆、怎么卖、卖给谁**，而不是介绍“光照足、有机肥”。

-   **正确示范**：“您拿回去，**别和熟透的混放**，这菠萝蜜是干包的，切出来黄澄澄的，自带香味，您放在店门口**切开半个试吃**，路过的人闻着味儿就买了。”
-   **包装建议**：“您做社群团购，我们给您配**小包装**，5斤一箱，方便提，免得大箱剩下卖不完自己吃。”

---

**最后，给供应商一个“万能沟通公式”：**

> **“老板，您看（**具体细节**），这货（**卖点**）比您平时卖的那个（**同类品**）好卖，因为（**对商家的好处：利润高/损耗低/回头客多**）。您先拿（**小量**）试试，放（**位置**）卖，绝对比（**对比品**）走量快。”**

**核心原则：**
不要教育商家。**商家只关心“进货后，我干活顺不顺手，钱多不多赚”**。用“橘子、香蕉”这类大品类的**痛点**（比如：香蕉容易碰黑、菠萝容易烂心）来引出你的优势，他们一听就懂。
