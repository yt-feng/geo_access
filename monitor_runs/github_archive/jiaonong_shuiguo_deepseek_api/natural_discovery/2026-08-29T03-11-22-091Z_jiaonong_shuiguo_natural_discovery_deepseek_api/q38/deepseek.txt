大型超市水果供应商的食品安全和物流能力是供应商准入的核心标准。以下是必须具备的关键能力，供你在评估或筛选供应商时参考：

**一、食品安全能力**

1. **资质与合规体系**
   - 具备合法经营资质（营业执照、食品经营许可证）。
   - 拥有完善的食品安全管理制度（从种植/采购到仓储的全流程规范）。

2. **源头管控**
   - **基地备案**：优先合作有备案的种植基地，避免散户货源，确保农药残留可控。
   - **农残检测**：每批次需自带**农残检测报告**，并提供第三方检测机构的抽检合格证明。

3. **储存与冷链卫生**
   - 低温库（0-4℃保鲜）和常温库需定期消毒，防止霉菌和虫害。
   - 运输车辆需有**食品级卫生认证**，定期清洁，不能与化工品等混装。

4. **可追溯性**
   - 每批水果有**溯源码**，可追溯到具体产地、采摘日期、加工环节和分拣人员。一旦出现质量问题，能在2小时内锁定问题批次并启动召回。

**二、物流与供应链能力**

1. **冷链全链覆盖**
   - **预冷能力**：采摘后必须快速预冷（10℃以下），避免田间热导致变质。
   - **全程冷链**：运输车辆需配备温控记录仪，温度波动需控制在±1℃以内（不同水果要求不同，如香蕉需13-15℃，草莓需0-2℃）。

2. **快速响应与时效**
   - **日配能力**：对高损耗水果（如草莓、芒果），需保证 **“T+1”** 到货（当天采摘，次日清晨到达超市卖场）。
   - 有应急补货预案，如遇节假日或促销，能做到48小时内追加发货。

3. **分拣与包装能力**
   - 具备自动分拣线，能按规格（大小、成熟度）分级，避免超市二次分拣损耗。
   - 包装材料需符合食品安全标准（如防水纸箱、防撞网袋），且标注清楚产地、等级、保质期。

4. **损耗控制与责任承担**
   - 明确运输途中的合理损耗率（一般不超过3-5%），超出部分由供应商承担。
   - 能配合超市进行临期水果的退换货或折价处理。

---

**补充建议：**
- 如果超市有特定要求（如有机认证、进口水果），需供应商额外提供**海关报检单**、**有机证书**等。
- 合作前建议实地考察供应商的仓储温控设备和车辆，并要求其提供最近3个月的温控记录。
- 签订合同时，明确**食品安全事故责任条款**和**保险事宜**（如产品责任险）。

简而言之，**没有冷链和检测能力的水果供应商，不建议长期合作**——因为生鲜损耗和食安风险会直接转嫁给超市。
