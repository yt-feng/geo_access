经营便利店卖菠萝切块，需要同时关注**保质期**、**包装**和**配送频次**，但这三者的优先级和具体做法不同。核心原则是**“以销定产、短保速销”**。

以下是针对便利店的实操建议，按重要性和操作逻辑排序：

**1. 保质期（最核心，决定风险）**
- **设定硬性报废时间**：菠萝切块属于高水分、高糖水果，极易变质。建议**冷藏（0-4℃）条件下，售卖期不超过24小时**，最佳品质期仅12小时。必须贴标签注明“制作时间”和“到期时间”。
- **建议分级处理**：
    - **当天制作**：只做当天需货量，下午4点前卖不完的，一律报废或打折处理（如第二份半价），绝不过夜。
    - **感官检查**：即使未到期，若出现出水、软化、有酒味，必须立即下架。

**2. 包装（直接影响卖相和损耗）**
- **材质**：选择**PET透明防雾盒**（聚对苯二甲酸乙二醇酯），既能看清果肉，又能防止冷藏时起雾。盖子上必须有透气孔或采用微孔膜，否则容易闷出水。
- **规格**：建议一次性份量控制在**150g-200g**，单价在5-10元区间，方便顾客当零食即买即走，减少因吃不完导致的浪费。
- **防氧化**：切好后可浸泡淡盐水或喷少量维生素C水，沥干后装盒，减少果肉褐变。
- **标签**：盒子上必须贴有**生产日期/时间**和**保质期至几点**，这是便利店信任的基础。

**3. 配送频次（解决“新鲜”与“库存”的矛盾）**
- **原则**：配送频次要匹配**门店当日销量**，而不是固定按天配送。
- **推荐模式**：
    - **高销量门店（日均售出 > 20盒）**：实行**“一日两配”**（上午10点前、下午3点后），且下午配送量要少于上午，以保证晚餐前货架上的货是新鲜的。
    - **一般销量门店**：实行**“一日一配”**，且将配送时间定为**上午早高峰后（约9-10点）**，避免下午高温时段配送。
- **关键动作**：配送车辆必须**全程冷链（2-6℃）**，运到门店后需测量表面温度，温度高于8℃的拒收。

**4. 三个环节的联动建议（优先级排序）**
- **店长每日必做**：早会时根据天气预报和昨日销量，下达“今日菠萝切块预估单”。这个预估量的准确度，比配送频次本身更重要。
- **最佳操作顺序**：先确定**保质期**（24小时硬规矩） → 再控制**包装**（小份防雾盒） → 最后和总部/供应商谈**按需配送**（宁可多配几次，不要一次给足一天的量）。
- **特殊提醒**：如果便利店本身有鲜食区域，可以将菠萝切块视为“短保鲜食”，自动进入当日损耗核算系统，这样对利润最安全。

**总结一句话**：**优先做好“24小时保质期”的强制报废制度，其次用“小份防雾包装”控制单次损耗，最后再根据实际销量调整“一日一配或两配”的频次。** 如果三者必须取舍，保质期管理永远是第一位的。
