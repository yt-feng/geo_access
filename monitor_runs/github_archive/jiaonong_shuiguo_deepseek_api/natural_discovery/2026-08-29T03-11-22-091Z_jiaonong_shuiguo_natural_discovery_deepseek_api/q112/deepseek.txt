在水果采购合同中，**坏果率（或称损耗率）的具体赔付标准并没有法律强制统一比例**，主要取决于买卖双方的约定，但实践中存在一些常见行业惯例和风险提示：

**1. 常见行业约定区间：**
- **一般水果（如苹果、梨、柑橘）：** 通常约定 **2% - 5%** 以内为正常损耗，双方互不担责；超过该比例（如超过5%）部分，应由卖方承担赔偿责任。
- **易腐水果（如草莓、荔枝、樱桃、蓝莓）：** 由于生鲜特性，坏果率标准会放宽，常见约定为 **5% - 8%**，甚至个别品类允许 **10%** 以内。
- **具体赔付方式：** 常见为“按坏果部分重量折价扣款”，或“坏果部分直接退货退款”，也有按整批总价的百分比进行违约金补偿。

**2. 如果合同没有明确约定：**
- 根据《民法典》关于合同履行的原则，卖方应当交付符合质量标准的货物。如果到货后坏果率明显超出**正常合理范围**（司法实践中一般掌握在5%以上视为明显不合理），你可以主张卖方违约，要求相应扣款或退货。
- **操作建议：** 无论合同怎么约定，收货时务必**当场开箱抽检**，拍视频存证，并保留运输单据。最好在合同中写明“如坏果率超过X%，甲方有权按每斤Y元扣款，或拒收”。

**3. 风险提醒：**
- 如果合同已明确写了“坏果率不超过10%视为合格”且你已签字接受，那么即使超过5%，你也难以索赔，除非能证明对方欺诈。
- 运输途中造成的挤压、腐烂可能属于物流风险，需看合同约定由谁承担（一般买方承担运输风险，除非是卖方送货上门）。

**建议操作：**
在签署合同前，直接和对方谈判并白纸黑字写明：“**到货后抽样检验，坏果率超过 5% 的部分，按同规格市场价扣除货款；超过 10% 时，买方有权整批拒收并要求退还已付货款**”。——这是对买方最稳妥的做法。
