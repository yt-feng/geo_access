甜品店采购香蕉，要避免到店后很快变黑，关键在于**采购源头**和**到店后的储存**两个环节。仅靠到店后的处理，效果有限。

以下是具体、可执行的操作建议：

### 一、 采购源头的把关（最优先）
1.  **选择“绿熟期”香蕉**：不要买全黄或带黑点的香蕉。应采购**果皮整体呈绿色，或仅有少量黄绿色**的香蕉。这个阶段的香蕉在常温下还有3-5天的后熟期，能保证到店后的售卖/使用时间窗口。
2.  **避开雨季/成熟度高的批次**：夏季高温或连续阴雨天时，香蕉成熟极快。如果当天必须用香蕉泥，可以买熟透的；如果计划储存2-3天，坚决买偏生的。
3.  **检查果柄**：果柄新鲜、切口湿润的香蕉更耐放；果柄发黑干枯的已开始老化。

### 二、 到店后的储存与摆放（关键）
1.  **悬挂放置**：最有效的方法。如果条件允许，用挂钩将香蕉**悬挂**起来，模拟其在树上的状态。这能减少果皮因重力压迫产生的压痕，显著延缓变黑。
2.  **不要洗，保持干燥**：到店后**绝对不要用水冲洗**。表面的水分会加速微生物繁殖和黑斑产生。
3.  **乙烯“隔离”**：香蕉会释放乙烯气体催熟自己和其他水果。将香蕉**单独存放**，不要和苹果、梨、芒果、牛油果放在同一个箱子里，否则会迅速催熟。
4.  **包裹果柄**：用保鲜膜或锡纸**紧紧包裹住香蕉的果柄（把儿）**。这是乙烯释放最集中的位置，包住能大幅减少自身催熟气体扩散。

### 三、 应急处理方案
- **如果必须裸露在常温柜台**：用纸张包裹香蕉，避免光照（光线会升温加速成熟）。
- **冰箱冷藏（仅限完全成熟后）**：
    - 如果香蕉已经达到你需要的熟度，请**立刻放冰箱冷藏室**。香蕉皮在低温下会变黑，但**果肉内部会保持硬挺且甜味不变**，可持续保存3-5天。
    - 注意：**生香蕉绝对不能放冰箱**，会停止后熟，口感发涩且无法挽救。

### 四、 甜品店的实用降损技巧
1.  **按需采购、少量多次**：如果用量不大，建议每日或隔日小批量采购绿色香蕉，不要一次囤积一周的量。
2.  **优先使用“将熟”香蕉**：将刚到店的偏生香蕉摆放在后厨区域（阴凉通风处），将已成熟的香蕉优先用于制作香蕉奶昔、香蕉泥或蛋糕，因为这类产品对果皮卖相无要求。

**总结口诀**：**买绿的、包果柄、挂起来、别碰水、避阳光。** 做到这五点，香蕉在常温下可维持2-3天不变黑。
