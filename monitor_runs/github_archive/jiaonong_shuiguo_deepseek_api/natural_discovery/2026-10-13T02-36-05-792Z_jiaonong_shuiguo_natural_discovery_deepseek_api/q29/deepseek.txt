超市和水果供应商的账期没有统一标准，但可以按渠道类型和水果品类给一个大致区间。

**常见账期区间**

- **7～15天**：多见于区域中小超市、生鲜专营店、社区团购，尤其是叶菜、浆果、鲜切水果等易损耗品类，供应商议价能力弱、周转要求高时常见。
- **15～30天**：比较主流的区间，很多连锁超市、地方商超对常规水果供应商采用这一档。
- **30～45天**：大型连锁超市、全国性商超比较常见，供应商规模较大、合作稳定时可能出现。
- **45～60天甚至更长**：多见于强势大型零售渠道对中小供应商，水果这类高损耗品类中相对少见，供应商通常会用价格或供货条件来平衡。

**影响账期的关键因素**

1. **品类损耗速度**：越易坏（草莓、荔枝、叶菜），账期越短，否则供应商资金和损耗压力大。
2. **超市规模与话语权**：连锁越大、越强势，账期往往越长。
3. **供应商规模**：大供应商能承受更长账期，小供应商通常要求现结或短账期。
4. **合作阶段**：新供应商常被要求较短账期或现结，稳定合作后可能延长。
5. **结算方式**：账期之外还要看是否有“账期+月结”“账期+承兑”等附加条件。

**实操建议**

- 谈判时先明确：账期起算日（送货日、对账日还是开票日）、对账周期、付款方式。
- 水果类建议控制在**15～30天**较平衡；易损耗品类尽量压到**7～15天**。
- 如果超市要求30天以上，可以争取：缩短对账周期、部分现结、提高采购价或降低损耗分担。
- 把账期和价格、退货率、损耗承担捆绑谈，比单纯争几天更有效。
