社区超市卖小包装香蕉，核心不是“怎么包得好看”，而是**采购时就按小包装的周转和损耗逻辑去选货、定规格、控成熟度**。可以从下面几块注意：

1. **选规格：按“一次吃完”定单包重量**
   - 常见小包装：2–3根/包、4–5根/包、500g左右/包。社区店更建议做 **2–3根或350–500g**，适合单人、小家庭。
   - 采购时要求供应商按小包装需求分拣，不要拿大把蕉自己硬拆。硬拆容易伤果柄、破皮，后续黑斑和腐烂会加快。
   - 如果自己做包装，采购时优先选**条蕉均匀、果指大小一致**的货，这样每包重量稳定，顾客复购时预期一致。

2. **控成熟度：别采太熟，给货架期留时间**
   - 小包装香蕉在货架上通常要放1–3天，采购成熟度建议控制在 **3–4号色**（偏青黄、刚转黄），到店后自然转黄。
   - 如果采5–6号色（已经很黄、带糖斑），当天卖不完损耗会明显上升。
   - 夏天、社区店客流慢时，成熟度要再低一点；冬天可略高一点。
   - 采购时要问清供应商：这批货是催熟到什么程度、还能放几天。不要只听“今天刚到的”。

3. **包装方式：透气、防压、防催熟集中**
   - 不要用完全密封的塑料袋长期包，香蕉会释放乙烯，闷着容易加速成熟和发黑。优先用**带透气孔的保鲜袋、网套+托盘、透气膜**。
   - 小包装最好有**托盘或底托**，避免香蕉被压伤。尤其是2–3根一包，果柄朝下或侧放容易折断。
   - 标签不要直接贴在香蕉皮上，贴包装膜或托盘上。撕标签容易破皮。
   - 如果做组合包，避免和苹果、梨、番茄等乙烯释放量大的果蔬混放。

4. **采购批次：少量多次，比一次囤货更重要**
   - 小包装本身毛利有限，损耗一高就吃掉利润。建议 **小批量、高频补货**，比如每天或隔天补一次，而不是一周采一次。
   - 采购量按“日销量 × 1.5天”估算，先试销一周再调。社区店客流不稳定，宁可缺货也别大量压货。
   - 如果供应商支持拆箱混装，优先按小包装规格拿货，减少门店二次分拣。

5. **运输和到店验收：重点看压伤、果柄、温度**
   - 运输中避免挤压、暴晒、闷热。香蕉怕压、怕冻、怕高温。
   - 到店验收重点看：
     - 果柄是否完整，有没有断裂、发黑；
     - 果皮有没有压痕、划伤、水烂；
     - 有没有已经软塌、渗汁的；
     - 箱内温度是否过高，有没有闷出酒味。
   - 有伤的香蕉不要硬做小包装，可以挑出来做特价散卖或当天处理，否则会传染其他蕉。

6. **陈列和日常管理：减少人为损耗**
   - 小包装不要堆叠太高，2–3层以内，避免下层压伤。
   - 放在阴凉通风处，避免阳光直射和靠近热源。
   - 每天挑一次：把开始出糖斑、变软的先挑出来做“今日特价”或试吃，不要等全黑再处理。
   - 如果门店有冷柜，香蕉一般不建议低温冷藏，容易冻伤变黑；常温阴凉更合适。

7. **和供应商谈条件：把损耗责任前移**
   - 谈清楚：到货成熟度、单包规格、允许的压伤比例、破损退换规则。
   - 如果供应商能按小包装直供，优先直供，门店只做贴标和陈列，减少拆包损耗。
   - 争取“到货24小时内坏果可换”或“按比例补损”，尤其是夏天。

简单判断标准：**采购时选偏青黄、果指均匀、果柄完整、能放2–3天的货；包装用透气+托盘；门店少量多次补货，每天挑软的先卖。** 这样小包装香蕉的损耗通常比大把散卖更可控。
