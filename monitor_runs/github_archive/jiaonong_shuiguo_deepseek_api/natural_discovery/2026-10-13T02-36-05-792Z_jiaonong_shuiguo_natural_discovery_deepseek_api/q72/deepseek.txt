做水果批发的大客户，账期和额度谈判的核心是**把“赊销”当成一笔有价贷款来定价**，而不是单纯让步。水果有损耗高、价格波动大、回款慢的特点，所以谈法要围绕“风险可控 + 长期绑定”来设计。

**一、先给自己算清底线，再上桌**

1. **算资金成本**：你赊出去的钱，要么是自有资金（机会成本），要么是贷款/占用供应商货款（实际利息）。比如月息0.8%，30天账期就相当于让利约0.8%。
2. **算单客户安全额度**：可用公式  
   `可授信额度 ≈ 该客户月均采购额 × 账期月数 × 安全系数`  
   安全系数通常取0.3–0.5，首次合作更要低。
3. **算毛利承载力**：如果一单毛利只有5%，给30天账期基本白干。**账期越长，报价里越要包含资金成本**。

**二、账期怎么谈：分层递进，不一步到位**

- **首单**：现款现货，或最多7天账期。用“首次合作风控”当理由，客户一般能接受。
- **稳定合作1–3个月后**：给15天账期，同时要求月采购额达到约定门槛。
- **成为核心大客户后**：给30天账期，但要绑定年度采购量或月度最低采购额。
- **更长期限（45–60天）**：只给战略客户，且必须配合担保、保证金或价格上浮。

关键话术：  
“账期不是不能给，是和采购量、结算稳定性挂钩。您月采购稳定到X万，我给您30天；达不到就回到15天，这样对双方都公平。”

**三、额度怎么谈：动态授信，不是固定数字**

- **初始额度**：按客户月均采购额的30%–50%给，比如月采购10万，先给3–5万额度。
- **额度调整**：连续3个月按时回款、采购量达标，额度可上调20%–50%。
- **超额处理**：超出额度部分必须现款，或单独审批。
- **设置熔断**：逾期超过约定天数（如7天），立即停止发货并降额。

**四、必须写进合同的风控条款**

1. **账期起算日**：明确是发货日、到货日还是对账确认日，避免扯皮。
2. **逾期罚息**：比如日息0.05%–0.1%，或按未付款金额收取违约金。
3. **停货权**：逾期即可暂停供货，且不承担违约责任。
4. **价格调整权**：账期客户报价可比现款客户高1%–3%，覆盖资金成本。
5. **担保措施**：大额授信可要求法定代表人个人担保、保证金或房产抵押。
6. **对账机制**：每月固定对账日，双方签字确认，避免“糊涂账”。

**五、谈判中的实用策略**

- **用现款价换账期**：报两个价，现款价低，账期价高，让客户自己选。
- **用账期换采购量**：给账期可以，但要求月度最低采购额和年度增量承诺。
- **用额度换回款速度**：额度给足，但要求周结或半月结，比月结更安全。
- **分批放账**：先给小额短期，跑通回款再放大，别一上来就给大额度长账期。
- **保留退出机制**：合作条款里写明，连续2次逾期可单方面终止授信。

**六、一句话总结**

水果供应商谈账期和额度，本质是：**用采购量和回款稳定性换授信，用授信换长期绑定；额度从小到动态放大，账期从短到长阶梯释放，价格里始终包含资金成本。** 先保命，再做大。
