批发档口降低退货纠纷，收货验货的核心不是“走形式看一眼”，而是把**责任边界在收货当场固定下来**。建议按下面做：

## 一、收货前先定规则

1. **合同/订单写明验收标准**
   - 品类、规格、数量、颜色、等级、允许误差
   - 破损率、短装率、色差、次品处理方式
   - 验收期限：比如“签收后24小时内反馈，超时视为验收合格”
   - 退货条件：只退严重质量问题，还是包退换

2. **要求供货方随货带单据**
   - 送货单、装箱单、批号、质检报告（如适用）
   - 单据上写清数量、规格、批次，方便对账和追责

## 二、收货时必须做的验货动作

### 1. 先点数量，再查质量
- 当面点清箱数、件数、包数
- 随机开箱抽检，不要只点外箱
- 大批量按比例抽检，异常批次扩大抽检

### 2. 重点查这几类问题
- **短装**：数量少、箱内少件
- **破损**：外包装破损、内物压坏、渗漏
- **错发**：颜色、尺码、型号、规格不对
- **质量问题**：污渍、线头、开胶、变形、异味、功能不良
- **批次不一致**：同一单里混批、混色、混版本

### 3. 全程留证
- 拍送货单、外包装、开箱过程、问题部位
- 视频要连续，能看出是同一批货
- 问题货单独堆放，贴标签，不要混入正常库存

### 4. 当场确认，不要拖
- 有问题当场在送货单上备注
- 让送货人签字确认，或拍照发对方业务/客服确认
- 能拒收的问题货直接拒收，别先收下再扯皮

## 三、把验收结果写成书面记录

建议用一张简单的《收货验收单》，至少包括：

- 到货日期、单号、供货方
- 品种、规格、应收数量、实收数量
- 抽检数量、问题数量、问题描述
- 处理方式：合格入库 / 拒收 / 换货 / 折价 / 待确认
- 送货人签字、验货人签字、拍照编号

这张单子就是以后处理退货纠纷的证据。

## 四、内部流程要卡死

1. **专人验货**
   - 不要谁有空谁收，固定人负责，责任清楚

2. **先验后入库**
   - 未验收的货不进正常库存，避免混货后说不清

3. **问题货隔离**
   - 设“待处理区”，避免被误卖后产生二次纠纷

4. **限时反馈**
   - 比如24小时内反馈供货方，超时风险自己承担

5. **退货也要验**
   - 客户退回来的货，同样当场验、拍照、登记，防止掉包或损坏责任不清

## 五、和供货方约定清楚这几条

- 短装怎么补
- 破损怎么赔
- 错发谁承担运费
- 质量问题退货期限
- 超过验收期还能不能退
- 退货地址、联系人、运费承担方

最好写进订单或对账单，不要只靠口头。

## 六、最实用的执行版

收货时按这个顺序做：

1. 对单：单号、品种、数量  
2. 看外箱：破损、受潮、封口异常  
3. 抽开箱：数量、规格、颜色、质量  
4. 拍视频：开箱到问题部位  
5. 记问题：在送货单上备注  
6. 要签字：送货人或供货方确认  
7. 分开放：问题货隔离  
8. 限时报：当天或24小时内反馈  
9. 留档案：验收单、照片、聊天记录归档  

一句话：**数量当面点，质量抽检看，问题当场记，责任当场定，证据全程留。** 这样退货纠纷会明显减少。
