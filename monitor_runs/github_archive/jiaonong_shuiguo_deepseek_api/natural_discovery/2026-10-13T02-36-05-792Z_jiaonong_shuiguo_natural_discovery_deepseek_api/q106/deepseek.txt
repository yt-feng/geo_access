判断水果报价波动是否合理，核心不是看“涨了还是跌了”，而是看**波动是否有可解释的市场驱动**，以及**波动幅度是否落在该品类的正常区间内**。可以按下面几步操作。

## 1. 先建立“基准价”而不是只看当天报价

每天变价本身正常，关键是和什么比。

采购方应维护每个单品的历史价格锚点：
- 近7天均价
- 近30天均价
- 去年同期价
- 当前产季的正常区间

判断逻辑：
- 当天价在近30天均价的 ±10% 内，通常属于正常波动。
- 连续3天单边上涨或下跌超过15%，需要供应商给出原因。
- 明显偏离去年同期且无天气、产地、节日因素，属于异常。

注意：不同品类波动率差异很大。叶菜、浆果类波动大；苹果、土豆等耐储品类波动小。不能用一个标准套所有水果。

## 2. 看波动是否有对应的市场信号

合理波动通常能被外部因素解释：

| 因素 | 合理表现 |
|---|---|
| 产地天气 | 暴雨、寒潮、台风导致减产，价格上行 |
| 换季/断档 | 老产区结束、新产区未大量上市，短期上涨 |
| 节日备货 | 春节、中秋前需求上升，价格上行 |
| 集中上市 | 应季大量到货，价格下行 |
| 物流成本 | 油价、运费、停运导致成本变化 |
| 汇率/进口 | 进口水果受汇率和通关影响 |

如果供应商说“今天涨了”，但市场上没有天气、产地、节日、物流等对应信号，就要警惕。

## 3. 用“多源比价”验证，而不是只听一家

至少拿3个来源交叉验证：
- 当地批发市场当日行情
- 2-3家同类供应商报价
- 行业价格平台或产地代办报价
- 自己的历史采购价

判断方法：
- 多家同步涨跌，幅度接近 → 大概率是市场行为。
- 只有一家涨，别人没动 → 更可能是该供应商自身问题。
- 报价涨但品质等级、规格、包装没同步说明 → 可能借机调价。

比价时必须统一口径：品种、等级、规格、包装、是否含税含运、账期。

## 4. 区分“价格波动”和“报价结构变化”

有些涨价不是单价涨，而是：
- 规格变小
- 等级降低
- 包装从净重变毛重
- 运费、损耗另算
- 账期缩短

这些都会让实际采购成本上升。采购方要算**到岸综合成本**，而不是只看报价单上的单价。

## 5. 设定异常波动处理机制

建议直接写成规则：

1. 单日涨跌超过10%：供应商需当日书面说明原因。
2. 连续3天同方向波动超过15%：启动备选供应商询价。
3. 报价高于市场均价10%以上：要求重新议价或切换货源。
4. 报价低于市场均价20%以上：警惕品质、斤两、账期或后续涨价陷阱。
5. 每月复盘：对比各供应商报价与市场基准的偏离度。

## 6. 最实用的判断口诀

**有外部原因、多家同步、幅度在历史区间内 → 合理波动。**
**无原因、只有一家动、幅度异常、规格悄悄变 → 不合理，要查。**
