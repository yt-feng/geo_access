生鲜平台做一件代发水果，供应商的仓配能力不是“能发货”就行，核心要能扛住**水果易损、时效敏感、SKU波动大、售后率高**这四个特点。建议重点看以下几类能力：

**1. 仓储能力**
- **温区匹配**：不同水果要求不同。比如荔枝、杨梅需要冷链或冰袋保温；苹果、橙子可常温；香蕉、芒果对温度敏感，不能简单混放。供应商至少要能区分常温、冷藏、保温发货。
- **分区与防压**：水果怕压、怕闷、怕催熟。仓库要有独立拣货区、打包区，重货和易损果分开，不能和异味商品混存。
- **库存准确率**：一件代发最怕超卖。供应商需要WMS或至少ERP库存同步，能按平台订单实时锁库存，日清日结。
- **批次管理**：能按采摘/入库批次先进先出，避免老果新果混发，尤其是浆果、桃李类。

**2. 加工与打包能力**
- **分级筛选**：能按平台标准做果径、糖度、成熟度、外观分级，而不是统货直发。
- **预冷能力**：采摘后快速预冷，是延长货架期、降低损耗的关键，尤其对樱桃、蓝莓、荔枝。
- **专业包材**：单果网套、珍珠棉、吸水纸、冰袋、泡沫箱、透气孔纸箱等要配套。不同品类包材方案不能一刀切。
- **打包时效**：订单生成后能在约定时间内完成拣货、打包、交运。大促期间要有临时工和备用产线。

**3. 配送与时效能力**
- **快递资源**：至少对接2-3家快递，能根据目的地、品类、成本切换。偏远地区要明确是否发货、加收多少。
- **冷链/保温链路**：需要冷链的品类，要能提供冷链快递、干冰/冰袋方案，并控制中转时间。
- **时效承诺**：能按区域给出可兑现的时效，比如江浙沪次日达、华北48小时。不能承诺了却发普通快递。
- **异常处理**：爆单、天气、疫情、快递停发时，要有备用线路和主动通知机制。

**4. 售后与逆向能力**
- **坏果包赔规则**：能接受平台售后标准，比如坏果率超过多少全赔或按比例赔。
- **补发/退款响应**：能在约定时间内处理，不需要平台反复催。
- **逆向物流**：水果一般不退货，但要有凭证审核、拍照定损、补发流程。
- **数据复盘**：能按SKU、区域、快递统计坏果率、时效达成率，持续优化。

**5. 系统与协同能力**
- **订单对接**：能通过API或ERP对接平台订单，支持自动抓单、打单、回传单号。
- **库存同步**：多平台卖货时，库存要实时同步，避免超卖。
- **对账能力**：运费、包材、赔付、结算周期清晰，能按单对账。
- **客服接口**：有专人对接平台客服，处理异常订单。

**6. 资质与合规**
- 营业执照、食品经营许可证或食用农产品相关资质。
- 产地证明、检测报告，尤其是农残、重金属等平台可能抽检的项目。
- 包装标签合规，包括品名、产地、等级、净含量、保存方式、发货方信息。

**判断供应商是否合格，可以重点问这几个问题：**
1. 你们发荔枝/蓝莓/水蜜桃分别用什么包材和温层？
2. 订单几点前截单，几点交快递？大促日产能多少？
3. 坏果率目前多少？售后怎么赔？多久响应？
4. 哪些地区不发货或加运费？冷链覆盖哪些城市？
5. 能不能API对接，库存多久同步一次？
6. 有没有预冷设备？还是采摘后直接打包？

**简单结论：**
一件代发水果，供应商至少要具备：**分温仓储 + 预冷分级 + 专业包材 + 稳定快递/冷链 + 实时库存系统 + 坏果赔付能力**。如果只具备“有货、能发快递”，通常做不大，售后和损耗会把平台利润吃掉。
