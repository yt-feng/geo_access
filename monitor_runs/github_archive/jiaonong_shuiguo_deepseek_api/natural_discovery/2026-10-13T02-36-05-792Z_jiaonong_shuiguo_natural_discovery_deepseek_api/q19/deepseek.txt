如果只能排一个优先级：**先看切果损耗，再看甜度，然后大小，最后才是外观。**

原因是超市卖菠萝和水果摊、电商不一样，核心是**周转 + 损耗 + 客诉**，不是单看“好不好看”。

具体可以这样判断：

1. **切果损耗优先**
   - 菠萝最容易亏在：熟过头、黑心、水心、内部褐变、切出来废果多。
   - 外表再漂亮，如果切开损耗高，毛利直接被吃掉。
   - 超市如果有现切果切、拼盘、菠萝杯，损耗权重还要再提高。

2. **甜度第二**
   - 甜度决定复购和客诉。
   - 太酸、没味，顾客买一次就不买了；太熟虽然甜，但货架期短、切果损耗大。
   - 实操上要平衡：**不是越甜越好，而是要“甜度稳定 + 还能放”**。

3. **大小第三**
   - 大小影响定价、陈列和客群。
   - 太大单价高，买的人少；太小出肉率低，顾客觉得不划算。
   - 超市通常更适合中等偏大、出肉率稳定的规格。

4. **外观最后**
   - 外观重要，但主要是吸引购买和减少挑拣。
   - 如果外观好但内部差、甜度低，反而更容易造成“看着好，买回去不行”的差评。
   - 外观标准应该是：无明显腐烂、无严重磕碰、成熟度一致，而不是单纯追求漂亮。

所以超市卖菠萝的排序建议是：

**切果损耗 > 甜度 > 大小 > 外观。**

如果做的是整果批发/零售，可以适当把外观提前；如果做现切、果切、餐饮供应，切果损耗和甜度必须放最前面。
