问这些问题，核心目标是把“区域保护”和“串货”从口头承诺变成可写进合同、可执行、可追责的条款。建议分四步问。

**第一步：先问“区域保护”的定义和边界**

不要只问“有没有区域保护”，要问清楚保护的是什么：

- 保护的是“独家代理权”，还是仅“优先续约权”？
- 保护范围是省、市还是区县？边界以行政区划还是门店/渠道类型划分？
- 保护期内，品牌方自己能不能在区域内直营、做电商、直播带货？
- 区域内出现其他批发商拿货，算不算违约？怎么认定？
- 保护期限多长？到期后凭什么续约，续约条件会不会被单方面提高？

**第二步：问“串货”的认定和处理机制**

串货问题的关键不是“禁止”，而是“怎么查、怎么罚、罚谁”：

- 怎样界定串货？跨区销售、低价倾销、线上乱价是否都算？
- 品牌方有没有货品追溯码/批次码？能否查到货从哪个代理流出？
- 发现串货后，品牌方多久内处理？对窜货方罚款、断货还是取消代理？
- 如果串货来自品牌方自己的直营或电商渠道，怎么处理？
- 我作为受害方，能不能直接向品牌方索赔？依据是什么？

**第三步：问“价格与库存”的配套规则**

串货往往由价格差和压货引起，要一起问：

- 全国统一零售价、供货价、最低销售价分别是多少？是否允许区域调价？
- 线上渠道价格谁定？品牌方自营店是否遵守同一价格体系？
- 有没有最低进货量/年度任务？完不成会不会被削区域或断货？
- 库存积压、临期果品能不能退换？退换条件是什么？

**第四步：把答案落到合同与证据上**

- 要求把区域范围、独家性、串货认定标准、处罚措施、违约赔偿写进合同附件。
- 要求品牌方提供现有代理区域清单，避免“一区多代”。
- 保留所有沟通记录，尤其是招商人员口头承诺，尽量让其书面确认。
- 先小批量试单，观察品牌方是否真的管控串货，再决定是否加大投入。

**一句话总结**：问“保护谁、保护多大、谁来查、怎么罚、罚多少、写不写进合同”。如果对方对串货认定和处罚含糊其辞，基本可以判断这个品牌对渠道管控能力有限，代理风险较高。
