生鲜水果到货后出现坏果，责任划分通常不能一概而论，要看到货时间、坏果比例、包装情况、顾客举证和平台规则。一般可按下面几个层次判断：

**1. 先看“签收前”还是“签收后”**
- **签收前就已腐烂、压坏、渗漏**：通常属于商家或配送方责任。商家应承担退换、补发或退款。
- **签收时外观完好，签收后放置一段时间才坏**：更可能是顾客储存不当或水果自然后熟/变质，责任偏向顾客，但商家若承诺“坏果包赔”则另说。

**2. 看坏果比例和性质**
- **少量坏果**：常见处理是按比例退款或补差价，不一定整单退。
- **大量坏果、整箱腐烂**：通常认定商家发货或物流环节存在明显问题，应整单退款/补发。
- **个别坏果但属于易腐水果正常损耗**：若商家提前说明，且比例在合理范围内，可能由双方协商分担或按平台规则处理。

**3. 看包装和物流**
- **包装不当导致挤压、闷坏**：商家责任。
- **冷链中断、配送延迟导致变质**：配送方或商家责任，商家通常先对顾客负责，再向物流追偿。
- **顾客要求放代收点、快递柜，延迟取件导致坏果**：顾客可能承担部分责任。

**4. 看顾客是否及时取证**
顾客应在到货后尽快开箱拍照/录像，保留：
- 外包装、面单、开箱过程；
- 坏果整体和特写；
- 坏果数量、比例；
- 与客服沟通记录。
如果拖到几天后才反馈，且无法证明到货时已坏，责任认定会偏向顾客。

**5. 常见责任划分建议**
- **商家/平台主责**：到货即坏、大量坏果、包装明显不合格、冷链断裂。
- **物流主责或连带**：运输延误、暴力分拣、冷链失效。
- **顾客主责**：签收后长时间未取/未冷藏、自行放置过久、无法举证。
- **共同责任**：少量坏果、易腐品正常损耗、双方都有一定过错时，按比例协商。

**6. 实操处理原则**
对顾客：先拍照取证，尽快联系客服，要求按坏果比例退款或补发。
对商家：先安抚并按规则赔付，再根据物流合同追偿；同时保留发货前质检、包装、温控记录。
对平台：通常按“坏果包赔”“签收后X小时内反馈”等规则判定，谁违反承诺谁承担。

一句话总结：**到货时就坏，商家/物流担责；签收后因顾客储存或延迟取件才坏，顾客担责；少量正常损耗按比例协商，大量腐烂通常商家先赔再追偿。**
