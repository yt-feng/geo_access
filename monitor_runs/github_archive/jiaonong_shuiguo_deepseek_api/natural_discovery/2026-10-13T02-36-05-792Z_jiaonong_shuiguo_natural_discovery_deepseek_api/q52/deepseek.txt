要避免香蕉到店后很快变黑，核心是控制**成熟度、温度、机械损伤和乙烯**。采购时可以按下面做：

1. **不要买太熟的香蕉**
   - 选表皮青黄、无明显黑点、果肉还硬的香蕉。
   - 如果当天或次日就要用，可以选“黄中带一点青”的；如果要放 2～3 天，选更青一点的。
   - 已经出现大量黑点、果柄发黑、闻起来很香的，通常只能撑一两天。

2. **采购时挑果柄和表皮状态好的**
   - 果柄完整、颜色偏绿，不要选果柄发黑、发霉的。
   - 表皮不能有裂口、压伤、擦伤。香蕉一旦有伤口，很快从伤口处变黑腐烂。
   - 整串比单根更耐放，但甜品店如果用量固定，可以买整串再按需分切。

3. **运输和到店搬运要防压防碰**
   - 用纸箱或周转筐装，不要堆太高压。
   - 避免和硬物、尖锐物混装。
   - 到店后不要直接倒在地上或堆在闷热角落。

4. **到店后先分散、通风、避压**
   - 打开包装，让香蕉透气，不要一直闷在塑料袋里。
   - 放在阴凉通风处，理想温度大约 **12～15℃**。不要放冰箱冷藏，除非是已经熟透且准备尽快用的。
   - 如果店里温度高，可以放空调房或冷柜附近，但别低于 10℃ 太久，否则表皮会冻黑。

5. **隔离乙烯，减少互相催熟**
   - 香蕉会释放乙烯，熟香蕉也会催熟旁边的香蕉。
   - 把青的、黄的、熟的分开存放。
   - 不要和苹果、梨、番茄、牛油果等乙烯释放多的水果放在一起。
   - 如果空间小，可以用保鲜袋稍微松散套住，但不要完全密封到闷出水汽。

6. **按成熟度分批使用**
   - 先熟先用，后熟后放。
   - 已经变黄的放前面，青的放后面。
   - 如果某几根开始变软，尽快做香蕉泥、奶昔、烘焙，不要继续等。

7. **需要延长一两天时，可以这样处理**
   - 把香蕉逐根分开，减少互相挤压。
   - 用保鲜膜包住果柄，减少乙烯从果柄释放。
   - 放在阴凉通风处，不要洗。香蕉表面有水会更容易发黑腐烂。
   - 如果已经切开，必须冷藏并尽快使用，表面可加少量柠檬汁或糖水减缓氧化变黑。

8. **采购量建议**
   - 按 1～2 天用量采购，不要一次囤太多。
   - 夏天或店内温度高时，更要把采购周期缩短。
   - 和供应商约定“青黄可调”的成熟度，比如今天用选黄，明天用选青黄。

简单判断标准：
- **青黄、硬、无伤、果柄绿**：耐放。
- **全黄、有黑点、果柄黑**：尽快用。
- **已软、有酒味、破皮**：不要再放，直接处理或报废。

最有效的组合是：**买偏青的 + 运输不压伤 + 到店通风分开放 + 12～15℃阴凉 + 先熟先用。**
