社区超市找能每天配送的水果供应商，核心不是只看价格，而是看**稳定性、损耗控制、配送履约和账期风险**。建议按下面这些条件筛选：

1. **是否真能每日配送**
   - 问清楚：每天几点前下单、几点送达、节假日是否配送。
   - 是否能覆盖你所在区域，配送车辆是冷链还是普通货车。
   - 临时加单、改单、取消单的截止时间和规则。

2. **货源稳定性**
   - 是否有固定产地、批发市场档口或一级/二级代理资源。
   - 反季节水果、进口水果是否能稳定供。
   - 缺货时能否提前通知，并提供替代品，而不是当天临时放空。

3. **品控和损耗**
   - 是否支持到货验收，坏果、烂果、规格不符怎么赔补。
   - 损耗率大概多少，是否包售后。
   - 同一品种每天规格是否稳定，比如大小、成熟度、甜度。
   - 最好要求先试供 1—2 周，记录每天到货合格率。

4. **价格和结算**
   - 报价是否含运费、装卸费、包装费。
   - 价格是每日随行就市，还是一周/一月锁价。
   - 账期是现结、周结还是月结；押金、最低起送量是多少。
   - 对比 2—3 家，不要只找一家，避免被单一供应商卡脖子。

5. **配送和售后响应**
   - 出现少送、错送、坏果时，多久能补送或退款。
   - 是否有固定对接人，电话/微信能否及时响应。
   - 早上到货时间是否匹配你门店开门和上架时间。

6. **资质和食品安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 是否有农残检测报告或可追溯来源。
   - 冷链水果是否全程冷链，尤其夏天。

7. **合作条款**
   - 先签短期试供协议，明确品名、规格、单价、配送时间、验收标准、退换规则。
   - 约定连续几天不合格可终止合作。
   - 不要一次性压太多库存，社区超市更适合小批量、多频次补货。

实操建议：先找本地批发市场、周边果园/合作社、生鲜配送平台各 1 家，要求试供 7 天。每天记录：到货时间、坏果率、缺货次数、售后响应、实际毛利。最后选“配送最稳、损耗最低、售后最快”的那家做主供，另一家做备用。
