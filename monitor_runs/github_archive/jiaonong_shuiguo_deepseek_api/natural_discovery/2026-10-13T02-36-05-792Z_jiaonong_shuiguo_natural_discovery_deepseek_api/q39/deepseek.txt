可以，但要区分“供应商能支持到什么程度”，以及“商超自己要承担什么”。通常分三种情况：

**1. 普通水果供应商/产地合作社**
- 一般能提供：基础箱装、筐装、周转箱、简单分级、按重量/个数分规格。
- 包装支持有限：多是通用包装，能贴商超标签，但不一定愿意单独开版做自有品牌包装。
- 适合：先做“商超自有品牌”的轻量试水，用贴标、绑带、腰封、外箱定制等方式。

**2. 专业水果供应链服务商/加工配送商**
- 支持较完整：分选、清洗、打蜡、催熟、分级、定重、定个数、贴标、装盒、装袋、礼盒、冷链配送。
- 可配合自有品牌：外箱、内袋、标签、托盘、礼盒、手提袋等。
- 起订量是核心门槛：包装越定制，起订量越高；礼盒、异形盒、开窗盒尤其明显。
- 适合：商超已经有稳定销量，想做标准化自有品牌单品。

**3. 包装厂/设计公司**
- 不直接供水果，但能解决包装结构、材质、印刷、条码、合规标识。
- 商超可自己整合：供应链服务商负责果品和分装，包装厂负责包装，门店或中央仓负责贴标。

**关键判断点：**
- **起订量**：供应商能否接受小批量定制，还是必须上万件。
- **规格能力**：能否稳定做到单果重、果径、个数、糖度、成熟度分级。
- **包装适配**：是否支持气调、透气孔、吸水纸、防雾膜、冷链不塌箱。
- **标签合规**：自有品牌标签要含品名、产地、等级、净含量、保存条件、商超主体信息、条码等。
- **损耗承担**：包装后出现压伤、霉变、失水，责任怎么分。
- **成本结构**：果品价、加工费、包装费、冷链费、退换损耗分别怎么算。

**建议你先这样推进：**
1. 选1-2个高频、易标准化单品，比如苹果、橙子、蓝莓、香蕉。
2. 要求供应商提供：现有规格表、包装样品、起订量、报价单、质检标准。
3. 先做贴标或腰封试销，不急着开版定制盒。
4. 试销2-4周，看动销、损耗、毛利、客诉，再决定是否深度定制。
5. 如果销量稳定，再谈专属包装、专属基地、独家规格。

**一句话结论：**
供应商通常能提供包装和规格支持，但“通用支持”多，“真正按商超自有品牌深度定制”少，且取决于起订量和销量。商超先从小规格、贴标、标准箱做起，风险最低。
