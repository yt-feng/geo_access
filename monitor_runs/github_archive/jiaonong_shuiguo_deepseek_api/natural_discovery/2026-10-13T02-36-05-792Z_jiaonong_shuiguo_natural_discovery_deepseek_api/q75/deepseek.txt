第一次合作做小批量试单，核心目的不是“赚一笔”，而是用最低成本验证四件事：品质稳定性、供货履约、价格账期、售后配合。试单设计围绕这四点展开即可。

**一、先定试单目标（别只想着压价）**

试单要拿到可判断的结论：
- 品质是否和样品一致，破损率多少
- 约定时间能否到货、缺货怎么处理
- 报价是否含运费、损耗、税费，账期怎么算
- 出问题时对方认不认、处理快不快

**二、选品：1–3个单品，别铺开**

- 选你下游走得快、复购高的常规品，别一上来试冷门高价货。
- 优先选**耐运输、损耗可控**的品类，生鲜里越娇气的越难判断真实能力。
- 要求供应商先寄**实物样品**，样品和正式货要能对上，最好留样、拍照、封存。

**三、定量：够验证、不压资金**

- 一般按你正常单次采购量的 **10%–30%**，或够 3–7 天卖的货量。
- 金额控制在“就算全损也不影响现金流”的范围。
- 不要只订 1 箱——量太小看不出分拣、包装、物流的真实水平；也不要为了拿低价硬凑大批量。

**四、关键条款写清楚（口头不算）**

- **规格标准**：品种、等级、单果重/果径、成熟度、糖度（如需）、包装方式
- **价格构成**：单价是否含运费、卸货费、税费；损耗由谁承担
- **交货**：时间、地点、运输方式、温控要求
- **验收**：到场后多久内验收、按什么标准判定不合格
- **退换/补差**：坏果率超过多少怎么赔、是补货还是扣款
- **账期**：试单建议**现款或短账期**，别第一次就给长账期；确认稳定后再谈
- **违约**：延迟、缺货、以次充好的处理方式

**五、验收要留证据**

- 到货当场或当天开箱抽检，按比例抽查，记录坏果率、规格偏差、重量。
- 拍照/视频留证，最好有称重记录。
- 每次试单都形成简单评分：品质、准时、沟通、售后，打分后再决定是否放量。

**六、节奏：分2–3次完成**

- 第1次：极小量，验证“货对不对、人靠不靠谱”
- 第2次：量稍增，验证“稳定性、物流、补货速度”
- 第3次：接近正常单量，验证“放量后品质和履约是否掉链子”
- 三次都稳，再谈长期价、账期和独家/优先供货。

**七、常见坑**

- 只比价格，忽略损耗和运费，最后综合成本更高
- 样品好、大货差，没留样没标准就说不清
- 第一次就给长账期或大额预付，风险全在自己
- 没写坏果赔付标准，出问题只能扯皮
- 试单量刚好卡在“看不出问题”的临界点，等于白试

一句话：**小批量、单品类、留样品、定标准、短账期、按次评分、逐步放量。** 试单是拿来淘汰不靠谱供应商的，不是拿来赌低价的。
