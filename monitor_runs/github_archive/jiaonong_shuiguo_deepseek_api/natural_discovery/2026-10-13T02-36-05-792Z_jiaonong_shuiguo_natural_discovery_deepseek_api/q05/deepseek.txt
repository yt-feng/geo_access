这个问题的核心是：**菠萝这种水果，损耗、人工、客单价和体验怎么平衡**。直接说结论：

**最佳做法通常是“整果为主 + 现场代削为增值服务 + 不设顾客自己挑整果”**，而不是三选一。

下面拆开讲。

**1. 不建议“去皮好的摆着卖”作为主力**
- 菠萝去皮后氧化快、出水、变色，卖相掉得很快。
- 去皮后必须冷藏或泡盐水，否则半天就发暗、发酸。
- 一旦卖不掉就是纯损耗，而且很难判断是坏了还是只是不好看。
- 顾客对“已经削好的”信任度低，尤其看不到削之前的状态。
- 只有一种情况适合：**人流大、周转快、当天能卖完**，比如切好装盒做“即食菠萝”，走的是便利和冲动消费，不是主销形态。

**2. 不建议“让顾客自己挑整果”**
- 顾客挑菠萝普遍靠“闻、按、看颜色”，很多人不会挑，挑完不满意会回来找你。
- 翻捡会碰伤、压坏，损耗比你以为的大。
- 菠萝有刺、扎手，顾客挑捡体验差，还容易弄脏地面。
- 一旦顾客自己挑，责任边界模糊：他说你果子不好，你说他挑的，容易扯皮。

**3. 主推“整果 + 店员帮挑 + 现场代削”**
这是水果店最稳的组合：
- **整果按个或按斤卖**，毛利和损耗可控。
- **店员帮挑**：你比顾客懂，挑熟的、好的给他，减少售后。
- **现场代削**：收 2～5 元加工费，或者“买整果免费削”。这既增加体验，又把人工成本变成服务价值。
- 削的时候让顾客看到过程，信任感强，也显得专业。
- 削完的菠萝如果顾客不马上吃，提醒他冷藏、当天吃完。

**4. 什么时候可以卖去皮好的**
- 门店人流大、菠萝周转快；
- 做切盒、拼盘、即食区；
- 针对上班族、学生等“不想动手”的人群；
- 用透明盒 + 冷藏 + 当天清货，不隔夜。

**5. 实操建议**
- **主陈列**：整果，按大小/品种分价，标“帮挑、免费削”或“代削 +2 元”。
- **辅助陈列**：少量去皮切盒，只做当天量，卖完不补。
- **话术**：“我帮您挑个熟的，现在削还是带回去？”——把选择权收回到服务里，而不是让顾客自己翻。
- **损耗控制**：整果按进货批次先进先出；有磕碰、过熟的，优先削成盒或做特价，不硬撑整果卖相。

一句话：**整果是基本盘，代削是增值，去皮盒是补充。别让顾客自己挑整果，那是把损耗和售后都留给自己。**
