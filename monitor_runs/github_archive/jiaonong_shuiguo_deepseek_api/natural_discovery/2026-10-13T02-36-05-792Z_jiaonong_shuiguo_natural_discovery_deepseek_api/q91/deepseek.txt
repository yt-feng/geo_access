建议优先做 **单根 + 小把**，整袋作为补充，不要一上来只做整袋。判断逻辑如下：

1. **单根最适合便利店**
   - 便利店的核心场景是“即时、少量、顺手买”。
   - 香蕉是高频、低单价、即食型商品，单根最容易冲动购买。
   - 适合搭配早餐、酸奶、关东煮、饭团等一起买。
   - 缺点是损耗和称重/收银效率要处理好，最好按根定价，不要现场称重。

2. **小把适合家庭补货和客单提升**
   - 3—5根一把比较合适，既能提高客单价，又不会像整袋那样压力大。
   - 适合下班回家、附近居民、两人小家庭。
   - 定价可以略低于单根单价，制造“买一把更划算”的感觉。

3. **整袋要谨慎**
   - 整袋更适合社区团购、家庭囤货、线上预售，不太适合传统便利店主推。
   - 香蕉成熟快，整袋如果当天卖不掉，第二天就容易过熟、发黑，损耗高。
   - 除非你的门店在社区门口、客流稳定、有冷藏/催熟/折价处理能力，否则不建议把整袋当主力。

4. **更稳的组合建议**
   - 主力：单根，按根卖，放在收银台附近或进门动线。
   - 辅助：3—5根小把，放在水果区或冷藏柜旁。
   - 补充：整袋只做预订、团购或周末家庭装。
   - 分级处理：青一点的做小把/整袋，熟一点的拆单根快速卖，过熟及时做折扣或加工成果切/奶昔原料。

5. **关键看三个条件**
   - **客流类型**：写字楼/学校/地铁口，单根优先；社区家庭多，小把优先。
   - **周转速度**：日销快，可以上小把和整袋；日销慢，只上单根。
   - **损耗承受力**：香蕉损耗高，整袋风险最大，单根最容易控损。

结论：**先上单根，再上3—5根小把，整袋只做补充或预售。**  
如果只能选一个，选 **单根**；如果能选两个，选 **单根 + 小把**。
