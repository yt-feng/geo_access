判断香蕉批发商是否稳定供货，不能只看报价，重点看这几点：

1. **看产地资源是否固定**
   问清楚对方香蕉主要来自哪里，是广西、云南、海南，还是老挝、缅甸、菲律宾、厄瓜多尔等进口货。稳定供货商通常有固定产区、固定合作基地或长期代办，不会今天说广西、明天说越南，来源含糊。

2. **看全年供应能力**
   香蕉有季节空档。问对方：
   - 淡季从哪里补货？
   - 台风季、寒潮期怎么保证？
   - 春节、国庆前能不能持续发车？
   如果对方只说“随时有货”，但说不出具体补货渠道，风险较大。

3. **看日/周发货量**
   直接问他每天能稳定发多少车、多少件、多少吨。比如：
   - 日发几车？
   - 单车多少件？
   - 连续一周能不能保证？
   稳定档口一般有冷库、加工线、装车队伍，不是临时拼车。

4. **看加工和催熟能力**
   香蕉分生蕉、熟蕉。做批发档口，要问：
   - 是否有催熟房？
   - 能不能按你的销售节奏控制熟度？
   - 有没有分拣、洗蕉、打冷、包装能力？
   只有货源、没有加工能力的，供货容易断档或质量不稳。

5. **看合作客户结构**
   问他主要供哪些市场、超市、电商或二批。如果他有长期合作的大客户，通常说明供货相对稳定。可以要求看发货记录、装车视频、冷库视频，但注意不要只看对方发的宣传图。

6. **看付款和风险条款**
   稳定供货商一般敢谈：
   - 定金比例
   - 到货验收标准
   - 坏货、烂蕉、重量不足怎么赔
   - 延迟发货怎么处理
   如果对方只要求全款、不愿定质量标准、不愿承担到货损耗，稳定性要打问号。

7. **小批量试单**
   最直接的办法：先小批量试 3—5 次，不要一上来压大单。重点看：
   - 是否按时装车
   - 到货重量是否足
   - 青熟度是否一致
   - 烂蕉率多少
   - 后续补货是否顺畅
   连续几次都稳定，再谈长期合作和账期。

8. **实地或视频核验**
   有条件去产地/档口看：
   - 冷库
   - 催熟房
   - 装车现场
   - 工人和车辆
   没条件就要求实时视频，不要只收提前拍好的素材。

9. **警惕几个信号**
   - 报价明显低于市场太多
   - 什么产地、什么季节都能大量供
   - 催你打全款
   - 不愿给具体地址、公司名、装车视频
   - 合同只写“香蕉”，不写等级、重量、熟度、损耗
   - 出问题后只换人不赔损

简单说：**稳定供货 = 固定产区 + 持续发货量 + 加工能力 + 敢担责的条款 + 多次试单验证。**  
你可以先让对方提供：最近一周装车记录、产地视频、冷库/催熟房视频、日发量、淡季补货方案，再决定要不要合作。
