超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体要求会因超市规模、地区监管和水果品类有所不同：

**一、主体资质类**
- 营业执照
- 食品经营许可证（或食品流通许可证）
- 若为进口水果，还需海关相关资质证明

**二、进货凭证类**
- 供货发票或销售凭证
- 进货台账/送货单，记录品名、数量、产地、日期
- 上游供应商的资质复印件（索证索票制度要求）

**三、检测报告类**
- **农残检测报告**：这是最核心的一项，通常要求符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》。可以是供应商自检报告，也可以是第三方检测机构出具的报告。
- **产地证明或合格证**：部分品类要求提供产地检疫证明或食用农产品合格证。
- **进口水果**：需提供入境货物检验检疫证明、海关报关单。

**四、实际执行中的弹性**
- 大型连锁超市（如永辉、沃尔玛）通常要求较严，会指定第三方检测或要求批批检测。
- 小型超市、农贸市场摊位的执行相对宽松，一般以索证索票为主。
- 生鲜电商平台往往要求供应商提供近期（如半年内）的第三方检测报告。

**建议**：如果你是供应商，最稳妥的做法是准备好营业执照、食品经营许可证、每批次的农残快检报告或第三方检测报告、送货单，进口水果额外备齐报关和检疫文件。如果你是超市采购方，建议在合同里明确约定检测项目、报告有效期和抽检责任，避免后续纠纷。
