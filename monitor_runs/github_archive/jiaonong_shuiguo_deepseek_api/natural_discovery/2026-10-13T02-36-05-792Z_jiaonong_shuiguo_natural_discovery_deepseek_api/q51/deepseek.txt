要固定，但**不是只固定产地，而是固定“产地+品种+等级+成熟度+加工批次”的组合**，并且用验收标准兜底。

直接给结论：

1. **核心原料要固定供应批次或至少固定产区+品种**
   - 比如金桔、柠檬、芒果、葡萄、草莓这类风味差异大的水果，产地和季节一变，酸度、香气、出汁率都会变。
   - 茶饮店最怕的不是“绝对一样”，而是“今天太酸、明天太甜、后天没香”。
   - 所以对招牌产品，建议固定：**品种、产区、等级、成熟度、加工方式**，能锁批次就锁批次。

2. **不要迷信“固定产地”**
   - 同一产地不同果园、不同采摘期、不同成熟度，风味照样差很多。
   - 同一品种在不同年份，气候也会让酸甜比变化。
   - 所以产地只是第一层，真正要固定的是**可验收的指标**。

3. **采购时更实用的做法**
   - 招牌款：固定供应商+固定加工批次，必要时做风味盲测。
   - 常规款：固定产区范围+品种+等级，允许换批次，但每批验收。
   - 季节性产品：提前做替代方案，比如换品种、调糖酸比、改配方。
   - 要求供应商提供：品种、产地、采摘/加工日期、批次号、糖度、酸度、规格。

4. **店里要建立验收标准**
   - 看：颜色、果形、有无破损霉变。
   - 闻：香气是否正常。
   - 测：糖度、酸度，至少用折射仪和滴定或口感对比。
   - 尝：做标准杯，和上一批对比。
   - 记：每批留样，记录批次和使用反馈。

5. **最稳的策略**
   - **招牌产品锁批次或锁“产区+品种+加工厂”。**
   - **非招牌产品锁标准，不锁死单一产地。**
   - **永远保留一个备选供应商和替代配方。**

一句话：固定产地有用，但不够；固定批次更稳，但成本高。最合理的是**固定品种、等级、成熟度和验收标准，招牌款再锁批次**。
