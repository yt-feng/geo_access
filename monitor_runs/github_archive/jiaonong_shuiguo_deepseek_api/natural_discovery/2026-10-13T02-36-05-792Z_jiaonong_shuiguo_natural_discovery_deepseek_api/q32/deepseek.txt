判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要看他有没有“跨产区调度能力”和“冷链+催熟”体系。可按下面几步核验：

**1. 先问产地结构，不要只听“我们全年有货”**
问清楚：
- 自有基地还是市场调货？
- 主要产区有哪些？比如海南、云南、广西、广东、福建，以及进口的菲律宾、越南、厄瓜多尔、哥伦比亚等。
- 各产区分别什么季节上市？
- 如果一个产区受灾，替代产区是谁？

能全年稳定供货的供应商，通常不是依赖单一产区，而是有多个产区或进口渠道轮换。

**2. 看历史供货记录**
要求提供：
- 过去12个月或24个月的供货明细；
- 每月实际发货量、履约率、缺货次数；
- 旺季和淡季的到货差异；
- 是否遇到台风、寒潮、雨季病害时仍能供货。

重点看：**淡季、灾年、春节前后**是否断供。这比旺季能不能供货更能说明问题。

**3. 核验冷链和催熟能力**
香蕉是呼吸跃变型水果，全年稳定供应不只是“有香蕉”，还要能控制成熟度。
问：
- 有没有产地预冷、冷藏运输、港口/中转仓？
- 到仓后是自己催熟还是外发催熟？
- 催熟库容量多大？能否按门店销售节奏分批出库？
- 夏季高温、冬季低温时怎么控温？

如果供应商没有催熟能力，只能靠批发市场拿熟蕉，全年稳定性通常较差。

**4. 看合同里的保障条款**
不要只签“原则上保证供应”，要写清：
- 年度最低供货量、月度分解量；
- 缺货违约责任；
- 替代产地或替代品种的触发条件；
- 价格调整机制，避免一缺货就乱涨价；
- 质量标准：条重、梳数、青度、伤痕、药残检测。

**5. 做小规模压力测试**
正式放量前，可以：
- 连续3个月按计划下单，观察履约率；
- 故意在淡季或天气异常时增加一次订单，看响应速度；
- 要求提供第三方农残检测和检疫证明；
- 到其催熟库、冷库、分拣现场实地看。

**6. 关键判断标准**
如果满足以下多数条件，全年稳定供货能力较强：
- 有2个以上产区或进口渠道；
- 能提供12个月以上连续供货记录；
- 自有或长期合作催熟库；
- 冷链覆盖产地到门店；
- 合同有最低供货量和违约条款；
- 淡季不缺货，灾后能快速切换产地。

**简单结论：**
只看“现在有没有货”不够，要看他**不同季节从哪里拿货、断货时怎么补、有没有催熟和冷链、过去一年有没有断供记录**。最好用“多产区+历史履约+冷链催熟+合同约束+小规模试单”五项一起判断。
