通常需要，具体看你企业的采购用途和财务要求，但这两项一般都应作为供应商的基本能力来要求：

1. **开发票**
   - 只要是企业对公采购，基本都要求供应商能开正规发票。
   - 常见是增值税普通发票或增值税专用发票，取决于你公司是否一般纳税人、财务是否要求抵扣。
   - 采购前要确认：开票项目、税率、是否支持对公转账、能否开专票。

2. **定制包装**
   - 如果是企业福利发放，通常需要定制包装，比如印企业 Logo、节日祝福、福利卡、手提袋等。
   - 是否必须定制，取决于预算和用途：
     - 普通员工福利：可接受通用礼盒，但定制包装更有企业关怀感。
     - 客户礼品、节日慰问、品牌活动：一般建议定制。
   - 定制通常涉及起订量、设计费、打样费、交期，需要提前和供应商确认。

**建议采购时直接要求供应商满足：**
- 能开正规发票，且发票类目与水果礼盒一致；
- 支持对公付款；
- 支持定制包装，明确起订量、打样时间、印刷内容和交付周期；
- 提供食品安全相关资质和售后保障。

如果供应商不能开发票，通常不建议作为企业福利采购对象；如果不能定制包装，则看你的福利场景是否必须，但至少应能提供统一、体面的礼盒形式。
