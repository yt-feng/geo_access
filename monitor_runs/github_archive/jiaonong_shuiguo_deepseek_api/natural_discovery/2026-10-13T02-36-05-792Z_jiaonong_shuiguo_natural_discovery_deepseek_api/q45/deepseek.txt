连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是**价格调整、品质验收、损耗归属、账期结算、返利费用、违约与退出机制**这几类条款。下面按风险高低说明。

**1. 价格与调价机制**
水果价格波动大，合同如果只写“年度供货价”，很容易在行情大涨时供应商断供，大跌时超市被高价套牢。
要写清：
- 基准价对应什么规格、等级、产地、包装。
- 调价触发条件：比如批发市场均价波动超过±10%，或季节性品种按周/月议价。
- 调价程序：谁提出、用什么数据、提前几天通知、双方不认可时怎么处理。
- 是否允许供应商单方停供。最好约定不得因短期行情波动随意断供。

**2. 品质标准和验收规则**
“新鲜”“无腐烂”“符合国家标准”这类表述太虚，争议时很难判定。
要写清：
- 每个单品的等级、果径、糖度、色泽、成熟度、农残标准。
- 验收方式：到仓检、门店检、抽检比例、第三方检测。
- 不合格处理：拒收、扣款、退货、换货、降价接收，分别适用什么情形。
- 验收时限：到货后几小时内提出异议，逾期是否视为合格。
- 生鲜有隐蔽瑕疵的，是否允许门店后续追溯。

**3. 损耗和退货归属**
这是水果合同里最容易扯皮的地方。
要区分：
- 运输损耗：谁承担。
- 仓储损耗：超市仓库还是供应商承担。
- 门店损耗：上架后腐烂、压伤、滞销谁负责。
- 退货条件：是质量问题退货，还是滞销也可退。
如果约定“无条件退货”，供应商通常会把成本加进报价；如果约定“概不退货”，超市门店损耗会很大。比较稳的是按品类、按比例、按原因分别约定。

**4. 账期与结算**
常见坑是账期模糊、对账慢、扣款无依据。
要写清：
- 结算周期：月结、半月结还是周结。
- 对账日、开票日、付款日，以及遇到节假日是否顺延。
- 扣款项目：质量扣款、缺货罚款、促销费用、损耗补偿，必须列明计算方式。
- 超市能否单方从货款中抵扣。供应商通常反感无限抵扣权，最好限定范围和凭证。
- 逾期付款是否计息。

**5. 返利、进场费、促销费**
年度合同常见“综合返利”“年度达标返利”“促销服务费”。
要写清：
- 返利基数：含税还是不含税，按供货额还是按结算额。
- 达标条件：全年采购额、单品采购额、增长率。
- 返利支付方式：现金、货款抵扣还是货物折让。
- 费用是否与真实服务对应。否则供应商可能事后主张是变相收费。
- 年度未完成采购量时，返利怎么处理。

**6. 供货保障与缺货责任**
水果季节性、产区天气影响大，但超市又怕断货。
要写清：
- 最低供货量、最高供货量，还是按订单供货。
- 缺货通知时间、替代方案、替代品是否同价。
- 缺货违约金是否合理。过高可能被法院调低，过低则没有约束力。
- 不可抗力范围。天气、疫情、交通管制是否属于免责，要有边界，不能什么都算不可抗力。

**7. 排他性与渠道限制**
供应商可能同时给竞品超市供货，超市可能要求独家或区域独家。
要写清：
- 是否独家、独家范围是单品、区域还是全渠道。
- 独家期间供应商能否做电商、社区团购、批发市场。
- 超市是否承诺最低采购量。没有最低量却要求独家，供应商容易反悔。
- 违反独家条款的违约金和终止权。

**8. 食品安全与责任**
水果涉及农残、防腐剂、催熟剂等问题。
要写清：
- 供应商保证符合食品安全法及国家标准。
- 出现抽检不合格、消费者投诉、监管处罚时，谁承担罚款、赔偿、召回费用。
- 是否要求提供检测报告、产地证明、承诺达标合格证。
- 超市因供应商问题被处罚，能否全额追偿。

**9. 合同期限与退出**
年度合同不等于必须做满一年。
要写清：
- 生效日、到期日、是否自动续约。
- 提前终止条件：连续几次质量不合格、缺货、食品安全事件、付款逾期。
- 终止后的库存、在途货物、已下订单怎么处理。
- 是否设置过渡期，避免突然断供。

**10. 争议解决和证据**
要写清：
- 对账单、验收单、微信/邮件订单是否作为合同附件或有效证据。
- 争议解决是诉讼还是仲裁，地点在哪里。
- 生鲜纠纷时效短，最好约定快速处理机制。

**实务上最建议坚持的几条：**
1. 价格不能一口价锁死，要有调价机制。
2. 品质标准要量化，验收时限要明确。
3. 损耗和退货按原因分层约定，不要笼统写“包退包换”。
4. 所有扣款、返利、费用都要有计算依据和对账确认。
5. 食品安全责任和追偿条款不能省。
6. 缺货、断供、质量事故要设置可执行的终止和赔偿机制。

如果只挑三个最危险的坑：**价格锁死无调价、验收标准模糊、损耗退货全包或全不包**。这三类最容易在年度执行中变成亏损或断供。
