最应该先问**售后**，其次才是配送，最后才是价格。

原因是：

1. **售后决定你能不能真的赚到钱**  
   水果是生鲜，损耗、坏果、大小不符、成熟度不稳都很常见。  
   如果供应商售后差，坏果不赔、赔付慢、要求一堆照片和证明，最后这些损失基本都会落到团长自己身上。  
   你表面上有差价，实际可能被售后吃掉利润，还会得罪邻居和群友。

2. **配送决定你的履约稳定性**  
   配送慢、临时放鸽子、不按约定时间到、冷链不行，都会直接影响用户体验。  
   但配送问题通常还能通过换供应商、补发、提前备货来补救。  
   售后如果一开始就很差，后面会长期反复折磨你。

3. **价格重要，但不是第一优先**  
   价格低但售后差，等于低价里藏着高风险。  
   团购团长做的是信任生意，一次坏果处理不好，可能丢的不是一单，而是一整群客户。  
   价格应该在售后和配送都能接受之后，再拿来比较。

更实用的问法是：

- **售后**：坏果怎么赔？多久内反馈有效？按比例赔还是全额赔？要不要退回？谁承担运费？
- **配送**：几天到？能不能固定到货时间？坏了/迟到了怎么处理？是否支持冷链？
- **价格**：起送量多少？能不能混批？不同规格差价多少？账期还是现结？

所以结论很直接：  
**先问售后，再问配送，最后谈价格。**  
如果只能问一个问题，就问：**“坏果、烂果、斤两不足，怎么赔，多久赔，谁来承担？”**
