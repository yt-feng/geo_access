优先谈**账期**，其次**售后**，最后**配送**。

理由很直接：长期合作里，账期直接影响你的现金流和经营风险，是“钱”的问题；售后决定出问题时的损失能不能兜住，是“风险”的问题；配送更多是效率和体验，通常在前两项谈稳后再优化，代价和优先级都更低。

具体判断标准可以这样用：

1. **账期优先谈**
   - 水果是高频、易损耗、价格波动大的品类，现金流压力比一般标品更明显。
   - 优先争取：月结、半月结、固定对账日、逾期处理方式。
   - 如果供应商给不了长账期，就谈“部分账期+部分现结”，或者用稳定采购量换账期。
   - 核心底线：不要让自己长期垫资，尤其是旺季备货时。

2. **售后第二谈**
   - 水果售后高频，烂果、压伤、规格不符、到货成熟度不对都会发生。
   - 优先明确：坏果率标准、拍照留证时限、补货/退款/扣款规则、责任划分。
   - 最好谈成“按比例赔付”或“下次补货抵扣”，比每次扯皮更省事。
   - 如果售后规则模糊，后面每一单都可能变成消耗。

3. **配送最后谈**
   - 配送重要，但通常可以通过换物流、自提、调整下单时间、合并订单来缓解。
   - 优先谈：到货时间窗口、冷链/保鲜要求、临时加单响应、缺货替代规则。
   - 如果配送不稳定但账期和售后都很好，可以先接受，后续用采购量换改善。

**结论：**
先谈账期，保住现金流；再谈售后，控制损耗和纠纷；最后谈配送，提升效率。  
如果只能谈一个，选**账期**。如果供应商账期很硬，那就把**售后**谈死，至少保证坏货不自己扛。
