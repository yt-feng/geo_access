判断水果供应商靠不靠谱，重点不是看他嘴上说得多好，而是看这几件事能不能长期稳定做到。你可以按下面这套标准去筛。

**1. 先看货源和稳定性**
- 问他香蕉主要来自哪里，是云南、广西、海南，还是进口菲蕉、厄瓜多尔蕉；菠萝是广东徐闻、海南、福建，还是进口。
- 靠谱供应商会说清楚产区、季节、替代方案。比如香蕉淡季从哪补，菠萝过季怎么换。
- 不靠谱的通常只会说“都有”“要多少有多少”，但一到缺货就涨价或断供。

**2. 看报价方式是否清楚**
- 正常会报：产地、规格、等级、净重、毛重、箱规、当日报价、是否含运费、是否含税。
- 你要特别问清楚：是按斤还是按件，是否扣皮重，次果怎么算，坏果怎么赔。
- 如果报价含糊，只说“很便宜”“到了再说”，后面很容易扯皮。

**3. 看样品和实际到货差距**
- 第一次合作不要只听介绍，先拿样或小批量试单。
- 香蕉重点看：成熟度、条形、均匀度、是否有水烂、黑星、药害、冻伤。
- 菠萝重点看：果眼深浅、成熟度、黑心、水菠萝、烂心、大小均匀度。
- 靠谱供应商的样品和大货差距小；不靠谱的常常样品很好，大货参差。

**4. 看分级和损耗承担**
- 问清楚：一级果、二级果比例大概多少，是否允许挑果，次果怎么处理。
- 香蕉和菠萝都容易有损耗，靠谱供应商会明确：运输损耗、到店坏果、催熟问题分别谁承担。
- 如果他说“水果都有损耗，正常”，但不给具体比例和赔付标准，要谨慎。

**5. 看物流和到货时间**
- 香蕉怕冻、怕热、怕压；菠萝怕闷、怕摔。问清楚用什么车、是否冷链、几天到。
- 靠谱供应商能给出固定发货日、到货时间范围，并且异常会提前通知。
- 经常临时改时间、拼车乱装、到货时间说不准的，长期合作会很累。

**6. 看售后和赔付速度**
- 关键不是永远不出问题，而是出问题后怎么处理。
- 靠谱的：有照片视频就能认，按比例赔、补货或下次抵扣，处理快。
- 不靠谱的：先拖，再推给物流，最后让你自己承担。

**7. 看价格是否长期合理**
- 不要只找最低价。水果供应里，明显低于市场价通常意味着等级差、催熟乱、压秤或售后差。
- 你可以同时问 2—3 家，比较同一规格、同一等级、同一到货条件的价格。
- 靠谱供应商价格会随行就市，但不会今天一个价、明天翻倍，也不会老客户反而更贵。

**8. 看合作条款能不能落地**
- 最好有简单书面或微信确认：品名、规格、等级、单价、数量、到货时间、赔付标准。
- 不需要很复杂，但关键信息要留痕。
- 长期合作可以谈：固定账期、坏果赔付比例、旺季优先供货、淡季保底量。

**9. 实地或视频看档口**
- 有条件就去他档口、仓库、加工点看。
- 看库存周转快不快，烂果多不多，工人分拣是否规范，发货是否按单。
- 如果连视频看货都推脱，风险较高。

**10. 用“小单试、中单验、大单稳”的方式合作**
- 第一周：小批量试，验品质、时效、售后。
- 第二周：加量，看稳定性。
- 一个月：如果连续 3—4 次到货稳定、赔付痛快，再考虑长期主供。
- 同时保留一个备用供应商，防止被一家拿捏。

**简单判断口诀：**
- 说得清产地和规格；
- 样品和大货一致；
- 报价和扣重透明；
- 坏果赔付有标准；
- 到货时间稳定；
- 出问题不推责；
- 价格不是最低但合理；
- 小单试过后再放量。

对你开水果店来说，香蕉和菠萝都是引流和走量品，最怕断货、品质不稳和售后扯皮。所以选供应商，优先选“稳定、透明、赔得快”的，而不是单纯最便宜的。
