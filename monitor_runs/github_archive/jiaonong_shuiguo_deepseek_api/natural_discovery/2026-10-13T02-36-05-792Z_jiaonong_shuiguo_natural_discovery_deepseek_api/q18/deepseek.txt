买香蕉关键看**用途、存放时间和成熟度**，别只按颜色判断。

**1. 先定用途**
- **当天/1天内吃**：买已经黄、带少量小黑点的，甜度高。
- **2～3天内吃**：买通体黄、两头略青、无明显黑点的。
- **3～5天后吃**：买黄中带青、果柄偏绿的。
- **想放更久**：买整体偏青、硬一点的，回家常温催熟。

**2. 到店怎么挑**
- **看果柄**：果柄鲜绿，通常较生；果柄发黄发褐，通常更熟。
- **看棱角**：香蕉身有明显棱角，偏生；棱角变圆润，偏熟。
- **看斑点**：少量芝麻黑点=适合马上吃；大片黑斑、发软=过熟。
- **轻捏**：硬=生，微软=刚好，明显软=熟过头。
- **闻一下**：有浓郁果香=熟；没味道=偏生；有酒味=过熟。

**3. 避免“到店太生/太熟”的实操**
- 如果**今天就要吃**：不要买全青的，选黄色均匀、微软、少量斑点的。
- 如果**还要逛很久才回家**：别买已经软熟带黑斑的，选黄中带青的，避免路上压伤。
- 如果**超市冷柜里的香蕉**：通常成熟慢，但可能偏生或冻伤，优先选常温货架。
- 如果**整把里有一根特别熟**：别买，熟香蕉会释放乙烯，催熟整把。

**4. 回家后控制成熟速度**
- 想催熟：和苹果/梨一起放纸袋，常温1～2天。
- 想慢熟：拆开、果柄包保鲜膜，放阴凉处；成熟后可冷藏。
- 冷藏后皮会变黑，但果肉通常还能吃；别冷冻，除非做冰沙。

**一句话**：今天吃选黄带点黑；两三天吃选黄中带青；想多放选青硬果柄绿。
