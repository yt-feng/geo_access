判断的核心不是“他能不能种出菠萝”，而是“他能不能持续把符合你规格的菠萝、按你要的时间和量送到仓”。建议从下面几个可验证的维度逐项排查。

**1. 先把自己的规格定死**
在谈供应商前，先明确并书面化：
- 品种（如金钻凤梨、台农、都乐等）
- 单果重区间（例如1.2–1.5kg）
- 成熟度/糖度（如到货糖度≥14°Brix，或指定青果/熟果）
- 果形、无黑心、无裂口、无药残等外观与安全指标
- 包装方式（箱规、单箱净重、码放层数）
- 到货温度要求（常温/冷链）
- 验收标准与拒收条件

规格越模糊，供应商越容易“这次行、下次糊弄”。

**2. 查真实产能，不看话术看数据**
- 问自有基地面积、合作农户数量、年/季产量，而不是只听“我们有几千亩”。
- 要求提供近几个月的实际出货记录：发货日期、数量、规格合格率。
- 关键问题：**旺季和淡季分别能给你多少量？** 茶饮用量往往集中，供应断在旺季最致命。
- 如果他自己不是种植方，要确认他是否有稳定的一级/二级货源，而不是临时去批发市场拼货。

**3. 用历史履约记录判断稳定性**
要求对方提供：
- 过去6–12个月给其他客户的送货记录（可脱敏）
- 准时到货率、规格合格率、拒收/退换货次数
- 有没有因为天气、物流、节假日断供过

如果一个供应商拿不出任何历史履约数据，稳定性基本没法判断。

**4. 实地或视频验厂/验园**
重点看：
- 分选线是否按重量/糖度分级，还是人工随意挑
- 冷库/预冷能力，菠萝是否做预冷处理
- 包装区是否规范，有没有混装、以次充好
- 仓储和物流衔接：装车后多久发车，能否全程温控

没有分选和预冷能力的供应商，规格一致性通常差。

**5. 小批量试单 + 多批次验证**
正式合作前做：
- 连续3–5批小单试送
- 每批记录：到货时间、数量差异、规格合格率、损耗率
- 故意在不同天气、不同周次下单，看波动
只有多批次都稳，才算初步合格。

**6. 合同里写死保障条款**
- 规格、数量、到货时间、验收标准
- 缺货/迟到/规格不符的赔偿或扣款
- 旺季优先供货承诺
- 允许你方突击抽检
- 备选供应商机制：主力+备用，避免单点依赖

**7. 问几个“送命题”**
- 台风季/雨季断货怎么办？有没有备选产区？
- 你最大的单日发货能力是多少？
- 如果我临时加单30%，你几天能补上？
- 去年有没有出现过整批拒收？怎么处理的？
- 你的菠萝从采摘到发车一般多久？

回答含糊、只会说“没问题”的，风险高。

**实操建议：**
先用“小批量多批次试单+历史履约数据+分选预冷能力”三项筛，再签带违约条款的合同。茶饮连锁最怕的不是单价高一点，而是旺季断供或规格忽好忽坏导致门店出品不稳定。
