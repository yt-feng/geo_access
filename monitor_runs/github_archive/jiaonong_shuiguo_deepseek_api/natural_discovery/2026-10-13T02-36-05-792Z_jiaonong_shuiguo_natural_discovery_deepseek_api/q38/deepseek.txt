大型超市对水果供应商的要求，核心围绕“食品安全合规”和“冷链物流履约”两条线。以下是通常必须具备的能力清单：

**一、食品安全能力**

1. **资质证照齐全**
   - 营业执照、食品经营许可证（或食品生产许可证，视加工环节而定）
   - 种植/养殖基地需有产地证明；若为进口水果，需有入境货物检验检疫证明、报关单
   - 涉及分装、切果的，还需对应生产许可

2. **可追溯体系**
   - 能实现“从基地到门店”的批次追溯：产地、采摘日期、加工日期、检测记录、发货批次一一对应
   - 出现问题时能快速锁定并召回特定批次

3. **农残与污染物检测能力**
   - 每批次或定期提供农残检测报告（如农残快检、第三方检测）
   - 对重金属、霉菌毒素等有相应控制
   - 有自检实验室或稳定合作的第三方检测机构

4. **质量分级与验收标准**
   - 按超市要求做大小、糖度、色泽、成熟度、瑕疵率分级
   - 能配合超市的收货验收标准，接受抽检和退货机制

5. **仓储与加工卫生管理**
   - 仓库、分拣车间符合食品卫生要求，有防鼠防虫防潮措施
   - 人员健康证、操作规范、清洗消毒记录
   - 若做预包装或鲜切，需符合对应卫生规范

6. **召回与应急机制**
   - 有食品安全事故应急预案、召回流程
   - 能配合超市做下架、召回、原因分析和整改

**二、物流与冷链能力**

1. **冷链运输能力**
   - 水果多数需冷藏或保温运输，供应商需有冷藏车或稳定冷链合作方
   - 能控制运输温度，并有温度记录可查
   - 对温度敏感品类（如浆果、荔枝、车厘子）有专门温控方案

2. **仓储冷链**
   - 有冷库或恒温库，能按品类分温区存放
   - 先进先出、批次管理，避免压货变质

3. **配送时效与稳定性**
   - 能按超市约定的频次、时间窗送货到仓或到店
   - 高峰期、节假日、恶劣天气下仍有履约能力
   - 有备用车辆和备用路线

4. **损耗控制能力**
   - 采摘、预冷、分拣、包装、运输各环节有降损措施
   - 能控制到货合格率和损耗率在超市可接受范围内

5. **包装与装卸规范**
   - 包装能保护水果、便于冷链和搬运
   - 装卸过程符合卫生和防损要求

6. **信息化对接能力**
   - 能提供发货单、检测报告、温度记录等单据
   - 有条件时能与超市系统对接订单、库存、批次信息

**三、超市通常还会重点考察的**

- 基地或货源稳定性，能否长期稳定供货
- 是否有食品安全责任险
- 过往合作案例和履约记录
- 对突发质量问题的响应速度
- 是否接受超市的飞行检查、抽检和审核

**简单判断标准：**
如果一家供应商能做到“证照全、可追溯、有检测、能冷链、按时送、出问题能召回”，基本就具备大型超市水果供应商的核心门槛。不同超市还会在温控精度、检测频次、配送时效上有更细的硬性标准，具体以其供应商准入审核表为准。
