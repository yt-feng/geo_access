判断水果供应商是否合规、稳定，采购方（养老院/医院食堂）可以从**资质合规、供货能力、质量与安全、履约历史、风险预案**五个维度做核查。重点不是“便宜”，而是**不断供、不出食品安全事故、可追溯**。

---

## 一、合规性核查（硬门槛，先卡这一关）

1. **营业执照**
   - 经营范围须包含水果批发/零售/农产品销售等。
   - 核对统一社会信用代码，可在“国家企业信用信息公示系统”查询是否存续、有无异常经营、行政处罚。

2. **食品经营许可证 / 食品流通相关许可**
   - 若供应商直接供应食品（含水果分拣、包装、配送），通常需要食品经营许可证。
   - 核对许可项目、有效期、经营地址是否与实际一致。

3. **食用农产品相关证明**
   - 要求提供**产地证明、购销凭证、合格证**等。
   - 对重点品种可要求**农残检测报告**（第三方或供应商自检），并关注检测项目是否覆盖常用农药。

4. **从业人员健康证**
   - 涉及分拣、包装、配送的人员应有有效健康证明。

5. **冷链/运输合规**
   - 若供应冷藏水果或需温控配送，查看车辆、冷库、温控记录是否合规。

6. **票据与追溯**
   - 能否提供**正规发票/收据**、**批次台账**、**进货凭证**，实现“来源可查、去向可追”。

> 判断要点：证照齐全只是底线，还要看**证照是否在有效期内、经营范围是否匹配、实际经营地址是否一致**。

---

## 二、稳定性核查（能不能长期不断供）

1. **货源基地或稳定采购渠道**
   - 是否有固定产地、合作社、批发市场档口或长期合作果园。
   - 避免只靠“临时倒手”的中间商。

2. **供应能力**
   - 日均/峰值供货量能否覆盖食堂需求。
   - 节假日、恶劣天气、疫情等情况下是否有备用货源。

3. **仓储与冷链能力**
   - 是否有冷库、分拣场地、保鲜设施。
   - 水果损耗率是否可控，能否按食堂计划分批配送。

4. **配送能力**
   - 自有车辆还是外包？配送频次、时效、准时率如何。
   - 是否能固定线路、固定时间送达，减少食堂库存压力。

5. **合作客户与经营年限**
   - 是否长期给医院、养老院、学校、机关食堂供货。
   - 经营年限过短、客户结构单一，稳定性风险较高。

6. **价格波动应对**
   - 是否接受阶段性调价机制、是否签订框架协议。
   - 对季节性涨价、极端天气涨价是否有预案。

---

## 三、质量与食品安全核查（医院/养老院尤其关键）

1. **验收标准**
   - 明确品种、规格、成熟度、新鲜度、无腐烂、无虫害、无异味。
   - 对叶菜、浆果等易腐水果，约定到货温度和时限。

2. **农残与污染物**
   - 定期索取检测报告，必要时食堂自行抽检。
   - 重点品种：草莓、葡萄、苹果、柑橘等。

3. **包装与标识**
   - 是否有品名、产地、批次、日期等信息。
   - 预包装水果看标签是否规范。

4. **不合格处理机制**
   - 是否承诺退换货、补货时限、赔偿方式。
   - 是否接受食堂现场拒收并记录。

---

## 四、履约与合作记录核查

1. **试供期**
   - 先签短期试供合同，观察1—3个月。
   - 记录准时率、破损率、退货率、投诉次数。

2. **历史履约**
   - 要求提供近1年主要客户名单或合作证明。
   - 向同类机构侧面了解其供货表现。

3. **合同条款**
   - 明确品名、规格、单价、结算方式、违约责任、食品安全责任。
   - 约定“因供应商原因导致食品安全事故”的赔偿与追责。

4. **财务稳定性**
   - 是否存在频繁变更法人、地址、股东。
   - 是否有大量诉讼、被执行、欠税等风险信息。

---

## 五、现场考察与动态管理

1. **实地看**
   - 看仓库、冷库、分拣区、车辆、卫生条件。
   - 看是否有虫鼠害防治、清洗消毒、温控记录。

2. **定期评估**
   - 每月打分：质量、时效、价格、服务、投诉处理。
   - 连续不达标应警告、降量或更换。

3. **备份供应商**
   - 至少保持2家合格供应商，主供+备供。
   - 避免单一供应商断供影响老人、患者用餐。

4. **留样与台账**
   - 每批次留样、记录进货日期、数量、供应商、检测情况。
   - 一旦出现问题可快速追溯。

---

## 六、快速判断口诀

**证照全、货源稳、冷链有、检测做、票据齐、履约好、能退换、有备选。**

如果供应商在这8项里缺3项以上，建议不纳入主供，只能作为临时补充。医院和养老院对食品安全、持续供应要求高，优先选**资质齐全、有同类机构供货经验、能提供检测和追溯、愿意签食品安全责任条款**的供应商。
