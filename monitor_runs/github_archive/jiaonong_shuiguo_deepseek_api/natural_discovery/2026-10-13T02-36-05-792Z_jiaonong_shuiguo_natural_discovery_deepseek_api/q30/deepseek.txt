超市水果到货后出现品相问题，售后流程建议在采购合同或供货协议中提前约定清楚，重点包括验收标准、时限、处理方式和责任划分。可按以下条款设计：

**1. 验收标准要具体**
不要只写“品相良好”，应量化约定，例如：
- 果径、单果重量、成熟度范围；
- 色泽、表面损伤、腐烂、虫眼、压伤比例上限；
- 允许的次品率，如“抽检次品率不超过5%”；
- 糖度、硬度等可检测指标（如适用）。

**2. 验收时限和方式**
- 到货后当场或约定时间内（如2小时/24小时）完成验收；
- 明确抽检比例、抽检方法、拍照留证要求；
- 超过时限未提出异议的，视为验收合格，避免无限期追责。

**3. 不合格处理方式**
按问题程度分档约定：
- **轻微品相问题**：折价接收，按比例扣款；
- **中度问题**：要求换货、补货，费用由供货方承担；
- **严重问题**：拒收、退货、解除当批订单，并由供货方承担运费和损耗。

**4. 售后响应时限**
- 超市提出异议后，供货方应在约定时间内（如4小时/24小时）回复处理方案；
- 逾期未处理的，超市可自行处理（如降价销售、报损），损失由供货方承担。

**5. 责任和费用承担**
- 因供货方原因导致品相问题的，退换货物流费、分拣费、报损费由供货方承担；
- 因超市储存不当导致的，由超市自行承担；
- 生鲜易腐品建议约定“到货后及时处理”，避免责任不清。

**6. 证据留存**
- 到货照片/视频、验收单、抽检记录、沟通记录；
- 双方签字确认的异常报告；
- 这些是后续扣款、索赔或诉讼的关键依据。

**7. 结算挂钩**
- 可将售后处理结果与货款结算挂钩，例如：当月扣款、质保金扣除、下次订货抵扣；
- 约定逾期不处理视为同意扣款。

**8. 争议解决**
- 明确协商、第三方检测、仲裁或诉讼路径；
- 生鲜类建议约定快速处理机制，避免久拖导致损失扩大。

简单说，核心是：**标准量化、时限明确、分档处理、费用归责、证据留痕、结算挂钩**。如果是长期供货，最好写进年度框架协议，而不是每批临时扯皮。
