建议把资料分成“合规资质 + 批次检测 + 溯源凭证”三类来要，重点是**批次可对应**，而不只是要一张过期的通用报告。

1. **供应商主体资质**
- 营业执照
- 食品经营许可证/食品生产许可证（按实际业态）
- 若为种植基地直供：种植主体资质、产地证明或基地备案信息

2. **该批次水果的检测报告**
- 农残检测报告，最好由 CMA/CNAS 资质机构出具
- 报告上要能对应：品名、品种、产地、批次号/采收日期、检测日期
- 检测项目建议覆盖常见高风险农残，如有机磷、氨基甲酸酯、拟除虫菊酯等；有条件可要求全项或按 GB 2763 对应品类项目检
- 不要只收“合格证”或供应商自检单，最好同时有第三方报告

3. **批次溯源与合格凭证**
- 批次号、采收/包装日期、产地、供应商名称
- 食用农产品合格证或产地准出证明
- 进货凭证、送货单、发票或收据
- 若为进口水果：入境货物检验检疫证明、海关报关单等

4. **供应商承诺与责任文件**
- 质量安全承诺书
- 农残超标退换货、赔偿、下架召回条款
- 如可能，签采购合同补充协议，明确抽检不合格责任

5. **到货后可做的动作**
- 每批留样并记录批次
- 对高风险品种做快速检测或送第三方抽检
- 建立供应商档案，按批次索证索票，保存期限一般不少于产品保质期满后6个月；没有明确保质期的，保存不少于2年

简单说：**营业执照/许可证 + 对应批次的第三方农残检测报告 + 合格证/溯源凭证 + 质量承诺**。如果供应商只能提供“一批货一张很久以前的报告”，不能对应你要采购的批次，风险就比较高，建议暂缓采购或要求补检。
