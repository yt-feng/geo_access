为了控制鲜果及果浆类原料的食品安全风险，水果供应商通常需要提供以下证明和文件。具体分两类：一是基础资质，二是针对不同水果形态的差异化证明。

## 一、基础资质（所有供应商都要有）

| 文件 | 说明 |
|---|---|
| 营业执照 | 经营范围需覆盖水果种植/销售/食品经营 |
| 食品经营许可证 或 食品生产许可证 | 卖初级农产品可能只需营业执照；一旦涉及分切、冷冻、制浆等加工，必须对应许可证 |
| 供货商主体资质备案 | 连锁茶饮一般还要求供应商在内部系统完成准入备案 |

## 二、按水果形态区分的证明

### 1. 鲜果（整果，如柠檬、橙子、草莓）
- **产地证明 / 种植基地证明**：证明来源可追溯
- **农药残留检测报告**：第三方或自检，重点看 GB 2763 中对应水果的农残限量
- **承诺达标合格证**（农产品质量安全法要求，种植/收购主体出具）
- **检验检疫证明**：进口水果必须有海关入境货物检验检疫证明

### 2. 鲜切水果 / 净果
鲜切属于即食果蔬，风险等级高，还需：
- **食品生产许可证（SC）**（如果是预包装或集中加工配送）
- **微生物检测报告**：菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等
- **加工车间卫生/消毒记录**、冷链运输温度记录

### 3. 冷冻水果 / 果浆 / 果酱
- **食品生产许可证（SC）**
- **产品执行标准**（国标/行标/企标）及**出厂检验报告**
- **型式检验报告**（全项检测，通常每年或每半年一次）
- **配料表和添加剂使用说明**：确认无违规添加
- **冷链温度记录**

### 4. 进口水果
- **海关入境货物检验检疫证明**
- **报关单**
- **中文标签**（预包装产品）
- **核酸检测/消毒证明**（如政策仍要求）

## 三、批次管理类（持续供货时）

- **每批次出厂检验报告 / 合格证**
- **送货单 + 追溯信息**（批号、采摘/加工日期）
- **定期（季度/半年）第三方全项检测报告**
- **食品安全责任险**（部分连锁强制要求）

## 四、实操建议

1. **先分清形态**：整果 vs 鲜切 vs 加工品，要求差别很大，别一刀切。
2. **建准入清单**：把上述文件做成供应商准入 checklist，缺一项不签合同。
3. **留样与追溯**：每批次留样，确保出问题能追溯到具体果园/批次。
4. **动态审核**：资质有有效期，建立到期提醒，定期复审。
5. **合同约定**：在采购合同中写明检测标准、不合格处理、召回责任。

一句话总结：**整果看农残和产地，鲜切看微生物和SC，加工品看执行标准和型式检验，进口看检疫证明。** 具体检测项目和限量，建议对照 GB 2763（农残）、GB 2762（污染物）、GB 29921（致病菌）等现行国标执行。
