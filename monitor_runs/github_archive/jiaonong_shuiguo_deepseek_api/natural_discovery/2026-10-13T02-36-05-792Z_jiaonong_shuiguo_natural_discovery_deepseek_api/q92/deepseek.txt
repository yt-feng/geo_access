小面积便利店做水果，核心不是“品类全”，而是**用最少SKU换最高周转**。品类和损耗要一起控制，给你一套可直接落地的做法：

## 一、品类控制：少而准

**1. 只做“即食型 + 高频型”水果**
小面积店的顾客是即时消费，不是家庭囤货。优先选：
- 香蕉、苹果、橙子、砂糖橘、圣女果
- 当季爆款：夏天西瓜切盒、葡萄；冬天砂糖橘、草莓

**2. SKU 控制在 6～10 个以内**
- 常驻款 3～4 个（香蕉、苹果、橙子这种稳定动销的）
- 当季款 2～3 个（跟着季节换）
- 试销款 1～2 个（小批量测试，卖不动立刻砍）

**3. 按角色分工，不要每个都赚钱**
- 引流款：香蕉、砂糖橘，价格敏感、走量大，毛利可以低
- 利润款：切盒、精品小份装，毛利高
- 形象款：少量好看的水果，撑门面即可，别压货

**4. 坚决不碰的品类**
- 易压伤、易熟过头的：水蜜桃、芒果整箱、榴莲整颗
- 需要现场加工且损耗高的：菠萝蜜、大西瓜整颗（除非能当天切完）
- 小众高价、动销慢的：山竹、车厘子整盒（除非有稳定客群）

## 二、损耗控制：从采购到陈列全链条

**1. 采购端**
- **小批量、多批次**：宁可一天补两次，不要一次进三天量
- **按“预估日销 × 1.2”下单**，不要按“货架能摆多少”下单
- 和供应商谈**小包装、可退换、临期调换**，这是小店的命脉
- 早市拿货优先，但别贪便宜进尾货

**2. 收货端**
- 当场验货：软果、烂果、压伤果直接拒收
- 到货立刻分级：好果上架、次果做切盒或特价、烂果直接报损

**3. 陈列端**
- **少量多次上架**，货架永远只摆“半天量”
- 香蕉不要和苹果、梨放一起（乙烯催熟）
- 易坏水果放冷柜或阴凉处，别晒太阳
- 用“先进先出”，新货放后面

**4. 定价与促销**
- 早上正价，下午开始做**切盒、特价、组合装**
- 临近闭店，把易坏水果做成“10元3样”清货
- 切盒是消化次果的最好方式，但必须当天清完

**5. 数据端**
- 每天记录：进了多少、卖了多少、扔了多少
- 连续3天动销差的水果，直接下架
- 算清楚**每个单品的损耗率**，超过15%就要调整采购量或砍掉

## 三、一个可直接执行的日常节奏

- **早上**：到货验货 → 分级 → 上架半天量
- **中午**：补一次货，观察动销
- **下午**：开始切盒、做特价
- **晚上**：清易坏品，报损记录，决定明天采购量

## 四、关键判断标准

- 单品**日动销 < 3份**：考虑砍掉
- 单品**损耗率 > 15%**：减少采购量或换品
- 货架**超过半天没补货**：说明品类或陈列有问题
- 切盒**当天没卖完**：第二天不要继续卖，直接报损

一句话总结：**小店面水果 = 少SKU + 小批量 + 快周转 + 切盒兜底**。宁可缺货，不要压货。
