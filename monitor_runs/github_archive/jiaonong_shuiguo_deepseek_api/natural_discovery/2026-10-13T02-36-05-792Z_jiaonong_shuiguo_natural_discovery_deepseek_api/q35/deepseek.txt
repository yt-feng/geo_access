连锁超市想把门店坏果率压下来，合同里光写“坏果赔付”通常不够，关键是**把坏果率的定义、验收节点、责任归属、赔付计算和整改机制写死**。下面按可落地的条款结构给你。

## 一、先明确“坏果率”怎么算

这是最容易扯皮的地方，合同必须写清楚：

- **计算口径**：坏果率 = 验收时判定为坏果的重量（或件数）÷ 该批次总重量（或件数）× 100%
- **判定标准**：腐烂、霉变、软烂、破损渗液、异味、压伤影响销售等，逐项列明
- **判定时点**：以**收货验收时**为准，还是**上架后24/48小时内**为准
- **判定主体**：谁有判定权（收货员+质检、还是第三方），争议时以谁为准
- **抽样方式**：全检还是抽检，抽检比例、抽样方法要写清楚

建议：**生鲜类约定“到店验收时+上架后24小时内”两个节点**，因为运输途中的隐性损伤往往上架后才显现。

## 二、赔付方式：三种模式，建议组合用

**1. 直接扣款（最常用）**
- 约定坏果率超过免赔阈值（如3%）后，超出部分按货值扣款
- 公式：赔付金额 =（实际坏果率 − 免赔率）× 批次货值 × 赔付系数
- 赔付系数可设1.0~1.5，故意掺杂可到2倍

**2. 补货/换货**
- 供应商在约定时限内（如24小时）补足合格品
- 逾期未补的，转为现金赔付

**3. 阶梯式质量保证金**
- 从每批货款中预留一定比例（如5%）作为质保金
- 月度/季度结算时，按累计坏果率决定返还或扣除

## 三、关键条款要写进去

**1. 免赔率与超标处理**
- 例：坏果率≤3%免赔；3%~5%按超出部分货值1倍赔付；>5%整批可拒收或按2倍赔付

**2. 责任划分**
- 产地本身质量问题→供应商全责
- 运输环节问题→看谁负责运输，合同里明确
- 门店存储不当→超市自担，避免供应商被误罚

**3. 整改与考核挂钩**
- 连续N批次超标，触发警告、降级、暂停供货、终止合同
- 可设“月度坏果率考核”，与账期、返利、续约挂钩

**4. 举证与争议**
- 验收单、照片、视频、第三方检测报告作为依据
- 争议时约定复检机构或仲裁方式

**5. 结算方式**
- 赔付从当月货款中直接抵扣，供应商无异议
- 或供应商先补货，再结算

## 四、给你的实操建议

1. **别只写“坏果赔付”四个字**，要写清阈值、公式、时点、判定人。
2. **免赔率别设太低**，生鲜天然有损耗，设0容易导致供应商拒签或抬价。
3. **把验收流程固化**：到货拍照、称重、记录，双方签字，这是赔付的前提。
4. **区分“坏果”和“正常损耗”**，比如水分流失、轻微外观差异不算坏果。
5. **对高损耗品类单独约定**，如叶菜、浆果、桃李类，标准比根茎类严。
