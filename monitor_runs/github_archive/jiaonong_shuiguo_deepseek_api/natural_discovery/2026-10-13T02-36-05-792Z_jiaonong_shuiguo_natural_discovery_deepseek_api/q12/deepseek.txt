水果店卖菠萝的损耗，主要来自**过熟腐烂、运输磕碰、黑心、以及顾客挑剩**。采购时判断“合适熟度”，核心是：**不要进全熟果，也不要进完全青硬的生果，优先选“即将转熟、能放3～5天”的果。**具体可以按下面几点判断：

1. **看果皮颜色**
   - 全青、发暗、无光泽：太生，糖度低、酸，后熟慢，短期卖相差。
   - 青中带黄、尤其是果眼周围开始泛黄：比较合适，通常还能放几天，适合门店周转。
   - 整体金黄、底部也开始黄：熟度高，适合1～2天内卖完，但损耗风险大。
   - 有明显褐斑、渗汁、发软：已经过熟或开始坏，不建议采购。

2. **看果眼和果皮状态**
   - 果眼扁平、清晰，果皮紧实：熟度适中。
   - 果眼鼓胀、发亮、像要撑开：往往接近过熟。
   - 果皮发皱、失水：放久了，品质下降。
   - 有黑点、软塌、汁液外渗：不要。

3. **闻气味**
   - 几乎无味：偏生，可少量进，但最好能放。
   - 有淡淡菠萝香、不刺鼻：合适。
   - 香味浓、带发酵酒味：过熟，损耗高。
   - 有酸腐味：已坏。

4. **摸硬度**
   - 硬、按不动：偏生。
   - 稍有弹性、整体紧实：合适。
   - 一按就陷、局部软：过熟或内部开始坏。
   - 重点摸底部和果眼密集处，这两个地方最容易先坏。

5. **看底部和切口**
   - 底部干燥、无霉、无渗液：正常。
   - 底部发黑、发黏、有霉点：不要。
   - 如果是已切顶或切底的，切口发褐、发酸、出水，不要。

6. **看叶片**
   - 叶片青绿、有韧性：相对新鲜。
   - 叶片干枯、发黄、一拔就掉：放久了，熟度或新鲜度差。
   - 但叶片状态只能辅助，不能作为唯一标准。

7. **分季节和用途采购**
   - 夏天温度高：后熟快，尽量进青黄果，少进金黄果。
   - 冬天温度低：可适当进熟一点，但不要全熟。
   - 如果店里现削现卖多：可进略生一点，减少腐烂。
   - 如果整果礼盒或顾客即买即吃多：可进青黄到微黄，但控制数量。

8. **实操采购建议**
   - 一批货里做搭配：大部分选“青中带黄、果皮紧实、淡香”的果，少量选“较黄、马上能卖”的果。
   - 不要整批进一个熟度，否则要么一起生、要么一起熟、一起烂。
   - 进货后按熟度分级：熟度高的放前台优先卖，青一点的放后面或稍阴凉处。
   - 菠萝不要堆太厚，避免压伤；底部容易坏，最好单层或分层垫软。
   - 每天挑一次，把开始软、香味浓、底部发黑的先削盒卖或特价处理。

简单记：**采购菠萝，选“青黄相间、果皮紧实、淡香、底部干净”的果最稳。全青太生，全黄太熟，有酒味、软塌、渗汁的坚决不要。**
