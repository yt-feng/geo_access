水果店做小区团购，供应商要重点支持这几类服务，否则后面很容易卡在损耗、履约和售后上：

1. **稳定供货与每日报价**
   - 能提前给次日/次周可供品类、规格、产地、到货时间。
   - 价格随行就市，但最好有“团购爆品价”或阶梯价：达到多少箱/多少斤更便宜。
   - 能预留库存，不是今天报完明天没货。

2. **按团购规格分拣打包**
   - 支持按份/按箱/按斤预包装，比如5斤装、10斤装、家庭装、尝鲜装。
   - 能贴标签：品名、规格、产地、食用建议、售后电话。
   - 最好能代分拣、去烂果、简单分级，减少你店里二次人工。

3. **品控与退换售后**
   - 承诺坏果、烂果、缺斤少两的赔付标准，比如按比例赔、拍照即赔、下次补货抵扣。
   - 到货后有质量问题能在几小时内响应，不让你自己承担全部售后。
   - 对团购批次留样或记录，方便追溯。

4. **冷链/保鲜与配送支持**
   - 易坏水果如草莓、蓝莓、荔枝、榴莲、车厘子，需要冷链或冷藏车。
   - 能送到你店里，也能支持“送到小区自提点”或“分小区集单配送”更好。
   - 配送频次稳定，最好支持次日达、隔日达，避免团购开团后断货。

5. **起订量与账期灵活**
   - 小水果店现金流紧，供应商最好支持低起订量、混批、少量多频。
   - 可谈账期：现结、周结、月结，或押金+账期。
   - 团购爆单时能临时加单，不临时抬价。

6. **营销与素材支持**
   - 提供水果图片、视频、卖点文案、产地故事、检测报告。
   - 支持试吃样品、地推物料、团购海报。
   - 能配合你做“今日爆品”“接龙套餐”“满减/满赠”。

7. **数据与对账支持**
   - 每批货有清晰单据：品类、规格、数量、单价、金额、损耗。
   - 支持微信/表格/小程序对账，退货、补货、扣款记录清楚。
   - 能按小区、按团购批次统计供货，方便你算毛利。

8. **合规与资质**
   - 营业执照、食品经营/流通相关资质、水果检测报告或产地证明。
   - 特别是进口水果，要有报关、检疫等合规文件。
   - 能开票或提供收据，方便你后续做企业团购。

你挑供应商时，最该先问这5个问题：
- 团购价能不能按量阶梯？
- 坏果怎么赔，多久内响应？
- 能不能按我要求的规格分拣打包？
- 易坏水果能不能冷链/稳定次日达？
- 爆单时能不能优先保供，不临时涨价？

如果只能选最重要的，优先看：**品控赔付、分拣打包、稳定配送**。这三项决定你能不能长期做小区团购，而不只是做一次。
