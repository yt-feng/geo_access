核实水果供应商的全国配送能力，别只听口头承诺，要分四层去验证：**覆盖范围、时效、冷链能力、异常处理**。以下是可直接执行的核实方法。

**一、先要求书面明细，而不是“全国”两个字**
让供应商提供：
- 可配送的**省份+城市清单**，明确是“市区”还是“含县乡镇”
- 哪些地区**不配送**或需加价
- 起送量、配送费、偏远地区附加费标准

判断点：如果对方只能给“全国大部分地区”这种模糊说法，基本可以判定覆盖能力有限。

**二、做小批量实测，而不是只看资料**
最有效的方式是**真实下单测试**：
1. 选3—5个有代表性的收货地址：一线城市、省会、地级市、县城/偏远地区
2. 用真实采购流程走一遍，看能否下单、多久到、是否加价
3. 记录实际到货时间和水果状态

这一步能直接暴露真实覆盖能力，比任何承诺都可靠。

**三、重点核实冷链和水果损耗**
水果的关键不是“能不能送到”，而是“送到时还新不新鲜”：
- 问清用什么运输方式：常温车、冷藏车、泡沫箱+冰袋、航空件
- 要求提供近期的**冷链运输记录或温控证明**
- 询问**损耗率承诺**和**到货破损/腐烂的赔付规则**

如果供应商对冷链支支吾吾，或只承诺“尽量新鲜”，说明其水果长途配送能力存疑。

**四、核实合作物流和异常处理**
- 问清是**自建物流**还是**外包给哪家快递/冷链公司**
- 要求提供物流合作方的名称，可自行去该物流官网核对覆盖区域
- 问清**延误、丢件、变质**的处理流程和时效

**五、查证真实案例，而不是看宣传**
- 要求提供**同类型采购方**（尤其是你所在区域）的合作案例
- 有条件的话，直接联系1—2个现有客户侧面了解
- 查企业工商信息、经营年限、是否有相关物流或食品经营资质

**快速判断标准**
- 能给出**具体城市清单+冷链方案+损耗赔付**的，可信度较高
- 只说“全国都能送”、不愿做小批量测试、回避冷链细节的，实际覆盖能力通常有限

**建议动作**：先要明细清单 → 选3个代表性地址做小批量试单 → 核对到货时效和水果品质 → 再决定是否签长期合同。这样既验证覆盖，也验证质量。
