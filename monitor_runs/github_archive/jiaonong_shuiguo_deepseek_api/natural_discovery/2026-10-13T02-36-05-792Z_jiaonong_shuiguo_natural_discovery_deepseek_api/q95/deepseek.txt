选学校食堂水果供应商，核心不是“找最便宜的”，而是先保证**稳定供货、食品安全可追溯、账期和结算可控**，再比价格。可以按下面步骤做。

**1. 先明确采购标准**
- 品类：香蕉、苹果、橙子这类常见水果，优先选耐储存、易分餐、损耗低的品种。
- 规格：苹果、橙子按单果重量分档，比如苹果 75-85mm、橙子 65-75mm；香蕉按成熟度分 1-3 成熟、4-5 成熟，避免到货即过熟。
- 质量：无腐烂、无大面积机械伤、无虫害，农残检测合格。
- 频次：食堂通常每周 2-3 次配送，香蕉可单独提高频次，苹果橙子可适当降低。
- 结算：月结还是周结，是否含税、含运费、含损耗。

**2. 供应商来源优先顺序**
1. 当地大型农产品批发市场里有固定档口的批发商：响应快，适合小批量、多频次。
2. 产地合作社或种植基地直供：价格有优势，但起订量大，适合苹果、橙子这类耐储水果。
3. 专业水果配送公司：能提供检测报告、分拣、配送和售后，适合学校这种需要票据和台账的场景。
4. 大型商超或生鲜平台的企业采购渠道：价格偏高，但合规性和票据较稳。

**3. 必须核验的资质**
- 营业执照、食品经营许可证或食用农产品相关经营资质。
- 供货凭证：产地证明、进货票据、批发市场交易凭证。
- 检测报告：农残快检或第三方检测报告，至少能覆盖常见农残项目。
- 人员健康证：涉及分拣、切配、配送的人员。
- 保险：食品安全责任险优先。

**4. 实地考察看什么**
- 有没有冷库、分拣区、清洗区，是否生熟分开。
- 水果堆放是否离地离墙，有没有防鼠防虫措施。
- 损耗怎么处理：烂果是否包退换，退货是否及时补货。
- 配送车辆是否清洁，是否与生鲜、化学品混装。
- 能不能提供每日或每批次快检记录。

**5. 比价和试供**
- 不要只看单价，要算“到货可食用成本”：单价 + 运费 + 损耗 + 退换货成本。
- 先让 2-3 家试供 2-4 周，按同一规格、同一时间送同批水果。
- 试供期重点看：到货合格率、重量是否足、成熟度是否稳定、临时加单响应、退换货速度。
- 香蕉容易催熟和碰伤，试供时单独打分。

**6. 合同里写清楚**
- 品名、规格、产地、单价、浮动机制。
- 配送时间、频次、最低起送量、临时加单响应时间。
- 验收标准：抽检比例、不合格处理、退换货时限。
- 食品安全责任：若出现农残超标或食安问题，供应商承担检测、赔偿和法律责任。
- 结算方式：账期、发票类型、对账周期。
- 违约和退出机制：连续几次不合格可终止合作。

**7. 简单判断标准**
优先选同时满足这几条的：
- 能稳定每周送 2-3 次；
- 能提供每批次快检或进货凭证；
- 烂果包退换，24 小时内补货；
- 价格不是最低，但到货合格率稳定在 95% 以上；
- 愿意签食品安全责任条款。

如果学校规模不大，建议“1 家主供应商 + 1 家备选供应商”。主供负责日常，备选用于应急和比价，避免单一供应商断供或抬价。
