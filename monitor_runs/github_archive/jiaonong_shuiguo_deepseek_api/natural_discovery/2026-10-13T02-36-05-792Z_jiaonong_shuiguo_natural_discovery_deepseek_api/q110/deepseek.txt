# 产地直采≠一定更便宜

产地直采能去掉中间环节，但“更便宜”是有条件的，不是必然。

## 会便宜的情况
- **量大且稳定**：能填满整车、持续走货，产地愿意给批发价。
- **绕过多个中间商**：原本经过“产地代办→一级批发→二级批发→你”，直采能砍掉2-3层加价。
- **应季集中采购**：产地货源充足时议价空间大。
- **长期合作包园/包地块**：锁定产能，价格通常低于市场调剂价。

## 反而更贵的情况
- **量小**：买几百斤却要产地单独发货，物流、人工、损耗摊下来比去批发市场贵。
- **品控和损耗算不清**：产地直采通常要自己承担分级、次果、运输损耗。中间商卖的“净果价”已经把这些风险算进去了，直采看似单价低，实际到手成本可能更高。
- **物流成本高**：冷链、专车、空运费用在小批量时非常不划算。
- **产地临时涨价**：直采没有稳定协议时，产地说涨就涨，你还没有备选渠道。
- **资金和账期成本**：产地通常要现款甚至预付，占用资金；批发市场可能有账期。
- **售后无保障**：坏果、缺斤少两要找产地扯皮，中间商反而能兜底换货。

## 判断是否真便宜，算这个账
**到手综合成本 =（采购价 + 物流 + 人工 + 包装 + 损耗 + 资金占用）÷ 实际可用净果重量**

只看“采购单价”几乎一定会被误导。把净果率、损耗率、账期都折算进去，才看得出直采到底省没省。

## 实操建议
1. **先比到手净成本**，不要比报价。
2. **小批量阶段**：走批发市场或靠谱代办更划算，直采等量起来再做。
3. **要直采就谈三件事**：分级标准、损耗赔付、账期/结算方式。
4. **至少备两个产地或一个批发渠道**，防止被单一产地卡价。
5. **季节性品类**（如荔枝、西瓜）直采优势明显；**全年常规品**（如苹果、橙子）除非量大，否则直采未必占优。

一句话：**直采是“规模+品控+物流”都到位时的降本手段，不是天然更便宜的采购方式。**
