水果锁价能锁多久，没有统一标准，主要看品类、季节、供应商类型和你的采购量。大致可以这样判断：

**1. 常规锁价周期**
- **国产应季水果**：一般很难锁超过 **1～2周**，很多供应商只接受 **3～7天**。因为产地天气、上货量、批发市场行情波动太快。
- **国产反季/库存水果**：如冷库苹果、梨，通常可锁 **15～30天**，量大可谈到 **1～2个月**。
- **进口水果**：如智利车厘子、泰国榴莲、新西兰奇异果，受船期、汇率、关税影响，常见锁价 **1～4周**，少数大渠道能锁 **1～2个月**。
- **长期合同**：大型商超、连锁水果店和产地合作社/大型批发商，可能签到 **季度价、半年价甚至年度框架价**，但通常不是完全固定单价，而是“保底价+浮动机制”或“随行就市但给折扣”。

**2. 供应商愿意锁价的前提**
- 你采购量稳定且可预测，比如每周固定要多少件。
- 你愿意付定金、保证金，或承诺最低采购量。
- 锁价不是锁死市场价，而是约定一个价格区间或调整规则。
- 对易腐、价格波动大的水果，供应商通常只锁短期。

**3. 实操建议**
- **短期锁价**：7～15天，适合叶菜类、浆果类、应季瓜果。
- **中期锁价**：30天左右，适合苹果、梨、柑橘、进口香蕉等相对稳定的品类。
- **长期合作**：签框架协议，约定“基准价+市场波动调整幅度”，比如批发市场价涨跌超过10%再调价。
- **分品类谈**：不要所有水果都要求锁一个月，供应商很难接受，容易在质量或供货上找补。
- **写清条款**：锁价周期、数量、质量标准、付款方式、违约金、调价触发条件都要写进合同。

**一句话结论：**
普通水果锁价通常 **7～30天**；进口和耐储水果可谈到 **1～2个月**；想锁半年以上，一般只能做框架协议或价格区间，很难完全固定单价。
