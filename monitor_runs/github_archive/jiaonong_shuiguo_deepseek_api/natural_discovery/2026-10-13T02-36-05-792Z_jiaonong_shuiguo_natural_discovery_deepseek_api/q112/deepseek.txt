水果采购合同中的坏果率赔付标准，法律上没有统一规定，主要看合同约定和行业惯例。以下是可操作的判断依据：

**一、常见约定区间**

| 坏果率 | 通常处理方式 |
|--------|-------------|
| ≤3% | 多数视为合理损耗，不予赔付 |
| 3%–5% | 可协商扣款或部分赔付 |
| 5%–10% | 一般可要求按比例赔付或换货 |
| >10% | 通常可要求全额赔付、退货或解除合同 |

**二、关键前提：合同里必须有明确约定**

赔付能否主张，取决于合同是否写清了：
- 坏果率的计算方式（按数量、重量还是货值）
- 抽检方法（全检还是抽检、抽检比例）
- 验收期限（货到后几小时内提出异议）
- 赔付方式（扣款、补货、退货、违约金）

如果合同没约定，只能依据《民法典》第577条（违约责任）和实际损失主张，举证难度大。

**三、实操建议**

1. **合同里写明**：例如"坏果率超过5%，超出部分按货值双倍扣款；超过10%，买方可拒收并要求赔偿"。
2. **约定验收流程**：到货后24小时内完成抽检，超期视为合格。
3. **保留证据**：到货拍照、过磅单、抽检记录、双方签字确认单。
4. **分级设定**：不同品类（如草莓、苹果）耐受度不同，最好按品类分别约定。

**四、没有合同约定时怎么办**

可参照行业惯例或双方交易习惯，主张"超过合理损耗部分"的损失。合理损耗一般认3%–5%，但需结合品类、运输距离、季节综合判断。

**一句话结论**：想有赔付依据，合同里就要写明阈值；常见做法是**超过5%可要求赔付，超过10%可拒收或索赔**。具体数字双方协商确定即可。
