为公司下午茶批量采购水果，选供应商时建议按下面几个维度来判断，能比较快筛掉不靠谱的。

**一、先明确自己的需求**
- 人数和预算：多少人、人均预算多少，决定采购量和档次。
- 频次：一次性活动，还是每周/每月固定配送。
- 形式：整果、果切拼盘、还是混合。果切方便但保质期短、对冷链要求高。
- 配送时间：能否精确到某个时间段送到公司。

**二、供应商类型怎么选**
- 本地水果批发市场商户：价格低，适合量大、能自提或短途配送，但配送和售后不稳定。
- 生鲜电商/企业采购平台：如各类B2B生鲜平台，配送和开票规范，适合固定频次，价格中等。
- 专业果切/下午茶供应商：省事、品相好，适合直接摆台，但单价偏高、需冷链。
- 本地果园/合作社直供：新鲜、性价比可能高，适合当季单品，但品类少、配送能力参差。

**三、重点核验这几项**
1. **配送能力**：是否支持批量、指定时间、冷链；超时或破损怎么赔。
2. **品控**：能否提供样品或试单；坏果率标准是多少、怎么补。
3. **资质与票据**：营业执照、食品经营许可（尤其果切）、能否开专票。
4. **价格结构**：是否含配送费、包装费、切配费；起送量和账期。
5. **售后**：坏果、少送、迟到如何处理，是否有明确时限。

**四、实操建议**
- 先小批量试单1–2家，重点看准时率、坏果率和口感。
- 固定频次的话，签简单协议，写清品类、规格、单价、配送时间、赔付标准。
- 不要只比单价，把配送费、损耗、补货成本一起算总成本。
- 当季水果优先，反季水果贵且品质不稳定。
