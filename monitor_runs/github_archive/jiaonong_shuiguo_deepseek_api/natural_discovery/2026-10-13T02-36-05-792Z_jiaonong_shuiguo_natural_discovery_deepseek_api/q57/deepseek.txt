结论先说：**大多数餐饮连锁采购水果，优先采用“中央厨房/配送中心统一收货”，门店只做二次验收和少量应急补货。**但要不要完全统一，取决于水果品类、门店密度、损耗敏感度和管理能力。

下面给你一个可判断的标准。

## 一、两种模式的核心差异

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 品控标准 | 容易统一，可集中验货 | 各店标准不一，波动大 |
| 采购议价 | 强，集中采购量大 | 弱，单店量小 |
| 损耗管理 | 可集中分拣、催熟、冷藏 | 分散损耗，难统计 |
| 配送成本 | 需要冷链/配送体系 | 供应商直送，省配送 |
| 门店操作 | 门店省事，接货即可 | 店长/厨师要验货、称重、退货 |
| 灵活度 | 较低，临时加货慢 | 高，适合小店/单店 |
| 食安追溯 | 强，批次统一可控 | 弱，批次分散 |
| 资金/结算 | 总部统一对账 | 门店多、对账复杂 |

## 二、建议：什么情况选统一收货

满足以下条件，**优先中央厨房统一收货**：

1. **门店数量 ≥ 5～10 家**，且水果是高频刚需。
2. **水果用于标准化产品**，比如沙拉、果茶、甜品、套餐配果。
3. **有冷链或准冷链能力**，至少能做到冷藏分拣、当日/次日配送。
4. **总部有品控或采购团队**，能制定验收标准。
5. **需要统一品牌口感**，比如每家店西瓜甜度、柠檬大小要一致。
6. **供应商愿意配合大批量分级供货**。

统一收货的最大价值不是“省事”，而是：
- 把品控从门店经验变成总部标准；
- 把损耗从门店黑箱变成可统计成本；
- 把采购从分散议价变成集中议价；
- 把食安责任从门店分散变成总部可追溯。

## 三、什么情况可以门店分开收货

以下情况，门店分开收货更划算：

1. **门店很少**，比如 1～3 家，建中央厨房不经济。
2. **水果品类极不标准**，比如门店现切果盘，需要每天看货挑货。
3. **本地供应商直送成本明显更低**，且能保证新鲜度。
4. **门店分散在多个城市**，中央配送半径太长，水果损耗反而更高。
5. **水果只是少量辅助配料**，不是核心产品。
6. **总部没有品控和配送能力**，统一收货只会变成“统一压货”。

## 四、更推荐的实际方案：混合模式

对多数连锁餐饮，最稳的是：

**中央厨房统一采购 + 统一验收标准 + 统一分拣配送 + 门店二次验收 + 少量应急直送。**

具体做法：

1. **核心水果统一收货**
   - 比如柠檬、西瓜、芒果、草莓、蓝莓等标准化程度较高的。
   - 由中央厨房按批次验收糖度、成熟度、重量、外观。

2. **易损/急用水果门店直送**
   - 比如熟透牛油果、即食香蕉、当天急需的鲜果。
   - 供应商直送门店，但必须按总部标准验收。

3. **建立统一验收标准**
   - 品种、规格、成熟度、糖度、重量、瑕疵率、到货温度。
   - 门店只能按标准收货，不能凭感觉。

4. **损耗按批次归属**
   - 中央厨房分拣损耗归中央厨房；
   - 门店保存损耗归门店；
   - 配送损耗归配送方。
   - 这样才能判断问题出在哪。

5. **设置应急补货机制**
   - 门店可临时向本地供应商补货，但需总部备案。
   - 应急采购价格和品质要纳入月度复盘。

## 五、决策公式

你可以直接用这个判断：

**如果“统一收货带来的品控提升 + 采购降本 + 损耗可追踪” > “配送成本 + 中央厨房运营成本 + 灵活性损失”，就选统一收货。**

更简单地说：

- **5 家店以下、水果非核心、无冷链**：门店分开收货。
- **5～10 家店、水果较重要、有基础配送**：混合模式。
- **10 家店以上、水果核心、有中央厨房/冷链**：中央厨房统一收货。

## 六、最终建议

如果你问的是“长期做连锁”，答案通常是：

**中央厨房统一收货为主，门店分开收货为辅。**

但不要一刀切。水果和冻品、粮油不同，它成熟度变化快、损耗高。最忌讳的是：总部为了统一而统一，结果配送半径过长、门店缺货、损耗反而更高。

所以正确做法是：
**统一标准、统一采购、分级配送、门店二次验收、应急直送补充。**
