做水果生意，选供应商时最容易被忽视的，往往不是价格和品种，而是那些“出问题时才暴露”的细节。下面按优先级列出来：

**1. 损耗责任怎么分**
这是最容易吃亏的地方。要明确：运输途中烂果、到货后次品率超过多少算谁的？很多供应商口头说“包赔”，但实际操作时按“整车均价”折算，或者要求你提供开箱视频、当天反馈，过期不认。一定要在合作前把赔付标准、时效、举证方式写清楚。

**2. 供货稳定性，而不是单次质量**
一次好货不代表长期稳定。要观察供应商在旺季、雨季、节假日、产地减产时的表现。很多小供应商平时货好，一到缺货就抬价或直接断供。可以问：你主要从哪几个产地拿货？如果这个产地受灾，替补方案是什么？

**3. 分级标准是否一致**
同一批“一级果”，不同供应商的标准可能差很多。要约定具体的规格：单果重量范围、糖度、果径、着色度、允许的瑕疵比例。最好有文字或图片标准，避免每次靠感觉扯皮。

**4. 账期和结算方式**
现结、周结、月结，直接影响你的现金流。要问清楚：是否有押金、是否支持部分退货、退货后怎么扣款。有些供应商低价吸引你，但要求全款现结，一旦压货你的资金链会很紧。

**5. 冷链和运输细节**
水果损耗很大程度在运输环节。要了解：是否全程冷链、装车温度、到货时间、卸货责任。尤其是夏季和远距离运输，很多供应商用普通货车省成本，到货后烂一半，责任却推给“天气”。

**6. 产地信息和可追溯性**
长期做，最好知道货从哪个产区、哪个合作社或农场来。这不仅关系到品质稳定，也关系到出问题时能否追责。有些供应商其实是二手甚至三手贩子，中间加价多，信息不透明。

**7. 对你的客户群是否匹配**
供应商的货适合高端精品店还是社区团购？如果他的分级偏粗、包装简陋，你拿去做高端客户就会售后不断。选供应商前，先明确自己的客群和定位。

**8. 合作初期的试单机制**
不要一上来就大批量。先小批量试三到五次，覆盖不同天气和时段，观察到货质量、损耗率、售后响应速度。试单期就能看出对方是否靠谱。

**9. 合同和口头承诺**
水果行业很多靠人情，但长期稳定一定要有简单合同或书面确认。至少包括：品名、规格、单价、数量、交货时间、验收标准、损耗赔付、结算方式、违约处理。

**10. 供应商的财务健康度**
这点常被忽略。如果供应商本身资金紧张，可能会在缺货时优先供大客户，或者突然提价、断供。可以通过合作中的付款节奏、催款频率、员工流动等侧面判断。

总结一句：**价格决定你赚多少，损耗和责任划分决定你亏多少。** 选供应商时，把“出问题怎么办”问清楚，比只谈价格重要得多。
