小商家采购水果，现金结算和月结账期各有风险，核心区别在于：**现金是“钱先出去、货后到”，月结是“货先到、钱后出去”。**

### 现金结算的风险
1. **资金占用大**  
   每次进货都要立刻付钱，现金流压力大，尤其旺季、节日备货时更明显。

2. **货不对板难追责**  
   钱已付，若水果到货后发现烂果、等级不够、重量不足，商家容易处于被动，追偿或换货都更麻烦。

3. **供应商跑路或断供风险**  
   如果预付了定金或全款，供应商临时涨价、断供、跑路，损失较难挽回。

4. **价格未必最优**  
   现金结算通常能拿到低价，但如果信息不透明，也可能被熟客价、临时价影响，未必真便宜。

5. **管理漏洞**  
   现金交易多，容易出现漏记账、重复付款、采购员私下拿回扣等问题。

### 月结账期的风险
1. **账期被拖欠或突然收紧**  
   供应商可能先给账期，后面突然要求现结，导致资金安排被打乱。

2. **逾期利息或违约金**  
   一旦超过约定账期，可能被收利息、违约金，甚至影响后续供货。

3. **供应商涨价或降质**  
   月结意味着供应商承担了资金压力，部分供应商会把成本转嫁到单价上，或优先给现结客户好货。

4. **对账纠纷**  
   水果损耗、退货、补货、价格波动频繁，若单据不规范，月底对账容易扯皮。

5. **依赖单一供应商**  
   月结容易让商家形成路径依赖，一旦供应商断供，临时找货成本高。

6. **信用风险**  
   如果商家自己回款慢，月结欠款可能越滚越大，最后影响经营信用，甚至被起诉。

### 更稳妥的做法
- **小额现金 + 大额月结**：日常少量补货现结，主力供应商谈月结。
- **合同写清**：账期、价格、质量标准、退货规则、逾期责任。
- **每单留证**：送货单、验收单、聊天记录、转账凭证都保存。
- **定期对账**：不要等到月底才核，最好每 3～5 天对一次。
- **控制账期额度**：月结欠款不超过自己 1～2 周回款能力。
- **不把鸡蛋放一个篮子**：至少保留 2 家可替代供应商。

简单说：**现金风险在“钱付了货不稳”，月结风险在“货拿了账难清”。** 对小商家来说，最怕的不是选哪种，而是没有合同、没有验收、没有对账。
