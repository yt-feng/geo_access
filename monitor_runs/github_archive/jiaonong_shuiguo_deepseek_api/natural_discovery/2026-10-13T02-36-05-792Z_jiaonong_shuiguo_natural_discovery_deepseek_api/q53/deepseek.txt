餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找“稳定、少量也送、损耗低、对账简单”的渠道。可以按下面优先级选：

1. **本地水果批发市场的固定档口**
   - 适合：每天用量不大，但能固定时间采购。
   - 优点：价格通常比零售低，品类灵活，可以现场看货。
   - 省心做法：固定1-2家档口，加微信，每天发需求，让对方按你的标准配货；谈好“坏果包换/补”。不要每天临时换摊，否则品质和价格都不稳。
   - 注意：要早起，通常凌晨到上午去拿货；如果店里没人去，可以问档口能不能同城配送或拼车送。

2. **本地生鲜配送平台/B2B平台**
   - 例如美菜、快驴、菜划算这类，具体以你所在城市实际覆盖为准。
   - 适合：不想自己跑市场，要求每天送、开票、对账方便。
   - 优点：线上下单，次日或当日送，售后有流程。
   - 缺点：少量订单可能起送价高、配送费不低，水果品质有时看批次。
   - 省心做法：先试1-2周，重点看准时率、坏果率、售后响应。适合作为主渠道或备用渠道。

3. **本地水果店/社区精品水果店合作**
   - 适合：每天只要几斤、几种，量很小。
   - 优点：离得近，沟通快，临时补货方便。
   - 缺点：单价偏高，长期成本不低。
   - 省心做法：谈月结或周结，固定每天几点送，按你的菜单给推荐当季水果。

4. **产地/一级供应商直供**
   - 适合：单品类用量稳定，比如每天固定要柠檬、橙子、西瓜等。
   - 优点：价格低、品质稳定。
   - 缺点：通常起订量大，不适合“每天少量多品种”。
   - 建议：只对用量最大的1-2个单品找产地或一级商，其余走本地配送。

5. **同行拼单/中央厨房配送**
   - 如果你附近有餐饮同行，可以拼单找同一个供应商，凑起送量。
   - 优点：拿到批发价，配送也愿意接。
   - 缺点：需要协调分货和结算。

**最省心的组合建议：**
- 主渠道：本地生鲜B2B平台或批发市场固定档口，负责每天基础用量。
- 备用渠道：附近水果店，负责临时缺货、急用。
- 大单品：如果某一种水果每天用量稳定，单独找一级商或产地直供。

**选供应商时重点问清这6件事：**
1. 每天少量送不送？起送量多少？
2. 几点前下单，几点送到？
3. 坏果、烂果怎么赔？是补货还是退款？
4. 价格是每天变，还是周价/月价？
5. 能不能开票？能不能月结？
6. 临时加单、换品种行不行？

**实操上最省心的做法：**
- 固定供应商，不要每天换。
- 固定每周菜单和水果品种，让供应商提前备货。
- 收货时当场抽检、拍照，坏果及时发群里确认。
- 用微信或表格记录每天品种、数量、单价、售后，月底对账。
- 先试合作1-2周，再决定是否长期。

如果你每天用量真的很少，比如每天只有几斤，优先找**附近水果店+本地生鲜平台备用**，比找批发商更省心。量稍微稳定后，再转批发市场固定档口或B2B平台。
