水果店遇到坏果，和供应商怎么结算或赔付，关键看**坏果是在到货验收前发现，还是到货后存放/销售中才发现**，以及你们事先有没有约定。通常可以按下面几种方式处理：

1. **到货当场发现坏果**
   - 先拍照、录视频，保留送货单、过磅单、聊天记录。
   - 能拒收的就直接拒收，剔除坏果后按实际好果数量结算。
   - 如果已经整车/整批收货，可以当场和供应商确认坏果数量，按“好果重量/件数”结算，坏果部分不计价或由供应商补货。
   - 常见做法：坏果扣款、补货、换货，或者下一车抵扣。

2. **到货后短时间内发现坏果**
   - 如果合同或行业惯例有“到货后24小时/48小时内可反馈”的约定，要在期限内通知供应商。
   - 超过期限，供应商可能不认，尤其是水果本身易腐，责任容易扯皮。
   - 能证明是运输损伤、产地问题、催熟问题、冷库问题的，可以要求供应商承担。
   - 如果是自己存放不当、温度不对、挤压造成的，通常只能自己承担。

3. **结算方式**
   - **扣重结算**：按实际好果重量结算，坏果不计价。
   - **扣款结算**：按坏果金额从货款中扣除。
   - **补货/换货**：供应商下次补同等数量好果。
   - **折扣结算**：整批按比例打折，比如坏果率10%，整批按90%结算。
   - **退货退款**：坏果比例很高时，整批退回，供应商退款或换货。
   - **保证金/质保金扣除**：如果有长期合作保证金，可从保证金中扣。

4. **赔付比例怎么谈**
   - 轻微坏果：一般扣坏果部分，或按3%—5%折让。
   - 明显坏果：按实际坏果数量扣款，或要求补货。
   - 大面积坏果：可要求退货、退款，甚至赔偿运费、人工分拣费、损耗费。
   - 如果已经影响销售，比如整批烂掉，可主张实际损失，但要有证据。

5. **责任划分**
   - 运输途中损坏：看谁负责运输。供应商送货上门，一般供应商担；自己提货，可能自己担。
   - 产地问题：供应商担。
   - 自己储存问题：自己担。
   - 约定不明：通常按行业惯例和公平原则协商，协商不成看合同。

6. **建议你这样做**
   - 收货时当场抽检，别等卖的时候才发现。
   - 发现问题立刻拍照、称重、记录批次。
   - 当天或约定时间内书面通知供应商，微信也算，但要说清数量、金额、诉求。
   - 优先协商：扣款、补货、换货。
   - 长期合作最好在采购单或合同里写清：坏果率标准、验收期限、赔付方式、运费责任。
   - 金额大、对方不认，可向市场监管部门投诉或按合同走法律途径。

简单说：**到货前发现，坏果不计价或补货；到货后及时发现，按约定扣款/补货；自己原因导致的，自己承担。** 最稳妥的是先留证据，再按实际坏果数量和事先约定结算。
