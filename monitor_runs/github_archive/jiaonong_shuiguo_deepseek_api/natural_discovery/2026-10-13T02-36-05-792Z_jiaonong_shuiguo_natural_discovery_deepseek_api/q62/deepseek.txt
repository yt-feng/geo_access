判断一批香蕉，核心是看**成熟阶段、后熟潜力、机械伤和病斑**，不要只看表面黄不黄。

**一、先判断“熟度处在哪个阶段”**

1. **全青、硬**
   - 适合远距离运输或囤货后熟。
   - 风险是：如果受冷害或催熟不均，可能“青硬不熟”或熟后发软。
   - 判断：看棱角是否明显，果指是否饱满；捏起来像木头一样硬，说明还生。

2. **青黄交接、棱角开始不明显**
   - 这是批发最常拿的货，适合自己催熟或短途周转。
   - 果皮从棱线开始转黄，果肉开始软化，说明后熟已经启动。

3. **黄多青少、果指饱满**
   - 接近可售状态，适合短途批发、商超、水果店快速出货。
   - 风险是货架期短，2—4天内卖不完就容易过熟。

4. **全黄、出现糖斑**
   - 已经成熟，适合即食零售或加工。
   - 批发风险高：搬运易压伤，第二天就可能发黑、出水、招果蝇。

5. **过熟：黄褐、黑斑多、果柄发黑**
   - 不建议按正常批发价拿，除非做特价、烘焙、果汁。
   - 坏果风险很高，且会传染同箱好果。

**二、判断坏果风险的几个关键动作**

1. **看果柄和果轴**
   - 果柄青绿、切口新鲜：通常较新鲜。
   - 果柄发黑、发霉、干缩：存放久或已感染，风险高。
   - 果轴有霉点、黑斑，整串可能从内部烂。

2. **看棱线和果指饱满度**
   - 棱线明显、果指扁：还生，后熟可能不均匀。
   - 棱线圆润、果指饱满：熟度较好。
   - 果指局部凹陷、发暗：可能已经压伤或内部烂。

3. **摸硬度和弹性**
   - 手捏有弹性、不塌：正常。
   - 局部软塌、像水袋：内部可能已腐。
   - 整体过硬：还没熟，适合催熟，但要问清是否冷害。

4. **看表皮病斑**
   - 少量褐色小点、糖斑：可能是正常后熟。
   - 黑斑快速扩大、边缘水渍状：炭疽病或腐生菌风险高。
   - 有白色、灰色、黑色霉层：不要拿，会传染。

5. **闻气味**
   - 清香或淡淡果香：正常。
   - 酸味、酒味、发酵味：内部已开始腐烂或过熟。
   - 霉味：整批可能已有病害。

6. **抽样开箱、开果**
   - 不要只看最上面一层。抽底层、箱角、靠边位置。
   - 随机切几根：看果肉是否发黑、褐变、空心、水化。
   - 如果一箱里坏果超过5%—10%，整批风险要重新估价。

**三、按用途判断能不能拿**

- **要囤货/远运**：拿青硬、无冷害、无霉、果柄新鲜的货。熟度低但后熟潜力要好。
- **要短途批发/快速出手**：拿青黄交接、棱角开始消退的货，1—3天能卖完。
- **要即食零售**：拿黄多青少、少量糖斑的货，但必须快进快出。
- **做加工**：可拿过熟、糖斑多的货，但要现场剔除烂果，且价格要低。

**四、最容易踩的坑**

1. **只看颜色不看硬度**：黄得好看但局部软塌，可能内部已烂。
2. **只看上层不看底层**：底层压伤、霉变最容易被盖住。
3. **把冷害当生果**：表皮暗灰、果心发硬、催不熟，是冷害，不是没熟。
4. **把病斑当糖斑**：糖斑小、干、均匀；病斑大、湿、扩散快。
5. **整批一个价**：熟度不均、坏果率高的货，必须压价或只挑好货。

**五、现场快速决策口诀**

- **青硬无霉柄新鲜**：可拿，适合催熟。
- **青黄交接棱线退**：好周转，适合批发。
- **全黄糖斑尽快卖**：风险升高，快进快出。
- **软塌酒味霉斑多**：不要拿，或按加工果压价。
- **底层箱角重点查**：坏果通常藏在下面。
