会有影响，但影响大小取决于你的销售方式和客户群体。

**主要影响：**

1. **按根卖/散卖**：大小不一影响最明显。顾客会挑大的，剩下的中小果难卖，损耗增加。
2. **按箱卖/整箱批发**：影响较小。客户买整箱通常看重总价和整体品质，对单根大小容忍度高。
3. **做果切、榨汁、甜品原料**：基本不影响，大小不一是可以接受的。
4. **礼盒装**：影响很大，大小不齐会显得不专业、掉档次。

**实际经营建议：**

- **分级销售**：把大果、中果、小果分开，分别定价。大果按根卖或做礼盒，中果正常散卖，小果低价促销或做果切原料。
- **混装促销**：大小混在一起按“特价箱”卖，明确告知大小不一但价格便宜，适合家庭自用客户。
- **采购时谈价**：如果一批货大小差异大，可以以此压采购价，把差价转化为利润空间。
- **控制采购比例**：如果主要靠散卖，尽量采购规格相对均匀的货；如果做果切或批发，可以接受混装低价货。

**结论**：大小不一定会“卖不掉”，关键是你怎么分、怎么定价、卖给谁。混装货只要价格和渠道匹配，照样能走量。
