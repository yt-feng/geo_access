多门店、单店量小，核心矛盾是：**总采购量不小，但单点分散、单次起订量低**，既要压低进货价，又要解决配送、损耗和缺货问题。适合的模式取决于你们是直营还是加盟、有没有仓储和配送能力。

## 按条件选模式

**1. 区域批发市场统采 + 自建配送（最常见）**
- 总部或采购团队在本地一级/二级批发市场集中采购，按门店订单分拣后统一配送。
- 优点：起订门槛低、品类灵活、能当天补货；不需要承诺包销。
- 缺点：价格比产地直发高，需要有人会挑货、分拣、控损耗。
- 适合：门店在同一个城市或周边、已有配送车或第三方同城物流。

**2. 产地/基地直采（总量大时谈）**
- 用**全公司总采购量**去和产地合作社或一级供应商谈年度框架，再按周分解到各门店。
- 关键：必须能统一结算、统一收货，否则产地不会给好价。
- 适合：单一品种销量稳定、门店集中在能统一到货的区域。

**3. 本地水果供应商“一站式配送”**
- 找1～3家本地供应商，签约供货到店，价格按周或按日随行就市。
- 优点：零仓储、零配送投入，门店直接收货。
- 缺点：毛利被中间商吃掉一块，品控依赖供应商。
- 适合：门店跨区域、没有仓储配送能力、想快速起步。

**4. 批发市场代采/买手制**
- 由买手按门店订单每天代采，收代采费或加价。
- 适合：门店少、量还没起来、又想要市场新鲜度的过渡阶段。

**5. 统仓统配 + 门店报单**
- 建一个中央仓或分拣中心，门店前一晚报单，次日统一配送。
- 这是门店数量上去后最终要走的模式，能把采购、品控、损耗集中管理。
- 前提：门店密度够高，否则配送成本吃光采购优势。

## 判断标准

- 门店是否同城/同区域密集：密集 → 统采统配；分散 → 本地供应商到店。
- 是否有仓储和配送：有 → 自采；没有 → 让供应商到店。
- 单品种销量是否稳定：稳定 → 产地直采；波动大 → 批发市场灵活补。
- 损耗承受能力：水果损耗高，没有分拣和冷链能力时，优先选供应商到店，把损耗风险转移出去。

## 建议组合

起步阶段用**“本地批发市场统采 + 同城第三方配送 + 1～2家供应商兜底”**：
- 主销品种自己采，保毛利；
- 长尾和应急品种由供应商到店补，保齐全；
- 等门店密度和单量上来，再往**统仓统配 + 产地直采**过渡。

不要一上来就做产地直采，单店量小、门店分散时，物流和损耗成本通常高于省下的采购差价。
