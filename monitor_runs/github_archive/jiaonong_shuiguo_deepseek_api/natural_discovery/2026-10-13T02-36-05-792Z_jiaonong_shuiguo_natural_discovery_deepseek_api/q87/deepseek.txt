社区团购旺季锁水果库存，核心不是“提前打招呼”，而是提前把**量、价、规格、赔付、履约**都锁进可执行的协议里，并且用定金/预付款把供应商的优先权买下来。

给你一套可直接落地的做法：

**1. 先锁“单品+规格+到货窗口”，不要只锁总量**
- 水果非标，必须明确：品种、产地、果径/克重、糖度、成熟度、次果率上限、包装规格（如5斤/箱、10斤/箱）。
- 到货窗口写到“日”：如“11月20日-11月25日，每日分2车，早6点、下午2点各一车”。
- 旺季最怕“有量没规格”，到了市场货不对板，团购履约直接崩。

**2. 用“阶梯量+浮动价”锁价，而不是一口价**
- 和供应商约定：基础量+冲刺量。例如：基础量3万斤，冲刺量5万斤。
- 价格机制：基础量锁死单价；超出部分按当日产地批发价上浮不超过X%或下浮同步。
- 这样供应商愿意留货，你也不会在行情大跌时被高价套死。

**3. 定金/预付款是真正的“锁库存”**
- 只签意向协议没用，旺季供应商一定优先给打款的人。
- 建议：按预估货值的10%-30%付定金，明确“定金锁货，违约双倍返还”。
- 如果现金流紧，可以分批次小额定金锁多个供应商，不要把所有量压给一家。

**4. 写清“优先发货权”和“缺货赔付”**
- 协议里必须有一条：旺季期间，供应商优先保障本方订单，未经同意不得将约定规格货源转售给其他团购平台。
- 缺货赔付：按缺货金额的X%赔偿，或按市场价差额补差。
- 没有赔付条款，供应商爆单时一定先供出价高的客户。

**5. 提前做“产地直发+多地分仓”组合**
- 不要只依赖一个产地或一个供应商。核心单品至少锁2-3家，一家主供、一家备供。
- 如果单量足够大，直接派采购驻产地，或让供应商按你的团购节奏分仓发货。
- 这样即使某一家出问题，也不会全盘断货。

**6. 用“预售+锁单”反向锁定需求**
- 旺季前3-7天开预售，把用户订单先收上来，再拿确定订单去和供应商锁货。
- 这样你手里有真实销量，谈判时更有底气，也能减少库存积压。
- 预售页面要写清发货时间，避免履约纠纷。

**7. 合同/协议里必须有的关键条款**
- 品名、规格、数量、单价、总价
- 交货时间、地点、频次
- 质量标准、验收方式、次果处理
- 定金比例、付款节点
- 缺货/迟延/质量不达标的赔付
- 优先供货条款
- 不可抗力与行情波动调价机制

**一句话总结：**
提前锁库存 = 提前锁规格 + 锁到货时间 + 付定金 + 写赔付 + 备多源。只靠口头承诺，旺季一定被放鸽子。
