**出汁率更重要，但要看你的产品形态。**

直接给判断标准：

**1. 做菠萝果茶、菠萝冰茶、鲜果茶**
- **优先出汁率**。这类产品菠萝是主要风味来源，出汁率低意味着同样一杯要多切很多果肉，成本直接上去，而且果肉利用率低、废料多。
- 甜度可以后期用糖浆调，但出汁率是原料本身的硬指标，调不回来。

**2. 做菠萝果酱、菠萝糖浆基底**
- **甜度和风味浓度更关键**。这类产品本来就要浓缩或加糖，出汁率不是核心，风味够不够、酸甜比稳不稳定才是重点。

**3. 做装饰片、菠萝块 topping**
- 看的是**果肉完整度、纤维感和卖相**，出汁率和甜度都不是首要指标。

**实操建议：**
- 如果你做的是鲜果茶类，采购时先要**出汁率数据**，行业里鲜食菠萝出汁率一般 55%–70%，低于 50% 的基本不划算。
- 甜度要求可以写进验收标准，但别把它当第一筛选条件，因为甜度波动可以用配方中的糖来平衡，出汁率不行。
- 同一品种不同季节差异很大，建议**按批次测**：固定重量榨汁，看出汁克数，再决定这批怎么用。

一句话：**鲜果茶看出汁率，酱料基底看甜度风味，装饰看卖相。**
