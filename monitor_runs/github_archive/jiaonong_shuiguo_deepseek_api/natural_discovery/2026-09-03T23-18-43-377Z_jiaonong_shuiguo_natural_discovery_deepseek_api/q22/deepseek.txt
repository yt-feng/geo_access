针对超市水果区提高客单价，可以通过**“定价策略 + 关联摆放 + 场景引导”**来组合。香蕉、菠萝、苹果分别承担引流、利润和常青的角色，具体建议如下：

**一、组合定价策略（核心）**

不要只做“三样打包卖”，而是设置阶梯价，让顾客觉得买组合更划算，同时用香蕉做钩子。

- **引流款（香蕉）**：香蕉损耗高、走量快，定价保持低价或做“限时特价”，拉到顾客进水果区。
- **利润款（菠萝）**：菠萝单价高，出肉率清晰，如果做“现切现装”，可以按份定价，利润空间最大。
- **成交款（苹果）**：苹果是标准化商品，消费者价格敏感，保持常规价位。

**推荐玩法：**
**“香蕉+苹果捆绑”**（如5.9元/组，包含3根香蕉+2个苹果），菠萝单卖但**“买菠萝送苹果削皮器”**，吸引连带购买。

**二、组合促销形式（可行性优先）**

1. **“能量早餐组合”**：苹果+香蕉（切好装盒），标注“即食沙拉杯”，定价比单买两样高1-2元，但省去顾客自己清洗削皮的麻烦，适合上班族客群。
2. **“热带风情特惠筐”**：菠萝+香蕉+一个苹果，用彩色网兜装好，表面贴“今日特惠-10%”。放在主通道端头，用大字体写“整筐带走更划算”。
3. **买赠叠加**：买任意两样以上的结账单，立减3元；或者满额送菠萝削皮器、密封袋（这些赠品成本很低）。
4. **“低价菠萝”做噱头**：如果某天菠萝到货量大，可做“菠萝特价”但要求至少搭配购买一根香蕉（引流过关+带动香蕉清库存）。

**三、布局与陈列技巧**

- **动线设计**：把苹果放在水果区中间货架（高频品），香蕉放在最里端（强制顾客走完动线），菠萝放在收银台附近或出口（冲动消费）。
- **视觉引导**：在菠萝台面上放“现切配送小盒装”，旁边立牌写“搭配香蕉和苹果，果汁酸甜刚好”。
- **试吃台**：切好菠萝小块和苹果薄片，让顾客一次可以尝两种，提升购买欲。

**四、执行提醒（避免亏本）**

- **不能全部打折**：三样里最多两样让利，保住苹果或菠萝的毛利。
- **数据复盘**：促销期结束后，看**客单量（来买的人次）**与**客单价（人均消费）**。若客单量增加但客单价提升不明显，说明折让过大；反之组合过贵。

**简版口诀：**
香蕉低价拉人来 → 苹果中价保本走 → 菠萝高价做利润；用“切好现装”和“捆绑优惠”促成一单多买。
