针对餐饮店“每天少量、但需要稳定供应”的需求，选供应商的核心原则是：**省心的关键在于“小批量多频次+低损耗+账期灵活”，而不是单纯找最便宜的批发商。**

以下是分阶段的实操建议，你可以直接照着筛选：

### 1. 首选本地“农贸市场散户”或“社区配送型平台”
- **找菜市场里的固定档口老板**（不是流动摊贩）。你要的不是他卖多便宜，而是**让他摸清你每天的用量规律**。你每天固定告诉他“今天要2斤苹果、1斤橙子”，他帮你顺路送，或者你每天去取。这种模式损耗最低，且他熟悉你后，质量不好的会主动帮你避开。
- **社区团购/生鲜电商的“企业版”**（如美团优选、多多买菜的企业采购入口，或当地本地的“菜篮子”配送公众号）。优点：**次日达、不用囤货、价格透明**。你只需要前一天晚上下单，第二天早上到货，坏了拍照就赔，非常适合控量。

### 2. 锁定“专供餐饮渠道”的水果配送商（关键词：净果/切果）
- 打开地图或58同城，搜索 **“净菜配送”、“团餐配送”、“水果净切”**。这类供应商专做饭店、奶茶店、果切店生意，他们每天有固定物流车次。
- **他们的核心价值**：帮你**去皮、切块、打包好**（比如你要西瓜丁、柠檬片），你拿到手直接摆盘，省去人工，且他们自己有冷库，你的库存压力为零。

### 3. 谈合作的“三条铁律”，决定是否省心
- **规定“最低送货量”**：不要不好意思开口。直接问：“**我每天只要20块钱的量，能不能送？**”大多数大配送商不愿意，你就找跑腿代买或社区团长。如果对方愿意送，但要求你每天最低50元，那你就让他**每两天送一次**，量集中一点。
- **锁定“坏果包赔”协议**：在微信上文字确认“**果损超过10%当天补货**”。这是省心的底牌，不写清楚，最后吃亏的都是小商户。
- **固定付款周期**：**不要预付月结**（怕跑路），谈好“周结”或“货到付款”，每天零买也能周结，既给老板稳定感，又保住自己现金流。

### 4. 替代方案：只抓“耐放型+易耗型”组合
如果实在找不到愿意小批量送的，建议你调整采购结构：
- **耐放的**（苹果、橙子、柚子、柠檬、圣女果）：每周去水果批发市场集中采一次，放阴凉处或冷藏，能顶一周。
- **易损耗的**（草莓、香蕉、切好的西瓜、芒果）：直接在美团买菜、朴朴超市（如有本地版）当日早上现买，满减偶尔用，虽单价略高，但不会烂在店里。

### 5. 避坑预警（非常重要）
- **不要找“总代”或“大批发商”**，他们的利润点在一箱起卖，你只要三五斤，会被随意加价或甩尾货。
- **警惕“临时水果摊”**，第一天便宜拉客，第二天就换电话。
