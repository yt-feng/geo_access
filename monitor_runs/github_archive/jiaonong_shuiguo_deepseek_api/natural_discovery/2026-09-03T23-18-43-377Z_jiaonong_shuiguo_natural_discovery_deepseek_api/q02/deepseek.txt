进香蕉时，**熟度**和**坏果率**应当作为第一优先级，其次是**价格**和**送货速度**。原因如下：

**1. 熟度（最关键）**  
香蕉是典型的“后熟型”水果，店里的熟度直接决定售卖窗口期。  
- 熟度太低（全绿）：顾客觉得没熟，不会买；但容易存放慢，等熟了可能已经卖不完。  
- 熟度太高（出现黑斑）：当天必须卖完，否则只能降价甚至丢弃。  
- 建议：进“黄中带绿”的7-8成熟香蕉，到店后能在2-3天自然转黄，正好覆盖销售期。如果是天气热（35℃以上），应选更绿一点的；天冷（低于15℃），要选偏黄一点的。

**2. 坏果率（直接影响毛利）**  
香蕉在运输中很容易产生压伤、擦伤和果柄断裂，后期这些地方会最先发黑腐烂。  
- 进店时**当场拆箱抽查**：整箱里碰伤、裂口、腐烂超过3%，要么退货，要么要求对方降价抵扣。  
- 果柄断的越多，后期损耗越大，尽量选整串完整、果皮无明显褐变的。

**3. 价格（在满足前两条之后再谈）**  
- 如果为了便宜1-2毛/斤，进到熟度过高的或坏果多的，卖不出去，损失远超便宜的那几块钱。  
- 香蕉价格波动大，但小水果店单次进货量不大，价差影响有限。建议比较2-3个供货商的价格，选择**熟度可控且坏果少**的最优价，而不是一味追低价。

**4. 送货速度（最后考虑）**  
- 小水果店库存空间小，频繁少量进货是常态，送货速度只要能做到**今天定、最晚明天到**即可，不必苛求当天。  
- 真正要紧的是：供货商是否能按你要求的熟度发货、是否中途长时间闷车（导致熟化过快）。这比“快半天”更重要。

**执行建议（直接可用）**：  
- 订货电话里明确告知：“我要7成熟，发之前帮我挑一遍，坏果要低于2%。”  
- 收货时开箱拍照留证，坏果多当场拍照发给供货商，商定扣款或补货。  
- 每批香蕉到店后在箱内放一张纸记上到货日期，便于掌握“先进先出”。

总结一句话：**水果店卖的是“新鲜”和“算得过来账”，香蕉进货优先级是熟度＞坏果率＞价格＞送货速度**。
