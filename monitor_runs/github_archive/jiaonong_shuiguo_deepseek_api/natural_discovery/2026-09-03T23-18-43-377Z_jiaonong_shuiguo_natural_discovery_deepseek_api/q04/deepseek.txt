针对水果店香蕉损耗问题，采购环节是控制源头最关键的一步。香蕉是典型的**后熟型水果**（采收时是绿色，靠自身释放乙烯催熟），所以采购时的“熟度”和“到货时间”直接决定了货架期。

以下是具体到可执行的建议：

**一、 采购时对熟度的硬性要求（按到货周期倒推）**

不能要求到货就是“黄亮可食”，否则门店只能卖1天。建议按以下标准**分单**要求：

1.  **常备货（周转期3-5天）：**
    -   **色卡要求：** 到货时要求香蕉**全绿**或**黄绿比≤1：9**（即通体绿色，仅果柄微黄）。
    -   **硬度要求：** 用手轻捏，果肉硬实，棱角分明。
    -   **目的：** 这批货到店后需要放入催熟库（或自然常温堆放）3-5天才能全黄，留足了缓冲时间。

2.  **补急需（当天或次日要卖）：**
    -   **色卡要求：** 到货时要求**头尾绿、中段黄**（黄绿比约8：2），且果皮**无黑点**。
    -   **目的：** 这批货到店即可上市，能解燃眉之急，但必须要求批次新鲜（无磕碰伤）。

3.  **最核心的一条：务必拒绝“全黄”或“有芝麻点”的货。**
    -   如果你在批发市场看到已经全黄甚至带黑点的香蕉，这种大概率是**已催熟且搁置了一晚**的货，直接低价处理，不建议采购。因为到店当天卖不完，第二天必然发黑软烂。

**二、 采购时对“到货时间”的精确要求**

到货时间决定了你验货时香蕉的状态，以及是否能错开高温时段。

1.  **时间窗口：** 必须要求**上午10点前到店**（或批发市场开市第一车货）。因为上午温度低，且你有一整天的时间来处理（分把、催熟、上架）。
2.  **严禁隔夜车：** 绝对避免要求“今天订，明天下午送到”。因为下午运输和卸货会经历一天中最高的气温，加上明天到店已经消耗掉一天熟化期，货损会非常严重。
3.  **到货前沟通：** 下单时明确写清“**当日采摘/当日装车**”，并要求供货商提供**装车时间**。如果你无法核实装车时间，宁可多付一点运费要求冷链车（15℃左右），也不要省这个钱赌普货车。

**三、 到货验收时的“三查”动作（决定能否拒收）**

光要求不够，验收必须执行，否则白订：

1.  **查“把”：** 看果柄截面是否新鲜湿润（白色或浅绿色），如果干枯发黑，说明在产地或库房存放过久。
2.  **查“芯”：** 切开一根香蕉中心轴，如果芯是**白色脆生**的，说明是当天的；如果芯是**透明水浸状**或**褐变**，说明经过冷藏又遇高温，熟化已失控。
3.  **查“磕碰”：** 若表皮有大量黑线或凹陷软斑，这类属于运输挤压伤，伤处会迅速氧化变黑，影响整个货架期，可要求按折价收货或直接拒收。

**四、 如果做不到精细化，给总经理/店长的死命令**

如果上述要求太复杂，采购只需记住一条黄金法则：
**“采购时永远买比你想卖的早一天半的那个状态。”**
即：你希望它明天小黄，那今天就订**全绿微黄**的；你希望它今天下午就能全黄，那这批货必须是**昨晚刚催完，今早刚出库**的冷藏车，且果皮必须硬挺。

**最后补充：** 如果水果店规模小，无法自建催熟库，建议**不要一次性大批量采购**。改成“小批量、高频次”采购（例如2天一批），并要求供应商直接提供**已催熟但未全黄**（黄绿比6：4）的货，到店后常温放置半天即可售卖，这是损耗最小的操作模式。
