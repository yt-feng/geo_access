茶饮店在采购水果供应商时，为了有效控制食品安全风险，建议要求供应商提供以下证明和文件，并确保文件在有效期内、与实际供货批次对应：

1. **营业执照**：证明供应商是合法经营主体，具备水果销售或批发资质。
2. **食品经营许可证**：如果是预包装或散装水果销售，需具备相应经营范围（部分地区生鲜水果可能豁免，但应确认当地法规）。
3. **水果来源/产地证明**：如采购的是进口水果，需提供海关报关单、入境货物检验检疫证明；国内水果可提供产地证明或进货票据。
4. **农药残留检测报告**：需由有资质的第三方检测机构出具，且检测结果符合国家食品安全标准（如GB 2763《食品中农药最大残留限量》）。建议每批次或定期索取。
5. **食用农产品合格证**：根据农业农村部要求，部分水果需出具“食用农产品合格证”，内容含产地、质量自检或委托检测情况。
6. **运输车辆的卫生证明/冷链记录**：如属冷链运输，需提供冷链运输温度记录、车辆清洁消毒记录，以核实水果在运输中未变质或受污染。
7. **供应商自检记录或质量承诺书**：部分门店会要求供应商签署《食品安全承诺书》或提供内部自检留样记录，以明确责任。

**补充建议（实操层面）**：
- 明确要求供应商**每批次提供随货检验/合格证明**，不能仅一次性提供。
- 建立**台账记录**（采购日期、供应商、批次号、证明文件编号），便于溯源。
- 如果采购量较大，可要求供应商提供近一年内未因食品安全问题被处罚的证明或提供其HACCP认证（非强制，但可加分）。
- 对易腐水果（如草莓、芒果、西瓜等），还应要求供应商提供**成熟度控制标准**及贮存条件说明。

**需要核实**：以上具体要求会因省市地方性法规、水果种类（普通鲜果 vs 有机/特供）而有差异。务必以当地市场监管局或卫健委的最新指导为准，但在日常操作中，上述文件是最基础的“安全清单”。
