在便利店售卖菠萝切块，**保质期、包装和配送频次三者缺一不可，但优先级和核心逻辑不同**。下面拆解一下，方便你做决策：

### 1. 保质期：是决策的总开关（最优先）
- **为什么关键**：菠萝切块属于高酸性、高糖分水果，**切开后会快速滋生细菌和氧化**。即使冷藏，口感也很快变差（发酸、出水、变软）。
- **实操建议**：
  - 建议在包装上明确标注**“当日制作”**或**“24小时内食用”**，并严格执行废弃制度。
  - 上架时间最好在 **早上9点-10点** 左右，确保当天是新鲜切块。
  - 不要售卖超过 **12小时** 的切块（这是口感食安的底线），高峰期卖不掉的到点强制下架。

### 2. 包装：决定“看起来新鲜”和“保存期限”（次优先）
- **为什么关键**：包装直接决定了顾客的第一印象、防氧化效果以及是否容易漏汁。
- **实操建议**：
  - **必须使用自带**“透气孔”**或**“锁水膜”**的食品级PET盒+密封盖**，不要用保鲜膜直接缠菠萝，膜会粘果肉且无支撑。
  - **低氧包装**（抽真空或充氮气）能延长保质期1-2天，但成本高，**便利店散卖不建议**，会导致口感变软。
  - 盒内可放少量**吸水垫**或**脱氧剂**（要合规），防止切块泡在汁水里变烂。
  - 包装规格建议 **150g-200g/盒**，单价控制在10元内，方便随手买。

### 3. 配送频次：决定“补货时间”和“损耗率”（第三位）
- **为什么关键**：如果你依赖中央厨房配送，频次决定了你陈列柜里的新鲜度；如果门店自切，则无需此环节。
- **实操建议**：
  - **如果是冷链配送**：建议 **每日早晨一次**（如7点前到店），单日分批上架。一天两次（早晚）会显著提升销量（晚高峰补一次），但损耗率也会上升，需根据销量测算。
  - **盯销售数据**：如果这家店菠萝切块日销低于5盒，**改为隔日配送**，避免积压。
  - 如果是供应商送货：要求**“日配”**，且必须送到即冷藏（0-4℃），交接时查验中心温度。

---

**给你的核心决策建议（按顺序执行）**：

1. **先定保质期**（比如：当天凌晨切，傍晚前必须清空） → 倒推所有动作。
2. **包装宁可贵5毛，也不能省**：用带良好密封性的盒装，配吸水垫，这是防差评的最短路径。
3. **配送频次与销量挂钩**：如果每天能卖出15盒以上，一天两配；卖不动就一天一配，宁缺勿滥。

**一句话总结**：**保质期是生死线（必须内控12小时），包装是体验线（防氧化、防漏汁），配送频次是盈利线（频次越高损耗越大，按销量调）**。

如果你们是自有加工，建议每天早晨现切，直接摆冷藏柜，不需要配送环节，就压缩成本了。
