针对养老院或医院食堂这类特殊场景，水果采购除了常规的生鲜标准，还必须兼顾**食品安全、营养适配、供货连续性**。以下从“合规”和“稳定”两个维度给你一组可落地的判断方法：

---

### 一、合规性判断（红线，不可妥协）

1. **证照齐全是第一道门**
   - 必须核验：营业执照（经营范围含水果、食品销售）、**食品经营许可证**（或食品生产许可证，若对方是种植企业需看是否纳入监管）。
   - 不同点：医院和养老院的采购属于**集中用餐单位**，根据相关规定，供货商必须能提供**“电子一票通”或销售凭证**，且台账要能追溯到产地。如果对方只能给白条或收据，可认定不合规。
   - 建议：要求供应商提供**最近3个月的进货检验报告**或对外的第三方农残检测报告（可索要，对方必须能拿得出）。

2. **农残与农事记录**
   - 优先选择能提供**逐批农残快检报告**的供应商（哪怕是复印件加盖公章）。
   - 若是直供基地，需核验种植端的“三品一标”（绿色食品、有机、地理标志等）或政府出具的合格证。
   - 注意：医院对**孕妇、儿童、老人**的免疫耐受度低，建议将农残检测视为“每批必验”，而非“每季度抽验”。

3. **运输与仓储资质**
   - 水果属于易腐食品，供应商必须配备**冷链车或恒温车**，且车上应具有温度记录仪（不是摆设）。如果对方用普通货车且无任何保鲜措施，直接淘汰。
   - 如果有分拣中心的，查看其仓库是否有**防鼠、防虫、温湿度控制设备**，现场脏乱差的一票否决。

4. **历史处罚查询**
   - 通过当地市场监管局官网或“信用中国”查询供应商是否有行政处罚记录（如售卖变质食品、抽检不合格等）。这是低成本但最有效的合规筛选。

---

### 二、稳定性判断（重点看供应链能力）

1. **看源头绑定程度**
   - 区分“批发商”与“基地直供”。批发商虽便宜但断货风险高（市场价格波动大，他会优先保高价客户）。
   - 建议优先选择有**固定合作果园/基地**且能出示产地收购合同或合作协议的供应商，表明其货源受法律约束，不会随意弃单。

2. **看历史交易韧性**
   - 让供应商提供近**一年内为其他机关食堂、学校、医院供货的案例清单**，并随机抽1-2家去电核实满意度（直接问对方采购负责人：“最近三个月有没有断过货？”）。
   - 重点问询：**极端天气（如台风、霜冻）下供应是否有替代方案**（应从跨省基地调货，而不是一句“看情况”）。

3. **现场考察分拣能力**
   - 去其库房或档口看两个指标：
     - **周转速度**：库存水果是否超过两天？如果是，说明其销售能力弱，你的订单优先级可能不高。
     - **分级筛选能力**：是否有独立质检员？如果工人只是往箱子里倒货不挑拣，你收到的“以次充好”概率会高。
   - 稳定性不只是“有货”，更是“每次货品一致”。

4. **写进合同的价格联动机制**
   - 最怕供应商“每天报价随行就市”，下周涨你不签他就断供。可要求**每月或每两周定价一次**，以批发市场均价为基准，固定上浮比例。
   - 在合同中可明确：**延迟到货30分钟以上的扣款条款**，以及“季节性缺货时，供应商需提前7天书面预警并给出替代品种方案”。

---

### 三、实操建议（对采购负责人的提醒）

- **试供期是试金石**：不要一上来签一年。先签1个月试用，要求每天提供当日到货清单和农残快检记录，若一个月内出现2次水果表皮破损严重或断货，果断终止。
- **保留“一物一证”背书**：每次送货让供应商在送货单上注明“本批次经农残自检合格，如抽检不合格愿承担全部责任”，并加盖公章。这能有效约束其更谨慎。
- **备胎不可少**：即使是合规稳定的供应商，也建议默默设立**第二备选供应商**，避免因对方自身经营问题导致老人或病人无水果吃。

---

### 判断一句话总结：
**合规看证照、检测、仓储；稳定性看源头、经历、书面契约。** 如果对方拿不出食品经营许可证或者检测报告，无论价格多低，直接过；如果对方能提供冷链车辆消毒记录和一周前的货单存根，才值得进入谈价阶段。
