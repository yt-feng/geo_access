选择供应商时，很多人只盯着价格和口感，但长期稳定往往取决于“看不见的细节”。最容易忽视的几个点：

**1. 供应链的“抗风险弹性”（而非单一货源）**
- 只问“你价格多少”是不够的。要问：“如果连续暴雨3天，你的苹果/芒果从哪调货？能保证几天不断货？调货成本谁承担？”
- 很多小供应商只有单一产地，一旦产区受灾就束手无策。而稳定的供应商通常有2-3个备用产地或冷库周转库存，且能在合同中明确“缺货补货条款”。

**2. 水果的糖度仪数据 + 分选标准（而非只看表面）**
- 水果表面光鲜，内部可能已经过熟或偏生。你需要供应商提供每次批次到货时的“糖度检测报告”（可要求现场测），以及他们的分选标准（比如按克重、色泽、瑕疵比例分几级）。
- 最容易被忽视的是：**同一规格下，不同批次的成熟度波动**。稳定合作要求供应商承诺“每批糖度误差不超过±1度”并写入合同。

**3. 账期与退换货政策的“法律细节”**
- 口头承诺“坏了包赔”不算数。要确认合同里是否写明：损耗率超过多少（如5%）按梯度赔偿？赔偿是按批发价还是零售价？退货的物流费用谁出？
- 很多坑在于“自然损耗”定义模糊：运输碰伤、挤压、自然呼吸作用的失重，到底算不算损耗？要提前明确。

**4. 冷链的“断链时间记录”（而非只问是否有冷链）**
- 很多供应商有冷库，但装卸货时在常温下暴露1-2小时，导致水果回温结露，影响货架期。问清楚：从产地冷库到你那边的全程温度记录（是否有温控仪数据？中途开箱几次？）
- 更细的：夏季高温时，他们是否会用“预冷+冰袋+保温棉”而不是单纯放冰块？冰块融化积水也会加速腐烂。

**5. 供应商的“库存新鲜度”管理（而非只看订单量）**
- 问清他们的仓库周转天数：如果一个批次的进货超过5-7天还没卖完，会直接甩卖还是继续卖你？好的供应商会建立“先进先出”的台账，并主动告诉你哪些批次是临期品。
- 容易被忽视：同一箱水果里，下层垫的纸、通风孔设计是否科学？透气不良会闷出异味。

**6. 对“异常天气预警”的响应能力**
- 长期稳定的供应商会提前1-2天告知“台风/霜冻马上影响哪些产区，建议你提前备货”或“未来一周高温，建议减小库存量”。
- 如果供应商从不主动提醒季节风险，只等你下单，那旺季缺货、淡季压库迟早会来。

---

**最后给你的可执行建议：**
1. **做一次“盲测”**：要求供应商寄不同批次的样品（不能只寄最好的），对比糖度、硬度、破损率。
2. **签“阶梯式合同”**：首月小批量试合作，写明试用期条款，再谈长期折扣。
3. **实地看一次他们的分选线**：看工人是按大小盲目装袋，还是用光谱仪/电子秤分级。

长期稳定不是靠熟人信任，而是靠合同里写清楚每个模糊点。你是做社区团购、商超渠道还是街边店？不同场景的需求差异很大，可以再细化聊。
