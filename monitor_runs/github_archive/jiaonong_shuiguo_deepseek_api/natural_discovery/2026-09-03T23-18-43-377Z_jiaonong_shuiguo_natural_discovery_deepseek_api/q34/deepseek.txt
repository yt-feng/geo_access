在商超采购水果时，**损耗率对最终毛利的敏感度通常远高于进价**。原因是：损耗是“从进价到毛利”之间的**直接乘数**，而价格降幅只是基数改变。

为了让你直观判断，我给出一个简化模型，你可以代入实际数据验证：

**核心公式**：
毛利 = 销售额 - 进货成本 - 损耗成本
=（售价 × 销量）-（进价 × 进货量）-（进价 × 损耗量）

假设：
- 进货量 100kg，进价 10元/kg（即成本 1000元）
- 售价 15元/kg，如果全部卖出，营收 1500元，理论毛利 500元

**情况A：进价降低 10%**（9元/kg）
- 成本变为 900元，若所有水果正常卖出，毛利 = 1500 - 900 = **600元**
- 毛利率提升 (600-500)/500 = 20%

**情况B：损耗率增加 10%**（即多损耗10kg水果）
- 仍然进价10元/kg，但实际卖出90kg，营收 1350元，总成本仍是1000元
- 毛利 = 1350 - 1000 = **350元**
- 毛利率下降 (500-350)/500 = 30%

结论：**同等幅度的损耗变化对毛利的影响大约是进价变化的1.5倍**。而且现实中，水果损耗的波动范围远大于价格波动（水果价格季节性波动常见10-20%，损耗率却可能从5%飙升至30%甚至更高）。

**实操建议**：

1. **先控损耗，再谈价格**。损耗管理是水果采购的第一优先级。
2. **建立损耗预警机制**：制定不同品类（如香蕉、浆果、叶菜）的标准损耗率，超过阈值立即复盘进货量或陈列方式。
3. **价格谈判优先级**：当损耗控制稳定后，才把精力放在议价上，因为价格谈判空间通常有限（供应商也有成本）。
4. **关注“批次周转”而非单纯压价**：采购时宁愿贵一点但要求供应商保证成熟度一致、包装减震，这比便宜5%但损耗翻倍划算得多。
5. **用数据说话**：每周统计每个SKU的真实毛利（扣损耗后），你会发现高损耗的SKU即使进价再低，最后实际毛利常为负数。
