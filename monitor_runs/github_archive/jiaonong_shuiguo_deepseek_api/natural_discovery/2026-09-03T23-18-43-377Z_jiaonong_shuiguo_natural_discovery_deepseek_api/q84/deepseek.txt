针对家庭团购水果礼盒，**组合原则是：耐放、富含维C、有香气、有颜值，同时避免“互相催熟”搭配出问题**。

推荐两套方案，可以直接参考去选品：

---

**方案一：全家人通用·均衡营养型**（性价比最高，最稳妥）
- **组合内容**：**苹果** 6个 + **橙子** 6个 + **香蕉** 2串 + **菠萝** 1个（约2-3斤）
- **理由**：
  - 苹果是“百搭果”，耐储存，两三天慢慢吃不会坏。
  - 橙子富含维C，适合秋冬防感冒，也是水果盒里的“重量担当”。
  - 香蕉能迅速补充能量，小孩和老人血糖需求都能满足，而且撕皮即食，是家庭消耗最快的。
  - 菠萝放在其次，因为需要削皮处理，通常吃一半留一半，但能给整盒提香气，而且正当时令便宜好吃。
- **注意**：**香蕉不要和苹果放一个袋子里紧贴**。苹果会释放乙烯催熟香蕉，导致香蕉变黑变软。可以让配送方用纸分隔，或者发货时香蕉单独用保鲜膜包一下。

---

**方案二：健康轻食·低糖送礼型**（适合注重健康、有控糖需求或喜欢做饭的家庭）
- **组合内容**：**苹果** 6个 + 橙子 5个 + **菠萝** 2个（或1大1小）+ **香蕉** 少半箱（2-3根散装）
- **理由**：
  - 如果针对健身/减脂家庭，菠萝含菠萝蛋白酶助消化，橙子纤维多，两者都低糖高水分。
  - 香蕉可以减量，因为部分人怕升糖，散装几根给小孩吃就够了。
  - 这种组合更突出“鲜切”场景，适合做菠萝炒饭、橙子果茶等，互动性更强。

---

**额外关键提醒（针对团购卖家）：**
1. **不要混合挤压**：菠萝外壳坚硬带刺，千万不能压在苹果橙子上面，否则会把软果实划伤。建议菠萝单独兜袋，放礼盒最下层或隔层。
2. **控制成熟度**：团购一般次日达或隔日达，**香蕉要选偏青微黄的七成熟**，橙子要选常温未催过头的，这样到客户手里能多放几天。
3. **包装隔断**：盒内用防震棉分隔，苹果和菠萝之间必须隔开，避免刺伤。
4. **文案建议**：主推「一周不重样」：橙子补C、苹果护肠、香蕉应急、菠萝解腻，家庭周末一起切，一家三口吃三天刚好。

**如果只能选两样主打，果断主推苹果+橙子货源品质；香蕉和菠萝作为补充拉升客单量和丰富度。**
