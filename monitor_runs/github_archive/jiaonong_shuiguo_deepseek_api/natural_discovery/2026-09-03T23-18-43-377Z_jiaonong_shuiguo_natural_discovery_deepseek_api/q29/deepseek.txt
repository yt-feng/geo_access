针对超市与水果供应商的账期，**常见区间为7天至45天**，具体取决于合作模式、水果品类及双方市场地位。以下是关键参考：

**1. 按超市类型划分：**
- **大型连锁超市（如永辉、沃尔玛）**：通常要求 **30-45天**，部分甚至60天（凭借采购量大掌握话语权）。
- **区域中型超市/生鲜专卖店**：常见 **15-30天**，双方会协商促销费用或损耗分担。
- **社区小店/个体超市**：多为 **7-15天**，或者直接“现结”（现金/当日转账），因水果易腐且供应商不愿承担风险。

**2. 按水果品类划分：**
- **高价耐储水果（如苹果、柚子）**：账期可放宽至 **30-45天**，因损耗率低。
- **时令浆果/叶菜（如草莓、荔枝）**：账期极短，通常 **3-7天** 或现结，供应商不会接受长账期，否则风险过高。
- **进口水果（如车厘子、牛油果）**：若通过一级代理，多为 **15-30天**，可能附带保底销量条款。

**3. 谈判关键点（直接影响账期长短）：**
- **损耗分摊比例**：若超市承担部分物流损耗，供应商可接受更长账期。
- **付款保证**：供应商更信任“批结”方式（即每批货物结清上一批货款），而非“月结”。
- **账期起算日**：需写明是“到货后X天”还是“验收合格后X天”，避免模糊产生纠纷。

**4. 行业警示（不可忽视）：**
- 水果是 **非标、易腐商品**，账期超过45天极易引发供应商资金链断裂或“断供”，尤其夏季高温期。
- 若超市坚持长账期（如90天），通常需 **支付利息或提高进货价** 作为补偿，否则不建议任何供应商接受。

**实操建议：**
- 首次合作建议谈判 **15-20天** 作为测试期，观察对方履约能力。
- 签约时务必写入“逾期付款违约金”（通常按日万分之五），并明确对账日（如每月25日截止当月账期）。
