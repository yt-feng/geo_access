选择水果礼盒供应商时，**需要明确要求支持开发票，且定制包装是加分项（建议尽量选择支持，但可按公司预算和用途取舍）**。原因如下：

1. **发票**：这是企业报销、做账和税务合规的**硬性要求**。无论购买量多少，供应商必须能开具增值税普通发票（税率9%或13%）或增值税专用发票（可用于抵扣，需提供公司纳税识别号）。**建议在合同中写明开票类型、税率和开票时限**，避免后续扯皮。

2. **定制包装**：
   - **若用于客户拜访、商务往来或节日送礼**——定制包装（印公司Logo、祝福语等）能提升品牌形象，属于有价值的“软性宣传”，**建议要求提供**。
   - **若仅作为内部员工福利**——定制包装不是必须，但若量大有团购需求，部分供应商会免费提供简易贺卡或外贴标签。**你可以先问供应商是否免费提供基础定制（如贴纸、腰封）**，若收费再评估性价比。

**实用建议**：
- 先列一份供应商询价表，明确询问“能否开专票/普票”“定制包装费用如何计算”“最低起订量”等。
- 若供应商小作坊式经营、无法开票，直接淘汰；若对方仅能开普票，则需确认是否影响公司财务报销（通常普票即可）。
- 定制方案要提前锁定：要求供应商提供设计稿预览，确认印刷色差、Logo清晰度，并约定交付前质检。

**结论**：发票是必要条件，定制包装按用途选择，但明确告诉供应商“我们需要开票，且有定制需求”，能帮你筛掉部分不专业的商家。
