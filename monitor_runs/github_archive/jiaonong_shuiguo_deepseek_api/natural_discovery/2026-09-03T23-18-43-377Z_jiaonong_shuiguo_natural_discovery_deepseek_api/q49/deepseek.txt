针对茶饮店旺季菠萝用量突然变大的情况，与供应商约定临时补货时，建议按以下步骤操作，重点在于**明确量、质、价、时和售后**：

**第一步：先盘点、预估缺口**
- 先算出你目前的库存还能撑几天，以及按往年旺季或最近3天日均销量，预估未来5-7天（甚至更长的补货周期）需要的总用量。
- 给供应商一个尽可能准确的数字（例如：“本周末前，我预计需要额外补充800公斤新鲜菠萝，另外准备200公斤冷冻菠萝作为备用”）。

**第二步：电话/微信先行口头沟通，取得确认**
- 直接联系对接的销售或老板，说明情况：“最近菠萝销量爆了，现有库存不够，想临时加单，能否在本周三前送到？”
- 立刻询问对方**是否有现货/能不能调货**。如果对方不能完全满足，要求对方给出**部分供应方案**（比如先送500公斤，后续再补300公斤）。

**第三步：明确临时补货的5个合同要点（必须以书面记录为准）**
1. **数量与分批送达时间**：如果一次送不完，要写明分批数量和每批到货时间。例如：“周三送300公斤，周五送500公斤。”
2. **规格与品质标准**：必须写清楚**成熟度**（几成熟）、**单果重量范围**、**无烂果/碰伤比例**，以及**糖度最低值**（如不低于11度）。旺季容易出现抢货，品质容易参差不齐，这个最不能马虎。
3. **价格条款**：因为量突然增大，供应商可能要求涨价。建议明确：“本次临时补货在原有合同价格基础上上浮不超过X%”，或者“若当日市场批发价低于约定价，按低价执行；若高于，需提前告知并书面确认”。
4. **账期与付款**：旺季补货钱款可能较大，明确是“货到验收后3天内付款”还是“先付定金30%，尾款收货后结清”，避免因付款争议中断供货。
5. **违约责任（保底条款）**：如果供应商不能按约定时间送齐，导致你断货，要约定赔偿方式或至少要求“优先调配权”（即如果供应商货不够，必须先满足你的紧急订单）。

**第四步：跟进与验收**
- 让供应商微信或邮件发来**书面的《临时补货确认单》**，包含上述内容，你回复“收到，按此执行”作为凭证，这将是你维权的重要依据。
- 每次收货时，**现场拆箱检查**菠萝的成熟度和烂果率，抽检2-3箱并拍照留证据，有问题当时拒收或拍照拒收部分。

**第五步：建立长期备用机制（防患于未然）**
- 主动建议供应商：“旺季我们菠萝用量大且波动快，是否可以给我们留一个‘安全库存预约’？比如每天你预留200公斤给我，我用就用，不用提前一天通知取消。”
- 同时保留1-2家备选供应商，作为应急，避免单点依赖被拿捏。

**特别提醒：**
- 千万别只口头“您好”。旺季时口头承诺极易失效，**一切以聊天记录/邮件文字确认为准**。
- 如果补货价格谈不拢，可以考虑要求对方搭配送货（比如同时送一点其它用得多的水果或包材），以对冲涨价。

如果你觉得对方实力一般、市场缺货严重，请务必优先考虑**“部分到货+提前一天二次确认下一次到货”**的滚动锁定方式，防止断货。
