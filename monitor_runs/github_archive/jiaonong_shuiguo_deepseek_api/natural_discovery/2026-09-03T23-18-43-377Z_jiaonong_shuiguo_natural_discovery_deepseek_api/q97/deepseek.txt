在酒店采购水果盘原料时，供应商应当保证以下**规格**和**外观**标准，以确保出品质量、卫生和成本可控：

**一、规格标准（尺寸、重量、成熟度）**
1. **成熟度统一**：供应商应明确水果的成熟度等级（如7-8成熟），既不能过生导致口感差，也不可过熟易烂损。例如西瓜须沙瓤，哈密瓜须达到可即食甜度。
2. **果径/单果重**：如苹果、橙子要求果径在一定范围（如80-90mm），每箱重量误差不超过±5%。奇异果、圣女果需大小一致，避免大小差异影响摆盘。
3. **包装规格**：按酒店要求的份量或箱装（例如每箱净重5kg/10kg），装箱内无过度挤压。

**二、外观标准（感官检查）**
1. **无机械损伤**：表面无碰压伤、划痕、刺伤、软斑。
2. **无病虫害与霉变**：果面无虫眼、菌斑、腐烂点，果柄新鲜不干枯。
3. **色泽与洁净度**：颜色符合品种特征（如红提呈红色、青提翠绿），果面干净无泥土、农药残留痕迹。
4. **形状均匀**：果形端正，无畸形、歪斜，特别是切盘用水果必须保证切面平整。
5. **无异常气味**：无发酵味、酸臭味或化学残留异味。

**三、附加要求（建议与供应商书面约定）**
- **农残检测合格**：供应商需随批次提供当季水果的农残快检报告或合格证明。
- **新鲜度时限**：明确规定采摘到送达时间（如48小时内），且到货需冷藏车运输，温度符合品类要求（如4-8℃）。
- **临时换货责任**：若到货抽检发现表皮破损率超过2%，供应商应承诺24小时内无偿补换。

**以上标准最好写入采购合同或订单备注，并采取到货抽检（按箱随机拆验）的方式执行。** 不建议口头相信，否则一旦出现整批质量波动，酒店损失会很大。若无法保证来源，可要求供应商提供“产地证明”或“自检记录”作为参考。
