在超市卖菠萝时，**应该优先关注“切果损耗”**，其次再兼顾甜度、大小和外观。原因如下：

1. **损耗直接决定利润**：  
   菠萝皮厚、刺多，若需现场切割或提供削皮服务，损耗率通常高达 **15%-25%**（去头尾、去皮、去眼）。如果损耗控制不好，即便进价较低，实际毛利也可能被侵蚀。建议在陈列时优先供应“整果”，并通过成熟度分级减少切开后无法售出的风险。

2. **甜度决定复购**：  
   顾客吃后觉得甜才会再买。可通过**目测果眼间距（间距大通常更甜）、按压底部（微软有弹性更成熟）、闻香气**来判断。若开切试吃，建议每日限量，避免过度损耗。

3. **大小错位满足不同客群**：  
   - 小果（约1-1.5斤）：适合单身或小家庭，单价低，走量快。  
   - 中果（1.5-2.5斤）：主流选择，利润较稳。  
   - 大果（2.5斤以上）：适合家庭聚会，但单价高，需避免滞销后熟透变质。

4. **外观是基础门槛，但不必过度追求完美**：  
   无明显黑斑、霉变或软烂即可。轻微磕碰或果眼偏深不影响食用，但**若外观有瑕疵，至少要明确标出“轻微瑕疵特价”，避免退货纠纷。**

**总结实操建议**：  
- 进货时按**整果损耗率预估**（超过25%坚决不收）。  
- 上架时用**熟度分层法**：成熟度高的做“今日鲜切”或试吃，次熟的陈列整果。  
- 若超市有现切菠萝柜台，建议将切好的果肉按**份量称重计价**，而非按整果去皮后的“果重”标价，减少顾客对损耗的预期差。  

**一句话结论**：先算好切果损耗的账，再谈甜度和外观，否则容易白忙一场。
