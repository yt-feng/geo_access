为了控制香蕉的熟度，采购时可以按以下维度管理，确保既适合饮品也适合甜品：

**1. 明确用途区分熟度需求**
- **饮品（如香蕉奶昔、冰沙）**：需**全熟或略过熟（果皮出现大量黑点）**，此时甜度高、软糯易打泥，无需额外多放糖。
- **甜品（如香蕉布丁、蛋糕夹层）**：需**中等熟度（果皮黄中带绿，手感稍硬）**，避免太软影响切块成型或加热后过度出水。
- **装饰或香蕉片**：需**7-8成熟（果皮整体金黄，果肉紧实）**，切后不易褐变软塌。

**2. 采购时的现场判断标准**
- 看颜色：果皮全黄但无黑斑 = 适合做甜品；果皮出现褐色或黑色斑点但无损伤 = 最适合打饮；果皮全绿或带青 = 不可立即使用（需常温放置1-2天催熟）。
- 摸硬度：轻捏果实两端，若感觉紧实有弹性为偏生；若略微发软且能轻松按出浅坑为适中；若很软且凹陷不回弹为过熟（只适合立即做饮或冷冻）。
- 闻气味：散发明显香蕉清香且无发酵酒精味。
- 拒绝根部发黑、果皮破裂、有霉点或手感发粘的批次（内部可能已烂心）。

**3. 分级入库与轮换管理**
- 每次采购按“当日可打饮、2-3天内做甜品、1周内变软”分别安排货架位置。
- 若店里用量大，可要求供应商分两批到货：第一批中等熟度，第二批偏绿，按需自然催熟。
- 明显过熟的香蕉不要丢弃——**剥皮切块冷冻**，可随时用于打冰沙，且冷冻保存风味稳定。

**4. 应急与替代方案**
- 若采购时发现全部偏生，可将香蕉与苹果/苹果皮同放纸袋，室温下1-2天催熟（乙烯作用），忌放冰箱（会变黑且停止熟化）。
- 若当天急需，允许供应商临时调换批次，或采购袋装熟香蕉（已在催熟库处理过）。

**5. 记录与供应商要求**
- 每次收货记录熟度等级（如：G=全绿，L=黄绿，Y=全黄，M=带点斑），出一份“熟度对照标准表”给供应商，便于其备货。
- 明确约定“熟度波动范围”，例如饮品用香蕉要求黑斑面积不超过20%，甜品用要求无黑斑。

**简单总结**：按当天和未来3天的菜单量倒推——饮品先买最熟的，甜品买黄但硬的，装饰用偏生的；收货时用“颜色+硬度+气味”三查，再按温度分层存放。若要做成标准化出品，建议直接统一采购“略带绿头”的中熟香蕉，到店后按用途催熟，最易控制。
