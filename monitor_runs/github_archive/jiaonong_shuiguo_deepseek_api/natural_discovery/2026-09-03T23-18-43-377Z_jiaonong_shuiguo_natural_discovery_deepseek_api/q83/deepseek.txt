针对生鲜电商水果到货后出现坏果的投诉，责任划分的核心原则是**“谁在哪个环节造成了不可逆的损坏，谁负责”**，但实际操作中通常**优先保护消费者权益**，然后由平台与供应商、物流方内部追责。

具体责任划分可按以下逻辑判断：

**1. 首先判断“坏果”的性质和原因（关键）**

- **自然腐烂/病害**：比如内部发霉、软烂、有虫眼。这类大概率是**源头品控问题**（供应商发货时未筛选干净），或**储存不当**（仓内温度异常）。
- **物理损伤**：比如压伤、碰伤、裂果、破袋。这类主要是**包装不达标**或**快递运输暴力分拣**导致。
- **到货时已过熟/失水**：比如香蕉、柿子到货已变黑、变软，属于**成熟度预估不当**，责任多在**商家或选品环节**。
- **收货后存放时间过长**：如果顾客签收超过24小时（电商规则通常约定为24小时内反馈），且无证据证明开箱即坏，责任可能偏向**顾客保存不当**，但商家通常仍会酌情补偿或协商。

**2. 按平台规则划分（实际操作优先级最高）**

- **“坏果包赔”是生鲜电商的默认承诺**：几乎所有主流平台（如盒马、京东到家、美团买菜、叮咚买菜）都执行“坏果按比例赔付”或“全额退款”。
- **规则核心**：只要顾客在签收后**24小时（少数为48小时）内**，提供**坏果和面单（快递单/订单号）的清晰合照**，平台**无条件先行赔付**——无需顾客自证责任。
- 此时，**责任划分主要是平台内部的事**：
  - 若坏果占比 >50%，通常整单退款；
  - 坏果占比 10%~50%，按坏果重量或个数比例折价退款；
  - 少数严重情况（整箱烂透）可能额外赔偿优惠券。

**3. 平台内部的追责链条（供商家/运营参考）**

- **供应商/产地采摘方**：负责采摘成熟度、预冷、装箱。
- **平台分拣仓**：负责入仓质检、冷库温控、打包（泡沫箱、冰袋、防震网套是否到位）。
- **物流配送**：负责运输时效、避免抛摔（但坏果通常是包装不抗压，物流难摆责）。

**4. 责任划分的具体结论（给客服或商家的处理建议）**

- **如果顾客证据齐全（照片清晰、在时效内）**：**不要和顾客争论“是不是你自己压坏的”**。因为生鲜损耗本身就是行业痛点，争论责任会快速流失客户。**应直接按规则赔付**，同时登记批次信息。
- **如果顾客反馈超时（如3天后说坏果）**：可以先核实是否放入冰箱保存。若未冷藏，可以明确告知可能是存放问题，但**出于体验，仍可提供50%退款或补偿券**，避免差评。
- **如果是大额订单或批发客户**：可能需要检查物流签收记录（是否本人签收、是否当面验货），必要时可要求客户提供开箱视频，但不要强求。

**5. 给你的直接建议（若你是消费者）**

- **第一时间拍照**：拍下坏果特写 + 订单号 + 快递面单。
- **在平台订单页发起“售后/坏果理赔”**，上传照片，一般1-2小时处理。
- 如果平台推诿，可引用《消费者权益保护法》第二十四条，要求三倍赔偿（但生鲜类执行上较难，通常赔退即可）。

**总结一句话**：
**顾客只要在收货24小时内拍照反馈，责任默认为商家/平台全责，应无条件退款或按比例赔偿；超过时效且无照片，责任倾向顾客，但商家应基于客诉弹性处理。源头品控和包装是减少此类纠纷的根本。**
