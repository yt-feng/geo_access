水果店采购香蕉时，一箱里大小不一样**确实会影响销售**，但影响程度取决于你的定位、销售方式和客户群体。

**具体影响主要体现在以下几个方面：**

1. **外观和陈列问题**：大小混装放在货架或果篮里，视觉上显得不整齐、不专业，尤其在精品水果店或超市，会降低顾客的购买欲望。
2. **定价困难**：整箱价格无法统一，如果按个卖，大小不同难以标价；按斤卖，顾客容易挑选大的，剩下小的更难卖。
3. **损耗增加**：如果顾客可以自行挑选，小的或被挑剩的香蕉容易滞销、熟透变质，增加损耗。
4. **客户体验差异**：买回去发现同一串或同一箱香蕉大小差异大，部分顾客会觉得自己吃亏，影响复购。
5. **部分销售渠道有硬性要求**：如果卖到单位食堂、大型商超、酒店等，通常要求规格统一（如每箱单根重量或长度相近），混装会被拒收或压价。

---

**但也不是完全没有优势，要看情况：**

- 如果你做**平价/批发流动摊**，大小混装可以用来“一箱一口价”促销，对价格敏感的老顾客反而觉得划算。
- 如果客户是**家庭日常消费**，大小混装对部分人不敏感，他们主要是看口感和价格。
- 你可以把大果和小果**分开陈列**，大果卖高价，小果做特价或拼盘，反而能减少浪费。

---

**给你的实操建议：**

- **常规零售店**：尽量避免采购大小严重不均的箱子，尤其是做精品水果店。采购时优先选“单箱规格接近”的等级货，比如“大果”“中果”级别。
- **如果已经采购了混装箱**：拆箱后按大小分类，大小分开摆放并分别定价（大的略贵，小的略便宜），同时把小果优先销售（比如做成切好的果盘或特价促销）。
- **如果是网上或社区团购**：建议在商品描述里明确“整箱大小略有差异”，提前降低顾客预期，减少售后纠纷。

**结论：** 一箱大小不一，短期看可能影响销量和利润，**但只要你主动分拣、合理标价，就能最大程度减少负面影响**。如果条件允许，长期做稳定生意还是建议优先采购规格接近的香蕉。
