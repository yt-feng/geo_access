在茶饮店采购菠萝原料时，**出汁率通常比甜度更重要**，但两者都不能极端偏废。核心逻辑要围绕**产品稳定性、成本、复配能力**来考虑。

**为什么出汁率更关键：**

1. **利润与成本直接挂钩**：出汁率低意味着每杯饮品消耗的菠萝原料更多。假设A款菠萝出汁率55%，B款出汁率45%，做一杯500ml的菠萝茶，A款用果肉约200g，B款需要约245g，长期下来是显著的成本差异。
2. **口感与质地**：高出汁率的菠萝果肉纤维更细腻，榨汁后不易产生絮状物，茶饮挂杯、沉淀少，出品更清爽。低出汁率往往伴随果肉粗糙、纤维感强，容易让饮品出现“渣感”，影响饮用体验。
3. **适配性更广**：出汁率高的菠萝可以灵活用于纯果汁、果肉果茶、冰沙、气泡水等多条产品线；而出汁率低但特甜的菠萝，往往只能做“甜口”产品，很难平衡酸度。

**但甜度不可忽视，原因是：**

- 甜度决定了你**是否需要额外加糖浆**，以及**糖浆用量**。如果买回的菠萝甜度低，你每杯都要额外加果糖或蔗糖，既增加成本，也可能导致“甜但无果味”的假甜感。
- 茶饮店产品通常有固定的甜度标准（如三分糖、全糖），如果原料本身甜度波动大，你很难稳定复刻标准配方，影响顾客回头率。

**实操建议（采购决策）：**

1. 优先选**出汁率≥50%**、甜度≥13°Brix（糖度计可测）的菠萝原料，这是性价比平衡点。
2. 试饮时**不要只喝纯果汁**，要调成你店里的成品饮品再判断——加茶、加冰后，酸涩感和甜感都会被放大或稀释。
3. 如果预算有限，**出汁率优先**，甜度不足可以通过**少量糖浆+柠檬汁/热带水果搭配（如百香果、芒果）**来弥补风味层次；但如果出汁率低，很难靠调味挽回口感。
4. 采购时询问供应商“**出汁率**”具体数值（不是含糖量），并要求提供样品做实际压榨测试。不要只听宣传语。

总之：**出汁率决定口感上限和成本底线，甜度决定风味调整空间。** 如果只能二选一，果断选高出汁率的菠萝。
