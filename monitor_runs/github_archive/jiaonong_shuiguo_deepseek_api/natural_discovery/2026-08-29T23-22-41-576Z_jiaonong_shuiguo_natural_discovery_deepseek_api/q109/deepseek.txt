在与长期合作的水果供应商谈判时，**优先顺序建议为：售后 > 账期 > 配送**。

原因如下，供你参考：

1. **售后（最优先）**：水果是生鲜易腐品，损耗是最大的隐性成本。如果售后谈不拢（比如到货坏果率、退换货标准、折价补偿规则），账期再长、配送再快，你最终也可能因为货物积压或腐烂而亏钱。**售后条款是控制利润底线的关键**，建议明确坏果率标准（如超过X%无条件补发或扣款）和售后响应时限（如6小时内反馈）。

2. **账期（次优先）**：账期直接关系到你的资金周转压力，但注意，账期越长，供应商通常会在单价上“**加价**”来对冲风险。如果现金流不是极度紧张，建议优先争取“**次月结**”或“**15天账期**”，并搭配**阶梯式付款**（如首批现结，后续按月结），这样既能维持信任，也不会把价格扯得太高。

3. **配送（可谈判）**：配送频次和时效（如每日到货、冷链温度要求）虽然影响损耗，但通常可以通过调整订货计划或本地化拼车来弥补。只要供应商承诺“**当日或次日送达+冷链达标**”，配送细节可以适当让步，作为换取售后或账期优化的筹码。

---

**实操建议**：
- 谈判时**把售后条款写进合同**，口头承诺一律无效。
- 可以提出“**整年订货量**”，用集中采购量换取更宽松的售后（如坏果全赔）。
- 如果供应商是本地大型批发商，通常账期可谈空间小，但售后更规范；如果是产地直供，账期好谈但售后执行可能需要强约束。

最终目标：**用配送的妥协，换取售后的兜底和账期的灵活**。如果只能选一项，优先把售后谈死，这是你利润的“保险丝”。
