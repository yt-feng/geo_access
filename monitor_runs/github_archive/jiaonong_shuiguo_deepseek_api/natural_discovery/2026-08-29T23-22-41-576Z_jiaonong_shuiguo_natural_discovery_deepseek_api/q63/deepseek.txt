判断菠萝批发哪个规格更容易出货，核心是看**你的下游客户（超市、水果店、档口、食堂/餐饮）他们的核心诉求和消费场景**。通常没有绝对“最好”的规格，但有**优先级策略**。

给你一个实操性强、可立即用的判断方法，分四步走：

**第一步：先看你的“客户画像”（这是最关键的一步）**

-   **如果下游是连锁超市/精品水果店：** 他们更看重**外观统一、个头适中（单果重1.2-1.5kg）**，因为摆柜好看，而且家庭消费是主流。这种场景下，**中果（如5-6头/箱）通常最好出货**。
-   **如果下游是街边水果店/社区店：** 他们喜欢**性价比高**，顾客买来主要是自吃或做菜。**大果（如4-5头/箱）** 因为便宜、肉厚，反而比小果更受欢迎，但前提是外观不能太次。
-   **如果下游是餐饮/食堂/果汁店/切果店：** 他们只认**出肉率和价格**，对品相要求低。这种客户**优先选择大果或统货（混装果）**，因为切果成本低，且大果出果率高。

**第二步：看“重量分界点”的走量规律（经验法则）**

-   **走量最大、最稳的黄金规格**：单果重量在 **1.3kg - 1.8kg** 之间的（对应常见的 6-7头/箱）。这个区间既不小气，又不会太大导致单个售价过高，是绝大多数零售端的“舒适区”。
-   **风险提示**：**单果超过2kg的大果**，虽然单价诱人，但家庭一次吃不完，很容易出现“零售卖不动”的情况，导致下游批发商不敢拿货。除非你对接的是切果厂或食堂，否则不要主推超大果。
-   **风险提示**：**单果低于0.8kg的小果**，虽然便宜，但零售顾客普遍觉得“没肉”，且批发利润极薄，除非对接的是工厂（做罐头），否则很难走量。

**第三步：做一次“最小成本试单”（最可靠的判断）**

不要凭感觉。给你的核心客户（比如固定的3-5个超市老板）各发一箱不同规格的样品，并记录以下数据：
1.  **拿货率**：他们是否愿意在24小时内回购？
2.  **下游反馈**：他们店里实际顾客是更偏爱“大个的”还是“适中的”？
3.  **损耗率**：哪个规格到店后腐烂速度更快？（菠萝越大，运输碰撞风险越高）

**第四步：结合季节调整（非常重要）**

-   **冬春季节（1-4月）**：天气冷，顾客买菠萝多以“尝鲜”或做菜（如菠萝咕咾肉）为主，**中果（1.2kg左右）** 更好卖，因为一顿能吃完。
-   **夏秋季节（5-9月）**：天气热，菠萝是解暑水果，家庭购买量大，且常用来打果汁。**大果（1.5kg以上）** 会因为“划算”而更容易走量。

---

**给你一个立刻能执行的行动建议：**

1.  先不要大量囤一个规格。用一车货，其中 **60% 放中果（5-6头/箱），30% 放大果（4头/箱）**，剩下的10%放小果试水。
2.  主动联系你手头最大的3个老客户，直接问：“老王，我这批货有大中小三种，你上周店里哪个卖得最快？我下一车给你专门留那个规格。”
3.  **最关键的一点**：**不要只看批发价（单价/斤）**，要算 **“单箱利润”**。如果你进的是统货，大果出肉率高，但损耗也大；中果虽然单价利润薄，但周转快，其实整体回报更高。

如果以上都试过还是不确定，那最简单的办法是：**看你这批货的“底色”** —— 如果这批果甜度高、黑心少，就主推大果（餐饮端会抢）；如果只是外观漂亮但味道一般，就主推中果（零售端看脸）。
