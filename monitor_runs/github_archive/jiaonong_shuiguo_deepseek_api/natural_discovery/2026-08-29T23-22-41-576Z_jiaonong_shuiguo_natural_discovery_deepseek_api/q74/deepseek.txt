针对批发档口拓展餐饮客户，菠萝和香蕉的规格选择需要结合餐饮端的实际使用场景（如切配、摆盘、烘焙、果汁等）和损耗控制来定。以下是具体建议：

---

### **一、菠萝规格建议**
餐饮端对菠萝的核心需求是**出肉率**和**易处理性**，同时要兼顾甜度和酸度。

1. **按果型规格分**：
   - **小果（1.5-2.2斤/个）**：适合做果切、沙拉、甜品点缀，出餐小巧精致，适合高端轻食店。
   - **中果（2.5-3.5斤/个）**：最主流，适合餐厅做水果拼盘、菠萝饭、烤菠萝、菠萝炒饭，出肉率高且切配方便。
   - **大果（4斤以上）**：适合自助餐、大型餐饮、果汁店，能降低单果成本，但注意是否对切配效率有要求。

2. **按成熟度和加工形态分**：
   - **鲜果（自然熟）**：提供青皮或微黄皮均可，但建议推荐**糖度15度以上**（甜度高），便于餐厅直接做鲜切或榨汁。
   - **去皮菠萝**：适合小型餐厅或果汁店，减少处理时间，但注意包装要求（如真空或冰袋）。
   - **菠萝芯/菠萝丁（冷链装）**：适合烘焙店（做菠萝包内馅）、连锁快餐（做披萨/炒饭料），规格建议5kg/袋。

3. **关键提示**：
   - 明确要求“无黑心、无硬芯”，尤其是做炒饭和果汁的客户。
   - 提供“成熟度标记”（如黄1-2天、黄3-4天），便于餐饮客户排期使用。

---

### **二、香蕉规格建议**
餐饮客户对香蕉的规格更重视**熟度一致性**和**单根长度/重量**，常用于水果拼盘、烘焙（香蕉蛋糕）、轻食、奶昔。

1. **按条重和长度分**：
   - **小果（每条150-180g，长度15cm以下）**：适合做果切拼盘、儿童餐、甜品装饰，摆盘好看。
   - **中果（每条180-230g，长度18-22cm）**：最主流，适合餐厅做香蕉牛奶、披萨、沙拉，出餐口径统一。
   - **大果（每条250g以上，长度24cm+）**：适合做整根烤香蕉、自助餐台、酒店早餐，视觉冲击力强。

2. **按整把规格分**：
   - **国产蕉**：常按“把”卖，建议提供**6-7根/把**的小把装，适合小餐厅；或**9-12根/把**的中把装，适合大客流门店。
   - **进口蕉（如菲律宾蕉）**：通常单根独立包装，规格更标准，建议标注“无青头、无农药残留”。

3. **按熟度和加工形态分**：
   - **青熟（7-8成熟）**：适合需要放几天的客户（如烘焙店做催熟）。
   - **黄熟（9成熟）**：即买即用，适合做果切、果汁。
   - **冻香蕉（去皮/切段）**：适合做奶昔、冰淇淋，建议提供1kg×10袋的规格。

4. **关键提示**：
   - 明确“无疤痕、无冻伤”，对餐饮客户而言，外观瑕疵会影响出品美感。
   - 提供“催熟服务”或“分级标准”（如颜色对照卡），减少客户退换货率。

---

### **三、给档口的额外建议**
1. **提供“餐饮专用套餐”**：例如菠萝+香蕉组合装，重量按餐饮客户日均消耗量设计（如菠萝10个+香蕉20把），降低采购频次。
2. **建立退换货标准**：明确“到货24小时内可退换无条件损耗”，增加信任感。
3. **给视觉化信息**：在档口贴规格标签（如“菠萝2.8-3.2斤/个”“香蕉180g/条”），并配上切配示范图（如菠萝丁、香蕉片），让客户直观理解。
4. **物流细节**：菠萝需防磕碰（垫泡沫网），香蕉需竖放（防压伤），并注明“夏季需冰袋配送”。

---

**总结**：  
- 菠萝优先推**中果（2.5-3.5斤）**，重点讲“出肉率和糖度”。  
- 香蕉优先推**中果（180-230g）**，重点讲“熟度稳定和长度统一”。  
- 根据餐饮客户类型（快餐/烘焙/果汁/酒店）灵活调整小规格或大规格。
