水果采购谈锁价（即固定采购价格）的期限，**没有统一标准**，主要取决于**水果的品类、市场波动幅度、采购体量和对供应商的议价能力**。

在实际操作中，可以按以下情况参考：

1.  **大宗、耐储类（苹果、梨、柑橘、土豆等）**：
    - 一般能锁 **1-3个月**。这类水果上市季节集中，冷库库存充足，价格相对稳定。如果有长期合同，甚至能锁到产季结束。
    - 供应商更愿意接受这类锁价，因为风险可控。

2.  **季节性小众水果（草莓、杨梅、荔枝、樱桃等）**：
    - 一般只能锁 **3-7天**，甚至按天锁价。
    - 这类水果价格受天气、到货量影响剧烈，供应商通常只愿意锁定周转周期内的价格，锁太久他们自己会亏损。

3.  **进口水果（车厘子、牛油果、阳光玫瑰等）**：
    - 一般锁 **1-2周**。价格受海运船期、期货行情影响大，供应商普遍以“到港价+固定利润”的方式报价，不太肯长期锁价。

4.  **大宗基础款（云南香蕉、海南西瓜等）**：
    - 如果按月采购量稳定（比如每周固定几柜），可以谈 **锁2-4周**，但一般要在合同中约定“涨跌超过10%重新议价”的弹性条款。

**给你的实操建议：**

- **不要只谈“锁多久”**，要谈“锁什么”：锁的是到岸价、出库价，还是含配送价？税费、损耗怎么算？这些不明确，锁期长也没用。
- **设定价格浮动区间**：比如约定“若市场均价波动超过±8%，双方可按新价协商”，这样供应商敢给你锁更久，你也不会吃亏。
- **用采购量换锁期**：一次性承诺3个月的稳定订单，供应商通常愿意锁30-60天。如果没有量，只想锁价，没人愿意陪你扛风险。

**总结**：日常锁价普遍在 **7-30天**，大宗稳定品类可锁一个产季；高波动水果别贪长，稳一点反而更安全。
