在商超水果采购中，**损耗低通常比价格低更影响最终毛利**，尤其是在高损耗品类（如草莓、荔枝、热带水果）上。

原因和逻辑如下：

**1. 损耗低直接保护已实现的销售额**
- 假设采购价便宜10%（例如每斤省1元），但损耗率从5%上升到12%（多损耗7%），那么你损失的不仅是7%的进货成本，更是**7%的可售商品对应的高毛利销售额**。水果的毛利通常在30%-60%，损耗掉的每一斤，其50%的毛利直接归零，还倒贴了仓储和人工。
- 举例：进价10元/斤，售价15元/斤。采购价降1元（省10%），但损耗从5%升到12%（多损失7斤/100斤）。
  - 原方案毛利：95斤×5元=475元
  - 低进价高损耗方案：93斤×4元=372元，**实际毛利反而少了103元**。

**2. 损耗影响的是“确定性”**
- 采购价格是进价，可以谈；但损耗是经营风险，尤其是生鲜水果。损耗一旦失控，会导致：
  - 卖不出去时只能打折出清，进一步侵蚀毛利率。
  - 损耗高意味着必须频繁报损、退货，增加管理成本。
- 采购价格低往往伴随货源品质不稳定（如统货、尾货、露天堆放的），表面便宜，实际是“坑”。

**3. 不同品类的侧重不同**
- **易腐高损耗品类（草莓、樱桃、荔枝、叶菜类）**：损耗低 >> 价格低，优先选稳定货源、冷链完善的供应商，哪怕单价贵10%-15%，只要损耗控制在5%以内，毛利仍优于便宜但损耗15%的货源。
- **耐储品类（苹果、梨、柑橘、西瓜）**：价格低和损耗低影响接近，可适当放宽损耗在5%-8%的采购方式，把价格谈下来。

**4. 实操建议**
- 采购前明确目标损耗率（例如标准品≤8%，精品≤5%），并直接在合同或结算时与供应商约定，**高于目标损耗按比例扣款或退货**，把损耗风险转嫁给供应商。
- 到货后做“试销”：小批量试卖2-3天，对比实际损耗再决定是否大批量采购便宜货源。
- 每日盘点损耗原因：是运输磕碰、陈列不当，还是货源本身品质差。若是后者，果断放弃低价格。

**结论**：5元以下的廉价水果，如果损耗率多出3%-5%，毛利立刻归零。所以成熟商超通常遵循“**品质和损耗优先，价格作为第二考量**”，除非你是做临期清仓或客流拉动型引流品，否则不要为了省两毛钱冒损耗风险。
