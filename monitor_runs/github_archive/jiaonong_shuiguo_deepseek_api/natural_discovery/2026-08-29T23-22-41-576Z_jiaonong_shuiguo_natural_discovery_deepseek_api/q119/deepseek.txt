选择水果供应商时，大家往往关注价格、新鲜度和送货速度，但以下这些细节容易被忽视，却直接决定生意的长期稳定性：

---

**1. 是否具备**产地直采**或**分级分选**能力**
- **直采 vs 二道贩子**：很多“供应商”其实是从批发市场拿货的中间商。如果对方没有自己的产地资源或稳定农户合作，一旦市场缺货，你的供应就断。
- **分级标准**：水果是按大小、糖度、瑕疵分级售卖的。供应商是否愿意按你的定价档位（如商超精品、街边小店、线上平价）帮你分级挑货，决定你毛利和损耗。

**2. 账期与资金周转的真实规则（不只看价格）**
- **隐性费用**：部分供应商会以“低价”吸引你，但结算时加收装卸费、纸箱费、冷链费，甚至强制最低起订量。必须白纸黑字确认所有费用。
- **账期稳定性**：长期合作时，供应商是否允许你账期月结？还是只收现金？如果他有资金压力，可能会中途涨价或断供。

**3. 售后**扯皮**的判定标准**
- **损耗率承诺**：比如香蕉、荔枝、草莓等易腐品，供应商是否承诺按比例赔付？赔款计算是按重量还是按箱数？一定要写清楚。
- **“灰姑娘条款”**：很多供应商只赔“烂掉的部分”，但送货时表面完好的“内部软伤”（如苹果碰伤、柚子干水）往往不认账。要约定抽检方法和赔付时效。

**4. 冷链物流的“最后一公里”细节**
- **是否全程冷链**：有些供应商用常温车送货，夏天超市看着新鲜，但到家再放几天就坏了。询问对方冷库温度记录是否可查。
- **到货时间窗口**：如果对方每天下午3点才送到，而你上午主打线上订单，直接导致库存积压。要确认到货时间能匹配你的高峰销售时段。

**5. 供应商的**信息透明度**与应急能力**
- **价格波动通知**：恶劣天气、节假日前后水果暴涨是常态。好的供应商会提前一周通知你调价，临时抱佛脚的基本不靠谱。
- **补货响应速度**：旺季水果卖完，你急需补货，对方是能当天加急送货，还是“明天给你排单”？测试一次节假日前的紧急补货即可判断。

**6. 替换品的主动权**
- 长期合作后，如果某款水果产地减产，只跟你降价不说，换货时是否强行推荐你库存积压的品类？你要约定“替换需经我方书面确认”，防止被绑定烂货。

---

**落地建议**：
- **先试3个月小单**，不要一开始就签年度大单。
- **抽查源头单据**：偶尔要求看供应商的采购合同、产地证明（如绿色无公害认证），防止挂羊头卖狗肉。
- **留“备份供应商”**：至少保持两家货源，哪怕价格高5%，关键时刻能救命。

一句话总结：**别只砍单价，要把“损耗赔付、账期、送货时间、应急补货”写进合同里，并实际测试一次旺季。**
