针对小水果店进货香蕉，**建议优先级为：熟度 > 坏果率 > 送货速度 > 价格**。  
具体分析如下：

1. **熟度（最重要）**  
   香蕉是典型的后熟型水果，一旦成熟速度极快，且保质期短（尤其夏季）。  
   - **选几成熟？**  
     - 如果店内销量快（1-2天内能卖完）：选7-8成熟（果皮绿但带微黄），到店后自然熟成，口感最佳。  
     - 如果销量慢（单日卖不完）：必须选5-6成熟（果皮全绿），否则2天后就会发黑腐烂。  
   - **判断方法**：看果柄是否鲜绿、果面是否光滑（越青越耐放）。要求供应商标注成熟度批次。

2. **坏果率（第二重要）**  
   一箱香蕉若坏果超过5%，直接吃掉利润。  
   - **注意**：香蕉运输中易压伤，装箱时果皮破损、果柄断裂的都算坏果。  
   - **进货要求**：先拿一箱抽检，开箱检查底层和边角（供应商常把好果放表面）。  
   - **建议**：与供应商约定“坏果包赔”，否则换供应商。

3. **送货速度（第三）**  
   香蕉不像蔬菜需要“当日鲜”，但送货太慢会加剧熟度失控。  
   - **合理范围**：从产地到店，24-48小时内可接受（冷链或箱装能延迟）。超过3天坚决不进。  
   - **本地批发市场进货**：一般当日上午订、下午到，影响不大。若跨省订货，需问清物流时效。

4. **价格（最后考虑）**  
   香蕉毛利通常低（10%-20%），但价格波动大（香蕉季），且坏果率直接抵消“便宜”的差价。  
   - 若价格低20%，但坏果率高5%，其实**总成本反而更高**。  
   - **策略**：不要为低价囤货，香蕉是“勤进快销”的品类，根据日销量决定进货量。

---

**执行建议**：  
- 首次合作，只订少量试卖，观察2天后剩余香蕉的品相。  
- 进店后，若表面熟了但芯硬，说明没催熟好，下次换供应商。  
- 夏季可要求供应商用“冰袋+气泡柱”，冬季则要检查是否冻伤（果皮发黑）。  

**一句话总结**：**宁可贵一点，买刚青、完整、次日送达的香蕉；熟度买错，亏得最多。**
