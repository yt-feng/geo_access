酒店采购水果盘原料时，供应商应重点保证以下**规格和外观标准**。这些标准直接关系到出品品质、成本控制和客人的消费体验。

---

### 一、规格标准（定量指标）

1.  **单果重量/尺寸**：
    *   **标准明确**：例如，草莓单颗重量≥15g，蓝莓果径≥12mm，西瓜单片厚度1.5cm±0.2cm，哈密瓜切块大小均匀（如2cm×2cm）。
    *   **分级要求**：供应商必须按**酒店约定的等级**（如特级、一级）供货，不得混入次级果。

2.  **成熟度/糖度**：
    *   **成熟度检测**：应达到“可食用成熟度”而非“运输成熟度”。例如，芒果、木瓜需软硬适中，香蕉需无青皮。
    *   **糖度要求**：可要求供应商提供糖度计数据（如西瓜糖度≥11%，哈密瓜糖度≥12%），或用试吃抽检确认。

3.  **新鲜度**：
    *   **供货时间**：必须为当天或前一日采摘/切割的原料，供货到店时间需精确到小时（如每日上午9:00前送达）。
    *   **冷链要求**：全程冷链运输（4℃-8℃），到货时水果中心温度≤10℃。

4.  **数量误差**：
    *   单件包装重量误差≤±5%（如5kg装西瓜篮，实重需≥4.75kg）。
    *   供应商应附带**送货单**，注明品种、规格、数量、到货时间。

---

### 二、外观标准（定性指标）

1.  **颜色与光泽**：
    *   **自然色**：果皮颜色应均匀、有光泽，无明显褪色、暗沉。
    *   **颜色要求**：例如，西瓜瓤应正红或粉红（按品种），哈密瓜肉应橙黄或翠绿，葡萄皮色应一致。

2.  **形状完整性**：
    *   **无畸形果**：如草莓应呈圆锥形，不允许有裂口、缩头；苹果无“歪脖子”、凹陷。
    *   **表面平整**：果皮无凹凸不平（除天然凹陷外）。

3.  **瑕疵控制**：
    *   **无病斑**：不允许有黑斑、褐斑、霉点、水渍状腐烂。
    *   **无虫蛀**：切开检查无虫洞、虫类残留物。
    *   **无机械伤**：不允许有挤压伤、压扁、划痕、碰伤、擦伤（轻微不影响食用的划伤可允许<2%）。

4.  **清洁度**：
    *   **无农残残留**：表面无白色药粉、泥土、污物、胶带残留。
    *   **无蜡涂层**（除非特别指定），需为天然果蜡可清洗。

5.  **包装规范**：
    *   **标签完整**：外包装箱体需注明产地、采摘日期、品种、重量、供应商信息。
    *   **防压设计**：易碎水果（如草莓、葡萄）需用吸塑盒+分隔层，确保运输途中无压痕。

---

### 三、供应商需额外满足的隐性标准

1.  **批次可追溯**：每批水果能追到具体产地及采摘批次号（应对食安抽查）。
2.  **农残符合国标**：需提供每批次的**农残检测报告**（无报告但需有声明及应急预案）。
3.  **备货能力**：能应对突发加单（如宴会），并保证同批原料品质一致。

---

### 四、酒店验收时的建议动作

-   **三方抽查**：由厨师长、采购、仓储三方现场开箱，按上述标准抽检（建议抽检率≥20%）。
-   **次品处理**：约定次品率上限（如≤3%），超比例部分供应商需无条件换货或扣款。
-   **留样拍照**：对不符合项拍照存档，作为扣款或更换供应商的依据。
