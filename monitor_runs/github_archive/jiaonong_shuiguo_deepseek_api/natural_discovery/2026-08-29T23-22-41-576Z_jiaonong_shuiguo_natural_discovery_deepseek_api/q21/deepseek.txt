在超市采购水果时，供应商通常需要提供以下几类**检测报告**和**进货证明**，以符合食品安全法规和商超的验收要求（具体以当地市场监管部门和超市合同为准）：

---

### 一、必须提供的核心证明（缺一不可）

1. **水果检测合格报告（第三方或官方机构）**
   - 针对**农药残留**（常见检测项目：有机磷、氨基甲酸酯类）、**重金属**（铅、镉等）、**致病菌**（如需）等。
   - 报告须由具有**CMA/CNAS资质**的检测机构出具，且**报告日期在进货前1个月内**（部分超市要求15天内）。

2. **进货凭证（供货商出具）**
   - 发票、送货单或购销合同，需注明水果品名、规格、数量、产地、供货商名称及联系方式。

3. **供应商资质证明**
   - 营业执照副本复印件（加盖公章），经营范围含水果销售或种植。

---

### 二、根据水果来源额外提供的证明

| 水果来源 | 必须提供的额外证明 |
|---------|-------------------|
| **国内产地直供** | 产地证明（村委会/合作社/农业局出具）、产地收购单据。 |
| **进口水果** | **入境货物检验检疫证明**、海关报关单、原产地证、中文标签（须标明产地、品种、生产日期）。 |
| **经过初级分选/包装** | 包装企业的《食品生产许可证》（如涉及净菜加工）或仅分装的备案证明。 |
| **有机/绿色认证产品** | 相应有机认证证书或绿色食品证书（如宣传该特性）。 |

---

### 三、注意事项（实操建议）

1. **报告时效性**：果蔬类检测报告通常**一批一报**，同一批次水果建议要求供应商每次送货附最新报告，不要依赖长期通用报告。
2. **报告真实性核验**：超市采购员可要求供应商提供报告编号，在检测机构官网（如“国家市场监督管理总局-检验检测机构资质查询”）或电话核实。
3. **留存时限**：所有单据和报告需在超市保存**不少于2年**，以备市场监管部门检查。
4. **特殊水果**：如**鲜切水果（果切盒）**，还须供应商提供**冷链运输记录**和加工环节的卫生证明。

---

### 四、若供应商无法提供怎么办？
- 依据《食品安全法》第五十三条，超市有义务查验并保存进货查验记录。若无法提供，**不得采购**，否则面临行政处罚。
- 可要求供应商**先行补充报告**，或改为从正规批发市场采购并索取**市场开具的“履历单”**（部分大型批发市场有统一追溯体系）。

---

如还需更具体的**各品类检测项目清单**（如草莓、西瓜、进口车厘子等），可进一步说明您的采购品类。
