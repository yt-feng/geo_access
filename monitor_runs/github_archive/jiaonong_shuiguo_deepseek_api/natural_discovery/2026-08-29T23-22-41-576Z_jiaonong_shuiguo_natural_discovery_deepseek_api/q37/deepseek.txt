商超做会员日水果活动，如果想让活动效果最大化、避免在高峰期出现缺货或损耗过大的问题，**供应商需要在活动开始前至少3-7天**就启动配合准备。

以下是供应商需要提前做好的核心准备工作，建议按时间线分阶段执行：

**一、 活动策划期（提前7-10天）：备货与选品**

-   **确认爆品SKU**：不能让商超随意指定，供应商要基于历史销售数据，和商超采购共同锁定3-5款“引流爆品”（如应季的榴莲、车厘子、西瓜），以及10款左右的高毛利“利润品”。
-   **动态备货计划**：根据商超会员日预估销量（通常是平时周末的3-5倍），**至少按预估销量的120%备货**，防止断货。同时要预留出因天气或物流延误导致的缓冲库存。
-   **锁定货源与价格**：提前与上游产地或批发市场锁定货源，确保会员日价格具有绝对竞争力（通常要比常规售价低15%-20%）。

**二、 物流与仓储准备（提前3-5天）：保障新鲜度**

-   **分批到货机制**：千万不要一次性把货全送到门店，要与商超确认**分批次、分时段**送货（如活动前夜送一批、活动当天凌晨送一批），避免门店冷库爆仓。
-   **冷链无缝衔接**：确认配送车辆温控处于适宜水果保存的区间（如香蕉13-15℃，苹果0-4℃），并**提前告知商超到货的准确时间**，确保货到即可入冷库，缩短在常温区暴露时间。

**三、 门店现场配合（提前1-2天）：陈列与道具**

-   **特殊道具支持**：如活动涉及整箱售卖，提前准备**标准化的包装箱或礼盒**；若是散称，要提前提供足量的背心袋、托盘、保鲜膜等耗材给门店。
-   **陈列堆头支持**：配合商超理货员，提前一天规划出**端头堆位**（主通道位置），并确保陈列面积比平时至少扩大50%。
-   **价格标识与物料**：提前制作好凸显会员价的爆炸贴、POP海报，以及**试吃台**所需的牙签、垃圾盒等。

**四、 人员与售后保障（活动当天）**

-   **驻场促销员**：活动当天必须安排**至少1名专职促销员提前30分钟到岗**，负责试吃引导、剥皮切块服务（如榴莲、凤梨），能极大提升销量。
-   **紧急补货通道**：活动当天全程保持手机畅通，一旦商超断货，需承诺**2小时内紧急补货**（需提前安排好加班车和备用货源）。
-   **坏果包赔机制**：提前跟商超确定好“活动果品坏果售后”的口径（如当场换新或退款），**供应商要兜底调换**，避免因售后纠纷导致商超罚款，甚至影响货款结算。

**五、 给供应商的特别提醒（避坑指南）**

-   **签订备货协议**：若商超订货量特别大，务必在合同或订单中写明“预估订货量”与“最低保底收购量”，防止商超最终只卖出一半，剩余损耗全压在供应商身上。
-   **禁售风险品**：会员日通常人流量大，**不要准备易腐烂、难以保鲜且利润低的水果**（如熟透的芒果、娇贵的葡萄），优先选耐运输、出果率高的品种。

**建议动作：** 在活动开始前一周，主动给商超采购发一份《会员日供货准备确认函》，列明到货批次、预计销量、损耗承担比例，并以书面形式签字确认，这是保障自身权益最关键的一步。
