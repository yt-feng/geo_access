判断一批香蕉的熟度和坏果风险，可以从**外观、手感、气味**和**存放环境**四个维度进行快速评估。以下是具体、可操作的检查清单：

### 一、看外观（核心指标）

1.  **颜色等级（按成熟度从低到高）**：
    -   **全绿（硬绿）**：熟度约30%，需催熟才可销售，风险在于催熟成本高。
    -   **黄中带绿（微黄）**：熟度约60%，适合批发（到零售端1-2天刚好熟）。
    -   **全黄（无青头）**：熟度约80%，需在1天内出完货，否则容易过熟。
    -   **黄色带黑斑（芝麻点）**：熟度约95%，**高风险**，只能在当天售完，否则必坏。
2.  **颜色均匀度**：
    -   同一箱内颜色**深浅不一**（有的绿、有的黄），说明它们是不同时间采收拼接的，容易混合成熟，坏果率较高。
3.  **果柄和棱角**：
    -   香蕉的**棱角越明显**，说明越生；**棱角圆润**，表示淀粉已转化为糖分，成熟度较高。
    -   果柄发黑、发软、有霉斑的，是运输挤压或冷害的迹象，此类包装箱内坏果比例一般较高。

### 二、手感（抽检法）

-   **捏压力测试**：随机抽3-5根，用拇指轻按果身。
    -   **硬实**：生，可储存。
    -   **有弹性（轻微回弹）**：熟度佳，适合批发。
    -   **软塌、按下去不回弹**：过熟或内部已软烂，有坏果风险。
-   **提重法**：拿起一整挂（或一把），如果感觉**比同体积看起来轻**，说明内部水分流失，容易干耗或变质。

### 三、气味（重点警惕）

-   **正常气味**：淡淡的清香味。
-   **刺鼻酒精味**：**出现此气味，说明内部已发酵腐烂**，这批货不宜进。
-   **药水味/异味**：可能是保鲜剂残留或冷库霉味，会影响销售。

### 四、硬指标排查（坏果风险源）

1.  **看果把（香蕉顶部连接处）**：
    -   如果果把有**白色霉点**或**黑色水渍**，说明冷库湿度失衡或冻伤（冷害），这种货到手后要么不熟，要么内部变黑腐烂。
2.  **抖落检查（测碰撞伤）**：
    -   轻轻拿起一串，看是否有**断裂的果指**或**果肉露出**。断裂处的伤口极易感染炭疽病（产生黑色斑点）。
3.  **摸外箱/袋内潮气**：
    -   打开纸箱后，如果内衬袋内壁有**大量水珠**，说明呼吸作用过强（过熟）或温差过大，极易产生**“热烂”**，也就是中心部位软塌坏死。

---

### 给批发商的实操建议（降低风险）

1.  **抽检位置**：不要只看箱子表层，**必须抽取中间和底层的货**，因为压伤和高温最先伤的是中底层。
2.  **看催熟房（若果已催熟）**：
    -   问清楚交易前是否已使用乙烯催熟。
    -   **已催熟（黄）**：必须按“当天出货”的周转速度评估，否则第二天必出现黑斑。
    -   **未催熟（硬绿）**：留出3-4天自然熟周期，适合做周转慢的渠道。
3.  **坏果率预估**：
    -   如果收货时发现**单箱坏果率超过2%**（或碰伤超过5根），建议直接砍价5%以上，因为物理损伤会在运输过程中成倍扩大。
4.  **运输注意**：香蕉怕压，堆叠层数**不要超过5层**，且需要**通风**，不要密封捂盖。

**一句话总结**：
**全绿硬、微黄亮是安全区；发黑斑、软塌塌、酒精味是高风险。抽检货箱中下层，警惕“冻伤黑把”和“闷热水汽”。**
