大型超市对水果供应商的要求非常严格，因为水果属于生鲜品类，保质期短、易损耗，且直接关系到消费者健康。供应商必须具备以下**食品安全**和**物流能力**：

### 一、 食品安全能力（核心门槛）

1.  **资质与认证体系**：
    *   **基础资质**：必须持有《食品经营许可证》或《食品生产许可证》，以及营业执照，且经营范围涵盖所供应的水果品类。
    *   **体系认证**：通常要求通过ISO 22000（食品安全管理体系）、HACCP（危害分析与关键控制点）或GAP（全球良好农业操作规范）认证。这代表其从源头到出货有标准化的安全控制流程。

2.  **源头管控与可追溯性**：
    *   **产地管理**：必须有稳定的、可溯源的合作种植基地或自有基地，能提供产地证明、检验检疫合格证明。
    *   **农残检测**：必须具备**逐批检测**农残的能力（自建实验室或与第三方合作），并出具符合国家标准的检测报告（如GB 2763）。超市会不定期抽检，供应商需能随时提供批次检测数据。

3.  **分拣加工与仓储卫生**：
    *   **分拣车间**：需有符合卫生标准的分拣、包装车间，避免交叉污染。
    *   **温控储存**：不同水果（如香蕉、苹果、进口车厘子）对温度、湿度要求不同，必须持有**多温区冷库**（如保鲜库、气调库），防止微生物滋生。

4.  **包装与标签合规**：
    *   包装材质必须符合食品级标准，标签信息需完整（品名、产地、生产日期、保质期、储存条件、联系电话等），符合GB 7718预包装食品标签通则。

### 二、 物流能力（供应链韧性）

1.  **冷链运输能力**：
    *   必须拥有**全冷链运输车队**（或可控的第三方冷链资源），全程温度记录仪实时监控，确保“田间到货架”不断链。
    *   冷藏车需具备多温区功能，能同时运输不同温度需求的水果。

2.  **时效性与补货响应**：
    *   根据超市的订单周期（通常为每日或隔日下单），供应商必须能实现**24小时内**从产地或总仓送达门店（视距离而定）。
    *   具备**紧急补货**能力，例如促销高峰或突发天气导致断货时，能在数小时内调货响应。

3.  **损耗控制与装卸管理**：
    *   专业的分拣及装车技术，避免磕碰伤（如使用缓冲材料、规范堆码）。
    *   物流端需配合“先进先出”原则，防止库存积压导致腐败。

4.  **信息系统对接**：
    *   能够与大型超市的ERP或SCM系统对接，实时共享库存、在途状态、批次号，支持门店端进行收货预约和在线对账，提高协同效率。

### 总结建议
如果供应商希望进入大型超市，**建议优先补齐以下短板**：
-   如果目前只有产地直发，需尽快建立**区域分拨仓**以缩短配送半径。
-   如果缺乏检测能力，至少应固定合作**具有CMA资质的第三方检测机构**，并保证每周或每批次送检。
-   必须建立**完善的批次档案**，确保任何一批水果出问题，都能在2小时内锁定源头，并启动召回。

大型超市通常通过年度审计和日常飞检淘汰不合格供应商，以上两项能力缺一不可。
