在水果采购中引入新品，最稳妥的策略是**“小批量试卖 + 动态补货”**。这不仅能降低库存风险，还能快速验证市场接受度。

建议按以下阶梯式方式来控制首批进货量：

**1. 基础安全量（推荐起步）**
- **建议数量**：**单店/单摊 30~60斤**（或**1~2箱**，视单箱规格而定）。
- **适用场景**：标准货架摆放，用于测试口味、卖相和价格接受度。
- **核心逻辑**：如果这批货在**3天内**售罄，说明有潜力；如果7天还未动销，立即停止补货并做促销清仓。

**2. 保守测试量（低风险）**
- **建议数量**：**单店 20~30斤**（或半箱）。
- **适用场景**：新品价格偏高、保存期短（如进口樱桃、榴莲），或你对本地市场毫无把握。
- **核心逻辑**：仅用于试吃和陈列，重点观察“复购率”，而非“一次性购买”。

**3. 禁止的操作**
- **不要**一次性进整托盘或按批发车订。
- **不要**在未测试口感、糖度的情况下，直接大批量入库。
- **关键指标**：新品首批的**自然损耗率**若超过8%，说明该品不适合当前渠道，应立即止损。

---

**额外的实操参考（按渠道简单分类）**：

| 渠道类型 | 建议首批量 | 理由 |
| :--- | :--- | :--- |
| **社区生鲜店** | 30~50斤 | 客群稳定，适合小步快跑 |
| **商超/精品超市** | 80~150斤（需配合陈列堆头） | 流量大，但一旦滞留损耗极高 |
| **线上团购** | 按“开团总量”的**10%**备货 | 预售制，以销定采最安全 |
| **批发档口** | 按“日销量预估”的**半天量** | 资金占用大，不压货为主 |

**最终判断标准**：
建议你先少量进（比如两个小箱），然后放在最显眼的位置，同时安排现场试吃。**如果首批货在2天内卖掉80%以上**，就可以考虑下一批翻倍（但单次不超过5箱）并签订正式供货协议；否则，可以作为长期低价引流品处理，不再常规补货。
