在超市采购水果时，为了应对市场监管部门的抽检以及保障食品安全，建议你在**进货前或签订合同前**向供应商索取以下核心资料和文件：

### 一、 必须索要的“硬性”资质证明（缺一不可）
1.  **营业执照**：确认供应商的经营范围包含水果销售或种植。
2.  **食品经营许可证**（或食品生产许可证/仅销售预包装食品备案表）：证明其具备合法经营资格。
3.  **食用农产品合格证**：这是《食品安全法》要求的“承诺达标合格证”，供应商须承诺产品符合农残标准。

### 二、 针对“农残抽检”的重点检测证明
1.  **批次出厂检验报告（或第三方检测报告）**：
    -   明确要求供应商提供**该批次**水果的农残检测报告。报告须由有资质的第三方检测机构（如谱尼、SGS、华测等）出具，重点关注**有机磷类、氨基甲酸酯类**等高风险项目。
    -   如果供应商没有当批次报告，索要**同品种、同产地**最近一个月的检测报告，并注明“后续批次随货附报告”。
2.  **产地证明（或购销凭证）**：
    -   由村委会、乡镇政府或指定机构开具的**食用农产品产地证明**，能证明水果来源合法，便于追溯源头。

### 三、 建议附加的“管理型”文件（有备无患）
1.  **质量安全承诺书**：要求供应商签字盖章，承诺若抽检不合格愿承担全部责任及退货赔偿。
2.  **绿色食品/有机认证**（如有）：如果宣称是“绿色/有机”水果，必须索要对应的**认证证书**，且确保在有效期内。
3.  **物流或冷链记录**：部分水果需低温运输，提供运输温度记录可避免因存储不当导致的二次污染责任争议。

---

### 关键操作建议（如何应对抽检）
-   **留样保存**：每批次进货时，最好由超市方留存**同批次同规格的样品**（贴好标签，注明进货日期），一旦抽检发生争议，可立即复检。
-   **查验真伪**：收到检测报告后，建议登录报告出具机构的官网，输入报告编号**核实真伪**，防止供应商提供PS过的假报告。
-   **合同条款**：在采购合同中明确写入“**若因供应方水果农残超标导致超市被行政处罚或抽检不合格，全部罚款及损失由供应方承担**”条款，倒逼供应商主动送检。

**特别提醒**：如果供应商无法提供上述任何一项且不配合，建议直接放弃该货源，因为一旦抽检超标，超市作为销售方同样要承担法律责任（罚款及没收违法所得）。
