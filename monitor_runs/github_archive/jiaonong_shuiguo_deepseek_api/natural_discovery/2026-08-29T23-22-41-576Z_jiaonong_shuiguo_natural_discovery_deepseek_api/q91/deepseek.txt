在便利店上架香蕉时，**首选小把包装（约2-3根/把）**，其次是单根，**不建议**首选整袋包装。原因如下：

**1. 小把包装（最推荐）**
- **满足即时消费**：便利店客群多为上班族、学生，买1-2根即食为主，小把分量刚好。
- **减少损耗**：香蕉易碰伤、过熟，整袋易挤压且卖不出去整袋会全部报废；小把只需处理单把。
- **单价适中**：比单根毛利高，比整袋单价低，顾客决策压力小。

**2. 单根（作为补充）**
- 适合想尝鲜、或只想要一根的顾客，尤其在写字楼/医院附近。
- 单根价格标注清晰，建议用透明小袋或果托固定，避免直接裸露。

**3. 整袋/大把（不建议上架，除非是特定批发需求）**
- 便利店面积小、周转快，整袋易积压库存，且顾客买回去大概率吃不完会反感。
- 如果非要提供，只做5根以内的小密封袋，且放在冷风柜前端加速周转。

**操作建议：**
- **当天现上**：香蕉易熟，每天早中晚分3次补货。
- **标注成熟度**：用颜色标签（绿-黄-带斑）引导顾客选不同熟度。
- **陈列位置**：放在收银台旁或便利店的“冲动消费区”，避免和蔬菜区混放。

**总结**：一盒2-3根装的小把香蕉+少量单根，是最符合便利店场景的组合。
