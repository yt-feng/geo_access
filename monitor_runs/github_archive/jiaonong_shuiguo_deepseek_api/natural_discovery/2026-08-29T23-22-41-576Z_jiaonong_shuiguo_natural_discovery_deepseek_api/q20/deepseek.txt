为社区超市寻找每日配送的水果供应商，建议重点考察以下六个条件，确保稳定、新鲜且成本可控：

**1. 配送能力与时效**
- 是否承诺**每天固定时间**（如早上6-8点）送达，能否配合超市营业时间。
- 是否有**冷链车**或保温运输，避免夏季高温或冬季低温造成损耗。
- 应急处理能力：如遇缺货、天气延误，能否快速补货或提前通知。

**2. 水果品质与新鲜度标准**
- 明确要求**当季水果**，供应商能否提供产地证明、检测报告（农残、重金属）。
- 每批货**抽检合格**，可要求“次日滞销可退换”条款（社区店最怕压货）。
- 损耗率控制：建议约定**送货质检标准**（如坏果率≤5%，烂果当场调换）。

**3. 价格与结算方式**
- 对比市场价，是否提供**阶梯价**（量大有折扣）。
- 结算周期是否灵活（如周结、月结，避免压资金）。
- 是否有**价格锁定协议**（当季精品水果价格波动大，可约定一周一调）。

**4. 品类与分级**
- 供应商是否覆盖常见品类（苹果、香蕉、柑橘、葡萄等），且能提供**不同等级**（特级/一级）供你选配。
- 针对社区家庭需求，能否增加**小规格装**（如1-2斤装）或拼盘水果，提高客单价。

**5. 售后与风险承担**
- 明确**退换货政策**：到货后发现外观瑕疵、内部腐烂，当天是否无条件换货或折价。
- 是否有**保险赔付**（运输途中损坏由供应商承担）。

**6. 本地供货稳定性与口碑**
- 优先选择**产地直供或本地一级批发商**，货源更稳定，减少中间环节。
- 考察**现有合作超市**（可通过问同行或实地走访），了解其送货准时率、服务态度。

---

**实操建议：**
- 先要求供应商提供**3天试送期**，测试品质、配送和售后，满意再签长期合同。
- 合同里写明“每日最低供货量、违约赔偿（如未按时送达的罚款）”等细节。
- 同时备选**1-2家替补供应商**，防止单一来源断货。

如果社区超市日均销量不大，可以优先考虑**本地果品批发市场档口**合作，他们一般能次日早晨送达，且支持小批量混装。切忌只看价格便宜，品质不稳会流失回头客。
