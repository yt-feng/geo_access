针对便利店小面积、低客流、高周转的特点，水果采购的核心策略是**“宁少勿多、按日裁剪、场景即食”**。

以下是具体的操作建议，分为品类控制、损耗控制和补充技巧三部分：

### 一、品类控制（“少而精”原则）

便利店不适合做“水果超市”，必须做**“决策前置”**。

1.  **锁死上限（SKU数量）**：
    -   门店面积小，水果区域建议只保留 **6-8个SKU**（单品数）。
    -   陈列面积控制在1-2组风幕柜或1组中岛货架，**绝不用地堆**。

2.  **结构配比（70%畅销 + 30%高毛利/冲动型）**：
    -   **基础引流款（必做）**：香蕉、苹果（如红富士）、梨（如秋月梨）。这些是家庭日常刚需，复购率高，走量快，不容易积压。
    -   **时令尝鲜款（选做）**：只在当季主推1-2个爆款（如夏天的麒麟瓜、秋冬的赣南脐橙）。**注意：不要一次性上架全品类**，要一个季一个爆款。
    -   **即食小份装（盈利款）**：切好的果切（如西瓜拼盘、菠萝蜜盒装）。这是便利店毛利最高、最好卖的形式，因为顾客在便利店买水果多是“立刻吃”。

3.  **绝对规避**：
    -   **避免**进货整箱的榴莲、芒果、山竹等贵重且不易一次卖完的水果（除非你有温控柜台且客流量极大）。
    -   **避免**进货需要长期保存且易发霉的品类，如草莓、杨梅（除非能保证当天售罄）。

### 二、损耗控制（核心原则：用“陈列”和“加工”替代“库存”）

小门店的损耗大多来自“卖不掉”而非“进价高”。

1.  **采购频率：少批多次**
    -   不要一次性大量进货。尽量做到 **“每天早上一批”**（保证上午新鲜），如果下午2点前销量好，下午再补充一批小货。
    -   宁可断货，不可积压。缺货的损失远小于损耗的损失。

2.  **“表面陈列法”**：
    -   货架正面只放最饱满、最漂亮的2-3层。
    -   下面或仓库放“备货”，但备货量**永远不超过当日预估销量的50%**。

3.  **分级处理（把“坏果”变成“毛利”）**：
    -   每天下午5点后，将外观有轻微瑕疵（但未腐烂）的水果，转做 **“果切”**（切片/切块），贴上“今日特价”标签，以8-9折快速清掉。
    -   如果实在卖不掉，直接在晚间闭店前打折处理（如“晚上8点后8折”），**绝不隔夜**（损耗会翻倍）。

4.  **渠道与包装采购**：
    -   进货时**能买小包装的绝不买大箱装**（如香蕉按把进，苹果按4-6个的锁鲜装进）。
    -   优先选择供应商能提供“坏果包赔”的货源。

### 三、额外补充（提升利润空间）

1.  **“组合套餐”**：
    -   把水果和零食（如搭配一包每日坚果）或酸奶组合销售，提高客单价，摊薄单品毛利压力。

2.  **数据复盘（每天5分钟）**：
    -   每天统计：昨日全天**卖了多少个单品**。
    -   如果某个单品连续2天销量垫底且剩余库存较多，**立即下架**，暂停补货，直到清完库存为止。

### 执行清单（每日操作参考）

-   **早上**：上架新鲜水果（数量按昨日销量×1.2倍）。
-   **中午**：观察动销，把卖得慢的品种前置到黄金位置。
-   **下午4-6点**：将散装水果挑拣，好的做果切，有瑕疵的做特价。
-   **晚间7点后**：全场水果按剩货量打折，清空当日库存。

最后一句口诀：**“摆得少、补得快、卖不掉就切盒卖。”** 只要坚持这两个“少（少SKU、少库存）”，损耗基本能控制在5%以内。
