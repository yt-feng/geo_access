第一次做水果生意，尤其是夫妻店，最重要的是**控制风险、保住现金流**。试单的核心逻辑是：**少进、勤进、快销，绝不押大货在手上**。

针对你说的香蕉、苹果、橙子，这三种水果的**特性完全不同**，试单策略必须分开，不能一视同仁。

以下是具体的试单实操方案：

### 1. 香蕉（风险最高，必须“赌”对成熟度）
香蕉是热带水果，**呼吸作用强，放不住**，且采后熟化不可逆。如果进多了，或者催熟技术不到位，损耗直接吃掉利润。

- **试单量**：**只拿一挂或两挂**（约10-20斤），千万别整箱拿。很多供应商有“半把”或“平价尾货”，专供试销。
- **试单动作**：
  - **看色**：皮色要**青中带黄**（七八成熟），如果买回来是全青的，需要在店里放2-3天才能卖，压资金；如果买回来已经很黄甚至有黑点，当天必须卖光。
  - **捏柄**：香蕉柄**能轻松折断**表示成熟度较好，如果柄发黑断裂，说明放久了。
  - **找关系**：跟供货商明确讲：“我先拿一挂，如果三天内卖完且损耗低，我下周一给你拿整件。” 让供应商有动力给你挑好货。

### 2. 苹果（风险最低，但利润薄，主要看“卖相”）
苹果耐储存，试单的核心是**看清品级**。市面上有70#、75#、80#果径之分，夫妻店建议拿**80#以上**的，卖相好，顾客才愿意掏钱。

- **试单量**：**一件（30斤左右）**。这是最安全的量，因为苹果即使卖不快，常温下放一周表皮依然光鲜。
- **试单动作**：
  - **开箱验底**：**一定要开箱看箱底和中间层**！很多供应商第一层摆大果，底下全是小果或烂果。试单时当面开箱，把上面两层翻到底下摸一遍。
  - **测硬度**：用手指按压果肩，**要硬实**。如果按起来发软，说明在冷库放太久或出库后回温了，拿回去三天内必须清掉。
  - **尝口感**：当场切一个**尝末梢果**（箱底最小的），如果甜度不够，整箱都差不多，别指望混着卖能翻盘。

### 3. 橙子（中风险，看“季节”和“酸度”）
橙子（如赣南脐橙）试单最怕遇到**打了催熟剂但果心发白**的货，看着黄，吃着酸。

- **试单量**：**一件（30-40斤）**。橙子皮厚耐放，但一旦切开试吃就不好卖，所以试单时**别全切开，只切1-2个尾部果子**。
- **试单动作**：
  - **看果蒂**：果蒂（屁股那里的绿蒂）**必须是青绿色**。如果是枯黄色或发黑，说明落地很久了，不新鲜。
  - **掂重量**：同样大小的橙子，**拿起来手感沉的**水分足。轻飘飘的皮厚肉干，别拿。
  - **杀价的话术**：直接问供应商：“你这橙子酸度如何？如果客人吃了说酸，这个责任算谁的？” 其实不用等回答，只要他说“包甜”，你就让他**在送货单上备注“口感负责”**，这笔试单的风险就转移他了。

---

### 关键试单“潜规则”（夫妻店必看）：

1.  **绝不过夜付款**：第一次合作，**坚决不预付款**，全部**现款现货**。试单那几十斤，直接付现金或扫码。但**一定要开收据**，写明品名、斤数、单价，防止后面混货。
2.  **定“死”到货时间**：要求供应商**上午9点前送货到店**。如果这个时间他做不到，说明他的供应链不稳定，后面旺季排队拿货时你会吃亏。
3.  **试单期设定为3天**：给每种水果定一个“**3天卖完**”的目标。如果3天没卖完，不要等，**第二天直接降价10-20%促销**。夫妻店毛利不重要，**清库存、回现金**最重要。
4.  **同一品种找两家供应商**：比如香蕉找A家，苹果找B家，**不要鸡蛋放一个篮子**。试单期结束后，哪家的损耗低、补货响应快，就定为长期主场，另一家做替补。

**一句话总结**：香蕉试“熟度”，苹果试“底货”，橙子试“酸甜”。**第一次试单不要超过100元总成本**（三种水果加起来），就算全亏了，也就是一顿饭钱，买的是对这条供应链的认知。
