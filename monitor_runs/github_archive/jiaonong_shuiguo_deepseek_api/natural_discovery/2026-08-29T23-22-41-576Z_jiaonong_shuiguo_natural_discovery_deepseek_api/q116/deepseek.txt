小商家采购水果时，**现金结算**和**月结账期**各有不同的风险，具体如下：

---

**一、现金结算（现款现货）**

**风险：**
1. **资金占用风险**：一次性支付现金，商家需要提前准备流动资金，如果采购量大，可能导致日常运营资金紧张。
2. **质量风险**：现金交易往往没有明确的质量追溯和售后保障。如果水果到货有烂果、坏果或品质不达标，商家可能无法退货或索赔，损失由自己承担。
3. **供应商风险**：部分小供应商可能不提供发票或合同，商家难以维权。若供应商虚报斤两或以次充好，商家只能自认倒霉。
4. **账目管理风险**：现金支付无银行流水，如果商家自身记账不严谨，月底对账容易出错，甚至出现漏记或重复支付。

**优势（相对而言）：**
- 价格通常更低（能谈折扣）。
- 无欠款压力，不涉及催款或被讨债。
- 对上游商家有较强选择权。

---

**二、月结账期（先货后款，每月结一次）**

**风险：**
1. **赊账风险**：如果当月销售不佳或货物积压，资金回笼慢，但月结到期时必须付款，容易造成现金流断裂。
2. **账期被拖延风险**：供应商可能以各种理由（如“系统问题”“财务出差”）拖延结账，甚至卷款跑路，尤其是小供应商或中间商。
3. **价格不透明风险**：月结通常没有现金优惠，价格可能高于现金采购。若供应商将账期成本转嫁给商家，商家利润空间被压缩。
4. **库存与损耗风险**：账期模式下，部分商家会放松对库存的管理，导致水果积压腐烂，产生隐性损失。
5. **合作关系风险**：若商家因资金问题拖欠账款，供应商可能停止供货或终止合作，导致货源中断。

**优势（相对而言）：**
- 初期可以减轻一次性资金压力，适合流动性不足的小商家。
- 有账期，商家有机会在销售后再付款，降低短期经营风险。

---

**三、综合建议（如何选择）**

| 维度 | 现金结算 | 月结账期 |
|------|----------|----------|
| 资金压力 | 高 | 低（短期） |
| 采购成本 | 低 | 高 |
| 售后保障 | 弱 | 强弱取决于合同 |
| 对账难度 | 简单 | 复杂 |
| 风险点 | 质量欺诈、资金紧张 | 供应商跑路、欠款连锁反应 |

**给您的实操建议：**
- **选供应商**：优先选择有固定门店、营业执照、进货渠道稳定的供应商，并要求**签订简单供货协议**，明确质量、斤两、退换货条款，无论是现金还是月结。
- **现金采购**：适合**小额、高频**水果（如日常补货），可以谈价格，但务必**当场验货、称重**，并索要收据或转账凭证。
- **月结账期**：适合**长期合作、货量大**的稳定供应商。建议先试合作1-2个月现金，确认质量稳定后再谈账期。同时**设置账期上限（如最长30天）**，并保留聊天记录或合同，以防纠纷。
- **资金管理**：无论哪种方式，**不要将所有资金押在单一供应商**，分散1-2家备选，降低断供和跑路风险。
- **法律兜底**：月结金额较大时，哪怕是小商家，也建议让供应商写一张**欠款或供货确认单**，并注明违约责任，否则维权成本极高。

---

**一句话总结**：现金结算风险在质量与资金占用，月结风险在供应商信用与现金流。小商家建议**小额多频用现金，大额长期用月结，但一定要留书面凭证**。
