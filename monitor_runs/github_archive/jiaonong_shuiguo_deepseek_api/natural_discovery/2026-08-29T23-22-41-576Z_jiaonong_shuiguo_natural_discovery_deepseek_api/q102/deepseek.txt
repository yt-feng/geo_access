在采购企业福利水果礼盒时，**建议优先选择同时支持开发票和定制包装的供应商**。这两项能力直接影响报销合规性和员工满意度。

具体判断标准如下：

**1. 发票能力（必须项）**
- **增值税专用发票**：若企业有一般纳税人资格，可抵扣进项税，必须确认供应商能开具专票。
- **增值税普通发票**：小规模企业或个人独资企业通常只需普票。
- **开票内容**：需确保发票明细能开“水果”、“水果礼盒”或“食品”，避免出现“礼品”字样（部分企业财务制度禁止将礼品入账福利费）。
- **抬头和税号**：提前确认供应商能准确填写贵司的完整开票信息（含地址电话或银行账号）。

**2. 定制包装（加分项，视需求而定）**
- **常规定制需求**：印LOGO、祝福语、企业名称的礼盒/手提袋，多数正规水果供应商可提供，但需问清**MOQ（起订量）**（如500盒起）和**打样费**是否另计。
- **非标定制（如异形盒、保温袋、冷链箱）**：需确认供应商是否有自己的包装工厂或有稳定合作厂，否则交货期可能延长。
- **高性价比方案**：若采购量小（低于100份），可优先选供应商**现有的节日主题礼盒**（如中秋、春节款），要求贴带LOGO的不干胶标签，成本通常更低。

**3. 额外风险提醒**
- **资质验证**：要求供应商提供食品经营许可证、营业执照（含水果销售范围），并要求其提供**水果的检验检疫证明**（尤其进口水果）。
- **物流与赔付**：确认坏果、磕碰的赔付条款（如按个赔付或补发），并写入合同或订单备注。
- **试用建议**：首次合作建议先采购**少量试发**，检查果品新鲜度、包装完整性，再批量下单。

**执行建议**：将“**可开专票/普票+支持LOGO定制包装+起订量与交期写明**”作为筛选供应商的硬性条件，在询价时直接要求对方在报价单中列明这三点，避免口头承诺。若供应商无法定制包装，但发票合规，可分开采购包装（另找印刷厂）与水果，但需自行组装，成本更高不推荐。
