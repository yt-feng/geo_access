在采购香蕉用于烘焙时，**成熟度应优先于价格**，但两者需要结合考虑。以下是具体建议：

### 1. 首选“成熟度中高、带斑点”的香蕉
- **原因**：烘焙中（尤其做香蕉蛋糕、马芬）需要香蕉的**甜度**和**天然香气**，而这些在香蕉完全成熟、表皮出现黑斑（俗称“芝麻点”）时达到峰值。此时果肉软糯、甜度最高，烤出的蛋糕更香甜，且果肉易压成泥。
- **不建议**：选全青或半黄的香蕉（风味不足，口感发涩）；也不建议选过熟至黑腐的（有酒味或酸味，影响成品）。

### 2. 考虑“价格”时注意“损耗与出成率”
- 成熟度高的香蕉通常更便宜（因为不耐储存），但要注意**采购量**与**使用周期**。如果店铺卖得快，可以按需采购低价熟果；如果囤货，可能因过熟造成损耗，反而增加成本。
- 合理策略：**少量多次采购**，根据每日销量预估，优先保证熟度合适，避免因追求低价而大量囤积未熟香蕉。

### 3. 附加建议
- 与供应商协商：明确要求“带斑点的熟蕉”，可要求定期配送，或允许当日按需调整量。
- 如果偶尔遇到价格极低的青香蕉，可放置2-3天催熟，但需预留时间，且注意通风避免腐坏。
- 采购时检查果皮：表面有黑斑但果肉无黑点、无酒味为佳。

**总结**：在成熟度达标的前提下，再比较价格；优先选择“熟度达标且价格合理”的批次。这能保证蛋糕品质，同时控制实际成本。
