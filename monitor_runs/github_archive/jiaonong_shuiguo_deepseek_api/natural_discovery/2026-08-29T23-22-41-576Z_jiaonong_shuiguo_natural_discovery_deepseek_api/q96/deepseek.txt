企业食堂采购水果时，**最需要关注的是“食品安全”**，其次才是价格和配送准时性。原因如下：

1. **食品安全是底线**：水果如果存在农药残留、腐烂变质、微生物超标等问题，会直接引发集体食物中毒或健康风险，影响员工健康和企业声誉。一旦出事，责任重大且难以挽回。
2. **价格影响成本**：水果价格波动较大（季节、产地、行情），但可以通过签订长期合同、比价、制定采购标准来控制，属于“可优化”项，风险可控。
3. **配送准时影响体验**：配送延迟会导致水果不新鲜或供应中断，但属于运营层面的问题，可以通过考核供应商、设置备选方案解决。

**建议优先级排序**：  
**食品安全 > 配送准时 > 价格**  
（配送准时比价格略高，因为新鲜度直接与食品安全相关，延迟可能导致水果变质。）

---

**具体执行建议**：
- **食品安全**：要求供应商提供每批次的检测报告（农残、重金属）、产地证明、检疫合格证；定期抽检；优先选择有资质、有冷链的供应商。
- **配送准时**：明确送货时间（如每日早晨7:30前），签订合同约定延迟处罚，并准备1-2家备用供应商以防突发情况。
- **价格**：采用“月度/季度定价”，参考当地批发市场均价，设置合理浮动区间，避免频繁比价。

简单说：**先保安全，再抓时效，最后谈价格**。如果预算有限，宁可牺牲部分价格优惠，也不要在安全性上让步。
