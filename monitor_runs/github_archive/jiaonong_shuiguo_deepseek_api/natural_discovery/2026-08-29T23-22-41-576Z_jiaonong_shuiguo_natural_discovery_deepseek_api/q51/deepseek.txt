针对茶饮店水果口味波动的问题，**建议采用“固定核心产地 + 灵活补充批次”的策略，而非完全固定**。

原因和具体操作如下：

**1. 为什么不建议完全固定产地？**
- **季节风险**：单一产地受气候影响大（如雨水多导致甜度下降），一旦减产或品质下滑，断供风险高。
- **成本波动**：固定产地若遇价格暴涨（如台风季柠檬），毛利率会瞬间被吞噬。
- **口味单一**：不同产地的同类水果（如云南夏黑 vs 新疆无核白葡萄）风味差异明显，完全固定会限制你开发季节限定款的能力。

**2. 核心建议：锁定“品质参数”而非“产地标签”**
- **制定验收标准**：比如对芒果，固定**糖度（Brix≥15）**、**果肉厚度（≥2cm）**、**纤维感**、**成熟度（7-8成熟）**。无论产地怎么换，只要达标就收货。
- **分批试采**：在采购前3-5天，要求供应商寄送小样，你亲自试糖度、试口感，确认合格后再发大批量。

**3. 供应批次管理策略**
- **主力款（如招牌杨枝甘露）**：固定2-3个经过验证的稳定产地（如台农芒果），但**每批次到货后必须抽检**，不合格拒收。
- **季节款/特调款**：可以使用“短周期切换”，比如夏季用海南芒果，秋季切到广西芒果，提前一周测试新批次口味。

**4. 实际操作建议（防踩坑）**
- **签订“品质协议”**：在采购合同中写明糖度、酸度、色泽的具体数值范围，一旦超出可要求换货或折价。
- **小批量试单**：新产地第一次合作，只采购3-5天用量，试销后根据顾客反馈决定是否转正。
- **建立“产地花名册”**：记录每个产地、每个批次的口感特征（如“菲律宾菠萝偏酸，适合配椰奶；湛江菠萝偏甜，适合单饮”），形成数据库。

**总结**：**固定品质标准，柔性切换产季**。这样既能保证招牌饮品口味稳定，又能灵活应对市场波动，还能在季节更替时推出差异化新品。如果有条件，尽量与当地大型批发市场或产地直供商建立长期合作，优先保证你的“品质优先级”。
