在水果采购合同中，**“坏果率”赔付比例没有全国统一的法定标准**，完全由买卖双方在合同中自行约定。但根据行业惯例和市场常态，以下是给你可执行、可判断的参考建议：

**1. 核心赔付标准（可直接套用）**
- **起赔点：** 建议约定为 **3% - 5%**。即坏果率超过这个比例，买方就有权要求卖方赔付。
- **赔付比例（阶梯式）：** 不要笼统写“按比例赔”，要写清楚计算方式：
  - 坏果率 5% → 10%：按**实际坏果重量占总重比例，乘以合同总价**赔付（例如：坏果8%，则赔付总价的8%）。
  - 坏果率 10% → 20%：建议约定**赔付总价的15% - 20%**，或者直接**拒收整批货**（若严重变质影响二次销售）。
  - 坏果率超过 20%：**视为根本违约**，买方有权**解除合同、全额退款**，并要求卖方赔偿运费、仓储费等损失。

**2. 关键细节（务必写进合同）**
- **“坏果”定义：** 必须写明什么是坏果。例如：**“指腐烂、发霉、有明显机械损伤导致汁液外流、或果肉变味无法销售的果实。”** 表皮轻微擦伤、有斑点但果肉完好，通常不视为坏果。
- **抽样规则：** 写明如何核定坏果率。约定“双方共同在到货后 **24小时内**，随机抽取 **每箱按10%比例（或至少5箱）** 开箱清点，坏果数除以抽样总数即为坏果率”。
- **赔付时效：** 约定“卖方在接到书面索赔通知后 **7个工作日内** 支付赔款，逾期每日按应赔金额的 **0.5%** 支付违约金”。
- **特殊情况：** 如果是冷链运输，应注明“因运输途中温度失控导致的高比例腐烂，由承运方或卖方先行垫付赔偿”。如果货品是易腐水果，建议明确“到货即验收，超过48小时未提出异议视为货品合格”。

**3. 实操建议（避坑）**
- **千万别只写“坏果无偿换货”**：因为水果是易腐品，换货可能无法及时卖出去。**优先约定“折价赔付”（退差价），而非“补发”**。
- **保留证据：** 要求司机或收货员当场拍照、留样，双方在验收单上签字确认坏果数量，否则后期扯皮维权成本极高。
- **如果对方是果农/批发市场散户：** 他们通常只认“超过10%才赔”，那么你可以谈：“5%以下不赔，5%-10%按半价赔，超过10%全额赔”，这样更容易达成一致。

**如果你想直接写进合同的一句话版：**
> “乙方保证交付水果的完好率不低于 **95%**（即坏果率≤5%）。验收时若坏果率超过5%，甲方有权按实际坏果比例扣减货款；若坏果率超过 **15%**，甲方有权拒收整批货物并要求乙方承担全部运输、仓储损失；若因乙方隐瞒质量问题导致甲方销售受损，乙方需双倍赔偿。”

**提示：** 以上比例是基于一般批发市场的风险控制逻辑，如果你采购的是高端水果（如进口车厘子、草莓），建议将起赔点压得更低（如1%-2%），因为这类水果单价高、毛利低。最终数字一定要结合你的采购价格和销售周期去谈。
