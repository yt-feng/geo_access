关于商超采购菠萝是卖整果还是切好的，**建议以“整果为主，现场切售为辅”的组合模式**，具体取决于门店的定位、客流和损耗控制。

以下是具体分析和执行建议：

**一、为什么不能只卖一种？**

1. **整果（菠萝）**：适合家庭消费，客单价高，但最大的痛点是**削皮难、容易扎手**，且菠萝的“内伤”（黑心、过熟）在切开前无法发现，损耗率较高。
2. **切好的（菠萝块/菠萝杯）**：适合即食场景（写字楼、学校周边、年轻客流），单价低但毛利高，且能**即时发现坏果并剔除**，降低损耗。但切好的保鲜期极短（一般冷藏不超过24小时），卖不完就是纯损耗。

**二、具体操作建议（可执行方案）**

1. **整果为主力**（建议占比60%-70%）
   - 陈列：放在水果区显眼位置，挂上“免费代削皮”或“现场现切”的标识。
   - 定价：整果按斤卖，定价略低于切好的单价，吸引家庭用户购买。
   - **关键动作**：设置**削皮服务台**，配备菠萝刀和一次性手套，由店员现场削皮。这样既解决了顾客怕麻烦的痛点，又能把“切削产生的边角料”变为增值品（见下条）。

2. **切好的为补充**（建议占比30%-40%）
   - **售卖形式**：切成1/4块、1/8块或装杯（加盐/糖水），用保鲜膜封好，贴当日标签。
   - 摆放位置：放在冷柜或冰台上，旁边放一次性竹签，鼓励试吃。
   - **重点原则**：**只切整果中的“熟度中等偏上”的**，因为熟度高的整果不耐储存，但你切出来卖就正好利用黄金食用期。
   - **损耗对冲**：将削皮产生的果芯、带皮的边角料，做成**菠萝汁**或**菠萝糖水**单独售卖（成本极低，毛利高），这能有效覆盖切果的损耗。

3. **按客流动态调整**
   - 工作日白天：多切果，因为周边上班族、学生是主力。
   - 周末/节假日：多摆整果，家庭采购多，且周末门店人流量大，可以现场让顾客看到削皮过程，增加信任感。

**三、核心风险提醒（必看）**

- **切果的“变质”风险**：切好的果肉在常温下极易滋生细菌，**必须全程冷链（0-4℃）**，并且只做当天的量，**过了当日关店前2小时，宁可打折清场，也不要留到次日**。
- **整果的“黑心”问题**：进货时抽查，如果发现一批货源黑心率高，整果建议改为“先切后卖”模式，避免砸招牌。

**四、最终决策建议**

如果你是**小型社区店**：建议**主卖整果（带代削皮服务）**，切果少量备货（每天切5-10个），因为社区店客群稳定，整果复购率高。

如果你是**大型超市/生鲜店**：采用**“整果+切果+现榨汁”三合一**，把切果区做成一个“加工增值区”，能明显提升客单价。

**最简单的判断标准**：你先观察一周，若切果每天下午前就卖完，就加大切果比例；若每天下午还剩大量切果，就降低切果数量，把精力放在整果和削皮服务上。
