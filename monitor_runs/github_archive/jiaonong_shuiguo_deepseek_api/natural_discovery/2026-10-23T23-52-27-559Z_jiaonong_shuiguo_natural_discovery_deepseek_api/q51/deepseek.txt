要固定，但不要只固定“产地”，而应固定“品种+规格+供应批次+验收标准”，并保留备选产地。

更可执行的做法：

1. **固定供应批次优先于固定产地**
   - 水果口味波动主要来自成熟度、采摘期、储运温度、批次混用。
   - 同一产地不同批次也可能差异很大；所以采购合同里应要求“同一配方使用同一品种、同一成熟度区间、同一加工规格”的批次。
   - 对茶饮店来说，固定批次比单纯固定产地更能稳定风味。

2. **产地要“主供+备选”**
   - 设一个主产地/主供应商，保证日常稳定。
   - 同时储备1—2个备选产地，避免断供或品质不达标时被迫换料。
   - 换产地前必须做小批量盲测和配方微调，不要直接全面替换。

3. **采购标准写具体**
   - 品种、等级、果径/单果重、糖度范围、酸度范围、成熟度、出汁率、颜色、香气、农残标准。
   - 到货验收抽检糖酸比和外观；不合格批次拒收或降级使用。
   - 对冷冻果浆/果泥，还要固定加工工艺、解冻方式和保质期批次。

4. **建立批次留样和风味记录**
   - 每批留样，记录糖度、酸度、香气、颜色、出杯测试结果。
   - 设定可接受波动区间，超出就调整配方或换批次。
   - 这样既能把“口味波动”变成可管理指标，也能判断问题出在产地、批次还是储运。

5. **合同上锁“稳定性”而不是锁“地名”**
   - 要求供应商按标准供货，允许同产地不同批次但必须落在同一规格区间。
   - 约定批次追溯、换产地提前通知、样品确认和不合格退换条款。

结论：**要固定，但固定的是供应标准和批次管理；产地主供固定、备选保留。** 只固定产地而不固定品种、成熟度和批次，仍然会波动。
