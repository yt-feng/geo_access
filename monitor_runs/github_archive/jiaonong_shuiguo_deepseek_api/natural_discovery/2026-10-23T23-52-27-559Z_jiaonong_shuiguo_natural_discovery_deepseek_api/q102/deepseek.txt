**1. 开发票：必须支持**
- 企业福利采购通常要入账、报销和税前扣除，供应商必须能开合规发票。
- 优先确认：能否开**增值税专用发票**（一般纳税人企业可抵扣时更有利）或**普通发票**；发票品名能否开“水果礼盒/食品”等与采购内容一致的项目；能否按企业要求开票到指定抬头和税号。
- 注意：水果属于农产品，部分供应商可能只能开免税普票或代开发票，要提前确认你们财务是否接受。

**2. 定制包装：强烈建议支持，但按需选择**
- 企业福利礼盒通常需要体现企业标识、节日祝福、员工关怀卡片等，定制包装能提升福利感知。
- 确认定制范围：外箱/手提袋/腰封/贺卡上的LOGO、企业名称、祝福语；起订量；打样时间和费用；定制后是否影响退换货。
- 如果预算有限或员工人数少，可只做**贴纸/腰封/贺卡**轻定制，成本低、起订量低。

**3. 采购时的可执行建议**
- 供应商筛选表里直接列两项硬指标：**能否开票、发票类型；能否定制、起订量和打样周期**。
- 合同写明：开票时间、发票类型、票面品名；定制内容确认稿、打样确认、交付时间；因定制导致的错发/质量问题责任。
- 要求先看样品和发票样例，再批量下单。

结论：开发票是硬性要求；定制包装不是所有场景都必须，但企业福利采购中建议优先选择支持轻定制的供应商。
