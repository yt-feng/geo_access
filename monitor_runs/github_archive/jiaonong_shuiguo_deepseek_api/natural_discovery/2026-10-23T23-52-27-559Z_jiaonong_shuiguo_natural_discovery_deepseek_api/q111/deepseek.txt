# 判断检测报告是否对应当前批次

## 核心原则：三对一验——对批号、对样品、对时间、验真伪

---

## 一、对批号（最关键）

1. **报告上的样品批号/生产批号**必须与送货单、包装箱标签上的批号**完全一致**（包括字母、数字、分隔符）。
2. 如果是"报告未标注批号、只写'送检样'"——**不能直接认定为对应本批**，需供应商补充说明或重新确认。
3. 抽取几箱实物核对箱标批号，防止"报告是一批、货是另一批"。

## 二、对样品信息

1. **品名、品种、规格（等级/大小）、产地**与本次采购一致。
2. **抽样数量、抽样地点**合理（如报告写的是产地抽样，而货是分装后发货，要留意中途换货风险）。
3. 报告若只写"水果"等宽泛类别、无具体品名，对应性存疑。

## 三、对时间

1. **报告出具日期/检测日期**应在合理时效内：
   - 农残等常规项目一般要求与到货时间接近（行业常见做法是批次对应、非按天算，但日期明显早于本批生产/采收期的不算数）。
   - 报告日期**早于本批采收/生产日期**的，逻辑上不可能对应本批。
2. 注意报告有效期与批次的关系：报告针对的是"那个送检样"，不是"这个批"。

## 四、验真伪（防PS和套用报告）

1. 通过出具机构官网/官方公众号/二维码**查询报告编号**，核对报告内容与原件一致。
2. 核对**检测机构资质**（CMA/CNAS标志）、报告编号格式、骑缝章、防伪标识。
3. 联系人向供应商索要**该批次对应的送检委托单或抽样记录**，交叉印证。
4. 警惕：同一份报告反复用于多个批次、报告无编号、机构查无此报告。

## 五、按风险分级处理

| 情况 | 处理建议 |
|---|---|
| 批号、品名、时间全部吻合且可验真 | 可采信，留存复印件/电子件归档 |
| 批号缺失但其余吻合、供应商为长期合格供方 | 书面要求供应商出具"该报告对应本批"的确认函，并保留抽检权 |
| 批号不符、日期不合逻辑、无法验真 | 不采信，要求重新送检或自行抽样送检 |
| 高风险品类（如鲜食、农残敏感品种） | 不依赖供应商报告，到货后自行抽样快检或送第三方 |

## 六、留痕与合同保障

- 在采购合同/质量协议中明确：**报告须与批次一一对应，供应商对报告真实性负责，报告不实承担退换货及赔偿**。
- 每批到货时**登记报告编号、批号、检测日期**，建立台账，便于追溯和发现"一报告多用"。
- 对重点批次可**自行留样**，发生争议时以自留样复检为准。

---

**一句话判断法**：批号对不上、日期说不通、官网查不到——三条中任一条不满足，就不能认定报告对应本批，应要求补充或自行送检。
