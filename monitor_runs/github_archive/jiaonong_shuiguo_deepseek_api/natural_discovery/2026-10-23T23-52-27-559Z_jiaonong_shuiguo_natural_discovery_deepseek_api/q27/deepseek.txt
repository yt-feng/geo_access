判断“大小规格是否适合门店销售”，核心不是只看单个果子大小，而是看**规格是否稳定、是否匹配门店客群和售卖方式、是否影响损耗与毛利**。可按下面几步做。

### 1. 先按门店售卖方式定规格方向
- **散卖/堆头**：规格允许有差异，但同一批不能大小混得太明显。苹果一般按横径或单果重分档，橙子按横径或单果重分档。
- **预包装/按份卖**：要求单果大小更均匀，否则同一袋/盒里大小差太远，顾客会觉得不值。
- **礼盒/精品**：规格必须整齐，大小、颜色、果形一致性要求最高。

### 2. 到货验收看四个指标
**① 横径/单果重是否落在约定档位**
- 不要只看“大不大”，要看**是否集中在同一档**。例如同批苹果大部分集中在一个横径区间，少量偏离可接受；如果一批里跨两三个规格，就不适合直接上架。
- 现场用卡尺或分选圈抽检，至少随机抽 30～50 个，记录最大、最小、平均和超档比例。

**② 大小均匀度**
- 同一陈列面/同一包装内，大小差异不能一眼看出明显分层。
- 建议设一个内部标准：超档或明显偏小的比例超过约定范围，就要求供应商分选或降级处理。

**③ 大小与品质是否匹配**
- 大果不一定好卖。大果若皮厚、空腔、口感差，反而不适合。
- 小果若口感好、价格合适，适合社区店、水果切、家庭小份购买。
- 橙子要特别看**皮厚、汁水、空壳感**；苹果看**果形、硬度、表面伤**。规格大但品质不稳，不要按大规格卖。

**④ 大小是否影响损耗**
- 过大果在散卖中容易剩货、被挑剩；过小果在礼盒/精品区不成立。
- 门店要结合日均销量判断：规格越偏大，越依赖高客单或礼品场景；规格偏小，越依赖高频、性价比场景。

### 3. 用“门店销售测试”判断是否适合
上架前做小批量试销：
- 同一价格带下，观察**顾客拿取率、称重客单、挑剩率**。
- 散卖看：顾客是否反复挑大小、剩货是否集中在某一规格。
- 预包装看：同一包装内是否有明显大小差，退货/投诉是否增加。
- 若某规格连续 2～3 天挑剩率高、动销慢，说明规格与客群不匹配，应调整陈列位置、改包装或换规格。

### 4. 采购合同/收货标准要写清楚
建议在采购单上明确：
- 品种、产地、等级；
- **横径或单果重区间**；
- 允许的超档比例；
- 大小均匀度要求；
- 不合格的处理方式：拒收、降级、折价或要求分选。

### 5. 简单可执行的判断口径
可以这样判断一批货是否适合门店：
- **规格集中**：同批大多数果子落在同一档，少量偏离；
- **陈列整齐**：同一堆头/同一包装内大小不突兀；
- **品质匹配**：大果不空、不粗皮，小果不酸涩、不干水；
- **动销正常**：试销后挑剩率低，称重客单和毛利可接受；
- **损耗可控**：大小规格不会导致大量剩货或被迫降价。

一句话：**适合门店销售的规格，是“分档清楚、同批均匀、品质跟得上、卖得动且损耗可控”的规格，不是单纯越大越好或越小越便宜。**
