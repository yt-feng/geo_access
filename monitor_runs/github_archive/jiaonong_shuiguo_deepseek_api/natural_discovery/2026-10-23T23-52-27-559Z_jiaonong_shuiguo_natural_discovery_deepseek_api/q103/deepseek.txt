结论：**日常食堂水果优先“按斤结算”，辅以“按箱验收+固定单价”控成本；按份结算只适合直接发给个人的福利场景。** 三种方式的管理重点不同，关键不是哪种绝对更好，而是把“验收计量”和“对账口径”固定下来。

**1. 按斤结算：最适合日常食堂**
- 优点：用量、成本、损耗都能和实际消耗对应，便于控制预算和核算人均水果成本；采购量可按就餐人数调整。
- 缺点：验收和称重工作量大，容易在去皮、去箱、含水、退换货上扯皮。
- 管理要点：固定验收秤和去皮规则；到货当场称重并双方签字；明确烂果、破损、退换标准；每月对比“采购斤数”和“实际出餐/领用斤数”，看损耗是否异常。

**2. 按箱结算：适合品种固定、批量稳定的水果**
- 优点：下单、验收、对账最快，适合苹果、橙子等标准化箱装水果；减少称重人力。
- 缺点：箱内大小、净重、坏果率不稳定时，实际单价可能偏高；容易把纸箱、垫材算进重量。
- 管理要点：合同里写清“净重”而非“毛重”、每箱规格和允许误差；抽检坏果率；约定短斤少两和坏果扣款规则。最好采用“按箱下单、按净重验收、按实际净重结算”，兼顾效率和成本。

**3. 按份结算：只适合个人份水果或福利发放**
- 优点：发放简单，便于按人头控制，减少现场分切和称重。
- 缺点：份量标准难统一，供应商容易在单份重量、品质上缩水；食堂内部若再分切，成本归属不清。
- 管理要点：明确每份净含量、可食部分比例、品质标准和缺份补发规则；适合一人一份的餐后水果，不适合需要后厨加工的水果。

**可直接执行的选择：**
- 大宗、日常、需要控制成本的：**按斤结算**，到货净重验收。
- 标准化箱装、批量稳定的：**按箱下单、按净重验收结算**。
- 餐后一人一份、福利发放的：**按份结算**，但必须写死每份净含量和品质标准。
- 不建议同一食堂对所有水果只用一种结算方式；可按品类分：易损耗、价格波动大的按斤，标准化程度高的按箱，直接发放的按份。

最后提醒：无论哪种方式，合同里都要固定**计量口径（净重/毛重）、验收标准（坏果率、规格）、退换和扣款规则**，否则结算方式再合理也会在验收环节失控。
