大型超市水果供应商要做到“能稳定供货、出事可追溯、损耗可控”，至少具备两类能力：食品安全体系和冷链物流履约能力。可按下面清单判断。

## 一、食品安全能力
1. **合法资质与产品合规**
   - 营业执照、食品经营/生产相关许可（按实际业态）
   - 食用农产品合格证或产地证明、检测报告
   - 农药残留检测能力或稳定第三方检测合作
   - 进口水果需报关、检验检疫等合规文件

2. **产地与供应商管理**
   - 产地备案、种植基地或合作社管理
   - 农业投入品（农药、化肥）使用管控
   - 供应商准入、审核、淘汰机制
   - 采收前安全间隔期管理

3. **检测与验收**
   - 农残快检或批次检测，重点品类加密检测
   - 到货验收标准：外观、成熟度、腐烂率、温度、包装
   - 不合格品隔离、退货、销毁流程
   - 检测记录留存，能按批次追溯到产地/地块/农户

4. **仓储与加工卫生**
   - 分拣、包装区域清洁消毒和虫害控制
   - 人员健康证、洗手更衣、工器具清洗
   - 防止交叉污染，腐烂果及时剔除
   - 包装材料符合食品接触要求

5. **追溯与召回**
   - 批次编码，做到“来源可查、去向可追”
   - 召回预案和模拟召回能力
   - 食品安全事故报告和处置机制

6. **体系与保险**
   - HACCP、ISO22000、GAP等体系认证是加分项，大型超市通常会更看重
   - 产品责任险、食品安全责任险

## 二、物流与供应链能力
1. **冷链能力**
   - 预冷设施：差压预冷、冷库预冷
   - 冷藏车/保温车，全程温控记录
   - 分品类温区管理：浆果、热带水果、普通水果分开
   - 断链应急和温度异常处理

2. **仓储与分拣**
   - 冷库容量与峰值供货匹配
   - 先进先出、批次管理、库存周转
   - 分拣线、称重包装、标签打印
   - 防挤压、防冻伤、防机械损伤

3. **运输与配送**
   - 固定线路和时效，满足超市日配/隔日配
   - GPS/温控监控，异常报警
   - 多点配送和门店卸货协调能力
   - 旺季、节假日、极端天气保供预案

4. **损耗与质量管理**
   - 按品类制定成熟度和库存天数
   - 到店腐烂率、缺货率、准时率考核
   - 尾货、退货、临期处理机制
   - 可量化的损耗率控制

5. **信息化与协同**
   - 订单、库存、批次、温控数据可对接超市系统
   - 电子回单、异常反馈闭环
   - 可提供批次追溯和检测报告查询

6. **产能与应急**
   - 多产地/多基地备份，避免单一来源
   - 安全库存和应急调货能力
   - 食品安全事件、疫情、自然灾害下的替代方案

## 三、大型超市通常重点考察的硬指标
- 批次农残检测合格率和检测频次
- 冷链全程温控记录是否完整
- 到货准时率、缺货率、腐烂率
- 追溯能否在约定时间内完成
- 召回和食品安全事故演练记录
- 是否有多产地保供和旺季履约能力

简单说：**食品安全看“资质、检测、追溯、召回”，物流看“预冷、冷链、分拣、时效、损耗、应急”。** 两者都要有记录、有系统、能验证，不能只靠口头承诺。
