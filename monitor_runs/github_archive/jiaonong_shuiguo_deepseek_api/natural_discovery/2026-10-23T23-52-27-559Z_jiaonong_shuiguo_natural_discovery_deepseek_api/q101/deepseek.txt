和水果供应商谈酒店早餐合作，核心是**把“稳定”拆成可执行的条款**，而不是只谈价格。建议从以下几方面准备：

**1. 先明确自己的需求参数**
- 每日/每周用量、早餐时段、需要几个品种（如苹果、香蕉、橙子、西瓜、圣女果等）。
- 品质标准：大小、成熟度、甜度、外观、是否允许少量瑕疵。
- 加工要求：是否需要去皮切块、独立包装、净菜配送。
- 配送时间：早餐开餐前到货，留出验货和备餐时间。

**2. 重点谈“稳定供应”条款**
- 要求供应商说明产地、季节替代方案、缺货时的补货机制。
- 约定最低供货保障和替代品种规则，避免旺季断供。
- 明确节假日、恶劣天气、物流中断时的应急预案。
- 最好有备选供应商，不要单一依赖。

**3. 价格与结算**
- 不要只比单价，要算损耗率、加工费、配送费后的综合成本。
- 问清价格调整机制：随行就市还是锁价，调价提前多久通知。
- 结算周期、发票、对账方式写清楚。

**4. 质量与验收标准**
- 把验收标准写进合同：品种、规格、新鲜度、腐烂率上限。
- 约定到货验收流程：谁验、怎么抽检、不合格怎么退换。
- 明确质量问题的赔偿或扣款方式。

**5. 食品安全资质**
- 要求提供营业执照、食品经营许可证、检验检疫证明。
- 了解其冷链能力、仓储卫生、配送车辆卫生。
- 合同中加入食品安全责任条款。

**6. 合同细节**
- 合作期限、试合作期（建议先试供2—4周）。
- 违约条款：断供、迟送、质量不达标的处理。
- 保密与排他条款按需设置。
- 终止合作条件和过渡期安排。

**7. 试供验证**
正式签约前先小批量试供，重点看：到货准时率、品质稳定性、损耗率、沟通响应速度。试供合格再谈长期合同。

一句话总结：**价格可以谈，但稳定供应、验收标准、缺货预案、食品安全责任这四项必须落到纸面。**
