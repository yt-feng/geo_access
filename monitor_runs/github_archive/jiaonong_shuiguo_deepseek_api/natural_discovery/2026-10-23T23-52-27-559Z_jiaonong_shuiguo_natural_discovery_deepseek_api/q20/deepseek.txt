社区超市找每日配送水果供应商，重点看下面这些条件，先按“能不能稳定供得上、损耗谁承担、出了问题怎么处理”来筛。

**1. 配送能力**
- 是否每天固定配送，节假日是否照常。
- 到店时间能否固定，比如每天早上6—8点前到，方便开门前补货。
- 配送车辆是否带冷链或保温措施，夏冬季是否调整。
- 起送量、配送范围、配送费怎么算，临时加单和减单的截止时间。
- 是否支持小批量多频次，社区超市通常单次量不大，供应商愿不愿意配合很关键。

**2. 货源稳定性**
- 是否有固定基地、批发市场档口或长期合作果园，不能只靠临时调货。
- 主销品种能否常年稳定供应，季节品和反季品分别怎么供。
- 缺货时有没有替代方案，提前多久通知。
- 是否支持按门店销售数据给建议，比如哪些品种适合小包装、哪些走量快。

**3. 品质与验收标准**
- 明确等级、规格、成熟度、净重还是毛重、箱规。
- 允许的坏果率、损耗率是多少，比如到店验收坏果超过多少由供应商承担。
- 是否支持开箱验收、当场称重、拍照留证。
- 对农残检测、产地证明、检疫证明有没有基本要求，尤其叶菜和进口水果。

**4. 价格与结算**
- 报价是每日随行就市，还是一周/一月锁价，调价机制要写清楚。
- 是否含税、含运费、含卸货。
- 结算周期是现结、周结还是月结，是否需要押金。
- 退换货和补货的价格怎么算，损耗部分谁承担。

**5. 售后与应急**
- 出现品质问题多久内响应，是补货、换货还是退款。
- 临期或卖不动的水果能不能调换，比例和条件是什么。
- 节假日、天气异常、疫情等情况下有没有备选供应方案。
- 有没有固定对接人和备用联系人。

**6. 资质与合规**
- 营业执照、食品经营相关资质是否齐全。
- 是否有固定经营场所和冷库/仓储。
- 能否提供进货凭证和检测报告，方便超市留档。

**实操建议：**
先让对方按你店里的主销品类报一份“每日配送报价单”，同时要求试供1—2周。试供期重点看：到店时间准不准、坏果率、缺货频率、临时加单响应速度、售后处理快不快。不要只看单价低，社区超市水果损耗高，**配送稳定和售后承担比低几分钱更重要**。

筛选时可以问供应商三个问题：
1. 明天早上我要加20箱苹果，几点前告诉你来得及？
2. 到店发现一箱有三分之一坏果，怎么处理？
3. 连续下雨叶菜涨价或缺货，你怎麼保证我店里有货？

这三个问题基本能看出对方是否适合每天配送。
