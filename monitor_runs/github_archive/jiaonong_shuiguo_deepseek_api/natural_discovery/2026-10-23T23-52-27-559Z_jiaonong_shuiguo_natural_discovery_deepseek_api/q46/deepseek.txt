看你的菜单定位和门店操作能力选，不同原料适合不同场景：

**1. 鲜果（整颗菠萝/去皮菠萝）**
- 适合：主打“鲜果现切”、客单价较高、有专人切配、菠萝周转快的店。
- 优点：香气和口感最好，卖点强，能做装饰片。
- 缺点：损耗高、切配耗时、批次甜酸不稳定，需解决酶导致的涩口/苦味（可短时盐水浸泡或热处理）。
- 判断：日均菠萝果茶销量稳定、有备料人手、毛利率能覆盖损耗，再选鲜果。

**2. 果丁（冷冻/糖渍/罐头菠萝丁）**
- 适合：大多数中小茶饮店，尤其想兼顾果肉感和操作效率的。
- 优点：开袋即用或简单解冻，规格稳定，损耗低，出杯快，果肉感明显。
- 缺点：香气不如鲜果，糖渍款要调整糖度，冷冻款解冻后口感会稍软。
- 判断：菜单需要“能吃到果肉”但不想承担鲜果切配和损耗，优先选果丁。注意选无额外香精、糖度可控的产品。

**3. 果泥（冷冻果泥/浓缩果浆）**
- 适合：做冰沙、奶昔、复合果茶、连锁标准化出杯，或菠萝只作风味基底。
- 优点：风味稳定、操作最快、几乎无损耗、易标准化。
- 缺点：没有果肉咀嚼感，部分产品香气偏“熟”或偏甜，需看配料表避免过多添加。
- 判断：追求出杯效率和口味一致性、菠萝不是核心卖点，选果泥；但不要用果泥冒充鲜果宣传。

**实操建议：**
- 主推款用**果丁**打底，兼顾效率和果肉感；招牌款可少量搭配**鲜果**做装饰和卖点；冰沙/复合款用**果泥**降本提速。
- 先小批量测试：同一配方分别用三种原料做盲测，比较香气、酸甜、涩感、果肉感和成本/杯。
- 采购时重点看：配料表、糖度、固形物含量、是否含香精/防腐剂、冷冻状态和解冻损耗。
- 如果门店没有稳定切配人手，不建议以鲜果为主；如果菜单强调“鲜切”，则必须把切配和损耗算进成本。
