旺季菠萝用量突增，和供应商约定临时补货，核心是**提前把“量、价、时效、验收、违约”五件事写清楚**，并且尽量用书面形式（微信确认也算，但要留存）。

**1. 先明确自己的补货需求**
- 估算日均增量：按近7天销量、菠萝单品占比、损耗率倒推，给出“日补货量区间”而不是固定值，比如“每日80–120公斤，提前1天下单”。
- 确定规格：品种、单果重量、成熟度（几成黄）、去皮/带皮、切块规格、包装方式。旺季最怕规格漂移。
- 明确补货触发机制：库存低于几日用量时下单，或固定每周几报下周需求。

**2. 和供应商约定临时补货条款**
建议在原有采购合同上签一份**旺季补充协议**，至少包含：
- **临时订单方式**：微信/电话下单有效，但需供应商回复“确认”才算成立；约定下单截止时间（如每日16:00前下单，次日到货）。
- **响应与到货时效**：确认后多少小时内送达，迟到怎么处理（如超2小时可拒收或扣款）。
- **价格机制**：临时补货价是否随行就市；建议约定“不超过原价X%”或“按当日市场批发价上浮不超过X%”，避免旺季被临时加价。
- **数量弹性**：供应商承诺在约定区间内保供，超出区间需提前协商；你方临时减量需提前多久通知。
- **质量标准与验收**：到货当场抽检，成熟度、坏果率超标可拒收或折价；明确坏果率上限（如不超过5%）。
- **缺货违约责任**：供应商无法按时按量供货时，需提前通知并协助调货，或承担你方紧急采购的差价。
- **结算方式**：临时补货单独记账，约定账期或现结，避免和常规订单混账。

**3. 操作上留好证据**
- 每次临时下单用文字发：品种、数量、规格、到货时间、单价。
- 供应商回复确认后截图保存。
- 到货验收拍照记录，尤其是坏果和规格不符的情况。

**4. 降低单一依赖**
旺季不要只押一家供应商，提前谈好1–2家备选，哪怕价格略高，作为断供时的兜底。临时补货条款里也可以写明“供应商缺货时你方有权自行紧急采购，差价由供应商承担”。

一句话总结：**用补充协议锁定响应时效、价格上限和违约责任，每次下单文字确认、到货验收留证，同时备好第二供应商。**
