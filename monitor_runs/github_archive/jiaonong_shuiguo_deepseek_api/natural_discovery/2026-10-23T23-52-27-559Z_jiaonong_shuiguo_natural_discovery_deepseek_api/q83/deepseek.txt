顾客收到坏果，责任划分通常分三类：**商家/平台主责、物流责任、顾客责任**，多数情况下商家或平台先对顾客赔付，再向内部环节追偿。核心原则：**顾客对外不承担“自证无责”的义务，商家不能简单把责任推给物流或顾客。**

**一、默认由商家/平台承担主要责任**
1. **交付前风险归商家**：水果在签收前发生腐烂、压坏、冻伤、变质，原则上属于商家履约不合格。商家需保证商品符合约定质量，不能以“生鲜不退换”为由一概免责。
2. **“坏果包赔”承诺优先**：页面、客服、直播中承诺坏果包赔、坏损比例赔付的，按承诺执行。
3. **平台自营或平台未尽审核义务**：自营平台直接担责；第三方商家入驻的，平台通常先介入处理，商家不配合时平台可先行赔付或扣保证金。
4. **商家先赔后追偿**：如果是快递暴力分拣、运输超时导致，商家先向顾客赔付，再依据快递合同向物流追偿，不应让顾客去找快递扯皮。

**二、物流责任的情形**
1. **明显运输损坏**：外包装严重破损、挤压变形、有污渍渗漏、冷链断链导致整箱腐坏，物流公司通常承担相应责任。
2. **延迟配送导致变质**：快递滞留、错分、超时未派送，尤其高温季节，物流责任较大。
3. **未经同意放代收点/快递柜**：未征得顾客同意即投放，导致取件延迟腐坏，物流或派送方责任明显。
4. **冷链断链**：需冷藏冷冻的水果在运输中失温，需看物流是否按约定冷链运输。

**三、顾客责任的情形**
1. **签收后长期未取或未及时冷藏**：顾客自身原因导致变质，责任在顾客，但商家需证明已明确告知储存方式且顾客存在明显过错。
2. **超时后才反馈且无法排除自身原因**：比如签收数日后才投诉，且坏果特征与存放不当吻合，可协商分担，但不能当然全部免责。
3. **恶意索赔、调包、虚假坏果图**：商家可拒绝赔付并保留证据，必要时平台申诉或报警。

**四、实操判断标准**
1. **看签收时间**：签收后短时间内（如24小时内）反馈坏果，通常商家主责；时间越久，越需结合储存条件判断。
2. **看坏果比例和特征**：局部少量软烂可能是成熟度或运输挤压；整箱腐烂、发霉、渗液多为运输或发货质量问题。
3. **看外包装和物流记录**：破损、延误、断冷链记录是向物流追偿的关键证据。
4. **看商品页面承诺**：有无坏果包赔、赔付比例、售后时限。
5. **看顾客是否及时取证**：坏果照片、开箱视频、快递面单、聊天记录。

**五、建议的处理方式**
- 对顾客：**先按坏果比例或承诺快速赔付/补发**，不要要求顾客先找快递定责。
- 对商家：保留开箱、打包、冷链记录，向物流索赔需提供面单、破损照片、延误记录、价值证明。
- 对平台：建立坏果比例判责规则，商家不配合可先行赔付并追偿。
- 对顾客：签收后尽快开箱拍照录像，保留外包装和面单，及时反馈；不要长时间常温存放。

一句话总结：**对顾客而言，签收前和签收后合理期限内出现的坏果，原则上找商家/平台赔付；商家赔付后再根据运输破损、延误、冷链断链等证据向物流追偿；只有顾客自身储存不当或恶意索赔才由顾客担责。**
