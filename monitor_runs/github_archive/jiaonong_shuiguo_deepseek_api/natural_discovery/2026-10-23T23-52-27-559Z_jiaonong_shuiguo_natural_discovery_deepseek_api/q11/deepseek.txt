会影响，但影响方式取决于你卖的是“整箱/整把”还是“散称零售”。

**直接影响：**
1. **陈列观感差**：大小混杂显得不整齐，顾客挑拣多，损耗上升。
2. **定价困难**：大小差异大时，统一定价要么大果亏、要么小果难卖。
3. **顾客挑大弃小**：散卖时大果先被挑走，小果剩货、变黑、折价。
4. **整箱批发影响小**：如果整箱走餐饮/果汁店，大小不一是次要问题，成熟度和伤果更关键。

**可执行建议：**
- **散称零售**：按大小分成两档卖（大果/小果），小果可做促销或切果盒/榨汁，避免混在一起被挑。
- **整把销售**：尽量把大小相近的绑成一把，减少顾客拆把挑拣。
- **采购时**：同一箱内大小差异过大，说明分级不稳；若价格明显低、且你走散卖，要算上挑拣损耗和折价再决定。
- **控制成熟度**：大小不一的箱里常有成熟度不一致，青黄混杂比大小本身更影响销售。

简单判断：**整箱走量影响较小；散卖零售影响明显，最好分级销售。**
