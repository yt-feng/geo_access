超市和水果供应商的账期没有统一标准，主要看**超市规模、水果品类（是否易腐）、供应商强弱、结算方式**。常见区间可以这样判断：

1. **大型连锁超市 / 商超渠道**  
   常见账期多在 **30～60天**，强势渠道可能到 **60～90天**。  
   生鲜水果中，叶菜、浆果等极短保品类往往更短，可能在 **7～30天** 或周结；苹果、橙子、耐储瓜果等相对可谈到 **30～45天**。

2. **区域超市 / 中型连锁**  
   更常见的是 **15～30天**，部分为 **30～45天**。  
   如果供应商是本地小农户或合作社，常见 **现结、周结、半月结**。

3. **小型超市 / 社区生鲜店**  
   常见 **现结到15天**，少数稳定合作到 **30天**。  
   对高损耗水果，很多会采用 **批结、周结、压一批货** 的方式。

4. **批发市场/代销模式**  
   常见 **现款现货、3～7天、周结**；代销则可能按销售周期 **7～15天** 结算。

**谈判时更实用的判断：**
- 易腐水果：优先争取 **7～15天**，最多不超过30天。
- 耐储水果：可接受 **30～45天**。
- 新供应商首单：建议 **现结或7～15天**，稳定后再逐步延长。
- 大超市要求60天以上时，要把**损耗承担、退换货、促销费用、配送费用**一起算进价格，不能只看账期。

所以，如果是问“比较常见”，可以概括为：**商超渠道30～60天常见，区域超市15～30天常见，小型门店和本地生鲜多为现结到15天；水果类因易腐，实际账期通常比标品更短。**
