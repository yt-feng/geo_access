做餐饮客户，核心不是“多备几种”，而是按餐饮用法的稳定规格备货，并让档口好分级、好报价。菠萝和香蕉建议按下面准备。

**菠萝**
- **鲜切/果盘/饮品店用**：主备 **1.2–1.5kg/个** 的中果，成熟度7–8成，果眼浅、无黑心；再备少量 **1.5–2kg/个** 大果做展示或整果出品。
- **后厨/甜品/炒菜用**：备 **1.5–2kg/个** 大果，出肉率高，适合切块、炒饭、咕噜肉。
- **小餐饮/快餐/一人食**：可备 **0.8–1.2kg/个** 小果，按个卖、损耗低。
- **规格表达**：不要只写“大中小”，直接标 **单果重区间、成熟度、是否去皮/去眼、是否鲜切真空、每箱净重和个数**。餐饮客户最关心出成率和稳定到货。
- **建议SKU**：整果中果、整果大果、鲜切块真空装（如2.5kg/袋）、去皮整果真空装。先各少量试销，按客户复购调整。

**香蕉**
- **餐饮通用**：主备 **单根120–150g、每把5–7根、成熟度6–7成** 的货，适合后厨催熟后做果盘、甜品、早餐。
- **饮品/甜品店**：备 **单根100–130g** 中小果，成熟度7成，出杯稳定；另备少量 **8–9成熟** 即用果，但控制量，香蕉后熟快。
- **烘焙/油炸/香蕉船**：备 **单根150–180g** 大果，外形整齐、长度一致。
- **规格表达**：标 **单根重、每把根数、每箱净重、成熟度、是否催熟、到货后货架期**。餐饮客户尤其怕今天香蕉太生、明天全黑。
- **建议SKU**：7成熟通用箱、8成熟即用箱、大果烘焙箱。不要一次上太多成熟度，容易压货。

**档口执行建议**
1. 先定 **3个菠萝SKU + 3个香蕉SKU**，每个SKU只留一个主规格和一个备选。
2. 报价按 **元/kg、元/箱、元/个** 三种口径都给，餐饮采购好比对。
3. 首批给餐饮客户做 **小箱试样**：菠萝5kg/箱、香蕉8–10kg/箱，附成熟度和存放建议。
4. 重点记录客户退货原因：菠萝黑心、出肉率低；香蕉成熟不齐、压伤。这比多备规格更有用。

总结：菠萝以 **1.2–1.5kg中果为主、1.5–2kg大果为辅**；香蕉以 **单根120–150g、6–7成熟为主**，再配少量即用熟果和大果。先小箱试销，按餐饮客户实际用法固化规格。
