建议按“门店类型 + 客流结构 + 损耗能力”来定，不要一刀切。对多数社区超市，更稳的组合是：**整果为主、鲜切为辅**。

**判断框架**

1. **整果更适合的情况**
   - 门店有生鲜区、有称重和陈列条件；
   - 客群以家庭采购为主，买回家自己处理；
   - 采购量可控、周转快；
   - 你想降低加工人工、食品安全和短保损耗风险。
   - 优点：毛利结构简单、损耗相对可控、操作门槛低。
   - 风险：外观品相要求高，顾客嫌削皮麻烦，动销慢时整果也会烂。

2. **鲜切更适合的情况**
   - 门店靠近办公区、学校、交通节点，即时消费强；
   - 有冷藏陈列和日清能力；
   - 能做标准化加工、有专人操作；
   - 客群对便利性敏感，愿意为“即食”付溢价。
   - 优点：提升便利性、客单价和冲动购买，能消化外观稍差但品质正常的果。
   - 风险：短保、冷藏、刀具砧板清洁、交叉污染、氧化变色、当天卖不掉就报损。

**采购和运营建议**

- **先小批量测试 2—4 周**：整果和鲜切同时上，记录日销量、报损率、毛利率、加工耗时。
- **整果选耐储、外观好的规格**，按个或按斤卖；鲜切选成熟度合适、出成率高的果，不要用已过熟或开始水烂的果。
- **鲜切必须日清**，冷藏陈列，标注加工时间，严格执行刀具、砧板、手套和台面消毒。
- **算清出成率**：菠萝去皮去眼后出成率通常明显低于整果，鲜切定价要覆盖原料、人工、包装、冷藏和报损，不能只看售价高。
- **看动销再扩品**：鲜切日销量稳定、报损可控再增加规格；否则退回整果为主，避免为了“看起来丰富”增加损耗。

**结论**：社区家庭型门店优先**整果为主**；办公/学校/即时消费型门店可**鲜切为主或整果+鲜切组合**。最不建议的是没有冷藏和日清能力却大面积上鲜切。
