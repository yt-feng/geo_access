先看结论：**香蕉进货优先级应为：熟度 > 坏果率 > 送货速度 > 价格**。这不是说价格不重要，而是香蕉是典型“高损耗、强时效、成熟度决定能不能卖”的品类，价格便宜但熟度不对，反而更容易亏。

具体判断如下：

1. **熟度最优先**
   - 香蕉进店时最好处于“可继续后熟、但当天或次日能开始卖”的状态。
   - 太青：占货架、周转慢，遇到降温或客流差容易拖到过熟。
   - 太黄：当天卖不掉就快速起斑，损耗直接上升。
   - 小水果店销量有限，建议分批进：一部分当天可卖，一部分青一点后熟。

2. **坏果率第二**
   - 香蕉怕压、怕闷、怕冷，箱内发热或运输挤压会造成隐性坏果。
   - 进货时要看箱底、果指连接处、果柄和表皮有无水烂、黑腐、压伤。
   - 坏果率高会直接吃掉毛利，尤其小批量进货时更明显。

3. **送货速度第三**
   - 香蕉对温度变化和挤压敏感，送货慢会增加闷箱、受热、受冻风险。
   - 但送货速度要结合季节看：夏天更看重快送和通风，冬天要防冻，不能只求快。
   - 如果供应商能稳定次日达、且包装和温度控制好，速度稍慢也可接受。

4. **价格放在最后比较**
   - 价格低但熟度不合适、坏果多，综合成本更高。
   - 小水果店应算“到手可售成本”，不是只看每斤进价：进价 + 损耗 + 催熟/处理时间 + 压货风险。
   - 同样品质下再比价格；如果价差很小，优先选熟度稳定、坏果少、送货稳的供应商。

**可执行建议：**
- 先定销售节奏：日销多少斤，就按“今天卖 + 明天卖 + 少量后熟”分三档进货。
- 每次收货抽检箱底和中间层，记录坏果率；连续两次坏果率高的供应商降级。
- 夏季优先快送和通风包装，冬季优先防冻和稳定熟度。
- 比价时用“可售斤成本”比较，而不是只看标价。

一句话：**小水果店进香蕉，先买“能卖且少坏”的货，再谈快和便宜；熟度错、坏果多，低价就是陷阱。**
