优先做**小把（3～5根）为主，单根做补充，整袋只做少量试销**。原因是便利店的核心场景是“即时、少量、顺手买”，香蕉又极易压伤和过熟，包装方式要同时兼顾损耗和客单。

可执行建议：

1. **主推小把 3～5 根**
   - 最适合一人或两人即时消费，客单价高于单根，又不像整袋那样容易吃不完。
   - 用透明膜或扎带轻固定，别包死，留透气孔，避免闷出水汽。
   - 陈列时把蕉柄朝外、蕉身不受压。

2. **单根作为补充**
   - 放在收银台或早餐/酸奶旁边，适合“顺手加一根”。
   - 单根毛利低、分拣和称重成本高，不宜作为主陈列，但能降低顾客购买门槛。
   - 建议选成熟度稍低、外观完整的单根，避免熟透软烂。

3. **整袋谨慎试销**
   - 只适合家庭客群明显、周边社区型门店，或做促销组合。
   - 整袋容易因挤压和熟度不一致造成高损耗，先小批量试 1～2 周，看动销和报废率再决定。
   - 袋装要打孔透气，标注或区分成熟度，避免顾客买回家两天全黑。

4. **用成熟度做分层，而不是只靠包装**
   - 当天吃：黄熟、带少量糖斑，可单根或小把。
   - 两三天吃：黄中带绿，主推小把。
   - 家庭囤：略绿的小把或整袋，少量陈列。

5. **看数据再调整**
   - 连续观察 7～14 天的销量、报废率和客单价。
   - 如果小把动销快、报废低，就扩大排面；单根若主要带动其他商品可保留；整袋报废率高于销量贡献就下架。

**结论：便利店香蕉以 3～5 根小把为主，单根引流补充，整袋小批量试销，并按成熟度分级陈列。**
