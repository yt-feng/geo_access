**结论：在商超水果采购里，损耗低通常比采购价格低更影响最终毛利；但前提是价格不能高到失去竞争力。** 更准确地说，决定毛利的是“售价 − 进价 − 损耗”，而水果损耗的波动幅度往往远大于进价差异。

可以这样判断：

1. **先看损耗对毛利的影响**
   - 假设售价10元/斤，进价5元/斤，损耗率5%：  
     实际可售成本≈5÷0.95=5.26元，毛利≈4.74元。
   - 若进价降到4.5元，但损耗升到15%：  
     实际可售成本≈4.5÷0.85=5.29元，毛利≈4.71元。  
     进价降了10%，但损耗上升10个百分点，毛利几乎没改善。
   - 水果损耗从5%升到15%很常见；进价想再降10%—15%却往往要牺牲品质或账期。

2. **低进价的风险**
   - 低价货常见问题：成熟度高、规格不匀、产地/批次不稳、后期腐烂快。
   - 低价还可能带来：客诉、退货、称重差、陈列卖相差、动销慢，最后变成“便宜进、烂着卖”。
   - 如果低价来自大批量囤货，还会增加资金占用和滞销风险。

3. **低损耗的价值**
   - 同样售价下，损耗每降1个百分点，通常直接增厚毛利。
   - 低损耗意味着：可售率高、陈列时间长、复购稳定、退货少。
   - 对商超来说，水果是引流品类，稳定品质带来的客流和复购，比单斤进价差更重要。

4. **什么时候价格低更关键**
   - 该单品是**价格敏感型引流品**，顾客对价格极敏感。
   - 动销极快、当天能卖完，损耗可控。
   - 用于促销对比，且能通过限量、快进快出控制损耗。
   - 竞争店同品质价格明显更低，你不跟价就丢客流。

**实操建议：**
- 采购决策不要只比“进价”，要算**可售成本 = 进价 ÷（1 − 预计损耗率）**。
- 优先选**品质稳定、损耗可预测**的货源；低价货必须小批量试销，验证损耗后再放量。
- 对高损耗单品，重点谈**退换货、账期、到货成熟度、分级标准**，这比压价更能保毛利。
- 用“毛利额 = 销量 ×（售价 − 可售成本）”做单品复盘，连续看2—4周，别凭单次进价判断。

一句话：**低价决定你“看起来有多少毛利”，低损耗决定你“最后能不能拿到毛利”。水果采购中，低损耗的优先级通常更高。**
