第一次合作，试单的核心不是“便宜”，而是**低风险验证**：验证品质稳定性、履约可靠性、结算配合度。建议按下面设计。

**一、先定试单目标**
只验证4件事：
1. 到货品质是否与样品/描述一致；
2. 到货时间是否守约；
3. 损耗率、规格偏差是否在可接受范围；
4. 对方沟通、售后、票据结算是否顺畅。

**二、控制试单规模**
- 单品试，不要多品混试；先选你周转最快、最好判断品质的1个品类。
- 数量以“1—2天能卖完/消化完”为宜，避免压货。
- 金额控制在你可承受损失范围内，建议不超过首次合作预算的20%—30%。
- 不要一次性付全款，优先“订金+到货验收后尾款”或货到付款。

**三、明确规格和验收标准**
下单前书面确认：
- 品种、产地、等级、单果规格/重量区间；
- 成熟度、色泽、糖度或口感要求（能测就测）；
- 包装方式、每箱净重、箱规；
- 允许损耗率、次果率、规格不符比例；
- 到货时间、卸货地点、运输温控要求；
- 出现质量问题的处理方式：补货、折价、退货还是扣款。

**四、设计分批到货**
如果数量稍大，拆成2批到货，比如先到60%，卖1—2天看动销和品质，再到40%。这样能避免一次性踩坑。

**五、验收流程要固定**
到货后当场做：
1. 称重核对净重；
2. 随机抽3—5箱开箱，检查上下层是否一致；
3. 记录次果、烂果、规格偏差；
4. 拍照/视频留证；
5. 24小时内反馈问题，要求对方书面确认处理方案。

**六、付款和账期**
首单建议：
- 小比例订金，尾款验收后付；
- 不接受无凭证大额预付；
- 明确发票/收据、对账方式；
- 如果对方要求全款预付，试单金额要再压低，或改为少量多批次。

**七、试单后做复盘**
按四项打分：品质一致性、到货准时率、损耗率、售后响应。任一核心项不达标，不急着放大订单；连续2—3次小单稳定后，再谈账期、返点、独家规格或更大批量。

一句话：**小批量、单品类、分批到、验后付、留证据、看复盘。**
