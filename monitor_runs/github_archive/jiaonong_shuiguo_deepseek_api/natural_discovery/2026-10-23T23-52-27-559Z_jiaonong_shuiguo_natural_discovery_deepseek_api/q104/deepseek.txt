# 单位采购水果：品质不一致的验收与售后处理

核心原则：**验收前先定标准，验收到货时留证据，售后按比例谈补救，不要整批退或整批收**。

## 一、到货前的准备（验收依据）

1. **把品质标准写进合同/订单**：按品类写明品种、规格（单果重/直径）、成熟度、允许的次果率（如≤5%）、产地、包装方式。没有书面标准的，验收时容易扯皮。
2. **约定验收方式和时限**：到货后几小时内完成抽检、抽检比例（如每批随机抽3–5箱/10%）、不合格如何判定。
3. **约定售后条款**：次果率超标怎么赔（补发/折价/退货）、响应时限、运费谁承担。

## 二、到货验收怎么做

1. **当场开箱抽检，拍照录像**：拍整车/整批外观、开箱过程、问题果特写、箱唛和批次号，最好带时间水印。
2. **分层抽样**：不要只看最上面一层。从上、中、下不同位置各抽几箱，按品类检查大小、色泽、软硬度、有无霉变/压伤/虫害。
3. **量化记录**：按箱记录好果/次果数量，算出次果率和主要问题类型（如压伤、过熟、规格偏小），让送货人签字确认抽检结果。对方不签的，录像并书面（微信/邮件）告知。
4. **分类处理，不要一刀切**：
   - 轻微不一致（如个别规格偏小、少量压伤）：可收货，但记录并折价。
   - 明显不达标（次果率超约定、霉变、以次充好）：该批次拒收或整箱退回，其余合格批次正常收。
   - 整批混装严重：拒收并要求换货，避免后续分拣成本转嫁给单位。

## 三、售后怎么谈

1. **第一时间书面反馈**：到货验收后尽快（合同约定时限内）把抽检记录、照片发给供应商，明确诉求：补发、折价、换货或退货。
2. **按比例算，不情绪化**：例如抽检次果率15%、约定≤5%，可要求对超标部分折价或补发同等数量，而不是要求整批免单。这样供应商更容易接受，也站得住脚。
3. **留好凭证**：验收单、照片、沟通记录、付款凭证。金额较大的可要求供应商出具书面确认。
4. **建立供应商评价**：同一供应商连续出现品质不一致的，记录在案，下次采购时降低份额或更换，比单次扯皮更有效。

## 四、几个实操提醒

- **生鲜有特殊性**：水果到货后品质会继续变化，验收要快，售后要趁早，拖久了责任难界定。
- **不要先签收后验货**：签收单上注明“外观验收，内在品质待抽检”或直接当场抽检完再签。
- **单位内部先统一口径**：谁验收、谁对接供应商、谁审批折价，提前定好，避免经办人独自承担压力。

一句话：**标准前置、抽检留证、按比例索赔、记录供应商表现**，基本能覆盖大多数品质不一致的情况。
