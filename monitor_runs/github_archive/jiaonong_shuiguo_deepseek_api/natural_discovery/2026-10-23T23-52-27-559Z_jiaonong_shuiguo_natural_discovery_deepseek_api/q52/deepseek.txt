采购时优先选**七成熟左右、表皮全黄但无明显黑点、果柄完整**的香蕉；到店后不要冷藏，挂起来或单层摆放，避免挤压，先熟先卖。香蕉很快变黑主要是**碰伤、闷热、乙烯积聚和低温冷害**造成的。

具体可执行做法：

1. **采购标准**
   - 选表皮黄色、略带一点青肩的，适合甜品店1—3天内用完。
   - 不要选已经有大面积黑斑、破皮、果柄发黑腐烂的。
   - 整串买比散装更耐放，果柄完整能减少伤口。

2. **运输和到店处理**
   - 运输时不要压、不要堆太满，避免磕碰。
   - 到店后拆掉塑料袋或紧包装，保持通风。
   - 有伤、有黑点的先挑出来优先使用，不要和好果混放。

3. **存放方式**
   - **不要冷藏**：香蕉在低温下会冷害，表皮更快变黑。
   - 放在阴凉通风处，避免阳光直射和靠近烤箱、热源。
   - 最好**悬挂**，减少受压面积；没有挂钩就单层平放，果柄朝上。
   - 成熟度高的香蕉可以分开摆放，减少乙烯互相催熟。

4. **控制催熟**
   - 香蕉会释放乙烯，不要和苹果、梨等释放乙烯多的水果密闭混放。
   - 如果已经偏熟，可把果柄用保鲜膜包一下，减缓成熟，但不要整根密封。
   - 需要延缓时，分开单根摆放比整串堆着更稳。

5. **采购节奏**
   - 按销量少量多次采购，甜品店更适合“勤进快销”。
   - 把香蕉分为**当天用、次日用**两批，避免一次全熟。
   - 熟透但没坏的香蕉可尽快做香蕉泥、果酱、烘焙，不要等到发黑再处理。

一句话：**买七成熟、不冷藏、不挤压、通风悬挂、少量多次、先熟先卖。**
