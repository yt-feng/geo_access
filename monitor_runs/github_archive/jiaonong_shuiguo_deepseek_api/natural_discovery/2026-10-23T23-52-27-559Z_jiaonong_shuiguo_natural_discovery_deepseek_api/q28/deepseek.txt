建议先从**香蕉**试起，但要做“进口香蕉的稳定分级供应”，不要一上来押注高单价进口苹果或菠萝。理由按可执行性排序：

1. **香蕉最适合先做稳定进口**
   - 全年需求稳定、周转快、顾客价格敏感但复购高。
   - 进口香蕉通常以青蕉到货、门店或配送中心催熟，能通过成熟度分级控制损耗。
   - 供应链相对成熟，容易做周度固定订货。
   - 风险点：催熟和温控要求高，必须解决“青蕉—催熟—上架”流程，否则损耗会吞掉毛利。

2. **菠萝可以做第二步，但不适合作为第一支稳定进口单品**
   - 进口菠萝有差异化卖点，客单价高于香蕉。
   - 但品种差异大、成熟度窗口短、削皮和售后处理要求高，损耗和顾客投诉更敏感。
   - 适合先小批量试销，验证顾客对品种和价格的接受度，再考虑稳定引入。

3. **苹果不建议作为“进口稳定单品”的起点**
   - 国产苹果供应充足、价格带完整，进口苹果很难靠“稳定日常销量”建立优势。
   - 进口苹果更适合做差异化、礼盒或高端补充，不适合作为引流和稳定周转的第一支进口水果。
   - 除非你的超市定位高端、进口苹果已有明确客群，否则先做香蕉更稳。

**落地建议：**
- 第1—4周：只引入进口香蕉，固定供应商、固定到货日、固定催熟标准，记录损耗率、日销量、毛利率。
- 第5—8周：若香蕉周销量稳定、损耗可控，再小批量引入1—2个进口菠萝品种试销。
- 进口苹果暂作为补充SKU，不承担稳定进口水果的主力。
- 判断标准：连续4周周销量波动小、损耗率可接受、缺货率低，再扩大品类。
