采购香蕉时，关键是**按用途和预计使用天数分熟度采购**，不要一次全买同一熟度。

- **当天或次日要做饮品/甜品**：买**黄熟、微软、带少量糖斑**的香蕉，香气足、甜度高、易打泥。
- **2～4天内使用**：买**七八成熟、整体偏黄但两端略青、手感稍硬**的，室温催熟。
- **备货超过4天**：一部分买**青黄交接、手感硬**的，放阴凉通风处慢慢熟；不要冷藏未熟香蕉。
- **做香蕉泥、奶昔、冰沙**：用熟度高的，但避免已大面积发黑、出水、有酒味或酸味的。
- **做切片装饰、烤制甜品**：选中熟、形状完整、表皮无破损的，太熟切片易烂。

采购控制建议：

1. **按销量定采购量**：按每天预计用量×到货间隔来买，熟度分批，避免集中成熟。
2. **验收看三点**：颜色、手感、气味。表皮有少量黑点可以，但大面积黑斑、软塌、渗液、酒味不要。
3. **分开放置**：青的放室温催熟；熟的放阴凉处优先用；需要延缓成熟的再冷藏，但冷藏后表皮会变黑，适合内部使用，不适合展示。
4. **建立“先用熟、后催青”的顺序**：每天检查，把最熟的挑出来做香蕉泥、奶昔或当日甜品。
5. **和供应商约定到货熟度**：不要只说“要香蕉”，要明确“到货七八成熟、黄中带青、无大面积黑斑”。

简单记：**饮品和甜品用香、用甜，采购要分批；当天用买黄熟，备货买青黄，验收拒软烂渗液。**
