做家庭团购水果礼盒，建议优先考虑“好分、耐放、甜酸搭配、全家都能吃”，而不是追求品种多。组合上可以这样选：

**推荐组合：苹果 + 橙子 + 香蕉，菠萝少量搭配或单独成档**

- **苹果**：耐放、寓意好，家庭接受度最高，适合做礼盒主体，占比可到 40% 左右。
- **橙子**：耐放、酸甜解腻，和苹果形成基础盘，占比 30% 左右。
- **香蕉**：便宜、软甜，老人小孩都方便吃，但怕压、熟得快，占比 20% 左右即可，别放太多。
- **菠萝**：有特色但处理麻烦、有人嫌酸或扎嘴，家庭礼盒里建议少量，或者做成“加购/升级款”，不要作为必放主体。

**更稳的团购方案：**
1. **基础家庭款**：苹果 + 橙子 + 香蕉，比例约 4:3:2，另留 1 成空间做填充或小果。
2. **升级家庭款**：苹果 + 橙子 + 香蕉 + 小菠萝/凤梨，菠萝控制在 1 个或少量切盒，避免整箱太重、太难处理。
3. **怕踩雷就分档**：标准款不放菠萝；喜欢尝鲜的家庭可选“加菠萝版”，减少售后争议。

**包装和选品注意：**
- 香蕉单独套袋或放上层，避免压伤其他水果。
- 苹果、橙子选耐储运的中果，别一味追求大果，家庭团购更看重性价比。
- 菠萝如果放整只，要提醒售后和成熟度；如果做切盒，配送和保鲜要求更高。
- 礼盒总重建议控制在家庭一次能吃完、又不会太重的范围，常见 5 斤左右比较合适。

一句话：**家庭团购最稳的是“苹果+橙子+香蕉”打底，菠萝做少量升级款或可选款。**
