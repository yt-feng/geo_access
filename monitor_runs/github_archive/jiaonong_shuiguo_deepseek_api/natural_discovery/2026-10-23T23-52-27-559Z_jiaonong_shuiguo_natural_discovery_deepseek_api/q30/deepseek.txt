# 超市水果到货品相不好的售后流程约定建议

建议在采购合同或供应商协议中，把“品相”从主观判断变成可执行的验收标准和分级处理规则，核心是**先验收、按比例定责、分级处置、留证闭环**。

## 一、验收标准要量化

“品相不好”必须拆成可判定的指标，否则售后无法执行：

- **外观指标**：果径/单果重范围、色泽、畸形率、机械伤（压伤、划伤、磕碰）比例、腐烂/霉变比例、裂果率。
- **新鲜度指标**：果蒂状态、表皮皱缩、软化程度、异味。
- **抽样规则**：按到货批次随机抽检（如每批次抽3–5箱或按比例抽样），以抽样结果推算整批。
- **判定阈值**：例如“腐烂果≤3%、机械伤≤5%、畸形果≤8%为合格”，超出部分按比例扣款或退换。阈值需结合品类和季节约定，并明确以到货当日验收为准。

## 二、验收时限与程序

- **到货即验**：约定收货后若干小时内（如2–4小时）完成验收，逾期视为合格，避免事后扯皮。
- **双方在场**：验收时供应商或承运方在场确认，或通过拍照/视频留证后书面确认。
- **验收单**：记录批次、数量、抽检结果、不合格比例、处理意见，双方签字。

## 三、分级处置规则

按不合格程度分档，避免一律退货造成浪费：

1. **轻微瑕疵（在阈值内）**：正常收货，可协商折价。
2. **超出阈值但可销售**：按不合格比例扣款，或降价接收、由超市自行处理（如特价区）。
3. **严重不合格（腐烂、霉变、明显变质）**：整批拒收或退货，供应商承担运费及损耗。
4. **补货/换货**：约定供应商补货时限，补货仍不合格的处理方式（如终止该批次合作、扣违约金）。

## 四、责任与费用划分

- 明确**运输损耗责任**：装车前品相由供应商负责，运输途中因承运方原因造成的损伤由承运方或按合同约定承担。
- **退货费用**：谁的责任谁承担退货运费及销毁费用。
- **扣款计算方式**：写明公式，如“扣款金额=不合格比例×该批次货款”，避免口头议价。

## 五、留证与争议处理

- 验收全程拍照/录像，保存抽样样品（必要时冷藏留样至争议解决）。
- 约定争议解决方式：先协商，协商不成按合同约定的仲裁/诉讼处理。
- 建立供应商评分记录，连续不合格的触发淘汰或整改条款。

## 六、落地建议

把这些写进**采购合同附件《验收与售后细则》**，按品类分别列阈值表；同时给收货员一份一页纸的《验收操作卡》，减少执行偏差。关键是阈值要事先谈定、验收要当场完成、处理要按档执行，三点做到，售后纠纷会大幅减少。
