可以按“熟度分级 + 到货窗口 + 验收动作”来提要求，核心是让香蕉到店时处于“还能卖几天”的状态，而不是已经进入后熟高峰。

**1. 采购时明确熟度等级**
不要只说“不要太熟”，建议用可判断的标准写进采购单：

- **要求到货熟度：7成熟左右，青黄转色初期。**
  - 果皮以青为主、棱角明显、手感硬；
  - 允许少量果指转黄，但不得大面积黄、不得有黑斑；
  - 切开或轻按果肉不软塌。
- **禁止到货：**
  - 果皮超过1/3转黄、果指发软；
  - 果柄发黑、果指有压伤/水烂；
  - 有酒味、酸味；
  - 冷害蕉（皮暗灰、心硬）混入。
- 如果店内销量快、想当天开卖，可要**8成熟**：青黄各半、略能按动；如果销量慢，坚持**6.5—7成熟**。

**2. 要求到货时间**
香蕉后熟很快，到货时间比“产地熟度”更关键：

- **要求清晨或开门前到货**，当天上架，避免下午/晚上到货后闷在仓库过夜。
- **运输时间尽量短**：同城/近郊采购，要求采摘或催熟后24小时内到店；跨区域要求冷链或控温运输，避免高温车厢。
- **分批到货**：不要一次到一大车。按日销量拆成每周2—3次，小批量、多批次。
- **到货温度**：要求运输温度约13—15℃，不要低于12℃防冷害，也不要高于20℃加速后熟；夏天尤其要问清是否控温。

**3. 写进采购要求的验收条款**
可以直接对供应商这样说：

> “香蕉要7成熟、青黄转色初期，果皮无黑斑、果指不软、无压伤水烂；清晨到店，采摘/催熟后24小时内送达，运输控温13—15℃；到货抽检，熟度超标或压伤超过5%的批次拒收或折价。”

**4. 店内配合**
- 到货后不要堆压，摊开或挂起通风；
- 青蕉放阴凉处，黄蕉少量上架、先进先出；
- 不要和苹果、梨等释放乙烯的水果混放，除非你想催熟；
- 每天挑出黄熟蕉做促销或加工，避免整批拖熟。

一句话：**采购时要求“青黄初期、硬身无斑、清晨小批量到货、13—15℃运输”，验收时按熟度和压伤比例拒收。**
