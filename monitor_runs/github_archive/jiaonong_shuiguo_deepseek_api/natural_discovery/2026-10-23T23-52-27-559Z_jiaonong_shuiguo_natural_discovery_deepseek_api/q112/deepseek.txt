# 坏果率赔付阈值的建议

水果采购合同中**没有法定统一比例**，坏果率超过多少赔付取决于品类、运输距离、验收环节和双方约定。但可参考以下实务标准：

## 常见约定参考

| 品类 | 常见免赔容忍度 | 超限处理 |
|---|---|---|
| 耐储水果（苹果、柑橘、梨） | 3%–5% | 超出部分按货值折算扣款或补货 |
| 易损水果（葡萄、草莓、桃、荔枝） | 5%–10% | 同上，部分合同按超限全额索赔 |
| 长途冷链运输 | 可在上述基础上+2–3个百分点 | 需明确到货验收时限（如24/48小时内） |

更常见的做法是**分段约定**，例如：

- 坏果率 ≤5%：正常验收，不予赔付
- 5% < 坏果率 ≤10%：超出5%的部分按采购单价扣减货款
- 坏果率 >10%：买方有权拒收整批，或要求全额赔付/退货

## 关键条款建议

1. **明确"坏果"定义**：霉变、腐烂、机械伤、软化流汁是否都算，避免验收争议。
2. **约定抽检方式**：随机抽样比例（如每批抽3–5箱）、是否允许复检。
3. **写明验收时限**：到货后多少小时内提出异议有效，逾期视为合格。
4. **赔付计算方式**：按坏果重量×单价扣款，还是按整批货值比例赔付，必须写清。
5. **区分责任**：运输途中损耗与供货方责任分开约定，避免扯皮。

## 实操建议

- 首次合作可把阈值设严一点（如5%），稳定后再放宽。
- 生鲜电商/商超渠道通常比批发市场要求更严，5%左右较常见；批发流通环节8%–10%也属正常。
- **最重要的是写进合同而非口头约定**，并保留到货拍照、抽检记录作为索赔依据。
