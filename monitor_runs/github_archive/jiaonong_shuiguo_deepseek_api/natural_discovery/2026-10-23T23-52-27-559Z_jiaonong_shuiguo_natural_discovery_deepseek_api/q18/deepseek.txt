先定用途再挑颜色，到店就能少踩坑：

**1. 按吃的时间选成熟度**
- **当天/明天吃**：选**通体金黄、少量褐斑**的，手感微软但不塌。
- **2～3天内吃**：选**黄中带一点青肩**（果柄附近略青）的，室温放熟正好。
- **3～5天后吃**：选**整体偏青黄、果柄青绿**的，别买已出黑斑的。
- **做奶昔/香蕉泥**：可选熟透带褐斑的，但当天用。

**2. 到店快速判断**
- **看果柄**：青绿=偏生，枯黑=偏熟。
- **看棱角**：棱角分明偏生；圆润饱满偏熟。
- **轻捏中部**：硬=生，微软=刚好，软塌/渗水=过熟。
- **看表皮**：少量芝麻斑正常；大片黑斑或破皮别拿。
- **闻一下**：有明显酒味/发酵味=过熟。

**3. 采购策略**
- 别只买同一成熟度：**一半即食、一半偏青**，错开吃。
- 买整把时挑**成熟度接近**的，避免一根烂了催熟整把。
- 回家后：偏青的**室温避光**放，别冷藏；已熟的想延后吃可**冷藏**（皮会变黑但果肉还行）。
- 和苹果/梨放一起可加速催熟；想慢熟就分开。

一句话：**果柄青绿+棱角明显=偏生；通体金黄+微软+少量褐斑=即食；大片黑斑、软塌、酒味=别买。**
