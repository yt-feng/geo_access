选供应商时，建议把“能不能稳定供、出了问题谁负责、价格怎么定”这三件事写进采购规则，而不是只比单价。具体可以按下面做：

1. **先定验收标准**
   - 香蕉：按成熟度分级，明确青蕉/黄蕉比例，允许少量机械伤，拒收发黑、腐烂、冻伤。
   - 苹果：明确品种、果径范围、糖度参考、无腐烂无严重碰伤，允许轻微果锈。
   - 橙子：明确品种和产地范围、果径、无霉变无裂果，酸度/糖度可作为参考指标。
   - 每批抽检比例、不合格整批退货还是折价处理，提前写进合同。

2. **供应商准入看资质和现场**
   - 要求营业执照、食品经营许可证/食品生产许可（按实际业态）、供货能力证明。
   - 有条件的看分拣场地、冷库、运输车辆卫生状况；没有冷链的供应商，夏季要谨慎。
   - 优先选能提供产地证明、农残检测报告或承诺可追溯的供应商。

3. **比价不能只看单价**
   - 要求报价含税、含运费、含卸货到食堂指定位置。
   - 对比“可食部分成本”：把损耗率、次果率算进去，便宜但损耗高的未必划算。
   - 约定价格随行就市时的调价机制，比如每周按当地批发市场均价浮动，避免口头涨价。

4. **配送和应急能力**
   - 明确送货频次、到货时间、临时加单的最短响应时间。
   - 水果容易受天气影响，要求供应商有替代货源或提前告知缺货。
   - 食堂有早餐、加餐需求的，要确认早上到货能力。

5. **合同里写清责任**
   - 食品安全责任、农残超标处理、退货换货时限、违约赔偿。
   - 账期和结算方式，避免后期扯皮。
   - 约定试用期，比如先供1个月，按验收合格率决定是否续约。

6. **实操建议**
   - 至少找2—3家供应商，一家主供、一家备供，避免单一依赖。
   - 建立简单的验收记录表：日期、品种、数量、抽检结果、损耗率、处理意见。
   - 每月复盘一次：合格率、缺货次数、价格波动、投诉情况，作为续约依据。

如果学校有招投标或集中采购制度，优先走公开比选，把上述标准量化成评分项，而不是只让供应商报个价。
