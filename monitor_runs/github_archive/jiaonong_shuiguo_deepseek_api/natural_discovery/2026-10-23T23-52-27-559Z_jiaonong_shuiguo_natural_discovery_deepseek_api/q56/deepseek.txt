茶饮店控制水果供应商食品安全风险，建议把证明分成“资质类、检测类、过程类、追溯类”四组来收，并按高风险水果加严。

**1. 主体资质证明**
- 营业执照
- 食品经营许可证或食品生产许可证（按供应商实际业态）
- 若为种植基地直供：产地证明、种植主体登记/备案材料
- 若为进口水果：海关入境货物检验检疫证明、报关单

**2. 检测合格证明**
- 每批水果的农残检测报告，优先要求带CMA/CNAS标识的第三方报告
- 供应商自检报告可作为补充，但不能完全替代第三方检测
- 重点水果（草莓、葡萄、柑橘、苹果、桃等）建议按GB 2763关注的农残项目检测
- 必要时加做重金属、霉菌毒素（如苹果汁/果浆类）检测

**3. 过程与人员证明**
- 运输车辆清洁消毒记录、冷链温度记录（冷藏水果）
- 供应商从业人员健康证明
- 仓储虫害防治记录
- 若供应商负责切果/鲜切：还需提供加工场所卫生证明、切配过程记录

**4. 追溯与承诺文件**
- 供货批次清单，能对应到产地、采收/加工日期、批号
- 食品安全承诺书/质量保证协议
- 不合格品召回与处置承诺
- 供应商审核表或现场审核记录（首次合作必做）

**实操建议**
- 首次合作：收齐资质+第三方检测+现场/视频审核，签质量协议。
- 日常进货：每批索取送货单、批次检测报告或合格证明、冷链记录；无批次检测的至少定期抽检。
- 高风险鲜切水果：提高抽检频次，要求供应商提供切配环节卫生记录。
- 建立“一供应商一档案”，证照到期前提醒更新，检测报告按批次归档至少2年。

如果供应商只能提供营业执照、拿不出批次检测或追溯材料，建议列为高风险供应商，限制采购或要求整改后再合作。
