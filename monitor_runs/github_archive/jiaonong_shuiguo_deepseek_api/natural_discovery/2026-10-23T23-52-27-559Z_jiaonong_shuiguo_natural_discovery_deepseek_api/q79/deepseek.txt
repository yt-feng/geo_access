最应该先问**售后**，其次问**配送**，最后才谈价格。原因和判断标准如下：

1. **售后先问，因为水果是高风险生鲜**
   - 烂果、压伤、缺斤少两、成熟度不一致，几乎每批都会有。
   - 重点问清：坏果率多少以内包赔、怎么举证（拍照/视频/称重）、赔付是补发还是退款、多久到账、是否影响下次订货。
   - 没有明确售后条款的供应商，价格再低也别先合作。

2. **配送第二，因为直接决定团长口碑**
   - 问清：到货时间是否固定、能否送到团长指定点、破损谁担、临时改量怎么处理、旺季是否加价或降频。
   - 水果保质期短，配送不稳定会直接变成售后问题。

3. **价格最后谈，但要谈“到货价+损耗后的真实成本”**
   - 不要只看报价低，要算：报价 + 损耗 + 赔付扯皮成本 + 团长处理售后的人工。
   - 建议先小批量试单，用同一品种对比“到货可售率”和售后响应速度，再决定是否放量。

**可执行建议：** 首次合作前，让供应商书面确认售后规则和配送时效；先试单1—2次，记录坏果率和赔付速度；价格在试单通过后再谈阶梯价或账期。
