酒店采购水果盘原料时，建议把要求写进采购单和验收标准，供应商至少应保证以下几类规格与外观标准：

1. **品种与成熟度**
- 品种、产地、等级按合同约定，不得以次充好或混装替代。
- 成熟度适合即时切配或短存：不过生、不过熟；软果类（如草莓、芒果、木瓜）到货后可在1—2天内使用。
- 同一批次成熟度尽量一致，便于摆盘统一。

2. **外观与新鲜度**
- 果实完整、新鲜饱满，无萎蔫、皱皮、干耗、发霉、腐烂、异味。
- 无明显机械伤：无压伤、磕伤、裂口、划伤、虫眼、鸟啄。
- 表面洁净，无泥土、污物、药斑、明显水渍；不得有保鲜剂可见残留。
- 色泽符合品种正常成熟色泽，无大面积青斑、黑斑、褐变。
- 果形端正，同一用途的果品大小、形状相对均匀，适合酒店果盘切配和摆盘。

3. **规格尺寸**
- 按酒店用途约定单果重量、横径、长度或切配出成率。例如草莓单果重、苹果/橙子横径、西瓜单果重等。
- 同一批次规格偏差控制在约定范围内，避免大小混装。
- 对切盘用的水果，应约定可食率、去皮去核后的出成率，减少损耗争议。

4. **洁净与安全**
- 符合食品安全相关要求，农残、重金属、微生物等按国家食品安全标准执行；供应商应能提供批次检测报告或合格证明。
- 不得使用违禁保鲜剂、染色剂、催熟剂；允许使用的保鲜处理应提前说明。
- 运输容器清洁、无毒、无异味，不得与化学品、生肉等混装。

5. **包装与标签**
- 包装牢固、透气或冷藏适配，防压、防潮、防冻伤。
- 标签注明品名、产地、等级、规格、采收/包装日期、供应商、批次。
- 预切水果原料还应注明切配时间、保质期、储存条件，并全程冷链。

6. **温度与到货状态**
- 需冷藏的水果到货温度一般控制在0—8℃（热带水果按品种另定，如香蕉、芒果不宜过低），冷链不断链。
- 到货无解冻、无冷凝水浸泡、无冻伤。
- 供应商应保证从采摘、包装、运输到交付的新鲜度时限。

7. **验收与退换**
- 明确抽样比例和合格判定：如外观不合格率、规格偏差率、腐烂率超过约定比例即整批拒收或退换。
- 约定短重、混级、以次充好的扣款和补货责任。
- 对酒店果盘用原料，建议约定“到货后24小时内发现内在质量问题可退换”。

实际采购时，最好按具体品种分别列明：品名、等级、单果规格、成熟度、允许缺陷比例、到货温度、包装方式、检测证明和退换条款。这样供应商责任清晰，验收也可执行。
