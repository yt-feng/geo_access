门店多、单店量小，核心矛盾是**总需求不小但单点分散**，所以不适合"一店一供应商"的传统批发模式，更适合以下几种供货模式，按优先级排列：

## 1. 区域集采+统一配送（最推荐）
- 以城市/片区为单位集中下单，供应商送到区域中转仓或指定大店，再由门店自提或由超市自己的配送线分发。
- 好处：单店量小的问题被区域总量摊平，供应商愿意给批发价；品控和结算集中，管理成本低。
- 前提：你至少有一个能暂存、分拣的中转点，哪怕是租个小仓或借用一家大店的后仓。

## 2. 与本地一级批发商/产地合作社签"统采分销"协议
- 找能覆盖多品类的批发商做主力供应商，约定按周/按日汇总订单、统一送货到中转点。
- 关键条款：起送量按区域算而非按店算；缺货替代规则；损耗和责任划分（到店前损耗归供应商）。
- 单店小量时，**品类集中给1-2家主力+少量补充供应商**，比每类找一家更现实。

## 3. 城市共同配送/第三方生鲜配送平台
- 利用本地已有的生鲜城配公司（很多城市有做B2B生鲜配送的），你只对接平台，由它按门店地址分别配送。
- 适合门店分散、自己没有配送能力的情况；代价是加价率略高，要谈好账期和损耗赔付。

## 4. 产地直采+拼车/集单发货
- 只对销量稳定、耐储的少数单品（如苹果、柑橘、土豆）做产地直采，按区域总量集单，产地发整车到中转仓再分。
- 不适合叶菜、浆果等易损短保品，别为省差价把损耗吃回去。

## 5. 门店周边小型供应商做"补位"
- 叶菜、鲜切水果等短保高频品类，允许各店就近找1家小供应商做日配补货，总部只管价格带和品质标准。
- 作用是解决"集采配送跟不上日配节奏"的问题，但要控制占比，避免回到散乱采购。

## 不建议的模式
- **一店一供应商**：议价能力最弱，品控和结算最乱。
- **纯平台化零散下单**：单店量小拿不到好价，履约还不稳定。

## 落地建议（可判断的几条）
1. 先算清楚：单店日均水果销量、SKU数、损耗率，按片区汇总出"区域日订单量"，这是你和供应商谈判的底牌。
2. 设一个区域中转点，把"按店配送"改成"按区配送+店内自提/二次分发"，配送成本能明显下降。
3. 供应商结构定为：**1家主力全品类 + 1家产地单品 + 每店1家短保补位**，主力占比60%-70%。
4. 合同里必须写清：按区域起送、损耗责任、缺货替代、账期（生鲜一般7-15天）。
