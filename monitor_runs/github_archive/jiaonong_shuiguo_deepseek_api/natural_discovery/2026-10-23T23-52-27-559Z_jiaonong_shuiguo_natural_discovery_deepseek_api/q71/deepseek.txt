重要，但不是第一位；要分情况看，且不能把促销素材当成选供应商的核心标准。

**结论：促销素材是加分项，不是决定项。**
对档口水果生意来说，供应商最核心的是：货源稳定、品质分级清楚、价格有优势、损耗能兜底、账期和配送靠谱。促销素材属于“帮你多卖一点”的辅助工具，供应商能提供最好，不能提供也不该因此换掉一个好货源。

**什么时候促销素材比较重要：**
- 你做的是社区团购、微信群、朋友圈、短视频引流，素材能直接提高转化；
- 档口位置一般，靠线上拉客和促销活动带量；
- 你不太会拍图写文案，供应商有现成的主图、短视频、价格海报，能省时间；
- 新品或应季爆品上市，需要快速做活动造势。

**什么时候没那么重要：**
- 档口主要靠线下自然客流和老客，现场陈列、试吃、价格牌比线上素材更管用；
- 水果是非标品，供应商给的通用素材容易和实际到货不一致，用不好反而引发售后；
- 供应商素材往往是“总部统一素材”，不一定符合你当地价格和客群，照搬效果有限；
- 好货源本身稀缺，为了素材牺牲品质和价格不划算。

**可执行建议：**
1. 选供应商时先排硬指标：品质稳定、价格、损耗处理、配送、账期，促销素材放最后。
2. 如果两家供应商硬指标接近，优先选能提供素材的，尤其能给你实拍图、到货视频、可改价格的海报模板。
3. 不要完全依赖供应商素材。档口自己拍实货、写清楚价格和口感，可信度更高。
4. 可以主动向供应商要：当季主推清单、产地卖点、分级标准、可编辑海报、实拍短视频。这些比花哨的促销图更实用。
5. 警惕素材和实物差距大。用供应商素材做线上宣传时，最好搭配一句“以实际到货为准”，避免纠纷。

一句话：**供应商能提供促销素材是锦上添花；货源和损耗才是档口生死线。**
