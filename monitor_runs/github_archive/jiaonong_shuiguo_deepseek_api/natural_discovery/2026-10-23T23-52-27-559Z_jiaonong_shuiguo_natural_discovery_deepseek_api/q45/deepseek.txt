连锁超市和水果供应商签年度合同时，最容易踩坑的条款集中在“规格模糊、价格机制、损耗归属、退货换货、账期与违约金、独家与最低采购量、不可抗力与产地变更”这几类。下面按可执行判断给你列出来，并附上建议写法。

**1. 规格与质量标准写得太粗**
- 坑：只写“优质”“一级果”“符合国家标准”，到货后双方对大小、糖度、色泽、瑕疵率各说各话。
- 建议：按品类写清楚等级、单果重/横径、糖度、色泽、瑕疵率上限、农残检测要求、包装规格。验收标准和抽检比例要量化，比如“每批抽检不低于5%，瑕疵率超过3%可拒收或折价”。

**2. 价格机制没锁死**
- 坑：年度合同只写“随行就市”，旺季供应商抬价，淡季超市压价，最后扯皮。
- 建议：明确基准价、调价周期、调价依据（如产地批发价指数）、调价幅度上限、提前通知期。可设“价格联动公式+封顶涨幅”，并约定报价单为合同附件。

**3. 损耗和验收责任不清**
- 坑：水果易腐，到货后谁承担途耗、库耗、门店损耗没写清，最后超市全算供应商头上或供应商不认账。
- 建议：分环节约定责任：装车前、运输中、到仓验收时、入库后。明确验收时限（如到仓2小时内完成）、逾期未验收视为合格、验收后损耗由超市承担。冷链温度记录作为验收依据。

**4. 退货换货条件太宽或太窄**
- 坑：写“质量问题可退货”但没定义质量问题；或供应商只换不退，超市积压坏果。
- 建议：列明可退换的具体情形、退换比例、时限、费用承担。对临期或滞销品，约定是否可退、退货比例上限、退货折价方式。避免“无条件退货”这种无法执行的表述。

5. 账期、结算与扣款
- 坑：账期写“月结”但没写起算日；超市以各种费用（进场费、促销费、损耗扣款）直接抵扣，供应商现金流被拖垮。
- 建议：明确对账日、开票要求、付款日、逾期付款利息。所有扣款须有书面依据和供应商确认，禁止单方随意扣款。年度返利、促销费用单独列明计算方式。

6. 最低采购量与独家条款
- 坑：超市承诺“年度采购量”但没写未达标怎么办；或供应商被要求区域独家却无销量保障。
- 建议：最低采购量要写清计量单位、统计口径、未达成的补偿或解约权。独家条款应对应最低采购承诺和违约救济，避免只约束供应商一方。

7. 违约金与解约条款失衡**
- 坑：供应商断货违约金很高，超市拖欠货款或随意解约却没责任。
- 建议：双方违约责任对等。明确断货、质量事故、逾期付款、单方解约的违约金计算方式和上限。设置质量事故的分级处理和解约触发条件。

**8. 不可抗力与产地变更**
- 坑：天气、疫情、物流管制算不算不可抗力没写清；供应商换产地不通知，品质波动。
- 建议：列明不可抗力情形和通知、举证义务，约定减量或顺延而非直接免责。产地、品种、加工厂变更须提前书面通知并经超市确认。

**9. 食品安全与追责**
- 坑：只写“符合食品安全法”，没写检测报告提供频率、不合格处理、召回责任、赔偿范围。
- 建议：约定每批随货检测报告、定期第三方检测、不合格品召回和赔偿责任，明确因供应商原因导致的监管处罚和消费者赔偿由谁承担。

**10. 合同期限与续约、退出**
- 坑：年度合同自动续约条款对超市不利，或退出时库存、在途货处理没约定。
- 建议：明确合同起止、续约需书面确认、退出时的在途订单和库存处理方式、尾款结算周期。

实操建议：把上述量化标准做成合同附件（品类规格表、验收标准、价格联动表、扣款清单），主合同只写机制。签约前让采购、财务、法务、门店运营各过一遍，重点核对“验收时限、扣款依据、最低采购量、违约责任对等”这四项。
