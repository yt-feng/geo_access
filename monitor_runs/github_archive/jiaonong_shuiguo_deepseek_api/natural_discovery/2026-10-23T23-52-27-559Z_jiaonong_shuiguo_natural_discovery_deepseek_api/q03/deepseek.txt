第一次试单，核心不是“找最便宜”，而是用最小成本验证三件事：货稳不稳、损耗谁承担、补货快不快。建议按下面做。

**1. 先定试单原则**
- 每样只拿 **1—2箱**，不要一次囤多。
- 香蕉、苹果、橙子分开验证，因为三者风险点不同：
  - 香蕉：催熟状态、到店后还能卖几天
  - 苹果：外观、口感、压伤
  - 橙子：大小均匀度、皮厚、酸度、坏果率
- 试单期控制在 **1—2周**，同一供应商至少补货2—3次再判断。

**2. 试单前问清5个问题**
直接问供货商，并要求写进聊天记录：
1. 起送量多少？夫妻店小批量送不送？
2. 价格是当天报价还是锁价？一天内波动怎么算？
3. 坏果、压伤、烂果怎么赔？是拍照补货、下次抵扣还是直接退？
4. 几点前下单、几点送到？临时补货能不能当天到？
5. 香蕉是青蕉还是催熟蕉？到店大概几成熟？

**3. 三样货的试单重点**
- **香蕉**：先拿1箱，记录到店成熟度。太青卖不动，太黄当天卖不完。重点看第二天、第三天品相和掉秤。
- **苹果**：拿1箱中号常用规格，开箱查底层和边角，看压伤、碰伤、大小是否均匀。先试口感再谈量。
- **橙子**：拿1箱，随机抽10个称重、切开2—3个看酸度和水分，记录坏果数。重点防“上面大下面小”。

**4. 每次到货当场验收**
- 称重：整箱重量、去皮后净重。
- 拍照：开箱前、开箱后、坏果特写。
- 记录：到货时间、数量、坏果数、成熟度、卖相。
- 当天卖完前别追加同款大单。

**5. 用简单表格打分**
每家供应商记这几项，试2—3次再定：
- 到货准时率
- 坏果率（坏果数÷总数）
- 实际净重是否足
- 卖相和口感
- 补货响应速度
- 售后是否爽快

**6. 判断标准**
可以继续合作：连续2—3次坏果率低、重量足、补货快、售后不扯皮。
要换掉：一次试单坏果明显多还推责、经常晚送、报价和结算不一致、小单不情愿送。

**7. 试单话术**
“老板，我店里先试卖，香蕉、苹果、橙子各要1箱，麻烦按店里常卖的规格发。到货我先开箱验，坏果和压伤按实际拍照，能补能抵咱们再长期合作。今天下单明天几点能到？”

最后提醒：第一次别只找一家，**同时试2家、每家小单**，对比后再定主供。夫妻店最怕的不是单价高几毛，而是断货和烂货压手里。
