判断哪个规格更容易出货，不要只看“哪个卖得多”，而要看“哪个规格在批发环节周转最快、退货最少、下游最愿意重复拿”。可以按下面几步做：

1. **按规格分开记账**
   至少分成：小果、中果、大果、特大果，或按重量区间分。每个规格记录：
   - 到货量
   - 当天/3天内出货量
   - 出货价
   - 损耗率（烂、压伤、熟透）
   - 退货/投诉次数
   - 下游客户类型（水果摊、商超、餐饮、电商、二批）

2. **看“周转天数”而不是单纯销量**
   计算：某规格库存÷日均出货量。
   周转天数越短，越容易出货。大果可能单价高但压货久，小果可能便宜但走得快。

3. **看“ repeat 拿货率”**
   同一客户7天内是否再次拿同一规格。重复拿货率高，说明这个规格稳定好卖，不是靠一次低价冲量。

4. **看损耗和退货后的真实利润**
   用“净出货毛利”判断：
   净毛利=销售额-进货成本-损耗-退货-人工分拣。
   有些规格看着出货快，但损耗高、退货多，实际不如中规格。

5. **分客户看规格偏好**
   - 水果摊/社区店：常偏中果，好卖、价格适中
   - 商超：偏外观整齐、规格统一
   - 餐饮/果汁店：偏大果或次果，重出汁率、价格
   - 电商：偏标准化中果，怕压伤
   如果某规格在某一类客户里重复拿货最多，就是你的“主推出货规格”。

6. **做小批量测试**
   同一批货里，每个规格拿少量同时放出去，连续3-5天记录出货速度和客户反馈。不要凭感觉一次压太多。

**最简判断标准：**
优先选“周转天数最短 + 损耗率低 + 重复拿货率高 + 净毛利为正”的规格。  
如果只能看一个指标，看**7天内重复拿货率**；如果只能看两个，再加**周转天数**。

**实操建议：**
先用一周把每个规格的出货量、库存、损耗、退货记下来，算出周转天数和净毛利，再决定主推哪个规格、哪个规格要减少进货或改走餐饮/果汁渠道。
