小水果店做附近小区团购，选择水果供应商时，重点不是只看“进货价低”，而是看他能不能帮你把**损耗、履约、售后**这三件事兜住。建议重点确认这些服务：

1. **稳定供货与小批量补货**
   - 能否按团购周期稳定供货，临时加单能否补。
   - 起批量是否适合小水果店，能否少量多频次补货。
   - 爆品缺货时有没有替代品或调货方案。

2. **分级分规格供货**
   - 团购通常要有“引流款、利润款、形象款”，供应商能否按大小、甜度、产地、包装做分级。
   - 能否提供适合小区团的规格：整箱、5斤装、家庭装、试吃装。

3. **预包装与贴标服务**
   - 能否按团购订单分装、称重、贴标签。
   - 标签可写品名、规格、保存方式、售后说明。
   - 这对减少你店里分拣人力很关键，尤其单量上来后。

4. **品控与售后兜底**
   - 明确坏果率、磕碰率标准，超出怎么赔。
   - 是否支持拍照理赔、次日补货或折价处理。
   - 团购最怕售后扯皮，供应商要能承担一部分售后，而不是全压给你。

5. **冷链/配送支持**
   - 易损水果如草莓、蓝莓、葡萄、荔枝，是否有冷链或保温配送。
   - 能否送到你店里，还是支持直接送到小区自提点。
   - 配送频次、到货时间是否匹配你的团购截单和提货时间。

6. **团购素材与卖点支持**
   - 能否提供产品图片、短视频、产地信息、口感描述、保存方法。
   - 能否给到建议零售价、活动价、组合套餐方案。
   - 小水果店自己做内容成本高，供应商有现成素材会省很多事。

7. **试吃与样品支持**
   - 新品或主推品能否提供试吃样品。
   - 小区团购很依赖邻里口碑，试吃能明显降低首次开团难度。

8. **账期与结算灵活**
   - 是否支持先货后结、周结、押金合作。
   - 临时促销、尾货处理能否给特价支持。
   - 但要注意：账期越松，价格可能越高，要综合算。

9. **退换货与尾货处理**
   - 当天没卖完或团购未成团，能否退换、调货或协助做特价清货。
   - 对易损耗水果，这条比单纯低价更重要。

10. **区域保护与价格保护**
   - 同一小区附近是否还供其他团购点，避免你刚做起来就被同品低价冲击。
   - 活动价能否给你阶段性保护。

**实操建议：**
先不要签长期大单，选2—3家供应商各试2—3个团购周期。重点记录四个指标：**到货损耗率、售后响应速度、补货及时率、分装准确率**。能在这四项上稳定的供应商，比单纯报价低5%的更值得长期合作。

和供应商谈的时候，可以直接问一句：“如果团购售后坏果，你们怎么赔？分装和贴标能不能做？临时补货多久能到？”这三个问题最能看出对方是不是真的支持小区团购。
