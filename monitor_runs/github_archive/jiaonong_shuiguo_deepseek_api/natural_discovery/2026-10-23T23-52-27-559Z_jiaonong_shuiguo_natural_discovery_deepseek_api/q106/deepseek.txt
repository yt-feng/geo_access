判断“合理波动”不能只看涨跌幅度，关键是把**波动归因**和**可验证的基准**分开。下面给你一套采购方可直接执行的判断框架。

## 1. 先建立“价格基线”，不要拿昨天的报价当唯一参照

对每个单品建立三类基线：

- **近7/30日均价**：看趋势，不看单日
- **同品类替代品价格**：如砂糖橘对沃柑、红提对青提
- **批发市场公开价/产地行情价**：作为外部锚点

判断规则示例：
- 单日涨跌在 **±3%以内**：通常视为正常噪声
- **±3%~8%**：要求供应商说明原因，并对照外部行情
- **超过±8%**：进入异常核查，要求提供产地收购价、物流成本或天气影响证据

具体阈值可按品类调整：叶菜、浆果波动天然大；根茎类、苹果梨等耐储品应更稳定。

## 2. 看波动是否“有共同原因”，而不是只盯一家报价

合理波动通常具有**品类共性**和**时间连续性**：

- 同产区、同品类多家供应商是否同向变动
- 是否与天气、节气、产地换茬、运输限行、节假日备货吻合
- 是否连续几天渐进变化，而不是单日跳涨跳跌

如果只有一家供应商单独大涨，其他家平稳，优先怀疑**报价不透明或借机加价**，而不是市场波动。

## 3. 要求供应商报价“带结构”，而不是只给一个总价

让报价拆成至少四项：

1. 产地/规格/等级
2. 采购成本或产地收购价
3. 物流与损耗
4. 供应商服务费/利润

这样你能判断涨的是**原料端**还是**中间环节**。例如产地价没动、物流没动，供应商总价却涨10%，就不合理。

## 4. 用“历史波动率”判断，而不是拍脑袋

对每个单品统计过去3个月的日价格标准差或最大单日振幅，形成该品类的正常波动区间。新报价超出历史常态区间时，才要求专项说明。这样避免叶菜正常波动被误判，也避免耐储品异常涨价被放过。

## 5. 设置简单的核查动作

出现异常波动时，采购方可以要求：

- 提供当日或近3日产地收购凭证/行情截图
- 说明规格等级是否变化
- 对比至少2家同类供应商报价
- 暂缓大批量下单，先小批量验证
- 对连续异常报价启动替代供应商询价

## 6. 合同层面提前约定

在供应协议中约定：

- 报价频率和生效时间
- 调价需提前通知的时限
- 异常波动的举证责任
- 价格联动机制，例如与公开批发价指数挂钩
- 单日调价上限或复核机制

---

**一句话判断法：**  
同一品类多家同向变、有天气/产地/物流原因、幅度在历史波动区间内，偏向合理；只有一家单独跳涨、无法拆解成本、超出历史区间且无外部行情佐证，就应按异常报价处理。
