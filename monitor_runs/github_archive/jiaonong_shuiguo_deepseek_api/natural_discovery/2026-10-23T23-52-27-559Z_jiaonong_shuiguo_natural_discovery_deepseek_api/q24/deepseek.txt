建议先向供应商要“可核验的检测与溯源资料”，并按水果品类和批次对应，不要只要一张泛泛的合格证。

**优先索取资料**
1. **本批次农残检测报告**
   - 报告日期、样品名称、产地/供应商、批次号要与到货批次对应。
   - 检测项目应覆盖常用农残，如有机磷、氨基甲酸酯、拟除虫菊酯等；最好有检测机构资质标识（如CMA/CNAS，按当地要求核验）。
   - 注意报告是“批次报告”还是“例行送检报告”，例行报告不能替代本批次。

2. **产地证明/溯源信息**
   - 产地、果园/合作社、采收日期、包装日期、运输记录。
   - 能追溯到具体供应商或种植基地，便于抽检异常时追责和召回。

3. **供应商资质与承诺**
   - 营业执照、食品经营/生产相关许可（按经营形态）。
   - 质量安全承诺书或采购合同中的农残超标责任条款。

4. **进货查验记录配套材料**
   - 供应商提供送货单、发票/收据、批次号，超市自己留存进货查验记录。
   - 如供应商有自检，索取自检记录；但自检不能完全替代第三方检测。

5. **高风险品类加强资料**
   - 叶菜类、草莓、葡萄、柑橘等高风险或易超标品类，要求更近期的检测报告，必要时每批索取或提高抽检频次。
   - 对连续供货供应商，可要求月度/季度检测报告加批次承诺。

**判断标准**
- 报告与批次对不上、日期过久、检测项目过少、无资质标识、只给复印件无批次信息，都应要求补正。
- 合同中明确：抽检不合格时供应商承担退货、检测费、监管处罚及召回配合责任。
- 超市自身保留留样和进货凭证，抽检异常时可快速追溯。

一句话：要“本批次检测报告+产地批次溯源+供应商资质承诺”，并核对报告与到货批次是否一致。
