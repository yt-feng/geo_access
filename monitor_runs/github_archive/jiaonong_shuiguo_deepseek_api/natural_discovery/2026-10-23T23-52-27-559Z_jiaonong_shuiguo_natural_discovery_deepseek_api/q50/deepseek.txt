甜度和出汁率不是二选一，要按用途分层看：**出汁率决定成本和出品稳定性，甜度决定风味下限，但对茶饮店来说通常“出汁率优先于绝对甜度”。**

判断标准可以这样定：

1. **鲜果茶/水果茶现切现捣**
   - 优先看：**出汁率、果肉纤维、成熟度一致性**。
   - 甜度只要达到可接受区间即可，因为糖度可以靠糖浆微调，但出汁少、果肉柴会直接影响杯量和口感。
   - 建议：同一批次抽测出汁率，低于你的标准就换供应商或调整采购规格。

2. **榨汁/打泥做果昔、菠萝冰**
   - 出汁率权重更高，直接决定每杯原料成本和出品效率。
   - 甜度不足可以用糖浆补，但酸涩、纤维粗、出汁低很难补救。

3. **做菠萝果酱、糖渍、装饰片**
   - 甜度和香气权重上升，出汁率次要。
   - 这类用途更看重成熟度、香气和切面外观。

4. **门店采购的实际决策**
   - 先设一个**最低甜度门槛**（比如可溶性固形物达到你设定的标准），低于门槛不收货。
   - 在达标原料中，再选**出汁率高、批次稳定、损耗低**的。
   - 不要为“特别甜”付明显溢价，因为茶饮最终甜度由配方控制；但出汁率低会带来隐性成本。

一句话：**甜度是准入指标，出汁率是经营指标。茶饮店批量买菠萝原料，出汁率通常更重要；做装饰或果酱时再提高甜度权重。**
