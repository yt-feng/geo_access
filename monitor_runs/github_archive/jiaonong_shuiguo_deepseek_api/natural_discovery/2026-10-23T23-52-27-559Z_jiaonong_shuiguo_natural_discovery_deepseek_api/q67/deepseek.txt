和品牌方谈代理，区域保护和串货是决定你能不能赚钱的核心条款。建议你按下面顺序问，并把答案落到合同里，不要只听口头承诺。

**一、先问区域保护，确认“独家”到底独到什么程度**

1. 我代理的区域范围具体怎么划？是按省、市、区县，还是按渠道（商超/水果店/电商）划分？
2. 这个区域内是独家代理，还是可以同时有多家？如果有多家，我的权益怎么保障？
3. 品牌方自己或它的直营渠道，能不能在我区域内直接卖货？线上旗舰店、直播带货发到我区域算不算？
4. 区域保护有没有业绩门槛？比如年进货量不达标就取消独家，具体标准是多少、怎么考核？
5. 保护期限多长？到期续约的条件是什么？
6. 如果品牌方在我区域内又签了第二家，或者自己直供，我有什么救济？违约金怎么算、能不能退货或解约？

**二、再问串货，重点问“怎么认定、怎么处理、谁举证”**

1. 串货的定义是什么？是跨区域销售就算，还是低价倾销才算？线上销售算不算串货？
2. 品牌方对串货有什么管控手段？有没有产品追溯码/批次码？能不能查到货从哪个代理流出？
3. 我发现别人串货到我区域，向谁举报、多久处理、处理结果怎么反馈给我？
4. 串货方被抓到怎么处罚？罚款、扣返利、断货、取消代理资格，具体标准写不写进合同？
5. 我被认定串货时，举证责任在谁？有没有申诉和复核机制？
6. 因串货导致我价格体系崩了、货卖不动，品牌方赔不赔？能不能要求调换货或补偿？

**三、必须落到合同里的几个关键点**

- 区域范围、独家性、品牌方自营/线上的边界，写清楚。
- 业绩考核标准、保护期限、续约条件，写清楚。
- 串货认定标准、举报流程、处理时限、处罚措施，写清楚。
- 品牌方违约（区域内再授权、自营直销）的违约责任和你的退出机制，写清楚。
- 退货、调换货、价格保护条款，尤其是水果有保质期，压货风险要提前约定。

**四、谈判时的实用提醒**

- 别只听“我们管得很严”，要问具体案例：过去一年处理过几起串货、怎么处理的。
- 要求看现有代理合同模板，重点看区域保护和串货条款是不是模糊表述。
- 线上渠道一定要单独问，很多品牌线下保护、线上不管，等于没保护。
- 水果损耗大，区域保护和串货条款要配合退货/调换货机制一起谈，否则保护了区域也扛不住压货。

一句话总结：区域保护问“独家边界和品牌方自己会不会抢”，串货问“怎么查、怎么罚、我被冤枉怎么办”，所有答案都要写进合同并约定违约责任。
