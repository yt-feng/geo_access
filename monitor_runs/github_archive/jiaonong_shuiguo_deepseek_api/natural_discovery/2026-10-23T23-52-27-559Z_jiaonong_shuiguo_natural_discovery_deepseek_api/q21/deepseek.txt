超市采购水果时，供应商通常需要提供以下检测报告或进货证明，具体以当地监管要求和超市验收标准为准：

1. **营业执照及食品经营许可相关资质**
   - 供应商营业执照
   - 食品经营许可证或食用农产品销售相关备案/许可材料
   - 若为生产合作社或基地直供，可提供种植主体资质、产地证明等

2. **产地证明或供货证明**
   - 产地证明、村委会/合作社/基地出具的供货证明
   - 购销合同、送货单、发货单、进货台账
   - 批发市场开具的销售凭证或电子交易凭证

3. **农产品质量安全检测报告**
   - 农药残留检测报告，常见为快速检测报告或定量检测报告
   - 报告应体现样品名称、检测项目、检测结果、检测日期、检测机构或自检主体
   - 超市一般要求批次对应，或至少近期批次报告

4. **承诺达标合格证**
   - 食用农产品承诺达标合格证是常见进货凭证之一，尤其适用于蔬菜、水果等食用农产品
   - 应包含生产者信息、产品名称、数量、开具日期、承诺内容等

5. **检验检疫相关证明**
   - 国产水果一般以农残检测和合格证为主
   - 进口水果需提供海关入境货物检验检疫证明、报关单等
   - 进口水果还应能追溯至进口商或口岸

6. **包装标识和标签材料**
   - 预包装水果需符合标签标识要求
   - 散装水果应提供品名、产地、生产者或供货者信息等追溯信息

7. **其他超市验收材料**
   - 供应商档案、质量保证协议
   - 批次送货单、验收记录
   - 冷链水果的运输温度记录
   - 有机、绿色、地理标志等认证证书，如宣称相应认证则需提供

实操建议：超市采购时应要求“**一批次一凭证**”，至少做到供应商资质齐全、进货凭证可追溯、农残检测或合格证随货同行；进口水果重点核验检验检疫证明和报关信息。具体清单建议按当地市场监管部门和超市内部验收制度确认。
