结论：**绝大多数餐饮连锁，水果优先“中央厨房统一收货”，但要有例外清单：门店直收只保留给极少数高损耗、强本地化、即时性品类。**

## 为什么中央厨房统一收货更好

对水果这种**高损耗、强品质波动、价格波动大**的品类，统一收货的核心价值是：

1. **品质标准统一**：糖度、成熟度、规格、瑕疵率能按同一标准验收，避免各店标准不一。
2. **议价和集采优势**：总部集中采购、集中结算，价格和账期更有优势。
3. **供应商管理集中**：准入、考核、追溯、换供应商都在总部，门店无权私采，降低灰色空间。
4. **食品安全可追溯**：农残检测、批次记录、索证索票集中在中央厨房，责任清晰。
5. **减少门店操作负担**：门店只管收货使用，不承担采购和验收专业能力。
6. **数据集中**：采购量、损耗、品质投诉可汇总分析，反哺供应商和配方。

## 但以下情况门店分开收货更合理

- **极短保、高损耗品类**：如草莓、蓝莓、鲜切水果、部分叶菜类水果，经中央厨房再配送会多一次搬运和温控风险。
- **本地特色强**：门店所在区域有强本地供应链，统一配送反而慢、贵、不新鲜。
- **配送半径过长**：中央厨房到门店超过合理冷链半径，配送频次跟不上销售节奏。
- **门店现制现售占比高**：如果水果主要用于门店现场制作、对成熟度要求差异大，门店直收更灵活。

## 建议的落地模式：**“统采统收为主 + 例外直采白名单”**

1. **主品类统一**：苹果、橙子、西瓜、香蕉、柠檬等耐储或标准化程度高的，全部中央厨房统一收货、统一验收、统一配送。
2. **例外白名单**：只对极短保、高损耗、本地化强的品类开放门店直收，且必须总部准入供应商、总部定标准、门店按标准验收、数据回传。
3. **验收标准前置**：糖度、规格、成熟度、瑕疵率、农残检测报告、冷链温度记录，做成可执行的验收卡。
4. **损耗责任分开算**：中央厨房到店损耗归物流/仓储，门店存储损耗归门店，避免扯皮。
5. **动态评估**：每季度看损耗率、投诉率、到店新鲜度、综合成本，决定某品类是否收回或放开。

**判断标准一句话**：如果某水果的“多一次中转”带来的品质损失小于“统一标准+集采+可追溯”带来的收益，就中央厨房收；反之才放门店。
