判断香蕉供应商能否全年稳定供货，核心不是看对方“承诺”，而是看**产地组合、硬件设施、历史履约数据**三条线能不能互相印证。建议按下面顺序核查：

**1. 先问产地结构，不接受单一产区**
- 香蕉主产区有季节差：国内海南、广西、云南、广东上市期不同，进口主要来自菲律宾、越南、厄瓜多尔、柬埔寨等。
- 合格供应商应能说清：哪几个月靠哪个产区/进口国，切换节点是什么，某产区受灾时替补来源是哪。
- 只有“我们常年有货”但讲不清产地轮换的，基本是贸易倒手，旺季能供、淡季或灾年容易断。

**2. 查硬件：催熟库和冷链决定“全年”能力**
- 香蕉是青果运输、催熟后上市。供应商（或其合作加工厂）要有**催熟库容量、温湿度控制、冷链车/冷库**。
- 问：旺季日处理量多少箱？催熟库几个库房、总容量？停电或设备故障有无备用？
- 催熟能力不足的供应商，在到货集中期会压货、在淡季又供不上，全年稳定性差。

**3. 要历史履约数据，而不是口头保证**
- 让对方提供近12个月：月度供货量、断供次数、到货合格率、平均到货时间。
- 最好要2—3个同规模连锁超市客户的合作年限和月均供货量（可要求提供联系人做背调）。
- 重点看**春节后、台风季、雨季、进口国政策波动期**这几个时间点的供货记录。

**4. 合同上把“稳定”变成可考核条款**
- 约定月度最低供货量+旺季增量响应时间（如提前X天报量，X天内到货）。
- 设断供违约金、替代货源报备义务、质量不达标退换货和补货时限。
- 要求供应商提供备用产地/备用加工厂，并在合同附件中列明。

**5. 采购方自己做压力测试**
- 先小批量试单3个月，覆盖一个淡旺季切换点，记录到货准时率、损耗率、催熟一致性。
- 同时保留第二供应商，哪怕份额小，避免单一依赖。

**快速判断口诀**：讲得清产地轮换、拿得出催熟库和冷链、给得出近12个月履约数据、合同敢写断供责任——四条都满足才谈得上全年稳定；只满足前两条的是“有货能力”，不是“全年稳定能力”。
