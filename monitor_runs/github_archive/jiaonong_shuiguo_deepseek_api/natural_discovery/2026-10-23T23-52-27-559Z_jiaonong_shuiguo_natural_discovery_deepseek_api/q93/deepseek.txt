这三项都要管，但优先级不一样：**先看保质期和包装，再定配送频次**。菠萝切块是即食鲜切水果，风险主要在微生物和氧化变质，不是单靠“多配送”能解决的。

**优先级建议：**

1. **保质期（第一优先）**
   - 鲜切菠萝冷藏条件下通常建议**当天制作、当天售完**，最长不超过**24小时**（以门店实际制度和当地监管要求为准）。
   - 必须做**制作时间标签**，明确“制作时间、保质截止时间”，到期下架，不能靠“看着没坏”继续卖。
   - 切块后冷藏温度控制在**0—4℃**，售卖柜不能常温敞开摆。

2. **包装（第二优先）**
   - 必须用**食品级密封容器或覆膜盒**，减少暴露和交叉污染。
   - 包装上要有**制作日期/时间、保质期、储存条件**；散装裸卖风险最高，不建议。
   - 检查封口是否完整，渗汁、鼓盖、冷凝水过多都要关注。

3. **配送频次（第三优先，但影响库存和损耗）**
   - 配送频次解决的是“新鲜度和周转”，不是保质期本身。
   - 建议**少量多次**：根据日销量定配送量，按“上午补一次、午后看销量补一次”的节奏，避免一次压太多货。
   - 鲜切菠萝不适合大量囤货，配送频次应服从**日销量和保质期**，而不是固定追求高频。

**可执行判断标准：**
- 若只能改一项：**先把保质期标签和冷藏闭环做到位**。
- 若损耗高、下午常剩货：**再调配送频次，减少单次配送量**。
- 若出现渗漏、异味、发黏、颜色发暗：**直接下架，不靠配送频次补救**。

简单说：**保质期是底线，包装是保障，配送频次是优化周转的手段。**
