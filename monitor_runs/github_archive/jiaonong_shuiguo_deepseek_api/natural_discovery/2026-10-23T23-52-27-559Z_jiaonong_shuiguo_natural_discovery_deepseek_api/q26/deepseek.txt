社区超市卖小包装香蕉，采购和包装要重点抓“成熟度、份量、透气、防压、周转”五件事。下面按可执行要点说：

1. **先定小包装规格**
   - 建议做 **2–3 根/袋**，净重约 **300–500g**，面向单人/小家庭。
   - 规格不要过多，先上1–2个SKU试销；避免大袋卖不动、小袋不够买。
   - 定价按“袋”而不是按斤，便于消费者快速决策，也便于控制毛利。

2. **采购成熟度要偏低**
   - 小包装周转慢于散装，采购时不要拿已经黄熟、带黑斑的货。
   - 优先选 **青黄交界、果指饱满、棱角稍明显** 的香蕉，给门店留2–3天销售期。
   - 夏季或空调不足的店，成熟度再降半档；冬季可略高。
   - 到货后按成熟度分两批：稍青的先进库/后场上架，已黄的先上架。

3. **包装材料要透气、防压**
   - 不要用完全密封的塑料袋长期闷着，容易积水汽、加速腐烂。优先用 **打孔袋、网袋、透气膜袋**，或袋口不封死。
   - 袋上建议开透气孔，尤其冷藏/空调环境；但孔不要大到掉果。
   - 底部要有一定支撑，避免袋装香蕉堆叠后压伤；可用浅托盘、分隔盒或纸浆托。
   - 标签贴在不直接接触果皮的位置，避免胶粘剂污染果面。

4. **控制单袋重量和堆码高度**
   - 单袋不要超过500g太多，堆叠不超过2–3层，防止下层果指压伤。
   - 香蕉怕压、怕碰，采购箱内也要用纸隔板/果托，运输中避免和硬物混装。
   - 门店陈列不要整袋平堆在收银台暴晒处，选阴凉、通风、避免阳光直射的位置。

5. **损耗管理要前置**
   - 采购量按“日销×1.5–2天”试单，先小批量高频补货，不要一次压太多。
   - 每天早晚翻检，把开始出黑斑的袋装香蕉挑出，做 **打折区/熟食搭配/员工内购**，不要等烂在货架。
   - 建立简单记录：到货成熟度、上架日期、日销量、报损量。连续一周看哪个规格损耗高，及时调份量或改成熟度。
   - 夏季损耗通常高于冬季，采购量要更保守；雨季注意袋内水汽，必要时换更透气的包装。

6. **采购验收要点**
   - 看果指是否完整、有无机械伤、裂口、水烂、霉点。
   - 摸果身：太软的不收；青硬但饱满的可以收。
   - 闻气味：有酒味、酸味说明已过熟或内伤。
   - 抽检箱内中层和底层，避免只看表面。
   - 问清产地、采摘/催熟时间、运输温度，尽量固定供应商，减少批次波动。

**建议先做的小测试**：选2–3根/袋、300–400g和400–500g两个规格，各上架一周，记录日销和报损；同时比较打孔袋和网袋两种包装。哪个规格卖得快、损耗低，就主推哪个。
