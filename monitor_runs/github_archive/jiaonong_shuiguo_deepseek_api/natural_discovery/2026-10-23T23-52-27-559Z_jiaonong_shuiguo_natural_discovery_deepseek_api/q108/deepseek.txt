核实全国配送，不能只看供应商一句“能全国配送”，要拆成“能不能送到、多久送到、出了问题谁负责”三层来验。建议按下面做：

1. **先问清配送定义**
   - 是全国所有城市主城区，还是仅限地级市/部分区域？
   - 偏远地区、县域、乡镇是否覆盖？
   - 是供应商自营配送，还是外包给快递/冷链平台？
   - 生鲜是普通快递、冷链快递，还是干线+落地配？

2. **要求提供可核验的覆盖清单**
   - 让供应商给出近3—6个月实际配送过的城市/区域清单，最好带订单量级或客户类型，而不是只给“合作快递全国可达”。
   - 要求提供合作物流商名称、冷链资质、网点范围。
   - 对采购方目标城市，逐一确认“是否直达、是否中转、预计时效”。

3. **做小批量试单**
   - 选采购方最远、最偏、最难送的目标城市做试单，至少覆盖3类：一线城市、普通地级市、县域/偏远地区。
   - 试单要看：实际到达时间、包装完好率、温控记录、损耗率、签收方式。
   - 不要只试一个近处城市，那验不出真实覆盖能力。

4. **核验物流轨迹和签收数据**
   - 要求提供真实发货单号，采购方自己查轨迹，确认始发地、中转站、末端网点。
   - 看是否出现“到不了转寄”“自提点签收”“长时间无轨迹”等情况。
   - 抽查历史订单的签收时效和异常率。

5. **明确异常责任和赔付**
   - 合同里写清：覆盖范围、时效承诺、温控标准、损耗上限、延误/变质/拒收的处理和赔付。
   - 确认偏远地区是否加价、是否保价、是否送货上门。
   - 问清旺季、节假日、天气异常时的运力保障。

6. **实地或视频核验仓储与冷链**
   - 看供应商是否有分仓、冷库、预冷能力、包装标准。
   - 全国配送能力强的供应商通常有多仓或稳定干线，不是单仓发全国。

7. **用第三方信息交叉验证**
   - 查企业工商信息、冷链资质、合作物流合同或授权证明。
   - 向其现有客户（尤其同区域客户）做背景了解。
   - 对“全国配送”宣传，要求书面承诺并写入合同，而不是口头承诺。

**最简可执行结论：**先要目标城市覆盖清单和物流商信息，再对最远/最难送区域做小批量试单，最后把覆盖范围、时效、损耗和赔付写进合同。只提供“合作快递全国可达”的，不能等同于生鲜实际配送能力。
