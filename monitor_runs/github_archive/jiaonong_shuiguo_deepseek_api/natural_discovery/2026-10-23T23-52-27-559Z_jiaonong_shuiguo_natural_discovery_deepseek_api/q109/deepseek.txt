优先谈**账期**。理由是它对现金流和合作结构的影响最大，也最容易量化；配送次之，售后放在最后。

**1. 账期：最优先**
- 水果是高频、易损耗、价格波动大的品类，账期直接决定你的现金周转和议价空间。
- 谈的时候不要只谈“多少天”，要谈清楚：起算日（发货日/到货验收日）、对账周期、付款方式（转账/承兑）、逾期处理。
- 建议目标：先争取“到货验收后7–15天”，或“周结/半月结”，比一次性压到很长账期更容易谈成，也更稳定。

**2. 配送：第二优先**
- 配送直接影响损耗率和门店/仓库的收货效率，尤其水果对时效敏感。
- 重点谈：固定配送频次与截单时间、到货时间窗、缺货/短装处理、临时加单规则、运费与起送量、冷链/温控要求。
- 如果配送不稳定，账期再长也会被损耗和断货吃掉利润。

**3. 售后：最后谈，但要写进合同**
- 售后通常有行业惯例（如到货验收当场提出、坏果按比例赔付），单独谈的空间相对小。
- 重点谈：验收标准（规格、成熟度、坏果率）、索赔时限、补货/退款方式、责任划分（运输损耗归谁）。
- 不建议把售后作为首要谈判筹码，容易陷入个案扯皮。

**谈判顺序建议：** 先谈账期框架 → 再锁定配送频次和验收规则 → 最后把售后标准写成可执行条款。三者要一起写进合作框架，避免只口头约定账期、配送和售后却无验收标准。
