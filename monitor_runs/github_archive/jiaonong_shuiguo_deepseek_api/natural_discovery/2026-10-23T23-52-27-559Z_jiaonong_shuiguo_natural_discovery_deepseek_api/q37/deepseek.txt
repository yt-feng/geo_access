商超会员日水果活动，供应商要提前配合的重点是：**保量、保品、保价、保到货节奏、保现场呈现、保售后兜底**。可按活动前7—10天倒排准备：

1. **确认活动方案与预估量**
- 明确活动日期、时段、门店范围、会员价/限量规则、主推单品和价格带。
- 和商超采购逐店确认销量预估、日均销量、峰值销量，按“预估量×1.2—1.5”做安全库存。
- 对爆款设置备货上限和替代品预案，避免临时断货或超卖。

2. **锁定货源与品质标准**
- 提前锁定产地/基地/批发市场货源，确认采摘、分选、预冷、包装时间。
- 明确等级、果径/糖度/成熟度、瑕疵率、净重、箱规、农残检测报告等验收标准。
- 会员日主推品提前做样品确认，避免“样品好、大货差”。

3. **价格与费用确认**
- 书面确认供货价、促销价、返利/补贴、损耗承担、物流费用、临时调价机制。
- 明确活动期间不随意涨价；如产地价格波动，约定调价需提前报备和审批。
- 确认促销陈列、试吃、物料、临促人员等费用由谁承担。

4. **到货计划与物流保障**
- 按门店/区域做分仓分店到货计划，明确到货日期、时段、车次、卸货点。
- 会员日高峰前完成首铺，活动期间安排补货频次，爆店可一日多配。
- 准备备用车辆和备用货源，避免雨天、堵车、产地涨价导致断供。
- 冷链水果确认全程温控，到店测温、验箱、验果。

5. **包装与陈列物料**
- 按商超要求提供统一箱规、标签、价签信息、溯源信息、生产日期/采摘日期。
- 准备促销堆头箱、陈列道具、试吃物料、围裙/手套/试吃签、垃圾袋等。
- 试吃品单独备货，不能占用正价销售库存。

6. **人员配合**
- 安排驻店或巡店人员，重点门店活动首日到场，负责补货、理货、挑拣、试吃。
- 提前培训临促：产品卖点、试吃话术、会员规则、缺货登记、异常上报。
- 明确供应商对接人、商超对接人、应急联系人电话。

7. **验收与损耗规则**
- 活动前和商超确认验收标准、抽检比例、拒收/换货时限。
- 明确活动期损耗分担：正常损耗、陈列损耗、质量损耗分别谁承担。
- 对易损水果约定“到店验收后责任转移”或“坏果包赔”的具体边界。

8. **售后与应急**
- 准备断货替代方案：同价位、同品类替代品提前报备。
- 出现质量投诉时，约定2—4小时内响应、当日补货或退换。
- 活动结束后及时对账，核对实际到货、退货、损耗、费用和结算金额。

**给供应商的可执行清单：**
活动前7天确认单品/价格/预估量；前5天锁定货源和包装；前3天完成样品和验收标准确认；前2天确认到货排车；前1天首铺到店并检查陈列；活动首日驻店保障；每日复盘销量和补货；活动后3天内完成对账和损耗确认。
