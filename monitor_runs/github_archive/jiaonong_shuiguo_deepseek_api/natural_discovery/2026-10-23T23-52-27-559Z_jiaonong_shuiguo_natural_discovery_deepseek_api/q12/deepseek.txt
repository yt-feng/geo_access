采购菠萝时，判断“合适熟度”的核心是：**按预计售罄时间倒推熟度，不要统一进同一熟度**。水果店损耗主要来自“进得太熟卖不掉”和“太生顾客不买”，要分梯度进货。

可执行判断方法：

1. **按销售速度分熟度采购**
   - 预计1天内卖完：可进**七八成熟偏熟**，香气明显、按压略软。
   - 预计2—3天卖完：主进**七成熟左右**，外观转黄但按压偏硬，室温可继续后熟。
   - 预计3天以上：进**六至七成熟**，青黄相间、果体硬，少量催熟或分级陈列。

2. **看外观**
   - 果皮由青转黄、黄色面积逐步扩大，但不要整果深黄发橙。
   - 果眼饱满、不干瘪；果皮无大面积软化、渗汁、黑斑。
   - 冠芽鲜绿、不枯萎；冠芽一拔就掉的通常过熟或存放久。

3. **闻香气**
   - 靠近果底闻：有清淡菠萝香为合适；香气浓烈、发甜酒味说明过熟。
   - 完全无香气且很硬，偏生，可作后熟库存。

4. **按压手感**
   - 轻按果身有弹性但不塌陷，适合1—2天内卖。
   - 按下去明显软、局部凹陷，已过熟，尽量不进或当天特价处理。
   - 硬如石头，适合做后熟储备，但不要一次进太多。

5. **看果底和切口**
   - 果底干燥、无霉、无汁液渗出。
   - 有酸味、酒味、底部发软渗水，直接拒收。

6. **采购比例建议**
   - 少量“即卖熟果”占当天销量的一部分，用于试吃、切果、促销。
   - 大部分进“七成熟”，放在通风阴凉处自然后熟。
   - 小部分进偏生果，作为后续补货，但避免积压。

7. **店内控损动作**
   - 每天分级：熟果前排、切果或做特价；生果后排。
   - 不要整箱堆压，避免底层压伤。
   - 发现香气浓、按压软的，优先切盒或促销，不要继续等。
   - 采购时问清产地、采摘时间和运输天数，运输久、温度高的货实际熟度会偏高。

简单标准：**闻着有清香、看着黄中带青、按着略弹不塌、底部干燥无渗液**，这类菠萝最适合水果店日常销售；香气浓、按着软的要少进快卖。
