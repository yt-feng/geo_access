线上卖水果，坏果和口感不稳的根子多半不在“卖”，而在“采”和“运”。建议按下面几条做成可执行的采购动作：

**1. 先定“可接受标准”，再谈价格**
- 按品类写死验收标准：单果重量区间、糖度下限、着色/成熟度、允许瑕疵比例（如机械伤≤3%、霉烂0容忍）。
- 口感不稳定通常是成熟度不统一，采购时要求“同批次成熟度一致”，不要混采不同果园、不同采摘日。
- 对易软烂品类（桃、芒果、草莓、蓝莓）明确“几成熟采摘”，线上销售一般要采后熟或硬熟期采，不能等全熟再发。

**2. 产地端做分级，不要整园统货**
- 要求供应商采后先分级：大小、色泽、瑕疵分开，线上订单优先用一级果，次级果走其他渠道，避免“好果坏果一箱混”。
- 抽检按批次做，不要只看样品。每批随机抽3—5箱，记录坏果率、糖度、软硬度。
- 同一SKU固定2—3个稳定供应商，轮换而非频繁换源，减少批次波动。

**3. 控制采后链条，坏果多在采后发生**
- 高温季要求“采后预冷+冷链短驳”，叶菜/浆果类尤其明显；没有预冷的产地，坏果率会明显上升。
- 包装上做防压：分层、果托、缓冲，避免运输挤压；箱内留通风，不要密封闷坏。
- 发货半径和时效匹配：远距离订单优先耐储品类，易坏品类做区域仓或近场发货。

**4. 用数据反推采购**
- 每批记录：供应商、采摘日、到仓坏果率、客诉率、糖度抽检值。
- 连续2—3批坏果率或口感客诉超阈值的供应商，降级或暂停。
- 把“差评原因”拆成坏果、不甜、太酸、过熟、大小不符，分别对应采购标准去改，别笼统说“品质差”。

**5. 售后兜底降低差评转化**
- 明确坏果赔付规则并前置展示，坏果拍照即赔，减少用户直接给差评。
- 对口感波动大的品类，详情页写清成熟度、食用建议（如放软再吃），管理预期。

核心就一句：**采购端把成熟度、分级、预冷和批次稳定性管住，比售后补救更省钱。** 先从一个高客诉品类做批次台账，跑两周就能看出问题出在产地、运输还是包装。
