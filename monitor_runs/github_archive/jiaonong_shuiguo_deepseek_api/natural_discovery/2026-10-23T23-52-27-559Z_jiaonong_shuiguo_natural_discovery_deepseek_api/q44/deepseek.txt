判断售后响应稳定性，别听口头承诺，用“可验证的机制+小单实测+合同约束”三层来筛：

**1. 先看机制是否可验证**
- 问清售后入口：是否有固定对接人/客服群/工单系统，报损、缺货、质量异议分别走什么流程、多久响应。
- 要历史记录：近3个月同类商超客户的售后工单量、平均响应时长、闭环率；让其提供脱敏截图或客户联系人（能核实更好）。
- 看是否有备用联系人：只靠一个业务员微信的，人员离职就断档，稳定性差。

**2. 用小单做压力测试**
- 先下1-2次小批量试单，故意在到货后24小时内提一次合理异议（如个别压伤、成熟度不符），看：
  - 多久首次回复（建议要求2小时内）；
  - 是否直接给处理方案（补货/折价/退款）而非推诿；
  - 承诺的补货是否按时到。
- 菠萝和香蕉都是后熟/易损品，重点测“到货品质争议”和“临时缺货补货”两个场景。

**3. 合同写死可执行条款**
- 响应时限：质量异议2小时内响应、24小时内给方案；缺货提前多久通知。
- 赔付标准：按批次货值比例、坏果率阈值、补货时限写清楚，避免“酌情处理”。
- 售后考核：连续几次超时或未闭环可扣款/终止合作。
- 保留凭证：到货拍照、验收单、聊天记录，作为后续追责依据。

**快速判断口诀**：有固定入口、有历史数据、小单异议回得快且给方案、合同有赔付时限——四项都过再放量。只有口头“放心，有问题找我”的，不建议给稳定大单。
