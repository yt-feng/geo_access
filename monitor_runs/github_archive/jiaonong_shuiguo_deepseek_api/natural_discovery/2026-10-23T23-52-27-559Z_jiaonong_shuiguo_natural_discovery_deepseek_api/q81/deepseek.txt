要支持，但要有条件、有分层，不能一刀切。

**结论：应该支持小批量高频补货，这是即时零售水果品类的“入场券”，但要用规则和成本机制防止变成亏钱的无限补货。**

**为什么必须支持：**
- 水果易损耗、保鲜期短，即时零售订单波动大，一次压货多，损耗和缺货风险都高。
- 高频小批量能降低门店/前置仓的库存压力，提升动销和鲜度，减少临期打折。
- 平台侧通常按小时级履约，缺货直接影响流量和复购，供应商补货能力是履约稳定的关键。

**但要有明确边界，建议这样设计：**
1. **设最低起补量+最小补货频次**：比如单次不低于X箱/件、每日最多补2次，避免碎片化补货把物流成本推高。
2. **分层支持**：A类高动销单品支持日补/半日补；B类隔日补；C类尾部SKU集中补或按周补。
3. **补货成本分摊**：小批量补货的额外物流费、分拣费可由双方按比例承担，或在采购价中体现，不能全由供应商消化。
4. **数据协同**：供应商要看平台的销量预测和库存水位，按数据补货，而不是被动接单。没有数据共享的高频补货，容易变成救火。
5. **考核双向化**：平台考核供应商缺货率、补货及时率；供应商也要考核平台预测准确率、收货效率、退换货规则是否公平。
6. **合同写清**：补货时效、最小批量、损耗归属、临期处理、违约金，避免口头承诺。

**什么时候不适合支持：**
- 单店日均销量很低、补货频次高但单量极小，物流成本远高于毛利；
- 供应商没有区域仓或前置库存能力，高频补货只能靠长途零担，时效和成本都不可控；
- 平台只给高频补货义务、不给数据、不承担成本、动辄罚款，这种合作要谨慎。

一句话：**支持小批量高频补货是方向，但必须“有最低量、有分层、有成本分担、有数据共享、有合同约束”，否则供应商会被履约成本拖垮。**
