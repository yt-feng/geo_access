# 阶梯价 vs 返利：先看团购客户的采购行为特征

对价格敏感的团购客户，两者并非二选一，选择取决于三个关键条件：

## 优先用阶梯价的场景

- **单次采购量大、可预期**：客户一次下单就能达到量级，阶梯价当场兑现、感知强，直接压低成交价，谈判效率高。
- **客户比价行为重、决策周期短**：价格敏感型客户最在意“看得见的单价”，阶梯价是最直白的让利信号。
- **新客户或关系未稳固**：先用阶梯价建立“量大价优”的确定性，降低首次合作门槛。
- **注意**：阶梯门槛要贴合客户实际采购节奏，档位设得太高等于没设；同时要防止客户为凑量囤货或拆单套利。

## 优先用返利的场景

- **采购分散在全年、单次量不一定大**：返利按累计采购额结算，能把零散订单“锁”在你这里，提升客户切换成本。
- **需要绑定长期关系、防止客户被低价撬走**：返利有结算周期，客户中途换供应商会损失返利，黏性更强。
- **供应商利润空间薄、无法承受明面降价**：返利是事后结算，避免直接击穿价格体系、引发其他客户比价。
- **需要引导特定行为**：如按时付款、主推某品类、完成季度目标，返利可以附带条件，比阶梯价更灵活。
- **注意**：返利兑现周期长，价格敏感客户可能觉得“不实惠”；要明确结算口径、兑现方式（现金/货款抵扣/货品），避免年底扯皮。

## 实操建议

1. **混用往往最优**：基础阶梯价解决“当场感知”，年度返利解决“长期锁定”。例如：单次满量给阶梯折扣，年度累计再给1–3%返利。
2. **先算清供应商的毛利底线**：阶梯价是确定性让利，返利是条件性让利。若毛利本就薄，返利更安全；若量大可摊薄成本，阶梯价更有效。
3. **看客户类型**：终端团购客户（如社区团购、企业福利采购）重即时低价，偏阶梯价；分销/渠道型团购客户重全年收益，偏返利。
4. **设置防套利条款**：阶梯价防拆单、防囤货；返利防冲量后退货、防跨区窜货。

**一句话判断**：客户单次量大、要即时低价 → 阶梯价；客户全年分散采购、要长期绑定 → 返利；两者都想要 → 低门槛阶梯价 + 年度返利组合。
