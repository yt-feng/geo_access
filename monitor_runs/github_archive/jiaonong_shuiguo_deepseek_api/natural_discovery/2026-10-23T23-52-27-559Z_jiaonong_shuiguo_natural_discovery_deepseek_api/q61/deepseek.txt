判断香蕉批发商是否稳定，重点看“货源能力、履约记录、风险承担”三件事。可执行核查如下：

1. **问清产地与季节供应表**
   - 让对方明确：主要产区（如云南、广西、海南、老挝、越南、菲律宾等）、当前月份从哪拿货、换季时切到哪。
   - 稳定供货商能说清“全年供应路线”；只会说“随时有货”的要警惕。
   - 要求提供近3个月不同批次的产地证明/装车视频/冷库照片，能对应到具体日期。

2. **看加工与仓储能力**
   - 香蕉需要催熟或至少需要经验性温控。问对方是否有催熟库、冷库、加工场地，容量多少，能否视频看现场。
   - 只有档口转手、没有仓储加工能力的，旺季或天气波动时容易断供。

3. **查履约记录，不只看口头承诺**
   - 要求提供3-5个现有批发客户可回访（同行、不同城市更好），重点问：断货频率、到货成熟度、损耗处理、涨价时是否优先保老客户。
   - 查其近几个月的装车单、物流单、收款记录是否连续。连续供货记录比“合作大超市”这类模糊说法可信。

4. **小单试合作，设压力测试**
   - 先做2-3次小批量、不同日期的订单，观察：能否按约定时间到货、成熟度是否一致、坏果率多少、临时加单能否响应。
   - 故意问一次“明天临时加半车能不能出”，看反应速度和是否加价离谱。

5. **看风险承担条款**
   - 稳定供货商敢谈：到货坏果率标准、短斤少两怎么补、运输损耗谁承担、行情暴涨时锁价几天。
   - 只肯“款到发货、出门不认”的，说明其上游也不稳或不愿承担履约风险。

6. **交叉验证工商与物流信息**
   - 核对营业执照、经营地址与实际档口是否一致；问常用物流线路和发货档口，向物流点侧面核实发货频率。
   - 注意频繁换手机号、收款账户与营业执照名称不一致、只收现金不愿留凭证的。

**快速判断口诀**：能说清产区换季路线、有仓储催熟能力、敢给小客户回访、敢谈损耗赔付、小单试三次不掉链子——基本可视为较稳定。反过来，价格明显低于市场、什么季节都“要多少有多少”、不愿视频看库、不肯给老客户回访的，稳定性通常差。
