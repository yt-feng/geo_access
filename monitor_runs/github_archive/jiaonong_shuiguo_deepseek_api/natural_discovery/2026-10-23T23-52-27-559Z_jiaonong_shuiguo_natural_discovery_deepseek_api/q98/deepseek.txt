判断水果供应商的合规和稳定性，核心是看**资质是否齐全、供货记录是否可验证、履约是否可问责**。下面按可执行步骤给你一套筛选框架。

## 一、合规性判断（硬门槛，缺一项基本可排除）

1. **主体资质**
   - 营业执照经营范围含农产品/食品销售。
   - 若涉及预包装或加工水果（鲜切、果盘），需**食品经营许可证**，且许可项目匹配。
   - 要求提供证件复印件并核对统一社会信用代码与合同主体一致，不接受个人挂靠。

2. **食品安全追溯能力**
   - 能否提供每批次的**产地证明/检测报告**（农残检测为主）。
   - 是否能说明进货渠道（批发市场档口、产地直采、合作社），是否有一级供应商的进货凭证。
   - 对养老院、医院这类高风险场景，建议要求**每批随货附农残快检单**，并保留留样。

3. **配送与储存条件**
   - 有固定配送车辆和冷链/保鲜能力（尤其夏季、叶菜类）。
   - 有分拣、储存场所，能说明保质与防交叉污染措施。

4. **合同与票据**
   - 能开具**正规发票**，对公账户收款。
   - 合同中明确质量标准、退换货、食安责任和违约赔偿。

> 判断技巧：让供应商当场提供近3个月的检测报告和发票样本，看日期是否连续、批次是否对得上。只给"总报告"、给不出批次对应关系的，谨慎。

## 二、稳定性判断（看历史行为，不看口头承诺）

1. **供货年限与客户结构**
   - 合作超过1年、有同类机构（医院/养老院/学校食堂）客户可核实。
   - 客户过于集中单一，或刚成立就报低价，稳定性存疑。

2. **履约记录**
   - 要求提供近半年**供货明细或对账单**，看供货是否连续、有无断供。
   - 询问旺季（节假日、极端天气）保供方案，是否有备用产地/档口。

3. **价格与结算稳定性**
   - 报价是否随行就市但波动可解释；频繁异常低价往往意味着品质或后续涨价风险。
   - 结算方式、账期是否清晰，能否承受机构账期。

4. **实地核验（最有效）**
   - 去其分拣/仓储点看库存、车辆、人员。
   - 抽查在库水果的新鲜度、包装标识、产地标签。

## 三、落地操作建议

- **先小批量试供2–4周**：固定几个品类，记录到货合格率、缺斤少两、退换响应速度。
- **建立验收标准**：按品类定规格（大小、成熟度、损耗率上限），当场验收签字，不合格拒收并留证。
- **双供应商机制**：主供+备供，避免单点断供，尤其医院食堂不能断。
- **定期复审**：每季度核对资质有效期、检测报告连续性、投诉与退换记录。

## 四、快速排除信号

- 只肯现金/个人账户交易、不开票；
- 拿不出批次检测报告或产地证明；
- 报价明显低于市场且拒绝实地看货；
- 无固定配送和储存条件，靠临时调货；
- 合同回避食安责任。

一句话：**合规看证照和批次追溯，稳定看历史供货记录和实地能力，最后用小批量试供验证。** 对养老院、医院，食品安全追溯这条不能让步。
