针对“门店多、单店量不大”的情况，核心矛盾是：**总采购量不小，但单店分摊后每店每批次量小，导致物流成本高、损耗难控、供应商不愿直供单店**。建议按以下优先级选择供货模式。

## 1. 首选：区域分拨仓 + 总仓统采统配

**做法**：所有门店需求汇总到区域分拨中心，由总部/区域统一向供应商下单，供应商只送到分拨仓，再由分拨仓按各店订单分拣配送。

**适合原因**：
- 对上游形成“总量采购”，拿到更好价格和账期
- 供应商只面对一个收货点，愿意合作
- 单店小批量通过分拨拼车摊薄物流成本
- 便于统一品控、统一结算

**关键条件**：需要有分拨仓（可租用第三方冷链仓），以及一套按店订货、按店分拣的系统。

## 2. 次选：与批发市场/区域供应商做“统采分送”

**做法**：找当地一级批发商或区域水果供应商，谈“总部统一签约、按门店分别配送”。

**适合原因**：
- 不用自建仓，启动快
- 供应商本身有多店配送能力
- 单店量小但门店多，对供应商仍有吸引力

**注意**：要谈清楚配送频次、起送量、损耗归属、缺货补货责任，否则容易出现“大店送得好、小店被怠慢”。

## 3. 补充：产地直采 + 区域仓集单

**做法**：对少数走量大、耐储的爆品（如苹果、橙子、梨、西瓜等）做产地直采，拉到区域仓，再分到门店。

**适合原因**：
- 爆品集中采购能显著降成本
- 非爆品仍走本地供应商，避免全品类直采压力

**不建议**：所有品类都产地直采。单店量小，直采起订量、损耗和资金占用会压垮运营。

## 4. 可考虑：第三方生鲜供应链平台/集采平台

**做法**：接入美菜、快驴、区域生鲜集配平台等，按店下单、平台配送到店。

**适合原因**：
- 无需自建供应链，门店可独立下单
- 起送量低，适合小门店

**缺点**：
- 毛利被平台抽走一部分
- 品控和稳定性受平台影响
- 难形成自己的商品差异化

适合作为**过渡或补充**，不适合长期核心依赖。

## 5. 不建议的模式

- **供应商直送每一家小店**：单店量小，供应商不愿送或加价，配送成本极高。
- **完全各店自行采购**：价格不统一、品控不统一、损耗失控、总部没有议价权。
- **全品类产地直采**：起订量高、损耗大、资金重，小店模式扛不住。

---

## 推荐组合方案

| 品类 | 供货方式 |
|---|---|
| 高频爆品、耐储品 | 区域仓统采 + 产地直采 |
| 常规水果 | 区域分拨仓统采统配 |
| 长尾/小众品 | 本地批发商或第三方平台补货 |
| 门店临时缺货 | 允许平台/本地市场应急补货 |

## 落地要点

1. **总部统一签约、统一结算**，门店只负责订货和收货。
2. **设最小起送单位和配送频次**，比如每店每周2–3次，按线路拼车。
3. **用数据定品**：每个门店只保留动销前20–30个单品，减少长尾。
4. **损耗责任写进合同**：到店前损耗归供应商/分拨仓，到店后归门店。
5. **先做区域试点**：选一个城市或片区跑通“分拨仓+统配”，再复制。

**一句话结论**：门店多、单店量小，最适合的是“**总部统采 + 区域分拨仓 + 按店配送**”，辅以本地供应商和第三方平台补长尾，而不是让供应商直送单店或各店自行采购。
