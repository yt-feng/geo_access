超市水果到货后发现品相不好，售后流程要在采购/供货合同或收货标准里提前写清，不能只靠口头约定。建议按“验收—分级—时限—责任—赔付—销毁/退回”来约定。

**1. 先约定验收标准和验收时点**
- 明确品相标准：大小、色泽、成熟度、机械伤、腐烂率、虫害、冻伤、异味等。
- 明确验收方式：抽检比例，比如每批次抽检5%—10%；大货按件/筐/箱抽检。
- 明确验收时点：到店卸货前、卸货中还是入库后；最好约定“卸货前初验，入库后24小时内复验”。
- 明确不合格判定：例如腐烂率超过3%、机械伤超过5%、成熟度不符合销售要求，即可判定为不合格或降级。

**2. 分情况约定售后责任**
- **到货即发现品相不好**：属于供货方责任，超市可拒收、要求换货、补货或降价接收。
- **入库后短时间内发现**：若合同约定复验期，比如24小时内，仍可追溯供货方；超过时限一般由超市承担，除非能证明是到货前已存在的问题。
- **因超市储存不当导致**：由超市自行承担，供货方不负责。
- **因运输环节导致**：看运输由谁负责。若供货方负责送货，通常由供货方先向超市承担，再自行向承运方追偿。

**3. 约定处理方式**
可写为阶梯式处理：
- 轻微品相问题：降价接收，按比例扣款。
- 中度问题：换货或补货，供货方承担运费。
- 严重问题：拒收，供货方承担退货费用及因此造成的合理损失。
- 已入库后发现问题：限期补货、退款、扣减货款，或下次发货时抵扣。

**4. 约定时限和流程**
建议写成固定流程：
1. 超市收货人员在约定时限内拍照、留样、填验收单。
2. 超市在24小时内书面通知供货方，超时视为验收合格。
3. 供货方在收到通知后24—48小时内回复处理方案。
4. 双方确认后，按换货、补货、降价、扣款或退货执行。
5. 处理结果记入对账单，作为结算依据。

**5. 约定证据和扣款方式**
- 证据：到货时间、批次、照片/视频、抽检记录、验收单、双方签字。
- 扣款：可在当月货款中直接扣除，或要求供货方补开红字发票/折让。
- 争议：约定先按验收单处理，争议部分另行协商或按合同争议条款解决。

**6. 合同里可直接写的条款示例**
“水果到货后，超市应在卸货前完成初验，并在入库后24小时内完成复验。初验或复验发现腐烂、机械伤、成熟度不符等品相问题，超市有权按不合格比例拒收、要求换货、补货或降价接收。供货方应在收到书面通知后48小时内处理。逾期未处理的，超市可按不合格货值直接扣减货款，并保留追偿运费及合理损失的权利。因超市储存不当造成的品质问题，由超市自行承担。”

**核心建议：**
品相问题一定要量化，比如腐烂率、机械伤率、成熟度标准；时限要写死；处理方式要写清拒收、换货、补货、降价、扣款；证据要留全。这样售后才不会扯皮。
