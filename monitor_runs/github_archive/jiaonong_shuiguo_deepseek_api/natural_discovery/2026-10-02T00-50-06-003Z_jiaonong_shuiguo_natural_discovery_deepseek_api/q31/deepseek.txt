连锁商超找长期水果供应商，招标评分标准的核心逻辑是：**不要只比价格，而是比“长期稳定交付能力”**。水果是非标、易损耗、强季节性的品类，一次报价低但断供、品质波动大，后续损失远高于采购差价。

下面给一套可直接落地的评分框架，按100分制，采购方可根据自身规模调整权重。

## 一、总体权重建议（100分）

| 维度 | 建议权重 | 说明 |
|---|---|---|
| 价格与成本 | 25–35分 | 不能过高，否则失去招标意义 |
| 品质与标准化能力 | 20–25分 | 长期合作的核心 |
| 供应保障与履约能力 | 15–20分 | 防断供 |
| 供应链与冷链能力 | 10–15分 | 决定损耗率 |
| 企业资质与财务健康 | 8–12分 | 防合作中途暴雷 |
| 服务与响应 | 5–10分 | 日常配合度 |
| 可持续/合规/ESG | 3–8分 | 视商超定位 |

## 二、各维度具体评分项

### 1. 价格与成本（25–35分）
- **报价竞争力**：以有效报价的加权平均价或最低价为基准，越接近基准分越高，避免“恶意低价”直接满分。
- **价格调整机制**：是否接受随行就市、按周/月联动批发市场指数调价，而不是锁死一口价。愿意接受合理调价机制的反而加分。
- **账期接受度**：能接受商超账期（如30/60天）或提供账期弹性。
- **附加成本透明度**：运费、损耗、退换货责任是否清晰，无隐藏费用。

> 关键：设**价格下限保护**，报价明显低于成本的要能解释，否则可能后期以次充好或断供。

### 2. 品质与标准化能力（20–25分）
- **分级标准**：能否按商超要求做果径、糖度、色泽、成熟度分级。
- **质检与检测**：是否有农残检测、自有质检流程、批次可追溯。
- **样品与试供**：招标阶段要求送样+小批量试供，按实际表现打分。
- **损耗控制承诺**：承诺到货合格率、损耗率上限。
- **包装标准化**：是否支持商超要求的周转筐、托盘、标签规范。

### 3. 供应保障与履约能力（15–20分）
- **自有基地/稳定货源**：自有种植基地或长期合作农户比例。
- **多产地布局**：能否跨产区调配，避免单一产区受灾断供。
- **反季节供应能力**：能否全年稳定供货。
- **历史履约记录**：过去合作客户的准时交付率、断供次数。
- **产能匹配**：其供应量是否覆盖商超需求，且不过度依赖单一客户。

### 4. 供应链与冷链能力（10–15分）
- **冷链覆盖率**：采摘后预冷、冷藏运输、到店温控。
- **仓储能力**：是否有分拣中心、气调库。
- **物流时效**：从产地到门店的时间，是否支持日配/隔日配。
- **信息化**：能否对接商超系统，提供批次、库存、物流数据。

### 5. 企业资质与财务健康（8–12分）
- 营业执照、食品经营许可、种植/养殖相关资质。
- 近两年财务报表或纳税、社保记录，判断是否稳健。
- 有无重大食品安全事故、行政处罚、诉讼。
- 保险：产品责任险、货物运输险。

### 6. 服务与响应（5–10分）
- 售后处理时效：质量问题响应、退换货速度。
- 专属对接人/客服团队。
- 配合促销、临时加单、新品试销的意愿。

### 7. 可持续/合规/ESG（3–8分）
- 绿色种植、有机认证、GAP等。
- 劳工合规、环保合规。
- 对商超ESG报告的支持能力。

## 三、评分表落地建议

1. **资格预审先卡硬门槛**：资质不全、无冷链、无稳定货源的直接淘汰，不进入打分。
2. **技术分与价格分分开**：先评技术（品质、供应、冷链等），技术不达标的低价也不采纳。
3. **设置试供期**：中标不等于长期锁定，先签3–6个月试供，按KPI考核再转长期合同。
4. **KPI写入合同**：到货合格率、损耗率、准时率、断供罚则、质量事故赔偿。
5. **避免唯低价**：可设“价格分不超过35分”，防止劣币驱逐良币。

## 四、一句话总结

长期水果供应商招标，评分标准要围绕 **“稳、质、链、价”** 四个字：供应稳定、品质可控、冷链完整、价格合理。价格权重控制在三分之一左右，把更多分数留给品质和履约能力，才能选到能长期合作的供应商。
