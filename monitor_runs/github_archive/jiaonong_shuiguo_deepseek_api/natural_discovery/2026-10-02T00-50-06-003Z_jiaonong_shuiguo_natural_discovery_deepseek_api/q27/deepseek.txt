判断苹果和橙子的规格是否适合门店销售，核心是看**分级标准、目标客群、陈列方式和损耗控制**。可以按下面这套方法直接操作。

## 一、先明确门店定位

不同门店对“合适规格”的要求不同：

- **社区生鲜店/便利店**：偏好中等个头，方便按个卖，顾客一次买 2～4 个。
- **精品超市/高端店**：偏好大果、外观整齐，适合礼盒或高价散卖。
- **水果专营店/批发型门店**：规格可以更宽，但要求分级清楚，避免混装。
- **线上到家/社区团购**：更看重单果重量稳定、标准化，减少客诉。

所以第一步不是问“多大最好”，而是问：**卖给谁、怎么卖、按斤还是按个、是否做礼盒。**

## 二、苹果怎么判断规格

苹果通常按**横径**分级，单位是毫米，不是单看重量。

常见参考：

- **小果**：60～65mm，适合低价促销、儿童果、切果。
- **中果**：70～75mm，最适合作门店日常散卖，接受度高。
- **大果**：80～85mm，适合精品陈列、按个卖、礼盒。
- **特大果**：90mm 以上，适合高端礼盒，但门店日常动销可能偏慢。

判断要点：

1. **看横径是否均匀**：同一批货大小差最好控制在 5mm 以内。
2. **看果形和色泽**：大小达标但畸形、色差大，也不适合精品陈列。
3. **看硬度与新鲜度**：规格再合适，发绵、失水也不适合门店销售。
4. **看包装标识**：供应商应标明品种、产地、横径范围、净重、等级。
5. **试摆试卖**：按 70～75mm 和 80～85mm 分开陈列，观察 3～7 天动销和损耗。

门店日常建议：

- 散卖主推 **70～80mm**。
- 按个卖可考虑 **80～85mm**。
- 礼盒用 **85mm 以上**，但不要大量压货。

## 三、橙子怎么判断规格

橙子也常按**横径**分级，但不同品种差异大，比如脐橙、血橙、砂糖橘、沃柑不能同一标准。

常见参考，以脐橙/普通甜橙为例：

- **小果**：60～65mm，适合榨汁、促销。
- **中果**：65～75mm，适合日常散卖，顾客接受度高。
- **大果**：75～85mm，适合按个卖、礼盒。
- **特大果**：85mm 以上，外观好但皮可能偏厚，需试吃判断。

判断要点：

1. **看横径范围**：同一陈列区尽量统一在 5～10mm 区间内。
2. **看皮厚和可食率**：大果不一定好，皮太厚会影响复购。
3. **看水分和糖酸比**：规格合适但口感差，不适合长期主推。
4. **看是否易剥、易分瓣**：影响顾客体验，尤其社区店。
5. **看损耗**：橙子若压伤、油胞破损，损耗会很快上升。

门店日常建议：

- 散卖主推 **65～75mm**。
- 按个卖可考虑 **75～80mm**。
- 榨汁区可用 **60～65mm** 或外观略差但口感正常的果。
- 礼盒用 **75～85mm**，要求大小一致、颜色统一。

## 四、直接可用的验收判断表

采购时可以用这张表快速判断：

| 项目 | 苹果 | 橙子 | 门店判断 |
|---|---|---|---|
| 规格单位 | 横径 mm | 横径 mm | 必须标明范围 |
| 均匀度 | 同批差≤5mm | 同批差≤5～10mm | 差太大不适合精品陈列 |
| 主销规格 | 70～80mm | 65～75mm | 适合社区/日常散卖 |
| 按个卖 | 80～85mm | 75～80mm | 需看门店客群 |
| 礼盒 | 85mm 以上 | 75～85mm | 要求外观整齐 |
| 低价促销 | 60～65mm | 60～65mm | 可用于引流或榨汁 |
| 关键风险 | 发绵、色差、畸形 | 皮厚、干水、压伤 | 规格达标也要看品质 |

## 五、最实用的采购决策方法

1. **先定销售方式**：按斤卖、按个卖、礼盒卖，规格要求不同。
2. **要求供应商分级**：不要混装，至少分中果、大果两档。
3. **小批量试销**：每个规格先拿 1～2 箱，摆 3～7 天看动销。
4. **看三个数据**：日均销量、损耗率、顾客投诉。
5. **再放大采购**：动销快、损耗低、投诉少的规格，才是适合门店的规格。

简单结论：

- **社区店日常散卖**：苹果选 70～80mm，橙子选 65～75mm。
- **按个卖或精品陈列**：苹果选 80～85mm，橙子选 75～80mm。
- **礼盒**：苹果 85mm 以上，橙子 75～85mm，且必须大小颜色整齐。
- **促销/榨汁**：苹果 60～65mm，橙子 60～65mm，但口感不能差。

最终不要只看规格数字，要结合**目标客群、陈列方式、试销动销和损耗**一起判断。
