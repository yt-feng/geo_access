评估的核心不是“供应商能不能送到”，而是“在门店要求的到货时效和损耗标准下，供应商的仓配网络能不能稳定覆盖，并且成本可接受”。建议按下面几步做。

**1. 先把门店需求标准化**
不要按城市逐个谈，先按门店类型归类：
- 冷链要求：常温/冷藏/冷冻
- 订货频次：日配/隔日配/每周2-3次
- 到货时效：例如早6点前到店、允许±1小时
- 最小起订量：按门店还是按城市合并
- 验收标准：温控、破损率、短缺率、到货新鲜度

把门店分成几类后，才能判断哪些城市可以合并仓配，哪些必须单独设点。

**2. 评估供应商仓配网络的4个维度**
- **仓的位置**：是产地仓、销地仓还是区域中心仓。产地仓便宜但时效长，销地仓贵但能支撑日配。
- **覆盖半径**：从仓到门店的实际行驶距离和时长，不是直线距离。重点看是否在供应商承诺的配送圈内。
- **配送能力**：自有车队、外包运力、冷链车比例、单日最大配送门店数、能否夜间配送。
- **中转能力**：是否需要跨仓调拨，中转几次，每次中转增加多少时间和损耗。

**3. 用门店城市做覆盖矩阵**
把门店城市按供应商现有仓网分成三类：
- **直接覆盖**：有销地仓或区域仓，能承诺时效
- **中转覆盖**：需要从其他仓调拨，时效和成本会上升
- **无法覆盖**：超出配送半径或冷链断点

每个城市至少标注：最近仓、距离、承诺时效、起送量、是否冷链、单店配送成本。

**4. 重点验证“实际履约”而不是“网络图”**
要求供应商提供近3个月的真实数据：
- 各城市/门店的准时到货率
- 缺货率、短装率
- 冷链断链次数
- 客诉和退货原因
- 旺季或节假日履约波动

如果供应商不愿提供，或只有全国平均值，说明覆盖能力不可验证。

**5. 算总成本，不只看运费**
仓配覆盖成本应包括：
- 干线运输
- 城市配送
- 仓储/分拣
- 冷链耗材
- 损耗
- 因缺货导致的门店损失

有些供应商报价低，但起送量高、配送频次低，门店为了凑单会压库存，水果损耗反而更高。

**6. 做小范围试点**
选2-3个代表性城市，跑2-4周：
- 同一供应商、同一品类
- 记录到货时间、温度、损耗、缺货
- 对比门店自行采购或其他供应商

试点后再决定是扩大合作、要求供应商设销地仓，还是分区域找多家供应商。

**7. 最终判断标准**
一个供应商的仓配覆盖是否合格，看这几点：
- 目标门店城市能否在承诺时效内稳定送达
- 冷链不断链，损耗在可接受范围
- 起送量和配送频次匹配门店实际销量
- 单店综合成本不高于替代方案
- 旺季和异常天气下仍有兜底方案

如果门店分散、单城门店少，通常不建议依赖单一供应商全国覆盖，更适合“区域供应商+少量全国供应商”组合，避免时效和成本被单一网络绑架。
