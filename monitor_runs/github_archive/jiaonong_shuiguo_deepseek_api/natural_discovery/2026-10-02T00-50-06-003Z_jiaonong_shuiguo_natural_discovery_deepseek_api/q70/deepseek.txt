批发商要控制“货到损耗高”的风险，合同里不能只写“坏果由卖方负责”这种笼统表述，否则出了事很难追责。建议从以下几条写：

**1. 先定义“坏果/损耗”标准**
写清楚什么算坏果，例如：
- 腐烂、发霉、软烂、渗汁；
- 裂口、压伤面积超过一定比例；
- 冻伤、日灼、病虫害；
- 规格不符、成熟度不符也可视为不合格。

**2. 约定验收时间和地点**
- 到货后多少小时内完成验收，比如“卸货后4小时内”；
- 在卸货现场或指定冷库验收；
- 过期未提异议是否视为合格，要谨慎，批发商最好保留合理验收期。

**3. 约定损耗比例和扣款方式**
常见写法：
- 自然损耗不超过X%，超过部分由卖方承担；
- 坏果率≤3%按合格，超过3%部分按实扣款；
- 坏果率超过10%，买方有权拒收或要求退货；
- 扣款金额=不合格数量×单价，或按整批货款比例扣减。

**4. 写明责任归属和举证**
- 装车前坏果由卖方负责；
- 运输途中因冷链、挤压、延误造成的坏果，按承运责任或卖方责任约定；
- 到货后买方应及时拍照、录像、留存过磅单和验收记录；
- 双方对坏果有争议时，可约定第三方检测或共同复检。

**5. 约定处理方式和赔偿**
- 卖方补货、换货、退款、折价；
- 因坏果导致买方被下游索赔的，卖方是否承担；
- 运费、冷藏费、分拣费由谁承担；
- 严重违约可解除合同并索赔。

**6. 写清例外情况**
- 买方卸货后保管不当造成的损耗；
- 不可抗力；
- 买方指定运输或冷链方式导致的损耗。

**可直接参考的条款表述：**
“以卸货后4小时内双方共同验收结果为准。坏果包括腐烂、霉变、严重压伤、冻伤及不符合约定规格的果实。坏果率在3%以内视为合格；超过3%的部分，卖方按不合格数量×单价向买方退款或折价；坏果率超过10%，买方有权拒收整批货物，卖方承担退货、运费及冷藏费。买方应在验收期内拍照、过磅并书面通知卖方，逾期未通知视为验收合格，但隐蔽瑕疵除外。”

**关键点：**
不要只写“坏果包赔”，要写清**定义、验收时限、损耗比例、扣款公式、拒收条件、举证方式**。这样货到后损耗高，批发商才有依据扣款、退货或索赔。
