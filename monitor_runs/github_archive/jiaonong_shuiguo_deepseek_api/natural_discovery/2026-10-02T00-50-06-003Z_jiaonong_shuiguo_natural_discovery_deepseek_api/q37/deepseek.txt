商超做会员日水果活动，供应商需要提前配合的准备，核心是**保供、保价、保品质、保陈列、保履约**。可以按下面几项执行：

1. **确认活动商品和价格**
   - 提前确认活动单品、规格、等级、包装形式、活动价、供货价、毛利率。
   - 明确是否限购、限量、分时段上架，避免门店超卖或供应商超发。
   - 对爆款水果提前锁量锁价，防止活动前批发市场价格波动导致断供或临时涨价。

2. **提前备货并锁定产能**
   - 按商超预估销量、历史同期销量、门店数、活动天数，提前 7～15 天备货。
   - 对易缺货单品如车厘子、榴莲、阳光玫瑰、蓝莓等，提前锁定产地或一级批发货源。
   - 预留 10%～20% 安全库存，用于补货和损耗替换。

3. **分拣加工和标准化**
   - 提前完成分级、称重、装盒、贴标、封箱。
   - 统一规格，例如按粒、按盒、按斤、按份，避免门店二次分拣压力。
   - 标签需含品名、规格、产地、日期、保质期、储存条件、条码或门店要求信息。

4. **质量控制和质检报告**
   - 提前提供农残检测、产地证明、检疫证明等商超要求文件。
   - 活动前做抽检，剔除次果、伤果、烂果、大小不均果。
   - 明确到店验收标准：糖度、硬度、颜色、成熟度、单果重、允许损耗率。

5. **物流配送和到店时效**
   - 按商超要求提前排车，确认到店时间、卸货口、预约规则。
   - 易损水果如草莓、葡萄、水蜜桃，需加固包装、控温运输。
   - 活动首日建议提前 1～2 天到店，避免当天集中到货造成拥堵。
   - 对门店补货设置应急响应，例如上午下单、下午或次日达。

6. **陈列和物料配合**
   - 提供堆头、端架、冷柜陈列建议，包括陈列量、翻堆频率、先进先出。
   - 配合提供试吃果、促销牌、爆炸贴、价格牌、产地故事卡等物料。
   - 安排促销员或理货员驻场，负责补货、挑拣、试吃、叫卖。

7. **损耗和退换货约定**
   - 提前书面确认损耗承担比例、退换货标准、临期或变质处理方式。
   - 对高损耗水果，建议约定门店验收后责任划分，避免活动后扯皮。
   - 准备替换货预案，某单品质量不达标时可快速换品或补货。

8. **人员和沟通机制**
   - 供应商指定活动对接人，商超采购、门店生鲜主管、物流三方建群。
   - 活动前开一次对接会，确认销量目标、补货节奏、突发处理流程。
   - 活动期间每天反馈销售、库存、损耗、缺货情况，及时调整。

9. **促销和价格保护**
   - 确认活动价是否低于日常供货价，差额由谁承担。
   - 若商超要求“全网最低价”或比价，供应商需提前评估能否承接。
   - 避免活动期间其他渠道低价冲击，导致商超投诉或扣款。

10. **结算和票据准备**
   - 提前确认开票信息、税率、账期、对账周期。
   - 活动结束后及时核对送货单、验收单、退货单，避免结算差异。

简单说，供应商要在活动前做到：**货已备、价已锁、质已检、标已贴、车已排、人已到、损耗已谈、补货已通**。其中最关键的是前三项：**爆款锁量、活动价确认、到店时效**。这三项没做好，会员日水果活动很容易出现断货、品质差或门店亏损。
