想买到“到家正好能吃、还能放几天”的香蕉，关键不是看颜色一个指标，而是按**用途 + 颜色 + 手感 + 季节/存放**一起判断。给你一套到店就能用的方法：

## 1. 先决定你买回去什么时候吃
- **1～2天内吃**：买已经黄、带少量褐斑的。
- **3～5天内吃**：买通体黄、但斑点很少的。
- **想放一周左右**：买黄中带绿、两端还略青的。
- **想放更久**：买偏绿、硬一点的，回家分开放。

一句话：**越绿越耐放，越黄越接近可吃，褐斑越多越要马上吃。**

## 2. 到店看颜色
- **全绿/硬**：太生，通常还要几天。
- **绿黄相间**：适合想放几天的人。
- **通体黄、无斑**：适合2～4天内吃。
- **黄带少量褐斑**：最适合马上吃，甜度高。
- **大面积褐斑/发黑**：已经过熟，除非当天做香蕉蛋糕/奶昔，否则别买。

## 3. 再捏手感
轻轻捏香蕉中部：
- **硬得像木头**：太生。
- **略有弹性、不软塌**：刚好。
- **一捏就陷、局部发软**：过熟或碰伤。
- **表皮发亮、发黏**：可能已经坏了。

## 4. 看蒂和两端
- **蒂部青绿**：通常较生。
- **蒂部转黄/略干**：成熟中。
- **蒂部发黑、果柄干枯**：偏熟，放不久。
- **两端发黑但果身还硬**：可能是冷伤或存放问题，慎买。

## 5. 按季节调整
- **夏天**：香蕉熟得快，买比目标成熟度**生一点**。
- **冬天/空调房**：熟得慢，可以买**黄一点**的。
- **如果超市冷柜附近摆放**：香蕉容易冷伤，表皮发黑但里面硬，别买。

## 6. 买回家怎么放，决定你“到店判断”是否有效
- **想催熟**：和苹果/梨一起放纸袋里，室温。
- **想慢熟**：分开挂起来，别挤在一起。
- **已经黄了**：室温放1～2天，吃不完再冷藏。
- **冷藏注意**：香蕉皮会变黑，但果肉还能吃；别一买回来就冷藏，会停止成熟。
- **别放塑料袋闷着**：容易捂坏。

## 7. 最稳的采购策略
如果你不是当天吃：
- **买一串“黄中带绿”的**，再单独买**1～2根“黄带斑”的**。
- 这样今天有得吃，后面几天也能接着熟。

## 快速判断口诀
**全绿太生，全黄正好，带斑快吃，发黑别买；想放久买绿黄，想马上吃买黄斑。**
