建议先要“能证明批次合规 + 能追溯到来源”的资料，不要只要一张营业执照。可按下面清单向供应商索取，并要求与本次到货批次对应：

1. **批次对应的检测报告**
   - 优先要：农残检测报告，项目至少覆盖有机磷、氨基甲酸酯、拟除虫菊酯等常见农残，最好有禁用农药项目。
   - 报告上要能对应：品名、产地、供应商/生产商、检测日期、报告编号。
   - 关键：**最好是本批次或近期批次的报告**，不是一年前的通用报告。

2. **产地证明或采购来源证明**
   - 产地证明、基地证明、合作社证明、收购凭证等。
   - 用于确认水果实际来自哪里，出了问题能追溯。

3. **供应商资质**
   - 营业执照。
   - 食品经营许可证，或食用农产品销售相关资质。
   - 如果是进口水果：入境货物检验检疫证明、报关单等。

4. **承诺书/质量保证协议**
   - 供应商承诺所供水果符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》。
   - 约定：若抽检不合格，供应商承担退货、赔偿、监管处罚等相关责任。

5. **快速检测或自检记录**
   - 如果有，要求提供供应商自检记录或第三方快检记录。
   - 超市也可自己抽样做农残快检，作为入场把关。

6. **追溯信息**
   - 批次号、采摘日期、包装日期、发货日期。
   - 最好能做到“一批一码”或至少台账可对应。

**实操建议：**
- 对新供应商：先审资质和检测能力，再小批量试供。
- 对老供应商：也要按批次抽要检测报告，不能长期免检。
- 合同里写清楚：**每批次随货提供检测报告或合格证明；无法提供的，超市有权拒收或加强抽检。**
- 如果供应商只能提供“合格证”但没有检测数据，风险较高，建议自己送检或快检。

一句话：**要“批次检测报告 + 产地来源 + 资质证照 + 质量承诺”，并且能对上这次到货批次。**
