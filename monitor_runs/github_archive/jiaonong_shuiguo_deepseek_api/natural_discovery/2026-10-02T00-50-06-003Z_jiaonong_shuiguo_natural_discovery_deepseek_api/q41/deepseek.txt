判断商超采购香蕉时催熟能力是否稳定，核心不是看单次结果，而是看**到货一致性、催熟后表现、批次波动和可追溯性**。可以从下面几个可执行维度判断。

## 1. 看香蕉到货时的“基础成熟度”是否一致

催熟稳不稳定，首先取决于原料蕉是否稳定。

采购时要重点看：

- **颜色一致**：同一批香蕉到货时，青色/微黄比例是否接近，不能有的还很青、有的已经转黄。
- **饱满度一致**：蕉指粗细、弯曲度、棱角程度是否接近。太瘦、棱角明显的通常成熟慢且不均匀。
- **硬度一致**：用手轻捏蕉身，整批硬度是否接近，不能软硬混杂。
- **蕉轴状态**：蕉轴是否新鲜、无发黑、无霉变、无严重失水。
- **切口/伤口**：有无机械伤、压伤、擦伤。伤口多的批次催熟后容易黑斑、软烂、不一致。

如果一批货本身成熟度差异大，再好的催熟库也很难做到稳定。

## 2. 要求供应商提供稳定的“催熟窗口”数据

不要只问“能不能催熟”，要问具体指标：

- 到货时**硬度**大概多少；
- 建议催熟温度、湿度、乙烯浓度、时长；
- 催熟后第几天达到可售黄度；
- 货架期能维持几天；
- 不同季节到货的催熟参数是否调整。

稳定供应商通常能说清楚：
**到货状态 → 催熟参数 → 出货颜色 → 货架期** 这一整条链路。

如果对方只会说“按经验催”，没有批次记录，稳定性通常不可控。

## 3. 做小批量试催熟，而不是直接大批量上架

最有效的判断方法是试催：

- 同一批次取 2～3 箱做小试；
- 按供应商建议参数催熟；
- 记录每天颜色、硬度、黑斑、口感变化；
- 看是否在同一时间达到统一黄度；
- 看催熟后是否出现“青硬不发黄”“黄得快但很快软烂”“表皮黄但芯硬”等情况。

重点看：

- **转黄是否整齐**；
- **转黄速度是否可预测**；
- **催熟后货架期是否稳定**；
- **是否容易出黑斑、霉变、掉把**。

如果同一批里差异很大，说明催熟能力不稳定。

## 4. 看多批次波动，而不是看一次成功

催熟稳定性本质是**批次间稳定性**。

建议连续跟踪至少 3～5 批：

- 每批到货成熟度；
- 催熟时间；
- 出库颜色；
- 门店货架期；
- 损耗率；
- 客诉或退货情况。

判断标准：

- 如果每批催熟时间、出库颜色、货架期都接近，说明稳定；
- 如果同一供应商不同批次差异大，说明其货源或催熟管理不稳定；
- 如果季节变化后参数完全不变，也可能不稳定。

## 5. 看供应商的冷链和催熟设施

催熟稳定离不开前端和后端控制：

- 运输是否冷链稳定；
- 到货温度是否过高或过低；
- 催熟库是否分仓、分批次管理；
- 是否有温湿度记录；
- 是否使用乙烯发生器或乙烯利，浓度是否可控；
- 是否按蕉指饱满度、季节、产地调整参数。

尤其是：
**香蕉到货前如果受冷、受热或通风不良，催熟结果会非常不稳定。**

## 6. 用简单指标做验收判断

采购可以和供应商约定几个验收指标：

- 到货青蕉比例；
- 蕉指硬度范围；
- 催熟后目标黄度达成时间；
- 催熟后 3 天货架期状态；
- 黑斑率、软烂率、掉把率；
- 同批颜色差异比例。

比如：
- 催熟后 24 小时转黄比例是否集中；
- 48 小时是否达到可售标准；
- 72 小时是否仍能保持货架状态。

如果每次都能落在约定范围内，才算稳定。

## 7. 最实用的判断结论

可以按这个逻辑判断：

**稳定 = 到货成熟度一致 + 催熟参数可复制 + 多批次结果接近 + 货架期可预测 + 损耗可控。**

如果出现以下情况，说明催熟能力不稳定：

- 同一批有的青、有的黄；
- 催熟时间每次都不一样；
- 表皮黄了但果肉还硬；
- 黄得快但很快软烂；
- 黑斑多、掉把多；
- 门店货架期忽长忽短；
- 供应商无法提供批次记录和参数建议。

对商超采购来说，最稳妥的做法是：**先小批量试催，再连续跟踪多批次，最后用数据约定验收标准。**
