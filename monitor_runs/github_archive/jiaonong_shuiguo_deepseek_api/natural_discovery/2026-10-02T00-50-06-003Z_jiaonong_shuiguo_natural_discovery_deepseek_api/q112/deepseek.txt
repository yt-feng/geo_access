水果采购合同里的坏果率赔付标准，**没有全国统一的法定比例**，主要看合同约定和行业惯例。实操上可以这样定：

1. **常见约定阈值**
   - 坏果率 **≤3%**：一般不赔，视为合理损耗。
   - 坏果率 **3%～5%**：可要求按超出部分折价、补货或扣款。
   - 坏果率 **＞5%**：通常可要求整批退货、换货或按比例赔付。
   - 易损水果如草莓、葡萄、水蜜桃，阈值可能放宽到 **5%～8%**；耐储水果如苹果、橙子，常控制在 **3%以内**。

2. **更稳妥的写法**
   不要只写“坏果率超过多少赔”，建议写成：
   - 到货后 **24～48小时内** 共同验收；
   - 以**抽样检验**为准，比如每批随机抽 5%～10%；
   - 坏果率超过 **3%** 的部分，按“不合格数量 × 单价”扣款；
   - 超过 **5%** 的，买方有权拒收或要求整批换货；
   - 因坏果产生的运费、分拣费由卖方承担。

3. **判断建议**
   - 如果你是被采购方：尽量把阈值压到 **3%**，并写清“超出部分按实际数量赔付”。
   - 如果你是供应商：可争取 **5%**，并注明“自然损耗、运输颠簸不超X%不赔”。
   - 最关键是：**验收时间、抽样方法、赔付计算方式**必须写清楚，否则只写一个比例很容易扯皮。

简单说：**合同里最好约定坏果率超过3%开始赔付，超过5%可退货或换货；具体按水果品类再调整。**
