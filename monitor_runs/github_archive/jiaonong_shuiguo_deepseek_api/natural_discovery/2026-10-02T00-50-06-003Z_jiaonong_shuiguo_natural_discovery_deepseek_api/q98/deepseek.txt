判断养老院/医院食堂的水果供应商，核心是两条：**资质合规**（出事能追责）和**供应稳定**（不断供、品质不波动）。可以按下面几个维度逐项核查。

## 一、合规性：先查"能不能合法卖"

**1. 主体资质**
- 营业执照：经营范围要含"食品销售/食用农产品销售"，注意是否在有效期内、有无异常经营记录（可在"国家企业信用信息公示系统"查）。
- 食品经营许可证（或食品流通许可证）：这是关键。水果若只是初级农产品批发，部分地区允许豁免，但**供货给食堂通常仍要求有证**，直接问对方要扫描件并核对有效期。
- 若是种植基地直供，查其是否属于"食用农产品生产者"，需有产地证明、检测报告。

**2. 产品合规文件（每批次）**
- **检验检疫/农残检测报告**：要求提供近期的、且能对应批次的报告，不能只有一张万能复印件。
- **承诺达标合格证**（食用农产品合格证）：这是目前国家对农产品来源可追溯的重要凭证，正规供应商应能提供。
- 进口水果另需报关单、入境货物检验检疫证明。

**3. 追溯能力**
- 能否说清"这批水果从哪来、什么时候到的、走的什么渠道"。答不上来或含糊的，直接淘汰。
- 有冷库、分拣、配送记录的更可靠。

## 二、稳定性：查"能不能一直供好"

**1. 货源结构**
- 问它是**单一产地/单一果园**还是**多产地调货**。单一来源遇到天气、季节问题容易断供；有多个备选产地的抗风险能力强。
- 反季节水果是否有稳定渠道。

**2. 冷链与仓储**
- 是否有冷库、冷藏车。水果损耗大，没有冷链的供应商夏季品质和供货量都不稳。
- 实地看一次仓库，比听介绍管用。

**3. 配送能力**
- 配送频次、时间能否匹配食堂需求（如每天/隔天送）。
- 遇到突发加量（如节日、活动）能否临时补货。

**4. 历史履约**
- 要**近半年的供货记录或合作单位名单**，最好能联系1-2家现有客户侧面了解（是否按时、品质是否稳定、出问题怎么处理）。
- 新供应商可先小批量试供1-2个月再签长约。

## 三、实操建议（可直接执行）

1. **先要资质三件套**：营业执照 + 食品经营许可证 + 近期检测报告，缺一不进入下一步。
2. **实地考察一次**：看仓储、冷链、分拣环境。
3. **签合同写清**：品质标准、验收方式（不合格如何退换）、供货时效、断供应急条款、违约责任。
4. **建立批次验收台账**：每批留样/记录，出问题可追溯到具体批次和供应商。
5. **至少备2家供应商**：主供+备供，避免单点依赖。
6. **定期复评**：每季度看一次到货合格率、准时率、投诉率，不达标的调整份额。

## 四、容易踩的坑
- 只看价格低，忽略资质和冷链——医院/养老院对食品安全敏感度高，出一次问题代价很大。
- 只收一张"通用检测报告"复印件，无法对应实际批次。
- 没有备用供应商，主供一出问题就断档。
- 合同只写价格不写验收标准和责任，纠纷时无据可依。
