控制水果新鲜度和库存，核心是“少进、快出、勤查、早处理”。给你几个可执行的点：

**一、订货：按销量定，不按感觉定**
- 先做7天销量记录：每个单品每天卖多少、剩多少、损耗多少。
- 订货量 = 近7天日均销量 × 本次间隔天数 × 0.8～0.9（安全系数）。
- 新品类先小量试销，卖得动再放量。
- 固定订货日和到货日，避免“看到便宜就多拿”。

**二、分级管理：把水果分三类**
- 引流款：香蕉、苹果、橘子等，销量稳但利润薄，保证不断货即可，别压太多。
- 利润款：草莓、车厘子、葡萄等，单价高、损耗大，按预售/小批量高频补。
- 促销款：当季大量上市、价格低的，用来做活动，快进快出。

**三、陈列：先进先出，少量多次**
- 货架不要堆太满，堆满看着多，实际压货、压伤。
- 每层只摆当天能卖完的量，卖完再补。
- 新货放后面，旧货放前面，贴日期标签。
- 易压伤的水果（桃、草莓、葡萄）用浅盘、小筐，别叠高。

**四、每天三次检查**
- 早上开门：挑出隔夜软伤、发黑、裂口的，直接处理。
- 中午：看哪些卖得慢，及时调整位置或降价。
- 晚上关门前：把明天可能坏的挑出来，做次日特价或果切。

**五、临期处理：越早越值钱**
- 当天没卖完但还好的：晚上打折、做果切、搭配销售。
- 轻微瑕疵：做果切、榨汁、做水果捞。
- 已经坏的：立刻扔掉，别放在货架上影响形象和交叉污染。
- 设“损耗台账”，每天记扔了多少、为什么扔，一周复盘一次。

**六、库存红线**
- 给每个单品设最高库存：比如香蕉最多2天量，草莓最多1天量。
- 超过红线就不再进货，先清库存。
- 冷库/冰箱只放需要保鲜的，别把所有水果都塞进去，有些水果怕冷（香蕉、芒果）。

**七、和供应商配合**
- 找能小批量、多频次送货的供应商。
- 谈好次品退换：到货当场验，坏果直接退，别自己扛。
- 季节性水果提前问产地行情，价格要跌时少囤。

**八、简单考核指标**
- 损耗率：水果行业控制在5%～10%算正常，超过就要查订货和陈列。
- 周转天数：越短越好，叶菜、草莓类最好1天内，苹果橘子可2～3天。
- 缺货率：别为了不压货把畅销款卖断，缺货也是损失。

一句话：**订货看数据，陈列控数量，检查要勤快，处理要趁早。** 先从一个品类试点，跑顺了再推广到全店。
