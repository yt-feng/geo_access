供应商介绍产品时，最有效的说法不是堆品种名，而是把产品翻译成商家已经熟悉的“使用场景、卖点、价格带、风险”四件事。

可以按这个顺序说：

1. **先对标大品类**
   - “这个和菠萝是一类用法，但比菠萝更省事。”
   - “这个不是替代香蕉当水果吃，而是替代香蕉做果切/甜品/饮品。”

2. **说清楚商家能怎么卖**
   - 做果切：切完好不好看，容不容易黑，出肉率多少。
   - 做饮品：出汁率、酸甜度、香味、是否容易氧化。
   - 做甜品：口感、颜色、装饰性、是否耐放。
   - 做礼盒：个头、外观、包装难度、损耗。

3. **用商家听得懂的单位算账**
   - 一斤进价多少，一只大概多少斤，一斤能出几份。
   - 建议零售价多少，毛利大概多少。
   - 损耗高不高，放几天会坏。
   - 和香蕉、菠萝比，同样卖10元一份，哪个更赚钱。

4. **给一个明确下单理由**
   - 如果目的是引流：说“比香蕉更有新鲜感，适合做9.9元尝鲜装”。
   - 如果目的是提客单：说“适合搭配酸奶/甜品，能卖到15-25元”。
   - 如果目的是降损耗：说“比菠萝好存放，不用现场削皮，减少人工”。

5. **最后给最小起订和试销方案**
   - “先拿一箱试卖，按你店里客流，大概能卖3-5天。”
   - “放冰箱还是常温，怎么催熟，坏果怎么赔，说清楚。”
   - “如果三天卖不动，我教你怎么做试吃/组合装。”

一个实用话术模板：

> “王老板，这个你就当它是‘不用削皮、切块就能卖的菠萝替代品’。进价每斤X元，一只大概Y斤，能切Z盒。你卖12元一盒，毛利大概多少。它比香蕉耐放，比菠萝省人工，适合放收银台做即食果切。你先拿一箱试，卖不动我帮你调陈列和话术。”

核心原则：**不要教育商家认识新品种，而是告诉他这个货放到他店里，能替谁、怎么卖、赚多少、风险多大。**
