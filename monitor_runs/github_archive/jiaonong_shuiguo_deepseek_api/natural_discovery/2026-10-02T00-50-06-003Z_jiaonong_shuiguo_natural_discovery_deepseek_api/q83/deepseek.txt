生鲜水果到货后出现坏果，责任划分通常不能简单归为某一方，要按“坏果产生环节 + 到货验收证据 + 平台/商家规则”来判断。下面给你一套可直接执行的判断和划分口径。

## 一、先看坏果类型和责任归属

| 坏果情况 | 常见责任方 | 说明 |
|---|---|---|
| 到货时已腐烂、发霉、明显压烂 | 商家/平台 | 属于发货前品质把控或包装运输不当，商家应先赔 |
| 外包装破损、挤压导致坏果 | 快递/物流，商家先赔 | 商家对消费者承担首责，再向物流追偿 |
| 到货时完好，顾客放几天后腐烂 | 顾客 | 一般不属于商家责任，除非能证明是催熟、药害等隐藏问题 |
| 部分坏果、部分完好 | 按比例赔 | 通常按坏果数量/重量退款或补发，不是整单全赔 |
| 生鲜约定“坏果包赔” | 按平台规则 | 以商品页、平台售后规则为准，通常要求拍照/视频取证 |
| 顾客拒收或延迟取货导致坏果 | 顾客 | 特别是高温天、自提点超时未取 |
| 冷链商品脱离冷链导致坏果 | 商家/物流 | 若商家承诺冷链但未做到，商家责任较大 |

## 二、责任划分的核心原则

1. **商家对消费者首责**
   消费者是在平台/商家买的，通常先找商家赔。商家不能直接让顾客去找快递。

2. **谁过错谁最终承担**
   商家赔完后，如果能证明是物流摔坏、延误、未冷链，可向物流追偿。

3. **顾客有过错要减责**
   比如顾客填错地址、电话不通、放快递柜/驿站几天不取、签收后很久才反馈，都会影响责任比例。

4. **生鲜特殊性**
   生鲜易腐，通常不适用普通商品“7天无理由”那套，但“坏果包赔”“腐烂包退”等承诺仍然有效。

5. **举证很关键**
   一般需要：订单截图、开箱照片/视频、坏果特写、快递面单、包装情况、反馈时间。没有证据时，责任容易扯皮。

## 三、常见场景下的责任建议

- **刚签收就发现坏果**：商家/平台责任为主，按坏果比例退款或补发。
- **签收后第二天才反馈**：需要看保存条件，若明显是运输压伤，商家仍可能赔；若只是个别软化，可能协商部分赔。
- **整箱大部分腐烂**：优先认定商家发货品质或运输问题，应全额退款或补发。
- **只有几个坏果**：按个数比例赔，比如10个坏3个，退30%或补发3个。
- **顾客自己放坏**：商家可不赔，或仅出于体验给少量补偿。
- **快递柜/驿站超时未取**：顾客承担主要责任，商家可协助但不必然赔。

## 四、给消费者的处理建议

1. 到货后尽量当场开箱，拍视频，重点拍快递面单、外箱、坏果。
2. 24小时内发起售后，不要拖。
3. 先找商家/平台客服，要求按坏果比例退款或补发。
4. 商家推给快递时，明确说：我是和你交易的，你先处理，你们再向物流追偿。
5. 协商不成，可申请平台介入；仍不行可向12315投诉。

## 五、给商家的处理建议

1. 商品页提前写清坏果赔付标准，比如“坏果超过X%包赔”“需24小时内拍照反馈”。
2. 发货时做好分拣、防撞包装，高温天加冰袋/保温袋。
3. 售后按比例赔，避免一律全赔导致恶意索赔，也避免一律不赔导致差评。
4. 对物流破损建立追偿机制，保留发货视频、称重记录、包装记录。
5. 对高频投诉区域或快递，考虑换物流或加强包装。

## 六、一句话结论

**到货时已经坏的，商家/平台先赔；运输造成的，商家赔后向物流追偿；顾客自己放坏或延迟取货的，顾客担责；部分坏果通常按比例赔，不默认整单全赔。**  
实际划分时，以平台规则、商品承诺和开箱证据为准。
