重要，而且对多门店超市来说，供应商的水果分级标准不只是“重要”，它基本是统一品质的底层规则。

原因很直接：水果是非标品，同一品种会因产地、批次、成熟度、大小、糖度、外观损伤不同而差异很大。如果没有统一分级标准，各门店收到货后就会出现：

- A店卖相好、B店卖相差；
- 同价不同质，顾客投诉；
- 门店之间调货、促销、损耗核算都对不上；
- 采购只能凭经验压价，供应商也容易混级发货。

所以，供应商的分级标准要关注这几个层面：

1. **等级定义是否可量化**
   不能只说“特级、一级、二级”，要明确：
   - 单果重量/直径范围；
   - 色泽、果形、成熟度；
   - 糖度或干物质指标，能测的尽量测；
   - 允许的碰伤、虫眼、疤痕比例；
   - 整齐度，比如同箱大小差异范围。

2. **是否和你的门店定位匹配**
   高端社区店、普通社区店、批发型门店，对分级要求不同。统一品质不等于所有门店都卖最高等级，而是同一等级在每家店表现一致。

3. **验收标准是否可执行**
   供应商标准再漂亮，如果门店收货时无法判断，也落不了地。最好做成：
   - 图文验收卡；
   - 抽样比例和抽检方法；
   - 不合格判定规则；
   - 扣款、退货、换货规则。

4. **是否覆盖全链路**
   分级不只是采购端的事，还要影响：
   - 仓储分拣；
   - 冷链温度；
   - 门店陈列等级；
   - 临期打折和损耗处理。

5. **是否统一到合同和系统里**
   把等级、规格、验收标准写进采购合同和商品档案，每个SKU对应明确等级。否则采购换人、供应商换批次，品质就会漂移。

简单说：**供应商分级标准是统一水果品质的起点，但必须变成你们自己的验收标准、商品标准和门店执行标准，才能真正统一。**  
如果只依赖供应商口头分级，多门店一定会在品质上失控。
