优先选**小把（3～5根）**，其次才是单根；整袋通常不建议作为主推。

判断逻辑很简单：便利店卖香蕉，核心不是“最便宜”，而是**降低购买门槛 + 减少损耗 + 匹配即时消费**。

**1. 小把：最适合做主打**
- 顾客一次买3～5根，既能当早餐、加餐，也不容易吃不完。
- 客单价通常比单根高，又不会像整袋那样让顾客犹豫。
- 对门店来说，按小把定价和陈列都比散根更好管理。
- 适合上班族、学生、家庭顺手买。

**2. 单根：适合补充场景，不适合当唯一选择**
- 对只想马上吃一根的人很友好，购买门槛最低。
- 但客单价低，称重、贴标、收银都更琐碎。
- 香蕉容易碰伤，单根反复挑拣后损耗会上升。
- 可以少量提供，满足“立刻吃”的需求，但不要把它当主力。

**3. 整袋：大多数便利店不建议**
- 适合家庭采购，但便利店顾客更多是即时消费。
- 整袋分量大，顾客容易嫌多，尤其一个人住或临时买。
- 一旦成熟度没控好，整袋卖不掉就是集中损耗。
- 除非你店面靠近社区、家庭客多，且能稳定走量，否则不要主推。

**更稳的做法：组合上架**
- 主推：小把3～5根，占大部分陈列。
- 辅推：单根少量，放在收银台附近或即食区。
- 谨慎试：整袋只在社区店、家庭客多的时段少量试卖。

**定价和陈列建议**
- 小把可以按“把”定价，减少称重麻烦。
- 单根按根卖，适合搭配早餐、酸奶、咖啡。
- 香蕉不要堆太满，成熟度分开陈列：偏青的放后面，偏黄的放前面先卖。
- 每天检查，出现黑斑、碰伤的及时降价或做成果切、奶昔原料，别硬撑原价。

**一句话结论：**
便利店上香蕉，**小把为主，单根为辅，整袋慎上**。如果只能选一个，选小把。
