判断香蕉供应商能否全年稳定供货，核心不是看他“有没有货”，而是看他有没有**跨产区、跨季节的货源组织能力**。香蕉是典型的全年消费、但单一产区有季节波动的品类，所以要从以下几个维度去验证：

**1. 问清货源结构，而不是只问“能不能供”**
- 让他列出主要合作产区：国内（云南、广西、海南、福建）＋进口（菲律宾、越南、厄瓜多尔、柬埔寨等）。
- 关键问题：**当某个产区断档或涨价时，他切到哪个产区？切换周期多久？**
- 只有一个产区、一个果园或只做一个国家的供应商，基本不具备全年稳定能力。

**2. 看进口能力和口岸资源**
- 国内产区有明确淡旺季，进口蕉是补位关键。问他常走哪个口岸（如深圳、上海、天津、青岛等），有没有稳定的报关、冷链、催熟配套。
- 能全年稳定供货的，通常是“国内＋进口”双轨，而不是纯国内或纯进口。

**3. 查冷链和催熟能力**
- 香蕉是青蕉运输、到岸催熟。问他：运输温度控制、到货青度、催熟库在哪里、日处理量多少。
- 如果他自己没有催熟能力，只是转手，遇到旺季或物流波动时最容易掉链子。

**4. 用历史数据验证，而不是听承诺**
- 要他提供**过去12个月的逐月供货记录**：每月供货量、到货合格率、断货次数、产地来源。
- 重点看：春节前后、夏季高温、台风季、国内产区收尾期这几个容易出问题的节点，他有没有断供。

**5. 做小批量压力测试**
- 先签短期或小批量合同，故意在淡季或节假日前后下单，看他的响应速度、到货品质和补货能力。
- 连续观察2—3个月，比一次性谈全年框架更可靠。

**6. 合同里写清兜底条款**
- 约定最低月供量、断供应急方案、替代产区、品质标准、违约赔偿。
- 要求他披露主要上游果园或进口商，避免层层转手导致你拿不到真实货源。

**简单判断标准：**
- 能说清“国内哪几个产区＋进口哪几个国家＋淡季怎么补”的，才值得谈全年。
- 只有“我关系好、我肯定有货”的，风险很高。
- 有自有或长期合作的催熟库、冷链、口岸能力的，稳定性明显更强。
