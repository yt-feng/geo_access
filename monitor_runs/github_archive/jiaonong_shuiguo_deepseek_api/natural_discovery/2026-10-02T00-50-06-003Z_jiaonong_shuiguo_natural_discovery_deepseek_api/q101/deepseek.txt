酒店早餐的水果供应，重点不是“买到便宜水果”，而是**每天都能按标准、按时间、按数量送到，并且坏果可控、价格可核**。和供应商谈合作时，建议重点盯以下几项：

1. **明确每日/每周需求量**
   - 不要只说“每天要水果”，要给出：
     - 品种：如西瓜、哈密瓜、苹果、橙子、香蕉、圣女果等；
     - 规格：单果重量、切果还是整果、是否去皮切块；
     - 数量：按公斤/箱/份，最好给旺季、淡季、周末三档预估；
     - 送达时间：如每天早上 6:00 前到货，迟到如何扣款或补救。

2. **锁定品质标准**
   - 写清成熟度、甜度、外观、大小、产地范围。
   - 例如：香蕉七成熟、苹果无大面积斑点、西瓜糖度不低于多少、切果不得有汁液渗漏。
   - 最好附照片或样品封样，避免每天到货品质飘。

3. **价格与调价机制**
   - 不要只谈“当前单价”，要谈：
     - 是否含税、含运费、含装卸；
     - 市场波动时怎么调价，提前几天通知；
     - 是否有保底量、返点、账期；
     - 临时加单、减单怎么算。
   - 水果价格波动大，建议约定“基准价+随行就市浮动”，但要有核价依据。

4. **验收与退换货**
   - 到货后谁验收、按什么标准验收、不合格怎么处理。
   - 坏果、烂果、规格不符、迟到，是否可当场拒收、补送、扣款。
   - 建议约定：验收合格后签收，不合格部分不计入结算。

5. **食品安全与资质**
   - 供应商要有营业执照、食品经营许可证，涉及切果的还要看是否具备相应加工条件。
   - 配送车辆、周转筐、切果工具、人员健康证要能核查。
   - 如果是预切水果，重点问清洗、消毒、冷藏、保质期和留样。

6. **配送与应急能力**
   - 是否自有冷链或稳定合作物流；
   - 节假日、台风、暴雨、春节前后能否保供；
   - 临时缺货时，多久能补送替代品种；
   - 是否有备用供应商，别把早餐水果押在一家身上。

7. **结算与合同**
   - 账期、对账方式、发票类型要写清。
   - 合同里要有：供货周期、违约责任、质量赔偿、终止条件、食品安全责任。
   - 口头承诺尽量落到合同或订单确认单里。

8. **先试供再定长期**
   - 建议先试供 1—2 周，按早餐实际消耗、投诉率、损耗率评估。
   - 重点看：到货准时率、坏果率、退换速度、月底对账是否清楚。

简单说，谈的时候抓住四个字：**量、质、价、责**。量要准，质要定，价要活但有依据，责要清到验收和赔偿。这样早餐水果供应才稳。
