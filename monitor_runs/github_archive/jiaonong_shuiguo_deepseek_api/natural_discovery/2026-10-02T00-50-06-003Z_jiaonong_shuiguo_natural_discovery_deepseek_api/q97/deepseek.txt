酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准，供应商至少应保证以下几类要求。

## 一、规格标准

1. **品种与等级**
   - 明确具体品种，如红富士苹果、皇冠梨、海南贵妃芒、进口橙等，不接受口头“同类替代”。
   - 明确等级，如一级果、精品果、酒店专供果；不能混入二级果、落地果、残次果。

2. **单果重量/尺寸**
   - 按品种约定单果重或直径，例如：
     - 苹果：单果 180–220g，直径 75–85mm；
     - 橙子：单果 180–250g，直径 70–85mm；
     - 火龙果：单果 400–600g；
     - 西瓜：单果 4–6kg，或按切块用途约定；
     - 圣女果：单果 12–18g，直径 20–25mm。
   - 同一批次大小应相对均匀，避免一盘水果里明显大小不一。

3. **成熟度**
   - 到货成熟度应适合酒店当日或次日使用：
     - 即用型：8–9 成熟，可直接切盘；
     - 备货型：7–8 成熟，可短期存放后熟。
   - 不接受过生、过硬、无香味，也不接受过熟、发软、出水、发酵。

4. **新鲜度与货龄**
   - 应明确采摘或到货时间要求，如“采摘后 24–48 小时内到货”。
   - 叶菜类、浆果类、切果类原料周转快，不能长期库存。
   - 冷冻/冷藏水果需符合对应温控要求，不得反复解冻。

5. **食品安全与检测**
   - 农残、重金属、微生物等应符合国家食品安全标准。
   - 供应商应能提供批次检测报告、产地证明、合格证或溯源信息。
   - 进口水果应有合法入境货物检验检疫证明。
   - 预切水果应符合即食果蔬卫生标准，冷链完整。

6. **包装与运输**
   - 使用食品级周转箱、保鲜箱或原包装，不得与化学品、生肉、海鲜混装。
   - 运输温度按品种要求：
     - 热带水果：一般 10–15℃ 或常温通风；
     - 温带水果：0–8℃；
     - 浆果类：0–4℃。
   - 到货后包装无破损、无挤压、无污染、无虫害。

7. **供货稳定性**
   - 应保证同一规格、同一品质的持续供应能力。
   - 缺货时需提前通知，并提供经酒店确认的替代方案，不能擅自换品种、换等级。

## 二、外观标准

1. **整体外观**
   - 果形端正、自然，无明显畸形、偏斜、双头、裂口。
   - 色泽符合品种特征，成熟度一致，不过青、不过红、不发暗。
   - 表面干净，无泥污、药斑、虫粪、霉斑、黑点扩散。

2. **缺陷控制**
   - 不接受明显腐烂、发霉、发酵、异味、流汁。
   - 不接受大面积机械伤、压伤、磕碰伤、冻伤、日灼伤。
   - 轻微瑕疵可限定比例，例如：
     - 外观瑕疵果不超过 5%；
     - 严重缺陷果为 0；
     - 单盘可用率不低于 95%。

3. **病虫害与异物**
   - 无活虫、虫卵、虫蛀孔、蚂蚁、果蝇等。
   - 无金属屑、玻璃、塑料片、毛发、泥沙等异物。
   - 叶类水果无黄叶、烂叶、病斑叶。

4. **规格一致性**
   - 同批次颜色、大小、成熟度、果形应基本一致。
   - 用于拼盘的水果，单果大小和切面颜色应协调，不能一批大一批小、一批生一批熟。

5. **切盘适用性**
   - 果肉应紧实、少籽或无籽、不易氧化褐变、出水少。
   - 切后应能保持形状，不快速软塌、发黑、渗汁。
   - 例如苹果、梨等易氧化水果，供应商可建议或提供防褐变处理方案。

## 三、验收与退换货建议

1. **到货抽检**
   - 每批次按比例抽检，如 10%–20%。
   - 检查数量、重量、规格、成熟度、外观、温度、包装、检测报告。

2. **验收判定**
   - 严重缺陷、腐烂、异味、农残报告缺失：整批拒收。
   - 轻微瑕疵超标：按比例扣重、折价或退货。
   - 规格不符：要求换货或降级处理，不得按原价结算。

3. **合同写明**
   - 品种、等级、单果重/直径、成熟度、产地、包装、冷链、检测报告。
   - 到货时限、缺货通知、替代规则、退换货责任、赔偿标准。
   - 食品安全责任：因原料问题导致客诉、处罚或损失的，供应商承担相应责任。

简单说，酒店水果盘原料的核心标准是：**品种等级明确、大小成熟一致、新鲜无腐无虫、食品安全可追溯、冷链包装合规、切盘可用率高**。采购时最好做成一张《水果原料验收标准表》，按品种逐项写清楚，验收时直接对照执行。
