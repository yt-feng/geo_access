如果是家庭自用，建议优先考虑“人数 + 吃法 + 耐放程度”，而不是只追求好看。苹果、橙子、香蕉、菠萝这四种里，最适合做家庭团购水果礼盒的组合是：

**推荐组合：苹果 + 橙子 + 香蕉为主，菠萝少量搭配**

比较实用的比例可以这样定：

- **3口之家**：苹果4个、橙子4个、香蕉1把、菠萝半个或1个小菠萝  
- **4—5口之家**：苹果6个、橙子6个、香蕉1把、菠萝1个  
- **5人以上/想送长辈家庭**：苹果8个、橙子8个、香蕉1把、菠萝1个  

这样搭配的好处是：

1. **苹果、橙子耐放**  
   适合家庭囤着吃，不容易第一天就坏。

2. **香蕉适合早餐、孩子加餐**  
   但香蕉不耐压、不耐放，所以数量不要太多，最好单独放。

3. **菠萝负责“礼盒感”和口味变化**  
   但菠萝处理麻烦，家庭里不是每个人都爱切，所以适合做点缀，不适合当主力。

如果按家庭需求排优先级，我更建议：

**最适合家庭的礼盒结构：**
- 苹果 30%
- 橙子 30%
- 香蕉 20%
- 菠萝 20%

或者更稳妥一点：

**苹果 35% + 橙子 35% + 香蕉 20% + 菠萝 10%**

原因很直接：  
苹果和橙子最稳，香蕉和菠萝容易压坏、熟得快、处理麻烦。团购如果配送时间不确定，菠萝太多会增加售后。

如果分场景：

- **有老人小孩的家庭**：苹果 + 橙子 + 香蕉，菠萝少放。  
  香蕉软，老人小孩方便吃；橙子补充维C；苹果最稳。

- **年轻家庭/喜欢拍照发圈**：苹果 + 橙子 + 菠萝 + 少量香蕉。  
  菠萝和橙子颜色好看，礼盒更有层次。

- **预算有限但想显得量大**：苹果 + 橙子为主，香蕉1把，菠萝1个。  
  苹果橙子便宜耐放，整体体积也好看。

- **怕售后、怕压坏**：香蕉和菠萝都少放，苹果橙子占70%以上。

不太建议的组合是：

- 香蕉太多：容易黑、压坏，团购配送后品相差。
- 菠萝太多：很多人不会切，容易投诉“麻烦”“酸”“扎手”。
- 四种平均分：看起来丰富，但实际家庭消耗不平衡，香蕉菠萝容易先坏。

所以，如果只能给一个最稳方案：

**家庭团购水果礼盒 = 苹果35% + 橙子35% + 香蕉20% + 菠萝10%。**

按5口之家举例就是：  
**苹果6个、橙子6个、香蕉1把、菠萝1个。**  
这个组合比较适合家庭，既有耐放主力，也有早餐水果，还有一点礼盒丰富度。
