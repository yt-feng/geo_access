判断一批香蕉，核心是看“颜色、硬度、棱角、果柄切口、轴心、气味、温感”这几项，再结合你打算几天内卖完来决定能不能拿。

**一、先判断熟度**
1. **看颜色**
   - 全绿：生，适合长途或囤货，但要看有没有催熟条件。
   - 绿中带黄、果尖转黄：开始熟，通常1-3天进入可售期。
   - 黄多绿少、果柄还绿：适销，适合马上批给零售端。
   - 全黄、果柄也黄：熟，最好1-2天内走掉。
   - 出现黑斑但果肉还硬：进入食用佳期，但货架期短。
   - 大面积黑斑、发软：高风险，容易烂。

2. **看棱角**
   - 棱角明显、果身硬：偏生。
   - 棱角变圆、果身稍软：熟度上来。
   - 棱角几乎不明显、手感软：过熟风险高。

3. **摸硬度**
   - 轻按果身，硬、回弹快：生。
   - 稍有弹性：适熟。
   - 一按一个坑：过熟或开始坏。
   - 注意别只捏一根，要抽不同箱、不同位置。

4. **看果柄和轴心**
   - 果柄切口新鲜、绿色或浅绿：采摘和运输较新。
   - 切口发黑、干缩、发霉：存放久或冷链有问题。
   - 整串轴心发黑、软烂：内部可能已开始腐坏。

5. **闻气味**
   - 清香正常。
   - 明显酒味、酸味、发酵味：已经过熟或内部腐烂。
   - 霉味：有霉菌感染，整批风险高。

6. **看果皮和果肉**
   - 表皮有少量小斑点正常。
   - 大面积黑斑、渗水、裂口、发霉：坏果。
   - 抽检剥开：果肉发暗、水化、黑心、异味，说明批内温度或成熟度不均。

**二、判断坏果风险**
重点看这几个信号：
- **箱内温差大**：同一批有的很绿、有的很黄，说明成熟不均，后面容易集中烂。
- **箱底有无汁液**：有黏液、甜水、酒味，通常底层已压坏。
- **果柄发霉**：霉菌会传染，坏果率会快速上升。
- **果皮渗水发亮**：不是新鲜，是细胞破裂，风险高。
- **冷链是否断过**：香蕉怕冻也怕闷。冻伤后皮发暗、发黑，果肉软烂；闷热则快速催熟。
- **运输和存放时间**：夏天高温，青蕉也可能几天内突然转黄；冬天受冻后看似青，回温后很快黑。

**三、拿货时的实操抽检**
1. 不要只看上面一层，抽**上、中、下、边角**。
2. 每箱至少看：
   - 颜色是否一致；
   - 果柄是否新鲜；
   - 箱底是否有汁液；
   - 有无霉点、裂口、压伤。
3. 随机剥2-3根，看果肉有无黑心、水化、异味。
4. 问清：采摘时间、运输温度、是否催熟、到货几天。
5. 用手轻按整串，判断整批软硬是否一致。

**四、按销售周期决定拿不拿**
- **1-2天卖完**：可拿黄多绿少、少量黑斑的，但必须便宜、快走。
- **3-5天卖完**：拿绿中带黄、果柄绿、硬度中等的。
- **7天以上**：拿全绿或偏生，但要有催熟和冷库条件。
- **没有催熟条件**：不要拿全青蕉，容易砸手里。
- **没有冷库、天气热**：不要拿熟度高的，坏果速度很快。

**五、简单判定口诀**
- 绿硬棱角明：生，能放。
- 黄多柄还绿：好卖，快走。
- 全黄柄也黄：熟，别压货。
- 黑斑加酒味：坏，别拿。
- 箱底有汁、柄发霉：整批风险高。
- 同批颜色乱：成熟不齐，后续损耗大。
