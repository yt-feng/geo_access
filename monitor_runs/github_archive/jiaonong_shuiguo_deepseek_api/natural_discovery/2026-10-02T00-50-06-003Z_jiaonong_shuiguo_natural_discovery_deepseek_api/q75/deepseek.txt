第一次合作做小批量试单，核心目标不是赚钱，而是**用最小成本验证供应商的4件事：品质稳定性、发货履约、结算配合、售后态度**。下面给你一套可直接执行的设计方案。

## 一、先定试单目标（决定怎么设计）

试单要验证的优先级排序：

1. **品质是否符合你的销售标准**（最重要）
2. **到货时间和损耗率是否可控**
3. **沟通与售后是否配合**
4. **结算方式是否可接受**
5. 价格是否有持续合作空间

所以试单**不要只试一个品种、一个规格**，最好覆盖你未来主推的品类。

## 二、试单规模怎么定

建议原则：**金额小、品种准、次数少、有对比**。

- **金额**：控制在你能承受全损的范围内，比如首次单批货值几千到一两万（按你自身体量定），不要压上全部资金。
- **品种**：选1–2个你确定好卖、且能代表供应商主力能力的品种。
- **规格**：每个品种至少测 **2个规格/等级**（如大果/中果、一级/二级），才能看出分级是否稳定。
- **数量**：每个规格少量，够你上架测试和观察即可，比如各几箱到十几箱。
- **批次**：建议 **分2次下单**，中间隔几天，避免一次偶然好或坏就下结论。

不建议第一次就试十几个品种，那样物流、品控、对账全乱，反而看不出问题。

## 三、试单必须锁定的关键条款

下单前用文字（微信/合同）确认清楚：

1. **品名、品种、产地、规格、等级标准**（单果重、果径、糖度范围、成熟度）
2. **包装方式**：箱规、每箱净重、是否带托盘、是否预冷
3. **价格与费用**：单价、是否含运费、装卸费、代办费
4. **发货时间与物流方式**：谁找车、谁承担在途风险、预计到货时间
5. **验收标准**：允许的损耗率、次果率、烂果率上限
6. **售后规则**：出现质量问题的赔付方式（补货/退款/扣款），凭证怎么提供（照片、视频、开箱记录）
7. **结算方式**：首次合作建议 **货到验收后付款** 或 **部分定金+到货结清**，不要全额预付
8. **票据**：是否可开票、开什么票

## 四、到货验收怎么做（试单成败关键）

一定要做标准化验收，别凭感觉：

- **到货当天开箱抽检**：随机抽若干箱，不要只查最上面一层
- **记录数据**：总到货量、烂果数、次果数、规格不符数、实际净重
- **拍照/录像留证**：开箱过程、问题果特写、称重画面
- **算三个指标**：
  - 损耗率 = 问题果重量 / 总重量
  - 规格符合率
  - 实际净重与标称净重差异
- **及时反馈**：到货24小时内把问题发给供应商，看对方响应速度和态度

## 五、试单评估表（建议打分）

每个维度1–5分，低于3分要警惕：

| 维度 | 观察点 |
|---|---|
| 品质 | 口感、外观、成熟度、均匀度 |
| 规格 | 是否与约定一致 |
| 损耗 | 烂果、次果比例 |
| 履约 | 是否按时发货、到货 |
| 包装 | 是否抗压、是否适合运输 |
| 沟通 | 响应是否及时、是否专业 |
| 售后 | 出问题是否认账、是否爽快处理 |
| 价格 | 是否有竞争力、是否稳定 |
| 结算 | 条件是否合理、是否灵活 |

## 六、判断是否继续合作的信号

**可以推进二次合作：**
- 损耗在约定范围内
- 规格基本符合
- 发货准时
- 出小问题愿意配合解决
- 价格有合理空间

**要谨慎或换供应商：**
- 品质波动大，第一次就明显不符
- 规格严重不符还推责
- 发货拖延、物流信息不透明
- 售后扯皮、要求你先付款再谈
- 报价明显低于市场且解释不清（可能有坑）

## 七、几个实操提醒

- 首次合作**不要赊账也不要全额预付**，走“定金+到货验收后结清”最稳。
- 所有约定**留文字记录**，口头承诺不算。
- 试单阶段就按正式合作标准走流程，才能看出对方真实水平。
- 可以同时接触2–3家供应商，用小批量并行试单做对比，但别让任何一家觉得你只是比价。
- 试单成功后，再逐步放大单量，并谈账期、返点、独家规格等条件。

一句话总结：**试单要小到亏得起，标准要严到看得出问题，验收要细到能谈判，评估要客观到能决定是否长期合作。**
