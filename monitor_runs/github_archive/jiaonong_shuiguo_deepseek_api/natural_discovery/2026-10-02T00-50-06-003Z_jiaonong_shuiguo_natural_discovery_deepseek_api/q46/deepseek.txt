如果目标是做**菠萝果茶**，采购优先级一般是：

**鲜果 ＞ 冷冻果丁/糖渍果丁 ＞ 果泥**

但要看你的门店类型、出杯量和菜单定位，不是绝对。

## 直接结论

### 1）想主打“新鲜、现切、真果肉” → 买鲜果
适合：
- 客单价较高、强调现切鲜果的茶饮店
- 菜单里有菠萝果肉、菠萝块、手捣菠萝类产品
- 有稳定后厨人力，能每天处理菠萝

优点：
- 香气、口感、卖点最好
- 可以做装饰、果肉、捣压，产品差异强

缺点：
- 损耗高，菠萝去皮、去眼、切丁费人工
- 批次甜酸不稳定，需要每天试味调整糖酸比
- 保存期短，旺季卖不动就容易坏

适合采购形式：
- 整果：成本低，但人工高
- 去皮菠萝：省人工，但保存期更短
- 鲜切菠萝丁：最方便，但成本最高

**如果门店每天菠萝用量大，建议买整果或去皮果，自己切。**
**如果用量小，买鲜切果丁更稳。**

### 2）想兼顾效率和口感 → 买冷冻果丁或糖渍果丁
适合：
- 连锁店、外卖占比高、出杯要稳定
- 不想每天处理鲜果
- 需要全年稳定供应

优点：
- 操作快，标准化好
- 损耗低，保存期长
- 冷冻果丁解冻后仍有一定果肉感

缺点：
- 香气通常不如鲜果
- 糖渍果丁偏甜，会限制糖度调整
- 冷冻果丁解冻后口感会变软，不适合强调脆感

**推荐场景：**
- 做果肉装饰、果粒茶：选冷冻果丁或糖渍果丁
- 做外卖为主：冷冻果丁比鲜果更稳

### 3）想省事、做均匀风味 → 买果泥
适合：
- 做菠萝风味基底、冰沙、奶昔、混合果茶
- 不需要明显果肉感
- 追求每杯味道一致

优点：
- 出杯快，标准化最强
- 没有切果损耗
- 适合和百香果、芒果、柠檬等复配

缺点：
- 没有果肉口感，产品显得“工业感”
- 香气通常弱于鲜果
- 如果菜单写“鲜果茶”，用果泥容易让顾客觉得不值

**果泥更适合做：**
- 菠萝冰茶基底
- 菠萝气泡饮
- 菠萝奶昔/冰沙
- 复合果茶中的风味补充

不适合单独作为“鲜果菠萝茶”的核心卖点。

## 建议的组合采购方案

大多数茶饮店最稳的是：

**鲜果 + 冷冻果丁/果泥组合**

例如：
- 鲜果：用于门店主推款、现切装饰、手捣菠萝
- 冷冻果丁：用于外卖款、稳定出杯
- 果泥：用于冰沙、基底、复配饮品

这样既能保留“鲜果”卖点，又能控制损耗和标准化。

## 按门店情况选

| 门店情况 | 建议 |
|---|---|
| 单店、客单价高、人手够 | 鲜果为主 |
| 单店、人手少、销量一般 | 鲜切果丁或冷冻果丁 |
| 外卖多、连锁、要标准化 | 冷冻果丁 + 果泥 |
| 主打冰沙/奶昔 | 果泥为主 |
| 主打果肉感 | 鲜果或冷冻果丁 |
| 预算低、想省人工 | 果泥，但别宣传“鲜果” |

## 采购时重点看什么

1. **糖度**：菠萝批次差异大，鲜果要测糖度或用糖酸比调整。
2. **品种**：台农、金钻、香水菠萝等香气和酸度不同，先小批量测试。
3. **加工形态**：
   - 果丁大小是否适合吸管
   - 冷冻果丁是否结块
   - 果泥是否含糖、含防腐剂
4. **出杯测试**：
   - 加茶后香气是否还在
   - 久放是否发苦、发涩
   - 和柠檬、百香果搭配是否冲突
5. **成本核算**：
   - 不要只看采购价，要算**每杯可食用成本 + 人工 + 损耗**。

## 最简建议

- **想做好喝、有卖点：买鲜果。**
- **想稳定、省人工：买冷冻果丁。**
- **想做基底、冰沙、标准化：买果泥。**
- **最推荐：鲜果做招牌，冷冻果丁做常规，果泥做复配。**
