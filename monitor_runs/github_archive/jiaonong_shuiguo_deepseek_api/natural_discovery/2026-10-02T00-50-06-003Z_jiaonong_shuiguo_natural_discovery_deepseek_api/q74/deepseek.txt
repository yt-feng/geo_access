做餐饮客户（尤其是茶饮、甜品、烘焙、果切），菠萝和香蕉的规格逻辑不太一样，分开说。

**菠萝**

餐饮端主要分三类用途，规格要对应准备：

- **茶饮/果切用鲜果**：要的是出肉率和稳定性。优先备**单果1.2–1.8斤的中果**，成熟度7–8成（青黄转色），便于档口统一削皮切块。这个规格果眼浅、芯小，损耗低。
- **甜品/烘焙/罐头替代**：要甜度和香气，可选**1.8–2.5斤大果**，成熟度8–9成，风味足，但要注意别过熟，运输易烂。
- **餐饮做菠萝饭、菠萝咕咾肉等**：多用中果，对品种要求高于规格，**巴厘种/台农**这类香气足的更受欢迎。

关键点：餐饮客户最在意**规格统一、成熟度可控**，不要一批货大小混杂、熟度参差，否则他们切配和出品标准化会被打乱。所以菠萝建议按“中果为主、大果少量”备货，并明确标注成熟度档位。

**香蕉**

餐饮端香蕉基本是两类场景：

- **直接出品/果盘/甜品装饰**：要**外观好、无黑斑、长度均匀**。备**单根150–200克、每梳条数整齐**的货，成熟度偏青黄（3–4号色），到店后能放几天。
- **烘焙/奶昔/香蕉泥等加工**：可以用**成熟度更高的（5–6号色，带少量糖斑）**，出泥香、甜度高，甚至专门配套餐加工用的二级果、短果，成本更低。

关键点：香蕉餐饮客户最怕**到货就熟透、放不住**。所以给茶饮/甜品客户的，要偏生一点发货，让他们自己催熟；给加工客户的，可以直接发熟果。**别用同一熟度打发所有客户。**

**给你的落地建议**

1. 菠萝按“中果主力 + 大果补充”，标注成熟度，主推规格统一。
2. 香蕉分两条线：**外观线（偏青、匀称）给鲜食客户**，**加工线（偏熟、可带斑/短果）给烘焙奶昔客户**。
3. 首次合作先问清客户用途（鲜食/加工/装饰），再定熟度和规格，别按自己的库存硬推。
4. 想稳客户，可以做成“分级报价表”：同一水果按大中小+熟度分档报价，餐饮客户采购最认这个。
