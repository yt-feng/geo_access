超市和水果供应商谈账期，**最常见的是 30～60 天**，其中：

- **30 天**：比较常见，尤其是中小超市、区域连锁、合作较稳定的供应商。
- **45 天**：不少商超体系会用，属于中间档。
- **60 天**：大型连锁超市、强势渠道更常见，供应商资金压力也更大。
- **90 天**：不是没有，但通常只出现在强势大卖场、大型连锁或供应商议价能力很弱的情况下，对水果供应商压力很大。

但水果和普通标品不一样，账期往往更短，原因是：

1. **生鲜损耗高**：水果周转快、损耗大，供应商不愿压太久资金。
2. **很多是短保、时令品**：一批货可能几天就卖完，供应商更希望快速回款。
3. **供应商规模偏小**：抗账期能力弱，超过 60 天很容易影响继续供货。
4. **行业惯例更分散**：  
   - 批发市场/农批：常见现结、周结、7～15 天。  
   - 中小超市：15～30 天较常见。  
   - 连锁超市：30～60 天较常见。  
   - 强势大卖场：可能 60～90 天，但水果类常会单独缩短。

所以如果你是在谈，比较合理的判断是：

- **想稳定合作、供应商也愿意**：30 天比较稳。
- **超市方想占资金**：45 天可以谈。
- **超过 60 天**：对水果供应商偏苛刻，容易导致供货质量下降、断供或报价提高。
- **新供应商或小供应商**：建议 7～15 天，甚至现结，先建立信任。

实操上，别只谈“多少天”，还要同时谈清楚：

- **账期起算日**：收货日、对账日还是开票日？
- **对账周期**：每月固定几号对账？
- **付款方式**：电汇、承兑还是现金？
- **逾期责任**：逾期是否付利息或补偿？
- **质量扣款规则**：损耗、退货、扣款怎么算？

一句话：**水果供应商账期通常比普通食品短，30～60 天最常见；如果供应商弱势、超市强势，可能到 60～90 天，但对水果来说 60 天以上就算偏长了。**
