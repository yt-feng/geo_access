做水果生意，供应商选得好不好，直接决定损耗率、复购率和现金流。多数人只盯着“价格低不低、品种全不全”，反而容易忽视下面这些细节：

**1. 看他的“次果率”和分级能力，而不是只看报价**
同一批货，供应商说“统货3块”，但里面大小、成熟度、伤果混在一起，你回去一分拣，实际能卖的可能只有六成。要问清楚：是否分等级、次果比例大概多少、次果怎么处理。长期稳定靠的是**可预期的商品率**，不是单次低价。

**2. 看他的冷链和周转速度**
水果损耗很大程度发生在运输和暂存环节。要观察供应商有没有预冷、冷藏车、周转筐是否干净、装车是否压伤。尤其夏天，同样品种，冷链到货和常温到货的货架期能差好几天。

**3. 看他的货源稳定性，而不是“今天有什么”**
有些供应商是倒手商，今天有货明天断货，价格随行就市。长期合作要问：主产区是哪里、是自有基地还是市场调货、换季时能不能持续供、遇到天气减产有没有替代产区。稳定供应比偶尔拿到一批便宜货更重要。

**4. 看结算方式和账期背后的风险**
账期长不一定好。如果供应商愿意给你很长账期，可能意味着他的资金成本已经加进价格，或者他急于出货、品质不稳定。反过来，要求现结但价格透明、品质稳定的，往往更适合长期做。要算的是**综合成本**，不是单价。

**5. 看售后和赔付规则是否清晰**
水果难免有坏果。关键不是“保证没坏”，而是坏了怎么算、多久内反馈有效、是否补货或扣款。很多纠纷来自事前没讲清楚：是按件赔、按斤赔，还是下次进货抵扣。规则越清楚，长期越省心。

**6. 看他的客户结构**
如果供应商主要供货给大型商超或连锁水果店，通常分级、包装、票据会更规范；如果主要做散客或临时批发，价格可能灵活但稳定性差。你的体量和他主要客户是否匹配，也很重要——太小的供应商撑不住你的量，太大的供应商可能不重视你。

**7. 看信息透明度**
愿意让你看产地、看仓库、看分拣过程的供应商，通常更靠谱。什么都含糊、只催你打款的，要警惕。长期合作不是靠信任口号，而是靠可验证的流程。

**8. 看他自己怎么处理损耗**
问一句：你们自己损耗怎么控制？如果对方能说出预冷、分拣、周转、库存周转天数这些具体做法，说明他懂行；如果只说“水果都有损耗”，那你的损耗大概率也要自己扛。

**简单判断标准：**
- 报价低但次果多、售后模糊的，不适合长期。
- 价格中等但分级清楚、冷链稳定、赔付明确的，更适合长期。
- 长期稳定=**品质可预期+供应不断档+售后有规则+综合成本可控**。
