判断香蕉批发对方是否稳定供货，核心不是听他怎么说，而是看他**有没有蕉园、能不能持续出货、出了问题时兜不兜底**。你可以按下面几个维度去核验，基本能筛掉大部分不靠谱的。

**1. 先分清他是哪一类供货方**
- **种植户/蕉园直供**：自己有地，价格低，但品种、数量受季节和天气影响，不一定常年稳定。
- **产地代收/合作社**：组织周边农户货源，通常比单个蕉园稳定，适合走量。
- **一级批发商/催熟商**：货稳定、规格统一，但价格高一层，适合做熟蕉或商超。
- **中间倒爷**：没园没仓，靠调货，价格可能便宜，但最容易断供、以次充好。

你要的“一手”，通常指前两类。倒爷再便宜也谈不上稳定一手。

**2. 看硬实力，不看话术**
- **有没有自己的蕉园或长期合作的农户**：能说清具体产区、面积、品种、上市时间。
- **有没有加工/催熟场地**：香蕉要催熟、分拣、打包，有场地说明他有持续操作能力。
- **冷库和运输能力**：香蕉怕冻怕热，稳定供货方一般有冷链或固定车队。
- **日/周出货量**：直接问他每天能稳定出多少件、多少吨，旺季淡季分别多少。答不上具体数字的，基本不稳。
- **是否只做香蕉**：专做香蕉的通常比什么都卖的更稳、更懂行。

**3. 用“连续小单”试供**
别一上来就签大单。先下**3~5次小批量**，每次隔几天，观察：
- 到货时间是否稳定；
- 重量、条数、成熟度是否一致；
- 坏果率、青黄比例是否波动大；
- 临时加单、改规格时他能不能配合。

能连续几次稳定交付的，才值得谈长期。

**4. 重点问清“断供怎么办”**
稳定供货的关键在异常处理：
- 下雨、台风、寒潮导致减产时，他有没有备用产区或备用货源？
- 缺货提前几天通知？
- 质量问题怎么赔、怎么补？
- 价格波动时是锁价还是随行就市？锁价能锁多久？

愿意把赔付和替补方案写进合同的，可信度明显更高。

**5. 实地或视频核验**
- 有条件就去产地看蕉园、看仓库、看催熟房。
- 没条件就要求视频看现场，注意背景是否一致、是否像临时摆拍。
- 查他的营业执照、合作社资质、过往发货记录、物流单号。
- 找同行打听：这个人在产地的口碑、有没有拖欠农户或客户的情况。

**6. 几个危险信号**
- 报价明显低于市场价，还说“多少都有”；
- 不肯视频、不肯给产地具体位置；
- 每次发货地、包装、规格都不一样；
- 催你打大额预付款；
- 出问题就推给天气、物流，从不担责。

**实操建议：**
先按“小单试供 + 视频验场 + 问清断供赔付”三步走。连续试供3次都稳定，再逐步加大采购量。价格可以谈，但稳定供货能力必须排在价格前面。对批发档口来说，断货和品质波动带来的损失，通常比每斤贵几分钱大得多。
