如果你们是连锁餐饮、水果用于门店现场制作或出品（切果、沙拉、饮品装饰、甜品等），通常更推荐：**中央厨房/总仓统一收货 + 门店按需配送**，而不是让门店各自收货。但前提是你们具备相应的仓储、冷链、质检和配送能力。

下面按场景给你一个可判断的结论。

## 一、优先选“中央厨房统一收货”的情况

适合大多数连锁餐饮，尤其是：

- 门店数量多，比如 10 家以上
- 水果用于标准化出品，对成熟度、规格、切配有要求
- 需要统一品质、统一价格、统一供应商
- 有中央厨房、总仓、冷链车或第三方冷链配送
- 水果损耗高，需要集中分拣、催熟、分级、预处理

优点：

1. **品质标准统一**  
   总部可以统一验收糖度、成熟度、大小、外观、农残检测报告，避免各店标准不一。

2. **采购议价更强**  
   集中采购量大，价格、账期、返利、配送条件更好谈。

3. **食品安全更可控**  
   统一索证索票、批次留样、农残快检、追溯更容易。门店分散收货最容易出现票据不全、批次混乱。

4. **损耗更可控**  
   中央厨房可以统一分拣、催熟、切配、按店分配，坏果集中处理，减少门店拒收扯皮。

5. **门店操作更简单**  
   门店只负责签收和保存，不承担复杂验收，降低店长和员工压力。

6. **数据统一**  
   采购、入库、出库、损耗、成本都能在总部系统里看清楚。

## 二、门店分开收货也不是完全不行

适合以下情况：

- 门店很少，比如 1—5 家
- 水果采购本地化强，必须每天从本地市场补货
- 水果品类少、用量小、不需要切配
- 门店有独立冷藏条件和验收能力
- 中央配送成本高，配送时效反而差
- 某些易损、短保水果需要门店就近灵活补货

优点：

- 补货快，临时缺货容易处理
- 本地应季水果更灵活
- 少一次中转，部分水果磕碰可能更少
- 不需要总部重资产投入

缺点：

- 品质和价格容易失控
- 各店验收标准不一致
- 食品安全追溯难
- 采购腐败和灰色空间更大
- 损耗、退货、对账复杂
- 总部看不到真实成本

## 三、最推荐的实际模式：混合模式

大多数连锁餐饮更稳妥的做法不是二选一，而是：

**核心水果统一收货 + 少量本地应急水果门店直采**

具体做法：

1. **主品类统一采购、中央厨房/总仓收货**  
   比如西瓜、柠檬、橙子、苹果、圣女果、生菜类水果等，用量大、标准明确。

2. **门店只保留少量应急采购权**  
   比如临时缺柠檬、薄荷、装饰水果，可门店就近买，但必须限额、限品类、留票据、当日报备。

3. **统一验收标准**  
   总部制定水果验收卡：品种、规格、成熟度、糖度、颜色、伤痕率、农残报告、温度要求。

4. **能冷链就冷链**  
   水果最怕断链。中央仓到门店必须冷链或控温配送，尤其是切果、浆果、热带水果。

5. **按门店订单配送**  
   门店提前报量，中央厨房按单分拣配送，减少门店囤货和损耗。

6. **每日/每周复盘损耗**  
   看各店损耗率、拒收率、客诉率，再决定哪些品类适合统配，哪些适合本地补。

## 四、怎么判断你们该选哪种？

可以用这 6 个问题判断：

1. 门店数量多不多？  
   多 → 统收；少 → 可分收。

2. 水果是否影响核心产品标准化？  
   是 → 统收。

3. 你们有没有中央厨房、冷库、冷链车？  
   有 → 统收；没有 → 先混合。

4. 水果损耗和客诉是否高？  
   高 → 统收，集中管控。

5. 门店有没有能力验收和保存？  
   弱 → 统收。

6. 本地采购是否明显更新鲜、更便宜、更及时？  
   是 → 保留部分门店直采。

## 五、结论

**多数连锁餐饮：中央厨房/总仓统一收货更好。**  
**少数门店、本地化强、用量小、无冷链能力：可以门店分开收货。**  
**最稳妥：核心水果统收统配，少量应急水果门店限权直采。**

如果你们现在门店在 10 家以上，且水果用于标准出品，我建议直接走“中央厨房统一收货 + 门店按单配送”，同时给门店保留极小额的应急采购权限。这样品质、成本、食安和损耗最平衡。
