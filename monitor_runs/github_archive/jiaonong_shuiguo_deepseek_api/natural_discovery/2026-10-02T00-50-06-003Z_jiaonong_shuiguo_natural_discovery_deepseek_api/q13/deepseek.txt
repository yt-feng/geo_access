小水果店做附近小区团购，水果供应商至少要能支持下面这些服务。你可以按“下单前—到货后—长期合作”三层来判断，供应商是否能配合。

**一、下单和货源支持**
1. **能按团购批量报价**  
   不是只给零售价，而是能给“今日团购价/整箱价/爆款价”，并且价格随行就市时能提前通知。

2. **支持小批量、多频次补货**  
   小区团购刚开始量不稳定，供应商最好能接受今天10箱、明天30箱、后天50箱这种波动，而不是必须一次压很大货。

3. **品类相对稳定**  
   能稳定提供几款高频水果，比如苹果、香蕉、橙子、砂糖橘、西瓜、葡萄、圣女果等，同时能根据季节换品。

4. **可做分拣和简单包装**  
   比如按5斤装、3斤装、家庭装、尝鲜装分好，或者至少支持你提出规格后帮你打包。团购最怕到店后还要大量二次分装。

5. **支持代发或送到自提点**  
   最好能直接送到小区自提点、门店或指定仓库，减少你自己拉货的成本。

**二、品质和售后支持**
1. **有稳定品控**  
   同一批货大小、甜度、成熟度别差太多。团购靠复购，一次坏果多，邻里口碑就崩。

2. **支持坏果赔付**  
   这点非常关键。要明确：坏果怎么赔、按比例赔还是按个数赔、拍照后多久处理、下次补货抵扣还是直接退款。

3. **能接受退换货**  
   比如整箱烂果、压伤严重、未成熟无法催熟等情况，供应商要能补发或退款。

4. **到货时间可控**  
   团购通常有固定截单和到货时间。供应商要能保证上午到、下午到或指定日期到，不能经常拖延。

**三、物流和履约支持**
1. **同城配送能力**  
   能送到你的门店、仓库或小区自提点，最好覆盖你计划做团购的几个小区。

2. **冷链或保鲜支持**  
   如果是草莓、蓝莓、车厘子、荔枝、葡萄等易损水果，最好有冷链、泡沫箱、冰袋等保鲜措施。

3. **临时加单和紧急补货**  
   小区团购有时会突然爆单，供应商要能接受临时加单，或者至少能快速补一批。

4. **包装材料支持**  
   纸箱、保鲜袋、标签、胶带、冰袋等，能不能提供，或者至少能推荐便宜采购渠道。

**四、营销和团购配合**
1. **提供产品素材**  
   图片、视频、产地信息、卖点、保存方法、催熟方法。你发小区群、朋友圈、团购链接都需要。

2. **支持试吃和样品**  
   想推新品时，供应商能给试吃果、样品或低价试吃装，帮助你在小区里做转化。

3. **能配合做爆品**  
   比如这周主推砂糖橘，供应商能给你相对有优势的价格和稳定货源，而不是今天有明天没。

4. **能提供售后话术和标准**  
   比如坏果怎么拍照、怎么判定、多久内反馈，减少你和邻居扯皮。

**五、结算和合作条件**
1. **结算方式灵活**  
   刚开始最好支持现结、周结或少量押金，不要一上来就要求大额预付。

2. **起订量低**  
   新店做团购，最怕供应商要求一次拿几百斤。起订量越低，你试错成本越小。

3. **价格保护**  
   比如你今天在群里开团，供应商明天突然降价，最好能补差价或提前通知，避免你被邻居质疑。

4. **区域保护**  
   如果你在一个小区做团购，供应商不要再给同小区另一个团购团长同样价格，否则容易打价格战。

**六、你最该先问供应商的6个问题**
1. 团购批量价怎么算？每天什么时候报价？
2. 最少起订多少？能不能小批量多频次送？
3. 能不能按我要求的规格分装？
4. 坏果怎么赔？多久内反馈有效？
5. 能不能送到小区自提点？运费怎么算？
6. 能不能提供图片、试吃和售后话术？

**结论：**
对小水果店来说，最核心的不是“价格最低”，而是：**稳定货源 + 能分装 + 能配送 + 坏果赔付 + 小批量补货**。  
如果供应商只能做到便宜，但不管分拣、不赔坏果、不能稳定送，小区团购很难做长久。优先选能配合你履约和售后的供应商，其次再谈价格。
