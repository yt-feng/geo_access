食堂采购香蕉要减少“熟过头”的浪费，核心是**控制采购成熟度、分批到货、按成熟度分流使用、改善存放条件**。可以按下面执行：

1. **采购时不要只买“黄的”**
   - 优先采购**青黄相接、果柄青绿、果身硬实**的香蕉。
   - 避免采购已经出现黑斑、果柄发黑、整串发软的香蕉。
   - 和供应商约定：到货成熟度以“可存放3—5天”为标准，而不是“当天可吃”。

2. **分批到货，而不是一次囤太多**
   - 按食堂日均用量计算，每次采购量控制在**2—3天用量**。
   - 如果供应商能配合，采用“小批量、多频次”配送。
   - 周一、周三、周五分批到货，比一次进一周量更不容易熟过头。

3. **到货后先分级**
   - 青硬：放常温、通风处，后熟。
   - 微黄：优先安排1—2天内食用。
   - 已熟软：当天使用，做香蕉牛奶、香蕉粥、香蕉饼、烘焙等。
   - 黑斑严重但未腐坏：尽快加工，不建议直接售卖。

4. **存放要避开“催熟条件”**
   - 香蕉不要和苹果、梨、西红柿等释放乙烯较多的果蔬混放。
   - 放在**阴凉、通风、避光**处，不要堆压。
   - 不要直接放冰箱冷藏未熟香蕉，容易冻伤变黑。
   - 已熟香蕉若需延后1—2天使用，可冷藏，但表皮会变黑，内部仍可加工。

5. **按成熟度设计菜单**
   - 微黄香蕉：直接作为水果发放。
   - 熟软香蕉：做香蕉奶昔、香蕉燕麦、香蕉蛋糕、香蕉派、香蕉粥。
   - 次果或外观差的：用于加工，不进入直接售卖窗口。
   - 提前和档口沟通：哪些香蕉必须当天消化，哪些可以再放一天。

6. **建立简单台账**
   - 记录每天到货量、成熟度、使用量、剩余量。
   - 连续记录1—2周后，就能算出更准确的采购量。
   - 比如：日均实际消耗80斤，就采购80—100斤，分2次到货，而不是一次买200斤。

7. **和供应商约定退换或加工支持**
   - 合同里写明成熟度标准、到货验收标准。
   - 对成熟过快的批次，协商退换、折价或转为加工用途。
   - 如果供应商能提供“青蕉+催熟指导”，比直接送熟蕉更可控。

8. **最后手段：及时加工，不要等坏**
   - 一旦出现大面积变软，不要再等“明天再说”。
   - 当天加工成香蕉泥、冷冻香蕉块、香蕉干、烘焙原料。
   - 熟香蕉去皮后分装冷冻，可延长使用时间，适合做奶昔和烘焙。

一句话执行方案：**买青一点、分次到货、到货分级、避乙烯混放、熟软就加工，按日均消耗而不是按仓库空间采购。**
