这三者不是同一优先级，而是有先后顺序的“底线—成本—效率”关系：

1. **食品安全是底线，优先于价格和准时**
   企业食堂涉及群体性用餐，水果一旦出现农残超标、霉变、致病菌污染等问题，可能引发多人健康事件和法律责任。因此必须先满足：
   - 供应商资质齐全，可追溯；
   - 每批次有农残检测或合格证明；
   - 验收时检查新鲜度、霉变、异味、破损；
   - 有留样、退换货和应急处置机制。

2. **价格是长期经营指标，但不能突破安全底线**
   水果采购价格直接影响食堂成本。合理做法是：
   - 在合格供应商之间比价；
   - 用季度/月度框架协议锁定价格波动；
   - 按当季水果调整菜单，降低采购成本；
   - 不以“最低价”作为唯一中标标准，否则容易牺牲品质和安全。

3. **配送准时是运营保障，影响供餐稳定性**
   配送不准时会导致：
   - 当日水果无法供应；
   - 临时替代增加成本和食品安全风险；
   - 食堂供餐计划被打乱。
   所以配送准时应作为合同履约条款，但一般排在食品安全之后、与价格共同权衡。

**结论：**
企业食堂采购水果，优先级应是：**食品安全 > 配送准时/价格（视企业运营模式权衡）**。  
更准确地说：**食品安全是一票否决项；价格和配送准时是在安全合格基础上的核心竞争项。** 如果食堂供餐时间刚性很强，配送准时可以排在价格之前；如果成本压力大，则可在安全达标前提下强化比价和季节性采购。
