**常见支持形式：**

1. **陈列支持**
   - 提供陈列道具、堆头围挡、价签牌、地贴
   - 派理货员或促销员到店帮忙摆台、补货、翻堆
   - 承担部分堆头费、端架费，或给"陈列返利"

2. **海报支持**
   - 提供产品图片、文案、卖点素材
   - 分摊DM海报的印刷/上刊费用（常见叫"海报费""DM费"）
   - 定制店内吊旗、爆炸贴、立牌

3. **试吃支持**
   - 提供试吃样品（免费或按成本价）
   - 派试吃员/促销员，或承担试吃员工资
   - 提供试吃台、一次性用品、试吃装

**怎么谈更有效：**

- **提前锁定**：促销档期前和采购一起跟供应商谈，写进促销协议，别临时要。
- **用销量换支持**：承诺订货量、陈列位置、档期时长，供应商更愿意投入。
- **分清形式**：是给货（买赠、搭赠）、给钱（费用补贴）还是给人（促销员），三者成本不同。
- **注意成本归属**：试吃样品和促销员工资往往是大头，明确谁出。
- **合规**：试吃涉及食品安全，样品来源、保质期、操作规范要留记录。

**实操建议**：先列一个"我们要什么支持"的清单，按重要性排序，跟供应商一家家谈，通常大品牌支持力度大、条件也硬，中小供应商更灵活但资源有限。
