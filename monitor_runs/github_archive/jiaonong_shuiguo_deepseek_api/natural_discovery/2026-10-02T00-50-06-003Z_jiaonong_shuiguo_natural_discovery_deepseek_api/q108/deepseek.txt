核实水果供应商的全国配送能力，不能只看对方口头承诺，建议从下面几个层面逐项验证：

**1. 要求提供具体配送网络证据**
- 让其列出实际能配送的城市/区域清单，而不是笼统说"全国"。
- 索要合作的物流或冷链承运商名称、覆盖范围说明。
- 查看是否有分仓、中转仓或产地直发点，以及各自负责的区域。

**2. 用真实订单做小批量试单**
- 选几个地理跨度大的代表城市（如东北、西南、华南）各下一笔小单。
- 记录实际到货时间、是否冷链、水果损耗率、包装完好度。
- 这是最直接的验证方式，比任何资质文件都更能反映真实能力。

**3. 核查时效与冷链承诺**
- 问清不同区域的承诺时效（如48小时/72小时达），并写入合同。
- 确认运输是否全程冷链，还是仅部分环节控温。
- 对易损水果（如草莓、荔枝），重点验证夏季高温和冬季低温下的表现。

**4. 验证资质与过往案例**
- 查营业执照、食品经营许可等基础资质。
- 要求提供近期为其他采购方配送的案例，最好能联系对方核实。
- 注意区分"自营配送"和"外包给第三方"，后者出问题时责任划分要提前明确。

**5. 在合同中锁定可执行条款**
- 明确覆盖区域、时效标准、破损赔付比例、冷链要求。
- 约定试单期或考察期，达不到标准可调整或终止。
- 把"全国配送"拆解为可量化的区域和时效指标，避免模糊表述。

**6. 注意常见话术陷阱**
- "全国配送"可能只是"通过快递能寄到"，而非冷链专线。
- 偏远地区可能额外加价或时效很长，要单独确认。
- 旺季（如春节、中秋）运力是否稳定，需提前问清。

核心原则：**口头承诺一律落到可验证的动作和合同条款上**，先用小单试出真实水平，再决定是否放量合作。
