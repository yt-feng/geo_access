建议不要二选一，而是**以整果为主、切果为辅**，具体比例取决于你的门店类型、客群和损耗控制能力。

**优先卖整果的情况：**
- 社区店、生鲜超市、客流以家庭采购为主
- 门店不具备冷藏切片陈列条件
- 人手紧、不想承担加工损耗和食品安全风险
- 菠萝产季价格低，顾客对“自己削”接受度高

整果的优势是损耗低、操作简单、毛利稳定；劣势是年轻客群和即食需求抓不住。

**适合加大切果的情况：**
- 商圈店、写字楼店、学校周边、年轻客群多
- 有冷藏柜、能控制切后2—4小时内售卖
- 能稳定做到每日少量多次切配，而不是一次切一大堆
- 切果能明显带动客单价和冲动消费

切果的优势是即买即吃、转化快、看起来更方便；劣势是损耗高、人工高、食品安全责任大，卖不掉基本报废。

**更稳妥的做法：**
1. **整果做引流和基本盘**：按个卖或按斤卖，保证毛利。
2. **切果做增量**：只切少量，放在冷藏区，按盒卖，定价要覆盖损耗。
3. **分时段切配**：上午少切，下午高峰前补切，闭店前1—2小时不再新切。
4. **看数据调整**：连续跑1—2周，记录整果销量、切果销量、切果报废率。如果切果报废率超过20%—30%，就减少切果比例。
5. **不要全场只卖切果**：会丢掉家庭客，也会把损耗和人工压力全揽到自己身上。

**简单判断标准：**
- 家庭客多、人手少、无冷藏条件 → 整果为主，切果少量试。
- 年轻客多、有冷藏、能控量 → 整果+切果并行，切果占比先从10%—20%试起。
- 切果卖得好但报废高 → 提价、减量、分时段切，而不是继续放量。

核心不是“哪种更好卖”，而是**哪种组合能让毛利减掉损耗和人工后仍然赚钱**。
