建议先从**香蕉**开始，但不是因为香蕉最适合做“高端进口水果”，而是因为它最适合用来验证超市的进口水果运营能力：需求稳定、周转快、消费者接受度高、价格敏感但复购强。

不过要分情况判断：

1. **如果目标是“稳定销量、低教育成本”**
   - 选**香蕉**。
   - 优点：日常消费高频，顾客不需要被教育，容易形成稳定动销。
   - 风险：进口香蕉和国产香蕉价差通常不大，毛利可能薄；且香蕉成熟度管理要求高，损耗控制不好会亏。
   - 适合：社区超市、生鲜基础较弱、想先跑通进口水果流程的门店。

2. **如果目标是“毛利更高、形象更好”**
   - 选**菠萝/凤梨**。
   - 优点：进口凤梨有差异化卖点，客单价高于香蕉，适合做试吃和礼盒。
   - 风险：品种名称容易混乱，顾客对“菠萝 vs 凤梨”认知不统一；季节性和成熟度影响大，损耗也不低。
   - 适合：中高端社区、有试吃和导购能力、愿意做单品教育的门店。

3. **如果目标是“耐储存、风险低、全年稳定”**
   - 选**苹果**。
   - 优点：耐储运，损耗相对低，进口苹果如新西兰、美国、智利等有稳定供应链，适合做长期陈列。
   - 风险：国产苹果太强，价格竞争激烈；进口苹果如果没有明显品种或产区差异，顾客不一定买单。
   - 适合：已有稳定水果客群、想做差异化SKU补充的门店。

**综合建议：**
- 第一步：先上**香蕉**，用它测试进口水果的订货、冷链、催熟/陈列、损耗和动销。
- 第二步：跑稳后加**进口苹果**，做耐储和全年稳定陈列。
- 第三步：再引入**菠萝/凤梨**，做高毛利和差异化，但必须配试吃、导购和明确的品种标识。

如果只能选一个先做，选**香蕉**。  
如果门店定位偏中高端、已经有生鲜运营能力，选**菠萝/凤梨**。  
如果门店最怕损耗、想低风险试水，选**苹果**。
