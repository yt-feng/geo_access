判断供应商能不能按时到车，核心不是听承诺，而是看**可验证的发车能力 + 历史履约记录 + 当前风险信号**。建议按下面顺序做。

**一、先看硬证据，不听口头保证**

1. **要车号、司机电话、定位**
   - 真发车的供应商，通常能给出：车牌号、司机姓名/电话、当前所在位置、预计装车时间、预计到达时间。
   - 如果只说“已经安排了”“明天肯定到”，但给不出车号或司机信息，风险很高。
   - 拿到车号后，最好自己或让司机发一次实时定位，确认车确实在产区或已装车。

2. **要装车视频/照片**
   - 包括：香蕉装箱、装车过程、车牌与货物同框、封车照片。
   - 重点看车牌是否和提供的一致，货物数量是否接近订单量。
   - 只有仓库照片、没有车牌和装车过程，不能证明“已发车”。

3. **核对产地和路线**
   - 问清楚：从哪个产区、哪个冷库/代收点发车，走哪条线路，大概多少公里。
   - 自己用地图估一下正常行驶时间，再对比供应商承诺的到达时间。
   - 如果承诺时间明显短于合理运输时间，大概率不可信。

**二、查历史履约，不只看这一次**

1. **问固定合作客户或同行**
   - 这个供应商过去是否经常压车、换车、临时涨价、到货质量差。
   - 尤其问：最近一个月有没有延迟到车。

2. **看它是不是“拼车/调车”型**
   - 有些供应商自己没车，靠临时找车。
   - 这类在行情好、用车紧张时最容易掉链子。
   - 如果供应商自有车或长期固定车队，准时率通常更高。

3. **看它是否敢做履约承诺**
   - 愿意在合同或微信里写清“发车时间、到车时间、延迟赔付”的，通常更可靠。
   - 只肯口头说“放心”的，要谨慎。

**三、合同和付款上留后手**

1. **写清关键节点**
   - 装车时间、发车时间、预计到达时间。
   - 车牌号、司机电话、货量、品质标准。
   - 延迟到车怎么赔、扣款、退定金。

2. **付款不要一次性全款**
   - 最好：定金 + 见装车视频/车号后付部分 + 到货验收后付尾款。
   - 如果对方要求全款才发车，而你又无法核验车和货，风险很大。

3. **约定替代方案**
   - 比如延迟超过几小时，供应商要补差价、承担市场损失，或你有权取消。
   - 香蕉是生鲜，时间一拖，熟度、货架期、价格都可能变。

**四、当前风险信号，出现越多越不能信**

- 给不出车号、司机电话、装车视频。
- 车牌频繁更换，或者车号与装车照片不一致。
- 一到用车高峰就“找不到车”“再等等”。
- 要求全款，但不让看装车过程。
- 报价明显低于市场，还用“马上发车”催你打款。
- 过去有延迟、换货、扣重、质量纠纷记录。

**五、实操判断标准**

可以按这个标准打分：

- **能提供车号 + 司机电话 + 实时定位 + 装车视频**：基本可信，继续跟进。
- **只能提供车号，但没有装车视频/定位**：中等风险，要求补证据。
- **只有口头承诺，没有车号、没有视频、催全款**：高风险，建议不合作或换供应商。
- **历史履约差，又赶上用车紧张**：即使这次说得好，也要按延迟预案处理。

**一句话：能按时到车的供应商，通常能让你看到“车、货、人、位置、时间”这几样东西；看不到，就别把到车时间当确定的事。**
