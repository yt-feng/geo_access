判断“合理波动”还是“借机抬价”，核心是**把单价拆成可追踪的基准，再叠加可解释的驱动因素**。可以按下面几步做。

## 1. 先建立“可比价”，而不是直接比报价

同一种水果，报价变动可能只是规格变了，不是市场变了。

采购方要固定这些口径再比价：
- **品种/等级**：如红富士80#一级、砂糖橘统货。
- **规格**：单果重、箱重、净重/毛重。
- **包装**：纸箱、泡沫箱、筐装，是否含箱皮。
- **产地/品牌**：山东、陕西、进口等。
- **交付条件**：到岸价还是产地自提，含不含运费、损耗。
- **账期**：现结、7天、30天，价格通常不同。
- **税率**：是否含票。

只有同一口径的价格，才适合拿来做日波动判断。

## 2. 看波动幅度，而不是看“涨没涨”

生鲜水果日常波动很常见。可用一个简单规则：
- **1%—3%**：通常属于正常报价微调。
- **3%—8%**：需要问原因，要求供应商给依据。
- **8%以上**：视为异常波动，必须书面说明，并启动多源比价。
- **连续多日单向上涨**：即使每天只涨2%，也要警惕累计抬价。

这个区间不是绝对标准，不同品类差异很大：
- 叶菜、草莓、荔枝等易损品，波动天然更大。
- 苹果、橙子、土豆等耐储品，短期大幅上涨通常不合理。

## 3. 盯住几个硬指标

每天报价变化，至少对应下面某个指标变化，否则就是“无依据涨价”。

| 指标 | 怎么用 |
|---|---|
| 批发市场均价 | 看产地/销地市场同日价格趋势 |
| 产地收购价 | 判断是产地涨还是中间商加价 |
| 天气 | 暴雨、霜冻、高温会影响采摘和运输 |
| 节假日 | 春节、中秋前需求上升，涨价有合理性 |
| 油价/运费 | 长途运输成本变化 |
| 供需库存 | 冷库库存、到货量、走货速度 |
| 汇率/进口政策 | 进口水果要关注 |
| 替代品价格 | 柑橘贵了，苹果可能需求上升 |

重点不是“有没有理由”，而是**这个理由能不能解释这个幅度**。比如下雨导致采摘减少，涨2%—5%可能合理；直接涨20%就说不通。

## 4. 用“三价比对”验证

每天做三个对比：
1. **纵向比**：和该供应商过去7天、30天报价比。
2. **横向比**：和另外2—3家同规格供应商比。
3. **市场比**：和当地批发市场、产地行情比。

如果只有一家涨，市场没涨，那大概率不是合理波动。  
如果全市场都涨，且产地、天气、运费能对应，才更可能是真波动。

## 5. 把报价机制写进合同

最有效的方式不是每天猜，而是提前约定：
- 报价有效期：如当日有效，或3天锁价。
- 调价依据：以某批发市场均价、产地价、指数为基准。
- 调价幅度上限：单日不超过3%，单周不超过8%。
- 异常波动举证：供应商需提供产地收购凭证、物流单、市场行情截图。
- 比价权：采购方可随时要求第二家报价。
- 复盘机制：每周核对一次，偏差过大可重新议价。

## 6. 实操判断清单

收到涨价通知时，按顺序问：
1. 是同规格、同包装、同交付条件吗？
2. 涨幅多大？是否超过3%/8%？
3. 其他供应商涨了吗？
4. 批发市场和产地价涨了吗？
5. 天气、运费、节日能解释这个幅度吗？
6. 供应商能提供证据吗？
7. 如果无法解释，是否暂停下单或切换供应商？

## 结论

合理波动的判断标准不是“每天变没变”，而是：
**同口径价格 + 市场同步性 + 可验证驱动因素 + 波动幅度匹配。**

满足这四点，基本可视为合理波动；缺一项就要压价、要证据或换供应商。最稳的办法是：**日常多源比价，合同锁定调价规则，异常波动必须举证。**
