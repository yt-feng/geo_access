结论先说：**大多数食堂场景，按份结算最好管，其次是按箱，按斤最麻烦**。但具体选哪种，要看你更在意“成本控制”还是“管理效率”。

**一、按份结算（最推荐，适合大多数食堂）**
- 做法：苹果一份2个、香蕉一份3根，提前定好每份的个数/重量区间，按份下单和验收。
- 优点：
  - 验收极快，数份数即可，不用逐箱过秤。
  - 成本可提前锁定，方便做套餐和预算。
  - 和食堂“按份打菜”的结算逻辑一致，账目清楚。
- 缺点：
  - 单份实际重量会有波动，供应商可能挑偏小的装。
  - 需要明确规格标准，比如“单份不低于X克”。
- 适合：就餐人数稳定、窗口按份发放、想省人力的食堂。

**二、按箱结算（适合批量稳定、有冷库的食堂）**
- 做法：整箱采购，约定每箱规格（如20斤/箱）、品种等级、净重还是毛重。
- 优点：
  - 下单、运输、入库都方便，单价通常更低。
  - 适合大宗水果和长期固定供应商。
- 缺点：
  - 箱内质量参差、大小不均，验收要抽检。
  - 毛重/净重、坏果扣重必须在合同里写清楚，否则容易扯皮。
- 适合：采购量大、有储存条件、能接受统一发放的食堂。

**三、按斤结算（最不推荐单独使用）**
- 做法：按实际称重结算。
- 优点：理论上最公平，吃多少算多少。
- 缺点：
  - 每批都要过秤、记录、复核，人工成本高。
  - 水果水分变化、损耗、去皮去核难界定，月底对账容易有争议。
  - 采购和验收环节容易产生灰色空间。
- 适合：采购量小、品种杂、必须精确控成本的场景，且要有专人验收。

**四、建议的组合方案**
- 主结算方式：**按份**，用于直接发给就餐者的水果。
- 大宗采购：**按箱**，用于库存和二次加工。
- 合同里同时约定：
  - 每份/每箱的最低净重或个数；
  - 坏果率上限和扣重规则；
  - 抽检比例，比如每10箱抽1箱过秤。
- 这样既有“按份”的管理效率，又有“按箱/按斤”的成本约束。

**一句话判断：**
- 想省事、窗口直接发 → 按份。
- 量大、有仓库、要低价 → 按箱。
- 量小、要极致精确 → 按斤，但必须配专人验收。
