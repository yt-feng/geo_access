**供应商一般能给的支持**

1. **价格支持**
   - 周末特价供货：针对1-2个爆款单品，按平时价再降5%-15%，或给“周末专供价”。
   - 满额返利：比如周末进货满一定金额返点、返货。
   - 搭赠：进10箱送1箱，相当于变相降价。
   - 账期支持：周末促销压货，允许延后几天结算。

2. **物料支持**
   - 海报、价签、吊旗、展架、围挡。
   - 促销台、堆头围布、试吃盒、一次性叉子。
   - 印有品牌logo的购物袋、气球、小礼品。
   - 部分供应商还能提供临时促销员或试吃推广。

3. **活动支持**
   - 联合做“品牌周”“产地直供周”。
   - 供应商出费用做店内试吃、买赠。
   - 提供爆款货源保障，避免周末断货。

**供应商愿不愿意给，关键看这几点**

- **采购量**：你周末能走多少量，是最硬的筹码。
- **是否主推**：你愿不愿意把好位置、好排面给它的单品。
- **合作稳定性**：长期稳定进货的店，更容易拿到支持。
- **回款信用**：不拖款、不压账，供应商更愿意投入。
- **谈判时机**：提前3-7天谈，别到周五下午才要。

**你可以这样谈**

“这周末我想主推你家XX单品，计划做门店特价和堆头，预计能卖XX箱。你能不能给个周末专供价，或者支持点海报、价签、试吃物料？如果效果好的话，后面每周固定推。”

**最实用的做法**

- 选1-2个单品做爆款，不要全店都求支持。
- 先找平时合作最好、走量最大的供应商谈。
- 把“你能给它什么”说清楚：好位置、主推、稳定采购、现场拍照反馈。
- 价格支持和物料支持可以分开要，先要价格，再要物料，成功率更高。

如果供应商不给，也可以退一步要：免费配送、临时调货、延长账期、搭赠小单品，这些也算实际支持。
