选学校食堂水果供应商，核心不是“找最便宜的”，而是找**能稳定供货、质量可控、票据齐全、出了问题能追责**的供应商。香蕉、苹果、橙子这类常见水果，建议按下面几个维度来筛。

**1. 先明确你们食堂的采购特点**
- 用量大、频次高：通常每周多次配送，要求供应商有稳定货源。
- 品种固定：香蕉、苹果、橙子属于大宗常见果，重点看分级、成熟度、损耗率。
- 安全要求高：学校食堂一般要索证索票，最好能提供检测报告或产地证明。
- 价格敏感但不能只看低价：低价往往伴随次果、催熟不均、损耗大。

**2. 供应商来源优先级**
可以按这个顺序找：
1. 当地大型农产品批发市场里有固定档口的果商；
2. 本地水果种植合作社或基地直供；
3. 有资质的生鲜配送公司；
4. 大型商超或电商平台的食堂配送渠道。

对学校来说，**本地有实体档口或配送中心的供应商**通常更稳，因为退换货、补货、现场看货都方便。

**3. 重点考察这几项**
- **资质**：营业执照、食品经营许可证、供货凭证、检验合格证明。
- **货源**：香蕉看产地和催熟能力，苹果看产地和分级，橙子看品种和糖酸比。
- **分级标准**：要求明确规格，比如苹果直径、橙子单果重、香蕉每把根数，避免到货以次充好。
- **配送能力**：能否按约定时间送到，是否有冷链或常温车，坏果能否当场退换。
- **报价方式**：按斤、按箱还是按份，是否含税含运费，价格随行就市时怎么调价。
- **结算方式**：月结还是周结，是否需要押金，发票能否开。

**4. 建议的筛选流程**
1. 先找 3—5 家候选供应商；
2. 要求提供资质、报价单、样品；
3. 组织食堂、后勤、财务一起看样比价；
4. 小批量试供 2—4 周，重点看到货质量、损耗、准时率；
5. 试供合格后签合同，明确品种、规格、价格、配送、退换、违约责任；
6. 定期评估，保留 1 家主供应商 + 1 家备选供应商。

**5. 香蕉、苹果、橙子的特别注意点**
- **香蕉**：最容易因催熟和运输出问题。要约定成熟度，比如到货时青黄比例，避免当天全熟或全是青的。
- **苹果**：耐储存，但要注意大小分级和碰伤。可要求按直径分档，比如 75、80、85。
- **橙子**：看皮厚、水分和糖度。可要求现场抽检，避免酸果、干果混入。

**6. 合同里一定要写清楚**
- 品种、规格、等级、单价、数量；
- 配送时间、地点、频次；
- 验收标准和不合格处理方式；
- 退换货时限和费用承担；
- 食品安全责任和赔偿条款；
- 价格调整机制；
- 发票和结算周期。

**简单判断标准：**
如果一家供应商能做到：**资质齐全、有固定货源、能按规格送货、坏果包退、价格透明、票据正规**，就可以进入试供。只靠低价、没有固定档口、不能提供票据的，不建议长期合作。
