核心原则：**把「补货」写成可执行、可追责、能兜底的条款，而不是只写一句“供应商负责补货”。** 下面按「事前约定 → 到货判定 → 补货执行 → 营业兜底」给你一套可直接用的约定框架。

## 一、事前就要约定的关键条款

**1. 明确验收标准，别用“新鲜”“合格”这种模糊词**
- 写清品种、规格（单果克重/直径）、成熟度、糖度、外观标准（无腐烂、无压伤、无虫眼等）。
- 附上图片或样品封样，双方各留一份，作为争议依据。
- 约定抽检比例和方法（如每箱抽检10%，或按到货批次抽检）。

**2. 明确“不合格”的判定与举证**
- 到货后多长时间内提出异议有效（建议：卸货当场或2小时内）。
- 由谁判定：门店店长+供应商共同确认，有争议时可拍照/录像留证。
- 约定照片、视频、称重记录可作为证据。

**3. 明确补货的时限（这是不影响营业的核心）**
按影响程度分档，写进合同：

| 情形 | 补货时限 | 方式 |
|---|---|---|
| 少量不合格、不影响当日主推 | 24小时内 | 下次配送顺带补 |
| 影响当日营业（如主料烂果多） | 4小时内 | 供应商就近调货/同城急送 |
| 紧急缺料（当天就要用） | 2小时内 | 供应商承担同城闪送/自提 |

**4. 约定“先补后赔”还是“以补代赔”**
- 优先补货，补不了才折价退款。
- 明确补货数量按不合格数量1:1补，损耗大的可约定1:1.2。

## 二、补货执行的具体写法（可直接抄）

> 1. 甲方（门店）在到货验收时发现不符合约定标准的，应当场或2小时内通知乙方（供应商），并留存照片/视频。
> 2. 乙方应在接到通知后【X】小时内完成补货，补货标准与原订单一致，费用由乙方承担。
> 3. 若乙方未按时补货，甲方有权自行就近采购替代品，差价及因此产生的合理费用由乙方承担，并从当期货款中直接扣除。
> 4. 因补货不及时导致甲方当日营业受影响的，乙方按【每延误1小时赔付XX元/或当批次货款的X%】承担违约责任。

## 三、真正“不影响营业”的兜底设计

光靠供应商承诺不够，要给自己留后手：

1. **保留备选供应商**：常用水果至少有1家备选，能当天调货。
2. **安全库存**：对高频主料，门店常备1–2天用量，不完全依赖当日到货。
3. **账期挂钩**：把补货履约和货款结算绑定，约定“未补货部分暂不结算”，比事后追偿有效得多。
4. **授权自行采购**：合同里写明门店可紧急自采、差价由供应商承担，避免扯皮耽误出杯。
5. **固定对接人**：双方各留紧急联系人电话，避免“找不到人”。

## 四、容易踩的坑

- 只写“不合格可退换”，没写时限 → 供应商拖到第二天，你当天没料。
- 没写“自行采购差价由谁承担” → 你自己买贵的，钱要不回来。
- 没留证据 → 供应商说“到货是好的”，你无法举证。
- 验收标准太主观 → 争议时各说各话。

## 一句话总结

**补货条款要写成：什么算不合格 + 多久内补 + 不补怎么办 + 营业损失谁担。** 再加上“安全库存 + 备选供应商 + 货款挂钩”，才能真正做到不合格也不影响出杯。
