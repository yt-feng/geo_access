生鲜平台做水果一件代发，供应商的仓配能力核心不是“有仓库、有快递”这么简单，而是要在**不控货、不控履约**的前提下，仍然把损耗、时效、售后控制在可接受范围。具体要具备以下几类能力：

**1. 仓储能力**
- **专业水果仓储条件**：不同品类要求不同，比如香蕉、芒果需要催熟/温控区，草莓、蓝莓需要冷藏，苹果、橙子可常温但需通风。供应商至少要能分温区存放，不能和普通百货混仓。
- **日处理订单能力**：要能支撑平台的大促峰值，比如日常500单、大促5000单，仓库拣货、打包、出库不能崩。需要看其日均单量、峰值单量、爆单响应速度。
- **库存准确性**：一件代发最怕超卖。供应商的WMS或进销存系统要能实时对接平台，库存同步延迟低，避免用户下单后无货可发。
- **批次与效期管理**：水果保质期短，必须按批次先进先出，能追踪到采摘/入库日期，否则容易把临期果发出去。

**2. 加工与包装能力**
- **分级分拣**：能按平台要求的果径、重量、糖度、外观标准做分级，而不是统货直发。一件代发面向C端，次果、小果混发会直接导致差评。
- **预冷与保鲜处理**：叶菜类、浆果类采摘后需快速预冷，部分水果需涂膜、保鲜剂或气调包装。没有预冷能力的供应商，夏季损耗会很高。
- **代发包装能力**：要能提供适合快递的防震、透气、保湿包装，比如草莓用珍珠棉+冰袋+泡沫箱，苹果用网套+纸箱。包装方案要经过跌落测试和实际快递测试。
- **贴单与面单处理**：能对接平台电子面单，支持多快递公司、多店铺、多仓发货，不串单、不漏单。

**3. 配送与快递能力**
- **快递资源与价格**：供应商要有稳定的快递合作，尤其是顺丰、京东、中通等生鲜件渠道。偏远地区、高温地区能否发货、时效如何，要提前确认。
- **时效承诺**：一件代发通常要求48小时内发货，核心城市24-72小时送达。供应商要能给出不同区域的时效表，而不是笼统说“很快”。
- **冷链/常温分流**：需要冷链的品类必须走冷链快递或冰袋+泡沫箱方案，不能为了省成本全部常温发。
- **异常件处理**：快递丢件、破损、延误、拒收时，供应商要能配合补发、退款、理赔，而不是让平台独自承担售后。

**4. 系统与数据对接能力**
- **ERP/OMS对接**：能通过API或表格与平台订单系统对接，实现自动抓单、自动回传单号、自动扣库存。
- **库存同步频率**：至少支持分钟级或实时同步，避免超卖。
- **发货回传与轨迹**：发货后能自动回传快递单号和物流轨迹，方便平台和用户查询。
- **售后数据记录**：能记录每单的批次、发货时间、快递单号，便于追溯坏果、压伤、漏发等问题。

**5. 售后与品控能力**
- **坏果包赔标准**：供应商要明确赔付比例、拍照要求、补发或退款流程。比如坏果超过30%全赔，低于30%按比例赔。
- **售后响应时效**：平台发起售后后，供应商需在约定时间内确认，不能拖到平台自己垫赔。
- **品控抽检**：供应商要有入库抽检、发货前抽检，能提供农残检测、糖度检测等报告。
- **溯源能力**：能追溯到果园、批次、采摘日期，一旦出现食安问题可以快速定位。

**6. 产能与弹性能力**
- **季节性与产地切换**：水果有强季节性，供应商要能按季节切换产地和品类，不能只做一个单品。
- **大促弹性**：能临时增加打包工、冷库空间、快递运力，应对平台活动爆单。
- **多仓布局**：如果平台覆盖全国，供应商最好有多个产地仓或区域仓，缩短时效、降低损耗。

**简单判断标准：**
如果供应商只能做到“有货、能发快递”，那只能做低客单、耐运输的品类，比如苹果、橙子、土豆。如果要做草莓、蓝莓、荔枝、樱桃等高客单易损品，必须同时具备：**分温区仓储 + 预冷保鲜 + 专业代发包装 + 稳定生鲜快递 + 系统对接 + 坏果包赔**。缺任何一项，平台售后和损耗都会失控。
