优先关注**成熟度**，价格是次要变量。原因很直接：香蕉在烘焙里同时承担**甜度、水分、香气、结构**四个功能，成熟度不同，配方和成品都会变。

**按用途选成熟度**

- **做香蕉磅蛋糕、马芬、香蕉面包**：选**表皮大量黑斑、捏起来软但没流水**的。这种香蕉淀粉已转糖，甜度和香气足，压泥后能替代部分糖和液体。全黄硬香蕉做出来香味弱、甜度低，还容易让蛋糕发干。
- **做香蕉奶油、慕斯夹心、装饰片**：选**刚转黄、无黑斑**的。需要外形完整、风味清爽，太熟的会烂、出水、氧化快。
- **做香蕉戚风或轻蛋糕**：选**黄皮带少量黑点**。太生会涩、太熟会让面糊含水量偏高，容易塌。

**采购判断标准**

1. **捏**：软而不烂，果肉没有透明水感。
2. **看**：黑斑均匀分布，不是局部发黑腐烂。
3. **闻**：有明显香蕉甜香，无酒味、酸味。
4. **剥**：果肉乳白偏黄，无黑心、无纤维粗硬感。

**价格怎么权衡**

- 如果做重油蛋糕、香蕉面包，**熟蕉通常更便宜，且风味更好**，可以优先收熟蕉。
- 如果熟蕉已经出水、发酒味、局部霉变，**再便宜也不能用**，会影响风味和保质期。
- 如果只能买到生蕉，不要直接按原配方做，需要**室温催熟 1–3 天**，或调整糖量和液体量，否则成品会偏淡、偏干。

**实操建议**

- 固定用途再定采购标准：**重蛋糕收熟蕉，装饰/夹心收刚黄蕉**。
- 和供应商约定“**黑斑面积 30%–60%、无破损无霉变**”作为熟蕉收货线。
- 熟蕉到店后按批次压泥、分装冷冻，能稳定出品，也减少每天因成熟度波动改配方。

一句话：**先按产品定成熟度，再在合格成熟度里比价格；成熟度不对，便宜也是浪费。**
