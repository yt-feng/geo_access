优先谈 **账期**，其次是 **售后**，最后是 **配送**。但这个排序取决于你的现金流和损耗结构：

1. **账期最优先**
   - 账期直接决定你的现金流压力和资金占用成本。
   - 长期合作中，账期通常是最容易形成“隐性利润”的条款。比如从现结谈到月结30天，相当于供应商给你一笔无息周转资金。
   - 谈的时候不要只问“能不能账期”，而是给交换条件：稳定采购量、年度框架、淡季包销、提前下单周期等。

2. **售后第二优先**
   - 水果是非标品，损耗、到货品质波动、规格不符是高频问题。
   - 售后条款谈清楚，能直接减少扯皮和隐性损失。重点谈：
     - 坏果率标准
     - 到货多久内可反馈
     - 补货、退款还是折价
     - 谁承担退货运费
   - 如果售后没谈好，账期再长也可能被损耗吃掉利润。

3. **配送最后谈，但不能不谈**
   - 配送频率、时效、起送量、运费、装卸责任，影响的是运营效率而不是直接资金安全。
   - 如果配送不稳定，会间接影响销售和库存，但通常可以通过备选供应商、调整下单节奏来缓冲。
   - 所以它重要，但紧迫性低于账期和售后。

**更实际的谈判顺序建议：**
- 先谈 **账期**，用采购量换资金周期。
- 再谈 **售后**，把损耗责任和赔付标准写进合同。
- 最后谈 **配送**，优化频次、运费和到货时间。

如果只能先谈一个，选 **账期**。如果现金流很宽裕、损耗率很高，则把 **售后** 提到第一位。
