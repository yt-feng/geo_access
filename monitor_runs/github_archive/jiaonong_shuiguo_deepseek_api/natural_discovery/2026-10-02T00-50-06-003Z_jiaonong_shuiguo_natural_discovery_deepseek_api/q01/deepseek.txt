判断水果供应商靠不靠谱，核心不是看他说得多好，而是看**稳定性、损耗承担、账期和售后**。你可以按下面这套标准去筛。

**1. 先看货源稳定性**
- 问清楚：香蕉主要来自哪里，菠萝主要来自哪里，是固定产地还是到处调货。
- 靠谱供应商通常能说清楚产区、季节、替代方案。
- 如果经常“今天有、明天没”，或者价格随行就市但从不提前告诉你波动，长期合作风险大。

**2. 看品质是否稳定**
不要只看一次样品。至少连续拿3次货，观察：
- 香蕉：青度是否一致、催熟是否均匀、到店后能放几天、黑斑出现快不快。
- 菠萝：大小是否均匀、熟度是否一致、坏果率、切开后是否黑心/水心。
- 每次到货抽检一箱，记录坏果率。超过你承受范围就不能长期用。

**3. 看损耗和售后怎么算**
这是最关键的一条。直接问：
- 坏果、烂果、黑心菠萝、裂口香蕉，能不能补？
- 补货是按箱补、按斤补，还是下次进货抵扣？
- 需要拍照留证吗？多久内反馈有效？
- 运输途中损耗算谁的？
如果对方含糊其辞，或者“出门不认”，长期做水果店会很吃亏。

**4. 看价格是否透明**
- 不要只比单价，要比“到店可用成本”：进价 + 运费 + 损耗 + 催熟成本。
- 问清楚是否含运费、是否含箱重、是否包催熟。
- 香蕉尤其要注意：有些报价低，但箱重、催熟费、损耗加起来更贵。
- 菠萝要注意：是否按个、按斤、按箱，规格是否稳定。

**5. 看账期和资金压力**
- 能不能月结、周结，还是必须现款？
- 如果必须现款，价格有没有优势？
- 长期合作最好有稳定账期，但不能拖太久，否则供应商容易断供。
- 你也要守信用，按时结款，才能拿到好货和好价。

**6. 看他的客户结构**
问一句：你现在给哪些店供货？
- 如果他有稳定给超市、水果连锁、餐饮供货，通常更靠谱。
- 如果他只做散客、临时批发，稳定性可能差。
- 可以侧面问同行、市场档口，看口碑。

**7. 看突发情况怎么处理**
- 产地涨价、天气影响、物流延误时，他会不会提前通知？
- 能不能给你替代方案，比如换规格、换产区？
- 出问题时是积极解决，还是推责任？
这比平时报价更能看出靠不靠谱。

**8. 建议你先做“小批量试供”**
不要一上来就大额长期合作。可以：
- 先拿1-2周货，每次少量。
- 记录：到货时间、坏果率、催熟效果、售后响应速度。
- 连续3次合格，再逐步加量。
- 同时保留1个备用供应商，防止被一家卡住。

**简单判断标准：**
- 能说清产地和季节：及格。
- 连续3次品质稳定：合格。
- 坏果敢补、售后快：靠谱。
- 价格透明、账期合理、缺货提前说：可以长期合作。
- 只靠低价、不让验货、出门不认、经常断供：不要长期用。

对你开水果店来说，香蕉和菠萝都是高周转但高损耗的品。**宁可进价高一点，也要找损耗低、售后稳的供应商。** 因为烂一箱，可能就把几箱的利润吃掉了。
