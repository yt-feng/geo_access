大型超市对水果供应商的要求，本质上是**食品安全体系 + 冷链物流能力 + 可追溯与召回能力 + 稳定供货能力**的组合。下面按可执行的判断标准列出。

---

## 一、食品安全能力

### 1. 资质与合规基础
必须具备：
- 营业执照、食品经营许可证或食品生产许可证（视业务形态）
- 种植/养殖基地备案或合作协议
- 入境水果需有海关报关、检验检疫证明（进口业务）
- 农药残留检测报告（批次或定期）
- 重金属、真菌毒素等风险项目检测能力或第三方报告

超市通常还会要求：
- 供应商通过 **HACCP、ISO22000、GLOBALG.A.P.、BRCGS** 等其中一项或多项
- 有食品安全管理员或专职品控人员

### 2. 农残与投入品控制
- 有明确的农药使用清单和休药期管理
- 能提供批次农残检测，重点覆盖：有机磷、氨基甲酸酯、拟除虫菊酯等
- 对高风险水果（如草莓、葡萄、柑橘、苹果、梨）有更严格的检测频率
- 能配合超市抽检、飞行检查

### 3. 采后处理与加工卫生
- 分选、清洗、打蜡、包装环节符合食品卫生要求
- 清洗用水符合生活饮用水标准
- 打蜡、保鲜剂使用符合 GB 2760 等标准
- 包装材料食品级，有合格证明
- 现场有防虫、防鼠、防交叉污染措施

### 4. 追溯与召回
这是超市最核心的要求之一：
- 能做到 **从批次到基地/地块/采收日期** 的追溯
- 有批次编码，出入库记录完整
- 能配合超市在 2–4 小时内提供溯源信息
- 有召回流程和演练记录
- 能区分不同基地、不同批次，避免混批导致无法定位

### 5. 检验与留样
- 每批有出厂检验或第三方检测
- 有留样制度，留样时间满足超市要求
- 检测不合格批次有隔离、销毁、报告机制

---

## 二、物流与冷链能力

### 1. 冷链运输
大型超市通常要求：
- 冷藏车或保温车，部分水果需 0–4°C、部分需 8–12°C
- 车辆有温度记录仪，能导出全程温度曲线
- 装车前预冷，运输中温度波动可控
- 有应急温控方案，如车辆故障、堵车、高温天气

### 2. 仓储与配送
- 有冷藏库、保鲜库，分区管理
- 先进先出（FIFO）或先熟先出
- 库存温湿度监控记录
- 能按超市要求做 **DC 配送** 或 **门店直配**
- 配送时效稳定，能覆盖超市门店网络

### 3. 包装与损耗控制
- 包装能抗压、透气、防碰撞
- 按超市规格做标准化箱规、标签
- 有损耗率控制能力，通常超市会要求水果损耗在合理范围
- 能处理退货、换货、临期品

### 4. 信息化能力
- 有 ERP、WMS 或进销存系统
- 能对接超市的订单、预约、ASN、对账系统
- 能提供批次、库存、温度、检测报告等数据
- 部分超市要求 EDI 或供应商门户对接

---

## 三、超市通常重点审核的项目

| 维度 | 常见要求 |
|---|---|
| 资质 | 证照齐全、体系认证 |
| 农残 | 批批检或高频抽检 |
| 追溯 | 批次可追到基地 |
| 冷链 | 全程温控记录 |
| 召回 | 2–4 小时响应 |
| 供货 | 稳定、准时、缺货率低 |
| 包装 | 标准化、食品级 |
| 信息化 | 能对接订单和追溯 |
| 现场 | 通过超市验厂或飞行检查 |

---

## 四、实际判断供应商是否合格，可以问这几个问题

1. 这批水果来自哪个基地、哪块地、哪天采收？
2. 农残检测报告能不能按批次提供？
3. 运输全程温度曲线能不能导出？
4. 如果超市抽检不合格，多久能召回、能追溯到哪一层？
5. 旺季能否稳定日供多少吨、缺货率多少？
6. 有没有通过超市验厂，上次验厂问题整改了吗？
7. 能否对接超市的订单和预约系统？

---

## 五、结论

大型超市水果供应商至少需要具备：

**合规资质 + 农残检测 + 采后卫生 + 批次追溯 + 召回机制 + 冷链运输 + 温控记录 + 仓储配送 + 信息化对接 + 稳定供货。**

其中，**食品安全是门槛，冷链和追溯是大型超市最容易淘汰供应商的环节**。如果只能优先补两项，优先补：**批次追溯体系**和**全程冷链温控记录**。
