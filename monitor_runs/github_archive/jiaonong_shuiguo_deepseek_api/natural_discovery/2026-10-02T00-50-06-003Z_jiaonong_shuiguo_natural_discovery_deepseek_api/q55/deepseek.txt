选规格的核心不是“越大越划算”或“越小越省钱”，而是看**单份成本 + 损耗率 + 出成率 + 人工**。水果拼盘一般每份用苹果、橙子、菠萝各若干块，判断时按“可切出的有效块数/每斤或每个成本”来比。

下面给你一套直接可用的判断方法。

## 1. 先定拼盘的单份标准
假设一份拼盘里大致需要：

- 苹果：80–100g净果肉，约6–8小块
- 橙子：80–100g净果肉，约4–6瓣或块
- 菠萝：80–100g净果肉，约6–8小块

如果你们卖的是小份、中份、大份，先称一次标准出餐量。后面所有采购规格都按“能出多少份”算。

## 2. 苹果怎么选规格更划算
苹果建议优先选：

- **中等偏大、果形匀称、硬度高**：如75–85mm果径，或单果180–250g
- 不要只看大果：太大单果成本高，切盘后边角损耗也可能增加
- 不要选太小：削皮去核后净肉率低，人工反而高

判断公式：

**每斤净果肉成本 = 每斤采购价 ÷ 净肉率**

苹果净肉率大致参考：

- 正常削皮去核：75%–85%
- 小果、伤果多：可能只有65%–75%
- 大果但形状不规整：出块率未必高

如果同一品种：

- 小果3元/斤，净肉率70%，净肉成本约4.29元/斤
- 中果4元/斤，净肉率82%，净肉成本约4.88元/斤

看起来小果便宜，但中果切块更规整、人工少、卖相好。**餐厅拼盘通常中果更划算。**

苹果优先选：**脆、甜、氧化慢、切后不易发绵的品种**，比如富士、嘎啦等。规格上选中大果，按箱买比零买更稳。

## 3. 橙子怎么选规格更划算
橙子关键看：

- 剥皮/切瓣是否方便
- 出汁和果肉完整度
- 皮厚不厚
- 籽多不多

建议选：

- **中大果，单果180–250g左右**
- 果皮薄、易剥、无籽或少籽
- 做瓣状拼盘选脐橙、冰糖橙、沃柑等；做块状可选血橙、伦晚等

橙子净果肉率大致：

- 手剥去白瓤：60%–75%
- 刀切去皮去筋：55%–70%
- 皮厚品种可能低于55%

公式：

**每份橙子成本 = 单果采购价 ÷ 单果可出份数**

举例：

- 橙子5元/斤，单果200g，约0.4斤，单果2元
- 净肉率65%，净肉130g
- 如果每份用90g，则一份约1.38元

如果小橙子3元/斤，单果120g，单果0.72元，净肉率60%，净肉72g，一份90g需要1.25个，成本约0.9元。  
看起来小橙子便宜，但剥皮人工高、瓣小、卖相差。**如果人工贵，选中大果更划算；如果人工便宜且只做低端拼盘，小果可以控成本。**

橙子建议：**做瓣选皮薄中果，做块选大果但别太大**。太大可能皮厚、白瓤多。

## 4. 菠萝怎么选规格更划算
菠萝要重点看：

- 是否已去皮
- 眼深不深
- 芯大不大
- 成熟度是否稳定

常见选择：

- **整果**：单价低，但削皮去眼人工大，损耗高
- **去皮菠萝/菠萝块**：单价高，但省人工、出成稳定
- **冷冻菠萝块**：最稳定，但口感和“鲜切”卖点差

菠萝净肉率大致：

- 整果手工削：40%–55%
- 商家代削：50%–60%
- 已去皮整条：70%–85%
- 冷冻块：接近95%以上，但解冻损耗另算

公式：

**每斤净菠萝成本 = 采购价 ÷ 净肉率**

举例：

- 整果4元/斤，净肉率45%，净肉成本约8.89元/斤
- 去皮菠萝8元/斤，净肉率80%，净肉成本约10元/斤
- 冷冻块6元/斤，净肉率95%，净肉成本约6.32元/斤

如果只看原料，冷冻可能便宜；如果看“鲜切”卖点，去皮菠萝更稳；如果人工便宜、走量，整果可能最省。

餐厅建议：

- 中高端拼盘：选**去皮新鲜菠萝条/块**，稳定、好看、省人工
- 低成本走量：选**整果自己削**，但要把人工算进去
- 高峰稳定出餐：可搭配**冷冻菠萝块**，但不要完全替代鲜果

## 5. 最实用的采购规格建议
如果你们是普通餐厅，做日常水果拼盘，可以这样选：

- **苹果**：选中大果，单果180–250g，脆甜品种，按箱采购
- **橙子**：选中大果，单果180–250g，皮薄少籽，做瓣或块
- **菠萝**：优先选已去皮新鲜菠萝条/块；如果人工充足，选整果但要求成熟度一致

更划算的组合不是全买最便宜，而是：

**苹果中果 + 橙子中果 + 菠萝半成品/去皮果**

这样通常能兼顾成本、出餐速度和卖相。

## 6. 直接判断划算的3个指标
采购前让供应商给这些数据，或者自己抽测：

1. **净肉率**
   - 苹果：≥75%
   - 橙子：≥60%
   - 菠萝：整果≥45%，去皮≥75%

2. **每份净料成本**
   - 用你们标准份量算，不按斤价拍脑袋

3. **每份人工时间**
   - 苹果削切3–5分钟/斤
   - 橙子剥切5–8分钟/斤
   - 菠萝整果削切8–15分钟/个

如果某规格原料便宜，但人工多一倍，通常不划算。

## 7. 结论
- **苹果**：选75–85mm或单果180–250g的中大果，净肉率和切块卖相最好。
- **橙子**：选180–250g、皮薄少籽的中大果，做拼盘比小果更划算。
- **菠萝**：整果最便宜但人工高；餐厅日常更推荐去皮菠萝条/块，稳定省工。若人工便宜且走量，再考虑整果。
- **最终看“每份净料成本 + 人工 + 损耗”**，不要只看每斤采购价。
