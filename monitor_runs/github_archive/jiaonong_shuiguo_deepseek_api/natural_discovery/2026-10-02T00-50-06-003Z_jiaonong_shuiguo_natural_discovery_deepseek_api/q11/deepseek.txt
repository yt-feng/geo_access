会影响，但影响大小取决于你怎么卖。

**核心结论：**
一箱香蕉大小不一，**不会直接导致卖不掉，但会明显影响定价、损耗和顾客体验**。关键是按用途分流，而不是混在一起硬卖。

**具体影响：**

1. **整箱/整串卖时影响大**
   顾客挑整串时，会优先拿大小均匀、颜色一致的。大小混杂的那串容易被剩下，最后变成损耗。

2. **散卖时影响小**
   如果拆开按根卖，大小不一反而能让顾客按需挑：大的做果盘、小的自己吃，都能卖掉。

3. **价格上会被压**
   大小不一的货，顾客心理上会认为“次一级”，同样品质下，均匀的能卖更高价。

4. **损耗更高**
   小的、青的、熟的混在一箱，后熟速度不一致，容易有的已经过熟、有的还硬，增加坏果。

**可执行建议：**

- **进货时**：同一批尽量选大小接近的，尤其是打算整串卖的时候。
- **到店后先分级**：
  - 大且均匀的：整串卖、做礼盒、卖高价。
  - 中等均匀的：正常散卖。
  - 大小混杂或偏小的：拆散按根卖，或做特价、果切、奶昔原料。
- **陈列上**：不要把大小差太多的放同一串/同一堆，顾客会专挑好的，剩下难卖。
- **定价上**：大小混杂的货不要按均匀好货的价格卖，适当降价或做组合促销，加快周转。
- **控制库存**：大小不一的货周转要更快，别等全熟再卖。

**一句话：**
大小不一不是不能卖，而是不能“混着按好货卖”。分级、分流、分价，基本就能把影响降到最低。
