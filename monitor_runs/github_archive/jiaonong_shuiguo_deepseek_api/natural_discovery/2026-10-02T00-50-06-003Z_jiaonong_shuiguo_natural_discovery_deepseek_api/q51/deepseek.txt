要，但不要“死固定”，而是**固定标准 + 锁主产区 + 保留备选批次**。水果茶最怕的不是换产地，而是没有验收标准，导致今天酸、明天淡、后天香气不够。

可以按这个思路做：

1. **固定的是风味标准，不是单一产地**
   - 比如柠檬：酸度、出汁率、香气、苦味控制。
   - 芒果：甜度、纤维感、颜色、成熟度。
   - 草莓：香气、酸甜比、果肉完整度。
   - 只要达到标准，产地可以换，但必须经过测试。

2. **主供应产地/批次要相对固定**
   - 固定 1 个主产区或主供应商，保证日常稳定。
   - 再配 1—2 个备选产区，防止断货、涨价、季节结束。
   - 不要只压一个产地，否则遇到台风、减产、封路会很被动。

3. **采购时锁“批次”比锁“产地”更实际**
   - 同一产地不同批次也可能差异很大。
   - 大货前先拿样品做杯测/试饮，确认糖酸比、香气、颜色。
   - 批量到货后抽检，不合格就退或降级做其他产品。

4. **建立简单可执行的验收表**
   - 糖度：用糖度计或口感标准。
   - 酸度：固定滴定或对比样品。
   - 香气：和上一批标准样对比。
   - 颜色、大小、成熟度、坏果率。
   - 每批留样，方便追溯。

5. **配方上留调整空间**
   - 糖浆、茶底、冰块、柠檬汁比例不要卡到 0.1 克不可调。
   - 给店员一个“微调区间”，比如酸了加 3—5 克糖，淡了减少水量。
   - 但调整必须有上限，不能每杯靠感觉。

6. **和供应商签稳定条款**
   - 约定规格、成熟度、糖酸范围、坏果率、到货温度。
   - 约定换产地/换批次要提前送样确认。
   - 约定不合格的处理方式：退换、补货、扣款。

**结论：**
要固定，但固定的是**品质标准和主供应关系**；产地和批次可以作为变量管理。最稳的做法是：**一个主产区 + 一个备选产区 + 每批送样验收 + 门店微调标准**。这样既不会因为换产地崩口碑，也不会被单一产地卡死。
