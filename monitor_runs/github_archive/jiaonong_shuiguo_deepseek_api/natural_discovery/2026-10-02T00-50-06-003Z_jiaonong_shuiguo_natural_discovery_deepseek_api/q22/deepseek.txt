香蕉、菠萝、苹果可以分别承担引流、提客单、做利润的角色，组合起来会比单独打折更有效。

我先给一个可落地的组合方案，再给几种不同目标的变体。

**一、角色分工**

- **香蕉**：高频、价格敏感、决策快，适合做引流和凑单触发器，不建议做主要利润来源。
- **菠萝**：客单较高、有加工需求、季节性明显，适合做“加购升级”和提升客单。
- **苹果**：日常刚需、耐储存、品种多，适合做利润和组合锚点，尤其是礼盒、家庭装。

**二、主推组合：香蕉引流 + 菠萝升级 + 苹果提利润**

**方案1：水果三件套，阶梯定价**

- 单买：香蕉 3.99/斤，菠萝 9.9/个，苹果 5.99/斤
- 组合价：香蕉1把 + 菠萝1个 + 苹果2斤 = 19.9
- 单独买合计约 24.8，组合省约 5 元

这个组合的好处是：香蕉负责让顾客觉得便宜，菠萝负责拉高客单，苹果负责撑住毛利。顾客本来只想买香蕉，看到组合后可能多买两样。

**方案2：满额加购，而不是直接降价**

- 买苹果满 15 元，加 5 元换购菠萝半个或小菠萝一个
- 买香蕉满 2 把，加 3 元换购苹果 1 斤

这种方式比全场打折更保护毛利，也能让原本只买一样的人多买第二样。

**方案3：按场景打包**

- **早餐组合**：香蕉1把 + 苹果3个 + 即食燕麦/酸奶（如果超市有）  
- **家庭果盘组合**：菠萝1个 + 苹果2斤 + 香蕉1把  
- **办公室下午茶组合**：香蕉2把 + 苹果1斤 + 切好的菠萝盒

场景化组合比单纯“便宜卖”更容易提高客单，因为顾客买的是“解决一个需求”，不是三样水果。

**三、陈列和动线**

- 香蕉放在水果区入口或主通道，负责拉人进来。
- 菠萝放在香蕉旁边或稍后位置，做“加购升级”。
- 苹果放在组合区核心位置，旁边放组合价签和购物篮。
- 组合商品集中陈列，标“三件套”“家庭装”“省X元”，不要分散。
- 试吃优先给菠萝和苹果，香蕉认知度高，不需要重点试吃。

**四、价格设计原则**

- 组合价要比单买合计低 15%—25%，太低伤毛利，太高没吸引力。
- 用“省X元”而不是“打X折”，顾客对省多少钱更敏感。
- 香蕉可以微利甚至平进平出，但不要长期亏本，否则会拉低整体毛利。
- 苹果选 1—2 个中高毛利品种做组合，不要全用最低价品种。
- 菠萝如果损耗大，优先做半个、切盒、加购，而不是整颗硬推。

**五、不同目标的变体**

- **目标：冲客流**  
  香蕉特价 + 苹果正常价 + 菠萝加购价。重点是把人引进来。

- **目标：提客单**  
  组合价、满额换购、家庭装。重点是让顾客多买一件。

- **目标：清菠萝库存**  
  菠萝切盒 + 苹果香蕉搭配成“果盘组合”，或买苹果满额加购菠萝。

- **目标：做利润**  
  苹果礼盒 + 菠萝精品 + 香蕉作为赠品或换购品，利润主要来自苹果和菠萝。

**六、执行时要注意**

- 先跑 7—14 天，看三个指标：客单价、组合购买率、水果区毛利。
- 如果组合购买率低，检查价签是否清楚、陈列是否集中、组合是否真的好用。
- 如果客单上去了但毛利下降太多，减少香蕉折扣，增加苹果和菠萝的组合权重。
- 如果菠萝损耗高，改成切盒或半个装，不要整颗硬绑。
- 不同门店客群不同：社区店适合家庭装，商圈店适合小份果盘和下午茶组合。

**一句话建议**：用香蕉把人引进来，用菠萝做加购升级，用苹果做利润和组合锚点；主推“三件套19.9”或“买苹果满15元加5元换购菠萝”，比三样一起打折更有效。
