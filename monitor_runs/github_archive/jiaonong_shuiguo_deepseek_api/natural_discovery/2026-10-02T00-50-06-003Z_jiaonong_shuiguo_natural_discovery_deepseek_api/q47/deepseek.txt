采购香蕉时，先按用途分等级，不要只写“要熟香蕉”或“要青香蕉”，否则到货波动会很大。

**1. 按用途定熟度等级**
- **做冰沙、奶昔、香蕉牛奶、果泥、冰淇淋基底**：用 **7～8 成熟**。
  - 外观：黄色，两端仍带一点绿，无黑斑。
  - 手感：捏起来有弹性，但果肉还紧实。
  - 优点：甜度够、香气有，但不会太软烂，打碎后不易发黑、发酸。
- **做香蕉蛋糕、香蕉面包、松饼、布丁**：用 **9～10 成熟**。
  - 外观：全黄，带少量黑点或大面积黑斑。
  - 手感：明显变软。
  - 优点：甜度高、香气足，适合捣泥和烘焙。
- **做装饰切片、水果茶顶饰、甜品摆盘**：用 **6～7 成熟**。
  - 外观：黄色偏青，无斑。
  - 手感：硬挺。
  - 优点：切片成型好，不易断、不易氧化变黑。
- **做炸香蕉、烤香蕉、焦糖香蕉**：用 **7～8 成熟**。
  - 太生会涩，太熟一加热就烂。

**2. 采购时写清验收标准**
建议订单和验收单直接写：
- 品种：如香芽蕉、小米蕉、芭蕉等，按门店配方固定。
- 成熟度：按 1～10 级写明，例如“7～8 成熟，黄色带轻微绿肩，无黑斑”。
- 单根重量/每箱规格：如“单根 120～150g”“每箱 13kg 左右”。
- 允许瑕疵：黑斑面积、压伤、裂口、发霉比例。
- 到货温度：常温或 13～15℃ 运输，避免冷藏冻伤。

**3. 分批次采购，不要一次全买熟**
香蕉后熟很快，尤其夏天。建议：
- 日常用量按 **1～2 天** 一批采购。
- 高峰前备货，也至少分 **两批**：一批 7 成熟，一批 8～9 成熟。
- 如果供应商只能给同一熟度，收货后自己分开放：青一点的放常温催熟，熟一点的优先用。

**4. 到货后按熟度分流**
- **6～7 成熟**：常温放 1～2 天，用于装饰或等它转熟。
- **7～8 成熟**：直接用于冰沙、奶昔、果泥，优先消耗。
- **9～10 成熟**：当天做烘焙、果泥或冷冻保存，不要继续常温放。
- **已过熟、发黑流汁**：不要用于饮品装饰，可评估做香蕉面包，但发酸、酒味、霉变必须报废。

**5. 储存控制**
- 未熟香蕉：常温、通风、避光，不要冷藏。
- 已熟香蕉：可冷藏 1～2 天延缓过熟，但表皮会变黑，果肉仍可用；做饮品前再剥皮。
- 去皮的香蕉果肉：加少量柠檬汁或维C溶液防氧化，密封冷藏，尽量当天用完；也可分装冷冻做冰沙。
- 不要和苹果、梨、番茄等释放乙烯多的水果混放，会加速成熟。

**6. 门店简单判断法**
- **能切片、边缘整齐**：6～7 成熟，适合装饰。
- **能切但略粘刀、甜香明显**：7～8 成熟，适合饮品。
- **一剥皮就软塌、黑斑多、香气浓**：9～10 成熟，适合烘焙。
- **有酒味、酸味、渗液、霉点**：不合格，报废。

**7. 最稳的采购策略**
让供应商按“用途”供货，而不是只按“香蕉”供货：
- A 级：6～7 成熟，做装饰。
- B 级：7～8 成熟，做饮品。
- C 级：9～10 成熟，做烘焙。
每天根据销量分别下单，到店后再按成熟度贴标签，先熟先用。这样比单纯控制“买熟一点还是生一点”更稳定。
