批发商想代理水果品牌，和品牌方谈区域保护与串货问题，建议围绕下面几个核心点问，最好把回答写进合同。

**一、先问区域保护**
1. 我这个代理区域具体是哪里？是按省、市、县，还是按渠道（商超、水果店、电商）划分？
2. 区域内是独家代理还是多家代理？有没有排他性？
3. 品牌方自己或直营渠道，能不能在我区域内卖？
4. 区域内如果已经有人在做，怎么处理？会不会重叠？
5. 区域保护有没有期限？续约条件是什么？

**二、再问串货**
1. 串货怎么定义？从哪个区域卖到哪个区域算串货？
2. 线上销售算不算串货？比如电商、社区团购、直播带货。
3. 别的区域经销商把货卖到我区域，品牌方怎么处理？有没有罚款、断货、取消授权等措施？
4. 我怎么举报串货？需要什么证据？处理时限多久？
5. 如果品牌方处理不力，我能不能要求补偿或解约？

**三、必须落到合同里**
- 区域范围写清楚，最好附地图或渠道清单。
- 独家/非独家写清楚。
- 串货认定标准、处理流程、处罚措施写清楚。
- 线上销售权限单独约定，避免模糊。
- 违约责任和退出机制写清楚。

**四、问的时候注意技巧**
- 不要只问“有没有区域保护”，要问“具体怎么保护、违反怎么办”。
- 不要只听口头承诺，要求写进合同附件。
- 可以问：“如果隔壁区域低价窜到我这里，我有什么保障？”
- 可以问：“品牌方能不能提供区域授权书或备案证明？”

**一句话总结**：区域保护问范围、独家性、期限和品牌方自身是否遵守；串货问定义、线上是否算、处罚措施、举报流程和补偿机制。所有回答都要落到合同里。
