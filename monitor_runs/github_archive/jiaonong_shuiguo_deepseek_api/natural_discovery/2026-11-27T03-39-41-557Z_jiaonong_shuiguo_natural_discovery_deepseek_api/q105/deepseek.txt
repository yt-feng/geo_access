水果锁价没有统一标准，能锁多久取决于品类、季节、供应商类型和你的采购量。一般可分几档：

1. **国产应季水果（苹果、梨、柑橘等耐储品类）**
   - 常见锁价周期：**1～3个月**
   - 冷库货源、大批量年单可谈到**3～6个月**，但通常附带锁量、预付定金或分批提货条款。

2. **国产时令水果（荔枝、樱桃、桃、西瓜等）**
   - 基本很难锁长，常见**1～4周**，甚至只锁单批货。
   - 供应商一般只愿意锁“保底价+浮动区间”，因为产地天气和行情波动大。

3. **进口水果（香蕉、车厘子、奇异果等）**
   - 香蕉等全年供应品类可锁**1～3个月**；
   - 车厘子等强季节品类通常按船期/批次锁价，**单批或1～2周**更现实。

4. **大型商超/连锁与一级供应商的年框**
   - 可签**6～12个月框架价**，但多为“基准价+调价机制”，不是完全固定价；遇到产地大幅涨跌会触发重新议价。

**实操建议：**
- 不要只谈“锁价”，要谈**锁价+锁量+质量标准+调价触发条件+违约条款**。
- 对波动大的品类，优先谈**保底价+浮动上限**，比硬锁死更容易成交。
- 锁价期越长，供应商越可能要求**预付定金、最低采购量、分批提货**。
- 先从小批量、短周期锁价试合作，再逐步延长。
