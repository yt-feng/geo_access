香蕉和菠萝的售后，核心不是“出了坏果怎么赔”，而是**把损耗从售后环节前移到选品、到货、分发和预期管理**。高损耗品做社区团，售后率能不能压住，70%取决于流程设计，30%才取决于赔付态度。

## 一、先定规则：把“不可控损耗”变成“可预期损耗”

1. **单品定损耗率红线**
   - 香蕉：夏季到货损耗率控制在3%以内，冬季5%以内；超过就暂停该供应商。
   - 菠萝：到货损耗率控制在5%以内（含黑心、烂心、压伤）。
   - 每周统计一次，按供应商、批次、团长维度看，连续两周超线就换供应商或改规格。

2. **售后规则前置公示**
   - 香蕉：表皮黑斑、轻微压伤不售后；果肉发黑、发酸、整把腐烂才赔。
   - 菠萝：切开黑心、烂心、明显水渍腐烂才赔；外表青皮、小磕碰不赔。
   - 规则写在团购页和群公告里，配图说明“可赔/不赔”的边界，减少扯皮。

3. **赔付方式标准化**
   - 优先“下一单抵扣券”或“按比例退款”，不轻易全额退款。
   - 香蕉按“根”赔，菠萝按“个”赔，避免整单退。
   - 设置单团售后预算上限（比如销售额的2%），超了就要复盘流程，而不是无限兜底。

## 二、选品和到货：损耗从源头压

1. **香蕉别选全熟到货**
   - 到货七成熟，分发后2–3天自然熟，正好覆盖“到货—自提—食用”周期。
   - 夏季要求供应商用透气箱+分层摆放，避免闷热催熟过度。
   - 到货当天抽检：切开2–3根看果肉，有发酸、水烂的直接整批拒收或降级处理。

2. **菠萝选“耐运输品种+成熟度可控”**
   - 优先选凤梨类耐储品种，普通菠萝夏季黑心风险高。
   - 到货成熟度控制在七八成，不要全黄到货。
   - 到货抽检切开2–3个看黑心，黑心比例超5%整批退换。

3. **供应商条款写清楚**
   - 到货24小时内坏果率超约定比例，供应商补货或扣款。
   - 香蕉、菠萝单独签损耗条款，不和普通水果混在一起结算。

## 三、分发环节：减少“最后一公里”损耗

1. **到货当天分装，不堆压**
   - 香蕉悬挂或平铺，不叠压；菠萝单层摆放，避免底部压伤。
   - 夏季自提点选阴凉处，避免暴晒和闷箱。

2. **分时段自提，缩短存放时间**
   - 香蕉、菠萝设定“到货当天18点前自提”，超时提醒，减少在自提点过夜。
   - 自提点准备纸箱隔层，避免团长反复翻拣造成二次损伤。

3. **团长培训三句话**
   - “香蕉黑斑正常，果肉黑才赔。”
   - “菠萝切开黑心拍照赔，外表磕碰不赔。”
   - “有问题24小时内拍照反馈，超时不处理。”

## 四、售后执行：快、准、留证据

1. **24小时拍照售后**
   - 要求用户拍“整体+切开面+订单截图”，一次提交，避免反复沟通。
   - 团长初审，平台抽审，减少恶意售后。

2. **分级赔付**
   - 香蕉：单根坏赔单根，整把坏赔整把，不整单退。
   - 菠萝：黑心赔单个，按售价比例退；连续两单同批次出问题，直接下架该批次。

3. **售后数据反哺选品**
   - 每周看“香蕉/菠萝售后率、赔付金额、供应商批次”。
   - 售后率超红线：换供应商、改成熟度、改规格（比如香蕉改小把装，菠萝改单个装）。

## 五、最实用的三条落地动作

1. **本周就做**：把香蕉、菠萝的“可赔/不赔”规则做成两张图，发群公告和团购页。
2. **下一团就改**：香蕉到货七成熟、菠萝七八成，到货抽检切开验果肉，不合格整批拒收。
3. **每团必看**：售后率按供应商和团长统计，连续两周超线就换人或换货。

一句话总结：**香蕉控成熟度和堆压，菠萝控黑心和批次抽检；规则前置、分级赔付、数据反哺供应商，售后率才能压得住。**
