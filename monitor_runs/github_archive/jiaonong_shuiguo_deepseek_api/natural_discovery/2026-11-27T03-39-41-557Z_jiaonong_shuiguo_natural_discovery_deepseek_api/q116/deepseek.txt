小商家采购水果，现金结算和月结账期各有什么风险，下面按“资金、货损、履约、账务”分开说，便于直接判断。

## 现金结算（现款现结）

**主要风险：**
1. **资金占用与周转压力**：水果保质期短、损耗高，现金一付出去就沉淀在货里；一旦卖得慢，现金流会立刻紧张。
2. **货损后难追偿**：当场付款后，如果回去发现烂果、规格不符、缺斤少两，议价和追责空间小，尤其对流动摊贩、临时供应商。
3. **供应商跑单/断供风险**：现金交易往往缺正式合同和凭证，供应商临时涨价、断供、换人时，你缺少约束手段。
4. **税务与凭证风险**：现金采购若没有规范发票或收据，入账、成本核算、税务抵扣都容易出问题。
5. **内部舞弊风险**：现金采购环节多，采购人员虚报价格、吃回扣、虚增数量较难核查。

**相对优势：** 价格可能更低、关系简单、不背债。

## 月结账期（先货后款）

**主要风险：**
1. **信用与坏账风险**：账期本质是供应商给你信用，但如果你销售回款慢，容易形成拖欠，影响后续供货甚至被断供。
2. **对账纠纷**：水果每天价格、等级、损耗都在变，月结时容易出现“当时说好的价”“退货没扣减”“损耗算谁的”等扯皮。
3. **货损责任不清**：账期内发现质量问题，供应商可能以“已签收”“时间久了”为由拒认，退货扣款难落实。
4. **隐性成本**：月结价格通常高于现金价，或附带最低采购量、指定品种等条件，实际成本可能更高。
5. **供应商集中风险**：账期依赖单一供应商时，对方提价、断供或收紧账期，你会很被动。
6. **账务管理风险**：赊购笔数多、价格波动大，若没有逐笔对账单，月底容易多付、重复付或漏记负债。

**相对优势：** 缓解现金流、便于用销售回款覆盖货款。

## 给小商家的实操建议

- **不要二选一，分层使用**：高频、易损耗、价格波动大的品种可现金锁价；稳定走量品种可谈短账期（7—15天），比月结更可控。
- **现金采购也要留凭证**：每笔写清品种、等级、数量、单价、日期，拍照留证，尽量转账并备注，避免纯口头现金。
- **账期必须配对账单**：每日或每周签字确认到货数量、价格、退货和损耗，月底只核对汇总，避免“月结变月结不清”。
- **合同写清货损规则**：到货验收时限、烂果扣款标准、退货由谁承担运费，越具体越少扯皮。
- **控制单一供应商占比**：无论现金还是账期，主供不超过总采购量的六到七成，保留备选。
- **算真实成本**：月结价减去现金价，再对比资金占用成本，别只看“能不能晚付”。

一句话：**现金结算的风险在“付出去难追”，月结的风险在“欠着说不清”；前者靠验收凭证，后者靠逐笔对账和书面规则。**
