会，而且香蕉的损耗风险比菠萝更高。起订量偏高通常会通过三个机制放大损耗：

1. **库存周转变慢**：一次进太多，尤其香蕉后熟快，卖不完就过熟、发黑、报损。
2. **品质窗口被压缩**：香蕉从青到黄到过熟时间短，菠萝相对耐放，但大批量堆压也会出现黑心、腐烂、碰伤。
3. **预测误差被放大**：起订量越高，实际销量稍低就会形成剩余；生鲜需求波动大时，高起订量等于把预测误差变成损耗。

判断上可以这样看：

- **香蕉**：对起订量最敏感，建议按“日均销量 × 补货周期 × 安全系数”控制，安全系数不宜过高；宁可少量多次。若起订量明显高于3～5天销量，损耗风险偏高。
- **菠萝**：耐储性较好，但仍受成熟度、温度、堆压影响；若起订量超过7～10天销量，且仓储通风/温控一般，也有风险。
- **关键不是绝对起订量，而是“起订量对应多少天销量”**。超过正常周转天数越多，损耗风险越大。

可执行建议：

- 先统计近4周香蕉、菠萝的日均销量和报损率；
- 把起订量折算成“可售天数”，香蕉尽量控制在3～5天内，菠萝控制在7天内；
- 与供应商谈分批到货、混合拼柜、降低单品起订量或提高补货频次；
- 对高起订量批次做重点陈列、分级销售（熟蕉做折扣/加工，菠萝做切果）；
- 若起订量无法降低，优先压缩订货频次而不是单次盲目加量，并预留促销消化方案。

结论：**会。香蕉尤其明显，菠萝次之；起订量越高，周转天数越长，损耗风险越大。**
