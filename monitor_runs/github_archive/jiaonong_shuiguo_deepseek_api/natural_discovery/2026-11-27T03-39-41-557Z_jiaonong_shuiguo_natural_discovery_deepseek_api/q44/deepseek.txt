判断供应商售后是否稳定，不要只听口头承诺，建议在采购前和试单期用“可验证动作”来检验：

1. **合同里写清售后条款**
   - 到货腐烂、黑心、断果、催熟不均、香蕉青熟不一致等，分别约定赔付比例和响应时限。
   - 明确报损流程：拍照/视频留存、几小时内反馈、几小时内给处理方案、退款或补货到店时限。
   - 写清“响应超时”的违约责任，而不只是质量问题责任。

2. **试单时故意做一次售后测试**
   - 首单保留少量自然损耗或轻微不合格品，按合同流程正式报损。
   - 记录供应商首次回复时间、是否主动给方案、补货/退款实际到账时间。
   - 重点看是否推诿给物流、天气、门店保存，是否要求你反复催。

3. **要求固定对接人和升级通道**
   - 合同或订单确认单上写明销售对接人、售后负责人、备用联系人及电话。
   - 问清非工作时间、节假日、旺季爆单时谁处理。
   - 测试一次晚间或周末发消息，看是否有明确回复机制。

4. **看其履约记录，而不是看规模**
   - 要求提供近3个月同类商超客户的售后处理记录样例，可脱敏。
   - 关注平均响应时长、补货及时率、报损争议率。
   - 大供应商不一定响应快，小型产地直供反而可能更灵活，关键看是否有专人专流程。

5. **用分批到货和小额多频订单验证**
   - 先做2—3周小批量、多频次试单，专门观察香蕉催熟批次差异和菠萝到货成熟度。
   - 每次问题都走正式售后单，形成记录。
   - 连续3次售后都能在约定时限内闭环，再考虑放大采购量。

6. **设置售后考核和退出机制**
   - 月度考核：响应及时率、赔付/补货完成率、重复问题发生率。
   - 约定连续两次超时或一次恶意推诿可暂停合作、扣保证金或终止合同。
   - 保留备用供应商，避免单一供应商售后失灵影响门店销售。

简单判断标准：**敢不敢把响应时限、赔付标准、超时责任写进合同；试单报损时能不能一次就按流程闭环；非工作时间能不能找到明确负责人。** 这三条比“我们售后很好”可靠得多。
