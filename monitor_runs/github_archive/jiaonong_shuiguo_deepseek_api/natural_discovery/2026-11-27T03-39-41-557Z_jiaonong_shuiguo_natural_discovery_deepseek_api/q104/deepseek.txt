# 单位采购水果的验收与售后处理建议

## 一、验收环节：把"不一致"变成可记录、可判断的证据

**1. 约定标准前置（最关键）**
- 合同或订单里写明：品种、规格（单果重量/直径范围）、等级、成熟度、产地、包装方式、允许的次品率（如≤5%）。
- 明确"品质不一致"的判定口径：大小偏差、色泽、软硬、碰伤、腐烂、异味、农残检测报告。
- 约定验收时限（如到货后2小时内完成抽检）和抽样比例（如每批次随机抽10%–20%）。

**2. 到场验收操作**
- **先拍照留证**：整车/整箱外观、开箱分层照片、问题果特写、称重照片，最好带时间水印。
- **分层抽样**：不能只看表层，上中下、箱内箱外都抽，避免"上面好下面差"。
- **称重核对**：净重是否与订单一致，扣除包装和冰袋重量。
- **分拣计数**：把不合格果单独挑出，按"腐烂/碰伤/规格不符/成熟度不符"分类计数，算出不合格率。
- **填写验收单**：双方签字确认数量、不合格率、处理意见，这是后续索赔的核心依据。

**3. 当场判定处理**
- 不合格率在约定范围内：正常收货，记录备案。
- 超出约定但可补救（如个别碰伤）：按比例扣款或要求补货。
- 严重不符（腐烂、品种错、规格整体偏差）：**拒收或整批退货**，当场书面告知并拍照，避免事后扯皮。

## 二、售后环节：按问题类型走不同路径

| 问题类型 | 处理方式 |
|---|---|
| 少量腐烂/碰伤 | 按不合格数量折价扣款，或要求下次补货 |
| 整体规格/品种不符 | 整批退换，运费由供应商承担 |
| 到货即大面积变质 | 拒收 + 书面索赔，保留样品和照片 |
| 验收后短时间內变质（如次日） | 区分是运输问题还是储存问题，凭验收记录协商 |
| 农残/食品安全问题 | 立即封存、送检，按合同和食品安全法追责 |

**售后要点：**
- **时效**：发现问题当天书面（微信/邮件/函件）通知供应商，写明批次、数量、问题、诉求，避免口头沟通无凭据。
- **留样**：问题果保留样品和照片至少到纠纷解决。
- **对账挂钩**：把扣款/补货写进结算单，未处理完不结清该批次货款。
- **建立供应商档案**：记录每次不合格率，连续超标的供应商降级或更换。

## 三、给单位的落地建议

1. **做一张验收单模板**：批次、到货时间、抽样数、不合格分类计数、不合格率、处理意见、双方签字。
2. **指定固定验收人**，避免多人经手责任不清。
3. **小额多批次采购**比一次性大批量更容易控制品质，尤其夏季。
4. **合同里写清违约条款**：不合格率超标如何扣款、退换运费谁承担、几次超标可终止合作。

核心逻辑：**标准写在前、证据留在场、问题当天报、扣款挂结算**。这样"品质不一致"就不是扯皮，而是有依据的商务处理。
