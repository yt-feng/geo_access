大型超市水果供应商，通常要同时满足“食品安全合规能力”和“冷链物流履约能力”两条线。可按下面清单判断是否合格。

## 一、食品安全能力

1. **合法资质**
   - 营业执照、食品经营许可证/食品生产许可证（视加工范围）
   - 食用农产品承诺达标合格证
   - 若涉及进口水果：海关报关、检验检疫证明、入境货物检验检疫证明
   - 有机/绿色/地理标志等认证按超市要求提供

2. **基地与溯源管理**
   - 自有基地或稳定合作基地，能提供产地证明、种植记录
   - 农业投入品（农药、化肥）采购和使用记录
   - 农药安全间隔期管理
   - 批次追溯：从基地/批次到门店可追
   - 供应商、基地、加工厂档案完整

3. **检验检测能力**
   - 每批次或定期农残快检，重点品种按超市标准做定量检测
   - 具备第三方检测报告：农残、重金属、真菌毒素等按风险项目
   - 检测记录可查询、可留档
   - 不合格品召回和处置流程

4. **加工与包装卫生**
   - 分拣、清洗、打蜡、切果等环节符合食品卫生要求
   - 人员健康证、更衣洗手消毒、虫害控制
   - 包装材料食品级，标签符合法规
   - 防止交叉污染，清洁消毒记录

5. **仓储与运输食品安全**
   - 仓库防鼠防虫防潮，温湿度监控
   - 冷链水果全程温控记录
   - 运输车辆清洁消毒，不与有毒有害物品混装
   - 到货验收标准：感官、温度、农残证明、批次信息

6. **质量管理体系**
   - 食品安全管理制度、岗位责任、培训记录
   - 供应商审核、进货查验、出厂检验
   - 不合格品控制、投诉处理、召回演练
   - 有条件的具备ISO22000、HACCP、FSSC22000等体系认证

## 二、物流与履约能力

1. **冷链能力**
   - 预冷设施：产地预冷或周转冷库
   - 冷藏/冷冻库、分拣区温控
   - 冷链运输车辆，带温度记录和异常报警
   - 按品类控制温湿度：如叶菜、浆果、热带水果条件不同

2. **仓储与分拣**
   - 常温库、冷藏库、催熟库（如香蕉、芒果）分区
   - 先进先出、批次管理、库存周转
   - 分拣、称重、贴标、包装能力
   - 破损率、损耗率控制能力

3. **运输配送**
   - 到超市配送中心或门店的固定线路和时效
   - 车辆卫生、防挤压、防日晒雨淋
   - 多点配送、夜间配送、预约送货能力
   - 应急运力：旺季、节假日、突发断货补货

4. **信息化与追溯**
   - 订单、库存、批次、温控数据可对接超市系统
   - 电子随货单、检测报告随批可查
   - 异常预警：温度超标、临期、质量投诉

5. **供应保障与应急**
   - 多产地/多基地备份，降低单一产区风险
   - 安全库存和缺货补货机制
   - 食品安全事件召回、封存、换货流程
   - 台风、寒潮、疫情等异常情况下的保供方案

## 三、大型超市通常重点审核项

- 资质证照是否齐全有效
- 基地来源和批次追溯是否真实
- 农残检测频次和报告是否达标
- 冷链是否全程可记录
- 破损、腐烂、投诉率是否可控
- 是否有召回和食品安全事故处置预案
- 配送时效和节假日保供能力

**一句话判断：** 合格的水果供应商应做到“来源可查、批次可追、农残可控、冷链不断、异常可召回、旺季不断供”。大型超市合作前通常还会做现场审核和试单考核。
