# 水果品相不好的售后流程约定建议

核心原则：**到货即验、限时反馈、分级处理、责任可追溯**。建议在合同或采购单的服务条款中明确以下几项。

## 一、验收环节先卡住

1. **到货当场验收**：约定收货时双方（或收货人+司机）共同开箱验货，按比例抽检（如每批次抽检10%–20%，大宗可分层抽样）。
2. **验收标准写清楚**：不要只写"品相好"，要量化——
   - 外观：无腐烂、无霉变、无明显机械伤、着色度、果径/规格区间；
   - 允许的瑕疵比例：如单批次"明显瑕疵果"不超过3%–5%视为合格，超出部分按约定处理；
   - 分级：合格品、可折价品（轻微瑕疵）、拒收品（腐烂/变质）三类，附照片示例。
3. **验收单双方签字**，注明到货时间、批次、数量、抽检结果。这是后续追责的唯一依据。

## 二、反馈时限要设死

- 约定"到货后X小时内（建议4–24小时，视品类易腐程度）提出异议有效"，超时视为验收合格。
- 异议需附照片/视频+抽检记录，避免口头扯皮。
- 内部也要约定：门店/仓库收货后多久内上报，防止货压几天才说有问题。

## 三、分级处理方式

| 情况 | 处理方式 |
|---|---|
| 瑕疵比例在允收范围内 | 正常收货，不追责 |
| 轻微超标（如5%–10%） | 折价接收，按瑕疵比例扣款 |
| 严重超标或腐烂变质 | 整批或部分拒收，供应商换货或退款 |
| 已收货后发现隐蔽问题 | 限时内可退换，运费责任方承担 |

## 四、责任与费用

- 明确**运输损耗、冷链断链、到货延误导致变质**的责任归属（一般由供应商承担到交付验收为止）。
- 换货/退货的**运费、二次损耗**由责任方承担。
- 约定**扣款或赔付方式**：从货款中直接抵扣、补货、或按批次金额比例赔付，避免事后协商无据。
- 累计质量问题的**淘汰机制**：如月度不合格批次超X次，可终止合作或调降采购价。

## 五、留痕与对账

- 每批货建立记录：到货时间、验收结果、异议记录、处理结果，随对账单一起确认。
- 售后处理结果需双方书面（含微信/邮件）确认，避免月底对账时翻旧账。

## 一句话落地版条款

> "货到后由买方当场抽检，明显瑕疵果超过5%的部分，买方有权在到货后12小时内凭照片及验收单提出异议，卖方须在24小时内换货或按瑕疵比例折价，运费由责任方承担；超时未提异议视为验收合格。"

具体比例和时限要按你的品类（叶菜更短、根茎果类可放宽）和供应商议价能力调整，写在采购合同或年度框架协议里，比每次口头约定更有效。
