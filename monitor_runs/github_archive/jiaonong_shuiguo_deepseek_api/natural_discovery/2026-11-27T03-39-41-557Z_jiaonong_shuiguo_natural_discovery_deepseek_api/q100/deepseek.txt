食堂采购香蕉要想少浪费，核心不是“买更耐放的香蕉”这么简单，而是把**采购成熟度、分批到货、储存条件和消耗顺序**一起管起来。可执行的做法如下：

1. **按用途定成熟度，别统一买“黄透”的**
   - 当天或次日直接吃的：买黄熟、无明显黑斑的。
   - 2—3天后用的：买“黄中带一点绿尖”的。
   - 做香蕉奶昔、烘焙、香蕉粥等加工用途：可专收表皮有少量黑点的熟蕉，但当天用完。

2. **少量多次、分批到货**
   - 把一周采购量拆成2—3批，避免一次到货后集中转熟。
   - 与供应商约定“按成熟度分批送”，不要只按重量送。
   - 食堂按每日预计消耗量下单，宁可周中补货，不要一次性囤满。

3. **收货时按成熟度分级**
   - 收货即分：青黄蕉、黄熟蕉、即食蕉三档。
   - 即食蕉放取餐区优先消耗；黄熟蕉放阴凉通风处；青黄蕉单独存放催熟。
   - 有黑斑但果肉未坏的，及时转加工窗口，不要继续摆在水果台。

4. **储存别犯常见错误**
   - 香蕉不宜冷藏，低温会发黑、影响口感；放**阴凉、通风、避光**处。
   - 不要整箱密封闷着，打开包装透气。
   - 成熟香蕉会释放乙烯，催熟其他果蔬，最好与未熟水果分开。
   - 悬挂或单层摆放，减少压伤；伤果最先消耗。

5. **建立“先熟先出”的消耗顺序**
   - 每天早班检查一次成熟度，贴“优先食用”标识。
   - 水果台只摆当天能吃完的量，其余留在库房按成熟度轮换。
   - 临近周末少订即食蕉，避免周一集中变熟。

6. **给熟蕉留“消化出口”**
   - 食堂可固定设置香蕉加工品：香蕉牛奶、香蕉燕麦粥、香蕉松饼等。
   - 对表皮黑点较多但果肉完好的香蕉，规定当天转加工，不进入次日水果台。
   - 与供应商协商少量“熟蕉折扣”专供加工，反而能降低成本。

7. **用数据定采购量**
   - 记录近2—4周每天香蕉进货量、售出量、废弃量。
   - 按“日均实际消耗×1.1—1.2”订货，波动大的学校按天微调。
   - 遇到考试周、放假前后、天气突变，提前减量。

8. **验收标准写进采购约定**
   - 明确到货成熟度比例，例如：70%黄熟即食、30%青黄后熟。
   - 拒收严重压伤、果柄发霉、整箱过熟的批次。
   - 要求供应商小箱分装，避免大箱挤压和集中催熟。

最有效的组合是：**小批量多批次 + 按成熟度分级 + 先熟先出 + 熟蕉转加工**。只要每天有人看一眼成熟度并调整摆放和加工，浪费通常就能明显下降。
