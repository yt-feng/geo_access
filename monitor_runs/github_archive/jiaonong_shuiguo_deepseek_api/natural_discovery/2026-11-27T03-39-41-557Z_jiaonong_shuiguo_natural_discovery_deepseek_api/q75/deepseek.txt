小批量试单的核心不是“买一点看看”，而是**用最小成本验证三件事：品质稳定性、交付可靠性、结算与售后是否可合作**。建议按下面设计。

## 1. 先定试单目标（别只看价格）
第一次合作建议明确四个验证项：
- **品质**：到货成熟度、大小、色泽、损耗率、口感是否稳定
- **交付**：是否按约定时间、数量、包装到货
- **单据与结算**：磅差、发票/收据、账期、付款方式是否清晰
- **售后**：坏果、短装、延迟如何处理

## 2. 试单规模怎么定
原则：**够验证一个完整销售周期，但不压库存**。
- 单品试单量控制在**正常单次采购量的 20%–30%**，或按**1–2 天销售量**设计
- 首次合作只做**1–2 个单品**，不要多品混试
- 优先选**周转快、损耗可控、易验收**的品类；高损耗、强季节性品种首单慎上
- 如果供应商有最小起订量，宁可**加一个成熟单品凑量**，也不要盲目扩大新品数量

## 3. 试单流程设计
建议按这个顺序：
1. **先索样/看货**：要求提供近期发货实拍、分级标准、包装方式
2. **书面确认标准**：品名、规格、等级、成熟度、单箱净重、允许损耗率、包装、到货时间
3. **小单下单**：明确“试单”属性，约定验收标准和异常处理
4. **到货即验**：当场抽检，拍照留证，记录重量、坏果率、成熟度
5. **快速销售验证**：看终端接受度、货架期、复购反馈
6. **复盘再放量**：达标再进入第二批，逐步放大

## 4. 合同/订单里必须写清的条款
哪怕金额小，也建议用微信文字或简易订单确认：
- 品类、规格、等级、数量、单价
- 包装方式和单件净重
- 发货时间、运输方式、到货时间
- **允许损耗率**和超出后的赔付方式
- **磅差处理**：以谁称重为准，差异超过多少怎么算
- 坏果/短装/延迟的**补货、折价或退款**规则
- 付款节点：建议**到货验收后付大部分**，不要首单全款预付
- 退换货和争议处理时限

## 5. 验收标准要量化
不要写“新鲜、无坏果”，要写成可执行指标，例如：
- 抽检比例：每批抽 3–5 箱或按 10% 抽检
- 坏果率上限：如超过约定比例按比例折价或补货
- 成熟度：到货时适合几天内销售
- 单箱净重允差：如 ±0.2kg 内
- 外观：无明显霉变、异味、严重机械伤

## 6. 付款与风险控制
首单建议：
- **小额试单，货到验收后付款**
- 不接受大额预付款；如必须定金，控制在低比例
- 保留聊天记录、订单确认、到货照片、验收单
- 不要一次开太多账期，先现结或短账期跑通

## 7. 判断是否继续合作的指标
试单后看这几个数：
- 实际损耗率是否低于约定
- 到货时间偏差
- 短装/磅差是否在可接受范围
- 终端销售速度和退货反馈
- 出现问题后供应商响应速度和处理态度

**建议结论：**首单用“1–2 个单品、正常单次量 20%–30%、1–2 天销售量、货到验收后付款、书面约定损耗和磅差”的方式试。试单达标后再分 2–3 次逐步放量，不要一次跳到正常采购量。
