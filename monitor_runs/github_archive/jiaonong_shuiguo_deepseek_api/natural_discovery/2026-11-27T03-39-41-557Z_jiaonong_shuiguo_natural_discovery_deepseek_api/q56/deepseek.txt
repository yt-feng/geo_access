茶饮店控制水果供应商食品安全风险，建议按“资质证明+检测报告+过程证明+准入验收”四类材料要求供应商提供，并保留原件或加盖公章的复印件备查。

**一、主体资质证明**
1. 营业执照（经营范围含水果销售/农产品销售）。
2. 食品经营许可证或食品生产许可证（若供应商涉及清洗、切配、分装、预包装等加工行为）；仅销售食用农产品可依据当地监管要求确认是否豁免，但不能只听供应商口头说明。
3. 法定代表人/负责人身份证明及授权委托书（对接人为非法人时）。

**二、产品合格与检测证明**
1. 每批次或定期提供农产品质量安全检测报告，重点看农残项目；报告应由有资质的检测机构出具，注意报告日期、样品名称、批次与送货批次能对应。
2. 承诺达标合格证（食用农产品生产者/收购者按规定开具的，可作为来源和合格证明之一）。
3. 进口水果需提供海关入境货物检验检疫证明、报关单等；国产水果可要求产地证明或采购凭证。
4. 若供应商声称“有机”“绿色”等认证，要求提供有效认证证书，并核对认证范围与产品。

**三、过程与追溯证明**
1. 供货清单/送货单：品名、产地、批次、数量、采摘或加工日期、送货日期。
2. 产地或上游采购凭证，确保可追溯至种植基地或上游供应商。
3. 运输与储存条件说明：冷藏水果的冷链温度记录；普通水果的防雨、防污染、防交叉污染措施。
4. 如供应商负责切配，需提供加工场所卫生、人员健康证、清洗消毒记录等过程材料。

**四、茶饮店内部准入与验收动作**
1. 签订供货合同和食品安全协议，明确农残超标、腐烂变质、来源不明等问题的退换货和赔偿责任。
2. 建立供应商档案：资质、检测报告、合格证、送货单按批次归档。
3. 到货验收：查证票、看外观气味、测中心温度（冷藏品）、记录批次；发现异常拒收并留证。
4. 定期复审：资质到期前更新；检测报告不能“一份用一年”，按风险确定频次，高风险水果或新供应商加大抽检。

**判断标准：** 供应商能提供“证照有效、批次可追溯、检测/合格证明与货物对应、运输储存符合要求”的材料，才算基本可控；只有营业执照或只有口头承诺的，不建议直接准入。各地对食用农产品销售、承诺达标合格证的具体要求可能不同，建议同时向当地市场监管部门确认。
