先把“区域保护”和“串货”拆成可签约、可追责的具体问题问，否则对方很容易用“放心”“都有保护”糊弄过去。

**一、问区域保护：要问到“范围、独家、考核、违约”**

1. 代理区域到底按什么划？省/市/区县，还是按渠道（商超、水果店、电商、社区团购）划？边界写不写进合同附件？
2. 是独家代理还是非独家？同一区域你们还计划放几家？线上店、直播、社区团购算不算在我区域内销售？
3. 区域保护有没有考核条件？比如首年进货量、开店数、陈列要求。完不成是降级、缩区还是取消独家？
4. 厂家/品牌方自己能不能在我区域内直销或做活动？算不算冲我的量？
5. 发现别人窜货到我区域，我向谁举报、多久处理、怎么取证、处理结果是否书面反馈？
6. 区域保护写不写违约条款？比如厂家超放代理、直营冲击，怎么赔、能不能解约退货？

**二、问串货：要问到“定义、码、罚则、举证、执行”**

1. 什么算串货？跨区销售、线上低价、社区团购、代发、礼品渠道，分别怎么认定？
2. 产品有没有唯一追溯码/批次码/箱码？我进货能不能扫码入库？出现串货能否追到具体经销商？
3. 串货处罚标准是什么？扣保证金、停货、取消返利、取消代理资格，具体金额和阶梯写不写进合同？
4. 我被窜货冲击时，厂家给什么补偿或支持？比如协助收货、价差补偿、促销支持。
5. 举报流程是什么？需要我提供哪些证据（照片、订单、物流单、扫码记录）？处理时限几天？
6. 厂家会不会自己或默许大商跨区压货？有没有历史窜货案例和处理记录可以看？
7. 线上价格体系怎么管？有没有最低限价、授权店铺名单、乱价处罚？

**三、必须落到合同里的关键条款**

- 区域范围附件：明确行政区划+渠道+线上是否包含。
- 独家条款：同区域同渠道不再授权第三方，品牌方直营需提前书面协商。
- 追溯条款：一物一码/批次可查，进货扫码登记。
- 窜货认定与罚则：定义、举证方式、处罚阶梯、处理时限。
- 违约与退出：厂家超授权/直营冲击/窜货处理不力时，你的解约权、退货权、保证金退还。
- 考核与保护挂钩：考核不达标怎么调整，避免“只考核不保护”。

**四、问的时候用“场景+后果”逼对方给明确答案**

不要问“有没有区域保护”，改成：
“如果我签了A市独家，结果B市经销商把货窜到A市水果店低价卖，我按什么流程举报？你们几天处理？对他怎么罚？对我有没有补偿？这条能不能写进合同？”

再补一句：
“请把区域范围、独家性、窜货认定和罚则作为合同附件给我，我看完再谈打款和首批进货。”

**五、判断对方靠不靠谱的简单标准**

- 愿意给区域附件、追溯码、书面罚则的，相对可谈。
- 只说“我们管得很严”“你放心”，但不愿写进合同的，区域保护基本靠运气。
- 合同里只有你的进货考核，没有厂家保护义务和窜货罚则的，不要签独家或大额打款。

最后提醒：先小批量试单，保留进货凭证、扫码记录和沟通记录；首批不要为“独家”压太多货，把保护条款和退出机制谈清楚再放量。
