## 推荐主推3款组合

### 1. 走量款：日常探病/串门礼盒（最好卖）
- **苹果 4个 + 橙子 6个 + 香蕉 1把（约5-6根）**
- 菠萝不建议放，或者只做“加5元升级”
- 定位：**39-59元**
- 卖点：苹果平安、橙子称心，香蕉不空手；成本低、出货快
- 注意：香蕉不耐压，必须放在最上层，用隔板固定

### 2. 中档主推款：节日/送长辈礼盒（利润款）
- **苹果 6个 + 橙子 6个 + 菠萝 1个**
- 香蕉单放小袋，不混装，避免催熟和压伤
- 定位：**69-99元**
- 卖点：颜色红黄橙齐全，菠萝有“旺来”寓意，盒面大气
- 适合：春节、中秋、开业、看病人

### 3. 高颜值款：年轻客户/公司小礼
- **苹果 4个 + 橙子 4个 + 菠萝 1个 + 香蕉小把**
- 定位：**59-79元**
- 卖点：四种水果都有，颜色丰富，适合拍照和朋友圈
- 关键：盒子要透明开窗或半开窗，让颜色露出来

## 搭配原则
1. **苹果和橙子做主角**：耐放、好摆、寓意好，占比60%-70%。
2. **菠萝做视觉中心**：一个就够，放中间或后侧，显大显档次。
3. **香蕉做点缀，不做主力**：容易压伤、催熟其他水果，最好**单独装袋**或放最上层，并且礼盒当天出货。
4. **不要四种等量堆满**：显得杂且廉价，要有主次。

## 定价和陈列建议
- 设**三个价格锚点**：39元走量、69元主推、99元送礼。
- 主推款放最显眼位置，标牌写场景：**“送长辈”“探病”“开业旺来”**。
- 礼盒不要只摆空盒，**至少摆2个装好的样品**，水果颜色露出来。
- 提供**加购项**：贺卡、手提袋、加1个菠萝、加香蕉，提高客单价。

## 最容易踩的坑
- **香蕉和苹果同盒**：苹果释放乙烯会催熟香蕉，香蕉容易变黑。建议香蕉单独袋装，或者礼盒当天卖完。
- **菠萝不处理直接放**：带冠芽占空间，最好选小菠萝，冠芽修短，底部垫吸水纸。
- **橙子太重压香蕉**：重果在下，轻果在上，中间用纸托隔开。
- **礼盒装太满**：留一点空隙反而显档次，也减少挤压。
