核心思路：把“补货”从口头沟通变成到货验收标准 + 时限 + 替代方案 + 责任扣款，写进采购合同或每次订货单备注里，避免缺货停售。

**1. 到货验收标准写清楚**
- 品名、品种、规格（克重/果径/糖度范围）、成熟度、允许瑕疵比例（如坏果率≤3%）。
- 验收方式：抽样比例、拍照留证、当场过秤。
- 不合格判定：坏果率超标、规格不符、成熟度不足/过熟、农残或异味。

**2. 补货时限与方式**
- 约定“验收不合格后X小时内响应，Y小时内补货到店”，比如：2小时确认、当日营业高峰前补到。
- 明确补货是“换货”还是“补足差额”，不合格品退回或就地处理由供应商承担。
- 高峰时段保护：约定上午10点前到货的批次，若不合格须在午市前补齐；否则触发替代方案。

**3. 缺货替代方案（最关键）**
- 允许门店就近采购同规格替代品，差价由供应商承担或从货款扣。
- 约定替代品验收标准与供应商原货一致，保留小票和照片。
- 设置“紧急补货联系人”和备用供应商，合同里写明备用渠道启用条件。

**4. 责任与扣款**
- 延迟补货按小时计违约金，或按缺货导致下架单品的预估营业额比例扣款。
- 月度不合格率超过约定阈值，可暂停订单、要求整改或终止合作。
- 扣款从当批或当月货款中直接抵扣，避免事后追讨。

**5. 操作落地**
- 每次订货单附验收标准和补货条款，供应商签字或线上下单确认即视为同意。
- 门店保留验收照片、称重记录、沟通记录，作为扣款依据。
- 新供应商先小批量试供，稳定后再放量。

一句话：合同里写死“不合格判定—补货时限—替代采购—扣款抵扣”四件事，门店就不会因为等补货而停售。
