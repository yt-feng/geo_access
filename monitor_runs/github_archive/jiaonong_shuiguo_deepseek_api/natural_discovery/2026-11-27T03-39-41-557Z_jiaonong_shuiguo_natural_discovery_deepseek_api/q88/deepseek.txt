线上水果最怕的不是“有坏果”，而是坏果率高和口感波动大导致差评集中。采购端要把控制点前移，核心是做“分级采购+到货验收+批次追溯+售后兜底”。

**1. 先定可验收的采购标准**
不要只写“新鲜、甜”，要写成可测指标：
- 品种、产区、采收期、果径/单果重区间；
- 成熟度或糖酸度范围（如糖度下限、酸度上限，按品类定）；
- 允许缺陷比例：坏果率、机械伤率、裂果率、畸形果率分别设上限；
- 口感一致性要求：同一批次糖度波动范围、软硬度和汁水感；
- 包装和运输温湿度要求。

**2. 选供应商看“稳定性”而不是只看低价**
优先选择有分级线、预冷能力、冷链和批次管理能力的供应商。采购前要求提供：
- 近几批次的质检记录和糖度抽检记录；
- 产地天气、采收进度和库存周转情况；
- 是否按大小、成熟度、外观做过分级；
- 坏果赔付和补发规则。

**3. 到货验收必须抽检并留样**
每批到货按比例抽检，重点看：
- 坏果、压伤、裂口、霉变；
- 同批次糖度差异和软硬差异；
- 中心温度、包装内冷凝水、异味；
- 运输时长和途中温控记录。

抽检结果直接决定“全收、降级收、拒收或折价收”，不要等上架后靠客服补救。留样和拍照记录用于后续追责和复盘。

**4. 采购节奏上减少“赌批次”**
- 新供应商先小批量试销，连续几批稳定后再放量；
- 同一单品不要过度依赖单一产区或单一批次；
- 高温季、雨季、节假日前适当提高验收比例；
- 对易损品类缩短在仓时间，优先“产地直发+预售+近场仓”。

**5. 用分级销售降低口感预期错位**
同一批果按糖度、大小、成熟度分级：高端款、标准款、特价款分开卖，详情页写清口感特征和适宜食用时间。口感不稳定的批次不要混卖，否则差评会集中到同一链接。

**6. 售后规则要前置**
明确坏果赔付比例、拍照要求、补发/退款时效；对高风险批次主动做“坏果包赔”提示。采购合同里约定坏果率超标后的扣款、补发和责任分担。

**最有效的落地顺序**：先定品类验收标准 → 供应商小批试单 → 每批抽检留样 → 按批次分级销售 → 差评按批次回溯采购。这样能把“坏果和口感不稳定”从售后问题变成采购验收问题。
