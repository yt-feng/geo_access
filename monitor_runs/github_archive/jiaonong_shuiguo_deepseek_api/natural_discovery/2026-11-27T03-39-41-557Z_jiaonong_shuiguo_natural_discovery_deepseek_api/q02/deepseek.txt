这四项不是并列选，建议按这个优先级判断：**坏果率 → 熟度 → 送货速度 → 价格**。对小水果店来说，香蕉是易损耗、周转要快、 customer 对卖相敏感的品，先保证能卖出去、少报损，再谈进价低。

具体可执行判断：

1. **坏果率优先**
   - 香蕉最怕“进价便宜但坏得多”，坏果、压伤、黑斑多会直接吃掉毛利。
   - 建议定一个收货底线：明显压伤、断裂、发黑、霉变的拒收或扣重；连续两次坏果率高的供应商降级。
   - 小水果店单次进货量不大，宁可单价略高，也要稳定少损。

2. **熟度第二，但要按销售节奏选**
   - 不要只问“熟不熟”，要问“几成熟”。按你预计几天卖完选：
     - 当天/次日卖完：可接偏熟、带少量芝麻点的。
     - 2—3天卖完：接7—8成熟、青黄相间、硬挺的。
     - 周转慢：接更青一点，但要有催熟条件，别接太生导致几天不变黄。
   - 熟度不匹配销售速度，比价格贵更伤利润。

3. **送货速度第三**
   - 香蕉怕反复搬运和高温挤压，送货慢、装卸粗会显著增加压伤和催熟失控。
   - 但速度不是越快越好，关键是**稳定、准时、轻拿轻放**。固定时段到货，方便你安排上架和催熟。
   - 如果供应商送货快但每次压伤多，仍应降级。

4. **价格最后看，但要看“到手可售成本”**
   - 不要只比每斤进价，要算：进价 ÷ 可售比例，再加损耗、运费、人工。
   - 例：A家便宜但坏果多、熟度不匹配，实际可售成本可能更高；B家贵一点但稳定少损，反而更划算。

**简单决策规则：**
- 新供应商先小批量试单，重点记录：坏果率、到货熟度、到货准时率、可售比例。
- 稳定供应商里再谈价格；价格明显低但坏果率或熟度不稳定的，不作为主供。
- 小水果店最好有**1家主供 + 1家备供**，避免断货时被迫接高价或差货。

一句话：**先卡坏果率和熟度，保证卖得掉、损得少；再要求送货稳定；最后在合格供应商里比价格。**
