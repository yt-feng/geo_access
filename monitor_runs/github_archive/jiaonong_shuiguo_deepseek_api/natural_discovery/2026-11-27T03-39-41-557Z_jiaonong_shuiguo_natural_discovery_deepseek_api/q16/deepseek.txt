建议用“分层供货”而不是二选一：**香蕉以本地批发为主，苹果以稳定供应商为主**，再各留一个备用渠道。理由如下。

**香蕉**
- 香蕉成熟快、损耗高，社区超市通常需要小批量、高频补货，能根据当天销量调整熟度。
- 本地批发更适合灵活补货、处理催熟和尾货，运输半径短，断货时容易临时补。
- 风险是品质和价格波动大，所以要固定1个主批发商+1个备用摊位，要求按熟度分级，先小批量试供。
- 如果本地批发无法稳定提供合适熟度，或损耗一直偏高，再转向能按周配送的稳定供应商。

**苹果**
- 苹果耐储存、品种和等级要求明确，顾客更在意口感和外观一致性，适合稳定供应商。
- 稳定供应商能保证规格、糖度、包装和持续供货，便于定价和减少退货。
- 建议先选1家主供应商，签短期试供，明确等级、大小、瑕疵率和到货时间；同时保留1个本地批发作为旺季或临时补货渠道。

**可执行的判断方法**
1. 先各试供2周：香蕉每天或隔天补，苹果每周2次。
2. 记录4个数：到货损耗率、缺货次数、顾客复购/投诉、实际毛利。
3. 香蕉看“熟度可控+损耗低+补货快”；苹果看“规格稳定+口感一致+价格可预期”。
4. 任何一类主渠道连续两周损耗高或缺货，就切换或增加备用渠道。

对社区超市来说，**香蕉偏本地灵活，苹果偏稳定供应**是最稳妥的组合。
