甜度和出汁率不是二选一，优先级取决于你买的是**鲜果**还是**果浆/冷冻果肉**，以及主打产品。

**结论先说：**
- **买鲜菠萝做现切/手打柠檬茶/菠萝茶**：**出汁率优先，甜度次之**。出汁率低会导致出品量不稳定、损耗高、成本不可控；甜度可以用糖浆微调，但酸涩和纤维感难救。
- **买冷冻果肉/果浆/浓缩汁做标准化饮品**：**甜度/风味稳定性和糖酸比优先**。出汁率由供应商工艺决定，你更该看可溶性固形物、pH、香气和批次稳定性。
- **做纯果茶、突出“鲜果感”**：两者都要，但先卡**出汁率下限**，再选出汁达标里**糖酸比合适**的。

**可执行判断标准：**
1. **先算出汁率底线**：按你的单杯用量和损耗反推。比如单杯需果肉80g，鲜果出肉率50%，那1kg原料只够约6杯；出肉率40%就只剩5杯，成本差20%以上。
2. **甜度不要只看“甜”**：看**糖酸比**。菠萝甜但酸低会寡淡，酸高会压茶香。鲜食/饮品常用糖酸比大致在**12–20**区间更适口，具体按你的糖浆添加量调。
3. **出汁率看两个指标**：**出肉率/出汁率**和**纤维粗细**。纤维粗、芯硬会堵滤网、影响口感，实际可用率比标称低。
4. **批次稳定性优先于单次极值**：茶饮店最怕这周甜下周酸。鲜果选固定品种和产区，冷冻/果浆选固定供应商并做糖度、pH验收。
5. **按产品定位排权重**：
   - 走量型菠萝茶：出汁率＞糖酸比＞香气
   - 高端鲜果茶：香气和糖酸比＞出汁率，但出汁率不能低于成本线
   - 小料/装饰：甜度外观＞出汁率

**一句话：鲜果先保出汁率和可用率，再调甜度；加工原料先保甜度/糖酸比和批次稳定，再看出汁率。**
