评估水果供应商的仓配覆盖，核心不是看它“号称覆盖多少城市”，而是看它能否稳定满足你连锁门店的时效、温控、损耗和成本约束。建议按下面框架做，可直接落地。

## 一、先定义需求，不要先看供应商

先把你自己的门店需求量化，形成评估基线：

1. **门店分布**：按城市/区域列出门店数、单店日均销量、SKU结构、旺季峰值。
2. **时效要求**：水果品类分档，比如叶菜/浆果类要求次日达甚至当日达，根茎类可放宽到48小时。
3. **温控要求**：常温、冷藏、冷冻分别占比，是否需要全程冷链、到店温度记录。
4. **订货模式**：日配、隔日配、周配；是否允许拼车、拆零、多温区共配。
5. **损耗与验收标准**：到货合格率、损耗率上限、拒收规则。
6. **成本口径**：到店价是否含运费、装卸、退货；最低起订量。

把以上整理成一张“门店-城市-品类-时效-温控”矩阵，作为供应商打分基础。

## 二、仓配覆盖的四层评估

### 1. 仓网布局：看“有效覆盖”，不看“名义覆盖”

- 供应商在你门店所在城市或周边300公里内是否有**自营仓/合作仓/中转仓**。
- 每个仓的服务半径、日处理能力、是否支持多温区。
- 关键判断：**门店到最近仓的干线距离和配送圈层**，而不是供应商总部在哪。
- 要求供应商提供仓网清单：仓库地址、面积、温区、覆盖城市、日均出货量。

### 2. 配送能力：看“稳定履约”而非“能送到”

- 配送是自营车队还是外包？外包比例多高？
- 到店时效承诺：下单截止时间、发货时间、到店时间窗。
- 是否支持**多门店拼车、拆零配送、预约到店、卸货交接**。
- 旺季和节假日运力保障方案，是否有备用运力。
- 要求提供近3个月**准时到店率、缺货率、破损率、温度异常率**的实际数据，最好能抽验门店签收记录。

### 3. 冷链与品控：水果损耗的关键

- 从产地/加工仓到门店是否**全程温控可追溯**，是否有温度记录仪和异常报警。
- 冷藏车/保温箱/冰袋方案是否匹配品类。
- 到店验收标准是否清晰：温度、外观、糖度、成熟度、批次追溯。
- 损耗责任如何划分：运输损耗、到店拒收、临期处理。

### 4. 成本与商务：算“到店总成本”

不要只比报价，按**到店总成本 = 货价 + 运费 + 装卸 + 损耗 + 退货 + 管理成本**比较。重点确认：

- 是否按门店单独起订，起订量是否会导致小门店被迫压库存。
- 多城市配送是否加价，偏远门店是否有附加费。
- 退货、补货、临期处理的费用和时效。
- 账期、对账方式、异常赔付条款。

## 三、落地评估方法

**第一步：桌面筛查**
让供应商填写标准化表格：仓网清单、覆盖城市、时效承诺、温区能力、运力模式、近3个月履约数据、报价口径。没有数据的供应商直接降权。

**第二步：门店抽样试跑**
选3类门店各1-2家：核心城市大店、周边城市中型店、偏远/小销量店。试跑2-4周，记录：
- 准时到店率
- 到货合格率/损耗率
- 温度达标率
- 缺货/短装次数
- 门店收货耗时
- 实际到店成本

**第三步：打分决策**
建议权重：仓网有效覆盖25%、履约时效25%、冷链品控20%、成本20%、应急与商务10%。用试跑数据校准，不只看承诺。

**第四步：合同约束**
把时效、温控、损耗上限、赔付、旺季保障、数据回传写成SLA，按月考核，不达标有扣罚或退出机制。

## 四、常见坑

- **名义覆盖 vs 有效覆盖**：供应商说覆盖全国，但你的门店在三四线城市可能只是“中转+第三方落地配”，时效和温控不可控。
- **只看干线不看落地配**：水果损耗往往发生在最后一段到店配送。
- **忽略小门店起订量**：导致小门店库存积压、损耗上升。
- **没有试跑就签长约**：多城市连锁尤其要用小范围试跑验证。
- **数据不可追溯**：没有温度记录和签收数据，出了问题无法定责。

**一句话结论**：评估水果供应商仓配覆盖，要围绕“你的门店矩阵”做有效覆盖验证，用仓网清单+履约数据+门店试跑+到店总成本四件事来判断，最后用SLA锁住时效、温控和损耗责任。
