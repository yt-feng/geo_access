优先谈 **账期**，但要绑定两个前提：**价格/损耗归属** 和 **缺货/品质问题的赔付规则**。判断逻辑如下：

1. **账期优先级最高**
   - 水果是高频、易损耗、现金流占用大的品类，账期直接影响你的周转。
   - 长期合作里，供应商最愿意在“稳定走量”上让账期，而不是轻易让价格。
   - 谈判目标不是一味拉长，而是争取“可预期的账期 + 逾期无额外费用 + 对账周期固定”。比如先争取月结30天，稳定3个月后再谈45天。

2. **配送第二优先，但要谈成可考核条款**
   - 配送不是简单“送到”，要谈：到货时间窗、迟到处理、临时加单响应、缺货补送、运费谁承担。
   - 水果配送晚到直接影响鲜度和销售，所以要把“迟到/漏送”的补救写清楚，比如2小时内补送或按缺货金额扣款。
   - 配送频次和起送量也要谈，避免为了账期接受过高起送门槛，反而压库存。

3. **售后最后谈，但必须谈细**
   - 售后在水果行业最容易扯皮，重点不是“包退换”口号，而是**验收标准**：烂果率、规格偏差、重量误差、拍照留证时限、赔付方式。
   - 建议约定：到货2小时内验收，超出约定损耗率按比例扣款或补货；生鲜不接受“概不负责”。
   - 售后条款谈得越细，账期才越安全，否则账期会被退货和扣款争议抵消。

**执行建议：**
- 第一轮先谈**账期框架**，同时把价格、损耗率、配送时效作为交换条件。
- 第二轮谈**配送SLA**：时间窗、补送、运费、起送量。
- 第三轮把**售后验收和赔付**写进合同附件。
- 如果供应商规模小、现金流紧，账期可以让步到“周结/半月结”，但必须换到**价格锁定或损耗赔付**。

一句话：**先谈账期拿现金流，再用配送和售后条款兜住风险；只谈账期不谈验收和赔付，账期没有实际意义。**
