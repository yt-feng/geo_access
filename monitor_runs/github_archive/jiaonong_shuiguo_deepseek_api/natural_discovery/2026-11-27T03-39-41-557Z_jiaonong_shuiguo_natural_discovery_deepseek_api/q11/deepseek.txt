会影响，但影响多大取决于你怎么卖。

**结论：大小不一会影响销售，但不是致命问题，关键看是否分级和定价。**

具体判断：

1. **整箱统货卖**：影响较大。大小混杂会让顾客挑拣、翻动，损耗增加，卖相变差，尤其香蕉容易碰伤。顾客会觉得“这一箱不值这个价”。

2. **分级销售**：影响小很多。把大果、中果、小果分开，按不同价格卖，反而能覆盖不同客群：
   - 大果：礼盒、单根高价
   - 中果：主力零售
   - 小果：低价促销、切果盘、做香蕉奶昔原料

3. **采购时的建议**：
   - 如果整箱价明显低于分级货，且你有分拣人力，可以进。
   - 如果箱内大小差异过大、成熟度也不一致，建议压价或换货，因为分拣成本和损耗会吃掉利润。
   - 香蕉成熟度不一致比大小不一更影响销售，采购时优先看成熟度是否均匀。

4. **销售端可执行动作**：
   - 到货当天分拣，按大小分三档定价。
   - 小果和碰伤果及时做促销或加工，不要混在好果里。
   - 陈列时同档位放一起，避免顾客翻箱挑拣。

**一句话：大小不一会影响销售，但通过分级定价可以转化为多档销售；如果不想分拣，就尽量采购规格较均匀的货。**
