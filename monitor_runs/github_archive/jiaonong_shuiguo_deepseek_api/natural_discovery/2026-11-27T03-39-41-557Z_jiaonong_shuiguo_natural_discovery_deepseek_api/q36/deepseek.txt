建议**以整果为主、切果为辅**，具体看门店客群和损耗管理能力。给你一个可执行的判断框架：

**优先卖整果的情况**
- 门店客群以家庭采购、中老年顾客为主，整果更符合习惯。
- 门店有称重、削皮服务能力，整果附加值能提上来。
- 菠萝进价低、周转快，整果毛利和损耗都更可控。
- 整果耐放，适合做堆头、促销引流。

**优先做切果的情况**
- 门店在办公区、商圈、年轻客群集中，即食需求强。
- 门店有冷藏陈列和日清能力，能控制切果损耗。
- 切果能带动客单价，适合做果切拼盘、下午茶场景。
- 但切果损耗高、保质期短，必须“少量多次、当日清货”。

**更稳的组合策略**
1. **整果做引流和毛利**：主陈列整果，提供免费或低价削皮服务。
2. **切果做增量**：只做小份装，按小时补货，闭店前打折清货。
3. **按门店分级**：社区店整果为主；商圈店、写字楼店切果比例提高。
4. **看数据调整**：连续两周看整果动销率、切果损耗率、客单价，再决定配比。

**关键判断指标**
- 整果：动销率、削皮服务使用率、损耗率。
- 切果：日清率、损耗率、切果客单价、复购率。
- 如果切果损耗率超过可接受范围，就缩减切果SKU，不要硬推。

一句话：**整果是基本盘，切果是增量盘；先小批量测试切果，再按门店客群和损耗数据调整比例。**
