这四个指标不是并列关系，应该先定“角色”：**甜度决定复购，外观决定进店转化，大小和切果损耗决定毛利**。如果只能排优先级，建议是：

**甜度 ≥ 切果损耗 ＞ 外观 ＞ 大小**

具体判断：

1. **甜度优先**
   - 菠萝是典型“买一次不好吃就不再买”的水果，甜度不稳定会直接伤复购。
   - 超市很难逐个测糖，实操上看：品种、产地、成熟度、进货批次稳定性。
   - 建议建立批次验收：同一供应商连续两批甜度差，就降级或换货。

2. **切果损耗要重点算**
   - 如果超市做鲜切菠萝，损耗比大小更关键。
   - 关注：去皮去眼损耗率、坏心黑心比例、切后氧化变色、当日未售完折价。
   - 建议算“可售果肉成本”，不要只看整果进货价。
   - 鲜切占比高时，切果损耗应排在甜度之后第一位。

3. **外观是流量指标，不是核心利润指标**
   - 外观好能降低顾客挑选阻力，但外观好不等于甜。
   - 外观标准应服务分级：精品果、普通果、鲜切果分开陈列和定价。
   - 不要为了外观统一大量淘汰，否则损耗转嫁到成本。

4. **大小要看客群和定价**
   - 家庭客群偏中小果，一次吃完、价格门槛低；多人家庭或礼盒才偏大果。
   - 大小均匀有利于陈列和定价，但不应压过甜度和损耗。
   - 大果不一定毛利高，皮厚、芯大、切损耗高时反而差。

**可执行建议：**
- 整果销售为主：**甜度 ＞ 外观 ＞ 大小 ＞ 切果损耗**。
- 鲜切销售占比高：**甜度 ＞ 切果损耗 ＞ 大小 ＞ 外观**。
- 设三个验收动作：批次试吃、抽切开果看黑心/坏心、记录每批去皮出肉率。
- 定价用“出肉率”倒算，不要只按斤进价加价。
