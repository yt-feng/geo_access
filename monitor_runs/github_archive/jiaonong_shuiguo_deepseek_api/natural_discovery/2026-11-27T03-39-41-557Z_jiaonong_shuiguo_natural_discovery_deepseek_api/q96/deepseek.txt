这三项不是同一层级的问题：**食品安全是底线，价格是约束条件，配送准时是保障条件**。企业食堂采购水果时，建议按这个顺序判断：

1. **食品安全优先，一票否决**
   - 水果是生鲜，存在农残、霉变、运输污染、储存温度不当等风险。
   - 企业食堂面向群体供餐，一旦出现食安问题，影响面大、责任重。
   - 应要求供应商提供检测报告/承诺达标合格证、进货查验记录，保留批次追溯信息；验收时看新鲜度、有无腐烂霉变、包装和运输卫生。

2. **配送准时是硬约束，但服务于食安**
   - 水果配送不准时，会打乱食堂备餐、导致临时替代或积压变质。
   - 但准时不能以牺牲冷链、新鲜度为代价。应把“准时率+到货合格率”一起考核。
   - 建议约定到货时间窗口、迟到处理、缺货替代规则。

3. **价格重要，但放在满足前两项之后**
   - 水果价格波动大，适合比价、锁价或随行就市加浮动上限。
   - 不应单纯追求最低价，否则容易换来低品质、以次充好或断供。
   - 可比较“同等品质规格下的综合成本”，包括损耗率、退换货成本。

**可执行结论：**
- 采购准入：食品安全不达标直接淘汰。
- 供应商选择：在合格供应商中，优先看配送稳定性和品质合格率，再比价格。
- 合同考核：食安权重最高，配送准时设为硬性条款，价格用比价和波动机制控制。
- 日常验收：每批次查证、看外观、测温度/储存条件，留样和记录。

一句话：**食品安全决定能不能买，配送准时决定能不能稳定用，价格决定划不划算；顺序不能倒。**
