# 商超水果采购压价不谈崩品质的谈判方法

核心原则：**压价要压“结构成本”，不压“果品本身”**。直接砍单价最容易换来降级货、掺次果、缺斤少两。下面按可执行顺序给方法。

## 一、谈判前：先把“品质”量化成可验收条款

价格谈判必须有验收标准兜底，否则压下来的价一定在品质上找回来。建议谈价前先定死：

- **规格标准**：单果重量区间、果径、糖度（如≥12°）、着色率、成熟度。
- **等级定义**：一级果/统货的明确区分，写明允许的次果比例上限（如≤3%）。
- **验收方式**：到货抽检比例、糖度抽测、破损率与损耗责任归属。
- **扣罚条款**：不合格批次的退货、折价、补货规则。

有了这套，“压价”就变成“在明确标准下比价”，供应商无法用降级来消化降价。

## 二、压价压这四类“结构成本”，不碰果价本身

1. **包装与物流**：换周转箱替代纸箱、合并发货批次、自提或指定物流、减少过度包装——这部分降本不影响果品。
2. **账期与结算**：现结/短账期换价格折让，或用稳定回款换返点；这是供应商最愿意让的。
3. **采购量与节奏**：承诺年度/季度采购量、锁定单品包园或包量，换阶梯价；淡季提前锁货换低价。
4. **损耗共担**：把门店端损耗数据拿出来，谈“到货合格率提升换单价下调”，双方一起降总成本，而不是单压单价。

## 三、谈判话术与筹码

- **用总量说话**：“这个单品我们全年走X吨，愿意签量价协议，你给阶梯价。”
- **用对比施压**：“同规格同糖度，另一家报的是X，你能否在包装和账期上做优化做到这个价？”——比的是同标准，不是裸价。
- **给交换条件**：现结、免入场费、陈列位、联合促销，换取价格或返点，而不是单向砍。
- **留台阶**：不追求一次砍到底，谈“试销一个月+达标后调价”，降低对方抗拒。

## 四、守住三条底线

- **不压到低于合理成本线**：明显低于市场成本的报价，必然是降级、掺货或短斤少两，长期总成本更高。
- **不口头压价**：所有价格、规格、扣罚写进合同或订单附件。
- **不只看单价看总成本**：把损耗率、退货率、客诉、称重差异算进去，综合毛利才是真成本。

## 五、落地检查清单

- [ ] 品质标准已量化成验收条款
- [ ] 本次压价明确落在包装/物流/账期/量级哪一项
- [ ] 有同标准竞价比价
- [ ] 有阶梯价或量价协议
- [ ] 扣罚与退货规则书面化
- [ ] 试销期+达标调价机制

一句话总结：**把“降价”翻译成“降结构成本+明确验收标准+给交换条件”，价格能下来，品质守得住。**
