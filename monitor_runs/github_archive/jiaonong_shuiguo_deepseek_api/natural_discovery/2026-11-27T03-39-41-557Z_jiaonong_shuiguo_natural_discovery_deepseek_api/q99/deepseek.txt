选择公司下午茶水果的批量配送供应商，按下面几项做筛选和验证，基本就能避免踩坑。

## 1. 先明确需求，再去找供应商
采购前先确定4件事，否则容易被供应商带节奏：
- **人数和预算**：多少人、人均多少钱（下午茶水果常见人均8–15元）。
- **配送频率**：每周1次还是每天，固定周几。
- **配送时间窗口**：比如下午2点前必须到，写进合同。
- **水果形式**：整果、果切拼盘、还是混合果盒。果切方便但保鲜和卫生要求高，整果便宜但员工体验差一些。

## 2. 供应商类型怎么选
| 类型 | 适合场景 | 注意点 |
|---|---|---|
| 本地水果批发商/档口 | 量大、预算紧、有固定收货点 | 需要自己协调配送，品控靠人盯 |
| 生鲜电商企业购（如美团、京东企业版等） | 中小批量、要发票、要稳定售后 | 价格略高，选品有限 |
| 本地果切/下午茶配送商 | 要开箱即食、体验好 | 重点查卫生资质和冷链 |
| 水果店长期合作 | 小公司、灵活 | 议价空间小，旺季可能断供 |

**优先找本地有企业客户案例的供应商**，跨城配送的水果损耗和时效风险高。

## 3. 必须验证的4个硬指标
1. **资质**：营业执照、食品经营许可证；做果切的还要看冷链和操作间卫生情况。
2. **配送能力**：是否有自有车辆/冷链，能否承诺送达时间，迟到怎么赔付。
3. **品控机制**：坏果率怎么算、怎么补，是否支持到货验收后拍照报损。
4. **发票和账期**：能否开专票、月结还是现结，这直接影响采购流程。

## 4. 先小批量试单
不要一上来签长期合同。**先试单2–3次**，重点看：
- 实际到货和样品是否一致；
- 坏果率（超过5%就要求补货或换供应商）；
- 配送是否准时；
- 售后响应速度。

## 5. 合同里写清楚这几条
- 单品规格（比如苹果单果多少克、几级果）；
- 坏果赔付标准（比如坏果超3%按比例退款或补发）；
- 配送时间和迟到处理；
- 价格调整机制（水果价格波动大，约定按周或按月调价）；
- 临时加量/减量的提前通知时间。

## 6. 一个实用做法
找**2家供应商并行**：一家主力、一家备选。主力出问题时不至于下午茶开天窗，同时也能形成比价压力。

总结一句话：**先定需求和预算 → 找本地有企业配送经验的供应商 → 验资质和售后 → 小批量试单 → 合同写清品控和赔付**。按这个顺序走，比单纯比价更靠谱。
