判断香蕉一手货源稳不稳，别只听“我是产地直发”，要按可验证的硬指标逐项过。下面给你一套批发档口可直接用的判断清单。

**1. 先看对方是不是“真一手”**
- 问清楚：是自有基地、长期包园，还是产地经纪人/代采。
- 真一手通常能说清：产区具体县镇、品种（巴西蕉/威廉斯/皇帝蕉等）、大致种植面积或合作农户数、催熟还是青蕉。
- 要求看：果园/包装厂视频、装车现场、包装箱标识、产地证明或购销合同。只发网图、拒绝实时视频的，降级。
- 注意“一手”不等于“最低价”，稳定供货的核心是**有固定货源组织能力**，不是嘴上说产地。

**2. 用“小单+连续单”测试稳定性**
- 首单不要压大，先做1—2车或小批量试单。
- 连续下3—5批，观察：能否按约定时间到货、重量是否足、等级是否一致、损耗率是否稳定。
- 稳定供货商的特点是**批次差异小**；不稳定的是第一批好、后面换货、掺级、拖延。

**3. 查履约能力，不只看报价**
重点问并写进合同/聊天记录：
- 日/周可供量、最小起订量、旺季淡季供应变化；
- 装车时效、运输方式、到货城市和时效；
- 遇雨天/台风/寒害/节假日，替代方案是什么；
- 是否支持锁价、锁量，锁多久；
- 断供或延迟的赔付规则。

**4. 验货标准要前置**
香蕉最容易扯皮的是成熟度、条蕉饱满度、青硬度、机械伤、病虫害、把形和单把重量。要求对方明确：
- 采收成熟度、到货成熟度；
- 等级标准（条长、粗度、每把条数、允许花皮/黑斑比例）；
- 损耗怎么算、谁承担、怎么补货。
能把这些说细并敢写进协议的，通常比只报低价的靠谱。

**5. 看资金和结算方式是否合理**
- 长期稳定供货一般不会要求你每次全款预付给陌生个人账户。
- 优先对公账户、可开票、有固定经营主体。
- 首次合作可谈“定金+到货验收尾款”或平台担保；对方强烈要求大额全款且拒绝任何保障的，风险高。
- 查营业执照、经营年限、是否有包装厂/冷库/催熟库，能实地看最好。

**6. 交叉验证口碑**
- 问同市场同行是否拿过他的货；
- 看其装车视频是否长期同一包装厂、同一车牌/司机；
- 让其提供2—3个现有批发客户（可先电话核实）。
注意：只给“朋友说好”的不算，能给可回访客户的更可信。

**7. 几个高风险信号**
- 报价明显低于产区主流价，还承诺长期锁价；
- 什么产区、什么品种都能供，量要多少有多少；
- 只催定金，不让看货、不让视频、不签简单协议；
- 频繁换收款账户、换公司名；
- 首批很好，第二批开始掺级、缺斤、拖延。

**实操建议：**先按“小批量试单—连续3批—验货标准书面化—再谈长期锁量”的顺序走。真正稳定的供货商，敢让你看现场、敢写损耗和赔付、敢接受小单测试；只靠低价和口头承诺的，不建议把档口主货押上去。
