学校食堂采购水果，核心是**合规、稳定、可追溯、性价比**，不要只看单价。建议按下面流程选香蕉、苹果、橙子供应商。

### 1. 先定采购标准，不要先找供应商
先把验收标准写进采购文件，避免后期扯皮：

- **香蕉**：成熟度可分级，到货时7–8成熟，果指饱满、无黑斑腐烂、无冻伤；允许少量运输擦伤但不影响食用。
- **苹果**：品种、规格统一，脆度、着色、果径分级明确；无腐烂、无严重碰压伤、无药斑异味。
- **橙子**：果径、糖酸度、皮厚、籽量可接受范围明确；无霉烂、无严重失水、无冻伤。
- **通用要求**：农残检测合格、来源可追溯、冷链或常温运输条件符合品类要求、包装标识完整。

### 2. 供应商准入条件
优先选能提供以下材料的供应商：

- 营业执照、食品经营许可证或食用农产品销售相关资质；
- 产地证明、进货凭证、承诺达标合格证或农残检测报告；
- 稳定供货能力证明：配送车辆、仓储、分拣能力、应急补货能力；
- 食品安全责任保险、退换货和赔付承诺；
- 学校食堂同类供货案例，可实地或电话核验。

### 3. 供应商类型怎么选
常见有三类，建议组合使用：

- **一级批发商/产地合作社**：价格有优势，适合香蕉、橙子等大宗单品，但要看分拣和配送能力。
- **本地水果配送商**：响应快、退换货方便，适合苹果等日常稳定供应，但单价可能略高。
- **大型商超或供应链平台**：合规材料齐全、票据规范，适合作为备选和应急渠道。

建议**主供应商1家+备选供应商1–2家**，避免单一供应商断供。

### 4. 比价不要只比单价
用“综合到货价”比较：

- 单价 + 损耗率 + 配送费 + 退换货成本；
- 按可食部分或实际合格到货量折算；
- 要求供应商按固定规格报价，例如香蕉按每箱净重、苹果按果径等级、橙子按果径和糖度范围。

### 5. 试供和小批量验收
正式合作前做2–4周试供：

- 每次到货抽检数量、重量、成熟度、腐烂率、碰压伤率；
- 记录迟到、缺货、退换货响应时间；
- 香蕉重点看催熟均匀度和到货后货架期；
- 苹果重点看批次一致性和脆度；
- 橙子重点看失水、霉变和口感稳定性。

### 6. 合同关键条款
合同里写清楚：

- 品类、规格、等级、单价或调价机制；
- 最低供货量和应急补货时限；
- 验收标准和不合格处理：退货、换货、扣款、终止合作；
- 农残检测和来源追溯责任；
- 食品安全事故赔付责任；
- 价格随行就市时，约定参考市场价和调价周期，避免口头涨价。

### 7. 简单可执行的筛选办法
让每家供应商同时报香蕉、苹果、橙子三个单品，并提交资质和检测材料；先小批量试供两周；按“合格到货率、损耗率、响应速度、票据合规、价格”五项打分，选总分最高的做主供应商，第二名做备选。

**一句话原则：先定验收标准，再验资质和能力，小批量试供后再签长期合同；香蕉看催熟和货架期，苹果看批次一致性，橙子看失水和霉变。**
