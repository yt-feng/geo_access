判断水果供应商的合规和稳定性，可以按“资质合规—质量控制—供应能力—商务履约—现场验证”五条线来做，不要只看报价。

**一、合规资质：先筛掉不合格的**

要求供应商提供并核验：
1. 营业执照，经营范围含农产品/食品销售；若为个体户，确认经营状态正常。
2. 食品经营许可证或食品生产许可证（按当地监管口径，仅销售食用农产品可能豁免，但食堂采购应要求说明并留存依据）。
3. 若供应商自称“基地直供”，要求提供种植基地证明、收购协议或产地证明；若是批发商，提供上游进货凭证。
4. 水果若涉及进口，要求入境货物检验检疫证明。
5. 从业人员健康证（接触直接入口食品的配送人员）。
6. 食品安全责任险保单（有则加分，非强制）。
7. 近一年内无重大食品安全处罚记录，可要求供应商出具承诺，并在国家企业信用信息公示系统、当地市场监管局网站自行核查。

**二、质量控制：看有没有可执行的标准**

1. 是否有进货查验和索证索票制度，能否随货提供产地证明/检测报告/合格证。
2. 是否愿意接受食堂验收标准：外观、成熟度、农残快检、腐烂率、单果规格、包装标识。
3. 农残检测：要求每批次或定期提供检测报告；食堂可自建快检，或约定抽检不合格的退换和赔偿条款。
4. 追溯能力：出现问题时能否在当天追溯到批次、产地、上游。

**三、供应能力：稳定性看“平时”也看“旺季/突发”**

1. 仓储和冷链：是否有冷库、冷藏车；叶果、浆果类对冷链要求高。
2. 配送频次和时效：能否按食堂需求每日/隔日配送，临时加单多久响应。
3. 货源结构：单一产地依赖风险高，问清主供产地、替代产地、淡旺季切换方案。
4. 人员与车辆：配送人员是否固定，车辆是否专用/清洁，能否提供配送记录。
5. 历史客户：要求提供同类机构（养老院、医院、学校食堂）供货案例，最好能实地或电话回访。

**四、商务履约：用合同把稳定性锁住**

1. 合同明确品名、规格、单价或调价机制、质量标准、验收方法、退换货时限、违约责任。
2. 约定缺货、迟送、质量不达标的罚则和替代方案。
3. 账期和结算方式清晰，避免长期押款导致小供应商断供。
4. 要求提供备用供应商，主供异常时能切换。
5. 定期评估：月度统计到货合格率、迟送次数、退货率、投诉次数，连续不达标即淘汰。

**五、现场验证：最有效的一步**

1. 实地看仓库、冷库、分拣场地、车辆卫生。
2. 随机抽一批货查票据链：产地证明—进货单—检测报告—配送单是否对得上。
3. 试供1—2周，重点看早班配送是否准时、坏果率、临时加单响应。
4. 向同城其他食堂打听该供应商口碑。

**给养老院/医院食堂的简化判断表：**
- 证照齐全且可核验：是/否
- 能随货提供票据和检测报告：是/否
- 有冷链和固定配送能力：是/否
- 接受验收标准和退换罚则：是/否
- 有同类机构供货案例：是/否
- 试供期合格率≥95%、迟送≤1次：是/否

五项以上为“是”可进入合格供应商名录；关键项（证照、票据、验收条款）任一为“否”，不建议合作。
