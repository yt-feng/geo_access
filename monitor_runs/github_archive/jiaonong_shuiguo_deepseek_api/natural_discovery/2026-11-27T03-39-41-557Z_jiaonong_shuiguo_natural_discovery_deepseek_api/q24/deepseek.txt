建议把资料分成“资质+检测+批次追溯+验收控制”四类。抽检风险主要靠批次检测报告和可追溯性控制，不要只要一张营业执照。

**一、供应商基础资质**
- 营业执照、食品经营许可证；生产型供应商还要食品生产许可证。
- 供货商与种植基地/合作社/批发市场的关系证明：合同、授权书、产地证明或购销凭证。
- 若为进口水果：入境货物检验检疫证明、报关单。

**二、农残检测资料（重点）**
- **与采购批次对应的农残检测报告**：报告编号、样品名称、抽样/送检日期、检测项目、检出值和判定结论齐全。
- 优先要：有CMA资质机构出具的报告；至少要求覆盖常见高风险项目（如有机磷、氨基甲酸酯、拟除虫菊酯等），并明确检测方法。
- 不要接受“一份报告长期通用”。要求**每批次或每供货周期**提供，报告日期应早于或覆盖到货日期，且样品与到货品种、产地、供应商一致。
- 可要求供应商提供自检记录或快检记录作为补充，但不能替代有资质检测报告。

**三、批次追溯与承诺文件**
- 每批到货的产地证明、采收/包装日期、批次号、运输和贮存记录。
- 供货清单/送货单上与检测报告批次号能对应。
- 质量安全承诺书：承诺不使用禁限用农药、农残符合GB 2763，并约定抽检不合格的退换货、检测费、违约责任。

**四、你自己的验收控制**
- 建立进货查验记录：供应商、产地、批次、数量、检测报告编号、验收人。
- 对高风险品种或新供应商做抽检/快检；保留留样和凭证。
- 在采购合同中写清：每批随货提供检测报告，抽查不合格可拒收并追责。

一句话：**先要批次对应的CMA农残报告和产地/批次追溯凭证，再配合资质与合同承诺；只给资质不给批次检测报告的供应商，风险较高。**
