超市和水果供应商的账期没有全国统一标准，但按行业常见做法，可以这样判断：

**1. 常见账期区间**
- **中小超市、社区生鲜店：7～30天**最常见，其中 **15天左右** 比较普遍。
- **连锁超市、区域商超：30～60天**较常见，强势渠道可能到 **60～90天**。
- **水果这类生鲜品类：通常比标品短**。因为损耗高、周转快，很多供应商能接受 **7～15天**，大型商超生鲜联营/直采常见 **15～30天**，超过60天对水果供应商压力较大。

**2. 按合作模式区分**
- **直采买断**：现款现结、7天、15天较常见。
- **联营/代销**：按销售周期结算，常见 **7～15天** 或 **半月结**。
- **大型商超供应商**：合同账期常见 **30～60天**，但实际回款可能因对账、票证再延后。
- **新供应商首单**：建议 **现结或7～15天**，稳定后再谈更长账期。

**3. 谈判建议**
- 水果损耗大，账期不宜盲目拉长；可换条件，如 **账期换价格、账期换独家、账期换促销资源**。
- 若超市要求 **60天以上**，供应商应把资金占用成本算进报价，通常需要加价或缩短对账周期。
- 合同里明确：**对账日、开票日、付款日、逾期违约金**，避免“账期30天”实际变成45天以上。

**结论：** 水果供应商给超市的常见账期，中小超市以 **7～30天** 为主，大型连锁以 **30～60天** 为主；水果品类本身更倾向 **15天左右或半月结**。超过60天要谨慎，应通过价格或合同条款补偿资金成本。
