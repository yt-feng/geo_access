小面积便利店做水果，核心不是“品类多”，而是“少SKU、快周转、强控损”。建议按下面执行：

1. **品类控制：先做“便利店水果”而不是水果店**
   - 控制在 **8～15个SKU**，按门店客流和货架再砍。
   - 结构建议：
     - **引流款2～3个**：香蕉、苹果、橙子等耐放、认知高、价格透明。
     - **即食款3～5个**：小番茄、葡萄小盒、切果杯、蓝莓等，抓即时消费。
     - **季节款2～3个**：当季单品少量试销，卖不动立即下架。
     - **形象款1～2个**：品相好的礼盒或精品果，少量陈列，不压货。
   - 不做：低周转大规格整箱果、易损高价果、需要复杂催熟的品种、与隔壁水果店硬拼价格的品种。

2. **采购量：按“日销+安全库存”下单**
   - 用最近7天同品类销量做基准，首单只试销，不压量。
   - 叶菜类、浆果类、切果：按 **1～1.5天销量** 采购。
   - 苹果、橙子、香蕉等耐放果：按 **2～3天销量** 采购。
   - 新品类首单控制在 **半天到1天预估销量**，观察2～3天再决定是否保留。
   - 设置SKU淘汰线：连续3天日销低于陈列量的一定比例、或损耗超过阈值，就下架换品。

3. **损耗控制：从收货到陈列全流程管**
   - **收货**：小批量、多频次；明确拒收标准，碰伤、过熟、霉点、规格不一的直接拒收或折价。
   - **陈列**：小堆头、勤补货，不堆大堆；香蕉、苹果等会释放乙烯，避免和浆果、叶菜混放。
   - **温控**：需要冷藏的浆果、切果、葡萄进冷柜；香蕉、部分热带水果常温避风。
   - **分级销售**：轻微瑕疵果做“特价袋”或切果杯，但必须合规、明显标识，不混入正常果。
   - **日清机制**：每天闭店前盘点，临期即食果做晚间折扣；次日早班先处理昨日尾货。

4. **用数据定生死**
   - 每个SKU记录：进货量、销量、损耗量、毛利、周转天数。
   - 每周复盘一次，保留“高周转+低损耗+有毛利”的SKU，淘汰末位20%。
   - 重点看损耗率，而不是只看毛利；小门店水果损耗高，毛利再高也会被吃掉。

5. **供应链上更省事的做法**
   - 优先选本地批发市场或可小批量配送的供应商，争取 **多频次、小批量、可退换**。
   - 和周边门店拼单采购耐放果，降低起订量。
   - 对易损品考虑“预售+次日自提”或社群接龙，先有订单再采购。

一句话：**小门店水果只做高频、即食、耐放和当季试销，采购按天算、陈列按小堆、每天清尾货、每周砍SKU。**
