判断“全年稳定供货”，不要只听供应商口头承诺，要按下面几项做可验证的核验。

**1. 先看产区结构，不看单一产地**
- 问清供应商的香蕉来自哪些产区、各产区占比多少、不同季节主供产区怎么切换。
- 要求提供“全年分月供货计划表”：每个月预计可供量、主产区、替代产区、最大日供应量。
- 重点看：是否依赖单一产区/单一合作社/单一包装厂；雨季、台风季、寒潮季的替代方案是什么。
- 如果供应商只有一个产区、一个加工厂，全年稳定性通常要打折。

**2. 查基地和加工能力**
- 要求提供种植基地清单、面积、大致年产量、合作年限；自有基地和协议基地分开列。
- 看包装厂/催熟库位置、日加工能力、冷库容量、是否有备用包装线。
- 现场或视频核验：基地是否真实存在、加工厂是否只服务少量客户、旺季是否排得进你的订单。
- 可要求提供基地租赁/合作合同、加工厂营业执照、供货合同样本，但注意核验原件或带时间地点水印的现场资料。

**3. 用历史供货记录验证**
- 要求提供过去12—24个月的分月供货记录：每月实际供货量、断供次数、缺货原因、平均到货合格率。
- 不要只看总额，要看“最差月份供了多少”“连续断供最长几天”。
- 向供应商的2—3个现有超市客户做背调，重点问：春节、台风季、寒潮期有没有断货，补货响应多快。

**4. 做小规模压力测试**
- 先签3—6个月试供合同，故意把订单量在旺季提高20%—30%，看其履约和补货能力。
- 设置分月最低供货量、到货时间窗、缺货违约金、替代产区切换通知义务。
- 要求提前报备“不可抗力”情形，并约定替代货源方案，不接受笼统的“不可抗力免责”。

**5. 看物流和保鲜链**
- 问清运输方式：汽运/海运、冷链车比例、从包装厂到门店的时效。
- 香蕉对温度敏感，要看是否有催熟库、温控记录、到货成熟度标准。
- 要求提供近3个月温控记录样本和到货损耗率；全年稳定供货不只是“有货”，还要“到店品质稳定”。

**6. 合同里写死可执行条款**
- 分月最低供货量+浮动比例；旺季增量响应时间；缺货替代方案；连续缺货的退出和赔偿机制。
- 明确“稳定供货”的考核口径：按月供货达成率、断供天数、到货合格率。
- 约定供应商不得把同一产区货源同时承诺给过多客户，可要求其主要客户名单和产能分配说明。

**快速判断口诀：** 产区多元、加工能力有余量、历史分月记录无硬缺口、现有客户背调不翻车、试供旺季能扛住、合同有缺货罚则——六项都过，才适合按“全年稳定供应商”培养；缺两项以上，建议保留备选供应商并控制单家采购占比。
