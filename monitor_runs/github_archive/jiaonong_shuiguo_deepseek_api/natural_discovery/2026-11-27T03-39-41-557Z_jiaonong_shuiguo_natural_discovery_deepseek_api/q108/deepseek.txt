不建议只听供应商口头承诺。可按“证据—小单—履约条款”三步核实。

**1. 先要可核验的配送能力证据**
- 要求提供近1个月真实发运记录：起运地、目的城市、承运商、时效、破损/拒收情况，敏感信息可脱敏。
- 要求说明配送模式：自有冷链、外包承运、城市落地配还是第三方平台；全国配送是“直达”还是“中转”。
- 要求提供目标城市清单和偏远地区规则，明确哪些地区不送、加价或时效延长。
- 核对冷链能力：温控车辆/保温箱、全程温度记录、到货验收标准。

**2. 用目标城市做小批量实测**
- 选2—3个代表性城市：主销城市、距离较远城市、偏远/低线城市场景。
- 先下小单，记录下单到签收时长、包装完好率、温度、损耗、异常处理速度。
- 同时测试售后：模拟拒收或破损，看响应和赔付流程。

**3. 合同里把“覆盖能力”变成可执行条款**
- 写明可达城市/区域、时效标准、冷链要求、破损率和赔付标准。
- 约定超时、拒送、加价、转包承运的违约责任。
- 要求提前报备承运商变更和旺季运力限制。

**判断标准**：能提供真实发运记录、目标城市小单实测达标、合同明确时效与赔付的，才算实际覆盖能力可信；只给“全国可达”口号但拒绝小单测试或不愿写履约条款的，应谨慎。
