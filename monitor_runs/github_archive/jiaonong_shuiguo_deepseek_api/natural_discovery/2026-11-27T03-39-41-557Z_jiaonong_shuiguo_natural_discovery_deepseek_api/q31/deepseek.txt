连锁商超招长期水果供应商，评分标准建议按“商务资质+商品与品控+供应链履约+价格+服务协同”五块设置，总分100分。核心原则：**价格权重不宜过高（建议25-30分），品控和履约能力权重应高于价格**，因为水果损耗大、季节波动强，长期合作最怕断供和品质不稳。

**一、商务资质与规模（10-15分）**
- 营业执照、食品经营许可、种植/加工资质齐全（否决项）
- 注册资本、年营收、同类商超供货案例（每提供1个有效案例得分，设上限）
- 基地直采/自有果园/合作社协议证明（加分项，体现源头可控）
- 食品安全责任险、检测报告体系

**二、商品品质与品控体系（25-30分）**
- 样品盲评：外观、口感、规格一致性、成熟度（建议现场打分，占10-15分）
- 农残检测能力：自有检测室或第三方送检频次、检测项目覆盖（加分）
- 分级标准与包装规范：是否按商超标准分拣、预冷、包装
- 追溯体系：批次可追溯、产地证明、有机/绿色认证（有则加分）
- 损耗控制方案与历史损耗率数据

**三、供应链与履约能力（25-30分）**
- 仓储冷链能力：冷库面积、冷链车辆数量、预冷设施（水果关键项，权重要高）
- 配送时效：到店频次、应急补货响应时间（如24小时内）
- 产能与稳定性：主推单品年供应量、旺季保供承诺、多产地布局（防单一产区风险）
- 过去12个月供货履约记录/违约情况
- 应急预案：极端天气、疫情、价格暴涨时的保供方案

**四、价格与商务条件（25-30分）**
- 报价水平：按品类分别报价，与市场均价对比（建议用“基准价下浮率”而非绝对价，便于比价）
- 价格调整机制：是否接受随行就市、调价周期、涨跌幅约束
- 账期与结算方式：能否接受商超账期（如30-60天）
- 退换货与损耗分担条款的接受度

**五、服务与协同（10-15分）**
- 专职对接团队、驻场或巡店服务
- 促销支持：堆头、试吃、季节主推配合
- 新品开发与定制包装能力
- 信息化对接：订单系统、库存共享
- 培训与售后响应

**操作建议：**
1. **设否决项**：资质不全、检测不合格、有重大食品安全事故记录的直接废标。
2. **样品盲评单独设环节**，避免只看纸面材料。
3. **价格分用公式**：最低有效报价/投标报价×价格权重，防止恶意低价；同时设“低于成本价需说明”。
4. **长期合同加考核条款**：季度评分（品质合格率、到货准时率、损耗率、投诉率），连续不达标可降级或退出，评分标准里可设“接受考核机制”为得分项。
5. **分品类招标**：叶菜、根茎、进口果、时令果的品控和冷链要求差异大，建议按品类分别设权重，不要一套标准通吃。

一句话：**资质设门槛，样品看品质，冷链和保供定生死，价格给合理权重，考核机制锁长期。**
