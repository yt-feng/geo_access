水果采购合同里并没有统一法定比例，坏果率超过多少赔付要靠合同约定。实操上建议这样定：

1. **先分“到货验收”和“储存后”两个阶段**
   - 到货现场抽检发现的坏果：一般超过 **3%～5%** 就应启动扣款/换货/赔付；叶菜、浆果、桃等易腐品可放宽到 **5%～8%**，但要在合同里写明。
   - 入库后短期内因原果质量问题出现的坏果：可约定 **到货后24～48小时内** 复检，超过 **5%～10%** 由供方承担。

2. **不要只写一个比例，要写清计价方式**
   建议约定：
   - 坏果率 ≤3%：正常收货；
   - 3%＜坏果率≤8%：按坏果重量扣款，或按“坏果率－3%”×批次货款扣减；
   - 坏果率＞8%：买方有权拒收、要求换货或整批退货；
   - 因坏果导致整车/整批无法销售：供方承担退货、运费及合理损失。

3. **必须约定抽检规则**
   合同里写明抽样比例、抽样方法、验收时限、双方到场复检、拍照留证、第三方检测机构。否则比例写了也难执行。

4. **按品类设不同阈值**
   例如：苹果/梨等耐储水果可严一些（3%～5%）；草莓、葡萄、荔枝等易损水果可设5%～8%；叶菜可设5%～10%。具体以双方议价和行业惯例为准。

5. **赔付条款建议写成可执行公式**
   例如：“坏果率超过5%的，超出部分按该批次合同单价的1.5倍从货款中扣除；超过10%的，买方有权拒收，供方承担往返运费。”

**结论：** 合同里建议把赔付触发点设在 **3%～5%** 作为常规线，易腐品类放宽到 **5%～8%**，并同时约定抽检方法、验收时限和扣款公式。不要只依赖一个“坏果率多少”的数字。
