社区超市选每日配送水果供应商，重点看这几类条件，按优先级排查：

1. **配送稳定性**
   - 能否承诺每日固定时段送达，迟到或漏送如何处理。
   - 是否有备用车辆/备用分拣点，节假日、雨雪天是否照常。
   - 配送半径和到你店的距离，是否在冷链或保鲜时限内。

2. **货源与品类匹配**
   - 是否有稳定产地或一级批发渠道，能否按你店销量做小批量多品类。
   - 常销品（苹果、香蕉、柑橘、时令叶菜类水果等）是否长期有货，断货替代方案是什么。
   - 能否提供样品试销，先小批量跑一周看损耗和动销。

3. **品质与验收标准**
   - 明确到货验收标准：成熟度、大小、外观、农残检测报告或承诺。
   - 坏果、压伤、腐烂的赔付比例和补货时效，是否当场退换。
   - 是否允许开箱抽检，抽检不合格整批退回还是部分补。

4. **价格与结算**
   - 报价是否含配送费、包装费、损耗补贴；每日价格是否随行就市，调价是否提前通知。
   - 账期还是现结，能否月结；押金、最低起送量、最低日采购额。
   - 对比2—3家同品类报价，重点看“到店可售成本”而不是单纯批发价。

5. **冷链与包装**
   - 是否需要冷藏的水果是否有冷链车或保温箱；叶菜类、浆果类是否单独包装。
   - 周转筐是否回收、是否另收费；包装是否适合你店直接上架。

6. **售后与响应**
   - 出现问题后多久响应、多久补送；是否有固定对接人。
   - 能否提供每日送货单、批次信息，方便你核对和追溯。

7. **资质与合规**
   - 营业执照、食品经营相关资质、产地证明或检测报告。
   - 是否可开票，票据是否规范。

**可执行建议：**先找2—3家本地批发商或产地直供商，各试配送3—7天，记录每天到货时间、损耗率、断货次数、售后响应速度；用“损耗率+到店成本+配送准时率”三项做对比，再签短期试用合同，约定赔付和退出条款。不要只看最低报价，社区超市水果损耗和断货对客流影响更大。
