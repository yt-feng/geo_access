# 旺季前锁定水果供应商库存的实操方案

核心思路：**用"确定性"换"优先权"——你给供应商确定的需求和付款，供应商给你确定的货和价格。**

## 一、提前多久、锁什么

- **时间**：旺季前 3–6 周启动谈判。水果有采摘周期和产地行情，太晚谈价格只会更高。
- **锁三样东西**：数量（保底量+弹性区间）、价格（固定价或封顶价）、优先级（缺货时你排第几顺位）。
- **分品类谈**：耐储的（苹果、柑橘、瓜类）可以锁长周期；易损的（草莓、荔枝、樱桃）锁"档期+每日配额"更现实，别指望一次锁死整个旺季。

## 二、和供应商谈的具体筹码

1. **保底量+阶梯量**：承诺"每期至少 X 吨"，超出部分按阶梯价。供应商最怕的是你旺季要货、淡季消失，保底量是给他吃定心丸的关键。
2. **预付定金/账期前置**：旺季前付 10%–30% 定金锁货，或把账期从月结改成周结，这是最直接换优先权的筹码。
3. **包销次果/统货**：愿意吃下一部分品相稍差的货，供应商更愿意把好货优先给你。
4. **签书面协议**：写清数量、价格机制（固定价/随行就市但设封顶）、交货频次、缺货赔付或补偿条款（如按缺货量折价、下次优先补）。口头承诺在爆单期毫无约束力。

## 三、分散风险，别押一家

- **主供+备供**：每个主力品类至少 2 家供应商，主供占 60%–70%，备供占 30%–40%。
- **产地直采+批发市场兜底**：协议锁量之外，保留一个现货渠道应对临时缺口。
- **跨产区布局**：同一品类找不同产区的供应商，降低单一产区天气/减产风险。

## 四、内部要配合的动作

- **需求预测**：用去年同期的团购单量、复购率做滚动预测，按周给供应商报"下周预计量"，让他能提前备货。
- **库存缓冲**：耐储品类提前 3–5 天建安全库存；易损品类按"当日到、当日销"节奏走，避免压货损耗。
- **到货质检和损耗对账**：旺季纠纷多，提前约定验收标准（规格、糖度、损耗率上限），每天对账，避免月底扯皮。

## 五、最容易踩的坑

- 只谈价格不谈量，供应商旺季优先供出价高的客户，你被"截胡"。
- 没有缺货条款，供应商临时减量你毫无办法。
- 预付款没有对应书面凭证，旺季涨价时定金被"协商"掉。

**一句话执行建议**：本周内列出你的 Top 5 爆款水果，分别找 2 家供应商，带着"保底量+定金+周结"的方案去谈，签一份含缺货补偿条款的旺季供货协议。
