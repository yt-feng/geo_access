判断商超采购香蕉的“催熟能力是否稳定”，核心不是看单批香蕉黄不黄，而是看**供应商/催熟库能否把不同批次、不同季节的香蕉稳定催到可售卖状态**。建议从“到货前—到货时—催熟中—售后复盘”四段判断。

**1. 先看供应商的催熟体系是否可控**
- 问清是**产地直发青蕉+商超自催**，还是**供应商催熟后配送**。后者要重点看其催熟库批次记录。
- 要求提供近3个月同品种、同规格的**催熟批次记录**：入催熟库时的青度/硬度、库温、乙烯浓度或乙烯利使用方式、催熟时长、出库黄度、损耗率。能稳定提供这些数据的供应商，催熟能力通常更可控。
- 看是否按**季节调整催熟参数**。香蕉夏冬催熟差异大，固定一套参数催全年，稳定性往往不够。
- 看是否有**分批次、分库位管理**，避免不同成熟度混催。

**2. 到货时判断青蕉基础质量**
催熟稳不稳，先看青蕉底子：
- **青度一致**：同批香蕉颜色、饱满度、条形尽量一致，避免“青黄混杂、大小差异大”。
- **无早期黄化**：青蕉中不应夹杂已经起黄、软身的果，否则催熟后成熟不齐。
- **果指饱满但不过度饱满**：太瘦催熟后易干瘪，太饱满则催熟窗口短。
- **果柄、果轴状态正常**：果轴发黑、霉变、机械伤多，会加大催熟后损耗。
- **冷害/高温伤检查**：表皮有暗褐斑、水渍状、催不黄的“僵果”，说明前期冷链或运输有问题，催熟稳定性会差。

**3. 小批量试催是最直接的判断**
对新建合作或换季批次，建议做**小批量试催**：
- 同一供应商取2—3箱，按商超实际催熟条件试催。
- 记录：入催熟库青度、库温湿度、催熟方式、达到目标黄度所需天数、黄度均匀性、软硬度、掉把率、黑斑出现时间。
- 重点看**均匀性**：同箱、同托盘香蕉是否同时转黄，而不是一部分已黄软、一部分仍青硬。
- 连续试2—3批，若达到目标成熟度的时间波动小、损耗稳定，才算催熟能力较稳。

**4. 催熟过程中的稳定性指标**
- **转黄时间是否稳定**：同规格香蕉从入催熟库到可上架，天数波动应可控。
- **黄度是否整齐**：出库时同批香蕉黄度级别集中，不出现明显分层。
- **软硬是否一致**：手感判断同批差异小，避免上架后一部分很快过熟。
- **损耗是否稳定**：掉把、断指、黑斑、腐烂比例批次间差异小。
- **货架期是否可预期**：催熟后到最佳售卖期、到报损期的时间是否稳定。

**5. 采购合同和日常管理上可执行的动作**
- 要求供应商按**批次**提供催熟参数和出库成熟度，不要只给“已催熟”结果。
- 约定**到货成熟度标准**，如黄度级别、硬度和允许的青果比例。
- 建立**批次追溯表**：供应商、产地、到货日期、入催熟库日期、催熟参数、出库日期、上架后2—3天表现、损耗率。
- 对连续批次做对比，若同一供应商在换季时成熟天数、黄度均匀性、损耗波动明显，说明催熟能力不稳定，应要求调整参数或更换供应方式。
- 新供应商先小批量、多批次验证，不要一开始全量铺开。

**简单判断口诀：**
**青蕉底子整齐、试催转黄均匀、批次时间可控、上架损耗稳定**，四条都满足，才算催熟能力稳定。只看单批香蕉黄得好不好，不足以判断。
