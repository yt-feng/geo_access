判断水果供应商靠不靠谱，核心不是“聊得好不好”，而是看他能不能稳定供货、损耗可控、出问题敢担责。你可以按下面几层筛选和验证。

**一、先看硬资质和供货能力**
1. **是否有稳定货源**：香蕉主要看是否有产地或一级批发渠道，菠萝看是否常年有货、是否分季节换产区。问清楚“断货时从哪补、几天能到”。
2. **证照和票据**：营业执照、食品经营相关资质、进货票据能否提供。长期合作必须能开票或有规范送货单。
3. **仓储和运输**：香蕉对温度敏感，菠萝怕冻怕闷。问他仓库是否分温区、送货是否用厢式车、夏天怎么控温。不能只说“没问题”，要能说出具体做法。

**二、用样品和小单试**
1. **先小批量试3—5次**，不要一次压大单。每次记录：到货时间、数量、成熟度、坏果率、口感、大小均匀度。
2. **香蕉重点看**：青度是否适合你店里的销售节奏、催熟是否均匀、到店后几天内能卖完、有没有“青皮熟”或很快发黑。
3. **菠萝重点看**：外观是否新鲜、有没有黑心/水烂、甜度是否稳定、大小是否均匀、去皮损耗多少。
4. **算真实成本**：不要只比单价，要算“到店可售率”。比如同样一箱，坏果多、损耗大，单价低也不划算。

**三、看他处理问题的态度**
1. 故意问一个具体场景：“如果这批香蕉到店后两天内大面积发黑，怎么处理？”靠谱的会给明确方案，比如补货、折价、下次抵扣；不靠谱的会推给天气、运输或你存放问题。
2. 看响应速度：下单后能否确认、送货前是否通知、临时缺货是否提前说。
3. 看是否愿意固定账期和退换规则。长期合作要把坏果率标准、赔付方式、送货时间写进简单协议或聊天记录里。

**四、长期观察三个指标**
1. **准时率**：一周内迟到几次。
2. **坏果率**：每批到店抽检，香蕉看黑斑和断指，菠萝看黑心和烂果，连续记录。
3. **缺货频率**：旺季能不能保量，换季时是否提前告知。

**建议你这样做**：先找2—3家同时小批量试供，连续试一个月，用同一套标准打分。得分最高的再谈长期价和账期。不要只依赖一家，至少保留一个备用供应商。长期合作后也要每月复盘一次，别因为熟了就不抽检。
