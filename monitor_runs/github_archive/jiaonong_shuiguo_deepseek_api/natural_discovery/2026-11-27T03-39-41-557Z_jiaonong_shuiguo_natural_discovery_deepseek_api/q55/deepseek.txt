选规格的核心不是“越大越划算”，而是**按出成率、切配损耗和上桌形态**算。水果拼盘里三种水果的可执行建议：

**苹果**
- 选**中等偏大、大小均匀**的，单果约200–250克更稳。拼盘切瓣/切块，太大反而单块厚、边角料多。
- 优先看**硬度高、无磕碰**的，粉面苹果切后易发绵、出水。
- 划算判断：同样斤价下，选**果径均匀**的，切出来块数稳定、损耗低；不要为“特大果”多付溢价。

**橙子**
- 选**中果、皮薄、手感沉**的，单果约180–220克。拼盘主要用瓣，皮厚的大果出肉率低。
- 别盲目选特大果：皮厚、白瓤多，切瓣后修边损耗大。
- 划算判断：按**出肉率**比价，不按单果大小比价；同价选皮薄、果形端正的。

**菠萝**
- 选**中等果、成熟度7–8成**，单果约1–1.5公斤更适合餐厅稳定切配。太大果芯粗、边角多；太小出成率低、切块少。
- 拼盘用块/片，优先选**果眼浅、果芯细**的品种；成熟度过高切后易出水塌软。
- 划算判断：按**去皮去芯后的净肉重量**算，不按整果斤价算。

**采购组合建议**
- 拼盘走量：苹果、橙子选**中果统一规格**，菠萝选**中等果**，切配标准化最好。
- 高端拼盘：苹果选脆甜中大果，橙子选皮薄中果，菠萝选果眼浅的中果，别为超大果加价。
- 比价时统一问供应商：**净出成率、单果克重区间、成熟度**，用“净肉成本”而不是“整果斤价”判断划算。

一句话：**苹果橙子选均匀中果，菠萝选中等成熟果；按净出成率比价，不为特大果付溢价。**
