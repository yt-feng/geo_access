采购香蕉时，不要只提“要熟一点的”，而要直接规定**到货时的成熟度、颜色比例、运输方式和验收标准**。具体可以这样要求：

1. **到货熟度以“青为主、微黄为辅”**
   - 到货时允许：**70%–80%果指整体青绿或仅转黄，20%–30%开始转黄**。
   - 不要整批“全黄”“黄中带黑斑”，也不要过硬全青到短期难卖。
   - 如果货架周转快，可接受“青中带黄”；周转慢则更偏青。

2. **按销售周期定批次熟度**
   - 目标2–3天卖完：可要到货约**3–4成熟转黄**，即少量转黄、多数青。
   - 目标4–5天卖完：要求**更青、更硬，转黄比例更低**。
   - 高温季节或周末前，宁可分批到青货，不要一次到高熟度货。

3. **明确到货时间与到店验收节点**
   - 要求**清晨到货、上午完成验收**，避免午后高温卸货。
   - 订货时说清楚：“到店时按约定成熟度验收，过熟拒收或折价。”
   - 不要让供应商提前一天晚上送到闷放，香蕉在密闭车厢和店内高温处会加速转黄。

4. **要求冷链或通风运输，不能闷箱**
   - 夏季要求**通风运输或适当低温运输，避免暴晒和密闭车厢**。
   - 到货纸箱要通风，不能整箱密封堆在热处。
   - 到店后**先开箱散热、分级**，青黄分开陈列，不要整箱闷着。

5. **写进采购单的验收标准**
   - 颜色：青绿至微黄为主，黄熟果不超过约定比例。
   - 硬度：果身硬实，无明显软塌。
   - 外观：无大面积黑斑、无裂果、无机械伤、无霉变。
   - 温度：手感不发热，箱内不闷湿。
   - 不合格处理：过熟、软烂、黑斑多的部分**拒收或按比例扣款**。

6. **少量多次、分批到货**
   - 把一次大单拆成**2–3次小批量到货**，每次间隔1–2天。
   - 先卖转黄的，青的留在通风阴凉处后熟。
   - 这样比一次性要求“耐放”更有效。

一句话采购要求可以写成：**“香蕉到货以青绿微黄为主，黄熟比例不超过三成，清晨到货、通风运输，到店验收硬实无黑斑；过熟软烂拒收，按2–3天销售周期分批到货。”**
