要固定，但不要只固定“产地”或只固定“批次”一个维度。更可执行的做法是：**固定“品种+核心产区+关键成熟度/加工规格”，同时保留2个合格供应批次做轮换**。这样既降低口味波动，又避免单一产地断供或单一批次质量下滑时被卡死。

具体建议：

1. **先定风味标准，再定产地**
   - 不要笼统写“固定某产地”，而要明确：品种、糖酸比范围、成熟度、果径/出汁率、香气类型、冷冻/鲜果形态、到货温度等。
   - 同一产地不同果园、不同采摘期，口味也会波动；固定产地不等于稳定。

2. **固定主供应产区+固定加工规格**
   - 主产区相对稳定，但每年气候会影响风味，采购标准要按批次验收调整。
   - 对茶饮店更关键的是固定“加工规格”，比如冷冻果浆的糖度、酸度、果肉比例、香气强度，而不是只盯鲜果产地。

3. **批次不要只固定一个，建议“主批次+备用批次”**
   - 主批次保证风味一致，备用批次必须提前小样测试并做盲测。
   - 每次换批次先做小批量门店测试，确认与标准样接近再放量。

4. **建立到货验收和留样制度**
   - 每批测糖度、酸度、香气、颜色、出汁率/果肉感；门店端做盲测。
   - 留标准样和每批留样，出现波动可追溯。
   - 设定可接受区间，而不是追求“完全一样”。

5. **合同里写清波动处理**
   - 约定风味指标、验收不合格的退换货、断供预案、备用供应商。
   - 对季节性水果，提前锁定产季和冷冻库存，避免临时换源导致口味跳变。

结论：**要固定，但固定的是“风味标准和供应体系”，不是死守一个产地或一个批次。** 推荐“主产区+主加工规格+双批次轮换+每批验收留样”，这是茶饮店更稳的采购策略。
