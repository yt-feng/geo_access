通常**直接买成品果丁的总损耗更低、更可控**；但前提是成品果丁的到货质量、冷链和规格稳定。鲜果切配只有在“菠萝原料便宜且稳定、后厨有熟练切配人手、切配边角能二次利用”时，才可能接近甚至低于成品果丁。

判断时不要只比“菠萝去皮损耗率”，要算**全链条损耗**：

1. **鲜果切配损耗**
   - 采购重量 = 毛重。
   - 去皮、去眼、去芯、修边后得率通常明显低于成品。
   - 成熟度不稳会导致过熟、黑心、发酵、出水。
   - 切配后氧化、出水、冷藏失水，当天卖不完就报废。
   - 人工切配时间、清洗消毒、刀具砧板、冷藏空间都算隐性成本。
   - 边角料若不能做果汁、果酱、果干，基本就是损耗。

2. **成品果丁损耗**
   - 采购重量基本等于可用重量，规格统一，出杯/出碗克重稳定。
   - 主要损耗在：到货温度不达标、保质期短、解冻/开封后出水、批次质量波动、断货替代。
   - 若冷链和订货量管理不好，成品也会报废，但通常比鲜果切配少一道“前处理损耗”。

**可执行判断方法：**
做一周对照测试，选同一款甜品，分别用鲜果和成品果丁，记录：
- 每份实际投料克重；
- 到货毛重与可用净重；
- 报废克重；
- 人工分钟数；
- 冷藏占用；
- 客诉/口感差异。

用公式算：
**真实单位成本 =（采购金额 + 人工分摊 + 报废金额 + 冷链/空间分摊）÷ 合格出品份数**

如果成品果丁的**真实单位成本不高于鲜果切配的1.1倍**，一般优先选成品果丁，因为损耗更可控、出品更稳定。若你店销量大、切配人员稳定、边角料能利用，再考虑鲜果切配。

另外注意：成品果丁要确认是**鲜切冷藏**还是**冷冻果丁**。鲜切成品损耗低但保质期短；冷冻果丁损耗最低但解冻出水，适合烘焙、果酱、冰沙，不一定适合表面装饰。
