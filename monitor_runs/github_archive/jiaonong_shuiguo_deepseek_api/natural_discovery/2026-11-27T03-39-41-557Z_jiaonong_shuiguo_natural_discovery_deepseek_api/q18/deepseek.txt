买香蕉前先按“打算几天吃完”定熟度，到店用“看色+摸硬度+看果柄/棱角”判断，不要只按整串颜色选。

**1. 先定用途**
- 当天或1–2天吃：选**黄皮带少量褐斑、手感略软**的，甜度最好。
- 3–5天吃完：选**整体黄色、两端仍带一点绿、捏着微软不塌**的。
- 一周左右吃完：选**黄绿相间、果身硬挺**的，回家常温放熟；别放冰箱冷藏，表皮会变黑、成熟会乱。
- 想做奶昔/香蕉面包：可买**熟斑较多但不流水、不烂**的。

**2. 到店快速判断**
- **看颜色**：全绿太生；全黄但无斑点适合放2–3天；黄带少量芝麻斑接近最佳食用期；大面积黑斑且果柄发黑、果身软塌则过熟。
- **摸硬度**：轻捏果身中部，像鼻尖/耳垂那种“微软有弹性”最好；硬如石头偏生；一捏就陷、表皮起皱偏熟。
- **看果柄和棱角**：果柄青绿、切口新鲜更好；果身棱角分明通常偏生，圆润饱满偏熟。
- **看整串一致性**：整串同色便于统一存放；如果一串有青有黄有黑斑，回家成熟节奏不一致。想分次吃可故意选“渐熟串”，但要知道先吃黄的。
- **避开损伤**：有裂口、流水、明显压伤、霉点、果柄发黑的不要。

**3. 采购顺序和存放**
- 香蕉最后买，减少挤压和闷热；装袋别扎太紧，避免压伤。
- 回家后**常温阴凉处悬挂或平放**，不要冷藏未熟香蕉；已很熟又吃不完，可剥皮冷冻做奶昔。
- 想催熟：和苹果/梨放同一个纸袋，别密封太久。想延缓：分开单根、减少挤压，放阴凉处。

最简单执行：**当天吃选黄带斑、微弹；3天吃选全黄微硬；一周吃选黄绿硬挺。**
