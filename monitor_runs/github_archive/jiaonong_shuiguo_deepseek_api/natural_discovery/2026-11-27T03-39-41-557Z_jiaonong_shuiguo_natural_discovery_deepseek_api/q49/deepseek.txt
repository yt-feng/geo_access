# 旺季菠萝临时补货的供应商约定要点

核心思路：**提前把“临时补货”的规则写进框架协议或补充协议，而不是临时打电话求人。** 旺季用量突增时，你手里有没有“约定”直接决定拿货价和供应优先级。

## 一、先定清楚几个可量化条款

1. **临时补货触发机制**
   - 约定：正常订单量基础上，单次追加不超过日常订单的 X%（如50%~100%），提前 N 小时（建议24~48小时）通知即视为临时补货。
   - 明确“旺季”时间段（如4—9月），期间适用补货条款。

2. **补货价格**
   - 两种可选：① 按当日市场价/产地收购价+固定加价（如0.3~0.5元/斤）；② 按原合同价上浮不超过X%。
   - 关键：写死“上浮上限”，避免旺季被坐地起价。同时约定若市场价下跌，补货价随之下调。

3. **供应保障与优先级**
   - 要求供应商承诺：收到临时补货通知后 N 小时内确认、M 小时内到货（如24小时内）。
   - 约定旺季期间供应商给你的供货优先级（如“不得低于其总供货量的X%”或“优先于新客户”）。

4. **品质与规格不变**
   - 临时补货的菠萝规格（单果重量、成熟度、去皮/带皮）与常规一致，验收标准不放松。
   - 约定不合格品的退换时限（如到货2小时内提出，24小时内补足）。

5. **违约与备选**
   - 供应商未按约定补货：按缺货金额的X%赔付，或承担你临时高价采购的差价。
   - **你自己必须留后手**：同时储备1~2家备选供应商，协议里写明“临时补货不构成独家采购义务”，避免被单一供应商卡脖子。

## 二、谈判时的实操建议

- **用“量”换“稳”**：告诉供应商旺季总采购量预期，承诺全年/旺季最低采购量，换取补货优先权和价格上限。
- **预付/账期做交换**：临时补货可约定现结或缩短账期，换取供应商优先排货。
- **书面化**：所有口头承诺落到补充协议或微信书面确认，写明“本条款与原合同同等效力”。
- **留痕**：每次临时补货用固定格式下单（数量、到货时间、价格），双方确认，避免月底对账扯皮。

## 三、一句话结论

**把“提前多久通知、最多加多少量、价格上浮上限、多久到货、违约怎么赔”这五件事写进协议，再自备一家备选供应商**，旺季补货就不会被动。
