建议先做“小批量、多批次”的试卖，不要一次压货。具体量可以按下面方法定：

1. **先定试卖目标**：只验证三件事——顾客买不买、复购高不高、损耗大不大。不是先追求销量。

2. **初始试卖量建议**
   - **单店/单档口**：新品首轮建议 **1～3天销量**，或 **20～50公斤/件（按品类）** 起步。
   - **叶菜、浆果、熟透易损水果**：更保守，先 **10～30公斤** 或 **半天到1天量**。
   - **苹果、柑橘、梨等耐储水果**：可到 **50～100公斤** 或 **2～3天量**。
   - **多门店**：先选 **2～3家代表性门店** 试卖，单店量同上，不要全部门店同步铺货。

3. **判断公式**
   - 试卖量 ≤ **日均预计销量 × 试卖天数 × 0.5～0.7**
   - 例如预计一天卖30公斤，试卖3天，首单约 **45～63公斤**，取偏保守值。
   - 如果供应商有起订量，超过这个数就要求 **拆分批次、混装或先代销/寄售**。

4. **看数据再加单**
   - 售罄率 **80%以上**、损耗 **低于5%～8%**、有顾客问复购：可以加单到 **3～5天量**。
   - 售罄率 **50%以下** 或损耗 **超过10%**：暂停加单，换陈列、试吃或调价后再试。
   - 连续 **2～3个补货周期** 稳定动销，再考虑正常铺货。

5. **合同上要稳**
   - 先谈 **小批量起订、可退换/损耗分担、账期或寄售**。
   - 明确到货成熟度、规格、破损率标准。
   - 首批不要做独家包销或大额预付。

一句话：**首单按1～3天量、单店20～50公斤起，易损品类再减半；用售罄率和损耗率决定是否加单。**
