社区超市做水果，核心就一句话：**用“高频少量+快进快出+早发现早处理”把损耗压下去，而不是靠大库存撑陈列。** 下面给一套能直接执行的办法。

**1. 订货：按销量定，不按感觉定**
- 每个单品记 7 天销量，取日均销量做基础订货量。
- 首次试新品只进 2–3 天量，卖得动再加。
- 订货公式：**订货量 = 日均销量 × 补货周期 × 安全系数（1.1–1.3）－现有库存**。天气热、节假日适当上调，雨天、节后下调。
- 叶菜、草莓、葡萄、香蕉这类高损耗品，宁可一天补两次，也不要一次压三天。

**2. 陈列：少量多次，勤翻勤挑**
- 陈列量控制在当天能卖完的 1/2–2/3，卖空了再补，保持“满而不堆”。
- 每 2–3 小时翻检一次，把碰伤、软果、熟透的挑出来，别让它传染好果。
- 易压伤的果（桃、葡萄、草莓）用小盒、浅筐，别堆高。
- 香蕉、芒果等后熟果，没熟透的放后仓，熟一批上一批。

**3. 库存：分区+先进先出**
- 后仓只放 1–2 天周转量，按“今天必卖、明天可卖、后熟待用”三区放。
- 所有货贴到货日期，**先进先出**，新货放里面，旧货摆前面。
- 每天闭店前盘一次高损耗品，每周盘一次全品，账实对不上马上查原因。

**4. 鲜度分级处理，别等坏了才动**
- **A 级**正常陈列原价卖。
- **B 级**（轻微碰伤、略软）当天下午做“特价筐”或切果盒，价格降 20%–40%。
- **C 级**（明显熟透）做果切、果汁、员工餐或联系周边餐饮/果汁店折价出，别过夜。
- 设定死线：叶菜不过夜，草莓葡萄 1–2 天，苹果梨可放但也要翻。

**5. 用数据卡住压货**
- 每个单品算**周转天数 = 当前库存 ÷ 日均销量**，超过 2–3 天的高损耗品就停订或促销。
- 每天看三个数：**损耗率、售罄时间、滞销单品**。损耗率连续高，就砍订货量或换品。
- 设滞销红线：上架 3 天动销低于 30% 的，立即特价或换位置，别硬摆。

**6. 简单可落地的日常节奏**
- 早市：补陈列、挑次果、上后熟果。
- 午市后：翻检一次，B 级转特价。
- 闭店前：清 C 级、盘高损耗品、定次日订货。
- 每周：复盘销量和损耗，淘汰 2–3 个卖不动的品，腾给周转快的。

**一句话判断标准：** 后仓水果周转超过 2 天、陈列台出现连续 3 小时卖不动的单品、当天损耗率明显高于平时——这三条出现任意一条，就立刻减订、促销、转处理，不要等。
