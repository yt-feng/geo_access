建议优先做“小把（3–5根）”为主，再搭配“单根”做补充；整袋不建议作为主包装。判断依据和落地方式如下：

1. **主推小把（3–5根）**
   - 便利店消费多为1–2人即时消费，小把兼顾“看起来新鲜、买得完、单价可接受”。
   - 比单根更有毛利空间，也减少顾客挑拣造成的损耗。
   - 建议固定根数、统一标价，比如“3根装/5根装”，避免称重带来的排队和人工成本。

2. **保留单根作为补充**
   - 适合只想买1根搭配早餐、酸奶或临时需求的顾客。
   - 单根容易因反复触摸、掰扯造成损耗，建议放在收银台附近或独立小篮，减少翻拣。
   - 单根定价可以略高一点，但要明码标价，避免顾客觉得不划算。

3. **整袋不建议主推**
   - 整袋更适合家庭计划性购买，便利店客流以即时性为主，整袋动销慢、占陈列位、熟度不均时损耗大。
   - 如果附近有家庭客群或社区店，可少量试销“整袋”，但要做小规格，并放在靠里位置，不作为主陈列。

4. **陈列和损耗控制**
   - 香蕉按成熟度分两批：青黄相间的小把放主陈列，熟度高的单根或小把放收银台做即时促销。
   - 每天检查，出现黑斑的及时降级为单根或做搭配促销，避免整把报废。
   - 先小批量试销1–2周，看单根、小把、整袋各自销量和损耗，再调整比例。通常便利店可按“小把70%、单根20%、整袋10%”起步测试。

结论：**以3–5根小把为主，单根为辅，整袋少量试销或不作为主包装。**
