门店多、单店量小，核心矛盾是：**总需求不小但极度分散，单店配送成本高、损耗风险大**。适合的供货模式要围绕“集中采购、集中分拣、多频次小批量配送”来设计，而不是让每个店各自找供应商。

### 推荐优先考虑的几种模式

**1. 区域配送中心 + 本地批发市场组合（最现实）**
- 在门店密集区域设一个小型中转仓/分拣点，由总部或区域统一向一级批发商、产地代采集中进货。
- 单店不直接对接供应商，而是按“次日订单”从区域仓补货。
- 本地批发市场作为补充，用于临时缺货、应急调货，但控制比例（建议不超过20%），否则品控和成本难稳定。

**2. “统采统配”的第三方生鲜配送商**
- 找服务社区超市、便利店连锁的B2B生鲜配送平台（如区域性的美菜类、地方生鲜供应链公司），要求其按门店小批量、多频次配送。
- 适合门店数在几十家以内、自建仓不划算的阶段。
- 关键谈三点：起送量、配送频次（最好日配或隔日配）、损耗赔付规则。

**3. 产地/基地直采 + 区域集散仓（规模上去后）**
- 只对销量稳定、耐储的少数单品（如苹果、土豆、洋葱、柑橘）做产地直采，拉到区域仓再分拨。
- 叶菜、鲜果等易损耗品类仍走本地批发或配送商。
- 避免“全品类直采”，小批量门店撑不起产地直发的物流成本。

**4. 供应商“拼车共配”模式**
- 联合几家同类超市或不同品类供应商，共用一条配送线路，分摊运费。
- 适合门店分散、单店日均水果需求低的区域。
- 需要有人牵头做订单汇总和线路排程，否则协调成本高。

### 不建议的模式
- **每店各自找供应商**：价格不统一、品控不稳、配送成本高。
- **完全依赖产地直发到店**：单店量小，物流成本会吃掉毛利。
- **纯批发市场现采**：价格波动大、品质不稳定，多店难以统一标准。

### 判断标准
选模式时看三个数：
1. **单店日均水果销售额**：低于3000元，优先第三方配送或区域仓补货；高于5000元且门店集中，可考虑自建小型分拣点。
2. **门店到区域仓/配送商的距离**：配送半径建议控制在1小时车程内，否则小批量配送不经济。
3. **损耗率承受线**：水果行业损耗通常5%–15%，小批量多频次配送能把门店库存压到1–2天，是控损关键。

**落地建议**：先选一个门店密集的城市做试点，用“区域仓统采 + 第三方配送日配”跑1–2个月，算出单店配送成本和损耗率，再决定是否扩大自采比例或自建分拣点。
