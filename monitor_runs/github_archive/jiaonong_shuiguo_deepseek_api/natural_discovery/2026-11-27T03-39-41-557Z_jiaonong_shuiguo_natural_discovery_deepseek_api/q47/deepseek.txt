采购香蕉做茶饮/甜品，核心是**按用途分熟度、少量高频、分级验收**。建议这样做：

1. 先按用途定熟度
- **做饮品/奶昔/冰沙/果泥**：买**7成熟左右**，表皮黄但两端略绿，捏起来偏硬，适合打泥，甜度靠糖浆/其他水果补。
- **做果肉顶料/切片装饰**：买**8成熟**，通体黄、少量芝麻点，果肉成形不烂。
- **做香蕉泥甜品、布丁、蛋糕夹层**：用**8.5—9成熟**，表皮有少量黑点，香气足、易压泥。
- **做香蕉面包/磅蛋糕/高甜甜品**：可用**9—全熟**，表皮黑点多，甜度和香气最好，但必须当天处理。
- 茶饮店不建议一次采太多全熟蕉，损耗和氧化很快。

2. 采购订单控制
- **少量高频**：按2—3天用量下单，夏季缩短到1—2天。
- **分批到货**：同一批不要全是同一熟度，按“今天用+明天用+后天催熟”搭配。
- **明确规格**：向供应商写清“表皮颜色、黑点比例、单根重量、允许机械伤比例”，不要只说“要熟香蕉”。

3. 验收标准
- **看**：颜色均匀，无大面积青绿、无超过1/3面积黑斑、无霉点。
- **捏**：硬度和用途匹配，饮品用偏硬，甜品泥用微软。
- **查**：果柄不霉、无裂口流汁、无严重压伤；压伤蕉易发酸、出黑水。
- **抽检**：每箱抽3—5根切开看内部，拒绝“外黄内硬”的催熟不均货。

4. 仓储与催熟
- **未熟蕉**：18—20℃阴凉通风，不要冷藏，避免乙烯积聚过熟。
- **将熟蕉**：单独存放，减少堆叠，可用纸箱+少量苹果/乙烯催熟，每天翻检。
- **已熟蕉**：当天优先用；需暂存可去皮分装冷冻做果泥，不建议整根冷藏太久，表皮会黑、果肉易软烂。
- **先进先出**：按熟度贴标，先熟先用，每天挑出过熟蕉转做甜品泥或报废。

5. 损耗控制
- 设定**香蕉损耗率目标**，例如饮品店控制在3%—5%以内。
- 过熟但未变质的蕉，及时转做香蕉泥、香蕉蛋糕、冷冻果泥，减少直接报废。
- 连续到货熟度不稳，换供应商或要求分批配送。

一句话：**饮品用偏硬黄蕉，装饰用黄带点，甜品泥用软黄带黑点；采购少量分批，验收看色、捏硬、查伤，先进先出。**
