年度水果采购合同里，最容易踩坑的通常是**把“不确定的品质和价格”写成看似确定的条款**。按风险从高到低，重点盯这几类：

1. **品质标准写得模糊**
   - “新鲜”“无腐烂”“符合国家标准”都不够可执行。
   - 要写清品种、规格（单果重/果径/等级）、糖度、成熟度、色泽、允许瑕疵比例、农残检测标准及判定方法。
   - 明确**验收地点、验收时限、抽检比例、不合格处理**：拒收、降价、换货、退货费用谁承担。
   - 易腐品要约定“到货后几小时内提出异议”，避免事后扯皮。

2. **价格与调价机制**
   - 年度合同不要只写一个固定价，水果价格波动大。
   - 明确是固定价、随行就市还是区间价；调价触发条件、参考市场、调价频率、提前通知期。
   - 防止供应商在行情上涨时以“缺货”逼涨，或行情下跌时超市被锁高价。
   - 约定价格是否含税、含运费、含装卸、含包装。

3. **订单与最低采购量**
   - “年度采购量”是预估还是承诺？预估量不构成义务要写明。
   - 最低起订量、单次下单提前期、供应商最小供货量、超市最低提货量。
   - 避免签了“包销”却无实际采购约束，或反过来被供应商要求按预估量赔偿。

4. **交货与损耗责任**
   - 明确交货时间窗、地点、运输温控要求。
   - 水果损耗高，要写清**装车前后、运输途中、卸货前**的损耗由谁承担。
   - 迟到、短交、以次充好的违约金和替代采购差价索赔权。
   - 不可抗力范围别写太宽，天气、堵车不能都算不可抗力。

5. **食品安全与追溯**
   - 要求供应商提供产地证明、检测报告、合格证，约定抽检不合格的召回、下架、赔偿和监管处罚责任。
   - 明确农残超标、食安事故的**无限责任或高额赔偿**，以及超市对供应商的追偿权。
   - 保留供应商资质、批次追溯信息。

6. **账期与结算**
   - 账期起算点写清：到货验收合格后、对账确认后还是开票后。
   - 对账周期、发票类型、付款方式、逾期付款责任。
   - 质量扣款、退货冲抵、促销费用如何结算，避免月底对不上账。

7. **退货、换货与尾货处理**
   - 滞销、临期、品质下降时能否退换，费用谁承担。
   - 年度结束未售完库存怎么处理，别默认超市全兜。
   - 促销期临时加量、降价的支持政策。

8. **排他性与供货范围**
   - 是否约定某品类独家供应？独家容易在缺货时被卡脖子。
   - 供应商能否同时给周边竞品供货、价格是否最惠。
   - 若约定“最优惠价”，要写清比对口径和违约后果。

9. **违约与解约**
   - 连续几次质量不合格、断供、迟延可解约。
   - 违约金要覆盖替代采购差价、下架损失、客诉赔偿。
   - 避免只约束超市、不约束供应商的单向条款。

10. **合同期限与续约**
    - 年度合同起止日、自动续约条件、提前终止通知期。
    - 价格、品质标准是否随续约重新谈。

**最实用的做法**：把品质验收标准做成合同附件，逐项可量化；价格机制单独写清触发条件；把“预估量不构成采购承诺”和“不合格品处理时限”两条写死。签约前让采购、品控、财务三方各自审一遍对应条款。
