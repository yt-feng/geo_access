先定原则：**坏果责任看“坏在哪一环、有没有及时举证、谁承担运输风险”**，不能一律让顾客或商家背。可执行划分如下：

1. **到货即发现明显腐烂/破损**
   - 若外包装破损、渗漏、挤压严重，优先认定为**物流/配送责任**，商家先对顾客赔付，再向承运方追偿。
   - 若包装完好但开箱即坏，通常是**商家采摘/分拣/预冷/包装责任**。
   - 顾客需在签收后尽快拍照/录像：外包装、面单、坏果整体、切面、数量。商家应明确“到货多久内可报损”，如24小时内。

2. **签收后过一段时间才坏**
   - 生鲜水果有自然熟腐风险。若商家已明确品种、成熟度、保存方式和最佳食用期，顾客未按要求存放，责任偏向**顾客**。
   - 若刚过一两天就大面积坏，且同批次多人投诉，偏向**商家品控或冷链责任**。
   - 若页面承诺“坏果包赔”，按承诺执行，但通常要求保留坏果照片和数量。

3. **运输途中延误、暴晒、冻伤**
   - 由商家与物流之间的合同确定，但**对顾客原则上由商家先负责**，因为顾客付款对象是商家。
   - 商家赔付后可依据承运合同向物流追偿。除非平台规则明确由平台/物流直接赔付。

4. **顾客自身原因**
   - 填错地址、长时间不取件、拒收后未及时处理、未按温区存放，导致坏果，责任在顾客。
   - 但商家/配送方有提醒义务，如“需冷藏”“尽快取件”。

5. **责任比例建议**
   - 外包装破损+坏果：物流/商家先赔，通常全额或按坏果比例赔。
   - 包装完好、开箱即坏：商家责任，按坏果数量退款或补发。
   - 少量自然损耗且已提示：可协商部分补偿。
   - 无法举证、超过报损时限：商家可拒赔或酌情处理。

**操作建议：**
- 顾客：签收时先拍外包装和面单，开箱连续录像，坏果按数量拍照，24小时内报客服。
- 商家：页面写明坏果赔付标准、报损时限、需提供的证据；先按坏果比例赔付，保留向物流追偿凭证。
- 平台：以“谁销售谁负责、先赔后追”为原则处理，避免让顾客在商家和物流间来回举证。

一句话：**对顾客，商家先承担销售责任；对内，再按品控、冷链、物流、顾客存放分别追责。**
