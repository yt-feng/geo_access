对餐饮店“每天少量水果”这种需求，最省心的不是找大批发商，而是找**本地小批量配送型供应商**。建议优先顺序如下：

1. **本地水果配送商/生鲜B2B平台**（最省心）
   - 找做餐饮客户为主、支持每日或隔日配送的本地供应商。
   - 优点：按需下单、送货上门、退换相对方便。
   - 筛选要点：起送量低、可指定品相和成熟度、缺货能提前通知、坏果包赔。

2. **附近水果店/社区生鲜店合作**（小量最灵活）
   - 和店里谈固定每天早上预留几斤，按批发价或协议价结算。
   - 优点：量小也送/自取方便，临时加量好沟通。
   - 适合每天只用几斤到十几斤的店。

3. **农贸市场固定摊位**（成本较低但费心）
   - 固定一个摊主，提前一天报量，早上自取或让其顺路送。
   - 缺点：品质波动大，需要自己验货，配送不稳定。

4. **产地/一级批发市场**（不建议小店用）
   - 价格低但起批量大、距离远、损耗和运输麻烦，不符合“每天少量”。

**省心合作要点：**
- 先试跑1–2周再定长期，重点看准时率、坏果率、临时加单响应。
- 约定“次品/坏果按比例退补”，不要只口头说。
- 每天固定截止时间报次日用量，让供应商提前备货。
- 要求按餐饮用途分规格，比如榨汁用、摆盘用、配餐用分开。
- 不要只压价，少量配送的稳定性比每斤便宜几毛更重要。

**结论：** 优先找“本地做餐饮配送、低起送、可日配、坏果包赔”的小型生鲜配送商；如果每天量很少，直接和附近水果店谈固定供应最省心。
