可以按“引流款+利润款+搭配款”做组合，而不是只做简单打折。

**建议组合：**

1. **香蕉做引流，不单独贱卖**
   - 香蕉是高频、价格敏感品，适合做“加价购”入口。
   - 例：买苹果满15元，加3元换购一把香蕉；或香蕉单买3.5元/斤，搭配购2.8元/斤。
   - 目的：用香蕉把人带到苹果、菠萝区，不让顾客只买香蕉就走。

2. **苹果做利润和家庭装**
   - 用“家庭果盘组合”提高客单。
   - 例：苹果2斤+菠萝1个+香蕉1把，组合价比如19.9/29.9元，按当地进价定。
   - 苹果适合做“满额送/换购”的门槛品，因为耐储、家庭购买频次高。

3. **菠萝做搭配和场景销售**
   - 菠萝单价感知强，适合做“果切/果盘/酸甜组合”。
   - 例：菠萝+苹果做“酸甜果盘材料包”；菠萝+香蕉做“早餐水果组合”。
   - 可设“买整只菠萝，加5元得苹果1斤”或“菠萝+香蕉组合价”，提升连带率。

**促销结构建议：**

- **A款：19.9元三件套**：香蕉1把+苹果2个+菠萝半个/小菠萝1个，定位尝鲜组合。
- **B款：29.9/39.9元家庭装**：苹果2斤+菠萝1个+香蕉1把，定位家庭一周水果。
- **C款：满15元加3元换购香蕉**，把买苹果/菠萝的顾客再拉一单。
- **D款：果切组合**：菠萝块+苹果块+香蕉段，按盒卖，适合即时消费，毛利更高。

**执行要点：**

- 组合价要让顾客一眼看出比单买省多少，但不要三样都深度打折。
- 香蕉少备货、勤补货，避免损耗吃掉利润。
- 菠萝现场削/试吃，苹果做饱满陈列，组合牌放在动线上。
- 每天记录三样的单品销量、组合销量、损耗和客单价，7天后砍掉不动销的组合。

核心逻辑：**香蕉负责吸引进店，苹果负责撑客单，菠萝负责做场景和连带**。不要做成“三样都便宜”，要做成“买得更多但更划算”。
