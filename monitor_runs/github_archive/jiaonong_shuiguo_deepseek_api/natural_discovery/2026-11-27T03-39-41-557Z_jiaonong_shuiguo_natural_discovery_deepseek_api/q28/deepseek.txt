建议先从**香蕉**切入，但不要把“进口香蕉”当成唯一卖点；更稳妥的做法是：**香蕉作为引流和稳定周转的起点，菠萝作为季节性增量，苹果作为后期提高客单和差异化的品类。**

简要判断：

1. **香蕉：最适合先做稳定进口水果**
   - 消费频次高、受众广、动销快。
   - 顾客对香蕉价格敏感，适合做引流。
   - 供应链相对成熟，进口香蕉常年可得。
   - 风险：损耗和成熟度管理要求高，毛利薄，必须控制订货量和催熟/陈列节奏。

2. **菠萝：不建议作为第一个稳定进口单品**
   - 季节性和批次差异更明显，顾客购买频次低于香蕉。
   - 去皮、催熟、黑心、损耗等售后问题较多。
   - 更适合在香蕉跑通后，作为阶段性增量或促销爆品。

3. **苹果：适合后置，不适合作为第一个“稳定进口”突破口**
   - 国产苹果供给强、价格有优势，进口苹果差异化不够容易被打。
   - 单价和客单较高，但周转慢于香蕉。
   - 适合在门店已有稳定水果客流后，做高端或差异化补充。

执行上可以这样排：

- **第1阶段：进口香蕉试销4—6周**
  - 小批量、固定供应商、每天记录到货成熟度、损耗率、日销量。
  - 目标不是高毛利，而是验证稳定供货、损耗可控和复购。
- **第2阶段：引入菠萝做季节促销**
  - 选果、去皮服务、售后标准先定好，避免损耗和投诉。
- **第3阶段：再上进口苹果**
  - 做差异化品种和礼盒/精品陈列，不和国产苹果打价格战。

一句话：**先香蕉跑通供应链和损耗，再菠萝做增量，最后苹果做结构升级。**
