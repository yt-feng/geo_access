旺季最怕的不是“没货”，而是**临时被涨价、被优先供别人、到货质量不稳、损耗算你头上**。和供应商谈合作时，建议按下面几组问题提前问清，并尽量写进供货协议或微信文字确认。

**1. 供货能力与优先级**
- 旺季每天/每周最多能稳定供我多少箱/斤？最低起订量多少？
- 我这种单品在你们客户里排什么优先级？断货时按什么顺序保供？
- 你们有几个产地/基地/批发市场档口？主供地受灾或涨价时，备用货源在哪里？
- 旺季是否会出现“先接单后无货”？缺货提前多久通知我？

**2. 价格与调价机制**
- 报价是产地价、批发价还是到店价？含不含运费、装卸、包装？
- 旺季涨价提前几天通知？有没有锁价期或保底量锁价？
- 同一品种不同等级怎么定价？次果、小果怎么算？
- 长期合作有没有阶梯返利、满量优惠或淡季搭售条件？

**3. 品质标准与验收**
- 每批货的规格、成熟度、糖度、大小、色泽、新鲜度标准是什么？能否样品封存？
- 到货后多久内可验收？坏果率/损耗率超过多少可以拒收、换货或扣款？
- 运输温控、包装、防压防冻怎么做？谁承担途中损耗？
- 出现农残、霉变、冷害等问题怎么处理？能否提供检测或产地证明？

**4. 配送与时效**
- 正常下单后多久到货？旺季最晚到货时间？能否凌晨/早市前送达？
- 配送频率、车辆、装卸责任怎么安排？临时加单接不接？
- 节假日、雨天、交通管制时怎么保配送？延误怎么补偿？

**5. 结算与风险**
- 结算周期是现结、周结还是月结？要不要押金/保证金？
- 缺货、迟延、质量不达标的具体违约责任是什么？
- 价格波动大时，能否约定“最高涨幅”或“提前锁量锁价”？
- 合作终止时，未交付订单和预付款怎么处理？

**6. 替代与应急**
- 某个单品断货时，能否优先调其他等级/相近品种？调货价怎么算？
- 能否给我预留旺季安全库存？需要我提前多久报量？
- 有没有固定对接人和24小时应急电话？

**实操建议：** 先拿1—2个主销单品做“小批量旺季试供”，同时问清上述问题；关键条款用文字确认，尤其是**保供量、锁价期、损耗赔付、迟到/缺货补偿**。不要只谈价格，旺季真正决定你能否不断货的是**供应优先级、备用货源和违约成本**。
