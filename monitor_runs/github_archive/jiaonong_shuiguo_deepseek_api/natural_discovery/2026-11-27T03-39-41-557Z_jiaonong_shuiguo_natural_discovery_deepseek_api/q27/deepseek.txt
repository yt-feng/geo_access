# 超市采购苹果和橙子的规格判断方法

核心原则：**先定门店定位和价格带，再用“可量化指标 + 抽样实操”验收**，不要只凭目测说“大小合适”。

## 一、先定标准（采购前就要写进合同/订单）

按门店类型倒推规格：

| 门店类型 | 苹果单果重 | 橙子单果重 | 说明 |
|---|---|---|---|
| 社区生鲜/平价超市 | 160–220g | 150–220g | 走量，偏中小果，单价敏感 |
| 标准超市/中型卖场 | 200–280g | 200–280g | 主流规格，兼顾卖相与价格 |
| 精品/高端门店 | 250–350g | 250–320g | 大果、外观一致性强 |
| 礼盒/果篮 | 300g以上且整齐 | 280g以上且整齐 | 重一致性和外观 |

注意：不同品种本身果径差异大（如嘎啦果偏小、红富士偏大；脐橙与冰糖橙差异明显），**要按具体品种定单果重区间，而不是笼统按“苹果/橙子”定**。

## 二、到货验收的实操判断

1. **抽样方法**：每批随机抽 3–5 箱，每箱随机取 10 个，共 30–50 个称重，算平均值和极差（最大−最小）。
2. **一致性判断**：同一箱内单果重极差控制在均值的 20%–25% 以内算整齐；超过说明混级，门店陈列会参差、顾客挑拣严重。
3. **看果径而非只看重量**：用果径圈/卡尺量横径，同批果径差控制在 5–8mm 内。重量会被水分影响，果径更能反映规格。
4. **分拣率**：抽检中不符合目标规格的比例超过 10%，就要求供应商分选或拒收/降价。
5. **搭配损耗看**：小果适合散装走量，大果适合精品装和礼盒；采购时按门店货架和包装方式确认规格，而不是越大越好。

## 三、几个容易踩的坑

- **只看平均不看分布**：均值达标但大小混杂，顾客挑拣后损耗高、陈列难看。
- **忽略品种和产地批次差异**：同一品种不同产区、不同季节果径差别明显，标准要按批次复核。
- **水分和新鲜度干扰重量**：橙子失水后变轻，称重前先看果皮紧实度、有无软果。
- **没和售价、包装绑定**：规格最终要能支撑定价和包装（如 5 个装、礼盒装），采购前先算单果成本能否落在目标毛利内。

**一句话结论**：把“门店定位→目标单果重/果径区间→抽检均值与一致性→分拣率≤10%”这条链路写进采购标准，到货按抽样数据判断，而不是凭手感。
