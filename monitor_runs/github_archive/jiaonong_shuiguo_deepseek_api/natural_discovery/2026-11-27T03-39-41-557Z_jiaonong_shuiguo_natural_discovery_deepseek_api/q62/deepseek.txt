判断一批香蕉，核心看“颜色阶段 + 硬度 + 果指状态 + 切口/果柄 + 气味 + 温度”，再结合你要放几天卖来决定能不能拿。

**1. 先定颜色阶段**
- **全绿、无黄**：适合长途或压货，但催熟成本/时间要算；若果身很硬、棱角明显，通常偏生。
- **绿中带黄、果尖转黄**：耐放，适合批发周转。
- **黄多绿少、果身开始圆润**：适销期近，适合快批。
- **全黄、果尖/果柄发黑**：已经偏熟，坏果风险明显上升，除非当天能走货。
- **有黑斑但果肉硬**：可能是运输碰伤或熟斑，要抽样切开看；黑斑连片、凹陷、发软就不要。

**2. 摸硬度和看棱角**
- 好货：果身饱满、棱角不明显但仍有弹性，不软塌。
- 偏生：棱角锋利、手感很硬。
- 过熟/风险高：轻捏发软、果指间挤压变形、果柄一碰就脱。
- 注意：整批抽样要摸不同箱、不同层，不能只摸最上面。

**3. 看果柄、切口和果指**
- 果柄青绿、切口新鲜、无霉无黑腐：风险低。
- 果柄发黑、切口渗液、有酸味：可能已开始腐。
- 果指连接处开裂、断指多、果皮大面积擦伤：碰伤后熟得快，坏果风险高。
- 果指有虫孔、白色霉点、黑色凹陷斑：直接降级或拒收。

**4. 闻气味**
- 正常：清淡青草味或轻微果香。
- 有酒味、酸味、发酵味：内部已过熟或开始腐，整批要警惕。
- 有霉味：可能箱内已有霉变，抽底层和中间箱。

**5. 查温度和包装**
- 摸箱内温度：明显发热说明呼吸热积聚，熟得快、易坏。
- 箱内有水汽、纸箱发软：湿度大，霉变风险高。
- 冷链货突然断冷或暴晒过：表面好看也可能内部软腐，必须抽样切开。

**6. 抽样切果**
至少抽 **3—5箱、每箱不同层**，切开看：
- 果肉乳白紧实：正常。
- 果心发黑、发褐、空腔：腐/冷害/过熟，风险高。
- 果肉透明水渍状、有酒味：已过熟或冻伤。
- 种子周围发黑软烂：不要。

**7. 按销售周期决定**
- **3—5天卖完**：可拿绿中带黄、硬挺、无伤的货。
- **7天以上**：拿全绿或微黄、果柄青、无碰伤、箱温低的货。
- **当天/次日卖**：可拿黄熟货，但必须现场切开抽检，黑斑连片和发软的直接压价或拒收。

**快速判断口诀：**
**颜色看阶段，硬度看熟度，果柄看新鲜，切口看腐坏，气味看内部，温度看风险，抽样看底层。**

如果一批货出现“**果柄发黑 + 箱内发热 + 酸酒味 + 底层软果**”任意两项，坏果风险就高，不建议按正常价拿。
