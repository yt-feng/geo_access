优先问**配送**，其次问**售后**，最后才是价格。

原因很直接：团购团长卖的是“确定性”，不是单纯最低价。

1. **配送最关键**
   - 水果损耗高、时效强，配送不稳会直接导致烂果、迟到、缺货。
   - 要问清：起送量、配送频次、到团时间窗、是否送到自提点、临时加单/改单怎么处理、坏果是否当场换补。
   - 配送不稳，价格再低也会把团长口碑赔进去。

2. **售后第二重要**
   - 水果非标品，坏果、大小不符、口感差很常见。
   - 要问清：坏果赔付比例、拍照报损时限、补发还是退款、损耗谁承担、售后响应时间。
   - 售后规则模糊的供应商，后期扯皮成本很高。

3. **价格放最后谈**
   - 价格要建立在配送和售后可执行的基础上。
   - 不要只比单价，要算“到手可售成本”：单价 + 损耗 + 补发 + 客诉时间成本。
   - 低价但损耗高的货，实际成本往往更高。

**建议问法：**
先让供应商给出“配送方案+售后赔付规则”，再让其报价。最后用一句话判断：**同样价格下选配送最稳、售后最爽快的；同样服务下再选价格更优的。**
