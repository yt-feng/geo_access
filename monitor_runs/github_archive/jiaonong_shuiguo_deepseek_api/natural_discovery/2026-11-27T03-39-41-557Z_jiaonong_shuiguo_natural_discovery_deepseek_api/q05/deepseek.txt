这要先说清楚：你问的是“水果店经营时怎么卖菠萝”还是“顾客买菠萝选哪种”？下面按经营场景回答；如果你是顾客采购，末尾我也给一句判断。

**经营建议：不要三选一，按“分区+分级”卖最稳。**

1. **整果为主，占销量大头**
   - 菠萝耐放、损耗低、毛利好，适合让顾客自己挑。
   - 顾客挑整果有参与感，也容易接受“自己挑的不能怪店家”。
   - 整果适合标价按个/按斤，配上“帮削皮/帮切”服务。

2. **去皮好的做便利款，但控制量**
   - 去皮菠萝适合上班族、即时吃、懒人顾客，能拉高客单价。
   - 但去皮后失水、氧化、易污染，损耗和食品安全风险都高。
   - 建议：**少量现削、冷藏陈列、当天清完**，不要提前大量削好堆着卖。

3. **让顾客自己挑，但要有规则**
   - 整果区可以让顾客自己挑，但设“已挑不退换”或“当场验果”规则。
   - 店员要会教：看果眼、闻香气、按硬度、看底部，避免顾客挑生果后回来扯皮。
   - 对不会挑的顾客，店员可代挑并说明成熟度，减少售后。

**实操组合：**
- **整果区**：自己挑，按斤/按个卖，提供付费或满额免费削皮。
- **鲜切区**：少量现削盒装，标清“当日鲜切、冷藏保存、尽快食用”。
- **服务台**：顾客买整果可现场削皮切块，收少量加工费或满额免费。
- **分级处理**：成熟度高的做鲜切或特价；外观差的做果汁/特价整果，别混在正价区。

**关键判断：**
- 人流量大、上班族多、商圈店 → 鲜切便利款比例可高一些，但仍要少削勤补。
- 社区店、家庭客多、老人多 → 整果自己挑为主，削皮服务为辅。
- 夏天高温、卫生条件一般 → 鲜切要更谨慎，宁少勿多。

**如果你是顾客买菠萝：** 想放几天选整果自己挑；当天吃、不想动手选去皮鲜切的，但要看是否冷藏、是否当天削、有没有异味和汁水浑浊。
