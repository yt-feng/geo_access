酒店早餐水果供应，核心是把“稳定”落到可执行的条款和验收标准上，谈判时重点抓以下几块：

1. **明确品类和等级标准**
   - 按酒店早餐常用水果分档：苹果、香蕉、橙子、西瓜、哈密瓜、圣女果、葡萄等，明确品种、产地范围、单果规格（克重/直径）、成熟度、糖度下限、外观缺陷允许比例。
   - 写清楚“同等价位替代规则”：某品种断货时，供应商可提替代品，但需提前报备并经酒店确认，不能自行降级替换。

2. **稳定供应机制**
   - 约定固定下单周期和提前期，例如每日16:00前下单次日晨配，或每周两次配送。
   - 要求供应商提供备货方案：安全库存、替代产区、应急调货时限（如断货后几小时内补到）。
   - 约定缺货违约责任：按缺货金额比例扣款、累计缺货可终止合同，避免只写“尽量保证”。

3. **价格与调价机制**
   - 不要只谈单价，谈“价格形成方式”：固定周期报价（如每周/每月）、参考批发市场均价浮动、上下浮幅封顶。
   - 明确是否含税、含运费、含卸货到指定冷库/厨房；临时加单是否加价。
   - 对季节性波动大的品种设调价窗口，避免供应商临时大幅涨价。

4. **验收标准与退换货**
   - 到货时间、验收人、验收方式写进合同：抽检比例、糖度抽测、腐烂/压伤/异物的处理。
   - 不合格品退换时限（如2小时内补换）、费用承担、是否影响当日早餐供应。
   - 建立扣款或索赔标准，例如腐烂率超标按批次折扣或整批退回。

5. **食品安全与资质**
   - 要求营业执照、食品经营许可证、水果农残检测报告或承诺书，按批次提供农残快检/合格证明。
   - 明确运输温度、车辆卫生、包装不得使用有害材料；切配水果若由供应商提供，还需符合即食食品卫生要求。
   - 约定食品安全事故的责任和赔偿，保留追溯批次信息。

6. **配送与现场配合**
   - 配送频次、到达时间窗口要匹配早餐备餐节奏，迟到如何处理写清楚。
   - 卸货位置、冷链存放、包装回收、垃圾清理由谁负责。
   - 节假日、大型会议、旺季的增量供应能力要提前确认。

7. **合同期限与退出机制**
   - 建议先签3—6个月试合作，设月度考核（到货准时率、合格率、缺货次数、投诉响应）。
   - 明确连续考核不达标可无责终止，避免被长期合同绑定。
   - 约定账期、结算方式、发票类型，以及质量保证金或履约保证金（如适用）。

8. **谈判时先摸清底牌**
   - 让供应商按“品类+规格+周配送量”报价，而不是只报一个笼统价格。
   - 要求提供现有酒店客户案例或配送能力说明，实地看分拣/仓储条件。
   - 同时接触2—3家供应商比价，但不要只压价，稳定供应往往需要合理利润支撑。

一句话总结：谈判重点不是把单价压到最低，而是把**规格、缺货责任、验收退换、调价规则、食品安全追溯**写清楚，并用试合作和月度考核验证供应商的真实履约能力。
