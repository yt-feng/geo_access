做附近小区团购，水果供应商至少要支持下面这些服务，否则小店很容易被损耗、配送和售后拖垮。

1. **稳定供货与分级报价**
   - 能否按小区团购做“次日达/隔日达”稳定供货。
   - 是否提供不同等级：引流款、利润款、福利款，按箱/按斤/按份报价。
   - 是否支持小批量起订，避免小店压货。

2. **预售锁单与按单备货**
   - 供应商能否接受小店先收单、再报量备货。
   - 是否支持临时加减单，截单时间是否固定。
   - 对爆单、缺货是否有替代品方案。

3. **品控与标准化**
   - 是否有统一规格，比如净重、果径、成熟度、箱规。
   - 能否做坏果率承诺，比如到货坏果超过多少包赔。
   - 是否支持按团购份量分装、贴标。

4. **冷链与配送**
   - 是否支持送到小店自提点，而不是只到大仓。
   - 配送频次、到货时间是否稳定。
   - 夏季/易损水果是否有冷链或冰袋支持。

5. **售后与赔付**
   - 坏果、压伤、缺斤少两怎么赔。
   - 是否支持拍照报损、当日/次日补货或退款。
   - 售后责任边界要写清：供应商到店前问题归供应商，到店后归小店。

6. **营销素材支持**
   - 是否提供水果图片、卖点文案、产地信息、检测报告。
   - 能否给团购专属价、试吃装、引流爆品。
   - 是否配合做“今日团/明日到”的素材。

7. **结算与账期**
   - 现结、周结还是押金合作。
   - 是否支持按实际到货结算，而不是按发货结算。
   - 价格保护：团购期间供货价是否稳定。

8. **退换货与尾货处理**
   - 未售完尾货能否换货或折价处理。
   - 临期/成熟度偏高水果是否有处理方案。

9. **合规与票据**
   - 能否提供进货凭证、检测报告或产地证明。
   - 是否可开票，至少能提供收据/对账单。

10. **试合作机制**
   - 先做1—2个小区、1—2周试团。
   - 重点看：到货准时率、坏果率、售后响应速度、缺货替代能力。

**给小店的落地建议：**
和供应商谈的时候，不要只谈价格，优先确认这5条写进合作约定：**小批量起订、按单备货、到店配送、坏果包赔、售后响应时限**。先用一个小区试跑，记录每团损耗率和售后率，再决定是否扩到更多小区。
