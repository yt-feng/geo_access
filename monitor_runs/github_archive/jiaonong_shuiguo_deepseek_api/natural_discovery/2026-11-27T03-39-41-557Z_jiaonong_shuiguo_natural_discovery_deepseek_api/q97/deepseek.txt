酒店采购水果盘原料时，建议把“规格标准”和“外观标准”写进采购单/验收单，并明确允收、拒收和让步接收规则。可按以下维度要求供应商保证：

**一、通用规格与外观标准**
1. **品种与产地明确**：写明具体品种、等级、产地或允许替代范围，不接受以“时令水果”笼统供货。
2. **新鲜度**：到场时无萎蔫、皱皮、发酵味、霉斑、虫蛀；果柄切口新鲜，叶菜类不黄化。
3. **成熟度**：适合酒店当日或短时展示与食用，一般要求“八成熟左右、可即食”，不得过硬或过熟软烂。
4. **大小与重量**：按品种规定单果直径/长度/单果重量范围，同批次规格均匀，允许偏差建议控制在±5%～10%，具体按酒店标准定。
5. **色泽与果形**：具有该品种固有色泽，着色均匀；果形端正，无明显畸形、偏斜、裂口。
6. **表面与表皮**：无大面积机械伤、压伤、擦伤、日灼、冻伤、病斑；允许轻微自然瑕疵但不影响切配和外观。
7. **洁净度**：无泥土、污物、农药残留风险；供应商应提供符合食品安全要求的检测或承诺文件。
8. **气味与口感**：无异味、发酵味、霉味；到货抽检口感正常。
9. **病虫害与异物**：无活虫、虫卵、虫蛀孔、霉变；无枝叶杂物、泥沙、包装碎屑等异物。
10. **温度与冷链**：易腐水果应冷链运输，到场中心温度符合品种要求；冷藏水果不得断链或反复回温。

**二、按水果类型补充标准**
- **苹果、梨、橙、柚等**：果形端正，无大面积锈斑、裂果、腐烂；硬度适中。
- **葡萄、提子**：果穗完整，果粒饱满，无落粒、裂果、霉烂；果梗新鲜。
- **草莓、蓝莓、树莓**：无压伤、渗汁、霉变；盒装无结露积水，单果完整。
- **西瓜、哈密瓜、菠萝等**：成熟度适中，无软腐、裂口；切配类应规定糖度或成熟度区间。
- **香蕉、芒果、猕猴桃等后熟水果**：明确到货成熟度阶段，避免到场即过熟或长期不熟。
- **柑橘类**：无青果、干疤、水肿、腐烂；果蒂新鲜。
- **火龙果、猕猴桃等**：无软塌、冻伤、机械压痕。

**三、包装与标识**
1. 包装完好、清洁、无污染，内包装不与水果发生反应。
2. 外箱标识品名、等级、规格、产地、采收/包装日期、供应商信息、批次号。
3. 同批次可追溯；不得混级、混批、以次充好。
4. 不得使用有害保鲜剂或过量保鲜处理，保鲜方式应提前告知。

**四、验收与责任条款**
1. **抽检比例**：建议按到货件数抽检，重点检查霉烂、压伤、规格偏差、成熟度和中心温度。
2. **允收标准**：明确不合格率上限，例如单批外观不合格率超过5%可拒收或折价；霉烂、虫害、异味应零容忍。
3. **拒收与换货**：到货不符合约定时，供应商应限时补货/换货，并承担因此造成的损失。
4. **短重与规格偏差**：按净重验收，包装重量不计；规格偏差超范围按折价或退货处理。
5. **食品安全文件**：供应商应提供营业执照、食品经营/生产相关许可、检验合格证明或承诺书，必要时提供农残检测报告。
6. **留样与追溯**：每批次留样并记录，出现问题可追溯至批次。

**五、建议写入合同的关键句**
“供应商保证所供水果符合约定品种、等级、规格、成熟度和新鲜度要求；无霉烂、虫害、异味、明显机械伤和异物；符合国家食品安全相关要求；到货验收不合格的，酒店有权拒收、要求换货或折价处理，相关费用由供应商承担。”

实际操作中，最好把每种水果的**单果规格、成熟度、允许瑕疵比例、冷链温度、抽检比例**做成一张验收表，随采购单发给供应商并双方确认，这样验收时最不容易扯皮。
