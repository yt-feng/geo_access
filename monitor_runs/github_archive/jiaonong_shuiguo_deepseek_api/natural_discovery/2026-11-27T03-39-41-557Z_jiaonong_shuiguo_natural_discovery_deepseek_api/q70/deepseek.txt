# 生鲜批发合同坏果责任条款写法

核心思路：**坏果责任不能只写“可退换”，必须约定可量化的验收标准、责任划分、处理方式和时限**，否则发生争议时无法执行。

## 一、先约定“什么算坏果”（验收标准）

没有标准的“说烂就烂”，条款就是废纸。建议写：

- **定义**：霉变、腐烂、软烂渗汁、明显异味、冻伤/灼伤、病虫害、严重机械压伤等，逐项列举。
- **量化门槛**：如“单果腐烂面积超过X%”、“同批次坏果率超过X%视为整批不合格”，并约定抽样比例和抽检方式（如每批次随机抽3箱，按重量计）。
- **区分“到货即坏”与“储运后坏”**：明确以**卸货时双方共同验收**结果为准；验收后买方自行储存导致的损耗，卖方不担责。这一条很关键——很多扯皮都出在“是不是你自己放坏的”。

## 二、责任划分与免责

- **卖方责任**：到货验收不合格的坏果，卖方按约定补货、折价或退款。
- **买方责任**：验收签字后、或买方未在约定时限内提出异议的，视为合格；买方储存不当造成的损耗自行承担。
- **不可抗力/运输方责任**：如因承运人原因致损，约定由谁向承运人追偿（通常由卖方负责与物流交涉，买方只对卖方）。

## 三、处理方式要写死（三选一或组合）

1. **补货**：坏果部分按同规格同数量补发，运费由责任方承担；
2. **折价扣款**：按坏果重量/比例从货款中扣除，明确扣款单价计算方式；
3. **退货退款**：整批不合格时全额退，并约定退货运费由谁出。

建议写“买方有权选择其一”，避免卖方只肯折价不给补货。

## 四、时限与流程（最容易被忽略）

- **异议期**：如“卸货时当场验收，或到货后24小时内书面/拍照提出，逾期视为验收合格”。
- **举证方式**：要求买方提供**带时间水印的照片/视频、开箱过程录像、过磅单**，避免事后拿别批货的烂果索赔。
- **响应时限**：卖方应在收到异议后X小时内答复，逾期视为认可。

## 五、参考条款模板（可直接改）

> 1. 验收以卸货时双方共同抽检为准，抽检比例不低于每批次3箱。单果腐烂、霉变、软烂渗汁面积超过10%，或单批次坏果重量占比超过3%的，视为不合格。
> 2. 不合格部分，买方有权在到货后24小时内凭带时间水印的照片及过磅记录提出，卖方应在12小时内确认，并选择补货、按实际坏果重量×约定单价扣减货款或退货退款；补货及退货运费由卖方承担。
> 3. 买方逾期未提出异议，或验收合格后因储存、转运不当造成的损耗，由买方自行承担。
> 4. 因承运人原因造成的货损，由卖方负责向承运人追偿，不影响买方依本条向卖方主张权利。

## 六、给批发商的实操提醒

- **别只签框架**：每批次附**送货单**，写明品种、规格、数量、单价、验收结果，双方签字，比合同条款更管用。
- **留证据**：发货前拍照/录像装箱，记录装车时间和车厢温度（冷链货尤其重要），这是抗辩“路上坏的”最有力证据。
- **坏果率门槛要谈得现实**：生鲜行业通常有1%–5%的自然损耗区间，门槛定太低你赔不起，定太高对方不签，按品类实际谈。
- **大额交易可约定第三方检验**：争议时送当地质检或行业协会抽检，费用由责任方承担。

一句话总结：**标准量化 + 当场验收 + 异议时限 + 处理方式三选一 + 举证要求**，五样写全，坏果责任才真正可执行。
