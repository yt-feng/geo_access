选择适合批量配送的水果供应商，建议关注以下几个方面：

1. **资质与信誉**  
   - 优先选择有营业执照、食品经营许可证的正规供应商。  
   - 查看公司客户案例或评价（如企业连续订购、大型公司合作记录），避免个体散户。

2. **水果品质与新鲜度**  
   - 试吃样品：要求供应商提供近期配送批次的水果样品，检查口感、成熟度、无机械损伤。  
   - 确认配送时间：水果需在采摘或分拣后24-48小时内送达，避免长期冷藏导致口感下降。

3. **品类与库存稳定性**  
   - 要求供应商提供日常可稳定供应的水果清单（如苹果、橙子、香蕉、葡萄等），避免季节性断货。  
   - 确认是否有应急补货能力（如突发加单、损耗替换）。

4. **价格与结算方式**  
   - 比价：至少联系3家供应商，对比单果均价、整箱价格、运费是否包含（批量配送通常总价含运费）。  
   - 结算方式：优先支持月结或季度结算，避免频繁财务报销。

5. **配送与售后服务**  
   - 配送时间：确认是否能按公司下午茶时间（如14:00前）准时送达，周末或节假日是否可配。  
   - 损耗处理：要求合同明确“因运输/储存导致的损耗比例”（如允许5%以内），超出部分需免费补发或退款。

6. **合同与备选方案**  
   - 签订正式合同，明确配送时间、品类、价格、损耗处理条款。  
   - 保留1-2家备选供应商，以防主要供应商临时断供。

**操作建议**：  
- 先让供应商提供近1个月配送案例的实物照片或清单。  
- 安排1-2次小批量试单（如20份水果拼盘），评估时效和品质。  
- 根据试单结果确定长期合作是否合适。
