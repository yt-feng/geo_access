判断水果供应商是否靠谱，可以从以下几个方面入手（重点针对香蕉和菠萝这类大宗水果）：

1. **看供应稳定性与发货时效**  
   - 香蕉需要特定成熟度（如七八成熟）才能运输，询问供应商是否有**恒温冷库**和**控熟处理**能力。  
   - 菠萝要求**无损伤、无黑心**，确认对方能否做到**48小时内从产地直发**（尤其夏季）。  
   - 测试法：要求**连续一周下小单**，观察能否准时到货、品质波动是否在可接受范围内。

2. **验货与损耗处理**  
   - 到货后当场开箱检查：香蕉的**把柄是否发黑**（常见运输伤）、菠萝的**眼是否干瘪**（失水或存放过久）。  
   - 询问**损耗承担比例**，靠谱供应商通常接受**3%-5%损耗**内免费补货或退款。

3. **资质与价格规律**  
   - 要求对方提供**营业执照**和**产地证明**（如海南、广西的菠萝产地证）。  
   - 警惕价格**长期低于市场价15%以上**，可能是陈货或掺杂劣果（例如用菠萝柄过长的次品充好）。  
   - 建议对比：到当地批发市场查同品质香蕉的批发价，如果供应商报价高出20%以上需警惕。

4. **合同关键条款**  
   - 必须写明：**规格（如香蕉每把多少根、菠萝单果重量范围）**、**验收标准（含裂纹、霉变允许比例）**、**付款方式（建议先付30%试单，稳定后月结）。  
   - 示例条款：**“到货后24小时内验收，如有质量问题，供应商需在48小时内补发或退款”**。

**最后建议**：先通过**农贸市场同行**或**本地果品协会**推荐（尤其是做了3年以上的老店），第一次合作**从小批试点开始**，避免被大单压款压货。
