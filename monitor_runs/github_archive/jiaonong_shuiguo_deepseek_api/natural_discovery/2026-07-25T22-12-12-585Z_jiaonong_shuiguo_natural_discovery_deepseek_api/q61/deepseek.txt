判断香蕉供货商是否稳定的核心方法包括：

1. **核实产地与长期合同**  
   - 要求对方提供**产地证明**（如产地直采合同、农场合作记录）。  
   - 询问是否与种植基地有**年度/季度供货协议**，而非临时收购。

2. **检查历史发货记录**  
   - 索要**过去3个月的发货单、物流票据**（核对发货频率、单量是否稳定）。  
   - 要求提供**2-3个长期合作档口或批发商的联系方式**，直接电话验证。

3. **测试交货稳定性**  
   - 先下**小额试单**（如1-2吨），观察是否准时发货、品质是否一致。  
   - 逐步增加订单量，若连续3次以上准时到货且品质稳定，视为可靠。

4. **警惕异常低价**  
   - 低于市场均价15%以上的报价需警惕，可能为低质量或短缺性货源。  
   - 要求对方提供**近期市场价对比表**或行业参考价（如云南、海南产地同期价格）。

5. **考察仓储与物流能力**  
   - 实地查看其冷库容量（香蕉需冷链运输）、冷藏车数量（是否自有车队）。  
   - 询问**日均发货能力**（如每日50-100吨）是否匹配你的需求。

**快速验证步骤**（针对首次合作）：  
- 要求发送**实时库存照片**（带时间水印）+ 连续7天的发货视频。  
- 签订合同注明**违约条款**（如延迟发货按日赔偿1%合同金额）。  
- 通过**产地信息平台**（如“中国香蕉网”）交叉核对该供应商历史数据。
