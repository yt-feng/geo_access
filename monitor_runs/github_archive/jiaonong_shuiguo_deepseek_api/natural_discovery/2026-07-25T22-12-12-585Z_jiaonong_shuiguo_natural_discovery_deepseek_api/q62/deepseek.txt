判断一批香蕉的熟度和坏果风险，可从以下四个维度进行快速评估：

1. **果皮颜色与光泽（熟度）**  
   - 青皮带黄：七成熟左右，适合长途运输或短期存放。  
   - 全黄无斑：九成熟，货架期约2-3天。  
   - 出现芝麻点（褐色小点）：熟度较高，需当天或隔天售完。  
   - 表皮无光泽或发暗：可能已过熟或即将变质。

2. **果柄与切口（新鲜度与风险）**  
   - 切口洁白干燥：新鲜；切口发黑、发黏或渗水：已开始腐烂，感染风险高。  
   - 果柄捏有弹性：正常；果柄软塌：植株病害或储存温度过高。

3. **触感与硬度（坏果直接信号）**  
   - 轻轻按压中段：略有弹性为正常；过软或有凹陷点：大概率内部已坏。  
   - 整把提起时轻微抖动：若部分香蕉晃动厉害或易脱落，可能果柄已断裂或腐烂。

4. **气味与冷害痕迹（隐藏风险）**  
   - 正常：清香；若有酸味、酒味或霉味：已开始发酵或局部霉变。  
   - 表皮出现不规则暗沉、水渍状斑点：可能受过冷害（低于11℃），会导致后期无法正常上色且易烂。

**实操建议**：  
- 抽样切梢：切开果柄或顶部，看内部是否发褐或出现水渍（黑心病早期信号）。  
- 查看包装：内部是否潮湿、有水汽（高温高湿易诱发炭疽病）。  
- 试吃：如果果肉疏松、发软或有酸味，整批需降级处理或立即销售。

**高风险信号（直接拒收）**：  
- 揉搓表皮有汁水渗出。  
- 一箱中有超过5%出现灰黑色霉斑或白色菌丝。  
- 整箱有刺鼻药味或异味。
