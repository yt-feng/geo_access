为茶饮店采购香蕉控制熟度，建议按以下方式操作：

1. **明确用途**：不同产品需要不同熟度
   - 做奶昔、冰沙、布丁：选熟透（表皮有黑斑，很软）
   - 装饰切片、奶盖顶料：控制在刚熟（表皮金黄，较硬）——太熟会烂、易氧化
   - 烤制或糖浆类：中等熟度最好

2. **采购技巧**：采购时可要求供应商分批次发货
   - 每周补货2-3次，每次配送全绿或半绿的香蕉，让它们自然在店里成熟
   - 到货后立即检查：轻捏有弹性、无软烂、无黑斑（除非你要熟透的）

3. **按量下单**：每天预估用量，只买3天内能消耗完的量。发现香蕉太生、太熟都可以换货

4. **验收标准**：
   - 生用（切片/装饰）：表皮100%黄色，微硬，无青色
   - 熟用（搅拌/打泥）：表皮70%-80%黄色带小斑点，稍软

5. **快速补救**：如果到货的香蕉太生，放在室温（25℃左右）1-2天；太熟可用于冷冻保存做冰沙底

最后，直接和供应商沟通：说明你要剥皮后不会氧化太快的香蕉，提前说好“全黄微硬”或“全绿但是可以换货”就行。
