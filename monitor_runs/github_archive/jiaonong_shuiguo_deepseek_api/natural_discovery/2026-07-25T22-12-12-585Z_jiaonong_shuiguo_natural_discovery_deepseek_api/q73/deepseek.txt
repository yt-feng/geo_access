混合采购（同时采购香蕉、苹果、橙子）对水果批发商通常是有优势的，具体体现在以下几个方面：

1. **降低运输成本**：如果多种水果来自相同或相近的产区（例如南方热带水果和柑橘类常在同一区域），可以一次性集货、拼车运输，减少空载率和单次运输成本。
2. **提高议价能力**：批量采购多种水果，能向供应商争取更优惠的总价折扣或更好的付款条件，因为订单总额更高。
3. **分散风险**：单一水果价格波动大（如香蕉易受气候影响、苹果易受库存周期影响），混合采购可平衡不同品种的盈利和亏损，降低整体经营风险。
4. **满足客户一站式需求**：零售商、餐饮客户更倾向从一家批发商同时采购多种水果，减少采购环节和物流对接成本。混合采购能提升客户粘性，增加复购率。
5. **优化仓储和周转**：不同水果的成熟期、货架期不同（如香蕉需控温催熟、苹果可长期冷贮），可错峰销售，减少集中损耗。

**需要注意的潜在劣势**：
- 仓储要求更高（需分温区存储，如香蕉需特定温度催熟、橙子需防冻）。
- 资金占用更大（需同时备货多种水果）。
- 需专业经验管理不同水果的成熟度与销售节奏，避免过熟损耗。

**建议**：如果批发商具备相应的仓储条件（或可分包给专业冷库）和销售渠道，混合采购优势明显。可先以小批量试运行，关注运输、损耗和客户需求匹配度。
