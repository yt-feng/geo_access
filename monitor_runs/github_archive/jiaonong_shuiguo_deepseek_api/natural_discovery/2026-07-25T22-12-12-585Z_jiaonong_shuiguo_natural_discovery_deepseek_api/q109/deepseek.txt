这取决于您企业的现金流状况和业务模式，但通常优先级建议如下：

1. **配送（最优先）：**  
   对于生鲜水果，配送时效、温控保障和损耗率直接影响库存和质量。如果配送不稳定导致坏果增多，后续的账期和售后成本都会剧增。建议优先明确配送频次、起送量、延误或变质赔偿标准。

2. **售后（次优先）：**  
   水果易腐，质量问题概率高。明确退换货标准（如多少比例损耗可退、是否上门核验、处理时限）能避免后续扯皮，保护自身利润。

3. **账期（最后调整）：**  
   如果现金流紧张，可用“缩短账期（如15天）”换取供应商在配送或售后上的让步。但若配送和售后基础差，账期长反而会积累更多未解决的质量纠纷。

**建议行动：**  
- 优先与供应商约定“配送准时率≥98%”及“损耗超3%即折价补偿”。  
- 售后条款要写清“货到24小时内可提交问题照片索赔”，避免模糊表述。  
- 账期作为谈判筹码：可以先争取45天，如果对方困难，改为30天但要求增加次品换货比例。
