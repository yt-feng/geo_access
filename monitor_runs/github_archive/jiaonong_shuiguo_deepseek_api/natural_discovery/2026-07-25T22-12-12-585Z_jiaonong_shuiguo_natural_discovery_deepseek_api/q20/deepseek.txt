选择社区超市的日配水果供应商时，建议重点关注以下几点：

1. **配送稳定性**：核实供应商能否保证每日按时送达，尤其是早晨或超市规定的时间段。可要求提供历史配送记录或试运行期。

2. **新鲜度与损耗率**：询问当天采摘到送达的时间，一般水果应控制在24小时内。可要求对方说明损耗标准，并确认是否支持退换不合格品。

3. **品种与季节适配**：确认供应商能否按季节提供当地居民常购品种（如夏季西瓜、冬季柑橘），以及是否有稳定的小众热门品种供应。

4. **价格与结算方式**：至少对比3家供应商的批发价，注意是否含运费。确认结账周期（例如周结、月结）和是否支持零星退货抵账。

5. **资质与溯源**：要求提供营业执照、农产品检测报告（尤其是农药残留），以及水果产地证明。如果涉及进口水果，需检验检疫证明。

6. **应急响应能力**：测试供应商在断货、天气异常时的处理方案（如替代品种或紧急补货）。可询问是否有备用供应渠道。

7. **包装与库存建议**：评价其包装是否减少运输损伤，以及能否根据超市历史销售数据给出合理备货建议（如减少易损耗品的单次量）。

建议先小批量试合作1-2周，观察实际到货质量、时效和调换服务的效率。
