采购小包装香蕉时，主要需关注**包装设计**和**损耗控制**两点。以下是具体建议：

**一、包装注意事项**
1. **透气性**：香蕉呼吸作用强，必须用带孔塑料袋或微孔保鲜膜，防止积湿发霉。
2. **防护结构**：选用硬质托盘或纸板隔层，防止挤压碰伤。避免直接堆叠。
3. **尺寸适配**：单包装建议2-3根（约300-500克），适合单人家庭高频消费。太长（如4-5根）易成熟不均。
4. **标签贴放**：贴在不挤压部位（如顶部或包装袋边缘），避免直接贴在香蕉皮上留胶痕。
5. **外观透明区**：包装至少留50%透明区域，方便顾客检查成熟度与损伤。

**二、损耗控制**
1. **成熟度分级**：进货时选7-8分熟（果皮黄绿相间、轻按有弹性），避免全青（催熟成本高）或全黄（货架期短于2天）。
2. **集中催熟**：若超市有催熟库或乙烯利处理，可统一催熟至8分熟再包装；否则直接采购8分熟产品。
3. **上架管理**：每日翻检，单包装内只要有一根出现黑斑或软烂，立即拆包以折扣出售或做果泥。避免连带整包丢弃。
4. **温湿度控制**：冷柜温度需稳定在**13-15℃**（严禁低于12℃导致冷害变黑），湿度保持90-95%。
5. **供应链时限**：从包装到上架，总时限控制在**2-3天**。夏季运输必须用冷藏车（15℃以下）。

**三、其他策略**
- **试购测试**：首批进200包，分2家供应商（如产地直采+批发市场），对比一周内损耗率。
- **防碰措施**：采购时检查包装箱内是否有弹性填充物（如珍珠棉），香蕉与箱壁间应有≥2cm空隙。
- **库存周转**：设置“最后销售日”标签（如包装后第3天），到期未售即降价15-20%。

如果能同时提供**带孔包装**和**独立托盘**，可减少约30%的碰伤损耗。建议在采购合同中加入“到货后24小时内损耗超8%则供应商承担”的条款。
