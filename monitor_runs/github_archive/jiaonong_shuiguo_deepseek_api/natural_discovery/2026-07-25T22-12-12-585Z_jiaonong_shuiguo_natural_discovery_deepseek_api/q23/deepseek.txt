通常是可以的。供应商为了促进自家水果的销量，往往会提供陈列、海报、试吃等支持，具体包括：

1. **陈列支持**：提供水果专用的陈列架、托盘、堆头道具，或者安排专职促销员负责理货和补货。
2. **海报/宣传物料**：提供产品海报、吊旗、价签卡、促销爆炸贴等印刷品，部分供应商也可提供电子版素材用于超市内屏或群发。
3. **试吃支持**：提供试吃样品、试吃台、牙签/小碟等耗材，有时还会派试饮/试吃员协助。

**建议操作**：
- 提前与供应商沟通促销档期、预期销量，书面确认支持范围和费用分摊（如海报设计费、试吃损耗是否由供应商承担）。
- 建议将支持内容写入合同或促销协议，明确责任，避免口头承诺无法兑现。
