水果店遇到坏果的结算或赔付方式通常依据**进货时的约定**（合同或行业惯例）来执行。以下是常见且相对合理的处理流程和原则：

### 1. 第一步：及时确认坏果性质
-   **区分是否自然损耗**：水果有一定自然损耗（如部分易损水果1%-3%的破损率），通常这部分不赔偿。
-   **明确责任**：
    -   **供应商问题**：如新鲜度差、内部霉变、运输中因包装不当造成的挤压。
    -   **顾客或存储问题**：水果上架后未及时处理、长期陈列不当、冷库温度异常等导致的变质，一般由店家承担。

### 2. 常见的结算与赔付方式（按优先级）

**情况A：按账期货款扣除（最常用）**
-   **做法**：在结算当月账款时，统计出所有坏果数量（拍照或视频留证），按**进货价格**（不是零售价）计算总金额，直接从应付给供应商的货款中扣除。
-   **注意**：必须提供清晰的坏果证据，建议收货时立即开箱分拣并拍照。

**情况B：按约定比例赔付（行业标准）**
-   **做法**：双方事先约定一个“免赔率”（例如：金桔、葡萄等易坏品种，5%以内不赔；超过部分，供应商承担）。实际结算时按超出部分的数量×进价赔付。
-   **常见比例**：
    -   高价值水果（车厘子、蓝莓）：通常0免赔或极低免赔。
    -   易损耗水果（草莓、香蕉）：可能约定5%-10%的免赔率。
    -   普通水果：1%-3%免赔率。

**情况C：换货（适合小额或批量问题）**
-   **适用场景**：坏果比例较高（如超过20%），且供应商有库存。
-   **做法**：供应商下次送货时，免费补充同等质量和数量（或折价补货）的好果。
-   **注意**：换货产生的运输成本通常由供应商承担。

**情况D：现金折让（小额补偿）**
-   **适用场景**：只有少量坏果，且双方合作稳定。
-   **做法**：供应商下次进货时，直接少收对应金额，或者补发少量其他水果作为补偿。

**情况E：签收前的处理（最理想）**
-   **做法**：供货合同约定“**收货时开箱检查**”，当场发现明显坏果（如腐烂、挤压出水）直接拒收或标记，供应商当场补货或减价。这部分通常不会被算作“内部损耗”。

### 3. 避免踩坑的关键点
-   **不要用零售价换算**：赔付时**必须用进货价**（你花多少钱买的），不能按你打算卖多少钱算。
-   **保存证据**：整箱坏果的**照片、视频、快递面单、供应商送货单**。最好提供10秒以上、有整体画面和特写镜头的视频。
-   **明确时间窗口**：大多数供应商接受**收货后2-4小时内**的坏果反馈。超过24小时可能不予受理（尤其运输途中或临时存储问题）。
-   **坏果类型分辨**：如果是**内部腐烂**（表面完好但切开已坏），收货时看不出来，应在发现后立即（建议1小时内）拍照联系供应商，这种情况常见的行规是可以赔付的。

### 4. 实操建议
-   **首次合作**：建议在进货单上写一句“出现腐烂等质量问题，按实际坏果数量×进货价在结款时扣除”。
-   **长期合作**：和供应商约定“**每月统计一次坏果率**”，超过行业平均损耗比例的部分由供应商承担。
-   **紧急处理**：如果大批量坏果（如整车或整箱），优先联系供应商退货或换货，不要自行拆除包装，保留原样。

**总结**：
-   **推荐方式**：**拍照留证 → 核算进价 → 在当月货款中直接扣除对应金额**。
-   **避免做法**：没有证据就口头索赔；以零售价要求赔偿；过了24小时才反馈。
-   **底线原则**：在“自然损耗”范围内的不计赔，超出部分按进价赔付，这是行业通行且公平的做法。
