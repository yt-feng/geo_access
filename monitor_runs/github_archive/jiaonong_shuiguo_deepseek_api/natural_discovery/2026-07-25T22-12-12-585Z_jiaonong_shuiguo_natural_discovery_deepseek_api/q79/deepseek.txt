最应该优先问三个方面的顺序如下：**配送 > 售后 > 价格**。

具体原因和建议：

1. **配送（最优先）**  
   水果易损耗、保质期短，配送时效和保鲜条件直接影响品质。  
   - 要问：配送频次（是否每日/隔日）、配送时间窗口（是否能在开团前到货）、冷链/保鲜措施（夏天尤其重要）、起送量和配送范围。  
   - 关键指标：**是否顺丰/冷链直达，能否指定时间段派送**。

2. **售后（第二优先）**  
   水果难免出现坏果、磕碰或规格不符，售后政策决定你的损失控制能力。  
   - 要问：坏果包赔比例（常见是10%~50%不等）、赔付方式（退款/补发/优惠券）、是否需要开箱拍照、理赔时效（多久内必须反馈）。  
   - 注意：**是否支持“签收后48小时内补拍照片即可售后”**，避免对方以“超时”推脱。

3. **价格（最后考虑）**  
   价格可以通过比价和长期合作压下来，但配送和售后不过关，低价反而会导致客诉和口碑崩盘。  
   - 建议：先拿小批量试单，确认配送和售后靠谱，再谈价格优惠或批量折扣。

**总结执行建议**：第一次合作时，按上述顺序逐一确认，并**签书面或聊天记录留证**（如“坏果包赔30%”“签收后48小时内覆盖售后”），避免口头承诺。
