从损耗角度来看，**鲜果切配的损耗通常低于直接购买成品果丁**，原因如下：

1. **鲜果切配损耗可控**：购买整颗菠萝（带皮）的损耗率约在40%~50%（去皮、去眼、去芯），但你可以通过多次切割、合理利用边角（如制作菠萝汁或装饰）降低实际损耗至30%~40%。

2. **成品果丁损耗隐蔽**：成品果丁虽然降低了切配人工和时间成本，但存在以下隐性损耗：
   - 储存损耗：开封后未用完的果丁因接触空气易氧化变质，需按“先进先出”原则快速消耗。
   - 包装损耗：部分果丁可能因运输挤压或包装破损产生浪费。
   - 糖水浸泡损耗：为延长保质期，成品果丁常浸泡在糖水中，实际果肉重量可能低于标称。

3. **成本与灵活性的权衡**：
   - 如果甜品种类单一（如仅用菠萝丁做装饰或果酱），成品果丁可节省人工，但需精确预估短期用量。
   - 如果甜品种类多（如同时做菠萝炒饭、菠萝挞等），鲜果切配能按需调整形状和成熟度，损耗更可控。

**具体建议**：
- 优先鲜果切配，将损耗率控制在35%以下，并利用菠萝皮、芯制作糖浆或废料处理。
- 若购买成品果丁，尽量选择品牌信誉高、包装日期近的产品，并严格按单次用量分装冷冻。
