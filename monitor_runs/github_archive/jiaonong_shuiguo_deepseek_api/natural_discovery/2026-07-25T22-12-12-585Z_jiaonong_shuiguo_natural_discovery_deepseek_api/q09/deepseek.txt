在水果店旺季与供应商谈判时，建议提前问清以下5类关键问题，以降低断货风险并保证利润空间：

1. **供货稳定性**  
   - “旺季日均最大供货量是多少？能否签**保底供货协议**？”  
   - “如果遇极端天气或物流问题，是否有**备选产地或替代供应商**？”

2. **价格与结算**  
   - “可否锁定旺季**价格区间**（如随行就市但不超过某个涨幅）？”  
   - “账期和交付款方式是什么？**阶梯返利或满减政策**如何设计？”

3. **质量与售后**  
   - “到货后的**验收标准**（如大小、成熟度、瑕疵率）有哪些？”  
   - “出现临期、腐烂或品质不符时，**退货退款**流程是什么？”

4. **物流与履约**  
   - “每天**截单时间**和**配送时效**（从下单到店铺）是多少？”  
   - “是否支持分时段配送、紧急补货？**运费由谁承担**？”

5. **应急方案**  
   - “如果临时超额需求，**最快多少小时**能补货到店？”  
   - “合作期内连续2次断货，是否有**违约金或降低价格**等补偿机制？”

**提示**：建议将以上问题整理成书面清单，签约前要求供应商明确答复并写入合同。旺季前可先试合作1-2批，验证其响应速度。
