在超市采购水果时，供应商通常需要提供以下检测报告或进货证明，以确保产品符合食品安全和品质要求：

1. **产地证明或供货证明**：证明水果的来源地或供应商资质，如生产许可证、营业执照等。
2. **农产品质量安全检测报告**：包括农药残留、重金属、微生物等检测结果，符合国家标准（如GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》）。
3. **食用农产品合格证**：部分地区要求经营者自我开具或由监管部门出具的合格证明。
4. **检疫证明**（针对进口水果）：如海关签发的《入境货物检验检疫证明》，证明水果通过检验检疫、无有害生物。
5. **批次检测报告**：对于特定水果（如草莓、蓝莓）可能需提供新鲜度、成熟度、大小、外观等质量检测结果。
6. **运输和储存证明**：如冷链运输记录、温度监控报告等，确保水果在运输过程中未变质。

另外，根据超市自有采购标准，可能还会要求 **第三方检测机构出具的报告** 或 **产品追溯码**。建议在采购前与供应商确认具体要求，并保留相关文件以备核查。
