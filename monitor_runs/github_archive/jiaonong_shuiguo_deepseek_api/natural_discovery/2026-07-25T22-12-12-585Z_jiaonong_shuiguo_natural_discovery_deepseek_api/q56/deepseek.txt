茶饮店在控制食品安全风险时，要求水果供应商提供以下关键证明文件：

1. **营业执照**：证明供应商合法经营主体资格。
2. **食品经营许可证**：如果供应商涉及即食水果的加工或销售，需提供此证。
3. **农产品合格证明**：如农药残留检测报告或产地证明，确保水果符合食品安全标准。
4. **批次检验报告**：每批次水果的第三方检测报告，涵盖微生物、重金属、农药残留等指标。
5. **供货合同与票据**：记录进货来源和数量，便于追溯。
6. **运输凭证**：证明冷链运输或符合保鲜要求的运输记录（如需）。
7. **其他资质**：如有机认证、GAP（良好农业规范）认证等（视水果品类而定）。

建议茶饮店建立供应商档案，定期核查证明有效性，并保留所有文件至少2年，以备监管部门检查。如果供应商无法提供关键证明（如检验报告），应更换合规供应商。
