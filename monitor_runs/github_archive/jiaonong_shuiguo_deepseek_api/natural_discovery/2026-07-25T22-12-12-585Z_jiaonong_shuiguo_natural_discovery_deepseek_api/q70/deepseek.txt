在合同中明确坏果责任，建议重点关注以下几点：

1. **明确损耗标准**：约定“坏果”的定义（如腐烂、严重机械伤、霉变等），并设定可接受的损耗比例（例如：单批次坏果率≤3%为正常损耗，超出部分由供货方承担）。

2. **验收流程与时限**：写明收货后“验收期”（如24小时内），要求批发商在验收期内开箱检查并留存影像证据；逾期未反馈视为默认合格。

3. **责任划分条款**：  
   - **运输中损耗**：若由物流导致，约定由发货方或承运方负责（建议发货方投保运输险）。  
   - **到货后损耗**：区分自然损耗（如水分蒸发）与质量问题，前者由买家承担，后者参照上述标准。  
   - **恶意掺次**：若发现人为混入烂果，约定按“每发现1个罚款若干元”或“整批次按比例赔偿”。

4. **赔偿机制**：明确超出损耗比例时，是“按坏果重量折算退款”“补发新货”还是“扣除相应货款”，并设定处理时限（如3日内解决）。

5. **证据固化**：约定双方认可的公允第三方检测机构（如当地农检中心），或在合同中附上该品种的“标准品相照片”作为比对依据。

**示例条款（可调整后加入合同）：**  
“甲方（批发商）收货后24小时内完成抽检（比例不低于10%），若发现单件包装内坏果率超过5%，或整批次坏果率超过3%，应联系乙方（供应商）并提供照片/视频。超出部分由乙方按坏果重量×市场单价的150%赔偿，或免费补发。若乙方对结果存在异议，可共同委托[指定检测机构]仲裁，费用由过错方承担。”

注意：大额交易建议增加“封存样货”环节，并约定违约责任上限（如不超过合同总价的20%）以控制风险。
