建议**优先卖整果，同时提供按需去皮服务**，这样可以兼顾不同顾客需求。具体理由如下：

1. **整果优势**：  
   - 顾客可亲自检查菠萝新鲜度（如色泽、果眼、香味），减少对“可能被替换”的顾虑。  
   - 延长菠萝保存时间（未去皮可常温存放2-3天），适合想回家自己处理或分次食用的顾客。  
   - 减少店内损耗：提前去皮的菠萝若未及时售出，易褐变、出水，品质快速下降。

2. **去皮服务可作增值选项**：  
   - 提供现场按需去皮，注意保持操作卫生（戴手套、用专用工具），去皮后立即用保鲜膜包裹或装入盒中。  
   - 推荐面向：现场即食顾客、老年人、怕麻烦但想多吃水果的人群。

**操作建议**：  
- 店里摆放整果和“现切现卖”的菠萝盒（标明去皮时间，建议2小时内卖出）。  
- 对整果明码标价，去皮服务可免费或稍加价（如+1元，体现人工成本）。  
- 每日盘点：优先将库存中成熟度高的菠萝进行去皮促销，避免过度积压。

**风险提示**：  
- 若只卖去皮好的，顾客易因无法确认新鲜度而流失；单卖整果则会损失怕麻烦的客群。  
- 注意：顾客自行挑选时，避免用手按压果肉（易导致内部损坏），可提供专用夹子或由店员协助检查成熟度。

**总结**：主推整果 + 按需免费去皮是当前水果店较优的平衡方案，能满足不同客群诉求，控制损耗。
