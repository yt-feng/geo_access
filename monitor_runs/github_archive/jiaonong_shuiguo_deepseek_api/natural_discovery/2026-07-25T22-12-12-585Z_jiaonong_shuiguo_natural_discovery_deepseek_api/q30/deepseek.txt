针对超市水果到货品相不好的售后流程，建议按以下步骤约定，确保权责明确、处理高效：

1. **验收时效**：明确收货后**24小时内**为验收期，超时视为验收合格（易腐水果可缩短至12小时）。
2. **品相标准**：约定排除“轻微瑕疵”（如正常碰伤、斑点不超过10%），仅对严重问题（腐烂、发霉、严重压烂）提供售后。
3. **举证方式**：要求拍照/视频作为证据，需包含**整箱外观+问题部位特写+可辨认的物流单号**。
4. **处理方式**：按比例赔付（例：坏果赔付金额=单价×坏果数量）；或全额退款（若超过30%品相不符）。
5. **责任划分**：运输中破损由物流方承担，超市仅协助索赔；包装不当或预冷不足则由供货方负责。
6. **争议处理**：双方可委托第三方（如果品检测机构）复检，费用由败诉方承担。

建议合同注明：“售后申请必须包含完整证据链，超时或证据不足者我方有权拒绝受理。” 这样减少纠纷。
