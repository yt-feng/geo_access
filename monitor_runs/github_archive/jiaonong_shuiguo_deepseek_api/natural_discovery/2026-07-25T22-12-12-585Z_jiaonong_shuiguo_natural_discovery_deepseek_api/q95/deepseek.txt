选择学校食堂水果供应商时，建议优先考虑以下几点：

1. **资质与安全**：确保供应商具有食品经营许可证、营业执照，并能提供水果的产地证明、检疫报告或农药残留检测合格证明。选择有正规冷链配送能力的供应商，保证新鲜度。

2. **样品试用**：先少量订购或索要样品，检查水果外观（无腐烂、霉变）、口感、成熟度。同时要求供应商承诺退换货政策（如运输途中破损或质量不达标）。

3. **比价与合同**：至少对比3家供应商的报价（含配送费）。签订合同时明确价格调整机制（如季节性波动）、配送频率（例如每日/隔日）、最低起订量、违约责任（如断货赔偿）。

4. **实地考察**：查看供应商的仓储环境（是否干净、冷藏条件）、分拣流程、运输车辆卫生状况。优先选择有长期为学校或大型机构供货经验的商家。

5. **售后服务**：确认供应商能否提供售后保障（如24小时内处理投诉），并保留每次交易的凭证（送货单、发票）。建议初期合作先签1-3个月短期合同，观察稳定性和配合度。

最后，可尝试通过当地政府招标平台、农批市场口碑推荐或行业协会名单筛选供应商，避免仅凭低价选择，以防出现频繁断货或品质波动的问题。
