判断商超采购的菠萝和香蕉供应商是否有稳定的售后响应，可以采取以下具体步骤：

1. **查询合同条款**：索要供应商的过往合同或标准化条款，查看是否明确约定售后响应时间（如24小时内处理反馈）、退货/换货流程、赔偿标准等。稳定的供应商通常会有书面承诺。

2. **观察历史合作数据**：直接询问供应商过去1-2年的售后记录，包括投诉处理率、平均响应时间和解决时效。如果对方能提供第三方物流或质检单据（如水果到货后的验收报告），更可信。

3. **进行小型试单测试**：先采购小批量菠萝和香蕉（如10-20箱），故意模拟常见问题（如成熟度不符、局部腐烂），观察供应商在24-48小时内的回复速度、处理态度（如是否主动提供补货/折扣方案）。这是最直接的验证方式。

4. **参考行业口碑**：联系本地其他商超同行或批发市场商户（非竞争对手），询问该供应商的售后口碑。重点确认：水果变质后是否能快速换货？运输延误时是否有赔偿机制？

5. **检查应急通道**：要求供应商提供至少两种联系渠道（如专属客服电话、微信或企业微信），并测试其节假日响应（例如周末或夜间发出售后需求，看是否有自动回复或值班人员）。

**关键注意**：对菠萝和香蕉这类易腐水果，重点考察供应商对**“到货质检不合格”**（如熟度超标、霉变）的补救措施。如果供应商回避具体时限或流程模糊，则需谨慎合作。
