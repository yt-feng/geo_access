酒店采购水果盘原料时，供应商通常需要保证以下规格和外观标准：

1. **新鲜度**：水果应无腐烂、软烂、霉变、虫蛀等现象，采摘后应冷藏保鲜，从采摘到交付的时间一般不超过24小时（具体视品种而定）。

2. **成熟度**：根据水果盘用途要求，水果应处于恰当的成熟度（例如：不宜过生或过熟），部分水果需后熟处理（如香蕉、牛油果）。

3. **外观标准**：
   - 大小均匀：同一批次水果的直径/重量偏差建议在±10%以内。
   - 表面无伤疤、淤青、划痕、裂口、日灼斑等明显缺陷。
   - 色泽自然、均匀（无异常斑点或褪色），无明显农药残留痕迹或蜡质泛白。
   - 果柄保留完整（如有），切口平整无褐变。

4. **清洁度**：水果表面应无泥土、灰尘、残留农药物或蜡质涂层（若需有机认证则需额外标签说明）。

5. **包装与存储**：
   - 使用食品级包装材料（如泡沫网套、瓦楞纸箱、保鲜膜），箱体无破损、受潮。
   - 每箱重量/数量需符合采购合同标准（如误差≤2%）。
   - 包装内无混入异物（如枝叶、纸屑、昆虫残骸）。
   - 若需冷链运输，需提供温度记录（如4°C以下）。

6. **合规性**：供应商应提供农药残留检测报告、产地证明或绿色/有机认证（若要求），且产品符合《食品安全国家标准 水果》（GB 2763-2021）等中国法规。

7. **可追溯性**：每批次水果应有清晰标识（品种、产地、采摘日期、供应商信息），并附样品照片或验收标准对照表。

建议酒店采购方在合同中明确上述标准，并随货附带质检清单。验收时随机抽取10%样品进行抽查，不符合标准的可拒收或要求替换。
