采购菠萝时，判断熟度主要看以下几点，有助于减少损耗：

1. **外观颜色**：成熟菠萝呈金黄色或橙黄色，略带青绿说明还在后熟期。优先选**底部（果柄处）微黄、靠近叶子部分带些许青色**的，这样的菠萝耐储存，不会立刻过熟。

2. **按压硬度**：轻轻按压果身（避开果眼），**微软但有弹性**最佳。太硬说明不熟，存放后可能酸涩；太软或局部塌陷可能已过熟或内部变质。

3. **叶片状态**：拔一下叶子容易脱落，说明成熟度较高；如果叶子紧实不易拔动，则偏生。建议选**拔叶子稍有阻力但能轻易脱落**的。

4. **气味**：成熟菠萝散发**淡淡清香**。无气味说明偏生，有浓烈甜味或酒精味说明过熟，可能内部已烂。

5. **果型与重量**：选**匀称、圆润**的，畸形果可能发育不均。同样大小选**较重**的，水分更足。

**采购建议**：根据销售节奏，快销（1-2天内卖出）可进偏熟的，慢销（2天以上）进微青、硬实的。避免一次性购入全熟或全生货品，混合不同熟度更灵活应对销售。
