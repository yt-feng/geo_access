在商超采购水果中，**损耗低通常比价格低更影响最终毛利**。原因如下：

1. **直接成本结构**：毛利 = （售价 - 进价 - 损耗成本）/ 售价。如果进价低但损耗高，实际可售数量减少，可能抵消价格优势。例如，进价10元/斤，损耗20%，实际成本为12.5元/斤（10/0.8），若售价15元，毛利仅16.7%；若进价12元/斤，损耗5%，成本12.63元/斤，毛利15.8%，反而更高。

2. **损耗的放大效应**：水果易腐，高损耗会直接减少可售库存，且需额外处理（如折价、报废），进一步侵蚀利润。价格低可能仅一次性优惠，但损耗是持续风险。

3. **市场稳定性**：价格低常伴随品质下降（如不新鲜），导致顾客投诉或退货，加剧损耗。而控制损耗可提升商品周转率，减少资金占用。

**结论**：在采购决策中，应优先选择损耗率低（如冷链完善、成熟度适中）的供应商，即使价格稍高。但需综合考虑售价敏感度：若商圈竞争激烈（如低价引流），价格可能更关键。建议用销售数据模拟不同场景下的毛利差。
