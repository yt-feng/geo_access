针对社区团购旺季爆单，提前与水果供应商锁定库存，可以采取以下具体策略：

1. **签订预采购协议**：提前1-2个月与核心供应商签订框架协议，明确旺季期间的预估采购量（如每日XX吨）、品种、规格、价格浮动上限（如承诺不低于市场价XX%收购），并设定最低交付量。

2. **支付定金或保证金**：向供应商支付一笔不可退还的定金（如总货值的10%-20%），作为锁定库存的担保。双方约定若我方超额采购则优先供应，若供应商违约则双倍返还定金。

3. **分批次下单 + 滚动预测**：按周或3天为一个周期，根据预售数据和天气、节假日等因素滚动更新未来1-2周的采购量，并提前3-5天给供应商正式订单，确保其预留对应库存。

4. **建立分级供应商体系**：将供应商分为A级（核心，锁定70%库存）、B级（备用，锁定20%库存）、C级（应急，临时调配）。对A级供应商提供年度返点或更多订单倾斜。

5. **合作共建临时分拣仓**：在产地或中转地设置临时仓库，供应商提前将水果送到仓库，我方按需逐步提货，避免一次性囤积和运输延误。

6. **设定阶梯式奖惩条款**：在合同中明确：若供应商按时足量交付，给予额外奖励（如每吨补贴X元）；若延迟或缺量交付，按货值X%扣除违约金。

7. **共享消费者需求数据**：向供应商提供历史同期爆款品种、区域销量、复购率等数据，帮助其精准安排采摘和保鲜计划。

8. **提前锁定冷库及运输资源**：建议供应商预留冷库库容，并签订运输车队旺季包车协议，确保锁定的水果能及时出库。

**执行步骤**：
- 提前45天：梳理供应商名单，筛选出产能稳、质量高的前5-10家。
- 提前30天：与核心供应商开始谈判，签订预采购协议并支付定金。
- 提前15天：完成分仓选址，对供应商进行库存盘点。
- 旺季前7天：每日调度，确保所有锁定的库存已备好或已入临时仓。

注意：避免过度锁定单一供应商，保留20%左右的弹性供应渠道（如批发市场、产区经纪人），以防突发断供。
