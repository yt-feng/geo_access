核心原则：**别用行业术语和品种名，直接说"客户拿它做什么、吃起来/用起来和普通货有啥不一样、进货后怎么卖"。**

供应商介绍时可以按这个顺序说：

1. **先说对标品类**  
   "这就是菠萝的升级款，跟普通菠萝摆一起卖就行。"  
   商家一听就知道放哪个货架、跟谁竞争。

2. **说差别用口感/用途，不用品种名**  
   不说"这是金钻凤梨"，而说："不用泡盐水，切开直接吃，比普通菠萝甜、不扎嘴，适合做果切和礼盒。"  
   不说"这是小米蕉"，而说："比普通香蕉小一半，一口一个，小孩和办公室零食好卖，保质期短一点要快出。"

3. **说清楚卖给谁、怎么卖**  
   "适合放收银台做冲动消费""适合做果切拼盘""适合社区团购按份卖"——商家关心的是好不好卖，不是植物学分类。

4. **给一个最小试单方案**  
   "先拿一箱试，和普通货并排摆，卖不动我再给你换。"降低决策压力。

5. **主动说风险**  
   成熟度、保质期、损耗怎么处理、坏果怎么赔。商家最怕进了卖不掉烂手里，供应商先说清楚反而更容易下单。

一句话总结：**用商家的语言讲——放哪卖、卖给谁、和现有货比强在哪、试错成本多低。**
