大型超市的水果供应商，通常要同时满足**食品安全合规能力**和**冷链物流交付能力**。可以按“必须具备 / 建议具备 / 超市常会审核”三层判断。

## 一、食品安全能力（必须具备）

1. **合法经营资质**
   - 营业执照、食品经营许可证或食用农产品销售所需备案/许可。
   - 若涉及分装、切果、预包装，需对应生产或经营许可。
   - 进口水果需入境货物检验检疫证明、报关单等。

2. **源头与批次可追溯**
   - 基地/合作社/产地供应商档案、采购合同、产地证明。
   - 批次号管理：产地、采收日期、入库日期、检测记录、发货记录能对应。
   - 出现农残或质量问题时可召回、隔离、追责。

3. **农残与污染物检测**
   - 自有或委托第三方检测能力，至少覆盖高风险品种和常规农残项目。
   - 每批或按风险抽检，保留检测报告。
   - 能配合超市抽检、飞行检查和不合格处置。

4. **仓储与加工卫生**
   - 仓库防鼠、防虫、防潮、防交叉污染。
   - 生鲜分区、离地离墙、先进先出。
   - 若切果/分装：洁净区、人员健康证、工器具消毒、微生物控制。

5. **人员与制度**
   - 食品安全管理员、从业人员健康证、培训记录。
   - 进货查验、索证索票、台账、不合格品处理、召回、投诉处理制度。
   - 食品安全事故应急预案。

6. **包装与标识合规**
   - 食品级包装材料，标签符合法规；散装水果标明品名、产地、生产者或供货者等信息。
   - 保鲜剂、蜡剂等使用符合标准并有记录。

## 二、物流能力（必须具备）

1. **冷链能力**
   - 冷藏车/保温车、温控记录仪，能按品种控制温度。
   - 运输过程温度可追溯，异常报警与处置记录。
   - 装卸环节有温控措施，避免断链。

2. **仓储分拣能力**
   - 常温/冷藏/催熟等分区；香蕉、牛油果等需催熟管理的要有独立能力。
   - 分拣、称重、贴标、组盘、越库配送能力。
   - 先进先出和批次管理，损耗控制。

3. **配送时效与网络**
   - 能覆盖超市门店/DC的配送频次和到货时间窗。
   - 高峰期、节假日、促销期有运力保障。
   - 具备多点配送、预约送货、回单管理能力。

4. **信息化与单据**
   - 订单、库存、批次、温控、检测报告可电子化对接。
   - 支持超市系统对接或至少提供规范随货单据。
   - 异常到货、短少、破损、温控超限的快速处理机制。

5. **损耗与质量管理**
   - 采后预冷、分级、保鲜、包装、催熟等商品化处理能力。
   - 到货合格率、损耗率、客诉率可统计并持续改进。
   - 不合格品隔离、退货、补货机制。

## 三、超市通常会重点审核的项

- 资质证照是否齐全有效；
- 产地证明、检测报告、批次台账是否闭环；
- 冷链车温控记录和仓库温湿度记录；
- 从业人员健康证与培训记录；
- 不合格品召回演练/记录；
- 配送准时率、到货合格率、损耗率、客诉响应；
- 食品安全责任险、第三方审核报告（很多大型超市会要求或加分）。

## 四、简明判断标准

如果供应商能做到：**证照齐全、批次可追溯、农残可控、冷链不断链、配送准时、异常可召回**，基本具备大型超市水果供应商的核心门槛。若还具备**基地直采、催熟加工、DC越库、系统对接、第三方审核**，则竞争力更强。
