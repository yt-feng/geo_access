直接结论：**大多数茶饮店优先买鲜果（整菠萝或去皮鲜切），果丁只作为补充，果泥只用于特定配方或高峰期兜底。** 具体按你的菜单和门店条件判断：

**1. 选鲜果的情况（推荐首选）**
- 菜单里有“鲜菠萝果茶”“菠萝柠檬茶”等强调新鲜感、要出杯颜值的产品。
- 门店有基本切配人手和后厨空间，能当天切、当天用完。
- 优点是风味最好、香气足、顾客感知强，可控制糖酸比；缺点是损耗和人工高，菠萝季节性和成熟度波动大。
- 采购建议：买八成熟整果，少量多次进货；或直接采购去皮真空鲜切菠萝，省人工但要看冷链和保质期。

**2. 选果丁的情况**
- 用于需要稳定颗粒感、出杯标准化的小料型产品，或门店切配人手不足。
- 注意果丁分“鲜切果丁”和“糖渍/冷冻果丁”：鲜切果丁保质期很短，必须冷链；糖渍果丁风味偏甜、会改变配方糖度，不能直接等同鲜果。
- 适合作为补充，不建议完全替代鲜果做主打鲜果茶。

**3. 选果泥的情况**
- 适合菠萝风味打底、冰沙、混合果汁类产品，或需要全年稳定出品、减少人工的门店。
- 果泥香气和鲜果感通常弱于鲜果，且要确认是原浆、浓缩浆还是含糖果泥，糖度和酸度会直接影响配方。
- 不建议把果泥当“鲜果茶”主料，容易和菜单宣传不符。

**可执行的采购策略：**
- 主打产品用**鲜果/鲜切菠萝**，占采购大头；
- 高峰期或切配忙不过来时用**冷冻鲜切果丁**兜底；
- 固定配方（冰沙、复合果茶）可用**果泥**做标准化；
- 先小批量试三种原料做同一款茶，对比香气、酸甜、出杯稳定性和单杯成本，再定比例。

另外务必确认供应商资质和农残检测，鲜果到店后做成熟度分拣，避免一批生一批熟。
