可以从“买、收、存、用”四个环节控制，核心是别一次买太熟、别堆着闷、先熟先处理。

1. **采购标准**
   - 优先采购**七到八成熟**、果柄青绿、果身硬挺、无黑斑的香蕉。
   - 分批下单：按未来2—3天用量采购，避免一次囤5—7天量。
   - 与供应商约定**按成熟度分批配送**，不要同批全是黄熟蕉。

2. **验收与分流**
   - 收货时按成熟度分三档：青硬、微黄、已熟。
   - 青硬蕉放常温催熟；微黄蕉优先近期使用；已熟蕉当天或次日必须处理。
   - 有碰伤、裂口的单独挑出，先做香蕉奶昔、香蕉粥、香蕉面包等加工用途。

3. **存放方法**
   - 未熟蕉：常温、通风、避光，不要冷藏。
   - 已熟蕉：可冷藏延缓过熟，但表皮会变黑，不影响内部；也可去皮切段冷冻，用于奶昔、烘焙。
   - 不要整串堆压，悬挂或单层摆放，减少压伤。
   - 香蕉会释放乙烯，别和已熟水果密封混放；需要催熟时可与苹果同袋，但要及时检查。

4. **使用与预警**
   - 食堂设定“成熟度看板”：青、黄、熟、急用四区，贴日期标签。
   - 每日晨检，把最熟的香蕉调到当天水果或加工窗口。
   - 菜单联动：熟蕉优先做香蕉牛奶、香蕉燕麦粥、香蕉松饼等，不直接上桌的熟蕉转加工。
   - 设置库存阈值：超过2天用量就停止采购，先消化库存。

5. **采购量简单算法**
   - 按“日均用量×配送周期×0.8”下单，留20%安全余量，而不是按最大用量买。
   - 夏季或高温天再下调10%—20%。

最有效的做法是：**小批量、多频次采购 + 收货按成熟度分流 + 熟蕉当天转加工**。这样比单纯靠冷藏更能减少浪费。
