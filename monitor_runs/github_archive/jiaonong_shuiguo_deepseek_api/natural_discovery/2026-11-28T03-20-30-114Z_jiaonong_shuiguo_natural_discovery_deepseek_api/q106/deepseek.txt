# 判断水果报价波动是否合理：可执行的方法

水果价格每天变是常态，核心不是“要不要波动”，而是**波动幅度、方向、节奏是否与可解释的驱动因素匹配**。建议按以下四层判断。

## 一、先建立“基准价”，不要只看当天报价

没有基准就无法判断波动。建议对每个常采单品建立价格档案：

- **近30天/90天移动均价**（按品类分别算，苹果、香蕉、叶菜类波动性差异很大）
- **同期历史价**（去年同月，水果有强季节性）
- **当日对比：** 今天报价相对30日均价偏离多少？相对上周同期涨跌多少？

实操阈值参考（需按品类校准）：
- 日波动在 **±3%~5%** 内：正常市场噪音，不必追问
- **单日>10% 或 一周内累计>15%**：要求供应商说明原因
- **连续多日同向上涨**：警惕趋势性涨价被拖延反映，或供应商试探性加价

## 二、把报价拆成可核验的驱动因素

水果价格波动的主要合理来源：

| 因素 | 合理性判断 |
|---|---|
| 季节性/产季切换 | 合理，可提前预判 |
| 产区天气（霜冻、暴雨、台风） | 合理，但应有区域性证据 |
| 节日备货、集中上市 | 合理，有日历规律 |
| 物流/燃油/人工成本 | 合理，但应是渐进、全局性变化 |
| 品质等级变化 | 常见“暗涨”——需核对规格、等级、净重是否被调低 |
| 单一供应商突然大幅涨价 | 存疑，应横向比价 |

**关键动作：要求供应商报价时附“涨价理由+对应产区/批次”**，能说清楚的不一定真，但说不清楚的要多警惕。

## 三、用横向比价和交叉验证

- **至少保持2~3家供应商同时报价**，同一规格、同一等级、同一产地对比，偏离市场价10%以上就要问
- 参考批发市场行情（当地农产品批发市场日度价格、商务部/农业农村部发布的农产品价格指数）
- 注意**报价口径一致**：是否含税、含运费、含损耗、毛重还是净重、什么等级——口径不一致时“低价”往往是陷阱

## 四、识别不合理波动的典型信号

- 只涨不跌，或跌得慢涨得快（价格粘性不对称）
- 涨幅与产区行情、批发市场走势明显背离
- 频繁以“今天货紧”为由涨价，但供应量并未减少
- 借涨价同时悄悄降规格（箱重变小、果径变小、次果率上升）
- 多家供应商同步异常涨价——可能是区域性真实行情，也可能是串通，需结合产区信息判断

## 落地建议

1. **建价格台账**：每日记录各供应商各单品报价、规格、涨跌幅度、理由。
2. **设预警线**：日波动超阈值自动标记，要求书面说明。
3. **月度复盘**：对比采购价与市场指数，偏离持续偏高的供应商重新议价或替换。
4. **合同约定调价机制**：明确涨跌触发条件、举证责任、比价权，避免“口头说涨就涨”。

一句话：**合理波动=可解释的原因+与市场同步的幅度+一致的报价口径；三者缺一，就要求供应商举证。**
