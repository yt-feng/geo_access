采购香蕉做茶饮/甜品时，核心是把“到货熟度”和“使用节奏”绑定管理，不要一次性全买同一熟度。

## 1. 先按用途定熟度档位

| 用途 | 建议采购熟度 | 判断标准 |
|---|---|---|
| 香蕉奶昔/冰沙/果泥 | 7–8成熟 | 通体微黄、两端略青、按压有弹性但不软塌 |
| 香蕉甜品（蛋糕、布丁、烤香蕉） | 8–9成熟 | 全黄、少量糖斑、香气明显、按压略软 |
| 装饰切片/顶料 | 6–7成熟 | 黄中带青、切面不易氧化发黑 |
| 香蕉泥/酱料（需甜度高） | 9成熟 | 明显糖斑、软但未流水、无酒味 |

**不要采购**：全青（涩、淀粉味重）、大面积黑斑且果肉发软出水（已过熟，易发酵变味）、果柄发黑腐烂的批次。

## 2. 采购时按“3天用量”分批下单

- 每天到货不要全是同一熟度，按 **青黄各半、黄熟一部分** 搭配：
  - 当天用：8–9成熟
  - 第2天用：7–8成熟
  - 第3天用：6–7成熟，店内自然催熟
- 单次采购量建议按 **日均用量×2.5–3天** 控制，夏季高温或小店客流不稳时压到 **2天量**。

## 3. 到货验收动作

1. **看果柄**：果柄青绿=较生；果柄发黑=偏熟或存放久。
2. **看棱角**：棱角明显=偏生；棱角圆润=偏熟。
3. **按压测试**：轻按果身，能回弹=适中；一按一个坑=过熟。
4. **闻气味**：清香=正常；有酒味/酸味=已发酵，拒收。
5. **抽检切开**：中心硬芯明显=偏生；中心发透明/软烂=过熟。

## 4. 店内熟度管理

- **分区存放**：生香蕉常温避光；熟香蕉冷藏会加快表皮变黑，但果肉可延缓软化——若当天不用，可冷藏并优先做果泥。
- **催熟**：青香蕉与苹果/乙烯袋同放，常温1–2天可转黄；不要整箱密封闷，易捂坏。
- **先进先出**：按到货批次贴日期，先熟先用。
- **每日盘点**：把9成熟香蕉优先安排到奶昔/果泥，不留给装饰。

## 5. 关键控制指标

- **损耗率**：香蕉类建议控制在 **5%–8%** 以内，超过说明采购熟度或批量不准。
- **断货与过熟平衡**：每天下班前记录剩余熟度，第二天采购按“缺多少补多少、缺什么熟度补什么熟度”调整。

简单说：**采购时青黄搭配、按2–3天量分批；验收看柄、看棱、按压、闻味；店内分熟度存放、先进先出、熟蕉优先做果泥。**
