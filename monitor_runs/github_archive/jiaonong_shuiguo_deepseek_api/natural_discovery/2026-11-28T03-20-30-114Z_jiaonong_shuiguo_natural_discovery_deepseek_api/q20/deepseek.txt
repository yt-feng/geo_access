社区超市做每日水果配送，筛选供应商时建议按下面顺序看，先排硬门槛，再看稳定性和成本。

**一、先看硬性履约条件**
1. **能否真正做到每日配**：问清配送频次、下单截止时间、到店时间窗口；是否节假日照常，雨雪天、旺季是否降频。
2. **配送半径和仓库位置**：离店多远、是否有本地分拣仓；距离过远，早配和补货都容易出问题。
3. **起送量和最小起订**：社区超市单店量不大，要确认每单品最小起订件数/重量，是否能混装，不够量是否加运费。
4. **配送费用和结算**：运费是否含在价里、退换货怎么算；账期是现结、周结还是月结，押金要求。

**二、再看商品和品质稳定性**
5. **品类覆盖和季节性替换**：常卖果品是否齐全，能不能按季节换品；是否支持小批量多品种。
6. **分级标准**：按斤还是按箱、果径/等级/成熟度标准是否明确，避免“看货一个样、到货一个样”。
7. **损耗和退换机制**：到货坏果、压伤、熟度不合适怎么处理，是否支持当场验收拒收、次日补货或折价。
8. **农残检测和票据**：能否提供产地证明、检测报告或进货凭证，生鲜经营被抽检时用得上。

**三、看供应稳定性**
9. **货源组织能力**：是自有基地、产地直采还是批发市场倒手；倒手多的，价格和品质波动大。
10. **旺季/节日保供能力**：春节、中秋、台风天等能不能保量，是否有备选货源。
11. **历史服务对象**：是否服务过社区店、生鲜店、便利店，可要求看合作案例或试配。

**四、看成本和合作条款**
12. **报价是否含税含运**：要求给单品报价表，比较同一等级果品的到店价，不只看批发价。
13. **价格调整机制**：随行就市还是锁价，调价提前多久通知。
14. **试配期**：建议先签2—4周试配，按到货合格率、缺货率、准时率、损耗率考核，再决定长期合作。

**实操建议**
- 至少找2—3家同时试配，不要一开始只押一家。
- 建一个简单验收表：到店时间、品种数量、坏果率、缺货项、退换处理，连续记两周就能看出谁靠谱。
- 优先选“本地仓+每日固定线路+明确退换规则”的供应商，价格低但配送不稳的，后期损耗和缺货成本更高。
