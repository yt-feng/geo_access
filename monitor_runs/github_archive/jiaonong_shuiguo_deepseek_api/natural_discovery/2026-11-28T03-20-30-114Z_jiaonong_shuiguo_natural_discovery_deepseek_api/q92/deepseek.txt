小店卖水果，关键不是“买得全”，而是“只买能快速周转的”。建议按下面思路控制品类和损耗：

1. **先定品类结构，不求全**
   - 只做3类：高频刚需（苹果、香蕉、橙子）、即时消费（小番茄、葡萄、切果）、引流特价（当季最便宜1—2款）。
   - 总SKU控制在8—12个，单品最多2个规格。不要同时上多种苹果、多种葡萄。
   - 先只保留“周销量稳定、客单价低、耐放或周转快”的品；连续7天卖不动的直接砍。

2. **按销量倒推采购量**
   - 用近7天日均销量×1.2—1.5倍作为次日订货量，不要按“看起来满”来补货。
   - 香蕉、葡萄、草莓、切果这类高损耗品，按半天到1天量订货；苹果、橙子、梨可2—3天订一次。
   - 每天固定两次补货窗口（早、晚），避免一天多次小批量进货增加挑拣损耗。

3. **采购端控损耗**
   - 优先选耐储运、标准化程度高的单品；叶菜类、熟透软果少做或不做。
   - 进货时按“卖相分级”采购：便利店适合中小果、统货，不必追求大果礼盒。
   - 和供应商谈“少量高频、可退换残次”的条件；不能退换的品就压缩采购量。
   - 到店立即分拣：完好品上架，轻微瑕疵品做切果或特价，严重破损当场退回或报损记录。

4. **门店端控损耗**
   - 陈列量控制在当天销量的60%—70%，少量多次上架，避免堆头压伤。
   - 高损耗品放冷柜或阴凉处；香蕉、芒果等不要低温冷藏。
   - 每天固定时段做“临期特价”，比如下午4点后对软果、切果打折，比等到坏掉再扔划算。
   - 切果只做1—2款，现切现卖，不提前大量备货。

5. **用数据做淘汰**
   - 每天记录：进货量、销量、报损量、剩余量。
   - 连续3天报损率超过10%的单品，减量或停售；连续7天销量排名末位的单品直接淘汰。
   - 每周复盘一次，只保留“销量前8名+1个季节引流品”。

6. **简单执行标准**
   - 单品日采购量不超过2天销量；
   - 叶菜/软果类不超过1天销量；
   - 报损率目标控制在5%—8%以内，超过就砍品类或减订货量；
   - 新品一次只试1—2个，试销3天，卖不动立即下架。

核心原则：**品类少、批量小、频次高、快淘汰**。便利店水果赚的是周转钱，不是品类齐全的钱。
