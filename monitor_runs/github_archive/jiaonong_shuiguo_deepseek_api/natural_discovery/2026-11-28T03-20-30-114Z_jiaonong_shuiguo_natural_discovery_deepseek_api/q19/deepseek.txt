优先关注**甜度和切果损耗**，其次才是大小和外观。更准确地说：  
- **如果按整果卖**：甜度、外观、大小都影响成交和复购。  
- **如果按切果/果切卖**：切果损耗是第一优先级，甜度第二，外观和大小次之。  
- **超市经营综合排序**：**切果损耗 ≥ 甜度 > 外观 > 大小**。

具体判断：

1. **切果损耗优先**
   - 菠萝有冠芽、果皮、果眼和两端，切果出成率直接影响毛利。
   - 同样进货价下，出成率差几个点，利润差很明显。
   - 要关注：单果可切净重、坏心/黑心率、过熟率、果眼深度、去皮去眼人工成本。
   - 建议按“**可售净果成本 = 进货价 ÷ 出成率**”算真实成本，而不是只看整果进价。

2. **甜度是复购核心**
   - 菠萝酸、淡、无味会直接砸口碑，尤其是果切和试吃。
   - 要关注品种、成熟度、产季、批次差异。
   - 可做简单分级：试吃甜度、糖酸比、香气、软硬。甜度不稳定的批次不要主推果切。

3. **外观影响成交，但别过度溢价**
   - 外观好能提升陈列效果和整果成交，但超市更应看“外观缺陷是否影响出成和口感”。
   - 轻微外观瑕疵但甜度好、损耗低的货，适合做果切或促销，不必一刀切拒收。

4. **大小看场景**
   - 整果销售：中等偏大、形状端正更好卖。
   - 果切销售：大小不是核心，稳定出成率和切块规格更重要。
   - 过大果可能单价高、动销慢；过小果出成低、人工占比高。

**可执行建议：**
- 整果为主：**甜度 > 外观 > 大小 > 切果损耗**，但仍要抽测损耗。
- 果切为主：**切果损耗 > 甜度 > 大小 > 外观**。
- 采购验收至少记录：批次甜度抽测、坏心率、出成率、外观次品率、单果均重。
- 用“**净果成本 + 损耗率 + 动销速度**”做进货决策，不要只凭外观或大小压价。

一句话：**超市卖菠萝，先算切果损耗，再保甜度；外观决定好不好卖，大小决定怎么卖。**
