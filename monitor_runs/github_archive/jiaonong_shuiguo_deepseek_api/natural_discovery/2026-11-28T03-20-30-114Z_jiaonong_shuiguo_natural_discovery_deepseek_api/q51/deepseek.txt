要固定，但不要只固定“产地”，更要固定“品种+规格+成熟度+供应批次+验收标准”。水果风味波动通常不是单一产地造成的，而是品种、成熟度、季节、运输和储存共同导致。

建议做法：

1. **固定供应来源，但保留备选**
   - 主供应商固定产地或产区，锁定品种和规格。
   - 同时准备1—2个备选产区，避免断供时临时换料导致口味突变。

2. **固定“批次管理”比固定“产地”更关键**
   - 要求供应商按批次供货，记录采摘/加工日期、品种、糖酸度、成熟度。
   - 同一款产品尽量使用同一成熟度区间的原料，例如固定“七成熟”或“全熟冷冻果”。

3. **建立验收指标**
   - 感官：颜色、香气、酸甜比、纤维感、异味。
   - 理化：糖度、酸度、出汁率、可溶性固形物。
   - 到货抽检并留样，批次不合格就拒收或降级使用。

4. **按产品分层策略**
   - 招牌产品：固定品种、产区、批次标准，优先用冷冻果浆/浓缩汁稳定风味。
   - 季节限定：允许风味自然波动，但要在菜单上明确“当季风味”。
   - 普通产品：可接受多产区，但必须通过拼配或糖酸调整保持稳定。

5. **和供应商签风味标准**
   - 不要只写“某地水果”，要写清品种、等级、糖酸度范围、成熟度、冷冻/冷藏方式、允许波动范围。
   - 约定批次留样和异常处理机制。

结论：**要固定供应体系和批次标准，而不是死守某一个产地。** 产地固定能降低风险，但如果没有品种、成熟度和验收标准，仍然会波动；反过来，有批次标准和拼配能力，即使换产区也能保持稳定。
