会增加，而且香蕉和菠萝的损耗风险对起订量特别敏感。判断要点如下：

1. **香蕉**
   - 呼吸跃变型水果，催熟/后熟快，高起订量意味着到货后集中成熟。
   - 若销售速度跟不上，容易过熟、发黑、压伤，损耗率上升明显。
   - 尤其夏季、运输时间长或冷链不稳定时，风险更大。

2. **菠萝**
   - 相对耐储，但整箱起订量高会带来堆压、通风不足、黑心病/腐烂风险。
   - 成熟度偏高时保质期短，集中到货也会增加滞销损耗。

**可执行判断**：  
- 用“日均销量 × 补货周期 × 安全系数”估算合理起订量，别只看单价折扣。  
- 香蕉建议小批量、多频次补货；菠萝可适当放宽，但要控制成熟度和库存周转天数。  
- 若起订量超过 **7天预估销量**，香蕉损耗风险通常明显偏高；菠萝超过 **10—14天销量**也要谨慎。  
- 谈判时可要求供应商拆分规格、混装、分批到货，或把高起订量换成价格折让而非一次性压货。

结论：**会，香蕉尤其明显；高起订量应用“周转天数+成熟度+冷链”三项一起评估，不宜只按采购单价决策。**
