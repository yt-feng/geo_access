判断香蕉供应商能否全年稳定供货，不能只看“有没有货”，要查产地结构、硬件、订单历史和风险预案。可按下面顺序做：

1. **先看产地是否跨区域**
   - 香蕉怕寒、怕台风，单一产区很难全年稳定。
   - 优先选在海南、云南、广西、广东及东南亚（菲律宾、越南、老挝、柬埔寨等）有**多产区调配能力**的供应商。
   - 要求供应商说明：1—12月各月主要从哪些产区拿货，哪些月份是淡季/风险月，如何补位。
   - 如果供应商只依赖一个县或一个基地，全年稳定性要打问号。

2. **看冷链和催熟能力**
   - 香蕉是呼吸跃变型水果，稳定供货不只是“有香蕉”，还要能按超市销售节奏交付合适成熟度。
   - 重点核实：产地预冷、冷链运输、催熟库容量、日处理量、温湿度记录。
   - 问清楚：旺季/淡季分别能日供多少吨，临时加单最快多久响应，断货时有没有替代仓。

3. **查真实供货历史**
   - 不要只看宣传册。要求提供近12个月供货记录：每月供货量、断供次数、到货合格率、损耗率、客诉率。
   - 可向其现有客户侧面核实，尤其是同类型连锁超市。
   - 看其订单波动承受能力：春节、台风季、寒潮期是否出现过明显断供。

4. **做小规模试单和压力测试**
   - 先签短期试供，连续供4—8周，覆盖一个风险时段。
   - 测试三件事：常规订单准时率、临时加单响应、质量波动时补货速度。
   - 试单期间按批次记录到货成熟度、青果/黄果比例、机械伤、损耗。

5. **看合同里的稳定性条款**
   - 明确年度/月度最低供货量、缺货违约责任、替代产区方案、价格调整机制。
   - 要求供应商提供备用产地或备用加工厂，不能只写“尽力供货”。
   - 对台风、寒潮、节假日等风险期，约定提前备货天数和库存责任。

6. **看资金和上游控制力**
   - 有自有基地或长期包园合同、能预付产地货款的供应商更稳。
   - 如果供应商主要靠临时市场调货，价格低但全年稳定性通常弱。
   - 可查其采购合同、基地合作协议、冷链车辆和催熟库租赁/自有证明。

**快速判断结论：**
- 能给出“分月产区表+近12个月供货记录+备用产区+冷链催熟能力+试单表现”的，才值得进入年度供应商候选。
- 只会说“我们常年有货”、拿不出分月产地和断供记录的，不宜作为全年主供应商，最多做补充渠道。

建议采购做法：**主供应商+备用供应商双源采购**，主供占60%—70%，备用占30%—40%，每季度复核断供率和到货合格率。
