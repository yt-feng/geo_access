更适合线上卖的是**切配菠萝（鲜切）**，其次是**冷冻菠萝**，**整果菠萝更多是引流和走量，不建议作为线上主推核心品**。

可以按这个顺序判断：

1. **切配/鲜切菠萝：最适合线上主推**
   - 线上用户买生鲜更看重“省事、即食、规格稳定”，鲜切最匹配。
   - 客单价和毛利通常高于整果，适合做水果杯、早餐、沙拉、下午茶场景。
   - 但损耗、冷链、微生物和保质期要求最高，必须解决：冷链配送、短保标识、切配后氧化/出水、临期折价。
   - 适合平台：即时零售、社区团购次日自提、会员店线上、便利店线上。
   - 判断条件：如果你有本地切配能力+冷链履约，优先做鲜切；没有就不要硬上。

2. **冷冻菠萝原料：适合做差异化线上品，不适合作为大众鲜果主推**
   - 优势是保质期长、损耗低、标准化强，适合B端餐饮、烘焙、饮品店，也适合C端做冰沙/果茶原料。
   - 线上C端认知弱，用户容易把它当“鲜果替代品”比较，价格敏感；需要明确场景包装，比如“冰沙原料”“烘焙用”“饮品店同款”。
   - 更适合：抖音/拼多多做场景化内容电商、B端批发线上化、私域团购。
   - 判断条件：有稳定冷冻供应链和场景化内容能力可做；否则容易变成低价库存品。

3. **整果菠萝：适合引流和产地心智，不适合做高毛利主推**
   - 优势是认知强、价格透明、履约相对简单，适合做爆款引流、产地直发、箱装团购。
   - 劣势是线上比价严重、毛利薄、成熟度不可控、售后争议多（坏果、酸、黑心、熟度不一致）。
   - 更适合：产地直发箱装、社区团购自提、平台大促引流。
   - 判断条件：有产地直采和分级能力可做；没有分级能力，售后会吃掉利润。

**采购建议：**
- 如果是创业型生鲜电商：先用**整果做引流**，用**鲜切做利润和复购**，冷冻作为补充SKU测试。
- 如果冷链弱：优先**整果+冷冻**，不要做鲜切。
- 如果有中央厨房/门店切配：优先**鲜切**，整果做价格锚点。
- 如果面向B端饮品/烘焙：优先**冷冻原料**，鲜切和整果作为补充。

**一句话结论：**线上主推选**鲜切菠萝**，整果负责引流，冷冻负责长保和B端/场景化补充；三者不是替代关系，而是按你的冷链和切配能力组合卖。
