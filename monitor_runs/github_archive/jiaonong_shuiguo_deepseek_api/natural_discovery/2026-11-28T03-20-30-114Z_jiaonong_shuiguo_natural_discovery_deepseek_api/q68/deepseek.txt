判断供应商能不能按时到车，核心不是听承诺，而是看“车、货、人、款”四个环节有没有可验证的节点。建议按下面做：

1. **先看车源是否锁定**
   - 问清：是自有车、长期合作车，还是临时调车。
   - 要求提供车牌号、司机电话、车辆当前位置、预计装车时间。
   - 临时调车风险最高，若供应商说不清车牌和装车点，基本要打问号。

2. **看装车计划是否具体**
   - 不要只听“明天到”，要确认：哪天几点装车、装哪一车、装车地点、装车负责人。
   - 要求装车前发空车到场照片或视频，装到一半发进度，装完发过磅单/装车单。
   - 没有具体装车时间的“按时”，等于没有承诺。

3. **看历史履约记录**
   - 优先选合作过、过去准时率高的供应商。
   - 新供应商先小批量试单，不要一上来压大单。
   - 问同行、市场档口、司机，侧面核实其是否常拖车、常换车。

4. **看合同和违约约束**
   - 书面写清到车时间、装车时间、迟到处理、空车/坏车替代方案。
   - 约定超时扣款或补偿，比如每延迟几小时扣多少、耽误上市怎么赔。
   - 付款节点跟装车/到车挂钩，不要提前全款。

5. **保留备用方案**
   - 同一批次至少准备一个备选供应商或备选车源。
   - 旺季、天气异常、节假日前后，提前1—2天锁车。
   - 到车当天早上再确认司机位置，发现异常立即启动备选。

6. **几个危险信号**
   - 只说“放心”“肯定到”，但给不出车牌、司机、装车时间。
   - 反复换车、换司机、换装车点。
   - 报价明显低于市场，又要求大额预付。
   - 装车前不愿发视频、不愿给过磅单。

**可执行结论：** 对供应商按“车牌锁定+装车时间+过程照片/视频+违约条款+备用车源”五项打分，五项齐全可正常下单；缺车牌和装车时间的，只给小单或不合作。到车当天早上必须再核一次司机位置，不能等。
