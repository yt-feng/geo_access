连锁商超招标水果长期供应商，评分标准建议“先设门槛、再评能力、最后比价格”，并把长期供应最怕的断供、品质波动、食安风险前置。可按100分制设置，权重供参考，需按品类（叶菜类水果/浆果/瓜果/进口果）和门店规模调整。

**一、资格门槛（不计分，不合格淘汰）**
- 营业执照、食品经营/生产许可、种植基地或合作社证明、产地证明
- 近2年无重大食品安全处罚、无严重失信记录
- 具备冷链运输能力、固定分拣场所、农残检测能力或第三方检测报告
- 能满足最低日供货量、覆盖招标区域门店、接受账期和退换货条款
- 缴纳履约保证金、投保食品安全责任险（如有）

**二、评分项建议（100分）**

1. **供应保障能力 25分**
   - 自有/签约基地面积、年产能、单品可稳定供应量（8分）
   - 多产地布局、季节替代方案、灾害天气应急预案（7分）
   - 冷链仓储与运输车辆、配送频次、门店覆盖半径（6分）
   - 缺货补货响应时限、断供应急承诺（4分）

2. **质量与食品安全 25分**
   - 果品等级标准、糖度/大小/色泽/新鲜度等可量化指标（7分）
   - 农残检测制度、检测频次、可追溯体系（7分）
   - 采后预冷、分拣包装、冷链温控记录（5分）
   - 退货率、损耗率承诺及质量问题赔付方案（4分）
   - 食品安全责任险、召回机制（2分）

3. **价格与成本 20分**
   - 报价合理性，建议用“同期市场批发价下浮率”或“单品报价+调价机制”而非单纯最低价（10分）
   - 价格调整机制是否透明，是否挂钩公开市场价格指数（5分）
   - 账期、运费、包装费、损耗承担等综合成本（5分）
   - 注意：价格分不宜过高，避免低价中标后品质下滑。

4. **履约与服务 15分**
   - 订单满足率、准时到货率承诺（5分）
   - 退换货、临期/次品处理、门店投诉响应时限（4分）
   - 节假日、促销高峰期保供方案（3分）
   - 对接团队、驻场或专属客服配置（3分）

5. **企业资质与业绩 10分**
   - 同类商超/连锁渠道供货经验、合作年限（4分）
   - 近3年类似项目业绩及客户评价（3分）
   - 财务稳健性、履约保证金、保险配置（3分）

6. **可持续与合规 5分**
   - 种植规范、农药使用管理、绿色/有机认证（3分）
   - 包装环保、产地社会责任合规（2分）

**三、关键设置建议**
- **价格分用“合理低价”而非“最低价”**：可设最高限价和成本合理性审查，异常低价要求说明，防止恶意低价。
- **设置样品和试供环节**：投标样品盲评占质量分一部分；中标前安排2—4周试供，试供不合格可取消资格。
- **合同挂钩考核**：把到货率、退货率、农残合格率、投诉率写入合同，按月扣罚或末位淘汰，评分只是入口。
- **分品类设权重**：叶菜/浆果损耗高，质量与冷链权重上调；大宗瓜果价格权重可略高；进口果强化溯源和通关资质。
- **防止围标**：要求提供基地证明、检测报告、业绩合同关键页，必要时实地考察基地和分拣中心。

总体建议权重：供应保障25、质量食安25、价格20、履约服务15、资质业绩10、可持续合规5。若商超对食安风险极敏感，可把质量食安提到30分，价格降到15—18分。
