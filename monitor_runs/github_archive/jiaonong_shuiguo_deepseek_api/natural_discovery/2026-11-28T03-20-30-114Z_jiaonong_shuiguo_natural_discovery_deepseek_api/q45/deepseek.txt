连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是“价格怎么变、质量怎么判、损耗谁承担、账期怎么扣、违约怎么算”这几类条款。下面按风险从高到低列出最容易出问题的条款和可执行建议。

**1. 价格与调价机制**
- 坑：只写年度框架价，没写随行就市调价规则；或供应商单方调价、超市单方压价，旺季断供、淡季压库存。
- 建议：约定“基准价+调价触发条件+调价周期+书面确认流程”。例如以批发市场均价或约定指数为参考，周/月调价；单方不得调价；价格异常时双方有重新协商权，协商不成有退出或替代供应安排。

**2. 质量标准与验收**
- 坑：只写“新鲜、无腐烂”这类模糊标准，验收时扯皮；等级、规格、糖度、农残、包装、冷链温度没量化。
- 建议：附《质量验收标准》作为合同附件，明确品种、等级、单果规格、色泽、糖度/酸度、允许缺陷比例、农残检测要求、冷链温度区间、抽检比例和不合格处理方式。验收以双方签字确认的抽样结果为准，避免口头验收。

**3. 损耗与退换货**
- 坑：运输损耗、仓储损耗、门店损耗混在一起；到货不合格谁承担运费和销毁费用没写；退换货时限模糊。
- 建议：分环节约定损耗承担：装车前后、运输途中、到店验收后分别归谁；明确不合格品拒收、换货、折价、销毁的时限和费用承担；约定退换货响应时间，比如到货后几小时内提出、供应商几小时内补货。

**4. 订单与供应保障**
- 坑：年度合同只给框架量，没有最低采购量或最高供应量；旺季供应商优先供高价客户，超市断货；超市随意取消订单，供应商索赔。
- 建议：约定年度预计量、月度滚动订单、最低/最高采购量、订单确认时限、缺货违约责任和替代供应权。对生鲜可设“计划量±浮动比例”，超幅部分双方协商。

**5. 账期、结算与扣款**
- 坑：账期过长且无明确起算点；质量扣款、促销扣款、损耗扣款没有上限和依据；对账差异处理没时限。
- 建议：明确对账日、开票日、付款日及起算点；约定扣款必须有书面依据和供应商确认，设置扣款上限或争议处理机制；对账差异在约定工作日内解决，逾期视为确认的条款要谨慎。

**6. 违约责任与赔偿**
- 坑：违约责任只约束供应商，超市违约无责任；违约金过高或过低；间接损失、商誉损失是否赔偿没写。
- 建议：双方对等设置违约责任；违约金与可证明损失挂钩，避免约定明显过高被调整；明确缺货、质量事故、食品安全事件的赔偿范围和上限；食品安全问题可约定召回、检测、赔偿和解除合同权。

**7. 食品安全与合规**
- 坑：只要求供应商“保证合格”，没写检测报告、追溯、证照更新、事故处理流程；出事后责任全推给供应商。
- 建议：要求供应商提供营业执照、食品经营/生产许可、批次检测报告、产地证明；约定农残超标、致病菌等问题的召回、下架、检测费用和赔偿责任；明确供应商证照失效时的通知和替换义务。

**8. 独家/排他与非竞争**
- 坑：约定独家供应但没约定供货保障和价格约束；或限制供应商给周边竞争对手供货，可能引发反垄断和履约争议。
- 建议：谨慎签排他条款；如签，必须配套最低供货量、价格约束、违约解除权，并评估是否触及反垄断风险。

**9. 合同期限与退出**
- 坑：年度合同自动续约、退出条件模糊；旺季前供应商解约或超市突然换供应商，库存和门店缺货损失没人担。
- 建议：明确起止日、续约需书面确认；约定提前通知期、过渡期供货义务、库存处理方式和解除后的结算规则。

**10. 不可抗力与市场异常**
- 坑：把价格波动、天气、交通管制都写成不可抗力，供应商借此免责断供。
- 建议：不可抗力范围写具体，排除一般市场价格波动；约定异常情况下的通知、证明、替代供应和减损义务。

**最优先处理的四件事：**  
1）把质量验收标准做成量化附件；  
2）写清价格调整和订单确认流程；  
3）分环节约定损耗与退换货责任；  
4）对账、扣款、付款起算点写死。  
这四项没写清，后面几乎必然扯皮。合同签署前建议让采购、财务、门店运营和法务各审一遍，重点核对附件与正文是否一致。
