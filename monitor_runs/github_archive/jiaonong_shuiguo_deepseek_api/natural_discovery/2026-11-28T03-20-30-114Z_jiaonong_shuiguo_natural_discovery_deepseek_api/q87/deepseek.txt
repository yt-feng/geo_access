旺季锁库存的核心是“把不确定的需求变成可执行的合同与节奏”，而不是临时打电话要货。可以按下面几步做：

1. **先做需求预测，再谈锁量**
   - 按过去4周+去年同期+今年增长趋势，拆到“单品×周×仓/团长区域”。
   - 给供应商一个“保底量+弹性上限”，例如：保底80%，弹性上浮20%，超出部分提前3天确认。
   - 水果损耗大，不要一次性锁死所有量，锁“核心爆品+稳定款”，叶菜/浆果类留弹性。

2. **签短期锁量协议，写清关键条款**
   - 锁量不等于锁价，明确：锁量比例、价格调整机制（随行就市/周度报价）、品质标准（糖度、规格、瑕疵率）、到货时间窗、违约与补货责任。
   - 约定“优先供货权”：旺季期间同规格同价优先给你。
   - 约定“缺货替代方案”：主供断货时，供应商需提前多久通知、能否调同级货。

3. **用定金/预付款换优先权**
   - 对核心供应商可付10%–20%预付款锁产能，但要求对应“保底供货量+违约退款”。
   - 预付款只给合作稳定、履约记录好的供应商，避免旺季前换新供应商。

4. **分散供应，不要单点依赖**
   - 每个爆品至少2家供应商：主供70%，备供30%。
   - 备供平时也给小单养着，旺季才能顶上。
   - 跨产区布局，避免单一产地天气/物流风险。

5. **提前锁定物流与到货节奏**
   - 和供应商确认“采摘—分拣—装车—到仓”时间，水果按日到货，不要一次压太多库存。
   - 旺季前2周做一次压力测试：让供应商按峰值量80%发一次货，看分拣、包装、冷链是否跟得上。

6. **建立日报机制**
   - 每天同步：销量、库存、在途、供应商可用量。
   - 当某单品日销量连续2天超预测20%，立即触发弹性补货。
   - 对供应商按“到货准时率、品质合格率、缺货次数”打分，旺季结束复盘。

7. **合同外留一手**
   - 提前谈好2–3家备用供应商，哪怕价格略高。
   - 对特别紧俏的单品，可接受“锁量不锁价”，但设价格上限。
   - 不要把所有预付款押在一个供应商身上。

一句话：**用“保底+弹性”的协议锁量，用预付款换优先权，用双供应商和日报机制兜底。** 旺季最怕的不是价格涨，而是断货和品质崩。
