和水果供应商谈酒店早餐合作，核心是把“稳定”拆成可考核的条款，而不是只谈价格。重点注意以下几类：

**1. 先明确需求再谈**
- 列出早餐常用水果清单、每日/每周用量、可接受替代品（如某品种缺货时用什么替换）。
- 明确规格标准：单果重量区间、成熟度、外观瑕疵允许范围、是否需要预切/去皮。
- 明确送货时间窗口（如每天6:00前到货）和验收地点。

**2. 稳定性要写进合同**
- 供货频次、最低供货量、缺货提前通知时限（如提前24小时）。
- 缺货处理：替代方案、补货时限、违约扣款或赔偿。
- 价格机制：固定价还是随行就市；调价需提前通知并设上限；季节性品种单独定价。
- 账期与结算方式，以及质量不达标时的退换货规则。

**3. 质量与食品安全**
- 要求供应商提供营业执照、食品经营许可、检测报告或产地证明。
- 明确农残、霉变、异物等问题的责任和退换货流程。
- 到货验收标准写清楚：谁验收、按什么标准拒收、拒收后如何补货。

**4. 供应能力要核实**
- 问清货源是自营基地、批发市场还是多级调货，后者稳定性通常更差。
- 要求提供类似客户案例或试供期（如先试供2–4周）。
- 评估其冷链运输能力，尤其是夏季和远距离配送。

**5. 合同细节**
- 设试供期和考核指标（到货准时率、合格率、缺货次数）。
- 约定独家/非独家、最低采购承诺是否必要。
- 明确不可抗力、提前解约条件、违约责任。
- 保留备用供应商，避免单一依赖。

**6. 谈判策略**
- 不要只压价，优先谈“稳定供应+质量兜底”的条款。
- 用试供期和月度考核换取价格或服务让步。
- 把口头承诺全部落到书面，尤其是缺货替代和赔偿。

一句话：价格可以谈，但**规格、频次、缺货替代、验收标准、违约赔偿**这五项必须白纸黑字，否则“稳定供应”无法执行。
