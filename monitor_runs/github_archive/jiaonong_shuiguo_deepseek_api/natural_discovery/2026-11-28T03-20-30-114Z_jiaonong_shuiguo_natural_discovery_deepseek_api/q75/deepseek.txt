第一次合作、小批量试单的核心目标不是“赚一笔”，而是**用最低成本验证供应商的真实能力**。建议按下面这套设计来做。

## 一、先定试单要验证什么

试单要验证 5 件事，别只盯价格：
1. **品质稳定性**：同一批货里大小、成熟度、瑕疵率是否一致。
2. **规格真实度**：承诺的等级、克重、箱规是否对得上。
3. **损耗与耐运输性**：到货后烂果、压伤、失水比例。
4. **交付可靠性**：能否按约定时间、数量、包装发货。
5. **售后态度**：出问题是否认账、补货或赔付是否爽快。

## 二、试单规模怎么定

原则：**小到不伤筋动骨，大到能暴露问题。**

- 单品试单量控制在**正常单次采购量的 10%～20%**，或按“**1～2 个托盘/整车零担的最小起订量**”来定。
- 金额上建议单次试单总货值控制在**你能承受全损的范围内**（例如不超过单店/单渠道 3～5 天销售额）。
- **不要只试一个单品**：选 2～3 个代表性单品，一个走量款、一个高毛利款、一个易损耗款，能快速看出供应商的真实水平。
- 分批到货：条件允许时同一供应商**分 2 次、间隔 3～7 天各发一小批**，验证其稳定性，而不是只看一次“精心准备”的样品。

## 三、试单前必须谈清楚的条款

1. **规格书面化**：品种、产地、等级、单果克重区间、箱规、净重、成熟度、包装方式，全部写进订单或聊天记录确认。
2. **验收标准**：明确允许的瑕疵率/烂果率（例如到货烂果≤3%，超出部分按比例扣款或补货）。
3. **价格与费用**：是否含运费、装卸费、损耗谁承担，报价是到岸价还是产地价。
4. **结算方式**：首单建议**货到验收后付款**或**小比例定金+尾款验收付**，避免全款预付。
5. **售后时限**：到货后多少小时内可提异议，补货/赔付怎么执行。

## 四、到货验收怎么做

- **到货即拍**：开箱、称重、抽检全程留视频和照片。
- **抽样比例**：每批至少抽 3～5 箱，记录单果重量、烂果数、压伤数、成熟度。
- **称净重**：核对箱规和净重是否短斤少两。
- **记录到货时间**：从发货到到货的时长和途中温控情况。
- **48 小时内出结论**：品质、损耗、规格三项打分，决定是否进入第二批或终止。

## 五、试单后的判断标准

可以继续合作的信号：
- 规格符合率 ≥95%，烂果率在约定范围内；
- 第二批品质与第一批接近；
- 出问题时响应快、愿意补货或扣款。

应谨慎或换供应商的信号：
- 靠“混装次果”凑数；
- 规格靠口头承诺、拒绝书面确认；
- 售后推诿、把损耗全推给运输；
- 第二批明显降质。

## 六、一个可执行的试单模板

> 首单：选 2～3 个单品，每品 1～2 个最小起订单位，货值控制在可承受全损范围内；书面确认规格、验收标准、到岸价和售后；货到验收后付尾款；7 天内视情况补第二批小单验证稳定性；两批都合格再逐步放量到正常采购量的 30%～50%。

**一句话总结：试单要小、要书面、要抽检、要分两次，重点验证“品质稳定+售后靠谱”，而不是只看首单价格。**
