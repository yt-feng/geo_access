# 生鲜批发合同中的坏果责任条款：怎么写才靠得住

先明确一个底线：**"损耗高"这类模糊表述不能写进责任条款**，否则双方各说各话。条款要落到三个可量化的东西上——**验收标准、责任分界点、赔付计算方式**。

---

## 一、先定"坏果"的判定标准

不要只写"坏果由供货方负责"，要写清楚什么算坏果：

- 列举判定情形：霉变、腐烂、软烂流汁、机械压伤、冻伤、虫蛀、裂口渗出等；
- 明确**抽检方法**：如"按每批次随机抽检不少于X箱/件，抽检样本中坏果重量占比≥X%即判定为不合格批次"；
- 区分"**可接受瑕疵**"（如表皮轻微擦伤不影响食用）与"**不合格**"，避免收货方把所有外观瑕疵都算坏果。

## 二、把责任分界点写在"交付"上

这是最容易扯皮的地方。建议写法：

> 货物自供方交付承运人/运抵指定地点并由需方签收时起，风险转移至需方；但因供方包装不当、货物交付前自身品质缺陷、或冷链断链造成的腐烂变质，责任仍由供方承担。

关键点：
- **运输环节的温控责任归属**必须写明（谁找的物流、谁负责冷链、温度记录由谁保存）；
- 如果是**需方自提或需方指定物流**，因运输导致的损耗原则上需方承担，但供方应保证交付时货物符合约定标准；
- 建议约定**到货后X小时内提出异议**有效（生鲜行业常见4—24小时，越短越利于取证），逾期视为验收合格。

## 三、赔付方式要可计算、可执行

三种常见写法，按谈判地位选：

1. **按比例扣款**："不合格批次按坏果重量占比对应货款的1.5倍/2倍扣减"（倍数体现惩罚性）；
2. **按件补货**："坏果率超过X%的批次，供方按不合格件数等量补发，运费由供方承担"；
3. **整批退换**："坏果率超过X%（如10%）的，需方有权整批退货或要求换货，由此产生的运费及需方合理损失由供方承担。"

建议同时约定**赔付上限**（如不超过该批次货款的200%），否则供方风险不可控，也可能谈不下来。

## 四、证据条款（最容易被忽略）

> 需方提出质量异议时，应提供到货时货物状态的照片/视频、抽检记录及温度记录；供方有权在X小时内到场复检，逾期未复检视为认可需方记录。

这条对双方都有保护作用——供货方最怕的是"事后才说坏了"，有了时限和证据要求，扯皮空间会小很多。

## 五、实操建议

- **先试一单再定条款**：用小批量试运行，实测各环节损耗率，把真实数据写进合格标准，比拍脑袋定10%靠谱；
- **包装要求单列**：箱体规格、内衬、冰袋/保温措施、码放层数，这些直接决定损耗，属于供货方义务；
- **明确不可抗力与免责**：极端天气导致的运输延误等，约定通知义务和协商机制，但**不建议把"正常运输损耗"整体免责**，那等于条款白写。

---

一句话总结：**坏果责任条款 = 判定标准（怎么算坏）+ 风险分界（何时转移）+ 赔付算法（怎么赔）+ 证据规则（怎么举证）**，四块缺一，真出问题时都很难执行。建议把这几条交给对方作为谈判稿，重点争"判定标准"和"异议时限"，这两项定了，其余都好谈。
