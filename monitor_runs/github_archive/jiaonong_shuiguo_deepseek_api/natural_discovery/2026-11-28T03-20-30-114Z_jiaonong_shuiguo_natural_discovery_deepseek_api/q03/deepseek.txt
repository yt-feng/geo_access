# 夫妻店第一次找水果供货商：试单建议

## 一、先定试单原则

第一次合作别谈“长期低价”，核心是**验证三件事**：货稳不稳、损耗谁承担、结账规则清不清。建议每家供应商只试 **1～2 个单品**，金额控制在 **300～800 元**，不要一次进全品类。

## 二、选品试单策略

| 品类 | 适合试单吗 | 原因与试法 |
|---|---|---|
| **香蕉** | 最适合先试 | 周转快、损耗敏感，能试出催熟度和到货成熟状态；先试 1～2 箱 |
| **橙子** | 适合 | 耐放、损耗低，能试出规格是否统一、是否有烂果；先试 1 箱/1 件 |
| **苹果** | 适合但别多 | 耐放，重点看大小分级和碰伤率；先试 1 箱中果或小果 |
| **叶菜/草莓/葡萄** | 不建议首单 | 损耗高、售后争议大，等供应商稳定后再碰 |

试单时**同一单品只找 1 家**，不同单品可分别找 2～3 家横向比，避免被一家绑定。

## 三、试单前必须问清的 6 件事

1. **起送量和价格**：多少件起送？是否含运费？到店价还是市场自提价？
2. **到货时间**：几点到店？能不能避开早高峰？迟到怎么处理？
3. **规格标准**：香蕉几成熟到店？苹果几号果？橙子单果重量范围？
4. **损耗与售后**：烂果、碰伤、短斤少两怎么赔？拍照后多久处理？是否下次补货抵扣？
5. **结账方式**：现结、周结还是月结？有没有押金或账期门槛？
6. **退换货**：卖不动或品质不达标能否退？退货运费谁出？

## 四、到货验收怎么做

- **当场开箱抽检**：每箱抽上中下三层，看底层有没有烂果、碰伤。
- **称重核对**：抽查 1～2 箱净重，防“带箱称”和短斤。
- **拍照留证**：到货状态、烂果、箱标都拍，当天发给供应商确认。
- **记录成熟度**：香蕉到店几成熟、几天能卖完，直接决定下次订货量。

## 五、试单后的判断标准

连续试 **2～3 次**，用这几条判断是否长期合作：

- 到货品质**波动小**，不是这次好下次差；
- 售后**响应快**，不推诿；
- 价格不是最低但**算上损耗后毛利能接受**；
- 送货时间稳定，不影响开门营业。

任何一条明显不达标，就换下一家，不要因为“便宜一点”将就。

## 六、给夫妻店的小提醒

- 首单**别压货**，香蕉按 1～2 天销量订，苹果橙子按 3～5 天订。
- 优先找**本地批发市场有固定档口**的供应商，比流动送货的更容易追责。
- 第一次合作尽量**现结或小额周结**，别一上来就押大额账期。
- 把每次试单的到货价、损耗率、售后结果记在本子上，两三家比完再定主供。

**一句话总结：先小量、单品类、现结试 2～3 次，重点验品质稳定性和售后，别被低价和账期话术带跑。**
