建议先把“资料清单”和“验收动作”一起定，别只收几张纸。可向供应商要以下资料，并按可核验性分级：

**必须提前索取**
1. **供货主体资质**：营业执照、食品经营/生产相关许可；若是合作社或种植基地，提供基地/合作社证明及供货关系说明。
2. **批次检测报告**：与拟供货批次对应的农残检测报告，重点看检测项目是否覆盖常见高风险农药、检测机构资质（CMA/CNAS）、报告日期、样品名称和批次可追溯性。不要接受“一年一张通用报告”替代批次报告。
3. **承诺书/质量保证协议**：明确农残超标责任、退换货、赔偿和召回配合义务。
4. **产地与批次信息**：产地证明或供货证明、采摘/包装日期、批次号，便于抽检不合格时追溯。

**建议索取**
5. **种植环节记录**：农药采购和使用记录、安全间隔期执行记录；有条件的要基地自检记录。
6. **合格供应商评价资料**：以往抽检结果、第三方审核报告、快检记录。
7. **运输与贮存记录**：冷链或常温运输温湿度记录，避免把贮藏问题混同农残问题。

**到货时同步做**
- 按批次留存样品和送货单，核对报告批次与实物批次一致；
- 用农残快检做入仓筛查，快检阳性或报告缺失的批次先隔离，不直接上架；
- 在合同中写明：供应商须随货提供批次报告，超市有权抽检，超标即拒收并追责。

判断标准很简单：**报告能对应到这批货、检测机构可查、责任能落到合同里**，才算资料齐全；只有资质复印件和口头保证，不够。
