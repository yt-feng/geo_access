不要只凭口头承诺，建议按“证据→小单→合同”三步核实。

1. **先要可验证的配送证据**
   - 要求提供最近3个月的实际配送记录：订单城市/区县、到货时效、是否冷链、签收异常。
   - 让对方明确：是自有物流、长期合作承运商，还是临时找货拉拉/快递；不同模式覆盖和温控差别很大。
   - 要求给出全国覆盖清单：哪些省份/城市可次日达、哪些只能隔日、哪些偏远地区不送或加价。
   - 水果重点问冷链：干线冷藏车、城市配送保温箱/冰袋、到货温度记录、破损/腐损赔付标准。

2. **做小批量试单**
   - 选采购方实际要覆盖的2—3个代表性城市，尤其一个偏远或非核心城市，下小单实测。
   - 记录：下单到发货时间、物流单号可查性、到货时效、包装完好率、果温/新鲜度、异常处理速度。
   - 不要只测总部所在城市，那最容易“看起来能送”。

3. **交叉核验**
   - 查企业工商信息、经营范围、是否有道路运输/食品经营相关资质。
   - 要求提供承运商名称和合作证明，必要时直接联系承运商确认该线路。
   - 向对方现有客户要2—3个可回访案例，重点问旺季、节假日、偏远地区表现。

4. **把承诺写进合同**
   - 明确覆盖区域、时效标准、冷链要求、损耗率上限、超时/腐损赔付、偏远地区加价规则。
   - 约定试单不达标可终止或调整价格。
   - 保留物流轨迹、温控记录、签收照片作为验收依据。

**判断标准：** 能提供近3个月真实轨迹+覆盖清单+冷链方案，且小单在非核心城市也达标，才算实际覆盖能力可信；只给“全国都能送”口头承诺的，按未核实处理。
