更适合家庭的组合思路：**少用“每样都放一点”的散拼，改成“主果+配果”的家庭分享装**。苹果、橙子耐放又大众，香蕉、菠萝负责丰富口感和香味，但香蕉、菠萝不耐放，比例不宜高。

推荐3种可执行组合：

1. **日常家庭实惠装（最稳）**
   - 苹果 40% + 橙子 35% + 香蕉 15% + 菠萝 10%
   - 适合3—5口之家，价格容易控制，苹果橙子耐放，香蕉菠萝两天内吃掉。
   - 礼盒定位：家庭日常水果、周末分享。

2. **老人小孩兼顾装（更好卖）**
   - 苹果 35% + 橙子 30% + 香蕉 25% + 菠萝 10%
   - 香蕉软甜、橙子好剥，适合有老人小孩的家庭；但香蕉比例别超过30%，否则到货后容易发黑。
   - 礼盒里香蕉建议单独装袋，避免压伤其他水果。

3. **节日/走亲访友家庭装（更好看）**
   - 苹果 40% + 橙子 30% + 菠萝 20% + 香蕉 10%
   - 菠萝整只或切半带网套更有“礼盒感”，苹果橙子打底显饱满；香蕉只做点缀，降低损耗。
   - 适合春节、中秋、探亲场景。

**不建议的组合：**
- 香蕉超过30%：家庭一次吃不完，容易坏，售后多。
- 菠萝超过25%：占体积、处理麻烦，不是所有家庭都会削。
- 四种水果平均各25%：看起来丰富，实际不耐放、成本也不好控。

**包装和定价建议：**
- 苹果、橙子放底层和四周，香蕉放上层单独袋装，菠萝竖放或单独隔开。
- 家庭装建议做 **5斤装和8斤装** 两个规格，5斤走日常复购，8斤走节日送礼。
- 宣传语突出“耐放的主果+当天吃的香蕉菠萝”，并注明香蕉建议2—3天内食用、菠萝尽快切开，减少客诉。

如果只选一个最稳方案：**苹果40%+橙子35%+香蕉15%+菠萝10%**，适合大多数家庭团购。
