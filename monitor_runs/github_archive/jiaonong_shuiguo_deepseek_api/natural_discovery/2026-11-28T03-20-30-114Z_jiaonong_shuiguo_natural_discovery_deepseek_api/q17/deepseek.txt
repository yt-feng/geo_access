# 社区超市水果的鲜度与库存控制

社区超市水果的核心矛盾是：**销量小、品类多、损耗快**。控制思路可以概括为“少进、快转、动态定价、按数据订货”四条。

## 一、订货：少量多次，按销量定

- **按日均销量订货，不按“感觉”订。** 记录每个单品过去7天的日均销量，订货量控制在日均销量的1.2～1.5倍（周末可上浮到1.5～2倍）。
- **叶菜类、浆果类（草莓、蓝莓、葡萄）最怕压货**，宁可少进、卖完再补，也不追求“货架满”。
- **耐储类（苹果、橙子、梨、土豆）可适当多备**，作为客流和毛利的基本盘。
- **新品类先小批量试销**，观察3～5天动销再决定是否加大订货。
- 和批发商谈**小批量、高频次配送**（比如隔天送、甚至每天送少量），用配送频次换库存周转。

## 二、陈列与鲜度管理

- **先进先出**：新货放后面/下层，旧货放前面，每天开门前翻一遍货。
- **分级处理**：按品相分“正常售卖 / 打折区 / 处理区”，不要等烂了才动。
- **控温控湿**：叶菜保湿、热带水果（香蕉、芒果）避免低温冷藏，冷藏柜温度每天检查。
- **少摆勤补**：货架陈列量控制在半天到一天的销量，避免长时间暴露、被翻拣损伤。

## 三、动态定价，及时出清

- 设定**分级降价规则**：比如当天未售完的鲜果，闭店前2小时打8折，次日早市打6折，再卖不掉转处理或做果切/果汁。
- **打折要果断**：水果损耗是“指数级”的，今天舍不得降5毛，明天可能全损。
- 设一个**临期/品相不佳专区**，集中打折，减少正价区的视觉损耗。

## 四、用数据复盘

- 每天记录：**进货量、销量、损耗量、损耗金额**。
- 每周复盘哪些单品**周转慢、损耗高**，下次减量或直接砍掉。
- 关注**动销率**（售出/进货），连续两周动销差的品类就淘汰。
- 算出每个品类的**损耗率红线**（比如叶菜不超过8%，浆果不超过10%），超线就调整订货策略。

## 五、几个实用小招

- **预售/团购**：对易损耗单品做小区群预售，按单进货，几乎零库存。
- **果切和果汁**：把品相下降但没坏的水果加工出售，减少直接报损。
- **和周边餐饮/水果摊合作**：处理品低价批量走掉，别全砸在自己手里。
- **订货看天气**：连续雨天客流降，订货要下调；节假日前可适度备货。

**一句话原则：水果库存的目标不是“货架好看”，而是“当天进、尽快卖、卖不完及时降价出清”。** 把订货量压到日均销量的1.2～1.5倍，配合先进先出和分级降价，压货和损耗就能明显降下来。
