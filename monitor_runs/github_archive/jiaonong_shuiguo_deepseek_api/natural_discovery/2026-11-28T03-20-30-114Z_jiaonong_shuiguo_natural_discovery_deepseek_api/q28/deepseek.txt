建议先从小范围试销的**菠萝**开始，其次苹果，最后香蕉。判断依据是“进口稳定性”和“超市运营难度”，不是单纯看销量。

**优先级建议**

1. **首选：菠萝（尤其金菠萝/凤梨类）**
   - 进口货源相对集中，品种和规格容易标准化，适合做差异化。
   - 单价和毛利空间通常比香蕉、普通苹果更好，能测试门店对进口水果的接受度。
   - 风险是损耗和成熟度管理，但可通过小批量、短周期补货控制。
   - 适合先做1—2个SKU试销，观察2—4周动销和损耗。

2. **次选：苹果**
   - 供应链最稳、耐储存、损耗低，适合作为“稳定进口”的基础品类。
   - 但进口苹果与国产苹果竞争激烈，消费者价格敏感，差异化不如菠萝明显。
   - 如果超市目前水果品类偏基础、客群价格敏感，可先上进口苹果作为低风险补充。

3. **最后：香蕉**
   - 香蕉是高频刚需，但进口香蕉与国产/区域供应链竞争充分，价格透明、毛利薄。
   - 成熟度、冷链和损耗管理要求高，一旦动销不畅容易集中损耗。
   - 不适合作为“引入稳定进口水果”的第一步，更适合在已有稳定客流和冷链条件后补充。

**可执行试销方案**
- 首批只选**菠萝1—2个SKU**，小批量进货，按周补货。
- 同步设一个进口苹果小堆头作对照，观察客单价、复购和损耗。
- 连续观察4周：动销率、损耗率、毛利率、顾客询问/复购。
- 若菠萝损耗可控且动销达标，再扩SKU；若不行，转用苹果做稳定基本盘，香蕉暂缓。

**判断口诀**：先试“差异化强、可控小批量”的菠萝；要稳基本盘选苹果；香蕉等冷链和客流成熟后再上。
