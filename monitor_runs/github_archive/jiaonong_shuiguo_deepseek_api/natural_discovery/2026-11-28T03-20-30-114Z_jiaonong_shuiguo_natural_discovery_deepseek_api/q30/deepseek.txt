# 超市水果到货品相不好的售后流程约定建议

核心思路：**把“品相不好”这个模糊说法变成可量化、可举证、有时限的验收标准**，否则售后必然扯皮。建议在采购合同或到货验收单中约定以下条款：

## 一、先明确“品相不好”的判定标准

不能只写“品相不好可退换”，要写具体：

- **量化指标**：如腐烂/霉变果比例、机械损伤（压伤、裂口）比例、果径规格偏差、成熟度（过生/过熟）、色泽均匀度等，按品类分别设定。
- **抽样规则**：约定按批次随机抽检比例（如每批抽 5% 或每车抽 N 箱），抽检不合格率超过阈值（如 5% 或 10%）即整批可主张退换或折价。
- **参照物**：以合同附件中的样品照片/封样为准，避免“我觉得不好看”式争议。

## 二、约定到货验收时限与举证方式

- **验收窗口**：到货后 X 小时内（如 4 小时/当日）完成验收并书面提出异议，逾期视为验收合格——这条对超市有利，也倒逼自己及时验货。
- **举证要求**：开箱拍照/录像，保留带批次号、到货时间的照片，必要时双方共同取样封存。
- **异议形式**：书面（验收单批注、邮件、微信工作群）提出，口头不算。

## 三、约定处理方式（分级）

按问题严重程度分层，避免一刀切：

1. **整批拒收**：腐烂率/损伤率超阈值，或与样品严重不符 → 退货，运费由供应商承担。
2. **折价接收**：轻微品相问题（如外观瑕疵但不影响食用）→ 按约定折扣率（如 8 折/9 折）结算，或扣减对应比例货款。
3. **换货补货**：部分不合格 → 供应商在 X 小时内补足合格货，逾期按缺货处理。

## 四、约定责任与时限

- **响应时限**：供应商收到异议后 X 小时内（如 24 小时）确认并给出处理方案，逾期视为认可超市的处置意见。
- **费用归属**：退换货运费、损耗、二次分拣人工由责任方承担；因品相问题导致无法销售的部分不计入结算。
- **结算挂钩**：约定“验收合格单”作为付款前提，或预留质量保证金（如货款的 5%–10%），售后处理完毕再结清。

## 五、留好兜底条款

- 明确“品相标准以本合同附件为准，附件未列明的，按行业通行的可销售标准执行”。
- 约定争议解决方式（协商→第三方检测/行业协会调解→诉讼或仲裁）。
- 生鲜易腐，建议约定**退货货物就地处理**（如折价转销、销毁并拍照留证），避免来回运输扩大损失。

## 落地建议

最实用的做法是：**做一张《到货验收单》**，正面列品类、批次、数量、抽检比例、不合格率、判定结论（合格/折价/退货），背面附品相标准照片和抽样规则，双方签字。这样售后流程就固化在单据里，不依赖口头约定。

如果你告诉我具体品类（如叶菜、浆果、柑橘）和采购模式（可退换的经销还是买断），我可以帮你把阈值和条款写得更具体。
