建议以“整果为主、切果为辅”，但先做一个两周的小规模对照测试再定，不要直接二选一。

**判断依据**

1. **整果更适合作为引流和主销品**
   - 菠萝整果有价格感，顾客容易冲动购买，适合堆头、端架、门口促销。
   - 损耗相对可控：表皮外观差一点还能打折处理，切果一旦氧化、出水、变色就直接报损。
   - 采购和门店操作简单，不需要额外加工人力和包装成本。
   - 适合家庭采购和促销场景。

2. **切果更适合做增量，不适合做主力**
   - 切果解决“不会削、嫌麻烦、想即食”的需求，能提高客单价和毛利。
   - 但依赖加工人力、保鲜条件、包装和动销速度；当天卖不完损耗高。
   - 适合写字楼、社区年轻客群、水果区收银口或即食场景强的门店。

**可执行建议**

- **先做两周AB测试**：选2—3家代表性门店，整果正常陈列；切果只在其中一半门店上架，每天记录销量、毛利、报损、加工工时。
- **切果SKU要少**：先做1—2个规格，比如小盒即食、家庭装，不要一开始铺很多。
- **整果做价格锚点**：整果促销价拉客流，切果按份卖，体现便利溢价。
- **切果严格限时**：按门店动销定加工量，上午、下午分两批切，闭店前折价清货，避免过夜。
- **看三个指标再决定**：切果日销量是否稳定、报损率是否低于毛利增量、加工人力是否挤占其他工作。

**结论**

大多数商超门店应“整果主销、切果试销”。如果门店年轻客群多、即食需求强、水果加工能力强，可提高切果占比；如果社区家庭客群为主、人力紧张，整果优先。最终用两周数据决定，不要凭感觉全面切换。
