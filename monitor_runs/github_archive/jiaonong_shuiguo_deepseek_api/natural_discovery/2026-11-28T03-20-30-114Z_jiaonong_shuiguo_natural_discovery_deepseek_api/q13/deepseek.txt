小水果店做小区团购，供应商至少要支持这几类服务，建议你按“能不能落地”逐项确认：

1. **小批量、多频次配送**
   - 是否支持每天/隔天送，最低起送量多少。
   - 能否按团购节奏分拣到单品、按份打包。
   - 临时加单、减单的截止时间和处理规则。

2. **稳定供货与品质分级**
   - 同一单品能否稳定供应，缺货时有没有替代方案。
   - 是否支持按规格分级，比如大小、甜度、净重、坏果率。
   - 到货验收标准、坏果/损耗赔付规则要写清楚。

3. **团购包装与分拣支持**
   - 能否按“每份/每袋/每盒”预包装，贴团购标签。
   - 是否支持混装套餐、按小区订单分筐分袋。
   - 包装耗材费用谁承担，能否代贴标签。

4. **价格与账期**
   - 团购价、阶梯价、活动价是否支持。
   - 是否支持先货后结、周结或月结，押金/账期条件。
   - 价格保护：团购期间降价或供应商调价怎么处理。

5. **售后与损耗兜底**
   - 坏果、少重、漏发怎么赔，赔付时限和凭证要求。
   - 是否支持补发、退款或下次抵扣。
   - 生鲜损耗率超过约定比例时如何处理。

6. **冷链与时效保障**
   - 易坏水果是否冷链配送，夏季/节假日能否保障。
   - 到店时间是否固定，迟到影响团购交付怎么处理。
   - 是否支持直接配送到小区自提点。

7. **商品与营销支持**
   - 能否提供团购单品素材：图片、规格、卖点、建议零售价。
   - 是否支持试吃样品、爆品推荐、节日礼盒。
   - 能否配合做预售、锁单、限量活动。

8. **订单与数据对接**
   - 能否接收微信/表格/小程序订单汇总。
   - 是否提供每日报价单、库存表、对账单。
   - 退换货和结算数据能否清晰可查。

9. **售后响应**
   - 是否有固定对接人，响应时间多长。
   - 早上到货发现问题能否当天处理。
   - 节假日和爆单期是否有应急联系人。

10. **合规与票据**
   - 能否提供营业执照、食品经营/生产相关资质。
   - 是否可开票，票据类型和税率。
   - 送货单、验收单、赔付记录是否齐全。

**最需要先谈死的 5 件事：**最低起送量和配送频次、坏果赔付标准、团购包装分拣谁做、账期和押金、缺货/迟到的处理规则。建议先小批量试合作 1—2 周，用真实团购单测配送、损耗和售后，再签长期条件。
