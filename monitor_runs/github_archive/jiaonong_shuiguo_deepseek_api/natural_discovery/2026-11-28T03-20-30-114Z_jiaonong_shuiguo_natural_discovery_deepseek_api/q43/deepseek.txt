# 连锁门店水果供应商仓配覆盖评估方法

评估跨城市水果供应商的仓配覆盖，核心是回答一个问题：**供应商能不能在水果保鲜窗口内，把合格品按门店需要的频次和批量送到每一家店，且总成本可控。** 建议按下面五层依次评估。

## 1. 先明确自身需求口径（评估基准）

- **门店分级**：按销量、距离、温控条件分A/B/C级，不同级别可接受不同的配送时效和频次。
- **SKU分级**：叶菜/浆果等易损短保品 vs 苹果/柑橘等耐储品，保鲜窗口差异大，覆盖要求不同。
- **时效要求**：从采摘/分拣到门店上架的允许小时数，这直接决定"覆盖半径"。
- **批量与频次**：单店起送量、每周配送次数、能否拼车。

## 2. 评估供应商仓网结构

要求供应商提供（并可抽验）：
- **仓源清单**：产地仓、区域中心仓、城市前置仓各自的地址、面积、温区（冷藏/气调/常温）、日吞吐能力。
- **覆盖地图**：每个仓的配送半径和辐射门店清单，按实际行驶时间算，而非直线距离。
- **跨城链路**：产地到区域仓的干线运输方式与时长，区域仓到门店的支线方式与频次。
- **温控能力**：冷链车/保温箱数量、温控记录方式、断链预案。

## 3. 计算关键覆盖指标

| 指标 | 含义 | 判断标准 |
|---|---|---|
| 门店覆盖率 | 在承诺时效内可送达的门店占比 | 核心城市应接近100% |
| 平均/最长履约时长 | 下单到到店的时长分布 | 最长时长须小于该品类保鲜窗口 |
| 配送频次达成率 | 实际频次/承诺频次 | 低于90%需预警 |
| 单店起送量与拼车率 | 小门店能否经济配送 | 拼车率低则小门店成本高 |
| 缺货/损耗率 | 覆盖不足的直接体现 | 分品类设阈值 |
| 单位配送成本 | 元/店/次或元/公斤 | 按城市和门店级别对比 |

## 4. 做压力与边界测试

- **旺季/极端天气**：节假日、台风暴雨时仓配是否仍达时效。
- **新店扩张**：新增城市或门店时，是就近仓覆盖还是要新设仓，切换周期多长。
- **单点故障**：某仓停摆时有无备用仓和改道方案。
- **品质抽检**：到店果品新鲜度、破损率是否与承诺一致（覆盖好但品质差等于无效覆盖）。

## 5. 落到商务与合同条款

- 把**覆盖率、时效、频次、损耗率**写成可量化的SLA和考核条款。
- 明确**覆盖不足的补偿**（缺货赔付、临时调货费用归属）。
- 约定**仓网变更告知义务**，避免供应商悄悄撤仓导致覆盖缩水。
- 对多供应商可采用**分区/分品类组合**，用主供+备份供覆盖不同城市，降低单点依赖。

## 快速判断口诀

> 先定保鲜窗口 → 再看仓到店的**实际行驶时效** → 核对承诺频次与起送量 → 验温控与应急 → 最后用损耗率和单位成本验证"覆盖是否真的有效"。

如果供应商只能提供仓源清单却给不出**按门店粒度的时效分布和损耗数据**，基本可判断其覆盖能力未经真实验证，应要求试点城市试跑1–2个月再全面铺开。
