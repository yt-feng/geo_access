先把方向说清楚：批发商想绑定稳定大客户，账期和额度不是“给不给”的问题，而是“用规则换确定性”。建议按下面顺序谈。

**一、先定谈判框架：账期换量、额度换信息**
- 明确告诉对方：账期和额度可以给，但对应条件是**年度采购量/月均采购量承诺、结算准时率、订单提前期、品类集中度**。
- 不要一上来报账期数字，先问对方：现在从谁家拿货、账期多少、最痛的点是什么（缺货、品质不稳、价格波动、资金周转）。
- 你的筹码不是“便宜”，而是**稳定供应+品质一致+按需分拣配送**，这些对水果大客户比账期更值钱。

**二、账期怎么谈：阶梯式，不做一刀切**
建议给三档，让对方自己选：
1. **现结/周结**：价格最优或优先锁货；
2. **15天账期**：月采购额达到约定门槛，首月可试；
3. **30天账期**：只给合作满3个月、准时率达标、有担保或押金的核心客户。

关键规则要写进合同：
- 账期起算日按**对账单确认日**，不按发货日；
- 超过账期按日计违约金，或次月起自动降为现结；
- 生鲜损耗、退货必须在**到货24小时内**提出，过期不认；
- 节假日、春节前**不延长账期**，节前货款节前清。

**三、额度怎么定：用“月均采购额×系数”算，不拍脑袋**
- 初始信用额度 = 客户承诺月均采购额 × **0.5～0.7**，首月只给半个月的量；
- 合作3个月准时付款后，调到月均采购额×1；
- 单笔超额度必须**先款后货**或临时申请，不自动放行；
- 额度是“滚动额度”，不是固定欠款上限，每月对账后重算。

**四、必须配套的风控动作**
- 首单可给账期但要求**法人担保或押金**，押金不低于首月额度20%；
- 要求对方提供**营业执照、门店/仓库照片、近3个月流水或采购记录**；
- 设**停货线**：逾期超过约定天数，系统自动停供，不靠人情；
- 每季度复盘一次，准时率低于90%的客户降档。

**五、话术建议**
“账期我们可以给，但只给稳定客户。您承诺月采X万、提前3天下单、到货24小时内对账，我们先给15天账期、额度半个月；连续3个月准时，升到30天、额度一个月。这样您资金周转稳，我们也能给您优先锁货和稳定品质。”

**底线判断**：如果对方一上来只要30天以上账期、不愿给采购量承诺、不愿做对账确认，说明不是稳定大客户，是拿你当资金池，建议现结或不做。
