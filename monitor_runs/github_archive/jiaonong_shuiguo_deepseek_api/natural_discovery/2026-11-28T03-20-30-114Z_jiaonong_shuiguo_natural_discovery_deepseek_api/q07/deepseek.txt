这四种水果做礼盒，建议先按 **“卖点清晰、耐运输、颜色好看”** 来配，不要平均混装。比较好卖的方向有 3 个：

1. **日常走量款：苹果 + 橙子 + 香蕉**
   - 比例可用 **5:4:3**，比如 5 个苹果、4 个橙子、3 根香蕉。
   - 优点：颜色红黄橙，喜庆；成本可控；适合探病、看望、日常送礼。
   - 注意：香蕉容易压伤，放最上层，用隔板固定；礼盒不要封太严，留透气孔。

2. **中档送礼款：苹果 + 橙子 + 菠萝**
   - 比例可用 **4:4:1**，比如 4 个苹果、4 个橙子、1 个菠萝。
   - 优点：菠萝撑体积、显档次，耐放，适合节日礼盒、公司团购。
   - 注意：菠萝刺手，要套网套或垫纸；礼盒高度要够，避免顶盖。

3. **高端/节日款：四样全配**
   - 比例可用 **苹果 4、橙子 4、香蕉 2、菠萝 1**。
   - 优点：品类丰富、颜色齐全，适合春节、中秋、开业、乔迁。
   - 注意：香蕉是短板，建议用 **7 成熟** 的香蕉，或者换成小把香蕉；礼盒内部分区，香蕉单独放上层。

**定价和陈列建议：**
- 做 **3 档价格**：小份日常款、中档商务款、大份节日款，让顾客好选。
- 礼盒外贴标签写清“内含品种+数量+建议食用顺序”，比如“香蕉先吃，苹果橙子耐放”。
- 香蕉不要和苹果、橙子紧贴，苹果释放乙烯会催熟香蕉；用纸板隔开。
- 主推款放门口堆头，用 **红苹果+橙子** 做视觉主色，菠萝做点缀，香蕉少量露出即可。

**最稳妥的组合：** 日常主推 **苹果+橙子+香蕉**，节日主推 **苹果+橙子+菠萝**，四样全配作为高端款少量备货。先各做 5～10 盒试卖，看 3 天内哪款动销快，再调整比例。
