可以，但取决于你找的是哪一类供应商，以及你要的“包装和规格支持”具体到什么程度。

**一般情况下的能力边界：**

1. **包装支持**
   - **水果种植/产地供应商**：通常能提供基础包装（纸箱、泡沫箱、网套、贴标），但自有品牌包装（印你商超LOGO、品牌名、条码、合规标签）多半要你定稿后他们代采或你指定包材厂。
   - **产地合作社/代办**：包装能力弱，通常只做通货箱，自有品牌包材要你自己解决。
   - **专业果蔬供应链/加工配送商**：能提供从包材采购、贴标、分装到打码的一条龙服务，这是最匹配自有品牌需求的类型。

2. **规格支持**
   - 能按你要求的单果重、果径、等级、每箱净重、每盒个数做分选和定重，但**需要你有量**。量小的时候供应商不愿单独开分选线，往往只能迁就现有规格。
   - 规格标准要写进合同：果径区间、允许偏差、次果率、成熟度、农残检测要求。

**要问供应商的关键问题（可直接照着问）：**
- 能否代采/代印自有品牌包材？起订量多少？包材费用谁承担？
- 能否按我指定的规格分选定重？最小起订量（按车/按吨）是多少？
- 标签合规（品名、产地、等级、净含量、条码、生产商信息）由谁负责？
- 出现规格不符、烂果、短重的赔付标准是什么？
- 是否支持贴标后直发门店/DC，还是只能发大仓？

**给你的判断建议：**
- 先明确你是**只换包装**还是**连规格等级一起定制**。只换包装，多数供应链商能做；连规格定制，必须找有分选线的供应商且量要够。
- 自有品牌的核心风险不在包装，在**品质稳定性**。建议先小批量试单，锁定一个产季的规格标准，再谈包材起订。
- 包材最好由商超统一设计、指定供应商，避免各产地包装不一致。

如果你告诉我品类（比如苹果、柑橘、蓝莓）、预估年采购量和是否走DC，我可以帮你判断该找哪类供应商、哪些支持是合理的。
