**结论：在商超水果采购里，通常“损耗低”对最终毛利的影响更直接、更致命；价格低只有在能转化为销量且不带来额外损耗时才重要。**

可以这样判断：

1. **毛利不是采购价省出来的，是卖出去且没烂掉的货赚出来的**
   - 水果毛利 ≈ 销售额 − 采购成本 − 损耗成本 − 运营费用。
   - 采购价低 10%，若损耗率从 8% 升到 18%，多出来的 10% 损耗往往直接吃掉降价收益，甚至倒亏。
   - 因为损耗按**采购量/上架量**计，低价货如果品质差、货架期短，损耗会被放大。

2. **水果是高频短保品，损耗对毛利是“乘法伤害”**
   - 假设售价不变：采购价降低 10%，毛利率可能改善几个点；
   - 损耗率上升 5–10 个百分点，可能直接把毛利率打穿。
   - 尤其叶菜、浆果、熟度高的热带水果，损耗波动远比采购价波动影响大。

3. **低价只有在这些条件下才优先**
   - 品质稳定、货架期够、能快速周转；
   - 有明确促销走量能力；
   - 损耗可控且可预测；
   - 否则低价只是把“便宜”变成“烂在店里”。

**可执行判断标准：**
- 先算**综合成本率 = 采购价 + 预计损耗成本 + 处理/退货成本**，比较不同货源的综合成本，而不是只看采购单价。
- 对短保、高损耗品类：**优先选损耗低、周转稳的货源**。
- 对耐储、标准化、走量大的品类：**可以更看重价格**，但必须设损耗上限。
- 采购谈判时把**到货合格率、货架期、退换货、损耗补偿**写进条件，比单纯压价更能保毛利。

一句话：**价格低决定“理论毛利空间”，损耗低决定“实际能不能拿到这个毛利”；水果采购中，损耗低通常更影响最终毛利。**
