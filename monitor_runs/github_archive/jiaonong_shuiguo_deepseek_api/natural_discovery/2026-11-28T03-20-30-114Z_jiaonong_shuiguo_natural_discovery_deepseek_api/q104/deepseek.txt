单位采购水果验收和售后，核心是把“标准前置、到货可判、差异可追溯、售后有闭环”四件事做实。建议按下面做：

## 一、采购前先定验收标准

不要等到货再争论“好不好”，先把标准写进订单或合同附件：

1. **品种、规格、等级**：如苹果直径范围、单果重量区间、糖度范围、成熟度要求。
2. **外观标准**：颜色、大小均匀度、表面伤疤、虫眼、腐烂、压伤、畸形果比例上限。
3. **新鲜度标准**：果柄状态、叶片状态、气味、硬度、是否冷库久存。
4. **包装与标签**：箱规、净重、产地、采摘/包装日期、是否混装。
5. **允许偏差**：明确“不合格比例超过多少即整批拒收或折价”，例如外观瑕疵不超过5%、腐烂不超过1%。
6. **到货时限**：下单到送达时间、冷链要求、到货温度记录。

## 二、到货验收怎么做

建议采用“抽检+拍照+记录+会签”的方式：

1. **先查单据和包装**
   - 核对品种、数量、规格、产地、批次、送货单。
   - 检查包装是否破损、受潮、挤压，净重是否足量。
   - 冷链水果查运输温度记录。

2. **分层抽样**
   - 不要只看最上面一层。
   - 按箱数随机抽取，比如每批抽5%—10%的箱，每箱从上、中、下不同位置取样。
   - 大批量可分上、中、下、内、外多点抽样。

3. **现场判定**
   - 称重：单果重量、整箱净重。
   - 测量：直径、糖度如有条件可用糖度计。
   - 感官：颜色、硬度、气味、成熟度、腐烂、虫害、压伤、裂口。
   - 计数：不合格果数量/比例。
   - 拍照录像：问题果、包装、批次标签、抽样过程、称重读数都要留证。

4. **形成验收记录**
   - 记录到货时间、批次、数量、抽样数、不合格数、不合格率、判定结果。
   - 验收人、送货人双方签字确认；如有争议，当场封存样品并拍照。

5. **判定处理**
   - **合格**：正常入库。
   - **轻微偏差**：按约定折价接收，书面确认扣款金额。
   - **不合格比例超限**：拒收该批或要求换货。
   - **部分不合格**：可挑拣后按实际合格数量结算，挑拣费用和损耗由供方承担，前提是合同有约定。

## 三、售后怎么闭环

1. **当场提出，避免事后扯皮**
   - 到货验收发现的问题，当场在送货单上注明，并让送货人签字。
   - 不要先签“数量无误”再事后追责。

2. **分级处理**
   - **可挑拣的**：供方限时补换或折价。
   - **影响食用的**：整批退换，费用由供方承担。
   - **已入库后发现隐蔽问题**：如内部腐烂、异味，保留批次样品和照片，24小时内书面通知供方，按合同约定处理。

3. **约定响应时限**
   - 例如：验收异议当场提出；隐蔽质量问题到货后24小时内反馈；供方2小时内响应、24小时内给出换货/补货/折价方案。

4. **扣款与补货留痕**
   - 折价、扣款、补货、换货都要有书面确认单或邮件/聊天记录。
   - 记录批次号，便于追溯同一供应商其他批次。

5. **供应商评价**
   - 每次验收记录不合格率、售后响应速度、补换货及时性。
   - 连续多次不合格的供应商，降低采购份额或暂停合作。

## 四、建议直接写进采购单的条款

可以简化为：

> 到货后按双方确认的规格和抽样比例验收。外观瑕疵超过5%、腐烂超过1%的，采购方有权拒收或按不合格比例折价；供方应在接到通知后24小时内完成补换货，逾期采购方可自行处理并由供方承担差价。验收异议当场提出并拍照留证，隐蔽质量问题到货后24小时内书面反馈。

这样验收时有依据，售后时有流程，争议时也有证据。
