优先关注成熟度，价格排第二。原因很直接：香蕉在烘焙里既提供甜味和香气，也影响含水量、组织结构和色泽；成熟度不对，配方再稳也会翻车，价格再低也可能变成损耗。

可执行判断标准：

1. **按用途定成熟度**
   - **香蕉蛋糕/磅蛋糕/玛芬**：选**7～8成熟**，表皮黄、带少量黑斑，果肉软但未流汁。香气足、甜度高，压泥后水分和结构较平衡。
   - **香蕉面包、湿润型蛋糕**：可用**8～9成熟**，黑斑较多，果肉很软。适合压泥，但需相应减少配方液体或调整粉量。
   - **装饰用香蕉片/夹心**：选**6～7成熟**，偏硬、切片成形好，避免过快褐变出水。
   - **过熟发黑、有酒味或酸味**：不要用于出品，可考虑做香蕉泥冷冻备用或直接淘汰。

2. **采购时看“到货成熟度”而不是“当天成熟度”**
   - 你要算从到货到使用的时间。若当天就要用，买7～8成熟；若2～3天后用，买6～7成熟，让它在库内后熟。
   - 香蕉后熟快，夏季尤其明显。一次不要按最低价囤太多，按**3～5天用量**分批采购更稳。

3. **价格只在成熟度合格后比较**
   - 同成熟度、同品种下比价；不要用“过熟低价蕉”替代标准成熟度香蕉，除非你能立即处理并调整配方。
   - 比较**可食率**：去皮损耗、黑斑切除损耗、压泥出水损耗都要算进去。低价但损耗高的香蕉，实际成本未必低。

4. **现场验收要点**
   - 看：颜色均匀、黑斑少量、无明显机械伤和霉点。
   - 摸：软硬一致，没有局部烂软或过硬。
   - 闻：有香蕉香气，无酒味、酸味。
   - 查：果柄是否发霉，箱内是否有压伤渗液。

**结论：先按产品确定成熟度标准，再在合格成熟度里比价格和可食率。** 对烘焙店来说，成熟度是质量变量，价格只是成本变量；成熟度错配会同时带来口味、结构和损耗问题。
