核心是买“成熟度合适的青香蕉”，并在到店后控制温度、湿度和机械损伤。

**采购时**
- 优先买**七成熟左右、略带青绿色**的香蕉，不要买已经全黄、带黑斑的。
- 选**整串/整把、果柄完整**的，少买散果；散果伤口多，更易黑。
- 检查果柄和果身有无挤压伤、裂口、水渍；有伤的先黑。
- 不要买冷藏过的香蕉，表皮可能已受冷害，回温后很快发黑。
- 夏季少量多次采购，别一次囤太多。

**运输到店**
- 用周转筐平放，别堆压；香蕉怕压、怕摔。
- 避免暴晒和高温车厢，尽量阴凉通风运输。
- 不要和苹果、梨、番茄等释放乙烯较多的果蔬混放，会催熟。

**到店存放**
- 放在**阴凉通风处**，适宜温度约 **13–15℃**；不要放冰箱冷藏，香蕉易冷害发黑。
- 湿度别太高，保持通风，避免闷在塑料袋里。
- 整串悬挂或果柄朝上放置，减少受压面。
- 已黄的尽快用于出品或促销，青的单独存放。
- 需要延缓成熟时，可用保鲜膜包住**果柄**，并与其他催熟水果隔离。

**使用顺序**
- 按成熟度分批：青的放后面，黄的先用。
- 每天挑出开始转黄、有黑点的先做香蕉泥、奶昔、烘焙等，不必等全黑。

一句话：**买青一点、整把少伤、阴凉通风不冷藏、少量多次、按熟度先用。**
