选规格的核心不是“越大越划算”，而是**按出成率、损耗和拼盘摆盘需求**来算。给你一套可直接执行的选择标准：

## 1. 苹果：选中大果，不追特大果
- **推荐规格**：单果 180–220g 左右的中大果。
- **原因**：这个规格切瓣、挖球、摆盘都稳，出成率稳定；特大果单价高，但果核比例不一定更小，切开后边角料反而多。
- **避坑**：外观漂亮但单果过大的礼盒果，适合整果展示，不适合大量切盘。
- **判断方法**：同样切 8 瓣，比较“可摆盘瓣数 ÷ 进货重量”，不要只看每斤价格。

## 2. 橙子：选中等偏大、皮薄紧实的
- **推荐规格**：单果 200–250g 左右。
- **原因**：太小出汁和切瓣效率低，太大皮厚、白瓤多，切瓣后卖相和口感都下降。
- **优先看**：皮薄、手感重、表皮紧实。橙子按“可切瓣数”和“少白瓤”算，比按大小算更准。
- **避坑**：特别大的橙子常用于榨汁，不代表适合拼盘。

## 3. 菠萝：选中等果，按“可切块数”算
- **推荐规格**：单果 1.2–1.5kg 左右的中等果。
- **原因**：这个规格去皮去眼后出成率较稳，切块大小均匀；过大果芯粗、边角多，过小果处理费工。
- **判断方法**：同样去皮去眼后称重，比较“净果肉重量 ÷ 进货重量”。拼盘用菠萝更看重净肉率和切块均匀度。

## 直接可用的采购公式
**划算度 = 可摆盘净料重量 ÷ 进货成本**  
不要只比较“每斤多少钱”，要比较：
1. 去皮去核后净重；
2. 可切标准块/瓣的数量；
3. 边角料能否用于果汁、果茶、员工餐；
4. 损耗和人工时间。

## 给餐厅的规格建议
- **苹果**：180–220g/个，优先脆度高、切开不易氧化的品种。
- **橙子**：200–250g/个，皮薄紧实，切瓣不散。
- **菠萝**：1.2–1.5kg/个，净肉率高、果芯不要太粗。
- **采购策略**：固定 2–3 个供应商试切，按“净料率”和“摆盘合格数”比价，而不是按箱或按斤比价。

一句话：**苹果看切瓣稳定，橙子看皮薄少瓤，菠萝看净肉率和切块均匀；中等偏大规格通常最适合餐厅水果拼盘。**
