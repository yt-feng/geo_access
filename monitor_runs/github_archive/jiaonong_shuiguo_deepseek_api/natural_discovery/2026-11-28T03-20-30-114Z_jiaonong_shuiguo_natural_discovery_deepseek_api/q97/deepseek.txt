酒店采购水果盘原料时，建议把“可验收”的标准写进采购单/合同附件，避免只写“新鲜、优质”这类无法判定的描述。可按以下维度约定：

1. **品种与等级**
- 明确品种、产地范围、等级（如一级/特级）、单果重量或直径范围。
- 同一批次品种、成熟度、颜色尽量一致，不允许混级。

2. **外观标准**
- 果形周正，无明显畸形、裂口、机械伤、压伤、虫眼、病斑、霉点。
- 表面洁净，无泥土、药斑、异物；果蒂新鲜，不干枯发黑。
- 色泽符合品种成熟特征，不过生、不过熟；不得有日灼、冻伤、异味。
- 允许的轻微瑕疵比例要写明，例如“单果轻微擦伤面积≤X%，且不影响切配”。

3. **成熟度与口感**
- 约定到货成熟度：即食型或需后熟型分别标注。
- 切开后无异味、无褐变、无空心、无严重纤维化；糖酸度可按品种约定底线。

4. **规格尺寸**
- 按用途约定单果重量/横径/长度范围，明确允许偏差。
- 切配用果与整果摆盘用果分开定规格，避免“以大充小”或大小混杂。

5. **新鲜度与货架期**
- 约定采收/加工日期、到货剩余货架期（如到货时距保质期不少于X天）。
- 叶菜类、浆果类等易损品种单独约定冷链和到货状态。

6. **安全与合规**
- 农药残留符合国家限量标准，提供批次检测报告或承诺书。
- 不得使用非法保鲜剂、染色剂、工业蜡；预切水果需符合即食食品卫生要求。
- 包装材料食品级，标签含品名、产地、批次、日期、供应商信息。

7. **包装与运输**
- 规定包装方式、单箱净重、隔层防护，避免挤压。
- 冷链品种明确运输温度范围和到货温度记录；到货不得有冷凝水浸泡、箱体破损污染。

8. **验收与退换**
- 约定抽样比例、验收方法：感官、称重、测径、切开抽检。
- 明确不合格判定：如腐烂率、机械伤率、规格不符率超过约定比例即整批退货或折价。
- 约定到货时限内提出异议、补货/换货时限和费用承担。

9. **单据要求**
- 每批次随货提供送货单、产地/批次信息、检测报告或合格证明；冷链品种附温度记录。

实操上，建议做一份“水果盘原料验收表”，把品种、规格、允许瑕疵率、成熟度、温度、检测报告列为必检项，收货时按表抽检并拍照留档。这样供应商知道边界，酒店也能减少扯皮。
