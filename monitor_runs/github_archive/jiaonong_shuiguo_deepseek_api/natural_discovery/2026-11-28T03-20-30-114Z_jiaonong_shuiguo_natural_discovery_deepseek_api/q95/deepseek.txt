# 学校食堂水果供应商选择：可操作建议

## 一、先定资质门槛（硬性筛选）

**必须核验的证件：**
- 营业执照（经营范围含食用农产品销售）
- 食品经营许可证（或食品流通许可证）
- 供货商若为批发商，要求提供上游产地/一级批发市场来源证明
- 送货人员健康证（直接接触食品的）

**加分项：**
- 有学校、机关食堂供货案例（要求提供合同或证明，别只听口头）
- 能提供批次农残检测报告（至少定期抽检报告）

> 注意：香蕉、苹果、橙子属于食用农产品，一般不要求每批出厂检验，但学校食堂应自己保留抽检记录，这是监管检查重点。

## 二、按品类看供应商类型

| 品类 | 适合的供应商 | 原因 |
|---|---|---|
| 香蕉 | 产地/一级批发商，能控制催熟 | 香蕉需催熟，小贩转手易过熟或催熟剂滥用 |
| 苹果 | 产地合作社或大型批发商 | 耐储，可一次大批量采购，压价空间大 |
| 橙子 | 产地直采或区域批发商 | 季节性明显，产地直采新鲜度和价格更优 |

**实操建议：** 不必一家通吃。可以按品类分包——香蕉找有催熟库的批发商，苹果橙子找产地或大批发商，形成2–3家竞争。

## 三、现场考察看什么

1. **仓储条件**：是否有冷藏/通风库，香蕉是否单独催熟间，苹果橙子是否避光通风
2. **分拣标准**：有无烂果挑拣流程，残次率大概多少
3. **配送能力**：几点到货、是否有冷藏车、临时加单能否响应
4. **退换机制**：烂果怎么算、多久内可退

## 四、定价与合同要点

- **定价方式**：建议按"周报价"或"随行就市+约定浮动上限"，别签死一年价，水果波动大
- **验收标准写进合同**：按品类写清规格（如苹果单果直径、香蕉成熟度）、允许残次率（一般≤3%–5%）
- **结算**：月结为主，留5%–10%质保金
- **违约条款**：连续两次验收不合格可终止合作

## 五、试供期

先签1–2个月试供合同，重点看：到货准时率、残次率、临时补货响应。试供合格再签年度框架。

## 六、一个容易忽略的点

**价格比对基准**：以当地一级批发市场同期同规格均价为参照，要求供应商报价不高于市场价的一定比例（如5%–10%），并保留每月比价记录。这比单纯"最低价中标"更稳，能避免低价进来后以次充好。
