**判断结论：** 即时零售的水果供应商应该支持小批量高频补货，否则很难跟上平台履约节奏；但要用起订门槛、加价规则、品类分层和补货窗口来约束，避免变成亏损型服务。

**为什么必须支持**
- 即时零售是30分钟到1小时履约，门店/前置仓的水果库存薄，缺货直接丢单，且平台会降权。
- 水果损耗高、保质期短，大批量压货会推高报损，小批量高频更符合生鲜周转逻辑。
- 平台侧通常按销量和履约评分分配流量，补货响应慢会直接影响复购和排名。

**但要有条件，建议这样设计**
1. **分品类定频次**：高周转爆款（香蕉、苹果、橙子、应季热销）每日1—2补；中长尾低频品按2—3天补，不要求全品类高频。
2. **设最低起补金额/件数**：如单次不低于300—500元或20—30件，低于门槛收小单附加费，覆盖拣货配送成本。
3. **阶梯定价**：标准补货价、小批量加价3%—5%、紧急补货再加急单费，把高频成本显性化。
4. **固定补货窗口**：每日固定截单时间，非窗口紧急单单独计费，避免全天候随叫随到。
5. **数据协同**：和平台/门店共享销量和库存，按安全库存自动触发补货，减少盲目小单。
6. **考核与对赌**：对连续小单但低销量的门店，协商提高起订量或调整为隔日补；对高销量门店给优先补货权。

**不适合无条件支持的情形**
- 单店日均销量太低、补货频次高但客单极小，物流成本吃掉毛利。
- 供应商距离远、配送网络不经济，小单履约成本高于货值。
- 平台不承担缺货责任却要求无限次随叫随到，风险全压给供应商。

一句话：**支持小批量高频是入场券，但要用规则把“高频”变成可算账的生意，而不是免费增值服务。**
