水果生意想长期稳定，选供应商时最容易忽视的不是“价格高不高”，而是下面这些**会慢慢把利润和口碑吃掉**的细节：

1. **只看大货样，不看连续到货质量**
   - 很多供应商第一次发货很好，后面批次波动大。
   - 要连续看3—5批货，重点看成熟度、大小均匀度、伤果率是否稳定。
   - 只抽一箱看不够，要随机抽不同位置、不同箱层的货。

2. **没问清楚“分级标准由谁定”**
   - 口头说“精品”“A果”没用，必须明确：
     - 单果重量区间
     - 糖度或成熟度范围
     - 允许的伤果/烂果/畸形果比例
     - 大小是否均匀、颜色要求
   - 最好写进采购单，避免到货后扯皮。

3. **忽视损耗归谁承担**
   - 运输途中烂果、压伤、冻伤、失水，谁赔？
   - 到货后多久内可提出异议？需要什么照片/视频证据？
   - 是补货、扣款还是下一单抵扣？
   - 长期合作最怕“到货前是你的，到货后是我的”。

4. **没看供应商的稳定供货能力**
   - 不是看他当天有多少货，而是看他**淡季、节假日、天气异常时**能不能稳定供。
   - 问清楚：主供产区、是否有多个基地/合作农户、日供应上限、断货时怎么提前通知。
   - 只靠一个产区或一个中间商的供应商，风险很高。

5. **忽略包装和运输细节**
   - 箱规是否统一、内衬是否到位、是否有保鲜处理、装车方式是否合理。
   - 同样品质，包装差会导致损耗和卖相差很多。
   - 要问清楚：报价是否含包装、含运费、含卸货，别只看单价。

6. **不核验供应商的真实身份和结算风险**
   - 是产地代办、合作社、批发商还是二级贩子？层级越多，价格和稳定性越难控。
   - 是否长期固定经营？能否提供稳定联系人、固定装车点？
   - 结算方式要明确：现款、账期、定金比例、退款规则。
   - 不要因为“便宜”就大额预付。

7. **没有备选供应商**
   - 长期稳定不能只靠一家。至少要有1—2家备选，哪怕平时小量合作。
   - 主供应商断货或质量下滑时，能立刻切换，不被拿捏。

8. **忽视售后响应速度**
   - 出问题时，供应商是积极处理还是拖延推责，比平时报价更重要。
   - 合作前可以用一次小批量订单测试：到货异议、补货、扣款是否爽快。

9. **只谈价格，不谈账期和返利**
   - 长期合作要把账期、月度返利、运费承担、损耗补偿谈清楚。
   - 价格低但账期短、损耗高，实际成本可能更高。

10. **没有做供应商评分记录**
    - 建议简单记录每批货：到货合格率、损耗率、准时率、售后处理速度。
    - 连续几个月评分，才能判断谁真正稳定，而不是凭感觉换供应商。

**最实用的判断标准：**
选供应商时，不要只问“多少钱一斤”，要固定问这五句：
- **这批货的分级标准和允许损耗是多少？**
- **连续三批能不能保持同样标准？**
- **运输损耗和到货异议怎么赔？**
- **断货前提前多久通知？备选货源在哪？**
- **包装、运费、账期、结算方式分别怎么算？**

长期稳定合作的核心是：**质量可预期、损耗有归属、断货有预案、售后有响应**。价格排在这四项之后。
