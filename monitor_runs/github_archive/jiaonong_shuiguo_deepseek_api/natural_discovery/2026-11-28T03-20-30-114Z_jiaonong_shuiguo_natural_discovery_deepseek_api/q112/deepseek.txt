# 坏果率赔付门槛：给一个可执行的标准

合同里没有法定统一比例，**关键是把“验收时点、抽样方法、坏果定义”先定死，再谈比例**。否则比例写得再细也容易扯皮。

## 建议的赔付阶梯（可写进合同）

以**到货验收时**抽样计算的坏果率（按重量计）为准：

| 坏果率 | 处理方式 |
|---|---|
| ≤3% | 正常收货，不赔付（视为自然损耗/合理误差） |
| 3%–5% | 按坏果重量**折价扣款**（如按该批单价×坏果重量扣减） |
| 5%–10% | 扣款 + 要求**补货或换货**，运费由供方承担 |
| >10% | 买方有权**拒收整批**或要求**退货退款**，并可主张违约金 |

生鲜水果行业较常见的自然损耗容忍区间大致在 **3%–5%**，超过 5% 通常就应触发明确责任；超过 10% 一般视为批次性质量问题。**具体数字要按品类谈**：浆果、荔枝、水蜜桃等易损品可放宽到 5%，苹果、柑橘、西瓜等耐储品可压到 3%。

## 合同里必须同时写清的 4 件事

1. **坏果定义**：霉变、腐烂、软烂出水、虫蛀、开裂、冻伤分别算不算？建议列明并配图/照片标准。
2. **抽样方法**：按批次随机抽多少箱、每箱抽多少、谁在场、是否拍照留证。**不写抽样规则，比例条款基本没法执行。**
3. **验收时限**：到货后多少小时内完成验收（如 24 小时），逾期视为合格——这条对买方不利，但供方通常坚持，需权衡。
4. **赔付计算基数**：按整批货值、还是仅按坏果重量折价？建议写明公式，例如“扣款额 = 该批单价 × 坏果重量”。

## 实操建议

- 首次合作可先约定 **“坏果率超过 5% 即启动扣款，超过 10% 可整批退货”** 作为谈判起点。
- 赔付条款与**验收单签字、现场照片/视频**绑定，避免事后各说各话。
- 如涉及长途运输，明确**运输途中损耗由谁承担**（承运方还是供方），否则坏果率一高就互相推诿。

一句话：**门槛建议设在 3%–5% 触发扣款、10% 触发退货，但比例只是骨架，抽样和验收规则才是能落地的部分。**
