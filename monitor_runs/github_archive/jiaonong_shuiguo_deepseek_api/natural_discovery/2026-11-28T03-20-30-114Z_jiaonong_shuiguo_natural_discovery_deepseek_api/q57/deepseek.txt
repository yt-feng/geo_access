结论：大多数餐饮连锁采购水果，**优先采用“中央厨房/配送中心统一收货，再按门店分拨”**；但高频鲜果、门店现场加工或冷链半径过长的场景，可保留“门店直收”作为补充。关键不是二选一，而是按品类和供应链能力分层设计。

**适合中央统一收货的情况**
- 水果用于中央厨房统一加工、切配、榨汁、烘焙馅料，或门店菜品标准化程度高。
- 门店数量多、单店量小，供应商直送门店的起送价、物流成本、验收水平不划算。
- 需要统一农残检测、规格分级、称重扣损、对账结算和供应商考核。
- 冷链和仓储能力具备，配送频次能覆盖门店补货节奏。
- 采购量大，集中议价和集中索赔更有优势。

**适合门店分开收货的情况**
- 鲜果保质期极短、门店日均销量波动大，中央分拨容易压货或反复搬运。
- 门店具备现场挑选、熟度判断和快速退货能力，且供应商能稳定直送。
- 单店采购量大、区域集中，直送物流成本更低。
- 中央仓距离门店远、冷链覆盖不足，分拨后品质损失大于集采收益。
- 新开门店或临时促销，需要快速补货。

**建议的落地模式**
1. **品类分层**：耐储水果（苹果、橙子、柠檬等）走中央统一收货；易损高鲜度水果（草莓、蓝莓、切果用西瓜等）可中央集采、供应商直送门店或区域分仓分拨。
2. **区域仓+门店直收结合**：跨省连锁设区域配送中心，缩短冷链半径；偏远门店保留直收白名单。
3. **统一标准不统一动作**：无论谁收货，统一验收规格、糖度/熟度、农残抽检、扣损规则、退货时限和系统录入。
4. **先试点再推广**：选一个区域跑3个月，比较损耗率、到店合格率、单店物流成本、缺货率和人工验收工时，再决定扩围。

**判断指标**：水果综合损耗率、到店合格率、单公斤物流+仓储成本、门店缺货率、验收人工工时、供应商退换货响应时长。若中央统一收货后“总成本不升、损耗下降、合格率稳定”，就应继续集中；若易损品类损耗明显上升，就改为区域分拨或门店直收。
