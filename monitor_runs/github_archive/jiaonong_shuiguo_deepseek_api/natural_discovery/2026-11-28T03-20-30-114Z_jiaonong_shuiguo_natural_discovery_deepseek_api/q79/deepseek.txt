最应该先问**售后**，其次**配送**，最后才是**价格**。

原因是团购团长卖水果，真正决定你能不能长期赚钱的不是进货价，而是**坏果谁承担、损耗谁兜底**。水果是非标生鲜，坏果、压伤、熟度不稳几乎必然发生。如果售后规则不清楚，低价进货最后会变成团长自己贴钱赔客户，还会伤团购群信任。

建议按这个顺序判断供应商：

1. **售后优先问清楚**
   - 坏果率多少以内算正常？超出怎么赔？
   - 是补货、退款还是按比例赔付？
   - 拍照报损的时限和标准是什么？
   - 团长先赔客户后，供应商多久结算？
   - 整批质量问题能不能退换？

2. **配送再问清楚**
   - 到团点还是到小区？谁卸货？
   - 几点到？延误导致水果变质谁负责？
   - 冷链/保温条件如何？
   - 起送量、配送费、临时改量怎么算？

3. **价格最后谈**
   - 价格必须建立在售后和配送责任清楚之后。
   - 不要只比单价，要算“到手可售成本”：进货价 + 损耗 + 赔付 + 配送 + 团长售后时间。

一句话：**先问售后能不能兜底，再问配送稳不稳，最后才谈价格低不低。** 价格低但售后模糊的供应商，风险通常由团长承担。
