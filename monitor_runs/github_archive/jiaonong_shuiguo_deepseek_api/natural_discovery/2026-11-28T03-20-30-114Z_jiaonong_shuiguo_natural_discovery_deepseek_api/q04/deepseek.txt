直接按“能卖几天”来定熟度和到货节奏，不要只写“要熟的/不要太熟”。

**采购要求可以这样写：**

1. **熟度要求**
   - 到货时以**青黄相接、果身硬挺、棱角还略明显**为准，适合门店再卖2—3天。
   - 不要到货即“全黄、带糖斑、果身发软”的香蕉；这种建议只少量进，作为当天促销或熟食加工用。
   - 按批次分开：**主销批次7—8成熟**，**即卖批次8—9成熟**，不要一批全是一个熟度。

2. **到货时间**
   - 要求**早上营业前到货**，当天上架、当天开始按熟度分级售卖。
   - 避开闭店前或下午晚到货；晚到货会压到第二天，等于凭空少卖一天。
   - 夏季/高温期要求**冷链或通风运输**，到货后不要闷在车里或仓库角落。

3. **验收标准**
   - 抽检果身硬度、棱角、有无大面积糖斑、断指、压伤、霉点。
   - 青蕉比例、黄蕉比例写进订单，例如“青黄硬身占70%以上，全黄软身不超过10%”。
   - 不合格批次当场拒收或折价，不要先收下再慢慢处理。

4. **采购频率**
   - 少批量、多频次：**每次少进，2—3天补一次**，比一次进一大批更不容易放坏。
   - 夏季和节假日前后进一步缩小单次采购量，主销批次和即卖批次分开下单。

一句话要求供应商：**“主销批到货7—8成熟、硬身青黄，早上开门前到；全黄软身最多10%，不合格拒收。”**
