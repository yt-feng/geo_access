做餐饮每天要少量水果，最省心的通常不是“批发市场大档口”，而是能稳定小批量、按需配送的本地二级供应商。建议按这个顺序找：

1. **本地水果配送商/生鲜B2B平台**
   - 找专门给餐饮、茶饮、食堂送货的本地水果配送商，通常支持每天小批量、按箱/按份配送到店。
   - 优点：省心、能开票、有售后；缺点：单价比批发市场略高。
   - 适合：每天用量不大但要求稳定、不想自己跑市场。

2. **附近水果店/社区生鲜店谈长期供货**
   - 找离店近、品质稳定的水果店，谈“每天早晨按单送”或“到店自取+预留”。
   - 优点：灵活、小量也能拿、沟通快；缺点：品类受限于该店货源，旺季价格波动要提前约定。
   - 适合：每天只要几斤到十几斤、品类不复杂的店。

3. **本地农贸批发市场的固定档口**
   - 选一个档口长期合作，约定每天少量留货、固定时间取货或加配送费送货。
   - 优点：价格透明、品类多；缺点：要早起、品质需每天盯，售后不如配送商省心。
   - 适合：自己或员工能固定早上去取货的店。

4. **产地/合作社直供**
   - 只适合单品用量稳定且较大的情况；每天少量一般不值得，物流和起送量不划算。

**筛选时重点看这几点：**
- 是否支持**小批量、每日配送**，起送量多少；
- 缺货/品质差时**能否当天补换**；
- 价格是随行就市还是**一周/一月锁价**；
- 能否**开票**、对账是否简单；
- 先试送1—2周，看准时率、损耗率和坏果处理。

**最省心的组合建议：** 主供应商选本地餐饮水果配送商，保底稳定；再备一家附近水果店作为临时补货。这样既不压库存，也不怕断货。
