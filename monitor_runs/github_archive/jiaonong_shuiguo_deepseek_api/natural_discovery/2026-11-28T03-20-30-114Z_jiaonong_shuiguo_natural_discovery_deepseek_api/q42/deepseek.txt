# 商超水果采购压价不影响品质的谈判框架

核心原则：**压价不是压品质，而是压掉对方水分、转移风险和成本。** 谈价格时永远把“品质标准”写进前置条件，让降价发生在非品质环节。

## 一、谈之前先做三件事

1. **建成本底牌**：拿到产地收购价、包装费、冷链运费、损耗率的大致区间（多问几家供应商、逛批发市场、查产区行情）。知道对方毛利空间，谈判才不会变成砍品质。
2. **定分级标准**：把你要的规格写成可检验的条款——单果重量区间、糖度、着色率、瑕疵率上限、大小均匀度、到货新鲜度（采摘/发货时间）。**先锁标准，再谈价格**，避免对方用降级货回应降价。
3. **算清总成本**：到岸价 + 损耗 + 退货 + 账期资金占用，而不是只看单价。有些低价单损耗高，实际更贵。

## 二、压价的正确着力点（不碰品质）

- **压中间环节，不压产地**：要求直采、减少代办/多层批发，价格自然下来而果品不变。
- **以量换价**：承诺稳定采购量或包园/包批次，换单价折扣，而不是换等级。
- **改包装和物流**：散装替代精装、优化装箱规格、合并发货降低运费——降的是包装物流成本，不是果子。
- **调账期换价格**：现结/短账期换折扣；反过来，账期长就要低价，这是资金成本的对价。
- **错峰和规格**：非节日高峰采购、接受略小但同品质的规格，价格更低。
- **损耗与售后条款**：约定到货验收标准、次品率上限和退换机制，把损耗风险留在供应端，等于变相降价。

## 三、谈判话术结构

1. 先给标准和量：“这个规格、这个量、长期合作。”
2. 再给目标价和依据：“同产区同规格市场价是X，我了解到产地价是Y，我们希望到岸价Z。”
3. 把降价和条件绑定：“价格能到Z，我可以现结/加大单次采购量/全年包量。”
4. 守住品质红线：“低于这个标准我们不收，价格再低也没意义。”让对方明白降品质换不来订单。

## 四、必须写进合同的品质条款

- 规格、糖度、瑕疵率、新鲜度等验收指标及抽检方式
- 次品率超标的扣款/退货/补货规则
- 价格调整机制（随产区行情浮动，避免单方毁约或以次充好）
- 违约与质量责任（如腐烂、农残超标）

## 五、要警惕的信号

- 对方一口答应大幅降价却不问条件——大概率准备降等级或掺货。
- 反复强调“便宜就是这样”——说明品质底线守不住，换供应商比继续谈更划算。
- 只谈单价不谈验收——后期扯皮成本会吃掉降价收益。

**一句话总结**：把谈判焦点从“单价”转到“标准+总量+账期+物流+损耗分担”的组合上，价格在非品质维度上让出来，品质用合同条款锁死。这样压下来的是渠道水分，不是果子本身。
