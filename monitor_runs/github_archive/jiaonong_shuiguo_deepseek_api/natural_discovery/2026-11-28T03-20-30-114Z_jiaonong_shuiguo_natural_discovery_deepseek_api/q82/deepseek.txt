低价香蕉最容易引发三类投诉：一是到货青硬或过熟发黑，二是重量/规格不符，三是坏果不给赔。建议把“低价”做成可控的引流品，而不是全店价格战。具体做法：

1. **选品上只做“能标准化的香蕉”**
   - 优先选耐运输、后熟可控的产地和规格，不要用尾货、清园果做低价。
   - 单一批次采购，避免混收，减少成熟度不一致。
   - 低价可以体现在规格上，比如小果、短果，但要在页面写清楚克重/根数。

2. **把成熟度分级写进商品页**
   - 明确标注发货成熟度：例如“7-8成熟发货，收到后常温1-3天转黄”。
   - 配图说明青果、转黄、可食用的状态，降低“收到是青的”预期落差。
   - 不要用“即食”“香甜软糯”等绝对化描述。

3. **设收货验收和售后规则**
   - 到货当天拍照反馈坏果、压伤、黑斑，按根数或比例赔付，规则提前公示。
   - 明确“青果未熟不属于坏果”，但给出催熟方法：常温避风、与苹果同放、不要冷藏。
   - 坏果赔付要快，低价品建议直接按比例退款，避免纠缠影响口碑。

4. **控制履约环节**
   - 分拣时按成熟度分开装，青果和熟果不要混箱。
   - 夏季高温减少熟果发货比例，冬季可适当提高。
   - 自提点避免暴晒、闷热，到货后尽快通知取货。

5. **用规格和限量管理低价**
   - 低价香蕉做限量引流，比如每团限2份，避免大量囤货后集中投诉。
   - 页面写清“低价品优先保证价格，外观可能有轻微斑点”，但坏果仍赔。
   - 不要用低价香蕉替代所有SKU，保留正常品质款做对比。

6. **建立批次复盘**
   - 每批记录产地、成熟度、到货时间、投诉类型。
   - 连续两批投诉率高的供应商直接换掉，不要靠售后硬扛。

核心是：**低价可以降规格、降包装、限量，但不能降成熟度标准和售后确定性。** 把“青果怎么催熟、坏果怎么赔、规格是多少”三件事写清楚，投诉会明显下降。
