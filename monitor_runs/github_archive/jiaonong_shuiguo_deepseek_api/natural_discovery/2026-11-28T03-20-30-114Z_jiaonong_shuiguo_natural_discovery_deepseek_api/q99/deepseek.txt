选下午茶水果供应商，核心看四件事：**批量配送稳定性、食品安全资质、报价透明度、售后响应**。下面给你一套可直接执行的筛选和采购方法。

**一、先明确需求再找供应商**
- 人数和预算：按人均8–15元估算，30人以下可找本地水果店，50人以上优先找批发商或专业果切/企业配送商。
- 形式：整果（苹果、香蕉、橘子、圣女果）最稳；果切省事但必须冷链、当天切配；混合果盒好看但损耗和成本高。
- 频次：每周1次还是每天配送，决定要不要签月度框架协议。

**二、供应商类型对比**
1. **本地水果批发市场商户**：价格最低，适合大批量整果，但配送和售后弱，需自己验货。
2. **专业企业下午茶/果切配送商**：有套餐、能定时送、带票，价格中等，适合长期合作。
3. **生鲜平台企业购（如美团、京东等企业服务）**：流程规范、有发票，价格偏高，适合小批量或应急。
4. **连锁水果店**：灵活、可临时加单，批量折扣有限。

**三、必须核验的资质和条件**
- 营业执照、食品经营许可证；涉及果切的要求有冷食类制售许可或明确冷链配送能力。
- 能否开具增值税发票，报价是否含配送费、包装费、切配费。
- 配送时间窗能否固定（如下午2点前送达），迟到如何处理。
- 坏果、缺斤少两的赔付标准，最好写明“坏果按比例补送或退款”。

**四、试单验证，不要一上来签长约**
先下1–2次小批量试单，重点看：
- 到货时间是否准时；
- 实际重量与标称是否一致（抽称1–2箱）；
- 坏果率是否超过5%；
- 包装是否适合办公室分发（独立小包装或易分装）；
- 售后响应速度。

**五、谈价和合同要点**
- 按月或按季度签框架价，锁定3–5个常备单品价格，避免时令波动。
- 要求提供当日或次日到货的质检/农残检测报告（至少能提供批次来源）。
- 约定最低起送量、临时加单截止时间、节假日配送安排。
- 付款账期尽量月结，保留10%左右尾款或采用先试单后月结。

**六、避坑提醒**
- 不要只看“果切拼盘”单价低，果切损耗和卫生风险高，优先选可整果分发的品类。
- 警惕报价明显低于市场价的供应商，可能在重量或品质上缩水。
- 夏季配送要求冷链或加冰袋，香蕉、芒果等易损水果不建议大批量下午茶采购。
- 固定1家主供应商+1家备用，避免临时断供。

**可执行结论**：50人以内、每周1–2次，优先找本地有企业配送经验的水果商或连锁店谈月结套餐；50人以上，找批发市场商户或专业果切配送商，先试单2次，验准时率、坏果率和开票能力，再签季度框架协议。
