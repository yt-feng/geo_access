# 水果到货不合格，怎样约定补货才不影响营业

核心思路：**把"验收标准、判定时限、补货时效、缺货兜底"四件事写进采购合同或供货单，并且让补货责任跟着"到店时间"走，而不是跟着"发现问题的时间"走。**

## 一、合同里必须写清的5个条款

**1. 验收标准要可量化**
- 按品类写清：糖度范围、单果重量/规格、成熟度（几成熟）、外观（无腐烂、无压伤面积上限）、农残检测要求。
- 不要写"新鲜""优质"这类模糊词，否则扯皮时无法判定。

**2. 验收时限和判定权**
- 约定到货后**X小时内**（建议2小时内，鲜果当天）完成验收，逾期视为合格——这条对双方都公平，也逼门店及时验。
- 明确不合格的判定方式：拍照留证+双方确认，或按抽检比例（如每批次抽检10%，不合格率超5%整批退）。

**3. 补货时效（最关键）**
- 写"**当日补货**"：上午到货不合格的，**当天营业高峰前（如14:00前）**补到位；下午到货不合格的，**次日开店前**补到位。
- 明确"补货到达时间"是考核点，不是"发货时间"。

**4. 缺货兜底责任**
- 供应商未按时补货的，门店可自行采购同品质水果，**差价由供应商承担**，并从货款中直接扣。
- 设违约金：每延迟X小时按该批次货款的Y%计，或每次固定金额。

**5. 结算挂钩**
- 不合格批次不计入结算；连续N次（如月内2次）不合格，门店有权终止合作。

## 二、不影响营业的操作安排

- **安全库存**：对高频核心水果（柠檬、芒果、草莓等）保持**1.5～2天用量**的库存，补货窗口内不缺料。
- **双供应商**：核心品类备一家备用供应商，主供出问题时应急调货。
- **分时段到货**：把补货约定在营业低谷（如上午10点前、下午2-4点），避免高峰期接货影响出品。
- **菜单弹性**：对易出问题的水果，准备1-2个替代配方，短期缺料时切换而非停售。

## 三、一句话总结

**"标准量化 + 2小时验收 + 当日/次日开店前补到 + 差价和违约金兜底 + 安全库存和备用供应商"**，这五条凑齐，水果不合格基本不会演变成断货停售。
