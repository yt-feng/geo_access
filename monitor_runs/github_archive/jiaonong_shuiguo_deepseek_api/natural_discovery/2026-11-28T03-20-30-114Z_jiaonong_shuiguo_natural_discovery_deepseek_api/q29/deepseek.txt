超市和水果供应商的账期没有全国统一标准，常见区间可以按渠道和品类粗分：

- **商超/连锁超市常规账期**：生鲜水果常见 **15～30天**；不少区域超市给到 **30～45天**；强势连锁、大型卖场对中小供应商可能 **45～60天**，甚至更长。
- **水果单品/时令水果**：因为损耗高、价格波动大，实际常见 **7～15天** 或 **15～30天**，部分现结/周结。
- **供应商议价弱时**：账期往往被拉长到 **45～60天**；供应商是品牌、独家货源或稀缺单品时，可谈到 **15～30天** 甚至现款。
- **行业现实**：账期之外还要看“到货验收后起算”还是“对账后起算”、有无质量扣款、促销费用、退换货承担。很多纠纷不在天数，而在起算点和扣费。

**可执行建议**：
1. 先问清对方现有供应商的结算周期，作为锚点。
2. 新供应商首单争取 **现结或7～15天**，稳定后再谈 **30天**。
3. 合同写明：对账日、发票日、付款日、逾期利息、质量异议期限。
4. 若对方要求 **60天以上**，要核算资金占用成本，通常应换取更高供货价或更小扣费。

简言之：**15～30天最常见，30～45天普遍，45～60天偏长但存在；水果生鲜更适合短账期。**
