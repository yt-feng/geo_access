判断哪个规格更容易出货，不要凭“感觉哪个好卖”，按下面几步做，一般一周内就能看出结果。

1. **先定“规格”口径**
   把菠萝按实际交易习惯分清楚，比如：
   - 按重量：小果、中果、大果（如 1.0–1.2 斤、1.2–1.5 斤、1.5 斤以上）
   - 按等级：A/B/C 果、青果/熟果
   - 按包装：散装、箱装、筐装
   
   口径不统一，后面数据没法比。

2. **看近 7–15 天真实出货数据**
   每个规格记录：
   - 出货量（件/斤）
   - 出货速度（当天出完还是压货）
   - 退货/损耗率
   - 客户询价次数
   
   **最容易出货的规格 = 出货量大 + 周转快 + 损耗低**，不是单价最高的。

3. **区分客户类型**
   批发客户一般分：
   - 水果店/商超：偏好中果、外观整齐、耐放
   - 摊贩/社区团购：偏好小中果、价格低、走量快
   - 餐饮/加工：偏好大果或次果，看重出肉率
   - 礼盒/电商：偏好中大果、品相好
   
   同一个规格对不同客户出货速度可能完全相反，要分开看。

4. **做小批量对比测试**
   选 2–3 个规格，各拿一批同时放档口或发给同类客户，记录 24–48 小时内的成交比例。  
   重点看：
   - 哪个规格先被问
   - 哪个规格砍价少
   - 哪个规格剩货少
   
   先动销、少剩货的规格通常就是更好出的。

5. **看利润，不只看销量**
   计算每个规格的“单位时间毛利”：
   **毛利 = 售价 − 进价 − 损耗 − 运费/包装**
   有些小果出货快但损耗高、毛利薄；中果可能速度中等但综合更稳。批发商要选“周转快且不亏损耗”的规格。

6. **快速判断口诀**
   - 询价多、成交快、剩货少 → 主推
   - 出货慢但毛利高 → 做补充规格
   - 损耗高、退货多 → 减少进货
   - 连续 3 天压货 → 降价清或停进

**实操建议：** 先连续记 7 天各规格的出货量和剩货量，按“出货量×毛利÷压货天数”排个序，排前面的就是更容易出货的规格；同时按客户类型分开推，不要一个规格打所有客户。
