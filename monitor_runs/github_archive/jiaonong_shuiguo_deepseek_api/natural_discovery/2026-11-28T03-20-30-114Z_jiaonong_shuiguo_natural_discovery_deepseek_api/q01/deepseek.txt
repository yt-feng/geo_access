判断水果供应商靠不靠谱，核心不是看他说得多好，而是用低成本方式验证四件事：**货稳不稳、品质波动大不大、账期和售后是否守信、出问题能不能找到人**。香蕉和菠萝都是后熟/易损品类，对供应链要求比苹果梨高，建议按下面做。

**1. 先小单试，不要一上来锁长期**
- 先连续进 3～5 次小批量，分别看不同批次：香蕉青度是否一致、催熟后有没有大量断指/黑心；菠萝果眼深浅、黑心、烂心比例。
- 每次记录：到货时间、损耗率、可售率、口感反馈、售后响应速度。
- 连续几次损耗稳定、波动小，再谈长期价和账期。

**2. 看他的货源和周转，而不是只听报价**
- 问清楚香蕉是哪里来的、是否自己催熟、催熟库温湿度怎么控；菠萝主要产区、季节切换怎么安排。
- 靠谱供应商通常能说清楚“这批货适合几天卖、现在什么熟度、下一批什么时候到”，而不是只报低价。
- 观察他的档口/仓库：香蕉和菠萝是否分区、有没有挤压伤、周转是否快。库存积压久、混放严重的要谨慎。

**3. 用合同或订单把关键条款写清楚**
长期合作至少明确：
- 品类、规格、熟度标准、单次最小起订量；
- 到货验收标准和不合格处理方式（拒收、换货、扣款）；
- 损耗责任怎么分，尤其是香蕉催熟失败、菠萝黑心；
- 价格调整机制，别只口头说“随行就市”；
- 账期、结算方式、逾期怎么处理；
- 违约和退出机制。

**4. 重点测试售后和稳定性**
- 故意在一次小单中反馈问题，看他是否及时换货/补差，还是推给天气、运输。
- 问如果节前或雨天断货，能不能提前锁量、有没有替代产区。
- 长期供应商最好有 2 家备选，不要单吊一家。香蕉和菠萝都可以用“主供+备供”降低断货风险。

**5. 几个危险信号**
- 报价长期明显低于市场，却说不清货源和熟度；
- 不让看库、不让挑货、验收标准含糊；
- 每次到货品质差异很大，售后靠拖；
- 催着大量压货或提前打长期款；
- 只谈价格，不谈损耗、退换和账期。

实操上，你可以先做一张简单的供应商评分表：**到货准时、损耗率、品质稳定性、售后响应、价格透明度、断货应对**六项，每次进货打分，连续一个月再看是否值得长期合作。这样比凭感觉判断可靠得多。
