先给可执行结论：**别只按“颜色”挑，按“计划吃几天”反推成熟度；到店后用“看色+摸棱+看蒂+闻味”四步判断。** 香蕉是呼吸跃变型水果，买回家还会继续变熟，所以到店时**略生一点比略熟更安全**。

### 1. 先定购买策略
- **当天或明天吃**：选**全黄、带少量小褐点**的，风味最好。
- **2～3天吃完**：选**黄中带绿尖**的，回家正好陆续熟。
- **4～5天吃完**：选**绿黄相间、棱角明显**的，放室温催熟。
- **一次买多**：不要全买同一成熟度，**一半偏黄、一半偏绿**，分批吃。

### 2. 到店四步判断
1. **看颜色**  
   - 太生：整体青绿、无黄。  
   - 刚好偏生：黄底带绿尖。  
   - 即食：全黄。  
   - 偏熟：黄底有零星褐点。  
   - 太熟/易坏：大面积褐斑、发黑、果柄发黑。

2. **摸棱角**  
   香蕉有棱。**棱角分明=偏生；手感圆润、略有弹性=成熟；一按软塌=过熟。** 不要捏中间，轻捏果柄附近。

3. **看果柄和蒂部**  
   - 果柄青绿、切口新鲜：较生、耐放。  
   - 果柄发黄：接近可吃。  
   - 果柄发黑、发软：偏熟，尽快吃。  
   - 蒂部发霉、渗液：不要买。

4. **闻味道**  
   靠近果柄闻：**青草味=偏生；明显甜香=成熟；酒味/酸味=过熟或已变质。**

### 3. 避坑
- **不要买表皮大面积擦伤、发黑、渗水的**，即使局部还能吃，也容易整串快速坏。
- **不要买冷藏区拿出来的香蕉**，低温会冻伤发黑。
- **别买整串完全同熟度的**，除非当天全部吃完。
- 超市喷水保鲜的香蕉，回家后**擦干表面**再放。

### 4. 回家后控制成熟速度
- **想催熟**：和苹果/梨一起放纸袋，室温避光。
- **想延缓**：成熟后拆散、包裹果柄、冷藏；表皮变黑但果肉正常仍可吃。
- **已切开**：冷藏并尽快吃，不建议久放。

一句话：**按吃完时间选成熟度，优先“黄中带绿尖”，摸起来圆润但不软塌，果柄新鲜不发黑。**
