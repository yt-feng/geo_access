优先建议：**先上“小把装”，同时试点少数单根，不建议一上来主推整袋。**

判断逻辑和可执行建议如下：

1. **主力选小把装**
   - 便利店的核心场景是即时消费、顺手买、单人/两人份。
   - 小把装（比如3—5根）客单价适中、损耗比整袋低、比单根更有毛利空间。
   - 适合放在收银台附近或鲜食区，做“早餐/加餐”场景。

2. **单根作为补充试点**
   - 单根适合办公室、学生、单人即时吃，决策门槛最低。
   - 但单根容易碰伤、品相要求高、称重/贴标人工成本高。
   - 建议只在客流大、年轻客群多、有鲜食运营能力的门店试点，且用固定价或小篮陈列，不要全店主推。

3. **整袋谨慎上**
   - 整袋适合家庭采购，但便利店客群和场景匹配度较低。
   - 香蕉成熟快，整袋一旦卖不动，损耗和降价压力大。
   - 除非门店在社区、家庭客多，或有预订/团购渠道，否则不建议作为首推规格。

**落地做法：**
- 第一周：小把装为主，单根少量试销，整袋不上或只接受预订。
- 看三个指标：**日销量、损耗率、毛利额**。单根若损耗高、人工贴标麻烦，就撤；小把装若周转稳定，就扩陈列。
- 包装上标注“即食/稍青”更利于顾客选择，减少因成熟度误判造成的投诉。

结论：**主推小把装，单根小范围试点，整袋暂缓。**
