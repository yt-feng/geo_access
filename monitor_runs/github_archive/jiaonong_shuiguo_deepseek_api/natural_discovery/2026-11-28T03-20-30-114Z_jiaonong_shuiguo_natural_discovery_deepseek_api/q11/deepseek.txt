会影响销售，但要看“差异程度”和“你怎么卖”。

**结论：**
- **轻微大小不一**：影响不大，甚至可做分级销售。
- **大小差异明显**：会影响顾客挑选、称重心理和损耗，必须分级或调整销售方式。
- **一箱内大小混杂且成熟度也不一**：影响最大，容易压货、破损、客诉。

**具体影响点：**
1. **顾客挑选偏向大果、匀称果**，小果、异形果剩到最后，增加损耗。
2. **按箱/按把卖**时，大小不一会让顾客觉得“不划算”，复购下降。
3. **按斤卖**影响相对小，但顾客仍会翻挑，造成香蕉表皮损伤。
4. **大小差异大且成熟度不一致**，后熟不齐，今天卖一部分、明天烂一部分。

**可执行建议：**
- 进货时问清**规格分级**，尽量选同一等级，不要混级箱。
- 到店后**按大小/成熟度分拣**：大果做精品陈列或按把卖，小果做特价、散卖、果切或促销组合。
- **不要混堆任挑**，用“按把/按份”售卖，减少翻拣损耗。
- 大小差异超过明显视觉落差时，**不要按精品价卖**，否则影响口碑。
- 若长期混级严重，建议换供应商或要求**固定规格、固定成熟度**。

**判断标准：**
如果顾客一眼能看出“这箱大小差很多”，就会影响销售；如果只是略有差异但不明显，通过分级陈列基本可控。
