对小水果店，优先级建议是：**坏果率 > 熟度 > 送货速度 > 价格**。但不是四个单独看，而是按“先保损耗和周转，再谈低价”的顺序判断。

**1. 坏果率优先**
香蕉是易损耗、易催熟连锁反应的水果。坏果率高会直接带来退货、客诉、整批催熟、动销变慢。小水果店客流有限，一批坏果卖不掉就是净亏。谈进货时应明确：到货坏果率、怎么扣重/补货、开箱验收标准。

**2. 熟度排第二**
熟度决定你当天到货后还能卖几天。小水果店周转不快，建议进**偏生一点、能分批次自然转熟**的货；不要图当天好看进全熟货。要问清采摘/催熟状态、预计货架期，最好能小批量多次补。

**3. 送货速度第三**
香蕉周转快，送货慢会错过销售窗口，也会增加仓储催熟风险。但它不如坏果率和熟度致命，因为可以通过固定送货频次、提前订货来管理。

**4. 价格放最后**
低价但坏果多、熟度不合适，综合成本反而最高。小水果店应算“到手可售成本”，不是只看进价：进价 + 损耗 + 退换成本 + 压货风险。

**可执行做法：**
- 先固定1—2家供应商，连续试3—5批，记录每批到货坏果率、可售天数、送货准时率。
- 每次进货少量多批，香蕉不要一次压太多。
- 验收时抽箱/开箱拍照，坏果当场扣重或补货。
- 价格谈判放在质量稳定之后，用稳定采购量换更好的退换条件。

一句话：**小水果店进香蕉，先买“能卖得掉、损耗低”的货，再谈便宜和快。**
