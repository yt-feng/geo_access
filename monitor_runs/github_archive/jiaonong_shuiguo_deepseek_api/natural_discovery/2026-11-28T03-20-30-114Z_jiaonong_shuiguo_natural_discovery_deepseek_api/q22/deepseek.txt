可以按“引流品+利润品+连带品”做组合，而不是简单三件打包。香蕉适合做引流，苹果做稳定销量和利润，菠萝做提升客单的加购品。

**1. 主推组合：香蕉+苹果“家庭果盘装”**
- 香蕉2斤 + 苹果3斤，定一个比单买略低的组合价，比如组合价比单买省3—5元。
- 话术：“回家直接做果盘，早餐+加餐都够。”
- 目的：把只买香蕉的低客单顾客，带到苹果上。

**2. 加价购：买香蕉/苹果满额，加价换菠萝**
- 买满15元，菠萝切盒或小菠萝加价5—8元换购。
- 菠萝整果处理麻烦，切盒更适合做加购，能提高成交率。
- 目的：不强行打包，降低顾客决策成本，同时拉高客单。

**3. 场景组合：早餐组、下午茶组**
- 早餐组：香蕉+苹果，主打“5分钟早餐水果”。
- 下午茶组：菠萝切盒+香蕉，主打“酸甜解腻”。
- 用不同场景做两个价格带，避免只有一个组合价。

**4. 分级定价，不要只打折**
- 香蕉做特价引流，限购1—2斤，避免被单一低价拉低整体毛利。
- 苹果推中大规格家庭装，做利润。
- 菠萝主推切盒和小果，做加购和冲动消费。

**5. 陈列和话术**
- 三品相邻陈列：香蕉入口引流，苹果居中，菠萝切盒靠近收银或组合区。
- 标牌写“组合省X元”“加X元换菠萝”“家庭果盘一次买齐”，不要只写“促销”。
- 组合装用透明盒或网袋，让顾客一眼看出分量和搭配。

**建议先跑7天小测试：**
- A区做“香蕉+苹果组合装”；
- B区做“满15元加价换菠萝”；
- 比较客单价、组合渗透率、菠萝加购率和损耗。
- 如果菠萝损耗高，就主推切盒；如果苹果动销慢，就把它放进组合里做连带。

核心原则：**香蕉负责把人引进来，苹果负责把客单稳住，菠萝负责把客单往上加。**
