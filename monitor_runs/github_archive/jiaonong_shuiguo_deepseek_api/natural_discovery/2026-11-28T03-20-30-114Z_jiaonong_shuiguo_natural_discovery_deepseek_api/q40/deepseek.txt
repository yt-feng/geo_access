节假日水果需求暴增，核心不是临时抢货，而是提前把“量、价、品质、到货节奏”锁定下来。可按以下顺序做：

1. **提前做需求预测，按品类分级锁定**
   - 用近2—3年同节假日销售数据，按门店、品类、单品拆出日均销量和峰值系数。
   - 把水果分为三类：
     - **爆款刚需**（如礼盒苹果、橙子、车厘子、砂糖橘等）：提前45—60天锁量锁价。
     - **节令鲜品**（如草莓、樱桃、荔枝等）：提前20—30天锁定产区和大仓到货计划。
     - **补充型品类**：保留20%—30%灵活采购量，随行就市。
   - 预测要留安全库存，但不宜全部压成库存，水果损耗高，锁“货源+到货节奏”比锁“仓库库存”更重要。

2. **与核心供应商签“保量保价+浮动机制”协议**
   - 提前签订节日供货框架：明确品类、规格、质量标准、日供货量、峰值供货量、到货时间、违约赔付。
   - 价格不要一次性死锁，可采用“基础价+市场波动区间”或“阶梯价”，避免供应商节前毁约或以次充好。
   - 对核心单品至少准备**2—3家供应商**，主供占60%—70%，备供占30%—40%，防止单一产区天气或物流中断。

3. **向上游产区或一级批发市场前置锁货**
   - 对耐储水果，提前在产区或一级批发市场支付定金锁货，约定节前分批发运。
   - 对鲜嫩易损水果，锁定“产地直发+区域大仓中转”节奏，减少门店直配压力。
   - 要求供应商提供备用包装、备用物流线路，节日期间物流比货更易出问题。

4. **用“分批到货+多仓分拨”降低损耗和断货风险**
   - 不要节前一次性大量到店，按“节前3天小高峰、节前1天峰值、节中补货”分批到仓。
   - 区域大仓提前预留冷链库容和分拣人力，门店只保留1—2天周转量。
   - 对礼盒类提前完成包装和质检，节前直接分拨门店。

5. **建立节日应急采购和替代方案**
   - 预留10%—20%应急采购预算，对接本地批发市场、周边基地、兄弟门店调拨。
   - 对爆款单品准备可替代规格或品种，避免某一单品断货导致陈列空缺。
   - 节前一周每日跟踪产区天气、批发价、到货量和门店库存，触发阈值立即补单或调拨。

6. **合同和质量验收要前置**
   - 锁货协议写清糖度、规格、新鲜度、损耗率、退换货标准。
   - 节前提前验货，不要等节前最后一天集中到货；到仓即抽检，不合格立即启用备供。
   - 对供应商节前临时涨价、减量要有违约条款和备选名单。

**可执行判断标准：**
- 距节日60天：完成爆款品类预测和主供应商框架协议。
- 距节日30天：完成核心单品锁量锁价、备供签约、仓容和物流确认。
- 距节日15天：首批锁货到仓，启动每日量价库存跟踪。
- 距节日7天：按峰值计划分批到货，应急采购名单和调拨机制待命。

一句话：**提前锁“核心单品+主备供应商+分批到货+应急调拨”，不要把节日货源押在临时采购上。**
