连锁超市要把门店坏果率压下来，合同里不能只写“坏果赔付”，而要把**验收标准、责任归属、赔付计算、扣款方式、举证流程**写清楚。建议按下面结构约定：

1. **明确“坏果”定义和验收标准**
   - 按品类分别约定：腐烂、霉变、软烂、破裂、冻伤、虫害、异味、规格不符等是否计入坏果。
   - 约定允许损耗率，例如：叶菜类≤3%，根茎类≤2%，浆果类≤2%，具体按品类和季节调整。
   - 约定验收时点：到店验收、上架前复检、保质期内抽查分别适用什么标准。
   - 避免只写“新鲜”，要写可操作指标：外观、硬度、气味、温度、包装完整性、农残/质检证明等。

2. **区分责任节点**
   - 供应商责任：产地质量、采摘成熟度、预冷、包装、运输温度、到店时效。
   - 物流责任：承运温度记录、装卸损伤、延迟交付。
   - 门店责任：收货后储存温度、陈列时间、翻检频率、先进先出执行。
   - 建议约定：到店验收签字前的坏果由供应商承担；验收后因门店储存不当造成的由门店承担；责任不清时以温度记录、验收照片、监控/批次记录判定。

3. **赔付计算方式要可执行**
   - 不要只写“按实际损失赔偿”，建议写公式：
     - 当批坏果赔付额 = 坏果数量 × 采购单价 × 赔付系数；
     - 或按当批货款比例扣款：坏果率超过约定阈值的部分，按超标比例×当批货款扣减。
   - 示例：坏果率≤3%不赔付；3%—5%部分按货款的1.5倍扣减；超过5%可整批拒收或按当批货款30%—50%扣款。
   - 对易腐品可约定“整批拒收权”和“补货时限”，避免只赔钱但门店缺货。
   - 赔付应覆盖：货款、合理运输费、门店处理费、促销折价损失；是否覆盖客诉赔偿要明确，不宜笼统写“一切损失”。

4. **扣款与结算绑定**
   - 约定月度对账：以验收单、坏果照片、抽检记录、退货单为依据。
   - 赔付款优先从当月货款或质保金中直接扣除，不足部分供应商补足。
   - 设置质保金或履约保证金，例如月供货额的5%—10%，合同终止后无争议再退。
   - 约定扣款异议期，例如收到对账单后3个工作日内提出，逾期视为认可。

5. **抽检和举证规则**
   - 约定抽检比例和方法：按批次随机抽检，抽检基数、样本量、拍照留证。
   - 单方记录是否有效要写清：例如门店验收系统记录+照片+视频可作为扣款依据，供应商可申请复检。
   - 复检时限和费用承担：复检合格则费用由超市承担，不合格由供应商承担。
   - 保留批次追溯：供货批次、到店时间、温度记录、验收人、退货记录。

6. **违约和退出机制**
   - 连续或累计坏果率超标可约定：警告、扣款、暂停下单、减少订货量、解除合同。
   - 设置整改期，例如7天内提交整改报告，整改后仍不达标可终止合作。
   - 因坏果引发食品安全或客诉的，约定独立责任和赔偿上限，避免无限责任。

7. **合同条款示例**
   > 乙方交付商品经甲方门店验收，坏果率超过本品类约定阈值的，超标部分按“坏果数量×采购单价×2”从当月货款中扣除；坏果率超过10%的，甲方有权整批拒收，乙方应在24小时内补货。因乙方包装、运输或预冷不当导致的坏果，由乙方承担退货、补货及处理费用。甲方应在收货后24小时内完成验收并留存照片和验收记录，乙方对扣款有异议的，应在收到对账单后3个工作日内书面提出并申请复检。

核心原则：**坏果率按品类定阈值，赔付按公式算，扣款从货款走，举证靠验收记录，超标有整改和退出机制。** 不建议只写“坏果包赔”，否则执行时容易扯皮。
