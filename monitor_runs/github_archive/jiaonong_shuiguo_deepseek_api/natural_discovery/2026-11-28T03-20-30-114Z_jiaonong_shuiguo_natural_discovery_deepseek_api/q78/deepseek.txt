香蕉和菠萝的售后控制，核心不是“出问题后怎么赔”，而是把损耗和争议前置消化掉。分四块说：

**一、选品和到货标准要往前压**

- 香蕉：不要拿全青或全黄的货。到货以“七八成熟、果指饱满、无棱角”为基准，青香蕉在团长自提点催熟风险大，容易一边青一边烂。夏天缩短在途时间，优先选产地近、周转快的批次。
- 菠萝：选成熟度均匀的批次，避免“一箱里有的生有的过熟”。到货抽查切开1-2个看芯部，芯发黑、水渍状直接整批退，不要流入团。
- 和供应商明确：高损耗品按“到货验收不合格整批退换”，而不是事后按个赔。把损耗责任压在上游。

**二、分级销售，把瑕疵品提前定价消化**

- 香蕉按把卖、按成熟度分档：正常档原价，偏熟/表皮有斑的做“今日特价”或搭赠，不要等用户投诉再处理。
- 菠萝按个头和外观分级，小果、外观瑕疵的做低价引流款，明确标注“外观瑕疵不影响食用”。
- 高损耗品不要追求高毛利，毛利留出3%-5%作为售后准备金，心里有数。

**三、履约环节减少二次损伤**

- 香蕉怕压怕闷：分装时不要堆叠过高，自提点通风存放，夏天避免暴晒和密闭车厢。
- 菠萝怕闷怕碰：竖放或单层摆放，不要和重物混装。
- 自提点明确告知团长：到货当天尽量通知取货，香蕉、菠萝隔夜损耗明显上升。设置“到货24小时内取货”提醒，超时未取的引导尽快处理。

**四、售后规则要简单、可执行、有边界**

- 规则前置：开团页写清楚“香蕉表皮少量斑点属正常成熟现象，不影响食用；切开后芯部发黑、明显腐烂可售后”。菠萝写“外观轻微瑕疵不售后，切开芯部黑变、水烂可售后”。
- 售后方式：高损耗品优先“退款不退货”或“补发代金券”，减少来回拉扯和二次物流成本。小额直接退，大额看照片判断。
- 设时限：到货后24小时内反馈有效，超时说明原因可酌情处理，避免无限期售后。
- 设阈值：单团售后率超过某个比例（比如5%），不是逐个赔，而是复盘这批货的供应商和成熟度，下一团换批次或换品。

**一个可判断的标准：** 如果某个高损耗品连续两团售后率偏高，且集中在“到货即坏”，问题在供应链，换供应商比优化售后更有效；如果集中在“取货晚、存放不当”，问题在履约，改自提点流程。先分清损耗发生在哪一段，再决定是赔、是换、还是改流程。
