优先关注**保质期管理**，其次**包装**，最后**配送频次**。三者的优先级和判断标准如下：

1. **保质期（最高优先级）**
   - 菠萝切块属于鲜切水果，高风险、短保质期，核心是**先进先出 + 时限下架**。
   - 建议明确：加工后冷藏售卖时限、每日巡检频次、到期前折价或下架规则。
   - 判断标准：能否做到每批次可追溯加工时间，过期零售卖。

2. **包装（第二优先级）**
   - 包装直接影响汁液渗漏、氧化、交叉污染和货架观感。
   - 重点关注：密封性、冷藏适应性、是否标注加工/分装日期和保质期。
   - 判断标准：冷藏条件下不渗漏、不串味，标签信息完整可查。

3. **配送频次（第三优先级）**
   - 若门店自行加工，配送频次主要影响原料菠萝的新鲜度；若总部配送切块成品，则频次影响库存周转和临期压力。
   - 判断标准：原料或成品到店后能在保质期内售完，不因频次过低造成积压、也不因过高增加损耗。

**结论：先保“不过期”，再保“包装不坏、标签清楚”，最后用配送频次去匹配销量和损耗。** 如果只能抓一件事，就抓保质期时限和下架执行。
