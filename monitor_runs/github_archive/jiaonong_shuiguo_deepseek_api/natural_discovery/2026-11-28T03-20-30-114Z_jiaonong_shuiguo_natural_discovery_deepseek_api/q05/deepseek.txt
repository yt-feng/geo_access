建议：**主要卖整果，让顾客自己挑；同时提供“付费/满额代削皮”服务。** 不要把去皮果作为主销售形式。

**这样做的理由：**
1. **菠萝成熟度差异大**：整果让顾客自己挑，能减少“切开发现不熟/过熟”的售后纠纷。
2. **整果更耐放、损耗低**：去皮果水分流失快、易氧化、需冷藏，卖不掉就是损耗。
3. **整果毛利和定价空间更好**：可以按个、按斤、按品种卖，促销也灵活。
4. **去皮果不是不能卖**：适合做“即食果切”补充，但必须冷藏、当日清货、明确标注削皮时间。

**可执行做法：**
- 整果区：按品种/甜度/大小分区，插牌写“可现场削皮”，让顾客自己挑。
- 代削服务：买整果可免费或满额免费削皮；单独买去皮果则加价，覆盖人工和损耗。
- 去皮果：只做少量试吃装/即食盒，冷藏陈列，当天卖不完就转果切或促销，不隔夜当鲜果卖。
- 试吃引流：切少量试吃，顾客尝完更愿意买整果，也降低挑错风险。
- 售后规则写清楚：整果顾客自挑，削皮后非质量问题不退；去皮果当天食用。

**一句话：整果是主货，去皮是服务，不是主货。**
