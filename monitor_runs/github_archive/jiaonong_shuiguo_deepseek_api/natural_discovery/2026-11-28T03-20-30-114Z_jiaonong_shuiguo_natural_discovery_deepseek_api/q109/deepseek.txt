优先谈**账期**，其次**售后**，最后**配送**。前提是：先确认供应商的稳定供货能力、品质波动和报价体系，否则谈账期容易换来隐性涨价或降质。

**1. 账期最优先**
- 账期直接改善现金流，是长期合作里最有含金量的条款。
- 水果损耗高、价格波动大，账期能给你留出销售和周转窗口。
- 谈法：不要一上来要60天。可先争取“月结30天”或“货到7—15天”，再绑定采购量、准时付款换更长账期。
- 注意：账期越长，供应商越可能把资金成本摊进单价，必须同时锁定报价和调价机制。

**2. 售后第二优先**
- 水果非标、易损，售后规则不清，账期再长也会被损耗吃掉利润。
- 重点谈：到货验收标准、坏果率上限、拍照留证时限、补货/退款/折价方式、责任划分。
- 最好写成“按批次验收、按比例赔付”，而不是口头承诺。

**3. 配送第三优先**
- 配送重要，但通常可通过换物流、调整订货频次、自提等方式替代，谈判杠杆不如账期和售后。
- 重点谈：送达时间窗、冷链/温控要求、迟到和破损责任、临时加单规则。
- 如果配送直接影响门店营业，可提到第二优先。

**建议谈判顺序**：先谈品质标准和价格机制，再谈账期，随后明确售后赔付规则，最后约定配送时效和责任。三项一起谈时，用“长期采购量+稳定回款”换账期，用“明确验收标准”换售后，用“固定订货节奏”换配送保障。
