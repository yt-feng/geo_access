提前问清楚下面几类问题，基本能把旺季断货风险压住。谈的时候别只问“能不能供上”，要问到可执行、可追责的程度。

**1. 供货能力与峰值承诺**
- 旺季最大日供/周供量是多少？按品种、等级分别说。
- 我预计旺季每天需要X箱，你能承诺保底多少？超额部分怎么处理？
- 有没有历史同期供货数据或合作案例？
- 你上游是产地直采、基地还是批发市场？源头稳不稳？

**2. 缺货时的替代与补救**
- 某个品种断货，能否提前通知？提前多久？
- 有没有替代品种、替代等级或备用产区？
- 缺货时是“少供”还是“完全不供”？有没有补偿机制（如优先补货、价格折让）？

**3. 价格与锁价机制**
- 旺季价格怎么定？随行就市还是提前锁价？
- 锁价锁多久？锁量锁不锁价？
- 涨价提前几天通知？涨幅有没有上限？
- 临时调货的加价规则是什么？

**4. 品质与验收标准**
- 规格、等级、成熟度、瑕疵率怎么定？按箱还是按斤？
- 到货验收不合格怎么处理：退、换、折价？损耗算谁的？
- 冷链/运输温度要求？到店时间窗口？
- 有没有样品封样或书面标准？

**5. 订单与履约节奏**
- 每天/每周下单截止时间？提前几天报量？
- 送货频次、到店时间、迟到怎么处理？
- 旺季能不能加急补单？加急费怎么算？
- 最小起订量、拆零政策？

**6. 结算与账期**
- 现结、周结还是月结？旺季账期会不会收紧？
- 押金、保证金有没有？
- 退换货、损耗折价怎么在账上扣？

**7. 风险与违约条款**
- 断供、迟送、品质不达标有没有书面违约责任？
- 不可抗力（天气、交通、产地减产）怎么界定和通知？
- 合作期限？旺季结束后能不能延续？
- 独家还是非独家？能不能同时备第二供应商？

**8. 备选方案**
- 让对方明确：如果你这边突然增量30%，最快多久能响应？
- 你自己也要问自己：第二供应商是谁？本地批发市场兜底渠道有没有？

**谈的时候建议落到书面**：把保底量、峰值量、通知时限、验收标准、违约补偿写进简易供货协议或微信确认记录里。口头承诺在旺季最容易失效。

优先问前三类——**峰值保底、缺货通知与替代、锁价规则**，这三项直接决定你会不会断货、断货后能不能补救。
