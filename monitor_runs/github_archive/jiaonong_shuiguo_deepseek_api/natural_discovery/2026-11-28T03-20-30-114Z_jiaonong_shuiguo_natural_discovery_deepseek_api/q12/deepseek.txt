采购菠萝时，核心目标不是“挑最熟的”，而是**按预计销售节奏分批采购、让到店熟度略低于即食熟度**。菠萝是后熟水果，判断熟度主要看这几项：

1. **闻底部香气**
   - 底部是菠萝香气最集中的位置。闻到明显甜香但不冲鼻，适合 1–3 天内卖完。
   - 几乎没香气：偏生，可放，但不要一次采太多。
   - 香气浓烈、带发酵酒味：过熟或内部已开始变质，损耗风险高。

2. **看果皮颜色**
   - 青绿为主：生，适合计划 3–5 天以上销售的批次，但要看品种，有些品种青皮也甜。
   - 黄绿相间、约三分之一到一半转黄：比较适合水果店日常采购，兼顾货架期和即食性。
   - 大面积金黄、底部明显黄：适合当天或次日即食销售，不宜压货。
   - 注意：颜色不是唯一标准，不同品种差异很大。

3. **按压底部和果身**
   - 轻按底部略有弹性、不软塌：熟度较合适。
   - 硬得像石头：偏生。
   - 一按就陷、局部发软：过熟或碰伤，容易烂。
   - 不要只捏中部，底部更能反映后熟程度。

4. **看果眼和果皮状态**
   - 果眼扁平、间距均匀，通常成熟度较好。
   - 果眼鼓得厉害、果皮发亮紧绷，可能偏生。
   - 果皮有渗液、发黑、明显压伤、霉点：直接排除。

5. **掂重量和看冠芽**
   - 同等大小掂起来有分量，说明水分足；明显轻飘可能失水或过熟空心。
   - 冠芽青绿有精神较好；冠芽枯黄不一定代表果肉坏，但货架期可能偏短。

6. **切开抽检**
   - 大批量采购前，至少切开 1–2 个同批次样品看：果肉是否透亮、中心是否发黑、有无水渍状。
   - 菠萝常见“外熟内生”或“外生内熟”情况，抽检比只看外观可靠。

**采购策略建议：**
- 每天销量稳定的店：按 **7 成偏生、3 成即食熟** 搭配采购。
- 气温高、周转慢时：多采黄绿相间、香气淡的，少采全黄。
- 做现切或果汁：可接受略熟、香气足的，但必须当天处理。
- 到店后青果常温通风存放，熟果尽快冷藏或优先陈列，避免堆压。

简单判断口诀：**闻底香、看转黄、按底软、掂分量、切样查。** 采购熟度以“到店后 1–2 天达到最佳食用状态”为准，比追求到店即食更能降损耗。
