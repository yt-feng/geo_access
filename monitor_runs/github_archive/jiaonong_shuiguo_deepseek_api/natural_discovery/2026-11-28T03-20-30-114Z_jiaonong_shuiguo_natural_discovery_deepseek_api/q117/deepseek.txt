先给一个可执行的判断：**新品首轮试卖不要按“供应商推荐量”下单，按“能在一到两周内卖完、且卖不完也不心疼”的量来定。** 对大多数水果门店/档口，建议首轮试卖量控制在 **单店单品的日销预估量 × 3～7 天**，并且设置一个总金额上限。

具体可以这样定：

1. **先小批量试销**
   - 如果完全没历史数据：首轮建议 **单店 1～2 箱/件，或 20～50 公斤** 起步，具体看包装规格。
   - 如果是连锁多店：先选 **2～3 家代表性门店**试卖，不要全渠道铺开。
   - 首轮总采购金额建议控制在 **单店单日水果营业额的 1%～3%**，最多不超过 5%。

2. **按销售速度反推**
   - 先估一个保守日销量，比如每天能卖 10 公斤。
   - 首轮订 **3～5 天量**，即 30～50 公斤。
   - 如果 3 天内动销率低于 50%，说明定价、陈列或客群不匹配，不要补货。
   - 如果 3 天内卖掉 70% 以上且复购出现，再按 7～10 天量补第二单。

3. **看品类调整**
   - **高损耗、短货架期**（草莓、荔枝、杨梅、水蜜桃）：首轮 1～2 天量，最多 3 天量。
   - **耐储水果**（苹果、梨、橙子）：可放到 5～7 天量。
   - **礼盒/高单价新品**：先 5～10 盒试陈列，不压库存。
   - **散装大众果**：可按 3 天量试，观察动销和损耗。

4. **必须同时设三个止损线**
   - **时间线**：3 天看动销，7 天看是否补货；7 天卖不到 50% 就促销清尾。
   - **损耗线**：试卖期损耗率超过 5%～8%，暂停进货。
   - **毛利线**：算上损耗后的实际毛利低于门店同类水果平均水平，就不适合作为常规新品。

5. **和供应商谈试销条件**
   - 争取小批量起订、混装、可退换或破损补货。
   - 要求首批给试销价或陈列支持。
   - 不要一次签大单；先做 2～4 周试销期，再谈正式采购价和账期。

**一句话结论：首轮试卖按“3～5 天保守销量”下单，单店单品先从 1～2 箱/20～50 公斤起，选 2～3 家店试销；3 天看动销、7 天决定补不补，卖不动就及时清尾。** 这样最稳，既不会错过新品，也不会被库存和损耗拖住。
