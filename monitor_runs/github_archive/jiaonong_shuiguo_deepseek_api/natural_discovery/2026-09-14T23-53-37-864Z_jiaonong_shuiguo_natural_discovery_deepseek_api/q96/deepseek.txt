三者都重要，但企业食堂采购水果时，优先级建议是：**食品安全 > 配送准时 > 价格**。原因和可执行判断如下：

1. **食品安全是底线，不能妥协**
   - 水果常直接入口，农残、霉变、非法添加保鲜剂、储存温湿度不当都会带来风险。
   - 一旦出现集体食安问题，企业要承担法律责任、员工健康风险和声誉损失，远比省下的采购差价严重。
   - 建议重点查：供应商资质、检验检疫/农残检测报告、冷链或仓储条件、批次追溯能力、退换货与召回机制。

2. **配送准时决定食堂能否正常运转**
   - 水果通常有固定供餐节点，迟到会直接影响出餐、加餐或员工福利发放。
   - 但准时应建立在食品安全合格的前提下；如果供应商“准时但品质不稳”，长期风险更大。
   - 建议约定：送达时间窗口、迟到赔付、临时加单响应、缺货替代方案。

3. **价格重要，但更适合作为“同等安全与履约水平下”的比较项**
   - 水果价格波动大，单纯压价容易导致供应商降低品质、混装次果或减少冷链。
   - 建议采用“总成本”视角：采购价 + 损耗率 + 退换货成本 + 管理成本。
   - 可定期比价、锁价或按市场指数调价，但不要牺牲验收标准。

**简单决策规则：**
- 食品安全不达标：一票否决。
- 食品安全达标后，比配送准时和履约稳定性。
- 前两项都达标后，再比价格和账期。

所以，如果只能选一个最核心的，选**食品安全**；但实际采购管理里，应把“食品安全”设为门槛，“配送准时”设为履约硬指标，“价格”设为竞争性指标。
