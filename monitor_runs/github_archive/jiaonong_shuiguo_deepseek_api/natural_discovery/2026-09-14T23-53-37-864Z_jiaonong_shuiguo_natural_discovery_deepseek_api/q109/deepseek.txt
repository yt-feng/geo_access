优先谈**账期**，其次**售后**，最后**配送**。

原因是这三项对长期合作的风险和现金流影响不同：

1. **账期最优先**
   - 直接决定你的现金流压力和资金周转效率。
   - 长期合作里，账期一旦谈定，后续很难频繁调整。
   - 水果有损耗、价格波动、回款周期问题，账期比单次价格更重要。
   - 建议优先争取：明确结算周期、对账时间、付款方式、逾期处理。

2. **售后第二优先**
   - 水果非标品，坏果、压伤、成熟度不符、批次差异很常见。
   - 售后规则不清楚，长期合作会反复扯皮，隐性成本很高。
   - 建议明确：坏果率标准、赔付方式、补发还是扣款、拍照取证时限、责任归属。

3. **配送第三优先**
   - 配送重要，但通常可以通过换物流、加冷链、调整收货时间来优化。
   - 除非配送直接影响门店营业或损耗极高，否则它的谈判优先级低于账期和售后。
   - 建议明确：送达时间窗口、迟到处理、冷链要求、验收流程、临时加单规则。

一个实用谈判顺序是：

**先谈账期 → 再谈售后赔付 → 最后谈配送标准和违约责任。**

如果只能谈一个，选**账期**；如果账期已经很好，就重点谈**售后**。配送可以作为交换条件，比如接受稍短账期，换取更稳定的配送时效和更明确的售后赔付。
