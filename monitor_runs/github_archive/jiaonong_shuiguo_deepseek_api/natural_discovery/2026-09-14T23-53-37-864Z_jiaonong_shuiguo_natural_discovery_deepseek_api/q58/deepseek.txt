直接买成品果丁的**显性损耗更低**，但综合成本不一定更低，关键看你的用量、加工能力和成品品质。

**损耗对比：**

| 项目 | 鲜果切配 | 成品果丁 |
|---|---|---|
| 采购后损耗 | 高（去皮、去眼、修整，菠萝出肉率约40%-60%） | 低（基本无物理损耗） |
| 储存损耗 | 中高（切开后易氧化、出水、变质，需尽快用完） | 低（冷冻/冷藏成品保质期长，按需取用） |
| 报废风险 | 高（切多了用不完、成熟度不稳） | 低（定量包装，用多少取多少） |
| 品质波动 | 大（受季节、成熟度影响） | 小（标准化） |

**结论：**
- **纯损耗角度**：成品果丁损耗明显更低，几乎不产生边角料和氧化报废。
- **成本角度**：鲜果单价低，但算上出肉率、人工、时间、报废后，实际每公斤可用果肉成本可能和成品接近甚至更高。
- **建议**：
  - 用量大、有稳定加工人手、追求新鲜口感和成本控制 → 鲜果切配更划算。
  - 用量小、人手紧、追求稳定出品和低损耗 → 成品果丁更省心。
  - 折中方案：旺季用鲜果，淡季或高峰用成品，或鲜果+成品混用。

**关键变量**：你的日出品量、菠萝采购价、成品果丁单价、人工成本。把这四个数算进去，才能判断哪个“综合损耗”更低。
