要在超市买到“刚好能吃、又不至于回家立刻烂”的香蕉，核心是看颜色、摸硬度、查果柄，而不是只看整把香蕉黄不黄。

**1. 先定用途，再选成熟度**
- **当天吃/明天吃**：选 **黄底、带少量褐点** 的，闻起来有甜香。
- **2～3 天后吃**：选 **通体偏黄、两端略绿** 的。
- **4～6 天后吃**：选 **整体黄绿、硬挺** 的。
- **想放一周左右**：选 **绿色较多、果柄青绿、捏起来很硬** 的。

**2. 现场判断方法**
- **看颜色**：  
  - 全绿：太生，通常要放好几天。  
  - 黄中带绿：适合过几天吃。  
  - 全黄：适合 1～2 天内吃。  
  - 黄带褐点：最甜，但最好当天吃。  
  - 大面积发黑、果肉软塌：不要买。
- **摸硬度**：  
  - 硬得像石头：太生。  
  - 捏着有弹性、不软塌：刚好。  
  - 一捏就陷、表皮发皱：太熟或存放过久。
- **看果柄和连接处**：  
  - 果柄青绿、切口新鲜：较新。  
  - 果柄发黑、干枯、发霉：放久了。
- **看棱角**：  
  - 棱角分明：偏生。  
  - 棱角变圆润：成熟度较高。
- **闻气味**：  
  - 有清甜香蕉香：成熟适中。  
  - 有酒味、酸味：过熟或已变质。

**3. 避免“到店太生或太熟”的实用做法**
- **别买整把完全同色的**，尤其全黄带黑点的，回家可能一天就过熟。
- **如果超市只有全绿或全黄**：  
  - 全绿：买回家和苹果/熟香蕉放一个纸袋，1～2 天可催熟。  
  - 全黄：当天吃；想多放，冷藏熟香蕉，皮会变黑但果肉可多撑 2～3 天。
- **优先买果柄青绿、表皮无伤、捏着硬中带弹的**。
- **按天数拆开买**：比如一把偏绿、一把偏黄，先吃黄的，绿的继续放。

**4. 回家后怎么控熟**
- **想快熟**：和苹果/梨一起放纸袋，室温 1～2 天。
- **想慢熟**：分开存放，别和苹果、梨放一起；阴凉通风处。
- **已熟想延后吃**：剥皮后冷冻，或整根冷藏 2～3 天。
- **别把生香蕉直接冷藏**，容易冻伤、表皮发黑且难正常成熟。

简单记：**当天吃选黄带点；过几天吃选黄带绿；一周后吃选绿硬柄青。**
