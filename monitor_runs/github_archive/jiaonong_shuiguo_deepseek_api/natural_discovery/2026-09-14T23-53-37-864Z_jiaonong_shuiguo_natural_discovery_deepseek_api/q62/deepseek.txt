判断一批香蕉，核心是分“到货时的成熟阶段”和“后续坏果风险”两条线看。批发商最怕的是：看起来能放，实际已经进入快速后熟；或者表面好，箱内已经开始烂。

下面按可执行的方法说。

**一、先判断熟度处在哪个阶段**

香蕉熟度一般看颜色、手感、果指状态、果柄和棱角。

1. **颜色**
   - 全绿、硬：典型生蕉，通常适合继续催熟或长途周转。
   - 绿中带黄、果柄仍绿：开始转熟，进入可控制窗口。
   - 黄多绿少、果尖微黄：已接近销售熟度。
   - 全黄、出现糖斑：适销期很短，适合快批快走。
   - 黄中带褐斑、果柄发黑：已经偏熟，坏果风险明显上升。

2. **手感**
   - 捏起来很硬，回弹差：生。
   - 稍有弹性但不软：适中，通常最好卖也好周转。
   - 手感发软，尤其果指中部软：偏熟，运输和存放风险大。
   - 局部软陷：大概率已有压伤或内部腐坏。

3. **果柄和果轴**
   - 果柄青绿、切口新鲜：货较新。
   - 果柄发黄、发黑、干缩：采摘或运输时间偏长，后熟可能不匀。
   - 果轴发黑、发霉、渗液：整箱风险高。

4. **棱角**
   - 生蕉棱角明显，截面偏方。
   - 越熟越圆润，果指饱满。
   - 如果已经圆鼓但手感又软，通常熟过头。

5. **果指饱满度和果尖**
   - 果尖发黑不一定是坏，但若伴随软、渗液、异味，就要警惕。
   - 果指饱满、颜色转黄、果尖略黄，通常是接近可售状态。

**二、判断坏果风险，重点看这些信号**

1. **箱内温度和历史**
   - 香蕉怕冻也怕闷。
   - 如果运输中温度过低，可能出现“冷害”：表皮发暗、发灰、发黑，后熟不均，催熟也难整齐。
   - 如果温度过高、通风差，会加速后熟和发霉。

2. **有没有压伤、擦伤**
   - 果指互相挤压处发黑、发软，后续最容易从伤口烂。
   - 批发环节最怕“内伤”：外面看只是黑点，里面已经软腐。

3. **霉变和渗液**
   - 果柄、果轴、箱底有白霉、绿霉、黑霉。
   - 箱底有汁液、酒味、酸味。
   - 这些都不是小问题，说明整批或整箱已进入腐坏过程。

4. **成熟是否整齐**
   - 同一箱里有的很绿、有的很黄，说明后熟不均。
   - 这种货催熟后容易分批成熟，损耗大，销售节奏难控。

5. **果皮是否发暗、发灰**
   - 不是正常黄，而是灰暗、水渍状，可能是冷害或过熟。
   - 水渍状斑块一按就软，坏果风险高。

6. **气味**
   - 正常香蕉有清香。
   - 有酒味、酸味、发酵味，说明已经开始内部变质。

**三、现场快速抽检方法**

不要只看最上面一层。建议抽 3 到 5 箱，重点查：

- 上层：看颜色、果柄、果轴。
- 中层：看有没有压伤、软果。
- 下层：看箱底有没有汁液、霉斑、异味。
- 随机捏几根：看软硬是否一致。
- 随机切开 1 到 2 根可疑果：看内部是否发黑、软腐、空心。
- 看箱内温度记录或问运输时间、产地、是否催过熟。

**四、给批发商的判断结论**

可以这样分：

- **适合继续存放或长途周转**：全绿或绿中带黄，果柄青，手感硬到稍弹，无霉无异味，成熟整齐。
- **适合尽快催熟销售**：黄绿相间，果柄开始转黄，手感稍软但均匀，无明显伤口。
- **适合当天或一两天内快批**：黄多绿少，有少量糖斑，手感偏软，但无霉无渗液。
- **高风险，谨慎接货**：果柄发黑、果轴发霉、箱底渗液、酒味酸味、局部软陷、成熟极不整齐、冷害发灰。
- **不建议接**：已经大面积软腐、霉变、渗液、异味明显，或切开内部坏果比例高。

**五、最实用的底线**

一句话：**看颜色定阶段，捏手感定软硬，查果柄果轴定新鲜度，翻箱底定坏果风险，闻气味定是否已变质。**

如果只能记一个原则：**颜色可以骗人，手感和箱底气味最不容易骗人。**
