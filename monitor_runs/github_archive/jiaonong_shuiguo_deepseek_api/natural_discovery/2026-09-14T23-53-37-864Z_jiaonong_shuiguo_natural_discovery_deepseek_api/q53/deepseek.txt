最省心的通常不是“水果批发商”，而是 **本地生鲜配送商/餐饮供应链平台**，因为它们能按你的用量、频率、品种做小批量配送，而且售后相对有保障。

可以按这个优先级找：

1. **本地餐饮生鲜配送公司**
   - 搜“城市名 + 餐饮生鲜配送 / 食堂配送 / 水果配送”
   - 优点：可按天/隔天送，能开发票，缺货补送、坏果售后相对规范
   - 适合：每天少量、品种固定、不想自己跑市场

2. **美菜、快驴、菜划算这类餐饮供应链平台**
   - 优点：线上下单，次日达或按约定送，省沟通
   - 缺点：不同城市覆盖和品质稳定性差异大，水果有时不如专业水果商
   - 适合：先试单，看本地仓配质量

3. **本地水果店/精品水果店合作**
   - 直接谈：每天或隔天固定送，按餐饮价结算
   - 优点：灵活、量小也愿意送，沟通快
   - 缺点：发票、售后、稳定性看店主
   - 适合：用量很小，比如每天几斤到十几斤

4. **批发市场固定摊位**
   - 优点：价格低，品种多
   - 缺点：要自己早起采购或谈配送，售后麻烦
   - 适合：你有空自己管，或者量稍大

选供应商时重点看这几点：
- **能不能按你的量送**：别找只做大批发的
- **配送时间是否固定**：餐饮最怕临时缺货
- **坏果怎么赔**：拍照即赔、下次补送最省心
- **是否开发票**：能开票通常更正规
- **账期**：日结、周结、月结提前谈清楚
- **品种替换**：比如今天没有芒果，能不能提前问你要不要换

建议你先做一件事：
列出你每周要的水果品种、大概斤数、送货时间，然后找 **2家本地生鲜配送 + 1家水果店** 同时试送一周。比较“准时率、坏果率、售后速度、价格”，留下最稳的那家。

如果用量真的很少，最省心的往往是 **附近水果店固定合作**，而不是大型批发商。
