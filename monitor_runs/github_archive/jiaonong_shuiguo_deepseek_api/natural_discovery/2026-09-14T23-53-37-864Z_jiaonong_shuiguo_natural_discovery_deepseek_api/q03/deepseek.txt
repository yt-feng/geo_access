夫妻店第一次找水果供货商，试单的核心原则是：**少量多批、先试后定、把损耗和售后说清楚**。不要一上来就压价压量，先把“货稳不稳、损耗谁担、结算怎么算”跑通。

下面按常见品类给你一个可执行的试单方法。

## 一、试单前先定3件事

1. **试单量**
   - 香蕉：1箱（约12–15kg）或半箱
   - 苹果：1箱（约10–20kg）
   - 橙子：1箱（约10–20kg）
   - 不要一次进多品种大货，先各拿1箱。

2. **试单周期**
   - 至少试2–3次，间隔3–7天。
   - 第一次看货，第二次看稳定性，第三次看售后和补货速度。

3. **结算方式**
   - 首次建议现结或货到付款，别轻易押账。
   - 问清楚：是否含运费、是否包卸货、破损怎么赔、退换货时限。

## 二、三个品类分别怎么试

### 1. 香蕉
香蕉最容易出问题：催熟程度、压伤、黑斑、掉把。

试单重点：
- 要“青蕉”还是“熟蕉”？夫妻店一般要**微黄带青**，能放2–3天。
- 问清楚：是产地直发还是市场调货？催熟几天？
- 开箱检查：
  - 有没有大面积压伤
  - 有没有黑斑、发霉
  - 把数是否整齐，掉把多不多
- 试单建议：先拿1箱，放店里卖2天，看损耗率。超过10%损耗就要警惕。

### 2. 苹果
苹果相对耐放，但要看规格、口感、伤果。

试单重点：
- 问清楚：80#、85#、90#还是统货？大小是否均匀。
- 看：
  - 有没有碰伤、虫眼、裂口
  - 颜色是否一致
  - 口感是脆甜还是发面
- 试单建议：先拿1箱，拆开分上中下三层看，别只看表面。
- 如果供货商说“轻微伤不影响卖”，你要明确：伤果超过多少比例算不合格。

### 3. 橙子
橙子看新鲜度、水分、大小和酸度。

试单重点：
- 问清楚：产地、品种、规格（如65mm、70mm、75mm）。
- 看：
  - 表皮是否发皱、失水
  - 有没有软果、烂果
  - 切开试水分和甜度
- 试单建议：先拿1箱，随机抽5–10个切开或剥开试。
- 如果做散卖，大小不均可以接受；如果做礼盒或标准袋装，规格必须统一。

## 三、试单时必问的问题

直接照着问，别不好意思：

1. 这批货是产地直发还是批发市场拿的？
2. 今天拿和后天拿，价格会差多少？
3. 破损、烂果怎么赔？是补货还是扣款？
4. 退换货时限是多久？当天还是24小时内？
5. 最少起送量是多少？运费谁出？
6. 能不能先拿1箱试卖，后面再加量？
7. 如果卖不动，能不能换其他品类？
8. 账期怎么算？现结有没有优惠？

## 四、试单判断标准

试单后按这几个指标打分：

| 指标 | 合格线 | 不合格表现 |
|---|---|---|
| 损耗率 | 香蕉≤10%，苹果≤5%，橙子≤5% | 明显超线 |
| 规格一致性 | 大小基本均匀 | 大小混装严重 |
| 新鲜度 | 无大面积软烂、发霉 | 有异味、发黏 |
| 售后响应 | 当天或次日处理 | 推诿、不认账 |
| 补货速度 | 1–2天能补 | 拖3天以上 |
| 价格稳定性 | 一周内波动小 | 今天一个价明天一个价 |

## 五、实操建议

- **第一次只试1–2家**，不要同时找5家，否则你顾不过来。
- **每次试单留样**：拍照片、记日期、记损耗，后面谈价有依据。
- **先小量跑通，再谈账期**：第一次现结，第二次可以谈“压一批结一批”。
- **不要只看价格**：便宜但损耗高，最后更贵。
- **香蕉、苹果、橙子可以分开找供货商**：不一定一家全包，谁家强就拿谁家。

一句话总结：**每家先拿1箱，卖2–3天，算损耗、看售后、比补货速度，三次下来再定长期合作。**
