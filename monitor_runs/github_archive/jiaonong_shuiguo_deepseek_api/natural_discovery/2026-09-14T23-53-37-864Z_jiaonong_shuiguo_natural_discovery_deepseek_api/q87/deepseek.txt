社区团购旺季锁水果库存，核心是**用确定性换确定性**：你给供应商确定的量、确定的付款、确定的时间窗口，供应商才愿意把货留给你。具体可执行的做法：

**1. 提前锁定，分层签协议**
- 提前2-4周沟通，不要等爆单当天再要货。
- 分层锁：先锁**核心爆品**（如应季主推水果）的70%-80%量，剩余用备用供应商补。
- 协议写清楚：品种、规格（克重/糖度/果径）、单价或价格浮动区间、到货时间、日供应量、验收标准、违约金。

**2. 用“保底量+预付款”换优先权**
- 给供应商一个**保底采购量**，哪怕卖不完也按保底结算一部分，供应商才敢为你囤货。
- 支付**定金或预付款**（常见20%-30%），这是最有效的锁货手段。
- 约定**价格保护**：旺季涨价时，你按约定价拿货；跌价时按市场价或重谈，避免供应商毁约。

**3. 锁产能而不只是锁库存**
- 水果是易腐品，库存本身有限。更可靠的是锁**采摘/分拣/冷链档期**。
- 让供应商按你的发货节奏**分批采摘、分批到货**，避免一次性压货烂损。

**4. 建立备用与对冲**
- 同一爆品至少备**2-3个供应商**，主供锁量，副供补缺口。
- 关注替代品类：主推水果缺货时，用相近价位/口感的水果顶上，避免团购断档。

**5. 用数据提前预测**
- 根据历史同期销量、社群预售、团长接龙数据，给出**相对准确的预估量**。
- 预售模式：先开团收款，再按订单向供应商下单，能大幅降低你的库存风险。

**6. 合同里必须写清的几条**
- 到货时间与每日最低供应量
- 质量不达标如何处理（退换/扣款）
- 供应商违约（断供、涨价、转卖）的赔偿
- 不可抗力（天气、物流）的分担方式

**一句话建议**：旺季锁货不是“打招呼”，而是**提前签量、付定金、锁档期、留备胎**。先用预售测真实需求，再用保底量+预付款把核心供应商绑住，风险最小。
