判断的核心不是“他有没有菠萝”，而是**他能不能持续、按你定的标准、在你要的时间把货交出来**。可以从下面几个可操作的维度去验证。

**一、先把自己的规格定死**
规格越模糊，后面越扯皮。菠萝采购至少要明确：
- 品种：如金钻凤梨/台农17/都乐金菠萝等
- 成熟度：几成熟采收、到店时糖度范围
- 规格：单果克重区间（如1.0–1.3kg）、果径、是否要求无冠芽
- 形态：整果/去皮果/切块/冷冻果肉/果浆
- 等级：A级果标准、允许瑕疵比例（黑心、裂口、碰伤上限）
- 包装：箱规、每箱个数、净重
- 冷链与到货温度
- 验收标准：抽检比例、糖度检测方式、不合格处理

有了这份《到货验收标准》，才能谈“能不能稳定按规格送”。

**二、用四个硬指标筛供应商**
1. **产地/货源结构**
   - 自有基地、合作社、还是市场倒货？
   - 单一产地依赖度多高？遇台风、雨季、寒潮有没有替代产区？
   - 问清楚：广东、海南、云南、菲律宾、泰国等不同产季的切换方案。
   - 只能做“当季市场货”的，通常稳定性差。

2. **分级与加工能力**
   - 有没有分选线、糖度检测、称重分级、预冷设备？
   - 能否按你的规格做定制包装？
   - 只有人工肉眼分拣的，批次波动会比较大。

3. **冷链与物流**
   - 从采收到装车多长时间？
   - 运输温度能否全程控制？有没有温度记录仪？
   - 到你中央仓/门店的时效是几小时还是几天？
   - 说“发普通物流也行”的，鲜果稳定性通常要打问号。

4. **供应量与你的需求匹配度**
   - 他日/周供应能力是多少？你旺季峰值需求是多少？
   - 同时供几家客户？会不会一到旺季先保大客户，把你排后面？
   - 要求提供近3个月同类客户的供货记录或发货单样例。

**三、用小批量试单验证，而不是听承诺**
建议分三步：
1. **首单小批量试送**：连续送3–5批，每批抽检糖度、单果重、坏果率、到货温度。
2. **压力测试**：临时追加20%–30%订单，看能否按时补货。
3. **异常测试**：故意提一次规格微调或提前/延后要货，观察响应速度和配合度。

记录成表：批次、到货时间、合格率、糖度、坏果率、缺斤少两、异常处理时长。连续3批合格率低于约定值，基本可判定不稳定。

**四、合同和验收机制要写清楚**
- 规格、等级、包装、到货时间、温度要求
- 抽检比例和不合格判定
- 短交、晚到、品质不达标的扣款/退货/补货条款
- 旺季保供条款和违约赔偿
- 要求提供产地证明、检测报告、冷链温度记录
- 约定替代品种或替代产区的触发条件

**五、几个红旗信号**
- 只肯口头承诺，不愿签规格附件
- 报价明显低于市场，通常靠混级或压成熟度
- 无法提供稳定产地，靠“今天市场有什么发什么”
- 没有预冷和冷链，用常温车发鲜果
- 旺季频繁说“今天没货，明天补”
- 同一规格前后两批果径、糖度差异很大

**结论**：能不能稳定按规格送货，关键看三件事——**货源是否有弹性、分级冷链是否可控、试单数据是否连续达标**。先定标准，再小批量试，最后用合同锁住保供和验收，比单纯比价可靠得多。
