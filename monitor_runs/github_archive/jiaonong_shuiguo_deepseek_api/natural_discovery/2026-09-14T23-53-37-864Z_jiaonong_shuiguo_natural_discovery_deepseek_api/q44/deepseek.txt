判断供应商售后响应是否稳定，关键不是听承诺，而是看它有没有可验证的机制和过往记录。可以从这几个方面入手：

**1. 合同里写清楚响应条款**
- 明确响应时限：如到货后出现质量问题，几小时内回复、几小时内给出处理方案（退换/补货/扣款）。
- 明确责任划分：腐烂、磕碰、成熟度不符、重量短缺分别怎么赔。
- 明确对接人和备用联系人，避免"找不到人"。

**2. 要求提供历史履约证据**
- 让其提供近3-6个月给其他商超/客户的供货记录和售后处理记录。
- 问清楚过去出现质量问题时，平均多久解决、是否足额赔付。
- 可向其现有客户侧面打听（同行、批发市场熟人）。

**3. 用小批量试单检验**
- 先下小单，故意在验收时提出一个真实问题（如部分香蕉过熟、菠萝黑心），观察：
  - 多久回复；
  - 是否推诿；
  - 是否按约定补货或退款。
- 连续试2-3次，看响应是否稳定，而不是只处理一次就变脸。

**4. 看其自身货源和冷链能力**
- 菠萝、香蕉都是易损、对温度敏感的水果，售后响应慢往往和货源不稳、冷链差有关。
- 问清楚产地、到货周期、有没有冷库/冷藏车。供应链稳的供应商，售后通常也更靠谱。

**5. 设置考核和约束**
- 约定月度/季度考核：售后响应时长、赔付及时率、投诉率。
- 预留质量保证金或账期尾款，作为售后不履约的约束。
- 连续两次响应超时或推诿，可触发更换供应商条款。

**6. 观察日常沟通细节**
- 平时询价、催货、反馈问题时，回复是否及时、是否专人负责。
- 如果平时就爱拖延、换人对接，售后大概率也不稳定。

**简单判断标准：**
- 合同有明确时限 + 有历史记录 + 小单测试通过 = 相对可靠；
- 只口头承诺、不给证据、试单就推诿 = 风险高，不建议长期合作。

实际采购中，建议至少保留2家供应商，避免单一依赖，也能用竞争压力促使其售后稳定。
