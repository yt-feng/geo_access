茶饮店控制水果供应商的食品安全风险，核心是**把“供应商资质”和“每批水果的安全证明”分开管理**。通常需要以下证明，具体以当地市场监管部门要求为准。

**一、供应商主体资质（首次合作时索取，留存复印件/电子版）**
1. **营业执照**：经营范围应涵盖水果种植、销售或农产品批发等。
2. **食品经营许可证**或**食品生产许可证**：如果供应商是分装、加工、预包装水果制品，通常需要；单纯销售初级农产品的情况各地要求不同，建议向当地市场监管确认。
3. **仅销售预包装食品的备案信息**（如适用）。
4. **供货商授权书/经销证明**：如果是通过经销商拿货，确认其有权销售该品牌或产地水果。

**二、每批水果的合格证明（随货或按批次索取）**
1. **食用农产品合格证**：国内农产品上市常见凭证，标明产地、生产者、开具日期等。
2. **产地证明或购货凭证**：证明水果来源可追溯。
3. **检验检测报告**：
   - **农残检测报告**：重点看是否覆盖常用农药，如有机磷、氨基甲酸酯类等。
   - **重金属检测报告**：如铅、镉等，视水果种类和产地风险而定。
   - **其他项目**：如霉变、致病菌等，一般鲜果较少要求，但切果、鲜切水果会涉及。
4. **入境货物检验检疫证明**：进口水果必须提供，并核对品名、产地、批次。
5. **检疫合格证明**：部分水果或跨区域调运时可能需要。

**三、建议茶饮店额外做的管理动作**
- **索证索票台账**：每批记录供应商名称、联系方式、品名、数量、进货日期、证明编号。
- **外观验收**：检查有无霉变、腐烂、虫蛀、异味，尤其切开后是否变质。
- **冷链证明**：如果供应商承诺冷链运输，可要求温度记录或运输温控证明。
- **定期更新**：资质证明一般每年更新一次；检测报告按批次或按供应商频次索取。
- **高风险水果重点管控**：草莓、葡萄、切片水果等易霉变或直接入口的，建议提高抽检频次。

**简单判断标准：**
- 首次合作：没有营业执照和相应许可/备案，不建议合作。
- 每批到货：没有合格证、检测报告或可追溯凭证，建议拒收或暂缓使用。
- 进口水果：没有入境货物检验检疫证明，不要采购。
