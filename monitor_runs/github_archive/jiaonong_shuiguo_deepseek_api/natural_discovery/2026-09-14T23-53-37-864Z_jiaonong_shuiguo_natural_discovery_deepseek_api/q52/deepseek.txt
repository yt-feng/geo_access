要避免香蕉到店后很快变黑，核心是控制**温度、乙烯、机械伤和湿度**。采购时和到店后可以这样做：

1. **采购时选成熟度合适的香蕉**
   - 不要买已经全黄、带黑点、柄部发黑的。
   - 优先选**微黄带一点绿**或**青黄交接**的，到店后还能放几天。
   - 如果当天就要用，可以买熟一点的；如果要放 3～5 天，买偏青一点的。

2. **避免买“已经催熟过头”的货**
   - 香蕉柄发黑、果皮有压伤、有酒味，说明已经过熟或受过伤，到店后很快会黑。
   - 尽量选整串完整、没有明显磕碰、没有大面积擦伤的。

3. **运输和搬运要防压防摔**
   - 香蕉最怕挤压和碰撞，受伤部位会迅速变黑。
   - 不要堆太高，不要和重物混装，最好用纸箱或周转筐分层放。

4. **到店后立刻拆箱、通风、分散摆放**
   - 不要一直闷在塑料袋或密封箱里，乙烯积聚会加速变黑。
   - 放在阴凉、通风、避免阳光直射的地方。
   - 理想存放温度大约 **12～15℃**。太低会冻伤变黑，太高会熟得快。

5. **把香蕉和苹果、梨、西红柿等分开**
   - 这些水果会释放乙烯，催熟香蕉。
   - 如果香蕉已经比较熟，更要单独放。

6. **不要提前清洗或喷水**
   - 表面有水容易滋生霉菌，也会加速腐烂变黑。
   - 用之前再洗或再剥。

7. **按成熟度分批使用**
   - 先熟先用，后熟后用。
   - 如果一部分已经黄熟，可以放冰箱冷藏延缓，但冷藏后表皮仍可能变黑，果肉短期还能用，适合做甜品、奶昔、香蕉泥。

8. **需要更久保存时**
   - 熟香蕉可以去皮后冷冻，做甜品时直接使用。
   - 未熟香蕉不要放冰箱，否则容易冻伤、变黑且难熟。

简单判断：
- **买偏青、无伤、通风放、别闷袋、远离苹果梨**，就能明显延缓变黑。
- **已经全黄有黑点的，尽快用掉或冷冻**，不要再指望久放。
