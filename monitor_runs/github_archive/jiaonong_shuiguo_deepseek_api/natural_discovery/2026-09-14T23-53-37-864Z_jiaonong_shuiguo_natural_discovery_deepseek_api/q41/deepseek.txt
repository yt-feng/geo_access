判断商超采购香蕉时催熟能力是否稳定，核心不是看单次催熟结果，而是看**到货批次在相同催熟条件下，转色、软熟、货架期是否一致且可复现**。可从以下几个环节把关：

1. **看产地和批次一致性**
   - 同一供应商、同一产区、同一采收期、同一加工厂（催熟/分装厂）的货，稳定性通常更好。
   - 避免混批：不同山头、不同采收日、不同冷链经历的香蕉，催熟反应差异会很大。
   - 采购时要求供应商提供批次号、采收日期、加工日期、冷链记录。

2. **看到货青硬度和成熟度**
   - 到货应为均匀青硬、饱满度适中，不能软硬不一。
   - 抽查不同箱、不同层、不同位置，若个别已经发黄、发软，说明冷链或批次管理不稳定，后续催熟很难整齐。
   - 香蕉饱满度要适合目标催熟窗口，过瘦催熟后干瘪，过饱满则容易催熟过快。

3. **看冷库和运输温度记录**
   - 香蕉对温度非常敏感。运输和暂存一般要求约 **13–15℃**，低于约 **12℃** 易发生冷害，催熟会发黑、发僵、不上色。
   - 要求供应商提供全程温度记录，重点看是否有低于 12℃ 或高于 20℃ 的异常波动。
   - 冷害果常表现为表皮暗淡、维管束发黑、催熟后色不均，这类货不能作为稳定催熟批次。

4. **做小批量催熟测试**
   - 每批到货先抽 1–2 箱做标准催熟，不直接全库催熟。
   - 记录：开始转色时间、达到目标色号时间、软熟时间、青头/黑斑/梅花点情况、货架期。
   - 连续 3–5 批结果接近，才算催熟能力稳定。
   - 测试条件要固定：温度、湿度、乙烯浓度、催熟时长、通风条件尽量一致，否则无法比较。

5. **看催熟后的“整齐度”**
   - 稳定批次：同一箱内转色一致，果指之间差异小，达到目标色号时间集中。
   - 不稳定批次：有的已黄软，有的还青硬；或表面黄了但芯还硬；或很快出黑斑、发酸。
   - 若每批都需要靠临时加乙烯、延长催熟或反复调整温度，说明上游原料稳定性差。

6. **看货架期和损耗**
   - 催熟到目标色号后，在商超常温或冷藏陈列条件下，观察 2–4 天。
   - 稳定批次货架期可预期，损耗集中在可接受范围；不稳定批次常出现突然软烂、黑斑爆发、脱柄。
   - 采购应把“催熟后 2–4 天损耗率”纳入供应商考核。

7. **建立供应商评分**
   - 每批记录：到货青硬均匀度、温度异常、催熟时间、转色均匀度、货架期、损耗率。
   - 连续多批稳定、可复现的供应商优先；单批好但波动大的，不能算稳定。
   - 对供应商提出明确标准：同批次均匀度、可催熟窗口、目标色号达成时间、到店货架期。

简单判断口诀：
**一看批次和冷链，二测小批催熟，三比转色整齐度，四验货架期损耗。**
如果一批货在固定催熟条件下，转色时间、软熟速度和货架期都能连续多批接近，才说明催熟能力稳定。
