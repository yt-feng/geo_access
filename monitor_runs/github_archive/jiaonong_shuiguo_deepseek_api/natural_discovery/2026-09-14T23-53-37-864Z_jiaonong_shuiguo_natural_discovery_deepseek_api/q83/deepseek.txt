生鲜水果到货后出现坏果，责任划分通常不能一概而论，主要看**坏果发生的时间点、原因、以及各环节是否有过错**。可以按下面几个维度判断。

## 一、先看责任发生在哪个环节

**1. 采摘/产地环节**
- 如果水果在采摘时就已经过熟、带伤、有病斑，属于源头质量问题。
- 责任一般在供应商/产地，平台或商家可向其追偿。

**2. 仓储/分拣环节**
- 冷库温度不达标、混放挤压、分拣时没剔除坏果，导致到货后腐烂。
- 责任在平台或商家的仓储分拣方。

**3. 运输/配送环节**
- 冷链断链、运输时间过长、暴力装卸、快递延误、高温暴晒。
- 责任在物流/配送方；如果是平台自营配送，则由平台承担。

**4. 顾客签收后环节**
- 顾客未及时取件、放太久、保存不当导致坏果。
- 这部分责任通常由顾客承担。

**5. 正常生理损耗**
- 水果本身易腐，运输中少量软化、轻微磕碰属于合理损耗。
- 一般由商家通过售后政策承担，不算某一方过错。

## 二、按“谁过错、谁担责”划分

| 情形 | 责任方 |
|---|---|
| 发货时就是坏果/病果 | 商家或供应商 |
| 冷链断链导致腐烂 | 物流方，平台可先行赔付 |
| 分拣不严混入坏果 | 商家/平台 |
| 配送延误导致变质 | 物流/配送方 |
| 顾客签收后久放变质 | 顾客 |
| 无法查明原因 | 一般由商家先向顾客赔付，再内部追偿 |

## 三、对顾客的售后处理原则

对消费者来说，通常不需要区分内部是谁的责任，**先找商家/平台售后**即可。常见处理方式：

- **少量坏果**：按比例退款或补发。
- **大量坏果/整箱变质**：全额退款或补发。
- **生鲜类**：很多平台支持“坏果包赔”，但一般要求签收后一定时间内拍照申请。

商家赔付后，如果确认是物流或供应商问题，可以再向对应方追偿。

## 四、实操建议

**对商家/平台：**
1. 明确售后规则：坏果比例、申请时限、需提供的照片。
2. 保留发货前质检、冷链温度、物流签收记录。
3. 与供应商、物流方签清责任条款。

**对顾客：**
1. 签收后尽快开箱，坏果拍照/拍视频。
2. 保留包装、面单、坏果原状。
3. 在规定时间内申请售后，通常更容易获赔。

**一句话总结：**  
到货坏果的责任，核心看坏果是**发货前就有、运输中造成，还是签收后造成**；对顾客一般由商家/平台先行售后，内部再按过错向供应商或物流追偿。
