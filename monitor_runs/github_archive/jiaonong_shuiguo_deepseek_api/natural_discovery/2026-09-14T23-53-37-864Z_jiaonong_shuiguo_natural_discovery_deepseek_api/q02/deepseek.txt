这四个都重要，但对小水果店来说，**优先级通常是：坏果率 ＞ 熟度 ＞ 送货速度 ＞ 价格**。  
原因不是价格不重要，而是小店的抗损耗能力弱，香蕉又是最容易“看着好、两天就砸手里”的品类。

**1. 坏果率最重要**
香蕉一旦有隐性损伤、压伤、水烂，后面会传染、加速整批坏。  
小店进货量小、周转快，但一旦坏果率高，基本等于直接亏钱。  
建议：每次到货抽检，重点看有没有黑斑蔓延、柄部腐烂、压伤、发霉。坏果率高的供应商，价格再低也要谨慎。

**2. 熟度第二重要**
香蕉赚钱靠“卖相+时间差”。  
太生，顾客不买；太熟，当天卖不完就报废。  
小店最好按销售节奏进：

- 当天卖：可以进微黄、少量芝麻点
- 卖2-3天：进青黄、硬挺
- 想控损耗：宁可稍生一点，也别进太熟

**3. 送货速度第三**
香蕉怕闷、怕压、怕反复搬运。  
送货慢、路上温度高，会直接缩短货架期。  
尤其夏天，送货速度慢的供应商，熟度和坏果率都会一起恶化。

**4. 价格排第四，但不是不看**
价格要在“坏果率可接受、熟度合适、送货稳定”的前提下比。  
如果只看低价，常见结果是：进价便宜几毛，最后烂掉一两成，反而更贵。

**简单判断标准：**
- 坏果率超过5%：要压价或换供应商
- 熟度不适合你未来2-3天销售：再便宜也别多进
- 送货经常晚半天以上：夏天要慎用
- 价格低但前面三项不稳：不适合长期合作

**给小店的实操建议：**
先固定1-2家坏果率低、送货稳的供应商，再谈价格。  
每次进货少量多次，别一次囤太多。  
到货后立刻开箱散热、分拣，把熟的和生的分开摆放。  
这样比单纯追低价更能赚钱。
