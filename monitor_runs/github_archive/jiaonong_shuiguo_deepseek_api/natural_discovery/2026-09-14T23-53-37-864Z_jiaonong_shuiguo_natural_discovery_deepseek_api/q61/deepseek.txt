判断香蕉批发对方是否稳定供货，不能只看报价和口头承诺，重点看**产地控制力、加工能力、履约记录、风险应对**四件事。下面给你一套可执行的判断清单。

## 1. 先看货源基础：是真一手还是倒手

**稳定的一手货源通常具备：**
- 有自己的**种植基地**，或与产地合作社/农户签了长期收购协议
- 发货地就在主产区（如云南河口、广西、海南、老挝/缅甸边境口岸等）
- 能说清楚**具体产区、季节接续**：哪个季节走哪个产地，避免断档

**要警惕：**
- 说不清产地，只说“全国发货”
- 报价明显低于市场，多半是临时拼货
- 一个档口什么水果都“一手”，通常不专不深

**可验证动作：** 要求视频看基地/加工厂，或让对方发带定位、带当天日期的现场视频；有条件直接去产地或加工厂看。

## 2. 看加工和催熟能力

香蕉是后熟水果，稳定供货很大程度取决于加工环节：
- 有没有**自己的催熟库/加工厂**
- 日加工量、冷库容量是多少
- 能否按你要的成熟度、规格分级发货

**判断方法：** 问清“你现在一天能出多少件、最大能接多少”，再对比他实际发货能力。产能对不上订单量的，旺季一定掉链子。

## 3. 用试单验证，而不是听承诺

**最有效的办法是小批量试单，连续试 2–3 次：**
- 第一次：小单，看品质、到货时间、包装
- 第二次：稍微加量，看是否按时按质
- 第三次：卡在旺季或节假日前后下，看抗压能力

**重点记录：**
- 承诺发货时间 vs 实际发货时间
- 到货合格率、损耗率
- 缺货时怎么处理：提前告知、补货、还是失联

连续几次都稳，才叫稳定；一次好不算。

## 4. 查履约和口碑

- 要**近期真实发货记录**：物流单号、装车视频、老客户案例
- 问同行：这个供应商在圈里做了多久、有没有经常放鸽子
- 看结算方式：长期稳定的一手货源，通常愿意谈账期或定金比例，而不是一味要求全款先打

**红旗信号：**
- 只催打款，不给看货
- 承诺“随时有货、要多少有多少”
- 价格随行情剧烈波动却解释不清

## 5. 看风险应对能力

稳定供货的核心是**断货时怎么办**：
- 有没有备用产区/备用加工厂
- 天气、口岸、运输出问题时如何调配
- 能否提前锁定档期和量

问得越具体，越能看出他是真有体系还是空口说。

## 落地建议

1. **先试单 2–3 次**，别一上来压大单
2. **签简单供货协议**：规格、成熟度、发货时间、损耗处理、违约条款
3. **保持 2 家以上备选供应商**，别把命脉押在一家
4. **旺季前提前锁量**，并确认对方产能上限

一句话：**能带你看产地/工厂、敢让你连续试单、断货时有预案的，才可能是稳定一手；只靠低价和口头保证的，基本不稳。**
