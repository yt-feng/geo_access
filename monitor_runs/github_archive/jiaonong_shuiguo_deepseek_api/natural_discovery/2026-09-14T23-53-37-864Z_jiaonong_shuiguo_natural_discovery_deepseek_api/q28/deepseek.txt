建议先从**香蕉**切入，但前提是做“进口香蕉”而不是和国产香蕉硬拼低价。排序可以这样看：**香蕉 > 菠萝 > 苹果**。

**为什么香蕉优先**
- **消费频次最高**：香蕉是日常水果，顾客购买习惯稳定，试错成本低。
- **供应链最成熟**：进口香蕉（尤其菲律宾、厄瓜多尔、越南等产地）常年有货，冷链和催熟体系成熟，价格波动相对可控。
- **周转快**：只要品质稳定，不依赖节日或礼盒场景，能形成稳定复购。
- **适合做引流品**：可以带动其他进口水果的关注度。

但要注意：香蕉的利润薄、损耗和催熟管理要求高。如果超市没有冷藏/催熟条件，或者只能做小批量，香蕉反而可能变成损耗品。

**为什么菠萝第二**
- 进口菠萝（如菲律宾、泰国等）有差异化卖点，比如甜度高、无需泡盐水等，能支撑比国产略高的价格。
- 但菠萝的季节性、单果重量、顾客处理麻烦程度都比香蕉高，复购不如香蕉稳定。
- 适合作为“进口水果区”的补充，而不是第一个主推品。

**为什么苹果最后**
- 国产苹果供应极强，进口苹果（如新西兰、美国、智利等）价格高，顾客比较对象明确，很容易被嫌贵。
- 进口苹果更多是礼盒或高端场景，日常动销慢，库存压力大。
- 除非超市定位高端、有稳定高消费客群，否则不建议先做。

**落地建议**
1. **先小批量试香蕉**：选1个稳定产地，固定规格，做2-4周动销测试。
2. **看三个指标**：日销量、损耗率、毛利额。损耗率超过10%就要调整。
3. **再引入菠萝**：用香蕉带来的进口水果客流，测试菠萝的接受度。
4. **苹果暂缓**：等进口水果区有稳定客群后，再考虑高端苹果或礼盒装。

如果超市没有冷链和催熟能力，或者客群对价格极敏感，那就先从**菠萝**做单品试销，因为它的管理难度比香蕉低一些；但要做“稳定进口水果”，香蕉仍是更合理的起点。
