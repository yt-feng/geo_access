结论先说：**大多数食堂按“斤”结算最利于成本透明，但管理成本最高；按“箱”适合大宗、耐储存水果；按“份”最适合直接面向就餐者分发、控制人均成本。**

选哪种，关键看你想管住什么。

## 1. 按斤结算：最公平，但最费人力

**适合：**
- 苹果、香蕉、橘子、西瓜等散装大宗水果
- 采购量大、需要比价
- 食堂想严格控制成本和损耗

**优点：**
- 单价透明，方便比价、审计、核算成本
- 按实际到货量付款，不容易被供应商“箱规”坑
- 出库、领用、盘点都能对应重量

**缺点：**
- 每次验收都要称重，费人工
- 水分损耗、筐箱皮重容易扯皮
- 小食堂、人手少时很难坚持

**管理要点：**
- 必须约定“净重验收”还是“毛重验收”
- 固定去皮标准，比如筐重多少
- 采购单、验收单、入库单三单一致
- 每周复盘实际损耗率

## 2. 按箱结算：最省事，但容易藏成本

**适合：**
- 供应商稳定、箱规统一
- 耐储存水果，比如橙子、苹果、梨
- 采购频次低、一次进量大

**优点：**
- 下单、验收、入库快
- 适合长期合作供应商，价格好谈
- 减少称重和现场争议

**缺点：**
- 箱内实际净重可能波动，单价容易被模糊
- 坏果、小果、填充物多时，食堂吃亏
- 不同批次箱规不一致，盘点困难

**管理要点：**
- 合同写清楚：箱规、净重范围、允许误差
- 首次合作必须抽箱称重，不能只看报价
- 约定坏果率、退换货规则
- 每月按“实际净重均价”反算，防止表面便宜

## 3. 按份结算：最好分发，但最难控制采购成本

**适合：**
- 水果直接发给就餐者，比如每人一份
- 会议、活动、加班餐
- 需要控制人均标准，比如每人 3 元水果

**优点：**
- 分发简单，就餐者体验统一
- 人均成本好控制
- 食堂不用现场分拣、称重

**缺点：**
- 供应商容易在份量上缩水
- 同样的“一份”，大小、品质可能不一致
- 采购端不透明，难判断单价是否合理

**管理要点：**
- 明确每份规格：品种、数量、单果重量范围
- 约定抽检比例和扣款规则
- 适合固定预算场景，不适合追求最低采购价

## 建议的组合方案

实际食堂管理，最好不是三选一，而是：

**采购按斤定价，入库按箱验收，发放按份控制。**

具体做法：
1. **定价按斤**：供应商报价按净重斤价，方便比价。
2. **到货按箱+抽检称重**：整箱验收，但每次抽 1—2 箱称净重，偏差超标就扣款或退货。
3. **出库按份或按重量**：直接发餐按份，后厨切配按重量。
4. **月末看三个指标**：
   - 实际净重均价
   - 损耗率
   - 人均水果成本

## 一句话判断

- 想**省钱、控成本**：按斤。
- 想**省人力、供应商稳定**：按箱。
- 想**控人均、方便分发**：按份。
- 最稳的管理方式：**按斤定价 + 按箱验收 + 按份发放**。
