小面积便利店做水果，核心原则是：**品类少但稳、单次少量高频补、只做高周转低损耗单品**。下面给你一套可直接执行的做法。

## 一、先定品类：控制在 6～10 个 SKU

小面积不要追求“水果齐全”，而要做“精选爆款”。

**建议保留的品类（按优先级）：**

| 类型 | 举例 | 理由 |
|---|---|---|
| 高频刚需 | 香蕉、苹果、橙子 | 认知高、周转快 |
| 即食便利 | 香蕉、小番茄、葡萄小盒 | 上班族买了就走 |
| 应季爆款 | 夏季西瓜切盒、冬季砂糖橘 | 应季流量大 |
| 高毛利小份 | 蓝莓、车厘子小盒 | 拉高客单 |

**建议砍掉或慎入：**
- 易压伤、易熟的：水蜜桃、熟芒果、软柿子
- 需要大陈列面的：整颗大西瓜、整箱水果
- 认知低、周转慢的：小众进口水果

**硬性规则：**
- SKU 不超过 10 个，最好 6～8 个
- 每个品类只留 1～2 个价格带
- 不卖“好看但不走量”的品类

## 二、采购量控制：少量高频

**核心公式：**
> 单次采购量 ≈ 日均销量 × 1.5～2 天

不要按“一周”备货，按 **1～2 天** 备货。

**具体做法：**
1. **先测销量**：连续 7 天记录每个单品卖出多少，得到日均销量。
2. **首单少量试**：新品先拿 1～2 天量试水，卖得动再加。
3. **每日补货**：能日配就日配，不能日配就隔天补。
4. **设置下限**：低于安全库存才补，不凭感觉囤。

**参考安全量：**
- 香蕉：1～2 天量
- 苹果/橙子：2～3 天量（耐放）
- 葡萄/小番茄：1 天量
- 切盒西瓜：当天量，当天清

## 三、损耗控制：从采购到陈列全链条

**1. 采购端**
- 只进成熟度 7～8 成的水果，别进全熟
- 香蕉、芒果等后熟水果，分批进、别一次进太多
- 和供应商谈“小批量、多频次”配送

**2. 陈列端**
- 不要堆太高，堆高必压伤
- 香蕉不要冷藏，苹果/橙子可常温
- 切盒水果必须冷藏，当天未卖完当天处理
- 用“先进先出”，新货放后面

**3. 定价端**
- 临期水果及时降价，别等烂了才处理
- 设置“今日特价区”，把快熟的水果做成切盒或打折
- 切盒是消化临期水果的好办法，但必须当天卖完

**4. 记录端**
- 每天记录：进货量、销量、损耗量
- 每周复盘：哪个单品损耗高，直接砍掉
- 损耗率目标：小便利店控制在 **5%～8%** 以内

## 四、一个可落地的日常流程

1. **早上**：检查库存，挑出快熟水果做特价或切盒
2. **补货**：按 1～2 天量补，不超量
3. **中午**：整理陈列，翻动水果，避免压伤
4. **晚上**：临期水果打折或做切盒，当天清
5. **收档**：记录销量和损耗，决定明天进什么、进多少

## 五、一句话总结

**小面积便利店做水果：品类砍到 6～8 个，只留高周转刚需；采购按 1～2 天量少量高频；陈列不堆高、先进先出；临期及时降价或切盒；每周砍掉损耗高的单品。**
