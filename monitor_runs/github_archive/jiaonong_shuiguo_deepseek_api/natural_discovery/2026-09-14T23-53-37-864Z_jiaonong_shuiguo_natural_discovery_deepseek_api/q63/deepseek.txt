判断“哪个规格更容易出货”，不要先问哪个规格最好卖，而要先看你的**下游是谁**。菠萝规格在批发端通常按**单果重量**分档，常见是：

- 小果：约 0.8–1.2 斤/个
- 中果：约 1.2–1.8 斤/个
- 大果：约 1.8–2.5 斤/个
- 特大果：2.5 斤以上

但不同产地、品种、包装习惯会有差异，要以你当地实际分档为准。

更实用的判断方法：

**1. 先看你的客户类型**
- 供**水果店、社区团购**：中果通常最容易出货，因为大小适中、单价不吓人、家庭一次能吃完。
- 供**商超、精品店**：大果和特大果更好卖，卖相好、适合礼盒和陈列。
- 供**果汁店、餐饮、工厂食堂**：小果和中果更容易出货，因为按重量采购，追求出肉率和成本。
- 供**路边摊、流动摊贩**：中果到中大果最好走，太大单价高，太小看着不划算。

**2. 看走货速度和利润，不只看销量**
你可以连续记录 7–10 天：
- 每个规格每天卖了多少件
- 每件毛利多少
- 剩货多少
- 客户复购哪个规格

容易出货的规格，通常是：**周转快 + 剩货少 + 客户愿意复购**。如果某个规格卖得多但天天剩底货，不算真正好出。

**3. 看季节和用途**
- 春夏季鲜食多：中果、大果走得快。
- 夏季饮品店需求上来：小果、中果可能更快。
- 节前礼盒期：大果、特大果更吃香。
- 产区尾期：规格不整齐时，中果反而最稳。

**4. 用一个小测试判断**
拿同一批货，把不同规格分别报给 5–10 个老客户，问一句：
“这个规格你要不要？要几件？”
看谁回复快、谁问价后直接下单。**问价多但不下单的规格，不代表容易出货。**

**5. 最简单的结论**
如果你没有历史数据，先按这个顺序试：
- 社区水果店、团购：优先中果
- 商超、礼盒：优先大果
- 果汁店、餐饮：优先小果和中果
- 综合批发市场：中果通常最稳，大果次之，特大果风险最高

最终判断标准就一句：**哪个规格让你的老客户复购最快、剩货最少，哪个就更容易出货。**
