# 超市门店多、单店量不大，适合的水果供货模式

## 核心矛盾

你的情况本质是：**采购总量不小，但单店需求分散、单店起订量低**。这导致两个问题：
- 直接找产地/大批发商，对方嫌你单店要货少、配送麻烦
- 走本地小批发，价格没优势、品质不稳定

所以选模式的关键是：**把"多店小量"汇集成"总量集中"，同时解决最后一公里配送。**


## 推荐模式（按优先级）

### 1. 区域配送商 / 城市集配仓（最匹配）
找一个本地水果配送商，负责给你**所有门店统一分拣、统一配送到店**。
- 你只需对一个供应商下单，他按门店拆分配送
- 适合：门店在同一城市或邻近城市
- 谈的时候强调"总采购量"，而不是单店量
- 缺点：中间商加价，需谈好账期和损耗责任

### 2. 产地直采 + 第三方城市配送
自己对接产地或一级批发市场拿货，货到你的**中转仓/前置仓**，再由第三方城配分送到各店。
- 适合：你有能力建一个小中转仓，或已有仓库
- 优势：价格最优，品质可控
- 关键：必须解决"分拣+配送"这一段，否则多店会拖垮你

### 3. 供应商分级 + 单品聚焦
不要一家通吃。按品类拆：
- **走量大的单品**（苹果、香蕉、橙子等）：找产地或大批发直采
- **走量小、易损的单品**（浆果、进口果）：找本地配送商
- 这样既拿到主力的价格优势，又用小批量灵活补货

### 4. 联合采购 / 拼单平台
如果周边有同类小超市，可以联合下单凑量；或用生鲜B2B平台（如美菜类模式）按需下单到店。
- 优势：不用自己压货，起订量低
- 缺点：平台价格通常高于直采，品质稳定性看平台


## 判断标准（怎么选）

| 你的条件 | 优先模式 |
|---|---|
| 门店同城、无仓库 | 区域配送商 |
| 有中转仓、采购能力强 | 产地直采+城配 |
| 品类杂、单量小 | 分级供应+本地补货 |
| 想轻资产、不压货 | B2B平台/集配商 |


## 必须谈清楚的几件事

1. **配送频次**：能否按店、按需配送（而非整车到总仓）
2. **起订量**：是按总单算还是按单店算——务必按**总量**谈
3. **损耗责任**：水果损耗谁承担，验收标准写清楚
4. **账期**：生鲜供应商账期通常短，提前确认
5. **价格机制**：是否随行就市，多久调一次价

---

**一句话结论**：你的最优解大概率是**"本地集配商统一配送"为主 + 对走量大单品单独直采**，核心是把多店需求汇总成一个采购总量去谈，而不是让每个店单独找货。
