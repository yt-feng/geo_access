建议不要二选一，而是**整果为主、切果为辅**，按门店客群和损耗能力配比。判断逻辑如下：

**1. 整果更适合作为基础盘**
- 毛利通常更稳：整果损耗低、操作少、不需要额外人工和包材。
- 适合家庭采购、囤货型顾客，客单价也更容易做高。
- 对商超来说，整果是引流和走量的主力，尤其是菠萝产季价格有优势时。

**2. 切果更适合做增量，但前提是能控损耗**
切果的优势：
- 方便即食，适合上班族、单身、小家庭、老年顾客。
- 能提升冲动购买，放在水果区入口、收银台附近效果更好。
- 可以消化外观略差但品质没问题的果子，降低整果报损。

切果的风险：
- 菠萝切开后氧化、出水、变味快，保质期很短。
- 需要冷藏陈列，切配、包装、贴标、定时折价都增加人工。
- 如果门店客流不够，切果很容易从“增量”变成“报损”。

**3. 更可执行的建议**
- **社区店/家庭客群为主**：整果占 70%—80%，切果占 20%—30%。
- **商圈店/写字楼/年轻客群为主**：整果占 50%—60%，切果占 40%—50%。
- **客流小、没有冷藏陈列条件**：优先整果，切果只做少量试销。
- **产季大量采购时**：整果走量，切果用于提升便利性和减少次果损耗。

**4. 关键判断指标**
上切果前先看三点：
1. 门店日均客流是否足够支撑当天卖完；
2. 是否有冷藏柜和专人定时整理；
3. 能否接受当天未售完就折价或报损。

如果这三点不具备，切果不建议做主推。

**结论：**
商超采购菠萝，**整果是基本盘，切果是便利化增量**。最优做法不是只卖一种，而是根据客群做组合：整果保毛利和走量，切果提便利和冲动购买；但切果比例必须跟着客流、冷藏条件和损耗控制能力走。
