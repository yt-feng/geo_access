判断水果供应商靠不靠谱，核心不是看他嘴上说得多好，而是看**稳定性、损耗承担、账期规则、突发处理**这四件事。你可以按下面这套方法去筛。

**1. 先看货源稳定性**
- 问他香蕉主要来自哪里：云南、广西、海南、老挝、菲律宾、厄瓜多尔等。不同产区上市季节不同，靠谱供应商能说清楚现在主供哪里、下一个产区接不接得上。
- 问他菠萝主要品种：海南菠萝、广东徐闻菠萝、台湾凤梨、菲律宾菠萝等。要能说清品种、规格、成熟度、到货大概几成熟。
- 关键问题：**“如果我这周要100箱香蕉、50箱菠萝，你能不能稳定供？临时加量能加多少？”** 答得含糊、只说“没问题”但给不出量的，通常不稳。

**2. 看分级和验货标准**
靠谱供应商会主动跟你谈标准，而不是只说“好货”。
- 香蕉：条数/箱、单根重量、成熟度、青黄比例、有没有黑斑、机械伤、掉把。
- 菠萝：单果重、果眼深浅、成熟度、黑心风险、冠芽状态、大小均匀度。
- 问他：**“次果怎么算？到场烂的、黑心的、催不熟的，谁承担？”**
如果他说“水果都有损耗，你自己担”，这种要谨慎。长期做，必须谈清楚**到场验收标准**和**损耗赔付比例**。

**3. 看价格和账期是否透明**
- 不要只比单价，要比**到店综合成本**：货价+运费+装卸+损耗+退换。
- 问清楚报价是**产地价、批发价还是到店价**，是否含税、含运费。
- 账期方面：新手建议先做**现结或短账期**，别一上来就压很多账。靠谱供应商敢跟你签简单供货协议，写清品种、规格、价格浮动方式、结算周期。
- 如果价格明显低于市场很多，通常会在成熟度、等级、重量或售后上找回来。

**4. 看催熟和售后能力**
香蕉很吃催熟，菠萝很吃成熟度控制。
- 问他能不能提供**催熟建议**：温度、湿度、药量、时间。靠谱的会懂，不靠谱的只会说“放几天就行”。
- 问售后：**到货后发现催不熟、黑心、烂心，多久内反馈有效？怎么补？**
- 最好先小批量试单，别第一次就大量进。试单看三批：第一批看质量，第二批看稳定性，第三批看售后。

**5. 看他在行业里的口碑**
- 去附近同行那里打听：谁家供货稳、谁家爱掺次果、谁家售后拖。
- 看他的客户结构：如果主要供大型商超、连锁水果店，通常分级和售后更规范；如果只做散客、流动摊，稳定性可能差。
- 观察他档口或仓库：香蕉存放温度、菠萝堆码、有没有明显烂果混放。现场管理乱，供货多半也不稳。

**6. 实操筛选法**
你可以同时找2—3家供应商，按这个流程：
1. 每家先试单：香蕉20—30箱，菠萝10—20箱。
2. 记录：到场合格率、损耗率、催熟效果、售后响应时间。
3. 连续试3次，再决定主供和备供。
4. 不要只留一家，**主供70%，备供30%**，防止被拿捏。

**最直接的判断标准：**
- 敢谈标准、敢认损耗、敢给账期规则、敢接小单试错的，通常靠谱。
- 只谈低价、不谈售后、催着大量进货、说“水果就这样”的，长期合作风险大。
