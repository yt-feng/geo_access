提升水果区客单价，核心不是单纯打折，而是让顾客“多买一件、买大份、买搭配”。香蕉、菠萝、苹果这三种很适合做组合促销，因为它们价格带不同、用途互补、消费频次高。下面给你几套可直接落地的方案。

## 一、先定组合逻辑

- **香蕉**：高频、低价、易冲动购买，适合做引流品
- **菠萝**：客单价中等、有季节感、适合做利润或搭配品
- **苹果**：家庭常备、耐储存、适合做凑单和提升客单

组合目标：用香蕉引流，用菠萝提客单，用苹果凑满额。

## 二、可直接执行的促销组合

### 方案1：三果家庭装，直接提客单
**组合价：香蕉1把 + 菠萝1个 + 苹果4个 = 15.9/19.9元**
- 原价合计通常高于组合价2-4元
- 用统一保鲜袋或网兜打包，放在入口堆头
- 话术：“一家三口一周水果，一次买齐”

适合：社区超市、家庭客群。

### 方案2：满额换购，用香蕉引流
**买菠萝或苹果满15元，加3元换购香蕉1把**
- 顾客本来只买菠萝，可能为了换购再拿苹果
- 香蕉成本低，适合做钩子
- 换购价要明显低于单买价，但不要免费

适合：想提高客单但不想直接降菠萝、苹果价格。

### 方案3：早餐/下午茶场景组合
**香蕉2根 + 苹果2个 + 菠萝切盒1份 = 9.9元**
- 针对上班族、学生、年轻家庭
- 菠萝提前切盒，提升便利性和溢价
- 放在收银台附近或冷藏柜端头

适合：商圈店、写字楼店、年轻客群。

### 方案4：第二件半价，但限定组合
**买菠萝1个，苹果第二件半价；买苹果满10元，香蕉第二把半价**
- 不要全场第二件半价，否则伤毛利
- 只针对指定搭配，引导跨品类购买
- 价签写清楚：“搭配购买才享”

适合：水果区想做连带但不想全品类降价。

### 方案5：按份卖，不按斤卖
- 香蕉：1把约1kg，统一定价
- 菠萝：1个装袋，统一定价
- 苹果：4个/6个装盒，统一定价
- 再设“三样各1份 = 组合价”

按份卖能减少顾客比价，也更容易做组合价。

## 三、陈列怎么配合

1. **入口堆头放香蕉**：低价、颜色亮，吸引进店
2. **中间岛台放组合装**：三果家庭装、切盒组合
3. **苹果旁边放菠萝**：苹果是常购，菠萝是提升客单
4. **收银台放小份组合**：香蕉2根+苹果2个，冲动购买
5. **价签写结果，不写复杂规则**
   - 好：“三样一起买，省4元”
   - 差：“部分商品满额可享阶梯折扣”

## 四、定价建议

- 组合价 = 原价合计的 **85%-90%**
- 引流品香蕉可以让利多一些
- 苹果、菠萝保持正常毛利
- 组合装毛利可以低一点，但客单要明显上升

举例：
- 香蕉单买 5元
- 菠萝单买 8元
- 苹果4个 7元
- 合计20元，组合价 **16.9元**
- 顾客多买了原本不打算买的品类，客单从8元提到16.9元

## 五、最推荐先试的一套

如果只选一个方案，建议先做：

**“买菠萝+苹果满15元，加3元换购香蕉1把”**

理由：
- 不直接降菠萝、苹果价格
- 用香蕉做钩子，成本可控
- 能明显把只买一件的顾客拉到两件以上
- 执行简单，价签和收银都好操作

## 六、注意点

- 不要三种同时大特价，否则客单可能上去但毛利下来
- 组合装要限量，比如“每日限50份”，制造稀缺
- 香蕉熟得快，组合装当天打包当天卖
- 菠萝切盒要冷藏，标注切制时间
- 每天看数据：组合装销量、客单价、毛利率，三天不动就换位置或换价格
