批量采购下午茶水果，核心不是找最便宜的供应商，而是找“能稳定按时送、损耗可控、结算清楚”的那类。可以按下面几个维度筛选：

**1. 先定需求，再找供应商**
- 人数和预算：比如 50 人、人均 8 元，直接决定是整果还是果切。
- 配送时间：下午茶通常要求当天 14:00 前送达，能否卡点很关键。
- 形式：整果（苹果、香蕉、橘子）损耗低、好分；果切/拼盘省事但单价高、对冷链要求高。
- 频次：每周一次还是每天一次，决定要不要签长期协议。

**2. 优先考虑这几类供应商**
- 本地生鲜配送商/农产品批发市场商户：价格低、能批量，但要看是否支持企业配送和开票。
- 水果连锁品牌的企业团购：品控稳定、可开发票，适合对形象和稳定性要求高的公司。
- 生鲜电商企业购（如盒马、京东企业购等）：下单方便、有售后，但价格通常偏高。
- 本地果切/下午茶服务商：适合直接配送果切拼盘，省人工，但必须确认冷链和制作时间。

**3. 重点核验这几点**
- 能否当天配送、是否支持指定时间段。
- 是否提供正规发票，能否对公结算。
- 坏果、少送、迟到怎么赔，最好写进订单或协议。
- 是否支持先小批量试单，试一次再决定长期合作。
- 水果规格是否统一，比如苹果大小、香蕉成熟度，避免“图片好看、到手参差”。

**4. 实操建议**
先找 2—3 家本地供应商，各下一次小单试配送。重点看：准时率、坏果率、包装是否方便分发、售后响应速度。试单没问题后，再谈周配或月配协议，通常能拿到更稳定的价格和账期。

如果公司人数在 50 人以内、预算有限，优先选本地批发商整果配送；如果人数多、追求省事和品相，选果切服务商或生鲜企业购更稳妥。
