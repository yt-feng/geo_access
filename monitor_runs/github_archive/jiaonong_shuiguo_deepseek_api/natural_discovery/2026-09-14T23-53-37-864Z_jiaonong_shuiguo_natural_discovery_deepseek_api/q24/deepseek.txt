超市要防农残抽检风险，核心是让供应商提供**可追溯、可验证、能对应到具体批次**的资料。建议按下面清单提前要，不要只要一张“合格证”就完事。

## 一、基础资质资料

1. **营业执照**
2. **食品经营许可证/食品生产许可证**（视供应商类型）
3. **供货商与产地/合作社/基地的关系证明**
   - 直采合同
   - 合作社供货协议
   - 基地备案证明
4. **农产品质量安全承诺书**
5. **若为进口水果**
   - 入境货物检验检疫证明
   - 报关单
   - 海关相关合格证明

## 二、批次对应的检测资料（最关键）

按**每一批到货**要，不是只要年度报告：

1. **农药残留检测报告**
   - 最好由 CMA/CNAS 资质机构出具
   - 报告日期要覆盖本批次
   - 检测项目建议覆盖：
     - 有机磷类
     - 氨基甲酸酯类
     - 拟除虫菊酯类
     - 杀菌剂类
     - 高毒禁限用农药
2. **快检报告或基地自检记录**
   - 适合作为辅助，不能替代法定检测
3. **承诺达标合格证**
   - 很多农产品已推行，可作为基础凭证
4. **批次追溯信息**
   - 采摘日期
   - 包装日期
   - 产地地块/大棚编号
   - 批次号/追溯码

## 三、种植和用药管理资料

1. **农业投入品使用记录**
   - 农药名称、成分、用量、施药时间、安全间隔期
2. **采收记录**
   - 是否严格执行安全间隔期
3. **基地土壤、水源、环境检测**（如有）
4. **绿色食品、有机、GAP 等认证**（如有）
   - 认证不能代替批次农残检测，但可作为加分项

## 四、物流与验收资料

1. **发货单/送货单**
   - 品名、数量、批次、产地、车牌
2. **运输温度记录**
   - 尤其冷藏水果
3. **到货验收记录**
   - 超市自己也要留
4. **不合格处理约定**
   - 退换货
   - 赔偿
   - 抽检不合格责任归属

## 五、合同里要写清楚

建议在采购合同或质量协议中明确：

1. 供应商必须按批次提供检测报告或合格证
2. 检测项目、频次、标准由超市确认
3. 超市有权自行送检
4. 若抽检不合格：
   - 供应商承担检测费、罚款、下架损失、赔偿
5. 提供虚假资料的责任
6. 追溯时限要求，比如 2 小时内提供批次资料

## 六、最实用的索要话术

可以直接发给供应商：

> 请随每批到货提供：营业执照、食品经营许可证、本批次农残检测报告或承诺达标合格证、产地证明、批次追溯信息、送货单。检测报告须有 CMA/CNAS 资质，检测项目覆盖有机磷、氨基甲酸酯、拟除虫菊酯及禁限用农药。资料不全或批次不对应，收货时不予验收。

## 七、优先级排序

如果供应商一时给不全，至少先要：

1. **批次农残检测报告**
2. **承诺达标合格证**
3. **产地/批次追溯信息**
4. **营业执照和食品经营许可证**
5. **合同中的质量责任条款**

一句话：**年度报告不如批次报告，复印件不如可追溯原件，合格证不如对应批次的农残检测。**超市要把“每批可查、责任可追”作为验收门槛。
