做大客户的核心不是“给账期换订单”，而是**把信用变成可控的生意条件**。水果这行损耗高、价格波动大，账期和额度谈不好，很容易变成你替对方承担风险。

下面按可执行的方式拆开讲。

## 一、先想清楚：你能让渡什么，要换回什么

**你能给的：**
- 账期（资金占用时间）
- 额度（最多欠多少）
- 价格稳定性 / 优先供货
- 品控、分拣、配送、退换货
- 旺季锁量

**你要换回的：**
- 最低采购量 / 月采购额承诺
- 独家或优先采购比例
- 结算准时率
- 价格随行就市但不过度压价
- 预付款或保证金

**原则：账期和额度不是白给的，必须绑定采购承诺和违约成本。**

## 二、账期怎么谈

水果行业常见账期从现结、周结、半月结到月结，30天以上已属较优条件。建议这样设计：

**1. 新客户一律不赊，或只给小额度短账期**
- 先做现结/周结，跑2-3个月，看回款、看退货率、看沟通配合度。
- 稳定后再谈账期，不要一上来就月结。

**2. 账期逐步升级，不要一步到位**
- 现结 → 7天 → 15天 → 30天
- 每次升级都对应采购量或采购占比的明确提升。

**3. 账期起算点写清楚**
- 是“发货日”“到货日”“对账确认日”还是“开票日”？
- 建议用**对账确认后起算**，避免对方拖着不对账。

**4. 设账期上限和封顶条件**
- 例如：账期30天，但单笔欠款不超过X万，累计不超过Y万。
- 一旦超限，自动转现结或停止发货。

**5. 绑定回款节点**
- 例如每周固定一天对账，次周固定一天付款。
- 把“付款日”写进合同，不要靠催。

## 三、额度怎么谈

额度不是拍脑袋，要按你的**资金承受能力 + 对方信用 + 采购规模**算。

**1. 先算你的底线**
- 你最多能压多少货款不影响进货和周转？
- 假设你月流水100万，现金流能承受的应收上限可能只有15-25万。
- 超过这个数，即使客户再好也不能给。

**2. 额度与采购额挂钩**
- 建议初始额度 = 对方月均采购额的50%-100%，且不超过你能承受的上限。
- 例如对方月采购20万，你可以给10-15万额度，30天账期。
- 采购量涨了，额度再谈，但要有观察期。

**3. 设置动态额度**
- 基础额度 + 临时额度
- 旺季可临时上浮，但要约定临时额度到期必须清零。
- 连续3个月准时回款，可上浮；逾期一次，下调或暂停。

**4. 额度封顶 + 超限处理**
- 超额度部分必须现结或预付。
- 超限不发货，写进合同，执行要硬。

## 二、合同里必须写清楚的条款

- **账期起算和付款日**
- **额度上限和超限处理**
- **逾期违约金**（例如日万分之几，或按LPR加几点）
- **逾期暂停供货权**
- **对账义务和时限**（对方多久内确认，不确认视为认可）
- **质量争议和退货处理**（水果易腐，必须约定验收时限，超时视为合格）
- **价格调整机制**（随行就市，还是锁价多久）
- **最低采购承诺和未达标补偿**
- **担保措施**（保证金、法人连带、抵押、第三方担保）

## 三、实操谈判节奏

**第1步：先小后大**
- 先给现结/周结的小单，观察2-3个月。
- 看回款是否准时、退货是否合理、是否压价过分。

**第2步：用“升级”换“承诺”**
- “我们可以给15天账期，但月采购不低于X万，且准时付款。”
- “额度可以到Y万，但需要预付10%保证金或法人担保。”

**第3步：把风险写进价格**
- 如果对方非要长账期大额度，价格上要留出资金成本。
- 例如30天账期，报价里加1%-2%的资金成本，或减少返利。

**第4步：设置退出机制**
- 连续逾期、采购量不达标、恶意压价，可降级或终止。
- 终止后欠款一次性结清。

## 四、几个关键判断

**可以给的条件：**
- 对方采购稳定、回款准时、退货率低、沟通顺畅。
- 你能承受的最大应收不超过现金流安全线。

**不能给的条件：**
- 一上来就要60天账期+大额度。
- 不提供任何担保、不承诺采购量。
- 你自身现金流紧张，靠赊销换订单。
- 对方同时压价、压账期、压退货。

**一句话：账期和额度是信用工具，只能给经过验证的客户，并且必须绑定采购承诺、担保和违约成本。**
