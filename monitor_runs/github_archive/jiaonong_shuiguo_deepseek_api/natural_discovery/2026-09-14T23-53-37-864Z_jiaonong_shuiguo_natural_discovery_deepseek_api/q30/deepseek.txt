超市水果到货后发现品相不好，售后流程的核心是：**先分清是“外观瑕疵”还是“腐烂变质/规格不符”，再按合同或验收单约定的时限、证据、处理方式走。** 建议在采购合同或到货确认单里直接写清楚，避免事后扯皮。

可以这样约定：

**1. 验收时限**
- 到货后 **2小时内** 做外观抽检，**24小时内** 完成全面验收。
- 超过约定时限未提出异议，视为验收合格；但腐烂、变质等隐蔽问题可在 **48小时内** 凭照片/视频补报。

**2. 品相标准**
- 写明品种、等级、单果重量/直径、成熟度、色泽、允许瑕疵比例。
- 例如：碰伤、压伤、黑斑、裂口、软烂果比例不得超过 **3%—5%**，超过部分按不合格处理。

**3. 证据要求**
- 到货现场拍：整车/整批、外包装、标签、抽检过程、问题果特写。
- 保留：送货单、验收单、聊天记录、称重记录。
- 最好双方现场共同确认，签字或拍照留痕。

**4. 处理方式**
按不合格比例分档：
- **轻微超标**：降价接收，按不合格部分扣款。
- **中度超标**：退货或换货，运费由供货方承担。
- **严重腐烂/变质/规格严重不符**：整批拒收，供货方承担退货运费及因此造成的合理损失。

**5. 退款/换货时限**
- 确认责任后 **24小时内** 给出补货或退款方案。
- 退款到账不超过 **3—7个工作日**。
- 换货到店不超过 **24—48小时**，生鲜类尽量当天补。

**6. 责任与免责**
- 因运输、冷链、包装不当导致品相问题，由供货方负责。
- 因超市收货后存放不当导致，由超市负责。
- 不可抗力可协商，但需及时通知并提供证明。

**7. 争议解决**
- 先协商；协商不成按合同约定的仲裁或诉讼处理。
- 建议约定“问题批次货款可暂扣，待处理完再结算”。

**实操建议：**
最稳妥的是在采购合同里加一张《到货验收及售后标准表》，把品类、验收时限、瑕疵率、扣款比例、退换货时限都列成表格。每次到货按表验收、拍照、签字，售后就按表执行，基本不会扯皮。
