分品类看：

**香蕉**
- 香蕉通常是青蕉采购，需要催熟后销售。
- 起订量太高会导致：一次性催熟量过大，短期内卖不完，后熟过快，很快出现黑斑、软烂。
- 损耗主要来自：催熟节奏失控、压货、温度波动。
- 香蕉对乙烯敏感，堆积太密、通风差会加速成熟。

**菠萝**
- 菠萝相对耐储，但起订量高仍有风险。
- 风险主要在：成熟度不一致、运输磕碰、长期存放后内部褐变或腐烂。
- 如果是鲜切或即食用途，对成熟度和外观要求更高，压货损耗会更明显。

**判断是否高风险，看这几个条件：**
1. 日均销量是否稳定，能否在 3–7 天内消化完。
2. 是否有冷库、催熟房、分温区储存条件。
3. 采购的是青蕉还是熟蕉，菠萝是几成熟。
4. 供应商是否允许分批到货，而不是一次性压到仓。
5. 下游是否有促销、加工、团购等兜底渠道。

**可执行建议：**
- 优先谈“分批到货”或“阶梯起订”，而不是一次性大单。
- 香蕉按催熟批次下单，不要一次把未来两周的量全催熟。
- 菠萝按成熟度分等级采购，先卖熟度高的，青的短存。
- 算一个简单阈值：起订量 ÷ 日均销量 = 可售天数。超过 5–7 天，损耗风险明显上升。
- 如果只能高起订量采购，先确认有没有低价处理渠道，否则不建议接。

所以，起订量高本身不是绝对问题，关键是**消化速度、储存条件和到货节奏**是否匹配。匹配不好，损耗几乎一定会增加。
