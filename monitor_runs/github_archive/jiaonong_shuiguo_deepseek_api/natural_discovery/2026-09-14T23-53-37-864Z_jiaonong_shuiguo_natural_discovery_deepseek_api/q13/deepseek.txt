小区团购的核心不是“团购”本身，而是**稳定、低损耗、能按需供货**。对小水果店来说，供应商至少要支持下面这些服务，否则你会被售后和损耗拖垮。

**1. 按团购节奏供货**
- 支持**提前1-2天下单**，而不是当天临时要货。
- 能按你预估的团购量供货，**允许小批量多频次**，比如今天订30份、明天订50份。
- 最好能配合**固定截单时间**，比如每晚8点截单，第二天早上到货。
- 能接受**临时加单/减单**，但要有明确截止时间，避免你团了却拿不到货。

**2. 品控和分级**
- 能提供**团购专供规格**，比如统一大小、统一成熟度，避免这批甜那批酸。
- 支持**样品确认**，你先看货再定长期合作。
- 坏果、烂果、次果有明确**赔付或补货标准**。
- 最好能按**小区团购场景**分装，比如5斤装、10斤装、家庭装。

**3. 价格和结算灵活**
- 给**团购价**，比普通批发价更有优势，或者按量阶梯降价。
- 支持**一件代发/整车配送/自提点配送**，看你小区团购怎么做。
- 结算方式灵活：现结、周结、月结，或者押金+账期。
- 价格波动大的水果，能提前锁价或约定浮动范围。

**4. 配送和时效**
- 能送到你店里、小区自提点，或者直接分送到多个小区。
- 配送时间稳定，最好**早上到货**，方便你当天分拣和通知取货。
- 有冷链或保鲜措施，尤其是浆果、荔枝、樱桃这类易坏水果。
- 出现缺货、延误时，能提前通知并给替代方案。

**5. 售后和损耗承担**
- 坏果、少货、错货能**快速补发或退款**。
- 有明确的售后响应时间，比如2小时内处理。
- 愿意承担一部分团购损耗，或者给你**损耗补贴**。
- 能提供**售后凭证**，方便你在群里向邻居解释。

**6. 营销和素材支持**
- 提供**水果图片、文案、卖点**，方便你发小区群。
- 能配合做**爆品推荐**，比如本周主推什么、什么适合团。
- 支持**试吃装、小份装**，降低邻居第一次下单门槛。
- 有稳定货源，不会今天推了明天就断货。

**7. 数据和对接**
- 能提供**每日/每周报价单**。
- 支持微信、电话、小程序或表格下单。
- 能给你**库存和到货通知**，避免你超卖。
- 如果你做接龙团购，供应商能配合按名单分装最好。

**你筛选供应商时，重点问这8个问题：**
1. 团购价怎么算，量大了能不能再低？
2. 提前多久下单，能不能临时加单？
3. 坏果怎么赔，多久处理？
4. 能不能按小区团购规格分装？
5. 配送费怎么算，能不能送多个小区？
6. 价格波动时怎么锁价？
7. 能不能先给样品和报价单？
8. 断货时有没有替代品或补偿？

**最实用的建议：**
先不要找大供应商，先找**本地批发市场里能做小批量、愿意配合分装、售后爽快**的供应商。你先跑通一个小区，测试3-5个爆品，把损耗和售后流程走顺，再扩到周边小区。供应商能不能支持“小批量+稳定品控+快速售后”，比价格低更重要。
