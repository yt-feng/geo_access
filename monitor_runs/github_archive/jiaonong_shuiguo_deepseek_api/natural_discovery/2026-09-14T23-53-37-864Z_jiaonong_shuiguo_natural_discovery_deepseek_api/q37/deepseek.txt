商超做会员日水果活动，供应商要提前配合的重点，不是只把货送来，而是围绕**爆量、低毛利、高损耗、强时效**这四个特点做准备。建议按下面清单推进。

**1. 提前确认活动方案**
供应商要先和商超确认清楚：
- 活动时间、门店范围、线上是否同步
- 引流单品、爆款单品、利润单品分别是什么
- 目标销量、日均销量、峰值销量
- 促销价、供货价、毛利承担方式
- 是否限购、是否叠加优惠券、是否做第二件折扣

这些没确认，后面备货和定价都会乱。

**2. 备货要按“峰值”而不是“日均”准备**
水果会员日通常销量会突然放大，供应商至少要准备：
- 活动预估销量的 1.2～1.5 倍货源
- 爆款单品额外安全库存
- 替代品种，防止某个单品断货或品质不达标
- 分批次到货计划，避免一次性到店导致压货和损耗

特别是叶菜类、浆果类、熟度高的水果，不建议一次性大批量压到门店。

**3. 品质和规格必须提前锁定**
会员日最容易出问题的是“低价但品质差”。供应商要提前做到：
- 明确果径、糖度、成熟度、净重、箱规
- 提供样品并封样，避免到货标准不一致
- 活动前 3～5 天开始控货，不把尾货、二级果混入
- 对易损水果加强包装，如草莓、蓝莓、葡萄、车厘子
- 标注采摘/加工日期，保证货架期

**4. 物流和到货节奏要配合门店**
水果活动讲究时效，供应商要提前安排：
- 根据门店订单分仓、分线路配送
- 重点门店优先送、早送
- 活动前一天完成首波铺货，活动当天早晨补货
- 避开商超收货高峰，提前预约送货时段
- 准备应急补货车辆和人员

如果商超是多门店联动，最好按门店销量分级配送，不要平均铺货。

**5. 价格和费用提前谈妥**
供应商要提前确认：
- 供货价是否含税、含运费
- 促销折扣由谁承担，承担比例多少
- 损耗谁负责，是否给损耗补贴
- 堆头费、DM 费、海报费、线上推广费
- 临期、滞销、品质不达标是否退换货
- 结算周期和扣款方式

这些一定要在活动前形成书面确认，避免活动后扯皮。

**6. 物料和陈列支持**
供应商可提前配合提供：
- 试吃台、试吃果、牙签、手套、垃圾袋
- 价签、爆炸贴、海报、跳跳卡
- 陈列筐、垫纸、假底、分层道具
- 员工推荐话术和产品卖点
- 线上图文素材、短视频素材

如果是重点单品，最好安排促销员驻场，负责试吃、补货、挑拣和现场处理。

**7. 人员安排**
供应商要提前明确：
- 谁对接采购
- 谁对接门店收货
- 谁负责活动当天巡店
- 谁处理缺货、品质投诉、临时补货
- 是否有驻场促销员，几点到店

会员日当天最好有专人巡店，发现断货、品质差、陈列乱，能马上处理。

**8. 风险预案**
提前准备这些异常处理方案：
- 爆款断货：替代单品、紧急调货
- 品质投诉：退换货、现场挑拣、补损
- 天气影响：雨天、高温对到货和销量的影响
- 价格错误：价签和系统价格不一致
- 竞品截流：周边商超同步促销时的应对

**9. 活动后复盘**
活动结束后 1～3 天内，供应商要和商超一起复盘：
- 实际销量 vs 预估销量
- 断货率、损耗率、退货率
- 毛利是否达标
- 哪些单品值得下次主推
- 哪些门店表现好，哪些门店需要调整
- 费用是否合理，结算是否顺畅

**一句话总结：**
供应商提前配合的核心是：**方案确认、按峰值备货、锁品质规格、保时效配送、谈清费用、配齐物料人员、做好风险预案。**  
其中最重要的是：**别只备货，要备“能卖得动、不断货、损耗可控”的货。**
