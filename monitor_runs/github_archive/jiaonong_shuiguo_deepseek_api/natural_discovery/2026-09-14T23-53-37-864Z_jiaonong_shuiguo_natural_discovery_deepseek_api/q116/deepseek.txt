小商家采购水果，现金结算和月结账期的风险不一样，核心区别是：现金结算主要承担“钱货两清后的质量与价格风险”，月结主要承担“赊账后的信用与现金流风险”。

**一、现金结算的风险**

1. **质量售后被动**
   - 钱已付清，后续发现烂果、规格不符、重量不足，追偿难度大。
   - 对方可能只愿意补一点，或者直接不认。
   - 应对：当场验货、拍照、称重，约定“验收后X小时内可退换”，尽量留书面或聊天记录。

2. **价格谈判空间小**
   - 现金容易让供应商觉得你“急要货”或“不懂行”，报价可能偏高。
   - 尤其水果价格波动大，现结不一定拿到最低价。
   - 应对：多问两三家，按箱/按斤比价，固定几个稳定供应商。

3. **现金管理风险**
   - 大额现金交易容易出错、丢失、被偷。
   - 账目不清，月底算不出真实毛利。
   - 应对：尽量转账，保留收据或转账备注；现金也要当场记账。

4. **供应商稳定性风险**
   - 现结关系弱，行情好时供应商可能优先供月结大客户。
   - 旺季缺货时，你可能拿不到好货。
   - 应对：不要只靠一家，至少维护2—3个备选渠道。

5. **税务与凭证风险**
   - 现金采购常拿不到发票或合规凭证。
   - 后续做账、报税、成本核算会有麻烦。
   - 应对：能要发票就要，至少保留收据、转账记录、送货单。

**二、月结账期的风险**

1. **信用风险最大**
   - 货先拿走，钱后付，供应商可能突然要求提前结、停止供货，甚至起诉。
   - 如果你经营波动，容易陷入“旧账未清、新货不供”的局面。
   - 应对：合同写清账期、对账日、付款日、逾期后果；不要口头约定。

2. **现金流风险**
   - 月结容易让商家误以为“资金宽裕”，实际是欠款。
   - 水果损耗快、毛利薄，一旦销售慢，账期到了却没钱付。
   - 应对：按周核算应付账款，预留至少一期货款，不把月结当利润。

3. **采购价可能更高**
   - 供应商会把资金占用成本、坏账风险算进价格。
   - 表面月结方便，实际单价可能比现结高。
   - 应对：对比“现结价”和“月结价”，算清真实成本。

4. **对账纠纷**
   - 水果批次多、损耗多、退换多，月底对账容易扯皮。
   - 重量、等级、烂果扣款、临时调价都可能成为争议点。
   - 应对：每批送货单当天签字确认，退换货当天记录，月底只做汇总确认。

5. **依赖风险**
   - 月结让你依赖某个供应商，对方一旦涨价、断供，你短期难切换。
   - 可能被要求接受较差品质或搭配采购。
   - 应对：月结供应商可以有一个主渠道，但必须保留现金采购的备用渠道。

6. **法律与催收风险**
   - 逾期不付，供应商可能停供、扣货、起诉，影响门店信誉。
   - 如果是个体户或小公司，个人资产也可能受牵连，取决于合同和主体形式。
   - 应对：不要超额赊账，合同主体写清楚，避免个人无限兜底。

**三、给小商家的实用建议**

- **新手或小量采购：优先现金/现结**，但必须当场验货、留凭证。
- **销量稳定后再谈月结**，账期从7天、15天开始，不要一上来就30天。
- **现结压价，月结控量**：现结争取低价，月结控制欠款上限。
- **每批货当天确认**：品种、数量、单价、损耗、退换，避免月底扯皮。
- **保留两个渠道**：一个现结灵活补货，一个月结稳定供货。
- **算真实成本**：月结价减现结价，再考虑资金占用和坏账风险，不一定划算。

一句话总结：**现金结算怕“货不对板没处追”，月结账期怕“账越滚越大、现金流断掉”。** 小商家最稳的做法是：现结为主、月结为辅，月结必须合同化、限额化、对账日常化。
