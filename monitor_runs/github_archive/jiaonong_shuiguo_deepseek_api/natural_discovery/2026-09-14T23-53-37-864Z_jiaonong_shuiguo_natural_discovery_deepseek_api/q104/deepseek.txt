单位采购水果出现品质不一致，核心是把“验收标准”和“售后规则”提前写进订单或合同，到货后按同一套标准执行。可按下面操作。

## 一、采购前先把标准定清楚

不要只写“新鲜、优质”，要量化：

1. **品种、规格、产地**：如红富士80mm以上、单果重200g以上。
2. **成熟度**：如香蕉七成熟、芒果八成熟。
3. **外观**：允许轻微果锈、不影响食用；不允许霉斑、腐烂、明显压伤、虫蛀。
4. **糖度/口感**：有条件可约定糖度范围或试吃标准。
5. **包装**：箱规、净重、是否含冰袋、防压措施。
6. **批次一致性**：同一批次颜色、大小、成熟度应基本一致，不能混装尾货。
7. **验收时限**：到货后多久内验收，如2小时内或当天。
8. **不合格比例**：如抽检不合格率超过5%，整批拒收或按比例扣款。

## 二、到货验收怎么做

建议“先拍照、再抽检、后签收”。

### 1. 到货前
- 要求供应商提前发发货清单、批次照片、采摘/分拣时间。
- 安排两人以上验收，避免单人判断争议。

### 2. 到货时
- 先拍整车/整托盘照片、外包装照片。
- 核对品种、数量、规格、产地、批次是否与订单一致。
- 检查运输温度、是否有挤压、水渍、异味。

### 3. 抽检方法
- 按箱抽检，不要只开一箱。
- 大货可按5%—10%抽检；批量小则逐箱检查。
- 每箱随机取上、中、下三层，避免只查表面。
- 记录：总箱数、抽检箱数、不合格果数、不合格类型。

### 4. 判定标准示例
- 腐烂、霉变、虫蛀：直接不合格。
- 压伤、裂口、破皮：超过约定比例即不合格。
- 大小、颜色、成熟度明显不一致：按批次一致性问题处理。
- 净重不足：按实际净重结算或补货。

### 5. 签收注意
- 不要先签“全部合格”再慢慢检查。
- 可在签收单上备注：“已抽检，发现XX箱存在XX问题，待处理”。
- 不合格部分单独存放、拍照、封样，避免和合格品混放。

## 三、售后怎么处理

根据问题程度分档：

| 问题程度 | 处理方式 |
|---|---|
| 少量轻微不一致 | 按比例扣款，或下次补货 |
| 部分腐烂、压伤 | 不合格部分退货、换货或折价 |
| 不合格率较高 | 整批退货，供应商承担运费 |
| 影响使用/活动 | 要求补货并赔偿延误损失 |
| 多次出现 | 终止合作，列入不合格供应商 |

建议约定：
- **补货时限**：如24小时内补到。
- **退换货费用**：质量问题由供应商承担。
- **扣款方式**：按不合格数量×单价，或按整批比例扣款。
- **留证要求**：照片、视频、称重记录、签收备注。

## 四、和供应商沟通的话术

可以这样说：

> 本批到货抽检XX箱，发现XX箱存在腐烂/压伤/规格不符，不合格率约XX%。请按合同约定在XX小时内补换货，不合格部分我们单独存放并拍照留证。若未按时处理，将按订单约定扣款或退货。

## 五、建议留存的证据

1. 采购订单、合同、聊天记录。
2. 到货照片、视频。
3. 抽检记录表。
4. 称重记录。
5. 签收单备注。
6. 与供应商沟通记录。
7. 不合格样品封存照片。
