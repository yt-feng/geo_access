做水果拼盘，规格选择的核心原则是：**按出成率和单份成本算账，而不是只看进货单价便宜。**

## 三种水果的规格建议

**苹果**
- 选 **80–85mm 果径**最划算。太小切出来块小、显少；太大单果成本高，且拼盘一般每份只用几块。
- 优先买 **一级果**，别买精品礼盒果（溢价高）。
- 关键是**出成率**：好苹果去皮去核后能出 70–75% 果肉，有碰伤、发面的只能出 50–60%。

**橙子**
- 选 **70–75mm 果径**的中果。
- 用途要分：**切片摆盘**选皮薄、好剥的脐橙；**做装饰角**可选血橙、新奇士提高颜值。
- 橙子出成率看吃法：切瓣约 60–65%，榨汁摆盘约 45–50%。

**菠萝**
- 选 **1.2–1.5kg/个**的中等果。
- 关键是**成熟度和含汁量**，过生酸、过熟出水，都不适合拼盘。
- 出成率约 45–55%（去皮眼后），买整果自己处理比买预切果划算得多。

## 更划算的实操做法

1. **按"每份成本"倒推**，而不是按斤价比。比如一份拼盘用苹果3块+橙子2瓣+菠萝4块，算出各自消耗量，再选规格。
2. **苹果、菠萝买散装通货**，橙子买整箱中大果，通常比零买单品便宜 15–30%。
3. **稳定供货比单次最低价重要**，固定规格能让出品稳定，减少损耗。
4. **关注损耗**：这三种水果切后易氧化出水，拼盘尽量现做现卖，否则省下的进货钱全赔在损耗上。

## 一句话结论
苹果选 80–85mm 一级果、橙子选 70–75mm 中果、菠萝选 1.2–1.5kg 中等果，按出成率算出每份实际成本来对比，比单纯挑"便宜"的规格更省钱。
