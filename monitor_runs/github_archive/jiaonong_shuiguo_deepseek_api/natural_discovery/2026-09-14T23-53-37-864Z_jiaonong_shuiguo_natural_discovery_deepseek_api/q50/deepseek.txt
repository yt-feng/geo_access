优先看**出汁率**，但前提是甜度达标、风味正常。两者不是二选一，而是有先后和底线。

简单判断顺序：

1. **先定甜度底线**
   菠萝本身甜度太低，后面靠糖浆硬补，会变成“糖水味”，盖掉果香，还增加糖成本和配方波动。  
   所以甜度不能太差，至少要稳定、能用。

2. **再看出汁率**
   茶饮店用菠萝，通常要的是果汁、果肉、果酱感或直接做果茶。出汁率低意味着：
   - 同样重量出不了多少汁；
   - 原料成本变高；
   - 备料时间长、损耗大；
   - 配方稳定性差。  
   所以从门店经营角度，出汁率往往更直接影响成本和效率。

3. **还要看出汁后的风味**
   有些菠萝出汁率高，但酸涩重、香气淡、纤维粗，做出来不好喝。  
   这种“高出汁率”没有意义。

实际选购建议：

- **做果汁/果茶主料**：出汁率优先，甜度达标即可，酸甜比稳定更重要。
- **做装饰、果肉粒、菠萝片**：果肉完整度、纤维口感、甜度优先，出汁率次要。
- **做果酱/熬煮类**：出汁率和果胶、纤维有关，但甜酸平衡和香气更重要。
- **如果只能二选一**：  
  - 门店走量、成本敏感：选**出汁率更高**的。  
  - 高端鲜果茶、强调风味：选**甜度和香气更好**的。  
  - 但甜度低于底线、需要大量加糖补救的，直接淘汰。

一句话：**甜度是底线，出汁率是效率，风味是决定复购的关键。采购时先卡甜度底线，再在同甜度档里选出汁率最高的。**
