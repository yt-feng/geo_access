这三个不是"选一个"的问题，而是要排优先级。对团购团长来说，正确的顺序是：

**配送 > 售后 > 价格**

原因很简单：

**配送是第一位的，因为它是你无法补救的环节。**
水果是生鲜，团长最怕的是"货到不了"或"到得太晚"。你可以在群里道歉、可以退款，但用户当天没收到水果、或者收到的时候已经压烂了，这个体验是补不回来的。配送不稳的供应商，价格再低、售后再好，都会持续消耗你的信任。所以先确认：能不能定时定点送到？坏天气怎么办？爆单了能不能加车？迟到了怎么赔？

**售后是第二位的，因为它决定了你出事时能不能兜住。**
水果一定有损耗，关键是出问题后供应商认不认、快不快。要问清楚：烂果坏果的赔付标准是什么？是拍照即赔还是必须退回？多久到账？有没有免赔额或"超过X%才赔"的门槛？售后爽快的供应商，能让你在群里快速给用户交代，保住口碑。

**价格放最后，不是不重要，而是它最容易让人踩坑。**
价格低往往意味着要么配送凑合、要么售后扯皮。团长真正该算的是"综合成本"：低价但损耗高、售后难，最后你自己贴钱又贴时间，反而更贵。

**给你的实操建议：**
先用配送和售后筛掉不合格的供应商，剩下来的再比价格。谈的时候把配送时效、售后赔付标准写进约定，别只听口头承诺。可以先用小批量试单，重点观察"迟到率"和"售后响应速度"这两项，再决定要不要长期合作。
