需要，而且这两项通常是企业福利采购的基础门槛，不是可选项。

具体判断如下：

1. **开发票：必须支持**
   - 企业采购要入账、报销、做税前扣除，通常需要合规发票。
   - 优先确认：能否开**增值税专用发票**或**普通发票**，发票内容能否开成“水果”“食品”“福利品”等符合财务要求的名目。
   - 如果供应商只能开收据或不能开票，基本不建议合作，后续财务可能不认。

2. **定制包装：建议支持，很多场景下是刚需**
   - 企业福利礼盒通常需要体现公司标识、节日祝福、员工关怀主题。
   - 常见定制包括：外盒LOGO、腰封、贺卡、手提袋、封签等。
   - 如果只是内部发放、预算有限，也可以接受供应商标准包装；但若是节日福利、客户答谢、年会礼品，定制包装通常能明显提升体验。

3. **采购前建议重点确认**
   - 发票类型、税率、开票时间、是否另加税点。
   - 定制包装的起订量、打样费、设计费、周期、是否支持小批量。
   - 水果礼盒的规格、产地、净重、损耗赔付、配送时效。
   - 是否支持分地址发货、员工签收、售后补发。

4. **结论**
   - **开发票：必须支持。**
   - **定制包装：最好支持；如果用于企业统一福利或对外赠送，基本应作为供应商筛选条件。**
   - 如果供应商只能满足其一，优先保留“能开票”；定制包装可根据预算和场景再谈。
