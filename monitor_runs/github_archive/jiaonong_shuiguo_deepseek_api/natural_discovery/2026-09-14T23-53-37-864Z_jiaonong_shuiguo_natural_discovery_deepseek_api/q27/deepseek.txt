判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看**门店客群、陈列方式、损耗控制、价格带和周转速度**。可以按下面几个维度直接判断。

### 1. 先看门店定位和客群
- **社区生鲜店/便利店**：适合中等规格，方便顾客一次买几个，单价不要太高。
- **精品超市/水果专营店**：可以接受大果、礼盒果，但要求外观、糖度、硬度稳定。
- **食堂/团购/餐饮供货**：更看重出肉率、加工便利和稳定供应，规格可以偏大或统一。
- **流动客多的门店**：小规格、低单价、即买即吃更好卖。

### 2. 苹果怎么判断规格
苹果常用“果径”毫米数分级，比如 70、75、80、85、90 等。门店采购时重点看：
- **70-75mm**：适合社区店、便利店、散卖，价格亲民，顾客接受度高。
- **75-80mm**：大多数门店的主力规格，兼顾卖相和价格。
- **80-85mm**：适合精品陈列、礼盒、家庭采购。
- **85mm以上**：更适合礼盒、高端店，普通门店容易价高滞销。
- **低于65-70mm**：除非做促销、儿童果或加工，否则门店卖相偏弱。

判断是否适合门店：
- 果形端正、无明显畸形；
- 色泽均匀，无严重锈斑、碰伤、虫眼；
- 硬度好，不软塌；
- 同一批次大小相对均匀，方便定价和陈列；
- 尝口糖酸比合适，不能只看外观。

### 3. 橙子怎么判断规格
橙子也常按果径分级，比如 60、65、70、75、80mm 等。不同品种差异大，比如脐橙、血橙、冰糖橙、沃柑不能一刀切。
- **小果 55-65mm**：适合便利店、小家庭、促销，但剥皮和卖相要过关。
- **中果 65-75mm**：门店主力，大小适中，价格和接受度平衡。
- **大果 75-85mm**：适合精品店、礼盒、企业采购。
- **85mm以上**：普通门店要谨慎，容易单价高、周转慢。
- 如果是**沃柑、砂糖橘类**，通常更看重单果重和皮薄易剥，不完全按大果逻辑。

判断是否适合门店：
- 果皮细腻、颜色均匀，无严重青果、花皮；
- 手感沉，说明水分足；
- 无软腐、压伤、冻伤；
- 表皮无大面积药斑或机械伤；
- 试剥、试吃，看化渣性、甜度、酸度；
- 同规格整齐，便于按斤或按个销售。

### 4. 用“门店销售测试”快速判断
采购前可以小批量试卖：
- 同一品种进 2-3 个规格；
- 观察 3-7 天动销；
- 看哪个规格**周转最快、损耗最低、毛利最稳**；
- 记录顾客反馈：嫌大、嫌小、嫌贵、复购如何；
- 如果大果卖得慢、小果回头多，就调整主力规格。

### 5. 关键判断标准
适合门店销售的规格通常满足：
1. **顾客一次能吃完或家庭一次能用完**；
2. **单价落在门店主流价格带**；
3. **陈列好看，大小整齐**；
4. **损耗低，耐摆放**；
5. **周转快，不压库存**；
6. **毛利率能覆盖损耗和人工**。

### 6. 简单实操建议
- 社区店：苹果主力 75-80mm，橙子主力 65-75mm；
- 精品店：苹果 80-85mm，橙子 75-85mm，可配礼盒；
- 便利店：苹果 70-75mm，橙子 60-70mm，小份装更好；
- 团购/食堂：优先稳定、耐储、出肉率，不追求外观极大。

一句话：**门店销售规格要匹配客群和价格带，优先选周转快、损耗低、外观整齐的中等规格，大果只作为补充，不要盲目追大。**
