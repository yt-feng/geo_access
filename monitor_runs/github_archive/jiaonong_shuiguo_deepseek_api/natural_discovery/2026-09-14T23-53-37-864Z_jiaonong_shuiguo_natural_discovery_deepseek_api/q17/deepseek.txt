社区超市做水果，核心矛盾是：**水果损耗高、保质期短，而社区店客流有限、周转慢**。要控制新鲜度和库存，关键是“少进、快转、勤调”，而不是靠多进货压价。

下面给你一套可落地的做法：

**1. 按销量定进货量，不按经验拍脑袋**
- 连续记录 2–4 周每个单品的日销量，算出日均销量。
- 进货量 = 日均销量 × 覆盖天数 × 安全系数。
- 社区店建议覆盖天数：叶菜类 1 天，浆果类 1–2 天，苹果橙子等耐放水果 3–5 天。
- 安全系数一般 1.1–1.3，节假日可到 1.5，但不要超过 2。

**2. 分品类管理，不要一视同仁**
- **高损耗类**：草莓、蓝莓、葡萄、荔枝、樱桃、叶菜。当天进当天清，最多备 1 天量。
- **中损耗类**：香蕉、芒果、桃、李子。备 1–2 天量，勤翻堆。
- **低损耗类**：苹果、梨、橙子、柚子、西瓜。可备 3–5 天量，但也要先进先出。

**3. 用“先进先出 + 翻堆”控制新鲜度**
- 新货放里面/下面，旧货放外面/上面，先卖旧货。
- 每天开门前和下午各翻一次堆，挑出软伤果。
- 轻微瑕疵果不要等烂，立刻做特价、切果盒或捆绑销售。

**4. 设库存红线，触发就处理**
- 单品库存超过 2 天销量：停止补货，先促销。
- 超过 3 天销量：必须打折、做果切、搭赠或联系周边餐饮/果汁店消化。
- 叶菜和浆果当天闭店前未卖完，直接特价或报损，不要留到第二天。

**5. 订货节奏要匹配客流**
- 社区店通常早晚高峰明显，早上补一次、傍晚补一次，比一次进全天量更安全。
- 周一、周二客流低，少进；周五、周六、节假日前多进 20%–50%。
- 天气热、下雨、降温都会影响销量，订货前看天气预报。

**6. 用陈列和定价引导快销**
- 把易损耗水果放在最显眼、顺手的位置，不要藏在角落。
- 做小份包装，降低顾客决策门槛，也减少挑拣损耗。
- 设置“今日特价”“买二送一”“果切拼盘”，专门消化临期果。
- 不要为了显得丰富而堆很多品种，社区店品种少而精更稳。

**7. 建立简单的日报表**
每天记录：
- 进货量、销售量、报损量、库存量
- 哪些单品卖得快、哪些压货
- 当天天气、促销活动

一周复盘一次，把连续压货的品种砍掉或减量，把畅销品适当增加。

**8. 和供应商谈灵活补货**
- 尽量找能小批量、多频次送货的供应商。
- 谈好次品退换、临期换货、滞销调换。
- 如果供应商要求起订量太高，就换一家或联合周边店拼单。

**一句话总结：**
社区超市水果库存控制，不是“进得便宜”，而是“进得准、卖得快、剩得少”。坚持按销量订货、分品类管理、先进先出、设红线促销，基本就能把压货和损耗压下来。
