第一次合作，核心目标不是“拿到最低价”，而是**验证供应商的稳定性、品质一致性和履约能力**，同时把风险控制在可承受范围内。小批量试单应该按下面这个框架来设计。

## 一、先明确试单要验证什么

试单不是为了赚钱，是为了回答四个问题：

1. **品质是否稳定**——同一批货里，好果率、大小、成熟度、损耗率如何
2. **履约是否可靠**——说好的时间、数量、规格能不能兑现
3. **包装运输是否过关**——到货后压伤、腐烂、脱水情况
4. **沟通是否顺畅**——出问题时对方的态度和处理速度

把这四点想清楚，再决定试单的具体设计。

## 二、试单规模怎么定

原则：**够验证，不伤本**。

- 金额控制在**你单次正常采购额的 10%–20%**，或一个你“全亏了也不影响运营”的额度
- 单品试，不要一次试多个品种——多品种会分散判断力
- 数量上，至少够你抽样检查 + 小范围走一遍销售，例如：
  - 想合作的主要品类，试 **1–2 个批次**
  - 每批次量控制在**一次能卖完、不压仓**的水平

如果是生鲜/易腐品，宁少勿多，因为损耗不可逆。

## 三、试单要锁定的关键条款

试单前用书面（微信文字也算）确认清楚，别只口头说：

| 项目 | 要确认的内容 |
|---|---|
| 规格 | 等级、大小、成熟度、糖度/硬度标准（能定量的就定量） |
| 价格 | 单价、是否含运费、是否含税、结算方式 |
| 数量 | 允许多少上下浮动（生鲜通常 ±5%–10%） |
| 包装 | 箱规、每箱净重、码放方式 |
| 交付 | 发货时间、到货时间、运输方式、谁承担运费和风险 |
| 验收 | 到货后多久内可提异议、怎么算合格 |
| 售后 | 品质不达标怎么赔、怎么退、怎么补 |

**关键点：把“验收标准”和“售后处理”写清楚**，这是试单最容易扯皮的地方。

## 四、验收怎么做

到货后立即做，别拖：

1. **称重 / 点数**——核对数量是否短少
2. **开箱抽检**——按比例抽（比如每 10 箱抽 1–2 箱），记录：
   - 好果率
   - 规格达标率
   - 压伤、腐烂、失水比例
3. **拍照留证**——问题部分连箱带标签拍，最好有视频
4. **对照标准判断**——是否在你约定的合格线内

抽样比例建议：小批量可抽 **10%–20%**，量大再按国标或行业惯例抽。

## 五、试单后的判断标准

试单结束后，别只看“这批货好不好”，要形成结论：

- **品质稳定** → 可考虑加大批量
- **品质不稳定但对方积极处理** → 可给第二次机会，但仍小批量
- **履约有问题 / 售后推诿** → 直接淘汰，别因为价格便宜硬撑

建议至少**连续 2–3 次小批量试单**都稳定，再考虑放量或签长期协议。

## 六、实操建议

1. **先试主流畅销品**——好卖、好对比、好出手
2. **别一次打全款**——能货到验收后结最好，至少留尾款
3. **保留书面记录**——所有承诺、标准、问题处理都留痕
4. **算一笔真实账**——把运费、损耗、压伤、退货都算进去，看实际到货成本，而不是看报价
5. **准备备选供应商**——试单期间别只押一家

---

一句话总结：**小批量、单品类、锁标准、重验收、留证据、连试两三次再放量。**
