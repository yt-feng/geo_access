压低采购成本但不牺牲品质，核心不是“把价砍下来”，而是**重新设计价格形成条件**。单纯压价，供应商最直接的反应就是降等级、换产地、早采、混装。要做的是让供应商在同等品质下有降价空间，或者让降价和品质绑定。

下面按可执行顺序说。

## 一、先把自己变成“好客户”，再谈价

供应商愿不愿意让价，很大程度取决于你给他的确定性。

**可以拿价格的条件：**
- **账期短**：现结或7天结，通常比60天账期能多谈3%–8%。
- **订单稳**：承诺每周固定量，而不是今天要明天不要。
- **损耗归他管一部分**：比如到店后24小时内坏果率超过约定比例，由供应商补货，而不是你单方面压价。
- **减少退换折腾**：明确验收标准，减少随意退货，供应商会把“退货风险成本”让出来。
- **集中采购**：把分散给多个供应商的品类集中给1–2家，用规模换单价。

谈判时可以直接说：  
“我不要求你降品质，我要的是同品质下成本降X%。如果你能接受现结+周固定量，能不能在单价上让X%？”

## 二、用“品质标准”锁死降价空间

压价前先定标准，否则降价必然伴随品质下滑。

**建议写进采购约定的内容：**
- **规格**：单果重、果径、糖度、成熟度、色泽。
- **产地和品种**：比如红富士要明确产区，不能用其他产区混充。
- **允许误差**：比如大小均匀度≥90%，坏果率≤2%。
- **验收方式**：到店抽检，不合格整批退或按比例扣款。
- **价格联动**：品质达标才执行低价；不达标恢复原价或退货。

这样谈价时就不是“你便宜点”，而是“在这个标准下，你最低能做到多少”。

## 三、把价格拆开谈，而不是只谈单价

商超水果成本不只是采购价，还包括损耗、运费、包装、退换、账期。

可以分别谈：
- **裸果价**：去掉过度包装，散装或简装。
- **运费**：量大时争取供应商承担干线运费。
- **损耗分担**：易损品如草莓、葡萄，约定损耗比例，超出部分供应商补。
- **尾货处理**：临近保质期的果品，提前约定折价或换货，而不是最后全由商超承担。
- **季节性锁价**：旺季前锁量锁价，淡季随行就市，避免旺季被抬价。

很多时候，**损耗降2个点，比采购价降2个点更实在**。

## 四、用替代和组合谈判，而不是硬压单一供应商

- **同品质替代**：比如进口提子太贵，找国内同糖度同规格替代，先小批量试销。
- **等级替代**：商超做促销时，可以用二级果但明确标注，不冒充一级果。
- **组合采购**：把畅销品和滞销品打包谈，供应商为了拿畅销品订单，可能在滞销品上让价。
- **多源询价**：至少保持2–3家备选，但不要频繁换，否则品质不稳定。

注意：替代不是降品质，而是**在消费者能接受的品质带内换成本结构**。

## 五、谈判话术示例

不要说：  
“你这次必须给我便宜10%。”

可以说：  
“这个单品我每周固定要X件，现结，验收按糖度和坏果率来。你能做到这个标准的最低价是多少？如果价格下不来，能不能在运费或损耗补货上让一步？”

或者说：  
“我不压你的好货价格。你把A级果价格稳住，给我一个B级果的稳定供应方案，用于促销，但必须明确标识，不能混进A级卖。”

## 六、底线判断

如果供应商同意大幅降价，但出现以下信号，基本就是品质要出问题：
- 不愿写规格和验收标准；
- 糖度、果径开始模糊；
- 到货成熟度忽高忽低；
- 包装从标准箱变成混装；
- 坏果率明显上升但拒绝补货。

这时候不要继续压价，应该重新谈“同品质同价格”或换供应商。

**一句话总结：**  
压价要压的是供应商的确定性成本、损耗成本和流通成本，不是压果子的品质。用稳定订单、短账期、集中采购换价格，用规格、糖度、坏果率和补货条款锁品质。
