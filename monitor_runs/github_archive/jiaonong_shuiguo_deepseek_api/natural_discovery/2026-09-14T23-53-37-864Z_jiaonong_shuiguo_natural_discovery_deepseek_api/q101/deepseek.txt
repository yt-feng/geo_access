酒店早餐水果供应，核心不是“找到最便宜的供应商”，而是建立一套能长期稳定、品质可控、出了问题有人兜底的合作机制。谈合作时重点盯住以下几件事。

**一、先明确自己的需求，再去谈**

- **品种结构**：早餐通常需要 3–5 个常备品种（如西瓜、哈密瓜、苹果、橙子、香蕉）加 1–2 个应季品种。先定下来，不要让对方牵着走。
- **规格标准**：按“可食用部分”而不是“毛重”谈。比如西瓜要求糖度、成熟度、切开无空心；苹果要求单果大小区间、无碰伤。规格越具体，后期扯皮越少。
- **用量与频次**：按天/周给出预估量，并说明淡旺季波动（入住率高时可能翻倍）。这直接决定对方给你的价格档位和配送安排。
- **验收时间**：早餐用果通常要求清晨到货，要确认对方能否在酒店开餐前 1–2 小时送达并完成验收。

**二、价格与结算条款**

- **计价方式**：优先按净重或按件计价，避免“毛重里掺冰瓶、垫纸”导致实际得率偏低。要求明确损耗由谁承担。
- **价格调整机制**：水果价格波动大，别接受“一口价全年”。约定一个调价周期（如每月/每季度），并绑定一个双方认可的参考价来源或市场行情，写清涨跌幅触发条件。
- **结算账期**：明确对账日、开票类型（普票/专票）、付款周期。账期越长对方报价通常越高，要和现金流平衡。

**三、质量与验收**

- **到货验收标准**：写清外观、成熟度、糖度、新鲜度、农残检测要求。最好附一份验收单模板，双方签字确认。
- **不合格处理**：出现烂果、生果、规格不符时，是当场拒收、换货，还是折价接收？退换货的时限和运费谁承担，必须写死。
- **抽检与留样**：约定抽检比例和留样制度，尤其是涉及食品安全时，保留追溯依据。

**四、供应稳定性与风险**

- **备选供应商**：至少储备 1 家备选，避免单一供应商断供或坐地起价。
- **断供条款**：约定缺货、恶劣天气、节假日高峰期的应对方案和违约责任。
- **食品安全资质**：查验营业执照、食品经营许可证、检测报告，明确食品安全事故的责任划分和赔偿。

**五、配送与现场配合**

- **配送时间、频次、车辆与人员**：是否固定司机、能否进后厨、是否需要酒店方协助搬运。
- **包装要求**：周转筐是否回收、是否押金、是否影响二次使用。
- **对接人机制**：双方各指定一名日常对接人和一名负责人，避免口头承诺无人认账。

**六、合同里必须落地的几条**

1. 品种、规格、单价、调价机制；
2. 配送时间、频次、验收标准与不合格处理；
3. 账期、开票、付款方式；
4. 断供、质量事故的违约责任与赔偿；
5. 合同期限、续约与退出条件（含提前通知期）。

**一个实用建议**：正式签约前先让对方试供 1–2 周，用真实早餐场景跑一遍，重点看清晨到货准时率、损耗率和换货响应速度。试供期表现比报价单更能说明问题。
