要减少香蕉放坏，采购时重点抓两个条件：**到货熟度**和**到货时间**，并按你计划的售卖速度来定。

**1. 到货熟度怎么要求**
- 如果打算 **2～3天内卖完**：可以要到货时 **已经微黄、开始转熟** 的香蕉，也就是通常说的 **3～4号色**，口感好、卖相好，但必须快卖。
- 如果打算 **4～6天慢慢卖**：建议要求 **青黄之间、以青为主**，大约 **2号色左右**，到店后还能自然转熟。
- 如果打算 **7天以上或天气热**：尽量要 **偏青、硬身、无黄斑** 的货，约 **1～2号色**，但要注意太青的香蕉口感差，需要催熟或等它转熟。
- 不要一次全要同一个熟度。最好 **分批次采购**：一批偏熟立刻卖，一批偏青后卖，降低集中变坏风险。

**2. 到货时间怎么要求**
- **夏季高温**：要求 **清晨到货**，避开中午和下午高温。到货后尽快开箱散热，不要闷在车里或仓库角落。
- **冬季低温**：避免 **清晨或夜间低温到货**，否则容易受冷害，表皮发黑、果肉变硬。可要求 **上午稍晚或中午前后到货**。
- **雨天**：尽量要求 **雨停后或做好防雨** 到货，香蕉怕水湿，箱内潮湿会加快腐烂。
- **到货后处理**：无论什么季节，到货后先 **开箱通风、分拣**，把已经发黄、有伤、有霉点的挑出来先卖或处理，不要和青蕉混放。

**3. 给供应商的具体采购要求可以这样写**
> 本次香蕉要求到货熟度约2～3号色，青黄之间，果身硬，无黑斑、无裂口、无压伤。夏季请安排清晨到货，冬季请安排上午到货，避免冷害。到货后需开箱散热。若熟度超过4号色或已有黄斑，请提前说明并降价或改发偏青货。

**4. 更实用的做法**
- 让供应商 **按你每天销量分2～3批到货**，而不是一次到一大批。
- 店里香蕉不要堆太厚， **悬挂或单层摆放** 比堆箱更耐放。
- 已经转黄的香蕉放 **阴凉通风处**，不要放冷柜；未熟的青蕉也不要直接放低温冷库，容易冻伤。
- 如果夏季销量慢，采购时宁可 **偏青一点、每次少拿一点**，比拿熟货更安全。
