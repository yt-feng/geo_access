核心思路是：**把补货从“等对方重新发货”改成“先补偿、后结算”，并把验收标准前置到下单环节**。具体可以这样操作：

**1. 合同/订单里写清验收标准**
- 品种、规格、单果重量、成熟度、糖度（如适用）、外观（无腐烂/压伤/虫眼）、到货温度、包装方式。
- 明确“不合格”的判定权在门店，并约定抽检比例（如每箱抽检10%）。
- 约定到货时间窗口，比如“每日X点前送达”，超时即视为违约。

**2. 不合格处理条款（关键）**
- **现场扣款/折价**：不合格部分当场按比例扣减货款，不用等补货。
- **补货时限**：约定“不合格品在X小时内补送到店”，且补货优先于当日营业高峰前。
- **替代方案**：若无法按时补货，供应商需按缺货金额的X%支付违约金，或允许门店自行采购、差价由供应商承担。
- **不影响营业的兜底**：约定“先补货后追责”，即供应商必须先补足当日营业所需，再谈赔偿，避免门店因等货停售。

**3. 结算方式**
- 采用“月结+验收单”模式：每次到货签验收单，不合格项当场记录并双方确认，月末按实际合格量结算。
- 预留质量保证金（如货款的5%-10%），出现多次不合格可扣减。

**4. 日常执行**
- 固定1-2家备用供应商，主供应商出问题时能立刻切换。
- 门店收货时拍照留证，当天发群里确认，避免事后扯皮。
- 对高频不合格的供应商设置淘汰线，比如“月度不合格率超5%即暂停合作”。

**一句话总结**：补货条款要写成“不合格当场扣款 + 限时补足 + 补不上就赔差价”，这样门店不用等、不用停，营业不受影响。
