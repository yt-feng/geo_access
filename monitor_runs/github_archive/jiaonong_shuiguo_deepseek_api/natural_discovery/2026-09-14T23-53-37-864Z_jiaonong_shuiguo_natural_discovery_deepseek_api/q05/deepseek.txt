优先建议：**卖去皮好的，但保留整果让顾客可选，不要让顾客自己动手挑着削。**

更具体一点，按场景分：

1. **如果主打走量、客流快、游客多**
   - 最适合：**去皮好的，切块/整颗泡盐水装盒**
   - 优点：顾客买了就走，客单价容易提高，损耗可控，卫生也更规范。
   - 注意：必须冷藏展示，当天削当天卖，时间久了会发酸、出水、发暗。

2. **如果顾客很在意新鲜、想自己判断**
   - 最适合：**整果+现场削皮**
   - 优点：顾客看得见原料，信任感强，适合社区店、老顾客多的店。
   - 注意：削皮要由店员操作，不要让顾客自己挑完自己削，容易弄脏、弄乱、伤手，也影响效率。

3. **如果店里有空间、人手够**
   - 最优组合：**整果区 + 去皮装盒区 + 可代削服务**
   - 顾客可以买整颗，也可以买削好的，还可以要求现场削。
   - 这样既照顾价格敏感型顾客，也照顾图方便型顾客。

4. **不建议的做法**
   - 完全让顾客自己挑、自己削：现场乱、损耗大、卫生风险高。
   - 只卖去皮好的：有些顾客会怀疑不新鲜，尤其是夏天。
   - 只卖整果：很多年轻人、上班族嫌麻烦，销量会受限。

**结论：**
- 想省事、走量：主推**去皮好的**。
- 想稳客、树口碑：**整果和去皮都卖，削皮由店员做**。
- 最佳模式：**整果可选，去皮主推，现场代削作为增值服务。**
