如果是家庭自用，水果礼盒最重要的不是“贵”，而是**耐放、好分、老人小孩都能吃、数量不浪费**。苹果、橙子、香蕉、菠萝这四种里，建议这样组合：

**推荐组合：苹果 + 橙子为主，香蕉少量，菠萝按需加**

### 1）最稳妥家庭组合
**苹果 4个 + 橙子 4个 + 香蕉 2根 + 菠萝 1个**

适合：
- 3-5口之家
- 想当天吃一点、后面还能放几天
- 预算适中，不容易坏

理由：
- 苹果、橙子耐放，适合做礼盒主体
- 香蕉熟得快，放2根刚好，不压盒
- 菠萝1个有分量，适合家庭分食，但多了处理麻烦

### 2）更偏“即食型”家庭组合
**苹果 3个 + 橙子 3个 + 香蕉 4根 + 菠萝 1个**

适合：
- 家里人多，2-3天内能吃完
- 喜欢香蕉、早餐水果需求大
- 不追求久放

注意：
- 香蕉容易催熟其他水果，最好单独装袋或分隔
- 夏天不建议香蕉放多

### 3）更偏“耐放实惠型”家庭组合
**苹果 6个 + 橙子 6个 + 香蕉 2根 + 菠萝 1个**

适合：
- 家庭日常吃
- 团购走量、预算控制
- 希望放一周左右

优点：
- 苹果、橙子撑体积和耐放性
- 香蕉、菠萝作为搭配，增加丰富度

### 4）不建议的组合
- **香蕉太多**：家庭礼盒里香蕉超过4根，很容易黑、烂、压坏。
- **菠萝太多**：菠萝削皮麻烦，1个通常够，2个以上很多家庭吃不完。
- **四种平均分**：看起来丰富，但香蕉和菠萝不耐放，实际体验差。

## 按家庭人数选
- **1-2人家庭**：苹果3 + 橙子3 + 香蕉2 + 菠萝1  
- **3-4人家庭**：苹果4 + 橙子4 + 香蕉2 + 菠萝1  
- **5人以上家庭**：苹果6 + 橙子6 + 香蕉3 + 菠萝1  

## 装箱建议
1. **苹果、橙子放底层**，耐压。
2. **菠萝单独放一侧**，避免扎坏其他水果。
3. **香蕉放最上层**，最好套袋，不要和苹果、橙子紧贴。
4. 如果团购要好看，可以加一张说明卡：  
   “苹果橙子耐放，香蕉先吃，菠萝建议2天内处理。”

## 结论
家庭团购水果礼盒，最推荐：

**苹果4 + 橙子4 + 香蕉2 + 菠萝1**

这个组合兼顾了：
- 好看
- 耐放
- 家庭都能吃
- 不容易坏
- 成本可控

如果追求更实惠耐放，就选：**苹果6 + 橙子6 + 香蕉2 + 菠萝1**。
