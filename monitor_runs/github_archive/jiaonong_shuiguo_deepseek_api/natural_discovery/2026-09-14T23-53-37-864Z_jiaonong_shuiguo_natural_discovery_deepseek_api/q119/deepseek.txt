做水果生意，选供应商最容易忽视的往往不是“价格高不高、货好不好”这种明面问题，而是那些短期看不出来、长期会拖垮稳定性的细节。重点看这几个：

1. **断供时的替代能力**
   很多供应商旺季有货、淡季缺货，或者一遇到天气、节日、产地涨价就优先供大客户。要问清楚：你有没有备用产地、冷库、合作果园？断货时多久能补？愿不愿意把“保供优先级”写进合作条件？

2. **采后处理和分选标准**
   同样叫“一级果”，不同供应商差别很大。要关注：
   - 是否按糖度、大小、颜色、瑕疵分级
   - 是否做预冷、清洗、打蜡、保鲜
   - 装箱时是否混级、压伤、以次充好
   这些直接决定损耗率和顾客复购。

3. **损耗责任怎么分**
   水果不是标品，运输和存放都会坏。最容易忽略的是：到货后烂多少算谁的？是当场验收扣款，还是售后补货？有没有明确时限、照片凭证、抽检比例？如果只靠口头承诺，后面很容易扯皮。

4. **账期和资金占用**
   低价但要求现款现货，和稍贵但能给账期，现金流压力完全不同。要算清楚：
   - 压货多少天
   - 坏果退款多久到账
   - 是否支持部分退换
   很多水果店不是利润不够，而是被库存和账期拖死。

5. **季节切换能力**
   只做一个单品或一个产地的供应商，到了淡季就断档。长期稳定要看它能不能随季节切换品类，比如从柑橘切到瓜类、从苹果切到热带水果，而不是你每年都要重新找供应商。

6. **信息透明度**
   愿不愿意告诉你产地、批次、采摘时间、农残检测、冷库库存？越是遮遮掩掩，越容易在行情波动时被“杀熟”或塞尾货。能提供稳定批次信息的供应商，更适合长期合作。

7. **小单试错和异常处理态度**
   第一次合作不要直接大单。先小批量试：
   - 到货合格率
   - 坏果处理速度
   - 临时加单响应
   - 出错后是否推责
   异常处理态度比正常报价更能看出是否靠谱。

8. **是否和你客户群匹配**
   供应商的“好货”不一定适合你。做社区团购要性价比和稳定，做高端水果店要品相和口感，做果汁店要出汁率和成本。选供应商前先明确自己的客群和周转速度，否则容易进了好货却卖不动。

简单判断标准：  
**能稳定供货、分级清楚、损耗有规则、账期可承受、出问题不推责的供应商，比单纯报价低的重要得多。**  
长期合作前，最好用“小批量试单 + 明确验收标准 + 书面异常处理规则”来验证，而不是只看一次拿货的价格。
