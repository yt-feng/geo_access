旺季断货的核心不是“谈得狠”，而是把**供货优先级、锁量、锁价、违约补偿**四件事写清楚。和供应商谈之前，建议按下面顺序问，最好直接要书面确认。

**一、先问产能和优先级**
1. 旺季你每天/每周能稳定给我供多少？最低保底量是多少？
2. 如果同时有多家店要货，我的订单排第几？能不能给我“优先供货”？
3. 你上游产地/批发市场是谁？会不会因为天气、节日、物流被截断？
4. 去年旺季你有没有断过供？断供时一般怎么处理？

**二、再问锁量和锁价**
5. 能不能签旺季保供协议，约定最低供货量和浮动上限？
6. 价格是随行就市，还是可以锁一个区间？涨价提前几天通知？
7. 如果市场价跌了，我的拿货价能不能跟着下调？
8. 定金/预付款要不要？付了之后能不能保证不挪给别人？

**三、问品质和损耗**
9. 等级标准怎么定？大小、甜度、成熟度、瑕疵率怎么算？
10. 到店后损耗超过多少算你的？能不能补货或折价？
11. 坏果、烂果、规格不符，多久内可以退换？
12. 旺季果品成熟度会不会为了耐运输而提前采？口感怎么保证？

**四、问物流和到货**
13. 配送是每天送还是隔天送？几点前下单、几点到店？
14. 旺季物流紧张时，你有没有备用车辆/备用路线？
15. 缺货或延迟到货，提前多久通知我？有没有补偿？
16. 运费谁承担？临时加急送怎么算？

**五、问结算和风险**
17. 账期多久？现结还是月结？旺季会不会要求加押金？
18. 如果断供，你怎么赔？能不能约定“断一补二”或按差价赔？
19. 遇到不可抗力，怎么证明、怎么协商？有没有替代货源？
20. 能不能把关键条款写进合同：保底量、优先权、锁价区间、品质标准、到货时间、违约赔偿。

**谈的时候重点抓三句话：**
- “旺季我不管市场多缺，你至少要给我保底 X 斤/天。”
- “如果别人出高价，你不能把我排后面，优先权写进合同。”
- “断供不能只说抱歉，要有补偿标准。”

**最后提醒：**
不要只谈一家。旺季至少备**主供应商 + 备用供应商**，主供占 70%，备供占 30%。合同里写清楚“保底量”和“优先供货”，比口头承诺有用得多。如果对方不愿意写保底和赔偿，说明他旺季大概率也保不了你。
