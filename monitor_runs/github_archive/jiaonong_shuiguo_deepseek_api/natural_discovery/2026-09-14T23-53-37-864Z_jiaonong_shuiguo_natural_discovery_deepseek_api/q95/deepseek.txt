选水果供应商，核心不是“找最便宜的”，而是先保证**食品安全和稳定供货**，再比价格。可以按下面几步做。

**1. 先定采购标准**
- 香蕉：要求成熟度可调，比如青蕉、微黄蕉，避免一到货就过熟；单根无明显黑斑、无腐烂。
- 苹果：果形完整、无明显碰伤、无霉心；按大小分级，比如70、75、80果径。
- 橙子：皮薄汁多、无烂果、无严重干疤；按规格分等级。
- 统一要求：农残检测合格、可追溯来源、坏果率上限，比如到货验收坏果不超过3%—5%。

**2. 供应商类型怎么选**
- 一级批发商/大型农批市场商户：价格低、品类全，但质量波动大，适合有验收能力、采购量大的食堂。
- 产地合作社/果园直供：价格和新鲜度较好，适合苹果、橙子等耐储水果；但配送和售后可能弱。
- 专业水果配送公司：服务稳定、能开票、可退换，适合学校食堂，尤其是有审计、留样、索证索票要求的。
- 商超或生鲜平台：合规性强、票据齐全，但价格通常偏高，适合小批量或应急。

学校食堂优先选：**能开发票、能提供检测报告、能稳定配送、能退换坏果的配送商或合作社**。

**3. 重点看哪些资质**
- 营业执照、食品经营许可证。
- 水果农残检测报告或承诺达标合格证。
- 进货凭证、产地证明或追溯信息。
- 配送车辆和分拣环境是否干净，是否与生鲜、化学品混运。
- 是否能按学校要求提供留样、验收单、对账单。

**4. 比价不要只看单价**
要按“可食用部分成本”比：
- 到货价 + 运费 + 损耗 + 退换成本。
- 同样100斤，坏果10斤和坏果3斤，实际成本差很多。
- 要求报价写清楚：规格、等级、含税否、配送频率、起送量、账期、坏果赔付。

**5. 建议的筛选流程**
1. 先找3—5家：本地农批大户、产地合作社、水果配送公司各找几家。
2. 让对方按香蕉、苹果、橙子分别报价，并提供资质和检测报告。
3. 小批量试供2—4周，记录到货合格率、损耗率、配送准时率、售后响应。
4. 验收时拍照、称重、记坏果，双方签字。
5. 综合评分：食品安全40%、稳定性25%、价格20%、服务15%。
6. 选1家主供、1家备供，避免单一供应商断供。

**6. 合同里必须写清楚**
- 品种、规格、等级、单价、是否含税含运。
- 送货时间、频次、临时加单怎么处理。
- 验收标准、坏果率上限、超标怎么扣款或退换。
- 农残检测、索证索票责任。
- 账期、结算方式、发票类型。
- 食品安全事故责任和赔偿。

**简单判断标准：**
如果供应商只能给低价，但没票据、没检测、坏果不赔、送货不稳，不建议给学校食堂用。学校食堂应优先选**资质齐全、可追溯、能退换、配送稳定**的供应商，价格放在第二位比较。
