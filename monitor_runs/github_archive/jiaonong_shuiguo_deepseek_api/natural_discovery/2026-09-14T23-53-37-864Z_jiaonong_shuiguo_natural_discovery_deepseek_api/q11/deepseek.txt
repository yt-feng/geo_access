会影响，而且通常是**明显影响**，但影响大小取决于你的客户群和卖法。

**主要影响：**

1. **挑拣和损耗增加**
   大小混装时，顾客会翻挑大的，剩下小的难卖，翻动还容易压伤香蕉。最后小果、伤果只能降价或报损。

2. **定价困难**
   同一箱里大小差太多，按统一价卖，大的觉得亏、小的嫌贵；按等级分开卖，又增加分拣人工。

3. **顾客体验不稳定**
   散卖水果店如果同一堆香蕉大小差异大，顾客会觉得“品质不整齐”。但如果是按斤称、价格便宜，部分顾客能接受。

4. **陈列效果差**
   香蕉是冲动型、外观敏感型商品。大小均匀、颜色一致的堆头更好卖，混装显得杂乱，降低购买欲。

**怎么判断能不能接受：**

- 如果做**散客按斤称、走性价比**：影响可控，但要把大小果分开陈列、分开定价。
- 如果做**礼盒、精品果、企业团购**：影响很大，大小不一会直接拉低档次，最好拒收或要求分级。
- 如果做**熟果促销、榨汁、烘焙原料**：影响较小，价格合适就能出。

**实操建议：**

1. 采购时明确规格，比如“每根长度、单根重量区间”，不要只写“一箱多少斤”。
2. 到货后按大、中、小分三级，分别定价陈列。
3. 大小混装的箱子，优先做促销或搭配销售，不要和精品果混放。
4. 长期看，固定要求供应商分级装箱，哪怕单价略高，通常比损耗和压价更划算。

结论：**会影响销售，尤其是精品和礼盒场景；做低价散卖影响小一些，但必须分级卖，不能混在一起统价卖。**
