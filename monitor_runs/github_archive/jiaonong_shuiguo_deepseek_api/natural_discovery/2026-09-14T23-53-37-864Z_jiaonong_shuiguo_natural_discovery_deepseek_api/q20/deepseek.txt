社区超市找每天配送的水果供应商，建议重点看这几类条件。你可以把下面当作筛选清单和谈判底线。

## 一、配送能力（最核心）

- **是否真能每天配送**：问清是每天固定送，还是“下单后次日达”“隔日达”。社区超市客流碎片化，断货很伤客。
- **配送时间是否匹配营业**：最好能在早市前送到，比如 6:00–8:00；晚到会错过早高峰。
- **起送门槛**：有些供应商按金额或箱数起送，要确认你每天的单量能不能稳定达到。
- **配送费怎么算**：是否包运费、满额免运费、临时加急是否加价。
- **缺货补送能力**：当天缺品能不能当天或次日补，还是只能等下一周期。

## 二、货源与品质稳定性

- **货源渠道**：产地直采、批发市场、二级批发商，稳定性和价格差异很大。社区店更适合找能稳定供应的产地或一级批发。
- **品种覆盖**：能否覆盖你常卖的 20–40 个核心单品，而不是只有几款特价果。
- **等级和规格**：同一种水果分大小果、精品果、统货，要明确你订的是哪一档。
- **坏果率与售后**：坏果、压伤、烂果怎么赔？是拍照秒赔、下次补货抵扣，还是拒收？这个必须写清。
- **季节性替代方案**：某单品过季或涨价时，能否提前推荐替代品，避免货架空。

## 三、价格与结算

- **报价是否含税、含运费**：很多低价是未含运费或未含损耗的。
- **价格调整机制**：是每天随行就市，还是一周一价？频繁调价会让你难定价。
- **账期与结算**：现结、周结、月结？社区超市现金流紧，能谈周结或半月结更好。
- **返点/损耗补贴**：量大时能否谈返点，或按销售额给损耗补贴。

## 四、资质与合规

- **营业执照、食品经营许可证**：水果一般需食品经营相关资质，至少要有合法经营主体。
- **检测/溯源**：能否提供农残检测报告或产地证明，尤其是叶菜、草莓、葡萄等高风险品。
- **开票能力**：能否开普票或专票，关系到你后续做账和税务。

## 五、实操建议

1. **先小批量试供 1–2 周**：不要一上来签长期约，先看准时率、坏果率、补货速度。
2. **同时谈 2 家备用供应商**：一家主供、一家备供，防止旺季或节假日断供。
3. **建一个简单验收表**：每天记录到货时间、品种、数量、坏果数、缺品数，谈条件和换供应商时都有依据。
4. **优先选本地或同城供应商**：每天配送对距离敏感，跨城物流很难保证稳定。
5. **合同里写清关键条款**：配送时间、起送量、坏果赔付、价格调整、违约处理。

简单说，社区超市选每日配送水果供应商，核心不是“谁最便宜”，而是**能不能每天准时到、品质稳、坏了有人赔、缺了能补**。这四点满足后，再比价格。
