大型超市对水果供应商的要求，通常比普通批发市场高一个层级：不只是“能供货”，而是能稳定、可追溯、低损耗地供货。核心能力可以分成食品安全和物流履约两块。

**一、食品安全能力**

1. **合法资质与主体合规**
- 营业执照、食品经营许可证/食品生产许可证（按业态）
- 若为进口水果，需有进出口资质、入境货物检验检疫证明
- 种植端如为自有基地，需有土地/种植合规证明；如为合作社采购，需有稳定协议和来源档案

2. **农残与污染物控制**
- 具备农残检测能力，或与第三方检测机构长期合作
- 能按国标做批次检测，重点包括有机磷、氨基甲酸酯、拟除虫菊酯等
- 对重金属、霉菌毒素等有抽检机制
- 能提供批次检测报告，而不是只给一份年度报告

3. **追溯体系**
- 能做到“批次—基地/供应商—采收时间—检测结果—发货流向”对应
- 一旦出现抽检不合格或客诉，能快速锁定批次并召回
- 最好有信息化系统，至少要有可核验的纸质/电子台账

4. **仓储与加工卫生**
- 分拣、包装场所符合食品卫生要求
- 有防鼠、防虫、防尘、温湿度控制
- 人员健康证、更衣消毒、工具清洗消毒制度
- 生熟不分、果蔬与化学品混放是硬伤

5. **包装与标签合规**
- 预包装水果标签符合法规：品名、产地、生产者/经营者、日期等
- 保鲜剂、蜡、催熟剂等使用符合国标，不能违规添加
- 进口水果中文标签和检疫证明齐全

6. **召回与客诉处理**
- 有不合格品隔离、销毁、召回流程
- 能配合超市做抽检、飞行检查、客诉溯源
- 有食品安全责任险更优

**二、物流与供应链能力**

1. **冷链能力**
- 不同水果温区不同：浆果、荔枝、樱桃等需全程冷链；香蕉、芒果等需特定催熟/温控
- 需有预冷、冷藏车、冷库、温控记录
- 不是“有冷库”就行，而是能证明全程温度可追踪

2. **产地集货与分级加工**
- 能按超市标准做分级、筛选、称重、包装
- 能处理贴标、条码、箱规、托盘规格等要求
- 有稳定的产地采购网络，避免单点断供

3. **仓储与库存管理**
- 先进先出、批次管理、临期预警
- 损耗率可控，能区分自然损耗和异常损耗
- 对高损耗品类有专门操作规范

4. **运输与配送履约**
- 能按超市要求的频次、时段、门店配送
- 有车辆调度、在途跟踪、异常反馈机制
- 能应对节假日、促销、极端天气的峰值需求

5. **品控与验收配合**
- 到货合格率、破损率、温度合格率等指标稳定
- 能接受超市DC或门店验收标准，并处理拒收、退换货
- 有退货、补货、换货的快速响应机制

6. **信息化与单据能力**
- 能对接超市订单系统、ASN预约、条码、电子回单
- 提供检验报告、温控记录、发货单、对账单等
- 数据能对齐，减少人工扯皮

**三、超市通常重点考察的硬指标**

- 是否有稳定基地或长期合作产地
- 是否有农残检测报告和追溯台账
- 是否有冷链车/冷库及温控记录
- 到货合格率、损耗率、准时率
- 异常处理速度：拒收、客诉、召回
- 能否接受超市的审核、抽检和罚则

**四、一句话判断**

如果一家水果供应商只能做到“有货、能送”，但做不到批次检测、全程温控、可追溯和稳定履约，通常很难进入大型超市的常规供应链；能进入的，基本都具备“食品安全体系 + 冷链物流体系 + 信息化单据”这三项组合能力。
