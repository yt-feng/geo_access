重要，而且通常是多门店水果品质能不能“统一”的前置条件。原因不在“分级”这个动作本身，而在于：**没有统一、可验收的供应商分级标准，门店之间就只能靠个人经验判断，品质必然漂移。**

可以从三个层面判断它有多重要：

**1. 对“统一品质”的直接作用**
- 多门店最大的问题是：同一批货分到不同门店，店长/收货员对“好果”的判断不一致。
- 如果供应商分级标准明确（比如按果径、糖度、着色度、机械伤比例、成熟度分档），采购就能下**同一等级订单**，门店按同一标准收货，偏差会小很多。
- 反之，供应商说“精品”，A店认为是精品，B店认为是一般货，统一就无从谈起。

**2. 对成本和损耗的影响**
- 水果是非标品，等级差一点，损耗和客诉差很多。
- 统一分级后，可以做到：
  - 不同门店按客群订不同等级，而不是混着发；
  - 高等级走高端门店，中等级走社区店，减少“好货贱卖、差货硬卖”；
  - 收货时按等级扣罚或拒收，减少门店端扯皮。

**3. 对供应商管理的作用**
- 分级标准是供应商准入、考核、淘汰的依据。
- 没有标准，采购只能凭关系或感觉换供应商，品质不稳定。
- 有标准后，可以按批次抽检、按等级结算，供应商也知道要做到什么程度才能继续供货。

**但要注意：分级标准重要，不等于“越复杂越好”。**
对多门店超市，更关键的是这几点：
- **可量化**：糖度、果径、色卡、伤果率等能测能拍；
- **可执行**：门店收货员几分钟内能判断，不需要实验室；
- **分档少**：通常2～3档就够，太多反而执行不了；
- **和门店定位挂钩**：不同门店可以卖不同等级，但同一等级的标准必须一致；
- **有抽检和奖惩**：否则标准只是纸面文件。

**结论：**
供应商分级标准很重要，它是多门店水果品质统一的基础工具。没有它，统一品质主要靠人；有了它，才能靠制度和流程。但标准必须简单、量化、可验收，并且和门店定位、采购结算、供应商考核绑定，否则作用有限。
