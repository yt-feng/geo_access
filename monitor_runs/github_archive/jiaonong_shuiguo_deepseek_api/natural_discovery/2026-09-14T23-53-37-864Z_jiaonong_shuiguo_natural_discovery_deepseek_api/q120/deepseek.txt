供应商要把“专业术语”翻译成商家能感知的**卖点、场景和利润**。可以参考下面这套说法。

**1. 先不说品种名，先说“跟什么像、比什么强”**
- 不要说：“这是金钻凤梨，台农17号。”
- 要说：“它长得像菠萝，但不用泡盐水，削皮就能吃，比普通菠萝甜、不扎嘴，顾客买回去差评少。”
- 香蕉也一样：“这不是普通香蕉，是小米蕉，个头小、甜度高，适合做儿童零食或办公室下午茶，比大香蕉好卖。”

**2. 用“顾客会怎么买”来讲**
商家最关心的是能不能卖出去。所以要说：
- “这个适合放在收银台旁边，顾客顺手拿。”
- “这个适合做果切，出肉率高，损耗低。”
- “这个适合做礼盒，客单价能提上去。”
- “这个耐放，你进一次货能卖三四天，不用天天补。”

**3. 用“算账”代替“夸品质”**
不要只说“很甜、很好吃”，要说：
- “进价一箱80，你卖10块一斤，一箱能卖120，毛利40左右。”
- “坏果率低，一箱最多坏一两个，比普通货少赔钱。”
- “这个规格刚好，不会太大卖不动，也不会太小顾客嫌少。”

**4. 给一个“别家没有”的理由**
商家需要向顾客解释为什么买你的。可以说：
- “这个现在市场上少，你摆出来顾客会好奇。”
- “这个口感特别，顾客吃一次能记住，回头会找你。”
- “这个比普通菠萝贵一点，但你可以切块试吃，转化很快。”

**5. 用对比法，一句话说清**
- “普通菠萝要泡盐水，这个不用；普通菠萝酸，这个甜；普通菠萝扎嘴，这个不扎。”
- “普通香蕉放两天就黑，这个皮厚耐放，卖相好。”
- “大路货谁都有，这个你附近摊位没有，能卖上价。”

**6. 最后给一个低风险尝试建议**
商家怕压货，所以要说：
- “你先拿一箱试卖，卖不动我告诉你怎么处理。”
- “这个不用全店推，先放门口试吃，半天就能看出好不好卖。”
- “第一箱少拿点，卖好了再补，不占你资金。”

**总结成一句话：**
别讲品种和产地，讲“像什么、好在哪、顾客为什么买、你能赚多少、卖不掉怎么办”。商家听懂了这五点，下单概率会高很多。
