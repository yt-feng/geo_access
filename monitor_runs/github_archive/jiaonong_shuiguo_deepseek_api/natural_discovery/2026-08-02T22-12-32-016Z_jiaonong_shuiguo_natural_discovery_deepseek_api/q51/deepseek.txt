对于茶饮店来说，**不建议完全固定产地，但强烈建议固定核心供应批次和供应商的“质量标准”**。

这是一个在稳定性和灵活性之间做平衡的问题，具体建议如下：

**1. 为什么不能完全“死磕”单一产地？**
- **产量风险**：单一产地遭遇极端天气（如台风、霜冻），会直接导致断货。
- **品质断崖**：同一产地不同季节的糖度、酸度、香气波动极大，比如夏天的芒果和冬天的芒果风味完全不同。
- **成本陷阱**：固定产地容易让供应商摸清底牌，议价空间变小；且产地价格飙升时，你无法切换性价比更高的替代产区。

**2. 为什么一定要“固定批次”？**
水果是生鲜，不同批次的成熟度差异巨大。如果你今天进的芒果是7成熟，明天是9成熟，你的配方比例、糖浆添加量全部要变，严重影响出品稳定。

**核心做法：**
- **锁定“采后标准”而非“产地”**：和供应商签订协议，明确**糖度值（Brix）、酸度、单果重量、成熟度（几成开）**。例如：“台农芒果，要求糖度16度以上，单果重200g±20g”。只要达到这个标准，不管产地是哪，都能用。
- **建立“同批号锁鲜”机制**：每次进货后，将同一批次的果品分装标注“生产日期+到货批次”，优先使用旧批次（先进先出）。

**3. 具体采购执行的“三段式”策略：**
- **主产区锁定（70%的量）**：选定1-2个核心产区（如草莓选丹东），签长约，确保季度大头供应。
- **次产区替补（30%的量）**：保留1-2个备用产地（如云南草莓替代），一旦主产区品质下滑或价格暴涨，立即切换，保证不断货。
- **动态备胎（应对极端）**：和2-3家批发商建立“应急微信群”，平时只做关系维护不拿货，专用来处理突发缺货。

**4. 最容易被忽略的“批次试饮”环节**
每次新到一批次的果品，**必须做“峰值测试”**：
- 将新批次水果和当前正用的批次做同配方盲测（做两杯一样的，让员工投票）。
- 如果新批次风味差异超过可接受范围（比如喝不出明显区别即可，水果纤维质感除外），**坚决退货，或者调整配方糖度比例**，不要硬用。

**总结结论：**
不要问“要不要固定产地”，而应该问**“能不能固定品质参数”**。你的进货单上应该写的是 **“糖度≥15°、无皱皮、无霉斑”** ，而不是单纯写“福建漳州产地”。这样既保住了口味下限，又留住了灵活进化的可能。
