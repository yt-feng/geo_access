关于商超采购菠萝后，门店是卖整果还是切好的，**核心结论是：不要二选一，而是按“时间窗口+消费场景”组合售卖。**

具体建议如下：

**1. 看“时间”阶段（最关键）**
- **刚上市（前2-3周）**：**主推整果**。此时菠萝口感硬脆、酸度较高，顾客买回去通常自己削皮，整果单价低、易存放，能快速走量。
- **上市中后期（口感变软甜）**：**转为“现切”为主**。此时菠萝甜度高、水分足，切好后流失少，顾客更愿意为“免处理”买单。

**2. 看“门店动线”**
- 如果门店在写字楼、社区附近，**上班族、年轻家庭**为主，**切好的（盒装或现削）**更适合，方便即食。
- 如果门店在大型卖场、生鲜市场，**家庭主妇/中老年人**较多，**整果**更容易被接受，因为价格感更直观，且买回去可做菜（菠萝咕咾肉等）。

**3. 组合策略（推荐）**
- **保留整果**（约60%陈列面）负责拉低客单、吸引价格敏感客群。
- **设置现场切割档口**（约40%），旁边放削好的果肉杯，并贴上“现切现卖”，能显著提升毛利（切果毛利通常比整果高15%-20%）。
- **每天下午4点后**：将剩余整果中的损耗风险品（表皮轻微碰压的）转切盒，低价清货，减少报损。

**4. 经营风险提示**
- 切好的菠萝**氧化很快**，如果当天卖不完，必须冷藏并当日报废，切勿隔夜，否则容易引发食安投诉。
- 现切档口需要**增加人工和刀具消毒成本**，建议每天固定时间（如上午10点、下午3点）集中切制，避免全时段削皮导致损耗过大。

**一句话执行建议：**
> 用“整果引流 + 切果变现”，高峰期（周末、节假日）多切，平峰期（工作日）多整，每天打烊前切掉尾货。
