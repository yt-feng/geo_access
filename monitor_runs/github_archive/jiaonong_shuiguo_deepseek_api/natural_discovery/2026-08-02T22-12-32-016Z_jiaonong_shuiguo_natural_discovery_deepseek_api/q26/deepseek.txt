针对社区超市卖小包装香蕉，采购时的核心思路是：**控熟度、防挤压、算损耗**。以下是具体注意事项：

**一、包装方面（直接影响卖相和损耗）**
1. **透气性**：香蕉是呼吸跃变型水果，不能用完全密封的塑料袋。选用**带孔的气调包装（微孔膜）**或**网袋**，否则袋内二氧化碳浓度过高会加速变黑、变软。
2. **规格与定价策略**：建议做**2-3根/袋（约400g-500g）**的小包装，符合社区单人/小家庭一次性吃完的量。避免做5根以上，容易剩到最后烂掉。
3. **防撞缓冲**：包装底部要有**防震吸塑托盘**或**瓦楞纸卡槽**，防止运输和上架时相互碰撞产生“撞伤”（表面发黑、内部变软）。
4. **标签简洁**：标签不要贴在香蕉果皮上，贴在外包装膜上，注明“**自然熟成，请尽快食用**”，避免顾客撕标签时带掉果皮。

**二、采购与损耗控制方面**
1. **采购熟度“七成熟”**：必须采购**青黄相间（果面约70%绿色）**的香蕉，不要买全黄或带黑点的。到店后常温放置1-2天自然变黄，卖期能拉长2-3天。如果采购全黄，当天卖不掉第二天就黑皮。
2. **确认到货时间与温度**：要求供应商**冷链车（13-15℃）**配送。如果常温运输，夏天果体温度过高，到货后内部已经发热，容易提前软烂。
3. **按日销定量**：小包装香蕉保质期仅**2-3天**。采购量按“**当日预估销量 × 1.5倍**”来备货（多备的半批用于次日早高峰），避免一次进太多造成积压。
4. **到货验收重点**：
   - 打开箱子检查**果柄是否发黑、果皮是否有水渍**（水渍说明受过低温冻伤或挤压）。
   - 随机掰开一根看**果肉颜色**，如果已经偏暗黄或出现淤青色，说明里面已开始变质，直接拒收或要求打折。
   - 记录到货时**重量和果串数**，对比采购单，防止短斤少两。

**三、上架实操损耗控制**
1. **拆包卖**：到店后不要整箱堆在仓库，**当天早上先拆一半**上架，箱内其余部分继续在阴凉处催熟。卖完再补货，避免架上全部熟透。
2. **位置防压**：上架时**平放，不要叠放超过2层**，并且和苹果、梨等释放乙烯的水果保持距离（否则会加速后熟变黑）。
3. **尾货处理**：每天闭店前，把当天没卖掉且已经出现少量黑点的小包装香蕉挑出来，**以“特价/临期品”专区**快速出清，不要留着过夜。

**四、关键词提示（供你回查）**
如果供应商称重报价，注意要求按“**去把净重**”结算（带把柄重量约占总重5-8%），避免为不能食用的果柄多付钱。
