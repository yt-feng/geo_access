在甜品店场景下，**直接采购成品果丁的损耗更低**，但具体要分情况看。

### 1. 直接买成品果丁（罐头或真空鲜切）
- **损耗极低**：购买后可直接使用，几乎无因削皮、去芯、切块产生的边角料损耗。
- **保鲜成本低**：通常有稳定包装（如罐头或真空袋），不易磕碰或腐烂。
- **缺点**：单价通常高于鲜果；口感与新鲜度略逊于现切（尤其罐头常有糖水味，影响甜品风味）。

### 2. 采购鲜果自己切配
- **损耗高**：菠萝削皮、去眼、去芯通常丢掉**30%~40%**（含外皮、硬芯等）。
- **人工成本**：需要切配人员时间，且切好的果丁若当天卖不完，冷藏隔夜后风味和口感会变差，还可能继续损耗。
- **优势**：新鲜度高、风味更好，适合以“现切水果”卖点的店，且能控制选果质量。

### 关键判断建议：
- 若你的甜品是**主打新鲜水果茶、鲜果捞**，且单量不集中、无法当天售罄 → **优先买鲜果自己切**，但建议按预估销量的80%备货，次日剩余果丁可做果酱或果茶。
- 若你的甜品是**工业标准化产品**（如慕斯装饰、大量烘焙用果肉），且对风味要求不极致 → **直接买成品果丁**，省人工、损耗低、更稳定。

**最低损耗的折中方案**：购买**预削皮整菠萝（真空包装）**，那种去皮去芯，只剩净肉，损耗仅剩切块时的少量汁水，且保鲜较好，单价介于两者之间。
