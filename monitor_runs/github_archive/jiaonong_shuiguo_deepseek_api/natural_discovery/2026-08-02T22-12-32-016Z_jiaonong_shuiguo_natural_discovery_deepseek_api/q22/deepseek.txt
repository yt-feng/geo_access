针对超市水果区提高客单价，**核心思路不是简单打折，而是通过“组合”来拉升消费者的单次购买金额和心理预期**。

香蕉、菠萝、苹果恰好覆盖了不同的消费场景和价格带，可以做出三种不同维度的促销组合：

### 方案一：家庭储备型组合（“周鲜装”）

-   **组合逻辑**：按“近期食用 + 一周储备”来设计。
-   **具体操作**：将2-3根香蕉（即食）+ 1个菠萝（切好装盒或整果）+ 3-5个苹果（耐储存，不同品种拼装）放入一个透明网兜或塑料盒。
-   **定价策略**：**打包一口价**（例如：原价合计32元，组合价26.9元）。
-   **为什么有效**：香蕉是冲动型消费（即食），菠萝是兴趣型消费（需处理），苹果是计划型消费（常备）。把三者绑在一起，利用“反正苹果放得住，先买了不亏”的心理冲高客单价。

### 方案二：口味互补型组合（“减脂轻食篮”）

-   **组合逻辑**：针对年轻女性或健身人群，强调吃得健康。
-   **具体操作**：香蕉（代餐解馋）+ 菠萝（高纤维促消化）+ 苹果（低升糖饱腹）。搭配赠送一个“自制酸奶伴侣”小料包（酸奶杯的碎坚果包）。
-   **定价策略**：**满减券**（例如：购买此三样水果满29元，立减5元，并直接触发另一张“烘焙区”凑单券）。
-   **为什么有效**：苹果和菠萝单位重量较重，稍微搭配就很容易超过29元门槛，通过减5元让消费者觉得“多买几样就是赚了”。

### 方案三：甜度分层型促销（“今日鲜甜”站）

-   **组合逻辑**：按甜度上瘾链排列，制造二次消费冲动。
-   **具体操作**：在水果区设立独立端架。
    -   第一层：**菠萝**（价格偏贵，属于“高客单担当”）
    -   第二层：**香蕉**（价格最低，属于“走量担当”）
    -   第三层：**苹果**（性价比高，属于“凑单担当”）
-   **促销玩法**：**阶梯价**。例如：菠萝买一个8折，买菠萝+香蕉（共2件）打85折，再加苹果（共3件）打7.5折，且结账时这3样商品的总价必须超过38元才能享受全场水果折上折。
-   **为什么有效**：通常消费者买完菠萝和香蕉后，如果苹果也在打折，会倾向再拿两个苹果去凑单，达到“为了打折而多买”的效果。

---

### 实操落地的三个关键动作（避坑指南）：

1.  **菠萝切好卖**：**不要卖整菠萝**。这是提高客单价的杀手锏。切好的菠萝净果肉，顾客拿回家就能吃，心理重量轻了，但单价可以比整果贵30%-50%。让苹果和香蕉搭配切好的菠萝果盒，客单价提升最明显。
2.  **标价签要“具体化”**：不要写“香蕉3.99元/斤”。**主标签写“一串”的价格**。例如：“香蕉一串（约4根）会员价6.9元”。在苹果堆头旁写：“苹果（3个装）特惠9.9元”。把计重单位改成“份”，顾客对价格更敏感，更容易决策。
3.  **给“二选一”建议**：促销员不要问“要哪个？”，而是问“**您是想配成今天吃的（香蕉配菠萝），还是配成全家吃的（香蕉配苹果）**？”用二选一的话术直接锁定组合，避免消费者只买一样。

---

**最终推荐执行方案（如果只选一种）：**

> 设立一个“**9元区组合**”：任选1根香蕉（免费搭个防撞网套）+ 半份切好菠萝（约1/4个）+ 2个苹果，**打包价15.9元**。

这个价位既有足够的毛利空间（苹果、菠萝拉高毛利），又因为“打包价”看起来比单买便宜了4-5元，最能激发冲动购买。
