在超市采购香蕉时，要避免“太生”或“太熟”，核心是**看颜色+摸手感+结合吃的时间**。以下是可操作的建议：

**1. 按“吃的时间”选成熟度：**
- **今天/明天就吃**：选**黄色为主、带少量褐色斑点（梅花点）**的，这种是“熟透了但不烂”的甜度巅峰。
- **2-3天内吃**：选**全黄色、无斑点**的，回家常温放1-2天就会逐渐变甜。
- **囤货一周以上**：选**黄中带绿（尾部或棱角微绿）**的，别选全绿的（可能太生且催熟慢）。

**2. 用“看”和“摸”双重判断：**
- **看颜色**：避免买**全绿**（太生，可能不甜且涩）和**大面积褐色/发黑**（过熟，肉质可能软烂）。
- **摸手感**：轻轻捏香蕉中部和尾部（别捏顶部），**整体均匀微软**是刚好；**头部硬、尾部软**可能不均匀；**捏着发软发粘**说明过熟。
- **看棱角**：香蕉棱角越分明越生，**棱角圆润**说明熟度刚刚好。

**3. 额外技巧（针对挑剔场景）：**
- 如果超市只剩全绿的，**不要买**，因为家用常温催熟往往口感不佳（可能生硬）。除非你打算用苹果/乙烯利催熟。
- 如果只剩熟透的，可以买来**当天做香蕉奶昔、烘焙**，用途不同则要求不同。
- 香蕉是后熟水果，**买回来别放冰箱冷藏**（会变黑+口感沙），常温放置即可。剥皮后想保鲜再放冰箱。

**一句话总结：看你要吃多快，选对应颜色。今天吃完买带斑点的，平时吃买全黄的，想囤着等吃就买微带青的。**
