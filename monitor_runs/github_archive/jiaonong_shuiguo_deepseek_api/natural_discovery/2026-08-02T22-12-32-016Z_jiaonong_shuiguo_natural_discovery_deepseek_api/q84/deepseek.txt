针对家庭场景的水果礼盒，建议以“营养搭配 + 耐储存 + 口感层次”为原则。以下给出三组直接可用的组合方案，并附上选择理由，方便你按预算和需求挑选：

---

### 方案一：经典均衡型（最推荐，性价比高）
**组合：** 苹果 4个 + 橙子 4个 + 香蕉 1把（约5-6根） + 菠萝 1个  
**理由：**  
- **苹果、橙子**耐放，常温可存1周以上，适合家庭慢慢吃。  
- **香蕉**提供即食甜香，但需提醒2-3天内吃完，避免过熟。  
- **菠萝**可切开后冷藏，增加新鲜感，且菠萝维C含量高，适合全家补充。  
- **份量**：约8-10斤，两三天可吃完，不易浪费。

---

### 方案二：轻食营养型（适合有小孩/老人家庭）
**组合：** 苹果 2个 + 橙子 3个 + 香蕉 2根 + 菠萝 半颗（切好分装）  
**理由：**  
- 减少单次份量，避免吃不完。  
- 菠萝半颗可提前削皮切块，用保鲜盒装好，方便老人小孩直接吃。  
- 香蕉按“2根/天”的量给，避免一次囤太多。  
- 适合放在办公室或小家庭随取随吃。

---

### 方案三：实惠大规格（适合聚会或送礼）
**组合：** 苹果 6个 + 橙子 6个 + 香蕉 2把 + 菠萝 2个  
**理由：**  
- 足够4-6人吃2-3天，适合周末家庭聚会。  
- 菠萝可做两种吃法：一个切块冰镇，一个做菠萝饭/果汁。  
- 注意：香蕉需尽快吃，或选择较生的香蕉（放2天自然熟）。

---

### 小贴士（团购执行建议）
1. **果品成熟度**：香蕉选微青的（到货后1-2天熟）；菠萝选带绿叶、按蒂部稍软的；苹果橙子选果香浓、无外伤的。  
2. **包装建议**：用硬纸盒或竹篮内铺碎纸条，菠萝单独用网套固定，防止压坏。  
3. **份量调整**：若家庭人数少，可把“菠萝1个”换成“菠萝蜜1盒”或“小西瓜1个”，但原方案更经典。  
4. **价格导向**：如果追求低价走量，用“苹果+橙子”做基础款，另加一根香蕉做点缀，成本更低。

---

如果需要更极致的保存方案（如冷藏、切块装盒），或有特殊口味偏好（例如换成柑橘类、圣女果等），可以再调整。直接按此方案组织团购即可。
