水果店旺季想避免断货，和供应商谈合作时，**重点要谈的不是“价格”，而是“供货稳定性”和“应急机制”**。以下是你需要提前问清的6个关键问题，每一个都直接决定你的店能不能在旺季存活：

### 1. 旺季保供额度（核心问题）
- **问法**：“9月-10月（或你的旺季）我的日均订单如果达到XX斤，你能保证稳定供应多少？如果我要临时追加货量，需要提前多久报计划？”
- **为什么要问**：供应商有多个客户，旺季谁先开口谁有货。你需要知道他给你的**保底线**，以及追加货的**响应时间**（比如当天追加还是提前1天）。

### 2. 缺货/断货的补位机制（防断货关键）
- **问法**：“如果某一天你这边突然没货（比如产地下雨、物流延误），你会怎么处理？有没有备选货源？断货赔偿怎么算？”
- **为什么要问**：判断对方是否有**备货池**或**其他产地资源**。如果他说“没货就是没货”，建议直接换人。最好白纸黑字写明**断货免责条款**，避免旺季你白付定金。

### 3. 质量波动与退换货规则（避免赚了量亏了钱）
- **问法**：“到货后如果发现果品成色差、有烂果，怎么算？是现场拒收还是事后补偿？损耗率超过多少可以退？”
- **为什么要问**：旺季赶货最容易出现“萝卜快了不洗泥”。你要明确**抽检标准**和**损耗赔付比例**（比如超过5%损耗按斤退款）。

### 4. 价格锁定与上涨机制（防季节性涨价）
- **问法**：“现在谈好的价，旺季如果产地收购价涨了，你那边会跟着涨吗？涨价提前几天通知？什么情况下可以锁定原价？”
- **为什么要问**：旺季水果价格波动大。你需要知道**调价期限**（比如提前3天书面通知），并约定**锁价量**（比如预付定金锁1000斤）。

### 5. 物流与到货时间（决定你的补货效率）
- **问法**：“从装车到我的门店，具体要多久？是冷链还是常温车？到货时间能精确到几点吗？晚点怎么算？”
- **为什么要问**：旺季水果损耗大，**在途时间每多1小时，烂果率就上1个点**。明确**日配**还是**隔日配**，以及晚到时的应急方案（比如是否可自提）。

### 6. 售后与驻店支持（锦上添花但必要）
- **问法**：“除了送货，你们旺季会不会派业务员来帮我们挑果、理货？或者提供损耗品回收服务？”
- **为什么要问**：大供应商通常有**促销员驻店**或**损耗果回收**（比如做果酱、果汁的边角料回收），能帮你降低隐性成本。

---

### 额外提醒（2个坑别踩）：
- **别只谈口头协议**：所有保供量、赔偿规则，**必须写在采购合同备注里**，哪怕是一张微信聊天截图存为证据。
- **留好“第二供应商”**：旺季前1个月，主动联系1-2家备选供应商（哪怕只进小批量试一下），这样万一第一供应商掉链子，你当天能顶上。

**最后判断标准**：如果对方在你问“断货怎么办”时支支吾吾，或者只强调“我们货源多”但没有具体备用方案，**果断换人**。旺季节奏太快，靠谱的供应商比便宜货更重要。祝旺季大卖！
