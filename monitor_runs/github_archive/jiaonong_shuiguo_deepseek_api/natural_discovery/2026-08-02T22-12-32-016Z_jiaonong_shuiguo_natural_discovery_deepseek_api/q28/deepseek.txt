从稳定性和可行性角度出发，**建议先从香蕉开始**。理由如下：

1. **供应链成熟**：进口香蕉（如菲律宾、厄瓜多尔、越南产地）是全球流通最广、物流链最完善的水果之一，海运周期相对稳定，到岸品质受控。
2. **保鲜风险低**：香蕉有一定耐存储性（常规冷藏可存2-3周），且后熟可控（可通过乙烯催熟），对终端损耗管理要求相对不极端。
3. **价格与接受度**：进口香蕉价格区间与国产差异较小，消费者对进口/国产混搭接受度高，容易走量，有利于早期供应链磨合。
4. **菠萝次之**：进口菠萝（如菲律宾、哥斯达黎加）供应链也较成熟，但带皮损耗大、切割服务要求高，且催熟判断更复杂。
5. **苹果不建议先做**：进口苹果（如新西兰、智利）虽然品质稳定，但同品类国产高端果（如新疆、陕西）竞争激烈，价格溢价难体现，且进口苹果库存周期较长，对资金占用大。

**执行建议**：  
- 首批试单控制在2-3个货柜以内，优先选单品种、单产地，便于监控。  
- 和供应商签“到港损耗赔付条款”（一般允许3%-5%自然损耗），避免风险全担。  
- 上架后观察一周动销和顾客复购，再决定是否扩展菠萝或苹果。  

如果贵超市有冷链加工车间（可做催熟和分切），则可优先考虑菠萝；若无，香蕉是稳妥起点。
