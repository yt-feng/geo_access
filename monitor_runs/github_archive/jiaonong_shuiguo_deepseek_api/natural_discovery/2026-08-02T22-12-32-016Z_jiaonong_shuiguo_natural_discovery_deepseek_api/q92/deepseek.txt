针对便利店面积小、需兼顾坪效与水果损耗的情况，建议遵循“**少而精、快周转、本地化、重陈列**”的原则。具体执行建议如下：

**一、品类控制：精简SKU，聚焦“三高”**

1. **按面积定基础SKU数（建议）**
   - **40㎡以下**：只上4-6个SKU（单品）。
   - **40-80㎡**：6-10个SKU。
   - 禁止铺满货架，每平方陈列水果的SKU超过1.5个会直接拉高损耗。

2. **必须选的四种高流转品类**
   - **日常引流款（2个）**：香蕉（毛利低但走量大，水份蒸发慢）、苹果（红富士，耐储存）。
   - **应季爆发款（1-2个）**：当季最热门水果，如夏季西瓜切块、秋季橘子，价格透明自带流量。
   - **高利润补充款（1个）**：如圣女果或蓝莓小盒装，客单价高且适合即食。
   - **组合/加工款（1个）**：**建议直接买“鲜切”拼盘**（如切好的菠萝、哈密瓜），毛利可达60%以上，且到期前2小时可打折止损，是控制损耗的核心。

3. **绝对不碰的品类**
   - 大包装整箱买（如整箱橙子、整箱梨）。
   - 极易腐坏的浆果类（草莓、桑葚）若当日无法售完，坚决不进货。
   - 依赖冷链长时间存储的进口果（如车厘子、牛油果），除非有日清能力。

**二、损耗控制核心策略**

1. **以销定采（日采日清）**
   - 每日**早晨8点前**下单，**下午4点**对剩余水果进行**二次清点**。
   - 订货量公式：`明日订货量 = 昨日销量 × 1.2（安全系数）`。如果昨日最后2小时有大量滞销，安全系数降为0.8。

2. **分级损耗管理**
   - **A级（卖相完好的原果）**：放在货架正面，原价。
   - **B级（轻微碰伤、表皮瑕疵）**：**立即转为“鲜切”**（切掉坏处），装入透明盒，贴“当日特价”标签，定价为原价6折。
   - **C级（有明显软烂）**：**直接报损丢弃**，不要试图低价卖，会拉低门店口碑并增加投诉。

3. **陈列与温度控制（减少物理损耗）**
   - 香蕉**不要**和其他水果混放（乙烯催熟会加速周边水果腐坏），单独放置。
   - 叶类果（如提子、葡萄）和切开的瓜类**必须冷藏**，且不能在冷库放置超过1天（易出水）。
   - 避免“翻堆式”理货：顾客翻走后，员工不要全部翻底，只补缺位，减少机械伤。

4. **每日三时检查法**
   - **早市**（8:00-9:00）：挑出过熟果。
   - **午市**（12:00-14:00）：对热销款进行补货，同时将不新鲜的挪至打折区。
   - **晚市**（18:00-19:00）：**进行“闭店前冲刺”**，所有剩余水果统一打7折销售，或与关东煮、便当捆绑满减，目标当日清空率≥90%。

**三、采购避坑建议（针对小面积）**

1. **找本地批发市场“尾货”**：下午4点以后去批发市场，专门找“今日不得隔夜”的散货，价格可低30%-50%，适合鲜切。
2. **避免一次购齐**：不要采购全品类，一次进货控制在3-5种，卖完再补。
3. **善用“以货易货”**：如果隔壁店有蔬菜或奶茶店，可以商量互助售卖（如对方代卖果汁，你帮卖蔬菜），降低你的仓储压力。

**最终底线（数据指标）**
- 水果动销率（当日售出/进货数量）必须 ≥ 85%。
- 周损耗率（报损金额/进货金额）一旦连续两周超过 **5%**，立即缩减SKU数量或砍掉滞销单品。

**一句话总结**：面积小就做“精品即食”，把大部分损耗留在批发市场端，而不是门店端。
