甜品店采购香蕉时，香蕉变黑主要是乙烯催熟和表皮受损伤引起的。为了避免香蕉到店后很快变黑，建议从“采购选品”“运输保鲜”和“店内存放”三个环节入手：

### 1. 采购时：选对成熟度和品相
- **避免全熟果**：采购时尽量选七、八成熟的香蕉（果皮微绿、棱角略显）。完全金黄的香蕉到店后1-2天就会开始出黑点。
- **检查外观**：不要买有挤压伤、碰伤、水渍斑的香蕉，破损处会迅速褐变并传染。
- **验货时轻拿**：开箱验货时不要用手指按压果肉，以免留下指印褐斑。

### 2. 运输中：物理防护+控温
- **平放不堆叠**：香蕉不能竖放或重压，箱内要用软垫隔开，运输时车厢温度控制在13~15℃（过高加速成熟，过低会冻伤）。
- **即时通风**：到店后第一时间开箱散热，香蕉堆放会积聚乙烯气体，加速自身变熟变黑。

### 3. 店内存放：控温+分隔乙烯
- **挂起来或平铺**：不要堆叠密封在塑料袋里。悬挂起来（用挂钩吊果柄）或单层平铺在架子上，保证空气流通。
- **避开日晒和热源**：不要放在窗边、烤箱旁或空调直吹处（冷热交替易产生水珠）。
- **分拣处理**：如果发现个别已熟透的，应立即挑出单独存放或先用掉，它会释放乙烯催熟整批货。
- **可考虑冷藏但注意**：如果短期（1-2天）能用完，可整串放在冷藏室（4~8℃），但注意表面会变褐（不影响内质）；如果甜品店需要外观干净，建议放在阴凉处即可，不要刻意冷藏。

### 额外小技巧（适合甜品店）
- **少量多次下单**：若每天消耗量不大，建议每次采购2-3天用量，避免囤货。
- **单独存放**：不要把香蕉和苹果、梨、桃子混放，它们会互相催熟。

如果到店后已经微带黑点，但果肉还硬，可以先切块冷冻（做奶昔/冰沙用），把损耗留给耐储存的用途。
