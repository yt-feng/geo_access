批量配送水果供应商的选择，核心要看 **“稳定供应能力、损耗控制、账期与售后”** 这三件事。以下是一套可直接执行的操作建议：

---

**一、先明确你的实际需求（影响供应商档位）**
- 采购频次：每周几次？单次金额？
- 人数规模：20人/50人/200人？
- 水果形态：整果（如苹果、香蕉）还是预切果盒？
- 预算范围：按人均每日/每周标准？

**二、筛选供应商的硬性标准（按优先级）**
1. **产地直供或一级批发**：优先选择有自有果园、或从本地大型批发市场（如北京新发地、上海辉展、广州江南市场）直接进货的供应商，避免二级三级加价。
2. **损耗赔付条款**：必须在合同中写明“如遇坏果、重量不足、质量问题，按比例赔付或整件补发”，这是最关键的筛选点。
3. **配送时效与冷藏能力**：要求供应商提供冷链配送车辆证明，并约定“最晚送达时间”（如午前11点前），迟到需提前通知并有补偿机制。
4. **账期灵活度**：通常至少支持月结30天，愿意提供试用期（如先送1-2次再签约）的优先。

**三、实际操作流程（5步法）**
1. **找3-5家候选供应商**：通过本地水果批发市场商户、公司周边生鲜平台、朋友公司行政推荐，不要只依赖美团/叮咚等零售平台（价格偏高）。
2. **索要资质**：营业执照、食品经营许可证、水果检疫证明、农药残留检测报告（重点看最近批次）。
3. **要求送样实测**：让每家送一份“当日清单”试吃1-2天，重点看：水果大小均匀度、成熟度是否一致、外箱是否干净无异味。
4. **比价而非比单价**：让每家提供“周套餐”报价（比如苹果、橙子、香蕉、梨各多少斤），对比总价，而不是单斤价格。
5. **签约与考核**：合同期建议先签3个月，写明KPI（每周准时率≥95%、月损耗率≤5%），连续2次不达标可解约。

**四、常见避坑提醒**
- **不要只看“便宜”**：水果批量采购中，价格低10%但损耗高20%，实际成本反而更高。
- **明确“当季优先”**：要求供应商每月提供当季推荐清单，避免拿到反季高价果。
- **预留备用供应商**：至少保留一个备选，防止主供应商断货时下午茶开天窗。
