采购菠萝时，判断熟度主要看以下几个方面，既能保证口感，又能减少损耗：

**1. 看外观：**
- **颜色**：成熟的菠萝外皮呈**金黄或橙黄色**，且颜色越深通常越甜。如果外皮大面积还是青绿色，说明偏生；如果外皮出现褐色或发黑，且按压有凹陷，则可能过熟或开始变质。
- **果眼（棘突）**：菠萝表面的“眼”越深、越突出，通常说明成熟度越高、更甜。若果眼扁平且浅，可能不够熟。
- **底部**：看菠萝底部的切口，切口越新鲜、果肉颜色呈淡黄色或白色，说明刚采收不久；如果底部发软、发黑或有异味，说明存放过久。

**2. 按压手感：**
- 用手轻轻按压菠萝中部，如果**稍微有弹性、能感觉到果肉紧实且略微回弹**，说明熟度刚好。
- 如果按压感觉**硬邦邦、按不动**，说明生；如果**按压有明显塌陷、软烂感**，说明过熟或内部可能受损。

**3. 闻气味：**
- 成熟的菠萝凑近底部（切口处）能闻到**浓郁的菠萝香气**。如果闻到淡淡的清香但不够浓，说明稍生；如果闻到酸味或酒味，说明已发酵或变质，应放弃。

**4. 掂重量：**
- 同样大小的菠萝，**分量更重**的说明水分足，通常更新鲜，成熟度也更均衡。轻飘飘的可能内部干瘪或过熟。

**采购建议（针对损耗）**：
- **不要全买全熟**：全熟的菠萝再放1-2天就容易变质，损耗极高。建议按比例采购——**约70%选“八成熟”**（外皮黄色但略带青、按压有弹性、闻着有淡淡香味），**30%选“全熟”**（颜色全黄且香气浓）用于当天或次日销售。
- **检查果柄和底部**：如果果柄发黑、底部有裂口，说明容易腐烂，即使看起来熟度合适也要谨慎采购。
- **批次备注**：采购时用记号笔在包装或菠萝上标好到货日期，上架时先卖先到的，避免堆积造成过熟损耗。

总结：**“按弹性、闻香气、看底部、别全熟”**，综合判断，能有效平衡口感和损耗。如果批发商允许，可现场切开一个进行试吃确认，最直观。
