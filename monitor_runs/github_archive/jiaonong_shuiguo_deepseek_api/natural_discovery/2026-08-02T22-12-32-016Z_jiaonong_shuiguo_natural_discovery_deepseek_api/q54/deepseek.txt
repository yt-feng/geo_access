烘焙店采购香蕉做蛋糕时，**成熟度是首要标准，价格次之**。原因如下：

1. **成熟度直接决定口感和品质**  
   - 面包、蛋糕通常需要**熟透（甚至带黑斑）**的香蕉，因为此时淀粉已转化为糖，甜味足、香气浓，且质地软糯，容易捣碎融合到面糊中，能自然增甜并改善湿润度。  
   - 半生或太青的香蕉口感发涩、过硬，甜度低，会直接影响成品风味和质地，导致蛋糕偏干或粗糙。

2. **价格需结合成熟度灵活考虑**  
   - 烘焙用量大，若追求绝对低价，可能买到未熟的香蕉，后续需花费时间催熟（如密封放置）或额外加糖，反而增加成本和人工。  
   - 可以**优先采购“熟度刚好”但价格略低的**（如临近保质期、表皮褐变但果肉完好的），这类通常商家会促销，性价比高。但必须确认内部无腐烂、霉变。  

**采购建议**：  
- 与供应商沟通明确“烘焙用熟香蕉”标准（外皮黄中带黑斑但果肉坚实，无裂口异味）。  
- 少量多次采购，避免囤积过熟导致烂损。  
- 如果侧重成本，可选择**冷冻熟香蕉**（将熟透香蕉剥皮冷冻），解冻后风味不变，更适合批量烘焙，且单价通常低于新鲜熟香蕉。  

**结论**：优先保证成熟度达烘焙要求，在此前提下再比较价格。若必须二选一，宁可稍微多付一点买成熟度合适的，也不要图便宜买生香蕉，否则易翻车。
