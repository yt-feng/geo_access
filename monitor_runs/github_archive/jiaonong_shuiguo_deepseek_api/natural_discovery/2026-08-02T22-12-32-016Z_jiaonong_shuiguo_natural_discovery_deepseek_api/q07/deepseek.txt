针对水果礼盒，**苹果、橙子、香蕉、菠萝**这四种水果组合，建议遵循“**色彩分明 + 大小错落 + 耐放优先**”的原则来搭配。以下提供三种主流且好卖的方案：

---

### 方案一：经典吉利款（最稳妥）
**搭配**：苹果（红） + 橙子（黄/橙） + 香蕉（黄）  
**说明**：颜色喜庆，价格亲民，适合春节、中秋等传统节日送礼。香蕉放最底层或侧边，苹果和橙子叠放顶层。

---

### 方案二：高端果篮款（利润高）
**搭配**：苹果（红/绿） + 菠萝（顶叶留长） + 橙子  
**卖点**：菠萝是视觉主角，摆中间或顶部，橙子垫底当“固定墩”，苹果塞缝隙。菠萝带叶看起来高档，适合走亲访友。

---

### 方案三：养生轻享款（年轻客群）
**搭配**：香蕉 + 橙子 + 苹果（少量） + 菠萝（切块装盒）  
**说明**：菠萝切块用透明盒装好，适合进公司或办公室赠送；香蕉选饱满整齐的，整体走“即食新鲜”路线。

---

### ⚠️ 关键实用建议（直接影响好不好卖）

1. **香蕉必须底部垫软纸/泡沫**，避免压伤碰黑，否则顾客打开礼盒会失望。
2. **菠萝选生的**，进盒前表皮微青，运输途中自然后熟，能延长存放期3-5天。
3. **苹果和橙子擦净打蜡（食用蜡）**，表皮光亮亮，卖相提升30%。
4. **组合不要超过4种**，这四种已经是极限，再多显得杂乱，且顾客会担心“坏得快”。
5. **标价策略**：建议分两档——低配88元（苹果+橙子+香蕉），高配168元（加菠萝并加大果径），让顾客有对比选择。

---

**最终推荐首选**：  
红苹果（6个） + 橙子（4个） + 香蕉（1把） + 小菠萝（1个，留叶）。  
菠萝放右上角当“塔尖”，用竹签固定装饰，既好看又避免挤压。
