在超市采购水果时，供应商一般需要提供以下检测报告或进货证明，以确保食品安全和合法合规：

### 1. 强制性证件（必须有）
- **营业执照**：确认供应商是合法经营主体。
- **食品经营许可证**（或食品生产许可证）：表明其具备水果销售或生产的资质。
- **食用农产品合格证**：各地普遍要求，由生产者或供货者出具，承诺产品合格。

### 2. 检测报告（核心）
- **农药残留检测报告**：这是最重要的，应包含有机磷、氨基甲酸酯类等常见农残项目的检测结果，且需在有效期内（通常为3个月或半年）。
- **重金属污染检测报告**（如铅、镉、汞、砷）：产地或品种有风险时尤其需要。
- **微生物检测报告**：针对表面接触果肉、易破损或即食类的进口水果。

> 若为 **绿色食品、有机食品、地理标志产品**，需提供相应认证证书及季度抽检报告。

### 3. 进货来源证明
- **进货发票或购销合同**：证明货物来源合法、可追溯。
- **产地证明或供应商资质复印件**：如生产基地的营业执照或种植基地备案信息。
- **运输温度记录单**（如果涉及冷链运输的水果，如草莓、蓝莓需冷运）。

### 4. 针对特殊水果的额外资料
- **进口水果**：必须提供《入境货物检验检疫证明》以及海关报关单，且外包装需有中文标签。
- **预包装水果（如盒装切盘）**：需提供生产日期、保质期、生产商信息及出厂检验报告。

### 5. 索证索票的量化建议
- 采集时要求供应商 **每批次** 提供检测报告，不要接受过期报告。
- 建立《供应商档案清单》，记录每种水果对应的证件有效期。
- 保存所有凭证至少 **2年**（根据《食品安全法》要求）。

---

**提醒**：若供应商无法提供农药残留检测报告或拒绝提供营业执照，建议直接取消合作，因为这是采购合规的基本底线。你可以要求供应商出具“食用农产品合格证”作为快速替代，但必须附有法定代表人签字或盖章。
