评估水果连锁门店的供应商仓配覆盖，不能只看“能不能送”，核心要回答三个问题：**能不能准时送达、能不能保新鲜、成本是否可控**。

以下是可执行的分步骤评估方法：

**第一步：先做“半径-时效”匹配**
1.  **拉出所有门店坐标**：按城市分组，标注每个门店的地址、日均销量、SKU数量（尤其是叶菜/浆果等高损耗品占比）。
2.  **核算“最后1公里”时效**：跟供应商确认每个仓的**最晚截单时间**和**承诺到店时间**。例如：今天21:00前下单，明天早上8:00前到店。
3.  **画“热力圈”**：以供应商DC（配送中心）为圆心，标出能覆盖的半径。**判断标准**：单程配送时间超过3小时（或超过150公里）的城市，强烈建议要求供应商增设**前置仓**或**城市协同仓**，否则损耗会吃掉毛利。

**第二步：做“频次与批量”的压力测试**
- 水果不能像干货一样一周送一次。评估供应商是否能做到**A类店（高销量大店）每日一送**，B类店（社区店）**隔日一送**。
- 关键指标：询问供应商在不同城市的**最低起送金额/件数**。有些供应商跨城配送，单店起送量大，会导致门店压货，必须调低至“单店日销量的1.2倍以内”才算健康。

**第三步：用“波动模拟”检验韧性**
水果受天气、行情影响极大。向供应商提三个“如果”：
- 如果A城市突降暴雨，货源断供，他是否有**异地调拨**的备选方案？（比如从B城市仓库跨城发冷链车）
- 如果某门店单日销量暴增2倍（节假日促销），他能否在**24小时内**从临近仓调货？
- 各仓之间的**安全库存周转天数**是多少？低于1.5天的仓，风险较高。

**第四步：核算“冷链物流破损率”**
这一步最容易被忽略。要求供应商提供**最近3个月的签收破损率**和**拒收率**。
- 如果破损率>3%，说明其周转箱、泡沫箱或冷链车温控不达标，跨城配送的损耗会转嫁给你。
- 如果数据敏感不提供，可以**做一次盲测**：随机选3个不同城市门店，下单同一批高价水果（如车厘子），看实际到货品质是否一致。

**第五步：价格与覆盖的“利益平衡”**
- 跨区域配送通常会有**物流附加费**。你需要算清：是让供应商统一配送到门店更划算，还是**由供应商集中送城市总仓、再由本地城配分拨**更划算？后者能显著降低跨城冷链成本。
- 谈判要点：如果某城市门店数量超过3家，应该要求供应商**免收跨城配送费**或给予该城市**专属阶梯价**，否则覆盖不经济。

---

**最终决策建议表：**

| 评估维度 | 合格线（绿区） | 黄区（需谈判） | 红区（淘汰） |
| :--- | :--- | :--- | :--- |
| 配送时效 | 12小时内到店 | 24小时内到店 | 超过48小时 |
| 最低起送量 | <门店单日销量的1倍 | 1-1.5倍 | >2倍 |
| 破损率 | <1% | 1%-3% | >5% |
| 应急调拨 | 有明确的跨城支援预案 | 有，但需额外收费 | 无预案或无法响应 |

**最后给你一个实操提示**：不要迷信“全国仓网”，优先评估**在主干城市（如省会/枢纽）是否有DC**。如果供应商只在产地发货，无论他宣传多强大，都不适合做连锁鲜果的日常供应。建议你亲自去其DC看一圈冷库温度记录仪和分拣线，比看PPT有用得多。
