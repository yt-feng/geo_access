采购方在试卖新品时，建议**首批试卖量控制在门店（或线上渠道）**周正常销量的 **10%～20%**，同时**最少备货3～5天的安全库存**。

具体可以参考以下策略：

1. **按渠道定基础量**  
   - **线下门店**：单店试卖量建议不超过该店同类水果周均销量的 **15%**，若门店不大，可控制在 **10～15箱/店**（或10～15公斤，视单品大小而定）。  
   - **线上平台/社群**：由于退货和损耗风险更高，首周备货量建议为预计日单量的 **5～7倍** 作为上限，防止断货也避免积压。

2. **按品类调整**  
   - 高损耗（如草莓、山竹、榴莲）：按 **5～8%** 周销量试卖，宁可缺货不可压货。  
   - 低损耗耐储存（如苹果、柑橘、柚子）：可提高到 **15～20%**，给足促销空间。

3. **设定明确的止损/放量节点**  
   - 试卖期统一设为 **7天**（一个完整消费周期）。  
   - **3天内**：若动销率低于20%（即每天售出库存不到5%），立即降级为捆绑搭售或退回供应商，停止加单。  
   - **第7天**：如果累计售出 **70%以上** 且复购率 >15%，则考虑加量至常规订货的100%；若售出在40%～70%，继续小批量补货观察。

4. **必须同步做两件事（比数量更重要）**  
   - **占位营销**：即使量小，也要给新品预留独立陈列位（端架或堆头），配合试吃、折扣价，避免被果堆淹没。  
   - **记录反馈**：每天记录实际销量、顾客试吃转化率、退货原因，7天后用数据回传供应商，作为谈判采购价或换货的依据。

**简单总结**：  
- 大原则：宁可断货，不可烂库存。  
- 最稳公式：**试卖量 = 该店周均销量 × 10%**，且总货值不超过该店周总采购预算的5%。  
- 如果采购方资金压力小、渠道稳定，可放宽至20%，但需同步签订**未售罄换货或退货运费共担条款**，降低风险。

建议你直接用这个公式算一下当前门店的周销量，再跟供应商签个短周期的试销补充协议，比拍脑袋订货更稳妥。
