在水果采购合同中，**坏果率超过 3%～5%** 时应设置赔付条款。具体比例取决于水果品类、运输周期和双方议价能力：

- **常规鲜果（如苹果、橙子）**：建议约定**坏果率 ≤3%** 为合格线，超过部分（如3%~5%）按比例扣款，超过5%可整批拒收。
- **易腐水果（如草莓、荔枝、芒果）**：因自然损耗高，可放宽至 **≤5%**，但要明确“坏果”定义（如霉变、腐烂、严重压伤），排除轻微碰伤和失水皱皮。
- **长期供货合同**：建议设置阶梯赔付：  
  - 坏果率 5%~8%：按坏果重量×订单单价赔偿  
  - 坏果率 8%~15%：按坏果重量×2倍单价赔偿  
  - 坏果率 >15%：整批退货，卖方承担运费和违约损失

**关键条款必须包含**：
1. **抽样标准**：约定“到货后48小时内，双方共同随机开箱抽查，每批次抽检≥10箱”。
2. **赔付触发**：写明“抽查比例折算后，坏果率超过X%即启动赔付”。
3. **免责情形**：若因买方存储不当（如未冷藏）、运输延迟超24小时导致腐烂，卖方免责。

**实操建议**：
- 如果是首次合作，可先做“小批量试单”，用实际到货数据协商最终比例。
- 合同里写明“坏果率”计算方式为：坏果重量 ÷ 该批次总重量 ×100%，避免按数量引发争议。
- 若对方为大型供应商，可争取“坏果率≤2%”的苛刻条款作为谈判筹码，但需准备接受更高单价。

没有统一法定标准，务必以合同书面约定为准。签订前请让律师审阅条款。
