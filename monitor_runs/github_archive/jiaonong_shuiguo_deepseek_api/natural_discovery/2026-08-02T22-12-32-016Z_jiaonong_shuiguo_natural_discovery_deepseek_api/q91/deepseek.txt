针对便利店上架香蕉，**建议优先选择“小把包装（约2-3根）”为主，辅以少量“单根装”**，**整袋（5斤装以上）不适合便利店常规销售**。

具体选择逻辑与操作建议如下：

### 1. 核心结论：小把装是首选
- **销量与动销**：便利店客单价低、周转快，消费者多为“即买即吃”。2-3根的小把装既能满足一顿或一天的需求，又不会因一次性买太多吃不完而放弃购买。
- **损耗控制**：香蕉是呼吸跃变型水果，整袋存放易因相互挤压和乙烯气体催熟而加速变质。小把装能显著降低单次废弃率。
- **毛利合理**：小把装单价在5-8元区间，符合便利店“零嘴+水果”的消费心理，比单根装更有“量”的感觉，比大包装更适合冲动消费。

### 2. 什么时候考虑单根装？
- **场景**：写字楼、地铁站附近的便利店，顾客随手带走，或作为早餐/下午茶搭配。
- **做法**：单根建议**按根定价**（如1.5-2元/根），并用小托盒或保鲜膜单独包好，贴在收银台附近或冷风柜旁，便于即拿即走。
- **注意**：单根暴露面积大，必须用保鲜膜包裹，否则褐变快，损耗高。

### 3. 为什么不做整袋大包装（5斤/10斤）？
- **便利店冰箱容量小**，整袋香蕉无法在门店内完成熟化控制，极易出现“一边青硬、一边软烂”的品质问题。
- **价格敏感度高**：整袋价格高，消费者会转向菜市场或生鲜超市购买，便利店无价格优势。
- **滞销风险**：若三天卖不完，整袋直接报废，单次损耗超过利润。

### 4. 执行建议（关键细节）
- **进品选“七分熟”**：不要进全熟的，选择表皮黄中带绿、果柄新鲜的批次，常温存放2天自然熟透，减少店内报废。
- **陈列位置**：放在收银台侧边货架或入口水果区，**不要与苹果、梨等强催熟水果混放**（乙烯会加速香蕉变黑）。
- **补货节奏**：每天分两次上架（上午开店、午后），每次只放少量在货架，其余暂存后仓。
- **标价策略**：建议用“2根装5.9元”或“3根装7.9元”的整数定价，比散装称重更易成交；单根可用“第二根半价”来清货。

**一句话总结**：便利店卖香蕉要“小而精”，小把装保底，单根装引流，坚决不上整袋大包装。
