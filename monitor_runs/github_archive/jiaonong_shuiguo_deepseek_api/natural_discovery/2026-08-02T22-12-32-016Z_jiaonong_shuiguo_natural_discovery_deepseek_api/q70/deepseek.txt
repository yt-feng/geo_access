在合同中明确坏果责任，核心是**划清“责任时间节点”**和**约定“验收标准与流程”**。批发商要避免货到后扯皮，建议在购销合同中加入以下条款或措辞：

**1. 明确“风险转移”节点（最关键）**
- 建议写法：**“标的物毁损、灭失的风险，自乙方（批发商）在物流单/收货单上签字确认签收时起，由乙方承担；此前（含运输途中）的风险由甲方（供货商）承担。”**
- 补充说明：若采用货到付款或物流代收，务必写明“**签收即视为对数量无异议，但不视为对质量无异议**”，防止供应商以“签收即验收”为由推责。

**2. 设定“坏果率”标准及赔偿方式**
- 建议写法：**“乙方有权在收货后24小时内对货物进行开箱抽验。若单批次坏果率（按个数/重量计）超过[3]%，乙方有权拒收该批次超标部分，甲方应按超标部分货款金额的[1.5]倍向乙方赔偿，或乙方有权从应付货款中直接扣除。”**
- 也可以约定“阶梯赔偿”：超过5%赔偿运费+货款、超过10%整批退回等。

**3. 明确“异议期限”与“除外观瑕疵外的隐蔽瑕疵”**
- 建议写法：**“乙方发现坏果应在签收后[12/24]小时内以拍照、录像方式向甲方提出书面异议，逾期视为对该批次质量无异议。但因水果内部腐烂、霉变等需切开或存放后才发现的内在质量问题，乙方可在收货后[48/72]小时内提出，甲方不得以已签收为由拒绝处理。”**

**4. 明确运输条件与责任方（若为甲方代办运输）**
- 若由甲方负责找车发货，写明：**“甲方应确保包装符合常温/冷藏（具体温度）运输要求，若因包装或装车问题导致运输途中挤压、腐烂，责任由甲方承担。”**
- 若由乙方指定物流，建议写明“**乙方指定物流公司，甲方仅负责按时备货，运输责任由乙方与物流方协调**”，这样坏果无法赖到供应商头上。

**5. 增加“不可抗力”兜底条款（防扯皮）**
- 写明：因地震、台风、封路等不可抗力导致延迟或损坏的，双方互不担责，但**甲方应在事发2日内通知乙方**，否则需赔偿损失。

**特别提醒：**
- **拍照/视频留证**是合同中约定的核心证据，务必在合同中写明“异议以现场照片/开箱视频为证”。
- 若货量大，建议写明**“抽样验收标准”**：如“按每批次随机抽取10%开箱检验，抽检结果代表整批质量”。
- 如果对方是强势供应商，可退一步：把“赔偿”改为“**补发等量好果并承担补发运费**”，更容易谈成。
