判断香蕉一手货源是否稳定，不能只看对方口头承诺，核心要看**供应链的“硬实力”和“履约记录”**。作为批发档口，你可以从以下几个关键维度去考察和判断：

**1. 看“产地锁定”而非“市场倒卖”**
- **关键指标**：对方是否拥有或长期包销**固定产区的种植基地**（如云南、海南、老挝、缅甸等）。
- **提问话术**：“你们现在主要收哪里的货？是自有基地还是到产地收散户的果？” 
- **判断标准**：如果对方说“随时能调货”、“哪里便宜收哪里的”，这种通常不稳定（行情波动大时容易断货）；如果对方能清晰说出具体村寨/农场、种植面积、砍蕉周期，稳定性更高。

**2. 看“规格稳定性”与“分级能力”**
- **实操测试**：要求对方提供连续3-5批货的**规格标准**（如每把蕉的梳数、单梳重量、成熟度控制）。
- **判断标准**：一手稳定货源能保证**同一产地、同一品种、相似成熟度**的货。如果对方每次发来的货“大小不一、熟度忽高忽低”，说明它可能是从不同渠道拼凑的，后续供应必然不稳。

**3. 看“全年供货周期承诺”**
- **关键指标**：香蕉有产季差异（如夏季中美洲、冬季东南亚），但云南、海南基地可基本全年供应。
- **提问话术**：“淡季（如高温雨季或台风季）你们怎么保障不断货？”
- **判断标准**：稳定供货商一般会说“我们有冷库保鲜库存”或“有跨产区调配资源”，而不是“到时候再看”。

**4. 考察“履约记录”与“容错机制”**
- **实操动作**：不要一次性下大单，先**小批量试单3次以上**，重点观察：
  - **准时率**：承诺到货时间与实际到货时间差多少？
  - **损耗率**：每车蕉到档口后，烂果、压伤比例是否在合理范围（通常5%以内）？
  - **售后响应**：出现短斤缺两或质量问题，对方是否爽快赔付/补货？

**5. 验证“资金实力”与“抗风险能力”**
- **关键指标**：稳定供货商一般有垫资能力。
- **调研方式**：看对方是否有自建冷库、冷藏车辆，或者是否和大的物流公司有常年协议。如果对方只做“过手生意”（货到市场再卖给你分货），说明中间环节多，断供风险大。

**6. 要求提供“车次/批次清单”**
- **直接询问**：“能不能把你们过去一个月的发货车次或批次号给我看看？”
- **判断标准**：稳定货源通常有完整的批次记录（日期、产地、数量）。如果对方支支吾吾或拿不出任何单据，大概率是临时整合的货源。

---

**总结核心判断逻辑：**
**稳定 = 产地锁定 + 规格标准 + 跨季预案 + 可追溯记录 + 售后兜底。**

**最直接的验证方法：**
先和对方签一个**“周定量保供协议”**（哪怕量小），约定如果断供，每日赔偿违约金。**敢签有违约金条款的合同**，本身就是最有力的稳定供货承诺。

如果对方一谈“合同”就退缩，基本可以断定其供货不稳定。
