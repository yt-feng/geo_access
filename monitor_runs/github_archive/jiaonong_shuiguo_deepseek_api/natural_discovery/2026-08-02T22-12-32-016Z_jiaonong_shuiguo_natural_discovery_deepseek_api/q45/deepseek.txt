跟水果供应商签年度合同，最容易踩坑的其实是**“模糊的品控标准”**和**“单向的风险条款”**。因为水果是生鲜，损耗大、品质波动大，合同一旦写得不够精确，后期大概率会产生纠纷。

以下是我帮你梳理的5个最容易踩坑的条款，以及对应的规避建议：

**1. 品控标准（最核心的坑）**
- **坑点**：合同只写“品质优良”、“新鲜”或“符合国家一级标准”。这等于没说。同一批货，供应商觉得达标了，但你的门店觉得不新鲜，扯皮无解。
- **建议**：在附件中明确**可量化的理化指标**（如甜度≥12度、糖酸比、直径范围、着色度≥80%），以及**外观缺陷率**（如碰压伤、腐烂的允许比例，例如≤2%）。同时约定**到店时的核心温度**（冷链运输必须≤X℃）。

**2. 损耗与退换货责任（最容易“吃哑巴亏”）**
- **坑点**：条款写“商品验收合格后，不予退换”或“损耗由超市承担”。水果在运输和门店陈列中必然有损耗，如果不分环节，超市要承担所有自然损耗，成本极高。
- **建议**：
    - 明确**运输途损**（如超过3%由供应商承担）和**到店前腐烂**的责任归属。
    - 约定**到货后48小时或72小时内**发生的质量问题（如内部褐变、发霉）的**追溯期**，可无条件换货或退款。
    - 明确**门店陈列损耗**（因顾客翻拣导致的损伤）由超市承担，避免责任混淆。

**3. 价格调整与锁价机制（行情波动大）**
- **坑点**：年度合同锁死单价，结果市场价暴跌时你吃亏，市场价暴涨时供应商断供。或者写“价格随行就市”，这等于没锁价，供应商想调就调。
- **建议**：采用**“基础价+浮动区间”**模式。例如约定合同基准价，当市场批发价波动超过±10%时，双方按公式重新核算结算价（如基准价 + 实际批发价×60%）。同时设置**调价通知时限**（如提前7天书面通知）和**调价频率上限**（如每月最多调一次）。

**4. 供应量与**“保底”** 条款（防止断供或积压）**
- **坑点**：合同只写“按需供应”，不设最低采购量。结果是旺季你下大单，供应商说没货；淡季你不想进货，供应商强行要求你收下。
- **建议**：约定**年度最低采购量**（如50吨）和**月度上下浮动比例**（如±20%）。同时明确**不可抗力或极端天气**（台风、冰雹）导致减产时的**替代方案**（如允许调换品种，或按比例配货）。

**5. 结算账期与质保金（资金链风险）**
- **坑点**：账期写“月结60天”，但供应商可能因账期长而降低供货优先级，甚至中途要求现金支付。或者质保金占比过高，挤占供应商现金流，导致其偷工减料。
- **建议**：明确**账期起算点**（是开票日还是对账日），建议用“对账后30天”并写明逾期付款的违约金。将质保金控制在**年采购额的2%-5%**，且约定质保金只用于覆盖**退货**，不得用于抵扣日常损耗。

---

**给你的落地建议**：
在正式签合同前，**做一次小批量试供（试采2-3周）**，重点检验：**到货准时率**（迟到几次）、**果品规格一致性**（大小是否混杂）、**对账反馈速度**。如果试供期间都经常扯皮，那么年度合同就不要签，改为季签或月签。

**最后提醒你一点**：千万不要在合同里写“一切以供应商提供的送货单为准”，这会导致你的验收入库单失去效力。所有条款最好双方**先口述沟通确认**，再由法务翻译成合同语言。
