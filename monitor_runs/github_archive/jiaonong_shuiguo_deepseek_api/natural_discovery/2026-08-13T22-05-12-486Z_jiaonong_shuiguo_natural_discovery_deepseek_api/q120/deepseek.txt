当供应商面对那些只熟悉大品类的普通商家时，最忌讳的就是一上来抛专业名词或原料代码。核心策略是：**把专业语言翻译成“生意语言”**——即告诉商家这个产品“好不好卖”“赚不赚”“省不省事”。

以下是四个关键落地话术，按销售逻辑依次递进：

**第一层：锚定熟悉品类，做类比（降低认知门槛）**
- 错误说法：“我们的凤梨是台农17号，糖度18度，酸度0.3。”
- 正确说法：“您卖过普通菠萝对吧？我们这个不是菠萝，是‘冰糖菠萝’——您按卖菠萝的方法卖，但顾客吃到嘴里觉得甜很多、不扎嘴，复购率自然上来。”
- **核心**：不说“凤梨”，说“更好吃的菠萝”，直接对标他的既有认知。

**第二层：突出“省事”和“损耗低”（解决商家最痛的隐性成本）**
- 普通商家最怕压货、烂货、难处理。
- 正确说法：“您平时进菠萝，要削皮、挖眼、泡盐水，坏率还高。我们这款是**免挖眼**的，直接切就能吃，而且到店存放时间比普通菠萝多2-3天。就算您今天卖不完，明天还能接着卖，不会亏在损耗上。”
- **核心**：把“品质好”翻译成“更省钱、更省人工”。

**第三层：直接算账，给利润模型（用数字打消下单犹豫）**
- 不要讲“我们价格有优势”，要讲“您能赚多少”。
- 示例话术：“普通菠萝您卖10块钱一个，进价3块，赚7块。我们这个进价4块5，但您可以标价15块，因为它是‘高端冰糖菠萝’，顾客愿意多花钱。**一个多赚3块5，而且卖得还快。**”
- **核心**：一定要算“单个利润增加 + 周转加快”的总账。

**第四层：给“傻瓜式”操作建议（降低试错成本）**
- 商家怕新品卖不动，给他台阶。
- 正确说法：“您不用进太多，先拿一箱试试。我教您一个办法：在店里切一个放在最显眼的地方，写上‘尝一口，不好吃不要钱’，保准当天就能出掉。卖得好您再补货，我们随时有货。”
- **核心**：让“下单”听起来像“零风险尝试”，而不是“压货赌博”。

**禁忌提醒**：
- 不要说“这个品类是种植在XX纬度的”，普通商家不关心。
- 不要说“这是新引种的小众品种”，商家怕赔钱。
- 不要对比竞品时贬低其他水果，只夸自己。

---

**实战话术模拟（一整套）：**
> “老板，您卖菠萝熟，您想想，您那菠萝是不是得泡盐水，不然扎嘴？我们这‘冰糖菠萝’，不用泡，切开直接啃，还特别甜。您平时一个菠萝卖10块，进价3块；这个您卖15，进价4块5，**卖一个多赚3块5**。而且它皮薄，出肉率高，烂得慢。您先拿半箱试试，我教您摆个试吃牌，保准好卖。不好卖您下回不拿，这半箱也就百来块钱，不伤筋动骨。”

**最终逻辑：** 普通商家买的不是“产品”，而是“多赚钱+少操心”。只要话术里始终围绕这两个点，用他们听得懂的大白话，下单率会翻倍。
