针对家庭团购水果礼盒，建议在“营养均衡”、“耐储存”、“食用方便”和“价格实惠”四个方向上组合。以下几个方案供参考：

**方案一（最经典、最稳妥）：苹果2斤 + 橙子2斤 + 香蕉1.5斤 + 菠萝1个**
- 理由：苹果和橙子耐放，香蕉补充钾和膳食纤维，菠萝开胃解腻。这个组合覆盖了日常水果的主要需求，适合大多数家庭。

**方案二（甜度优先、老人小孩都喜欢）：苹果2斤 + 橙子2斤 + 香蕉2斤 + 菠萝1个（成熟度偏高）**
- 理由：香蕉和菠萝选偏甜品种，配合苹果的脆甜和橙子的酸甜，整体好感度高，适合家里有小朋友或老人。

**方案三（性价比团购款）：苹果2.5斤 + 橙子1.5斤 + 香蕉2斤 + 菠萝半个**
- 理由：苹果便宜耐放，香蕉和菠萝水分足、份量感强，橙子作为补充酸味。这个组合成本可控，视觉量大，适合主打“实惠”的团购。

**注意事项（家庭实用维度）：**
1. **成熟度**：菠萝建议选熟度适中（底部有香味但不过软），香蕉可以选略带青的，避免到家后几天就烂。
2. **分装建议**：可以用网套包好苹果和橙子，香蕉单放，菠萝用保鲜膜裹好，避免互相催熟。
3. **份量控制**：如果家庭人口少（2-3人），建议香蕉减至1斤，菠萝备注“按客户要求切块或不切”，避免浪费。
4. **替代方案**：如果团购地区菠萝贵或不好买，可将菠萝换成1斤柿子、1斤梨或一盒蓝莓（视成本调整）。

**给团购组织的额外提示**：宣传时可以主打“每天一种水果、一周吃不完不浪费”的卖点，同时说明“支持按需调整”，能提高下单率。
