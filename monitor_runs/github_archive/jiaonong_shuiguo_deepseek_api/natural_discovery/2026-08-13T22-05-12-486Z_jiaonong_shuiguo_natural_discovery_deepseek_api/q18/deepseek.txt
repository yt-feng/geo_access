挑选香蕉时，目标是在“刚好熟透”和“还有几天缓冲期”之间找到平衡。以下是几个可执行的判断方法，按优先级排序：

**1. 看颜色（最直接）**
- **想今天/明天吃**：选**全黄且带少量棕色小斑点**的。斑点=糖分转化完成，口感最甜糯。
- **想放2-3天再吃**：选**整体黄、但蒂部（两端）还是绿色**的。这是“离熟还差一步”的最佳状态。
- **拒绝**：**通体碧绿**（到店太生，可能催不熟或口感发涩）、**大面积发黑或表皮裂开**（过熟，果肉可能发软塌陷）。

**2. 摸硬度（辅助判断）**
- 用手指**轻轻按压香蕉中部**（不要捏两端），感受弹性：
  - **稍有弹性、按下去能回弹** → 刚合适。
  - **硬邦邦、按不动** → 偏生。
  - **一按就软塌塌、甚至出水** → 过熟。
- 注意：很多超市的“熟香蕉”外皮完好但果肉已烂，所以按压中部比只看皮更准。

**3. 看果柄切口**
- 切口**新鲜、湿润**的香蕉通常采摘时间短，更耐放。
- 切口**干枯变黑、皱缩**的说明放很久了，即使皮黄也可能内部已过熟。

**4. 避开“催熟陷阱”**
- 超市里**整串挂在架上、表皮完好**的香蕉，可能被乙烯利催过，催熟后快速转黄但内部糖分未完全转化，口感会**偏酸不甜**。
- **优先选**：带青色蒂头的、单独散的（通常更接近自然成熟度）。

**5. 采购场景差异**
- **如果在大型商超**：直接去“特价区”找有少量斑点的，通常性价比最高且熟度刚好。
- **如果在小店或菜市场**：问老板“这批什么时候到的”？新鲜到货的选绿蒂，放一天的选全黄。

---

**避坑总结**：不要只看表面全黄就买，一定要**捏中部+看蒂部颜色**。如果超市货架上的香蕉已经出现**大量黑斑且果柄发软**，直接跳过，大概率是“外熟内烂”。

最后提醒：如果买回去发现太生，放**苹果或梨**一起扎袋放室温，可加速催熟；如果太熟，立即剥皮冷冻，做奶昔或香蕉面包用。
