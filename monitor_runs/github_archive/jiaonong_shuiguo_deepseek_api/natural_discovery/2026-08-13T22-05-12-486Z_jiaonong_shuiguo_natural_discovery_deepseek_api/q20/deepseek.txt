为社区超市挑选**每天配送**的水果供应商，核心是看**“稳定、新鲜、账期”**三者平衡。以下是明确、可执行的条件清单：

**1. 供货稳定性（最关键）**
- **自有或固定基地**：问清楚是否有稳定的产地（自有果园/长期合作基地），确保全年不断货。
- **补货响应时间**：明确要求当天或次日凌晨送达，并要求对方承诺**缺货提前通知**机制。
- **应急预案**：询问恶劣天气或节假日（如春节、中秋）的备货方案，防止断供。

**2. 新鲜度与损耗控制**
- **发货时间**：采购预冷、凌晨采摘/发车的时间，确认到货时水果无萎蔫、碰伤。
- **冷链能力**：配送车辆是否带冷藏/保温设备（夏季尤其重要）。
- **损耗处理规则**：签订协议，约定**到货抽检**和**自然损耗比例**（一般允许3%-5%），超出部分无条件补货或退款。

**3. 价格与账期**
- **报价透明度**：要求每日/每周报价单，区分**规格等级**（A级果/B级果），避免混掺。
- **账期灵活性**：多数社区超市资金周转紧张，可洽谈**周结或月结**，但需警惕要求预付大额定金的供应商。
- **价格波动机制**：夏季水果（西瓜等）价格波动大，确认是否按当日市场价联动调整。

**4. 品类与规格适配性**
- **小批量多品种**：每天配送，最好能**拆零供货**（例如每箱小包装），避免压库存。
- **分级包装**：按社区超市的日常销售习惯，提供**散装、筐装**或**预包装**两种形式，方便陈列。

**5. 资质与安全**
- **必要条件**：营业执照、食品经营许可证，并要求提供**每批次农残检测报告**（打印或电子版）。
- **溯源能力**：能做到**扫码溯源**（产地、采摘日期、检测信息）的优先，避免风险。

**6. 试合作期（强烈建议）**
- 先签**1-2周试供协议**，每日送少量常规品（如苹果、香蕉、橙子），重点观察：
  - 是否真实做到“天天送”且不迟到；
  - 到货品质是否稳定；
  - 出现坏果时，售后处理是否迅速（最好能“拍照秒赔”）。

**总结优先顺序**：**稳定性 > 损耗赔付 > 账期 > 品类 > 价格**。建议同时联系2-3家供应商，用试合作对比后，再锁定主力供应商。
