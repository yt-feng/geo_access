给小店供货时（不同于大型商超），**报价和分级一定不能搞“复杂标准”**，否则小店老板记不住、容易扯皮。他们最关心的是**“我能卖多少钱”**和**“烂掉多少”**。

针对香蕉和菠萝，建议采用**“按熟度/卖相分级 + 按件报价”**的方式，最清晰也最容易被接受：

### 一、 香蕉的分级与报价（核心：看卖相和熟度）

香蕉到了小店手里是会继续熟的，所以分级不要按“单根克重”分（那是出口标准），而按**“当天能不能卖”**分。

**建议分为三个等级：**

1.  **一级货（当天熟/即卖货）**
    - **标准**：果皮颜色黄绿相间或全黄，果身硬挺，无黑斑、无裂口，单串重量均匀（约25-30斤/箱）。
    - **话术**：“这个货到了就能摆着卖，不压秤、卖相好。”
    - **报价**：**单价最高**，通常比二级货每箱贵5-8元。因为小店当天能回本，最愿意进这个货。
2.  **二级货（标准青熟货）**
    - **标准**：整串偏青绿色，但果身饱满，没有冻伤或压伤。需要常温放1-2天才能黄。
    - **话术**：“这个放一天，明天全黄，利润大。如果你摊子周转慢，进这个合适。”
    - **报价**：**中等价**。小店主采购主力货，因为损耗可控（不会突然全烂）。
3.  **三级货（处理货/尾货）**
    - **标准**：果皮有少量黑点（芝麻蕉），但果肉未软烂；或者轻微碰撞，但当天卖完没问题。
    - **报价**：**直接按“沉底价”走**，比如“这箱你给XX元拿走，不称重了”，或者明显低于市价。
    - **提醒**：这个等级**不要主动推荐**，除非老板明确要卖便宜货，否则容易扯皮。

**报价技巧**：**不要报“每斤”价格，直接报“整箱”价格**。因为小店老板算账快，你报“每箱78元”，他们立刻知道“我卖3块一斤能赚多少”。如果报“每斤2.8元”，他们还要算箱子多重，容易觉得被坑。

---

### 二、 菠萝的分级与报价（核心：看大小和熟度）

菠萝保质期短，分级重点在**成熟度**和**瑕疵**。

**建议分为两个大级（不用分太细）：**

1.  **精品果（可挑货）**
    - **标准**：单果重量在1.5-2斤左右，果形椭圆（不能是瘦长形），叶色翠绿，果眼浅，无“水伤”（按压果眼不发软）。
    - **话术**：“这批是精品，果型正，切出来漂亮，顾客愿意买。”
    - **报价**：按**“个”**报，比如“这块头的，一个给你X元”。按个报价避免大小差异纠纷，且方便小店给顾客“10元2个”的定价。
2.  **通货果（统货）**
    - **标准**：大小不一，有轻微果锈或轻微熟过头，但只要削开里面是好的。
    - **报价**：按**“袋/件”**报价。比如“这件40斤，你就给XX元，回去你按个卖，利润你自己算”。
    - **特别提醒**：菠萝最容易出现“熟透了但外面看不出来”的情况。**结账前必须抽查一个切开**，如果里面是“生白心”或“黑心病”，这批货必须当场压价，否则一旦切开发黑，小店老板可能直接拒收第二天的货。

---

### 三、 让报价“清楚”的三个关键动作

光有分级还不够，批发商跟小店对接时，**必须做两件事**：

1.  **报“到手价”而不是“提货价”**：
    如果有送货费，直接明确说：“这箱香蕉78，送货费5块，一共83，转我给你。” 如果**模糊处理**（比如“货价78，运费看情况”），小店会觉得你加价离谱，合作不长久。
2.  **明确损耗责任**：
    直接定死规矩：“**二级香蕉如果到了发现冻黑、压烂的，当场拍照，当场扣钱；熟过头烂的（放三天烂的），概不负责**。”这句话很重要，因为香蕉和菠萝是呼吸跃变型水果，放久了烂是店主自己的问题，必须先说清。
3.  **用“比价法”帮他算账**：
    报价别光报数字，要帮店老板算：“这个菠萝你卖10元2个，进货4.5元/个，一天卖一个档口最差卖20个，毛利110元，比进别人的死果强多了。” 当他发现你的货好卖、利润清晰，就不会纠结你那每斤多出来的几毛钱了。

| 品种 | 等级名称 | 判断标准（一眼可见） | 报价方式 |
| :--- | :--- | :--- | :--- |
| **香蕉** | **一级（快熟）** | 黄绿相间、无黑斑 | 报**整箱价**（最贵） |
| | **二级（青货）** | 全青、饱满、无冻伤 | 报**整箱价**（中等） |
| | **三级（处理）** | 有黑点、当天消化 | 报**一口价**（不称重） |
| **菠萝** | **精品果** | 1.5-2斤、果形正、叶绿 | 报**单个价** |
| | **通货果** | 大小不一、轻微瑕疵 | 报**整件价** |

**最后一句最关键的话**：跟小店老板报价时，**永远让他先说“你给个价”**。如果他说“你这价贵了”，你就问“那你说多少钱能拿？” 这样既避免你报低了亏钱，又显得分级明确、价格有商量余地（实际不降价，但给他个“杀价成功”的面子）。
