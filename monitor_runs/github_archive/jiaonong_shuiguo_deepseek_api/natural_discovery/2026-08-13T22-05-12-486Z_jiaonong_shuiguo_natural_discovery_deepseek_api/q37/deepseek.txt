商超会员日活动是吸引客流、提升复购率的关键节点，水果作为高频刚需品类，供应商的配合直接影响活动成败。为了避免当天出现缺货、损耗高或现场混乱，供应商需要提前从**货、人、场、策**四个维度做好以下准备：

### 一、 备货与选品（核心）
1. **锁定爆款清单（至少提前10天）**：
   - 根据商超会员画像（家庭客、年轻白领），确认3-5款引流爆品（如榴莲、车厘子、西瓜、阳光玫瑰）。
   - 明确每款商品的**目标销量**（基于历史数据*1.5-2倍），并确认供应量是否充足。
2. **品级与规格调整**：
   - 会员日活动建议主推**性价比高的通货/一级果**，避免高端极品（损耗大）和低质尾货（影响复购）。
   - 确认包装规格（如整箱、单颗、切盒），切盒类需提前与商超确认加工间产能和包装盒库存。
3. **安全库存与机动补货**：
   - 设定安全库存线（建议为日常的3倍），并预留**紧急调货渠道**（如本地批发市场备用档口）。
   - 提前向商超采购确认**补货响应时间**（如当天上午下单、3小时内到货）。

### 二、 物流与仓储（时效保障）
1. **分批次配送计划**：
   - 活动前一天晚：配送基础量（预估全天销量的40%）。
   - 活动当天上午8点前：补充高峰量（60%），避免开门前无货。
   - 高峰时段（下午3-6点）：安排临时加急车，确保货架不断档。
2. **冷链与品质控制**：
   - 确认运输车辆制冷达标，避开中午高温时段配送。
   - 到店交接时，与商超收货员**共同抽检**果品新鲜度（重量、磕碰、糖度），签收责任单。
3. **周转筐与耗材**：
   - 提前准备足够周转筐、气泡柱、吸水纸，防止挤压。
   - 需和商超确认**空筐回收时间**，避免占用通道。

### 三、 人员与现场支持（执行保障）
1. **驻店促销员安排**：
   - 活动当天至少安排2名（高峰期3名）熟练促销员，负责试吃、叫卖、打包、补货。
   - **提前1天到店**熟悉堆头位置、价签打印、称重系统操作。
2. **试吃与加工方案**：
   - 准备试吃品（带好一次性手套、牙签、垃圾回收盒），试吃品需切得稍大块，保证口感。
   - 安排专人现场处理**高价水果**（如榴莲开壳、菠萝削皮），减少排队等待时间。
3. **应急培训**：
   - 对促销员进行话术培训（如“今日会员专享价，仅此一天”），并明确**退换货流程**（避免顾客纠纷）。

### 四、 商品企划与数据协同
1. **陈列与物料配合**：
   - 提供**端架或堆头设计图**（需提前3天提交商超陈列部审核）。
   - 提前印刷手写价签、爆炸贴、会员专属标识（统一风格，突出“会员价”“限量”）。
2. **价格策略确认**：
   - 确认会员价是否对标竞品（如低于周边超市5%-10%），并确认**毛利底线**。
   - 敲定买赠方案（如满50元送果叉/果袋），避免现场临时决策。
3. **数据复盘预沟通**：
   - 提前与商超采购约定**活动后48小时**内的数据复盘会（SKU销量、损耗率、客单价）。
   - 确认是否提供电子价签同步，以及会员系统是否支持**自动核销**专属券。

### 五、 风险预案（应对突发）
- **断货预案**：预留应急备用车型，若爆款断货，10分钟内联系周边批发市场调货。
- **品质预案**：若发现变质果，准备**同价位替代品**（如甜瓜换西瓜），并提前告知促销员。
- **客流超预期**：提前备好10%的散装果（不贴标），应对排队称重压力。

**最后提醒**：供应商务必在活动前3天，与商超运营、采购、生鲜经理召开一次线上或线下**碰头会**，明确每个环节的负责人和联系方式（包括商超夜班收货人员电话），确保信息同步。
