选择学校食堂水果供应商，建议重点考察五个方面：**资质、安全、新鲜度、价格、配送**。以下是具体操作建议，你可直接用于筛选和谈判：

**一、明确基本要求（采购门槛）**

1. **证件齐全**：供应商必须持有《营业执照》和《食品经营许可证》。如涉及进口水果（如进口香蕉、橙子），还需提供《入境货物检验检疫证明》。
2. **常驻经营**：优先选择在本地有固定档口或仓库的供应商，避免纯上门推销的流动商贩。

**二、按水果特性挑供应商**

- **香蕉**：对成熟度和催熟技术要求高，建议选择**有专用催熟库**的供应商（能控制温度和乙烯浓度），到货后需能提供“7成熟→校园存放2-3天自然熟”的批次。
- **苹果**：耐储运，价格透明，优先选**产地直供**或大型批发市场一级商，质量稳定且性价比高。
- **橙子**：皮薄易破损，注意供应商是否使用**防撞网套+纸箱包装**。优选能提供当季产地（如赣南脐橙、湖南冰糖橙）溯源凭证的。

**三、现场验货与试吃（关键步骤）**

- 预约一天，亲自到对方**仓库和货架**看：
  - 水果是否有虫眼、腐烂、压伤；
  - 包装是否干净、有无农药残留检测报告（要求每周更新）；
  - 香蕉催熟库温度是否在14℃-18℃之间。
- 当场随机开一箱试吃，重点看：苹果脆度、橙子水分、香蕉成熟均匀度。若对方拒绝试吃或现场开箱，直接淘汰。

**四、价格与配送条件谈判**

- **比价3家以上**：同品种同类级别，要求对方出示基础批发价，再谈合理加价（通常加价10%-15%为正常）。
- **明确配送频率**：香蕉不能长期囤货，要求**每周至少配送2次**，且早读前到货。
- **坏果处理承诺**：要求合同写明“单次配送损坏率超过5%部分，按市场价退换或折价”。

**五、合同与试运行**

- 首次合作建议**先签订30-45天试用合同**，同时要求打入质保金（例如5000元）。
- 合同中写明：
  - 每日/每周送货时间；
  - 质量验收标准（可附照片示例）；
  - 食品安全责任赔偿条款（如因水果问题引发学生健康问题，供应商承担全部责任）。

**六、常见风险排查**

- 🔴 **不要选**：无固定电话、无法提供质量承诺、报价远低于市价（可能有农药残留或次果）、只收现金不给对公账户（可能有税务或资质问题）。
- 🟢 **加分项**：已有至少2家学校/企事业食堂合作案列，可提供对方联系方式供核验。

**最后建议**：如果学校有阳光食堂平台或教育局指定的供应商名录，优先从名录里选，后续审计会更方便。若没有，按上述步骤进行本地批发市场调研（如当地农批市场），即可找到可靠货源。
