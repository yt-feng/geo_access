社区超市销售小包装香蕉，采购时最关键的是**平衡外观卖相与损耗风险**。以下是具体注意事项，分包装和损耗两个维度：

---

### 一、包装细节（直接影响卖相和保鲜）

1. **透气性优先**  
   - 香蕉是呼吸跃变型水果，会释放乙烯，包装必须**透气**。避免用完全密封的塑料袋（易积水发霉），首选**带孔薄膜袋**、网袋或带透气孔的保鲜盒。
   - 若用保鲜膜包裹，需在果柄处留缝。

2. **单份规格要灵活**  
   - 小包装建议**3-5根/份**，重量在**400-600克**之间，太轻显得不值，太重则失去“小包装”意义。
   - 可搭配不同成熟度（如2根较生+1根较熟），方便顾客今天吃一根、明天吃一根。

3. **防碰伤设计**  
   - 包装内应有**纸托、泡沫垫**或**隔层**，避免香蕉直接接触盒底或被挤压。
   - 香蕉弯度大，尽量让弯面朝上侧放，平放易压伤“脊线”。

4. **标签与熟度标示**  
   - 在包装上明确标注**“现剥即食”**或**“需催熟”**（用颜色区分，如绿色标签=偏生）。
   - 印上“请勿重压”提示，减少顾客翻拣造成的损伤。

---

### 二、损耗控制（采购源头决定损耗率）

1. **按成熟度分批采购**  
   - 避免一次性进全熟或全生。建议**70%生（青色）**，留出2-3天货架期，因为小包装整体卖得快，可在门店自然转熟。
   - 若直接进熟蕉，虽然好看但当天卖不完必损耗。

2. **果柄断裂和“黑指”问题**  
   - 采购时抽查：**果柄是否发黑、断裂**，果皮是否有**暗色压痕**（内部可能已软烂）。
   - 小包装因个体暴露，破损会被放大，验收时逐盒快速翻看。

3. **数量与周转周期挂钩**  
   - 按“**当天销量+1天安全库存**”的1.5倍订货，切勿贪多。小包装损耗率通常比整串高5%-10%，宁可缺货次日补，不可囤积。

4. **物流防护要求**  
   - 要求供应商用**硬纸箱+隔板**运输，每层香蕉间垫瓦楞纸。到货后轻拿轻放，禁止从高处摔落。

---

### 三、门店操作建议（减少卖场损耗）

| 环节 | 要点 |
|------|------|
| 上架 | 香蕉区避开空调出风口，保持**13-15℃**，湿度60%以上 |
| 翻拣 | 每天早晚各盘一次，挑出碰伤蕉打折或做果切 |
| 余货处理 | 临期熟蕉可转做**香蕉奶昔原料**或**烤香蕉**，提升价值 |

---

### 核心结论
- **包装：透气、防压、标注熟度**。
- **采购：按8成生度分批进，严查碰伤果柄**，按日销1.5倍订货。
- 损耗控制关键在于**“小批量、多频次”**，而非追求单次低价。

建议先小批量试销2周，记录实际损耗率，再调整采购频率和包装规格。
