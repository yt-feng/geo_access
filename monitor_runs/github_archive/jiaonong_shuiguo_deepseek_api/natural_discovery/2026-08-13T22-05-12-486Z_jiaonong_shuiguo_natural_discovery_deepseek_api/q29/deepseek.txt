在超市与水果供应商的谈判中，**账期（即赊销结算周期）并没有统一标准**，具体取决于供应商的规模、水果品类、超市的信用等级以及市场供需关系。不过，行业内确实有一些常见的实践区间：

**1. 常见账期范围（按主体）**

- **大型连锁超市（如永辉、沃尔玛、大润发等）**：通常要求**45天～60天**，甚至更长（90天）。因为其采购量大、议价能力强，且拥有完善的供应链金融体系。
- **中型超市/社区连锁**：一般在**30天～45天**。
- **小型超市/生鲜店**：通常**7天～15天**（或采取“现结”或“快结”模式，因为生鲜保质期短）。

**2. 按水果品类细分**
- **不耐储存的鲜果（如草莓、樱桃、荔枝）**：账期通常**极短**（1～7天），甚至采用“现款现货”或“当日结算”，因为损耗风险高。
- **耐储存的水果（如苹果、梨、柑橘、香蕉）**：账期可较长，常见为**30天～60天**。

**3. 行业背景与趋势**
- **传统惯例**：早年超市普遍要求30天左右，但近年来大型零售商为了缓解自身现金流，普遍延长至45～60天。
- **生鲜电商/新零售**（如盒马、叮咚买菜）：通常采用**“T+1”或“T+3”**（即货物验收后1～3天结算），因为其追求高周转和新鲜度。
- **供应商弱势时**：如果水果供应竞争激烈（如夏季西瓜），供应商可能被迫接受60天甚至更长的账期；反之（如精品进口水果，如晴王葡萄），账期往往缩短至15～30天。

**4. 谈判要点与建议**
- **锚定行业基准**：谈判时可直接引用“45天”作为市场平均线，再根据自身供货能力调整。
- **用“账期换价格”**：如果超市要求60天账期，可要求采购价上浮5%-8%，或要求超市承担部分仓储损耗。
- **合同明确条款**：务必写明“到账日计算方法”（如签收后X自然日）、“逾期违约金”（常见为日万分之五）以及“退货和损耗责任划分”。
- **风险控制**：对于中小超市，建议首次合作采用“先试单+短账期”（如15天），合作稳定后再延长。

**总结**：如果你是一般的区域供应商，**30～45天**是较容易达成的平衡点；如果是大型超市，你会面临60天左右的强要求。建议优先争取“现结+佣金”或“短账期+走量”的组合模式，避免单一账期压垮现金流。
