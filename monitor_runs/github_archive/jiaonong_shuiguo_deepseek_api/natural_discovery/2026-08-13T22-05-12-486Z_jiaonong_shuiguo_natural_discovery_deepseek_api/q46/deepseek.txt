针对茶饮店采购菠萝用于果茶，**最推荐的是“冻果丁”或“果泥”，不建议买鲜果**（若追求极致新鲜和门店定位高端则另当别论）。具体选择依据你的出杯效率、成本控制和风味稳定性来决定。

**三种选择的对比与建议：**

**1. 鲜果**
- **适用情况**：门店有专门后厨、客流大且当日消耗快，或主打“新鲜现切”作为卖点。
- **优点**：口感脆爽、香气最自然，可做装饰或定制果肉颗粒大小。
- **硬伤**：处理耗时（削皮、去芯、切丁）、损耗高（保存期仅2-3天）、品质不稳定（同一批熟度不均）、人工成本高。
- **建议**：如果非要鲜果，建议**改买“鲜切菠萝丁（冷链）”**，即供应商已去皮切好，门店只需简单分装，但成本较高。

**2. 速冻/冷链果丁（推荐）**
- **适用情况**：绝大多数标准化茶饮店，追求出品速度与口感平衡。
- **优点**：**口感保留度最高**（比果泥脆，有咀嚼感），使用方便（直接舀取），损耗低（冷冻保存期长），风味一致性高（选同一产区品种）。
- **缺点**：化冻后会有部分汁水析出，需注意沥干；对冷链要求高（到货后应及时-18℃冷冻）。
- **成品表现**：适合做菠萝四季春、菠萝冰茶，果肉颗粒感明显，适合“加料”型产品。

**3. 菠萝果泥/果酱（含果浆）**
- **适用情况**：做**气泡水、奶盖茶、冰沙**或需要**浓郁菠萝底味**的产品，或者门店人力极度有限。
- **优点**：**风味极其稳定**（不依赖季节），出杯速度最快（直接泵取），存放方便（常温或冷藏均可），且不会有果肉沉淀导致分层。
- **缺点**：口感是绵密或流质，没有果肉脆感；如果买的是“果酱”，糖度更高，会显著影响甜度控制，需调整糖浆用量；部分低端果泥香精味重。
- **成品表现**：适合做“菠萝啵啵”类（需额外加脆啵啵增加口感），或做分层饮品。

---

**采购决策清单（按优先级排序）：**

1. **核心看菜单**：如果菜单主打**果肉嚼感**（如“满杯菠萝”），买**冻果丁**；如果主打**清爽果汁感**（如“菠萝气泡美式”），买**果泥**；如果两者都要，可以买**冻果丁+少量浓缩菠萝汁**替代果泥。
2. **看门店人力**：有员工能切丁，买冻果丁也便利；如果店员都是小白，直接买**预拌果酱**最省事。
3. **避开廉价陷阱**：不要买价格过低的“菠萝罐头丁”（糖水味重且软烂），也不要买白色硬芯多的散装冻块。应认准**无添加糖、原切无芯**的产品（配料表只应有“菠萝”）。
4. **测试建议**：首次采购先买**小包装试用**（各买1公斤对比），做同一款产品连续试饮3天，重点看**隔夜是否氧化发黑**以及**化冻后是否有木质纤维渣**。

**成本/储存提醒**：
- 冻果丁成本约8-15元/公斤（视产地），出杯成本可控；
- 果泥储存注意开封后48小时内用完，否则易发酵；
- 鲜果采购成本最低但隐形成本（人工、损耗）最高，不建议作为日常主料。

**最终一句话**：**日常主料选“冷冻菠萝原切丁”，出品风味追求浓郁时再额外叠加“冷冻菠萝浓缩汁”**，既保口感又控成本，最稳妥。
