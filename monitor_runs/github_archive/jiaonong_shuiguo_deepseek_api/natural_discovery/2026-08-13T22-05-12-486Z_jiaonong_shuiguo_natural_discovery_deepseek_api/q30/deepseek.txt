在超市或生鲜渠道采购水果时，品相问题是最常见的退货/赔付纠纷点。为了避免事后扯皮，建议在**采购合同或订单备注**中，提前把“品相”标准和售后流程写得尽量清晰、可执行。

以下是一套可以直接套用的**售后流程约定模板**，你可以根据合作方（供货商/产地代办）的强势程度，选择“严格版”或“宽松版”。

### 一、核心约定条款（强烈建议写入合同）

**1. 验收标准前置（拍照+抽检）**
- 约定：到货后 **2小时内** 内完成抽检。抽检比例不低于总箱数的 **10%**（或双方约定箱数）。
- 关键动作：必须**当面开箱拍照/录视频**，留存批次、箱体喷码、物流面单照片。照片需包含：整箱外观、开箱后表层、底层果实特写。
- 标准参考：烂果、裂果、严重压伤（超过指甲盖大小且凹陷发黑）、霉变、冻伤，视为“品相不合格”。单纯大小不均、轻微擦伤、有斑点但未腐烂，一般不计入“品相问题”（此条需明确标注）。

**2. 售后时效约定（黄金24小时）**
- 条款示例：*“乙方（超市）须在到货后 **24小时内** 以书面形式（微信/邮件）向甲方（供货商）提出品相异议，并附上现场照片及抽检记录。超过24小时未提出，视为默认验收合格，甲方不再承担品相责任。”*
- **注意**：如果你验收当晚没查，第二天早上发现坏了，只要在24小时内提出来，依然有效。所以验收时间不要拖到第二天下午。

**3. 赔付比例的计算方式（重点）**
- **问题果率 ≤ 3%**：甲方不承担任何赔付（属于正常损耗，超市自担）。
- **问题果率 3% - 10%**：甲方按 **问题果重量 × 采购单价** 进行折价补偿（例如退差价），超市可自行挑选销售或做降价处理。
- **问题果率 > 10%（或≥15%）**：视为**整车/整批不合格**，甲方需**无条件整批换货**，换货费用（运费）由甲方承担；或者超市方直接**整车拒收**，乙方承担来回运费及超市侧产生的装卸费。
- **特别约定**：若整批货物品质极差（如大面积霉变），超市有权**现场立即拒收**，无需等待24小时，但必须现场拍摄完整开箱视频。

**4. 极端情况补充（缺斤短两与暗伤）**
- 缺重：到货后过磅，净重与单据误差超过2%，按缺重比例赔偿（建议6小时内提出）。
- 暗伤（内部褐变、果心发黑）：这类问题表面看不出来，建议约定“**开卖后48小时内**，若发现连续3个以上切开内部褐变，可追溯原批次索赔”。

### 二、实际操作流程（SOP）

如果你现在还没签合同，现在就要处理这批货，按此流程操作：

1. **立即留证**：马上把所有已开箱的和未开箱的，分3-4个角度拍高清视频和照片（含时间水印）。特别拍特写腐烂、压伤处。
2. **书面通知**：马上通过微信或邮件，将照片发给供货商，明确文字写明“**XX月XX日到货批次，品相不合格，申请按合同约定售后**”。
3. **统计损耗**：把所有问题果挑出来，单独称重。计算问题果率。
4. **给出处理方案**：明确告知对方两个选项：
   - 方案A：按问题果率**折价退款**（适合大批量但有部分能卖，建议拿这个）。
   - 方案B：直接**退货重发**（适合完全没法卖，但重发的物流时间可能会影响上架）。
5. **拒绝口头承诺**：如果供应商说“下次补偿”，直接要求“本次随货款扣除”或本次直接抵扣，否则不接下次货。

### 三、给你的一句实用建议

**“品相不好”和“坏果”是两个概念。**
- 如果只是丑、有斑点、个头小——按**折价**处理（例如按总价的8折结算）；
- 如果烂、霉、水烂——按**拒收或换新**处理。

**谈判话术参考（对供货商）：**  
*“你这批货的车厘子，表皮皱缩加裂口的占了15%，按咱们行业规矩，这批我不能按原价收。给你两个选择，要么按总价打7折我留下自己处理，要么你现在安排车拉回去，运费你的，我这边拒收。你看哪个。”*

如果对方拒绝承担售后，你又急需用货，可以按“问题果率折价”先行结算扣款，并在单据备注“保留追偿权利”，后续再谈。
