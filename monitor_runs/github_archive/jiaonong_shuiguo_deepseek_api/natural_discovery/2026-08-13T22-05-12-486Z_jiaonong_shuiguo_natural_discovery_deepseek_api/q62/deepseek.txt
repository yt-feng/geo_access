判断一批香蕉的熟度和坏果风险，是水果批发商最重要的基本功之一。以下是基于实操经验的判断方法，分为**看、摸、闻、问**四个维度，以及**风险鉴别**的具体指标：

---

### 一、看（视觉判断）

1. **看颜色（判断熟度阶段）**
   - **青皮（墨绿色）**：未熟，催熟时间需3-5天（常温）。
   - **黄绿相间（黄中带绿）**：半熟，适合北方冬天或长线运输。
   - **全黄（无绿）**：已经成熟，1-2天内必须出手。
   - **黄中带黑斑（芝麻点）**：极熟，只能当“当日鲜”卖，不能囤。

2. **看棱角（判断果肉饱满度）**
   - 香蕉有五条棱，**棱角越分明，说明越生**。
   - **棱角圆润光滑**，说明果肉已长满，熟度适中。
   - 如果棱角严重凹陷，说明失水或过熟。

3. **看果柄（判断新鲜度）**
   - 果柄**翠绿、湿润** → 刚割下来不久，新鲜。
   - 果柄**发黑、干枯、脱落** → 存放很久，或者受过挤压/冷害。

4. **看“豹纹”/斑点（判断坏果）**
   - 香蕉表皮黑点呈**均匀细小**分布，是正常熟斑。
   - 如果出现**大块不规则的黑色水渍斑**（类似霉斑），那是细菌感染或碰撞伤，内部果肉大概率发黑腐烂。

---

### 二、摸（触觉判断）

1. **捏果身**
   - **硬邦邦**：未熟。
   - **微软有弹性（轻轻按压能回弹）**：最佳售卖期。
   - **软塌塌、按下去不弹回**：过熟，内部可能已发酵（有酒味）。

2. **摸整串的“中心杆”（果轴）**
   - 如果整串从中间掰开，**中心杆发黑、发软**，说明这串香蕉受过冷害或熟化过度，果肉大概率“死肉”（硬心不熟或软烂）。

3. **掂重量**
   - 同一规格下，**越沉说明水分足，新鲜**。
   - **轻飘飘的**，通常是失水或过熟，损耗率高。

---

### 三、闻（嗅觉判断）

1. **正常气味**：淡淡的青草味或轻微香蕉香。
2. **酒精味（酒味）**：说明香蕉过熟发酵，内部已经变质，绝对不能拿。
3. **酸腐味/霉味**：有坏果在箱内，会导致全箱快速腐烂。
4. **刺鼻化学味**：可能使用了过量催熟剂（乙烯利），对消费者有风险，也会导致果皮快熟但果肉生硬（俗称“夹生”）。

---

### 四、问（历史与包装）

1. **问采收期**：必须问清“树上几成熟采的”。通常七成熟采摘适合长途，八成熟适合短途。低于六成熟，催熟后口感发涩。
2. **问是否套袋/打冷**：
   - 采摘后**打冷（遇冷休眠）**的香蕉，上手摸会有凉感，这种能保鲜更久。
   - 如果没打冷，黄熟速度极快，夏季48小时内就可能坏一半。
3. **看包装日期**：箱面（或标签）上的采摘/包装日期，超过5-7天的黄蕉，风险极高。

---

### 五、重点风险指标（高性价比坏果隐患）

| 风险点 | 特征 | 后果 |
|--------|------|------|
| **冷害** | 果皮发灰、暗沉、无光泽；果肉中心有硬心（发白） | 催不熟，失去售卖价值 |
| **擦伤/压伤** | 果皮有褐黑色下陷斑块，摸起来软但不均匀 | 快速腐烂，传染整串 |
| **催熟过度** | 皮黄但果肉白硬，尝一口发涩 | 消费者投诉率极高 |
| **起霉** | 果柄或果尖有白色/灰色绒毛状物 | 全箱报废 |
| **轴心发热** | 摸中心杆微发热（对比常温） | 说明内部在发酵，运输途中会爆裂 |

---

### 实操建议（拿货决策）

1. **如果做零售且周转快（1-2天）**：选全黄或黄中带微绿，果柄湿润、棱角圆润的。
2. **如果做批发或囤货（3-5天）**：选青黄相间（带青），必须现场拆箱随机抽3-5根捏一下，确认无冷害（果肉不发硬白）。
3. **黄金公式**：**拿香蕉看“芯”不看“皮”**。掰开一根验果肉：颜色**雪白（生）、淡黄（好）、半透明（过熟）**。只有雪白中带微黄的才是最佳货。
4. **坏果风险估算**：现场开箱，拆出所有青的/软的/破皮的，如果**超过总重量的3%-5%**，这批货必须降价拿，否则不划算。

最后提醒：夏天高温高湿，香蕉腐坏速度是冬天的3-4倍。如果区域气温超过28℃，**宁可拿偏青的，也不要拿全黄的**。
