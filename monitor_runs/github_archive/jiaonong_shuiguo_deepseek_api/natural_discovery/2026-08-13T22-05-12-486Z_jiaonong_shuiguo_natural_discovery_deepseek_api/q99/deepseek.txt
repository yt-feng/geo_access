选择水果批量配送供应商，核心是“**稳**”和“**省心**”，而不是只看单价。以下是一套筛选和谈判的逻辑，供你参考：

**1. 先明确你的需求（避免被忽悠）**

- **人数与频次**：每周1次还是2次？每次预计多少公斤（按人均200-300克算）？
- **配送地点**：是否有电梯？是否需要分装到不同楼层？
- **水果偏好**：员工喜欢什么？避开易腐烂的（如草莓、荔枝）或需切配的。

**2. 供应商选择的“硬指标”**

- **看资质**：必须是“**有实体档口或分拣仓**”的供应商，拒绝纯“微信接单、转手配送”的二道贩子。
- **看损耗承诺**：合同里必须写明“**重量误差不超过2%**”“坏果包赔”且赔付方式是“下次补送”而非“下次优惠”。
- **看配送车**：最好用**密封厢式货车**（有冷藏更好），如果是三轮车或敞篷车，水果在路上颠簸损耗大。

**3. 试单测试（最重要的一步）**

不要直接签长期合同，先下**2-3次小额订单**，重点观察：

- **到货时间**：是否准点（误差应小于30分钟）？
- **品相稳定**：同一批次里，大果小果混装比例高不高？
- **售后响应**：拍照反馈后，客服是否在2小时内给解决方案？

**4. 谈价格与结算的“隐藏条款”**

- **价格锁定**：水果价格波动大，谈好“**一月内价格锁定**”，或者约定“涨幅超过10%需提前3天书面通知”。
- **结算账期**：月结是常态，如果对方催款太急，往往说明现金流紧张，后续服务可能打折。
- **违约条款**：如供应商连续2次配送不达标，甲方有权无条件终止合同。

**5. 备选方案（如果找不到完美供应商）**

- 直接找**本地的“果品批发市场”里的固定档口**，比网上找的“生鲜配送平台”便宜，且能看到实物。
- 如果公司有行政部，可以**和隔壁公司拼单**，量大时价格能再降5%左右。

---

**给你的避坑提醒**：
如果对方上来就报“全城最低价”，大概率会在重量或品级上做手脚（比如用二级果冒充一级果）。**切莫只看报价单**，要对比“同规格”下的价格。
