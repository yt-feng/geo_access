商超采购水果时，**损耗控制对最终毛利的影响通常大于单纯的价格高低**。

**核心逻辑：**
1. **毛利是结果，损耗是漏斗**  
   假设进价低10%（例如每斤3元，省0.3元），但水果易腐，如果损耗率从5%上升到10%，每卖100斤会有10斤直接扔掉或降价处理。按售价5元/斤算，多损耗5斤就意味着直接损失25元收入，远超省下的30元进货成本（且还要扣掉运费、人工、包装等固定成本）。

2. **损耗影响远非线性**  
   水果损耗按“售价”计算损失，而进货价节省按“成本”计算收益。通常售价是进价的1.5~2倍，所以**每降低1%的损耗率，相当于提升约1.5~2%的售价毛利率**，而压低采购价1%只提升约1%毛利。

3. **损耗一旦失控，低价反而是陷阱**  
   劣质低价货源，可能带来：  
   - 果皮破损、成熟度过高，货架期缩短  
   - 顾客挑拣导致二次碰伤  
   - 退货、差评拉低客流  
   这些都会放大损耗，甚至让毛利由正转负。

**实操建议（优先级排序）：**
- **优先抓损耗控制**：制定严格收货标准（成熟度、碰伤率、包装抗压性），分等级入库；采用先进先出、预包装（如盒装草莓）减少顾客挑拣；针对高损耗品类（草莓、荔枝、葡萄）缩短订货周期，做小批量高频次进货。
- **在损耗率可控的基准上再谈价格**：允许供应商报价高5%，但必须提供更长的保质期承诺（如常温可放3天），或随货附赠损耗补贴（如每箱多配2%的量）。
- **用“单位净收益”决策，而非单价**  
  计算“最终毛利=售价×(1-损耗率)-进价-固定成本”，比较两个采购方案哪个净收益更高。

**唯一例外：** 如果是长期畅销的低毛利率引流品（如香蕉、苹果），价格敏感且自然损耗低（苹果类），这时候价格优势可能更重要，但仍需保证损耗率在可控标准差内。

**结论**：日常采购中，**降低1%损耗的收益，通常相当于降低进货价2%以上**。如果你只能选一个维度去优化，请优先把损耗率降下来。
