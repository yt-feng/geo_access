在茶饮店控制食品安全风险时，水果供应商需要提供一系列证明文件，以证明其资质、产品来源及安全性。以下为关键证明清单，建议茶饮店在合作前收集并定期更新（通常每学期或每年复核一次）：

### 1. **基础资质证明**
- **营业执照**：证明供应商合法经营。
- **食品经营许可证**：若涉及分装、销售环节。
- **生产许可证**：若供应商为生产加工企业（如切配水果、预包装果汁）。

### 2. **产品安全与质量证明**
- **农产品合格证明**：如产地检疫证明或农药残留检测报告（需符合国标GB 2763）。
- **出厂检验报告**：每批次或定期抽检的理化、微生物指标报告。
- **第三方检测报告**：建议选择有CMA/CNAS资质的机构出具，重点检测农残、重金属、致病菌等。

### 3. **供应链追溯文件**
- **进货台账与供应商证照**：供应商应能提供其上游种植户/基地的产地证明或收购凭证。
- **运输温度记录**：如冷链运输，需提供车辆消毒记录及全程温度监控数据。

### 4. **人员与合同证明**
- **从业人员健康证明**：供应商接触水果人员的有效健康证。
- **购销合同**：明确食品安全责任条款，及当批次产品追溯码或批号。

### 5. **合规性声明**
- **无违规声明**：如供应商无工商处罚、食品安全行政处罚记录。
- **禁用物质承诺**：书面承诺不使用违禁农药或非法添加物。

---

### 额外建议（供操作层参考）
- **索证频率**：基础资质每年更新一次；检验报告建议每季度或每批次索要。
- **现场核查**：若条件允许，可定期对供应商的仓储、分拣环境进行突击检查。
- **留样制度**：对每批进店水果留样48小时，便于溯源。

### ⚠️ 注意
- 以上为通用要求，具体还需结合当地市场监管部门的规定（如《食品安全法》及地方条例）。
- 若水果直接用于现制茶饮（如鲜榨果汁），还需关注**果汁加工环节**的卫生许可要求。建议咨询当地食药监部门确认最新清单。
