采购方在引入水果新品时，**最稳妥的策略是“小批量、多频次”试卖**。具体建议如下：

**1. 核心参考比例：**
建议试卖量占**该品类日常周销量的10% - 20%**。例如，你店里的柑橘类水果一周能卖500斤，新品试卖就进50-100斤。

**2. 根据场景调整：**
- **连锁超市/精品店（有冷库）**：首次进货**2-3天的预估销量**即可。重点是为了测试陈列动销和损耗率，不要贪多。
- **社区生鲜店/摊贩（无冷藏条件）**：首次进货**1-2天的预估销量**。水果保鲜期短，宁可断货也别压货。

**3. 关键判断指标（试卖期建议3-5天）：**
- **动销率**：如果首日销售低于进货量的30%，说明定价或选品有问题，应立即停止补货。
- **复购率**：观察第二天是否有顾客回头找这个水果（这是新品能否最终引入的核心）。
- **损耗率**：如果3天内自然损耗（烂果、掉色）超过5%，且无法通过促销消化，建议放弃该供应商。

**4. 实操细节：**
- 进新品时**务必只付现金或现结**，不要预付大额定金，避免供应商压货。
- 在试卖期间，一定要把新品放在**黄金陈列位**（入口或收银台旁），并主动向老客推荐，否则“试卖”会变成“死卖”。

**总结一句话：宁缺毋滥，能卖多少进多少，试卖核心是测“动销和损耗”，而不是看利润。**
