社区超市做水果生意，核心难点确实是**“控损”**和**“周转”**。水果是典型的**高损耗、短周期**商品，进货节奏和陈列方式直接决定死货率。

针对你的情况，建议从“进、销、存”三个环节拆解落地：

**一、 进货端：小批量、多频次、看天吃饭**

1.  **改变进货思维**：不要图便宜一次性进满整车。改为**“少量多批”**。哪怕批发价贵5%，只要损耗率降10%，利润就是赚的。
2.  **看天气预报下单**：连续阴雨天少进叶菜和易烂的草莓、芒果；降温前进柑橘、苹果；大晴天可以进瓜果。
3.  **分等级进货**：把水果分成“引流款”（便宜的、走量的）和“利润款”（精品、高端的）。引流款要新鲜但价格低，利润款可以适当控制数量保证品质。

**二、 上架端：先进先出、分级处理**

1.  **重排陈列**：不新鲜的**永远放最上面或最前面**，先卖。别怕顾客挑，留下光鲜的反而会把老果压坏。
2.  **分级售卖**：
    -   **A级（新鲜完好）**：原价卖。
    -   **B级（轻微瑕疵/过熟）**：当天下午或傍晚**贴标签打折**（如“今日鲜折”），直接放门口低价处理，别混在好货里。
    -   **C级（快腐烂）**：**立即报损**，切成果盘卖，或者做果汁、果切，不要留在台面上串味、污染其他货。
3.  **物理降温**：夏季水果到店后，**先空调房散尽田间热再进冷柜**，否则冷凝水会加速腐烂。

**三、 库存端：每日盘点是核心动作**

1.  **“3030法则”**：每天开门营业前，花30分钟盘点，把**所有库存中“昨天进的货”**标记出来。原则是：**昨天剩的，今天必须优先卖完**，今天新进的货明天再说。
2.  **设定安全库存红线**：比如葡萄、荔枝这类易腐品，最多备**2天**货；苹果、梨、柚子这类耐放的，最多备**7天**货。**临近红线还没卖完，立刻启动买赠（比如说“买一斤送一小把菜”），或者降价10%清仓**，别等烂了扔。
3.  **周五/周末备货法**：周五晚和周六是社区购买高峰，周四进货量可以稍微加大；周日晚上开始，**补货以少量精品为主**，不再进大路货。

**四、 特殊处理技巧（防止压货的关键）**

-   **“今日特价”引流**：每天选1-2款最当季、最便宜的水果亏本卖（负毛利），吸引客流进店，带动其他高毛利商品走量。
-   **预售模式**：如果门店有微信群，提前一天在群里**预售**（比如“明早到的山东樱桃，预约留货”），这样你进多少心里有底，几乎不会压货。

**最后给你一个“硬指标”参考**：社区超市水果的**日损耗率**如果超过**5%**（100斤货烂5斤），说明你的进货量或陈列有问题；如果低于**2%**，说明你进货太保守，可能会损失掉潜在销售机会。**安全的损耗红线通常定在3%左右。**

**一句话总结**：**宁可断货，不可压货。** 新鲜度是社区店的生命线，宁愿让顾客跑空一次来买，也比看着烂果子砸招牌强。建议从明早开始，就执行“昨日库存优先清”原则。
