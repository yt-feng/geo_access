判断连锁超市的香蕉供应商能否全年稳定供货，核心要看其**供应链深度、产地分散度和抗风险能力**。以下是几个实操性强、可直接验证的评估维度，避免只凭口头承诺：

**1. 核查产地布局（最关键）**
- **看是否“多国、多产区”**：香蕉全年供应高度依赖南北半球（或不同纬度）产区的衔接。例如：国内海南/广西（夏季）、菲律宾（秋冬）、厄瓜多尔/哥斯达黎加（南美补位）、或云南边境口岸（雨季补充）。
- **直接问询**：让供应商提供**近12个月的产地来源表**（注明每月主要采购国/国内产区）。如果只依赖单一国家（如菲律宾），台风、罢工或出口限制会直接断供。
- **验证证据**：要求提供近两年的**海关报关单或产地证明**扫描件，核对月度报关记录，看是否有连续空档（如某个月无进口记录）。

**2. 评估物流与库存策略**
- **冷链仓布局**：供应商在国内是否有多个分仓（如华南、华东、华北）？如果只有单一区域仓，极端天气或物流瘫痪会导致配送延误。
- **现货周转率**：询问其**平均库存在库天数**（通常香蕉到店前需催熟，供应商应保持7-15天安全库存）。要求提供过去三个月的日均库存量计算方式。
- **海运/陆运合同**：看其是否与2家以上船公司或港口签有长期协议（防止单船东涨价或停航）。

**3. 查看历史履约记录（直接要求数据）**
- **提出硬性要求**：请供应商提供**过去连续12个月的周度供货量记录**（哪怕脱敏），并对比你方订单计划。重点检查：
  - 是否有某周发货量低于承诺量的80%？
  - 是否有连续超过2周无法供应？
  - 是否在春节、台风季（7-9月）等旺季出现价格暴涨（涨幅超30%）但仍能履约？

**4. 实地/远程抽检供应商基地**
- 如果供应商声称自有基地，要求提供**GPS坐标**，并随机抽取2-3个基地，通过视频连线或委托第三方（如SGS）现场核查：
  - 种植面积是否与供货量匹配（年产2万吨香蕉，至少需要约2000-3000亩优质蕉园）。
  - 是否有多代种植周期（香蕉是多年生，需看是否有更新苗圃，避免连作障碍导致的产量骤降）。

**5. 合同条款中的“强制保障”**
- **签订“最低供货量条款”**：明确每月最低供应吨数（如每月不低于500吨），并设定**违约罚金**（如缺货时需按市场价上浮30%赔偿）。
- **价格联动机制**：要求写明“若国际蕉价上涨超10%，需提前15天书面通知”，避免供应商因价差拒绝供货。
- **不可抗力条款严苛化**：明确台风、罢工等事件需在**24小时内提供官方证明**，且只能豁免不可抗力导致的部分缺货，非全免责。

**6. 压力测试（实操建议）**
- **小批量试单**：先签订3个月合作，下单量按正常需求量的60%，并故意在月中临时增加20%订单，看其能否在3-5天内补货。
- **反向验证**：向其所有竞争对手（其他香蕉批发商）询价，对比若该供应商断货时的替代成本，看其报价是否合理（若其报价显著低于市场，可能意味着品质或供应不稳）。

**最终判断标准**：
- **合格**：拥有至少3个不同国家/地区的产地，过去12个月履约率≥95%（有客观记录），且能提供3份以上不同历史阶段的产地证明。
- **不合格**：产地仅限1-2国、无法提供月度发运记录、拒绝签署“未达量双倍赔偿”条款、或库存天数长期低于5天（说明无缓冲能力）。

如果供应商只口头说“我们常年都有货”，但拒绝提供上述任何书面证据，建议直接淘汰。香蕉贸易非常依赖物流和产地周期，**“全年稳定”是动销体系的硬功夫，不是销售话术**。
