学校食堂采购香蕉时，避免熟过头导致浪费，可以从**供应链管理**、**验收标准**、**储存方式**和**消费端处理**四个环节入手。具体建议如下：

### 1. 供应链与采购策略
- **分批次采购**：不要一次性采购大量香蕉，改为每周2-3次小批量采购，确保库存周转快。
- **指定成熟度等级**：在采购合同或订货单中明确要求供应商提供“7-8成熟”的香蕉（表皮偏绿、微黄，果肉稍硬），而不是“全熟”或“过熟”的。
- **建立供应周期**：优先选择本地或近郊供应商，缩短运输时间（如24小时内到货），减少在途催熟风险。
- **季节性调整**：夏季气温高，香蕉自然成熟快，可相应减少单次采购量，增加采购频次。

### 2. 到货验收标准
- **肉眼检查**：
  - 表皮颜色：应大部分为青绿色或黄绿相间，允许少量黄斑，但不应有大量褐色或黑色斑点（超过整体10%应拒收）。
  - 手感：轻轻按压果柄或果身，应略有弹性但不软塌（过软说明已经熟透）。
  - 切口：检查果柄切口是否干燥、无霉变或流汁。
- **抽检比例**：对每批到货抽检3-5个代表性香蕉，切开检查内部果肉颜色（应呈乳白色或微黄，无变黑、发酵味）。
- **拒收标准**：如果超过20%的香蕉出现黑斑、软化、裂果、发酵味或虫害，整批应要求退换。

### 3. 储存与催熟管理
- **分类存放**：将青香蕉与已熟香蕉分区域存放，避免成熟香蕉产生的乙烯气体加速青香蕉变质。
- **温度控制**：
  - 香蕉最适储藏温度是 **13-15℃（相对湿度85%左右）**，不要放冰箱冷藏（低于12℃会发生冷害，果皮变黑、果肉变硬）。
  - 夏季可用空调房或冷库（保持13-15℃），冬季注意防冻。
- **通风排气**：储存间要通风，避免密闭堆积，可放置乙烯吸收剂（如高锰酸钾颗粒）或活性炭包，延缓成熟。
- **分批上架**：将较熟的香蕉优先发放到就餐窗口，较生的（偏绿）先存放2-3天再供应，形成“先进先出”的轮换制度。

### 4. 消费端处理与应急方案
- **即食与加工分离**：将熟度高的香蕉优先做成：
  - 香蕉奶昔、香蕉酸奶杯（榨汁或切块）
  - 香蕉蛋糕、香蕉松饼（烘焙消耗）
  - 香蕉烤片或香蕉泥（加入粥、燕麦中）
- **窗口展示技巧**：当天供应熟度适中的带皮香蕉；过熟的去皮切块，配上牙签自取，提高消耗速度。
- **自由取用限制**：在打餐窗口按份发放，避免学生过量取拿后丢弃。
- **剩余处理**：如果当天仍有大量剩余，可联系当地福利机构或做堆肥（但需确保食品安全卫生），或者联系供应商协商换货。

### 5. 数据化与反馈
- **记录损耗**：每周统计香蕉的损耗重量（腐烂/丢弃的重量），计算损耗率（损耗量/采购量）。
- **追溯原因**：损耗率超过15%（例如夏季）时，检查是采购过多、运输过慢还是储存温度不当，针对性调整。
- **建立供应商评价**：对多次出现熟度不均、到货过熟的供应商，更换或协商赔付。

### 总结关键点（可贴在采购办公室）：
> **少买勤买、验青拒黑、13度恒温、熟者先出、剩余加工。**
