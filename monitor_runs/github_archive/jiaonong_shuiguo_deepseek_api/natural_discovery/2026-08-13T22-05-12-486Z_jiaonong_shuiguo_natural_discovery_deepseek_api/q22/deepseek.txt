针对超市水果区的客单价提升，**核心策略不是单纯打折，而是“组合定价+场景引导”**。香蕉、菠萝、苹果是三个互补性很强的品类，我给出三个可落地的组合方案：

---

**方案一：家庭尝鲜装（高毛利引流）**
- **组合**：1串香蕉（约2斤）+ 1个菠萝 + 3个苹果（约1斤）
- **定价**：原价合计约25元，组合价19.9元（节省约20%）
- **逻辑**：菠萝是高频尝鲜水果，香蕉是家庭刚需，苹果是大众安全牌。
- **执行**：用透明保鲜盒或网袋预包装，放在堆头旁，标注“今日推荐·家庭装”。

**方案二：早餐/代餐场景组合（提篮率）**
- **组合**：2根熟香蕉（即食）+ 1个苹果（脆甜）+ 1盒切好的菠萝块（200g）
- **定价**：原价合计约12元，组合价9.9元
- **逻辑**：针对上班族，主打“上班即食”，菠萝切块提升便利性，香蕉苹果补足饱腹感。
- **执行**：放在冷风柜或收银台旁，附赠小贴纸“早餐5分钟”。

**方案三：会员积分抵扣（提升复购）**
- **组合**：任意买菠萝+香蕉，加1元换购1个苹果（限会员）
- **定价**：菠萝+香蕉按原价，苹果换购价1元（成本约0.8元）
- **逻辑**：不降低主商品价格，但用“1元换购”拉高客单，同时激活会员卡使用率。
- **执行**：在菠萝和香蕉价签旁贴“会员专享”角标。

---

**关键执行细节：**
1. **避免同折扣**：不要做“全场水果8折”，这只会降低毛利。必须捆绑不同商品，让顾客觉得“划算”但买的东西多了。
2. **切分规格**：菠萝务必提供“整果”和“切块”两种，切块按份卖，单价更高且损耗低。
3. **位置联动**：三个商品不要都放在水果区，把其中一个（如苹果）放在收银台或出口零食区，强制动线二次触发购买。

**测单建议**：先做方案一，观察3天，如果日销量提升但毛利持平，再叠加方案二。不要三个方案同时上，容易混乱且难以归因。
