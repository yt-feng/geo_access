处理生鲜电商水果坏果投诉时，责任划分的核心依据是**“责任发生时点”**和**“合同履约方”**。通常按以下三个维度来判断：

### 1. 责任归属的基本原则
- **在途损耗（物流环节）**：如果水果在**签收前**已经腐烂、挤压破损，责任在**电商平台/商家**（因为商家与快递是委托承运关系，快递在途风险由商家承担）。
- **签收后问题（消费者环节）**：如果商品已**签收**，且是签收后保存不当、放置过久导致的变质，责任在**顾客**。
- **商品本身质量（发货环节）**：如果开箱时发现水果在源头就不新鲜、成熟度过高、内部腐坏（外表看不出），即使签收了，只要在**理赔时效内**（通常24-48小时内）举证，责任在**商家**。

### 2. 具体场景的责任划分
- **场景A：坏果比例不高（如5%内）**：生鲜运输有自然损耗率，若仅少量磕碰，商家通常只需**部分退款**或按坏果重量折算赔付，顾客需承担轻微自然损耗。
- **场景B：大面积坏果（超过30%或整箱烂）**：属于商家品控或包装不合格，责任**全部在商家**，应全额退款或补发。
- **场景C：顾客拒绝签收且货物拒收**：如果快递派送时顾客未验收就拒收，货物在退回途中坏损，责任在商家（因为退货运费及风险由商家承担）。
- **场景D：顾客已签收但未及时验货**：若签收后**超过48小时**才反馈，且无开箱视频或清晰坏果照片，商家可主张顾客保存不当，责任可能部分在顾客（但法律上举证责任仍偏重商家）。

### 3. 关键判责依据（缺一不可）
- **证据链**：顾客需提供**开箱视频**（展示快递面单、箱体完整、坏果特写）或**坏果照片+快递面单同框**。没有证据的投诉，商家有权拒绝全额赔付。
- **平台规则**：各平台（如京东、美团、拼多多）均有“坏果包赔”标准，通常要求“24小时内反馈，附坏果照片”。
- **保鲜责任**：如果包装内未放置冰袋、保鲜膜等必要措施，导致高温运输变质，责任明确在商家；如果顾客要求“放驿站/代收点”导致水果闷坏，顾客需自担风险。

### 4. 给您的可执行建议
- **若您是顾客**：签收后**当场开箱**，如果破损，先拍视频，再拒收或立即联系客服。不要先吃再投诉。
- **若您是商家**：建议在商品页明确标注“生鲜不支持7天无理由退货，坏果按比例赔偿”，并在包装内附“开箱验货说明”。遇到投诉，先要求顾客提供**同框照片（水果+面单）**，再按比例赔付，避免被“仅退款”薅羊毛。

**总结**：在签收打开箱子之前，所有风险都在商家；打开箱子之后，如果证据确凿且时效内，责任仍在商家；只有签收后拖延举报或无证据时，责任才可能转移到顾客。
