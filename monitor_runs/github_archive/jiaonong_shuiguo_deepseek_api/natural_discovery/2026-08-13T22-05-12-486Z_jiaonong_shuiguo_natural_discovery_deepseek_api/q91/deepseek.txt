在便利店上架香蕉，**建议首选“单根包装”，同时搭配少量“小把”**。具体选择取决于你的店铺定位和客流，以下是分析逻辑：

**1. 首选“单根包装”（用保鲜膜或纸质独立包装）**
- **理由**：便利店顾客多为冲动性、即时性消费（如白领、上班族），他们通常只买1根，携带方便，且单价低（如2-3元/根），决策成本低。
- **损耗控制**：单根包装能减少顾客挑拣时的碰伤，且售价可以略高（毛利可观），避免整把卖不完造成的腐坏。
- **适用场景**：如果你位于写字楼、地铁站、学校附近，客单价敏感、购买频率高，这个选择最稳妥。

**2. 次选“小把包装”（2-3根一捆，用胶带或小托盘固定）**
- **理由**：适合家庭或情侣顾客，一次买2-3根刚好。比整把（5-7根）更易消化，且比单根更有“量感”，适合促销（如“买三根送纸巾”）。
- **注意**：小把包装必须用贴纸/胶带固定，防止顾客拆散，且要在保鲜膜上打孔透气，否则加速变质。

**3. 不建议“整袋包装”（5根以上塑封袋）**
- **理由**：便利店空间小，售点周转快，整袋销售容易积压。除非你有冷风柜且客流大、一天能卖完，否则损耗风险高。整袋更适合超市，不适合便利店。

**执行建议**：
- **试销策略**：第一周尝试“单根+小把”各占一半，观察哪个售罄率高。便利店数据更新快，建议每天记录销量。
- **陈列位置**：放在冷风柜或收银台附近（高毛利区），不要放在蔬果区深处，方便随手拿。
- **新鲜度提示**：在价签上写“当日鲜果，建议当日食用”，减少顾客对不新鲜疑虑。
- **补充方案**：如果销量有限，可以推出“香蕉+酸奶”或“香蕉+咖啡”的套餐促销，加速周转。

**成本核算提示**：单根包装的人工成本略高（需人工包膜），但如果日销控制在20-30根以内，完全能承受。若日销超50根，可考虑改用整把，但前提是附近有稳定客源。

**一句话总结**：便利店香蕉的黄金公式是“**单根为主（占70%），小把为辅（占30%）**”，根据周销量动态调整比例。不要为了“齐全”而上整袋。
