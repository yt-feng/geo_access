针对社区超市卖小包装香蕉，采购时核心要抓住**“熟度分级”**和**“包装透气”**这两个关键点。以下是直接可执行的操作建议：

**一、采购时的硬性检查清单（避免采到“雷”）**

1. **熟度统一性**：明确要求供应商按**色卡等级**发货（建议订“绿转黄”或“黄中带绿”阶段，即色卡3-4级），严禁混装。同一包装内香蕉颜色必须基本一致，否则顾客会挑软的先买，剩下硬的滞销，损耗翻倍。
2. **单包重量锁定**：小包装建议定在 **500g-750g（约3-5根）**。重量太小，单包元价格低但毛利不足；太大则单价过高，社区居民购买犹豫。
3. **看“蕉柄”与“棱角”**：
   - 蕉柄翠绿、饱满、无发黑——新鲜。
   - 蕉身上棱角明显（未完全圆润）——适合放2-3天，适合社区家庭。
   - 买回后3天内就要吃的，要选棱角圆滑、颜色亮黄、无黑点的。

**二、包装工艺的核心要点（防损耗直接决定利润率）**

1. **必须开孔透气**：**绝对不能全密封**。香蕉是呼吸跃变型水果，密闭袋内释放的乙烯会加速自熟，2天就会变黑产生酒味。正确做法是用带透气孔的保鲜袋（孔径3-5mm）或打孔的PE膜托盘。
2. **避免“贴体包装”**：即膜紧贴香蕉皮的包装，这会造成接触面皮肤擦伤和冷凝水积聚。应留出**1-2cm**缓冲空间。
3. **垫纸与隔离**：小包装内建议垫一张吸水纸（吸冷凝水），并且**不要使用普通胶带直接缠绕蕉身**，胶带残留的胶会腐蚀表皮，用扎带或束口袋封口。

**三、运输与到店后的衔接损耗（采购时就要谈好）**

1. **到货温度**：香蕉最佳储运温度是 **13-15℃**，绝对不能低于12℃（会冻伤发灰，无法恢复），也不能高于25℃（加速熟透）。到货时用手摸包装袋，如果温度过高或过低，直接拒收或要求折扣。
2. **到店即拆包**：所有小包装到店后**必须立即拆开**，在常温（20℃左右）通风处散放1-2小时，让水汽挥发后再重新包好上架，否则袋内憋出的水汽是坏果的直接源头。
3. **签订“折耗率”条款**：采购合同中要明确**自然损耗率（通常3-5天内）**，建议约定供应商承担超过5%的烂果。

**四、上架后的防损耗小技巧（采购只是第一步）**

- 小包装香蕉不要叠放超过3层，压烂的损耗往往占比最大。
- 货架位置**不要放在苹果、梨旁边**，苹果释放乙烯催熟香蕉。
- 建议实行“**当日装袋，次日贴标签**”的错峰包装，避免包装好但卖不动，第三天就黑。

**总结一句话**：采购时盯紧**色卡熟度+透气孔包装+到货温度**，这三项做到位，社区超市的香蕉损耗通常能控制在5%以内。如果供应商提供的是全密封包装，坚决不要订——那是地堆大货的包装方式，不是为小包装设计的。
