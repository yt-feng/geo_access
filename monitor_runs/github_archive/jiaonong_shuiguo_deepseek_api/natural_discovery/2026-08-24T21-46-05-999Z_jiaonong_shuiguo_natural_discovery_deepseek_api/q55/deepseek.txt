挑选水果拼盘用的苹果、橙子、菠萝时，**核心策略是“先算去皮率和出品率，再算单价”**，而不是单看一斤多少块钱。以下是你可直接套用的选择逻辑和规格建议：

### 1. 苹果：选“大果”比“小果”更省
- **为什么选大果**：苹果去皮去核后，出品率约在85%-90%。大果（如80#以上，单果重250g+）去皮损失比例小，切出的块状更规整，适合拼盘摆盘。小果（65#以下）去皮后损耗大，且果肉薄，切出来碎渣多，浪费多。
- **规格建议**：采购时看“果径”，要**80#以上（直径≥80mm）**的大果，不要买特价的小果。价格只要不高于小果的20%，通常大果更划算。
- **注意**：避开“高桩”或“畸形”果，这类果切块后形状难看，需重新修整，浪费人工。

### 2. 橙子：选“薄皮”且“中等偏大”的
- **为什么看皮厚**：橙子出汁和果肉率差距大，厚皮橙（如部分脐橙）去皮后损耗可达40%-50%。皮薄、瓣膜易剥离的品种（如甜橙、血橙）出品率更高。
- **规格建议**：选**单果重200-250g左右**的中大果。太小（150g以下）去皮后只剩一点点，不划算；过大（300g+）可能皮厚或纤维粗，且切瓣时容易散。
- **实操技巧**：买样品时，**现场剥一个算净肉重量**，对比“净肉价 = 总价 ÷ 净肉重量”，而不是比单价。

### 3. 菠萝：选“大果”但“矮胖”的
- **为什么选大果**：菠萝去皮去眼后，出品率约在55%-65%（无眼品种如都乐金菠萝更高）。同样价格下，大果（2.5-3.5斤/个）出肉率明显高于小果（1.5-2斤），因为小果的皮和芯占比更大。
- **规格建议**：挑**整体圆润、底部不凹陷**的，果型尽量“矮胖”而非“细长”，细长果芯大、肉薄。这个形状的直接好处就是切出来肉多。
- **性价比关键**：如果接受预切菠萝，很多批发商卖“去皮净肉”，**可以直接问净肉价**，往往比自己买整果去皮更划算（省人工和损耗）。

---

### 综合采购建议（实际操作层面）
- **别在零售店买“切好的果切”**：直接买整果自己切，毛利能差30%-50%，除非你人力成本极高。
- **找批发市场“按箱/按件”进货**：问清“净重”和“果径/果重级别”，同级别下批发的苹果、橙子比超市散装至少便宜15%-25%。
- **按标准重量采购**：建议苹果定“80果”、橙子定“200-250g”、菠萝定“3斤/个”，这三个规格在餐饮行业通用，损耗最低。
- **如果只买一种做拼盘**：优先菠萝（大果），因为其单价低、果肉占比高，且颜色金黄卖相好，综合成本最低。

**最后一句总结**：不要以“斤”为单位算钱，要以“切好后的成品克重”为单位算，选大果、薄皮、矮胖果，最划算。如果不方便现场剥皮测试，就按上述规格参数采购，基本不会亏。
