针对小水果店进香蕉，**第一优先级是熟度，第二是坏果率，第三是价格，最后才是送货速度**。理由如下：

1. **熟度（最关键）**  
   - 香蕉是典型的呼吸跃变型水果，采摘后还会继续后熟。  
   - 如果进的香蕉太生（全绿），小店没有催熟设备，顾客买回去可能一周都不熟，容易引发差评和退货。  
   - 如果太熟（表皮有黑斑、出现酒味），损耗极快，可能当天卖不完就得扔。  
   - **建议**：根据你店铺的日均销量，选择“半黄带绿”或“七分熟”状态的货，确保有2-3天的销售窗口。

2. **坏果率（直接影响毛利）**  
   - 香蕉在运输过程中非常容易压伤、断裂、发霉。  
   - 坏果率直接算进你的成本——10%的坏果意味着你要用90%的货去覆盖全部成本。  
   - **操作建议**：开箱时当面抽检，随机选2-3箱，看表面是否完整、有无黑心、果柄是否发霉。如果坏果率超过5%，当场压价或拒收。

3. **价格（次要但需平衡）**  
   - 香蕉是大众水果，顾客对价格很敏感，但小店打价格战拼不过大型连锁或批发市场。  
   - **建议**：价格只要不高于周边超市零售价的10%-15%即可，重点放在“卖相好、口感熟”的差异竞争上。

4. **送货速度（最不重要，除非断货）**  
   - 香蕉不像叶菜那样急需保鲜，运输快慢对品质影响小。  
   - 只要供货商能在1-2天内准时送到即可，不必为“当天达”多付运费或选择更贵的供应商。

---

**一句话总结**：  
进货时先看熟度和坏果率，价格合理，送货慢一点没关系。如果三者冲突，宁可多花几毛钱进熟度合适、坏果少的，也不要图便宜进一堆“熟透快烂”或“全青难熟”的香蕉。这样既保住了顾客体验，也减少了自己的损耗。
