在超市与水果供应商的常规谈判中，账期（即从收货到付款的周期）通常在 **30天到60天** 之间比较常见。具体天数会因以下因素浮动：

1. **超市规模**：大型连锁超市（如永辉、沃尔玛）议价能力强，账期可拉长至60-90天；中小型超市或社区店通常为15-30天。
2. **水果品类**：普通大路货（如苹果、香蕉）账期较短（30天左右）；高价值、保鲜期短的进口水果或精品水果，因供应商资金压力大，账期可能缩短至10-20天，甚至现款现货。
3. **合作关系**：首次合作通常要求较短账期（15-30天）或预付定金；长期稳定供应商可协商延长至45-60天。
4. **市场惯例**：生鲜行业的行业平均账期约为40天左右，但为防止坏账，许多超市会在合同中加入“售完结算”条款，但这对供应商不利，实际执行中较少。

**建议**：如果是供应商，首次报价时开60天，留出让步空间；如果是超市方，优先争取45天账期，并与对方明确“到货验收合格后起算”的细则。同时，务必在合同中写入逾期付款的滞纳金条款，并约定退换货责任。
