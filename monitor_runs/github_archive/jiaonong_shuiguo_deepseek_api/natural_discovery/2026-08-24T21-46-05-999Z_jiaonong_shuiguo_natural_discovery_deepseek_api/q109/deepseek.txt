针对长期合作的水果供应商，**优先级建议：账期 > 配送 > 售后**。

具体原因和谈判策略如下：

**1. 账期（最优先）**
- **为什么最关键**：水果是**高损耗、强时效**商品，现金流直接决定你的周转能力。账期越长，你的资金占用压力越小，抗风险能力越强。
- **谈判目标**：争取从“现结”改为“月结30天”或“周结+滚动账期”，甚至尝试“首批压一批货，后批结算”。
- **实操建议**：明确账期起始日（如收货后第X天算起），并要求**坏果、烂果直接在货款中抵扣**，而不是“下次补货”。

**2. 配送（次优先）**
- **为什么重要**：水果的损耗率在配送环节最高。配送频次、到货时间和分拣标准直接影响你门店的新鲜度和损耗。
- **谈判目标**：争取**每日或隔日送达**，且**送达时间固定在上午/下午特定时段**（避开你的客流高峰）。
- **实操建议**：约定**“损耗赔付条款”**——比如到货时表皮破损、挤压变形的部分，按重量或金额比例当场扣除。这是配送条款的硬性保障。

**3. 售后（最后谈）**
- **为什么排最后**：售后多为“事后补救”，对长期合作影响不如前两者直接，且标准模糊。如果你账期和配送谈得够好，售后问题会大幅减少。
- **谈判目标**：如果前两项谈不拢，售后可以成为让步筹码。例如：“账期我愿意缩短到15天，但你要承诺坏果包退、次果无条件换新。”

**谈判顺序建议**：
- 先谈**账期**（争取最长周期）。
- 再谈**配送**（锁定频次和损耗标准）。
- 最后谈**售后**（退换货规则和响应时限）。

**给一个具体的优先级组合参考**：
“账期月结30天 + 每日送达 + 到货损耗当季扣除” > “账期月结15天 + 两日一送 + 售后48小时响应”。

简单说：**钱握在自己手里最稳，货到得快损耗少，售后是兜底而非主力**。如果供应商只能满足一样，优先要“账期”。
