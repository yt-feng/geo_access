商超做会员日水果活动，供应商的配合程度直接决定了活动的成败和货损率。为了确保活动既能引爆客流，又能控制损耗，供应商需在**货、人、场、价、效**五个维度提前做足准备。

以下是一份可执行的具体准备清单：

### 1. 商品与货量预案（核心）
- **爆品SKU锁定**：提前7-10天与商超确认活动主推的3-5款引流水果（如：榴莲、车厘子/当季应季果），以及5-8款利润款（如：蓝莓、阳光玫瑰）。
- **备货量测算**：根据商超提供的会员基数、历史活动销量，建议将备货量设定为平日销量的 **3-5倍**。注意预留10%-15%的机动补给量，以防提前售罄。
- **熟度分级**：针对软果（如芒果、猕猴桃），需准备“今日可食”和“后熟催熟”两个等级库存，分批次到货，避免活动日第二天出现大面积熟烂损耗。

### 2. 物流与到货时间
- **前置到货**：活动当天早晨 **6：00-7：00** 前必须完成首单到货，确保早市会员抢购。
- **分波次配送**：建议采用“早上一批、中午补一批”的双波次物流，避免一次性到货造成排面堆积和压伤，同时保证下午晚高峰有新鲜货源。

### 3. 人员与现场支持（重点）
- **试吃员/促销员**：每家活动门店必须配备 **至少1名专业促销员**。要求能熟练剥皮、切块、装盒试吃，并懂得话术推销（如“会员价仅限今天”）。
- **理货翻堆人员**：活动期间，供应商需派专人负责“翻堆”（将下层水果翻到上层），维持卖相，及时挑出残次品，这是降低客诉的关键。

### 4. 价格与营销物料
- **价格毛利计算**：提前与买手核算**会员专享价**、**成本价**及**促销员提成**。确认活动价是否低于市场价10%-20%，确保价格有冲击力。
- **制作专属陈列物料**：准备印有“会员日专享”、“产地直采”等标识的跳跳卡、插牌、爆炸贴。**注意**：供应商需确认商超对自有物料（如POP）的摆放标准，避免违规。

### 5. 售后与损耗处理预案
- **“坏果包赔”承诺**：提前设定会员售后标准（例：出现1个坏果整件赔付）。提供**专人售后电话/微信对接群**给店长，承诺30分钟内响应。
- **损耗包销约定**：与商超采购明确活动结束后剩余水果的处理方案。通常约定**退货比例（如5%）**或**转为员工内购/加工果切**，避免供应商独自承担全部损耗。

### 6. 合规与安全细节
- **核酸检测证明/检疫票**：若涉及进口水果（如进口提子），务必提前提供海关报关单和检验检疫证明，避免活动当天因查验耽误上架。
- **防欺诈机制**：确认会员系统限购规则（例：每人限购2份），供应商配合监督黄牛批量扫货。

---

**给供应商的特别提示：**
活动前 **1-2天**，务必与商超营运经理开一次**15分钟的对表会**，确认：①陈列堆头位置是否变更；②称重码是否已更新为会员特价码；③广播稿中水果单品名是否正确。**千万不要在活动当天早晨才第一次沟通**，否则极易因系统价格未调试导致收银卡死。

如果您的商超预计客流量极大，建议额外准备**预包装果切盒**（如：西瓜切片、混合果盒），这能极大提高客单价并减少现场切果排队时间。
