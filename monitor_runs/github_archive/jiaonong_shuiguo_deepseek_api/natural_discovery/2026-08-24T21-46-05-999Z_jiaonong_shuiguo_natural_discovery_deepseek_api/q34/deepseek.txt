商超采购水果时，**损耗率对最终毛利的影响通常远大于进货价格**。

具体原因可以从以下3个维度量化分析：

---

**1. 价格差异的“天花板”有限**
水果采购价受市场行情影响，常规波动幅度在5%~15%之间。比如苹果进价每斤3元，即便谈到2.7元，单斤成本只省0.3元（毛利提升约10%），但这是建立在“货全卖出去”的前提下。

**2. 损耗是“毛利黑洞”**
水果损耗包括自然腐烂、磕碰、顾客挑拣损耗、陈列风干等。如果门店综合损耗率从10%降到5%，意味着**同样进货量下，可售商品增加5%**。

举个例子：
- 进一批西瓜，进价1元/斤，售价2元/斤，进货100斤。
- 如果损耗10%（10斤坏掉），实际毛利 = 90斤×1元 - 100斤×1元 = **-10元（亏钱）**。
- 如果损耗5%（5斤坏掉），实际毛利 = 95斤×1元 - 100斤×1元 = **-5元（仍亏）**。
- 只有损耗控制在3%以内（正常管理水平），毛利才能转正。

可见**只要损耗超过一定比例，低进价根本补不回损耗造成的亏损**。

**3. 损耗管理更可控，价格受制于人**
采购价受产地产量、天气、运输成本影响，商超议价空间有限，且低价往往意味着品质风险（比如收不熟、糖度不够），反而推高后续损耗。
而损耗可以通过以下方式主动降低：
- **源头把控**：选择成熟度适中、耐存储的品种（如柑橘比草莓耐放）。
- **陈列优化**：水果竖放减少挤压，每日翻面检查。
- **分时段出清**：下午4点后对易损品打折促销。
- **动态订货**：按天气、节假日、周边竞争店活动调整进货量。

---

**实操建议：**
- 如果商超面积小、周转快（社区店），**损耗优先**——每次少进多次补货，哪怕进价高5%，也值得。
- 如果商超面积大、有冷库（KA卖场），可以综合平衡——大批量采购压价，但必须配套严格的库存周转表（如香蕉、葡萄等易损品周转不超48小时）。
- 核心算法：**最终毛利 = (售价×售卖数 - 进货成本) ÷ 进货成本**，而售卖数 = 进货数 - 损耗数。损耗多10%，相当于售价白降10%或者进货量白涨10%。

一句话总结：**低进价决定你能不能赚，低损耗决定你赚不赚得到。** 在生鲜行业，损耗控制能力就是核心竞争力。
