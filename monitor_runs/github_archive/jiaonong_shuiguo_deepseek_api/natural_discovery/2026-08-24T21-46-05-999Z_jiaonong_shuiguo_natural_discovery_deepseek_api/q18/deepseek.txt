在超市采购香蕉时，要避免买到过生或过熟的，可以通过以下几个方法判断和选择：

1. **看颜色和斑点**  
   - 太生：表皮青绿色、棱角分明（太硬）→ 需冷藏几天才能熟。  
   - 太熟：表皮出现大面积黑斑、局部发黑或发软 → 可能已过熟甚至变质。  
   - 优选：**表皮均匀黄色，略带少量小褐点**，没有大面积黑斑或青皮。

2. **摸硬度（用手轻按）**  
   - 优质：果肉紧实但有弹性，轻按能微微回弹，不会硬邦邦也不会软塌。  
   - 太生：手感硬实，按不动。  
   - 太熟：一按就凹陷、或明显软烂。

3. **看果柄（蒂）**  
   - 刚采摘的香蕉，果柄较绿、硬。  
   - 成熟度适中的，果柄微黄但干燥。  
   - 如果果柄发黑、发粘，通常已放置很久或受过挤压，不建议买。

4. **看整串而不是单根**  
   - 单根熟度不代表整串，尽量选整串颜色一致的。  
   - 如果一串里既有青皮又有黑斑，说明运输过程催熟不均，熟度难控。

5. **根据计划食用时间购买**  
   - 如果你打算1-2天内吃：选全黄、带少量斑点。  
   - 如果打算4-5天后吃：选偏黄但略带青皮的。  
   - 不要贪图便宜买一大串，吃不完会过熟。

6. **避免翻动和拿压伤**  
   - 不要拿最底层或被其他物品压住的香蕉，挤压处易发黑腐烂。

**快速总结：**  
- 到手香蕉：**全黄、无大面积黑斑、果肉有弹性、果柄微黄不下垂**。  
- 需要隔几天吃：选稍带青皮的。  
- 到家后如果第二天就吃，可以放常温；若要延缓熟度，放冰箱冷藏（但皮会变黑，肉质不变，剥皮食用无碍）。

如果买回来发现过生了（比如多买了），可以**把苹果或熟香蕉一起放进纸袋**，能加速催熟。如果买太熟，尽快吃完或冷冻做香蕉冰激凌。
