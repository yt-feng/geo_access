遇到水果到货不合格的情况，处理的核心原则是**“明确责任、快速补货、降低停售影响”**。建议你从**采购合同约定**和**日常流程管理**两个层面入手，具体如下：

### 一、 合同条款约定（事先防范）
在供货合同中，务必写清楚以下补货条款，这是你跟供应商谈判的依据：

1.  **明确验收标准**：写明“以国家标准GB 2763农残标准及双方确认的样品等级（如M号/均果）为验收依据”，避免“好坏”扯皮。
2.  **补货时限**：约定“若到货不合格率**超过5%**，供应商须在**24小时内**（或你指定的营业高峰前）送达同批次合格品”。
3.  **替代方案**：约定“若无法按时补货，供应商需在**2小时内**书面授权允许门店使用本地市场采购替代品，差价由供应商承担”。
4.  **违约免责**：明确“因供应商补货延迟导致门店饮品停售的损失（按当日该水果饮品的预估营业额计算），由供应商承担”。

### 二、 紧急补货操作流程（当日应对）
如果现在突然遇到不合格，按以下顺序操作，优先保证营业：

1.  **分级筛选**：先挑出完全不能用的，**能用的（如轻微擦伤、稍不成熟）立刻转用**。比如能做果酱、果汁或做点缀的，先保住当天核心sku不断货。
2.  **内部调剂**：第一时间在门店群或管理群发“缺口预警”，看其他分店是否有富余库存可以**调拨**（通常1-2小时内可到）。
3.  **启动供应商加急**：电话通知供应商，要求其**先发货、后补合同**。让他们直接发“次日达”或“同城急送”。**注意**：一定要明确告知“货物到了先拍视频验收，若仍不合格则拒收并索赔”。
4.  **本地应急采购**：如果供应商无法满足，**立刻派专人去当地农批市场或生鲜平台**（如美团快驴、美菜）采购替代货源。这是最后一道保险。

### 三、 日常预防措施
-   **建立“安全库存”**：对于畅销水果（如柠檬、芒果），建议保持当天销量的1.2倍库存，能缓冲一天。
-   **缩短验收时间**：把验收流程标准化（看颜色、捏硬度、查农残卡），到货后**30分钟内**完成验收。一旦不合格，立刻拍照留证并发给供应商。

### 关键提醒：
-   **先发制人**：补货协议里一定要有**“若不合格率超过约定比例，供应商无条件无条件补发新货，且不得扣除门店的质量保证金”**的条款。
-   **留痕**：所有补货沟通用微信文字或电话录音，不要口头无凭。
-   **切勿擅自丢弃**：不合格的水果拍完照、留样后，再按供应商要求处理（有的供应商会要回去走保险）。

**一句话总结**：合同里写好“超5%返工、24小时补到、缺货赔钱”，日常遇到问题了，先挑能用、再调拨、最后急采。这样店员不会慌乱，营业也不会中断。
