在向供应商采购水果前，为了应对农残抽检（尤其是市场监管部门的随机检查），建议你提前向供应商索取并核对以下**核心资料**，并保留纸质或电子版存档：

**1. 法定必备证明（最关键）**
- **产地证明**：明确水果具体产地（如某省某县某村），证明货品来源合法，便于后期追溯。
- **食用农产品合格证**（或产地准出证明）：由生产者或合作社开具，承诺无违规用药。
- **进货查验记录**（索证索票）：你自己进货时必须登记供应商名称、地址、联系方式，以及水果名称、数量、进货日期。

**2. 检测报告（应对抽检的核心）**
- **当批次农残快检报告**：供应商自检或第三方快检的阴性报告（许多批发市场天天出）。
- **第三方权威检测报告**：尽量要求提供**最近3个月内**、由具有CMA（中国计量认证）资质的检测机构出具的**全项目农残检测报告**（重点看是否包含常规的有机磷、氨基甲酸酯类等）。
- 如果采购量大或要求高，可要求供应商提供**出口加工用**或**商超专用**的“批批检”报告。

**3. 供应商资质（证明对方合法经营）**
- **营业执照**（复印件盖章）。
- 如为种植基地，最好有**无公害/绿色/有机认证**证书（如无认证，至少要有产地证明）。
- 如果是批发市场档口，索取**市场管理方的经营许可证**或摊位合同。

**4. 其他合规文件**
- **承诺书**：要求供应商出具书面承诺，声明该批水果未使用国家明令禁止的农药，且符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》。
- **物流单据**：如运输车辆信息、温度记录（如有时），证明流通环节未混入污染。

---

**给您的实操建议（关键）：**
- **别只收纸**：收到的报告要**亲眼看日期、看检测项目**，并拍照上传至公司内部台账系统。
- **宁可多要不可少**：如果供应商无法提供以上任何一项，强烈建议**先暂停进货**，或要求“先抽检、后付款”。
- **抽检应对**：如果市场监督部门抽检，你只需证明“已履行进货查验义务”且来源清晰，即使万一不合格，也能主张**免于处罚**（需配合主动召回）。

如果供应商是批发商而非生产商，他可能无法提供产地证明，此时**务必索要该批次水果的“产地信息”和“上游供货发票”**，并做好台账，这是应对抽检的最后防线。
