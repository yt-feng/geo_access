在水果店卖菠萝，**建议优先提供“整果”和“去皮切块（带盒）”两种形式，让顾客自己选择**。原因如下：

1. **整果**：适合有经验的顾客、买回家自己处理，或囤货。
   - 优点：利润高、损耗小（外壳还能卖废品），顾客可以根据自己需求挑成熟度。
   - 缺点：去皮麻烦，需要顾客回家自己削，容易劝退“懒人”或着急吃的顾客。

2. **去皮切块（预包装）**：适合快节奏顾客、办公室、或不想动手的人群。
   - 优点：即买即吃，转化率高，适合冲动消费。
   - 缺点：损耗大（切开后氧化快，当天卖不完要打折或处理）。

**不推荐“只卖去皮好的单一选择”**，因为：
- 顾客群体不同（有人要买多、有人只要一小块）；
- 只卖去皮会导致小份量的顾客买不到，大份量的顾客又嫌少；
- 切开的必须快速售出，否则容易变质，增加风险。

---

**具体操作建议：**
- 门口放整果（带价格），旁边放一个切开的展示样品，标明“可现场去皮”。
- 备一个切果台（或提前按盒切好）放在冷藏区，标明“去皮切块，15元/盒”等。
- 如果人手不够，可以提供“免费去皮”服务——只对购买整果的顾客，这样兼顾毛利和便利。

**注意：**
- 切好的菠萝要当天卖完，收工前若剩，建议打折或低价处理，避免隔日售出引起投诉。
- 整果挑货时看“果眼大且平、底部香浓、按压微软”的成熟度，确保顾客拿回家两天内可食。

这样，无论顾客是果断型还是犹豫型，都能快速成交，且你的损耗可控。
