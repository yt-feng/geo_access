采购香蕉用于茶饮店（如香蕉奶昔、香蕉拿铁、甜品等）时，熟度控制是影响风味、口感和保质期的核心环节。以下是具体可执行的采购与分级建议：

**一、明确不同用途对应的熟度标准**
- **调制饮品（奶昔、冰沙、果茶）**：建议选择**7-8成熟**的香蕉（即表皮黄中带少量绿点，手感微软但不塌）。这个阶段甜度适中，纤维较少，打浆后顺滑，不会因过熟产生酒精味或酸味。
- **做香蕉泥/果酱**：可用**8-9成熟**（表皮大面积变黄，有少量黑斑点）。风味最浓郁，糖分高，适合熬煮或直接压泥。
- **做切片装饰或可丽饼/蛋糕顶部**：建议**6-7成熟**（表皮黄绿，手感紧实）。切面不易发黑，形状保持好，卖相佳。

**二、采购时的实操检查方法（到货验收）**
1. **看颜色**：优先选**整体黄绿色均匀**的批次。若整箱发黑或全黄，说明熟度偏高。
2. **摸硬度**：轻捏香蕉中部，**微软但指压后能回弹**为佳；过硬（硬如石头）则需多放2-3天；过软（一按一个坑）则当天需用完。
3. **查果柄和表皮**：果柄应呈青黄色，若变黑则可能运输中受闷；表皮有细小黑点（梅花点）是自然成熟标志，但大面积黑斑或破损不要收。
4. **闻气味**：应有清甜香气，若有酸味或发酵味，说明过熟或变质。

**三、到店后的熟度分级管理（防止浪费）**
建议按“**当天用 > 三天内用 > 催熟用**”三档分拣：
- **最成熟（皮黄、软）**：立刻用于制作当天饮品或甜品，优先消耗。
- **中等成熟（黄绿）**：常温存放于**18-22℃、通风**处，预计2-3天内达到最佳状态。
- **较生（青硬）**：与苹果或成熟香蕉同袋密封（释放乙烯催熟），但注意不要放冰箱催熟（会抑制成熟）。

**四、关键避坑提示**
- 茶饮店**尽量避免一次性采购过多**，因为香蕉成熟速度极快（夏季2天就会过熟）。建议**按3天销量定量采购**，或与供应商约定“分批次送货”。
- 若必须长期备货，可将采购来的香蕉**剥皮冷冻**（整根或切片真空包装），冷冻香蕉适合做冰沙和奶昔，但不能做装饰。
- 进货时**别贪便宜买青香蕉**，因为人为催熟（如注射乙烯利）可能不均匀，导致外熟内硬，口感差。

**五、推荐采购清单模板（给供应商）**
- 规格：每根约150-180g，长度大于18cm，无机械伤。
- 熟度要求：**黄绿色比例约70%**（即近黄绿色，但大部分黄）。
- 交付周期：**每周一、三、五**分三次送货，确保到店时处于当日可用或次日可用状态。
