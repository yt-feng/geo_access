水果采购谈锁价（价格保护）的具体时长，**没有固定标准**，完全取决于**水果品类**、**市场行情**和**供应商实力**。但根据行业惯例，可以给你一个务实的参考区间：

**一、 按品类分的常见锁价周期**

1. **应季大宗水果（如苹果、梨、柑橘、西瓜）：**
   - **锁价周期：** **1 - 2 周**。
   - **原因：** 产量大、供应充足，市场价波动相对平缓。供应商敢锁价1-2周，但超过这个时间，如果产区突然下雨、降温或集中上市，价格就会松动，供应商会要求重新议价。

2. **进口水果（如车厘子、榴莲、山竹、牛油果）：**
   - **锁价周期：** **3 - 7 天**（甚至按船期/航班算）。
   - **原因：** 海运、空运成本高，行情波动剧烈（尤其是海运到港前价格随时变）。供应商通常只锁定“当前在途货物”的价格，到达目的港后按约定的比例（如：涨跌超出5%重新议价）结算。

3. **反季节水果或小众高端果品（如冬枣、蓝莓、阳光玫瑰）：**
   - **锁价周期：** **次日或单批次（2-3天）**。
   - **原因：** 产量不稳定，保鲜难度高，基本不可能长期锁价。供应商只会对“已采摘的货”锁价。

**二、 按谈判筹码分的锁价时长**

- **你有账期优势（现金采购）：** 可以谈到 **10-15天** 的锁价，甚至要求“跌价补差、涨价不补”。
- **你是大客户（月采购量大）：** 可以谈 **1个月** 的锁价协议，但通常要承诺最低采购量（比如日均100箱）。
- **市场处于上涨期：** 供应商最多锁 **3天**，且会附加“随行就市”条款。
- **市场处于下跌期（买家主导）：** 反而不用锁价，直接按照每日现价结算更划算。

**三、 给你的实操建议（如何谈出更久锁价）**

1. **不要锁死价格，锁“价格区间”**：例如：锁定当前价格，但约定如果产地收购价涨跌超过 8%，则双方按新价格%重新计算。这能让供应商更有安全感，愿意延长锁定期。
2. **锁定“单品项”而非“整体”**：例如只锁定“XX产地5斤装苹果”，不要锁“所有水果”，因为个别单品波动大。
3. **用“预付款”换“锁价期”**：你预付总货款20%-30%，供应商几乎都会同意把锁价期拉长到 **20-30天**，因为他们的资金压力被分担了。

**结论：** 最稳妥的做法是 **签 7-15 天** 的锁价协议，并添加“价格保护”条款（若跌价，供应商补差价或下次发货抵扣）。长期锁价超过1个月，除非是签订年度框架协议（只保底价不保现价），否则风险很大，双方都容易违约。
