开水果店，长期稳定供货是命脉。判断一个供应商是否靠谱，不能只听他说，要看“货”“账”“人”三个维度的硬指标。

以下是你可以直接落地验证的**6个判断标准**：

### 1. 看“验货标准”是否统一（核心）
- **香蕉（催熟是关键）**：问清楚他供的是**自然熟**还是**催熟**，以及成熟度（如“7成熟”“8成熟”）。靠谱的供应商会告诉你具体成熟度，且能接受你开箱验货。如果他说“都熟透了，拿回去就能卖”，这反而是大忌——因为香蕉到店后熟得快，损耗极高。
- **菠萝（黑心问题）**：要求供应商承诺**“菠萝眼”深度**和**黑心率**。你可以直接切一个样品，看果芯是否发黑。靠谱的供应商会允许你随机切果，并且对“黑心包赔”有明确的售后条款。

### 2. 看“极端天气”下的处理方式
- **台风/暴雨季节**：香蕉和菠萝产地易受影响。靠谱供应商会提前告诉你“明天货源紧张，价格可能上调X%”，并主动和你商量替代方案（比如换成进口香蕉）。
- **不靠谱的常见话术**：“哎呀今天下雨，货在路上淋了，有点发黑，你凑合卖吧。”——这种一票否决。

### 3. 看“账期”和“退换货”承诺
- 长期合作，**不要接受“概不退货”**。香蕉到店若在48小时内出现大面积断裂或黑芯，菠萝切开后发现黑心，靠谱供应商通常承诺**“按比例折价或换货”**。
- 警惕**“必须现金结清，压一批货”**的供应商。正规供应商一般支持“先货后款”或“月结”，但你可以先小额试单。

### 4. 看“尾货”处理能力
- 香蕉和菠萝**极易损耗**。靠谱供应商会帮你处理“尾货”，比如你卖剩下的熟透香蕉，他可以低价回收（做香蕉泥）或者帮你介绍烘焙店。
- **不靠谱的**：只管卖货，卖完就消失，你的损耗全自己扛。

### 5. 看“冷链物流”的细节
- 香蕉怕冷也怕热，菠萝怕压。问清楚**专用车运输**还是拼车。拼车运输的香蕉，如果和榴莲、芒果混装，会被催熟到烂心。
- **实操验证**：让你第一次订货，要求他发**到货温度记录仪**的照片（如果他能提供，说明很专业）。

### 6. 看“同行口碑”和“试单”测试
- 直接问同一条街或者水果批发市场的其他店主：“他家货稳不稳？”（尤其是问卖香蕉的老店，他们会说真话）。
- **终极测试**：**下最小单**（比如10箱香蕉、5箱菠萝），连续合作3次，看是否每次品质一致。**如果第一次好，第二次差，第三次又恢复，这种靠运气出货的供应商，直接放弃。**

---

**立刻可执行的判断动作**：
下次去批发市场，直接到档口，**打开一箱香蕉，从侧面抽出一把，看果柄根部是否发黑（发黑=存储过久）**。再拿一个菠萝，**用指甲掐一下菠萝眼**，如果出水很多且刺手，说明是催熟的（不按季节出产），长期卖口感不稳定，容易遭客诉。

**最后提醒**：长期合作，合同里一定要写清楚**“到货新鲜度标准”和“损耗赔付比例”**。如果对方说“行业里都不写这些”，那他心里就没打算对你负责。
