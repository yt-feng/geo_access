针对养老院或医院食堂采购水果，**核心逻辑是“资质合规为门槛，供应稳定为生命线”**。因为服务对象（老人、病人）对食品安全要求极高，且不允许断供。

以下是具体的判断和操作建议：

### 第一步：资格审查（合规性——一票否决）

这是第一道关，不满足则直接淘汰。你需要让供应商提供以下**原件或加盖公章的复印件**并现场核验：

1.  **营业执照**：经营范围必须包含“食品销售”或“水果批发”或“农产品销售”。
2.  **食品经营许可证**：**必须提供**。注意看“主体业态”和“经营项目”，必须包含“预包装食品销售”或“散装食品销售”。（如果只卖初级农产品，有些地方仅需备案，但医院/养老院食堂务必要求有证）。
3.  **人员健康证**：所有送货、分拣人员需有有效的健康证明。
4.  **产品检测报告**：**每批次**水果需提供农药残留快检报告。供应商若自有检测室，需提供检测记录；若外送检测，需有第三方CANS/CMA认证报告。
5.  **溯源凭证**：能提供上游产地证明或批发市场开具的“食用农产品合格证”。

> **特别提醒**：查一下供应商是否在当地市场监管局有“行政处罚记录”或“食品安全事故通报”。可通过“国家企业信用信息公示系统”查询。

---

### 第二步：稳定性评估（经验与实地考察）

资质没问题，但能否长期稳定供应，主要看以下几点：

1.  **经营年限与规模**：建议选择**经营3年以上**、年营业额在100万以上的中型批发商或基地直供商。刚开业的小店风险高。
2.  **冷库与冷链能力**：**强烈建议实地考察**。看其仓库是否有冷藏库（0-5℃）？运输车辆是否是密封厢式货车？没有冷链能力的水果供应商，夏季损耗大、变质风险高。
3.  **货源渠道**：询问其主要货源。是**基地直采**（稳定但品类少）还是**一级批发市场**（品类齐全但受行情波动影响）？理想选择是“基地直供+市场补货”的组合模式，这样不会因为单一产地受灾而断供。
4.  **应急预案**：当你的采购量突增（如过节）、或遇恶劣天气时，供应商有无备用货源？**签订合同时务必写明断供赔偿条款**。

---

### 第三步：日常履约监控（动态稳定）

选定供应商后，不能用“印象分”管理，要用数据监控：

-   **到货准时率**：每月统计，低于95%需警告。
-   **退换货率**：每批次抽检，若坏果率超过5%（或合同约定标准），必须整箱退货。
-   **价格稳定性**：要求供应商提供“一周内批发价波动表”，若长期高于市场价10%以上，说明其有宰客行为，不稳定。

---

### 第四步：防坑指南（特别针对机构食堂）

1.  **拒绝“口头承诺”**：合同里必须写清**“结算周期（月结/周结）”、“质量违约金”、“农药残留超标一票否决”**。
2.  **推荐“双供应商”机制**：如果食堂水果需求量大，建议同时与2家供应商合作（比如A供主货，B备选），每周轮换或按品类划分，避免被单一供应商“卡脖子”。
3.  **小批量试供**：不要第一次就签年度合同，先签订1个月试供期，观察其对账、送货、质量问题处理态度。

---

**最终结论**：
**合规看“三证一品”（执照、许可证、健康证、检测报告）；稳定看“冷库+基地直采+3年经验”。**

如果上述硬性条件都达标，且实地仓库整洁无异味、运输车有冷链，基本可以放心合作。反之，哪怕价格低30%，也建议放弃，因为老人和病人的食品安全风险成本远高于这30%的差价。
