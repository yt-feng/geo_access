在采购香蕉用于烘焙蛋糕时，**成熟度**应该优先于价格。原因如下：

1. **风味与质地**：熟透的香蕉（表面出现褐色斑点）天然糖分高、风味浓郁，散发出强烈的甜香，这是烘焙香蕉蛋糕（如香蕉面包、马芬）**最核心的味道来源**。如果采购未熟或青香蕉，蛋糕会发酸、口感硬，即使价格便宜，也会严重影响成品品质和顾客口碑。
2. **质地与水分**：熟香蕉更软糯，容易捣成泥，且含水量适中，能自然为面糊增加湿润感，避免蛋糕干硬。未熟香蕉质地硬、水分少，需要额外添加油脂或牛奶来补救，反而增加成本。
3. **性价比考量**：虽然熟香蕉价格通常略高（约比青香蕉贵10%-20%），但用量更省——熟香蕉出泥率高（可达85%以上），未熟香蕉出泥率低（约70%），且风味不足时需多用糖或香精，综合成本并不一定更优。
4. **季节性因素**：若香蕉处于产季，熟果价格与青果差距较小；若反季或进口，差距可能加大，此时可适当折中——**采购“黄中带绿、轻按有弹性”的七成熟香蕉**，放在室温下1-2天自然熟化，兼顾价格与质量。

**操作建议**：
- 与供应商约定**按“黄熟度”分级**（如5-7成熟），而非只看单价，可要求报价时附带熟度说明。
- 若预算紧张，可采购**临熟香蕉（皮黄、果肉硬）**，到店后置于通风处催熟，避免直接买青果。
- 每日少量多次采购，避免囤积熟透果腐烂浪费。

如果香蕉用于**大批量、标准化生产**，建议固定采购“全熟”果；若用于**低客单价产品**，则可接受“八成深”果，但需在配方中增加少许烘焙糖或成熟果泥补偿风味。
