在超市采购苹果和橙子时，判断大小规格是否适合门店销售，核心目标是**保证顾客满意度、减少损耗、并符合目标客群的消费习惯**。以下是具体、可执行的标准和实操建议：

### 一、 核心原则：参考“市场基准”而非“绝对尺寸”
不同地区、不同季节的消费偏好不同。因此，采购前应先明确**目标门店的顾客画像**（例如社区店偏家庭装、精品店偏高端装）。
适合门店销售的标准，通常以**“行业内普遍认可的等级”**为准。苹果和橙子根据果实横径通常分为：
- **苹果（以红富士为例）：** 直径70mm-75mm为小果，75mm-80mm为**中果（最受欢迎）**，80mm-90mm为**大果**，90mm以上为**特大果**。
- **橙子（以赣南脐橙为例）：** 直径65mm-70mm为小果，70mm-80mm为**中果（口感与价格平衡点）**，80mm以上为大果。

**核心建议：** 优先采购**中果至大果的中间档位**（例如苹果80mm左右，橙子75mm左右），这类规格皮薄、果肉饱满、出汁率高，且单果重量适中，不易因过大导致内部空心或过小影响卖相。

### 二、 实操判断步骤（采购现场执行）
不要只凭肉眼，建议使用以下方法：

**1. 使用专业工具（最建议）**
- 随身携带一个**果径测量圈（又称“环规”）**，淘宝几元钱一套。当场套果，凡能通过的即为合格。直接淘汰过小果。

**2. 手测对比法（无工具时的替代）**
- **苹果：** 用你的大拇指和食指围绕苹果最粗的部位，如果刚好能扣住且手指间有轻微缝隙，通常就是80mm左右（相当于普通成年人拳头略大）。如果扣不住且手指很紧，说明偏大。
- **橙子：** 标准75mm的橙子，握在手里时，手指刚好能包住，且果皮表面有明显凹凸感但按压不软。

**3. 单果重量参考（辅助判断成熟度）**
- 苹果（80mm）单果重约250克-300克。
- 橙子（75mm）单果重约200克-250克。
- 如果尺寸达标但重量明显偏轻，说明果肉可能萎缩或水分流失，不适合销售。

### 三、 结合门店动销的淘汰标准（避免买到“压秤货”）
即使尺寸达标，以下情况必须**退回或拒收**：

| 指标 | 苹果/橙子 | 处理办法 |
|------|-----------|----------|
| **过大异常果** | 超过90mm（苹果）/85mm（橙子） | 除非门店定位高端大果礼盒，否则**不建议采购**，因为单果价格高、顾客一次性吃不完，易造成损耗。 |
| **过小次果** | 低于65mm | **坚决不采**，容易给顾客“劣质”印象，且价格竞争力弱。 |
| **畸形果/严重疤痕** | 果形不圆、有深色硬疤 | 即使尺寸对，也必须剔除，影响陈列美观。 |
| **软果/水伤** | 按压果皮有明显凹陷不回弹 | 尺寸再大也不要，易在货架期快速腐烂。 |

### 四、 动态调整：按季节和销售场景微调
- **夏季/高温季节：** 顾客更偏向随买随吃，建议采购**中果**（如75mm苹果），减少大果因吃不完导致的家庭浪费。
- **节假日/礼盒季：** 可增加**大果比例**（80-85mm），因为礼品属性更强。
- **结账台/水果切：** 如果门店有鲜切果盒业务，可以采购一些**小果（65-70mm）**，成本低，切块后不影响品质。

---

**最终决策建议：** 采购前，先用环规抽检3-5箱，计算符合“中果区间”的占比是否≥80%。如果不足，果断和供应商协商换货或压价。记住一句话：**宁可买标准偏小一点的均匀果，也不要买大小混杂的“盖帽果”。** 均匀度（规格一致性）比单果更大更重要。
