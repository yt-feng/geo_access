水果店采购香蕉时，**一箱里面大小不一样，是会明显影响销售的**，但影响程度取决于你的经营定位和销售方式。

以下是具体影响和应对建议：

**1. 会影响“形象”和“定价”**
- **散称零售**：顾客挑选时会嫌弃“大的太贵、小的不划算”，挑来挑去造成损耗，且显得不专业，容易影响店铺口碑。
- **整箱/礼盒销售**：大小不均会显得不整齐，顾客会认为“以次充好”，影响复购。

**2. 会影响“利润率”和“损耗”**
- 小果通常卖不上价。如果你整箱采购均价高，但混有大量小果，无法按大果价格卖出，就会压缩利润。
- 大小混装还会导致成熟度不一致，小的容易过早变熟或过烂，增加损耗。

**3. 分情况判断是否采购**
- **建议采购**：如果你的店面主要以“促销、引流、做特价”为主，或者你计划分拣后“大果精品卖、小果特价处理或做果切”，这样可以采购。
- **不建议采购**：如果你的店定位中高端、主打精品水果，顾客对品相敏感，则尽量采购大小均匀的整箱。

**4. 实操建议**
- **采购前明确需求**：跟供应商提前说清楚“要均匀的”，或者要求“按大小分拣装”。
- **到货后立即分拣**：按大、中、小分类，分别定价或分区陈列，避免混卖。
- **小果快速处理**：小果适合做果切、榨汁，或做“特价处理”，别积压。
- **跟供应商谈退换**：如果混装严重且事先没说明，可以沟通部分退换或下次补贴。

**总结一句话**：大小不一不是不能买，但会降低消费体验和利润空间。**如果条件允许，优先选择大小均匀的整箱；如果已采购，务必分拣后分类销售。**
