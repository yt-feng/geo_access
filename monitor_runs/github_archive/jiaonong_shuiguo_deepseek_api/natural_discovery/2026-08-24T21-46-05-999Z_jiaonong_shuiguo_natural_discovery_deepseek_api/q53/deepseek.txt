对于餐饮店每天少量水果的采购需求，核心痛点是**量小、频率高、要求稳定**。基于这些特点，以下是比较省心的供应商类型和筛选建议：

**首选（最省心）：本地生鲜配送平台 / 社区团购B端渠道**
- **优势**：这类平台（如美菜网、快驴进货、蜀海供应链等）专门服务餐饮企业，起送门槛低，部分平台支持次日达，甚至当日达。水果普遍是加工好的净菜或标准包装，损耗低。你只需要在APP上下单，明码标价，配送稳定。
- **操作建议**：选择**每日配送**（或隔日）的区域仓，锁定2-3种常用水果即可，避免菜单上出现“今日不供应”的尴尬。

**次选（性价比高）：周边大型农贸批发市场的“固定档口”**
- **优势**：虽然批发市场主要走量，但你可以主动找几个批发商谈“每周小批量供货”的协议。让他们给你的门店留货，你承诺每周固定采购量（哪怕一天只需5斤）。
- **关键点**：**不要找流动商贩**，要找在市场内长期租摊位的老板，这样出现质量问题（如坏果）可以当场退换或补货，没有平台手续费。

**第三选项（针对起送量低）**：社区生鲜店 / 精品超市的“B端团购通道”
- **优势**：很多连锁社区超市（如百果园、钱大妈等）有企业团购业务，虽然单价比批发贵，但胜在**零损耗**（按需供应）和**品质稳定**。适合你每天量<10斤且对水果颜值要求高（如摆盘）的场景。

---

**筛选供应商时的“省心”标准（执行清单）：**

1. **问清“最小起送量”**：必须确认能否只送5斤、10斤。如果对方说“最少50斤”，直接排除。
2. **约定“坏果包赔”条款**：无论找谁，合同或口头协议必须明确“当日送达如有腐烂，拍照秒赔或次日补货”，这是省心的保险丝。
3. **选择“非远距离冷链”**：跨省冷链价格高且损耗大。本地供应商（车程1小时内）能最大程度保证水果新鲜，且退换货及时。
4. **避开“季节性单品”**：如果是做饮品或摆盘，建议跟供应商指定“全年常供”的水果（如苹果、香蕉、橙子、柠檬），避免供应商因断货给你临时换货导致质量不稳定。

---

**最后避坑建议**：
- **不要贪图“最便宜”**，选“次日达且能包赔”的。每天多花十几元，换来的是不用自己凌晨去进货、不用囤货、坏果有人管，这比省下的成本更值得。
- **试单策略**：先和候选供应商下3天小单（每天3-5斤），验证其准时率、包装完整度和退换货速度，再正式合作。

**最直接的行动**：今天打开地图搜“美菜网 同城”，或联系本地最大农批市场的办公室，让他们推荐2-3个“接受小件订单”的固定档口，下午打电话谈一次即可。
