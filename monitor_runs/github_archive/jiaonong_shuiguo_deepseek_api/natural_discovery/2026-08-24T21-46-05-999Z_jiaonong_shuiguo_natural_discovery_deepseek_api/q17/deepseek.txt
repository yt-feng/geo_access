针对社区超市进水果，控制新鲜度和库存的核心策略可以总结为：**“小批量、多频次、看数据、快周转”**。这需要彻底抛弃“一次进满”的批发思维。

以下是六个可立刻执行的具体建议，帮你把损耗降到最低：

**1. 改变进货模式：从“按箱进”变成“按盒/按斤进”**
社区店的辐射半径小，消费者对“新鲜”极其敏感。供应商整箱批发虽然单价便宜，但往往捆绑了不熟的、熟过头的、小的。**建议：** 尝试与本地水果批发商或配送平台协商，能否支持“破箱”混装，或者一天两送（上午、下午各一次）。哪怕单价贵2-3毛，但损耗率下降10%以上，利润空间反而更大。

**2. 用“动销率”代替“感觉”判断进货量**
不要凭经验拍脑袋进货。**核心公式：** 昨日销量 × 1.2（补足今日高峰，留出安全垫）。例如昨天卖了20斤苹果，今天进货就进24斤。如果连续三天某水果动销率低于30%（进货100斤，只卖出30斤），马上暂停进货，并立即启动促销清货。

**3. 严格执行“先进先出”与“倒筐”动作**
**这是最便宜但最有效的方法：** 每次补货时，把手上的旧货往筐子角落放，新货摆在显眼位置。同时，每天开业第一件事，把所有水果筐拿起来轻轻颠一下/翻个面，让上下层的透气，避免贴地的一面被压烂出汁。**不要怕麻烦，这一步能减少30%的“烂底”损耗。**

**4. 建立“临期预警”和“限时折价”机制**
水果是有“生命”的。制定一张简单的表格：
- **卖相完好、口感最佳**（第1-2天）：原价。
- **略有软化/表面微干**（第3-4天）：贴“特价”标签，直接打7-8折，卖的是“性价比”。
- **有轻微损伤/即将过熟**（第5天）：直接做成果切拼盘（利润率高）或“买一送一”清货。
**切记：** 一旦判断卖不掉，**当机立断**打折，千万不要等到烂了再扔。

**5. 利用“黄金时段”调节库存**
社区店的高峰期通常在**傍晚下班后（17:00-19:30）**。如果你在下午4点前发现库存偏高，尤其是叶菜类、香蕉、草莓等极易损耗的品类，建议在高峰期前1小时就开始**“试吃引流”**——切开放着让人尝，并吆喝“今天到货，新鲜程度自己看”。试吃能显著加速清货，同时也降低了顾客对“不新鲜”的防备。

**6. 建立“数据台账”，哪怕是用本子记**
每天打烊后花5分钟，记录：
- **昨日剩货量**（剩的越少越好，说明进货准确）
- **今日进货量**（对比前几天）
- **今日卖出量**（卖掉的钱）
连续记录两周，你就会发现规律：比如周六水果销量是周一的1.5倍，周三通常很差。据此调整进货日期，能最大程度避开压货。
