在便利店铺货香蕉时，**建议优先选择单根包装**，其次是**小把（2-3根）**，不推荐整袋包装。

理由如下：

1. **单根包装（最优）**  
   - **适配即时消费**：便利店顾客以防饿、解馋为主，单根购买频次高，单价低，冲动消费概率大。
   - **损耗可控**：单根独立售卖，坏一根只需丢弃一根，不会连带整批报废（香蕉极易碰伤、过熟）。
   - **陈列灵活**：可竖放或横放于冷风柜、收银台前端，视觉上显得量大、新鲜。

2. **小把（2-3根，次选）**  
   - 适合**家庭补充**或**办公室分享**场景，可提高客单价，但需注意：必须用带孔保鲜膜或托盘承托，防止相互挤压。
   - 若你的店面面积小、客流以白领为主，小把是很好的补充，但需要每日根据保质期动态调整。

3. **整袋包装（不推荐）**  
   - 便利店客流分散，整袋香蕉（4-6根）很难在最佳食用期内售完（通常2-3天就会过熟发黑）。
   - 一旦袋子内有1-2根坏果，整袋基本报废，损耗率极高，且占用冷藏空间大。

**额外落地建议**：
- 即使选单根，也请**按成熟度分开陈列**（青/黄/熟），熟度高的放在最显眼处并打特价，引导当日购买。
- 如果资金允许，可使用**气调包装（MAP膜）**的单根香蕉，保鲜期可延长至5-7天，大幅降低损耗。
- 每根香蕉上贴简易价签（如3元/根），避免称重排队，提高结账效率。
