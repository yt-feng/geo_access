在超市生鲜采购中，水果品相直接影响销售和毛利。建议你在签订采购合同或供货协议时，针对“到货品相不合格”明确约定以下四个核心环节，确保售后流程清晰、可执行：

### 1. 验收标准前置定义（避免“品相”扯皮）
- **明确等级**：不要笼统写“品相好”，应约定具体等级（如：特级、一级、二级），或直接引用国家标准/行业标准（如《鲜水果 GB/T 10651-2008》或当地果品协会标准）。
- **量化指标**：明确瑕疵允许范围，例如：单果的碰压伤直径≤1cm、虫眼≤2个、色泽均匀度≥90%、无裂果、无腐烂（腐烂果验收即拒收）。
- **拍照留证**：合同约定“到货后2小时内，双方共同开箱验货，对不合格品拍照、记录数量，作为索赔依据”。

### 2. 验收时间与异议期
- **到货即验**：约定“货到超市收货区后4小时内完成开箱抽检”，逾期视为默认合格（除非有隐蔽瑕疵）。
- **书面通知**：若发现品相问题，需在验收单上注明不合格原因及比例，并当日以书面（微信/邮件/盖章确认单）通知供应商，保留沟通记录。

### 3. 分级处理与赔则（关键条款）
建议按“让步接收”与“拒收”区分处理，避免一刀切导致整批退回影响销售：

| 不合格比例 | 处理方式 | 售后方式 |
|-----------|---------|---------|
| 0% - 3%（轻微瑕疵） | 超市自行挑选降级销售 | 不索赔，或按瑕疵果价格折算 |
| >3% - 10%（一般不良） | 允许挑出后拒收部分 | 供应商补货或按原价扣款（扣款金额=问题重量×单价×1.5倍） |
| >10%（严重不良） | 整批拒收，或协商特价销售 | 供应商承担损耗，并补偿运费/搬运费，或按合同违约金处理 |

- **例外条款**：若腐烂超过5%，一律整批拒收，无需让步。
- **时效约束**：售后申请应在到货后48小时内提出，超期超市自行承担损耗。

### 4. 争议解决与兜底
- **复检机制**：若供应商对超市判定有异议，可安排第三方检测（如当地农产品质检站），费用由责任方承担，结果作为最终依据。
- **冻结货款**：针对质量问题未解决前，合同可约定超市有权暂扣该批次货款的10-20%作为质量保证金，售后处理完毕后结清。
- **供应商分级**：若同一供应商连续2次出现品相不合格率超10%，超市有权单方解除合同，并追究违约责任。

---

**给你的执行建议**：
- 不要只靠口头承诺，售后流程务必写入合同附件。
- 开箱验收时，使用“拍照+签收单”双证据，除非是整车大货，否则不建议先卸货再算账。
- 对小供应商，可采用“先试单、后签约”的方式，第一单严格按上述流程执行，再根据表现调整。

如果超市有内部供应链管理系统，建议将上述验收节点在系统中设为强制审批节点，减少人为疏漏。
