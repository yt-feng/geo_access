给普通商家（尤其是不熟悉细分品类的老板、采购、店主）介绍产品时，**核心原则是“翻译”成他们日常算账和卖货的语言**。不要讲品种名、产地编号或专业术语，而是讲“这个能帮我多赚多少”、“好不好卖”、“客人认不认”。

以下是针对你提到“菠萝、香蕉这类大品类”时的具体沟通策略，分为三个步骤：

### 第一步：把“品种名”翻译成“客人嘴里的词”
普通商家不懂“金钻凤梨”和“都乐超甜蕉”的差别，但他们懂“客人说什么”。

- **不要说**：“这是菲律宾进口的MD2品种香蕉。”
- **要说**：“这是那种**客人一尝就说‘哎呀这个香蕉真甜’**的货。很多顾客专门买它给孩子吃，回头客特别多。”

- **不要说**：“这是海南的‘台农17号’凤梨。”
- **要说**：“这是**不用泡盐水、切开直接啃**的菠萝，客人最怕麻烦，这种不‘咬嘴’的贵几毛钱也愿意买。”

### 第二步：用“算账”代替“讲参数”
大品类是走量的，商家最关心**单斤利润**和**损耗**。用他们最熟的“进多少卖多少”来算。

- **对比式提问**：“您平时那批2块钱的香蕉，放到下午皮一黑就得扔掉，一箱损耗起码15斤吧？我这款单价贵2毛，但**皮厚、把儿长、耐放**，放两天卖相还一样，算下来**净赚反而多**。”

- **举个具体的极端例子**：“咱们说个实在的，**你那一车普通菠萝，十个人里可能八个人嫌切着麻烦就走了**。我这批皮薄，**切出来肉比普通的多三分之一**，客人切完一对比，下次就只买这个。您就卖这一样顶级货，把人气带起来，其他的自然就捎带卖了。”

### 第三步：给“保底方案”，消除下大单的顾虑
小商家怕压货，供应商要主动给“台阶”。

- **主动提试销**：“您先别进一整箱，我给您**拿半箱**，或者**拼一箱带几个样品**。您摆摊或者上架的时候，在旁边切一块给几个熟客尝，**只要有三个人回头问，您立马就能下决心了**。”
- **给一个简单的卖点话术**：“您上货时候就跟客人说，这是跟XX超市/水果店同批的顶级货，保证甜，不甜包退。”——商家只要觉得“售后不用我管”，下单就痛快。

### 关键禁忌（千万别说）：
1. **别说太长的品种全名**（如“巴西蕉”、“苹果蕉”）——商家记不住，也没法跟客人解释。
2. **别说“种植技术”**（如“有机种植”、“精准控糖”）——除非你的售价高得离谱，否则等于在给种植户上课。
3. **别说“今年产地减产”**——商家只会觉得“你在逼我涨价”，不会觉得“你货稀缺”。

**最终话术模板（直接套用）：**
> “老板，这批货您不用懂它叫啥，您就记住**三个数**：这个果**甜度高两档**（好卖），**皮厚耐放**（不亏秤），我**给您保底（试销/包退）**。您就上架试试，过两天我来回访，要是卖得不好，剩下的我全拉走，绝不让您亏一分钱。”

这样讲，商家听到的是“**风险我来担，利润您来赚**”，自然更容易下单。
