选择长期稳定的水果供应商，除了关注价格、新鲜度和送货速度外，最容易忽视的往往是以下**几个细节**，它们往往决定了生意能否长期跑赢同行：

**1. 分拣与损耗处理的标准**
- **忽视点：** 只看“整箱拿货价”，没细究箱内的“次品率”和“烂果率”。
- **为什么重要：** 有些供应商为了压成本，会把大小不一、甚至有轻微压伤的果子混在箱子底部。长期下来，你的损耗率会远超合同预估，利润被悄悄吃掉。
- **建议：** 约定**明确的验收标准（如单果克重、糖度、外观瑕疵比例）**，并在合同中写明“开箱验货有权拒收次品”的条款。看供应商是否愿意配合随机拆箱抽检。

**2. 供应链的“天气与突发风险”应对能力**
- **忽视点：** 只关心平时供货是否稳定，没测试过**极端情况（台风、价格暴涨、产地断货）**下的处理机制。
- **为什么重要：** 水果批发价波动极大，遇到产地减产或物流中断，很多供应商会直接取消订单或大幅涨价。稳定生意最怕货源突然断供。
- **建议：** 问清供应商是否有多产地备用渠道。**下单后保留书面聊天记录或合同**，明确“遇不可抗力无法供货时，需提前X小时通知并协商替代方案”。

**3. 冷链与“最后一公里”的温控记录**
- **忽视点：** 只关注送到时的品相，不关心运输途中**是否全程低温**。
- **为什么重要：** 部分供应商为了省油费，用普通货车运荔枝、草莓等易腐水果，表面看着还行，但内部可能已经发生**“冷害”或“熟化”**，放一两天就会快速变质，你根本来不及卖。
- **建议：** 偶尔**突击检查**到货车辆车厢温度记录（有车载温控仪的更好），或直接抽样切开看果芯温度。确保你有**恒温仓库**，且供应商的装车时间要短。

**4. 供应商的“账期”与财务健康度**
- **忽视点：** 只看供应商报价便宜，没查它的**付款条件和现金流**。
- **为什么重要：** 很多小型供应商靠赊销经营，一旦回款周期拖长（比如你要求月结），它可能会拖你货或降低品质。如果它自己资金链紧张，随时可能跑路。
- **建议：** 首次合作坚持**现款现货**，观察3个月后，再谈“月结”或“预付定金”。同时，定期查看供应商的营业执照和是否有其他商户的负面投诉。

**5. 包装与规格的“隐形差异”**
- **忽视点：** 只看“一箱XX斤”，没确认**箱子自重、包装层数和净含量误差**。
- **为什么重要：** 有些供应商会把纸箱加厚自重（比如纸箱就重1.5斤），或者用发泡箱充重。你按“斤”标价，实际到手净果比打的少很多。
- **建议：** 采购时**每次随机称重空箱和净果**，并规定“净含量误差在±3%以内”作为合格线，超差直接扣款。

**6. 供应商的“售后响应”和“证据留存”习惯**
- **忽视点：** 认为签了合同就万事大吉，遇到纠纷时才发现对方不认账。
- **为什么重要：** 水果质量问题非常零散，比如一箱里有5个烂果，很多供应商会推说是“运输挤压”或“你储存不当”。
- **建议：** 约定**到货后2小时内**若有问题需拍照留痕并反馈，供应商需在24小时内给出补偿（退款或补货）。**所有沟通尽量用微信/飞书等文字工具**，保留聊天记录作为凭证，避免电话口头承诺。
