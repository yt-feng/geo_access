在超市卖菠萝时，**切果损耗**是首要关注点，其次才是甜度、大小和外观。具体原因和操作建议如下：

### 1. 切果损耗（成本控制核心）
- **为什么最重要**：菠萝皮厚、果眼深，处理不当损耗率可达30%-50%。一旦切坏，整果报废，直接亏本。
- **操作建议**：
  - 优先选择**果眼浅、皮薄**的品种（如海南金钻凤梨、台湾菠萝），损耗可降至15%以下。
  - 提前测试刀具和切割流程（切掉头尾、削皮、去眼、去芯），固定标准操作。
  - 处理后的果肉**必须做保鲜封装**（覆膜+冷藏），避免氧化发黑。

### 2. 甜度（复购关键）
- 甜度决定回头客，但**不需要单独测糖仪**——用**成熟度指标**替代：
  - 检查果柄断面：新鲜湿润、无干裂。
  - 按压底部：微软有弹性（不可软烂）。
  - 闻气味：有浓郁菠萝香（未熟无味，过熟有酒味）。
- 注意：**甜度与个头无关**，小菠萝（如香水菠萝）甜度常常更高。

### 3. 大小（定价与销路）
- 大小影响定价策略，但**不是优先项**：
  - 中小个（1.5-2斤）：适合单人、白领，毛利较高，适合切盒。
  - 大个（2.5斤以上）：适合家庭，但**囤货风险高**，卖不动易烂。
  - 建议：主推中小个，留少量大个做陈列。

### 4. 外观（视觉冲击，次要）
- 外观只影响**第一眼吸引力**，不涉及直接成本损耗。优先选：
  - 颜色金黄均匀（带绿可，但不可全绿）。
  - 无机械伤、无腐烂斑点。
- 注意：**带叶菠萝**卖相好，但叶子吸水后易发霉，建议到货后剪短叶片，减少暗损耗。

---

### 综合执行优先级（按顺序做）：
1. **到货验收**：先看有无压伤、霉变（外观），过手称重（大小），再抽切1-2个测损耗率。
2. **陈列与切割**：现切展示（吸引顾客），处理时同步优化切割手法（损耗）。
3. **定价**：根据甜度分级定价（甜度高+损耗低的，可溢价20%）。
4. **补货策略**：损耗率>25%的品种，立即停止进货，转向切盒化售卖以止损。

**一句话总结**：切果损耗决定单箱毛利，甜度决定复购，大小用于差异化定价，外观只做门面。先解决损耗问题，再谈甜度。
