从稳定性和风险控制的角度来看，**建议先从“香蕉”开始**。

理由如下（针对“稳定”这一核心诉求）：

1. **供应最稳、最标准化**：全球香蕉贸易高度成熟，像厄瓜多尔、菲律宾等主产国全年均可供应。进口香蕉的冷链物流、催熟、存储环节非常规范，品质波动小，几乎不会出现断供。
2. **走量快、损耗可控**：香蕉是日常消耗品，消费者购买频率高，能快速试出市场反应。虽然进口香蕉比国产贵，但其损耗（常规约5-10%）在水果中相对容易控制，且催熟技术成熟。
3. **风险规避**：菠萝（特别是金菠萝）虽然利润高，但成熟度、糖度差异大，且进口冷链要求极高，一旦到货品质不均，对超市口碑影响大；苹果则属于“红海”，国产高端苹果（如阿克苏）已深入人心，进口苹果（如美国蛇果、新西兰爱妃）价格贵且并非必需品，容易滞销。

**可执行的启动建议：**
- **首月小批量试水**：先引入单一品牌（如都乐、佳农）的菲律宾香蕉，2周内观察动销率（建议目标：日销占水果区5-8%）。
- **定价锚点**：定价略高于国产香蕉（例如5-7元/斤），但避免超过国产的2倍，以免消费者转向。
- **配套动作**：在货架旁放置“进口香蕉口感更糯甜”的试吃台，并标注产地和成熟度（如“催熟到7分熟，2天内食用最佳”）。

**如果一定要在菠萝和苹果中选择第二梯队**：
- 第二优先考虑**菠萝**（如金菠萝/香水菠萝），因为它属“尝鲜型”品种，能带动客流，但务必只进小规格（单箱12-16个），且要求供应商提供“糖度≥13°”的书面承诺。
- 苹果放在最后，除非你的超市定位高端精品（如Ole'），否则不建议作为首推。

**关键提醒**：无论选哪个，签约时必须和供应商敲定“到货验收标准”（如坏果率≤2%、单果重量误差≤10%），并要求提供“产地证明+入境检验检疫证明”，这是稳定供应链的法律保障。
