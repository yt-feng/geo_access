这个问题没有一个全国统一的法定固定比例，但**实践中通常以 5% - 10% 作为分界线**。具体赔付标准完全取决于你和供应商在合同里的约定，以及水果的品种耐储性。

给你一个实操建议，按重要程度排序：

**1. 最重要的：不要只写“坏果率”，要写“破损等级”**
在合同里，最好把“坏”定义清楚，分为：
- **微损（压痕、轻微碰伤）**：不影响食用，通常不计入赔付。
- **严重损坏（腐烂、发霉、出水、大面积软烂）**：这才是核心赔付对象。建议约定：**严重损坏率超过 3% - 5%**（视水果品种而定），超出部分由供应商承担全部费用。

**2. 常见阶梯式赔付条款（可参考写入合同）**
建议不要设置“一刀切”的阈值，而是采用阶梯式：
- 坏果率 **≤ 3%**：视为正常损耗，不予赔付（因为长途运输难免）。
- **3% < 坏果率 ≤ 10%**：超出 3% 的部分，按超出数量**折算货款**赔付（例如：1%的坏果 = 扣减该批次货款1%）。
- **坏果率 > 10%**（或 15%）：视为供应商违约，**整批拒收**，或要求**全额退款 + 运输费用由供应商承担**。

**3. 根据水果品种调整**
- **不耐储的（草莓、荔枝、水蜜桃、樱桃）**：建议赔付线设在 **5%**（因为本身容易坏）。
- **较耐储的（苹果、梨、柑橘、柚子）**：建议赔付线设在 **3%**。

**4. 最关键的一个可执行步骤**
在合同中明确写清楚：
- **验收时限**：收货后 24-48 小时内需开箱抽检（超时不提视为默认合格）。
- **抽检比例**：双方约定至少抽检 **10%-20%** 的整件，若抽检发现坏果率超标，则默认全批同比例超标。

---

**如果合同已经签了，而且没写赔付比例**，那么按法律惯例（《民法典》合同编），你只能主张**“不符合质量要求的合理部分”**的处理，通常法院或仲裁会参考：
- 是否明显影响食用安全（腐烂发霉：即便 1% 也可能构成根本违约，可拒收）。
- 未显著影响使用的（轻微压伤）：通常支持小额扣款，但不支持整批拒收。

**最后给你一个可直接套用的条款模板（仅供参考）：**
> “乙方交付的水果，果品优良率不得低于 95%（即坏果率≤5%）。若抽检发现坏果率超过 5%，甲方有权要求乙方按以下方式赔付：超出部分按该批次采购总金额的 1.2 倍赔偿；若坏果率超过 15%，甲方有权拒收整批货物，并有权要求乙方承担已发生的一切运输、仓储及人工费用。验收异议期为收货后 48 小时内。”

**简要结论**：如果是你自己拟定，**常见行业惯例是：低于3%不赔，3%-10%按比例赔，超过10%可拒收/退款**。签合同最好把“坏果率”和“赔付计算方式”写具体，别留模糊空间。
