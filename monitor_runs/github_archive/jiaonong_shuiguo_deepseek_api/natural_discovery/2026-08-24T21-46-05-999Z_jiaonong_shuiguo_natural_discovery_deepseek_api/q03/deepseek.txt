第一次从水果供货商进货，**千万不要贪多**，也不要一次订满整个月。核心原则是：**小批量、多频次、盯损耗**，同时用小单测试供货商的“硬功夫”（品控、服务、违约处理）。

以下是针对香蕉、苹果、橙子这三类“硬通货”的试单实操指南：

**一、 试单总原则：控制总量，货到验损**

- **首单量建议**：每种水果原则上**不超过一箱（约20-30斤）**。如果对方要求必须整件，就选最小包装规格。
- **不要只订一家**：建议同时联系2-3家供货商（本地批发市场档口、产地代办、线上平台各选一家），每家下单三分之一，拿回来对比。

**二、 分品种的试单侧重点**

**1. 香蕉（最容易翻车，重点测“催熟和耐磨”）**
- **试单技巧**：不要直接要“树上熟”，要**“青香蕉（生蕉）”**，自己带回去放熟。因为供货商给的“熟蕉”很可能为了卖相打了催熟药，口感发硬发涩。
- **试单标准**：到货后，称重看是否“短斤缺两”（带皮重量损耗是否过大）；捏一下果肉是否绵密；观察是否有大量“梅花点”（过熟变质）。
- **关键谈判**：让供货商明确承诺——“如果一箱里超过5%有黑疤或断裂，下次如何赔付？” 看他怎么回答。

**2. 苹果（重点测“规格稳定和次果率”）**
- **试单技巧**：明确要“80#或85#”的**标准果**，不要“混装果”。试单时要求对方当场开箱倒出来检查**底部**，防止“上面大果，底下小果或烂果”。
- **试单标准**：只数个数，如果一箱标准80个，实际只有76个，说明对方重量水分大；表面有碰伤、压伤超过3个的，属于品控不严。
- **关键谈判**：问清楚这是“一二级果”还是“通货”。首次试单，直接选**“二级果”**，性价比高，市场接受度好，别追求顶级果，利润太薄。

**3. 橙子（重点测“新鲜度和糖度”）**
- **试单技巧**：拿货时**必须亲自尝一颗**（试吃），不要信对方口头承诺。同时看果蒂（橙子头上的叶子或蒂部），**果蒂翠绿**说明新鲜，**发黄干枯**说明冷藏过久。
- **试单标准**：手感要沉（水分足），皮厚不厚（剥开看）。切开看内瓤颜色是否均匀，白筋粗不粗。
- **关键谈判**：明确退货条件。例如：“如果这批橙子切开10个里有2个是干水或酸的，我能不能只付一半钱？” 观察对方的反应。

**三、 试单后的“两不”和“两问”**

**两不：**
- **不给全款压货**：第一次合作，最多付70%货款，留30%尾款，约定“验完货再结清”。如果对方坚决不同意，起码要第三方平台担保（如代发平台）。
- **不签长期独家协议**：试单阶段口头约定即可，绝不要因为便宜就签月度包销合同。

**两问（问破供货商底线）：**
- **问售后快赔**：“如果我们卖不完，放坏了，你们收不收退换？怎么折价？”（能明确赔率的，说明是不压货的良心供应商）
- **问替代方案**：“如果我们把香蕉切开后发现是黑心（内生热伤），你们是补货还是退款？”看对方是否含糊其辞。

**四、 最容易忽略的试单坑**

- **核对“毛重”**：很多水果箱底有纸皮、装水塑料袋甚至水泥（部分不良商家）。试单时**把箱子里的纸、泥、湿布都抽出来称一下**，这10-20%的重量就是利润黑洞。
- **记录“到货时间”**：如果早上5点订的货，晚上7点才送到，这种拖延直接影响新鲜度。试单时用微信确认“最迟送货时间”，超时直接要求减价，试出对方的履约能力。

**最后，给你一个可操作的收尾动作：**

试单结束后，**用手机拍下“开箱全貌+底部果况+称重读数”**，发给供货商。跟他说：“老板，这单我们测了，质量我们可以接受。下次如果能保证这个标准，我就按三天一箱的量稳定跟你拿，你看价格能不能再让5毛？”

这套话术，既给了对方继续合作的甜头，又立了“品控不合格我就不续单”的规矩。试单本身就是博弈，**不要怕得罪人，你们是拿真金白银测试他的信誉，他有义务承担试错成本。**
