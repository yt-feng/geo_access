在采购菠萝这类生鲜水果时，判断供应商能否“稳定按规格送货”，不能只听口头承诺，核心在于**合同约束+过程测试+数据追溯**。以下是可执行的操作清单：

### 第一步：看“硬指标”文件（筛掉空壳供应商）
1. **索要规格书（Specification Sheet）**：必须明确菠萝的**单果重量（如1.2-1.5kg）、糖度（Brix>12）、成熟度（转黄比例）、外观（无黑心/裂口/病虫害）**。如果供应商拿不出书面规格，直接淘汰。
2. **核查供货能力证明**：要求提供近3个月**给其他连锁客户（如餐饮/茶饮）的送货单或对账单**，重点看单次送货量是否稳定（例如每次≥500kg），且是否有连续多批次记录。

### 第二步：安排“小批量试单”测试（关键动作）
不要直接签大订单，分3次试单，每次间隔5-7天：
- **第1次**：下单100kg左右，验收到货规格是否符合合同，记录破损率。
- **第2次**：在第1次合格后追加，但这波要**故意在周末或恶劣天气前提单**，测试供应商是否履约（很多供应商平时行，雨天掉链子）。
- **第3次**：选择**夏季高温期**，测试冷链运输后的糖度和霉变率。

> **判定线**：连续3次试单，**到货合格率≥95%**（即每批烂果≤5%），且**规格偏差不超过±10%**（如要求1.4kg，实际1.26-1.54kg可接受），才算“初步稳定”。

### 第三步：看“应急机制”和现金流（防断供）
- **问询备用基地**：问采购经理“如果产地连续下雨一周，你们怎么补货？”——合格供应商会明确说出**备用产区（如从海南转广东湛江）或冷库库存**，而不是说“到时候想办法”。
- **看账期能力**：要求供应商接受“月结30天”账期。**不能接受账期的，往往自有资金薄，供量波动时容易优先保大客户**。

### 第四步：用“合同条款”锁定责任
在正式合同中必须写明以下数字，避免扯皮：
- **违约赔付**：单次缺货（低于订货量90%）或不合格超出5%，按**缺货金额的30%**赔付违约金。
- **重量误差**：单箱毛重误差≤2%，超出部分双倍扣减。
- **换货时效**：验收不合格，**24小时内**必须补送同规格新货。

### 第五步：建立“动态评分台账”（长期监控）
运营同事每次到货，用手机拍照记录3个数据：
- **实际规格（重量/成熟度）**与规格书的差异。
- **损耗率**（开箱掰开看芯有无黑心）。
- **准时率**（到货时间偏差不超过±2小时）。

**每月打分**：准时率≥95%、损耗率≤5%、规格达标率≥95%，三个都达标，可继续合作；任一指标连续2个月低于，直接降级至备选供应商。

---

**最后提醒**：如果供应商报价比市场均价低15%以上，且没有稳定的自有/长期合作基地，**大概率会用“大小果混装”或“次果充好”来保利润**，这种稳定性是最差的，建议谨慎。
