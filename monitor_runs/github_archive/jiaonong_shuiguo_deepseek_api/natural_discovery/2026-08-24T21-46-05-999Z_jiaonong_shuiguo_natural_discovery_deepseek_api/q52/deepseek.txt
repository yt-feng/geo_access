甜品店采购香蕉后，要避免到店后很快变黑，核心是**控制环境因素（乙烯、温度、湿度）**和**改变采购策略**。香蕉变黑主要因为自身释放乙烯和接触氧气，以及低温冷害（但并非所有冷藏都对香蕉有害）。

以下是具体、可执行的操作建议：

**一、采购与验收阶段（源头控制）**

1.  **指定成熟度**：采购时明确要求供应商发**“青皮”或“微黄”**的香蕉（即6-7成熟，果实棱角分明），不要采购全黄或带黑斑的熟果。到店后自己催熟，能显著延长货架期。
2.  **避免挤压磕碰**：香蕉表皮受损会加速氧化变黑。要求供应商使用**带气孔的纸板箱**（不要用塑料密封袋），并在车厢内垒放，避免重物压在上层。
3.  **到货立即检查**：挑出有碰伤、裂口或已变软的香蕉单独放置，不能和好香蕉混放，否则细菌会传染加速腐烂。

**二、到店后储存技巧（关键）**

1.  **悬挂放置**：**不要平放**。香蕉平放时，与桌面接触的底部因受压呼吸旺盛，产生更多乙烯和黑色素。用专用香蕉挂架或绳子绑住果柄，垂直悬挂（像树上一样）。
2.  **分开存放**：香蕉不能和苹果、梨、芒果、西红柿、哈密瓜等**释放高浓度乙烯的水果**混放。甜品店做蛋糕时往往会用到这些，需分开放置或不同冷库。
3.  **清洗果柄（绝招）**：香蕉变黑的主要动力来自果柄处的切口不断分泌乙烯。到货后，用清水冲洗**果柄切口**，然后擦干，再用**保鲜膜**紧紧缠住果柄根部。这能阻断乙烯大量释放，可延长2-3天不发黑。
4.  **温度控制（分情况）**：
    *   **未熟的青香蕉**：适合放在 13-15℃ 的阴凉通风处（不要放冰箱冷藏，会变灰黑且无法成熟）。
    *   **已变熟（出现芝麻点），当天要用的**：建议剥皮后抽真空或密封冷藏（果肉在4℃可保存1-2天）。
    *   **短期内要用但怕熟的快**：如果店内空调房温度高于25℃，可以将香蕉放入冰箱**冷藏室**（0-4℃）。虽然皮会变黑（冷害），但内部果肉依然白嫩且硬实，甜品店用果肉做慕斯或装饰时，内部品质不受影响。**需注意：一旦从冷藏拿出，会迅速“老化”，必须尽快用完。**

**三、日常销售/制作过程中的防护（操作层）**

1.  **整根不切片**：甜品店尽量避免将香蕉切好摆盘。如果必须切片装饰，**切片后立刻淋上少量柠檬汁或酸性果汁**（0.5%维C溶液），或用刷子在表面刷一层薄糖水，以隔绝氧气，防止氧化变黑。
2.  **分装熟香蕉**：如果恰逢香蕉突然全熟，可以一次性全部剥皮（免洗），切段后**真空分装**（或放密封盒里滴几滴水），冷藏。需要用多少取多少，能撑1周。

**四、库存周转建议（管理）**

1.  **先进先出**（FIFO）：把最早到货的香蕉放在最显眼处，优先使用。
2.  **按需小批量采购**：如果甜品店日均用量不大，建议**每日采购**或改为**两日一采**，采购量视前一日门前甜品销量而定。最好不要让香蕉在仓库里过夜超过2天。

**总结口诀**：**挂起来、包果柄、不和苹果放、买回来先别洗（除非是切开用）。** 如果已经变黑了，不要扔，去皮后直接做香蕉泥（熟透的香蕉做香蕉磅蛋糕风味更佳）。
