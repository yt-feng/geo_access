评估连锁门店水果供应商的仓配覆盖，核心逻辑是**“以门店销售预测为起点，以到店保鲜质量为目标，以全链条成本为约束”**。水果属于高损耗、短保质期商品，因此评估不能只看“能不能送到”，更要看“送到时还新不新鲜”以及“应急反应快不快”。

以下是分步骤的实操评估框架：

### 第一步：定义“覆盖”的硬性指标（KPI底线）
在评估供应商方案前，先设定门店必须满足的**服务水平协议（SLA）**：

1.  **到店时效**：从供应商仓库发货到门店签收，**常温/冷链**分别要求多少小时？（例如：一线城市24小时内，跨省48小时内）。
2.  **生鲜完好率**：验收时，水果磕碰、腐烂率必须低于**0.5%~1%**（不同品类不同，如草莓需更严格）。
3.  **温控断链点**：供应商从产地/总仓到门店，冷链车是否全程打冷？中途是否允许开箱？

---

### 第二步：评估供应商的仓网布局（网络密度）
不能只看对方“有没有仓库”，要看仓库**离你的门店有多近**。

| 评估维度 | 关键问题 | 优秀标准 |
| :--- | :--- | :--- |
| **前置仓/分拨仓** | 供应商在**你的核心门店城市**（或300公里半径内）是否有自建或长期租赁的周转仓？ | 每个省级核心城市至少有1个分拨仓，并能提供仓租合同或现场照片证明。 |
| **干线能力** | 从总仓到分拨仓的班车频率（每日/隔日）？ | 每日有固定班次，能支持“次日达”末端配送。 |
| **末端配送** | 是供应商自有车队，还是外包到第三方物流（3PL）？ | 自有车队优先（可控性高）；若外包，需确认3PL的冷链资质和投诉率。 |

**行动建议**：如果一家供应商在5个城市有门店，但他只在1个城市设了仓，那么即使他说“全国覆盖”，你的跨城门店损耗风险也会极高，**不建议签约**。

---

### 第三步：评估动态履约机制（比静态仓更关键）
水果销售波动大，供应商不能是“死板的送货机器”，要评估其**应对峰值和缺货**的能力：

1.  **补货响应速度**：门店昨晚下单，今早能到吗？如果当天下午突然爆单，能否在6小时内加急补货？
2.  **替代品方案**：如果某款水果（如巨峰葡萄）断货，供应商能否在1小时内提供同品质的替代品（如夏黑葡萄）并主动报告价格差异？
3.  **退换货逆向物流**：门店拒收的损耗果，供应商多久上门取走并冲抵货款？（建议要求48小时内）。

---

### 第四步：现场模拟测试（压测法）
不要听PPT，直接“动真格”：

- **盲测发货**：选择3家不同距离的门店（近郊、市中心、偏远县城），要求供应商在下单**后24小时内**送达，并附上全程温度记录仪（T-log）数据。
- **检查水果呼吸热**：验收时用手摸包装箱内衬，如果温度明显高于环境温度，说明在途散热不良，这种供应商要扣分。
- **应急演练**：提前告知气象局发布了台风预警，询问供应商备选转运路线预案是否具体到道路名称。

---

### 第五步：成本与覆盖的平衡模型
覆盖越好，单价通常越高。你需要计算**总持有成本（TCO）**：

\[
\text{单位成本} = \text{采购单价} + \frac{\text{运输费} + \text{仓储费} + \text{损耗分摊}}{月均采购量}
\]

- **如果供应商只覆盖核心城市**：省去了跨省运输费，但需评估**非核心城市门店是否值得为它单独开线**。
- **如果供应商覆盖全部城市**：建议让出10%-15%的采购溢价，但必须要求对方承诺“**坏果包赔，且赔付比例不低于2%**”，否则高溢价无意义。

---

### 第六步：建立供应商退出预警机制
签约后至少每季度评估一次：

- **量化指标**：准时到货率（目标≥98%）、到货完好率（≥99%）、售后处理时效（≤24小时）。
- **红线触发**：如果连续2个月在某个城市“完好率”低于98%，要求供应商在该城市增设临时周转点，或者**降级为B类供应商（减少采购量）**。

---

**最终决策建议**：
如果供应商的仓配方案能做到“**仓距核心门店≤300公里、冷链不断链、24小时应急响应、坏果赔付率≥2%**”，那么此覆盖体系基本合格。若在偏远城市无法覆盖，不建议强行选用，可考虑**区域专门供应商（专供该省）**与核心全国供应商组合使用，以降低风险。

**请注意**：以上所有涉及具体百分比（如98%）均为行业常见基准值，具体条款必须写入合同，并以实际谈判为准。如果对方无法提供温度记录仪数据，请高度警惕其冷链真实水平。
