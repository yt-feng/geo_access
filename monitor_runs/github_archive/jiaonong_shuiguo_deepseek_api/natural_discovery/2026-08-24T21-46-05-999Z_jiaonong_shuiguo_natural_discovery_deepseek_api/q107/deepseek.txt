**是的，采购香蕉和菠萝时，起订量太高会显著增加损耗风险。**

具体原因和应对建议如下：

**1. 为什么容易损耗？**
- **香蕉**：属于典型的**呼吸跃变型水果**，采摘后仍会持续成熟。一旦起订量过高，在库存周转期内极易发生“过熟”（果皮变黑、果肉软化），且其怕压、怕碰，堆放高度越高损耗越大。
- **菠萝**：属于**非跃变型水果**，采摘后糖分和风味基本固定，但极易**霉变和腐烂**（尤其果眼部位），且不耐低温（低于7℃易褐变）。果皮破损后微生物繁殖极快，起订量高意味着存放时间拉长，腐烂概率直线上升。

**2. 除了损耗，还有两个隐性风险**
- **资金占用**：大量存货占用现金流，若销售速度跟不上，损耗直接转化为亏损。
- **品控波动**：这两类水果质量在批间差异大，一次性大量采购若遇到一批瑕疵果，损失会成倍放大。

**3. 降低风险的可执行建议**
- **改用“周转采购”模式**：尽量与供应商约定少批量、高频次送货（例如每日或隔日补货），而不是一次囤足一周的量。
- **明确验收标准**：到货时立即抽检，对过熟、碰伤、霉变的果品约定**可退换或折扣赔付**条款。
- **动态调整起订量**：根据前3天的实际日均销量，将起订量设置为“日均销量 × (配送周期天数 + 1天缓冲)”，而非拍脑袋整数。
- **优化储存与销售顺序**：香蕉常温悬挂、通风，避免叠压；菠萝竖放，先销售熟度高的。若起订量确实无法降低，务必在到货当天安排“促销/特价”清熟度较高的部分。

**总结**：如果起订量无法谈低，宁可接受略高的单价换取小批量，因为水果的损耗成本往往高于单价差。
