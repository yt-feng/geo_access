判断香蕉批发时的熟度和坏果风险，核心是**看“果把”和“果身”**，同时结合**产季和运输**判断。以下是实用判断方法：

### 1. 看熟度（决定你能卖几天）

- **看果把（果柄）切口**：新鲜切口呈**青白色**且湿润，为刚催熟后出厂，硬度高，适合长途或囤货。切口发黑、干瘪，说明已经放置很久（果龄大），熟度偏高。
- **看果棱**：用手捏香蕉侧面，果棱（凸起的棱角）**明显突出**为生，**摸上去圆润、棱不明显**为即将成熟，**完全无棱且整体软**为熟透。
- **看颜色**：全绿为“硬熟”，适合冷藏；黄中带绿（“绿头黄”）是**最佳批发状态**，能放2-3天；全黄且出现黑点（梅花点），只能当天卖。
- **试手感**：轻捏，皮肉分离感越明显越熟。

**建议**：拿“绿头黄”占比70%以上，全黄占比≤15%为安全线。

### 2. 判断坏果风险（关键看运输和损伤）

- **查“压伤”**：打开纸箱，翻动中间几把，如果发现果身有褐色**凹陷斑**（手指按压位置），这是**碰撞伤**，3天内必烂，风险极高。
- **查“发霉”**：检查果把末端是否有白色/灰色霉点，这是果霉菌感染，会快速传播。
- **查“腐烂流水”**：箱底如果有褐色汁液，说明底层香蕉已腐烂，整箱可能污染。
- **查“催熟剂残留”**：如果果把切口流出的乳汁是**黑褐色**，说明催熟过度，不建议拿。

### 3. 高风险信号（直接放弃）

- **整箱发热**：手伸进箱内感觉温度明显高于外界，说明香蕉在箱内“自熟”发酵，大概率开箱就烂。
- **果柄发黑且有酸味**：已开始酒糟化，卖不上价。
- **雨季/台风季到货**：如果产地连续下雨或台风，香蕉水分大易裂，即便外观完好，内部也可能“水烂”。

### 4. 实操建议

- **签收要求**：整箱按批次抽检3-5箱，翻底看最下层，**不签书面“完好”**，保留拒收权。
- **风险对冲**：如果拿的货全黄比例超20%，**务必掐好24小时销售节点**，否则建议让批发商打折或换货。
- **备选方案**：如果现场判断困难，拿货时要求批发商注明“催熟日期”，一般来说，**催熟后第3-5天是香蕉黄金售卖期**，以此倒推你的进货时间。

**一句话口诀**：青把切口看新老，果棱圆滑才算熟；箱内发热赶紧退，霉点压伤全不要。
