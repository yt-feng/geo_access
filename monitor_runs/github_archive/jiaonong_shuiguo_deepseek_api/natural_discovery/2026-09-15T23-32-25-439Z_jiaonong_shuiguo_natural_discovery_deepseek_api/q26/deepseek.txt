社区超市卖小包装香蕉，核心矛盾是：**香蕉后熟快、怕压怕冻，小包装又会放大损耗和人工**。采购和包装要围绕“控熟、防压、快周转”来做。

**一、采购时先定分级和成熟度**

1. **不要按“越大越好”采**  
   小包装通常按根卖或 3～5 根一袋，适合选中等果指、长度均匀、弯曲顺手的蕉。太大装不进盒、袋，太小显得分量不足。

2. **成熟度按销售节奏分批采**  
   - 计划 1～2 天卖完：采 3～4 级熟（微软、转黄）。
   - 计划 3～5 天卖完：采 1～2 级熟（青硬、微黄）。
   - 不要一次全采同一成熟度，否则要么一起青、要么一起黑。
   - 夏天适当偏青采，冬天可稍熟采，但社区超市若没有催熟/冷藏条件，宁青勿过熟。

3. **采购时重点看蕉梳和蕉指状态**  
   - 蕉梳完整、果柄短而干净，减少伤口。
   - 果皮无大面积擦伤、水渍、黑斑、裂口。
   - 果指饱满但不过度鼓胀，过鼓往往已接近过熟。
   - 切口新鲜，不发黑、不流汁、不霉。
   - 无药害斑、冻伤斑、挤压伤。

4. **问清产地、采收期和运输温度**  
   香蕉怕冻，低于约 12～13℃易冷害，皮发暗、难后熟；高于 30℃又容易过快转熟。运输和到店温度尽量稳定，避免暴晒、闷车厢、冷库直吹。

**二、包装上要解决“防压、透气、控熟、好拿”**

1. **优先用透气包装，不要全密封**  
   香蕉会释放乙烯，密封袋里会催熟自己，很快出黑斑。可选：
   - 打孔 PE 袋；
   - 网套 + 托盘 + 透气膜；
   - 纸质/可降解透气盒；
   - 橡皮筋捆把后裸放，再套薄袋。
   
   不建议真空、完全密封、厚膜热封。

2. **按“根”或“小把”分装，别硬掰单根**  
   单根香蕉伤口大、易发黑。最好按自然蕉梳分成 3～5 根一把，或切梳后保留短果柄。若必须单根卖，切口要平整，并用食品级蜡纸/膜包切口。

3. **包装要防压**  
   - 盒装：选有分隔或凹槽的托盘，避免叠压。
   - 袋装：不要装太满，袋内留空间。
   - 陈列：不要堆高超过 2～3 层，重物不要压在上面。
   - 网套能防擦伤，但会挡视线，建议局部使用。

4. **标签别贴在果皮上**  
   标签贴包装上，避免撕扯果皮。若必须贴果，选易揭标签，贴果柄附近。

5. **控制单包规格**  
   社区超市常见小包装：
   - 2～3 根装：适合一人食、儿童；
   - 4～5 根装：适合小家庭；
   - 6～8 根装：适合大家庭但损耗风险高。
   
   先试 3 根和 5 根两种，看动销。包装越大，一旦熟过头越难处理。

**三、损耗控制的关键动作**

1. **到店立刻拆箱散热**  
   不要整箱闷着。拆箱、分把、挑出伤果，按成熟度分区。

2. **分区陈列，先进先出**  
   - 青的放里面/下层，熟的放前面。
   - 每包标到店日期或成熟度色标。
   - 每天翻堆，把快熟的挑出来做特价或加工。

3. **温度别太低**  
   社区超市若放冷柜，香蕉不宜长期低于 13℃。夏天可放阴凉通风处，避免空调直吹和日光灯直射。冬天远离门口冷风。

4. **不要喷水**  
   香蕉喷水会加速黑斑和霉变。保持干爽。

5. **快熟果及时分流**  
   - 做“今日特价”；
   - 做香蕉奶昔/果切搭配；
   - 员工试吃或折价处理；
   - 不要等全黑再降，越晚越没人买。

6. **设损耗警戒线**  
   小包装香蕉损耗通常比整梳高。建议先按：
   - 日损耗率超过 5%：检查采购成熟度是否太熟、包装是否闷；
   - 超过 10%：减少采购量或改为“按把卖 + 现场分装”；
   - 连续 3 天剩货：降低单包根数或改预售/预订。

**四、采购谈判和到货验收要点**

- 合同里写明：成熟度等级、单根长度/粗细范围、允许伤果比例、到货温度、包装方式。
- 到货抽检：每箱抽 2～3 把，看切口、果柄、黑斑、压伤、软硬。
- 不合格当场拍照、记录、拒收或扣重。
- 要求供应商分批送，不要一次压太多货。
- 先小批量试销 1～2 周，记录每天到货量、售价、丢弃量、售罄时间。

**一句话建议**：小包装香蕉采购要“偏青分批采、透气防压装、到店快散热、熟果快分流”；包装优先打孔袋/透气盒，按 3～5 根一把卖，别做全密封和单根硬掰。
