要避免香蕉到店后很快变黑，核心是**控制乙烯、减少机械损伤、降低温度但别冻伤**。可以按下面做：

1. **采购时选成熟度合适的香蕉**
   - 不要买已经全黄、带黑点、果柄发黑的。
   - 甜品店如果 1–2 天内用完，可以买**微黄、果柄青绿、硬度适中**的。
   - 如果需要放 3–5 天，买**青黄、偏硬**的，到店后自然熟。

2. **运输和到店后避免挤压、碰撞**
   - 香蕉变黑很大原因是**机械伤**，碰伤处会快速褐变、发黑。
   - 不要堆压，不要和硬物混装。
   - 到店后轻拿轻放，别整箱倒来倒去。

3. **悬挂或单层摆放，减少接触面**
   - 最好用**香蕉挂钩**悬挂，减少受压。
   - 没条件就单层平放，果柄朝上或侧放，不要叠压。
   - 不要直接贴冷柜内壁或风口。

4. **隔离乙烯，别和苹果、梨、番茄等放一起**
   - 苹果、梨、番茄、牛油果等会释放乙烯，催熟香蕉。
   - 香蕉自身也会释放乙烯，所以到店后尽量**分开放、少量分批取用**。
   - 可以用保鲜袋 loosely 套住，但不要完全密封，避免水汽闷坏。

5. **温度控制：12–15℃ 左右较合适**
   - 香蕉怕冷，**低于 10℃ 容易冻伤变黑**，所以不要直接放冰箱冷藏室。
   - 夏天如果室温太高，可放阴凉通风处，或放**空调房、冷藏柜外侧、12–15℃ 的保鲜区**。
   - 已经切开的香蕉必须冷藏，但那是另一回事。

6. **到店后尽快做“分批处理”**
   - 把青一点的、黄一点的分开。
   - 先熟先用的放前面，后熟后用的放阴凉处。
   - 如果当天用不完，可把部分香蕉**去皮切段冷冻**，做奶昔、冰沙、香蕉泥，避免继续变黑。

7. **减少水汽和冷凝水**
   - 香蕉表面有水容易发黑。
   - 从冷库/冷链车到常温店后，不要马上拆袋，等温度回升一点再拆，减少冷凝水。
   - 纸箱内可垫吸水纸，但不要包得太严。

8. **采购节奏比保存更重要**
   - 甜品店最好**少量多次采购**，比如每天或隔天补货。
   - 不要一次囤太多。香蕉是呼吸跃变型水果，一旦开始熟，很难长期压住。

简单记：**买青黄适中、不挤压、不冷藏冻伤、避乙烯、阴凉通风、分批用。**  
如果已经出现少量黑点但果肉没坏，可以优先做香蕉泥、烘焙或冷冻，不要继续常温放。
