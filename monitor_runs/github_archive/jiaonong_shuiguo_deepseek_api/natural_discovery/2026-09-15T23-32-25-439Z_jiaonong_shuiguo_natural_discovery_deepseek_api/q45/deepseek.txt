连锁超市和水果供应商签年度合同，最容易踩坑的条款集中在“价格随行就市”“损耗归属”“账期与对账”“退换货标准”“独家/返利”这几块。下面按风险从高到低说，并给出可执行的写法方向。

**1. 价格条款：最忌“随行就市”四个字**
- 坑：只写“价格随行就市，双方协商”，到旺季涨价或淡季压价时没有依据，扯皮甚至断供。
- 建议：约定定价基准和调整机制。比如“以XX批发市场每日均价为基准，上下浮动不超过X%”；或“每月X日双方根据上月均价确认下月价，未确认则沿用上月价”。同时写清调价提前通知期（如提前7天书面通知）。

**2. 损耗与验收：水果是生鲜，损耗不写清必吵**
- 坑：只写“按国家标准验收”，但水果没有统一可操作标准，收货时超市说烂了、供应商说运输正常。
- 建议：把验收标准量化写进合同附件：品种、等级、单果重量/直径、成熟度、糖度、允许瑕疵比例（如坏果率不超过3%）。明确验收时限（如到货2小时内完成）、验收地点、谁承担卸货前损耗。途损一般由供应商担，收货后超市保管不当的损耗由超市担，要分界清楚。

**3. 账期与对账：拖款和扯账的重灾区**
- 坑：只写“月结30天”，但没写对账日、发票开具时间、起算点，导致“货到日”“对账日”“开票日”三个口径打架。
- 建议：写清“每月X日前双方完成上月对账，供应商X日内开票，超市收到发票后X日内付款”。约定逾期付款违约金（如日万分之几），也约定供应商发票不合规的后果。

**4. 退换货与质量责任：要区分“质量问题”和“卖不动”**
- 坑：超市要求“卖不完可退货”，供应商以为只退坏货，结果临期、滞销全退回来。
- 建议：明确可退范围。质量不合格、农残超标、规格不符的可退并由供应商承担；正常销售中的滞销、临期是否可退、退货比例上限、退货费用谁担，都要单独写。农残检测责任和超标赔偿也要约定。

**5. 返利、进场费与独家条款：容易踩反垄断和算不清账**
- 坑：口头承诺返利、返点没写清计算口径；或约定“超市不得从其他供应商进货”这类排他条款。
- 建议：返利写清基数（含税/不含税、是否扣退货）、比例、结算时间、支付方式。独家/排他条款要谨慎，可能触及反垄断法，且实际执行中超市往往做不到，反而给供应商留把柄。进场费、促销费、堆头费要列明项目和金额，避免“其他费用另议”。

**6. 供货保障与违约责任：防止旺季断供或压价断供**
- 坑：只写供应商违约赔偿，没写超市无故拒收、拖欠货款的违约责任，权利义务不对等。
- 建议：约定最低供货量或供货保障义务，以及超市最低采购量（若有）。违约责任对等：供应商断供应提前通知并赔偿；超市无故拒收或逾期付款也要担责。约定不可抗力范围，但要把“市场价格波动”排除在不可抗力之外。

**7. 合同期限与自动续约**
- 坑：写“到期自动续约一年”，结果想换供应商时发现被绑定。
- 建议：到期前X天双方书面确认是否续约，未确认则到期终止，不要默认自动续。

**8. 争议解决与管辖**
- 坑：约定在超市所在地法院，供应商异地维权成本高。
- 建议：协商选择双方都能接受的管辖地，或约定仲裁。小供应商尤其要注意这一条的实际成本。

**一句话总结**：价格要有基准和调价机制，损耗验收要量化，账期要对账开票付款三口径统一，退换货要区分质量问题和滞销，返利排他要写清且防反垄断风险，违约责任要双向对等。
