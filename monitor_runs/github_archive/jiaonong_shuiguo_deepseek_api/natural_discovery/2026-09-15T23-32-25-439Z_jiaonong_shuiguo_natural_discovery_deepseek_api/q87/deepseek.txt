社区团购旺季爆单前锁定水果库存，核心是**把“口头预留”变成“有约束力的分阶段锁量协议”**。水果非标、易损、价格波动大，供应商通常不愿意无条件压货，所以要用机制设计让对方愿意锁。

---

## 一、先做需求预测，再谈锁量

供应商最怕你“说要100万斤，最后只提10万斤”。所以先拿出可信的预测：

- **历史数据**：去年同期单量、品类结构、复购率
- **预售数据**：提前7–15天开预售，用真实订单反推需求量
- **分层预测**：爆款品类（如砂糖橘、车厘子、西瓜）单独预测，长尾品类合并

**可执行动作**：把预测拆成“保底量 + 弹性量”两档，比如保底8万斤、弹性上限15万斤。这样供应商知道最低能出多少，也愿意给你留产能。

---

## 二、锁定库存的4种协议方式

### 1. 保底量 + 预付款锁价
- 约定保底采购量，支付**10%–30%预付款**
- 供应商按锁定价供货，超出部分按市场价或约定浮动价
- 适合：价格波动大的品类（车厘子、榴莲）

### 2. 分阶段锁量
- 旺季前30天锁总意向量的60%
- 前15天根据预售数据追加20%
- 前7天最终确认剩余20%
- 每阶段价格可重新议，但量优先保障

### 3. 包园/包基地
- 直接和产地果园或合作社签包销协议
- 提前支付定金，锁定整片果园的产出
- 适合：单品爆款、量大、能承受一定损耗

### 4. 联合采购/拼单锁量
- 联合周边几个社区团购团队一起向供应商下单
- 用总量换优先供货权和更低价
- 适合：中小团购平台，单独议价能力弱

---

## 三、合同里必须写清楚的条款

| 条款 | 作用 |
|------|------|
| 保底采购量 + 未达标补偿 | 防止你放鸽子，也防止供应商不给你留货 |
| 分级定价 | 锁价部分、浮动部分分开 |
| 质量标准 | 糖度、大小、成熟度、损耗率上限 |
| 交付节奏 | 每天/每批到货时间和数量 |
| 违约条款 | 供应商断供、你弃单分别怎么赔 |
| 不可抗力 | 天气、疫情、物流中断的处理 |
| 优先供货权 | 旺季供不应求时你必须排前面 |

---

## 四、用“利益绑定”让供应商愿意锁

光靠合同不够，要给供应商实际好处：

1. **预付款**：直接解决供应商现金流，最有效
2. **稳定订单**：承诺整个旺季持续采购，不是一锤子买卖
3. **缩短账期**：现结或周结，比账期30天更有吸引力
4. **共担损耗**：约定合理损耗率，超出部分双方分担，而不是全压给供应商
5. **品牌背书**：帮供应商做产地宣传，长期合作价值

---

## 五、旺季前的执行时间表

- **旺季前60天**：筛选2–3家主力供应商，谈框架协议
- **前45天**：签保底量协议，付预付款
- **前30天**：开预售，用数据修正预测
- **前15天**：追加弹性量，确认物流和仓储
- **前7天**：最终锁量，供应商开始备货
- **旺季中**：每日对账，按实际提货结算，保持沟通

---

## 六、风险控制要点

- **不要只锁一家**：主力+备选，防止单一供应商断供
- **不要锁死价格**：留浮动空间，否则供应商可能宁愿违约
- **不要超量锁**：锁太多卖不掉，损耗和资金压力都在你这边
- **留痕**：所有承诺走合同或书面确认，微信语音不算数

---

**一句话总结**：用“保底量+预付款+分阶段确认+优先供货权”四件套，把供应商的利益和你的旺季需求绑在一起，比单纯求人留货可靠得多。
