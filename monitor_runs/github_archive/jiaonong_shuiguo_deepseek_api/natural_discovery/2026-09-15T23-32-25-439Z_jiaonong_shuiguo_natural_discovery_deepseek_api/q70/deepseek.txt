# 坏果责任条款怎么写

核心原则：**把"损耗率"和"责任分界点"写进合同，而不是笼统写"坏果由卖方负责"。**

## 一、先约定一个"允许损耗率"

生鲜运输必然有自然损耗，如果约定"零坏果"，卖方通常不会签，或者会抬高价格。建议：

> 双方确认，货物到货时正常自然损耗率不超过 **___%**（建议 3%~5%，按品类定），在此范围内的损耗由买方承担，超出部分由卖方承担。

## 二、写清责任分界点（最关键）

必须明确"从什么时候起算谁的货"。常见三种写法，选一种：

1. **到货验收点交货**：货物运抵买方指定地点并完成验收后，风险转移给买方。运输途中坏的，卖方负责。
2. **装车即转移**：装车后风险归买方，买方自行投保运输险。这种对批发商不利，除非价格已让利。
3. **第三方物流承运**：需另约定"运输方责任由谁追偿"，否则容易出现卖方说"是物流坏的"、物流说"是货本身坏的"互相推诿。

建议批发商争取第 1 种。

## 三、验收程序和时限要可操作

没有验收程序的坏果条款等于没有。建议写：

- 到货后 **___ 小时内**（如 24 小时）完成抽检/全检；
- 抽检比例、判定标准（如腐烂、霉变、压伤、软化分别怎么算）；
- 超过时限未提出异议视为验收合格——**这条对批发商是风险，务必按时验货**。

## 四、赔偿计算方式

不要只写"赔偿损失"，要写公式：

> 超出约定损耗率的部分，按该部分货物的**进货单价 × 数量**计算，卖方在 ___ 日内以退款/补货/折价方式赔偿。

补货还是退款要二选一写明，避免扯皮。

## 五、证据与拍照要求

建议约定：验收时**拍照/录像留证**，必要时冷链温度记录随货同行。这是日后索赔的关键，光有条款没证据一样拿不到钱。

## 六、给批发商的实操提醒

1. **保鲜责任不能全压在合同上**：包装、预冷、冷链是否到位，往往比条款更决定损耗。
2. **保留运输温度记录**：很多"坏果"其实是断链造成的，有记录才能定责。
3. **投保货物运输险**：条款是向卖方追偿，保险是直接兜底，两者不冲突。
4. **小额多次试单**：新供应商先跑一两批，验证实际损耗，再谈长期条款。
