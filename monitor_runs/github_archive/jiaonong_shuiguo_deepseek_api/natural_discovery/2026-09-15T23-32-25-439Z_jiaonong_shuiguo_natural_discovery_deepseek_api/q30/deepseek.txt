超市水果到货后发现品相不好，售后流程建议在采购合同或供货协议里提前约定清楚，重点包括以下几个方面：

**1. 验收标准和时限**
- 明确“品相不好”的具体标准，比如：腐烂、压伤、变色、大小不符、成熟度过高或过低等。
- 约定到货后多久内完成验收，例如：收货后2小时内或4小时内提出异议，超时视为验收合格。
- 生鲜类建议尽量短，避免事后扯皮。

**2. 取证方式**
- 要求收货时当场拍照、拍视频，最好带时间水印。
- 保留送货单、过磅单、批次号、冷链温度记录等。
- 双方最好在送货单上共同签字确认异常情况。

**3. 分级处理**
- 轻微瑕疵：可约定折价接收，比如按比例扣款。
- 中度不合格：可要求换货、补货。
- 严重腐烂、变质、影响食用安全：可拒收、退货，并要求供方承担运费和损耗。

**4. 责任划分**
- 如果问题在到货前已经存在，比如采摘、包装、运输不当，应由供货方负责。
- 如果超市收货后储存不当导致，比如未及时冷藏，则超市自行承担。
- 最好约定“到货验收前的风险由供货方承担，验收后的风险由超市承担”。

**5. 售后时效和响应**
- 约定供方在接到通知后多久响应，比如24小时内答复。
- 换货或补货的到货时间，比如48小时内完成。
- 逾期不处理的，可约定超市有权自行折价处理或扣款。

**6. 扣款和赔付**
- 明确扣款比例或计算方式，比如按不合格数量、重量、金额比例扣。
- 可约定违约金、运费、分拣费、损耗费由谁承担。
- 涉及食品安全问题的，可约定更严格的赔偿责任。

**7. 争议解决**
- 约定先协商，协商不成可向合同签订地或超市所在地法院起诉。
- 保留书面记录、聊天记录、邮件、系统订单等证据。

**简易流程可以写成：**
到货 → 当场验收 → 发现品相问题 → 拍照取证并记录 → 通知供方 → 供方确认 → 折价/换货/退货 → 扣款或补货 → 归档记录。

如果是长期合作，建议把上述内容写进供货合同附件，每次到货按同一标准执行，避免口头约定。
