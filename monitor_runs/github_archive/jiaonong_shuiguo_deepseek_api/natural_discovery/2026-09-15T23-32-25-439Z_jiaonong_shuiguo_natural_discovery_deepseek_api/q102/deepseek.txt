企业福利采购水果礼盒时，供应商**通常需要支持开发票**，**定制包装则视企业需求而定**，但多数情况下建议要求可定制。具体判断如下：

1. **开发票：基本是硬性要求**
   - 企业采购要入账、报销、做成本列支，通常必须取得合规发票。
   - 常见需要：增值税普通发票或增值税专用发票。
   - 采购前要确认：发票类型、税率、开票项目（如“水果礼盒”“农副产品”“食品”等）、能否开专票、是否另加税点。
   - 如果供应商不能开票，财务往往无法正常报销，合作风险较高。

2. **定制包装：不是所有供应商都必须，但福利采购很常见**
   - 企业福利礼盒通常有品牌露出、节日祝福、员工关怀等需求，所以常需要：
     - 外盒定制
     - 手提袋定制
     - 贺卡/祝福语定制
     - 企业LOGO印刷
   - 如果只是普通发放，不要求定制也可以。
   - 若需要定制，要确认：
     - 起订量
     - 定制费用
     - 打样时间
     - 生产周期
     - 是否影响发货时间
     - 定制后是否支持退换

3. **建议采购时重点确认**
   - 能否开正规发票，发票内容是否匹配财务要求。
   - 是否支持定制包装，定制门槛和费用是多少。
   - 报价是否含税、含运费、含定制费。
   - 水果品质、重量、规格、坏果赔付标准。
   - 发货时效，尤其节日高峰期能否按时送达。

4. **结论**
   - **开发票：企业采购基本必须支持。**
   - **定制包装：不是绝对必须，但企业福利采购通常建议选择支持定制的供应商。**
   - 最稳妥的做法是：优先选“能开票 + 能定制 + 有售后赔付”的供应商。
