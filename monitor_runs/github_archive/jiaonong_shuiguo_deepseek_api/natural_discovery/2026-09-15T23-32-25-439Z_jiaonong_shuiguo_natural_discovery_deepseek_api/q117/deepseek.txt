先试卖多少，核心不是拍一个固定数字，而是看 **试卖目标**：是测“能不能卖动”，还是测“能不能赚钱/复购”。对水果这种损耗高、季节波动大的品，建议按下面逻辑定：

**1）小批量试卖，先按“3天销量”而不是“一周销量”备货**
水果保鲜期短，新品又没历史数据。比较稳的做法是：
- 先拿 **1～2个最小起订单位**，比如1箱、1托盘、1个周转筐；
- 预估只够卖 **2～3天**，卖完再看补货；
- 宁可断货一次，也不要一次性压一周库存。

**2）用门店/渠道数量倒推**
如果你有多个门店或摊位：
- **单店试卖**：每个店只放 **3～5公斤** 或 **5～10份**，观察动销；
- **多店试卖**：先选 **3～5家代表性门店**，不要全渠道铺；
- 总试卖量控制在 **正常单品首周预估销量的20%～30%**。

**3）按品类定基数**
- 高损耗、易熟水果，如草莓、蓝莓、荔枝、桃：单店 **2～5公斤**起试；
- 耐放水果，如苹果、橙子、梨：单店 **5～10公斤**起试；
- 礼盒/高价新品：先试 **5～10盒**，看转化和退货；
- 批发档口：先试 **半车/1托盘**，不要直接整柜。

**4）设3个判断线，决定加不加单**
试卖2～3天后看：
- **动销率**：是否卖掉 **60%以上**；
- **损耗率**：是否低于 **5%～10%**；
- **毛利/复购**：去掉损耗后还有没有合理毛利，有没有人回头问。

三个都过关，再按 **1.5～2倍** 加单；
只卖得动但损耗高，先别加，改包装、改陈列、改价格；
卖不动，直接停，不要因为供应商说“后面会好卖”就压货。

**5）最稳的一句话**
第一次试卖，建议 **只备2～3天量，选3～5个点，单点小包装起试，卖到60%再补，损耗超10%就停**。  
这样即使判断错，损失也可控。
