夫妻店第一次找水果供货商，核心不是“先谈最低价”，而是先验证三件事：货稳不稳、损耗能不能控、结账方式能不能承受。常见货里，香蕉、苹果、橙子正好代表三种不同风险，试单方法要分开。

下面给你一套可以直接执行的试单办法。

**一、先定试单原则**

1. **不要一次在一家进全品类**
   第一次合作，最好同一品类只找1家试，最多2家对比。不要今天这家香蕉、明天那家苹果、后天又换，否则出问题分不清是货的问题还是店的问题。

2. **试单量要小，但要有代表性**
   不要只拿一两箱“样品”，那看不出真实到货质量。
   建议按你店里 **1-2天销量** 来试，既能看真实售卖，又不会压太多货。

3. **先问清结算和退换**
   第一次合作优先选：
   - 可现结或短期账期
   - 坏果、次果有明确处理方式
   - 能送货到店
   如果对方一上来就要你大量压货、长期赊账、坏果不认，直接降级。

**二、三类货怎么试**

**1. 香蕉：重点试“熟度”和“到店后还能放几天”**

香蕉最容易亏在熟度上。

试单时问清楚：
- 发货时是几成熟？
- 到你店里大概几天能卖？
- 夏天和冬天熟度是否一样？
- 有没有催熟？催熟后几天到货？

试单建议：
- 第一次拿 **1-2件**，不要多。
- 到店后记录：当天颜色、硬度、第二天变化、第三天是否开始出黑点。
- 如果到店就已经很黄很软，说明路上或催熟过头，不适合夫妻店慢卖。
- 如果太青，顾客当天不买，也会压货。

判断标准：
- 到店时最好是 **微黄带青、能放2-3天逐步转黄**。
- 如果当天就必须降价甩卖，这家香蕉供货商不合格。

**2. 苹果：重点试“规格、口感、碰伤率”**

苹果相对耐放，但坑在规格和口感。

试单时问清楚：
- 是70、75、80还是85果？
- 是净重还是毛重？
- 箱内有没有垫板、分层？
- 是不是冷库果？口感是脆还是粉？

试单建议：
- 第一次拿 **1-2箱**，不要只拿一箱，因为一箱可能看不出整批稳定性。
- 到店后开箱检查：
  - 上层、中层、下层各拿几个看
  - 数碰伤、烂果、小果比例
  - 试吃口感
- 记录：一箱里坏几个、小几个、能卖几个。

判断标准：
- 碰伤和烂果超过 **3%-5%**，就要谈补偿或换货。
- 如果大小严重不匀，顾客挑剩多，实际利润会被吃掉。
- 苹果可以试同一供货商连续拿2次，看第二次是否和第一次一致。

**3. 橙子：重点试“水分、酸度、皮厚、烂果”**

橙子风险在水分流失和烂果。

试单时问清楚：
- 是什么品种？脐橙、血橙、冰糖橙还是普通甜橙？
- 产地和到货时间？
- 是现摘还是库存果？
- 有没有打蜡？

试单建议：
- 第一次拿 **1-2箱**。
- 到店后切开试：
  - 水分够不够
  - 酸不酸
  - 皮厚不厚
  - 有没有干巴、发软、霉烂
- 放2-3天再看：水分是否明显下降，烂果是否增加。

判断标准：
- 切开后干、酸、皮厚，顾客复购差。
- 一箱烂果超过 **5%**，基本要扣款或换货。
- 如果供货商说“橙子有点酸正常”，但你不做榨汁，那就要谨慎。

**三、试单流程建议**

1. **先列需求**
   写清楚：品类、规格、大概数量、送货时间、结算方式、坏果处理。

2. **找2-3家问价**
   不要只问单价，要问：
   - 到店价还是批发价
   - 是否含运费
   - 坏果怎么赔
   - 能否少量混送
   - 下次涨价提前几天说

3. **选1家主试，1家备选**
   主试拿香蕉、苹果、橙子各少量。
   备选先不加微信下单，只保留联系方式。

4. **到店验货**
   当场开箱，拍照，记录：
   - 到货时间
   - 箱重
   - 坏果数
   - 熟度
   - 口感
   - 顾客反馈

5. **卖2-3天再复盘**
   看实际损耗、实际售价、实际利润。
   不要只看进货价低，要看 **卖完能赚多少**。

6. **决定是否续单**
   如果损耗可控、口感稳定、送货准时，再逐步加量。
   如果第一次就坏果多、熟度不对、结账麻烦，直接换。

**四、夫妻店特别要注意的几点**

- **别贪便宜拿尾货**
  尾货价格低，但损耗高，夫妻店人手少，处理坏果很耗时间。

- **别一次压太多**
  香蕉、橙子都不算特别耐放，第一次试单量控制在1-2天销量。

- **账期要谨慎**
  如果供货商主动给很长账期，先想清楚自己现金流。夫妻店最怕账期变成习惯，最后对不上账。

- **固定一家不如固定标准**
  谁家货稳、损耗低、结账清楚，就逐步固定。不要因为熟人介绍就放松验货。

**五、最简单的一句话建议**

第一次试单：
**香蕉试熟度，苹果试规格和碰伤，橙子试水分和烂果。**
每家先拿1-2天销量，到店开箱记录，卖2-3天算实际损耗，再决定要不要长期合作。
