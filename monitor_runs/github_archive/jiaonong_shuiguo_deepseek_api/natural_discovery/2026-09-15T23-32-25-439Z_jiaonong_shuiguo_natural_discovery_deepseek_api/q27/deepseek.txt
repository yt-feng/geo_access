判断超市采购的苹果和橙子大小规格是否适合门店销售，核心不是“越大越好”，而是看**目标客群、陈列方式、价格带、损耗和周转**。可以按下面几个维度做可执行判断。

## 1. 先定门店销售场景

不同门店适合的规格不同：

| 门店类型 | 更适合的规格方向 | 原因 |
|---|---|---|
| 社区生鲜店 | 中果、中大果 | 家庭日常购买，单价敏感，走量快 |
| 精品超市 | 大果、特大果、礼盒果 | 客单价高，看外观和稀缺性 |
| 便利店/小超市 | 中果、小果、便携装 | 即买即吃，单次消费低 |
| 水果专营店 | 分级齐全 | 可做引流款、利润款、礼盒款 |
| 团购/批发渠道 | 统货或中大果 | 看重性价比和稳定供应 |

所以先问：**这批苹果橙子准备卖给谁、怎么卖、卖多少钱？**

## 2. 苹果怎么判断大小规格

苹果常见按横径分级，采购时看“70、75、80、85、90”等规格，单位通常是毫米。

### 适合门店销售的判断标准

- **社区店/普通超市日常散卖**
  - 苹果：75–85mm 比较稳。
  - 75mm 以下偏小，适合低价引流或家庭装。
  - 85mm 以上偏大，适合精品区、礼盒或高客单。
- **精品超市/礼盒**
  - 80–90mm 更合适，果形端正、颜色均匀。
  - 90mm 以上可做高端礼盒，但要控制采购成本。
- **便利店/小包装**
  - 70–80mm 更合适，单果重量适中，方便按个卖。

### 现场快速判断

1. **看横径**：用卡尺或分级圈抽查，不要只看样品。
2. **看均匀度**：一箱里大小差异太大，陈列难看，也难定价。
3. **看单果重**：
   - 70mm 左右：约 150–180g
   - 75mm 左右：约 180–220g
   - 80mm 左右：约 220–260g
   - 85mm 以上：约 260g 以上
4. **看果形和表皮**：大小达标但畸形、锈多、碰伤多，也不适合正常排面。
5. **看硬度与新鲜度**：苹果规格再合适，发绵、失水就不适合门店销售。

## 3. 橙子怎么判断大小规格

橙子常见按横径分级，如 60、65、70、75、80mm，也有按“几号果”或每箱个数分。

### 适合门店销售的判断标准

- **普通超市/社区店散卖**
  - 橙子：65–75mm 比较合适。
  - 太小：剥皮难、卖相弱，适合榨汁或低价。
  - 太大：单价高，部分顾客觉得不划算。
- **精品超市/礼盒**
  - 70–80mm，果面干净、颜色橙红、大小均匀。
- **榨汁用途**
  - 60–70mm 也可，重点看出汁率、酸甜比和价格。
- **按个销售**
  - 选 70–75mm 左右，单果约 180–250g，顾客容易接受。

### 现场快速判断

1. **抽查横径**：一箱抽上中下三层，不要只拿最上面。
2. **看均匀度**：同批次大小差最好控制在 5mm 内。
3. **看单果重**：
   - 65mm：约 150–180g
   - 70mm：约 180–220g
   - 75mm：约 220–260g
   - 80mm：约 260g 以上
4. **看皮厚和可食率**：皮太厚、空壳感强，不适合主推。
5. **看新鲜度**：果蒂绿、果皮紧实、有弹性、无软烂。
6. **看糖酸比**：门店销售不能只看大小，太酸会影响复购。

## 4. 采购时最实用的判断流程

### 第一步：定价格带
先确定门店准备卖多少钱一斤或一个。

- 如果计划卖 3.99–5.99 元/斤，选中小果、统货更稳。
- 如果计划卖 6.99–9.99 元/斤，选中大果、均匀度好的。
- 如果计划做 19.9–39.9 元礼盒，选大果、精品果。

### 第二步：看目标顾客
- 家庭主妇/中老年客群：更看重性价比，中果好卖。
- 年轻白领：更看重方便、颜值，中大果和小包装好卖。
- 送礼客群：大果、礼盒果更好卖。

### 第三步：算损耗和毛利
规格不合适会带来隐性损耗：

- 太小：顾客挑剩多，尾货多。
- 太大：单价高，动销慢，易失水。
- 不均匀：顾客翻捡严重，碰伤增加。
- 过熟：排面期短，损耗高。

建议采购前算：

**可售毛利 = 预计售价 × 可售率 - 采购成本 - 损耗 - 包装 - 人工**

如果大果采购价明显高，但售价上不去，就不适合。

### 第四步：做小批量试销
不要一次压太多。先采购 1–2 箱或小批量：

- 观察 1–3 天动销。
- 看顾客是否翻捡、嫌弃大小。
- 看尾货比例。
- 看是否回头购买。

## 5. 简单采购标准

### 苹果
- 普通门店主推：**75–85mm，大小均匀，单果 180–260g。**
- 引流款：**70–75mm，低价走量。**
- 利润款/礼盒：**85mm 以上，果形端正。**

### 橙子
- 普通门店主推：**65–75mm，单果 180–250g。**
- 精品/礼盒：**70–80mm，颜色好、均匀。**
- 榨汁款：**60–70mm，看出汁率和价格。**

## 6. 一句话判断

**能稳定卖出去、顾客不嫌小也不嫌贵、陈列好看、损耗可控的规格，才是适合门店销售的规格。**

采购时不要只问“这是几号果”，要同时确认：**横径、单果重、均匀度、成熟度、损耗率、采购价和门店计划售价。**
