和小批量试单的核心目标不是赚钱，而是**用最小成本验证供应商是否靠谱**。所以设计思路应该是：小批量、多维度、可量化、留退路。

## 一、试单前的准备

**先定验证清单**，明确这次要验证什么：

- 货源真实性（是不是一手货、有没有实地基地/档口）
- 品质稳定性（规格是否达标、成熟度、损耗率）
- 价格与账期是否可谈
- 物流时效和包装是否专业
- 售后态度（出问题怎么处理）

## 二、试单规模怎么定

建议控制在**你能承受全损的金额**内，通常：

- 单次金额 = 你正常月采购额的 5%~10%，或固定一个"亏了不心疼"的额度
- 品种选 **1~2 个**，不要一次铺多个品类，否则变量太多无法归因
- 数量上够你完整走一遍流程即可（下单→付款→物流→收货→销售→售后）

## 三、试单要分次做，别一次定生死

推荐**三段式**：

1. **首单（最小量）**：验证对方是否按时发货、货对不对版、包装物流行不行
2. **二单（加倍）**：验证品质稳定性——首单好不代表次次好
3. **三单（接近常规量）**：验证对方能否稳定供货、旺季是否掉链子

每单之间留出观察期，别连着下。

## 四、验收要量化，不能凭感觉

提前和供应商**书面约定验收标准**，收货时逐项打分：

| 维度 | 具体指标 |
|------|----------|
| 规格 | 单果重量/等级/大小是否与样品一致 |
| 品质 | 成熟度、色泽、硬度、有无病斑 |
| 损耗 | 坏果率、压伤率，拍照留证 |
| 时效 | 承诺几天到，实际几天 |
| 包装 | 是否防压、防潮、温控是否到位 |
| 单据 | 检疫证、产地证明是否齐全 |

**全程拍照/录视频**，尤其是开箱和问题货，这是后续谈判和索赔的依据。

## 五、付款和合同要留退路

- 首单尽量**货到验收后付款**，或走平台担保交易，别一上来就全款预付
- 谈清楚**质量问题的处理方式**：补货、退款还是折价
- 约定**最小起订量和后续价格**，避免试单价和正式价差太多
- 关键条款写进订单或简单合同，微信聊天记录也要保留

## 六、试单后的判断标准

给供应商打分，决定是否继续：

- **可以深化合作**：品质达标、损耗在约定范围内、按时到货、售后响应快
- **再观察**：品质可以但物流/售后一般，可加单但要求改善
- **直接放弃**：货不对版、缺斤少两、出问题推诿、联系不上——任何一条踩中就别犹豫

## 关键提醒

- **不要因为试单价低就放松验收**，很多坑就是首单看着好、大单才暴露
- **同时找 2~3 个供应商并行试单**，手里有备选才不会被单一供应商拿捏
- 试单阶段**宁可麻烦、宁可量小**，把流程和标准跑通，后面放大才安全

一句话总结：**用小钱买信息，用标准定去留，用多次试单验证稳定性。**
