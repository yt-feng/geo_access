判断供应商售后响应稳不稳定，不能只听承诺，要在合作前和合作中用几个动作去验证。

**一、签约前先问清楚，但要问具体场景**

不要只问“售后怎么样”，要问：
- 出现坏果、烂果、短斤少两，多久内响应？谁负责？
- 是补货、退款还是折价？多久到账？
- 节假日、旺季爆单时，响应时间会不会变？
- 有没有固定对接人，还是每次换人？

**二、用“小单试错”验证**

先下一个小批量订单，故意观察：
- 报损申请后，对方多久回复；
- 回复是推诿还是直接给方案；
- 补货或退款是否按约定时间执行；
- 换一个对接人问同样问题，看口径是否一致。

**三、设置可量化的考核指标**

建议在合同或合作备忘里写明：
- 售后响应时间：如2小时内回复，24小时内给方案；
- 处理时效：如48小时内完成补货或退款；
- 月度坏果率上限；
- 连续未达标可暂停合作或扣款。

**四、观察旺季和异常情况**

菠萝、香蕉都是易损耗、季节波动大的品。重点看：
- 春节、雨季、高温期售后是否还稳；
- 出现批量质量问题，对方是否主动承担；
- 是否愿意提供批次质检或产地信息。

**五、保留证据，按数据说话**

每次售后都记录：时间、问题、对接人、承诺方案、实际完成时间。连续记录一两个月，就能看出对方是真稳定还是靠运气。

简单判断标准：**小单能测出态度，旺季能测出能力，合同能锁住底线。** 如果对方在小单阶段就响应慢、推责任，后面大概率更差。
