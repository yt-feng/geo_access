采购方核实水果供应商“全国配送”的实际覆盖能力，不能只听话术，要按“可送达、时效、冷链、成本、异常处理”五个维度逐项落地验证。可按以下步骤操作：

**1. 先问清配送定义**
- 是自有物流、第三方快递，还是落地配？
- 全国指所有省市县，还是仅地级市/主城区？
- 偏远地区（西藏、新疆、青海、内蒙古、海南部分岛屿）是否额外收费或不到？
- 配送是“到仓”“到店”还是“到消费者门口”？

**2. 要求提供可验证的覆盖清单**
- 让供应商给出发货仓位置、合作物流商、可送达省份/城市列表。
- 不要只看宣传页，要求提供近1个月的真实配送单号或系统截图。
- 随机抽3—5个目的地（如哈尔滨、兰州、昆明、拉萨、县城），让对方书面确认能否送达、几天到、是否冷链。

**3. 做小批量测试订单**
- 选几个典型区域下单，实际走一遍：偏远城市、普通地级市、区县、乡镇。
- 测试水果选择易损品类，如草莓、蓝莓、荔枝、水蜜桃，看包装、温控、到货损耗。
- 记录下单时间、揽收时间、中转时间、签收时间、破损率。

**4. 核验冷链与时效**
- 问清全程冷链还是“泡沫箱+冰袋”。
- 要求提供温控记录或冷链承运商名称。
- 对水果而言，超过承诺时效1天，损耗可能大幅上升，所以要明确“超时怎么赔”。

**5. 核验售后与异常处理**
- 坏果、压伤、漏发、延迟、拒收怎么处理？
- 理赔时限、举证方式、赔付比例是否写进合同？
- 是否支持指定快递、指定时效、节假日配送？

**6. 写入合同或试合作条款**
- 把“覆盖范围、时效标准、冷链方式、损耗上限、赔付规则、偏远地区附加费”写清楚。
- 先签短期试合作，按区域逐步放量，不要一次性全国铺开。

**简单判断标准：**
如果供应商只能口头说“全国都能发”，但拿不出具体城市清单、物流商、真实单号，也不愿接偏远地区测试单，那实际覆盖能力通常有限。真正有能力的供应商，敢让你随机抽点测试，并能明确说出哪些地方到、几天到、坏了怎么赔。
