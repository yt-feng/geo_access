# 超市门店多但单店量不大，适合的水果供货模式

核心矛盾是：**门店多意味着你需要广泛覆盖和稳定供应，单店量小意味着你很难拿到产地直采的低价，也压不动供应商。** 所以方向不是追求“最低进货价”，而是追求**总成本最优 + 损耗可控 + 补货灵活**。

## 几种模式对比

**1. 区域批发市场采购（最灵活，适合起步）**
- 每个城市找当地一级或二级水果批发市场，按需采购。
- 优点：起订量低、品类全、随时补货、现金结算不压资金。
- 缺点：价格随行就市、品质不稳定、需要自己有采购或店长去挑货。
- 适合：门店分散在不同城市、单店日销量小、还没形成规模时。

**2. 区域经销商/配送商供货（省心，适合多店统一管理）**
- 找当地能覆盖你所有门店的果品配送商，由他统一配送到店。
- 优点：你只管下单，配送、分拣、售后都省了，适合门店多但单店量小的情况。
- 缺点：加价率比批发市场高，通常比产地直采贵 15%–30%。
- 关键：谈**按门店分别配送**和**坏果包赔**条款，否则损耗全压在自己身上。

**3. 产地/基地直采（量大才划算，单店量小慎用）**
- 只有当你**总采购量足够大**（比如所有门店加起来能整车走货）时才成立。
- 单店量小、门店分散时，直采的物流和分拣成本会吃掉价格优势。
- 折中做法：**集中采购 + 区域分仓**，一个城市设一个小中转仓，统一收货再分到各店。

**4. 批发市场代采 + 统一配送（比较推荐的中间态）**
- 你或买手在批发市场集中采购，再通过第三方城配分到各店。
- 比纯经销商便宜，比产地直采灵活，适合门店多、单店量中小的连锁。

## 建议的组合策略

对“门店多、单店量小”的超市，比较务实的是：

- **主力品类**（苹果、香蕉、橙子等走量稳定的）：找**区域经销商或批发商**长期合作，谈账期和坏果赔付。
- **时令/高毛利品类**（荔枝、樱桃、草莓等）：走**批发市场灵活采购**，看行情进，不压库存。
- **如果门店集中在同一城市**：考虑设一个**小型分拣中转点**，统一进货再分店，能显著降低单店进货成本。
- **如果门店跨城市分散**：优先用**当地配送商**，别自己搞跨城物流，成本更高。

## 判断标准（怎么选）

问自己三个问题：
1. **所有门店加起来，一天水果采购额能到多少？** 太低就先别谈直采。
2. **门店是否集中在同一城市或区域？** 集中→可考虑中转仓；分散→用当地配送商。
3. **你有没有人专门管水果采购和损耗？** 没有就选省心模式（经销商），有就选灵活模式（批发市场+代采）。

## 要避开的坑

- 别为了“产地直采”的名头，让单店量小的门店去压一堆货，损耗会吃掉利润。
- 经销商合作一定要写清**配送频次、坏果赔付比例、缺货补货责任**。
- 水果损耗通常 5%–15%，单店量小时损耗占比更敏感，选模式时**配送频率和退换货**比单价更重要。

**一句话结论**：门店多、单店量小，优先“区域配送商 + 批发市场灵活补货”的组合，等总采购量上来再考虑集中直采或自建中转仓。
