水果店减少香蕉放坏，采购时可以按“**到货熟度 + 到货时间 + 批次节奏**”来提要求，不要只说“要生一点/熟一点”。

**1. 到货熟度怎么要求**
- 如果预计 **2～3天内卖完**：可以要到货 **3～4号色**，即果皮开始转黄、基本无青肩，适合直接上架。
- 如果预计 **4～6天内卖完**：建议要到货 **2～3号色**，果身硬、青黄相间，先放仓库或后场，卖多少催多少。
- 如果天气热、门店客流慢：尽量要 **2号色左右**，偏青硬，别要已经出梅花点或果柄发黑的。
- 如果做促销、走量快：可以要 **4～5号色**，到店就能卖，但必须配合快进快出。

可以用香蕉行业常用的颜色卡沟通：1号全青，2号青转黄，3号黄带青，4号黄多青少，5号全黄，6号起糖斑，7号过熟。采购时直接说“要2.5～3号色，不要5号以上”。

**2. 到货时间怎么要求**
- 最好要求 **早上到货**，让门店当天有完整时间分拣、上架、催熟或冷藏。
- 避开 **傍晚到货后直接过夜**，尤其夏天，闷在仓库或车厢里一晚，第二天损耗会明显增加。
- 如果供应商从批发市场发货，要求 **冷链或通风车运输**，不要暴晒、不要和乙烯释放量大的水果如苹果、梨长时间混放。
- 到货后立即开箱散热，不要整箱闷着。香蕉对温度敏感，**13～15℃左右较适合存放**，低于10℃容易冻伤发黑，高于25℃又熟得快。

**3. 采购批次怎么提**
- 不要一次进太多同一熟度。可以要求供应商 **同一批里搭配2号色和4号色**，或者分两次到货。
- 例如：周一要2.5号色一批，周三要4号色一批，门店轮流上架，减少集中成熟。
- 如果供应商只能给一个熟度，那就按“**预计售卖天数倒推熟度**”：卖得慢要青，卖得快可黄。

**4. 到货验收标准**
到货时重点看：
- 果柄是否发黑、发霉；
- 果皮有没有压伤、裂口、水烂；
- 青肩是否均匀，有没有“青一块黄一块”的催熟不匀；
- 箱内有没有明显热气、水汽；
- 抽检几根，手感是否过硬或过软。

不合格就当场拍照、记录、拒收或要求补损。采购要求最好写进订单：**“到货2.5～3号色，上午到店，无压伤、无发霉、无冻伤，超熟拒收。”** 这样最可执行。
