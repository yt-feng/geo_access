茶饮店用香蕉，采购熟度的核心原则是：**按用途分熟度采购，不要只买一种熟度。**

**1. 做冰沙、奶昔、香蕉牛奶类饮品**
- 最佳熟度：**7～8分熟**，表皮黄色、带少量青肩，捏起来微软但有弹性。
- 原因：此时甜度够、香气出来，但果肉还比较紧，打冰沙不会太稀，香蕉味明显。
- 太生：涩、粉、香气弱。
- 太熟：打出来容易发黑、发酸、口感糊。

**2. 做香蕉果酱、香蕉泥、甜品夹心**
- 最佳熟度：**9～10分熟**，表皮全黄、出现少量黑点。
- 原因：淀粉转糖充分，甜度和香气最高，压泥顺滑，适合做酱和夹心。
- 注意：黑点过多、果肉发软出水就不要再用于果酱，容易发酵变味。

**3. 做装饰切片、香蕉块、烤香蕉**
- 最佳熟度：**7分熟左右**，黄皮、青肩少、果肉硬挺。
- 原因：切片不散，烤后形状还在。
- 太熟的香蕉切片容易烂，出品不整齐。

**4. 采购与库存控制建议**
- **别一次只进一个熟度**：按未来3～5天用量，分“生一点”和“熟一点”两批进。
- **生蕉催熟**：7分熟以下可常温放置，和苹果/香蕉同放可加速催熟；不要直接冷藏，冷藏会黑皮、断熟。
- **熟蕉管理**：到9分熟后，如果当天用不完，及时去皮、切段、冷冻，做冰沙/奶昔仍可用；不要常温堆压。
- **每天挑一遍**：把黑点多的挑出来优先做果酱或冷冻，避免一根烂影响一箱。
- **按天气调整**：夏天熟得快，采购熟度要偏生；冬天可适当偏熟。
- **按销量定采购量**：香蕉损耗高，建议按“日销量×1.5～2天”备货，不要按一周囤。

**简单判断标准：**
- 青肩明显、捏不动：太生，放2～3天。
- 全黄、微软有弹性：做饮品、切片合适。
- 全黄带黑点、很软：做果酱、香蕉泥。
- 大面积发黑、流水、酒味：报废，不要用。
