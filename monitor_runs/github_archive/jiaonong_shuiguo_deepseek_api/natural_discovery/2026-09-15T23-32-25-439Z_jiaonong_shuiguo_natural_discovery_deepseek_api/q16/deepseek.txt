要看你现在缺的是“价格优势”还是“稳定省心”，建议分开处理：

**1. 香蕉：优先选稳定供应商**
- 香蕉是高频、易损耗商品，成熟度、到货时间、催熟控制很关键。
- 本地批发可能便宜，但批次质量不稳定，今天黄明天青，损耗会吃掉利润。
- 如果能找到本地一级批发商，且能稳定隔天送货，也可以作为“稳定供应商”来用。
- 建议条件：能约定成熟度、固定送货频次、坏果可换/补、价格随行就市但有账期或返利。

**2. 苹果：可以本地批发 + 稳定供应商双轨**
- 苹果相对耐存，适合比价。
- 本地批发适合试销、补货、做促销款；稳定供应商适合做主力常备款。
- 如果本地批发市场离得近，苹果可以每周去1—2次选货，利润空间通常比全走供应商大。
- 但如果你没有精力天天挑货，苹果也建议交给稳定供应商，要求分等级报价。

**3. 更实际的做法**
- **先小批量试**：香蕉找1家稳定供应商，苹果同时从本地批发和供应商各进一批。
- **算三笔账**：到货价、损耗率、实际毛利。不要只看批发价低。
- **看售后**：坏果能不能换、缺货能不能补、送货及不及时，比单价差几毛更重要。
- **定主力+补充**：稳定供应商做日常主力，本地批发做临时补货和促销引流。

**结论**：  
香蕉优先稳定供应商；苹果可以本地批发和稳定供应商并行，谁的综合成本低、损耗少，就逐步加大谁的比例。社区超市最怕的不是进价高一点，而是断货、烂货和没人送。
