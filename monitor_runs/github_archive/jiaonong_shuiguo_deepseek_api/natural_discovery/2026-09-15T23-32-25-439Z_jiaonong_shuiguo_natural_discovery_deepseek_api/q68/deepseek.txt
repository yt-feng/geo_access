判断供应商能不能按时到车，核心不是听他“保证”，而是看**他有没有可核验的排车和发车证据**。可以按下面几步做。

**1. 先问清楚“到车”定义**
- 是到产地装货，还是到你市场档口？
- 是毛车到，还是装好货发车？
- 几点到、迟到多久算违约？
定义不清，后面扯皮没用。

**2. 要可核验的排车证据**
让供应商提供：
- 车牌号、司机电话
- 当前车辆位置或装货地
- 预计装货时间、发车时间
- 如果已发车，要高速通行记录、定位截图、装车视频
只有“已经安排了”“在路上”这种话，不能算证据。

**3. 看他的历史履约记录**
重点问：
- 最近3车香蕉分别哪天到、迟了多久
- 有没有临时换车、换司机、换产地
- 下雨、堵车、查超时怎么处理
如果你是新客户，可以要求先做一车小单或短途单试履约。

**4. 合同里写死时间和责任**
建议写明：
- 最晚到车时间
- 迟到按小时或按车扣款
- 因迟到导致烂货、掉价、档口空置谁承担
- 司机临时加价、放空怎么赔
没有违约成本的“保证”，基本不可信。

**5. 到车前做动态跟踪**
- 发车前确认一次
- 装完货确认一次
- 上高速后每4—6小时确认一次
- 距离你还有2—3小时再确认一次
如果中间出现“手机没电”“司机不接”“定位没有”，就要按高风险处理。

**6. 用几个硬信号判断风险**
高风险信号：
- 只给微信语音，不给车牌和司机电话
- 车牌反复变
- 装货时间一拖再拖
- 报价明显低于市场
- 要求你先打全款
- 说“到了再说”“肯定没问题”

低风险信号：
- 车牌、司机、定位、装车视频都能对上
- 愿意把迟到责任写进合同
- 有稳定合作的下游档口或长期司机
- 主动同步路况和到车时间

**7. 最实用的做法**
- 新供应商：先小批量试一车
- 老供应商：也要每车确认车牌和司机
- 重要档口：同时备一个备用供应商
- 款尽量分阶段付，不要全款押在一个不确定的车上

一句话：**能按时到车的供应商，通常能给你车牌、司机、定位、装车证据，并愿意承担迟到责任；给不了这些的，不要按“能按时到”来安排销售。**
