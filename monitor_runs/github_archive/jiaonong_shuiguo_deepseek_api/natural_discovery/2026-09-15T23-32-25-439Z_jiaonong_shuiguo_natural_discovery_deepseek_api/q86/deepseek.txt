生鲜平台做一件代发水果，供应商的仓配能力至少要能支撑“单件发货、时效稳定、损耗可控、售后可追溯”这四点。重点看以下几类能力：

**1. 仓储与分拣能力**
- **多温区仓储**：水果并非都常温，需具备常温、冷藏甚至部分冷冻能力，且能按SKU分区管理。
- **专业水果存储条件**：不同水果对温度、湿度、通风要求不同，如香蕉、芒果需催熟/温控，浆果类需冷链，柑橘类相对耐存。
- **单件分拣能力**：一件代发是“按订单拣货打包”，不是整箱批发。供应商需有波次拣货、称重、打包、贴单系统。
- **库存准确率**：平台订单直接下发，库存不准会导致超卖、缺货、延迟发货。一般要求库存准确率≥98%甚至更高。

**2. 包装与预处理能力**
- **水果分级与筛选**：按大小、糖度、外观分级，避免“图片好看、到手货差”。
- **预冷与保鲜处理**：采摘后快速预冷，能显著降低损耗，尤其是叶菜、浆果、荔枝等。
- **防震防压包装**：水果易碰伤，需有网套、蛋托、气柱袋、珍珠棉等适配方案。
- **冷链包装能力**：泡沫箱+冰袋、保温袋、干冰等，根据品类和时效选择。

**3. 订单履约与发货能力**
- **系统对接能力**：能对接平台ERP/OMS/WMS，支持订单自动抓取、面单打印、发货回传。
- **日单量弹性**：大促或爆单时能否日发几千到几万单，且不严重延迟。
- **发货时效**：通常要求16:00前订单当日发出，或24小时内揽收，具体看平台承诺。
- **快递资源**：有稳定合作的快递，尤其能发顺丰、京东、中通等，且生鲜线路覆盖到位。

**4. 配送与时效保障**
- **产地直发或区域仓发**：离消费者越近，时效和损耗越好。跨省远距离发水果，风险明显更高。
- **冷链干线+落地配**：部分品类需冷链运输，不能全程常温。
- **时效承诺**：如“48小时达”“72小时达”，供应商要能给出可兑现的覆盖范围。
- **异常处理**：航班延误、天气、疫情等导致延迟时，有备选线路和主动通知机制。

**5. 品控与售后能力**
- **到货损耗率**：行业里生鲜一件代发损耗通常要求控制在5%以内，部分高客单水果要求更低。
- **售后响应**：坏果、烂果、缺斤少两能快速赔付或补发，且能提供照片/视频凭证。
- **批次追溯**：能追溯到采摘批次、加工时间、发货仓，便于平台处理投诉和复盘。
- **质检报告**：农残检测、产地证明等，尤其是平台入驻和商超渠道。

**6. 数据与协同能力**
- **库存同步**：实时或准实时同步，避免超卖。
- **发货数据回传**：快递单号、发货时间、物流轨迹及时回传平台。
- **售后数据反馈**：能按SKU、地区、快递统计损耗和投诉，帮助平台优化选品和路由。

**简单判断标准：**
如果供应商只能做到“有货、能发快递”，但没有温控、预冷、分级、系统对接和售后赔付能力，就不适合做生鲜一件代发。至少应具备：**多温区仓储 + 单件分拣打包 + 系统对接 + 稳定快递 + 损耗赔付机制**。

**平台筛选时建议重点问：**
1. 哪些品类能做一件代发？日发单量上限多少？
2. 发货仓在哪里？到你主要消费者区域时效多久？
3. 损耗率多少？坏果怎么赔？
4. 能否对接平台系统？发货回传是否自动？
5. 大促期间会不会爆仓、延迟发货？
