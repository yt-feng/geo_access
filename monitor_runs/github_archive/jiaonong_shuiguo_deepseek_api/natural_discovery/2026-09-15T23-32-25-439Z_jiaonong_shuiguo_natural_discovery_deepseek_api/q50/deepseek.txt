结论先行：**开茶饮店买菠萝原料，出汁率通常比甜度更重要，但不能只看一个指标——要按“有效可交付成本”来判断。**

更实用地说，应该看这三个指标：

1. **出汁率**：决定你每公斤原料能做出多少杯里的菠萝汁/果肉感。
2. **甜度/糖酸比**：决定风味是否够稳定，能不能少加糖还保持好喝。
3. **损耗率**：去皮、去芯、修果、氧化、坏果扔掉的量，实际比标称甜度更影响成本。

---

## 为什么出汁率更关键？

茶饮店买菠萝，最终不是直接卖鲜果，而是拿来做：

- 菠萝果茶
- 菠萝气泡饮
- 菠萝果肉果酱
- 搭配百香果、柠檬、绿茶等

这些产品里，菠萝主要承担的是：

- 出汁量
- 果肉纤维感
- 香气
- 酸甜平衡

如果出汁率低：

- 每杯要用更多原料
- 出品速度慢
- 果肉和汁水不稳定
- 成本会明显上升

甜度不够，很多情况下还能通过：

- 加糖浆
- 调整糖酸比
- 搭配其他水果
- 改变配方比例

来补救。

但出汁率低、果肉少、纤维差，往往很难靠配方完全补回来。

---

## 但只看出汁率也不行

如果菠萝很出汁，但：

- 酸涩重
- 香气弱
- 甜度太低
- 纤维太粗
- 氧化快
- 批次不稳定

那做出来的茶饮会很难标准化。

所以更合理的判断标准是：

> **在可接受的甜酸比和香气下，选出汁率高、损耗低、批次稳定的原料。**

---

## 茶饮店采购时建议怎么选？

### 1. 先看用途

| 用途 | 更重要的指标 |
|---|---|
| 做鲜果茶、果肉茶 | 出汁率 + 果肉感 + 香气 |
| 做浓缩汁、糖浆基底 | 甜度、糖酸比、风味稳定性 |
| 做菠萝果酱 | 果胶、纤维、甜酸比 |
| 做装饰果片 | 外形、成熟度、切片损耗 |
| 做外卖爆款 | 出汁率、稳定性、操作效率 |

如果做的是**鲜菠萝果茶**，出汁率和果肉感优先级很高。  
如果做的是**调味型菠萝饮**，甜度和风味稳定性更重要。

---

### 2. 算“每杯有效成本”

不要只问：

- 一斤多少钱？
- 甜不甜？

要算：

> **每杯可用菠萝汁/果肉成本 = 采购单价 ÷ 实际可用出汁量**

举例：

- A 菠萝：10 元/斤，出汁率 50%，每斤可用汁 0.5 斤，有效成本 20 元/斤汁
- B 菠萝：12 元/斤，出汁率 70%，每斤可用汁 0.7 斤，有效成本约 17.1 元/斤汁

虽然 B 更贵，但有效成本更低。

这就是为什么出汁率经常比单纯甜度更重要。

---

### 3. 现场测试方法

采购前建议做小测试：

- 同一批次取 3～5 个菠萝
- 去皮去芯后称重
- 榨汁后称重
- 记录出汁率
- 测糖度，比如用折光仪看 Brix
- 测酸度或至少试喝判断糖酸比
- 放置 30～60 分钟看氧化、变色、分层
- 和茶底搭配试喝，不只看纯果

重点不是“这个菠萝甜不甜”，而是：

> **和茶底搭配后，能不能稳定做出好喝的菠萝茶饮？**

---

## 最终建议

如果你只能二选一：

- **做鲜果茶、果肉茶、追求果感**：优先选 **出汁率高** 的。
- **做调味饮、浓缩基底、追求稳定甜感**：优先选 **甜度和糖酸比稳定** 的。
- **实际经营**：选 **出汁率高 + 糖酸比稳定 + 损耗低** 的，不要只盯甜度。

一句话：

> **甜度决定好不好喝，出汁率决定赚不赚钱；茶饮店采购菠萝，先保证出汁率和稳定性，再要求甜度。**
