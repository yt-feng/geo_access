# 水果采购：现金结算 vs 月结账期

**没有绝对安全的选项，两种结算方式的风险类型完全不同。**

---

## 现金结算的风险

| 风险 | 说明 |
|------|------|
| **资金占用大** | 每次进货都要立刻掏钱，现金流压力集中在采购环节，遇到淡季或突发支出容易周转不开 |
| **无追溯凭据** | 如果只给现金不索要收据/送货单，一旦出现质量纠纷（烂果、缺斤少两），维权几乎无从下手 |
| **被"杀熟"风险** | 供应商知道你付现快，可能报高价或把尾货优先塞给你，因为你不占账期、议价筹码反而弱 |
| **假钞/找零纠纷** | 大额现金交易中的操作风险，虽然概率低但确实存在 |
| **安全风险** | 携带大量现金上门采购，人身和资金安全有隐患 |

**核心问题：现金结算把风险从"信用"转移到"当下资金"上。**

---

## 月结账期的风险

| 风险 | 说明 |
|------|------|
| **信用依赖** | 你完全依赖供应商的信任，一旦对方收紧账期或要求提前结清，你措手不及 |
| **隐性涨价** | 月结价格通常比现结高 3%–8%（供应商把资金成本转嫁给你），你以为省了现金，其实多付了钱 |
| **对账困难** | 一个月累积多笔送货，如果没有每笔签字确认，月底对方说多少就是多少 |
| **质量被动** | 货已经用了/卖了，发现问题时账已挂上，退换货谈判处于劣势 |
| **断供风险** | 一旦你延迟付款一次，供应商可能直接停供，水果是日配品类，断一天就影响生意 |
| **关系绑架** | "都合作这么久了"容易让你不好意思拒绝不合理的供货质量或价格 |

**核心问题：月结把风险从"当下资金"转移到"信用关系和隐性成本"上。**

---

## 实操建议

1. **混合策略最优**：核心大单品走月结（锁价格、锁供应），时令/试新品走现结（灵活、可挑货）。
2. **月结必须做到**：每笔送货单当场签字确认数量+单价+质量，月底对账有据可依。
3. **现结必须做到**：索要收据或转账备注品名数量，保留至少一个月。
4. **砍价逻辑**：如果你能稳定现结，明确要求"现结价"，通常能比月结价低 5% 左右。
5. **底线原则**：无论哪种方式，**不要把所有采购押在一个供应商身上**，至少保留一个备选渠道。

---

**一句话总结：现金结算怕的是"钱紧+没凭据"，月结怕的是"隐性涨价+被断供"。小商家最稳的做法是——现结拿价格，月结拿稳定，两条腿走路。**
