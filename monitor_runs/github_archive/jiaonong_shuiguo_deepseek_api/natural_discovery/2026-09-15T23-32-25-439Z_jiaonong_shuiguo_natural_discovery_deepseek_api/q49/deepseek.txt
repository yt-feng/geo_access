旺季菠萝用量突然变大，临时补货最怕两件事：一是供应商说“没货”或临时涨价，二是品质和平时不一致。要解决这个问题，核心不是“临时求货”，而是提前用**框架协议 + 弹性补货机制**把规则定好。

建议按下面几步和供应商约定：

**1. 先签一份年度框架协议，约定“基础量 + 弹性量”**
- 基础量：按平时月均用量锁定，供应商必须保证。
- 弹性量：约定一个上浮比例，比如旺季可临时增加 **30%—50%**，供应商需优先保障。
- 超出弹性量的部分，约定“尽力协调”而非强制，避免对方直接拒谈。

**2. 约定临时补货的触发和提前期**
- 触发条件：比如单周用量超过基础量 20%，或仓库库存低于 X 天用量。
- 提前期：临时补货至少提前 **3—5 天**下单；紧急补货提前 **24—48 小时**，但价格或运费可能上浮。
- 补货频率：明确每周可补几次、每次最小起订量是多少。

**3. 锁价或约定价格调整规则**
- 旺季最怕坐地起价。可以约定：
  - 基础量内价格锁定；
  - 弹性量内价格按约定上浮上限，比如不超过市场均价的 **5%—10%**；
  - 超出弹性量部分随行就市，但需提前书面确认。
- 如果供应商要求涨价，必须提前 **7—15 天**通知，否则按原价执行。

**4. 明确品质标准和验收方式**
- 约定菠萝的品种、成熟度、单果重量、糖度、有无黑心/烂心等。
- 临时补货不能降级：如果品质不达标，你有权拒收或要求换货。
- 验收当场抽检，留好照片和记录，避免后期扯皮。

**5. 约定违约责任和备选方案**
- 供应商未按约定补货，导致你断货，可约定赔偿或扣减货款。
- 你临时取消补货，也要给供应商合理通知期，否则可能承担部分损失。
- 同时开发 **1—2 家备选供应商**，哪怕平时不用，旺季前也要打好招呼、送样确认。

**6. 实操上怎么做**
- 旺季前 1 个月，和供应商开一次会，口头确认今年预计增量，并形成书面补充协议。
- 每周滚动预测未来 2 周用量，发给供应商，让对方提前备货。
- 每次临时补货都用微信或邮件确认：品种、数量、单价、到货时间、验收标准，留痕。
- 如果供应商配合好，旺季结束后可以给一定奖励，比如优先续约或增加基础量，稳定关系。

**一句话总结：**
不要等到缺货才打电话求货。提前用“基础量保供 + 弹性量上浮 + 锁价规则 + 品质验收 + 违约条款”把临时补货写进协议，再配合滚动预测和备选供应商，旺季才不会被动。
