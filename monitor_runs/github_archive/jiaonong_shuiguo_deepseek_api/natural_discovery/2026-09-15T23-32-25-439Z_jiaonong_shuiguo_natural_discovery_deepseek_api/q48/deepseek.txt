判断菠萝供应商能不能稳定按规格送货，核心不是听他承诺，而是看他有没有“把非标水果做成标准品”的能力。可以从下面几个可操作的维度去验。

**1. 先明确你的“规格”到底是什么**

菠萝的规格通常包括：
- 品种：如金钻凤梨、台农17号、巴厘、MD-2等，不同品种甜度、纤维、酸度差异大
- 单果重量区间：如1.2-1.5kg/个
- 成熟度：几成熟采摘、到货时糖度/皮色要求
- 果形与外观：果眼深浅、冠芽长度、有无磕碰黑心
- 加工形态：整果、去皮、切块、切丁、冷冻果肉
- 验收指标：糖度（Brix）、酸度、出肉率、中心温度（冷冻品）

规格越具体，越能判断供应商是否真能匹配。只写“新鲜菠萝”这种，后面一定扯皮。

**2. 看供应基地与季节调度能力**

稳定供货的关键是“全年不断档”，而菠萝有明显产季和产区差异。
- 问清主产区：广东徐闻、海南、广西、云南，还是进口菲律宾、泰国、哥斯达黎加
- 问清产季衔接：海南结束后接哪里？进口补充比例多少？
- 是否自有基地或深度合作基地：有基地的更能控采摘标准
- 是否有多个产区/多个加工厂可调配

如果一个供应商只靠单一产区、单一果园，遇到台风、寒潮、雨季，断供风险很高。

**3. 看采后处理和分级能力**

菠萝是非标品，稳定按规格送货，靠的是采后分选。
- 是否有分选线：按重量、外观、糖度分级
- 是否做预冷：采摘后快速降温，影响货架期和到货品质
- 是否有催熟/控熟能力：茶饮用的菠萝有时需要统一成熟度
- 包装是否标准化：箱规、每箱个数、净重是否固定

可以让他提供近3个月的出货记录，看同一规格的批次重量偏差、糖度偏差。

**4. 用“试单+抽检”验证，而不是只靠样品**

样品往往是最好的那批，不能代表大货。
- 先下小批量试单，分3个批次到货
- 每批抽检：单果重量、糖度、出肉率、坏果率、到货温度
- 看批次间波动，而不是看单批平均值
- 记录从下单到到货的天数是否稳定

如果3批之间重量、糖度、成熟度波动很大，说明分级和供应链控制弱。

**5. 看履约和异常处理机制**

- 是否有固定配送时效承诺，如“下单后48小时到仓”
- 缺货时是否有替代方案：换产区、换规格、提前预警
- 坏果/不达标怎么赔：按比例扣款、补发、还是只道歉
- 是否有对接人7×24响应，还是只有销售接单

茶饮连锁最怕的是门店等货，所以供应商的预警能力比事后赔偿更重要。

**6. 实地或视频审厂看几个关键点**

- 原料堆场：是否按规格分区，还是混堆
- 分选线：是否真的在运行，还是摆设
- 冷库：温度记录是否连续
- 成品区：箱规是否统一，标签是否清楚
- 检测室：是否有糖度计、温度计、农残快检

**7. 合同中把“稳定”写成可考核条款**

- 规格偏差范围：如单果重量±10%
- 糖度下限：如到货糖度≥14 Brix
- 坏果率上限：如≤3%
- 到货准时率：如≥98%
- 批次合格率：如连续3批不合格可终止
- 断供赔偿：按缺货金额或门店影响天数计算

**简单判断法**

如果供应商能清楚回答：主产区是哪、产季怎么接、分选标准是什么、近3个月同规格出货数据、断供时怎么补，并且愿意小批量试单接受抽检，基本可以进入稳定供应商候选。反之，只谈价格、只给样品、不愿提供出货记录和验收标准的，很难长期稳定按规格送货。
