判断一批香蕉，核心不是“现在黄不黄”，而是“它现在处在哪个后熟阶段、还能放多久、路上会不会烂”。批发场景要按下面顺序看。

## 1. 先问/确认关键信息
- 产地、品种：菲律宾、厄瓜多尔、越南、云南/广西等差异很大。
- 采收成熟度：通常按“饱满度”分，7成、7.5成、8成、8.5成、9成。
- 是否催熟：未催熟青蕉、已催熟黄蕉、还是催熟中。
- 运输和到货时间：当天卖、3天卖、7天卖，判断标准完全不同。
- 冷库/冷链情况：有没有断冷链，是否受过冻。

## 2. 看外观：判断熟度
### 青蕉阶段
- 颜色青绿、棱角明显：成熟度低，适合远运或再催熟。
- 颜色转浅绿、棱角变圆：开始后熟，适合短期存放。
- 出现“黄边”或局部转黄：已经进入后熟，放不了太久。

### 黄蕉阶段
- 通体黄、果指饱满：适熟，适合尽快出货。
- 黄中带青：还能放1—3天，视温度而定。
- 出现糖斑/芝麻点：接近最佳食用期，也意味着货架期短。
- 大面积黑斑、果柄发黑：过熟，坏果风险高。

### 坏果早期信号
- 果指发软、按下去不回弹。
- 果柄、果轴发黑、发霉。
- 果皮有水渍状暗斑，尤其靠近果柄。
- 有酒味、酸味、发酵味。
- 箱内发热、有水汽，说明呼吸热大、霉变风险高。

## 3. 摸和按：判断硬度和后熟速度
- 硬：成熟度低，可放。
- 稍软但有弹性：适熟。
- 软塌、局部凹陷：过熟或碰伤。
- 同一箱里软硬差异大：成熟不均，坏果风险高。

## 4. 看果柄、果轴和切口
- 果柄青绿：新鲜。
- 果柄发黄、发黑、干缩：放久了或受热。
- 果轴发黑、长毛：整箱可能已感染。
- 切口发黑、流汁：运输损伤或病害。

## 5. 闻气味
- 青草味：未熟。
- 清香：正常后熟。
- 酒味、酸味、甜腻发酵味：已经开始烂，风险高。
- 霉味：直接警惕整批货。

## 6. 抽箱检查，不要只看表面
批发量大时，至少抽：
- 上、中、下三层。
- 箱边、箱角、箱底。
- 不同批次、不同垛位。

重点看：
- 箱底有没有压伤、烂果、汁液。
- 中间有没有发热。
- 底层是不是比上层熟得快。
- 有没有“一个烂果带坏一片”的情况。

## 7. 按用途判断能不能拿
- 当天/次日卖：可拿适熟、刚转黄、少量糖斑的货。
- 3—5天卖：拿青黄交界、硬度较好、无黑斑的货。
- 7天以上或远运：拿青绿、饱满度7—7.5成、未催熟或轻催熟的货。
- 做烘焙/加工：可接受较熟，但不能有霉变、酒味。
- 做零售精品：要成熟均匀、果指饱满、无机械伤。

## 8. 坏果风险高的典型情况
- 已大面积黄熟，但还要放几天。
- 箱内发热、有水汽。
- 果柄发黑、发霉。
- 有酒味/酸味。
- 断冷链后又回温。
- 受过冻：果皮发暗、水渍状，后熟不正常。
- 同一批软硬差异很大。
- 箱底有汁液和烂果。

## 9. 实操拿货口诀
**看颜色、按硬度、查果柄、闻气味、抽底层、问成熟度、算销售期。**

一句话：
- 要快卖：拿黄中带青、硬中带软、无黑斑的。
- 要放几天：拿青绿、饱满、硬、未催熟的。
- 有酒味、发软、果柄黑、箱底烂：别拿，或至少压价并当天处理。
