茶饮店使用水果，属于食品原料，供应商应提供的证明。以中国大陆常规监管要求为准，核心分两类：**主体资质**和**产品合格证明**，另加**追溯凭证**。

## 一、供应商主体资质（证明它是合法经营主体）

| 供应商类型 | 需要的证照 |
|---|---|
| 水果种植户/合作社直销 | 营业执照（或农民专业合作社法人营业执照）；若仅销售自产农产品，按《食品安全法》可免于许可，但需能证明自产自销 |
| 经销商/贸易商 | 营业执照 + 食品经营许可证（经营范围含食品销售/食用农产品销售） |
| 进口水果 | 供应商资质 + 入境货物检验检疫证明/海关报关单 |

> 注意：单纯卖初级农产品（未加工的水果）通常只需营业执照，不需要食品生产许可证；但一旦涉及预包装、切配、速冻等加工，就要生产许可。

## 二、产品合格证明（按批次提供）

1. **检验合格报告**
   - 供应商自检报告，或
   - 有资质第三方检测机构出具的检验报告（CMA/CNAS）。
   - 检测项目重点：农药残留（如有机磷、氨基甲酸酯类）、重金属（铅、镉）、致病菌（切开水果或即食水果需关注沙门氏菌、大肠菌群等）。

2. **食用农产品合格证**
   - 现在很多地区推行“承诺达标合格证”，由生产者/收购方开具，是低门槛但有效的追溯+承诺凭证。

3. **入境货物检验检疫证明**（进口水果必须）。

## 三、追溯与交接凭证

- 每批次的**送货单/销货清单**：写明品名、数量、批次/产地、日期、供应商盖章或签字。
- **产地证明或采购凭证**：便于发生问题时追溯。
- 建议保留**每批次对应关系**，不要只留一张通用报告。

## 四、按风险分级的实操建议

- **高风险**：切开即食水果（如现切西瓜、芒果、柠檬片直接入杯）——要求每批检测报告或合格证，索证索票完整。
- **中风险**：需去皮、加热、榨汁后过滤的——至少保留合格证+送货凭证。
- **低风险**：整果仅作装饰、不直接接触饮品——资质+送货单即可，但仍建议抽检。

## 五、茶饮店自己还要做的

1. **索证索票制度**：建立供应商档案，证照复印件加盖公章并定期更新（注意有效期）。
2. **进货查验记录**：名称、规格、数量、生产日期/批号、供货者、联系方式、进货日期。
3. **快速检测**：有条件的门店可对农残做快检，尤其对叶菜类、带皮直接使用的水果。
4. **储存与效期管理**：冷藏温度、先进先出、切开水果限时使用。
5. **合同约定**：在采购合同中明确供应商须提供上述证明、出现不合格的赔偿与召回责任。

## 六、一句话判断标准

> 监管检查时，能对每一批水果说清楚：**从谁买的、有没有资质、这批合不合格、什么时候进的**——这四件事有凭证，基本就达标。

具体证照名称和是否免许可，各地市场监管口径略有差异，建议以当地市场监管局要求为准。
