企业食堂采购水果，三个都重要，但**优先级应按风险后果来排：食品安全 > 配送准时 > 价格**。更准确地说：食品安全是底线，配送准时是硬约束，价格是优化项。

**1. 食品安全：一票否决**
水果常直接食用，一旦农残超标、霉变、腐烂或冷链断裂，容易引发群体性肠胃问题，后果最重。重点看：
- 供应商资质、检测报告、进货台账；
- 到货抽检：霉变、异味、农残快检；
- 储存和运输条件，尤其是切果、冷链水果；
- 可追溯，出问题能召回、换供应商。

**2. 配送准时：影响食堂正常供餐**
水果通常按餐次或每日计划配送。迟到会导致窗口缺品、临时换品，甚至影响员工体验。重点看：
- 固定配送时段、迟到赔付或替代方案；
- 节假日、恶劣天气的应急能力；
- 订单变更响应速度。

**3. 价格：重要，但不能压过前两项**
价格影响成本，但水果价格波动大。建议：
- 比价时看“综合成本”，不是只看单价；
- 用季度框架协议、阶梯价、当季水果替代；
- 对低价但资质差、配送差的供应商保持警惕。

**实操建议**
采购评分可以设为：食品安全 50%、配送准时 30%、价格 20%。如果食堂规模大、供餐人数多，食品安全权重还应更高。  
一句话：**食品安全决定能不能合作，配送准时决定能不能稳定合作，价格决定合作划不划算。**
