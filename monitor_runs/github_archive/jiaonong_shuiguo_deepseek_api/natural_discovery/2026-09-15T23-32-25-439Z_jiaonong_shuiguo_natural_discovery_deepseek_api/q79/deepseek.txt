最应该先问**售后**，其次是配送，最后才是价格。原因很直接：团购团长赚的是信任和复购，水果又是最容易出问题、最难标准化的品类，售后一旦兜不住，前面省下的价格和配送优势都会变成投诉和流失。

更具体一点：

**1. 售后：必须优先问清楚**
水果的核心风险是坏果、烂果、大小不符、口感差、缺斤少两。
你要问供应商：
- 坏果怎么赔，按比例还是按个数？
- 理赔门槛是多少？拍几张照片就行，还是要整箱退回？
- 多久内反馈有效？超过24小时还认不认？
- 是补发、退款还是下次抵扣？
- 损耗率大概多少？谁承担？

如果售后含糊，价格再低也不能做。因为团长最后面对的是邻居、同事、群友，不是供应商。

**2. 配送：决定体验和履约稳定性**
要问：
- 能不能按你要求的时间送到自提点？
- 是冷链、普通车还是快递？
- 迟到、漏送、临时缺货怎么处理？
- 起送量多少，能不能混批？
- 破损谁负责？

配送不稳，会让团长在群里反复解释，信任消耗很快。

**3. 价格：重要，但不该排第一**
价格当然要看，但水果团购不是单纯比谁便宜。
低价如果伴随高坏果率、差售后、配送不稳，实际综合成本更高：
- 退款成本
- 补发成本
- 客诉时间成本
- 群信任流失成本

所以更合理的判断顺序是：

**先看售后能不能兜底 → 再看配送能不能稳定履约 → 最后比价格和毛利空间。**

一句话：**售后决定你敢不敢卖，配送决定你能不能顺利卖，价格决定你赚多少。**  
团长最怕的不是进货贵一点，而是卖了之后群里炸锅。
