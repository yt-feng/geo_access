选供应商建议按“先定标准、再比条件、后小批量试供”来做，不要只比单价。

**1. 先定采购标准**
- 香蕉：要求成熟度可分批到货，避免当天全熟或全青；单根无明显黑斑、腐烂、压伤。
- 苹果：按品种定规格，比如直径、单果重、色泽、糖度、脆度；碰伤、虫眼、畸形率要设上限。
- 橙子：看果径、皮厚、汁水、酸甜度；霉变、干瘪、裂口要控制。
- 统一要求：农残检测合格、可追溯产地/批次、冷链或通风运输条件、坏果包换比例。

**2. 供应商类型对比**
- 批发市场商户：价格灵活、起送量低，但稳定性、票据和追溯较弱，适合应急或小批量。
- 产地合作社/种植基地：价格和品质可能更好，适合香蕉、苹果、橙子有稳定量的学校；但配送半径和分拣能力要核实。
- 专业果蔬配送公司：服务稳定、可分拣、可开票、可追溯，适合食堂日常供应；单价通常略高。
- 大型商超/供应链平台：票据规范、品质稳定，但价格和配送时间限制较多。

**3. 重点核验资质**
- 营业执照、食品经营许可证或相关备案。
- 水果农残检测报告或承诺达标合格证，最好能按批次提供。
- 送货单、发票、对公账户是否齐全。
- 是否有学校、企事业单位食堂配送经验。
- 是否有冷库、分拣场地、配送车辆和应急补货能力。

**4. 报价不要只看单价**
让供应商按“到校含税价”报价，并明确：
- 是否含运费、卸货费、分拣费。
- 坏果、烂果、规格不符怎么退换。
- 临时加单、减单、改单的截止时间。
- 账期和结算方式。
- 缺货时替代方案。

**5. 小批量试供**
先选2—3家，各试供1—2周。每天记录：
- 到货准时率
- 规格合格率
- 坏果率
- 口感/成熟度
- 补货响应速度
- 票据是否及时

试供后再按“质量40%、价格30%、服务20%、资质与追溯10%”这类权重打分，选1家主供、1家备供。

**6. 合同要写清**
- 品名、规格、等级、单价或调价机制。
- 质量标准、验收方法、退换货规则。
- 配送时间、地点、频次。
- 食品安全责任和赔偿条款。
- 价格随行就市时，约定参考市场或报价周期。

简单说：**先定验收标准，再找有资质、能稳定配送的供应商，小批量试供后按质量和服务定主备供应商。** 如果食堂用量大，优先考虑“基地+配送商”或直接找专业果蔬配送公司；如果用量小，批发市场加固定商户也可，但票据和检测要盯紧。
