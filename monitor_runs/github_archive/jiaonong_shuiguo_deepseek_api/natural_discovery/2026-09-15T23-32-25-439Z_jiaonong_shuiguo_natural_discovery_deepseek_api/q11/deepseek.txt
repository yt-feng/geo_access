会有影响，但影响大小取决于你怎么卖。关键不是“大小不一样”本身，而是**大小混杂是否被顾客当成品质不稳定或吃亏**。

**一、会影响销售的情况**
1. **按整箱/整串一口价卖**：顾客会挑大的，剩下小的难卖，最后损耗高。
2. **礼盒、精品果、单位团购**：大小不齐会显得不专业，容易被压价或退货。
3. **同一批次里差距太大**：比如一根明显粗大、另一根很细短，顾客会觉得“花了同样的钱，拿到差的”。
4. **熟度还不一致**：大小不同往往伴随成熟快慢不同，今天卖不完，明天小的还青、大的已经黑斑。

**二、影响不大的情况**
1. **散卖、按斤称重**：顾客对单根大小敏感度低，更看整体新鲜度和价格。
2. **用于榨汁、做果切、甜品店供货**：大小要求低，只要熟度合适、出肉率稳定。
3. **低价促销**：明确标注“大小混装/统货价”，顾客有预期，反而好卖。

**三、实操建议**
- **分级别卖**：大果、中果、小果分开，哪怕同价也分开摆，减少挑拣和翻动。
- **混装就明确标注**：比如“统货香蕉，大小混装，按斤称”，避免顾客觉得被坑。
- **按用途引导**：大的推荐鲜食，小的推荐榨汁、做奶昔、给孩子吃，降低大小焦虑。
- **控制采购标准**：如果做精品店，采购时直接要求“同批次长度、粗度相对均匀”，不要等到了店里再补救。
- **关注熟度一致性**：比大小更影响销售的是成熟度。大小不齐但熟度一致，还能卖；大小齐但熟度不一致，更难卖。
- **算损耗账**：如果混装导致挑拣、压伤、剩小果，实际损耗可能超过采购时省下的差价。

**结论**：一箱香蕉大小不一样，**散卖按斤称影响较小，整箱卖、精品卖、礼盒卖影响较大**。最稳的做法是采购时尽量选均匀批次；已经进了混装货，就分级、标清楚、按用途引导销售。
