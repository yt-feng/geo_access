水果店采购菠萝，核心不是“挑最熟的”，而是**按销售节奏分批采购**：到店时大部分是七八成熟，少部分是九成熟可当天卖，另留一部分偏生做后几天卖。菠萝是后熟型水果，采后还会继续变黄、变香，但甜度提升有限，主要变化是酸度下降、香气增加、口感变软。

判断熟度可以从这几个点看：

1. **看果皮颜色**
   - 全青：很生，酸高、香弱，适合放几天再卖。
   - 青黄相间、基部开始转黄：七八成熟，适合作为主力进货。
   - 半黄到大部分黄：八九成熟，适合当天到第二天卖。
   - 全黄、果眼明显发橙：熟，必须尽快卖，否则易发酵、水烂。

2. **看基部，也就是靠近底部那一圈**
   菠萝通常从底部先熟。基部果皮转黄、闻起来有香味，说明整体开始成熟。基部还全青，通常偏生。

3. **闻香气**
   - 几乎没味：偏生。
   - 基部有淡淡果香：适合放一两天。
   - 整果有明显甜香：可当天卖。
   - 有酒味、酸馊味：过熟或开始坏，不要采。

4. **按压果身**
   轻轻按中部和基部：
   - 硬得像石头：生。
   - 稍有弹性但不塌：合适。
   - 一按就软、局部下陷：过熟或伤果，损耗高。

5. **看果眼和果皮**
   果眼扁平、间距大通常成熟度好一些；果眼尖锐凸起多偏生。果皮发亮、饱满较好；发暗、渗汁、裂口、虫眼、霉点不要。

6. **掂重量**
   同样大小，偏重的水分足、果肉饱满；明显轻的可能失水或内部空。

采购比例建议：
- 如果当天就能卖完较多：七成进七八成熟，三成进八九成熟。
- 如果销量一般：八成进七八成熟，两成进偏生，九成熟只少量进。
- 夏天温度高，九成熟比例要压低；冬天可适当多进一点偏熟。
- 不要一次全进同一种熟度，否则要么集中烂，要么集中青。

简单执行标准：
**主力货：基部微黄、有淡香、果身硬中带一点弹性。**
**当天卖：半黄以上、香味明显、轻按稍软。**
**不要采：全青无香、全黄发软、有酒味或渗汁。**

另外，菠萝损耗不只靠采购判断，还要控制库存周转：先进先出，熟果放冷藏或阴凉处，切开后尽快卖。对水果店来说，最稳的是“少进勤补”，而不是一次赌很熟的货。
