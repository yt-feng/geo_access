酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准里，供应商必须按批次保证。下面是一套可直接用于询价、下单、验收的通用标准。

**一、规格标准**

1. **品种与产地**
   - 明确品种、等级、产地，例如：红富士苹果、一级果；海南贵妃芒；进口都乐香蕉等。
   - 同一批次应品种纯正，不得混装、以次充好。

2. **单果重量/尺寸**
   - 按酒店果盘切配要求约定单果重或直径。
   - 例如：
     - 苹果：单果 180–220g，直径 75–85mm；
     - 橙子：单果 180–250g，直径 70–85mm；
     - 西瓜：单瓜 4–6kg，成熟度 8–9 成；
     - 哈密瓜：单瓜 1.5–2.5kg；
     - 火龙果：单果 350–500g；
     - 葡萄：单串 400–600g，果粒均匀；
     - 圣女果：单果 12–18g，直径 20–25mm。

3. **成熟度**
   - 必须适合酒店当日或短期内切配使用。
   - 一般要求：到货时 7–9 成熟，既能立即使用，也能短存 1–3 天。
   - 香蕉、芒果、牛油果等后熟水果，应约定到货成熟度，避免当天太生或次日过熟。

4. **新鲜度**
   - 应为当季或近期采收，不得为长期冷库积压、失水、发糠、发绵产品。
   - 叶菜类、浆果类应尽量为当日或前一日采收。

5. **损耗率**
   - 明确可接受损耗率，例如：整果到货可食率不低于 85%–90%。
   - 切配后可用率应满足酒店出餐标准。
   - 对草莓、蓝莓、葡萄等易损水果，应单独约定破损率上限，例如不超过 3%–5%。

6. **包装与运输**
   - 使用食品级周转箱、保鲜箱或原厂包装。
   - 不得与有毒、有害、有异味物品混装。
   - 冷链水果应全程冷藏运输，到货中心温度符合要求。
   - 每批次应附送货单、产地/批次信息、检测合格证明或承诺书。

**二、外观标准**

1. **整体外观**
   - 果形端正、大小均匀、色泽自然。
   - 无明显畸形、病斑、虫眼、裂口、腐烂、霉变。
   - 无大面积机械伤、压伤、擦伤、冻伤。

2. **表面与果面**
   - 果面干净，无泥土、药斑、污渍、异物。
   - 允许少量自然瑕疵，但不能影响切配和出品美观。
   - 例如苹果允许轻微果锈，但不能有烂心、黑斑、明显碰伤。

3. **成熟与色泽**
   - 色泽应符合该品种成熟特征。
   - 不得青涩未熟，也不得过熟发软、发酵、出水。
   - 同一批次颜色、大小应相对一致，便于果盘摆盘。

4. **气味与口感**
   - 具有本品种应有香气，无酸败、发酵、霉味、药水味。
   - 试吃应酸甜适口、无异常苦味、涩味、异味。
   - 果肉不得空心、褐变、发绵、纤维过粗。

5. **洁净与安全**
   - 无农药残留超标风险，供应商应提供合格证明或快检报告。
   - 无致病菌、寄生虫、异物污染。
   - 预切水果还应符合即食食品卫生标准。

**三、验收与退换要求**

建议在合同中明确：

1. **抽检比例**
   - 每批次按 5%–10% 抽检，重点检查重量、直径、成熟度、腐烂率。

2. **拒收标准**
   - 腐烂、霉变、虫蛀、异味、严重压伤超过约定比例，整批拒收。
   - 规格不符、成熟度不符、混级严重，要求退换或折价。

3. **退换货时效**
   - 到货 2 小时内提出异议，供应商应在 4–24 小时内补货或退换。
   - 因原料问题导致酒店出餐延误，应约定违约责任。

4. **批次追溯**
   - 每批水果应有品种、产地、采收/加工日期、供应商信息。
   - 便于出现食品安全问题时追溯。

**四、可直接写进采购单的简版条款**

> 供应商应保证所供水果品种纯正、新鲜、无腐烂霉变、无虫害、无异味、无严重机械伤；单果重量、直径、成熟度符合酒店要求；同一批次大小、色泽基本一致；到货可食率不低于约定标准；全程符合食品安全及冷链运输要求。验收不合格的，酒店有权拒收、要求退换或扣款。
