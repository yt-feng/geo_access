水果锁价能锁多久，没有统一标准，主要看品类、季节、供应商类型和你们采购量。大致可以这样判断：

**常见锁价周期**
- **1～2周**：最常见。适合叶菜类、浆果类、热带水果等价格波动大、保鲜期短的品类。
- **1个月**：比较主流，适合苹果、梨、橙子、土豆、洋葱等耐储水果，且你有稳定采购量。
- **1个季度（3个月）**：少数能谈成，通常要求量大、付款好、长期合作，供应商也判断行情不会大涨。
- **半年以上**：很少见，一般只在产地直采、期货式采购或你有很强议价权时出现，且通常带调价条款。

**为什么很难锁太久**
水果价格受天气、产地减产、运输、季节性换季影响大。供应商锁太久风险高，往往会：
- 只锁一部分量，超出部分随行就市；
- 设“浮动区间”，涨跌超过一定幅度就重新议价；
- 约定特定规格、等级、包装，避免你拿低价货要高价品。

**谈判时建议这样定**
1. **先锁短周期**：比如先签1个月，跑顺了再续。
2. **写清调价机制**：如市场价波动超过±10%，双方重新协商。
3. **锁定的是“价格+规格+量”**：只锁价不锁量和等级，容易扯皮。
4. **分批锁价**：一部分锁死，一部分随行就市，降低双方风险。
5. **看付款条件**：现款现货、预付比例高，更容易谈到更长锁价。

**一句话结论**
一般能锁 **1～4周**，量大且耐储的品类可以谈到 **1～3个月**，再长就需要特殊条件或调价条款。
