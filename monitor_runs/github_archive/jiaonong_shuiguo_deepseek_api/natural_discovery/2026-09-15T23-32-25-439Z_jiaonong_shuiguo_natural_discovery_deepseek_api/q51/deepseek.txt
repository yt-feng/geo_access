要固定，但不要只固定“产地”这一个维度，而要用“产地+品种+批次+验收标准”一起锁。

**直接建议：**
1. **核心爆款水果要固定产地和供应批次**  
   比如草莓、芒果、葡萄、柠檬这类直接决定招牌产品风味的，最好固定到具体产区、品种、果园或供应商基地。不同产地糖酸比、香气差异很大，换产地很容易被老顾客喝出来。

2. **不要只写“固定产地”**  
   同一产地不同批次也会波动，受季节、降雨、成熟度、采摘时间影响。采购合同里要加：品种、规格、成熟度、糖度范围、酸度范围、出汁率、香气要求、到货温度、验收拒收标准。

3. **供应批次要可追溯**  
   每批到货记录：产地、采摘/加工日期、批次号、糖度检测、感官测试。门店做小样杯测或试饮，合格才大批量用。这样出问题时能快速定位是哪个批次。

4. **保留1-2个备用供应源，但不要频繁切换**  
   固定单一产地风险也大：减产、涨价、天气灾害会断供。更稳的做法是：主供应基地占70%-80%，备用基地占20%-30%，且备用基地提前测试过配方适配性。切换时要有过渡拼配方案，避免口味突变。

5. **用配方和工艺缓冲波动**  
   水果风味不可能100%稳定。可以通过糖浆、茶底、酸度调节、拼配不同批次来缩小差异。但前提是门店有标准SOP和每批检测，不能靠店员凭感觉调。

6. **按产品分级管理**  
   - 招牌产品：固定产地+固定批次+每批验收。  
   - 常规产品：固定产地，允许批次内微调。  
   - 季节限定：可灵活换产地，但提前做消费者测试。  
   - 装饰性水果：优先稳定供应和成本，不必过度锁定。

**一句话结论：**  
要固定，但固定的是“稳定风味模型”，不是死守一个产地。核心水果锁定产地和批次，同时建立验收标准、备用供应和拼配缓冲，才能既稳定口味又不断供。
