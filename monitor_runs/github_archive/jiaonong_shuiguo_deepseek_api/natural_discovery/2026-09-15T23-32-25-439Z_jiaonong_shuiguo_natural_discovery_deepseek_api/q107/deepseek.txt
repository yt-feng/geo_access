会增加，而且香蕉和菠萝的损耗逻辑不太一样，要分开判断。

**香蕉：起订量高，损耗风险通常更明显**
- 香蕉是呼吸跃变型水果，采购后还会继续后熟，温度、乙烯、挤压都会加速变黄、起斑、发软。
- 如果一次性到货太多，门店或仓库来不及在最佳窗口卖完，就会出现“前一批还没卖完，后一批已经开始熟”的情况。
- 香蕉对挤压和堆压敏感，整箱堆太多容易压伤，压伤部位会先黑先烂。
- 所以香蕉的起订量如果明显高于日均销量，损耗风险会上升得比较快。

**菠萝：起订量高，损耗风险相对低一些，但也不是没风险**
- 菠萝整体比香蕉耐放，完整果皮较厚，常温下周转窗口通常更长。
- 但菠萝会怕冷害、怕潮湿、怕堆压，长期放也会黑心、发霉、果眼腐烂。
- 如果是已削皮或鲜切菠萝，损耗风险会大幅上升，和香蕉一样不能压太多库存。
- 菠萝整果如果起订量高，但销量稳定、储存条件合适，风险通常比香蕉可控。

**判断会不会增加损耗，关键看这几个数**
1. **日均销量**：起订量除以日均销量，得到可售天数。
2. **最佳销售窗口**：
   - 香蕉通常按天甚至按半天算；
   - 完整菠萝通常按几天算；
   - 鲜切菠萝按小时到1天算。
3. **储存条件**：有没有冷藏、通风、避压、分开放乙烯。
4. **到货成熟度**：青蕉和熟蕉的可用时间差很大；菠萝成熟度高也会缩短货架期。
5. **补货频率**：如果一周只能送一次，高起订量风险明显更大；如果能隔天补，风险会小很多。

**实操建议**
- 香蕉：起订量最好不要超过“最佳销售窗口内能卖完的量”，比如按2～3天销量控制，而不是按一周销量压货。
- 菠萝整果：可以适当高于香蕉的周转天数，但也要看仓储温度和田头成熟度。
- 如果供应商起订量降不下来，可以：
  - 拆分到多个门店或渠道分摊；
  - 要求分批送货；
  - 混搭不同成熟度，先卖熟的、后卖青的；
  - 对高到货量做促销或加工成果切、果汁、烘焙原料；
  - 记录每天损耗，反推安全起订量。

简单说：**起订量高一定会增加损耗风险，香蕉比菠萝更敏感；能不能接受，取决于起订量对应多少天销量、储存条件和补货频率。** 如果起订量超过最佳销售窗口的1.5～2倍，通常就要警惕。
