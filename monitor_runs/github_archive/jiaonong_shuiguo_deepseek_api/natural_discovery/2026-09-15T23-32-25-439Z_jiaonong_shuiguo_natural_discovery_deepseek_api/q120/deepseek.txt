核心一句话：**别讲品种和行业术语，讲“顾客会怎么买、你什么时候用、赚不赚钱、坏不坏”。**

供应商介绍产品时，可以按下面这套顺序说，商家最容易听懂并下单：

1. **先说它像什么常见货**
   - “这个不是小众货，它相当于菠萝里的凤梨、香蕉里的皇帝蕉。”
   - 用商家已经熟悉的大品类做锚点，降低理解成本。

2. **再说顾客为什么买**
   - 不要只说“果香浓、酸甜比好”，要说：
   - “顾客买回去主要是做果切、榨汁、送礼、给孩子吃。”
   - “它比普通菠萝甜，不用泡盐水，切开就能吃。”
   - 商家关心的是能不能卖出去，不是品种多高级。

3. **说清使用场景**
   - “早餐店可以配酸奶，奶茶店可以打果泥，水果店可以做高端果切。”
   - “火锅店可以当解腻赠品，烧烤店可以烤着卖。”
   - 场景越具体，商家越容易判断自己能不能用。

4. **直接算利润**
   - “进价 X 元，建议卖 Y 元，一斤出多少果肉，损耗大概多少。”
   - “一箱能切几盒，每盒成本多少，卖多少不亏。”
   - 商家听不懂“糖度 18 度”，但听得懂“一箱多赚 30 块”。

5. **说风险和保存**
   - “能放几天，要不要冷藏，熟了是什么样，坏了是什么样。”
   - “先拿一箱试卖，卖不动我教你做试吃。”
   - 降低下单顾虑，比夸产品有用。

6. **给一句简单选择理由**
   - “你要是想跟普通香蕉拉开差距，就上这个；要是只想走量，还是普通蕉。”
   - 让商家觉得你在帮他选，不是硬推。

一个可直接套用的话术模板：

> “老板，这个你就当它是‘升级版菠萝’。顾客买回去不用泡盐水，切开就能吃，主要做果切和送礼。进价一箱 XX，能切 XX 盒，建议卖 XX，一盒大概赚 XX。冷藏能放 X 天，先拿一箱试卖，卖得好再补。你要是只想走低价，就用普通菠萝；想拉高客单，就配这个。”

关键原则：
- **用大品类做参照**
- **用顾客场景解释**
- **用利润和损耗说服**
- **用试卖降低门槛**

商家下单不是因为懂了品种，而是因为听懂了：**这东西我卖得掉，而且能赚钱。**
