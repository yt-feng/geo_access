做水果生意，供应商选得对，长期稳定才有底。多数人只看价格、看货样、看是否“能供货”，但真正决定你能不能长期赚钱和少踩坑的，往往是下面这些容易被忽视的细节：

1. **产地稳定性，而不是“这次货好”**  
   要问清楚：是自有基地、合作基地，还是市场倒货？  
   倒货商这次能给你好货，下次未必有。长期做，优先选有稳定产地、能持续供同品质货的供应商。

2. **分级标准是否一致**  
   很多纠纷不是坏货，而是“标准不一致”。  
   比如你说大果，他发中果；你说七成熟，他发九成熟。  
   要明确：规格、糖度、成熟度、色泽、单果重、瑕疵容忍度，最好有文字或样品标准。

3. **损耗责任怎么分**  
   水果最容易在运输和到货后出问题。  
   要提前谈清楚：运输损耗、压伤、腐烂、冻伤、失水，分别谁承担，超过多少比例怎么赔。  
   否则每次出问题都扯皮，长期合作很难稳定。

4. **供货能力是否匹配你的销售节奏**  
   不是看他一天能发多少，而是看：  
   旺季能不能优先给你？  
   淡季能不能保底？  
   你突然加量时，他有没有弹性？  
   很多供应商平时合作好，一到旺季就先把货给大客户，小客户被放空。

5. **账期和结算方式是否可持续**  
   低价但要求全款预付，和价格稍高但能给账期，现金流压力完全不同。  
   要算清楚：账期、定金比例、尾款条件、发票、是否支持退换。  
   长期稳定不是单看进货价，而是看资金周转能不能转得动。

6. **物流和冷链能力**  
   水果不是普通商品，温度、时效、装卸都会影响品质。  
   要问：是否自有冷链？还是外包？  
   发货时效多久？  
   中转几次？  
   到货温度记录有没有？  
   很多供应商货好，但物流不行，最后到你手里全烂。

7. **是否只做单一品类**  
   只做一个品类的供应商，专业度高，但风险也集中。  
   多品类供应商方便一站式采购，但可能每样都不精。  
   长期稳定最好是：核心品类找专业供应商，辅助品类找补充供应商，不把鸡蛋放一个篮子。

8. **售后响应速度**  
   出问题时，是马上补发、退款，还是拖到你自己认亏？  
   合作前可以故意小批量试单，观察他处理问题的态度和速度。  
   售后差的供应商，价格再低也会把你拖死。

9. **是否愿意和你一起做计划**  
   真正长期的供应商，会问你：  
   你每月大概要多少？  
   什么规格？  
   什么时间要？  
   能不能提前报计划？  
   如果他只做“一手交钱一手交货”，你很难稳定。

10. **市场行情波动时的态度**  
    涨价时是否突然断供、抬价？  
    跌价时是否硬塞货？  
    这最能看出供应商是否值得长期合作。  
    可以在合作前了解他和其他客户在行情波动时的口碑。

11. **隐性成本**  
    便宜货可能带来：  
    挑拣人工增加、损耗增加、客诉增加、退货增加、资金占用增加。  
    真正要算的是“到货可售成本”，不是“进货单价”。

12. **是否合规和可追溯**  
    尤其做商超、电商、团购，要关注：  
    农残检测、产地证明、发票、包装合规、品牌授权。  
    一旦被抽检或客诉，源头不清会很麻烦。

简单判断一个供应商能不能长期合作，可以看四点：  
**品质稳不稳、供应稳不稳、售后快不快、算总账划不划算。**  
建议先小批量试单，再逐步放量，不要一上来就押重注。长期稳定的关系，靠的是标准清楚、责任清楚、利益清楚，而不是单纯靠交情或低价。
