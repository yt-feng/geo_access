食堂采购香蕉要避免“买回来很快就熟过头”，核心不是只靠采购员会挑，而是要把**采购量、成熟度、储存、加工和领用节奏**一起管起来。可执行的做法如下：

1. **按使用周期少量多次采购**
   - 香蕉后熟快，尤其夏天。建议按 **1～3 天用量** 分批买，不要一次备一周。
   - 如果食堂每天用量稳定，可固定“每周送 2～3 次，每次送 1～2 天量”。
   - 遇到周末、假期、考试周、活动餐等用量波动，提前调整订单，不要按平日惯性下单。

2. **采购时选不同成熟度搭配**
   - 不要全买同一成熟度。可按比例搭配：
     - 当天或次日用：**黄熟、带少量芝麻点**
     - 2～3 天后用：**黄中带绿、无斑点**
     - 更晚用：**偏绿、硬身**
   - 这样到货后自然形成“先熟先用”的梯队，减少集中过熟。

3. **收货时明确验收标准**
   - 拒收或降级处理：
     - 已经大面积黑斑、果柄发黑、软塌、有酒味
     - 表皮破裂、渗液、明显压伤
   - 可接收：
     - 果形完整、无严重机械伤、成熟度符合订单要求
   - 验收后按成熟度分级，不要混堆。

4. **储存要避风、避压、避高温**
   - 未熟或半熟香蕉：放在 **阴凉通风处**，理想约 **13～18℃**，不要直接放冰箱冷藏，容易冻伤发黑。
   - 已熟香蕉：可冷藏延缓继续过熟，但表皮会变黑，不影响内部果肉时可尽快用于加工。
   - 不要堆太高、不要压伤，压伤部位会加速腐烂。
   - 不要和苹果、梨、西红柿等释放乙烯较多的果蔬混放，会催熟香蕉。

5. **建立“先熟先用”制度**
   - 每天检查一次，把香蕉分成：
     - 立即使用
     - 1～2 天内使用
     - 可继续存放
   - 熟度高的优先放到窗口、配餐或加工间。
   - 给香蕉贴简单颜色标签或日期标签，避免新旧混用。

6. **把过熟香蕉转成加工用途**
   - 轻微过熟但无异味、无腐烂的香蕉，可用于：
     - 香蕉牛奶/奶昔
     - 香蕉粥、香蕉饼、香蕉馒头、香蕉蛋糕
     - 水果捞、酸奶配料
   - 这样能把“卖相不好但还能吃”的香蕉消化掉，而不是直接扔。
   - 但如果有酒味、酸味、霉变、渗液，必须废弃，不能加工。

7. **和供应商约定退换或调剂**
   - 合同中写清成熟度标准、到货验收、不合格退换。
   - 对长期供应商可约定：如果集中过熟，允许调换部分或调整下次送货量。
   - 对用量小的食堂，可要求供应商提供小规格包装，避免一箱太多。

8. **做简单数据记录**
   - 记录每次：
     - 采购量
     - 到货成熟度
     - 实际使用量
     - 丢弃量
   - 连续记 2～4 周，就能看出每天大概该买多少、什么成熟度最合适。
   - 如果某几天丢弃多，就下调采购量或改成熟度。

9. **制定应急预案**
   - 发现香蕉集中变熟：
     - 当天增加香蕉窗口供应
     - 通知后厨做香蕉加工品
     - 临时做特价或搭配餐
     - 联系供应商调剂
   - 不要等到全部黑斑才处理。

**最有效的组合是：少量多次采购 + 不同成熟度搭配 + 每天分级巡查 + 过熟转加工。**  
如果只能做一件事，优先做：**把一次采购量压到 1～3 天，并让到货香蕉有生有熟。**
