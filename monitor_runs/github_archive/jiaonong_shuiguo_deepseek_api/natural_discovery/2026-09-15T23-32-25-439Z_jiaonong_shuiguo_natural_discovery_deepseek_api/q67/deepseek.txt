和水果品牌方谈代理时，区域保护和串货是必须问清楚的核心条款。建议你按下面几组问题直接问，并要求对方把答案写进合同。

**一、先问区域保护**
1. 我代理的是哪一级区域：省、市还是区县？边界怎么划？
2. 这个区域内，品牌方自己还招不招第二家代理？直营、电商、商超渠道算不算“另开渠道”？
3. 保护是独家还是非独家？如果是独家，独家期限多久，续约条件是什么？
4. 区域外客户主动找我拿货，我能不能卖？算不算串货？
5. 线上销售是否允许？如果允许，平台、店铺、价格有没有限制？

**二、再问串货**
1. 串货怎么定义？是以货流到区域外为准，还是以谁先投诉为准？
2. 发现串货后，谁来查、多久给结论、依据什么证据？
3. 处罚标准是什么：罚款、扣返利、停货、取消代理权，还是几项并罚？
4. 罚款金额按进货额、销售额还是固定金额算？有没有上限？
5. 我被别人串货冲击时，品牌方有没有义务处理？处理不了我能不能索赔或退出？
6. 线上低价乱价算不算串货？跨区一件代发算不算？
7. 品牌方自己的电商、直播、社区团购渠道，会不会和我代理区域重叠？重叠时怎么保护我？

**三、必须写进合同的关键点**
- 代理区域、渠道、期限、独家性
- 串货定义、取证方式、处罚标准、申诉流程
- 品牌方对乱价的处理责任和时限
- 返利、保证金、任务量与串货处罚的抵扣关系
- 退出机制：被串货严重影响时，能否解约、退保证金、清库存

**四、谈判时的判断标准**
- 对方只说“放心，不会串货”，但不肯写定义和处罚，基本不可信。
- 只罚代理商、不约束品牌方自己和线上渠道，说明风险主要在你这边。
- 任务量定得很高、区域又小，很容易被逼着串货，要提前算清楚。
- 保证金和返利如果随便被扣，等于你的利润被品牌方捏着。

**五、建议你直接这样问**
“请把区域保护范围、线上渠道归属、串货定义、取证流程、处罚标准、我方被串货时的补偿或解约权，全部写进代理合同。没有这些条款，我不签。”
