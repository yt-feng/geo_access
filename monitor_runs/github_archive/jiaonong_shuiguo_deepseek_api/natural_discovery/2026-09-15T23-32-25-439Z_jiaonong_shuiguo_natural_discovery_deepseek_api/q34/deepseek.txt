结论：**在商超水果经营里，通常会先看“损耗低”，再看“价格低”。**  
但更准确地说，不是二选一，而是：**低采购价决定理论毛利空间，低损耗决定这个毛利能不能真正落袋。**

如果非要判断哪个对最终毛利影响更大，可以分三种情况：

1. **叶菜、浆果、熟度高的热带水果、现切果切类**  
   **损耗影响更大。**  
   因为这类商品采购价再低，只要到店后烂得快、挑拣多、报损高，最终毛利会被迅速吃掉。比如采购价便宜10%，但损耗从8%升到20%，通常得不偿失。

2. **苹果、梨、橙子、柚子、土豆、洋葱等耐储水果**  
   **采购价影响更大。**  
   这类损耗相对可控，周转慢一点也未必立刻坏。采购价每低几个点，往往能更直接转化为毛利。

3. **促销引流型水果，如香蕉、西瓜、应季大单品**  
   **两者都关键，但损耗往往更致命。**  
   因为这类商品销量大、价格透明、毛利薄，一旦损耗高，基本就是“卖得越多亏得越多”。

可以用一个简单公式判断：

**最终毛利 = 销售额 × 毛利率 - 损耗成本 - 运营成本**

而损耗会同时打击两头：

- 采购100斤，坏了20斤，只有80斤可卖；
- 可卖部分的成本被抬高；
- 坏掉的部分还要承担采购、物流、人工、货架成本。

所以低采购价是“账面优势”，低损耗是“真实利润”。

实际采购决策建议：

- **先算综合成本，不只看采购单价。**
  综合成本 = 采购价 ÷ 可售率 + 损耗处理成本 + 物流仓储成本。

- **优先选能稳定供货、成熟度可控、分级稳定的货源。**
  便宜但批次不稳、熟度不齐、压伤多的货，通常损耗更高。

- **高损耗品类，宁可选贵一点但品质稳的货。**
  比如草莓、蓝莓、荔枝、龙眼、桃、葡萄等。

- **耐储品类，可以更积极比价。**
  比如苹果、橙子、柚子、瓜类等。

- **用数据复盘。**
  按单品看：采购价、售价、损耗率、周转天数、毛利率。  
  如果某单品损耗率超过毛利缓冲，就别单纯追低价。

一句话总结：

**低采购价决定你能不能赚，低损耗决定你最后赚不赚得到。多数商超水果经营中，损耗低对最终毛利的保护作用更直接、更刚性；耐储单品则采购价影响更大。**
