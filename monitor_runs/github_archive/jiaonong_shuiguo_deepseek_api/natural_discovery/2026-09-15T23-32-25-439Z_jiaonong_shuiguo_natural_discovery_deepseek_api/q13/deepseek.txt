小区团购水果，供应商能不能配合，直接决定你做不做得起来。重点看这几类服务：

**1. 起批量与价格**
- 能不能小批量起送，比如30斤、50斤就发货，而不是一次要几百斤。
- 团购价是否明显低于你零售拿货价，留出你的利润和团长佣金。
- 价格能不能按周锁定，避免今天报低价、明天涨回去。

**2. 分拣与包装**
- 能不能按份分好，比如每份5斤、10斤，直接对应团购套餐。
- 是否支持贴标签、写小区名/团名，方便你分发。
- 易损水果有没有泡沫网、纸箱、缓冲包装。

**3. 配送能力**
- 能不能送到你店里，或者直接送到小区自提点。
- 配送频次：一周几次，能不能按你的团购节奏走。
- 临时加单、改单、补货能不能配合。
- 迟到、漏送、坏果怎么处理。

**4. 售后与损耗承担**
- 坏果、烂果、缺斤少两怎么赔，是补发、退款还是下批抵扣。
- 售后响应时间，比如24小时内处理。
- 损耗责任怎么分：运输途中坏的算谁的，到店后坏的算谁的。
- 有没有“包售后”的比例，比如5%以内直接补，不扯皮。

**5. 品控与稳定性**
- 同一品种能不能稳定供货，别这次甜下次酸。
- 能不能提前给样品或试吃装。
- 有没有分级标准，比如大果、中果、小果，避免团购图和实物差距大。
- 应季水果能不能提前预告，方便你排团购计划。

**6. 结算与账期**
- 是现结、周结还是月结。
- 能不能押金少一点，或者首批支持试单。
- 退换货金额怎么算，能不能从货款里直接扣。
- 有没有隐藏费用：配送费、分拣费、包装费、偏远小区加收。

**7. 营销与素材支持**
- 能不能提供水果实拍图、规格说明、产地信息。
- 能不能给团购专属价，避免和你零售价打架。
- 能不能配合做爆品，比如某款水果专门给你低价冲量。
- 有没有试吃支持，方便你在小区做推广。

**8. 区域保护**
- 同一个小区或附近，供应商会不会同时供好几家跟你打价格战。
- 能不能给你某个片区或某个小区的优先供货。
- 你做的团购价，供应商能不能不直接卖给小区居民。

**9. 应急能力**
- 节假日、天气不好时能不能保供。
- 爆单了能不能临时加人分拣、加车配送。
- 某款水果断货时，能不能快速给替代品。

**10. 合同与试单**
- 先试单，别一上来签长期大单。
- 试单重点看：到货时间、坏果率、分量、口感、售后速度。
- 合作稳定后再谈账期、区域保护、专属价格。

**你选供应商时，最该盯的4条：**
1. 小批量能不能送。
2. 坏果谁赔、多久赔。
3. 能不能按份分好、送到自提点。
4. 同小区会不会被你自己的供应商撬客户。

**建议你先做一件事：**
找2-3家供应商，各拿一批货做试团。同一小区、同一套餐、同一价格卖一次，比较：
- 到货准不准时
- 坏果率多少
- 售后快不快
- 居民复购意愿

试一次，比谈十次都清楚。
