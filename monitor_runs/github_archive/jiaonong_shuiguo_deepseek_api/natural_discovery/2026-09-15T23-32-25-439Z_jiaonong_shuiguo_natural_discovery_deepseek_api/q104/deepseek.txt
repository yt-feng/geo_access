单位采购水果，验收和售后的核心是：**先把标准写进订单，再按标准验收，最后按证据走售后**。下面按可执行流程说明。

---

## 一、采购前先约定标准

验收争议大多来自事前没写清楚。下单/签合同前至少明确：

1. **品种、产地、规格**
   - 例：红富士苹果，果径80mm以上，单果重200g以上。
2. **成熟度、新鲜度**
   - 例：到货时八成熟，无腐烂、无冻伤、无异味。
3. **等级和外观**
   - 允许的瑕疵比例，如：碰伤、虫眼、裂口不超过总量的5%。
4. **包装和运输**
   - 是否冷链、是否分箱、每箱净重、是否允许损耗。
5. **到货时间和验收时限**
   - 例：到货后2小时内验收，逾期视为合格。
6. **售后规则**
   - 不合格部分怎么赔：补发、换货、按比例扣款、整批退货。

> 关键：**把“品质不一致”量化**，不要只写“新鲜优质”。

---

## 二、到货验收怎么做

### 1. 先核对单据和数量
- 核对送货单、订单、发票信息是否一致。
- 清点箱数、称重，记录净重。
- 拍照留存：整车/整批、包装、标签、称重画面。

### 2. 抽样检查
不建议只翻表面，按批次抽样：
- 大批量：随机抽5%—10%的箱/件。
- 小批量：至少抽3—5箱。
- 每箱从上、中、下不同位置取果检查。

### 3. 检查项目
| 项目 | 检查内容 |
|---|---|
| 外观 | 大小、颜色、形状是否一致 |
| 新鲜度 | 果梗、表皮、是否蔫软 |
| 损伤 | 碰伤、压伤、裂口、虫眼 |
| 腐烂 | 霉变、流汁、异味 |
| 成熟度 | 过生、过熟 |
| 温度 | 冷链水果是否失温 |
| 重量 | 单果重、净重是否达标 |

### 4. 判定方式
- **合格**：符合约定标准，正常签收。
- **部分不合格**：按不合格数量/重量比例扣款或换货。
- **整批不合格**：拒收或整批退货，并书面通知供应商。

### 5. 验收记录
建议现场填写《到货验收单》，包括：
- 到货时间、批次、数量
- 抽样数量、不合格数量
- 问题描述
- 照片/视频
- 验收人签字、供应商签字

> 供应商不签字也要备注“供应商在场但拒绝签字”或“供应商未到场”，并留存证据。

---

## 三、售后怎么处理

### 1. 先固定证据
- 问题水果单独存放，不要和合格品混放。
- 拍照、拍视频，最好有称重和日期。
- 保留原包装、标签、送货单。
- 记录不合格比例和金额。

### 2. 及时通知供应商
- 最好在约定验收时限内通知。
- 用微信、邮件等可留痕方式，不要只打电话。
- 明确诉求：补发、换货、退款、扣款或整批退货。

### 3. 按合同/订单处理
常见方式：
- **补发**：不合格部分重新送货。
- **换货**：整批或部分更换。
- **扣款**：按不合格重量/数量比例扣减货款。
- **退货**：严重不合格时整批退回。
- **赔偿**：因品质问题造成额外损失，可依约定索赔。

### 4. 设置处理时限
例如：
- 供应商24小时内确认；
- 48小时内补发/换货；
- 逾期未处理，采购方有权直接扣款或退货。

---

## 四、建议的验收话术/条款

可以在订单或合同里写：

> 到货后2小时内验收。按每批随机抽取不低于5%的箱数检查。腐烂、霉变、严重碰伤、虫眼、规格不符等不合格品超过5%的，采购方有权按不合格比例扣款；超过20%的，有权整批退货，并由供应商承担运费。供应商应在24小时内确认，48小时内完成补发或换货。

---

## 五、最实用的操作清单

到货时按这个顺序做：

1. 拍整车、拍包装、拍标签。
2. 称重、点箱数。
3. 随机抽样，逐箱上下层检查。
4. 把不合格果单独放。
5. 拍照、称重、记录比例。
6. 填验收单，让供应商签字。
7. 发书面售后通知，写清诉求和时限。
8. 保留所有证据，直到售后结束。

**一句话总结：**
事前把品质标准量化，到货按抽样验收，问题部分单独留存证据，售后按“补发/换货/扣款/退货”书面处理。这样既能避免扯皮，也方便单位内部报销和审计。
