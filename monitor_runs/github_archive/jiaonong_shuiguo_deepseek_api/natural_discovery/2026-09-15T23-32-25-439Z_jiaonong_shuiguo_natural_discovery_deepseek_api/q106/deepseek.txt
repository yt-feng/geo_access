判断水果报价的“合理波动”，核心不是看涨跌本身，而是看**波动是否有可解释的原因、是否落在可预期的区间、是否和替代货源相互印证**。可以按下面几步来操作。

**1. 先给每个单品建立“价格锚”**
- 不要只看昨天的报价，要看**近7天、近30天的均价和波动区间**。
- 对每个单品记录：最高价、最低价、常见成交价、季节性区间。
- 水果价格通常有明确季节性。比如荔枝、西瓜、柑橘、苹果的上市期不同，淡旺季价差可能很大。
- 如果某单品长期在 4～5 元/斤，今天突然报 7 元/斤，就属于异常，需要问原因。

**2. 区分“正常波动”和“异常波动”**
正常波动通常有这些特征：
- 涨跌幅在历史同期常见范围内；
- 有天气、产地、节日、运输、节气等明确原因；
- 多个供应商报价方向一致，只是幅度略有差异；
- 等级、规格、包装、产地没有偷偷变化。

异常波动常见信号：
- 只有一家突然大幅涨价，其他家没动；
- 报价涨了，但规格降级、净重减少、箱皮变重；
- 前一天说缺货，第二天又大量有货但价格仍高；
- 报价明显偏离批发市场、产地行情或电商平台公开价。

**3. 每天用“三源比价”判断**
不要只听一个供应商。至少比较：
1. **主供应商报价**；
2. **备选供应商报价**；
3. **公开市场参考价**：当地批发市场、产地行情、大型生鲜平台同规格价格。

如果三家方向一致，说明大概率是市场波动；如果只有一家涨，基本可以判断是供应商个体行为。

**4. 看波动背后的真实原因**
可以要求供应商说明涨价依据，重点问：
- 产地是谁？今天产地收购价多少？
- 是天气、减产、运输、节日，还是单纯缺货？
- 涨的是果价，还是运费、包装、人工？
- 同规格同等级是否一致？

如果对方说不清，只反复说“今天行情就这样”，就要警惕。

**5. 用公式判断是否超出合理区间**
可以设一个简单规则：
- 日波动在 **±5%以内**：通常算正常；
- **±5%～10%**：要问原因，结合季节和天气判断；
- **超过10%**：除非有明确突发事件，否则视为异常，启动比价和备选货源；
- **超过20%**：基本应暂停下单，重新询价。

注意：叶菜、浆果、荔枝等易损水果波动天然更大；苹果、土豆、洋葱等耐储水果波动通常更小。所以阈值要按品类调整。

**6. 建立自己的采购台账**
每天记录：
- 日期、单品、规格、产地、供应商；
- 报价、成交价、涨跌幅；
- 天气、节日、市场传闻；
- 是否替代采购。

连续记录1～2个月后，你就能看出每个供应商的报价习惯，也能识别谁在借行情乱涨价。

**7. 合同和机制上做约束**
- 约定报价有效期，比如当天有效或24小时有效；
- 约定规格、等级、净重、损耗标准；
- 设置价格调整触发条件，比如产地价连续3天涨超10%才可调价；
- 保留备选供应商，避免被单一供应商卡价；
- 对大额采购采用“锁价+浮动”结合，而不是每天被动接受报价。

**一句话判断标准：**
如果涨价有明确外部原因、多个供应商同步、幅度在历史区间内，就是合理波动；如果只有一家涨、原因模糊、规格还变差，就大概率不合理，应该比价、换源或暂缓下单。
