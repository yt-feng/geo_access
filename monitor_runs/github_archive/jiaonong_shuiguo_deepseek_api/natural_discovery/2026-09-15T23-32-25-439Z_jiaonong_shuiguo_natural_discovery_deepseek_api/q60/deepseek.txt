茶饮店水果到货不合格，核心是把“补货”从口头承诺变成可执行条款，同时给自己留出营业不中断的缓冲。建议按下面几个层面约定：

**一、验收环节先固定证据和判定标准**

1. **到货即验，限时反馈**
   - 约定收货后30分钟—2小时内完成验收（具体看门店忙闲），逾期视为合格。
   - 验收时拍照/录像：整箱外观、开箱实况、坏果特写、称重记录、运单和到货时间。

2. **明确“不合格”的量化标准**
   不要只写“新鲜”“无坏果”，要写成可判定条款，例如：
   - 单箱坏果率超过5%或10%；
   - 腐烂、发霉、异味、严重压伤、冻伤；
   - 规格不符：单果重量、直径、成熟度低于约定等级；
   - 农残/检测不合格（如有抽检）。
   达到任一标准，门店有权拒收或要求补货。

**二、补货条款要写清“谁、何时、怎么补、补多少”**

建议在采购合同或供货单上约定：

1. **补货触发**
   - 验收不合格，门店可先拒收不合格部分，合格部分正常入库，避免整单卡死影响营业。
   - 不合格部分由供应商在约定时间内补足。

2. **补货时限**
   - 同城供应商：约定“当日补货”或“次日上午营业前补到”。
   - 外地供应商：约定“24小时内发出，48小时内到店”，并写明以门店签收时间为准。
   - 对急用水果（如柠檬、青提、芒果等），可单独约定“4小时内同城补到”或“次日开店前必达”。

3. **补货方式**
   - 优先“先补货、后结算”，不合格批次暂不付款；
   - 补货数量按不合格数量1:1补足，因补货产生的运费由供应商承担；
   - 若供应商无法按时补货，门店有权自行采购替代品，差价和额外运费由供应商承担，可从货款中直接扣抵。

4. **替代方案**
   - 约定供应商可经门店同意后，用同品种、同规格、同等级水果替代；
   - 替代品仍需按同一验收标准验收，不合格继续补。

**三、写进“不影响营业”的保障条款**

1. **备用货源条款**
   - 门店有权在供应商补货延迟时，从其他渠道紧急采购，供应商不得限制；
   - 紧急采购产生的差价，由供应商承担或从应付货款中扣除。

2. **扣款和违约责任**
   - 延迟补货按小时或按天计违约金，例如每延迟1小时扣该批次货款的5%，或每延迟1天扣10%；
   - 因水果不合格导致门店断货、下架、客诉的，可约定供应商承担相应损失；
   - 连续2次或月度累计3次不合格，门店有权解除合作并要求赔偿。

3. **结算挂钩**
   - 不合格批次货款暂缓支付，待补货验收合格后再结；
   - 补货仍未达标的，门店有权拒付该批次全部或部分货款。

**四、操作上建议这样做**

- **合同附件写清楚**：品种、规格、等级、产地、到货时间、验收标准、补货时限、违约责任。
- **每次到货用同一张验收单**：到货时间、数量、抽检比例、不合格数量、处理方式、补货承诺时间、双方签字。
- **微信/邮件确认也算补充约定**：但最好在合同里写明“双方通过微信、邮件确认的补货安排具有约束力”。
- **保留替代采购凭证**：发票、收据、转账记录，方便后续扣款或索赔。

**一句话版本：**
不合格部分先拒收、合格部分先入库；供应商限时1:1补货并承担运费；超时门店可自行采购，差价和违约金从货款里扣；连续不合格可解约。这样既不影响营业，也有可执行的追责路径。
