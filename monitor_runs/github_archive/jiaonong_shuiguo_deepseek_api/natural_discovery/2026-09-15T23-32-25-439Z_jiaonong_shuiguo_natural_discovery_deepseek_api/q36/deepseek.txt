建议不要二选一，而是按门店客群和损耗能力做组合：**整果做引流和低损耗基本盘，切果做毛利和便利增量，但切果比例要严格控制。**

可以直接按下面逻辑判断：

1. **先看门店客群**
   - 社区店、家庭客多：整果为主，切果为辅。家庭更愿意买整果，单价低、耐放。
   - 商圈店、写字楼店、年轻人/单身客多：切果比例可以提高，切好即食、下午茶场景更强。
   - 学校、医院、交通枢纽附近：切果通常更好卖，但要看是否有冷藏条件和现场加工条件。

2. **看损耗和运营能力**
   - 整果损耗低，但周转慢会黑心、腐烂。
   - 切果损耗高，暴露面大、易出水、易变质，必须冷链、及时折价、限时清货。
   - 如果没有冷藏柜、没有专人打理、不能做到当天切当天清，切果不建议做多。

3. **看毛利结构**
   - 整果：毛利通常较低，但适合做价格形象、吸引客流。
   - 切果：有加工溢价，毛利更高，但扣掉损耗、人工、包材后未必高。
   - 关键不是“切果毛利高不高”，而是**切果损耗率能不能压住**。一般切果损耗和折价如果控制不好，很容易把溢价吃光。

4. **建议的实操比例**
   - 先按 **整果 70%—80%，切果 20%—30%** 试。
   - 商圈/年轻客群店可调到 **整果 50%—60%，切果 40%—50%**。
   - 社区家庭店建议 **整果 80%以上，切果少量试销**。
   - 试销两周，看三个数：切果售罄率、折价率、综合毛利。售罄率低或折价率高，就减切果。

5. **具体做法**
   - 整果：分规格卖，小果做低价引流，大果做家庭装。
   - 切果：只切成熟度合适的果，别拿快坏的果切，否则口感差、投诉多。
   - 切果做成小份、透明盒、标时间，当天清。
   - 下午高峰前切，不要早上大量切。
   - 切果可搭配其他水果做拼盘，提高客单和周转。

6. **判断结论**
   - 如果门店客群偏家庭、没有强冷链、人手紧：**以整果为主，切果少量试。**
   - 如果门店在商圈/写字楼、年轻人多、有冷藏和现场加工条件：**整果+切果组合，切果可做到三到五成。**
   - 最稳的做法不是选一种，而是：**整果保客流和低损耗，切果提毛利和便利，按数据动态调比例。**
