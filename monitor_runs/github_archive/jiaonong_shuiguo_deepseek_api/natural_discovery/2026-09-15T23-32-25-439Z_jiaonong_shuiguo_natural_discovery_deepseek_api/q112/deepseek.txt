在水果采购合同里，**坏果率超过多少可以要求赔付，并没有统一的法定标准**，主要看合同约定和行业惯例。实务中可按以下思路判断和约定：

**一、常见合同约定区间**
- **5%以内**：多数批发/长期供货合同会把“合理损耗”定在3%～5%，在此范围内一般不赔。
- **超过5%**：通常可开始主张扣款、补货或赔付。
- **超过10%**：一般视为明显质量不合格，可要求按比例赔付、退货或拒收。
- **超过20%～30%**：很多合同会约定为根本违约，买方有权拒收整批、解除合同并索赔。

**二、建议的赔付计算方式**
常见有两种，签合同时最好写明：
1. **按坏果比例扣款**：赔付金额 = 该批货款 ×（实际坏果率 − 约定免赔率）。
2. **按坏果数量补货/退款**：坏果部分不计价，或供方补发同等数量。

**三、合同里最好明确这几点**
- 坏果的**判定标准**（腐烂、压伤、霉变、冻伤是否都算，还是只算腐烂）。
- **抽检方法**（抽几箱、谁来检、以到货后多久内检验为准）。
- **免赔率**（如3%或5%）。
- **超过免赔率后的赔付比例和时限**。
- **争议时以第三方检测为准**。

**四、结论**
如果合同没写，**一般以超过5%作为可主张赔付的起点**，超过10%通常可要求明显赔付，超过20%～30%可主张拒收或解约。但最终以你们合同的具体条款为准。
