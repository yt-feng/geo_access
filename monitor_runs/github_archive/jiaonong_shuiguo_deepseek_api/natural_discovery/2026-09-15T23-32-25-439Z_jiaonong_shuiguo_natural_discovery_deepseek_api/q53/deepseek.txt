餐饮店每天少量水果，最省心的通常不是“找最便宜的”，而是找**稳定、能小批量配送、售后不扯皮**的渠道。可以按这个优先级选：

1. **本地水果批发市场里的固定档口**
   - 适合：每天几斤到几十斤、品类常换。
   - 省心点：可以当天补货，能看货，坏果一般能换。
   - 做法：固定1家主档口 + 1家备选，谈好“每天几点前下单、几点送到、坏果怎么赔”。
   - 注意：别只找最便宜的，要选愿意给你留好货、能临时加单的。

2. **本地生鲜配送平台/B2B平台**
   - 如美团优选商家版、美菜、快驴这类，具体以你所在城市开通为准。
   - 适合：不想自己跑市场，想要线上下单、次日达。
   - 省心点：价格透明、开票方便、售后流程化。
   - 注意：少量订单可能起送费高，品质波动要看评价，先试一周再定。

3. **本地果园/合作社直供**
   - 适合：有固定单品需求，比如每天要西瓜、柠檬、橙子。
   - 省心点：源头价、新鲜度好。
   - 注意：通常起订量高、配送不稳定，少量需求不一定愿意接。可以几家小店拼单。

4. **周边超市/便利店代采**
   - 适合：极少量、临时缺货。
   - 省心点：随时能买。
   - 注意：成本高，不适合长期。

5. **社区团购团长/本地跑腿代买**
   - 适合：每天量很小、品类不固定。
   - 省心点：灵活。
   - 注意：品质和时效不稳定，只能当补充。

**建议你这样定供应商：**

- 先列需求：每天大概几斤、要几种、几点要到、能接受什么价格。
- 找3个渠道各试3天：批发档口、B2B平台、果园/合作社。
- 重点看4件事：
  1. 能不能每天稳定送；
  2. 坏果是否包换；
  3. 临时加单能不能接；
  4. 能不能月结或开票。
- 最后固定“1主1备”：主供应商负责日常，备用的防断货。

**最省心的组合：**
本地批发市场固定档口做主力，生鲜B2B平台做备用。量特别少时，直接让档口每天顺带送，比你自己跑市场省事很多。

签合作前最好用微信文字确认：品种、规格、单价、配送时间、坏果赔付、临时加单规则。这样后面不容易扯皮。
