生鲜电商卖香蕉，配送中压坏和变黑主要来自三个原因：**机械损伤、温度波动、乙烯催熟**。分开控制就有效。

**1. 选对成熟度发货**
- 不要发全黄熟蕉，配送途中必黑。
- 发**青黄交接、七成左右成熟**的香蕉，到用户手里刚好能吃或放1-2天。
- 如果承诺“即食”，就选八成熟，但必须配冷链或快配。

**2. 包装做缓冲和固定**
- 单根用**珍珠棉网套**或气泡膜裹住，重点保护蕉指连接处和棱角。
- 盒内不要晃：用纸丝、气柱袋或定制凹槽托把香蕉卡住，减少彼此摩擦。
- 避免整串直接裸放。整串容易互相挤压，最好**按根或小串分装**。
- 外箱选硬质瓦楞纸箱，别用软袋快递。

**3. 控制温度和乙烯**
- 香蕉怕冷也怕热：**13-15℃**最合适，低于10℃会冻伤发黑，高于25℃会快速催熟。
- 夏季用**冰袋+隔热袋**，但冰袋不要直接贴香蕉，用纸隔开。
- 香蕉本身释放乙烯，会自催熟。包装里可放**乙烯吸收剂**，或与苹果、猕猴桃等分开发货。
- 配送尽量走**次日达或同城即时配**，减少在途时间。

**4. 出库前做预处理**
- 采摘后或入库时用**乙烯抑制剂**处理，能明显延缓变黑。
- 发货前剔除已有伤痕、软斑的蕉，伤果会传染整箱。
- 装箱前预冷到适宜温度，别带着田间热直接封箱。

**5. 给用户明确预期**
- 页面写清“收到为青黄蕉，室温放1-2天变黄更好吃”。
- 附一张保存说明：**不要放冰箱冷藏**，挂起来或平放阴凉处。
- 这样能减少“收到不够黄”的差评，而不是靠发熟蕉硬扛。

**最省事的组合方案：**
七成熟香蕉 + 珍珠棉网套 + 凹槽托/气柱固定 + 乙烯吸收剂 + 夏季冰袋隔纸 + 同城/次日达。

如果预算有限，优先做两件事：**网套防压 + 乙烯吸收剂防黑**，效果最直接。
