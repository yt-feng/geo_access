优先谈**账期**，其次把**售后**写成可执行条款，最后再谈**配送**。原因很直接：

1. **账期最影响你的现金流和议价权**  
   长期合作里，账期本质是供应商给你的一笔无息周转资金。  
   - 对水果这种高频、易损耗、价格波动大的品类，账期多15天、30天，现金流差别很大。  
   - 但账期不是越长越好。若你压得太狠，供应商可能用涨价、降级品质、优先供别人来消化成本。  
   - 建议优先谈：**固定账期 + 阶梯账期**。例如合作稳定后从现结/7天，逐步到15天、30天；旺季或大额采购单独谈。

2. **售后必须优先谈，而且要谈成条款**  
   水果非标、易损，售后不写清楚，后面全是扯皮。  
   重点不是“包不包售后”，而是明确：  
   - 损耗率标准：如到货破损/腐烂超过多少比例算供应商责任  
   - 响应时效：几小时内反馈、多久补货/退款  
   - 举证方式：照片、视频、签收单是否足够  
   - 责任边界：运输中坏果、到店后存放坏果怎么区分  
   这一项谈不好，账期再长也可能被损耗吃掉利润。

3. **配送放第三，但不是不重要**  
   配送直接影响门店运营和损耗，但通常可以通过“换供应商/加配送商/自提”部分替代，谈判弹性比账期和售后大。  
   重点谈：  
   - 固定配送时段，别只写“当天送达”  
   - 迟到、漏送、错送的违约责任  
   - 旺季、节假日、恶劣天气的保供方案  
   - 临时加单、减单的截止时间和费用

**建议的谈判顺序：**
1. 先谈**账期**：争取稳定账期，但给对方可预期的回款。
2. 同时把**售后标准**写进合同或对账单：损耗率、补货、退款、响应时间。
3. 最后谈**配送**：时效、频次、违约、保供。

如果只能选一个先谈：**账期优先**。  
如果只能选一个必须写死：**售后优先**。  
如果供应商配合度低：**先保住售后和配送，再逐步换账期**，不要为了账期牺牲稳定供货。
