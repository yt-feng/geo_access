做餐饮客户（尤其是茶饮、甜品、烘焙、酒店自助、快餐）和做零售散客的选品逻辑不一样，餐饮要的是**稳定、出成率高、好加工、能标准化**。下面按菠萝和香蕉分别说规格。

## 菠萝（餐饮主用途：鲜切、菠萝炒饭、饮品、甜品装饰）

餐饮客户最看重两点：**出肉率**和**甜度稳定**。建议按用途备三档：

**1. 鲜切/果盘/自助餐——要大果、果眼浅**
- 品种优先：金钻凤梨（台农17）、甜蜜蜜凤梨，免挖眼、出肉率高
- 规格：单果 **1.2–1.8kg**
- 成熟度：**7–8 成熟**到货，便于档口控后熟
- 卖点：切开即用、无涩口、糖度 14–16 度

**2. 茶饮/果汁/菠萝水——要酸甜平衡、出汁多**
- 品种：金钻或巴厘菠萝均可，但要求糖酸比稳定
- 规格：单果 **0.8–1.2kg**，可做小果走量
- 成熟度：**8–9 成熟**，香气足、出汁率高
- 注意：茶饮店常要求批次糖度一致，最好能报“糖度范围”

**3. 菠萝炒饭/烘焙馅料——可接受加工果**
- 规格：**去皮菠萝块/菠萝丁**，或中等果 **1–1.5kg**
- 要求：果肉偏硬、耐炒、不易烂
- 可备：冷冻菠萝丁作为补充，解决淡季和损耗问题

**档口建议备货比例**：鲜切大果 50%、茶饮中果 30%、加工果/冻品 20%。  
报价时直接给“单果重区间 + 糖度 + 是否免挖眼 + 去皮出成率”，餐饮采购最容易下单。

## 香蕉（餐饮主用途：早餐、果盘、烘焙、奶昔、员工餐）

餐饮用香蕉核心是**规格统一、后熟可控、不易断货**。香蕉不能只按“斤”卖，要按**条重和成熟度**分。

**1. 果盘/酒店自助/早餐——要外观好、大小均匀**
- 规格：**单条 120–150g**，每把 5–6 条
- 成熟度：到货 **3–4 成熟**，档口自己催熟到 6–7 成熟上架
- 要求：条形直、无黑斑、无擦伤

**2. 奶昔/烘焙/香蕉船——要大果、出肉多**
- 规格：**单条 150–200g**
- 成熟度：**7–8 成熟**，甜度高、香气足
- 可接受：轻微斑点果，价格更低，适合加工

**3. 快餐/员工餐/走量——要性价比**
- 规格：**单条 100–130g**，或按箱走
- 成熟度：**5–6 成熟**，方便短期周转
- 包装：**13kg/箱**左右是常见批发规格，也可按 10kg、12kg 分装

**关键提醒**：香蕉是后熟水果，餐饮客户最怕“今天到货明天全黑”。所以你要能提供：
- 到货成熟度
- 催熟建议（温度、天数）
- 不同成熟度对应什么用途

最好把香蕉分成 **生果档、即用档、加工档** 三类，而不是混在一起卖。

## 给批发档口的实操建议

1. **先问客户用途**：鲜切、饮品、烘焙、员工餐，规格完全不同。
2. **做一张规格卡**：品名、品种、单果/单条重、成熟度、糖度、包装、建议用途、出成率。
3. **菠萝主推“免挖眼 + 出肉率”**，香蕉主推“条重均匀 + 后熟可控”。
4. **搭配冻品/半成品**：菠萝丁、香蕉泥，能提高餐饮客户黏性。
5. **小批量试单**：先给茶饮店、早餐店、快餐店各送一箱试，稳定后再签周配。
