可以按“引流款 + 利润款 + 搭配款”做组合，不要只做单一降价。香蕉、菠萝、苹果的促销目标不同：

**1. 香蕉做引流，但不单独贱卖**
- 香蕉是高频、价格敏感品，适合做“限量引流价”。
- 例如：香蕉 1.99 元/斤，限购 3 斤，放在水果区入口。
- 目的不是靠香蕉赚钱，而是把人引到水果区。

**2. 菠萝做搭配和现场感**
- 菠萝适合做“现场削皮/切块试吃”，提升购买欲望。
- 组合方式：
  - 买整颗菠萝，加 3 元换购削皮切块服务或小份苹果。
  - 菠萝 + 苹果做“酸甜果切拼盘”，按盒卖，毛利通常高于整果。
- 菠萝客单价提升点在于：从“买一颗”变成“买果切、拼盘、酸奶搭配”。

**3. 苹果做利润和家庭装**
- 苹果耐放、认知度高，适合做家庭装、礼盒装、分级卖。
- 组合方式：
  - 香蕉 + 苹果 + 菠萝 = “家庭水果周套餐”，比如 19.9 元/份。
  - 苹果单独做 5 斤家庭装、10 斤箱装，价格比散卖略低，但客单价更高。
- 用苹果拉高整体毛利，不要用苹果做最低价引流。

**4. 推荐三种可直接执行的促销组合**

**组合 A：9.9 元尝鲜包**
- 香蕉 2 根 + 苹果 2 个 + 菠萝切块 1 盒。
- 适合放在收银台附近或水果区端头。
- 作用是降低尝试门槛，带动果切和搭配购买。

**组合 B：19.9 元家庭水果包**
- 香蕉 1 把 + 苹果 4 个 + 菠萝 1 颗。
- 适合家庭客群，强调“一周水果一次买齐”。
- 比单买便宜 3—5 元，但客单价从几元提到 20 元左右。

**组合 C：满 29 元加 3 元换购**
- 买香蕉、苹果、菠萝任意组合满 29 元，加 3 元换购菠萝切块或苹果 2 个。
- 这是提高客单价最直接的方法：让顾客从买一样变成买三样。

**5. 陈列和话术**
- 入口：香蕉低价牌，写“限时引流”。
- 中间：菠萝试吃，写“现场削皮，免费切块”。
- 旁边：苹果家庭装，写“买整箱更划算”。
- 端头：组合套餐，写“香蕉+苹果+菠萝，一次买齐”。
- 员工话术：不要问“要不要香蕉”，而是说“今天菠萝很甜，加 3 元可以换购切块，和苹果一起做拼盘”。

**6. 关键判断指标**
- 看三个数：客单价、组合套餐销售占比、果切/菠萝切块销量。
- 如果香蕉卖得快但客单价没涨，说明只引流没转化，要加换购和套餐。
- 如果菠萝切块卖得好，就扩大果切区。
- 如果苹果家庭装卖得好，就主推整箱和礼盒。

**7. 不建议的做法**
- 三个都降价，会互相抢销量，毛利整体下滑。
- 香蕉无限量低价，容易被大爷大妈扫空，带不来其他品类销售。
- 组合套餐太复杂，顾客算不清，执行也难。

最简方案：**香蕉限购低价引流，菠萝试吃切块做转化，苹果家庭装做利润，再设“满 29 加 3 元换购”拉客单价。**
