批发商担心到货损耗高，核心是把“坏果怎么认定、谁来承担、怎么赔、怎么防止扯皮”写进合同。建议在合同中单独设一条“到货验收与坏果责任”，不要只写一句“坏果由卖方负责”，否则容易无法执行。

可以按下面结构写：

**1. 明确验收标准和时限**
- 货到目的地后多少小时内完成验收，例如“卸货后24小时内”。
- 逾期未验收视为合格，但隐蔽瑕疵除外。
- 验收地点、验收人、联系方式写清楚。
- 双方可共同验收，或委托第三方检验。

**2. 明确坏果定义和计算方式**
不要只写“坏果”，要具体列明：
- 腐烂、发霉、流汁、严重压伤、冻伤、虫蛀、异味、开裂等。
- 按重量还是按件数计算损耗率。
- 抽样比例和抽样方法，例如“按每车随机抽取10箱，每箱抽检10%”。
- 以抽检结果推算整批，还是逐箱全检。

**3. 约定允许损耗率和责任分界**
- 例如：运输合理损耗在3%以内由批发商承担，超过3%部分由供货方承担。
- 或：到货坏果率超过5%，供货方按超出部分赔偿。
- 若因冷链、包装、装卸导致，责任归供货方或承运方，要写清楚。
- 若因批发商二次运输、储存不当导致，供货方不负责。

**4. 明确赔偿方式**
常见有三种，选一种或组合：
- 按坏果重量/件数直接扣款。
- 补发同等数量合格货。
- 按合同单价的1倍至2倍赔偿，具体倍数双方谈。
建议写公式，例如：
“赔偿金额 =（实际坏果率 - 允许坏果率）× 到货总重量 × 合同单价。”
这样比“酌情赔偿”可执行。

**5. 明确举证责任和检验费用**
- 谁主张坏果，谁先拍照、录像、保留样品。
- 双方对结果有争议时，送约定的第三方检测机构。
- 检测费先由谁垫付，最终由责任方承担。
- 超过约定时间未提出异议，视为验收合格。

**6. 明确与运输、保险的衔接**
- 若承运人造成损坏，供货方先向批发商赔，再向承运人追偿。
- 若已投保，保险赔付不足部分由责任方补足。
- 不要写“保险赔了就不管”，否则批发商仍可能吃亏。

**7. 写清例外情形**
- 不可抗力、极端天气、疫情管控等，可免责或部分免责。
- 但供货方不能把“本身质量差”说成不可抗力。
- 批发商未按约定收货、卸货、冷藏导致的扩大损失，自行承担。

**一个可直接套用的条款示例：**

> 到货验收与坏果责任  
> 1. 买方应在货物到达约定地点后24小时内完成验收，并书面或拍照记录。逾期未提出异议的，视为验收合格，但隐蔽瑕疵除外。  
> 2. 坏果包括腐烂、发霉、流汁、严重压伤、冻伤、虫蛀、异味等不符合约定质量标准的水果。坏果率按重量计算。  
> 3. 双方约定合理损耗率为3%。坏果率在3%以内的，由买方承担；超过3%的部分，由卖方按以下方式赔偿：赔偿金额=（实际坏果率-3%）×到货总重量×合同单价。  
> 4. 买方应在验收时拍照、录像并保留样品。双方对坏果率有争议的，送双方认可的第三方机构检测，检测费由责任方承担。  
> 5. 因卖方包装、冷链、装卸或货物本身质量原因导致的坏果，由卖方负责；因买方二次运输、储存不当导致的扩大损失，由买方负责。  
> 6. 卖方应在确认责任后7日内完成补货或退款。

**谈判时重点抓三件事：**
1. 坏果率怎么算，必须具体。
2. 超过多少谁承担，必须写数字。
3. 争议怎么检验、多久提异议，必须写流程。

如果对方只肯写“坏果协商解决”，对批发商基本没有保障，尽量改成“按抽样比例计算、超过约定损耗率由卖方按公式赔偿”。
