如果只能排一个优先级：**食品安全优先，其次是配送准时，最后才是价格。**

理由很直接：

1. **食品安全是底线，出问题成本最高**
   企业食堂一旦发生农残超标、霉变、腐烂水果混入等问题，影响的是员工健康，后果可能包括投诉、停工、赔偿、监管处罚和品牌受损。水果很多是即食或简单清洗后食用，风险比需要高温加工的食材更直接。

2. **配送准时直接决定食堂能不能正常开餐**
   水果通常不是主菜，但如果用于餐后配餐、果切、会议茶歇，迟到就会打乱出餐和供应计划。尤其夏天，配送延迟还会增加变质风险。

3. **价格重要，但不能凌驾于前两者**
   水果价格波动大，采购当然要控成本。但如果为了低价牺牲新鲜度、来源可追溯性或配送稳定性，最后往往用投诉、损耗和更换供应商的成本补回来。

实操上建议这样排序和权衡：

- **先设食品安全门槛**：供应商资质、检测报告、农残快检、冷链/仓储条件、验收标准，不达标直接淘汰。
- **再考核配送能力**：准时率、缺货率、异常处理速度、旺季保障能力。
- **最后比价格**：在合格供应商之间比价，而不是拿所有供应商一起比最低价。
- **综合评分示例**：食品安全 50%，配送准时 30%，价格 20%。如果是夏季或果切需求高，配送和冷链权重还应再提高。

一句话结论：**食品安全是一票否决，配送准时是保障运营，价格是在前两项达标后的优化项。**
