学校食堂选水果供应商，核心不是“找最便宜的”，而是找**能稳定交付合格果品、能配合学校结算和验收流程、出问题能及时处理**的供应商。可以按下面几步判断和筛选。

**1. 先明确采购标准，再谈价格**
不同水果的验收标准要写清楚，否则后面扯皮：
- 香蕉：成熟度适中，青黄比例可控，无黑斑腐烂，单根长度和把型相对统一；最好能按周分批次熟化，避免同一天全熟。
- 苹果：果径分级明确，比如70/75/80，无碰伤、无虫眼、无腐烂，硬度尚可，品种稳定。
- 橙子：果径、皮厚、酸甜度、出汁率有基本要求，无青果、无烂果、无冻伤。
建议直接做一张《水果验收标准表》，写清品种、等级、单果规格、成熟度、允许损耗率、拒收条件。

**2. 供应商类型怎么选**
常见有三类：
- 一级批发商/产地直供：价格通常有优势，适合采购量大、有冷库或周转快的学校；但配送和售后可能不如本地配送商灵活。
- 本地水果配送商：配送及时、退换方便、能小批量多频次送货，适合大多数学校食堂；价格可能略高。
- 大型商超或供应链平台：流程规范、票据齐全，但价格通常偏高，适合应急或小额补充。

学校食堂一般优先选**本地配送商 + 产地直采结合**：主量走本地稳定配送，部分大宗水果在产季直采降成本。

**3. 重点看这几个能力**
- 配送能力：能否按学校要求的时间送到，比如每天早上6点前到食堂；迟到是否影响早餐/午餐供应。
- 冷链和仓储：香蕉、苹果、橙子对温度要求不同，香蕉怕冻，橙子怕冻伤，苹果相对耐储。供应商有没有分温区仓储很关键。
- 损耗处理：送到后发现烂果、规格不符，能否当天补换？损耗率超过约定怎么扣款？
- 票据合规：能否开正规发票，能否提供检验检疫、农残检测或产地证明。学校采购通常需要这些。
- 价格机制：是固定价、周报价还是随行就市？建议按周或半月报价，并约定波动幅度，避免一天一价。
- 结算账期：学校通常月结，供应商能否接受，是否加价。

**4. 实地考察和试供**
不要只看报价单。至少做三件事：
- 去供应商仓库或档口看：水果堆放是否分区，有没有烂果混放，冷库是否正常。
- 要近期供货案例：问他们给哪些学校、单位送过，配送频次和投诉处理怎么样。
- 试供2-4周：先小批量试，重点看准时率、果品合格率、补换速度、对账是否清楚。

**5. 比价时不要只比单价**
用“综合到货成本”比较：
综合成本 = 报价 + 损耗 + 退换货成本 + 配送不及时导致的应急采购成本 + 票据和结算成本。
有的供应商单价低，但损耗高、经常缺货，实际更贵。

**6. 合同里必须写清的条款**
- 品种、规格、等级、成熟度、允许损耗率；
- 配送时间、频次、临时加单响应时间；
- 验收方式：食堂现场验收，不合格当场拒收或扣重；
- 退换货时限：比如2小时内响应，当天补换；
- 价格调整机制和报价周期；
- 食品安全责任和票据要求；
- 结算周期和违约处理。

**7. 实操建议**
- 至少找3家供应商比价试供，不要长期只依赖一家。
- 主供应商 + 备用供应商，防止断供。
- 香蕉这类后熟水果，要求供应商按学校用量分批催熟，不要一次送全熟。
- 苹果、橙子可以适当加大单次采购量，但要有通风或冷藏条件。
- 每月做一次供应商评分：合格率、准时率、投诉次数、价格稳定性，连续差的淘汰。

简单说：**先定验收标准，再选本地稳定配送商，试供后再签合同，合同里把损耗、退换、配送和票据写死。** 这样比单纯找低价供应商更稳。
