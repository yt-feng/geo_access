提高客单价的核心不是“便宜”，而是让顾客**一次买更多、买更高价、顺手多带一件**。水果区用香蕉、菠萝、苹果做组合，建议按“引流—利润—搭配”三层来设计：

1. **香蕉做引流，不单独降价太狠**
   - 作用：香蕉是高频、敏感、易比价商品，适合吸引进店和带动关联购买。
   - 做法：  
     - 散称香蕉保持正常价或略低价，但设置“买香蕉加1元换购苹果1个/菠萝切块1盒”。  
     - 或“香蕉满5元，加3元换购菠萝切块”。  
   - 目的：用香蕉把人带到水果区，再用换购拉高单笔金额。

2. **苹果做利润和家庭装**
   - 作用：苹果耐放、家庭购买频次高，适合做规格升级。
   - 做法：  
     - 设置“小袋装/家庭装/礼盒装”三档：  
       - 小袋：3—4个，原价。  
       - 家庭装：8—10个，标“省X元”，但总价明显高于小袋。  
       - 礼盒装：高颜值包装，适合送礼，毛利更高。  
     - 组合：“苹果+香蕉=早餐果盒组合”，定价略低于单买总和，但高于顾客原本只买香蕉的金额。

3. **菠萝做搭配和场景触发**
   - 作用：菠萝单价感知高、香气强、有季节感，适合做“加购件”。
   - 做法：  
     - 整颗菠萝不主推，主推**去皮切块盒**，解决顾客嫌麻烦的问题。  
     - 组合：“苹果+菠萝切块”做沙拉组合；“香蕉+菠萝切块”做奶昔组合。  
     - 加购话术：买苹果/香蕉满额，加5—8元换购菠萝切块。

4. **推荐组合促销方案**
   - **方案A：早餐果盒组合**  
     香蕉1把 + 苹果4个 + 菠萝切块1盒，定价为单买总价的85%—90%。  
     适合上班族、家庭客，客单价通常能从只买香蕉提升到组合价。
   - **方案B：满额换购**  
     买香蕉满5元，加3元换购苹果2个；买苹果满15元，加5元换购菠萝切块。  
     作用是逐级抬客单，而不是一次打折到底。
   - **方案C：三件阶梯价**  
     任选1件原价，任选2件9折，任选3件8.5折。  
     注意：折扣只适合毛利足够的苹果和菠萝切块，香蕉可少参加或设上限。

5. **陈列和话术很关键**
   - 三个品类相邻陈列，但不要混成一堆。  
   - 组合商品用统一托盘/网袋/标签，标“组合价”“加购价”“省X元”。  
   - 店员话术：  
     “香蕉今天很新鲜，加3元可以换一盒菠萝切块，做奶昔刚好。”  
     “苹果家庭装更划算，再带一把香蕉就是早餐组合。”

6. **避免的坑**
   - 不要三个都做特价，否则销量涨、客单不涨、毛利还掉。  
   - 不要让香蕉承担全部折扣，香蕉只负责引流。  
   - 菠萝切块要控制损耗，最好按预估销量分批切。  
   - 组合价要高于顾客原本单买香蕉的金额，否则只是替代，不是提升客单。

简单执行版：  
**香蕉正常卖/略低价引流；苹果做家庭装提客单；菠萝切块做加购和组合；主推“香蕉+苹果+菠萝切块”早餐组合，标组合价并设满额换购。**
