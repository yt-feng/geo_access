结论先说：**进货量不大，优先考虑“批发市场 + 少量固定供应商”的混合模式，而不是一开始就死磕一个固定供应商。**

原因是：小店的核心矛盾是**现金流和试错成本**。量小的时候，固定供应商给你的价格优势有限，但会让你承担压货、起订量、品类单一的风险。

### 分阶段判断

**1. 刚开店 / 品类没跑通阶段**
- 更适合：**批发市场**
- 好处：起批量低、能现场看货、可以小批量试多个品类、现金结算灵活、随时换款。
- 适合服装、饰品、日用杂货、部分食品等“款式/品类变化快”的店。

**2. 已经知道哪些货好卖、销量稳定**
- 更适合：**固定供应商**
- 好处：价格更稳、补货快、可谈账期、品质一致、减少每次跑市场的时间。
- 适合复购高、标准化强的商品，比如包装材料、固定原料、常用耗材。

**3. 最优做法：混合**
- 主销、稳定的 20% 商品 → 固定供应商，谈长期价和账期。
- 新品、测试款、应急补货 → 批发市场。
- 这样既有价格和稳定供应，又保留灵活度。

### 怎么选，看这 4 个指标
- **起订量**：固定供应商要求太高，你资金会被压死。
- **补货速度**：卖得快的货，断货损失比进货价差更大。
- **品质稳定性**：客户会复购的品类，品质波动是致命的。
- **账期**：能给你 7–30 天账期的供应商，价值远高于便宜 3%。

### 实操建议
1. 先跑 2–3 次批发市场，把同类货的价格、质量、起批量摸清。
2. 从中挑 1–2 家沟通好的档口，问能不能“小批量长期拿”。
3. 同时找 1 家固定供应商，只供你最稳定、最好卖的单品。
4. 每次进货记录：进价、售罄天数、退货率、客户反馈。
5. 等某个单品月销量稳定后，再把它转到固定供应商，争取更低价格或账期。

### 一句话决策
- **量小、品类没定型** → 批发市场为主。
- **量小但已有稳定爆款** → 该爆款找固定供应商，其余走市场。
- **千万别**为了“看起来像长期合作”而接受高起订量、长账期、不可退换的固定供应商。
