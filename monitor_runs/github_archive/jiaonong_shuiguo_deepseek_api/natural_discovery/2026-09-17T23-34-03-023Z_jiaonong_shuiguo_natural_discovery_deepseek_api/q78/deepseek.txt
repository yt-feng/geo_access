香蕉和菠萝做社区团购，售后核心不是"卖出去"，而是**在损耗发生前就把它变成可预期、可分摊的成本**。给你一套可直接落地的做法。

## 一、先认清这两个品的损耗点不一样

**香蕉**：损耗主要在"催熟节奏"和"压伤"。到货太生卖不动，太熟当天烂，堆压一层就黑一片。
**菠萝**：损耗主要在"削皮损耗"和"黑心/烂心"。外观看不出来，切开才发现，属于验收阶段难发现的问题。

所以两者的售后策略要分开设计。

## 二、香蕉：用"熟度分级 + 预售锁量"控售后

1. **按熟度定价分级卖**
   - 青蕉（可放3-5天）走"家庭囤货装"，主打便宜；
   - 黄蕉（1-2天吃完）走"即食装"，当天自提。
   - 让客户自己选熟度，而不是你赌熟度。客户选了青蕉放坏了，售后责任清晰。

2. **倒推采购节奏**
   - 别一次进够3天的量。香蕉到货后第二天才到最佳口感，第三天开始风险陡增。
   - 按"到货日+2天"作为销售窗口，超窗口的货转为促销或员工消化，不要硬撑到第4天。

3. **减少压伤**
   - 分装时不要码超过2层，自提点用筐不用袋闷着。
   - 这条能直接砍掉一半的"到手就黑"投诉。

## 三、菠萝：把"切开风险"前置到规则里

1. **预售 + 现场削/或明确"不削"**
   - 如果团长现场削皮，削出来的坏果当场换，售后在提货点就解决，不到群里发酵。
   - 如果不削，就在商品页写清"菠萝不代削，黑心烂心包退"，降低客户预期差。

2. **设"开果凭证"规则**
   - 客户反馈坏果，要求拍"切开后的照片+外皮"，一张图判断，不用来回扯。
   - 这个规则提前写进群公告，后面执行不吵架。

3. **挑选比售后便宜**
   - 菠萝进货时抽检切开1-2个看黑心率，黑心率高的批次直接不接，别等卖出去再退。

## 四、通用的售后机制（两个品都能用）

- **坏果包退不包换情绪**：明确"拍照即退，无需退货"，小额直接退，别让客户跑一趟。省下的沟通成本比那几块钱值。
- **损耗率预算进定价**：高损耗品定价时把预期损耗（香蕉8%-15%、菠萝5%-10%）算进去，别指望零损耗。
- **预售制压库存**：先收单再进货，能卖多少进多少，这是社区团购对高损耗品最有效的杠杆。
- **售后数据留痕**：记录哪个批次、哪个供应商、哪天出的问题，连续出问题的供应商直接换，别反复交学费。

## 五、一句话判断标准

> 如果某个品的售后要靠"事后扯皮"解决，说明你定价时没把损耗算进去，或者没做预售。

把损耗当成**进货时就确定的成本**，而不是**卖完后才知道的意外**，售后自然就控住了。

需要的话，我可以帮你按"预售量-进货量-损耗率"做一个简单的定价和订货公式。
