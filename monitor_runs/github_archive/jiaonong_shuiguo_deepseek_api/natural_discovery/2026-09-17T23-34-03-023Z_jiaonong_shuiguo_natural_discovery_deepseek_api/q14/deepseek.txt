**通常能给的支持**
- **价格支持**：周末特价供货、满件返利、爆品直降、临期/尾货清仓价。适合做引流款，比如西瓜、香蕉、苹果、应季柑橘。
- **物料支持**：纸箱、周转筐、保鲜袋、海报、爆炸贴、价签、横幅、试吃盒、围裙/工牌等。品牌商或一级供应商更常见。
- **活动支持**：搭赠、试吃品、买赠、联合促销、堆头陈列物料、甚至派人驻场。
- **账期支持**：周末促销压货时，申请延后几天结算或临时提高授信额度。

**一般拿不到或很难拿的**
- 直接给现金补贴，除非你是连锁大客户或单品采购量很大。
- 定制化物料，小门店通常只能拿通用物料。
- 损耗兜底，水果损耗一般仍由门店承担。

**怎么谈更有效**
1. **提前 3-5 天谈**，不要周五才开口。
2. **明确量**：说清楚周末预计卖多少箱/斤，比“想搞活动”更容易拿到价。
3. **绑定主推单品**：选 2-3 个爆品集中要支持，不要全店都要。
4. **给供应商回报**：堆头位置、主推陈列、朋友圈/社群曝光、长期采购承诺。
5. **谈组合**：价格降一点 + 物料给一点 + 账期松一点，比只压价更容易成。
6. **留记录**：微信确认价格、数量、物料、结算时间，避免周末扯皮。

**现实判断**
- 小水果店：通常能拿到**少量特价 + 基础物料**，别预期太高。
- 有稳定采购量：可以谈**周末专供价、搭赠、陈列物料**。
- 连锁或大单：可以谈**返利、联合促销、驻场支持**。
