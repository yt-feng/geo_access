选哪种形态，主要看你的**菜单定位、出杯量、人工成本和稳定性要求**。直接给结论：

## 快速决策

| 你的情况 | 推荐 |
|---|---|
| 主打鲜果茶、客单价中高、有切配人力 | **鲜果**（现切） |
| 出杯量大、追求稳定、人手紧张 | **果丁（冷冻/糖渍）** |
| 做冰沙、奶昔、需要均匀口感 | **果泥** |
| 刚起步/小店/菜单不复杂 | 果丁，兼顾效率和成本 |

## 三者对比

**鲜果**
- 优点：卖点强、"现切鲜果"能支撑溢价，风味最自然
- 缺点：耗损高（菠萝削皮去芯损耗大）、依赖季节和成熟度、每天要切、出杯速度慢、不同批次酸甜不稳定
- 适合：精品店、招牌款、能做透明化展示的

**果丁（冷冻或糖渍）**
- 优点：开袋即用、标准化、损耗低、四季稳定、出杯快
- 缺点：糖渍款含糖需调配方；冷冻款风味略逊鲜果，解冻有出水问题
- 适合：绝大多数连锁/外带店的主力选择

**果泥**
- 优点：口感均匀、易调味、适合机器出品（冰沙、雪克）
- 缺点：缺少"嚼得到果肉"的体验，做果茶卖点弱；部分产品含添加
- 适合：冰沙类、混合风味茶、需要一致性的饮品

## 实操建议

1. **大多数茶饮店最优解：果丁打底 + 少量鲜果点缀**。用果丁保证稳定和效率，招牌款再加现切菠萝提升卖相和卖点。
2. **先小批量测试**：同一款茶分别用三种原料做盲测，看顾客反馈和你的出杯效率，再定采购比例。
3. **算清损耗账**：鲜果菠萝削皮去芯后净得率通常在 50%–60% 左右，别只按毛重算成本。
4. **注意菠萝蛋白酶**：鲜菠萝会让部分奶制品变苦、影响口感，做含奶饮品时鲜果要处理（如盐水/加热）或改用果丁/果泥。
