可以，但通常不是“默认一定会给”，而是要看**供应商实力、单品销量、合作条款、促销规模**。超市做水果促销时，供应商常见能提供的支持主要有这几类：

**1. 陈列支持**
- 提供**陈列道具**：堆头筐、藤编篮、展示架、分层托盘、假底、价签牌、插卡。
- 提供**陈列方案**：怎么堆、怎么分层、动线怎么摆、主推品放哪里。
- 派人**理货/补货/做形象**：尤其是一些品牌水果、进口水果、精品水果供应商。
- 争取**更好陈列位**：端头、主通道、收银线附近、水果区入口，这些往往需要供应商出费用或给政策。

**2. 海报/宣传支持**
- 提供**产品图片、文案、卖点**：产地、甜度、规格、吃法、营养卖点。
- 提供**海报、爆炸贴、跳跳卡、立牌、吊旗、地贴**等物料。
- 承担部分**DM海报费、广告费、促销档期费**。
- 配合做**线上宣传**：社群图、朋友圈素材、短视频素材、直播脚本。
- 有些供应商还能给**试吃台围挡、主题氛围物料**。

**3. 试吃支持**
- 提供**试吃果品**，这是最常见也最实际的支持。
- 提供**试吃台、牙签、纸杯、手套、托盘、垃圾桶**等耗材。
- 派**促销员/试吃员**驻场，或者承担促销员工资。
- 配合做**试吃话术、切果标准、试吃流程**。
- 承担试吃产生的**损耗**，这点一定要提前谈清楚。

**4. 费用与政策支持**
- **特价供货**：促销档期给更低进货价。
- **搭赠**：进10箱送1箱，用于试吃或引流。
- **损耗补贴**：水果易损，促销期间损耗谁承担要写明。
- **返点/档期费**：供应商给超市一笔费用换陈列位或海报位。
- **保价补差**：促销后如果降价，供应商补差价。

**5. 但要注意**
- 不是所有供应商都给，**小供应商、临时供应商、低毛利单品**通常支持有限。
- 支持往往和**采购量、合作账期、年度合同、促销档期**挂钩。
- 最好在**促销前书面确认**：谁出物料、谁出人、谁出试吃果、损耗谁担、费用谁付。
- 如果是超市自己主导的促销，供应商可能只给货，不给额外支持。

**实操建议**
你可以直接这样跟供应商谈：
1. “这次促销你们能提供哪些陈列道具和海报物料？”
2. “试吃果、试吃台、试吃员你们能承担哪部分？”
3. “促销价基础上，能不能再给搭赠或损耗补贴？”
4. “如果我们要端头/堆头/海报位，你们能出多少费用？”
5. “所有支持写进促销确认单，避免事后扯皮。”

简单说：**能提供，而且通常能提供陈列、海报、试吃、费用四类支持，但必须提前谈、书面确认，不能默认供应商全包。**
