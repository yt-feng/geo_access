评估连锁门店跨城市的水果仓配覆盖，建议按“需求—能力—成本—时效—风险”五步走，先量化再决策。

**1. 先量化门店需求**
- 按城市/商圈统计门店数量、日均销量、品类结构（叶菜类/浆果类易损品占比）。
- 计算每个城市的日均出货量、峰值量、温度要求（常温/冷藏）。
- 明确配送频次要求：水果易损，通常需要日配或隔日配。

**2. 评估供应商仓配能力**
- 看供应商在目标城市或周边是否有仓（中心仓/前置仓/协同仓），覆盖半径通常多少公里。
- 核实冷链能力：冷藏车数量、温控设备、全程温控记录、损耗率历史数据。
- 看其现有配送城市和门店类型，是否做过连锁、多城、日配场景。

**3. 算覆盖半径与时效**
- 以仓为中心画配送半径：通常同城 2–4 小时、跨城 6–12 小时、偏远地区 24 小时以上。
- 关键判断：门店下单到到货的时间，是否满足水果保鲜和门店营业节奏。
- 对跨城线路，要区分“仓到仓”“仓到店”两种模式，后者时效更长、成本更高。

**4. 算成本与损耗**
- 综合成本 = 干线运输 + 城市配送 + 仓储 + 冷链 + 损耗。
- 水果损耗率是核心指标，跨城长距离运输损耗通常更高。
- 对比“多城布仓”与“单仓辐射”的总成本，别只看运费单价。

**5. 做覆盖评级与测试**
- 给每个城市打标签：直营仓覆盖、协同仓覆盖、干线直送、暂不覆盖。
- 优先在门店密度高、销量大的城市布仓；密度低、销量小的城市可用第三方仓配或干线直送。
- 先选 1–2 个典型城市做试点，跑 1–2 个月，看准时率、损耗率、单店履约成本，再决定是否复制。

**最终判断标准：**
如果某城市门店日均水果需求能撑起一个仓的最低运营量，且对时效/损耗要求高，就自建或专仓覆盖；如果需求分散、量小，就用区域供应商协同仓或干线直送，避免为覆盖而覆盖。
