优先关注**成熟度**，价格放在第二位。原因是：香蕉在烘焙里的作用不只是“提供香蕉味”，还直接影响蛋糕的**甜度、湿度、香气、组织结构和保质期**。

**怎么判断该买什么成熟度**
- **做香蕉蛋糕/香蕉磅蛋糕/香蕉马芬**：买**表皮大面积出现黑点、但果肉还没发酸发烂**的香蕉，也就是常说的“熟到发黑但没坏”。这种香蕉淀粉已经大量转成糖，甜度高、香气足、压成泥后水分和黏稠度也合适。
- **如果买太青**：甜度低、香气弱，烤出来香蕉味淡，还容易带涩感，通常需要额外加糖，反而增加成本。
- **如果买已经过熟到流汁、发酸、酒味明显**：不要用于直接做蛋糕，容易影响风味和成品稳定性，也可能带来食品安全风险。

**价格该怎么看**
- 如果成熟度合适，价格便宜当然优先买。
- 如果价格很低但香蕉太生，不建议为了省钱硬买，因为后续要补糖、补香、调整配方，成品还不稳定。
- 如果价格很低但已经过熟，只适合当天立刻处理，比如压泥后冷冻保存，或者做成香蕉泥再用于烘焙，不适合继续常温放。

**采购建议**
1. **按用途定成熟度**：当天做，买黑点多的；计划几天后做，买刚出黑点的，放几天正好。
2. **少量试货**：先买一箱看成熟速度、果肉状态、出泥率和风味，再决定是否长期采购。
3. **和供应商约定成熟度**：不要只说“要香蕉”，要明确“表皮有黑点、果肉软但不流汁、无酸味酒味”。
4. **价格比较要按可食部分算**：太生或过熟都会增加损耗，不能只看每斤单价。
5. **过熟香蕉可冷冻**：剥皮后压泥，按份量分装冷冻，能减少浪费，也能稳定供应。

一句话：**先看成熟度是否适合做蛋糕，再看价格是否划算；成熟度不对，再便宜也不建议大量买。**
