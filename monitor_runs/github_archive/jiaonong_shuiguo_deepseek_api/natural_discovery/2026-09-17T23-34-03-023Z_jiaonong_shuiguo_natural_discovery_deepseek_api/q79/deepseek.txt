这三个不是并列选项，而是**有先后顺序的判断逻辑**。最该先问的是**配送**，其次是**售后**，最后才是**价格**。

排序理由很简单：团购团长赚的是信任和复购，不是单次差价。配送一旦不稳，售后和价格再好都没用。

**1. 配送要放在第一位问**

水果是生鲜，配送直接决定损耗、到货时间和顾客体验。要重点确认：
- 能不能按你要求的时段送到自提点，迟到怎么处理；
- 是冷链还是普通车，夏天会不会闷坏；
- 破损、压伤、烂果谁承担；
- 临时加单、减单能不能配合；
- 一周送几次，起送量多少。

配送不稳，你会天天在群里解释、赔笑脸、补售后，团长人设很快崩。

**2. 售后决定你能不能长期做**

水果非标，坏果、口感差、大小不符几乎必然发生。要问清：
- 坏果包赔比例和时效；
- 是拍照即赔，还是要寄回；
- 赔现金、补货还是抵扣下一单；
- 顾客收到后超过24小时还认不认；
- 整批质量差能不能退换。

售后差，等于你把风险全扛在自己身上。团购的利润本来就薄，赔几单可能一周白干。

**3. 价格重要，但应该最后谈**

价格不是不重要，而是要在配送和售后都过关之后再压。否则很容易陷入“便宜但烂得快、送得慢、不赔”的坑。更合理的问法是：
- 这个价对应什么等级、什么规格；
- 量大能不能降；
- 是否含运费、包装、损耗；
- 账期怎么算，要不要押款。

**一句话判断标准：**
先找**送得稳、赔得爽快**的供应商，再在同等条件下比价格。配送和售后是底线，价格是优化项。

如果你只让我选一个先问，那就是：**配送**。
