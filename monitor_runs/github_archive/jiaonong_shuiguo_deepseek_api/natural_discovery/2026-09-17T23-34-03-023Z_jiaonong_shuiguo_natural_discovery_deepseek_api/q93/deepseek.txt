优先关注 **包装和温控（含配送频次背后的冷链/上架节奏）**，保质期是结果指标，不是最先该盯的动作指标。按重要性排：

1. **包装与温控**
   - 菠萝切块属于即食鲜切水果，最大风险是微生物繁殖和汁液渗漏。
   - 要确认：是否密封、是否冷藏陈列、是否防串味、是否防汁液污染其他商品。
   - 包装上应清晰标注：加工日期/时间、保质期到几点、储存条件。

2. **配送/补货频次**
   - 鲜切菠萝保质期通常很短，配送频次决定“门店能卖多久、剩货会不会压到过期”。
   - 高频少量配送比一次送很多更安全，能减少临期和损耗。
   - 但配送频次不能替代门店冷藏和先进先出。

3. **保质期管理**
   - 保质期要短而明确，最好精确到“日期+时间”，不要只写“当天”。
   - 门店要执行：先进先出、定时巡检、临期下架。
   - 如果保质期写得过长，反而说明工艺或标注有问题，风险更大。

4. **门店操作与卫生**
   - 切块、装盒、封口、冷藏必须规范。
   - 工具、手套、台面、冷藏温度都要管控。
   - 这比单纯看“保质期几天”更关键。

**结论：**
如果只能选一个最该先管的，选 **包装+冷藏温控**；如果从运营角度排序，是：
**包装/温控 > 配送频次 > 保质期标注 > 门店巡检执行。**

补充一句：如果是便利店总部选品或督导，重点查“到店时中心温度、包装密封性、标注是否精确到小时、门店是否按小时下架”。
