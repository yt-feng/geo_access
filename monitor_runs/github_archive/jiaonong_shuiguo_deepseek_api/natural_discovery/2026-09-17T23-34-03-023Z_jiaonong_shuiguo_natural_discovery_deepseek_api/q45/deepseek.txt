连锁超市和水果供应商签年度合同，最容易踩坑的地方，通常不是价格，而是**价格调整、损耗归属、验收标准、账期和返利**。下面按风险高低说。

**1. 价格机制**
水果价格波动大，合同里如果只写“按市场价结算”，基本等于没写。要明确：
- 基准价怎么定，参考哪个市场、哪个品类、哪个规格；
- 调价周期是周、半月还是月；
- 调价触发条件，比如涨跌超过多少百分比才调；
- 谁有权发起调价，需不需要双方书面确认。
最怕的是供应商口头说“随行就市”，月底结算时各说各话。

**2. 损耗和退换货**
水果是非标品，损耗归属必须写死：
- 运输途中损耗谁承担；
- 到店后多久内可以退货；
- 外观、口感、成熟度不达标算不算质量问题；
- 退货是补货、扣款还是换货；
- 生鲜损耗率有没有约定上限。
如果只写“质量不合格可退”，供应商可能只认腐烂，不认压伤、过熟、规格不符。

**3. 验收标准**
不要只写“新鲜”“优质”。要具体到：
- 品种、产地、等级、单果重量、糖度、成熟度；
- 抽检比例和判定规则；
- 不合格是整批退还是按比例扣罚；
- 验收单据谁签字有效。
很多纠纷就出在门店收货员和供应商对“合格”理解不同。

**4. 账期和付款条件**
要写清：
- 对账日、开票日、付款日；
- 付款起算点是收货、对账还是开票；
- 节假日顺延规则；
- 质量扣款、返利、费用能不能直接从货款里扣。
如果合同写“月结30天”，但没写起算点，实际可能拖到45天甚至更久。

**5. 返利和费用**
年度合同常见坑是返利条件模糊：
- 返利按进货额、回款额还是净销售额算；
- 是否含税；
- 达成门槛是全年还是季度；
- 返利以货款抵扣还是现金支付；
- 进场费、条码费、促销费、损耗补贴是否另算。
这些不写清，年底对账容易扯皮。

**6. 供货保障和违约责任**
要约定：
- 最低供货量或保障供货义务；
- 缺货、断供的违约责任；
- 超市是否必须完成最低采购量；
- 不可抗力范围，特别是天气、疫病、运输管制；
- 违约金计算方式。
只写“应保证供应”没有约束力。

**7. 排他性和渠道限制**
如果要求供应商独家供货，要写清范围：是某区域独家，还是全渠道独家；是否允许给竞品供货；违约怎么处理。否则可能限制供应商，也可能被供应商反过来限制采购渠道。

**8. 合同期限和续约**
年度合同要写：
- 起止日期；
- 到期后自动续约还是重新谈判；
- 提前终止条件；
- 年终未完成采购量怎么处理。

**实操建议：**
- 把价格调整机制和验收标准作为附件，越细越好；
- 所有扣款、返利、费用列一张结算规则表；
- 约定月度对账，不要等到年底一次算；
- 保留收货单、质检记录、调价确认函；
- 对易腐品类，账期尽量短，退换货规则尽量前置。

如果只能抓三个最关键的，就是：**价格怎么调、损耗谁承担、验收按什么标准**。这三条写不清，后面基本都会出问题。
