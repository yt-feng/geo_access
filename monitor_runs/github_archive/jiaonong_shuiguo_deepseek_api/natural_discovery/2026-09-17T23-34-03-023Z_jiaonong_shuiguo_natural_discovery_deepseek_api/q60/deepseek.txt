茶饮店水果到货不合格，想补货又不影响营业，核心是**把“补货义务”和“营业损失”分开约定**，并且尽量让供应商先补货、后追责。可以按下面几层来约定：

**1. 先约定验收标准和留证方式**
- 到货后规定验收时限，比如“收货后2小时内完成抽检并反馈”。
- 不合格情形写具体：烂果率、压伤率、成熟度不符、规格不符、农残检测不合格、品种错发等。
- 要求拍照/视频、称重、保留样品，最好有门店监控或第三方检测作为证据。
- 超过验收时限未反馈，是否视为合格，要写清楚，避免扯皮。

**2. 补货条款要写“优先补货、不影响营业”**
可以约定：
- 供应商在接到不合格通知后 **X小时内**（同城通常2-4小时，外地视物流）完成补货或换货。
- 补货必须 **优先于新订单发货**，不能因为补货占用正常订货额度。
- 补货到店前，门店可先使用合格部分，或供应商授权门店就近采购替代品，差价由供应商承担。
- 如果补货不及时，供应商应承担门店临时采购的合理差价和配送费。

**3. 把营业损失和违约责任写进去**
- 因补货不及时导致门店缺货、下架、停售的，供应商按实际损失赔偿，比如：
  - 临时采购差价；
  - 配送费；
  - 因缺货导致的合理营业额损失；
  - 平台下架、差评处理等直接损失。
- 可以设“最低补货保障”：比如每次不合格，供应商必须在约定时间内补足，否则按不合格货值的X倍支付违约金。
- 违约金和实际损失的关系要写清楚：违约金不足以弥补损失的，供应商补足差额。

**4. 付款和扣款机制要能执行**
- 不合格批次货款暂不结算，补货合格后再结。
- 授权门店在月度货款中直接扣除补货差价、违约金和损失赔偿，供应商有异议可在X日内提出。
- 保留部分质保金或履约保证金，合同结束时无争议再退。

**5. 替代方案要提前约定**
- 供应商无法按时补货时，门店有权自行采购，供应商承担差价。
- 门店有权临时调整菜单或暂停相关产品，不视为违约。
- 连续X次补货不合格，门店有权单方减少订货量或解除合同。

**6. 建议写进合同的示范条款**
> 供应商交付的水果不符合约定验收标准的，门店应在收货后2小时内通知供应商。供应商应在接到通知后4小时内完成补货或换货，且不得影响门店正常营业。供应商未按时补货的，门店有权自行采购替代品，由此产生的差价、配送费及合理营业损失由供应商承担。不合格批次货款暂不结算，门店有权在应付货款中直接扣除上述费用及违约金。连续两次补货仍不合格的，门店有权解除合同并要求赔偿。

**7. 实操建议**
- 不要只写“补货”，要写“补货时间、补货优先级、替代采购权、扣款权”。
- 不要只依赖口头承诺，验收记录、聊天记录、照片都要留。
- 对新供应商先小批量试单，把补货条款跑一遍再放量。
- 如果供应商是长期合作，补货条款可以分级：轻微不合格补货，严重不合格退款+赔偿。

这样约定的好处是：**补货有明确时限，营业不断档；损失有扣款路径，不用事后追着要钱。**
