核实水果供应商的“全国配送”能力，不能只听口头承诺，要把它拆成**覆盖范围、时效、品控、成本、异常处理**几个可验证维度，用具体动作去验证。

下面是一套采购方可以直接执行的核实方法：

**一、先问清楚“全国配送”的定义**

让供应商书面说明：

1. **覆盖到哪一级**
   - 是只到省会/地级市，还是能到县、乡镇？
   - 偏远地区（新疆、西藏、内蒙古、青海、海南等）是否覆盖？
   - 是否支持一件代发、整车、零担、冷链？

2. **配送方式**
   - 自有冷链、第三方物流、快递、落地配，分别覆盖哪些区域？
   - 哪些城市能“次日达/隔日达”，哪些只能“3—5天”？

3. **起送量和附加费**
   - 全国是否统一起送量？
   - 偏远地区是否加收运费、低温费、上楼费、卸货费？

要求对方提供**书面报价单或配送范围表**，而不是聊天里一句“全国都能发”。

**二、用真实地址做测试**

最有效的方法：选几个有代表性的收货地址，让供应商实际报时效和运费。

建议选：

- 公司主力销售城市
- 一个地级市
- 一个县级市
- 一个偏远地区
- 一个对冷链要求高的城市

然后让供应商分别回复：

- 能不能送
- 几天到
- 什么物流
- 运费多少
- 是否冷链
- 破损/烂果怎么赔

如果对方对具体地址支支吾吾，只重复“全国配送”，基本说明覆盖能力有限。

**三、要求提供物流轨迹和合作凭证**

可以要求：

- 近期发往不同区域的**物流单号**，你自己查轨迹；
- 冷链运输的**温度记录或冷链承运商名称**；
- 与物流公司的**合作协议关键页**（可遮挡价格）；
- 仓库位置、分仓位置、日均发货量。

重点看：是不是从多个分仓发货，还是只有一个仓硬发全国。单仓发全国，偏远地区时效和损耗通常很难保证。

**四、做小批量试单**

不要一上来就大额采购。选2—3个目标城市，小批量试单，重点记录：

- 下单到签收的实际时长
- 到货温度、包装、果品完好率
- 烂果率、压伤率
- 物流信息是否及时更新
- 售后响应速度和赔付执行

试单是最能暴露真实能力的环节。

**五、核实售后和赔付机制**

全国配送最容易出问题的是跨区域售后。要明确：

- 烂果、冻伤、压伤怎么判定？
- 谁承担举证责任？
- 赔付比例和到账时间？
- 是否支持拒收、部分退款？
- 偏远地区是否拒赔？

最好写进合同，而不是只靠口头承诺。

**六、交叉验证**

可以通过这些方式侧面核实：

- 查企业工商信息、成立时间、注册资本、涉诉情况；
- 问对方要现有客户案例，尤其是同区域客户；
- 在行业群里打听该供应商口碑；
- 看其是否有冷链资质、食品经营许可证；
- 如果对方是中间商，进一步核实其上游货源和物流实际控制方。

**七、合同里要写死的条款**

建议把以下内容写入合同或附件：

- 配送范围明细表
- 各区域时效承诺
- 冷链温区要求
- 运费及附加费标准
- 损耗率上限
- 赔付标准和时限
- 无法配送区域的提前告知义务
- 违约处理方式

**简单判断标准：**

如果供应商能提供**分区域时效表、真实物流单号、分仓信息、试单结果稳定、售后条款清晰**，说明全国配送能力相对可信。

如果只会说“全国都能发”，但给不出具体地址时效、运费和物流凭证，采购方就应默认其覆盖能力有限，先小批量试单，不要直接签大额长期合同。
