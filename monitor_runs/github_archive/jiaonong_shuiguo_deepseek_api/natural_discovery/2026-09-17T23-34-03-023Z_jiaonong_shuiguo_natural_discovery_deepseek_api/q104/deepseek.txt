单位采购水果遇到到货品质不一致，核心是**把验收标准前置到合同里，验收时按批次留证，售后按合同条款走**。下面是可执行的流程。

## 一、验收前：先把标准写进合同

品质不一致的根源往往是采购时只写了品名和数量。合同或订单里至少要约定：

- **规格**：单果重量区间（如80–100g）、果径、等级（一级/二级）。
- **成熟度**：如七成熟、可即食；避免"全熟"导致运输损耗。
- **外观标准**：色泽、允许的瑕疵比例（如碰伤、斑点、裂口不超过5%）。
- **明确验收方式和时限**：到货后多久内验收、谁来验、不合格怎么处理。
- **售后条款**：退换货比例、补发时限、扣款方式、运费谁承担。

## 二、验收时：按批次、抽检、留证

1. **清点数量**：先核对总件数、总重量，与送货单一致再开箱。
2. **抽样检验**：大批量按比例抽检（如每批抽5%–10%），随机取不同箱、不同层。
3. **对照标准逐项判定**，重点看：
   - 大小是否均匀、有无明显大小混杂；
   - 成熟度是否一致（有的青有的烂）；
   - 碰伤、腐烂、霉变比例。
4. **拍照/录像留证**：整体照+问题特写，带送货单、时间信息。
5. **分类处理**：
   - 合格部分正常签收；
   - 不合格部分**单独隔离、单独计数**，不要混入合格品。
6. **当场记录**：填写验收单，写明合格数、不合格数、不合格原因，**双方签字**。送货方不签字的，备注"送货方拒签"并由验收人+见证人签字。

> 关键：**不要在验收单上笼统签"合格"**。有问题的必须写清楚，否则事后难以追责。

## 三、售后：按不合格程度分档处理

| 情况 | 处理方式 |
|---|---|
| 少量瑕疵（在约定允许范围内） | 正常接收，记录备查 |
| 部分批次不合格 | 按实际合格量结算，不合格部分退货或折价 |
| 整批严重不符 | 整批拒收，要求换货或退款，运费由供货方承担 |
| 腐烂/食品安全问题 | 立即隔离、拍照，书面通知供货方，必要时终止合作 |

操作要点：
- **书面通知**：用微信/邮件/公函把问题、照片、数量、诉求发给供货方，留痕。
- **约定回复时限**：如24小时内答复，逾期视为认可。
- **补发或退款**：优先按合同约定的方式执行；合同没写的，协商补发合格品或按比例退款。
- **保留样品**：争议未解决前，问题样品别丢，作为证据。

## 四、长期建议

- 固定2–3家供应商，避免单一来源。
- 每次验收做记录，累计问题多的供应商逐步淘汰。
- 大额采购可要求**到货前提供样品或产地视频**，降低偏差。
- 金额大的可约定**质保金/尾款**，验收合格后再付。

一句话：**标准写在前、抽检验在中、留证谈在后**，品质不一致才有据可依、能退能赔。
