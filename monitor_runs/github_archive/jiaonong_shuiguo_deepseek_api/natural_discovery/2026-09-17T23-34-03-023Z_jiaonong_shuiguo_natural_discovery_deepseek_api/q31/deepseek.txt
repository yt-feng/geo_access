连锁商超找长期水果供应商，评分标准核心要把“能长期稳定供货”和“水果这种非标品控得住”分开考核。建议用百分制，结构如下：

**一、价格与成本（30–35分）**
- 报价竞争力：对标同类商超同品质行情，不比最低价，比“性价比分”
- 价格调整机制：是否接受随行就市但有涨跌幅上限（如±10%内）
- 账期与结算：能否接受月结/45天，是否收进场费、条码费

**二、供货稳定性（20–25分）**
- 自有基地或长期合作果园面积、产地数量
- 全年供应能力：能否覆盖淡旺季，断供预案
- 冷链与仓储：产地预冷、冷链车、周转仓配置
- 历史履约：近2年供货合同履约率、缺货率

**三、品质与品控（20–25分）**
- 果品标准：糖度、规格、外观、农残检测报告
- 分级能力：能否按商超要求做大小/成熟度分级
- 质检体系：自检+第三方检测，批次可追溯
- 损耗率承诺：到店损耗率、坏果包赔条款

**四、企业资质与实力（10–15分）**
- 营业执照、食品经营/流通许可、种植/加工资质
- 注册资本、年营收、合作商超案例
- 食品安全事故记录、诉讼记录

**五、服务与配合（10–15分）**
- 配送时效：下单到到店时间、频次
- 退换货响应：坏果、滞销处理速度
- 促销支持：堆头、试吃、节日保供
- 信息化：能否对接订单/库存系统

**六、加分项（5–10分）**
- 有机/绿色认证、地理标志产品
- 助农、乡村振兴、碳减排等社会责任
- 可做自有品牌或定制包装

**设置时注意：**
1. 价格分不要过高，否则容易招来低价低质、旺季断供的供应商。
2. 品质和稳定性合计建议不低于45分，这是水果长期合作的关键。
3. 设置“一票否决”：农残超标、重大食品安全事故、虚假资质直接废标。
4. 履约保证金和季度考核挂钩，避免中标后躺平。

如果你们是区域连锁、单店日均水果销量不大，可以适当降低“自有基地”权重，提高“配送频次”和“退换货响应”；如果是全国性商超，则基地面积、冷链和全年供应能力权重必须拉高。
