做水果拼盘想更划算，核心不是“买最便宜的”，而是**按出成率、损耗、切配稳定性和顾客感知**来选规格。下面按苹果、橙子、菠萝分别说，最后给一个组合建议。

**1. 苹果**
- **优先选：中等偏大、大小均匀的当季苹果**
  - 单果重建议：**180–220g**
  - 这种规格切出来的片/块大小一致，摆盘整齐，损耗低。
- **不建议：**
  - 太小的果：削皮去核后剩得少，切配费工。
  - 太大的果：单价高，而且一个果切出来太多，拼盘用不完容易氧化。
- **划算点：**
  - 选**80–90mm果径**通常性价比高。
  - 如果餐厅走量，买**10kg或20kg箱装**比散买便宜，但要确认没有大量碰伤。
  - 苹果出成率大约**70%–80%**，即1kg苹果最后可用果肉约0.7–0.8kg。

**2. 橙子**
- **优先选：皮薄、无籽、大小均匀的脐橙/伦晚/沃柑等**
  - 单果重建议：**180–250g**
  - 这种规格切瓣、去皮、切块都稳定，摆盘好看。
- **不建议：**
  - 太小的果：剥皮后肉少，出成率低。
  - 皮太厚的果：看着大，实际肉少。
- **划算点：**
  - 如果做**带皮切片**，选中大果，切片直径统一。
  - 如果做**纯果肉块**，优先算出成率，而不是只看单价。
  - 橙子出成率大约**55%–70%**，皮厚品种可能更低。
  - 买**15kg–20kg箱装**通常比零售划算，但要注意存放，橙子怕压、怕闷。

**3. 菠萝**
- **优先选：成熟度适中、果眼浅、圆柱形好的菠萝**
  - 单果重建议：**1.2–1.8kg**
  - 这种规格削皮去眼后，出肉比较稳定，切块也整齐。
- **不建议：**
  - 太小的果：削完剩得少，人工成本高。
  - 太大的果：如果当天用不完，损耗大。
  - 过熟的果：切时容易烂，出水多，影响拼盘卖相。
- **划算点：**
  - 如果餐厅用量大，可以直接买**已削皮菠萝**，虽然单价高，但省人工、省损耗，综合成本可能更低。
  - 如果自己削，菠萝出成率大约**45%–60%**。
  - 买**整箱装**通常比单个买便宜，但要按当天/两三天用量控制，避免熟过头。

**最划算的选法：**
- **苹果：** 80–90mm果径，单果180–220g，箱装当季果。
- **橙子：** 单果180–250g，皮薄无籽，箱装。
- **菠萝：** 单果1.2–1.8kg，成熟度适中；用量大可直接买削皮果。

**一个简单判断公式：**
> **实际可用成本 = 采购价 ÷ 出成率**
>
> 比如苹果10元/kg，出成率75%，实际可用成本约13.3元/kg。  
> 橙子8元/kg，出成率60%，实际可用成本约13.3元/kg。  
> 菠萝6元/kg，出成率50%，实际可用成本约12元/kg。  
> 这样比只看标价更准。

**如果只记一句话：**
苹果选中大均匀、橙子选皮薄无籽、菠萝选1.2–1.8kg成熟适中；走量买箱装，但一定要按出成率和当天损耗算，不要只看单价。
