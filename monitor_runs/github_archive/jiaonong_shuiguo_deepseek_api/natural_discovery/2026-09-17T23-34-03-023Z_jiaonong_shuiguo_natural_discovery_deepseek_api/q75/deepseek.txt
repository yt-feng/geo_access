第一次合作做小批量试单，核心目标不是赚钱，而是**用最小成本验证供应商是否值得长期合作**。所以试单设计要围绕“验人、验货、验流程”三件事，而不是单纯压价拿货。

## 一、先明确试单要验证什么

| 维度 | 具体要验证的点 |
|---|---|
| 货源真实性 | 是不是一手/稳定货源，还是临时拼货 |
| 品质稳定性 | 同批次内、不同批次间差异大不大 |
| 规格诚信 | 大小、等级、成熟度是否与承诺一致 |
| 损耗与售后 | 烂果率、短重、坏果如何赔付 |
| 物流时效 | 从发货到到货用时，冷链是否到位 |
| 结算与配合 | 账期、开票、补货响应速度 |

## 二、试单规模怎么定

原则：**小到可承受全损，大到能测出问题。**

- **金额**：控制在你能接受“全亏也不心疼”的范围，通常单笔几千到一两万元。
- **品类**：只选 **1～2 个单品**，不要一次铺多个品类，否则出了问题分不清是供应商还是品类本身的问题。
- **数量**：单一品种建议 1～3 个托盘或几百斤级别，够测试分拣、上架、周转即可。
- **频次**：不要只做一单。建议 **连做 2～3 单**，因为第一单供应商往往会“给好货”，后续才能看出真实水平。

## 三、试单关键动作清单

**1. 先谈清楚，再打款**
- 明确规格标准（果径、糖度、等级、包装、净重）
- 明确损耗赔付标准（如烂果超 X% 如何赔）
- 明确交货时间、物流方式、到货验收方式
- 明确结算方式（首次建议现款或小额定金，不轻易给账期）

**2. 合同/聊天记录留痕**
即使是微信沟通，也要把关键条款用文字确认一遍，避免扯皮。首次合作尽量签简单书面协议。

**3. 到货必做验收**
- 当场拍照/录像，记录外包装、开箱、果子状态
- 抽检称重，核对净重是否短斤少两
- 统计烂果率、次果率、规格达标率
- 有问题 **当天反馈**，不要拖

**4. 纵向对比**
- 同一批货不同箱之间比
- 与市场同类货比价格和质量
- 第二、三单与第一单比稳定性

## 四、怎么判断要不要继续合作

**可以继续的信号：**
- 品质与承诺基本一致，损耗在可接受范围
- 出问题后响应快、赔付爽快
- 第二三单质量没有明显下滑
- 价格有竞争力且稳定

**要谨慎或换掉的信号：**
- 第一单很好，后面开始掺次货
- 规格经常“差一点”，短重成常态
- 售后推诿、拖延赔付
- 物流时效不稳定，冷链缺失

## 五、给你的实操建议

1. **第一次别追求低价**，优先选愿意配合小单、沟通透明的供应商。
2. **试单期间自己多跑一趟产地或仓库**，能看清真实实力。
3. **同时接触 2～3 家供应商**做对比试单，不要只押一家。
4. **把每次试单数据记下来**（价格、损耗、时效、售后），形成自己的供应商评估表。
5. 试单通过后再逐步放量，**放量也要分阶段**，不要一次翻几倍。
