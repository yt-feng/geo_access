判断香蕉供应商能否全年稳定供货，不能只看他说“可以”，要看他的**货源结构、产地布局、冷链能力和历史履约记录**。香蕉是典型的季节性、区域性强的水果，单一产地几乎不可能全年稳定。

具体可以从以下几个维度核查：

**1. 产地是否多元布局**
- 问清楚他全年各月份分别从哪些产区拿货。
- 国内主产区：海南、云南、广西、广东、福建；进口主要来自菲律宾、越南、厄瓜多尔、哥伦比亚等。
- 如果供应商只依赖一个产区，遇到台风、寒害、病害就会断供。
- 正常做法是：国产季用国产，国产淡季用进口补，或者南北产区轮换。

**2. 是否有自有或长期合作的种植基地**
- 自有基地、包园、长期订单农业，比临时市场收购稳定得多。
- 要求提供基地位置、面积、合作年限、年供应量。
- 只做“市场倒手”的贸易商，价格波动时容易优先供出价高的客户。

**3. 冷链和加工能力**
- 香蕉需要催熟、冷藏、运输温控。问是否有催熟库、冷库、冷藏车。
- 没有冷链的供应商，夏季损耗大，很难保证持续供货品质。
- 跨区域长距离供货，必须看他的物流是自营还是外包，旺季是否有运力保障。

**4. 历史履约数据**
- 要求提供过去12个月的供货记录：每月供货量、断供次数、到货合格率。
- 可以让他提供几家现有连锁超市客户作为参考，直接打电话核实。
- 重点问：春节、台风季、国产淡季这几个时间点有没有掉过链子。

**5. 合同约束**
- 合同里写明全年最低供应量、月度供应计划、断供违约责任。
- 约定替代方案：某产区受灾时，供应商必须用其他产区或进口货源补足。
- 设置价格调整机制，避免他因市场涨价而优先卖给别人。

**6. 实地验厂验仓**
- 去他的加工厂、冷库、催熟库看实际库存和作业能力。
- 看淡季时仓库里有没有货、有没有在途货。
- 看他的采购台账，确认货源是否真实多元。

**简单判断标准：**
如果供应商能清楚说出“1—3月从哪进、4—6月从哪进、台风季怎么补、进口怎么衔接”，并且有冷库、有基地、有历史记录，基本可信。如果只说“我关系广、随时能调到货”，但拿不出产地和记录，风险很高。

最稳妥的做法是：先小批量试单，跨越一个淡季和一个旺季，再决定是否签全年框架协议。
