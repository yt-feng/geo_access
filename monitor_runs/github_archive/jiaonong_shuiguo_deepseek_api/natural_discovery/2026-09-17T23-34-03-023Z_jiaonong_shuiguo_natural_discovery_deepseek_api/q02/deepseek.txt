这四者不是并列关系，应该按“先保底线，再算成本”的顺序看：

1. **坏果率最重要**  
   香蕉是易损、易熟水果，坏果多会直接吃掉利润，还会影响顾客复购。  
   - 建议先看：到货后能卖的占比、有没有明显压伤/发黑/霉点。  
   - 如果坏果率经常超过 5%～10%，价格再便宜也要慎重。

2. **熟度第二重要**  
   熟度决定你能不能马上卖、能卖几天。  
   - 太生：顾客当天不买，占地方，还要等。  
   - 太熟：当天卖不完就容易损耗。  
   - 小水果店最好收“微黄/带青、可放1～3天”的货，别一次全收熟蕉。

3. **送货速度第三重要**  
   送货快能减少搬运和存放损耗，也能让你补货更灵活。  
   - 如果前一天下单第二天一早到，通常比“便宜但拖两天”更划算。  
   - 夏天尤其明显，慢一天可能熟一批、烂一批。

4. **价格放到最后综合算**  
   不是不看价格，而是不能只看单价。  
   应该算：  
   **实际可售成本 = 进货价 ÷ 可售比例**  
   比如 A 家 2 元/斤，坏果 3%；B 家 1.7 元/斤，坏果 15%。  
   A 实际成本约 2.06 元/斤，B 约 2.0 元/斤，B 还多了挑拣和损耗风险。  
   所以便宜不一定真便宜。

**给小水果店的实操建议：**
- 固定 2～3 个供应商，不要只压一家。
- 每次到货抽检：坏果率、熟度、重量是否足。
- 优先选“坏果率低 + 熟度合适 + 送货稳”的供应商。
- 价格谈判放在质量稳定之后，再要求账期、退换货、补损。
- 夏天少量多次进，冬天可适当加量。

一句话：**先看坏果率和熟度，再看送货速度，最后用“实际可售成本”比价格。**
