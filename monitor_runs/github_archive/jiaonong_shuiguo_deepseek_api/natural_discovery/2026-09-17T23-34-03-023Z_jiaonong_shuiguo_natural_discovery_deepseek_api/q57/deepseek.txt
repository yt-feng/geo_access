结论：**绝大多数餐饮连锁，水果应由中央厨房/总仓统一收货、统一验收、统一分拨；门店只做二次验收和临期处理。** 只有少数特殊品类或特殊门店模型才适合门店分开收货。

下面给你可判断的依据和适用边界。

## 一、为什么统一收货更好

**1. 品质标准统一**
水果最大的问题是批次差异大。中央厨房统一收货可以：
- 统一验收标准（糖度、硬度、规格、成熟度、损耗率）
- 统一拒收和索赔口径
- 避免各门店店长凭个人感觉收货，导致同一品牌不同门店品质不一致

**2. 采购议价和供应商管理更强**
总部/中央厨房集量采购，价格、账期、返点都更有优势。门店分散收货会把采购权打散，供应商多、价格乱、腐败风险高。

**3. 食品安全和责任可追溯**
统一收货能集中做农残快检、留样、温控记录。门店分散收货时，检测能力和记录往往不到位，出问题难以追责。

**4. 损耗更可控**
水果损耗高，统一收货后可以：
- 按门店销量精准分拨
- 把外观稍差但仍可用的果子调给榨汁、甜品、果茶等加工用途
- 减少门店因“收多了卖不掉”造成的报废

**5. 财务和结算更清晰**
统一进货、统一对账、统一开票，门店按内部调拨结算，比几十家门店各自对账效率高得多。

## 二、什么情况下适合门店分开收货

只有满足以下条件之一，才考虑门店直收：

1. **极度依赖本地鲜度和短链配送**
   比如门店每天需要当天采摘的叶菜类、浆果类，中央厨房配送反而增加一次装卸和运输时间。

2. **门店数量少、区域集中、单店采购量大**
   比如只有3—5家店，且都在同一城市，总部统一收货再配送反而不经济。

3. **特殊品类不适合二次分拣**
   如高端鲜切果盘用的即食水果，中央厨房分拨容易造成二次损伤。

4. **门店有独立加工和独立核算需求**
   比如旗舰店、独立品牌店，需要自己控制出品。

## 三、更优的折中模式

实际连锁餐饮里，最推荐的是**“中央厨房统采统收 + 门店二次验收 + 例外直配”**：

- **主品类**：苹果、橙子、西瓜、柠檬、香蕉等耐储水果，中央厨房统一收货分拨。
- **高鲜度品类**：草莓、蓝莓、芒果、即食果切原料，可由供应商直配门店，但必须执行总部统一标准、统一价格、统一检测。
- **门店角色**：只做二次验收，发现不合格立即拍照上报，由总部统一向供应商索赔。
- **系统支持**：门店收货数据实时回传总部，纳入供应商考核。

## 四、判断公式

你可以用这个简单标准判断：

> **如果水果用于标准化出品、门店数量超过10家、有中央厨房或总仓，就统一收货。**
>
> **如果门店少于5家、区域高度集中、水果鲜度要求极高且配送半径很短，可以门店直收，但必须总部控标准。**

## 五、落地建议

1. 先梳理水果品类，分成“耐储统收”和“高鲜直配”两类。
2. 制定统一验收标准：规格、成熟度、糖度、损伤率、温控要求。
3. 中央厨房配快检和留样能力。
4. 门店只保留二次验收权和异常上报权，不保留自主采购权。
5. 用损耗率、投诉率、供应商准时率三个指标每月复盘。

**一句话：能统收就统收，统收不了的就“总部定标准、供应商直配、门店只验收”，但采购权和定价权不要下放到门店。**
