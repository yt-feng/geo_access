小面积便利店做水果，核心不是“品类齐全”，而是 **少SKU、高频补、快周转**。建议按下面这套逻辑控制品类和损耗：

## 1. 先砍品类：只做“顺手买”的水果

便利店水果不是水果店，顾客买的是即时性、便利性。建议控制在 **6–10个SKU** 以内。

优先保留：
- **高频刚需**：香蕉、苹果、橙子、砂糖橘、圣女果
- **即食型**：切好的西瓜/哈密瓜/菠萝（如果有冷藏条件）
- **小份装**：单人份、2–3个装、小盒装
- **季节爆品**：夏天西瓜、荔枝；冬天砂糖橘、草莓，但只做1–2个

谨慎或不做：
- 易压伤：水蜜桃、葡萄、芒果
- 高损耗：草莓、蓝莓、车厘子（除非客群消费力强）
- 需要挑拣/称重的散装大堆头
- 低频小众：火龙果、牛油果、山竹等，除非有稳定需求

原则：**每个品类只留1–2个价格带，不做全规格。**

## 2. 采购量：小批量、多频次

小店最怕一次性进太多。建议：
- **香蕉、苹果、橙子**：按2–3天销量采购
- **草莓、葡萄、切果**：按1天销量采购，甚至半天
- **叶菜类水果**：基本不做
- **新品**：先试1–2盒/1–2斤，卖得动再加

一个实用公式：

> **首次采购量 = 预估日销 × 1.5**
> 稳定后：**采购量 = 前3天平均日销 × 补货周期天数 × 0.8**

乘以0.8，是给损耗留安全边际。

## 3. 按销量分级管理

把水果分成三类：

| 类型 | 例子 | 策略 |
|---|---|---|
| A类引流 | 香蕉、苹果、砂糖橘 | 保证不断货，价格有竞争力 |
| B类利润 | 橙子、圣女果、切果 | 正常补货，控制库存 |
| C类测试 | 草莓、蓝莓、新品 | 少量试卖，卖不动立刻停 |

每天记录销量，连续3天卖不动的，直接淘汰，不要恋战。

## 4. 损耗控制：从收货到出清

### 收货
- 少量多次，宁可缺货，不要压货
- 拒收已经软、裂、发霉、过熟的
- 香蕉、芒果等后熟水果，按成熟度分批陈列

### 陈列
- **先进先出**：新货放后面，旧货放前面
- 不要堆太高，小面积店铺尤其容易压伤
- 易坏水果放冷藏或阴凉处
- 切果必须冷藏，标注时间

### 定价与出清
- 正常价卖2天
- 第3天做 **组合销售**：如“香蕉+苹果”“切果2盒优惠”
- 临近保质期做 **打折区**，不要等到烂了再处理
- 切果当天未售完，当晚下架，不要第二天继续卖

### 报损
- 每天固定时间报损，记录品项、数量、原因
- 每周复盘：哪些水果总在报损，直接砍掉

## 5. 小门店的替代方案

如果门店太小、没有冷藏、客流不稳定，可以考虑：
- **只做香蕉、苹果、橙子、砂糖橘**四样
- **做预包装小份水果**，不散卖
- **和附近水果店/供应链合作**，每天小批量配送
- **切果外包或中央厨房配送**，门店只负责冷藏陈列

## 6. 一个可直接执行的起步配置

适合10–30㎡便利店：

- 香蕉：1–2把
- 苹果：5–8个，小份装
- 橙子/砂糖橘：1–2筐小份
- 圣女果：2–3盒
- 切果：2–4盒，冷藏
- 季节单品：1个，少量试卖

每天补1次，晚上7点后对切果和易坏品做折扣出清。连续一周记录后，再决定加什么、砍什么。

**一句话总结：品类做窄，采购做小，补货做快，出清做狠。** 小店水果赚的不是毛利，是周转。
