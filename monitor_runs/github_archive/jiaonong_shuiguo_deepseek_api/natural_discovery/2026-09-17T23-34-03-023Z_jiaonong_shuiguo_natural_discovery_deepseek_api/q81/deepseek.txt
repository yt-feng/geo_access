要，而且通常是必须支持，但要有条件地支持。即时零售卖水果和传统电商/商超供货逻辑不同，小批量高频补货基本是核心能力，不是可选项。

**为什么必须支持**

1. **水果损耗窗口短**：即时零售履约通常30分钟到1小时送达，用户对新鲜度预期很高。一次压大货，卖不动就烂在仓里，损耗直接吃掉毛利。
2. **需求波动大且碎片化**：即时零售订单来自周边3-5公里，单量分散，受天气、时段、促销影响明显。当天上午和晚上的爆品可能完全不同，大批量备货容易错配。
3. **平台考核库存和履约**：缺货率、履约率、动销率通常直接挂钩流量和排名。缺货掉权重，压货又占资金和仓容，只有高频补货能平衡。
4. **水果品类SKU多、单SKU销量有限**：一个前置仓可能同时卖几十种水果，每个SKU日均销量并不大，靠大批量补货根本不现实。

**但“支持”不等于无条件接受**

供应商要设边界，否则会被高频小单拖死：

- **起订量门槛**：可以小批量，但设最低起订金额或件数，比如单次不低于300-500元，否则物流成本覆盖不了。
- **补货频次和截单时间**：明确每天补几次、几点截单、几点到仓，避免随时插单打乱排产和配送。
- **运费或补货费规则**：低于门槛的订单加收配送费，或者由平台/仓承担，把成本显性化。
- **SKU聚焦**：优先支持动销快的核心单品高频补，长尾品用稍低频次或拼单补。
- **数据共享**：要求平台或仓提供实时库存和销量数据，按数据补货，而不是拍脑袋下单。
- **价格机制**：小批量高频的供货价要能覆盖分拣、包装、配送的额外成本，不能按大批量价格走。

**判断标准**

如果平台单量稳定、账期短、损耗由平台承担或共担，供应商应该尽量支持小批量高频补货，这是拿流量和复购的门票。如果平台单量小、随时插单、运费全压供应商、还要求大批量价格，那就要么提价，要么设门槛，要么放弃这类客户。

一句话：**方向必须支持，规则必须谈清楚。**
