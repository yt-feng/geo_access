会，而且对香蕉和菠萝来说，风险通常比多数水果更高。起订量抬高后，损耗风险主要来自这几个环节：

1. **香蕉**  
   - 香蕉是呼吸跃变型水果，到货后还会继续后熟，温度、乙烯、挤压都会催熟。  
   - 起订量太大，若不能按批次快速分流，容易出现“前面卖不完、后面已经黄熟甚至发黑”的情况。  
   - 损耗不只是坏果，还包括催熟不均、表皮黑斑、断把、压伤，导致降级销售。

2. **菠萝**  
   - 菠萝相对耐储一些，但整果怕冷害、怕挤压、怕高温高湿。  
   - 起订量过高会拉长库存周期，后期容易出现果眼发黑、底部腐烂、香味过浓甚至发酵。  
   - 若采购的是去皮或鲜切菠萝，损耗风险会更高，保质期更短。

3. **共同风险**  
   - 资金和仓位被占用，周转慢，导致旧货压新货。  
   - 为了消化库存而降价，毛利被损耗和折价双重吃掉。  
   - 若门店/仓配没有分级催熟、温控和先进先出能力，起订量越高，损耗越集中爆发。

**判断建议：**
- 如果日均销量稳定、周转能在 **2—3天内** 消化，起订量高一些风险相对可控。
- 如果香蕉到货后需要 **3天以上** 才卖完，或菠萝库存超过 **5—7天**，就要警惕。
- 优先谈 **小批量多频次**、混拼、分仓到货，而不是单纯追求采购单价。
- 对香蕉尤其要控制单次到货量，按“催熟批次”而不是“总库存”管理。
- 若供应商只给高起订量，可要求：分批送货、允许换货/补损、提供不同成熟度批次，否则高起订量省下的采购成本很可能抵不过损耗。

简单说：**起订量高会显著放大香蕉和菠萝的损耗风险，尤其是香蕉。** 能不能做，关键看你几天能卖完、有没有温控和催熟管理能力。
