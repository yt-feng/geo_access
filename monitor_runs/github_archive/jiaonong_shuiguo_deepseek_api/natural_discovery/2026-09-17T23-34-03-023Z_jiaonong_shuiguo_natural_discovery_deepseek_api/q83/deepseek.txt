生鲜水果到货后出现坏果，责任划分通常不能一概而论，要结合**坏果产生的时间点、原因、平台规则、物流方式和证据**来判断。实务上一般分成以下几类。

## 一、先看坏果是什么原因造成的

### 1. 发货前就已腐烂、霉变、明显压伤
责任一般在**商家/平台**。

常见情形：
- 发货时水果已经不新鲜
- 装箱前已有软烂、霉点、裂口
- 成熟度过高，不适合长途运输
- 包装不合格，导致运输中容易压坏

这种情况下，顾客签收后发现坏果，商家应承担退换、补发或退款责任。

### 2. 运输过程中因物流原因损坏
责任可能在**物流方**，但顾客通常不需要直接找物流，而是找商家/平台处理。

常见情形：
- 快递暴力分拣导致压伤
- 运输时间过长导致腐烂
- 冷链中断导致变质
- 到货后长时间未派送

消费者与商家之间存在买卖合同关系，所以顾客一般先向商家主张权利，商家再向物流追偿。

### 3. 顾客签收后保存不当
责任通常在**顾客**。

常见情形：
- 到货后长时间不取件
- 高温下放置太久
- 没有按要求冷藏
- 自己磕碰、挤压造成损坏

如果平台能证明是签收后保管不当导致，商家通常不承担或只承担较小责任。

### 4. 商品本身属于易损、易熟品类
这类要结合**平台事先说明**和**坏果比例**判断。

例如：
- 草莓、樱桃、杨梅、水蜜桃等本身易损
- 商家若已标明“轻微碰伤不售后”“坏果包赔比例”等规则
- 若坏果超过合理比例，仍应赔
- 若只是少量轻微瑕疵，可能按平台规则部分赔付

## 二、责任划分的常见原则

### 1. 谁销售，谁先负责
消费者在生鲜电商下单，直接合同相对方通常是商家或平台自营。因此：
- 自营：平台负责
- 第三方商家：商家负责，平台协调
- 平台承诺“坏果包赔”：平台或商家按承诺执行

### 2. 谁过错，谁最终承担
商家先赔给顾客后，可以再根据原因向物流、仓储、供应商追责。

### 3. 举证责任很关键
顾客需要提供：
- 开箱照片/视频
- 坏果特写
- 快递面单
- 到货时间
- 与客服沟通记录

商家若主张“是顾客保存不当”，也需要举证。

### 4. 按坏果比例赔付更常见
很多生鲜平台不是“有一个坏果就全赔”，而是：
- 坏果超过一定比例，按比例退款
- 严重腐烂、异味、霉变，可能整单退
- 少量轻微压伤，可能小额补偿

## 三、实际处理建议

### 顾客角度
1. 到货后尽快开箱，拍照录像。
2. 不要先扔掉坏果，保留证据。
3. 第一时间联系客服，说明坏果数量和比例。
4. 要求补发、退款或部分赔付。
5. 若平台不处理，可申请平台介入或向消协投诉。

### 商家角度
1. 明确售后规则：坏果包赔范围、比例、时限。
2. 改进包装和冷链，降低运输损耗。
3. 要求顾客提供开箱证据，避免恶意索赔。
4. 对物流破损保留追偿依据。

### 平台角度
1. 制定统一坏果判定标准。
2. 区分“质量问题”和“保存不当”。
3. 对高频投诉物流或供应商做整改。

---

## 四、简单结论

可以按这个顺序判断：

1. **发货前就坏**：商家责任。
2. **运输中坏**：商家先赔，再向物流追偿。
3. **签收后因顾客保存不当坏**：顾客责任。
4. **易损水果少量轻微损伤**：按平台规则部分赔或不赔。
5. **大量腐烂、霉变、异味**：通常商家/平台应退换或赔偿。

所以，核心不是“到货后有坏果就一定谁赔”，而是看**坏果形成时间、原因、比例和证据**。对消费者来说，最稳妥的是：**及时开箱留证，先找商家/平台售后；对商家来说，则是先按规则赔付，再向责任环节追偿。**
