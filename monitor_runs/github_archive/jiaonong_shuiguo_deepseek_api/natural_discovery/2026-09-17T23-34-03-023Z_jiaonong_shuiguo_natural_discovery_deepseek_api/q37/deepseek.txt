商超做会员日水果活动，供应商要提前配合的核心是：**保供、保品质、保价格、保陈列、保售后**。建议至少提前 **7—15天** 启动准备，重点包括以下几项：

1. **确认活动方案**
   - 明确活动日期、时段、门店范围、会员规则。
   - 确认参与单品、规格、包装形式、活动价、供货价、毛利空间。
   - 明确销量预估、每日供货量、补货频次、最小起订量和配送时间。

2. **锁定货源与产能**
   - 提前锁定产地、基地或批发市场货源，避免活动期间断货。
   - 对易缺货单品准备替代品种或备用供应商。
   - 确认采摘、分拣、加工、包装、物流能力能否支撑峰值销量。

3. **品质与验收标准**
   - 提前约定等级、果径、糖度、成熟度、色泽、瑕疵率、单果重等标准。
   - 明确拒收标准，如腐烂、压伤、冻伤、异味、农残不合格等。
   - 活动前做样品确认，最好封样，避免到货后争议。

4. **包装与标识**
   - 按商超要求准备预包装、散装、称重码、条码、价签或箱贴。
   - 会员日爆品可做专属包装、组合装、家庭装，提升客单。
   - 标识需符合门店和法规要求，包括品名、产地、等级、净含量、日期等。

5. **价格与费用确认**
   - 提前确认供货价、活动扣点、促销服务费、损耗承担、返利政策。
   - 明确临时调价机制，避免活动前原料涨价导致供货争议。
   - 对特价爆品可申请供应商专项支持，如特价供货、赠品、物料补贴。

6. **物流配送与补货**
   - 制定活动期间配送计划，避开门店收货高峰。
   - 对爆品安排多批次小批量补货，减少门店库存压力。
   - 明确冷链、温控、防压、防冻、防雨措施。
   - 准备应急车辆和备用路线，防止断货。

7. **门店陈列与物料**
   - 提前提供堆头、端架、试吃台、POP、海报、爆炸牌等物料。
   - 配合门店做主题陈列，如“会员日鲜果爆品”“产地直采”。
   - 可安排促销员或试吃人员，但需提前报备、培训、办证。

8. **人员与现场支持**
   - 供应商可安排理货、试吃、导购、补货人员驻店。
   - 提前培训产品卖点、保存方式、试吃话术、售后口径。
   - 明确现场负责人和联系方式，便于门店临时调度。

9. **库存与损耗管理**
   - 按预估销量分日、分店、分时段供货，避免一次性压货。
   - 对高损耗水果设置安全库存和折价处理权限。
   - 约定活动后尾货处理方式：退货、折价、转场、供应商回收等。

10. **售后与应急机制**
   - 明确质量问题处理流程：拍照、留样、确认、补货、退款或扣款。
   - 准备应急预案：断货、爆单、品质异常、物流延误、客诉集中。
   - 活动期间保持专人对接，快速响应门店和采购。

11. **数据复盘准备**
   - 提前约定统计口径：销量、销售额、毛利、损耗、客诉、缺货率。
   - 活动后及时复盘，判断是否继续合作、调整价格或优化单品。

简单说，供应商要提前做到：**方案确认、货源锁定、样品封样、价格敲定、包装到位、物流排期、物料到店、人员待命、售后兜底**。其中最关键的是：**爆品不断货、品质不翻车、价格不反悔、现场有人管。**
