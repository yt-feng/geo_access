社区超市卖小包装香蕉，核心是：**采购时就要按“小包装零售”倒推规格、成熟度和周转**，不能按整箱大货思路采。

重点注意这些：

1. **单包规格**
   - 常见做 **2–3 根/包**，重量约 **400–700g**。
   - 如果社区客流偏老年/小家庭，可做 **2根装**；偏年轻上班族，可做 **3根装**。
   - 避免单包超过 **1kg**，否则失去“小包装”意义，也容易压伤。

2. **采购成熟度**
   - 不要采全黄熟蕉，小包装上架后很快发黑、出水。
   - 优先采 **微黄、带青肩** 的香蕉，回店后能自然转黄。
   - 夏季或高温天，成熟度再降一档；冬季可略高。
   - 如果门店没有催熟能力，就找供应商要“已催熟但未全熟”的货。

3. **果指大小和均匀度**
   - 同一包内香蕉粗细、长短尽量一致，卖相好，也减少压伤。
   - 避免过粗大果，小包装里1根就占满，顾客觉得不划算。
   - 果柄切口要整齐，减少腐烂起点。

4. **包装方式**
   - 可用 **透气保鲜袋/打孔袋**，不要完全密封。
   - 完全密封会闷出水汽，加速发黑腐烂。
   - 若用托盘+保鲜膜，膜上要打孔或选透气膜。
   - 标签不要直接贴在蕉皮上，最好贴包装袋或托盘侧面；撕标签容易伤皮。
   - 袋内可放少量吸水纸，但不要直接包紧果身。

5. **损耗控制**
   - 香蕉损耗主要来自：压伤、冻伤、闷腐、过熟、频繁翻动。
   - 采购箱内不要堆太高，小包装分装后也要浅放，避免重压。
   - 门店冷藏温度不要低于 **12–13℃**，香蕉怕冷，低温会皮黑、心硬。
   - 最佳陈列是 **阴凉通风、避晒、避风口**，不是放冷柜。
   - 每天挑出黑斑严重、软烂的，及时折价或做果切/奶昔原料，别等整包报废。

6. **采购量和周转**
   - 小包装香蕉周转要快，建议按 **1–2天销量** 采购，不要一次压太多。
   - 夏天按 **1天** 甚至半天销量控货；冬天可略放宽。
   - 如果门店客流不稳定，先做小批量测试：2根装、3根装各试几天，看动销和损耗。
   - 记录“到货成熟度—上架天数—报废率”，再调整采购成熟度和数量。

7. **供应商要求**
   - 明确要求：果指均匀、无严重机械伤、无黑腐、切口新鲜。
   - 问清到货成熟度、是否催熟、能否退换残次。
   - 如果供应商按整箱混装大小果，小包装损耗会明显升高，最好要求分规格或换供应商。

8. **定价和陈列配合**
   - 小包装适合做 **低价便利装**，但要把损耗算进毛利。
   - 陈列在动线端头或收银附近，减少顾客翻拣。
   - 可设“今日熟度推荐”：微黄适合放2–3天，带黑斑的当天吃，减少顾客挑拣造成的损耗。

简单判断标准：  
**采购时选微黄带青肩、果指均匀、2–3根一包、透气包装、12℃以上存放、按1–2天销量进货。**  
如果到货已经全黄、袋内水汽重、果指大小乱，小包装损耗通常会偏高。
