要避免香蕉到店后很快变黑，核心是 **减少机械损伤 + 控制乙烯 + 控制温湿度 + 分批催熟/存放**。甜品店采购香蕉，通常不是买回来马上卖，而是要做香蕉泥、切片、装饰或烘焙，所以重点不是“放很久”，而是“到店后还能稳定用 1～3 天”。

### 1. 采购时就要选对成熟度
- **不要买已经全黄、带黑点很多的香蕉**：这种到店后基本 1 天内就会继续变黑。
- **优先选 7～8 成熟**：果皮黄中带一点绿，手感微软但不过软。
- 如果当天就要用，可以选 8～9 成熟；如果第二天、第三天才用，选 6～7 成熟更稳。
- **避免买冷藏过的香蕉**：香蕉怕冷，低温会造成表皮快速变黑、发暗。

### 2. 运输和到店搬运要防压防擦
香蕉变黑很多时候不是“熟得快”，而是**被压伤、擦伤后局部氧化变黑**。
- 用周转筐或纸箱装，不要堆太高。
- 避免和硬物、尖锐包装挤在一起。
- 到店后轻拿轻放，不要直接倒出来摔。
- 有损伤的香蕉单独挑出，优先用掉，不要和好香蕉混放。

### 3. 到店后立刻做“分拆 + 去乙烯”
香蕉自身会释放乙烯，扎在一起会互相催熟。
- **把整串香蕉剪成小串或单根**，减少互相催熟。
- 如果暂时不用，**用保鲜膜包住香蕉根部**，因为乙烯主要从果柄和根部释放。
- 不要和苹果、梨、番茄、牛油果等释放乙烯多的水果放在一起。
- 可以放一小包**乙烯吸收剂**在存放箱里，甜品店后厨很实用。

### 4. 存放温度要合适
- **未熟香蕉**：放在 13～16℃ 左右、通风阴凉处。
- **已熟香蕉**：如果 1～2 天内用完，放阴凉通风处即可。
- **不要直接放冷藏**：香蕉皮会很快变黑。  
  但如果已经熟透、准备做香蕉泥或烘焙，可以**剥皮后冷冻**，而不是带皮冷藏。
- 夏天后厨温度高时，可以放空调房或较凉快的储藏区，但不要贴地、贴墙。

### 5. 已经偏熟时，用“分离使用法”
甜品店最稳的做法不是硬保鲜，而是按成熟度分流：
- **全黄无黑点**：适合装饰、切片。
- **带少量黑点**：适合做奶昔、香蕉泥、夹心。
- **黑点较多但果肉没坏**：适合烘焙、香蕉磅蛋糕、马芬。
- **果肉发软出水、有酒味**：不要用于生食装饰，尽快处理或报废。

### 6. 最实用的到店操作流程
1. 到货先检查：挑出压伤、裂口、过熟的。
2. 剪成小串，包根部。
3. 按成熟度分三筐：  
   - 今天用  
   - 明天用  
   - 后天用
4. 今天用的放最方便拿取处；明天用的放阴凉通风处；后天用的尽量偏生。
5. 每天翻看一次，先熟先用。
6. 需要长期保存的，剥皮后密封冷冻，做烘焙或果泥。

### 7. 不建议的做法
- 整串闷在塑料袋里放后厨。
- 放冰箱冷藏带皮香蕉。
- 和苹果、梨等混放。
- 堆压在一起。
- 等到全黑才处理。

**一句话总结：**  
采购时选 7～8 成熟，运输防压，到店后剪小串、包根部、避乙烯、放 13～16℃ 阴凉通风处，并按成熟度分批先用。这样香蕉到店后通常能多稳定 1～3 天，不容易很快变黑。
