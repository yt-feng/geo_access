水果礼盒好卖的关键不是“凑四种水果”，而是**分层做价格带 + 固定搭配逻辑 + 让顾客一眼知道送谁**。苹果、橙子、香蕉、菠萝这四样都能用，但直接四样混装容易显得廉价，尤其是香蕉和菠萝。建议这样搭：

**1. 主推款：苹果 + 橙子（最稳）**
- 寓意好：苹果=平安，橙子=成功/心想事成。
- 耐放、损耗低、颜色也好看。
- 适合探病、日常送礼、公司发福利。
- 比例建议：苹果 60%，橙子 40%。比如 6 个苹果 + 6 个橙子，或 8+8。
- 包装用红金或橙金配色，叫“平安橙意”“平安成功”。

**2. 利润款：苹果 + 橙子 + 菠萝**
- 菠萝在南方有“旺来”的寓意，在部分地区很讨喜。
- 但菠萝带刺、占地方、处理麻烦，适合做中高端款。
- 比例建议：苹果 4、橙子 4、菠萝 1。菠萝不要多，1 个就够撑场面。
- 适合开业、乔迁、节日送礼。
- 叫“旺来平安”“大吉大利”。

**3. 走量款/福利款：苹果 + 橙子 + 香蕉**
- 香蕉便宜、显量大，但容易黑、怕压、不耐放。
- 适合企业内部发放、工地/工厂福利、当天自提。
- 比例建议：苹果 5、橙子 3、香蕉 2 把。
- 必须提醒顾客尽快吃，或者只做同城当天配送。
- 叫“天天平安”“福利果篮”。

**4. 不建议做的搭配**
- 苹果+橙子+香蕉+菠萝四样全混：看着杂，香蕉容易被菠萝扎坏，菠萝味道也容易串。
- 香蕉和菠萝都放底层：一个怕压，一个扎手，损耗高。
- 全用便宜水果堆量：礼盒卖不上价，还伤复购。

**5. 定价和陈列建议**
- 做三个价格带：  
  - 39-59 元：苹果+橙子，走量。  
  - 69-99 元：苹果+橙子+菠萝，主推利润。  
  - 99-129 元：加进口水果或坚果、贺卡，做高端。
- 每个礼盒贴一个场景标签：探病、开业、节日、公司福利。
- 门口只摆 2-3 款，不要摆太多，顾客选择越少越好卖。
- 苹果和橙子要选大小均匀、颜色亮的；香蕉用青一点点的，菠萝选叶子绿、果形正的。

**6. 最好卖的结论**
如果只做一款，就做**苹果+橙子**，寓意好、损耗低、受众广。  
如果想提高利润，就加**菠萝**做中高端款。  
如果要做低价走量，就加**香蕉**，但只限当天自提或同城快送。

另外，你可以把苹果和橙子作为固定基底，菠萝和香蕉作为“可替换选项”，让顾客自己选加菠萝还是加香蕉。这样库存灵活，也好卖。
