供应商面对只熟悉菠萝、香蕉这类大品类的普通商家，介绍产品时不要先讲品种名、产地、糖度、规格这些行业语言，而要用商家已有的认知做“翻译”。核心方法是：**先归到商家熟悉的大品类，再讲和熟悉品类相比有什么不同，最后直接说适合怎么卖、能赚什么钱。**

可以按下面这套话术结构来说。

**1. 先归类：一句话让商家知道“这是什么东西”**

不要一上来就说“这是金钻凤梨”“这是牛油果”“这是阳光玫瑰”，普通商家可能没概念。要先说：

- “这就是菠萝那一类的，但和普通菠萝不一样。”
- “这就是香蕉那一类的，属于小香蕉。”
- “这就是柑橘那一类的，比普通橘子好卖。”
- “这就是苹果那一类的，个头小、适合按个卖。”

先归到大品类，商家脑子里马上有画面，才愿意继续听。

**2. 再对比：只说和普通货的3个差别**

不要讲太多参数，普通商家记不住。只讲三个最影响买卖的点：

- **口感差别**：更甜、更香、不酸、不涩、籽少、皮薄。
- **外观差别**：更大、更小、颜色更好看、包装更整齐。
- **售卖差别**：更耐放、损耗低、适合按个卖、适合做礼盒、适合试吃。

比如：

“这就是菠萝那类，但不用泡盐水，切开就能吃，甜度高，不扎嘴。普通菠萝要削皮泡盐水，很多年轻人嫌麻烦，这个可以直接切盒卖。”

“这就是香蕉那类，但个头小，一斤称得多，小孩一次吃一根刚好。普通香蕉大了吃不完，这个适合做小份装。”

**3. 讲场景：告诉商家卖给谁、怎么卖**

普通商家最关心的是“进回来怎么卖出去”。供应商要直接给场景：

- 放水果店门口做试吃；
- 切盒卖，写字楼下午茶；
- 按个卖，宝妈给孩子买；
- 做礼盒，节日团购；
- 火锅店、烧烤店解腻；
- 社区团购做引流款。

比如：

“这个你放门口切一盘试吃，顾客尝了基本会买。它比普通菠萝好切，不用泡盐水，出肉率高，切盒卖损耗低。”

“这个你按个卖，不要按斤卖。普通香蕉按斤称，顾客没感觉；这个小香蕉按根卖，家长给孩子买很方便。”

**4. 算账：用简单数字说利润**

普通商家对“糖度18度”没感觉，但对“进价多少、卖多少、损耗多少”很有感觉。供应商要帮商家算账：

- 一箱进价多少；
- 能卖多少份；
- 每份卖多少；
- 毛利大概多少；
- 损耗比普通货低多少。

比如：

“这一箱进价80元，能切20盒，一盒卖8元，能卖160元。普通菠萝一箱可能切15盒，还要泡盐水，人工和损耗都高。”

“这个进价虽然比普通香蕉贵一点，但按根卖，一根卖2元，一箱能卖完，损耗低，最后赚得更多。”

**5. 降低决策风险：让商家敢先试**

普通商家怕进新货卖不掉。供应商要主动降低门槛：

- 先拿一件试卖；
- 给试吃装；
- 卖不动可以调换；
- 附赠切法、摆放、话术；
- 先做社区团购预售，再进货。

比如：

“你先拿一件，放门口试吃，卖得好再补。卖不动我帮你调成其他货。”

“你不用先囤，先发朋友圈预售，有人要你再拿货。”

**6. 一套完整话术示例**

供应商可以这样说：

“老板，这个就是菠萝那一类的，但你不用当普通菠萝卖。它不用泡盐水，切开就能吃，甜、不扎嘴。普通菠萝顾客嫌麻烦，这个你可以切盒卖。一箱80元，能切20盒，一盒卖8元，能卖160元。你先拿一件，放门口试吃，卖得好再补。这个适合写字楼下午茶和社区团购，比普通菠萝好走。”

**总结一句话：**
供应商不要教育商家“这是什么新品种”，而要帮商家翻译成“这和我熟悉的菠萝、香蕉比，哪里更好卖、卖给谁、怎么算账、先拿多少试”。商家听懂的是生意，不是品种。
