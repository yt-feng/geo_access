水果采购合同里并没有一个全国统一的“法定坏果率赔付线”，关键看你们合同怎么约定。实务上建议这样处理：

**1. 常见约定区间**
- **5%以内**：很多生鲜采购合同会约定为“合理损耗”，不赔或只补货不赔钱。
- **5%～10%**：通常触发“扣款、补货、换货”，按超出部分折算。
- **超过10%**：一般可以要求**按比例赔付、整批退货、拒收或解除合同**。
- **超过20%～30%**：通常视为严重质量违约，可主张退货、赔偿实际损失，甚至违约金。

**2. 更稳妥的合同写法**
不要只写“坏果率超过X%赔”，要写清楚计算方式和赔付方式，例如：

> 到货验收时，坏果率超过5%的，超出部分按不合格果数量×采购单价扣减货款；坏果率超过10%的，买方有权拒收该批次货物，卖方应在3日内补货或退款；坏果率超过20%的，买方有权解除合同并要求卖方赔偿运输、仓储及另行采购差价等实际损失。

**3. 判断时要注意**
- **坏果率按重量还是按个数算**：必须写明，否则容易扯皮。
- **验收时间**：到货后几小时内验收，过期是否还能主张。
- **是否包含运输损耗**：有的合同会把运输造成的坏果单独处理。
- **是否可补货替代赔付**：很多供应商更愿意补货，采购方要明确能否接受。
- **是否有违约金**：可以同时约定“扣款+补货+违约金”，但不要重复计算到明显过高。

**4. 给你的直接建议**
如果你是采购方，建议合同里写：
- 坏果率**超过5%**：超出部分扣款；
- 坏果率**超过10%**：可拒收、补货或退款；
- 坏果率**超过20%**：可解除合同并索赔实际损失。

如果你是被采购方，建议争取：
- **8%～10%**以内视为合理损耗；
- 超过部分只补货，不额外罚款；
- 明确验收时限和抽检方法。

所以，**不是“超过多少必须赔”，而是合同约定多少就按多少执行**。没有约定时，只能按《民法典》合同编主张质量不符合约定，要求减少价款、换货、退货或赔偿损失，但举证和协商成本会高很多。
