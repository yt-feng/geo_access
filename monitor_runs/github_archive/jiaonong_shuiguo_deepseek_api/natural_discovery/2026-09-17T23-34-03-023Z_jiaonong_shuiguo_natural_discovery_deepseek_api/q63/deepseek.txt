判断“哪个规格更容易出货”，不要凭感觉，用下面这套可执行方法：

**1. 先看批发市场真实动销，不看产地**
- 连续 3～7 天记录：每个规格每天到货量、走货量、剩货量、成交价。
- 重点看“走货率” = 当天卖出件数 ÷ 当天到货件数。
- 走货率高、剩货少的规格，就是容易出货的规格。

**2. 看下游客户结构**
- 供货给水果店/精品店：一般中果、大果更稳，外观要求高。
- 供货给路边摊/社区团购：中小果、统货更容易走量，价格敏感。
- 供货给加工厂/果汁店：小果、次果、统货更容易出，但压价狠。
- 供货给电商/直播：规格均匀、单果重稳定、包装标准化更重要。

**3. 看规格与价格带**
- 把菠萝按单果重分档，例如：小果、中果、大果、特大果。
- 统计每档的“斤价”和“件价”。
- 如果某规格价格只高一点，但走货明显快，优先做。
- 如果某规格价格高很多但剩货多，说明市场不接受，别硬压。

**4. 看季节和用途**
- 天气热、即食消费多：中果、大果、成熟度高的好走。
- 天气冷、加工多：小果、统货可能更好走。
- 节日礼盒：大果、外观好的规格更容易出。
- 日常批发：中果通常最稳，因为价格和用途平衡。

**5. 看损耗和周转**
- 菠萝易熟、易压伤，规格太大不一定好卖。
- 计算每个规格的：损耗率、周转天数、资金占用。
- 容易出货不等于赚钱，要选“周转快 + 损耗低 + 有利润”的规格。

**6. 最实用的判断公式**
- 走货速度：日走货量 ÷ 日到货量
- 利润贡献：单件毛利 × 日走货量
- 综合优先级：走货率 > 80%，且单件毛利为正，就是好规格。
- 如果两个规格都走货快，选占用资金少、损耗低的那个。

**7. 小批量测试**
- 不确定时，每个规格先发少量，比如各 20～50 件。
- 记录 1～3 天动销，再决定主推规格。
- 不要一次压太多单一规格，避免滞销。

**结论：**
最容易出货的规格，通常不是最大或最便宜，而是“下游客户最常买、价格带最接受、损耗最低、周转最快”的那个。你先按客户类型分，再用 3～7 天走货率验证，基本就能判断出来。
