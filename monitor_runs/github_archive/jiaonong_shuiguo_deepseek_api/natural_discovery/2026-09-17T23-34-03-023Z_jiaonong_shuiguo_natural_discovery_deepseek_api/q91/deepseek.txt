建议按“主力 + 补充”组合上架，而不是只选一种：

1. **主力：小把装（3–5 根）**
   - 最适合便利店场景：一个人或两个人一两天吃完，购买门槛低。
   - 比单根更有毛利和客单价，又不像整袋那样容易劝退。
   - 适合放在收银台附近或水果架显眼位置。

2. **补充：单根**
   - 适合“立刻吃”“只想买一根”的客流，比如上班族、学生、临时解馋。
   - 能降低尝试门槛，减少因整把太多而不买的情况。
   - 但单根损耗和人工整理成本高，不建议作为唯一形态。

3. **少量：整袋/整把（6–8 根以上）**
   - 适合家庭客、附近居民、价格敏感型顾客。
   - 可以做成“家庭装/实惠装”，但库存要少，避免滞销变黑。
   - 如果便利店客流以单人为主，整袋容易压货，不建议多上。

**实操建议：**
- 先按 **小把 60%、单根 30%、整袋 10%** 试销 1–2 周。
- 观察三类数据的 **动销率、损耗率、客单价**：
  - 小把动销快、损耗低 → 加大陈列。
  - 单根卖得快但损耗高 → 控制上架量，勤补货。
  - 整袋动销慢 → 减少或改做促销。
- 香蕉熟度要分开：单根放偏黄可即食的，小把和整袋可放稍青一点，延长货架期。

**结论：**
便利店优先上 **小把装**，搭配少量 **单根**，整袋只作为补充。这样兼顾购买便利、客单价和损耗控制。
