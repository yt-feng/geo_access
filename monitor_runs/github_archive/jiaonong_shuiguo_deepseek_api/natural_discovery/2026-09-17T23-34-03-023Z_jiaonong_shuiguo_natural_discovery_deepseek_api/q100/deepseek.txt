要避免香蕉熟过头，核心是**控制采购节奏和储存条件**，而不是等到快坏了再处理。可以按下面几步做：

**1. 采购时就要控制成熟度**
- 优先采购**颜色偏绿、刚转黄**的香蕉，不要买已经全黄甚至带黑斑的。
- 和供应商约定**按成熟度分批送货**，比如一周送2—3次，每次少量，而不是一次囤很多。
- 如果供应商只能给熟蕉，要求**单独标注成熟批次**，优先使用。

**2. 储存要分状态处理**
- **未熟/偏绿**：放在室温、通风处，不要进冷库，否则会冻伤变黑。
- **刚转黄**：放在阴凉通风处，避免堆压，堆太厚中间容易发热催熟。
- **已熟但还没软**：可以进**冷藏**（约10—12℃）减缓后熟，但香蕉皮会变黑，果肉仍可正常使用。
- **已软熟**：尽快用于加工，不要再常温放置。

**3. 食堂可操作的催熟/延缓技巧**
- 不要把香蕉和苹果、梨、西红柿等**释放乙烯**的水果放在一起，会加速成熟。
- 需要延缓时，可**分开存放、减少堆叠**，并适当通风。
- 需要催熟时，才把香蕉和苹果放一起密封。

**4. 用“先进先出”和每日检查**
- 建立**香蕉批次标签**：到货日期、成熟度、预计可用期限。
- 每天检查一次，把**最熟的先拿出来**，安排到当餐或次日使用。
- 不要等出黑斑才处理，**转黄当天就要列入优先使用清单**。

**5. 熟过头前的分流使用**
- 轻度熟：直接作为餐后水果。
- 较熟但没坏：做**香蕉奶昔、香蕉粥、香蕉饼、烘焙香蕉蛋糕/面包**。
- 很熟但未变质：可**去皮冷冻**，后续做冰沙、果酱或烘焙。
- 已经发酸、发黏、有酒味：不要再用，直接报损并记录原因。

**6. 采购量建议**
- 按“**日均用量 × 1.5—2天**”作为安全库存，不要按一周量一次买。
- 夏季或室温高时，进一步缩短到**1天或半天用量**。
- 如果食堂没有加工能力，就尽量**少量多次采购**，这是最有效的办法。

简单说：**买偏生的、少量多次送、先进先出、转黄就优先用、熟软就加工，基本就能把浪费压下来。**
