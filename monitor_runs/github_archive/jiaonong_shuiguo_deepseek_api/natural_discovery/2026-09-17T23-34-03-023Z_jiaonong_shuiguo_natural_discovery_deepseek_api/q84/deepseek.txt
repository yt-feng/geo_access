家庭水果礼盒优先考虑“不容易压坏、老少都能吃、颜色好看、成本可控”。苹果、橙子、香蕉、菠萝这四样里，最稳妥的组合是：

**推荐组合：苹果 + 橙子 + 香蕉，菠萝少量搭配或作为升级款**

具体按家庭人数分：

**1）3—4人家庭：基础款**
- 苹果 4个
- 橙子 4个
- 香蕉 1把，约5—6根
- 菠萝 0—1个  
特点：日常吃、价格稳、接受度高。香蕉容易熟，适合尽快吃。

**2）5—6人家庭：实惠款**
- 苹果 6个
- 橙子 6个
- 香蕉 1把，约6—8根
- 菠萝 1个  
特点：分量够，颜色也好看。菠萝建议选小果或中果，别太大，否则礼盒显得笨重。

**3）送礼/升级款：苹果 + 橙子 + 菠萝 + 香蕉少量**
- 苹果 6个
- 橙子 6个
- 菠萝 1个
- 香蕉 3—4根，或单独小把  
特点：菠萝有“旺来”的好寓意，橙子有“心想事成”，苹果有“平安”，香蕉补充甜香和量感。但香蕉不耐放，送礼要提醒尽快吃。

**不建议的搭配方式：**
- 香蕉放太多：容易压伤、催熟其他水果，礼盒到货后很快变黑。
- 菠萝放太大：占空间、扎手、削皮麻烦，很多家庭嫌处理麻烦。
- 苹果和橙子都放太多：礼盒重、成本高，看起来反而单一。

**摆放建议：**
底层放苹果、橙子，中层放菠萝，香蕉放最上层或单独隔开。香蕉最好用纸包一下，避免和苹果、橙子贴太近，因为苹果和橙子会释放乙烯，催熟香蕉。

**最推荐的家庭团购方案：**
- 苹果 5个 + 橙子 5个 + 香蕉 5根 + 小菠萝 1个  
这个组合大小适中，四口之家能吃3—5天，颜色有红、橙、黄、绿，拍照也好看。

如果只能选三样，优先 **苹果 + 橙子 + 香蕉**；如果要更有礼盒感，再加一个小菠萝。
