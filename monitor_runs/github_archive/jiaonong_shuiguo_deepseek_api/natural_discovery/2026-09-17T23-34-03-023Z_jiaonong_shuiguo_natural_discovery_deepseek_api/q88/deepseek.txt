线上卖水果，差评主要来自两类：**坏果/损耗**和**口感不稳定**。这两件事的根源大多不在客服，而在采购和供应链。下面按可执行的顺序说。

## 一、先定标准，再谈采购

没有验收标准，采购就是碰运气。要按品类明确写出来：

- **成熟度**：几分熟采摘、到仓后几天内可售。比如芒果、猕猴桃要按硬度分级，而不是只看颜色。
- **糖度**：用糖度计抽检，设定下限。例如橙子/柑橘类常见要求糖度 ≥ 11–12°Brix，具体按品类定。
- **果径/单果重**：分级收购，避免大小混装导致客户预期落差。
- **外观容忍度**：允许的疤痕、日灼、轻微压伤比例，写清楚“可接受/拒收”。
- **新鲜度**：采摘到发货的时间上限。

标准要落到合同和验收单上，而不是口头说“要好的”。

## 二、采购环节的关键动作

1. **锁定产区而非只比价**
   同一品种不同产区、不同海拔、不同批次，口感差异很大。优先和固定基地/合作社合作，要求分批次供货，避免“这批甜下批酸”。

2. **看采摘和预冷**
   很多坏果不是路上坏的，是采后没及时预冷。要求：
   - 清晨或低温时段采摘；
   - 采后尽快预冷到适宜温度；
   - 运输全程冷链或控温，尤其浆果、荔枝、桃等。

3. **按成熟度分批采购**
   不要一次囤太多。线上订单波动大，采购节奏要跟销售节奏匹配。易熟水果宁少勿多，卖完再补。

4. **抽检而不是全信供应商**
   每批到仓抽检：
   - 随机开箱，看底层和中间层；
   - 测糖度、硬度；
   - 称重、量果径；
   - 记录坏果率。
   抽检不合格整批退或降级处理。

5. **建立供应商分级**
   按到货合格率、口感稳定度、售后率给供应商打分。连续两批不达标的，减少或停止合作。不要因为便宜一直用问题供应商。

## 三、减少坏果的包装和物流

- **按品类选包装**：浆果用透气盒+缓冲；柑橘类可网套+纸箱；怕压的加隔层。
- **控制装箱量**：不要为了省运费硬塞，挤压是坏果主因之一。
- **快递选择**：易坏品走时效稳定的渠道，偏远地区慎发或加价发。
- **发货前二次分拣**：把已软、有伤、异味的挑出来，宁可少发也别发出去。

## 四、减少口感不稳定的运营手段

- **按批次标注**：同一商品不同批次口感有差异，详情页可写“本批次偏酸甜/偏甜”，管理预期。
- **成熟度提示**：告诉客户“收到后放几天再吃”，减少“没熟就吃”的差评。
- **小份试吃装**：新供应商或新批次先上小规格，收集评价再放大。
- **售后前置**：坏果包赔要写清楚、流程简单。很多差评不是因为坏果，而是因为售后麻烦。

## 五、最简单的落地清单

采购时至少做到：

1. 有书面验收标准（成熟度、糖度、果径、坏果率上限）；
2. 每批抽检并记录；
3. 固定产区、分批采购；
4. 采后预冷+控温运输；
5. 发货前二次分拣；
6. 供应商按合格率分级管理。

**核心逻辑**：坏果靠“采后+物流+分拣”控制，口感靠“产区+成熟度+批次管理”控制。这两件事都是采购端能提前解决的，等客户给差评就已经晚了。
