水果店遇到坏果，处理方式主要取决于**你与供应商的约定**以及**坏果是在哪个环节发现的**。一般可按下面几种情况结算或赔付：

## 1. 到货验收时当场发现坏果
这是最有利的情况。

- **按约定扣重/扣款**：很多生鲜供应商默认有“损耗率”，比如到货后允许 3%～5% 的自然损耗，超出部分由供应商承担。
- **直接拒收坏果**：坏果比例高，可整批拒收或只收好果，坏果部分不结算。
- **拍照留证**：称重、拍照、录视频，记录车牌/送货单/时间，避免事后扯皮。
- **结算方式**：好果按实际重量结算，坏果不计价；若已付款，可要求下次货款抵扣或退款。

## 2. 收货后短时间内发现坏果
比如第二天开箱才发现。

- 先看合同或口头约定有没有**售后时效**，常见是到货后 24～48 小时内反馈有效。
- 在时效内：凭照片、视频、称重记录找供应商，通常按**坏果重量 × 进货单价**扣款或补货。
- 超过时效：供应商可能不认，除非能证明是**隐蔽性坏果**（如外表正常、内部腐烂）。

## 3. 已经卖出去后顾客反映坏果
- 对顾客：一般由水果店先赔或退换，这是门店责任。
- 对供应商：如果你能证明是**进货时就坏**，可以拿顾客反馈、照片、同批次坏果证据去找供应商追偿。
- 但现实中，已售出后的追偿较难，供应商常只认“到货验收”环节。

## 4. 常见的结算/赔付方式
1. **扣重结算**：坏果不计入结算重量。
2. **折价结算**：整批按比例降价，比如坏果多，整单打 8 折。
3. **补货**：供应商下次补同等重量好果。
4. **退款/抵扣**：已付款的，退现金或从下批货款里扣。
5. **共担损耗**：按约定损耗率，超出部分供应商担，范围内门店自担。

## 5. 建议你这样做
- **进货前明确规则**：损耗率多少、售后时效多久、坏果怎么赔，最好写在送货单或微信里。
- **每次验收留证**：开箱视频、称重照片、送货单签字。
- **坏果单独存放**：别和好果混放，方便供应商复核。
- **及时反馈**：一般当天或次日就提，别拖。
- **大额进货可约定**：坏果超过一定比例（如 10%）整车退货或供应商承担运费。

## 6. 一句话原则
**到货验收时发现的坏果，供应商承担；验收后因门店储存不当造成的，门店承担；约定损耗率以内的，通常门店自担，超出部分找供应商。**
