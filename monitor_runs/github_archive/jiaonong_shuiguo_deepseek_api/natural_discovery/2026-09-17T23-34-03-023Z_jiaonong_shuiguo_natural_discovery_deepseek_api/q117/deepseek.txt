先给一个可执行的起步量，再讲怎么调。

**结论：先小批量试卖，别一次压货。**
比较稳的起步量可以按这个公式：

**首批试卖量 = 单店日均预估销量 × 试卖天数 × 1.2～1.5 倍安全系数**

其中：
- **试卖天数**：建议 **3～7天**，水果看的是周转速度，太短不准，太长容易损耗。
- **日均预估销量**：让供应商给同类品种在你同渠道/同区域的历史数据，或者参考你现有最接近品类的销量。
- **安全系数**：1.2～1.5，不要超过1.5，水果不是标品，压多了就是损耗。

**举个可判断的例子：**
如果你预估某新品单店每天能卖 **20斤**，试卖 **5天**：
- 基础量 = 20 × 5 = 100斤
- 加安全系数1.2～1.5 = **120～150斤**

那首批就拿 **120～150斤** 试。先铺1～2个店或1个渠道，不要全渠道同时上。如果供应商要求起订量明显高于这个数，就谈：
1. 混拼其他成熟单品一起发；
2. 先给最小起订量，但要求分2～3批到货；
3. 谈试销期损耗补贴或退换比例。

**试卖期间盯3个指标：**
- **动销率**：3天内卖了多少比例。低于50%就放缓。
- **损耗率**：超过8%～10%就要警惕，水果品类不同标准不同。
- **复购/反馈**：有没有人问第二次、有没有差评集中在口感/成熟度/大小。

**调整规则：**
- 3天动销 **>70%**：可补第二批，量加到首批的1.5～2倍。
- 3天动销 **40%～70%**：维持原量再观察2～3天。
- 3天动销 **<40%**：停止补货，先促销清掉，再决定是否淘汰。

**一句话：首批按“3～7天用量、1.2～1.5倍安全系数”试，先少后多，看动销和损耗再放量。**
