做水果生意想长期稳定，选供应商时最容易忽视的不是价格和品类，而是那些“平时不出事、一出事就断链”的细节。按重要性给你排一下：

**1. 供货稳定性 > 单次价格**
- 很多新手只看谁便宜，忽视对方在旺季、节前、天气异常时能不能持续供货。
- 要问：他的货源是自有基地、长期合作农户，还是临时倒货？临时倒货商在缺货时第一个涨价或断供。
- 判断方法：连续3个月观察他每周报价和到货量是否稳定，而不是看一次报价。

**2. 分级和品控标准是否一致**
- 同一个供应商，这批货好、下批货差，是水果生意最大的隐性成本。
- 要确认：他按什么标准分级（大小、糖度、成熟度、瑕疵率）？能否书面或微信留痕？
- 最容易忽视：**“次果率”处理**。到货后烂果、小果、生果谁承担？有没有补损或扣款机制？

**3. 物流和损耗责任归谁**
- 水果损耗高，很多纠纷出在“谁负责运输温控”和“到货后多久内可反馈”。
- 关键细节：
  - 冷链还是普通车？温度记录能不能提供？
  - 到货后几小时内可提异议？超过时间是否不认？
  - 卸货前还是卸货后验货？一旦卸货，责任往往就转移了。

**4. 结算方式和账期陷阱**
- 低价往往绑定“现结”或“大额预付”，这会占你现金流。
- 要警惕：先给低价吸引，等你依赖后再要求预付、缩短账期或突然涨价。
- 建议：新供应商先小批量现结试单，稳定后再谈账期，不要一上来压重金。

**5. 产地和季节替代方案**
- 只依赖一个产地或一个供应商，遇到台风、霜冻、疫情、道路管控就会断货。
- 要问：这个品类下市后，他有没有替代产地或替代品种？能不能提前给下季计划？
- 长期稳定靠的是“主供应商 + 备用供应商”，不是单一最低价。

**6. 售后和异常处理速度**
- 出问题时，对方是补货、退款还是扯皮？这比平时报价更能决定你能不能长期做。
- 观察细节：微信回复速度、是否主动提前通知缺货、是否愿意承担合理损耗。

**7. 是否了解你的销售场景**
- 你做社区团购、水果店、电商还是批发，对成熟度、包装、规格要求完全不同。
- 好供应商会问你的销售周期和客群，而不是只问“要多少箱”。

**实操建议：**
- 新供应商先做3次小批量试单，分别在不同时间点。
- 每次记录：到货时间、损耗率、规格达标率、售后响应。
- 用“稳定供货 + 品控一致 + 损耗可控 + 账期合理”四项打分，而不是只比价格。
- 至少保留2家同类供应商，主供占70%，备供占30%，防止被单一供应商卡脖子。

一句话：**长期稳定的供应商，不是最便宜的，而是出问题时最可预期、最愿意按规则处理的那一个。**
