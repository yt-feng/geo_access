可以按“等级 + 规格 + 单件净重 + 单价/件”来报，最清楚。香蕉和菠萝分法不一样，下面给你一套批发商可直接用的分级报价模板。

## 一、香蕉分级报价

香蕉建议按：**级别 + 每根规格 + 每件净重 + 成熟度 + 价格** 报。

### 1. 分级标准
| 等级 | 外观标准 | 适合客户 |
|---|---|---|
| 特级 | 果形直、饱满，无黑斑，无擦伤，梳形整齐 | 水果店、精品超市 |
| 一级 | 果形较好，少量轻微擦伤，无烂果 | 普通水果店、社区店 |
| 二级 | 果形一般，有少量斑点、擦伤，不影响食用 | 小店、促销、榨汁 |
| 处理级 | 黑斑多、压伤明显，需尽快卖或加工 | 榨汁店、特价处理 |

### 2. 规格写法
按每根粗细或每件净重写：

- 大果：单根约 120–150g
- 中果：单根约 90–120g
- 小果：单根约 60–90g

报价示例：

> 香蕉一级中果，净重 18斤/件，成熟度 3–4成，¥XX/件  
> 香蕉二级大果，净重 20斤/件，成熟度 4–5成，¥XX/件  
> 香蕉处理级，净重 18斤/件，¥XX/件，不退不换

### 3. 报价必须写清
- 净重还是毛重
- 每件几把/几根
- 成熟度：青、微黄、黄熟、熟透
- 是否允许10%以内外观瑕疵
- 是否包售后：烂果、压伤怎么赔

## 二、菠萝分级报价

菠萝建议按：**级别 + 单果重量 + 品种 + 成熟度 + 价格** 报。

### 1. 分级标准
| 等级 | 外观标准 | 适合客户 |
|---|---|---|
| 特级 | 果形端正，无裂口，无黑心，冠芽完整，单果大 | 精品水果店 |
| 一级 | 果形正常，轻微擦伤，无烂果 | 普通水果店 |
| 二级 | 果形稍偏，有擦伤或小裂口，不影响削皮 | 小店、促销 |
| 处理级 | 裂口、软果、黑心风险高，需尽快处理 | 榨汁、特价 |

### 2. 规格写法
菠萝最关键是按单果重量分：

- 大果：2.5–3斤/个
- 中果：1.8–2.5斤/个
- 小果：1.2–1.8斤/个

报价示例：

> 菠萝一级大果，单果 2.5–3斤，¥XX/件，约6个/件  
> 菠萝一级中果，单果 1.8–2.5斤，¥XX/件，约8个/件  
> 菠萝二级小果，单果 1.2–1.8斤，¥XX/件，约10个/件  
> 菠萝处理级，¥XX/件，适合榨汁，不包黑心

### 3. 报价必须写清
- 品种：台农、金钻、巴厘、香水等
- 单果重量区间
- 每件个数
- 成熟度：青皮、半黄、黄熟
- 是否包黑心
- 是否带冠芽
- 是否去头去尾

|---|---|---|---|---|---|---|---|

## 四、最不容易扯皮的做法

1. **先定等级，再谈价格**：不要只说“好货便宜货”，要说特级、一级、二级。
2. **按净重报价**：小店最怕毛重当净重卖。
3. **写清售后范围**：烂果、黑心、压伤、裂口分别怎么赔。
4. **最好配实拍图**：同一等级拍一张标准图，避免收货时争议。
5. **报价单有效期写短**：比如“本报价3天内有效”，因为水果价格波动大。

一句话：  
**香蕉按“等级+每根大小+净重+成熟度”报；菠萝按“等级+单果重量+品种+成熟度+是否包黑心”报。**  
这样小店一看就知道贵在哪、便宜在哪，后面也少扯皮。
