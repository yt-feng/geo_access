判断水果供应商靠不靠谱，核心看四条：货源稳不稳、货对不对版、价格账算不算得清、出问题认不认账。下面给你一套可以直接用的筛选和验货办法。

**一、先看他有没有稳定货源**

香蕉和菠萝都是产地集中、季节波动大的品类，靠谱供应商通常能说清楚：

- 香蕉主要来自哪里：海南、广西、云南，还是菲律宾、越南、厄瓜多尔等进口；
- 菠萝主要来自哪里：广东徐闻、海南、福建，还是菲律宾、泰国等；
- 换季时有没有替代产区，断货了怎么补。

如果对方只会说“都有货”“你要多少有多少”，但说不清产地和档期，基本要多留个心眼。

**二、看货要对版，不能只看样品**

长期进货最怕“样品好、大货差”。你可以这样做：

1. **先小批量试单**，别一上来就压大单。
2. **香蕉看成熟度、条形、焦尾、黑星病、机械伤**。长期做零售，最好要求供应商能提供不同成熟度的货，或者能帮你催熟。
3. **菠萝看品种、糖度、黑心、水心病、果眼深浅、冠芽状态**。凤梨和普通菠萝口感、损耗、售价差别很大，必须写清楚。
4. **每次到货抽检**，不要只点数量，要开箱看中层和底层。

**三、看价格和结算是否透明**

靠谱供应商一般能做到：

- 报价包含什么、不包含什么说得清楚，比如是否含运费、装卸费、损耗补偿；
- 价格随行就市时，提前告诉你涨跌原因；
- 称重方式明确，是毛重、净重还是扣箱重；
- 账期、押金、退换货规则提前讲清，不临时改口。

如果价格明显低于市场价，还要确认是不是次果、尾货、催熟过度或者混级货。

**四、看出问题后的态度**

这是最能筛掉不靠谱供应商的一环。你可以故意问几个具体问题：

- 到货发现黑心菠萝比例高，怎么赔？
- 香蕉催熟后出现大量断指、青硬，怎么处理？
- 连续两车质量下降，能不能换货或补差价？

靠谱的会说清责任和比例；不靠谱的通常先推给天气、产地、运输，最后让你自己承担。

**五、长期合作建议**

- 至少备2家供应商，一家主供，一家备用，避免被单一供应商拿捏。
- 先试单3到5次，再谈长期账期和独家价。
- 每次到货记录：日期、产地、批次、成熟度、损耗率、售后处理。做一个月，你就能看出谁稳定。
- 对香蕉和菠萝最好分开找专业供应商，不要指望一家什么都强。

**简单判断标准：**
能说清产地和档期、敢让你小批量试、质量波动有售后、价格账透明、愿意长期配合调整成熟度，这样的供应商就值得长期合作。反过来，只靠低价、催你压货、出问题不认账的，不要长期用。
