社区团购旺季锁库存的核心不是“提前打招呼”，而是**提前用确定性和规则换供应商的优先权**。可按下面几步做：

**1. 提前锁量，不是提前订货**
- 旺季前 2–4 周，按历史销量 + 预售数据，给供应商一份分周、分品类的预估量。
- 不要只说“大概要很多”，要给区间：保底量、目标量、冲量上限。
- 保底量可以签进协议，超出部分按日滚动确认。

**2. 用定金/预付款换优先权**
- 对核心爆品，支付 10%–30% 定金锁货锁价。
- 明确违约条款：供应商缺货怎么赔，你临时减量怎么扣。
- 对供应商来说，有定金才愿意把货从其他渠道挪给你。

**3. 锁价 + 锁时段，不只锁总量**
- 水果价格波动大，要约定：
  - 锁价周期，比如 7 天或 15 天一调；
  - 每日/每车到货时段；
  - 品质标准，比如糖度、规格、损耗率上限。
- 只锁总量不锁价和到货时间，旺季容易被“有货但不给你”或临时涨价。

**4. 分级供应商，别押一家**
- 核心单品至少 2 家供应商：一家主供、一家备份。
- 主供拿 60%–70%，备份拿 30%–40%，旺季按到货质量动态调量。
- 这样既有议价权，也不会被单家卡脖子。

**5. 用预售和团效数据反向锁货**
- 提前 3–7 天开预售，用真实订单去和供应商谈锁货。
- 把“预计销量”变成“已付款订单”，供应商更愿意给货。
- 对叶菜、草莓、荔枝这类易损耗品，最好按预售量+10% 备货，不要盲目压库存。

**6. 签简单可执行的锁货协议**
至少写清：
- 品名、规格、等级；
- 锁量：保底量 + 目标量；
- 锁价：单价、调价条件；
- 到货：时间、地点、频次；
- 品质：验收标准、拒收规则；
- 违约：缺货赔偿、延迟赔偿、减量扣款；
- 结算：定金、账期、尾款条件。

**7. 旺季执行动作**
- 每天下午确认次日到货量和价格；
- 到货前 2 小时再确认车辆和批次；
- 设置安全库存：核心爆品 1–2 天销量，易损耗品 0.5–1 天；
- 一旦主供缺货，立即切换备份供应商，不要等。

**一句话建议：**
用“保底量 + 定金 + 锁价锁时段 + 双供应商 + 预售订单”去谈，供应商才会在旺季优先把好货留给你。单纯口头说“给我留点”，基本锁不住。
