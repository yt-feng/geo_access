判断水果报价波动是否合理，不能只看“今天涨了多少”，而要看**波动是否符合品类规律、市场行情和成本逻辑**。可以按下面几步做。

## 1. 先区分：哪些水果本来就会天天变

**波动大的品类：**
- 叶菜类、浆果类、荔枝龙眼、樱桃、桃子、杨梅等
- 特点：保鲜期短、产区集中、天气影响大、上市期短

**波动小的品类：**
- 苹果、梨、橙子、土豆、洋葱等
- 特点：耐储存、全年供应、库存调节能力强

如果供应商对耐储存水果也天天大幅调价，就要警惕；如果对时令鲜果小幅日调，通常正常。

## 2. 建立“合理波动区间”，而不是凭感觉

对每个单品设定一个可接受的日波动范围，例如：

| 品类 | 正常日波动参考 |
|---|---|
| 耐储存水果 | 0%–3% |
| 常规水果 | 2%–5% |
| 时令鲜果 | 5%–10% |
| 极端天气/节日前 | 10%–20% |

这不是固定标准，而是企业内部管控线。超过区间就要供应商提供说明。

## 3. 看报价波动的“方向”和“原因”是否一致

合理波动通常能对应到具体原因：

- **产地天气**：暴雨、寒潮、台风导致减产或采摘受阻
- **季节交替**：尾季货源少，新季未大量上市
- **节日备货**：中秋、春节前需求集中
- **物流成本**：油价、冷链、跨区域运输紧张
- **市场供求**：批发市场到货量明显减少
- **品质变化**：规格、等级、糖度、个头变化

如果供应商只说“市场涨了”，但你说不出具体原因，或者所有品类同时同幅度涨，通常不合理。

## 4. 用三个外部参照交叉验证

### ① 批发市场行情
看当地或主产区批发市场的当日/近三日价格，例如农业农村部信息中心、各地农产品批发市场官网、行业报价群。

### ② 多个供应商比价
不要只问一家。至少保留2–3家供应商报价，看是否同步涨跌。
- 多家都涨：可能是真行情
- 只有一家涨：可能是转嫁成本或试探性涨价

### ③ 历史采购数据
对比自己过去30天、90天、去年同期的采购价。
- 如果今天价格明显高于历史同期，且没有极端天气，就要质疑
- 如果低于历史同期，也要确认是不是品质降级

## 5. 要求供应商提供“调价依据”

可以固定要求供应商在调价时附上：
- 产地收购价变化
- 批发市场参考价
- 规格等级是否变化
- 运输费用变化
- 调价生效时间和有效期

对长期合作供应商，可以约定：
- 单日涨幅超过5%需提前书面说明
- 超过10%需双方确认后再执行
- 报价有效期至少24小时，避免一天多价

## 6. 重点排查“假波动”

以下情况往往不是合理波动：

- 同一单品一天内多次调价，且每次都是上涨
- 涨价时说是市场原因，降价时却不主动降
- 报价低但到货品质差，实际综合成本更高
- 规格、包装、净重悄悄变化，单价看似没涨
- 只给口头报价，不提供书面记录
- 长期只涨不跌，或跌得慢、涨得快

## 7. 实操建议：做一个简单的价格监控表

每天记录：
- 日期
- 单品
- 规格/等级
- 供应商报价
- 批发市场参考价
- 涨跌幅
- 调价原因
- 是否异常

连续记录2–4周后，你就能看出每个单品的正常波动带。超过波动带且无合理解释的，就谈判、换供应商或调整采购比例。

## 结论

判断水果报价是否合理，核心是四句话：

1. **看品类**：时令鲜果波动大，耐储水果波动小。
2. **看幅度**：超过内部设定区间就要说明。
3. **看原因**：天气、季节、供需、物流、品质是否对得上。
4. **看参照**：批发市场、多家供应商、历史价格交叉验证。

如果供应商能做到“调价有依据、幅度有区间、报价有记录”，基本就是正常市场波动；如果做不到，就要按异常波动处理。
