水果店采购菠萝，核心原则是：**不要按“已经最好吃”的标准进，而应按“到店后还能卖几天”的标准进。** 菠萝是后熟型水果，采购熟度要分用途、分销售节奏来定。

可以按下面几个可执行标准判断：

1. **看外观**
   - 适合采购的菠萝：果皮大部分呈青黄到黄绿色，底色开始转黄，但还没全黄。
   - 如果整颗已经金黄、甚至发橙，通常已经偏熟，适合1—2天内尽快卖完。
   - 如果全青、果眼很紧、毫无黄意，后熟慢，适合做特价引流或需要放几天再卖，但口感风险高。

2. **闻气味**
   - 靠近果柄或果底闻：
     - 有淡淡清香：适合采购，能放1—3天。
     - 香味明显、甜香浓：已经较熟，适合当天主推。
     - 有酒味、酸味、发酵味：不要进，损耗风险极高。

3. **按压果皮**
   - 用手指轻按果身：
     - 硬实、几乎按不动：偏生，可放，但卖相和口感要等。
     - 稍有弹性、不软塌：比较合适。
     - 一按就陷、局部软：过熟或内部开始坏，别进。
   - 注意不要只按一个点，要换几个位置，避免局部黑心。

4. **看果柄和底部**
   - 果柄切口新鲜、无霉斑：较好。
   - 果柄干枯、发黑、有黏液：存放久，别进。
   - 底部有汁液渗出、发黏：内部可能已过熟或腐烂。

5. **看果眼和形状**
   - 果眼大而平、颜色转黄：成熟度较高。
   - 果眼尖突、颜色青绿：偏生。
   - 果形饱满、圆整：通常果肉较好；畸形、干瘪的损耗概率高。

6. **按销售策略定熟度**
   - 如果店流量快、当天能卖完：可进七八成熟到接近全熟，香味足、试吃转化高。
   - 如果小店、销量一般：进六七成熟，青黄底色，回店后自然转黄。
   - 如果要切果盒或做促销：可用偏熟果，但必须当天处理。
   - 如果要放3天以上：只进硬实、青黄、无香或微香的果。

7. **采购时的简单比例建议**
   - 当天卖：30%偏熟，70%中熟。
   - 正常周转：20%偏熟，60%中熟，20%偏生。
   - 夏季高温：减少偏熟比例，因为后熟快、损耗快。
   - 冬季低温：可适当增加偏生比例，但别进全青果。

8. **控制损耗的实操办法**
   - 进货后按熟度分区：熟果放最前面，生果放后面或阴凉处。
   - 不要堆压，菠萝怕压伤，压伤后容易局部腐烂。
   - 每天翻检，先卖香味浓、颜色黄的。
   - 切果盒、做特价、榨汁，优先处理偏熟果。
   - 采购时同一批不要全进一个熟度，要分开，方便轮换。

一句话判断：**采购时选“底色开始转黄、有淡淡香味、果身硬实稍有弹性”的菠萝最稳；全青太慢，全黄太险。**
