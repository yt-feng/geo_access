要分两层看：**“固定”能降低波动，但不能消除波动；真正要固定的是验收标准和配方补偿机制，而不是把采购锁死在一个产地/批次上。**

### 1. 完全固定单一产地/批次，风险反而更大
- 水果是农产品，同一产地不同年份、季节、降雨、成熟度都会变。
- 固定单一来源后，一旦减产、涨价、品质下滑，你没有替代方案，只能被动接受或断供。
- 同一“批次”也不可能全年稳定，鲜果尤其做不到。

### 2. 更稳妥的做法：固定“标准”，不固定“唯一来源”
建议采购时这样做：

- **固定品种和等级**：比如指定品种、糖度范围、酸度范围、果径/成熟度、出汁率。
- **固定验收指标**：糖度（Brix）、酸度、香气、颜色、软硬、坏果率、农残检测。
- **固定加工形态**：如果鲜果波动大，可部分改用冷冻果泥、NFC果汁、果酱、浓缩浆，用标准化原料打底。
- **保持2–3个合格供应来源**：主供应商+备用供应商，按同一套标准准入。
- **按批次留样和记录**：每批到货测糖酸、做杯测，记录风味表现。

### 3. 门店端要有“补偿机制”
固定产地解决不了所有问题，配方要能微调：
- 设定糖度、酸度、茶底浓度、冰量、果肉比例的调整范围。
- 每批水果先做小样测试，再决定是否微调糖浆或柠檬/酸味原料。
- 对波动大的品类，优先用“鲜果+标准化原料”组合，而不是纯鲜果。

### 4. 什么时候适合固定产地/批次？
- 你做的是**高端单品**，风味辨识度极强，愿意为稳定性牺牲部分成本。
- 该产地能稳定供货，且有合同锁量、锁价、锁质机制。
- 你有能力做批次检测和配方补偿。

### 结论
**不要只固定一个产地或批次。**
更合理的是：**固定品种、等级、验收标准和加工形态，保留2–3个合格来源，并用配方微调和标准化原料兜底。**  
这样既能控制水果口味波动，又不会把自己卡死在单一供应链上。
