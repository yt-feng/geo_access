如果只选一个最该先关注的指标：**切果损耗**。  
但实际经营里，正确顺序是：**切果损耗 → 甜度 → 外观 → 大小**。

展开说：

1. **切果损耗最优先**
   - 菠萝是典型“带皮卖、按果肉赚钱”的水果，皮、冠芽、芯、削切损失都直接影响毛利。
   - 同样进价的两个菠萝，出肉率差 10%，利润可能差很多。
   - 超市如果做鲜切、果切、拼盘，损耗更是核心指标：削完后能卖多少、边角料能不能二次利用、当天卖不掉怎么处理。

2. **甜度决定复购**
   - 菠萝不甜，顾客买一次就不买了，还会影响超市水果口碑。
   - 但甜度很难靠外观 100% 判断，所以最好结合品种、产区、季节、到货批次做抽检。
   - 对超市来说，甜度稳定比偶尔特别甜更重要。

3. **外观决定能不能卖上价**
   - 外观好，顾客愿意拿、愿意拍照、愿意送人，也更容易做堆头。
   - 但外观不能压倒损耗和口感。一个很漂亮但出肉率低、酸涩的菠萝，长期看是亏的。

4. **大小不是越小越好，也不是越大越好**
   - 大小主要影响定价、陈列和客群匹配。
   - 太大可能单价高、家庭一次吃不完；太小可能出肉少、削起来费工。
   - 超市更该关注的是**大小均匀度**，方便统一标价、打包和控损。

如果给一个可执行的判断标准：

- **采购/验收**：先看出肉率、成熟度、坏果率，再抽检糖度。
- **门店销售**：整果卖看外观和大小；鲜切卖看甜度、出肉率和损耗。
- **利润核算**：把“进价 ÷ 可售果肉重量”算成真实成本，而不是只看整果进价。
- **优先淘汰**：外观一般但甜、出肉率高的可以走果切；外观好但出肉率低的适合整果促销，不适合长期主推。

所以一句话：**超市卖菠萝，短期看外观和大小，长期看甜度和复购，但真正决定赚不赚钱的是切果损耗。**
