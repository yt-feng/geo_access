小水果店做附近小区团购，水果供应商至少要能支持这几类服务，否则后面容易卡在损耗、履约和售后上。

**1. 稳定供货与分级能力**
- 能按团购时间稳定供货，不是今天有明天没。
- 能提供不同等级：引流款、利润款、形象款。
- 最好能按小果店需求做简单分级、分拣，比如大小、成熟度、外观。

**2. 团购价与起批量支持**
- 支持小批量起订，不要一上来就要求整车或大仓起批。
- 能给小店团购专供价，而不是和门店零售价混在一起。
- 价格最好有阶梯：达到多少件返点、补贴或降价。

**3. 预售和按单采摘/备货**
- 小区团购通常是先成团、后到货，供应商要能支持预售模式。
- 能按预估单量备货，也允许临时增减一定比例。
- 对易熟水果，能按到货时间倒推采摘或出库，减少压熟。

**4. 分拣、打包和贴标**
- 能按小区团购规格打包，比如5斤装、3斤装、家庭装。
- 能贴团购标签、门店标签、自提点标签。
- 如果做“到店自提”，最好按自提点或楼栋分好，减少小店二次分拣。

**5. 冷链与短途配送**
- 对草莓、荔枝、樱桃、蓝莓等娇气水果，要有冷藏或冷链支持。
- 能配送到小店、社区自提点或指定分拣点。
- 配送时间要匹配团购到货时间，不能经常临时改点。

**6. 售后与坏果赔付**
- 明确坏果、压伤、腐烂、少重的赔付标准。
- 支持拍照理赔，流程要简单。
- 最好能补发、退款或下次抵扣，而不是只口头承诺。
- 对团购批量售后，要能一次性处理，不用小店逐个扯皮。

**7. 损耗兜底和退换货**
- 对高损耗水果，能接受一定比例退换或折价。
- 成团后卖不完、品质不达标时，有退换或调货机制。
- 如果做预售，供应商要能承担“到货品质不达预期”的主要责任。

**8. 营销素材与产品信息**
- 提供水果图片、视频、卖点、产地、规格、保存方法。
- 提供团购文案、价格建议、建议零售价和活动价。
- 最好能给小店做小区团购的专属素材，而不是通用图。

**9. 结算与对账支持**
- 支持按团、按周或按月结算。
- 能提供清晰对账单：品名、规格、数量、单价、赔付、返点。
- 如果涉及押金、预付款、账期，要提前写清楚。

**10. 售后响应和补货速度**
- 团购最怕到货当天出问题，供应商要能当天响应。
- 爆单后能快速补货，不是只做一锤子买卖。
- 有专人对接小店，不要每次换人、每次重新沟通。

**你筛选供应商时，重点问这8个问题：**
1. 最小起订量多少？
2. 团购价是否含配送和包装？
3. 能不能按自提点分拣贴标？
4. 坏果怎么赔，多久到账？
5. 预售成团后能不能临时加单？
6. 高损耗品有没有兜底？
7. 配送频率和时间能不能固定？
8. 有没有团购素材和对账明细？

**最适合小水果店的供应商，不一定是价格最低的，而是：**
能小批量起订、能按单备货、能分拣打包、能处理售后、能稳定配送。  
因为小区团购赚的是复购和口碑，一次坏果处理不好，可能整个小区群就冷了。
