判断供应商能不能按时到车，核心不是听他口头承诺，而是看他有没有稳定的货源组织能力和真实的发车记录。可以从下面几个可操作的维度去判断：

**1. 先看“车”从哪来**
- 问清楚是自有车辆、固定合作车队，还是临时找车。临时找车的，遇到雨天、旺季、运费波动就容易放空。
- 让他发当天或近三天装车的视频/照片，要求带时间水印或现场能对上货。
- 问车牌号、司机电话、装车时间、预计到达时间，最好直接和司机通一次话，确认已经装车或正在装车。

**2. 看货源是不是真在他手里**
- 香蕉是产地集中、季节性强的品类，真正有能力的供应商通常有固定代办、基地或冷库。
- 问他：这车货是从哪个产区、哪个冷库/档口发的？能不能发定位或现场视频？
- 如果他说“还在地里砍”“还在收”，那到车时间基本不可控，至少要留出1—3天缓冲。

**3. 用“历史记录”验证**
- 合作前让他提供最近几车发往其他市场的记录，比如车牌、市场名、到达时间。
- 可以直接打电话给那个市场的接货人核实，比他说什么都管用。
- 新供应商第一次合作，不要只看价格，先问“最近一周发了几车、有没有延误、延误原因是什么”。

**4. 把时间节点写死**
- 不要只写“某天到”，要写清楚：装车时间、发车时间、预计到达时间、最晚到达时间。
- 约定延误怎么处理：比如超过几小时扣运费、超过一天怎么赔、香蕉成熟度变化谁承担。
- 定金不要一次给太多，最好按“装车后付一部分、到车验收后付尾款”来。

**5. 看他的反应**
- 靠谱的供应商会主动告诉你装车进度、司机电话、路上情况。
- 一问三不知、只催定金、不愿给司机电话、不愿视频看货的，按时到车的概率很低。
- 如果他说“放心，肯定到”，但给不出具体车牌和司机，基本可以当成没发车。

**6. 给自己留后手**
- 香蕉怕熟、怕压、怕耽误，最好同时问1—2家备用供应商。
- 到车时间卡得紧的，提前把卸货、冷库、档口安排好，避免车到了没人卸。
- 第一次合作可以小批量试一车，验证他的发车和到车能力，再放量。

简单说：**能给出车牌、司机电话、装车视频、冷库定位，并且愿意把延误责任写清楚的，才值得信；只给口头承诺、催定金、不给具体信息的，不要赌他能按时到车。**
