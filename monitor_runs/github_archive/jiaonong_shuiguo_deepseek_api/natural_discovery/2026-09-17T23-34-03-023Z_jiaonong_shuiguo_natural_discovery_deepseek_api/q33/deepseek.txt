重要，而且往往是多门店水果品质能不能统一的第一道关口。

原因很直接：门店端能做的主要是收货、陈列、温控和及时挑拣，但水果的**基础品质上限在供应商分级时就已经决定了**。如果供应商的分级标准模糊，比如只写“大果”“精品”“一级”，不同采购、不同批次、不同产地理解不一致，就会出现：

- 同一SKU在不同门店大小、熟度、糖酸比、外观差异明显；
- 采购以为买的是A级，门店收到却是混级货；
- 损耗率、客诉率、毛利率无法横向比较；
- 采购压价时供应商用低一级货补利润，品质继续漂移。

所以，多门店超市要统一水果品质，供应商分级标准不只是重要，而是必须**可量化、可验收、可追溯**。建议至少明确这几类指标：

1. **外观规格**  
   单果重量/直径范围、果形、色泽、瑕疵面积、机械伤、病斑、日灼等允收比例。

2. **内在品质**  
   糖度、酸度、成熟度、硬度、干物质等，至少对核心单品设抽检标准。

3. **成熟度与货架期**  
   是硬熟、转色、即食还是催熟后销售，必须和门店销售节奏匹配。否则总仓分得再均，门店也会有的太生、有的太熟。

4. **允许缺陷比例**  
   不能只写“无严重缺陷”，要写成可判断的百分比，比如：  
   - 轻微外观缺陷果不超过5%；  
   - 严重缺陷果不超过1%；  
   - 单箱混级率不超过3%。

5. **包装与批次一致性**  
   箱规、净重、层数、垫片、标签、批次号、产地、采摘日期、分级日期都要统一，方便门店收货和追溯。

6. **抽检与判定规则**  
   明确抽样数量、合格判定、拒收条件、复检流程、扣款或退换货规则。否则标准只是纸面标准。

7. **供应商分级管理**  
   不只是给水果分级，也要给供应商分级：A级供应商、B级供应商、观察供应商、淘汰供应商。把到货合格率、损耗率、客诉率、退货率纳入考核，和采购量、账期、新品导入挂钩。

对多门店超市来说，最有效的做法通常是：

- 先选10—20个高频核心水果，做统一分级卡；
- 每张分级卡配图片、尺寸图、糖度范围、缺陷示例；
- 总仓和门店用同一套收货验收表；
- 供应商送货必须带批次和分级信息；
- 每月用门店损耗、客诉、销售数据反推分级标准是否合理。

一句话：**供应商分级标准是统一水果品质的源头标准。没有它，门店端再努力也只是在补救；有了它，采购、仓储、门店才有共同语言。**
