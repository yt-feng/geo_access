连锁超市想通过合同压低门店坏果率，核心要把“坏果”定义清楚、责任分清楚、赔付可计算、执行可落地。建议从下面几块写进合同：

**1. 先把“坏果”定义写死**
不要只写“坏果”“损耗”，要列明判定标准，例如：
- 腐烂、发霉、软烂、渗液；
- 碰伤、压伤面积超过一定比例；
- 失水萎蔫、变色、开裂；
- 虫蛀、异味；
- 不符合约定规格（大小、成熟度、糖度等）。
并约定判定时点：到店验收时、上架前、售卖中、闭店盘点时分别怎么算。

**2. 责任按环节划分**
- 供应商责任：采摘、分级、包装、冷链、运输环节造成的坏果；
- 门店责任：收货后存储温度、湿度、堆压、陈列、翻堆、未先进先出造成的坏果；
- 不可抗力或自然损耗：约定合理损耗率，超出部分才赔。
最好按品类设“自然损耗率”，比如叶菜、浆果、根茎类分别不同。

**3. 赔付方式要可执行**
常见有四种，可组合：
- **按件赔付**：坏果数量 × 进货单价 × 赔付倍数；
- **按金额扣款**：当期坏果金额直接从货款中扣；
- **补货赔付**：供应商补发同等数量合格品，运费由责任方承担；
- **违约金**：坏果率超过约定阈值，按批次货值或月度供货额比例支付违约金。
建议写明：赔付不影响超市要求补货、退货、换货或解除该批次订单的权利。

**4. 设置坏果率阈值和阶梯**
例如：
- 批次坏果率 ≤ 3%：正常损耗，不赔；
- 3%＜坏果率 ≤ 8%：按超出部分货值 1 倍赔付；
- 8%＜坏果率 ≤ 15%：按超出部分货值 2 倍赔付，并补货；
- ＞15%：整批退货，供应商承担运费，并按该批货值 30% 支付违约金。
具体比例按品类和毛利调整，别一刀切。

**5. 验收和取证流程**
合同要约定：
- 收货时双方共同验收，拍照、称重、记录；
- 门店发现坏果后多长时间内通知供应商；
- 供应商多久内到场确认，逾期视为认可；
- 留存照片、视频、盘点单、系统记录；
- 争议时以第三方检测或双方共同封样为准。

**6. 结算和扣款授权**
写清楚：
- 超市有权从应付货款、保证金中直接扣除赔付金额；
- 供应商对扣款有异议的，应在几个工作日内提出，否则视为同意；
- 每月对账时列明坏果批次、数量、金额、扣款依据。

**7. 防止责任转嫁过头**
如果门店自己冷链断了、堆压严重、没按先进先出，却把坏果全算供应商，容易引发争议。合同里最好写：
- 供应商只对交付时及运输环节质量负责；
- 门店收货后因存储、陈列不当导致的坏果，由门店承担；
- 双方每月复盘坏果数据，按品类调整损耗标准。

**8. 建议加一条考核激励**
比如：
- 月度坏果率低于目标值，给予返点或优先续约；
- 连续超标，超市可调整供货份额、暂停新品、终止合同。
这样比单纯罚款更能压降坏果率。

**一句总结：**
合同里不要只写“坏果赔付”，而要写成：**坏果定义 + 责任环节 + 损耗阈值 + 阶梯赔付 + 取证流程 + 直接扣款 + 月度复盘**。这样门店坏果率才降得下来，赔付也吵不起来。
