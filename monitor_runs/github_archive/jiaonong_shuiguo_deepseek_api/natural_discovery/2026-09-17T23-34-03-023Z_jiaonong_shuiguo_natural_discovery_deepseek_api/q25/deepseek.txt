# 超市门店多、单店量不大，适合的水果供货模式

核心矛盾是：**门店多意味着总需求不小，但单店量小意味着单个门店没有议价权、也撑不起直采。** 所以关键不是"找大供应商"或"自己直采"二选一，而是按品类分层设计供货结构。

## 一、先做品类分层，不同品类用不同模式

| 品类 | 特征 | 推荐模式 |
|---|---|---|
| 苹果、梨、柑橘、香蕉等大宗常销品 | 需求稳定、耐储、标准化高 | 产地直采 / 区域大供应商统采，走总仓分拨 |
| 时令爆品（荔枝、西瓜、樱桃等） | 季节性集中、走量快 | 产地代采或产地直发总仓，短期集中操作 |
| 叶菜、草莓、蓝莓等易损品 | 损耗高、周转要求快 | 本地批发市场 / 本地供应商日配 |
| 精品、进口果 | 单店量小、单价高 | 专业进口商或区域精品供应商，小批量多频次 |

**结论：不要用一种模式覆盖所有水果。** 大宗走直采降成本，易损走本地保新鲜，精品走专业商保品类。

## 二、门店多但单店量小，最适合的三种落地模式

**1. 总仓集单 + 统一分拨（最推荐）**
- 各门店需求汇总到总仓/配送中心，由总部统一向供应商或产地下单。
- 用"多店合单"把单店小量拼成有议价权的整批货，再分拨到店。
- 适合：大宗果、时令果。能显著压低采购价和物流单价。

**2. 区域供应商 + 多门店拼单配送**
- 按城市/区域找1-2家本地水果供应商，让其按片区给多家门店合并配送。
- 你不需要自建冷链，供应商承担分拣和配送，按片区结算。
- 适合：没有总仓、门店分散、易损品为主的情况。

**3. 产地代采 / 产地直发**
- 找产地代办或合作社，按你的总需求量集中采购，直发总仓。
- 单店量小没关系，只要**总量够一个整车或一个批次**即可。
- 适合：时令爆品、大宗单品冲量。

## 三、关键操作要点

- **总部统一谈价、统一结算**：门店多就是筹码，绝不能让单店各自找货，否则量分散、价格高、品质乱。
- **设置起订量和拼单机制**：把单店小需求按品类/区域合并，达到供应商起订线再下单。
- **易损品本地化、耐储品远端化**：这是控制损耗和成本的核心原则。
- **用数据定品**：统计各店销量排名，只对 Top 单品做直采，长尾品交给供应商配齐。
- **先跑通一个区域再复制**：别一上来全部门店铺开，先在一个片区验证供货和配送，再复制到其他区域。

## 四、一句话建议

**总部集单、按品类分层：大宗直采走总仓，易损本地日配，精品找专业商，用"多店拼单"把小单店量凑成议价能力。** 这样既不用自建重资产供应链，又能把门店多的规模优势用起来。
