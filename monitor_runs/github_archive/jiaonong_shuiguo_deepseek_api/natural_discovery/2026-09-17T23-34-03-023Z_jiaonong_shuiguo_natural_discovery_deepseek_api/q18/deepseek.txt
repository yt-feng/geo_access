核心是：**先定“打算几天吃完”和“怎么吃”，再按成熟度挑，不要只看颜色。**

**到店挑香蕉的判断**
- **当天或第二天吃**：选**通体黄、带少量小黑点**的。黑点越多越熟，甜但放不久。
- **2–3天内吃**：选**黄中带一点青肩**，也就是两头或棱线略青，捏起来微软但不塌。
- **3–5天吃**：选**整体偏青黄、摸起来硬**，回家常温放熟。不要冷藏，冷藏会变黑、口感差。
- **想做奶昔/香蕉面包**：可以买**黑点较多、已经很软**的，通常也便宜。
- **不要买**：表皮发灰、发暗、冻伤斑、破口流汁、整串软塌或有酒味/酸味的。太青但已经软塌也可能内部坏了。

**到店操作建议**
1. **整串看根部**：根部发黑、发霉、湿黏的别拿，容易整串坏。
2. **轻捏中段**：想马上吃就挑“微软”；想多放就挑“硬”。
3. **按棱线判断**：棱线明显、手感硬，说明还生；棱线变圆、手感软，说明熟。
4. **分开买**：如果家里有人马上吃、有人过几天吃，直接买两串不同成熟度，比买一串“刚刚好”更稳。
5. **看季节和室温**：夏天熟得快，买青一点；冬天室温低，买黄一点。

**回家后怎么控制**
- **想催熟**：和苹果或梨一起放纸袋里，常温1–2天。
- **想慢熟**：单根分开，减少挤压，放阴凉通风处；成熟后可冷藏1–2天，但皮会变黑，果肉仍可吃。
- **已经熟透吃不完**：去皮切段冷冻，做奶昔或烘焙。

一句话：**当天吃买黄带黑点，2–3天吃买黄带青肩，3天以上买青黄硬香蕉；别买软塌、破口、发霉的。**
