对水果小商家来说，现金结算和月结账期的风险不是“哪个更安全”这么简单，而是两类风险的性质不同：

**现金结算的主要风险**
1. **资金压力集中在当下**：每次进货都要立刻掏钱，旺季或节假日前囤货时，现金流容易被抽干。
2. **采购量受限**：手头现金不够时，可能错过低价大批量进货的机会。
3. **账目混乱风险**：现金交易如果没有当场记录、让对方签字或开收据，后期对账、退货、换货时容易扯皮。
4. **人身与保管风险**：携带大量现金去批发市场，存在丢失、被盗、收到假币的可能。
5. **税务与合规风险**：长期大额现金往来，若没有合规票据，入账和税务处理会比较被动。

**月结账期的主要风险**
1. **供应商信用风险**：账期本质是供应商给你垫资，一旦你经营下滑或回款慢，可能被断供。
2. **隐性涨价**：愿意月结的供应商，报价往往比现金价高，或者把账期成本折算进单价。
3. **欠款累积失控**：水果损耗高、周转快，如果销售不及预期，欠款会越滚越大，最后变成债务压力。
4. **对账纠纷**：月结通常涉及多次送货、退换货、损耗扣款，若没有逐笔确认，月底容易对不上账。
5. **关系绑架**：长期月结后，供应商可能以此要求你优先采购、接受较差品质或提价。
6. **合同与法律风险**：如果只是口头月结，没有书面约定账期、利息、违约责任，一旦纠纷很难维权。

**更实际的判断标准**
- 如果你**现金流稳定、采购量小、追求低价**：现金结算更划算，但必须笔笔留凭证。
- 如果你**周转快、有稳定下游回款、需要扩大采购**：月结能缓解资金压力，但要控制欠款上限和账期长度。
- 不管哪种方式，都建议：**每笔交易留单据、定期对账、设定赊账上限、避免只靠口头约定**。

简单说：现金结算的风险是“当下没钱”，月结的风险是“以后欠钱”。小商家最怕的不是选错一种，而是没有对账和额度控制。
