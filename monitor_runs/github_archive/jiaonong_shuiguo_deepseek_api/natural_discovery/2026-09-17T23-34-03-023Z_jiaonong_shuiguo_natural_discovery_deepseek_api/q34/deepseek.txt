结论：**对最终毛利的影响，通常是“损耗低”比“采购价低”更关键，但要看品类和损耗弹性。**

可以这样判断：

**1）先看毛利公式**
毛利 ≈ 销售额 - 采购成本 - 损耗成本 - 运营分摊  
其中损耗不是小项，而是会直接吃掉销量和利润。

举例：  
- 采购价低 10%，但损耗从 8% 升到 18%，很可能净利润反而下降。  
- 采购价高 5%，但损耗从 15% 降到 5%，最终毛利通常更好。

**2）为什么损耗更影响最终毛利**
水果是高频、短保、非标品，损耗会同时打击三件事：  
- 可售数量减少  
- 临期降价拉低客单和毛利  
- 影响陈列、复购和门店形象  
所以损耗每上升 1 个百分点，往往不是简单少 1% 利润，而是成倍侵蚀毛利。

**3）什么时候“价格低”更重要**
以下情况，低价采购的权重会上升：  
- 品类耐储、周转快，如苹果、橙子、梨  
- 有稳定大宗走量，能快速清货  
- 采购价差异极大，且能控制住损耗  
- 用于引流，不指望单品高毛利

**4）什么时候“损耗低”绝对优先**
以下情况，必须优先控损耗：  
- 高损耗品类：草莓、蓝莓、荔枝、樱桃、桃子、葡萄  
- 门店客流不稳定、冷链弱、陈列时间长  
- 采购团队对品质判断弱  
- 促销和定价能力不足

**5）实操判断标准**
可以用一个简单指标：  
**单位可售毛利 = 售价 - 采购价 - 单位损耗成本**

如果两个货源对比：  
- A：采购价低 8%，损耗高 10 个百分点  
- B：采购价高 5%，损耗低 8 个百分点  
通常 B 更优，因为 B 的可售率和周转更稳。

**6）给商超采购的建议**
优先顺序建议是：  
1. 先控损耗：冷链、验收、分级、先进先出、日清  
2. 再谈价格：用稳定销量换采购折扣  
3. 最后做结构：引流品低毛利，利润品靠低损耗  
4. 用数据复盘：按品类看“采购价差 vs 损耗率差 vs 最终毛利”

一句话总结：  
**水果采购里，低价决定“看起来能不能赚”，损耗决定“最后到底赚不赚”。多数情况下，损耗低对最终毛利的实际影响更大。**
