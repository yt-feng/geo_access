线上卖菠萝，核心不是“哪种形态更好”，而是“哪种形态匹配你的履约能力、客单价和损耗承受力”。直接给结论：

**按线上适配度排序：切配 > 整果 > 冷冻原料**（前提是冷链能力正常）。如果冷链弱、客单价低，则反过来：**整果 > 切配 > 冷冻原料**。

下面是可判断的依据。

**整果**
- 适合：冷链要求低、履约简单、客单价低、走量。
- 优势：损耗风险低，不怕温控波动，退货争议少，毛利结构简单。
- 劣势：客单价低，用户要自己削，线上复购驱动弱；菠萝外观差异大，差评容易集中在“大小/成熟度不一致”。
- 适合场景：社区团购、产地直发、低价引流。

**切配（鲜切）**
- 适合：有冷链、当日达/次日达、客单价中等以上、想做复购和溢价。
- 优势：即食体验好，客单价和毛利更高，容易做组合装、下午茶场景，复购强。
- 劣势：损耗高，必须全程冷链，保质期短，切配后微生物风险和出水问题会放大差评；对加工环境和时效要求高。
- 关键判断：**如果你做不到“切配后 24 小时内到用户手里 + 全程 0-4℃”，就不要主推切配。**

**冷冻原料**
- 适合：B端、餐饮供应链、烘焙/饮品原料、长期囤货场景。
- 优势：保质期长，损耗低，履约稳定，适合标准化。
- 劣势：C端家庭即食体验差，解冻后口感明显下降，线上消费者预期容易错位，退货和差评风险高；客单价和复购逻辑都不如鲜切。
- 关键判断：**冷冻菠萝更适合卖给奶茶店、餐饮店、烘焙店，不适合作为生鲜电商 C 端主推款。**

**实操建议**
1. 如果你做 C 端生鲜、冷链一般：主推整果，切配做高毛利补充。
2. 如果你做 C 端、冷链强、时效快：主推切配，整果做低价引流。
3. 如果你做 B 端或饮品原料：主推冷冻原料，整果和切配按客户需求配。
4. 不要同时把三种形态都当主品，会分散库存和履约资源。先选一个主形态，再配一个补充形态。

一句话：**C 端线上优先切配，但前提是冷链和时效过关；冷链不过关就卖整果；冷冻原料走 B 端。**
