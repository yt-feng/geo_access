餐饮店每天少量水果，最省心的选择通常不是大型批发商，而是**本地中小型水果配送商/生鲜B2B平台**，其次才是批发市场固定档口。关键看三点：**能按日/隔日送、能少量起送、坏果能赔**。

下面按省心程度排序给你建议：

**1）本地生鲜B2B平台（较省心）**
- 代表类型：美菜、快驴、菜划算这类，以及各地本地的餐饮供应链平台。
- 优点：线上下单、次日达、有售后、起送量相对低。
- 缺点：水果品质波动比专业水果商大，热门品类偶尔缺货。
- 适合：每天用量不大、SKU少、不想自己盯采购的店。

**2）本地中小水果配送商（最推荐）**
- 怎么找：在本地餐饮群、菜市场、同行群里问“谁给餐饮店送水果”；或直接找附近水果店谈长期配送。
- 优点：可以谈每天送、少量送、按月结，坏果直接换，灵活。
- 注意：一定要先试送1周，看准时率、新鲜度、损耗处理。
- 适合：每天少量但要求稳定新鲜的餐饮店。

**3）批发市场固定档口（适合会挑货的人）**
- 优点：价格低、品类全。
- 缺点：要早起、要自己搬、少量拿货价格优势不大，售后麻烦。
- 适合：有店员顺路采购，或用量虽少但品类固定。

**4）大型商超/会员店（最不推荐长期用）**
- 优点：品质稳、随时买。
- 缺点：单价高、不适合每天少量补货，长期成本高。
- 适合：临时应急。

**选供应商时重点问这5个问题：**
1. 最少起送多少？能不能每天送/隔天送？
2. 几点前下单、几点送到？错过饭点能不能补？
3. 坏果怎么赔？拍照就行还是必须退回？
4. 能不能固定品类和规格？比如苹果大小、香蕉熟度。
5. 结账方式：现结、周结还是月结？

**最省心的组合建议：**
- 主供应商：本地中小水果配送商，签简单月结，每天送。
- 备用供应商：一个生鲜B2B平台，缺货时补。
- 应急：附近水果店，临时救急。

**避坑提醒：**
- 不要只图便宜找流动摊贩，今天有明天没，品质不稳。
- 不要一次订太多，水果损耗比蔬菜快。
- 先小批量试送3-7天，再决定是否长期合作。
- 把“坏果包赔”写进微信聊天记录里，也算简单凭证。
