判断一批香蕉，核心是看“颜色、手感、果柄、果面、气味”五个维度，再结合季节和运输方式判断风险。下面给你一套可直接在现场用的判断方法。

## 一、先看颜色：判断熟度阶段

香蕉熟度一般分 7 个色阶：

1. 全青硬  
2. 青中带微黄  
3. 青黄各半  
4. 黄多青少  
5. 全黄，无斑点  
6. 黄带少量糖斑  
7. 黄带大量褐斑，甚至发黑

批发拿货建议：

- **想囤 3–7 天再卖**：拿 2–3 号色，青黄之间，硬身。
- **想 1–3 天内卖**：拿 4–5 号色。
- **当天或次日促销**：拿 5–6 号色，但必须当天走货。
- **6–7 号色**：风险高，除非做特价、烘焙、果汁，否则慎拿。
- **1 号全青**：如果催熟条件好、气温合适，也可拿，但要看是否“死青”。

注意：  
如果全青但果身已经发软、果柄发黑，可能是“冷伤”或“闷伤”，这种很难正常催熟，风险大。

## 二、摸手感：判断成熟度和是否软腐

用手轻捏果身中段：

- **硬实、回弹好**：熟度低，耐放。
- **微软、有弹性**：熟度中等，适合近期卖。
- **明显发软、按下去不回弹**：过熟或开始坏。
- **局部特别软**：可能是内伤、压伤、腐烂起点。
- **整把都软但颜色还青**：可能是冷害或催熟不均，风险高。

重点摸：

- 果指中段
- 果指与果柄连接处
- 蕉梳切口附近

这些地方先软、先黑，往往先烂。

## 三、看果柄和切口：判断新鲜度和是否闷坏

- **果柄青绿、切口新鲜**：通常较新鲜。
- **果柄发黑、干缩**：存放久或运输时间长。
- **切口发黑、发黏、有汁液**：容易从切口感染，坏果风险高。
- **果柄一碰就掉**：过熟或已开始腐坏。
- **蕉梳连接处发黑腐烂**：整把可能从内部坏。

如果切口有酸味、酒味，基本可以判定已经开始变质。

## 四、看果面：找坏果和隐藏风险

重点看：

- **黑斑**：少量糖斑正常；大片黑斑、凹陷黑斑要警惕。
- **水渍状斑**：像被水泡过，通常是腐烂前兆。
- **裂口**：容易感染，尤其夏天。
- **压伤**：运输挤压造成，表面可能看不出来，但摸得到软块。
- **虫眼、霉点**：直接拒收或挑出。
- **果指之间有黏丝、汁液**：说明已有烂果污染。

还要翻看箱底和中间层。  
很多坏果不在表面，而在箱底、中间、靠边受压处。

## 五、闻气味：判断是否内部发酵

- **清香味**：正常。
- **酒味、酸味、甜腻发酵味**：过熟或内部腐烂。
- **霉味**：有霉菌感染。
- **无味但果身软**：可能冷害或存放过久。

只要闻到明显酒味、酸味，整批货的保鲜期通常很短。

## 六、结合季节和运输判断风险

### 夏天高温
- 熟得快，坏得也快。
- 拿 2–3 号色更稳。
- 避免拿 5 号以上。
- 注意箱内发热、闷味。

### 冬天低温
- 警惕冷害。
- 冷害表现：果皮发暗、发灰、青而不熟、果身软、催熟后不上色。
- 从冷库直接拿出的货，要看是否有“青软”现象。

### 长途运输
- 看切口、果柄、箱底。
- 运输时间长，压伤和切口感染风险高。

### 催熟货
- 如果已经催熟过，颜色均匀但果柄还青，可能催熟不均。
- 催熟过度的货，货架期短。

## 七、现场快速判定表

| 情况 | 熟度 | 坏果风险 | 建议 |
|---|---|---|---|
| 全青硬实，果柄青 | 低 | 低 | 可拿，适合囤 |
| 青黄各半，硬实 | 中低 | 低 | 适合 3–7 天卖 |
| 黄多青少，微软 | 中 | 中 | 1–3 天卖 |
| 全黄无斑，微软 | 中高 | 中 | 尽快卖 |
| 黄带糖斑，稍软 | 高 | 中高 | 当天到次日卖 |
| 大片黑斑，软 | 过熟 | 高 | 慎拿 |
| 青但软，果柄黑 | 异常 | 高 | 可能冷害/闷坏，别拿 |
| 有酒味酸味 | 变质 | 很高 | 拒收 |

## 八、拿货时的实操建议

1. **不要只看表面**：翻箱底、看中间层。
2. **随机抽 3–5 把**：摸中段、看果柄、闻切口。
3. **问清采摘和运输时间**：时间越长，风险越高。
4. **问催熟情况**：是否催过、催到什么色阶。
5. **按销售速度拿货**：卖得慢就别拿熟货。
6. **夏天少拿多补**：避免一次压太多。
7. **冬天防冷害**：青软、发暗的货不要。
8. **坏果率超过 5%–10%**：要么压价，要么拒收；超过 10% 风险已经很高。
9. **切口发黑发黏、有酒味**：直接判高风险。
10. **整批颜色不均**：可能催熟不均或混装，后续管理麻烦。

**青硬柄青可囤，黄软柄黑快走；青软酒味是坏货，黑斑水渍风险高。**
