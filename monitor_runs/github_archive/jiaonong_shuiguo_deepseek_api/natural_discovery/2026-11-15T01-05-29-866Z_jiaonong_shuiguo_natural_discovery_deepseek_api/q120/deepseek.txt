核心原则：**别用产地术语和品种编号开场，先用商家熟悉的“卖法”翻译产品**。可分三步说。

**1. 先对标：把它挂到商家已知的品类上**
- 说“这是菠萝的升级款/替代款”，而不是直接甩“金钻凤梨”“台农17号”。
- 句式：“跟您常卖的菠萝比，它**更甜、不用泡盐水、切开就能吃**。”
- 香蕉同理：“跟普通香蕉比，它**更糯、皮更薄、熟得快**，适合做即食果切或下午茶场景。”

**2. 再用商家语言讲三个决策点**
供应商介绍时按这个顺序说，商家最容易判断：
- **怎么卖**：按个卖、按斤卖还是做果切/礼盒？目标客群是家庭还是餐饮？
- **卖多久**：货架期几天、什么时候最好卖、损耗风险在哪。
- **赚多少**：进货价对比现有同类，建议零售价多少，毛利大概几个点。
- 例：“这个凤梨适合按个卖，家庭客单价能上去；常温放5天没问题；进价每斤比普通菠萝高1块，但零售能高3块，毛利更厚。”

**3. 给一个“先小批量试”的台阶**
商家最怕压货。直接说：“先拿一箱试卖，卖不动我们支持调换/补损耗。”比讲十句品种优势都管用。

**避坑提醒：**
- 少说“糖度18度”“海拔800米”这类参数，除非商家主动问。
- 别说“这个品种您肯定知道”，商家不知道会不好意思问，反而不敢下单。
- 用对比句，不用形容词堆砌：“比您现在卖的**更耐放/更好剥/出肉率更高**”。

一句话模板：**“这就是您卖的菠萝的升级版，好处是免泡盐水、按个卖毛利更高、先拿一箱试卖不压货。”**
