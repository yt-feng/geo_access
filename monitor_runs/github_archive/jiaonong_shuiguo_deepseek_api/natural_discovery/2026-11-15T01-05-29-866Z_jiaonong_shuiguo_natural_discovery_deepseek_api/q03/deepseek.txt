第一次试单，核心不是“找最便宜的”，而是用最小成本验证三件事：**货稳不稳、损耗大不大、结账和售后靠不靠谱**。香蕉、苹果、橙子建议分开试，不要一次在一个供货商身上压全品类。

**1. 试单前先定好标准**
- 每样先试 **1—2箱/件**，总试单金额控制在你能承受当天卖不完的范围内。
- 提前问清：是否送货到店、起送量、结算方式（现结/周结）、破损和烂果怎么赔、换货时限。
- 要求供货商发当天或前一晚的实拍货，不要只看图片库。

**2. 三个品类分别怎么验**
- **香蕉**：重点看成熟度和催熟一致性。试单时看青黄比例、有没有明显压伤、到店后2—3天能否正常转黄。香蕉损耗和催熟风险最高，第一次别拿太多，先看它给你的货是否适合你店里的客流速度。
- **苹果**：重点看规格是否统一、硬度、碰伤和果面。开箱抽查上下层是否一致，别只看表层。苹果相对耐放，适合用来判断供货商是否“表里如一”。
- **橙子**：重点看新鲜度、皮厚薄、大小均匀度和失水情况。切开或剥几个看汁水，留意有没有发软、异味、霉点。橙子试单可以顺带验证供货商对“坏果”的处理态度。

**3. 试单时做简单记录**
每批货记下：进货价、数量、到店时间、开箱坏果数、当天卖出量、2—3天后剩余和损耗。连续试 **2—3次** 再决定是否长期合作，不要一次就定。

**4. 建议的试单节奏**
第一周找 **2家** 供货商小量对比：同一品类各拿一点，比较到货质量、损耗和售后。第二周对表现好的那家加量，但仍保留一个备选。夫妻店最怕断货和烂货，保留备选比压价更重要。

**5. 谈的时候直接问这几句**
“这批货今天到店，坏果怎么算？”“上下层不一样能不能换？”“香蕉催熟到什么程度适合我这种小店？”“起送多少？多久送一次？”“先小量试两三次，可以吗？”

**判断标准**：到货新鲜、规格稳定、坏果少且售后爽快，就可以继续；如果第一次就出现上下层不一致、坏果不认、送货不准时，直接换，不要因为便宜几毛钱将就。
