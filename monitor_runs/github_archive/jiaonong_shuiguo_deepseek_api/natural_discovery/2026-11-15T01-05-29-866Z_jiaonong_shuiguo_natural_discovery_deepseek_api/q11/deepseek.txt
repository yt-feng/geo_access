会影响，但不一定是坏事。关键看你怎么卖、怎么定价、怎么陈列。

**会影响销售的情况：**
- 大小混装但按“统货”一个价卖：顾客会挑大的，剩下小的难卖，损耗变高。
- 大小差异太大：顾客会觉得品质不稳定，尤其送礼或做果切、奶茶店的客户更在意规格统一。
- 没有分级陈列：好果和次果混在一起，整体卖相被拉低。

**不一定影响、甚至能提高销量的做法：**
- **分级销售**：大果、中果、小果分开卖，分别定价。大果做礼盒/精品，中果走量，小果做促销或果切原料。
- **按用途卖**：小果适合做香蕉奶昔、果切、甜品店原料；大果适合零售和送礼。
- **混装做促销**：明确标注“大小混装特价”，吸引价格敏感顾客，但不要冒充精品果。
- **控制采购标准**：如果门店主要做零售精品，采购时尽量选规格相对均匀的；如果做社区平价店，混装+分级反而能降低采购成本。

**判断建议：**
1. 先看你店里的客群：送礼/精品客多，大小不均影响大；社区日常消费，影响小。
2. 看差价：混装采购价比统货精品低多少，能不能覆盖分拣和损耗成本。
3. 看销量结构：如果小果能通过果切、促销快速走掉，混装可以接受；否则优先采购规格均匀的。

简单说：**大小不一会影响销售，但通过分级、分用途、明示促销可以化解；最怕的是混在一起按一个价卖。**
