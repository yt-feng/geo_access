结论先说：**多数餐饮连锁更适合“中央厨房/区域配送中心统一收货”，门店只做验收确认和少量应急直采**。但这取决于水果品类、门店密度、配送半径和损耗承受能力，不是一刀切。

## 判断框架

| 维度 | 中央厨房/DC统一收货 | 门店分开收货 |
|---|---|---|
| 采购议价 | 量大，议价强 | 分散，议价弱 |
| 品质标准 | 可统一分级、统一验收标准 | 各店标准不一，易扯皮 |
| 食品安全追溯 | 集中留证，追溯清晰 | 分散，追溯难 |
| 损耗控制 | 集中分拣可剔次果，但二次搬运增加损耗 | 一次到店，搬运少，但门店验收能力参差 |
| 配送时效 | 依赖冷链和配送半径，远距离易损 | 到店快，适合短保高损品 |
| 门店操作 | 减少门店采购人力 | 店长/店员要花时间收货、验货、对账 |
| 腐败风险 | 集中库存若周转不灵，风险集中 | 风险分散，但单店积压也常见 |

## 建议按品类分流

**适合中央厨房统一收货：**
- 耐储水果：苹果、橙子、梨、西瓜、哈密瓜等
- 标准化程度高的：预包装果切原料、罐头/冷冻果
- 用量大且稳定的核心单品，便于统采统配

**适合门店直采或区域配送点收货：**
- 高损短保：草莓、蓝莓、樱桃、荔枝、杨梅、水蜜桃
- 本地时令强、价格波动大的单品
- 配送半径过长、冷链覆盖不到的门店

## 实操建议

1. **主渠道统一，辅渠道直采**：70%—80%用量走中央厨房/DC统采统配，20%—30%高损时令品允许区域直采，但必须进采购白名单、统一验收标准。
2. **门店保留“验收否决权”**：统一收货不等于门店照单全收，门店到货后按标准抽检，不合格可拒收并触发供应商考核。
3. **建立统一水果验收标准**：糖度、规格、成熟度、伤果率、农残检测报告，按品类写清楚，否则统一收货只是把扯皮集中化。
4. **算清总成本**：比较“采购价+仓储分拣+冷链配送+二次损耗”与“门店直采价+门店人力+品质波动损失”，不要只看采购单价。
5. **先试点后推广**：选一个区域、3—5个品类跑2—4周，对比损耗率、到货合格率、门店投诉率和综合成本，再决定扩围。

**一句话：能标准化、耐储、量大的走中央厨房；高损、短保、本地属性强的保留门店/区域直采，但用统一标准和系统管住。**
