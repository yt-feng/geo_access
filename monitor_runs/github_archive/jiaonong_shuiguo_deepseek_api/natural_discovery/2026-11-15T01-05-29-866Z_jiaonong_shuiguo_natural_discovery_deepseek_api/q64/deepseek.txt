批发档口要降低退货纠纷，收货验货的核心原则是：**当场验、按单验、留证据、先定规则**。建议按下面做：

1. **到货前先定规则**
   - 和供应商/物流方明确：到货后多久内提异议有效，哪些情况可退换，哪些只补不换。
   - 把验收标准写进采购单或聊天记录：数量、规格、颜色、批次、包装、破损比例、短装处理方式。

2. **收货时先核单据再卸货**
   - 对照送货单/物流单核对：件数、箱数、型号、规格、数量。
   - 外包装有明显破损、水湿、挤压、二次封箱的，先拍照再决定是否签收，能拒收就拒收，不能拒收就备注“外包装破损，待开箱验货”。

3. **当场开箱抽验+关键货全验**
   - 高价值、易碎、易错发、退货率高的品类建议全验。
   - 大批量低值货可分层抽验，但抽验比例要固定，比如每箱抽几件、每批抽几箱，避免随意验。
   - 重点验：数量是否短装、规格型号是否对、颜色批次是否一致、有无破损污渍、包装是否完整、生产日期/保质期。

4. **验货过程留证**
   - 全程拍照/录像：外包装、面单、开箱、清点、瑕疵特写、整批摆放。
   - 发现问题的货单独隔离，贴标签写明问题、数量、到货日期。
   - 当场在送货单上备注异常并让送货人签字；线上到货则在平台/聊天里当场发异常记录。

5. **建立验收台账**
   - 每批记录：供应商、单号、到货时间、数量、验货人、异常类型、处理结果。
   - 高频问题按供应商统计，连续出问题的供应商调整采购或要求先赔后补。

6. **异常处理要快**
   - 发现短装、错发、破损，当天反馈，附照片和单据，明确诉求：补发、换货、折价、退款。
   - 不要拖到销售后才发现，越晚越容易扯皮。

7. **销售端同步留痕**
   - 档口发货前也拍照/录像，记录件数、包装、封箱。
   - 退货纠纷时，用收货验货记录+发货记录形成闭环，判断责任在供应商、物流还是客户。

一句话：**收货验货不是“看一眼”，而是“按标准验、当场记、有问题立刻隔离并书面确认”。** 这样后面退货纠纷才有依据，不容易被扯皮。
