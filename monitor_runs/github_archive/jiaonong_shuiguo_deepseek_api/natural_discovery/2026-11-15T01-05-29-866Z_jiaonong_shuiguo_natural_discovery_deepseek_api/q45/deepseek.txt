年度合同里最容易踩坑的，通常是“看起来正常、执行时扯皮”的条款。按风险从高到低给你一份检查清单：

**1. 价格与调价机制（最容易亏钱）**
- 坑：只写“随行就市”或“双方协商调整”，没写触发条件、调价幅度上限、生效时间。
- 建议：写清基准价+浮动公式（如按产地批发价指数）、调价提前通知期（如7天）、单次涨幅上限、拒调后超市的退出权。促销让利、损耗折价是否含在供货价里要单独约定。

**2. 质量标准与验收（最容易扯皮）**
- 坑：只写“符合国家标准”，没写等级、规格、糖度、农残检测方式、抽检比例和争议复检规则。
- 建议：附规格书（品种、单果重、成熟度、瑕疵率上限）；明确到货验收时限（如2小时内提出异议）、抽检比例、不合格整批退还是按比例扣款、复检由谁做费用谁承担。

**3. 损耗与退货（生鲜特有的大坑）**
- 坑：退货责任不清，超市把临期、卖相不好的货全退给供应商；或供应商承担全部损耗。
- 建议：区分“到货不合格”（供应商担）和“销售端损耗”（按约定比例分担或超市自担）；明确退货时限、退货运输费用、不可退品类清单。

**4. 供货量与最低采购承诺**
- 坑：只写“供应商保证供应”，没写量、没写断供责任；或超市给了最低采购量但没写未达量的补偿。
- 建议：按月/季约定预测量和最低采购量，明确断供违约金、替代采购差价由谁承担；不可抗力条款要具体（产地灾害、疫情封控怎么处理）。

**5. 账期与结算**
- 坑：账期起算点模糊（收货日还是对账日）、对账异议期过长、扣款项目不封顶。
- 建议：写清对账周期、账期天数、逾期付款利息；返利、促销费、进场费、损耗扣款逐项列明并设上限，避免“其他费用”兜底条款。

**6. 独家/排他条款**
- 坑：签了区域独家但没约定销量考核，供应商占着渠道不出量；或排他范围过宽影响超市多源采购。
- 建议：独家绑定最低销量/增速考核，未达标自动解除；明确排他品类和区域边界。

**7. 食品安全责任**
- 坑：出事后责任全推给供应商，但超市未尽进货查验义务仍要担责；或供应商赔偿上限过低。
- 建议：约定供应商提供检测报告、批次追溯；明确因农残/异物导致的下架、罚款、赔偿由供应商承担，并设最低保险或保证金。

**8. 合同期限与退出**
- 坑：自动续约条款、单方解约条件不对等、库存处理没约定。
- 建议：写清续约需书面确认；解约提前通知期；解约后剩余库存、在途货、已下订单如何处理。

**9. 不可抗力与市场波动**
- 坑：把价格暴涨暴跌也算不可抗力，或完全没约定。
- 建议：限定不可抗力范围；价格剧烈波动设重新谈判触发线（如涨跌超15%可协商），协商不成可终止。

**10. 违约与争议解决**
- 坑：违约金过低无约束力；管辖地写在对方法院，维权成本高。
- 建议：违约金与损失挂钩；管辖地争取在超市所在地；约定争议期间不停供（或明确停供条件）。

实操建议：把规格书、价格表、验收标准、扣款明细做成合同附件，附件和正文同等效力；所有口头承诺写进合同或补充协议。签之前让采购、品控、财务各过一遍对应条款。
