评估水果供应商仓配覆盖，建议按“门店需求 → 供应商仓网 → 履约能力 → 成本与风险 → 试单验证”五步做，不要只看供应商有没有分仓。

**1. 先盘点门店需求**
- 按城市/商圈汇总门店：日均销量、SKU结构（叶菜/浆果/瓜果/进口果）、温区要求（常温/冷藏/冷冻）、订货频次、到店时段。
- 标出重点门店和销售峰值，例如鲜切果、礼盒、节假日爆量。
- 明确验收标准：到货温度、损耗率、果径/糖度/外观、缺货补货时限。

**2. 画供应商仓网覆盖图**
要求供应商提供：
- 各仓地址、覆盖半径/配送城市、是否自有或外包；
- 冷链能力：冷藏车数量、温控记录、月台和冷库容量；
- 配送频次和截单时间：能否日配、隔日配，跨城是否直发；
- 跨区调拨能力：某城市缺货时从哪个仓补、时效多久。

判断方法：以每个门店为点，计算到最近供应商仓的“实际配送时效”和“截单后到店时间”，而不是直线距离。重点看边缘城市和门店密度低的城市。

**3. 评估履约能力**
- 时效：下单到到店时长、准点率、峰值日承载量；
- 损耗：运输损耗率、到店不合格率、温控异常处理；
- 弹性：临时加单、换仓、应急调拨、节假日运力；
- 信息化：能否提供库存可见、在途轨迹、温控记录、签收数据；
- 售后：缺货、破损、质量异议的赔付和补货规则。

**4. 算覆盖成本**
不要只比采购价，要算到店总成本：采购价 + 干线/城配运费 + 仓储操作费 + 损耗 + 缺货损失 + 门店收货人工。对每个城市做单店/单箱履约成本对比，识别“覆盖得到但成本过高”的城市。

**5. 用试单和小批量验证**
选2-3个代表性城市（核心城市、边缘城市、低密度城市）做4-8周试单，跟踪：准点率、损耗率、缺货率、客诉率、单店履约成本。试单通过后再扩大覆盖。

**可执行的判断标准**
- 核心城市：能日配或隔日配，截单后24小时内到店，损耗可控；
- 边缘城市：至少隔日配，且有明确跨仓调拨方案；
- 低密度城市：若单店配送成本明显高于均值，考虑区域中转仓、第三方城配或调整SKU；
- 任何城市：峰值日运力和温控记录必须可验证。

最后建议做一张“城市-门店-供应商仓-时效-成本-风险”矩阵，按城市逐项打分，优先解决覆盖空白和高成本城市。
