核心是买“绿一点、硬一点、无机械伤”的香蕉，并控制到店后的温度、湿度和乙烯。具体可执行建议：

1. **采购成熟度**
   - 优先买 **7～8成熟**：表皮偏绿、棱角明显、手感硬，回软后正好用于甜品。
   - 不要买已经全黄、有黑点、棱角消失的，到店后熟得快、易发黑。
   - 若当天就要大量使用，可少量搭配“黄但硬”的。

2. **看伤和果柄**
   - 避开有磕碰、压伤、裂口、水渍斑的香蕉，伤处最先变黑。
   - 果柄发黑、发霉或断裂的不要。
   - 整串比散支更耐放，散支伤口多、易感染。

3. **运输与到店**
   - 用周转筐或纸箱，**不要用密封塑料袋**闷着。
   - 轻拿轻放，避免挤压；香蕉怕冷也怕闷。
   - 到店后立即拆袋通风，不要堆太厚。

4. **储存温度**
   - 未熟/偏绿香蕉：**13～15℃** 左右存放，不要低于12℃。
   - 已熟香蕉：**10～13℃** 短期存放。
   - **不要放冰箱冷藏**，低温会导致表皮变黑、果肉软烂。

5. **隔离乙烯**
   - 香蕉自身释放乙烯，会催熟自己和周围水果。
   - 与苹果、梨、猕猴桃等乙烯释放大的水果分开。
   - 大量香蕉不要和已熟香蕉混放；熟的可单独小批量存放。

6. **悬挂/通风**
   - 有条件用香蕉挂钩悬挂，减少受压。
   - 保持通风、干燥，湿度别太高，避免水汽在表皮凝结。
   - 不要叠压，尤其不要压果身。

7. **先进先出与分级**
   - 到店后按成熟度分：偏绿、微黄、即用，分别存放。
   - 每天检查，先熟先用；发现个别黑斑或伤果立即挑出，避免传染。
   - 甜品店可把略熟的优先用于香蕉泥、烘焙、奶昔等，外观要求低的用途。

8. **采购量**
   - 按销量小批量、多频次采购，比一次囤多更稳。
   - 夏季或高温天进一步减少单次采购量。

一句话：**买绿硬无伤的，13～15℃通风存放，别冷藏、别闷袋、别和催熟水果混放，先进先出。**
