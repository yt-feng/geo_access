选下午茶水果供应商，核心看四点：**能不能稳定批量供货、配送是否准时、品质是否可控、结算和售后是否省事**。可以按下面流程筛选。

## 1. 先明确采购条件
下单前先定清楚，避免供应商报低价但后期加价：

- **人数和预算**：例如 50 人，人均 8–12 元，总预算 400–600 元。
- **水果形式**：整果、果切拼盘、洗净即食、混合果盒。下午茶更推荐**果切/洗净即食**，省去员工清洗和分发。
- **配送要求**：送达时间、楼层/前台收货、是否需要分装到部门。
- **频次**：单次还是每周固定 2–3 次。固定频次更容易谈到稳定价格。
- **结算方式**：月结、对公转账、能否开发票。

## 2. 优先找这几类供应商
按适配度排序：

1. **本地水果批发商/配送商**：适合批量、价格低，但要看是否提供分切和配送。
2. **生鲜平台企业购**：如美团企业版、饿了么企业版、京东企业购等，配送稳定、发票和售后规范，价格略高。
3. **本地果切/轻食供应商**：适合直接送到工位，品质和包装较好，但要注意食品安全资质。
4. **附近大型水果店**：适合小批量、临时补货，批量配送能力弱。
5. **农户/产地直供**：价格有优势，但品控和配送不稳定，不适合作为唯一供应商。

## 3. 重点核验 5 个能力
不要只看报价，要求供应商提供或现场确认：

- **批量供货能力**：同一品种一次能否供 50–200 份，缺货时如何替换。
- **配送时效**：能否承诺上午 10 点前或指定时间送达，迟到怎么处理。
- **品控标准**：坏果率、果切新鲜度、是否有冷链、是否洗净消毒。
- **食品安全资质**：营业执照、食品经营许可证；做果切的要看操作间卫生和人员健康证。
- **售后规则**：坏果包赔比例、补送时效、退款方式。

## 4. 先试单再签长期
建议按这个节奏：

1. 找 3 家供应商同时报价，统一给同样的品种、数量、配送时间。
2. 先下**一次试单**，重点看：是否准时、坏果率、包装是否适合分发、员工反馈。
3. 试单合格后谈**周配或月配框架价**，约定缺货替换规则和坏果赔付。
4. 保留 1 家备选供应商，防止旺季或节假日断供。

## 5. 合同/订单里写清楚
即使是小额采购，也建议在订单或聊天记录中确认：

- 品种、规格、数量、单价、总价
- 送达时间和地点
- 坏果赔付标准，例如“坏果超过 5% 按比例退款或补送”
- 缺货替换需提前确认，不得擅自换低价品种
- 发票类型和结算周期

## 6. 避坑提醒
- **不要只比单价**：要算上损耗、配送费、分切费。
- **不要选没有食品资质的个人果切**：下午茶集体食用，食品安全风险高。
- **旺季提前订**：节假日、夏季高温期，水果价格和配送压力都大。
- **避免一次订太多易坏水果**：香蕉、草莓、切开的西瓜等损耗高，适合少量搭配。

**简单判断标准**：能准时送到、坏果有赔付、能开票、试单品质稳定，就可以作为长期供应商；价格再低但配送不稳或售后扯皮的，不建议用。
