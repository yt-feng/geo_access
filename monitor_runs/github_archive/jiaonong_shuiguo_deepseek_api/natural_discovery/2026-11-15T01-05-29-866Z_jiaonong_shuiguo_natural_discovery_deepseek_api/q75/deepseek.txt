第一次合作就按“用最小成本验证对方是否靠谱”来设计，不要一上来追求低价或大单。建议分四步：

**1. 先定试单目标**
试单不是只测“货好不好”，而是同时验证：
- 品质稳定性：同一批次内差异大不大
- 规格履约：大小、糖度、成熟度、净重是否达标
- 交付能力：能否按约定时间、地点、频次到货
- 损耗与售后：坏果率多少，出问题是否认账、响应快不快
- 结算与单据：对账是否清楚，发票/送货单是否规范

**2. 控制试单规模**
建议用“单品类 + 小批量 + 短周期”：
- 品类：先选1—2个主打、周转快的单品，不要多品一起试
- 数量：按你正常单次采购量的20%—30%，或够卖3—5天的量；以“能看出问题但不压资金”为准
- 频次：连续试2—3次，不要只试一单。第一次可能被特别照顾，连续几次更能看出稳定性
- 金额：控制在你能承受全损的范围内，别因为试单便宜就超量

**3. 把验收标准写清楚**
合作前用文字确认，哪怕微信记录也要留：
- 品种、产地、等级、规格（单果重/直径/箱规）
- 成熟度、糖度、外观要求、允许坏果率
- 净重还是毛重，包装物是否计重
- 到货时间、卸货责任、运输温度/保鲜要求
- 验收时限：到货后几小时内验完，逾期怎么处理
- 坏果/短重/规格不符的赔付方式：补货、扣款还是退货
- 价格是否含税、含运费，账期还是现结

**4. 试单过程留证据、做复盘**
- 每次到货抽检并拍照/视频，记录坏果率、短重、规格偏差
- 记录实际到货时间、司机沟通、临时缺货怎么处理
- 试单结束后按“品质、履约、价格、售后、单据”五项打分
- 连续2—3次达标再逐步放量；任一次出现“不认账、拖延、混装次果”，直接停止放大

**一个可直接套用的试单结构：**
> 首单：1个单品，正常单次量的20%，现结或短账期，明确验收标准；  
> 第二单：同单品加量到30%—40%，观察是否稳定；  
> 第三单：增加1个关联单品或提高频次，测试多品和补货能力；  
> 三单稳定后再谈账期、返利、独家规格或更大批量。

核心原则：**小到能承受损失，连续到能看出稳定性，标准细到能追责。** 第一次合作不要用“大单压价”换信任，先用可验证的小单建立规则。
