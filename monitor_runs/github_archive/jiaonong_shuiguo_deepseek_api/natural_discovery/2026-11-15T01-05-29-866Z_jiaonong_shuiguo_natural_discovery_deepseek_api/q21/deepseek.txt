超市采购水果时，供应商通常需要提供以下证明和检测材料（具体以当地市场监管要求和超市自身验收制度为准）：

1. **营业执照**  
   供应商合法经营主体资格证明。

2. **食品经营许可证/食品生产许可证**  
   根据供应商经营性质提供相应许可证；仅销售食用农产品的，按当地规定部分地区可免于食品经营许可，但需确认当地口径。

3. **进货凭证/购销合同/发货单**  
   证明水果来源、批次、数量、供货商信息，便于追溯。

4. **产地证明或食用农产品合格证**  
   常见形式包括：
   - 食用农产品承诺达标合格证；
   - 产地证明；
   - 供应商自检合格证明；
   - 批发市场出具的销售凭证。

5. **农药残留检测报告**  
   重点项。可为：
   - 供应商自检报告；
   - 第三方检测机构出具的检测报告；
   - 批发市场快检合格记录。  
   超市一般要求批次对应或近期报告。

6. **入境货物检验检疫证明**  
   进口水果必须提供，并核对海关报关单、入境货物检验检疫证明等。

7. **其他根据风险要求的材料**  
   - 包装标签、产地、品种、采摘/包装日期；
   - 冷链运输温度记录（如适用）；
   - 有机、绿色、地理标志等认证证书（如宣称相应认证）；
   - 承诺书/质量保证协议。

**实操建议：**  
超市应建立供应商档案和进货查验记录，做到“一批一证/一票一据”，检测报告尽量与采购批次对应；对高风险水果或新供应商，可要求第三方农残检测报告。具体清单建议以当地市场监管部门要求和超市验收标准为准。
