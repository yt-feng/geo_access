小水果店进香蕉，优先级建议这样排：**熟度 > 坏果率 > 送货速度 > 价格**。

理由很实际：

1. **熟度第一**
   香蕉是典型的后熟水果，进得太生要等，进得太熟当天就可能卖相变差、损耗飙升。小水果店周转快但客群有限，最好按“今天/明后天能卖完”的节奏进：日常销售选**微软、青黄转黄**的；想做即时售卖可少量进**已经偏黄但没黑点**的。熟度不对，价格再低也可能砸手里。

2. **坏果率第二**
   香蕉容易压伤、捂坏，一箱里坏几根会迅速传染。要明确问批发商：**整箱坏果怎么算、能不能换**，并现场抽看箱底和中间。坏果率高的低价货，实际成本往往更高。

3. **送货速度第三**
   它对香蕉很重要，但不如前两项决定成败。小水果店库存浅，最好选**能稳定次日送、当天补货**的供应商；送货慢会导致你不敢少进，被迫压库存。若供应商熟度稳定、坏果包换，稍慢半天通常可接受。

4. **价格最后**
   不是不重要，而是香蕉价格透明、毛利薄，应该比**“到店可售成本”**：进货价 + 损耗 + 压货风险。每斤便宜几毛但熟度差、坏果多，通常不划算。

实操建议：固定 1 家主供应商 + 1 家备用；每次少量多批次进；前几次记录**到店熟度、坏果率、实际售罄天数**，用一周数据再决定是否换供应商。
