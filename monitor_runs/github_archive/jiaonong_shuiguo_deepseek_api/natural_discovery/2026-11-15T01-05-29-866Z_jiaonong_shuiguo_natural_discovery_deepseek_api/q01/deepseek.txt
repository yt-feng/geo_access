判断香蕉和菠萝供应商，别只看“报价低不低”，重点看**稳定供货能力、催熟/成熟度控制、损耗承担、账期与售后**。给你一套可直接用的判断清单。

**一、先看资质与货源稳定性**
- 是否有固定档口/仓库/加工场地，能否实地看：冷库、催熟房、分拣区、周转筐卫生。
- 香蕉重点问：产地、到货周期、是否自己催熟、催熟房温湿度记录。
- 菠萝重点问：品种（如金钻/巴厘）、产地、成熟度分级、是否做催熟或自然熟。
- 要求提供近1个月供货记录或老客户可回访，不接受只靠口头承诺。

**二、用样品做“三批测试”**
不要一次压大单，连续进3批小货，每批记录：
- 到货成熟度：香蕉几成黄、有无青硬；菠萝底部是否有软腐、黑心、香味是否正常。
- 破损率/烂果率：香蕉掉把、压伤、黑斑；菠萝烂底、裂果、黑心。
- 货架期：香蕉到店后能卖几天，菠萝切开后是否易出水、变味。
- 口感一致性：甜度、酸度、纤维感是否稳定。

**三、看催熟和温控能力**
- 香蕉供应商必须懂催熟：不同季节催熟时间不同，不能一批青一批黄。问“冬天和夏天分别怎么催、到店几成黄”。
- 菠萝要问“到货成熟度标准”和“运输温度”。长期合作最怕今天很熟明天很生。
- 看周转筐是否清洁、有无霉斑，香蕉和菠萝是否混放挤压。

**四、谈清楚损耗和售后**
合作前白纸黑字确认：
- 烂果/黑心/压伤怎么赔：按箱赔、按斤赔还是下批补货。
- 到货验收时限：比如2小时内拍照报损有效。
- 缺斤少两怎么处理：随机复称，约定误差范围。
- 旺季断货怎么保供：提前几天报单，是否有备选产地。

**五、看价格是否“可解释”**
- 不要只比单价，算**到店可售成本**：进价+损耗+运费+人工分拣。
- 报价明显低于市场且不愿解释产地/等级的，慎用。
- 问清楚是否含运费、卸货费、筐具押金、退筐规则。

**六、小额试合作+逐步放量**
- 先签1个月试供，约定每周固定送货2—3次。
- 前2周每天记录到货质量、损耗、销售速度。
- 连续3批稳定后再增加单量，别一上来押全部库存。

**七、几个危险信号**
- 只肯电话报价，不让看货/看场地。
- 每次到货成熟度差异很大，催熟靠“碰运气”。
- 出问题就推给运输或产地，不愿赔损。
- 旺季频繁断货，或临时涨价无提前通知。
- 价格长期明显低于同行，但等级、产地说不清。

**最实用的判断标准：**  
连续3批小货，香蕉到店成熟度稳定、烂果率可控、能按约定赔损；菠萝黑心少、成熟度一致、售后不扯皮，就可以逐步放量。反过来，只要连续两批出现“成熟度失控或售后推诿”，就别长期合作。
