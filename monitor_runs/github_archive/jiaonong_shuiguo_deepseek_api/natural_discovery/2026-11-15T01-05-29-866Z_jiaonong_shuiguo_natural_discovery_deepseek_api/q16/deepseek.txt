# 社区超市增加香蕉苹果：本地批发 vs. 稳定供应商

**结论：优先选稳定供应商，本地批发作为补充。** 香蕉和苹果都是高频、易损耗、价格波动大的生鲜品类，供应链稳定性比单次进价更重要。

## 为什么

| 维度 | 本地批发 | 稳定供应商 |
|---|---|---|
| 价格 | 单次可能更低，但随行情波动 | 合同价，略高但可预测 |
| 品质一致性 | 批次差异大 | 可约定等级、规格、糖度 |
| 损耗风险 | 高（品控不可控） | 可通过验收标准+退换货条款降低 |
| 断货风险 | 高（货源不稳定） | 低（可约定保供） |
| 结算 | 多为现结 | 可谈账期，缓解现金流 |

社区超市的核心竞争力是“顾客来了就能买到、品质稳定”，一次缺货或一次烂果就会流失熟客。香蕉尤其如此——它成熟度变化快，需要供应商配合做催熟和分批到货。

## 具体做法

1. **苹果**：找1家稳定供应商签季度框架，约定规格（如80#果径）、等级、到货频次（每周2次）、验收标准（烂果率≤3%）、退换条款。苹果耐储，稳定供应最划算。
2. **香蕉**：优先找能做“催熟+小批量高频配送”的供应商（香蕉批发商通常有催熟库），约定每周2–3次到货、成熟度分段（青果/黄果搭配），避免一次到货全熟造成集中损耗。
3. **本地批发留作应急**：遇到供应商临时断货、或节日备货临时补量时，用本地批发补缺口，不签长约。
4. **先小量试合作**：新供应商先跑2–4周，观察到货准时率、烂果率、顾客复购反馈，再决定是否签长约。

**判断标准**：如果某供应商能承诺“烂果率≤3%、缺货提前24小时通知、可退换”，即使单价比本地批发高5%–8%，也值得选——生鲜损耗和客流失的成本远高于这点差价。
