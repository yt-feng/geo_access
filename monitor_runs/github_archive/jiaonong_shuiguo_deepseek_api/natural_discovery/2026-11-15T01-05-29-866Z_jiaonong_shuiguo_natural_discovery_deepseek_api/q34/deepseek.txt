更影响最终毛利的是**损耗低**，尤其是商超水果这种高损耗、短保质期品类。价格低通常只影响“进货毛利空间”，损耗低才决定“这个毛利能不能留下来”。

可以这样判断：

1. **价格低是分子问题，损耗高是分母和报废问题**
   - 进价低：单品毛利率看起来更高。
   - 损耗高：报损、打折、品相下降、客诉退货会直接吃掉毛利。
   - 水果尤其如此，损耗每上升几个点，可能就把低价采购带来的毛利优势全部抵消。

2. **水果毛利对损耗更敏感**
   举例：售价10元/斤，进价6元/斤，理论毛利4元。
   - 如果损耗10%，实际可售成本约6.67元，毛利约3.33元。
   - 如果损耗20%，实际可售成本约7.5元，毛利约2.5元。
   - 进价从6元降到5.5元，只多0.5元毛利；但损耗从10%升到20%，少约0.83元毛利。  
   所以高价低损耗往往比低价高损耗更稳。

3. **低价常常伴随更高损耗风险**
   低价货源可能有：规格不齐、成熟度高、库存尾货、运输伤、货架期短。采购价低不等于最终成本低，要算“可售成本”：
   **可售成本 = 采购价 ÷（1 - 损耗率）**
   比较供应商时，应比较可售成本和周转速度，而不是只看采购价。

4. **什么时候价格低更重要**
   - 损耗可控且稳定，比如苹果、橙子、柚子等耐储品；
   - 有明确促销走量、当天能清货；
   - 供应链短、周转快、冷链稳定；
   - 低價差足够大，且能覆盖新增损耗和运营成本。

**结论：**  
对商超水果最终毛利，**损耗低通常比价格低更关键**。采购决策应优先看“低损耗、稳定品质、快周转”，再用价格做优化；只追求低价容易形成“毛利虚高、报损吃光”的结果。实际考核建议同时看：**毛利率、损耗率、周转天数、可售成本、缺货率**。
