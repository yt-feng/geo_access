最应该先问**售后**，其次**配送**，最后才是**价格**。

原因是团购团长真正承担的是“邻里信任 + 履约风险”，不是单纯进货：

1. **售后优先**
   - 水果是非标品，坏果、规格不符、成熟度不稳几乎必然发生。
   - 要问清楚：坏果怎么赔、赔付时效、是否按比例赔、要不要返图、运费谁承担、整批质量问题能否退换。
   - 售后不清，一次烂果就可能把团长的口碑和利润一起吃掉。

2. **配送第二**
   - 水果时效敏感，要问：到团点的时间、是否冷链/周转筐、破损谁负责、迟到怎么处理、能否按团点分批送。
   - 配送不稳会直接造成缺货、压货和售后叠加。

3. **价格最后**
   - 价格低但售后差、配送不稳，实际综合成本更高。
   - 价格要在售后和配送条款明确后再谈，并且算“到团点含损价”，不是只看进货价。

**可执行判断标准：**
- 售后：坏果赔付是否48小时内可执行、是否按比例赔、是否有上限。
- 配送：能否固定时段到团点、破损责任是否明确、迟到是否有补偿。
- 价格：同等售后和配送条件下比价，重点看“含损耗后的毛利”。

一句话：**先保口碑和履约，再谈成本；售后不清的供应商，价格再低也不建议做主供。**
