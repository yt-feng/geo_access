优先谈**售后（尤其是质量与损耗的责任划分和赔付机制）**，其次谈**账期**，最后谈**配送**。理由是：水果是非标、易腐、损耗波动大的品类，长期合作里最容易侵蚀利润和引发扯皮的是“坏果、短斤少两、到货不新鲜”由谁承担；这个规则没谈清，账期再长也可能是用坏果成本换来的，配送再准时也挡不住质量纠纷。

具体判断和谈法：

1. **售后优先谈，谈成可执行的规则**
   - 明确验收标准：到货抽检比例、坏果率/损耗率上限（如超过多少按比例扣款或补货）。
   - 明确责任时点：装车后、到货后多久内提出异议有效；拍照留证要求。
   - 明确赔付方式：补货、折价、扣款还是退货，处理时限多久。
   - 明确短斤少两和规格不符怎么算。
   这是长期合作的地基，先把它写成简单条款，后面账期和配送才有意义。

2. **账期第二谈，重点不是“越长越好”，而是现金流与价格的交换**
   - 先问清楚：现结、周结、月结分别什么价；账期延长是否加价。
   - 谈一个与自身销售回款周期匹配的账期，而不是盲目拉长。水果周转快，账期过长往往意味着供应商把资金成本加进单价。
   - 约定对账日和付款日，避免“月结”变“拖结”。
   - 如果供应商规模小，账期过长可能带来断供风险，要评估其承受能力。

3. **配送最后谈，但要有硬约束**
   - 明确送达时间窗口、频次、临时加单的响应时间。
   - 明确冷链/保鲜要求、装卸责任、迟到或漏送的补偿。
   - 配送问题通常可以用备用供应商或调整下单节奏来缓冲，紧迫性低于售后和账期。

**一句话结论**：先谈售后规则，把损耗和 quality 风险锁死；再谈账期，用付款条件换价格或稳定性；配送放在最后做标准化约束。如果只能先谈一件事，就谈售后。
