先把目标拆清楚：你要的是**稳定大客户**，不是单笔低价。账期和额度本质上是你在用资金和风险换客户的采购稳定性。建议按下面几步谈。

## 1. 先定原则，不要一上来给账期

- **额度分离**：授信额度 ≠ 账期。额度解决“能拿多少货”，账期解决“多久付款”。
- **新客户先现款或短账期**，用3–4周稳定采购记录再升级。
- **账期和采购量、回款记录挂钩**，写成阶梯条款，不口头承诺。
- **额度上限=你能承受的坏账上限**，不是客户想要多少给多少。

## 2. 谈账期的具体节奏

建议给批发商一个阶梯方案：

- **第1个月**：现款现货，或“3天账期”，额度设为单周采购额的50%–70%。
- **第2–3个月**：回款准时，升到**7天账期**，额度提到单周采购额的1倍左右。
- **稳定合作3个月后**：可谈**15天账期**，额度控制在**2周采购额**以内。
- **半年以上优质客户**：再考虑**30天账期**，但额度不超过**月采购额的50%–70%**，且设置封顶金额。

关键话术：
> “账期可以给，但按回款记录逐步放开。前三个月先7天，准时回款后我们升到15天，额度也跟着采购量走。”

## 3. 额度的算法

用这个公式做底线：

**授信额度 ≤ 客户月均采购额 × 账期系数 × 你的风险承受比例**

- 7天账期：系数约0.25
- 15天账期：系数约0.5
- 30天账期：系数约1
- 风险承受比例：新客户0.3–0.5，老客户0.6–0.8

举例：客户月采购10万，给15天账期，风险比例取0.5，额度约 **2.5万**。不要因为客户说“别人给30万”就突破自己的现金流底线。

## 4. 用条件换条件

不要单方面让步，每给一项都换一项：

- 给账期 → 换**最低月采购量**或**独家品类采购**。
- 提额度 → 换**预付款比例**或**法定代表人个人担保**。
- 缩短账期 → 换**价格折扣**或**优先供货**。
- 延长账期 → 要求**月度对账签字**、**逾期停供条款**。

## 5. 必须写进合同的条款

- 账期起算日：以**签收单日期**为准，不以客户内部流程为准。
- 逾期处理：逾期X天暂停供货，逾期X天取消额度。
- 额度动态调整：连续2个月采购下降或回款延迟，额度自动下调。
- 对账机制：每月固定日对账，签字确认。
- 质量争议不影响已确认货款的付款义务，避免客户拿质量问题拖账。

## 6. 谈判底线

- 现金流撑不住的账期，再大的客户也不给。
- 没有书面对账和签收制度的账期，不给。
- 单一客户授信不超过你月现金流的**20%–30%**。
- 新客户第一笔大额订单，坚持**部分预付款+货到付款**，不要直接上账期。

一句话总结：**账期按月阶梯放，额度按采购额算，每让一步都换一个承诺，全部写进合同。**
