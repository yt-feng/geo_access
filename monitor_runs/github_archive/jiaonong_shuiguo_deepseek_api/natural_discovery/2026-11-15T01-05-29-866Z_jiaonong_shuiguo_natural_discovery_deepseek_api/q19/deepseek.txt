超市卖菠萝，**四者都要看，但优先级不是并列的**。更可执行的判断是：

**核心优先级：切果损耗 > 甜度 > 外观 > 大小。**

但要看你的经营目标：如果是**日常走量、控毛利**，先盯切果损耗；如果是**高端鲜食/礼品**，甜度和外观权重上升；如果是**促销引流**，大小和外观更影响成交。

### 1. 切果损耗：最该先关注，直接决定赚不赚钱
超市卖菠萝通常不只是整果，还涉及削皮、切块、装盒、试吃、坏果处理。损耗高会把甜度和外观带来的溢价全吃掉。

重点看：
- 到货后坏果率、黑心/水心/空心率
- 削皮去眼后的出成率
- 切果盒的报废率和动销速度
- 不同批次、不同产地、不同成熟度的损耗差异

**判断标准：** 如果出成率低、切果报废高，再甜再大也可能不赚钱。先建立按批次记录：到货量、坏果量、切果出成率、报废量、销售额。

### 2. 甜度：决定复购和口碑
菠萝是典型“买一次不甜就不回头”的水果。甜度不够，试吃转化差，切果盒也卖不动。

重点看：
- 糖度是否稳定，不只看单个样本
- 酸甜比和口感，不能只追求高糖
- 成熟度是否适合超市销售周期
- 不同批次甜度波动

**建议：** 到货抽检糖度，记录批次；试吃反馈和复购比单次甜度更重要。

### 3. 外观：影响首次成交，但不是长期核心
外观决定顾客愿不愿意拿起来看，尤其整果销售。但菠萝有刺、有冠芽，外观瑕疵对切果影响较小。

重点看：
- 果形是否端正、无腐烂霉变
- 颜色是否代表适销成熟度
- 冠芽和表皮是否新鲜
- 是否适合陈列和分级销售

**判断标准：** 外观用于分级和陈列，不应为“好看”牺牲出成率和甜度。

### 4. 大小：影响定价和客群，不是唯一标准
大小影响单价、切片规格和顾客选择，但大果不一定好卖，小果不一定差。

重点看：
- 目标客群偏好：家庭装、单人份、切果盒
- 大小是否均匀，便于定价和陈列
- 大果出成率是否真的更高
- 小果是否适合促销和切果

**判断标准：** 按用途分级，而不是单纯追求大。整果走家庭客群可偏大，切果盒和单人消费可偏中等。

### 实操建议
1. **先建损耗台账**：按批次记录坏果率、出成率、切果报废率。
2. **再做甜度抽检**：每批抽检糖度和口感，不达标就调整用途，比如转切果、试吃或促销。
3. **外观分级销售**：好外观做整果陈列，一般外观转切果或试吃，避免一刀切。
4. **大小按场景定价**：大果做家庭装/礼盒，中果做日常整果，小果做切果盒或促销。
5. **每周复盘**：比较不同产地、批次、成熟度的“损耗—甜度—售价—动销”，用数据决定采购。

一句话：**超市卖菠萝，先看切果损耗保利润，再看甜度保复购，外观和大小用于分级和定价。**
