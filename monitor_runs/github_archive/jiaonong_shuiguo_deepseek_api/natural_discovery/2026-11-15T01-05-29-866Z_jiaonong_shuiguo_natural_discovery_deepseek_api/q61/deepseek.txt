判断香蕉批发“一手货源”是否稳定，不要只听对方说“基地直发”，要按**能不能持续出货、品质能不能稳住、价格和账期能不能兑现**三条线去验。给你一套可执行的判断法：

### 1. 先核实“一手”身份
- 要求对方提供：种植基地/合作社证明、产地收购点照片或视频、分拣包装场地址、营业执照和法人信息。
- 视频核验时让他**现场拍当天香蕉、包装线、冷库/装车区**，并报当天日期；只发库存图的不算。
- 问清楚：是自有基地、包园收购，还是从产地代办转手。转手也可以合作，但价格和稳定性要按二级货源判断。
- 最好实地去看一次，重点看：有没有固定分拣场、是否常年有货、装车是否规律、残次果怎么处理。

### 2. 用“连续供货记录”验证稳定性
不要只看一次样品，要求：
- 连续 **3—5 批**小批量试单，观察每批到货的成熟度、条形、青度、机械伤、烂指率是否一致。
- 看对方是否能固定**每周/每天出货量**，并给出近一个月的装车记录、发货单或产地收购记录。
- 问极端情况：产区下雨、寒害、价格大涨时，他如何保供？有没有备用基地或合作果园？
- 旺季前提前锁量试一次，看他是否临时加价或换货。

### 3. 看产地和季节匹配
香蕉供应有明显产区轮换。稳定供货商应能说清楚：
- 当前主供产区在哪里，下一阶段产地怎么切换；
- 不同季节的催熟、运输、保鲜方案；
- 遇到台风、寒潮、病害时如何调整。
如果对方只会说“云南/广西/老挝都有”，但说不清具体县、包装场和切换计划，稳定性要打折。

### 4. 用合同和账期约束
- 合同写明：品种、规格、单批数量、验收标准、残次率上限、到货时限、价格调整机制、违约赔付。
- 先做**小批量现款**，稳定后再谈账期；不要一上来给长账期。
- 每批留样并拍照封存，出现质量争议有依据。
- 付款尽量走公账，避免私人转账无凭证。

### 5. 现场/视频验货的关键指标
每批重点看：
- 青度是否适合你当地催熟销售；
- 条形、把型、单把重量是否稳定；
- 机械伤、黑星、烂指、掉把比例；
- 箱内上下层是否一致，有没有“盖面货”；
- 装车温度、通风和运输时长。

### 6. 几个危险信号
出现以下情况要谨慎：
- 只肯发样品图，不愿视频看现场或装车；
- 报价明显低于市场，但要求大额预付；
- 每次货源产地、包装场说法不一致；
- 不能提供固定出货量，靠“今天有明天没”；
- 拒绝写验收标准和残次赔付；
- 催你长期锁量，却不给稳定供货记录。

**最稳的做法：**先小批量试 3 批，再实地看一次产地或分拣场，最后用合同锁定规格、残次率和保供责任。能通过“连续供货+现场核验+合同约束”这三关的，才算稳定一手货源。
