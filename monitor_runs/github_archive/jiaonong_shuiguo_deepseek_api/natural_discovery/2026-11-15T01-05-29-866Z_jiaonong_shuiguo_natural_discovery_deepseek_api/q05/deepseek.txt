水果店卖菠萝，最稳妥的做法是：**整果为主，代削/去皮果为辅，让顾客自己挑整果，现场代削或标价分档。**不建议只卖提前去皮好的。

**为什么整果为主**
- 顾客自己挑能参与品质判断，减少“你替我选的不好”的争议。
- 整果耐放、损耗低，卖不完还能继续陈列。
- 国内买菠萝习惯看外观、闻香味、按硬度，整果更容易成交。

**为什么要有代削/去皮果**
- 很多顾客怕削、怕扎手，代削能明显提升便利性和客单价。
- 提前去皮果适合做“即食果盒/半价处理”，但不适合当主力：
  - 去皮后失水、氧化、易污染，损耗和食品安全风险都高。
  - 顾客看不到原果，容易怀疑不新鲜或拿次果削。
  - 一旦削好卖不掉，基本只能降价。

**具体怎么操作**
1. **整果区**：让顾客自己挑，标清品种、单价、甜度/口感提示。
2. **代削服务**：买整果可免费或加1—2元代削，现场削、当场装盒，顾客看得见。
3. **去皮果只做少量**：现削现卖，标注削皮时间，2小时内卖完；卖不完做果盒或降价，不隔夜当鲜果卖。
4. **分档定价**：整果一个价，代削果略高，提前去皮/临期果盒低价处理，别混在一起。
5. **避免争议**：代削前让顾客确认果子，削后不退换；提前说明“代削果不参与挑果”。

一句话：**让顾客挑整果，你负责代削；去皮果只做便利补充，不做主力。**
