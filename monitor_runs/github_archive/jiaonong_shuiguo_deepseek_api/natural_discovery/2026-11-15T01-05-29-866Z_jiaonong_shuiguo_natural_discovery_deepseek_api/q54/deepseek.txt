优先关注**成熟度**，价格其次。

原因很直接：香蕉在烘焙里主要承担甜味、香气、保湿和结构作用，成熟度不同，效果差别很大。

- **最适合做蛋糕的香蕉**：表皮大面积金黄、带少量黑点，果肉软但不流汁。甜度高、香气足、容易压泥，成品质地更湿润。
- **过生**：硬、涩、甜度低、香气弱，压泥后颗粒感重，蛋糕风味不足，还可能增加配方调整难度。
- **过熟到发黑流汁**：香气最强，但酸味、酒味和酶解变化明显，水分比例不稳定，容易影响配方平衡和保质期；除非你有稳定处理经验，否则不建议大量采购。
- **价格**：只在**成熟度达标**的前提下比较。为了低价买生蕉，通常需要额外催熟和损耗管理；为了低价买过熟蕉，则要承担风味不稳定、报废和客诉风险。

采购建议可执行地写成三条：

1. **先定成熟度标准**：要求金黄带黑点、果肉软糯、无明显酸败酒味。
2. **价格比较放在同成熟度之间**：同等级比价，不拿生蕉价和熟蕉价直接比。
3. **按使用节奏采购**：当天/次日用的买熟蕉；需要存放的买略生一点，在店内完成催熟，并做少量试烤验证。

一句话：**成熟度决定蛋糕能不能做好，价格决定成本划不划算；先保证成熟度，再谈价格。**
