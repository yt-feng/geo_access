判断“合理波动”的关键，不是猜供应商有没有乱报价，而是把**每天变价拆成可解释的驱动因素**，再用规则约束。可以按下面做：

## 1. 先判断波动的来源
水果日报价波动通常来自几类因素：

- **产地收购价变化**：天气、降雨、寒潮、高温、病虫害、集中上市或断档。
- **等级/规格变化**：同一品种不同大小、糖度、外观、包装，价格差异很大。
- **市场供需变化**：节假日备货、餐饮/团餐集中采购、学校开学、替代水果价格。
- **物流与损耗**：油价、冷链、运输距离、装卸损耗、到货新鲜度。
- **供应商自身策略**：库存处理、临时缺货、搭配销售、账期和配送服务差异。

先要求供应商报价时附带**品种、等级、规格、产地、包装、到货时间、是否含税含运**。如果这些口径不统一，价格本身不可比。

## 2. 建立“基准价+合理区间”
不要只盯昨天价格，建议用三种基准交叉看：

- **近7天/30天移动均价**：日波动看7天，趋势看30天。
- **同品类多供应商比价**：至少2—3家，比较同一规格和到货条件。
- **批发市场公开价/产地行情**：作为参考锚点，但要换算等级、包装、损耗和运费。

然后设区间，例如：
- 日常品种日波动在±3%—5%内，通常可视为正常；
- 叶菜、浆果、天气敏感品种可放宽到±8%—10%；
- 超过区间，要求供应商给出原因和证据。

具体阈值要按你们品类历史数据校准，不要一刀切。

## 3. 看“波动结构”而不是单日涨跌
更可靠的判断信号：

- **连续小涨小跌**：多为市场正常变化。
- **单日大幅跳涨且多家同步**：可能是产地灾害或节假日备货，需核实。
- **只有一家涨、其他家稳定**：优先怀疑供应商报价或规格变化。
- **涨价同时降规格/换包装/延迟配送**：属于隐性涨价，要重点管。
- **跌价但到货质量下降**：可能是清库存或降等级。

## 4. 用采购规则约束
建议写入采购协议或询价流程：

1. **统一报价口径**：品种、等级、规格、产地、包装、税率、运费、账期全部列明。
2. **报价附依据**：超过约定幅度时，供应商需说明原因，并提供产地价、批发市场价或进货凭证。
3. **多源比价**：每次调价至少对比两家；大额采购做周度比价。
4. **价格复核机制**：采购员初核，负责人复核异常波动。
5. **调价频率限制**：约定每日最多调整一次，或超过一定幅度需提前确认。
6. **质量与价格联动**：到货验收不合格按约定扣款或退换，防止“低价低质”。
7. **保留历史数据**：按品种建立价格台账，记录报价、成交价、到货质量、供应商原因说明。

## 5. 实操判断表
可以给采购员一张简单表：

| 情况 | 判断 | 动作 |
|---|---|---|
| 涨跌幅在历史正常区间，多家同步 | 合理波动 | 正常执行，记录 |
| 单家上涨，其他家稳定 | 可能不合理 | 要求说明，转比价 |
| 大幅上涨但产地/市场同步涨 | 大概率合理 | 核实后接受或调整售价 |
| 涨价但规格下降、配送变差 | 隐性涨价 | 按合同异议 |
| 连续多日单向异常上涨 | 需警惕 | 暂停增量，启动复核 |
| 低价明显低于市场且质量不稳 | 不一定划算 | 查等级、损耗、账期和售后 |

## 6. 最实用的落地办法
让供应商每天报价时同步给一句“**价格变动原因**”，你们按品种记录一周。连续记录2—4周后，就能算出每个品种的正常波动区间。之后采购判断不再靠感觉，而是看：**是否超出区间、是否多家同步、是否规格变化、是否有凭证**。

一句话：**合理波动=可解释、可对比、可验证、在历史区间内；不合理波动=口径不清、单家异常、隐性降质、拒绝说明。**
