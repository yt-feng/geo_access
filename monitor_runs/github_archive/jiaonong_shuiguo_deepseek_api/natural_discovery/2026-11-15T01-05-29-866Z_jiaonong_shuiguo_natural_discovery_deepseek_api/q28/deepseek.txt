建议先从**香蕉**试起，但前提是把它当作“引流+走量”的稳定单品来运营，而不是高毛利单品。排序判断如下：

1. **香蕉：最适合先做稳定进口水果**
   - 消费频次高、价格敏感、顾客接受度高，容易形成稳定销量。
   - 进口香蕉供应链成熟，规格和催熟流程相对标准化。
   - 风险点：损耗和催熟管理要求高，毛利通常不高，需要控制库存周转和成熟度。
   - 适合作为“稳定客流”的入口，而不是靠它赚高毛利。

2. **菠萝：可作为第二阶段补充**
   - 季节性和成熟度差异更明显，顾客对甜度、酸度、去皮便利性敏感。
   - 损耗和售后争议比香蕉高，适合在有稳定客流后再做差异化。
   - 如果做鲜切或即食，能提升毛利，但会增加人工和冷链要求。

3. **苹果：不建议作为“进口稳定单品”的起点**
   - 国产苹果供应充足、价格竞争强，进口苹果差异化不够明显。
   - 顾客对进口苹果的价格敏感，动销容易受国产替代影响。
   - 更适合作为品类补充或高端礼盒，而不是稳定走量入口。

**可执行建议：**
- 先小批量试销进口香蕉，固定1—2个供应商，观察2—4周动销、损耗率、客诉和周转天数。
- 设置简单指标：损耗率控制在5%以内、周转天数不超过3天、毛利率能覆盖损耗和人工再考虑扩量。
- 香蕉稳定后再引入菠萝，优先做小规格或鲜切测试；苹果最后作为补充，不做主推。
- 如果门店客流弱、冷链和催熟条件不足，则不要先做香蕉，可改为先做耐储的进口苹果小包装试销。
