**1. 价格支持：一般能给，但看量、账期和品项**
- **走量大的常规单品**：供应商更可能给周末特价、返点、搭赠，常见形式是“周末进货满X件，单价降Y”或“买N送1”。
- **易损耗、当季集中上市的水果**：供应商更愿意降价清货，但你要承担损耗，别只看进价。
- **品牌包装果、进口果**：价格空间小，更多给物料或陈列支持。
- **新供应商/小供应商**：价格支持通常更灵活，但稳定性和售后要确认。
- **判断标准**：先问“周末促销专供价能不能比日常低5%—10%”，如果对方只肯给搭赠，也算支持，折算进毛利再决定。

**2. 物料支持：比价格更容易争取**
常见可要的：
- 堆头/陈列物料：海报、价签、爆炸贴、展架、围挡
- 试吃物料：牙签、试吃盒、一次性手套、小份包装
- 品牌方物料：品牌横幅、吊旗、促销服、遮阳棚
- 冷链/保鲜支持：周转筐、保鲜袋、冰袋，部分供应商可借或送

**3. 怎么谈更有效**
- 提前**3—5天**沟通，明确周末档期、预计销量、陈列位置。
- 用“**保底进货量+重点陈列+社群/朋友圈曝光**”换支持。
- 价格和物料分开谈：价格谈不动就争取搭赠、账期、损耗补差或物料。
- 要求书面确认：促销价执行时间、数量上限、物料到店时间、未卖完处理方式。

**4. 注意别踩坑**
- 口头特价要确认是否限购、是否只限某批次。
- 物料可能带品牌露出要求，先看是否影响你店内其他商品陈列。
- 促销价进货量大时，算清损耗和周末两天实际动销，别为低价压货。

**结论**：能争取，优先谈“周末专供价+搭赠+物料”，小供应商和当季单品成功率更高；品牌果和进口果重点要物料和陈列支持。
