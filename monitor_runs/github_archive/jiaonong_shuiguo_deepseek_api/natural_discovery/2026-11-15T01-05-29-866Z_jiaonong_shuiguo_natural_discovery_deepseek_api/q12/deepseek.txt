菠萝损耗主要来自两点：**进货时已经过熟**，以及**熟度不齐导致一批货集中坏**。采购时不要只追求“当下最甜”，而要按你门店的销售速度分层选熟度。

### 1. 先按销售速度定采购熟度
- **日销快、1～2天能卖完**：可进“七八分熟到刚熟”的货，香气明显、果肉开始变软，适合现切现卖。
- **普通水果店、2～4天周转**：主进“六七分熟”，也就是外观转黄但按压偏硬、香气淡，放店里自然后熟。
- **周转慢或天气热**：优先“六分熟偏生”，黄面积少、手感硬，减少集中过熟。
- **不建议一批全进同一熟度**：按 6成、7成、8成熟搭配，先卖熟的，生的后熟补位。

### 2. 现场判断菠萝熟度的可操作指标
**看**
- 果皮由青转黄，**底部先黄、黄得均匀**更可靠；只有局部一块黄、其他青硬，熟度不匀。
- 果眼要平展、饱满；果眼深陷、发黑或有汁液，别要。
- 冠芽（顶部叶子）青绿有生气；叶子一拔就掉、基部腐烂，说明过熟或存放久。
- 果身有裂口、渗汁、局部软塌，直接剔除。

**闻**
- 闻**果底部**：有清淡菠萝香＝开始熟；香气浓甜＝偏熟，适合快卖；有发酵酒味、酸味＝过熟，别进。
- 无香气不代表不好，可能是偏生，适合后熟。

**按**
- 用手掌轻按果身中下部：**硬而有弹性**适合周转；**明显软、按下去不回弹**偏过熟。
- 不要只看颜色，硬度和香气更关键。

**掂与看切口**
- 同规格掂起来偏重、汁水足；轻飘的可能失水或空心了。
- 如果是切尾或去冠的货，看切口：新鲜、无褐变、无汁液渗出；切口发黑、发酸味不要。

### 3. 采购时的批次控制
- **少量多次**比一次压货更稳，尤其夏季。
- 要求供应商**同一批熟度尽量一致**，不要大小、熟度混装。
- 到店后立刻分级：熟的分开放、优先陈列；生的放阴凉通风处后熟，别堆压、别闷塑料袋。
- 菠萝怕冷害，**不宜长时间低温冷藏**；未切的放在阴凉通风处，切开的冷藏并尽快售完。

### 4. 简单记法
**“底部微黄、香气清淡、按压硬中带弹”**——这是适合水果店周转的采购熟度。  
**“香气浓、按着软”**——只适合当天能卖完的量。  
**“酒味、渗汁、果眼黑、叶子一拔就掉”**——损耗风险高，不要进。
