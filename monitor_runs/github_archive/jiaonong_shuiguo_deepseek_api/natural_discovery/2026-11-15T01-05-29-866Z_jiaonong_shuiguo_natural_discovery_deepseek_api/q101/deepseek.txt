和水果供应商谈酒店早餐合作，重点不是“把价格压到最低”，而是把**稳定供应、品质一致、损耗可控、责任清晰**写进合作条件。建议按下面几类事项准备和谈判：

**1. 先明确自己的需求**
- 列出早餐常用水果清单，区分**每日必供**和**季节性/轮换**品类。
- 给出日均用量、周末/节假日峰值、最大最小订货量。
- 明确验收时间窗口，例如每天几点前到货，迟到如何处理。
- 明确加工要求：整果、切果、去皮去核、果切盒等，以及是否要求冷链配送。

**2. 品质标准要可验收**
- 按品类写清等级、单果规格、成熟度、外观、甜度或口感底线。
- 约定“允许不合格比例”，例如到货抽检不合格超过一定比例可拒收或换货。
- 明确验收方式：抽检比例、谁验收、不合格拍照留证、当场退换还是补货。
- 对香蕉、牛油果等后熟水果，约定到货成熟度，避免早餐当天不能出餐。

**3. 供应稳定性与替代方案**
- 要求供应商说明货源基地、季节性缺口时的替代方案。
- 约定缺货提前通知时间，以及缺货时的替代品类、补货时限和违约责任。
- 对核心品类可要求备选供应商或安全库存，不要单一来源。
- 节假日、极端天气、疫情等特殊时期的保供方案要写进合同或附件。

**4. 价格与结算**
- 不要只谈单价，要谈**含税、含配送、含加工**的到货价。
- 明确价格调整机制：调价周期、参考市场依据、提前通知天数、单次涨幅上限。
- 约定临时加单、紧急补货是否加价。
- 结算周期、对账方式、发票类型、付款条件写清楚。
- 可设置质量保证金或账期约束，但要注意合规和双方承受能力。

**5. 食品安全与资质**
- 核验营业执照、食品经营许可、检测报告、产地证明等。
- 明确农残、重金属等检测责任和频次，要求随货或定期提供检测报告。
- 配送车辆、周转箱、从业人员健康证、冷链温度记录要符合要求。
- 约定食品安全事故的责任划分、召回、赔偿和配合调查义务。

**6. 损耗与退换货**
- 明确验收前损耗由供应商承担，验收后按约定分担。
- 对内部质量问题，如切开后发现黑心、腐烂，约定发现后多长时间内可反馈并补货。
- 退换货响应时限要具体，例如几小时内补到位。
- 避免“只换不退”“下次抵扣”等模糊条款。

**7. 配送与服务**
- 约定配送频次、到达时间、卸货位置、验收联系人。
- 迟到、漏送、错送的违约金或补偿方式。
- 要求固定对接人和备用联系人，异常时多久响应。
- 旺季或临时增加用量，提前多久下单可保证供应。

**8. 合同关键条款**
- 合作期限、试用期、考核退出机制。
- 月度/季度考核指标：到货准时率、验收合格率、缺货次数、投诉响应。
- 连续不达标或重大食品安全问题的解约权。
- 价格、账期、违约责任、争议解决方式。
- 所有口头承诺写进合同附件，尤其是品质标准、补货时限、调价规则。

**9. 谈判策略**
- 先小批量试供2—4周，用实际到货合格率、缺货率、损耗率说话。
- 不要只找一家比价，至少准备两家备选，但避免恶意压价导致品质下降。
- 把“稳定”折算成成本：缺货导致早餐投诉、临时采购高价，往往比单价差更贵。
- 对核心品类争取账期或质量保证金，对非核心品类保持灵活采购。

**最需要盯住的四个指标：到货准时率、验收合格率、缺货次数、异常响应时长。** 把这四项写进考核，比单纯谈价格更能保证早餐水果稳定供应。
