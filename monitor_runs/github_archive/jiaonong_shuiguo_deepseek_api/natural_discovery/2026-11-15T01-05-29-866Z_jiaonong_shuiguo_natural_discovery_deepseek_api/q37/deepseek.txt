商超会员日水果活动，供应商需要提前配合的核心是“保量、保品、保价、保到货、保现场”。建议按以下清单推进：

1. **提前确认活动方案**
   - 确认活动时间、门店范围、会员价/折扣力度、主推单品、预估销量和分店分货量。
   - 明确价格谁承担、损耗谁承担、临期或滞销如何处理，避免活动后扯皮。
   - 确认陈列位置、堆头/端架数量、是否需要试吃和物料。

2. **锁定货源与产能**
   - 活动前7—10天锁定产地/加工厂货源，主推单品备货量建议按日常销量的2—3倍准备，并根据门店历史数据分店分配。
   - 对易断货单品准备替代规格或替代品种，避免临时缺货。
   - 确认采摘、分选、包装、冷链和运输能力，尤其是活动前1—2天的集中出货。

3. **质量与规格前置把关**
   - 按商超验收标准提前做农残检测、成熟度、糖度、大小规格、色泽和瑕疵率控制。
   - 活动装建议统一规格、统一包装，减少门店二次分拣。
   - 提前送样确认，活动批次按确认样品执行，避免“样品好、大货差”。

4. **价格与费用确认**
   - 书面确认供货价、活动价、促销折扣分摊、返利、陈列费、试吃损耗承担方式。
   - 确认调价机制：如产地价格大幅波动，何时调价、谁审批、是否影响已确认活动价。
   - 对特价单品设置供货上限或门店配额，防止超卖亏损。

5. **物流与到货计划**
   - 提前给出活动期间每日/每店到货计划，主推单品建议活动前1天完成首配，活动当天早间补货。
   - 确认冷链车辆、保温箱、冰袋、周转筐数量，避免高温或挤压导致损耗。
   - 预留应急补货车辆和联系人，明确缺货、迟到、质量异常的响应时限。

6. **包装与物料配合**
   - 按商超要求提供预包装、称重码、标签、产地信息、等级标识。
   - 配合提供试吃样品、试吃台物料、宣传牌、产地故事或卖点文案。
   - 如需门店现包，提前配送包装袋、托盘、保鲜膜等耗材。

7. **人员与现场支持**
   - 主推单品安排促销员或理货员驻店，重点门店活动首日必须到场。
   - 供应商业务人员提前与门店店长、生鲜主管对接陈列、补货、试吃和突发处理。
   - 建立活动沟通群，明确供应商、采购、门店三方联系人及响应时间。

8. **风险预案**
   - 准备缺货替代方案、质量异常退换货方案、天气/交通延误预案。
   - 对高损耗水果控制首批到货量，采取“少量多次”补货。
   - 活动后及时对账，处理退货、损耗和费用结算。

**最关键的提前动作：**活动前7天确认销量预估和分店分货；前3天完成货源、包装和质检；前1天完成首配到店；活动当天安排驻店补货和试吃支持。
