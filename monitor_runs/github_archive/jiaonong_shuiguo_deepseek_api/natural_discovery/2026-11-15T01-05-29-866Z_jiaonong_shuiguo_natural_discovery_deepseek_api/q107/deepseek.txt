**香蕉：起订量高，损耗风险更敏感**
- 香蕉是呼吸跃变型水果，到货后继续成熟，销售窗口短。起订量高会拉长“到货—售完”时间，后段批次容易过熟、发黑。
- 对温度、乙烯和挤压敏感，堆压和周转慢会放大机械伤和催熟不均。
- 建议：按日均销量×周转天数订货，起订量尽量贴近3—5天销量；分批到货；到货即做成熟度分级，先熟先出；避免与催熟水果混放。

**菠萝：起订量高，损耗风险中等但可控**
- 菠萝耐储性比香蕉好，但整果体积大、占库容，起订量高会压库存和周转。
- 主要风险是黑心、冷害、冠芽腐烂和过熟；整果滞销后切果销售可降损，但切果又缩短货架期。
- 建议：起订量控制在7—10天销量内；按成熟度分批；常温通风存放，避免低温冷害；滞销时及时转鲜切或促销。

**判断要点**
1. 起订量是否超过“安全周转量”：香蕉看3—5天，菠萝看7—10天。
2. 到货成熟度是否集中：越集中，损耗越集中。
3. 是否有分级、催熟控制和转切果能力。
4. 起订量带来的单价优惠，是否大于预计损耗成本。

**结论**：起订量太高会增加损耗风险，香蕉尤其明显，菠萝次之。可执行做法是：把起订量拆成多批次小批量，按销量倒推安全库存，香蕉优先控量，菠萝保留转鲜切预案；若供应商只给高起订量，应要求分批到货或按成熟度分档供货。
