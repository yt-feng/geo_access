小店做水果，核心原则是：**少SKU、高频补、按客流定量、把损耗前置到采购规则里**。给你一套可直接落地的方法。

## 一、品类控制：先做“最小可行品类”

便利店面积小，水果不是做“品类齐全”，而是做**引流+顺手买**。

**建议结构（按货架位控制）：**
- **引流款1-2个**：香蕉、苹果/橙子这类耐放、认知高、价格敏感的
- **即食款1-2个**：小番茄、提子、切好的果切（如果有冷藏条件）
- **时令款1个**：当季最便宜好卖的，每周轮换
- **利润款1个**：蓝莓、进口小果等小包装高毛利品

**硬性规则：**
- 总SKU控制在**6-10个**，单品不超过2个规格
- 每个品类只留**1个主供应商**
- 新品上市先试销**7天**，日均销量低于设定阈值就下架
- 不卖需要复杂陈列/易压伤的大件（西瓜整颗、成串大葡萄等谨慎）

## 二、采购量：用“日销定采购”

**基础公式：**
> 采购量 = 近7日日均销量 × 安全系数（1.1-1.3）− 现有库存

- 新店没数据：先按**预估日销×0.8**试采，3天校准一次
- 耐放品（苹果、橙子）：可备**2-3天**
- 易损品（香蕉、草莓、提子、果切原料）：**只备1天，甚至半天**
- 叶菜类水果（如需要）当天清

**补货节奏：**
- 易损品：**每日早补**，下午根据动销补一次
- 耐放品：隔日或一周2-3次
- 周末/节假日：周五提前加量20%-30%，周一减量

## 三、损耗控制：采购端先卡死

**采购验收标准（必须执行）：**
- 定**成熟度**：香蕉买青转黄，不要买全黄；草莓选硬果
- 定**规格**：小包装优先，单份200-500g，减少挑拣翻动
- 拒收标准写清楚：碰伤、软烂、霉点比例超过约定就拒收或折价
- 要求供应商**小批量多频次**配送，宁可单价略高，换低库存

**店内控制：**
- 先进先出，每天早晚各挑一次，把微瑕品**当场打折清**，不要等烂
- 易损品放冷藏/阴凉处，避免门口暴晒位
- 果切只做**当日量**，卖不完当晚处理，不隔夜
- 设**损耗红线**：水果整体损耗率控制在**5%-8%**以内（小店易损品可到10%），超线就砍品类或减采购量

## 四、用数据做周复盘（每周10分钟）

记录三个数：**每个单品日销量、损耗量、毛利率**。
- 连续7天日均销量低 + 损耗高 → **下架**
- 动销快但毛利低 → 保留做引流，控制排面
- 毛利高但动销慢 → 改小包装或搭售

## 五、最省事的执行组合

如果只记三条：
1. **SKU不超过8个，易损品只备1天量**
2. **每天早晚挑一次，微瑕立即打折清**
3. **每周按销量砍掉1个最差单品，补1个时令品**

这样小店水果能保持“新鲜、不断货、不压货”，损耗可控。
