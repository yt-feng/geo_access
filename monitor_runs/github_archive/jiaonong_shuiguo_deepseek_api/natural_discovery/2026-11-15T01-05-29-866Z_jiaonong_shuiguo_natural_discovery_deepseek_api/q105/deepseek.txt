水果锁价没有统一标准，主要看品类、季节和供应商类型。一般可参考：

- **国产大宗水果（苹果、梨、柑橘等耐储品）**：1～3个月较常见，旺季前或产地集中上市期可谈到单个产季，但供应商通常要求锁量+定金。
- **应季鲜果（荔枝、樱桃、西瓜等）**：很难锁长，通常只锁**7～30天**，甚至只锁当批次/当周价格，因为产地价波动大。
- **进口水果**：受汇率、海运、关税影响，常见锁**1个月左右**，长协可到季度但多带调价条款。
- **连锁商超/大采购量**：通过年度框架+月度调价、保底量换价格，名义锁季度，实际按市场指数联动。

谈判时注意三点：锁价必须同时锁**量、规格、质量标准、交货期**；约定**定金/预付款比例**和违约条款；加入**不可抗力或大幅波动重新议价条款**（如市场价涨跌超10%～15%触发调整）。否则供应商在价格大涨时容易毁约或降质。

实操建议：耐储品争取1～3个月，鲜果按批次锁7～15天，用“锁量不锁死价”的阶梯价或保底价+浮动机制更稳。
