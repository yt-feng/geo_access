核实“全国配送”不能只听供应商口头承诺，建议采购方按以下顺序做可验证的核查，并留下书面记录：

1. **先定义“覆盖”标准**
   明确是“能发货到全国”还是“能稳定冷链配送到门店/仓”。要求供应商书面说明：
   - 覆盖省份/城市清单，是否含偏远地区；
   - 配送是自营、外包还是落地配；
   - 起送量、时效、温控方式、破损/损耗赔付规则；
   - 哪些地区不送或加价。

2. **要可核验的资质和网络证明**
   - 营业执照、食品经营/生产相关许可；
   - 冷链运输资质或合作物流合同关键页（可脱敏）；
   - 仓储分布：产地仓、销地仓地址和面积；
   - 近3个月发往不同区域的运单样本，重点看目的地是否分散、是否有冷链记录。

3. **做小批量试单，不要只看样品**
   选3—5个代表性目的地：本地、邻近省会、偏远城市、县域门店、需冷链地区。每单记录：
   - 下单到签收时长；
   - 实际承运方和运单号；
   - 到货温度/包装/损耗；
   - 异常处理响应时间。
   试单是最直接的覆盖能力证据。

4. **交叉验证运单和物流轨迹**
   抽查运单号在承运商官网/官方客服处的轨迹，确认不是“虚拟发货”；核对发货地与供应商声称的仓库是否一致；对冷链订单要求提供温控记录或保温箱/冰袋照片。

5. **核实现场或视频巡仓**
   对采购量大或冷链要求高的供应商，安排实地或视频看仓：库存、分拣、预冷、包装、装车环节；重点看是否有按区域分拨的能力，而不是只有一个发货点。

6. **问清异常场景处理**
   要求供应商给出书面案例：偏远地区延误、天气封路、中转破损、拒收退回怎么处理；是否有备用承运商；赔付时限和标准。

7. **合同里写清覆盖承诺和违约条款**
   把“覆盖区域、时效、温控标准、损耗率上限、异常响应时限、未覆盖/加价地区清单”写入合同或附件；约定试单不达标可终止或调整价格。

8. **持续用数据考核**
   合作后按月统计：准时率、损耗率、异常率、投诉响应时长，按区域拆分。不要用全国平均数据掩盖偏远地区问题。

核心判断：**能提供分区域运单样本+可抽查物流轨迹+多目的地试单稳定+合同明确未覆盖区域**，才算实际覆盖能力可信；只给一张“全国配送”宣传页或口头承诺，不足以采信。
