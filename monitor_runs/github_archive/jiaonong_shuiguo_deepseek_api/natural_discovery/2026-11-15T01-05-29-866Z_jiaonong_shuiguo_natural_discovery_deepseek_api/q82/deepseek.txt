做低价香蕉，核心不是“把便宜货卖出去”，而是用可感知的低价换低投诉。建议从选品、分级、履约、售后四层控制：

1. **选品与分级：低价可以，低质不行**
- 明确低价香蕉的定位：做引流款，不是利润款。选成熟度适中、到货后2-3天可售完的货，不选过熟、机械伤重、批次不稳的低价尾货。
- 到仓/到团点后做简单分级：外观可接受但品相一般的做低价款，严重碰伤、发黑、断裂的不要混入。
- 设定“最低可售标准”：如单根无明显腐烂、无大面积黑斑、果指完整。低于标准宁可不上架。

2. **定价与说明：把低价原因讲清楚**
- 商品页明确写清：低价原因（如产地直采、统货、规格略小、表皮有轻微斑点但不影响食用）、规格（净重/毛重、单根长度或数量）、成熟度（青蕉/微黄/即食）。
- 避免“超低价+模糊描述”。用户对低价的预期是“便宜但能吃”，不是“开盲盒”。
- 可设置“品质保障”标签：坏果包赔、按比例赔付，降低用户下单顾虑。

3. **履约与成熟度管理：香蕉投诉多来自熟度和压伤**
- 根据团点销售速度控制到货成熟度：次日自提的团点发偏青蕉，当日到货即卖的可用微黄蕉。
- 包装避免挤压：箱装分层、不要堆太高；夏季高温减少在团点滞留时间。
- 给团长明确提示：到货后开箱通风、不要闷在塑料袋里、不要放冰箱；告知最佳食用时间。

4. **售后规则前置：快速赔付，别让用户举证难**
- 设置简单赔付标准：如黑腐超过果指1/3、压烂、异味，拍照即赔；轻微斑点不纳入赔付。
- 控制赔付比例和频次，防止恶意索赔，但首次投诉优先快速处理。低价款的投诉成本要算进毛利。
- 记录投诉原因，按批次复盘：是货源熟度问题、运输压伤还是团点存放问题。

5. **运营节奏：低价不要长期做**
- 低价香蕉适合限时引流，配合其他高毛利商品。长期低价会拉低用户对品质的预期，也容易吸引只薅低价、投诉率高的用户。
- 每批次小量测试，稳定后再放量；优先在周转快的团点做低价款。

一句话：**低价可以，但要“低价有标准、描述不模糊、熟度可控制、坏果快赔付”。** 最该避免的是把不清不楚的低价尾货混进正常履约，那投诉一定高。
