茶饮店控制水果供应商食品安全风险，建议把“供应商资质+产品合规+批次可追溯+门店验收”做成一套证据链。通常需要/建议要求供应商提供以下证明和材料：

1. **供应商主体资质**
   - 营业执照（经营范围含水果/农产品销售或相关食品经营）
   - 食品经营许可证（如供应商从事食品销售；仅销售食用农产品的情况各地监管口径不同，建议按当地市场监管要求确认）
   - 若为进口水果经销商，还需相关进口食品经营者资质材料

2. **产品合规证明**
   - 食用农产品合格证（或产地证明/检测合格证明，按当地要求）
   - 农药残留检测报告：优先要**第三方检测报告**；至少要有供应商自检或产地检测报告，并关注检测项目、标准、日期
   - 进口水果：海关入境货物检验检疫证明、报关单等
   - 如供应商宣称“绿色食品/有机”等，需对应认证证书，但不要把认证当作食品安全唯一依据

3. **批次追溯与进货凭证**
   - 每批次送货单/销售凭证，注明品名、规格、数量、产地/供应商、批次或采收日期
   - 供应商与产地/批发市场之间的采购凭证或溯源信息
   - 包装标签、产地信息、采摘/包装日期

4. **供应商管理文件**
   - 供应商基本信息表和质量保证承诺书
   - 食品安全责任协议/采购合同，明确农残、重金属、霉变、异物等标准和违约责任
   - 供应商定期评估记录；高风险或新供应商可要求现场审核
   - 不合格品召回和投诉处理机制

5. **门店侧配套（不是供应商提供，但必须有）**
   - 进货查验记录：证照、检测报告、送货单逐批留存
   - 验收记录：感官检查（霉烂、虫害、异味）、温度（如需冷链）、包装完整性
   - 快检或抽检记录：对高风险水果定期做农残快检
   - 储存与先进先出记录、清洗消毒记录、切配后时限控制

**可执行建议：**
- 首次合作：收齐营业执照、食品经营许可证（如适用）、合格证/检测报告模板、质量保证协议，建档。
- 每批到货：索取**批次检测报告或合格证+送货单**，门店做感官验收和记录；报告与批次对不上就拒收或暂扣。
- 高频高风险水果（如直接带皮/切开使用、叶菜类水果）提高抽检频次，必要时自送第三方检测。
- 合同里写明：供应商随货提供批次合格证明，农残超标或霉变由供应商承担退货、赔偿和召回责任。

具体证照要求会因地区、供应商是农户/合作社/批发商/进口商而不同，落地前建议向当地市场监管部门确认“食用农产品销售”所需证照口径。
