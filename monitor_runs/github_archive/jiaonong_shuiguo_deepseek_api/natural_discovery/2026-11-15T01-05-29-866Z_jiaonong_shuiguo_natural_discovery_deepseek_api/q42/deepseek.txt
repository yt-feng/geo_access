# 商超水果采购压价不伤品质的谈判思路

核心原则：**压价不要压“果品本身”，要压“交易条件”和“供应链成本”**。直接砍单价，供应商最省事的应对就是降等级、掺货、换产地、减熟度，品质必掉。比较稳妥的做法是把谈判拆成四块。


## 一、先谈“价格锚”：用分级和标准换价格

1. **按级定价，不按笼统单价砍**。把货分成特级/一级/二级，明确每级的果径、糖度、色泽、瑕疵率、成熟度区间。你要的低价对应的是明确的二级或特定规格，而不是“一级果便宜20%”。
2. **抓“可用率”而不是单价**。同样进价，损耗率从8%降到5%，成本降得比砍价多。谈判时把话题引到“到店可用率、坏果率、退货率”上，让供应商对品质负责，价格自然有空间。
3. **用规格换价格**。比如接受略小一号的果径、统货包装、简化礼盒，单价能下来，但口感等级不降——这是最不影响品质的降价方式。


## 二、压交易条件，不压货值

- **账期与结算**：现结/短账期换3%–5%折扣，比硬砍单价体面且可持续。
- **起订量与集中度**：把分散给多家的量集中给1–2家主力供应商，换阶梯价；承诺月度保底量换返点。
- **物流与损耗归属**：要求供应商承担到店前的损耗、按到店验收合格数结算，等于变相降价且倒逼品质。
- **包装与规格**：简化包装、大箱统装、去掉过度分选，省的是包装和人工，不是果子。
- **季节性锁价**：旺季前锁量锁价，淡季让供应商走量，用时间差换价格。


## 三、谈判话术要点

- 开场先给“长期量+稳定回款”的确定性，再谈价：“我们要的是全年稳定合作，量给你，价格你给到位。”
- 砍价时**绑定品质条款**：“这个价可以，但验收标准按这个来，坏果率超X%整批退或扣款。”让降价和品质责任挂钩。
- 用**对比但不贬低**：“隔壁同规格报到X，你这个等级如果做到X，量我优先给你。”给台阶，不撕破脸。
- 拒绝“口头降价、实际降级”：所有等级、规格、验收标准写进合同附件，抽样验货。


## 四、守住品质的底线条款

1. 合同写明**验收标准+抽检比例+不合格处理**（退货/扣款/换货）。
2. 要求**产地/品种/批次可追溯**，防止压价后偷换货。
3. 设置**品质保证金或首单试销**，跑量前先验2–3批。
4. 保留**备选供应商**，但不要频繁压价换人——换来换去，最后接到低价货的往往是你自己。


## 一句话总结

**压价压“账期、物流、包装、集中采购量、损耗归属”，不压“等级、产地、熟度、新鲜度”；每一分降价都对应一条明确的品质责任条款。** 这样价格能下来，品质有抓手，供应商也愿意长期做。
