判断检测报告是否对应“当前批次”，核心是核对 **批次标识、样品信息、时间逻辑、检测项目与结论** 四类信息，并结合索证索票和抽检复核。可按下面清单执行：

1. **核对批次号/生产日期是否一致**
   - 检测报告、送货单、包装标签、发票/订单上的批次号、采摘/包装日期、产地必须能互相对应。
   - 若报告只写“苹果”“柑橘”等大类，没有批次号或生产日期，不能直接认定为对应批次。
   - 报告上的样品名称、规格、产地、供应商名称应与实际到货一致；贸易商供货时还要看报告主体是生产商还是供应商。

2. **看抽样与报告时间逻辑**
   - 报告采样/送检日期应早于或接近该批到货日期，不能明显晚于到货后补做。
   - 检测报告日期应在该批次生产/采摘之后；若报告日期早于批次生产日期，可能不是同一批。
   - 注意报告有效期：检测报告通常只对来样或所检批次负责，不能简单用一份旧报告覆盖后续多批次。

3. **核对检测机构与报告真伪**
   - 查看是否盖有检验检测专用章/CMA标识（如适用），报告编号、机构名称、联系方式是否完整。
   - 通过检测机构官网、电话或报告二维码核验报告编号真伪。
   - 复印件、截图、PS痕迹明显、无骑缝章或多页缺页的，应要求提供原件或电子签章版。

4. **核对检测项目是否覆盖风险**
   - 农药残留项目应覆盖该水果常检高风险项目；有承诺“无农残”“绿色/有机”的，还要看对应认证和检测项目。
   - 报告结论必须明确“合格/符合”，不能只看有报告不看结论。
   - 若采购合同或平台有特定项目要求（如重金属、保鲜剂、二氧化硫等），要逐项核对。

5. **建立批次对应证据链**
   - 要求供应商在送货单上注明检测报告编号、批次号、生产日期，并盖章/签字。
   - 保留包装标签照片、到货验收记录、抽样记录，必要时双方封样。
   - 一份报告对应多个门店/多次送货时，要求供应商提供批次拆分说明或每批次的对应声明。

6. **存疑时做复核**
   - 信息对不上、报告模糊、批次频繁更换但报告不变时，可拒收或要求补证。
   - 对高风险品种/新供应商，采购方可自行送第三方检测或现场抽检，费用和责任在合同中约定。
   - 合同中明确：供应商须随货提供与批次一致的检测报告，虚假报告承担退货、赔偿和违约责任。

**快速判断口诀：** 看“三号”（批次号、生产日期、报告编号）能否对上，看“三期”（采样、报告、到货）是否合理，看“三章”（检测章、供应商章、送货单签章）是否齐全；对不上就暂缓收货并要求补证。
