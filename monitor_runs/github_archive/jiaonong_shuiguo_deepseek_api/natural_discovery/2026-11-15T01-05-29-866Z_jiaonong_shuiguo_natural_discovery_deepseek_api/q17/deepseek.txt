# 社区超市水果：控鲜 + 控库存的实操方法

核心思路是**“小批量、快周转、按天定生死”**——水果是损耗生意，不是囤货生意。

## 一、订货：按销量定，不按感觉定

- **建单品台账**：每个品类记录近7天日均销量、损耗量。订货量 ≈ 日均销量 × 1.5天（社区店客流稳定，备一天半足够）。
- **分品类定节奏**：
  - 叶菜类、草莓、葡萄、荔枝等**易损品**：每天早晚两次小批量补，宁缺勿压；
  - 苹果、梨、柑橘、土豆洋葱等**耐存品**：3天一批，可适当多备；
  - 香蕉、芒果等**后熟品**：订半熟货，按成熟度分批上架。
- **看天订货**：高温、雨天销量降、损耗升，主动减单；节假日提前1天加量但不翻倍。

## 二、收货：当天验，不合格拒收

- 固定验货标准：看果柄、闻气味、捏硬度、抽箱查底层（上层好货掩盖底层烂货是常见坑）。
- 到货即分拣：**一级品上主陈列，二级品（轻微磕碰）单独打折区，三级品当天处理**（切果盒、员工价、次日早市特价）。
- 要求供应商按小箱/小件配送，减少单次到货量。

## 三、陈列与保鲜：少摆勤补

- **陈列量控制在半天销量**，货架空一点没关系，勤补货比堆满更保鲜；
- 易损品放冷藏柜或阴凉处，避免阳光直射和堆压；
- 香蕉、牛油果等忌冷藏的单独放；
- 每天**早晚两次巡架**，挑出软烂、发黑的立即下架，别让一颗烂果传染一筐。

## 四、库存预警与清货机制

- 设**单品库存上限**（如叶菜不超过1.5天量），超限不再进货；
- **动态定价清货**：临期/次品当天下午5点后打折，晚上8点后打包特价，宁可保本出清也不留到第二天；
- 每周盘点一次，算出各品类**损耗率**，损耗持续高的品类直接减量或换供应商；
- 用简单表格或收银系统记录进销存，别凭记忆。

## 五、止损底线

- 单品连续两周损耗率超10%，要么换货源，要么砍掉该品类；
- 库存周转天数目标：叶菜类≤1天，普通水果≤2–3天，耐存品≤5天。

**一句话总结**：少量多次进货、到货即分级、陈列只摆半天量、临期主动降价清、每周看损耗数据调结构。水果店赚钱靠周转，不靠囤货。
