最容易忽视的不是“价格”和“好不好吃”，而是下面这些会直接影响损耗、复购和现金流的细节：

1. **同一供应商的“分级稳定性”**  
   不要只看样品。要确认：同一规格连续3批的糖度、单果重、成熟度、瑕疵率是否稳定。水果生意长期赚钱靠的是“每次差不多”，不是“偶尔特别好”。

2. **产地/批次可追溯与混装风险**  
   问清楚是自有基地、合作社还是多产地拼货。多产地拼货容易同批不同质，售后时扯皮。要求批次号或至少能对应到采收日期、产地。

3. **采后处理与冷链细节**  
   重点问：预冷多久、运输温度、是否混装催熟水果、到货时中心温度。很多损耗不是货不好，是采后和运输断链。

4. **验收标准是否可执行**  
   不要只写“新鲜无腐烂”。要量化：容许腐烂率、机械伤比例、规格误差、糖度下限、到货温度、超差如何处理。最好有照片标准和抽检比例。

5. **售后赔付的触发条件和时限**  
   最容易忽视的是“发现坏果后多久内报损有效、怎么举证、赔货还是赔款、是否扣下一批货款”。没有书面规则，长期合作一定会在旺季扯皮。

6. **供应弹性与旺季保供能力**  
   问：节假日/天气异常时能不能保量、涨价机制是什么、断供提前多久通知。长期稳定不是永远便宜，而是缺货时知道预期。

7. **账期与资金占用**  
   低价比高账期更危险。要算清：现结折扣、账期利息、压货资金占用、退货扣款。很多水果生意死在“毛利看着有，现金流转不动”。

8. **供应商的下游客户结构**  
   如果它主要供商超，规格和稳定性通常更好；如果主要走批发市场，价格弹性大但一致性弱。还要看它是否同时供你的直接竞品，避免同质化价格战。

9. **包装与物流责任边界**  
   纸箱承重、内衬、托盘、装车责任、卸货责任、运输破损谁承担。水果损耗很多发生在“最后一公里”和装卸环节，合同不写清就会默认你承担。

10. **换供应商的切换成本**  
    别忽视试销期、口感差异导致的客诉、陈列调整、员工分拣习惯。长期稳定供应商要留备选，但不要频繁换；最好保持“主供+备供”，备供每季度小批量验证。

可执行建议：  
- 新供应商先做**3批小批量试销**，每批记录到货温度、腐烂率、规格合格率、客诉率、实际毛利。  
- 合作前签一页《验收与赔付细则》，把上面第4、5、9条写死。  
- 主供占比控制在70%左右，备供20%-30%，避免被单一供应商卡脖子，也避免分散到没有议价权。
