水果店遇到坏果，结算或赔付的核心原则是：**先保留证据、按合同/约定处理、能退换优先退换，不能退换再谈折价或扣款**。不要先自行扔掉或混卖，否则容易失去索赔依据。

可以按下面步骤处理：

1. **到货当场验收**
   - 抽检或全检，坏果、烂果、压伤、霉变的分开拍照/录像。
   - 保留称重记录、进货单、送货单、批次、车牌/送货人信息。
   - 让送货人当场签字确认坏果数量；对方不签，就拍照录像并发微信/短信确认。

2. **看合同或长期约定**
   - 有合同：按合同里的验收标准、损耗率、赔付比例、退换货条款执行。
   - 没合同：按行业惯例和双方长期交易习惯谈，通常要求**退货、换货、折价或扣减对应货款**。
   - 常见约定方式包括：坏果按实际数量全额扣款；按比例折价；超过约定损耗率的部分由供应商承担；整批严重不合格可拒收或整批退货。

3. **优先选择处理方式**
   - **能退换**：坏果退回换好果，运费/损耗由责任方承担。
   - **不能退换**：按坏果数量对应货值扣款，或双方协商折价。
   - **整批严重坏果**：可拒收，要求退款或换货。
   - **已售出后才发现**：保留顾客反馈、照片、退款记录，向供应商追偿对应损失；但要注意及时通知供应商，避免拖延导致责任不清。

4. **结算时怎么扣**
   - 按“坏果数量 × 进货单价”扣减最清晰。
   - 如果合同约定损耗率，比如允许3%损耗，则只对超过3%的部分索赔。
   - 扣款前最好书面确认：微信、短信、对账单签字都可以，写明批次、数量、金额、处理方式。
   - 不要在没有通知供应商的情况下直接从大额货款里随意扣，容易引发争议；先发对账明细和照片，给对方确认期限。

5. **协商不成怎么办**
   - 保留进货凭证、验收记录、照片视频、沟通记录、退货物流凭证。
   - 先按合同争议条款协商；协商不成可向市场监管部门投诉或走诉讼/仲裁。
   - 金额不大时，优先用“后续订单扣减”方式解决，成本更低。

6. **日常预防**
   - 固定验收标准：坏果率、压伤标准、霉变标准、退货时限。
   - 送货单上增加验收签字栏。
   - 对高频出问题的供应商，改为货到付款、批次抽检、缩短账期或换供应商。

简单说：**当场验、留证据、按约定、先退换、再扣款、书面确认**。没有合同就按实际坏果数量和进货价谈扣减，别把坏果损失全部自己承担。
