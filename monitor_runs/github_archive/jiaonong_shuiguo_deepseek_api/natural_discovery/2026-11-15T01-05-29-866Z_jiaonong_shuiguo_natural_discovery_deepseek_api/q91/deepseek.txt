优先选 **小把（3–5 根）为主，单根为辅，整袋谨慎上**。便利店卖香蕉，核心不是“包装好看”，而是 **周转快、损耗低、客单低、即买即吃**。

具体建议：

1. **主力：小把 3–5 根**
   - 最适合便利店场景：一个人或两个人当天/两天内吃完。
   - 客单价适中，比单根更有销售效率，又不像整袋容易剩。
   - 陈列时按“把”卖，不要强迫顾客拆开。

2. **辅助：单根**
   - 适合写字楼、学校、交通枢纽、社区门口等“即买即吃”场景。
   - 单根能降低尝试门槛，也能消化小把里快熟的单根。
   - 但单根损耗和理货成本高，只建议作为补充，不建议全部单根。

3. **整袋：谨慎上，最好不做主推**
   - 整袋适合家庭客群明显的社区店，但便利店主流客群是单人/即时消费，整袋成交慢、熟度风险大。
   - 如果周边家庭客多，可少量上 **小袋 5–6 根**，不要大袋。
   - 整袋必须明确标价、标熟度建议，避免顾客买回去吃不完。

**判断标准很简单：**
- 门店在写字楼/学校/交通点：**单根 + 小把**。
- 社区店、家庭客多：**小把为主，少量小袋**。
- 香蕉损耗高、客流不稳定：**先只上小把，测 1–2 周再决定是否加单根或小袋**。

另外，香蕉上架要按熟度分级：**青黄果做次日销售，黄熟果当天主推，过熟果及时打折或做果切/搭配促销**。便利店卖香蕉，包装形式是次要的，**控制订货量和熟度周转**才是关键。
