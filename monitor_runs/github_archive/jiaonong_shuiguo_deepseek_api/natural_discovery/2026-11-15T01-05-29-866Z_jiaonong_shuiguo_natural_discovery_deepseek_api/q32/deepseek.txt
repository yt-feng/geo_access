判断香蕉供应商能否全年稳定供货，不能只听“我们全年都有货”，要按“产地结构—产能与季节—冷链与催熟—合同与应急”四条线做可核验的尽调。香蕉是典型的跨产区、跨季节品类，单一产地很难全年稳定，核心看供应商是否有多产区组合和计划能力。

**1. 先问清产地结构，不要只看总货量**
- 要求供应商列出全年各月份的主供产区、备用产区和预计占比。比如国内海南、云南、广西、广东，以及进口菲律宾、越南、厄瓜多尔等，能否形成季节衔接。
- 重点看“青黄不接”月份：国内产区换季、台风季、寒潮期、春节前后，供应商靠哪个产区补位。
- 如果供应商只报一个产地或一个港口，却承诺全年稳定，基本要打问号。

**2. 核产能和季节波动，要数据不要口头承诺**
- 要求提供近12个月逐月实际供货量、最大月供、最小月供、断供或减供记录。
- 问自有基地/合作基地面积、挂果面积、合作农户数量、单月可调度货量，以及这些货量中有多少已锁定给其他客户。
- 看供应商是否有跨区域调货能力。香蕉主产区受台风、寒潮、病害影响明显，多产区布局比单一大基地更抗风险。
- 可要求提供产地证明、采购合同或基地合作协议摘要，敏感价格可脱敏，但产区、数量、期限要能对上。

**3. 冷链和催熟能力决定“有货”能否变成“可卖”**
- 香蕉需要采后冷链、催熟和周转。问供应商是否有稳定的冷藏运输、港口/口岸通关能力、催熟库容量和日处理量。
- 看其能否按你的门店节奏分批到货，而不是一次性压货。全年稳定不仅是总量稳定，更是周度、日度到货稳定。
- 要求提供冷链车辆、催熟库、质检流程的证明或现场查验机会；新供应商建议先小批量试单。

**4. 合同里把“稳定”写成可考核条款**
- 约定月度最低供货量、到货合格率、缺货提前通知期、替代产区方案和违约处理。
- 设置安全库存和双供应商机制：主供应商占70%—80%，备用供应商占20%—30%，避免单点依赖。
- 对台风、寒潮、口岸拥堵等情形约定预案，比如提前备货天数、替代产地、价格调整机制。
- 付款和账期与履约表现挂钩，不要一次性给足账期或预付款。

**5. 现场和外部交叉验证**
- 实地看基地、加工厂、冷库、催熟库，重点看淡季是否仍有出货记录。
- 查近一年的物流单据、质检报告、海关/口岸记录（如涉及进口），核对供货连续性。
- 向其现有客户（尤其是同规模连锁超市）了解旺季缺货率、到货质量波动和应急响应。
- 用试单验证：连续3个月、覆盖至少一个淡季月份，按周考核到货量和合格率。

**简单判断标准：**
- 能拿出逐月产区切换表、近12个月供货数据、多产区证明和冷链催熟能力的，可信度较高。
- 只承诺“全年有货”、说不出淡季来源、没有备用产区、不愿接受试单和合同考核的，不建议作为主供应商。
- 最稳妥的是“主供+备供+合同考核+淡季试单”组合，而不是把全年稳定押在一家供应商的口头保证上。
