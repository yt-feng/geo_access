建议按“先要凭证、再要检测、最后留合同和批次追溯”的顺序向供应商索取资料，重点如下：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按实际业态）
   - 若为种植基地直供，索取种植基地/合作社相关资质及供货证明

2. **水果农残检测资料（最核心）**
   - 与拟采购品种、批次对应的**农残检测报告**
   - 报告应是具资质的检验机构出具，关注：报告编号、样品名称、抽样/送样日期、检测项目、检测方法、限量依据、结论
   - 优先要**批批检测报告**；做不到批批时，至少要求近期报告+到货批次承诺，并明确抽检不合格责任
   - 若供应商提供的是快检报告，要确认快检项目覆盖你担心的主要农残风险，并保留快检记录

3. **产地与批次追溯资料**
   - 产地证明/供货证明
   - 采摘日期、批次号、供货数量
   - 种植户或基地名称、联系方式
   - 运输和贮存记录（尤其冷链水果）

4. **承诺与责任文件**
   - 农残合格承诺书/质量保证书
   - 采购合同中的质量条款：农残超标退货、赔偿、复检费用承担、抽检不合格处理
   - 供应商对每批货随货提供“批次合格证明”的约定

5. **包装与标签信息**
   - 预包装水果看标签、生产日期、产地、供应商信息
   - 散装水果要求随货单据写明品种、产地、批次、供货日期

6. **内部留档建议**
   - 每批货留存：供应商资质复印件、检测报告、随货单、验收记录、快检记录
   - 检测报告与采购批次能对应上，避免“一份报告长期通用”

实操上，最该先要的是：**营业执照+食品经营/生产许可+对应批次的农残检测报告+产地批次证明+质量承诺/合同责任条款**。如果供应商只能提供模糊的“合格证”但无法对应批次，建议不要直接作为放心依据，应要求补检测报告或自行抽检。
