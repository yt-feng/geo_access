做小包装香蕉，核心是“少进货、快周转、控呼吸热”，包装和损耗要一起看。给你一套可直接执行的采购和验收要点：

**一、包装形式**
1. **按份定量**：社区店建议每份2～3根、约300～500克，单人/小家庭一次吃完。不要做太大份。
2. **优先选择带透气孔的薄膜袋或网袋**：香蕉呼吸旺，完全密封容易闷出水和黑斑。塑料袋必须打孔，或用开孔网袋、纸托+保鲜膜局部包。
3. **避免整串紧裹**：整串用保鲜膜缠死会积聚乙烯和水分，加速成熟。可整串买回后店内分份，用橡皮筋或扎带轻固定，袋口留缝。
4. **托盘/纸盒保护**：小包装放浅纸托或硬纸盒，防止堆叠压伤。香蕉怕挤压，压痕处最先发黑。
5. **标签位置**：价签贴袋面，不要直接贴果皮；果柄处可包一小段保鲜膜，减少柄部失水开裂。

**二、采购时的成熟度控制**
1. **看颜色分级**：社区店快销，采购以“微黄带绿”为主，即1～2号色；留少量“黄熟”当天卖。不要一次全进全黄果。
2. **分批到货**：每周2～3次小批量补货，比一次进一周量更稳。小包装本身是快消品，断货比压货损失小。
3. **问清催熟状态**：采购时确认是自然熟还是催熟果，催熟果后熟快、货架期短，要缩短陈列时间。
4. **检查果柄和棱角**：果柄发黑、棱角明显鼓起、表皮有压伤水渍的不要。整箱里看底层和中间，压伤常藏在下面。

**三、验收与到店处理**
1. **开箱散热**：到店立即拆箱，不要连纸箱闷放。香蕉装箱后有田间热和呼吸热，闷着会加速转黄。
2. **挑出伤果**：有碰伤、裂口、发霉的单根立即挑出，伤果会释放乙烯并传染。轻微碰伤可切段做“即食份”当天特价，不要混在正常份里。
3. **分份时机**：建议到店后分份，不要采购时就要求供应商全部分好小袋——分装越早，伤口和闷袋风险越大。若供应商分装，验收时重点查袋内是否有水汽、袋底是否积水。
4. **称重抽检**：小包装按份卖要抽称，避免“标500克实际420克”引发投诉；同时查每份根数是否一致。

**四、陈列与损耗管理**
1. **阴凉通风陈列**：不要放冷柜，香蕉低于12℃会冷害发黑；也不要暴晒。放阴凉货架，避免与苹果、梨等释放乙烯的水果紧挨。
2. **少量多补**：陈列量控制在半天销量，卖完再补，减少翻动。
3. **每天两次翻检**：上午和傍晚各挑一次，转黄果移到“今日特价”区，黑斑果及时下架。
4. **设损耗台账**：按“到货份数—售出份数—报损份数”记，连续两周就能算出合理进货量和安全库存。

**五、采购合同/沟通要点**
- 明确到货成熟度范围（如1～2号色为主，黄熟不超过20%）。
- 约定压伤、水烂、霉变的验收扣重比例。
- 小包装若由供应商分装，约定袋型、打孔、每份重量和根数，并抽检袋内积水。
- 先小批量试销一周，测出日均销量再定固定采购量。

一句话原则：**香蕉小包装赚的是周转钱，不是囤货钱；采购宁少勿多、宁绿勿黄，包装要透气、陈列要阴凉、每天勤挑。**
