甜度和出汁率不是二选一，要按用途定优先级。给茶饮店的可执行判断：

**结论：多数茶饮场景里，甜度优先于出汁率；但做鲜果茶/果肉感产品时，出汁率权重会明显上升。**

具体分开看：

1. **做菠萝果酱/糖浆/浓缩底**  
   优先看**甜度和风味浓度**，出汁率次要。因为这类产品后面会加糖、加水或茶汤稀释，原料本身香气和甜感不够，后面很难补得自然。

2. **做鲜菠萝果茶、果肉茶**  
   两个都重要，但排序是：**香气/甜酸平衡 > 果肉质地 > 出汁率**。出汁率低不一定差，果肉紧实反而更适合做果肉型产品；但出汁率太低会导致单杯原料成本高、出品不稳定。

3. **做菠萝冰沙、果汁类**  
   **出汁率权重上升**，因为直接决定出杯量和成本。但甜度也不能太低，否则要靠糖浆补，容易盖掉果香。

4. **算成本时别只看单价**  
   用“每杯可用果肉/果汁成本”判断：  
   **每杯成本 = 原料单价 ÷（出汁率或可用果肉率）**  
   出汁率低的原料即使便宜，单杯成本也可能更高。

**建议采购标准：**
- 先定产品类型：果肉型还是果汁型；
- 果肉型：甜酸比、香气、果肉完整度优先，出汁率设最低门槛；
- 果汁型：出汁率和甜度一起测，算出每杯成本；
- 小批量试产：同一配方做3杯，比较香气、甜酸、出杯量、是否需要补糖。

如果你是开茶饮店采购鲜菠萝，**优先选香气足、甜酸平衡、成熟度稳定的果**，出汁率作为成本指标而不是第一筛选指标。
