可以从“买、收、存、用”四个环节控制，重点是成熟度分级和先进先出。

1. **采购时控制成熟度**
- 优先采购七到八成熟的香蕉，避免一次性大量采购已经出现黑点、软塌的货。
- 和供应商约定到货成熟度标准，例如“允许少量芝麻蕉，但软烂、裂果、明显压伤比例不超过约定值”。
- 分批到货，不要一次囤太多；按食堂每日用量测算，香蕉保质期短，通常按2—3天用量采购更稳。

2. **收货时按成熟度分级**
- 到货后立即分为青一点、正好熟、偏熟三档。
- 偏熟的优先当天使用，不要和青香蕉混放，避免乙烯催熟整批。
- 香蕉有机械伤、裂口的单独挑出，优先加工使用。

3. **储存上减少催熟和压伤**
- 未熟香蕉常温存放，避免冷藏造成冷害；已熟香蕉可短期冷藏延缓过熟，但表皮会变黑，不影响内部使用。
- 不要整箱堆压，悬挂或单层摆放更好。
- 香蕉不要和苹果、梨等释放乙烯较多的水果混放。
- 保持通风，及时挑出已过熟果，避免影响其他香蕉。

4. **使用上做分级菜单**
- 正好熟的直接作为餐后水果。
- 偏熟的优先用于香蕉牛奶、香蕉燕麦、香蕉面包、水果沙拉、烘焙等加工用途。
- 建立“今日先用偏熟香蕉”的标识和先进先出规则，食堂窗口、库房、加工间信息同步。
- 对剩余香蕉做每日盘点，临期偏熟的在次日菜单中优先消化。

5. **用数据控制采购量**
- 记录每日领用量、剩货量和废弃量，按周调整采购量。
- 遇到节假日、考试周、天气变化等用餐人数波动，提前调整订单。
- 和供应商约定小批量、多频次补货，比一次压低价格大量采购更能减少浪费。

核心是：**别买太熟、到货分级、偏熟先用、少量多次补货。**
