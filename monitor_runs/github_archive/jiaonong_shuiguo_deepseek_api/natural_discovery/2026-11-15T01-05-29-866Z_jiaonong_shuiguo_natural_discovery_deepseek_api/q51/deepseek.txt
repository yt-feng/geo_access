要固定，但不要只固定一个产地或一个批次。更稳妥的做法是：**固定“质量标准 + 主供应商 + 备用产地”，按批次验收和拼配，而不是把配方锁死在单一产地/单一批次上。**

具体建议：

1. **先固定质量标准，而不是先固定产地**
   - 设定可量化指标：糖度、酸度、香气、出汁率、颜色、果径/成熟度、农残检测、微生物指标。
   - 水果口味波动是自然属性，单靠“固定产地”不能完全解决；同一产地不同季节也会波动。

2. **主供应商固定 + 备用供应商备案**
   - 主供应商保证稳定性和可追溯性，签年度框架协议，明确规格、验收标准和异常处理。
   - 至少储备1—2个备用产地或供应商，避免主产地受灾、涨价或断供时临时换料导致口味突变。

3. **固定“供应批次逻辑”，不是固定单一批次**
   - 要求供应商按采摘期/加工批次供货，保留批次号、采摘日期、检测报告。
   - 每批到货做小样杯测/感官测试，合格才入库；不合格批次退货或降级使用。

4. **建立拼配标准，用“风味目标”抵消波动**
   - 比如设定目标糖酸比区间，不同批次按比例拼配，使最终饮品风味落在可接受区间。
   - 对鲜果类可考虑冷冻果浆、浓缩汁、NFC果汁作为稳定基料，鲜果做风味增强，降低纯鲜果波动。

5. **门店端做简单可执行的管控**
   - 每批水果到店做糖度抽测和试饮，记录“偏酸/偏甜/香气弱”的调整方案。
   - 配方留出微调空间，比如糖浆±5%、柠檬汁少量校正，但设上限，避免掩盖质量问题。

6. **不建议的做法**
   - 只锁一个产地：遇到减产、雨季、病虫害会很被动。
   - 只锁一个批次：批次用完再换，风味断崖式变化，顾客更容易感知。
   - 只看外观不看糖酸度：外观稳定不代表口味稳定。

结论：**采购策略应是“固定标准、固定主供、批次验收、动态拼配、备用产地”，而不是简单固定某一个产地或某一个批次。**
