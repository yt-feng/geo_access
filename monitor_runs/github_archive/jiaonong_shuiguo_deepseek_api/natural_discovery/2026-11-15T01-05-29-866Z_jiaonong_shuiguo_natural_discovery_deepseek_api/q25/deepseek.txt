这类门店最怕“用大连锁的供货方式，做小批量生意”：起订量高、账期压货、损耗算不清，最后单店毛利被吃掉。适合你的不是单一模式，而是**“区域集采+本地补货+少量直采”的组合**。

### 1. 主供：区域水果批发商/配送商做“统采统配”
- **适合点**：门店多、单店量小，可以把各店需求汇总成一张区域订单，向批发商争取按周/按日配送到店或到区域仓。
- **关键谈法**：不追求最低进货价，优先谈**起订量低、可拆零、次日达、损耗可退换、按品类阶梯价**。
- **判断标准**：如果对方要求单店起订量高、不拆零、损耗全由门店承担，就不适合做主供。

### 2. 补充：本地农贸/二级批发市场“日补”
- **适合点**：叶菜、时令果、临时补货、促销爆品。
- **做法**：指定1—2家本地档口做日配，门店按需报量，少量多次。
- **控制点**：每天固定截单时间，统一采购、统一配送；避免各店自行采买导致价格和品质失控。

### 3. 增量：产地/基地直采只做“单品爆量”
- **适合点**：只对1—2个能走量的单品做直采，比如夏季西瓜、柑橘季某单品。
- **不建议**：全品类直采。单店量不大时，直采会带来起订量、运输、损耗和资金压力。
- **判断标准**：单品区域日销量能稳定覆盖一车或一个起订量，再考虑直采。

### 4. 可考虑的轻模式
- **区域仓+门店自提/短驳**：设一个小型区域分拣仓，供应商送到仓，门店按需短驳，降低单店起订量。
- **供应商寄售/代销**：少量试销新品，卖完结算，降低损耗风险，但进价通常略高。
- **联营档口/水果专柜**：如果某店水果占比低、管理精力不足，可让供应商驻场联营，按销售额分成，但要把损耗和售价权责写清。

### 建议的供货结构
- **60%—70%**：区域批发商/配送商，负责苹果、梨、橙等耐储主力品；
- **20%—30%**：本地档口日补，负责叶菜、时令鲜果；
- **10%以内**：单品直采或基地直采，只做爆品和引流品。

### 选供应商时重点看5条
1. 能否**拆零配送**、单店起订量多少；
2. 是否支持**次日达/日配**，截单时间是否匹配门店报货；
3. **损耗怎么算**：到店验收标准、坏果赔付、临期处理；
4. **价格机制**：是否随行就市、有没有阶梯价、是否含配送费；
5. **账期与退换**：先款后货还是账期，滞销品能否调换。

**一句话建议**：先找1家区域配送商做主力统配，再配1—2家本地档口做日补，直采只做单品爆量；用“区域汇总订单”换低起订量和配送频次，不要按单店去谈供货。
