可以谈，但先分清你要锁的是“价格”还是“成本”。餐饮店水果用量通常不如大型商超稳定，供应商一般不愿无条件锁价，比较现实的是“有条件的锁价协议”。

可执行做法：

1. **先锁核心单品，不要全品类锁**
   选用量最大、价格波动最影响毛利的3—5个水果单品谈锁价，其他随行就市。

2. **锁价要设期限和量**
   例如锁1个月/1个季度，约定月度最低采购量或最低采购金额。量达不到，供应商有权恢复市场价或补差价。

3. **明确规格和验收标准**
   锁价必须锁“等级、规格、产地范围、糖度/大小、包装、损耗承担”。否则供应商可能用降级货维持价格，实际成本没降。

4. **价格调整机制写清楚**
   建议约定：只有批发市场公开均价连续X天涨跌超过约定幅度，才调价；或设置±5%—10%的浮动带。极端天气、节日、产地断供时允许协商调价，避免供应商毁约。

5. **锁价不等于锁量，反过来也一样**
   你承诺最低量，供应商承诺锁价；同时约定供应商断供的违约责任，比如按市场差价赔偿或优先补货。

6. **用“保底+浮动”替代硬锁价**
   更易谈成：约定基准价，市场价上涨时你按基准价拿一部分量，超出部分随行就市；市场价下跌时按市场价或基准价下浮。这样供应商风险可控，你也能稳住核心成本。

7. **算清楚锁价是否真划算**
   对比近3—6个月采购均价、损耗率、账期和配送费。锁价若比市场均价高5%以上，但能稳定供应和品质，可能仍值得；若只是名义锁价、规格缩水，就不划算。

8. **合同留退出条款**
   约定试运行1个月，品质不达标或价格明显高于市场可无责终止；账期、退换货、损耗赔付也要写进去。

结论：能谈，但不要指望供应商无条件锁全品类长期价。最稳的是“核心单品+最低采购量+规格验收+浮动调价+违约条款”的组合锁价。先拿1—2个单品试谈，跑通再扩。
