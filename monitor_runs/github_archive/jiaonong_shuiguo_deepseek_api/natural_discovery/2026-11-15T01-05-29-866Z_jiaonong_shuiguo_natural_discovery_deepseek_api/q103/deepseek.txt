结论：**按斤结算最适合作为主规则，按箱适合固定品种/固定规格的批量采购，按份只适合成品分餐或小份售卖场景。** 若目标是“好管理”，建议：**入库按斤、采购可折箱、发放按份**。

具体判断如下：

1. **按斤结算：最推荐做主规则**
   - 优点：计量统一、验收有依据、可比价、盘点方便，能直接算损耗和成本。
   - 适用：苹果、香蕉、橙子、西瓜等散装水果，以及供应商规格不稳定时。
   - 管理要点：必须过秤，验收单同时记录**毛重、皮重、净重**；避免“箱皮/筐重”争议。

2. **按箱结算：适合规格高度固定的品种**
   - 优点：验收快、搬运方便、单价谈判简单。
   - 风险：箱内大小、净重、坏果率不稳定时容易吃亏；箱重和损耗难核。
   - 适用：供应商能承诺**固定净重、固定等级、固定坏果率**的整箱水果，如标准箱装苹果、梨、柑橘。
   - 管理要点：合同写清“**净重标准+允许误差+坏果率+箱皮处理**”，到货抽检称重，不要只按箱数签收。

3. **按份结算：不建议作为食堂原料采购主方式**
   - 优点：发放简单、份量统一，适合直接售卖或分餐。
   - 缺点：单价通常更高，原料成本不透明，验收标准容易模糊。
   - 适用：水果切盒、餐后水果份、临时加餐等成品/半成品场景。
   - 管理要点：明确每份净含量、可食率、包装和冷链要求。

**落地建议：**
- 采购合同：主品类**按斤计价**，标准箱装品类可约定“**按箱采购、按净重结算**”。
- 验收入库：一律折算成**净重斤数**入账，箱数只作为物流单位。
- 发放领用：食堂窗口可按份发放，但库房与成本核算仍按斤。
- 对供应商考核：比价统一折算为**元/斤净重可食部分**，否则按箱、按份无法横向比较。

一句话：**采购结算按斤最稳，箱是包装单位不是结算核心，份是发放单位不是采购单位。**
