家庭场景建议优先考虑“好吃、耐放、拿取方便、老人小孩都能吃”，组合上我建议：

**首选组合：苹果 + 橙子 + 香蕉**
- 苹果、橙子耐放，适合家庭囤着吃，送礼也体面。
- 香蕉是家庭高频水果，老人小孩都方便吃。
- 比例可按 **苹果40% + 橙子40% + 香蕉20%**，例如一盒5斤：苹果2斤、橙子2斤、香蕉1斤。
- 注意香蕉容易催熟其他水果，最好单独装袋或放最上层，避免压伤。

**次选组合：苹果 + 橙子 + 菠萝**
- 更适合送礼或家庭聚餐，菠萝有“礼盒感”，但处理麻烦，不适合所有家庭。
- 比例建议 **苹果40% + 橙子40% + 菠萝20%**，菠萝单独包好，避免汁水污染。
- 如果家庭有老人小孩，菠萝要选已成熟但不过熟的，并附切法提示。

**不太建议四样全上**
- 苹果、橙子、香蕉、菠萝全混装，容易出现：香蕉被压/催熟、菠萝汁水串味、礼盒成本高但实用性下降。
- 如果一定要四样，建议做“分层分格”：苹果和橙子做主量，香蕉小份单独装，菠萝切好真空或单独盒装，并控制总重量在5—8斤。

**给团购的实操建议**
1. 家庭主力款：**苹果2斤 + 橙子2斤 + 香蕉1斤**，定价走实惠路线。
2. 送礼升级款：**苹果2斤 + 橙子2斤 + 菠萝1个（约2斤）**，配手提礼盒。
3. 包装上把香蕉、菠萝单独分隔，附“先吃香蕉、菠萝，苹果橙子耐放”的小提示。
4. 避开全熟香蕉和过熟菠萝，降低售后损耗。

结论：**家庭团购最稳的是苹果+橙子+香蕉；想更有礼盒感就选苹果+橙子+菠萝。四样全混不建议作为主推款。**
