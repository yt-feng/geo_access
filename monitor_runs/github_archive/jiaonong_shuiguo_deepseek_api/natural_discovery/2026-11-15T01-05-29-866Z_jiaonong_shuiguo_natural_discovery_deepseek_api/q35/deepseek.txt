连锁超市要把门店坏果率压下来，合同里不能只写“坏了赔”，而要把**验收标准、责任分界、赔付计算、扣款/补货机制、举证和追溯**写清楚。建议按下面结构约定：

## 1. 先定义“坏果”和“坏果率”
合同里明确：

- **坏果范围**：腐烂、霉变、软烂、渗液、异味、开裂、冻伤、虫害、机械伤导致不可售等，最好附图片标准或验收作业指导书。
- **坏果率计算口径**：  
  `坏果率 = 抽检不合格数量 ÷ 抽检总数量 × 100%`  
  或按金额：`不合格金额 ÷ 抽检货值 × 100%`。  
  要写清是“按批次抽检”还是“按门店收货批次全检/抽检”，抽检比例、抽样方法、谁来抽、何时抽。
- **分级**：轻微瑕疵、可折价销售、完全不可售，分别处理，避免全部按最高赔付。

## 2. 明确责任分界点
建议以**门店收货验收完成**为分界：

- 收货前：供应商承担坏果责任；
- 收货时发现：按验收结果当场扣重、拒收、折价或补货；
- 收货后：因门店储存、陈列、温控、翻堆不及时造成的坏果，供应商不承担；但合同可约定到货后**24/48小时内**发现隐蔽性腐烂仍可追溯，需保留批次、照片、温控记录。
- 运输环节：谁承运、谁投保、温控责任写清。

## 3. 赔付方式要可执行
不要只写“按实际损失赔偿”，建议组合约定：

1. **当场扣重/折价**：验收不合格部分直接扣减结算数量或按比例折价。
2. **补货**：供应商在约定时限内补足合格品，逾期按缺货金额一定比例违约金。
3. **现金赔付**：按不合格货值×倍数赔付，例如“坏果货值1倍退款+0.5倍违约金”，倍数要结合品类毛利和损耗设定。
4. **门店损耗补偿**：对已上架后短期内集中出现的批次性坏果，可按“该批次进货金额×约定比例”补偿，但需限定追溯时限和举证条件。
5. **质量保证金/账期扣款**：月度结算时统一扣减，避免每笔争议。
6. **上限与例外**：设置单批次赔付上限、月度累计上限，以及不可抗力、门店原因除外。

## 4. 设置坏果率考核和阶梯条款
例如按月统计：

- 坏果率≤2%：正常结算；
- 2%–5%：超出部分按货值赔付；
- 5%–10%：赔付+警告+限期整改；
- 连续两月>10%或单月>15%：超市有权暂停下单、终止合同、扣除质量保证金。

具体阈值要按品类定，叶菜、浆果、根茎类标准不同，不要一刀切。

## 5. 举证和流程写清楚
约定：

- 收货时双方共同验收并签字/系统确认；
- 异常批次保留照片、视频、抽样记录、温控记录；
- 供应商可在收到通知后**24小时内**复检或提出异议，逾期视为认可；
- 争议由双方共同委托第三方检测，费用由责任方承担；
- 所有扣款需附明细，月度对账确认。

## 6. 合同条款示例骨架
可写成：

> 乙方交付商品不符合约定质量标准，经甲方门店验收或甲方在到货后48小时内发现的隐蔽性质量问题，甲方有权选择拒收、折价、要求补货或按不合格货值【1】倍扣款；因乙方同一批次坏果率超过【5%】的，超出部分按【不合格货值×1.5】赔付；月度累计坏果率超过【8%】的，甲方有权暂停下单并要求乙方限期整改；连续【2】个月超过【10%】的，甲方有权解除合同并扣除质量保证金。因甲方储存、陈列、温控不当造成的坏果，乙方不承担责任。验收记录、照片及系统数据作为扣款依据。

## 关键提醒
- **别只约定“坏果包赔”**，否则执行时容易扯皮。
- **赔付倍数要与毛利匹配**：生鲜毛利有限，倍数过高供应商会涨价或拒签，过低没有约束力。
- **按品类设标准**：叶菜、水果、根茎、浆果的坏果率阈值和追溯时限不同。
- **系统留痕**：收货扫码、批次号、照片、温控记录要能关联到供应商和门店，否则条款难落地。

最终建议让采购、门店运营、法务一起定：先统计各品类近3个月实际坏果率，再设阈值和赔付倍数，合同附件附《生鲜验收标准及坏果判定图例》。
