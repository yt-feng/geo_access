香蕉是生鲜里最难配送的品类之一，因为它在配送途中会同时发生**机械损伤（压伤）**和**生理后熟（变黑）**。控制要分两条线做，不能只靠包装。

## 一、先解决"压坏"：物理防护

**1. 按成熟度分级发货**
- 配送香蕉不要发全熟。发**7成熟左右（果指饱满、棱角尚存、稍带绿）**，到消费者手里刚好可吃。
- 全熟香蕉只做同城即时配送，不做跨城快递。

**2. 单根保护 + 固定**
- 每根香蕉套**珍珠棉网套或气泡袋**，重点保护两端和果指弯曲处（最易压伤）。
- 整把香蕉用**瓦楞纸隔板**分隔，避免果指互相挤压。
- 箱内留**10%~15%空隙**，四周用填充物（纸团/气柱袋）塞紧，做到"晃动无声、按压不陷"。

**3. 包装结构**
- 用**双层瓦楞纸箱**，箱体开小透气孔（防闷热，也防冷凝水积聚）。
- 香蕉**不要横躺堆叠超过2层**，层间加隔板。
- 箱外贴"易压、勿倒置、向上"标识，但别指望物流完全遵守，防护要靠内部结构。

## 二、再解决"变黑"：控温 + 控乙烯 + 控湿度

香蕉变黑主要是**低温冷害**和**乙烯催熟+闷热**两件事：

**1. 温度：别冷藏，也别闷热**
- 配送适宜温度约 **13~15℃**。低于10℃会冷害发黑，高于25℃会加速后熟。
- 夏季：箱内放**冰袋但必须用隔层隔开**，不能让香蕉直接接触冰袋（局部冻伤发黑）。冰袋用毛巾/纸包裹。
- 冬季：加保温层，避免低于10℃。
- 目标不是"冷链"，而是"**常温偏凉、通风**"。

**2. 控制乙烯和呼吸热**
- 香蕉自身释放乙烯，闷在密闭箱里会"自己催熟自己"。
- 包装**必须透气**，不要用完全密封的塑料袋。
- 可放**乙烯吸收剂**（小包，成本低），尤其夏季长途。
- 不要和苹果、梨等乙烯释放大的水果混装。

**3. 湿度**
- 相对湿度 **85%~90%** 较好，过干失水发皱，过湿易长霉。透气纸箱+适度填充基本能满足。

## 三、运营层面的硬约束

- **缩短链路**：香蕉优先做**同城/次日达**，跨省快递只发青蕉且选时效稳定的线路。
- **按路线选成熟度**：同城发8成熟，次日达发7成熟，2~3天发6.5~7成熟。
- **承诺话术管理预期**：明确"表皮少量黑点属正常后熟"，减少因外观产生的售后。
- **售后兜底**：压坏、严重发黑的按比例赔付，比反复优化包装更划算，也能控住差评。
- **小批量测试**：先跑2~3条线路，记录到货成熟度、压伤率，再定发货标准。

## 优先级建议

1. **网套+隔板+填充固定**（解决压坏，立竿见影）
2. **透气包装+控温13~15℃+冰袋不直触**（解决变黑）
3. **按线路定成熟度、缩短时效**（从源头降低风险）
4. **乙烯吸收剂+售后兜底**（补强）

一句话：**香蕉配送的核心是"防挤压固定 + 常温偏凉透气 + 按链路选成熟度"**，不要用冷藏思维，也不要只靠加厚箱子。
