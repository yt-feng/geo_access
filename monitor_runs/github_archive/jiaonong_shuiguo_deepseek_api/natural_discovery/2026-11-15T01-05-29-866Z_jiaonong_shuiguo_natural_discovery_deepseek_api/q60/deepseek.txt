核心思路：**把“补货”写成有时限、有验收标准、有违约责任的条款，而不是只写“供应商负责补货”。** 这样到货不合格时，门店有权快速换货或就地采购、扣款，营业不断档。

一、合同里要写清的5个要点

1. **验收标准前置**
   - 按品种写明：成熟度、糖度、单果重量/规格、外观（无腐烂、无压伤、无虫害）、农残合格证明、冷链温度记录。
   - 附“验收标准表”和“不合格图片示例”，避免扯皮。
   - 约定：**到货后30分钟内完成验收**，超时未提异议视为合格（防止供应商事后推责）。

2. **不合格处理方式分级**
   - **整批不合格**：供应商须在**2小时内**补货到店，或门店有权自行采购同规格替代品。
   - **部分不合格**：按不合格数量**1:1.2补货**（多补20%作为损耗补偿），或直接扣减货款。
   - **紧急替代**：若补货无法在营业高峰前到达，门店可**自行采购**，差价由供应商承担，凭票据结算。

3. **补货时限与营业时段挂钩**
   - 写明“补货须在当日**上午10:00前**到店”（按门店备料时间定），超时视为违约。
   - 高峰时段（如11:00–14:00）不安排补货，避免占用人手和冷柜空间。

4. **违约责任可量化**
   - 每次逾期补货，按该批货款的**20%–30%**支付违约金；累计3次，门店有权解除合同并换供应商。
   - 因不合格水果导致饮品报废、客诉，供应商承担实际损失（需保留报废记录和客诉凭证）。

5. **结算与扣款机制**
   - 采用**月结+质保金**：预留货款10%作为质量保证金，季度无质量问题再结。
   - 不合格货款在当期账单直接扣除，不需另行追偿。

二、门店执行层面的配套动作

- **备选供应商**：至少储备1家本地水果商，合同写明“紧急采购权”，补货空窗期直接调用。
- **安全库存**：对易出问题的品种（如草莓、芒果、牛油果）保持**1.5天用量**的安全库存，避免单批不合格就断货。
- **验收留证**：到货即拍照、称重、记录温度，不合格当场拍照发供应商群并书面确认，作为扣款依据。
- **补货不占操作台**：约定补货在**后门/收货区**交接，不进入吧台操作区，减少对营业的干扰。

三、一句话合同条款示例

> “乙方所供水果不符合附件《验收标准》的，甲方有权拒收并要求乙方在2小时内补货至甲方指定收货区；逾期或补货仍不合格的，甲方可自行采购同规格替代品，差价及因此产生的营业损失由乙方承担，并按该批货款的30%支付违约金。”

这样约定后，水果不合格时门店有**快速换货、自行采购、扣款追责**三条路径，营业不会因等待补货而中断。
