# 旺季菠萝临时补货的供应商约定要点

旺季用量突增时，最好**在旺季前就谈好“弹性补货条款”**，而不是临时一家家去问。核心是把“不确定性”提前写进协议。

## 一、先明确自己的需求边界

补货前先算清三个数，谈判才有底气：

- **日耗峰值**：旺季最高单日菠萝用量（kg/个），按历史最高周的 1.2～1.3 倍预估
- **补货触发点**：库存低于几天用量时启动补货（建议 2～3 天安全库存）
- **可接受提前期**：从下单到到货最多几天（鲜果一般 1～3 天，视产地和冷链）

## 二、和供应商约定的关键条款

**1. 弹性供货量（核心）**
约定一个基准量 + 浮动上限，例如“周基础供货 X kg，旺季可上浮至 1.5X，上浮部分提前 48 小时通知”。避免口头“尽量满足”，要写清上限和通知时限。

**2. 临时补货的响应时限**
明确：下单方式（微信/电话/系统）、下单截止时间（如每日 14:00 前）、到货时限（如次日 10:00 前）。写清“超时未到”的处理。

**3. 价格机制**
临时补货最容易在价格上扯皮。提前约定：
- 旺季浮动价的上限（如不超过基准价 15%）
- 或按“当日报价 + 固定加价”结算
- 明确是否含运费、损耗如何算

**4. 品质标准不降级**
写清规格（品种、单果重量、成熟度、无腐烂）、验收标准和不合格退换规则。旺季供应商容易拿次果充数，验收条款要保留。

**5. 违约与备选**
约定供应商无法足量供货时的通知义务（如提前 24 小时告知），以及你方可启用第二供应商而不算违约。

## 三、实操建议

- **双供应商策略**：主供应商占 70%，备选 30%，旺季备选随时可激活，避免被单一供应商卡脖子。
- **书面确认**：即使是微信沟通，补货也要留存“数量、单价、到货时间”的书面记录。
- **分批到货**：鲜果不耐存，宁可每日小批量补，也别一次压太多货导致损耗。
- **预付或账期**：临时补货供应商常要求现结，提前谈好结算方式，避免到货时扯付款耽误时间。

## 四、一句话总结

**旺季前签“基准量 + 浮动上限 + 48 小时通知 + 价格封顶 + 品质验收”的补充协议，同时养一个备选供应商**，比旺季临时求人可靠得多。
