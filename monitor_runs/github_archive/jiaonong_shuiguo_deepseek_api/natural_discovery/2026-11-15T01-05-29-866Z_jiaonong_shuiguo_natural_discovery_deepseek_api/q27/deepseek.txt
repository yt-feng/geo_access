判断“大小规格是否适合门店销售”，核心不是只看单个果子多大，而是看**分级是否稳定、是否符合目标客群、陈列是否好看、损耗是否可控、价格是否匹配**。可以按下面几个可执行步骤判断。

## 1. 先定门店销售场景
不同门店对规格要求不同：

- **社区生鲜店/便利店**：中等个头、拿取方便、单价低，适合家庭日常购买。
- **精品超市**：大小均匀、外观好、礼盒或精品装，规格可以偏大但必须整齐。
- **水果专营店**：分级要清楚，大中小果分价销售，避免混装。
- **餐饮/团购渠道**：更看重单果重量稳定、出成率、耐储运。

先明确主要卖给谁，再定“合适规格”，不要单纯追求大果。

## 2. 苹果怎么判断
重点看：

- **单果重量/横径是否稳定**：同一批内大小差异不能太明显。门店零售通常喜欢同一陈列层内规格接近。
- **果形是否端正**：偏圆、无明显畸形，陈列时更整齐。
- **果面是否干净、无磕碰**：门店销售对外观敏感，磕碰果适合做特价或加工，不宜混入正价陈列。
- **果梗是否完整、果皮是否紧实**：判断新鲜度和耐放性。
- **大小与包装是否匹配**：如果做袋装、盒装，要测试一袋/一盒装几个、总价是否好卖。
- **顾客拿取是否方便**：过大不一定好卖，尤其是日常家庭购买；过小则容易被认为“规格低”。

**可执行判断**：随机抽 20～30 个，称重并量横径，看最大最小差异；再按门店计划售价试算单果成本和毛利。若同一批大小差异大，应要求供应商分級或自己分档销售。

## 3. 橙子怎么判断
重点看：

- **果实大小是否均匀**：橙子混装最影响陈列和顾客挑选。
- **果皮是否细腻、无明显病斑和机械伤**：表皮粗糙、伤多会降低正价销售比例。
- **手感是否紧实、有重量感**：同样大小偏轻可能汁水不足或存放偏久。
- **果蒂新鲜度**：果蒂干枯、发黑通常影响新鲜感。
- **是否适合目标包装**：散卖、网袋、礼盒对大小要求不同；网袋装要特别测试大小一致性和总重。
- **皮厚和出汁情况**：如果是鲜食零售，皮过厚、干水会影响复购。

**可执行判断**：抽样切开或试吃，结合称重看大小档位；把明显偏小、偏大、花皮、伤果挑出，计算正价果比例。正价果比例过低，即使采购价便宜也可能不适合门店。

## 4. 用“三个比例”做快速判断
采购前建议现场估算：

1. **正价销售比例**：外观、大小、新鲜度达标、能按正常价卖的比例。比例太低不适合做主推。
2. **损耗/降级比例**：磕碰、畸形、过小过大、花皮等需要特价或处理的占比。
3. **规格集中度**：大部分果子是否落在 1～2 个规格档内。过于分散会增加分拣和陈列成本。

## 5. 陈列和价格测试
小批量试销最可靠：

- 按大、中、小分档陈列，观察顾客拿取和询问。
- 比较同价位下顾客更偏好哪个规格。
- 看一天内翻挑后的残次率、顾客是否反复挑剩下的大果或小果。
- 计算“到店成本 + 分拣损耗 + 陈列损耗”后的真实毛利，而不是只看采购单价。

## 6. 采购时的判断清单
可以现场直接问/查：

- 这批货是否已分级？分级标准是什么？
- 同批最大最小差异有多大？
- 正价果比例大概多少？
- 有无磕碰、日灼、病斑、干水、皮厚问题？
- 适合散卖、袋装还是盒装？一袋/盒装几个、总价多少？
- 预计几天卖完？门店冷藏和陈列条件是否匹配？
- 如果卖不动，能否退换或转特价/加工？

**结论**：适合门店销售的规格，应是“目标客群愿意买、大小相对整齐、正价果比例高、损耗可控、陈列方便、价格有毛利”的规格。不要只凭单果大小下结论，最好先抽样分级并小批量试销。
