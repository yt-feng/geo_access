# 判断香蕉批次熟度与坏果风险

## 一、先看外观（最关键）

**熟度判断：**
- **青绿硬实**：生蕉，适合长途运输或囤货，需催熟后卖
- **黄绿相间（转色期）**：七八成熟，2~4天可售，适合批发走量
- **通体金黄、棱角圆润**：适熟，1~2天内要出货
- **出现糖斑（芝麻点）**：完熟，当天到次日必须卖，零售最佳但批发风险高
- **大面积褐斑、发黑**：过熟，损耗大

**看棱角**：香蕉横截面越接近圆形越熟；有明显棱角说明还生。

## 二、查坏果风险（重点看这几个部位）

1. **果柄（把头）**：发黑、发霉、渗液→整把感染风险高，常是冠腐病
2. **蕉指中段**：软塌、凹陷、水浸状斑→内部已烂
3. **果尖**：发黑干枯正常；发软渗水则是坏果
4. **轴心/蕉梳连接处**：有霉点说明装箱时已受潮，整箱易串坏
5. **表皮擦伤**：运输磕碰处会先黑先烂，看箱内摩擦面

## 三、动手验（别只看表面）

- **捏**：轻捏蕉指中段，整体均匀微软=适熟；局部软陷=坏果；硬如石头=生
- **掂**：同规格偏轻的失水，偏重发沉的可能内部水烂
- **翻箱**：**一定翻到底层和中间层**，表层好不代表整箱好，底层压伤、闷热最易坏
- **闻**：有酒味/酸味=已发酵过熟；霉味=真菌感染

## 四、看批次信息

- **产地采收期**：采收越久、运输链越长，风险越高
- **冷链是否断过**：香蕉怕冷（低于12℃冻伤发黑），也怕闷热；问清运输温度
- **箱内湿度**：纸箱受潮、有水汽→霉变高风险
- **同批抽检比例**：至少抽3~5箱，重点抽底层、靠边、靠门位置的箱

## 五、快速决策参考

| 状态 | 熟度 | 可售窗口 | 风险 |
|---|---|---|---|
| 青硬 | 生 | 需催熟，5~7天 | 低（但要防冻伤） |
| 黄绿 | 7~8成 | 2~4天 | 低 |
| 金黄 | 适熟 | 1~2天 | 中 |
| 糖斑 | 完熟 | 当天 | 高 |
| 褐斑/软塌/霉柄 | 过熟或坏 | 不建议接 | 很高 |

**实操建议**：接货时按"抽箱—翻底层—捏中段—看果柄—闻气味"五步走；对转色不均、果柄发黑的批次压价或拒收；青蕉可接但必须确认没冻伤（冻伤蕉皮发暗、催不熟）。
