结论：**如果只能选一个作为线上主推，优先“冷冻菠萝原料/冷冻果块”做差异化走量；若你的线上渠道以家庭即时消费为主，则“切配鲜果”更适合做爆品；整果适合做低价引流和产地故事，但不建议作为唯一主推。**

**分渠道判断：**

1. **整果**
   - 适合：产地直发、低价引流、直播/内容电商、家庭囤货、自有仓储和成熟菠萝催熟/品控能力。
   - 优点：损耗相对可控、客单价低、易讲产地故事、运输标准化程度较高。
   - 风险：线上消费者对“熟度不可控、切开酸、黑心、售后扯皮”敏感；整果毛利低，物流和售后容易吃掉利润。
   - 建议：只做引流款或产地直发款，明确品种、成熟度、净重、坏果赔付规则。

2. **切配鲜果**
   - 适合：美团买菜/叮咚/盒马等即时零售、社区团购、家庭小份装、办公室下午茶。
   - 优点：即食便利、客单价和毛利空间更好、复购场景强、适合小份装和组合装。
   - 风险：保鲜期短、冷链要求高、切配后微生物和出水问题、售后时效要求高。没有冷链和日配能力不要轻易做。
   - 建议：做200—500g小份装，主打“当日切配/冷链直达”，设置明确配送半径和签收后售后时限。

3. **冷冻原料/冷冻果块**
   - 适合：线上全国发货、餐饮/烘焙/茶饮B端、家庭冷冻囤货、破壁/烘焙/果茶场景。
   - 优点：保质期长、跨区域履约稳定、损耗低、适合组合装和复购；可做“无添加冷冻果块”“果茶原料”等差异化。
   - 风险：需要冷冻仓储和冷链快递，解冻后口感不如鲜切；家庭用户对“冷冻=不新鲜”的认知需要教育。
   - 建议：优先做B端小包装或家庭烘焙/果茶场景，标注解冻方式和适用场景，不要跟鲜切拼“鲜”。

**可执行组合：**
- **全国发货为主**：冷冻果块做主推，整果做低价引流，切配只在有同城冷链时做。
- **同城即时零售为主**：切配鲜果做主推，整果做补充，冷冻做长尾。
- **B端/茶饮烘焙客户**：冷冻原料优先级最高。
- **初创、冷链能力弱**：先做整果产地直发，验证品控和售后，再上冷冻，最后考虑切配。

一句话：**没有冷链能力就不要主推切配；想做全国线上稳定履约，冷冻原料最稳；想做家庭即时消费爆品，切配鲜果最合适。**
