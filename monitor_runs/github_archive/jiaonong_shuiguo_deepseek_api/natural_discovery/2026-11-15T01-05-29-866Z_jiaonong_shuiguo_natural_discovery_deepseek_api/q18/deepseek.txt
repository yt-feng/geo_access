买香蕉想避开“太生/太熟”，关键是**在到店前先想好什么时候吃**，到店后用“看颜色+摸手感+看果柄和棱角”快速判断。

可以直接按这个标准挑：

1. **今天或明天就吃：选黄底、少量褐斑**
   - 通体黄色、两头略黄，果身有 1～3 个小褐斑最好。
   - 不要选大面积黑斑、果柄发黑发软的，可能里面已过熟。
   - 表皮有轻微“梅花点”通常更甜，但只适合马上吃。

2. **2～3 天后吃：选黄中带绿**
   - 果身大部分偏黄、两端或棱角处还带一点绿。
   - 摸起来略有弹性但不软塌。
   - 这种回家常温放 1～3 天刚好。

3. **3～5 天后吃：选绿多黄少**
   - 果身以绿色为主、棱角明显，但**不要硬得像石头**。
   - 果柄切口新鲜、不发黑不霉。
   - 买回后常温放，别马上冷藏。

4. **现场快速判断**
   - **看棱角**：棱角很尖、果身硬＝偏生；棱角不明显、果身圆润＝偏熟。
   - **摸手感**：轻按有弹性＝适中；按下去软陷＝过熟；完全按不动＝偏生。
   - **看果柄**：青绿或浅黄、干燥无霉点较新鲜；发黑、发软、渗液不要。
   - **看表皮**：少量褐斑可接受；大面积黑斑、破皮、裂口、霉点不要。
   - **闻一下**：有淡淡果香即可；明显酒味/酸味说明过熟。

5. **采购策略**
   - 一次买两串：一串“黄中带绿”今明两天吃，一串“绿多黄少”后面吃。
   - 如果超市香蕉已经全部很黄，优先选**果柄还硬、果身没软塌**的。
   - 夏天熟得快，偏生一点更稳；冬天可适当选黄一些。
   - 买回家后：未熟别冷藏，常温催熟；熟透再冷藏，但表皮会变黑，不影响果肉。

一句话：**想马上吃选黄带少量褐斑，想放几天选黄中带绿，别选棱角尖硬或果柄发黑软塌的。**
