水果礼盒想好卖，核心不是“水果越多越好”，而是**组合有主题、看着满、成本可控、送礼有面子**。苹果、橙子、香蕉、菠萝这四样里，**香蕉和菠萝不适合做主视觉/长途礼盒**：香蕉易压伤、熟得快；菠萝带冠芽重、占空间、处理麻烦。建议用 **苹果+橙子做主体，香蕉/菠萝做局部点缀或做“现场自提款”**。

给你几套直接能卖的搭配：

### 1. 主推款：平安橙意礼盒（最好卖）
- **内容**：苹果6个 + 橙子6个 + 香蕉2根 + 小菠萝1个（或菠萝切盒1份）
- **定位**：58～88元档，日常送人、探病、员工福利
- **卖点**：苹果寓意平安，橙子寓意心想事成；香蕉和菠萝增加丰富度
- **包装**：红色/橙色手提礼盒，苹果橙子摆外圈，香蕉放上层，菠萝放侧边或单独切盒
- **注意**：如果要做隔天配送，香蕉换成2个橙子，菠萝换成苹果，稳定性更高

### 2. 高端款：四喜临门礼盒
- **内容**：精品苹果4个 + 橙子4个 + 香蕉1把（4～5根） + 菠萝1个
- **定位**：98～128元档，节日送礼
- **卖点**：四样水果凑“四喜”，适合春节、开业、乔迁
- **包装**：大号硬盒+拉菲草+贺卡；菠萝放底层，苹果橙子在上层，香蕉最后放
- **适合**：现场自提、同城短途配送；不适合快递

### 3. 走量款：小份尝鲜盒
- **内容**：苹果2个 + 橙子2个 + 香蕉1根 + 菠萝切块1盒
- **定位**：29～39元，办公室下午茶、单人送礼
- **卖点**：便宜、好看、不浪费
- **注意**：菠萝切盒要密封冷藏，2小时内卖完或配送

### 4. 不建议主推的组合
- **香蕉+菠萝占一半以上**：损耗高、卖相不稳
- **整箱混装快递**：香蕉易黑、菠萝易压坏，售后多
- **四种水果数量完全一样**：成本高，而且香蕉菠萝显廉价，反而拉低礼盒档次

### 定价和陈列建议
- **成本占比控制在售价的45%～55%**，包装占8%～12%，毛利留30%以上
- 礼盒里**苹果和橙子占体积60%以上**，颜色亮、耐放、撑场面
- 香蕉选**偏青一点**的，配送前再放熟；菠萝选小果，或者直接卖“菠萝切盒+礼盒”
- 主推2款就够：**58～68元平安橙意款** + **98～108元四喜款**，别让顾客选择困难

### 最好卖的一句话文案
- “平安橙意礼盒，送长辈送同事都体面，68元拎走。”
- “四喜临门礼盒，苹果橙子香蕉菠萝全配齐，开业乔迁首选。”

**结论**：优先做 **苹果+橙子为主体，香蕉少量点缀，菠萝做小果或切盒** 的“平安橙意礼盒”，定价58～88元，现场自提和同城短送为主；再配一个98元左右的四喜款做节日高端。这样最好卖、损耗也低。
