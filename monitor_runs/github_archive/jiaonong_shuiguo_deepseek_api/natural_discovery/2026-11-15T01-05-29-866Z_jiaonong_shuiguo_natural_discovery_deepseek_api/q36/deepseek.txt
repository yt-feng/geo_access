直接结论：**多数商超应以“整果为主、鲜切为辅”，不要二选一。** 整果承担引流和毛利，鲜切承担便利性和损耗转化，关键看门店客流结构和菠萝周转速度。

**建议这样配比和判断：**

1. **整果为主的情况**
   - 社区店、家庭客群多、客单价偏低：整果更有价格优势，顾客愿意买回家自己削。
   - 菠萝到货新鲜、周转快：整果损耗可控，毛利空间通常更好。
   - 门店人手紧、鲜切操作间或冷链条件一般：优先整果，避免鲜切交叉污染和氧化损耗。

2. **鲜切更适合的情况**
   - 商圈店、写字楼店、年轻客群、即时消费多：鲜切即买即吃，转化率更高。
   - 整果出现外观瑕疵但果肉完好：可转鲜切，减少报损。
   - 门店有冷藏展示柜、切配人员和标准化操作：鲜切能拉高客单价和连带销售。

3. **实操配比建议**
   - 先按销量试：整果占菠萝品类 **60%—70%**，鲜切占 **30%—40%**，每周看数据调整。
   - 鲜切不要一次性切太多，按半天销量分批切，冷藏陈列，当天清完。
   - 整果做促销价引流，鲜切做便利装、小份装，避免互相压价。
   - 鲜切必须明确标注切配时间、保质期和冷藏条件，操作间卫生要过关。

4. **看三个指标决定增减**
   - **整果日周转率**：当天卖不完比例高，就减少整果订货或转鲜切。
   - **鲜切报损率**：鲜切损耗超过鲜切销售额的10%—15%，就收缩鲜切量。
   - **客群结构**：家庭客多偏整果，单人/即时消费多偏鲜切。

**一句话：社区家庭店整果优先，商圈便利店鲜切加量；先小批量测试，用周转率和报损率说话。**
