判断“催熟能力是否稳定”，核心不是看单批香蕉黄不黄，而是看**同一来源、同一处理条件下，多批次到货后的转黄一致性、病害和货架期波动**。商超采购可按下述可执行方法判断。

## 1. 先区分“供应商催熟稳定”与“商超自己催熟稳定”
- 若采购的是**已催熟香蕉**：看供应商到货批次的一致性。
- 若采购的是**青蕉后自行催熟**：看青蕉成熟度、催熟房控制和到货后表现。
建议在合同或询价时明确：催熟由谁做、到货应是几成熟、允许的色差范围。

## 2. 建立批次验收记录，用数据判断
每批到货记录：
- 产地/果园或供应商批次号
- 到货日期、运输温度、途中时长
- 青蕉硬度和颜色（可用香蕉色卡1–7级）
- 果指粗细、饱满度、机械伤
- 催熟方式（乙烯浓度/温度/湿度/时长，若自催）
- 催熟后第2、4、6天的转黄等级、青条比例、软硬、黑斑、掉把、异味

**稳定性判断标准建议：**
- 连续3–5批，同一供应商同一规格，催熟后到达目标色级的时间波动不超过约半天到1天；
- 同箱内青黄不齐比例低，比如目标色级时“青条/僵果”比例稳定在可接受范围内；
- 不同批次货架期差异小，不出现某批2天就过熟、另一批5天还不黄。

## 3. 看青蕉基础质量，这是催熟稳定的前提
采购青蕉时重点看：
- **饱满度**：棱角明显但不过瘦，七成半到八成饱满更利于均匀转黄；过瘦易催不熟或果肉差。
- **颜色均匀**：整批青绿一致，避免混入已微黄、水伤、冻伤果。
- **果指均匀**：粗细长短差异小，否则催熟后成熟不同步。
- **无严重机械伤和病害**：轴腐、冠腐、炭疽潜伏、擦伤会在催熟后集中爆发。
- **切口和果轴新鲜**：果轴发黑、霉变说明采后处理或冷链有问题，催熟稳定性差。

## 4. 用小样试催，而不是只看供应商口头承诺
对新供应商或新批次，先做**小批量试催**：
- 取同批次3–5箱，按计划温湿度/乙烯条件催熟；
- 每天固定时间观察颜色、硬度、青条比例、黑斑；
- 记录达到可售色级的时间和第3–5天损耗；
- 连续做2–3个批次再放量采购。

若试催中出现：同箱成熟差2个色级以上、催熟后大量青硬果、催熟后迅速发软出水、黑斑集中出现，说明稳定性不足。

## 5. 现场快速判断供应商是否靠谱
- 问清**催熟房温度、湿度、乙烯浓度、循环风、催熟时长**是否有记录；没有记录的基本难稳定。
- 看其**分批次管理**：不同产地、不同成熟度是否分开催熟，混催是波动大源。
- 看**到货冷链**：香蕉低于约13℃易冷害，催熟后表现会很差；运输温度记录比口头保证更有用。
- 看**同一天不同批次**的颜色和硬度是否一致，而不是只看样品箱。

## 6. 采购合同里加可执行条款
建议约定：
- 到货成熟度范围（如色卡2–3级）；
- 催熟后目标色级达成时间；
- 青条率、僵果率、黑斑/腐烂率上限；
- 连续批次不稳定的退货、换货或降级处理；
- 要求供应商提供批次号和催熟记录。

**结论：** 判断催熟能力是否稳定，最可靠的方法是“**固定规格+连续批次小样试催+量化记录转黄时间和青条/损耗波动**”。单批好看不代表稳定；连续3–5批转黄时间、色差、货架期波动小，才算稳定。
