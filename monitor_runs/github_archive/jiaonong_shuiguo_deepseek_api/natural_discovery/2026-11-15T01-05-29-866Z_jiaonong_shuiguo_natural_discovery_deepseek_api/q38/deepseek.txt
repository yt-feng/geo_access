大型超市（如沃尔玛、永辉、盒马这类）对水果供应商的准入要求通常分为**食品安全合规能力**和**物流交付能力**两大块。以下是可判断、可执行的清单。

## 一、食品安全能力（硬门槛）

**1. 资质证照**
- 营业执照、食品经营许可证（或食品生产许可证，视加工环节）
- 种植/养殖环节：产地证明、农业投入品使用记录
- 进口水果：海关报关单、入境货物检验检疫证明
- 有机/绿色/地理标志等认证（如供应对应品类）

**2. 检测能力与报告**
- 每批次或定期提供农残检测报告（符合GB 2763农残限量标准）
- 重金属、真菌毒素（如展青霉素）检测
- 具备自检实验室，或与第三方检测机构（CMA/CNAS资质）建立固定合作
- 能配合超市做飞行检查、抽检

**3. 追溯体系**
- 从产地→分选→仓储→配送的批次可追溯
- 有完整的进货查验、销售记录（符合《食品安全法》要求）
- 能提供批次号、采收日期、产地地块信息

**4. 质量分级与品控**
- 有明确的分级标准（大小、糖度、外观、成熟度）
- 采后处理能力：预冷、清洗、打蜡（如允许）、分级包装
- 损耗率控制记录和客户投诉处理机制

**5. 体系认证（加分/部分超市强制）**
- HACCP、ISO 22000、GAP（良好农业规范）
- 部分高端渠道要求有机认证或GlobalG.A.P.

## 二、物流能力（交付保障）

**1. 冷链能力**
- 预冷设施（差压预冷/真空预冷），采收后快速降温
- 冷藏车/保温车，全程温控记录（可导出温度曲线）
- 冷库分区管理，不同品类（如香蕉、浆果、柑橘）分温区存放

**2. 仓储与分选**
- 具备分选包装车间，符合卫生规范
- 仓储有防虫防鼠、温湿度监控
- 先进先出（FIFO）库存管理

**3. 配送时效与覆盖**
- 能按超市要求的时间窗配送（如夜间到店、DC预约制）
- 覆盖超市配送中心（DC）或门店的线路能力
- 高峰期（节假日）运力保障方案

**4. 信息化与协同**
- 订单、库存、物流信息可对接（EDI/API或至少Excel模板）
- 能提供在途温度、到货时间等数据
- 异常处理机制（断货、延迟、质量异议的响应时限）

**5. 包装与损耗控制**
- 符合超市要求的包装规格和标识（品名、产地、批次、日期）
- 运输防护（防挤压、防冻、防潮）
- 可承诺到货合格率和损耗上限

## 三、实操建议

- **先拿超市的供应商准入清单**：不同系统要求差异大（永辉偏重检测报告，盒马偏重冷链和追溯），按清单逐项准备。
- **优先补齐三样硬材料**：营业执照+食品经营许可、近3个月第三方农残检测报告、冷链温度记录能力证明。
- **做一次模拟审核**：按HACCP思路自查产地、分选、仓储、运输四个环节的记录是否闭环。
- **物流上先证明“温控可查”**：超市最常卡的是“有没有冷藏车”和“能不能导出温度记录”，这两点能提供就过了一大半。

一句话判断标准：**资质齐全、批批可检、批次可追、全程可冷、按时可到**——这五点齐了，基本满足大型超市水果供应商的准入底线。
