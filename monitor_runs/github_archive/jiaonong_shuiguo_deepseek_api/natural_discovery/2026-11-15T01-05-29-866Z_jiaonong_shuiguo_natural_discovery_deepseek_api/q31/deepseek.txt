连锁商超招长期水果供应商，评分标准建议按“资格门槛+量化评分”两层设计，核心是把“能不能长期稳定供、品质波动小、损耗可控、价格机制合理”变成可打分项。下面给一套可直接落地的框架。

## 一、先设资格门槛（不计分，不满足直接淘汰）

1. 具备合法经营资质：营业执照、食品经营/生产相关许可、种植基地或合作社证明、产地证明。
2. 供货能力：近2年有商超/连锁渠道供货案例，能提供合同或结算凭证；具备日均/峰值供货能力和应急补货能力。
3. 质量与检测：有农残检测能力或第三方检测报告，能执行批次检测；可接受商超抽检和飞行检查。
4. 冷链与仓储：有预冷、冷藏、分拣、包装能力，能覆盖目标门店配送半径。
5. 合规与风险：无重大食品安全处罚、无严重失信记录；有食品安全责任险更佳。

## 二、评分维度与权重建议（总分100分）

| 维度 | 建议权重 | 主要评分点 |
|---|---:|---|
| 产品质量与稳定性 | 25分 | 样品感官、糖度/规格合格率、农残检测、批次一致性、产地稳定性 |
| 供货保障与履约能力 | 20分 | 产能、峰值供货、缺货应急、配送时效、冷链覆盖、历史履约 |
| 价格与成本机制 | 20分 | 报价合理性、价格调整公式、账期接受度、包装/损耗责任、长期降本能力 |
| 食品安全与溯源 | 15分 | 检测频次、溯源体系、召回机制、保险、飞行检查配合 |
| 服务与响应 | 10分 | 对接团队、售后处理时效、退换货、门店投诉响应 |
| 可持续与ESG | 5分 | 基地管理、农药使用规范、环保包装、社会责任 |
| 商务与合作意愿 | 5分 | 合同接受度、独家/优先供货、促销支持、新品开发配合 |

权重可按品类调整：叶菜类提高“冷链+损耗+应急”权重；进口/高端水果提高“溯源+品质一致性”权重；大宗基础果提高“价格机制+产能”权重。

## 三、关键评分项要“可验证、可量化”

1. 质量稳定性（建议15分）
   - 连续3—5批次样品检测合格率：≥98%得满分，95%—98%按档递减，低于95%淘汰或低分。
   - 规格合格率、糖度达标率、坏果率：设定明确阈值，如坏果率≤3%。
   - 产地/品种稳定性：是否有固定基地、是否频繁换产地。

2. 供货保障（建议12分）
   - 日均供货能力与峰值能力：按商超预估量的1.2—1.5倍设置。
   - 缺货应急方案：是否有备用基地、跨区域调货、24小时补货承诺。
   - 配送时效：门店到货准时率承诺≥98%，冷链断链次数为0。

3. 价格机制（建议12分）
   - 不要只比“最低报价”，要评“价格形成机制”：随行就市+封顶价/保护价、月度调价公式、异常天气调价规则。
   - 账期与结算：接受商超账期、对账透明度。
   - 损耗责任：运输损耗、门店验收损耗由谁承担，是否有明确比例。

4. 食品安全与溯源（建议15分）
   - 批次检测报告、第三方检测频次。
   - 溯源到基地/地块/批次，能否48小时内完成召回。
   - 是否购买食品安全责任险。
   - 是否接受不提前通知的飞行检查。

5. 历史履约（建议8分，可并入供货保障）
   - 近2年商超供货合同数量、履约评价、是否有断供/质量事故记录。
   - 可要求提供客户证明或允许商超做背景访谈。

## 四、评分规则设计要点

1. 客观分优先：检测数据、供货量、准时率、合同案例等尽量用客观材料打分，减少评委主观空间。
2. 设置“一票否决”：食品安全事故、虚假材料、农残超标、转包/贴牌冒充基地直供，直接废标。
3. 样品与现场考察结合：先盲样评分，再对高分供应商做基地/仓库/冷链现场核查，现场不符可扣分或取消资格。
4. 价格分不要唯低价：可采用“基准价+合理区间”，低于成本价需说明，防止低价中标后断供或降质。
5. 长期合同设考核联动：中标不是终点，合同里设季度/年度KPI（到货准时率、坏果率、投诉率、缺货次数），与续约、份额调整、扣款挂钩。

## 五、一个简化的评分表示例

- 质量与稳定性 25分：样品感官5分、批次合格率8分、规格/糖度达标7分、产地稳定性5分。
- 供货与履约 20分：产能6分、应急补货5分、冷链配送5分、历史履约4分。
- 价格与成本 20分：报价合理性8分、调价机制5分、账期与损耗责任4分、降本方案3分。
- 食品安全与溯源 15分：检测能力5分、溯源体系4分、召回与保险3分、检查配合3分。
- 服务响应 10分：团队配置3分、售后时效4分、退换货3分。
- ESG与商务 10分：基地规范3分、环保包装2分、合同配合3分、促销/新品支持2分。

## 六、招标文件里建议写清的硬条款

1. 质量标准：按品类写明规格、糖度、坏果率、农残标准、验收方法。
2. 供货承诺：日均量、峰值量、补货时限、缺货违约金。
3. 价格机制：调价周期、调价依据、封顶/保护价、异常天气条款。
4. 损耗与退换：运输损耗、验收损耗、门店退换货责任。
5. 考核与退出：季度考核指标、连续不达标降份额或终止合同。
6. 溯源与召回：批次追溯、召回时限、事故赔偿责任。

总体原则：**门槛看“能不能长期供”，评分看“供得稳不稳、品质稳不稳、价格机制合不合理、出事能不能兜住”**。不要只比价格，长期水果供应的最大风险是品质波动和断供，评分权重要向质量稳定性、供货保障和食品安全倾斜。
