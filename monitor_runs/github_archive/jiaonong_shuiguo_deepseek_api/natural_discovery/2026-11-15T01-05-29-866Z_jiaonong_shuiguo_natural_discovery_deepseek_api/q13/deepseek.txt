做小区团购，水果供应商至少要能支持下面这些服务。你可以拿这张清单直接问供应商，能明确回答“能/不能、怎么收费、多长时间”的再合作。

1. **稳定供货与分级**
   - 每天可报次日可售品类、数量、规格、产地。
   - 支持按团购做分级：如家庭装、尝鲜装、整箱装。
   - 能承诺缺货替代方案：同价替换、减量退款或整单取消。

2. **小批量、多频次配送**
   - 支持你按团购单量小批量补货，不必一次压大货。
   - 明确配送频次：每日一配、隔日配，还是满额配送。
   - 明确到店时间、卸货责任、迟到和漏送怎么赔。

3. **按团购单分拣打包**
   - 能按小区/团长/订单分袋、贴标签、装筐。
   - 支持统一规格，避免“图片大、实物小”。
   - 可代贴团购标签、放宣传卡，需提前确认是否收费。

4. **售后与损耗兜底**
   - 坏果、烂果、少重、规格不符的赔付标准要写清。
   - 支持拍照报损，明确响应时限和补货/退款方式。
   - 生鲜损耗比例、运输破损责任归属要提前约定。

5. **价格与账期支持**
   - 团购价、整箱价、临期促销价要能提前锁价。
   - 支持日结、周结或押金合作，避免你垫资压力过大。
   - 价格波动时提前通知，不能当天临时大幅涨价。

6. **退换货和临期处理**
   - 未售完或品质下降的水果能否退换、折价处理。
   - 临期果能否支持做特价团，不混入正价团。
   - 退货的运费、损耗由谁承担要明确。

7. **样品和试吃支持**
   - 新品类能否提供小份样品、试吃装。
   - 样品是否收费、后续下单能否抵扣。
   - 能否提供简单卖点资料：产地、甜度、保存方式、适合人群。

8. **包装与物料**
   - 提供周转筐、保鲜袋、纸箱还是你自备。
   - 包装是否计入成本，回收规则是什么。
   - 能否配合做小区团购的统一视觉和规格说明。

9. **结算与对账**
   - 每单有明细：品类、重量、单价、数量、损耗、赔付。
   - 支持微信/表格对账，能开收据或发票。
   - 退款、补货、抵扣怎么入账要清楚。

10. **应急能力**
   - 爆单时能否临时加量，提前多久通知。
   - 天气、节假日前能否保供。
   - 出现食品安全或集中投诉时，能否第一时间换货并承担相应责任。

**最建议你优先确认的5件事：**
- 能不能小批量每日配；
- 能不能按订单分拣贴标；
- 坏果怎么赔、多久赔；
- 价格能不能提前锁；
- 爆单和缺货时怎么兜底。

合作前最好让对方给一份**报价单+配送时效+赔付标准**，先小范围试团1—2个小区，跑通再放量。
