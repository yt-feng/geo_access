三个都重要，但优先级不是并列：**先看保质期（决定能不能卖），再看包装（决定坏得快不快/合规不），最后看配送频次（决定周转和损耗）**。菠萝切块属于鲜切水果，核心风险是微生物增殖和汁液流失变质。

### 1. 保质期：第一优先
- **必须定“短保”**：鲜切菠萝建议冷藏销售，保质期通常按内部验证定（很多便利店会设 **当日/次日** 售完，具体应做菌落/感官验证，不要凭感觉标太长）。
- **建立时间标签**：切配时间、废弃时间要能追溯；到点下架，不能只靠“看着没坏”。
- **到店后剩余保质期要卡住**：比如门店只接受剩余保质期≥2/3的产品，否则拒收。

### 2. 包装：第二优先，直接影响保质期
- 要**密封、防汁液渗漏、冷藏适配**；推荐带盖托盘/密封盒+保鲜膜或气调包装，避免裸露。
- 包装要能**标注切配日期/保质期/贮存条件**，并防止交叉污染。
- 重点不是“好看”，而是**密封性+冷藏稳定性+不积水**。汁液积在底部会加速变质。

### 3. 配送频次：第三优先，但决定门店运营
- 鲜切菠萝适合**高频短途配送**：每天配送或隔日配送，单店少量多次，减少门店库存天数。
- 配送频次要和**销量匹配**：日销量低的店不要压货，否则报废率高。
- 配送过程必须**冷链**，到店立即入冷藏柜，不能常温中转。

### 可执行判断标准
1. **保质期是否短且可追溯**：没有切配时间/废弃时间，直接不合格。
2. **包装是否密封、冷藏稳定、标签齐全**：漏汁、鼓包、冷凝水严重都不合格。
3. **配送是否冷链且频次匹配销量**：到店剩余保质期不足、常温配送，不合格。

一句话：**保质期是底线，包装是保障，配送频次是周转手段；三者中先卡保质期和冷链，再优化包装和高频配送。**
