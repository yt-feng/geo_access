常见做法是把“坏果率”写成**可量化的验收标准 + 阶梯赔付**，而不是只设一个固定比例。一般建议：

1. **到货验收坏果率 ≤ 3%**：可视为正常损耗，不赔付。
2. **坏果率 3%～5%**：按坏果重量/金额扣减货款，或要求补货。
3. **坏果率 5%～10%**：除扣减外，可要求按坏果金额的1～2倍赔付，或整批退货。
4. **坏果率 >10%**：通常可约定为根本违约，买方有权拒收/退货、解除合同并要求赔偿。

更稳妥的合同写法是：

> 到货抽样验收，坏果率≤3%不赔付；3%<坏果率≤5%，按坏果重量扣款；5%<坏果率≤10%，按坏果金额2倍赔付或退货；坏果率>10%，买方有权拒收并解除合同，卖方承担运费及损失。

需要注意：  
- **抽样方法要写清楚**（随机抽取多少箱、每箱抽多少、以重量还是个数计）。  
- **“坏果”定义要写清楚**（腐烂、霉变、压伤、开裂、虫害等是否计入）。  
- **赔付基数要写清楚**（按坏果重量、整批货款还是坏果金额倍数）。  
- 易腐水果建议约定**到货后几小时内验货**，逾期视为验收合格。

所以，若只问一个阈值：**坏果率超过5%就应明确启动赔付；超过10%可约定拒收/解约。** 具体比例还要结合水果品类、运输距离和行业惯例调整。
