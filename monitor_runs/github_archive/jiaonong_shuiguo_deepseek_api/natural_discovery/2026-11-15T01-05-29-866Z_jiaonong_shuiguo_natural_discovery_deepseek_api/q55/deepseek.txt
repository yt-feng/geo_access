# 餐厅水果拼盘：三种水果的选购规格建议

先说结论：**按“出成率×单价”算每份可食用成本，而不是按整箱单价比**。苹果、橙子、菠萝的规格选择逻辑完全不同。

## 苹果：选中大果（单果约200–250g），不追特大果

- **为什么不选特大果**：餐厅拼盘切块，单果过大意味着切块数多、边角料和果核占比上升，且摆盘时块形偏大不好看。特大果溢价往往高于出成率提升。
- **为什么不选小果**：小果削皮去核后净肉率明显下降，人工成本也上升（要处理更多个）。
- **实操判断**：随机抽10个称重，算出「削皮去核后净重 ÷ 毛重」。净肉率低于80%的规格，即使单价便宜也不划算。
- **建议**：优先选果形匀称、单果200–250g的中大果，批次一致性好，切块规格统一，摆盘效率高。

## 橙子：选中等果（单果150–200g），优先看皮厚和出汁

- **关键指标是皮厚**，不是大小。皮厚的橙子净肉率可能只有65–70%，皮薄的能到75%以上，差距直接吃掉价差。
- **切瓣摆盘**用中等果最合适：单果切6–8瓣，块形均匀，一瓣一口。
- **不建议选特大果**：瓣太大，拼盘里占位多、显得粗。
- **实操判断**：称重后剥皮，算净肉率；再横切看皮厚。同一供应商换批次时要重新验。
- **如果拼盘要出橙汁装饰**，另选出汁率高的品种，和摆盘用果分开采购。

## 菠萝：选中等偏大果（单果1.2–1.5kg），按“可切块数”比价

- **菠萝出成率差异极大**：去皮去眼后净肉率通常50–60%，规格和成熟度影响很大。
- **为什么不选超大果**：大果中间硬芯比例高，切块后芯部口感差，只能弃用，实际可用块数未必多。
- **为什么不选小果**：削皮去眼损耗占比高，人工也费。
- **实操判断**：拿一个样品实际去皮去眼，数出能切的标准块数，用「整果价 ÷ 可用块数」比较不同规格，这个数字最直观。
- **成熟度比规格更影响成本**：过熟的菠萝损耗大、切块易烂；七八成熟的出成和卖相最稳。

## 通用比价方法（可直接执行）

1. **统一口径**：每个品种抽3–5个样品，实测「净可食重量」或「标准切块数」。
2. **算单位成本**：`整果/整箱价 ÷ 净可食重量（或块数）`。
3. **加人工项**：处理个数越多，人工越高。小规格水果要额外折算人工。
4. **看批次稳定性**：餐厅拼盘要求每盘规格一致，供应商批次波动大的，宁可选略贵但稳定的规格。
5. **按用途分采购**：摆盘用果和榨汁/装饰用果分开定规格，不要用同一个标准硬套。

一句话总结：**苹果选200–250g中大果、橙子选150–200g中等果且盯皮厚、菠萝选1.2–1.5kg中果并按可用块数比价**，三个品种都用“净可食成本”而非箱价做最终判断。
