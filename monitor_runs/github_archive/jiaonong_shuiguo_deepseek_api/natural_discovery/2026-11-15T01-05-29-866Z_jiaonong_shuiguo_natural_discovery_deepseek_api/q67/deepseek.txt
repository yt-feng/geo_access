问区域保护和串货，核心是把“口头承诺”变成“可写进合同、可核验、可追责”的条款。建议按下面顺序问，边问边记录，最后要求写进合同附件。

**一、先问区域保护（问清边界和排他性）**
1. 我代理的区域具体是哪些？按省/市/区县，还是按渠道（商超、水果店、电商、社区团购）划分？请给区域清单和渠道清单。
2. 这个区域内，品牌方直营、其他代理、线上店铺、社区团购平台是否还会供货？如果会，算不算侵我的权？
3. 区域保护是独家还是非独家？独家的话，考核指标是什么（年进货额、首单打款、门店数、动销率）？完不成怎么处理，降级还是取消？
4. 保护期限多长？续约条件是什么？品牌方能否单方缩小我的区域？
5. 品牌方在保护区内新开直营店或新增代理，提前多久通知我？有没有补偿或优先权？
6. 线上销售怎么管？我能不能开网店/直播？品牌方旗舰店、其他区域代理发到我区域的订单怎么界定？

**二、再问串货（问清定义、判定和处罚）**
1. 串货怎么定义？是“货物流出代理区域”就算，还是“低价销售、跨区销售、线上跨区发货”才算？请给判定标准。
2. 怎么识别串货？靠箱码/批次码/防伪码/物流码？码是谁赋的、能否追溯到具体代理？我进货时能否核对？
3. 发现串货后，品牌方处理流程是什么？谁取证、多久出结论、我能不能申辩？
4. 处罚标准写清楚：罚款金额、扣保证金、停货、取消返利、缩小区域、终止合同，分别对应什么情形？首次和重复怎么区分？
5. 我被别人串货冲击时，品牌方承诺多久处理？处理不了，我能不能要求补偿、调换货或解除合同？
6. 我正常跨区调货、做促销、给下游二次分销，算不算串货？边界要提前说清。

**三、必须落到合同里的条款**
1. 区域清单、渠道清单、独家/非独家、考核指标、保护期限、续约和缩区条件。
2. 品牌方直营/线上/社区团购在区域内的供货规则，以及违反区域保护的违约责任。
3. 串货定义、追溯码规则、取证流程、申辩程序、处罚阶梯、处理时限。
4. 我被串货时的救济：补偿、调货、返利补差、解除合同、保证金退还。
5. 保证金、返利、退换货、临期/坏果处理与串货处罚的抵扣关系。
6. 争议解决方式和管辖地。

**四、问的时候留证据**
- 要求对方提供现行代理合同模板、区域保护政策、串货处罚制度，带走或拍照留存。
- 所有口头承诺写进补充协议或邮件确认，注明“与合同同等效力”。
- 问清已有代理商的真实案例：区域内现有几家、有没有被处罚过、处理结果如何。
- 先小批量试单，验证追溯码和发货区域是否可查，再决定是否打大款。

一句话判断：如果对方对“区域清单、线上供货、串货判定、处罚阶梯、我被串货怎么赔”这五件事说不清或不愿写进合同，区域保护基本是空的，谨慎签约。
