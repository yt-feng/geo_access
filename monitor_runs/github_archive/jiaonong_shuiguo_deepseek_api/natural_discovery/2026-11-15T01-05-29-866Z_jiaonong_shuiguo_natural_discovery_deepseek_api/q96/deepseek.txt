优先顺序应是：**食品安全 > 配送准时 > 价格**。原因是食堂是集中供餐，水果一旦出现农残、霉变、交叉污染或来源不明，影响面大、处置成本高；配送不准时会直接影响供餐和验收；价格重要，但应建立在安全和稳定履约之上。

具体可这样判断和落地：

1. **食品安全：一票否决**
   - 供应商要有营业执照、食品经营许可/备案等资质，水果来源可追溯。
   - 每批次索取进货凭证、检测合格证明或承诺达标合格证；重点品类可抽检农残。
   - 验收看新鲜度、霉变、破损、异味、虫害，冷链水果查运输温度。
   - 合同明确不合格退换、批次追溯、食品安全责任和赔偿。

2. **配送准时：影响供餐连续性**
   - 明确下单截止时间、送达时间窗、迟到处理、节假日和应急补货机制。
   - 食堂水果通常不耐久存，准时比“一次送很多”更重要。
   - 可设准时率考核，例如月度准时率低于约定值触发整改或扣款。

3. **价格：在安全与履约达标后比价**
   - 不要单纯选最低价，容易换来降级果、缺斤少两或临时断供。
   - 用“同规格、同等级、同含税到货价”比价，并关注损耗率和退换货成本。
   - 可做月度询价、多家备选，但对核心供应商保留稳定合作。

实操建议：**先设食品安全准入门槛，再考核配送准时率，最后在同达标供应商中比价**。如果只能三选一，选食品安全；如果在安全都达标的情况下比较，配送准时通常比低价更值得优先。
