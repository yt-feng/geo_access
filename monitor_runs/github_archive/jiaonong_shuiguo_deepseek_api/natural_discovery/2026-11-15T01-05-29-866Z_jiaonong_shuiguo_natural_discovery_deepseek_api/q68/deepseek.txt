判断供应商能不能“按时到车”，别只听口头承诺，要落在**可验证的动作和节点**上。可按下面做：

1. **先看供应商有没有稳定货源和装车能力**
   - 问清：货在哪个产区/冷库、每天能出几车、装车工人和车辆怎么安排。
   - 要求提供：当天或前一天的装车视频、冷库/档口照片、车牌和司机联系方式。
   - 关键不是“有没有货”，而是“能不能在约定时间把货装上车”。

2. **合同/订单里写死节点和违约**
   - 写清：装车截止时间、发车时间、到达时间、车型/吨位、车牌、司机电话。
   - 写清逾期处理：超过几小时扣款、超过多久可取消、定金怎么退、空车损失谁承担。
   - 不要只写“尽快”“大概明天”，要写具体日期和钟点。

3. **要求关键节点主动反馈**
   - 装车前：确认货已到场、包装/成熟度合格。
   - 装车中：要求拍装车视频，视频里带车牌或当天时间标记。
   - 发车后：要司机电话，自己或让代办直接跟司机确认位置，不要只经供应商转述。
   - 临近到车：提前确认高速/路况和预计到达时间。

4. **用小额试探和分批合作验证**
   - 新供应商第一次不要压大单，先走一车或小批量。
   - 连续两三次都能按节点装车、发车、到车，再逐步加量。
   - 老供应商也要看旺季表现，旺季最容易掉链子。

5. **看历史履约而不是看规模**
   - 问同行、市场代办、司机：这个供应商是否经常拖车、换车、临时加价。
   - 重点看：是否经常“有货没车”“装车排队”“司机临时换”。
   - 规模大不等于按时率高，关键看近期履约记录。

6. **设置备用方案**
   - 同一批次至少备一个备选供应商或代办。
   - 旺季提前锁车、锁冷库、锁装车时间。
   - 自己掌握司机和车牌信息，避免供应商中间换货换车你不知情。

一句话：**能按时到车 = 有货 + 有车 + 有装车安排 + 有节点反馈 + 有违约约束。** 只满足前两项不够，必须看装车和发车的实际证据。
