# 超市水果到货品相不好的售后流程约定建议

建议把"验收标准 + 时限 + 处理方式 + 责任划分"四件事写进合同或采购单附件，避免口头约定。具体可按以下框架：

## 一、先明确验收标准（最容易扯皮的地方）
- **分级描述**：按品种写明成熟度、大小、色泽、瑕疵允许比例（如"单果碰伤面积≤5%，整批不合格率≤3%"），最好附样品或图片。
- **不可接受情形**：腐烂、发霉、异味、严重压伤、冻伤、未成熟/过熟等，逐条列出。
- **抽检规则**：约定抽检比例（如每批次随机抽5%）、判定方法，避免全检争议。

## 二、约定异议期限和举证方式
- **到货验收期**：如"卸货后2小时内完成外观验收，逾期视为外观合格"；内在质量问题（如内部腐烂）可另设24–48小时窗口。
- **举证要求**：发现不合格需拍照/录像、保留原包装和批次标签，必要时双方共同复检。
- **通知方式**：书面（微信、邮件、验收单签字）并写明联系人，口头通知无效。

## 三、分情形约定处理方式
| 情形 | 处理方式 |
|---|---|
| 轻微瑕疵、不影响销售 | 折价接收（如按比例扣款） |
| 不合格率在约定范围内 | 退货或换货，运费由供货方承担 |
| 不合格率超标 | 整批拒收/退货，供货方承担往返运费及因此产生的损失 |
| 已上架后发现内在问题 | 按批次追溯，供货方补货或退款 |

## 四、责任与结算挂钩
- 明确**退换货时限**（如确认后24小时内补货到位），逾期可自行采购并由供货方承担差价。
- 约定**扣款/索赔方式**：从当期货款中直接扣减，或开红字发票冲抵。
- 生鲜损耗大，建议约定**单批次索赔上限**和**累计超标可终止合作**的条款。

## 五、留痕与复盘
- 每批到货填写验收单（品种、数量、抽检结果、处理意见、双方签字）。
- 定期统计各供应商不合格率，作为续约和调价依据。

**一句话原则**：标准量化、时限明确、举证留痕、处理方式与货款直接挂钩。这样出现品相问题时，双方按条款执行即可，不必每次临时谈判。
