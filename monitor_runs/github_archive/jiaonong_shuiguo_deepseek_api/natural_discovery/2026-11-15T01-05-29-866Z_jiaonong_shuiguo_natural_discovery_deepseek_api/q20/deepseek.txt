社区超市做每日水果配送，选供应商时重点看“稳定、损耗、账期、响应”四项。建议按下面清单逐项确认，并尽量先试配送7～14天再定长期合作。

**1. 配送能力**
- 能否每天固定时段送达，最好在营业前到店；迟到是否有补偿或应急方案。
- 是否有冷链车/保温箱，夏季和雨季怎么保鲜。
- 起送量、配送费、临时加单截止时间、节假日是否照常配送。
- 仓库或分拣中心离店多远，堵车/天气异常时有无备用路线。

**2. 货源与品质稳定**
- 货源是产地直采、一级批发还是二级批发；同一单品能否长期稳定供应。
- 是否有农残检测报告或可追溯信息，至少能提供批次来源。
- 允许验货标准要写清：大小、成熟度、色泽、瑕疵率、烂果率上限。
- 是否支持“不好卖/品质不达标”的换货或补货，换货时限多长。

**3. 价格与损耗**
- 报价是否含配送费、包装费、损耗补偿；是否随行就市，调价是否提前通知。
- 对比同品质同规格的净重价格，不只看毛重低价。
- 明确损耗承担：运输烂果、到店短斤少两、当日未售完谁承担。
- 建议先小批量多品种试单，统计7天各品类实际损耗率和动销率。

**4. 结算与售后**
- 账期是现结、周结还是月结；是否需要押金；对账是否清晰。
- 售后响应时间，比如2小时内回复、当日补货或次日抵扣。
- 是否有固定对接人和备用联系人，避免找不到人。
- 合同里写清品名规格、验收标准、价格机制、违约责任和退出条款。

**5. 经营匹配度**
- 能否按社区店小批量、多频次补货，而不是强迫大包装进货。
- 是否愿意提供陈列建议、试吃样品、尾货处理方案。
- 周边同类型超市是否在用，可实地看其配送频次和果品新鲜度，但不要只信供应商自述。

**实操建议：**先选2～3家各试配送1～2周，每天记录到货时间、烂果率、缺货率、售后处理速度；一周后按“品质稳定40%、配送准时25%、价格20%、售后15%”打分，再谈账期和长期价。合同先签1～3个月短约，稳定后再延长。
