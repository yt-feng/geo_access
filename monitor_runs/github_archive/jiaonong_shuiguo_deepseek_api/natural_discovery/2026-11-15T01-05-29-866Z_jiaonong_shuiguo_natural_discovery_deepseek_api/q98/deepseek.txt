判断供应商合规与稳定，核心看“证照可核验、来源可追溯、履约可验证、风险可替换”四条线。下面按可执行动作列出。

## 一、合规判断：先看证照和票据，不看口头承诺

1. **主体资质**
   - 营业执照：经营范围含食用农产品销售/食品销售；核对统一社会信用代码、地址、法人，现场拍照留存。
   - 食品经营许可证（如供应商从事食品销售、分装、配送）：核对许可项目、有效期、经营场所是否与实际一致。
   - 若供应商只是种植户/合作社：要求提供合作社营业执照、产地证明、农户协议；通过批发市场供货的，要能提供市场入场销售凭证或产地证明。

2. **票据与溯源**
   - 每批次提供**进货凭证/销售单**，写明品名、数量、产地、采摘或进货日期、供应商盖章或签字。
   - 能提供**承诺达标合格证**（食用农产品）、检测报告或快检记录；重点看农残检测项目是否覆盖常用高风险品种。
   - 追溯链要能闭合：食堂下单→供应商供货单→产地/批发市场凭证→检测记录。缺一环就要求补，补不了就降级或替换。

3. **人员与车辆**
   - 配送人员健康证（涉及直接接触食品的配送环节）。
   - 配送车辆卫生状况、是否与化学品/生鲜混装；冷藏水果看温控记录。

4. **合同条款**
   - 明确质量标准、验收标准、退换货、农残超标责任、食品安全事故赔偿、票据提供义务。
   - 约定“证照到期前主动报备”“产地变更提前告知”“抽检不合格立即停供并追溯”。

## 二、稳定性判断：看履约记录和供应能力，不看规模大小

1. **供应能力**
   - 问清主要品类、产地、季节替代方案；要求提供近3个月供货品种和数量记录。
   - 是否有备用产地/备用批发渠道；单一产地、单一品种依赖度高的，稳定性风险大。

2. **履约表现**
   - 连续试供2—4周，记录到货准时率、缺货率、损耗率、规格达标率、票据齐全率。
   - 看是否频繁换产地、换包装、换联系人；频繁变更且解释不清的，稳定性存疑。

3. **价格与账期**
   - 价格随行就市可以，但报价逻辑要清楚；明显低于市场价且无法解释来源的，合规风险高。
   - 账期、结算方式写进合同，避免口头赊账；稳定供应商通常能接受对公结算和发票。

4. **应急能力**
   - 临时加单、节假日前备货、恶劣天气配送，是否有明确响应时限。
   - 出现农残超标或疑似食源问题时，能否2小时内提供批次流向和替代货源。

## 三、现场核查清单（可直接用）

- [ ] 营业执照、食品经营许可证原件或加盖公章的复印件
- [ ] 近3批次进货凭证/销售单/产地证明
- [ ] 近3批次检测报告或快检记录
- [ ] 配送人员健康证、车辆卫生照片
- [ ] 主要品类产地和季节替代方案
- [ ] 合同中的质量、退换、赔偿、票据条款
- [ ] 试供期记录表：准时率、缺货率、损耗率、票据齐全率

## 四、判断结论

- **合规底线**：证照齐全且可核验、每批次有票有溯源、检测记录可查。三项缺一项，不作为主供应商。
- **稳定底线**：试供期内准时率稳定、缺货有替代方案、票据持续齐全、价格逻辑合理。达不到就保留第二供应商。
- **建议策略**：养老院/医院食堂不宜单一供应商，至少“1主1备”，主供占70%左右，备供占30%，每季度复核证照和履约记录。
