**1. 开发票：必须支持**
- 企业福利采购一般需要**增值税发票**用于入账和税前扣除；能否开专票、税率多少，要提前确认。
- 重点确认：开票主体与合同主体一致、发票品名能否开“水果礼盒/食品”、是否支持分批开票、退换货后能否红冲。
- 若供应商只能开普票或加税点开票，要提前算进总成本。

**2. 定制包装：建议要求支持，至少作为加分项**
- 企业福利常需要体现公司标识、节日主题、贺卡、LOGO、统一礼盒外观。
- 重点确认：**起订量、打样费、打样周期、包装设计版权、是否额外收费、定制后是否影响退换货**。
- 若采购量小，可退一步要求“贴标/腰封/贺卡定制”，成本更低。

**3. 合同里建议写清楚**
- 发票类型、税率、开票时间；
- 包装定制内容、验收标准、打样确认流程；
- 水果品种/规格/净重/坏果赔付标准；
- 交付时间、配送范围、破损和变质处理方式。

**判断标准：** 不能开发票的供应商直接排除；定制包装不是所有场景都强制，但企业福利采购中应优先选择能支持的供应商，至少支持LOGO贴标或贺卡定制。
