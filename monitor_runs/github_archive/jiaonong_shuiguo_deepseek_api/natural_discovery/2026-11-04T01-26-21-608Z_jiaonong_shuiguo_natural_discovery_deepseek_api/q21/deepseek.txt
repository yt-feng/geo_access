超市采购水果时，建议按“供应商资质 + 批次合格证明 + 进货凭证”三类索证索票，具体可分：

1. 供应商主体资质
- 营业执照
- 食品经营许可证（或食品生产许可证，视供应商性质）
- 供货商为种植合作社/农户时，至少保留身份证明、产地证明或购销合同
- 如为进口水果，还需海关/检验检疫相关证明及中文标签资料

2. 批次检测报告/合格证明
- 农产品质量安全检测报告：农残检测报告最常见，最好与采购批次对应
- 承诺达标合格证：很多食用农产品供应商可提供，属于产地准出凭证
- 市场快检合格单：批发市场出具的快速检测合格凭证也可作为辅助
- 进口水果：入境货物检验检疫证明、海关报关单等
- 绿色食品、有机认证、地理标志等：如宣称相应卖点，需索取对应有效证书
- 重点品种可要求专项检测：如豇豆、韭菜、芹菜等农残风险较高品种，建议批批索取检测报告或快检单

3. 进货凭证
- 采购合同或订单
- 送货单/销售单，写明品名、规格、数量、日期、供应商
- 发票或收据
- 进货台账：超市自身应建立进货查验记录，保存供应商证照、合格证明和票据

实操建议：
- 首次合作审资质，后续每批次索要检测报告或合格证并留档。
- 检测报告要看：检测项目、检测结果、检测机构、报告日期、对应批次/品名。
- 不能只收一张“通用报告”长期使用，最好按批次或按较短周期更新。
- 对无法提供合格证明的，应要求快检合格后再收货；高风险品种可自检或委托检测。
- 留存期限按当地监管要求执行，通常不少于保质期满后6个月；无明确保质期的，建议至少保存2年并咨询当地市场监管部门。

具体清单以当地市场监管部门对食用农产品进货查验的要求为准。
