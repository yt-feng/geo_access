# 提前向供应商索取的核心资料

**一、产地与检测报告类（最关键）**

1. **当批次农残检测报告**：要求与本次到货批次号/采收日期对应，不能只给一张旧报告。报告应由具备CMA资质的检测机构出具，查看检测项目是否覆盖常见高风险农药（如有机磷、氨基甲酸酯类），以及结论是否为"合格"。
2. **产地证明/供货证明**：确认货源来自备案基地或正规合作社，便于追溯。
3. **种植过程中的用药记录**（如供应商能提供）：了解采收前是否遵守安全间隔期。

**二、资质与承诺类**

4. **供应商营业执照、食品经营许可证**（或食用农产品销售相关资质）。
5. **质量安全承诺书/供货协议条款**：明确农残超标时的退换货、赔偿和追责责任。
6. **产地准出证明**：部分地区实行食用农产品合格证制度，可要求提供"承诺达标合格证"。

**三、可操作性建议**

- **报告与批次绑定**：在采购合同中写明"每批到货须附对应批次检测报告，无报告可拒收"。
- **自检+抽检双保险**：对高风险品种（叶菜、草莓、豇豆等）用快速检测卡自检，或定期送第三方抽检，不要完全依赖供应商报告。
- **保留样品与记录**：每批留样并记录供应商、批次、到货日期，一旦抽检出问题可快速追溯和索赔。
- **优先选择有追溯码/合格证的产品**：可扫码溯源的产品风险相对可控。

**判断标准**：如果供应商只能提供"通用报告"、报告与批次对不上、或拒绝在合同中写超标责任条款，应视为高风险供应商，谨慎合作或提高自检频次。
