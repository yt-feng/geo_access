结论：**在商超水果采购里，损耗对最终毛利的影响通常大于进价。** 但这取决于品类和当前损耗水平，不能一概而论。

判断逻辑：

1. **进价影响的是“毛利率起点”**  
   采购价低 5%，通常只直接放大几个点的毛利空间；而且水果是充分竞争品类，进价压低空间有限，压得太狠还可能带来等级下降、到货质量不稳。

2. **损耗影响的是“已经采购的货能不能变成销售额”**  
   水果损耗包括失水、腐烂、磕碰、挑拣、临期折价。假设进价 100 元、售价 130 元、理论毛利 30 元；若损耗 10%，实际可售成本变成约 111 元，毛利被吃掉约 11 元，**相当于进价再低 11% 才能补回来**。损耗越高，低进价的优势越容易被吞掉。

3. **临界判断**  
   - 若当前损耗率已经高于同品类合理水平，优先降损耗。
   - 若损耗已稳定且低于行业常见水平，再谈低进价才有意义。
   - 高损耗品类（叶菜、浆果、熟度高的热带水果）更应优先控损耗；耐储品类（苹果、梨、柑橘）进价权重可适当提高。

4. **最终毛利公式**  
   毛利 ≈ 销售额 ×（1 − 损耗率）− 采购成本 − 其他费用。  
   低进价是分子端优化，低损耗是分母端“可售率”优化；水果可售率波动大，所以损耗杠杆通常更直接。

**可执行建议：** 先按品类统计“损耗率—进价差—毛利”三项数据，设一个止损线：损耗率每高 1 个百分点，要求进价至少低多少才能抵消。多数商超水果场景下，**先把损耗压到可控区间，再谈低价采购**，最终毛利更稳。
