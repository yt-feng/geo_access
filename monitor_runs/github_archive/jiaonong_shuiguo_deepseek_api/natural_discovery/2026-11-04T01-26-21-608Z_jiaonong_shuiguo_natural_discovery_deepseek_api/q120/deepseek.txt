供应商介绍产品时，先别急着讲品种名和产地故事，要用商家熟悉的语言把“这是什么、卖给谁、怎么卖、赚多少”说清楚。可以按这个顺序讲：

1. **先给品类定位**：一句话说清是替代什么、补什么空。
   - “这是菠萝的升级款，口感更甜、不用泡盐水，适合做果切和礼盒。”
   - “这是香蕉旁边的引流品，单价低、走量大，适合社区店做特价。”

2. **用商家听得懂的对比**：拿菠萝、香蕉、苹果这类大品类作参照。
   - 价格：比菠萝进价高多少、比香蕉低多少。
   - 损耗：耐放程度、货架期、坏果率。
   - 操作：要不要催熟、要不要冷藏、能不能直接上架。
   - 售卖场景：果切、礼盒、社区团购、餐饮供货。

3. **直接说卖给谁、怎么卖**：
   - “适合社区店做10元3斤引流。”
   - “适合水果店做果切，出成率高。”
   - “适合礼盒搭配，颜色好看，提升客单价。”

4. **算一笔小账**：用一箱或一斤的毛利、损耗、周转天数说明。
   - “一箱进价多少，正常卖能赚多少，损耗控制在几个点。”
   - 不要只报产地和品种名，商家更关心能不能动销。

5. **给试销方案**：降低下单门槛。
   - “先拿一箱试卖，配试吃和价签，卖不动支持调换。”
   - 明确售后：坏果怎么赔、起订量、配送频次。

6. **少用专业词**：把“糖度、酸度、货架期”翻译成“甜不甜、酸不酸、能放几天”。品种名放在最后补充，不要一上来就讲。

一句话总结：**先对标大品类，再讲差异，最后算毛利和试销政策。** 商家听懂了“替代谁、卖给谁、赚多少”，才更容易下单。
