先给一个可执行的判断框架：**新品首轮试卖不要按“总量百分比拍脑袋”，而按“单店/单仓一周可消化量 + 损耗承受上限”来定**。比较稳的做法是：

### 1. 首轮试卖量建议
- **单店首轮：1～3天销量，最多不超过5天销量**
- **单个SKU首轮总量：控制在预计周销量的30%～50%**
- **小型门店/新渠道：先拿2～5箱或20～50公斤级小批量**
- **连锁采购：先选2～3家代表性门店试卖，不要全渠道铺开**

水果新品最大的风险不是卖不动，而是**卖不动后损耗**。所以首轮量应满足“能看出动销速度”，又不至于压货。

### 2. 更稳的量化公式
可用这个公式倒推：

> **首轮试卖量 = 单店日均预计销量 × 试卖天数 × 安全系数**

- 试卖天数：**3天**
- 安全系数：**0.6～0.8**（新品保守取低）
- 若完全没历史数据，按同类水果、同价位、同规格的**日均销量的50%**预估

例如同类水果单店日均卖20公斤，新品首轮可试：
> 20 × 3 × 0.6 = **36公斤/店**

### 3. 试卖前必须和供应商确认
- 是否支持**小批量起订**
- 是否支持**坏果赔付/损耗补货**
- 首批到货成熟度是否适合**3天内销售**
- 补货周期是**1天还是3～5天**
- 试卖期内能否**锁价**
- 临期/尾货能否**退换或调拨**

### 4. 试卖判断标准
建议设3个硬指标，试卖3～5天后决定：
- **动销率**：3天卖出首批量的**60%以上**，可小步补货
- **损耗率**：水果新品超过**8%～10%**要谨慎；叶菜/浆果类可放宽到10%～15%
- **复购/询问**：有顾客主动复购或询问，才值得扩大

### 5. 稳妥节奏
**首轮小批量试卖 → 3天看动销 → 卖得动补第二批（首轮的50%～70%）→ 连续两周稳定后再进主推位。**

一句话结论：**首轮按单店3天预估销量的六到八成下量，选2～3家店试卖，设损耗上限和补货门槛，不要一次性全渠道铺货。**
