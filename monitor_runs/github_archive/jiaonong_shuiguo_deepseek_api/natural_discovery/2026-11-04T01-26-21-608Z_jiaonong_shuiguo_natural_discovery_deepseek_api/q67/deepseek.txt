# 和水果品牌方谈代理：区域保护与串货怎么问

核心原则：**不要只问“有没有区域保护”，而要问“保护如何落地、违约怎么追责”**。没有罚则和核查机制的区域保护等于没有。建议把问题拆成四组，逐条要书面答复，并写进合同。

## 一、区域保护（问清边界和排他性）

1. 我代理的**确切区域范围**是什么？按省/市/区县，还是按渠道（KA、水果店、社区团购、电商）划分？
2. 在这个区域内，是否**只授权我一家**？品牌方自营、直营电商、直播带货是否也算在内？
3. 区域内**已有其他代理或经销网点**吗？如有，他们和我的边界怎么划？
4. 区域保护期限多久？**续约条件**是什么？完不成任务会不会被缩区或换人？
5. 跨区销售（比如客户主动来我区域提货、我发货到区域外）算不算串货？**判定标准**是什么——按发货地还是收货地？
6. 线上销售归谁？我能不能开网店/做直播？品牌方旗舰店和直播间会不会以更低价格冲击我的区域？

## 二、串货（问清认定、追责和举证）

7. 串货的**具体认定规则**写在哪里？是否有编码/批次追溯（如箱码、果标、溯源码）？
8. 发现串货后，品牌方**多久内核查、如何处理**？对串货方的处罚是什么（罚款、扣返利、断货、取消代理）？
9. 我被别人串货冲击时，**向谁投诉、多久响应、如何补偿**？有没有书面承诺？
10. 如果品牌方自己（或关联公司、授权电商）低价倾销到我的区域，算不算串货？怎么处理？
11. 举证责任在谁？我举报串货需要提供什么证据？品牌方不处理怎么办？

## 三、价格与任务（串货的根源往往在这里）

12. 出厂价、建议零售价、最低限价是否统一？**不同区域/渠道是否存在价差**？价差过大就是串货诱因。
13. 年度/季度进货任务、返利政策怎么定？任务定得过高会逼着代理往外窜货，也会让别人窜进来。
14. 临期果、次果、尾货的处理渠道是否受区域限制？

## 四、落到合同（最关键）

15. 上述区域保护、串货认定与罚则，能否**逐条写进代理合同**，而不是口头承诺或“政策文件随时调整”？
16. 违约救济：品牌方违反区域保护时，我能否**解约、退货、索赔**？
17. 政策调整（缩区、改价、增开代理）需不需要**提前书面通知并征得我同意**？

## 实操建议

- 让对方**书面回答**（邮件/盖章文件），口头承诺一律不算。
- 要求查看**现有代理合同模板**中关于区域和串货的条款原文。
- 谈之前先摸清该品牌**现有网点密度和线上价格**，判断保护是否名存实亡。
- 合同里争取写入：**串货罚则、核查时限、我被冲击时的补偿机制、品牌方自营/电商的约束条款**。
- 保留进货批次与编码记录，这是日后举报串货和自证清白的依据。

一句话总结：**问“保护范围 + 判定标准 + 核查时限 + 违约罚则 + 我的救济手段”五件事，全部要白纸黑字。**
