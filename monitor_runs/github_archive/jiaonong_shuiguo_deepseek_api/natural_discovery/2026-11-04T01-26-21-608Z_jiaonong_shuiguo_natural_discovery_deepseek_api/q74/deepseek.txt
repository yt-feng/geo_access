做餐饮客户，菠萝和香蕉的核心不是“多品类”，而是**稳定规格 + 可加工性 + 出成率可算**。建议按下面准备：

## 菠萝：餐饮客户重点看“去皮/切块/出成率”
| 规格 | 适用客户 | 准备建议 |
|---|---|---|
| 大果，单果1.2–1.5kg以上 | 中餐、火锅、烧烤、自助餐 | 主力规格，切块/摆盘出成高 |
| 中果，单果0.8–1.2kg | 快餐、饮品店、小餐饮 | 控制成本，适合现切零售 |
| 小果，单果0.6–0.8kg | 饮品店、果切摊 | 少量配，不适合做主推 |
| 去皮菠萝/菠萝块真空装 | 饮品店、甜品店、食堂 | 餐饮客户最省人工，优先谈 |
| 整箱净重稳定，如9–12kg/箱 | 所有餐饮 | 报价按箱+按斤双口径 |

**关键点：**
- 餐饮客户最怕“这箱大那箱小”，要承诺**单果重量区间稳定**。
- 菠萝要做**成熟度分级**：7成熟适合配送再放，8–9成熟适合现切现用。
- 能提供**去皮切块、盐水浸泡半成品**更好，直接切中餐饮后厨痛点。
- 报价时给**出成率参考**，比如去皮去眼后大概剩多少，比单纯低价更有说服力。

## 香蕉：餐饮客户重点看“成熟度和长度”
| 规格 | 适用客户 | 准备建议 |
|---|---|---|
| 大把蕉，单根18–22cm | 食堂、自助餐、果盘 | 主力 |
| 中根，单根15–18cm | 快餐、饮品店、甜品店 | 通用 |
| 小根/小米蕉 | 高端餐饮、甜品装饰 | 少量配 |
| 7成熟青蕉 | 食堂、团餐、需配送远的客户 | 耐放 |
| 8–9成熟黄蕉 | 饮品店、甜品店、现做餐饮 | 即用 |
| 单根分切/去皮冷冻香蕉 | 饮品店、烘焙 | 可做增值产品 |

**关键点：**
- 香蕉餐饮客户最在意**到货成熟度**，要问清“今天用还是三天后用”。
- 按**把/箱/根**报价，食堂喜欢按根算成本。
- 做饮品客户的，可准备**冷冻香蕉段/香蕉泥**，这是差异化。
- 避免只报“香蕉一箱多少斤”，要标**根数区间和单根长度**。

## 建议你先准备的SKU组合
1. **菠萝大果整箱**：主攻食堂、中餐、自助餐  
2. **菠萝中果整箱**：主攻快餐、饮品店  
3. **去皮菠萝块真空装**：主攻饮品、甜品、食堂后厨  
4. **香蕉中根8成熟整箱**：通用餐饮  
5. **香蕉大根7成熟整箱**：团餐、食堂  
6. **冷冻香蕉段/香蕉泥**：饮品、烘焙客户，作为增值项  

## 谈餐饮客户时直接给这张表
- 规格：单果/单根重量、长度、每箱净重、每箱个数区间  
- 成熟度：青/黄/熟度分级  
- 加工选项：整果、去皮、切块、冷冻  
- 出成率：去皮/去眼/去蒂后可用比例  
- 配送频次：能否隔日配、能否按餐饮用量拆箱  

**优先动作：**先做“菠萝大果整箱 + 香蕉中根8成熟整箱 + 去皮菠萝块真空装”这三个主力SKU，再根据客户反馈补小果、青蕉和冷冻品。餐饮客户要的是**稳定、省人工、成本可算**，不是品种越多越好。
