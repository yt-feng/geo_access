香蕉和菠萝的售后失控，通常不是“赔不赔”的问题，而是**损耗在前端已经发生，售后只是最后爆出来**。控制售后要按“选品—收货—分级—配送—售后规则”五段卡住。

**1. 选品和采购：先降低高风险批次**
- 香蕉：优先选7成熟左右、果指饱满、无大面积青斑转黑斑的货；夏季缩短在库时间，别一次囤多。高温天尽量少做“超低价大串香蕉”，大串更容易压伤。
- 菠萝：选果眼浅、无软塌、无酒味、冠芽新鲜的；雨季和高温季减少整果预售，改做“现切盒”或“小果”。
- 采购合同里明确：到货抽检标准、烂果率上限、超标退换或扣款。不要所有损耗都自己扛。

**2. 收货抽检：把坏货挡在团点外**
- 每批抽检，香蕉看压伤、断裂、黑腐；菠萝看底部软腐、酒味、霉点。
- 设定收货红线：单批明显坏果超过约定比例就整批拒收或降级做特价，不进正常团。
- 到货后拍照留档，尤其是开箱第一时间的状态，售后判责用得上。

**3. 分级和包装：别把“次果”混进正价团**
- 香蕉分“即食”和“耐放”两档，即食果当天配送到自提点，耐放果才做次日/隔日团。
- 菠萝整果和切盒分开卖；切盒必须冷链、当天清。
- 包装上香蕉用隔板/纸包减少挤压，菠萝竖放或加网套，避免运输中互相压伤。

**4. 配送和自提：缩短最后一段的暴露时间**
- 高温天香蕉、菠萝尽量走“次日达”或“上午到、下午提”，别在自提点露天放太久。
- 自提点明确存放要求：阴凉通风、不叠压、不暴晒；香蕉不要和苹果/梨混放催熟。
- 超时未取的，提前提醒；明确“超时未取导致变质”的售后边界。

**5. 售后规则：简单、可执行、有边界**
- 香蕉：轻微黑点、表皮花不算售后；大面积黑腐、断裂出水、果肉变质按比例赔。建议“拍照+坏果比例”赔付，不要求整单退。
- 菠萝：外部轻微青斑不算；切开后黑心、软腐、酒味、霉变才赔。整果和切盒分开定规则。
- 设置时限：自提后24小时内反馈，切盒当天反馈；超时只做协商。
- 赔付优先“按坏果比例补发/退款/下单价折”，别一上来整单退，否则会被少数人薅。
- 高频售后用户单独标记，后续订单要求开箱视频或到店自提验货。

**最有效的动作排序：**
1. 收货抽检设红线，坏批次不进团；
2. 香蕉分即食/耐放，菠萝减少整果预售；
3. 售后只认“坏果比例+照片+时限”，不认情绪；
4. 高温季主动降量，宁可少团一次，别用低价冲量换售后。

核心一句话：**高损耗品控售后，靠“少进坏货、快周转、分级卖、规则清”，不是靠事后赔钱。**
