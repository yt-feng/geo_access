直接说结论：**水果店卖菠萝，最优是“整果为主、提供免费代削/代切服务，不建议提前大量削好摆卖；也不建议完全放任顾客自己翻挑”。**

分三层说：

**1. 整果为主，是最稳的**
- 菠萝整果耐放、损耗低、卖相可控，顾客也容易判断新鲜度（看叶冠、闻香味、看底部）。
- 去皮好的最怕两件事：氧化出水、卖不掉就报废。除非你客流稳定、当天能卖完，否则削好摆卖损耗很高。
- 整果还能让顾客有“挑”的参与感，但你要把挑的范围控制住。

**2. 去皮好的可以少量做，但只做“引流/便利款”**
- 适合：下班高峰、写字楼/学校附近、顾客赶时间。
- 做法：少量现削、标价略高、当天清完；不要提前大批量削好冷藏摆一天。
- 关键判断：如果削好的当天卖不完超过两三成，就说明这个店不适合主推去皮款。

**3. 顾客自己挑，要“给挑法，不给翻堆”**
- 完全让顾客自己翻，容易捏伤、翻乱、掉叶冠，损耗和纠纷都增加。
- 更好的是：整果分档摆好（按大小/成熟度），店员在旁边教一句“看叶冠绿、底部干爽、闻着有香味就熟”，顾客指哪个你拿哪个。
- 想保留自选感，可以设“自选区”和“代削区”，自选区顾客自己拿，代削区你帮挑帮削。

**可执行方案：**
- 主陈列：整果，分大小两档，标清“可免费代削”。
- 便利款：每天固定时段少量现削，卖完为止，不隔夜。
- 服务话术：“您自己挑也行，我帮您看下熟度；挑好我免费削。”
- 损耗监控：连续一周记录削好款卖剩比例，超过20%就减量或停做。

一句话：**整果是基本盘，代削是服务，削好现卖是补充；顾客可以挑，但你要管陈列和挑法。**
