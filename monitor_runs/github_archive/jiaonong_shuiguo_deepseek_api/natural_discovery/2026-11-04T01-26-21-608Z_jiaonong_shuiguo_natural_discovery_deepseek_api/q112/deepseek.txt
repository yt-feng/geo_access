坏果率没有统一的法定赔付阈值，关键看合同怎么约定。实操建议：

1. **合同里最好明确写清**：验收标准（如“坏果率≤3%为合格”）、检测方法（抽检比例、以重量还是个数计）、超出后的处理方式（扣款/换货/退货/解除合同）。

2. **常见行业做法**：生鲜水果通常约定坏果率在 **3%～5%** 以内视为合理损耗、不赔付；超过约定阈值按超出部分扣款，或整批退货/换货。具体阈值因品类、运输距离、包装方式差异很大，易腐水果可适当放宽。

3. **没有约定时**：只能依据《民法典》合同编关于质量不符合约定的规定主张违约责任，但“坏果率多少算不合格”容易产生争议，所以务必在合同中量化。

4. **建议条款写法**：约定抽检比例（如每批随机抽5箱）、计数方式、阈值（如坏果率>5%）、赔付计算（如按坏果重量×单价的1.5倍扣款）、异议期限和复检机制。

简单说：**阈值由合同定，建议设在3%～5%，并配套抽检和扣款规则**；没有合同约定就很难有确定标准。
