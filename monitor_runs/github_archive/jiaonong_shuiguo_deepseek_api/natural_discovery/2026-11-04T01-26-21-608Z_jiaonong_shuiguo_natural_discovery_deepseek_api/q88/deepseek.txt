采购端要把“坏果率”和“口感波动”拆成可验的指标，不能只靠供应商口头承诺。给你一套可直接落地的做法：

**1. 先定验收标准，再谈价格**
- 按品类写清：单果重/果径、糖度（Brix）下限、酸度或糖酸比、成熟度、允许瑕疵比例。
- 坏果定义要具体：腐烂、霉变、压伤、裂口、虫眼分别算，不能笼统说“次果”。
- 每批抽检比例固定，如到货每托盘抽若干箱、每箱抽若干果；记录坏果率、糖度、硬度。
- 设定拒收线：如坏果率超过X%、糖度低于Y即整批拒收或折价，写进合同。

**2. 采购前锁定“口感稳定”来源**
- 优先固定产区、固定果园/合作社、固定采摘批次，减少混收混装。
- 要求供应商按成熟度分批采摘，不要“一树下果”；不同成熟度分开报价和发货。
- 对糖度波动大的品类，采购前要近几批检测记录，连续稳定再放量。

**3. 用“小批量试销+复购数据”反向选品**
- 新品先小批量到仓试销，记录差评关键词：酸、淡、烂、软、不甜。
- 差评集中在哪类问题，就回到验收标准加严哪一项。
- 同一供应商连续两批口感波动大，降级或替换，不因低价长期绑定。

**4. 物流和包装按品类定制**
- 易压伤品类用分隔托、加厚箱、防震填充；易腐品类控制预冷和冷链时长。
- 采购合同明确运输温度、到货时限、责任划分；到货即拍开箱视频和抽检照片。
- 夏季高温或远距离订单，适当提高成熟度标准或缩短在途时间。

**5. 建立批次追溯和供应商评分**
- 每批记录：产地、采摘日、到货日、抽检糖度/坏果率、对应线上差评率。
- 按“坏果率、糖度达标率、差评率、到货时效”给供应商打分，采购量向高分供应商集中。
- 对反复出现问题的批次留样，作为扣款、换货或终止合作依据。

**6. 线上页面预期管理**
- 详情页写清品种口感特点、酸甜度、保存方式，避免用户预期错位。
- 对口感波动大的批次，不做“纯甜保证”这类绝对化宣传。

核心判断标准：**每批可抽检、坏果有拒收线、糖度有下限、供应商有评分、差评能回溯到批次。** 做到这五点，坏果和口感不稳定会从“运气问题”变成可管理的采购问题。
