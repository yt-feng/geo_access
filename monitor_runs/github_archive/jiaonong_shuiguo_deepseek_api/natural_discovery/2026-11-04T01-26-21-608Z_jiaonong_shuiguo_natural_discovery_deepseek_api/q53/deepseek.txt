餐饮店每天用量少，最省心的不是找“大供应商”，而是找**本地小批量、能稳定日配、按份/按箱起送**的渠道。建议按这个优先级选：

1. **本地农贸批发市场的固定档口**
   - 适合：每天少量、品类要灵活。
   - 省心点：可以谈每天固定时间送货，缺货可临时换品。
   - 注意：选有固定摊位、能做月结/周结的，不要只找流动摊贩。

2. **本地生鲜配送小平台/社区团购供应商**
   - 适合：每天只要几斤到十几斤，想要线上下单。
   - 省心点：起送量低、次日达、有售后。
   - 注意：确认是否支持餐饮商户、能否开票、坏果赔付规则。

3. **附近水果店/小型水果批发商做“日配”**
   - 适合：用量少且品类固定。
   - 省心点：距离近，临时补货快。
   - 注意：谈好固定配送时间和缺货替代方案，避免旺季被零售客户挤占。

4. **产地/一级批发直供**
   - 不建议小用量门店首选。
   - 原因：起订量大、损耗和压货风险高，不够省心。

**筛选供应商时重点看5条：**
- 能否**每天固定时间送**，而不是你每天催；
- 起送量是否低，是否支持**小份多品**；
- 坏果/少货是否**当场补或下次抵扣**；
- 价格是否**一周一调**，避免每天扯价；
- 是否能**微信下单、对账清晰、支持月结**。

**最省心的组合建议：**
主供应商选1家本地农贸档口或生鲜配送平台，做日常稳定配送；备选1家附近水果店，专门应急补货。不要只押一家，也不要找太多家，2家足够。

签约前先试配1周：每天记录到货时间、缺货率、坏果率、临时补货响应。试配稳定后再谈周结/月结和固定菜单。
