连锁超市和水果供应商签年度合同，踩坑往往不在“价格”本身，而在**价格机制、质量标准、损耗归属、账期结算、返利费用**这几类条款。下面按风险从高到低列出最容易出问题的点，并给出可执行的写法建议。

**1. 价格条款：只锁定“年度价格”但没写调价机制**
水果价格波动大，固定年价要么供应商亏本断供，要么超市被高价套牢。建议：
- 采用“基准价+市场联动”，约定参考批发市场均价或第三方价格指数，按月/季度调整；
- 明确调价触发条件（涨跌幅超过X%）、申请流程和生效时间；
- 促销价、特价品的成本分担单独写，避免供应商以“促销亏本”为由降低品质或断供。

**2. 质量标准：只写“符合国家标准”等于没写**
水果的坑多在规格、成熟度、农残、外观。建议：
- 按品类附质量规格表：品种、等级、单果重/果径、糖度、成熟度、色泽、允许缺陷比例；
- 明确验收方法（抽检比例、检测方式）和不合格处理（拒收、降级、换货、扣款）；
- 农残检测责任和费用谁承担、超标如何追责要写清；
- 约定“以到货验收为准”还是“以入库后复检为准”，避免事后扯皮。

**3. 损耗与退货：最容易模糊的地带**
水果在运输、卸货、仓储中都会损耗。建议：
- 明确交货方式（送货到门店/配送中心）和风险转移节点；
- 约定运输损耗率上限，超出部分由供应商承担；
- 区分“到货即发现的不合格”和“入库后短期变质”的责任归属，写清退货时限和举证方式；
- 避免笼统写“包退包换”，要限定品类、时限和条件。

**4. 账期与结算：现金流陷阱**
- 账期起算点要明确（到货验收合格日/对账确认日），避免超市无限拖延；
- 对账周期、发票要求、付款方式写清，约定逾期付款责任；
- 警惕“月结+季度返利+年终返利”叠加导致实际回款周期过长，供应商可能用降低品质来对冲。

**5. 返利、进场费、促销费：名目多、易争议**
- 年度返利按采购额还是按回款额计算、阶梯如何设、何时结算，必须写死；
- 进场费、条码费、促销推广费要列明项目和金额，避免“其他费用”开口子；
- 约定费用调整需双方书面确认，防止单方扣款。

**6. 供应保障与违约责任：只约束供应商不约束自己**
- 明确最低供货量/最高供货量、断供的违约责任和替代采购差价承担；
- 同时也要写超市的采购承诺（如最低采购量），否则供应商可能要求涨价或优先供别人；
- 违约金比例要合理，过高可能被认定无效，过低则没有约束力。

**7. 独家/排他条款与品类冲突**
- 是否约定独家供应、区域限制、禁止向竞品供货，要评估反垄断和实际执行风险；
- 明确供应商能否同时供其他渠道，避免“独家”变成供应商抬价筹码。

**8. 食品安全与追责**
- 明确供应商对农残、添加剂、腐烂变质导致的食物中毒或监管处罚承担赔偿责任；
- 要求提供检测报告、产地证明、承诺书，并约定抽检不合格的处罚和终止权；
- 约定召回配合义务和费用承担。

**9. 合同期限与退出机制**
- 年度合同要写清续约条件、提前终止情形（连续质量问题、断供、检测不合格等）；
- 约定终止后的库存处理、未结货款结算和过渡期供货安排。

**优先动作建议：** 签约前先做三件事——①按品类做一份质量规格附表，双方签字确认；②把价格联动公式和调价流程写成可操作的条款；③把损耗率、退货时限、账期起算点三个数字谈定并写入合同。这三项谈清楚，大部分年度合同纠纷可以提前规避。

需要提醒：以上是通用风险清单，具体条款还要结合当地法规（如食品安全、反垄断、格式条款）和双方实际交易习惯，重要合同建议由法务或专业律师审阅。
