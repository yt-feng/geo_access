商超会员日水果活动，供应商要配合的核心是：**提前把“货、价、陈列、履约、风险”五件事锁死**。可按下面清单准备：

1. **活动方案与销量预测对齐**
   - 提前7-15天与商超确认：活动日期、会员价/折扣力度、主推单品、限购规则、线上线下是否同享。
   - 按商超给的预估销量+安全库存（通常1.2-1.5倍）备货，明确断货补货责任。
   - 确认价格保护：活动价是否倒挂、费用谁承担、促销后是否恢复原价。

2. **货源与品质锁定**
   - 提前锁定产地/批次，优先安排活动前1-2天到货，避免久放。
   - 按商超验收标准做分级：糖度、果径、色泽、瑕疵率、农残检测报告。
   - 准备备选货源，防止天气、物流导致缺货。

3. **包装与陈列物料**
   - 按活动形式准备：散装陈列、预包装、礼盒、试吃装、爆款堆头。
   - 提供价签/ POP/爆炸贴/跳跳卡/试吃台物料的设计源文件或实物，并确认商超审核。
   - 预包装商品提前贴好条码、会员价签、生产日期/保质期。

4. **物流与到货履约**
   - 明确到货时间窗、卸货口、预约流程、冷链要求。
   - 活动前1天完成首配，活动期间安排日配/隔日配，避免门店断货。
   - 准备应急补货车辆和联系人，明确缺货响应时限（如2-4小时）。

5. **门店执行配合**
   - 提前给门店做单品卖点、试吃话术、陈列标准培训。
   - 安排导购/试吃人员，确认进场证、健康证、着装要求。
   - 活动首日安排巡店，检查陈列、价签、品质、库存。

6. **促销与费用确认**
   - 书面确认：供货价、活动扣点、陈列费、试吃损耗承担、赠品支持。
   - 明确结算方式与对账周期，避免活动后扯皮。
   - 如需商超线上渠道，提前提供图片、文案、规格、库存。

7. **风险预案**
   - 品质风险：活动前抽检，坏果包退换标准写清。
   - 断货风险：备选单品/替代规格，提前报备。
   - 价格风险：确认会员价不与其他渠道冲突。
   - 损耗风险：试吃损耗、临期处理、退货比例提前约定。

**最简执行版：** 活动前10天确认单品/价格/预估量；前5天锁货源和物料；前2天到货并完成门店陈列；活动首日供应商到场巡店；活动期间每日反馈库存和品质。
