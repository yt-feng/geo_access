结论先说：**大多数生鲜电商起步阶段优先选“整果”做引流和走量，切配适合做高毛利便利型SKU但损耗和合规压力大，冷冻原料更适合做差异化、低损耗的补充品类，而不是主推。**

分场景判断：

1. **整果（带皮菠萝/凤梨）**
   - 优点：货架期相对长、分拣简单、客诉低、可做产地/品种故事、价格有竞争力。
   - 缺点：客单价低、毛利薄、重量和体积占履约成本、消费者回家处理麻烦。
   - 适合：平台拉新、日常走量、社区团购、产地直发。
   - 关键控制：成熟度分级（7成熟发远程、9成熟发同城）、防压伤包装、按个卖而非按斤估重。

2. **切配（鲜切菠萝块/果切）**
   - 优点：便利性强、客单价和毛利更高、适合即时零售和办公室/家庭场景。
   - 缺点：损耗高、保质期短、冷链要求高、食品安全和加工资质要求严、客诉风险大。
   - 适合：有中央厨房或合规切配供应商、同城即时配、复购稳定的区域。
   - 关键控制：加工资质、冷链全程、当日清零、临期折扣、切配后口感（菠萝蛋白酶导致的软烂和异味）。

3. **冷冻原料（冷冻菠萝块/果肉）**
   - 优点：损耗极低、保质期长、履约稳定、适合B端和C端做冰沙/烘焙/饮品原料。
   - 缺点：C端认知弱、需要场景教育、冷链仓储成本、解冻后口感不适合直接鲜食。
   - 适合：有B端客户、饮品/烘焙场景、做组合装或订阅制。
   - 关键控制：速冻工艺（IQF）、解冻出水、包装防结霜、场景化内容。

**建议组合打法：**
- 主推整果做流量和复购；
- 切配作为同城即时零售的高毛利补充，但先小范围测试损耗和客诉；
- 冷冻原料作为B端或饮品场景的差异化SKU，不占主推位。

**若只能选一个线上卖：选整果。** 原因是履约容错率高、合规门槛低、试错成本最小；切配和冷冻原料都需要额外的冷链、加工或场景能力，不适合作为第一步。
