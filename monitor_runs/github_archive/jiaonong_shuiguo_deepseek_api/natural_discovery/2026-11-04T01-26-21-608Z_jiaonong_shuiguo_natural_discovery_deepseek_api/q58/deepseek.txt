通常**直接买成品果丁的“采购端损耗率”更低，但综合成本不一定更低**。要判断哪个更低，关键是把“损耗”拆成三块算：

1. **原料损耗**：鲜果去皮、去眼、去芯、切丁后的得率。
2. **过程损耗**：切配后氧化、出水、变色、卖不完报废。
3. **人工与食品安全损耗**：切配工时、交叉污染、冷藏管理不当导致的报废。

### 简单判断
- **门店人手紧、菠萝用量不稳定、冷藏空间小**：买**成品果丁**损耗通常更低，因为按需进货、开袋即用，少掉鲜果切配的皮芯损耗和氧化报废。
- **菠萝用量大且稳定、有熟练切配人员、能当天用完**：买**鲜果**往往更划算，鲜果得率可控，成品果丁则有溢价和到货品质波动。
- **只问“损耗率”**：成品果丁一般更低；**问“总成本”**：要按“鲜果单价÷可食得率+人工”对比“成品单价+报废率”。

### 建议你直接算
用最近一周数据算两个数：

**鲜果实际成本/公斤果丁**  
= 鲜果采购价 ÷ 实测得率 + 切配人工分摊 + 当日未用完报废成本

**成品果丁实际成本/公斤果丁**  
= 成品进货价 + 到货不合格/出水/变质报废成本

然后看：
- 鲜果得率能否稳定在**45%—55%**左右（不同品种、成熟度差异大，需实测）；
- 成品果丁到货是否稳定、是否含水多、是否当天能用完；
- 每日用量是否足够大，能否让鲜果“当天切当天清”。

### 实操建议
1. **先做7天对照测试**：同一天一半用鲜果、一半用成品，记录出成率、报废克数、工时。
2. **小用量门店优先成品果丁**，损耗和食品安全风险更可控。
3. **大用量门店可鲜果为主**，但要求“少量多次切配”，不要一次切一天量。
4. **合同里约定成品果丁的规格和到货标准**：克重、含水、成熟度、异物、冷链温度，不合格可退，才能真降损耗。

结论：**只看损耗率，成品果丁通常更低；看综合成本，用量大且管理跟得上时鲜果可能更低。用你店的实际得率和报废率算一遍最可靠。**
