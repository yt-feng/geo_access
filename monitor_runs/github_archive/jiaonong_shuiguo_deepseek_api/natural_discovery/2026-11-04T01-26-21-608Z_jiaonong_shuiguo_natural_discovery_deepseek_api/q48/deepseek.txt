判断菠萝供应商能否稳定按规格送货，重点不是看对方“有没有货”，而是看它有没有**分级、品控、排产和异常处理能力**。建议按下面几步做，能较快筛出靠谱供应商。

**1. 先把自己的规格写成可验收标准**
不要只说“要甜、要大”，要写成可检验项：
- 品种：如金钻凤梨/台农/巴厘，固定品种
- 单果重量区间：如1.2–1.5kg，允许偏差±5%
- 成熟度：如糖度12–14度、果眼转黄比例、无青果混装
- 外观：无黑心、无裂口、无机械伤、冠芽长度要求
- 包装：箱规、每箱净重、码放层数、托盘要求
- 到货温度/运输方式：常温还是冷链，运输时长上限
- 验收抽检比例和拒收规则：如抽检10%，不合格率超5%整批拒收或折价

规格越细，越能看出供应商是否真能接。

**2. 要求供应商提供“分级能力”证据**
问清并现场看：
- 是否有固定分级线或人工分级班组，日分级产能多少
- 同一批次内重量、成熟度如何分档，能否按你的区间单独备货
- 是否有催熟/预冷/保鲜处理能力，还是纯转手贸易
- 产地是自有基地、长期合作果园还是临时市场调货
纯贸易商在旺季容易“有什么发什么”，稳定性通常弱于有分级仓的供应商。

**3. 做小批量压力测试**
不要一上来签大单，先做3–5次小批量试单，且故意安排在不同周：
- 每次记录到货合格率、重量区间符合率、糖度抽检结果、破损率
- 看是否每次规格一致，而不是“第一次好、后面飘”
- 试单中提一次临时加量或提前/延后一天送货，看响应速度
这比看样品更有效，样品可以挑，连续交付很难伪装。

**4. 查它的排产和货源稳定性**
- 问清当前产季、产区、可供货周期，是否跨产区接力供货
- 你的周需求量占它该品类周出货量的比例，最好不超过20%–30%，避免你被它其他大客户挤掉
- 是否有备用产区/备用果园，遇到雨天、台风、节假日物流停运怎么补
- 旺季和节前能否签“保量协议”，而不是只签价格

**5. 把稳定性写进合同和验收流程**
- 约定周度/月度供货量、允许浮动比例、最低起送量
- 明确规格偏差处理：超重/欠重、成熟度不符、黑心率超标如何扣款或退货
- 约定缺货违约金或补货时限
- 每批留样，记录批次号、产地、采摘日期，出现问题可追溯
- 付款与验收挂钩，保留质量保证金或账期

**6. 看物流和到货一致性**
- 固定承运方还是临时找车，运输时长是否稳定
- 夏季是否有遮阳/通风/冷链措施，到货温度是否记录
- 卸货后抽检：同一箱内上下层是否一致，避免“上层好果、下层次果”

**简单判断口诀：**
能给你看分级现场、敢接小批量连续试单、有备用产区、愿意把规格和赔付写进合同的，稳定性通常较高；只强调价格低、样品好、但说不清分级和排产的，慎用。

对茶饮连锁来说，菠萝通常还要后续切丁/榨汁，建议额外加一项**出成率测试**：按你的加工方式测去皮去眼后的净果率，稳定性不只看到货合格，还要看每批出成率波动。
