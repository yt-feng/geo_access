采购菠萝时，**不要只看“熟没熟”，而要看“买回去后几天内会到最佳状态”**。水果店有陈列期和损耗压力，比较合适的做法是：

1. **按销售节奏分批次采购**
   - 快卖、当天下班前能卖掉的：可采**七八分熟到接近完熟**。
   - 要放2—3天卖的：采**六七分熟**，留后熟空间。
   - 不建议整批都采全熟，损耗会明显放大。

2. **看外观判断熟度**
   - **果皮颜色**：从青绿转黄，黄色面积越大越熟；但不要只追求全黄，青黄相间更适合短期存放。
   - **果眼**：果眼大而平、间隙变宽，通常成熟度较高；果眼紧密发青的更生。
   - **果形**：果身饱满、端正，不要选明显畸形、局部软塌的。
   - **冠芽**：叶片青绿有精神较好；冠芽枯黄萎缩往往存放偏久。

3. **闻气味**
   - 靠近果底闻：有清淡果香说明接近适售；**香味浓烈、发酸、发酵味**说明过熟或开始变质，采购时要压价或拒收。
   - 完全没香味的多为偏生，可少量搭配采购。

4. **按压手感**
   - 轻按果身有轻微弹性、不硬如石头，说明接近可售。
   - **局部发软、渗汁、凹陷**是过熟或碰伤，损耗高风险。
   - 整体过硬则偏生，适合计划后续几天销售。

5. **看果底和切口**
   - 果底干净、干燥、无霉点。
   - 有汁液渗出、发黑、霉斑、酒味，说明已过熟或腐烂，不要采。

6. **采购比例建议**
   - 当天现切或促销走量的：约**20%—30%接近完熟**。
   - 主体库存：**六七分熟、青黄相间**。
   - 少量偏生作为后备：约**10%—20%**，根据门店客流调整。
   - 夏季高温后熟快，整体熟度要下调；冬季可适当提高。

7. **到店后马上分级**
   - 全黄、香味明显的放前排当天卖或做果切。
   - 青黄相间的放后排周转。
   - 有软伤、异味的立即隔离处理，避免传染和扩大损耗。

核心原则：**采购熟度要匹配你的周转天数，而不是追求“最甜最好看”。** 对水果店来说，最佳采购状态通常是**青黄相间、果香清淡、果身略弹但不软塌**。
