社区超市找日配水果供应商，重点不只是“便宜”，而是每天能不能稳定、按品质、按时送到。建议按下面条件逐项看：

**1. 日配能力**
- 是否每天固定配送，节假日、雨天、临时补货能否安排。
- 配送时间是否匹配开店前上架，比如早上6—8点前到店。
- 最小起订量、起送价、临时加单截止时间。
- 配送范围是否覆盖你门店，车程多久，是否冷链车或保温箱。

**2. 货源稳定性**
- 是否有稳定产地、批发市场档口或一级代理，不要只看二级倒手。
- 能否提供当日或近两日批次信息：产地、规格、等级、采摘/到货时间。
- 换季和节日期间是否有替代品方案，避免断货。
- 同一单品能否长期稳定供应，而不是今天有明天没。

**3. 品质标准**
- 明确等级、规格、净重/毛重、允许损耗率，写进供货标准。
- 看样品和实际到货是否一致，重点看成熟度、大小均匀度、伤果烂果比例。
- 叶菜、浆果、热带水果是否分开温区配送。
- 包装是否适合社区店小批量上架，避免大箱拆零损耗。

**4. 价格与结算**
- 报价是否含运费、包装费、卸货费。
- 价格随行就市时，提前约定调价通知时间和参考市场。
- 是否有阶梯价、临期/尾货处理价、破损补货规则。
- 账期、押金、退换货结算方式要清楚。

**5. 售后与损耗**
- 坏果、短斤少两、到货不新鲜怎么赔：补货、换货还是扣款。
- 报损时限和拍照留证要求，避免扯皮。
- 缺货、迟到、品质波动的违约责任。
- 是否支持小批量多品种混配，适合社区店试销。

**6. 试合作方式**
先别签长约，建议：
- 先试配1—2周，每天记录到货时间、损耗率、缺货次数、客诉。
- 同时保留1家备选供应商，防止单一依赖。
- 用“到货合格率、准时率、损耗率、补货响应”四个指标评估。

**实操判断标准：**
连续7天配送准时率≥95%，到货损耗率控制在约定范围内，缺货能提前通知并有替代方案，售后当天响应，才适合做长期日配供应商。合同里把品质标准、损耗赔付、配送时间和违约条款写清楚，比单纯压价更重要。
