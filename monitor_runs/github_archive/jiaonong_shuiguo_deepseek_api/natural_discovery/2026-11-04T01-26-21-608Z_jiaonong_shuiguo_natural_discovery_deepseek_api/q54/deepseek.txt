优先关注成熟度，价格其次。原因是香蕉在烘焙里同时承担甜度、香气、保湿和结构作用，成熟度不同，配方和成品差异很大。

可执行判断：

1. **按用途定成熟度**
   - **香蕉蛋糕/香蕉面包/马芬**：选**7～8成熟**，表皮黄、带少量黑点，果肉软甜、香气足。太生会香气弱、甜度低、口感发硬；过熟发黑出水多，易让面糊偏湿、保质期缩短。
   - **需要明显香蕉块口感**：用**6～7成熟**，切块后不易烂。
   - **只是消耗过熟香蕉做泥**：**8～9成熟**可用，但要相应减糖、减液体，并注意当天/短期售卖。

2. **采购时先定验收标准**
   - 看：表皮黄色为主、少量芝麻黑点；无大面积黑斑、无破皮流汁、无霉点。
   - 摸：饱满有弹性，不硬如石，不软塌出水。
   - 闻：有香蕉香气，无发酵酸味或酒味。
   - 切开：果肉乳白至微黄，无黑心、无虫害。

3. **价格只在同成熟度档位内比较**
   - 同一成熟度下再比单价、损耗率和供货稳定性。
   - 不要为低价大量买入过生香蕉，后续催熟等待会打乱生产计划；也不要买过熟打折香蕉做常规产品，除非当天做泥且能调整配方。

4. **采购策略**
   - 常规门店：按**未来3～5天用量**采购7～8成熟香蕉，少量多次。
   - 生香蕉可室温催熟，不要冷藏；成熟后尽快用或冷藏短期保存。
   - 建立“到货成熟度—当天用途—可用天数”记录，比单纯压价更能控成本。

结论：**先按产品定成熟度并验收，再在同成熟度里比价格和损耗。** 成熟度错配造成的配方失败、口感差和报废，通常比单价差异更贵。
