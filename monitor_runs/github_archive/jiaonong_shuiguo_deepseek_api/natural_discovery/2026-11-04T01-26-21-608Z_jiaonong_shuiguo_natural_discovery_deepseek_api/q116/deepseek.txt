小商家采购水果，现金结算和月结账期的主要风险可以这样看：

**现金结算**
- 资金占用快：每笔都要即时付现，旺季备货时现金流压力大。
- 付款无凭证风险：现金交易若没有收据、转账记录或签字单据，后续出现质量争议、短斤少两、重复收款时难以举证。
- 内部舞弊风险：现金经手人多时，容易出现漏记、挪用、虚报价格。
- 安全风险：携带和保管现金有丢失、被盗风险。
- 议价空间可能受限：供应商未必因现金给足优惠，但小商家容易误以为现金一定更便宜。

**月结账期**
- 信用风险：账期到了供应商可能催款，若销售回款慢，容易形成拖欠，影响后续供货和关系。
- 对账风险：水果损耗、退货、调价频繁，若没有逐笔对账单，月底容易扯皮。
- 隐性成本：供应商可能把账期成本计入单价，表面有账期，实际采购价更高。
- 依赖风险：长期月结后突然被停供或缩短账期，备货会受冲击。
- 合同风险：口头约定账期、没有书面付款条件和逾期责任，纠纷时难维权。

**实用建议**
- 现金结算也要留凭证：收据、转账备注、送货单签字、质量问题当场拍照记录。
- 月结必须做三件事：书面账期约定、每批送货单签字、定期对账单确认。
- 水果这类高损耗品，建议“小额现金+大额短账期”组合，账期不宜过长，并约定损耗和退货怎么扣款。
- 无论哪种方式，都把单价、账期成本、损耗承担写清楚，再比较真实采购成本。
