节假日水果需求暴增，核心是**提前把"量、价、质、到货时间"四件事锁死**。可以按下面几步做：

## 1. 先做需求预测，别凭感觉备货
- 用近2-3年同节假日的**单品销量、客单价、损耗率**做基线，按门店分级（大店/社区店/乡镇店）给不同备货系数。
- 重点抓**节日礼盒果、易爆单品**（如车厘子、阳光玫瑰、砂糖橘、榴莲、苹果礼盒），这些是缺货和涨价的重灾区。
- 提前2-4周把预测单发给采购，留出锁货窗口。

## 2. 提前锁货源：合同+定金+分批到货
- **提前签约锁量锁价**：对核心单品与主供应商签节日保供协议，约定数量、价格区间、质量标准、违约条款。
- **付定金锁产能**：产地直采的，提前打定金锁定果园/合作社的货，避免节前被高价截胡。
- **分批到货**：不要一次性压到节前3天，按"节前7天—节前3天—节中补货"分批次，降低损耗和仓储压力。
- **多源备份**：每个核心单品至少2个供应商（主供+备供），主供在产地、备供在批发市场或周边基地。

## 3. 拓宽采购渠道，别只靠一个批发市场
- **产地直采**：节前量大单品直接对接产区合作社/基地，价格和量更可控。
- **区域批发市场**：作为补货和应急渠道，节前锁定几个稳定档口。
- **供应商联合备货**：让供应商按你的预测提前备货到其仓，约定节前定时配送。
- **进口果提前订柜**：车厘子、榴莲等进口单品周期长，要提前下单锁船期/柜期。

## 4. 物流和仓储要提前排
- 节前运力紧张，提前和物流方**锁定车辆和时段**，约定到店时间窗口。
- 冷库/保鲜库提前腾仓，易损耗单品控制单店库存天数。
- 制定**节日补货节奏表**：哪天到哪些店、补哪些品、谁负责。

## 5. 设定应急预案
- 价格波动预案：约定价格上限或调价机制，避免节前被临时加价。
- 缺货预案：备供供应商48小时内补位，或用替代单品顶上堆头。
- 质量预案：到货验收标准前置写进合同，不合格拒收/换货条款明确。

## 6. 门店端配合
- 节前把陈列、堆头、礼盒位提前规划，避免到货后没位置。
- 控制单店备货深度，宁可节中补货，不压太多损耗。

**一句话总结**：提前2-4周做预测，用"合同锁量锁价+定金锁产地+分批到货+双供应商备份+锁运力"把货源钉死，再配一套缺货和价格应急方案。这样节假日爆量时才有货可卖、有价可控。
