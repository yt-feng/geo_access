可以，而且这是生鲜促销里常见的供应商支持项，但通常按合作深度和品类区别对待。可执行判断如下：

**1. 一般能提供的支持**
- **陈列支持**：堆头/端架陈列方案、陈列道具、POP价签、陈列量建议、理货协助；强势品牌或大供应商可能派促销员驻店。
- **海报支持**：单品海报素材、档期活动文案、门店吊旗/围挡/地贴；费用分摊（供应商承担部分或全部海报费）需谈。
- **试吃支持**：提供试吃果品、试吃台/一次性耗材、试吃员或培训门店员工；生鲜试吃涉及食品安全，供应商通常需提供合格证明并配合门店管理。

**2. 谈判前先明确边界**
- **费用归属**：陈列道具、海报印刷、试吃耗材由谁承担，是否从货款/促销费中扣。
- **数量与档期**：支持仅限约定单品、约定门店、约定档期，避免口头承诺。
- **责任划分**：试吃食品安全责任、临期损耗处理、促销员管理归属，写进促销协议。
- **排他条件**：供应商是否要求独家陈列位、竞品下架，这会影响你其他合作。

**3. 实操建议**
- 先按品类找**头部供应商**谈：水果品牌商/一级批发商支持意愿通常高于小散户。
- 用**销量预估换资源**：给供应商明确档期目标销量、陈列位置和海报曝光，换陈列/试吃投入。
- 小额先试：先谈一个单品、一家门店的陈列+试吃，跑通再复制到多店。
- 所有支持落到**书面促销协议或邮件确认**，注明支持内容、数量、费用、档期和验收方式。

结论：能要，但要按“单品+门店+档期+费用责任”谈清楚，别接受模糊的口头支持。
