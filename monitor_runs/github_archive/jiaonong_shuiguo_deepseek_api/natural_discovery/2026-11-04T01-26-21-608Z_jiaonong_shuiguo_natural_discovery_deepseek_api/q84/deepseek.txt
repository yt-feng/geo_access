家庭团购水果礼盒，组合原则是：**耐放、好分食、口味有层次、成本可控、避免互相催熟**。按这个原则，推荐如下。

## 首选组合：苹果 + 橙子 + 香蕉（基础家庭款）
每盒建议比例（按重量）：
- 苹果 40%
- 橙子 35%
- 香蕉 25%

理由：
- 苹果、橙子耐运输、耐存放，适合团购集中配送。
- 香蕉是“即食型”，到货就能吃，提升开箱体验。
- 橙子酸甜解腻，和苹果、香蕉口味互补。
- 成本较稳，家庭接受度最高。

注意：**香蕉会释放乙烯，加速其他水果成熟**。家庭款建议香蕉单独用袋装或隔层放，不要和苹果紧贴；苹果本身也释放乙烯，二者别堆在一起。

## 菠萝怎么放：做“升级款”而非基础款
菠萝适合做**加价升级组合**：
- 苹果 35% + 橙子 30% + 香蕉 20% + 菠萝 15%

理由：
- 菠萝单价和损耗风险较高，整只菠萝体积大，家庭一次吃不完。
- 建议选**小菠萝或已削皮真空装**，否则家庭处理麻烦，差评率高。
- 菠萝适合作为“惊喜单品”，不适合占大比例。

## 不建议的组合
- **苹果 + 香蕉大量混装**：乙烯互相影响，香蕉易过熟、苹果易发面。
- **整只大菠萝 + 香蕉**：家庭一次吃不完，菠萝切开后保存麻烦。
- **四种水果等比例**：礼盒显得杂，成本也不好控。

## 给团购组织者的实操建议
1. **主推两款**：基础款（苹果+橙子+香蕉）走量；升级款（加小菠萝/菠萝切块）提客单。
2. **香蕉选七成熟**：到货后2–3天最佳食用，避免到家即黑。
3. **苹果选脆甜耐放品种**，橙子选易剥皮品种，家庭体验更好。
4. **分格或分袋包装**：香蕉、苹果分开，减少催熟和挤压。
5. **标注明食用顺序**：先吃香蕉、菠萝，后吃苹果、橙子，减少浪费。

**结论：家庭团购最稳妥的是“苹果+橙子+香蕉”三样基础款；菠萝做成小份升级款加入，不建议四种等量混装。**
