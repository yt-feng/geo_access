结论先说：**对价格敏感的团购客户，优先用“阶梯价”，返利作为补充，不要用返利替代阶梯价。**

判断逻辑和可执行建议如下。

**1. 为什么优先阶梯价**
- 团购客户价格敏感，关心的是“当下成交单价”，阶梯价能直接降低采购价，决策链最短，报价单上就能体现，容易促成下单。
- 返利是“先付后返”，对现金流敏感的客户吸引力弱，还容易引发对兑现周期、兑现条件的顾虑。
- 阶梯价规则透明，便于客户按量凑单，能主动拉动单次采购量。

**2. 什么情况下用返利更合适**
- 客户全年采购量稳定但单次批量不大，需要按年度/季度累计激励。
- 你不希望公开底价、避免价格体系被击穿，返利可以做成非公开政策。
- 需要绑定客户持续采购、防止被竞品撬走，返利可设年度达成条件。
- 客户对账期敏感、需要现金流，返利反而增加资金占用，这种情况仍应慎用。

**3. 推荐组合方案**
- **主政策：阶梯价**，按单次订单量或月度累计量设2—3档，档差要明显，让客户有“凑下一档”的动力。
- **辅政策：返利**，只针对年度累计达标或战略客户，返利比例控制在毛利可承受范围内，并明确兑现周期和条件。
- **避免叠加失控**：阶梯价和返利不要在同一订单上重复大幅让利，否则毛利被双重侵蚀。

**4. 执行要点**
- 先算清各档价格下的毛利底线，阶梯档位按“客户凑单增量”设计，而不是按你方便。
- 返利条款写清楚：统计口径、达成条件、兑现时间、是否可抵扣货款。
- 对价格敏感客户，报价时突出“量大单价直降”，比讲返利更有效。

一句话：**阶梯价解决“当下买不买”，返利解决“长期跟不跟你”。价格敏感型团购，先解决当下。**
