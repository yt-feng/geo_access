你好。批发商想用合同条款控损耗，核心思路是：**把“坏果”从笼统概念拆成可测量的验收标准 + 分级责任 + 时限证据链**，否则条款写了也难执行。下面给你可直接落到合同里的写法和要点。

**一、先定“什么算坏果”（缺这个，后面全扯皮）**
在合同附件里列明品类级标准，例如：
- 腐烂、霉变、软烂出水：整果计坏；
- 机械伤、裂口、压伤：按面积/深度定档（如单果损伤面积≥X%计坏）；
- 虫害、病斑：单果病斑≥X%计坏；
- 规格不符（大小、成熟度）单独列“降级/折价”，不混入坏果率。
建议约定：**抽样方法**（随机抽N箱、每箱抽N果或按重量比例抽）、**坏果率计算式**（坏果重量÷抽样总重量），并写明“以抽样结果推定整批”。

**二、责任按“损耗区间”分级，不搞一刀切**
可写成阶梯条款，例如：
- 坏果率≤A%：买方自担（合理自然损耗）；
- A%＜坏果率≤B%：超出A%部分按货值折价扣款；
- 坏果率＞B%：买方有权拒收该批或要求换货，运费/装卸费由卖方承担；
- 若因卖方包装、预冷、采摘成熟度不当导致，卖方承担超出部分及直接处置费。
注意：**扣款基数**写清楚（按该批货值、按超出部分货值），避免“按全车货值扣”的争议。

**三、把“到货时点”和“证据”写死**
- 验收时限：到货后X小时内完成抽检并书面通知，逾期视为验收合格（对批发商有利但也要合理，否则易被认定格式条款无效）；
- 通知方式：书面/微信/邮件+照片视频，注明“坏果照片需含箱号、批次、时间水印”；
- 共同复检：争议时双方委托第三方或共同开箱复检，费用由责任方承担；
- 留样：保留抽样样品至结算后N天。

**四、运输与风险转移要配套**
明确**风险转移点**：是装车、到货还是卸货后。若卖方负责运输，约定温控/时效要求及违反时的责任；若买方自提，坏果责任按装车验收结果划分。**保险**条款也写上：谁投保、理赔款归属。

**五、可执行的兜底条款**
- 卖方对“隐蔽性腐烂”（到货后24—48小时内显现）承担举证责任倒置：卖方需证明装车时合格；
- 累计坏果率超阈值可触发**整批退货/解除该批次订单**，并约定违约金或损失赔偿上限；
- 结算时预留**质量保证金**（如货款的5%—10%），验收期满无争议再付。

**实操建议**：合同正文只写原则，把“品类坏果标准表、抽样规则、分级扣款表”放附件并由双方签字确认；首次合作先小批量试单，用实际抽检数据校准A%、B%阈值。这样条款既能保护你，也不至于因标准过苛被对方拒绝或日后被认定显失公平。
