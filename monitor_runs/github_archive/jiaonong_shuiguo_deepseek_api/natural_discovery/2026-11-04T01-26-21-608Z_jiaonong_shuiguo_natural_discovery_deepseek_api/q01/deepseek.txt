判断水果供应商靠不靠谱，核心看四件事：货稳不稳、价实不实、人守不守信、出了问题是补货还是扯皮。下面按你可以直接执行的顺序说。

**1. 先小批量试单，不要一次押大**
- 连续试3～5次，每次只订你1～2天能卖完的量。
- 观察：到货时间是否准时、重量是否足、坏果率多少、规格是否和样品一致。
- 香蕉重点看：青黄度是否适合你店里的周转速度、催熟是否均匀、有没有“外表好里面黑心”。
- 菠萝重点看：成熟度是否一致、有没有黑心、烂心、运输压伤，叶冠是否新鲜。

**2. 用数据验货，不靠感觉**
每次到货做简单记录：
- 实际净重 vs 订货重量，差多少。
- 抽箱检查坏果/压伤比例，香蕉看梳把整齐度、菠萝看果眼和底部。
- 到货时间、温度、包装是否完好。
- 连续记录一个月，坏果率经常超过你承受范围、重量经常不足的，直接淘汰。

**3. 看价格是否“可解释”**
- 问清楚报价含不含运费、装卸费、包装费、损耗补货。
- 对比2～3家同规格报价，长期合作价应随行就市，不是今天特别低、明天突然高。
- 警惕明显低于市场价的报价，通常会在重量、等级、熟度或坏果补货上找回来。

**4. 看响应和售后**
故意在一次到货后反馈问题，比如“这箱菠萝有压伤/香蕉熟度偏了”，看对方：
- 是否及时回复；
- 是否承认并给出补货、折价或下次抵扣；
- 是否推给运输、推给你存放问题。
长期合作最怕的不是偶尔出问题，而是出问题不认。

**5. 看供货稳定性**
- 问他香蕉、菠萝的主产地和替代货源。只靠一个产地、一个批次的供应商，遇到天气或行情波动容易断货或涨价。
- 问清楚旺季淡季的供应能力，能不能提前一天确认次日货。
- 观察他给其他水果店供货是否频繁断货、临时换规格。

**6. 看合同和结算方式**
- 长期合作要有简单书面约定：品种规格、等级、单价随行就市机制、送货时间、验收标准、坏果补货比例、结算周期。
- 刚开始尽量短账期或现结，稳定后再谈账期。不要因为对方给账期就放松验货。
- 保留每次订单和验货记录，出现问题时有依据。

**7. 几个红旗信号**
- 报价明显低于市场且不愿解释；
- 不让看样品或样品和到货不一致；
- 每次重量都“刚好”偏少一点；
- 坏果补货总拖到下次、下次又拖；
- 催你大额预付或长期压货；
- 只有口头承诺，不愿写基本规格和验收标准。

**最实用的做法：** 同时保持2家供应商，一家主供、一家备供，各试一个月。用“到货准时率、净重足称率、坏果率、问题响应速度”四项打分，谁稳定就给谁加量。不要只看谁价格低，长期看“稳定+售后”比每箱便宜几块钱更重要。
