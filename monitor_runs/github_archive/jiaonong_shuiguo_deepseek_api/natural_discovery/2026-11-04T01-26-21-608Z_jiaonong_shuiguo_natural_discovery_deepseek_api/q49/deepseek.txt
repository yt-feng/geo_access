旺季临时补货的核心是把“临时”变成有约束的短周期协议，而不是口头加单。建议按以下要点和供应商约定：

**1. 先定补货机制，而不是只谈量**
- 约定旺季临时补货的触发条件：如周用量超过平时X%时启动。
- 约定下单方式：每天固定时点前发次日/后日需求，供应商在X小时内确认。
- 约定最低补货量和加急起订量，避免小单频繁配送。

**2. 锁量不锁死，设弹性区间**
- 给供应商一个旺季周度预估量，并约定±15%～20%的弹性浮动。
- 超出弹性上限的部分，供应商可协商排期，但你保留优先供货权。
- 明确“临时补货不挤占已确认的常规订单”。

**3. 价格和费用写清楚**
- 临时补货单价是否与常规价一致；若加急，加价上限多少。
- 配送费、装卸费、冷链费谁承担，临时单是否另收。
- 旺季价格调整需提前X天书面通知，不能随单涨价。

**4. 品质与验收标准不放松**
- 明确菠萝规格（品种、单果重量、成熟度、去皮/带皮）、糖度范围、外观要求。
- 约定到货验收：抽检比例、不合格处理（拒收/换货/折价）和补货时限。
- 临时补货同样适用原质量标准，不能以“加急”为由降级。

**5. 违约和保障条款**
- 供应商未按确认量供货的，约定违约金或优先赔付方式。
- 你方临时取消订单的提前通知时限和费用。
- 约定不可抗力、产地减产时的替代方案和通知义务。

**6. 用书面形式固定**
- 签一份旺季补充协议，附周度预估量、价格表、验收标准、联系人及响应时限。
- 日常加单用微信/邮件确认也可，但要在协议里写明“书面确认形式包括哪些”。

**可执行做法：** 先统计过去2～4周实际用量，算出旺季周均和峰值，带着数据找供应商谈“周度锁量+日补货+弹性区间”。第一次合作先跑两周小批量临时补货，验证响应速度和品质，再扩大承诺量。
