# 水果到货不合格：补货条款怎么约定才不耽误营业

核心思路是**把"不合格"判断标准前置、把补货时限写死、把现场处置权交给门店**，避免到货后扯皮、等总部审批、断货停售。

## 一、先约定"不合格"的判定标准（最关键）

验收争议多发生在"算不算坏"上。建议在采购/供货合同里写明：

- **量化指标**：如腐烂率≤3%、压伤果≤5%、单果重量区间、糖度下限（如西瓜≥10度）、外观（无霉斑、无虫蛀）。
- **抽样规则**：按批次随机抽检，抽检不合格即整批可退，避免"只退坏的几个"导致营业中断。
- **判定主体**：门店店长/值班主管现场判定即可，**不需供货方到场确认**；有争议时以门店留存照片/视频为准。

## 二、补货时限：按"营业恢复"倒推

不要写"尽快补货"这类软表述，建议写死：

| 情形 | 补货时限 |
|---|---|
| 常规不合格 | 当日营业结束前或次日营业前送达 |
| 影响主推/爆款产品 | 4小时内或当日首波客流前送达 |
| 紧急缺货 | 门店可先就近采购，凭小票向供货方报销 |

## 三、给门店"应急采购权"

这是最实用的条款：**不合格批次退货后，门店有权就近以市场价采购同等品质水果应急，差价由供货方承担或在货款中扣减**，无需事先审批。这样即使补货迟到，营业也不断。

## 四、罚则与结算挂钩

- 补货超时：按该批次货款的X%（如20%）扣减，或按停售时段营业额损失赔偿。
- 同一供应商月度不合格≥2次：门店可单方更换供应商、终止合作。
- 退货货款在当期结算中直接扣除，不拖到下一账期。

## 五、书面留痕

补货约定要落到**书面合同或供货确认单**上，每次到货验收拍照留存（带时间水印），补货沟通走微信/系统订单留痕，避免口头承诺无法追责。

**一句话总结**：标准量化 + 时限死磕 + 门店可自行应急采购 + 罚则挂货款，这四条写进合同，补货就不会拖垮营业。
