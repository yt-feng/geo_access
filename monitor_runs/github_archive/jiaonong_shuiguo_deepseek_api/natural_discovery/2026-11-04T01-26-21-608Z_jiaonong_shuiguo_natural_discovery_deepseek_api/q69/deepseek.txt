可以按“等级看外观、报价看规格、结算看损耗”三层来做，批发商和小店都容易对照，不容易扯皮。

**一、先定分级标准（香蕉、菠萝分开）**

**香蕉建议分3级：**
- A级：果指长短整齐、果皮无黑斑或极少、无机械伤、无裂果，成熟度统一（比如7成熟发货）。
- B级：果指略不均、少量表皮擦伤或轻微斑点、不影响剥皮食用，成熟度允许略有差异。
- C级：长短不齐、明显黑斑/压伤/裂口、适合当天促销或加工，不适合正常陈列。

关键要把“成熟度”写进等级：例如香蕉按“青果/微黄/黄熟”标注，不然A级黄熟和A级青果价格不能一样。

**菠萝建议分3级：**
- A级：单果重量区间稳定、果形端正、无裂口、无软烂、冠芽完整、成熟度一致（如8成熟）。
- B级：果形略偏、轻微日灼或小擦伤、单果重量略偏离标准，但果肉正常。
- C级：裂口、软果、明显碰伤、冠芽残缺，适合当天切果或促销。

菠萝必须把“单果重量区间”作为报价单位，比如A级按“每箱几个、单果几斤”报，不要只说大中小。

**二、报价表要统一口径**

每档报价至少写清6项：
1. 品名和等级（香蕉A/B/C，菠萝A/B/C）
2. 规格：香蕉按每箱重量/每把几根；菠萝按每箱个数+单果重量区间
3. 成熟度：青果/微黄/黄熟，菠萝几成熟
4. 包装：箱装/筐装，净重还是毛重
5. 单价：元/箱或元/斤，明确按净重结算
6. 损耗和售后：比如“开箱验货，坏果超过X%按个数补，签收后X小时内报损”

**三、给小店看的报价示例（文字版）**

香蕉：
- A级黄熟，净重18斤/箱，果指均匀无黑斑，XX元/箱
- B级微黄，净重18斤/箱，少量表皮擦伤，XX元/箱
- C级黄熟，净重18斤/箱，有斑点压伤，适合促销，XX元/箱

菠萝：
- A级，8成熟，每箱6个，单果2.5—3斤，XX元/箱
- B级，8成熟，每箱6个，单果2—2.5斤或果形略偏，XX元/箱
- C级，熟度偏高或有小裂口，每箱6个，XX元/箱，建议当天售

**四、执行建议**
- 第一次合作先做“样品对照”：每级各拿一箱，小店现场看货再下单。
- 报价单上不要只写“统货价”，统货也要注明“含坏果率约X%”，否则售后容易争。
- 同一等级内，香蕉按成熟度再分青/黄两档，菠萝按单果重量再分档，价格会更清楚。
- 结算时以净重和开箱验货为准，报损时限写死，比如“签收2小时内报损，拍照留证”。

这样分级和报价，小店能按等级和规格直接比价，批发商也能把成熟度、重量、损耗责任说清楚。
