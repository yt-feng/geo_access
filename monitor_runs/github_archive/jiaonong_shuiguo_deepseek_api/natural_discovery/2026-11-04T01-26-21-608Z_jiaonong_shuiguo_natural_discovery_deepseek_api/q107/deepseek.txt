会，而且香蕉和菠萝的风险点还不一样。起订量过高通常会放大损耗，尤其在这两类水果上：

**香蕉**
- 香蕉是呼吸跃变型水果，后熟快，到货后销售窗口短；起订量过高容易造成集中后熟、来不及卖完。
- 温度、乙烯积累和堆压都会加速变黄、发黑、软烂。
- 若采购的是青蕉，还需考虑催熟节奏；量大但催熟/出货能力跟不上，损耗会明显上升。

**菠萝**
- 菠萝虽然比香蕉耐放一些，但起订量过高会带来仓储堆压、通风不良和过熟问题。
- 菠萝对低温较敏感，冷库温度不当易出现冷害、黑心；常温堆放过久也会腐烂。
- 整箱起订量高时，尾货和外观瑕疵品更难及时消化。

**判断建议**
1. 用“日均销量 × 补货周期 × 安全系数”倒推起订量，而不是只看供应商门槛。
2. 香蕉建议少量高频补货，控制单批到货量在能于后熟窗口内售完的范围内。
3. 菠萝可适当批量，但要确认仓储通风、温度和周转天数。
4. 若起订量明显高于周销量，优先谈拆分起订、混柜拼单、分批发货或代储。
5. 把损耗率、尾货折扣和仓储成本算进采购总成本；起订量带来的单价优惠若低于预期损耗，就不应接受。

简言之：**会增加损耗风险，香蕉更敏感、菠萝更依赖仓储条件；起订量应以周转能力为上限，而不是以供应商门槛为下限。**
