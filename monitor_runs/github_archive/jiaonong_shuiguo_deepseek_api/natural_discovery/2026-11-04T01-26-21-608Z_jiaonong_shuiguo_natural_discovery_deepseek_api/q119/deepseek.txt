水果生意想长期稳定，选供应商时最容易忽视的不是价格和账期，而是那些“平时不出事、一出事就断货或砸口碑”的细节。重点看这几项：

1. **同一品质的稳定性，而不是样品品质**  
   很多供应商样品很好，但批量供货波动大。要看他能否按你的标准分等级、能否长期保持一致，而不是每次靠“挑好货”。

2. **产地与货源组织能力**  
   问清楚是自有基地、合作基地还是市场代采。代采型供应商在行情紧张时容易先保大客户或直接涨价断供。长期合作要看他在产地有没有稳定关系。

3. **损耗责任怎么分**  
   最容易忽视的是“到货后多久内可反馈”。水果损耗有隐蔽性，比如箱内压伤、底层烂果、成熟度不均。要提前约定验收时限、抽检比例、赔付方式，别等出了问题再扯皮。

4. **成熟度和货架期的匹配**  
   供应商只按“甜不甜”供货不够。你要根据销售速度选成熟度：走量快可以要熟一点，走量慢必须偏生。忽视这一点，会出现“货很好但卖不完就烂”的亏损。

5. **包装和运输细节**  
   同样一批货，纸箱抗压、内衬、冰袋、装车方式不同，损耗差别很大。要看供应商是否按品种和距离做包装，而不是一套包装发全国。

6. **季节切换和替代方案**  
   长期稳定不能只靠一个单品一个产地。要问供应商在换季、减产、天气异常时有没有替代产区或替代品种，能否提前预警。

7. **结算之外的隐性成本**  
   低价供应商可能通过缺斤少两、等级混装、运费另算、损耗不赔把利润吃回去。要算“到店可售成本”，不是只看采购单价。

8. **信息透明度**  
   愿意让你了解产地、批次、采摘时间、检测情况的供应商，通常更可控。什么都不愿说、只催下单的，长期风险高。

9. **应急响应能力**  
   临时补货、节假日备货、突发质量问题处理，最能看出供应商是否可靠。合作前可以用一次小批量急单测试。

10. **是否只把你当“消化库存的渠道”**  
    长期供应商应该能根据你的销售数据建议进货节奏，而不是总想压货给你。压货型合作短期便宜，长期容易造成高损耗和资金占用。

实操建议：先小批量合作1—2个产季周期，固定验收标准，记录每批到货损耗率、可售率、投诉率。连续3—5批稳定，再谈账期和独家政策。最容易忽视的核心一句话：**不要只看他能不能供好一批货，要看他能不能在行情波动、天气异常、你临时要货时，仍然按标准稳定供。**
