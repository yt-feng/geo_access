超市向水果供应商拿货，常见账期大致分三档：

- **7～15天**：最常见于叶菜、浆果、鲜切水果等**高损耗、短保鲜**品类，或中小超市、区域供应商。
- **30天**：比较主流的月结账期，适合苹果、梨、柑橘、香蕉等耐储水果，也是不少超市的标准采购条件。
- **45～60天**：多见于大型连锁超市、强势渠道对供应商的账期，或供应商议价能力弱、想换取稳定销量的情况。

实际谈判时可参考这些判断：

1. **按品类定账期**：易腐水果账期短，耐储水果可长；不要全店一刀切。
2. **看供应商规模**：小供应商现金流紧，15～30天更现实；大供应商可接受30～45天。
3. **看合作阶段**：新供应商首单建议现款或7～15天，稳定后再拉长到30天。
4. **用账期换条件**：账期拉长到45～60天时，通常要对应更低采购价、更高返利或促销支持，否则供应商会把资金成本折进报价。
5. **注意行业惯例**：生鲜行业账期普遍短于包装食品和日用品，60天以上在水果品类中不算普遍，容易影响供货稳定性。

如果问“比较常见且双方都能接受”的答案：**30天月结最主流；高损耗水果7～15天更常见；大型连锁压到45～60天也有，但不建议作为中小超市的默认条件。**
