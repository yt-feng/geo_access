建议在采购/供货合同或到货验收单里把“品相不好”拆成可判定标准和固定动作，避免售后靠扯皮。可按下面约定：

1. **明确验收标准**
   - 到货后 **2小时内**（或双方约定时限）完成验收并拍照/视频留证。
   - 按品类写清可接受范围：大小、色泽、成熟度、碰伤/压伤/腐烂比例、畸形果比例、包装破损等。
   - 例：同批次腐烂率≤3%、明显压伤≤5%、不符合等级比例≤5%为合格；超过即触发售后。

2. **约定分级处理**
   - **轻微不符**：折价接收，按不合格比例扣款。
   - **中度不符**：部分退货/换货，供应商在 **24小时内**补货或退款。
   - **严重不符**（腐烂、异味、大面积压伤）：整批拒收或全退，供应商承担运费/损耗。

3. **固定售后流程**
   - 到货验收→拍照留证（整批、问题部位、称重/计数）→ **2小时内**书面通知供应商→供应商 **4小时内**响应、**24小时内**给出换货/补货/退款方案→逾期视为认可超市方处理意见。
   - 换货补货到店后重新验收，仍不合格可终止该批次并索赔。

4. **费用与责任**
   - 因品相问题产生的退货物流费、销毁费、档期损失由供应商承担；可约定违约金或按批次货款比例扣减。
   - 生鲜易腐品建议约定“先处理后补单”，避免拖延导致证据灭失。

5. **留证与对账**
   - 验收单双方签字，照片带时间水印；售后处理结果写入对账单，作为扣款依据。
   - 每月汇总不合格率，连续超标可约定调整供货资格或扣减保证金。

一句话：**把“品相”量化成比例，把验收和通知时限写死，把折价/换货/退货/费用承担对应到具体情形**，售后就有可执行依据。
