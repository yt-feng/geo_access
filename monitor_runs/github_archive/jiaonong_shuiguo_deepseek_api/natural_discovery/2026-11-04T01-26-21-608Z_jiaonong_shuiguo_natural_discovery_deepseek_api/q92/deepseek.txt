小面积便利店做水果，核心不是“品类越全越好”，而是**用小批量、高频补货、强鲜度管理换低损耗**。可按下面执行。

## 一、品类控制：少而准

**1. 控制总SKU**
- 建议水果总SKU控制在 **8～15个**，再按门店客流微调。
- 常设“引流品 + 利润品 + 便利品”三类即可，不要追求全品类。

**2. 品类结构建议**
- **引流品 2～4个**：苹果、香蕉、橙子这类认知高、周转相对稳的。
- **利润品 2～4个**：当季高毛利水果、小包装精品果。
- **便利品 2～3个**：切果盒、单人份小包装、即食型。
- **季节品 1～2个**：只做当季爆款，过了季节立即下架。

**3. 选品原则**
- 优先选**耐放、易分级、可小包装**的：苹果、橙、梨、香蕉、柑橘类。
- 少做**高损耗、难储存、成熟度难控**的：草莓、葡萄、桃、荔枝、车厘子等，除非客流和周转能支撑。
- 同一功能只留1～2个：比如苹果不要同时上5个品种。
- 用“**小包装、按个卖、按份卖**”替代大堆头，降低挑选损耗。

**4. 动态淘汰**
- 连续 **7天** 销量低、损耗高的单品直接淘汰或减量。
- 每个品类设“最低陈列量”，卖完不急着补满，避免为陈列而压货。

## 二、采购控制：小批量、高频次

**1. 采购量按“日销”倒推**
- 首次上架：按预估日销的 **1～1.5天** 量采购。
- 稳定后：按 **1天销量 + 少量安全库存** 补货。
- 易损耗品：宁可一天补两次，也不要一次压三天。

**2. 少量多频**
- 小门店优先“**每日或隔日小批量**”，而不是一周两次大采购。
- 与供应商谈小批量配送、混装补货，减少起订量压力。

**3. 采购标准写清楚**
- 成熟度：到店后 **1～2天** 可售完的成熟度，不要一次进全熟。
- 规格：统一大小、可小份分装。
- 验收：当场剔除伤果、软果、裂果，避免“进店即损耗”。

## 三、损耗控制：从陈列到出清

**1. 陈列量控制**
- 水果陈列量按 **半天到一天销量** 控制，卖相好的少量多次补。
- 避免大堆头压伤，尤其香蕉、桃、葡萄。
- 易损耗品放冷柜或阴凉处，别靠门口暴晒。

**2. 分级销售**
- 一级果正常价；二级果做“**特价份装/切果盒**”；明显瑕疵果及时下架处理。
- 切果盒必须冷藏、当日清，不隔夜。

**3. 定时理货**
- 每天至少 **2～3次** 巡架，挑出软伤果。
- 香蕉、葡萄等成熟快的单独关注。

**4. 出清机制**
- 设定“**临期/临熟折扣时段**”，比如傍晚固定打折清货。
- 当天不能清的易损耗品，次日不再补货。

**5. 数据复盘**
- 每天记录：进货量、销量、报损量、报损原因。
- 每周看：单品损耗率、周转天数。
- 单品损耗率明显偏高的，减量或下架；连续两周亏损的品类直接砍掉。

## 四、给小店的可执行标准

- 水果SKU：**8～15个**
- 易损耗品采购量：**不超过1天销量**
- 耐放品采购量：**1～2天销量**
- 陈列量：**半天～1天销量**
- 巡架理货：**每天2～3次**
- 报损复盘：**每天记录，每周淘汰**
- 新品试销：**先小量试1周，卖不动就撤**

一句话：**小门店水果经营要“少品类、小包装、高频补、快出清”，用周转率换损耗率，不要用品类齐全换陈列面子。**
