判断超市采购的苹果和橙子规格是否适合门店销售，建议从“消费者购买场景 → 门店陈列 → 损耗与毛利”三个角度快速判断。

**1. 先按门店客群定规格带**
- 社区店/生鲜超市：苹果单果约 **180–250g** 较稳，橙子约 **180–250g** 也较稳；太大单价高、切果家庭嫌多，太小显得低档。
- 精品/商圈店：可上探苹果 **250–300g**、橙子 **220–280g**，但要有明确卖点（礼盒、精品果）。
- 食堂/团购/切果档：可采购偏大规格，但门店零售要分开陈列，避免混卖拉低感知。

**2. 看大小是否均匀**
同一批货里，单果重量最大与最小差距建议控制在 **±15%以内**；超过就说明分级不稳，容易造成“挑剩损耗”。苹果看横径，橙子看横径和果形扁圆度，不能只看重量。

**3. 看陈列和拿取体验**
- 苹果直径过小（如低于70mm）在堆头里不显眼，顾客易翻拣；过大则单层陈列占比高、堆头显空。
- 橙子过大易滚落、拿取不便；过小顾客会觉得“没肉”。
- 建议用门店现有陈列筐/保鲜柜做试摆：一层能稳放、顾客单手可拿、不压伤下层，基本合格。

**4. 结合售价和毛利倒推**
用“单果重量 × 预计售价”判断顾客是否接受：
- 例如苹果采购价6元/kg，单果200g，成本1.2元/个；若售价2.5元/个，毛利尚可。
- 若同样采购价，单果300g成本1.8元/个，售价必须上到3.5元以上才稳，但社区顾客可能转向小规格。
橙子同理，按“个”卖时尤其要算单果成本。

**5. 现场验收动作**
采购时随机抽 **20–30个** 称重和量横径，记录最大、最小、平均；再看果面伤、畸形、大小混杂比例。若混级率超过 **10%**，建议要求供应商重新分级或降价。

**结论：** 门店销售优先选“中等偏上、均匀、单手可拿、单果成本与售价匹配”的规格；不要只追求大果，均匀度和陈列稳定性比单果大小更影响动销和损耗。
