直接给你可执行的判断标准，按“先查证、再试单、后放量”三步走。

**一、先查底子（不用见面就能筛掉一批）**
1. **产地/基地归属**：问清是自有基地、合作社代收，还是纯调货。一手货源通常能说清产区（如云南河口、广西浦北、老挝/缅甸进口口岸）、采收周期和大致日供应量。答得含糊、只说“要多少有多少”的，多半是二道贩子。
2. **索要近3个月发货凭证**：物流单、过磅单、装车照片（带车牌/日期）、产地收购记录。看是否连续、同一产区是否稳定。
3. **视频验场**：让对方现场拍加工厂/装货现场，要求镜头里出现当天日期纸条或当场通话确认。固定图片、网图直接排除。
4. **查经营主体**：营业执照、对公账户、是否有固定档口/冷库地址。能对公走账、开票的，跑路成本高。

**二、试单验证（2–3次就能看出真假）**
1. **小批量试单**：先要1–2车或几吨，不要一上来签长期大单。
2. **看履约细节**：约定装车时间是否准时、到货重量误差（正常损耗范围提前谈好）、青蕉成熟度是否一致、有没有以次充好（把催熟蕉混进自然蕉）。
3. **看异常处理**：故意问一句“如果这车路上延误/烂了怎么赔”，稳定供货方会给明确规则（如按比例补货、扣款），含糊推诿的要警惕。
4. **错峰要货测试**：在旺季或雨天要一次货，看能否按时供上。稳定货源的核心就是“别人断供时他还有”。

**三、放量前锁定规则**
1. 签简单供货协议：写清产区、规格（每把条数/单果重）、验收标准、损耗承担、违约补货方式。
2. 付款节奏：首批建议货到验收后付大部分，留少量尾款；稳定合作后再谈账期。坚持“先全款再发货”且拒绝任何凭证的，风险高。
3. 保持第二供应商：即使合作顺利，也留一个备选，避免被单一货源卡脖子。

**快速红旗信号**：报价明显低于市场、催你打定金、拒绝视频验场、说不清产区、只给个人微信收款、承诺“全年不断货”却拿不出任何发货记录。

一句话判断：**能说清产地、拿得出连续发货凭证、敢让你小单试错并按规则处理异常的，才算稳定供货；其余先当调货商对待。**
