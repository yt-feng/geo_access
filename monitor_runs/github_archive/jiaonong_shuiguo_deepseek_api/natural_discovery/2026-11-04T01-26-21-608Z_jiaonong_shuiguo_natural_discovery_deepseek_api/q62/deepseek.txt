# 判断香蕉熟度和坏果风险（批发收货用）

## 一、先分清香蕉的“两种状态”

批发环节香蕉分两类，判断标准不同：

- **青蕉（生蕉）**：7–8成熟采收，靠乙烯催熟。重点是“能不能安全催熟、会不会中途烂”。
- **黄蕉（催熟后）**：直接进零售。重点是“还能放几天、有没有隐性伤”。

---

## 二、青蕉入库：判断熟度和风险

**1. 看果指饱满度（最关键）**
- 果指棱角明显、截面接近三角形 → 偏生（6–7成），耐放，催熟时间长。
- 棱角变圆、截面近椭圆 → 7–8成，正常催熟料。
- 已明显圆润饱满 → 偏熟，催熟后易过软、货架期短。
- **收购建议：青蕉以7–8成为主，超过8成慎收。**

**2. 看果皮颜色**
- 全绿带轻微黄晕：正常。
- 出现“黄中带绿斑块”不均匀：可能受冷或催熟不均，风险高。
- 果皮发暗、发灰、有水渍感：冻伤或湿害，**直接拒收**。

**3. 看果轴（蕉头）和切口**
- 切口新鲜、无霉斑、无发黑流汁：正常。
- 切口发黑、长白毛/绿霉、有酸味：已感染，整把风险高。
- 果轴过粗、有裂口：机械伤多，催熟时易从伤口烂。

**4. 摸硬度**
- 整把硬实、有弹性：好。
- 局部发软、按压不回弹：内部已开始软化或碰伤，**挑出**。
- 发黏、渗液：腐烂早期，整箱隔离。

**5. 看“蕉指缝隙”**
- 蕉指之间干净、无黑点：正常。
- 缝隙有黑色小点密集（炭疽病初期）：催熟后会大面积黑斑，**风险高**。

**6. 闻味**
- 青草味正常；有酒味、酸味、霉味 → 已开始发酵或腐烂，拒收。

---

## 三、黄蕉收货：判断还能放多久

**1. 颜色分级（行业常用1–7级）**
- 3–4级（绿黄、黄多绿少）：货架期3–5天，适合分销。
- 5级（全黄）：2–3天，适合快销。
- 6–7级（带黑斑、糖斑）：1天内必须出手，**批发慎收**。

**2. 找“隐性坏果”**
- **果柄处发黑/发软**：从柄端开始烂，外表看不出来，掰开才发现。抽检时掰几根看柄芯。
- **蕉指根部渗液、发黏**：冠腐病/轴腐病，一箱里会传染。
- **表皮黑斑是“点”还是“片”**：零星糖斑正常；成片黑、按压软 → 炭疽病，会扩散。
- **两头软中间硬**：碰伤或冷害，催熟后局部烂。

**3. 手感抽检**
每箱随机抽3–5根，捏中部和柄端：有软点、空心的挑出。

**4. 温度史**
问清运输和仓储温度。**低于12℃会冷害**：表皮发暗、催熟不匀、芯发黑。冷害蕉外表可能还行，催熟后大面积发黑，是批发最大的坑。

---

## 四、坏果风险的快速抽检流程（可执行）

1. **整批看外观**：颜色是否均匀、有无水渍/霉斑/异味。
2. **按箱抽检**：每10箱抽1箱，每箱抽5把，重点看切口、果柄、蕉指缝隙。
3. **掰检**：抽3–5根掰开柄端和中部，看芯是否发黑、发软。
4. **算比例**：坏果/可疑果超过**3–5%**，整批压价或拒收；超过10%直接不要。
5. **问温度史和采收期**：采收超过7天、运输温度低于12℃或高于30℃，风险加倍。
6. **小批试催**：大批量前拿1–2箱做乙烯催熟试验，24–48小时看是否均匀转黄、有无黑斑爆发。

---

## 五、一句话判断口诀

**青蕉看棱角、看切口、看缝隙黑点；黄蕉看色级、看柄端、看黑斑是点还是片；问温度史，抽掰柄芯，坏果超5%就压价或拒收。**
