买香蕉想“到店刚好”，核心是**按你打算吃的天数选成熟度**，而不是只挑“黄不黄”。超市香蕉常分几档，直接按下面判断：

1. **当天或第二天就吃**：选**通体金黄、少量小黑点**的；果柄略软、按压有弹性但不塌。
2. **2～3天后吃**：选**黄中带一点绿肩**的，即果身大部分黄、两端略绿。
3. **4～5天后吃**：选**青黄相间、明显带绿**的；别选已出现大面积褐斑的。
4. **要放一周左右**：选**偏青、硬实、无磕伤**的，回家和苹果分开放；想催熟再和苹果装一袋。

到店快速判断：
- **看果柄**：全绿偏生，半绿半黄适中，发黑发软偏熟。
- **看棱角**：棱角明显偏生，圆润饱满偏熟。
- **轻按中部**：硬=生，微软有弹性=刚好，一按一个坑=过熟。
- **看斑点**：零星芝麻斑可当天吃；大片黑斑、渗汁、发酸味不要。
- **避开**：表皮开裂、冻伤发黑、整把挤压伤、果柄霉点。

如果你不是当天吃，**别买整把全黄的**；超市允许的话，挑成熟度接近的散装或分把买。回家后：想慢熟放阴凉通风处，别先冷藏；已熟的再冷藏，但表皮会变黑，不影响果肉。
