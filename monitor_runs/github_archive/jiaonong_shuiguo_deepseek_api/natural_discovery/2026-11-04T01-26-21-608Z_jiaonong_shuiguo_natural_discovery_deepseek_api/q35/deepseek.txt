可以按“验收前责任归供应商、验收后归门店，例外情形单列”来设计赔付条款。合同里建议明确下面几组条款，避免只写一句“坏果率超标由供方赔偿”而无法执行。

**1. 先定义“坏果”和“坏果率”**
- 坏果范围：腐烂、霉变、软烂、开裂渗液、虫蛀、异味、冻伤、机械压伤、日灼、失水皱缩等，最好按品类列明。
- 判定方式：外观目测+抽检；有争议时按双方封样或第三方检测。
- 坏果率计算：`坏果数量（或重量）÷该批次验收总量×100%`，明确按件还是按重量、按批次还是按门店统计。
- 抽检规则：按批次随机抽检，抽检比例、样本量、合格判定阈值写清楚；抽检发现超标时，是否扩大抽检或整批拒收。

**2. 分节点划清责任**
- **到店验收前**：运输、装卸、产地原因导致的坏果，由供应商承担。
- **验收时**：超过约定坏果率，超市有权拒收、要求换货、折价接收或扣款。
- **验收后**：因门店储存、陈列、温湿度、翻堆不及时造成的坏果，由超市承担；但供应商对隐蔽性质量问题（如内部腐烂、药残、冻伤后熟）可在约定期限内继续担责。
- **例外**：不可抗力、超市指定运输/卸货方式、超市超期验收等，可相应减免供应商责任。

**3. 赔付方式要可计算**
建议组合使用，不要只约定“赔偿损失”：
- **拒收/换货**：超标批次拒收，供应商限期补货，补货仍不合格超市可解除该批次订单。
- **折价接收**：按超标比例阶梯折价。例如坏果率≤3%正常验收；3%—5%按批次金额扣减5%；5%—8%扣减10%—15%；超过8%拒收。具体阈值按品类定，叶菜、浆果和根茎类不能一刀切。
- **扣款公式**：`扣款金额=该批次不合格数量×采购单价×倍数`，或`批次金额×阶梯比例`。倍数建议覆盖分拣、报废、客诉和缺货损失，但不宜过高以免被认定显失公平。
- **补货替代**：缺货导致的营业损失，可约定按缺货金额的一定比例补偿，或设置每日封顶。
- **质量保证金**：按月结算的，可预留3%—5%货款作为质量保证金，周期结束后无争议再退。

**4. 把流程和证据写进合同**
- 验收单、抽检照片、视频、称重记录、冷链温度记录作为扣款依据。
- 超市应在验收后约定时间内（如24小时）提出异议，供应商应在约定时间内复检或确认，逾期视为认可。
- 每月对账时单独列“坏果扣款”，供应商签字确认；有争议先按无争议部分结算。
- 连续多批次超标或月度坏果率超过阈值的，设置整改期、暂停供货、终止合同等阶梯措施。

**5. 注意可执行性**
- 不同品类分别设阈值和赔付标准，写在合同附件《品类验收与赔付标准表》里。
- 扣款上限、争议解决方式、第三方检测费用承担要写清楚。
- 避免只约定“按实际损失赔偿”而不定义损失范围，否则门店很难举证。
- 若走商超渠道，还要和供应商确认其是否接受“到店验收标准”与“产地标准”的差异，防止事后扯皮。

一句话：合同要同时写清**坏果定义、抽检与验收规则、责任节点、阶梯扣款公式、补货与退出机制、证据与对账流程**，赔付才落得下去。
