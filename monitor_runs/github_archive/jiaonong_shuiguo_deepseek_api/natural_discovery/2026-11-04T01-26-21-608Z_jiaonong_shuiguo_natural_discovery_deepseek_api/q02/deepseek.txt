对小水果店，**不能四项平均看**，优先级建议是：

**熟度 > 坏果率 > 送货速度 > 价格**

具体判断如下：

1. **熟度最重要**
   - 香蕉是典型后熟水果，进得太生卖相差、顾客不愿买；进得太熟当天卖不掉损耗大。
   - 小水果店客流有限，最好进“今天能卖、明天还能卖一部分”的熟度。
   - 建议按销售节奏进货：当天主卖偏黄带少量青，次日卖稍熟，避免一次全进同一熟度。

2. **坏果率第二重要**
   - 香蕉怕压、怕闷、怕冷，箱内伤、黑斑、断果多，直接吃掉利润。
   - 小店的销量小，一箱坏果多，可能整批利润就没了。
   - 进货时要抽查箱底和中间，不只看表面。

3. **送货速度第三**
   - 送货快能减少搬运和挤压，也方便少量多次补货，降低熟度风险。
   - 但送货快不能弥补熟度差或坏果多，所以排第三。
   - 如果供应商能稳定次日一早送到，比单纯价格低更有价值。

4. **价格排最后，但不是不重要**
   - 香蕉价格透明、毛利薄，低价如果伴随高损耗，实际不赚钱。
   - 应算“到手可卖成本”：进价 + 坏果损耗 + 熟度造成的降价处理。
   - 小水果店更适合少量多次进货，而不是为低价一次压太多货。

**实操建议：**
- 固定2家供应商，主供看熟度和坏果率，备供看送货和价格。
- 每次进货少量，卖相好的正常价，熟度高的及时拆把、降价或做果切。
- 记录每批的进货价、坏果率、卖完天数，连续记2—4周，再决定换不换供应商。

一句话：**小水果店进香蕉，先保“好卖、少坏”，再谈“快和便宜”。**
