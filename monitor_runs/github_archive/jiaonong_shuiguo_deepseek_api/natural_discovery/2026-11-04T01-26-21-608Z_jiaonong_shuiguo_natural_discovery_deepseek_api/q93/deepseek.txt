先给结论：**三者都要管，但优先级取决于你的售卖形态**。对便利店鲜切菠萝，最该先抓的是**保质期/效期管理（含冷链温度）**，其次才是**包装**和**配送频次**；包装和配送频次本质是服务于保质期的两个手段。

**判断顺序建议：**

1. **保质期（含冷链）是第一优先**
   - 鲜切菠萝是高水分、高糖、易氧化褐变、易滋生微生物的即食鲜果，属高风险短保商品。
   - 要明确：切制后冷藏条件下的**售卖时限**（例如当日切当日售、或按门店规定的最长冷藏小时数），并做**效期标签**（切制时间、到期时间）。
   - 冷链温度比包装更能决定安全，冷藏断链一次就可能让保质期失效。
   - 可执行动作：到店贴效期签、临期下架折价规则、每日闭店前清点报废。

2. **包装是第二优先，但要选对类型**
   - 包装的核心作用是**隔绝污染、减缓氧化褐变、控制汁液渗漏**，不是单纯好看。
   - 优先选密封性好的冷藏即食包装（如带盖托盘/封膜），标注切制日期和保质期。
   - 包装不合格会直接缩短实际保质期，所以它是保质期的保障条件，不是独立指标。

3. **配送频次是第三优先，但决定你能不能“卖短保”**
   - 鲜切菠萝不适合大量囤货，配送频次应匹配**门店日销量**，做到少量多次、先进先出。
   - 频次太低会导致门店被迫压货、临期报废上升；频次太高则配送成本上升。
   - 可执行动作：按日均销量定配送量，设置安全库存上限，配送时检查到店温度和包装完整性。

**一句话决策规则：**
- 如果你现在**报废/客诉多** → 先查保质期和冷链；
- 如果**褐变、渗汁、卖相差** → 先改包装；
- 如果**经常缺货或大量临期** → 先调配送频次和订货量。

所以不是三选一，而是：**以保质期为纲，用包装保它，用配送频次匹配销量。**
