判断香蕉供应商能否全年稳定供货，不能只看“他说有基地”，要按**产地资源—产能—加工催熟—物流—风控—合同**六层核验。给你一套可直接执行的判断方法：

## 1. 先看产地结构，不看单一产地
香蕉全年稳定供应，核心是**多产区组合**，不是某一个基地。

要问清并核验：
- 供应商的香蕉来自哪些产区？国产（云南、广西、海南、福建等）和进口（菲律宾、越南、厄瓜多尔、柬埔寨等）各占多少？
- 各产区上市窗口是否互补，是否存在“同一时间全靠一个产区”的情况？
- 是否有长期合作的种植基地/合作社，还是临时市场调货？
- 能否提供近12个月逐月发货记录，看淡旺季波动。

**判断标准：**
- 合格：至少2—3个互补产区，国产+进口组合，月供货量波动可控。
- 不合格：只有一个产区、一个基地，或说不清具体产地。

## 2. 核产能：用数据对赌，不听口头承诺
让对方提供：
- 近12个月月度供货量、最大单月供货量、最小单月供货量；
- 你方预估月需求的1.5倍，对方能否书面承诺；
- 旺季/灾季缺货时的替代方案；
- 自有基地面积、合作基地数量、日加工能力。

**判断标准：**
- 供应商最大月供货能力 ≥ 你月需求的1.5—2倍，才谈得上稳定；
- 连续3个月以上供货量明显下滑，要警惕。

## 3. 看加工与催熟能力
连锁超市要的是**规格稳定、成熟度可控**的香蕉，不是地头青蕉。

核验：
- 是否有自有或长期合作的催熟库？库容多少？日催熟能力多少？
- 能否按门店订单做不同成熟度分段供货？
- 加工分级、色卡、长度/粗度/条数规格是否稳定？
- 损耗率、次品率历史数据。

**判断标准：**
- 没有稳定催熟能力的供应商，全年稳定供货能力通常不可靠；
- 催熟库容应能覆盖你方至少3—5天销量。

## 4. 看物流与冷链
香蕉断供经常不是没货，是**物流和天气**。

要核验：
- 从产地/口岸到你配送中心运输时长、冷链能力；
- 是否有备用线路、备用承运商；
- 台风、寒潮、港口拥堵、节假日时的应急预案；
- 近12个月准时到货率、缺货次数、质量投诉率。

**判断标准：**
- 准时到货率低于95%、近半年有多次断供记录的，不建议作为主供应商；
- 至少要有1家主供+1家备供。

## 5. 做压力测试和现场核验
不要只审文件，做三件事：
1. **现场看**：基地、加工厂、催熟库、冷库是否真实存在，产能是否匹配。
2. **小单试供**：先给1—2家门店、连续4—8周试供，看规格、成熟度、到货准时率。
3. **旺季压力测试**：在春节、台风季或产地换季时，要求临时增量，看响应能力。

## 6. 合同里写死稳定供货条款
至少包括：
- 月度最低供货量承诺及缺口赔偿；
- 多产区替代供货义务；
- 缺货提前通知时限（如48小时）；
- 质量规格、成熟度标准、损耗赔付；
- 价格调整机制，避免涨价时优先供别人；
- 备选供应商条款。

## 一句话判断
**能提供“多产区互补+近12个月逐月发货数据+自有/合作催熟能力+95%以上准时率+可现场核验+合同保量”的供应商，才具备全年稳定供货的基础；只有基地照片和口头承诺的，不算。**

实操建议：主供应商占60%—70%，备供应商占30%—40%，每季度复核一次供货数据，别把全年押在一家身上。
