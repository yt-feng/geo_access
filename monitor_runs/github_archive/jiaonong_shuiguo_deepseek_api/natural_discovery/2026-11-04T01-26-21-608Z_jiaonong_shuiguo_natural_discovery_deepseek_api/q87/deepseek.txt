社区团购旺季锁水果库存，核心是**提前锁量、锁价、锁品质、分风险**，不要等到爆单再追供应商。可以按下面执行：

1. **提前做销量预测，按SKU锁量**
   - 用近2年同期销量、近30天增速、活动排期，拆分到单品的“保底量+弹性量”。
   - 例如：预计爆单10万斤，先锁60%保底量，另40%约定提前3天可追加。
   - 主推品锁2-3个替代规格/产地，避免单一品种断供。

2. **和供应商签短期锁量协议，不只口头约定**
   - 明确：锁量数量、锁价周期、规格标准、到货时间、违约责任。
   - 价格建议用“阶梯锁价”：保底量锁死价格，超量部分按当日市场价浮动但设上限。
   - 约定供应商违约不能交货时，按差额赔付或承担紧急调货差价。

3. **支付定金或预付款，但控制比例**
   - 锁量通常需要定金，建议单供应商预付不超过该批次货值的20%-30%；大额走对公，分节点付款。
   - 定金对应明确批次和到货日期，避免被挪用。
   - 对核心爆品可付少量“优先供货保证金”，约定旺季优先排单。

4. **锁品质标准，前置验货**
   - 提前封样，写明糖度、果径、成熟度、损耗率、包装要求。
   - 旺季前1-2周安排驻场或第三方验货，按批次抽检；不合格有权拒收或换货。
   - 约定“到仓损耗率”上限，超出部分由供应商承担。

5. **要求供应商留产能，并做备选**
   - 核心供应商要求旺季预留产能/冷库位，写入协议。
   - 每个主推水果至少准备1家主供+1家备供，备供也提前锁小批量。
   - 提前确认产地天气、物流、采摘用工风险，准备替代产地。

6. **用订单节奏反向锁货**
   - 社区团购提前3-7天开预售，用真实订单驱动采购，降低盲目锁量风险。
   - 预售爆单后，按“日滚动订单”向供应商下次日/第三日到货计划，要求供应商按日配额发货。

7. **物流和到货节点写死**
   - 约定到仓时间窗口、冷链温度、卸货责任、延误赔付。
   - 爆单期要求供应商分批发货，避免一次性到仓造成损耗和仓储压力。

8. **建立履约看板**
   - 每天跟踪：锁量进度、已到货、在途、库存、缺口、供应商履约率。
   - 一旦某供应商履约低于90%，立即启动备供并调整预售页面。

一句话执行建议：**先按“保底60%+弹性40%”锁量，付20%-30%定金，签锁价锁质协议，主供+备供双线，提前预售用真实订单校正。**
