# 学校食堂水果供应商选择：可执行框架

## 一、先定准入底线（不满足直接淘汰）

学校食堂有食品安全责任，供应商准入比普通餐饮更严，建议设硬门槛：

- **证照齐全**：营业执照、食品经营许可证（经营范围含预包装/散装食品销售）；若为种植基地直供，另需产地证明或合作社资质。
- **检测能力**：能提供每批次农残检测报告，或承诺配合学校/第三方抽检。香蕉、橙子、苹果均为常检品类，重点看农残（如有机磷、拟除虫菊酯类）。
- **配送资质**：有冷藏/常温配送车辆和固定配送人员，能进校门并配合登记。
- **可追溯**：能说清货源产地、批次，出问题能召回。

## 二、按品类分开评估（三种水果逻辑不同）

- **香蕉**：后熟型，最考验供应链。重点问：到货是青蕉还是黄蕉？是否提供催熟服务或催熟房？配送频次能否做到2–3天一次、少量多次？香蕉损耗高，供应商若只会"整箱压货"要慎选。
- **苹果**：耐储，适合批量采购、周配或双周配。重点看等级规格是否稳定（大小、糖度、外观）、是否有冷库、能否按学校要求的规格分级供货。
- **橙子**：季节性强，重点看产季对接能力、产地直采比例、是否打蜡（学校建议选不打蜡或食用蜡合规的）、酸度是否适合学生。

## 三、用"样品+试供"代替纸面评审

实操建议：
1. **索样试吃**：每个品类让2–3家供应商送样，组织食堂管理员+教师/学生代表盲评（口感、外观、规格一致性）。
2. **小批量试供2–4周**：观察到货准时率、损耗率、规格偏差、售后响应。香蕉重点看一周内损耗，苹果看规格稳定性，橙子看酸甜度和坏果率。
3. **算综合成本**：不只看单价，要算"单价×（1+损耗率）+ 配送成本"。香蕉损耗常达5%–10%，低价但高损耗的供应商实际更贵。

## 四、合同与日常管理要点

- 合同写明：规格标准（如苹果单果克重区间）、验收标准（坏果率上限，如≤3%）、退换货时限、食品安全责任与赔偿条款、价格调整机制（随行就市需提前报备）。
- 要求**每批次留样+检测报告随货**，学校保留抽检权。
- 建立**月度评分**：准时率、合格率、投诉次数，连续不达标触发淘汰。
- 避免单一供应商垄断，建议每品类保持1家主供+1家备选。

## 五、渠道来源建议

优先顺序：本地一级批发商/产地合作社直供 > 大型农产品配送企业 > 电商平台集采。学校用量稳定、账期长，适合找能签年度框架协议的本地配送商，响应更快；跨区域平台价格可能低但售后和鲜度风险高。

**一句话判断标准**：能提供检测报告、能小批量高频配送、愿意接受试供期考核、合同里敢写损耗赔付的供应商，才值得进入下一轮。
