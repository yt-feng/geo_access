判断供应商售后响应，不能只听口头承诺，建议用“可验证的动作”来试。下面按可执行程度排序：

1. **合同里写死响应条款**
   - 明确响应时限：如质量问题反馈后 **2小时内回复、24小时内给出处理方案、48小时内到店处理或补货**。
   - 明确责任：腐烂率、断货、规格不符、农残检测不合格时的退换、扣款、补货规则。
   - 明确对接人和备用联系人，避免只留一个业务员电话。

2. **用一次真实的小问题做压力测试**
   - 首单故意不要一次下太大，随后反馈一个具体问题，例如“到货香蕉成熟度不均”“菠萝有机械伤”，看对方多久回复、是否给方案、是否到场。
   - 记录：首次回复时间、解决时间、是否推诿、是否主动补损。

3. **问清楚售后流程，而不是只问“有没有售后”**
   - 谁受理？业务员、客服还是负责人？
   - 需要什么凭证？照片、视频、留样、签收单？
   - 是补货、折价、扣款还是退货？多久执行？
   - 节假日和早市时段是否有人响应？

4. **查历史履约记录**
   - 要求提供近3个月同类商超客户的售后记录或合作证明，可脱敏。
   - 问其现有客户中是否有做生鲜日配的，生鲜售后频次高，最能反映响应能力。
   - 如果能联系到其现有客户，重点问“出问题时找谁、多久解决”。

5. **看现场和库存保障能力**
   - 有稳定冷库、分拣场地、配送车辆的供应商，售后补货更现实。
   - 问清楚菠萝、香蕉的常备库存和安全库存，缺货时能否优先级补货。
   - 香蕉是后熟商品，要问成熟度分级和催熟责任；菠萝要看产地、规格和机械伤控制。

6. **设置试合作期和考核指标**
   - 先签1个月试合作，考核：回复时效、到货合格率、补货及时率、投诉闭环率。
   - 把售后响应纳入月度评分，连续不达标可终止或调整订单比例。

7. **保留证据和双通道联系**
   - 每次反馈用微信/邮件留痕，要求对方文字确认处理方案。
   - 除业务员外，保留其主管或公司固定电话，防止业务员失联。

一句话：**稳定售后不是“说得好”，而是“合同有条款、问题有测试、过程有记录、结果有考核”。** 对菠萝和香蕉这类生鲜，重点看腐烂、成熟度、规格不符和补货时效这四类问题的实际处理速度。
