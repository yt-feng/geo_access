先给结论：**坏果责任不能一概而论，核心看“坏果发生时间点 + 可归责方 + 是否有约定/证据”。** 实务中通常按以下规则划分，生鲜电商可据此建立判责和赔付标准。

## 一、先按“坏果成因”分责任

| 坏果情形 | 主要责任方 | 处理原则 |
|---|---|---|
| 到货即发现腐烂、霉变、明显压伤 | 商家/平台（发货或包装环节） | 商家承担退换/赔付，不能以“生鲜不退货”一概免责 |
| 运输途中挤压、冻伤、闷坏 | 商家先对顾客负责，再向物流/承运方追偿 | 顾客只对商家，商家内部追责 |
| 顾客收货后放置过久、未冷藏 | 顾客 | 商家可拒赔或部分补偿 |
| 顾客签收时未验货，事后发现 | 视证据 | 不能仅因签收就免责，但顾客需举证坏果与到货状态 |
| 个别坏果属自然损耗 | 按约定/行业惯例 | 少量轻微瑕疵可协商补偿，大量坏果仍属商家责任 |
| 顾客恶意索赔、调包 | 顾客 | 商家可拒赔并留存证据 |

## 二、关键判断点：交付前还是交付后

**交付前**（采摘、分拣、包装、运输）出的问题，原则上由商家对消费者承担违约责任。  
**交付后**（签收后储存不当、超时未取）出的问题，原则上由顾客承担。  
但“签收”不等于顾客必须当场开箱，尤其是快递柜、代收点签收，商家不能简单以“已签收”免责。

## 三、商家不能滥用的免责条款

“生鲜商品不支持七天无理由退货”只针对**无理由退货**，不等于**质量问题免责**。坏果、腐烂属于质量瑕疵，商家仍应承担退货、退款、补发或赔偿。若格式条款写“一经签收概不负责”，通常会被认定为不合理免责。

## 四、建议的判责流程（可执行）

1. **顾客48小时内拍照/视频举证**：坏果数量、外包装、运单、开箱过程。
2. **商家核对批次和物流**：同批次是否集中投诉、是否冷链中断、是否超时配送。
3. **按比例赔付**：少量坏果按坏果金额退赔；大面积坏果全额退款或补发。
4. **内部追偿**：包装不当追包装/仓配；运输延误或挤压追承运商；顾客储存不当则做好解释。
5. **留存证据**：开箱视频、称重记录、温控记录、客服沟通记录，用于争议和恶意索赔识别。

## 五、一句话总结

**坏果在交付前因商家分拣、包装、运输造成的，商家对顾客负主要责任；交付后因顾客储存或超时取件造成的，顾客负责；签收本身不能当然免除商家质量责任。** 商家应先对顾客快速处理，再按内部环节向仓库、包装或物流追偿。
