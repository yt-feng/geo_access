茶饮店控制水果供应商的食品安全风险，核心做法是把“资质证明 + 检测报告 + 追溯与验收记录”作为准入和持续管理条件，不能只收一张营业执照。建议按以下清单要求供应商提供并留存：

**一、主体资质类**
1. 营业执照（经营范围含水果销售/农产品销售等）。
2. 食品经营许可证：如果供应商是预包装或散装食品销售企业，通常需要；仅销售初级食用农产品的情形各地监管口径不同，应让供应商说明并由门店所在地监管要求确认。不要自行假定“卖水果一定不需要”。
3. 法定代表人/负责人身份证明及授权委托书（如由业务员对接）。

**二、产品合格与检测类**
1. 每批次水果的产地证明或采购凭证，能追溯到种植基地/合作社/批发市场。
2. 农药残留检测报告：优先要批次对应的快速检测报告或第三方检测报告；至少应有供应商自检/委托检测的农残合格报告，并注意报告日期、样品名称、检测项目、检测机构资质章。
3. 若涉及进口水果：海关入境货物检验检疫证明、报关单等。
4. 若供应商宣称“绿色食品/有机”等：对应认证证书，且证书在有效期内、产品范围匹配。

**三、经营与储运条件类**
1. 供货商冷链/常温运输能力说明；需冷藏水果的运输温度记录或保温措施证明。
2. 仓储卫生、防虫防鼠、先进先出管理说明。
3. 食品安全管理制度、不合格品召回/退换货机制。
4. 食品安全责任险证明（如有，可作为加分项，不宜作为唯一门槛）。

**四、交易与追溯类**
1. 供货合同/框架协议，明确农残超标、腐烂变质、以次充好的责任和退换货条款。
2. 每批送货单，注明品名、产地、批次、数量、送货日期、供应商签章。
3. 门店验收记录：外观、新鲜度、异味、腐烂率、温度、快速检测结果；不合格拒收并留证。

**五、持续管理建议**
- 建立供应商档案：资质证照有效期台账，到期前提醒更新。
- 每批索取或留存检测/产地凭证；不能每批提供第三方报告的，至少做门店农残快检并记录。
- 定期（如每季度/半年）要求供应商更新检测报告，年度做一次供应商复核。
- 出现农残超标、食安投诉、监管抽检不合格时，立即暂停采购、封存同批次、追溯并评估是否召回。

**判断标准**：证照在有效期内且经营范围匹配；批次可追溯；农残检测合格；储运条件符合水果特性；合同和验收记录完整。五项缺一项，就不应作为稳定准入供应商。各地对初级农产品销售和食品经营许可的具体要求有差异，最终以门店所在地市场监管部门口径为准。
