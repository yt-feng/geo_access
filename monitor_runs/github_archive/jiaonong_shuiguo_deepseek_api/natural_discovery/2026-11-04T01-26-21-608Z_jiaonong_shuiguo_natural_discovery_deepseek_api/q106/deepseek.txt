水果供应商报价每天变是正常的，但采购方可以用一套“可判断的框架”区分合理波动和借机抬价。下面按可执行方法说明。

## 一、先建立自己的价格基准

不要只看供应商报价，自己要有参照物：

1. **批发市场价**：当地一级批发市场同品种、同规格、同等级的价格，是最直接的基准。每天或隔天记录。
2. **历史成交价**：自己过去30–90天的采购价，按品种、产地、规格分类存好，形成自己的价格曲线。
3. **多供应商比价**：同一品种至少询2–3家，看报价离散度。如果只有一家涨、其余持平，多半是个体问题；如果普遍上涨，才可能是市场因素。
4. **产地/期货信息**：主产区天气、上市季节、节日备货、运输成本（油价、冷链）等，能解释大部分趋势性波动。

## 二、判断波动是否“合理”的四个维度

**1. 幅度**
- 日常小幅波动（比如±5%以内）通常正常。
- 单日跳涨超过10%–15%，要求供应商说明原因，并对照批发市场价核实。
- 连续多日单向上涨且无市场依据，要警惕。

**2. 方向与一致性**
- 合理波动通常与市场整体方向一致：产区减产、节前备货、雨季运输受阻等，会带动多品种或多供应商同步变化。
- 只有你这一家涨、其他家不涨，或者只涨你常买的规格，属于可疑信号。

**3. 频率与节奏**
- 水果本身季节性强，换季、产地切换时价格跳变正常，但应能说清“从哪个产区换到哪个产区”。
- 如果每天都有“理由”涨一点、跌得很少，属于典型的挤牙膏式抬价，要看月度均价而不是单日报价。

**4. 可解释性**
- 合理波动能对应到具体事实：某产地暴雨、某品种断档、节假日物流紧张、包装/人工成本变化。
- 解释含糊（“行情就这样”“今天都涨”）且拒绝提供依据的，按不合理处理。

## 三、具体操作建议

1. **做价格台账**：品种、规格、等级、产地、供应商、日期、单价、涨跌幅、原因备注。每周看一次趋势，不盯着单日。
2. **设置波动阈值**：例如单日涨跌超过8%–10%触发复核，要求供应商书面/口头说明并附市场参考。
3. **比价机制**：每周固定向2–3家询价，形成“市场价区间”，报价明显高于区间上沿的要求解释。
4. **合同里约定调价规则**：以某批发市场均价或双方认可的指数为基准，设定浮动范围和提前通知期，避免临时口头涨价。
5. **看月度加权均价**：单日报价容易做文章，按月加权均价对比历史，更能识别真实成本变化。
6. **保留替代方案**：对波动大的品种，提前准备备选供应商或替代品种，谈判时更有底气。

## 四、快速判断口诀

- **看幅度**：小波动正常，大跳涨要证据。
- **看对比**：市场涨不涨、别家涨不涨。
- **看原因**：说得清产区、天气、季节、运输，才算合理。
- **看趋势**：不盯单日，看周均价、月均价。
- **看合同**：有调价机制，就不靠临时扯皮。

核心一句话：**合理波动是“市场在动、大家同步动、原因说得清”；不合理波动是“只有你的报价在动、原因说不清、跌少涨多”。** 用基准价+比价+台账+阈值四件事，基本能判断。
