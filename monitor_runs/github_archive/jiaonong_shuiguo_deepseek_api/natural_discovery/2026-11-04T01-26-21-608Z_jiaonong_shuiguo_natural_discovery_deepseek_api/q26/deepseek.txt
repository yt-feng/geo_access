社区超市卖小包装香蕉，采购时重点盯住这几件事，能直接减少损耗和售后。

**一、包装形式怎么选**
- 优先选**带透气孔的小袋装或网袋装**，不要用完全密封的塑料袋。香蕉呼吸强度大，密封袋里水汽散不掉，容易闷出黑斑、发霉。
- 单包重量建议控制在**2—3根、约300—500克**，适合一顿吃完，减少“买多了放坏”导致的复购下降。
- 如果做**盒装**，选带通气孔的吸塑盒或纸盒，盒底垫一张吸水纸；**不建议透明密封盒**直接装香蕉。
- 标签贴在不显眼处，不要贴住果皮大面积区域，撕标签时容易带破皮。

**二、采购时的果品状态**
- 小包装香蕉要按**售卖周期倒推成熟度**采购：当天卖完可要黄熟；计划卖2—3天，应采**微黄、果身硬挺、棱角尚存**的青黄蕉，回店后自然转黄。
- 不要一次全采同成熟度，**分2—3个成熟度批次进货**，避免集中变黄集中报损。
- 拒收果柄发黑腐烂、果身有压伤软斑、表皮大面积擦伤的货；这些在小包装里会被放大。

**三、包装与损耗直接相关的细节**
- **果柄要保留**，但切口要平，避免刺破同袋其他香蕉。
- 装箱运输时用**纸箱+隔层**，不要堆压过高；香蕉怕压，压伤后2—3天就发黑。
- 门店陈列**不要放冷柜**，香蕉低温会冻伤变黑；常温阴凉通风陈列，小包装之间留空隙。
- 每天挑出**已出黑点但未坏**的单包做快销处理（如打折或拆开散卖），不要等整包坏掉。
- 采购量按**日均销量×1.5天**控制，小包装本身周转慢的话，宁可少进勤补。

**四、和供应商要谈的**
- 明确**到货成熟度标准**和**压伤、黑斑的验收扣重比例**。
- 问清包装是否含**吸水纸/透气孔**，包装成本是否含在单价里。
- 小批量试销1—2周，记录每天报损包数，再定稳定采购量。

一句话：小包装香蕉的核心是**透气、少压、控成熟度、勤挑损**，包装别密封，采购别贪多。
