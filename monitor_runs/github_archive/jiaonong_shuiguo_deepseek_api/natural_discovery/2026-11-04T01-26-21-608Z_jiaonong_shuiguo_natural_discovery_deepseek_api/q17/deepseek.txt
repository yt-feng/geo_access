开水果店控制新鲜度和库存，核心是**“以销定进、快进快出、分级处理”**。下面给你一套可直接落地的方法。

## 一、进货端：少进、勤进、看数据进

1. **按销量定进货量**：每种水果记录近7天日均销量，进货量≈日均销量×1.2～1.5（叶菜类、浆果类取低值，苹果橙子可略高）。新品类首单只进1～2天量试销。
2. **高频小批量**：易腐水果（草莓、葡萄、荔枝、香蕉、叶菜）每天或隔天进；耐储水果（苹果、梨、橙、柚）2～3天进一次。宁可补货，不要一次压满。
3. **固定供应商+早市拿货**：和1～2个批发商建立稳定关系，要求当天新鲜货；早上拿货，当天上架。
4. **看天进货**：高温、雨天客流下降，进货量下调20%～30%；节假日前适度增加，节后立刻收缩。
5. **只进当季主推**：反季水果价格高、损耗大，少量点缀即可，不做主力库存。

## 二、库存端：分区、分级、定上限

1. **设库存上限**：按货架+后仓总容量，给每类水果定“最高库存天数”（易腐1～2天，耐储3～5天），超限就停进。
2. **先进先出**：新货放里层/下层，旧货放外层，贴到货日期标签，每天翻检。
3. **温区分离**：香蕉、芒果等热带水果常温避风存放；葡萄、草莓、叶菜冷藏；苹果梨单独放（释放乙烯会催熟其他水果）。
4. **分级销售**：上架前分“精品/常规/特价”三档，轻微碰伤的当天做特价或切果盒，不要留到第二天。
5. **每日盘点**：闭店前花10分钟盘点，记录损耗和剩余，第二天据此调整进货。

## 三、销售端：加快周转、减少压货

1. **动态定价**：临近保鲜期的水果下午/傍晚打折清货，宁低价卖完，不要烂在店里。
2. **组合促销**：把周转慢的搭配热销品做果篮、切果拼盘、满减，提升动销。
3. **预订+团购**：社区群提前接龙预订，按订单进货，减少盲目库存。
4. **切果/果汁消化**：品相下降但未变质的水果，当天做切果盒或鲜榨，明确标注当天制作。
5. **陈列少量多次**：货架不要堆太满，卖一层补一层，减少顾客翻拣造成的损伤。

## 四、几个关键控制指标（每天看）

- **损耗率**：水果店正常损耗5%～10%，超过10%说明进货过多或品类不对。
- **库存周转天数**：易腐品类控制在1～2天，整体不超过3～5天。
- **单品动销**：连续3天卖不动的单品，下次停进或减半。
- **临期清单**：每天列出“明天必须清掉”的货，优先促销。

## 五、最简单的执行口诀

**“少量多次进、当天货当天卖、隔夜货先处理、卖不动就停进。”**
