水果礼盒想好卖，核心不是“每种都放一点”，而是**按价格带和送礼场景做3档搭配**，让顾客一眼知道买给谁。

## 建议主打3个礼盒

### 1. 走量款：88～108元“日常心意盒”
适合员工福利、探病、邻里送礼。

- 苹果 4个（寓意平安）
- 橙子 4个（寓意成功）
- 香蕉 1把（约1kg，看着满）
- 菠萝 1个（撑体积、显丰富）

**配比逻辑**：苹果橙子耐放、成本稳；香蕉填视觉；菠萝做“礼盒感”。  
**包装**：牛皮纸色手提盒＋红色丝带，别过度包装。  
**卖点话术**：“四样果，四季平安，百元内送人有面子。”

### 2. 主推利润款：128～158元“平安旺来盒”
适合节日、客户、亲戚走动，是最容易出量的中间价。

- 苹果 6个（平安）
- 橙子 6个（心想事成）
- 香蕉 1小把（约0.8kg，选短粗好看的）
- 菠萝 1个（旺来）

**升级点**：苹果橙子选大果、果面干净；菠萝选金钻或凤梨，贴“旺来”标签。  
**卖点话术**：“平安＋成功＋旺来，送礼寓意全齐。”  
建议这个档位占礼盒SKU的50%以上。

### 3. 高客单款：198～268元“精品果礼”
适合商务、重要客户、节庆高端送礼。

- 苹果 6～8个（精品大果，单果分级）
- 橙子/沃柑 6～8个（选甜度高、易剥的）
- 香蕉 不放或只放精品小把（香蕉易压、不耐放，高端盒里少放）
- 菠萝 1个精品凤梨，或换成更贵的进口水果补位

**关键**：高端盒不要靠香蕉撑量，香蕉在高端场景里反而拉低质感。可以用“苹果＋橙子＋凤梨＋1～2款高价值水果”做结构。

## 搭配上的4个实操原则

1. **香蕉少放、晚放**：香蕉催熟其他水果，礼盒里放多了容易坏，最好出货前再放，或用小把单独固定。
2. **苹果橙子做主角**：耐运输、寓意好、成本可控，适合做礼盒主体。
3. **菠萝负责“显大”和寓意**：一个菠萝很撑盒，标签写“旺来”，比散放好卖。
4. **按场景命名，不按水果命名**：叫“平安旺来盒”“探病安心盒”“员工福利盒”，比“苹果橙子香蕉菠萝组合”好卖得多。

## 定价和陈列建议

- 三档价格拉开：**98 / 138 / 218元**左右，避免只做一个价。
- 门口堆头放主推款，贴场景标签：**探病、员工福利、节日送礼、客户答谢**。
- 提供**企业团购价**：10盒以上9折，50盒以上另谈，水果店礼盒很大一部分靠团购。
- 做“**可替换**”：苹果可换梨，橙子可换沃柑，菠萝可换凤梨，但礼盒主视觉不变，减少损耗。

**最推荐先上的组合**：  
**苹果6＋橙子6＋香蕉1小把＋菠萝1个，定价138元左右**，作为主推款；再用苹果4＋橙子4＋香蕉＋菠萝做98元走量款。高端款先少备，接预定再做，避免压货。
