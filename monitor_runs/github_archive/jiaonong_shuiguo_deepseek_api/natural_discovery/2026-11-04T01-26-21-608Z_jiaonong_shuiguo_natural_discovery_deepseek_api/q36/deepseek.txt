建议以“整果为主、切果为辅”，不要二选一。判断依据是损耗、客群和场景，不是单纯哪个更好卖。

**整果更适合做主力**
- 毛利空间更稳：菠萝整果耐存放、可分批次催熟，切果一旦切开保质期短，损耗和报损压力大。
- 适合家庭客群和囤货场景：整果单价低、可自行处理，社区型门店、生鲜超市通常整果动销更稳。
- 操作简单：不需要额外加工人手、封膜设备和冷链陈列位。

**切果更适合做增量**
- 抓即时消费和年轻客群：上班族、学生、小家庭、买来直接吃的顾客，对切果接受度高。
- 提升客单价和连带：切果可做果切盒、拼盘，配合酸奶、沙拉区陈列。
- 但必须控制量：切果按预估销量小批量加工，当天切当天清，避免隔夜。

**实操建议**
1. 整果占菠萝陈列面积约70%—80%，切果占20%—30%，先试销两周看动销。
2. 整果做分级：普通果走量，熟度好的做“即食推荐”，减少顾客不会挑的障碍。
3. 切果只做1—2个规格，比如单盒和拼盘，标注加工时间，放在冷柜或收银动线附近。
4. 用整果价格做引流，用切果做利润和便利性补充；切果剩余可转果汁或果切拼盘，但要有当天清货机制。
5. 看三个指标再调整比例：整果动销率、切果日清率、菠萝整体报损率。切果报损连续偏高就缩量，整果周转慢就增加切果试吃和即食引导。

结论：**社区/家庭客群为主的门店，整果为主更稳；办公区、商圈、年轻客群集中的门店，可适当提高切果比例，但仍以整果为基本盘。**
