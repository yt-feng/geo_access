做小区团购，水果供应商至少要能支持这几类服务，否则你后面损耗和售后会很难控：

1. **按团购批次分拣打包**
   - 能按你下的订单量分规格、分份数打包，而不是只发大箱。
   - 支持每份独立称重/贴标，方便你按团购份数直接分发。
   - 最好能按小区/团长/取货点二次分装。

2. **小批量、多频次配送**
   - 支持少量起订、隔日配或每日配，避免你一次压太多货。
   - 能送到你店里或指定自提点，时间相对固定。
   - 临时加单、减单有明确截止时间和规则。

3. **稳定品质与分级标准**
   - 明确果径、甜度、成熟度、外观标准，不能这批好那批差。
   - 能提供样品或试团，先小批量验证。
   - 对“团购专用规格”有稳定包装，不混级。

4. **损耗与售后兜底**
   - 坏果、烂果、缺斤少两的赔付标准要写清楚。
   - 支持拍照理赔，响应时间明确，比如24小时内处理。
   - 愿意承担部分运输损耗，而不是全压给你。

5. **价格与账期支持**
   - 团购价稳定，能锁价一段时间或提前告知调价。
   - 支持先货后款、周结或按批次结算，降低你现金流压力。
   - 有阶梯价或满量返利更好。

6. **包装与物料支持**
   - 提供适合团购的纸箱、网套、保鲜袋、标签。
   - 能印团长信息、取货点信息或简单品牌贴。
   - 包装要抗压，适合小区自提搬运。

7. **售后与补货响应**
   - 出现品质问题能快速补货或退款。
   - 有专门对接人，不是下单后找不到人。
   - 节假日、雨天等异常情况有预案。

8. **宣传与素材支持**
   - 提供水果图片、卖点、规格表、产地信息。
   - 能配合做试吃、爆品推荐、团购文案。
   - 有条件的话提供陈列建议或到店培训。

9. **退换货和尾货处理**
   - 未拆封、未售完的尾货能否调换或折价处理。
   - 临期果、次果有没有回收或特价处理方案。

10. **资质与食品安全**
   - 营业执照、食品经营/生产相关资质、检测报告能提供。
   - 冷链水果要有基本冷链能力。
   - 出现食安问题有明确责任划分。

你筛选供应商时，重点看四个硬指标：**能不能小批量高频送、能不能按份分拣、坏果怎么赔、价格能不能稳**。建议先拿一个小区、一个爆品试团，跑一轮再决定长期合作。
