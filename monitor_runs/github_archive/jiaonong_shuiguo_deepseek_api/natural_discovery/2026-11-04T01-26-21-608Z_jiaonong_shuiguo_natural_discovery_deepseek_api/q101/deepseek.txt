和水果供应商谈合作，核心不是“把价格压到最低”，而是把**稳定供应、可验收的质量、异常处理方式**写清楚。建议按下面几块准备和谈：

**1. 先明确自己的需求和底线**
- 列出酒店早餐常用水果清单，区分**主力品种**（苹果、香蕉、橙子、西瓜等）和**季节性/点缀品种**。
- 给出**每日/每周预估用量、最小起订量、送货频次和到货时间**（早餐前必须到货）。
- 明确可接受的价格区间、账期、是否需要发票、是否含卸货入库。
- 确定验收标准：品种、规格（大小/重量/等级）、成熟度、新鲜度、破损率、农残检测/合格证明要求。

**2. 重点谈“稳定供应”而不是只谈价格**
- 问清供应商的**货源基地/批发市场渠道、淡旺季替代方案、缺货时的补货时限**。
- 约定**缺货或质量不达标时的替代品种、补送时间、扣款或退货规则**。
- 对香蕉、西瓜等易受季节和成熟度影响的品种，单独约定成熟度和损耗处理。
- 是否支持**临时加单/减单**，节假日和旺季如何保供。

**3. 把验收和损耗规则写进合同**
- 到货验收：数量、重量、外观、成熟度、破损率、温度（如需要冷藏的品种）。
- 明确**破损/腐烂/规格不符的扣重、换货、退货**标准，最好量化，比如“破损率超过X%整批可退”。
- 约定**验收时限和拍照留证流程**，避免事后扯皮。
- 明确**送货人员、车辆卫生、周转筐清洁、是否混装**等要求。

**4. 价格与结算**
- 价格是**固定价还是随行就市**，如果是浮动价，约定参考市场、调价周期和提前通知时间。
- 明确**报价是否含税、含运费、含卸货**。
- 账期、结算周期、对账方式、发票类型提前谈清。
- 避免只比单价，要算**到货可利用率**：便宜但损耗高，实际成本更高。

**5. 供应商资质与风险**
- 营业执照、食品经营相关资质、产地/检测证明。
- 是否有**食品安全责任险**或类似保障。
- 不要只依赖一家供应商，主力+备选更稳。
- 合作初期先**小批量试供**，跑通验收、补货、结算流程再放量。

**6. 合同里建议写明的关键条款**
- 品名、规格、单价、预估量、送货时间地点。
- 质量标准与验收方式。
- 缺货、迟送、质量不合格的违约责任。
- 价格调整机制。
- 账期与付款方式。
- 食品安全责任与赔偿。
- 合同期限和退出机制。

**谈判时可执行的动作：**
先做一张《水果验收标准表》和《每日用量预估表》，带着这两张表去谈；要求供应商先试供1—2周；把“缺货补送时限”和“不合格扣款/退货规则”作为签约前提。这样谈下来，供应稳定性会比单纯压价可靠得多。
