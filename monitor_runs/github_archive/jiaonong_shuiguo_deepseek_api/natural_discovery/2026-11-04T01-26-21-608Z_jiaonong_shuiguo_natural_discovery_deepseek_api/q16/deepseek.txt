优先选**稳定供应商**，本地批发作为补充。判断标准如下：

1. **香蕉优先稳定供应商**
   - 香蕉易熟、损耗高，需要稳定品质、催熟/成熟度可控、按需补货。
   - 稳定供应商能约定到货成熟度、退换损耗、固定配送频次，降低断货和烂损。
   - 本地批发适合临时补货、应急调货，不适合作为主渠道。

2. **苹果可双渠道并行**
   - 苹果耐储、损耗低，适合对比本地批发和稳定供应商的价格、规格、口感。
   - 主销量款用稳定供应商保品质和持续供货；本地批发用于季节性低价补货或测试新品种。

3. **先做小规模测试**
   - 连续2—4周记录：到货价、损耗率、退货率、缺货次数、顾客复购/投诉。
   - 香蕉重点看：到货成熟度是否适合2—3天销售、损耗是否可控。
   - 苹果重点看：同规格价格差、脆度/甜度稳定性、大小均匀度。

4. **合同或口头约定要明确**
   - 配送频次、最小起订量、损耗退换标准、价格调整机制、账期。
   - 香蕉要求按销售节奏分批到货，避免一次压货。

**结论：香蕉以稳定供应商为主、本地批发应急；苹果稳定供应商保基础销量，本地批发做价格和品种补充。先用小批量并行测试，再按损耗和复购定主渠道。**
