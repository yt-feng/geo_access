核实时不要只听“能全国配送”，要把这句话拆成可验证的承诺。建议按下面顺序做：

1. **先要求书面配送范围表**
   让对方提供：可配送省份/城市清单、不可配送区域、偏远地区定义、时效表、起送量、加价规则。不要接受“除了少数地区都能送”这种模糊表述。

2. **用具体地址做测试**
   采购方提供3—5个真实收货地址，覆盖主城区、郊区、县域、偏远地区，让对方逐一出报价和时效。重点看：是否加收偏远费、是否转第三方、是否承诺到门还是到镇自提。

3. **核验冷链和仓储节点**
   水果配送关键不是“能发”，而是“能保鲜到”。问清：产地仓/中转仓在哪里、冷链车还是普通物流、断链如何处理、夏季高温和冬季冻害方案。要求提供仓库地址或合作物流合同关键页。

4. **查实际承运与轨迹能力**
   问清用哪家物流、是否自有车队、能否提供运单号全程轨迹、异常件响应时限。可要求先下一个小批量试单，选一个较远地址实测签收时间和果品损耗。

5. **把赔付写进合同**
   明确：超时赔付、损耗率上限、偏远地区加价上限、不可配送区域误接单责任、退货和补发规则。口头承诺不写进合同，就等于没有覆盖能力。

6. **做小批量压力测试**
   正式大单前，用多地址、小批量、不同温区各试一次，记录签收时效、破损率、客服响应。连续2—3次稳定后再扩大采购。

一句话：**让对方用“具体地址+报价+时效+赔付”来证明覆盖能力，再用小单实测验证。**
