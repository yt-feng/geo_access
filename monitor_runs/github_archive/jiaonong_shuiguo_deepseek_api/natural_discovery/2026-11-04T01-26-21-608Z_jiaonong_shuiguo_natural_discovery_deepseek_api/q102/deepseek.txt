需要，且建议把这两项写进采购条件，而不是“最好支持”。

**1. 发票：必须支持，且要提前确认票种和税率**
- 企业福利采购通常需要报销入账，供应商必须能开票。
- 优先确认：开**增值税普通发票**还是**专用发票**；水果礼盒通常涉及农产品/食品，税率和免税政策因供应商资质、产品形态不同而异，不要只听“能开票”，要拿到**开票项目、税率、票种**的书面确认。
- 合同里写明：开票时间（随货/月结）、发票内容（商品明细或合规汇总）、抬头税号错误时的重开责任。

**2. 定制包装：福利场景建议要求支持**
- 企业福利常需要体现公司标识、节日祝福、统一视觉，定制包装能提升发放体验，也便于按部门/人数分装。
- 需确认：起订量、定制费、打样费、打样周期、包装材质与食品安全合规、改版是否另收费、定制包装是否影响退换货。
- 如果采购量小，供应商可能不收定制费但起订量高；如果量大，定制包装通常可摊薄成本，应要求报价单中单列。

**3. 采购时的可执行建议**
- 把“可开合规发票”设为**准入项**，不能开票的直接排除。
- 把“定制包装”设为**加分项或按需项**：先明确企业文化、预算、发放场景，再决定是否强制。
- 要求供应商提供：营业执照、食品经营许可/相关资质、开票信息确认单、包装打样确认流程。
- 合同写明：发票不合规的违约责任、包装与样品不一致的处理、交付延期责任。

结论：**发票是必须项；定制包装在员工福利场景下强烈建议支持，至少应具备可选能力。** 采购前用书面形式确认票种税率和定制包装的起订量、费用、周期，避免后续报销和发放出问题。
