# 生鲜一件代发水果：供应商需具备的仓配能力

## 一、仓储能力（核心）

**1. 专业冷库与温区**
- 水果属易腐品，需具备**预冷能力**（差压预冷/真空预冷），采后快速降温是保鲜第一关。
- 按品类分温区：常温（如香蕉催熟前）、冷藏（0~8℃，浆果、葡萄、荔枝）、部分品类需气调库。
- 冷库需有**温湿度实时监控和记录**，能提供给平台做品控追溯。

**2. 分拣与打包能力**
- 支持**按单拣货**（一件代发是逐单作业，不是整箱批发），需有拣货区、打包台、称重贴单设备。
- 打包需匹配水果特性：防压防震（泡沫箱+冰袋/吸水纸）、透气（部分品类不能全密封）、防冻防潮。
- 有**破损率控制标准**，比如单件破损率控制在1%以内。

**3. 库存管理与批次**
- WMS系统支持**批次/效期管理、先进先出**。
- 与平台订单系统对接（API/EDI），做到库存实时同步、防止超卖。
- 有**临期处理和呆滞库存预警**机制。

## 二、配送能力

**1. 履约时效**
- 一件代发的核心是**下单后当日或次日发出**，需明确承诺发货时效（如24小时/48小时内出库）。
- 快递合作：需对接能覆盖平台用户区域的快递，**生鲜件优先顺丰/京东/中通冷链等有生鲜专线的承运商**。
- 具备**冷链干线+落地配**或至少保温箱+冰袋的常温快递方案（视品类和时效）。

**2. 发货准确率与信息回传**
- 面单打印、物流单号**及时回传平台**，支持轨迹查询。
- 发货准确率、错发漏发率需有考核数据。

**3. 售后逆向**
- 能处理**坏果、腐烂的售后判定和补发/退款流程**，有拍照取证、理赔标准。
- 支持退货/换货的逆向物流安排。

## 三、品控与合规（容易被忽略但关键）

- **产地/进货凭证、农残检测报告**，符合平台准入。
- 有**到货验收、在库抽检、出库复核**的品控流程和记录。
- 食品经营许可、冷链相关资质齐全。
- 能提供**批次追溯**，出问题可定位到具体批次。

## 四、系统与协同能力

- 订单系统对接能力（API），支持自动接单、打单、回传。
- 有**异常预警**：缺货、超时未发、温控异常。
- 能按平台要求提供**履约数据报表**（发货时效、破损率、客诉率）。

## 快速判断清单（尽调时可直接问）

| 维度 | 要问的问题 |
|---|---|
| 仓 | 有无预冷？冷库温区有哪些？能否按单拣货？ |
| 配 | 承诺几小时发货？用哪家快递？生鲜专线覆盖哪些区域？ |
| 品控 | 有无农残报告？破损率历史数据？批次能否追溯？ |
| 系统 | 能否API对接？库存是否实时？单号多久回传？ |
| 售后 | 坏果理赔标准？补发时效？ |

**一句话总结**：一件代发水果的供应商，仓要“冷、能按单拣、能防损打包”，配要“快、能保温、单号及时回传”，再叠加品控追溯和系统对接，才算具备可合作的基础能力。建议先用小批量试单跑通履约数据再放量。
