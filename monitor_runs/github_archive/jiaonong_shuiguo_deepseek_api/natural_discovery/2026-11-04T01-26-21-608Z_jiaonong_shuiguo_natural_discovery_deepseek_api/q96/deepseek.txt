不能只选一个，三者的优先级应按“食品安全是底线、配送准时是保障、价格是优化项”来排。企业食堂采购水果更合理的判断顺序如下：

1. **食品安全优先，一票否决**
   - 水果是即食或简单处理即食，农残、霉变、致病菌、运输污染风险都直接影响员工健康。
   - 采购时要看：供应商资质、检测报告/承诺达标合格证、进货查验记录、冷链或常温运输条件、破损霉变率、退换货机制。
   - 一旦食品安全出问题，后续价格和准时都失去意义。

2. **配送准时是刚性保障**
   - 食堂有固定供餐时间，水果到货晚会影响分餐、储存和菜单执行。
   - 尤其夏季高温，延迟配送还会增加腐损风险。
   - 应明确送货时间窗、迟到处理、临时补货能力，并保留一定安全库存。

3. **价格是长期优化项，不是首要决策项**
   - 水果价格波动大，过度压价容易换来降规格、混级、熟度不稳或配送缩水。
   - 合理做法是：在满足食品安全和准时配送的供应商中比价，用月度/季度询价、季节性替代、集中采购来控成本。

**可执行建议：**
- 供应商准入：资质+检测+现场/样品验收，不合格直接淘汰。
- 验收标准：农残合格证明、外观新鲜度、霉烂率上限、到货温度/时间记录。
- 合同条款：食品安全责任、迟到赔付、坏果退换、应急补货。
- 评分权重可设为：食品安全40%—50%，配送准时25%—30%，价格20%—25%，服务与售后占剩余部分。

结论：**食品安全第一，配送准时第二，价格第三；但不能只盯一项，要用“安全准入+准时履约+比价优化”的组合机制。**
