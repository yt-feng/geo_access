酒店采购水果盘原料时，建议把“规格标准”和“外观标准”写进采购单/验收单，作为到货验收和扣款依据。可按以下维度要求供应商：

**一、规格标准**
1. **品种与产地明确**：写明具体品种（如红富士、贵妃芒、夏黑葡萄）、等级和允许产地范围，不接受同品类低端替代。
2. **单果重量/直径分级**：按品种设定规格区间，例如苹果单果180–220g、橙子直径70–80mm、西瓜单果5–7kg；同一批次规格偏差不超过约定范围（如±10%）。
3. **成熟度**：要求适合酒店即时切配的成熟度，通常7–8成熟到货、可短时后熟；禁止到货即过熟或青硬无法食用。
4. **数量与净重**：按净重验收，明确去皮、去叶、去梗后的可食率或净重标准；腐烂、破损、不可用部分不计入净重。
5. **包装规格**：规定每箱/每筐净重、单层摆放、防压防潮，标注品种、等级、产地、采收/包装日期、供应商信息。
6. **食品安全**：符合国家食品安全标准，提供农残检测合格证明或承诺；不得使用违规保鲜剂、染色剂、打蜡需符合规定。

**二、外观标准**
1. **新鲜度**：果面洁净、无萎蔫、无皱缩、无发酵味、无霉斑；果柄新鲜（如适用）。
2. **形状与大小**：果形端正、无明显畸形；同批次大小、色泽基本一致，便于摆盘统一。
3. **色泽**：达到该品种应有的色泽，着色均匀；不接受明显青果、着色不良或日灼、冻伤果。
4. **表面缺陷**：无明显机械伤、压伤、裂口、虫眼、病斑、药斑；允许的轻微瑕疵需约定比例（如单果轻微擦伤面积不超过1cm²，且每箱不超过5%）。
5. **洁净度**：无泥土、枝叶杂物、虫体、异物；预冷或冷藏到货的需符合温度要求。
6. **一致性**：同一批次品种、等级、成熟度、色泽、规格统一，适合酒店自助餐/果盘标准化出品。

**三、验收与责任条款**
1. **抽检比例**：建议每批抽检10%–20%，重点查规格、成熟度、腐烂率和外观缺陷。
2. **不合格判定**：约定腐烂率、破损率、规格不符率上限（如腐烂率≤2%、外观不合格率≤5%），超限可拒收或按比例扣款。
3. **退换货**：到货2–4小时内完成验收，不合格品供应商限时补换；因原料问题导致酒店客诉或损耗，由供应商承担。
4. **留样与追溯**：每批次留样并记录产地、批次、检测信息，便于追溯。

实际执行时，建议把上述内容做成《水果原料验收标准表》，按品种逐项列明规格区间、允许缺陷和抽检比例，随采购合同附上，供应商签字确认。
