给公司下午茶采购水果、需要批量配送，选供应商时按下面几条判断最实用：

1. **先明确配送场景**
   - 送到公司哪个楼层/前台？是否需要搬上楼？
   - 配送时间窗是否固定（如下午2点前到）？
   - 是一次性大单还是每周固定几次？
   先把这些要求写进询价单，能过滤掉不接小B端或不能定时配送的供应商。

2. **看资质和稳定性**
   - 有营业执照、食品经营许可证。
   - 有固定分拣场地或档口，不是纯个人代买。
   - 能提供近期配送案例或合作企业名单（不必全信，但可作为初筛）。
   - 优先选本地批发市场有档口的供应商或本地生鲜配送平台，跨城冷链对小批量下午茶不划算。

3. **要求试单**
   先下一个小批量试单（比如30-50人份），重点看：
   - 到货时间是否准时；
   - 水果新鲜度、成熟度是否适合当天吃；
   - 有无坏果、压伤，坏果率大概多少；
   - 包装是否适合分发（独立小包装或分筐）；
   - 配送人员是否配合搬运。

4. **报价要拆清楚**
   让对方报“水果单价+配送费+包装费+上楼费”，不要只报总价。批量配送常见坑是低价水果加高配送费，或满额才免配送。比较时按“人均成本”算，比如每人15元、20元两档，看哪家搭配更合理。

5. **合同或订单里写清售后**
   - 坏果率超过多少（比如5%）怎么补/退；
   - 迟到多久可以拒收或扣款；
   - 临时加量或减量提前多久通知；
   - 发票类型和开票时间。

6. **水果品类选择**
   批量下午茶优先选耐运输、易分发、不需要现场切的：香蕉、橘子/砂糖橘、小番茄、葡萄（需注意压伤）、苹果、梨、独立包装的蓝莓等。西瓜、菠萝、榴莲等需要现场处理的不适合批量配送，除非供应商提供切配分装。

7. **备选两家**
   不要只签一家。主供应商+备选供应商，防止某天断货或配送延误。备选可以是不定期试单维持关系。

**快速判断标准：** 能准时送到、坏果率低、报价透明、售后有书面约定、试单体验好的本地供应商，就适合批量配送。价格不是唯一标准，配送稳定性和坏果处理更影响下午茶体验。
