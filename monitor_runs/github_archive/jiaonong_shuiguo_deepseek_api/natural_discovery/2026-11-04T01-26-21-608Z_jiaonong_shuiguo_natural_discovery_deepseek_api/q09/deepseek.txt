和供应商谈旺季合作，核心是**把“断货风险”提前锁进条款**，而不只是问“能不能保证供货”。建议重点问清以下几类问题：

**1. 供货能力与旺季保障**
- 旺季日均/峰值能给我供多少量？按品种、规格分别说。
- 你同时供几家店？旺季会不会优先保大客户、把我排后面？
- 有没有备用货源或备用产地？主产区减产时怎么补？
- 旺季前能否提前锁定库存？锁量要不要定金、锁多久？

**2. 价格与调价机制**
- 旺季价格怎么定？是锁价还是随行就市？
- 调价提前几天通知？有没有涨跌幅上限？
- 量大有没有阶梯价？长期合作有没有返点？
- 报价含不含运费、损耗、包装？到店价还是产地价？

**3. 品质与验收标准**
- 每个品种的规格、成熟度、甜度、大小怎么定标准？
- 到货损耗率控制在多少？超标怎么赔或补？
- 允许的次品比例是多少？谁来判定？
- 能不能先看样品、试供一批再定？

**4. 配送与时效**
- 下单后多久到货？旺季频次能不能加密？
- 配送时间窗口是否固定？迟到影响销售怎么处理？
- 运输温控、保鲜怎么做？坏果谁承担？
- 临时加单能不能接？加单截止时间？

**5. 断货与违约条款（最关键）**
- 约定供货量完不成，怎么补偿？是补货、赔差价还是扣款？
- 断货导致我临时从别处高价调货，差价谁承担？
- 质量不达标拒收后，多久补货？
- 连续几次违约能不能终止合作？押金/保证金怎么退？

**6. 结算与账期**
- 现结还是账期？账期多久？
- 押金多少、什么条件退？
- 退货、损耗、罚款怎么在货款里扣？

**7. 合作弹性**
- 旺季能不能签“保底量+浮动量”协议？
- 淡季是否也要承诺采购量？避免被绑定。
- 独家还是非独家？非独家更利于你留后手。

**实操建议：**
- 不要只口头承诺，把**供货量、到货时限、损耗率、断货赔偿**写进合同或订单确认单。
- 旺季前**至少备两家供应商**，主供+备供，备供哪怕量小也保持合作。
- 先小批量试供，看实际到货品质和准时率，再放量。
- 每天记录到货量、损耗、缺货情况，作为谈赔偿和换供应商的依据。

一句话：**问量、问价、问标准、问时效，最后全部落到“断货怎么赔、品质不达标怎么补”的书面条款上。**
