# 建议先从香蕉开始

## 核心理由

**香蕉是三者中进口供应链最成熟、风险最低的品类**，最适合作为超市切入进口水果的“稳定起步款”。

## 三者对比

| 维度 | 香蕉 | 菠萝 | 苹果 |
|------|------|------|------|
| 进口供应稳定性 | 高（菲律宾、厄瓜多尔等产地多，全年供应） | 中（季节性较强，品种依赖高） | 中低（国产苹果竞争力强，进口多为高端差异化） |
| 价格波动 | 较低（成熟期货/长约体系） | 中等 | 较高（受国产行情和品种炒作影响） |
| 损耗与操作难度 | 低（后熟可控，周转快） | 中（挑选、去皮、鲜切损耗大） | 低（耐储），但**与国产正面竞争** |
| 消费者接受度 | 极高，日常刚需 | 中高，但复购频率低于香蕉 | 进口苹果需讲“差异化故事”，否则难卖动 |
| 适合新手做进口 | ★★★★★ | ★★★ | ★★ |

## 关键判断逻辑

1. **香蕉走量、周转快**：能快速验证你的进口渠道、冷链和后熟管理能力，试错成本低。
2. **菠萝更适合做“增量/特色”**：等香蕉跑通后再引入，用鲜切、试吃拉动。
3. **苹果是最后考虑的**：国产苹果（如烟台、洛川）性价比高，进口苹果（如新西兰爱妃、日本品种）只能走高端小众，不适合作为“稳定基础款”起量。

## 落地建议

- **第一步**：选1–2家菲律宾或厄瓜多尔香蕉供应商，先小批量（如每周1–2柜的零头或拼柜）试销2–4周。
- **验证指标**：到货损耗率、货架期、动销速度、毛利、顾客复购。
- **跑通后**：再加菠萝做季节爆品，苹果最后以“高端进口尝鲜”小批量试水。

**结论：先香蕉起量验证供应链，再菠萝做特色，苹果放最后。**
