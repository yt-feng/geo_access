核心原则：**别追求“全黄熟香蕉”，采购时选偏生、带一点绿的，并控制到货后的存放条件。**

1. **采购成熟度**
   - 选**7～8成熟**：果身黄但两端仍略绿、手感硬实、无黑点。
   - 避免已经全黄、有梅花点、果柄发黑的香蕉，这类到店后很快变黑。
   - 批量采购时可按“今天用、明后天用”分批买不同成熟度。

2. **检查机械伤**
   - 有磕碰、压伤、裂口的香蕉会先黑先烂，采购时翻箱检查。
   - 搬运时避免堆压，香蕉怕挤怕摔。

3. **到店后立即拆箱通风**
   - 不要原箱闷着，纸箱内积热和乙烯会催熟。
   - 拆开包装，放在**阴凉通风处**，理想温度约**13～15℃**。
   - **不要放冰箱冷藏**，香蕉低温会冻伤发黑。

4. **悬挂或单层摆放**
   - 能悬挂最好，减少受压面积。
   - 不能悬挂就单层摆放，果柄朝上，避免叠压。

5. **隔离乙烯源**
   - 香蕉不要和苹果、梨、番茄等释放乙烯的果蔬混放。
   - 已熟的香蕉和偏生香蕉分开存放，熟果释放乙烯会催熟生果。

6. **包裹果柄**
   - 用保鲜膜包住香蕉果柄，可减少乙烯从果柄释放，延缓整体成熟。
   - 不要整根密封，否则容易闷出水分和霉。

7. **先进先出，少量多次**
   - 甜品店按日销量少量多次采购，比一次囤大批更稳。
   - 每天先检查，把最熟的优先用于香蕉泥、蛋糕、奶昔等加工用途。

8. **已开始变黑的处理**
   - 表皮少量黑点但果肉正常，可尽快加工使用。
   - 果肉发软发酸、有酒味就不要再用。

一句话：**买偏生、轻拿轻放、拆箱通风、13～15℃阴凉存放、包果柄、远离其他水果、少量多次进货。**
