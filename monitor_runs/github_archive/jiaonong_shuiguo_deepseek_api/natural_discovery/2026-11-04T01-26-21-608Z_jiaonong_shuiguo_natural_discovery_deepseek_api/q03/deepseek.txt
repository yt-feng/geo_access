第一次试单，核心不是“找到最低价”，而是用最小成本验证供货商是否稳定、货是否对路。建议按下面做。

**一、先定试单原则**
- 每家先小批量：香蕉1箱、苹果1箱、橙子1箱，最多再加1个应季单品。
- 不要一次压大货，不要先付长期预付款。
- 同一天或同一周找2～3家对比，别只试一家。
- 试单重点看：到货品质、损耗、重量是否足、补货速度、售后态度、价格是否含运费。

**二、试单前先问清**
问供货商这几项，能过滤掉不少不靠谱的：
1. 香蕉是几成熟发货？到店后大概几天转黄？有没有催熟统一标准？
2. 苹果、橙子是什么规格、产地、等级？是按箱还是按斤？净重多少？
3. 报价含不含运费、装卸费？起送量多少？
4. 坏果、烂果、短斤少两怎么赔？是下次补货抵扣还是当场退？
5. 每天几点截单、几点到店？临时补货能不能加？
6. 能不能先看样品或到货验收后再结算？

**三、三个品类分别怎么验**
- **香蕉**：最考验供应链。看青度是否一致、有没有大面积压伤、催熟是否均匀。试单时记录“到店颜色—第2天—第3天”的变化。如果到店已经全黄或硬青不一致，后续很难卖。
- **苹果**：看大小是否均匀、表皮碰伤、口感脆度、箱内上下是否一致。重点查底层有没有小果、次果混装。
- **橙子**：看皮厚薄、干水、裂果、酸度。现场切开1～2个尝，别只看外观。问清是当季果还是库存果。

**四、到货验收怎么做**
- 当场称重，抽箱检查上下层。
- 每个单品拍照留档：整箱、开箱、坏果特写。
- 记录到货时间、数量、坏果数、重量差。
- 坏果当场挑出，让司机或业务员确认，别等卖完再扯皮。
- 当天就把问题反馈给供货商，看对方处理速度。售后态度比口头承诺重要。

**五、试单后怎么判断**
连续试2～3次再定主供，重点看：
- 品质是否稳定，不是第一次好第二次差；
- 损耗率能不能控制在你能接受的范围内；
- 缺货、晚到时有没有替代方案；
- 价格是否透明，短斤少两是否经常发生；
- 沟通是否顺畅，出了问题是否认账。

**六、夫妻店实操建议**
- 先定一家主供、一家备供，不要只押一家。
- 香蕉可以稍谨慎，损耗高；苹果、橙子可先做引流品试水。
- 第一次结算尽量短账期或货到付款，别被“低价”诱导压货。
- 把每次试单的到货品质、损耗、售后记成简单表格，三次后自然能看出谁靠谱。

一句话：**小批量、多对比、重验收、看售后，连续试三次再定主供。**
