水果店遇到坏果，先别急着扣款，按“证据—责任—规则”三步走，结算和赔付会清楚很多。

**一、先固定证据，再谈赔付**
1. 收货时当场抽检，坏果单独挑出，拍全景+特写+货箱标签/批次，最好录开箱视频。
2. 记录品种、数量、进货价、坏果数量、坏果率、到货时间。
3. 坏果单独存放，别混放或直接扔掉，等供应商确认或按约定处理。
4. 当天书面通知供应商，微信/邮件都行，写明批次、坏果数、诉求和回复期限。

**二、按合同/约定定责任**
- 有采购合同或供货协议的，按约定执行：常见是“到货验收合格后风险转移”，验收前坏果由供应商承担；也有约定“损耗率包干”，比如3%以内不赔、超出部分赔。
- 没有书面约定的，按行业惯例和过错协商：运输途中腐坏、到货即坏、内部霉变且非存放问题的，通常由供应商补货、换货或折价赔付；因门店存放不当、超期销售的，一般自担。
- 生鲜易腐，尽量在到货当天或约定验收期内提出，拖久了责任难认定。

**三、常见结算/赔付方式**
1. **补货/换货**：坏果数量下次补发，最常用。
2. **货款抵扣**：本次结算直接扣减坏果金额，按进货价×坏果数量扣，别按零售价扣。
3. **折价接收**：轻微瑕疵可协商降价，比如按七折、八折结算。
4. **退货退款**：坏果率高、无法销售时整批退，运费和责任按约定。
5. **现金赔付**：较少见，需双方书面确认金额和方式。

**四、实操建议**
- 小额、偶发坏果：优先协商“下次补货”或“本单扣减”，别为几箱果伤长期合作。
- 批量、反复坏果：书面发质量异常通知，要求限期整改；连续多次可依合同扣款、减少订单或终止合作。
- 扣款前先和供应商确认，保留沟通记录；单方直接扣款容易引发纠纷。
- 结算单上注明“扣坏果款X元，原因：某批次坏果X斤”，双方签字或微信确认。

**一句话原则：先验收留证，再按约定定责，能补货不扣款，扣款只扣进货成本，所有动作留书面记录。**
