做餐饮客户，核心是按“用途”分规格，而不是按批发市场那套统货思路。菠萝和香蕉分别给你按餐饮场景拆一下。

## 菠萝（餐饮客户）

餐饮用菠萝主要分三类用途，规格要求差异很大：

**1. 鲜切/果盘/自助餐**
- 要**成熟度适中偏生一点**（7-8成熟），到店后还能放2-3天不烂
- 单果重建议**1.2-1.8斤**，太大切出来块头不均，太小出成率低
- 品种优先**金钻/台农17号**，甜度高、芯小、不用泡盐水
- 要求：无黑心、无裂口、冠芽完整

**2. 热菜/菠萝咕咾肉/炒饭**
- 可以用**成熟度更高的**（8-9成熟），甜度够
- 单果**1.5-2.5斤**都行，反正要切丁
- 价格敏感，可以用**国产普通品种**，不必金钻
- 关键：**出肉率**要稳定，芯不能太大

**3. 饮品/果汁/茶饮**
- 要**高糖度**的，最好能测糖（14度以上）
- 规格反而不重要，**按斤或按箱**走
- 可以推**冷冻菠萝块/菠萝丁**作为补充，茶饮店用量大且稳定

**建议你档口备：**
- 金钻/台农17号 中果（1.2-1.8斤）——走鲜切和果盘
- 普通品种 大果（2斤以上）——走热菜
- 冷冻菠萝丁——走饮品

## 香蕉（餐饮客户）

餐饮用香蕉规格比菠萝更细分：

**1. 果盘/自助餐/酒店**
- 要**外观好、大小均匀**，单根**120-150克**最佳
- 成熟度**7-8成**（到店后2-3天刚好）
- 品种：**巴西蕉/威廉斯**，卖相好
- 要求：无黑斑、无碰伤、把型整齐

**2. 烘焙/甜品/香蕉派**
- 要**熟度高的**（9成以上，带黑斑最好），甜度和香气才够
- 规格不重要，**按斤走**，价格要低
- 可以专门收**熟蕉/处理蕉**，成本低，烘焙客户很认

**3. 饮品/奶昔/冰沙**
- 要**熟透的**，越熟越甜越香
- 冷冻香蕉块是茶饮店刚需，用量稳定
- 建议你直接对接**冷冻香蕉**供应商或自己做冷冻

**4. 员工餐/食堂**
- 走**统货/二级蕉**就行，价格优先
- 单根80-120克，不挑外观

**建议你档口备：**
- 精品把装蕉（120-150克/根，7-8成熟）——走果盘酒店
- 熟蕉/处理蕉（按斤）——走烘焙甜品
- 冷冻香蕉块——走饮品

## 实操建议

1. **先摸清客户类型再备货**：餐饮客户分酒店、连锁快餐、茶饮、烘焙、食堂，需求完全不同。别一上来全规格都备，先跑3-5家问清楚用途。
2. **菠萝和香蕉都建议配冷冻品线**：茶饮和烘焙客户对冷冻菠萝丁、冷冻香蕉块的需求量大且稳定，利润比鲜果好，损耗低。
3. **报价按用途报，不按斤报**：比如“鲜切专用金钻菠萝，XX元/斤”，比笼统报“菠萝XX元/斤”更容易成交。
4. **先小批量试供**：餐饮客户最怕断供和品质不稳，先供一周稳定了再谈长期。
