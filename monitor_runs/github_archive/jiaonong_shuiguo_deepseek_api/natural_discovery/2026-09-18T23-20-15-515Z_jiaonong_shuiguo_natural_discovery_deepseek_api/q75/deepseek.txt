第一次跟新的水果供应商合作，小批量试单的核心目标不是赚钱，而是用最低成本验证四件事：**品质稳定性、供货能力、结算信用、损耗真实水平**。所以试单设计要围绕“可验证、可止损、可对比”来做。

## 一、先明确试单目标

试单只回答这几个问题：

1. 到货品质是否达到你批发渠道能卖的标准；
2. 承诺的规格、成熟度、糖度、大小是否一致；
3. 发货时效和包装是否能扛住运输；
4. 损耗率到底多少，谁承担；
5. 出现问题时，对方处理态度和速度如何。

不要一上来就谈长期低价，先验证可靠性。

## 二、试单规模怎么定

建议按“**小批量、多批次、单品类**”设计。

- **金额**：控制在你能承受全损的范围内，比如单次 3000～10000 元，视你自身规模定。
- **批次**：不要只做一单，至少做 **2～3 批**，因为水果受天气、采摘期影响大，一单好不代表稳定。
- **品类**：先选 **1～2 个单品**，最好是当季、周转快、你熟悉的品。不要一次试五六个品。
- **数量**：每批可逐步递增，比如第一批最小起订量，第二批加 30%～50%，第三批再放大。

这样既能看出稳定性，又不会压太多资金。

## 三、试单前必须谈清楚的条款

第一次合作，口头承诺尽量落到文字，哪怕是微信记录。

**1. 规格标准**
- 品种、产地、等级、单果重/直径、糖度、成熟度；
- 允许的次果率、伤果率、大小误差范围；
- 包装方式：箱规、净重、毛重、层数、是否带冰瓶/保鲜剂。

**2. 价格与费用**
- 是产地价、装车价还是到货价；
- 运费、装卸费、包装费谁承担；
- 是否含税、是否开票。

**3. 交付**
- 发货时间、运输方式、预计到货时间；
- 迟到怎么处理，是否补偿；
- 谁负责装车、谁负责卸货。

**4. 验收与售后**
- 到货后多长时间内验收；
- 拍照、视频、称重、开箱取样怎么做；
- 损耗在多少以内算正常，超过部分怎么赔；
- 是补货、扣款还是退货，必须提前写清。

**5. 结算**
- 先款后货、货到付款、还是定金加尾款；
- 第一次建议不要全额预付，尽量“小定金 + 到货验收后付尾款”；
- 如果对方要求全款，试单金额就要更小。

## 四、试单执行流程

1. **先小样确认**：让对方先寄一箱样品，你亲自看货、试吃、称重。
2. **下第一批小单**：按最小起订量走，全程留痕。
3. **到货立即验收**：称重、开箱、拍照、记录损耗，最好同步录像。
4. **记录数据**：到货时间、净重、坏果率、规格达标率、口感、包装破损。
5. **做第二批**：如果第一批合格，再放大一点，重点看稳定性。
6. **横向对比**：同时问 2～3 家供应商，同样标准下比价格、比损耗、比售后。

## 五、验收时重点看什么

- **净重是否足**：很多问题出在毛重当净重、箱底垫重。
- **上下层是否一致**：有的上面好下面差。
- **成熟度是否统一**：太生卖不掉，太熟损耗大。
- **损耗率**：当场分拣，好果、次果、烂果分别称重。
- **包装抗压**：运输后有没有压伤、冻伤、闷坏。

建议做一张简单验收表：

| 项目 | 标准 | 实际 | 是否合格 |
|---|---|---|---|
| 净重 | 约定重量 |  |  |
| 规格 | 单果重/直径 |  |  |
| 糖度 | 约定范围 |  |  |
| 坏果率 | ≤约定比例 |  |  |
| 到货时间 | 约定时间 |  |  |
| 包装 | 无严重破损 |  |  |

## 六、试单后的判断标准

可以继续合作的情况：

- 连续 2～3 批品质稳定；
- 损耗在约定范围内；
- 售后响应快，愿意承担该承担的责任；
- 价格不是最低，但综合成本可控；
- 沟通不拖延，发货不随意改期。

要谨慎或停止的情况：

- 第一批好，第二批明显降级；
- 损耗超标但推责任；
- 总是要求全款、催款很急；
- 规格频繁变，解释含糊；
- 到货时间不稳定，影响你的下游交付。

## 七、给批发商的实操建议

1. **第一次不要贪低价**，低价往往对应高损耗或降级货。
2. **不要只试一家**，至少同时接触 2～3 家，保持替代方案。
3. **试单金额控制在全损可接受范围**，不要影响主业现金流。
4. **所有承诺留文字**，尤其是损耗赔付和到货时间。
5. **每批做记录**，用数据判断，不靠感觉。
6. **试单期不压大库存**，快进快出，先跑通链路。
7. **尾款验收后再付**，这是对品质最有效的约束。

一句话总结：**小批量、多批次、单品类、强验收、留尾款、做对比。** 先验证供应商靠不靠谱，再谈放量和压价。
