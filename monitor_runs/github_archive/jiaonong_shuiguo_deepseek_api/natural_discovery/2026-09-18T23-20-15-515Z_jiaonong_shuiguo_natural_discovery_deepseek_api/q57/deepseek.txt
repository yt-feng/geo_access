对绝大多数餐饮连锁，**水果优先中央厨房统一收货**，但要做“分级”：耐储、标准化程度高的水果走中央厨房；易损、短保、门店即用即摆的水果可门店直配或门店二次验收。

可以按下面判断。

**一、中央厨房统一收货更适合的情况**
- 水果用于统一配方：果切、沙拉、甜品、饮品、酱料、拼盘。
- 品类相对耐储：苹果、橙子、柠檬、西瓜、哈密瓜、火龙果、猕猴桃等。
- 门店数量多，采购量集中，需要统一品质、统一价格、统一损耗核算。
- 总部要控供应商、控账期、控食品安全追溯。
- 需要做农残检测、分拣、催熟、清洗、切配、称重分包。

**好处：**
1. 采购议价强，供应商更愿意配合。
2. 品控标准统一，避免各店收货尺度不一。
3. 食品安全追溯更清晰，农残检测和留样更集中。
4. 减少门店收货人力，店长不用天天盯水果。
5. 损耗、出成率、成本能按中央厨房口径统一核算。
6. 适合做净果、果切、定量包装，减少门店操作差异。

**代价：**
1. 多一次装卸和短驳，易碰伤、压伤。
2. 中央厨房需要冷库、分拣区、催熟区、检测能力。
3. 配送频次不够时，门店会出现断货或库存积压。
4. 对冷链和到店时效要求高。
5. 初期系统、称重、标签、报损流程要跟上。

**二、门店分开收货更适合的情况**
- 水果是门店现场展示、现切现卖、顾客自选，比如火锅店自助水果、烤肉店小菜台、快餐店果切杯。
- 极短保、极易损：草莓、蓝莓、树莓、樱桃、荔枝、杨梅、芒果、熟香蕉、水蜜桃等。
- 门店密度低、配送线路长，中央厨房送过去反而损耗更大。
- 单店销量差异极大，统一订货容易错配。
- 供应商能直送门店，且总部能远程控品控和价格。

**好处：**
1. 减少中间转运，易损水果外观更好。
2. 门店按当日客流灵活补货。
3. 短保水果周转更快。
4. 配送成本可能更低。

**代价：**
1. 各店验收标准容易不一致。
2. 采购分散，议价和品控弱。
3. 食品安全追溯和农残检测更难统一。
4. 容易出现门店私自换供应商、虚报损耗、账实不符。
5. 总部难准确掌握真实毛利和损耗。

**三、更优的落地方式：混合模式**
建议不要二选一，而是分品类、分场景：

1. **中央厨房统采统收统配**
   - 苹果、橙子、柠檬、西瓜、哈密瓜、火龙果、猕猴桃、葡萄等。
   - 用于标准饮品、沙拉、甜品、果切原料。
   - 中央厨房做检测、分拣、催熟、切配、定量包装。

2. **供应商直送门店，总部定供应商和标准**
   - 草莓、蓝莓、樱桃、荔枝、杨梅、熟香蕉、水蜜桃等。
   - 门店按总部验收标准收货，拍照上传，系统留痕。
   - 总部做飞行检查、神秘顾客、损耗稽核。

3. **中央厨房统采，门店二次验收**
   - 适合中央厨房配送条件一般，但总部又要控采购的情况。
   - 中央厨房负责供应商、价格、检测；门店负责到店品质确认和差异上报。

**四、决策看这几个指标**
- 门店数量：超过20—30家，中央厨房优势明显。
- 单店日均水果用量：用量越大，越适合统采。
- 水果易损度：越易损，越倾向门店直配。
- 配送半径：2小时内冷链可达，中央厨房更可行；超过4小时，易损品慎用。
- 加工需求：需要切配、称重、包装，中央厨房更优。
- 食安要求：越高，越应中央统一检测和追溯。
- 信息系统：没有订货、收货、报损、称重、追溯系统，不建议全部门店分散收货。

**五、推荐结论**
- 如果你们是连锁餐饮，且有中央厨房：**主水果统收统配，易损短保水果门店直配，总部统一管供应商和验收标准。**
- 如果你们没有中央厨房，但门店多：**总部统采统价，供应商分线路直送门店，门店按标准验收并拍照留痕。**
- 如果门店少、水果用量小、以易损水果为主：**门店分开收货更现实，但必须总部定标准和供应商。**

一句话：**能标准化的走中央厨房，不能标准化的走门店直配；总部控规则，门店控到店品质。**
