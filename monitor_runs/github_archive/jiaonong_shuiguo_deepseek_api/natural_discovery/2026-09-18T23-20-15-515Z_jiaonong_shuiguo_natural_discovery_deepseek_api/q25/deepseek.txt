门店多、单店量小，核心矛盾是：**你需要多品类、高频次、小批量、能配送到店的供货方式，但你的单店采购量又不足以让供应商给你好价格和好服务**。

适合你的模式，按优先级排：

## 1. 区域批发市场 + 自采/代采（最现实）
- 适合：门店集中在同一城市或周边
- 做法：在本地批发市场固定1-2个档口，或雇一个采购/司机每天统采后分拨到各店
- 优点：品类全、起订量低、价格随行就市、现金结算灵活
- 缺点：损耗和品控靠你自己，需要有人盯货
- 关键：**把多店需求合并成一次采购**，这样你实际采购量就不小了

## 2. 本地水果供应链公司/配送商（省心但加价）
- 适合：门店分散、你没精力自采
- 做法：找做B端配送的供应链公司，按门店下单、次日达
- 优点：一站式、有品控、能退换、省人力
- 缺点：加价率通常10%-25%，小单可能收配送费或设起订额
- 关键：谈**多店合并结算、按店分拣配送**，而不是每店单独下单

## 3. 产地/一级供应商 + 区域分仓（做大规模后）
- 适合：门店数足够多、单城门店密度够
- 做法：你自己在城市设一个小分仓，从产地或一级商整车进货，再分拨到店
- 优点：毛利最高
- 缺点：需要仓储、损耗管理、分拣人力，起步阶段不划算
- 关键：**先跑通前两种，等单城日销量能凑够整车再上**

## 4. 联采/抱团采购（放大议价权）
- 适合：你是连锁但不是巨头
- 做法：和同城其他非竞争连锁超市组成采购联盟，合并订单找供应商
- 优点：用别人的量补自己的量，拿到更好价格
- 缺点：协调成本高，品控标准要统一

## 5. 单品爆款直采 + 长尾批发市场补货（组合打法）
- 适合：大多数中小连锁
- 做法：销量大的3-5个单品（如苹果、香蕉、橙子）直接找产地或一级商；长尾品类走批发市场或配送商
- 优点：核心单品有价格优势，长尾不缺货
- 缺点：要管两套供应链

---

## 给你的判断标准

| 你的情况 | 建议 |
|---|---|
| 门店同城、有车有人 | 批发市场自采 + 多店合并 |
| 门店分散、人手紧 | 本地B端配送商 |
| 单城门店>20家、日销量稳定 | 考虑设分仓 |
| 想压价但量不够 | 联采或单品直采 |

## 最关键的一句话
**不要按"单店"去谈供货，要按"全部门店合并后的总量"去谈。**
你单店量小，但多店加总后可能就是一个中型客户的量。把所有门店的采购需求集中到一个供应商或一个采购动作上，你才有议价权和配送服务。

另外，水果损耗高，**配送频次比价格更重要**。宁可选一个贵一点但能隔日配、能退换的供应商，也别为了低价压一堆货在店里烂掉。
