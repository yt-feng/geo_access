社区超市卖小包装香蕉，核心矛盾是：**香蕉本身容易后熟、怕压、怕冷，小包装又会放大损耗和人工成本**。采购和包装要围绕“快进快出、减少翻动、控制成熟度”来做。

下面按可执行要点说：

## 1. 采购时先定“卖几天”的节奏
小包装香蕉不适合囤。建议按 **1–2 天销量** 采购，最多不超过 **3 天**，并且：

- 优先选 **青一点、刚到转色期** 的香蕉，不要选已经全黄、带糖斑的。
- 问清产地/批次到货时的 **成熟度**，最好能按“几成熟”分档。
- 如果门店没有催熟能力，就采购 **已经催熟到可售状态但还偏硬** 的货。
- 避免一次采太多同一成熟度，最好青黄搭配，先卖黄的，青的继续后熟。

判断标准：  
- 适合小包装：果皮黄中带绿、果指饱满、无黑斑。  
- 不适合小包装：已经大面积糖斑、果柄发黑、果指发软。

## 2. 包装要解决“压伤、闷坏、散落”
小包装香蕉最常见的损耗不是卖不掉，而是 **压伤、摩擦伤、闷出黑斑**。

### 包装形式建议
- 用 **透气塑料袋或网袋**，不要用完全密封的厚塑料袋。
- 如果必须用托盘+保鲜膜，膜上要打孔，或者不要全包死。
- 小包装规格建议 **2–3 根/袋** 或 **3–5 根/盒**，不要太多，否则顾客一次吃不完，反而容易剩。
- 袋口不要扎太紧，留透气空间。

### 摆放要求
- 不要堆叠超过 **2 层**，最好单层平放或悬挂。
- 避免和苹果、梨、番茄等释放乙烯较多的果蔬放在一起，会加速香蕉变黑。
- 货架避免阳光直射和靠近热源。

## 3. 控制温度，但别把香蕉放冷
香蕉对低温很敏感：

- 未成熟香蕉：适合 **13–15℃** 左右。
- 已成熟待售：可短时间放 **12–14℃**，但不要低于 **10℃**。
- 家用/商用冷柜如果低于 10℃，容易导致果皮发黑、冻伤，虽然里面可能没坏，但卖相会差。
- 门店如果没有恒温库，就放在阴凉通风处，优先走量。

## 4. 损耗控制的关键动作
### 采购端
- 少量多次，按天补货。
- 要求供应商提供较一致的成熟度，避免一箱里有的全黄、有的全青。
- 到货后立刻开箱透气，不要闷在纸箱里过夜。

### 门店端
- 每天挑出 **开始出糖斑、发软** 的香蕉，及时做试吃、折扣或加工成果汁/香蕉奶昔。
- 小包装不要提前包太多，最好 **卖前再包**，减少闷坏。
- 员工补货时轻拿轻放，避免反复翻动。
- 记录每天报废量，连续几天损耗高，就减少采购量或改规格。

## 5. 建议的采购和包装组合
比较稳的做法：

- 采购： **青黄交接、偏硬、无伤** 的香蕉，按 1–2 天销量进。
- 包装： **2–3 根透气网袋/打孔袋**，单层摆放。
- 温度： **12–15℃阴凉处**，远离乙烯释放源。
- 销售： 黄的先卖，青的后卖；出斑的及时折价或加工。
- 补货： **一天一补或一天两补**，不囤货。
