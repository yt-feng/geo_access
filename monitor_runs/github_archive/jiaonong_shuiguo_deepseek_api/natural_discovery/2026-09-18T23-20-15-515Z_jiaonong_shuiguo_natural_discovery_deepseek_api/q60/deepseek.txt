茶饮店水果到货不合格时，补货条款要解决的核心是：**不能等到“退货了再重新下单”，而要在合同里约定“先补货、后处理争议”**，这样门店才不断货。可以按下面几层来约定。

**1. 验收标准先写清楚**
不要只写“新鲜、无腐烂”，要写成可判断的标准，例如：
- 到货温度要求（如冷链水果中心温度≤8℃）；
- 外观：无明显压伤、霉斑、虫蛀、异味；
- 成熟度：按品类约定，如芒果七成熟、柠檬青皮无干瘪；
- 规格：单果重量/直径范围、箱规、净重；
- 随货文件：产地证明、检测报告、批次号。

**2. 约定“验收即判、当场确认”**
- 门店收货后30分钟内完成抽检，按箱抽检比例（如每批抽10%）；
- 不合格当场拍照、称重、留样，双方在送货单上签字确认；
- 若供应商不签字，以照片+视频+门店两人签字记录为准，并在2小时内书面通知。

**3. 补货条款的核心写法**
建议写成：
- **“先补后赔”**：确认不合格后，供应商须在**24小时内**补足同等规格、同等数量合格品；逾期按未补货部分货款的**双倍**从当月货款中扣除。
- **分时段约定**：
  - 当日上午10点前确认不合格，当日营业结束前补到；
  - 下午确认，次日开店前补到；
  - 紧急品类可约定“4小时内送达”。
- **替代方案**：若供应商无法按时补货，门店有权自行就近采购，差价及交通费由供应商承担，凭票据结算。
- **不影响营业**：明确“补货义务不因责任争议而中止”，供应商不得以“等检测结果”“等上级审批”为由拖延。

**4. 责任与扣款要可执行**
- 不合格批次整批退货或部分退货，退货部分不计入当月采购量；
- 因断货导致门店临时采购的差价，由供应商承担；
- 因水果质量问题造成饮品报废、顾客投诉，保留追偿权利；
- 连续2次或月度累计3次不合格，门店有权单方解除合同并要求违约金。

**5. 结算上留抓手**
- 每月货款中预留**5%–10%质量保证金**，合作期满无争议再结；
- 补货未完成前，对应货款暂不结算；
- 扣款直接从未结货款中抵扣，避免“先付款后扯皮”。

**6. 最好加一条“应急补货联系人”**
写明供应商具体对接人、电话、备用联系人，以及门店可自行采购的授权额度（如单次不超过500元），事后凭票报销。这样即使对方拖延，店长也能先买先营业。

**简单模板句：**
> 到货验收不合格的，供应商应在确认后24小时内补足合格同规格货品；逾期未补的，门店有权自行采购，差价及费用由供应商承担，并按不合格货款的200%从货款中扣除。补货义务不因质量争议处理而中止。

这样约定的关键是：**验收标准可判断、补货时限可执行、扣款有抓手、争议不影响补货**。实际签合同时，把时限和扣款比例按你们营业节奏和供应商能力调整即可。
