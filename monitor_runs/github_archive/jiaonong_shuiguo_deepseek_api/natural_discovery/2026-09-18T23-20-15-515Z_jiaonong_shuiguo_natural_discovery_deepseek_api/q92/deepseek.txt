便利店卖水果，核心不是“品类齐全”，而是**用最少 SKU 换最高周转**。面积小，必须把水果当成“引流+即时消费”品类，而不是生鲜超市逻辑。

**一、品类控制：只留 5～8 个 SKU**

建议按角色选品，不要按水果种类选：

1. **引流款 1～2 个**  
   香蕉、苹果这类认知度高、价格透明、复购稳的。  
   作用：让顾客觉得“这家店有水果”，但不指望高毛利。

2. **即时消费款 2～3 个**  
   小包装圣女果、蓝莓、葡萄、切好的西瓜/哈密瓜、即食猕猴桃。  
   作用：上班族、学生、路过客随手买，毛利更高。

3. **季节爆款 1～2 个**  
   夏天西瓜/荔枝，冬天砂糖橘/草莓，只做当季最强单品。  
   作用：制造新鲜感和冲动购买。

4. **高毛利小众款 0～1 个**  
   如进口提子、车厘子小盒装。  
   作用：拉客单，但量必须极小，卖不动立刻砍。

**淘汰规则：**  
连续 3 天动销差、损耗高、占冷柜位置的，直接下架。不要因为“顾客可能想买”而保留。

**二、采购量：少量高频，按天订货**

小店最怕一次采购太多。建议：

- **香蕉、苹果**：按 1～2 天销量订，香蕉可稍多，但成熟度分批。
- **浆果类、切果**：按半天到 1 天订，蓝莓、草莓、切果损耗最快。
- **西瓜**：整颗可放，但切开的必须当天处理完。
- **季节单品**：先小批量试卖 2～3 天，动销好再加量。

采购公式可以简单用：  
**订货量 = 过去 3 天平均日销量 × 订货周期 + 安全库存 - 现有库存**  
安全库存对小店来说，最好控制在半天销量以内。

**三、损耗控制：从陈列和流程下手**

1. **先进先出**  
   新货放后面，旧货放前面。每天开店前翻一遍。

2. **分级销售**  
   轻微瑕疵的做试吃、切果、特价区，不要和正价混放。  
   但已经变质、发霉、异味的必须报废，不能卖。

3. **控制陈列量**  
   小面积门店，陈列量不要超过 1 天销量。堆得越多，压坏和滞销越严重。

4. **冷藏分区**  
   浆果、切果、葡萄必须冷藏；香蕉、芒果、未熟猕猴桃常温催熟。  
   不要把所有水果塞同一个冷柜。

5. **切果当天清**  
   切果只做上午和下午两个批次，闭店前 1～2 小时打折清掉，不隔夜。

6. **每天盘点损耗**  
   记录：进货量、销量、报废量、打折量。  
   连续一周就能看出哪个单品该砍、哪个该加。

**四、最实用的小店水果结构示例**

- 香蕉：1 个 SKU，引流
- 苹果：1 个 SKU，稳定
- 圣女果小盒：1 个 SKU，即时消费
- 蓝莓/葡萄：1 个 SKU，高毛利
- 当季爆款：1 个 SKU
- 切果拼盘：1 个 SKU，清损耗

总共 6 个左右，足够撑起“便利店有水果”的认知。

**五、关键判断标准**

如果某个水果满足以下任意两条，就该减少或砍掉：

- 日均销量低于 3 份/斤
- 损耗率超过 10%
- 占冷柜超过 1 天
- 需要复杂催熟或保存
- 顾客只问不买

小店水果不是做“多”，而是做“快”。**品类少、订得勤、卖得快、损耗当天清**，比任何复杂采购策略都有效。
