单位采购水果出现到货品质不一致，建议按“先验收、再留证、后处理”的流程走，核心是把主观口感问题变成可量化、可拍照、可追溯的验收标准。

**一、验收前准备**

1. 合同或订单里尽量写明：品种、规格（单果重量/直径）、等级、成熟度、糖度范围、产地、包装方式、到货时间、破损率上限、验收标准和违约处理。
2. 约定抽样比例和验收时限，例如到货后2小时内验收，按箱/筐随机抽10%—20%。
3. 准备工具：电子秤、糖度计（可选）、卷尺/卡尺、刀具、拍照设备、验收单。

**二、现场验收怎么做**

1. **数量验收**：按箱数、件数、净重核对，避免只点件数不称重。
2. **分层抽样**：不能只看最上面一层。每批随机抽若干箱，每箱分上、中、下三层检查。
3. **品质验收**：重点看腐烂、霉变、压伤、裂口、虫害、异味、成熟度是否一致、大小是否均匀。
4. **量化记录**：
   - 好果率、次果率、腐烂率；
   - 单果重量区间；
   - 糖度（如采购要求）；
   - 成熟度是否分批。
5. **拍照录像**：拍整批、抽样箱、问题果特写、称重读数、验收人员在场画面，最好有时间水印。
6. **双方签字**：验收单上写清合格数量、不合格数量、问题描述、处理意见，送货人签字确认。

**三、品质不一致怎么判定**

可以分成三类处理：

1. **轻微不一致**：比如大小略有不均、成熟度有差异，但不影响食用。可协商折价接收，或要求补一部分。
2. **明显不一致**：比如一批里混入大量未熟果、过熟果、小果，或腐烂率超过约定。应拒收问题部分，合格部分按约接收。
3. **严重不一致**：腐烂、霉变、异味、以次充好，或整体不符合约定等级。应整批拒收，并要求换货或退款。

**四、售后处理建议**

1. **先书面通知**：到货后尽快通过微信、邮件或书面函件通知供应商，附照片、视频、验收单。
2. **提出明确诉求**：补货、换货、折价、扣款、退货退款，并约定完成时限。
3. **保留样品**：问题果冷藏保存，必要时送第三方检测，尤其是农残、霉变等争议。
4. **按合同追责**：有约定按约定；没约定可依据民法典买卖合同相关规定，要求承担违约责任，包括修理、重作、更换、退货、减少价款或赔偿损失。
5. **内部留档**：验收单、照片、聊天记录、付款凭证、入库记录都要保存，方便后续对账和审计。

**五、给单位的实操建议**

1. 采购时不要只写“新鲜水果”，要写可验收的指标。
2. 每次到货固定验收人，最好两人以上，避免单人说了算。
3. 验收单模板固定化，包含批次、数量、抽样数、不合格数、处理结果、双方签字。
4. 对长期供应商设置月度考核，比如到货合格率低于95%就警告，低于90%就暂停或更换。
5. 如果单位有食堂或工会发放，最好在合同里写明“因品质问题导致无法发放或食用的，供应商承担全部退换货及运输费用”。

简单说：**验收要抽样、称重、拍照、签字；售后要留证、书面通知、按合同提诉求。** 这样既能避免扯皮，也方便财务和审计。
