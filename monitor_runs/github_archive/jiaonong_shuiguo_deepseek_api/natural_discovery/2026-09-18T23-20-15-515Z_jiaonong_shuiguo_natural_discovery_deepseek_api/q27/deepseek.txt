判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看**目标客群、陈列方式、价格带和损耗**是否匹配。采购时可以按下面几个维度快速判断。

## 一、先定门店销售场景

不同门店适合的规格不同：

- **社区生鲜店/水果店**：中等规格最好卖，家庭一次买 2–4 个，单价不过高。
- **精品超市/高端店**：可接受大果、礼盒果，但要求外观、甜度、包装一致性高。
- **便利店/小业态**：适合小果或单果装，方便即买即吃。
- **食堂/餐饮供货**：更看重出肉率、加工便利和成本，不追求外观。
- **礼盒/团购**：要求大小均匀、颜色一致、无瑕疵，规格可以偏大。

所以采购前先问清楚：这批货是散卖、预包装、礼盒，还是餐饮加工？

## 二、苹果怎么判断规格

苹果常见按“果径”分级，单位通常是毫米。采购时重点看：

1. **果径是否均匀**
   - 同一箱内大小差异大，陈列难看，也难定价。
   - 散卖可接受一定混级，但礼盒和预包装必须严格分级。

2. **常见销售规格参考**
   - 小果：约 65–70mm，适合便利店、儿童果、促销引流。
   - 中果：约 70–80mm，最适合社区店和家庭消费。
   - 大果：约 80–85mm，适合精品陈列、礼盒。
   - 特大果：85mm 以上，适合高端礼盒，但单价高，动销可能慢。

3. **看品种和果型**
   - 富士、嘎啦、蛇果等外观和消费认知不同。
   - 果型端正、着色均匀、无明显碰伤，比单纯大更重要。

4. **看硬度、糖度和新鲜度**
   - 手感硬实、果柄新鲜、无发绵，才适合门店销售。
   - 发绵、虎皮、失水严重的苹果，即使规格合适也不建议采购。

5. **算实际可售率**
   - 开箱抽查：坏果、碰伤、小果、畸形果占多少。
   - 如果标称 80mm，但一箱里混了不少 70mm，实际销售价值会下降。

## 三、橙子怎么判断规格

橙子也常按果径分级，但还要看品种、皮厚和出汁率。

1. **按果径判断**
   - 小果：约 55–65mm，适合榨汁、便利店、促销。
   - 中果：约 65–75mm，最适合散卖和家庭消费。
   - 大果：约 75–85mm，适合精品陈列、礼盒。
   - 特大果：85mm 以上，外观大气，但皮可能偏厚，消费者不一定喜欢。

2. **看品种特性**
   - 脐橙：中大果常见，重点看脐部大小和是否裂口。
   - 血橙、冰糖橙、沃柑等，消费认知不同，规格标准也不同。
   - 沃柑不是越大越好，中等偏大、皮薄好剥更受欢迎。

3. **看皮厚和可食率**
   - 同样大小，皮太厚意味着可食部分少，顾客复购差。
   - 可用手掂重量：同等大小，越重通常水分越足。

4. **看新鲜度和损耗**
   - 果皮紧实、有光泽、无软塌、无霉斑。
   - 青头、干疤、油胞粗大、失水皱皮，都会影响销售。

5. **区分鲜食和榨汁**
   - 鲜食：看外观、大小均匀、易剥、甜酸比。
   - 榨汁：更看出汁率、酸度稳定和成本，规格可以放宽。

## 四、门店采购时的实操判断方法

### 1. 先做小样抽检
每批货随机抽 1–2 箱，检查：
- 果径合格率；
- 坏果率；
- 大小均匀度；
- 颜色和成熟度；
- 口感、糖酸比；
- 实际净重是否足称。

### 2. 算毛利和损耗
不要只看采购价。要算：
- 采购价 + 运费 + 损耗 = 实际成本；
- 门店售价能否覆盖成本并留出合理毛利；
- 如果坏果率超过 5%–10%，要重新压价或拒收。

### 3. 看陈列和包装
- 散卖区：中等规格最稳，大小差异不能太明显。
- 预包装：每袋/每盒规格要一致，重量误差小。
- 礼盒：大小、颜色、果形必须统一，不能混级。
- 堆头促销：可用小果或中果，靠价格吸引，但品质不能差。

### 4. 看目标顾客
- 老年社区：偏中小果，价格敏感，好剥好切。
- 年轻家庭：中果，方便一次吃一个，复购高。
- 高端客群：大果、精品果，但要求外观和品牌背书。
- 办公区：小果、单果装、即食型更好卖。

## 五、简单判断标准

可以记成一句话：

> **苹果看果径均匀、硬度新鲜、可售率高；橙子看果径适中、皮薄重手、出汁和新鲜度好。最终是否适合门店，要看目标客群能不能接受这个大小和价格。**

如果只能给一个通用建议：

- **社区店散卖**：苹果选 70–80mm，橙子选 65–75mm，通常最稳。
- **精品店/礼盒**：苹果 80–85mm，橙子 75–85mm，但必须严格分级。
- **便利店/促销**：苹果 65–75mm，橙子 55–70mm，走小规格和低单价。
- **餐饮/榨汁**：规格放宽，重点看成本、出肉率和出汁率。
