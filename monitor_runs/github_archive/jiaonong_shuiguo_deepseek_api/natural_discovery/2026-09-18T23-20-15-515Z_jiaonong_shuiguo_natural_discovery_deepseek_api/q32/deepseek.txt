判断香蕉供应商能否全年稳定供货，不能只听承诺，要按“产地结构、硬件能力、历史履约、应急方案”四条线去核验。下面给你一套可执行的判断框架。

## 一、先看产地结构：单一产地一定不稳

香蕉是热带作物，国内主产区有海南、云南、广西、广东、福建，进口主要来自菲律宾、越南、厄瓜多尔、柬埔寨等。全年稳定供货的核心是**多产地轮换**。

判断要点：
- 问清供应商全年各月份的货源来自哪里，让他列出**1—12月的产地排期表**。
- 如果只报一个产地，基本可以判定旺季没问题、淡季或灾害期会断供。
- 国内+进口组合是常态：国内产区淡季靠进口补，进口价格波动时靠国内压。
- 要求提供各产地的**合作基地或长期协议证明**，而不是临时收购。

## 二、看硬件和加工能力：决定能不能“持续出好货”

香蕉要催熟、分拣、冷链，稳定供货依赖硬件：

- **催熟库**：有没有自建催熟能力，还是全靠外购熟蕉。外购熟蕉的供应链最脆弱。
- **冷库/冷链车**：香蕉对温度敏感，13—15℃储运。没有冷链，夏天损耗大、品质不稳。
- **加工线**：分拣、清洗、分级能力，决定能不能按你的标准持续供货。
- **日/月吞吐量**：问他最大日供货量，再对比你门店的需求峰值。产能刚好卡在你需求上，旺季必掉链子。

## 三、看历史履约：用数据而不是感觉

- 要求提供**过去12个月的供货记录**：月度供货量、断供次数、到货合格率。
- 查他服务过的同类客户，尤其是连锁超市，直接问同行“旺季有没有掉过链子”。
- 看**履约保证金或违约条款**：敢不敢签断供赔偿，是稳定性的强信号。
- 试用期建议跨一个淡季：比如南方产区交替的3—4月、台风季，最能暴露问题。

## 四、看应急和替代方案

- 问他遇到台风、寒潮、港口延误时怎么办，有没有**备选产地和备选物流**。
- 有没有安全库存？在销地或中转地有没有备货仓。
- 价格机制是否清晰：全年是固定价、随行就市，还是保底+浮动。只报低价、不谈波动机制的，通常旺季会涨价或减量。

## 五、快速判断清单（可直接用）

1. 能否提供1—12月产地排期表？不能 → 风险高。
2. 是否有自建催熟库和冷链？没有 → 依赖外部，风险高。
3. 过去12个月有无断供记录？有且无合理解释 → 谨慎。
4. 是否愿意签断供赔偿条款？不愿意 → 稳定性存疑。
5. 是否有备选产地和应急库存？没有 → 单点故障。
6. 能否跨淡季试供1—2个月？不能 → 可能旺季才接单。

## 结论

能全年稳定供货的香蕉供应商，通常具备：**多产地排期 + 自建催熟冷链 + 可查履约记录 + 敢签违约条款 + 有应急备选**。五项里缺两项以上，就要按“季节性供应商”来管理，提前准备第二供应商，不要赌一家。
