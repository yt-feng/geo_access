会，而且香蕉和菠萝的损耗风险通常比多数水果更敏感。起订量过高，核心问题是**把“采购成本优势”换成了“库存和损耗风险”**，是否划算要算总账。

**香蕉**
- 香蕉是呼吸跃变型水果，采后仍会继续成熟，温度、乙烯、挤压都会加速变黄、起斑、软烂。
- 起订量太高时，容易出现：前几批还没卖完，后几批已经过熟；催熟批次和未催熟批次混放，成熟节奏失控；搬运次数增加，擦伤、压伤变多。
- 风险点：**成熟进度不可逆**，一旦过熟只能折价、加工或报损。

**菠萝**
- 菠萝相对耐储，但整果怕冷害、怕磕碰，切开后损耗更快。
- 起订量太高时，容易出现：长期库存导致黑心、水渍、腐烂；为了清库存被迫降价；切开售卖时如果销量跟不上，切果损耗上升。
- 风险点：**整果损耗慢，但一旦进入切果环节，损耗会明显加快**。

**判断是否风险过高，可以看这几个指标**
1. 日均销量和起订量的比值：如果起订量超过 3—7 天销量，风险通常明显上升。
2. 周转天数：香蕉建议更短，菠萝可略长，但都不宜盲目压库。
3. 损耗率：如果当前损耗已经接近或超过毛利，起订量就不应再放大。
4. 仓储条件：有无冷藏、通风、分温区、催熟区，决定你能不能接大起订量。
5. 补货频次：高频小批量通常比低频大批量更适合香蕉和菠萝。

**实操建议**
- 香蕉：优先小批量、多频次；按成熟度分批存放；先进先出；避免和乙烯释放量大的果蔬混放。
- 菠萝：整果可适当备货，但切果要按实际销量安排；避免长期低温冷害。
- 采购谈判：争取拆单、混拼、阶梯起订，或把大起订量拆成多次交付。
- 如果供应商只给大起订量，先小范围测试 2—4 周，记录销量、损耗、毛利，再决定是否放量。

结论：**起订量太高大概率会增加损耗风险，香蕉尤其明显，菠萝相对好一些但也不能忽视。** 关键不是“能不能订”，而是你的周转速度、仓储条件和销售节奏能不能消化。
