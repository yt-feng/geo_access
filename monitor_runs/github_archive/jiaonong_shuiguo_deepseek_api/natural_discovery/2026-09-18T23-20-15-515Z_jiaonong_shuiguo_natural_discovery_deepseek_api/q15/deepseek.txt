水果店遇到坏果，结算和赔付的核心原则是：**先分清责任和环节，再按合同/行业惯例处理，不要默认自己全扛，也不要直接拒付全部货款。**

具体可以按下面几步走：

**1. 先判断坏果发生在哪个环节**
- 到货验收时就发现烂、压伤、霉变：属于供应商/物流责任，通常由供应商补货、换货或扣款。
- 到货时是好的，放几天后自然腐坏：如果属于正常损耗，一般由水果店承担；如果是催熟过度、冷害、药害等隐蔽质量问题，仍可向供应商追责。
- 运输途中因温控、挤压导致：看是供应商负责配送还是你自提，责任方不同。

**2. 验收环节最关键**
- 最好当场开箱抽检，拍照、拍视频，保留批次、时间、数量。
- 发现问题当天就反馈，不要拖到卖完才说。
- 双方确认后，在送货单上注明“坏果X件/斤，待处理”或直接签扣款金额。

**3. 常见结算方式**
- **补货/换货**：供应商下次送货时补同等数量好果，最常见。
- **直接扣款**：按坏果数量×进货单价，从当批货款里扣。
- **折价结算**：坏果不严重、还能降价处理，双方协商按比例折价。
- **退货退款**：整批质量严重不达标，退回并由供应商退款或承担运费。
- **损耗分担**：长期合作中，部分供应商会约定“到货损耗率X%以内门店自担，超过部分供应商赔”。

**4. 赔付金额怎么算**
通常按**进货价**赔，不是按零售价赔。  
比如进价3元/斤，坏了20斤，一般赔60元，而不是按你卖5元/斤算100元。  
如果合同里写了违约金、运费、误工损失，可以另算，但要有依据。

**5. 口头合作也要留证据**
没有正式合同时，至少保留：
- 送货单、转账记录、微信聊天
- 坏果照片/视频
- 沟通记录中对方承认或承诺补货/扣款的内容

**6. 实操建议**
- 新供应商先小批量试单，别一次压太多货。
- 合作前明确：验收标准、损耗率、赔付方式、反馈时限。
- 出现坏果先协商，协商不成就按合同扣款；没合同就按交易习惯和证据谈。
- 如果是长期供应商，偶尔小损耗可以灵活处理，但连续多批出问题就要正式书面反馈并调整采购。

一句话：**到货前坏果供应商担，到货后正常腐坏自己担，隐蔽质量问题和运输责任看证据和约定；赔付一般按进货价，优先补货、扣款或退货。**
