可以，但要看你跟供应商的合作模式、你的采购量和谈判方式。一般分两类支持：

**1. 价格支持**
- **临时特价/周末促销价**：常见。尤其是你主推某几个单品时，可以提前跟供应商谈“周末两天进货价下调 X%”或“满多少件给促销价”。
- **返点/补差**：有些供应商不直接降价，而是你先按原价进，周末卖完后按销量返点，或对促销单品做差价补偿。
- **爆品专供价**：如果你周末主推 1-2 个单品，且走量，供应商更愿意给。
- **账期支持**：部分供应商愿意给 7-15 天账期，缓解你促销备货的现金流压力。

**2. 物料支持**
- **海报/价签/爆炸贴**：供应商通常有现成的品牌物料，尤其是有品牌的水果、礼盒、进口水果。
- **堆头/展架/周转筐**：做周末堆头时，可以借或申请。
- **试吃物料**：试吃盒、牙签、一次性手套、围裙等，有的供应商会给。
- **遮阳棚/横幅/气球**：做店外促销时，部分供应商或品牌方能提供。
- **赠品**：比如买某品牌水果送小礼品、购物袋、果盘等。

**供应商愿不愿意给，主要看这几点：**
- 你周末主推的是不是他的货，且采购量是否比平时明显增加。
- 你是不是长期稳定客户，有没有固定采购习惯。
- 你能否帮他把量做起来，比如集中推一个单品。
- 你是否愿意在店里给他做品牌露出，比如挂他的海报、贴他的价签。
- 谈判时机：最好提前 3-5 天谈，不要周五晚上才说。

**比较实用的谈法：**
> “这周末我准备把你们家 XX 单品做主推，计划进 X 箱，店里做堆头和试吃，能不能给个周末促销价？另外有没有海报、价签或试吃物料支持？如果卖得好，后面每周都可以固定推。”

**注意：**
- 价格支持最好落到文字，比如微信确认“本周六日 XX 单品 XX 元/箱，限 X 箱”，避免事后扯皮。
- 物料支持要问清是否要回收、是否收押金。
- 如果供应商不给价格支持，可以退一步要物料、账期或赠品。
- 不要只找一家谈，多问 2-3 家，谁给的条件好就主推谁。

简单说：**能，但通常不是白给。你要用“主推位、走量、长期合作、品牌露出”去换。**
