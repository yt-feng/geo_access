做稳定大客户，核心不是“把账期要长、额度要满”，而是把账期和额度设计成**双方都能持续运转、风险可控**的合作机制。直接给你可执行的谈判思路和判断标准。

## 一、先想清楚：你要的不是账期，是“稳定供货+可预测回款”

批发商真正的诉求通常是：
- 货源稳定、品质稳定、价格有竞争力
- 回款周期匹配自己的下游销售节奏
- 旺季不断供，淡季不压货

供应商的诉求是：
- 回款安全、周转快
- 订单可预测、减少坏账
- 不被大客户拖死现金流

所以谈判要围绕**风险分担**，而不是单方面压账期。

## 二、账期怎么谈：按“阶梯+条件”设计，别一口价

### 1. 起步阶段：先短账期，建立信任
- 建议从 **7天、15天** 起步，不要一上来就要30天、60天。
- 首次合作可以用 **现结或3天内**，跑通2-3单后再谈账期。
- 目的：让供应商看到你的回款能力和订单稳定性。

### 2. 稳定合作后：用“条件换账期”
可以这样谈：
- **月采购量达到X万**，账期从15天延长到30天。
- **连续3个月按时回款**，额度从Y万提到Z万。
- **旺季提前下单+预付部分定金**，换取更长账期或优先供货。

### 3. 账期形式选择
- **固定账期**：如“货到15天/30天”，简单但风险集中。
- **滚动结算**：如“每周对账，次周付款”，更适合水果这种高频、易损品类。
- **部分预付+尾款账期**：如“30%预付，70%货到15天”，双方都安心。

### 4. 水果品类的特殊点
水果损耗高、价格波动大，供应商对账期更敏感。你可以主动提出：
- **验收标准前置**：到货后24小时内完成质检，超时视为合格。
- **损耗分担比例**：例如运输损耗超过X%由供应商承担，正常损耗由你承担。
- **价格随行就市但设保护价**：避免行情波动时互相扯皮。

## 三、额度怎么谈：按“回款能力”定，不按“你想要多少”定

### 1. 额度公式参考
供应商给你的一般是**信用额度**，即未付款情况下最多能拿多少货。

你可以用这个逻辑去谈：
> 月均采购额 × 账期天数 / 30 = 合理信用额度

例如：
- 月采购10万，账期30天 → 合理额度约10万。
- 月采购10万，账期15天 → 合理额度约5万。

### 2. 阶梯额度
- 首次合作：额度 **1-3万** 或 **单笔不超过X万**。
- 稳定3个月后：提到 **月采购额的50%-80%**。
- 半年以上无逾期：争取 **月采购额的100%** 或更高。

### 3. 额度不是越高越好
额度太高，一旦下游回款慢，你会被供应商追款，关系反而崩。
建议保留 **20%-30%的现金采购能力**，作为应急和议价筹码。

## 四、谈判时具体怎么说：给你一套话术框架

**开场：**
“我们想做长期稳定合作，不是压账期占便宜。我们希望一起把量做起来，但需要回款节奏匹配下游。”

**提方案：**
“前期我们可以现结或7天账期，跑顺后如果月采购稳定在X万，账期能不能到30天？额度按月采购的50%起步，连续3个月准时付款再往上调。”

**给保障：**
“我们可以签框架协议，约定验收标准、对账周期、逾期责任。也可以交保证金或提供下游合同作为凭证。”

**留退路：**
“如果账期暂时给不了，能不能在价格、优先供货、损耗承担上给支持？我们一样能接受。”

## 五、必须写进合同的几个关键点

1. **账期起算日**：是发货日、到货日还是对账日？必须明确。
2. **对账周期**：每周还是每月？谁先出对账单？
3. **逾期责任**：逾期利息、暂停供货、额度冻结等。
4. **质量与损耗**：验收标准、异议期限、损耗分担。
5. **价格机制**：固定价、随行就市还是保护价？
6. **额度调整条件**：什么情况下提额、降额、停供。

## 六、给你的最终建议

- **账期**：从7-15天起步，稳定后争取30天，用采购量和准时回款换。
- **额度**：按“月采购额×账期/30”测算，起步保守，阶梯提升。
- **核心筹码**：稳定订单、准时回款、预付定金、长期框架协议。
- **底线**：不要为了长账期把供应商现金流逼死，否则断供损失更大。
