酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准里，避免只写“新鲜、优质”这种无法验收的词。

下面按常见酒店果盘原料给出一套可直接用于询价、下单、验收的标准框架。

## 一、通用规格标准

### 1. 品种与产地
- 品种必须明确：如红富士苹果、金煌芒果、夏黑葡萄、红心火龙果等。
- 产地可要求：如新疆、海南、云南、进口等。
- 同一批次应品种纯正，不混装、不掺次。

### 2. 等级与大小
- 按行业等级：特级、一级、二级，或按酒店要求定制。
- 按单果重量/直径/长度分级，例如：
  - 苹果：单果 180–220g，横径 75–85mm
  - 橙子：单果 200–250g，横径 70–80mm
  - 芒果：单果 300–500g
  - 火龙果：单果 400–600g
  - 西瓜：单瓜 4–6kg
  - 葡萄：单串 500–800g
- 同批次大小应相对均匀，便于切配和摆盘。

### 3. 成熟度
- 到货成熟度要适合酒店使用周期：
  - 即用型：8–9 成熟，可直接切盘
  - 备用型：7–8 成熟，可存放 1–3 天
- 不得到货即过熟、发软、发酵或有酒味。

### 4. 新鲜度
- 采摘/到货时间：建议要求采摘后 24–72 小时内到店，视品种而定。
- 叶菜类、浆果类应更短。
- 不得有萎蔫、失水、皱皮、干枯。

### 5. 洁净度
- 无泥土、无大量灰尘、无残留枝叶杂质。
- 可要求供应商做初清，但酒店仍需二次清洗。
- 不接受明显带泥、带虫、带腐叶的货。

### 6. 包装与运输
- 包装：周转筐、纸箱、泡沫箱、保鲜箱，按品种定。
- 不得使用污染、异味、破损严重包装。
- 运输：冷藏车或冷链，温度按品种：
  - 叶菜、浆果：0–4°C
  - 热带水果：12–15°C，避免冷害
- 到货温度应记录，不符合可拒收。

### 7. 食品安全
- 农残符合国家食品安全标准。
- 可要求批次检测报告或合格证明。
- 不得使用催熟剂超标、保鲜剂违规、染色、打蜡不合规等处理。
- 进口水果应有合法入境货物检验检疫证明。

## 二、通用外观标准

### 1. 颜色
- 具有该品种成熟时应有的色泽。
- 色泽均匀，不过青、不过白、不过暗。
- 无明显褪色、黑斑、褐变。

### 2. 形状
- 果形端正，无明显畸形。
- 不得有严重偏斜、裂口、扭曲。
- 允许轻微自然差异，但不能影响切配和摆盘。

### 3. 表面
- 果皮光滑或符合品种特征。
- 无大面积疤痕、虫眼、病斑、霉点。
- 无腐烂、流汁、发黏、异味。
- 允许少量轻微外观瑕疵，但不得影响食用和出成率。

### 4. 硬度与手感
- 手感坚实，有弹性。
- 不得过软、塌陷、空心感明显。
- 浆果类不得破皮、渗汁、发霉。

### 5. 气味
- 有该品种自然清香。
- 无酸败、发酵、酒味、霉味、化学味。

### 6. 内部质量
- 切开后无严重空心、黑心、褐变、虫蛀。
- 果肉颜色正常，无异常纤维、硬块。
- 种子、果核比例不能过高，影响出成率。

## 三、按品种可加的要求

| 品类 | 规格重点 | 外观重点 |
|---|---|---|
| 苹果 | 单果重、横径、等级 | 端正、无虫眼、无碰伤 |
| 橙/橘 | 横径、皮厚、酸甜度 | 色泽均匀、无浮皮、无霉斑 |
| 芒果 | 单果重、成熟度 | 无黑斑、无流胶、果形饱满 |
| 火龙果 | 单果重、鳞片新鲜 | 无软腐、无压伤、颜色鲜亮 |
| 葡萄 | 单串重、果粒大小 | 果粉完整、无落粒、无霉 |
| 草莓 | 单果重、果形 | 无破皮、无渗汁、无霉 |
| 西瓜 | 单瓜重、糖度 | 纹路清晰、无裂口、无软斑 |
| 哈密瓜 | 单瓜重、糖度 | 网纹均匀、无腐烂、无压伤 |
| 猕猴桃 | 单果重、硬度 | 无皱皮、无软烂、无压痕 |
| 菠萝 | 单果重、成熟度 | 无黑心、无烂眼、冠芽新鲜 |

## 四、验收时建议写清楚的指标

1. **抽样比例**：如每批抽 10%–20%。
2. **不合格率**：如外观不合格率超过 5% 可拒收或扣款。
3. **腐烂率**：超过 1%–2% 可拒收。
4. **规格偏差**：如单果重量低于标准 10% 视为不合格。
5. **成熟度偏差**：过熟、过生比例超过 10% 可拒收。
6. **温度记录**：冷链到货温度不符合可拒收。
7. **农残/检测**：无合格证明可暂收待检或拒收。
8. **退换货**：不合格品应在 2–4 小时内补货或退换。

## 五、可直接写进采购单的简版条款

> 供应商所供水果须品种纯正、新鲜洁净、成熟度适宜，符合国家食品安全及农残标准。同批次规格均匀，无明显畸形、腐烂、虫眼、病斑、霉变、异味、失水皱缩及机械损伤。到货成熟度适合酒店果盘即用或短期存放，冷链运输温度符合品种要求。外观不合格率不超过 5%，腐烂率不超过 2%，规格偏差不超过 10%。不符合标准的部分，酒店有权拒收、要求退换或按比例扣款。
