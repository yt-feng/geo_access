可以按“引流品+利润品+搭配品”来组合，核心不是单纯打折，而是让顾客从“买一样”变成“买一组”。

**1. 组合设计**
- **香蕉做引流**：香蕉单价低、认知高、购买频次高，适合做特价或“加1元多1把”，把人吸引到水果区。
- **苹果做利润和复购**：苹果耐储、家庭购买率高，可以推中大规格袋装、礼盒装，提升单次购买量。
- **菠萝做搭配和冲动购买**：菠萝香气强、现场感强，适合做试吃、切果盒、搭配套餐，拉高客单。

**2. 具体促销组合**
- **套餐A：早餐水果包**
  - 香蕉1把 + 苹果4个 + 菠萝1个
  - 定价略低于单买合计，但要保证整体毛利。
  - 话术：早餐/办公室一周水果，省心搭配。

- **套餐B：菠萝+苹果“酸甜组合”**
  - 菠萝1个 + 苹果6个
  - 适合家庭客群，强调“切一盘、带一袋”。
  - 可送简易水果叉或削皮服务。

- **套餐C：香蕉买赠升级**
  - 买2把香蕉，加5元换购1个菠萝或1袋小苹果。
  - 目的：用低价香蕉带动菠萝、苹果销量。

- **套餐D：切果盒组合**
  - 菠萝块 + 苹果块 + 香蕉段
  - 适合即食客群，客单价通常高于整果。
  - 注意现场卫生、时效和损耗控制。

**3. 陈列和动线**
- 把香蕉放在水果区入口或端头，做低价吸引。
- 苹果放在主通道或堆头，突出家庭装、礼盒装。
- 菠萝放在香蕉旁边或收银动线附近，配合试吃。
- 组合套餐用统一托盘、统一价签，写清“单买多少钱，套餐省多少”。

**4. 定价建议**
- 不要三个都降价，否则毛利会被打穿。
- 香蕉可以微利甚至平进平出引流。
- 苹果保持正常毛利，靠规格升级提客单。
- 菠萝用“切好/试吃/换购”提升附加值。
- 套餐整体让顾客感觉省10%—15%即可，不必省太多。

**5. 可执行判断标准**
- 看三个指标：客单价、组合购买率、损耗率。
- 如果组合购买率低，优先改陈列和话术，不要先降价。
- 如果菠萝损耗高，减少整果堆量，多做切果盒或换购。
- 如果苹果动销慢，推袋装和家庭装，不要只做散卖。
- 如果香蕉特价带来人流但客单不涨，说明组合衔接不够，要把菠萝、苹果放在必经动线上。

**6. 一个简单落地方案**
- 周一至周五：香蕉特价引流，苹果家庭装主推，菠萝做加价换购。
- 周末：推“香蕉+苹果+菠萝”家庭组合箱，配合试吃。
- 收银台：放小份切好的菠萝、苹果，做最后加购。

一句话：**香蕉负责把人拉进来，苹果负责把客单做稳，菠萝负责把冲动购买做起来。**
