判断哪个规格更容易出货，不能只看“哪个便宜”或“哪个大”，要围绕**下游客户结构、走货速度、损耗、资金占用**四个点来拆。给你一套可执行的方法：

**1. 先看你的下游是谁**
- 供**水果店、社区团购**：通常中果最稳，顾客一次买一个，太大吃不完、太小嫌不值。
- 供**商超**：偏好规格整齐、外观一致，中大果更好摆台。
- 供**餐饮、果汁店、切果摊**：看出肉率和单斤成本，往往中大果、甚至大果更划算。
- 供**路边摊、批发市场二级批发**：价格敏感，中果、小果走量快。
- 供**礼盒、电商**：大果、精品果更好卖，但要求外观和包装。

**2. 用数据判断，不靠感觉**
连续记录 7–14 天，每个规格记这几个数：
- 日均出货箱数/件数
- 从到货到卖完的天数
- 损耗率（烂、黑心、压伤）
- 单件毛利
- 资金周转天数

判断标准：
- **出货快 + 损耗低 + 毛利可接受**：主推规格。
- **出货快但毛利极低**：引流规格，不能当利润主力。
- **毛利高但走得慢、损耗高**：谨慎囤，容易砸手里。
- **走货慢 + 损耗高**：直接淘汰或降价清。

**3. 菠萝要特别注意的规格逻辑**
菠萝和苹果、橙子不一样：
- 太大：家庭客嫌多，但餐饮、果汁、切果店喜欢。
- 太小：单价低，但出肉少、削皮麻烦，水果店不一定爱。
- 中果：通常最好平衡“单价、出肉率、家庭购买习惯”，是大多数批发场景的走量款。
- 季节性：夏季切果、果汁需求上来，中大果更好出；冬季家庭整果购买多，中果更稳。

**4. 最实用的测试方法**
不要一次押一个规格。拿一批货做小范围测试：
- 每个规格先各进少量，同一市场、同一时间段卖。
- 记录 3–5 天出货速度和剩余量。
- 哪个规格最先卖完、补货后还能继续卖，就是更容易出货的。
- 如果两个规格都快，就看哪个**损耗低、占用资金少**。

**5. 简单结论**
大多数批发场景下：
- **中果通常最容易走量**，因为下游覆盖面最广。
- **大果更容易做利润和特定渠道**，如果汁店、礼盒、商超。
- **小果主要靠低价走量**，但利润薄、客户挑。
- 最终要看你手里客户是谁：**客户结构决定规格，不是规格决定客户。**
