超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于超市的合规要求、水果品类和当地监管规定：

**一、基础资质证明**
- 营业执照
- 食品经营许可证（或食品流通许可证）
- 如果是进口水果，还需提供进出口经营权相关资质

**二、进货证明/溯源凭证**
- 供货凭证、购销合同或订单
- 进货台账（记录品名、数量、进货日期、供货商信息）
- 产地证明或供货证明
- 对于进口水果：海关报关单、入境货物检验检疫证明

**二、检测报告（按需提供）**
- **农药残留检测报告**：这是最常见的。可以是供应商自检报告，也可以是第三方检测机构出具的报告。超市通常要求批次对应或定期（如每季度/每半年）提供。
- **重金属检测报告**：部分品类或高风险产区可能要求。
- **食品添加剂检测**：一般水果较少涉及，但加工类水果制品可能要求。
- **微生物检测**：鲜果通常不强制，但预切水果或即食水果会要求。

**三、进口水果额外要求**
- 入境货物检验检疫证明
- 海关报关单
- 输出国或地区的植物检疫证书
- 中文标签（预包装进口水果）

**四、实际操作建议**
1. **提前确认超市要求**：不同超市（连锁商超 vs 社区超市）要求差异较大，大型连锁通常更严格，会要求每批次或定期提供检测报告。
2. **检测报告要能对应批次**：报告上的品名、产地、生产日期/批号最好能与实际供货对应，否则超市可能不认。
3. **保留复印件或电子版**：便于随时提供给超市备案。
4. **关注当地监管要求**：部分城市对食用农产品有专门的索证索票规定，可咨询当地市场监管部门。

如果是一般国产水果且超市要求不严，通常营业执照 + 食品经营许可证 + 进货凭证 + 农残检测报告就能满足；进口水果或大型连锁超市则要求更完整。
