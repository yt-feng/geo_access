会影响销售，而且影响比较直接。香蕉是典型的“外观一致性驱动购买”的水果，大小不齐主要会带来这几个问题：

1. **卖相差，顾客挑拣严重**
大小混装时，顾客会反复翻找“大的、好的”，导致：
- 小的、差的被翻来翻去，容易破皮、发黑；
- 整箱损耗变高；
- 顾客觉得“这箱不整齐”，购买意愿下降。

2. **分级销售变难**
如果大小差异大，就很难按统一价格卖。通常需要：
- 大果做精品/高价；
- 中果正常价；
- 小果特价或加工。
这会增加分拣人工，也压缩利润。

3. **熟度不一致，后熟难统一**
香蕉大小不同，往往成熟速度也不完全一致。混放时：
- 大的可能先熟、先软；
- 小的还青；
- 整箱催熟或存放时，很难统一到最佳售卖状态。

4. **顾客体验和复购受影响**
顾客买香蕉通常希望：
- 一手/一把大小接近；
- 颜色、熟度接近；
- 回家后能同时吃或同时放熟。
大小不齐会让顾客觉得品质不稳定，复购率会下降。

**但也不是绝对不能卖，关键看你怎么处理：**

- **如果只是轻微差异**：影响不大，可以正常卖，但最好按把整理，尽量让每把大小接近。
- **如果差异明显**：建议分拣分级：
  - 大果：精品价、单独陈列；
  - 中果：正常价；
  - 小果：特价、做果切、奶昔、香蕉干，或捆绑促销。
- **采购时**：尽量选同一产区、同一批次、同一规格的货。香蕉采购里，“均匀度”往往和“新鲜度、卖相”一样重要。
- **陈列时**：不要整箱倒出来混卖，按大小、熟度分把，能明显减少挑拣和损耗。

简单说：  
**轻微大小不一，影响有限；明显大小混装，会拉低卖相、增加损耗、压低价格，最好分拣后再卖。**  
如果你是想控制成本，可以混装采购，但一定要预留分拣和促销的空间，否则省下的采购钱很容易赔在损耗和降价上。
