**供应商一般能提供什么**

- **基础图片**：产区、果园、采摘、装箱、实物图。很多供应商有，但多为手机拍摄，光线、背景、清晰度参差。
- **规格参数**：品种、产地、单果重量/果径、糖度、包装方式、保质期、发货地。这类信息通常最靠谱，也最该由供应商确认。
- **卖点文案**：部分供应商会给，但多是“香甜多汁、现摘现发”这类通用话术，同质化严重，直接用的转化效果一般。
- **检测/资质**：农残检测、绿色食品、地理标志等，有的话会提供，但需要核对证书有效期和对应批次。

**供应商通常给不了的**

- 符合你店铺调性的精修主图、场景图、短视频。
- 针对你用户人群的差异化卖点提炼。
- 稳定的白底图、统一尺寸、统一风格。
- 可商用授权明确的模特图或版权图。

**建议的做法**

1. **先向供应商要三样**：实物图原图、规格参数表、可提供的资质证明。这三样是基础。
2. **自己拍或补拍**：至少准备白底主图、切开/试吃图、包装图、对比图（大小/糖度）。生鲜详情页最影响转化的是“真实感”和“到手预期”。
3. **卖点自己提炼**：不要直接用供应商话术。按“品种优势 + 产区/气候 + 采摘/发货时效 + 口感数据（糖度、果径）+ 售后保障”来写。
4. **明确版权**：让供应商书面确认图片可商用，避免盗图投诉。
5. **建立素材模板**：固定主图、详情页结构，供应商来图后按模板套，效率最高。

如果供应商只给参数不给图，可以要求寄样，你们自己拍。生鲜类目里，自拍素材的转化通常比供应商通稿图更好。
