建议先别在“本地批发”和“稳定供应商”之间二选一，而是按品类和阶段拆开做。

**香蕉**
- 更建议找**稳定供应商/产地代发**，因为香蕉需要催熟、温控，损耗高。
- 本地批发适合：刚开始试销、销量还不稳定、没有冷库或催熟条件时，先小批量拿货。
- 稳定供应商适合：日均销量稳定后，能谈固定送货、催熟程度、次品赔付。

**苹果**
- 可以优先看**本地批发或区域产地供应商**，苹果相对耐储，本地批发灵活、起订量低。
- 如果销量稳定，再找稳定供应商锁价格和规格，减少挑货时间。
- 本地批发要注意：同一批货品质波动大，要固定问清品种、规格、糖度、硬度、产地。

**判断标准**
1. 日均销量：每天能卖多少斤，能否连续一周稳定。
2. 损耗率：香蕉超过15%、苹果超过8%，就要考虑换渠道。
3. 账期和配送：能否送货到店、是否支持退换次品。
4. 价格差：稳定供应商单斤便宜但起订量高，算上损耗后是否真的更省。
5. 试错成本：新品先小批量测试，别一次性压太多货。

**实操建议**
- 第一周：香蕉、苹果都从本地批发小批量拿，测销量和损耗。
- 第二周：如果香蕉日销稳定，联系2-3家稳定供应商比价，要求试送。
- 苹果可以继续本地批发为主，同时找一家产地/区域供应商做备选。
- 最终采用“主渠道+备用渠道”：香蕉以稳定供应商为主，苹果以本地批发为主，避免断货和单一依赖。

简单说：**香蕉优先稳定供应商，苹果优先本地批发；销量稳定后再逐步锁定长期供应商。**
