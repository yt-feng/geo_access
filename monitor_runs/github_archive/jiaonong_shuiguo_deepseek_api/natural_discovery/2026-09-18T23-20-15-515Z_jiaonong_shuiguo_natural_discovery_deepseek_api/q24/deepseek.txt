超市要控制水果农残抽检风险，核心不是只收一张“合格证”，而是建立可追溯、可核验的资料链。建议向供应商提前索要以下资料，并按品类和批次管理：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（如适用）
   - 若为进口水果：进出口经营权相关资质、入境货物检验检疫证明

2. **批次检测报告**
   - 与本次到货批次对应的农残检测报告
   - 报告应有 CMA/CNAS 标识或检测机构资质证明
   - 检测项目最好覆盖：有机磷、氨基甲酸酯、拟除虫菊酯等常见农残，以及该品类高风险项目
   - 报告日期应覆盖该批次，不能长期用一份旧报告替代所有批次

3. **产地与种植信息**
   - 产地证明、种植基地名称和地址
   - 合作社或基地的收购/供货证明
   - 若为“基地直供”，可要求提供基地备案信息或种植记录

4. **承诺与追溯文件**
   - 农残合格承诺书/质量保证书
   - 供货清单，注明品名、规格、数量、产地、采摘/采收日期、批次号
   - 随货同行单或电子追溯码，便于抽检不合格时快速溯源

5. **高风险品类加严资料**
   - 对叶菜类、豇豆、韭菜、芹菜、草莓、葡萄等高风险水果蔬菜，建议要求每批提供检测报告
   - 可要求供应商提供第三方抽检报告，而不只是自检报告

6. **合同与责任条款**
   - 在采购合同中明确：农残超标责任、退货赔偿、检测费用承担、供应商配合召回义务
   - 约定超市有权自行送检，不合格时供应商承担相应损失

实际执行建议：
- **首次合作**：资质、基地信息、质量承诺书必须齐全。
- **每批到货**：至少收“随货同行单 + 批次检测报告或承诺书”。
- **高风险品类/高风险季节**：每批要检测报告，必要时超市自行快检或送检。
- **抽检前重点**：确保货证对应，批次号、日期、品名能对上，避免“报告是真的但与本次货无关”。

一句话：要资质、要批次报告、要产地追溯、要承诺书、要合同责任；高风险水果不能只靠一张通用合格证。
