优先看你的门店客群和损耗承受能力，按下面判断：

**1. 先选小把（2–4根），最适合多数便利店**
- 客群是上班族、学生、单人/双人家庭时，小把最容易卖动。
- 客单价高于单根，又不像整袋那样一次买太多。
- 损耗比整袋低，陈列也好看。

**2. 单根只适合“顺手买、马上吃”的场景**
- 适合：写字楼、地铁口、景区、医院附近，客流快、即买即食。
- 问题：客单价低、称重/贴标麻烦，香蕉皮容易碰伤，损耗不一定低。
- 如果做单根，建议只作为补充，不要当主力。

**3. 整袋适合家庭客群或价格敏感型社区**
- 适合：社区店、家庭采购多、周边有稳定住户。
- 优势：客单价高、上架快、减少分拣。
- 风险：香蕉熟得快，整袋一旦卖不动，损耗集中爆发。

**建议组合：**
- 主力：小把（2–3根或3–4根）
- 补充：单根，放在收银台或即食区
- 少量：整袋，只给家庭客群或做促销

**判断标准：**
- 如果顾客以前买水果多是“一次一两个”，选单根+小把。
- 如果顾客常买家庭装、囤货，选小把+整袋。
- 如果香蕉周转超过2天还卖不完，就减少整袋，改小把。
- 如果小把也剩，直接改单根试销。

简单说：**多数便利店选小把为主，单根做即食补充，整袋少量试销。**
