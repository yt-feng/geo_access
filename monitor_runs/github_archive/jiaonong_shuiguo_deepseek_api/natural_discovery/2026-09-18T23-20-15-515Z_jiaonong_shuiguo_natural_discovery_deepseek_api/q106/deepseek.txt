判断水果报价波动是否合理，核心不是看“涨没涨”，而是看**波动是否有可解释的原因、幅度是否在品类常态区间内、以及是否与外部可验证信号一致**。可以按下面几步操作。

## 1. 先给每个品类建“正常波动带”

不要用一个统一标准看所有水果。先按品类记录最近30～90天的到货价/批发价，算出：

- 日均价
- 周均价
- 波动率：`(当日价 - 近7日均价) / 近7日均价`
- 最大单日涨跌幅
- 季节性区间

然后设阈值，例如：

| 波动幅度 | 判断 |
|---|---|
| ±3%以内 | 正常日波动 |
| ±3%～8% | 需要问原因 |
| ±8%～15% | 异常，要求书面说明 |
| ±15%以上 | 高风险，暂停或比价 |

不同品类阈值不同：叶菜、浆果类波动天然大；苹果、橙子、土豆等耐储品类通常更稳。

## 2. 看波动是否“只对你涨”

同一个供应商，如果当天对别的客户没涨，只对你涨，合理性就低。  
可以这样做：

- 向2～3家备选供应商询同规格、同产地、同等级报价
- 对比市场批发价、产地收购价、期货/指数价（如苹果、柑橘等有公开数据）
- 看是否同一时间全市场都在涨

如果只有一家涨，通常不是市场波动，而是**报价策略、库存结构或客户分层**问题。

## 3. 要求供应商给出可验证的涨价理由

合理波动通常能对应到具体因素：

- 产地天气：台风、霜冻、暴雨、高温
- 季节性断档：换季、尾期、新货未上
- 物流：油价、运费、堵车、口岸延误
- 规格变化：大果变小果、A级变B级、净重变毛重
- 包装变化：箱规、冰瓶、泡沫箱、纸箱成本
- 汇率/进口成本：进口水果常见
- 节日备货：春节、中秋前需求集中

**不能接受的模糊理由**：  
“今天行情就是涨”“大家都涨”“老板说的”“明天可能还涨”。

合理做法是：让供应商提供产地证明、装车单、市场行情截图、物流单据或同级替代品报价。至少要有**可交叉验证的信息**。

## 4. 用“三价比对”快速判断

每天收到报价后，做三个对比：

1. **纵向比**：和昨天、上周同期、上月同期比
2. **横向比**：和其他供应商、批发市场同品级比
3. **替代比**：和可替代品类比，比如柠檬涨了，青柠、香水柠檬是否也涨

如果三个方向都指向同一原因，波动大概率合理。  
如果只有纵向涨、横向不涨、替代品也不涨，就要警惕。

## 5. 把“报价合理性”写进采购规则

建议直接和供应商约定：

- 报价必须含：品名、产地、等级、规格、净重、包装、税率、有效期
- 单日涨跌超过X%，需提前Y小时书面说明
- 连续涨价超过Z天，启动比价或锁价
- 允许采购方按周均价、半月均价或公式价结算
- 设置价格复核机制：每月抽查3～5次市场价

这样做的目的是把“每天变”变成**可审计的波动**，而不是供应商单方面说了算。

## 6. 一个简单判断流程

收到新报价后：

1. 算涨跌幅，是否超过该品类阈值？
2. 查其他供应商同品级报价，是否同步？
3. 查产地/天气/物流/节日等外部信号，是否支持涨价？
4. 查规格、等级、包装是否暗变？
5. 如果理由充分、幅度在带内、横向一致 → 接受
6. 如果理由模糊、只有你涨、幅度异常 → 要求说明、比价、暂缓下单或换供应商

## 结论

合理波动 = **有外部原因 + 幅度在品类常态内 + 多家同步 + 规格未变**。  
不合理波动 = **只对你涨 + 理由模糊 + 无法验证 + 借规格包装变相涨价**。

最实用的做法是：先建价格波动带，再做三价比对，最后用合同规则约束。这样供应商每天报价，你也能快速判断是市场正常变化，还是需要谈判或换源。
