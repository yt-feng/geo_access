结论先说：**对价格敏感的团购客户，优先用「阶梯价」；如果这个客户长期复购、单次采购量波动大、或你需要控价和绑定合作，则用「返利」。多数情况下，最好做成「阶梯价为主 + 返利为辅」的组合。**

下面给你判断标准和可执行建议。

## 一、先分清两者本质区别

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 优惠时点 | 下单时立刻享受 | 事后/季度/年度结算 |
| 客户感知 | 直接、清楚、刺激下单 | 有延迟，感知弱 |
| 对价格敏感客户效果 | 强 | 中等偏弱 |
| 供应商现金流 | 立刻让利 | 延后让利，现金流更好 |
| 控价能力 | 弱，容易击穿价格体系 | 强，可隐藏真实底价 |
| 绑定长期合作 | 弱 | 强 |
| 管理成本 | 低 | 高，需对账、核算、防窜货 |

## 二、什么时候用阶梯价

适合以下情况：

1. **客户就是冲着低价来的**，决策主要看单价。
2. **单次采购量大、需求明确**，比如一次团购 500 件、1000 件。
3. **你希望快速成交**，不想让客户等返利。
4. **SKU 简单、量价关系清晰**，容易设档位。
5. **市场竞争激烈**，需要现场比价时立刻有优势。

建议做法：
- 设 3～4 档即可，不要太多。
- 档位按数量或金额设，如：
  - 100～299 件：原价 95 折
  - 300～499 件：9 折
  - 500 件以上：85 折
- 明确「不含税/含税、运费、账期、退换货」条件，避免只比单价。

**注意：** 阶梯价一旦给出去，客户会把它当 baseline，后续很难收回。

## 三、什么时候用返利

适合以下情况：

1. **客户会长期复购**，不是一锤子买卖。
2. **单次采购量不稳定**，但年度总量可观。
3. **你不想公开击穿底价**，要维护其他渠道价格。
4. **需要客户完成额外动作**，比如主推、陈列、带新客、按时回款。
5. **你想绑定客户年度合作**，防止被竞品轻易撬走。

建议做法：
- 返利挂钩「年度/季度累计采购额」，而不是单次。
- 返利形式可以是：现金、货款抵扣、赠品、市场费用。
- 设门槛和封顶，避免无限制让利。
- 写清结算周期、兑现条件、是否含税、退货是否冲减。

**返利的缺点：** 对当下价格敏感的客户吸引力不如阶梯价，而且如果客户不信你会兑现，效果会大打折扣。

## 四、最推荐的组合方案

对价格敏感的团购客户，建议这样设计：

1. **基础阶梯价**：解决客户当下比价和成交问题。
2. **年度返利**：解决长期绑定和继续压价问题。
3. **返利条件**：和回款、复购、主推、不窜货挂钩。

举例：
- 单次 100 件：95 折
- 单次 300 件：9 折
- 单次 500 件：85 折
- 年度累计满 50 万：额外返 3%
- 年度累计满 100 万：额外返 5%，但必须按时回款、无窜货

这样客户既能立刻感受到优惠，你又能用返利把他留在长期合作里。

## 五、一句话判断

- **要快速成交、客户只比单价 → 阶梯价。**
- **要长期绑定、控价、防窜货 → 返利。**
- **客户价格敏感又可能长期复购 → 阶梯价打底，返利做钩子。**
