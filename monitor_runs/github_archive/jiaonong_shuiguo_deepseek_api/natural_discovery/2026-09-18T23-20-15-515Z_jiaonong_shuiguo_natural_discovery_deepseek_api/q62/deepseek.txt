判断一批香蕉的熟度和坏果风险，可以按下面几个步骤来，基本不用开箱太深就能有结论。

## 一、先看整体外观

**1. 颜色**
- 全绿：生，适合长途运输或需要催熟，但要看有没有“青得发硬、发暗”。
- 绿中带黄、果指根部转黄：开始熟，适合中短期销售。
- 黄多绿少、有少量糖斑：已熟，货架期短，适合快批快走。
- 全黄带黑斑：熟透，损耗风险高，除非当天能走完。
- 果柄发黑、果指皱皮：过熟或失水。

**2. 果形和饱满度**
- 果指饱满、棱角不明显：发育好，熟后口感好。
- 果指瘦、棱角明显：可能早采，催熟后也容易发硬、不甜。
- 果指变形、弯曲异常：可能授粉或生长问题，不一定坏，但卖相差。

**3. 果柄和切口**
- 果柄青绿、切口新鲜：采收时间短。
- 果柄发黑、干枯、切口发霉：存放久或运输受热，坏果风险高。
- 切口有白色乳汁：正常，说明较新鲜。
- 切口发黏、有异味：已经开始腐。

## 二、动手检查关键部位

**1. 摸硬度**
- 硬：生。
- 稍软但有弹性：开始熟。
- 软塌、按下去不回弹：过熟或内部已坏。
- 局部特别软：可能有内伤或腐点。

**2. 看果指连接处**
香蕉最易从果柄连接处开始坏：
- 发黑、发软、有汁液：坏果起点。
- 轻轻一碰就掉：过熟或已腐。

**3. 看表皮病斑**
- 少量芝麻状黑点：正常成熟糖斑。
- 大块黑斑、边缘水渍状：炭疽病或腐生菌，会传染。
- 白色/灰色霉层：霉菌感染，整箱风险高。
- 表皮有伤口、压痕、裂口：后续易烂。

**4. 闻气味**
- 清香：正常。
- 酸味、酒味、发酵味：内部已经开始烂。
- 霉味：有真菌感染。

## 三、抽样判断整批货

不能只看一箱，建议按比例抽：

- 100箱以下：抽5-10箱。
- 100-500箱：抽10-20箱。
- 500箱以上：抽20-30箱，分不同层、不同位置。

每箱重点看：
- 中间和底部：最容易捂坏。
- 靠箱壁和角落：运输中易压伤、受热。
- 果柄连接处：判断是否从内部开始腐。

**判断标准：**
- 抽样中坏果率低于2%-3%：风险较低。
- 3%-5%：有一定风险，适合快走。
- 超过5%-8%：风险高，要么压价，要么拒收。
- 超过10%：基本不适合正常批发。

## 四、判断熟度是否适合你的销售节奏

| 熟度 | 外观 | 适合 |
|---|---|---|
| 生 | 全绿、硬 | 长途、催熟后批发 |
| 中熟 | 绿转黄、稍软 | 2-4天销售 |
| 熟 | 黄多、少量糖斑 | 1-2天快批 |
| 过熟 | 全黄、黑斑、软 | 当天处理，风险高 |

如果你做的是二批、水果店配送，最好拿“绿转黄”的货，回去还能放几天。如果做的是现场零售或榨汁，可以拿熟一点的，但必须当天走量。

## 五、坏果风险的几个高危信号

出现以下情况，坏果风险明显升高：

1. **箱内有水汽、发热**：运输中捂了，霉菌和腐烂会快速扩散。
2. **果柄切口发黑发霉**：存放时间长或冷链断过。
3. **大量果指连接处发黑**：内部腐开始。
4. **有酒味、酸味**：整批可能已进入快速腐烂期。
5. **压伤、裂口多**：后续坏果会成倍增加。
6. **同一箱里已有明显霉斑**：整箱要单独处理，不能混放。

## 六、实操建议

1. **开箱先看果柄，再看颜色，最后摸硬度。**
2. **从箱底和中间抽，不要只看最上面。**
3. **坏果率超过5%就要谨慎，超过8%建议拒收或大幅压价。**
4. **有霉味、酒味的货不要拿，熟度再合适也不行。**
5. **拿回去后立即分拣，把发黑、发软、有伤口的挑出来，避免传染。**
6. **熟度偏高的货，单独放、快走，不要和生货混堆。**

简单记：**果柄新鲜、颜色绿转黄、手感有弹性、无霉无酒味、坏果率低于5%，就是相对安全的一批货。**
