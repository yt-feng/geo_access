批发商把坏果责任写进合同，核心是**把“谁承担、什么时候算损耗、怎么赔、怎么验”四件事写死**，避免到货后扯皮。可以按下面几块来写。

**1. 先明确责任划分节点**
不要只写“坏果由卖方负责”，要写到具体时点。常见写法：
- 装车/交货前坏果由供货方承担；
- 运输由谁负责，就由谁承担该段损耗；
- 到货验收时发现的坏果，按约定比例或标准由供货方承担；
- 验收签字后风险转移给批发商。
如果运输是供货方包运，建议写明“运输途中因挤压、温度、延误造成的坏果由供货方承担”。

**2. 定义“坏果”标准**
这是最容易扯皮的地方。要写清什么算坏果，最好量化：
- 霉变、腐烂、破裂、严重挤压变形、冻伤/烫伤；
- 单果损伤面积超过多少、或影响销售的比例；
- 是否包含自然瑕疵、轻微擦伤、大小不均。
可以约定“轻微擦伤不影响销售的不计为坏果”，避免把正常损耗全算进去。

**3. 约定允许损耗率和超标处理**
行业里常见做法是给一个合理损耗率，比如到货坏果率不超过3%—5%由批发商自担，超过部分由供货方按比例赔偿或补货。具体比例要按品类、运输距离、季节谈。
写法示例：
“到货验收坏果率在__%以内，视为合理损耗，由买方承担；超过__%的部分，卖方应按超出比例对应的货值予以补货或退款。”

**4. 写清赔偿方式**
不要只写“负责”，要写怎么负责：
- 按坏果数量对应货款直接扣减；
- 供货方补发同等数量合格货；
- 按坏果货值的__%赔偿；
- 运费、分拣费、仓储费是否由责任方承担。
建议优先选“扣减货款”或“补货”，执行最快。

**5. 验收流程和时间**
要约定：
- 到货后多少小时内验收，比如24小时或48小时；
- 验收方式：抽检还是全检，抽检比例多少；
- 发现坏果后怎么通知对方，是否需要照片、视频、第三方见证；
- 逾期未提异议是否视为验收合格。
如果容易争议，可以约定“双方共同验货”或“请第三方检测”。

**6. 争议解决和证据**
写明：
- 验收单、照片、视频、物流记录作为证据；
- 协商不成向哪个法院或仲裁机构起诉；
- 检测费用由谁先垫付、最终由责任方承担。

**7. 一个可直接参考的条款结构**
“卖方保证所供货物符合约定质量标准。货物交付买方指定地点后__小时内，买方应完成验收。验收发现霉变、腐烂、严重挤压等坏果的，买方应拍照并书面通知卖方。坏果率在__%以内为合理损耗，由买方承担；超过部分，卖方应在__日内按超出数量补货，或按对应货款扣减。因运输导致的坏果，由负责运输一方承担。逾期未提出异议的，视为验收合格。”

**关键提醒：**
- 损耗率、验收时间、坏果定义这三项一定要谈具体，不能只写“协商解决”；
- 如果是长期合作，可以按品类分别约定损耗率；
- 保留装车照片、物流温控记录、到货开箱视频，真出问题时比合同条款还管用。
