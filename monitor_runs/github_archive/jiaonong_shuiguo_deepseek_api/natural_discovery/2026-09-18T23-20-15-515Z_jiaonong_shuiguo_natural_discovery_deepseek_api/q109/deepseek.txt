优先谈 **账期**，其次是 **售后**，最后才是 **配送**。原因是这三项对长期合作的风险和现金流影响权重不一样：

1. **账期最值得优先谈**
   - 它直接决定你的现金流压力和资金占用成本。
   - 水果是高频、易损耗、价格波动大的品类，账期一旦太短，你会被进货节奏拖得很紧；账期太长，供应商也可能把风险转嫁到价格或品质上。
   - 长期合作里，账期是最容易形成稳定规则、也最影响你利润空间的条款。
   - 建议优先谈：结算周期、起算时间、对账确认方式、逾期处理、是否支持部分预付+尾款。

2. **售后第二优先**
   - 水果非标品，损耗、烂果、规格不符、到货时间延误都很常见。
   - 售后规则不清，后面每次出问题都要扯皮，长期合作反而更累。
   - 重点谈：坏果率标准、赔付方式、补发还是扣款、拍照留证时限、责任划分、是否影响账期结算。
   - 售后谈清楚，能反向保护账期执行，不然你容易被“先结款再处理”卡住。

3. **配送最后谈，但不是不重要**
   - 配送频率、时效、起送量、运费、临时加单响应，确实影响日常运营。
   - 但它通常比账期和售后更容易通过磨合调整，而且很多配送问题可以通过备选供应商、合理库存来缓冲。
   - 如果配送直接影响你门店营业，那它要提前谈；如果只是效率问题，可以放到账期和售后之后。

更实际的谈判顺序可以这样排：

**先谈账期框架 → 再谈售后责任 → 最后谈配送细节和价格联动。**

如果只能选一个先谈，选 **账期**。  
如果供应商在账期上很强硬，就用 **售后** 换空间，比如要求更明确的坏果赔付和补发机制，来降低你的实际综合成本。
