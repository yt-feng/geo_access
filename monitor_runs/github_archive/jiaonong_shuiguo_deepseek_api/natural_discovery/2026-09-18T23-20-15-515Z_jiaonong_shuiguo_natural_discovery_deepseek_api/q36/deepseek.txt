建议按“门店类型 + 客流场景 + 损耗控制能力”来定，不要一刀切。多数商超更稳的做法是：**整果为主，切果为辅，分时段、分渠道卖。**

**1. 卖整果更适合的情况**
- 客群以家庭采购为主，买回去1–2天内吃。
- 门店没有冷藏切果台、日清条件或专人处理。
- 菠萝产地/品种有卖点，比如香水菠萝、金钻凤梨，顾客愿意自己挑。
- 毛利可控，损耗主要来自自然腐烂，而不是加工污染。

整果优点：损耗低、操作简单、客诉少、适合堆头走量。  
缺点：客单价低、购买门槛高，年轻人嫌削皮麻烦。

**2. 卖切果更适合的情况**
- 门店在写字楼、商圈、社区年轻人多，即买即吃需求强。
- 有冷藏展示柜、每日清货机制、切配人员。
- 能控制加工损耗和食品安全风险。
- 可作为果切组合的一部分，提高客单价和连带购买。

切果优点：方便、客单价高、适合即时消费。  
缺点：损耗高、人工高、食品安全风险高、保鲜期短，卖不完基本报废。

**3. 更推荐的组合策略**
- **整果做引流和家庭客**：门口堆头、整果特价、按个卖或按斤卖。
- **切果做便利和利润**：盒装、杯装、拼盘，放在冷藏柜靠近收银台。
- **分时段切**：上午切少量试销，下午根据销量补切，闭店前打折清货。
- **分规格**：整果、半只、四分之一只、果切盒，覆盖不同人数。
- **看数据调整**：连续3–7天记录整果和切果销量、损耗、毛利，再决定主推比例。

**4. 采购端要注意**
- 如果门店切果能力强，采购可适当选成熟度高的果，降低切果成本。
- 如果整果为主，采购要选耐储运、外观好、成熟度适中的果。
- 切果多，必须配套冷链、消毒、防氧化、日清，否则食品安全风险会吃掉利润。

**结论：**
- 社区家庭型商超：**整果为主，切果为辅**。
- 商圈/写字楼/年轻人多的门店：**整果+切果并重，切果比例可提高**。
- 没有冷链和日清能力的门店：**优先整果，谨慎做切果**。
- 最稳的是：**整果保流量，切果保毛利，按销量动态调整。**
