结论：**大多数甜品店直接买成品果丁的综合损耗更低、更可控；但如果你对“新鲜现切”有强卖点、且能把菠萝边角料再利用，鲜果切配也可能更划算。**

判断关键不是只看“菠萝皮厚不厚”，而是看这几项：

1. **可食率损耗**
   - 鲜菠萝：去皮、去眼、去芯后，可食率通常远低于100%，而且不同品种、成熟度、工人熟练度差异很大。
   - 成品果丁：供应商已经承担了这些损耗，你买到的基本是可用的果丁重量。

2. **保存损耗**
   - 鲜果切配：切开后容易出水、发酵、变味，冷藏保鲜期短，当天用不完就容易报废。
   - 成品果丁：如果是冷链/真空/罐头/冷冻产品，保质期和稳定性通常更好，损耗更可控。

3. **人工与时间损耗**
   - 鲜果切配：要有人削皮、去眼、切丁、清洗，人工成本高，忙时还会拖慢出餐。
   - 成品果丁：开袋/解冻即用，省人工，适合标准化。

4. **品质与卖点损耗**
   - 鲜切：视觉上更像“新鲜现做”，但批次不稳定，酸甜、软硬、出水都可能影响甜品。
   - 成品：一致性更强，但部分产品口感偏软、偏甜或有糖水味，不一定适合所有甜品。

5. **边角料利用**
   - 如果你能把菠萝芯、边角料做成菠萝酱、菠萝汁、装饰片、试饮等，鲜果切配的实际损耗会下降。
   - 如果边角料直接扔，鲜果切配损耗通常明显高于成品果丁。

**建议你这样选：**
- **追求稳定、省人工、损耗可控**：直接买成品果丁，尤其是冷冻果丁或冷链鲜果丁。
- **追求现切卖点、销量大、能当天用完、能利用边角料**：买鲜菠萝切配。
- **折中方案**：核心展示款用鲜切，批量夹心/装饰/饮品用成品果丁。

**快速判断公式：**
鲜果切配实际成本 = 菠萝采购价 ÷ 可食率 + 人工成本 + 报废成本 + 边角料处理成本  
成品果丁实际成本 = 果丁采购价 + 解冻/开袋损耗 + 品质不匹配报废成本

如果鲜果切配算完没有明显低于成品，或者你店里人工紧、报废率高，就选成品果丁。
