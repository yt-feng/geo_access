想避免到店买到的香蕉太生或太熟，核心是：先明确你打算“什么时候吃”，再按用途挑颜色和手感，而不是只挑“最黄”的。

**1. 按食用时间选颜色**
- **当天或第二天吃**：选整体黄、带少量褐色小斑点（糖斑）的，通常最甜、口感最好。
- **2—3天后吃**：选黄色为主、两端还带一点绿的，室温放几天正好。
- **4—5天后吃**：选黄绿相间、绿色较多的，别选已经长黑斑的。
- **想放更久**：选偏绿、硬一点的，但不要选完全青绿发硬的，这种可能熟得慢且口感差。

**2. 看外观细节**
- 避免：大面积黑斑、果柄发黑发霉、表皮裂开、渗汁。
- 谨慎：整体深黄但果柄已干黑，可能内部过熟。
- 想要均匀成熟：选整串颜色接近的；如果一串里有的黄有的绿，成熟速度会不一致。

**3. 摸手感判断**
- **太生**：捏起来很硬，像木头。
- **刚好**：略有弹性，轻按能微微下陷。
- **太熟**：一按就凹，甚至发软、发黏。
注意别用力捏，香蕉容易压伤。

**4. 按用途选**
- 直接吃：黄皮带少量糖斑。
- 做奶昔/烘焙：可以选熟一点、带糖斑的。
- 切片/带饭：选刚转黄、还偏硬的，不容易压烂。
- 想囤货：买偏绿、硬的，回家分开放。

**5. 到店后的实用做法**
- 如果只买当天吃的：选黄带少量斑点的。
- 如果买一周量：一部分选偏黄，一部分选偏绿，回家按成熟度分开。
- 不要买一整串全都一样熟的，除非你很快能吃完。
- 回家后：想催熟，和苹果/香蕉放一起；想延缓，放进阴凉处，别急着冷藏。表皮变黑后如果果肉没坏，可以剥皮冷冻做奶昔。

**简单判断口诀：**
- 今天吃：黄+少量褐斑。
- 过两天吃：黄+两端微绿。
- 过几天吃：黄绿相间、手感硬。
- 别买：黑斑多、果柄发霉、按下去软塌。
