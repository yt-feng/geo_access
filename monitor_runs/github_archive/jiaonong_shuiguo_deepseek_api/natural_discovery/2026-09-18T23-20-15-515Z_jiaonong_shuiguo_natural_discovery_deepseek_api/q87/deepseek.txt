社区团购旺季爆单，和水果供应商锁库存的核心不是“打个招呼留货”，而是把**需求预估、定金/账期、分级标准、违约条款、履约节奏**提前谈死。给你一套可执行的做法：

**1. 先做可承诺的需求预测，而不是拍脑袋报量**
- 按过去30天和去年同期销量，拉出单品周销量。
- 把预测分成三档：保底量、目标量、冲量。
- 只对“保底量”承担提货责任，目标量和冲量作为弹性追加。
- 给供应商明确时间表：提前7天给首轮预测，提前3天确认最终量，旺季前14天锁定核心单品。

**2. 用“定金+保底量”锁库存**
- 对核心爆品支付10%—30%定金，锁定对应货量和价格。
- 合同写明：供应商不得把锁定量转卖他人；如缺货，按缺货金额赔付或补差价采购。
- 对非核心品，用“优先供货权”代替全额锁仓，降低资金压力。

**3. 合同必须写清水果的验收标准**
水果最容易扯皮，提前约定：
- 规格：单果重、果径、箱规、净重。
- 成熟度：几成熟采摘、到货可售期几天。
- 损耗率：允许多少坏果，超出部分怎么补。
- 验收方式：到仓抽检比例、拍照留证、24小时内反馈。
- 价格机制：锁价还是随行就市；如随行就市，约定浮动上限。

**4. 设计分批发货，避免一次压仓**
- 不要一次把货全拉到仓，按日/隔日分批到货。
- 约定每日最大供货量、最小供货量、到货时间段。
- 爆单时优先保证核心团点，异常天气或物流延误提前48小时预警。

**5. 准备备选供应商和替代品**
- 每个核心单品至少备2家供应商，主供70%、备供30%。
- 提前谈好备供的“紧急插单价”和最快到货时间。
- 对易缺货单品准备替代规格或替代品种，避免团长端直接断货。

**6. 用数据和对账建立长期关系**
- 每周对账，准时结款，旺季前可提前付一部分款换优先权。
- 把销量预测准确率、退货率、履约率共享给供应商，让对方敢给你留货。
- 对配合好的供应商给更长账期、更大份额，形成稳定绑定。

**一句话总结：**
锁库存 = 保底量 + 定金 + 验收标准 + 违约条款 + 分批发货 + 备选供应商。只靠口头承诺，旺季一定被放鸽子。
