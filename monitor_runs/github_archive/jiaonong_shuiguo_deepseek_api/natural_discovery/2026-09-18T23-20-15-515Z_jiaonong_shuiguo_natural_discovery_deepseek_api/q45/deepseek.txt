连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是**价格调整机制、损耗归属、验收标准、账期与返利、以及不可抗力/解除条款**。下面按风险点说明。

**1. 价格条款：只锁“年度框架价”最容易亏**
水果价格波动大，若合同只写一个固定价，供应商可能在行情上涨时断供或降质，行情下跌时超市又失去议价空间。
建议写清：
- 基准价 + 调价机制（按批发市场指数/产地价/双方确认的周度报价）；
- 调价触发幅度（如涨跌超5%可调）；
- 调价频率（周调、月调或季度调）；
- 调价需书面确认，未确认时按原价执行还是暂停供货。

**2. 规格与验收标准：模糊描述必扯皮**
“一级果”“新鲜”“大小均匀”这类词没有可执行性。
建议写：
- 具体品种、产地、单果重量/直径、糖度、成熟度、色泽、瑕疵率；
- 抽样比例、抽检方法、不合格判定；
- 不合格是拒收、降价接收还是换货；
- 谁承担检测费和退货运费。

**3. 损耗与短溢装：最容易吃掉毛利**
水果在运输、装卸、门店陈列中都会损耗。若合同不写清，供应商和超市会互相推。
建议区分：
- 运输途中损耗：一般由供应商承担，直到验收合格；
- 验收后损耗：由超市承担；
- 短装：按实际到货结算，还是补货；
- 溢装：是否接收、如何计价；
- 腐烂/压伤率超过约定比例时的扣款或退货规则。

**4. 账期与结算：现金流和坏账风险**
常见坑是“月结30天”但起算点不清，或对账流程太长。
建议写：
- 对账日、开票日、付款日起算点；
- 逾期付款违约金；
- 质量扣款、返利、促销费能否直接从货款扣；
- 发票不合规或对账争议时，是否可暂缓付款及暂缓范围。

**5. 返利与费用：口头承诺不算数**
年度返利、陈列费、促销费、进场费、损耗补贴等，若只写“另行协商”，年底必吵。
建议写：
- 返利计算基数（含税/不含税、是否扣除退货）；
- 返利触发条件（采购额、回款额、毛利额）；
- 支付方式（现金、货款抵扣、货物）；
- 费用是否含税、开什么票。

**6. 供货保障与违约责任：不能只罚供应商**
超市也怕供应商旺季断供，供应商也怕超市随意取消订单。
建议写：
- 最低/最高供货量或预估量，是否具有约束力；
- 断供、迟延、质量不合格的违约金和赔偿；
- 超市取消订单的提前通知期和补偿；
- 违约金是否可抵扣货款，是否设上限。

**7. 质量安全与追责：出食品安全事故时最关键**
水果可能涉及农残、催熟剂、霉变等。
建议写：
- 供应商保证符合食品安全标准，提供检测报告/承诺书；
- 出现食品安全问题时的召回、赔偿、罚款承担；
- 超市先行赔付后能否向供应商全额追偿；
- 保险要求（产品责任险）及保额。

**8. 不可抗力与解除：别把“行情波动”当不可抗力**
有些供应商会把“市场价格上涨”“运输紧张”写成不可抗力，这通常不成立。
建议写：
- 不可抗力范围、通知义务、证明文件；
- 持续多久可解除；
- 解除后的已发货结算、库存处理；
- 年度合同提前解除的赔偿和过渡期供货。

**9. 排他性与渠道限制：小心反垄断和违约**
若要求供应商“只能供本超市”或限制其供竞争对手，可能涉及垄断或商业贿赂风险。
建议：
- 排他条款要谨慎，最好有期限、范围和补偿；
- 禁止供应商向超市员工行贿；
- 明确违反廉洁条款的解除权和赔偿。

**10. 合同期限与续约：年度合同不等于自动续**
建议写：
- 生效日、到期日；
- 到期前多久谈续约；
- 未续约但继续供货时的处理；
- 年度考核不达标能否不续约。

**最实用的签约动作：**
1. 把“价格、规格、损耗、账期、返利”五项做成附件表格，别只写在正文。
2. 所有调价、扣款、退货、返利都要求书面确认，微信/邮件也要约定是否有效。
3. 先小批量试单1-2个月，再签全年量。
4. 让财务、门店运营、品控一起审，不要只采购部定。
5. 重点保留验收单、对账单、检测报告和沟通记录。

如果只能先抓三个最关键的，就是：**调价机制、验收与损耗归属、账期与扣款权**。这三项写不清，后面几乎都会变成扯皮。
