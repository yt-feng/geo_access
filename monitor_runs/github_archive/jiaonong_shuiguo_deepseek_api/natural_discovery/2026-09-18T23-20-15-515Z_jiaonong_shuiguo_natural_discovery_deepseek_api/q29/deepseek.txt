超市和水果供应商的账期没有全国统一标准，主要取决于**超市规模、水果品类、供应商议价能力、行业惯例和区域**。常见情况大致是：

| 合作场景 | 常见账期 |
|---|---|
| 大型连锁超市 / 卖场 | 30～60 天，强势渠道可能 60～90 天 |
| 区域连锁超市 | 15～45 天 |
| 中小超市 / 社区店 | 7～30 天，很多是现结或周结 |
| 生鲜水果供应商 | 通常比标品短，7～30 天较常见 |
| 进口水果 / 高价值水果 | 可能现款现货、预付定金，或 7～15 天 |
| 本地应季水果 | 现结、周结、半月结较多 |

水果和普通日用品不一样：

1. **损耗高、周转快**  
   水果保质期短，供应商资金和货损压力大，所以账期通常比粮油、日化短。

2. **强势超市会拉长账期**  
   大型商超可能要求 45～60 天，甚至 90 天，但往往会搭配进场费、返点、促销分摊等条件。

3. **弱势供应商只能接受更长账期**  
   如果供应商品牌力弱、可替代性高，账期容易被压长。

4. **新供应商通常账期更短**  
   刚开始合作，超市可能要求现结、周结或 15 天，稳定后再谈 30 天左右。

如果你是超市方去谈，比较务实的区间是：

- 先争取 **30 天**：对水果供应商来说不算特别苛刻，也便于超市现金流。
- 如果对方强势或品类稀缺，可接受 **15 天或周结**。
- 如果是大型连锁、采购量大，可以尝试 **45～60 天**，但要预期对方提高报价或减少配合度。

如果你是供应商，建议底线：

- 本地易腐水果：尽量 **7～15 天**，最长不超过 30 天。
- 进口或高货值水果：尽量 **现结或预付部分**。
- 对大型超市：30～45 天可谈，60 天以上要算清资金成本。

一句话总结：**水果供应商常见账期是 7～30 天，大型超市合作常见 30～60 天，90 天属于偏长且强势的账期。**
