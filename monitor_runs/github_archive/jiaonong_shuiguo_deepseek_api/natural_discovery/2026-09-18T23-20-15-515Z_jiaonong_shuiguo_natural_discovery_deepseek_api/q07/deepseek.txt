做水果礼盒，核心不是“凑齐四种水果”，而是让顾客一眼觉得**好看、值、送得出手**。苹果、橙子、香蕉、菠萝这四样搭配，建议按下面思路做：

**1. 先定主水果，别平均用力**
- **苹果、橙子**：耐放、寓意好、颜色喜庆，适合做主角。
- **香蕉**：容易熟、易压伤，适合当“填充+颜色点缀”，不适合放太多。
- **菠萝**：体积大、带刺感强、有档次感，适合做视觉中心或高价礼盒里的亮点。

**2. 推荐搭配比例**
按普通中档礼盒（比如8-10斤）：
- 苹果 40%
- 橙子 30%
- 香蕉 15%
- 菠萝 15%

如果是高端礼盒：
- 苹果 30%
- 橙子 30%
- 菠萝 25%
- 香蕉 15%

**3. 最好卖的几种组合**
- **平安如意礼盒**：苹果 + 橙子，主打“平安+成功”，最稳、最好卖。
- **旺来礼盒**：菠萝 + 橙子 + 苹果，寓意“旺来、成功、平安”，适合节日。
- **缤纷果礼盒**：苹果 + 橙子 + 香蕉 + 菠萝，颜色丰富，适合探病、日常送礼。
- **高端商务礼盒**：大苹果 + 进口橙 + 小菠萝，少放香蕉，显得更整齐高级。

**4. 摆放很关键**
- 菠萝放中间或后侧，撑高度。
- 苹果和橙子放两侧和前排，颜色对比强。
- 香蕉放上层或缝隙，别压在最下面。
- 尽量用**同色系垫纸+透明膜**，不要塞太满，留一点呼吸感。

**5. 定价和规格**
- 低档：39-59元，苹果+橙子为主，香蕉少量。
- 中档：69-99元，四种都有，菠萝小块或小菠萝。
- 高档：129元以上，用好苹果、进口橙、完整菠萝，包装升级。

**6. 最实际的建议**
先做三款测试：
1. **苹果+橙子**：走量款
2. **苹果+橙子+菠萝**：节日款
3. **四种混搭**：展示款

卖一周看哪种复购和询问最多，再调整。香蕉别放多，菠萝别切太小气，苹果和橙子一定要选颜色亮、大小均匀的，礼盒卖相第一。
