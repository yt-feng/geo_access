判断水果供应商靠不靠谱，核心不是“他说得好不好”，而是能不能长期稳定给你**能卖、少损耗、出问题能处理**的货。你可以按下面这套方法看。

**1. 先看稳定性，不只看价格**
- 连续问 3～5 次：同一品种、同一规格，报价和到货质量是否稳定。
- 问清楚：产地、等级、单果规格、成熟度、包装重量、是否催熟、大概几天到货。
- 靠谱供应商会说清“这批偏生/偏熟、适合几天卖完”，而不是只承诺“都很好”。

**2. 香蕉重点看这些**
- 到货成熟度：你开店通常要青蕉或微黄蕉，不能一来就全黄。
- 是否均匀：一箱里成熟度差太多，说明分拣或催熟不稳。
- 有没有药害、黑斑、裂口、断指、水烂。
- 问清楚：能不能按你要的成熟度发货，夏天和冬天到货成熟度是否调整。
- 试损耗：先小批量进，放 3～5 天看转黄、黑斑、掉把、烂果比例。

**3. 菠萝重点看这些**
- 成熟度：太生酸、太熟易烂，要能按销售节奏发。
- 外观：果眼、冠芽、表皮有没有碰伤、软烂、发霉。
- 规格：大小是否均匀，单果重量是否稳定。
- 口感抽检：切开看糖度、纤维、黑心、水心。
- 问清楚：品种、产地、是否催熟、到货后还能放几天。

**4. 用“小批量试单”验证**
不要一上来长期大单。先做 2～3 次小批量试单：
- 第一次：看货对不对版。
- 第二次：看稳定性。
- 第三次：故意反馈一次质量问题，看他处理速度和态度。
靠谱的会补货、换货、扣款或下一单调整；不靠谱的会推责、拖、失联。

**5. 看售后和结算**
- 坏果怎么赔：按箱、按斤、按比例，还是下次补？
- 多久内反馈有效：到货 24 小时还是 48 小时？
- 运费、卸货、退换谁承担？
- 能不能稳定开票、对账是否清楚？
- 是否要求长期压款、突然涨价、强制搭售？

**6. 看他的供货能力**
- 旺季能不能保量，雨天/节假日会不会断供？
- 有没有备用产地或冷库？
- 能不能固定时间到货，别今天早明天晚。
- 是否只做转手：一问产地、分级、催熟就含糊，要谨慎。

**7. 最实用的判断标准**
同时满足这几条，基本可以长期合作：
- 连续 3 次到货质量稳定；
- 规格和成熟度能按你要求调整；
- 坏果有明确赔付规则且执行快；
- 价格不是最低，但算上损耗后成本合理；
- 沟通及时，不玩消失，不临时乱涨价。

**建议你直接做一张表**
每次到货记录：供应商、日期、品种、进价、到货重量、坏果率、成熟度、售后处理、客户反馈。  
连续记 1 个月，谁靠谱一目了然。

如果你刚开始，优先选：
**能小批量试单 + 明确坏果赔付 + 能按成熟度发货 + 到货时间稳定**的供应商。  
价格最低但规则模糊、售后推脱的，通常不适合长期做香蕉和菠萝。
