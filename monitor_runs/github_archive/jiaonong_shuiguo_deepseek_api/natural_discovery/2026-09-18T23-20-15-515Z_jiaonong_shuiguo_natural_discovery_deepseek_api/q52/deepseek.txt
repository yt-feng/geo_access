采购时按“成熟度分级 + 少量多次 + 到店后控温控乙烯”来做，基本能明显延缓变黑。

**1. 采购时挑成熟度**
- 优先买**青黄相接、果柄偏绿**的香蕉，别买已经全黄、带黑点、果柄发黑的。
- 如果当天就要用，选**黄中带一点绿**；如果第二天用，选**青黄各半**；如果两三天后才用，选**偏青**的。
- 同一批货尽量成熟度一致，不要青黄混装，否则熟的先黑、青的后熟，损耗大。
- 看果柄和棱角：果柄发黑、棱角不明显、表皮有压伤或水渍的，到店后黑得最快。

**2. 运输和到店首步**
- 不要闷在塑料袋或密闭箱里，香蕉会释放乙烯，闷着会互相催熟。
- 到店后立刻**拆箱、通风、摊开**，别堆压。压伤处会先变黑。
- 如果货量不大，挂起来或单层平放；量大的话用透气筐，留缝隙。

**3. 到店后控温**
- 未熟青香蕉：可短时间放在**13–15℃**环境，别低于12℃，否则冻伤后更易黑。
- 已熟黄香蕉：放**阴凉通风处**，尽快用；不要放冰箱冷藏，冷藏后表皮会快速变黑。
- 如果必须冷藏延缓果肉过熟，可**剥皮后冷冻果肉**，但带皮冷藏不适合直接展示或短期使用。

**4. 隔离乙烯**
- 香蕉不要和苹果、梨、番茄、猕猴桃等乙烯释放量大的水果放在一起。
- 有条件可用**乙烯吸收剂**，或放一小包活性炭/高锰酸钾乙烯吸收包。
- 已经熟透的香蕉要**及时挑出**，否则会催熟整批。

**5. 采购策略**
- 甜品店用香蕉，建议**按1–2天用量分批买**，不要一次囤太多。
- 和供应商约定**固定成熟度**，比如“七成熟、果柄绿、无黑点”，比临时挑更稳定。
- 记录每天用量和损耗，反推每次采购量，通常比“买便宜大货”更省钱。

**一句话：买青一点、别闷袋、到店摊开通风、13–15℃短存、远离其他水果、熟一批用一批。**
