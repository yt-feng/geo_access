评估水果供应商的仓配覆盖，核心不是看它“能不能送到”，而是看送到你各城市门店时，**时效、损耗、成本、稳定性**是否达标。可以按下面这套框架做判断。

## 1. 先明确评估目标

水果是高频、易损、时效敏感品类，评估仓配覆盖要同时看四个维度：

- **覆盖范围**：能不能送到所有门店所在城市
- **履约时效**：从下单到到店要多久
- **品质保障**：运输温控、损耗率、到货新鲜度
- **成本结构**：配送费、起送量、加急费、退换货成本

如果只问“能不能到”，很容易出现“能送但送得慢、损耗高、旺季掉链子”的问题。

## 2. 用门店城市做覆盖映射

先把你的门店按城市分级：

| 门店类型 | 判断重点 |
|---|---|
| 一线/新一线核心城 | 供应商是否有本地仓或区域仓 |
| 二三线城市 | 是否靠区域仓辐射，时效是否达标 |
| 偏远/县级门店 | 是否支持专线、零担或第三方落地配 |
| 高销量门店 | 是否需要高频次、小批量、多温区配送 |
| 低销量门店 | 是否接受更低频次但更高单次起送量 |

然后让供应商提供一张**城市覆盖表**，至少包含：

- 覆盖城市
- 发货仓位置
- 配送方式：直送/区域仓/第三方落地配
- 承诺时效：次日达/隔日达/48小时/72小时
- 最低起送量
- 是否支持冷链
- 是否支持拆零
- 旺季/节假日是否限单

## 3. 重点评估仓配模式

水果供应商常见有三种模式：

### 1）产地直发
适合耐储水果、大批量采购。
优点是成本低，缺点是时效长、损耗风险高，不适合叶菜、浆果、熟度高的水果。

### 2）区域仓+城市配送
最适合连锁门店。
判断点：
- 区域仓离门店城市多远
- 是否覆盖你的门店密度
- 是否支持一日一配或一周多配
- 仓内是否有温区管理

### 3）城市前置仓/第三方落地配
适合门店密集、时效要求高的城市。
判断点：
- 前置仓是否只服务你，还是共用
- 分拣质量是否稳定
- 最后一公里是否冷链
- 门店收货时间是否可控

## 4. 用关键指标做量化评估

建议要求供应商提供或承诺以下指标：

| 指标 | 建议关注值 |
|---|---|
| 订单满足率 | ≥95% |
| 准时到店率 | ≥95% |
| 到货损耗率 | 按品类设阈值，通常≤3%-8% |
| 冷链断链率 | 越低越好，最好可追溯 |
| 缺货/短装率 | ≤2%-5% |
| 退换货响应 | 24小时内 |
| 旺季履约稳定性 | 大促/节假日不掉链子 |

水果品类差异很大：
- 苹果、橙子等耐储：时效要求可放宽
- 草莓、蓝莓、荔枝、叶菜：必须冷链+高频+短时效

## 5. 做实际测试，不只看方案

最有效的方法是**小范围试跑**：

1. 选3-5个代表性城市：核心城、卫星城、偏远城各一个
2. 选5-10家门店做2-4周试配
3. 记录：
   - 下单到到店时长
   - 到货温度
   - 损耗数量
   - 门店收货体验
   - 缺货/替换频率
   - 实际配送成本
4. 对比原供应商或备选供应商

试跑阶段重点看：
- 是否按承诺时效到店
- 水果到店后还能卖几天
- 门店是否需要额外分拣
- 出现质量问题谁承担

## 6. 成本不要只看单价

水果仓配的真实成本包括：

- 采购价
- 配送费
- 起送量造成的库存压力
- 损耗成本
- 门店人工分拣成本
- 退换货成本
- 缺货导致的销售损失

可以算一个**到店综合成本**：

> 到店综合成本 = 采购价 + 配送费 + 损耗分摊 + 门店处理成本 + 缺货损失

有些供应商单价低，但损耗高、配送慢，综合成本反而更高。

## 7. 建议的评估结论模板

你可以按这个结构给供应商打分：

| 维度 | 权重 | 判断标准 |
|---|---|---|
| 城市覆盖 | 20% | 是否覆盖全部门店城市 |
| 时效履约 | 25% | 能否稳定次日/隔日到店 |
| 冷链与品质 | 25% | 温控、损耗、新鲜度 |
| 成本 | 15% | 到店综合成本 |
| 稳定性 | 15% | 旺季、异常处理、退换货 |

结论分三档：
- **可全国主供**：覆盖广、时效稳、冷链强
- **可区域主供**：在部分城市有优势
- **仅补充/备用**：覆盖有限或稳定性不足

## 8. 实操建议

如果你现在就要判断，建议直接向供应商要这5份材料：

1. 城市覆盖清单
2. 发货仓/前置仓位置图
3. 时效承诺表
4. 冷链与损耗控制说明
5. 近3个月同类连锁客户履约数据

然后选3-5个城市试跑2-4周。  
**能稳定送到、损耗可控、旺季不掉链子，才算真正覆盖。**
