家庭团购水果礼盒，建议按“**好吃、耐放、成本可控、送到家不烂**”来组合。苹果、橙子、香蕉、菠萝这四样里，最适合做家庭装的核心是：**苹果 + 橙子 + 香蕉**，菠萝作为可选升级项，因为菠萝容易压伤、需要削皮、成熟度不稳定。

下面给你几种直接能用的组合方案：

**1. 基础家庭实用款：苹果 + 橙子 + 香蕉**
- 比例建议：苹果 40%、橙子 35%、香蕉 25%
- 适合：3—5 口之家、日常吃、送父母/普通家庭
- 优点：接受度高，老人小孩都能吃，成本相对稳
- 注意：香蕉不要和苹果、橙子混放太久，苹果会催熟香蕉。最好分袋装，或者香蕉单独放小袋。

**2. 均衡耐放款：苹果 + 橙子**
- 比例建议：苹果 50%、橙子 50%
- 适合：团购量大、配送时间不确定、想减少售后
- 优点：最耐放，损耗低，适合家庭囤着吃
- 缺点：种类少，礼盒感弱一点
- 可以加 1 个菠萝做“亮点”，但菠萝要单独网套+纸托，别压在底部。

**3. 高性价比家庭款：苹果 + 橙子 + 菠萝**
- 比例建议：苹果 45%、橙子 40%、菠萝 15%
- 适合：家庭人数多、喜欢酸甜丰富、当天能送到
- 优点：看起来更丰富，有“礼盒感”
- 注意：菠萝占空间、重量大、易扎伤其他水果，建议一箱只放 1 个，且放最上层或独立隔开。

**4. 不建议的家庭组合：香蕉 + 菠萝为主**
- 香蕉怕压、怕冷、怕催熟；菠萝怕压、怕闷、易流汁。
- 这两个如果占太高比例，配送后容易出现黑斑、压烂、出水，售后高。
- 如果一定要四样都放，建议：**苹果和橙子做主体，香蕉少量，菠萝最多 1 个，且分区包装。**

**家庭团购最推荐的比例：**
- 苹果 35%—40%
- 橙子 30%—35%
- 香蕉 20%—25%
- 菠萝 0%—10%，最多 1 个

**装箱建议：**
- 苹果、橙子放底层和四周，起支撑作用。
- 香蕉放上层，最好单独纸袋或隔层。
- 菠萝单独网套，放最上面或侧边，不要压。
- 礼盒不要装太满，留一点缓冲，避免运输压伤。
- 如果配送超过 1 天，建议去掉香蕉，改成“苹果 + 橙子 + 菠萝”或“苹果 + 橙子”。

**一句话结论：**
家庭团购水果礼盒，最稳的是 **苹果 + 橙子 + 香蕉**；想更耐放就 **苹果 + 橙子**；想礼盒丰富就加 **1 个菠萝**，但菠萝和香蕉都要少放、单独放。
