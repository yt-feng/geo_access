水果店采购菠萝，核心是把“采购熟度”和“计划销售天数”匹配起来。菠萝是后熟型水果，采购时不能只看“熟没熟”，还要看“到你手里还能放几天、几天内能不能卖完”。

下面给你一套可执行判断方法。

**1. 先定采购策略：不要一次全采同一熟度**
建议按销售节奏分三档采购：

- **马上卖：1～2天内卖完**  
  选成熟度高的，香气明显、果眼较平、按压略软。
- **主销：3～5天内卖完**  
  选成熟度中等，香气淡、果皮由青转黄、按压有弹性但不软。
- **周转/备用：5～7天以上**  
  选成熟度偏低，果皮偏青、无香气或很淡、按压硬实。

比例可按你店铺销量来定，例如：  
**2成即卖 + 5成主销 + 3成周转**。  
如果天气热、销量慢，就减少高熟度比例。

**2. 看外观：颜色不是唯一标准**
菠萝成熟时通常从底部开始转黄，逐渐向顶部扩展。

- **底部黄、顶部青**：中等熟度，适合放2～4天。
- **整体淡黄到金黄**：熟度较高，适合1～2天卖。
- **整体青绿**：熟度低，可放更久，但口感可能偏酸。
- **果眼大而平、间隙明显**：通常成熟度较高。
- **果眼尖、紧密**：偏生。

注意：有些品种即使成熟也偏青，所以不能只靠颜色。

**3. 闻香气：最实用的现场判断**
- **无香气**：偏生，可放。
- **底部有淡淡果香**：中等熟，适合近期销售。
- **整果香气浓、甚至有点酒味**：过熟或开始变质，损耗风险高，不建议多采。
- **有发酵味、酸臭味**：已经坏了。

现场采购时，重点闻**菠萝底部**，那里最先成熟，也最能反映真实熟度。

**4. 按压测试：轻按底部和中部**
用手指轻按菠萝底部和中部：

- **硬实、按不动**：偏生。
- **有弹性、微微下陷**：熟度合适。
- **明显发软、像按海绵**：过熟，容易烂。
- **局部软塌、出水**：已损伤或腐烂。

不要用力捏，菠萝容易压伤，压伤后很快发霉。

**5. 看底部和果心**
- **底部干燥、颜色正常**：较新鲜。
- **底部发黑、发软、渗汁**：不要采。
- **果心处有裂口、发褐**：可能内部黑心或过熟。
- **叶片容易拔、基部松动**：成熟度高，但也可能放不久。

**6. 结合季节和天气调整**
- **夏天高温**：菠萝熟得快，采购熟度要偏低，减少高熟果。
- **冬天低温**：可适当采熟一点，但注意防冻伤。
- **雨天或湿度大**：容易发霉，采购后要通风、不要堆太密。
- **节假日前**：可提前采中等熟度，节前催熟到最佳状态。

**7. 到店后的处理**
- 偏生的：常温通风放置，不要直接冷藏，可自然后熟。
- 中等熟的：优先陈列销售，避免堆压。
- 高熟或已有香气的：尽快切果、做果切、促销或加工。
- 不要整箱密封堆放，容易闷熟、发霉。
- 每天翻检，先卖熟度高的，后卖偏生的。

**8. 一个简单采购判断口诀**
**“青硬无香可放，黄香有弹快卖，软塌酒味淘汰。”**
