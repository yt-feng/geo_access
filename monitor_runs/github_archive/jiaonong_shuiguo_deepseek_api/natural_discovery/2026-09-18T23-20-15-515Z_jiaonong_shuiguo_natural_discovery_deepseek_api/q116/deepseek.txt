# 现金结算 vs 月结账期：小商家采购水果的风险对比

## 一、现金结算的风险

**1. 资金占用与周转压力**
现金一手交钱一手交货，意味着你的钱先进了供应商口袋。水果是高频、易腐品类，如果采购频率高，账上现金流会被持续抽走，遇到淡季或突发支出时容易周转不开。

**2. 货损后追偿困难**
现金已付清，如果拉回来的货有烂果、规格不符，你处于被动地位——退款、换货全凭对方良心，手里没有"尾款"作为制衡筹码。

**3. 无账期凭证，对账麻烦**
如果只有口头报价、手写收据，事后发现算错价、缺斤短两，很难追溯。建议至少保留过磅单和收款凭条。

**4. 被"看人下菜"**
现金客户在供应商眼里优先级可能低于稳定月结客户，紧俏好货（如精品果）可能先给账期客户。

**主要优点**：无欠款压力、价格通常更优惠（很多供应商给现金价 2%-5% 折扣）、关系简单。

---

## 二、月结账期的风险

**1. 供应商信用风险（你的钱可能打水漂）**
你先进货后付款，看似占了便宜，但如果供应商经营不善跑路，你已经卖出去的货没法退，预付款或押金也可能追不回。反过来，如果是你先卖货、月底再付，风险主要在**你自己能否按时付款**。

**2. 隐性成本转嫁**
账期不是白给的，供应商往往把资金成本打进单价——同样的果，月结价可能比现金价贵 3%-8%。看似缓解现金流，实际多付了钱。

**3. 坏账与关系恶化**
水果损耗率高，如果你的货卖不动、资金回不来，月底付不出款，轻则被停止供货、加收滞纳金，重则被起诉或列入行业黑名单，断掉货源。

**4. 对账纠纷**
月结累积多笔交易，一旦出现质量争议，容易和账期付款纠缠不清——"这批货有问题所以我不付"，供应商则要求"先结清再谈"，陷入扯皮。

**5. 依赖风险**
长期月结容易形成对单一供应商的依赖，对方一旦涨价或断供，你临时找替代货源会非常被动。

**主要优点**：缓解现金流压力、用别人的钱做生意、便于建立长期稳定关系拿到好货。

---

## 三、给小商家的实操建议

| 维度 | 建议做法 |
|------|----------|
| **混合策略** | 大额、稳定品类谈月结；小额、临时补货用现金，争取现金折扣 |
| **控制账期** | 月结周期尽量短（7-15天），别拖到30天以上，降低双方风险 |
| **留好凭证** | 每笔交易留存过磅单、质检照片、对账单，微信确认也算证据 |
| **设质量条款** | 合同或聊天里明确：货损可扣款/换货，不因账期付款而放弃索赔权 |
| **不押单一供应商** | 至少保持2家货源，避免被账期"绑定" |
| **算清真实成本** | 把月结溢价换算成年化资金成本，和现金折扣对比，哪个划算选哪个 |

**一句话总结**：现金结算的核心风险是"钱货两清后没筹码"，月结账期的核心风险是"信用和现金流双重暴露"。小商家最优解通常是**短期月结 + 保留现金议价能力 + 严格留凭证**，而不是二选一。
