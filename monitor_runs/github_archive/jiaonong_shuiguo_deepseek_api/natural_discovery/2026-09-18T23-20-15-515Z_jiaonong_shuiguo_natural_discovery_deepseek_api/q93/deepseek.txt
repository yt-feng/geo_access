这三个都重要，但优先级不一样。开便利店卖菠萝切块，核心风险是**食品安全和损耗**，所以排序应该是：

**配送频次 > 包装 > 保质期标注**

## 1. 配送频次（最关键）
菠萝切块是**鲜切水果**，属于高风险短保商品。
- 切好后最好**当天配送、当天售完**
- 如果一天只送一次，下午到晚上的货新鲜度就难保证
- 建议：**每天至少1次，销量好的门店可早晚各1次**
- 关键点：**配送频次决定你上架时的剩余货架期**，这个比包装更能决定能不能卖

## 2. 包装（第二重要）
包装直接影响氧化、水分流失和微生物污染：
- 必须**密封**，不能敞口放
- 优选**气调包装或真空/密封盒**，能延长几小时到1天
- 包装上要能贴**制作时间/保质期标签**
- 注意：包装再好也救不了放置太久的切块，它只是延缓，不是保险

## 3. 保质期标注（必须做，但不是决定因素）
- 鲜切菠萝通常**冷藏0-4℃、当天食用最佳**，一般标注**当天或24小时内**
- 标注是**合规和追溯**要求，也是给顾客的承诺
- 但不能靠标个“保质期24小时”就放松配送和包装，否则容易出问题

## 实操建议
| 项目 | 建议标准 |
|---|---|
| 配送 | 每天至少1次，最好当天切当天送 |
| 冷藏 | 0-4℃全程冷链 |
| 包装 | 密封盒/气调包装，贴制作时间 |
| 保质期 | 标当天或≤24小时 |
| 售卖 | 到点未售完就下架，不续标 |

**一句话结论**：先保证配送频次和冷链，把“新鲜”做出来；再用包装延长窗口；保质期标注是底线合规。三者缺一不可，但配送频次是决定成败的那一环。
