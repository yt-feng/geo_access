水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格”和“有没有货”，而是那些会直接影响损耗、现金流和客户复购的细节。下面按实战优先级说：

1. **稳定性比低价更重要**
   容易只看报价，忽视对方是否能长期稳定供货。水果价格波动大，今天便宜、明天断货，会直接打乱销售节奏。要问清楚：同一单品全年能供多久、雨季/旺季/节假日是否稳定、缺货时有没有替代方案。

2. **分级标准是否一致**
   很多供应商口头说“精品”“大果”，但实际批次差异大。要确认：大小、糖度、颜色、成熟度、伤果率、装箱规格是否统一。最好约定验收标准，比如“单果重量范围、瑕疵率上限、成熟度几成”。

3. **损耗责任怎么分**
   这是最容易吃亏的地方。要明确：运输途中烂果、压伤、冻伤、过热谁承担；到货后多长时间内可反馈；超过时限是否认；补货、退款还是折价。没有这条，长期合作很容易变成你单方面吃损耗。

4. **账期和结算方式**
   只谈单价，不谈账期，会压死现金流。要确认：现结、周结、月结还是押款；是否有保证金；价格随行就市还是锁价；节假日是否涨价。长期稳定合作，账期和调价机制比单次便宜几毛钱更关键。

5. **产地和季节切换能力**
   水果有强季节性。要了解供应商是只做单一产地，还是能随季节切换产区。只靠一个产地的供应商，在季末、气候异常时风险很大。能跨产区调货的，通常更适合长期合作。

6. **仓储和冷链能力**
   很多小供应商价格低，但仓储条件差，货到手里已经“内伤”。要看：是否有冷库、分拣线、冷链车；不同品类是否分开存；是否避免和乙烯释放大的水果混放。冷链不行，后期损耗会吞掉利润。

7. **售后响应速度**
   不是看他说得多好，而是看出现问题后多久回复、多久补货、是否推责。可以先小批量试单，故意反馈一次质量问题，观察处理态度和速度。长期稳定，售后比口头承诺重要。

8. **是否过度依赖单一供应商**
   即使一家很好，也不要把全部采购押在一家。至少保留2—3家备选，主供、辅供、应急供。这样在涨价、断货、质量波动时才有谈判空间。

9. **合同和凭证是否规范**
   长期合作不能只靠微信聊天。要保留报价单、验收标准、对账单、转账记录。出现纠纷时，这些比“当时说好了”有用得多。

10. **别忽视“隐性成本”**
   低价供应商可能带来：到货损耗高、分拣人工多、客户投诉多、退换货麻烦。算总账时，要把损耗率、人工、退款、复购下降都算进去，而不是只看进货价。

简单判断标准：  
**能稳定供货、标准一致、损耗有人担、账期可承受、售后响应快、可跨季调货**，这六条比单纯低价更值得长期合作。  
实操上，先小批量试单，再逐步放量；同时保留备选供应商，不要一次性把命脉交给一家。
