社区超市卖水果，控制新鲜度和库存的核心就一句话：**少进、勤进、快周转；按销量订货，而不是按感觉订货。** 水果毛利高但损耗更高，压货一天就可能把利润吃掉。

下面给你一套能直接执行的做法。

## 1. 先定“少而勤”的订货原则

- **订货量按最近7天同星期几的销量来定**，比如订周二的量就看过去两个周二卖了多少，再按天气、节假日微调。
- **别一次进太多**：社区店客流稳定但有限，宁可当天下午补一次，也不要早上堆满。
- **畅销品多进、长尾品少进**：每天销量前10的品占大部分陈列，冷门品只留样品或少摆。
- **高峰期前补货，而不是节前囤货**：社区店消费是日常性的，节日增量有限，囤多了节后全是损耗。

## 2. 用“动态库存线”管数量

给每个品类设一个**最低陈列量**和**最高库存量**：

| 品类 | 订货频率 | 库存原则 |
|---|---|---|
| 叶菜类（小白菜、菠菜） | 每天1—2次 | 当天基本清完，不留隔夜 |
| 浆果类（草莓、蓝莓） | 每天少量 | 按当天预计销量订，最多1.5天量 |
| 普通水果（苹果、橙子） | 2—3天一次 | 最多3—5天量 |
| 耐放水果（柚子、西瓜） | 3—5天一次 | 可适当多备，但不超过7天量 |

**判断标准**：某个品连续两天卖不完，第二天就减半订货；连续两天上午就卖空，就适当加量。

## 3. 分级陈列和及时处理

- **好果正价卖、次果及时降价**：每天早晚各挑一次，碰伤、软化的马上转到“特价筐”，别混在正价堆里拖坏其他果。
- **先进先出**：新货放后面或下层，旧货放前面，补货时把旧货翻到表面。
- **小份陈列**：每堆别摆太满，卖相好、翻动快，也方便随时清理坏果。
- **易损耗品少量多次上架**：草莓、葡萄这类别一次全倒出来，分小批上。

## 4. 建立简单的每日动作

**早上开门前**：
- 检查隔夜库存，挑出坏果、软果
- 按当天订货量收货，当场验货，不合格拒收
- 定当天特价品（优先处理临期、卖相下降的）

**中午/下午高峰前**：
- 补一次畅销品
- 清理一次坏果，避免传染

**晚上打烊前**：
- 盘点剩余，记录每个品今天卖了多少、剩多少
- 对明天可能卖不完的品，当晚做“晚间特价”清掉
- 根据剩余量决定第二天订货减多少

## 5. 用数据代替感觉

不用复杂系统，一个本子或手机表格就够，每天记三样：

1. **进货量**
2. **销售量**
3. **报损量**

一周后就能看出：哪些品天天剩、哪些品不够卖。**连续报损高的品，要么减订，要么换供应商，要么直接下架。**

## 6. 和供应商谈“小批量、高频次”

- 尽量找能**每天送或隔天送**的批发商，哪怕单价略高，也比压货损耗划算。
- 谈好**退换货规则**：比如叶菜当天卖不完可换、坏果可补，这能直接降低风险。
- 不要为了拿低价一次进大批，水果的“低价”往往被损耗吃回去。

## 7. 用促销主动清库存，而不是等坏

- 每天设1—2个“今日特价”，优先选库存偏多、临近保鲜期的品。
- 做**组合装**：比如“苹果+橙子+香蕉”小果篮，加快周转。
- 晚间时段做折扣清货，比第二天报损划算。

---

**最关键的三个动作**：  
1. 订货看最近销量，不看感觉；  
2. 每天早晚各清一次坏果、调一次价；  
3. 连续卖不动的品立刻减订或下架。
