建议先从**香蕉**试水，但前提是把它当作“稳定走量、低毛利引流品”，而不是高溢价进口品；**菠萝次之，苹果最后**。原因和可执行判断如下：

**1. 香蕉：最适合先做稳定进口**
- **需求稳定、周转快**：日常消费频次高，顾客价格敏感但购买惯性强。
- **供应链相对成熟**：进口香蕉多为菲律宾、厄瓜多尔等产地，催熟和冷链体系成熟，适合超市做常态化陈列。
- **风险点**：损耗和催熟管理要求高，必须控制进货批量、成熟度分级和日清折价。
- **建议**：先小批量固定SKU，做2—3周动销和损耗测试；毛利不必高，重点看周转和复购。

**2. 菠萝：可以作为第二梯队**
- **有差异化卖点**：进口菠萝如菲律宾、泰国等产地有认知，适合做试吃和季节性促销。
- **风险点**：去皮损耗、成熟度不稳定、顾客处理不便，动销依赖陈列和试吃。
- **建议**：不要一开始铺大货，先做试吃台和小规格预切果盒，观察损耗后再扩大。

**3. 苹果：不建议作为首个进口品类**
- **国产替代强**：国产苹果供应充足、价格带广，顾客对进口苹果的价格敏感度高。
- **进口苹果差异化弱**：除非有明确高端客群和稳定产地卖点，否则容易滞销。
- **建议**：等香蕉、菠萝跑出稳定客流后，再考虑进口苹果做高端补充，而不是首发。

**执行顺序建议：**
1. **第1个月**：只引入1—2个进口香蕉SKU，记录日销量、损耗率、毛利率、缺货率。
2. **第2个月**：若香蕉周损耗可控、动销稳定，再增加1个进口菠萝SKU，做试吃和小规格预切。
3. **第3个月后**：根据客群反馈决定是否引入进口苹果，优先选有明确产地和口感差异的品种。

**判断标准**：如果香蕉试销期损耗率明显高于门店水果平均损耗，或日销量波动大，就先不要扩品；先把催熟、陈列和补货节奏跑顺。
