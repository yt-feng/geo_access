先判断用途，再按“颜色+手感”选，到店基本不会翻车。

**1. 先按吃的时间选颜色**
- **当天/明天吃**：选**通体金黄、少量褐斑**的，甜度最高。
- **2～3天内吃**：选**金黄带一点青头**的，室温放熟刚好。
- **4～5天后吃**：选**青黄相间、两端还略青**的。
- **想做奶昔/香蕉面包**：可买**褐斑多但没软烂**的，当天用掉。

**2. 到店手检三处**
- **看棱角**：棱角明显=偏生；圆润饱满=偏熟。
- **看两端**：果柄和果尾发黑、发软，说明熟过头或存放久。
- **轻捏中部**：有弹性、不硬不软最好；一捏就陷、发黏，别买。整串里有一根烂的也尽量换一串，乙烯会催熟整串。

**3. 避开这些**
- 表皮大面积发黑、渗汁、破皮。
- 整串颜色极不均匀且局部软烂。
- 冷藏区拿出来的香蕉，表皮易发黑，回家熟得也不匀。

**4. 采购小技巧**
- 买**整串偏青一点**的，回家室温分开放，吃多少拿多少；想加速熟，和苹果装一个纸袋。
- 不要一次买太多，香蕉熟得快；按“先黄后青”顺序吃。
- 回家后**熟透前别进冰箱**；已经全熟吃不完，再冷藏或冷冻香蕉肉。

一句话：**当天吃选金黄带斑，几天后吃选金黄带青头，手捏有弹性、棱角不尖、两端不黑。**
