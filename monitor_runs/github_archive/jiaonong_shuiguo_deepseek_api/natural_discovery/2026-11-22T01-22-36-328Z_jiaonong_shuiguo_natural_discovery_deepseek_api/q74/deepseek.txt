做餐饮客户，核心不是“卖水果”，而是“卖稳定出品和加工便利”。菠萝和香蕉建议按用途分规格准备，别只按批发市场的大路货思路。

**菠萝：按“餐饮加工方式”分三档准备**
1. **鲜切/果盘/自助餐用**
   - 规格：单果1.2–1.5kg，果形端正，成熟度7–8成，无黑心。
   - 包装：按箱装，标注单果重区间；可另做“已去皮真空袋装”小规格试销。
   - 适合：酒店自助、水果捞、团餐果盘。
2. **热菜/炒饭/咕噜肉用**
   - 规格：单果1.5–2kg以上，出肉率高，成熟度偏生一点，耐切块、耐翻炒。
   - 包装：大箱装，按“出肉率”给餐饮客户做卖点。
   - 适合：中餐后厨、快餐、食堂。
3. **饮品/果汁/茶饮用**
   - 规格：成熟度8–9成，香气足，可提供“去皮切块冷冻袋”或“果肉真空袋”。
   - 包装：5kg/10kg餐饮装，标注解冻出汁率。
   - 适合：奶茶店、果汁店、水吧。

**香蕉：按“熟度+用途”分规格**
1. **即食/果盘/自助餐**
   - 规格：单根120–150g，梳形完整，熟度5–6成到店，催熟后2–3天可用。
   - 包装：按梳/按箱，标注到货熟度和建议使用窗口。
2. **餐饮后厨/烘焙/甜品**
   - 规格：单根150–200g，熟度6–7成，耐存放；可另供“熟香蕉”专供烘焙。
   - 包装：大箱装，按成熟度分批。
3. **饮品/奶昔/冰沙**
   - 规格：熟度8–9成，可做“去皮冷冻香蕉段”餐饮装。
   - 包装：5kg/10kg袋装，标注解冻后用途。

**档口落地建议**
- 先做“餐饮规格卡”：品名、单果/单根重、成熟度、包装、建议用途、到货后可用天数。
- 菠萝主推“鲜切真空袋+大果热菜箱”两个 SKU；香蕉主推“果盘梳蕉+冷冻香蕉段”两个 SKU，先小批量试客户。
- 报价按“净重/出成率”而不是只按毛重，餐饮客户更认这个。
- 对餐饮客户承诺稳定熟度比低价更重要，菠萝黑心率、香蕉到货熟度要写进供货标准。
