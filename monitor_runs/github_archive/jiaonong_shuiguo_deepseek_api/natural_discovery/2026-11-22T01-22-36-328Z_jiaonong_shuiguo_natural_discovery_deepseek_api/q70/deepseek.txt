合同里要把“坏果”从一句笼统的“损耗由卖方负责”写成可验收、可计算、可追责的条款。建议从下面几个方面写：

**1. 先定义“坏果”，不要只写“损耗”**
可约定坏果包括：腐烂、霉变、软烂出水、裂口渗汁、明显压伤、异味、病虫害、冻伤、机械伤等。并写明判定标准，例如：
- 腐烂、霉变、异味：单果出现即计为坏果；
- 压伤、裂口：超过果面一定比例或影响销售即计为坏果；
- 自然失水、轻微外观差异不算坏果，但超过约定标准可扣重。

**2. 约定到货检验时间和方式**
建议写：“买方在货到后____小时内完成抽检/全检，双方共同验货并拍照、录像留存；逾期未提出异议视为验收合格，但隐蔽性腐烂除外。”同时约定抽检比例、取样方法和争议时送第三方检测。

**3. 明确坏果率计算和扣款方式**
写清楚公式：
> 坏果率 = 抽检坏果重量 ÷ 抽检总重量 × 100%
> 扣款金额 = 该批货款 × 坏果率 × 约定倍数（如1.5倍或2倍）

或者直接写阶梯责任：
- 坏果率≤3%：买方自担；
- 3%＜坏果率≤8%：按坏果重量扣减货款，并由卖方承担分拣费；
- 坏果率＞8%：买方可拒收该批货物，或要求降价、换货；
- 坏果率＞15%：买方有权解除该批合同，卖方承担退货运费及因此造成的合理损失。

**4. 明确责任归属和举证**
约定因包装不当、采摘成熟度过高、预冷不及时、运输温度不达标导致的坏果由卖方负责；因买方收货后储存不当导致的由买方负责。要求卖方提供采摘时间、预冷记录、装车温度等，便于划分责任。

**5. 写清处理方式和时限**
例如：“卖方应在收到坏果通知后____小时内答复，____日内补货、换货或退款；逾期视为认可买方检验结果。”退换货费用、分拣费、冷链费由责任方承担。

**6. 设置质量保证金或尾款扣留**
可约定留5%—10%货款作为质量保证金，验收后____日无质量争议再支付；或约定坏果赔偿可直接从尾款中扣除。

**7. 注意可执行性**
坏果率标准要结合品种、运输距离和季节写，不要一律写“零坏果”，否则容易争议。建议附一份《验收标准及坏果判定图示》作为合同附件，比单纯文字更可执行。

核心一句话：**定义清楚、检验及时、公式可算、责任可分、违约可扣。**
