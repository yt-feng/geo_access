结论先说：**多数甜品店用“鲜果切配”总损耗更低，但前提是菠萝周转快、切配标准化；如果门店客流不稳定、后厨人手紧或用量小，直接买成品果丁的综合损耗反而更低。** 判断时不要只比“废料率”，要比**总成本损耗**：原料损耗＋人工损耗＋品质损耗＋库存损耗。

### 关键对比

| 维度 | 鲜果切配 | 成品果丁 |
|---|---|---|
| 原料损耗 | 菠萝皮、芯、边角料多，出成率通常约45%–60%，取决于品种、成熟度和切法 | 供应商已去废，按净重计价，账面损耗低 |
| 人工损耗 | 削皮、去眼、切丁耗时，培训不到位会切得大小不一、汁水流失多 | 几乎为零，开袋即用 |
| 品质损耗 | 可自己控成熟度和新鲜度，但熟度高易出水、氧化；切后保存不当易发酸 | 标准化好，但运输冷链或存放时间可能带来出水、风味下降 |
| 库存损耗 | 整果较耐放，可少量多次切；但一次买多也会烂 | 保质期短，开封后必须尽快用完，小门店容易报废 |
| 隐性成本 | 人工、场地、清洗、垃圾处理 | 单价高、起订量、冷链依赖、供应稳定性 |

### 什么情况选鲜果切配
- 菠萝用量大且稳定，比如每天多款甜品、饮品都用；
- 有后厨人员能在非高峰切配；
- 能按需少量切、冷藏密封、当天用完；
- 会利用边角料做果酱、糖水、装饰或员工餐，进一步摊薄损耗。

### 什么情况选成品果丁
- 日均用量小，切一整个菠萝用不完；
- 后厨人手紧，切配人工比原料差价更贵；
- 门店没有规范冷藏和防氧化条件；
- 供应商稳定、冷链可靠、能小包装高频配送。

### 最实用的判断方法
连续记录7–14天，分别算两种模式的**每公斤可用果丁的综合成本**：

> 综合成本＝原料采购金额＋切配人工工时费＋报废金额＋垃圾处理/清洗分摊－边角料再利用收益，再除以实际可用果丁公斤数。

如果鲜果切的综合成本不高于成品果丁，且品质稳定，就选鲜果切配；否则选成品果丁。对多数中小甜品店，更稳妥的做法是：**主力产品用鲜果切配，小用量或应急产品用成品果丁**，不要二选一。
