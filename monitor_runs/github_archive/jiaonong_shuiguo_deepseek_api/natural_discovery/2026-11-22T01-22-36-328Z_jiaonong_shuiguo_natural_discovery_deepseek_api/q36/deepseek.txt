建议按“门店位置+客流结构+损耗能力”来定，多数商超更稳的做法是：**整果为主，切果为辅，先小批量测试再放量**。

**优先卖整果的情况**
- 社区店、家庭客群多，购买目的是回家削皮或做菜。
- 门店人手紧，没法频繁切果、换盒、控温。
- 菠萝到货品质不稳定，整果更耐放、可挑拣、可分级卖。
- 想做低价引流：整果按个/按斤卖，价格感知强。

**更适合卖切果的情况**
- 商圈店、写字楼店、年轻客流多，即食需求强。
- 门店有冷藏陈列和专人做鲜切，能控制加工和废弃。
- 整果出现外观瑕疵但内部完好，可转切果减少损耗。
- 能做出差异化：去皮整块、菠萝块、拼盘，配叉子/小盒。

**实操建议**
1. **先按7:3或8:2测试**：整果为主，切果小盒试销，观察3—7天动销和废弃率。
2. **切果必须算损耗**：菠萝去皮去芯损耗高，切果售价要覆盖原料损耗、人工、包装和冷藏成本；废弃率持续偏高就收缩。
3. **整果做分级**：大果正常价，小果/外观瑕疵果做特价或转切果，别一刀切降价。
4. **切果控量**：按小时或按半天少量多次加工，避免一次切太多卖不掉。
5. **陈列分开**：整果放生鲜区做量感，切果放冷藏即食区/收银动线附近，别互相抢客。
6. **看数据再定**：连续看动销率、毛利额、废弃率、客诉。切果毛利额高但损耗也高，最终看净毛利，不看单价。

**判断口诀**：家庭客多、人手少、品质不稳——整果为主；年轻客多、有冷藏加工能力、即食需求强——切果可放大，但仍建议整果打底。
