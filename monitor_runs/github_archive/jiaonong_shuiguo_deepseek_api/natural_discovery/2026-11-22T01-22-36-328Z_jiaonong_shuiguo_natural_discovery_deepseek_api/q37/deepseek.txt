商超会员日水果活动，供应商要提前配合的重点是“保量、保质、保价、保陈列、保应急”，建议按活动前7—10天启动准备：

1. **确认活动方案与订单**
   - 明确活动时间、门店范围、引流单品/爆品、促销价、预计销量、毛利承担方式。
   - 提前锁定订单量，按日分解发货计划，避免一次性压货导致损耗。
   - 确认价格保护期、调价机制和费用分摊（特价、陈列、损耗、赠品）。

2. **货源与品质保障**
   - 提前锁定产地/基地货源，优先选择耐储运、成熟度可控的品种。
   - 制定分级标准：果径、糖度、色泽、瑕疵率、包装规格，活动前提供样品确认。
   - 安排备用货源和替代单品，防止主产区天气、运输或采收问题断供。

3. **备货与库存节奏**
   - 按“活动前1—2天到店为主、活动当日补货为辅”安排，减少门店后仓压力。
   - 对高损耗水果控制单店单次到货量，采用小批量、多频次配送。
   - 提前与商超确认收货时间、卸货口、预约排队规则，避免集中到货拥堵。

4. **价格与费用确认**
   - 书面确认供货价、促销价、返利/扣点、损耗补贴、临期处理责任。
   - 明确活动期间不随意涨价，若因产地价格大幅波动，按合同约定触发调价需提前报备。
   - 确认促销赠品、试吃物料、宣传图片和卖点文案由谁提供。

5. **包装与陈列物料**
   - 提供适合会员日堆头/端架陈列的周转箱、托盘、网套、保鲜膜、标签。
   - 包装规格统一，价签信息准确，避免门店二次分装耽误上架。
   - 提前提供陈列建议：堆头高度、动线位置、试吃台位置、补货频次。

6. **配送与冷链**
   - 确认冷链车型、温湿度要求、到店时间窗口和紧急补货响应时限。
   - 活动前完成车辆和人员安排，预留备用车辆。
   - 对易损水果加缓冲包装，配送单随货同行，方便门店验收。

7. **人员与现场支持**
   - 安排理货/促销人员或巡店人员，重点门店活动首日到场支持。
   - 提前培训产品卖点、试吃话术、挑选和储存方法。
   - 明确供应商现场负责人和商超对接人，建立活动沟通群。

8. **质量验收与售后处理**
   - 活动前与商超确认验收标准、抽检比例、拒收和扣罚规则。
   - 对到货不合格品明确退换货时限，最好活动当日2—4小时内响应。
   - 约定损耗和临期果处理方式，避免活动结束后扯皮。

9. **应急预案**
   - 准备断货替代方案、雨天/高温配送预案、门店爆单补货预案。
   - 预留10%—20%安全库存或备用货源。
   - 活动首日安排专人盯销售和库存，下午根据动销决定是否追加补货。

10. **活动前检查清单**
   - 样品确认、订单确认、价格确认、物料到店、人员排班、配送预约、验收标准、应急联系人，逐项打勾确认。
   - 建议活动前1天做一次联合检查，活动首日做一次复盘，及时调整后续补货。

核心判断标准：活动前能做到“单品有备用货源、门店有陈列物料、价格有书面确认、配送有预约时段、现场有应急联系人”，基本就具备配合条件。
