# 判断一批香蕉的熟度和坏果风险

看香蕉不能只看“黄不黄”，要看**颜色、手感、果柄、棱角、气味、切口**六个方面，而且一定要开箱抽查，不能只看箱面。

## 一、判断熟度

**1. 看颜色（最关键）**
- **全青/青绿**：生果，适合长途运输或自己催熟；批发拿货后要催熟，周期长、风险大。
- **青转黄、黄中带绿**：七成熟左右，最适合批发中转，耐放。
- **通体黄、果尖略绿**：八到九成熟，适合直接走零售，2—3天内要出手。
- **全黄、出现褐色斑点（芝麻蕉）**：完熟，口感好但货架期只剩1—2天，批发风险高，除非当天能走掉。
- **大面积发黑、发暗**：过熟或已开始坏。

**2. 看棱角**
香蕉越生，棱角越明显、越“方”；越熟，棱角越圆润饱满。整串棱角分明=偏生；圆鼓鼓=偏熟。

**3. 摸手感（轻捏果身中段）**
- 硬实有弹性：偏生；
- 微软、有回弹：适中；
- 一捏就软、发绵：过熟，易压伤坏果。

**4. 看果柄和果轴**
果柄青绿、切口新鲜=采后时间短；果柄发黑干枯、果轴发褐=存放久、风险高。

## 二、判断坏果风险（重点排查）

**1. 开箱抽查，别只看表层**
从上、中、下三层各抽几把，看箱底和中间有没有压伤、渗汁、发霉。

**2. 找机械伤和压伤**
运输挤压处会先变黑、变软、出水，这类果当天不处理就会烂，且会传染同箱。捏到局部发软、发黑的要重点数。

**3. 看果指连接处和果轴**
连接处发黑、流汁、有酒味=已开始腐坏；果轴发黑发霉说明整箱受潮或捂过。

**4. 闻气味**
正常是清淡果香；有**酒味、酸味、霉味**说明内部已发酵或霉变，整批风险大。

**5. 看切口和果皮表面**
切口发褐、渗液；果皮有霉点、水渍状斑、大面积黑斑扩散——都是坏果信号。

**6. 看有没有“水烂”和“炭疽病斑”**
果皮上小黑点迅速扩大、凹陷、连片，多是炭疽病，会快速传染，见到成片就要压价或拒收。

## 三、给批发商的实操建议

- **按用途选熟度**：要走二批/零售，拿七到八成熟（黄中带绿）；要当天出完，才拿全黄。
- **算货架期**：全黄货基本只有1—2天窗口，青黄货3—5天，全青要催熟，别按“看着好”多拿。
- **必开箱、必翻底**：表层好看不代表整箱好，箱底和中间最容易出问题。
- **抽样数坏果**：随机抽3—5箱，数出压伤、黑斑、软烂果比例。坏果率超过**3%—5%**就要谨慎，超过**10%**建议拒收或大幅压价（具体按你的损耗承受力定）。
- **闻味一票否决**：有酒味、酸味、霉味的批次，不管表面多好都别要。
- **看运输和存放条件**：夏天高温、捂箱、雨淋过的货，坏果风险明显高；冷库货要看有没有冻伤（果皮发暗、水渍状）。

**一句话判断**：颜色黄中带绿、棱角渐圆、手感微软有弹性、果柄青鲜、开箱无压伤无酒味——这类货熟度适中、风险低，最适合批发中转；全黄带斑、局部发软、有酒味或箱底渗汁的，货架期极短，慎拿。
