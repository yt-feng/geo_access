茶饮店用香蕉，核心是**按用途分熟度采购**，不要一次只买一个熟度。

### 1. 先按产品定熟度
- **做冰沙/奶昔/香蕉牛奶类饮品**：用**熟透但未烂**的香蕉，表皮大面积黄、带少量黑点，果肉软甜、香气足。太生会涩、不甜；过熟会发黑出水、酸味重。
- **做香蕉果泥、酱、挂壁**：可用**更熟一点**的，黄皮带明显黑点，甜度高、易压泥，但必须当天处理，不能久放。
- **做甜品装饰、切片、奶油蛋糕夹层**：用**刚熟到熟**的，整体黄、两端略青、按下去有弹性但不软塌，切面才挺。
- **做油炸香蕉、烤香蕉、焦糖香蕉**：用**偏硬一点**的，黄中带一点青，耐加热不易散。

### 2. 采购时看这几点
- **颜色**：青黄适合存放；全黄适合1–2天内用；黑点密集适合当天做果泥。
- **手感**：轻按有弹性、不软陷；果柄不干枯、不霉。
- **表皮**：少量黑点是熟度标志，但大面积黑斑、渗液、破皮不要。
- **成串状态**：整串偏青可分批催熟；已全黄的建议少量多次买。

### 3. 采购节奏建议
- **主力饮品**：买**黄中带少量黑点**的，2天内用完。
- **备货**：买**黄中带青**的，室温催熟，按天分批转熟。
- **甜品装饰**：每天少量买**刚熟**的，避免切后氧化发黑。
- **不要一次全买熟透的**，香蕉后熟很快，夏天尤其明显。

### 4. 到店后控熟
- 青黄香蕉**室温避光**放，不要冷藏，冷藏会黑皮、影响后熟。
- 已熟香蕉**分开存放**，避免乙烯催熟整批。
- 需要延缓成熟可**降低温度但别低于12℃**，并保持通风。
- 每天挑出黑斑多、软陷的，优先做果泥或当天特饮，不要继续陈列。

### 5. 简单验收标准
- **合格**：表皮黄、少量黑点、果柄完整、无霉无渗液、按压有弹性。
- **可催熟**：黄中带青、硬挺、无伤。
- **拒收**：大面积黑斑、破皮流汁、酸味、果柄霉变、整串软塌。

一句话：**饮品用熟蕉、装饰用刚熟蕉、备货用青黄蕉，分批买、每天挑、熟蕉当天消化。**
