超市水果到货品相不好，售后流程建议在采购合同或收货确认单里提前约定，核心是把“什么算不合格、怎么报、谁来判、怎么赔、多久办完”写清楚。可执行条款可以这样设计：

1. **验收标准写具体**
   - 按品类约定外观标准：大小、色泽、成熟度、机械伤、腐烂率、虫害、冻伤、失水萎蔫等。
   - 量化不合格比例，例如“单批次腐烂/严重压伤比例超过3%即整批可拒收或按比例扣款”。
   - 区分“轻微瑕疵”和“重大质量不符”，避免口头争议。

2. **到货验收时限**
   - 约定到货后多长时间内完成验收，例如2小时内初检、24小时内提出书面异议。
   - 生鲜易腐品建议现场拍照/视频留证，并在收货单上注明异常。
   - 超过时限未提出异议的处理方式也要写明，避免供应商事后不认。

3. **报损与举证流程**
   - 收货方发现品相不好，应在约定时限内提交：到货照片/视频、称重记录、抽检记录、收货单异常备注。
   - 双方可约定抽样比例和判定方法，例如每批随机抽3箱，按不合格果重量占比计算。
   - 必要时约定第三方检测或双方共同复检，费用由责任方承担。

4. **处理方式分级**
   - 轻微瑕疵：降价接收或按比例折价。
   - 部分不合格：按不合格重量/数量扣款，或退货换货。
   - 严重不合格：整批拒收、退货退款，供应商承担运费和损耗。
   - 已上架后发现隐蔽质量问题：约定追溯期和赔偿方式，例如24小时内可反馈，供应商补货或折价。

5. **退换货与费用承担**
   - 明确退换货触发条件、响应时限，例如供应商24小时内确认，48小时内补货或退款。
   - 明确运费、装卸费、冷藏损耗、废弃处理费由谁承担。
   - 约定供应商逾期不处理的，超市可自行折价处理并从货款中扣除。

6. **对账与扣款机制**
   - 约定质量扣款直接从当批或后续货款中抵扣，并出具扣款通知。
   - 保留质量保证金或账期约束，例如首批货款留存5%—10%作为质量保证金，合作稳定后调整。

7. **责任边界与争议解决**
   - 明确运输途中温控、装卸责任归属；到货前风险由供应商承担，验收合格后按约定转移。
   - 约定争议先复检协商，协商不成按合同争议条款处理。
   - 所有售后沟通尽量书面化，微信、邮件、系统工单均可作为凭证。

简单说，售后流程应约定为：**到货限时验收→拍照留证并书面异议→按量化标准判定→分级折价/换货/拒收→供应商限时响应→扣款或退款闭环**。这样既能让门店操作有依据，也能减少供应商扯皮。
