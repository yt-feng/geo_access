对餐饮连锁采购水果，**多数情况下建议“中央厨房统一收货为主、门店少量直收为辅”，而不是全部门店分开收货。** 但水果品类特殊，不能一刀切，关键看以下几项：水果是否耐储、门店是否具备验收能力、配送频次和损耗责任能否算清。

## 结论

**推荐模式：中央厨房统一收货 + 门店少量直采/应急补货。**

适用大多数连锁餐饮，尤其是：
- 门店数量多、分布在同一城市或区域；
- 水果用于统一产品配方，品质标准要求一致；
- 有冷藏/分拣/配送能力；
- 需要集中议价和供应商管理。

**不建议全部门店分开收货**，除非门店少、水果以门店现场鲜切/展示为主、且门店有成熟验收能力。

## 两种模式对比

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 采购议价 | 强，集中采购量大 | 弱，单店量小 |
| 品质标准 | 易统一，可集中验收 | 各店执行差异大 |
| 验收能力 | 可配专业品控 | 门店人员未必懂水果 |
| 损耗控制 | 可集中分拣、分级使用 | 损耗分散但难追责 |
| 配送时效 | 需冷链和二次配送 | 供应商直送更短 |
| 门店操作 | 门店省事 | 门店收货工作量大 |
| 责任追溯 | 清晰 | 容易扯皮 |
| 适合品类 | 耐储、标准化、配方用果 | 高鲜度、易损、展示用果 |

## 水果品类要分开看

**适合中央厨房统一收货的：**
- 柠檬、橙子、苹果、西瓜等耐储或标准化程度高的；
- 用于饮品、甜品、酱料配方的定量水果；
- 需要统一清洗、切配、分装的。

**适合门店直收或供应商直送门店的：**
- 草莓、蓝莓、荔枝、杨梅等极短保鲜期水果；
- 门店现场陈列、鲜切展示、顾客自选的水果；
- 单店销量波动大、中央厨房配送频次跟不上的。

更稳妥的做法是**按品类分层**：耐储和配方用果走中央厨房；高鲜度、展示型水果走门店直收，但供应商、价格、标准由总部统一谈。

## 决策判断清单

满足以下越多，越应中央厨房统一收货：
1. 门店数 ≥ 10 家，且同一区域配送可行；
2. 水果占产品成本比例较高，集中采购能降本；
3. 产品配方要求水果规格、糖度、成熟度统一；
4. 有冷藏库、分拣区和冷链配送；
5. 门店人员流动大，验收标准难执行；
6. 需要统一食安追溯和供应商考核。

满足以下越多，越应保留门店直收：
1. 水果保鲜期极短，二次配送会明显增加损耗；
2. 门店现场加工/展示比例高；
3. 门店分布分散，中央配送成本高；
4. 单店销量差异大，统配容易压货；
5. 已有可靠供应商能直送门店并接受总部统一管理。

## 落地建议

建议采用**“总部统谈、中央厨房统收统配为主、门店直收为辅”**的混合模式：

1. **总部统一供应商准入、价格框架和品质标准**，不让门店自行找供应商。
2. **耐储水果和配方水果由中央厨房收货、验收、分拣后配送门店。**
3. **高鲜度水果允许供应商直送门店，但必须按总部标准验收，门店拍照/抽检留痕。**
4. **建立分级验收标准**：糖度、规格、成熟度、伤果率、农残检测报告。
5. **损耗责任分开算**：中央厨房到店前的损耗归中央厨房/供应商，到店后的归门店。
6. **先试点**：选 5—10 家门店跑 1—2 个月，对比损耗率、到货合格率、门店投诉率和综合成本，再决定扩围。

**一句话：能集中验收的尽量集中，保鲜期极短和展示型水果保留门店直收，但标准和供应商必须由总部统一管。**
