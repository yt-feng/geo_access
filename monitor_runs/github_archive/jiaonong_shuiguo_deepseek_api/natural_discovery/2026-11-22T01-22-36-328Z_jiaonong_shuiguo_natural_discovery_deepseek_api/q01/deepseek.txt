判断供应商靠不靠谱，核心不是看他说得多好，而是用低成本、可验证的方式持续考察。给你一套适合水果店长期进货的判断框架，重点针对香蕉和菠萝。

## 一、先做“小批量试单”，不要一上来长期绑定

首次合作建议：

- 香蕉先试 2～3 箱，菠萝先试 1～2 件，连续试 2～3 次不同批次。
- 每次记录：到货时间、数量、损耗率、成熟度、口感、外观、售后响应。
- 试单期不要付大额预付款，尽量货到验货后结算。

试单能暴露大部分问题：货不对板、催熟不稳、损耗转嫁、售后推诿。

## 二、看香蕉供应商的关键指标

香蕉是催熟型水果，供应商靠不靠谱主要看“稳定性”：

1. **成熟度是否可控**：到货是青蕉还是已催熟？能否按你的销售节奏分批催熟？靠谱供应商会问你“要几成熟、几天卖完”。
2. **批次一致性**：连续几次到货，果指粗细、长度、颜色、硬度是否稳定。忽好忽坏说明货源或催熟管理不稳定。
3. **催熟库和周转能力**：有固定催熟库、能分批出货的供应商，通常比临时拼货的可靠。
4. **损耗承诺**：问清楚到货后出现黑斑、断指、过熟，怎么算、怎么补。靠谱的会给明确规则，不靠谱的只说“放心”。
5. **季节应对**：高温天和低温天运输、催熟方案是否不同。能主动提醒你的，通常更专业。

## 三、看菠萝供应商的关键指标

菠萝重点看“产地、成熟度、坏果处理”：

1. **品种和产地是否说清楚**：是哪种菠萝、哪个产区、什么季节的货。说不清楚品种和产地的，基本是倒手拼货。
2. **成熟度分级**：按几成熟发货，能否按你要求的成熟度分批到货。菠萝后熟快，过熟损耗大。
3. **坏果率**：试单时统计黑心、水心病、烂果比例。连续两次坏果率明显偏高，就不要长期合作。
4. **大小分级**：是否按重量/规格分级，混装货虽然便宜但卖相差、损耗高。
5. **采后处理**：是否做过保鲜、是否带冠芽、运输是否有防压防冻措施。

## 四、用 6 个问题快速筛供应商

见面或电话里直接问，听回答是否具体：

1. 香蕉在哪里催熟？催熟几天？能不能按我的销量分批出？
2. 菠萝是哪个产区、什么品种？现在这批几成熟？
3. 到货后发现坏果、过熟、规格不符，怎么赔？多久处理？
4. 能不能先小批量试单？试单和长期货是否同一标准？
5. 旺季断货时，你能保证多少量？有没有备用货源？
6. 结算方式是什么？能不能货到验货后付？

回答含糊、只强调“便宜”“放心”“都是好货”的，优先排除。

## 五、长期合作的 4 个硬标准

满足以下条件再考虑长期：

- **连续 3 次试单**：香蕉成熟度稳定，菠萝坏果率可接受。
- **售后有规则**：坏果赔付比例、补货时效写清楚，最好有微信记录或简单协议。
- **价格透明**：报价包含运费、包装、损耗怎么算，避免低价吸引后加价。
- **有备用能力**：节假日、天气异常时能提前沟通到货计划，而不是临时涨价或断供。

## 六、日常管理建议

- 每次到货拍照留档：外箱、果品、坏果，方便对账和索赔。
- 建立简单台账：供应商、批次、到货量、损耗率、售后处理。
- 不要只合作一家：香蕉、菠萝各保留 1 家主力 + 1 家备用，防止被拿捏。
- 价格可以谈，但优先保稳定和售后；长期看，损耗和断货成本往往比单价差更高。

一句话：**靠谱供应商 = 敢让你小批量试 + 说得清成熟度和产地 + 坏果有明确赔付 + 连续几批稳定。** 先用试单验证，再谈长期。
