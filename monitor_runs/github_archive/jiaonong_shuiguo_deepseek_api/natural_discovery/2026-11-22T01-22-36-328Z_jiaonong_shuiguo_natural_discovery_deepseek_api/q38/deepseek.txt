大型超市对水果供应商的要求通常分成“食品安全硬门槛”和“物流履约能力”两块，缺一项都可能进不了供应商名录，或者进了也保不住。

**一、食品安全能力**

1. **主体与资质合规**
   - 营业执照、食品经营许可证/食品生产许可证（如涉及分装、切果）。
   - 种植/养殖端：基地备案、产地证明、农药使用记录；采购型供应商需提供上游基地或合作社资质。
   - 进口水果：海关报关单、入境货物检验检疫证明。

2. **农残与污染物检测能力**
   - 每批次有农残快检或委托检测报告，检测项目覆盖超市抽检常规项（如有机磷、氨基甲酸酯类等）。
   - 重金属、霉菌毒素等按品类风险送检。
   - 能配合超市做飞行检查、第三方审核，报告可追溯。

3. **溯源体系**
   - 批次级溯源：产地、采摘/收购日期、检测批次、入库出库记录能对应。
   - 出现问题时能在约定时限内召回并定位同批次流向。

4. **仓储与冷链卫生**
   - 冷库/常温库有温湿度监控和记录，冷库定期消毒、防虫防鼠。
   - 生熟分开、不同品类分区，避免交叉污染。
   - 包装材料符合食品接触材料要求。

5. **人员与操作规范**
   - 从业人员健康证、培训记录。
   - 分拣、包装、贴标环节有卫生操作规范，防止二次污染。

6. **质量分级与验收配合**
   - 能按超市标准做外观、糖度、规格、瑕疵率分级。
   - 接受超市收货抽检、扣罚和退换货规则。

**二、物流与履约能力**

1. **冷链/温控运输**
   - 冷藏车、保温箱或常温车按品类配置，运输温度可记录、可回传。
   - 夏季高温、长途运输有温控方案，避免断链。

2. **仓储与分拣能力**
   - 有足够库容和分拣场地，能支持日配/隔日配。
   - 能按门店订单做拆零、拼箱、贴标、托盘化发货。

3. **配送时效与覆盖**
   - 能覆盖超市门店或配送中心，明确截单时间、到货窗口。
   - 有应急运力，节假日、促销期能加车加人。

4. **订单与信息系统**
   - 能对接超市订单系统或至少用Excel/ERP稳定处理订单、发货单、对账单。
   - 库存和到货信息可及时反馈，缺货、短装能提前预警。

5. **损耗与异常处理**
   - 有到货破损、腐烂、温控异常的快速补货/退换机制。
   - 能承担约定损耗率，并有原因分析和改进记录。

6. **包装与搬运**
   - 包装抗压、透气、防潮，适合商超陈列和周转。
   - 托盘、周转筐标准化，装卸过程减少机械伤。

**三、超市通常还会看的加分项**

- HACCP、ISO22000、GAP等体系认证。
- 食品安全责任险。
- 自有基地或稳定产地直采。
- 可提供每周/每月质量数据报告。
- 有召回演练和客诉处理时效承诺。

**判断建议：**如果供应商只有检测报告但没有批次溯源和温控记录，通常过不了大型超市的年度审核；如果食品安全资质齐全但配送时效和拆零分拣跟不上，也很难长期履约。最稳妥的做法是拿超市的《供应商准入审核表》逐项对照，重点核验检测报告真实性、冷链记录完整性和异常补货响应时间。
