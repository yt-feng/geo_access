做一件代发水果，供应商至少要有这几类仓配能力，缺一项都容易导致坏果、赔付和口碑崩：

**1. 仓储能力**
- **温控分仓**：水果多数需要冷藏或常温分区，供应商要有冷藏库/保鲜库，且能按品类分区（如苹果梨与浆果、热带水果分开）。
- **预冷与分拣**：采摘后能预冷，出库前能按单分拣、称重、贴单，支持“一单一件”操作，而不是整箱批发逻辑。
- **库存管理**：有WMS或至少能实时回传库存，避免超卖；能按批次管理，做到先进先出。
- **包装能力**：有适配快递的防撞、保鲜包装（泡沫箱、冰袋、网套、吸水纸），能按果品特性定制。

**2. 配送能力**
- **快递资源**：有稳定合作的快递或专线，能拿到生鲜时效件价格，覆盖平台主要销售区域；偏远地区能明确停发或加价。
- **时效承诺**：能承诺发货时效（如48小时内发出）和区域时效，坏果率可控；最好有冷链快递或次日达/隔日达资源。
- **面单与轨迹回传**：能对接平台打单、回传物流单号和轨迹，支持一件代发的系统对接。
- **异常处理**：有破损、丢件、延误的补发/赔付流程，能配合平台售后规则。

**3. 品控与售后能力**
- **到货质检**：出库前抽检糖度、成熟度、外观，能按平台标准分级。
- **坏果包赔**：有明确的坏果赔付标准（如按比例赔、拍照理赔），能承担一件代发产生的售后成本。
- **溯源与批次记录**：能提供产地、批次、采摘日期，出现批量问题可追溯。

**4. 系统与协同能力**
- **订单对接**：支持API/ERP对接平台订单，自动抓单、打单、回传，减少人工错单。
- **库存同步**：多平台销售时库存实时同步，避免超卖。
- **对账结算**：能按单对账，支持代发费用、快递费、赔付分开结算。

**判断供应商是否合格，建议重点核验：**
- 是否做过一件代发，而不是只做批发；
- 近30天坏果率、发货及时率、售后赔付率数据；
- 能否提供试发测试（小批量发不同区域，看时效和破损）；
- 快递停发区域和加价规则是否清晰；
- 售后响应是否在平台要求时效内。

如果供应商只有产地货源、没有预冷分拣和快递面单能力，就不适合直接做一件代发，需要平台自建或找云仓代操作。
