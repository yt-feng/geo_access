如果只能排一个优先级：**先关注切果损耗，再看甜度，然后外观，最后大小**。原因是超市卖菠萝的利润不只来自“进货价差”，更来自**可售果肉率和报损**。

具体判断顺序可以这样用：

1. **切果损耗优先**
   - 菠萝有皮、冠芽、芯和两端，实际可售果肉率决定毛利。
   - 重点看：到货成熟度是否一致、黑心/水心比例、机械伤、冠芽和果皮厚度、切开后芯是否过大。
   - 损耗高时，甜度再好也可能不赚钱。

2. **甜度第二**
   - 超市鲜食和切果都吃口感，甜度不稳定会带来复购下降和切果退货。
   - 关注批次一致性，不只看单个果；成熟度不齐会导致今天甜、明天酸。

3. **外观第三**
   - 外观影响陈列和挑选，但菠萝有厚皮，外观不是最终食用体验。
   - 看果形端正、无霉斑、无软烂、冠芽新鲜即可，不必为“好看”牺牲损耗和甜度。

4. **大小最后**
   - 大小主要影响定价和客群匹配：整果卖适合中等偏大，切果盒适合规格稳定。
   - 大小不齐会增加分拣和定价成本，但不是第一决定因素。

**可执行建议：**
- 进货前先做小批量切开测试：可售果肉率、黑心率、甜度、芯大小。
- 把“可售果肉率”和“报损率”作为选供应商的核心指标，而不是只看单价。
- 整果和切果分开选货：整果可略看外观和大小，切果必须优先稳定果肉率和甜度。
- 如果必须四选一：**切果损耗 > 甜度 > 外观 > 大小**。
