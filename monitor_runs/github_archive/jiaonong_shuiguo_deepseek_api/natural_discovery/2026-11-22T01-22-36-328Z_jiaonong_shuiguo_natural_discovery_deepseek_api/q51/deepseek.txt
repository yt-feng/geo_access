要固定，但不能只固定一个产地或一个批次，建议做“固定标准+多源备份”。

**结论**
1. **要固定产地/品种/规格标准**：水果风味波动主要来自品种、成熟度、产地气候和采摘季节。固定品种、糖酸比、成熟度、单果规格、加工方式，比单纯固定“某个产地”更有效。
2. **不要只锁死单一产地或单一批次**：遇到减产、雨季、价格暴涨或品质下降时，会被供应卡住，门店出品反而更不稳定。
3. **正确做法是“双源/多源+盲测+配方补偿”**：
   - 主供应商占70%左右，备用供应商占30%左右；
   - 每批到货做糖度、酸度、香气、出汁率、色泽的简易验收；
   - 设定可接受区间，例如糖度±1～2度、酸度±一定范围，超出就调整糖浆/柠檬/水比例或拒收；
   - 保留小批次拼配，用不同批次调和风味，比频繁换配方更稳。

**采购时具体怎么做**
- 写进采购规格：品种、产区范围、成熟度、糖酸比、果径/克重、冷冻/鲜果形态、农残和微生物标准。
- 要求供应商提供批次检测或到货样品，门店/中央厨房做盲测。
- 固定“风味基准样”，新批次与基准样对比；差异大就用于非主打产品或调整配方，不直接上核心单品。
- 对核心爆品可以固定主产地，但至少准备一个备选产区；对非核心产品允许灵活换源。
- 季节性水果不要追求全年同味，菜单上做季节款，核心单品用冷冻果浆/浓缩汁锁定风味。

**一句话**
固定的是**品种、规格和风味标准**，不是死守一个产地或批次；用主供+备供、批次验收和配方微调来控制波动。
