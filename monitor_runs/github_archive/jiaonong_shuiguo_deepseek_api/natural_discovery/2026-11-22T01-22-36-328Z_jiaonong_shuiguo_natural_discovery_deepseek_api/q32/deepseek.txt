判断“全年稳定供货”，核心不是听供应商口头承诺，而是把**供应能力拆成可验证的产能、产地结构、设施、履约记录和风险预案**，并用合同约束。可按下面清单操作。

**1. 先看产地与季节结构，不只看一个基地**
- 要求供应商列出全年各月份货源产地、面积、预计产量、上市月份。
- 香蕉主产区受台风、寒害、雨季、病害影响大，单一产地很难全年稳定。
- 合格供应商应有**多产区/多基地调配能力**，并能说明某产区受灾时从哪补货。
- 重点问：国产与进口比例、是否依赖单一省份或单一果园、是否有后备产区。

**2. 核查真实产能与硬件**
- 看基地或合作基地的种植面积、株数、历史出货量，不只看营业执照。
- 看加工厂：催熟库容量、冷库、分拣线、包装能力、日处理量。
- 香蕉需要催熟和冷链衔接，**催熟库容量决定旺季和节假日峰值供货能力**。
- 要求提供近12个月月度供货记录、主要客户、物流车辆或合作冷链资源。

**3. 用“历史履约+压力测试”验证**
- 调取近一年供货数据：月均供货量、最大单月供货量、断供次数、迟到率、损耗率。
- 做小批量试单：连续2—3个月下单，覆盖淡旺季，观察到货合格率、催熟一致性、缺货补货速度。
- 设置压力测试：临时增加30%—50%订单、要求48小时内补货，看响应能力。
- 向同行或现有客户侧面了解其旺季是否优先保供。

**4. 看质量稳定性，不只看出货量**
- 要求明确规格：果指长度、单把重量、青熟度、无伤率、农残检测。
- 全年稳定供货还包括**品质稳定**：不同批次到店后催熟时间、货架期是否一致。
- 要求每批提供农残检测报告和产地证明，定期抽检。

**5. 查风险预案与替代方案**
- 问清台风、寒潮、病害、物流中断、春节用工紧张时的应对方案。
- 是否有备用产区、备用加工厂、备用冷链承运商。
- 是否购买农业保险或货物运输险。
- 关键点：**供应商能否书面承诺“缺货时提前几天通知、如何补货、如何赔偿”**。

**6. 用合同把“全年稳定”变成可执行条款**
- 约定月度最低供货量、旺季峰值保供量、到货时间窗口。
- 约定缺货违约金、质量不合格退换货、价格调整机制。
- 约定备用供应商启用条件，避免被单一供应商绑定。
- 对关键月份设置履约保证金或账期约束。
- 不要只签年度框架，要按月滚动确认订单和产能。

**7. 采购方的内部动作**
- 至少保留**主供应商+备选供应商**，主供占比建议不超过70%。
- 建立月度供应商评分：到货率、合格率、损耗率、响应速度、价格稳定性。
- 旺季前提前锁量，淡季用价格和账期换全年保供承诺。

**快速判断结论：**
如果供应商能提供**多产区全年货源表、近12个月供货记录、催熟与冷链能力证明、缺货预案，并接受试单和合同保供条款**，基本可判断具备全年稳定供货能力。若只有单一基地、无法提供历史月度数据、拒绝试单或拒绝缺货赔偿，即使报价低，也不适合作为全年主供。
