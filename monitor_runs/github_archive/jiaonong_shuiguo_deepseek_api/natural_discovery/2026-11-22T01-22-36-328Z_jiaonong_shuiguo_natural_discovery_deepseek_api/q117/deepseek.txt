先给一个可执行的判断框架，再给数量建议。

**先明确“稳”的标准：** 试卖不是要赚多少，而是用最小成本验证三件事——到货品质是否稳定、顾客是否复购、损耗是否可控。所以试卖量应由“能在一周内卖完且损耗可承受”倒推，而不是按供应商推荐量走。

**数量建议（按门店类型）：**

| 场景 | 建议首次试卖量 | 判断依据 |
|---|---|---|
| 单店、中小型水果店/社区店 | 单品 20–30 公斤（或 1–2 箱） | 够摆 2–3 天排面，能在 5–7 天内卖完 |
| 单店、客流较大的生鲜超市 | 单品 50–80 公斤（2–4 箱） | 需支撑一周陈列和试吃，但不至于压货 |
| 多店连锁（3–10 家） | 选 2–3 家典型门店，每店 1 箱起，总计不超过 5 箱 | 先小范围跑数据，不全面铺开 |
| 高档/精品店 | 更少，10–20 公斤即可 | 客群窄，验证复购比铺量重要 |

**更通用的算法：**
- 按预计日销量 × 3–5 天 = 首单量；
- 同时设一条硬上限：**首单金额不超过该品类周营业额的 5%–10%**，或单店不超过 500–1000 元（按门店规模调整）。
- 如果新品单价高、保质期短（如草莓、蓝莓、榴莲），取下限；耐储品类（苹果、橙、瓜类）可取上限。

**试卖期要盯的四个指标：**
1. 到货损耗率（开箱即损）——超过 5% 就该和供应商谈；
2. 3 天动销率——3 天卖不到一半，说明定价或客群不匹配；
3. 复购/回头询问——比一次性销量更能判断是否续订；
4. 损耗成本——试卖期总损耗金额应控制在首单金额的 10% 以内，否则不算“稳”。

**操作建议：**
- 首单只订 **1 个批次、1 个规格**，不要同时试多个等级；
- 要求供应商给 **小箱/混装**，并约定到货品质不符可退换；
- 试卖 7 天后做“续订/不续订/换规格再试”三选一决策，不要无限期观察；
- 如果供应商要求起订量高，宁可选“先代销/寄卖一批”或换小包装，也不要为拿低价压大货。

一句话结论：**单店先试 1–2 箱（约 20–30 公斤）、控制首单金额在几百到一千元内，一周内看动销和损耗再决定是否放大**，这是最稳的起点。
