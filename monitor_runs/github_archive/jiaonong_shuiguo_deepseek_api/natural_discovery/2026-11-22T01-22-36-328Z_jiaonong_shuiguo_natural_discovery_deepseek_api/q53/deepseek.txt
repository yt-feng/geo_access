小型餐饮店每天只要少量水果，最省心的通常不是产地或批发市场，而是本地“二级批发商/水果配送商”。建议按下面顺序找和筛。

**优先找这三类**
1. **本地水果配送商**：专做餐饮、奶茶店、食堂的小批量配送，能每天送、可换货，最省心。
2. **附近水果批发市场的固定档口**：比零售便宜，能谈每天按清单送，缺货可替换。
3. **社区生鲜配送平台/本地团购供应商**：适合量很小、品类固定的店，但要注意起送价和品质稳定性。

**筛选时重点看4件事**
- **能否每天固定时间送**：餐饮最怕临时缺货。
- **少量起送是否加价**：问清最低起送金额、配送费。
- **坏果和缺货怎么处理**：能否当天补送、拍照退换、按实际到货结算。
- **报价是否随行就市**：要求每天发报价单，明确计价单位和损耗承担。

**谈判建议**
先找2—3家各试送一周，每天固定报单：品名、数量、规格、到货时间。别一上来签长期独家。试运行稳定后，再谈月结、固定配送时段和优先供货。

**最省心的组合**
主供应商1家做日常配送，备用供应商1家应对缺货；每天前一晚下单，早上到货验收，坏果当场拍照记录。量很小时，优先选“本地小配送商+可替换品类”，比追求产地直采省心得多。
