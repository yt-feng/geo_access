选规格的核心不是“越大越划算”，而是按**出成率、单份成本、损耗和出餐稳定性**算。水果拼盘建议这样选：

**1. 苹果**
- **优先选中等偏大、果形匀称的**：单果约 **180–220g** 比较稳。
- 不选特大果：拼盘切块后每片大小难统一，边角料多。
- 看用途：  
  - 切瓣/切片做装饰：选脆度高、果面光滑的中大果。  
  - 切丁混拼：中小果也能用，但人工挑拣成本会上升。
- **划算判断**：同样价格下，算出成率（去皮去核后净重/毛重）。苹果出成率通常较高，重点比“单斤价+损耗率”。

**2. 橙子**
- **选中等果，单果约 180–250g** 更合适。
- 太大果皮厚、白瓤多，切瓣出品不一定多；太小则剥切费工。
- 做拼盘优先选**皮薄、易剥、籽少、酸甜稳定**的品种。
- **划算判断**：按“可食净重”算，不要只看毛重价格。橙子皮厚差异大，毛重便宜未必真便宜。

**3. 菠萝**
- **选单果 1.2–1.8kg 的中等果**通常最适合餐厅。
- 太大：一次用不完，氧化和冷藏损耗高；太小：去皮去眼后净肉少、切工多。
- 优先选**成熟度一致、果眼浅、出肉率高**的。
- **划算判断**：按“去皮去眼后净肉重量”算单份成本，并考虑开果后保存时限。

**通用选择原则**
- **按份定量**：先定每份拼盘各水果克重，再反推采购规格。
- **算净料成本**：公式是 `净料单价 = 毛料单价 ÷ 出成率`，比毛价更准。
- **稳定优先**：餐厅拼盘最怕大小不一、成熟度不齐，规格稳定比偶尔低价更重要。
- **小批量高频采购**：菠萝、橙子切开后损耗快，别为单价便宜一次囤太多。
- **按季节换品种**：苹果、橙子、菠萝都有产季和品种差异，固定“规格区间”比固定“某个品种”更实用。

简单结论：**苹果选 180–220g 匀称中果，橙子选 180–250g 皮薄中果，菠萝选 1.2–1.8kg 成熟一致中果；最终用“净料成本+损耗+出餐稳定”三项判断，而不是只看斤价。**
