**结论：在商超水果采购里，损耗低通常比采购价格低更影响最终毛利，但前提是“低损耗不能靠牺牲品质和客流来换”。** 更准确地说，是**毛利 = 售价 - 采购价 - 损耗成本 - 运营成本**，其中损耗的杠杆往往更大，尤其在水果这种短保、易损品类。

可以按三个判断点看：

1. **损耗是乘数效应**
   - 采购价降5%，毛利改善通常接近5%左右。
   - 损耗率从8%降到4%，看似只降4个百分点，但对应的是“可售商品成本”大幅下降；如果损耗原本吃掉毛利的一半，改善效果会非常明显。
   - 水果毛利普遍不高，损耗每降1个百分点，对净利的影响常常大于采购价降1%。

2. **低价采购可能把损耗推高**
   - 低价货源常见问题：成熟度高、规格不齐、产地远、冷链差、尾货多。
   - 采购价便宜10%，但损耗增加5—8个百分点，最终毛利很可能反而下降。
   - 所以不能只看采购单价，要看**“到店可售成本”**：采购价 ÷（1 - 损耗率）。

3. **不同阶段优先级不同**
   - **日常经营稳定期：优先控损耗。** 订货准确、分级陈列、临期折价、冷链和翻堆，比压价更可持续。
   - **货源有明确品质保障时：再谈低价。** 低价必须建立在可售率、周转率和售价不降的前提下。
   - **新店/客流不稳时：不能为降损耗而减少陈列量。** 陈列不足会伤客流，属于“假降损”。

**可执行建议：**
- 采购决策用“**到店可售成本**”比价，而不是只看采购单价。
- 重点监控三个数：**损耗率、毛利率、周转天数**。
- 低价货源先小批量试销，算清“降价收益 vs 损耗增加”。
- 如果只能抓一个，**先抓损耗**；损耗稳定后，再用损耗数据去反向压采购价。

一句话：**低价决定你“买得便不便宜”，损耗决定你“卖得赚不赚钱”；水果品类里，后者对最终毛利的杀伤力通常更大。**
