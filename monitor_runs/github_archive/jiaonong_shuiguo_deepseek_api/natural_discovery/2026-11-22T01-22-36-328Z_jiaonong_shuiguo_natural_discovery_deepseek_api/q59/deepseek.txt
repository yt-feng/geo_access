可以谈，但“锁价”一般不是无条件锁死，而是有条件的价格稳定机制。餐饮店水果用量稳定、单品集中时，谈判空间更大。

建议这样操作：

1. **先锁定少数高频单品**
   不要一上来锁全部水果。先选用量大、规格稳定、季节性相对可控的2—4个单品，比如柠檬、橙子、苹果、西瓜等，逐个谈。

2. **谈“锁价+浮动区间”而不是死价**
   常见做法是：
   - 约定基准价和锁价周期，如1个月或1季度；
   - 约定触发调整的条件，如产地批发价涨跌超过5%—10%才调价；
   - 双方各承担一部分波动，例如涨幅在5%以内供应商承担，超过部分按比例分担。

3. **用采购量换价格稳定**
   给供应商可预期的周/月采购量、结算周期和最低采购承诺，换取锁价或优先供货。比如“每周固定采购XX斤、账期7天、连续合作3个月”。

4. **明确规格和质量标准**
   锁价必须同时锁规格：品种、等级、单果重量、成熟度、瑕疵率、包装、损耗处理。否则供应商可能用降规格来变相涨价。

5. **约定异常情况**
   极端天气、产地减产、物流中断时怎么调价、是否保供、是否可换替代品，都要写进协议，避免临时扯皮。

6. **保留比价和第二供应商**
   锁价不等于放弃市场比价。建议每1—2个月对比一次市场价，并保留1家备用供应商，防止被单一供应商绑定。

7. **先短期试运行**
   先签1个月或1个季度的试合作，记录实际到货价、质量、损耗，再决定是否延长锁价周期。

结论：**能谈，而且值得谈，但更适合“重点单品+有限周期+浮动机制+质量标准+采购量承诺”的组合锁价，而不是要求供应商长期固定一个死价格。**
