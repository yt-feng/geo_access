# 水果到货不合格，怎么约定补货才不耽误营业

核心思路：**把“补货”从口头承诺变成有时间、有数量、有替代方案、有违约后果的条款**，并且在采购合同或供货协议里提前写死，而不是等出了问题再谈。

## 一、合同里必须写清的 6 个要素

1. **验收标准（可判断）**
   - 按品类分别写明：品种、规格（克重/果径）、成熟度、糖度范围、外观（无腐烂、无压伤、无霉变）、农残检测要求。
   - 附一份“验收标准表”作为合同附件，避免“合格”各说各话。

2. **验收时限与方式**
   - 到货后多长时间内完成验收（如 2 小时内），超时未提异议视为合格——这条对双方都公平，也逼自己门店及时验货。
   - 明确验收人、拍照留证要求（整箱照 + 问题果特写 + 称重照）。

3. **补货时限（关键）**
   - 按影响程度分级：
     - **严重不合格**（整批腐烂/霉变/严重压伤）：要求 **当日或次日上午营业前** 补到位。
     - **部分不合格**（比例超标但可用）：**24 小时内**补足差额。
   - 写清“营业前”具体指几点（如次日 9:00 前），避免扯皮。

4. **补货方式与替代方案**
   - 优先同品同规格补货；若供应商无法及时补同品，约定**等价替换品类**或**按不合格比例退款/折价**，让门店能立刻用退款去市场应急采购。
   - 明确补货运费、损耗由供应商承担。

5. **不合格比例与判定**
   - 约定抽检比例和合格线，例如“抽检 10% 样本，不合格率超过 5% 即整批可拒收/要求补货”。
   - 拒收时供应商多久内拉走、是否收费，也写清楚。

6. **违约责任**
   - 迟延补货按日计违约金（如货款的 5%/天），或累计几次迟延可解除合作。
   - 因不合格水果导致门店停售、客诉的，约定供应商承担相应损失（可设上限，便于对方接受）。

## 二、不影响营业的实操做法

- **备双供应商**：主力 + 应急各一家，合同里都约定补货条款，临时缺货能互相兜底。
- **安全库存**：易损耗水果保持 1–2 天用量，给补货留缓冲。
- **到货即验、当场签收单**：不合格部分当场在送货单上标注并双方签字，这是后续索赔最有力的证据。
- **先退款后补货**：对严重不合格，约定“先按比例退款，再补货”，门店可立即用退款去周边市场买应急量，不等供应商。
- **补货不影响当日菜单**：对补货周期长的品类，提前准备替代配方或临时下架话术，避免临时手忙脚乱。

## 三、一句话模板（可直接放进合同）

> “乙方所供水果经甲方按附件《验收标准》验收，不合格率超过 5% 的，甲方有权拒收该批次。严重不合格（腐烂、霉变）的，乙方须于次日 9:00 前补足同品同规格货物；无法补足的，按不合格数量货款的 100% 退款，甲方可自行采购替代，差价由乙方承担。迟延补货的，每迟延一日按该批次货款的 5% 支付违约金。”

**判断标准**：一份好的补货条款，应该让门店在发现问题后 **当天就能决定“等补货”还是“拿退款自己买”**，而不是被动等供应商回复。签约前把验收标准表和分级补货时限谈定，比事后追责有用得多。
