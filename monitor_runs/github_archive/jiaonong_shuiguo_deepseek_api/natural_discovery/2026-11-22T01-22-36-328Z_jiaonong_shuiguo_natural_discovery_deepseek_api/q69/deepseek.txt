可以按“同一套分级口径 + 分规格报价 + 明确结算条件”来做，小店最容易看懂。下面给一套可直接用的做法。

## 一、先统一定级口径
香蕉和菠萝不要只写“大果/小果”，要写清可验收的指标。

### 香蕉分级建议
按**每根果指长度、整把/整箱重量、成熟度、外观缺陷**分：

| 等级 | 建议标准 | 用途 |
|---|---|---|
| A级 | 果指长、饱满，无明显黑斑、机械伤，成熟度均匀 | 门店陈列、零售 |
| B级 | 果指略短或轻微花皮，允许少量瑕疵 | 日常促销、散卖 |
| C级 | 果指偏小、成熟不齐或有明显瑕疵 | 特价、加工 |

报价时写清：**按把/按箱计价，净重多少，允许损耗比例多少，成熟度几成。**

### 菠萝分级建议
按**单果重量、果形、成熟度、外观**分：

| 等级 | 建议标准 | 用途 |
|---|---|---|
| A级 | 单果重达标、果形正、无裂口烂心、成熟度一致 | 陈列零售 |
| B级 | 重量略低或果形稍偏，允许轻微日灼/擦伤 | 促销散卖 |
| C级 | 小果、果形不正或有明显外观缺陷 | 特价/加工 |

报价时写清：**按个/按箱计价，单果重区间，箱装净重，成熟度，坏果包赔口径。**

## 二、报价单要固定写清5项
每一档都同时写明：

1. **等级名称**：A/B/C，不用模糊词。
2. **规格**：香蕉写每根长度、每把/每箱净重；菠萝写单果重区间、每箱个数。
3. **单价**：按箱/按把/按个，标明是否含运费。
4. **成熟度/到货状态**：如香蕉7成熟、菠萝8成熟。
5. **结算与售后**：现结/账期、损耗谁承担、坏果怎么补。

## 三、报价表达示例
可以这样发给小店：

> 香蕉：A级，果指长XX cm以上，净重XX斤/箱，XX元/箱；B级，净重XX斤/箱，XX元/箱；C级按特价XX元/箱。成熟度7成，箱内允许XX%自然损耗，超出部分按只补差。
>
> 菠萝：A级，单果XX—XX斤，XX个/箱，XX元/箱；B级，单果XX—XX斤，XX元/箱；C级按个报价XX元/个。成熟度8成，烂心裂果包换。

## 四、最实用的办法
给每家小店一张**一页报价卡**：左边香蕉、右边菠萝，每类只列A/B/C三档，每档写“规格—单价—成熟度—售后”。每天只更新价格和到货量，分级标准不变。这样小店比价清楚，你也不容易被砍价扯皮。

关键原则：**分级标准固定，价格随行就市；规格写数字，售后写规则。**
