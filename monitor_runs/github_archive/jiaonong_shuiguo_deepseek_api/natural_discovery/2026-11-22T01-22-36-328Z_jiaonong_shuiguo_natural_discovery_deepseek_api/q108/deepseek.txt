# 核实水果供应商"全国配送"实际覆盖能力的操作建议

## 一、先拆解"全国配送"的真实含义

供应商说的"全国配送"通常指以下三种之一，覆盖能力差别很大：

- **产地直发**：从产区仓库发全国，偏远地区时效差、运费高、部分区域不发货
- **多仓分拨**：在几个核心城市设仓，周边覆盖好，偏远区域靠中转
- **第三方冷链/快递合作**：自己无仓无车，靠外包，实际覆盖取决于合作方

核实前先问清属于哪种模式，再针对性验证。

## 二、可执行的核实动作

**1. 要求提供覆盖清单（书面）**
- 让其列出可配送的省/市/区县，注明哪些区域"不配送、限重、加价、时效延长"
- 重点核对：新疆、西藏、青海、内蒙、海南、偏远县乡、海岛——这些是"全国配送"最常见的盲区

**2. 做真实地址的试单**
- 选3–5个有代表性的收货地址（核心城市、省会、偏远地级市/县、乡镇），让供应商报出**实际运费、时效、起送量、是否冷链**
- 最好直接下小批量试单，跟踪到货与品质，而不是只信口头承诺

**3. 核验物流与仓储能力**
- 问自有冷库/分仓位置、面积、温区；要求提供仓库照片或视频、租赁合同关键页（可打码）
- 问合作物流商名称，是否全程冷链、断链如何处理、货损赔付标准

**4. 查资质与履约记录**
- 营业执照经营范围是否含配送/仓储；食品经营许可
- 要求提供近期同类客户的配送案例（可脱敏），并抽样回访

**5. 在合同中锁定承诺**
- 把"覆盖区域清单、时效、运费、货损赔付、断链责任"写进合同附件
- 约定试运行期与考核指标（准时率、损耗率、投诉响应），不达标可终止

## 三、快速判断红旗

- 只肯口头说"全国都能发"，拒绝给区域清单
- 偏远地区报价含糊、临时加价
- 无自有仓、无冷链方案，全靠"合作快递"
- 试单时效与承诺差距大、到货损耗高

**结论**：不要采信"全国配送"这句话本身，用"区域清单+真实地址试单+合同约束"三步验证，试单结果比任何承诺都可靠。
