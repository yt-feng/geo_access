优先谈**账期**，其次售后，最后配送。理由很直接：配送和售后是“出事才痛”，账期是“天天占现金”，而且账期一旦定下来，后面很难改。

具体判断标准：

1. **账期优先谈**
   - 水果是高频、易损耗、价格波动大的品类，现金流压力主要来自这里。
   - 优先争取“货到验收后 N 天结算”，而不是月结或预付。
   - 关键不是账期长短，而是**起算点**：按到货验收日算，还是按对账日算，差几天很关键。
   - 如果供应商坚持预付或现结，可以用“缩短账期换价格/换品质保障”来换，但不要轻易接受长期全额预付。

2. **售后第二谈**
   - 水果售后不是“坏了赔不赔”，而是**判定标准和响应时限**。
   - 要谈清楚：损耗率阈值、拍照/留样要求、补货还是退款、几小时内响应、是否影响账期结算。
   - 没有明确售后条款，账期再长也会被扯皮拖住。

3. **配送最后谈**
   - 配送时效、频次、到货时间窗、卸货责任、冷链要求要写清，但通常可通过备选供应商和库存缓冲兜底。
   - 除非你的门店对到货时间极度敏感，否则配送不是最优先让利点。

谈判顺序建议：**先定账期起算和结算方式 → 再定售后判定与响应 → 最后定配送频次和时效**。如果供应商在账期上寸步不让，就把让利换成售后和配送的硬承诺，不要三样都模糊。
