判断一家供应商能否稳定按规格送菠萝，重点是把“口头承诺”变成可验证的流程和证据。可以从下面几个方面做。

**1. 先明确规格并写进合同**
不要只写“菠萝”，要明确到可验收的指标，例如：
- 品种/产地，是否指定品种（如金钻、台农等，按你们实际需求写）
- 单果重量区间，比如 1.2–1.5 kg，超范围如何处理
- 成熟度/糖度，糖度下限、可用手感或糖度计抽检
- 外观，无腐烂、无黑心、无明显机械伤、果形要求
- 到货形态，是否带冠、去皮、切块、冷冻、罐装
- 包装，箱规、每箱净重、内衬、托盘要求
- 到货温度，常温或冷链，冷链需写温度区间
- 验收标准，抽检比例、不合格判定、拒收/扣款/换货规则

规格越可量化，后面判断供应商稳不稳定才越有依据。

**2. 看供应商的货源和季节供应能力**
菠萝有产区季节差异，单一产区供应商在淡季容易断供或降低规格。重点问：
- 有几个产区/合作果园，主产区切换时能否保持同一规格
- 是否有自有或长期合作基地，还是纯市场倒货
- 旺季和淡季的日供应上限、最小起订量
- 遇到台风、寒潮、集中上市期价格波动时怎么保供
- 是否做过茶饮连锁客户，能否提供同类客户供货案例（可要求匿名证明）

**3. 用小批量试单验证，而不是一次下大单**
建议做 2–4 周试单，至少覆盖正常日和周末/促销日：
- 每天按固定时间和数量下单，观察准时到货率
- 每批抽检重量、糖度、坏果率、切块规格
- 记录缺货、临时换产地、规格波动、补货响应时间
- 试单期间故意提出一次加急补货或临时增量，看响应能力

试单通过后再逐步放量，并保留至少一家备选供应商。

**4. 要求供应商提供可核验的交付数据**
可要求供应商提供：
- 近 3–6 个月同类客户供货记录（可脱敏）
- 每日可供应量和最大日发货能力
- 冷链车辆/仓库证明、质检或农残检测报告
- 异常处理流程和联系人响应时限

注意：这些材料只能作为参考，最好通过试单和现场看货交叉验证，不要仅凭供应商自述判断。

**5. 现场看货和看仓**
有条件的话去供应商的加工/分拣点看：
- 分拣是否按重量、成熟度分级
- 是否有预冷、冷藏或常温通风条件
- 包装是否统一，箱规是否稳定
- 坏果、次果如何处理，是否会和好果混装
- 发货记录、库存台账是否规范

**6. 合同里设置稳定供货约束**
- 约定准时到货率、规格合格率、坏果率上限
- 约定缺货提前通知时限和替代方案
- 约定连续不合格或断供的退出机制
- 约定价格调整机制，避免旺季随意涨价或降规格
- 约定备用供应商启用条件

**7. 建立日常验收和评分机制**
每批到货记录：到货时间、数量、抽检重量、糖度、坏果率、规格偏差、处理结果。按月给供应商打分，连续不达标就减少份额或启用备选。

简单判断标准：**能提供多产区货源、愿意小批量试单、规格可量化验收、异常响应有流程、试单期间准时率和合格率稳定的供应商，才值得放量。** 只靠关系或口头保证、不愿试单、规格说不清的，风险较高。
