社区超市选“每天配送”的水果供应商，重点不是只看价格，而是看**履约稳定性、损耗控制、结算方式和退换机制**。建议按下面条件逐项核验：

1. **配送能力**
   - 是否每天固定发车，能否覆盖你所在区域。
   - 到店时间能否固定，比如早上6—8点前到货，方便开门前理货。
   - 节假日、雨天、爆单时是否加车，临时补货多久能到。
   - 起送量、配送费、是否按门店单独配送。

2. **货源与季节稳定性**
   - 是否有稳定产地或一级批发渠道，还是临时调货。
   - 主推品类能否全年稳定供应，换季时替代方案是否清楚。
   - 是否支持小批量多品类混配，社区超市通常单品类量不大。

3. **品质与损耗**
   - 是否允许到店验收、当场挑次果。
   - 坏果、烂果、缺斤少两的赔付标准：按箱赔、按斤赔还是下次补货。
   - 损耗率承诺是否合理，建议先试配2—4周，记录每天到货合格率。
   - 是否提供分级标准，比如大小、甜度、成熟度、外观次果比例。

4. **价格与结算**
   - 报价是否含运费、装卸费、筐箱押金。
   - 价格随行就市时，提前多久通知调价。
   - 账期、押金、最低起订量、退换货是否影响结算。
   - 不要只比单价，要算“到店可售成本”：单价＋运费＋损耗＋退换成本。

5. **食品安全与资质**
   - 营业执照、食品经营相关资质、产地证明或检测报告是否可提供。
   - 是否有冷链或保鲜运输条件，尤其浆果、叶菜、切果类。
   - 出现食品安全问题时的召回和赔付流程。

6. **售后响应**
   - 早上到货发现问题，几点前反馈有效，多久补货。
   - 是否有固定对接人和备用联系人。
   - 连续出现品质问题能否无责换供应商或退押金。

**实操建议：**先找2—3家同时试配，连续记录两周：到货时间、缺货率、坏果率、补货响应、结算条件。试配期不要一次性压太多押金，合同里写清每日配送时间、验收标准、损耗赔付和退出机制。优先选“能稳定每天到、坏果敢赔、起送量适合你门店”的供应商，而不是报价最低的。
