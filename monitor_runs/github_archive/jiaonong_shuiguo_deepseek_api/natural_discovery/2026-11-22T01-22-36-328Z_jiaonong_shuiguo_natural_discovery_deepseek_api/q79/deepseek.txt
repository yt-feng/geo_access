最应该先问**售后**，其次**配送**，最后谈**价格**。

判断标准很简单：水果是非标、易损耗、时效敏感品类，团长真正承担的是**对邻居的履约责任**。一旦烂果、缺斤少两、延迟配送，团长损失的是信任，不是那点进价差。

建议按这个顺序问：

1. **售后**（第一优先）
   - 坏果、压伤、腐烂怎么赔：按颗、按斤还是按比例？
   - 多久内可报损？要不要拍照/留证？谁承担运费？
   - 是补发、退款还是抵扣下一单？
   - 缺斤少两怎么处理？
   - 有没有明确赔付时限，比如24小时内响应。

2. **配送**（第二优先）
   - 到团时间是否固定？迟到怎么补偿？
   - 是送到自提点还是团长处？卸货、分拣谁负责？
   - 冷链/保鲜条件如何？夏季和节假日怎么保障？
   - 临时改量、加单、少货怎么处理？

3. **价格**（最后谈，但不是不比）
   - 比价要同规格、同等级、同到货标准比。
   - 问清是否含运费、损耗、包装、分拣费。
   - 低价但售后差，等于把风险转嫁给团长。

一句话可执行建议：**先让供应商书面确认售后赔付规则和配送时效，再谈价格；售后说不清的，价格再低也不选。**
