可以按“引流品+利润品+场景组合”来做，不要只做简单打折。

**建议组合**
1. **香蕉做引流**：香蕉单价低、购买频次高，适合做“限时特价”或“满额换购”，例如消费满29元加3元换购一把香蕉，带动客单。
2. **菠萝做搭配利润**：菠萝适合与香蕉做“早餐/下午茶组合”，例如“香蕉+菠萝果切组合价”，比单买略便宜但提升总金额；也可做“买菠萝送香蕉一根”的关联陈列。
3. **苹果做品质升级**：苹果选精品规格做“家庭装/礼盒装”，例如“苹果+香蕉+菠萝家庭果篮”，定价高于单品合计的8-9折，主打一周水果。
4. **设三档促销**：
   - 满19元：香蕉特价；
   - 满39元：菠萝+香蕉组合价；
   - 满69元：苹果礼盒/家庭果篮升级。
5. **陈列联动**：三品相邻陈列，标“早餐组合”“家庭一周果篮”“加3元换购”，用爆炸牌写清组合价和节省金额。

**关键判断**：优先推“家庭场景组合”和“满额换购”，比三个单品同时降价更能提高客单价；香蕉让利控制在引流成本内，苹果和菠萝承担毛利。
