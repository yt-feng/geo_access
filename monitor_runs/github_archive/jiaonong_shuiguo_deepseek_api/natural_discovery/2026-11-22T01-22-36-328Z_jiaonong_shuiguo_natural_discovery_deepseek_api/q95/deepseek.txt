选香蕉、苹果、橙子这类食堂常用水果的供应商，建议别只盯“谁报价低”，而要按“能稳定供货+质量可控+账期和售后可落地”来筛。可以按下面几步做。

**1. 先定采购标准，再找供应商**
- 香蕉：按成熟度分级，食堂最好要“青黄适中、可存放2—3天”的货，避免全熟到货当天就发黑；明确每把/每箱规格、允许损耗率。
- 苹果：定品种（如富士、嘎啦）、果径范围、糖度大致要求、表面伤疤和碰压伤比例上限。
- 橙子：定品种（如脐橙、沃柑等）、果径、皮厚薄、可食率、酸度要求，避免“看着大但干水”。
- 统一写进采购单：品种、等级、规格、产地或品牌、到货时间、验收标准、不合格处理方式。

**2. 供应商类型怎么选**
- **一级批发商/大型果蔬配送公司**：适合食堂日常稳定用量，品类全、配送能力强，但价格未必最低。
- **产地合作社/基地直供**：适合苹果、橙子等耐储品，量大有价格优势，但要确认其分选、仓储和配送能力；香蕉不建议单纯找小产地户，因为催熟和运输要求高。
- **本地二级批发商**：响应快、小批量灵活，适合临时补货，但质量波动和加价可能更明显。
- 实操上建议“主供应商+备选供应商”各1—2家，主供占70%—80%，备供防止断供和临时压价。

**3. 重点核验这几项**
- 营业执照、食品经营许可或食用农产品相关资质；涉及配送的看冷链或常温运输能力。
- 是否有固定分拣场地、农残快检能力或可提供检测报告。
- 过往服务学校、机关食堂的案例，最好实地看仓库和分拣现场。
- 是否接受食堂验收标准、损耗赔付、临期或变质退换。
- 账期、结算方式、发票类型能否匹配学校财务要求。

**4. 用“试供+比价+验收”来定**
- 先让2—3家试供1—2周，同一品种同规格比价，不只看单价，还算上损耗、退换货和配送及时性。
- 每次到货按标准验收：数量、规格、成熟度、伤果率、新鲜度；拍照留档。
- 设定月度或季度评分：质量合格率、准时率、售后响应、价格稳定性，连续不达标就减量或淘汰。

**5. 合同里写清楚**
- 价格调整机制：随行就市可以，但要有报价周期和上限，避免临时大幅涨。
- 质量违约：伤果率、腐烂率超标怎么扣款、退换。
- 配送时效：迟到、漏送的处理。
- 食品安全责任：若出现农残或质量问题，供应商承担的责任和追溯方式。

简单判断标准：**能稳定按标准到货、损耗可控、出问题能当天处理、价格随行就市但不乱涨的供应商，比单纯报价最低的更值得选。** 香蕉尤其要看催熟和配送能力，苹果橙子可以适当引入产地直供比价。
