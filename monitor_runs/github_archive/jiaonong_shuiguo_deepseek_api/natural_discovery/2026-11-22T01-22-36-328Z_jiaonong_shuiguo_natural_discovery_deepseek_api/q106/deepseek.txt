判断“合理波动”不能只看涨跌幅度，而要把**价格变化拆成可解释的驱动因子**，并建立**供应商报价与市场基准的对照机制**。下面给一套可直接落地的判断框架。

## 一、先建立“基准价”而不是凭感觉

采购方每天收到报价后，至少要有三个参照：

1. **产地/批发市场行情价**：如当地大型批发市场、农业农村部信息中心、商务部市场监测、产区代办报价等（选你能稳定获取的2-3个来源，固定口径）。
2. **历史同期价**：过去2-3年同月份、同品种的价格区间，水果季节性极强，拿淡季和旺季比没有意义。
3. **自身成交价**：同规格、同产地、同等级的自己近30天成交价，作为供应商横向对比的锚。

关键点：**比较口径必须一致**——品种、规格（大小/等级）、产地、包装、是否含运费、结算方式（现结/账期）。口径不一致，任何波动判断都会失真。

## 二、把波动归因，看是否“讲得通”

每天报价变化，通常来自以下几类因素。能对应上的，倾向合理；对应不上的，要追问：

| 驱动因素 | 合理波动的表现 | 需要警惕的信号 |
|---|---|---|
| 季节/产期 | 换季、集中上市期价格下行 | 淡季反而莫名大涨 |
| 天气/灾害 | 产区降温、降雨、霜冻后短期上行 | 无天气事件却连续上涨 |
| 供需 | 节假日备货、学校开学、行情走强 | 需求平稳却连续跳涨 |
| 物流/燃油 | 运费、油价、限行导致成本变化 | 运费没变却称“物流涨” |
| 品质/等级 | 等级提升、损耗率变化 | 规格不变却按高档报价 |
| 汇率/进口 | 进口果受汇率、船期影响 | 国产果拿进口逻辑解释 |

## 三、设置“波动阈值+触发复核”规则

不要每天纠结，而是设规则：

- 单日涨跌 **≤5%**：视为正常噪声，记录不干预。
- 单日 **5%-10%**：要求供应商说明原因，并提供当日市场行情截图/产区信息。
- 单日 **>10%** 或**连续3天同方向累计>15%**：启动复核——对比2个以上市场基准，必要时询第二家供应商。
- 价格与市场基准**偏离超过10%-15%**（按品类设定）：要求重新议价或解释。

阈值要按品类定：叶菜、浆果类波动天然大，可放宽；苹果、柑橘等耐储果波动应更小。

## 四、用“成本结构”反推合理性

要求供应商对主要单品提供**成本构成**（产地收购价、包装、损耗、运费、人工、合理利润）。当报价变化时，看变化是否落在某个成本项上。例如产地价涨0.3元/斤，成品报价涨0.5元/斤，若损耗和运费没变，就要问多出的0.2元是什么。

## 五、机制上做三件事，长期降低被“波动”牵制

1. **多源比价**：每个核心单品保持2-3家合格供应商，日报价横向对比，偏离者自然暴露。
2. **锁价与浮动结合**：对耐储果签短期锁价或“基准价+浮动公式”（挂钩公开行情指数），把随意调价变成公式调价。
3. **留痕与复盘**：每日报价、行情、成交价存档，月底复盘“报价 vs 市场”偏离度，偏离大的供应商纳入考核。

## 六、一句话判断标准

**报价变化能对应到公开行情、天气/供需事件、成本项变化，且幅度在品类历史波动区间内，就是合理波动；解释不了、基准对不上、连续单边跳涨、或规格暗降的，就不是合理波动，要复核。**
