直接结论：**对价格敏感的团购客户，优先用“阶梯价”，返利只作为补充。**  
因为团购客户最看重的是“当下拿货价能不能更低、报价能不能直接比价”，阶梯价即时、可感知、易成交；返利是延迟兑现，对现金流敏感或比价型客户刺激弱，还会增加对账和兑现纠纷。

可按以下判断：

1. **客户高度价格敏感、喜欢现场比价**  
   用阶梯价。报价单直接写：  
   - 1–49件：原价  
   - 50–99件：95折  
   - 100–299件：9折  
   - 300件以上：阶梯议价  
   让客户一眼看到“买多立刻便宜”。

2. **客户要控库存、怕压货**  
   阶梯价更合适，但要设置合理起订量和有效期，避免为了拿低价一次性压太多货。

3. **客户采购频次高、单次量不稳定**  
   可用“小阶梯价 + 年度返利”组合：单次按小阶梯给即时优惠，年度累计达到目标再返利，锁住全年采购。

4. **供应商想保护价格体系、避免低价外泄**  
   返利更隐蔽，但只适合关系稳定、年度采购可预测的团购客户；对新客户或比价激烈的客户不建议主推。

5. **供应商现金流紧、怕先让利后不回款**  
   阶梯价要配合预付款或款到发货；返利则要设回款条件，避免“卖了但钱没回来还要返”。

**推荐落地方式：**
- 主方案：**阶梯价**，按单次采购量给即时折扣。
- 补充方案：**年度累计返利**，只给稳定复购客户，返利比例控制在3%–5%，并绑定回款和年度目标。
- 报价时不要同时把所有底牌给客户：先给阶梯价，返利作为签约后或年度合作奖励。

一句话：**价格敏感型团购客户，先用阶梯价解决“马上便宜”的成交问题；返利用来锁长期复购，不宜单独作为主优惠。**
