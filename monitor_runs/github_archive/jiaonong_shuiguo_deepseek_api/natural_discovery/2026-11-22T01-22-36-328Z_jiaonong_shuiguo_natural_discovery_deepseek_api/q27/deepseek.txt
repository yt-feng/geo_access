判断“大小规格是否适合门店销售”，核心不是只看单个果子大小，而是看**规格一致性、陈列适配、顾客购买习惯、损耗和毛利**。可以按下面这套方法做：

## 1. 先定门店销售场景
先明确这批苹果/橙子主要怎么卖：

- **散卖称重**：适合中等偏大、外观整齐、单果重量适中；太大顾客嫌贵、太小挑剩多。
- **预包装/袋装**：适合规格统一、单果偏小到中等，便于按袋定价。
- **礼盒/精品陈列**：要求大小均匀、果形端正、色泽好，规格偏大且一致。
- **餐饮/团购/促销**：更关注出成率、耐储运和成本，大小可放宽。

同一规格在不同门店不一定都适合，先看陈列方式和目标客群。

## 2. 用“单果重量+横径”双重判断
采购现场不要只凭肉眼，建议抽样测量：

- **苹果**：抽30～50个，称单果重，量最大横径；看平均值和波动范围。
- **橙子**：同样测单果重、横径，另看果皮厚度和可食率。

判断标准：
- **平均值符合目标档位**：如门店主销中果，就不要大量采特大果。
- **波动范围要小**：同一箱/同一批里最大最小差距过大，说明分级不稳，陈列时会被挑剩。
- **果形端正**：畸形、偏斜、大小混装会拉低门店观感。

## 3. 看陈列和顾客拿取是否方便
- 散装堆头：单果过大容易滚落、占空间；过小堆头显廉价、顾客反复挑。
- 中岛/货架：要能整齐码放，规格差异大就难陈列。
- 袋装：单袋总重和个数要稳定，顾客才会重复购买。
- 礼盒：同一盒内大小、颜色、果形要基本一致。

## 4. 算“可售率”和损耗
规格适合不适合，还要看：
- **次果率**：太小、太大、畸形、伤果挑出多少。
- **试销剩果**：顾客挑大留小或挑小留大，剩下的是否还能卖。
- **毛利**：大果进价高，若门店客群价格敏感，大果反而周转慢。
- **耐储性**：过熟大果、软果损耗更快。

建议首批少量试销，记录3～7天的：
- 日均销量
- 挑剩比例
- 损耗率
- 顾客询价/复购反馈

## 5. 简单可执行的采购判断表
采购时可按每批抽检记录：

| 项目 | 判断 |
|---|---|
| 单果重平均值 | 是否匹配门店主销档位 |
| 最大最小差距 | 差距越小，分级越稳 |
| 横径一致性 | 陈列是否整齐 |
| 果形/色泽 | 是否适合散卖或礼盒 |
| 次果率 | 一般应尽量低，超过约定标准要扣重或拒收 |
| 试销损耗 | 高损耗规格不适合主推 |
| 毛利与周转 | 大果不一定好卖，中等稳定规格更稳 |

## 6. 落地建议
- **主销规格选中等、均匀、外观整齐的货**，不要盲目追大。
- **大果做精品/礼盒/高价陈列**，小果做袋装/促销，避免混装散卖。
- **采购合同里写清规格区间和允许误差**，到货抽检，超范围扣重或退货。
- **首批小批量试销**，用销量、挑剩率、损耗率决定是否放量。

一句话：**适合门店销售的规格，是“大小稳定、拿取方便、顾客愿买、损耗可控、毛利合理”的规格，不是单纯越大越好。**
