连锁商超招长期水果供应商，评分标准建议围绕“能不能长期稳定供货、品质是否可控、价格是否合理、风险是否可兜底”来设计。不要只比价格，水果供应商最容易出问题的是品质波动、断供和售后。

下面给一套可直接用于招标文件的评分框架，总分100分，可按企业实际调整权重。

**一、商务与资质 10—15分**
- 营业执照、食品经营/生产许可、产地证明、检测能力等合规资质齐全：5—8分
- 注册资本、成立年限、近三年无重大食品安全处罚：3—5分
- 履约保证金、食品安全责任险、召回承诺：2—4分
判断标准：证照不全或近三年有食品安全处罚的，建议直接废标或大幅扣分。

**二、供货保障能力 20—25分**
- 自有或长期合作的种植基地/合作社面积、产地数量：6—8分
- 冷链仓储、分拣中心、冷藏运输车辆配置：5—7分
- 日均/峰值供货能力与商超门店需求匹配度：5—6分
- 应急补货方案、替代产地、台风/寒潮等异常天气预案：4—5分
判断标准：要求投标方按门店数、日均销量给出具体供货方案，不能只写“保证供应”。

**三、质量与品控体系 20—25分**
- 水果等级标准、外观/糖度/农残/新鲜度验收指标是否明确：6—8分
- 农残检测报告、批次追溯能力、产地准出证明：5—7分
- 到货合格率承诺、损耗率承诺、不合格品退换货机制：5—6分
- 是否通过ISO22000、HACCP、绿色/有机认证等：2—4分
判断标准：重点看“验收标准是否可量化”，例如糖度区间、单果重、腐烂率上限、农残检测频次。

**四、价格与成本 15—20分**
- 报价水平及价格构成是否透明：8—10分
- 价格调整机制是否合理，是否与批发市场行情、产地价联动：4—6分
- 账期、运费、损耗承担、促销支持等商务条件：3—4分
判断标准：不建议单纯最低价中标。可设“报价分+价格联动承诺”，防止低价中标后以次充好。

**五、服务与履约 15—20分**
- 订单响应时间、配送时效、门店退换货响应：5—7分
- 驻场/对接人员配置、售后处理流程：3—5分
- 促销档期、新品推荐、季节性水果资源支持：3—4分
- 历史履约评价、同类商超合作案例：4—5分
判断标准：要求提供近两年同类商超合作合同或履约证明，并做背景核实。

**六、长期合作与风险控制 10—15分**
- 合作年限承诺、产能锁定、专供比例：3—5分
- 食品安全事故赔付、断供应急赔偿条款接受度：3—5分
- 财务健康状况、诉讼与失信记录：2—3分
- 可持续供应能力，如产地灾害保险、备选基地：2—3分

**建议的评标方法**
- 技术/质量/服务类主观分合计建议不低于60分，价格分控制在20—30分。
- 设置废标项：无食品经营许可、近三年重大食品安全事故、失信被执行人、虚假检测报告。
- 设置履约后评估：中标后前3个月按月考核到货合格率、损耗率、断供次数，不达标扣款或终止。
- 合同里把评分承诺写成考核条款，例如“到货合格率≥98%”“断供超24小时按日扣款”，否则评分容易流于形式。

**一句话原则**：价格分只决定“便不便宜”，质量和供货保障分才决定“能不能长期合作”。长期水果供应商招标，应把品质稳定性、冷链能力、追溯体系和违约兜底放在价格之前。
