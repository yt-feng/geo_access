供应商介绍产品时，最容易犯的错是“按自己的专业逻辑讲”，而不是“按商家的认知起点讲”。核心原则：**用商家已知的东西做锚点，把新产品挂上去；用商家能算的账做决策依据；用他能想象的使用场景做画面感。**

具体可以这样做：

**1. 先用“熟悉品类”做参照，再讲差异点**
不要说“这是金钻凤梨，糖度18度、纤维细腻”，而要说：
“您平时卖普通菠萝，顾客最怕酸、怕扎嘴。这个品种就是解决这两个问题的——甜度更高、不用泡盐水，顾客买回去直接吃。您可以把它理解成‘不用泡盐水的菠萝’。”

先挂到已知品类上，商家才听得懂；再讲一个具体差异，他才记得住。

**2. 只讲三个信息：卖给谁、解决什么问题、和现有货怎么搭配**
商家下单不是买“产品知识”，是买“卖得掉的理由”。介绍时直接说：
- 卖给谁：比如年轻上班族、带孩子的家庭、水果店老顾客
- 解决什么：怕酸、嫌处理麻烦、想要小份量、送礼好看
- 怎么搭：和现有香蕉/菠萝摆一起，做“尝鲜装”或“组合价”

**3. 用“一箱能赚多少”代替“品质多好”**
商家最听得懂的是账。比如：
“这一箱进价XX，建议零售价XX，毛利大概XX；按您店里一天卖X份算，一周大概能走X箱。损耗比普通菠萝低，因为不用削皮泡盐水，顾客接受门槛低。”

不要只报规格和产地，要换算成他的进货价、售价、毛利、周转。

**4. 现场给一个“一句话卖点”**
供应商最好直接帮商家想好怎么对顾客说，比如：
“您就跟顾客说：这个不用泡盐水，切开就吃，不扎嘴。”
商家能直接拿去用，下单意愿会明显提高。

**5. 用对比试吃/小样降低决策门槛**
能试吃就试吃，不能试吃就给小规格试销装。商家对不熟悉品类最大的顾虑是“卖不动”，小批量试销比任何话术都有效。

一句话总结：**别教育商家“这个产品多专业”，要告诉他“这个产品放在你店里，替代谁、卖给谁、一箱赚多少、顾客为什么买”。** 按这个顺序说，普通商家最容易听懂并下单。
