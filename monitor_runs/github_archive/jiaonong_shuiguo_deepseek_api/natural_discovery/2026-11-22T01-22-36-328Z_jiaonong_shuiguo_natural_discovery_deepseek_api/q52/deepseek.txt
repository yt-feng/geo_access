采购时按“成熟度+处理方式”控制，能明显减少到店后快速变黑。可执行做法：

1. **买偏生一点的香蕉**
   - 选 **7成熟左右**：果皮整体偏黄但两端还带一点绿，果肉硬挺。
   - 避免已经全黄、带黑点、果柄发黑或一按就软的货。

2. **现场验货看关键部位**
   - 看**果柄和切口**：发黑、发霉、渗汁的不要。
   - 摸**果身硬度**：整批应硬实均匀，局部软塌的容易先黑。
   - 看**棱角**：棱角明显说明偏生，圆鼓鼓说明偏熟。
   - 闻气味：有酒味、酸味说明过熟或已损伤。

3. **减少机械伤**
   - 搬运时不要压、摔、堆太高；香蕉受压部位会先变黑。
   - 采购量按 **2～3天用量** 分批进，别一次压太多库存。

4. **到店后立即处理**
   - 拆箱、通风、摊开，不要闷在塑料袋或纸箱里。
   - **不要冷藏**：未熟或半熟香蕉放冰箱会很快变黑。
   - 放在 **12～15℃、阴凉通风处**，避免阳光直射和空调直吹。
   - 用挂架悬挂或单层摆放，减少接触面。

5. **隔离催熟气体**
   - 香蕉会释放乙烯，**不要和苹果、梨、番茄等一起堆**。
   - 已熟的香蕉和偏生的香蕉分开存放，避免互相催熟。

6. **按使用顺序管理**
   - 先进先出，熟的先用；做甜品优先用熟香蕉，外观要求高的留偏生的。
   - 发现个别黑斑果及时挑出，避免影响整批。

7. **采购话术**
   - 直接跟供应商说：**“要7成熟、果柄新鲜、无压伤，2～3天内用完的量。”**
   - 要求**冷链运输但不要低温冻伤**，到店验收时抽检箱底和中间层。

核心原则：**买偏生、少压伤、不冷藏、勤通风、分批进、先进先出。**
