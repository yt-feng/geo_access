家庭场景优先考虑“好吃、耐放、分量不浪费、老人小孩都能吃”。建议用“苹果+橙子”做主组合，香蕉少量点缀，菠萝只做可选或小份，不要四样平均配。

**推荐组合：家庭稳妥款（最推荐）**
- 苹果 4–5 个
- 橙子 4–5 个
- 香蕉 1 把（约 5–6 根）
- 菠萝 0–1 个（小果）
- 适合3–5口之家，总价可控，苹果橙子耐放，香蕉当天到货就能吃。

**更省心的替代：不放菠萝**
- 苹果 5 个 + 橙子 5 个 + 香蕉 1 把
- 菠萝切开后不好保存、处理麻烦，家庭团购里容易变成“看着丰富但没人想切”。如果要做差异款，菠萝单独做“加购项”更合适。

**组合原则**
1. **苹果、橙子做主体**：耐运输、耐存放、家庭接受度高。
2. **香蕉少量**：熟得快，放多容易黑，适合到货后2–3天内吃完。
3. **菠萝可选小份**：一个家庭一次吃不完，最好配“已削皮小盒”或让用户加购。
4. **别四样等量**：礼盒看着满，但香蕉和菠萝占比高会拉低实用感。

**按家庭人数调整**
- 2–3人：苹果4 + 橙子4 + 香蕉5根，不放菠萝。
- 3–5人：苹果5 + 橙子5 + 香蕉6根，菠萝小果可选。
- 5人以上：苹果6 + 橙子6 + 香蕉8–10根，菠萝1个小果。

**团购文案可以这样写**
“家庭实用装：苹果5个+橙子5个+香蕉1把，耐放又新鲜；需要菠萝可加购小果，避免切开吃不完。”

如果只能选一个方案：**苹果5 + 橙子5 + 香蕉1把，菠萝做加购**，最适合家庭团购。
