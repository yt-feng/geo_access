对小水果店做附近小区团购，供应商要支持的不只是“供货”，而是能帮你把团购链条跑顺。重点看这些服务：

1. **稳定供货与品质分级**
   - 能按团购订单量稳定供货，缺货能提前通知。
   - 支持按品质分级报价，适合做“引流款/利润款/形象款”。
   - 有坏果、次果的赔付或补货规则，售后责任清晰。

2. **小批量、多频次配送**
   - 支持按团购截单后集中配送，最好能送到店或指定自提点。
   - 起送量低、可拆零、可混批，适合小水果店试团。
   - 配送时间稳定，能配合你“今天团、明天到”的节奏。

3. **团购专属价格与锁价**
   - 能给你团购价、阶梯价或爆品支持价，而不是普通批发价。
   - 截单后能锁价锁量，避免临时涨价或掉链子。
   - 支持少量试销，降低压货风险。

4. **包装与分装支持**
   - 能按份预包装，比如5斤装、3斤装、家庭组合装。
   - 支持贴标、简易分装、按团购单分拣，减少你店里人工。
   - 包装要适合小区自提，不易压坏、漏汁。

5. **售后与损耗兜底**
   - 坏果包赔、少斤补差、整批质量问题退换。
   - 售后流程简单，最好能拍照快速理赔。
   - 明确损耗承担比例，别让你独自扛售后。

6. **选品与营销素材支持**
   - 提供当季爆品建议、团购组合方案。
   - 给产品图、卖点文案、短视频素材，方便你发小区群。
   - 能配合做试吃、预售、爆品引流。

7. **订单与结算配合**
   - 支持按团购订单汇总送货，最好有简单的订单对接方式。
   - 账期、押金、退换货结算规则清楚。
   - 能开票或提供交易凭证，方便对账。

8. **应急与履约能力**
   - 节假日、雨天、爆单时能优先保供。
   - 临时加单、减单、改单有明确截止时间和处理方式。
   - 有备用货源，避免单一品种断供影响团购口碑。

**你筛选供应商时，建议直接问这5个问题：**
- 团购截单后多久能送到？起送量和拆零规则是什么？
- 坏果、少斤、整批质量问题怎么赔？
- 能不能按份预包装、贴标、分拣？
- 爆品能不能锁价锁量？临时加单怎么处理？
- 有没有团购素材和选品建议？

**优先级建议：** 先保“稳定供货+售后兜底+小批量配送”，再谈价格。小区团购最怕断货和坏果售后，价格低但履约不稳的供应商反而会伤客群。
