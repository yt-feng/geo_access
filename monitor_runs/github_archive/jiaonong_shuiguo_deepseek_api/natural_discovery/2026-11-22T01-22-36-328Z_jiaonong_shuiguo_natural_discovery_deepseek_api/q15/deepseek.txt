水果店遇到坏果，和供应商结算或赔付，核心是先看约定、再验货留证、按责任划分处理。正常可按下面做：

1. **先看采购合同/供货单约定**
   - 有明确质量条款、损耗率、赔付比例的，按约定执行。
   - 常见约定包括：到货验收不合格可拒收；已收货后发现坏果按比例扣款；生鲜允许一定自然损耗（如1%—3%，以双方约定为准）。
   - 没有书面约定的，按交易习惯和双方协商处理。

2. **到货时当场验收**
   - 重点查：腐烂、霉变、压伤、冻伤、裂果、异味、成熟度过高。
   - 分拣出坏果，拍照/录像，保留带时间、批次、筐号、面单的证据。
   - 让司机或送货人在送货单上签字注明“坏果数量/拒收数量”，这是后续扣款的关键凭证。

3. **区分责任再谈赔付**
   - **运输途中损坏**：由供应商承担或供应商向物流追偿，水果店可拒收或要求补货。
   - **产地/采摘质量问题**：供应商承担，按坏果数量退款、补货或折价。
   - **水果店储存不当**：一般由水果店自行承担，不宜转嫁给供应商。
   - **自然损耗**：按行业惯例或合同约定比例处理，超出部分再协商。

4. **结算方式**
   - **拒收**：坏果不入账，不结算。
   - **已收货**：按坏果数量从本批货款中直接扣减；或供应商补发同等数量；或双方协商折价。
   - **整批质量问题严重**：可要求退货退款，并保留因断货造成的合理损失协商空间。
   - 扣款前最好书面/微信确认：“本批共X箱，坏果X箱/X斤，按单价X元扣款X元”，避免月底对账扯皮。

5. **固定证据**
   - 到货照片、开箱视频、坏果称重记录、送货单签字、聊天记录、转账/结算单。
   - 坏果尽量保留到供应商确认后再处理，避免“货没了说不清”。

6. **协商不成**
   - 先按合同约定的争议方式处理；没有约定的，可向市场监管部门投诉或通过诉讼解决。
   - 金额不大时，优先用“后续订单扣回”或“下批补货”方式解决，维持供货关系。

实操建议：**每批到货先验后签，坏果当场分拣、拍照、称重、让送货人签字确认；结算时按确认数量直接扣款或补货。** 不要把坏果混在好果里长期存放后再找供应商，容易因责任不清被拒赔。
