优先选**稳定供应商**作为主渠道，本地批发作为补充。判断标准就三条：损耗可控、到货稳定、总成本可算。

**建议的选法**

1. **香蕉**：优先稳定供应商。香蕉周转快、损耗高，最怕到货不熟或过熟。选能按你要求的成熟度分档供货、允许少量退换、每周固定配送2—3次的供应商。本地批发只在周末或临时缺货时补。
2. **苹果**：可以本地批发为主、稳定供应商为辅。苹果耐储、损耗低，本地批发价格和新鲜度通常更有优势；但要固定1—2个靠谱档口，先小批量试货，确认规格、糖度和坏果率。
3. **不要只选一边**：主供应商占70%—80%，本地批发占20%—30%，既保稳定又有议价空间。

**决策前做3件事**

- 各找2—3家报价，统一按“到店价+损耗率+退换条件+配送频率”比较，不只比单价。
- 先试销2周：香蕉按每天销量进货，记录坏果率和断货次数；苹果按箱试货，记录坏果率和顾客反馈。
- 算清隐性成本：本地批发若需自己凌晨采购、运输、挑拣，人工和时间要计入；稳定供应商若起订量高、配送慢，也要扣分。

**直接判断**

- 你店人手少、没冷链、销量不稳定 → 稳定供应商为主。
- 你店有人凌晨采购、周边批发市场近、苹果销量大 → 苹果可本地批发为主。
- 香蕉一律不要依赖临时本地采购，断货和品质波动会直接伤客流。
