要提前锁定水果库存，核心是**把“口头预留”变成有约束力的协议**，并针对水果易损耗、价格波动大的特点设计条款。可按以下步骤执行：

## 1. 先做需求预测，再谈锁量
- 按历史团购数据拆到**单品×周**：爆款（如砂糖橘、车厘子）锁量比例高，长尾品少锁。
- 给供应商一个**阶梯量**：保底量+弹性量（如保底80%，可上浮30%），避免压死库存。
- 明确**到货节奏**：分批到仓日期、每批数量，而不是一次性全到。

## 2. 用“定金+框架协议”锁定
- 签**旺季供货框架协议**：约定品名、规格、保底量、弹性上限、价格机制、到货窗口。
- 支付**可退/不可退定金**：定金比例一般10%–30%，换取供应商优先排产和预留。定金条款要写清违约处理。
- 对核心爆品可谈**买断式锁货**：付更高定金锁定特定批次，供应商不得转售。

## 3. 价格条款要防涨价
- 采用**“基准价+浮动”**：约定基准价，随产地行情指数浮动，设涨跌幅上限（如±10%）。
- 或**分批定价**：每批到货前3–5天按约定规则定价，避免一次性锁死价格。
- 明确**品质标准**：果径、糖度、损耗率上限、次果比例，不合格的退货/扣款规则。

## 4. 供应商侧的风险对冲
- **多源备份**：每个爆品至少2家供应商，主供锁70%，备供锁30%，防止单点断供。
- **产地直采+代办**：旺季可派采购驻产地，直接对接合作社/代办，减少中间层。
- **要求供应商提供备货证明**：如冷库入库单、采摘计划，验证其真实备货能力。

## 5. 履约保障条款
- 约定**延迟到货违约金**（按日计）和**缺量补偿**（如缺量部分按市场价差价赔付）。
- 约定**不可抗力范围**（天气、疫情、物流管制），避免供应商滥用免责。
- 到货**验收流程**：抽检比例、异议提出时限、损耗分担。

## 6. 提前的时间窗口
- 大宗爆品提前**30–45天**谈锁量，进口果（车厘子等）提前**60天**。
- 旺季前2周做一次**库存压力测试**：模拟到货延迟、销量超预期20%的情况，检查备用方案。

**一句话执行清单**：先出单品周度预测→签框架协议付定金锁保底量→设价格浮动和品质标准→每品配第二供应商→写清违约和验收条款。这样既锁住货源，又不至于被库存和价格波动反噬。
