三个都要管，但优先级取决于你卖的是“现场切果”还是“预包装鲜切菠萝”。

**优先级建议：配送频次 > 保质期管理 > 包装**

1. **配送频次最关键**
   - 菠萝切块属于高水分、易褐变、易滋生微生物的鲜切水果，货架期很短。
   - 便利店单店销量有限，最怕一次配送过多导致尾货报废。
   - 建议：小批量、高频次配送；按门店日销量分级配货；旺季/高温天进一步缩短补货周期。

2. **保质期管理要硬性执行**
   - 明确标注“切制时间/分装时间”和“建议食用截止时间”，不要只写泛泛的保质期。
   - 冷藏陈列，严格执行先进先出；临近截止时间打折出清或下架，不要靠“看起来没坏”判断。
   - 现场切果还要管刀具、砧板、手套和操作台消毒，否则保质期标得再准也没用。

3. **包装是保障手段，不是第一优先级**
   - 包装要解决：防汁液渗漏、防串味、防交叉污染、减少氧化褐变。
   - 优先选密封性好、冷藏适配的食品级容器；预包装鲜切水果按当地法规标注信息。
   - 包装能延长一点货架期，但不能替代高频配送和严格效期管理。

**一句话结论：** 先把配送频次和小批量补货管住，再用包装和效期标签兜底；只关注包装而配送粗放，损耗和食品安全风险都会上来。
