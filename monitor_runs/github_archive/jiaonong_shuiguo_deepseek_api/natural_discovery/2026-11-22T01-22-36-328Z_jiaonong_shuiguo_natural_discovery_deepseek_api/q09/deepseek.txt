旺季谈水果供应，核心不是“能不能便宜”，而是先把断货风险、品质波动和临时补货责任问清楚。建议提前问以下问题，并尽量落到书面或微信确认：

**1. 旺季保供能力**
- 旺季每天/每周能稳定给我供多少货？最低保供量是多少？
- 我临时加单，提前多久通知能安排？加单上限是多少？
- 你上游是产地直采、批发市场还是调货？旺季会不会优先保大客户而减少我的量？
- 有没有备用货源或备用供应商？你断货时怎么补偿或协助调货？

**2. 品质与规格**
- 每批货的等级、规格、成熟度、产地、品种怎么约定？有没有样品标准？
- 坏果率、损耗率控制在多少？超出部分怎么退换或扣款？
- 旺季会不会出现以次充好、混级、催熟过度？验收标准以谁为准？
- 送货时能否提供产地、批次、采摘/到货时间？

**3. 价格与锁价**
- 旺季价格随行就市还是可以锁价？锁价周期多长？
- 涨价提前多久通知？已下的订单是否按原价执行？
- 是否有保底采购量换更优价格？达不到保底量怎么算？
- 运费、装卸费、包装费、损耗谁承担？

**4. 配送与时效**
- 每天几点前下单、几点送达？旺季会不会延迟？
- 送货频次能否按我的销售节奏调整？临时补货几小时能到？
- 缺货、延迟、少送时怎么通知？有没有违约或补偿机制？
- 节假日、雨天、交通管制时怎么保配送？

**5. 退换与售后**
- 到货验收不合格，多久内可退换？运费谁出？
- 坏果是整批退、按比例赔，还是下次补货抵扣？
- 售后响应时间多长？有没有固定对接人？
- 因品质问题导致顾客投诉或损耗，是否承担部分责任？

**6. 结算与风险**
- 结算周期是现结、周结还是月结？旺季是否要求预付？
- 是否需要押金、保证金？合作终止后怎么退？
- 遇到极端天气、产地减产、疫情/交通中断，双方怎么分担风险？
- 能否先小批量试供一周，再签旺季保供协议？

**7. 合同关键条款**
- 保供量、品质标准、价格机制、送达时限、退换规则、违约责任、临时加单流程，都要写进协议。
- 不要只口头承诺“放心，肯定有货”，要问：**断货时你具体怎么赔、多久补、从哪调？**

实操上，建议你先拿一个爆款单品做7—10天试供，记录到货准时率、坏果率、临时加单响应速度，再决定是否把旺季主力品类交给对方。
