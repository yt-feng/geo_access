连锁超市要把门店坏果率压下来，合同里不能只写“坏果赔付”，而要把**验收标准、责任分界、赔付计算、扣款/补货机制、举证与时效**写清楚。建议按下面结构约定：

1. **明确“坏果”定义和验收标准**
   - 在合同附件中按品类列明：腐烂、霉变、软烂、开裂、虫害、异味、机械伤、冻伤、失水萎蔫等是否计入坏果。
   - 约定验收抽检比例、抽检方法、合格判定阈值。例如：到店抽检按箱/件随机抽取，坏果率超过约定阈值即整批可拒收或按比例赔付。
   - 区分“外观瑕疵”和“实质性坏果”，避免门店把轻微瑕疵全部算坏果。

2. **划分责任节点**
   - 明确风险转移点：是供应商发货、配送中心验收、门店收货，还是上架前。
   - 约定运输温湿度、包装、堆码要求；因供应商包装或冷链不合规导致的坏果，由供应商承担。
   - 门店收货后因储存不当造成的坏果，不应由供应商承担。可约定门店须在收货后一定时间内完成验收并反馈。

3. **赔付计算方式要可执行**
   - 建议采用“坏果率阶梯赔付”，而不是只写固定比例。例如：
     - 坏果率≤3%：正常收货，不赔付；
     - 3%＜坏果率≤8%：按坏果重量/金额的1.5倍扣款或补货；
     - 8%＜坏果率≤15%：按2倍扣款，或整批退货并由供应商承担运费；
     - ＞15%：整批拒收，供应商承担退货、销毁及因此产生的合理费用。
   - 赔付基数建议写“按该批次含税采购金额”或“按坏果对应货值”，并明确是否含运费、损耗处理费。
   - 可设置月度累计坏果率考核：超过月度阈值，除单批赔付外，再按月度采购额的一定比例扣款或要求整改。

4. **补货、退货和费用承担**
   - 约定补货时限，例如门店反馈后24/48小时内补货到位。
   - 明确退货、销毁、冷链运输、二次配送费用由责任方承担。
   - 对易腐商品，约定门店可先行处理坏果并保留照片/视频，事后结算，避免因等待查勘导致损失扩大。

5. **举证和时效**
   - 约定门店发现坏果后，在规定时间内通过系统/照片/视频报备，供应商可在约定时间内复核；逾期未提异议视为认可。
   - 明确抽检记录、收货单、照片、冷链记录作为赔付依据。
   - 对隐蔽性坏果，可约定收货后24小时内开箱发现仍可索赔，但需保留原包装和批次信息。

6. **质量保证金与扣款**
   - 可约定月结时直接从货款中扣除赔付款，或设置质量保证金。
   - 扣款需有书面/系统确认单，避免单方随意扣款引发争议。
   - 连续多批次坏果率超标，可约定暂停供货、整改、降低采购份额或解除合同。

7. **避免只写“按实际损失赔偿”**
   - 这种条款难执行。要写清计算公式、触发阈值、举证材料、处理时限和争议解决方式。
   - 同时约定供应商对因坏果引发的食品安全、顾客投诉、监管处罚承担相应责任，但应与门店储存责任区分。

实操上，建议把“坏果率标准表、抽检规则、赔付阶梯、报备时限”做成合同附件，按品类分别设置阈值。这样门店可执行、供应商可预期，也便于月度考核。
