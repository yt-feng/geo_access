旺季临时补货，核心是把「临时」变成有约束的约定，避免口说无凭。建议按下面几步做：

**1. 先算清需求量再谈**
- 按最近7天实际用量×旺季系数（比如1.3–1.5）估出每周缺口，给出一个「保底量+弹性上限」区间，而不是笼统说“会多用”。
- 明确规格：品种（如金钻/台农）、单果重量区间、成熟度（几成黄）、去皮/带皮、切块规格、农残要求。规格不清是补货纠纷第一大来源。

**2. 约定补货机制（写进补充协议）**
- **触发方式**：提前N天（菠萝建议2–3天）书面/微信下单，注明到货日期和数量。
- **响应时限**：供应商在几小时内确认接单，逾期视为未接单，你可另行采购且不违约。
- **弹性区间**：在保底量基础上，你可在±20%内临时增减，供应商不得拒接；超出部分协商。
- **价格**：锁一个旺季基准价+浮动上限（如按批发市场均价上下浮动不超过X%），或约定“临时补货价不高于当期市场均价”。避免旺季坐地起价。

**3. 约定到货与验收**
- 到货时间窗（如上午10点前到店），迟到超过X小时可拒收或折价。
- 验收标准写具体：坏果率≤5%、单果重量达标、成熟度符合；不合格部分当场拍照记录，可退换或扣款。
- 保留每批次的称重单和验收记录，作为对账依据。

**4. 约定违约与备选**
- 供应商断供的违约责任：按缺口量货款的X%赔偿，或承担你临时高价采购的差价。
- 你自己也要有备用供应商（至少1家），并在协议里写明“不可抗力/断供时双方免责但需提前告知”。

**5. 落地形式**
- 原合同有采购条款的，签一份《旺季临时补货补充协议》，把上面量、价、时限、验收、违约写清楚，双方盖章或微信书面确认。
- 每次下单用固定模板（品名/规格/数量/到货时间/单价），聊天记录留存。

一句话：**把“临时”拆成可量化的量、价、时限、验收、违约五件事，用补充协议固定下来，再留一个备选供应商兜底。**
