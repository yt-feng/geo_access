节假日水果需求暴增，靠临时找货通常来不及，价格也会被抬高。建议按“提前锁量、锁价、锁品质、锁运力”四条线并行安排。

**1. 提前做需求预测，而不是拍脑袋备货**
- 按门店拆分：用去年同节假日前2–3周的同品类销量，叠加今年客流、天气、促销计划做系数修正。
- 按品类分级：苹果、梨、橙等耐储品可提前7–15天备货；草莓、樱桃、榴莲、礼盒果等易损或节庆属性强的品类，按到货节奏分批锁。
- 设置安全库存和断货红线：例如重点门店礼盒果安全库存不低于3天销量，鲜果不低于1.5–2天销量。

**2. 产地和供应商双线锁货**
- 对主销大单品，提前与产地合作社、一级批发商签“框架协议+分批订单”，明确节前各批次到货日期、数量、规格、验收标准和违约条款。
- 不要只锁一家：每个核心品类至少2–3个备选供应商，主供锁60%–70%，备供锁20%–30%，留10%左右机动补货。
- 对节庆礼盒，提前锁定包装材料和组装产能，避免“有果无盒”。

**3. 价格和付款条件提前谈死**
- 优先谈“锁量锁价+浮动上限”，避免节前被临时加价；对易波动的进口果、反季果，可采用“基础价+市场联动上限”条款。
- 用预付款或定金换优先供货权，但比例要控制，并约定未按约到货的赔付。
- 对耐储品类可在价格低位时适度前置采购，但必须算清损耗和仓储成本。

**4. 物流和仓储提前排期**
- 节前2–3周锁定冷链车、装卸工和仓容，特别是易损水果的冷链运力。
- 对到货节奏做“错峰”：耐储品先到，鲜品集中节前3–5天到，避免门店仓爆仓和损耗。
- 设定到货验收标准：糖度、果径、成熟度、破损率写进订单，不合格拒收或折价。

**5. 门店端做分流和限购预案**
- 节前对爆款水果设置门店配额，按历史销量和客流分配，避免个别门店囤货。
- 对礼盒和整箱果设置预售或团购锁单，用订单量反推采购量。
- 准备替代品类：当某单品缺货时，用同价位、同用途水果做陈列替代，减少断货影响。

**6. 建立每日盯盘机制**
- 节前10天起每天更新：在途量、库存量、日销量、供应商履约率。
- 触发补货的条件写清楚，例如某单品库存低于2天销量且供应商到货延迟超过24小时，立即启动备选供应商。

执行上，最优先做三件事：**用去年数据算出各品类节前备货量；对前5大单品各签2家以上供应商并锁量锁价；提前锁定冷链运力和节前到货排期。** 这样比节前临时抢货更稳，也更能控住毛利。
