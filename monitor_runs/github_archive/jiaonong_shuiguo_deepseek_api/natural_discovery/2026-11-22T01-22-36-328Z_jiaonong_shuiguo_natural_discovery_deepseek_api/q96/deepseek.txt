最需要关注的是食品安全，但三者不是同一层级：食品安全是底线，价格和配送准时是约束条件。

可以这样判断和执行：

1. **食品安全优先，属于一票否决**
   - 水果直接入口，企业食堂一旦出现农残超标、霉变、致病菌污染，后果远高于采购成本和配送延误。
   - 必须关注：供应商资质、进货查验、农残检测或承诺、冷链/储存条件、霉变和破损率、追溯和退换货机制。
   - 不能为了低价或准时，接受来源不清、检测缺失、明显不新鲜的水果。

2. **价格重要，但不能突破食品安全**
   - 价格影响食堂成本和员工满意度，应通过比价、集中采购、季节性采购来控制。
   - 判断标准是“同等食品安全水平下比价”，不是单纯选最低价。
   - 明显低于市场价的水果要警惕来源、品质和成熟度问题。

3. **配送准时是运营保障，但通常可通过管理降低风险**
   - 水果配送延误会影响供餐，尤其早餐和加餐；但可通过安全库存、备用供应商、调整配送频次来缓解。
   - 准时性差是服务问题，食品安全差是安全风险，优先级不同。

**结论：**
企业食堂采购水果应坚持“**食品安全一票否决，价格在合格供应商中比较，配送准时通过合同考核和备份机制保障**”。如果必须排顺序：**食品安全 > 配送准时/价格**；价格和准时之间，则根据食堂供餐刚性、水果品类和库存能力权衡，但都不能牺牲食品安全。
