提前向供应商要的资料，核心是“证明这批水果来源可追溯、检测合规、责任可约定”。建议分四类要：

1. **主体与资质资料**
- 供应商营业执照、食品经营许可证/食品生产许可证（如适用）
- 供货商与上游基地/合作社/批发市场的采购合同或授权供货证明
- 若为进口水果：海关入境货物检验检疫证明、报关单

2. **批次追溯资料**
- 每批次的产地证明或基地信息（产地、果园/合作社名称、采收日期）
- 批次号/采收批次记录、运输和入库记录
- 承诺“一批一证/一批一记录”，避免只给年度资料

3. **农残检测资料**
- 该批次或近期批次的农药残留检测报告，优先要求有CMA/CNAS资质的第三方检测报告
- 报告要能对应品种、产地、批次/采样日期；注意报告日期与到货批次是否匹配
- 供应商自检报告可以作为补充，但不能替代第三方抽检或入市查验要求
- 可要求供应商提供承诺书：如抽检不合格，承担退货、销毁、罚款及由此产生的损失

4. **合同与应急约定**
- 采购合同里写明农残限量标准、抽检不合格处理、退换货和赔偿条款
- 要求供应商提前报备农药使用和安全间隔期情况（尤其高风险品种）
- 约定超市有权自行送检，不合格检测费由供应商承担

实操建议：不要只收“一张年度检测报告”，要按批次索要“产地/批次信息+对应检测报告+承诺书”。对高风险或新供应商，可先小批量采购并自行送第三方快检/定量检测，合格后再放量。
