判断哪个规格更容易出货，核心不是看“你手上哪个最多”，而是看**下游客户结构 + 单位价格带 + 损耗速度**。可以直接按下面几步做判断和验证。

### 1. 先按真实出货对象分规格
菠萝批发常见规格大致按单果重量分，例如：
- 小果：约 1–1.5 斤/个
- 中果：约 1.5–2.5 斤/个
- 大果：约 2.5–3.5 斤/个
- 特大果：3.5 斤以上

不同客户偏好不同：
- **水果摊/社区店**：更偏中果，单价低、好卖、家庭一次吃完。
- **餐饮/果汁店/甜品店**：更偏大果，出肉率高、加工效率高。
- **商超/礼盒**：更看外观和均匀度，规格要整齐。
- **批发市场二批**：看价格差和走量速度，常选性价比规格。

所以先列出你前 10–20 个客户分别拿什么规格，不要凭感觉。

### 2. 用“出货速度 + 毛利 + 损耗”三项判断
对每个规格连续记录 3–7 天：
- **日均出货箱数/件数**
- **从到货到卖完的天数**
- **损耗率**：烂果、黑心、压伤、失水
- **每件毛利**：售价 − 进价 − 损耗 − 搬运/场地分摊

判断优先级：
1. **周转天数最短**的规格通常最容易出货；
2. 如果两个规格周转接近，看**损耗后毛利**；
3. 不要只看单价高，大果如果压货久、损耗高，实际不一定更好卖。

### 3. 做小批量对比测试
最直接的办法：
- 同一批到货里，把各规格各留一小批，比如各 5–10 件；
- 同一天投放到相同渠道；
- 记录 24 小时、48 小时、72 小时出货比例；
- 连续做 2–3 批，看哪个规格稳定最快清掉。

如果某个规格 48 小时内出掉 70% 以上，且损耗低于其他规格，基本可以判断它更容易出货。

### 4. 看价格带是否匹配下游
问客户一句最有效：  
“你那边最好卖的是几斤一个的？什么价位走得快？”

如果中果在你的渠道里零售价刚好落在主流接受区间，通常比大果更稳。大果容易受餐饮客户波动影响，小果则容易因出肉率低被压价。

### 5. 快速判断结论
你可以用一个简单公式排序：

**出货优先指数 = 日均出货量 ÷ 平均周转天数 ×（1 − 损耗率）**

指数最高的规格，就是当前最容易出货的规格。  
同时再看毛利，选出“既好出又赚钱”的主推规格。

### 实操建议
先别大规模压单一规格。建议：
- **主推 1 个周转最快的规格**，保证现金流；
- **搭配 1 个毛利更高的规格**，供餐饮或特定客户；
- 每 3 天复盘一次客户拿货结构，按实际出货调整，不要按产地或经验拍脑袋。
