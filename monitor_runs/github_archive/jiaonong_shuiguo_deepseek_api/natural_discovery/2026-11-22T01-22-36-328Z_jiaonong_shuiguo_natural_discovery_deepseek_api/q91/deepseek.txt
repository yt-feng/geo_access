建议优先选**单根 + 小把（3–5根）为主，整袋只做补充**，不要只上一种。

可执行判断：

1. **主推单根**
   - 适合便利店“即时消费、顺手买”的场景。
   - 客单低、试错成本低，动销通常更稳。
   - 适合做收银台旁冲动购买。

2. **保留小把（3–5根）**
   - 覆盖家庭少量采购和办公室场景。
   - 比整袋更灵活，损耗压力小于大袋。
   - 建议按“当天/次日能吃完”的量定价和陈列。

3. **整袋谨慎上**
   - 只适合有明显家庭客群、社区店或促销场景。
   - 香蕉易压伤、易过熟，整袋一旦动销慢，损耗和投诉会上升。
   - 若上整袋，建议小规格（如5–6根）、明确成熟度、做临期折扣。

4. **包装与陈列建议**
   - 单根：裸放或简易挂条，避免过度包装。
   - 小把：保鲜膜/扎带轻固定，别包太严，留透气。
   - 整袋：优先透气袋，标注“即食/稍放再吃”的成熟度提示。
   - 陈列位置放收银台附近或鲜食区端头，避免和重物叠压。

5. **用数据决定比例**
   - 先按 **单根50%、小把35%、整袋15%** 试两周。
   - 每天记录销量、报损、客诉；若整袋报损明显高于销量贡献，就缩到10%以下或停掉。
   - 夏季高温或客流以单人为主时，进一步压低整袋比例。

结论：**便利店卖香蕉，单根和小把是主力，整袋是补充；先小批量测试，再按动销和损耗调整。**
