酒店采购水果盘原料时，建议把“规格外观标准”写进采购单或验收标准，至少覆盖以下几类：

1. **品种与等级**
   - 明确品种、产地范围、等级（如一级/特级/餐饮专用级），不接受混级、落地果、尾果。
   - 同一批次品种、成熟度、大小尽量一致，便于摆盘统一。

2. **单果规格**
   - 按品种约定单果重量/直径/长度范围，例如苹果、橙子按直径或单果克重；草莓按单果克重和果径；葡萄按串重和果粒大小。
   - 约定允许偏差，如单果规格合格率≥95%，同批次大小差异不超过约定范围。
   - 果盘用原料通常要求中小果型、匀称，避免过大或畸形影响切配和摆盘。

3. **成熟度**
   - 到货成熟度适合酒店当日或短期使用：可即食或1—2天内达到最佳食用状态。
   - 不过生、不过熟；香蕉、芒果、牛油果等呼吸跃变型水果要约定到货成熟阶段。
   - 切开后易褐变、易软烂的品种，应要求成熟度稳定。

4. **外观标准**
   - 果形端正、匀称，无明显畸形、偏斜、双果、裂果。
   - 果面清洁，无泥土、药斑、虫粪、汁液污染。
   - 色泽正常，具有品种应有色泽，无大面积青斑、日灼、冻伤、烫伤。
   - 无腐烂、霉变、发酵、异味、渗液、软塌。
   - 无可见虫害、虫孔、虫卵、活虫；无病斑、黑心、褐变。
   - 允许轻微自然瑕疵，但不得影响切配出成率和摆盘观感；可约定“外观不合格率≤5%”等容忍度。

5. **新鲜度与质地**
   - 叶片类/带梗类要求切口新鲜、不萎蔫；浆果类要求果粉完整、无渗汁；柑橘类要求果皮紧实、无干瘪。
   - 不得有冷害、冻伤、机械伤、压伤、磕碰伤。
   - 切开后应达到约定出成率，如去皮去核后可用率不低于某比例。

6. **安全与合规**
   - 农药残留符合国家食品安全标准，供应商提供批次检测报告或承诺书。
   - 不得使用违规保鲜剂、染色剂、催熟剂超范围使用；蜡处理品种应明确。
   - 预切水果原料应明确冷链温度、加工时间、包装标签和保质期。
   - 提供可追溯信息：批次、产地、采摘/加工日期、供应商资质。

7. **包装与运输**
   - 包装牢固、清洁、无污染，内衬符合食品接触要求；标明品名、规格、产地、批次、日期。
   - 运输温度按品种约定，冷链品种到货中心温度符合要求；不得与化学品、异味货物混装。
   - 到货不得有挤压、破损、受潮、日晒、冻伤。

8. **验收与退换**
   - 约定抽样比例和验收方法：按批次随机抽检，称重、量径、看外观、切开抽检。
   - 明确拒收条件：腐烂霉变、异味、虫害、严重机械伤、规格合格率不达标、农残报告缺失等。
   - 约定不合格品退换货时限和补货责任，避免影响早餐/宴会出品。

实操上，建议在采购合同附件中做一张“品种规格验收表”，每个水果列明：品种、等级、单果规格、成熟度、外观缺陷允许度、包装要求、到货温度、检测报告要求、抽样合格率。这样厨房和收货部都能按同一标准判断。
