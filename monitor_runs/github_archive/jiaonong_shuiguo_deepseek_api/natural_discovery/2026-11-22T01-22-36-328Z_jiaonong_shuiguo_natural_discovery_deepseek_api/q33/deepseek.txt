重要，而且不是“参考项”，是统一水果品质的前置条件。

多门店超市最大的问题不是单店卖不好，而是同一批水果在不同门店被不同人按不同感觉验收，最后出现：A店能收、B店拒收；今天能收、明天不能收；采购说一级果、门店看着像二级果。没有统一分级标准，品质管理会变成“人治”。

建议你重点看供应商分级标准是否具备这四点：

1. **可量化**
   不能只写“大果、色泽好、新鲜”。要有单果重量/横径、糖度、着色面积、瑕疵率、机械伤允许比例、成熟度区间、腐烂率上限等指标。

2. **可验收**
   标准要能落到收货台：抽检比例、抽样方法、判定规则、拒收或降级规则要明确。否则标准写得再漂亮，门店也没法执行。

3. **与你的销售分级一致**
   供应商的“一级/二级”要和超市货架等级、价格带、促销品定位对应。比如精品店和社区店可以共用验收底线，但分级用途要区分。

4. **批次稳定性**
   看供应商是否按批次出具分级结果，是否允许你复核，历史批次合格率是否稳定。多门店最怕的是标准有，但每批执行不一致。

可执行做法：

- 先选3—5个核心水果品类，建立自己的《收货分级卡》，不要一开始全品类铺开。
- 要求供应商按你的分级口径报价和交货，而不是你被动接受它的等级名称。
- 设定统一验收底线：腐烂率、机械伤、糖度下限、单果规格区间、成熟度。
- 对供应商分级标准做月度复核：到货合格率、降级率、门店投诉率、损耗率。
- 多门店用同一张验收表和同一套抽检规则，店长只有“按标准拒收/降级”的权力，不能凭感觉放宽。

结论：供应商分级标准很重要，但更重要的是把它转成你们超市自己的、可验收的、多门店一致执行的分级规则。供应商标准是基础，你的收货标准才是统一品质的抓手。
