这四种水果做礼盒，最容易卖的组合不是“放得越多越好”，而是按 **价格带 + 送礼场景 + 耐运输** 来搭。给你可直接落地的搭配方案：

## 一、主推3款，覆盖大多数顾客

### 1）日常探病/串门款：苹果 + 橙子 + 香蕉
- 配比参考：苹果4个 + 橙子4个 + 香蕉1把（约6–8根）
- 定位：**39–59元**亲民款，最好卖
- 优点：颜色亮、寓意好、成本低
- 注意：香蕉容易催熟其他水果，**香蕉单独套袋**，礼盒不要装太满

### 2）节日送礼款：苹果 + 橙子 + 菠萝
- 配比参考：苹果6个 + 橙子6个 + 菠萝1个（小果型）
- 定位：**69–99元**体面款
- 优点：菠萝有“旺来”寓意，整体耐放、卖相好
- 注意：菠萝刺手，必须削叶或套网套，礼盒内固定好

### 3）高性价比家庭款：苹果 + 香蕉 + 菠萝
- 配比参考：苹果6个 + 香蕉1把 + 菠萝1个
- 定位：**49–69元**
- 优点：分量感强，适合家庭自吃和送邻居
- 注意：香蕉成熟度选**微黄**，不要全熟，否则到顾客手里易黑

## 二、不建议主推的组合

- **四种全放**：容易显得杂、成本高、香蕉催熟其他水果，损耗大。可做少量“豪华款”但别当主力。
- **香蕉占比过高**：香蕉是礼盒里最容易坏、最拉低质感的单品，只做点缀。
- **菠萝放两个**：占空间、扎手、难固定，一个足够。

## 三、好卖的关键细节

1. **按价格带陈列**：39/59/79/99元各一档，顾客决策快。
2. **香蕉必须后熟管理**：进货选微黄，礼盒当天卖；夏天香蕉旁不要放苹果，苹果释放乙烯会催熟。
3. **苹果选大小均匀的**，橙子选颜色一致的，礼盒“整齐”比“多”更值钱。
4. **菠萝做小果**，整颗带叶好看但占空间，可提供“削好装盒”加价服务。
5. **加一张手写/印刷卡片**：探病写“早日康复”，节日写“平安橙意”，复购明显提升。
6. **成本控制**：礼盒毛利建议不低于35%，香蕉和菠萝按损耗率单独核算，别被低价款拖亏。

## 四、最推荐你先上的组合

**先上这三款试销：**
- 39–49元：苹果4 + 橙子4 + 香蕉1把（走量）
- 59–69元：苹果6 + 橙子6 + 菠萝1个（主推利润款）
- 79–99元：苹果8 + 橙子8 + 菠萝1个 + 香蕉少量点缀（节日款）

试销一周看动销：**哪款卖得最快就加量，香蕉损耗高的款及时调低香蕉比例**。
