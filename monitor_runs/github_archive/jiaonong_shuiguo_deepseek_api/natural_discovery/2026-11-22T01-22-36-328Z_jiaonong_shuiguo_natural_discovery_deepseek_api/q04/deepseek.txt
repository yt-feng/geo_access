可以按“到货成熟度 + 到货节奏 + 验收标准”三件事向供应商提要求，核心是让香蕉到店后还能卖2–4天，而不是到货即最佳食用期。

**1. 采购时明确熟度**
- 要求到货为**青黄交接、果指微硬**：表皮黄中带绿，绿尖明显，果肉按下去有弹性但不软。
- 不要“全黄、无绿尖、果指发软、表皮出现梅花点”的货，这种通常1–2天就过熟。
- 按季节调整：夏天要求更青一点，冬天可略黄一点；门店日均销量小，越要偏青采购。
- 分批要货：同一批里可要求“7成青黄 + 3成偏黄”，偏黄的先上货架，青的放后场催熟/周转。

**2. 明确到货时间**
- 要求**早上开市前到货**，避免下午高温时段到货；夏季尤其不要午后到货。
- 固定每周/每日到货频次，改成**小批量、多频次**，例如日销1箱就每次到半箱到1箱，隔天补。
- 要求供应商按“预计售卖天数”发货：到店后2–3天能卖完的量，不要一次压5–7天库存。
- 节假日或高温天提前沟通，避免供应商把库尾熟货压过来。

**3. 写进验收和合同要求**
- 验收抽箱：看箱内上下层熟度是否一致，防止“上层青、下层黄”。
- 明确拒收标准：果指软塌、大面积黑斑、果柄发黑腐烂、箱内有明显酒味/酸味、机械伤严重的拒收。
- 要求冷链或阴凉运输，夏季避免暴晒车厢；到货后门店立即拆箱通风，不要闷在纸箱里。
- 让供应商提供催熟批次和到货熟度说明，出现“到货即过熟”可退换或补差。

**给供应商的一句话版本：**
“香蕉要青黄交接、果指微硬、带绿尖的货，早上开市前送到；每次按我们2–3天销量小批量发，全黄发软、有梅花点、箱内上下熟度不一致的不要。夏季偏青发，冬季可略黄，到货过熟要能退换。”
