选择适合批量配送的水果供应商，核心看四件事：**稳定供货、配送履约、损耗控制、对账开票**。可按下面流程做，能直接落地判断。

**1. 先定采购标准**
- 明确人数、预算、配送频次（每周几次）、配送时间窗口（如下午2点前到）。
- 定品类结构：2–3种大众水果为主（香蕉、橘子、小番茄、苹果），1种时令水果做变化；避免易压伤、易氧化的水果做主力。
- 定验收标准：单果大小、成熟度、坏果率上限（建议≤3%–5%）、缺斤少两处理方式。

**2. 供应商类型选择**
优先顺序建议：
- **本地水果批发商/配送商**：适合批量、价格可控，要求有分拣和配送能力。
- **生鲜B2B平台**：履约稳定、开票方便，但价格略高，适合行政采购省事。
- **大型商超团购/企业采购渠道**：品质稳定，适合小批量高频。
- **产地直采**：不建议小批量下午茶采用，配送和售后成本高。

**3. 重点核验能力**
- 是否有**固定分拣场地和冷链/保鲜车辆**。
- 能否按公司地址**定时送达**，迟到如何处理。
- 是否支持**坏果包赔、补送或退款**，响应时限多久。
- 是否可提供**样品试吃**和首单小批量试配。
- 能否开**发票**、提供配送单和对账单。

**4. 用试单做判断**
先下1–2次小批量试单，观察：
- 到货时间是否准时；
- 重量是否足称；
- 坏果率是否在约定范围内；
- 分拣是否干净、包装是否适合办公室分发；
- 售后响应是否及时。

**5. 合同/订单里写清楚**
- 品类、规格、单价、数量；
- 配送时间、地点、联系人；
- 验收标准和坏果处理；
- 临时加单/减单的截止时间；
- 结算周期和开票信息。

**6. 建议的供应商组合**
不要只签一家。可选定**1家主供应商+1家备选供应商**，主供日常下午茶，备选应对临时加单或主供缺货。这样批量配送风险最低。

简单判断标准：**能稳定按时送、坏果少、足称、售后快、能开票**的供应商，就适合长期合作。
