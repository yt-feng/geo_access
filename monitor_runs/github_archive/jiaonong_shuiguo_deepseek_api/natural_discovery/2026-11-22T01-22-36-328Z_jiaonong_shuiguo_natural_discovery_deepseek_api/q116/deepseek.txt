小商家采购水果，现金结算和月结账期的风险可以这样判断：

**现金结算的主要风险**
1. **资金占用与周转压力**：现金当场流出，水果又是易腐、周转快的品类，一旦进货判断失误或销售不及预期，现金会被库存压住。
2. **无账期缓冲**：遇到退货、质量不合格、短斤少两时，已经付出去的钱更难追回，谈判主动权弱。
3. **凭证与税务风险**：现金交易容易只有收据甚至白条，后续出现质量纠纷、对账争议时举证难；若供应商不开票，进项抵扣和成本入账也可能不规范。
4. **安全与内控风险**：现金保管、交接、找零容易出错，也增加员工舞弊和丢失风险。
5. **价格未必最优**：现金看似能拿低价，但如果没有比价和验收机制，可能被“低价高损耗”抵消。

**月结账期的主要风险**
1. **信用依赖与断供风险**：账期建立在供应商信任上，一旦你回款慢、销量波动，供应商可能缩账期、停供或优先供货给现结客户。
2. **对账与纠纷风险**：水果损耗、退换货、价格随行就市，月结时容易出现“送货单价格”和“结算价格”不一致，对账不清会变成长期扯皮。
3. **隐性成本**：月结价格通常比现结略高，或者供应商把资金成本打进单价；看似缓解现金流，实际毛利被压缩。
4. **过度采购倾向**：账期会降低“付款痛感”，容易多进货，水果损耗上升，最后账期省下的现金被烂果吃掉。
5. **合同与法律风险**：如果没有书面账期、对账周期、逾期责任，容易从商业纠纷变成欠款诉讼；个人担保、联保也要谨慎。
6. **现金流错觉**：月结不是不付钱，只是延迟支付。若销售回款也慢，账期到期时可能集中付款，反而更紧张。

**实操建议**
- **现金结算**：坚持“验货后付款”，保留送货单、验收单、转账或收据；大额尽量走银行转账留痕；现结换低价要写进报价单。
- **月结账期**：签简单书面协议，明确账期天数、对账日、付款日、质量退换规则、逾期后果；每车验收签字，定期对账，不拖到月底才核。
- **混合策略**：小额急采现结，主供应商给短账期（如7—15天），并保留一个现结备选供应商，避免被单一账期绑定。
- **核心判断标准**：水果损耗率高、价格波动大，账期不宜过长；小商家更适合“短账期+高频对账+严格验收”，而不是追求长账期。
