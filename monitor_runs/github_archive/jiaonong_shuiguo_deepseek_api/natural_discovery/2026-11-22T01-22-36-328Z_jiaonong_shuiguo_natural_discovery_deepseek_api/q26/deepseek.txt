社区超市卖小包装香蕉，核心是“少进货、快周转、控机械伤和催熟节奏”。采购和包装重点看下面几项：

1. **规格要小且统一**
   - 单包建议 2–3 根或 300–500 克，按社区家庭“一次吃完”定规格。
   - 采购时要求同一批次果指粗细、长度、成熟度接近，避免大小混装导致顾客挑拣、剩小果。
   - 优先选“梳蕉”分切后的小把，不选散果重新拼装，散果切口多、易污染。

2. **成熟度分批采购**
   - 小包装周转慢于整把香蕉，采购不要一次全拿全熟果。
   - 建议 7 成左右成熟度为主，搭配少量 8 成熟果做当日即食陈列；熟果占比控制在一天能卖完的量。
   - 问清供应商催熟批次和催熟日期，避免拿到“已催熟但存放久”的货。

3. **包装方式**
   - 用透气打孔保鲜袋或开窗袋，别用完全密封袋，否则水汽积聚、易黑柄和发霉。
   - 袋上留透气孔，或采用薄膜托盘加透气膜；托盘要浅，避免压伤。
   - 标签贴在不直接压果肉的位置，价签或绑带不要勒住果柄和果身。
   - 若做预包装，包装日期和到店日期要清楚，便于先进先出。

4. **分切和切口处理**
   - 从整梳分切时用锋利刀，切口平整，尽量保留果柄，减少伤口。
   - 分切后尽快包装入冷藏或阴凉区，避免长时间裸露。
   - 切口发黑、渗液的不要包进小包装。

5. **运输和到店验收**
   - 采购运输避免挤压、暴晒和闷热，纸箱内加垫纸或分隔，别堆太高。
   - 验收看：果柄是否发黑腐烂、果身有无压伤擦伤、有无酒味酸味、包装内有无水珠。
   - 有机械伤的果不适合做小包装，容易在袋内快速腐烂传染。

6. **损耗控制**
   - 小包装采取“少量多次”补货，陈列量控制在半天到一天销量。
   - 先进先出，每天挑出黑斑严重、软烂的果，及时打折或下架，不要留在袋内。
   - 香蕉怕冷，不要放风幕柜冷风直吹处；一般阴凉通风陈列，避免温度过低导致皮黑。
   - 记录每天小包装销量和报废量，按 2–3 天数据调整采购规格和数量。

7. **采购合同/沟通要点**
   - 明确到货成熟度、单果规格范围、允许机械伤比例、包装破损退换规则。
   - 要求供应商按小批次供货，避免一次压货。
   - 问清是否可退换当天未售完的熟果，或是否有临期折价支持。

实操建议：先做 300–500 克/包的试销，采购以 7 成熟小把为主，每天少量补货；包装用打孔透气袋，陈列避开冷风直吹，每天早晚各挑一次损果。这样比一次性大包装拆卖更能控制损耗。
