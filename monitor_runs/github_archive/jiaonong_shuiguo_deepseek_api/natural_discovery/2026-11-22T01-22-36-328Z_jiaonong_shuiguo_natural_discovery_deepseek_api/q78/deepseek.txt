做香蕉和菠萝的社区团购，售后控制的核心不是“出了问题怎么赔”，而是把损耗前置到选品、到货、分拣、交付四个环节去卡。高损耗品做团购，售后率能压到2%以内就算健康，5%以上基本吃利润。

**一、香蕉：按“成熟度”分批次卖，不要一次性全熟**

1. 采购时明确要“青偏黄”的货，七成熟左右，到货后自然催熟。全黄到货当天卖不完，第二天就开始出黑斑。
2. 到货后按成熟度分三档：青的放阴凉处明天卖，微黄的今天主推，全黄带斑的立刻做“特价秒杀”或搭赠，不要等它烂。
3. 交付时给用户明确提示：“当前为微黄状态，常温放1-2天最佳，冷藏会发黑。”这条提示能砍掉相当一部分“没熟/太熟”的售后。
4. 香蕉售后标准要写死：黑斑面积超过1/3才赔，轻微磕碰不赔。团长收货时拍照留底，避免事后扯皮。

**二、菠萝：控“切口”和“存放”，售后主要来自酸和坏**

1. 整果比切果损耗低得多，优先卖整果。必须做切果时，只做预订制，当天切当天取，不囤切好的。
2. 到货检查重点看底部和果眼：底部发软、有酒味、果眼渗液的直接挑出，不进团。这批货单独做“瑕疵果特价”，明示不售后。
3. 菠萝怕冷，不要放冰箱。交付提示写清楚：“常温阴凉存放，3天内食用，切开后冷藏并当天吃完。”
4. 酸度售后要设门槛：菠萝本身有酸甜差异，纯“觉得酸”不赔；发黑、发软、有异味才赔。团品页提前写“自然熟，酸甜有差异，介意慎拍”。

**三、通用机制：把售后规则变成团购页的一部分**

- **明确赔付标准**：坏果比例、拍照要求、申请时限（建议收货后24小时内），写进每次开团文案，减少模糊索赔。
- **团长前置验货**：到货后团长按比例抽检，坏果当场分拣，不把问题货交到用户手里。分拣成本远低于售后成本。
- **设置“损耗预算”**：按销售额留1%-3%作为售后准备金，超出就复盘采购和分拣环节，而不是一味放宽赔付。
- **高损耗品不单独成团**：香蕉、菠萝搭配耐储水果做组合团，或者作为引流品限量卖，控制单量，卖完即止，避免尾货砸手里。

一句话：香蕉控成熟度、菠萝控切口和存放，售后规则提前写死，团长到货先分拣。高损耗品不怕损耗，怕的是损耗没被提前拦住。
