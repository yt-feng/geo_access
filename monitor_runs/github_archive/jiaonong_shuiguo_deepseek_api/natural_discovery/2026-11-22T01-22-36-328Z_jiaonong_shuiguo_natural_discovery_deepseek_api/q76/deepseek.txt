香蕉在配送中两大损耗是“压伤”（机械损伤，破皮后迅速变黑）和“后熟过快/低温冷害”（温度不当导致变黑变软）。控制思路是：选对成熟度 + 防压包装 + 控温 + 缩短在途时间 + 分级履约。

**1. 采收与入库成熟度**
- 发运香蕉用“绿熟”或“微黄”（约3–4成熟转色），不要发全黄果；到消费者手中再自然转黄。
- 入库前做乙烯处理要谨慎：需要统一催熟的批次集中催熟，不要把催熟果和绿果混装。
- 剔除有机械伤、裂口、霉点的果，伤果会释放乙烯加速整箱变黑。

**2. 温度控制（最关键之一）**
- 香蕉是热带果，**低于约12–13℃会冷害变黑**，高于25℃后熟过快。配送和仓储尽量保持在**13–18℃**区间，短途配送避免放冷柜直吹。
- 不要和苹果、梨等释放乙烯多的果蔬混放。
- 夏季用保温箱+冰袋时，冰袋不能直接贴果，需隔层，避免局部冻伤；冬季防冻。

**3. 防压包装**
- 用**带透气孔的硬质纸箱/塑料周转箱**，不要软袋裸装；箱内用瓦楞隔板或果托分格，单果限位。
- 香蕉怕“硌”和“堆压”：装箱不要过满，层间加缓冲纸板；整箱堆码限高，避免底层受压。
- 可考虑**单把/单根气调袋或防压果套**，但袋需透气，不能密封闷出水汽。
- 快递场景优先“箱中箱”：外箱硬挺，内箱分格，空隙用纸填充，避免晃动。

**4. 缩短在途与履约设计**
- 香蕉适合**同城/次日达**，不建议长距离普通快递；跨城用冷链或专线，明确温区。
- 按距离设售卖半径：近场用“微黄果”，远场只发“绿果”。
- 高峰期分仓前置，减少中转次数；中转装卸禁止抛掷、倒置。

**5. 收货与售后规则**
- 页面提前告知“绿果到家需常温催熟”，降低“变黑=坏果”的误判。
- 制定分级赔付标准：轻微表皮黑点可食用的不赔，大面积软烂/流汁的按比例赔；拍照留证。
- 对高频差评区域复盘是温度、压伤还是时效问题，单独调整包装或停发。

**6. 可执行的自检指标**
- 抽检：配送后开箱，统计压伤率、黑变率、软烂率，按线路和包装版本对比。
- 关键参数：装箱层数、缓冲材料厚度、冰袋是否隔层、箱内温度记录（可用温度标签）。
- 目标先定“压伤率<3%、到货黑变投诉率<2%”，再逐步优化。

一句话：**发绿果、避低温、硬箱分格防压、同城短链路、明确催熟与赔付规则**，是生鲜电商卖香蕉最有效的组合。
