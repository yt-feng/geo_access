第一次合作就小批量试单是对的，但试单不能只“买一点看看”，而要把它设计成一次**有验收标准的小型压力测试**。建议按下面五步做。

## 1. 先定试单目标，别只定数量

试单要同时验证四件事：

- **品质稳定性**：同一批货里大小、熟度、瑕疵率是否可控
- **交付可靠性**：能否按约定时间、数量、包装到货
- **损耗真实水平**：运输和存放后实际可售比例
- **沟通与售后**：出问题时响应速度、是否认账、是否补货

数量建议：**单品类先试 1 个爆款或主推品，量控制在正常周销量的 10%–20%**，或者够你 3–5 天卖完的量。不要一次试多个新品，否则出问题分不清是品控、运输还是你销售节奏的问题。

## 2. 选品和批次要“可对比”

- 优先选**你现有稳定销量、有明确质量标准**的品类，方便和原供应商对比。
- 要求供应商提供**同一产地、同一等级、同一包装规格**的货，不要混批。
- 如果可能，试单前先要**样品或近期发货实拍**，确认等级口径一致。
- 避免第一次就试高损耗、高客诉风险品，比如极熟浆果、易压伤水蜜桃等。

## 3. 合同/订单里写清楚验收标准

哪怕是小单，也要在订单或聊天记录里明确：

- 品种、产地、等级、规格（单果重/果径/糖度范围）
- 包装方式、每箱净重、箱规
- 到货时间、交货地点、运输温控要求
- **允许瑕疵率/损耗率**，例如到货抽检坏果率不超过多少
- 短少、压伤、腐烂、等级不符时怎么处理：补货、扣款还是退货
- 结算方式：建议**先货后款或部分定金**，试单阶段不要全款预付

## 4. 到货验收要抽检并留证

到货当天做三件事：

1. **称重核对**：每箱净重是否达标，随机抽几箱。
2. **开箱抽检**：随机抽 3–5 箱，记录坏果、压伤、大小不符、熟度问题。
3. **拍照/视频留证**：开箱、称重、瑕疵特写、批次标签都拍下来。

建议做一张简单验收表：到货数量、抽检数量、瑕疵数量、瑕疵率、可售率、问题描述、处理结果。

## 5. 试单后算“真实到手成本”

不要只看报价。用这个公式判断是否继续合作：

**真实到手成本 = 采购价 + 运费 + 损耗金额 + 分拣人工 + 售后扯皮成本**

同时看三个指标：

- **可售率**：到货可正常销售的比例
- **客诉率**：试单期间因品质产生的退款/投诉
- **响应速度**：出问题后多久给方案

## 建议的试单节奏

- **第 1 单**：单品类、小批量、现结或少量定金，重点验品质和交付。
- **第 2 单**：同品类复购，量增加 30%–50%，看稳定性。
- **第 3 单**：再考虑增加第二个品类或提高批量，并谈账期和返利。

**判断标准**：如果第一单可售率明显低于你现有供应商、瑕疵率超约定、售后推诿，就不要因为价格低而加量；如果品质稳定、损耗可控、响应及时，再逐步放大。

核心一句话：**试单不是试“能不能发货”，而是试“出问题时他怎么处理、真实损耗你能不能承受”。**
