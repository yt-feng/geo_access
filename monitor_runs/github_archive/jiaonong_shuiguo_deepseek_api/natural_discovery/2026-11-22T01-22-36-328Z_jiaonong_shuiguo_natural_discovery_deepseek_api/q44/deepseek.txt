判断供应商售后响应稳不稳定，不能只看口头承诺，建议用“可验证的动作”去测。按下面顺序做，基本能筛出靠谱的：

1. **先看合同里的售后条款是否具体**
   - 到货时间、验收标准（如菠萝黑心病/烂心、香蕉催熟度、机械伤比例）、异常判定方式要写清。
   - 售后响应要有时限：比如“2小时内响应、24小时内给出处理方案、48小时内补货/退款”。
   - 责任划分要明确：运输损耗、到货不熟/过熟、批次性质量问题分别谁承担。
   - 只有“保证售后”四个字、没有时限和赔付方式的，视为无稳定售后。

2. **用一次小单做压力测试**
   - 首单不要大，选一个正常工作日下单，故意在验收时提一个明确问题（如香蕉到货成熟度偏高、菠萝有机械伤）。
   - 记录：多久回复、谁回复、是否给方案、是否按约定补货或折价。
   - 再选一个周末或节假日前后下单，看非工作时间响应是否掉链子。生鲜问题常发生在凌晨到货，夜间响应能力很关键。

3. **要求提供近期的售后记录**
   - 让供应商给近1—3个月的售后处理台账：投诉批次、原因、处理时长、赔付/补货结果。
   - 注意看是否有“高频重复问题”，比如总是同一产地菠萝烂心、同一路线香蕉冻伤/压伤。
   - 台账可以脱敏，但要有日期、品类、问题类型、处理结果。

4. **确认对接人和升级路径**
   - 明确日常对接人、备用联系人、负责人三级联系方式。
   - 问清楚：凌晨到货出问题找谁？对方休息谁接手？有没有值班手机？
   - 最好在合同或订单确认单里附上联系人表和响应时限。

5. **看是否有本地/就近处理能力**
   - 菠萝、香蕉都是易腐品，售后不只是“赔钱”，还要能快速补货或就地处理。
   - 问供应商：本地有没有仓、有没有备用货源、补货最快几小时到店。
   - 只有外地发货、没有本地补货能力的，售后响应通常偏慢。

6. **用赔付条款倒逼响应**
   - 约定超时响应阶梯：超2小时未响应扣款/折价，超24小时未处理按批次比例赔付。
   - 生鲜验收留证：到货拍照、称重、抽检记录，避免扯皮。

7. **侧面打听**
   - 问同区域其他商超采购、市场档口、配送司机，供应商处理退换货是否爽快。
   - 看供应商是否长期做商超渠道；只做批发的，售后体系往往不如做商超的成熟。

**可执行结论：**
先签含明确时限和赔付的试销合同，用1—2次小单在正常时段和夜间各测一次响应，要求提供近3个月售后台账，确认三级联系人和本地补货能力。四项都通过再放量；任何一项含糊，先别给大单。
