# 坏果率赔付标准建议

合同里没有法定统一比例，关键看**品类、运输距离和验收方式**。实操建议如下：

## 一、常见行业参考区间

| 场景 | 建议约定坏果率 | 说明 |
|---|---|---|
| 产地直发、短途、易储水果（苹果、梨、橙） | **3%–5%** | 超过即按超出部分赔付 |
| 长途冷链运输、浆果类（草莓、蓝莓、葡萄） | **5%–8%** | 浆果损耗天然偏高 |
| 普通批发采购（非精品） | **5%–10%** | 需明确"坏果"定义 |
| 精品/商超供货 | **2%–3%** | 可要求全赔或退货 |

**更稳妥的写法**：约定"自然损耗率 X%（如3%），超出部分按实际坏果重量×采购单价赔付；坏果率超过 Y%（如10%）时买方有权整批拒收或退货。"

## 二、合同必须写清的4个要素

1. **"坏果"定义**——腐烂、霉变、机械伤、虫眼、软烂分别算不算，建议列明。
2. **抽检方法**——抽多少箱、按重量还是按个数计、谁在场见证。
3. **验收时限**——到货后多少小时内提出异议（如24–48小时），逾期视为合格。
4. **赔付计算方式**——按超出比例折算金额，还是整批退货，避免"赔多少"扯皮。

## 三、谈判提示

- 坏果率门槛越低对买方越有利，但供应商会把风险折进报价，**3%–5%是较易达成的平衡点**。
- 若对方坚持高门槛，可换条件：**超出部分只赔货不赔钱**，或**下批订单折价抵扣**。
- 保留到货开箱照片/视频作为证据，合同里约定"以买方验收记录为准"。
