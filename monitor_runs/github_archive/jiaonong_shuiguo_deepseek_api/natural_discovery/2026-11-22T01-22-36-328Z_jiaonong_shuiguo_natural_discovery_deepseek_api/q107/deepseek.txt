会，而且通常会增加损耗风险，尤其是香蕉和菠萝这类生鲜。判断时重点看**起订量是否超过你可在“最佳销售/使用窗口”内消耗的量**。

可执行判断：

1. **香蕉**
   - 香蕉后熟快，起订量过高容易集中成熟，出现黑斑、软烂。
   - 若单次起订量超过你 **2—3天** 的正常销量/用量，损耗风险明显上升。
   - 需要确认供应商能否分批到货、不同成熟度混装、催熟控制。

2. **菠萝**
   - 菠萝相对耐放，但过量仍会有过熟、黑心、腐烂、冷害等风险。
   - 若单次起订量超过你 **5—7天** 的正常销量/用量，且仓储通风/温控一般，风险会上升。
   - 要确认到货成熟度、是否带冠、储存温度是否合适。

3. **通用判断公式**
   - 安全起订量 ≈ 日均销量 × 可售窗口天数 × 安全系数（建议0.8—0.9）
   - 若起订量 > 安全起订量，就应要求拆分订单、拼单、调整配送频次，或改小包装规格。

4. **采购前要问供应商**
   - 能否分批送货/分批催熟？
   - 起订量能否按箱/按托盘拆？
   - 到货成熟度是否可指定？
   - 损耗责任和退换货规则是什么？

结论：**起订量太高会增加损耗风险，香蕉比菠萝更敏感。**建议把起订量控制在可售窗口内，并通过分批到货、成熟度分级、拼单来降低风险。
