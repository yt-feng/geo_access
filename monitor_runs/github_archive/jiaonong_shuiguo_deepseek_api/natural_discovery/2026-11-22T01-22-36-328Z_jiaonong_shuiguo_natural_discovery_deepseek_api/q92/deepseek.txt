小面积便利店做水果，核心不是“品类全”，而是**少SKU、快周转、强控损**。下面给一套可直接落地的控制方法。

## 一、先定原则

1. **面积小就别做“水果店”，做“顺手买”**
   - 只卖顾客进便利店时顺手会拿的水果：香蕉、苹果、橙子、小番茄、葡萄/提子、当季爆品。
   - 不做需要挑、需要称重、需要解释的复杂品类。

2. **品类控制在 6–10 个 SKU**
   - 常驻基础款 4–6 个：香蕉、苹果、橙/橘、小番茄、提子/葡萄、柠檬。
   - 季节款 2–3 个：夏天西瓜切盒、桃子；冬天砂糖橘、草莓少量。
   - 试销款最多 1 个，卖不动 3 天就撤。

3. **能切盒就不整卖大果**
   - 西瓜、菠萝、哈密瓜等大果，整卖占地方、损耗高，优先做**当日切盒**。
   - 切盒必须冷藏、贴时间标签、当天清。

## 二、采购控制：少量高频，按销订货

1. **订货公式**
   - 日订货量 = 前7天同品类日均销量 × 安全系数（1.1–1.2）－现有库存
   - 新店没有数据，先按“**1.5天销量**”订货，宁可少不可多。

2. **采购频次**
   - 叶菜类、莓果类：每天或隔天少量。
   - 香蕉、苹果、橙子：2–3天一次。
   - 小番茄、提子：2天一次。
   - 小门店最好固定**早市补货**，下午只做少量补缺。

3. **采购标准**
   - 不追求大果、漂亮果，追求**耐放、好拿、单价低**。
   - 香蕉买偏青一点，分批次上架；苹果选硬脆耐放品种；橙子选皮厚耐储的。
   - 草莓、蓝莓、切果等高损品，只在有稳定客流时少量上。

4. **供应商策略**
   - 找本地批发市场小批量拿货，或找可“少量多品”配送到店的供应商。
   - 谈**退换货**：坏果、次果能否换货或补损，哪怕只覆盖一部分。
   - 不要一次压价拿大箱，小门店大箱就是损耗。

## 三、陈列控制：少上勤补

1. **陈列量按“半天销量”摆**
   - 台面只摆半天能卖完的量，卖完再从后仓补。
   - 后仓库存不超过 1–1.5 天销量。

2. **分层陈列**
   - 上层：小番茄、提子等易损品，少量。
   - 中层：苹果、橙子等耐放品。
   - 下层/端头：香蕉、切盒，走量款。
   - 不要堆大堆，堆得越多挑损越大。

3. **预包装优先**
   - 小份盒装、袋装，标价清楚，减少顾客翻拣。
   - 袋装苹果、橙子按“个/份”卖，避免称重排队。

## 四、损耗控制：日清+分级

1. **每日两次理货**
   - 早班开店前挑一次，下午高峰前再挑一次。
   - 软伤、碰伤、过熟果立即挑出，避免传染。

2. **分级处理**
   - 轻微瑕疵：做“特价份”或切盒，当天清。
   - 明显软化：做切盒或榨汁（如有条件），贴当日食用标签。
   - 腐烂：立即报损丢弃，不要留在台面。

3. **报损记录**
   - 每天记录：品类、进货量、销售量、报损量、报损原因。
   - 连续3天报损高的品类，直接减量或停售。
   - 单品损耗率控制目标：耐放品 ≤5%，易损品 ≤10%，切盒 ≤8%。

4. **时间标签**
   - 切盒、预包装贴“制作时间+建议食用时间”。
   - 当日切盒当日清，不隔夜。

## 五、定价与促销配合

1. **基础款平价引流**
   - 香蕉、苹果、橙子定接近市场价，作为“顺手买”引流。
   - 不靠水果赚高毛利，靠带动其他商品。

2. **易损品小份高价感**
   - 小番茄、提子做小盒装，单价看起来低，实际按份控制量。

3. **傍晚清货**
   - 晚上固定时段对当日易损品做“第二份半价/买一送一”，清掉比报损好。

## 六、最简单的执行清单

- SKU：常驻 4–6 个 + 季节 2–3 个，试销最多 1 个。
- 订货：按前7天日均销量×1.1–1.2，库存不超过1.5天。
- 陈列：台面只摆半天量，少上勤补。
- 理货：每天早、午各挑一次。
- 报损：每日记录，连续3天高损就减量或停售。
- 切盒：当天做当天清，贴时间标签。
- 供应商：争取少量配送和坏果换补。

**一句话总结：小便利店水果要“少品类、小份装、勤补货、日清损”，把水果当引流品而不是利润品来做。**
