在甜品店采购香蕉时，想要避免到店后很快变黑，核心思路是**控制成熟度**和**改变储存方式**。香蕉变黑主要是乙烯气体催熟和低温冷害（但冷藏不会阻止，只是减慢）。

以下是可落地的采购和到店操作建议：

**1. 采购时（源头控制）：**

- **选购“绿蒂”香蕉**：不要买整把全黄的，要选**果柄（蒂头）还是绿色**的。绿蒂代表香蕉还未完全成熟，到店后自然存放2-3天才会刚好。
- **按“销售周期”分级买**：
  - 如果今天就要用或明天用：买**黄中带绿**的。
  - 如果打算放3-4天：买**整体偏绿**的。
- **不要买有碰伤/黑斑的**：哪怕只有一个小斑点，乙烯释放量高，会带动整把快速熟透。

**2. 到店后（储存处理）：**

- **拆开包装，不要捂**：不要整箱闷在纸箱里，纸箱会积聚乙烯，要拿出来散放在通风处。如果暂时不用，别用塑料袋密封，更不能用不透气的薄膜。
- **单独存放**：香蕉**不要和苹果、梨、猕猴桃**放在同一个果篮或冷柜，这些水果释放乙烯，会催熟香蕉。
- **悬挂或侧放**：如果有条件，把香蕉**挂起来**（减少压痕），或者**让弧面朝下**（凸面朝上）平放，减少与台面的接触面，避免压伤处变黑。
- **低温短保（关键）**：
  - 如果当天用完：直接放室温阴凉处即可。
  - 如果当天用不完，且甜品店温度高：**必须放冰箱保鲜层（4-8℃）**，但注意：
    - **不要紧贴后壁**（太冷会冻伤）。
    - **不要和面包、熟食混放**（串味）。
    - 即使放冰箱，果皮会变黑，但**果肉仍能保持硬挺**，不影响制作慕斯、切块或装饰的卖相（甜品店通常只用果肉，皮黑无所谓）。
- **急用技巧**：如果已经太生，需要快速催熟，在室温下放一个苹果在旁边即可；如果已经太熟但没坏，直接剥皮做香蕉泥冷冻备用，可保存很久。

**3. 小批量采购建议：**

- 甜品店建议**少量多次**，每次采购量控制在**2天内能用完**。
- 如果必须囤货，建议购买**冷冻香蕉丁/香蕉泥**（工业冷冻），避免鲜蕉损耗。

**总结口诀**：买绿蒂，拆箱放，避开苹果，当天不吃的进冷藏（果皮黑无所谓，果肉不软就行）。
