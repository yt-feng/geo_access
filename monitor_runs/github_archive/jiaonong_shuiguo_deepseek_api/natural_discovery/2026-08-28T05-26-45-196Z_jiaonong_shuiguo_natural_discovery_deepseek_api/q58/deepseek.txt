在甜品店采购菠萝时，**鲜果切配**和**直接买成品果丁**的损耗情况，需要分环节来看：

---

**结论（先给重点）：**
- **鲜果切配的“采购单价更低”**，但**“综合损耗率更高”**。
- **成品果丁的“采购单价更高”**，但**“综合损耗率更低”**。
- 对大多数甜品店（尤其是有固定出品的饮品/蛋糕店），**直接买成品果丁总损耗往往更低**，更省时间和人力。

---

**具体对比：**

| 环节 | 鲜果切配（买整颗菠萝） | 成品果丁（买切好的） |
|---|---|---|
| 采购单价 | 便宜，约3-6元/斤（视季节） | 贵，约8-15元/斤 |
| 去皮/去核/修整损耗 | 损耗率高达 **25%-35%**（菠萝皮厚、果眼深） | 几乎为0（工厂已处理） |
| 储存损耗 | 整颗常温可放2-3天，切开后冷藏高糖分易出水、变质 | 真空包装冷藏或冷冻，保质期更长，不易腐烂 |
| 人工/时间损耗 | 需专人削皮、挖眼、切丁，耗时（约5-10分钟/个） | 开袋即用，省时省力 |
| 出品一致性 | 切丁大小不一，影响甜品外观和口感统一性 | 标准切丁，美观统一 |
| 卫生风险 | 鲜果表面病原体若未洗净，易污染切配区 | 工厂清洗杀菌流程更规范 |

---

**更具体的计算示例（以你单日需要10斤果丁为例）：**
- **买整颗菠萝**：10斤果丁 ÷ 70%（可食率）≈ **14.3斤鲜果**，采购价约50-70元（按5元/斤），加上切配人工（1小时约30元）及可能浪费的边角料，**实际总成本约80-100元，且耗时1小时**。
- **买成品果丁**：直接买10斤，按12元/斤算，**成本约120元**，但**零人工、零损耗、开袋即用**。

---

**适用建议（帮您决定）：**
1. **店里每天果丁用量少于5斤，且有人手空闲** → 买鲜果自己切，**损耗可控（切配熟练可降到20%左右）**，降低采购成本。
2. **店铺高峰期出餐快，果丁用量大（如奶茶、水果捞、蛋糕夹心）** → **强烈建议买成品果丁**，损耗和人力成本远低于鲜果切配，出品也更稳定。
3. **如果对果丁新鲜度和口感要求极高（比如做高档法式甜品摆盘）** → 可买整颗鲜果，但要注意**当天用当天切**，避免隔夜氧化和出水。

---

**额外提醒：**
- 无论买哪种，**下单前问清产区和成熟度**（台湾、菲律宾凤梨或海南菠萝），避免买到过生或过熟导致的额外损耗。
- 成品果丁注意看**是否加糖或防腐剂**，甜品店建议选“无添加糖”的纯果丁，避免影响配方甜度。
