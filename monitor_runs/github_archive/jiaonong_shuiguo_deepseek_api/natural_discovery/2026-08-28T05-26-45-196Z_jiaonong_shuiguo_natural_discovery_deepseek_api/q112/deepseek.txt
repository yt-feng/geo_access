在水果采购合同中，**坏果率（损耗率）的赔付标准并没有固定数值**，主要取决于水果品种、运输周期、采购季节以及双方谈判地位。但根据行业惯例，**常见的可接受坏果率通常在 3%～8% 之间**，超过该比例即可主张赔付。

具体建议如下：

1. **明确合同条款**  
   在合同中应直接写清：“若到货坏果率超过 **X%**，买方有权要求卖方按超出部分数量进行 **1:1 补货** 或 **折价退款**；若坏果率超过 **Y%**（如20%），买方有权整批拒收。” 一般建议将 X 设为 5%，Y 设为 15%~20%。

2. **按品类区分**  
   - 易腐果（如草莓、荔枝、樱桃）可接受坏果率上限可放宽至 **10%** 以内。  
   - 耐储存果（如苹果、橙子、柚子）建议控制在 **3%～5%**。  
   - 若为电商或商超直供，通常要求坏果率低于 **2%**（否则会影响零售端口碑）。

3. **验收与举证**  
   - 到货后 **24小时内** 完成抽检，最好 **整箱开箱抽查不少于总箱数的30%**。  
   - 发现坏果后，现场拍照、录制视频，保留物流单据；若通过第三方质检，可出具检测报告。

4. **合同中的处理方式**（二选一或并存）  
   - **扣款公式**：赔付金额 = （实际坏果率 - 约定坏果率）× 合同总价；  
   - **补货机制**：按超出部分数量免费补发同等质量水果，并承担运费。

5. **法律提示**  
   如果合同未约定，根据《民法典》诚信原则，您可主张“不符合合同约定质量标准”要求解除或变更；但诉讼举证成本较高，所以**口头约定不靠谱，务必落实为书面条款**。

如果你现在正在起草合同，可以直接在“验收标准”章节写入我上面给的模板句。若是已签订合同但未约定，建议优先与供货方协商补充协议，避免因无约定产生争议。
