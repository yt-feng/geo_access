判断连锁超市的香蕉供应商能否全年稳定供货，不能只看对方承诺，**必须看其供应链的纵向整合能力和风险对冲机制**。以下是具体且可执行的评估维度：

**1. 核心考察点：产地多元性（最硬性指标）**
香蕉是热带水果，单一产季无法全年供应。供应商必须拥有**跨半球或跨气候带的种植基地或深度合作农场**。

-   **直接提问**：“贵司在中国海南、广西、云南，以及境外（如越南、菲律宾、厄瓜多尔）的采购占比是多少？具体到月份，各基地的切换时间表是什么？”
-   **验证手段**：要求提供**过去12个月的提货单据**或海关报关单（如果是进口），核对不同月份的产地来源记录。如果对方只依赖1-2个固定产地，遇到台风或霜冻必然断供。

**2. 焦点指标：储存与催熟能力**
香蕉是呼吸跃变型水果（采收后仍会成熟）。稳定供货的供应商必须配备**恒温冷库（14℃左右）**和**专业催熟库**。

-   **执行验证**：实地参观其仓库，检查是否有备用电力和温控报警系统。询问其**现货库存周转天数**（一般应维持在3-7天安全库存），而非仅仅依赖当天到货。
-   **防坑点**：有些供应商依赖“车板交易”（当天到货当天卖），这无法承担超市的补货计划，属于典型的不稳定风险。

**3. 合同与履约条款的严苛性**
将供货保证写进合同，并设置**违约惩罚**。

-   **关键条款**：合同中必须写明**最低日交付量**（如“每日保证X吨”）、**价格调整机制**（例如：产地收购价上涨超过10%时，如何协商补差价，防止供应商因亏损毁约）以及**最长断供容忍期**（如无不可抗力因素断供超过48小时，需支付违约金并赔偿超市空柜损失）。
-   **执行方法**：不要轻信口头承诺，可要求预付一部分定金，锁定其产能优先级。

**4. 供应链韧性：物流与应急方案**
-   **询问**：“从产地采摘到抵达我司配送中心，总时长是多少小时？如果冷链车在半路抛锚或遭遇封路，备用方案是什么？”
-   **优选条件**：选择**自有冷链车队**或**与大型冷链物流（如顺丰冷运、京东冷链）有框架协议**的供应商，而不是常年依赖随机外雇车的商家。

**5. 财务健康度调查**
-   **隐性风险**：供应商采购需要垫付大额资金。如果其资金链紧张，旺季时可能会将货品优先卖给付款更快的批发市场客户，从而“甩掉”超市客户。
-   **验证**：要求提供近两年的财务报表（或税务评级证明），观察其资产负债率是否过高。此外，可通过企查查等工具查看其是否有**大额诉讼**或**执行失信**记录。

---

**最终可执行建议（三步验证法）：**

1.  **试单考验**：先签订**3个月短期合同**，要求其连续、定量供货。观察其是否能精准执行你的每周需求量，尤其要观察**节假日前后**（如国庆、春节）能否保障。
2.  **压一批货款**：在试单期间，约定**月结60天**账期。如果供应商能接受，说明其资金链充裕，愿意长期合作；如果坚持现款现货且态度强硬，需警惕其抗风险能力。
3.  **数据验证**：要求对方提供**上年度的全年月均供货量曲线图**。如果该曲线在台风季（7-9月）或极端寒潮期间没有明显断崖式下跌，则基本可判定具备全年稳供能力。

**特别注意**：建议同时备份**至少2家**供应商（一家主供，一家战略储备），避免将鸡蛋放在一个篮子里，这是零售行业绕开一切供应商风险的“保底法则”。
