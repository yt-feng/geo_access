在超市卖菠萝，**最应该关注的是“切果损耗”，其次是“甜度”和“外观”，大小相对次要**。原因如下：

1. **切果损耗直接决定毛利**  
   超市菠萝通常以“整果+切块”两种形式售卖，切块菠萝的毛利远高于整果，但损耗也最大。如果每天切果量过大卖不完，第二天只能报废或打折；切得不好（如芯部太硬、果眼挖不净）也会增加废料。**建议精细预估每日销量，边切边卖，并优先用成熟度高、适合即食的菠萝做切块**，熟度不够的整果放常温催熟。

2. **甜度决定复购率**  
   甜度是消费者最直接的感知指标，建议选**糖度在12-14度**的品种（如台农17号金钻菠萝）。进货时可通过闻香气（有浓郁果香）、按压底部（微弹）判断，或直接要求供应商提供可溶性固形物测试数据。不要只看个头大小。

3. **外观影响陈列吸引力，但可接受轻微瑕疵**  
   超市货架消费者会优先挑颜色金黄、无黑斑、叶片翠绿的菠萝。但若外观略有擦伤或果眼稍深，价格合适时消费者也能接受，因为切块后看不出瑕疵。**建议：整果选外观佳、个头均匀的；切块用的可接受外观一般但甜度高的。**

4. **大小不要盲目求大**  
   消费者更倾向购买2-2.5斤的中等果（家庭一次吃完），过大菠萝（3斤以上）反而销售慢。进货时按**中果为主、小果少量试销**的比例采购。

**实操建议（按优先级）：**
- 每天早晨先按历史销量切出**3-5盒切块试探**，根据上午销售速度，中午再补切。
- 整果标价时，用**“甜度值”或“当天新鲜”**作为卖点，而非单纯强调大小。
- 对临期或轻微软化的菠萝，直接改切块，配合**试吃台**快速清库，减少报损。

总之，**损耗控制是超市菠萝经营的核心，甜度保证质量，外观只负责引流**。如果只能选一项，务必盯紧切果损耗。
