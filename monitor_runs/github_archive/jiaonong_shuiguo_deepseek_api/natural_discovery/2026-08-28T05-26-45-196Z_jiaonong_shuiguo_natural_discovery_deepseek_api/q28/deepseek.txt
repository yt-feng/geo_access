针对超市引入稳定的进口水果，**建议优先从进口香蕉开始**。

理由如下：

1. **供应链最稳定**  
   香蕉是国际大宗贸易商品，种植产地集中（如菲律宾、厄瓜多尔、越南等），全年均可供货，且期货式采购成熟，不易出现断货。

2. **消费频次最高**  
   香蕉是日常高频水果，国内消费者接受度极高，即便定价略高，动销（库存周转）也快，回款压力小。

3. **损耗易于控制**  
   香蕉是后熟型水果，可通过冷链控制成熟度（青蕉催熟），货架期可控，超市能灵活安排促销或组合销售，损耗风险低于菠萝（易烂）和苹果（竞争激烈）。

**具体操作建议**：
- 首批试采：从菲律宾或厄瓜多尔进口青蕉，在本地催熟，单店首批量控制在20-30箱（约400-600公斤）。
- 定价策略：比国产蕉高15-20%，强调“无催熟剂、可溯源”卖点，试销2周。
- 后续扩展：香蕉稳定后，再逐步引入进口苹果（如智利、新西兰）作为补充品类，最后再评估菠萝（需专业削皮服务，人工成本高）。

**注意事项**：首月建议与国内大型水果批发商或进口商签订短期合同，避免直接对接国外产地，先确保仓储、催熟设备和退货条款完善。
