单位采购水果，如果到货品质不一致，确实很常见，处理得好不仅能减少损失，还能规范后续采购。

核心思路是：**先固定证据，再分级处理，最后走对售后流程。**

以下是具体操作建议，分三步走：

### 第一步：验收环节（现场留痕，分级判定）

1.  **拆箱全检 vs 抽检比例**：
    -   如果采购量大（比如超过50箱），按**10%-20%**的比例随机开箱抽检。
    -   如果采购量小，建议**全检**，至少每箱要“看、摸、闻”一遍（看外观有无烂斑、摸硬度是否一致、闻有无异味）。

2.  **品质分级（关键动作）**：
    当你发现有差异时，立即**现场拍照/录像**，并将水果分为三堆：
    -   **合格品**：达到采购合同或样品标准。
    -   **次品（非腐坏）**：大小不一、轻微磕碰、颜色不均，但不影响食用。这类**建议协商折价接收**，留作员工内部消耗或打果汁用。
    -   **废品（腐烂变质）**：明显发霉、流水、软烂。这类**必须全额拒收或要求补货**。

3.  **称重计量**：区分后，分别称重并记录，注明“合格品XX斤，次品XX斤，坏果XX斤”。

### 第二步：售后谈判（分情况处理）

**情况A：刚到货，当场发现问题**
-   **直接拒收**坏果部分，让送货司机拉走，并在送货单上签字注明“已拒收坏果XX斤”，拍照留存。
-   或者要求供应商**现场换货**。

**情况B：供应商不在场，已签收后发现**
-   **黄金时间**：24小时内（水果易坏，一定要第一时间联系）。
-   **提供证据**：将第二步拍的照片、称重记录，以微信/邮件形式发给供应商，并明确告知“这批货有X%的损耗，超出合同约定的3%自然损耗范围”。

**情况C：达成售后协议**
-   **补货**：让供应商补发同等重量的“坏果”替代。
-   **退款**：按坏果占比，从货款中扣除。示例公式：`应扣款 = （坏果重量 + 次品降价部分） × 单价`。
-   **折价**：次品部分，按原价的50%-70%结算（具体比例看话术和供应商态度）。

### 第三步：规避下次风险（制度层面）

建议在下次采购合同中（或采购单备注栏）**明确约定量化标准**，而不是模糊的“新鲜”：
-   **大小规格**：例如“砂糖橘单果直径≥4.5厘米”，或“苹果约80#（直径80mm）”。
-   **重量公差**：例如“单箱净重允许±200g误差”。
-   **损耗率**：例如“到货坏果率（含软烂）≤2%，超出部分由供应商承担”。

---

**最后，一句硬话要先说在前面：**
如果供应商拒绝处理，**不要自行丢弃坏果**。保留原包装和坏果，锁在冷藏室（或阴凉处），作为后续向12315投诉或拒付货款的证据。

**如果对方是熟人很熟，且金额不大（几百块），建议折算成下次补货抵扣，处理成本最低。**如果金额较大，坚决按合同办。
