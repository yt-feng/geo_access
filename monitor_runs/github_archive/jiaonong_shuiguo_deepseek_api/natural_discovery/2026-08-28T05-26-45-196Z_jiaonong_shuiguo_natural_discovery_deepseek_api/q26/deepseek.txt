社区超市销售小包装香蕉，采购时主要关注**包装设计**、**损耗控制**和**供应链衔接**三个方面。以下是具体注意事项和操作建议：

**一、包装层面（直接影响卖相和货架期）**

1. **透气性必须优先**：香蕉是呼吸跃变型水果，密封不透气的包装（如全封闭塑料袋）会加速变质和“出汗”发霉。
   - **推荐**：使用带透气孔（孔径3-5mm）的PE或PP材质托盘+保鲜膜封装，或采用带孔网袋/扎孔包装。
   - **避坑**：不要用厚实的不透光纸盒直接接触果体，容易产生碰伤和闷热。

2. **重量规格设计**：社区家庭通常一次性消耗量小。
   - **建议**：单包重量控制在 **500g-800g**（约4-6根），或按“两根、三根”小份装，便于早餐或儿童食用。
   - **注意**：包装上必须清晰标注净含量，避免因缺斤少两引发客诉。

3. **缓冲与固定**：香蕉易碰伤。包装托盘应带有凹槽卡位（支撑果柄和果身），避免运输过程中相互撞击；果柄部分最好用扎带或缠绕膜单独收紧，减少水分蒸发和断裂。

4. **成熟度分级包装**：采购时要按成熟度分批次包装，不能混装。
   - 绿熟（耐放的）单独包，用于提前采购；
   - 黄熟（当天/次日可食用）单独包，并标注“即食”标签。
   - 避免同一包装内既有全青又有熟透发黑的，影响顾客体验。

**二、损耗控制层面（采购端和门店端）**

1. **明确采购成熟度**：不要采购全熟或过熟果。最好采购 **“7-8成熟”**（果皮黄中带绿，果肉硬实）的香蕉，在门店自然后熟。全熟果损耗周期极短，通常24小时内就会发黑。

2. **冷链与周转时间**：香蕉属热带水果，**严禁放入0-4℃冷藏库**（会冻伤变黑）。应储存于12-14℃阴凉通风处。
   - 采购时要求物流车辆保持常温（15℃左右）或恒温运输，避免高温暴晒。
   - 从产地/批发市场到店时间控制在24小时内，时长越短损耗越低。

3. **上架周转率测算**：小包装的货架期一般只有2-3天。
   - **采购量参考**：按“店内香蕉日销量 × 1.5倍”采购，避免积压。
   - **每日翻包**：当天未卖完的散包，次日必须拆开重包，挑出变软的单独降价处理，不能继续原包装售卖。

4. **验收标准**：收货时逐箱拆检，抽检率不低于20%。重点检查：
   - 果柄是否有霉变（尤其注意切口处）；
   - 果皮是否有明显压痕、黑斑（斑点超过3处即算损耗果）；
   - 整箱内有碰伤果比例超过5%应整批拒收或协商折价。

**三、额外建议（减少隐性损耗）**

- **设立“临期专区”**：把开始出现少量黑点的包装降到半价，放在收银台附近的促销篮，尽快周转。
- **标识建议**：在包装上贴小标签“自然成熟，请勿冷藏”，避免顾客带回家放冰箱加速变坏后索赔。
- **供应商合同**：与合作商明确“到店成熟度等级”和“包赔条款”（如：到货后24小时内出现严重发霉的占比超3%可部分退货）。

**核心原则**：包装服务于“透气+防碰+适量”，采购服务于“不见黑点+不冷藏+当日到货”。按此执行，小包装香蕉的损耗率可控制在8%以内（常规散装损耗约15%）。
