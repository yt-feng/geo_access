在超市与水果供应商谈判账期时，**常见的账期长度一般在30天到60天之间**，具体取决于合作模式、水果品类、供应商规模以及超市的采购政策。

以下是具体参考：

1. **常见区间**：大多数连锁超市（如永辉、华润万家等）的账期通常在 **30~45天**。如果是大型商超或全国性连锁，可能延长至 **60天**，但极少超过90天（除非是部分电商平台或新零售，如盒马曾对部分供应商有更长期限）。
2. **生鲜特殊性**：水果属于**易腐生鲜**，损耗率高，供应商对现金周转要求较高，因此账期普遍**短于干货、日化品类**（后者常见60~90天）。通常生鲜供应商能接受的极限是45天，超过60天会显著提高报价或要求预付款。
3. **谈判博弈点**：
   - 如果超市规模大、采购量大，可能会压到60天，但通常会给予**现结或15天短账期**作为支持（如扶持中小供应商）。
   - 可采取**阶梯账期**：前1~3次合作短账期（如15天）建立信任，之后拉长至30~45天。
   - 水果品类中，**高端水果或进口水果**（如车厘子、榴莲）由于单价高，供应商更倾向短账期（15~30天）或现结，以降低资金风险；普通大众水果（苹果、香蕉）则接受度更高。
4. **行业趋势**：近年来，随着供应链金融普及，部分超市（如永辉、大润发）对优质供应商提供“账期+供应链贷款”模式，即账期仍为45天，但供应商可通过超市平台以应收账款质押快速回款（约7天到账），这实际缩短了供应商的现金流压力。

**建议**：如果您是超市方，初次谈判可提出45天账期；如果是供应商，应争取30天以内，并强调水果损耗率来佐证。同时，务必在合同中明确**对账日、付款日、逾期违约金**（如每日万分之五），避免口头承诺。
