商超在做会员日水果活动时，供应商的配合直接决定活动的成败和毛利。建议供应商从以下五个维度提前准备，重点突出“履约效率”和“品质保障”：

### 1. 备货与库存管理（最核心）
- **提前锁量**：活动前3-5天，需与商超采购确认预估销量（参考去年同期、会员基数、天气），并签订**保底订货量**合同，避免供大于求。
- **分批到货**：建议按“活动前1天到70% + 活动当天早间到30%”的模式，保证水果新鲜度。避免一次性大量到货导致门店损耗。
- **安全库存**：为爆款单品（如榴莲、车厘子、西瓜）增加20%的机动库存，并准备**替代方案**（如A品种缺货，优先用B品种补位）。

### 2. 品质与损耗控制预案
- **采收标准**：活动果必须执行“**商超A级标准**”，糖度、克重、外观需高于日常供货（建议供应商提供《到货质检单》）。
- **损耗分摊**：与商超明确**自然损耗率**（如5%-8%），超出部分属于供应商责任。建议提前申请“售后折价处理”政策，允许在活动最后一天将次果特价清仓。
- **预冷与包装**：夏季活动必须使用**冷链车**，且小包装（如盒装、网套）利于顾客拿取，减少翻拣损耗；同时改用**气调包装**延长货架期。

### 3. 陈列与营销物料支持
- **陈列道具**：提供专属陈列架、假底（藤筐）、POP立牌、价格签、试吃台耗材（牙签、果盘、垃圾袋）。
- **试吃支持**：安排**专职促销员**，活动期间现场切果、叫卖。供应商需提前培训试吃话术（突出产地、甜度、性价比）。
- **价格策略**：建议提供**阶梯价格**，如会员日当天享受“折上折”（供应商让利3%-5%），并设置“买一送一”或“满额抽奖”的联合活动。

### 4. 物流与人手调度
- **配送时效**：确保活动日凌晨5：30前到货（赶在开门前上架），必须安排**双司机**以防疲劳或堵车。
- **装卸工人**：提前安排2-3名装卸工，需配合商超**收货口查验**（称重、测糖、验损），快速完成入库，否则影响上架效率。
- **机动补货**：活动当天下午2点前，需预留1辆备用车应对临时加单。

### 5. 售后与应急机制
- **专人驻场**：活动期间供应商需安排**业务代表**驻店（或手机畅通），处理现场质量问题（如顾客投诉、退货）时，供应商承担**先行赔付**，避免商超客诉升级。
- **天气预案**：若遇暴雨等极端天气，供应商需提前1天与商超确认是否**减少订单30%**，并共同承担滞销风险。
- **数据反馈**：活动结束后48小时内，向商超提交《动销分析报告》，含各单品售罄率、损耗率、毛利率，为下期活动优化。

---

**供应商特别注意的“避坑”点：**
- 会员日水果活动，**价格不是唯一**，品质的稳定性（同一批次口感统一）最关键，否则一个差评会让整场活动亏本。
- 若商超有**线上到家**业务，供应商需额外配合提供“线上专属小规格包装”（如500g盒装），并确保库存同步更新。

**建议行动清单：** 提前3天与采购确认订单→提前1天完成预冷/分拣→活动当天凌晨发货并安排驻场。提前问清楚商超是“损耗自担”还是“退货机制”，这决定你利润空间。
