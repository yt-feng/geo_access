针对餐饮连锁采购水果，**“中央厨房统一收货”是更优的选择**，但这需要结合你的门店数量和水果品类来细化执行方案。

**为什么中央厨房统一收货更好？**

1. **品质把控更严格**：水果品质波动大，中央厨房可以安排专人按统一标准（大小、糖度、成熟度）进行验收和分拣，避免各店收货标准不一，门店员工缺乏专业知识或人手不足时“放任”劣质果进入。
2. **损耗更可控**：统一收货后可以集中进行清洗、切配、分装（如果是果切/鲜榨），减少门店前场的二次处理损耗。库存也能集中周转，避免每家门店各自压货。
3. **降低采购成本**：大批量直采议价能力更强，且能减少每家门店单独叫货带来的物流分散和冷链成本。
4. **统一出品与食安追溯**：中央厨房能按配方规范化分装（如：每份果切固定克重），出现问题可以反向追溯批次，处理食安问题更高效。

---

**特别注意：两种水果需要单独处理**

- **极不耐储的“即食型”水果**（如熟透的榴莲、现切芒果、草莓、荔枝）：如果中央厨房离门店较远（超过2小时车程），建议**由中央厨房统一验收后，在当日凌晨将定量的货直接分拨给门店**，门店只做“暂存”而非“囤积”，避免在中央厨房过夜损耗。
- **需催熟的水果**（如香蕉、牛油果、猕猴桃）：必须统一到中央厨房，因为催熟需要专业控温控湿环境，门店无法处理。

---

**如果坚持“门店分开收货”**（适合：门店数极少<5家、或位于不同城市且无中央仓），则必须做到：
- 制定**极简验收SOP**（拍照上传、称重、按标准剔次率）；
- 由总部统一指定供应商和价格，门店只做订单汇总，不可自行采购。

---

**落地建议（可执行方案）**

1. **模式**：采用“**中央厨房统一收货 + 净菜/预包装分拨**”模式。即：总部统采鲜果，果品到中央仓后72小时内完成分拣加工。
2. **分拨逻辑**：按门店日销量和近效期规则，采用**“先进先出+动态补货”**，每天配送到店。
3. **应急机制**：中央厨房留20%安全库存，门店预留最小安全周转量（如1天），遇到爆单时启动紧急配送。

**结论**：请优先选择中央厨房统一收货，但要为不同水果设立“到店即加工即售”和“仓内催熟”两条通道，才是成本与新鲜度的最优解。
