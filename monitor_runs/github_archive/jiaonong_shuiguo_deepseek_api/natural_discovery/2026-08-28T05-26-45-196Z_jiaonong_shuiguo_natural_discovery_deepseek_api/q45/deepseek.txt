签订年度水果供应合同，超市方最容易在以下环节踩坑，建议重点关注：

**1. 价格与调价机制（最容易扯皮）**
- 踩坑点：只写“随行就市”或“按市场价”，但没定义“市场”是什么（批发市场？产地价？），也没有调价触发条件。
- 建议：明确基准价（如签订日当地批发市场均价），并设置调价幅度阈值（如一周内波动超过5%可协商调价）；同时约定价格有效期和重新议价的周期。

**2. 质量标准与验收标准（模糊不清）**
- 踩坑点：只写“新鲜、无腐烂”，但不同品类的糖度、大小、着色度、碰伤比例没有量化标准，导致到货后拒收/扣款纠纷。
- 建议：附上双方签字确认的《质量验收标准表》，明确每类水果的等级（如一级果直径≥XXcm，表皮损伤≤XX%），并规定抽查比例（如每批抽检10%）。

**3. 损耗与退换货责任（最容易被忽视）**
- 踩坑点：到货时验收合格，但上架后第3天发现大量软腐，没有约定“货架期”责任归属。
- 建议：约定“到货后24小时内快检，72小时内反馈质量异议”；同时明确仓储条件（谁的温度谁负责）和二次分拣损耗（通常超市自担，但可谈退换货比例）。

**4. 供应量弹性与缺货责任（季节性风险）**
- 踩坑点：只约定全年总吨数，没约定月度供应量浮动范围。遇到台风季或产期波动，供应商无法足量供应，超市却无权追责。
- 建议：约定月度计划量可浮动±15%，并写明缺货违约赔偿（如按短缺货值的30%赔付）；同时约定极端天气（台风、暴雨）的免责条款。

**5. 结算账期与发票（现金流陷阱）**
- 踩坑点：只写“月结”，但没写对账日、开票日、付款日，供应商拖票或超市压账各执一词。
- 建议：明确账期（如收货后45天）、对账截止日（每月25日）、付款日（次月10日前）；并约定“先票后款”还是“先款后票”，以及逾期付款的滞纳金（如每日万分之五）。

**6. 合同终止与续约条款（容易被锁死）**
- 踩坑点：只写了“合同一年”，没有设中途退出机制。若供应商合作差，超市要熬到年底。
- 建议：写明“连续两月供货准时率低于90%或质量投诉超过3次，超市有权提前30天书面终止”；同时约定续约自动续签条件（如双方无异议则自动顺延）。

**7. 农药残留与溯源（法律红线）**
- 踩坑点：没约定农残超标的法律责任。一旦被食品安全部门抽检不合格，超市可能承担连带责任。
- 建议：要求供应商提供每批次的农残检测报告，并保留产地证明；合同写明“因农残超标导致的行政处罚、下架损失，由供应商全额承担”。

**最后实操建议**：年度合同签订前，先试运行1-2个月的小批量订单合同，磨合验收和结算流程后再签长约。另外，所有口头承诺（如“临时缺货可以优先调货”）务必以补充协议或聊天记录形式留存。
