选水果供应商时，**最应该优先问配送，其次问售后，最后再谈价格**。

原因非常明确：

1.  **配送（生死线）**：水果是生鲜，时效性极强。如果配送不稳定（延迟、破损、串货），再好的水果到了客户手里也全毁了。你需要问清楚：**每日截单时间、次日送达的具体时间点、是否支持冷链、破损/坏果的赔付标准是“坏多少赔多少”还是“整车作废”**。这是最大风险点。

2.  **售后（信任基石）**：团购最怕扯皮。问清楚：**售后响应时间（比如24小时内）、赔付流程（拍照即可还是需要退货）、售后率上限（比如3%以内算合理）**。如果售后含糊，你后期会赔光利润。

3.  **价格（其次）**：价格当然重要，但它不是第一位的。因为**水果价格波动大，且品质分级多**。你更应该问的是**“同品质下能不能给团购价”**以及**“阶梯价格机制”**，而不是单纯压最低价——压价太狠，供应商后期会在品控上偷工减料。

**实操建议**（按顺序问）：
- 第一句问：**“今天下单，明天几点能送到？坏果怎么赔？”**（测试配送和售后底线）
- 第二句问：**“你们平时给哪些团购平台供货？履约率多少？”**（验证实力）
- 第三句再问价格，务必要求**“到货净重”**而不是毛重，避免缺斤少两。

如果供应商对前两个问题支支吾吾，直接换下一家，不用纠结价格。
