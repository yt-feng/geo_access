水果礼盒的搭配，核心原则是 **“好看、寓意好、耐运输、能赚钱”**。  
针对苹果、橙子、香蕉、菠萝这四种水果，我建议按照不同的定价和场景来设计礼盒，以下是比较实用的方案：

### 方案一：经典“吉祥四宝”礼盒（主打走量、大众消费）
*   **搭配**：苹果 6个 + 橙子 6个 + 香蕉 1把 + 菠萝 1个
*   **寓意**：苹果（平安）、橙子（心想事成）、香蕉（相交好运）、菠萝（旺来/财源广进）。
*   **包装建议**：用红色或金色底色的硬纸礼盒，上下分层。菠萝放在底层中间（因为个头大且容易压坏），香蕉放最上层（不能压）。橙子和苹果码放整齐。
*   **定价策略**：中等价位，走“家庭送礼”路线，适合送长辈和平辈。

### 方案二：高档“商务/探病”礼盒（主打精致、高毛利）
*   **搭配**：苹果 8个（选大果，如红富士） + 橙子 8个（选脐橙/血橙） + 菠萝半个（切好装盒，附赠叉子） + 香蕉不放或放少量（因为香蕉易碰伤，商务礼盒风险高）。
*   **注意**：商务或探病场景，**香蕉建议剔除**。因为香蕉一旦挤压变黑，整个礼盒品相就毁了。菠萝可以改成“切好的菠萝肉”用透明盒分装，显得高端。
*   **定价策略**：高价，主打“高端水果店”形象。

### 方案三：平价“尝鲜/自用”组合（主打性价比）
*   **搭配**：苹果 4个 + 橙子 4个 + 香蕉 1小把（5-6根）+ 菠萝 半个（去皮切块，真空包装）。
*   **卖点**：香蕉不耐放，但菠萝和苹果橙子耐放，买回去一周内吃完刚好。
*   **包装建议**：用普通开口式藤编篮或纸箱，成本低，定价亲民。

---

### 关键实操建议（避免亏钱）：

1.  **香蕉必须“特殊保护”**：香蕉乙烯催熟快，如果盒子里有苹果、菠萝，香蕉熟得会特别快（苹果释放乙烯）。如果要做混合礼盒，**香蕉用独立小包装袋（打孔透气）** 放最上层，或者干脆做成“香蕉单独小筐”附在礼盒侧边。
2.  **菠萝处理**：如果整果放，一定要选**绿皮硬菠萝**（耐压）。但顾客对“削皮技巧”有顾虑，建议提供**“代切服务”**，切好后用保鲜膜包好放入盒内，这样体验感最加分。
3.  **颜色搭配**：黄（香蕉/菠萝）+ 红（苹果）+ 橙（橙子），视觉冲击力强，放在店门口非常显眼。

### 最终推荐组合（请优先尝试这个）：
> **“心想事橙·平安旺财” 礼盒**  
> 苹果（红）6个 + 橙子（橙）6个 + 菠萝（黄绿）1个（代切好）  
> 香蕉（黄）1小把单独用牛皮纸袋系在礼盒手提绳上（不塞进盒内，防压坏）。  
> 售价定为进货成本的 **2.2倍 - 2.5倍**（比如成本30元，卖68-75元）。

如果不卖香蕉，可以完全去掉香蕉，用“苹果+橙子+菠萝”组合，因为香蕉损耗率高，容易影响口碑。但如果你要清库存加快周转，按方案三的“独立包装”也行。

**最后提醒**：礼盒里记得放一张小卡片，写“香蕉请尽快食用，苹果可稍后食用”，能显著降低投诉率。
