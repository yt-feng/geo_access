社区超市经营水果，控制新鲜度和库存的关键在于**“勤进快销”**和**“以销定采”**。

以下是具体可执行的操作方案，分为**进货前、在店中、销售后**三个阶段：

### 一、进货前：科学定量，避免拍脑袋

1.  **以销定采（看历史数据）**：
    -   统计**近3-5天**每天各类水果的实际销售量（不是进货量）。
    -   明日进货量 = 今日销售量 × 1.2（预留安全系数，应对突发购买）。
    -   **注意**：周末和节假日销量通常比工作日高30%-50%，周一和雨天要少进。

2.  **优化品类结构（分等级进货）**：
    -   **引流款（20%）**：苹果、香蕉、橘子等大众水果，走量快，允许有轻微损耗，利润薄但聚人气。
    -   **利润款（50%）**：应季的时令水果（如西瓜、葡萄、草莓），新鲜度是生命线，少进多次。
    -   **高端款（10%）**：进口水果或稀有品种，量要极少，甚至可以按个、按盒进货，卖完即止。

3.  **控制进货频次**：
    -   **高频**：香蕉、草莓、绿叶类（如阳光玫瑰）必须**一天一进**或**两天一进**。
    -   **中频**：苹果、橙子、梨等耐储存水果，可以**三天一进**。
    -   坚决不为了凑批发价而囤过多的高腐损水果。

### 二、在店中：保鲜与陈列技巧

1.  **分拣先行（到货第一件事）**：
    -   水果到店后，**第一时间**挑选出有磕碰、霉变的坏果，放在特价区（如“每日特价果篮”，按斤卖），**绝不能让烂果留在货架上**，否则会加速周围水果腐烂并赶走顾客。

2.  **先进先出（FIFO）**：
    -   新货放货架**后排/底下**，旧货放**前排/上面**。确保顾客先拿走的永远是旧货。

3.  **温度分区管理**：
    -   香蕉、芒果、木瓜、榴莲**不能放冷柜**（会冻伤发黑），放在常温阴凉处。
    -   草莓、蓝莓、樱桃、葡萄必须**冷藏存放**。
    -   西瓜、哈密瓜切开后必须裹保鲜膜冷藏。

4.  **陈列技巧（控制表面状态）**：
    -   货架上的量**少摆勤添**：台面上只摆一层或少量，不要堆得像小山（堆太多顾客翻动会碰坏）。卖空了再补新货。
    -   坏果**肉眼可见**：建议在收银台或入口设一个“特价处理区”，一旦发现品相稍差但没坏的，马上打折卖掉，回收现金流。

### 三、销售后：每日盘点与“追尾”清仓

1.  **每日闭店盘点（1分钟/品类）**：
    -   每晚关门前，看哪些货还有剩余。设定**鲜度红线**（比如草莓超过24小时、西瓜切开超过6小时），一旦触线，立即清仓。

2.  **“尾货”清仓策略（不要等烂）**：
    -   **黄昏特卖**：下午4-6点为销售高峰期，但对新鲜度敏感的顾客多。建议在**下午5点半后**，对肉眼可见发软或起斑的水果，直接5折或买一送一。
    -   **加工转化**：如果香蕉太熟，就剥皮做**香蕉牛奶**；如果苹果有磕碰，做成**水果捞**或**切块果盒**，按份装盒卖（比原价便宜一点），这是**最好的去库存方法**，能消化80%的轻微损耗。

3.  **建立“水果日历”**：
    -   不要逆季节进货。比如反季的西瓜在冬天贵且不甜，出货慢。应季水果（如夏天的西瓜、秋天的柿子）自然新鲜率高，进货量可以大一些，反季水果则严格少量多次。

### 核心口诀（每天执行）：
> **“坏果先挑、好果少摆、午后特价、晚市清空”**

**要点总结**：不要指望水果在店里能放几天。**水果店赚的钱，其实是“周转速度”的钱**。只要保证**当天进的高腐损水果（草莓、葡萄、香蕉）在打烊前基本卖完**，你的库存压力自然就小了。如果发现连续两天某种水果有剩，直接停止进货该品类一周，用数据替代感觉来管理。
