针对社区超市增加香蕉和苹果的采购选择，**建议采用“组合策略”**，即：**苹果优先本地批发（或周边产地直采），香蕉主要依靠稳定供应商**。

理由如下：

1.  **苹果（适合本地批发）：**
    *   **新鲜度与损耗**：苹果耐储存，但消费者看重“脆爽”。本地批发（或产地直采）能减少中间周转时间，通常水果表面更新鲜，卖相更好，且运输损耗低。
    *   **价格优势**：本地批发市场竞争充分，你可以根据当日行情灵活进货，单价通常比长期供应商便宜10%-15%，尤其适合走量的社区店。
    *   **风险提示**：本地批发价格波动大，且货源不稳定（受天气、节假日影响）。你需要有**快速处理尾货**的能力（如特价促销），否则容易库存积压。

2.  **香蕉（适合稳定供应商）：**
    *   **成熟度控制**：香蕉是典型的“后熟型”水果，需控制在树上七八成熟时采摘。稳定供应商能提供**统一标准的催熟处理**，并保证到货时的熟度均匀，减少你自行催熟的麻烦。
    *   **损耗不可控**：香蕉皮薄极易碰伤，且一旦过熟就全报废。本地批发市场良莠不齐，若买到熟度不均的货，损耗率可能高达20%以上，这远超你的毛利空间。
    *   **供应商价值**：稳定供应商通常能提供**退换货承诺**（如货损补偿）和**固定送货周期**，帮你锁定成本。

---

**具体执行建议（两步走）：**

1.  **苹果初期（前1-2周）**：先去当地一级批发市场（如距离你最近的果品批发市场），对比3-5家摊位的红富士/嘎啦等热销款。试探性拿货，每次控制在10-15公斤，测试你社区的复购率。后期若销量稳定，再考虑和其中2家建立固定拿货关系。
2.  **香蕉从第一天起**：直接联系2-3家本地做香蕉配送的商贸公司（或长期做水果生意的老店），要求对方提供**整箱净重、催熟标准（如“7成熟到仓”）及破损赔付比例**。签订简易合同，锁定每周到货量。避免在菜市场随机买散装香蕉。

**关键判断指标：**
- 如果你的社区店**日客流量 > 200人**，且店面有冷藏柜，可以适当增加苹果的本地直采比例。
- 如果你的店**面积小、放不下大量库存**，则建议苹果也适量用供应商，减少你的资金占用。

**温馨提示**：无论选哪种，**香蕉的陈列温度最好在14-18℃**，且不要和苹果混放（苹果释放乙烯会加速香蕉变熟）。先试运行1个月，用“周销量/进货量”的数据来决定最终侧重。
