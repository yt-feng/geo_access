在超市采购苹果和橙子时，判断大小规格是否适合门店销售，主要取决于**目标客群、定价策略和损耗控制**。以下是一套可直接操作的标准和步骤：

**一、 确定基础规格标准（参考行业惯例）**

- **苹果（以富士、嘎啦等主流品种为例）**：
  - **优质热销规格**：果实横径 **75mm-85mm**（约4两到6两/个）。
  - **大果/礼品规格**：85mm以上（6两以上），适合高价精品区，但走量稍慢。
  - **小果/散称规格**：70mm以下（3两以下），适合低价促销或儿童零食，但毛利低。
- **橙子（以脐橙、甜橙为例）**：
  - **主流热销规格**：果实横径 **70mm-80mm**（约4两-5两/个），单果重量较均匀。
  - **大果规格**：80mm以上（6两以上），适合礼盒或精品区。
  - **小果/特价规格**：65mm以下，通常用于做特价引流，品质稍差。

**二、 快速判断方法（现场执行）**

1. **肉眼比对法**：直接与标准物对比。例如，用超市常见的**一次性纸杯杯口（直径约70mm）**，苹果能正好卡住杯口即接近70mm；**一元硬币直径25mm**，可以快速估算。
2. **称重法（更准）**：随机抽选10-20个果子，用电子秤称总重，计算平均单果重。
   - 苹果均价在 **180-260克** 之间为佳。
   - 橙子均价在 **150-220克** 之间为佳。
3. **抽查均匀度**：在整箱中随机取出底层、中层、上层各5个，用游标卡尺或卷尺测横径。**最大与最小相差不超过5mm**为合格，否则大小不齐会导致顾客挑选慢、损耗高。

**三、 结合门店实际情况决策**

- **社区店/菜场店**：主销规格建议选**中果（75-80mm苹果、70-75mm橙子）**，因为家庭日常食用价格敏感，太大吃不完、太小没肉。
- **精品超市/高端社区**：可主销**大果（85mm苹果、80mm橙子）**，并配合独立包装，强调卖相。
- **促销引流时段**：可以进一小批**小果（65mm左右）**，标注“产地直采特价”，但注意小果容易脱水，必须快进快出。

**四、 关键损耗检查（比大小更重要）**

- **硬度和弹性**：苹果轻按果肩，橙子轻按果蒂周围，都应**略带弹性且硬挺**。如果发软或按下去凹陷，说明内部失水或快变质，再大也不好卖。
- **表观瑕疵**：苹果要求无虫眼、无大面积黑点（允许轻微红点），橙子要求表皮油胞细腻，无明显病斑。**大小合格但卖相差，会直接拉低客流。**

**五、 提供最终采购建议**

**行动清单：**
1. **优先采购中等偏大规格**（苹果75-80mm，橙子70-75mm），这是门店跑量最快、退货最少的区间。
2. **每次进货先抽样测10个果子**，计算平均单果重和核径合格率（低于90%拒收或压价）。
3. **对比供货商同规格价格**，如果散装大果价格仅比中果高10%以内，才值得考虑卖贵；如果差价超过20%，则中果为主。

**一句话决策公式：**  
**门店日常销售选“中等偏大、均匀度好”的货；活动促销选“小果特价”的货；礼盒或高档区才选“大果”的货。**
