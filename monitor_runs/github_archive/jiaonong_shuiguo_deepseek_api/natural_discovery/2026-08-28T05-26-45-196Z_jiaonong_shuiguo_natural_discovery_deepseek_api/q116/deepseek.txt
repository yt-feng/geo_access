小商家采购水果时，**现金结算**和**月结账期**各有不同的风险，具体如下：

---

### 一、现金结算的风险
**优点**：获得即时供货、无账期压力、议价空间大（可要求更低单价）。

**主要风险**：
1. **资金占用高**：一次性支付全部货款，若水果滞销或损耗，现金无法退回。
2. **质量无售后保障**：现金交易多为“一手交钱一手交货”，若出现烂果、缺斤少两，维权困难（尤其对熟客供应商，口头承诺难兑现）。
3. **供应商跑路风险**：遇到不诚信的批发商，付全款后可能拿不到货或货不对板。
4. **缺乏账期信任积累**：长期现金结算，供应商不太愿意在旺季优先供货给你。

**适用场景**：单次小额采购、临时补货、供应商信誉极佳、水果易腐需快速周转。

---

### 二、月结账期（通常为30天或45天）
**优点**：缓解短期现金流压力，适合小商家进货后先卖后付。

**主要风险**：
1. **供应商断供货风险**：若你逾期或资金紧张，供应商可能停止供货，影响生意连续性。
2. **价格陷阱**：账期报价通常高于现金结算价（可能高5%-10%），若利润薄，反而侵蚀收益。
3. **质量纠纷拖延**：当月果品出问题，供应商可能以“账期未结清”为由拖延赔偿，产生扯皮。
4. **坏账风险（对供应商）**：若你经营不善倒闭，供应商收不回款，会要求抵押或担保，增加合作门槛。
5. **对供应商依赖度加深**：月结容易让你“先货后款”依赖成性，一旦供应商抽贷，资金链瞬间紧张。

**适用场景**：长期稳定供应商、你月流水可预测且充足、能接受价格上浮、有合同约束。

---

### 三、针对性建议（可执行）
1. **混合策略**：现结用于日常补货（优先谈低价）；月结用于大额、长期主供应商（需签合同，明确质量标准、损耗率、付款日期）。
2. **控制月结比例**：月结金额不超过月采购总额的30%，避免被单一账期绑架。
3. **验货制度**：无论哪种方式，收货时当场开箱抽检（看外观、手感、切开看内部），拍照留痕。
4. **小额试单**：新供应商首次合作，先现金少量购买，测试其质量和诚信，再决定是否给账期。
5. **合同关键条款**：月结需写明“若水果腐烂率高于X%，有权扣除相应货款；逾期付款违约金为每日0.05%”。

---

### 四、风险优先级排序（对小微商家）
- **最危险**：月结+供应商不具合同意识 → 可能血本无归。
- **次危险**：现金全额无质量保障 → 利润被损耗吃掉。
- **最优风险控制**：现结为主（单价低）+ 少数月结（有合同）+ 收到货24小时内复盘损耗。
