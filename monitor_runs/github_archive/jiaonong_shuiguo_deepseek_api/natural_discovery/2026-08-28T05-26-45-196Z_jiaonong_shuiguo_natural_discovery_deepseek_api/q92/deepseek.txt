针对便利店这种**小面积、高周转**的业态，水果采购的核心逻辑不是“全而美”，而是**“小而精、快进快出”**。小门店最怕的不是没生意，而是**货架上的水果变成损耗**。

以下是从选品到出清的可执行方案：

### 一、品类控制：只卖“高频刚需”和“即食型”

1.  **严控SKU数量（单品数）：**
    -   建议日常在架**5-8个SKU**（单品）即可。少于3个显得冷清，多于8个容易积压。
    -   结构建议：**“2个引流款 + 3个利润款 + 2个功能款”**。

2.  **按“客群场景”选品（便利店客群画像：白领、夜归人、应急需求）：**
    -   **一口食水果（必须）：** 小番茄、蓝莓、草莓、切好的盒装果切（如西瓜、哈密瓜）。**这解决了“想吃但不想洗”的痛点**，毛利高且走量快。
    -   **即食型大单品：** 香蕉（永远的神）、苹果、梨。这些不需要试错，接受度高。
    -   **高端改善型（按季节上）：** 阳光玫瑰、草莓、车厘子。**只做“尝鲜”**，少量进货，卖完即止，不要当常规品。
    -   **坚决不碰：** 需要催熟的水果（如进口猕猴桃、榴莲整果）、体积过大的西瓜（除非能切开卖）、易腐烂的浆果（除非有冷藏展示柜）。

### 二、损耗控制：核心在于“分装”和“分级”

小店的损耗80%来自**“卖相变差”**。控制损耗分三步走：

1.  **源头采购策略（限制风险）：**
    -   **绝不押注整箱：** 尽量从本地批发市场拿货，而不是囤整箱。哪怕单价贵5毛钱，也要保证**能挑能选**。
    -   **验收标准：** 收货时要有**“三不签”**——不熟不签、过熟不签、有裂口/压伤不签。要当着送货人的面开箱检查。

2.  **陈列与分装（降低顾客翻拣损耗）：**
    -   **推行“不碰不选”模式：** 将散装水果尽量做成**盒装**。把“丑果”和“残缺果”提前挑出，**不要放在货架让顾客挑**。
    -   **分级销售（化损耗为利润）：** 把轻微碰伤但没烂的水果，切成果切盒，重新定价（比如原价苹果3元/个，果切拼盘卖5元/盒）。**这是最高级的损耗控制**，不要把坏果扔进垃圾桶。

3.  **动态补货与折价出清（紧盯保质期）：**
    -   **“一日两理”：** 早上理一遍，下班高峰前（下午5点前）理一遍。发现有软斑的立刻挑出。
    -   **临期三阶梯：** 当天下午3点后，对不耐放的水果（如草莓、盒装切果）进行**“8折→6折→买一送一”**的阶梯式促销，**坚决不带“隔夜果”过夜**（部分耐放品除外）。

### 三、给便利店管理者的“保命法则”

-   **用数据倒逼采购：** 如果某款水果连续**3天**日均销量不足5份，立即下架止损，不要觉得可惜，**减少上架品种就是减少损耗**。
-   **关注“每平米产出”：** 如果你的水果区不大，一个单品一天卖不出10份，就属于滞销品，必须清退。
-   **善用“组合销售”：** 比如和关东煮、酸奶绑定。“买酸奶+1元换购小番茄”，既清库存，又拉动关联销售。

**最后的核心建议：** 便利店水果最关键的是**“新鲜度即品质”**，顾客买的是“马上能吃”和“方便”。所以，**请把80%的冷柜面积留给“果切盒”和“小颗粒即食水果”**，这比卖大西瓜更符合便利店逻辑。
