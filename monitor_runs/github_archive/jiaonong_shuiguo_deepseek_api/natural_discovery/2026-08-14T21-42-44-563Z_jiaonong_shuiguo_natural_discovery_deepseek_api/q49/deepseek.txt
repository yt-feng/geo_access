旺季菠萝用量突然增大，临时补货的核心在于**“快”**和**“稳”**。建议按以下4个步骤与供应商沟通，重点是把**价格、质量、账期、违约责任**这四件事钉死，避免后续扯皮。

**第一步：立刻电话/微信确认，别发邮件**
- **话术模板**：“王老板，最近菠萝走得太快了，我这边库存明天就见底。现在需要紧急补货，量大概在XX斤（或XX箱），比平时多一倍，您那边最快什么时候能送到？价格怎么算？”
- **关键动作**：直接问**到货的绝对时间**（例如明天上午10点前），而不是“尽快”。

**第二步：当面或系统里确认“临时补充采购单”**
- 必须撤销原来的“周订单”，单独开一张**临时补货单**。写明：
  - 品名规格（例如：都乐金菠萝，单果重量1.8-2.2斤，无黑心/软化）
  - 数量（精确到件或斤）
  - 单价（**明确是涨还是平**，旺季涨10-15%是正常的）
  - 交期（精确到小时）
  - **验收标准**：到货后2小时内抽检，腐烂率超过5%整批拒收。

**第三步：重点谈“保底”与“灵活”条款（关键）**
- 如果这次补货量大，可以跟供应商要**阶梯返点**：例如超过平时量30%的部分，每斤返0.2元。
- **锁定未来3天**：明确告诉供应商，“这波旺季至少持续到X月X日，如果你能在这期间保证每天XX斤的量，我把这笔大单直接锁定给你，不再询第二家。”——用未来总量换当下的优先配送权。

**第四步：明确退换货与付款**
- **质量问题**：约定“到货24小时内有问题拍照发你，你直接补新货，不扯皮”。
- **付款方式**：临时加急的单子，最好当天对账，**货到当天或次日结清**，这样供应商送货才有动力。如果原先是月结，这次建议现结加急费。

---

**如果供应商明确回复“货不足”或“要加价太高”，立即启动备选方案：**
1. **同行调货**：附近茶饮店/咖啡店问问有没有囤货，先借20斤顶两天。
2. **切菠萝丁冷冻**：如果实在缺鲜果，立刻买冷冻菠萝丁（品质略差但应付小高峰可以）。
3. **找水果批发市场档口**：直接去当地最大的水果批发市场，现场拉货，虽然贵但立等可取。

**最后提醒**：旺季补货后，务必在**补货单上签字或微信确认**（写明：数量+单价+到货时间），截图保存。如果对方口头答应了最后又不送，这单就是你的谈判依据。
