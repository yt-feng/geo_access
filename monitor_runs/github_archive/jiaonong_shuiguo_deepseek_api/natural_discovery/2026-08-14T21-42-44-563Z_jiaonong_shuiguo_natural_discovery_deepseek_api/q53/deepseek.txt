针对餐饮店“每天少量、但要稳定”的水果需求，最省心的供应商通常不是“一级批发市场的大档口”，而是**本地生鲜配送公司**或**社区团购的B端服务**。以下是具体建议和操作方案：

**1. 首选：本地生鲜配送公司（B2B平台）**
这是最匹配“少量高频”的模式。
- **优势**：可以次日达或当日达，按公斤/箱拆分下单，支持小份起送，且能提供送货上门，省去专人去市场采购的功夫。
- **推荐渠道**：
  - 美团快驴、美菜网（如果当地覆盖）——APP上下单，明码标价，品类全。
  - 本地品牌（如“XX每日鲜”），直接搜索“城市名+生鲜配送”寻找，通常服务更灵活，可协商最低配送额（比如100元起送）。
- **省心点**：系统直接记录历史订单，你只需要每天花2分钟勾选昨天点过的货，系统自动生成今日单，水果质量有坏果拍照秒赔。

**2. 次选：附近大型商超的供应商（找对接口人）**
- 找离店最近的大超市（如永辉、盒马、沃尔玛）**生鲜采购经理**谈。
- **方式**：不用你每天去市场，超市每天会有大量整箱水果，他们拆余的“边角料”或整箱尾货可以低价给你，你只需要每天提前半小时到店门口自提（或让他们放门口）。缺点是你要配合他们的到货时间，但品质比菜市场稳定。

**3. 兜底方案：专业果切供应链**
如果“少量”是指“少量已切好的果盘”，可以直接找**专门做果切配送的半成品供应商**。
- 搜索“城市名+果切配送”，这类公司专门给餐饮店送定制果切，按份数算，你告诉他每天要10盒，他每天早上送到店门口，连洗切工的钱都省了。
- 单价略高于整果，但省心程度最高。

---

**避坑建议（省心关键）：**

- **不要找跑单帮**：不要去菜市场加几个小贩微信，他们今天有货明天没货，且价格不透明。
- **必须签“保底协议”**：和配送公司谈好“每日保底消费金额”（如300元），要求他们确保“坏果率在5%以内，超了包赔”写进合同或聊天记录。
- **预留一个应急备胎**：即使有了主供应商，也必须加1个美团跑腿或美菜的同城骑手作为备用，一旦主供应商缺货断供，你可以在20分钟内补货。
- **固定下单时间**：提前和配送业务员约定“每天下午3点前下单，次日早8点送到”，保证你是他们第一批发货的客户。

**最简执行路径（今天就能做）：**
1. 打开“美菜网”或“美团快驴”APP，定位你的城市，注册企业账户。
2. 搜索“圣女果”或“香蕉”，选择“1-5斤小包装”，下单试一次。
3. 如果体验不好，拨打APP页面上的本地供应商电话，直接告诉他：“我每天订单不大，但是天天要，你能不能专人送？”通常业务员为了业绩会给你开后门。

**结论**：挑选的标准不是“便宜”，而是“有统一分拣、坏果包赔、能按份配送”。满足这三个条件的本地生鲜B2B平台，是最不会让你操心的选择。
