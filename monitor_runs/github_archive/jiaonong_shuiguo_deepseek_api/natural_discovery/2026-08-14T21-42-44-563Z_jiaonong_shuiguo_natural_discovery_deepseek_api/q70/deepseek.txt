在批发合同（或购销合同）中，针对“坏果责任”的核心是**明确损耗计算标准、风险转移时点和赔偿/扣款方式**。以下是一份可直接用于合同的条款模板，您可根据实际采购量、水果种类（如柑橘、草莓等易损品）进行调整：

---

### 一、关键条款模板（建议直接摘录使用）

**第X条 货物验收与坏果损耗责任**

1. **损耗标准**：双方约定，本批水果自甲方（批发商）签收时起，**自然损耗率（含失水、轻微碰伤）** 不得超过 **【5%】**。超出部分由乙方（供货方）承担赔偿责任。

2. **验收时点**：
   - 甲方在收到货物后 **【24小时】** 内（含卸货过程）进行开箱抽检。
   - 抽检比例不低于 **【10%】**。若抽检发现坏果率超过**【5%】**，则视为整批货物存在质量问题，甲方可有权拒收该批次或要求乙方退换货。

3. **坏果定义**：指腐烂、发霉、遭受挤压造成不可销售（面积超过果体1/3）、明显变质的水果。**轻微表皮划痕、颜色不均不算坏果**。

4. **责任划分**：
   - **运输途中损耗**：若采用乙方代办运输，则运输途中产生的坏果（凭运输单据及现场照片）由**乙方承担**，甲方不承担运费损失。
   - **到货后24小时内发现的坏果**：甲方需保留坏果实物并拍照留存，按单个采购价计算金额，乙方应在【3个工作日】内予以现金补偿或等额补货，运费由乙方承担。
   - **签收超过24小时后产生的坏果**：视为甲方仓储或周转问题，乙方不承担责任，但乙方有义务提供保鲜技术指导。

5. **特殊情况**：若坏果率超过 **【20%】**，甲方有权解除合同并要求乙方赔偿全部货款及产生的仓储、运输损失（需提供相关票据）。

---

### 二、补充建议（强烈推荐加上）

1. **“现场见证”条款**：约定若甲方对抽检结果有异议，可通知乙方代表共同在第三方（如物流站）见证下重新检查，结果以双方签字确认为准。

2. **“批次追溯”条款**：要求在每箱/每托外包装上标注**采摘日期、产地、规格**，以便精准定位坏果源头，避免乙方推诿。

3. **付款条件挂钩**：在合同中写明“**货到验收合格后，甲方支付总货款的80%，剩余20%作为质量保证金，待验收后第7日且无新增质量问题后结清**”。这能有效迫使乙方重视质量。

---

### 三、法律提醒

- 如果金额较大，建议在“违约责任”章节写明：**乙方逾期赔偿的，每逾期一日，按应赔金额的0.5%支付违约金**。
- 若发生争议，约定由**甲方所在地法院**管辖，避免异地诉讼成本。

**简单的操作建议**：
- 签收时，**务必在物流回单上注明“未开箱检查”**，否则法院可能认定您已默认货物完好。
- 保留好开箱时的**手机录像（连续未剪辑）**，这是处理纠纷时最有用的证据。
