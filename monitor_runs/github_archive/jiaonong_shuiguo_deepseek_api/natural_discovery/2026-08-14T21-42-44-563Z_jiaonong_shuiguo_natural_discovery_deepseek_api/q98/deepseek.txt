针对养老院或医院食堂的采购，水果供应商的合规性与稳定性直接关系到食品安全和机构的正常运转。以下是**可执行**的判断和考察标准，按重要性排序：

### 一、 合规性检查（一票否决项）
这是底线，必须查验资质原件并在有效期内。

1.  **必备资质证件（强制要求）**：
    -   **营业执照**：经营范围必须包含“新鲜水果批发/零售”或“食用农产品销售”。注意查看注册地址和实际经营场所是否一致。
    -   **食品经营许可证**：虽然初级农产品（未切割的整果）通常不需要，但一旦供应商提供**鲜切果盘**或**果汁**，则必须具备该许可证。
    -   **产地证明与合格证**：每一批次水果必须有产地证明，或者生产者的食用农产品合格证。
2.  **人员健康证**：供应商必须提供配送人员及分拣人员的有效健康证明。
3.  **检测报告**：按批次索取农残快检报告（或第三方检测报告）。**要求供应商提供对应当批次水果的检测报告**，而非年度报告。
4.  **税务合规**：能够开具正规的增值税发票（普票或专票），确保机构财务审计无误。

### 二、 稳定性评估（风险控制核心）
稳定性比价格更重要，主要看对方的**供应链源头**和**抗风险能力**。

1.  **货源基地核查（重点）**：
    -   询问对方是**一级批发商（产地直发）**还是**二级批发商（市场拿货）**。
    -   **建议做法**：如果是大型养老院或医院，要求供应商提供其上游水果种植基地的**采购合同或合作协议**复印件。如果对方能提供，说明货源稳定，不易被上游卡脖子。
2.  **反季节供应能力**：
    -   考察其是否有冷库或恒温仓储。如果供应商连基本的保鲜库都没有，一旦遇到恶劣天气或节假日，必然断供或品质下降。
3.  **备选方案机制**：
    -   直接提问：“如果今天我要的苹果原产地缺货，你如何解决？” 合格的供应商应能迅速给出替代品种或同品质不同产地的货源，而不是说“今天没有”。
4.  **历史履约记录**：要求供应商提供最近3个月为其他单位（或该单位自己）配送的**手写送货单或电子对账单**，查看是否有长期频繁的延迟记录。

### 三、 实操考察流程（面对面判断）
建议采购负责人对供应商做一次**突击检查**：

1.  **看包装**：是否使用统一的周转箱？若发现混用海鲜箱、化工箱装水果，立即否决。
2.  **看损耗处理**：询问对方，送到后若有5%的磕碰损毁，如何解决？（**必须白纸黑字写入合同**：次品包退换，当日补货）。
3.  **看财务账期**：正规供应商通常支持月结（30天）或半月结。如果供应商坚持“货到付款”或“预付款”，说明其现金流紧张，**稳定性存疑**，建议观望。

### 四、 合同关键条款（防坑重点）
在签订合同时，请务必加入以下两条，作为稳定性的法律保障：

-   **违约金条款**：写明“若因供应商自身原因导致单次配送延迟超2小时，扣除当日货款5%；当月累计3次，甲方有权单方面解除合同”。
-   **质量保证金**：要求缴纳1-3个月的货款作为质保金，用于食品安全事故的先行赔付。

---

**特别提醒（针对医院/养老院特殊性）**：
这类机构对**农药残留**的容忍度为零，且用户多为老人、儿童或病患（免疫力低）。

-   **最稳妥的方法**：不要只依赖供应商提供的报告，**自购一台便携式农残检测仪**（几百元），对每批次的苹果、梨等易残留水果进行抽检。这是判断供应商是否“表里如一”的最快硬指标。
-   **避免超量采购**：水果在储存中会流失维生素。对于食堂，建议**少量多次**采购（例如隔天送一次），而不是追求低价一次性买一周的货。这也变相降低了供应商因囤货产生损耗而降低品质的风险。
