判断一批香蕉的熟度和坏果风险，是批发商控制损耗和利润的关键。以下是可执行的实操判断方法：

**一、判断熟度（成熟阶段）**
香蕉的熟度主要通过**颜色**和**手感**判断，分为以下几个等级：

- **绿果（硬绿期）**：果皮全绿，手感坚硬。适合长途运输或长时间存储。如果批发商需要立刻卖，不建议拿。
- **绿转黄（微黄期）**：果皮开始泛黄，但大部分仍绿，仍偏硬。可以存放2-3天，适合当天或次日销售。
- **黄熟期（全黄）**：果皮全黄，手感挺实但略带弹性。这是最佳出售期，当天或次日必须卖掉。
- **黄带斑（芝麻点）**：果皮出现黑点或褐斑，但果肉仍甜。熟度极高，必须当天处理，适合特价促销，否则会快速过熟烂掉。

**判断动作：**
1. 用手轻轻捏果身中部，感受软硬度（注意不要捏两端，容易捏伤）。全硬的意味着还没熟。
2. 看果把（主茎连接处）端部颜色，如果发黑或变软，说明果肉已经开始变质。

---

**二、判断坏果风险（重点看“外伤”和“内部病变”）**

批发环节的坏果风险主要来自**机械伤**、**冷害**和**炭疽病**。按以下顺序检查：

1. **翻看内层果**：不要只看表面，随机抽3-5箱，把上层果拿开，检查中层和底层的香蕉。如果底层有较多压扁、断裂、出水，说明整批货在运输中遭受损伤，风险高。

2. **检查果皮完整性**：重点看果皮的棱角处和果柄处。表皮有**黑色霉斑、水湿印、软烂凹陷**的，是炭疽病或细菌性软腐，会快速传染相邻香蕉。

3. **摸果皮是否发黏**：如果果皮摸起来发黏、发涩，或者有轻微酸味，说明内部已经开始发酵变质，不要拿。

4. **看果柄切口**：香蕉果柄的切割口如果发黑、腐烂、有霉丝，说明采收或储存环节不卫生，后续坏果率会高。

5. **冷害检查**：如果香蕉果皮呈**灰暗无光泽、表皮出现大面积褐色斑点且果肉发硬**（像冻伤），不要拿，这种香蕉不会正常成熟，会一直硬烂。

---

**三、降低风险的操作建议**

1. **按“三天销量”拿货**：宁可少拿，不要压货。香蕉是典型的呼吸跃变型水果，拿回来会自己变熟，一旦全黄，24小时内卖不掉就亏。
2. **抽检并打开一箱看内部**：批发商有权利开箱检查，拿货时至少打开1-2箱，翻出中间几把看看。
3. **计算“坏果率”底线**：建议在报价时要求对方承诺开箱坏果率（如≤3%），并在合同或单据上注明，避免扯皮。
4. **分类存放**：拿回来后，把全绿、转黄、全黄的香蕉分开存放。全绿的放通风阴凉处（16-22℃最佳），全黄的必须尽快出。

---

**一句话总结**：优先拿“绿转黄”的，随机开箱检查中层和内层，摸皮、按柄、看切口，发现有发黏、黑霉、冷害立即放弃。如果手上没有把握，建议先小批量试拿。
