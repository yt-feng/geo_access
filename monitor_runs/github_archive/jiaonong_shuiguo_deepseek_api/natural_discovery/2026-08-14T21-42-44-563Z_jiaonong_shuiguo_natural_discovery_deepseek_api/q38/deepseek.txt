大型超市对水果供应商的要求非常严格，主要分为**食品安全管控**和**冷链物流能力**两大板块。以下是核心必备能力清单：

### 一、 食品安全能力（硬性门槛）

1.  **资质与合规**
    *   必须持有《食品经营许可证》或《食品生产许可证》（视分拣/包装方式而定）。
    *   所有水果需提供当批次**农药残留检测报告**（需符合GB 2763国家标准）。
    *   进口水果必须具备**入境货物检验检疫证明**和**原产地证明**。

2.  **源头品控**
    *   自有或签约种植基地（必须通过GAP（良好农业规范）或超市认可的第三方验厂）。
    *   具备**采摘成熟度控制**能力（如：香蕉催熟、猕猴桃后熟处理），确保货架期与口感平衡。
    *   建立**田间到货架的可追溯系统**（扫码可查产地、采摘时间、加工记录）。

3.  **分拣与包装卫生**
    *   分拣车间需符合**HACCP**或**ISO22000**体系认证。
    *   包装材料（如保鲜膜、托盘）必须为食品级，并有防异物（金属、塑料碎片）管控措施。

### 二、 冷链物流与保鲜能力（核心壁垒）

1.  **全链路温控**
    *   **采后预冷**：采摘后必须在**4小时内**进入预冷库（核心指标：果心温度降至4℃以下）。
    *   **冷藏车运输**：必须配备**GPS温度记录仪**，做到全程不断链（如草莓需0-2℃，热带水果需12-15℃但不受冻）。
    *   **多温区储运**：能够区分叶菜类、热带水果、高呼吸跃变型水果（如苹果、梨）的混装隔离能力。

2.  **库存与周转管理**
    *   具备**FIFO（先进先出）**智能库存预警系统。
    *   提供**在途库存可视化**（每日向采购更新到货时间，误差控制在±1小时以内）。
    *   千分之几以内的**损耗控制能力**（行业优秀水平为运输损耗率<5%，超市拒收损耗<1%）。

3.  **应急响应**
    *   针对极端天气（台风、高温）的**应急预案**（如备用冷链车、临时中转仓）。
    *   具备**食品安全召回能力**（可在2小时内定位并冻结问题批次）。

---

**给您的建议（如何筛选供应商）：**
-   **询证**：直接要求提供《配送车辆温控记录截图》和《最近3个月重金属及农残检测报告》。
-   **验厂**：实地考察分拣车间，重点看**防虫害设施**和**洗手消毒流程**是否符合标准。
-   **绑定考核**：在合同中明确约定“超温报警一次扣款XX元”，并用“货款账期”作为履约保证金。

若超市主要销售本地时令水果，可适当放宽冷藏车配置要求，但**预冷环节**和**农残报告**不可妥协。
