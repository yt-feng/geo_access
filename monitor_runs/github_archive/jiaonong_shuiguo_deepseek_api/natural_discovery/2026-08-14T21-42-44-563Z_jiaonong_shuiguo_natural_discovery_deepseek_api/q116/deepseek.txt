对于小商家采购水果，**现金结算**和**月结账期**各有不同的风险，具体如下：

---

### 一、现金结算的风险

**优势**：价格可能更低（批发商喜欢现金），无账期压力，资金链清晰。

**风险**：
1. **质量无保障**：现金支付后，如果水果出现腐烂、短斤缺两、品种不符等问题，退换货难度大，维权成本高。
2. **供应商跑路**：一次性支付大额现金，若供应商经营不善或卷款跑路，损失无法追回。
3. **发票缺失**：现金交易常常没有正规发票，影响税务合规，审计时容易出问题。
4. **库存积压风险**：一次性现金采购量过大，若销售不畅，资金占压，且水果易腐，损耗率升高。

---

### 二、月结账期（赊账/月结30天等）的风险

**优势**：缓解短期资金压力，可以先卖货后付款，供应商对质量有顾虑时会更主动担责（因为尾款未结）。

**风险**：
1. **供应商赖账或拖延**：月结时，若供应商发次货、短货，或售后不配合，你因尾款在手，有一定制衡，但若合同模糊，容易扯皮。
2. **资金回笼风险**：你采购后卖给下游（如果也是赊账），若下游拖欠，你仍须按期付给供应商，可能造成资金链断裂。
3. **隐藏成本**：月结通常单价高于现金（供应商把资金成本转嫁给你），长期下来成本上升。
4. **合同风险**：若没有签书面合同，仅口头约定，发生纠纷时举证困难。
5. **逾期罚款**：月结合同常有“逾期每日罚息”条款，一旦忘记或资金紧张，罚款增加。

---

### 三、小商家实操建议（按风险排序）

1. **首单建议现金**：第一次合作，用现金小额试单，验证质量、服务和诚信。
2. **长期合作可谈月结**：合作稳定后，可谈月结，但**务必签书面合同**，明确质量标准、退换货条件、付款账期、逾期责任。
3. **控制赊账比例**：月结金额不要超过月销售额的30%—50%，避免被拖死。
4. **保留凭证**：现金要收据，月结要发票+送货单+验收单，拍照留档。
5. **分散供应商**：不要把所有鸡蛋放一个篮子，避免单一供应商出事导致断货或损失。

---

**总结**：现金结算是“低成本换高风险”，月结是“高成本换低风险”。小商家建议**首单现金、长期合同**，并在合同中明确质量与账期条款。如果无法核验供应商资质，优先选择现金+小额，避免踩坑。
