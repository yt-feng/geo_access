在超市采购水果时，作为采购方，通常需要供应商提供以下**核心检测报告**和**进货证明**，以确保食品合规、追溯可查：

### 一、必备的证明文件（资质与合法来源）
1. **营业执照**：供应商（生产商或批发商）的工商注册证明，确认其合法经营。
2. **食品经营许可证**（原食品流通许可证）：证明其具备食品批发或零售资格。
3. **产地证明**：能追溯到水果具体产地（如县级及以上农业主管部门或乡镇政府开具的产地证明）。
4. **农业生产基地的“三品一标”证书**（如有）：无公害农产品、绿色食品、有机产品认证及农产品地理标志。

### 二、针对水果品类的重点检测报告
通常要求供应商提供**同批次**或**近期1-3个月内**的第三方检测报告，至少涵盖以下指标：
- **农药残留检测**：《蔬菜水果中有机磷、有机氯、拟除虫菊酯等》农残指标（如GB 2763标准要求）。
- **重金属检测**：铅、镉、汞、砷等（尤其根茎类、叶菜类水果）。
- **真菌毒素**（特别是苹果、葡萄等易产生棒曲霉素、展青霉素的品类）。
- **其他特定项目**：视水果品种风险而定（如菠萝、芒果需检查链格孢毒素等）。

### 三、进货来源与批次信息
1. **进货发票或购销合同**：供应商与上游之间的交易凭证，用于追溯来源。
2. **送货单/出货单**：标明品名、规格、数量、生产/采摘日期、保质期。
3. **内部供货台账**：供应商自行记录每批水果采收、储存、运输的日志。
4. **运输证明**：若涉及冷链运输，建议提供车辆温度记录（如冷藏车温度监控单）。

### 四、针对进口水果的额外要求
若为进口水果，供应商还需提供：
- **海关进口报关单**
- **入境货物检验检疫证明**（出入境检验检疫局出具）
- **原产地证书**
- **中文标签及水果品名对应信息**（若供应商自营进口）

### 五、特别提醒（实战建议）
1. **核对批次一致性**：检测报告、送货单上的“生产日期/采收日期/批号”必须与实际到货水果一致，不能只看报告不看货物。
2. **报告时效性**：农药残留检测一般为1-3个月，如果水果是季节性库存（如冷库苹果），建议要求检测报告覆盖该存储批次的保鲜期。
3. **保留备份**：将供应商提供的所有证照需复印或扫描存档，每次进货后更新台账，便于食药监检查。
4. **对供应商分级管理**：对长期合作的大供应商，可要求其按月度提供统一检测报告；对散货小商贩，可要求提供产地证明+快速农残试纸检测（超市自检）作为补充。

如果供应商无法提供上述文件，建议**拒绝采购**，因为根据《食品安全法》，采购未查验许可证和相关证明文件将面临行政处罚。同时，超市自身可保留快检权利，抽检不合格的批次应及时下架并追溯。
