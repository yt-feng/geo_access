做社区团购水果，尤其是香蕉和菠萝这种高损耗品类，售后控制的核心在于**“源头选品分级 + 验收标准化 + 库存精准预估 + 前置沟通”**。

以下是一套可执行的实战方案，按环节拆解：

### 一、源头与收货端（把控损耗起点）

1.  **香蕉：只收“无青头、无爆裂”的七成熟货。**
    -   **实操：** 不要等全黄再收，到货后常温捂熟（乙烯催熟），收货时让供应商承担“熟度过高”的风险。验收时严格执行**“单箱烂果率超过2%整箱退回”**。
2.  **菠萝：买“青皮”比买“黄皮”更耐放。**
    -   **实操：** 全黄菠萝当天空耗，只适合少量试水。主推“微青/半青”果，收货时按“按压果眼位微软”为标准，硬邦邦的果客户反馈差，全软的售后爆表。

### 二、分拣与预处理（决定客户到手体验）

这一步是减少客诉的**关键**。

-   **香蕉：绝不整把卖，必须切条+包根。**
    -   根据团购份量，把香蕉切成**5-6根/份**的小把，用吸水纸或保鲜膜包住切口（重点包裹把柄处），再装袋。切开的伤口用保鲜膜包住，能延缓发黑。
-   **菠萝：能帮削皮就削皮，不能削皮要“高标”处理。**
    -   如果提供削皮服务，**必须提醒客户当天食用或冷藏不超过24小时**，并附赠盐水袋。
    -   如果卖整果，分拣时**必须剔除“果眼有黑斑、流汁、软塌”的果**，这类果直接挑出做福利特价，绝不可混入正品袋。

### 三、库存预估（高损耗的命门）

这两类水果是“今日果”，**坚决不留过夜库存**。

-   **计算公式：** 备货量 = 昨日销量 x **0.8**（保守系数）+ 当日特殊天气/节日加成。
-   **对策：** 宁可到晚上8点售罄被骂“怎么这么少”，也不要囤到第二天“烂在手里”。晚上7点半后，如果还有库存，立即群内发“清仓福利价”，优先消化尾货。

### 四、售后规则前置（降低赔付率）

水果售后不能等到用户拍了烂照再扯皮，要**主动设防**：

1.  **标准售后话术（群公告置顶）：** 写明“香蕉/菠萝属高损耗品，轻微擦碰、熟斑不在售后范围；**严重坏果（超1/3）或发霉，凭同一张坏果+包装照片，秒退款**（不退货，自行处理）”。
2.  **引导“晒图售后”：** 在群内主动说：“拿到手发现坏的，**直接拍一张坏果和包裹一起的照片发群里**，@团长直接退。”
3.  **赔付上限控制：** 别全额退，做**“比例退款”**。例如2斤香蕉烂了半斤，退1/4款即可，既保公平又控成本。

### 五、针对这两类品的特殊“防投诉”小技巧

-   **香蕉：** 发货时在袋内放一张**半熟状态的“绿色提醒卡”**，写“请勿放冰箱，常温放置1-2天更香甜”。这能有效防止客户因“太生”而投诉。
-   **菠萝：** 在袋外贴纸注明“**切记：削皮去眼后务必用盐水浸泡10分钟再食用**”，减少“吃了嘴麻/过敏”类投诉。

---

**执行摘要（照做即可）：**

-   **香蕉：** 切把包根防黑 + 八成熟+2%退货红线 + 尾货晚上9点前清掉。
-   **菠萝：** 硬皮检测标准 + 送盐水包 + 仅当天售。

如果每月售后率（按单量算）占比超过**3%**，说明不是售后问题，是**选品或分拣环节已经失控**，需要停售复盘，而不是单纯提高赔付红包额度。
