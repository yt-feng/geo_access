在便利店这种**小面积、高周转、低库存**的环境里，水果采购的核心思路是：**“小而精、快进快出、只做引流不做全品类”**。

以下是具体的实操建议，分为**品类控制**和**损耗控制**两块：

### 一、 品类控制：少而精，做“精选果切”和“基础果”

别把便利店当成水果店，你的SKU（单品数）**尽量控制在8-12个以内**，且要遵循“二八法则”。

**1. 必选刚需款（保销量）：**
- **香蕉**：永远的神，走量最大，成本低，对存储要求不高（常温即可），是吸引客流的首选。
- **苹果（红富士）**、**梨（皇冠梨/秋月梨）**：耐储存，损耗低，适合作为常备基础款。

**2. 升级引流款（拉毛利）：**
- **时令爆款（只做当季）**：比如夏天的西瓜（切块卖）、冬天的砂糖橘/草莓。只上1-2个当季最火的单品，风头过了立刻下架。
- **易操作高毛利款**：**蓝莓、小番茄（圣女果）**。这两个品类耐挤压、按盒卖，不需要现场挑拣，非常适合便利店。

**3. 绝对禁忌款：**
- **切开的散装高水分水果（如切开的菠萝蜜、榴莲）**：除非你有冷藏柜且周转极快，否则坚决不碰。
- **特殊热带水果（山竹、杨梅）**：损耗率极高，不折腾。

**4. 黄金补充：预包装果切**
- 这是便利店防损耗的**核武器**。如果门店面积小，尽量做**“现切果盒”**或**“提前预包装果盒”**（如西瓜盒、哈密瓜盒、混合果盒）。这样可以把品相稍差、卖相不好但没坏的水果“消化”掉，提高客单价。

---

### 二、 损耗控制：从“采购”到“售卖”的闭环管理

损耗不全是卖剩下的，**大部分损耗是买错了**。

**1. 采购策略：小批量、高频率**
- **坚持“日配”**：哪怕每天只进30斤，也不要一次性进90斤。便利店没有仓储空间，水果多放一天就是死一天。
- **看天订货**：下雨天、工作日早晨订货量减半，周末和晴天可以适当增加20%-30%。
- **反向采购**：每周统计**“烂掉扔掉”**的品类，哪个损耗超过5%，下个订货周期直接砍掉这个单品，别犹豫。

**2. 到货验收（损耗的第一道闸门）：**
- 验货时，**当场开箱看底**。水果店喜欢把好果放上面，烂果放下面。卸货时发现底部有压伤、水烂的，直接拒收或要求打折，这是硬性规矩。

**3. 门店陈列与保存（损耗的第二道闸门）：**
- **先进先出**：拆箱时写日期，老旧的水果摆前面卖。
- **常温与冷藏分开**：香蕉、苹果放常温阴凉处；草莓、蓝莓、切好的瓜类**必须进冷藏柜**，且冷藏柜温度保持在4-6℃。
- **“带伤处理”**：每天营业前挑出碰伤、轻微软烂的，**立刻**做成“当日特价果切”或“会员特价（例如：一元一个苹果）”，而不是等到烂透了再扔。

**4. 数据复盘（损耗的最后一道闸门）：**
- 每天记录：今天这个品类进了多少，卖了多少，扔了多少。
- **公式**：损耗率 = （进货量 - 销售量）/ 进货量。如果某单品的损耗率连续一周超过8%，立刻砍掉该品类。

---

### 三、 针对小店面的特殊“妙招”

1.  **巧用“收银台”**：在收银台放一个小的展示篮，只放3-4个精致的苹果或香蕉，很多顾客结账时会顺手带一个，这叫“冲动消费”，能显著降低库存压力。
2.  **不做“散称”做“份卖”**：别让顾客自己挑（挑剩的损耗最大）。所有水果按“份”或“盒”**固定标价**（如：一盒小番茄6元，一份香蕉2根3元），既保证了毛利，又避免了顾客反复翻捡造成的物理损耗。
3.  **建立“水果会员群”**：今天什么水果到货，晚上8点后有哪些“清货价”，直接群里发。利用预售和晚间清货模式，把损耗控制在晚上10点前。

**总结一句大白话：**
面积小就**别把水果当利润中心，把它当“引流品”**。用香蕉、苹果、小番茄这种好伺候的撑场面，用当季果切提毛利，一旦发现某个水果爱烂，下星期就**别进货了**。
