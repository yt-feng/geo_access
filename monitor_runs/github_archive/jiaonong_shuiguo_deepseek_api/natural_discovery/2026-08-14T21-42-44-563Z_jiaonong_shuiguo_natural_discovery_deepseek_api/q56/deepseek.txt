茶饮店在控制食品安全风险时，选择水果供应商（尤其是鲜切水果或原料水果）非常关键。供应商需要提供一系列证明，以保障从源头到门店的合规性。

以下是供应商必须或建议提供的关键证明文件清单：

**1. 基础合法经营资质（必须）**
- **营业执照**：确认其经营范围包含“食品销售”或“水果批发/零售”。
- **食品经营许可证**（或食品生产许可证，视其业态而定）：证明其具备合法的食品流通/销售资质。

**2. 产品来源与质量证明（核心）**
- **食用农产品合格证**（或产地证明）：这是证明水果来源合法、产地清晰的文件。对于需要追溯的品类（如香蕉、芒果等），能追溯到种植基地。
- **出厂检验合格报告**（或批次检验报告）：每批水果供货时，供应商应能提供当批次的外观、农药残留快检报告。
- **第三方检测报告**（至少每年一次或每季度一次）：针对高风险品种（如草莓、葡萄、柑橘类），需提供由有资质的第三方机构（如SGS、华测等）出具的**农药残留全项检测报告**。

**3. 特定风险管控证明（如适用）**
- **无重金属/污染物证明**：如果水果产自工业污染区附近，需提供土壤或产品的重金属检测报告。
- **冷链运输证明**（如为鲜切水果或需冷藏水果）：提供运输过程中的温度监控记录或冷链物流合作协议，证明运输全程符合0-4℃或特定温度要求。
- **鲜切水果生产许可**：若供应商提供的是预包装鲜切水果，必须持有《食品生产许可证》，且生产车间需符合国标（GB 14881或GB 31621）。

**4. 内部管理与追溯文件（加分项或建议）**
- **供应商管理制度及自查记录**：证明其有内部品控流程。
- **产品批号与追溯记录**：能提供每批水果的进货凭证和出库记录，确保一旦出问题能快速召回。

---

**给您的实操建议（如何落地）：**

1. **索证并归档**：要求供应商在首次合作时提供上述1、2类文件的复印件（加盖公章），并建立《供应商档案》。
2. **动态管理**：对于畅销或高风险水果（如西瓜、芒果），建议要求供应商**随货同行**提供当日或近三天的快速农残检测报告（可用胶体金快检卡）。
3. **签订协议**：在采购合同中明确约定，若供应商无法提供有效证明或产品不合格，需承担全部食品安全责任。
4. **内部抽检**：即使供应商提供了报告，建议门店在收货时，目测外观、抽查糖度，并根据风险对部分品种（如皮薄的葡萄、杨梅）进行快速盐水浸泡或使用农残速测卡进行二次把关。

**特别提醒**：如果供应商无法提供“食用农产品合格证”或“第三方检测报告”，建议谨慎合作，因为这是市面上主流茶饮品牌（如蜜雪冰城、喜茶等）的强制要求，也是规避《食品安全法》风险的重要防线。您可以将此要求直接写进供应商准入标准。
