采购香蕉和菠萝时，**起订量太高确实会增加损耗风险**，而且这种风险在水果品类中尤为突出。原因和具体建议如下：

**为什么风险高？**
1. **成熟度不一致**：香蕉和菠萝都是典型的“后熟型”水果。整箱采购时，箱内的成熟度往往参差不齐（有的青、有的黄、有的已过熟）。起订量高意味着到货后你很难在短期内消化掉，未成熟的可能还没熟就坏了，已成熟的可能放着放着就发软、发酸。
2. **存储条件苛刻**：
   - 香蕉对低温极敏感，低于11°C会变黑，但温度过高又加速过熟，腐烂极快。
   - 菠萝超过28天易变软、酸败，且切开后必须冷藏，损耗是“时间性”的，而不是单纯看总量。
3. **不可逆性**：一旦熟了，它们不会停止；一旦压伤或霉变，传染整个箱子。等量水果（如柑橘、苹果）可以常温慢慢卖，但这类热带水果撑不了几天。

**实操判断标准（可执行）**
- **计算“日消耗量”**：如果你每天能卖出约20根香蕉，起订量若超过5-7天的销量（例如140根/箱），损耗概率就极高。建议**单次采购量控制在3-5天内能卖完的量**，超期即风险。
- **看进货频率**：如果一周只采购一次，那起订量应远低于“周销量”；如果每天或隔天进一次货，可适量囤1-2天的量。
- **季节因素**：夏天（高温）和物流中转时间长时，起订量必须再下调20%-30%；冬天可略放宽。

**降低风险的具体建议**
1. **与供应商谈“分批分货”**：即便整箱起订，可以要求分两次送货（中间隔2-3天），供应商通常能接受。
2. **采购“半熟”状态**：香蕉选带柄、表皮青黄的，菠萝选果皮黄色但按压微硬的，给自己留3-5天缓冲期。
3. **到货后马上分级处理**：熟的放冷藏或拆开散放销售，生的单独存放。
4. **优先选择小规格包装**：香蕉通常有“小把装”（5-8根），菠萝有“小果型”，这些虽单价略高，但周转快、损耗低。

**简单结论**：如果起订量超过你**3天内的正常销量**，就应预警；超过**5天销量**，强烈不要订，除非你有冷藏柜或能快速分销（如做促销、切盘）。若订了，当天就得拆箱检查，成熟度不一致的立刻分开处理。
