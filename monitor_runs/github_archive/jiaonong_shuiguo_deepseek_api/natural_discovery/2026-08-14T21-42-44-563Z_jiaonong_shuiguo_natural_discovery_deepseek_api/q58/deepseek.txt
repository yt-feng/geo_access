在甜品店采购菠萝时，**“直接买成品果丁”通常损耗更低**，但具体要看你的使用场景。下面按损耗来源给你做个对比：

---

**1. 鲜果现切（自己买整菠萝切）**
- **生鲜损耗**：菠萝外皮、内芯、果眼等损耗率约 **30%~40%**（视菠萝品质和切配手法）。
- **时间损耗**：需专人清洗、削皮、挖眼、冲洗、切丁，单颗耗时约5~10分钟，高峰期容易积压。
- **库存损耗**：买来的整菠萝不能久放，若卖得慢，熟透或腐烂造成的丢弃损耗很高。
- **人工成本**：如果店里本来有后厨人员，可摊薄；但如果需要额外请工，人工成本会显著增加。

**2. 直接买成品果丁（预切鲜切菠萝丁）**
- **生鲜损耗**：买来基本零损耗（供应商已剔除废料，按净重计价）。
- **时间损耗**：开袋即用，几乎不占操作时间。
- **库存损耗**：需冷链保存，若开封后当天用不完，隔夜酸败风险高（但通常可以按需批量购入小包装）。
- **价格损耗**：成品单价通常比整菠萝贵15%~25%（包含加工和冷链成本）。

---

**结论与建议：**

- **如果甜品店菠萝用量大且稳定（比如每天固定做饮料、慕斯、蛋糕等）** → **直接买成品果丁更划算**（损耗低、出餐快、稳定性高）。
- **如果用量小、不固定，且后厨有富余人力** → 自己切整菠萝的原料成本更低，但需要你严格计算**废料+人工+损耗**，实际上未必便宜。

**额外提醒**：
- 无论哪种方式，你都要看供货商的**新鲜度**和**糖度**。成品果丁如果存放过久，风味和口感会变差。
- 如果用菠萝做高温烘焙（如果酱、烤菠萝），鲜切和成品差异不大；如果做冷饮或鲜切摆盘，成品果丁更容易控制大小均匀，颜值更好。

**最终建议**：先小批量试采购成品果丁对比一周，记录实际出成率、丢弃率和顾客反馈，用数据决定长期采购策略。多数甜品店在销量稳定后会倾向成品果丁。
