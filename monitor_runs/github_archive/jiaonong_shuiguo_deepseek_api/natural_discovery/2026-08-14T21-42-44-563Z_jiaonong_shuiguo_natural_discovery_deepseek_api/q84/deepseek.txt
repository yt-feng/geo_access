针对家庭团购的水果礼盒，建议以“**常温耐放 + 即食口感 + 色彩丰富 + 营养搭配**”为原则，首选以下组合：

---

**推荐组合（6-8斤装）：苹果2个 + 橙子2个 + 香蕉1把（约4-5根） + 菠萝1个（约1.5-2斤）**

**理由：**
1. **苹果**：耐储存，放一周没问题，给礼盒压秤。
2. **橙子**：补充维C，且橙子果肉紧实，不怕挤压。
3. **香蕉**：即食性强，孩子们爱吃，但熟得快，建议放在最上层，并用软纸包裹。
4. **菠萝**：香气浓，视觉上提档次，但需注意它会“催熟”其他水果（释放乙烯），所以**菠萝必须单独装盒或用塑料袋密封**，再放进礼盒。

---

**如果家庭人数多（4口人以上）或追求性价比：**
- 主选苹果+橙子各3个，菠萝1个，香蕉1把（不加葡萄、草莓等易烂水果）。
- 理由：苹果橙子不分时间吃都不踩雷，菠萝是点缀，香蕉是“孩子哄娃利器”。

---

**如果家里有老人或牙口不好：**
- 把菠萝换成**梨**或**哈密瓜**（切块装盒），香蕉保留，苹果削皮后切块，橙子剥皮分成瓣，避免困咬。

---

**包装建议（对家庭用户很关键）：**
1. 底部铺碎纸或泡沫垫，防止碰撞。
2. 香蕉和菠萝必须“独立放置”，否则香蕉会加速变黑，菠萝会被捂坏。
3. 在礼盒内放一张手写小卡片，注明“苹果请存放阴凉处，香蕉请勿冷藏，菠萝请尽快食用”，提升贴心感。

---

**成本参考（视当地市场价浮动）：** 如果用普通红富士、普通甜橙、普通香蕉和本地菠萝，礼盒总成本控制在40-60元比较合适；如果考虑高端礼盒（如阿克苏苹果+褚橙+进口香蕉+都乐菠萝），预算会到80-120元。
