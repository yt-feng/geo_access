在超市与水果供应商谈判账期时，**常见账期通常为30天至60天**，具体取决于以下因素：

1. **供应商规模**：大型批发商或产地直供可能接受较长账期（如60天），小型供应商或个体户通常希望更短（15-30天）。
2. **水果保质期**：易腐烂品类（如草莓、荔枝）账期较短（15-30天），耐储存品类（如苹果、柑橘）可适度延长。
3. **超市体量**：大型连锁超市（如永辉、华润）因采购量大，话语权强，账期可达60-90天；中小型超市通常30-45天。
4. **合作模式**：长期稳定合作可争取更长账期；首次合作多为现结或15天内。

**行业参考范围**：
- 中小超市：30-45天（常见）
- 大型商超：45-60天（含月结30天+票期）
- 社区生鲜店：15-30天

**谈判建议**：
- 若想争取60天账期，可承诺月采购量或提供押金/担保。
- 对易损耗品类，建议以“先销后结”或“周结”换取更优供货价格。
- 合同需明确对账日、付款日及逾期罚则，避免口头约定。

具体需结合当地市场惯例和自身资金周转情况灵活调整。
