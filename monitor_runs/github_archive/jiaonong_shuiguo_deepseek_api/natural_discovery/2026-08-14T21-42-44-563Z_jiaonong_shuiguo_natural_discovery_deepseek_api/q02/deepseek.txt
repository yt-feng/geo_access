对于小水果店来说，进货香蕉时，这四者的优先级建议如下：

**核心结论：熟度 > 坏果率 > 送货速度 > 价格。**

具体原因和操作建议：

1.  **熟度（最重要）**
    -   香蕉是典型的“呼吸跃变型”水果，采摘后还会继续成熟。进货时如果太生（全绿），顾客买回去要等很久，容易失去兴趣；如果太熟（出现黑斑、皮软），货架期极短，当天卖不完就只能报废。
    -   **判断方法**：进货时选**“黄中带绿”或“黄多绿少”**的香蕉，即大部分表皮已变黄，但果柄处和棱角处还有少量绿色。这样的香蕉放在店里常温下能保持2-3天最佳口感，给顾客留出购买窗口。

2.  **坏果率（直接影响毛利）**
    -   香蕉在运输中极其容易压伤、碰伤，一旦出现黑斑或水渍状软烂，整支蕉（整把）基本就不能按正常价卖了，损耗极大。
    -   **操作建议**：进货时当场拆箱抽查（至少开2-3箱检查中层和底层），**坏果率超过3%可以直接拒收或要求降价**。小水果店资金有限，宁可单价高一点，也不要进一堆“烂心”的蕉。

3.  **送货速度（影响周转）**
    -   香蕉保鲜期短，如果批发市场离店远，或者订货后隔天才到，那么熟度调控就很难。进熟度高一点的香蕉，隔天就全熟透了。
    -   **优先级判断**：如果你每天补货，并且供应商能**当天上午订货、下午或次日一早送到**，那速度问题不大。如果送货要2-3天，那熟度必须要求更生一些，并且要承担更多损耗风险。

4.  **价格（最后考虑）**
    -   香蕉单价不高，但损耗却很高。一斤便宜几毛钱，如果因为熟过头或者坏果多导致损耗10%，实际成本反而更高。
    -   **建议**：只拿“性价比合理”的价格，不要为了贪便宜进“处理货”或“尾货”。

---

**给你的实操建议（按天来做）：**

-   **订货量**：按“当天预计销量”来订，不要囤货。小店的香蕉周转周期最好**不超过2天**。
-   **进货时话术**：直接跟批发商说：“我要那种放2天还能卖的，黄中带绿，别给我顶熟或者带伤的。” 批发商知道你懂行，会给你更好的货。
-   **到货后处理**：到货后拆箱，不要堆太厚，平铺或用架子挂起来，通风透气，能延长货架期。

**如果只能选一个最重要指标，请务必选“熟度”。** 因为熟度不对，其他三项都白搭。
