生鲜平台要做水果的一件代发，供应商的仓配能力是整个履约链路的核心。如果这块跟不上，前面货源再好，后面投诉退款也会把利润吃掉。

供应商要具备的仓配能力，可以拆成**硬件设施**、**流程标准化**、**应急与成本控制**这三大块来看：

### 一、 仓储硬件与保鲜能力（这是地基）
1.  **多温区冷库（必备）**
    -   **保鲜库（0-4℃）**：存放大多数叶菜、浆果（草莓、蓝莓）、柑橘类。
    -   **催熟库/气调库**：针对香蕉、芒果、猕猴桃、牛油果等后熟型水果。**必须能控制乙烯浓度**，否则发出去要么是生的（硬邦邦），要么在路上熟透了烂掉。
    -   **周转冷库**：靠近打包区，用于当天订单的暂存和降温（预冷）。
2.  **预冷能力（核心差异点）**
    -   水果采摘后自带“田间热”，如果不做**强制预冷**（风冷或水冷），在常温下堆放几小时，保鲜期直接砍半。供应商必须要有能迅速把果心温度降到目标温度的设备或处理环节。
3.  **分拣分级区**
    -   不能靠人眼挑，至少要有**重量分级机**和**糖度抽检设备**（或者必须有严格的糖度检测SOP）。分级不精，件发出去的果子大小不一，平台差评率会飙升。

### 二、 一件代发的全链路作业能力（核心效率）
1.  **订单对接系统（IT能力）**
    -   **ERP/OMS系统必须能对接**：平台方（如抖音、拼多多、京东、小程序）一发货，供应商后台能自动抓取订单，自动生成面单。
    -   必须支持**多平台同步库存**，避免超卖（比如淘宝卖了100单，抖音也卖了100单，库存只有150，就会爆单导致缺货赔付）。
2.  **打包车间与耗材管理**
    -   打包必须采用**“冷链包装”**：珍珠棉/网套防撞 + 吸水纸/防潮垫 + **专业生鲜泡沫箱（EPP或EPS）** + **冰袋/冰瓶**（根据季节和距离计算冰袋数量）。
    -   包装必须**标准化**：不能徒手抓，要按重量/规格（如“中果5斤装”误差±50g）标准化装箱。
3.  **称重复核与质检关口**
    -   必须设有**逐单复秤**环节，防止缺斤少两。生鲜平台最忌“大的坏、小的酸、缺一两”。
    -   必须设有**发货前的人工抽检**（开箱检查有无压伤、霉变、糖斑）。

### 三、 仓储物流协同与应急能力（决定体验）
1.  **高效的拣货路径**
    -   仓库动线要合理：收货→预冷→储存→拣选→打包→称重→贴单→交货。**打包效率**至少要达到“单日每人打包数百单”的熟练工水平，遇到大促能快速扩产。
2.  **快递冷链合作网络**
    -   并不是所有快递都适合发水果，供应商**必须和主流冷链快递（如顺丰、京东、中通冷链、圆通冷链）签有协议价**，且清楚各快递在各区域时效的优劣（如发往新疆用X，发往江浙沪用Y）。
    -   必须清楚**“偏远地区停发”**的规则，避免超区导致猕猴桃在路上烂掉。
3.  **售后赔付的垫付能力**
    -   生鲜平台通常要求“坏果包赔”，供应商必须**有快速理赔资金池**和**清晰的理赔标准**（如坏3个内不赔，坏3个以上按比例赔，整箱全坏则重发/退款）。
    -   要有**补发应急库存**：预留少量同批次的良品库存，用于售后补发，不能等果季过了再补，那就没法补了。

### 四、 特别提醒（合规与成本陷阱）
-   **产地证明与资质**：要有《营业执照》、《食品经营许可证》或生产许可证（SC），如果做进口水果，要有报关单和检验检疫证明。
-   **库存管理**：生鲜水果是时效性商品，**不能用ERP的“静态库存”逻辑**，必须用“采摘在途量 + 冷库在库量 + 损耗预估”的动态逻辑，否则极易断货或缺货赔付。

---

**给你的实操建议：**
如果有平台找到你，或者你要去谈合作，建议先做一个**“48小时发货压力测试”**：让供应商在2天内发出100单测试件到不同省份，记录**货损率**（破损/腐烂率应低于3%-5%）、**时效**（偏远地区是否超过72小时）以及**包装箱是否变形**。这比看他们嘴上的承诺有效得多。

如果目前供应商只具备产地采摘能力，不具备上述冷库和预冷能力，也千万别硬接“一件代发”的活，建议先做“整车/整柜”的“一次性渠道批发”，等仓配能力补齐后再上平台。
