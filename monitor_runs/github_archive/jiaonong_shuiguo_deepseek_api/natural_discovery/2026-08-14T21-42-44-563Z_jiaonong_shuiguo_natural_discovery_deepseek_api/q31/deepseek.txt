连锁商超水果供应商招标的评分标准需要兼顾**长期稳定性、供应链能力、品质控制**和**成本竞争力**。以下是一套可执行的评分框架，供参考（总分100分）：

**一、商务资质与稳定性（20分）**
1. **企业规模与注册年限**（5分）：注册满3年、注册资本≥500万得满分；新成立或规模小酌情扣分。
2. **食品安全资质**（8分）：具备ISO22000/HACCP认证得满分；仅有常规营业执照得3分；有重大食安处罚记录一票否决。
3. **同类商超合作经验**（7分）：提供近2年为同等规模商超供货的合同或发票，每份得2-3分，上限7分；无经验但有明确管理方案得3分。

**二、供应链与产能（25分）**
1. **基地直采占比**（10分）：自有/长期合作基地证明（土地流转协议、采购合同）覆盖≥70%得满分，每降低10%扣2分。
2. **冷链与物流能力**（8分）：自有冷藏车≥5辆或与3家以上冷链物流商签约得满分；仅有常温运输扣3分。
3. **应急补货能力**（7分）：承诺12小时内补货到位得满分；24小时内得5分；48小时得2分。

**三、品质控制（30分）**
1. **农药残留检测**（10分）：提供每批次的第三方检测报告（SGS/华测等），且合格率100%得满分；缺少或合格率低于95%扣至0分并视为废标。
2. **商品损耗率承诺**（10分）：承诺进店损耗率≤3%得满分；3%-5%得6分；>5%扣至2分（需签订惩罚条款）。
3. **分拣与包装标准**（5分）：提供符合商超条码、规格、贴标要求的SOP文件得满分；仅口头描述得2分。
4. **质量追溯体系**（5分）：具备从产地到门店的全链追溯系统（扫码即可查到产地、采收日期等）得满分。

**四、价格与商务条款（15分）**
1. **报价结构**（8分）：采用“本埠批发市场均价±固定百分点”定价模式得满分；固定价模式得5分（需注明价格调整周期）。
2. **账期支持**（4分）：接受60天以上账期得满分；30天得2分；现款结算挑0分。
3. **价格调整机制**（3分）：每季度根据市场数据调价并约定波动上限（如周波动≤5%）得满分。

**五、服务与可持续发展（10分）**
1. **农残超标赔付方案**（5分）：承诺1:10赔偿及快速退货流程得满分；仅退货不赔得2分。
2. **绿色环保包装**（3分）：使用可回收箱体或月度减塑方案得满分。
3. **灾年保供方案**（2分）：提供极端天气下（台风、洪水）的备选基地清单得满分。

**关键提示**：
- 设置**强制性门槛**：无ISO认证、农残合格率不达标、有重大违约记录的供应商直接淘汰，不进入评分。
- 评分表需附**证明文件清单**（如合同复印件、检测报告日期），并在招标文件中声明“如发现造假，列入黑名单”。
- 建议对入围前3名的供应商进行**实地验厂**（检查基地、冷库温度记录），再按“评审分70%+验厂分30%”计算总分。
