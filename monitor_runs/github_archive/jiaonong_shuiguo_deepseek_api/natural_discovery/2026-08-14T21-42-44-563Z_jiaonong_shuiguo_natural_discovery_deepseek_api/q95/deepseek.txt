选择学校食堂水果供应商，建议从以下四个核心维度考察，并结合“试供期”来落地：

---

### 一、资质与安全（硬门槛，必须达标）

1. **证照齐全**：要求供应商提供营业执照、食品经营许可证、水果类检验检疫合格证明。如果是进口水果，还要有海关报关单和入境检验检疫证明。
2. **源头可溯**：能说清香蕉（多来自海南、云南、东南亚）、苹果（山东、陕西）、橙子（江西赣南、湖南）的产地或种植基地，最好有基地备案或合作协议。
3. **农残检测**：要求提供每批次或定期（如每月）的农残检测报告，优先选择有独立检测能力或与第三方检测机构合作的供应商。

---

### 二、品质与新鲜度（决定学生体验）

- **看卖相**：香蕉要表皮金黄、无黑斑，果柄不发黑；苹果要外观光洁、有自然香味；橙子要果皮紧实、有弹性，掂量有分量感。
- **分批配送**：水果怕挤压，建议要求按“一周两送”或“三天一送”的频率，避免一次送一整车导致底部闷烂。
- **冷链接力**：确认供应商有冷链运输车或至少冷藏仓库，特别是夏季高温时，进校前不能长时间露天暴晒。

---

### 三、报价与账期（控制成本）

- **比价方式**：不要只看单个水果的单价，要算“出肉率”或“可食率”。比如便宜的烂果多、损耗大，综合成本可能更高。建议让2-3家供应商分别报价，并注明产地和规格（如苹果80#，橙子直径7cm以上）。
- **账期协商**：学校通常有固定账期（30-45天），提前谈好，避免后续纠纷。如果供应商要求现结，则需视其规模谨慎选择。

---

### 四、售后与应急（长期稳定关键）

- **退换机制**：明确约定到货验收时，如有明显腐烂、碰伤，必须在24小时内无条件换货或扣款。
- **缺货替补**：要求供应商承诺如果某水果断货，能提供同等级替代品种（如用橘子替换橙子），且提前一天通知。

---

### 额外建议：

- **先试供2周**：不要直接签长期合同。签一个短期（如1个月）试供协议，考核出品质、准时率、损耗率、师生反馈，再转长期。
- **现场考察**：如果条件允许，到供应商仓库或配送中心看一眼，重点看分拣区域是否干净、是否有苍蝇、是否混放有毒物品。
- **本地优先**：优先选择本地或临近省份的供应商，物流时间短，水果更新鲜，且售后响应快。

---

**总结打分模板（建议用表格）**：
| 项目 | 权重 | 打分（1-5） |
|------|------|-----------|
| 资质证照 | 30% |    |
| 新鲜度与配送 | 30% |    |
| 价格与账期 | 20% |    |
| 售后与应急能力 | 20% |    |

综合得分最高的，再结合试供表现做最终决定。
