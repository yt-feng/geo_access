甜品店采购香蕉时，要避免到店后很快变黑，关键在于**选对成熟度、控制储存环境和缩短周转时间**。以下是可执行的具体建议：

**1. 采购时：明确成熟度标准**
- 不要买全黄或带黑点的香蕉。**首选“绿蒂、黄皮、个别略带青边”的香蕉**（即七八成熟）。全黄或软熟的，到店后一两天就会爆发性变黑。
- 如果甜品常用（如做香蕉船、切块），建议采购**“果皮颜色均匀、手感微微发硬但能捏动”**的。过于生硬的（全绿）会涩口，但可以常温催熟后使用。

**2. 到店后：立刻改变存放方式**
- **不要整箱堆放**。香蕉自产乙烯气体，密闭纸箱内会自我催熟并加速变黑。到店后必须**拆开包装，通风透气**，平铺在干燥的货架或托盘上。
- **不要和苹果、梨、牛油果混放**。这些水果释放大量乙烯，会迅速催熟香蕉。
- **避免与热源/阳光直射**。甜品店后厨的热风炉、蒸箱附近绝对不要放，最佳温度是13-20℃。

**3. 关键技巧：用乙烯吸收剂**
- 在香蕉存放区放**专用乙烯吸收剂（如高锰酸钾氧化铝颗粒）**，淘宝/批发市场有售，几块钱一包，能显著延长变黑时间。如果没有，可以在香蕉底下垫一层干毛巾吸湿，降低局部湿度。

**4. 日常管理：按需催熟，分批上货**
- 先进先出原则，先到先卖。
- **当天需要的量提前12小时从冷库/常温区拿到前场**，不要一次全部摆出来。用多少，拿多少。
- 如果做奶昔或烘焙，**变黑的香蕉可以直接冻进冷藏室（不去皮，密封袋）**，冻过的香蕉口感顺滑，且不会影响成品颜色，能减少浪费。

**5. 特别提醒（甜品店特有）**
- **不要将剥好的香蕉片泡在水里**，会加速褐变（氧化），应现切现用。
- 如果做冰淇淋或慕斯，可以用**冷冻香蕉泥**替代新鲜香蕉，采购时选择冷藏运输的即食型。

**总结执行清单**：采购选微青硬果 → 到店拆箱通风 → 单独存放+乙烯吸收剂 → 分批上架，按需催熟。

如果到店后已经出现局部黑点，不影响内部果肉的情况下，可以快速剥皮后泡入柠檬水（每500ml水加1勺柠檬汁），可临时防止切面氧化，但只能维持2-3小时，适用于即将使用的甜品。
