在商超水果采购中，**损耗率对最终毛利的影响通常远大于采购价格**。这是零售行业（特别是生鲜品类）的核心规律。

具体可以从以下几个维度来拆解，便于你直接用于决策：

**1. 数学上的**杠杆效应**（以苹果为例）**
假设售价固定为10元/斤：

-   **采购价从5元降到4元**（降幅20%），如果损耗率是10%，毛利从5元变成约5.4元，利润提升约8%。
-   **采购价不变（5元），但损耗率从10%降到5%**，毛利从5元变成5.25元（损耗减少的那5%的货直接变成了可售货品），利润提升约5%。
-   **关键点**：如果采购价低10%但损耗率高15%（比如低价果成熟度过高），很可能**利润直接归零甚至倒亏**。因为低价果往往伴随更高的次品率、更短的货架期。

**2. 损耗是“滚动”的，价格是“一次性”的**
采购价只影响**进货那一刻**的成本。但损耗每天在发生：

-   **价格影响**：一次采购，一笔账。
-   **损耗影响**：每天理货、扒皮、丢弃、打折处理，每天都在吃掉利润。**损耗是复利式的侵蚀**，而价格是一次性差异。

**3. 损耗对残值处理的影响**
水果一旦损耗，部分还能降价卖（残值），部分只能报废。你低价采购的水果，如果损耗多，最终废品率往往更高，处理成本（人工、垃圾清运）也更高，进一步压缩毛利。

**4. 实操结论（可直接执行）**
-   **如果你同时遇到两个供应商**：价格贵10%但损耗率低5%的供应商，**通常更优**（前提是售价不受影响）。
-   **如果你正在砍价**：优先砍**采购价**，因为谈判空间大；但**验收标准要更严**（比如成熟度、碰伤率、包装防护）。
-   **日常管理中**：**损耗是可控的**（通过订货量、陈列、售卖节奏），而**价格是市场波动的**（不可控）。你管理损耗的每一分钱，都是纯增的毛利。

**一句话总结**：
**对于水果这种短保、高波动商品，损耗率是决定毛利下限的“生死线”，采购价是决定上限的“加油门”。非要二选一，一定要优先控制损耗。** 如果你所在的卖场客流量极低，那么价格影响会相对变大，但绝大多数情况下，损耗是首要矛盾。
