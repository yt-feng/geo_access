采购香蕉用于茶饮店饮品或甜品时，熟度控制是产品口感和出杯稳定性的核心。香蕉的熟度直接影响其甜度、糯度和褐变速度，不适合“一刀切”。

以下是按用途和操作流程分类的控制方案：

### 一、按产品用途确定目标熟度（核心原则）

| 用途 | 理想熟度（斑点状态） | 口感特征 | 原因 |
| :--- | :--- | :--- | :--- |
| **奶茶/果茶（打底/挂壁）** | 9-10成熟（表皮大量黑点，果肉软糯） | 香甜、绵密、无涩味 | 成熟香蕉淀粉已转化为糖，易压成泥，与奶类融合度高；青涩香蕉会有生腥味和收敛感。 |
| **冰沙/思慕雪（搅拌用）** | 8-9成熟（表皮黄中带少量黑斑，果肉微软但不变软烂） | 清甜、有果香、纤维感少 | 搅拌时需快速打碎，过熟果肉纤维断裂后易出水，导致冰沙稀薄；稍硬的果肉能提供更好的体积感。 |
| **甜品/烘焙（香蕉蛋糕、布丁、班戟）** | 10成熟（表皮深褐色，果肉极端软绵） | 焦糖化香气浓郁 | 烘焙加热会进一步释放甜味，极熟香蕉能替代部分糖分，并增加湿润度。 |
| **装饰/切片（摆盘、果捞）** | 7-8成熟（表皮全黄无斑，果肉有弹性但已无色生） | 外形完整、不易褐变 | 过熟香蕉切片后会快速氧化发黑，且一碰就烂，无法保持形状。 |

---

### 二、采购时的具体操作标准

1.  **不要直接按“颜色”下单，要按“到店时间”下单**
    -   香蕉在运输和存放中会持续催熟。如果供应商送货当天就需使用，应要求**7-8成熟（皮黄青头）**，到店后自然放置1-2天达到最佳状态。
    -   如果采购量大需要一周内用完，必须进冷库（10-13℃）延缓熟化，采购时选**7成熟（整体偏黄带青）** 即可。

2.  **验收时用“指压法”分级**
    -   **轻按果柄端**（非果腹）：果肉略微凹陷且弹性恢复慢 = 9-10成，适合当天做泥。
    -   **按压果腹**：能感觉到柔软但无液体渗出 = 8-9成，适合冰沙。
    -   **按压明显坚硬** = 6-7成，不适合立即使用。
    -   **表皮出现大面积水渍状或果柄开裂** = 已过熟，拒绝收货（可能已发酵产生酒味）。

3.  **建立“日转熟”台账**
    -   到货后按熟度分为三批：**立即可用（黄多青少）、次日可用（青黄对半）、三天后可用（全青）**。在箱体上贴标签写明到货日和预期使用日，出库时遵循“先进先出”和“最熟先用”。

---

### 三、特殊场景处理建议

-   **若当天急需但只买到偏青香蕉**：不要用微波炉或烤箱催熟（会破坏果肉结构）。可将其与成熟苹果或梨一同放入密封牛皮纸袋，室温（20-25℃）静置18-24小时，次日即可变软，但香气会略淡。
-   **若临时收到过熟香蕉**：优先用于“香蕉泥/果酱”或“烤香蕉片”，避免直接切片装饰。如果发出酒精味，无论多甜都建议废弃，以免影响饮品风味。
-   **饮品店省成本方案**：采购“特级”或“次果”（表皮有划伤但果肉完好），但必须要求**9成熟以上**，因为次果本身偏生，到店后往往来不及催熟。

---

### 四、关键执行清单（可直接张贴）

-   **每日开档**：检查果库香蕉，按斑点数量排序，优先使用斑点最多的。
-   **出杯前**：去皮后若发现果肉中心有深色胶囊状（过熟籽），需剔除后再打泥。
-   **保存**：未剥皮香蕉**绝不冷藏**（皮会快速变黑），必须室温避光；已剥皮或切片的香蕉立即冷冻或浸泡柠檬水（1%浓度）防止褐变。

**最终建议**：如果没有大量仓储条件，宁可每日少量多次采购，也不一次性囤货。采购清单上建议固定写“**需黄带青，无黑斑，果柄新鲜，果肉硬实可压软**”，并要求供应商提供“到货后可存放≥3天”的批次。
