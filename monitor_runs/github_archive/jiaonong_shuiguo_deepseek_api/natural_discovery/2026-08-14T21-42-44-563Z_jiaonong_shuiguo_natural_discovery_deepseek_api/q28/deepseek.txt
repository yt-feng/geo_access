从超市引入进口水果的稳定性与市场接受度来看，**建议优先从进口香蕉开始**。

理由如下：

1. **市场接受度高**：香蕉是国内消费量最大的水果之一，消费者对进口香蕉（如菲律宾、厄瓜多尔等产地）的认知和购买习惯已经成熟。苹果虽然国内供应充足，但进口苹果（如美国、新西兰）价格高且消费群体较窄。

2. **供应链稳定**：进口香蕉的冷链运输和催熟技术相对标准，损耗可控。菠萝（尤其带叶鲜菠萝）在运输和储存中对温湿度更敏感，货架期短，管理难度大于香蕉。

3. **价格风险低**：香蕉全年需求平稳，进口价格波动相对可控；菠萝有季节性，且产地集中，供应受气候影响大。

**操作建议**：
- 首批建议引入小规格（如5-6根装）的菲律宾或厄瓜多尔香蕉，定价略高于国产（如+15%-20%），作为试水。
- 每周订货量先按现有销售量的20%-30%设置，观察2-4周动销率。
- 如首月动销率超过60%，再考虑逐步扩展至进口苹果（如爱妃、红玫瑰）或菠萝（如MD2品种）。

**不推荐**：不建议从菠萝开始，因为其损耗率高，若没有专业催熟和切割展示流程，容易造成批次亏损。苹果可作为第二阶段的补充品类。
