水果店遇到坏果（通常称“破损果”或“变质果”），结算或赔付方式主要取决于**你与供应商的合作模式**（代销、买断、一件代发等），以及**合同中是否约定了损耗率**。以下是不同情况下的标准处理流程和赔付规则：

### 一、先分清“损耗责任”归属
1. **运输途中损坏**（物流挤压、挤压腐烂）：责任方通常是物流，但一般由供应商代赔（因为供应商负责发货）。
2. **到货后自然损耗**（如香蕉、草莓自然熟透、轻微压伤）：属于合理损耗，通常**供应商不赔**，由门店承担。
3. **到货时已发现霉变、腐烂、水伤**：属于供应商发货质量问题，**供应商全赔**。
4. **存放不当导致坏果**（门店堆放过高、冷藏温度不对）：供应商不承担责任。

### 二、不同采购模式的结算方式

#### 1. 代销模式（供应商寄售，结售完再结算）
- **结算公式**：实际结算金额 =（卖出总量 + 免费处理量）÷ 到货总量 × 采购价 − 损耗费用。
- **坏果处理**：到货时挑出的坏果，拍照留证后，由供应商确认重量，按**采购价全额扣款**。
- 若到货后未及时卖完，储存期超过正常新鲜度（如叶菜48小时、芒果5天），剩下坏果归门店自己承担。

#### 2. 买断模式（现金进货，货权归你）
- **到货时验收坏果**：当场开箱验货，将坏果单独码放，拍照+称重，发给供应商。
- **赔付标准**：
  - **有明确合同**：按合同约定的“坏果率”（如5%以内不赔，超过5%的部分按进货价赔付）。
  - **无合同/临时采购**：通常按“坏果重量 ÷ 总重量 × 进货总价”计算赔付金额，要求供应商在下一批货款中抵扣，或直接退款。
- **注意**：不要自行丢弃，先拍照保留证据，否则无法索赔。

#### 3. 一件代发（线上平台发货，如拼多多/美团）
- 订单中出现的坏果，由平台介入处理，通常赔付标准是**按单个商品售价退款**（坏1个退1个）或**整单退款**。
- 你需要先向平台提交坏果照片，平台会从供应商保证金中扣除赔款给你。

### 三、标准赔付计算公式（供谈判使用）
```
赔付金额 = （验收时坏的重量 ÷ 到货总重量）× 进货总金额
```
或
```
赔付金额 = 坏果数量 ×（进货单价 ÷ 单件平均重量）
```
> 举例：你进100斤芒果，进货价每斤3元（共300元），到货坏了8斤，则赔付 = 8/100 × 300 = 24元。

### 四、实际操作建议（必须做）
1. **收货时验货留证**：开箱时录视频，逐一翻看，凡有霉斑、软烂、出水的果子，单独拍照+称重。
2. **第一时间报损**：到货后24小时内（越快越好）把照片和重量发给供应商，要求其确认“可赔付”。
3. **写清合同条款**：明确定义“正常损耗率”（建议水果5%以内，热带水果10%以内），超过部分供应商全赔。
4. **区分“可索赔”与“不可索赔”**：轻微磕伤、表皮斑点、熟透软果，一般不计入赔付；发霉、腐烂、流汁、有异味必须赔。

### 五、特殊提醒
- **不要用“不结账”来威胁**：除非供应商明显违约，否则不建议扣货款，容易引起纠纷甚至被停止供货。
- **若供应商拒绝赔付**：保存好证据，向当地市场监督管理局投诉（合同纠纷），或不再与其合作。
- **长期供应商**：建议在合同中加入“坏果率赔付条款”，并把赔付周期写进账期，如“赔付金额在下次结算时直接抵扣”。

如果供应商是水果批发市场档口，通常他们是不赔“自然损耗”的，只赔“明显运输损坏”，这种情况建议你**进货时按实际重量付款**，坏果当场让摊主捡出来，或在付钱时直接扣除对应金额。
