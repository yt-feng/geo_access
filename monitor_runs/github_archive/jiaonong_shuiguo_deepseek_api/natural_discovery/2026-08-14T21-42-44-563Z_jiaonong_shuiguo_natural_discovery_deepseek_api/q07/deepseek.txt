针对水果礼盒的搭配，核心原则是 **“好看、吉利、耐放、有层次”**。  
以下给你一套可以直接落地的搭配方案和避坑建议：

---

### 一、最稳妥的爆款组合（适合走量）
**苹果 + 橙子 + 香蕉 + 菠萝** 本身已经是一个**经典“平安吉祥”组合**：
- 苹果（平平安安）
- 橙子（心想事成）
- 香蕉（招财进宝/甜蜜）
- 菠萝（旺来/好运）

**推荐具体比例（6-8斤规格）**：
- 苹果 2-3个（红富士，颜色红）
- 橙子 3-4个（脐橙，颜色橙黄）
- 香蕉 1把（约1-1.5斤，绿皮微黄，不易压坏）
- 菠萝 1个（中等大小，留长叶，显得大气）

> 关键：**香蕉必须选微绿皮的**，否则在盒内闷一天就黑斑。菠萝要挑**叶子挺拔**的，视觉效果最好。

---

### 二、按人群场景调整（提高溢价）

| 送礼对象 | 调整方案 | 理由 |
|---------|---------|------|
| 长辈/祝寿 | 香蕉换成**石榴**或**弥猴桃**，菠萝换成**火龙果** | 石榴多籽（多子多福），火龙果红火 |
| 探望病人 | 去掉菠萝（酸性刺激），换成**哈密瓜/西瓜**，苹果减量 | 菠萝偏酸，且部分患者忌口 |
| 拜访朋友/同事 | 保持原组合，但**全部选小果**，做成小礼盒 | 一餐吃完不浪费，单价上也更好接受 |
| 高端礼盒 | 把菠萝换成**进口青提**或**车厘子**，橙子换成**血橙** | 颜色对比更鲜明，溢价空间大 |

---

### 三、具体操作细节（避免售后差评）

1. **底层放香蕉**（最怕压），**中间放苹果**，**上层放橙子和菠萝**。  
2. **菠萝周围垫干草或气泡膜**，它的刺容易扎破其他水果。  
3. 每样水果上贴**红色“平安”“吉”“旺”**小贴纸，成本5毛钱，客单价能提升10元。  
4. 盒内放**一张手写祝福卡**，比任何促销词都管用。

---

### 四、避坑提醒（非常重要）
- **不要放葡萄/草莓/蓝莓**，极易压碎，售后率极高。
- **不要用熟透的香蕉**，一过夜就全黑。
- **不要用青苹果**，卖相差且酸，用户会投诉。
