为社区超市挑选每日配送的水果供应商，建议从以下几个核心条件入手，优先保障稳定性和品质：

**1. 供货稳定性与频次**
- **每日配送能力**：确认对方是否承诺每日（含节假日）定时送达，缺货预警机制如何。
- **旺季/淡季保障**：夏季或台风季等天气波动期，是否仍能保证主要品类不断供。

**2. 水果品质与新鲜度**
- **验收标准**：要求供应商提供可执行的残次率（如按重量或个数，通常≤3-5%）、损伤赔付规则。
- **批次可追溯**：能明确告知每批次的产地、采摘时间，最好有基地直采或稳定合作农户。

**3. 价格与成本结构**
- **比价基础**：同一品种、同一规格下对比同行批发价，警惕低于市场价20%以上的“超低价”（可能有质量问题）。
- **账期与优惠**：日结、周结或月结的账期灵活性，以及整箱采购折扣。

**4. 配送与损耗控制**
- **冷链/保鲜条件**：是否有冷藏车或在途保鲜措施（泡沫箱+冰袋），这对夏季草莓、浆果类尤其重要。
- **补货响应速度**：临时加单（如天气热导致销量暴增）时，能否在2-4小时内补送。

**5. 品类丰富度与推荐能力**
- **应季品种更新**：能否按月提供应季水果清单，帮助超市引流。
- **搭配建议**：是否根据社区客群结构（年轻家庭/老年群体）推荐适销品（如普通苹果 vs. 高品质晴王葡萄）。

**6. 合同与售后**
- **退换货条款**：当日到货发现质量问题（如腐烂、碰伤），能否直接按比例扣除费用或次日补货。
- **违约赔偿**：明确约定“晚到/缺货”时的赔偿标准（如按日销售额的X%）。

**实际操作建议：**
- 先要求对方提供**3天试送期**，实际测试每日质量、数量和到岗时间。
- 高峰期（如周末）随机抽检2-3批，观察残次率是否稳定。
- 对比2-3家供应商，重点看**售后态度**，千万别只看单价。

如果无法核验对方货源资质（如产地证明、检疫证明），建议书面要求对方提供，避免后期因食品安全问题被追责。
