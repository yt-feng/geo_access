学校食堂在采购香蕉时遇到“熟过头”的问题很常见，尤其是大批量采购时。要避免浪费，核心在于**分级采购+周转管理**。以下是具体可操作的策略：

### 一、采购环节：分级与错峰
1. **按用途分级采购**  
   - **当日即食档口**：采购全熟（黄皮带少量褐斑）的香蕉，供当天领取或直接食用。  
   - **备餐/加工档口**（如西点、甜点）：采购偏生（青黄皮）香蕉，利用后熟期，在仓储过程中恰好成熟。  
   - **长期库存**：可少量采购青色硬香蕉（耐储存，约5~7天成熟）。

2. **与供应商约定“看货制”**  
   在合同中明确要求供应商在供货前提供每批香蕉的成熟度照片，或约定按“成熟度梯队”发货（例如每周分两批，一批偏生、一批略熟），避免一次性到货全部已熟。

3. **采用“成熟度模型”**  
   香蕉按颜色分7个等级（1=全绿，4=黄绿，6=全黄，7=褐斑）。食堂可以要求收货时成熟度在**3~4级（青黄转黄）**，留出2~3天出货窗口。

### 二、仓储与周转：先进先出
4. **物理分区**  
   在储藏室划分“已熟区（黄色）”、“待熟区（青色）”和“过期区”。已熟区放在取货最便捷处，待熟区放在通风阴凉处。

5. **气温控制**  
   - 若存储温度低（15℃以下），香蕉会停止成熟并变黑，注意不要放进冷藏室（除非直接食用前取出回暖）。  
   - 夏天若温差大，可放置少量苹果或乙烯发生袋，但**务必标明启用日期**，避免过度催熟。

6. **一周两次盘点**  
   每天早班与晚班登记“已熟数”和“次日预估需求”，优先取用最熟的。如果当天取用不完，立即改为制作防腐菜式。

### 三、现场消耗与加工
7. **优先做“临期加工”**  
   当香蕉进入5~6成熟度（全黄但无褐斑），且当日未卖完，第二天可：
   - 做成**香蕉奶昔/酸奶杯**（需搅拌，掩盖过熟外观）；  
   - 切块加蜂蜜做成**无添加果酱**（分装冷藏）；  
   - 与燕麦、鸡蛋做**烤香蕉松饼**（适合早餐窗口）；  
   - 若完全软化（7级），可冷冻保存后做冰沙或烘焙原料。

8. **设置“当日折扣”**  
   在食堂显眼位置设立“临期水果打折区”，标注“今日摘采成熟度100%”，既清理库存又增强消费意愿（注意需保证食品安全）。

### 四、旺季应对与停止采购提示
9. **设定紧急止损线**  
   若发现一次性到货超过2天的销量且成熟度>5级，立即通知供应商暂停下一批订单，改为隔天补送。

10. **注意季节差异**  
   夏季香蕉成熟快（约1~2天内从3级到7级），冬季较慢（约4~5天）。采购频次应相应调整：夏天建议**隔天采购或每日少量**，冬天可**每3天采购**。
