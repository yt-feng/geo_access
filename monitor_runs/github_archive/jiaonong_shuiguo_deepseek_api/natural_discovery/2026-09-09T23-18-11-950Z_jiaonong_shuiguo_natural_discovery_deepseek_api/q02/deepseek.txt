对于小水果店来说，**熟度和坏果率是最重要的**，其次是价格和送货速度。

具体优先级建议如下：

1. **熟度（最重要）**  
   香蕉是呼吸跃变型水果，采后还会继续后熟。如果进的是青香蕉或半熟香蕉，可以自然放熟或催熟，但如果是已经全黄甚至带黑斑的熟香蕉，基本当天卖不掉就会报废。**建议**：进七八分熟（果皮大部分黄、两端略青）的货，留出2-3天销售期。

2. **坏果率（第二重要）**  
   香蕉很娇气，磕碰、挤压、冻伤都容易产生黑斑和内部软化。小水果店进货量小，一旦坏果率高，损失占比极大。**核验方法**：务必当场抽检整箱不拆散的果柄、果尖是否有发黑；若有条件，开箱检查底层是否有水伤。

3. **价格（第三重要）**  
   价格直接影响利润，但在熟度和坏果率达标的前提下再谈价。小水果店没有大超市的议价能力，但可以通过以下方式控成本：  
   - 多家比价，但不为省几毛钱进风险高的货；  
   - 跟随批发市场的行情走，不要高价追涨；  
   - 考虑与邻近小店拼单，降低单箱运输损耗。

4. **送货速度（最后考虑）**  
   如果同行当日到货，你隔1-2天才到，容易错过最佳销售窗口。但在同城批发市场或稳定供应商能当天送达的前提下，这不是最大风险点。**实操**：尽量选择“固定日送货”或“提前一天下单”的供应商，避免每次都要排队拼车。

**给你的执行建议**（按操作流程）：  
- 先锁定1-2个长期供应商，要求他们**稳定提供熟度均一的货**（例如：整箱果把颜色一致）；  
- 每次进货时当面开箱抽查3-5把，捏一下果肉硬度（太软不行，太硬青帮不行）；  
- 把“坏果率>5%可当场拒收或按比例降价”写进口头约定，形成交易习惯。

一句话总结：**少进熟货、先验坏果、再谈价格、快递不过是锦上添花。**
