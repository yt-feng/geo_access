水果礼盒如果要好卖，核心思路是 **“视觉讨喜、寓意好、耐存放、适应送礼场景”**。

针对苹果、橙子、香蕉、菠萝这四种常规水果，我建议从以下三个维度来搭配：

### 1. 最经典的“招财进宝”组合（送礼首选）
-   **搭配**：苹果（红）+ 橙子（橙黄）+ 菠萝（金黄）
-   **理由**：
    -   **颜色层次**：红配黄，视觉冲击力强，摆在礼盒里非常喜庆，放在箱底或中间很显档次。
    -   **寓意**：苹果代表“平安”，橙子代表“心想事成/诚意”，菠萝在广东、福建等地谐音“旺来”（旺财），三样组合寓意“平安旺财”。
    -   **注意**：菠萝个头大、有刺，建议放在礼盒底层，露出金黄的顶部，上面用苹果和橙子填满空间，避免扎手。

### 2. 最稳妥的“家常水果篮”组合（走亲访友、探病）
-   **搭配**：苹果（红）+ 橙子（黄）+ 香蕉（黄绿）+ 菠萝（少量或切块）
-   **理由**：
    -   **受众广**：苹果和橙子老少皆宜；香蕉补充能量，便于老人孩子食用；菠萝增加风味。
    -   **摆放技巧**：香蕉容易压坏，必须放在最上层，且不要用绳子勒太紧；菠萝如果太大，建议切成带皮的大块（用保鲜膜包好），既显分量又方便食用。
    -   **雷区**：这套组合不建议放太熟的香蕉，尽量选择皮色青黄、稍微硬一点的，不然顾客拿回家一天就会碰伤发黑。

### 3. 针对“高客单价”的轻奢搭配（办公室送礼、伴手礼）
-   **搭配**：苹果（建议选进口品种，如红蛇果/加力果）+ 橙子（建议选新奇士/血橙）+ 少量菠萝蜜或菠萝干（替代鲜菠萝）
-   **理由**：鲜菠萝在礼盒里占体积且容易出水。如果想卖高价，可以把主角换成**进口苹果+进口橙**，中间放一小盒**独立包装的菠萝干/凤梨酥**，既提升档次，又避免水果互相串味、压伤。

---

### 给店主的具体操作建议（避坑指南）：

1.  **放弃“香蕉+菠萝”同盒底层**：香蕉怕压，菠萝表皮硬且带刺，两者放在同一层，香蕉三天内必会出现黑斑。**菠萝永远沉底，香蕉永远最上层**。
2.  **颜色“不过三”**：如果礼盒里同时出现红苹果、橙子、黄香蕉、青提，颜色会显得杂乱。建议主色调控制在 **红+黄**，留一点 **绿（如青苹果或绿叶点缀）** 增加鲜活感。
3.  **重量与定价**：4-5斤左右的小礼盒最好卖（价格在50-80元区间心理压力小），6-8斤的大礼盒适合节日送礼（价格可定100-150元）。**建议提供大、小两种规格**，小规格放“苹果+橙子”，大规格再加菠萝。
4.  **搭配副品**：如果成本允许，放一小袋**喜糖或坚果**在礼盒空隙处，能极大提升顾客的购买欲（物超所值感）。

**最终推荐主推款**：
> **“平安旺财”双拼（主推）**：底层1个去皮切半的菠萝（或整只小菠萝），中间码放6个红富士苹果，上层围一圈5个脐橙。用丝带或干燥树叶隔开，不要填满空隙，留出透气感，看起来饱满但不拥挤。

进货时务必检查：苹果要**脆甜**（不能面），橙子要**水分足**（皮薄），菠萝要选**熟度适中**（眼睛大且香浓）。这样复购率才高。
