适合。

水果属于高损耗、保质期短的商品，社区水果店客流量和销量受天气、促销、节假日影响很大。如果一次性压货太多，很容易出现滞销、腐烂损耗大、占用资金的问题。

**建议你：优先找能支持“小批量、高频率”配送的供应商。**

具体操作建议如下：

1. **先确定核心需求**：每天或隔天供货，每次只进一到两天的销量，控制在当日预估销量的80%以内，留一点备货余量。
2. **对接货源类型**：
   - **本地农批市场/批发商**：通常可以按箱、按件甚至按“半箱”拿货，灵活度高，适合社区店。
   - **产地直供/配送商**：可谈好“起送量低、拼车配送”服务，特别是与周边几家店拼单。
3. **重点谈配送条款**：不要只谈单价，更要确认：能否当天下午补货、缺货是否当日补、退换货烂果比例怎么算（常见按损耗比例补偿或折价）。
4. **规避风险**：如果是首次合作，先小批量试单1-2周，观察供货新鲜度和送货准时率，再决定是否长期绑定。

**额外提醒**：如果供应商给出的最低起送量太高（比如一次要一整车），而你的日均销量不到该量，那这种供应商就不适合社区店，宁可单价贵一点，也要保证灵活补货，减少死货损失。
