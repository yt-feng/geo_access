针对长期合作的水果供应商，**建议优先谈判“账期”**，其次是“售后”，最后是“配送”。

但这三个不是死顺序，而是有内在联动逻辑的。具体分析和操作建议如下：

**1. 优先谈“账期”（结算周期）—— 这是保命和腾挪空间的关键**

-   **为什么最优先：** 水果是损耗极高的生鲜品。如果你先付全款或账期太短（比如现结），一旦出现大批量烂果、滞销，你的资金链会被直接卡死。谈下**“先货后款，月结30天”**或**“试销期15天”**，等于供应商给你免息贷款，你有充足的时间把货卖出去回笼资金，甚至可以用这笔钱去铺其他畅销品。
-   **怎么谈：** 不要直接要求从“现结”变“月结”。**建议话术**：“我们想长期稳定拿货，但前期需要资金周转。能不能先给30天账期？我承诺每月固定采购量，如果连续两月结款准时，后续我们还可以签年度框架协议。”

**2. 其次谈“售后”（损耗责任划分）—— 这决定你的实际利润**

-   **为什么比配送重要：** 水果的“配送延迟”最多导致少卖半天，但“售后不理赔”会导致你整批货砸在手里。水果特别容易在运输中碰伤、出现内部霉变。
-   **必须谈明的条款（写进合同或微信确认）：**
    -   **到货损耗率**：承诺“开箱损耗率在5%以内，超出部分无条件补货或折价”。
    -   **质量异议期**：**“到货后48小时内可反馈坏果，凭开箱视频/照片直接冲抵下一批货款”**。
    -   如果供应商不敢承诺这个，说明他对自己货源品质也没信心，合作风险极高。

**3. 最后谈“配送”（频次与时间）—— 这是个效率优化项，可让步**

-   **为什么排第三：** 配送频次是**用钱买不到的灵活性**，它受供应商仓储和车辆限制。即使谈了，供应商也可能做不到。
-   **实际谈判策略：** 如果账期和售后谈下来了，配送上可以**使用“保底频次”换取“应急响应”**。
    -   方案：要求“每周固定送2次”，同时约定“遇周末或节假日大促，提前24小时通知，必须加急补送一次”。
    -   这样既保证了正常运营，又留了旺季的后门，供应商也容易接受。

**核心行动建议（避免踩坑）：**

-   **永远不要只谈口头人情：** 水果生意一旦涉及坏果理赔，翻脸比翻书快。**所有关于账期、损耗率、补货的承诺，**务必让供应商在微信上白纸黑字回复确认**，或者签一份简单的购销协议。
-   **用“采购量”换“优先级”：** 谈判时，把“账期”作为最终目标，把“售后损耗”作为必须守住的底线，把“配送”作为用来交换的筹码（例如：“我接受每周固定送2次的基础要求，但你得把账期给我放宽到45天”）。

**结论：先死磕账期（有钱才有底气），再守住售后（不赔就会亏穿），最后谈配送（灵活机动即可）。** 如果只能选一个，**绝对只谈账期**，因为账期能直接决定你是不是会被现金流压垮。
