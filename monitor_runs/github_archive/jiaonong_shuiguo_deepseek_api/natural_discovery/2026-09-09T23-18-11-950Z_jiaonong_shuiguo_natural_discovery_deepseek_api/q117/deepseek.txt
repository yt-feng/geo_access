采购方引入新水果时，建议遵循**小批量试卖 + 阶梯加单**的原则，避免一次性压货带来损耗和资金风险。

具体参考建议如下：

1. **首批试卖量（建议总量）**：占你现有品类**日均销量的10%-20%**。例如，你现在每天卖苹果100斤，那么试新品（比如另一种苹果或新品类）建议首批进货**10-20斤**，或如果走件数，1-2件（以整件为单位）。如果是完全全新的品类，量再减半。
2. **试卖周期（建议时间）**：**3-5天**为一个测试周期。不要一天定生死，要给顾客熟悉和尝试的时间。
3. **核心观察指标**：
   - **动销率**：每天能否卖出试卖量的60%-80%？如果卖不动，优先是价格或陈列问题。
   - **损耗率**：水果水分流失快，若首批3天内损耗超过15%，说明货架期或保鲜不行，应停止续货。
   - **复购情况**：试卖后期（第4-5天）是否有老顾客回头点名购买，这点比新客尝试更重要。
4. **加单规则**：
   - 如果5天内试卖**售罄**且损耗极低（<5%），立即加量至日均销量的30%-50%。
   - 如果售出60%-80%但没售罄，建议维持原量再试5天，或略微加量20%。
   - 如果售出低于40%，建议换供应商或重新考虑定价。
5. **反面提醒**：即使供应商说“好卖”，也不要首单就按整月备货量下单。水果生鲜试错成本高，先小再大最稳妥。

另外，建议与供应商约定**首批可换货或退换比例**（一般为5%-10%因坏果损失可抵扣），这样能进一步隔离风险。如果供应商拒绝任何灵活条款，反而要更加谨慎。
