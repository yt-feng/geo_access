选择学校食堂水果供应商时，需要把**食品安全、稳定供应、性价比**放在第一位。以下是具体建议：

**一、资质与准入（硬门槛）**
- 供应商必须持有营业执照、食品经营许可证（或生产许可证）。
- 要求提供每批次水果的**农药残留检测报告**，苹果、橙子带皮吃更需关注。
- 运输车辆需有冷链或保鲜设施，避免高温运输。

**二、考察与试吃**
- 实地考察库房/分拣场地，看是否干净、防虫鼠、有温控。
- 先小批量试单（如每种来10-20斤），核对重量、成熟度、坏果率。
- 重点检查：香蕉是否过熟易压伤（建议选7-8分熟，到校后1-2天完熟）；苹果表面是否打蜡或磕碰；橙子皮薄肉厚、无干水。

**三、供应与价格**
- 优先选本地或邻近基地直供，缩短运输时间（尤其香蕉怕挤压）。
- 要求供应商提供每周报价单，对比2-3家价格，警惕过低价格（可能含农残或用次果充好）。
- 签订合同明确：送货时间（如早餐前7:00到）、坏果赔付标准（例：当批坏果率超5%免费换新）。

**四、学校常用加分项**
- 配合学校“明厨亮灶”要求，可追溯果园产地。
- 能提供“切块服务”（如苹果切片）反而不建议，切后易氧化且增加污染风险，更适合现切现用。
- 寒暑假前能临时减量或暂停供应，避免学生放假造成积压。

**五、日常管理要点**
- 每次收货时，后勤老师当面拆箱抽检（随机选5箱），称重并拍照留证。
- 建立供应商月度评分表：准时率、次品率、响应速度等，得分低的淘汰。
- 香蕉、苹果分开存放：苹果释放乙烯会催熟香蕉，加速变质。

**快速行动清单：**
1. 发招标邀请或本地农业合作社考察；
2. 索取样品并做试吃+农残快检（学校可自备试纸）；
3. 签约先按“1个月试用期”操作，稳定后再签长期合同。

如果学校地处偏远，还可以考虑对接当地农产品批发市场的“指定配货点”，但他们通常不承担退换货责任，需提前书面约定。
