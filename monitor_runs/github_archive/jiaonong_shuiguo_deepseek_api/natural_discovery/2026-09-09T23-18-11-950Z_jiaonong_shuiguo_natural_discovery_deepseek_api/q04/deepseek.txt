水果店想减少香蕉在销售过程中因过熟或碰伤造成的损耗，**采购时的核心是“锁熟度”**，而不是“买便宜”。

以下是针对采购环节的硬性要求和执行建议：

**1. 明确熟度等级（色卡标准）**

不要口头说“要青一点”或“不要太熟”，要用专业色卡沟通。香蕉国际通用熟度分为1-7号（1号全绿，7号全黄带黑斑）。

- **夏季（高温/运输快）：** 要求**1.5号 - 2号**（即顶端微黄，果身基本全绿）。
- **冬季（低温/销售慢）：** 要求**2 - 3号**（果身微黄泛绿即可），因为冬季催熟慢。
- **绝对不能收：** 收货时果皮整体已转黄（4号以上）的，这种到店24小时内必熟透，只能按“即食”处理，损耗极大。

**2. 书面或协议约定“到货时间”**

- **对供应商（本地批发商）：** 要求**当日下单，次日晨达（上午8:00-9:00前）**。严禁下午到货——下午到货意味着这批货已经在库房或车上闷了一天，到店后熟化速度呈指数级加快。
- **对产地直采（长途运输）：** 必须在合同中写明**“从装车到店不超过48小时”**，且运输车厢要恒温（约13-14℃）。超过时限，按比例折价或拒收。

**3. 避雷采购细节**

- **拒绝“催熟后发货”：** 正规香蕉到货是青的，需要店里自己或安排催熟。如果供应商给的是“已经催熟但没熟透”的货（尾巴黄、果柄发黑），坚决不碰，因为这种货切开内部往往已糖化变质。
- **看“梳柄”损伤：** 货到后，随机抽3-5把，掰开看最里面的果指——如果果柄发黑、有腐烂水渍，说明运输时挤压受热，即使外皮绿也救不回，立即整批退回。

**4. 给店里留“缓冲期”**

采购时要求供应商按**“分批到货”**模式配合：

- 订货量中**40%** 到货为1.5号（用于5天后卖）。
- **60%** 到货为2.5号（用于3天后卖）。
- 坚决不订“全绿到货一次性大量”或“全熟到货”。

**核心口诀总结：**
> **“不见黄斑不收货，上午必达不留摊，熟度压到2号半，损耗减半不算难。”**
