选购香蕉时，要避开“太生”和“太熟”，可以从**外观、手感、颜色、时间**四方面判断，同时结合自己的食用计划来选：

**1. 看颜色（最直观）**
- **全绿/绿多黄少**：代表偏生，可能口感涩、硬，放2-4天才会熟。
- **黄绿相间**（约70%黄、30%绿）：偏熟，适合**当天或次日吃**，如果当天不吃，挑这种。
- **全黄、果皮有少量黑点（芝麻点）**：已接近最佳食用期，适合**立即食用**，或做香蕉奶昔、烘焙。
- **大面积黑斑、软塌出水**：过熟，不建议选。

**2. 摸手感（确认成熟度）**
- 轻轻捏香蕉柄部和果身。
- **太生**：捏起来硬邦邦，几乎没有弹性。
- **太熟**：捏起来软烂、有汁水渗出，且有发酵酒精味。
- **理想状态**：果身有轻微弹性、不硬也不软塌。

**3. 看果柄与外形**
- 果柄完整、略带青色，通常较新鲜。
- 果柄发黑干枯，多半存放过久。
- 避免选有明显压痕、裂口或局部发黑的香蕉（内部可能已过熟或腐败）。

**4. 按食用时间选**
- **计划3天内吃完**：挑全黄或黄多绿少的。
- **计划放一周再吃**：挑**七分熟**（果身黄绿相间偏黄，果柄仍微绿），成熟速度适中。
- **一次买多串**：可以搭配“一串偏生+一串偏熟”，先吃熟的，生的自然后熟。

**特别注意（超市采购细节）**
- 优先选**整把完整**的，避免选已被大量顾客反复捏过、磕碰较多的散装香蕉。
- 超市冷柜处多存放偏生的，常温货架处多为偏熟的，可按需选择。
- 如果只能买到偏生的，回家放在室温通风处（不要放冰箱冷藏，会阻止后熟），或用苹果/梨一起放纸袋催熟；如果买得太熟，立刻冷藏可延缓变质，建议当天处理。

总之，采购前先想清楚“我打算什么时候吃”，再按上述标准挑，基本不会踩坑。
