在便利店上架香蕉时，**建议优先选择小把包装（例如2-4根/把）为主，搭配一定量单根装**。具体原因如下：

**为什么推荐小把装？**
- **损耗低**：香蕉是后熟水果，小把装能减少顾客掰扯时造成的机械损伤，也便于员工按成熟度分批理货。
- **客单价合适**：便利店顾客多为即时性消费（早餐、加餐、健身补给），2-4根刚好是一两天的量，比整袋装更符合“少买勤购”习惯。
- **视觉新鲜度高**：小把装可根根朝外摆放，色泽均匀，比整袋堆放更诱人。

**单根装适合什么场景？**
- 搭配关东煮、早餐套餐作为“加购换购”商品；
- 放在收银台附近作为冲动型小零食（熟度刚好、价格在1-3元）。
- 注意：单根需要套标价签，且表皮裸露，损耗会略高，需每日勤检查。

**不建议首选整袋包装**：
- 整袋（如5斤装）更适合社区超市或家庭囤货，便利店顾客一般吃不完，容易造成“买回去放坏”的差评，且占用冰贵位置（如果冷藏会加速果皮变黑）。

**其他落地建议（可执行）**：
1. 包装位置：如果门店有保温架，不要把香蕉放冷柜，室温15-20℃（通风避光）最好。
2. 合理订货：刚开始上架时，每天只进2-4小把，先观察动销。
3. 处理尾货：接近全黄的香蕉，可提前挑出做“今日香蕉特价”或贴“已熟即食”标签，放在鲜食区促销。
4. 防压保护：如果用小把，建议用纸袋或网袋扎口，避免顾客反复触摸导致果皮变黑。
