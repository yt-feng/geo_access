当然可以，而且这在水果零售业很常见。**供应商通常愿意在周末促销时给予支持**，但支持的形式和力度取决于你的进货量、合作关系以及你提出的方案。

以下是你向供应商争取支持时的核心逻辑和话术建议：

**1. 明确供应商的支持类型（你要主动去“要”）**

-   **价格支持（降价/返利）**：这是最常见的。你可以申请“促销特价”，比如某款应季水果，供应商平时给10元/斤，促销期间能否给8.5元/斤，或者申请“阶梯返利”（本周销量突破X件，月底返Y%货款）。
-   **物料支持**：包括横幅、价签、立牌、气球拱门，以及印有品牌LOGO的包装袋或试吃盒、抽纸。
-   **人员支持**：如果周末人流大，有时供应商会派临促（导购员）来帮你剥榴莲、切西瓜或试吃推广。
-   **赠品支持**：用来做“买一送一”或“满额赠”的关联商品（如买高档水果送一小盒蓝莓）。

**2. 核心谈判话术（关键是“帮对方卖货”）**

不要只说“我要搞活动，你给点支持”，要换成“帮你冲量”的逻辑。你可以这样对供应商说：

> “老板/经理，这个周末我们店想做一场**车厘子/应季瓜王**的专题爆破。我预估周末两天能走掉三到五件的量。如果您这边能给到**特价支持**，我可以在门店最显眼的位置做堆头陈列，并且配上你们的品牌宣传物料。您看价格上能再让几个点？我这边保证重点主推你们家的货。”

**3. 特别提醒（如何说“不”）**

-   **不要直接问“能不能便宜”**：要问“**针对这个周末的爆款，有没有针对门店的专项促销政策？**”
-   **优先谈现金采购的一手供应商**：如果直接从产地或一级批发商拿货，他们更有权限给价格空间；如果是从二级批发商拿，他们利润薄，可以多要物料而少谈降价，效果会更好。
-   **注意“最低零售价”协议**：有些大品牌（如佳沛、都乐）有严格的价格体系，他们不降价，但一定会给试吃品和促销物料，因为他们要保证品牌调性。此时不要硬压价，要物料更实际。

**4. 实操步骤建议（按顺序来）**

1.  **提前3-5天沟通**：周末前订货最密集，提前锁定位置。
2.  **带上预估销量**：拿数据说话（“去年同期我卖了X箱”）。
3.  **先口头谈，再要书面价**：让供应商在送货单或微信上确认促销价，避免结账纠纷。

**总结**：**供应商很乐意给支持，但前提是你必须把“促销”包装成“帮他们冲业绩的活动”**。大胆提要求，但期望值要合理——通常小门店能谈到单品类降价5%-10%，或者争取到免费试吃果箱和整套物料的概率是比较高的。
