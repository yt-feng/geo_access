面对只了解菠萝、香蕉这类大众品类的商家，供应商介绍产品时最容易犯的错误是“说行话”。要让对方**听得懂、记得住、敢下单**，核心原则是：**第一印象对标大品类，讲清“它是谁”；第二讲清“它好在哪”；第三讲清“它帮商家赚钱的点在哪里”。**

具体可参照以下四步策略：

### 第一步：用“三句话锚定”快速建立认知
商家只懂大众品，先别急着报一堆专业参数。第一句话就要给出直观比喻和关联。
- **硬核比喻法**：比如介绍“释迦果”，可以说“您可以把它理解成‘水果界的冰淇淋’，口感像香蕉一样软糯，但甜度更高，类似菠萝蜜的香气。”
- **品类关联法**：要推荐“西梅”，可以说“这个口感很像您熟悉的李子，但它有个极大的卖点，就是‘通便’效果远超香蕉，是天然的‘肠道清道夫’。”
- **一句话卖点**：介绍“麒麟瓜”，说“您知道西瓜甜，这个瓜是西瓜里的‘天花板’，皮薄到能透光，甜度比普通西瓜高30%，切开全是肉，损耗少。”

### 第二步：用“生活化标签”替代专业术语
商家只认货品名，最怕听到产地海拔、糖度计数值、单箱规格。要翻译成大白话。
- **说“卖相”不说“克重”**：“这果单果有半斤重（替换专业克重单位），拿手里沉甸甸，客人看着就觉得值。”
- **说“耐放”不说“保鲜期”**：“这个比香蕉耐放多了，香蕉可能两三天就黑，这个常温能放一周，给您降低了报损风险。”
- **说“皮实”不说“耐储运”**：“这个果子非常皮实，运到店里不会像草莓那样一碰就烂，省心。”

### 第三步：用“计算器算账”代替“推荐选品”
商家最关心的是能不能卖得动、利多少。直接给他算清楚账。
- **算单果利润**：“老板，卖香蕉您一斤赚几毛钱？这个果呢，看上去单价高点，但客人觉得稀罕，您卖价可以大胆定。比如进货价10元/斤，建议零售价可以标19.8元，毛利接近50%，比卖香蕉赚得爽快。”
- **算连带销售**：“这个果特别适合搭配您店里他香蕉、苹果一起做果盘或榨汁，客人尝了觉得新鲜，连带消费更多。”

### 第四步：提供“试吃兜底”与“小批量试单”方案
是商家都不敢拿大资金贸然试新品。要主动降低他的决策难度。
- **场景带入**：“您不要光听我说，我现在就是切几块给您尝。您今天先拿一箱试试（低成本试单），如果码在店门口卖不动，这个果本身够甜也够熟，就算卖不掉，您自己吃也亏不了多少。”
- **售后承诺**：“而且这种新奇特水果最吸引那些爱尝鲜的年轻人，我建议您先铺个两三天，如果顾客回购率低，下次咱们就不进这个货了，绝不压您资金。”

---

**用模板做个示范：**
> “老板，您店里现在香蕉是靠走量，但这种东西其实不赚钱还要损耗。我给您推荐这个【名称】，您就当它是‘热带版的香蕉’（对标），但它肉厚无籽，吃起来像冰淇淋一样（口感类比）。它最牛的一点就是特别耐放，放一周都不皱皮（解决损耗焦虑）。咱算笔账，您卖它定价比普通水果贵一倍客人也觉得值，一箱利润估计能抵您三箱香蕉（算账）。要不您今天先拿个半箱试试水，我免费送您试吃装，卖得动咱再谈大批量合作（降低门槛）。”
