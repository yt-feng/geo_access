在水果店经营中，遇到坏果（尤其是收货时或短保期内变质）是高频问题。处理方式取决于**结算节点**（货到付款/月结）和**损耗原因**（运输损伤/存储不当/自然腐烂）。

以下是按流程分类的实操建议：

### 一、结算前的“坏果”处理（货到未结款）

**核心原则：先扣款或拒收，再结算。**

1. **收货当场验货**：如果开箱发现坏果（如撞伤、发霉、腐烂），直接拍摄带有时间戳的整箱照片和特写损坏照片，当着送货司机或供应商代表的面，**按比例扣除费用**。
   - 结算公式：应付金额 = 总货款 - （坏果斤数 × 采购单价）。
   - 如果供应商是月结且不给现场赔付，要求对方在送货单上手写注明“本次损耗X斤，于下次对账时扣除”，并签字盖章。

2. **具体赔付比例参考**：
   - **运输物理损伤**（压烂、碰伤）：视磕碰程度，一般按坏果总价的 **30%-100%** 赔付（因为损伤不可逆，无法二次销售）。
   - **自然变质/腐烂**：若在保质期内、储存合规情况下发生，通常由供应商承担 **100%**。
   - **极小比例损耗**：如坏果不足总件数的3%且单果价值低，行业惯例多为“供应商补货不赔钱”，下次送货时补足相应重量即可。

### 二、结算后的“坏果”处理（已付款但发现）

**核心原则：时效内索赔，超时自担。**

1. **黄金时效**：如果是常温水果（如香蕉、芒果）或冷藏水果（如草莓、蓝莓），**到货后24-48小时内**发现的变质（前提是店内温度控制正常），应**立即拍照、保留果皮/果肉样本**，联系销售员或老板。
2. **赔付方式选择**：
   - 金额较小（几十元内）：直接要求“**下次订单抵扣**”（货款减同等金额）。
   - 金额较大：要求明确按“质量问题件”退货退款，或按损坏斤数折算现金打到对公/微信账户。
3. **关键证据链**：必须提供**解冻前后对比图**（如冻品）或**切开内部腐烂图**，并明确告知你在收货时是完好的。如果供应商质疑你存放不当，你可以要求对方提供该批次水果的“冷链运输温度记录”来反证。

### 三、特殊品类注意事项（避免被“白嫖”）

- **香蕉、猕猴桃、牛油果**（后熟型）：这些水果在运输过程中会自然成熟，如果你采购时是青果，售卖时熟透了烂了，**一般不属于供应商责任**（因为时间在你这里流逝）。这类损耗需自行承担，或者与供应商约定“到货时成熟度等级”作为合同条款。
- **进口水果（如车厘子）** ：通常有“包赔等级”划分（如破损率低于0.5%不赔，高于按斤赔），务必在订货时口头确认或在微信聊天记录里明确。

### 四、终极防御手段（防赖账）

1. **私聊证据固化**：所有赔付诉求的沟通，尽量用**微信文字或截图**（而非纯电话），写明“X月X日到货的XX水果，检测到坏果X斤，按合同/惯例应扣除X元，请确认”。
2. **设定期限**：给对方一个明确的答复期限（如2个工作日），超期未回应，下次订货直接暂停打款，并在群里@对方负责人，将纠纷公之于众（但需注意措辞，不涉及人身攻击）。
3. **保留“试吃成本”**：如果供应商不认账，你可以要求对方下次送货时**免费补一箱价值相当的优质果**，以“弥补沟通成本”，这是业内普遍的软性补偿方案。

**最终结论**：结算前坏果直接扣钱/拒收；结算后24小时内凭证据照片索赔（抵扣下批货款最省事）。若供应商坚持不理会，只要你有聊天记录和采购单，可向当地的**市场监督管理局**（投诉12315）或**果品行业协会**投诉，对方通常会因忌惮行业声誉而妥协。
