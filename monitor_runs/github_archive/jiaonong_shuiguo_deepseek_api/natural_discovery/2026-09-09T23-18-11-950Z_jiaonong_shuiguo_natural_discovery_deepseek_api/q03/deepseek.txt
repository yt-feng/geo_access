第一次直接找大批发市场或大供应商，很容易被压货或买到不新鲜的回货。建议按“**小批量、多品种、短周期**”的原则去试，具体操作思路如下：

**1. 先定“试单量”安全线**

- 香蕉、苹果、橙子都属于走量快、损耗快的品类。
- 试单不要按“整柜”或“整件大批量”来。**每一种控制在10-20斤（约1-2箱）**即可。
- 比如：香蕉1箱（约15斤）、苹果1箱（约20斤）、橙子1箱（约20斤），加起来总金额控制在500元以内，这样就算全坏也亏得起。

**2. 去哪里试单（优先级排序）**

- **首选当地一级批发市场**：比如你城市的果品批发市场，早上5-7点档口人最多。别找那种看起来很大的“老板”，找那种只做单一品类的档口（比如只做香蕉的、只做苹果的）。
- **次选社区团购供应链**：如果你要的量太小（每种10斤以下），批发市场可能不卖，那就找做社区团购的供应商，谈“按箱试”。
- 不建议第一次就直接找产地直发（除非你有熟客带），不了解行情容易交学费。

**3. 试单时的“三步砍价”方法（不丢面子）**

- **第一步只问价**：问“香蕉什么价？”老板报一个价，别还价。
- **第二步确认质量**：问“今天这箱是几号果？甜度怎么样？上货几天了？”（对方如果说“走货快”，那大概率是新鲜货）
- **第三步压量谈价**：“老板，我第一次来，想拿三箱不同货试试水（香蕉、苹果、橙子），你看三箱一起按批发最低价给行不？”——因为你是真要拿，老板一般会给予比单拿更低的“打包价”或抹零。

**4. 试单时必看的三个“毁货”细节**

- **香蕉**：看柄是否发黑、表皮是否有芝麻点。第一单不要选全黄的（熟透容易第二天全烂），选**带一点绿头的黄**，能放3-4天。
- **苹果**：看果把（蒂）是不是新鲜的（湿润的就是刚摘的），另外捏一下硬度，偏硬说明耐放；如果苹果表皮油亮发粘，可能是打过蜡或储存久的。
- **橙子**：拿一个掂重量（同样大小越重越好水分足），注意看肚脐处有没有霉斑。如果开箱时有烂果，直接拍照给对方看，要求换货或补损，这是批发行规。

**5. 试单核心心法：一定要“留记录”**

第一次试完货，建议在手机备忘录给每一样货记下：
- 拿货价、规格大小
- 卖价、卖了多少天、损耗多少
- 顾客反馈（比如“橙子有点酸”“苹果很脆”）

这样试3-5次，你就能摸清哪几个档口的品质最稳定。**不要因为第一次货好就一次进大量**，一定要等两三周后确认那个供应商的批次稳定了，再加量。

**6. 最后一句大实话**
如果你是在社区门口开夫妻店，第一次试单**宁可从“本地二批”拿，也不要直接找最大的一级批发**。因为二批虽然贵几毛钱，但可以根据你的量帮你拆箱混装，而且好说话会教你一些门道。等你有稳定日销了，再慢慢绕开中间层。
