遇到生鲜电商水果到货后出现坏果的情况，责任划分通常遵循以下逻辑，具体需结合**物流环节**、**签收时效**和**平台规则**三大因素综合判断：

**1. 基本责任划分原则（按过错方）**
- **供应链源头问题（种植/包装）**：如果水果在采摘、分拣、装箱时已有“暗伤”或腐烂倾向（如冻伤、压伤未及时剔除），仓储或发货方需承担责任。
- **运输途中问题**：若物流环节出现剧烈颠簸、高温暴晒、冷冻失温或超时配送，且能通过物流轨迹或照片证明，物流公司需承担主要责任。
- **签收后问题**：消费者签收后放置时间过长、保存方式不当（如热带水果放冰箱），通常由消费者自行承担。

**2. 生鲜电商行业通行的“免责条款”与“售后承诺”**
- 几乎所有正规生鲜平台都有“坏果包赔”承诺：通常要求**在签收后24小时内**（少数48小时）提供坏果与快递单号的合影照片，经客服核实后按“坏果数量/总数量”比例赔偿（全额退款或部分退款）。
- 若顾客**未验货即签收**，或签收后超过平台规定时限才反馈，且无充分证据（如监控显示送到即坏），平台有权拒绝全赔，仅酌情补偿。

**3. 实操中“谁举证”很关键**
- **顾客举证**：需证明“收到时已坏”，而非收货后放置损坏（建议拍摄清晰开箱视频）。
- **商家/平台举证**：需提供发货时质检记录、物流轨迹及揽收时无异常的证据，才能与物流公司追责。

**4. 特殊情况处理建议**
- **如果顾客“代收”**（如放快递柜/门卫）：默认视为签收，若取件时发现坏果，可第一时间拒收或要求复称，并拍照留证，此时责任通常归物流或商家。
- **若平台拒绝赔付**：可保留证据向12315投诉或平台官方客服升级投诉，强调“商品品质未达标”，而非单纯运输损坏。

---

**给你的可执行建议**：
1. 优先**查看订单页面“售后政策”**，通常在“坏果包赔”条款中会写明赔付时效和材料要求。
2. 若顾客确实在收到后几小时内发现坏果，**立即拍照 + 拍摄视频**（含快递单号、果箱外观、坏果特写），发客服走售后流程。
3. 若损失大于平台赔付上限（如整箱全坏），可要求提供“发货质检报告”，否则质疑其未履行生鲜发货义务，必要时投诉至“全国12315平台”。

> 注意：生鲜电商普遍引用“运输属于不可抗力”条款，但实际司法实践中，**若商家未采用合适包装或冷链导致损耗，仍需承担主责**。遇到大额投诉时，可引用《消费者权益保护法》第24条“经营者提供的商品不符合质量要求，消费者可以要求退货退款”。
