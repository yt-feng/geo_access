判断一批香蕉的熟度和坏果风险，核心是**看“把”不看“皮”，捏“肉”不捏“面”**。建议按以下“五步法”快速筛查：

**第一步：先看香蕉“把”的颜色（最重要）**
- 青把：货很生，可能没催熟到位，批发拿回去需自行催熟，风险高（怕进冷库后转黄不均匀）。
- 黄把带绿：这是最佳收货状态，说明果实已适度成熟，常温运到门店2-3天刚好全黄。
- 全黄把且果柄发黑：过熟，货架期极短，易在批发环节就已变软发黑。
- 把上有霉斑或黑色水渍：内部可能已开始腐烂，坚决不要。

**第二步：捏香蕉的“棱”而不是“肚子”**
- 指腹轻捏香蕉脊梁的地方（正面凸起的棱线）：
  - 硬实有弹性 → 偏生，适合长途/补货；
  - 微软但不凹陷 → 最佳销售状态；
  - 轻轻一按就凹陷且不回弹 → 过熟或内部已坏。
- 千万不要捏中间肚子，果肉损伤后会加速全车腐烂。

**第三步：按“白点黑点”判断病斑**
- 皮上有零星小黑点（芝麻点）= 正常成熟，风味好。
- 皮上有大面积水渍状黑点或“屎斑”（凹陷、软烂）→ 这是炭疽病或运输挤压伤，内部果肉可能已黑心。
- 重点看香蕉“弯钩内侧”和“两把接触面”——这是最容易闷坏、霉变的位置。

**第四步：闻基部气味**
- 开箱时凑近香蕉柄部闻：
  - 若有一股酸味或酒味 → 内部在发酵，已经坏了；
  - 若有霉味 → 箱子潮湿或内部烂果；
  - 淡水果香带青涩味是正常的。

**第五步：抽查顶箱和底箱 + 弯腰再补一刀**
- 批发商常常把好果放上面，底部混次果。**务必抽2-3箱底部或中间的货**。
- 抽出几根香蕉，**轻轻弯折果柄**：若果柄一掰就断且断面发黑水浸，坏果风险极高；若果柄柔韧，则整体新鲜度好。
- 再检查箱内有无“漏液”——箱底纸板湿润或发黑，说明已有坏果混入。

**给批发商的实用判断结论（可直接执行）：**
| 观察项 | 安全 | 有风险 |
|--------|------|--------|
| 果把颜色 | 黄绿相间 | 全青或全黄发黑 |
| 果棱硬度 | 微弹不软 | 按压回弹慢/凹陷 |
| 黑点形态 | 干燥芝麻点 | 水渍斑、桑斑 |
| 底部气味 | 淡水果香 | 酸味、酒味 |
| 果柄韧性 | 弯而不断 | 易断且发黑 |

**如果必须冒险拿货**，优先选择“果把偏青一丝但无病斑”的，且拿货后**立刻拆箱透气，顶部不放重物，温度控制在13-15℃（不要低于12℃，会受冻发黑）**。冷藏车运输超过24小时，即使外表好看，到店也极易全批快速变黑，这类“冷藏后置”的货风险最大。
