选水果供应商时，**最应该优先问“售后”**，其次是配送，最后才是价格。理由如下：

1. **售后是风险底线（最关键）**  
   水果是生鲜，损耗率极高（破损、腐烂、口感差）。如果售后条款不清晰（比如坏果包赔标准、赔付比例、时效），一旦出问题，团长要自掏腰包补偿顾客，口碑和利润都会崩。必须问清：  
   - 坏果/烂果如何判定？按重量还是个数赔付？  
   - 赔付是秒退款还是抵扣下次货款？到账时间多久？  
   - 顾客差评或投诉，供应商是否承担责任？

2. **配送决定“新鲜”和“效率”**  
   即使供应商水果品质好，如果配送延迟、冷链不达标，到货后损耗会剧增。需确认：  
   - 是否全程冷链？送货准时率（误差几小时）？  
   - 缺货、多发、漏发如何处理？补发是否免费？  
   - 是否支持分时段到货（比如社区团购的取货时间）？

3. **价格最后谈，但要有比较基准**  
   在售后和配送达标的前提下，再对比价格。但要避开“低价陷阱”：  
   - 价格是否含税、含包装？包装重量是否算进净重？  
   - 是否允许抽查称重？水分流失导致的“缺斤少两”如何补？  
   - 对比同行同品质均价，而不是裸价。  

**执行建议**：先电话/面谈问清售后政策和配送细则，并要求写在合同或聊天记录中留证据。同时拿1-2款次品或瑕疵品试一下对方的售后响应速度——反应慢、推诿的供应商直接淘汰，即使价格再低也别选。
