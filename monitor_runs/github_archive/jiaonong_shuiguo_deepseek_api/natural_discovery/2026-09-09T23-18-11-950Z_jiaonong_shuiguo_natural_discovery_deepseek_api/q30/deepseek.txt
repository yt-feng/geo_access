针对超市水果到货后品相不佳的问题，售后流程的约定需要兼顾**明确性、可执行性和纠纷防范**。以下是建议的流程设计及关键条款：

---

### 一、售后流程框架（建议分五步）

**第一步：收货验收（24小时内）**
- **约定时限**：收货后**24小时内**（或约定工作日）完成开箱检查。
- **操作要求**：拍照/录像留存，按箱编号，记录品相问题（如腐烂、压伤、霉变比例）。
- **证据提交**：通过邮件、微信或供应商指定系统提交《异常反馈表》+清晰照片（需能区分批次）。

**第二步：责任判定（48小时内）**
- **约定分级责任**：
  - **运输损耗**：若外包装破损、物流颠簸导致，由物流方承担；若供应商发货前未损坏，由第三方物流负责。
  - **源头质量**：若到货即腐烂、畸形、色泽异常，属于供应商责任。
  - **模糊情况**：建议约定“**若双方无法判定，按供应商承担60%、超市承担40%共同分担损耗**”（或协商比例）。

**第三步：金额确认（收货后3日内）**
- **计算方式**：按实际损坏果品数量 × 合同单价，计算补偿金额或补发数量（补发需另算运费）。
- **注意**：若预计损失超过整批货值的**5%~8%**，超市可要求整批退货或折价留用。

**第四步：解决方案（收货后5日内）**
- **优先方案**：供应商**原价退款**（针对损坏部分）或**免费补发**。
- **备选方案**：按损坏比例降低整批货款折扣（如压价10%~20%）。
- **兜底方案**：若供应商拒绝处理，超市有权在货值扣除争议款项，并暂停合作至解决。

**第五步：争议升级（7~15日）**
- 若无法协商一致，提交**第三方质检机构**出具报告（费用过错方承担），或依据合同约定走仲裁/诉讼。

---

### 二、合同条款关键约定要点

| **条款名称**       | **建议内容**                                                                 |
|--------------------|-----------------------------------------------------------------------------|
| **风险转移节点**   | 水果在指定仓库签收后，损毁风险由超市承担；到货前由供应商承担。               |
| **退换货触发条件** | 烂果率（或损耗率）超过5%时触发售后；低于5%由超市自行承担损耗。               |
| **时效性要求**     | 逾期未反馈视为默认接受，但包装明显破损除外（需保留物流签收单）。             |
| **备用金/押金**    | 约定每批次预留5%~10%货款作为质保金，直至该批次结算完毕，用于抵扣售后损失。  |
| **违约责任**       | 供应商拖延处理超10日，每日按问题货值0.5%支付违约金。                         |

---

### 三、实操提醒（避坑指南）

1. **千万别做口头约定**：所有流程写入书面采购合同或电商平台规则。
2. **分级品控标准**：提前书面约定“品相好”的具体标准（如果径、色泽、无疤点占比），避免双方理解偏差。
3. **留底对方承诺**：若供应商宣称“包售后”，请让对方在订单一栏单独手写或签章确认。
4. **财务动作别割裂**：建议与供应商月结时，直接在应付账款中扣除经确认的损失金额，减少垫付风险。
5. **物流保险**：若进口或高频远途，建议超市购买货物运输保险（可转移风险）。

### 四、简易示例合同条款

> **第七条 品质与售后**
> 1. 乙方（供应商）应保证果品完好率不低于95%（以数量计）。收货后24小时内，甲方（超市）可对品相异常提出书面异议并提供影像证据。
> 2. 经确认属于乙方责任的，乙方应在3日内按损坏数量补发同等单价果品；不愿补发的，按货值140%现金赔付（含逾期损失）。
> 3. 每批次累计损耗率超过8%的，甲方有权拒收该批全部货品，已收货部分按80%折扣结算，并有权暂停乙方后续供货资格。
> 4. 任何争议双方协商；协商不成，交由收货地人民法院诉讼解决。
