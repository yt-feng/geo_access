针对水果供应商声称“全国配送”的说法，采购方不能仅凭口头承诺就下判断，必须进行多维度、可操作的核实。以下是一套系统性的核实方案：

### 第一步：界定“全国”的真实含义（合同目标确认）
先向供应商索要**《配送覆盖范围说明书》**，要求其明确：
1.  **核心覆盖区**：如华东、华南、华北等，具体到**地级市**。
2.  **偏远及特殊地区**：是否包含新疆、西藏、内蒙古、青海、海南等地的**县城及乡镇**，还是仅限省会城市。
3.  **时效承诺**：是“次日达”、“隔日达”，还是仅“3-5天内冷链到达”。

### 第二步：实操测试（最关键的验证）
**不要听他说，要看他做。** 建议进行至少2次小规模试单：

1.  **分区域多点测试**：
    -   选择一个**核心城市**（如上海）。
    -   选择一个**非省会城市**（如江苏常州或浙江温州）。
    -   选择一个**交通末梢区域**（如甘肃天水或贵州某乡镇，如果对方声称覆盖的话）。
    -   **测试动作**：仅下单**小批量**（如5kg）的当季易损水果（如草莓、车厘子），并指定送货地址为当地**农贸市场或冷库**。
    -   **观察指标**：从下单到发货的时长；物流轨迹更新的连续性；到达后水果的**损耗率**（如果运到非核心区损耗超过5%，基本说明冷链断链）。

2.  **压力测试（高温季节）**：选择夏季38℃以上的天气进行测试，查看其是否还能承诺“全程冷链”而非“泡沫箱加冰袋”。

### 第三步：核查物流硬件与合同条款
1.  **索要物流协议**：要求供应商提供其与顺丰冷链、京东物流或专线物流公司签订的**年度框架协议**复印件（可隐去价格），核实合同主体是否为其自身，还是第三方代发。
2.  **验仓验车**：如果采购量较大（如月采购额超10万），要求进行**视频验仓**，查看其冷库温度记录仪是否正常、是否有自有冷藏车队或固定合作车辆。
3.  **明确风险转移节点**：在合同中务必写明 **“物流风险转移”** 条款：
    -   必须是**“交付至采购方指定收货点并经验收合格后”** 风险才转移。
    -   如果供应商写“发货即完成交付”，对采购方极为不利。

### 第四步：历史案例与客户背书核实
1.  **要求提供大客户名单**：让供应商提供**3-5家**不同省份的活跃客户（最好是生鲜超市、水果连锁店或餐饮企业）。
2.  **反向验证**：拿到联系方式后，以“同行交流”名义询问对方：“平时他们走哪家物流？到货时效稳定吗？有没有出现过在高速上滞留导致腐烂的情况？”
    -   *注意：警惕供应商给假号码，可要求提供客户官网或大众点评上的公开门店电话，拨打门店电话向前台“顺手核对”。*

### 第五步：建立动态考核与备用机制
即使通过了上述测试，建议在正式合同中加入：
-   **KPI惩罚条款**：例如“超过72小时未送达指定城市的，该批次费用打5折”或“因配送延误导致的损耗由供应商全额赔付”。
-   **备用预案**：要求供应商提供“应急预案”，明确若遇天气、疫情等不可抗力导致某区域无法配送时，**需提前48小时书面通知**，并推荐就近的替代供应商或分仓。

### 关键避坑提示（采购方最易忽视的点）
-   **冷链≠冰袋**：很多声称“全程冷链”的供应商，实际是“泡沫箱+冰袋”走常温快递。核实方式：在你收到的测试包裹里放一个**带二维码的温度记录仪**（十几块钱一个），收货后扫码查看全程温度曲线，若中途温度高于8℃超过2小时，即视为冷链失效。
-   **明确“配送”与“运输”**：有些供应商只负责把货运到当地**物流园**，不负责送到你的**档口**。务必写明“送货上门并卸货”。

**结论建议**：若该供应商核心城市试单合格但偏远地区无法承诺时效，建议采购方缩小合作范围，仅将“全国配送”作为筛选门槛，实际下单时以**分省、分城报价**为准，并要求在报价单上注明“仅限XX地区”。切勿因一句“全国配送”而放弃对具体线路的验证。
