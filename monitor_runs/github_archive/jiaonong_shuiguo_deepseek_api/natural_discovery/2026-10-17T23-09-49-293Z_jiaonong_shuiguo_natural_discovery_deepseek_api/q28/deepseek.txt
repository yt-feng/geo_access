先做 **香蕉** 更稳，但前提是把它当“引流品”而不是“利润品”。三个品类的判断如下：

**1. 香蕉：最适合先做稳定性**
- 消费频率高、认知门槛低，顾客不太需要教育。
- 周转快，适合超市日常客流。
- 进口香蕉供应链成熟，规格和成熟度相对好标准化。
- 风险在于催熟和损耗：青蕉到店要控温、催熟、分级，卖相变化快，必须每天翻堆、及时打折处理。
- 适合作为“先跑通进口水果流程”的起点：先小批量、固定供应商、固定催熟标准，观察损耗率和周转天数。

**2. 菠萝：不建议作为第一个稳定进口品**
- 季节性和批次差异更明显，甜度、成熟度、黑心风险需要更细的验收。
- 顾客对“进口菠萝”和国产菠萝的价格敏感度较高，溢价空间有限。
- 损耗不一定高，但品质波动会让复购不稳定。
- 更适合在香蕉跑顺后，作为季节性补充或差异化单品。

**3. 苹果：适合做稳定利润品，但不适合做“第一个进口品”**
- 耐储、损耗低、货架期长，适合做稳定毛利。
- 但进口苹果与国产苹果竞争直接，顾客对产地和品种差异需要一定认知。
- 如果超市已有稳定苹果客群，可以同步小批量试进口苹果；否则先做香蕉更稳妥。

**建议的落地顺序：**
1. **先上香蕉**：小批量试销 2–4 周，重点看损耗率、日周转、缺货率。
2. **同步小批量试苹果**：选 1–2 个有认知的进口品种，做价格带对比，不压大库存。
3. **菠萝后置**：等香蕉和苹果的供应商、验收、损耗处理流程跑顺后，再按季节引入。

**判断标准：**
- 香蕉：损耗率能否控制在可接受范围、每天能否稳定动销。
- 苹果：进口与国产价差是否被顾客接受、复购是否稳定。
- 菠萝：批次品质是否稳定、售后和损耗是否可控。

所以答案是：**先从香蕉开始，苹果可小批量并行试，菠萝后置。**
