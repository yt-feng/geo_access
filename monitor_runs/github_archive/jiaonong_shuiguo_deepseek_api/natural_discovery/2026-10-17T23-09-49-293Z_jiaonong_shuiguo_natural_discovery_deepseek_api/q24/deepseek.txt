超市采购担心水果农残抽检，核心是先拿到可追溯到批次、可核验的合规材料，再配合抽检和合同约束。建议向供应商要以下资料：

1. **批次检测报告**
   - 要求与到货批次对应的农残检测报告，不接受只给一份“通用报告”。
   - 报告应含：样品名称、生产/供货单位、采样或生产日期、检测项目、检测方法、结果、判定依据、检测机构盖章/CMA或CNAS标识（如适用）。
   - 重点核对检测项目是否覆盖常用农药及高风险品种，报告日期是否在合理周期内。

2. **产地证明/供货证明**
   - 产地证明、种植基地或合作社供货证明、收购凭证，用于确认来源和批次对应关系。
   - 若是进口水果，要入境货物检验检疫证明、报关单等。

3. **供应商资质**
   - 营业执照、食品经营/生产相关许可（按经营模式）。
   - 供应商与种植基地、合作社的合同或授权供货关系证明。

4. **承诺书与质量协议**
   - 供应商出具农残符合国家标准的承诺书。
   - 在采购合同中明确：农残超标责任、退换货、检测费用承担、因抽检不合格造成的下架/处罚/声誉损失赔偿。

5. **追溯与召回资料**
   - 批次号、采摘/包装日期、发货单、物流记录。
   - 供应商的召回联系人和召回流程。

6. **快检或自检记录（如有）**
   - 供应商自检或第三方快检记录，可作为辅助，但不能替代合规检测报告。

**采购操作建议：**
- 每批到货做到“批次对报告、货证相符”，报告与实物批次号、日期、品种不一致的，暂缓收货或加做抽检。
- 对高风险品种（如叶菜类、草莓、葡萄、豇豆等）提高抽检频次，可送第三方检测或使用快检室初筛。
- 保留所有资料至少到该批次销售完毕后合理期限，便于抽检追溯。
- 如果供应商无法提供批次检测报告或来源证明，应视为高风险，优先换供应商或要求批批检测后再收货。

简单说：**要“批次检测报告+产地/供货证明+供应商资质+质量承诺/合同责任+追溯记录”**，其中批次检测报告和货证相符最关键。
