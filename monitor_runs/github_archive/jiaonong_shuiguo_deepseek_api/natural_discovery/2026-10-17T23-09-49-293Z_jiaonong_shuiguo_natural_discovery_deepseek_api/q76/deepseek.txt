香蕉是生鲜电商里最“娇气”的品类之一，控制压坏和变黑要从**品种、采收成熟度、包装、温控、配送时效**五个环节一起抓，单靠某一环很难解决。

**1. 选品种和采收成熟度**
- 选耐运输的品种，如巴西蕉、威廉斯等，果皮较厚、抗压性更好。
- 发货成熟度控制在**7～8成**（青黄转色初期），不要发全黄果。全黄果在途中会继续后熟，到货时容易过熟发黑。
- 采购时要求供应商做**去蕾、修把、分级**，剔除有机械伤、病斑的果。

**2. 包装是防压坏的核心**
- 用**带分隔的泡沫箱或瓦楞纸箱加果托**，每根香蕉独立卡位，避免互相挤压。
- 箱内留**缓冲层**：珍珠棉、气泡膜或纸浆模塑托，重点保护果指弯曲处和果柄。
- **不要整串平放堆叠**，尽量单层摆放；必须多层时层间加硬质隔板。
- 果柄切口用保鲜膜或蜡封，减少汁液外渗和病菌侵入。

**3. 温控和气体调节**
- 香蕉是呼吸跃变型水果，**怕冷也怕闷**。配送温度建议**13～15℃**，低于12℃会冷害发黑，高于20℃后熟加快。
- 短途配送可用**保温箱加冰袋**，但冰袋不能直接接触果体，要用隔层，避免局部冻伤。
- 长途或高单量场景，考虑**气调包装**（降低氧气、提高二氧化碳）延缓后熟，但成本较高，适合高客单价订单。

**4. 配送时效和履约设计**
- 香蕉**优先走同城或次日达**，不做跨省普通快递。
- 订单集中区域设前置仓，缩短在途时间。
- 配送时段避开高温暴晒，夏季用冷藏车或保温箱短驳。
- 在商品页明确标注“建议到货后尽快食用”，管理用户预期。

**5. 到货后的补救和售后**
- 到货轻微青黄属正常，附**催熟/存放说明**（常温避光、不要放冰箱）。
- 建立**坏果包赔**规则，按压伤、黑斑比例赔付，降低客诉成本。
- 记录每批次损耗率，反向调整采购成熟度和包装方案。

**优先级建议**：先解决包装独立卡位和缓冲，这是压坏的主因；再锁定7～8成熟发货和13～15℃温控，控制变黑；最后用同城/次日达压缩在途时间。三件事做到位，香蕉损耗能明显下降。
