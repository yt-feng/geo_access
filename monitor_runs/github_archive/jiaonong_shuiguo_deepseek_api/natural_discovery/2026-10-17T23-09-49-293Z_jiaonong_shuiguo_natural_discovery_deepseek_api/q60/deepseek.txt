# 水果到货不合格时的补货约定要点

核心思路：**把"补货"从"等供应商重发"变成"先用可用部分+限时补足短缺"，并让门店有自主采购的兜底权。** 具体可这样约定：

**1. 验收标准前置化（最关键）**
- 在采购合同/订单里写清每种水果的规格（单果克重区间、糖度下限、成熟度）、允许损耗率（如坏果率≤3%）、验收方式（抽检比例、谁签字有效）。
- 到货当场按标准验收，不合格部分拍照+称重+双方签字确认，作为补货依据，避免事后扯皮。

**2. 分级处理，不整批退**
- **轻微不合格**（外观瑕疵、略偏熟/偏生）：折价接收，用于榨汁、煮茶底等对品相要求低的用途，约定折价比例。
- **严重不合格**（腐烂、霉变、糖度不达标）：拒收并计入补货数量，但不影响整批中合格部分的正常入库使用。

**3. 补货时限与责任**
- 写明"确认不合格后 X 小时内（建议 4–8 小时，视城市配送能力）送达补货"，超时按缺货量扣款或由供应商承担门店紧急采购的差价。
- 约定补货的水果品质标准与首批一致，补货再不合格可二次追责或终止合作。

**4. 门店紧急采购兜底权**
- 加入条款：供应商未在时限内补足，门店有权自行就近采购同规格水果，差价及合理运费由供应商承担（可设单次上限）。这条是保证营业不中断的关键。

**5. 安全库存与预警**
- 对易损耗、断货影响大的品类（如鲜果茶主料），门店自身保留 1–2 天安全库存；同时约定供应商提前告知缺货风险，避免"到货才发现没有"。

**6. 结算挂钩**
- 补货部分单独记账，货款按实际合格入库量结算；建立月度不合格率考核，连续超标可换供应商。

**一句话总结**：合同里写死"验收标准 + 分级接收 + 限时补货 + 门店自采兜底 + 差价由供应商承担"，营业就不会被一次坏货卡住。
