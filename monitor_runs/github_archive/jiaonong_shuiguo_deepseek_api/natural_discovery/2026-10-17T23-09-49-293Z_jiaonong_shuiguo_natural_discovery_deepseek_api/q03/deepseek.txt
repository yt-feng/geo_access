第一次找供货商，核心不是“找最便宜的”，而是**用最小试单量验证四件事：品质稳定性、损耗率、结算规则、补货响应**。夫妻店经不起压货，试单要小、快、可退。

### 一、试单前先定好规则

1. **只试3个单品**：香蕉、苹果、橙子各1箱/1件，别一次上全品类。
2. **总量控制在1–2天销量**：比如香蕉先拿1箱（约12–15kg），苹果、橙子各1–2箱，卖完再补。
3. **明确试单目的**：不是看“能不能卖”，而是看“坏多少、补得快不快、账怎么结”。

### 二、三个单品分别怎么验

**香蕉**
- 看：到货成熟度。要青黄交接、能放2–3天卖完的，不要全黄或已出黑点。
- 称：整箱净重和标称差多少，箱底有没有垫纸/烂果。
- 试：当天拆箱，记录到货熟度、第2天和第3天各坏几根。香蕉是损耗大头，试单重点看“催熟是否均匀、有没有夹生”。
- 建议：第一次只要1箱，要求“可挑可换”或明确坏果怎么算。

**苹果**
- 看：果径是否整齐、有没有碰伤、蜡感是否异常。
- 抽：随机翻箱底，看下层有没有小果、烂果。
- 试：放3–5天看有没有软果、霉心。苹果相对耐放，重点验“箱内一致性和底层质量”。

**橙子**
- 看：表皮是否新鲜、有没有发软、霉斑。
- 称：同样看净重和箱内填充。
- 试：切开2–3个看干水、籽多、酸度。橙子容易“外好内干”，必须切开验。
- 建议：第一次拿小箱，要求供货商说明产地和采摘时间。

### 三、试单时必问的5个问题

1. **起送量和价格**：多少钱起送？试单量能不能送？价格含不含运费？
2. **结算方式**：现结、周结还是月结？第一次建议现结或货到付款，别押账。
3. **坏果处理**：到货坏果、箱底烂果怎么赔？是补货、扣款还是换货？**要具体比例和时限**，比如“到货24小时内拍照可扣”。
4. **补货响应**：当天几点前下单能次日到？断货怎么通知？
5. **退换条件**：卖不动或品质不对能不能换？第一次合作要留这个口子。

### 四、试单执行清单

- 到货当场：称重、拍照、拆箱抽检，记录净重和坏果数。
- 当天售卖：记录哪些先坏、哪些卖得慢。
- 3天后复盘：算实际损耗率 = 坏果重量 ÷ 到货净重。夫妻店水果损耗控制在**5%以内**算正常，香蕉可放宽到**8%–10%**，超过就要谈。
- 补一次货：试单后隔1–2天再补一次小量，专门看**响应速度和第二次品质是否一致**。很多供货商第一单好、第二单差，补货才是真考验。

### 五、避坑提醒

- 不要一次押三箱以上，不要被“整件便宜”诱导。
- 不要只看样品，要看**整箱底层**。
- 第一次别签长期独家，先合作2–3家小量对比。
- 价格明显低于市场价的，重点查净重和熟度，常见套路是“带箱称重、箱底垫重”。

一句话：**小量试、当场验、盯补货、算损耗**。试单跑完一轮，再决定是否固定合作。
