# 学校食堂采购香蕉：避免熟过头浪费的可执行做法

香蕉是典型的“后熟型”水果，采购后仍会持续变熟，食堂用量又相对集中，关键是从**采购节奏、验收标准、存放方式、使用顺序**四方面控制。

## 一、采购环节：按成熟度分批下单

1. **不要一次买“同一成熟度”的香蕉**
   - 大部分采购**七八成熟**（果皮青黄、果肉硬、无明显黑点），可放几天。
   - 少量采购**八九成熟**（黄中带少量青、适合当天或次日食用）用于近期供应。
   - 避免采购通体金黄、已有大量黑斑的“即食蕉”，除非当天就能用完。

2. **控制单次采购量**
   - 按“日均消耗量 × 2～3天”下单，而不是按一周量囤货。
   - 与供应商约定**分次配送**，比如每周配送2～3次，每次少量。

3. **与供应商明确成熟度要求**
   - 合同或订货单中写清：到货以青黄、无大面积黑斑、果指硬挺为准。
   - 要求供应商不要用“催熟过度”的货充数。

## 二、验收环节：当场判断，不合格拒收或降级

验收时重点看：

- **果皮颜色**：以青黄、黄绿为宜；通体深黄且带黑斑的，说明已过熟。
- **手感**：轻捏有弹性但不软塌；果柄发黑、果身软烂的不要。
- **气味**：有发酵味、酒味的已过熟。
- **果指状态**：无裂口、无流水、无霉点。

对已偏熟的批次，可**单独标记、优先使用**，不要和青蕉混放。

## 三、存放环节：延缓后熟

1. **悬挂或单层摆放**，避免堆压；堆压会加速局部软烂和碰伤。
2. **不要冷藏青蕉**：低温会冻伤果皮、导致发黑，反而影响外观和口感。放在阴凉通风处即可。
3. **远离其他催熟水果**：苹果、梨、番茄等会释放乙烯，加速香蕉成熟，尽量分开放。
4. **用保鲜膜包住果柄**（香蕉的“把”），可减少乙烯释放，延缓整体成熟。
5. **已切开或剥皮的香蕉**才需要冷藏，并尽快用完。

## 四、使用环节：先进先出 + 分级使用

- **先进先出**：先到货、先成熟的批次先出库使用。
- **按成熟度分配用途**：
  - 青黄蕉：留作后续几天直接供应。
  - 偏黄蕉：当天供应或做香蕉牛奶、香蕉粥等。
  - 已软熟但未变质的：优先用于加工（香蕉泥、烘焙、奶昔），不要等到黑斑再处理。
- **每日巡查**：食堂设专人每天检查一次，把即将过熟的香蕉挑出，提前安排到当天菜单。

## 五、兜底措施：减少“卖不掉”的浪费

- 与加工间联动：偏熟香蕉及时做成香蕉饼、香蕉粥、香蕉奶昔等，不直接丢弃。
- 小份供应：香蕉按个或半根供应，避免整串拆开后无人取用。
- 记录消耗数据：统计每周实际用量和剩余量，逐步校准采购量。

**一句话总结**：少量多次采购、到货以青黄为主、阴凉通风单层存放、先进先出、偏熟蕉提前转加工——这样能把“熟过头”的浪费压到较低水平。
