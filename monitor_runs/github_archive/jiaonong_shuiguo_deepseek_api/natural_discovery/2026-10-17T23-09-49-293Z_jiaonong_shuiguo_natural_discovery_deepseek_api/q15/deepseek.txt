# 水果店遇到坏果，和供应商结算/赔付的正常做法

核心原则：**先按合同/约定分清责任和损耗归属，再谈扣款或换货；不要先扣款后通知。**

## 1. 先看有没有事先约定

结算依据优先级：
1. 采购合同里的质量条款、损耗率、退换货条款
2. 供应商的报价单/送货单上有没有写明"包售后""坏果包赔""到货验收标准"
3. 行业惯例（没有约定时作为谈判依据，不是硬性权利）

常见约定方式：
- **到货验收扣重**：按件/按斤抽样，坏果比例超标部分扣重或拒收
- **包售后**：规定时限内（如到货24/48小时）拍照报损，按坏果数量补货或折价
- **固定损耗率**：双方约定一个可接受损耗比例（如3%~5%），超出部分才赔
- **买断制**：低价拿货、不包售后，风险自担——这种就不能事后要求赔付

## 2. 到货时就要做验收

- 当场开箱抽检，记录坏果数量、比例，拍照/拍视频留证
- 在送货单上注明"坏果X件/X斤，待处理"，让司机或送货人签字确认
- 发现问题当天就通知供应商，别拖到卖完再算账

## 3. 坏果的几种结算方式

| 情形 | 常见处理 |
|---|---|
| 到货即发现、比例高 | 拒收该批次，或整车退货 |
| 部分坏果 | 按坏果数量扣重/折价结算，或要求补货 |
| 已上架后才发现（如内部腐烂） | 在约定售后时限内报损，凭照片协商补货或抵扣下批货款 |
| 无约定、供应商不认 | 协商为主；金额小可折价了事，金额大且长期合作可谈"下批补偿" |

## 4. 操作要点

- **先沟通再扣款**：把照片、数量、金额列清楚发给供应商，确认后再在货款里扣，避免单方面扣款引发纠纷
- **留证据**：坏果照片（带日期）、送货单标注、聊天记录
- **区分责任**：运输磕碰、产地本身质量问题、自己储存不当，责任不同，别把自家损耗算到供应商头上
- **长期合作看总账**：小额坏果可以累积到下批一起谈，别每单都撕，但要有记录

## 5. 没有书面约定时

法律上可依《民法典》买卖合同质量瑕疵的规定主张减价、更换或退货，但实务中更依赖证据和协商。所以**最稳的做法是把"坏果怎么赔"写进采购单或微信确认一句**，比事后扯皮省事得多。

一句话：**验收当场定责、报损限时留证、扣款先协商、约定写在前头。**
