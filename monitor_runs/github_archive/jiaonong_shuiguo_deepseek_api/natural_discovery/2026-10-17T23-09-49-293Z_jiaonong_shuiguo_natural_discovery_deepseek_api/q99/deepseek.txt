选下午茶水果供应商，核心看四点：**批量供货稳定性、配送时效、品控与售后、结算与合规**。可以按下面流程判断和操作。

**一、先明确采购约束**
- 人数、预算/人、配送时间窗（如下午2点前到）、是否有忌口（芒果/菠萝易过敏）、是否需要切配。
- 建议优先选**整果或简单分装**，切配果盘批量配送易氧化、损耗和食安风险更高。

**二、供应商类型选择**
- **本地水果批发商/配送商**：适合20人以上、固定周期，价格和新鲜度较好，但需确认能否准时送到办公室。
- **生鲜平台企业购**（如美团/饿了么企业版、京东企业购等）：配送稳定、票据规范，适合中小批量，价格略高。
- **本地果园/合作社直供**：性价比高，但配送和售后不稳定，适合有长期合作经验时使用。
- **连锁水果店团购**：适合小批量、临时补货，批量价格优势弱。

**三、必须核验的5项**
1. **批量供货能力**：问清单次最大供应量、旺季是否断货、是否支持固定周期配送。
2. **配送时效与冷链**：确认到货时间窗、是否冷链车/保温箱、迟到如何处理。批量水果最怕下午才到或暴晒。
3. **品控标准**：要求提供当日或前一日到货样品；约定坏果率上限（如≤3%），超限补货或退款。
4. **售后响应**：坏果、少送、迟到是否有明确赔付规则，是否当天处理。
5. **资质与结算**：营业执照、食品经营许可（涉及切配需有）、能否开票、账期和付款方式。

**四、试单再放量**
先下**1–2次小批量试单**，重点看：到货时间是否准、坏果率、实际净重是否足、售后响应速度。试单合格再签固定周期采购。

**五、合同/订单里写清楚**
品种规格（如苹果直径、单果重量）、数量、单价、配送时间、坏果率上限、补货时限、迟到/缺货赔付、开票信息。避免只口头约定。

**六、批量配送水果的实操建议**
- 选耐运输水果为主：苹果、橙子、香蕉、圣女果、提子；少选草莓、蓝莓、切配西瓜等易损品。
- 按人数备**人均200–300克**，避免浪费。
- 要求**分箱/分袋包装**，方便各部门领取，减少翻拣损耗。
- 夏季优先上午采摘、冷链配送，到货后尽快分发。

**快速判断标准**：能明确承诺配送时间窗、坏果率赔付、支持试单且能开票的供应商，优先合作；只报低价但说不清配送和售后的，不建议批量采购。
