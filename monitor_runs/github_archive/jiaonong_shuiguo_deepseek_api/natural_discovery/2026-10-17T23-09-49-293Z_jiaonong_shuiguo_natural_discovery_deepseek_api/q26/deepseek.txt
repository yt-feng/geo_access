社区超市做小包装香蕉，核心是把“采购—分装—陈列—清货”这条链控住。下面按可执行要点说：

**一、采购时先定包装规格**
- 优先选**3–5根/袋、约500–800g**的小包装，适合1–2人家庭；不要一开始做太多规格。
- 采购时可要求供应商**按把/串预分**，或到店后分装。预分能减少店内反复翻动造成的机械伤。
- 包装材料选**透气打孔保鲜袋**或**食品级PE袋+扎口留微孔**，不要完全密封；香蕉呼吸强，闷袋易起水汽、发黑、长霉。
- 袋上留**透气孔**，袋内不要直接贴吸水面；如需标签，贴在袋面中部，避免压伤蕉指。
- 若做托盘+保鲜膜，膜要**打孔**，托盘不要过深，避免挤压。

**二、采购成熟度要匹配销售速度**
- 社区店周转慢时，采购**青黄交接、7–8成熟**的香蕉，到店后自然转黄；不要一次进全黄货。
- 小包装最好**分批次催熟/上架**：先卖黄度高的，青的放后场或货架下层慢慢转色。
- 采购时检查：蕉指饱满、无大面积黑斑、无裂口、无霉点、果柄不渗液；有机械伤的不要进小包装。

**三、分装和陈列的损耗控制**
- 分装动作要轻，**不要反复拆把**；拆把后伤口易氧化发黑，最好用干净刀具切分并尽快上架。
- 小包装不要堆叠挤压，**单层或少量叠放**；香蕉怕压，压伤后很快黑变。
- 陈列避开阳光直射和热源，温度尽量稳定；社区店可放**阴凉通风货架**，不要贴近门口冷热交替处。
- 每天巡架，把**黄度高的袋装香蕉**挑出来做临期组合或折扣，不要等黑斑明显再处理。

**四、损耗和库存管理**
- 小包装香蕉建议**按日销量订货**，初期少量试销，记录每天上架量、售出量、报损量。
- 设置简单规则：上架后**24–48小时**未售出的，转促销或搭配酸奶/早餐组合；出现明显黑斑、软烂、渗液的直接下架。
- 采购合同或收货单上明确**到货成熟度、机械伤比例、坏果赔付**，到货当场抽检拍照，避免损耗全由门店承担。
- 包装成本要算进毛利：袋、标签、托盘、人工分装都计入，别只看香蕉进价。

**五、容易踩的坑**
- 完全密封袋：水汽大，易霉变。
- 一次进太多全黄蕉：社区店卖不完，损耗高。
- 小包装装太满：挤压伤多，卖相差。
- 拆把后不处理切口：切口发黑，影响观感。
- 陈列在冷柜或空调直吹处：香蕉易冷害发黑。

建议先做**2–3个规格试销1–2周**，按报损率调整采购成熟度和每日订货量；小包装香蕉的利润不在进价，而在分装效率和损耗控制。
