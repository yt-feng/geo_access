判断养老院或医院食堂的水果供应商，重点不是看它规模多大，而是看它能不能持续、合规、可追溯地供货。可以从下面几个层面做尽调和日常管理。

## 一、先确认主体合规（门槛项）

1. **证照核验**
   - 营业执照（经营范围含食用农产品/食品销售）。
   - 食品经营许可证，或仅销售预包装食品的备案凭证；若供应商自行分拣切配，要看是否覆盖相应经营项目。
   - 查验时让供应商提供证件复印件并加盖公章，同时通过国家企业信用信息公示系统、当地市场监管部门平台核对真伪和有效期。

2. **主体与经营状态**
   - 看成立年限、是否有经营异常、行政处罚、失信记录。
   - 警惕刚注册、频繁变更法人或地址、注册资本与业务量明显不匹配的公司。

3. **上游来源合规**
   - 要求说明货源：产地直采、批发市场、合作社、进口商等。
   - 索取产地证明、检测报告、进货凭证；进口水果要有入境货物检验检疫证明。
   - 能说清“这批货从哪来、谁检测、出了问题找谁”的供应商更可靠。

## 二、判断稳定性（核心项）

稳定性不能靠口头承诺，要看几个可验证的点：

1. **供应能力**
   - 是否有稳定的产地或一级批发渠道，是否只做“倒手”中间商。
   - 旺季、节假日、极端天气下能否保供，是否有备选货源。

2. **仓储与冷链**
   - 是否有冷库、冷藏车或稳定合作的冷链物流。
   - 水果损耗率高，冷链能力直接决定到货质量和持续供货能力。

3. **配送与响应**
   - 配送频次、到货时间窗口、缺货补货机制。
   - 是否有专人对接、异常处理时限。

4. **财务与合同履约**
   - 是否接受账期、是否要求大额预付（预付比例过高要警惕）。
   - 是否有履约保证金、违约条款。
   - 可要求提供近期同类客户（医院、养老院、学校、机关食堂）供货证明或合同案例。

5. **历史履约记录**
   - 向它现有客户侧面了解：到货准时率、质量投诉率、退换货是否爽快。
   - 自己先做1—3个月试供，用小批量验证稳定性，再签长期。

## 三、把合规和稳定写进合同与验收

1. **合同条款**
   - 明确品名、规格、产地、等级、单价及调价机制。
   - 明确农残检测要求、抽检频次、不合格处理（退货、赔偿、终止合作）。
   - 约定供货响应时间、缺货违约责任、食品安全事故责任归属。
   - 要求供应商购买食品安全责任险（如有）。

2. **验收制度**
   - 每批查验：感官质量、数量、温度、包装、随货检测报告或合格凭证。
   - 定期抽检农残，保留样品和记录。
   - 建立供应商档案：证照、检测报告、送货单、验收记录、投诉处理记录，做到可追溯。

3. **动态评价**
   - 按月或季度打分：到货准时率、合格率、投诉次数、响应速度。
   - 设置淘汰机制，避免单一供应商垄断，至少保留1—2家备选。

## 四、特别提醒（养老院/医院场景）

- 服务对象是老人和病人，对食品安全容忍度极低，**优先选能提供批批检测或可追溯凭证的供应商**，不要只看价格。
- 生食水果（如切配果盘）风险更高，若涉及切配，供应商需具备相应食品经营条件，并控制切配环境和时限。
- 避免现金交易、个人账户收款、无票据采购，这类供应商合规风险高且难以追责。

**一句话判断标准：证照齐全可核验、货源清楚可追溯、冷链配送有保障、愿意接受抽检和违约条款、有同类机构供货案例。** 满足这几条再谈价格，先用试供期验证，再逐步放量。
