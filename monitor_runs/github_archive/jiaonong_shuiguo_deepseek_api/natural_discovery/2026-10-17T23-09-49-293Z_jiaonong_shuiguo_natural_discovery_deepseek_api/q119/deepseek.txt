水果生意长期稳定，选供应商时最容易被忽视的往往不是价格和现货，而是以下几类“平时不起眼、出问题才致命”的细节：

1. **同一产地的持续供货能力**
   很多供应商旺季有货、淡季就断，或者靠临时调货。要问他：这个单品全年能供几个月、断档期怎么补、有没有备用产区。稳定的水果生意怕的是“卖得好却突然没货”。

2. **分级标准和实际一致性**
   嘴上说“一级果”，实际大小、糖度、瑕疵率波动很大。要看他是否有明确分级：果径范围、糖度下限、允许瑕疵比例、包装规格。最好连续看几批货，而不是只看样品。

3. **损耗责任怎么划**
   最容易忽视的是运输和到货后的损耗归谁。要提前约定：到货验收标准、损耗超过多少算供应商责任、是补货还是折价、拍照留证流程。否则每次烂果都扯皮。

4. **采后处理和冷链是否真做到**
   水果稳定不只看产地，更看采后预冷、分级、包装、运输温度。问清楚：采摘后多久预冷、运输是否全程冷链、包装是否适合你的销售半径。很多供应商口头说冷链，实际是普通货车加冰袋。

5. **账期和资金占用**
   长期合作不能只看进价低。要算账期、押金、起订量、退换货周期。进价低但要求现款大额压货，现金流反而危险。

6. **供应商的下游客户结构**
   如果他主要供批发市场，你的电商或门店小批量、多频次需求可能排不上优先级。要确认他是否服务过和你类似规模的客户，愿不愿意做小批量稳定配送。

7. **异常处理速度**
   问清楚：出现质量问题时多久响应、是否补货、节假日和旺季能不能优先保你。长期稳定靠的是出问题时有人兜底，而不是永远不出问题。

8. **合同外的口头承诺**
   水果行业口头承诺多，最容易忽视的是把“保证甜”“坏了算我的”当真。所有关键承诺要落到书面：标准、损耗、账期、违约责任。

实操建议：先小批量试供2—3周，连续记录到货合格率、损耗率、缺货次数、响应速度，再决定是否长期合作。价格可以谈，供货稳定性和损耗责任才是长期利润的底盘。
