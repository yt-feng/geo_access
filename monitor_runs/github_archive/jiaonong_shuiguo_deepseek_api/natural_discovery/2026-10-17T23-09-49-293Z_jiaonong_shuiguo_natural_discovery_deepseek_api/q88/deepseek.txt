核心思路：把“口感不稳定”拆成可验收的采购标准 + 分供应商采购 + 到货抽检 + 售后闭环，而不是只靠采购员凭经验挑货。

可直接执行的做法：

1. **按品种定“可验收标准”**
   对每个主推水果写清：品种/产地、规格（单果重或果径）、成熟度、糖度下限、酸度或口感描述、允许瑕疵比例、软硬度、到货温度。比如“糖度低于X不收货”“软果率超过X%扣款或拒收”。没有标准的品类先小批量试销再定标。

2. **分供应商、分批次采购**
   同一单品至少保留2—3个备选供应商，按批次小量多频采购，避免一次压大货。新供应商先小批量试单，连续几批稳定后再放量。

3. **产地端控制成熟度和采后处理**
   线上销售要兼顾运输和货架期，采购时明确“采摘成熟度”和“发货成熟度”分开管理：耐储品种可产地熟度略低、到仓催熟；易损品种宁可缩短链路，不要为了低价收过熟货。要求供应商做预冷、分级、单果包装或缓冲包装。

4. **到货抽检制度化**
   每批到货按固定比例抽检：外观瑕疵、软果/裂果、糖度（用手持糖度计）、重量、温度。抽检结果直接决定收货、扣款、退货或降级销售。抽检数据按供应商和批次留存，形成淘汰依据。

5. **包装和物流匹配品类**
   易碰伤品类用蛋托/网套/隔板，避免大箱混装；夏季高温品类加冰袋或冷链，明确到货时限。很多“坏果差评”不是采购问题，是包装和时效问题。

6. **售后数据反推采购**
   把差评和退款原因归类：坏果、不甜、太酸、过熟、偏小、物流慢。每月按单品和供应商统计坏果率、口感投诉率，连续超阈值的供应商降量或淘汰。

7. **页面预期管理**
   详情页写清规格、口感特点、可能的酸度差异和储存建议，减少“口感不符合预期”类差评。对口感波动大的品种，主推稳定品种或做混装小规格试吃。

判断标准可以简单定为：**坏果率、口感投诉率、供应商批次合格率**三项按月看。先抓糖度和坏果率两个硬指标，比泛泛要求“品质好”有效得多。
