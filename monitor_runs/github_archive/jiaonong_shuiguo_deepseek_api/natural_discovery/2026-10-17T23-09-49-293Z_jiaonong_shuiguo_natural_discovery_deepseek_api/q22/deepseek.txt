# 香蕉、菠萝、苹果的组合促销思路

核心逻辑：**用香蕉做引流、菠萝做提价、苹果做连带**，三者毛利结构和购买场景不同，不能简单"打包打折"，否则容易只降毛利不增量。

## 一、先看清三种水果的角色

| 品项 | 特点 | 促销角色 |
|---|---|---|
| 香蕉 | 高频、价格敏感、易损耗、决策快 | 引流款，制造进店理由 |
| 菠萝 | 客单较高、有加工属性（削皮/切块）、季节感强 | 提价款，拉高客单价 |
| 苹果 | 耐储、家庭囤货、复购稳定、规格多 | 连带款，做组合和量贩 |

## 二、可落地的组合方案

**1. 场景组合装（主推）**
- "果切/沙拉组合包"：香蕉2根 + 菠萝1/4个（去皮切块）+ 苹果2个，定价略低于单买合计，主打上班族、健身、家庭早餐。
- 关键：菠萝必须预加工，降低购买门槛；用统一包装、固定价格（如9.9/19.9元），一眼可判断。

**2. 阶梯满赠，而不是直接降价**
- 买任意水果满29元送香蕉一把（或满39元加1元换购菠萝）。
- 目的：把单买苹果的顾客推到组合消费，同时香蕉成本低、感知价值高。

**3. 苹果做量贩、菠萝做加购**
- 苹果按"家庭装5斤/10斤"定价，单价下探但不破价太狠；
- 菠萝设置"加购价"：已购任意水果，菠萝第二个半价或加X元换购。
- 这样提价主要发生在菠萝上，苹果负责把篮子做大。

**4. 时段促销**
- 晚间（闭店前2小时）香蕉、切好的菠萝打折清货，减少损耗；苹果基本不打折，保护价格体系。

## 三、执行要点（决定成败）

- **算清毛利**：组合价必须保证整体毛利率不低于单品平均，用香蕉的低价换流量、菠萝的加工溢价补回来。
- **控制损耗**：香蕉和鲜切菠萝都是高损耗品，组合装只做预定量或小批量，避免为冲销量加剧损耗。
- **陈列联动**：三品相邻陈列，配"早餐组合""果盘组合"场景牌，比单纯"特价"更能提客单。
- **数据复盘**：跑2周看客单价、连带率、损耗率三项，只留有效的组合，砍掉只降毛利不增量的玩法。

## 四、要避免的坑

- 不做"三样一律打折"，会同时压三个品类的价格心智；
- 不用香蕉做大幅降价引流到脱离成本，香蕉本身毛利薄；
- 菠萝鲜切必须当日售完，否则损耗吃掉提价收益。

**一句话建议**：以"预加工菠萝 + 香蕉引流 + 苹果量贩"的组合装和满赠为主，用加购而非直降来提客单价，两周数据验证后保留有效组合。
