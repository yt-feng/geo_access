按“斤结算”通常最好管理，尤其是食堂这种需要成本核算、验收和库存盘点的场景；但要根据水果品类做混合规则，不能一刀切。

**建议规则**

1. **大宗、易损耗、按重量验收的水果：按斤结算**
   - 如苹果、梨、香蕉、橘子、西瓜等。
   - 优点：单价透明、验收可复称、损耗和成本易核算。
   - 管理要点：固定验收秤、去皮标准、允许损耗率、当场双方签字。

2. **标准化包装、整箱品质稳定的水果：按箱结算**
   - 如整箱苹果、橙子、猕猴桃、葡萄等有固定规格的。
   - 优点：收货快、减少称重工作量。
   - 前提：合同必须写清“箱规、净重范围、单果规格、坏果率、缺重处理”。
   - 风险：箱内大小不一、垫纸/冰袋增重、缺斤少两。建议首次合作抽检复称，之后按比例抽查。

3. **按份结算只适合即食、分餐或小包装场景**
   - 如水果切盒、单人份水果、会议果盘。
   - 优点：发放简单、份数好盘。
   - 缺点：单价通常偏高，规格容易缩水，不适合作为食堂主要采购方式。
   - 若使用，必须明确每份净含量、水果种类和更换标准。

**最稳妥的管理组合**

- 主采购：**按斤结算**，用于大多数散装水果。
- 标准化品类：**按箱结算**，但合同约定净重和抽检规则。
- 即食/分餐：**按份结算**，仅作补充。
- 统一验收：到货记录品名、规格、数量、单价、金额、坏果数、验收人。
- 统一比价：把所有结算方式折算成“可食部分每斤成本”再比较，避免按箱、按份看似便宜实际贵。

**一句话结论：**  
食堂水果采购以**按斤结算为主、按箱结算为辅、按份结算仅用于即食场景**，管理最清晰、成本最可控。
