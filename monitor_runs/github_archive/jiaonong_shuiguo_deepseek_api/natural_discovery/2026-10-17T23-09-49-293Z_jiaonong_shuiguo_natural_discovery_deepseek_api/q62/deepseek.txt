# 判断香蕉这批货的熟度和坏果风险

核心思路：**先看“色卡+手感+果指状态”，再看“切口、蕉轴、箱内温度和气”，最后抽样切开确认。** 香蕉是呼吸跃变型水果，判断熟度不能只看颜色，要结合硬度和采收/运输状态。

## 一、看颜色和果指状态（最快初判）

- **颜色对应熟度（常见商用色卡1–7级）**
  - 1–2级：全绿/绿中带黄，硬，适合长途或压货，但要注意是否“死青”。
  - 3–4级：绿黄转黄，果指饱满，适合批发周转。
  - 5–6级：全黄、带少量糖斑，适合零售尽快走货。
  - 7级：全黄带黑斑、果肉软，风险高，只适合即时处理。
- **果指棱角**：棱角明显、果身瘦硬=偏生；果指圆润饱满=接近可售熟度。
- **果柄和蕉轴**：果柄发黄发软、蕉轴变软发黑，说明整批后熟在加速。
- **异常信号**：局部先黄、其他仍青，可能受冷或催熟不均；果指表面有凹陷、水渍状、褐条，坏果风险高。

## 二、摸手感（比颜色更可靠）

- **整把轻捏**：硬挺有弹性=偏生；微软有回弹=适售；一捏就陷、发黏=过熟或内部已坏。
- **果指中段 vs 两头**：中段先软、两头还硬，常见于催熟不均；两头软、中段硬，警惕冷害或运输挤压。
- **果柄**：果柄一折就断且发软，说明后熟快，不适合再压货。

## 三、查切口、蕉轴和箱内环境（坏果风险重点）

- **蕉轴切口**：新鲜切口应为淡绿/白色、干爽；发黑、发霉、渗液，说明伤口感染或存放过久。
- **箱内气味**：有酒味、酸味、霉味，哪怕外观尚可，也要提高抽检比例。
- **箱底和边角**：看是否有压伤、渗汁、发霉；香蕉坏果往往从挤压伤和箱底积水开始。
- **温度痕迹**：果皮有暗褐条纹、果肉水渍状，可能是冷害；箱内发热、水汽重，易加速腐烂。
- **包装日期/催熟批次**：同一批颜色差异大，优先怀疑催熟不均或混批。

## 四、抽样切开确认（必做）

- 按**箱内上、中、下和边角**随机抽，不要只拿最上面一把。
- 切开看果肉：中心发褐、发黑、水渍状、有异味=坏果；果肉仍白硬=偏生。
- 抽检比例建议：小批至少3–5把，大批按箱数抽1%–3%，边角箱加倍。

## 五、快速判断表

| 观察项 | 偏生可压货 | 适售 | 高风险 |
|---|---|---|---|
| 颜色 | 1–3级绿/绿黄 | 4–6级黄 | 7级黑斑、局部先黄 |
| 手感 | 硬挺 | 微软回弹 | 一捏就陷、发黏 |
| 蕉轴切口 | 干爽淡色 | 轻微变色 | 发黑渗液发霉 |
| 气味 | 无 | 正常蕉香 | 酒味酸味霉味 |
| 果肉 | 白硬 | 乳白 | 褐变水渍 |

## 六、给批发商的实操建议

- **要压货/远销**：选3级左右、果柄硬、蕉轴干爽的货，但先确认不是“死青”——放1–2天不转黄就不适合压。
- **要快周转**：选4–5级、颜色均匀、手感微软的货，当天到次日走。
- **已见黑斑/酒味/箱底渗汁**：要么压价快出，要么拒收；不要按正常货入库。
- **混批或催熟不均**：分色分级，先卖熟的，生的单独存放，避免整批互相催熟。
- **入库前**：拆箱通风、挑出压伤和发霉果，别让坏果留在箱内传染。

一句话：**颜色定大致熟度，手感定真实状态，切口和气味定坏果风险，抽样切开定最终结论。**
