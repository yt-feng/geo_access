# 商超水果采购压价不降质：可执行的谈判思路

核心原则：**压价要压“结构”，不要压“底线”。** 能降的成本大多在规格、包装、物流、账期、损耗分担上，而不是单纯砍单价——单纯砍单价，供应商最直接的反应就是降等级、换产地、掺货。

## 一、谈之前先算清账，手里有牌

1. **拆成本**：把报价拆成 产地收购价 / 分选包装 / 冷链运输 / 损耗 / 供应商毛利。你清楚每一项的大致区间，谈判时就能指出“哪块能省”，而不是笼统砍价。
2. **定品质标准再谈价**：先书面明确等级（果径、糖度、着色、瑕疵率、农残检测要求），再谈这个标准下的价格。顺序反过来，供应商会用“降价可以，标准放宽”来应对。
3. **拿真实数据**：近几期采购量、退货率、损耗率、周转天数。用量和稳定性换价格，是最不影响品质的筹码。

## 二、压价优先动的五个“非品质项”

| 手段 | 做法 | 对品质影响 |
|---|---|---|
| 规格分层 | 同一品种拆成大果/中果/统货分别定价，中果做促销引流 | 无，反而匹配售价 |
| 包装简化 | 散装筐替代精装盒、减内衬、周转筐回收 | 无 |
| 物流整合 | 合并线路、提高单次装载率、自提或约车 | 无（需保冷链） |
| 账期与结算 | 缩短账期换折扣、现结价 vs 月结价分开谈 | 无 |
| 损耗分担 | 约定到货验收标准+超标扣款/换货，而不是压单价 | 正向，逼供应商控源头 |

## 三、用量和确定性换价（最有效）

- **锁量换价**：承诺月度/季度基础采购量，换阶梯价，超出部分另议。
- **错峰采购**：旺季前锁价、尾季低价收统货做加工/促销，但明确用途，不混入正价陈列。
- **产地直采/联采**：单品量大时绕开中间层，或联合其他门店拼单。前提是自己有分选和冷链能力，否则省下的差价会赔在损耗上。
- **长约+浮动机制**：约定“随产地行情浮动、设上下限”，行情跌时你受益，涨时供应商不亏，比死压一个价更可持续。

## 四、守住品质的三条红线（写进合同）

1. **验收标准量化**：瑕疵率上限、糖度下限、单果重区间、冷链到货温度，超标即扣款或拒收。
2. **降级不降标**：允许供应商报“次级果”低价，但必须单独标识、单独用途，不能冒充正品。
3. **抽检与追溯**：农残检测报告随批，定期盲检；连续不合格的降级或退出。

## 五、话术要点

- 不说“再便宜点”，而说“这个量、这个结算方式、这个包装，你能给到什么价”。
- 给对方留利润：压到供应商没利润，品质一定出问题；目标是压掉冗余环节，不是压掉他的生存空间。
- 用“长期订单+稳定回款”换价，比一次性砍价更有说服力。

## 一句话判断标准

**如果对方答应降价但要求“标准松一点、等级混一点、账期长一点”，这单就不要签；如果降价来自包装、物流、结算或量的承诺，可以谈。** 前者是拿品质换价，后者是拿效率换价。
