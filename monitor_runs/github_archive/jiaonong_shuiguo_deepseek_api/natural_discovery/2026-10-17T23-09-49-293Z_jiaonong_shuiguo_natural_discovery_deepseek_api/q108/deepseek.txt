采购方核实“全国配送”要以可验证的履约证据为准，不要只听口头承诺。可按下面顺序做：

1. **让对方书面列明覆盖范围**
   - 要求提供：可配送省份/城市清单、不可配送区域、偏远地区定义。
   - 明确是“自营配送”还是“外包/快递/落地配”，以及各区域对应承运商。
   - 要求写明时效：下单到发货、运输时长、到货窗口。

2. **抽查典型地址试单**
   - 选3类地址各下小单实测：一线城市、普通地级市、偏远县/乡镇。
   - 每单记录：是否接单、发货地、承运商、物流轨迹、实际到达时间、包装和温控状态。
   - 不要只试一个近处地址，重点测对方宣称的“全国”边远区域。

3. **核验物流轨迹和承运商**
   - 要求提供近期真实发货单号，采购方自行在承运商官网查询轨迹。
   - 核对发货地是否与对方仓库/产地一致，避免“全国接单、异地调货”导致品质和时效失控。
   - 对生鲜水果重点问冷链：哪些线路有冷链、温控记录能否提供、断链如何处理。

4. **查资质与履约能力**
   - 营业执照、食品经营/生产相关许可、仓储地址。
   - 要求提供仓库照片/视频或安排实地/视频验仓。
   - 问清自有车辆、合作物流、日均发货量、旺季运力保障。
   - 可要求提供近3个月同类客户的配送案例，但案例需能对应到真实单号或合同片段。

5. **把承诺写进合同/订单条款**
   - 明确覆盖区域、时效标准、破损/腐损赔付、延误责任、退换货流程。
   - 约定“不可配送区域需提前告知”，以及临时停发/管控时的替代方案。
   - 设置试单期和小批量履约考核，达标后再放量。

6. **用数据判断，不靠感觉**
   - 统计试单的接单率、准时率、破损率、腐损率、客服响应时长。
   - 对偏远地区单独看，因为“全国配送”最容易在这里失真。

**可执行结论**：先要覆盖清单和承运商信息，再做三类地址试单，查真实物流轨迹，最后把区域、时效、赔付写进合同。试单不达标就不放量；对方拒绝提供单号、仓库信息或不愿写赔付条款，基本可判断其“全国配送”能力不可靠。
