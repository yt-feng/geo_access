采购菠萝时，建议把“熟度”控制在**七八成熟到刚转黄**，不要追求全熟。原因是菠萝采后仍会缓慢转熟，但不会像香蕉那样明显变甜；全熟果在店里陈列、称重、削皮阶段损耗会明显放大。

可执行判断标准：

1. **看果皮颜色**
   - 优先选：**基部开始转黄、果身大部仍青绿或青黄相间**。
   - 谨慎选：**通体金黄**，适合当天或次日就卖完的少量补货。
   - 不选：**全青硬果**太多会酸、退货多；**大面积褐斑、渗汁**直接是损耗。

2. **看果眼和基部**
   - 果眼要**饱满、扁平、排列整齐**，不要明显凹陷发黑。
   - 基部切口新鲜、无霉、无酸味；基部发软或渗液说明过熟或已坏。

3. **闻气味**
   - 淡淡果香可以。
   - **浓烈酒味、发酵味、酸味**不要，说明过熟。

4. **按手感**
   - 轻按果身有**轻微弹性**即可；一按就软、局部塌陷的不要。
   - 整体很硬说明偏生，可少量采购做周转，但别大批量。

5. **看冠芽和叶片**
   - 叶片青绿、冠芽完整说明较新鲜。
   - 叶片枯黄、冠芽易脱落不一定代表果肉熟，只能作新鲜度参考。

6. **按销售节奏分批采购**
   - 当天主推：**青黄相间、基部转黄**为主。
   - 次日补货：少量**更青一点**的。
   - 促销/削皮果：可搭配少量**已全黄但无斑无软**的，当天消化。
   - 夏季高温、店内无冷柜时，熟度再降半档；冬季或冷柜条件好可略熟。

7. **到店验收动作**
   - 每批抽检：看基部、闻气味、按果身、切开1—2个查内部。
   - 内部标准：果肉**淡黄至金黄、无褐心、无水渍状**。
   - 发现基部发软、酒味、褐斑的批次，当场降级或拒收。

简单记：**采购以“基部转黄、果身青黄、轻按微弹、淡香无酒味”为合适熟度；全黄果只做少量当日周转。**
