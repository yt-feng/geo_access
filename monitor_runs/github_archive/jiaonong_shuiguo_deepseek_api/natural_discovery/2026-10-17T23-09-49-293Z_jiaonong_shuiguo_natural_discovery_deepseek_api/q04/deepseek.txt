可以按“先卖后熟、分批到货”来定采购要求，不要一次全要到同一熟度。

**1. 熟度要求**
- 采购时明确按香蕉表皮颜色和手感分级，别只说“熟一点/生一点”。
- 建议门店销售为主时：
  - **主销批次**：到货时约 **3～4号色**（青黄转黄、果身略硬但有弹性），适合2～3天内卖完。
  - **快销/即食批次**：约 **5号色**（黄多青少、微软），只少量到货，1～2天内卖完。
  - **催熟备用批次**：**2～3号色**，放店内阴凉通风处自然转黄，避免青硬就上架。
- 要求供应商“同箱熟度基本一致”，避免一箱里青黄混杂；同时控制机械伤、断指、水烂、黑斑。
- 夏季高温或门店周转慢时，主销熟度再降半级；冬季或周转快可略高半级。

**2. 到货时间**
- 不要一次到一周的量。按日销量拆成 **2～3批到货**，例如每天到一次或隔天到一次。
- 要求到货时间尽量放在 **门店开门前或早市前**，当天能上架消化；避免傍晚大批到货后闷在库房过夜。
- 周五、周末前可略增量，但熟度不要同步拉高；周一前减少高熟度到货。
- 合同中写明：到货熟度偏差大、青黄不均、机械伤超标可拒收或折价。

**3. 采购单可直接写**
“香蕉按颜色分级采购：主销批3～4号色，即食批5号色且占比不超过当日销量20%，同箱熟度一致；每日/隔日分批到货，到货时间为营业前；拒收青黄混杂、断指、水烂、明显机械伤批次。夏季主销熟度下调半级，按日销量分2～3批到货。”

核心就是：**主销批偏生、即食批少量、分批到货、同箱同熟度**。
