直接结论：**主打“顾客自己挑整果 + 现场免费去皮/切块”，不要只卖去皮好的。** 如果人手紧，可以备少量去皮果做便利装，但主陈列一定是整果。

具体判断和做法：

1. **整果更适合水果店**
   - 菠萝耐放、损耗低，整果能保留新鲜度和卖相。
   - 顾客挑整果有参与感，容易产生“我挑的更好”的心理。
   - 整果可按个头分级卖，价格弹性大。

2. **去皮好的只做补充**
   - 去皮果适合赶时间、买少量、现场吃的顾客。
   - 但去皮后失水快、易氧化、损耗高，必须冷藏且当天清掉。
   - 建议只备少量，标“现削当天吃”，不要作为主推。

3. **让顾客自己挑，但给标准**
   - 现场立个小提示：看果眼饱满、闻底部有果香、拿起来有分量、叶子易拔但不烂。
   - 店员可帮敲听声音、帮判断熟度，减少顾客挑坏果的顾虑。
   - 挑好后现场去皮切块，收少量加工费或满额免费，既控损耗又提体验。

4. **定价和陈列建议**
   - 整果按大小分两档：小果低价引流，大果正常价。
   - 去皮果按盒卖，价格覆盖加工和损耗。
   - 整果堆头放显眼位置，去皮盒放收银台附近做冲动消费。

**一句话：整果是主货，去皮是便利补充；让顾客挑整果，店里负责现场加工。**
