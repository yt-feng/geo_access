水果锁价能锁多久，没有统一标准，主要看品类、季节、供应商类型和你们采购量。一般可分几档：

1. **现货/批发市场供应商：通常锁不了太久**
   - 常见 **3～7天**，最多 **15天左右**。
   - 水果价格波动大，批发商一般只愿锁短期，且常附带“随行就市调整”条款。

2. **产地合作社/种植基地：可锁 1～3个月，少数更长**
   - 应季水果在产季前或产季初，常见锁 **15天～2个月**。
   - 如果你们采购量大、预付定金或包园，可能谈到 **整个产季**，但通常不是固定单价，而是“保底价+浮动”。

3. **大型经销商/进口商：1～3个月较常见**
   - 进口水果、冷链品可锁 **1～3个月**，但会要求最低采购量、保证金或分批提货。
   - 超过3个月的固定锁价很少见，供应商通常要求价格调整机制。

4. **长期框架协议：锁“机制”不锁死价格**
   - 可签 **6～12个月框架**，但价格按月/按季联动调整，比如参考批发市场均价、产地报价指数，设上下浮动区间。

**实操建议：**
- 易腐、价格波动大的鲜果：锁 **7～15天**，最多1个月。
- 大宗、季节性强的单品：在产季内锁 **1～3个月**，配合定金和分批提货。
- 别追求长期死价：供应商要么不签，要么报价里加很高风险溢价。更稳的是“锁价+锁量+浮动上限”组合。
- 合同里写清：锁价期限、最低采购量、提货节奏、质量等级、超期未提货调价、不可抗力与市场剧烈波动条款。

一句话：**短期锁价7～15天最常见，产地/大供应商可谈1～3个月，超过3个月的固定锁价很少，通常要改成框架+调价机制。**
