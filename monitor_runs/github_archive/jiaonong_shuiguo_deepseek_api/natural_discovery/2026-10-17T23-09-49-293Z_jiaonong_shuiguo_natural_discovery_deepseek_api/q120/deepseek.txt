供应商介绍时，核心不是把产品讲得更“专业”，而是帮商家快速判断三件事：**卖给谁、好不好卖、进了会不会砸手里**。建议按下面这个结构说。

**1. 先给“商家能对上号”的品类定位**
不要一上来报品种名，先把它归到商家熟悉的货架位置：
- “这是替代普通菠萝的中高端凤梨，不是新品种水果。”
- “这是走量型香蕉里的精品果，比普通香蕉贵一点，但损耗低。”
- “这是给水果店做差异化的小众果，不是大众走量款。”

一句话让商家知道：它放在哪个品类里、跟谁比、是走量还是做利润。

**2. 用“对比法”讲差异，别堆参数**
商家听不懂品种特性，但听得懂“跟原来有什么不同”。用三句话说清：
- **口感/外观差异**：比普通菠萝更甜、不用泡盐水、芯也能吃；
- **操作差异**：熟度好控制、货架期多几天、损耗少；
- **价格差异**：进价比普通货高多少，卖价能高多少。

比如：“普通菠萝要泡盐水、削皮费劲；这个开袋即食、芯不硬，切果盒更省工，损耗也低。”

**3. 直接给“卖货场景”**
商家下单前最想知道怎么卖。供应商要主动给场景：
- 适合切果盒、果汁店、社区团购、礼盒、餐饮配送；
- 建议陈列方式和试吃话术；
- 适合什么客群：家庭日常、年轻白领、送礼。

比如：“这个适合做 9.9 元切果盒，也适合社区团购按个卖，试吃转化高。”

**4. 用“算账”代替“夸产品”**
商家最听得懂的是毛利和损耗。尽量给可验证的估算：
- 进货价、建议零售价、单箱毛利；
- 损耗率大概多少；
- 一箱能卖几天、适合多大店拿多少货。

注意：这些数据要基于你自己的真实供货情况，不要编。可以给区间，并说明“按你当地售价核算”。

**5. 给“低风险下单理由”**
新品类商家怕压货。可以给：
- 小规格试销装；
- 混装搭配成熟品类；
- 明确售后：坏果怎么赔、熟度问题怎么处理；
- 首批建议进货量，而不是一上来推大箱。

**6. 话术顺序建议**
可以按这个模板说：
> “老板，这个货你按‘精品菠萝’理解就行。跟普通菠萝比，它不用泡盐水、芯能吃，适合做切果盒和试吃。进价比普通货高 X，建议卖 X，切盒毛利大概 X。你先拿一小箱试，配着香蕉菠萝卖，不好卖我这边给你调售后。”

**关键原则：**少讲品种故事，多讲**对标品类、差异点、卖货场景、毛利损耗、试销风险**。商家听懂这五件事，才更容易下单。
