很重要，但重点不是“供应商愿意不愿意小批量”，而是能不能把试卖做成低成本、可复盘的机制。

**为什么重要：**
- 便利店水果销量不稳定，最大风险是**损耗**，不是缺货。小批量试卖能先验证单品、门店、时段的需求。
- 水果保质期短，一旦大批量压货，卖不动就是直接报损。
- 不同门店客流差异大，用统一大货铺开容易造成“有的店缺、有的店烂”。

**但供应商“支持小批量”要看四个条件：**
1. **起订量和加价幅度**：小批量可以，但单价不能高到试卖没意义。
2. **配送频次**：最好能一周多次、按店补货，而不是一次送一批。
3. **损耗和退换机制**：临期、品质不达标能不能换货或折价，比单纯小批量更关键。
4. **换品灵活性**：试卖2—4周卖不动，能不能快速换单品，不压库存。

**可执行建议：**
- 选3—5个高频单品，在2—3家代表性门店做2周试卖。
- 每店每次只上小陈列量，比如单店单日少量铺货，卖完再补，不追求满排面。
- 用“售罄率+损耗率+毛利额”判断，不只看销量。
- 和供应商谈：小批量起订、固定配送日、残损换货、试卖期短、可换品。

**结论：** 小批量试卖很重要，但只有同时满足**低起订、低损耗、快配送、可退换/可换品**，供应商支持才真正有价值。否则只是“少量进货”，解决不了销量不稳定和损耗问题。
