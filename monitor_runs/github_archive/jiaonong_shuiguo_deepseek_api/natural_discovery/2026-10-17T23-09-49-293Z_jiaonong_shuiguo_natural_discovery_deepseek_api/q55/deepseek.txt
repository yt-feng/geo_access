选规格的核心不是“越大越划算”或“越小越便宜”，而是按**出品稳定、损耗可控、单盘成本**来定。给你一套可直接执行的判断方法：

## 1. 先定单盘用量，再倒推采购规格
水果拼盘一般按盘定量，例如每盘：
- 苹果：80–100g（约1/2个中小果）
- 橙子：80–100g（约1/2个中果）
- 菠萝：80–100g（约1/8–1/6个）

先按菜单确定每盘克重，再看每天/每餐出多少盘，算出各水果日均用量，再选最接近这个用量的包装规格，**减少开封后存放损耗**。

## 2. 苹果怎么选
- **优先选中等果（单果约180–220g）**：切半或切块都好控制，单盘成本稳定。
- 大果（250g以上）单价可能更低，但切配后边角多、氧化面大，适合出盘量大且能当天用完的店。
- 小果（150g以下）适合整果装饰或小份拼盘，但削皮去核人工高。
- **划算判断**：按“可食净重单价”比较，不要只看毛重单价。苹果可食率约80%–85%。

## 3. 橙子怎么选
- **优先选中等果（单果约180–220g）**：切瓣、去皮都方便，出成率稳定。
- 大果适合切厚片或整瓣装饰，但皮厚果多时净肉率未必高。
- 小果适合做瓣状小份，但人工成本上升。
- **划算判断**：看“净果肉成本”。橙子可食率约65%–75%，皮厚品种要打折。优先选皮薄、汁多、瓣整齐的规格。

## 4. 菠萝怎么选
- **优先选单果1.2–1.5kg的中等果**：成熟度好控，切块/切条出成稳定。
- 大果（2kg以上）毛重单价低，但一次用不完时损耗高，适合菠萝用量大的店。
- 小果出肉少、削皮人工高，除非做整只装饰，否则不优先。
- **划算判断**：按“去皮去芯后净肉成本”比较。菠萝可食率约50%–60%，芯和皮损耗大，必须算净重。

## 5. 直接可用的采购规则
- **出盘量稳定、每天用完**：选中等规格，净重单价优先。
- **出盘量小、隔天用**：选小包装/中等果，宁可单价高一点，也别囤大果造成损耗。
- **出盘量大、当天清**：可谈大果或整箱价，但必须核算净肉成本和切配人工。
- **统一规格**：同一菜品固定单果重量区间，保证每盘份量和成本可复算。

## 6. 一个简单公式
**每盘水果成本 = 采购单价 ÷ 可食率 × 每盘净用量 + 切配人工分摊**

比较规格时，把每个候选规格代入这个公式，选“每盘成本最低且损耗可控”的，而不是毛重单价最低的。

**结论**：苹果、橙子优先中等果（约180–220g），菠萝优先1.2–1.5kg中等果；所有规格都按可食净重和日均用量核算，出盘量小就别贪大果。
