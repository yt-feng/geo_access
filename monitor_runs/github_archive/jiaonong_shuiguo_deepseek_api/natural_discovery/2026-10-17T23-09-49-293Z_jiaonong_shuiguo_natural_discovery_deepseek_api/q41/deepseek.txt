判断香蕉催熟能力是否稳定，商超采购不要只看“黄不黄”，而要抓**批次一致性、到货成熟度、催熟响应、货架期表现**四件事。可执行判断如下：

1. **先看批次一致性**
   - 同批香蕉的梳形、条指粗细、长度、棱角状态要接近。差异大说明产地、季节或采收成熟度混杂，催熟后容易青黄不齐。
   - 随机抽3—5箱，记录青果比例、机械伤、断指、水烂、炭疽斑点。问题率高的供应商催熟稳定性通常差。

2. **看采收和到货成熟度**
   - 采购时要求供应商标明**采收成熟度**和**到货成熟度**，不要只写“7成熟”这类模糊说法。
   - 到货果指饱满度要够，棱角开始变圆但不能过软；果柄切口新鲜、无霉；果梳中心温度不宜过高。
   - 同一供应商连续3—5批的到货成熟度应稳定，否则催熟房很难固定工艺。

3. **做小批催熟测试**
   - 每批留样1—2箱，在相同温度、湿度、乙烯浓度和时长下催熟。
   - 重点看：**转黄是否同步**、果指两端是否先黄、青果残留比例、催熟后是否出现“青硬条”或“黄而不软”。
   - 稳定表现是：同箱转黄差不超过半天到1天，整批色差小，果肉软化均匀。

4. **看催熟后的货架期**
   - 催熟到目标色阶后，常温或冷藏条件下观察2—4天。
   - 稳定批次应转色均匀、果柄不霉、果指不大量脱落、货架期可预期；如果催熟后很快出现水烂、褐变、脱柄，说明前期成熟度或病害控制不稳定。

5. **建立供应商批次记录**
   - 每批记录：产地、季节、采收成熟度、到货成熟度、催熟参数、转黄天数、青果率、损耗率、货架期。
   - 连续比较同一供应商5—10批数据。**催熟参数可重复、结果波动小**，才算稳定；只靠单批表现好不能判断。

6. **现场快速判断技巧**
   - 摸果指中段：饱满但不软塌。
   - 看棱角：明显锐棱多，说明偏生且可能催熟不齐。
   - 看果柄和果梳切口：发黑、发霉、流胶多，催熟稳定性差。
   - 闻气味：有发酵味或酒味，说明已过熟或运输受损。

**结论：** 商超采购判断催熟能力是否稳定，核心不是问供应商“能不能催熟”，而是用**连续批次记录+同条件小批测试+催熟后货架期**来验证。建议把“同批色差、青果残留率、催熟后2—4天损耗率”作为三个硬指标，连续跟踪供应商批次，再决定采购比例。
