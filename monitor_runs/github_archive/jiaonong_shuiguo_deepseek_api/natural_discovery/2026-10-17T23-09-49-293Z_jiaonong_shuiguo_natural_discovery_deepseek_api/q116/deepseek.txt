小商家采购水果，现金结算和月结账期的风险可以分开看：

**现金结算的主要风险**
1. **资金占用大**：水果是高频、短周转品类，现金采购会持续压占流动资金，旺季或备货期容易现金流紧张。
2. **采购量受限于现金**：遇到好货、低价批次时，可能因手头现金不足错过采购机会。
3. **付款与验收脱节风险**：现金当场付清后，若发现短斤少两、等级不符、内部腐烂，追回货款和换货的谈判筹码较弱。
4. **安全与内控风险**：现金携带、保管有丢失被盗风险；多人经手时容易出现账实不符、私下拿回扣。
5. **无账期杠杆**：无法利用供应商信用来平滑经营波动。

**月结账期的主要风险**
1. **供应商信用风险**：账期内供应商可能涨价、断供或要求提前结清，尤其水果价格波动大时，口头账期不稳定。
2. **对账纠纷**：水果按批、按等级、按损耗结算，月结时容易出现数量、质量、退货扣款争议，拖成坏账或关系破裂。
3. **现金流误判**：账期容易让商家误以为资金宽裕，实际应付款集中到期时可能挤占工资、房租等刚性支出。
4. **过度依赖与断供风险**：长期月结可能形成单一供应商依赖，一旦对方停止赊销，采购立刻受影响。
5. **隐性成本**：月结价格通常高于现金价，或附带最低采购量、指定品种等条件，实际成本未必更低。
6. **违约与法律风险**：若到期未付，可能面临催收、诉讼、信用受损；若合同约定不清，滞纳金和争议成本较高。

**可执行建议**
- 现金采购：坚持“验货后付款”，保留称重单、质量照片和付款凭证；大额现金尽量走转账并备注批次。
- 月结采购：签简单书面协议，明确账期天数、对账日、质量异议期、退货扣款规则和逾期责任；每批货当场签收确认。
- 混合策略：小额急采用现金换低价，主供应商给短账期（如7—15天），并保留第二供应商备选。
- 设现金流红线：无论哪种方式，确保应付款到期前留有足够覆盖房租、工资和下一次进货的现金。
