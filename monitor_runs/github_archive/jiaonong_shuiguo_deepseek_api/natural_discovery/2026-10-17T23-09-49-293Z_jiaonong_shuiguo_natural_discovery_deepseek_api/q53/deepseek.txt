优先找“本地二级水果批发商 + 固定配送”的模式，比直接找产地、找大批发市场或找综合生鲜平台更省心。原因是：你每天量少、品类可能变化、最怕断货和品质不稳，需要的是小批量、可日配、能退换的供应商。

可按这个顺序找：

1. **本地水果批发市场里的中小批发商**
   - 选有固定档口、做餐饮/水果店配送的，不要选只做早市散客的。
   - 直接问：能不能每天按你报的品种和斤数送货？几点到？坏果怎么补？临时加单几点前说？
   - 优点：价格比平台低，品种灵活，小单也接。缺点：要自己筛人，最好签简单供货约定。

2. **做餐饮配送的本地生鲜/水果配送商**
   - 适合你不想每天采购、希望一张单子搞定。
   - 重点看是否服务过餐饮店、有没有固定线路。量少可能收配送费或有起送额，要提前算进成本。

3. **附近水果店/社区团购团长合作**
   - 适合每天只要几斤、品类不固定的小店。
   - 优点是省心、可临时补；缺点是价格略高、旺季可能先保零售。
   - 可作为备用渠道，不建议完全依赖一家。

4. **综合生鲜平台**
   - 适合应急和补缺，不建议作为唯一主供应商。
   - 品质和价格波动大，售后流程相对慢。

筛选供应商时重点问这几件事：
- 每天最晚几点报单，次日几点送达；
- 起送量、配送费、是否可混搭品种；
- 坏果/少斤怎么赔，是补货还是扣款；
- 价格是固定价还是随行就市，能否提前一天报价；
- 旺季或缺货时能不能提前通知并给替代品；
- 是否能提供简单票据或对账单。

建议做法：**主供应商1家 + 备用1家**。先试供1—2周，每天记录到货重量、坏果率、迟到次数。主供应商负责日常，备用供应商负责应急和比价。不要只压价，餐饮店少量水果最贵的成本是“断货和品质不稳”，不是每斤便宜几毛钱。
