节假日水果需求暴增，提前锁定货源的关键是**把“临时抢货”变成“提前锁量、锁价、锁品质、锁运力”**。建议按下面几步做，越早启动越有效：

## 1. 先做需求预测，别凭感觉下单
- **按品类拆**：礼盒果（苹果、橙子、猕猴桃）、走量果（香蕉、西瓜、砂糖橘）、高毛利果（车厘子、草莓、阳光玫瑰）分别预测。
- **按门店拆**：用近2—3年节假日同期销量、今年客流预估、促销计划，算出各店各品类安全库存。
- **留缓冲**：节假日损耗和临时补货都高，主推爆品可多备10%—20%，但鲜果别压太多，避免节后烂库。

## 2. 提前锁上游：产地+一级批发双线
- **主供应商提前签框架协议**：节前30—45天锁定品类、数量、价格区间、到货时间、质量标准、违约赔付。
- **产地直采**：对耐储果（苹果、梨、橙、柚）提前包园或订园；对短保果（草莓、樱桃）锁定大棚/合作社，按日分批到货。
- **批发市场做备份**：保留1—2家一级批发商做应急补货，别把全部量压在一个产地。
- **多源采购**：同一爆品至少2个产区/供应商，防天气、交通、疫情等断供。

## 3. 锁价方式要灵活
- **耐储果**：可提前锁价+分批提货，降低节前涨价风险。
- **短保果**：锁量不锁死价，约定随行就市但设上限，或采用“保底量+浮动价”。
- **礼盒装**：提前锁定包装箱、标签、人工，别等到节前一周才找包材。

## 4. 锁运力比锁货更容易被忽略
- 节前物流紧张，提前和承运商签节日运力保障协议，明确车辆、频次、温控要求。
- 短保水果优先安排冷链直发门店或配送中心，减少中转。
- 对偏远门店提前前置备货，避免节前最后两天集中到货压车。

## 5. 仓储和门店要提前腾仓
- 配送中心提前规划节日专区，耐储果提前入库，短保果按“少量多次”到货。
- 门店冷库、堆头、礼盒区提前排期，避免货到了没地方放。
- 设定库存红线：某品类超过X天销量就停止补货，防节后甩卖。

## 6. 合同里写清楚“节假日条款”
重点写：到货时间窗口、品质验收标准、缺货赔付、临时加量响应时间、价格调整机制、退换货责任。口头承诺不算，必须落纸面。

## 7. 节前演练一次补货链路
节前2周做一次模拟：下单—到货—分拣—门店收货—陈列，看看哪个环节会堵。发现瓶颈立刻补人、补车、补仓。

**一句话总结：节前30—45天启动，耐储果锁价锁量、短保果锁园锁运力、全品类多源备份，合同写清违约和加量条款，仓店运力同步提前排。** 这样比节前一周到处抢货稳得多。
