结论先说：**损耗低对最终毛利的影响通常更大，尤其是在水果这个品类。**但两者不是二选一，关键是看“低价格”是否以牺牲损耗为代价。

### 判断逻辑

最终毛利大致可以理解为：

**毛利 = 销售额 × 毛利率 − 损耗成本 − 其他运营成本**

水果的特殊性在于：
- 保质期短、易腐，损耗弹性大；
- 损耗不只是“烂掉的部分”，还包括临期打折、下架、报损、客诉退款；
- 采购价低往往伴随等级不稳、成熟度高、批次差异大，后端损耗会放大。

所以：
- **采购价低**主要改善的是“初始毛利率”；
- **损耗低**改善的是“实际可售率和周转效率”，直接决定低价优势能不能落地。

### 什么时候价格低更关键？

满足这些条件时，低价更可能带来更高毛利：
- 品类耐储运，如苹果、梨、橙、柚子；
- 周转快、客流稳定，能在最佳销售期内卖完；
- 有稳定分级和加工能力，可把次果转成果切、果汁、促销品；
- 供应商稳定，批次质量波动小。

### 什么时候损耗低更关键？

这些情况损耗低的优先级明显更高：
- 叶菜、浆果、桃李、热带水果等易腐品类；
- 门店客流不稳定、预测能力弱；
- 冷链、陈列、库存管理能力一般；
- 促销频繁、价格敏感但复购依赖品质；
- 损耗已经高于行业常见水平。

### 可执行的决策方法

不要凭感觉选，建议按单品做一次测算：

1. **算实际可售率**：到货数量中真正能正价卖出的比例。
2. **算综合成本**：采购价 + 运输 + 分拣 + 损耗 + 打折让利。
3. **算周转天数**：卖得越慢，损耗权重越高。
4. **做小批量对比测试**：同一单品选两个供应商，各跑一到两周，比较“最终毛利/陈列位/天”。

### 给采购的优先级建议

- **易腐水果：损耗优先，价格其次。**
- **耐储水果：价格优先，但必须设置损耗上限。**
- **新品或需求不稳：先控损耗，再谈低价。**
- **低价采购必须附带条件**：等级标准、到货成熟度、退换货规则、批次稳定性。

一句话概括：**低价决定你“理论上有多少毛利”，损耗决定你“最后能留下多少毛利”。水果品类里，后者通常更影响最终结果。**
