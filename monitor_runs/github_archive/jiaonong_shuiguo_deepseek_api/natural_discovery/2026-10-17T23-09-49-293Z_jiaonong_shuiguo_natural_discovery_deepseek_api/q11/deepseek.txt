会有影响，但影响大小取决于你怎么卖。香蕉一箱大小不一是常见情况，关键是把“混级”变成可控的销售方式，而不是整箱直接按一个价卖。

**会带来的影响：**
- 顾客挑大果、剩小果，导致小果损耗和差评。
- 整箱统价时，大果被挑走，小果难卖。
- 大小差异大时，顾客会觉得“不值这个价”。
- 熟度不一致会放大大小问题，小果熟得快、大果熟得慢，陈列后品相变差。

**建议做法：**
1. **分级销售**：到货后按大、中、小分开放，分别定价。大果做精品/单卖，中果做主力，小果做特价或切果/榨汁原料。
2. **整箱卖要明确规格**：如果整箱统价，提前说明“大小混装”，避免顾客预期落差；可搭配“整箱特价”走量。
3. **按用途分流**：小果做香蕉奶昔、果切、烘焙原料，或捆成小把特价，减少挑剩。
4. **控制熟度**：大小混装时尽量同熟度陈列，避免小果先熟烂；到货后及时分拣。
5. **陈列技巧**：大果放显眼位置做引流，小果捆把或装袋，减少顾客逐根挑。

**判断标准：**
- 大小差异在1个规格内、熟度一致：影响较小，捆把卖即可。
- 差异明显、顾客能一眼挑出：必须分级，否则小果会剩。
- 采购价足够低、能做特价走量：混装整箱卖也可行，但要明确告知。

简单说：**大小不一不是不能卖，而是不能“混着统价随便卖”。分拣分级、按用途分流，影响就能降到很低。**
