三者都重要，但如果必须排优先级：**食品安全第一，配送准时第二，价格第三**。

原因是企业食堂和普通零售不同：

1. **食品安全是底线，不可用价格或准时来交换**
   - 水果一旦农残超标、霉变、腐烂污染，影响的是整批就餐人员，属于群体性风险。
   - 食堂采购应优先看：供应商资质、农残检测/承诺达标合格证、进货查验记录、冷链和储存条件、霉变和破损率控制。
   - 一旦出问题，企业面临的健康、舆情、合规成本远高于采购差价。

2. **配送准时直接决定食堂能否正常供餐**
   - 水果通常按当日或次日菜单使用，晚到会导致菜单缺项、临时替换、浪费已备餐食。
   - 应明确送达时间窗口、迟到处理、缺货替代规则，而不是只看“能不能送”。

3. **价格重要，但应放在“满足前两项后的比价”**
   - 水果价格波动大，建议用“周期询价+浮动定价+质量验收标准”控制成本，而不是单纯追求最低价。
   - 过低价格往往对应等级下降、损耗转嫁或检测缺失，综合成本未必低。

**可执行建议：**
- 供应商准入：营业执照、食品经营许可/相关资质、检测报告或合格证缺一不可。
- 合同写清：验收标准（新鲜度、规格、霉变率上限）、送达时间窗、迟到/缺货赔付、退换货响应时限。
- 日常管理：每批查验、留样或记录，定期复盘损耗率和投诉率。
- 比价方式：先圈定合格供应商，再在合格名单内比价，避免“低价中标、质量失控”。

一句话：**食品安全是一票否决，配送准时是供餐保障，价格是在前两者达标后的优化项。**
