旺季菠萝用量突然变大，和供应商约定临时补货，核心是**提前把“临时补货”的规则写进协议或补签单**，避免口头承诺。可操作建议如下：

1. **先定补货机制，而不是每次临时打电话**
   - 约定旺季临时补货的**触发条件**：如周用量超过平常的120%、某个单品销量连续3天超预期。
   - 约定**提前通知时间**：例如当天14:00前下单，次日早上到货；或紧急单提前6小时。
   - 约定**最小/最大补货量**：如每次补货不少于X箱、不超过Y箱，避免供应商临时凑不出货或你压货。

2. **锁定价格和品质标准**
   - 临时补货价可约定为“基准价+浮动上限”，例如以当周市场均价为基准，上浮不超过5%—10%，防止旺季被临时加价。
   - 明确菠萝规格：品种、单果重量范围、成熟度、去皮/带皮、有无黑心、农残检测要求。
   - 约定**验收不合格的处理**：拒收、换货时限、损耗承担方，避免旺季断货时被迫收次品。

3. **约定供应保障和违约责任**
   - 供应商承诺旺季**优先保供**，明确断供或迟到的补偿方式，例如按缺货金额比例扣款、承担临时采购差价。
   - 你方也承诺临时补货的**最低采购量或最短合作期**，换取对方优先排产。
   - 设置**紧急替代方案**：供应商无法供货时，允许你从备用渠道采购，差价由责任方承担或双方按比例分担。

4. **用书面形式固定**
   - 在年度框架合同里加“旺季临时补货条款”，或补签一份《旺季临时补货确认单》，写清：补货触发条件、通知时限、价格机制、质量标准、到货时间、违约处理。
   - 每次临时补货用**微信/邮件/订货单**确认数量、单价、到货时间，保留记录。

5. **操作上留缓冲**
   - 旺季前让供应商提供**产能/库存证明**，并锁定一个安全库存量。
   - 同时维护**1—2家备用供应商**，哪怕平时少量拿货，保持联系。
   - 内部按“安全库存+在途+供应商承诺库存”三层管理，不要等断货才补。

简单说：**把临时补货变成有触发条件、有价格上限、有品质标准、有违约责任的书面机制**，再配合备用渠道，旺季就不会被供应商卡脖子。
