小面积便利店做水果，核心不是“品类齐全”，而是**少SKU、快周转、强控损**。可以按以下方式落地：

**1. 品类控制：只做“高频刚需+即食场景”**
- 建议水果SKU控制在 **8～15个**，按门店实际陈列面调整。
- 优先选择：苹果、香蕉、橙子、砂糖橘、梨、葡萄/提子、小番茄、黄瓜（可归果蔬）、季节性爆品1～2个。
- 避免：易磕碰、成熟度难控、单价高且动销慢的品类，如大面积榴莲、整箱草莓、精品礼盒果。
- 结构建议：
  - 60%常销基础款：苹果、香蕉、橙子、梨；
  - 30%即食便利款：小番茄、提子、切果盒、单人份；
  - 10%季节引流款：当季单品，少量试销。

**2. 采购量：小批量、多频次**
- 按 **1～2天销量** 订货，叶菜/浆果类按半天到1天；苹果、橙子等耐储果可2～3天。
- 新品类先“试销”：首单只进 **1～2箱或最小采购单位**，观察3～7天动销再决定是否保留。
- 设置单品淘汰线：连续7天日均销量低于设定值、或损耗率超过品类阈值，就下架或换品。

**3. 收货与陈列控损**
- 收货当场验收：看成熟度、磕碰、霉点、大小均匀度；不合规直接拒收或折价。
- 陈列“少量多补”：不要一次堆满，保持排面饱满但库存周转快。
- 香蕉、芒果等催熟水果单独存放，避免乙烯加速其他水果成熟。
- 易损水果用托盘、防撞垫，减少翻拣；切果盒冷藏并当日清货。

**4. 损耗管理：定标准、日盘点、快处理**
- 给每个品类设损耗率目标，例如基础耐储果 **3%～5%**，浆果/即食果 **8%～12%**，按门店实际调整。
- 每日闭店前盘点，记录报损原因：收货差、陈列伤、过期、动销慢。
- 临期/微瑕果做“即食折扣区”或切果盒，但要有明确时限和卫生标准。
- 当日未售完的鲜切果不建议隔日再卖。

**5. 数据闭环：用销量决定采购**
- 记录每个SKU的日销量、报废量、毛利率。
- 每周复盘：保留“销量稳、损耗低、毛利合理”的品，淘汰“占排面、损耗高、动销慢”的品。
- 采购计划按“昨日销量+天气+周末/节假日系数”微调，不要凭感觉铺货。

**一句话原则：** 小店面水果采购要“**品类少而准、单次少而勤、陈列少而补、损耗日清日结**”。先跑通10个左右核心SKU，再逐步增加季节品。
