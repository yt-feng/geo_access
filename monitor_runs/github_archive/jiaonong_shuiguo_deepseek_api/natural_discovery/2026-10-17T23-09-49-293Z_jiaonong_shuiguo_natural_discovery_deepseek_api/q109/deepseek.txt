优先谈**账期**。理由很直接：账期直接决定你的现金流和议价空间，而配送和售后在长期合作里通常有“最低可用标准”，但账期一旦定错，后面很难改。

具体判断顺序：

1. **账期最优先**
   - 水果是高频、易损耗、价格波动大的品类，现金流压力主要来自这里。
   - 长期合作中，账期从“现结/周结”谈到“月结”或“半月结”，等于供应商给你一笔无息周转资金。
   - 谈判时重点明确：结算周期、对账日、付款日、逾期处理、节假日是否顺延。
   - 注意不要只谈“月结30天”，要落成“收货后第几天对账、第几天付款”。

2. **配送第二**
   - 配送直接影响损耗和门店/仓库的运营节奏，但通常可以通过约定频次、时间窗、起送量、缺货补送来解决。
   - 优先谈：固定配送日/频次、到货时间窗、临时补货响应时间、运费承担、缺货/短少处理。
   - 如果配送不稳定，账期再长也会被损耗和断货吃掉。

3. **售后最后**
   - 售后重要，但长期供应商的售后往往可以标准化：坏果率、短少、质量问题、退换货时限、扣款方式。
   - 建议把售后写成可执行条款：到货多久内反馈、按比例扣款还是补货、坏果率阈值、责任归属。
   - 售后不需要花太多谈判资源，除非你过去已经被质量问题坑得很惨。

**一句话建议**：先谈账期拿到现金流，再用配送条款控损耗，最后用售后条款兜底。如果供应商在账期上很强硬，可以拿“配送频次+售后扣款标准”做交换，但不要轻易放弃账期。
