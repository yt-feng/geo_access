建议按“经营目标”排序，而不是单选：

1. **甜度优先**
   - 菠萝是强体验型水果，甜度不稳定会直接带来差评和退货。
   - 门店可做“到货抽测糖度+试吃”，把甜度作为准入指标，不达标不进或降级促销。

2. **切果损耗必须重点盯**
   - 如果做鲜切/果切，损耗直接吃掉毛利：黑心、过熟、机械伤、修削比例都会放大成本。
   - 建议记录：到货损耗率、修削率、当日未售切果报废率。切果业务里，损耗权重应排第一或第二。

3. **外观决定动销**
   - 外观影响顾客第一眼购买和陈列效果，但不应压过甜度。
   - 重点看：果形端正、无霉斑、无软烂、冠芽新鲜、无严重磕碰。外观差可转切果或促销。

4. **大小看客群和定价**
   - 家庭客群偏好中等偏大、一次吃完；小果适合低价引流或切果。
   - 大小本身不是越大约好，要和单价、客群、陈列位匹配。

**可执行判断：**
- **整果为主**：甜度 > 外观 > 大小 > 切果损耗（损耗仍要监控）。
- **鲜切/果切为主**：切果损耗 ≈ 甜度 > 外观 > 大小。
- **社区超市/走量**：甜度稳定和损耗控制优先，大小做分层定价，外观做分级陈列。

一句话：**甜度是复购底线，损耗是利润底线，外观是动销门槛，大小是定价分层工具。**
