判断茶饮连锁的菠萝供应商能否稳定按规格送货，建议从“能不能持续供”和“能不能按你的标准供”两条线分开验证，最后用小批量试单兜底。

**一、先定死规格，再谈稳定**
茶饮用的菠萝通常是两类：鲜果（现切/捣果肉）和冷冻果肉/果酱。先明确：
- 品种与产地：如金钻凤梨、普通菠萝，产地是否可替换；
- 成熟度与糖酸比区间：糖度范围、酸度或口感要求；
- 单果重量区间、果形、有无黑心/水心/空心；
- 加工规格：去皮切块尺寸、冷冻果肉的解冻失水率、固形物含量；
- 包装：箱规、单袋重量、冰衣率（冷冻品）、保质期和到货温度；
- 验收容差：允许的次品率、糖度波动范围、重量公差。

规格越细，后面越容易判断。没有书面验收标准，供应商“稳定”无法定义。

**二、验证持续供应能力**
1. **产地与季节**：问清菠萝来自哪个产区、主供季和淡季怎么解决。单一产区在淡季容易断供，要看是否有跨产区或冷冻库存补充方案。
2. **产能与客户结构**：日/月供货能力、现有客户里有没有同量级连锁、旺季会不会优先保大客户。要求提供近几个月的出货记录或订单履约样本。
3. **原料来源稳定性**：是自有基地、长期合作果园还是市场收购。市场收购型在价格波动时容易换货或降规格。
4. **仓储物流**：是否有冷链仓、到店/到仓的运输方式和时效，旺季运力怎么保障。

**三、用试单验证“按规格送”**
不要只看样品，样品往往是最好的那批。建议：
- 先下2—3批小单，覆盖不同周次，最好跨一次价格波动或天气变化；
- 每批按验收标准抽检：糖度、单果重、次品率、切块规格、冷冻品解冻失水率；
- 记录到货准时率、破损率、批次间一致性；
- 故意在订单里混入不同规格要求，看对方分拣和标签是否清楚。

**四、合同里写死稳定性条款**
- 规格书作为合同附件，明确验收方法和容差；
- 约定批次不合格的处理：退换、扣款、停单；
- 约定旺季保供比例和提前下单周期；
- 约定替代规格需提前书面确认，不能擅自换品种或产地；
- 设置月度/季度履约考核：准时率、合格率、断供次数，连续不达标可终止。

**五、快速判断信号**
比较危险的信号：只愿意给样品不愿小批量试单；说不清产地和淡季方案；规格靠口头描述；没有冷链能力却承诺全国稳定送；价格明显低于市场且不愿签规格附件。

比较可靠的信号：有书面规格书和验收标准；能提供多批次检测或出货记录；有跨产区或冷冻补充方案；愿意接受小批量多批次试单并承担不合格退换。

总结：先写规格书，再查产地/产能/客户结构，然后用跨批次小单验一致性，最后用合同条款把稳定供货变成可考核的义务。
