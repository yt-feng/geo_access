连锁超市降低门店坏果率，赔付条款要围绕“责任可界定、损失可计算、流程可执行”来设计，不能只写一句“坏果赔付”。建议合同从以下几层约定：

**1. 明确坏果定义和验收标准**
- 按品类分别约定：外观缺陷（腐烂、霉变、软烂、裂口、机械伤）、新鲜度指标（如叶菜萎蔫、果品硬度/糖度）、规格允许偏差。
- 约定“坏果率”计算口径：以到店验收数量为分母，还是以整批到货量为分母；抽样比例、抽检方法、判定阈值。
- 区分“到货即坏”和“门店储存期内变质”，前者归供应商，后者按储存条件责任划分。

**2. 分环节约定责任**
- 产地/装车环节：供应商承担装车前质量责任，可要求提供采摘时间、预冷记录、质检报告。
- 运输环节：明确温控要求（如冷藏车温度区间、记录留存），运输方或供应商对温控失效导致的坏果负责。
- 到店验收：约定验收时限（如到店2小时内完成抽检）、验收方式（抽检比例不低于X%）、不合格处理（拒收、换货、降价接收）。
- 门店储存：约定超市自身储存条件义务（温湿度、陈列时限），因超市储存不当导致的坏果由超市承担，避免供应商无限兜底。

**3. 赔付方式要可计算**
- 拒收/退货：不合格批次直接拒收，供应商承担往返运费；或按坏果比例扣减货款。
- 扣款公式：建议写“坏果数量×该品类当日结算单价×赔付系数”，系数可设1.0—1.5，体现违约惩罚。
- 阶梯赔付：坏果率在阈值内（如3%）正常扣减；超过阈值（如5%）按比例加倍扣款；超过更高阈值（如10%）整批拒收并可暂停供货资格。
- 补货义务：约定供应商在多少个工作小时内补足合格货品，逾期按缺货违约金处理。
- 质量保证金：可设月度/季度质量保证金，按坏果率考核后返还或扣罚。

**4. 数据与举证规则**
- 约定验收单据、抽检照片、温控记录、监控录像作为赔付依据，双方签字确认的验收单具有效力。
- 约定异议期：供应商对验收结果有异议的，应在到店后X小时内提出并复检，逾期视为认可。
- 明确抽检方法和争议时的第三方检测机构及费用承担。

**5. 累计考核与退出机制**
- 按月/季度统计各品类坏果率，设“连续X次超标”“月度坏果率超过X%”触发整改、扣保证金、暂停供货、终止合同。
- 对高损耗品类（叶菜、浆果）单独设阈值，避免一刀切。

**6. 注意合同可执行性**
- 赔付条款要与采购单价、账期、返利条款联动，避免扣款无法落地。
- 明确“赔付不影响超市其他救济权利”，如因坏果导致客诉、下架、损耗的间接损失可约定限额赔偿。
- 避免只写“按实际损失赔偿”而不定义计算方式，否则争议时难以举证。

核心思路：**坏果率阈值分档 + 责任按环节切分 + 扣款公式写死 + 验收举证流程固定 + 累计考核退出**。这样既能把门店坏果损失转嫁到可控环节，又不会因条款过严导致供应商拒签或执行时扯皮。
