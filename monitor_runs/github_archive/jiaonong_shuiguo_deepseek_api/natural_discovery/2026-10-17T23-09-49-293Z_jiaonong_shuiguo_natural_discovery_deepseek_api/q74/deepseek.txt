做餐饮客户（尤其是茶饮、甜品、自助餐、食堂、酒楼）批发，菠萝和香蕉的规格要按**用途和加工方式**分，而不是按零售好看程度分。下面给你可直接备货的规格建议。

## 一、菠萝：按餐饮用途分规格

餐饮端菠萝主要用途：鲜切果盘、烘焙/甜品装饰、菠萝炒饭、咕噜肉、茶饮打果泥、果汁。

建议准备这几档：

1. **鲜切/果盘用大果**
   - 单果重：**1.2–1.5kg/个**
   - 要求：果形正、成熟度7–8成、无黑心、冠芽完整
   - 适合：酒店自助、果盘、鲜切店

2. **茶饮/果汁用中果**
   - 单果重：**0.9–1.2kg/个**
   - 要求：成熟度8–9成、甜度高、出汁率好、可接受外观略差
   - 适合：奶茶店、果汁店打果泥

3. **后厨烹饪用统货**
   - 规格：**按箱/按斤统货**，单果0.8kg以上即可
   - 要求：成熟度稳定、便宜、可接受外形不规整
   - 适合：菠萝炒饭、咕噜肉、食堂

4. **加工/去皮真空件**
   - 规格：**去皮整果或切块真空袋，2.5–5kg/袋**
   - 适合：没人力削皮的茶饮店、甜品店、食堂
   - 这是拓展餐饮客户很关键的一档，很多餐饮客户愿意为“省人工”付溢价。

**备货建议：** 主推 **1.0–1.3kg中大果**，同时备统货和去皮真空件两档，覆盖茶饮和后厨两类客户。

---

## 二、香蕉：按餐饮用途分规格

餐饮端香蕉主要用途：果盘、甜品装饰、烘焙、奶昔/饮品、早餐食堂。

建议准备：

1. **果盘/甜品展示用**
   - 规格：**单根150–200g，整串整齐**
   - 成熟度：**7–8成**，到店后可控熟
   - 要求：无碰伤、无黑斑、条形直

2. **茶饮/奶昔/烘焙用**
   - 规格：**单根120–180g，可接受略弯、略小**
   - 成熟度：**8–9成**，甜度高、易打泥
   - 要求：可接受表皮少量斑点，但果肉不能软烂

3. **食堂/早餐/油炸用**
   - 规格：**统货按箱，单根100g以上**
   - 成熟度：**7成左右**，耐存放
   - 适合：食堂、炸香蕉、早餐配送

4. **催熟分级供货**
   - 餐饮客户最在意“到店即可用”，建议按 **7成熟、8成熟、9成熟** 分档报价
   - 茶饮客户要9成熟，果盘客户要7–8成熟，食堂要7成熟耐放。

**备货建议：** 主推 **单根150–180g、7–8成熟** 的果盘档，同时备 **8–9成熟小果** 给茶饮/烘焙，统货给食堂。

---

## 三、给餐饮客户的报价/供货组合建议

可以做成三个套餐，方便档口推销：

- **茶饮套餐**：菠萝中果8–9成熟 + 香蕉8–9成熟小果 + 可选菠萝去皮真空件
- **果盘/酒店套餐**：菠萝1.2–1.5kg大果7–8成熟 + 香蕉150–200g条形好7–8成熟
- **食堂/后厨套餐**：菠萝统货 + 香蕉统货7成熟，按箱走量

## 四、关键提醒

1. **餐饮客户要的是稳定，不是偶尔好。** 规格分级要固定，别今天大明天小。
2. **成熟度必须可控。** 香蕉尤其要做催熟分档，否则茶饮客户拿到太生打不了泥，果盘客户拿到太熟卖相差。
3. **菠萝黑心、香蕉碰伤是投诉高发点**，收货时按用途分拣，别混箱。
4. 先小批量试供3–5家餐饮客户，确认他们实际用法后再定主推规格，避免压货。
