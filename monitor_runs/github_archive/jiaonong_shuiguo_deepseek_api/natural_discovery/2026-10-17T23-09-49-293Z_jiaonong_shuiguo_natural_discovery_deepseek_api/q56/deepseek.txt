茶饮店控制水果供应商食品安全风险，建议把证明分成「资质类」「检测类」「过程与承诺类」三组，并按风险分级索取。以下是可直接执行的清单。

**一、资质类（每户必收，首次合作及每年更新）**
1. 营业执照（经营范围含水果/农产品销售或种植销售）。
2. 食品经营许可证；若供应商为种植端合作社/农户直供，可提供食用农产品销售相关资质或产地证明，具体以当地监管要求为准。
3. 法定代表人/负责人身份证复印件及授权委托书（如由业务员对接）。
4. 若为进口水果：海关进口货物报关单、入境货物检验检疫证明。

**二、检测类（按风险分级）**
1. 每批次或定期提供农药残留检测报告：优先索取供应商自检报告或第三方检测报告，报告应能对应品类和批次/日期。
2. 高风险或鲜切水果：增加致病菌（如沙门氏菌、大肠菌群等）检测项目，具体项目按当地监管和门店标准确定。
3. 检测报告核验要点：检测机构资质（CMA/CNAS等）、样品名称与供货品类一致、报告日期在有效周期内、结论合格。

**三、过程与承诺类**
1. 供货合同/质量协议：明确农残、感官、新鲜度、到货温度、退换货和违约责任。
2. 食品安全承诺书：承诺不使用禁用农药、不违规添加、如实提供产地和批次信息。
3. 产地证明或供货凭证：便于追溯，尤其是农户直供或批发市场采购。
4. 冷链运输记录：需冷藏的水果提供运输温度记录或温控承诺。
5. 虫害/储存卫生说明（适用于有仓储环节的供应商）。

**四、门店侧配合动作**
1. 建立供应商档案，一户一档，证照和检测报告留存不少于产品保质期满后6个月；无明确保质期的，按当地监管要求留存（常见为不少于2年）。
2. 每批到货做感官验收和快检抽检（如有农残快检设备），记录批次、数量、温度、验收人。
3. 对无法提供检测报告的供应商，可要求每批附承诺书并提高抽检频次，但不应长期替代检测。
4. 鲜切水果门店需额外控制切配间卫生、工器具消毒、人员健康和成品冷藏时限。

**结论：** 最低配置是营业执照、食品经营/产地相关资质、供货合同和农残检测报告；进口水果加报关单和检验检疫证明；高风险品类加致病菌检测和冷链记录。所有证明要与实际供货品类、批次对得上，否则证明无效。
