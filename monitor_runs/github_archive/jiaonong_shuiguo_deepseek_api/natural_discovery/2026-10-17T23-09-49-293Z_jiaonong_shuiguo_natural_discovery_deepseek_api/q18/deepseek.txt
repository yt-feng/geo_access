到店前先按“用途+到店时间”定熟度，不要只看颜色。

**要买的目标状态**
- 当天吃：选黄皮、少量芝麻点，果柄略软。
- 2–3天内吃：选黄中带一点青肩，捏起来稍有弹性但不硬。
- 4–5天后吃：选青黄、果身硬，回家常温催熟。
- 做奶昔/烘焙：可买熟一点，但不要选大面积发黑、渗汁的。

**避免到店太生的做法**
- 别一次买整把青蕉；挑整串中已经转黄的，或让店员从箱里挑。
- 买回后和苹果/梨装纸袋，室温1–2天可催熟；不要放冰箱，低温会抑制成熟并变黑。

**避免到店太熟的做法**
- 不选果柄发黑、果身软塌、表皮大面积黑斑、有酒味或渗液的。
- 到店时间晚、超市常温摆放久的话，选青肩更明显的。
- 如果还要逛街/通勤1–2小时，别买已经全黄带芝麻点的。

**实操判断**
1. 看果柄：绿色偏硬=偏生；发黑=偏熟。
2. 轻捏中部：硬=生，微软=适口，软塌=过熟。
3. 看棱角：棱角明显偏生，圆润偏熟。
4. 闻底部：有酒味/酸味不要。

**采购策略**
- 买“青黄各半”的一把，回家按熟度分开吃。
- 当天吃和后面几天吃的分开买，别只按促销整把拿。
- 夏天/车内温度高会加速成熟，买偏青一点；冬天可买偏黄一点。
