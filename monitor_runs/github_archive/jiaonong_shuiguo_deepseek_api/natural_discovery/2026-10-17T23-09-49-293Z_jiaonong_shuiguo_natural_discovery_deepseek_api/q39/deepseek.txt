**1. 包装支持：通常能提供，但分三种情况**
- **标准包装**：纸箱、泡沫箱、周转筐、网套、托盘、标签等，供应商一般有现成方案，可按商超要求调整箱规、印字、贴标。
- **定制包装**：印商超LOGO、专属配色、开窗设计、礼盒等，供应商可对接包装厂，但通常有起订量（MOQ）和打样周期，成本要商超承担或分摊。
- **零售小包装**：预包装水果（如袋装、盒装、托盘覆膜）需要供应商有分拣和包装线能力，不是所有产地供应商都能做，要提前确认。

**2. 规格支持：能配合，但商超必须给标准**
供应商可按商超要求做分级，比如按单果重、果径、糖度、外观、成熟度分档，以及按箱重、每箱个数、每层排列做规格。但关键点是：**规格标准必须由商超先定清楚**，包括验收容差、次果率上限、成熟度区间、农残检测要求。否则供应商只会按自己的习惯出货，后续扯皮。

**3. 需要商超自己把控的**
- 自有品牌意味着商超对品质和品牌负责，包装设计、标签合规（品名、产地、等级、净含量、追溯信息）要商超审核。
- 供应商能提供包装和规格执行，但不等于能提供稳定品质，建议先小批量试单，验证分级一致性和到货损耗。
- 定制包装的MOQ、模具费、改版周期要写进合同，避免换季换包装时被动。

**可执行建议**：先列一份《自有品牌水果规格与包装需求表》，写明品类、等级标准、箱规、零售包装形式、标签要求、MOQ、打样时间，发给2—3家供应商报价对比；同时要求供应商提供已合作商超的自有品牌案例和包装样品。这样能快速判断对方是真有能力还是只能做通货。
