和水果供应商谈酒店早餐合作，重点是把“稳定供应”拆成可执行条款，而不是只谈价格。建议关注以下几方面：

1. **明确供应能力与备用方案**
   - 要求供应商说明产地、季节性替代方案、日配送能力、节假日/极端天气应对。
   - 合同中约定缺货时的替代品类、提前通知时限和违约处理。
   - 最好有备选供应商，避免单一来源。

2. **品控标准写清楚**
   - 按品类约定规格：等级、单果重量/大小、成熟度、色泽、瑕疵率、农残检测要求。
   - 约定验收标准和拒收规则，例如到货抽检不合格整批退换。
   - 要求提供检测报告或合规证明，并保留追溯信息。

3. **配送与验收流程**
   - 明确每日送达时间、卸货地点、冷链要求、包装规格。
   - 酒店方安排专人验收，记录到货时间、温度、数量、品质。
   - 约定临时加单、减单的截止时间和响应速度。

4. **价格与结算机制**
   - 不要只锁单价，要约定价格调整机制：随行就市时参考哪个市场价、调整频率、涨幅上限。
   - 明确含税/含运费、损耗承担方、退换货费用。
   - 账期、对账方式、发票类型写进合同。

5. **损耗与食品安全责任**
   - 明确到货前损耗由供应商承担，到货验收后按酒店储存条件划分责任。
   - 约定食品安全事故的召回、赔偿和配合调查义务。
   - 要求供应商具备相应经营资质和保险。

6. **试供与考核**
   - 先做2—4周试供，按到货准时率、合格率、缺货次数、投诉响应打分。
   - 考核结果与订单量、续约挂钩，避免口头承诺。

7. **合同细节**
   - 写清合作期限、最低供货量或框架量、保密与廉洁条款、终止条件。
   - 避免长期排他协议，保留引入第二供应商的权利。

实操上，建议先列早餐水果清单和日均用量，再让2—3家供应商按统一规格报价和试供，用验收数据决定合作方。
