# 单位采购水果：到货品质不一致的验收与售后处理

## 一、验收阶段：先定标准，再逐批核对

**验收前必须有的依据**

- 采购合同/订单中写明的品种、规格（单果重、果径）、等级、成熟度、产地、到货时限
- 双方确认的样品或封样（最有效的手段，留样拍照+签字）
- 抽检比例约定（如每批次随机抽10%~20%，大批量按箱抽）

**验收操作要点**

1. **分区码放**：到货后按批次、供应商分开摆放，未验收前不混放、不入库。
2. **分层抽检**：不能只看表层。从不同箱、不同层随机取样，重点看箱底和中间层（品质不一致常藏在这里）。
3. **逐项记录**：品种是否一致、大小是否均匀、成熟度是否参差、有无腐烂/碰伤/冻伤/虫害、净重是否与标示相符（去箱去垫称重）。
4. **拍照留证**：问题果单独拍照，带包装、带批次标签，最好有称重和日期信息。
5. **当场判定**：可分为"合格入库 / 让步接收（降价或折量）/ 拒收退货"三档，验收单由双方签字，写明差异数量和比例。

**品质不一致最常见的三种情况及处理**

- **品种/规格混装**：按合同判不合格，可整批拒收或要求按实际品种折价。
- **成熟度不均**：分开处理——熟果优先发放/加工，生果单独存放观察；整批混装严重的按比例扣量。
- **部分腐烂碰伤**：按抽检不合格率推算整批，超出约定阈值（如5%）的，按比例扣款或退货。

## 二、售后阶段：把责任和时限写清楚

**合同里应提前约定（采购前就要落笔）**

- 验收异议期：到货后多少小时内提出（生鲜建议24小时内，易腐品更短）
- 不合格处理方式：补货、换货、折价、退货、扣款，按不合格比例对应
- 补换货时限：如48小时内补齐，逾期视为违约
- 质保金/尾款：留10%~20%尾款，验收合格且无售后问题后支付
- 多次不合格的退出机制：如一个季度内2次以上批次不合格，可终止合作

**到货后发现问题时的处理流程**

1. 验收当场或异议期内书面（微信/邮件/验收单）通知供应商，附照片和抽检数据。
2. 要求供应商到场确认；不能到场的，以其书面确认为准。
3. 按约定选择：整批退货 / 按不合格比例扣款 / 限期补换货。
4. 补换货到货后重新抽检验收，不能免检。
5. 记录进供应商考核台账，作为后续采购和结算依据。

**内部管理建议**

- 建立验收台账：批次、供应商、抽检数、不合格数、处理结果、签字人。
- 验收人、使用部门、财务分开，避免"验收即入库、有问题没人认"。
- 对易腐水果尽量缩短"到货—验收—入库"时间，验收不合格的单独隔离，防止污染合格品。

## 三、一句话总结

**验收靠"合同标准+封样+分层抽检+拍照签字"，售后靠"异议期+比例扣款/退换+尾款约束"；把这两段写进采购文件，品质不一致就有据可依、有路可走。**
