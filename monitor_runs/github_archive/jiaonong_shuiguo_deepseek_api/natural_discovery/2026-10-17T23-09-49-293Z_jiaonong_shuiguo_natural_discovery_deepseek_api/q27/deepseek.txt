判断苹果和橙子的规格是否适合门店销售，核心是：**先定门店客群和售卖方式，再用“单果重量+果径+外观+损耗”四项一起判断**。不要只看大小。

**一、先按门店定位定目标规格**

1. **社区生鲜/家庭日常店**
   - 苹果：单果 **160–220g**，果径约 **70–80mm** 较稳妥；偏小果可做特价引流，但不做主陈列。
   - 橙子：单果 **180–250g**，果径约 **65–75mm**；脐橙可偏大，冰糖橙可偏小。
   - 原则：家庭装、按斤卖，中等规格最好卖；过大单价高、过小削皮麻烦。

2. **精品/水果专营店**
   - 苹果：**200–280g**，果径 **80–85mm**，要求果形端正、着色均匀。
   - 橙子：**220–300g**，果径 **75–85mm**，要求皮薄、无明显斑点。
   - 原则：可做礼盒或精品陈列，但必须分级清楚，大小混装会拉低溢价。

3. **便利店/小面积门店**
   - 优先 **小规格、单果装、按个卖**：苹果 150–200g，橙子 150–220g。
   - 避免超大果占陈列面、难按份定价。

**二、现场验货的可执行方法**

1. **抽样称重**
   - 每批随机抽 **20–30 个**，逐个称单果重，算平均重和最大最小差。
   - 同一陈列等级内，单果重量差异建议控制在 **±15%以内**；超过说明大小不匀，不适合混装主推。

2. **量果径**
   - 用果径圈或卡尺测横径，按 **5mm 一档**分级。
   - 苹果常见档：70–75、75–80、80–85mm；橙子常见档：65–70、70–75、75–80mm。
   - 门店销售最好 **同档同价**，不要大小果同筐同价。

3. **看外观和手感**
   - 苹果：果形周正、无明显畸形，着色面积一致，无碰压伤、无腐烂点；手感硬实。
   - 橙子：果皮细腻、油胞均匀，无青斑大面积、无软塌；同等大小手感偏重说明水分足。
   - 有 **日灼、药斑、机械伤、裂口** 的果不适合正价陈列，应挑出降级或做特价。

4. **算损耗和毛利**
   - 到店后挑出残次果，称重算损耗率。苹果、橙子正常损耗建议控制在 **3%–5%以内**；超过 8% 要重新评估采购价和规格。
   - 按“采购价÷（1-损耗率）+包装/人工”反推售价，再看同规格竞品价格是否有竞争力。

**三、快速判断标准**

- **适合门店销售**：同一批次大小均匀、单果重落在目标区间、果面干净、损耗低、按档定价后毛利合理。
- **不适合**：大小混杂严重、超大果占比高但门店没有礼盒渠道、小果比例高且只能低价处理、软果/伤果多、损耗超过 8%。
- **建议做法**：采购时要求供应商按果径或单果重分级供货；到店后二次分拣，分成“正价档/特价档/处理档”，不要一筐混卖。

一句话：**先按客群定克重和果径区间，再抽样称重测径，最后用损耗和毛利验证；均匀度比单纯大小更重要。**
