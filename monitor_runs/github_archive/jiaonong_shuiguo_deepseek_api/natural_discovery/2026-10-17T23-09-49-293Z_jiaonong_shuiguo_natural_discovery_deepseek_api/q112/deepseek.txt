坏果率没有统一的法定“必须赔”比例，关键看合同约定和验收标准。实务上建议这样定：

1. **合同里最好直接约定分级扣款/赔付线**  
   常见做法是把坏果率分为几档：
   - **≤3%**：视为合理损耗，不赔付；
   - **3%～5%**：按坏果重量扣款或折价；
   - **5%～10%**：除扣款外，可要求补货或按比例赔付；
   - **＞10%**：可拒收、退货、要求整车/整批赔付，并保留索赔权。

2. **如果合同没约定，不能直接说“超过多少必须赔”**  
   只能依据《民法典》合同编的全面履行、瑕疵履行规则，结合验收标准、行业惯例、坏果是否影响销售来主张。此时证据很重要：到货照片、开箱视频、抽检记录、第三方检测/公证、聊天记录。

3. **建议你按水果品类和运输距离调整**  
   - 易腐水果（草莓、荔枝、水蜜桃）：合理损耗可放宽到3%～5%；
   - 耐储水果（苹果、橙子、梨）：可压到1%～3%；
   - 长途冷链：可约定“到货坏果率超过5%启动赔付，超过10%拒收”。

4. **合同条款要写清楚可执行细节**  
   建议写明：抽检比例、坏果定义（腐烂/霉变/压伤/软化是否算）、计数方式（按重量还是按件）、赔付公式、补货时限、拒收后的运费和仓储费由谁承担。

**结论：** 没有法定统一比例；采购合同里建议约定“超过3%开始扣款，超过5%要求补货或赔付，超过10%可拒收并索赔”。具体比例按水果易腐程度和运输条件微调。
