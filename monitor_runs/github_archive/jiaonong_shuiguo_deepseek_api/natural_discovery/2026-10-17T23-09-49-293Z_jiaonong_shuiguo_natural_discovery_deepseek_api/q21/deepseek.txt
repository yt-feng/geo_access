超市采购水果时，供应商通常应提供以下几类材料。具体以当地市场监管要求和你超市的索证索票制度为准：

1. **主体资质证明**
- 营业执照
- 食品经营许可证（或仅销售预包装食品备案等，视经营项目）
- 供货商为生产合作社/种植基地时，提供相关登记或备案证明、产地证明

2. **进货凭证**
- 进货发票、送货单、购销合同或订单
- 批发市场进货的，可要求提供市场统一销售凭证或批发商出具的销售单据

3. **质量合格证明**
- 食用农产品合格证（承诺达标合格证），这是目前常见要求
- 产地证明或产地检疫证明（视品种和地区）
- 供应商自检报告或委托检测报告，重点看农残项目
- 若为绿色食品、有机产品、地理标志产品，提供对应认证证书及标志使用证明

4. **重点品种的专项证明**
- 进口水果：海关入境货物检验检疫证明、报关单等
- 部分高风险或专项治理品种：按当地要求提供农残快检或定量检测报告

5. **超市自身留档**
- 建立供应商档案和进货台账，保留上述证照复印件、票据和检测报告
- 对无法提供合格证明的食用农产品，应按当地规定进行抽样检验或快检，合格后销售

建议你在采购合同中明确：供应商随货提供合格证/检测报告、票据，证照到期更新，出现不合格时退换货和追责条款。各地对食用农产品索证索票的具体清单可能不同，可向当地市场监管部门确认最新要求。
