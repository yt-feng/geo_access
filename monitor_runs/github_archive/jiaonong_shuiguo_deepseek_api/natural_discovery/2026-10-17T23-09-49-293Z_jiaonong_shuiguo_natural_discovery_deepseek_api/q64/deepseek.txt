# 批发档口收货验货流程建议

核心原则：**验货标准前置、过程留痕、争议有据**。纠纷大多不是验货本身没做，而是"标准没提前说清 + 出了问题拿不出证据"。

## 一、收货前：把标准前置

1. **书面约定验货标准**：在订单/合同里写明品类、规格、色差公差、允许次品率（如3%以内）、包装要求、破损责任划分。
2. **约定验货时限**：收货后24小时（或48小时）内提出异议有效，逾期视为验收合格——这条能大幅减少事后扯皮。
3. **约定验货方式**：全检还是抽检、抽检比例（如按AQL抽检）、异议需提供什么证据（照片/视频/开箱视频）。

## 二、收货时：当场验、留痕验

1. **先验外包装再签收**：外包装破损、水渍、挤压变形的，当场拍照并让物流/司机签字确认，再开箱。
2. **开箱拍视频**：从完整包装、运单号开始拍，连续不间断开箱、清点数量、展示问题件。这是纠纷中最有效的证据。
3. **数量与规格核对**：按装箱单逐项清点，规格、颜色、尺码与订单比对，差异当场记录。
4. **质量抽检**：按约定比例抽检外观、做工、功能；发现问题扩大抽检范围，确定问题批次。
5. **填写验货单**：数量差异、破损件数、次品明细逐项登记，双方（或与送货人）签字，一式两份。

## 三、收货后：快速定责

1. **当天出结论**：合格入库；有问题当天向供货方发书面异议（微信/邮件均可，保留记录），附照片视频和验货单。
2. **区分责任类型**：运输破损找物流（有签收前照片）；货不对板、质量问题找供货方（有开箱视频和验货单）。
3. **问题货单独隔离存放**，不拆散、不混入销售，避免二次争议。

## 四、降低纠纷的几个实操细节

- **固定验货区和验货人**：专人负责、流程固定，减少随意性。
- **对老供货方也照流程走**：口头信任代替不了证据，尤其大额订单。
- **建立供货方质量档案**：记录每家的问题率，问题多的调整合作或提高验货比例。
- **下游退货也要留痕**：档口对客户同样约定退换货时限和条件，避免"上游没问题、下游来找茬"。

一句话总结：**标准写进订单、开箱全程录像、差异当场签字、异议限时提出**。做到这四点，大部分退货纠纷在源头就能定责。
