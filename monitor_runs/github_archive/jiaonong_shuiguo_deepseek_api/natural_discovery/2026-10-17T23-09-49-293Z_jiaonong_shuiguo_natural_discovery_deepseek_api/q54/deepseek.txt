优先看成熟度，其次才谈价格。对烘焙店来说，香蕉成熟度直接决定出品稳定性和损耗。

**建议的采购判断：**

1. **做香蕉蛋糕/香蕉磅蛋糕**
   - 选**表皮金黄、带少量黑点、果肉软但不烂**的香蕉。
   - 这种成熟度甜度高、香气足、易压泥，蛋糕风味最好。
   - 全青香蕉淀粉多、香气弱，烤出来发干、甜味不足。
   - 过熟发黑、果肉流汁的香蕉不适合直接做蛋糕主体，易发酸、出水、影响组织。

2. **价格什么时候可以让步**
   - 如果**当天或次日就要大量压泥使用**，可以买“熟度偏高但未腐烂”的折扣香蕉，但必须现场检查：无霉斑、无酒味、果肉不液化。
   - 如果**计划存放2—3天再用**，不要贪便宜买全熟蕉，损耗会吃掉差价。

3. **采购策略**
   - 按用途分批买：**七成熟**少量备货，**九成熟**当天用。
   - 固定供应商时，把“成熟度等级”写进采购标准，比单纯压价更重要。
   - 算成本要看**可用果肉出成率**，不是只看每斤单价。便宜但削耗大的香蕉，实际成本可能更高。

**结论：** 香蕉蛋糕的风味和稳定性主要由成熟度决定，价格只在“熟度合适且能快速用完”的前提下才值得考虑。采购时先定成熟度标准，再在合格货源里比价。
