判断批发档口的一手香蕉货源是否稳定，不能只看对方是不是“产地直发”或报价低，要拆成**供货能力、货源真实性、履约稳定性、风险兜底**四件事来验。下面给可执行判断法。

**1. 先问清“一手”到底在哪一手**
- 问具体产区、合作社/基地名称、加工厂位置、装车点。
- 真一手通常能说清：香蕉从哪片地/哪个收购点来、在哪催熟或分拣、装车走哪条线。
- 如果只说“云南/广西/老挝货源”，但说不出乡镇、装车点、合作基地，大概率是二级调货。
- 要求视频看货：看蕉园或收购点、催熟库/分拣场、装车现场，且视频里要有当天标识或现场口令。

**2. 验供货量是否匹配你的档口**
- 直接问：**每天能稳定给你多少件/多少吨，连续供多少天，雨季/节假日怎么保**。
- 稳定供货方一般有固定日加工量，能给出“常规日供量+峰值日供量+最低保底量”。
- 只承诺“要多少有多少”的反而要警惕，香蕉受季节、成熟度、运输影响，没人能无条件无限供。
- 可先下**小批量试单**：连续3—5天每天固定量，看是否按时、同规格、同成熟度到货。

**3. 看履约记录和履约方式**
- 要求提供近1—2个月给其他档口的发货记录：物流单、装车单、过磅单，敏感信息可打码，但要看日期连续性。
- 问清楚：**装车后多久发车、路上几天、到货时间误差多大、缺货怎么补**。
- 稳定货源通常有固定物流线路和备用车，不会临时“等拼车”。
- 可让对方给2—3个老客户电话，重点问：断货频率、到货成熟度是否一致、售后是否认账。

**4. 用合同和结算方式锁稳定性**
- 首次合作不要大额预付，建议**小批量、货到验收后结**或少量定金+到货结。
- 合同写清：品种/规格、单件净重、成熟度、允许损耗率、到货时限、缺货违约金、补货时限。
- 香蕉关键指标要写：条蕉长度/粗度、每件把数或净重、青度/黄度、是否有药害/水烂/黑星。
- 约定**验收标准**：到货抽检比例、不合格怎么扣款或退换。

**5. 识别不稳定的危险信号**
- 报价明显低于市场且催你打全款。
- 只能发“仓库图”，不愿视频看装车点或催熟库。
- 问日供量就含糊，或说“今天有明天不一定”。
- 物流单日期不连续、发货地频繁变。
- 售后只口头承诺，不愿写损耗和补货条款。
- 频繁换收款账户或要求私下转账。

**6. 最稳的验证路径**
先做**3—5天小批量连续试单**，同时视频验装车点、查物流单连续性、问2个老客户；试单稳定后再谈周供/月供和账期。稳定供货的核心不是“最便宜”，而是**说得出产地、拿得出连续发货记录、断货有补货方案、坏货有人认**。
