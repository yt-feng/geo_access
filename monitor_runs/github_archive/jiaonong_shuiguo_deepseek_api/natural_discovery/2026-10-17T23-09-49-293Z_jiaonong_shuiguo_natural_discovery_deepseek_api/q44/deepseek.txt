判断售后响应，不要只听供应商口头承诺，建议在合作前和试单阶段用下面几个可验证的动作：

1. **先明确售后标准再谈响应**
   菠萝、香蕉都是高损耗生鲜，采购要提前和供应商约定：
   - 到货腐烂、黑心、过熟、压伤、规格不符的赔付比例；
   - 售后申请时限，比如到货后几小时内反馈；
   - 响应时限，比如2小时内回复、24小时内给处理方案；
   - 补货、换货、扣款、退货四种处理方式各自适用情形；
   - 节假日、爆量期间的响应安排。

   没有书面售后条款的供应商，响应稳定性通常无法判断。

2. **用试单制造“小售后”来验证**
   首单不要只下顺利货，可在正常订单中安排少量易触发售后的批次，观察：
   - 反馈后多久首次回复；
   - 是否主动要照片、箱号、到货时间等证据；
   - 是否当天给出处理方案；
   - 是否按约定补货或扣款；
   - 第二次出现同类问题时是否仍同样处理。

   真正稳定的售后，是“第一次和第三次处理速度一致”。

3. **看对接人是否固定、是否有备选联系人**
   问清楚：日常谁对接、休息日谁接替、售后找谁、财务扣款找谁。要求提供至少两个联系人及电话。只给一个业务员微信、休假就失联的供应商，响应风险高。

4. **测试非工作时间和旺季响应**
   可在傍晚、周末或节前下小单并提一个合理售后问题，观察是否有人受理。生鲜商超的售后往往发生在凌晨到货、早市前，供应商若只在工作日白天响应，实际意义有限。

5. **查其现有客户和履约记录**
   要求供应商提供2—3家同类型商超客户作为参考，重点问：
   - 出现质量问题后一般多久处理；
   - 是否经常需要反复催；
   - 补货是否及时；
   - 月底对账扣款是否痛快。

   也可要求看近期的售后处理记录或补货单，注意隐去敏感信息即可。

6. **把售后响应写进合同和考核**
   建议约定：
   - 响应超时、处理超时的违约责任；
   - 月度售后响应率、平均处理时长；
   - 连续两次不响应可暂停下单或终止合作；
   - 质保金或货款中预留售后扣款机制。

7. **采购内部留痕**
   所有售后通过固定渠道提出，比如微信群+书面售后单，保留到货照片、开箱视频、称重记录和沟通时间。这样既能约束供应商，也避免口头扯皮。

简单判断标准：**能书面承诺、有固定双联系人、试单售后2小时内响应且24小时内闭环、旺季不失联、扣款不拖延的供应商，才算有稳定售后响应。** 只靠“放心，有问题找我”这句话，不足以判断。
