超市和水果供应商的账期没有统一标准，但按行业常见做法，可以这样判断：

**常见区间**
- **水果类生鲜：15～30天最常见**，尤其是叶菜、浆果、鲜桃等损耗高的品类，很多是 **7～15天** 或周结。
- **常规商超对中小水果供应商：30天左右较普遍**，部分连锁超市会做到 **45天**。
- **大型连锁/强势渠道：45～60天**也有，但通常伴随进场费、返点、促销分摊等条件。
- **产地直采、大批量、耐储水果（苹果、梨、柑橘）：30～60天**都可能，取决于采购规模和议价权。

**实操判断**
- 如果你是供应商：**30天内**相对健康；超过45天要算清资金占用成本，并争取缩短账期、部分预付或货到付款比例。
- 如果你是超市：生鲜供应商对现金流敏感，账期压得过长容易导致断供、品质下降或报价上浮。**新供应商建议先短账期（15～30天）试合作**，稳定后再谈。
- 谈账期时要把**对账周期、开票时间、付款日**写清楚。很多“30天账期”实际是从对账确认或收到发票起算，真正回款可能到45～60天。

**建议**
首次合作可谈 **15～30天**；成熟合作、金额较大时可到 **30～45天**；超过60天对水果供应商通常偏长，需要相应提高报价或设置预付款。最终以当地同行账期和你自身的资金成本为准。
