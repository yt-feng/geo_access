判断水果供应商靠不靠谱，核心看五件事：稳定性、品质一致性、价格透明度、售后担当、现场细节。你可以按下面的顺序逐步筛。

**1. 先看供货稳定性**
- 问清楚香蕉、菠萝的产地和季节切换方案。香蕉主产区会随季节变化，靠谱供应商能提前告诉你“下个月换哪个产区、口感差异、价格大概怎么走”。
- 问日均供货量、最少起订量、断货时怎么补。长期做水果店，最怕旺季断货、淡季硬塞。
- 连续试供2到4周，看是否按时到货、到货量是否稳定。只试一两次看不出来。

**2. 用固定标准验品质一致性**
- 香蕉：看催熟是否均匀、青黄是否一致、果指饱满度、有无机械伤和黑斑蔓延。每次到货抽几箱看底层和中间层，不能只看表面。
- 菠萝：看果形是否端正、果眼深浅、成熟度是否统一、有无水烂和黑心。切开抽检2到3个，记录糖度和口感。
- 关键不是“这次好不好”，而是“每次是不是差不多”。品质波动大的供应商，长期合作会拖累你的损耗和口碑。

**3. 看价格和账期是否透明**
- 要求报价说清楚：是毛重还是净重、含不含箱皮和损耗、运费谁承担、价格随行情怎么调。
- 警惕明显低于市场价的报价，通常会在净重、等级、催熟度或售后上找回来。
- 账期和结算方式提前谈清楚，避免后期因为几箱烂果扯皮。

**4. 重点考察售后担当**
- 明确问：到货损耗超过多少算供应商的？坏果怎么赔？是补货、扣款还是换货？多久内反馈有效？
- 试供期间故意反馈一次小问题，看对方响应速度和态度。推诿、拖延、只口头答应不落地的，直接降级。
- 长期合作一定要有简单的书面约定或聊天记录留痕，别只靠口头。

**5. 现场细节和资质**
- 去仓库或档口看：冷库温度是否稳定、香蕉和菠萝是否分开存放、有没有催熟房、装卸是否粗暴、地面是否积水。
- 看营业执照、食品经营相关资质，问是否有检测报告。不是要对方多正规，而是出事时能找到人。
- 问清楚他的上游是谁，是一手货还是二批。一手货通常价格和稳定性更好，但也要看他的分拣能力。

**实操建议：**
先选2到3家同时小批量试供，用同一套验收标准打分，连续跑一个月。重点记录：到货准时率、抽检合格率、损耗率、售后响应时间、实际净重和报价是否一致。一个月后留一家主供、一家备供，不要只押一家。香蕉和菠萝都是损耗敏感品，供应商的“售后是否认账”比“报价低几毛”更重要。
