# 超市水果到货品相不好：售后流程约定建议

水果属于生鲜易腐品，品相争议要在“可当场判断、可快速处理”的时间窗内解决，否则责任无法界定。建议在采购合同或到货验收单里把以下几项写死：

## 一、先明确“品相不好”的标准

不要用“品相不好”这种模糊表述，约定可量化的验收标准：

- **分级标准**：按品种写明规格、大小、色泽、成熟度、允许的瑕疵比例（如：单果腐烂率≤2%，压伤果≤5%，果径误差范围等）。
- **参照物**：以样品、图片或行业标准（如GB/T相关水果等级标准）为准，双方各留一份签字样品。
- **可接受范围**：明确哪些属于正常损耗（运输轻微擦伤、自然色差），哪些属于拒收或降级处理。

## 二、约定验收时限与方式

- **到货即验**：收货后X小时内（建议2–4小时，生鲜越短越好）完成抽检，抽检比例和抽检方法写清楚。
- **拍照留证**：开箱、抽检、问题果品同框拍照/录像，注明时间、批次、数量，作为售后依据。
- **签收即确认**：超过约定时限未提出异议，视为验收合格（避免事后扯皮）。

## 三、分层处理规则

按问题严重程度分档，写清对应动作：

| 情形 | 处理方式 |
|---|---|
| 轻微瑕疵、在允许范围内 | 正常收货，不扣款 |
| 瑕疵率超标但可折价销售 | 按比例扣款或降级定价（写明扣款公式，如：超标部分按货值X%扣减） |
| 腐烂/变质/严重不符 | 拒收该批次，或退货退款，运费由供方承担 |
| 部分批次问题 | 只退问题部分，不影响合格部分结算 |

## 四、售后响应与时限

- **报障时限**：买方发现问题后X小时内（建议24小时内，生鲜可更短）书面/系统提交，附照片和数量。
- **供方响应**：供方在X小时内（建议4–8小时）确认或提出异议，逾期视为认可。
- **处理完成时限**：确认后X个工作日内完成换货、补货或退款。
- **补货优先**：能补货的优先补货，避免影响销售；不能补货的走退款/扣款。

## 五、责任与费用划分

- 运输途中造成的损耗由谁承担（通常供方负责到收货点）。
- 退货产生的运费、损耗由责任方承担。
- 因品相问题导致的第三方索赔（如顾客投诉），责任归属写清。

## 六、留痕与对账

- 每次售后形成书面记录（验收单、问题照片、处理结论、扣款金额），双方确认。
- 扣款在当期或下期结算中体现，约定对账周期，避免累积争议。

## 七、兜底条款

- 约定争议解决方式（协商→行业调解→诉讼/仲裁）。
- 对高频问题品种，可约定“连续X批次不合格可暂停供货或终止合作”。

**核心原则**：标准量化、时限明确、留证可查、处理分层。水果品相争议最怕“事后说不清”，把验收时点和证据要求写进流程，比事后争论“好不好看”有效得多。
