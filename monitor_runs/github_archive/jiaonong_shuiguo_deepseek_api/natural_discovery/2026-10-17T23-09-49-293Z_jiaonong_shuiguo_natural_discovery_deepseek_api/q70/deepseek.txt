# 坏果责任条款的写法建议

核心思路：**把“谁承担损耗”从模糊的“验收合格后付款”里拆出来，用“分级标准＋时效＋举证＋扣款机制”四条锁死。**

## 一、先定标准（否则责任无从谈起）

条款里必须写明坏果的判定口径，建议采用可量化的分级：

- 按**品种等级**（如一级/二级）分别约定允许的次果率上限，例如“到货次果率≤3%视为合格”。
- 明确“坏果”定义：腐烂、机械伤、软化出水、霉变等，逐项列举，避免争议时各说各话。
- 约定**抽检方法**：抽检比例（如每车随机抽10箱、每箱抽10个）、计数方式、双方是否到场共同验货。

## 二、责任归属按环节切分

- **装车前的损耗**：由供货方承担，以装车时双方签字的验货记录为准。
- **运输环节**：明确运输责任方（供方代办运输还是需方自提）。若供方负责送达，运输途中非需方原因造成的损耗由供方承担；若需方自提，装车后风险转移，但可约定“装车后X小时内到货”的时效约束。
- **到货后**：约定验收时限（如到货后**24小时内**完成验收并书面提出异议），逾期未提视为合格——这一条对双方都是保护。

## 三、扣款与补货机制（最关键）

不要只写“坏果由供方负责”，要写清楚怎么算钱：

- 超过允许次果率的部分，按**当批次单价×超损数量**从货款中直接扣除；
- 或约定“超损率每超1%，扣该批货款的X%”；
- 严重情形（如次果率超过10%）赋予需方**拒收或整批退货**的权利，退货运费由供方承担；
- 可加“补货优先”条款：供方在X日内补足合格货，补货部分不再计损耗。

## 四、举证与争议处理

- 验收时**拍照/视频留存**并双方签字确认，作为扣款依据；
- 约定异议期内的复检机制（如双方各请第三方或共同送检）；
- 明确“未在异议期内提出视为认可”，防止事后扯皮。

## 五、一条兜底表述（可直接改用）

> “货物到达需方指定地点后24小时内，需方按本合同约定的抽检方法验收。次果率未超过约定上限的，视为合格；超过部分的坏果，按当批次单价从应付货款中扣除，供方应在收到通知后3日内补足或退款。次果率超过10%的，需方有权拒收整批货物，往返运费及因此产生的损失由供方承担。逾期未提出书面异议的，视为验收合格。”

**提醒**：条款写得再细，前提是**装车和到货都有双方签字的验货单**。没有书面记录，坏果责任条款基本无法执行。建议把验货单作为合同附件，格式一并约定。
