更该看重**坏果率和熟度**，价格和送货速度排后面。香蕉是易损耗、后熟型水果，小店的利润往往不是被“进价高一点”吃掉的，而是被烂掉、催不熟、卖相差吃掉的。

建议按这个优先级判断：

1. **坏果率：第一优先**
   - 先看整批货的机械伤、黑斑、断指、发霉、水烂。
   - 小水果店议价能力弱，坏果多等于实际进价大幅上升。
   - 可执行标准：抽看箱底和中间层，不只看表面；坏果率明显高就压价或换货。

2. **熟度：第二优先**
   - 香蕉要按你预计几天卖完来选熟度。
   - 当天/次日卖：选黄熟、少量芝麻斑的。
   - 2～3天卖：选黄中带绿、棱角略明显的。
   - 更久卖：选偏绿但饱满的，别选“青得发硬”的，后熟风险大。
   - 熟度不匹配会导致要么当天卖不掉变黑，要么顾客买回去不能马上吃。

3. **价格：第三优先**
   - 在坏果率和熟度合格的前提下比价。
   - 不要只看每箱/每斤报价，要算“可售果成本”：进价 ÷ 可售比例。
   - 便宜但坏果多、熟度差的货，实际更贵。

4. **送货速度：第四优先，但有底线**
   - 香蕉不需要追求极快，关键是**到货稳定、少中转、少挤压**。
   - 送货慢但损耗低，通常比送得快但压伤多更划算。
   - 只有在你缺货断档、或夏天高温运输时，速度才要提前。

**简单决策规则：**
- 先淘汰坏果率高的；
- 再选熟度适合你销量的；
- 然后比可售果成本；
- 最后看送货是否稳定及时。

如果只能记一句话：**小水果店进香蕉，先保“能卖、少烂”，再谈“便宜、快送”。**
