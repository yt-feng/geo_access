家庭团购水果礼盒，建议以“耐放、全家都能吃、成本可控”为核心。苹果、橙子、香蕉、菠萝这四样里，**苹果和橙子做主，香蕉和菠萝做点缀**更合适；不建议四样平均分，因为香蕉易压伤、菠萝处理麻烦，放多了反而降低礼盒体验。

**推荐组合（按家庭装 5kg 左右）**
- 苹果 2kg：选中等果，耐放，老人小孩都适合。
- 橙子 2kg：选易剥品种，团购走量稳定，酸甜接受度高。
- 香蕉 0.8kg：选七成熟青黄蕉，单独隔层放，避免压苹果。
- 菠萝 1 个：约 1—1.5kg，选已削皮装盒或带冠小果，方便家庭一次吃完。

**为什么这样配**
- 苹果、橙子占 80%，礼盒看起来饱满，运输损耗低，家庭复购概率高。
- 香蕉少量放，满足“开箱即吃”，但要用隔板或网套保护，别和苹果紧贴，苹果释放乙烯会催熟香蕉。
- 菠萝只放 1 个，作为亮点；如果团购对象是老人多的家庭，可把菠萝换成同价橙子或苹果，减少处理负担。

**两个实用版本**
- 经济家庭版：苹果 2.5kg + 橙子 2.5kg + 香蕉 0.5kg，不带菠萝，损耗最低。
- 丰富家庭版：苹果 2kg + 橙子 2kg + 香蕉 0.8kg + 菠萝 1 个，适合节日团购。

**包装和定价建议**
- 用硬纸箱加蛋托隔层，香蕉单独装袋，菠萝竖放或单独网套。
- 定价按“经济版走量、丰富版做利润款”，团购页明确标注“香蕉七成熟，收到后常温放1—2天再吃”。
- 售后提前说明：香蕉表皮轻微碰伤、菠萝冠叶干枯不影响食用，避免团购纠纷。
