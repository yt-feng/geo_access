判断能否全年稳定供货，别只看供应商口头承诺，按下面几步做可核验的检查：

**1. 先问清供应结构，而不是问“能不能全年供”**
- 香蕉来源是单一产区还是多产区拼供？单一产区一定有季节性断档风险。
- 各产区分别对应哪几个月？列出12个月供应表，看有没有空档月。
- 国产（云南、广西、海南、广东、福建等）与进口（菲律宾、厄瓜多尔、越南等）如何搭配？进口可补国产淡季，但要确认报关和冷链能力。
- 要求供应商书面提供“月份—产区—预计周供量”表，作为合同附件。

**2. 看基地和加工能力，不只看贸易商身份**
- 是自有/合作基地，还是纯转手贸易？纯贸易商在缺货时优先保大客户，你是连锁超市未必排得上。
- 有没有自己的催熟库？香蕉必须催熟后上架，催熟能力决定旺季能否放量、淡季能否保供。
- 实地看：基地面积、挂果周期安排、催熟库容、冷库和冷链车队。

**3. 用历史数据验证，而不是听承诺**
- 要近12个月的逐月发货记录，重点看淡季月份（通常是国产蕉偏少的时段）发了多少。
- 要近2—3年合作客户的供货合同和履约情况，最好能联系1—2家同类超市客户侧面核实。
- 问清楚过去两年是否发生过断供、断供原因和处理方式。

**4. 做小批量压力测试**
- 先签3—6个月试供合同，故意覆盖一个淡季月份。
- 设定考核指标：到货准时率、单批次缺货率、损耗率、规格合格率、催熟后货架期。
- 试供期内要求每周固定报下周可供量，观察其预报准确度。

**5. 合同里把“稳定”变成可追责条款**
- 约定月度最低供货量和淡季保底量，明确断供违约金。
- 约定替代方案：主产区缺货时，供应商须在多长时间内从备用产区补货。
- 约定价格联动机制，避免缺货时被临时抬价。
- 要求关键产区/基地变更需提前报备，防止中途换低质货源。

**6. 自己留一手**
- 至少保持2家供应商，主供70%—80%，备供20%—30%，备供哪怕价格略高也要养着。
- 与备供商保持小批量持续合作，确保其随时能接量。

**一句话判断标准**：能拿出逐月产区供应表、有自有催熟和冷链、有覆盖淡季的历史发货记录、且愿意接受淡季保底量和断供违约条款的供应商，才具备全年稳定供货的基础；只承诺“没问题”但拿不出数据和合同的，按不稳定处理。
