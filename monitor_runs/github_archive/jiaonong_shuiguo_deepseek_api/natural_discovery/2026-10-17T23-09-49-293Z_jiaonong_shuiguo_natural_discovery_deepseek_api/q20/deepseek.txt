找每天配送的水果供应商，核心是看“稳定供货能力”和“配送履约能力”。建议按下面条件逐项核查，能现场验证的就不要只听口头承诺。

**1. 供货与产地能力**
- 是否有稳定的一级批发市场档口、产地直采基地或长期合作果园。
- 每天可供品类是否覆盖你店里常卖的10—20个核心单品，而不是偶尔有货。
- 季节性断货时有没有替代方案，比如换产地、换规格。
- 能否提供农残检测报告或进货凭证，至少做到可追溯。

**2. 配送履约能力**
- 是否每天固定时段配送，能否接受你要求的到店时间，比如早6点前到店。
- 自有车辆还是外包物流，车辆数量和覆盖范围是否匹配你的位置。
- 节假日、雨天、旺季是否照常配送，有没有备用车辆。
- 缺货、晚到怎么处理，能否当天补送。

**3. 价格与结算**
- 报价是每天随行就市，还是阶段性锁价，调价是否提前通知。
- 是否含配送费、装卸费、损耗补贴，起送量是多少。
- 结算周期是现结、周结还是月结，是否接受对账后付款。
- 同规格同品质下比较净价，不要只看毛价。

**4. 品质与损耗**
- 到货验收标准要写清楚：规格、成熟度、外观、允许损耗比例。
- 坏果、烂果、短斤少两怎么赔，是补货、折价还是退款。
- 能否先小批量试配一周，观察实际到货品质和损耗率。

**5. 响应与服务**
- 是否有固定对接人，微信或电话能否及时响应。
- 临时加单、减单的截止时间，比如前一天几点前可改单。
- 能否配合你做一些分级分拣，比如按门店陈列规格分装。

**6. 资质与风险**
- 营业执照、食品经营相关资质是否齐全。
- 了解其合作客户，最好有同类型社区超市或生鲜店案例。
- 不要一次性压太多预付款，先短期合作再逐步放量。

**实操建议：** 先列3—5家候选，每家试配3—7天，重点记录“到店准时率、缺货率、损耗率、售后响应速度”四项数据，再决定长期合作。合同里把配送时间、验收标准、损耗赔付和调价机制写明确。
