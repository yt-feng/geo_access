会，而且香蕉和菠萝的损耗风险对起订量变化都比较敏感，但原因不同。

**香蕉**
- 香蕉是后熟型水果，到货后仍会持续成熟，销售窗口短。
- 起订量高会带来集中到货、集中催熟、集中变软的问题，一旦卖不动就容易出现黑斑、过熟、报损。
- 建议：按“日均销量×周转天数”倒推起订量，周转天数控制在3～5天；优先小批量高频补货；要求供应商分批催熟或按成熟度分档发货。

**菠萝**
- 菠萝相对耐储，但整箱起订量高会带来库存积压、果眼发黑、内部褐变、底部腐烂等隐性损耗。
- 高起订量还会逼你压价促销，降低毛利。
- 建议：按周销量或活动销量定起订量；到货后先卖成熟度高的，冷藏或通风分储；整箱采购前确认箱规、单果重量和可拆分性。

**判断标准**
起订量是否过高，可以看一个简单指标：  
`起订量 ÷ 日均销量 = 预计周转天数`  
- 香蕉超过5天：损耗风险明显上升。
- 菠萝超过7～10天：也要警惕。
- 若起订量对应周转天数超过保质窗口的70%，就应谈拆分、拼单、减少SKU或改小箱规。

**可执行建议**
1. 先统计近2～4周日均销量和报损率，再倒推安全起订量。
2. 和供应商谈“小箱规、多频次、混拼”，比单纯压价更降损耗。
3. 对新品或促销期，先用小批量试销，再放大起订量。
4. 把损耗率纳入采购考核，避免只盯采购单价。

结论：起订量太高会显著增加香蕉和菠萝的损耗风险，香蕉尤其明显；应优先用小批量高频补货和更小箱规来控制。
