大型超市对水果供应商的要求，通常高于普通批发市场。核心是：**食品安全合规能力 + 冷链与履约能力 + 追溯与召回能力 + 稳定供货与品控能力**。可以按下面几类判断。

## 1. 食品安全合规能力（准入底线）

供应商至少要具备：

- **合法经营资质**：营业执照、食品经营许可证或食用农产品销售相关合规资质；种植/合作社类要有产地证明。
- **农残与污染物检测能力**：
  - 每批次或按超市要求频次提供农残检测报告；
  - 重点品类检测重金属、保鲜剂、真菌毒素等风险项；
  - 有自检实验室或稳定合作的第三方检测机构。
- **产地与投入品管理**：
  - 农药、化肥、保鲜剂使用记录；
  - 采收安全间隔期管理；
  - 禁止使用违禁农药，能提供产地环境说明。
- **包装与标签合规**：预包装水果标签、产地、等级、生产日期/采摘日期、储存条件等符合要求；散装水果有批次信息。
- **人员与场所卫生**：分拣、包装场所卫生管理，人员健康证，虫害控制，清洗消毒记录。
- **召回与不合格品处置制度**：能按批次召回、隔离、销毁并留记录。

大型超市通常会做**供应商审核**，包括文件审核和现场审核。没有检测报告、批次记录和召回制度，基本很难进入。

## 2. 冷链与物流履约能力

水果损耗高，物流能力直接决定能否稳定供货：

- **冷链仓储**：冷藏库、预冷设施，能按品类分温区管理；苹果、梨等耐储果与浆果、荔枝、车厘子等需分开控温。
- **预冷能力**：采收后快速预冷，尤其是叶菜类水果、浆果、桃李等易腐品类。
- **冷链运输**：冷藏车或保温车，有温度记录仪和全程温控数据；长途运输能提供温度曲线。
- **配送时效与频次**：能按超市DC（配送中心）或门店要求做日配/隔日配，具备夜间到货、预约送货能力。
- **装卸与周转**：周转筐、托盘标准化，避免挤压、日晒、雨淋；有破损率和损耗率控制方案。
- **应急能力**：旺季、节假日、极端天气下的备货和替代物流方案。

## 3. 追溯与质量管理能力

- **批次追溯**：从产地、采收、分拣、包装、入库到发货，能按批次追溯；出现问题能锁定同批次去向。
- **进货查验与出货记录**：每批有产地证明、检测报告、入库验收记录、发货记录。
- **分级与验收标准**：能按超市的规格、糖度、色泽、大小、瑕疵率分级，接受超市DC验收和退换货规则。
- **损耗与保鲜管理**：有品类保鲜方案、库存周转规则、临期处理机制。

## 4. 供货稳定与商业履约能力

- **货源稳定性**：自有基地、长期合作基地或多产地调配能力，避免单一产地断供。
- **产能与SKU覆盖**：能覆盖超市要求的品类和规格，旺季有增量供应能力。
- **结算与保险**：能接受账期、开票；有货物运输险或产品责任险更有利。
- **食品安全责任承担**：合同中能接受质量违约、召回、赔偿条款。

## 快速判断清单

如果只看关键项，大型超市水果供应商至少要能回答“是”：

1. 是否有合法资质和产地证明？
2. 是否能按批次提供农残检测报告？
3. 是否有预冷和冷藏运输能力，并能提供温度记录？
4. 是否能按批次追溯并执行召回？
5. 是否能按超市标准分级、验收和稳定日配？
6. 是否有不合格品隔离、销毁和记录制度？

**结论**：大型超市水果供应商的门槛不是“能供货”，而是“**合规可查、冷链可控、批次可追、质量可赔、供应稳定**”。食品安全合规是准入线，冷链和追溯是日常履约核心，稳定供货和品控决定能否长期合作。
