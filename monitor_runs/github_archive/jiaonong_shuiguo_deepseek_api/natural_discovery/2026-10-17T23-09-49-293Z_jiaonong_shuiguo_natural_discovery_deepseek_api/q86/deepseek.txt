做生鲜水果一件代发，供应商的仓配能力要按“能发货、发得稳、坏果可控、售后可追溯”四条来判断。建议重点核验以下能力：

1. **产地/销地仓与温区能力**
- 是否有常温、冷藏、催熟/暂存等分区；不同水果（香蕉、芒果、浆果、柑橘）温区要求不同。
- 仓库是否靠近产区或主销区，能否支持多仓发货降低时效和损耗。
- 是否具备预冷、分拣、打包、贴单一体化作业。

2. **订单履约与日处理能力**
- 日峰值单量、平均出库时效、截单时间、节假日/大促承载能力。
- 是否支持多平台订单接入、电子面单、批次打印、拆合单、赠品/卡片等定制。
- 能否承诺发货时限和超时赔付规则。

3. **包装与保鲜能力**
- 是否有水果专用包装方案：防撞、透气、吸水、冰袋/保温箱/泡沫箱等组合。
- 是否按品类做成熟度分级和包装适配，避免“统一包装发所有水果”。
- 能否提供包装测试数据和历史破损率。

4. **冷链与快递资源**
- 是否自有冷链车/干线，还是整合快递、落地配；冷链覆盖范围和一票多件能力。
- 合作快递是否稳定，旺季是否保时效；偏远地区、高温地区是否有专门方案。
- 能否提供物流轨迹回传和异常件预警。

5. **品控与损耗管理**
- 到仓验收标准、分级标准、成熟度标准、抽检比例和留样制度。
- 历史坏果率、破损率、客诉率数据；坏果包赔规则和补发/退款流程。
- 是否支持批次追溯：产地、采摘/入库时间、质检记录、发货批次。

6. **库存与系统能力**
- 是否支持实时库存同步、预售/缺货拦截、批次先进先出。
- 能否对接平台ERP/OMS/WMS，提供发货回传、物流单号回传、售后数据。
- 库存准确率和盘点频率。

7. **售后与逆向处理**
- 坏果理赔时效、举证方式（照片/视频/开箱视频）、赔付上限。
- 是否支持补发、退款、拒收处理；逆向件是否回收或就地销毁。
- 客服响应时间和异常订单处理SOP。

8. **合规与资质**
- 营业执照、食品经营/生产相关资质、产地证明、检测报告。
- 农药残留检测、检疫证明（如涉及）、包装标签合规。

**实操建议：**先小批量试发，选3-5个典型城市和2-3个易损品类，连续跑2-4周，重点看“48小时签收率、坏果率、破损率、客诉响应时长、库存准确率”。合同里明确发货时效、坏果赔付比例、旺季保障、系统对接责任和数据回传要求。不要只看报价，水果一件代发的核心成本往往在损耗和售后。
