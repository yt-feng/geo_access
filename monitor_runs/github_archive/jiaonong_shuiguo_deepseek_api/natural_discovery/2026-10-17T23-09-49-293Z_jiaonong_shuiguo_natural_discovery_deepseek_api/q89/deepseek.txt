结论先说：**对价格敏感、以“拿低价”为主要决策依据的团购客户，优先用阶梯价；返利只作为补充，用来锁量、锁复购和防止窜货。** 但具体要看团购客户是“一次性大单”还是“持续多批次采购”，以及你能否核验真实销量。

**判断标准与建议：**

1. **一次性、集中采购的团购客户 → 阶梯价更合适**
   - 价格敏感客户要的是“当场看到单价下降”，阶梯价最直观，成交阻力小。
   - 返利要事后兑现，客户会担心拿不到、周期长、算不清，砍价时反而更难谈。

2. **持续采购、多批次的团购客户 → 阶梯价为主，返利为辅**
   - 用阶梯价覆盖基础量级，给到“达到某量就降价”的确定性。
   - 再用返利奖励“年度累计量、按时回款、不窜货、复购稳定”，把优惠和可控行为绑定。

3. **担心客户压价、虚报量 → 少用前置阶梯价，多用返利**
   - 阶梯价一旦给出去，后续很难收回，客户可能先拿低价再拆单。
   - 返利按**实际回款销量**结算，能防止虚单、退货和窜货，适合量难核实的情况。

4. **阶梯价设计要点**
   - 档位不要太多，2—3档即可，避免客户只盯着最低档砍价。
   - 明确“以实际回款发货量为准”，写清退货、拆单、跨区销售的处理。
   - 最低档价格要留足毛利，不要为了团购大单击穿日常渠道价格。

5. **返利设计要点**
   - 返利比例不宜过高，建议以**年度/季度累计**为主，按回款结算。
   - 返利形式可用货款抵扣、下一单折扣，避免直接返现金。
   - 设置封顶和排除条款，防止客户为冲返利压货、窜货。

**一句话执行建议：** 先给客户一个**小档阶梯价**促成首单，再签**累计返利**绑定后续复购；如果客户只做一次性大单且量可核验，就直接用阶梯价，别把返利复杂化。
