针对生鲜电商水果到货后坏果的责任划分，建议按以下步骤处理：

1. **运输环节**：如果坏果是由于物流运输过程中的挤压、撞击或保温不当导致（如快递延误、暴力装卸），责任主要在于快递公司或电商平台（由其作为发货方与物流合同约定责任）。
2. **包装问题**：如果电商的包装不合理（如未使用防撞泡沫、冰袋未有效放置、纸箱过软），导致水果在运输中受损，电商应承担主要责任。
3. **水果品质**：如果水果本身在发货前已开始腐烂或过熟，属于电商发货质检不到位，商家需全责。
4. **顾客保存**：到货后顾客如未及时签收、未按储存要求冷藏、或放置过久导致后续腐烂，责任归于顾客。
5. **到货即损**：若顾客签收时已发现明显坏果，建议优先由电商直接赔付（通常平台有“坏果包赔”政策），此时责任在商家。

**实际操作建议**：
- 顾客收到坏果后，应立即拍照（含快递单、坏果全景、包装状态）并保留证据。
- 优先通过平台客服申请售后，多数平台政策是“部分坏果按比例赔付，全部坏果全额退款”。
- 如果是“生鲜易腐”商品，部分平台规定签收后24小时内反馈有效，超时可能无法获赔。
- 如果电商推卸责任（例如称顾客签收未检查），可向12315或市场监督管理局投诉。

最终，在无第三方责任（如快递暴力）时，电商公司通常承担最终赔付义务（因其与顾客存在买卖关系），物流风险一般由平台预购时已承担。
