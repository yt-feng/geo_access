遇到水果到货不合格时，建议按以下步骤处理并约定补货，以减少对营业的影响：

1. **立即检查并记录**：到货后立即开箱检查，拍照或视频记录不合格情况（如腐烂、压伤、成熟度不够等），并保留问题样品。

2. **通知供应商**：第一时间联系供应商，明确告知不合格比例、问题类型，并引用合同条款（如无合同则口头说明）。

3. **约定补货时间**：要求供应商在**约定时间内**（通常2-6小时内，视紧急程度）补发合格水果。可提出三个选项供其选择：
   - **同日补货**：若问题严重且急需，要求当日下午或晚上送达。
   - **次日优先补货**：若问题不严重，可协商次日早晨优先送达。
   - **临时替代方案**：若无法及时补货，要求供应商提供其他水果（如库存替代品种）或减少配送量，并调整订单。

4. **明确补货规格与价格**：补货水果必须符合原合同的**质量标准**（如大小、成熟度、新鲜度），且价格按原订单价执行，不得加价。

5. **约定违约责任**：如供应商未按时补货或补货仍不合格，应约定：
   - 按缺货部分货款的一定比例（如20%-50%）赔偿。
   - 提供免费替换或下次订单折扣（如满减）。

6. **调整营业计划**：在补货到达前：
   - 临时下架依赖该水果的饮品，并在菜单标注“今日售罄”。
   - 用库存替代品开发临时饮品（如橙子不合格改用柠檬），并告知顾客“本店因原料更换推出限时新品”。
   - 若影响大量订单，可主动致电已下单顾客说明情况并提供优惠券补偿。

7. **记录并改进**：对本次事件形成书面记录，包括供应商反馈、补货时间、损失，后续在合同中明确“首次不合格需在X小时内补货，违规扣减履约保证金”等条款。

**关键点**：补货时间必须具体到“时”，质量标准需对标原合同，违约责任应量化（如“每延迟1小时赔付5%货款”），同时立即启动替代方案避免断货。
