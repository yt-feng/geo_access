判断连锁超市香蕉供应商能否全年稳定供货，可重点考察以下核心维度：

1. **产地资源与多区域布局**：询问供应商是否拥有或合作来自不同气候带的香蕉产区（如：国内海南、广西、云南，以及厄瓜多尔、菲律宾等进口产区）。若供应商在至少2-3个地理隔离的产区有稳定合同或自有基地，则有效降低因单一区域台风、病害或季节性空窗期导致的断供风险。

2. **历史供应数据核查**：要求供应商提供过去24个月（至少12个月）的月度供货记录。关注是否存在连续2个月以上供货量低于合同量80%的情况。可随机抽取上年度3月和9月（传统淡旺季）的发货单据进行交叉验证。

3. **冷链物流与存储能力**：评估其是否具备预冷处理设施及不同温区的冷藏仓库（香蕉最佳储存温度13-14℃）。对于运输距离超过200公里的供应商，需确认其运输车辆是否配备恒温控制及实时温控记录仪。可要求提供最近三个月内的冷链设备维护记录。

4. **稳定的人力与采收窗口**：香蕉采收受成熟度严格限制。核实该供应商能否在全年365天内，每周至少提供3次采摘作业（节假日不中断）。可通过询问其采收工人数量、是否签订长期合同来判断。

5. **应急与替代方案**：明确询问“若突发产期灾害导致供货中断，贵方是否有备用供应商或进口渠道能在72小时内补充货源”。要求提供至少2家已签合作意向的备用供应商名单及对应的合同复印件（可遮盖价格等敏感信息）。

实际合作中，建议先签订**3个月短期试采购合同**，重点考察：每月实际到货的品相均匀度、单箱重量误差率（行业通常允许±0.3kg）、以及因断货产生的缺勤天数。如果出现连续两个月缺勤超过5%，则全年供应能力通常存疑。
