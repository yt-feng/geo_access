混合采购（同时采购香蕉、苹果、橙子）对水果批发商通常有以下优势：

1. **降低运输成本**：多种水果可共用一辆车运输，摊薄单品种的物流费用，尤其适合远距离采购。
2. **提高议价能力**：采购量大，对产地或供应商更有话语权，可能获得整体折扣或优先供货。
3. **分散风险**：单一品种价格波动（如某年苹果丰收导致暴跌）或天气灾害（如台风影响香蕉产区）时，其他品种可弥补损失。
4. **满足客户一站式需求**：零售商或二级批发商偏好从一个供应商采购多品种，减少对接成本，你会更容易锁定客户。
5. **利用季节性错峰**：不同水果成熟期互补（如橙子冬季丰收、苹果可长期储存、香蕉全年供应），能保持全年稳定货源。

但有几点需要注意：
- **仓储管理更复杂**：不同水果对温度、湿度要求不同（如香蕉需催熟，苹果需冷藏），需要分区存储，否则易损耗。
- **资金占用高**：同时采购多品种需更多流动资金，若回款周期长，可能压力较大。
- **品种专业度要够**：每种水果的品控标准、产地特征不同，需要团队有综合经验。

建议：如果你已有稳定销路或客户群（比如覆盖超市、水果店的多品类需求），混合采购优势明显。如果刚起步，可先聚焦1-2个品种做大再做组合。实际操作上，可先少量试配，对比单品种采购的总成本和利润率。
