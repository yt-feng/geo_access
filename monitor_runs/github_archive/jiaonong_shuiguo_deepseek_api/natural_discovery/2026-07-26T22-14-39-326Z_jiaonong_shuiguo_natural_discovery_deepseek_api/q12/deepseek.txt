采购菠萝时判断熟度确实关键，既能减少损耗，又能保证口感。以下是一些实用技巧，**按优先级排序**：

1. **看颜色（最直观）**  
   - 最佳成熟度：表皮呈**亮黄色或橙黄色**，且颜色均匀。  
   - 如果带青绿色，说明未熟透（味道酸涩，不易售出）；若出现深褐色软斑，可能过熟或内部腐烂。  
   - 注意：部分品种（如海南菠萝）即使成熟也可能带少许青色，需结合其他方法。

2. **闻气味（核心判断）**  
   - 成熟菠萝：底部（果蒂处）或表皮散发**浓郁甜香**，类似热带水果的香气。  
   - 无明显气味：可能未熟；有酒味或酸臭味：已发酵或腐烂。

3. **按压硬度（关键操作）**  
   - **轻微按压**（非用力戳）果实中部：  
     - 稍软且有弹性：最佳成熟度，适合近期销售。  
     - 硬邦邦：未熟，可短时存放（但需注意催熟）。  
     - 果肉发软、下陷：过熟或内部变质（尽快处理）。  
   - **避免按压过猛**：易导致淤伤加速腐坏。

4. **听声音（辅助法）**  
   - 轻弹果身：  
     - **清脆“嘭嘭”声**：果肉紧实成熟，含水量高。  
     - 沉闷“噗噗”声：可能中空或过熟。  

5. **看底部与叶片（防内部问题）**  
   - 底部（果眼）：应干燥、无霉斑或汁液渗出。  
   - 顶部叶片：容易**轻轻拔出一片**（若需用力拔才可能新鲜）；叶片枯萎则过熟。  

**采购建议（减少损耗）**：  
- 优先选**七八分熟**（黄绿相间，微香）：可存放2-3天，根据销量分批上架。  
- 避免一次性进大量完全成熟的菠萝（货架期短）。  
- 到货后立即分拣：完全成熟的冷藏（4-6℃），未熟的常温催熟。
