在餐厅做水果拼盘时，选择规格更划算的关键是**按季节、按实际出肉率、按加工损耗**来比较。以下是针对苹果、橙子、菠萝的具体建议：

### 1. 苹果
- **推荐规格**：中果（直径约7-8cm），每斤约3-4个。
- **理由**：
  - 小果去皮后出肉率低，且容易氧化变色需快速处理；
  - 大果切开后常需改刀成小块，拼盘中量感不明显，但单价偏高。
  - 中果切片后大小适中，适合直接摆盘，损耗率最低。
- **省钱技巧**：买“同规格袋装”或“尾货处理”的次果（轻微磕碰不影响内部），价格可低30%-50%。

### 2. 橙子
- **推荐规格**：70-75mm果径（中果），每斤约4-5个。
- **理由**：
  - 小橙子（如脐橙60果）皮厚、汁少，出肉率不足55%；
  - 大橙子（80mm以上）皮虽薄但每颗单价高，且切片后每片面积太大，拼盘会显得单调。
  - 中橙切片后每盘可用5-6片，刚好覆盖成本。
- **省钱技巧**：优先选“杂交橙”或“夏橙”（比脐橙便宜20%），同样规格可确保甜度和成色。

### 3. 菠萝
- **推荐规格**：1.2-1.5kg/个的中等菠萝（如香水菠萝或台农17号）。
- **理由**：
  - 小菠萝（＜1kg）削皮后出肉率不足40%，且糖度低、纤维粗；
  - 大菠萝（＞2kg）单个成本高，若当天卖不完容易变质。
  - 中等菠萝削皮后约得0.6-0.8kg净肉，刚好满足3-4人拼盘量，且果芯较细，浪费少。
- **省钱技巧**：批发市场直接选“统货”按箱拿，单价可比超市便宜30%，且可要求摊主代削皮（通常免费）。

### 总体划算组合公式
```
每份拼盘成本 = 苹果单价×(0.3) + 橙子单价×(0.3) + 菠萝单价×(0.4)
```
其中比例可根据季节调整：  
- **当季主推水果**（如应季菠萝）可占更大比例，因价格更低；  
- **反季水果**（如冬季菠萝）尽量少用，可替换为哈密瓜或火龙果。

### 行动步骤
1. 去批发市场优先看“当日尾货筐”——苹果、橙子常有0-2元/斤的次果（外观不影响内部）；
2. 菠萝直接买整箱（约8-10个，具体看大小），现场要求商贩按1.2-1.5kg帮你筛选；
3. 苹果、橙子如果采购量大，直接找一级代理按“统货价”打包（甚至能拿到超市进货价一半的价格）。
