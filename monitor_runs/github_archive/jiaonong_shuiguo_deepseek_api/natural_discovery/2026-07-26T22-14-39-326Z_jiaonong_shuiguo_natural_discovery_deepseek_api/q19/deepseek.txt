如果你是顾客，建议按以下优先级关注：
1. **外观**（最直观）：选择表皮金黄、叶片翠绿、无霉斑或软烂的菠萝。果眼小而均匀通常更甜。
2. **甜度**（次重要）：可通过闻底部果香（越浓越甜）或轻按果皮（有弹性说明熟度适中）判断。超市一般不提供甜度数据。
3. **大小**（参考项）：同等成熟度下，稍大的菠萝果肉更饱满，但部分品种（如台湾金钻）中小型可能更甜。
4. **切果损耗**（购买切果时重点）：若买已切好的，观察果肉颜色是否均匀（发白或褐变说明不新鲜），避免购买切口渗出大量汁水的（可能已变质）。

如果是超市经营者，则需按**损耗率 → 外观 → 甜度 → 大小**排序，优先控制切果损耗以降低运营成本。
