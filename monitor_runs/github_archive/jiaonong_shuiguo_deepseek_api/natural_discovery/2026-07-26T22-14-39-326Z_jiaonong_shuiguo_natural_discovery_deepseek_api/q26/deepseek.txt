采购小包装香蕉时，主要需关注以下包装与损耗问题：

**包装方面：**
1. **透气性**：香蕉呼吸作用强，包装袋需打孔或使用透气膜，避免二氧化碳积聚导致过早成熟或腐烂。
2. **防挤压**：使用硬质塑料托盘或独立分隔的包装盒，避免堆叠时压伤。每串香蕉不宜过多，建议按“2-3根/份”分装。
3. **成熟度控制**：包装前香蕉应处于“绿熟期”（果皮尚绿但可后熟），避免全熟或过青。包装内可附乙烯吸收剂（如高锰酸钾吸附剂）延缓后熟。
4. **标签与透明度**：包装需透明以便顾客查看成熟度，标签注明产地、采摘日期及建议储存方式（如“阴凉避光，请勿冷藏”）。

**损耗问题：**
1. **落果与擦伤**：运输中部分香蕉柄脱落或果皮擦伤，应在包装前剔除受损香蕉，并用泡沫网套包裹果柄。
2. **后熟不均**：小包装内若混入不同成熟度的香蕉，会导致部分腐烂。采购时应要求供应商按成熟度分级分装。
3. **温度敏感**：香蕉在12℃以下易受冷害（果皮发灰、无法正常成熟），运输和储存中避免空调直吹或靠近冷风口。
4. **销售周期**：建议每次采购量不超过3天销量，并安排“绿熟-微黄-全黄”三档混合陈列，减少滞销损耗。

**可选策略**：
- 向供应商要求“两段式包装”：内袋为微孔保鲜膜（控制乙烯），外箱为泡沫箱（缓冲+保温）。
- 优先选择带“可追溯二维码”的包装，方便处理售后（如顾客反馈香蕉未熟，可补发后熟剂或退款）。
