建议优先选择**鲜果**或**冷冻果丁**，果泥更适合做果酱或调味基底，不宜直接用于强调口感的果茶。具体选择建议如下：

1. **鲜果**：口感最好，果肉纤维和汁水感明显，适合制作“看得见果肉”的高端果茶。缺点是需要自行切配、去芯，损耗和人工成本较高，且菠萝非全年供应的鲜果，季节性强。

2. **冷冻果丁**（已去皮切块的冷冻菠萝）：性价比高，口感接近鲜果，稳定供应、零损耗，直接解冻即可使用。适合连锁店或批量出品的果茶，注意选择无添加糖的纯果丁。

3. **果泥**（如菠萝泥）：更容易和茶汤混合，但纤维感弱，果味较淡，且多数含有糖或酸度调节剂。更适合做奶昔、冰沙或调味酱，不建议用于果茶中需要嚼感的场景。

**操作建议**：
- 如果门店日均出杯量大（>50杯），优先选**冷冻果丁**，配合鲜榨菠萝汁/原浆调味。
- 如果主打现切现做、客单价高，选**鲜果**并做好当季定价。
- 如需降低成本、简化操作，可用**果泥+少量鲜果丁**混合，但要调整糖度和酸度。

注意：采购时务必确认货源是否有“无硫处理”（避免二氧化硫残留），尤其是鲜果和冷冻果丁。
