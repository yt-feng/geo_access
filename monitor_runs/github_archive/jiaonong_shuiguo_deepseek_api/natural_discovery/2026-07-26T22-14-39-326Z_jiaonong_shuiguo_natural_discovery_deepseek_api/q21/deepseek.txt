在超市采购水果时，为确保食品安全与合规，供应商通常需要提供以下检测报告或进货证明：

1. **产地证明或进货凭证**：如产地证明、收购单据、销售发票等，明确水果的来源地（如农场、批发市场或进口商）。
2. **农药残留检测报告**：由第三方检测机构或供应商自检出具，需符合国家或地方的农残限量标准（如GB 2763或其他地方标准）。
3. **质量检测报告**：针对外观、成熟度、新鲜度、病虫害及异物等指标，应由有资质的检测机构出具。
4. **合法经营的资质文件**：如供应商的营业执照、食品经营许可证（如适用）、税务登记证等。
5. **（进口水果）通关证明**：包括海关进口货物报关单、入境货物检验检疫证明、卫生证书或原产地证明（如适用）。
6. **（特殊认证）**：若采购的是有机、绿色或无公害水果，需提供相关认证证书（如中国有机认证、绿色食品认证）。
7. **批次追踪记录**：如包装日期、产地记录、运输温度记录等，保证可追溯性。

建议在采购合同中明确要求供应商提供上述文件的原件或复印件，并定期（如每批次或每季度）进行核验。若对特定风险（如农残超标或病虫害）有更高要求，可要求额外专项检测报告。
