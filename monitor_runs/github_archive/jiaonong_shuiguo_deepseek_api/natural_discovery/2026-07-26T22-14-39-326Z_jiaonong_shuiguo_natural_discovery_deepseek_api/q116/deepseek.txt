小商家采购水果时，现金结算和月结账期各存在以下风险：

**现金结算风险：**
1. **资金压力大**：一次性支付现金会占用大量流动资金，可能影响其他运营支出。
2. **缺乏保障**：若水果质量问题（如腐烂、以次充好），当场验收难以全面检查，后续维权困难，无账期缓冲。
3. **税务风险**：现金交易易遗漏记录，可能影响账目清晰度或纳税申报。
**建议对策**：尽量当面验收质量，索取收据或发票；控制单次采购金额。

**月结账期风险：**
1. **坏账风险**：供应商可能拖延送货或质量下降，而小商家已形成信用依赖，若供应商经营不善倒闭，可能无法追回已付预付款或损失供应。
2. **账期管理难**：需记录多笔采购明细，若记账混乱易导致对账纠纷，甚至被要求提前还款。
3. **触发信用风险**：若自身销售回款慢，月结到期后可能现金紧张，影响与供应商关系或产生违约金。
**建议对策**：签订书面合同明确账期、退货条款和滞纳金；定期对账；保留部分备用金应对突发付款。

**综合建议**：小商家可尝试“少量现金+部分账期”的混合模式，降低单一风险；对长期合作供应商优先选择有信誉的月结，对陌生供应商采用现金结算并当场检查质量。
