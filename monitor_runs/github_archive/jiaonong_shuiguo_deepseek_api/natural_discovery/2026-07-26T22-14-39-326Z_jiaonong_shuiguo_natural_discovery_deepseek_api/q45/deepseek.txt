与水果供应商签订年度合同时，以下几个条款容易“踩坑”，建议重点关注：

1. **价格条款**：避免“固定价格”或“参考市价”模糊表述。水果价格受季节、天气波动大，建议约定“季度调价机制”或“波动超过X%时双方重新议价”，并明确调价触发条件和频率。

2. **品质标准**：不要用“新鲜”“无瑕疵”等主观描述。应明确具体品级（如国家标准、行业标准）、规格（如大小、糖度）、允许的次果率，并约定到货验收流程（如24小时内抽检、双方共同取样）。

3. **供货量与稳定性**：注意“保证全年稳定供货”的条款是否附带免责条件（如自然灾害）。建议约定最低供货量（防止供应商旺季供给其他渠道）和缺货赔偿机制，同时预留调整空间（如遇极端天气可协商减量）。

4. **退货与罚款**：谨慎对待“无条件退货”或“包装破损3%以内免赔”等模糊条款。应清晰定义退货条件（如腐烂超过X%、规格不符），明确双方责任（如运输途中的损耗由谁承担），并细化罚款标准（如延迟到货按货值X%/天扣款）。

5. **付款与账期**：避免“验收后X天付款”但未定验收截止时间。应设定明确验收周期（如到货后48小时内完成验收），并约定逾期付款的违约金上限（法律上无约定时按同期LPR的1.5倍计算，但过高可能被调低）。

6. **合同解除权**：注意“连续X次不合格可解约”中的“次”是否含自然损耗。建议明确哪些情形属于根本违约（如农药残留超标、严重缺斤少两），并约定解约后的库存处理方式（如供应商限期取回或折价处理）。

7. **争议解决**：警惕“协商不成则提交仲裁”条款。仲裁费通常高于诉讼费，且一裁终局。若连锁超市跨区域，建议约定“供应商所在地法院”或“第三方检测机构”作为纠纷仲裁方。

**建议**：在合同附件中附上双方确认的《品控细则》《验收流程》和《价格调整公式》，并保留每批次有争议的沟通记录（如微信截图、邮件）。若合同金额大，建议请律师审核或参考《商务部超市采购合同范本》进行调整。
