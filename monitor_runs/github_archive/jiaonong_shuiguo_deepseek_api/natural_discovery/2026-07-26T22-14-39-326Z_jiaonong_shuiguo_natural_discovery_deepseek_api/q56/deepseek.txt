茶饮店从水果供应商采购时，为控制食品安全风险，供应商一般需要提供以下证明文件：

1. **营业执照**：证明供应商具备合法经营资质。
2. **食品经营许可证**：或生产许可证（如为生产企业），说明其具备食品生产/销售资格。
3. **农产品质量合格证明**：如产地证明、检测报告（可包含农药残留、重金属等指标）。
4. **产品批次检验报告**：每批次水果的第三方或出厂检验合格报告（重点农药残留、新鲜度、微生物等）。
5. **进货记录与追溯信息**：供应商应提供清晰的产品来源、生产日期、批次编号等（便于问题产品追溯）。
6. **运输与储存条件证明**（如需）：如冷链运输温度记录、储存卫生证明（尤其对易腐水果如草莓、葡萄等）。

此外，茶饮店应要求供应商定期提供**第三方检测报告**（如按年或按季度），并建立进货查验记录制度，保留相关票据至少2年。如使用进口水果，还需提供**入境货物检验检疫证明**及中文标签。

建议与供应商签订**食品安全责任协议**，明确其责任和赔偿条款。具体证明文件种类可能因当地监管要求（如“食用农产品承诺达标合格证”制度）略有差异，可咨询当地市场监管部门。
