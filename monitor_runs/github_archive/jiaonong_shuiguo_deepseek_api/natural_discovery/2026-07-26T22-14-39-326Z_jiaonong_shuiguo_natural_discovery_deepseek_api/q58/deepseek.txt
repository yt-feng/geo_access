从损耗角度来看，**直接购买成品果丁通常损耗更低**。原因如下：

1. **鲜果切配损耗**：  
   - 菠萝表皮、果眼、硬芯等不可食用部分约占整果重量的 **30%-40%**。  
   - 切配过程中还需去除腐烂、碰伤部分（可能额外增加5%-10%损耗）。  
   - 操作人员的技术熟练度、工具锋利度等也会影响果肉完整率。  
   - 存储不当（如未冷藏）可能导致氧化或变质。

2. **成品果丁损耗**：  
   - 供应商已通过工业化方式去除果皮、果眼等，损耗已由工厂承担。  
   - 购买时通常按净重计价，实际到货几乎无额外损耗。  
   - 但需注意：部分成品果丁可能添加糖水或防腐剂，且运输中若有破损或过期（若未及时使用）仍会产生损耗（约5%左右）。

**建议**：  
- 若甜品店每日菠萝用量超过10公斤，且能高效利用边角料（如制作果酱、饮品），鲜果切配可能更经济。  
- 若用量小或追求操作效率、减少人工成本，直接购买成品果丁更优。  
- 可对比供应商报价：  
  - 假设鲜菠萝采购价5元/公斤，实际可用果肉成本 ≈ 5元 ÷ (1-35%) ≈ 7.7元/公斤（含人工）。  
  - 若成品果丁售价低于7.7元/公斤，则成品更优。  

**注意**：若选择成品果丁，需检查生产日期、冷藏条件（0-4℃）及是否有添加剂（如柠檬酸防止氧化），避免因质量不稳定导致二次损耗。
