在和供应商谈合作时，提前问清楚以下问题，能有效降低断货风险：

1. **供应能力与备货周期**：旺季预计最大供货量是多少？需要提前多久下单？是否有最低起订量？
2. **应急补货机制**：如果突然出现爆单，最快多久能紧急补货？加急订单是否有额外费用？
3. **供应稳定性**：是否有多地仓储或备货点？有无备用供应商应对极端情况（如自然灾害、物流中断）？
4. **品质与损耗管控**：如何保证到货水果的新鲜度？运输途中的损耗由谁承担？损耗率标准是多少？
5. **价格与付款条款**：旺季价格是否会有变动？涨价需提前多久通知？付款账期是多久？定金比例是多少？
6. **退换货政策**：到货后发现品质不佳或损坏，如何退换？处理时限和流程是什么？
7. **物流与保障**：采用什么物流方式？能否提供冷链运输？如果物流延误造成断货，是否有赔偿机制？
8. **合作历史与案例**：旺季期间，是否有与其他大型水果店或连锁超市的合作经验？能否提供往期旺季的供货稳定性数据？

建议将这些要点整理成《供应商评估表》，在合作前逐条确认并留档，有条件的话可以先去供应商的仓库或产地实地考察。
