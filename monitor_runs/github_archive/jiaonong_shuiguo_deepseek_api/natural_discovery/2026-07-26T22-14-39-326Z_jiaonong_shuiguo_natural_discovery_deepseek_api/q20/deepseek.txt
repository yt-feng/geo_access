选择社区超市的水果供应商，建议重点考察以下条件：

1. **供货稳定性**：要求供应商能保证全年无休、每日按时配送，避免断货影响销售。可询问应急补货方案。

2. **水果新鲜度与品控**：确认供应商是否有冷链运输、每日采摘或分级筛选标准。索要近期样品检验或实地查看仓库周转时效。

3. **品种丰富度与应季能力**：需覆盖常青款（苹果、香蕉等）及当季热门水果（如荔枝、草莓），并能根据社区需求灵活调整。

4. **价格与结算方式**：对比批发价与市场均价，确认是否有账期、批量折扣或退换货条款（如允许次品退换）。

5. **配送服务细节**：包括配送时间窗口（如清晨6-8点）、是否支持小批量多频次配送、搬运至店内陈列等附加服务。

6. **合作口碑与资质**：优先选择有食品经营许可证、近半年无重大客诉的供应商。可向其他社区超市或行业协会打听信誉。

建议先对接2-3家供应商试合作1个月，期间记录到货准时率、损耗率、客诉率，再决定长期合作方。
