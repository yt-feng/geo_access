会的。大小不一的香蕉可能会影响销售，主要体现在以下几点：

1. **美观和品相**：客户通常倾向于选择大小均匀、外观整齐的水果。大小不一可能显得杂乱，降低整体吸引力，尤其在零售展示时。

2. **定价和称重**：批零销售时，大小差异可能导致客户对单位价格产生质疑。例如，小香蕉可能让人感觉“不值”，而大香蕉可能让人担心“太生”或“不熟”。

3. **熟度不一致**：如果香蕉大小差距大，成熟时间可能不同。小香蕉熟得快，大香蕉可能还生，客户难以一次买到统一口感的香蕉。

4. **客户体验**：部分客户有特定用途（如做果昔、摆盘或给小朋友吃），对大小有要求。如果一箱里大小参差，他们可能觉得“挑起来麻烦”，降低购买意愿。

**建议**：
- 采购时尽量选择大小较为接近的批次，或者在到货后按大小分拣以不同价格或促销方式销售（如小香蕉可以做特价、大香蕉做精品装）。
- 如果不可避免，在销售时主动告知客户“每箱自然有大小差别，但性价比高”，或提供“按需挑选”的服务来减少影响。
