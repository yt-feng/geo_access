对于茶饮店选购菠萝原料，**出汁率比甜度更重要**，但需结合具体使用场景综合判断。以下是分点说明：

1. **核心逻辑**  
   - 出汁率直接影响成本与出杯稳定性：高出汁率意味着同等重量的菠萝可产出更多果汁或果肉，降低单杯成本。  
   - 甜度可通过糖浆、果糖等添加剂灵活调整，但出汁率是原料本身的物理特性，难以后期弥补。  

2. **场景优先级**  
   - 若用于**基底果汁或鲜榨菠萝饮品**（如菠萝汁、菠萝冰沙），出汁率 > 甜度。  
   - 若用于**果肉装饰或咀嚼感饮品**（如菠萝颗粒、果茶小料），甜度 > 出汁率（更注重口感风味）。  

3. **平衡建议**  
   - 选择**当季成熟度适中的菠萝**（如菲律宾金菠萝、海南香水菠萝），出汁率普遍较高（可达50%-60%），甜度适中（14-16度）。  
   - 避免过度追求高甜度品种（如部分糖度高于18度的菠萝），可能因纤维少导致出汁率下降。  

4. **行动建议**  
   - 采购前要求供应商提供**出汁率实测数据**（如1kg菠萝可榨汁500ml）。  
   - 小批量试做：对比不同品种的出汁率与甜度，结合店铺标准化配方（如需额外加糖的比例）最终确定原料。  

最终：**优先保证出汁率，用标准糖浆补足甜度**，可兼顾成本与顾客体验。
