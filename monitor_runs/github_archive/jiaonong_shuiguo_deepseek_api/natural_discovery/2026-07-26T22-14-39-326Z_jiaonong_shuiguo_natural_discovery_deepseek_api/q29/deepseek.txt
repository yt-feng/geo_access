在超市与水果供应商谈判账期时，常见的账期天数通常在 **30天到45天** 之间，但具体会因超市规模、水果品类、供应商实力和市场惯例而有所差异：

- **小型超市或社区店**：账期较短，多为 **15-30天**，部分现结或7天内结款。
- **中型连锁超市**：常见账期为 **30-45天**，部分生鲜优势品类可能压缩至15-20天。
- **大型连锁超市**：账期较长，通常在 **45-60天**，顶级品牌可能达到60-90天（需结合供应商谈判能力）。
- **水果品类差异**：高损耗、保鲜期短的品类（如草莓、蓝莓）账期更短（7-15天），耐储存水果（如苹果、柑橘）账期可适当延长。

建议：首次合作尽量争取 **30天** 以内，长期合作可尝试协商至45天；若供应商要求延长账期，可要求对方提供价格折扣或更优服务条款作为交换。
