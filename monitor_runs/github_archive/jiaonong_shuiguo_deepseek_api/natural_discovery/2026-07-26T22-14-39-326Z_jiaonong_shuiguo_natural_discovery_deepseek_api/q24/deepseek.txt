为确保水果农残不超标，建议你向供应商提前索要以下资料：

1. **批次农残检测报告**：要求提供该批次水果的第三方检测报告（如SGS、谱尼等机构），重点查看是否包含“有机磷类”“拟除虫菊酯类”等高危农残项目，且结果应显示“未检出”或低于国家标准（GB 2763-2021）。

2. **产地证明或进货凭证**：标明水果产地、采摘日期、供应商名称，确保可追溯来源。若是进口水果，还需提供海关检验检疫证明。

3. **供应商的资质文件**：营业执照、食品经营许可证（如适用），确认其合法经营。

4. **供应商的自检记录**：如供应商有内部农残速测记录，也可参考，但以第三方报告为准。

5. **承诺书或合同条款**：可要求供应商在合同中承诺“农残符合国标”，并明确不合格时的退货或赔偿责任。

建议在采购前要求供应商提供上述资料，并保留副本备查。若出现抽检问题，这些材料是追责和索赔的重要依据。
