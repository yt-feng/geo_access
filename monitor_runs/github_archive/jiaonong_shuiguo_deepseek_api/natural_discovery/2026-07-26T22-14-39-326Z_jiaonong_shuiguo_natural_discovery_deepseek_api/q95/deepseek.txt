选择学校食堂水果供应商时，建议按以下步骤操作：

1. **明确核心需求**：  
   - 必须符合食品安全标准（如无农药残留、新鲜无腐烂）。
   - 稳定供应（每日/每周固定配送）。
   - 价格合理，适合学生消费水平。
   - 可提供种类多样的常见水果（香蕉、苹果、橙子为主）。

2. **优先选择本地供应商**：  
   本地或周边产地能减少运输时间，保证新鲜度，同时降低成本。可通过当地农业合作社、果品批发市场或生鲜电商平台寻找。

3. **审查资质和口碑**：  
   - 要求供应商提供营业执照、食品经营许可证、农产品检测报告（尤其关注农药残留检测）。
   - 查询是否有学校、企事业单位的合作经验，必要时索取评价或推荐信。
   - 实地查看仓储卫生状况、冷链设施（尤其夏季或热带水果）。

4. **对比报价与样品**：  
   - 请至少3家供应商报价（含单价、配送费、最低起送量）。
   - 要求提供免费样品（如每种水果10-20斤），重点检查：  
     * 香蕉：无黑斑、不软烂，成熟度适中。  
     * 苹果：表皮无伤痕、无病虫害，果肉紧实。  
     * 橙子：皮薄肉厚、水分充足，无霉变。  
   - 比较同等品质下的性价比（例如：同等级苹果每斤价格相差超过15%时需谨慎）。

5. **签订明确合同**：  
   包括：  
   - 配送频率和时限（如每日上午8点前送达）。  
   - 退换货标准（如破损率超过5%可拒收或补发）。  
   - 价格调整机制（如季节性波动是否提前通知）。  
   - 违约责任（如无故断供的赔偿方案）。

6. **试运行与反馈**：  
   建议先试合作一周（每天小批量订购），测试配送准时率、水果新鲜度、服务响应速度。同时收集食堂阿姨和学生反馈，调整后正式签约。

**快速判断技巧**：  
- 同一款水果，若供应商报价明显低于市场均价（如低于20%），可能喷保鲜剂或混入次品，需警惕。  
- 要求供应商提供近3天的水果价格明细，对比当地批发市场每日报价，差距在10%以内较合理。  

最后，可以考虑与2-3家供应商保持合作关系，避免单一依赖，同时定期更换供应商清单以保持竞争性。
