建议**固定产地**，但**不要完全固定供应批次**。具体分析如下：

1. **固定产地的原因**：同一产地的水果通常有稳定的风味特征（如广西百香果的酸甜比、海南芒果的香气浓度），便于消费者形成稳定的口感预期，也有利于研发标准配方。若频繁更换产地，容易导致饮品风味出现明显浮动（如同一款芒果饮品从海南换到越南产地，甜度和纤维感可能大相径庭）。

2. **不要完全固定供应批次的原因**：水果是农产品，即使同一产地、同一果园，不同采摘批次也会因成熟度、气候、运输时长产生差异。完全固定批次（如“只采第三批果”）反而可能面临供应中断风险（如该批次因天气歉收），且成本易被单一供应商控制。

3. **推荐操作方案**：
   - **建立核心产地+备选产地的二级供应库**：例如70%采购量来自固定的广西合作果园（保证基础风味），30%试采云南、海南果园（分散风险、测试风味）。
   - **批次管理：对每一批次水果进行“出成率+糖度/酸度检测”**：入库时抽检并记录数据，与历史标准对比。若新批次糖度低于标准线（如原本13%降至10%），则立即调整配方（加糖浆）或降级用于果酱等二次加工产品，避免直接用于要求风味的当季饮品。
   - **动态调整采购合同**：与供应商约定“核心批次+浮动批次”条款，允许根据市场批发价和品质检测结果，在每月初调整各批次的采购比例。

这样既能控制风味一致性，又能应对自然波动，避免极端情况（如某批次酸度过高导致整批报废）。
