核实水果供应商的全国配送能力，建议采购方按以下步骤操作：

1. **要求提供具体配送覆盖清单**：让供应商提供详细的配送城市、区域（包括县级市、乡镇）及时效承诺的书面说明。避免笼统的“全国配送”表述。

2. **测试偏远地区订单**：选择1-2个非省会、非中心城市的地址（如偏远县城、乡镇），要求供应商试发一单，跟踪物流是否正常送达。此举可验证实际配送网络覆盖深度。

3. **核查物流合作方**：询问供应商合作的主要物流公司（如顺丰、京东、中通冷链等）。对比该物流公司的官方配送范围，是否与供应商承诺一致。

4. **查阅客户评价与案例**：要求提供近期与当地客户的合作记录或合同案例，特别是偏远地区的订单凭证。可以联系部分客户进行侧面验证。

5. **明确配送条款与免责范围**：在合同中注明“配送至中国境内所有县级及以上行政区（不包括港澳台）”，并约定超出覆盖范围时的补救措施（如退款、补发或调整价格）。

6. **设立试合作期**：先进行小额、多订单的试合作1-3个月，覆盖不同区域，观察配送稳定性、到货时效和货损率。达标后再扩大合作。

7. **利用第三方地图或物流平台自查**：例如对供应商宣称的西北、西南地区地址，使用物流公司官网的“网点查询”功能或直接致电客服，验证是否在该地有配送能力。

如有条件，可要求供应商提供其冷链仓库（如有）的分布位置清单，与物流网络匹配验证。若无冷链运输能力而承诺全国配送生鲜水果，可能存在风险。
