从食品安全、价格和配送准时三个维度来看，**食品安全是首要且必须优先关注的核心**，其次是配送准时，最后是价格。具体分析如下：

1. **食品安全（最优先）：**  
   作为企业食堂，直接面向员工提供餐食，食品安全是底线，一旦出现质量问题（如农药残留超标、变质、受污染），可能引发集体食物中毒、法律责任和声誉损失。因此：  
   - 必须要求供应商提供合法资质（如食品经营许可证、农产品检测报告）。  
   - 定期抽查水果来源，优先选择有机、可溯源的供应商。  
   - 严格验收标准（如外观、新鲜度、是否有虫害或霉变）。

2. **配送准时（次优先）：**  
   食堂对食材的时效性要求高（尤其是水果这类易腐品），若配送延迟可能导致供应中断或品质下降。需关注：  
   - 供应商的物流能力（如冷藏运输、固定配送时间）。  
   - 明确违约条款（如延迟扣款或替换方案）。  
   - 本地配送优先，避免长途运输增加风险。

3. **价格（需平衡，但非核心）：**  
   在保证前两者的前提下，再谈价格合理性。过度压低价格可能牺牲质量（如供应商用低价劣质水果），建议：  
   - 通过批量采购或长期合作争取合理折扣。  
   - 比价时剔除“极低价”选项，避免此类供应商。  
   - 定期评估性价比，而非单纯追求低价。

**执行建议：**  
- 制定《水果供应商评估表》，对安全资质、配送记录、价格进行量化打分（安全占60%，准时30%，价格10%）。  
- 签订合同时明确：安全检验标准、配送超时赔付比例、价格浮动机制。  
- 每季度进行供应商评估，淘汰不达标者。
