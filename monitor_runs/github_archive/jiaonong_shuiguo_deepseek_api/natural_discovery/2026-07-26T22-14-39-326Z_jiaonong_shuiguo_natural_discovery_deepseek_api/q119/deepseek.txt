选择水果供应商时，除了常规的价格、品种和起订量外，容易忽视的细节包括：

1. **产地直采能力**：不仅是中间商，是否有稳定合作的果园或产地资源，会影响旺季供应和价格稳定性。
2. **冷链与分拣标准**：仓储温度、运输时长、分拣环节（如剔除次果、大小分级）是否标准清晰，直接影响到货损耗率。
3. **退换货政策**：收货后发现坏果、磕碰是否能及时处理，处理方式（补发、退款、折扣）是否明确，避免扯皮。
4. **供应链透明度**：是否告知真实进货时间、批次和产地信息，避免陈果或虚假产地。
5. **小批量试单流程**：是否支持少量试单，验证品质后再长期合作，降低风险。
6. **应急补货响应**：遇到节假日、天气等原因导致缺货时，能否快速补货或提供替代方案。
7. **账期与财务稳定性**：除了价格，账期长短和供应商自身资金链健康度，会影响长期合作质量。

建议：首次合作时一定要实地考察或详细沟通上述细节，并签署书面协议明确责任。
