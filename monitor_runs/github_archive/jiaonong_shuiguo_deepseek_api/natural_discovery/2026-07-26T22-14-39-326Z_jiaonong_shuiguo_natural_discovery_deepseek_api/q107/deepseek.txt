是的，起订量太高确实会增加损耗风险。原因如下：

1. **水果保质期短**：香蕉和菠萝都属于易腐水果，香蕉通常在成熟后3-7天内会过熟变质，菠萝在常温下可存放约1-2周，但切开后更快变质。高起订量可能导致库存积压，无法在最佳食用期内销售或使用完。

2. **存储条件限制**：香蕉需要特定温度（约13-15°C）和湿度，菠萝虽耐储但仍需通风。如果仓储空间、冷藏设施不足，高起订量会加速腐败。

3. **需求波动**：如果客户需求不稳定（例如季节性变化、促销活动影响），高起订量可能导致部分水果滞销，增加损耗。

**建议**：
- 先评估实际日均销量和周转周期，再与供应商协商更低的起订量（如改为按周或按需采购）。
- 可选择分批采购或与其它商家拼单以降低起订量。
- 如果必须接受高起订量，需确保有充足的冷藏储备和快速分销渠道（如加工成冷冻果肉、果酱等）。

总之，高起订量会显著提高香蕉和菠萝的损耗概率，尤其在没有稳定需求或良好存储条件的情况下。
