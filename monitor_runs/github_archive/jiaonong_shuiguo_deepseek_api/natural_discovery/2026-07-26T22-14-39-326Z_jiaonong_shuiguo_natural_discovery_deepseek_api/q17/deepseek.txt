针对社区超市水果经营，核心策略是**“少量快进、周期打折、按需陈列”**。以下是可以直接操作的建议：

**一、控制新鲜度（源头与陈列）**
1. **分批次进货**：不要一次性进全，按销量预测，每天或每两天小批量补货（如叶菜类当天卖完，根茎类可备2-3天量）。
2. **拆箱整理**：到货后立即拆除快递箱、保鲜膜，挑选出过熟或有瑕疵的水果，单独打折处理，避免传染整箱腐烂。
3. **冷藏与常温分开放**：热带水果（香蕉、芒果、木瓜）常温存放，冷藏会加速变黑；浆果、葡萄、草莓必须冷藏（0-4℃）。
4. **时间分区陈列**：
   - 最上层/最外侧：放当天新货（品相最好）。
   - 下层/里侧：放前一天的存货（适当优惠）。
   - 单独设立“临期/特价区”（如表皮微皱、有软点的），用醒目标签（如“今日特价，尽快食用”）主动处理。

**二、减少库存积压（销售与数据）**
1. **每日销量清单**：记录每种水果的**日销量、剩余量、到货时间**。例如“黄金瓜周一进20斤，周二剩12斤，周三必须清掉”。
2. **设置“清货政策”**：对超过2天未售完的，第2天下午开始8折，第3天5折或买赠（如买一送一）。
3. **组合销售**：临近过熟的（如香蕉、熟透的芒果、猕猴桃）可搭配成“水果沙拉材料包”或“榨汁套餐”，提价空间小但流转快。
4. **预订制**：在微信群/店门口黑板发布“明日到货预告”，让顾客提前预订，按预订量进货（尤其适合进口或高价水果）。

**三、常见错误避免**
- **不要整箱堆叠**：会让底部水果被压坏，建议用浅层陈列架，每层只放1-2层水果。
- **不要依赖“多进货才有利润”**：社区超市利润来自周转率，1天卖10斤比3天卖15斤更健康。
- **不要忽视“折损资金”**：每月统计因腐烂扔掉的水果价值，目标控制在进货额的5%以内。

**四、简单工具推荐**
- 用**黑板或白板**在冷库/货架旁写：品种、进货日期、建议销完日期。
- 用**手机备忘录**记录每日出清情况（如“周三土豆剩5斤，洋葱剩3斤”）。
- 若营业人员少，可设置**周循环表**：周一进叶菜，周二进柑橘类，周五进热带水果，错开高峰配送期。

**总结口诀**：
**小批量、勤补货；陈列分、不叠压；次日货、标记好；第三日、必出清。**
