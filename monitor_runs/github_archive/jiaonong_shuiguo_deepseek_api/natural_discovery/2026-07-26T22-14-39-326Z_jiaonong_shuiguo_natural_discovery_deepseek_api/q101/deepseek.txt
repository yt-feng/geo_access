与酒店供应商洽谈水果合作时，建议重点关注以下要点，以确保供应稳定、成本可控、品质达标：

1. **明确供应标准**：提前列出酒店早餐常用的水果品类（如苹果、香蕉、橙子、西瓜、蜜瓜、草莓等）、单次需求量（按周/天估算）、规格要求（如：苹果直径80mm以上、无碰伤、无腐烂）以及**成熟度**（如：香蕉需七成熟，熟度可控）。最好附上实物样图或书面标准。

2. **需求与配送计划**：明确**每日/每周固定配送时间**（如：早餐使用，需前一日晚8点前到货）、**临时加单的响应时间**（如：紧急情况下2小时内补货）、**退换货政策**（如：到货2小时内发现质量问题，包退换）。

3. **价格与结算**：约定**市场波动调价机制**（如：每月根据批发市场价格协商一次价格）、**价格有效期**（至少1个月）、**账期**（如：月结30天）。可以要求供应商提供**历史价格记录**作为参考。

4. **品质监控与反馈**：要求供应商提供**农残检测报告**或产地证明（尤其进口水果）。可以约定**定期抽检**（如：每周随机抽查10%到货量），退货标准要量化（如：水果出现5%以上损耗率，整批次拒收）。

5. **备用方案**：要求供应商列出**备选产品清单**（如：当季某种水果断供时，能稳定供应的替代品种），并明确**断供处罚条款**（如：提前24小时无通知断供，扣减当日货款的20%作为补偿）。

6. **合同关键条款**：
   - **最低起订量**：确保不因酒店用量小而被拒单。
   - **违约责任**：明确延迟、缺货、品质不达标的赔付标准。
   - **合同期限**：建议前3个月为试用期，后续可续签长期合同。

7. **实地考察**：签订合同前，建议实地查看供应商的**仓储条件**（冷库、分拣区）、**分拣流程**（是否有专人筛选果品）、**运输车辆**（是否冷链控温）。同时试送1-2次货，验证执行能力。

8. **合作后管理**：建立**供应商评分表**，每月从准时率、品质合格率、配合度三项打分。低于80分需书面警告，连续两个月不合格则启动备用供应商。

**推荐优先级**：同一品类可与3家供应商接洽，优先选择有酒店企业用户案例、能提供冷链配送、价格略高但信誉稳定的供应商（压低成本反易导致断供风险）。
