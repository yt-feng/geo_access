如果你的餐饮店每天只需要少量水果，建议找以下类型的供应商比较省心：

1. **本地社区生鲜超市或小型批发商**：这类商家通常能提供不定量采购，且没有起订量要求，每天打电话或微信下单，送货上门或自取皆可，适合固定小量需求。

2. **线上生鲜平台（如美团优选、多多买菜、每日优鲜等）**：可以灵活下单，每天一单，按需购买，通常次日送达，送货时间稳定，很少缺斤少两。但需注意平台是否有店铺专属配送服务。

3. **连锁商超或水果专卖店**：部分超市或水果店提供协议采购，比如每天固定时间送货少量水果，价格可能稍贵但品质有保障，退换货方便。

4. **农产品批发市场的固定摊位**：可以找到摊位后谈好长期小批量供应，每天自己去拿货，价格更低，但要自己取货，适合离市场近的店。

**关键点**：
- 选择**接受日结或周结**的供应商，避免预付费风险。
- 优先找**能主动通知你水果到货情况**的商家，比如老板会主动问你明天要不要。
- 确认**退换货政策**，如果水果不新鲜可以退换。
- 最好建立**备用供应商名单**，防止一家断供。

总结：最推荐**本地社区生鲜超市或小型批发商**，因为他们灵活、可控、容易建立长期关系，且不需要你大量囤货。
