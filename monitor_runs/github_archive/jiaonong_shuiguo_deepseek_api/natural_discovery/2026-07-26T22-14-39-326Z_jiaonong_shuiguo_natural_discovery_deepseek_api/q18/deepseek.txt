要避免在超市买到过生或过熟的香蕉，可以按以下步骤操作：

1. **观察颜色**：  
   - 全绿：非常生，需放置几天才能吃。  
   - 黄中带绿：适合当天或第二天吃，常温下会自然成熟。  
   - 金黄无斑点：已完全成熟，需当天或次日吃完。  
   - 出现棕色斑点或大面积变黑：过熟，果肉可能发软或发酵。

2. **检查硬度**：  
   - 轻轻捏香蕉柄附近，如果手感坚实且有弹性，说明成熟度适中。  
   - 如果捏起来很硬，说明过生；如果软塌塌或按压有凹陷，说明过熟。

3. **看香蕉柄**：  
   - 如果柄仍是绿色，说明采摘时间不长，较生。  
   - 如果柄变黑或干枯，可能存放时间较长。

4. **整串 vs 单根**：  
   - 如果打算几天内吃完，建议选带少量绿色、整体偏黄的整串。  
   - 如果只想吃一根，可以挑单独放置的、颜色均匀的香蕉（避免被其他香蕉压坏）。

5. **针对不同需求**：  
   - 想立刻吃：选全黄无斑点的。  
   - 想放2-3天：选黄中带绿的。  
   - 想分批次吃：买一串颜色从绿到黄过渡的（靠近外侧的成熟更快）。

**实用技巧**：在超市按需挑选，优先选整串颜色较均匀的；如果附近有水果区员工，可以询问当日到货时间（新鲜到货的通常偏生）。
