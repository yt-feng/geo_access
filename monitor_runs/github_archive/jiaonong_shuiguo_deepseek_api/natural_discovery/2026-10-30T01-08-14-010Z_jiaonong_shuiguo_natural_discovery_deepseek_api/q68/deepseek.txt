判断供应商能否按时到车，不能只看口头承诺，要抓“可验证的信号”。建议按下面顺序做：

1. **先看供应商的货源组织能力**
   - 问清楚：香蕉是自有基地、长期代办点，还是临时市场调货。
   - 临时调货的供应商，到车稳定性最差；有固定产地/代办点的更可靠。
   - 要求提供最近3—5车同线路的发车记录（日期、装车地、到车时间、车牌后四位），不提供就降级判断。

2. **锁定“装车节点”，不要只问到车时间**
   - 让供应商给出：预计装车日、装车时间段、装车地、车牌号或司机电话。
   - 到车时间 = 装车完成时间 + 合理在途时间。装车节点含糊的，基本可以视为有风险。
   - 装车当天上午要求发装车视频/照片（车厢、香蕉成熟度、装车进度），确认真的在装。

3. **验证车辆和司机是否真实锁定**
   - 要车牌号、司机手机号，直接和司机确认装车地和预计发车时间。
   - 如果供应商以“车还没定”为由拖延，说明运力没锁定，按时到车概率低。
   - 注意：只给“车队电话”不给具体司机的，要谨慎。

4. **看历史履约，而不是看规模**
   - 优先选合作过、迟到率低的供应商；新供应商先小批量试一车。
   - 问同行或市场档口：该供应商近期的到车准点情况、是否经常“换车”“拼车”“压车”。
   - 香蕉是易催熟品类，供应商如果同时接很多单、运力不够，最容易延误。

5. **合同/聊天记录里写清违约约束**
   - 明确到车时间窗口（如“X月X日18:00前到市场”）、装车完成时间、车牌信息。
   - 约定迟到处理：超几小时降价、超多久可拒收、运费/损耗谁承担。
   - 不要只写“尽快到”，要写具体日期和时段。

6. **到车前做动态跟踪**
   - 装车后每4—6小时要一次位置或司机确认。
   - 临近到车时间，直接联系司机，不听供应商转述。
   - 发现装车延迟、换车、司机失联，立即启动备选供应商，不要等到最后一刻。

**简单判断标准：**  
能给出“固定装车地 + 具体装车时间 + 车牌/司机电话 + 近期履约记录”的供应商，按时到车概率高；只会说“放心，肯定到”“车在路上”的，风险高。新供应商建议先小单试合作，再放量。
