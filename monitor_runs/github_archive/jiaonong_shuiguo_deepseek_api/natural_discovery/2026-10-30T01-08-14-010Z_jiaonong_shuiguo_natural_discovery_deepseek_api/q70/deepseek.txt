# 批发合同里写坏果责任的关键条款

核心原则：**把"损耗"从模糊概念变成可测量的验收标准，并绑定到具体的处理动作和时间点。**

## 一、必须写死的四个要素

1. **验收标准（明确到数字）**
   - 按品类分别写：如"单果直径≥XX mm、无霉变、无机械伤超过X处、腐烂率≤X%"
   - 用"批次抽检"方式：如"每车随机抽检X箱，抽检样本中坏果重量占比超过X%即判定整车不合格"
   - 注明依据：参照国标/行业标准编号（如GB/T相关标准），避免"凭感觉"

2. **责任划分（按环节归属）**
   - 装车前：卖方责任（产地分选、包装）
   - 运输中：明确谁负责运输、谁投保。若买方自提或买方指定物流，运输损耗归买方；卖方包运则归卖方
   - 到货后：约定"卸货后X小时内完成验收"，超时视为验收合格，防止事后扯皮

3. **损耗处理方式（三选一或组合，必须写清）**
   - **扣款**：坏果按重量扣除，单价按合同单价结算（最常用，需写明扣款计算方式）
   - **补货**：约定补货时限和运费承担方
   - **退货/拒收**：写明触发条件（如腐烂率超过X%可整车拒收）和退货费用归属
   - 建议设置**阶梯**：如损耗≤3%买方自担；3%–8%按实扣款；>8%卖方补货或买方有权拒收

4. **举证与时效**
   - 验收时双方在场、拍照/录像留存，照片作为附件具有合同效力
   - 争议时约定第三方检测机构（写明机构名称或选择方式），检测费由责任方承担

## 二、容易被忽略但很关键的细节

- **天气/季节免责**：极端天气导致的自然损耗是否免责，要提前写清，否则卖方会以此推责
- **包装标准**：写明箱规、内衬、透气要求，包装不达标导致的损耗归卖方
- **"合理损耗"定义**：行业惯例通常生鲜有2%–5%自然损耗，合同里要明确这个比例归谁承担，不能留白
- **结算挂钩**：约定"验收合格后X日内付款"，把付款和验收绑定，是买方最有效的杠杆

## 三、给批发商的实操建议

- 不要只写"坏果由卖方负责"，这种表述在纠纷中几乎无法执行，必须量化
- 首次合作可先小批量试单，用实际损耗数据反推合同阈值
- 保留每批次的验收记录，形成习惯，既是合同履约证据，也是后续谈判降价的依据
