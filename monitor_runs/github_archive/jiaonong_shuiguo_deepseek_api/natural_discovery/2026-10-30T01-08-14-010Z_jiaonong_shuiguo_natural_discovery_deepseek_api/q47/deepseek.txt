茶饮店用香蕉，采购熟度的核心原则是：**按“到货后1–3天内能用完”来定熟度，不要一次采购同一熟度，要分批错开。** 具体可按用途和表皮状态控制。

## 1. 按用途定熟度

- **打泥做香蕉牛奶、奶昔、冰沙**：用**7–8成熟**，表皮基本转黄、带少量青肩，捏起来略硬但有弹性。香气够、甜度适中，打出来不寡淡，也不容易发黑发酸。
- **做香蕉果肉顶料、切块装饰**：用**8成熟**，通体黄色、少量褐点。果肉完整，不易烂。
- **做香蕉蛋糕、布丁、焦糖香蕉、香蕉酱**：可用**9成熟**，表皮有褐斑、捏着软。甜度高、香气足，但当天到货当天用或冷藏保存。
- **不建议采购**：大面积发黑、果柄发霉、表皮破损流汁、捏着软烂的香蕉，茶饮店损耗和食品安全风险都高。

## 2. 采购时的判断标准

看表皮和手感，比看颜色更可靠：

- **青肩明显、整体偏绿**：适合提前1–2天到货，放熟后再用。
- **通体浅黄、果柄还偏绿**：适合次日用。
- **通体金黄、少量芝麻点**：适合当天到货当天用。
- **褐斑较多、手感软**：只适合当天做甜品或果泥，不适合切块。
- **果柄发黑、有酒味**：不要收。

## 3. 分批采购，不要“一刀切”

建议每次采购分两档：

- **60%–70% 采购8成熟**：到货后1–2天使用。
- **30%–40% 采购7成熟**：放1–2天接力使用。
- 当天高峰用量大时，再补少量9成熟做甜品。

这样能避免“第一天太生、第三天全烂”的损耗。

## 4. 到货验收和储存

- **验收**：抽检果柄、表皮、手感；有酒味、霉点、流汁的拒收或隔离。
- **储存**：7–8成熟放常温通风处催熟，不要堆压；9成熟尽快用完，必要时冷藏，但冷藏后表皮会变黑，不影响果肉，需当天用完。
- **切开后**：果肉尽快使用，暴露空气易褐变；可少量柠檬汁或覆膜冷藏，但不宜久放。

## 5. 简单可执行的标准

给采购写清楚：

> 香蕉到货以**通体黄色、果柄微绿、少量芝麻点、捏着有弹性**为主；青肩明显的占比不超过30%；拒收大面积黑斑、破皮流汁、有酒味和霉点的货。按日用量分2批到货，间隔1–2天。

这样控制熟度，比单纯按“黄不黄”采购更稳，损耗也更容易压下来。
