批发商想绑定稳定大客户，账期和额度要分开谈：先把“额度”当风险上限，把“账期”当价格条件。给你一套可直接用的谈法。

**一、先定原则**
1. **账期不是白给的**：账期=你给客户融资，必须换销量承诺、独家品类、预付款比例或价格上浮。
2. **额度按回款能力定，不按客户规模定**：大客户不等于低风险，先看它历史回款、下游账期、现金流。
3. **新客户先短账期小额度，跑3个月再放大**：首单现款或30%定金，稳定后再给7–15天。
4. **账期和额度分开设**：额度是“最多欠多少”，账期是“欠多久”，两个都卡住。

**二、额度怎么定**
- 公式：**授信额度 ≤ 客户月均采购额 × 0.5～1**，新客户取0.3～0.5，老客户稳定回款后逐步提到1。
- 同时设**单笔上限**和**滚动欠款上限**，比如单笔不超过额度40%，任意时点欠款不超过总额度。
- 超过额度部分：现款、预付或停止发货，写进合同。
- 额度每季度复核，连续2次逾期就降额。

**三、账期怎么谈**
- 新客户：**现款现结或预付30%+尾款7天**。
- 稳定3个月、无逾期：给**7–15天**。
- 6个月以上、月采购稳定：可给**30天**，但要求月采购保底量或季度返利绑定。
- 账期起算点写清楚：**以签收日/对账确认日为准**，不要用“发票日”含糊。
- 逾期条款：日万分之五违约金、暂停供货、取消账期，写进合同。

**四、用条件换账期**
- 要账期可以，换**月度保底采购量**或**季度增长承诺**。
- 换**品类独家**或**主推权**。
- 换**预付款比例**：预付50%可给30天，预付30%给15天，零预付只给现款。
- 换**价格**：账期客户单价上浮2%–3%，或现款客户给2%折扣。

**五、合同必写条款**
- 授信额度、单笔上限、账期天数、起算日。
- 逾期违约金、暂停供货权、额度调降权。
- 对账周期（如每月5日前确认上月账单）。
- 质量争议不影响无争议部分付款。

**六、实操节奏**
首单现款→第2–3个月给7天小额度→稳定后给15天→6个月后评估是否给30天。每次放大额度前看三个指标：**回款准时率、月采购额、逾期次数**。宁可少给额度，也不要账期失控。

一句话：**额度卡风险，账期换承诺，新客户先小后大，合同写死逾期后果。**
