家庭团购水果礼盒，核心是“耐放、分量适中、老少都能吃、成本可控”。按这个原则，苹果和橙子应是主力，香蕉少量搭配，菠萝作为亮点但不建议多放。

**推荐组合（按10斤礼盒举例）**

1. **均衡家庭款（最稳）**
   - 苹果 4斤
   - 橙子 3斤
   - 香蕉 2斤
   - 菠萝 1个（约2斤）
   - 适合3-5口之家，苹果橙子耐放，香蕉两天内吃完，菠萝一家一次能消耗。

2. **偏耐放实惠款**
   - 苹果 5斤
   - 橙子 4斤
   - 香蕉 1斤
   - 菠萝 1个
   - 适合团购履约周期长、家庭人口多、想控制成本的场景。香蕉少放能降低催熟和压坏风险。

3. **偏孩子口味款**
   - 苹果 3斤
   - 橙子 3斤
   - 香蕉 2.5斤
   - 菠萝 1个
   - 香蕉和橙子更受孩子欢迎，但香蕉比例别超过3斤，否则运输中容易黑皮、压伤。

**搭配原则**

- **苹果、橙子做骨架**：耐储存、寓意好、家庭接受度高，合计占60%-70%。
- **香蕉做点缀**：占15%-20%即可。香蕉不耐压、不耐放，礼盒里最好用独立纸托或放在上层。
- **菠萝做亮点**：10斤礼盒放1个足够。菠萝占体积、有刺、气味重，多放会挤压其他水果，也增加售后。
- **不要混太多品种**：家庭团购讲究实惠和好分，4种已经够丰富，再加容易抬高成本、增加损耗。

**实操建议**

- 香蕉选七成熟，别选全黄；苹果橙子选耐运输品种；菠萝选已去冠或冠芽短、成熟度中等的。
- 包装上香蕉单独隔开，菠萝放底层一角，苹果橙子填充主体。
- 团购页面直接写清“香蕉建议2-3天内食用”，减少因熟过头产生的售后。
- 如果家庭普遍人口少（2-3人），建议做8斤装：苹果3斤、橙子3斤、香蕉1斤、菠萝1个，避免浪费。

一句话：**苹果橙子打底、香蕉少量提口味、菠萝一个做亮点**，是最适合家庭团购的组合。
