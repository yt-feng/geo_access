连锁超市要把“坏果率”压下来，合同里不能只写一句“坏果赔付”，而要把**验收标准、责任分界、赔付计算、扣款/换货/退货机制、举证与时效**写清楚。建议按下面结构约定：

## 1. 先定义“坏果”和“坏果率”
合同里要明确可量化标准，避免扯皮：

- **坏果定义**：腐烂、霉变、软烂、渗液、异味、虫害、机械伤导致不可售、冻伤、日灼、裂口严重等，分别列明。
- **抽样规则**：按到货批次随机抽样，抽样比例、抽样位置、谁抽、谁见证写清楚。
- **坏果率计算**：  
  `坏果率 = 抽样中不可售坏果重量（或个数）÷ 抽样总重量（或总数）×100%`
- **判定标准**：例如“单批次坏果率≤3%为合格；3%—5%按比例扣款；＞5%可拒收或整批退货”。具体阈值按品类定，叶菜、浆果、根茎类不能一刀切。

## 2. 责任分界要写清
坏果可能发生在采摘、运输、仓储、门店陈列环节，合同要划分：

- **到货验收前**：供应商承担。
- **验收签字后**：一般由超市承担；但能证明是供应商隐瞒、以次充好、冷链断链导致的，供应商仍担责。
- **冷链责任**：运输温度、到货温度、测温记录、温控异常处理写进合同。
- **门店陈列责任**：因超市未按温湿度、先进先出、翻堆理货造成的坏果，不应由供应商赔付。

## 3. 赔付方式要可执行
建议采用“**比例扣款 + 换货补货 + 严重拒收**”组合，而不是只约定罚款：

- **按比例扣款**：  
  `扣款金额 = 该批次结算金额 × 坏果率 × 扣款系数`  
  扣款系数可设为1—3倍，超过阈值时提高系数。
- **换货/补货**：坏果部分由供应商在约定时限内补足，补货价按原合同价，运费由责任方承担。
- **整批拒收/退货**：坏果率超过约定上限，超市有权拒收或退货，供应商承担退货运费及因此产生的合理损失。
- **质量保证金**：可约定从货款中预留一定比例作为质量保证金，按月/季结算。
- **违约金上限**：注意与《民法典》公平原则匹配，避免过高被调整；建议区分一般违约和严重违约。

## 4. 验收流程和时效
- 到货后多少小时内完成验收；
- 验收单、照片、视频、抽样记录作为赔付依据；
- 供应商有异议的，应在多少小时内提出并复检；
- 逾期未提异议视为认可；
- 谁有权签收、谁有权确认扣款。

## 5. 证据与追溯
合同应要求：

- 每批次保留到货时间、温度记录、抽样照片、验收单；
- 坏果照片要能对应批次、托盘、箱号；
- 供应商提供产地证明、检测报告、冷链记录；
- 双方可约定第三方检测机构，费用由责任方承担。

## 6. 建议的合同条款示例

## 7. 关键提醒
- **别只约定“坏果率”不约定抽样方法**，否则无法执行。
- **别把门店损耗全部转嫁给供应商**，责任分界不清容易引发争议。
- **赔付要能直接从货款扣**，否则执行成本高。
- **按品类设阈值**，叶菜、浆果、根茎类、礼盒类标准不同。
- **保留复检和异议机制**，避免单方判定。
