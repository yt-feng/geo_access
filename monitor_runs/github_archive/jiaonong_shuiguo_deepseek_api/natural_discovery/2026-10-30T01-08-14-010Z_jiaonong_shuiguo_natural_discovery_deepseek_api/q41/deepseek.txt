判断商超采购香蕉的催熟能力是否稳定，核心是看“到货状态是否一致、催熟反应是否可重复、货架表现是否可控”。可执行判断如下：

1. **看到货成熟度是否集中**
   - 同一批香蕉的色度、硬度、果指粗细、长度应基本一致，不能一部分青硬、一部分已黄软。
   - 随机抽多个箱、多个托盘取样，不要只看表层。表层好看但内部成熟度差异大，说明源头分级或冷链不稳定。

2. **看青果硬度和色泽是否适合催熟**
   - 适合催熟的香蕉通常果身饱满、棱角略钝但未完全圆鼓，青绿色均匀，无大面积黄斑、水软、裂口。
   - 果柄切口新鲜、无霉变；果指表面无严重机械伤。机械伤会在催熟后先黑先软，造成批次不齐。

3. **查冷链和到货温度记录**
   - 青蕉运输和仓储温度应稳定，不能出现明显忽高忽低。温度波动会直接导致催熟反应不一致。
   - 到货时测果肉或箱内温度，抽不同位置对比。温差大说明运输或堆码有问题。

4. **做小批催熟试验，看重复性**
   - 每批到货先留样，在相同温度、湿度、乙烯条件下催熟，记录转黄时间、色度均匀性、软化速度、青条比例。
   - 连续几批在同样条件下结果接近，才算催熟能力稳定。若同一供应商批次间差异大，不能只凭经验下单。

5. **看催熟后的货架表现**
   - 稳定批次催熟后转黄均匀，果指之间差异小，货架期内软化速度可预测，黑斑、青条、掉把少。
   - 若催熟后很快出现水软、果柄发霉、局部青硬，说明催熟窗口窄或前期冷链有问题。

6. **建立供应商批次档案**
   - 记录产地、采收期、到货温度、青果色度、催熟参数、转黄天数、损耗率。
   - 重点看“同一供应商连续批次”的波动，而不是单批表现。稳定供应商应能提供分级、冷链和采收成熟度信息。

7. **现场快速判断口诀**
   - 一箱看均匀，二测温差，三留样催熟，四比连续批次，五看催熟后青条和软化速度。
   - 如果到货成熟度不齐、温度波动大、留样催熟结果每批不同，就说明催熟能力不稳定，应减少单次采购量或要求供应商改善分级和冷链。

简言之：**不要只看香蕉绿不绿，要看同批一致性、冷链稳定性、留样催熟的可重复性和催熟后货架表现。连续批次结果稳定，才是真的催熟能力稳定。**
