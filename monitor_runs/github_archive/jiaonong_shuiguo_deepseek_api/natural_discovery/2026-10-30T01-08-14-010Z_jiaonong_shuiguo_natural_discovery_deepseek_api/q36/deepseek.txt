建议以**整果为主、切果为辅**，但要看门店客群和损耗管理能力。判断逻辑如下：

**更适合卖整果的情况**
- 门店客群以家庭采购、中老年为主，整果更有性价比。
- 菠萝单价低、客单不高，切果加工后溢价空间有限，人工和损耗反而吃掉毛利。
- 门店没有稳定冷链和当日清货能力，切果损耗风险高。
- 整果可做堆头、促销、试吃引流，操作简单。

**可以加大切果比例的情况**
- 门店位于办公区、商圈、社区年轻客群集中，即时消费、小份购买需求强。
- 有冷藏陈列和当日清货机制，能控制切果损耗。
- 切果能带动客单价和毛利，尤其是搭配其他水果做果切拼盘。
- 门店人手能支持标准化削切和卫生管理。

**采购和陈列建议**
1. **整果做引流和价格锚点**，选耐储运、外观好的品种，控制进货量，先进先出。
2. **切果做利润和便利补充**，只切当日能卖完的量，冷藏陈列，标注加工时间，当天清货。
3. **先小批量测试**：连续1—2周记录整果和切果的销量、毛利、损耗、人工成本，再决定比例。
4. **损耗是核心判断指标**：如果切果损耗率明显高于整果毛利增量，就退回整果为主。
5. **不要一刀切**：不同门店按客群分开策略，办公区店可切果占比高，社区家庭店整果为主。

简单结论：**没有冷链和清货能力就卖整果；有年轻即时客群和损耗管控能力，就整果+切果组合，切果控制在当日可售完的量。**
