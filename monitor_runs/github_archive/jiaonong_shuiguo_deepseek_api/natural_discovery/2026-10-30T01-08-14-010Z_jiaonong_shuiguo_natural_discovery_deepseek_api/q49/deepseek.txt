旺季菠萝用量突增，临时补货的关键不是“打个电话让供应商多送点”，而是提前把**临时补货的触发条件、响应时限、价格和验收标准**写进补充约定，避免旺季被临时加价或断供。

可以按下面几步操作：

**1. 先算清“临时补货”的需求边界**
- 统计过去7天和预计未来7天的菠萝日均用量，算出常规日用量和峰值日用量。
- 明确你要的是“每日追加”还是“整批补货”，每次大概多少公斤/箱、什么规格（品种、单果重量、成熟度、去皮还是带皮）。
- 给自己留安全库存：临时补货量 = 预计峰值用量 - 常规合同日供应量 - 安全库存。

**2. 和供应商签一份简单的补充协议或微信书面确认**
至少写清以下条款：
- **触发方式**：你方在当天某时点前（如上午10点）以微信/电话/订单系统发出补货需求，供应商确认即生效。
- **响应时限**：供应商需在多少小时内确认，多少小时内送达（例如：确认后24小时内到店）。
- **补货上限**：约定每日/每周最大临时补货量，避免供应商以“没货”为由拒绝，也避免你方预估失真。
- **价格机制**：临时补货单价按合同价执行，或约定上浮上限（如不超过当周市场价的X%），防止旺季坐地起价。
- **质量标准**：品种、规格、成熟度、无腐烂变质，到货验收不合格可拒收或换货。
- **违约与替代**：供应商无法按时按量供货时的通知义务和补偿方式；你方是否有权紧急从其他渠道采购且不影响后续合作。

**3. 用“滚动预报+每日确认”管理节奏**
- 每周给供应商一份未来7天用量预报，旺季每天上午更新次日需求。
- 补货需求尽量走文字（微信/邮件），保留记录；电话确认后补一条文字“确认今日追加X箱，单价X，X点前送到”。
- 到货当场验收数量、规格、新鲜度，异常当场拍照并在送货单上注明。

**4. 准备备选供应商**
临时补货条款再细，也不如有一个备选渠道。旺季前至少接触1—2家二级供应商，谈好“紧急情况下可小批量拿货”的口头或书面意向，避免主供应商临时掉链子。

**可直接发给供应商的约定模板：**
> 因旺季用量增加，双方约定：我方每日10:00前以微信发出临时补货需求，供应商须在2小时内确认，确认后24小时内送达；临时补货单价按原合同价执行，单日追加量不超过X箱；到货验收标准按原合同执行，不合格可拒收并要求换货；供应商无法供货须提前12小时通知，我方有权紧急外采且不影响后续合作。

核心原则：**把“临时”变成“有规则的临时”**——触发、时限、价格、质量、违约五个要素写清楚，比口头打招呼可靠得多。
