结论先说：**多数水果批发商应采用“分层定价”：主力走量品类锁短中期价（3～7天或一个到货周期），波动大、时令性强的品类每天议价；不要一刀切。**

判断依据看四个变量：

1. **价格波动幅度**
- 日常波动小、供需稳定的品类（苹果、梨、土豆类耐储水果）：签3～7天甚至半月的框架价，减少议价成本。
- 时令性强、天气敏感、到货集中（荔枝、西瓜、樱桃、草莓）：每天议价或一天两价，锁价容易锁亏或锁死客户。

2. **你的库存和资金周转**
- 库存周转快、每天大量进出：锁价能稳定毛利，但要有“浮动条款”。
- 库存重、资金压力大：不宜长锁，优先快速出货，价格随行就市。

3. **客户结构**
- 对商超、餐饮、团购等长期客户：签短周期框架价，约定“随行调整机制”，保客户也保自己不倒挂。
- 对二级批发、散客：每天议价，成交快、风险低。

4. **采购端是否可对冲**
- 如果你能提前锁定产地收购价或到货成本，可以对下游签相应期限的价。
- 如果采购价本身天天变，下游长锁价就是单边赌行情，不建议。

**可执行做法：**
- 设一个“基准价+浮动区间”：比如锁3天基准价，涨跌超过5%重新议价。
- 每天议价品类控制在总SKU的30%以内，避免管理成本过高。
- 对长期客户签“保量不保价”或“保价带上限”的短约，不签超过一个到货周期的固定价。
- 记录每天品类价格波动率，连续两周波动大的品类转为日议价，波动小的转短约。

一句话：**耐储、波动小、长期客户多的品类签短约；时令、波动大、散客多的品类每天议价；合同里必须留价格调整条款。**
