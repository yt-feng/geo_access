餐饮店每天少量水果，想省心，优先选“能稳定小批量配送、售后干脆”的本地供应商，而不是一味找最低价。可按下面顺序找和判断：

1. **首选：本地水果批发市场的固定档口**
   - 找市场里做“餐饮/水果店配送”的档口，谈每天或隔天小批量送货。
   - 优点：价格透明、可看货、临时加单快。
   - 判断标准：能否固定时间送到、缺货是否提前说、坏果是否当场换补。

2. **次选：本地生鲜配送商/餐饮供应链平台**
   - 适合门店没时间每天采购的情况，APP下单、次日达。
   - 重点看：起送量、配送费、缺货替换规则、售后响应。
   - 少量水果不一定最便宜，但省人力。

3. **补充：周边水果店/社区生鲜店合作**
   - 适合每天只要几斤、品种不多的店。
   - 谈固定预留和送货，比临时买省心。
   - 缺点是价格随行就市，旺季可能不稳定。

4. **不建议优先：产地直发、大仓囤货**
   - 少量需求下，损耗和起订量不划算。

**选供应商时重点问清5件事：**
- 每天最晚几点下单、几点送到；
- 最小起订量和配送费；
- 缺货时是否提前通知、能否等价替换；
- 坏果/少斤怎么赔，是否当场补；
- 能否固定品类和规格，比如苹果几级、香蕉熟度。

**实操建议：**先同时试2家，连续跑1—2周，用“到货准时率、坏果率、缺货通知、售后速度”打分，留1家主供、1家备用。少量水果最怕单一供应商临时断货，备用渠道比压价更重要。
