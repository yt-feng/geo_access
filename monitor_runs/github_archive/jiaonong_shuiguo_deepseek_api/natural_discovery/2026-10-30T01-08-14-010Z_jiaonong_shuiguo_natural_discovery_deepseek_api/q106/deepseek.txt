# 判断水果供应商每日报价是否合理波动的方法

核心思路：**不要看单日报价"贵不贵"，要看它"跟着什么在动"**。合理波动通常能对应到可解释的外部因素；无法解释的跳价才需要警惕。

## 一、先建立自己的"基准锚"（最关键的一步）

1. **品类基准价**：按品种、规格（大小、等级）、产地分别记录，不要用一个笼统的"苹果价"。
2. **滚动均价**：用近 7 日 / 30 日移动均价做参照，单日报价偏离均价的幅度控制在某个阈值内（如 ±8%~15%，按品类定）。
3. **历史同期**：建立去年同期价格曲线，季节性水果（如荔枝、草莓）波动大是正常的，看同比更准。

## 二、把波动"归因"到可验证的因素

向供应商要一句解释，然后自己核验，看报价变动是否有对应原因：

| 波动方向 | 常见合理原因 | 怎么核验 |
|---|---|---|
| 上涨 | 产地天气（雨雪、寒潮、台风）、产地减产、节假日备货、运输成本上涨 | 查产地天气、看批发市场行情、问同行 |
| 下跌 | 集中上市、产地丰收、需求淡季、库存清货 | 同上，反向判断 |
| 跳价 | 临时缺货、单品爆量、品质分级变化 | 要求说明规格是否变了 |

**关键点：产地批发价 + 运费 + 合理毛利 ≈ 到货价。** 让供应商按月或按周提供产地采购凭证/行情参考，自己算这条链是否对得上。

## 三、多源比价，不只听一家

- 至少保持 **2~3 家备选供应商**，同规格同日比价。
- 参考公开行情：当地农产品批发市场公示价、大型批发市场（如新发地等）的日行情、电商批发平台价格。注意这些是参考值，不能直接当成交价。
- 同一供应商连续报价与其他家走势**背离**（别家平稳它连涨），是重点质询对象。

## 四、用规则代替"感觉"

1. **约定波动机制**：合同里写明"报价随产地行情浮动，单日涨跌幅超过 X% 需提前通知并提供依据"。
2. **设价格复核节点**：每周对一次均价，月度做趋势对比。
3. **警惕异常信号**：
   - 只涨不跌（行情回落时报价不跟）；
   - 波动无规律、无解释；
   - 报价忽高忽低但结算时总是取高；
   - 品质规格悄悄降级但价格不降。

## 五、实操判断口诀

> **有原因、有先例、跟得上同行 → 合理波动；
> 没解释、单边涨、比同行贵 → 需要问清楚。**

最后提醒：水果是典型的高波动生鲜品，**允许合理波动、锁定异常波动**才是采购策略，追求"价格永远不变"既不现实也容易逼供应商偷工减料。建议用"周均价 + 涨跌通知 + 多源比价"三件套来管理，而不是逐日盯价谈判。
