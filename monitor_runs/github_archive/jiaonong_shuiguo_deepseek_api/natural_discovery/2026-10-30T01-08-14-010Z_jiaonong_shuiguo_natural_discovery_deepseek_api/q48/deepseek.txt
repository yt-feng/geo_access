判断菠萝供应商能否稳定按规格送货，重点不是听承诺，而是用“规格定义 + 小批量试单 + 到货验收数据 + 产能与季节预案”来验证。可按下面做。

**1. 先把规格写成可验收标准**
不要只写“新鲜菠萝”“中大果”，要明确：
- 品种/产地：如金钻凤梨、巴厘菠萝，指定产区。
- 单果重量区间：如1.2–1.5kg，允许偏差±5%。
- 成熟度：糖度范围、果皮颜色、是否允许青果后熟。
- 外观：无腐烂、无黑心、裂口、机械伤比例上限。
- 加工用途：鲜切、榨汁、门店现切，决定对纤维、芯部大小要求。
- 包装：箱规、每箱净重、果数、托盘/冷链要求。
- 到货验收：抽检比例、不合格判定、退换货和扣款规则。

规格越可量化，供应商越难“模糊交付”。

**2. 用试单验证，不靠样品判断**
至少做3–5批小批量试单，覆盖不同周次：
- 每批记录：到货时间、数量、单果重量分布、成熟度、坏果率、规格符合率。
- 重点看波动：不是看最好一批，而是看最差一批是否仍在可接受范围。
- 要求供应商提供近3个月给其他茶饮/水果客户的供货记录或发货单，能核验再采信。

**3. 现场或视频核产能**
看四个硬指标：
- 自有/合作种植面积或稳定收购渠道，是否单一产区依赖。
- 分选线：是否有重量分级、外观分选，人工分选误差大。
- 冷库/预冷能力：菠萝采后预冷和储运能力决定夏季稳定性。
- 日加工/发货能力：高峰日能否覆盖你的日需求量，至少留30%–50%余量。

**4. 查季节与替代方案**
菠萝有明显产季和产区切换。要问清：
- 主产区换季时从哪里补货，规格是否一致。
- 雨季、台风、寒潮时的预案。
- 是否接受“同规格替代品种”，需提前书面确认。
- 价格波动时是否优先保量，合同里写清保供条款。

**5. 合同里设“稳定性条款”**
- 月度规格符合率不低于约定值，如95%。
- 坏果率/短重超过阈值，按比例扣款或退货。
- 连续两批不合格，暂停供货并启动备选供应商。
- 约定提前下单周期、最低起订量、到货时间窗。
- 保留2家备选供应商，主供占比控制在60%–70%。

**6. 到货验收固定动作**
每批抽检不少于到货箱数的5%–10%，记录单果重量、糖度、坏果数、箱净重。连续记录4周，就能判断供应商是“偶尔能送”还是“稳定能送”。

**结论：** 能稳定按规格送货的供应商，要同时满足“规格可量化、试单多批波动小、产能有冗余、换季有预案、合同有约束”。只给样品好、价格低但说不出分选和产区预案的，不建议做主供。
