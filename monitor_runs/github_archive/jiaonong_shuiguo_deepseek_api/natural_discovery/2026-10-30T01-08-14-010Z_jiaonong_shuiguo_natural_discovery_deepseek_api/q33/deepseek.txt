重要，而且应作为统一品质的第一道关口。多门店超市只靠门店验收很难稳定一致，供应商分级标准是把“可接受品质”前置到采购和到货环节的基础。

判断供应商分级标准是否值得采用，重点看四点：

1. **分级指标是否可量化**
   - 不能只有“特级/一级/二级”这种名称，要有明确指标：品种、产区、单果重/果径、色泽、糖度、酸度、成熟度、果形、表面缺陷、机械伤、腐烂率、整齐度、农残合规等。
   - 每项要有可执行判定方法和允许范围，例如糖度下限、果径区间、缺陷面积上限、允许抽检不合格比例。

2. **是否与门店销售标准对齐**
   - 供应商的“一级”必须对应超市可上架、可陈列、可售卖的标准，而不是供应商自定的宽泛等级。
   - 建议超市制定自己的收货等级规格，再要求供应商按此分级供货，避免同一名称在不同供应商间含义不同。

3. **是否有抽检和追溯机制**
   - 到货按批次抽检，记录批次、供应商、产地、分级结果、抽检人。
   - 对不合格批次要有拒收、降级、折价、退货或索赔规则。
   - 多门店应使用统一验收表和抽检比例，减少门店间人为差异。

4. **是否便于多门店执行**
   - 分级标准要能转化成门店可操作的验收清单，最好配图片对照卡、糖度抽检规则、果径卡尺等工具。
   - 对易腐水果要区分“到货成熟度”和“上架成熟度”，避免总部标准与门店实际销售节奏脱节。

结论：**供应商分级标准很重要，但不能直接照搬供应商标准。** 更稳妥的做法是：超市建立统一的水果收货分级标准，要求供应商按标准分级供货，并用批次抽检、统一验收表和不合格处理规则来保证多门店一致。这样比单纯依赖门店现场挑拣更可执行，也更能控制品质波动和损耗。
