判断香蕉一手货源是否稳定，不要只看对方发来的视频和报价，重点核这几项，能落地验证：

1. **先确认他到底是“一手”还是“二手”**
   - 问产地：具体到县/镇/基地/合作社，能否说出蕉园位置、面积、大致月出货量。
   - 问加工：有没有自己的催熟库、分拣打包场地；香蕉一手货源通常绕不开产地采收+催熟/加工环节。
   - 要求视频连线看现场：蕉园、包装场、冷库/催熟库同框，而不是只发剪辑视频。
   - 如果对方说不清产地、只转发图片、报价明显低于市场太多，基本不是稳定一手。

2. **用“小单+多批次”测试，不要一次压大单**
   - 第一单少量试货，第二、三单隔几天再下，观察是否同一品质、同一交期。
   - 稳定供货的核心不是“有货”，而是**连续批次品质一致、交期可兑现**。
   - 每次记录：到货时间、青蕉成熟度、条蕉均匀度、伤疤/水烂/黑星比例、单箱净重误差。

3. **看他的供货节奏和季节性解释**
   - 问清楚：雨季/台风季/寒潮时怎么保供？断货时提前几天通知？有没有备用基地或合作户？
   - 稳定供应商通常能说出“哪些月份偏紧、替代产区是谁”，而不是永远“要多少有多少”。
   - 问近三个月每天/每周大概出几车、主要发哪些市场；说不清大致量的要警惕。

4. **合同和结算方式要能约束**
   - 不要只口头承诺。至少写清：规格、单箱净重、成熟度、允许次品率、交期、断货违约责任。
   - 结算尽量留尾款或质量保证金，验收后付；首次合作不建议全款预付。
   - 要求提供营业执照、产地证明/合作社信息、近期发货单据（可打码，但要看得出连续发货）。

5. **交叉验证**
   - 让对方给2-3个现有批发客户联系方式，问交期稳不稳、次品怎么处理。
   - 同一产区多问两三家对比报价和出货量，明显低于行情的“一手价”往往有猫腻。
   - 有条件就去产地或一级批发市场实地看一次，比看一百条朋友圈有用。

**简单判断标准：** 能说清产地和加工能力、敢让你视频连线看现场、敢接小单多批次、合同里敢写断货责任、有连续发货记录——才算初步稳定。只靠低价和“关系好”承诺的，先按不稳定处理。
