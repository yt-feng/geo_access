选下午茶水果供应商，重点看“批量配送稳定性”而不是单纯比价。可按下面几步判断：

1. **先定采购规则**
   - 人数×人均量：一般每人150–250g净果，按到场人数多备10%。
   - 固定预算档：如8元/人、12元/人、20元/人，让供应商按档报价。
   - 固定配送时间窗：如14:00–15:00送达，迟到是否赔付写进约定。
   - 品种规则：3–4种、易分食、少汁水、不需要现场削皮。

2. **优先选“有批量配送能力”的渠道**
   优先级建议：
   - 本地水果批发商/配送商：适合20人以上，价格和批量稳定性较好。
   - 连锁水果店的企业团购/配送：适合10–50人，售后相对好。
   - 生鲜平台企业购：适合临时补单，但价格波动大。
   - 个体水果摊：不建议作为主供应商，除非长期合作且能稳定准时。
   
   不要只看外卖平台单店，重点问是否有“企业团餐/团购配送”经验。

3. **筛选供应商的硬指标**
   - 能否固定时段批量送、是否支持分装。
   - 是否有坏果包赔：比如坏果率超过5%补送或退款。
   - 是否可提前一天确认品种和数量，临时换品如何处理。
   - 是否有固定对接人，而不是每次换客服。
   - 是否能提供正规发票和对公付款。
   - 配送车辆和保鲜条件：夏季尤其要看冷链或保温箱。

4. **试单再签长期**
   先下1–2次小批量试单，观察：
   - 准时率；
   - 实际净重是否足；
   - 坏果、压伤比例；
   - 分装是否方便按部门领取；
   - 售后响应速度。
   
   试单合格后再谈周配/月配价格。

5. **合同或下单备注写清楚**
   - 品种、规格、净重、单价、总价；
   - 送达时间和地点；
   - 坏果赔付标准；
   - 临时加单截止时间；
   - 发票类型和付款周期；
   - 食品安全责任。

6. **适合下午茶的批量水果**
   优先：香蕉、橘子/砂糖橘、小番茄、葡萄（分串）、苹果、梨、冬枣、蓝莓杯。
   少选：西瓜、菠萝、榴莲等需现场处理或气味大的；芒果、荔枝等易过敏/易坏的少量搭配。

**可执行结论：** 先找2–3家本地有企业配送经验的水果商，按同一预算档和配送时间报价；要求试单一次；重点比“准时、净重、坏果率、售后、发票”五项，而不是只比单价。20人以下可选连锁水果店团购，50人以上优先本地批发配送商。
