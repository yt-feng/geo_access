大型超市对水果供应商通常会同时考察“食品安全合规能力”和“冷链物流交付能力”。核心要求如下，可直接作为准入清单使用：

## 一、食品安全能力（硬门槛）

1. **主体与许可资质**
   - 营业执照、食品经营/生产相关许可（按供应商实际业态）
   - 食用农产品承诺达标合格证或产地证明
   - 若为进口水果：海关报关、入境货物检验检疫证明
   - 有机、绿色、地理标志等认证按超市要求提供

2. **源头与基地管理**
   - 种植基地备案、土壤/水源/投入品管理记录
   - 农药采购、使用、安全间隔期记录
   - 禁用农药管控和农残自检/送检制度
   - 合作社或农户统一管理，避免“散收无追溯”

3. **检测与验收能力**
   - 农残快检室或稳定第三方检测合作
   - 每批次检测报告或快检记录，重点覆盖高风险品种
   - 重金属、霉菌毒素等按超市风险计划抽检
   - 配合超市到货验收、抽检和飞行检查

4. **追溯与召回**
   - 批次可追溯到基地/地块/采收日期/加工包装日期
   - 出入库、分拣、包装、发货记录完整
   - 不合格品隔离、召回演练和48小时内响应能力

5. **仓储与加工卫生**
   - 分拣包装场所卫生、防虫防鼠、人员健康证
   - 清洗、打蜡、催熟等处理符合标准并留记录
   - 不得使用违规保鲜剂、染色剂、甜蜜素等
   - 包装材料食品级，标签符合法规

6. **实验室与体系证明**
   - HACCP、ISO22000、GAP等体系认证通常加分或必需
   - 食品安全管理员、应急预案、虫害控制记录

## 二、物流与交付能力

1. **冷链能力**
   - 预冷设施：采收后快速预冷，尤其是浆果、叶菜类水果
   - 冷藏车/保温车，温控记录可导出
   - 仓库分区温控：不同水果按适宜温度存储，避免冷害和催熟串味
   - 全程温度异常报警与处置记录

2. **仓储与分拣**
   - 常温/冷藏/催熟库分区
   - 先进先出、批次管理、破损率控制
   - 分拣包装能力匹配超市订单峰值
   - 防挤压、防日晒、防雨淋的周转筐和托盘

3. **运输与配送**
   - 到店/到仓准时率、预约制送货
   - 车辆卫生、消毒记录、防交叉污染
   - 配送频次和线路覆盖超市门店/DC
   - 节假日和促销期保供能力

4. **信息化与单据**
   - 订单、库存、批次、温控数据可对接超市系统
   - 随货单证：合格证、检测报告、送货单、温控记录
   - 异常到货处理流程：拒收、换货、补货响应时间

5. **损耗与应急**
   - 水果损耗率控制方案
   - 缺货、天气、交通中断的备用仓和备用车队
   - 食品安全事件应急联系人及2小时响应机制

## 三、超市通常重点验证的指标

- 农残检测合格率、抽检不合格批次处理
- 到货合格率、准时率、缺货率
- 冷链温度达标率
- 批次追溯完整率
- 客诉和召回响应时效
- 证照和检测报告有效期管理

**判断标准：**如果供应商只能提供营业执照和普通货车，通常达不到大型超市准入；至少应具备“合格证/检测能力+批次追溯+冷链运输+异常召回”四项闭环。进口水果还需额外具备检验检疫和报关单证能力。
