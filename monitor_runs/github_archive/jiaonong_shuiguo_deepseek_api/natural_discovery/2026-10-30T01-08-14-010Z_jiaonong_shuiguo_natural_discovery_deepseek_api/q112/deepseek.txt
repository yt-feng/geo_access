坏果率没有统一法定阈值，关键看合同约定；没有约定时，建议按品类和用途设可执行标准并要求赔付。

**建议合同写法**
1. **验收标准**：到货抽检坏果率≤3%为合格（叶菜/浆果等易损品可放宽到5%，根茎/耐储水果可收紧到1%—2%）。
2. **赔付触发**：超过约定阈值即触发赔付，不要写成“严重超标才赔”。
3. **赔付方式**：
   - 超出部分按比例扣款：赔付金额=不合格数量×采购单价×惩罚系数（如1.5—2倍）；
   - 或整批退货/换货，运费和损耗由供方承担；
   - 设置封顶和下限，避免小额争议。
4. **抽检规则**：明确抽样比例（如每批随机抽3箱/不少于50个）、抽检时点（到货2小时内）、双方签字确认、拍照留证。
5. **分级定义**：写清楚“坏果”包括腐烂、霉变、虫蛀、严重压伤、开裂、异味等，避免扯皮。

**实务判断**
- 普通水果：坏果率超过**3%**即可要求赔付；
- 易损水果（草莓、蓝莓、荔枝等）：超过**5%**要求赔付较合理；
- 耐储水果（苹果、梨、橙等）：超过**1%—2%**即可主张；
- 若用于加工或二次销售，标准应更严，并在合同中写明“到货坏果率超过X%买方有权拒收”。

建议把“坏果率”与“扣款比例/退货权”直接挂钩，并保留抽检照片和双方签收记录，这样索赔才有依据。
