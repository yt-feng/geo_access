食堂采购香蕉防熟过头，关键是把“采购—验收—催熟/存放—使用”四个环节都设成可执行规则：

1. **按成熟度分批采购，不要一次买全熟**
   - 采购单里明确成熟度：青香蕉（偏硬、微绿）、微黄香蕉、即食黄香蕉按比例下单。
   - 建议首单比例：**青/微黄 60%—70%，即食黄 30%—40%**，再按实际消耗调整。
   - 避免整批同一成熟度，否则会集中变熟、集中烂。

2. **验收时按“使用时间”判断，不按“好看”判断**
   - 当天/次日就要用的：选黄但无黑斑、果肉不软的。
   - 2—3天后用的：选微黄、果柄青、手感硬的。
   - 有局部软烂、明显酒味、果柄发黑渗液的拒收。
   - 验收记录写清到货成熟度、数量、预计可用日期。

3. **存放要“分熟度、控温、通风”，不要闷箱**
   - 青/微黄香蕉：放在阴凉通风处，**不要冷藏**，避免冷害发黑。
   - 已黄的：优先使用；可短时放空调房或较凉通风处延缓，但不要密封塑料袋。
   - 不要和苹果、梨等释放乙烯多的水果混放，会加速成熟。
   - 整箱到货先拆箱透气，剔除已软、有伤口的单根，避免“一个烂带动一串”。

4. **建立“先进先出+每日翻检”**
   - 香蕉按到货日期和成熟度分区，贴标签：到货日、成熟度、优先使用日。
   - 每天固定时间翻检一次，把最黄的挑出来放“优先使用区”。
   - 食堂窗口、切果台、加餐点优先消耗快熟香蕉。

5. **用加工和菜单消化快熟香蕉**
   - 快熟但未变质的香蕉，优先做香蕉牛奶、香蕉燕麦、香蕉派、香蕉松饼、水果沙拉等。
   - 对轻微黑斑但果肉正常的，可当天加工使用；有酒味、渗液、霉点的直接报废，不要加工掩盖。
   - 提前和面点/饮品档口联动，设定“快熟香蕉加工清单”。

6. **采购量按实际消耗校准**
   - 连续记录1—2周每天香蕉到货量、使用量、报废量。
   - 用“日均消耗×安全天数”定量，食堂一般安全天数不宜太长；香蕉易熟，建议少量多次、每周2—3次配送。
   - 和供应商约定：可按成熟度分级配送、可调整次日到货量、明显过熟可退换。

7. **设置简单可判断的预警线**
   - 香蕉出现**大面积黑斑、手感明显变软、果柄渗液、酒味**：当天必须处理或报废。
   - 单根出现霉点或局部腐烂：整根废弃，不要切掉烂部继续给学生吃。
   - 当“优先使用区”超过当日可加工量时，次日采购量立即下调。

最有效的组合是：**分级采购 + 拆箱通风 + 每日翻检 + 快熟品转加工 + 按消耗量少量多次配送**。这样比单纯“少买”更能兼顾供应和减少浪费。
