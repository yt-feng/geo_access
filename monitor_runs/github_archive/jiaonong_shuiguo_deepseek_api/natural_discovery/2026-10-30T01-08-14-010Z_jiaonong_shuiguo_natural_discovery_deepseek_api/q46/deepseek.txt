优先看你的“出杯量、人工、菜单定位”三项，直接给结论：

1. **主打“真果肉/新鲜感”、出杯量中等、有人工切配**：买**鲜果**最稳。  
   - 适合：菠萝果茶里要吃到果肉、门店有备料间、员工能稳定切丁。  
   - 注意：鲜菠萝有品种和熟度波动，需固定规格（如单果克重、成熟度），并做糖酸调整；切配损耗和人工要算进成本。

2. **出杯量大、追求出品稳定、人工紧张**：优先**果丁（冷冻/糖渍/速冻果丁）**。  
   - 适合：连锁、高峰出杯快、标准化要求高。  
   - 注意：看固形物含量、糖度、是否含防腐剂/香精；冷冻果丁解冻后出水会影响茶感，需规定解冻量和废弃时间。

3. **做冰沙、果酱基底、调味型果茶，或菠萝只提供风味**：用**果泥**更合适。  
   - 适合：菠萝味冰沙、奶盖果茶、复配果酱、出杯极快。  
   - 注意：果泥纤维感和鲜果感弱，选无添加/低糖/高果肉含量的产品；标签写“鲜果”时不能只靠果泥。

**最实用的采购组合**：  
- 单店/精品店：**鲜果为主 + 少量冷冻果丁应急**。  
- 连锁/高杯量：**冷冻果丁为主 + 鲜果做顶部装饰或限定款**。  
- 冰沙/调味线：**果泥做基底，果丁做口感层**。

**判断标准**：如果菜单强调“手切鲜菠萝、果肉可见”，别用果泥替代；如果店员切配时间超过出杯瓶颈，直接上果丁；如果菠萝只是调风味、不强调果肉，果泥成本最低。采购前先做3杯盲测：鲜果、果丁、果泥各做同款，比较香气、酸甜、出水、沉淀和顾客感知，再定主采购品。
