判断香蕉供应商能否全年稳定供货，建议从以下方面考察：

1. **产地与产区布局**：要求供应商说明香蕉来源产区。香蕉主产区有季节性，单一产区很难全年稳定供应；能全年供货的供应商通常跨多个产区调货。要问清各产区上市时间，看能否覆盖全年。

2. **种植基地规模与自有程度**：了解供应商是自有基地、长期合作基地还是纯中间商。自有或长期合作基地比例越高，稳定性越好。要核实基地面积、位置、年产量。

3. **气候与灾害应对**：香蕉怕台风、寒害、病害（如枯萎病）。问供应商遇到台风季、冬季低温时如何保供，是否有备用产区、储备或应急预案。

4. **加工与仓储能力**：香蕉需要催熟和冷链。供应商是否有催熟库、冷库、冷链运输能力，决定其能否在淡季或断档期调节供应。

5. **历史供货记录**：要求提供近1–2年对同类超市或客户的供货记录、月度供货量，看是否有断供月份。可要求提供合作客户作参考（需对方同意）。

6. **合同保障**：在合同中约定全年最低供货量、断供违约责任、替代产区条款、价格调整机制，把“全年稳定”落到可追责的条款上。

7. **实地或视频验厂**：有条件时实地看基地、加工厂、冷库；至少视频核实。

8. **小批量试单**：先按季度或月度试单，观察淡季（如冬季、台风季）的实际供货表现，再决定长期合作。

核心判断标准：**多产区覆盖能力 + 自有/长期基地比例 + 冷链催熟能力 + 历史断供记录 + 合同约束**。单一产区、纯转手贸易商、无仓储能力的供应商，全年稳定供货风险较高。
