结论：**整果最适合作为线上生鲜电商的主销品；切配适合做高毛利补充，但要严格控损耗和冷链；冷冻原料更适合做B端/预制菜/烘焙渠道或线上补充SKU，不适合作为生鲜电商的主力鲜品。**

分场景判断：

1. **整果：最适合线上主卖**
   - 优势：标准化相对容易，耐运输，损耗可控，客单价可做高低搭配，消费者认知强。
   - 关键点：按果径/重量/成熟度分级；做“坏果包赔”；产地直发或区域仓发货；控制成熟度，避免到家过熟。
   - 适合：社区团购、次日达、产地直发、礼盒装。

2. **切配菠萝：适合做补充，不适合无冷链能力时主推**
   - 优势：即食便利、毛利较高、适合办公室/家庭小份场景。
   - 风险：呼吸跃变和汁液流失导致货架期短，易出水、变味、微生物风险高；配送温控要求高。
   - 建议：只在有冷藏仓、冷链配送和短半径履约时做；小份真空/气调包装；明确“冷藏即食、尽快食用”；先小范围测试复购和投诉率。

3. **冷冻菠萝原料：更适合B端或线上补充**
   - 优势：保质期长、损耗低、适合烘焙/饮品/预制菜/餐饮客户。
   - 劣势：C端生鲜电商消费者买“鲜果”心智强，冷冻原料单价和体验不匹配；需要冷冻配送，履约成本高。
   - 建议：作为B端原料、线上烘焙/饮品搭配SKU，或与鲜果组合销售，不作为鲜果主推。

**可执行建议：**
- 主推整果，占菠萝SKU的60%—70%；
- 切配做区域试点，占20%左右，仅限冷链覆盖区域；
- 冷冻原料做B端或补充SKU，占10%—20%；
- 用“坏果率、客诉率、复购率、履约成本、毛利率”五个指标跑2—4周测试，再决定扩品。
