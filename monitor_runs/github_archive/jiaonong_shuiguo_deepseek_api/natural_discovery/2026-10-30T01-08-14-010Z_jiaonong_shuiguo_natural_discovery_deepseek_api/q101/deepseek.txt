和水果供应商谈酒店早餐合作，核心是先把“稳定供应”拆成可执行的条款，再谈价格。建议按下面顺序准备和谈判。

**一、先明确自己的需求，再去谈**
- 用量：按品种列出每天/每周预计用量，区分旺季淡季，给出波动区间。
- 品种：早餐常用水果（如苹果、香蕉、橙子、西瓜、圣女果、时令水果）分“必供”和“轮换”两类，必供品种写进合同。
- 规格标准：单果大小、成熟度、甜度、外观瑕疵容忍度、是否预切/整果。早餐场景建议整果为主，减少损耗和食品安全风险。
- 送货要求：送货时间（早餐前到货）、频率、卸货地点、验收人、临时加单的响应时间。
- 结算方式：账期、对账周期、发票类型。

**二、重点谈“稳定”的保障机制**
- 备选货源：要求供应商说明主产地和备用产地，单一产地断供时如何替代。
- 缺货处理：约定缺货提前通知时限、替代品种方案、缺货违约金或补偿。
- 价格机制：不要只锁一个价。可约定基准价+随行就市调整，明确调价周期（如月度）、调价依据（当地批发市场均价或双方认可渠道）、涨幅上限。
- 质量波动：约定验收标准和不合格处理（拒收、换货、扣款），以及连续不合格的退出条款。
- 食品安全：要求提供资质证照、检测报告，明确农残超标责任和赔偿。

**三、合同里要写清楚的条款**
- 品种、规格、单价、最小供货量、送货时间和地点。
- 验收标准和验收流程（谁验、怎么记录、异议怎么处理）。
- 缺货、迟送、质量不达标的违约责任。
- 价格调整机制和账期。
- 合同期限、试用期、退出和解约条件。
- 食品安全事故的责任划分。

**四、谈判策略**
- 先小批量试供：设1—2个月试用期，按实际到货合格率、准时率评估，再签长期。
- 用“稳定用量”换“稳定价格和服务”：承诺基础采购量，换取优先供货和缺货补偿。
- 不要只找一家：至少备选1—2家供应商，避免被单一供应商卡住。
- 把口头承诺写进合同：送货时间、缺货通知、换货响应，都要落到纸面。

**五、容易踩的坑**
- 只谈价格不谈规格，到货大小不一、成熟度不可控。
- 没有缺货预案，旺季或天气异常时断供。
- 验收流于形式，没有记录，出问题无法追责。
- 账期和调价机制模糊，后期扯皮。

总结：谈判前把用量、品种、规格、送货、验收、缺货预案、调价机制列成清单，优先谈稳定供应和食品安全条款，价格放在保障机制之后谈。
