核心是把“不可控的农产品”变成“可验收的商品”：采购环节建立分级标准、到货抽检和售后归因，而不是只靠供应商口头承诺。

**1. 先定可验收标准，不要只说“要好的”**
- 按品类写清：品种/产地/规格（单果克重或直径）、成熟度、糖度范围、允许瑕疵比例、腐烂率上限、软伤/压伤上限。
- 例如：到货腐烂率≤1%，明显压伤≤3%，糖度抽检均值≥约定值且低于下限的比例≤10%。
- 标准要能现场判断：用糖度计、卡尺、电子秤、色卡/成熟度照片，不靠“看着还行”。

**2. 采购时把风险分给供应商**
- 优先选有分级包装能力的产地仓/合作社，而不是临时散户拼货。
- 合同写明：分级标准、抽检规则、不合格扣款/退换、到货腐烂率超标按比例赔付。
- 对新供应商先小批量试单，连续3—5批稳定后再放量；不要一次押单一供应商。

**3. 到货抽检做成固定动作**
- 每批随机抽检，记录：腐烂数、压伤数、糖度、单果重、成熟度、口感试吃。
- 抽检结果直接决定入库、折价或退货；异常批次单独隔离，避免混入好货。
- 建立供应商批次台账，按“坏果率、口感投诉率、到货波动”做月度排名，末位淘汰或降量。

**4. 用成熟度和物流降低“口感不稳定”**
- 采购成熟度按销售半径定：远距离发七八成熟，同城/次日达可发更高成熟度。
- 要求供应商采后预冷、分级包装；易压伤品类用蛋托/网套/隔板，减少运输软伤。
- 不同批次不要混发同一链接，避免顾客一次收到口感差异大的果子。

**5. 售后数据反哺采购**
- 把差评和退款按原因归类：腐烂、压伤、酸/不甜、过熟、大小不符。
- 每月把归因数据反馈给供应商，明确扣款或整改；连续两月不达标的换供应商。
- 评价引导写具体原因，比只看到“差评”更有采购价值。

**6. 库存和发货节奏也要管**
- 水果到仓后先进先出，设置最长在仓时间；易腐品类尽量预售/按单采，减少压货。
- 高温季节缩短在仓和运输时间，必要时加冰袋/保温箱，但先小批量验证成本是否划算。

最可执行的第一步：选销量最高的2—3个品类，各写一张“到货验收卡”（规格、糖度、腐烂率、压伤率、抽检比例、不合格处理），连续执行一个月，用差评归因和抽检记录筛供应商。这样坏果和口感问题会从“评价运气”变成可管理的采购指标。
