先给结论：**不能一概而论，应按“坏果发生环节 + 商品特性 + 平台/商家承诺 + 顾客操作”四条线划分责任。** 对生鲜水果，通常默认“到货验收前风险在商家”，但顾客延迟取货、未按要求冷藏、超时后才反馈等会减轻商家责任。实操上建议按以下规则判断：

**1. 先看坏果比例和性质**
- **少量轻微压伤、个别软果**：属于生鲜正常损耗范围，若平台有“坏果包赔/坏果率承诺”，按承诺赔；没有承诺可补发/部分退款，不宜全单免责。
- **大面积腐烂、发霉、异味、流水**：通常说明采摘、分拣、包装、冷链或运输环节有问题，商家/平台承担主要责任。
- **同一批次多人投诉**：优先推定商家或供应链责任，应主动召回/退款并排查。

**2. 看交付与验收节点**
- **快递柜/驿站签收但未及时取件**：若顾客超过合理时间（如夏季数小时、隔夜）取货导致闷坏，顾客承担相应责任；商家对“取件前已坏”仍应负责。
- **送货上门当场验收**：当场发现坏果，商家/配送方责任明确。
- **顾客已签收后较晚才反馈**：商家可要求提供开箱视频、坏果照片、快递面单；无法证明是到货即坏的，可协商部分赔付，不宜直接全责。

**3. 看商品特性和商家承诺**
- 易腐水果（草莓、荔枝、水蜜桃等）对时效和冷链要求高，商家若未用泡沫箱、冰袋、冷链，责任更大。
- 商家页面若写明“坏果包赔”“签收24小时内拍照理赔”，按约定执行；但格式条款不能完全免除商家对到货即坏的基本责任。
- 若顾客要求“放门口/代收点”且未及时取，风险相应转移。

**4. 责任划分建议（可直接执行）**
- **商家/平台主责**：到货即腐烂、发霉、异味，或冷链/包装明显不足；按坏果比例退款或补发，严重时全额退。
- **双方分担**：少量坏果+顾客延迟取件/未冷藏；按坏果数量部分赔付。
- **顾客主责**：签收后长时间未取、未按要求储存、超理赔时限且无证据；商家可拒全赔，但可给善意补偿。
- **配送方责任**：暴力分拣、延误、未冷链导致批量坏果；商家先赔顾客，再向配送方追偿。

**5. 处理流程建议**
先让顾客提供：订单号、快递面单、开箱视频/坏果照片、坏果数量。商家在承诺时限内按“坏果比例”赔付；批量异常则下架同批次并排查供应链。争议大时，以平台规则和消费者权益保护法为底线：**经营者应对交付时商品质量负责，不能仅以“生鲜不退不换”完全免责。**

一句话：**到货前坏，商家担；取货后因顾客保管不当坏，顾客担；混合原因按比例担；批量坏果优先查商家供应链。**
