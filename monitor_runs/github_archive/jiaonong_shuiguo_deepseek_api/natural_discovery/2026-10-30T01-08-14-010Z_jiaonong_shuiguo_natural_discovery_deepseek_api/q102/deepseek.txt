企业福利采购水果礼盒时，供应商支持开发票通常是**必须项**，定制包装则要看企业实际需求，一般建议作为**选配项**而不是所有采购的硬性门槛。

**1. 开发票：建议作为硬性条件**
- 企业采购属于对公支出，财务入账、税前扣除、审计合规都需要合规发票。
- 采购前确认：能否开**增值税专用发票/普通发票**、发票内容能否开“水果礼盒/食品/福利费”等可入账品名、税率和开票时效。
- 如果供应商只能开普票或无法开票，应谨慎，除非采购金额很小且公司财务明确接受。

**2. 定制包装：按需决定，不必一刀切**
适合要求定制包装的场景：
- 礼盒要体现企业LOGO、节日主题、慰问卡片；
- 员工福利需要统一品牌形象；
- 批量较大，供应商愿意承担起订量和打样成本。

不一定需要定制的场景：
- 采购量小、预算紧；
- 供应商标准礼盒品质和外观已满足需求；
- 定制周期会影响发放时间。

**3. 采购时建议明确写入合同/订单**
- 发票类型、税率、开票时间、发票内容；
- 定制包装的起订量、打样费、设计确认流程、交货周期、包装质量标准；
- 水果品种、规格、净重、损耗赔付和售后；
- 若定制包装涉及企业LOGO，确认版权使用和包装食品安全要求。

**结论：**开发票应作为供应商准入的硬性条件；定制包装建议根据预算、数量和发放场景决定，采购量大或强调企业形象时再要求，并把相关条款写进合同。
