看用途，结论不同。对多数茶饮店，**优先看甜度，其次看出汁率**；但如果是做鲜榨菠萝汁/果昔为主，**出汁率权重应提高**。

可执行判断：

1. **以菠萝果肉、菠萝块、装饰、果酱感小料为主**
   - 甜度更重要。
   - 原因：甜度不稳定会直接影响整杯风味平衡，需要频繁调糖；出汁率低只是损耗高一点。
   - 建议标准：到货先测糖度，设定可接受区间；甜度不达标就调整糖浆或配方。

2. **以鲜榨菠萝汁、果昔、冰沙为主**
   - 出汁率更重要或至少与甜度并重。
   - 原因：出汁率低会显著抬高单杯原料成本和出杯效率。
   - 建议标准：固定品种和成熟度，记录“每公斤出汁量”，低于历史均值就换供应商或批次。

3. **门店通用采购建议**
   - 先定产品结构：果肉类占比高→甜度优先；果汁类占比高→出汁率优先。
   - 建立两个验收指标：**糖度（Brix）**和**出汁率（每公斤出汁毫升数）**。
   - 不要只看单一指标：甜度太低可补糖，但出汁率太低会直接增加成本和操作时间；甜度太高也可能稀释后香气不足。

简单结论：**综合茶饮店，甜度是风味底线，出汁率是成本底线；多数门店先保甜度，再按产品结构选出汁率。**
