建议优先选**稳定供应商做日常主供，本地批发做补充**。理由和可执行判断如下：

1. **香蕉更适合稳定供应商**
   - 香蕉损耗高、成熟度要求高，需要稳定到货、可退换、能按周调整量。
   - 如果本地批发价低但批次不稳，香蕉容易出现青黄不接或当天卖相差。

2. **苹果可以本地批发补货，但主供仍建议稳定**
   - 苹果耐储，适合本地批发比价、补货。
   - 但社区超市销量有限，频繁跑批发市场的时间成本和起批量风险要算进去。

3. **用三个指标决策**
   - **损耗率**：香蕉损耗超过8%-10%，说明供应链不稳，优先换稳供。
   - **到货稳定性**：一周内是否出现缺货、成熟度不合格、临时涨价。
   - **综合成本**：批发价+运输+损耗+人工，不只看单价。

4. **推荐做法**
   - 找1家稳定供应商供香蕉和基础苹果，签简单周供协议：可退换、定等级、定频次。
   - 本地批发只用于临时补货和比价，不承担主供。
   - 先试销2周，记录销量、损耗、毛利和缺货次数，再定长期比例。
