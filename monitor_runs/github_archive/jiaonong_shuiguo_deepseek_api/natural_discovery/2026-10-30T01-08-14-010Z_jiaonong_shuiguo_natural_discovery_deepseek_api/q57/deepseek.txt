结论先给：**大多数餐饮连锁应以“中央厨房统一收货”为主，门店只保留极少数例外直采**。但“统一收货”不等于所有水果都进中央厨房再二次配送，建议按品类分层设计。

### 一、为什么统一收货更好
1. **品质标准统一**：水果的成熟度、规格、瑕疵率、农残检测最容易因门店不同而失控，中央厨房可集中验收、分级、拒收。
2. **采购议价和供应稳定**：总部集中下单，供应商更愿意保量保价，减少门店各自找货导致的价格和品质波动。
3. **食品安全可追溯**：统一索证索票、批批检测、留样和冷链记录，出问题能快速定位批次。
4. **减少门店操作负担**：门店后厨面积小、人手紧，水果验收需要专业判断，放在门店容易变成“谁有空谁收”。
5. **损耗更可控**：集中收货后可按门店订单分拣、按成熟度配送，减少门店囤货和过期损耗。

### 二、不建议全部统一收货的情况
以下品类或场景，门店分开收货或“供应商直送门店+总部统管”更合适：
- **极短保、易损水果**：如草莓、蓝莓、杨梅、荔枝、水蜜桃，二次分拣和转运会增加损耗，可由总部签约供应商直送门店，但必须执行总部验收标准和抽检。
- **门店现切果盘/鲜榨需求**：对成熟度要求高，门店按日订货、小批量直送更灵活。
- **偏远门店或配送成本过高**：统一配送的物流成本可能超过损耗节省，可设区域分仓或区域中央厨房。
- **极小规模连锁**：门店少于10家、中央厨房能力弱时，统一收货的固定成本可能不划算。

### 三、推荐落地模式
**“总部统采统签 + 中央厨房集中验收 + 门店直送例外清单”**
- 总部统一供应商准入、价格框架、验收标准、检测要求。
- 中央厨房负责耐储水果的集中收货、分拣、配送。
- 易损短保水果走“供应商直送门店”，但门店按总部标准验收，数据实时回传，总部抽检。
- 门店只保留极少数临时补货权限，且需总部审批或指定供应商。

### 四、判断标准
用三个指标决策：
1. **损耗率**：统一收货后综合损耗是否低于门店自收；
2. **履约成本**：包含物流、分拣、仓储的总成本；
3. **品质投诉率**：门店端水果品质投诉是否下降。

如果统一收货后“损耗+物流”总成本不高于门店自收，且品质投诉下降，就应坚持统一收货；反之，对易损品类做直送例外。
