# 便利店小面积水果的品类与损耗控制

**核心原则：少而准，快周转，不为"全"买单。**

## 一、品类控制：5～8个单品封顶

小面积便利店水果区的逻辑不是"卖水果"，而是"顺手买"——顾客买水、买烟、买关东煮时顺手带一盒。按这个逻辑选品：

- **只做TOP高频刚需**：香蕉、苹果（小果型）、橙子/沃柑、圣女果、葡萄（小串或盒装）、当季爆品1～2个。6个左右足够，最多8个。
- **砍掉"看起来全但周转慢"的**：榴莲、山竹、车厘子、整颗西瓜这类占地大、单价高、损耗敏感、动销慢的，除非店门口人流极好，否则不进或只做预订。
- **加工型优先于原果**：果切、小盒装、拼盘，单价可控、拿取方便、切掉的部分还能做成拼盘回收一部分，比堆整果更适合小店。
- **按周轮换，不做"常驻全品类"**：每周保留4～5个稳定款，2～3个位置给当季试销，一周卖不动就下架，不恋战。

## 二、损耗控制：从订货到出清的四道闸

**1. 订货：小批量、高频次**
- 按"日销×1～1.5天"订货，宁可补货也别压货。水果不像标品能压仓，多放一天就是损耗。
- 建立单品日销记录（简单表格即可），一周后就能看出真实动销，避免凭感觉进货。
- 香蕉、葡萄这类易损品按"2天量"订，苹果橙子可3天量。

**2. 陈列：控量+先进先出**
- 陈列量只放"半天到一天销量"，卖完再补，堆满台面=加速损耗。
- 严格先进先出，新货垫底、旧货在前。
- 易碰伤的（葡萄、桃）用托盘/盒装，减少翻拣。

**3. 分级处理：损耗不必全扔**
- 品相下降但可食用的 → 当天做成**果切/拼盘**，反而提升毛利。
- 临近闭店 → **限时折扣/打包促销**（如"晚间水果特价"），比第二天扔掉划算。
- 明显坏果 → 当天剔除，别让它传染整盒。

**4. 数据复盘：盯两个数**
- **损耗率**：水果类控制在5%～8%以内算健康，超过10%说明订货或选品有问题。
- **单品动销天数**：任何单品超过2～3天卖不完，下次减量或直接换品。

## 三、几个可直接落地的动作

1. 水果区面积控制在1～2个货架/冷柜，物理上限制品类数量。
2. 做一张"单品日销+损耗"周表，每周五复盘，砍掉末位2个单品。
3. 果切作为主力形态，原果只留引流款。
4. 与附近餐厅/员工餐谈好尾货处理，减少直接报废。
5. 别跟大超市拼品类，拼的是"新鲜、方便、顺手"。

**一句话判断标准**：如果某个水果你不敢保证2天内卖完，就别进。小店的胜负手在周转，不在齐全。
