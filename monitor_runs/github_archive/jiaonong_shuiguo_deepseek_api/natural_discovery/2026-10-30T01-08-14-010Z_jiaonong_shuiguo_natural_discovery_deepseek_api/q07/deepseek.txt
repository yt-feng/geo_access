水果礼盒要做得好卖，关键不是把四种水果平均塞满，而是按“送礼场景+价格带+视觉层次”做组合。苹果和橙子最稳，香蕉、菠萝更适合做点缀和“体量感”，不建议大量放香蕉，容易催熟、压伤、卖相差。

**推荐先做3个价位，别一开始铺太多SKU：**

1. **引流款 39~59元：“平安如意”小礼盒**
   - 苹果4个 + 橙子4个 + 香蕉1小把 + 菠萝1个小果或菠萝切盒
   - 卖点：寓意好、颜色亮、价格低，适合员工福利、随手礼
   - 注意：香蕉选偏青一点的，菠萝选小果，控制成本

2. **主推款 79~99元：“苹安橙意”中礼盒**
   - 苹果6个 + 橙子6个 + 香蕉2小把 + 菠萝1个
   - 卖点：苹果橙子占主体，香蕉做黄色提亮，菠萝做中心视觉
   - 这是最适合走量的价位，重点推

3. **利润款 129~159元：“果礼臻选”大礼盒**
   - 苹果8个 + 橙子8个 + 香蕉2~3小把 + 菠萝2个，可加一张贺卡
   - 卖点：体面、饱满，适合探亲、客户答谢
   - 注意：大礼盒别只靠数量堆，苹果橙子要选大果、表皮干净

**搭配原则：**
- **苹果、橙子占60%~70%**：耐放、寓意好、大众接受度高。
- **香蕉占15%左右**：提亮颜色、增加饱满感，但别贴苹果放，苹果释放乙烯会催熟香蕉。
- **菠萝占15%~20%**：放中间或做视觉焦点，建议选小菠萝，整颗更有礼盒感。
- 礼盒里用拉菲草/纸丝填缝，苹果橙子朝上，香蕉用保护套，菠萝立放或斜放。

**最好卖的细节：**
- 名字要吉利：平安橙意、苹安如意、橙心橙意。
- 标价签同时写“净重/个数”，减少顾客犹豫。
- 做2个现成样品摆门口，不要只放图片。
- 香蕉单独用袋子套一下，避免串味和催熟。
- 推出“企业团购10盒起送”和“加5元配贺卡”，提高客单。

先主推**79~99元中礼盒**，观察3~5天销量，再调整香蕉和菠萝比例。水果店礼盒最好卖的不是最贵的，而是**看起来满、寓意好、价格不心疼**的那一款。
