先给结论：谈判时不要只问“有没有区域保护”，而要把它拆成**可写进合同、可验证、可执行**的几组问题：授权范围、保护机制、串货定义与处罚、价格体系、任务考核、退出机制。下面是一份可以直接拿去问品牌方的问题清单。

## 一、区域保护：问“保护到什么程度”

1. 授权区域是按省、市还是区县？是否独家？独家期限多长？
2. 保护是只保护“签约主体”，还是保护整个区域内所有渠道？
3. 品牌方自己在区域内做直营、电商、直播、社区团购，算不算冲突？怎么处理？
4. 区域内已有其他代理商/经销商，签约后如何清理或并轨？
5. 保护是否以完成年度任务为前提？未完成时保护如何调整？
6. 跨区域调货、区域内多级分销，是否都受保护条款约束？

## 二、串货：先问“怎么定义”，再问“怎么罚”

1. 串货的官方定义是什么？跨省、跨市、线上低价销售、跨渠道供货，分别怎么认定？
2. 是否有批次码/追溯码？扫码能否查到供货来源？
3. 发现串货后，举报流程、核实时限、处理时限分别是多久？
4. 处罚对象是供货方还是销售方？处罚标准是罚款、扣返利、停货还是取消授权？
5. 被串货方的补偿机制是什么？有没有先例或书面规则？
6. 线上平台（电商、直播、社群）低价乱价是否纳入串货管理？由谁负责清退？

## 三、价格与渠道：问清“能不能管住”

1. 是否有建议零售价、最低限价？是否写入合同？
2. 线上销售是否授权？哪些平台、哪些店铺可以卖？
3. 品牌方对乱价链接的处理权限和时限是什么？
4. 促销、临期、尾货的处理规则是什么？会不会冲击区域价格？

## 四、任务与考核：问清“保护的对价”

1. 年度/季度采购任务、回款任务、铺市率指标分别是什么？
2. 未完成任务时，区域保护是否缩小、取消或转为非独家？
3. 任务调整机制是什么？市场变化时能否协商？
4. 返利、费用支持、市场投入与任务挂钩的具体规则？

## 五、合同与退出：问清“怎么落地”

1. 以上保护、串货、价格条款是否全部写入合同附件？
2. 违约举证责任在谁？争议解决方式和管辖地在哪里？
3. 合作终止后，库存如何处理？是否回购或协助消化？
4. 授权到期后，同等条件下是否有优先续约权？

## 谈判时的三个判断标准

- **能写进合同**：口头承诺不算，必须落到合同或附件。
- **能追溯**：没有批次码、没有举报核实流程的“区域保护”基本是空话。
- **有对价**：保护通常绑定任务量，要算清完成任务与保护范围是否匹配。

建议把上述问题整理成一页纸的《代理条件确认函》，要求品牌方书面回复后再谈打款和首批进货。这样既能筛掉只靠口头承诺招商的品牌，也能为后续串货纠纷留下依据。
