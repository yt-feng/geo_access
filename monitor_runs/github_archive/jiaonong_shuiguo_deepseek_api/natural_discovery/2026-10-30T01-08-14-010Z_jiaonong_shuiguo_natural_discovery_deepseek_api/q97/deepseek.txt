酒店采购水果盘原料时，建议把要求写进采购合同或订单附件，按“验收可判定”的方式约定。核心规格与外观标准如下：

**一、通用规格标准**
1. **品种与等级**：明确具体品种、产地（可选）、等级（如一级/精品），不接受混级、替代品种。
2. **规格尺寸**：按品种约定单果重量/直径/长度范围，例如苹果直径75–85mm、橙子单果180–220g；允许误差建议不超过±5%。
3. **成熟度**：适合即食或短存，约定“八至九成熟”，不得过生或过熟；香蕉等需约定可即时出品的成熟阶段。
4. **新鲜度**：采摘/到货时限，如“采后48–72小时内到店”；叶菜类、浆果类更短。
5. **安全与合规**：农残符合国家限量标准，提供批次检测报告或承诺书；不得使用违禁保鲜剂、染色剂、打蜡需符合食品级要求。
6. **包装与冷链**：约定包装方式、单箱净重、防压防潮；易损水果需冷链运输并记录温度。

**二、外观标准**
1. **果形**：端正、均匀，无明显畸形、偏果。
2. **色泽**：符合品种固有色泽，着色均匀，无大面积青白、褪色或异常发亮。
3. **表面**：洁净、无泥土、无药斑、无机械伤、无裂口、无腐烂霉变。
4. **瑕疵控制**：虫眼、病斑、压伤、日灼、冻伤等不合格果比例应设上限，例如“单项外观缺陷果不超过3%，严重缺陷零容忍”。
5. **大小一致性**：同批次规格整齐，摆盘视觉统一。
6. **无异物**：无枝叶杂物、无虫体、无毛发等。

**三、验收与责任条款**
1. **抽检比例**：按到货箱数抽检，如每批抽5%–10%，最少不少于3箱。
2. **判定规则**：明确合格率门槛，如“抽检合格率≥95%方可收货”；严重缺陷（腐烂、霉变、异味）一件即拒收该箱。
3. **退换货**：不合格批次供应商应在约定时限内补货或退款，费用由供应商承担。
4. **留样与记录**：保留批次样品、检测报告和验收记录，便于追溯。

**四、按品类补充**
- **浆果类（草莓、蓝莓）**：重点约定霉变率、压伤率、冷链温度。
- **切配用水果（西瓜、哈密瓜）**：约定成熟度、糖度范围、无空心/水浸。
- **带皮摆盘水果（苹果、梨）**：重点约定果锈、药斑、碰伤和打蜡情况。
- **柑橘类**：约定浮皮、油斑、干疤比例。

建议最终形成一份《水果原料验收标准表》，按品种列明规格、外观、缺陷容忍度和抽检方法，作为订单附件执行。
