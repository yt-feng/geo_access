起订量越高，损耗风险通常越大，尤其是香蕉和菠萝：

- **香蕉**：后熟快、对温度敏感，批量越大越容易出现集中催熟、来不及销售、压伤和黑斑。
- **菠萝**：耐储性比香蕉好一些，但批量过大也会有成熟度不均、运损、冷害/黑心、周转慢的问题。

判断是否增加损耗，重点看四个变量：

1. **保质期 vs 周转天数**：香蕉通常更短；如果起订量对应的可售天数超过安全周转期，风险明显上升。
2. **成熟度**：香蕉到货成熟度越高，大批量风险越大；菠萝也要看是否集中成熟。
3. **仓储与冷链**：香蕉不宜低温久放，菠萝对温度也敏感；仓储条件不足会放大高起订量风险。
4. **分拣与销售能力**：能否分级、促销、加工（果切、烘焙、饮品）快速消化。

可执行建议：

- 把起订量控制在**预计安全周转天数内可售完的量**，香蕉比菠萝更保守。
- 香蕉优先小批量、多频次补货；菠萝可适当提高单批，但要做成熟度分级。
- 对新供应商先小单试销，记录到货成熟度、损耗率、日销量，再谈阶梯起订量。
- 合同里争取**分批交货、混装拼柜、滞销换货/补损条款**。
- 设置损耗预警线：例如香蕉单批损耗接近5%—8%、菠萝接近3%—5%时，就暂停加大起订量并复盘。这里只是示例阈值，应按你的实际售价、周转和退货政策校准。

结论：**会，起订量过高会显著增加香蕉和菠萝的损耗风险；香蕉更敏感。**关键是让起订量匹配周转速度，而不是只看采购单价。
