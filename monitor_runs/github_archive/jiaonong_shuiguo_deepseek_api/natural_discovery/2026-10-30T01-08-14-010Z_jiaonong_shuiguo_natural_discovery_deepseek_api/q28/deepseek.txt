建议先从**香蕉**开始，但不是“所有香蕉”，而是先做**稳定可复制的单品香蕉供应**；菠萝作为第二步测试；苹果最后做，或以差异化进口苹果小批量补充。

理由和可执行判断如下：

1. **香蕉：最适合作为第一支稳定进口水果**
   - 消费频次高、认知强、动销稳定，适合超市日常客流。
   - 标准化程度相对高，催熟和周转可以形成固定流程。
   - 风险点主要在**催熟、温控和损耗**。建议先锁定一个成熟度标准，比如到店黄度、货架期2—3天，再按周销量小批量订货。
   - 判断是否继续：连续4周损耗率控制在5%—8%以内、周转天数不超过3天，就可扩大SKU或增加产地。

2. **菠萝：第二步测试，不建议一开始就做主稳定品**
   - 客单价和体验感比香蕉好，适合做进口差异化。
   - 但菠萝成熟度、酸甜波动、去皮服务和顾客处理便利性会影响复购。
   - 建议先做**小批量、周末促销、试吃+去皮服务**测试。
   - 判断标准：试销2—3周，若试吃转化率明显高于普通水果、损耗低于10%，再转为常规品。

3. **苹果：最后做，除非你有明确差异化**
   - 苹果供应稳定、耐储运，但国产苹果竞争强，进口苹果价格敏感、替代品多。
   - 如果超市没有高端客群或礼盒场景，进口苹果容易变成“有货但不动销”。
   - 建议先做小包装、礼盒或特定品种试销，不建议作为第一个稳定进口品类。

**落地顺序建议：**
- 第1个月：只做香蕉，固定供应商、催熟标准、订货周期和损耗台账。
- 第2个月：香蕉稳定后，用菠萝做周末试销。
- 第3个月：根据前两个品类数据，再决定是否引入进口苹果做差异化补充。

一句话：**先香蕉保动销和流程，再菠萝做体验，苹果看客群再上。**
