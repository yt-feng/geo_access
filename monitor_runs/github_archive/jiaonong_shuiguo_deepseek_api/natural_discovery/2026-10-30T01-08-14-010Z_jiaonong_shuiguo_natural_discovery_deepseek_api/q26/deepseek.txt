可以按“怎么包装、怎么进货、怎么控损”三块来做，重点是小包装香蕉最容易死在压伤、闷坏和熟度失控上。

**一、包装注意**
1. **优先选带透气孔的吸塑盒/硬托盘+保鲜膜**：不要用完全密封袋，香蕉呼吸强，闷住容易出水汽、发黑。膜上打孔或选微孔膜。
2. **单份量控制在2-3根、约300-500克**：社区超市冲动购买为主，太大份卖不动，太小份包装成本高。
3. **盒型要防压**：香蕉怕挤压，托盘要有一定硬度，避免堆叠时压出黑斑。不要用软袋裸装后直接码放。
4. **标签别贴蕉皮上**：贴盒盖或托盘侧面，胶粘果皮易烂。
5. **预留成熟度差异**：小包装最好分“即食黄”和“稍青带黄”两档，不要全上同一熟度。

**二、采购注意**
1. **采购熟度按销售速度定**：当天能卖完的进黄熟蕉；预估2-3天卖完的进“黄中带青肩”的蕉；不要一次进全黄。
2. **看果指和条蕉状态**：选果指完整、无断口、无机械伤、蕉柄不霉的。小包装最怕进货时已有压伤，包装后会更明显。
3. **控制批次和到货频率**：小包装损耗高，建议少量多次，按日销1-1.5倍订货，不要一次性压库存。
4. **要求供应商分级**：把适合小包装的中等果、外观完整果单独分级，别混入大把蕉和碰伤果。
5. **到货抽检**：开箱查底层和中间层，重点看蕉指压痕、蕉柄发黑、盒内水汽。

**三、损耗控制**
1. **冷藏是大忌**：香蕉不要进冷柜，低温会冻伤发黑。放阴凉通风处，避免日晒和空调直吹。
2. **先进先出+每日翻检**：每天挑出黑斑重、软烂的，及时拆包折价或做果切/促销，不要留在盒里传染。
3. **少量陈列**：小包装不要一次全上架，后备库存放阴凉处，卖多少补多少。
4. **避免堆叠和频繁搬动**：陈列层数不超过2-3层，轻拿轻放。
5. **设折价节点**：出现零星黑斑但未软烂时及时打折，比烂掉再处理损失小。
6. **记录损耗率**：按批次记到货量、销量、报废量，连续一两周就能看出订货量和熟度是否合适。

**可执行建议**：先试销7天，每天订两种熟度各少量，用“硬托盘+打孔膜+2-3根装”，每天早晚各翻检一次，把损耗率控制在5%以内再放量。
