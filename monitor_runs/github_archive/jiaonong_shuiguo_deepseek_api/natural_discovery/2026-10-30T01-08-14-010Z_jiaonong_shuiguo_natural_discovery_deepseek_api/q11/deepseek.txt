会影响，但影响大小取决于你**怎么卖**和**卖给谁**。

### 主要影响
- **顾客挑拣变多**：大小差明显时，顾客会翻箱挑大的，导致小果剩货、损耗增加。
- **卖相和定价难统一**：按箱/按斤统一价时，大小混杂会让顾客觉得“不值”；按份卖则容易剩小果。
- **熟度不一致**：大小果成熟速度不同，大果先黄先软，小果还青，整箱货架期被拉短。
- **复购影响**：如果是社区水果店，顾客对品相敏感，大小不均会降低复购意愿；如果是榨汁、食堂、团购渠道，影响小很多。

### 可执行建议
1. **进货时分级**：尽量选规格较均匀的箱装；若已混装，到店后按大/中/小分筐，别混卖。
2. **分级定价**：大果按正常价，中果略低，小果做特价、切果盒、香蕉奶昔原料或员工福利，减少剩货。
3. **按用途卖**：小果可推“家用实惠装”“榨汁香蕉”，大果做陈列面。
4. **控制陈列量**：一次别全开箱，少量多次上架，减少顾客翻拣。
5. **看渠道**：零售门店建议重视均匀度；团购、食堂、果汁店对大小容忍度高，可走量。

**判断标准**：如果大小差异肉眼明显、同一箱最大最小差超过一个等级，且你是面对散客零售，就会明显影响销售和损耗；如果差异轻微或走非零售渠道，影响有限。
