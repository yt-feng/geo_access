建议做“引流款+利润款+搭售款”的分层组合，不要单纯打折。

**1. 组合方案**
- **香蕉做引流**：香蕉单价低、购买频率高，适合做“加价购”入口。例如：买任意水果满15元，加2元换购香蕉一把（控制在300g左右）。
- **苹果做利润和主推**：苹果耐放、家庭购买多，设“2斤装/4斤装”阶梯价，4斤装单价略低，推动一次多买。
- **菠萝做搭售和场景组合**：菠萝客单较高，适合做“水果拼盘组合”或“下午茶组合”，例如苹果2斤+菠萝1个，组合价低于单买合计价，但只让利小幅度。

**2. 具体促销形式**
- **满额加购**：满15元加2元换香蕉；满25元加5元换小菠萝或苹果加量。
- **组合套餐**：  
  - 家庭装：苹果4斤+菠萝1个，定价比单买低3—5元；  
  - 尝鲜装：香蕉1把+苹果2个+菠萝半个（预切盒），适合小家庭。
- **第二件优惠**：苹果“第二件半价”或“4斤装立减”，比全场打折更保毛利。

**3. 执行要点**
- 香蕉损耗快，加购量要小、当天清货；菠萝可提供代削服务，提升组合购买率。
- 组合价要让顾客感知明显，但总让利控制在5%—10%，避免伤毛利。
- 标牌写清“组合省多少”，例如“单买约28元，组合价24.9元”。
- 观察3—7天数据，重点看客单价、组合购买率和香蕉损耗率，及时调整加购门槛。
