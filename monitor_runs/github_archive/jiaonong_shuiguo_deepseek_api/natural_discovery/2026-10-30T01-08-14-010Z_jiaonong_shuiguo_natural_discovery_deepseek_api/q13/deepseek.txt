# 水果供应商需要支持的服务

做小区团购，供应商能不能配合，基本决定了你的团购能做多大、亏不亏钱。按重要性排序，重点确认这几项：

**1. 按团购节奏供货（最关键）**
- 能按“今天下单、明早到货”的隔日模式备货，而不是让你提前囤货。
- 支持小批量、多批次，比如一车 30 箱也发，而不是“满 50 箱起”。
- 能接受临时加单或减单。团长群里最后下单往往集中在晚上，需要供应商当晚或次日清晨接单。

**2. 分级分拣与按份预包装**
- 按你的团购规格分拣：比如 3 斤装、5 斤装，直接装袋贴标，你到手就能发货。
- 愿意做次果挑除，避免“整箱里有烂果”引发的售后和群内口碑崩塌。
- 包装能适配小区自提：纸箱或网袋，便于堆放、清点、扫码。

**3. 稳定的品质与损耗兜底**
- 明确损耗率承诺和赔付规则：坏果怎么算、多少比例内免赔、超出怎么补货或退款。
- 有固定的到货时间窗口，方便你安排自提点人手。
- 换季或爆款缺货时，能提前告知并提供替代品，而不是当天放你鸽子。

**4. 价格与账期**
- 给团购专供价，而不是零售批发价；能按周或按次结算，最好支持“先货后款”或短账期。
- 价格随行情波动时提前打招呼，避免你按旧价开团后成本上涨。

**5. 配送与售后对接**
- 直接送到自提点或你的门店，运费谁承担要写清楚。
- 有专人对接售后：坏果拍照即赔、补发或抵扣下次货款，响应要快。
- 能提供简单的质检或产地信息，方便你在群里做信任背书。

**6. 试团与备选**
- 先小批量试 1–2 次，看准时率、损耗率、售后响应再放量。
- 至少备一个第二供应商，防止单一货源断供导致团购停摆。

**给你的落地建议：** 把上面几条写成一张“供应商合作确认单”，逐项让供应商签字或微信确认，尤其是**起送量、损耗赔付比例、到货时间、账期**这四项。这四项谈清楚，后面 80% 的扯皮都能避免。
