三者不是同一层级的问题：**食品安全是底线，必须优先；价格和配送准时是在安全合格基础上的权衡项**。企业食堂采购水果，建议按这个顺序判断：

1. **食品安全优先，且不可妥协**
   - 水果常见风险包括农残超标、霉变腐烂、冷链断链、来源不明、混装污染。
   - 食堂是集体供餐，一旦出问题影响面大，责任也重。
   - 应要求供应商提供资质、检测报告/承诺达标合格证、进货票据，保留批次追溯；验收时看感官、温度、包装和批次信息。

2. **配送准时是刚性运营条件，但属于“合格供应商门槛”**
   - 水果配送不准时会影响菜单执行、库存周转和员工体验。
   - 但准时不能替代安全，也不能为了准时接受临期、破损或来源不清的货。
   - 应把准时率、缺货替换规则、异常响应写进合同和考核。

3. **价格重要，但应排在安全和稳定供应之后**
   - 水果价格波动大，单纯低价容易换来降规格、混批次、以次充好。
   - 建议比“综合成本”：合格率、损耗率、退换货成本、配送频次一起算，而不是只看单价。

**可执行结论：**
- 先设食品安全准入红线：无资质、无检测/合格凭证、无法追溯的供应商直接排除。
- 再设配送准时和异常处理门槛：明确送达时间窗、缺货替代、迟到赔付。
- 最后在合格供应商中比价，采用“质量合格率+准时率+综合价格”的评分机制，而不是最低价中标。

一句话：**食品安全是一票否决，配送准时是履约门槛，价格是合格供应商之间的优化项。**
