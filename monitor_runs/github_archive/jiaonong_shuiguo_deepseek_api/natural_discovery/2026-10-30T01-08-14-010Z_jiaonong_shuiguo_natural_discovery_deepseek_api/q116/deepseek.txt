小商家采购水果，现金结算和月结账期各有风险，核心区别在于：**现金结算把风险放在“钱货当场两清后的质量与短斤少两”，月结把风险放在“赊账回收和关系依赖”**。可以按下面判断。

**一、现金结算的风险**
1. **质量出问题后难追责**：当场付钱，事后发现烂果、规格不符、以次充好，议价和退换空间小。
2. **短斤少两、压秤**：水果批次多、称重频繁，现金交易若没有票据和复称记录，事后很难核对。
3. **采购员道德风险**：现金经手人容易出现虚报价格、吃回扣、私拿差额，老板难留痕。
4. **资金占用即时**：每天或每批都要备现金，旺季现金流压力大，也增加保管和被盗风险。
5. **价格未必更优**：现金看似能压价，但若没有比价和书面约定，可能被“高价现金价”反向利用。

**二、月结账期的风险**
1. **坏账和拖欠风险**：水果损耗高、利润薄，一旦对方延迟结账或跑路，小商家抗风险能力弱。
2. **供应商加价或降质**：账期本质是融资，供应商可能把资金成本加到单价里，或在后期用次果维持利润。
3. **关系绑定与断供风险**：长期月结容易形成单一供应商依赖，对方涨价、断供时切换成本高。
4. **对账纠纷**：水果退货、损耗、补货频繁，若没有每笔签收和退货单，月底容易扯皮。
5. **现金流误判**：账面上有货、有利润，但钱没回来，容易继续进货导致资金链紧张。

**三、可执行建议**
- **现金采购**：坚持当场复称、拍照留样、写明规格和退换规则；单笔超过一定金额必须给收据；采购员与付款人分离。
- **月结采购**：设信用额度、账期上限和逾期停供线；每笔送货单双方签字，退货当日冲账；月结单价与现金价做对比，把账期成本算进毛利；不要只依赖一家供应商。
- **混合策略**：高频易损耗品部分现金采购换低价和灵活退换，主供应商给短账期但要求价格透明；关键看**综合成本=单价+损耗+资金占用+坏账概率**，而不是只看单价。

简单判断：**如果供应商可靠、对账规范、你现金流能承受，短账期可换稳定供应；如果品控不稳定、称重频繁、没有留痕能力，现金结算反而容易吃暗亏。**
