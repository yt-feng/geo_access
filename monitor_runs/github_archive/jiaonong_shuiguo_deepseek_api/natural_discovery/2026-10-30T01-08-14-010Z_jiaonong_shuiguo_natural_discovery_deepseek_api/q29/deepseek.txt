超市和水果供应商的账期没有全国统一标准，常见区间可以这样判断：

- **现款现结/周结**：多见于叶菜、草莓、荔枝等易损耗、短保水果，或小型超市、临时补货。
- **7～15天**：社区超市、生鲜店、区域小连锁较常见，适合周转快、损耗高的品类。
- **30天**：商超行业较常见的月结账期，尤其常规水果、长期稳定供应商。
- **45～60天**：部分中型连锁超市、区域商超会采用，通常伴随较高采购量或较强议价能力。
- **90天及以上**：多见于大型连锁商超、平台型渠道，但对供应商资金压力大，通常需要合同明确、规模采购或供应链金融配套。

实务上建议：

1. **按品类分账期**：易腐水果短账期，耐储水果可适当延长。
2. **新供应商先短后长**：先7～15天或货到付款，稳定合作后再谈30天。
3. **合同写清起算日**：是收货日、对账日还是开票日，避免“30天”变60天。
4. **关注隐性账期**：对账周期、开票周期、付款审批日都会拉长实际回款时间。
5. **大型商超90天以上要谨慎**：算清资金占用成本，必要时要求缩短账期、分批付款或供应链金融。

如果是你方作为供应商去谈，**30天月结是较常见且相对可接受的基准**；如果对方是强势大型连锁，45～60天也常见，但应尽量争取缩短或设置逾期付款条款。
