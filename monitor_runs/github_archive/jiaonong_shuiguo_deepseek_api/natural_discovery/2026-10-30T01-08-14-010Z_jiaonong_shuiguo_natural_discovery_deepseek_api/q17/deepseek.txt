# 社区超市水果：控制新鲜度和库存的实操办法

社区超市水果的核心矛盾是：**客流小、周转慢、损耗高**。所以思路不是“多进多卖”，而是“少进快转、动态调整”。

## 一、选品：先砍品类，再谈管理

- **只留高频刚需**：苹果、香蕉、橘子/橙、梨、应季瓜果、当季爆款（如夏天西瓜、冬天砂糖橘）。品类控制在 15–25 个 SKU，越少越好管。
- **砍掉“好看不好卖”的**：进口高价果、需要特殊存放的（如蓝莓、车厘子）少量试销，卖不动立即停。
- **按“周转天数”分级**：香蕉、草莓、叶菜类 1–2 天；苹果、橙、梨 3–5 天；瓜类 3–7 天。不同级别用不同的补货节奏。

## 二、订货：用“销量倒推”而不是拍脑袋

- **按天订货、按周复盘**：每天记录每个单品销量，订货量 ≈ 近 3–7 天日均销量 ×（1 + 安全系数）。安全系数按品类给：易损耗的 0.8–1.0（宁少勿多），耐放的 1.1–1.3。
- **小批量、多频次**：和批发商谈“少量多次”，比如香蕉两天一补、苹果一周两补。哪怕单价略高，也比烂在店里划算。
- **设“止损线”**：某单品连续 3 天销量低于预期，立即减半订货或停进。

## 三、陈列与保鲜：让货“看起来新鲜、实际也新鲜”

- **先进先出**：新货放后面/下面，旧货放前面，每天开店前翻一遍。
- **少量勤补**：陈列面不要堆满，堆满=压货。卖一层补一层，既显新鲜又减少挤压。
- **分区存放**：香蕉、芒果等怕冷的不进冷柜；叶菜、草莓冷藏并加湿；苹果会催熟其他水果，尽量单独放。
- **及时处理“临界货”**：当天卖相下降的，做“特价筐”“切果盒”“搭配促销”，不要等到烂了才扔。损耗要当天记录，才能算清真实成本。

## 四、库存与损耗管理：把数据做起来

- **每日盘点关键单品**：不用全盘，盘易损耗和高价值的那几个，记录“进货量、销量、损耗量、结存量”。
- **算清两个数**：**周转天数 = 平均库存 / 日均销量**，超过品类上限就预警；**损耗率 = 损耗量 / 进货量**，超过 5%–8% 就要查原因（订货多、陈列差、还是定价高）。
- **建立“临期处理”机制**：设定每天固定时间（如下午 5 点）检查，卖相/新鲜度到临界就降价或做组合促销，回笼现金比烂掉强。

## 五、用促销和定价调节周转

- **组合销售**：易损耗的搭配耐放的卖（如“苹果+香蕉”套餐），加快慢动销品出清。
- **时段定价**：傍晚对当日易损耗品打折，形成固定习惯，顾客会来“捡漏”，也减少隔夜损耗。
- **会员/预订**：社区店可做微信群预订、次日自提，按订单进货，几乎零库存风险。

## 六、一句话原则

**“宁可少卖一点，也不要压货烂掉。”** 社区超市水果的利润来自周转，不来自单次进货量。把品类砍窄、订货按销量倒推、陈列少量勤补、临界货当天处理，库存自然压不下来。
