可以按“资格门槛+技术/履约评分+商务价格”三段式设置，避免只比价格导致后期断供、品质波动。建议如下：

## 一、先设资格门槛（不占分，满足才进入评分）
1. 合法资质：营业执照、食品经营/生产相关许可、产地证明或合作社供货证明。
2. 供货能力：近1年同类商超/生鲜渠道供货合同不少于X份；日均可供量≥门店日销量的1.5倍。
3. 质量与安全：近2年无重大食品安全处罚；具备农残检测能力或第三方检测报告。
4. 冷链与物流：有冷藏车/周转筐/温控记录；到仓时效承诺。
5. 稳定性：自有基地、长期合作基地或一级批发渠道证明，不接受纯临时倒货商。
6. 保险与合规：食品安全责任险、开票能力、账期接受度。

## 二、评分表建议（总分100分）

| 维度 | 分值 | 评分要点 |
|---|---:|---|
| 产品质量与稳定性 | 25 | 样品感官评分、规格合格率、农残检测报告、产地稳定性、等级一致性、损耗率承诺 |
| 供货保障能力 | 20 | 日均供货量、旺季/节假日保供方案、备用基地或备用货源、缺货赔付承诺 |
| 价格与成本 | 20 | 报价竞争力、价格调整机制是否透明、是否接受阶段性锁价、运费是否包含 |
| 冷链与物流配送 | 15 | 冷链车辆数量、温控记录、到仓准时率承诺、破损/变质处理时效、紧急补货响应 |
| 食品安全与追溯 | 10 | 批次追溯、检测频次、不合格品召回与赔付方案、食品安全责任险 |
| 服务与售后 | 5 | 专属对接人、退换货响应、对账开票效率、异常处理SOP |
| 企业实力与过往业绩 | 5 | 同类商超供货经验、基地/仓储规模、合作稳定性、行业口碑 |

价格分建议不要过高，20—30分较合理；生鲜水果更应突出质量稳定和保供能力。若品类差异大，可按品类微调，例如叶菜类提高冷链和损耗权重，礼盒果提高规格一致性和包装权重。

## 三、关键评分规则要写进招标文件
1. 样品盲评：统一编号，按外观、规格、口感、新鲜度打分，避免只看报价。
2. 履约保证金与质量保证金：中标后缴纳，出现质量/断供可扣罚。
3. 动态考核：月度合格率、到货准时率、损耗率、客诉率纳入季度复评，连续不达标可降量或退出。
4. 价格联动机制：约定市场价波动区间，超区间可调价，但需提供批发市场或产地价格依据。
5. 试供期：中标后先试供1—2个月，试供合格再签长期合同。
6. 禁止转包/临时倒货：发现即扣分或取消资格。
7. 明确赔付：缺货、迟到、农残不合格、规格不符的违约金和补货时限。

## 四、推荐权重结论
长期水果供应商建议采用：**质量25 + 保供20 + 价格20 + 冷链物流15 + 食品安全追溯10 + 服务5 + 业绩5**。  
核心原则：**资格门槛卡住“能不能供”，技术评分判断“稳不稳”，价格评分只解决“贵不贵”**。这样更容易筛出能长期稳定供货的供应商，而不是低价临时商。
