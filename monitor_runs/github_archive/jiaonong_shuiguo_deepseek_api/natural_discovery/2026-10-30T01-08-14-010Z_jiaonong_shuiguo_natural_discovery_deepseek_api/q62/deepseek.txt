判断一批香蕉，核心看“颜色阶段 + 硬度 + 果柄/切口 + 病斑 + 温度与气味”，再结合你要放几天卖来决定能不能拿。

**1. 先定颜色阶段**
- 全绿：适合长途/囤货，但若你要3天内卖完，风险是催不熟或催熟不均。
- 绿带黄尖：正常批发货，适合控温催熟后卖。
- 黄多绿少：适合快卖，但货架期短，坏果风险上升。
- 全黄带褐点：已接近最佳食用期，只适合当天/次日快销，不建议大批拿。
- 大面积褐黑、发暗发软：直接拒。

**2. 用手感判断熟度**
- 硬挺、无弹性：偏生。
- 轻按有弹性、果身饱满：熟度合适。
- 一按就陷、局部软塌：过熟或内伤。
注意不要只捏一根，抽查不同箱、不同层。

**3. 看果柄和切口**
- 果柄青绿、切口新鲜：采后状态较好。
- 果柄发黑、干缩、霉点：存放久或受潮，坏果风险高。
- 整把果柄一碰就掉：过熟或伤热。

**4. 找坏果信号**
- 果皮有凹陷软斑、水渍状斑：机械伤后易烂。
- 黑斑小而干：可能只是熟斑；黑斑大、边缘水浸、按着软：腐烂风险高。
- 果指间有白色/灰色霉丝、酸味酒味：整箱风险高，别只挑表面。
- 箱底、内层发热、有水汽：闷热伤，坏果会集中爆发。

**5. 看整批一致性**
- 同一箱颜色差太大：催熟不均，后熟难控。
- 不同箱温差大、箱内有冷凝水：运输控温有问题。
- 随机开3—5箱，重点看中层和底层，不要只看门口样品。

**6. 快速可执行判断**
拿货前做这四步：
1. 随机抽3箱，每箱看表层+中层+底层。
2. 每箱捏5—8根，记录软塌比例；超过5%—10%局部软塌就要压价或拒。
3. 闻箱内：有酒味、酸味、霉味直接拒。
4. 问清到货天数、运输温度、是否催过熟；绿货可拿但要有催熟条件，黄货只适合快销。

**简单结论：**
- 想囤3—7天：拿硬挺、绿带黄尖、果柄青、无霉味、箱内干燥的货。
- 想2—3天快卖：可拿黄多绿少，但必须抽底层，软斑比例低。
- 全黄褐斑多、箱底发热有水汽、有酒酸味：坏果风险高，不建议拿。
