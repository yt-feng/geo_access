选食堂水果供应商，不能只看“谁报价低”，要按“食品安全资质 → 稳定供货能力 → 价格与结算 → 售后与应急”四关筛选。下面给你一套可直接执行的方案。

## 一、先定采购标准

1. **品种与规格**
   - 香蕉：按根/斤明确长度、成熟度，建议七成熟到校、两天内可售完。
   - 苹果：明确品种（如红富士）、单果规格（如75#/80#）、糖度底线。
   - 橙子：明确品种（如脐橙、冰糖橙）、果径、可食率。
   - 统一写进采购单：品种、规格、等级、成熟度、允许损耗率、农残要求。

2. **食品安全底线**
   - 供应商必须有营业执照、食品经营许可证（或食用农产品销售所需资质）。
   - 能提供每批次农残检测报告或承诺抽检；能追溯产地。
   - 配送人员健康证、运输车辆清洁证明。
   - 学校食堂采购食用农产品应索取并留存进货凭证、合格证明，具体以当地市场监管和教育局要求为准。

3. **价格与结算**
   - 不要只比单价，要比“到校含税含运费价”。
   - 约定价格调整机制：如每周/每半月按当地批发市场均价浮动，避免随意涨价。
   - 结算周期、发票类型、违约金写进合同。

## 二、供应商筛选流程

**第1步：列候选**
- 本地农产品批发市场有固定档口的商户；
- 本地水果种植合作社/家庭农场；
- 有学校、机关食堂配送经验的生鲜配送公司；
- 大型商超或供应链平台（适合小批量、补货）。

**第2步：资质初审**
要求提供：营业执照、食品经营许可证/相关许可、法人身份证、检测报告样例、配送车辆和人员资料、近一年供货案例。缺关键资质的直接淘汰。

**第3步：现场考察**
重点看：仓储是否分区分架、是否有冷藏条件、是否防鼠防虫、香蕉苹果橙子是否混放挤压、进货台账是否完整、退货区是否独立。

**第4步：样品试供**
先给1—2周小批量试供，按以下指标打分：
- 到货合格率；
- 规格符合率；
- 损耗率；
- 迟到次数；
- 临时补货响应时间；
- 退换货是否爽快。

**第5步：比价与定标**
建议至少3家比价，综合评分而不是最低价中标。可设：质量40%、价格30%、供货能力20%、服务10%。

## 三、合同里必须写清的条款

- 品名、规格、单价、数量、送达时间和地点；
- 质量标准：农残合格、无腐烂、无严重磕碰、成熟度范围；
- 验收方式：到货抽检比例、不合格整批退回还是部分退回；
- 损耗与短斤少两处理：复称、扣款、补货；
- 价格调整：触发条件、提前通知天数；
- 食品安全责任：若因水果引发食品安全问题，供应商承担检测、医疗、处罚等责任；
- 应急供货：学校临时加量或节假日前备货，供应商响应时限；
- 违约与退出：连续几次不合格即终止合作。

## 四、日常管理动作

1. **每批验收**：看外观、闻气味、抽称重量、查成熟度，留照片和记录。
2. **留样与台账**：进货票据、检测报告、验收记录归档，至少按当地要求保存。
3. **月度评分**：合格率、投诉次数、配送准时率，末位约谈或淘汰。
4. **保持2家以上备选**：主供应商+应急供应商，防止单一供应商断供或涨价。
5. **香蕉单独管理**：香蕉易催熟、易压伤，要求供应商控制成熟度，食堂少量多次下单。

## 五、简单可用的选择结论

- **首选**：有学校食堂配送经验、资质齐全、能提供检测报告、有冷藏/分拣能力、响应快的本地配送商。
- **次选**：本地合作社直供，价格可能更好，但要确认其能否稳定供货、能否开票、能否承担退换货。
- **不建议**：只有口头承诺、无固定场所、无法提供票据和检测证明的流动摊贩；以及单纯报价最低但规格和成熟度不稳定的供应商。

一句话：**先卡资质和安全，再试供看稳定性，最后用合同锁价格和责任；至少保留两家供应商。**
