评估连锁门店跨城市的水果供应商仓配覆盖，建议按“先定要求、再算覆盖、再压测、最后算账”的顺序做。水果损耗高、时效敏感，不能只看供应商有没有仓库，而要看“从产地/加工仓到门店”的完整链路能否稳定满足门店经营。

## 1. 先明确门店侧的仓配要求

按城市、商圈、门店类型分别列出：

- **配送频次**：每日1配、隔日配，还是每周几配；不同品类是否不同。
- **到店时段**：要求在营业前几点到店，是否接受夜间收货。
- **最小起订量与拆零**：单店单SKU最小起订量、是否支持按箱/按份拆零。
- **温区要求**：常温、冷藏、冷冻是否分车或分区；水果通常重点看冷藏和防挤压。
- **验收标准**：到货温度、成熟度、破损率、缺货替代规则。
- **峰值能力**：节假日、促销日、新店开业时的加量能力。

这一步的输出应是一张“城市—门店—品类—时效—温区—起订量”的需求表，作为后续评估基准。

## 2. 评估供应商仓配覆盖的四个层级

不要只问“覆盖哪些城市”，要拆成四级：

### 2.1 仓网覆盖

- 供应商在哪些城市有**DC/加工仓/前置仓**，是自营还是合作仓。
- 每个仓的**服务半径**和实际配送城市清单。
- 仓到门店是**直配**，还是“区域仓—城市仓—门店”多级转。
- 跨城配送时，是否经过中转、中转几次、中转仓是否具备冷藏能力。

判断标准：门店是否在供应商**实际稳定配送范围**内，而不是宣传覆盖范围内。

### 2.2 线路与时效覆盖

- 每个城市到门店的**标准在途时间**、发车时间、到店时间窗口。
- 是否支持**当日达/次日达/定时达**，水果品类实际达成率。
- 跨城线路是否固定班次，是否有备用线路。
- 极端天气、交通管制、节假日期间的时效预案。

建议要求供应商提供近3—6个月**按城市、按线路的准点率**，而不是只给整体平均值。

### 2.3 温控与品质保障覆盖

- 冷藏车/保温箱/冰袋配置比例，跨城长途是否有全程温控记录。
- 装卸环节是否控温，门店是否具备暂存条件。
- 不同水果的成熟度管理：采摘/加工后多久发运，到店剩余货架期。
- 破损、压伤、腐坏的赔付和责任划分。

水果仓配的核心不是“送到”，而是“送到时还能卖”。要重点看**到店合格率、损耗率、货架期**。

### 2.4 订单与异常处理覆盖

- 下单截止时间、变更订单的截止时间。
- 缺货、短装、品质不合格时的补货时效。
- 门店拒收后的逆向物流怎么处理。
- 是否有城市级客服/运营对接人，异常响应时限是多少。

## 3. 用可量化指标做覆盖评估

建议每个城市/线路建一张评分表，至少包括：

| 维度 | 指标 | 建议关注点 |
|---|---|---|
| 仓网 | 实际服务门店数、仓到店距离 | 是否稳定服务同类型门店 |
| 时效 | 准点率、平均在途时长、到店窗口达成率 | 按线路看，不只看整体 |
| 温控 | 全程温控覆盖率、到店温度合格率 | 跨城长途重点看 |
| 品质 | 到店合格率、损耗率、货架期达成 | 按品类看 |
| 弹性 | 加量响应时间、峰值履约率 | 节假日/促销 |
| 异常 | 缺货补货时长、拒收处理时长 | 是否有城市级响应 |
| 成本 | 配送费、起订量、拆零费、退换货成本 | 算到单店单品类 |

覆盖判断可以采用“**硬门槛+评分**”：

- 硬门槛：到店时段、温区、最小起订量、城市是否实际可配。
- 评分项：准点率、损耗率、峰值能力、异常响应、综合成本。

## 4. 做实际压测，而不是只看资料

对候选供应商建议做三轮验证：

1. **资料核验**：仓网清单、车辆/温控配置、近几个月线路准点率和损耗数据。
2. **小范围试配**：选2—3个代表性城市、不同距离门店，试配2—4周，记录准点、破损、缺货、温度、门店验收反馈。
3. **峰值压测**：在周末或促销日测试加量20%—50%时的履约表现，观察是否出现降频、延迟、品质下滑。

试配时特别要区分：

- 同城近距离门店；
- 跨城但同一区域仓覆盖的门店；
- 偏远城市或低销量门店。

很多供应商在核心城市表现好，但低密度城市会通过拼车、中转导致时效和品质下降。

## 5. 算清单店仓配经济性

覆盖不能只看能不能送，还要看单店是否划算：

- 单店单次配送成本；
- 起订量导致的库存和损耗；
- 拆零费、退换货费、冷链附加费；
- 因延迟/损耗造成的门店缺货损失；
- 多供应商拼单后的综合成本。

对低销量城市，可比较三种模式：供应商直配、区域仓中转、当地合作仓/第三方共配。不要为了统一供应商而让偏远门店承担过高履约成本。

## 6. 建议的决策输出

最终形成一张“城市—门店群—供应商”覆盖矩阵：

- **可直配且达标**：纳入主供应商；
- **可配但时效/温控有短板**：设置补充供应商或限制品类；
- **仅能中转覆盖**：评估损耗和货架期，谨慎分配叶菜、浆果等易损品；
- **无法稳定覆盖**：当地寻源或第三方共配。

总结一句话：水果供应商的仓配覆盖，要按“**仓到店的实际线路+时效+温控+品质+峰值+单店成本**”六项评估，并用小范围试配数据验证；只看仓库城市清单和整体覆盖率，容易误判。
