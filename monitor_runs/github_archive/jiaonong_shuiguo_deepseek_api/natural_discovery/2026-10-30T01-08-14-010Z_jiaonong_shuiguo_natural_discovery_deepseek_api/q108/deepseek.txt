# 核实水果供应商"全国配送"实际覆盖能力的方法

## 一、先拆穿"全国配送"的模糊表述

"全国配送"通常指以下多种不同情况，核实前要先让供应商说清楚是哪一种：

- **自营冷链直发**：自己有干线+城配能力
- **区域仓+第三方落地配**：只覆盖部分城市，其余转包
- **快递发货**：走顺丰/京东等，本质是"能寄到"但不保证时效和温控
- **只覆盖省会/地级市**：县乡不送或加价

**第一步：要求书面明确《配送覆盖范围表》** —— 列出省、市、区县级别，标注哪些是直送、哪些是转第三方、哪些不送、偏远地区加价标准。口头承诺不算数。

## 二、可执行的核实动作（按成本从低到高）

1. **抽样下单测试（最有效）**
   - 选3～5个目标城市，其中至少1个偏远地区（如新疆、西藏、县域），用真实地址下小批量试单。
   - 记录：实际到货时效、是否冷链、包装温控、是否被转给其他物流、破损率、签收环节是否本人/自提点。
   - 水果品类尤其要看**夏季高温和冬季低温两次试单**，温控问题往往只在极端天气暴露。

2. **要物流单据和运单号溯源**
   - 让供应商提供近期发往目标城市的**真实运单号**，自己查物流轨迹：起点是不是他们的仓、中转几次、末端是谁派送。
   - 轨迹显示"从产地直接到目的地"和"经多次中转转包"是两回事。

3. **查资质与实体**
   - 营业执照、食品经营许可证（水果属食用农产品，但分拣包装涉及食品流通）。
   - 要求提供**冷库/分拣中心照片或视频**，最好实地或视频验仓。
   - 问清冷链车辆是自有还是外包，外包要给合作方名称。

4. **问关键指标，逼对方给数字**
   - 目标城市**日均发货量**、**准时到达率**、**破损/腐损率**、**异常件处理时效**。
   - 只有笼统"都能送"却给不出任何数字的，基本是转包或快递发货。

5. **查第三方物流合作**
   - 若走落地配，问合作方是谁（如某区域冷链公司），可侧面核实该物流是否真覆盖该区域。

6. **同行/客户背调**
   - 要2～3个**同区域、同品类**的老客户联系方式（征得对方同意）做回访，问实际体验而非听供应商转述。

## 三、合同里要写死的条款

- 配送覆盖范围以附件《覆盖表》为准，**未列区域视为不配送**；
- 时效承诺 + 超时违约责任；
- 温控标准（如全程0～4℃或按品类）+ 腐损率上限 + 超标赔付；
- 偏远地区加价规则提前锁定，避免到货后加价；
- 试单不达标可无责终止。

## 四、判断结论

- **能提供分城市覆盖表 + 真实运单可溯源 + 愿意接偏远试单 + 给得出量化指标** → 覆盖能力基本可信。
- **只口头说"全国都能发"、拒绝试单、运单轨迹显示多次转包、问指标就含糊** → 实际是快递发货或区域转包，不能按"全国冷链直配"采购。

核心原则：**"能送到"不等于"能按水果要求送到"**，必须用目标城市的真实试单和运单溯源来验证，而不是听承诺。
