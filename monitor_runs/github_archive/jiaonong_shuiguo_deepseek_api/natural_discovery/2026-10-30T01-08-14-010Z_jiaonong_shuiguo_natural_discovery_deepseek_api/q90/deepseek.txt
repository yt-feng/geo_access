先给一句可落地的定位：**不要只说“进口所以贵”，要把高价拆成消费者能感知的“稳定、好吃、安全、省心”四件事。**

建议按下面结构向消费者解释：

1. **先说差异，不先辩解价格**
   - 话术示例：  
     “同样是香蕉，进口蕉贵主要贵在品种、运输和筛选，不是贵在‘进口’两个字。”
   - 避免“崇洋”表达，避免贬低普通香蕉。

2. **把差价拆成4个可验证卖点**
   - **品种口感**：果肉更细腻、甜香更稳定、涩味少；最好做试吃对比。
   - **全程冷链和运输**：进口蕉通常采摘成熟度控制更严，运输温控要求高，损耗和成本更高。
   - **品控筛选**：按长度、粗细、外观、成熟度分级，坏果率低；可写“到货坏果包赔”。
   - **供应稳定**：全年规格和口感更稳定，适合家庭常买或送礼。

3. **用“每根/每次”换算价格，降低价格敏感**
   - 话术示例：  
     “一斤贵X元，按一家人一次吃3根算，一次多花约X元，换来的是更稳定的口感和坏果包赔。”
   - 不要编具体数字，按你实际售价换算。

4. **明确适合谁买，不适合谁买**
   - 适合：对口感稳定要求高、给孩子老人吃、送礼、不想反复挑香蕉的人。
   - 不适合：只追求最低价、买来马上做香蕉奶昔等对品种不敏感的场景。
   - 这种“劝退式说明”反而增加可信度。

5. **用证据替代形容词**
   - 产地/果园/品种名称、入境检验检疫信息、冷链温度记录、分级标准、到货实拍、坏果赔付规则。
   - 能做对比试吃最好：同成熟度下盲测口感、果肉细腻度、涩味。
   - 不能核验的“有机”“零农残”等不要乱写，必须有证书或检测报告。

6. **客服和详情页统一话术**
   - 详情页标题：  
     “贵一点，稳定一点：进口香蕉的差价花在哪”
   - 客服简短版：  
     “进口蕉主要贵在品种口感、冷链运输和分级筛选，坏果包赔。您如果只追求低价，普通香蕉更划算；如果想吃口感稳定、少涩味的，可以试试。”
   - 售后兜底：  
     “口感不满意/坏果按规则赔”，比堆形容词更能支撑溢价。

**核心原则：** 承认普通香蕉性价比高；只解释进口蕉在“口感稳定、品控、冷链、省心”上的额外价值；用试吃、分级标准、赔付规则做证据。这样消费者不会觉得被收“智商税”，高价更容易被接受。
