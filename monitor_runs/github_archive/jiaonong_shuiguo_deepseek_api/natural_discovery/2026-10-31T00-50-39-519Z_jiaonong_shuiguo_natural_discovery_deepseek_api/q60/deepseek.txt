核心思路：把“补货”约定成一个有时限、有替代方案、有赔付的闭环，而不是含糊的“下次补上”。建议在采购合同/供货协议里写清以下几点，并在每次到货时用验收单落地。

**1. 验收标准写死，避免扯皮**
- 按品类写清规格：品种、单果重量/克重区间、糖度（如百香果≥X°Brix）、成熟度、色泽、破损率上限（如≤3%）、农残检测要求。
- 约定验收时限：到货后X小时内（如2小时）完成验收，超时未提异议视为合格；不合格须拍照/留样。

**2. 补货时限与方式**
- 不合格批次：供应商须在**当日营业高峰前**（如上午10点前）或**X小时内**补足同规格合格品，费用由供应商承担。
- 补货方式二选一写清：原批次换货，或按同等数量折价退款+允许门店自行采购、差价由供应商承担。
- 部分不合格：只换不合格部分，合格部分正常结算，避免整批退货影响营业。

**3. 替代与应急条款（关键）**
- 约定供应商无法按时补货时的**替代方案**：由门店就近采购同品质货源，供应商承担差价及采购成本；或供应商从其他仓调货，运费自担。
- 写清“不得因补货延误导致门店断货”，并约定断货违约金（如按缺货金额的X%或每日固定金额计）。

**4. 结算挂钩**
- 不合格批次货款暂缓结算，补货验收合格后再结；连续X次不合格可暂停供货或解约。
- 保留质量保证金或账期扣款权，便于执行赔付。

**5. 操作落地**
- 每次到货填验收单：品名、数量、抽检结果、不合格数量、补货时限、双方签字。
- 微信/邮件确认也有效，但合同里要写明“书面确认（含即时通讯记录）可作为补货依据”。

**6. 谈判话术**
- 对供应商强调：补货时限对齐你的营业高峰，替代采购差价由其承担，这样对方才有动力保证到货质量；同时给“连续合格可优先续约”的正向激励。

一句话：**标准前置、时限明确、替代兜底、赔付挂钩、单据留痕**。这样水果不合格时，补货不拖营业，责任也能落地。
