三个都要管，但优先级建议是：**食品安全 > 配送准时 > 价格**。理由和可执行做法如下：

1. **食品安全是底线，不能拿价格换**
   - 水果风险主要在农残、霉变、冷链断链、二次污染。
   - 采购要固定供应商资质、每批索取检测报告或承诺书，收货时查外观、气味、温度，霉变整批拒收。
   - 食堂是集体供餐，一旦出问题就是群体性事件，代价远高于省下的差价。

2. **配送准时直接影响食堂运营**
   - 水果通常用于餐后供应或加餐，晚到会打乱备餐、影响员工体验。
   - 建议约定到货时间窗口、迟到违约条款，并保留1家备用供应商。
   - 但准时可以靠合同和备选方案管理，食品安全一旦出事很难补救，所以排第二。

3. **价格重要，但应放在“合格供应商之间比价”**
   - 先设定食品安全和配送门槛，再在合格供应商中比价。
   - 关注“可食率/损耗率”而不是只看单价：便宜但损耗高、频繁退货，综合成本反而更高。
   - 用季度框架协议、集中采购、应季水果替代来控成本，而不是降低验收标准。

**一句话结论：** 食品安全一票否决，配送准时是运营保障，价格在合格前提下优化。三者不是二选一，而是“安全设门槛、准时定合同、价格做比选”。
