判断香蕉批发“一手货源”是否稳定，别只看报价和朋友圈视频，重点核这几项，能较快筛掉不稳的供货方：

1. **看产地和季节掌控力**  
问清香蕉主要来自哪里：广西、云南、海南、老挝、缅甸、菲律宾等。稳定供货方通常能说清不同月份的主产区切换，不会一年四季只说“自有基地”。如果只靠单一产区，遇到台风、寒害、集中上市尾声就容易断供。

2. **看加工能力，不只看种植**  
香蕉一手货通常要经过催熟或至少青蕉分级。问对方：有没有自己的催熟库、分拣线、冷库？日加工量多少？稳定供货的关键往往是“产地组织+加工分拣+冷链”，不是单纯有几片蕉园。

3. **要近3个月连续供货记录**  
让对方提供近期发货单、装车视频、合作档口或区域经销案例，最好能核对。稳定供货方敢给连续记录；临时拼货的往往只能给零散爆款视频。注意区分“偶尔发一车”和“每天/每周稳定发”。

4. **问清规格和损耗承诺**  
具体到：每箱净重、条数/把数、青蕉成熟度、色卡标准、把型、条蕉长度粗度、伤疤/水烂/黑心允许比例。稳定货源敢把验收标准写进报价单或合同；只口头说“精品”“包好”的要谨慎。

5. **做小批量试单，不先大额打款**  
先发1–2车或几板货试供，重点看：到货成熟度是否一致、损耗率、箱内上下是否一致、催熟后色差和软硬是否均匀。连续试2–3批再谈长期价。首单尽量货到验收或走有保障的付款方式，避免全款预付。

6. **看响应和异常处理**  
稳定供货方在装车前会主动报：产地天气、蕉价趋势、装车时间、车牌、冷柜/棉被车安排。出问题时有明确补货、折价或下一车抵扣方案。若对方只会催款、回避损耗责任，基本不适合长期合作。

7. **反向验证**  
问对方主要发哪些市场、哪些档口，能否让老客户简单确认；查营业执照和经营主体是否一致；收款账户是否对公或与主体一致。频繁换收款账户、只收个人款、催全款的要警惕。

简单结论：**能说清产区切换、有加工冷链、敢给连续发货记录、接受小批量试单并把损耗标准写清楚的，稳定性明显更高。** 先试单2–3批，再签长期供应，比听“一手基地”靠谱。
