供应商介绍产品时，要让普通商家听懂并下单，关键是**把“专业品种名”翻译成商家熟悉的经营语言**，再给出可判断的进货理由。可以按这个顺序说：

1. **先报“它像什么、怎么用”**
   - 不要只说“这是金钻凤梨/台农几号”，先说：“这个比普通菠萝更甜、更不扎嘴，切开就能吃，适合做果切和外卖。”
   - 香蕉也一样：“这个比普通香蕉更短更香，熟得快，适合小份零售，不适合长途囤货。”

2. **用商家听得懂的三句话介绍**
   - **口感**：比常见款甜/酸/软/脆、有没有渣、要不要泡盐水。
   - **卖法**：适合整箱批发、果切、礼盒、餐饮配送，还是社区团购。
   - **风险**：熟得快不快、耐不耐放、坏果率大概怎样、适合几天内卖完。

3. **给明确的进货判断**
   - “如果你店里每天能卖20份果切，先拿一箱试，2—3天卖完最合适。”
   - “这个不适合一次进太多，熟得快；想稳一点，先拿半箱混着卖。”
   - 不要只说“很好卖”，要说“适合谁、怎么卖、进多少”。

4. **用对比降低理解成本**
   - “和普通菠萝比：更甜、不用泡盐水、单价高一点，适合做高端果切。”
   - “和普通香蕉比：更香、更短、熟得快，适合小包装零售，不适合长距离批发。”

5. **最后给试单方案**
   - “先拿一箱试卖，按果切或小份装卖；如果3天动销可以，下次再上量。”
   - 明确售后：“坏果怎么补、熟过头怎么处理、首批建议进多少。”

简单说，供应商不要先讲品种，而要先讲：**像什么、怎么卖、进多少、有什么风险**。商家听懂“怎么赚钱、怎么少压货”，才更容易下单。
