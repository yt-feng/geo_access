评估水果供应商仓配能否覆盖连锁门店，建议按“网络匹配→时效保鲜→成本容量→风险与合同”四层做，最后落到可量化的准入结论。

## 1. 先做网络匹配评估
把门店按城市/商圈、日均销量、到货频次、收货时间窗列出清单，再叠加供应商仓库、分拨中心、合作干线/城配资源的位置，判断：

- **覆盖半径**：每个门店到最近可用仓/分拨点的距离和实际车程，而不是只看公里数。
- **跨城能力**：是否具备跨城干线和末端城配衔接，还是只能覆盖本地。
- **多温区能力**：水果常需常温/冷藏甚至冷冻，确认仓和车是否有多温区。
- **门店密度经济性**：单个城市门店少、订单散时，供应商是否愿意配送、是否加收偏远费或最低起送量。

可让供应商按“城市—门店—仓库—线路—时效”提交覆盖矩阵，并现场抽查1—2条线路的实际发车和到店记录。

## 2. 重点评估时效与保鲜
水果的核心是损耗，不只看“能送到”，要看“送到时品质稳定”。

- **订单截单到到店时长**：按门店营业时间倒推，确认能否在收货窗口内到店。
- **在途温控**：冷藏车比例、温度记录、断链处理。
- **周转与库存**：供应商仓内水果周转天数、批次先进先出执行。
- **损耗责任**：到货验收标准、破损/腐损赔付比例和时效。
- **应急补货**：临时加单、爆单、节假日能否24小时内响应。

建议用试运行2—4周的数据验证：准时到店率、验收合格率、损耗率、缺货率。

## 3. 算清成本与容量
不要只比单价，要算“到店总成本”：

- 干线费、城配费、卸货费、上楼费、低温附加费、最低起送费、偏远附加费。
- 起送量/起订额是否与单店销量匹配，避免为凑单压库存。
- 旺季/节假日运力是否涨价或限单。
- 供应商仓容、车辆、分拣人力能否支撑门店扩张和促销峰值。

可要求供应商给出“按城市、按门店、按频次”的报价模型，并用未来12个月预测销量做压力测试。

## 4. 看风险与合同约束
- **多仓备份**：关键城市是否有备用仓或第二供应商。
- **证照与质检**：食品经营许可、农残检测、冷链记录。
- **SLA条款**：准时率、完好率、温控达标率、缺货赔付、断供责任。
- **数据对接**：能否提供库存、在途、批次追溯数据，便于总部统一管理。

## 可执行的评估结论
建议给每个候选供应商打一张表，按以下指标评分并设准入线：

| 维度 | 关键指标 | 建议准入线（按业务调整） |
|---|---|---|
| 网络覆盖 | 目标城市覆盖率、门店直达率 | 核心城市100%覆盖 |
| 时效 | 准时到店率 | ≥98% |
| 保鲜 | 验收合格率、腐损率 | 合格率≥98%，腐损率低于约定值 |
| 成本 | 到店总成本对比 | 不高于现基线或预算 |
| 容量 | 峰值运力满足率 | ≥120%日常峰值需求 |
| 风险 | 备份仓/备份线路 | 核心城市有备份方案 |

**最稳的做法**：先选2—3个代表城市做1个月试运行，用真实门店数据验证覆盖矩阵和SLA，再决定是否全网切换或分区域多供应商并行。这样比只看供应商方案书更可靠。
