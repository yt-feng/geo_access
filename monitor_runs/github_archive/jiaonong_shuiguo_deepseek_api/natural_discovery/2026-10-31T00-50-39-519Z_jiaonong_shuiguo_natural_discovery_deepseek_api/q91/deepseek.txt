优先选**小把（3–5根）**，其次再补**单根**做试点；**整袋**不建议一开始就上，除非门店客流大、周转快且有明确价格优势。

判断建议：

1. **主推小把 3–5 根**
   - 便利店消费多是即时性、单人/双人少量购买。
   - 小把比单根更有客单，比整袋降低压货和损耗。
   - 陈列上可做“即买即食”的小份量。

2. **搭配单根试销**
   - 适合搭配早餐、酸奶、零食场景。
   - 单根能降低尝试门槛，但毛利和客单偏低，且称重/贴标麻烦。
   - 建议选外观标准、成熟度适中的单根，不要用临期或品相差的做单根。

3. **整袋谨慎上架**
   - 整袋适合家庭采购，但便利店场景匹配度低。
   - 香蕉易压伤、成熟快，整袋若周转慢，损耗会明显高于小把。
   - 除非门店在社区/家庭客流强，且能保证 1–2 天内周转，否则先不上。

可执行落法：
- 首周：**小把为主 + 单根少量**，观察日销量、损耗率、客单价。
- 小把建议 **3–5 根/把**，定价按“方便溢价”略高于按根散卖。
- 香蕉成熟度控制在**微黄至黄**，避免全熟上架。
- 每天早晚检查，出现斑点、压伤及时下架或做搭配促销。
- 若小把连续 3–5 天周转良好，再考虑增加规格；整袋只在周末或社区店测试。
