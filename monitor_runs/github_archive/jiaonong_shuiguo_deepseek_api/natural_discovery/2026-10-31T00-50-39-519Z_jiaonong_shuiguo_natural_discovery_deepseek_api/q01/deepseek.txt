判断水果供应商靠不靠谱，重点不是“嘴上说得好”，而是看**稳定性、质量一致性、账期与损耗责任**。你可以按下面这套方法实操。

## 1. 先看“供货稳定性”，不是只看价格
香蕉和菠萝都是周转快、损耗敏感的水果，供应商最重要的能力是持续稳定供货。

重点问清楚：
- 香蕉：主要来自哪里？是国产还是进口？不同季节会不会断货？
- 菠萝：品种是什么（如金钻、巴厘等）？产季切换时货源是否稳定？
- 每周能稳定给你多少量？临时加量提前多久能到？
- 下雨、台风、节假日前后，供货和价格怎么处理？

**判断标准：**
- 能明确说出产区、产季、替代货源方案的，相对靠谱。
- 只会说“都有、便宜、没问题”，但说不清来源和波动的，要谨慎。

## 2. 连续试供至少2—4周
不要一次大单合作，先小批量试供。

建议做法：
- 第一周：少量拿货，观察到货时间、重量、成熟度、破损率。
- 第二周：故意下一次稍急的单，看他应急能力。
- 第三周：比对不同批次的一致性。
- 第四周：谈退换货和账期。

**你重点记录：**
- 实际到货重量是否足秤
- 香蕉青熟度是否适合你店里的销售节奏
- 菠萝黑心、烂心、机械伤比例
- 坏果是否愿意补货或扣款
- 迟到频率

## 3. 看质量一致性，而不是单次好坏
水果供应商最容易出问题的是“第一批很好，后面变差”。

对香蕉重点看：
- 催熟均匀度
- 青蕉硬度、把形
- 到店后能放几天
- 是否容易掉把、发黑

对菠萝重点看：
- 果心是否黑心
- 成熟度是否统一
- 表皮损伤、烂果比例
- 甜度和酸度是否稳定

**建议你建立简单验收标准：**
- 每批抽检若干箱，记录坏果率。
- 连续3批坏果率明显超标，就说明不稳定。
- 坏果率、重量误差、迟到次数要写进合作约定。

## 4. 看他敢不敢承担损耗责任
靠谱供应商通常愿意明确：
- 到货坏果怎么赔
- 短斤少两怎么补
- 香蕉催熟不合适谁负责
- 菠萝黑心比例超过多少怎么处理
- 退货、补货多久内完成

**不靠谱的典型表现：**
- 只说“水果都有损耗”，不给你明确比例
- 出问题就推给产地、天气、运输
- 第一次赔偿爽快，后面开始拖
- 不愿意小批量试供，只催你大单打款

## 5. 价格要比较“到手成本”
不要只比每斤报价，要算：
**到手成本 = 采购价 + 运费 + 损耗 + 短秤 + 退换货成本 + 资金占用**

比如A报价低，但坏果多、经常短秤、不补货，实际成本可能更高。

你可以每周记录：
- 进货斤数
- 实际可售斤数
- 损耗斤数
- 退货补货金额
- 实际到手单价

连续记录一个月，就能看出谁真的便宜。

## 6. 看结算方式和合作意愿
长期合作建议：
- 初期现结或短账期
- 稳定后再谈账期
- 不轻易给大额预付
- 所有退换货、损耗标准尽量写清楚，至少微信文字确认

**靠谱供应商的特征：**
- 愿意带你去看货或看仓库
- 能提供稳定联系人，不是今天一个人明天换人
- 出现问题时响应快
- 不强迫你压大货
- 对香蕉催熟、菠萝储存能给建议

## 7. 最实用的判断办法
你可以同时找2—3家供应商，小批量并行试供一个月，按下面表格打分：

| 项目 | 权重 | 说明 |
|---|---|---|
| 到货稳定性 | 25% | 是否按时、是否断货 |
| 质量一致性 | 25% | 坏果率、成熟度、批次稳定 |
| 损耗赔付 | 20% | 是否爽快、标准是否清楚 |
| 到手成本 | 15% | 算上损耗和短秤后的真实成本 |
| 沟通响应 | 10% | 出问题能否及时解决 |
| 结算灵活度 | 5% | 账期、预付要求 |

试供后保留前两名，不要只依赖一家。香蕉和菠萝都容易受产季和天气影响，**单一供应商风险很高**。

## 结论
判断供应商靠不靠谱，最有效的方法是：**小批量试供 + 连续记录坏果率和到手成本 + 明确损耗赔付 + 保留备选供应商**。  
如果一家供应商能稳定供货、质量波动小、出问题愿意赔、价格算下来不虚低，就值得长期合作。反过来，报价再低但不愿试供、不承担损耗、经常短秤的，不建议长期进。
