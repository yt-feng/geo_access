要点：**别买“已经启动后熟”的香蕉，并把到店后的存放条件从“闷热催熟”改成“低温+通风+隔离”。**

可执行做法：

1. **采购时选成熟度偏低的**
   - 选颜色偏黄绿、无大面积黑斑、果柄完整、果身硬挺的香蕉。
   - 不要选已经有密集“芝麻斑”、果柄发黑、果身发软的，这类到店后很快变黑。
   - 同一批尽量选成熟度一致的，避免熟蕉释放乙烯催黑其他蕉。

2. **优先买整把/带果柄的，少买散蕉**
   - 散蕉伤口多，容易感染和失水。
   - 到店后按“先熟先卖”分批，不要把生熟混放。

3. **运输和到店后不要闷在塑料袋/纸箱里**
   - 塑料袋会积聚乙烯和水分，加速变黑。
   - 用透气筐，垫纸吸湿，避免挤压。

4. **到店后低温存放，但别放普通冰箱冷藏**
   - 香蕉适合 **13℃左右、通风、避光** 存放；普通冰箱 4℃ 会导致冷害发黑。
   - 甜品店如果没有恒温库，放阴凉通风处，避免靠近烤箱、热饮机、阳光直射。

5. **隔离乙烯源**
   - 香蕉不要和苹果、梨、番茄、熟香蕉等释放乙烯的东西堆一起。
   - 熟蕉单独放，尽快用掉或做果泥、焦糖香蕉、冷冻香蕉泥。

6. **果柄包裹/分开**
   - 可用保鲜膜包住果柄减少乙烯释放，但不要整根密封。
   - 整把蕉可拆分成小把，减少相互催熟。

7. **采购量按2—3天用量走**
   - 甜品店用蕉最好少量多次采购，别一次囤一周。
   - 当天用不完的熟蕉及时去皮冷冻，做奶昔、果泥、烘焙馅料。

**判断标准：**到店香蕉应是黄绿或刚转黄、硬挺、无斑；存放环境不闷、不冷、不挤、不混放。这样能明显延缓变黑。
