坏果投诉的责任划分，核心是先看**责任发生在哪个环节**，再看**谁承担举证义务**，最后按**平台规则/合同约定**处理。可以按下面框架判断：

## 1. 先定环节：坏果可能出现在哪一段

| 环节 | 典型情形 | 主要责任方 |
|---|---|---|
| 产地/采购 | 采摘成熟度过高、病害果混入、预冷不及时 | 供应商/采购方 |
| 仓储 | 冷库温度不达标、堆压、存放过久 | 仓库/平台自营 |
| 分拣包装 | 未剔除坏果、包装缓冲不足 | 分拣/包装方 |
| 配送 | 冷链断链、暴晒、挤压、超时 | 配送方/平台 |
| 顾客收货后 | 未及时冷藏、放置过久、人为损坏 | 顾客 |

**判断要点**：坏果是“到货即坏”还是“放几天后坏”；是局部压伤、霉变，还是整体过熟；同批次其他订单是否集中投诉。同批次集中出问题，优先查采购/仓储；个别订单出问题，优先查分拣/配送。

## 2. 再定举证：谁主张谁举证，但平台通常有先行赔付义务

- **顾客**：收货后应尽快拍照/录像，保留坏果、包装、面单，最好在签收后24小时内反馈。生鲜一般有“签收后X小时内售后”规则，超时可能影响受理。
- **商家/平台**：对“坏果率在合理范围内”“运输途中自然损耗”等抗辩，需要提供采购验收记录、冷链温度记录、分拣记录、配送轨迹等证据。
- **配送方**：若怀疑配送环节，需调取温控和时效记录。

实务中，平台对生鲜通常实行**先行赔付**，再向责任供应商或配送方追偿。这不等于平台最终担责，而是先保障顾客体验。

## 3. 常见情形下的责任划分建议

1. **到货即发现明显霉变、腐烂、异味**：一般由商家/平台承担，按坏果比例退款或补发；若整单严重，可全额退款。
2. **轻微压伤、个别软果，不影响食用**：可协商部分补偿，不宜一律按全损处理。
3. **同批次多人投诉**：定性为批次质量问题，商家/平台全责，并追溯供应商。
4. **顾客签收后隔多天才反馈，且无开箱证据**：责任难认定，通常按平台售后规则协商，商家可拒绝全赔。
5. **顾客自身存放不当**（如未冷藏、暴晒）：顾客承担主要责任。
6. **配送明显超时或包装破损**：配送方/平台承担主要责任，商家可追偿。

## 4. 可执行的处理流程

1. 顾客在售后时效内提交坏果照片、订单号、开箱视频。
2. 客服按坏果比例定损：如10个坏3个，按30%退款；整单腐烂则全退。
3. 商家/平台调取同批次投诉率和冷链记录，判断是否批次问题。
4. 批次问题：下架该批次、追溯供应商、对已投诉订单统一赔付。
5. 个别问题：按比例赔付，记录配送/分拣责任。
6. 争议较大时，以平台规则和消费者权益保护法为底线，避免让顾客承担不合理举证成本。

**一句话结论**：到货即坏，原则上商家/平台先赔；最终责任按采购、仓储、分拣、配送、顾客存放五个环节的证据划分，批次性坏果追供应商，配送性坏果追配送方，顾客存放不当由顾客承担。
