做水果礼盒，关键是**把“好看、吉利、好吃、耐放、好定价”放在一起**。苹果、橙子、香蕉、菠萝这四样都很适合做基础款，但不要平均搭配，按用途分价位和场景会更好卖。

## 一、先定3个价位，别只做一个礼盒

### 1. 引流款：39～59元
**搭配：苹果4个 + 橙子4个 + 香蕉1把**
- 苹果取“平安”，橙子取“心想事成”
- 香蕉补体积、显丰满，成本低
- 适合办公室下午茶、小家庭、随手礼
- 不建议加菠萝，避免礼盒过大、成本上升

**卖点话术：**“平安顺心小礼盒，日常送人不出错。”

### 2. 主销款：69～99元
**搭配：苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个**
- 四样齐全，颜色丰富：红、橙、黄、绿都有
- 有“平安、顺心、旺来”的好寓意
- 适合探亲、看望病人、同事团购
- 这是最适合作为门店主推的款式

**卖点话术：**“四果纳福礼盒，平安顺心旺来来。”

### 3. 升级款：109～139元
**搭配：苹果6个 + 橙子6个 + 香蕉1把 + 菠萝1个，或菠萝2个**
- 数量更足，适合送长辈、客户
- 用更大更整齐的果子，礼盒显得有档次
- 可加贺卡、手提袋，提升送礼感

## 二、搭配原则：别让香蕉和菠萝“抢戏”

- **苹果、橙子做主角**：耐放、寓意好、颜色稳，适合垫底和撑礼盒。
- **香蕉做填充和视觉高度**：但香蕉不耐放，最好当天包、当天卖，或少量陈列。
- **菠萝做“亮点”**：一个就够，太多会扎手、占空间、增加成本。菠萝要选冠芽完整、颜色鲜亮的。
- **每个礼盒水果数量要成双或成吉利数**：4、6、8个更讨喜，避免零散。

## 三、最好卖的陈列和包装方式

1. **做3个样品盒摆门口**：39元、69元、109元各一盒，透明膜或开窗礼盒，让顾客一眼看到差别。
2. **颜色分区**：红苹果、橙子、黄香蕉、绿菠萝，尽量让礼盒正面颜色跳出来。
3. **加寓意标签**：苹果=平安，橙子=心想事成，香蕉=招财，菠萝=旺来。标签比单纯说“新鲜”更好卖。
4. **分场景推荐**：
   - 探病/看老人：苹果+橙子为主，香蕉少放，菠萝可不放。
   - 同事/客户：四样齐全，主销款最稳。
   - 情侣/朋友：小礼盒，苹果+橙子+香蕉即可。
5. **接受预约定制**：香蕉容易熟，建议顾客提前订，现包现送。

## 四、定价和损耗控制

- 礼盒价不要只按水果成本加价，要算上**包装、损耗、人工**。
- 香蕉和菠萝损耗相对高，主销款里菠萝放1个即可，香蕉选成熟度中等的。
- 每天闭店前把品相稍差的水果做“今日特价礼盒”，不要留到第二天。
- 主推69～99元款，39元款引流，109元以上款做利润和送礼面子。

## 五、最推荐你先上的组合

**先做这一款主推：**
> 苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个，定价69～89元，取名“四果纳福礼盒”。

再配一个 **39～49元小礼盒** 引流，一个 **109元以上大礼盒** 接送礼需求。这样顾客进店后容易比较，也更容易成交。
