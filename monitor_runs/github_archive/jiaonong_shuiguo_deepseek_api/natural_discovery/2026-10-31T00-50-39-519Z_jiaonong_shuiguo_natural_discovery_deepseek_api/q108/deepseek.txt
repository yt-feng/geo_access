核实水果供应商“全国配送”，核心是分清它到底**真能做到全国范围配送**，还是**只覆盖主要城市、用中转或外包勉强送达**。建议采购方按下面几层验证：

1. **先让对方报明确范围，不接受笼统承诺**
   - 要求书面列出：可直发省份、只能中转城市、偏远地区是否可达、哪些地区不配送。
   - 问清是“自有冷链直达”“干线+落地配”还是“第三方快递/物流转寄”，不同模式对水果损耗影响很大。
   - 要求注明时效：下单后多久发出、到目的城市几小时/几天、是否承诺到货时效。

2. **用真实收货地址做测试，不要只问销售**
   - 选自己的实际门店/仓库地址，尤其选一个非省会城市或偏远地区，让对方报“门到门”价格和时效。
   - 最好下一个小额试单，实测：是否真送到、是否冷链、包装是否完好、到货温度、果品损耗、是否额外收偏远费/上楼费。
   - 同时测试一个正常城市地址做对照，看是否只对核心城市友好。

3. **查物流轨迹和承运主体**
   - 要求提供本次/样例订单的物流单号，看轨迹是否从产地或仓直发，是否中途多次转寄。
   - 问清承运方是谁：自有车队、合作冷链、普通快递。水果对温控要求高，普通快递全国发不等于有冷链覆盖。
   - 看是否每单都能提供温控记录或到货温度证明。

4. **核验仓储与分拨能力**
   - 问有几个产地仓/销地仓、分别在哪、覆盖哪些区域。
   - 要求看仓库照片/视频或实地考察，重点看冷库、分拣线、预冷能力。
   - 如果只有单一产地仓却承诺全国次日达，要警惕是外包转寄。

5. **把承诺写进合同和考核**
   - 合同附件写明：覆盖区域清单、时效标准、冷链要求、破损/腐损赔付、偏远地区附加费上限、超时处理。
   - 约定试运行期和考核指标：准时送达率、腐损率、温控达标率、异常响应时间。
   - 保留“覆盖能力不实可终止合作”的条款。

6. **交叉验证口碑和案例**
   - 要求提供同区域、同品类客户的合作案例，最好能联系核实。
   - 查企业工商信息、冷链资质、运输许可；看是否有食品安全相关资质。
   - 不要只看宣传页和销售口头承诺，重点看**能否提供可追溯的真实订单轨迹和试单结果**。

一句话判断标准：**能给出明确区域清单、真实物流轨迹、冷链模式和试单结果，才算实际覆盖；只说“全国都能发”但说不清中转和时效的，通常只是普通快递覆盖，不等于水果配送能力。**
