# 学校食堂采购香蕉避免熟过头浪费的建议

核心思路是**按成熟度分批采购 + 到货时间与使用节奏匹配**，而不是单纯"少买"。

## 1. 采购时按成熟度分级下单
- 香蕉采购时问清供应商到货的**熟度**（一般分为青绿、微黄、黄熟、带斑点四个阶段），要求分批到货：近期（2–3天内）用的黄熟蕉，后续用的青绿或微黄蕉。
- 避免一次全收黄熟蕉——这是食堂香蕉变质的主因。

## 2. 控制单次采购量，增加频次
- 按"日均消耗量 × 1.5–2天"下单，而不是一周一次大量进货。食堂一般可做到每周2–3次送货。
- 采购量参考近两周实际消耗，而不是按人头估算。

## 3. 到货后做熟度分流
- 到货当天挑出已偏熟的香蕉，优先安排当天/次日食用或用于加餐窗口。
- 青一点的香蕉放在**阴凉通风、避阳光直射、不贴地**处；不要冷藏（低温会黑皮），也不要和苹果、梨等释放乙烯的水果混放。
- 有条件可分开存放，延缓整体催熟。

## 4. 调整使用方式及时消化临期香蕉
- 把"快熟过头"的香蕉转到**早餐、加餐点、水果捞**等快速消耗渠道，或做成香蕉奶昔、蒸香蕉糕点等（需符合食品安全和供餐规范）。
- 与供应商约定**小批量、可退换**：临期货在约定熟度范围内可调换或折价，倒逼供应商按需配送。

## 5. 建立简单台账
- 记录每次到货的熟度、数量、实际消耗和报损，一两周后就能校准采购量和送货频次。
- 设一个报损率目标（如低于3%–5%），超标就调整下单量和到货熟度。

## 关键点
真正有效的不是"少买"，而是**让到货熟度跟使用节奏对齐**：分批到货、按天消耗、临熟蕉优先走快速消耗渠道。如果供应商只能整批送货，就改为提高送货频次、单次减量。
