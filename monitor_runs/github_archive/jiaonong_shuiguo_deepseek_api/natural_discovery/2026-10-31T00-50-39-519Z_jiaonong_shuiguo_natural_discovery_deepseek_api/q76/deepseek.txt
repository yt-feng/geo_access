香蕉配送的核心矛盾是“怕压 + 怕冷 + 怕乙烯催熟”，控制思路要分成四个环节：**采收成熟度、包装防压、温湿度与通风、配送半径和时效**。下面给可执行方案。

## 1. 采收和入库：别用全熟香蕉去配送
- 配送用香蕉建议采收成熟度控制在 **7成左右**，到仓后做催熟或自然转黄，不要等全黄再发。
- 入库前剔除已有机械伤、黑斑、裂口的果，单果伤会传染整串/整箱。
- 香蕉对低温敏感，**低于12℃容易冷害发黑**，不要和冷藏生鲜混放在冷库低温区。适宜储运温度大致 **13–15℃**，湿度 **85%–90%**，并保持通风。
- 香蕉释放乙烯，也怕乙烯：不要和苹果、猕猴桃等呼吸跃变型水果混装；仓库和车厢要定期通风。

## 2. 包装：防压优先于防撞
- **单果套袋或珍珠棉网套**，再装硬质纸箱；箱内用瓦楞隔板分格，避免果串互相挤压。
- 纸箱抗压强度要够，堆码层数严格限制，箱体标注“禁止重压、向上、怕压”。
- 箱内留少量通气孔，不要完全密封；密封会积累乙烯和水分，加速变黑和发霉。
- 夏季可在箱内加吸水纸或干燥剂，但不要让香蕉直接接触冰袋；冬季避免靠近车厢门冷风口。
- 不建议用塑料袋全封闭抽真空式包装，香蕉需要呼吸。

## 3. 装车和配送：减少挤压和温度波动
- 装车时香蕉箱放在**上层或独立隔区**，不与重货、冻品、尖角商品混堆；用挡板固定，防止急刹前冲。
- 车厢温度控制在 **13–15℃**，避免空调直吹和频繁开门导致温差结露。
- 配送半径优先控制在 **同城/次日达**；香蕉不适合长距离多日运输，跨城建议走“产地仓—城市仓—前置仓”分段短驳，末端用保温箱+冰袋时冰袋必须隔开。
- 末端骑手配送用硬质保温箱，香蕉放最上层，避免和饮料、米面等重物同箱挤压。

## 4. 选品和运营兜底
- 优先发**较青的香蕉**，页面标注“收到后常温放置1–3天转黄”，降低客诉。
- 对易压坏规格做包装升级，比如单根/小把装，减少整串运输。
- 售后规则明确：轻微表皮黑点不等于坏果；严重压伤、果肉变黑按比例赔付。用客诉数据反推包装和成熟度。
- 若单量小，可考虑产地直发硬质礼盒装，或与本地香蕉供应商合作做同城短链，减少中转次数。

**最优先做的三件事**：① 发货成熟度降下来，别发全黄果；② 单果网套+分格硬纸箱+限堆层；③ 配送温度保持13–15℃、同城短链、不与重货冻品混装。做到这三点，压坏和变黑会明显下降。
