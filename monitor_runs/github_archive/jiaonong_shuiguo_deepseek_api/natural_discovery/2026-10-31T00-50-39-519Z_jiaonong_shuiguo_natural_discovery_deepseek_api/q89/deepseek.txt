结论先说：**对价格高度敏感的团购客户，优先用“阶梯价”，返利作为补充而不是主机制。** 例外是：当客户跨区域/多品类采购、你难以事前核验真实销量、或需要绑定年度合作时，才把返利作为主机制。

判断要点：

1. **阶梯价更适合价格敏感的团购客户**
   - 价格敏感客户要的是“当下单价更低”，阶梯价直接、可感知、好谈判。
   - 阶梯价能引导客户集中采购、凑量，提升单次订单规模。
   - 对供应商来说，边际成本可控，折扣与销量挂钩，比事后返利更少扯皮。

2. **返利适合的情况**
   - 客户采购分散、全年持续拿货，需要年度绑定。
   - 你不希望公开底价，想用返利保护价格体系。
   - 客户有多个采购主体或跨区域，事前难核定阶梯量。
   - 返利可以设计成“达成全年目标后返”，增强客户迁移成本。

3. **不建议只用返利做价格敏感团购的主因**
   - 返利是滞后兑现，客户感知弱，谈判时不如直接降价有吸引力。
   - 返利容易产生对账争议、兑现周期长、客户担心拿不到。
   - 价格敏感客户往往更看重现金流和即时成本，而不是年底返点。

**可执行建议：**
- 主机制：**阶梯价**，设置3档左右，档差清晰，比如按单次团购量或月度累计量给价。
- 辅助机制：**年度返利**，只给达到年度框架量的客户，返利比例不宜过高，避免侵蚀价格体系。
- 防窜货/防拆单：阶梯价按“单客户单次订单”核定，返利按“年度累计实际回款”核定。
- 谈判话术：先给阶梯价锁单，再给返利锁年，形成“单次有优惠、全年有奖励”的组合。

一句话：**价格敏感团购，阶梯价打头阵，返利做年度锁客工具；不要反过来。**
