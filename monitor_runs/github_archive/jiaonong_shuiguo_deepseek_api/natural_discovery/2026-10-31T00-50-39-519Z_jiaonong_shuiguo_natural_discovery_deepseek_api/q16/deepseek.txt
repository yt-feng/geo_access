建议：**先确定“哪类货走本地批发、哪类走稳定供应商”，不要二选一。**

**判断标准：**
1. **香蕉走本地批发更合适**：香蕉后熟快、损耗高、价格波动大，需要少量多次、按成熟度补货。本地批发能灵活调货、看货、控制熟度。
2. **苹果走稳定供应商更合适**：苹果耐储、规格和口感要求稳定，适合固定等级、固定价格周期、按周/按批补货。
3. **本地批发适合作为补充渠道**：用于应急补货、试销新品类、处理临时缺货。
4. **稳定供应商适合作为主渠道**：用于苹果主供、香蕉的长期备选，以及品质标准统一。

**可执行做法：**
- 香蕉：先找1—2家本地批发商，按“少量多次”试两周，记录到货熟度、损耗率、进价波动。
- 苹果：选1家主供应商，要求固定规格、可退换坏果、明确账期和配送频率；同时留1家本地批发作备选。
- 两款都做“每周复盘”：损耗率、毛利率、缺货次数。香蕉重点看损耗，苹果重点看稳定供货和价格。
- 采购比例建议初期：香蕉本地批发为主，苹果稳定供应商为主；运行一个月后再按数据和实际履约调整。

**结论：** 香蕉优先本地批发，苹果优先稳定供应商；同时保留另一个渠道作为备份，比单独选一个更稳。
