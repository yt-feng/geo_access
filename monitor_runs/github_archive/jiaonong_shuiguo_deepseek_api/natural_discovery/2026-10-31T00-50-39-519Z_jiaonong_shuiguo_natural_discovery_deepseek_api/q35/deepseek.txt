连锁超市降低门店坏果率，合同里不能只写“坏果赔付”，要把**验收标准、责任归属、赔付计算、扣款方式、举证与时效、整改退出**分开约定。建议按以下结构落到采购/配送合同或质量补充协议里。

## 1. 先定义“坏果”和“门店坏果率”
合同中明确可量化标准，避免争议：

- **坏果定义**：腐烂、霉变、软烂渗汁、明显机械伤、冻伤、虫害、异味、成熟度不符、规格不符等，建议附照片示例和分级标准。
- **门店坏果率**：  
  `门店坏果率 = 门店验收或上架前确认的坏果重量（或件数）÷ 该批次到店总重量（或总件数）×100%`
- **统计口径**：按批次、SKU、门店、到货日统计；称重以门店电子秤或双方认可设备为准；抽检还是全检要写清。生鲜建议“到店验收全检+上架前复检”，并约定抽检比例与抽检不合格即整批按比例推定。
- **责任边界**：到店验收时已发现的坏果由供应商承担；验收后因门店储存、陈列、温控不当造成的坏果，供应商不承担。建议约定验收后多少小时内提出异议有效，例如叶菜2小时、浆果4小时、根茎类24小时，超时视为验收合格，但隐蔽性腐烂除外。

## 2. 设置阶梯式赔付，而不是一刀切
建议按“允许损耗率—超标赔付—严重违约”三档：

- **允许损耗率**：按品类设阈值，例如叶菜3%—5%、浆果5%—8%、根茎类2%—3%、热带水果5%—8%。阈值内不赔付但计入供应商考核。
- **超标赔付**：  
  `赔付金额 =（实际坏果率－允许损耗率）× 该批次到店总货值 × 赔付倍数`  
  赔付倍数建议1—3倍，按品类和严重程度区分。也可约定“超标部分坏果按货值全额退款，并另按超标货值20%—50%支付违约金”。
- **严重违约**：单批次坏果率超过阈值2倍，或月度累计超标N次，触发整批退货、暂停供货、扣减保证金、终止合同。
- **封顶与保底**：可设单批次赔付上限，但严重食品安全问题不设上限；同时约定最低赔付金额，避免小额争议。

## 3. 赔付方式要可直接执行
优先约定从货款或保证金中直接扣款：

- 供应商确认后，超市有权在当期或下期货款中直接扣除赔付金、退货运费、销毁处理费。
- 扣款需附《质量异常确认单》：批次、SKU、到货数量、坏果数量/重量、照片、门店、验收人、供应商确认或异议期限。
- 供应商逾期不确认也不异议的，视为认可。建议约定2个工作日内反馈，逾期按超市记录为准。
- 退货、换货、补货的运费和损耗由责任方承担；坏果销毁需双方可追溯记录，防止回流。

## 4. 举证、时效和争议处理
- 到货验收单、门店拍照/视频、称重记录、温控记录作为赔付依据。
- 约定异议期和复检机制：供应商可在24小时内申请复检，复检仍不合格的，复检费用由供应商承担。
- 因供应商原因导致食品安全事件的，除赔付外还应承担下架、召回、顾客赔偿、行政处罚及商誉损失，建议单列且不适用赔付上限。
- 明确不可抗力、门店自身原因、第三方物流责任的责任划分；物流由供应商委托的，供应商对到店质量负责。

## 5. 用考核条款倒逼源头改善
赔付只是事后手段，合同还应加：

- 月度/季度坏果率考核，连续超标触发整改通知。
- 供应商提交采摘、预冷、分级、包装、冷链温控记录。
- 整改期后仍不达标的，超市有权调整订货量、暂停新品、收取质量保证金或终止合同。
- 对重复超标设置累进违约金，例如第1次按超标货值1倍赔付，第2次2倍，第3次终止合同。

## 6. 建议写进合同的条款示例（可改写使用）
> 乙方交付商品到店后，甲方按附件《生鲜验收标准》验收。某批次坏果率超过该品类允许损耗率的，乙方应按“（实际坏果率－允许损耗率）×该批次到店总货值×2”向甲方支付质量赔付；超标坏果部分甲方有权拒收或退货，退货费用由乙方承担。赔付金及退货费用甲方有权直接从应付货款或质量保证金中扣除，无需另行征得乙方同意。乙方应在收到质量异常通知后2个工作日内确认，逾期未提出书面异议的视为认可甲方记录。单批次坏果率超过允许损耗率2倍或月度累计超标3次的，甲方有权暂停订货、要求整改直至解除合同。

**关键提醒**：不要只约定“坏果包赔”，一定要把**品类阈值、统计口径、确认时限、扣款授权、严重违约触发条件**写清，否则门店执行时很容易扯皮。建议把验收标准和照片示例作为合同附件，并与采购、门店验收、财务扣款流程打通。
