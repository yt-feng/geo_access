压低成本又不牺牲品质，核心不是“把价砍下去”，而是**把价格谈在可验证的品质标准上**。建议按下面几步做：

**1. 先定标准，再谈价**
采购前把品质要求写清楚：品种、产地、规格（单果重/果径）、成熟度、糖度、外观瑕疵率、农残检测、包装方式、到货时限、损耗赔付。  
谈价时只说一句话：“同等标准下比价，不达标按合同扣款或退货。”这样供应商不会用降级货来换低价。

**2. 用“分级采购”代替一味压价**
把水果分成A/B/C级：
- A级做正价陈列和礼盒；
- B级做促销、切果、果汁；
- C级做特价引流或加工。  
对供应商说：“A级你按标准报价，B/C级给我打包价。”这样整体成本降，品质形象不塌。

**3. 谈“量价+账期+损耗”三件事，不只谈单价**
可以交换的条件：
- 承诺月度/季度稳定采购量，换阶梯价；
- 现款现结或缩短账期，换2%—5%价格优惠；
- 要求供应商承担运输损耗和到货不合格部分的赔付；
- 淡季锁量、旺季优先供货，换全年均价。  
注意：账期换低价要算资金成本，别为了账期把单价抬高。

**4. 用“到货验收+动态调价”替代一次性死砍**
合同里写：按到货合格率调价。合格率95%以上按合同价；90%—95%扣款；低于90%退货或降价。  
供应商知道你会认真验收，报价会更实，不敢用次果充好。

**5. 多源比价，但不要只找最低价**
同一单品保持2—3家合格供应商，报价时要求按统一规格表报。  
比价看“到岸合格成本”= 单价+运费+损耗+退货成本，而不是只看报价单。最低报价往往在损耗和售后上找回来。

**6. 谈长期合作时给“确定性”**
供应商最怕量不稳、结款慢、验收随意。你给稳定 forecast、明确验收标准、按时结算，就有资格要更好的价格。话术可以是：  
“我们不是要最低价，是要同品质下最有竞争力的到岸价。量给你稳定，标准写清楚，达标我们长期做。”

**7. 避开三个坑**
- 不要用“别家更便宜”虚压价，容易被换货降级；
- 不要只谈单价忽略损耗和账期；
- 不要一次性把价压到供应商没利润，后期品质和供货稳定性都会出问题。

一句话总结：**先锁品质标准，再谈量价、账期和损耗；用分级采购和到货验收控成本，而不是用低价逼供应商降品质。**
