可以按“先定验收标准，再选供应商，再小批量试供”的顺序做，重点不是找最低价，而是找能稳定按标准交货的人。

**1. 先定采购和验收标准**
- 香蕉：按成熟度分级，青蕉、微黄、熟黄分开；要求无腐烂、无严重压伤，到货成熟度适合当天或次日食用。
- 苹果：定品种、规格（单果重）、果径、色泽；要求无烂果、无明显磕碰、无虫眼。
- 橙子：定品种、果径、糖酸口感基本要求；要求无霉变、无裂果、无严重失水。
- 统一写清：合格率、允许损耗率、到货时间、退换货时限、包装方式、农残检测或承诺材料要求。

**2. 供应商来源优先顺序**
- 本地大型批发市场中有固定档口、能做学校配送的商户。
- 本地水果种植合作社或基地，适合苹果、橙子等耐储水果。
- 有学校、机关食堂配送经验的生鲜配送公司，服务能力更完整。
- 大型商超供应链或区域生鲜平台，价格可能高些，但票据和检测材料较规范。

**3. 筛选时重点看这几项**
- 资质：营业执照、食品经营相关许可、供货来源证明；能提供农残检测报告或快检记录。
- 稳定性：同一品种能否连续供货，雨天、节假日是否断供。
- 配送能力：能否按学校要求的时间送到食堂，是否具备分拣、称重、留样配合能力。
- 价格机制：不要只比单次报价，要比“到货合格价”，把损耗、退换、运费算进去。
- 售后：坏果怎么赔、少斤怎么补、临期或成熟度不符怎么换，必须写进订单或合同。

**4. 建议做法**
先选2—3家同时小批量试供1—2周，每周按品种记录：到货重量、合格率、损耗率、退换响应时间、实际结算价。试供后再定主供应商和备选供应商，避免单一供应商断供。

**5. 合同或订单里必须写清**
品种规格、单价及调价规则、到货时间、验收标准、不合格退换、损耗承担、结算周期、食品安全责任。香蕉这类易损耗水果尤其要约定成熟度和压伤赔付标准。

简单判断：能长期稳定按标准送货、票据检测材料齐全、退换不扯皮的供应商优先；只报低价但规格模糊、不能稳定配送的，不建议作为主供应商。
