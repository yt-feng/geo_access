茶饮店控制水果供应商的食品安全风险，建议按“资质—检测—过程—追溯”四类索取证明，并做定期复核：

1. 主体资质
- 营业执照（经营范围含水果/农产品销售）
- 食品经营许可证；若供应商仅销售食用农产品，按当地规定可能免许可，但应书面确认并留存
- 若为进口水果：海关入境货物检验检疫证明、报关单

2. 产品合格证明
- 每批次食用农产品承诺达标合格证（优先）
- 或产地证明/购货凭证
- 农残快检报告或第三方检测报告（重点：农药残留；进口水果看检疫）
- 检测报告应与供货品种、批次对应，不能只用一张常年报告

3. 过程与人员
- 采摘、分拣、包装、运输的卫生控制说明
- 冷链运输温度记录（易腐水果）
- 配送人员健康证明或供应商人员健康管理承诺
- 包装材料食品级证明（如直接接触水果）

4. 追溯与责任
- 供货清单/送货单：品名、产地、批次、数量、日期
- 可追溯承诺书：出现问题时能提供上游来源
- 食品安全责任协议：明确农残超标、变质、异物的退换与赔偿责任

实操建议：首次合作做供应商审核并留存上述材料；每批收货查验合格证/检测报告和感官状态；每季度或每半年要求更新检测报告；对高风险水果（如直接鲜食、不去皮的）提高抽检频次。无法提供合格证明的批次，建议拒收或加大自检。
