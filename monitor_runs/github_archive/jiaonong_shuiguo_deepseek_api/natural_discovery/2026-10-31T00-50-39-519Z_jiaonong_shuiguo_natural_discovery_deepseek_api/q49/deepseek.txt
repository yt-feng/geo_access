旺季菠萝用量突增，和供应商约定临时补货，核心是把“不确定的临时需求”变成“有规则、有价格、有响应时限”的补充协议。建议按下面几步操作：

## 1. 先内部测算，再谈
- 统计近2周实际用量、日均用量、峰值日用量，估算旺季未来4–6周的周需求区间（例如：正常周用200kg，峰值周可能到500kg）。
- 明确你能接受的补货提前期（比如提前48小时报单、24小时到货）。
- 明确品质标准：品种、单果重量、成熟度/糖度、无黑心、冷链温度、到店验收标准。

## 2. 在原合同上补签“临时补货条款”
不要只口头约定，至少签一份补充协议或微信书面确认。关键条款建议包括：

- **触发与报单方式**：单次需求超过日常订单量X%时，提前X小时以书面/指定群报单；供应商X小时内确认可供应量。
- **响应时限**：确认后24–48小时内到货；无法满足时须在X小时内告知，并允许你自行采购替代，不视为违约。
- **价格机制**：临时补货价可按“基准价+浮动上限”，例如以当地批发市场当周均价为基准，上浮不超过10%–15%；或约定旺季锁价区间，避免临时坐地起价。
- **数量弹性**：约定供应商在旺季每周至少保障你基础量的X%，临时增量部分按“尽力供应”或“优先供应”处理，并写明未达保障量的补偿方式（如差价补偿、下期优先权）。
- **品质与验收**：到货抽检比例、不合格退换时限、因品质问题导致断货的责任。
- **结算**：临时补货单独对账，账期与主合同一致，避免混账。

## 3. 设置“双供应商+安全库存”兜底
- 主供应商承担70%–80%，备用供应商承担20%–30%，临时补货优先向主供应商报，主供应商无法满足时启用备选。
- 门店保持2–3天安全库存，旺季前把冷库/冰箱容量和周转算清楚。
- 对易损耗的菠萝，可谈“分批次到货”，比如每周两次小批量补，而不是一次压大量库存。

## 4. 谈判时给对方“确定性”换“弹性”
供应商旺季也怕你临时加量后不要货。你可以承诺：
- 旺季基础量保底采购；
- 临时补货提前报单、按约定价格结算、不随意取消；
- 长期合作、淡季也保持一定采购量。
用这些换对方的优先供应权和价格上限。

## 5. 落地动作清单
1. 整理近30天菠萝用量和旺季预测；
2. 列出品质验收标准；
3. 起草1页补充协议，重点写响应时限、价格上限、保障比例、违约处理；
4. 与主供应商谈，同时接触1家备用供应商；
5. 在门店建立“临时补货报单群”，所有报单、确认、到货记录留痕；
6. 每周复盘一次实际到货率和品质，作为后续调整依据。

如果用量波动特别大，建议直接谈“周度滚动订单”：每周五报下周基础量，临时增量提前48小时报，供应商在24小时内确认可供量。这样既不给对方太大压力，也能保证你有据可依。
