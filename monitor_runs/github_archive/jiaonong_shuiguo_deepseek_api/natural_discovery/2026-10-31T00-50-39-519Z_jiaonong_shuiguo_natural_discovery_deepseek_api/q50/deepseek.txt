优先看**出汁率**，其次才是甜度；但对茶饮店来说，真正要卡的是“**稳定可用性**”：出汁率决定成本和出品效率，甜度决定风味稳定和糖浆调整成本。

可以按这个顺序判断：

1. **出汁率更重要**
   - 茶饮店用菠萝通常是榨汁、打泥、做果肉装饰。
   - 出汁率低，原料损耗大、单杯成本高、备料时间长。
   - 出汁率不稳定比甜度不稳定更麻烦，因为直接影响出杯量和毛利。

2. **甜度要“稳定”，不是越高越好**
   - 太甜未必好，容易压住茶底，且不同批次糖度波动会让配方难标准化。
   - 甜度偏低可以靠糖浆微调；但酸涩、纤维粗、出汁少很难救。
   - 建议选**糖度稳定、酸甜平衡**的原料，而不是单纯追高甜。

3. **实际采购建议**
   - 先定用途：做果汁/果泥看出汁率和风味；做果肉装饰看果肉完整度和纤维。
   - 要求供应商提供**批次糖度范围、出汁率/固形物参考、成熟度**。
   - 小批量试产：同一配方分别测出杯量、糖浆调整量、静置分层、氧化变色。
   - 综合优先级：**出汁率稳定 ＞ 风味酸甜平衡 ＞ 甜度稳定 ＞ 单果大小/外观**。

结论：**如果只能二选一，选出汁率高的；但长期采购要选甜度稳定、酸甜平衡的，不要只看甜。**
