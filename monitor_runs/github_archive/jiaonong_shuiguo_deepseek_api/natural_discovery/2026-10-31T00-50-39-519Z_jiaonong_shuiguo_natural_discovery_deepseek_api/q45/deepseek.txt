连锁超市和水果供应商签年度合同，最容易踩坑的条款集中在“价格与调价、质量验收、损耗退换、供货保障、账期结算、违约与终止”六类。下面按风险点给可执行建议。

**1. 价格与调价机制**
- 坑：只写“随行就市”或“按市场价”，年底极易扯皮；旺季供应商单方涨价，超市无约束。
- 建议：约定基准价+调价触发条件（如批发市场指数波动超X%）、调价提前通知期（如7天）、书面确认程序；对大宗单品设年度价格上限或阶梯价。明确运费、包装、卸货费由谁承担。

**2. 质量标准与验收**
- 坑：只写“符合国家标准”，水果实际按等级、规格、成熟度、农残验收，标准模糊导致拒收争议。
- 建议：附《质量标准附件》，按单品写清品种、等级、单果重/果径、糖度、成熟度、外观缺陷率、农残检测要求；约定验收方式（到货抽检比例）、验收时限（如到货2小时内）、不合格处理（拒收/降级/折价）及复检规则。

**3. 损耗、退换与短装**
- 坑：生鲜损耗责任不清，超市把门店损耗转嫁供应商，或供应商短装不补。
- 建议：明确“到货验收前损耗由供应商承担，验收后由超市承担”；约定合理损耗率（如2%-3%）及超损扣款；短装按实结算并设补货义务；临期/变质品的退换时限和费用归属写清。

**4. 供货保障与断货责任**
- 坑：只写供货量，不写缺货违约金和替代方案，旺季断货超市无救济。
- 建议：约定年度/月度最低供货量、缺货提前通知、缺货违约金或扣减返利；约定不可抗力范围（天气、疫情）及举证；明确替代货源采购差价由违约方承担。

**5. 账期、结算与返利**
- 坑：账期口头约定，对账无期限；返利、促销费、进场费名目不清，年底被追讨。
- 建议：书面约定账期（如月结30/45天）、对账周期、发票要求、逾期付款利息；所有返利/促销支持/陈列费逐项列明计算基数和支付方式，避免“其他费用”兜底条款。

**6. 违约、终止与排他**
- 坑：违约条款只约束供应商；年度合同自动续约；排他条款限制超市找备选。
- 建议：违约责任双向对等；明确质量事故、连续断货、严重违约的解除权；约定合同期限和续约条件；排他/独家条款要限定品类和区域，并设退出机制。

**签约前必做**：把《质量标准》《价格表》《验收单》《退换货流程》作为合同附件；所有口头承诺写进合同；保留验收记录和对账单据。重点盯“调价权、验收标准、损耗归属、断货责任、费用名目”这五处，基本能避开大部分坑。
