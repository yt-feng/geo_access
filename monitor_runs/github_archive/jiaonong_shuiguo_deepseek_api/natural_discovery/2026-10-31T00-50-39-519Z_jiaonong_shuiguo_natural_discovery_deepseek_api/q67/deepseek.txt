直接问以下问题，并**要求写进合同或代理协议**，不要只听口头承诺。

**一、区域保护怎么问**
1. 我这个代理区域的**边界**具体是哪里？按省、市、区县还是按渠道划分？请写进合同附件。
2. 区域是**独家**还是非独家？独家的话，品牌方在区域内还能不能直营、开旗舰店、做电商、供货给其他经销商？
3. 品牌方在区域内**已有多少家代理/分销**？我签约后新增代理的规则是什么？
4. 区域保护是**只保护线下**，还是线上线下都保护？线上旗舰店、直播带货、社区团购算不算冲击我的区域？
5. 如果发现品牌方或其它代理在我区域内销售，**违约怎么认定、怎么赔偿**？有没有可执行的罚则和退出机制？
6. 我的**最低进货量/年度任务**是多少？完不成任务时区域保护是否自动失效？任务按什么口径考核？
7. 代理期限多长？**续约优先权**和区域调整规则是什么？

**二、串货问题怎么问**
1. 品牌方对串货的**定义**是什么？跨区域销售、线上低价销售、跨渠道供货分别怎么认定？
2. 每箱/每件产品有没有**批次码、区域码、防窜码**？能不能追溯到供货商？出现串货时品牌方怎么查、多久给结果？
3. 串货的**处罚标准**是什么？扣保证金、罚款、取消返利、断货、终止代理，分别对应什么情形？
4. 我被别人串货冲击时，**向谁投诉、多久处理、处理不了怎么补偿**？
5. 我如果无意中收到串货货源，责任怎么划分？品牌方是否要求我必须举报？
6. 线上平台低价乱价是否算串货？品牌方有没有**控价机制**和授权店铺名单？
7. 保证金多少、什么条件下扣、什么条件下退？罚则是否对品牌方和其它代理**同等适用**？

**三、必须落到纸面的条款**
- 代理区域边界和独家性；
- 品牌方直营/电商/团购渠道的销售限制；
- 串货认定标准、追溯手段、处罚和赔偿；
- 区域保护违约的赔偿和退出机制；
- 年度任务口径、返利条件、保证金退还条件；
- 争议解决方式和管辖地。

**四、判断建议**
- 如果对方**不愿把区域保护和串货罚则写进合同**，只承诺“放心，不会”，风险很高。
- 如果产品**没有批次追溯码**，串货基本查不清，区域保护很难执行。
- 如果品牌方自己**线上低价直营且不设限**，你的线下代理区域保护会被架空。
- 优先选**有明确区域码、控价体系、书面罚则**的品牌；保证金比例过高且罚则单方解释的，要谨慎。

谈判时可以把问题整理成一页《代理政策确认函》，让对方逐条书面回复并盖章，作为合同附件。
