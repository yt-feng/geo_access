第一次合作，小批量试单的目标不是“赚一笔”，而是**验证供应商是否值得长期合作**。建议把试单设计成一次“可控、可测、可退出”的小实验，按下面几步做。

## 一、先定试单目标（别只看价格）
试单要同时验证4件事：
1. **品质稳定性**：到货规格、成熟度、损耗率是否和样品/承诺一致。
2. **交付可靠性**：是否按约定时间、数量、包装到货，缺货/延迟怎么处理。
3. **结算与售后**：账期、票据、坏果赔付、退换货是否爽快。
4. **配合度**：沟通响应、临时调整、问题处理态度。

## 二、试单规模怎么定
- **金额**：控制在你能承受“全损也不影响经营”的范围，通常单次进货额的5%–10%，或相当于1–2天销量。
- **品类**：选**1–2个主力、易判断品质的品种**，不要一次铺很多SKU。
- **数量**：够覆盖你的核心客户1–2轮销售即可，便于观察复购反馈。
- **批次**：最好分**2批**下单（间隔几天），第一批验基础，第二批验稳定性。

## 三、试单前必须书面确认的条款
哪怕微信确认也要留痕：
- 规格等级、产地、包装方式、单箱净重/毛重、允许误差
- 价格、是否含运费、卸货费谁承担
- 到货时间窗口、延迟怎么赔
- **损耗/坏果赔付标准**（比如超过X%按比例赔或补发）
- 结算方式：现结/账期、是否开票
- 退换货条件

## 四、到货验收设计（关键）
提前定好验收动作，别到货再临时看：
1. **点数**：箱数、重量抽检。
2. **抽检比例**：至少抽10%–20%的箱，记录规格、成熟度、坏果率。
3. **拍照留证**：开箱、称重、坏果特写、整车/整批照片。
4. **填验收表**：品名、批次、到货时间、抽检数、不合格数、损耗率、处理结果。
5. **当天反馈**：有问题当天书面反馈，别拖到卖完再说。

## 五、试单期间重点观察
- 第一批和第二天货的品质是否一致
- 出现问题时供应商是**先解决还是先甩锅**
- 是否主动告知缺货、涨价、产地变化
- 小单是否被区别对待（这是很多批发商踩的坑）

## 六、设“继续/停止”标准
试单前就定好：
- **继续合作**：损耗在约定范围内、交付准时、售后响应及时、复购客户反馈正常。
- **观察再试**：品质可以但交付/沟通有瑕疵，再下1次小单验证。
- **停止**：损耗明显超标、缺斤少两、售后推诿、临时加价。

## 七、一个可执行的最小方案
> 选1个主力品种，下2批小单，每批约为1–2天销量；书面确认规格、价格、到货时间、损耗赔付；到货抽检20%并拍照填表；当天反馈问题；两批结束后按“品质/交付/售后/配合”四项打分，再决定是否放大采购。

核心原则：**小单验人，大单验品；先留证据，再谈放量。**
