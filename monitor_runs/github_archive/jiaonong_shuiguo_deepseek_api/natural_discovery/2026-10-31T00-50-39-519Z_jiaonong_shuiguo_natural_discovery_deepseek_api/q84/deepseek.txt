家庭团购水果礼盒，建议优先考虑“耐放、好分、老小都能吃、成本可控”，而不是追求品种多。苹果、橙子、香蕉、菠萝这四样里，最稳妥的是做 **“苹果+橙子”做主组合，香蕉少量点缀，菠萝不建议常规放进家庭礼盒**。

具体建议：

1. **推荐组合：苹果 + 橙子 + 香蕉（少量）**
   - 苹果：选耐放、大小均匀的，占比约40%—45%，是礼盒的“压舱石”。
   - 橙子：占比约35%—40%，家庭接受度高，颜色也好看。
   - 香蕉：占比约15%—20%，但一定要少量、偏生一点发货，避免到家就熟透。
   - 适合家庭日常吃，老人孩子都能接受，运输损耗也相对低。

2. **菠萝要谨慎**
   - 菠萝体积大、带皮重、需要削、成熟度不好控制，家庭礼盒里容易占重量又不讨好。
   - 如果一定要放，建议做“小菠萝/凤梨”单品加购，或者只在高档礼盒里放1个，不要作为常规家庭组合的主力。

3. **更推荐的两个家庭档位**
   - **基础家庭装**：苹果 + 橙子，比例约5:5或4.5:5.5，最稳，适合团购走量。
   - **丰富家庭装**：苹果 + 橙子 + 香蕉，比例约4:4:2，香蕉用独立袋装，减少挤压。

4. **不建议的组合**
   - 苹果+橙子+香蕉+菠萝四样全上：看起来丰富，但菠萝重、香蕉易压、家庭实际体验不一定好，售后风险也高。
   - 香蕉和菠萝放太多：香蕉催熟、菠萝占重，容易拉低礼盒性价比。

5. **团购操作建议**
   - 苹果、橙子选耐运输品种，香蕉发7—8成熟，菠萝如放则单独网套+直立摆放。
   - 礼盒标注“香蕉请及时取出，避免挤压催熟其他水果”。
   - 家庭装控制在5—8斤较合适，价格带更容易成团。

**结论：家庭团购首选“苹果+橙子”为主，香蕉少量搭配；菠萝不作为常规家庭礼盒必选项，最多做可选加购。**
