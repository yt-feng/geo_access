会影响，但影响大小取决于你**怎么卖**。香蕉一箱大小不一致，本质是“分级问题”，不是“质量问题”。

**会带来的影响**
1. **外观不整齐，降低顾客第一眼购买欲**：同一堆里大小差异大，看起来像“挑剩的”。
2. **顾客挑拣加剧**：顾客会挑大的、挑好看的，剩下小的难卖，损耗和投诉增加。
3. **定价困难**：统一定价时，大的觉得亏、小的嫌贵；按大小分价又增加称重和陈列成本。
4. **成熟度不一致时更明显**：大小不一常伴随成熟快慢不同，容易出现“有的已熟、有的还生”。

**可执行的处理建议**
- **到货就分级**：按大、中、小分三档，分别定价陈列，别混堆。
- **混装做特价**：大小混装按“家庭装/实惠装”低价走量，明确标注“大小不一，口感一样”，减少挑拣。
- **小果做加工或搭配**：小香蕉适合做香蕉奶昔、果切搭配、促销搭赠，别硬当精品卖。
- **陈列时把整齐面朝外**：同一层尽量放大小接近的，视觉上先稳住。
- **采购端提前约定**：下次采购要求供应商按规格分级，或接受混装但压价，把分级成本算进进货价。

**判断标准**：如果大小差异在**同一箱内肉眼明显、超过两个规格档**，就会明显影响销售；如果只是轻微差异，分级陈列后影响不大。核心不是“能不能卖”，而是**不能混在一起统一定价卖**。
