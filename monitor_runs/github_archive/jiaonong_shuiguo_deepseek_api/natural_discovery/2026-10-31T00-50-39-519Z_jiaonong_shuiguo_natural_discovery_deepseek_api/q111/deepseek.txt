# 判断检测报告是否对应当前批次的核心方法

**核心原则：报告必须能唯一锁定到“这一批货”，而不是“这个供应商”或“这个品类的常年报告”。**

## 一、先看报告本身能否唯一标识批次

| 核对项 | 合格表现 | 危险信号 |
|---|---|---|
| 报告编号与日期 | 有唯一编号，采样/检测日期在**本批货到货前合理区间内**（一般到货前数天至数周） | 无编号、日期明显早于当前采购周期（如用去年报告） |
| 样品名称/规格 | 与本次订购品种、规格、产地一致 | 品种不符、只写“水果”笼统名称 |
| 受检单位/委托方 | 是**本供应商**或本批货的生产主体 | 是其他公司，供应商称“借用” |
| 样品来源描述 | 写明产地/基地/批号/数量 | 无来源，无法回溯 |
| 检测项目 | 覆盖采购合同要求的农残/重金属项目 | 项目缺项、只检1-2项 |

## 二、用“批次三要素”做交叉核对

要求报告与**实物、单据**三方一致：

1. **批号/生产日期**：报告上的样品批号或采样日期 → 对照送货单、包装箱/箱码/产地编码 → 对照实物标签。三者能对上才算。
2. **数量与采样逻辑**：报告采样量应与本批规模大致匹配；小批量货配“大批量抽检报告”要警惕。
3. **产地/基地**：报告样品产地与本次货的产地证明、包装标识一致。

## 三、核验检测机构是否有效

- 机构具备 **CMA 资质**（报告上有CMA标志及资质编号），必要时看是否含CNAS。
- 到**国家认监委/市场监管部门公开渠道**查机构资质是否在有效期内。
- 报告有检测机构盖章、骑缝章、签发人签字；电子报告可扫二维码/官网编号验真。
- 注意：**CMA只证明机构有资质，不证明这份报告就是这批货的**，所以机构核验不能替代批次核对。

## 四、对供应商做“可追溯性”要求（最有效的防线）

采购合同中就约定：

- 每批货随附**该批次**检测报告，报告须注明**批号/采样日期/产地**，并与送货单批号一致；
- 供应商提供**采样记录、送检委托单**（能证明样品取自本批）；
- 允许采购方**自行或委托第三方对该批货复检**，费用与不合格责任在合同中明确；
- 建立**报告台账**：批号—报告编号—到货日期—检测项目逐笔登记，防止一报告多用。

## 五、实操判断口诀

> **“一编号、二日期、三批号、四产地、五机构、六盖章”**——六项全对得上，才可视为对应本批；任一项对不上，先按“存疑”处理，要求补证或自行抽检。

## 六、常见规避手法及应对

- **一报告多用**（同一报告发给多批货）→ 查报告采样日期与批号，要求逐批新报告。
- **借用他人报告**→ 核对受检单位名称。
- **只给合格页/复印件**→ 要完整原件或可验真电子版。
- **报告项目与风险不匹配**→ 按品种风险清单（如叶菜重点查有机磷、草莓查农残多项目）要求补检。

**一句话结论：报告编号、采样日期、批号、产地、受检单位五项与本批货实物和单据完全一致，且机构具备有效CMA资质、报告可验真，才算对应；否则应要求补证或自行复检。**
