每天少量水果，选供应商的关键是“少操心、能稳定、损耗低”，不建议优先找大批发商或纯平台比价。比较省心的做法是：

1. **优先找本地二级批发商/水果配送商**
   - 找当地农批市场里做“餐饮配送”的档口，而不是只做零售的摊贩。
   - 要求：固定时间送货、可退换坏果、按你的用量分装。
   - 优点：比一级批发灵活，起订量低，出问题能找到人。

2. **次选：本地生鲜配送平台**
   - 如当地的美菜、快驴这类餐饮供应链平台，或区域生鲜配送公司。
   - 适合少量、品类杂、不想自己盯货的店。
   - 注意看：起送价、配送费、售后是否爽快、是否强制搭售。

3. **小量可考虑“水果店长期合作”**
   - 和附近水果店谈餐饮供货价，每天顺路送或自取。
   - 适合每天几斤到十几斤的店，省心但价格略高，旺季可能被零售挤占。

4. **不建议一开始就找产地/一级批发**
   - 起订量大、损耗和运输自己扛，少量采购反而不省心。

**筛选时重点问清5件事：**
- 每天几点前能送到，能否固定时间；
- 起订量多少，少量是否加价；
- 坏果、烂果怎么赔，是否可现场退换；
- 能否按品种分装、提前一天报单；
- 账期还是现结，临时加单怎么处理。

**最省心的组合建议：**
主供应商选1家本地餐饮水果配送商，签简单月度合作；再备1家附近水果店或生鲜平台应急。每天报单、到货验货拍照，坏果当场登记，月底对账。这样既稳定，又不会被单一家卡住。
