选择适合批量配送的水果供应商，核心看稳定性、履约能力和售后。具体可按以下步骤执行：

**1. 先定需求再找供应商**
- 人数、预算/人、配送频次（每周几次）、配送时间窗口
- 是否需要切果/洗果/分装、是否有过敏或忌口要求
- 场地是否有冷藏条件（影响水果品类选择）

**2. 供应商类型优先级**
- 本地水果批发市场档口：价格低、品类全，但配送和售后不稳定，适合有专人对接的公司
- 生鲜B2B配送商（如美菜、快驴等区域服务商）：标准化程度高、可开票、有售后，适合常规批量配送
- 本地果园/合作社直供：新鲜度高、适合单品大批量，但品类单一、季节性明显
- 连锁水果店企业团购：服务好、可切配，但单价偏高

**3. 重点考察的硬指标**
- **履约稳定性**：能否固定时段送达、迟到如何处理、旺季是否断供
- **品控标准**：是否有分级标准、坏果率承诺（行业常见坏果包赔比例可谈，如5%以内包赔）
- **报价透明度**：是否含配送费、包装费、是否随行就市调价、调价是否提前通知
- **票据与合规**：能否开增值税发票、是否有食品经营许可
- **应急能力**：临时加单、换品、取消的响应时间

**4. 落地验证方法**
- 先小批量试单2–4周，记录到货时间、坏果率、重量是否足称
- 要求提供近期服务的企业客户案例（可电话回访1–2家）
- 签简易框架协议：明确配送时间、坏果赔付、调价机制、违约责任

**5. 避坑提示**
- 警惕报价明显低于市场价的供应商，常见问题是缺斤少两或以次充好
- 不要只锁定一家，保留1家主供应商+1家备选
- 水果价格波动大，合同里写清“随行就市但需提前3天书面通知”

**建议执行顺序**：先明确人数预算和配送频次 → 筛选3家本地供应商（1家B2B平台+1家批发档口+1家连锁团购）→ 小批量试单2周 → 按坏果率、准时率、响应速度打分 → 签框架协议并保留备选。
