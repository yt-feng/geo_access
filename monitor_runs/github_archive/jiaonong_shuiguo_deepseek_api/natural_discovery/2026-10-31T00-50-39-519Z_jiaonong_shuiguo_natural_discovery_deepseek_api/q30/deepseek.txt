建议把“到货验收—分级处理—索赔时限—责任归属”写进采购合同或供货确认单，而不是只在口头上约定。可按下面执行：

1. **到货验收标准写清楚**
   - 按品类约定最低品相：大小、色泽、成熟度、机械伤、腐烂率、冻伤/压伤比例。
   - 约定抽样比例和验收时限，例如到货后2小时内抽检，冷链水果4小时内完成。
   - 写明“不符合标准的批次可整批拒收或按比例扣款”，避免只能事后扯皮。

2. **分级处理机制**
   - **轻微品相问题**：不影响食用的，可协商折价接收，折价比例按缺陷比例计算。
   - **明显品相问题**：可要求换货、补发或退货，运费和损耗由供货方承担。
   - **腐烂、变质、食品安全风险**：立即隔离，整批拒收或销毁，并保留照片、视频、称重记录。

3. **售后申请时限和证据**
   - 合同里约定：到货验收发现的问题，须在验收时或到货后X小时内提出；隐蔽性问题在开箱/上架前提出。
   - 证据要求：到货单、抽检照片/视频、称重记录、温控记录、双方签字确认的异常单。
   - 超过时限未提出，视为验收合格，但食品安全问题除外。

4. **责任和费用承担**
   - 因供货方原因导致品相不合格：退换货费用、运输损耗、超市合理上架损失由供货方承担。
   - 因超市储存不当导致的问题：由超市承担。
   - 约定争议处理顺序：先协商折价/换货，协商不成按合同违约条款处理。

5. **结算挂钩**
   - 验收合格后才进入结算；有争议的批次暂缓付款。
   - 可约定质量保证金或月度扣款机制，避免供货方拖延处理。

6. **书面确认**
   - 每次售后处理形成《到货异常确认单》，写清批次、数量、问题、处理方式、金额、双方签字。
   - 微信、邮件沟通也应保留，并在合同中约定其可作为有效证据。

核心是把“什么算品相不好、多久内提、怎么赔、谁承担费用”量化，不要只写“保证质量、有问题协商解决”。
