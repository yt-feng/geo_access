建议按“损耗、客群、毛利”三条线分开定，不是三选一：

**1. 主推“顾客自己挑整果”，但设分区**
- 菠萝成熟度差异大，顾客自己挑能减少“买回去不甜/坏果”的售后纠纷。
- 整果最耐放，损耗最低，适合走量。
- 可设“1个价”“2个优惠价”，鼓励多买。

**2. 去皮好的只做“引流/即食”小份**
- 去皮果切损耗高、氧化快、需冷藏，适合切好装盒、当天清。
- 放在收银台或门口，标“即食/现切”，卖给赶时间、办公室、带小孩的顾客。
- 不要大量提前去皮，按小时分批切，卖不完做果切拼盘或折价清。

**3. 不建议“只卖整果不帮处理”**
- 很多顾客怕削菠萝麻烦。提供免费或低价代削，能明显提升成交。
- 代削放在“购买后处理”，不要提前削好摆着。

**4. 按客群微调**
- 社区店、中老年多：整果为主，代削服务。
- 写字楼、商圈、年轻人多：整果+小盒即食并行，即食占比可到三成。
- 客流小、当天卖不完风险高：整果为主，即食只做少量试销。

**5. 关键操作**
- 整果按成熟度分区：当天吃、放两天、做菜用。
- 去皮果切标注切制时间，冷藏陈列，当天未售完折价或转拼盘。
- 观察一周数据：整果销量、代削比例、果切报废率。果切报废超过两成，就缩量。

一句话：**整果让顾客自己挑是主模式，代削是服务，去皮小盒是补充引流，不要反过来。**
