单位采购水果到货品质不一致，验收和售后建议按“先定标准、再分区验收、当场留证、按合同处理”来做，避免事后扯皮。

**一、采购前先把标准写进合同/订单**
- 明确品种、规格（单果重量/果径）、等级、成熟度、糖度（如需要）、产地、包装方式。
- 约定允许的不合格率，例如“抽检不合格率≤5%可接收，超过则整批退换或按比例扣款”。
- 约定验收时限：到货后2小时内或当日完成验收，逾期视为合格（对供应商有利，单位要避免）。
- 约定售后：坏果、烂果、规格不符的处理方式，退换货时限、补货时限、扣款方式。
- 约定“品质不一致”的判定依据：以抽样检验和现场照片/视频为准。

**二、到货验收流程**
1. **核对单据**：送货单、品名、数量、规格、产地、批次与订单一致。
2. **抽样**：按批次随机抽样，大货可按5%—10%抽检，小批量全检关键项。
3. **分区验收**：把合格、不合格、待复检分开摆放，不要混放。
4. **检查重点**：
   - 外观：腐烂、霉变、虫害、机械伤、裂果、畸形。
   - 规格：单果重量/果径是否达标。
   - 成熟度：过生或过熟，是否适合单位食用和存放。
   - 新鲜度：萎蔫、失水、异味。
   - 包装：挤压、受潮、破损。
5. **当场记录**：拍照/视频，记录抽样数量、不合格数量、不合格类型，双方签字确认。
6. **出具验收结论**：合格接收、让步接收（扣款/折价）、拒收或退换。

**三、品质不一致的处理方式**
- **轻微不一致**：如少量规格偏小、成熟度略差，可按比例折价接收，并在验收单注明。
- **批量不一致**：如品种不对、规格严重不符、腐烂率超标，应当场拒收或要求整批退换。
- **部分不合格**：按合同约定扣款或要求补货，不合格品单独封存，避免混入合格品。
- **腐烂/食品安全风险**：直接隔离，不得入库食用，要求供应商当日处理并补货。

**四、售后跟进**
1. 验收后24小时内向供应商发出书面问题清单（照片、数量、批次、处理要求）。
2. 要求供应商在约定时限内补货、换货或退款，并保留沟通记录。
3. 对同一供应商连续出现品质问题的，记录履约情况，作为后续采购评价依据。
4. 涉及食品安全或金额较大的，按合同条款追责，必要时保留索赔权利。

**五、给单位的实操建议**
- 验收至少两人在场，一人清点、一人质检，避免单人说了算。
- 用统一验收单模板，包含批次、抽样数、不合格数、处理意见、双方签字。
- 不要先入库再验收；不合格品单独存放并标识。
- 对供应商提前发“到货验收标准”，让其送货前自检。

核心原则：**标准前置、现场留证、分区处理、按约售后**。这样品质不一致时，单位有依据、供应商也认账。
