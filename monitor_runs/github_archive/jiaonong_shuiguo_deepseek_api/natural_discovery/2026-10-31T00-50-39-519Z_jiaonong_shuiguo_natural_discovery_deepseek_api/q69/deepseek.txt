# 香蕉、菠萝分级报价怎么做才清楚

核心原则就一条：**分级标准写在报价单上，让小店老板不用问也能自己对照着验货、算钱。** 香蕉和菠萝的分级逻辑不一样，分开说。

## 香蕉：按"每把/每箱的条数+成熟度+外观"分

香蕉最关键的是**成熟度**（直接影响小店能卖几天）和**条数规格**，外观缺陷放第三。

建议这样定级（可按你的实际货源调整数值，但**标准必须固定、每次一致**）：

| 级别 | 规格 | 成熟度 | 外观 | 报价方式 |
|---|---|---|---|---|
| A级 | 每把5–6条，单条粗细均匀 | 7–8成熟（青黄，可放3–4天转黄） | 无黑斑、无机械伤、无断指 | 元/箱（注明净重和把数） |
| B级 | 每把4–6条，粗细略不均 | 8–9成熟（已见黄，2天内可售） | 允许轻微擦伤、少量小斑点 | 元/箱 |
| C级/处理货 | 断把、散条、条数不齐 | 已全黄或偏熟 | 明显斑点、磕碰，不影响食用 | 元/斤 或 打包价 |

**报价单上要写死的三件事**：① 每箱净重（去皮/含箱分开写）；② 每箱几把、每把几条；③ 成熟度对应"到店后还能放几天"。这三项一写，小店老板自己就能判断值不值。

## 菠萝：按"单果重量+果形+成熟度"分

菠萝按**个头（单果重）** 分档最直观，小店按个卖或按斤卖都容易算。

| 级别 | 单果重 | 果形/外观 | 成熟度 | 报价方式 |
|---|---|---|---|---|
| 大果（A） | 1.5kg以上 | 果形端正、冠芽完整、无裂果 | 青熟或半黄 | 元/个 或 元/斤 |
| 中果（B） | 1.0–1.5kg | 果形正常，轻微歪斜可接受 | 半黄 | 元/个 或 元/斤 |
| 小果（C） | 1.0kg以下 | 果形不规整、小裂口 | 视情况 | 元/斤 或 打包价 |

菠萝额外要标清楚：**是否带冠芽、是否催熟、到店可存放天数**（菠萝怕冷，别放冷库，这点要提醒）。

## 让报价"清楚"的通用做法

1. **一张表通吃**：级别 / 规格（重量或条数）/ 成熟度 / 外观允许范围 / 单价 / 计价单位（箱、斤、个）。计价单位一定要写，否则"一箱多少钱"最容易扯皮。
2. **样品即标准**：每个级别留一份实物样品或拍照存档，报价单附图上标级别，验收有争议就以样品为准。
3. **净重口径统一**：香蕉论箱、菠萝论个或论斤，都要注明含不含包装皮重。
4. **等级差价要拉开**：A/B/C 价差太小，小店会只挑A级或全要C级压价；价差一般按品质差距定，别拍脑袋。
5. **预留"处理货"通道**：熟过头、磕碰的单独一个价，写进报价单，避免每次临时议价。

一句话：**分级标准固定 + 计价单位写死 + 附样品图**，报价单本身就是验收单，小店照着核对就行。你可以按自己实际货源把上面的数值调一遍，调完就固定下来用，别每批换标准。
