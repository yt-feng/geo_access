到店买香蕉要“刚好”，核心是**按你打算几天吃完来选成熟度**，并在出门前做两个小判断：看超市通常的补货/上架节奏、看当天天气和路程。

可直接执行的做法：

1. **先定用途和时间**
   - 当天吃/第二天吃：选**全黄、少量芝麻点**的。
   - 3～5天吃完：选**黄中带一点绿尖**的。
   - 一周左右吃完：选**整体偏绿、明显有绿棱**的，回家常温放熟。
   - 要做奶昔/烘焙：可买**带黑点但果肉不软塌**的。

2. **到店前避免“太生”**
   - 别太早去。超市刚开门时，香蕉常是刚上架或还没挑过的，青蕉比例高；**傍晚补货后或下午**更容易挑到成熟度合适的。
   - 如果货架上全是青蕉，不要指望“放两天就好”，青蕉到可食可能需**3～7天**，按你吃的时间反推。

3. **到店前避免“太熟”**
   - 避开**高温时段和暴晒路程**。香蕉对热敏感，夏天买完别放车后备箱或电动车筐里晒。
   - 如果货架香蕉已经**大面积黑斑、果柄发黑、手感软塌**，说明过熟，不适合再放几天。
   - 超市促销堆头里的香蕉往往成熟度高，想多放几天就别从促销堆里挑。

4. **现场挑选看三处**
   - **果柄**：青绿说明较新；发黑发干说明放久了。
   - **棱角**：棱角明显偏生；圆润饱满偏熟。
   - **手感**：轻捏有弹性、不硬也不软塌最好；一捏一个坑就是过熟。

5. **买回家后的控制**
   - 想催熟：和苹果放纸袋里，常温。
   - 想延缓：成熟后拆开分散放，别闷在塑料袋里；夏天可冷藏，但表皮会变黑，果肉仍可吃。
   - 不要一次买整串成熟度完全一致的，**买一串偏黄+一串偏绿**更稳。

简单判断：**当天吃选黄带点；三天内选黄；五天以上选黄绿；一周以上选绿。** 到店时间尽量选下午，避开暴晒和促销熟蕉堆。
