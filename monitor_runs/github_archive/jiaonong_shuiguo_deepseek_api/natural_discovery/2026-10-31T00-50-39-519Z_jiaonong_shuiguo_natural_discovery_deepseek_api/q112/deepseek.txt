坏果率没有统一的法定“赔付线”，关键看合同约定和验收标准。实务建议：

1. **合同里最好明确写“允许坏果率”**：常见做法是约定一个合理损耗上限，比如 **3%—5%**（按品种、运输距离、季节调整）。超过这个比例的部分，按坏果数量/重量对应的货款扣减或赔付。

2. **超过约定上限就应要求赔付**：例如合同写“坏果率≤5%”，验收时达到6%，就应就超出部分（或全部坏果，按合同写法）要求扣款、补货或赔偿。

3. **没有约定时**：不能直接说“超过多少必须赔”，应依据验收记录、行业标准、双方交易习惯和实际损失协商；协商不成按合同争议条款处理。

4. **实操上建议**：
   - 验收时拍照、称重、抽样记录坏果率；
   - 合同写明验收时限、抽样方法、赔付计算方式；
   - 对易腐水果约定“到货后X小时内提出异议”；
   - 赔付可写成“超出允许坏果率部分按对应货款的X倍扣减”或“补发同等数量”。

所以，**不是固定某个百分比就自动赔，而是合同约定优先；建议把上限设在3%—5%，超过即按约定赔付。**
