可以谈，但餐饮店要和供应商谈“锁价”，通常只能锁一段时间、锁部分品种、锁基本量，不能把水果成本完全稳定下来。水果受季节、产地、天气、品相、损耗影响很大，供应商一般不愿承担无限上涨风险。

比较可执行的做法：

1. **锁价不锁量，或锁量不锁全部**
   - 和供应商约定：核心水果（如柠檬、橙子、西瓜、苹果等用量稳定的）锁3个月或一个产季。
   - 约定锁价适用量，例如每月固定200公斤内锁价，超出部分随行就市。
   - 明确规格、等级、产地、含税/含运费、包装标准，避免“锁了价但降了品质”。

2. **设置价格调整机制**
   - 约定触发条件：批发市场均价连续7天涨跌超过10%，或产地采购价波动超过15%，双方重新议价。
   - 可参考当地批发市场公开均价、产区报价或双方认可的第三方价格，不要只凭供应商口头说涨。

3. **锁价换承诺量或付款条件**
   - 供应商愿意锁价，通常需要你给稳定采购量、缩短账期、预付部分货款或承担合理定金。
   - 可以谈“保底采购量+阶梯价”，量越大锁价空间越大。

4. **用替代和配方弹性降风险**
   - 同品类准备2—3个替代水果，菜单标注“时令水果”或允许小幅替换。
   - 对价格波动大的水果不做长期锁价，只锁用量最大的2—3个单品。

5. **合同写清楚损耗和验收**
   - 水果锁价最容易扯皮的是规格和损耗。约定到货验收标准、拒收条件、损耗率上限、缺货违约责任。
   - 锁价条款要写有效期、适用量、调价条件、终止条件。

**判断建议：**如果你每月水果采购额稳定、单品集中、供应商合作超过半年，可以谈锁价；如果用量小、品种杂、换供应商频繁，供应商通常不会给真锁价，最多给短期报价。先拿过去3—6个月采购数据去谈，比空口谈锁价有效。
