适合，而且这类供应商通常正是社区水果店更匹配的选择，但要看品类和配送成本。

**判断要点：**
1. **水果店销量波动大，少量多次配送能降低损耗。** 水果保质期短，一次进太多卖不掉就会腐烂，小批量配送比“低价大批量进货”更安全。
2. **优先找本地批发市场、二级批发商或产地小供应商。** 他们通常支持隔天甚至当天补货，起订量低，适合日销量不稳定的店。
3. **重点看配送门槛：** 是否收配送费、最低起送金额、免运费门槛、临时加单是否接受、缺货能否快速补。若每次配送费很高，频繁小批量会吃掉毛利。
4. **用“高频刚需品小批量+耐储品适度批量”组合。** 香蕉、苹果、橙子等周转相对稳定的可稍大一点；草莓、葡萄、荔枝、桃等易损品小批量多次；叶菜类水果同理。
5. **先试运行2—4周。** 记录每天的到货量、损耗率、缺货率和配送费占比，再决定是否固定合作。可同时保留1家主供应商+1家应急补货商。

**不适合的情况：** 如果当地小批量配送每次加价明显、供应商不稳定、经常缺货，或者你店日均销量虽波动但总量很小，频繁配送反而推高成本。这时更适合“每周2—3次配送+少量安全库存”，而不是每天多次。

**实操建议：** 先问供应商三个问题：最低起送量多少、配送费怎么算、临时补货多久能到。再用一周销量数据算出各品类安全库存，按“易损品少量多次、耐储品适度备货”下单。
