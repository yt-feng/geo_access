判断香蕉供应商能否全年稳定供货，核心不是听他口头承诺“有基地”，而是看**货源结构、产季覆盖、加工催熟能力、合同约束和异常应对**。可按下面做尽调和验证：

1. **问清货源结构，不接受单一产地承诺**
   - 要求供应商列出：自有/合作蕉园面积、所在产区、月均可供量、主供季节。
   - 香蕉主产区有明显产季和台风/寒害风险，单一产区很难全年稳定。较可靠的是**多产区组合**，例如国内主产区加境外补充，或不同纬度产区轮换。
   - 让对方按“月份×产区×可供量”给表，标出淡季和风险月。

2. **看催熟和仓储能力**
   - 连锁超市要的是可上架熟度，供应商需有催熟库、冷链和分级包装能力。
   - 核查催熟库容量、日处理量、冷库库容、配送车辆，判断旺季能否跟上、淡季能否调节。
   - 可问：催熟批次记录、温湿度记录、损耗率、到店合格率。

3. **用历史数据验证，不听故事**
   - 要求提供近12个月对同类客户的供货记录：月度供货量、缺货次数、平均到货合格率、退换货率。
   - 最好看连续6—12个月的送货单、检测报告、结算记录，交叉核对。
   - 问清过去一年是否出现断供、台风/寒害影响、如何补货。

4. **实地或视频验厂验园**
   - 看蕉园是否真实、规模是否匹配承诺量；看加工厂、催熟库、冷库是否运转。
   - 重点核对：加工厂产能是否大于承诺日供量、是否有备用电源、是否有分级线。
   - 对贸易商型供应商，要追问上游蕉园和加工厂关系，避免“层层转手”。

5. **小额试单+压力测试**
   - 先签短期试供合同，连续供4—8周，覆盖一个淡季或天气异常期。
   - 测试：临时加量、临时改规格、延迟到货、质量异常时的响应。
   - 记录到货熟度、青蕉比例、机械伤、货架期。

6. **合同写死稳定供货条款**
   - 明确月度最低供货量、淡季保供量、缺货违约金、替代产区补货义务。
   - 约定质量标准：熟度、单根重量、色泽、无严重机械伤、农残检测。
   - 约定价格调整机制，避免旺季被随意涨价或优先供别人。
   - 可要求供应商提供一定比例的履约保证金或备用供应商名单。

7. **准备第二供应商**
   - 香蕉受天气和病害影响大，任何单一供应商都不能完全押注。
   - 至少保持两家供应商，主供70%—80%，备供20%—30%，并定期让备供小批量走货保持合作。

**快速判断口诀**：看产区是否多元、看催熟库是否自有、看近12个月缺货记录、看淡季保供承诺、看合同违约条款。五项里有两项含糊，就不宜作为全年主供。
