判断能不能稳定按规格送货，别只看样品和报价，要按“规格可量化、产能可验证、批次可追溯、违约有成本”四件事去核。给你一套可直接执行的判断方法：

**1. 先把规格写成可验收标准**
不要写“中大果、新鲜”，要落到验收表：
- 品种/产地/季节窗口；
- 单果重量区间、果径、成熟度（如糖度、色泽、果眼深浅）；
- 允许缺陷：黑心、机械伤、冠芽损伤、腐烂比例上限；
- 包装：箱规、净重、每箱果数、托盘/冷链要求；
- 到货温度、到货时限、抽检比例和判定规则。
规格越可量化，供应商越难“按心情送货”。

**2. 验证真实产能，不看口头承诺**
要求供应商提供：
- 自有基地/合作基地面积、当前在田面积、预计月供量；
- 近3个月同类客户的实际送货记录（可脱敏）；
- 加工分选线照片/视频、冷库容量、日处理能力；
- 旺季同时服务哪些客户，你的订单占其产能比例。
关键判断：**你的单量不能超过其旺季可分配产能的30%—40%**，否则旺季必被挤占。

**3. 做“小批量多批次”压力测试**
先签1—2个月试供，不一次性给大单：
- 每周固定2—3车，连续4—6周；
- 每车按验收表抽检，记录重量合格率、缺陷率、到货准时率；
- 故意设一次临时加量20%—30%的测试，看响应速度；
- 记录异常处理：换货时限、补货是否影响门店。
试供期合格率稳定在98%以上、准时率95%以上，再谈主供。

**4. 查供应链上游是否单一**
问清楚：是自有基地、长期合作基地还是市场代采。
- 市场代采型最不稳定，旺季价格一涨就换货；
- 单一基地要问灾害预案和替代产区；
- 要求提供至少两个产季/产区的备份方案。
没有备份产区的供应商，遇到台风、寒潮、雨季就会断供。

**5. 合同里把“稳定”变成钱**
必须写进合同：
- 规格不符的扣款/退货标准，按批次而非按月结算；
- 延迟到货违约金，按小时或按车计；
- 连续2—3批不合格的停供/替换条款；
- 旺季保供量、价格调整机制（挂钩什么指数、提前几天通知）；
- 质量保证金或账期约束。
**没有违约成本的“保证稳定”等于没保证。**

**6. 看现场和追溯**
实地或视频验厂：分选、称重、装箱、冷库、装车环节是否可控；每批货能否追溯到地块/批次/采摘日期；是否有农残检测报告和到货快检能力。连锁茶饮对农残和腐烂率敏感，追溯不到批次的供应商，出问题会连累门店。

**7. 用数据做月度评分**
建立供应商评分表：准时率、规格合格率、腐烂率、异常响应时长、补货成功率。连续两个月低于阈值就降级或引入第二供应商。**永远保留第二供应商**，主供占比控制在60%—70%，这是稳定供货的底线。

一句话：先量化规格，再用小批量多批次试出真实履约能力，最后用合同和第二供应商把风险锁住。样品好不代表能稳定送，试供数据和违约条款才是判断依据。
