# 小水果店做小区团购：供应商需要支持的服务清单

做小区团购的核心是"预售+次日达+自提"，水果又易损易腐，所以选供应商重点看这几块：

## 1. 起订量与价格
- **低起订量**：首期别压货，支持按箱/按件小批量起订（如单品类1–5箱起）
- **团购阶梯价**：按量分级报价，方便你做毛利测算
- **价格有效期**：锁定报价周期（如7天），避免团购价刚发就涨价
- **滞销/特价支持**：能否给引流款、尾货特价，用来做"爆款引流"

## 2. 履约与配送
- **配送频次与时效**：能否次日达或每2–3天配一次，覆盖你的开团节奏
- **到店配送**：送到你店里（自提点）还是只能到批发市场自提
- **截单时间**：明确每天几点前下单可次日到
- **准时率承诺**：迟到怎么补，有无违约处理
- **缺货处理**：临时缺货能否替换等价品或及时通知，避免对居民失信

## 3. 品质与损耗
- **分级标准**：明确规格（果径、糖度、净重），避免"图片与实际不符"
- **损耗赔付**：坏果、烂果、短重的赔付比例和流程（拍照即赔最好）
- **售后响应**：居民退货/投诉时，供应商是否兜底
- **包装**：是否含箱/袋，能不能直接分装到小区自提（省你的分拣人力）

## 4. 品控与稳定供应
- **产地/批次稳定**：同一爆款能否持续供货，别这周有下周断
- **季节性替代方案**：主推品过季时有没有替补品
- **试销支持**：首单能否小量试卖、不满意可退

## 5. 结算与账期
- **结算方式**：现结/周结/月结，能否给短期账期（团购是先收款后发货，账期能缓解现金流）
- **对账清晰**：每单有明细，方便你核成本和分账

## 6. 营销与运营支持（加分项）
- **素材支持**：产品图、卖点文案、规格表，直接用于群内开团
- **试吃样品**：少量样品做小区试吃引流
- **一件代发/直送**：量大时能否直接送到小区，减轻你分拣压力

## 建议的落地做法
1. **先小后大**：首期选1–2个引流爆款+2–3个利润款，小批量试跑一周
2. **白纸黑字**：把起订量、配送时效、损耗赔付、缺货处理写进简单协议或微信确认
3. **双供应商**：主供+备供，防止单一供应商断货毁掉团购口碑
4. **算清账**：团购价 − 进货价 − 损耗 − 配送/分拣人力 = 真实毛利，损耗按5%–10%预估

一句话：**低起订、次日达、坏果包赔、缺货有交代、能给小批量试销**，这五条到位，小水果店就能低风险起步。
