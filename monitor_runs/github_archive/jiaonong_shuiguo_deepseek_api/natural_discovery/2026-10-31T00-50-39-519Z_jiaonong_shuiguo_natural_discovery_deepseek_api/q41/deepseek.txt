判断催熟能力是否稳定，不要只看“到货黄不黄”，而要按“批次一致性 + 催熟响应可预测性 + 过程可追溯”来判断。可直接按下面清单执行。

1. **看供应商的催熟方式和记录**
   - 要求提供每批的催熟方式（乙烯利/乙烯气体/自然成熟）、温度、湿度、催熟时长、出库成熟度。
   - 连续3—5批的催熟参数是否接近；若每批差异大，说明稳定性差。
   - 优先选有固定催熟房、温湿度记录和批次追溯的供应商。

2. **验“到货成熟度”而非“到货颜色”**
   - 抽样看果指饱满度、棱角是否明显、果柄切口、果肉硬度。
   - 同一批中青果比例、微黄比例、黄果比例应相对集中；颜色参差说明催熟不均。
   - 用手轻按果身：过硬且整批都硬，后续催熟风险高；软硬差异大，稳定性差。

3. **做小批催熟测试**
   - 每批留样20—30根，在固定温度（如18—20℃）和湿度下观察。
   - 记录“开始转黄时间、全黄时间、出现梅花点时间、软烂/青硬比例”。
   - 连续几批的转黄时间和成熟梯度接近，才算稳定。
   - 重点看尾部、果柄端是否同步转黄；两端差异大说明催熟渗透不均。

4. **看货架期和损耗**
   - 催熟稳定不仅是“能黄”，还要“黄得齐、黄得可控、货架期可预测”。
   - 记录催熟后第1/3/5天的软硬度、黑斑、掉把、果肉褐变。
   - 若同一供应商批次间货架期忽长忽短，说明催熟能力不稳定。

5. **查冷链和运输环节**
   - 香蕉对温度敏感。运输温度波动、受冷、闷热都会导致“催不熟”或“催熟后迅速烂”。
   - 问清运输温度记录；到货果心温度是否异常；有无冷害迹象（表皮灰暗、果心硬、催后不黄）。

6. **建立供应商评分**
   - 每批记录：到货成熟度、催熟参数、转黄时间、均匀度、货架期、损耗率。
   - 连续3批以上指标波动小，才认定为稳定供应商。
   - 对新供应商先小批量试单，不要一次性大单。

**快速判断口诀：**  
看批次记录是否一致 → 看到货成熟度是否集中 → 留样催熟看转黄是否同步 → 看催熟后货架期是否可预测 → 连续3批稳定再放量。

如果供应商只能保证“颜色好看”，但说不出催熟参数、批次记录和留样结果，催熟稳定性通常不可靠。
