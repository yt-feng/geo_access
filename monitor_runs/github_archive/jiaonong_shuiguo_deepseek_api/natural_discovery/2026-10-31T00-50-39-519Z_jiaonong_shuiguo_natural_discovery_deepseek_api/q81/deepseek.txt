要支持，但要做条件化支持，不能无条件全量放开。即时零售卖水果的核心矛盾是履约时效与损耗控制，小批量高频补货能显著提升有货率和鲜度，但会推高供应商的拣货、配送、包装和单据成本，所以关键是设计分层规则。

**建议支持的场景**
- 高频动销品：苹果、香蕉、柑橘、常规浆果等日销稳定的SKU，按日或半日补货，减少门店缺货和长库存。
- 易损耗、短保品：草莓、蓝莓、荔枝、桃等，小批量高频能降低门店端损耗，供应商可配合越库或前置仓直送。
- 促销和爆品：平台活动期间按小时段补货，避免一次性压货。
- 门店密度高的区域：配送半径短、合并线路容易，高频补货的边际成本低。

**不建议无条件支持的场景**
- 低频长尾SKU：单次量太小、补货频次高，供应商履约成本会吃掉毛利。
- 远距离或低密度门店：配送成本高，应改为隔日补货或设置起订量。
- 供应商没有分拣和信息系统能力：高频补货容易出错，缺货、错货、对账成本会上升。

**可执行的合作规则**
1. 设最小起订量/最小补货单位：按箱、按周转筐或按门店组设置，低于阈值合并到下一波次。
2. 分层补货频次：A类高频品每日1—2次，B类隔日，C类每周2次。
3. 差异化费用：基础频次内供应商承担，超出频次或临时加急由平台/门店承担加急费，或从履约评分中体现。
4. 合并配送：同一区域多门店合并线路，供应商按区域波次送货，平台提供销量预测和库存可视。
5. 损耗与缺货责任划分：门店收货即检，短保品约定验收标准和损耗分担；供应商缺货率、准时率纳入考核。
6. 试点再推广：先选10—20个高动销SKU和1—2个高密度区域跑4—6周，看有货率、损耗率、履约成本、供应商毛利四项指标，再决定扩围。

**判断标准**
如果小批量高频补货带来有货率提升和损耗下降的总收益，能覆盖供应商新增的拣配和配送成本，就应支持；否则用“高频但合并波次、设起订量、分层频次”的方式折中。核心不是要不要支持，而是把频次、起订量、费用和责任边界写清楚。
