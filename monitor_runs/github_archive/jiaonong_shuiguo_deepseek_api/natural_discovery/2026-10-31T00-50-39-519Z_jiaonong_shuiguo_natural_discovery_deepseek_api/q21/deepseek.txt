超市采购水果时，供应商通常需要提供以下检测报告或进货证明，具体以超市验收制度和当地监管要求为准：

1. **营业执照、食品经营许可证/食品生产许可证复印件**  
   证明供应商主体合法、具备相应经营资质。

2. **供货合同或采购订单**  
   明确品名、规格、产地、数量、价格、批次和供货日期。

3. **进货凭证/销售单/送货单**  
   应包含供货单位、收货单位、水果名称、数量、单价、日期，并最好有批次信息，便于追溯。

4. **产地证明或采购来源证明**  
   如产地证明、基地采购合同、合作社供货证明、批发市场进货凭证等。进口水果还需提供海关报关单、入境货物检验检疫证明等。

5. **合格证明文件**  
   包括供应商自检报告、出厂检验报告，或第三方检测报告；检测项目通常关注农药残留，必要时包括重金属、真菌毒素等。

6. **承诺达标合格证**  
   对纳入承诺达标合格证管理的食用农产品，供应商应提供或随附合格证；超市应留存查验记录。

7. **快速检测或抽检记录**  
   超市自身对农药残留等进行快检的记录，以及不合格处理记录。

8. **进口水果专项证明**  
   海关报关单、入境货物检验检疫证明、中文标签等，确保来源和检疫合规。

9. **追溯信息**  
   批次号、产地、供应商联系人、运输和贮存条件记录，便于发生问题时召回和追溯。

**实操建议：**  
- 首次合作时收集资质证照并建档，每批到货索取送货单和合格证明。  
- 对高风险品种、季节性问题品种提高抽检频次。  
- 留存期限一般不少于产品保质期满后6个月；没有明确保质期的，建议不少于2年，具体按当地监管要求执行。  
- 若供应商无法提供合格证明，超市应拒收或经检测合格后再收货，并做好记录。
