茶饮店采购香蕉，核心是把“到货熟度”和“使用节奏”分开管：采购时按用途定熟度档次，到货后分批催熟/延缓，避免同一批同时全熟。

**1. 按用途定采购熟度**
- **做冰沙/奶昔/捣碎果肉**：到货用**7～8成熟**，果肉已软、甜度上来，但表皮还带少量绿或刚转黄。到店后可放1～2天再用。
- **做甜品装饰、切片、顶料**：用**8～9成熟**，表皮全黄、少量芝麻点，果肉成型不烂，便于切片。
- **做香蕉泥、酱、烘焙馅料**：可用**9成熟到起芝麻点**，甜度高、香气足，但必须当天或次日用完。
- **不建议采购全青或已大面积黑斑的香蕉**：全青催熟不可控，黑斑多则货架期极短、易发酵。

**2. 采购时看“色卡+手感+批次”**
- 要求供应商按**色度分级**供货，比如1～7级色卡，合同里写明到货色级范围，不接受混级。
- 现场抽检：看**棱角**是否明显，棱角越明显越生；摸**果身**，要硬中带弹，不能软塌；看**果柄**，青绿为生，枯黑为过熟。
- 同一批尽量选**成熟度接近**的，避免一箱里有的青有的黑。
- 问清**采摘/催熟日期**和运输温度，香蕉低于13℃易冷害，表皮发灰变黑但果肉仍硬，这种不要收。

**3. 到货后分批管理**
- 到货先**拆箱通风**，不要闷在塑料袋里，乙烯积聚会让整批快速变熟。
- 按“今天用、明天用、后天用”分成3批：今天用的放室温；明天用的可放阴凉处；后天用的**冷藏延缓**（注意冷藏会让表皮变黑，但果肉可继续用，适合做泥/酱，不适合装饰）。
- 需要加速熟化时，可和**苹果/梨**同放纸袋，利用乙烯催熟；需要延缓时，**单独存放、通风、避免挤压**。
- 每天按色卡挑出过熟果，优先做香蕉泥、酱或员工试饮，不要等全黑再处理。

**4. 库存与订货建议**
- 茶饮店香蕉用量通常不大，建议**少量高频**订货，每次订**2～3天用量**，不要一次囤一周。
- 设“安全库存+熟度库存”：比如常备1天可用熟蕉、1天半熟蕉、半天催熟蕉。
- 夏季高温熟得快，订货熟度可**下调半级**；冬季可**上调半级**。
- 记录每天损耗和实际用量，两周后就能算出适合你店的订货量和熟度档位。

**简单执行标准：** 装饰用8～9成熟全黄少斑；打泥/冰沙用7～8成熟黄带绿；到货分三批，今天用室温、明天用阴凉、后天用冷藏延缓；每次只订2～3天量，每天挑过熟果优先消耗。
