小面积便利店的思路不是“品类齐全”，而是“精选刚需+极短周转”，用少量SKU换高周转，损耗自然可控。可执行建议如下：

**1. 品类控制：只做3类左右，SKU控制在5~10个**
- 必选引流品：香蕉、苹果/柑橘这类耐放、认知度高、单价低的。
- 即食型：小番茄、葡萄小盒、切果盒（视是否具备鲜切条件）。
- 应季单品：当季只上1~2个，如夏天西瓜切盒、冬天砂糖橘。
- 不做：高损耗浆果（草莓、蓝莓）、大件整瓜、需要催熟/易碰伤的多品种混摆。每增加一个SKU，损耗和排面占用都上升，小店宁少勿多。

**2. 采购量：按“日销×1.2~1.5”订货，少量高频**
- 先跑2~3周记录每个单品日销量，再定订货量；初期宁少勿多，卖断比烂掉好。
- 叶菜/浆果类不碰或只做预订；耐放品类可2~3天一次，易损品每日少量补。
- 与附近批发商或水果店谈小批量、多频次配送，减少一次囤货。

**3. 收货和陈列**
- 收货当场分级：碰伤、软烂的当场拒收或折价，别进正价排面。
- 用统一小盒/小份包装，控制单份量，降低顾客挑拣造成的二次损伤。
- 陈列只留1~2层，先进先出，勤翻检；避免堆叠挤压。

**4. 损耗管理：设红线+动态处理**
- 给每个单品设损耗上限（如3%~5%），超了就减SKU或减订货量。
- 每天固定时间（如下午/闭店前）把临期品做组合果盒、打折或员工餐，别等到烂了才处理。
- 建立简单台账：进货量、销量、报损量，每周复盘，砍掉连续两周损耗高的单品。

**5. 兜底策略**
- 水果不是便利店必做项。若周边已有水果店/商超，可只保留香蕉、苹果等超耐放引流品，或直接放弃鲜果，改做果切/果干等低损耗替代。
- 先小批量试销2周，用数据决定留哪些、砍哪些。

核心判断标准：**单品日均销量能否覆盖其损耗和排面成本**，覆盖不了就下架。
