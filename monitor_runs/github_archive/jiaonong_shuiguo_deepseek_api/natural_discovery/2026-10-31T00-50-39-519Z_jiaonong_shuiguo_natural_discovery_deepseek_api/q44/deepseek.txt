判断供应商售后响应是否稳定，不要只听口头承诺，建议用“可验证的动作”去测。可以按下面几步做：

**1. 先看合同里有没有可执行的售后条款**
重点看是否写清：
- 响应时限：比如质量问题几小时内回复、多久给处理方案；
- 到货异常处理：缺斤少两、烂果、熟度不符、批次不合格怎么赔/换/退；
- 责任边界：运输损耗、仓储损耗、到货验收标准分别谁承担；
- 赔付方式：补货、扣款、折价、退货的触发条件和时限；
- 对接人和升级渠道：是否有固定业务+售后负责人，不能只留一个销售微信。

如果合同里只有“保证质量、及时处理”这类模糊话，稳定性基本不可判断。

**2. 用真实小单做压力测试**
先下1—2个小批量试单，故意设置可验证场景：
- 到货后按标准验收，记录烂果率、青熟度、单果重量、箱内损耗；
- 发现异常后在工作时间外发一次售后请求，看多久回应；
- 要求对方给出书面处理方案和时间点，观察是否按承诺执行；
- 看补货/退款是否按约定时间到账。

**3. 重点问菠萝和香蕉的专项售后能力**
这两种水果催熟和损耗特性不同，要问具体：
- 菠萝：黑心、水心病、烂眼、成熟度不齐怎么判责？到货后几天内可提异议？
- 香蕉：青熟度、催熟后坏果、运输压伤、批次不匀怎么处理？是否提供催熟建议和异常批次追溯？
- 是否可按批次留样、提供产地/加工厂信息、出现集中问题时能否快速换批。

**4. 查历史响应记录，而不是听案例**
要求供应商提供近3个月同类商超客户的售后记录摘要，至少包括：异常类型、提出时间、回复时间、处理结果。可脱敏，但要看频次和闭环率。没有记录或只给“合作很好”的评价，参考价值低。

**5. 做一次模拟异常演练**
在试单阶段提出一个明确售后诉求，比如“本批次香蕉到货青度偏高且压伤比例超验收标准，请24小时内给换货或折价方案”。观察：
- 是否有人接；
- 是否推给销售拖延；
- 是否按合同给方案；
- 是否按时闭环。
一次演练比十次承诺更能判断。

**6. 看组织配置**
稳定售后通常有：固定售后对接人、备用联系人、异常工单/群记录、批次追溯能力、区域仓或就近补货能力。只有销售一人对接、没有备货仓、没有批次记录的供应商，响应稳定性通常较弱。

**实操建议：**
先小单试合作，把验收标准、响应时限、赔付规则写进合同或订单确认单；连续跟踪2—3个批次，记录每次异常从提出到闭环的小时数和结果。连续两次超时或不按方案执行，就应降级或更换供应商。核心判断标准不是“态度好不好”，而是**有条款、有人接、有时限、能闭环、可追溯**。
