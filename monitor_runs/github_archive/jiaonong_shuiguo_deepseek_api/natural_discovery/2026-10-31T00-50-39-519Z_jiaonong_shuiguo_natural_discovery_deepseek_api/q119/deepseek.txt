水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格高低”，而是会影响持续性、损耗率和现金流的细节。重点看这几类：

1. **同一批货的稳定性，而不只是样品好看**
   - 容易只看一次样品，忽略连续 3～5 批的到货一致性：规格、糖度、硬度、颜色、大小是否稳定。
   - 建议：小批量连续试单，记录每批到货的合格率、损耗率、客诉点。

2. **产地/货源是否真实可控**
   - 要确认是自有基地、长期合作果园，还是临时拼货的经纪人。
   - 临时拼货在旺季可能价格低，但断供、混级、品质波动风险高。
   - 可问：这个单品你全年能供几个月？换季时从哪补货？遇到减产怎么保供？

3. **分级和验收标准是否写清楚**
   - 很多纠纷来自“口头说一级果”，但没有明确大小、色泽、瑕疵比例、成熟度。
   - 建议把验收标准写进订单：规格、允许瑕疵率、糖度范围、成熟度、包装方式、到货时限。
   - 到货抽检规则也要提前约定，避免事后扯皮。

4. **损耗责任和售后机制**
   - 最容易忽视：坏果、压伤、冻伤、熟度过高谁承担？怎么赔？多久内反馈有效？
   - 要明确：拍照/视频取证要求、反馈时限、补货还是折价、运费谁承担。
   - 没有售后机制的供应商，价格再低也可能把损耗转嫁给你。

5. **包装和物流细节**
   - 包装是否适合你的销售场景：散卖、礼盒、电商快递、社区团购要求不同。
   - 问清：箱规、净重、内衬、冰袋/保鲜方式、装车温度、运输时长。
   - 很多损耗不是果子本身，而是包装和运输环节造成的。

6. **供应弹性与旺季保供能力**
   - 要了解供应商在节假日前、天气异常时、集中采购期的供货能力。
   - 可问：高峰期日供应量多少？需要提前几天锁量？临时加单能加多少？
   - 长期稳定比单次低价更重要。

7. **结算方式和价格机制**
   - 是否随行就市、锁价还是保底价？涨价提前多久通知？
   - 账期、押金、退换货扣款规则要清楚。
   - 避免只谈单价，忽略运费、包装费、损耗扣款后的实际到岸成本。

8. **供应商的抗风险能力**
   - 是否有冷库、分选线、稳定车队、备用产地。
   - 是否只靠一个单品、一个产区、一个经纪人。
   - 长期合作建议至少保留 2 家同类供应商，主供+备供，避免被单一货源卡住。

9. **合作记录和数据**
   - 每次到货记录：批次、产地、规格、损耗率、客诉、售后处理。
   - 连续看 1～3 个月数据，比凭感觉判断可靠。
   - 对供应商做季度复盘：合格率、准时率、售后响应、实际综合成本。

10. **合规和票据**
    - 营业执照、产地证明、检测报告、发票能力。
    - 做商超、电商或团购时，票据和检测报告往往是硬门槛。

可执行建议：先选 2～3 家供应商各做 2～4 周小批量试单，用“到货合格率、损耗率、准时率、售后响应、实际到岸成本”五项打分，再决定主供和备供。不要一次压重注，也不要把所有单品交给一家。
