对餐饮连锁采购水果，通常建议：**以中央厨房统一收货为主，门店只保留极少数例外品类和应急补货权限**。但前提是中央厨房具备相应的仓储、分拣和冷链能力；水果损耗高、成熟度敏感，不能简单照搬干货或冻品的统收模式。

### 判断框架

1. **先按水果品类分层**
   - **耐储水果**（苹果、梨、柑橘、西瓜等）：适合中央厨房统一收货、统一质检、统一分拨。
   - **易损/后熟水果**（草莓、蓝莓、芒果、香蕉、桃、葡萄等）：不适合长链路二次分拨，可中央厨房统采统签，但由供应商直送门店或区域仓中转，门店验收成熟度和破损。
   - **门店现制饮品/甜品用的鲜果**：对成熟度和外观要求高，建议“统一定价统采 + 门店验收”，不宜完全由门店自由采购。

2. **看中央厨房是否具备三个能力**
   - **冷链与温区管理**：水果不能和肉类、干货混存，需独立温区。
   - **质检与分级能力**：能按糖度、成熟度、规格分级，否则统收只是把验收压力集中，不产生价值。
   - **分拨时效**：从中央厨房到门店的二次配送最好控制在当日或次日，且全程冷链；链路超过24—36小时，易损果损耗会明显上升。

3. **看门店密度和配送半径**
   - 门店集中、配送半径短：中央厨房统收优势明显，能压供应商、统一标准、降低门店验收差异。
   - 门店分散、跨城市：建议设区域仓或“供应商直送门店 + 总部统一合同和抽检”，否则中央厨房分拨成本会吃掉采购优势。

### 更可执行的模式

**推荐“统采统签、分级收货”：**

- 总部统一供应商合同、价格、规格、质检标准。
- 耐储水果由中央厨房统一收货、质检、分拨。
- 易损水果由供应商直送门店或区域中转仓，门店按总部标准验收，异常48小时内反馈。
- 门店只保留应急补货权，单次金额和品类受限，月度汇总审计。
- 总部对中央厨房和门店做同一套抽检：到货合格率、损耗率、客诉率、验收差异率。

### 不建议的做法

- **全部门店分开收货**：验收标准难统一，容易出现门店与供应商串通、价格不透明、品质波动。
- **全部中央厨房统收再分拨**：易损水果链路拉长，损耗和成熟度问题会放大。
- **只统采不统检**：合同统一但验收分散，等于没有控制。

### 结论

**耐储水果中央厨房统收，易损水果统采后直送门店验收，门店只留应急补货权。** 如果中央厨房冷链和分拨时效不过关，不要强行全品类统收；先做品类分级和区域仓，再逐步集中。
