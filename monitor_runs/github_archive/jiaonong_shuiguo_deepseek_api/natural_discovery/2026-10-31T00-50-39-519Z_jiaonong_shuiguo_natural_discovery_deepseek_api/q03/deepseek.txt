先给判断标准：夫妻店第一次试单，不要一次“进齐”，而要分三轮试：先试少品类、小批量、可退换；再比稳定性和损耗；最后才谈长期价。香蕉、苹果、橙子正好代表三种不同风险，要分开看。

**一、试单前的准备**
- 先定3个硬指标：到货损耗率、斤两是否足、缺货/换货是否痛快。
- 首单不要超过2—3个单品、每品1—2箱/件，宁可第二天补货。
- 问清报价口径：是毛重还是净重、含不含箱皮/垫纸、是否送到店、几点到、坏果怎么赔。
- 留证据：到货当场拍照、称重，记录日期和批次。

**二、三个品类怎么试**
1. **香蕉**：风险最高，看成熟度和催熟稳定性。
   - 首单只拿1件，要求“青黄适中、可后熟”，不要拿已经全黄或发青发硬的。
   - 到货看：果指饱满、无大面积黑斑、切口干净、箱内无挤压伤。
   - 试卖3天：记录每天变黄、黑斑、掉把、软烂数量。若第2天就大面积过熟，说明供货批次或催熟不稳，换。
   - 不要一次压太多，香蕉周转快但损耗也快。

2. **苹果**：风险中等，看硬度和内部伤。
   - 首单拿1箱，要求大小均匀、表皮无磕碰、果柄完整。
   - 当场抽5—10个切开看：有无霉心、水心、内部褐变；捏一下硬度，太软说明库存久。
   - 试卖5—7天：记录磕碰果、软果、烂果比例。苹果耐放，但“外表好、里面坏”最坑，抽切很关键。

3. **橙子**：风险在重量和水分。
   - 首单拿1箱，重点称净重，别只看箱标。
   - 抽切2—3个看：皮厚不厚、汁水足不足、有无干瓣、霉变。
   - 试卖5—7天：记录失水皱皮、霉变、酸度不稳定。橙子若净重不足或干瓣多，直接淘汰。

**三、三轮试单节奏**
- 第一轮：每品小批量，只验“货对不对、斤两足不足、坏果赔不赔”。
- 第二轮：对第一轮表现最好的1—2家各补一次同品，验“稳定性”，别只看一次好货。
- 第三轮：少量混拼，验送货时效、缺货替换、售后响应。三轮都稳，再谈周配或长期价。

**四、当场就要问清的话**
- 坏果赔付比例和时限？是拍照即赔还是下次补？
- 临时加单/减单截止几点？迟到怎么处理？
- 同品不同批次价差多大？旺季是否保供？
- 能否固定送货时间，避开你早市高峰？

**五、建议的淘汰线**
- 香蕉到货2天内黑斑/软烂超过一成，或后熟不齐，换。
- 苹果抽切发现霉心/内部褐变，或磕碰软果明显，换。
- 橙子净重明显不足、干瓣多、霉变多，换。
- 售后推诿、称重含糊、送货不准时，即使货便宜也不适合长期合作。

一句话：首单像“面试”，香蕉看后熟，苹果看内伤，橙子看净重和汁水；小批量、当场验、留证据、比两轮，再决定长期合作。
