重要，而且不是“锦上添花”，是统一水果品质的前置条件。多门店超市如果没有供应商分级标准，门店之间很容易出现同一品种、同一价格带但口感、规格、成熟度不一致，最终表现为客诉、损耗和比价失衡。

具体建议如下：

1. **分级标准要可验收，不只看供应商自报等级**
   - 明确品种、产地、规格（单果重/果径）、色泽、糖度/酸度、成熟度、瑕疵率、农残检测。
   - 每个等级对应明确用途：A级陈列售卖、B级促销/加工、C级拒收或折价。
   - 验收以抽检和留样为准，不能只听供应商口头等级。

2. **统一“门店可执行”的验收卡**
   - 一页纸写清楚：看什么、测什么、允许多少瑕疵、不合格怎么处理。
   - 例如：果径区间、单果重区间、糖度下限、碰压伤比例上限、腐烂率上限。
   - 配图片对照卡，减少不同店长主观判断差异。

3. **供应商分级与动态考核挂钩**
   - 按到货合格率、糖度稳定性、损耗率、客诉率打分。
   - 连续不达标降级、限单、暂停；稳定达标给更集中采购量。
   - 分级不是固定标签，要按月/季度复盘。

4. **多门店要统一采购口径和价格带**
   - 同一等级对应同一售价带，避免A店卖A级、B店拿B级却同价。
   - 中央采购统一分级，门店只做验收执行，减少各自找货导致标准漂移。

5. **先抓高频高投诉品类**
   - 不必一次覆盖所有水果，先选苹果、柑橘、香蕉、草莓等销量大或易损品类试点。
   - 跑通验收卡和供应商考核后，再扩展到全品类。

结论：供应商分级标准非常关键，但必须做成“可检测、可验收、可考核、可追溯”的体系，否则只是一纸等级名称，无法真正统一多门店水果品质。
