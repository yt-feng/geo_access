# 坏果责任的合同写法建议

核心思路：**把"损耗高不高"从口头担忧变成可测量、可举证、可追责的条款**。批发场景要重点盯三件事——验收标准、验收时限、超损怎么赔。

## 一、先定"什么是坏果"（定量标准）

不要写"坏果""腐烂"这种模糊词，建议按品类写死阈值，例如：

- 腐烂/霉变果：单果腐烂面积超过果面1/3即计为坏果；
- 机械伤：压伤、裂口导致无法正常销售的计为坏果；
- 规格不符：单果重量/直径偏离约定等级范围即计为不合格；
- 明确**抽样方法**：按到货批次随机抽检，抽检比例（如每批抽5%且不少于X箱），抽检不合格率即视为整批不合格率。

## 二、定验收时限和异议程序（最关键）

到货损耗纠纷大多输在"没及时验、没留证据"。条款要写：

- 买方应在到货后 **X 小时内**（生鲜建议24小时内、易腐品类更短）完成验收；
- 验收时**当场拍照/录像并封存样品**，双方签字确认；
- 逾期未提出书面异议的，视为验收合格——这条对卖方有利，买方要争取缩短自己的义务或改为"以实际销售中发现的坏果为准"。

## 三、定责任分担（按损耗率分档）

推荐"**合理损耗 + 超额赔偿**"结构：

| 到货坏果率 | 处理方式 |
|---|---|
| ≤ 约定合理损耗（如3%） | 买方自担，不追责 |
| 3%–10% | 卖方按坏果数量折价补偿或补货 |
| > 10% | 买方可拒收整批，或要求退货退款，运费由卖方承担 |

也可约定"**超额部分按货款比例扣减**"，例如坏果率每超1个百分点扣减对应货款的1.5倍，形成约束。

## 四、定举证与赔付方式

- 坏果认定以**双方共同验收记录**为准；有争议时约定第三方（如市场质检、冷链物流方）复核；
- 赔付方式写清楚：折价扣款 / 补发同等数量 / 退货退款，三选一或按档适用；
- 明确**运费、冷链费、装卸费**在退货时的承担方。

## 五、几个容易踩的坑

1. **只写"卖方保证质量"**——无法执行，必须量化。
2. **验收期过长或过短**：过长卖方不认，过短买方来不及验，按品类实际周转定。
3. **没约定运输环节责任**：若是买方指定物流或自提，途中损耗归属要单独写明（通常谁安排运输谁担途中风险）。
4. **不可抗力与自然损耗混淆**：明确"正常水分流失/轻微外观差异"不算坏果，避免扯皮。

## 一句话模板

> "到货后买方应于24小时内完成抽检验收并书面确认。坏果率≤3%由买方承担；3%–10%部分由卖方按坏果对应货款折价补偿；超过10%买方有权拒收整批，卖方承担退货及往返运费。坏果认定以双方签字验收记录及现场影像为准。"
