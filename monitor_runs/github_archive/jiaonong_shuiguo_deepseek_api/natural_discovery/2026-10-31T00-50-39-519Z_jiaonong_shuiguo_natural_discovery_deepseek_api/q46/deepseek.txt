建议先定用途和门店操作条件，再选形态。结论：

**首选顺序：鲜果 ≥ 冷冻/冷藏果丁 > 果泥**
- **想突出“鲜果感”、做门店招牌菠萝果茶**：买**鲜果**，现切现用。风味最好、卖点强，但损耗和人工最高。
- **出杯量大、追求稳定和效率**：买**冷冻果丁或冷藏果丁**。比鲜果省人工、批次稳定，口感接近鲜果；优先选无糖、无添加、急冻锁鲜的。
- **做冰沙、果泥类、需要统一酸甜和稠度**：买**果泥**。最稳定、最省事，但“鲜果感”弱，且要重点看配料表：选**100%菠萝果泥/果浆**，避开含糖、香精、增稠剂多的“果味酱”。

**采购判断标准：**
1. **菜单定位**：鲜果茶/颜值出品选鲜果或果丁；冰沙、奶昔、混合果茶选果泥。
2. **门店人力**：人手紧、高峰期出杯多，果丁更稳；有切配人手再上鲜果。
3. **损耗控制**：鲜果损耗高，先小批量试；果丁按周用量订货；果泥开封后冷藏时限要问清。
4. **成本**：按“每杯可食用成本”算，不只看每公斤单价。鲜果要算去皮损耗和人工。
5. **标签**：果丁看是否加糖、是否含防腐剂；果泥看果汁/果肉含量和配料表前几位。

**实操建议：**
- 先做**小批量盲测**：同一配方分别用鲜果、果丁、果泥出杯，比较香气、酸甜、纤维感、颜色和成本。
- 菜单可分层：**招牌款用鲜果/果丁**，**走量款用果丁**，**冰沙款用果泥**。
- 若只选一种起步：**选无糖果丁**，平衡风味、效率和稳定性最稳。
