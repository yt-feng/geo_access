酒店采购水果盘原料时，建议把“规格标准”和“外观标准”写进采购单/验收单，并在合同中约定抽检、退换货和扣款规则。可按以下维度要求供应商保证：

**一、通用规格与安全标准**
1. **品种与等级明确**：写明具体品种、产地（如需要）、等级（特级/一级）、单果重或单果直径范围，不接受混级、混品种。
2. **成熟度**：到货时处于“即食或1—2天内可食”的成熟度；不得过生或过熟。需冷链运输的明确到货中心温度（如0—4℃或按品种要求）。
3. **新鲜度**：无萎蔫、无失水皱缩、无发酵异味；叶菜类/浆果类尤其要新鲜。
4. **食品安全**：符合国家食品安全标准；农药残留检测合格；不得使用非法保鲜剂、染色剂、催熟剂超标；必要时要求提供批次检测报告或承诺书。
5. **包装与标识**：包装完好、无挤压；标签含品名、等级、产地、批次/采摘日期、供应商信息；冷链产品有温度记录。
6. **规格公差**：约定允许偏差，如单果重±5%—10%、直径±2—3mm；不合格比例超过约定（如5%）可整批拒收或按比例扣款。

**二、外观标准（按品类细化）**
1. **形状与大小**：果形端正、大小均匀，同一批次一致性高；无明显畸形、双果、裂果。
2. **色泽**：具有该品种成熟时应有的色泽，色泽均匀；无明显青斑、黑斑、褪色或日灼。
3. **表面缺陷**：无腐烂、霉变、虫蛀、虫眼、病斑、机械伤、压伤、冻伤、裂口；允许的轻微瑕疵需约定上限（如面积占比、个数比例）。
4. **清洁度**：无泥土、污渍、药斑、异物；果蒂/果柄处理整齐，不扎手、不藏污。
5. **气味与口感**：无异味、发酵味、苦味；抽检口感符合品种特征。
6. **切配适用性**：用于水果盘时，要求果肉紧实、出成率高、切开后不易褐变或出水；浆果类无软烂渗汁，瓜类无空心、过熟。

**三、验收与责任条款建议**
1. **抽样验收**：按批次随机抽检，记录单果重/直径、缺陷比例、温度、感官指标；留样备查。
2. **退换货**：腐烂、霉变、虫害、异味、农残不合格等为直接拒收项；规格/外观不合格超约定比例可退货或折价。
3. **扣款与赔付**：明确不合格率对应的扣款比例；因原料问题导致客人投诉或食品安全事件的赔偿责任。
4. **批次追溯**：要求供应商提供批次号，便于追溯和召回。

**可直接写进采购要求的简版条款：**
“供应商保证所供水果符合国家食品安全标准，按约定品种、等级、单果重/直径供货，大小均匀、果形端正、色泽正常、无腐烂霉变虫害及明显机械伤，到货成熟度适宜即食，冷链产品到货温度符合要求。验收抽检不合格比例超过5%的，采购方有权拒收或按比例扣款；发现腐烂、霉变、虫害、异味或农残不合格的，整批退货并由供应商承担相应责任。”

具体数值（单果重、直径、允许瑕疵比例、到货温度）需按酒店实际菜单和当地供应情况在采购单中逐项填明，避免只写“新鲜优质”这类无法验收的表述。
