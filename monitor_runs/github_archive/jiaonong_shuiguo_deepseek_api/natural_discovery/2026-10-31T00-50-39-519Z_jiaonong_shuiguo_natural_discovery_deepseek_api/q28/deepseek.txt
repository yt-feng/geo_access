建议先从**香蕉**试起，但把它定位成“引流+走量”的基础进口单品，而不是高毛利精品；菠萝作为第二梯队小批量测试；苹果最后再考虑。理由和可执行判断如下：

1. **香蕉：最适合先引入**
   - 消费频次高、认知门槛低，顾客不需要教育。
   - 进口香蕉（如菲律宾、厄瓜多尔等产地）供应链相对成熟，催熟和周转模式明确。
   - 适合做稳定销量和价格锚点，能带动水果区客流。
   - 风险点：催熟管理、货架期短、损耗控制要求高。建议先小批量固定周配，建立“到货—催熟—上架—折价”的标准流程。

2. **菠萝：适合第二批测试**
   - 进口菠萝有差异化卖点（如金菠萝、甜度稳定），但顾客对品种和成熟度敏感。
   - 整果处理麻烦、去皮损耗和售后问题较多，更适合先做小批量整果加少量鲜切。
   - 建议在香蕉跑通冷链和周转后，用1—2个SKU测试，观察动销和损耗再扩。

3. **苹果：不建议作为第一个进口单品**
   - 国产苹果供应充足、价格带成熟，进口苹果差异化不够强，容易陷入比价。
   - 进口苹果周转慢、占资金，对超市的精品客群和陈列能力要求更高。
   - 除非门店有明确高端客群，否则先放后面。

**落地建议：**
- 第一步：选1个进口香蕉SKU，按周配小批量试销4周，重点看损耗率、周动销、毛利和缺货率。
- 第二步：香蕉稳定后，引入1个进口菠萝SKU做对比测试。
- 第三步：苹果只在有稳定精品需求时再做，优先小盒装或礼盒装，避免大堆头压货。
- 判断标准：若香蕉周损耗可控、动销稳定，再扩品；若损耗高，先改催熟和订货节奏，不要急着加菠萝和苹果。
