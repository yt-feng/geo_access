社区超市每天配送水果，选供应商时按下面条件逐项筛选，能避开大部分坑。

**1. 配送能力（最优先）**
- 是否承诺**每日固定时段送达**，比如早6–8点，赶在开门前到货；临时补货能否当天响应。
- 配送范围是否覆盖你门店，起送量多少，配送费怎么算。
- 有没有**冷链（冷藏/保鲜运输）**，尤其是叶菜、浆果、荔枝这类易损品。
- 缺货、迟到、货损的赔付规则要写进合同。

**2. 货源与品质**
- 货源是产地直采、一级批发市场，还是二批转手——层级越少，价格和新鲜度通常越好。
- 是否支持**按日看样品或验货**，到货后能不能当场挑出坏果退换。
- 损耗率怎么算、坏果怎么赔（按箱赔还是按斤赔），这是社区超市水果生意最容易被吃掉利润的地方。
- 有没有稳定的品类供应，社区店一般需要常备20–40个SKU，供应商能否一站式配齐。

**3. 价格与结算**
- 报价是否**随行就市、每日或每周更新**，避免长期锁价导致品质下降。
- 账期：现结、周结还是月结；有没有押金、最低采购额。
- 对比2–3家的同品报价，注意别只看单价，要算上损耗、配送费后的“到手成本”。

**4. 资质与稳定性**
- 营业执照、食品经营相关资质是否齐全；做生鲜配送是否需要特定许可，按当地规定核实。
- 经营年限、日均配送量、服务过哪些同类客户，最好实地看下分拣场地。
- 有没有备用供应渠道，防止单一供应商断供。

**5. 合作条款**
- 试合作1–2周再签长约，先小量测试准时率、损耗率、售后响应。
- 合同写明：配送时间、品质标准、退换货规则、违约赔偿、价格调整机制。

**实操建议**：先列3家候选，各试配一周，记录每天的到货时间、坏果比例、缺货次数和售后响应速度，用数据选，不靠感觉。
