可以按“餐饮客户用途”来定规格，不要只按零售档口习惯备货。菠萝和香蕉建议分别准备以下档位：

**一、菠萝规格建议**

1. **鲜切/饮品店用**
   - 主推：单果 **1.2–1.5斤**，成熟度 **7–8成熟**，果眼浅、出肉率高。
   - 备少量：**1.5–2斤**大果，适合现切果盘、烤菠萝。
   - 要求：到货可即刻后熟，批次整齐，空心少，酸度稳定。

2. **后厨/果盘/自助餐用**
   - 主推：**1.5–2斤**，成熟度 **6.5–7.5成熟**，便于档口控熟。
   - 可配：**2斤以上**大果少量，用于展示或整果出品。

3. **餐饮批发包装**
   - 建议按 **9–12个/箱** 或 **12–15个/箱** 分档，标注单果重区间和成熟度。
   - 给餐饮客户最好能稳定提供“同批次、同熟度”的货，比单纯大小更重要。

**二、香蕉规格建议**

1. **饮品/甜品/后厨用**
   - 主推：**单根120–150g**，梳蕉整齐，成熟度 **6–7成熟** 到货，便于客户自控催熟。
   - 备货：**单根150–180g** 中大果，适合果盘、烘焙、炸香蕉。

2. **快餐/食堂/自助餐用**
   - 主推：**单根140–180g**，果指均匀，耐运输，成熟度 **5.5–6.5成熟**。
   - 不建议主推过小果，后厨损耗和人工成本高。

3. **餐饮批发包装**
   - 建议按 **13–15kg/箱** 或 **10–12kg/箱** 分档，明确“单根重、每梳条数、到货成熟度、催熟建议”。
   - 餐饮客户更看重稳定催熟窗口，香蕉建议做 **青蕉到货 + 分批催熟**，不要一次全发黄蕉。

**三、给档口的备货组合**
- 菠萝：**1.2–1.5斤占50%，1.5–2斤占40%，2斤以上占10%**
- 香蕉：**120–150g占40%，150–180g占50%，小果/特级果占10%**
- 首批先各备 **2–3个规格**，用一周时间记录餐饮客户复购和损耗，再砍掉动销差的规格。

**判断标准**：餐饮客户复购的关键不是“最便宜”，而是**规格稳定、熟度可控、出成率稳定、送货批次一致**。建议给每个规格贴清“单果重/单根重、到货熟度、建议使用场景”，让客户直接按菜单选货。
