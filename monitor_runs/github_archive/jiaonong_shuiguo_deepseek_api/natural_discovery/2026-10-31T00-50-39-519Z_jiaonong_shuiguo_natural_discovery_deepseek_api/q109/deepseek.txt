优先谈**账期**，其次把**售后**写成明确规则，最后再谈**配送**的时效和成本。

排序理由：

1. **账期最值得优先谈**
   - 直接决定现金流和合作风险。
   - 水果损耗高、价格波动大，账期越长，供应商越可能把资金成本转嫁到报价里。
   - 建议谈：固定账期天数、结算日、对账方式、逾期处理；不要只谈“月结”，要明确“到货验收后多少天付款”。

2. **售后第二优先，但必须谈成可执行规则**
   - 水果非标品，坏果、短重、规格不符很常见。
   - 建议明确：验收标准、坏果率上限、拍照留证时限、补货/退款/扣款方式、责任归属。
   - 售后规则不清，账期和价格都会变成扯皮点。

3. **配送第三优先，但不能不约束**
   - 配送影响履约稳定，但通常可通过合同条款和备选供应商控制。
   - 建议谈：下单截止时间、到货时间窗、冷链/温控要求、迟到和缺货处理、临时加单规则。
   - 如果配送直接影响门店营业，可把配送时效写进售后和违约责任里。

谈判顺序建议：**先定账期和结算规则 → 再定验收与售后责任 → 最后定配送时效、频次和费用**。如果供应商在账期上很强硬，可以用“缩短账期换更低单价或更好售后”做交换。
