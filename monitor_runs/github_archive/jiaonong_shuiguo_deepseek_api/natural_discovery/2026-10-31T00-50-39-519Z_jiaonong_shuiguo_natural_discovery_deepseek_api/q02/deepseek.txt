对小水果店进香蕉，**优先级建议：坏果率/到店可售率 ≥ 熟度（可控销售节奏）＞ 送货速度 ＞ 价格**。不能只看单价便宜。

判断标准可以这样定：

1. **坏果率/到店可售率最重要**
   - 香蕉是易损品，单价低但损耗高，实际成本会被放大。
   - 看“到手能卖的比例”，不是看进货价。
   - 简单算法：  
     **实际可售成本 = 进货价 ÷ 到店可售率**  
     例如2元/斤、可售率80%，实际成本是2.5元/斤；1.8元/斤但可售率60%，实际是3元/斤。

2. **熟度第二重要**
   - 小水果店销量有限，香蕉熟得快，过熟当天卖不掉就变损耗。
   - 优先要能分批次卖的熟度：一部分可当天卖，一部分1—2天后熟。
   - 如果店里没有催熟/控温条件，不要一次进太青或太黄。

3. **送货速度第三**
   - 速度快能降低搬运和存放损耗，也方便少量多次补货。
   - 但速度不能弥补坏果率高；如果送货快但每批烂得多，仍不划算。

4. **价格放最后**
   - 香蕉是引流品，毛利薄，但损耗一高就亏。
   - 低价只在“坏果率低、熟度合适、送货稳定”前提下才有意义。

实操建议：
- 每次收货抽检：看果指饱满度、表皮黑斑、果柄霉变、压伤、掉把。
- 要求供应商承诺坏果率，比如到店可售率低于90%就补货或降价。
- 小批量、高频次进货，比一次压低价拿大货更稳。
- 记录每批的“进货价、到店可售率、售完天数、损耗”，一周就能看出哪家供应商真正便宜。

结论：**先看坏果率和熟度，再看送货速度，最后比价格。** 对小店来说，少烂一点比每斤便宜几毛更重要。
