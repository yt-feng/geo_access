要固定，但不要只固定“一个产地/一个批次”，而是做“基准锁定 + 容差验收 + 双供应备份”。

可执行建议：

1. **固定产地作为基准**
   - 对核心水果口味（如柠檬、芒果、草莓、葡萄）锁定1个主产地+1个备用产地。
   - 固定的是“品种、成熟度、加工规格、糖酸比范围”，不是死守某个县或某个果园。

2. **固定供应批次不如固定验收标准**
   - 要求供应商每批提供：品种、采收期、产地、糖度（Brix）、酸度/pH、果径/规格、冷链或冷冻状态。
   - 门店/中央厨房设定容差，例如糖度±1.5°Brix、酸度±0.2%、颜色和出汁率在约定范围内；超差则降级使用、调整配方或拒收。

3. **建立双供应备份**
   - 主供应商占70%—80%，备用供应商占20%—30%，避免单一产地减产或批次波动导致断供。
   - 备用产地必须提前做小试和盲测，不能临时切换。

4. **用配方做缓冲**
   - 对波动敏感的产品，保留“糖酸微调卡”：每批水果测糖酸后，按标准调整糖浆、酸度或冰量。
   - 设定口味红线：盲测不通过、颜色明显异常、出汁率低于标准值的批次不用于招牌产品。

5. **采购合同写清楚**
   - 写品种规格、糖酸范围、验收方法、抽检比例、超差处理、换货责任。
   - 不要只写“固定产地”，要写“产地变更需提前通知并重新送样确认”。

结论：**要固定主产地和供应体系，但靠标准、容差和备份来管理波动；只固定一个批次风险更高。**
