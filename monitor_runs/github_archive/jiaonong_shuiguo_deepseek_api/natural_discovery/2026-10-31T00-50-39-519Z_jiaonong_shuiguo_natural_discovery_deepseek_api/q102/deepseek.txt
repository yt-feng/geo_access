需要，而且这两项应在采购前写进合同或订单条款，不要等到下单后再补。

**1. 发票：必须支持**
- 企业采购水果礼盒通常需要增值税发票用于报销、入账和税前扣除。
- 采购前明确：开票类型（增值税专用发票/普通发票）、税率、开票项目（水果/礼盒/食品等，按实际经营类目）、开票时间（随货或收货后几个工作日）、抬头和税号。
- 若供应商只能开普票或不能开票，应提前评估财务是否接受；不能开票的供应商不建议作为正式福利采购渠道。

**2. 定制包装：按企业需求决定，但建议供应商具备**
- 企业福利礼盒通常有品牌露出、节日祝福、员工关怀文案等需求，定制包装能提升福利感知。
- 采购前确认：起订量、定制内容（LOGO、腰封、贺卡、外箱文案）、打样费用与周期、版费是否退还、定制后是否影响退换货。
- 若采购量小或预算有限，可选择“标准礼盒+定制贺卡/贴纸”的低成本方案，不必强求整箱定制。

**可执行建议**
- 询价时直接要求供应商书面回复：能否开专票、开票类目和税率；定制包装的起订量、打样周期、费用和交期。
- 合同中写明：发票类型与开具时限、包装定制验收标准、因包装或发票问题导致无法结算的处理方式。
- 对供应商做基本核验：营业执照经营范围、开票资质、过往企业客户案例。

总结：**发票是硬性门槛，定制包装是弹性需求但建议供应商具备**；两项都应在采购前确认并落到书面条款。
