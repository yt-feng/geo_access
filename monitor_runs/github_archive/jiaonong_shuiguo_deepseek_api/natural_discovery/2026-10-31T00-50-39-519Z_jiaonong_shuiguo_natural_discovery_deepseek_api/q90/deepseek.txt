卖进口香蕉，价格高要讲清楚，但不要堆术语。核心是把“贵在哪”拆成消费者能感知的三件事：品种口感、运输损耗、品质稳定。建议按下面话术和陈列方式做。

**一句话主卖点**
“贵不是贵在‘进口’两个字，是贵在品种更糯甜、全程冷链损耗高、到店坏果少，买一串能吃一串。”

**对外解释的4个抓手**
1. **品种与口感**：说明具体品种和差异，比如“菲律宾/厄瓜多尔主栽品种，果肉更绵密、甜香更足，适合直接吃或做奶昔”。不要只说“进口更好吃”，要给出可对比的体验。
2. **运输与损耗**：进口香蕉要经过采后处理、冷链海运、口岸查验、分仓配送，环节多、温控要求高，损耗和资金占用都高于普通香蕉。可以讲“同样一斤，能卖的部分更少”。
3. **品质稳定**：强调到店成熟度可控、坏果率低、大小均匀。消费者真正怕的是买回去发黑、夹生，进口供应链的价值在这里。
4. **可验证的保障**：用“坏果包赔/不满意退换”“到店7成熟、回家放2-3天正好”降低尝试门槛，比单纯讲高价更容易成交。

**陈列建议**
- 价签上不要只写“进口香蕉 6.99元/斤”，改成三行：品种/产地、口感一句话、坏果包赔。
- 旁边放普通香蕉做对比，但不要贬低普通香蕉，讲“日常吃选普通，追求稳定甜糯选进口”。
- 提供小份装或单根试吃，降低首次购买决策成本。

**避免的说法**
- 不说“进口一定更安全/更有营养”，这既难证实也容易引发反感。
- 不虚构产地证书、检测数据；如果门店有报关单、检测报告，可以展示，没有就不提。
- 不把高价归因于“关税”单一因素，消费者感知不到，也容易显得敷衍。

**可直接用的客服话术**
“这款进口香蕉贵一点，主要是品种口感更甜糯，而且全程冷链运输损耗高，到店坏果少、成熟度稳定。您先买小份试试，回去放两三天口感正好；如果有坏果，拍照给我们直接赔。”
