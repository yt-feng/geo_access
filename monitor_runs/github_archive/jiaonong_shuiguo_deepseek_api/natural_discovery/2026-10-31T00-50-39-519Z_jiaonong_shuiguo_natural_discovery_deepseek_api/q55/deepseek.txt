选规格的核心不是“单价最低”，而是**按出成率和用途倒推**。水果拼盘要兼顾颜色、切块稳定、损耗低。给你按品类说结论：

**苹果**
- 优先选**中大果、果形端正、硬度高**的，如80–85mm左右规格；做拼盘切块、切片都稳，氧化和软塌少。
- 不要贪特大果：单果太大，切出来块大、边角料多，拼盘不好摆盘；也不要小果，削皮去核后出成率低。
- 划算判断：按“去皮去核后可切块重量”算，通常中大型硬脆果出成更稳。

**橙子**
- 做拼盘优先选**中果、皮薄、好剥或好切瓣**的规格，如70–80mm左右；切月牙瓣、去皮橙肉都方便。
- 大果看着气派，但瓣太宽、摆盘占空间，且皮厚品种出肉率不一定高；小果切瓣碎、费工。
- 关键看品种和皮厚，不要只看直径。夏橙、脐橙、血橙按你菜单颜色需求选。

**菠萝**
- 优先选**中等偏大、成熟度7–8成、果眼浅**的；单果1.2–1.5kg左右通常较好切、出肉稳定。
- 太大果芯粗、边角多；太小削皮损耗占比高。现场切用整果更划算，但要算削皮去眼去芯后的净出肉。
- 如果拼盘用量大且后厨人手紧，可对比**去皮菠萝/菠萝块**的净料价，别只比整果单价。

**划算的统一算法**
用“净料成本”比较：  
净料成本 = 采购单价 ÷ 出成率  
苹果出成率约70%–80%，橙子去皮切瓣约50%–65%，菠萝去皮去眼去芯约45%–60%（按品种和切法浮动）。  
再把人工、损耗、摆盘效果算进去：**中规格、品质稳定、好切好摆的规格通常最划算**，不是最大也不是最便宜。

**采购建议**
1. 先定每份拼盘的克重和块数，倒推每类水果净用量。
2. 要求供应商报“规格+品种+成熟度”，别只报“大果/中果”。
3. 先小批量试切，称净出成率，连续试2–3批再定长期规格。
4. 苹果选硬脆耐放，橙子选皮薄易剥，菠萝选果眼浅、成熟度可控；拼盘优先稳定性，不追极端低价。
