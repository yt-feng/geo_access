判断哪个规格更容易出货，不要只看“问的人多不多”，要看“批发成交结构”。可按下面几步直接做：

1. **先分规格统计成交，不统计询价**
   - 按重量/果径/级别分：如小果、中果、大果、特大果；或8头、10头、12头/箱。
   - 连续记录7–14天：每个规格的**出货箱数、成交客户数、退货/损耗、平均成交价、成交耗时**。
   - 询价多但成交少，只说明被比价，不代表好出。

2. **算两个核心指标**
   - **箱数占比 = 该规格出货箱数 ÷ 总出货箱数**：看主力规格。
   - **动销天数 = 当前库存 ÷ 近7日日均出货**：看哪个规格压货。
   - 优先推“箱数占比高 + 动销天数短 + 损耗低”的规格。

3. **看客户结构，而不是看单个大客户**
   - 水果店/社区团购通常偏好中果、规格整齐、价格稳的箱规。
   - 餐饮/加工/果汁厂更看重低价和小果、次果。
   - 礼盒/商超更看大果和外观。
   - 如果某个规格只靠1–2个客户吃量，不算“容易出货”，客户一走就压货。

4. **看价格带和替代关系**
   - 记录各规格成交价差。若大果比中果贵很多但走量明显慢，主推中果更稳。
   - 若小果降价后出货明显加快，说明价格敏感型需求强，可用小果做引流。
   - 不要用“最低价规格”直接当主推，要看毛利和损耗后的净贡献。

5. **做小批量测试**
   - 每个规格各拿固定箱数，同一时间段、同一批客户推广，记录成交率。
   - 测试3–5天即可看出：哪个规格**成交最快、退货最少、复购最多**。
   - 测试时保持报价、账期、配送条件一致，否则结论不准。

6. **最终判断口径**
   更容易出货的规格通常是：
   - 近7日箱数占比最高；
   - 动销天数最短；
   - 成交客户数多且分散；
   - 损耗和退货低；
   - 净毛利不拖后腿。

**实操建议：** 先建一张表，每天记“规格、出货箱数、成交客户数、报价、成交价、退货/损耗、剩余库存”。跑一周，按“箱数占比×动销速度×客户分散度”排序，排第一的就是当前更容易出货的规格。别凭感觉押大果或小果，批发端最容易错判的就是“询价热度”和“真实成交”。
