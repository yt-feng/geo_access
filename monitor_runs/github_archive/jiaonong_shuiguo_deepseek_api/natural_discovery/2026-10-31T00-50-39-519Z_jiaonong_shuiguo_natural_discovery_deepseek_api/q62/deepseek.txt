判断一批香蕉，核心看“外观信号 + 手感 + 切口 + 气味 + 抽样切开”，并且要把“当前熟度”和“后续催熟/存放风险”分开判断。

**1. 先定熟度：看颜色和棱角**
- 全绿、棱角明显：生货，适合长途或自己催熟，但怕冷害、怕闷。
- 绿中带黄、棱角略圆：适合批发周转，催熟空间大。
- 黄多绿少、棱角变圆：已进入销售期，周转要快。
- 全黄、出现糖斑：熟度高，零售可，批发压货风险大。
- 黄中带褐、果柄发黑：接近过熟，坏果风险明显上升。

**2. 看果柄和切口**
- 果柄青绿、切口新鲜无霉：周转基础好。
- 切口发黑、发黏、有酒味：可能已闷过或感染，坏果风险高。
- 整把果柄发黑但果身尚硬：可能是运输损伤或低温后回温，要抽样切开确认。

**3. 摸手感和硬度**
- 果身硬、回弹慢：偏生。
- 轻按有弹性、不软塌：适合近期销售。
- 局部软、按下去不回弹：软伤或内部已坏。
- 同一批里软硬差异大：成熟不均，催熟后容易出现“部分过熟、部分不熟”。

**4. 看表面和棱线**
- 棱线处发黑、凹陷、渗液：机械伤后易腐烂。
- 表皮有黑点但果肉硬：可能是运输摩擦或轻微病斑，要抽样确认。
- 黑点连片、扩大快、伴随霉毛：病害风险高。
- 表皮大面积发暗、水浸状：冷害或闷伤可能性大。

**5. 闻气味**
- 清香正常。
- 有酒味、酸味、霉味：内部已开始发酵或腐烂，整批要警惕。
- 有刺鼻药味：可能保鲜处理过重，需结合切口和果肉判断。

**6. 抽样切开，别只看外表**
随机抽 5～10 根，重点看：
- 果肉是否发黑、发褐、水化；
- 中心是否硬芯或已软烂；
- 靠近果柄处是否霉变；
- 有没有虫道。
外表好但切口发黑、果肉水化的，坏果风险高。

**7. 判断整批风险的关键信号**
出现以下情况，建议压价、快销或拒收：
- 同一箱内软硬差异大；
- 切口发黑发黏、有酒味；
- 表皮水浸状或大面积暗褐；
- 果柄霉变；
- 抽样切开有褐变、水化、霉心；
- 货已全黄且带糖斑，还要长途或压库。

**8. 给批发商的实操建议**
- 要“当前熟度 + 催熟潜力”分开问：现在能不能卖，放几天会不会集中软烂。
- 绿货重点查冷害和闷伤；黄货重点查过熟和机械伤。
- 大批量拿货先抽底层和中间箱，不只看看门口样品。
- 拿货后先做小批催熟试验，再决定整批节奏。
- 合同或单据上写明熟度、坏果率接受范围、切口和霉变标准，便于争议处理。

一句话：**颜色定销售窗口，切口和气味定腐烂风险，抽样切开定真实坏果率；三者不一致时，按最差信号处理。**
