核心原则：**不要按“今天最好吃”来采购，而按“预计售完时的成熟度”来倒推**。菠萝是后熟水果，采购熟度要留出卖场周转时间。

可执行判断：

1. **先定周转天数**
   - 当天能卖完：可采7～8成熟，允许少量即食。
   - 2～3天卖完：主采6～7成熟，少量7～8成熟做试吃/即食。
   - 超过3天：偏6成熟，但菠萝过生风味差，不建议压太多生货。

2. **看外观**
   - **果皮**：从底部向上转黄。整果青绿偏硬=偏生；底部1/3转黄、上部青=适合周转2～3天；大面积金黄=即食，损耗快。
   - **果眼**：果眼扁平、间距大通常成熟度较好；果眼深陷、尖锐偏生。
   - **果形**：选果形端正、饱满、无畸形；过瘦长往往肉少。
   - **底部**：底部有轻微果香正常；发黑、渗汁、霉点不要。

3. **闻香气**
   - 底部有明显甜香=接近即食，少采。
   - 几乎无香=偏生，可放。
   - 有发酵酒味=过熟，拒收。

4. **按压与手感**
   - 轻按果身微弹=适口。
   - 硬如石=生，可周转。
   - 一按就软、局部软陷=过熟或内伤，拒收。
   - 同样大小选重的，水分足；但过重且无香可能未熟。

5. **看冠芽和切口**
   - 冠芽青绿、挺立说明新鲜；冠芽枯黄萎蔫说明放久了。
   - 切口干燥、无汁液渗出、无褐变霉斑。

6. **分批次采购**
   - 建议：**60%～70%采6～7成熟做周转，20%～30%采7～8成熟做当日即食，10%以内试吃/促销**。
   - 到店后按成熟度分区：生货常温通风，熟货冷藏或优先切果/促销。

7. **验收抽检**
   - 每批随机抽几个，重点查底部：发软、酒味、渗汁、霉点即整批风险高。
   - 夏季高温、雨天或运输时间长时，熟度整体下调半级。

简单记：**底部微黄、有淡淡果香、果身硬中带弹、无软陷无酒味**，是周转较稳的采购点；全黄浓香只适合当天卖。
