优先关注**切果损耗**，其次甜度，再看外观和大小。原因是超市卖菠萝的核心不是“挑一个最好的”，而是**整批货的毛利和周转**。

可以按这个顺序判断：

1. **切果损耗（最优先）**
   - 菠萝是典型“带皮重、可食率低”的水果，损耗直接吃掉毛利。
   - 关注：去皮去眼后的可食率、坏心/黑心率、过熟软烂率、切开后褐变和出水。
   - 实操：按批次抽切，记录“进货重量→可售果肉/切块重量”，算实际出成率；损耗高的批次再甜也不能主推。

2. **甜度**
   - 甜度决定复购和口碑，但不能只看单果糖度。
   - 关注：批次平均糖度、酸甜比、是否“外甜内淡”、是否过熟发酸。
   - 实操：到货抽测糖度，设最低准入线；不达标就做促销、切块或加工，不进正价陈列。

3. **外观**
   - 外观影响首次购买和正价销售，但排在损耗和甜度之后。
   - 关注：果形端正、果眼浅、无裂口、无腐烂、无药斑、冠芽新鲜。
   - 注意：外观好但可食率低或黑心率高，属于“好看不赚钱”。

4. **大小**
   - 大小主要影响定价和客群匹配，不是第一决策项。
   - 关注：大小分级是否均匀、是否符合门店主流客群偏好、单果重量是否导致单价过高。
   - 实操：大果做礼盒/整果正价，小果做切块或促销，避免大小混杂拉低整体形象。

**结论：**
超市卖菠萝，第一看**切果损耗和出成率**，第二看**甜度稳定性**，第三看**外观**，最后用**大小**做分级和定价。如果只能盯一个指标，就盯“每批次实际可售出成率”，因为它同时决定毛利、定价和促销策略。
