线上水果销售要减少坏果和口感不稳定，核心不是“采购时挑得更仔细”这么简单，而是把采购标准、供应商管理和到货验收做成可执行的动作。可以按下面几层抓：

1. **先定可量化的采购标准**
   - 按品类写清：品种、产地、规格（单果重/果径）、成熟度、糖酸比或可溶性固形物下限、允许瑕疵比例、采摘/发货时间。
   - 不要只写“新鲜、甜”，要写成验收能测的指标。例如坏果率≤2%、机械伤≤3%、成熟度70%～80%发货、糖度抽检不低于约定值。
   - 不同季节、不同产区标准分开，避免用一套标准套全年。

2. **选供应商看稳定性，不只看价格**
   - 优先选有分级分选能力、冷藏/预冷条件、稳定发货记录的供应商。
   - 要求供应商提供近期批次抽检记录、产地证明和发货成熟度说明。
   - 新供应商先小批量试单，连续3～5批稳定后再放量；不要一次把单品押在一家。

3. **采购时控制成熟度和运输距离**
   - 线上销售要经过快递，采购成熟度应比线下零售略低，尤其是软果、浆果类。
   - 远距离发货选耐储品种或适当提前采摘，但必须做催熟/后熟方案，否则会出现“到了不甜”或“到了已烂”的两头问题。
   - 高温季节减少跨区远调，优先就近仓或产地直发，缩短在途时间。

4. **把验收做成抽检流程**
   - 每批到货按比例抽检：坏果、软果、机械伤、大小均匀度、糖度、异味。
   - 抽检要拍照留档，按批次记录，和供应商对账时用数据说话。
   - 设定拒收/扣款规则：坏果率超标拒收或折价，连续两批不达标降级供应商。

5. **采购和仓储衔接**
   - 到货后尽快预冷、分拣，剔除已软、已伤果，避免一颗坏果带动整箱。
   - 按成熟度分仓、先进先出，不要混批压货。
   - 包装上考虑防挤压、透气、防潮，尤其浆果和软果。

6. **用售后数据反推采购**
   - 按单品、供应商、批次统计差评原因：坏果、不甜、太酸、过熟、大小不符。
   - 差评集中的批次直接追溯供应商和采摘成熟度，下一批调整标准。
   - 对口感不稳定，建立“糖度抽检+试吃”双关，不能只看外观。

最直接可执行的第一步：先给销量前3的单品各做一张采购验收卡，写清规格、成熟度、坏果率上限、糖度下限、抽检比例和拒收规则，然后连续执行一个月，用差评和退货数据校正标准。这样比泛泛地“找好货源”更能压住坏果和口感波动。
