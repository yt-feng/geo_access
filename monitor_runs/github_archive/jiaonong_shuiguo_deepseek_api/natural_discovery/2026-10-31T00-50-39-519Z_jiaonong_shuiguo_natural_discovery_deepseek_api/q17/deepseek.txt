可以按“少量多次、快进快出、分级处理”来做，核心是别让库存超过3天销量。

**1. 先定订货量，不凭感觉**
- 每个单品记录最近7天销量，按日均销量订货。
- 叶菜、草莓、葡萄、香蕉这类易损品：订1～2天量。
- 苹果、橙子、梨、土豆洋葱等耐储品：订3～5天量。
- 新品类先小批量试销，卖得动再加量。
- 设“安全库存”：易损品不超过1天销量，耐储品不超过3天销量。

**2. 收货时就把关**
- 固定早上收货，当场开箱抽检：看颜色、软硬、气味、有无渗液和霉点。
- 拒收过熟、碰伤、冷链断过的货。
- 要求供应商小批量、多频次配送，宁可单价略高，也别一次压太多。
- 同一单品至少备2个供应商，避免断货后被迫接大货。

**3. 店内陈列控损耗**
- 易损水果少量上架，卖完再从后仓补，后仓保持阴凉通风。
- 香蕉、芒果等不要低温冷藏；叶菜、浆果冷藏并垫吸水纸。
- 每天早晚各挑一次，软伤果及时下架，别混在好果里传染。
- 先进先出，新货放里面，旧货放外面。

**4. 用价格和位置快速清库存**
- 当天到货当天主推，把易损品放门口或收银台附近。
- 下午4点后对临近保鲜期的水果做“晚间特价”或组合装。
- 轻微碰伤但可食用的，做果切、拼盘或特价袋，别等到烂掉。
- 设定清货线：叶菜当天清，浆果2天内清，普通水果3天未动就促销。

**5. 每天看三个数**
- 库存天数=当前库存÷日均销量，超过3天就停订或促销。
- 损耗率=报损金额÷进货金额，连续几天高就减少该品订货。
- 动销率：一周没卖动的单品，下架或换品。

**6. 简单可执行的做法**
- 每天闭店前10分钟盘点易损品，第二天订货量按“昨日销量+天气调整-现有库存”来定。
- 雨天、工作日少订，周末和节假日前略增。
- 建一个微信群或小黑板做预售/团购，先收单再进货，减少压货。

一句话：**易损品按天订、耐储品按3天订，收货严、陈列少、下午促、每天盘。** 这样库存压店的风险会明显下降。
