判断苹果、橙子大小规格是否适合门店销售，核心看三件事：**消费者单手/单次食用体验、货架陈列效率、价格带与损耗可控**。可按下面执行。

**1. 先定“销售单位”，再定规格**
- 散卖门店：看单果直径和单果重，避免过大或过小。
- 按份/按袋卖：看每份个数、总重、单价接受度。
- 礼盒/精品：看整齐度和外观一致性，规格可以偏大但必须均匀。

**2. 苹果的实用判断标准**
- 鲜食散卖主流：单果重约 **160–250g**，横径约 **75–85mm** 比较适口；太小显得廉价，太大单价高、单次吃不完。
- 家庭装/按袋卖：**180–220g/个** 易配重、易定价。
- 礼盒或精品：**220–300g/个**，但要求果形端正、大小一致。
- 门店操作：抽检一箱，随机称20个，算平均单果重和极差；极差过大说明分级不稳，陈列和定价都会乱。

**3. 橙子的实用判断标准**
- 鲜食散卖主流：横径约 **65–80mm**，单果重约 **150–250g**；皮薄、手感沉、果形匀称比单纯大更重要。
- 榨汁或家庭装：**70–85mm** 也可以，但要看出汁率和皮厚。
- 精品/礼盒：**75–85mm**，重点是一致性和外观。
- 门店操作：同样抽20个称重、量横径；同时切开2–3个看皮厚、汁水、籽量，避免“规格合适但品质不适合”。

**4. 用门店销售场景反推**
- 货架层高和陈列量：单果过大，堆头容易塌、层数少、补货频繁；单果过小，堆头显空、顾客觉得不值。
- 价格带：算“单果零售价”。顾客对苹果单果超过某价位、橙子单果超过某价位会犹豫，具体以你门店客群测试为准。
- 损耗：过大果易碰伤、切开卖损耗高；过小果挑拣多、残次率高。
- 复购：同一规格连续卖2–3周，看动销、投诉、挑剩率；挑剩多说明规格或定价不匹配。

**5. 快速验收集**
采购前做“三称三看”：
- 称平均单果重、称最大最小极差、称每箱净重是否足。
- 看横径一致性、看表皮瑕疵比例、看切开品质。
- 再算：单果成本、预计售价、毛利率、预计损耗。

**结论**：苹果散卖优先 **160–250g/个、75–85mm**；橙子散卖优先 **150–250g/个、65–80mm**。但最终以你门店客群的单果价格接受度、陈列方式和2–3周动销数据为准，规格均匀比单纯“大”更重要。
