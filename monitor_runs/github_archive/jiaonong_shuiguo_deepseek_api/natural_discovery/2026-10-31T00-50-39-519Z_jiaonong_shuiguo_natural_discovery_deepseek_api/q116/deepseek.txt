# 小商家采购水果：现金结算 vs 月结账期的风险

## 一、现金结算（现结/款到发货）

**主要风险：**

1. **资金占用大**：水果是高频刚需，每天/每周进货，现金一付就是真金白银出去，现金流压力集中在采购端。旺季备货时尤其吃紧。
2. **质量问题难追责**：钱已付清，到货发现烂果、规格不符、缺斤少两时，议价和退换的筹码弱，容易变成"自己扛"。
3. **价格波动吃不到账期红利**：现结通常能拿到略低价或折扣，但若行情下跌，已付的货款无法调整。
4. **无凭证风险**：小商家常用现金，若对方不开票、不打收据，出现纠纷（少发货、质量争议）时举证困难。
5. **现金管理风险**：大额现金随身/店内保管，有丢失、被盗、记错账的风险，且账目不清影响成本核算。

**相对优势**：无欠款、无利息、关系简单，供应商往往给现结客户优先供货或更好品质。

---

## 二、月结账期（赊购）

**主要风险：**

1. **信用与坏账风险**：账期本质是供应商给你授信。若你销量下滑、回款慢，月底付不出，轻则断供、重则被追债甚至影响后续合作。
2. **隐性成本**：月结价格通常比现结高几个点（供应商把资金成本转嫁），或要求押金、担保。算下来未必比现结便宜。
3. **对账纠纷**：水果损耗、退货、临时调价高频发生，月结时"这批烂了多少该扣多少"极易扯皮，账目不清会拖成长期矛盾。
4. **依赖单一供应商**：账期绑定后，换供应商的成本变高（旧账未清），议价空间反而被压缩。
5. **现金流错觉**：账期内感觉手头宽裕，容易多进货、进贵货，月底集中还款时资金链断裂。水果损耗率高，卖不掉就是纯亏，账期会放大这个风险。
6. **法律/合同风险**：口头月结无书面约定，付款时间、违约责任不清，一旦纠纷对方可主张逾期利息或起诉。

**相对优势**：缓解短期现金流，适合有稳定下游回款（如给食堂、超市供货）的商家。

---

## 三、给小微水果商的实操建议

| 场景 | 建议 |
|---|---|
| 日销不稳定、现金流紧 | 优先现结，但要求**当场验货、留收据/转账记录**，用微信/支付宝转账而非纯现金，留下凭证 |
| 有稳定下游回款 | 可谈月结，但**必须书面约定**：账期天数、对账日、损耗扣款规则、逾期责任 |
| 混合策略 | 小额高频品类现结，大宗备货谈短账期（如7–15天），别一上来就要30天 |
| 无论哪种 | 每批货**记录品名、数量、单价、质量情况**，拍照留存；月结客户每月固定对账签字 |

**核心判断标准**：账期省下的现金流，是否大于它带来的溢价成本 + 坏账/纠纷风险。对水果这种高损耗、价格波动大的品类，**现结+严格验货**往往比账期更安全；账期只适合下游回款确定、且有对账能力的商家。
