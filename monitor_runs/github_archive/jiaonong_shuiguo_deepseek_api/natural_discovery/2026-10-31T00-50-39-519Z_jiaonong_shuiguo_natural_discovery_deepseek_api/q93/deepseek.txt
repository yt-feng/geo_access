优先级很清楚：**保质期管理 > 包装 > 配送频次**。但三者不是并列选一个，而是先守住保质期这条底线。

**1. 保质期（最高优先级）**
菠萝切块是切开的水果，高水分、高糖，微生物风险远高于整果。核心是：
- 明确标注制作时间和废弃时间，建议冷藏条件下**当天制作当天售完**，最长不超过24小时，具体以你所在地区监管要求和内部标准为准。
- 执行“先进先出”，临期打折要有时点规则，不能靠店员感觉。
- 切开、装盒、冷藏全程控温，刀具和砧板生熟分开。

**2. 包装（第二优先级，直接决定保质期能否守住）**
- 用食品级密封盒或覆膜，减少氧化和交叉污染。
- 包装上必须有制作日期/时间、保质期、储存条件。
- 包装不是越贵越好，关键是密封性和冷藏陈列条件匹配。

**3. 配送频次（第三优先级，但影响损耗和鲜度）**
- 切块菠萝更适合**门店现场切制**，而不是中央厨房切好再配送，配送环节越多、时间越长，风险越大。
- 如果必须配送，频次要高、冷链要稳，且到店后剩余保质期要足够长。
- 配送频次本质是服务保质期的手段，不是独立目标。

**可执行判断标准：**
- 如果只能先改一件事：先把**制作时间标签和到期废弃制度**落地。
- 如果损耗高：先查包装密封和冷藏温度，再考虑提高配送频次。
- 如果出现客诉或变质：立即缩短保质期、改为门店现切，而不是靠加频配送硬撑。

一句话：**保质期是底线，包装是保障，配送频次是调节手段。**
