选择社区超市的水果供应商时，建议重点看以下几个方面，兼顾成本和稳定性：

---

### 1. **鲜度与损耗控制**
- 要求供应商提供**每日凌晨或早晨到货**，确保水果从产地到货架不超过12-24小时。
- 考察其损耗率承诺（通常应控制在5%以内），并要求对残次品、挤压品提供**退换货或补货**机制。

### 2. **品类与规格**
- 是否能覆盖**日常高频品类**（苹果、香蕉、橙子、梨、葡萄等）以及**季节性爆款**（如夏季西瓜、冬季柑橘）。
- 是否提供**分级供货**（特级/一级/通货），便于你根据定价选择档次。

### 3. **价格与账期**
- **价格对比**：要求提供近一周批发价或市场参考价，对比至少3家供应商。
- **结算方式**：小超市优先选**周结或月结**，避免现金压力；大供应商可能要求预付，需权衡。
- 注意**价格浮动条款**（如水果产地天气突变时，是否明确调价规则）。

### 4. **物流与时效**
- 是否提供**固定配送时间**（如早6点前送达），且能应对节假日加单。
- 是否有**紧急补货通道**（如周末缺货能否临时加送）。
- 覆盖范围是否涵盖你的位置，避免因距离远导致配送延迟。

### 5. **资质与稳定性**
- 核验**营业执照、食品经营许可证（或农产品合格证明）**。
- 实地查看其**仓库或分拣场地**，确认卫生条件与冷链设备。
- 问清**供货来源**（是否直采自产地，还是二三级批发），这关系到价格与品质稳定性。

### 6. **服务与响应**
- 是否提供**每日品质抽检报告**或简单的农残记录。
- 是否有**专属客服**，对售后（如坏果、缺斤短两）能否24小时内处理。

---

### 可操作建议：
- 先订**试合作一周**，每天少量进货，观察新鲜度、准时率和售后，再签长期合同。
- 要求对方提供**近三个月的其他合作超市名单**，可去实地走访（观察货架陈列是否新鲜、客流情况）。
- 在合同中明确**每日到货时间、损耗赔付标准、临时补货响应时间**等条款作为约束。

如果当地有批发市场（如农批中心），也可以对比“批发市场自采”和“供应商直送”的成本差——若每日采购量不大（低于200元），供应商直送更省力；量大则更建议直接对接产地合作社。
