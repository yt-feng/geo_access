在便利店出售菠萝切块，**保质期、包装和配送频次三者同样重要，缺一不可**。但根据你的经营痛点，可以按优先级这样处理：

**1. 保质期（决定性因素）—— 最优先**
- **核心标准**：切块菠萝的黄金赏味期是**当天现切、当天售完**。如果做不到，**冷藏条件下（0-4℃）最长不得超过24小时**，超过24小时即使不变质，口感也会发酸、出水，影响复购。
- **贴标要求**：必须打印**包装日期+食用期限（精确到小时）**，建议在到期前2小时做废弃处理，避免顾客买到临期品引发投诉。
- **损耗控制**：如果当日卖不完，**不要再二次销售**（禁止解冻/重新包装），直接折价处理或报损。

**2. 包装（影响卖相和货架期）—— 第二优先级**
- **必须密封**：使用**PET透明果切盒+密封盖**，防止氧化变黑和细菌污染。
- **底部吸水垫**：盒底铺**食品级吸水纸**，能吸收果汁，延长保鲜、防止果汁渗漏弄脏货架。
- **建议锁鲜方式**：如果条件允许，**充氮气或真空锁鲜包装**可以延长至48小时，但成本较高。普通密封盒只能撑到当天。
- **标注警示**：包装正面大字标注“**请冷藏保存，建议即买即食**”，避免顾客放室温后变质。

**3. 配送频次（决定新鲜度）—— 配合保质期设置**
- **如果门店有后厨/冷链**：每天**早、中、晚各配送或补货一次**（间隔4-6小时），每次出少量，卖完即止。
- **如果依赖中央工厂配送**：**必须每日凌晨配送**，且运输全程**冷链（2-5℃）**，到店后立刻入冷柜，配送车到店时间要避开中午高温时段。
- **关键动作**：与配送方约定**到货验收时间**，超时2小时未到店，可拒收或要求换新批次，因为超时极易导致果肉在运输途中变质。

**落地建议（可直接执行）：**
- 先测试一天**早上做一份、中午做一份**，观察下午4点后剩余菠萝的色泽和口感，确定你门店的实际保质期。
- 如果销量不稳定，**建议“小份多盒”**（比如每盒150g），比大盒更好卖完，减少损耗。
- **不要贪图“三天保质期”的切块**——便利店切块菠萝的产品定位就是“新鲜短保”，敢于标注“当日制售”反而能建立信任。

一句话总结：**以“24小时内售罄”为硬指标，用密封盒+吸水垫保证卖相，配送必须保证“凌晨到、冷链到、当日清”**。
