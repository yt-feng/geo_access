在酒店采购水果盘原料时，为保证出品质量、控制成本和维护客户满意度，供应商应明确保证以下**规格标准**和**外观标准**。以下是可以直接写入采购合同或验收单的具体要求：

### 一、规格标准（重量、尺寸、成熟度）

1.  **果径/尺寸统一**：同批次水果的果径误差应在±5%以内（例如：苹果直径75-80mm，橙子直径70-75mm），避免大小混装导致出品摆盘不协调。
2.  **单果重量**：明确最低克重（例如：草莓单颗≥15g，蓝莓颗粒饱满无瘪粒）。
3.  **成熟度指标**：
    -   可溶性固形物（糖度）：如哈密瓜糖度≥14%，西瓜≥11%（具体按品种调整）。
    -   硬度：猕猴桃、芒果等需供应至**可即食状态（软硬适中）**，或明确分为“即食级”和“催熟级”供酒店选择。
    -   无生涩、无过熟软烂。
4.  **净含量偏差**：整箱或分包净重误差不得超过标注重量的±2%（不含包装重量）。

### 二、外观标准（新鲜度、完整性）

1.  **色泽**：表皮颜色均匀，符合品种特征（如红提应呈紫红色，无青红色斑驳；金奇异果应呈金黄色）。
2.  **果形**：外形端正，无畸形果（如歪头、双胞胎果、裂果）。
3.  **表面光洁度**：
    -   **无斑点**：无黑斑、锈斑、药斑、日灼斑。
    -   **无机械伤**：无碰压伤、划伤、果柄断裂（苹果、梨类必须保留完整果柄，提子必须带新鲜果粉）。
    -   **无病虫害**：无虫眼、蛀孔、虫粪，无霉变、腐烂迹象。
4.  **清洁度**：表面无泥土、农药残留（需附带农残检测报告）、水分异常（表面不能有水迹导致保鲜期缩短）。
5.  **包装内部状态**：
    -   包装箱内无落叶、碎屑、异物。
    -   垫纸、保鲜膜干净，无异味（不能有塑胶味或化学味）。

### 三、特殊品种的特定要求（供参考）

-   **芒果/木瓜**：表皮无黑点（炭疽病），按压果肩处微软。
-   **葡萄/提子**：果粒紧实，不易脱落，霜（果粉）完整。
-   **西瓜/哈密瓜**：剖开后中心糖度均匀，无空心、无白籽带酸味。
-   **切配类（如菠萝蜜、去皮柚子）**：需真空包装，包装内无汁水溢出，果肉呈均匀金黄色。

### 四、供应商需提供的文件承诺

1.  **农残检测报告**：每批次提供（最低要求为符合国家GB 2763标准）。
2.  **产地证明**：确保非疫区、非灾害产区产品。
3.  **冷链运输保证**：如为冷藏水果（蓝莓、草莓、车厘子），到货温度应在0-5℃。

---

**执行建议**：直接将上述条款按品种细化后，列为采购合同的**附录验收表**。每次到货时，由收货人抽检（开箱率不低于30%），若外观合格率低于95%或存在严重腐烂，应有权整批次拒收或要求换货。
