选水果供应商时，**最应该先问“配送和售后”，价格放在最后谈**。

原因很简单：水果是生鲜，损耗高、时效强，如果配送和售后跟不上，即使进价再便宜，最终到手可能也是亏的。

给你一个清晰的优先级和具体话术建议：

**第一优先：问配送（决定货损和成本）**
- 问：**“你们是冷链车还是普通常温车？发货后多久到？”**
- 问：**“如果路上堵车、到货晚了，或者到货时果子发霉/碰伤，损耗怎么算？是补发、折算退钱，还是全赔？”**
- 问：**“送货是直接到小区门口，还是需要我自己去提货点拉？”**
（重点：确认配送时效、温控方式、延迟或破损的赔付标准）

**第二优先：问售后（决定信任和复购）**
- 问：**“到货后如果有个别坏果，理赔标准是什么？比如坏几个以内算正常，坏多了怎么处理？需要拍照片还是视频？”**
- 问：**“售后是直接找你对接，还是找客服？响应快不快？大概多久能解决？”**
（重点：确认售后流程清晰、有人担责、赔付周期短，避免“售后找不到人”）

**第三优先：才问价格（决定利润空间）**
- 问：**“这个价格是含税含运费的吗？量大有没有阶梯价？多久结一次款？”**
（重点：确认最终到手成本，而不是纯批发价，同时了解账期，避免压款风险）

---

**给你的实操建议：**
1. 先问配送和售后，如果对方回答含糊、推诿，即使价格再低也建议换一家。
2. 价格可以对比，但**不要为了省几毛钱选一个售后没保障的供应商**，团购的口碑比几块钱差价重要。
3. 最好能要求一次**试单**（进少量先测品质、配送和售后），看实际流程再决定长线合作。

**总结一句话：先问“如果果子坏了怎么办”和“多久能送到”，最后才问“多少钱一斤”。** 这样能帮你筛掉大量不靠谱的供应商。
