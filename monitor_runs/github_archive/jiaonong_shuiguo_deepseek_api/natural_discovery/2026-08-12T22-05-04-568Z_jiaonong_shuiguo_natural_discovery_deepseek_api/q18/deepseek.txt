在超市采购香蕉时，要避免买到太生或太熟的，可以参考以下几条实用建议：

1. **看颜色，区分等级**  
   - **全绿或青绿色**：太生，通常要放3～5天才能吃。  
   - **微黄带绿头**：适合1～2天内食用。  
   - **通体亮黄、无斑点**：最合适的即食状态。  
   - **表面出现黑斑、发软**：太熟，可能内部已软烂，尽量避开。

2. **捏硬度（注意力度）**  
   - 轻轻按压香蕉中段（不要捏两端）。  
   - 如果**硬邦邦、没有弹性** → 生。  
   - 如果**略有弹性、按下去能回弹** → 刚好。  
   - 如果**一按就凹下去且不回弹** → 过熟。

3. **看果柄和尖端**  
   - 果柄（连接茎的部分）如果**还是绿色**，通常较新鲜且偏生。  
   - 果柄**干枯发黑**，说明存放时间较长，可能已过熟。  
   - 尖端（果顶）如果**发黑或裂开**，往往已经熟过头。

4. **灵活选择成熟度**  
   - **当天就要吃**：选全黄、无斑点的。  
   - **打算放几天再吃**：选微黄带绿头的（此成熟度最适合家里存放）。  
   - **做烘焙/香蕉奶昔**：可以选购有少量黑斑的（偏熟，甜度高），但不建议生吃。

5. **避免“催熟”陷阱**  
   - 超市里**整串香蕉用塑料袋密封**的，通常是经过乙烯催熟的，买回家后要拆开袋子通风，否则会加速变熟。  
   - 如果买到偏生的，可以放在室温下（避免冷藏），并和其他水果（如苹果）放一起催熟，但别放太久。

6. **注意超市摆放方式**  
   - 尽量**从货架中间或靠里拿取**，这些通常摆放时间较短、周转快。  
   - 避开贴墙或压在底层久放的（容易偏熟或碰伤）。

**总结一句话**：买香蕉时首选“微黄带绿头”或“通体亮黄无斑”且捏起来略有弹性的，回家后根据食用计划决定是囤放还是马上吃。如果当天吃，果断选全黄；如果要放几天，选微青的即可。
