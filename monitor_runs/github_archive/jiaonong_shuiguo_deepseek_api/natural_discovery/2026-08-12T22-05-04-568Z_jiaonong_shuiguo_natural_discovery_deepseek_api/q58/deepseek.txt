选择**直接采购成品果丁**，在损耗上通常更低。原因如下：

1. **鲜果切配的损耗来源**：
   - **果皮、果芯、果眼**：菠萝可食率约60%-70%，去皮去眼去芯后，废料比例高达30%-40%。
   - **储存损耗**：整果存放易熟透、变质或碰伤，切配过程中的边角料如果当日卖不完，只能报废。
   - **人工误差**：员工切配熟练度不一致，可能削太厚或切不均匀，增加额外损耗。

2. **直接买成品果丁的优势**：
   - 供应商在产地或工厂统一去皮切丁，废料留在源头，店铺只收到可食部分，无外皮、果核等不可出售的重量。
   - 成品果丁按需采购，可精确控制当日用量，避免积压变质。
   - 工厂切配通常采用标准化工具，损耗率已由供应商承担（体现在单价里），对店铺而言，实际可售重量更高。

**注意点**：
- 成品果丁单价通常高于整果，但若计算上损耗和人工成本，**每斤可售果肉的净成本往往更低**。
- 如有条件，可做一次小规模对比实验：买1个整果，称量切配后的果肉重量，再对比成品果丁的单价，算出实际成本差异。

**结论**：若追求低损耗和操作便利，建议优先选成品果丁。若店铺销量大且冷藏管理到位，鲜果切配也可以接受，但损耗控制难度明显更高。
