在水果店卖菠萝时，具体选择哪种模式，可以从以下几个维度综合判断，并直接给出可执行建议：

**1. 按门店定位与客群分**
- **高端或精品超市/社区店（客流稳定、顾客图省事）**：建议**主打去皮好（即切菠萝）**。因为这类顾客更看重便捷、即买即吃，去皮菠萝单价高，毛利空间大。可搭配“现场现切”和“试吃”提升转化。
- **平价或批发型水果店（人流大、价格敏感）**：建议**整果为主，同时提供免费去皮服务**。顾客自己挑整果有参与感，觉得更新鲜；商家提供免费去皮，既解决痛点，又能吸引买整果的客群。售卖时挂上“买整果送去皮”的标识。

**2. 按损耗与效率管理**
- 整果损耗低、库存周转快，但需要有人力现场去皮。
- 去皮果损耗高（切开后必须当天卖完），但毛利和客单价高。建议：**每天定量备去皮菠萝**（根据前一天销量预估，下午补货），卖不完的可以作为特价水果处理，不浪费。

**3. 实操建议组合（最稳妥）**
- **最佳策略：整果为主 + 半去皮（选配）+ 去皮精品装**。
  - 摆放大堆整果，标价便宜，鼓励自己挑。
  - 旁边放几个去皮好的，用保鲜膜包好，标价稍高，方便赶时间的人。
  - 同时贴出“帮忙处理果皮”的提示，顾客自己挑完可让店员免费削皮，一举两得。

**4. 注意事项**
- 不要只卖去皮果：菠萝挑熟度很个性化，有些顾客喜欢偏甜偏熟，有些喜欢脆生，整果让他们有选择权。
- 去皮果必须保证新鲜度：切面发干、氧化发黑会影响口碑，建议覆膜冷藏，并在框边放“现切时间”。
- 在称重和价格上明确：去皮果是否含皮重？建议去皮果按净重计价，并在标签上写明，避免纠纷。

**最终建议**：如果只能选一个，**以整果为主，店内免费提供去皮服务**是最稳妥且符合大众习惯的做法；如果门店人流较少或顾客图省事，则主推去皮果。
