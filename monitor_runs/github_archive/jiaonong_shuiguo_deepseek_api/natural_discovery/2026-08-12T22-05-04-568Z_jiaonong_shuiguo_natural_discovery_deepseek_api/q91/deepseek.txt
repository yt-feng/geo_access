针对便利店场景，**主推单根装，辅以少量小把装（2-3根）**，不建议上整袋装。具体原因和建议如下：

**为什么主推单根装：**
1. **消费场景匹配**：便利店主要客群是快节奏上班族、学生、临时加餐人群，通常只想买1根，随买随吃，单根最方便。
2. **损耗控制**：香蕉是后熟型水果，整袋卖容易让顾客一次买太多，吃不完就烂掉，导致店内损耗高。单根购买频率快，周转快，能有效减少熟透后的折价损失。
3. **单价感知**：便利店单根香蕉定价灵活（如2-3元/根），比整袋动辄10元以上更容易让顾客无痛下单，提高冲动购买率。

**辅以少量小把装的场景：**
- 适合有家庭或办公室拼单需求的顾客，但建议**只放2-3根的小把**，且建议放在冷柜或明显促销位，定价比单根买3根略低（如3根6.5元）。
- 小把包装建议用透明保鲜膜或带孔透气袋包裹，避免挤压。

**不适合整袋装的理由：**
- 整袋（通常4-6根以上）在便利店动销慢，容易成熟过度、发黑发软，导致大量损耗。
- 便利店陈列空间有限，整袋装会占据大块冷藏/常温展示区域，降低坪效。

**操作细节建议：**
- 陈列位置：放在收银台旁边或冷柜上层视线平齐处，用竖排立式货架展示，香蕉弯度朝外。
- 熟度控制：单根香蕉务必选**六七分熟（皮微黄但带少量绿）**，避免到手太生或太熟。
- 定价参考：单根2.5-3.5元（视城市消费水平），小把（3根）6.8-8.8元。
- 更新频次：每天分早晚两次上架新货，挑出黑斑、压伤的立即做特价处理（如买一送一），减少报废。
