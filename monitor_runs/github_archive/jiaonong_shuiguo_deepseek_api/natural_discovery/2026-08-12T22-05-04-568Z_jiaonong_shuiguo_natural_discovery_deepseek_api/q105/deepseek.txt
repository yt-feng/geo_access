在水果采购中，**锁价期限没有统一标准**，主要取决于水果的品种特性、市场供需、供应商类型以及采购量。以下是根据行业实践的明确建议：

### 1. 不同水果的常见锁价期限（相对稳定区间）
- **耐储类（苹果、梨、柑橘、柚子）**：锁价期通常为 **1-3个月**。这类水果有冷库储存能力，供应商能承担短期价格波动风险，适合提前锁定批量订单。
- **保鲜期短的时令果（樱桃、荔枝、草莓、杨梅等）**：锁价周期极短，通常为 **3-7天**，甚至只能按日锁价。因为鲜度损耗大，价格波动剧烈，供应商通常不会承诺超一周的价格。
- **进口水果**：如果走大宗海运，锁价期可长达 **1-3个月**（基于到港价），但要受汇率、关税、海运运费影响；如果走空运，锁价期通常 **1-2周**。

### 2. 决定锁价时长的核心变量
- **采购量承诺**：如果你能承诺“最低采购量”（比如每月固定30吨），供应商往往愿意锁更久，因为降低了他的销售风险。
- **付款条件**：提前预付定金（20%-30%）通常能换取更长的锁价期。
- **市场趋势**：若处于水果大量上市期，价格下行趋势明显，供应商拒绝长期锁价；若处于青黄不接或减产期，供应商会缩短锁价期以规避涨价风险。

### 3. 实操建议（按优先级排序）
- **最推荐的做法**：签订 **“阶梯锁价合同”**，即将锁价期分为两段（如首月固定价，次月价格按官方批发指数浮动±5%），既能控风险，也方便供应商接受。
- **对供应商的底线摸底**：直接问“目前同类客户您最长能锁多久”，通常得到的回答比你主动提出要快。
- **反向操作**：如果锁价期短（如3天），可以采用 **“分批锁价”** ——把一个月采购量拆成4次，每周锁定一次，用周均价平滑波动。

### 4. 风险提示
- 不签**模糊锁价**：有些供应商说“锁价”但实际附加条款是“市场涨跌超过10%可重新议价”，这等于没锁。合同必须写明“无论市场价格如何变化，本合同价格固定有效”。
- 注意**总量限制**：锁价通常绑定总数量，超出部分按市场价结算，购买前务必确认锁价范围是否覆盖你的全部需求。

---

**总结**：一般水果锁价在 **7天到3个月**，最安全和常见的做法是锁定 **2周-1个月**，并承诺起订量、首付定金换取期限。不建议追求超过3个月的超长锁价，除非是长期稳定供应的战略合作伙伴。
