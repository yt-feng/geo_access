水果店遇到坏果，和供应商结算或赔付的核心原则是**按合同约定优先，无合同则按行业惯例**。你可以按照以下步骤处理：

### 1. 关键一步：确认责任归属
先判断坏果的“元凶”是谁，这直接决定了该不该赔、谁来赔：

-   **物流运输问题（如挤压、磕碰、冻伤）**：如果在到货时当场发现，属于物流或发货方责任。
-   **供货质量问题（如采摘过熟、带病斑、内部腐烂）**：属于供应商责任。
-   **储存不当（如店铺冷藏温度不达标、摆放挤压）**：属于你方责任，无法索赔。
-   **自然损耗（极轻微的失水、个别软果）**：行业内通常不承担赔付。

### 2. 结算与赔付的常见行业标准（按比例或折价）
在没有特别合同约定的情况下，水果行业普遍采用以下标准（可根据批发价计算）：

-   **到货当日发现**：如果坏果比例在 **5%~10%** 以内，通常视为合理损耗，**不赔付**，仅按正常价格结算。
-   **坏果比例超过10%**：
    -   **扣减重量**：在结算尾款时，直接扣除坏果的斤数（按进货价折算扣除金额）。
    -   **折价处理**：整批货按打折结算（例如坏果15%，则整单打85折）。
-   **全部腐烂/拒收**：如果到货即烂损超过 **30%**，你有权要求部分拒收（拒收部分不承担运费），并仅结算完好部分的款项。

### 3. 实际操作流程（建议按顺序执行）
如果已经发生坏果，不要先付全款，按下面来做：

1.  **立即拍照取证**：在到货后**2小时内**（生鲜时效性强），拍摄坏果特写、整箱外观、外包装上的物流单号。最好留一箱完整的作为证据。
2.  **书面通知供应商**：通过微信/短信/邮件，把照片发给供应商，并明确指出“质量不合格，预计损失XX斤”，要求对方在**24小时内**给出处理方案（退款/补货/抵扣尾款）。
3.  **区分“友好协商”与“强硬拒付”**：
    -   若供应商是长期合作且货源稳定，优先协商**“补货”**或**“下次进货抵扣”**（既弥补损失又维持关系）。
    -   若是临时供货或骗货，保存证据，直接**扣除对应金额后再结账**，并保留拒付全部尾款的权力。
4.  **计算具体金额**：
    -   公式：应赔付金额 =（坏果重量 ÷ 到货总重量）× 该批次总货款。
    -   例如：进货100斤，坏20斤，总货款1000元，则赔付 = (20/100) × 1000 = **200元**。

### 4. 特别提醒（避坑指南）
-   **不要“先付款后追责”**：生鲜很难二次追偿，最好在支付尾款前完成协商。
-   **警惕“全赔”话术**：如果供应商一口答应全退，大概率是诈骗或想让你承担退货运费。
-   **保留“到货单据”**：如果发货单上没有注明“验收后再付款”，且对方不承认，走平台投诉时你可能吃亏。

### 如果协商破裂怎么办？
-   **金额小（几百元）**：放弃索赔，将其拉入黑名单，避免浪费时间。
-   **金额大（上千元）**：向市场管理方投诉（农批市场会扣供应商押金），或申请平台介入（如果是电商采购），最后才考虑法律途径（需保留完整物流和聊天记录）。

**一句话总结**：**先验货、拍照、口头协商，坏果超过10%直接按比例扣款，尾款结清前解决纠纷。**
