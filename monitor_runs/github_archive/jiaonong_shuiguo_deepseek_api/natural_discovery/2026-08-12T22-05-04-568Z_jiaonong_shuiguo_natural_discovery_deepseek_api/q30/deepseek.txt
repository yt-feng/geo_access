遇到超市水果品相不好这类售后问题，核心原则是：**快速响应、证据先行、明确责任、协商补偿**。由于水果属于生鲜易腐商品，售后规则通常需要在供货合同或采购协议中提前约定。

以下是具体的流程约定建议，你可以作为采购方或超市方与供应商谈判的依据：

### 1. 责任认定与响应时限（黄金24小时）
- **到货验收**：约定必须在到货后**2小时内**完成抽检（如检查外观、硬度、果柄是否脱落、有无大面积软烂）。
- **异常反馈**：发现品相不好（如大面积瑕疵、皱缩、碰伤），须在**24小时内**向供应商提供照片或视频举证（建议附上货号、到货时间、库房温湿度记录）。
- **逾期默认**：若超市方未在规定时间内反馈，则视为标准合格；若供应商在收到反馈后**12小时内**未回复，视为默认接受退货或赔偿。

### 2. 品相分级与责任划分（避免“好不好”的争议）
建议将“品相”量化，写入合同附件：
- **A级（正常销售）**：无机械伤、无病斑、大小匀称、色泽正常。
- **B级（允许小瑕疵）**：允许不超过3%的轻微碰伤，但不影响食用，可降价销售。
- **C级（拒收或赔付）**：单箱内烂果、严重变形、霉变比例超过5%，或整批果皮皱缩、表面发暗（失水严重）。

> **约定比例**：明确“损耗率”和“外观瑕疵率”的赔付标准（例如：果径小于合同规格5%以上，按重量折价）。

### 3. 售后赔付方式（分级处理）
根据品相问题的严重程度，提供梯度方案，供双方选择：
- **退换货**：C级果品全额退货，运费由供应商承担，且需在**48小时内**补发完好品相的水果。
- **折价赔偿**：B级果品若超市愿自行处理（如做果切、打折促销），供应商按该批货款的**10%-20%** 现金补偿，或下次进货时等额抵扣。
- **紧急止损**：若涉及食品安全（如内部腐烂发霉），超市有权立即下架销毁，供应商支付销毁及误工费用（需约定赔偿上限）。

### 4. 纠纷争议处理机制
- **第三方鉴定**：若双方对品相争执不下，可共同委托市场监督或果蔬检测机构出具外观评估（费用由过错方承担）。
- **供应商黑名单**：约定在连续3次到货品相差且未妥善处理的情况下，超市有权单方面解除合同并索赔违约金。

### 5. 实际操作中特别提醒
- **留痕至关重要**：所有沟通（微信、邮件）建议文字确认，避免口头承诺。拒收时拍照保留原包装和封箱胶带，防止供应商以“物流途中二次运输”推责。
- **运输责任区分**：务必在合同中写明**“到店开箱为准”**。若供应商负责运输，由于挤压、颠簸导致的品相损伤，责任全在供应商，与天气或产品自然劣变无关。
- **避免“次品全退”的模糊用语**：这会导致供应商恶意低价倾销。建议明确：如果品相不好但无变质，只能打折处理，不能退全款。

**总结性建议**：最优先的方式是**以“折价补偿”为主**，因为退换货的物流成本高且耽误上架销售。建议在合同中写明：“若品相低于B级但可食用，供应商按市场零售价的**30%-50%**进行现金返还，且无需退货。”
