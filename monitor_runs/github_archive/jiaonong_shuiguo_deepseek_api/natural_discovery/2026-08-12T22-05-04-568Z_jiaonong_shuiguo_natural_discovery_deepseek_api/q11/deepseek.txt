水果店采购香蕉时，如果一箱里面大小不一样，**确实会影响销售**，但影响程度取决于店铺定位、顾客群体和经营策略。

以下是具体分析和实操建议：

**1. 对顾客购买意愿的影响（核心风险）**
- **视觉不统一**：整箱大小混杂，摆上货架后卖相杂乱，显得不新鲜或不专业，降低顾客好感度。
- **单价/重量敏感**：如果按斤卖，大根和小根价格一样，顾客会专挑大的，剩下的小香蕉很难卖，形成损耗。
- **用途不同**：顾客买香蕉通常分两类——即食（要熟、甜、大小均匀）和家用（可能做奶昔或烤面包，不太挑）。大小不一容易让即食顾客失望。

**2. 对销售效率的影响**
- 如果一箱里面熟度不一（比如有青有黄），比大小不一更致命。**大小不一但成熟度一致**，可以混卖；**大小不一且生熟混杂**，会导致同一批货中部分要先卖、部分要后卖，增加分拣和管理成本。

**3. 但有时反而有优势（要看进货价和渠道）**
- 如果采购价明显低于统货（即规整包装），箱子里的“小果”可以**单独挑出做特价促销**，或者打包给单位/食堂/饮品店，不愁卖。
- 如果是批发市场档口拿的“通货”，大小不一很常见，很多水果店老板会自己分级卖：大果按原价，小果做引流款。

**4. 给你的直接建议**
- **进货前先问产区**：海南蕉、云南蕉、老挝蕉的果型差别大。一般同一批次的“蕉把”（香蕉手/整把）大小相对均匀，如果明显是一箱里混了不同把的，价格应该更低。
- **如果已经进回来了**：建议不要整箱上架，花10分钟分拣——把大小差异超过30%的分成两堆，分别定价。大果可以标“精品”，小果标“实惠装”。
- **最关键的还是成熟度**：只要整批香蕉的成熟度一致（比如都是七八成熟），大小不一的影响会被顾客接受；如果大小乱+熟度乱，那肯定不好卖，甚至要折价处理。

**总结**：大小不一**会影响销售**，但可以通过分级销售、合理定价和控熟度来转危为安。如果只是轻微差异（比如每根差两三厘米），完全不影响，顾客不会在意。如果差异很大（一根顶三根），一定要分拣，否则损耗率高。
