在水果店采购菠萝时，判断熟度并不难，核心是**“闻、看、按、掂”**四个维度，但要注意**适度成熟**（即“七八分熟”），因为菠萝在采摘后还会继续后熟，太熟反而容易在店内耗损。

以下是具体建议：

### 1. 看颜色（最直观）
- **青绿色**：偏生，口感酸涩，切开后果肉偏白，甜度低，不建议作为现售主力。
- **黄绿色（约70%转黄）**：最佳采购区间。此时已开始糖化，存放2-3天会达到甜度峰值，损耗小。
- **全黄**：熟透，甜度最高，但**不耐放**，24小时内不卖掉易发酵变质，建议少量采购用作当日促销或试吃。

### 2. 闻气味（关键判断）
- 将菠萝凑近底部（果眼密集处）闻：
  - **浓郁香甜味** = 熟透了，需当天处理。
  - **淡淡清香** = 恰好，适合采购后冷藏或1-2天内卖。
  - **无味或青草味** = 偏生，建议等2天再卖。
  - **有酒味或酸馊味** = 已经过熟发酵，**不要采购**，损耗极高。

### 3. 按压硬度（测内部成熟度）
- 用手指轻轻按压菠萝**表皮**（靠近底部侧面）：
  - **稍微能按动、有弹性** = 成熟度适宜。
  - **硬邦邦** = 太生，水分和糖分不足。
  - **按压过软甚至凹陷** = 过熟或内部可能软烂，损耗率大。

### 4. 掂重量（测水分）
- 同样大小的菠萝，**越沉越好**（水分足）。
- 轻的菠萝可能果肉干瘪或已脱水，切开后空腔多，损耗高。

---

### 采购实战建议：
- **分批采购**：一次只采购未来2-3天能卖完的量，避免一次囤太多。
- **优先选“黄中带绿”**：这种状态既能保证甜度，又有3天左右的货架期，损耗最低。
- **隔天翻检**：采购回来冷藏（7-10°C），每天检查表皮颜色，变色快的先降价处理。
- **底部（果脐）判断**：底部越小越圆，通常果肉越厚，可食率高，损耗少。

---

⚠️ 注意：**不要看叶子长短**（那不是熟度指标，只是品种差异）。如果供应商能提供糖度测试仪，抽检糖度在12-14°Brix即可。只要坚持“闻香+按软”，就能大幅减少切开后才发现内部坏果的浪费。
