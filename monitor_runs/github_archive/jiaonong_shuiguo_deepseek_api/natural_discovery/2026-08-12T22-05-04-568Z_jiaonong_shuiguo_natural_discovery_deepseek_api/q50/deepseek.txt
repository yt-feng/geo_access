关于茶饮店采购菠萝原料，**「出汁率」比「甜度」更重要**，但更准确的说法是：**在保证基础甜度达标的前提下，出汁率是决定成本和出品稳定性的核心指标。**

以下是具体的分析和实操建议，帮助你做出可执行的决策：

### 为什么说「出汁率」优先级更高？

1.  **成本直接挂钩（核心）**：茶饮店的菠萝通常用于制作果汁、果茶或果肉基底。出汁率决定了你每斤原料能产出多少可售的液体。假设A级菠萝出汁率55%，B级40%，那么同样做一杯500ml的菠萝茶，原料成本差异可达30%以上。长期来看，低出汁率等于隐性亏损。
2.  **口感一致性**：出汁率高的菠萝，果肉纤维往往更细腻，榨出的汁水更顺滑，不易出现果渣堵塞出茶口的问题。这对于连锁门店的标准化出品至关重要。
3.  **实际甜度差异可控**：绝大多数菠萝品种（如金钻、台农17号）成熟后甜度差异不会太大（通常在12-16 Brix之间）。如果你买的是商用冷冻菠萝块或鲜切菠萝，甜度可以通过**补糖（糖浆）或使用高甜度搭配（如冰糖、荔枝汁）**来调整。但出汁率低，你无法通过添加任何东西来“变出”果汁。

---

### 如何具体判断和采购？

**第一步：先测出汁率（如果你买鲜果）**
- **方法**：取3-5个样品，去皮去芯称重，用商用榨汁机或手动挤压，称取最终果汁重量。
- **计算公式**：出汁率 = （果汁重量 ÷ 果肉去皮去芯总重量）× 100%
- **合格线**：针对茶饮用途，**建议选出汁率 ≥ 50%** 的菠萝。低于45%的品种，即使甜度高（如某些老品种），做果汁成本太高，更适合做烤菠萝或果肉布丁。
- **注意**：如果买的是**冷冻菠萝块**，留意包装上的“固形物含量”或“糖水菠萝”标签。**不推荐**买“糖水菠萝罐头”做饮品原料，因为糖水占重量，实际果肉出汁率可能只有30%左右。

**第二步：再测甜度（作为必要门槛）**
- **方法**：用糖度计（手持折射仪）测鲜榨果汁的Brix值。
- **合格线**：饮品店做菠萝茶，**鲜果汁Brix建议在12-14以上**。低于12的菠萝，你需要额外加糖，既增加成本又影响清爽度；高于16的菠萝可能过熟，容易有发酵味，也不适合长期储存。

**第三步：根据产品定位做取舍**
- **如果是做「菠萝冰沙/果茶」**：出汁率优先，因为要大量果汁打底，低出汁率的菠萝会让饮品寡淡。
- **如果是做「菠萝果肉点缀/顶料」**：甜度更重要，因为果肉直接入口，偏酸的菠萝会拉低整体风味，此时出汁率高低影响不大。

---

### 针对茶饮店的补充建议（避免踩坑）

1.  **不要只按品种买**：比如“金菠萝”和“香水菠萝”都甜，但**新鲜度的差异比对品种的偏好影响更大**。摸起来硬邦邦的菠萝出汁率一定低；捏起来微软、有浓郁果香的，出汁率和甜度通常双高。
2.  **测试你的门店配方**：买一小箱试货，按照你正式的SOP（标准操作流程）做一杯完整产品，计算杯量是否足够，口感和甜度是否稳定。**不要只凭试吃判断**，因为试吃甜不等于榨汁后够用。
3.  **长期采购建议**：如果用量大，找供应商要**专门的“饮品专用菠萝”**，这类菠萝通常是挑选出的硬肉高汁品种（如台农11号），即使甜度略低一点，但出汁稳定，更适合工业化连锁门店。

---

**一句话总结**：**先买样品测出汁率（≥50%），再测甜度（≥12 Brix），两个都达标才下单。如果只能二选一，选高出汁率的，因为甜度你可以用糖浆补，而出汁率你补不了。**
