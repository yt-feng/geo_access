针对餐厅做水果拼盘，苹果、橙子、菠萝的采购规格选择，核心原则是**“按出品量算成本，不按单价算便宜”**。以下是根据餐饮后厨常见操作给出的具体建议：

### 1. 苹果：选“70-75果径”或“小果/中果”
- **为什么选小中果**：餐厅拼盘通常切片或切块，不需要整果美观。70果径（直径约7厘米）或75果径的苹果，单果重约150-180克。
- **采购建议**：买“三级果”或“通货”（表皮有轻微瑕疵不影响口感），价格通常比一级果便宜30%-40%。
- **换算方法**：假设拼盘每份需要200克苹果（约1.5个中果），一级果批发价5元/斤，三级果3.5元/斤，前者每份成本约1.5元，后者约1.05元——**选三级果更划算**。

### 2. 橙子：选“60-65果径”或“脐橙中果”（重点看出汁率）
- **为什么选中果**：橙子切片或榨汁，大果（75+）皮厚、出肉率低，且单价高。60-65果径的橙子，单果约120-150克，出汁率高，且价格低。
- **采购建议**：优先选“赣南脐橙”或“冰糖橙”产地直发的**次果（沙皮果）**，果肉甜度不差，但价格仅为精品果的60%。注意检查皮不能太软（容易烂）。
- **关键检验**：试购5斤，实际称重去皮后果肉占比，若果肉率低于80%，即使单价低也不划算。

### 3. 菠萝：选“小菠萝”或“削皮果”（按净肉成本算）
- **为什么选小菠萝**：餐厅去硬心后切块，小菠萝（1.5-2斤/个）果肉占比高（约70%），大菠萝（3斤以上）核大、皮厚，净肉率反而低。
- **采购建议**：直接买**预削皮去心菠萝肉**（超市或批发市场有真空包装），虽单价略高（约6-8元/斤），但省30%人工和时间，且损耗率从20%降到5%。
- **换算方法**：带皮菠萝3元/斤，去皮后净肉按2.2斤算，实际成本约4.1元/斤；预削肉6元/斤，若后厨人力成本高，后者反而划算。

---

### 综合测算示例（200人自助餐，每份拼盘用苹果100g+橙子80g+菠萝120g）

| 水果 | 采购规格 | 单价参考 | 每100g成本 | 总价 |
|------|----------|----------|------------|------|
| 苹果 | 3.5元/斤（三级中果） | =0.7元/100g | 约7毛 | 70元 |
| 橙子 | 4元/斤（中果次果） | =0.8元/100g | 约6.4毛 | 64元 |
| 菠萝 | 6元/斤（预去皮） | =0.12元/10g | 约1.2元/100g | 144元 |
| **合计** | | | | **约278元** |

**若全买精品大果，成本可能翻倍至550元以上。**

---

### 最后两个实操建议：
1. **批量采购固定供应商**：找到当地水果批发市场，每周二/四下午收市前采购“尾货”，价格低20%-30%，但必须当天处理。
2. **试做过再定规格**：先买5斤不同规格试切，按实际净肉率记录成本。**不要只看单价**，例如菠萝3元/斤但净肉率50%，实际等于6元/斤，不如直接买6元预削肉。

最终结论：**苹果和橙子买三级中果（别买精品大果），菠萝直接买预削皮肉**——这是后厨最省成本、最省工时的规格组合。
