判断水果供应商是否靠谱，不能只听他口头承诺，要看**固定动作**和**风险兜底**。针对香蕉和菠萝这两个品类，我给你一套**实操筛选法**，照着做基本能避开大坑。

### 第一步：看“处理能力”而非“现货价格”

香蕉和菠萝是典型的**后熟型水果**，供应商的仓储和催熟技术比价格重要得多。

- **问香蕉催熟库**：靠谱供应商会有自己的催熟库，且能明确告诉你**乙烯利浓度、库温、催熟天数**（通常4-6天）。如果他只卖“青皮蕉”或者推脱说“拿回去自己放熟”，说明他没有后端能力，你拿货回来损耗极高。
- **问菠萝催熟环节**：菠萝对温度敏感，看他是否有冷库或冷链车。如果他说“都是当天现采”，反而可疑——因为产区到零售端通常有2-3天路程，没经过预冷处理的菠萝到店后极易黑心。

### 第二步：用“小批量试单”测试三个行为

不要一开始就签大合同，先拿**一筐香蕉+一箱菠萝（约20-30斤）**做试单，重点观察这三点：

1. **看“统货”与“分级”是否一致**：他送来的货外观好不好看是次要的，关键看**底部和内部**是否发霉、有无流胶，是否按你要求的成熟度（如香蕉要7成熟、菠萝要带绿稍黄）供货。如果一批货里大小、成熟度参差不齐，说明他没做分级，后续损耗全在你身上。
2. **看售后响应速度**：试单这批货到达后，**24小时内**主动告知你“这批货有几个坏果、怎么处理”的供应商，比等你找他扯皮的靠谱得多。关于坏果赔偿，要求**写入协议**：例如“自然损耗率超过5%的部分，按批发价赔付”，敢签这条的才值得长期合作。
3. **看付款条件**：靠谱供应商通常接受**“押一付一”或“次结”**。如果要求你一次性打全款进货，或者“款到发货”且价格明显低于市场均价5%以上，大概率是临期或品质有问题。

### 第三步：考核核心指标：损耗率

供应链是否靠谱，最终用数据说话。香蕉和菠萝到店后，**48小时内的损耗率**是硬指标：

- 香蕉要求到货后，**外层果皮无大块黑斑**，剥开无褐变，损耗率（需扔掉的）控制在**2%以内**。
- 菠萝要求**果眼无霉点、切口无酸腐味**，损耗率控制在**3%以内**。

如果连续两次试单损耗率超标，直接换人，不要听他说“天气原因”之类的解释。

### 第四步：核查“硬资质”防跑路

- **看营业执照和食品经营许可证**：拍下来留底，确认注册地址与送货地址一致。
- **打听同行口碑**：你去附近开得久的餐饮店或其他水果店，问一句“你香蕉找谁拿的”，如果好几个不同店老板提到同一个供应商，说明这个人在本地有稳定的配送网络，比网上找的更靠谱。
- **要求提供产地证明**：香蕉问是**菲律宾都乐**（大厂）还是**国产广西、海南**；菠萝问是**云南香水菠萝**还是**海南菠萝**，并让他提供原产地发货的物流单号（拍照存证）。连产地都说不清楚的，基本不专业。

### 特别提醒：香蕉和菠萝的一个隐藏大坑

**千万不要找“什么都卖”的综合批发商**。比如一个既卖猪肉又卖水果的供应商，他对香蕉的催熟和菠萝的保鲜经验一定不够。你需要找**只做香蕉+菠萝或热带水果**的垂直供应商，因为他们熟悉这两款水果的**后熟期和温湿度控制**。

---

**最终行动建议**：
1. **下一周试单**（半箱香蕉+5个菠萝），记录货损率和售后态度。
2. **谈合作条件**时，明确要求“货损超标赔付”写入合同，并约定“押一结一”（压一次货款，月结）。
3. **如果试单通过**，再加量到常规订单，但保留**每月抽查一次**到货品质的权利。

一句话总结：**靠谱的供应商是“测”出来的，不是“聊”出来的**。先用小单把对方的催熟技术、分级能力和售后承诺测清楚，再放量，你的损耗和资金压力都会小很多。
