生鲜电商水果出现坏果时，责任划分通常遵循**“谁过错、谁担责”**和**“谁主张、谁举证”**的原则，具体需要结合**运输环节**、**发货环节**、**收货环节**以及**合同约定**来综合判断。以下是清晰的划分框架和实操建议：

### 1. 核心责任判定（按流程拆解）

| 环节 | 常见责任方 | 判定依据 |
| :--- | :--- | :--- |
| **发货前（仓储/打包）** | 电商/商家 | 若水果在发货时已存在腐烂、撞伤、冻伤，或包装不符合防震防压要求（如未用泡沫箱、冰袋不足），属于商家未尽到质量保证和妥善包装义务。 |
| **运输途中（物流）** | 物流公司（但通常由商家先行赔付） | 若物流运输时间过长、野蛮装卸（暴力分拣）导致挤压、摔伤，或温控不到位导致变质，属于物流责任。但根据**合同相对性**，消费者通常直接找商家索赔，商家再向物流追偿。 |
| **收货时/签收后（短时间）** | 消费者（如果是自身存放不当） | 若消费者签收后未及时开箱验货，或未按生鲜品保存要求（如需冷藏却置于常温）导致脱冷变质，责任由消费者自担。 |

### 2. 关键判定规则（重要）

- **“坏果比例”规则**：生鲜行业普遍存在“自然损耗”容差（如3%-5%）。若坏果数量在合理损耗范围内，商家可免责；若超出合理比例，商家需承担全部或部分责任。
- **“快递签收”≠“最终验收”**：许多生鲜快递允许“倒签”或先签后验，但**收货后24小时内（或商家承诺的售后时效内）发现问题并提供开箱视频/照片举证，仍视为商家或物流责任**。
- **“冻伤/腐烂”与“撞伤”的区别**：冻伤（果皮发黑、果肉水渍状）多因冷链断裂；撞伤（局部软烂、凹陷）多因暴力装卸。若现场无法判断，一般推定商家负责，除非商家能证明是消费者存放不当。

### 3. 责任划分的例外情形（免责条件）

出现以下情况，**商家通常不承担赔偿责任**：
- 消费者已明确知道商品为“临期特价”或“秒杀处理品”，且页面显著提示“坏果不售后”；
- 收件地址位于偏远地区，且商家在发货前已明确告知运输时间较长，消费者仍坚持下单；
- 消费者未按提示保存（如把需要冷藏的荔枝常温放置超过2小时）。

### 4. 实操建议（消费者维权路径）

如果遇到坏果，建议按照以下顺序处理：

1. **立即拍照取证**：拍下**整箱水果整体状态**、**单个坏果特写**（挤压果要拍外皮伤痕，冻伤果要拍果肉剖面）、**快递面单/运单号**，最好有带日期的视频。
2. **在售后时效内联系客服**：通过平台官方渠道（如淘宝、京东、美团买菜APP内的售后入口）提交申请，不要私下微信转账，保留聊天记录。
3. **主张责任对象**：
   - 若坏果是**发货前就有**（如切开发现内部霉变），直接向商家索赔；
   - 若是**运输导致**（如整箱被压扁），商家拒绝赔付时，可要求商家提供发货时的打包视频，或向平台投诉并要求平台介入；
   - 若商家推诿，可直接在订单页面发起“平台介入”或申请官方客服仲裁。
4. **法律兜底**：若金额较大（如超过500元），可依据《消费者权益保护法》第24条要求退货退款或部分退款；若商家欺诈（如明知坏果仍发），可依据第55条主张价款三倍赔偿。

### 5. 总结一句话

> **坏果在途坏死，原则上由商家先行赔付消费者（再向物流追责）；坏果因消费者未及时验货或存放不当，责任自担；坏果超出合理损耗且商家无法自证清白，视为商家全责。**
