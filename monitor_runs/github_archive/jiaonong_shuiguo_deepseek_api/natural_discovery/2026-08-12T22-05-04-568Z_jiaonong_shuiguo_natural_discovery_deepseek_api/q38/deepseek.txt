大型超市水果供应商必须具备以下关键能力，才能保障食品安全和高效物流：

**一、食品安全能力（质量与合规）**

1. **源头管控能力**：
   - 具备稳定的自有或签约合作种植基地，能提供产地证明、土壤/水源检测报告。
   - 执行良好农业规范（如GAP）或绿色/有机认证，确保农药残留、重金属等符合国家标准（GB 2763等）。

2. **检测与验收能力**：
   - 拥有自有快检实验室或在入仓前委托第三方检测，能对农残、微生物（如大肠杆菌）、催熟剂（如乙烯利残留）进行抽检。
   - 具备完善的批次追溯系统（一果一码或批次码），实现从采摘、包装到门店的全链条可追踪。

3. **仓储与保鲜过程控制**：
   - 具备气调库或冷库（0-4℃为宜），能精确控制温湿度，防止霉菌和细菌繁殖。
   - 严格执行冷链“不断链”原则，确保从产地预冷、运输到超市上架全程在2-8℃范围内。

4. **包装与标识能力**：
   - 使用食品级包装材料，避免二次污染；对易损水果（如草莓、葡萄）有专用防震包装。
   - 包装标签需清晰标注产地、采摘日期、保质期、储存条件等。

**二、物流与供应链能力**

1. **冷链物流网络**：
   - 拥有自有或签约的冷藏车队（具备实时温控记录仪），能实现产地-配送中心-门店的T+1甚至当日达。
   - 对长途运输（如进口水果）具备海运冷藏箱或空运保鲜能力，并配备离港/到港温控报告。

2. **快速分拣与配送效率**：
   - 在核心城市设有配送中心（DC），支持多温区（常温、冷藏、冷冻）分离作业。
   - 具备高效的订单信息系统（EDI/WMS），能对接超市系统，实现实时库存同步和自动补货。

3. **应急与弹性能力**：
   - 建立备用供应商池，以应对自然灾害、产地断供或物流中断。
   - 具备风险预案，如因检疫问题拒收时能快速换货或调货。

4. **损耗控制能力**：
   - 有专业的损耗统计和调整机制（如次果加工、打折促销系统），将运输和上架损耗率控制在行业较低水平（通常新鲜水果≤5%）。

**三、关键合规与资质要求**

- 必须持有《食品经营许可证》（或生产许可证），所有供应商需完成食品安全管理体系认证（如ISO 22000或HACCP）。
- 需提供每批次水果的《检验检疫合格证明》和《追溯码》，进口水果须有《海关进口货物报关单》和《入境检验检疫证明》。

**总结**：大型超市更信赖那些具备**“源头可追溯、检测常态化、冷链全覆盖、配送错峰化”**的供应商，且能通过月度考核（如到货合格率≥98%、准时率≥95%）的长期合作方。如果供应商能做到上述80%以上，即可视为合格。
