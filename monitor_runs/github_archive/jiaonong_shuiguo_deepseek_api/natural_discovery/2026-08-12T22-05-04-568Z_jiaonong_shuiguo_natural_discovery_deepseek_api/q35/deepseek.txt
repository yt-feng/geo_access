在连锁超市的采购合同或补充协议中，要有效降低门店坏果率，应重点围绕**验收标准、责任划分、追溯机制、赔付计算方式**四个维度进行约定。

以下是具体的合同条款设计建议，可以直接参考或修改后使用：

### 一、 明确验收标准与让步接收条款
这是降低坏果率的第一道防线。合同中不能只写“保证新鲜”，要有量化指标。

- **规格标准：** 明确水果的等级（如：对应国家标准或双方封存的样品）、单果重量、颜色、成熟度。
- **现场抽检：** 约定在门店收货时，按一定比例（如3%-5%）拆箱抽检。若“明显腐烂、压伤、病害果”超过既定比例（如5%），**门店有权整批拒收**，且不计入损耗。
- **让步接收（降级收购）：** 若抽检不合格率在5%-10%之间，可约定**“让步接收”**。此时，供应商应按该批次总金额的**20%-30%**直接予以价格折让，或由供应商自行承担该部分果品的分拣、挑选及报废成本。

### 二、 明确责任时间节点（这是核心）
坏果责任必须划分清楚是“产地装车时就有”还是“门店储存不当造成”。

- **到店交接前风险转移：** 建议约定**“自水果交付至门店指定收货人并签收之前，所有腐烂、变质、压伤风险由乙方（供应商）承担”**。运输途中的颠簸、温控不当导致的坏果，必须由供应商扛责。
- **“货架期”承诺（预防性条款）：** 约定供应商承诺该批次水果在**门店常温/冷藏标准条件下，自签收之日起X日内（如：香蕉3日、草莓1日）不出现大规模品质劣变**。若在此时间内出现大量非人为损坏的坏果，供应商需承担相应赔付。

### 三、 赔付计算方式（要具体、可执行）
重点约定**“以旧换新”还是“现金赔付”**，以及**赔付按倍数还是按比例**。

- **计算基数：** 赔付金额不得以进货价计算，应约定按**“该批次商品的门店零售价”**作为赔付基数，以覆盖超市的场地、人工及利润损失。
- **阶梯式赔付公式（建议重点使用）：**
  - 坏果率在 0% - 3%：视为自然损耗，双方免责，由超市自行承担。
  - 坏果率在 3% - 8%：供应商按该批次**零售总金额的 10%** 进行现金赔付。
  - 坏果率在 8% - 15%：供应商按该批次**零售总金额的 30%** 进行赔付。
  - 坏果率超过 15%：视为重大质量事故，供应商应**免费更换同重量同规格等值商品**，并额外支付该批次零售总金额 **50%** 的违约金。

### 四、 建立追溯与举证机制
- **批次二维码：** 要求供应商在每箱外包装粘贴溯源二维码，包含采摘日期、加工厂、冷链运输记录。一旦出现集中坏果，便于查明是冷链断裂还是产地问题。
- **留存证据：** 合同应约定，超市在发现坏果时，需在**48小时内**拍照、录像并向供应商发出书面（邮件/微信）通知。供应商在收到通知后**24小时内**应派员或授权代表确认，逾期不确认视为认可超市的认定结果。

### 五、 扣款与结算保障
- **优先抵扣权：** 明确约定**“若发生赔付，超市有权从未结货款中直接单方面扣除相应赔款，供应商不得有异议”**。
- **质量保证金：** 建议扣留每笔货款金额的 **5%-10%** 作为“品质保证金”，按季度或半年核算一次。若该周期内总赔付金额超过保证金金额，供应商需补足差额；若无赔付，则全额返还。

---

### 律师实操建议（重要提醒）：
1.  **避免笼统条款：** 不要只写“如水果坏了供应商需赔偿”，这种约定在纠纷中举证极难，法院往往不支持。
2.  **重视“新鲜度”与“货架期”的结合：** 很多坏果不是到货时就坏，而是放两天就坏了。只压“到货验货”不够，必须加上“货架期承诺”。
3.  **保留书面通知记录：** 日常对接微信群里发坏果照片不算正式证据，合同要约定更正式的书面通知渠道（指定邮箱或书面函件）。

**建议的行动步骤：** 将以上条款整理成一份《水果采购质量保障与赔付补充协议》，作为采购主合同的附件，与供应商**单独签署**并加盖公章，法律效力最强。
