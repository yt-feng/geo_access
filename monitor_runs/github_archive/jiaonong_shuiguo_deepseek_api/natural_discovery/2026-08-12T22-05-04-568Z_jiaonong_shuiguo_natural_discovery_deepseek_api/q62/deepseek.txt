判断水果批发商拿香蕉的熟度和坏果风险，核心是**“看外观、捏硬度、问冷链、算时间”**。以下是具体的实操判断标准，适用于产地直采或市场批发场景：

### 一、看外观（判断熟度）

1.  **颜色分级（参考国际通用标准）**：
    -   **全绿（硬熟期）**：适合长距离运输或**囤货**，常温下约3-5天变黄。
    -   **绿黄相间（转色期）**：批发市场最常见，**适合立即批发给零售店**，约1-2天可售。
    -   **全黄（成熟期）**：果皮全黄无绿，**必须当天出完**，否则次日果肉变软、风味下降。
    -   **黄带黑斑（过熟期）**：果皮出现芝麻状黑点，**切勿整批拿货**，除非你在做低价促销且能当天清完。
2.  **看果柄（关键判断）**：
    -   **果柄鲜绿**：刚采收不久，新鲜度高。
    -   **果柄干枯发黑**：存放时间较长，内部可能已开始老化。
3.  **看棱角**：
    -   **棱角分明（五棱明显）**：偏生，口感涩。
    -   **棱角圆润（圆柱形）**：成熟度合适，糖分转化好。

### 二、捏硬度（判断坏果风险）

-   **抽查法**：不要只摸表面，**随机抽取箱内中层的香蕉**，用手轻捏果体。
    -   **整体硬邦邦**：没熟透，风险低，但可能催熟时间太长。
    -   **整体微软有弹性**：最佳状态，可出货。
    -   **局部发软、发鼓（水烂感）**：**高风险信号**，说明内部已开始发酵变质，这种果不耐运输，**必须压价或拒收**。
-   **注意**：**香蕉是箱内发热的**，如果箱子外壁摸起来温热，而里面果柄发黑，说明批发商可能在**捂熟**，这种果买回去极易批量烂掉。

### 三、问冷链与时间（风险源头）

1.  **问冷链**：香蕉在12℃-14℃下最耐放。如果批发商告诉你“今天早上从冷库刚拿出来”，风险低；如果告诉你“一直在常温货车里”，风险直接翻倍。
2.  **看库房**：如果货放在**通风干燥**处，问题不大；如果堆在**潮湿角落**（如脏乱水渍处），坏果风险极高。
3.  **问到货时间**：“这批货走了几天？”如果产地到批发市场超过4天且没进过冷库，大概率内部已软化。

### 四、最终试错与赔付规则

-   **开箱试吃**：买之前让批发商开一箱，**掰开一根看果肉**。如果果肉边缘发黑或有水渍状，整批不要。
-   **约定坏果率**：谈价时给批发商下心理暗示：“如果这箱烂了5根以上，下次我不来了”，并要求**整箱保底（烂果比例超过10%可换货）**。正规批发商通常接受“外箱破损包换”，但烂果一般只负责当批次。

### 五、特殊风险预警

-   **警惕“捂熟”货**：如果香蕉颜色全黄但**果皮无光泽、摸起来有粘手糊感**，通常是乙烯利催熟过度，口感发酸，且极易在1天内快速腐烂成黑泥。
-   **冬季风险**：冬天拿货，如果纸箱内衬有塑料膜，**必须检查是否有冷凝水**，滴水会导致果柄发霉，那才是最大的坏果源头。

**总结一句话**：**眼观色（绿黄）、手捏弹（硬软适中）、问时间（冷链）、开箱验（果肉）**。如果批发商拒绝开箱或含糊其辞，直接换一家。
