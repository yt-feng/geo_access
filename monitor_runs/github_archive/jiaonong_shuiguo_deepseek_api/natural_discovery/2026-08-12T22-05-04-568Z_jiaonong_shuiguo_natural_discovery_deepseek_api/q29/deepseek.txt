在超市与水果供应商的账期谈判中，**常见账期通常为30至60天**，具体因合作模式、双方规模和水果品类而有所不同。

以下是更细分的参考范围：

1. **标准商超（如大型连锁超市）**：通常为 **45-60天**。这是行业惯例，因为大超市订单量大、信用好，有更强的议价能力。
2. **中小型超市/社区店**：通常为 **15-30天**。为了维持供应稳定，这类超市需要更快的回款速度，或者采用“压一批、结一批”的模式。
3. **批发市场/农贸市场档口**：通常为 **现结或3-7天**。这类交易风险高、损耗大，供应商很少提供长账期。
4. **生鲜电商或新零售平台**：通常为 **30天左右**，但可能附加“结算单次最低金额”或“对账期”等条款。

**谈判时的关键提醒：**

- **水果是易损耗品**，供应商的抗风险能力较弱。如果账期太长（如超过60天），供应商可能会将资金成本和损耗风险转嫁到报价里，导致采购价上升。
- **建议策略**：如果你是采购方，可以提出“**现结或短账期换取更低单价**”，或者“**长账期（45天）但承诺月度销量**”，这样更容易达成双赢。
- 务必在合同中明确 **“到货验收合格后起算账期”**，避免因对账拖延而变相延长账期。
