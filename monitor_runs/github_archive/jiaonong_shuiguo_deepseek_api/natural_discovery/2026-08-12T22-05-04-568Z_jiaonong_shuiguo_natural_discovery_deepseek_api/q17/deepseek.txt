社区超市经营水果，核心矛盾在于**水果的“易腐性”**和**库存的“周转性”**。要解决“货压店”的问题，需要从**采购、陈列、动销、数据**四个维度同时发力。

以下是具体、可落地的操作建议：

### 一、 采购端：控制源头，少进勤补
1.  **“倒推法”报货**：不要凭感觉进货。根据**前3天同品类平均销量** + **今日天气/节假日系数**（下雨天减量20%，周末加量30%）来报货。宁可次日补货，不要一次进足。
2.  **分级采购**：进货时明确分级。**A级果**（品相极佳）用于高价陈列；**B级果**（略有瑕疵）用于促销引流；**C级果**（熟透或轻微碰伤）直接特价处理，当日清空。这样能把“损耗”提前转化为“利润”。
3.  **避坑原则**：反季水果（如冬季的西瓜）易腐烂且价高，尽量不进或少进。多选耐储存的品类（苹果、橙子、柚子）作为压舱石。

### 二、 店内部署：先进先出，视觉引导
1.  **“先进先出”纪律**：上货时，**必须**将旧货摆在上层/前层，新货放下层/后层。这是防止“底部烂果”压抑库存的第一道防线。
2.  **分类陈列控湿**：
    -   **叶菜类/草莓/蓝莓**：必须进冷藏柜，且不要叠放超过2层，否则底层必压坏。
    -   **香蕉/芒果/木瓜**：属于“后熟果”，不能进冷柜，常温摆放，一旦成熟度到8成，必须立刻转移至特价区。
3.  **“临期区”物理隔离**：在收银台旁设置**“今日特价/尽快食用”**专区，用夸张的黄色标签。这不仅是处理库存，更是**制造紧迫感**，让顾客觉得买到了便宜，而非买到了坏果。

### 三、 动销端：动态定价，快速兑现
1.  **“一日三价”策略**：
    -   **上午**：按正价销售，毛利控制在25-30%。
    -   **下午3点后**：对卖相稍差或熟度高的单品，降价20%促销。
    -   **晚上8点后**：所有易腐品（葡萄、桃子、菌菇）**一口价打包**（如10元3盒），目标是**回笼资金**，哪怕平本也好过扔掉。
2.  **“试吃转化”**：对于熟透的（但未坏的）水果，切成果切或果汁，放在试吃台。这能极大减少损耗，且能带动周边高毛利商品（如酸奶）的销售。

### 四、 库存数字化：盯紧“周转天数”
1.  **设定警戒线**：不同水果设定库存周转天数（如草莓2天，苹果7天）。每天闭店后，用Excel或收银系统导出库存表，**当天发现超过警戒线的SKU，次日开盘必须做买赠或搭配销售**。
2.  **巧用“搭售”**：如果西瓜库存多，可以推出“西瓜+勺子”的套餐，或者“切好的西瓜盒”加量不加价。**把“整果”变为“果切/果汁”**，是消化库存最快的方式，且毛利更高。

### 五、 特殊技巧：给水果“化妆”
-   **翻堆**：每天早中晚各翻动一次货架上的水果（尤其是苹果、梨），把底下的翻上来。这能减少因热度和重力造成的隐性损伤。
-   **喷水**：对绿叶菜和带皮水果（如黄瓜、青枣），定期用细雾喷壶喷水，保持鲜嫩感，视觉上能提升“新鲜度”，减少主观损耗。

**总结核心口诀**：**“宁可少卖，不可多进；上午看品质，下午看销量，晚上看库存。”** 严格执行“先进先出”和“临期区”制度，基本就能解决压货问题。如果连续两周某单品周转天数超过5天，请果断将其从进货清单中划掉。
