关于商超采购菠萝后，是卖整果还是卖切好的，**建议“双轨并行”，但以“卖切好的”作为核心增长点，同时保留部分整果以满足不同客群**。

具体决策取决于你的**门店定位、商圈人群和损耗控制能力**，以下是分场景建议和实操策略：

**一、先算一笔账（核心逻辑）**

| 维度 | 卖整果 | 卖切好的 |
|------|--------|----------|
| **毛利率** | 约20%-35%（看进货价） | 约40%-60%（去皮去芯后按份计价） |
| **损耗率** | 高（5%-15%，顾客挑拣、压伤） | 低（熟度统一切开，可及时售卖） |
| **客单价** | 低（单果约8-15元） | 高（一杯切好的可卖6-12元） |
| **周转率** | 慢（顾客挑，买完就走） | 快（即买即食，冲动消费） |
| **人工成本** | 低（无需现场加工） | 高（需专人切配、包装） |

**结论**：切好的菠萝**毛利更高、周转更快**，但需要人工和展示条件；整果是基础引流品，适合“称重买回家自己处理”的顾客。

**二、不同门店类型的建议**

1. **社区型/菜场型门店（家庭客多）**
   - **主推整果**：顾客习惯买回家自己削，按个卖或按斤卖。
   - **辅助切好的**：提供“代削皮”服务（免费或收1-2元），或切半装盒，方便下班族。
   - 重点：整果要做到“熟度均匀、个头统一”，避免烂芯。

2. **写字楼/商场/交通枢纽型门店（白领、游客多）**
   - **主推切好的**：做成独立小包装（200g-300g/盒），搭配竹签，价格标注“一份X元”，省去称重麻烦。
   - 可做“试吃台”，切好小块展示，刺激冲动购买。
   - 整果仅作为展示或小规格销售（如1斤装）。

3. **中高端精品超市（重视体验）**
   - **必须做切好的**，且要提升附加值：
     - 切好后用盐水浸泡或冷藏；
     - 分“菠萝肉”、“菠萝芯”等不同部位卖（芯更甜脆，可单独标价）；
     - 搭配薄荷叶、酸奶杯等组合售卖。
   - 整果要选“菲律宾菠萝”等高颜值品种，摆放在显眼位置。

**三、实操关键（决定成败的细节）**

1. **损耗控制（最重要）**：
   - 切好的菠萝**建议按“日清”原则**，当天未售完的果肉，傍晚做“买一送一”或打折处理，或直接做成果汁/果切拼盘。
   - 整果进货时，检查果柄底部，避免黑心；到店后**竖放**（果眼朝上），减少压伤。

2. **定价策略**：
   - 整果按斤定价时，可稍高于成本价，作为“对比锚点”（让顾客觉得切好的更划算）。
   - 切好的按份定价，例如：1/4个菠萝（约300g）卖6元，比买整果自己削更贵，但方便性溢价被接受。

3. **展示与鲜度**：
   - 切好的菠萝必须**冷藏展示**（4-8℃），用透明盒+保鲜膜，顶部放价签。
   - 现场切芒果的“明档操作”最能吸引人：看到新鲜切配，信任感更强。

4. **季节营销**：
   - 春季（菠萝上市期）：主打“新鲜现切”，买切好的送小勺。
   - 夏季：可做“冰镇菠萝”或“菠萝+椰汁”组合杯。

**四、最终建议（如果你只能选一种起步）**

- **如果你的门店有专人能负责加工（哪怕兼职）**：**先卖切好的**。因为毛利高，且能吸引年轻客群，快速回笼资金。
- **如果你暂时没人手、门店不能放冷藏柜**：先卖整果，但**必须提供免费削皮服务**，否则顾客流失。

**最后提醒**：无论卖哪种，一定要在进货时选**同一成熟度批次**（避免有的生有的熟），不然切好后口感差异会砸口碑。你先去周边3家超市（社区超市、便利店、精品超市）观察一下他们怎么卖，记录价格和盒子规格，再决定你的主推方向。
