商超采购水果时，**损耗控制通常比进价高低对最终毛利的影响更大**。这主要取决于水果损耗的放大效应。

核心逻辑在于：**损耗是“净损失”，而低价是“毛收益”。**

为了让你更直观地判断，我们可以从以下三个维度拆解：

**1. 数学测算：损耗的“利润吞噬”效应**
假设你购进一批水果，**进价为1元/斤，售价为3元/斤**（含税不考虑其他费用）。

- 情形A（进价低，损耗高）：进价0.9元/斤（省10%），但损耗率15%。
  - 实际可售数量 = 100斤 * 85% = 85斤
  - 毛利 = **85斤 × 3元 - 100斤 × 0.9元 = 255元 - 90元 = 165元**
- 情形B（进价高，损耗低）：进价1.1元/斤（贵10%），但损耗率控制在5%。
  - 实际可售数量 = 95斤
  - 毛利 = **95斤 × 3元 - 100斤 × 1.1元 = 285元 - 110元 = 175元**

**结论**：虽然B的进价贵了20%，但因为损耗低了10个百分点，最终毛利反而高出**10元/百斤**。损耗率每降低1%，相当于进价降低1%乘以（售价/进价）的倍数，这个倍数通常高达2~3倍。

**2. 商业现实：损耗是“时效性”的，低价是“一次性”的**
- **低价**：你可以在采购时砍价、批量采购或选择次级品，但价格优势在**入库那一刻**就已锁定。
- **损耗**：水果是易腐品，损耗每天都在发生（自然失水、腐烂、顾客挑拣、理货不及时）。今天省下的几毛钱进价，可能因为10%的腐烂而全部亏回去。**且损耗一旦发生，是不可逆的现金流出。**

**3. 运营中的“隐形损耗”**
很多低价水果（如尾货、次果）往往卖相不佳、成熟度高，这会导致：
- 顾客挑拣翻动加速损耗。
- 不得不频繁打折促销，进一步摊薄毛利。
- 增加员工理货、分拣的人工成本。
这部分隐性成本，往往比账面上的低价更致命。

---

**给你的实操建议（优先级排序）：**

1. **优先控损耗，而非压低进价**：采购时，在保证基本品质（成熟度、硬度、新鲜度）的前提下再谈价格。如果一款果品进价便宜但极易烂，宁可放弃。
2. **算清“综合成本”**：和供应商谈判时，不要只看单价，要求对方提供**易腐等级和预计可售卖天数**，用“每日毛利”而非“单斤毛利”来评估。
3. **用损耗率来倒逼采购**：如果某个品类损耗率连续超过10%（普通水果）或15%（高水分水果），即使它利润率再高，也要考虑替换供应商或调整采购品种。

**一句话总结**：**亏本的往往不是买贵了，而是坏多了。** 在水果这个行业，**损耗控制是毛利的第一道闸门**，价格只是第二道。建议你优先把损耗率盯紧，再谈价格。
