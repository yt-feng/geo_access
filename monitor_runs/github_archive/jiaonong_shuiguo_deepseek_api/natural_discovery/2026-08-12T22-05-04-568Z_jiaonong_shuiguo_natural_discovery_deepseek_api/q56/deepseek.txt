茶饮店在采购水果时，为确保食品安全并降低风险，应要求水果供应商提供以下核心证明和文件：

1. **营业执照**：确保供应商为合法注册企业，具有食品经营或生产许可资质。
2. **食品经营许可证/生产许可证**：证明其具备销售或加工水果的资质。
3. **农产品合格证明**：如产地出具的《农产品质量安全检测报告》或《合格证》，证明农药残留、重金属等指标符合国家标准。
4. **批次检测报告**：每批次水果的第三方或官方检测报告，重点包含农药残留（如GB 2763）、重金属、致病菌等项目。
5. **进货凭证与追溯信息**：供应商应提供供货清单、产地证明或追溯码，便于实现产品源头追溯。
6. **运输与储存证明**：如冷链运输记录、车辆消毒证明，确保水果在运输过程中未发生污染或变质。
7. **进出口相关文件**（如为进口水果）：海关报关单、入境货物检验检疫证明。

**建议操作额外措施**：
- 与供应商签订质量安全协议，明确责任和召回机制。
- 定期要求供应商更新随批次的检测报告，以应对季节性或产地变化。
- 建立供应商审核制度，最好实地考察其种植、分拣、包装环节。

若供应商无法提供上述完整证明，建议谨慎合作，宁可更换供应商，以规避潜在的食品安全风险。
