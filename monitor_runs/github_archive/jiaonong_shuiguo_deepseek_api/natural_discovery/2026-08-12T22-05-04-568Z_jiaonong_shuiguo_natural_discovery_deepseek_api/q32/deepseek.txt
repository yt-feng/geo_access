判断连锁超市的香蕉供应商能否全年稳定供货，不能只凭口头承诺，需要通过一套**结构化、可验证**的考核流程。以下是具体的实操建议：

### 第一步：考察源头与产地分布（决定抗风险能力）
香蕉是热带作物，单一产地受台风、病虫害、气候异常影响极大。全年稳定供货的核心在于**多产地轮换**能力。

- **索要产地清单**：要求供应商提供所有合作农场/基地的名单及所在国家（如厄瓜多尔、菲律宾、越南、中国云南/海南等）。
- **验证季节互补性**：确认不同产地是否覆盖全年不同月份。例如：中国大陆香蕉集中在秋季，东南亚（菲律宾、越南）可以衔接冬春，厄瓜多尔则全年稳定。
- **防伪措施**：要求提供海关报关单、原产地证明（Form E等），核验单据日期是否与装船期吻合。

### 第二步：考察仓储与冷链设备（决定全年稳定性）
- **仓库容量**：供应商是否拥有大型冷库（容量是否超过你常规周需求量的3-5倍）？这决定了他们在台风季或船期延误时能否提前囤货。
- **催熟房（催熟库）**：香蕉生鲜度高，供应商应具备专业催熟库（乙烯催熟），且催熟批次可灵活控制。如果只有冷库没有催熟房，交货周期会不可控。
- **损耗率承诺**：要求供应商书面承诺到货时的“干耗率”或“黑疤率”标准（如≤3%），并约定违约赔偿条款。

### 第三步：贸易历史与合同约束（决定契约可靠性）
- **要求过去3年的月度出货记录**：重点查看是否有连续断供超过7天的情况；如果对方拒绝提供，要高度警惕。
- **设置阶梯价机制**：香蕉价格随船期货价波动大（如菲律宾交割价格），建议在合同中约定**“月度锁价”或“最低供应量+浮动价”**，避免供应商因价格倒挂（现货价高于合同价）而捂货不卖。
- **违约金条款**：明确约定“因供应商原因导致断货，需按日赔偿超市当日该品类销售额的10%”。

### 第四步：现场查验（最关键的落地动作）
不要只看PPT，务必做**双盲抽检**：

1. **突击检查仓库**：随机时间到冷库，查看香蕉是否按到货批次分区域存放（不混批），看温度和湿度记录仪是否连续运行无跳崖。
2. **跟车验货**：跟车一次从对方仓库到你门店的物流，看是否全程冷链（香蕉要求在13-14℃环境）。
3. **小批量试单**：先签3个月合同，要求前两个月每批货物延迟2天交，看供应商是否抗压；如果连续两批有烂果，立即淘汰。

### 第五步：备用供应链评估（超市方自行准备）
即使供应商表现优秀，超市也应至少准备**1家备选供应商**（不同国家产区）。关键原则：**永远不要把全年香蕉总量放在同一个篮子里**。建议主供应商占比70%，备选占比30%，并每季度测试一次备选的响应速度。

---

**总结判断标准**：如果供应商能提供**完整产地清单+可查的报关记录+冷库实地照片/视频+最近一年的断供率为零**，且愿意在合同中明确“保量”条款，基本可判断具备全年稳定供货能力。

最后提醒：务必警惕报价过低的供应商，香蕉利润薄，过低价格往往意味着用次果或缩短冷链时间，长期看损耗会更高。建议你让财务部门按“到店成本+损耗成本”而非“批发价”来测算全年盈亏。
