采购方在引入新品时，建议采取**“小批量、多频次、快反馈”**的策略。最稳妥的做法是：

**首批试卖量建议控制在该门店（或渠道）该品类正常周销量的 20%～30% 之间。**

具体操作建议如下：

1.  **核心原则：只测市场，不赌库存。**
    -   如果供应商给的是最低起订量，优先选择**最小起订量**，而不是预估销量。
    -   水果损耗率高，首单宁少勿多。如果卖断货，可以紧急补货；如果滞销，损失可控。

2.  **按销售周期估算（以日销为基准）：**
    -   **保守试卖（3天量）**：用过去该品类日均销量 × 3天，作为首批订货量。这足以测试口感、价格接受度和复购率。
    -   **激进试卖（5天量）**：如果供应商给的价格极具竞争力，且该品类是当季爆品，可放宽到5天销量，但不建议超过7天。

3.  **关键监控指标（决定是否转正式采购）：**
    -   **动销率**：试卖期间，每天售出数量是否在递增？
    -   **损耗率**：水果易腐，若试卖结束损耗率超过10%，说明定价或品质有问题。
    -   **复购率**：是否有老客户回头购买（这是新品能否长期做的核心）。
    -   **售罄时间**：如果在试卖期内提前售罄，说明可以快速跟进大货。

4.  **给采购的特别提示：**
    -   跟供应商明确约定试卖期的**退换货政策**（如：变质果包赔）。
    -   试卖期通常为 **3~5天**，结束后立即开复盘会，不要拖到第7天才决定，否则新鲜度优势会消失。

**总结一句话：** 先订**够卖3天的量**（以日均销为基准），快速验证市场反馈，再决定是否加量。这比预估“大概能卖多少”更科学，也能在供应商面前掌握议价主动权。
