做水果生意，供应商选择最容易忽视的不是“价格”和“有没有货”，而是那些影响长期稳定的小细节。按实操重要性，重点看这几类：

**1. 分级标准是否稳定，而不是“今天好明天差”**
很多供应商口头说“一级果”“精品果”，但没有书面分级标准。长期做水果，最怕同一供应商这批甜、下批酸，这批大、下批小。要问清楚：按什么标准分？大小、糖度、色泽、瑕疵率怎么定？能否每次按同一标准供货？

**2. 损耗责任怎么分**
水果损耗高，最容易扯皮的是：运输中压伤、熟过头、到货后腐烂算谁的？要提前约定：到货验收时限、抽检比例、超标怎么赔、补货还是退款。否则每次出问题都靠人情谈，长期一定不稳定。

**3. 产地和季节切换能力**
只靠一个产地、一个品种，旺季过了就断供。要看供应商有没有多产地、多产区切换能力，比如同一品种不同纬度产区衔接。长期稳定不是永远有同一个货，而是淡季也能给出替代方案。

**4. 采后处理能力**
这个最容易被忽视。采摘时间、预冷、分拣、包装、冷链，直接决定到店后的货架期。尤其叶菜类、浆果类、荔枝、樱桃等，采后处理差，店里损耗会成倍增加。要问：是否有预冷？冷链车还是普通车？包装是否抗压？

**5. 结算和账期是否可持续**
有些供应商前期给账期很松，后期突然收紧，导致现金流断档。要观察：账期是否稳定、是否随行情随意变、旺季会不会要求现款。长期合作要的是可预期，不是一时便宜。

**6. 信息透明度**
能不能提供产地、采摘日期、批次、检测报告？出问题时能不能追溯到具体批次？不透明的供应商，一旦出现农残、品质事故，你很难快速处理。

**7. 旺季保供能力**
平时供货好不代表旺季可靠。要问：节假日、台风、寒潮、集中上市期，能不能优先保你？有没有备选货源？很多供应商旺季会优先给大客户，小客户容易被放鸽子。

**8. 售后响应速度**
不是看承诺，而是看实际：坏果反馈后多久回复？多久补货？是否推诿？长期合作中，售后速度比单次价格更重要。

**9. 是否只做“倒手”**
纯倒手供应商价格可能低，但品质和供应稳定性差。最好找有一定产地组织能力、分拣能力或冷链能力的供应商，哪怕价格略高，长期更稳。

**10. 合作边界和排他性**
要明确：是否给你区域保护？会不会同时给隔壁同行供同款低价？是否要求独家采购？这些不写清楚，后期容易打价格战。

**实操建议：**
选供应商时不要只看一次报价，做三件事：
- 连续试单 3 批，记录到货合格率、损耗率、售后响应；
- 要求提供书面分级和验收标准；
- 至少保留 2 个主力供应商 + 1 个备用供应商，避免被单一供应商卡脖子。

长期稳定靠的是“标准可复制、责任可界定、旺季有备份、售后不扯皮”，而不是单纯找最便宜的货源。
