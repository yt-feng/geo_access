小水果店做附近小区团购，水果供应商至少要能支持这几类服务，否则团购很容易在履约和售后上翻车。

**1. 稳定供货与分级能力**
- 能按团购批次稳定供货，不是今天有明天没。
- 能提供明确等级：果径、甜度、产地、规格、净重，避免“图片好看、到手差”。
- 能支持小批量多频次补货，适合小区团购的预售+集中配送模式。
- 最好能按团购价提供专门规格，比如5斤装、家庭装、尝鲜装。

**2. 价格与账期支持**
- 团购价要有优势，至少比零售进货价明显低。
- 能接受短期账期或押金制，减轻小店现金流压力。
- 价格波动时能提前通知，避免今天报价明天涨价。
- 能提供阶梯价：量小一个价，量大有返点或优惠。

**3. 分拣、包装与贴标**
- 能按小区团购订单做分拣，最好按“团长/小区/楼栋”分好。
- 包装要适合配送：抗压、透气、防磕碰，叶菜和浆果要单独处理。
- 能贴标签：品名、规格、重量、产地、保存方式、售后电话。
- 能支持定制包装或团长品牌贴纸，方便小区团购宣传。

**4. 配送与时效**
- 能配送到小店、团长点或小区集中点。
- 能按约定时间到货，团购最怕“说好下午到，晚上还没来”。
- 支持冷链或保鲜运输，尤其是草莓、车厘子、荔枝、蓝莓等。
- 能处理临时加单、减单、改地址。

**5. 售后与损耗承担**
- 坏果、烂果、少重、错发能快速补发或退款。
- 售后响应快，最好当天或次日处理。
- 能明确损耗责任：运输坏果谁承担，到货后多久内可售后。
- 能接受一定比例的自然损耗，而不是全推给小店。

**6. 营销与素材支持**
- 提供产品图片、视频、文案、卖点，方便发小区群。
- 能提供团购素材：海报、接龙文案、价格表、产地介绍。
- 能配合做试吃、爆品推荐、节日礼盒。
- 能提前给档期和主推品，方便小店排团。

**7. 数据与对账**
- 能按订单出库单、对账单，方便小店和团长结算。
- 能提供每批次重量、金额、售后扣款明细。
- 支持微信、支付宝、对公转账等灵活结算。
- 出现差异时能快速核对，不是“大概差不多”。

**8. 风险与合规**
- 有稳定产地或一级批发渠道，不是临时倒货。
- 能提供必要质检、农残检测或产地证明。
- 食品安全问题能追责、能召回。
- 不窜货、不绕开小店直接做小区团购，这点很关键。

**你筛选供应商时，重点问这8个问题：**
1. 最小起订量多少？
2. 一周能送几次？
3. 坏果怎么赔？
4. 能不能按小区分拣？
5. 团购价能不能锁价？
6. 有没有图片文案素材？
7. 售后多久内处理？
8. 会不会绕过我直接做小区团购？

**最适合小水果店的供应商，不是价格最低的，而是：**
供货稳、分拣细、售后快、不抢客、能配合做团购节奏的。  
如果只能选一个最关键能力，优先选**售后和损耗承担**，因为小区团购做的是信任，一次坏果处理不好，整个群都会流失。
