判断一批香蕉，核心看“颜色、手感、果柄、果身、气味、切口”六项，再结合季节和运输方式判断坏果风险。

**1. 看颜色**
- 青绿、硬：未熟，适合远途或囤货，但催熟成本高。
- 黄中带绿：转熟中，适合计划 2–4 天内出货。
- 通体黄、果尖微软：适熟，适合马上分销。
- 出现黑斑：如果是少量“芝麻斑”，通常是甜熟期；如果斑块大、连片、发暗，坏果风险高。
- 果柄发黑、发霉：说明存放久或受过潮，风险高。

**2. 摸手感**
- 整把硬：生。
- 轻按果身有弹性、不塌：熟度合适。
- 一按一个坑、回弹慢：过熟，运输和摆放损耗大。
- 局部软烂：已经开始腐坏，附近果子也容易被传染。

**3. 看果柄和切口**
- 果柄青绿、切口新鲜：货龄短。
- 果柄干枯、发黑、长毛：货龄长或冷链有问题。
- 切口发黑、渗液、有酸味：腐坏风险高。

**4. 闻气味**
- 有淡淡果香：正常转熟。
- 有酒味、酸味、发酵味：已经过熟或内部开始腐烂。
- 有霉味：整批可能受霉菌污染。

**5. 看果身和果指**
- 果指饱满、棱角不明显：发育好，熟后品质通常不错。
- 果指瘦、棱角尖：可能早采，催熟后口感差。
- 果身有裂口、压伤、水渍斑：运输伤，后续容易烂。
- 果轴/果冠发黑腐烂：整把容易从中心烂起。

**6. 判断坏果风险**
高风险信号：
- 整箱有酒味、酸味。
- 果柄大面积发黑发霉。
- 果身多处软烂、渗液。
- 箱底有汁液、纸箱发潮。
- 同一把里多根果指出现黑斑连片。
- 冷链断过、暴晒过、淋过雨。

低风险信号：
- 颜色均匀青绿或黄中带绿。
- 果柄青绿、切口新鲜。
- 手感硬实或轻弹。
- 无酒味酸味，箱内干燥。
- 只有少量表皮小斑点，果肉不软。

**7. 实操验货方法**
- 随机抽 3–5 箱，不要只看最上面。
- 每箱抽上、中、下三层。
- 重点翻箱底，看有没有汁液、霉斑、压烂果。
- 随机切 2–3 根，看果肉是否白净、有无黑心、异味。
- 按“好果/软果/烂果”计数，烂果超过 3%–5% 就要谨慎，超过 8%–10% 通常不建议整批接。

**8. 按用途判断**
- 马上卖：选黄中带绿到通体黄，少量芝麻斑可接受。
- 囤 3–7 天：选青绿偏硬、果柄新鲜、无伤。
- 做催熟：选青硬、果指饱满、切口新鲜。
- 做烘焙/果切：可接受更熟，但不能有酒味、酸味和软烂。

一句话：**青硬看果柄，转熟看颜色，过熟闻气味，坏果翻箱底和切口。** 如果果柄黑、箱底湿、有酒酸味、软烂多，这批货坏果风险就高。
