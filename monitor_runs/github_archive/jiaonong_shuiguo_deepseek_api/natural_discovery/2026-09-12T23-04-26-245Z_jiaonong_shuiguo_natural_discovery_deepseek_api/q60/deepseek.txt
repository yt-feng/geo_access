水果到货不合格，核心是**先把损失锁在“当日可补救”范围内，再用制度避免下次**。可以这样约定和处理：

**1. 当场验收，不合格不签收或少签收**
- 送货单上直接注明：品种、数量、不合格原因（烂果、规格不符、成熟度不够/过熟）、照片。
- 不合格部分**不进入入库单**，避免后续扯皮说“你已收下”。
- 可要求司机/供应商现场签字确认，或微信发图并让对方回复确认。

**2. 补货条款写进采购合同/供货确认单**
重点约定这几条：
- **补货时限**：比如“验收不合格后，供应商须在当日营业结束前或次日开店前1小时补足”。
- **补货方式**：优先“同规格同数量补货”，不能补货时按“退一赔一”或按采购价退款。
- **替代方案**：若无法及时补同款，供应商需提供同价位、同用途替代水果，并提前经门店确认。
- **费用承担**：补货运输费、因缺货产生的合理损失由供应商承担。
- **验收标准**：写清糖度、成熟度、单果重量、腐烂率上限，比如“腐烂率≤3%”。
- **违约责任**：超时未补货，按当次货款的20%-30%扣款，或取消当月返点/账期优惠。

**3. 不影响营业的实操办法**
- **保留安全库存**：对常用水果设1-2天安全库存，特别是易缺的柠檬、百香果、芒果、葡萄等。
- **替代菜单**：提前准备2-3款“可替换水果”的饮品配方，缺货时直接切换，不临时改菜单。
- **分时段补货**：要求供应商上午开店前、下午高峰前两个窗口补货，避免营业中反复处理。
- **紧急备选供应商**：本地水果店/批发市场留1-2个应急渠道，哪怕价格略高，先保营业。
- **门店权限**：店长可先采购应急水果，金额设上限，事后凭票向供应商扣款或报销。

**4. 避免扯皮的证据习惯**
- 收货全程拍照/录像，特别是开箱和称重。
- 不合格品单独存放，标注“待退”，不要和合格品混放。
- 补货沟通尽量走文字，电话后补微信确认。
- 每次问题记录在供应商考核表，累计几次就降级或换供。

**一句话建议**：合同里写清“验收不合格当日/次日开店前补足，否则按货款扣罚并承担缺货损失”；门店端同时留安全库存和替代配方，这样既不耽误营业，也能把责任压给供应商。
