判断给养老院或医院食堂供水果的供应商是否合规、稳定，核心是看四件事：**资质文件能核验、货源与冷链能力可查、检测/追溯制度能落地、合作与财务状态稳定**。这类场景的特殊性在于：吃水果的人很多是老人、病人，对食品安全、软硬适口、农残和微生物控制要求比普通食堂更高，所以不能只看报价。

## 一、先核验合规，不要只看复印件

要求供应商提供并**在官方渠道核验**以下材料，重点看是否在有效期内、主体名称是否一致：

1. **营业执照**：经营范围含食品/食用农产品销售，注册时间最好满2年以上。
2. **食品经营许可证 / 食品生产许可证（如涉及分装加工）**：无证或超范围经营直接淘汰。
3. **食用农产品相关承诺或备案**：若当地市场监管要求入场销售者备案，要看备案凭证。
4. **检验检测报告**：
   - 农残快检或定量检测报告，最好近1个月内、对应本次供货品类；
   - 有条件的看第三方检测机构报告，注意报告编号、样品名称、检测项目、结论是否可查。
5. **从业人员健康证明**：配送、分拣、接触直接入口水果的人员应有有效健康证。
6. **索证索票能力**：进货凭证、产地证明、供货商上游资质是否齐全，能否做到“一批一证、一批一票”。

**判断技巧**：对方只发微信图片、拒绝提供原件核验、报告日期与到货批次对不上、许可证经营范围写的是“预包装食品”却供散装鲜果，这些都是高风险信号。

## 二、看货源和供应链稳定性

医院、养老院不能接受“今天有货明天没货”，要重点问：

1. **货源基地或一级批发市场渠道**：是自有基地、长期合作果园，还是临时从批发市场倒货。后者价格波动大、稳定性差。
2. **主营品类和季节替代方案**：比如冬季北方水果、夏季易腐水果，是否有稳定替代品，避免断供。
3. **仓储和冷链**：
   - 是否有冷库、冷藏车或保温配送；
   - 验收时看水果中心温度、有无压伤、腐烂、异味；
   - 叶菜类水果、浆果类、切果类对冷链要求更高。
4. **配送频次和应急能力**：能否固定频次配送，临时加单多久能到，节假日是否配送。
5. **损耗与退换货机制**：坏果、烂果、规格不符是否无条件退换，响应时间写进合同。

## 三、把“稳定性”变成可考核指标

建议在合同或考察表中设置这些指标：

| 维度 | 可考核指标 |
|---|---|
| 准时率 | 每月准时到货批次/总批次 ≥ 98% |
| 合格率 | 抽检农残合格、感官合格 ≥ 99% |
| 退换货 | 质量问题2小时内响应，24小时内补换 |
| 价格波动 | 报价随行就市但需提前书面通知，涨幅有约束 |
| 断供记录 | 年度断供次数、缺货品类及原因 |
| 投诉处理 | 医院/养老院投诉闭环时间 |

连续2—3个月不达标，就应考虑备选供应商。

## 四、现场考察比看资料更有效

如果金额较大或供餐人数多，建议实地看：

- 分拣场地是否干净、有无防鼠防虫设施；
- 水果是否离地存放、生熟分开；
- 冷库温度记录是否完整；
- 快检设备是否真的在用，还是摆样子；
- 配送车辆是否清洁、有无温度记录；
- 工作人员是否戴手套、帽子，健康证是否上墙。

养老院和医院还可以要求供应商提供**每批次农残快检结果**，有条件的食堂自己做入厂快检，双保险。

## 五、财务和合作稳定性也要看

1. **结算方式**：是否接受月结、对公转账，能否开正规发票。只收现金、私人转账的慎用。
2. **经营异常**：通过国家企业信用信息公示系统查是否列入经营异常、严重违法失信、行政处罚。
3. **涉诉和被执行**：频繁买卖合同纠纷、被列为被执行人的，供货稳定性风险高。
4. **保险**：是否购买食品安全责任险，保额能否覆盖食堂规模。
5. **合作客户**：是否有学校、医院、养老机构等同类客户，能否提供合作证明或回访。

## 六、实操建议：先小批量试供

不要一上来就签长期大单。可以：

1. 先让2—3家供应商同时小批量试供1个月；
2. 每周记录到货时间、品质、损耗、退换货响应；
3. 对每批次做农残快检或索要检测报告；
4. 试供合格后再签年度框架协议，并保留1家备选供应商。

**一句话判断标准**：资质能在官方系统查到、每批水果能追溯到来源和检测、冷链和配送能稳定兑现、出了问题能快速退换并承担责任——四条都满足，才算合规且稳定。只要有一条含糊，就应降级为备选或直接淘汰。
