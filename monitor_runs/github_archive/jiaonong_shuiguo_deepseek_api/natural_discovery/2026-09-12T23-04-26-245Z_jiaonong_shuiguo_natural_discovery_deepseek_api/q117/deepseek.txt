先给一个可执行的判断框架：**新品首单不要按“预估销量”下，而要按“能快速验证、又不会压死库存”的量下。**

比较稳的做法是：

1. **先定试卖量：按 3～7 天销量试**
   - 如果是门店/档口：先拿 **3天预估销量 × 1.2** 左右。
   - 如果是线上团购/社群：先拿 **1～2 次团购量**，不要直接备一周以上。
   - 如果是批发档口：先拿 **最小起订量 + 少量加订**，优先谈可退换或补货快。

2. **设一个硬上限**
   - 新品首次采购金额，建议不超过该品类日常采购额的 **5%～10%**。
   - 或者不超过你 **3天总水果采购预算的 10%～15%**。
   - 超过这个数，就不是试卖，是押注。

3. **分两批下，不要一次压满**
   - 第一批：够卖 **2～3天**，看动销。
   - 第二批：如果前两天卖得动，再补 **3～5天**。
   - 如果第一天动销低于预期，立刻停补，转促销或搭配销售。

4. **用这几个指标判断能不能加量**
   - **售罄率**：3天内卖掉 70% 以上，可以考虑加订。
   - **损耗率**：超过 8%～10%，先别加，可能品种或包装不适合。
   - **复购/询问**：有顾客回头问、团购群有人接龙，才说明有持续需求。
   - **毛利**：扣掉损耗、运费、促销后还有合理毛利，才值得继续。

5. **最稳的首单公式**
   **首单量 = 最小起订量 与 “3天保守销量” 取较小值，再上浮不超过20%。**
   如果供应商要求起订量太大，就谈：
   - 拼柜/拼车
   - 先拿样品箱
   - 首批支持退换
   - 二次补货锁价
   - 账期或代销

6. **别忽略品种差异**
   - 易损耗、熟得快：草莓、杨梅、荔枝、水蜜桃，首单要更小，1～2天量。
   - 耐储存：苹果、橙子、梨、猕猴桃，可以放到3～5天量。
   - 礼盒/高价新品：先预售或团购接龙，再采购，最稳。

**一句话建议：**
新品首单按 **2～3天保守销量** 试，金额控制在品类采购额 **5%～10%**，卖得动再补，卖不动立刻停。能谈代销、退换、拼单的，优先用这些方式降低风险。
