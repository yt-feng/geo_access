水果采购合同里并没有一个全国统一的“坏果率超过多少就必须赔付”的法定比例。赔不赔、赔多少，主要看**合同怎么约定**，以及**验收标准和验收时间**是否明确。

实务上可以这样判断：

1. **先看合同约定**
   - 如果合同写了“坏果率超过3%由卖方赔付”或“超过5%按比例扣款”，就按合同执行。
   - 如果合同只写“按国家标准验收”或“质量合格”，但没有具体坏果率，就容易扯皮。

2. **常见行业做法（仅供参考，不是法定标准）**
   - 精品果、商超供货：坏果率通常要求控制在 **1%—3%** 以内。
   - 普通批发、电商发货：常见容忍度在 **3%—5%**。
   - 大宗加工果、允许一定瑕疵的：可能到 **5%—10%**，但一般会按等级扣价或折价。
   - 超过约定比例后，常见处理方式是：
     - 按超出部分比例扣款；
     - 整批退货；
     - 要求补货；
     - 赔偿分拣费、运费、损耗等实际损失。

3. **建议写进合同的最稳妥条款**
   - 明确验收标准：品种、规格、成熟度、腐烂、碰伤、虫眼、畸形分别怎么算。
   - 明确抽样方法：抽多少箱、每箱抽多少、谁来抽、什么时候抽。
   - 明确坏果率计算方式：是按重量、个数还是箱数计算。
   - 明确赔付线：例如“坏果率≤3%不扣款；3%—5%按超出部分扣款；＞5%买方有权拒收或退货，卖方承担运费及损耗”。
   - 明确验收期限：例如到货后24小时内验收，逾期视为合格。
   - 明确争议处理：复检机构、复检费用谁承担。

4. **如果合同没写，怎么办**
   - 可以按交易习惯、行业标准、双方以往合作惯例来协商。
   - 协商不成，只能看是否有证据证明对方违约，以及实际损失多少。
   - 法院或仲裁一般不会自动支持某个固定坏果率，而是看合同、验收记录、照片、视频、第三方检测等证据。

所以，**不是“超过多少就法定必须赔”，而是“合同约定超过多少就赔”**。如果你正在签合同，建议把坏果率、抽样方式、赔付比例和验收时限写清楚，这比事后争论“超过多少该赔”有用得多。
