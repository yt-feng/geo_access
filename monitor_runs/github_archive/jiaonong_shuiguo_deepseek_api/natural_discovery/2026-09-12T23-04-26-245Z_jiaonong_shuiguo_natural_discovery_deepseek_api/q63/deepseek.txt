判断菠萝哪个规格更容易出货，不能只看“大小”，核心是看**下游客户拿去做什么、按什么计价、损耗谁承担**。可以按下面几步直接判断。

**1. 先按销售渠道倒推规格**
- **水果店/社区团购/电商**：通常偏好 **单果 1.2–1.8 斤**，好按个卖、好打包、客单价低。
- **商超/精品水果店**：偏好 **1.8–2.5 斤**，外观整齐、果形好，适合按个或按斤卖。
- **餐饮/果汁店/烘焙/罐头厂**：更看 **出肉率和稳定性**，常用 **2.5 斤以上** 或加工专用果，按斤/吨计价。
- **路边摊/集市**：偏好 **1.5–2.5 斤**，走量快，太大反而难卖。
- **礼盒/节日团购**：偏好 **2–3 斤、果形正、冠芽完整**，但对价格不敏感，对颜值敏感。

**2. 看三个硬指标，不只看重量**
- **按什么卖**：按个卖就偏中小果；按斤卖可接受大果；加工厂按吨/出肉率算。
- **损耗率**：菠萝易烂、易碰伤。规格越大，运输磕碰和终端切果损耗可能越高；中小果周转更快。
- **出肉率**：加工客户最关心“去皮后剩多少”。同样重量下，果形圆、皮薄、眼浅的规格更好出。

**3. 用最快的方法试销判断**
拿同一批货分 3 档：
- 小果：1.2 斤以下
- 中果：1.2–2.0 斤
- 大果：2.0 斤以上

连续 3–5 天记录：
- **出货速度**：当天清货比例
- **询价次数**：哪个规格问的人多
- **退货/损耗**：哪个规格烂得多、退得多
- **利润**：不是只看销量，要算“销售额 - 损耗 - 运费 - 人工”

**4. 实操结论**
多数批发场景下：
- **走量最快**：1.2–2.0 斤中果，尤其水果店、团购、路边摊。
- **利润较稳**：1.8–2.5 斤，适合商超和礼盒。
- **加工厂好出**：2.5 斤以上或等外果，但价格压得低。
- **最难走**：特别大但果形差、或者特别小且成熟度不齐的规格。

**5. 建议你直接这样做**
先问下游客户一句话：  
“你是按个卖、按斤卖，还是拿去加工？”  
然后主推 **1.2–2.0 斤中果** 试销，搭配 **1.8–2.5 斤商超果**。  
如果 3 天内中果清货最快、损耗最低，就把它作为主规格；大果只留给加工或礼盒渠道，不要盲目囤。
