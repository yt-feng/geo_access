结论：**按箱结算最适合食堂水果的日常管理，按斤适合价格波动大或高值水果，按份只适合已分装到人的场景。**

**三种方式对比**

| 方式 | 优点 | 缺点 | 适用场景 |
|---|---|---|---|
| 按斤 | 计价公平，损耗和实际用量挂钩 | 称重、验收、对账最费人力，容易在称上和水分/筐重扯皮 | 西瓜、散装苹果、香蕉等价格波动大的品类 |
| 按箱 | 验收快、对账简单、便于计划采购 | 箱内品质不均、净重不足时容易吃亏 | 苹果、橘子、梨等标准箱装、日常大宗水果 |
| 按份 | 分发快、每人成本固定、损耗可控 | 采购端要提前分装，份量争议多，灵活性差 | 已切好/已分装到人的餐后水果 |

**食堂更推荐的做法**

1. **主用按箱**：大宗、标准化程度高的水果按箱采购，合同里写清楚**箱规、净重、允许误差、坏果率**。
2. **高值或波动大的按斤**：如车厘子、草莓、西瓜，按斤验收，避免箱装里以次充好。
3. **按份只用于分发环节**：采购按箱/斤，食堂内部再按份出餐，不要把“按份”当成采购结算方式。
4. **统一验收标准**：无论哪种方式，都要有**抽样称重、坏果扣重、拍照留痕**，否则按箱最容易吃暗亏。

**一句话判断**
- 想省管理成本、水果标准化 → **按箱**
- 想价格公平、控制品质 → **按斤**
- 想控制每人成本、减少分发纠纷 → **按份**，但只适合末端分发。
