旺季菠萝用量突然变大时，和供应商约定临时补货，核心不是“临时加一句”，而是提前把**补货触发条件、数量、价格、时效、验收、违约**写清楚。可以按下面这样做。

**一、先判断你需要的补货类型**
1. **紧急补货**：1—3天内要到，用于救急。
2. **短期增量补货**：未来1—2周每周增加固定量。
3. **旺季锁量补货**：整个旺季保证一个最低供应量，价格和优先级提前锁定。

不同方式，谈判重点不同。紧急补货最贵，锁量补货最稳。

**二、和供应商约定时，必须写清这7项**
1. **触发机制**
   - 例如：你提前24小时/48小时发书面补货通知，微信、邮件、订单系统都算书面。
   - 约定最低起订量，比如每次临时补货不少于50公斤/100箱。

2. **补货数量**
   - 不要只写“需要时补货”，要写“每次最多补多少、每天最多补多少、整月上限多少”。
   - 例如：旺季期间，供应商承诺每周可临时补货2次，每次不超过300公斤。

3. **价格**
   - 临时补货价格最容易涨。约定：
     - 按原合同价执行；
     - 或按市场价但不超过原合同价的X%；
     - 或按某批发市场当日均价上浮不超过5%。
   - 不要接受“到时再谈”，否则旺季容易被卡。

4. **到货时效**
   - 写清：下单后几小时/几天内到店。
   - 例如：当天12点前下单，次日10点前到店；紧急单24小时内到店。
   - 超过时效怎么赔，也要写。

5. **品质标准**
   - 菠萝品种、成熟度、规格、糖度、是否有黑心、腐烂率、单果重量范围。
   - 临时补货最怕品质降级，必须约定“与常规货同标准”。

6. **验收和退换**
   - 到店后几小时内验收。
   - 不合格部分怎么处理：拒收、换货、扣款、补发。
   - 例如：坏果率超过5%，当日换货或按比例扣款。

7. **违约责任**
   - 供应商不按时、不按量供货，怎么赔。
   - 你临时取消订单，怎么处理。
   - 建议约定：因供应商原因断供，导致你门店停售，按实际损失或每单固定违约金赔偿。

**三、实际操作建议**
- **提前谈，不要等断货再谈。** 旺季前1个月就签补充协议。
- **给供应商一个“保底量+浮动量”。** 比如保底每周500公斤，浮动最多再加300公斤。供应商更愿意接。
- **价格可以分段。** 合同内量按原价，超出部分按约定上浮价，双方都好接受。
- **用书面确认。** 微信聊天也要写清“品名、数量、单价、到货时间、验收标准”，并让对方回复确认。
- **保留替代供应商。** 即使签了临时补货协议，也要有1—2个备选，防止一家断供。
- **每次补货单独下单。** 不要只在电话里说，避免后面扯皮。

**四、可以直接用的约定模板**
> 旺季期间，甲方可提前24小时向乙方发出临时补货通知。乙方应在收到通知后24小时内送达。临时补货价格按原合同价执行；超出原合同量部分，上浮不超过5%。每次临时补货不少于50公斤，每周不超过3次。菠萝品质标准与常规货一致，坏果率超过5%的部分，乙方应无条件换货或按比例扣款。乙方未按时到货的，每延迟24小时按该批货款的10%支付违约金；因乙方断供导致甲方停售的，乙方赔偿甲方实际损失。

**一句话总结：**
不要只和供应商口头说“旺季帮我多补点”，而要签一个**临时补货补充协议**，把“提前多久说、补多少、什么价、多久到、什么品质、不合格怎么办、断供怎么赔”全部写死。这样旺季才不会被供应商牵着走。
