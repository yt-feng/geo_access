超市和水果供应商的账期没有统一标准，主要取决于**超市规模、水果品类损耗特性、供应商层级**三个因素。以下是一般市场惯例，供你判断：

## 常见账期区间

| 合作模式 | 常见账期 | 说明 |
|---|---|---|
| 大型连锁超市 / 商超 | 30–60 天 | 强势渠道，常压账期；部分要求月结30–45天 |
| 中型区域超市 | 15–30 天 | 较常见，有的按周结或半月结 |
| 小型超市 / 便利店 | 现结 或 7–15 天 | 议价能力弱，往往需现款或短账期 |
| 生鲜专营 / 批发市场 | 现结、周结为主 | 水果损耗高，供应商普遍要求快结 |

## 水果品类的特殊性

水果属于**高损耗、短保质期**商品，供应商对账期比一般标品更敏感：

- **叶菜、浆果等易损品**：通常要求现结或 7 天内
- **普通水果（苹果、柑橘等）**：可谈到 15–30 天
- **进口/高端水果**：因资金占用大，供应商倾向短账期

## 实操建议

1. **先看自身定位**：你是超市方还是供应商方？强势方通常能把账期拉长。
2. **账期与价格挂钩**：想要 60 天账期，供应商往往会在报价里加 2%–5% 的资金成本。可以用“缩短账期换降价”来谈。
3. **结算方式细化**：明确是“货到起算”还是“对账后起算”，以及逾期是否计息，避免扯皮。
4. **试探性报价**：供应商可先报“现结价”和“30天价”两档，让超市自己选。

总的来说，**30 天左右是超市与水果供应商之间最普遍的中间值**，具体要结合双方议价能力和品类损耗来定。
