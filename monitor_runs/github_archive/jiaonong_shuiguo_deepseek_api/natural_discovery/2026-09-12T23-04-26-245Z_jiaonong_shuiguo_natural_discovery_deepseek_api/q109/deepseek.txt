优先谈**账期**，其次**售后**，最后**配送**。原因是这三者对长期合作的风险和现金流影响不同。

**1. 账期最值得优先谈**
- 水果是生鲜，损耗和价格波动大，账期直接决定你的现金流压力和议价空间。
- 长期合作里，账期如果没谈清楚，后面很容易变成“先供货、后扯皮”。
- 优先争取：明确结算周期、对账时间、付款日、逾期处理，最好写进合同。
- 如果供应商强势，至少先锁定“账期稳定”，不要接受随口变。

**2. 售后第二优先**
- 水果质量问题高频，售后规则不清，最后往往是你承担损耗。
- 重点谈：坏果率标准、到货验收时限、补货/退款/折价规则、责任划分。
- 尤其要明确：是“按车赔”“按件赔”还是“按比例赔”，以及多久内有效。
- 售后谈清楚，能直接减少隐性成本，也能反向约束供应商质量。

**3. 配送第三优先，但不能不谈**
- 配送影响时效和损耗，但通常可以通过换物流、加冷藏、调整下单节奏来缓解。
- 重点谈：送达时间、冷链要求、迟到处理、临时加单/减单规则、运费承担。
- 如果配送不稳定，再好的账期和售后也会被拖累，所以它是保障项，不是最优先项。

**建议的谈判顺序：**
1. 先谈账期：锁定结算周期和付款规则。
2. 再谈售后：明确质量责任和赔付机制。
3. 最后谈配送：约定时效、冷链和异常处理。

**一句话结论：**
先谈账期保现金流，再谈售后保质量风险，最后谈配送保履约稳定。
