判断香蕉供应商能否全年稳定供货，核心不是看它“有没有蕉”，而是看它有没有**跨产区调度能力 + 催熟/冷链能力 + 合同履约记录**。香蕉是典型的“产地季节性轮换”品类，单一产区几乎不可能全年稳定，所以你要审的是它的**供应链结构**。

**1. 先问清它的货源结构，而不是问“能不能全年供”**
要求供应商书面列出全年各月份的产地来源，例如：
- 1-4月：云南/老挝/缅甸
- 5-8月：海南/广东/广西
- 9-12月：菲律宾/越南/厄瓜多尔等进口补位

如果对方只说“我们全年都有货”，但说不出月份和产区对应关系，基本不可靠。真正稳定的供应商一定有多产区组合，而不是赌一个产地。

**2. 查它有没有催熟和冷链能力**
香蕉从青蕉到门店可售，必须经过催熟。你要确认：
- 是否有自有或长期合作的催熟库
- 催熟库容量能否覆盖你的日销量峰值
- 冷链运输是否全程可控，尤其是夏季和冬季
- 到店蕉的成熟度是否可分级、可预约

没有催熟能力的供应商，旺季可能供得上，淡季或天气异常时最容易断。

**3. 看过往履约数据，不看口头承诺**
要求提供近12个月的：
- 月度实际供货量
- 缺货次数和缺货原因
- 到货合格率、烂耗率
- 突发天气或港口延误时的替代方案

重点看它有没有在春节、台风季、进口口岸拥堵期仍然稳定交付的记录。没有历史数据的供应商，建议先小批量试单3个月。

**4. 用合同锁“保供条款”，而不是只锁价格**
合同中要写清：
- 月度最低供货量
- 缺货赔偿或替代补货机制
- 产地切换时的提前通知期
- 质量标准（条蕉/梳蕉、长度、成熟度、机械伤比例）
- 价格调整机制（随行就市还是固定加价）

**5. 做一次压力测试**
可以故意在淡季或天气异常月份下一次略高于日常的订单，看它能否按时按质交付。这比看宣传资料有效。

**6. 最好保持“双供应商”**
即使一家很强，也建议主供+备供，比例约7:3。香蕉受台风、病害、口岸政策影响大，单一供应商风险太高。

简单判断标准：**能说清全年产区轮换、有催熟冷链、有12个月履约数据、愿意签保供条款的，才值得进入主供名单。**
