判断供应商售后是否稳定，核心不是听他口头承诺，而是把“响应”变成可验证、可量化的条件。可以从以下几个层面落地判断：

**一、签约前：先看硬性条款**
1. 明确售后范围：烂果、黑心、催熟不均、到货温度异常、缺斤少两等，分别怎么赔、赔多少、多久内提报有效。
2. 写死响应时效：如“2小时内响应、24小时内给处理方案、48小时内补货或退款”，并约定超时违约金。
3. 约定举证方式：照片、视频、抽检记录、第三方检测，避免事后扯皮。

**二、签约前：用历史记录验证**
1. 要近3—6个月其他商超客户的售后处理记录，看平均响应时间、赔付完成率。
2. 直接打电话给其现有客户（尤其同城、同规模的），问三个问题：出问题多久回？赔得爽不爽？补货及不及时？
3. 查有没有因售后被投诉、被市场监管处罚的公开记录。

**三、试单期：用小批量压力测试**
1. 先下小单，故意留1—2个可记录的问题（如到货有压伤、成熟度不符），按合同正式提报，计时看他多久回、怎么处理。
2. 测非工作时间：晚上或周末提报一次，看是否有人接、是否只是机器人回复。
3. 测补货能力：要求48小时内补一批，看是否真能到。

**四、日常运营：建立可追踪指标**
建议对每个供应商记这几个数：
- 首次响应时长（目标≤2小时）
- 方案确认时长（目标≤24小时）
- 赔付/补货完成时长（目标≤48小时）
- 售后一次解决率
- 月度投诉次数与金额占比

连续2—3个月不达标，就降级或替换。

**五、两个品类要特别注意**
- 菠萝：易黑心、易水烂，售后要覆盖“到货后开箱抽检”和“售卖期内变质”两种场景，明确责任分界。
- 香蕉：催熟和温度敏感，售后要写清是“到货成熟度不符”还是“仓储后催熟失败”，否则容易互相推责。

**一句话判断法：** 敢把响应时间、赔付标准、超时罚则写进合同，且试单期能按约执行的，才算有稳定售后；只靠口头说“放心，有问题找我”的，基本不可靠。
