酒店采购水果盘原料时，建议把“验收标准”写进采购单或合同附件，供应商至少应保证以下几类规格和外观要求：

**一、基本规格标准**
1. **品种与产地明确**  
   写清具体品种、等级、产地或产区，不接受模糊表述如“时令水果”“优质水果”。
2. **单果重量/大小分级**  
   例如苹果直径≥75mm、橙子单果重≥180g、西瓜单果重≥4kg等，按酒店实际摆盘需求定级。
3. **成熟度一致**  
   到货成熟度应适合当天或次日使用，不能一批生、一批过熟。需要后熟的品种可约定“到货成熟度70%～80%”。
4. **可食率与出成率**  
   对需要切配的水果，可约定出成率范围，如西瓜可食率≥60%，菠萝净肉率≥45%，避免供应商用次果充数。
5. **农残与食品安全**  
   供应商应提供农残检测合格证明或承诺符合国家食品安全标准，必要时可要求批批检测或定期送检。
6. **包装与标签**  
   包装应洁净、透气或冷藏适配，标签注明品名、产地、等级、净重、采摘/包装日期、供应商信息。
7. **冷链与运输**  
   需冷藏的水果应全程冷链，到货中心温度符合要求，如叶菜类0～4℃，热带水果按品种设定，避免冻伤或高温腐烂。

**二、外观标准**
1. **色泽正常**  
   具有该品种应有的色泽，不能明显褪色、发黑、发黄或染色。
2. **形状完整**  
   果形端正，无明显畸形、开裂、压扁、机械伤。
3. **表面洁净**  
   无泥土、药斑、虫粪、霉斑、污渍，无异常蜡感或不明涂层。
4. **无病虫害**  
   不得有活虫、虫卵、虫蛀孔、明显病斑、腐烂点。
5. **无腐烂与霉变**  
   到货时不得有软腐、酸腐、霉变、发酵味。
6. **无明显机械伤**  
   允许轻微表皮擦伤但不影响切配和存放；严重磕碰、裂口、刺伤应拒收。
7. **无异物**  
   不得混入枝叶、铁丝、塑料、石子等杂物。
8. **大小均匀**  
   同一批次内规格尽量一致，便于摆盘美观和成本核算。
9. **口感与风味正常**  
   抽检应具有该品种正常风味，不过酸、过涩、过生、过熟或异味。

**三、建议写进验收条款的量化要求**
- 抽检比例：每批次抽检5%～10%，不足10箱抽检不少于3箱。
- 不合格判定：腐烂、霉变、虫蛀、严重机械伤、异味，单项即可拒收。
- 允许误差：单果重量或直径允许±5%～10%偏差，超出部分按降级或扣重。
- 退货换货：不合格率超过约定比例，如3%～5%，供应商应无条件退换并承担运费。
- 到货时间：明确每日/每次到货时间，保证酒店备餐前完成验收。

**四、不同水果的侧重点**
- **苹果、梨、橙、柑橘**：重点看大小、色泽、无压伤、无腐烂。
- **西瓜、哈密瓜**：重点看成熟度、无裂口、无软腐、糖度可抽检。
- **葡萄、提子**：重点看果粒紧实、无掉粒、无霉变、果梗新鲜。
- **草莓、蓝莓、树莓**：重点看无压伤、无霉、无汁液渗出，冷链要求高。
- **菠萝、芒果、火龙果**：重点看成熟度一致、无冻伤、无黑心、无发酵。
- **香蕉**：重点看成熟度可控，避免到货即过熟或全青。

**五、最简可执行版本**
如果你只需要给供应商发一条标准，可以写：

“供应商须保证水果品种、产地、等级、单果规格明确；到货新鲜、色泽正常、大小均匀、无腐烂、无霉变、无虫害、无异味、无明显机械伤和异物；符合国家食品安全及农残标准；按酒店要求冷链配送；抽检不合格率超过5%时，酒店有权拒收或要求退换并扣款。”

这样既方便验收，也能减少后续扯皮。
