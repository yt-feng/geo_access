买香蕉时，想避开“太生”或“太熟”，核心是看**颜色、手感、果柄和用途**。

**1. 看颜色**
- **想要买回家放 2～4 天吃**：选**整体黄、略带一点点青肩**的。
- **想当天或第二天吃**：选**通体金黄、没有青肩**的。
- **想马上吃或做奶昔**：选**出现少量褐色斑点**的，甜度通常更高。
- **别选**：大面积青绿、硬邦邦的，通常要放很久；或者表皮大面积发黑、发软出水的。

**2. 摸手感**
- 轻轻捏一下：**微软但有弹性**，适合近期吃。
- **很硬**：偏生。
- **一按就陷、软塌塌**：偏熟，可能内部已经过软。
- 注意别反复捏同一根，香蕉容易压伤。

**3. 看果柄和蕉身**
- 果柄**青绿**：通常偏生。
- 果柄**发黄、略干**：成熟度较合适。
- 果柄**发黑、萎缩**：可能放久了。
- 蕉身有明显压伤、裂口、渗水的，别选，容易从伤处烂。

**4. 按用途选**
- **马上吃**：金黄或带少量糖斑。
- **放几天吃**：黄中带一点青。
- **做烘焙/奶昔**：带褐色斑点更甜。
- **想多放几天**：买稍青一点的，回家常温放。

**5. 到店快速判断口诀**
- 当天吃：**黄透微斑**
- 两三天吃：**黄多青少**
- 想多放：**青肩明显但已转黄**
- 不要：**全青硬、全黑软、有伤出水**

**6. 买回家后怎么控熟**
- 想快点熟：和苹果或熟香蕉放同一个纸袋里，常温催熟。
- 想慢点熟：分开挂放，别闷在塑料袋里；成熟后冷藏，表皮会变黑但果肉能多撑几天。
