超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果品类、超市规模和当地监管要求：

**一、基础资质证明**
- 营业执照
- 食品经营许可证（或食品流通许可证）
- 若是进口水果，还需进出口经营权相关资质

**二、进货证明（证明合法来源）**
- 供货发票或送货单
- 产地证明 / 采购合同
- 上游供应商的资质复印件

**三、检测报告**
1. **农药残留检测报告**：最常见、最核心，通常要求符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》。
2. **重金属及污染物检测**：部分品类或抽检时需要。
3. **食品添加剂/保鲜剂检测**：如使用保鲜处理时。
4. **植物检疫证明**：尤其进口水果或跨区域调运时，需《植物检疫证书》。
5. **进口水果**：还需海关出具的《入境货物检验检疫证明》。

**四、其他可能要求**
- 承诺达标合格证（农产品质量安全承诺书）
- 批次检测报告（超市一般要求“一批一检”或定期抽检）
- 包装标签符合 GB 7718 等标准

**实操建议：**
- 首次合作时索要全套资质 + 近期检测报告；
- 每次进货留存送货单和对应批次检测报告，建立台账；
- 进口水果重点核对检疫证明和中文标签；
- 具体清单建议直接向对接超市的采购/质检部门确认，因为不同超市（如永辉、沃尔玛、盒马）内控标准会有差异。
