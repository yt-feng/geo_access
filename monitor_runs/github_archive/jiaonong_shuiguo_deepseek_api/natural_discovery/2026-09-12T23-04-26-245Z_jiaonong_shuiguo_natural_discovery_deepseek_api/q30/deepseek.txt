超市水果到货后发现品相不好，售后流程建议按“验收前、验收中、验收后”分阶段约定，核心是把**判定标准、时限、举证方式、处理方式、责任归属**写清楚，避免扯皮。

下面是一份可直接拿去改的约定框架：

**一、先约定验收标准和时限**
1. **到货验收时限**：建议约定“到货后XX小时内完成验收”，生鲜类通常2-4小时内，最长不超过当日。
2. **验收方式**：双方共同在场开箱/抽检，或买方拍照、视频记录后发给供方确认。
3. **品相标准**：不要只写“品相好”，要量化，例如：
   - 外观：无明显压伤、裂口、腐烂、发霉、虫眼；
   - 成熟度：符合约定成熟度，过生或过熟比例不超过X%；
   - 规格：单果重量/直径/等级符合订单；
   - 新鲜度：无萎蔫、无异常气味、无冻伤。
4. **抽检规则**：按到货件数抽检，比如每批抽5%-10%；抽检不合格率超过X%，可判定整批不合格或按比例扣款。

**二、约定不合格的处理方式**
可按严重程度分档：
1. **轻微瑕疵**：不影响销售，可协商折价接收，比如按不合格比例扣款。
2. **中度不合格**：可要求换货、补货，或退货退款，运费由责任方承担。
3. **严重不合格**：腐烂、变质、食品安全风险，买方有权拒收整批，并要求退款及承担因此产生的合理费用。
4. **部分合格**：可约定“合格部分照收，不合格部分退货/换货”，避免整批一刀切。

**三、约定举证和责任**
1. **谁举证**：到货验收阶段，一般由买方在约定时限内拍照/视频并通知供方；逾期未提出，视为验收合格。
2. **供方确认**：供方应在收到通知后XX小时内响应，逾期不响应可视为认可买方提出的问题。
3. **责任归属**：
   - 运输造成的损伤，看是谁安排运输、谁承担运输风险；
   - 采摘/包装/冷链问题，通常由供方负责；
   - 买方存储不当导致的变质，由买方负责。
4. **证据保留**：不合格品建议保留样品或影像，直到售后处理完毕。

**四、约定退款、换货和费用**
1. **退款**：确认不合格后XX个工作日内原路退回或抵扣下一批货款。
2. **换货**：供方应在XX小时内补发，补发部分重新验收。
3. **费用**：因质量问题产生的退货运费、分拣费、损耗，由责任方承担。
4. **扣款公式**：可写“扣款金额=不合格数量×单价”，或“按不合格比例×该批货款”。

**五、写进合同或订单的简版条款**
可以直接用这段：
> 买方应在到货后____小时内完成验收。验收以双方共同抽检或买方影像记录为准。如发现腐烂、压伤、规格不符等品相问题，买方应在验收期内通知供方并保留证据。供方应在____小时内响应。轻微瑕疵按不合格比例折价；中度问题可换货或退货；严重变质买方有权拒收并退款。逾期未异议视为验收合格。因供方原因导致的质量问题，相关运费及合理损耗由供方承担。

**六、实操建议**
1. 每次到货都拍开箱视频，最好带时间、批次、货号。
2. 不要口头约定，微信、订单备注、合同都算，但要写清时限和标准。
3. 长期合作也建议每批留验收单，双方签字或聊天确认。
4. 如果是平台采购，先看平台规则；平台规则优先于你们私下约定时，要按平台流程走。

如果你要的是“超市作为买方”和“供应商作为卖方”之间的约定，上面这套就能直接用；如果你要的是“消费者在超市买到品相不好的水果怎么售后”，那是另一套流程，我可以再给你写消费者角度的版本。
