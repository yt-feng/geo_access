建议按“先要文件、再要批次、最后留样”的顺序准备，重点不是只看一张合格证，而是能对应到你要采购的批次。

**一、向供应商要的基础资质**
1. 营业执照、食品经营许可证（或食用农产品销售相关备案/资质）。
2. 若是种植基地直供：基地主体资质、种植/生产相关信息。
3. 若是批发商/经纪商：其上游来源说明，最好能追溯到具体基地或产地。
4. 供货合同或框架协议中明确农残超标责任、退换货和赔偿条款。

**二、每批次必须索要的资料**
1. **承诺达标合格证/食用农产品合格证**：看产地、主体、品种、批次、开具日期。
2. **检测报告**：优先要该批次或同批次、近期批次的农残检测报告。  
   - 最好由有资质机构出具（CMA/CNAS）。  
   - 报告要能对应品种、产地、批次/日期。  
   - 不要接受“一个品种一张旧报告长期通用”。
3. **进货凭证/销售单**：写明品名、数量、产地、批次、供货商、日期。
4. **产地证明或追溯信息**：如产地码、追溯码、基地名称、采收日期。
5. **自检记录**：供应商如有快检室，可要快检记录，但快检不能替代法定检测报告。

**三、如果供应商是外地或大批量供货**
1. 要该批次“产地准出”相关证明。
2. 要运输和贮存记录，避免混批、污染。
3. 要明确是否使用保鲜剂、防腐剂、催熟剂等，以及是否符合标准。
4. 对高风险水果（如草莓、葡萄、豇豆、芹菜、韭菜等）提高索证频次。

**四、超市自己应同步做的动作**
1. 每批到货登记：品种、产地、供应商、批次、数量、报告编号。
2. 抽检或快检：重点测有机磷、氨基甲酸酯类等常见农残。
3. 留样：按批次留样，保留到该批售完后再保存一定期限。
4. 不合格处理：立即下架、封存、通知供应商，必要时报告市场监管部门。
5. 建立供应商档案：资质、报告、不合格记录、整改记录。

**五、可以直接向供应商发的清单**
“请提供：  
1. 营业执照、食品经营许可证；  
2. 本批次食用农产品承诺达标合格证；  
3. 本批次或同批次农残检测报告（CMA/CNAS优先）；  
4. 进货凭证/销售单，写明产地、批次、采收日期；  
5. 产地证明或追溯信息；  
6. 如有快检，提供快检记录；  
7. 农残超标包退包换及赔偿承诺。”

**关键判断标准**
- 报告能否对应到“这一批”；
- 检测项目是否覆盖常见农残；
- 出具机构是否可靠；
- 产地、批次、日期是否一致；
- 供应商是否愿意承担超标责任。

如果供应商只能给一张模糊合格证、报告对不上批次，或者拒绝提供追溯信息，建议不要直接大批量采购，至少先做批批快检并保留书面风险告知。
