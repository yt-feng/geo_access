会，而且这是生鲜采购里很常见的风险点。起订量太高，通常不是“多买一点”这么简单，而是会直接放大损耗，尤其是香蕉和菠萝这两种熟度变化快、储存要求不同的水果。

**为什么起订量高会推高损耗**

1. **到货熟度不可控**
   - 香蕉：多为青蕉或催熟蕉。青蕉可放，但催熟后几天内就得卖/用掉；如果起订量高，一次到货太多，后熟会集中发生。
   - 菠萝：成熟后货架期短，气温高时更容易过熟、发黑、出水。

2. **销售速度跟不上到货速度**
   - 如果日均销量固定，起订量翻倍，库存周转天数就翻倍。
   - 香蕉、菠萝都不是耐放品类，周转一慢，损耗率会明显上升。

3. **储存条件容易被挤爆**
   - 香蕉怕冷、怕挤压、对乙烯敏感，不适合和很多果蔬混放。
   - 菠萝虽然相对耐放，但堆压、通风差、温度高时会快速劣变。
   - 冷库/货架一旦被高起订量占满，先到的货可能被压住，先进先出难执行。

4. **分级和次品率会被放大**
   - 到货量大时，次品、机械伤、成熟度不一的货也会同比增加。
   - 如果验收不严，损耗会从“少量挑拣”变成“整批处理”。

**怎么判断风险高不高**

你可以用一个简单公式判断：

**库存周转天数 = 当前库存量 ÷ 日均销量**

- 香蕉：如果周转天数超过 **2-3 天**，损耗风险就开始明显上升。
- 菠萝：如果周转天数超过 **3-5 天**（视气温和成熟度），也要警惕。
- 气温高、没有冷库、门店/档口销量波动大时，这个天数还要再缩短。

**可执行建议**

1. **先谈“阶梯起订量”**
   - 不要只接受一个高起订量，争取按箱/按件分档，或者混拼。
   - 例如：香蕉按成熟度分批次到货，菠萝按大小/成熟度分档。

2. **拆单到货，不要一次压满**
   - 把高起订量拆成每周多次到货。
   - 香蕉尤其适合“少量多次”，避免一批同时催熟。

3. **用销定采**
   - 按过去 7 天日均销量、未来天气、促销计划来算采购量。
   - 不要按“供应商起订量”倒推采购，而应按“能卖完的量”倒推。

4. **设置安全库存上限**
   - 香蕉安全库存尽量控制在 **1-2 天销量**。
   - 菠萝控制在 **2-3 天销量**，高温季节再降。

5. **验收时严控成熟度**
   - 香蕉：青蕉比例、催熟程度、是否有压伤。
   - 菠萝：果眼、底部、是否有软烂、出水、异味。
   - 到货熟度太高，即使量不大也会很快损耗。

6. **分开储存和先进先出**
   - 香蕉不要和苹果、番茄等释放乙烯的果蔬混放。
   - 菠萝要通风、避免堆压。
   - 先到先出，别让新货把旧货压住。

7. **算一笔损耗账**
   - 如果起订量增加 30%，但销量没增加，损耗可能增加得比 30% 更多。
   - 可以对比：高起订量带来的单价优惠，是否足以覆盖多出来的损耗和资金占用。

**结论**

会。起订量太高，对香蕉和菠萝都会增加损耗风险，香蕉通常更敏感，菠萝次之。关键不是“能不能放”，而是**到货熟度、周转天数、储存条件和销售速度是否匹配**。如果能做到少量多次、按销定采、严控成熟度，高起订量的风险可以降下来；如果做不到，建议优先谈低起订量或拆单到货，而不是只看采购单价。
