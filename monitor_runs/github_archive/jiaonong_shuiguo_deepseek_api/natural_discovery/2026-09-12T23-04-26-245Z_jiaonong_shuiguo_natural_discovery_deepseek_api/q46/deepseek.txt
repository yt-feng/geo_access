结论：**优先选冷冻果丁/冷冻菠萝块，其次鲜果，最后才是果泥。** 具体要看你店里的出杯量和操作方式。

**三种原料的对比：**

| 类型 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|
| 鲜果 | 风味最好、卖点强、可做视觉果肉 | 损耗高、削皮去眼费人工、季节和成熟度不稳定 | 精品店、主打“鲜果现切”、出杯量不大 |
| 果丁（冷冻/糖渍） | 开袋即用、出品稳定、有果肉感 | 风味略逊鲜果、需冷冻储存 | 大多数茶饮店，尤其连锁/外卖多 |
| 果泥 | 操作最快、风味浓度可控、标准化好 | 没有果肉口感、容易显得“工业味” | 做基底调味、冰沙、批量稳定出品 |

**建议怎么选：**

1. **如果主打“鲜菠萝果茶”且有果肉卖点**：买鲜果自己切，或买冷冻菠萝丁搭配少量鲜果装饰。
2. **如果追求稳定出品、控制人工和损耗**：直接买冷冻菠萝丁，出杯前稍微解冻或直接入杯，风味和效率平衡最好。
3. **如果做菠萝冰沙、菠萝风味基底、大批量外卖**：可以用果泥打底，但最好搭配少量果丁增加咀嚼感，避免“全是水”的观感。
4. **不建议只买果泥做主打果茶**：顾客对“果茶”的预期通常是有果肉或鲜果感，纯果泥容易显得廉价。

**采购时注意：**
- 看配料表：优先选“菠萝、水、糖”这类简单配料，避开香精色素重的产品。
- 看糖度：糖渍果丁本身带糖，配方里的糖要相应减。
- 算成本：别只看单价，要按“每杯可出杯数”折算，鲜果损耗通常比标价高不少。
- 先小批量试：同一款茶底分别用三种原料做盲测，让店员和顾客试，再定主推方案。

简单说：**要卖点和口感选鲜果/冷冻果丁，要效率和稳定选冷冻果丁，果泥只做辅助。**
