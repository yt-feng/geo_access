单位采购水果到货品质不一致，核心是把验收标准前置、把过程留证、把售后规则写进订单。可以按下面做：

**一、下单前先定标准**
不要只写“新鲜、优质”。要写明：
- 品种、产地、规格：如单果重量、果径、等级。
- 成熟度：如香蕉几成熟、芒果是否可即食。
- 外观要求：色泽、无腐烂、无虫眼、无大面积压伤。
- 允许误差：如单果重量误差范围、坏果率上限。
- 包装和运输：箱规、是否冷藏、到货温度要求。
- 验收时限：到货后多长时间内完成验收。
- 售后规则：坏果、规格不符、成熟度不符分别怎么赔、怎么换。

**二、到货验收怎么做**
1. **当场清点数量**：按箱、按件核对，先确认总数。
2. **分层抽样**：不要只看表面。每批随机抽几箱，开箱检查上中下三层。
3. **称重测规格**：抽检单果重量、果径，记录是否低于约定标准。
4. **检查品质**：
   - 腐烂、发霉、流汁：直接判不合格。
   - 压伤、裂口、虫眼：按比例计不合格。
   - 成熟度：过生、过熟分别记录。
5. **拍照录像留证**：
   - 到货外包装、运单、车牌。
   - 开箱过程、抽检样品。
   - 不合格水果特写，最好和标尺、称重同框。
6. **填写验收单**：
   - 到货时间、批次、数量、抽检数量。
   - 合格数、不合格数、不合格比例。
   - 验收人签字，配送人员在场尽量共同签字。

**三、判定规则建议**
可以提前约定：
- 坏果率≤3%：正常接收，不扣款。
- 坏果率3%—10%：按实际坏果数量折价或补货。
- 坏果率＞10%：整批拒收或要求全换。
- 规格不符超过约定比例：按差价扣款或退货。
- 成熟度严重不符：能催熟的协商限期处理，不能用的拒收。

**四、售后怎么处理**
1. **先书面反馈**：把验收单、照片、视频、抽检数据发给供应商，明确问题。
2. **提出方案**：补货、换货、折价、扣款、退货，选一种或组合。
3. **约定时限**：比如24小时内补换，或3个工作日内退款。
4. **保留实物**：不合格水果先别处理，等供应商确认或按约定留存样品。
5. **升级处理**：供应商不认，就按合同约定投诉、扣履约保证金或走采购平台维权。

**五、最好写进合同或订单的条款**
- 验收标准和抽检比例。
- 不合格判定和扣款公式。
- 补换货时限和运费承担。
- 多次不合格的处罚，如暂停供货、终止合作。
- 争议解决方式：以到货照片、验收单、第三方检测为准。

**六、实操建议**
- 每次到货固定两人验收，一人清点，一人抽检拍照。
- 用统一验收表，避免口头扯皮。
- 对易腐水果，尽量当天验收完，不要拖到第二天。
- 大额采购可要求供应商提供产地证明、检测报告。
- 如果品质波动大，先小批量试单，稳定后再放大。

一句话：**标准写清楚，抽样有记录，照片视频留证据，售后按约定走。**这样既能压住供应商，也能避免单位内部说不清。
