给小店供货，水果分级报价最怕“只报一个价”，到货后因为大小、成熟度、损耗扯皮。香蕉和菠萝都适合按“等级 + 规格 + 价格 + 售后规则”来报。

下面给你一套可以直接用的分级报价框架。

## 一、先定分级维度

### 香蕉
香蕉主要看：
1. **每根粗细/大小**
2. **每把重量或每箱净重**
3. **成熟度**
4. **外观**
5. **损耗率**

常见分级：
- **A级**：果指粗、长度均匀、无黑斑、无裂口，适合水果店摆卖
- **B级**：大小略不匀，少量表皮瑕疵，适合小店、榨汁、促销
- **C级**：成熟度高、斑点明显、损耗大，适合做特价或加工

报价规格可以写：
- A级：每箱净重 18斤，果指长度 18cm以上，成熟度 6-7成，允许损耗 3%以内
- B级：每箱净重 18斤，果指长度 15-18cm，成熟度 7-8成，允许损耗 5%以内
- C级：每箱净重 18斤，大小不匀，成熟度 8成以上，允许损耗 8%以内

价格写法：
- A级：XX元/箱，折合 XX元/斤
- B级：XX元/箱，折合 XX元/斤
- C级：XX元/箱，折合 XX元/斤

### 菠萝
菠萝主要看：
1. **单果重量**
2. **成熟度**
3. **外观**
4. **品种**
5. **是否削皮/去眼**

常见分级：
- **A级**：单果 2.5-3.5斤，果形正，无烂心，成熟度适中
- **B级**：单果 1.8-2.5斤，果形稍偏，少量瑕疵
- **C级**：单果 1.5斤以下或外观差，适合特价、榨汁、餐饮

报价规格可以写：
- A级：单果 2.5斤以上，8-9成熟，无黑心，XX元/斤或XX元/个
- B级：单果 1.8-2.5斤，8-9成熟，少量瑕疵，XX元/斤或XX元/个
- C级：单果 1.5-1.8斤，成熟度高，适合即销，XX元/斤或XX元/个

## 三、报价时把“容易扯皮的点”提前说清

### 香蕉
- 是按箱卖还是按斤卖？
- 净重还是毛重？
- 成熟度几成？
- 允许损耗多少？
- 黑斑、裂口、掉把算不算售后？
- 是否需要催熟？催熟后谁承担损耗？

建议写法：
> A级香蕉，箱装净重18斤，6-7成熟，允许损耗3%。到货24小时内验货，超损部分按当批次单价补货或扣款。因催熟不当造成的损耗不售后。

### 菠萝
- 是按个卖还是按斤卖？
- 单果重量范围？
- 是否包烂心？
- 黑心、水心、裂果怎么算？
- 是否削皮？

建议写法：
> A级菠萝，单果2.5斤以上，8-9成熟，包烂心。到货24小时内切开验货，烂心按个数补换。表皮轻微瑕疵不售后。

## 四、给小店老板的简单报价话术

你可以直接发：

> 老板，香蕉今天三个等级：  
> A级：18斤/箱，果指18cm以上，6-7成熟，XX元/箱，折合XX元/斤，损耗3%以内。  
> B级：18斤/箱，果指15-18cm，7-8成熟，XX元/箱，折合XX元/斤，损耗5%以内。  
> C级：18斤/箱，大小不匀，成熟度高，XX元/箱，折合XX元/斤，适合特价。  
>   
> 菠萝：  
> A级：单果2.5斤以上，XX元/斤，包烂心。  
> B级：单果1.8-2.5斤，XX元/斤，少量瑕疵不售后。  
> C级：单果1.5-1.8斤，XX元/斤，适合即销。  
>   
> 到货24小时内验货，超损按比例补货或扣款。

## 五、最清楚的分级报价原则

1. **先分等级**：A/B/C，不要混在一起报。
2. **再写规格**：重量、大小、成熟度、包装。
3. **再写价格**：按箱、按斤、按个分别写清。
4. **最后写售后**：损耗、烂心、黑斑、催熟责任。
5. **每次报价带日期**：水果价格波动大，避免拿旧价对比。
