判断供应商能不能按时到车，核心不是听他口头承诺，而是看**可验证的硬信息**。可以按下面几层来筛：

**一、先看“当天能不能发车”的硬条件**

1. **货是否已经在地里/仓库**  
   问清楚：是已经砍好装筐，还是“明天再砍”。没砍的香蕉，遇到下雨、工人不够、价格波动，最容易延误。

2. **装车工人和车是否落实**  
   直接问：装车工几个人、几点到、车是什么车牌、司机电话多少。只说“有车”但给不出车牌和司机电话的，风险大。

3. **加工/催熟环节是否卡住**  
   香蕉如果要做催熟、分级、装箱，问他当前加工到哪一步、还剩多少量。加工没完成，车到了也装不走。

**二、用“时间节点”倒推，而不是问“能不能按时”**

不要问“你能按时到吗”，要问：

- 今天几点砍完？
- 几点开始装车？
- 预计几点发车？
- 到我这多少公里、走哪条线？
- 预计几点到市场？

让他给出**具体时间点**。给不出节点、只说“放心”“没问题”的，基本不可靠。

**三、查他过去的履约记录**

- 之前合作过几次，有没有迟到、临时加价、换货、少斤两？
- 同市场其他批发商有没有被他放过鸽子？
- 他最近是不是同时在给很多人供货？单子接太多，车和货都容易排不过来。

**四、用“小单试 + 合同/微信留痕”降低风险**

- 新供应商第一次不要下大单，先跑一车小量试履约。
- 微信里把品种、数量、单价、装车时间、到货时间、迟到怎么赔写清楚。
- 定金不要一次给太多，最好“装车后付大部分”或“到车验收后结清”。
- 要求发装车视频、过磅单、车牌照片、司机电话。

**五、当天要盯的三个信号**

1. **砍蕉进度**：上午还没砍，当天发车基本悬。
2. **装车视频**：能实时发装车视频的，可信度明显高。
3. **司机是否真实**：直接和司机通话，确认位置和出发时间。只给“调度电话”不给司机电话的，要警惕。

**六、最简单的判断口诀**

- 有货、有工、有车牌、有司机电话、有明确时间点 → 大概率能到。
- 只有口头承诺，没车牌、没司机、没装车视频、时间含糊 → 大概率要拖。
