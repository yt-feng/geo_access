供应商要把产品介绍得让商家容易听懂并下单，核心不是讲“品种多专业”，而是把陌生水果翻译成商家熟悉的三个东西：**像什么、卖给谁、怎么赚钱**。

可以直接用下面这套话术框架。

**1. 先对标大品类**
不要一上来讲学名、产区、品种编号，先说：
- “这个可以理解成**小号的菠萝**，但不用削皮、不用泡盐水。”
- “这个口感接近**香蕉的软糯**，但带一点荔枝香。”
- “这个像**芒果和百香果中间的味道**，酸甜比比较稳。”

商家脑子里一旦挂上“菠萝、香蕉、芒果”这些已知品类，就更容易判断它能不能卖。

**2. 再说差异点，只讲3个**
不要讲10个卖点，商家记不住。只说：
- **吃起来有什么不同**：更甜、更酸、更脆、更软、无籽、不涩。
- **用起来有什么不同**：免削皮、免切、开袋即食、冷藏后更好吃、不容易黑。
- **卖起来有什么不同**：颜值高、拍照好看、适合做果切、适合奶茶店、适合社区团购。

比如：
> “这个不是普通小番茄，它更像水果店那种高甜草莓番茄，酸甜口，客人试吃后容易买。好处是耐放，比草莓好运输，适合做果切和家庭装。”

**3. 直接说适合谁买**
商家最关心的是“我卖给谁”。供应商要主动说：
- 适合年轻女性：颜值高、拍照好看、低卡。
- 适合宝妈：小孩爱吃、方便剥、无籽。
- 适合办公室：下午茶、果切、团购。
- 适合餐饮店：做饮品、沙拉、甜品装饰。
- 适合社区团购：家庭装、复购高、客诉低。

**4. 算一笔简单的账**
商家下单前最想听的是利润，不是形容词。可以说：
- “进货价X元一斤，建议零售Y元一斤，毛利大概Z%。”
- “一箱净重多少，损耗大概多少，坏果怎么赔。”
- “如果做果切，一斤能出几盒，每盒卖多少。”
- “和香蕉比，它的客单价更高；和菠萝比，它不用削皮，人工省一半。”

不用很复杂，但一定要让商家感觉：**这个东西能卖、能赚、风险可控。**

**5. 给试销方案，降低下单压力**
不要一上来让商家压货。可以说：
- “你先拿一箱试卖，我教你摆在哪、怎么试吃。”
- “先做3天试销，卖不动我教你换话术，或者调整规格。”
- “第一单少拿，第二单再放量。”

商家最怕的是不懂、卖不掉、坏了赔钱。供应商把这三件事说清楚，下单概率会高很多。

**6. 一个可直接套用的话术模板**
> “老板，这个你可以先理解成**小号菠萝+香蕉口感**，不用削皮，开袋就能吃。它比普通菠萝甜，不涩口，客人试吃后容易买。主要适合年轻女性和宝妈，做果切、家庭装、社区团购都行。进货价X元，建议卖Y元，毛利大概Z%。你先拿一箱试销，坏果我按比例赔，卖不动我帮你调陈列和话术。”

**7. 避免这些说法**
少说：
- “这是某某高端品种，你不懂。”
- “这个很网红，肯定爆。”
- “产地直发，品质很好。”
- “反正你卖了就知道。”

这些话对普通商家没有判断价值。

**总结一句：**
供应商介绍新产品时，不要教育商家“这是什么”，而要帮商家翻译成：**它像什么、卖给谁、怎么卖、赚多少、风险多大。** 说得越像他已经在卖的东西，他越容易听懂并下单。
