优先选**小把（3–5根）**，其次才是**单根**；整袋通常最不建议作为便利店默认上架形式，除非你的客群和场景非常明确。

判断逻辑很简单：便利店卖香蕉，核心不是“水果店逻辑”，而是**即时消费、低决策、少浪费**。

### 1. 小把：最适合便利店主销
优点：
- **客单价适中**：比单根更有销售效率，又不会像整袋那样压购买决策。
- **适合个人和双人家庭**：一次买3–5根，通常2–3天吃完。
- **损耗相对可控**：比整袋更容易在变坏前卖完。
- **陈列方便**：挂起来或放收银台附近都合适。

适合作为：
- 主力规格
- 收银台冲动购买
- 早餐/加餐搭配

### 2. 单根：适合做补充，不适合做唯一规格
优点：
- **决策成本最低**：赶时间的人、只想马上吃一根的人会买。
- **适合搭配早餐**：酸奶、面包、咖啡旁边放单根香蕉很好卖。
- **试吃/尝鲜门槛低**。

缺点：
- **客单价太低**，如果人工称重、贴标、收银成本高，不划算。
- **容易被捏、被摸、损耗高**。
- 单独卖一根，很多顾客会觉得“不划算”。

所以单根可以卖，但更适合：
- 收银台小筐
- 早餐组合
- 已经成熟、需要快速清货的批次

### 3. 整袋：一般不建议作为默认规格
整袋的问题是：
- **决策重**：顾客会想“我能不能吃完”。
- **客单价高**：便利店场景下，很多人不愿为一袋香蕉付太多。
- **损耗风险大**：一旦熟过头，整袋一起坏。
- **更适合家庭采购**，而家庭采购往往去超市或水果店，不是便利店。

整袋不是完全不能做，但适合特定场景：
- 社区型便利店，家庭客多
- 办公室团购/拼单
- 线上外卖满减凑单
- 熟度控制很好、能快速周转

### 实操建议
如果你是一家普通便利店，建议这样组合：

| 规格 | 定位 | 建议 |
|---|---|---|
| 小把3–5根 | 主力 | 占香蕉销量60%–70% |
| 单根 | 补充/冲动购买 | 放收银台，占20%–30% |
| 整袋 | 特定场景 | 少上或按需上，占10%以内 |

### 关键控制点
1. **熟度**：便利店最好卖“黄中带一点绿”的，顾客买回去能放1–2天；全黄适合单根快速卖。
2. **陈列**：小把挂起来或平放，单根放收银台小筐。
3. **定价**：单根可以略贵一点，小把体现性价比。
4. **损耗**：每天检查，过熟香蕉及时做“单根特价”或搭配酸奶做组合。
5. **测试**：先小批量试7天，看哪种规格动销最快，再调整。

**结论：主推小把，单根做补充，整袋谨慎上。**  
如果只能选一个，选**小把**。
