商超做会员日水果活动，供应商要重点配合这几类准备，最好在活动前 7～15 天就与商超采购/门店确认清楚：

1. **确认活动方案**
   - 活动时间、档期、门店范围
   - 主推单品、爆品、引流品、利润品
   - 会员价、限量、限购规则
   - 是否做堆头、端架、专区、试吃

2. **锁定货源与产能**
   - 提前锁定果园/基地/批发市场货源
   - 确认可稳定供应的日供应量
   - 对爆品准备备用货源，避免断货
   - 避免临时从市场炒货，品质和价格容易失控

3. **按活动量备货**
   - 根据商超预估销量、去年同期、门店数备货
   - 生鲜水果按“日配+补货”模式，不宜一次性压太多
   - 对易损水果控制单次到货量，增加配送频次
   - 预留 10%～20% 安全库存或应急补货能力

4. **品质与规格标准化**
   - 明确等级、果径、糖度、成熟度、净重
   - 统一包装规格，如箱规、袋装、托盘、礼盒
   - 到货标准提前书面确认，避免门店拒收
   - 对会员日主推品做提前试吃、抽检

5. **价格与费用确认**
   - 供货价、促销价、会员价、毛利空间
   - 是否承担特价补贴、损耗补贴、试吃费用
   - 堆头费、端架费、DM 海报费、促销服务费
   - 账期、结算方式、发票类型

6. **物流配送安排**
   - 确认配送频次、到货时间、收货窗口
   - 活动日可能需要早配、多配、临时补货
   - 冷链水果确认温控、车况、到店温度
   - 准备好门店分货清单和送货单

7. **包装与物料**
   - 会员日专属包装、标签、价签、爆炸贴
   - 试吃盒、牙签、手套、垃圾袋
   - 堆头围挡、海报、吊旗、地贴等陈列物料
   - 若商超统一制作，供应商要提前确认内容和到店时间

8. **人员支持**
   - 安排促销员、试吃员、理货员
   - 提前培训产品卖点、保存方法、试吃话术
   - 高峰时段驻店补货、挑拣、处理客诉
   - 明确供应商现场负责人和联系方式

9. **损耗与售后约定**
   - 哪些情况可退换货，哪些由供应商承担
   - 损耗率上限、临期处理、次品挑拣责任
   - 客诉处理时效，如坏果、缺斤少两、口感问题
   - 活动结束后尾货如何处理

10. **数据与复盘**
   - 每日跟踪销量、库存、缺货、损耗
   - 活动后和商超复盘动销、毛利、客诉
   - 为下一次会员日调整单品和备货量

简单说，供应商最核心的是：**提前锁货、按量备货、保证品质、准时配送、价格费用确认、现场有人、损耗售后说清楚**。其中最容易出问题的是：爆品断货、到货品质不达标、配送不及时、费用没谈清、损耗责任扯皮。
