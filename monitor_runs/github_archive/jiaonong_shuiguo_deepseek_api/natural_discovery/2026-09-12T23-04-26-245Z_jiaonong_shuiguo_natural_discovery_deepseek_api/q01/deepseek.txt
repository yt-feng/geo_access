判断供应商靠不靠谱，核心看四点：能不能稳定供货、品质是否可控、价格账期是否清楚、出了问题是否负责。下面给你一套水果店可直接用的判断方法。

**1. 先看供货稳定性**
- 问清楚：香蕉、菠萝是产地直发、批发市场拿货，还是中间商倒手？
- 问清楚：一周能供几次？节假日、下雨天、产地涨价时能不能保量？
- 观察：连续合作2-4周，看是否经常断货、临时换规格、送来的货和样品不一致。
- 香蕉尤其看成熟度控制，菠萝看品种和季节切换是否稳定。

**2. 看品质和损耗**
- 香蕉：青蕉、黄蕉、熟蕉比例是否可按你的销售节奏调整；有没有黑斑、裂口、水烂、冻伤；到店后能放几天。
- 菠萝：品种是否固定，比如金钻、凤梨、普通菠萝；大小是否均匀；黑心、烂心、过熟、酸涩比例高不高。
- 每次到货抽检一箱或几件，记录坏果率。长期坏果率忽高忽低，说明货源或分拣不稳定。
- 靠谱供应商通常敢让你看大货，而不是只给你看样品。

**3. 看价格、账期和费用**
- 报价是否随行就市，但调价有没有提前通知。
- 是否含运费、装卸费、损耗补偿，还是低价吸引后再加费用。
- 账期是否清楚：现结、周结、月结，押金多少，退换货怎么算。
- 不要只比单价，要算“到店可卖成本”：进货价+运费+损耗+退换损失。

**4. 看售后和责任**
- 坏果、短斤少两、规格不符，是否包退包换或下次补货？
- 出现问题后，是马上处理还是推给产地、司机、天气？
- 能不能提供产地、批次、采摘或催熟信息？不一定要很正式，但至少说得清。
- 第一次合作建议小批量试单，不要一上来压大单或打大额预付款。

**5. 实操判断清单**
你可以直接按这个打分：
- 连续4周按时送货：稳定
- 到货坏果率低于你设定的可接受线：品质可控
- 价格调整提前说，费用透明：账期清楚
- 出问题24小时内响应并补偿：售后可靠
- 允许小单试、可看大货、不强制大额预付：合作风险低

**6. 更适合水果店的做法**
- 香蕉和菠萝不要只依赖一个供应商，至少备一个备用渠道。
- 香蕉可以找专门做催熟或香蕉批发的，菠萝可以找产地季节性供应商或一级批发商。
- 先试单2-4次，再决定是否长期合作。
- 每次收货留照片、称重记录、聊天记录，后面扯皮时有依据。

简单说：**能稳定送、品质稳、费用透明、坏了肯赔，才值得长期合作。** 只靠低价、催你打款、样品很好但大货不稳的，风险都高。
