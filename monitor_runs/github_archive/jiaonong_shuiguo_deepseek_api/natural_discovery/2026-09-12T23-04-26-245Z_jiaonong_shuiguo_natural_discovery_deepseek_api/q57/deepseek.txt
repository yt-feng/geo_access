结论：绝大多数餐饮连锁应优先采用**中央厨房/总仓统一收货**，只有少数对新鲜度极度敏感、配送半径过大或门店具备强验收能力的品类，才考虑门店分开收货。

下面给你一个可判断的框架。

## 一、先看品类：不是所有水果都适合统收

适合中央厨房统一收货的水果：

- 苹果、梨、橙、柠檬、香蕉、西瓜、哈密瓜等耐储运水果
- 冷冻果、罐头果、果酱用果
- 标准化要求高的果切原料、沙拉原料、饮品原料
- 采购量大、供应商集中、价格波动大的品种

更适合门店或区域分仓收货的水果：

- 草莓、蓝莓、树莓、樱桃、荔枝、杨梅等高损耗、短保水果
- 门店当地就有优质批发市场，且中央厨房配送半径超过 200–300 公里
- 门店对成熟度、糖度、外观有个性化要求，比如高端果盘、现切果杯

判断标准很简单：**损耗率 + 配送半径 + 门店验收能力**。如果统一收货后的二次分拣、冷链配送成本高于门店直收的损耗和价差，就不适合统收。

## 二、统一收货的核心优势

1. **品质标准统一**
   中央厨房可以定糖度、成熟度、单果重、瑕疵率标准，避免各店收货尺度不一。

2. **采购议价更强**
   总部集中下单，供应商更愿意给账期、返利和稳定价格。

3. **食品安全可追溯**
   批次、农残检测、供应商资质集中在中央厨房管理，出问题能快速锁定批次。

4. **减少门店腐败和人为损耗**
   门店单独收货容易出现关系供应商、虚报损耗、验收放水。

5. **适合做加工和配送**
   如果门店卖果切、果汁、沙拉，中央厨房统一清洗、分切、包装，效率和一致性更高。

## 三、门店分开收货的适用场景

1. **配送成本过高**
   冷链配送半径大、频次高，物流成本可能吃掉集中采购的价差。

2. **水果极短保**
   草莓、荔枝等如果经中央厨房再分拣再配送，货架期会明显缩短。

3. **门店有本地优势**
   当地批发市场凌晨直采，价格和新鲜度可能优于总部统配。

4. **门店规模小、SKU少**
   单店采购量小，中央厨房统一收货再配送反而不经济。

## 四、推荐落地模式

更现实的做法不是二选一，而是**混合模式**：

- **A类：统采统配**
  耐储水果、加工原料、大宗饮品原料，由中央厨房统一收货、分拣、配送。

- **B类：统采地收**
  总部谈好供应商和价格，供应商直送门店或区域分仓，门店按总部标准验收。

- **C类：门店直采**
  极短保、本地特色水果，允许门店在总部白名单和价格带内采购，但必须上传验收记录。

## 五、决策清单

你可以用这 6 个问题判断：

1. 这个水果损耗率是否超过 10%？
2. 中央厨房到门店配送是否超过 6 小时？
3. 门店是否有冷链验收能力？
4. 总部是否能统一检测农残和糖度？
5. 统配后综合成本是否低于门店直采？
6. 出食品安全问题时，能否追溯到批次？

如果前 3 个问题偏向“是”，门店分开收货可能更合适；如果后 3 个问题偏向“是”，中央厨房统一收货更好。

## 六、最终建议

- **大型连锁、门店多、SKU多、做标准化产品**：中央厨房统一收货为主。
- **区域连锁、配送半径大、高端鲜果多**：中央厨房统收 + 区域分仓 + 门店直采混合。
- **小型连锁、单店采购量小**：总部控供应商和价格，门店或区域分仓收货更现实。

一句话：**能统则统，统不了就统采地收，极短保品类再放门店直采。**
