会有影响，但影响大小取决于你的销售方式。关键不是“大小不一样”本身，而是你**怎么分级、怎么定价、怎么陈列**。

**1. 如果整箱统货卖**
大小混杂会让顾客挑拣，把大的翻走、小的剩底，损耗和差评都会增加。适合做特价堆头，但要有心理准备：卖相一般，复购靠低价。

**2. 如果分拣后卖**
这是更推荐的做法：
- 大果、匀称果：走精品袋装或礼盒，价格高一点。
- 中果：正常散卖，按斤称。
- 小果、外观差的：做特价、切果盒、榨汁，或促销搭售。

**3. 如果做线上/社区团购**
大小不一会直接引发售后。建议按规格写清楚，比如“单根约120-150g”“大小混装，介意慎拍”，或者直接分“大果/中果”两个链接。

**4. 实际经营建议**
- 采购时先问清楚：是统货还是分级货，大小比例大概多少。
- 到店后必须过一遍手，把明显偏小、有伤的挑出来。
- 陈列时把大小接近的放一起，视觉上更整齐，顾客不会翻得太厉害。
- 定价时不要按同一单价卖所有规格，否则大果被挑走，小果砸手里。

**结论：**
大小不一不会让你卖不掉，但会拉低利润和效率。**统货可以进，但一定要分拣、分价、分渠道卖。** 如果你只是小店、走量为主，可以接受；如果你做精品水果或线上复购，最好采购分级货，或者自己分拣后再上架。
