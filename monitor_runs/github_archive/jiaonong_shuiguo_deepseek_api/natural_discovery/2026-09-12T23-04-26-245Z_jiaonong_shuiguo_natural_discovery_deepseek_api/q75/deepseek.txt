第一次合作，试单的核心目标不是“拿到最低价”，而是**用最小成本验证对方的真实履约能力**。建议按下面几个维度来设计：

## 一、先定试单目的

试单要回答四个问题：
1. 货对不对版（品种、规格、成熟度、口感）
2. 损耗率有多高（从发货到你手上烂了多少）
3. 履约靠不靠谱（能不能按时、按量发）
4. 结算和售后顺不顺（出问题认不认账）

这四个问题比价格重要得多。

## 二、试单规模怎么定

- **数量**：够装满一次真实销售场景即可，一般建议**1个整托盘或200-500公斤**（视品类），不要为了"试试"而拆得太碎，否则物流成本和损耗比例会失真。
- **单品优先**：第一次**只试1-2个主推品类**，不要一次铺开多个品种。品种越多，越难判断是哪一环出问题。
- **金额控制**：总金额建议控制在你能承受"全部亏掉也不影响现金流"的范围内。

## 三、试单合同/约定里必须写清的

即使是试单，也要书面（哪怕是微信文字确认）约定：

- 规格标准：单个重量区间、大小等级、成熟度、允许的次果比例
- 包装方式：箱规、每箱净重、内衬、是否打托盘
- 发货时间、运输方式、运费谁承担
- 损耗责任：到货后多少小时内可提异议、腐烂率超过多少谁赔
- 结算方式：**首单建议货到验收后付，或预付不超过30%**
- 是否含票、开票类型

## 四、到货验收怎么做

- **当场抽查**：随机开几箱，记录单果重、规格、坏果数，拍照留证
- **称重核对**：整批过秤，核对净重是否与约定一致（这是新手最容易吃亏的点）
- **记录损耗率**：分"运输损耗"和"存放后损耗"分别记，存放2-3天再复看一次
- **留样**：留几箱做对比，方便后续换供应商时参照

## 五、试单要观察的"软指标"

比货更值得注意的是人：
- 沟通是否及时、是否主动同步发货进度
- 你提出问题时，对方是解释还是推责
- 报价前后是否一致，有没有临时加价、换车、改时间
- 是否愿意配合你拍视频/照片确认货源

这些决定了能不能长期合作。

## 六、试单结论怎么下

试单后按三点判断：
1. **货品达标率**：是否达到你承诺给下游的标准
2. **综合成本**：算上损耗、运费、时间成本后，是否还有利润空间
3. **可持续性**：对方产能能不能稳定供货，还是只是"这一单刚好有货"

三项都不错 → 小步加量（翻倍试第二批）；有一项明显不行 → 换供应商或调整条款再试。

## 一个常见误区

很多批发商第一次喜欢压到极低的数量，比如"先发5箱看看"。但小到一定程度，对方不会认真对待，物流摊薄成本也高，试出来的结论反而是失真的。**试单要小，但不要小到物流和成本结构变形。**
