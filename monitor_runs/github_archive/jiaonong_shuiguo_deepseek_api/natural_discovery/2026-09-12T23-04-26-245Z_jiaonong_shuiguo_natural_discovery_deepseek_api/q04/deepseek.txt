要减少香蕉放坏，采购时重点抓两件事：**熟度**和**到货时间**。建议这样要求：

1. **熟度要求**
   - 如果打算 **2～4天内卖完**：采购 **3～4成熟**，也就是偏绿、硬、无黑点、无黄斑。
   - 如果打算 **1～2天内主推**：可以拿 **4～5成熟**，微黄带绿，刚好开始转色。
   - 如果当天就要促销或做果切：才可以拿 **5～6成熟**，但量要少，必须快进快出。
   - 不要长期采购 **6熟以上**，也就是大面积黄、带糖斑、果柄发黑的货，损耗会明显变高。

2. **到货时间要求**
   - 最好要求 **清晨到货**，上午上架，白天观察转色，晚上就能分级处理。
   - 避免 **下午晚到或闭店前到货**，因为堆一夜温度高、呼吸热大，第二天容易集中变黄甚至发黑。
   - 要求供应商 **按批次分成熟度到货**，不要一车全是同一熟度。比如：70%青硬货、20%微黄货、10%即卖货，方便你分批上架。

3. **采购时最好写进订单的要求**
   - “到货以青绿硬果为主，黄熟果不超过10%。”
   - “到货时间不晚于上午9点。”
   - “果柄完整、无发黑、无渗液、无大面积擦伤。”
   - “同一批内熟度尽量一致，不要青黄混杂太严重。”
   - “如到货熟度偏高，需提前告知并允许拒收或调价。”

4. **店里配合做法**
   - 到货后先拆箱散热，不要闷在纸箱里。
   - 按熟度分三档：青硬、微黄、即熟。
   - 青硬放阴凉通风处；微黄放展示位；即熟降价或做果切。
   - 香蕉不要和苹果、梨等释放乙烯多的水果混放，会催熟更快。

简单记：**采购要偏青、清晨到、分熟度、少量多次。**  
最稳的是：**主采3～4成熟，上午到货，黄熟货控制在10%以内。**
