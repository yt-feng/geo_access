三个都要关注，但优先级取决于你卖的是**预包装菠萝切块**还是**门店现切菠萝**。

**1. 如果是门店现切/散装切块**
最该先抓的是**保质期控制**，本质是“多久卖不掉就必须下架”。
- 菠萝切块属于高水分、易发酵变质的水果，常温下很快变味，冷藏也只能短时间保存。
- 建议明确标注切制时间，设定下架时限，比如冷藏条件下当天未售完即废弃，不要靠“看起来没坏”判断。
- 包装在这里主要是防污染、防串味、防水分流失，不是延长保质期的核心手段。
- 配送频次影响的是原料菠萝的新鲜度，但切块后的风险主要发生在门店环节。

**2. 如果是中央厨房/供应商配送的预包装菠萝切块**
优先看**保质期和冷链条件**，再看**包装**，最后才是**配送频次**。
- 保质期是合规和食安底线，必须按标签执行，临期要提前处理。
- 包装要密封、冷藏温控达标，否则标称保质期没有意义。
- 配送频次要匹配销量，避免一次到货太多导致临期积压，也避免断货。

**3. 实操排序建议**
- 第一：**保质期/下架时限**，这是食安红线。
- 第二：**冷链和包装密封**，决定切块能放多久、会不会污染。
- 第三：**配送频次**，决定原料新鲜度和库存周转，但它是管理效率问题，不是第一食安风险点。

**一句话结论：**
现切菠萝，先管“切后多久下架”；预包装菠萝，先管“保质期和冷链”。包装和配送频次都重要，但排在这两项之后。
