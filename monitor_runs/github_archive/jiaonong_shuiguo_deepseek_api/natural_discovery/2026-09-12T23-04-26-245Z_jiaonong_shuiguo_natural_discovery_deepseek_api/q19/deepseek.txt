超市卖菠萝，**不能只盯一个指标，而要先按“经营目标”排序**。如果只能选一个最该关注的，通常是：**切果损耗**。但它不是孤立指标，必须和甜度、大小、外观一起看。

可以这样判断：

1. **切果损耗：最影响利润**
   - 菠萝是典型“毛重进货、净果销售”的商品。
   - 如果损耗高，哪怕外观好、甜度高，也可能不赚钱。
   - 重点看：去皮去眼后的净出肉率、坏心率、黑心率、熟过头率、切后报废率。
   - 对超市来说，做鲜切果切、盒装菠萝时，损耗优先级最高。

2. **甜度：最影响复购**
   - 甜度不稳定，顾客买一次不甜，下次就不买了。
   - 但甜度不能只靠外观判断，最好结合品种、产地、季节、到货批次试吃。
   - 如果超市主打“即食菠萝”“手撕菠萝”“凤梨”，甜度权重会明显上升。

3. **大小：影响定价和场景**
   - 大果适合家庭整颗购买，也适合做果切，但单价高、动销可能慢。
   - 小果适合单人、小家庭、即食场景，周转快。
   - 大小还直接影响陈列、包装、称重和损耗。
   - 所以大小不是越大越好，而是要和客群匹配。

4. **外观：影响第一眼购买**
   - 外观决定顾客会不会拿起来。
   - 看果形端正、果眼深浅、果皮颜色、无腐烂、无碰伤、无软塌。
   - 但外观好不代表甜，也不代表出肉率高，只能作为筛选门槛。

**如果按超市经营优先级排：**

- **做鲜切、追求毛利：切果损耗 ＞ 甜度 ＞ 大小 ＞ 外观**
- **整颗售卖、追求动销：外观 ＞ 大小 ＞ 甜度 ＞ 切果损耗**
- **做社区复购、主打好吃：甜度 ＞ 切果损耗 ＞ 大小 ＞ 外观**
- **做低价促销：大小/外观 ＞ 切果损耗 ＞ 甜度**

**最实用的做法：**
把菠萝分成几个用途：
- 外观好、大小适中的：整颗卖。
- 甜度高、出肉率高的：做果切。
- 外观一般但甜度好的：打折或做试吃转化。
- 损耗高的批次：尽快处理，不要硬撑原价。

所以一句话：**超市卖菠萝，先看切果损耗保利润，再看甜度保复购，大小和外观决定怎么卖、卖给谁。**
