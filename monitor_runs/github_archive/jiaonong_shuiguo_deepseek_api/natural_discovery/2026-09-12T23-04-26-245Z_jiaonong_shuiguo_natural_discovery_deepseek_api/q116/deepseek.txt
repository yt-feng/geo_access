对小商家采购水果，现金结算和月结账期各有风险，核心区别是：现金风险集中在“钱货安全与现金流”，月结风险集中在“账期失控与坏账”。

**一、现金结算的风险**
1. **资金占用与周转压力**  
   现金当场付出，手里流动资金减少。水果损耗高、周转快，一旦当天卖得慢，就容易出现“货没卖完，钱已付完”。

2. **假币、短款、差错风险**  
   现金交易容易出现收假币、点错钱、找零错误、被偷被抢。尤其早市、批发市场人多杂乱时更明显。

3. **交易凭证弱，维权难**  
   现金结算往往只有手写收据或口头约定。出现缺斤少两、品质不符、短装、以次充好时，举证和追责都比较难。

4. **价格谈判空间可能更小**  
   有些供应商对现金客户给低价，但也有些会把现金客户当“急单客户”，临时涨价或优先给月结大客户好货。

5. **安全与税务合规风险**  
   大额现金携带不安全；如果账务不规范，也可能带来税务和内部管理问题。

**二、月结账期的风险**
1. **坏账和拖欠风险**  
   这是最大风险。货已经卖出或损耗了，钱却没回来。供应商跑路、翻脸、拖延、以质量问题拒付，都会让小商家很被动。

2. **现金流错觉**  
   账面上有利润，但钱在供应商那里。若同时欠着房租、人工、水电，容易资金链断裂。

3. **对账争议**  
   水果价格波动大、品质差异大，月结时容易出现“这批不新鲜”“那批价格不对”“扣损耗”等争议，导致结算拖延。

4. **被动依赖，议价能力下降**  
   一旦习惯月结，换供应商成本变高。对方可能涨价、压货、搭售滞销品，你也不容易马上切断。

5. **信用与合同风险**  
   如果没有合同、送货单、对账单、聊天记录，月结很容易变成“糊涂账”。口头月结最危险。

6. **内部管理风险**  
   采购、验收、付款如果没有分开或留痕，容易出现员工虚报、吃回扣、重复付款等问题。

**三、实操建议**
- **现金结算**：尽量转账留痕；现场验货、称重、拍照；小额现金，避免大额携带；索要收据并写清品名、数量、单价、日期。
- **月结账期**：必须签简单合同或确认单，写明账期、对账日、付款日、质量标准、扣款规则；每批送货单签字；每周或每半月对账，不要拖到月底。
- **混合策略**：新供应商先现金或短账期，合作稳定后再给7天、15天账期；不要一上来就给30天以上。
- **设红线**：月结额度不超过自己能承受的坏账范围；现金付款不超过每日安全库存资金。
- **保留证据**：送货单、过磅单、照片、聊天记录、转账记录、对账单都要留。

一句话：现金结算怕“钱货两空和周转断”，月结怕“货走了钱回不来”。小商家最好用“短账期+强对账+留凭证”的方式，而不是纯现金或长月结。
