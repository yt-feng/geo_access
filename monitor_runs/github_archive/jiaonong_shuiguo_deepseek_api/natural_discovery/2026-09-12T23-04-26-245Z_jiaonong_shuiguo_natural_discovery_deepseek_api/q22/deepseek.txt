可以按“高频刚需 + 低频尝鲜 + 家庭囤货”来组合，核心不是简单打折，而是让顾客从“买一根香蕉”变成“买一袋水果”。

**推荐组合：香蕉 + 菠萝 + 苹果做“3件套阶梯价”**

1. **基础引流款：香蕉**
   - 香蕉是高频、价格敏感、购买决策快。
   - 不要直接降价太多，可以做“香蕉 + 任意水果满减”。
   - 例：买香蕉满10元，加5元换购菠萝半个/苹果2个。

2. **利润/客单提升款：菠萝**
   - 菠萝单价高、体积大、视觉冲击强，适合做现场切果。
   - 用“半个菠萝 + 苹果3个 + 香蕉1把”做组合价。
   - 例：单买合计28元，组合价23.9元，顾客感觉省4元，超市客单从十几元拉到二十几元。

3. **家庭囤货款：苹果**
   - 苹果耐放、家庭购买频次高，适合做“满30元送/换购”。
   - 例：苹果满20元，加3元换购香蕉一把；或苹果+菠萝组合立减5元。

**具体促销方案**

- **方案A：水果三件套**
  - 香蕉1把 + 菠萝1个 + 苹果4个
  - 原价约35元，组合价29.9元
  - 放在入口堆头，标“今晚果盘/一周水果一次买齐”

- **方案B：加价换购**
  - 买苹果满20元，+5元换购菠萝半个
  - 买菠萝1个，+3元换购香蕉一把
  - 作用：不直接降主品价格，提升连带率

- **方案C：切果杯/果切引流**
  - 用香蕉、菠萝、苹果做混合果切杯，9.9元/杯
  - 买2杯送1根香蕉
  - 作用：消化品相稍差的水果，提高毛利和客单

**陈列建议**

- 三个品放一起，做“组合促销岛”。
- 香蕉放最前，菠萝做视觉中心，苹果放旁边做家庭装。
- 价签不要只写“特价”，要写：
  - “单买35元，组合29.9元”
  - “加5元多半个菠萝”
  - “一家三口一周水果”

**关键控制点**

- 香蕉别做深度打折，容易拉低整体价格感。
- 菠萝要解决“不会削、嫌麻烦”，最好提供免费削皮或半只装。
- 苹果按大小分档，组合用中果，避免用最好的果做低价。
- 组合价要让顾客一眼算出便宜，但整体客单必须高于原平均购买额。

**最推荐落地版：**
“苹果满20元 + 5元换购半个菠萝 + 3元换购香蕉一把”，同时在旁边放29.9元三件套。这样既能引流，又能把客单从10-15元拉到25-30元。
