水果店采购菠萝，核心是**按“预计卖完的时间”倒推采购熟度**：不是越熟越好，也不是越生越好。菠萝和香蕉类似，采后还会继续后熟，但速度受温度影响很大。

给你一套可执行的判断标准：

1. **先定销售节奏**
   - 如果 **1～2 天能卖完**：可以采/收 **7～8 成熟**，到店后基本能直接切、直接卖。
   - 如果 **3～4 天卖完**：采 **6～7 成熟**，到店后还会继续转熟。
   - 如果 **5 天以上才卖完**：采 **5～6 成熟**，但必须控制温度，否则容易黑心、水烂。
   - 夏天高温、店里没冷库：整体再降半档到一档，宁生勿过熟。
   - 冬天或低温环境：可以略高半档。

2. **看外观判断熟度**
   - **果皮颜色**：从基部向顶部由青转黄。  
     - 5～6 成熟：整体偏青，只有果底微黄。  
     - 7 成熟：果底到中部转黄，顶部还带青。  
     - 8～9 成熟：大面积金黄，香气明显。  
     - 全黄、果眼发褐、基部发软：已经过熟，损耗大。
   - **果眼**：果眼扁平、间隙变大，通常更熟；果眼尖突、排列紧，偏生。
   - **果形**：果身饱满、基部圆润的通常成熟度更好；果身细长、基部尖的偏生。
   - **叶片/冠芽**：冠芽青绿有生气说明较新鲜；冠芽干枯、基部松脱，说明存放久或过熟。

3. **手感判断**
   - 同样大小，**越重说明水分越足**，但过熟会失重发软。
   - 轻按果底：  
     - 硬：偏生，可放。  
     - 稍有弹性：适合 1～2 天卖。  
     - 明显软陷、渗汁：过熟，损耗高风险。
   - 闻果底：有淡淡菠萝香说明开始熟；香气浓烈、带酒味说明过熟。

4. **采购时的实操建议**
   - 同一批货不要全采一个熟度，做**梯次熟度**：  
     - 30% 偏熟，当天、次日卖；  
     - 50% 中等，2～3 天卖；  
     - 20% 偏生，3～5 天卖。
   - 优先看**果底**，因为菠萝通常从底部先熟。
   - 要求供应商按“到店时间”而不是“采摘时间”报熟度。
   - 到店后立即分级：熟的分开放、优先切果盒或促销；生的放阴凉通风处，不要堆太厚。
   - 夏天尽量用冷库或空调房，温度控制在 **8～12℃** 左右更稳妥；低于 7℃ 容易冷害，高于 20℃ 后熟很快。

5. **简单采购口诀**
   - 当天卖：果底黄、有香气、轻按微弹。
   - 两三天卖：果底微黄、中部青、按着硬中带弹。
   - 四五天卖：整体青、果底刚转色、按着硬。
   - 全青、无香、果眼尖：太生，卖相差，后熟慢。
   - 全黄、酒味、果底软：太熟，损耗高。
