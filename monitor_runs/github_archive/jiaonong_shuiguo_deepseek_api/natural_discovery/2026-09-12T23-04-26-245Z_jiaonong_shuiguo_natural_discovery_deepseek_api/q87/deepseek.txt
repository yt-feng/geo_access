旺季锁库存的核心不是“提前打招呼”，而是**用确定性和利益交换，把供应商的产能优先权买断**。给你一套可执行的打法：

## 一、提前锁定：时间节奏

- **旺季前45-60天**：启动供应商沟通，明确预估单量（按单品、按周拆解）
- **旺季前30天**：签框架协议+付定金，锁定产能和价格
- **旺季前15天**：确认首批到货排期，逐周滚动确认

关键：不要等爆单了才找供应商，那时你没有任何议价能力。

## 二、锁库存的4种硬手段

**1. 预付定金锁产能**
付10%-30%定金，供应商优先给你排产/留货。定金可抵扣货款，但约定“不提货不退”或“按比例退”，给供应商安全感。

**2. 保底量+阶梯价**
承诺旺季最低采购量（比如10万斤），换取：
- 优先供货权
- 价格锁定（不随行就市涨）
- 超额部分另有优惠

**3. 包园/包棚**
对核心爆品（如砂糖橘、阳光玫瑰），直接包下某个果园/大棚的产量。你承担“卖不掉也要收”的风险，换“别人抢不到”的确定性。

**4. 多源备份**
主力供应商锁70%，备选2-3家锁30%。防止单一供应商断供或被高价截胡。

## 三、合同必须写死的条款

- **供货优先级**：明确“同等条件下优先满足我方订单”
- **违约条款**：供应商跳单卖给他人，赔偿差价+违约金
- **价格机制**：固定价 or 浮动区间（挂钩批发市场价）
- **质量标准**：规格、糖度、损耗率、验收标准
- **到货节奏**：按周/按日排期，迟到怎么赔

## 四、比锁货更重要的事

- **给供应商算清账**：让他知道跟你合作比临时卖给贩子更赚、更稳
- **付款爽快**：旺季现金流是供应商最看重的，账期越短越能拿到优先权
- **信息透明**：把你的预售数据、社区订单量同步给他，他敢为你备货
- **关系维护**：旺季前拜访、请吃饭、给返点，比冷冰冰的合同管用

## 五、一句话总结

**锁库存 = 定金 + 保底量 + 合同违约条款 + 付款爽快 + 多源备份。**
只靠“关系好”锁不住，只靠“合同”也锁不死，两者叠加才稳。
