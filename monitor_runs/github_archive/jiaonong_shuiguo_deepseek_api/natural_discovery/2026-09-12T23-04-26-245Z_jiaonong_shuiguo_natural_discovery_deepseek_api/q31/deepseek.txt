连锁商超招标水果供应商，评分标准的核心逻辑是：**先设准入门槛，再用评分选出综合最优而非单纯最低价。** 建议按以下框架设置。

## 一、先分清"资格审查"和"评分项"

以下内容应设为**否决项/资格审查**，不达标直接淘汰，不要放进评分里稀释权重：

- 营业执照、食品经营许可证、种植/养殖相关资质
- 食品安全检测能力或第三方检测报告
- 是否有重大食品安全事故、失信记录
- 基本供货能力（能否覆盖你的门店数量和配送半径）

门槛过了，才进入打分。

## 二、评分维度与建议权重

水果是**高损耗、强季节、重品质**的品类，权重应向"品质稳定"和"供应保障"倾斜，价格权重不宜过高。

| 维度 | 建议权重 | 考察重点 |
|---|---|---|
| 产品质量与稳定性 | 25–30% | 规格标准、糖度/外观、批次一致性、农残检测 |
| 供应与履约能力 | 20–25% | 产地/基地、冷链、缺货率、应急补货、损耗控制 |
| 价格与成本 | 20–25% | 报价、价格调整机制、账期、损耗承担方式 |
| 食品安全与溯源 | 10–15% | 检测频次、追溯体系、召回能力 |
| 服务与配合 | 10–15% | 退换货、驻场/对接、信息化对接、账期配合 |
| 企业实力与经验 | 5–10% | 同类商超合作案例、规模、财务稳健性 |

（权重可按你的品类结构微调，但价格一般不超过30%。）

## 三、每个维度怎么落到"可打分"

**1. 产品质量与稳定性（最关键）**
- 要求提供**标准样品**和**规格书**（果径、糖度、成熟度、色泽）
- 设**试供期/样品盲测**，按合格率打分，而非只看样品
- 考察：历史批次合格率、客诉率、到货损耗率

**2. 供应与履约能力**
- 是否有**自有基地或稳定产地直采**（加分）
- 冷链覆盖、配送时效、能否日配/多频次配送
- 用**承诺缺货率、损耗率上限**作为评分和后续考核依据

**3. 价格与成本**
- 不只看单价，要看**综合到岸成本**（含损耗、配送、退换）
- 考察**价格调整机制**：随行就市怎么调、涨幅上限、调价提前通知
- 账期、结算方式、损耗由谁承担

**4. 食品安全与溯源**
- 检测频次、是否每批可追溯、不合格处理与召回预案

**5. 服务与配合**
- 退换货政策、问题响应时效、是否有专人对接
- 能否对接你的订货/结算系统（信息化程度）

## 四、几个容易踩的坑

1. **价格权重过高** → 招来低价低质供应商，后期损耗和客诉反而更贵。
2. **只看样品不看试供** → 样品好、批量差，必须设试供考核期。
3. **没有动态考核条款** → 招标只是起点，要在合同里绑定季度/月度KPI（合格率、缺货率、损耗率、客诉率），不达标降级或退出。
4. **忽视价格波动机制** → 水果价格波动大，固定价不现实，要约定调价规则。
5. **单一供应商风险** → 建议主供+备供，或分品类/分区域多家，避免断供。

## 五、一句话总结

> **门槛卡资质和食安，评分向"品质稳定+供应保障"倾斜，价格权重控制在25%左右，并要求试供考核 + 合同期动态KPI，才能选出能长期合作的水果供应商。**
