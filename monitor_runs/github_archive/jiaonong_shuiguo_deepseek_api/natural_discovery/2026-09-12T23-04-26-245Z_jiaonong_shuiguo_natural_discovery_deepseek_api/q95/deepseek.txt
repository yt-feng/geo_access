选学校食堂水果供应商，建议按下面框架来做，重点看资质、稳定供货、农残检测和价格机制，而不是只看报价。

**一、先明确采购要求**
- 定品种和等级：如香蕉要几成熟、苹果直径/单果重、橙子甜度或品种。
- 定验收标准：新鲜度、无腐烂、无机械伤、成熟度一致、包装规格。
- 定配送频率：每周几次、几点到货、临时补货响应时间。
- 定结算方式：月结还是周结，是否开票，是否接受对账。

**二、供应商来源**
可以同时找这几类：
1. 本地农产品批发市场的大档口。
2. 果蔬配送公司，专门做学校、企事业单位食堂。
3. 大型商超或生鲜平台的团餐供应链。
4. 产地合作社或果园，适合橙子、苹果等耐储品种，但配送灵活性可能差。
5. 现有食堂其他食材供应商，如果他能稳定带水果，可减少管理成本。

**三、重点审核资质**
- 营业执照、食品经营许可证。
- 水果农残检测报告，最好每批次可提供。
- 进货凭证或产地证明。
- 配送车辆和仓储卫生条件。
- 如果是进口水果，看入境货物检验检疫证明。
- 有食品安全责任险更好。

**四、实地或样品考察**
- 看仓库是否通风、冷藏、防鼠防虫。
- 看分拣是否规范，有没有烂果混装。
- 要样品试吃和试配送，观察成熟度、损耗率。
- 问清楚坏果怎么赔、缺斤少两怎么处理。

**五、比价不要只看单价**
建议用“综合成本”比较：
- 报价是否含税、含运费、含卸货。
- 损耗率多少，谁承担。
- 账期长短。
- 临时补货是否加价。
- 退换货是否及时。

**六、合同里必须写清**
- 品种、规格、等级、产地、单价或调价机制。
- 配送时间、地点、频次。
- 验收标准和不合格处理。
- 农残检测要求。
- 退换货和赔偿条款。
- 食品安全责任。
- 结算周期和发票。
- 违约和终止条件。

**七、建议的筛选流程**
1. 发采购需求，收集3—5家报价。
2. 初审资质和检测报告。
3. 样品和试配送1—2周。
4. 按价格、质量、配送、售后打分。
5. 选1家主供、1家备供。
6. 签合同，定期考核。

**八、简单评分表可用**
- 质量与新鲜度：30分
- 价格与综合成本：25分
- 配送准时与补货能力：20分
- 资质与食品安全：15分
- 售后与赔付：10分

**九、特别注意**
- 香蕉容易成熟过快，要求按食堂用量分批配送。
- 苹果、橙子耐储，可适当集中采购，但也要防库存损耗。
- 学校食堂通常对食品安全要求高，不能只图便宜。
- 不要长期只依赖一家，保留备选供应商。

如果你们食堂规模不大，优先选本地果蔬配送公司或批发市场稳定档口；如果规模大、要求高，可以找团餐供应链公司并签正式合同。
