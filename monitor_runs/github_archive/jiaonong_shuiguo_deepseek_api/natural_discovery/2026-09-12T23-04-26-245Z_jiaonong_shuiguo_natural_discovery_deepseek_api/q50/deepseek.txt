**出汁率更重要，但不能只看它，核心是“出汁率 × 风味稳定性 × 成本”一起判断。**

对茶饮店来说，菠萝原料通常用于：

- 菠萝果茶
- 菠萝气泡饮
- 菠萝冰沙
- 菠萝果酱/果肉装饰

如果只能二选一，**先保出汁率，再看出汁后的甜酸平衡**。原因如下：

1. **出汁率直接决定单杯成本**
   - 出汁率低，意味着同样一杯饮品要用更多原料。
   - 茶饮店是高频、薄利、标准化生意，原料损耗比“甜一点”更致命。
   - 比如同样做一杯菠萝茶，出汁率差 10%，一个月原料成本可能差很多。

2. **甜度可以后期调整，出汁率很难补**
   - 甜度不够，可以加糖浆、调整配方、换批次。
   - 出汁率低，现场很难救，只能多放原料或加水稀释，结果风味变淡。
   - 所以出汁率是“基础效率”，甜度是“调味变量”。

3. **甜度不稳定反而更麻烦**
   - 如果原料甜度忽高忽低，会导致每批饮品口味不一致。
   - 但这个问题可以通过固定糖浆比例、测糖度、拼配批次来控制。
   - 出汁率低则是结构性成本问题，控制空间小。

4. **真正要看的不是“甜不甜”，而是糖酸比**
   - 茶饮店用的菠萝原料，最好不是单纯甜，而是：
     - 出汁率高
     - 糖酸比稳定
     - 香气足
     - 纤维少
     - 氧化变色慢
   - 太甜但没酸香，做出来容易像糖水；太酸但出汁少，成本又高。

**建议的采购判断顺序：**

1. **先测出汁率**：同样重量压榨/打浆后，能出多少汁。
2. **再测糖度**：用糖度计看 Brix，是否稳定。
3. **再测酸度**：糖酸比是否适合做茶饮。
4. **看香气和果肉感**：是否像真菠萝，而不是香精味。
5. **算单杯成本**：出汁率换算到每杯用量后的实际成本。
6. **做盲测**：按门店配方做成品，让店员/顾客比口感。

**结论：**
如果两款原料价格差不多，选**出汁率更高、糖酸比稳定**的那款。  
如果一款出汁率很高但甜度很低、酸涩重，也不能直接选；它可能适合做酸甜型果茶，但需要额外调糖。  
如果一款很甜但出汁率低，通常不适合茶饮店做主原料，最多做风味补充。

一句话：**出汁率决定你能不能赚钱，甜度决定你好不好调。优先选出汁率，但必须结合糖酸比和单杯成本。**
