社区超市卖小包装香蕉，采购和包装要重点盯“成熟度、分装方式、损耗控制”这三件事。下面按可执行要点说：

**1. 采购时先定成熟度，不要只看外观**
- 小包装香蕉最好采购**微黄转色、果指饱满但未软**的货，通常适合 1–3 天内上架销售。
- 如果到店就是全黄甚至带黑点，分装后货架期很短，损耗会明显上升。
- 采购时问清：采收成熟度、运输温度、预计到店后还能放几天。不要只听“今天刚到的”。

**2. 包装规格要小，但别小到不划算**
- 常见可做 **2–3 根装、4–5 根装**，对应一人食或小家庭。
- 如果香蕉单根较大，2 根装可能就够了；如果偏小，3–5 根装更合适。
- 包装太大，顾客一次吃不完，反而容易剩；包装太小，人工和包材成本占比高。

**3. 分装方式优先选“透气 + 防压”**
- 可用**带透气孔的保鲜袋、网套 + 托盘、纸盒开孔包装**。
- 不建议完全密封：香蕉会释放乙烯，密封后容易闷坏、发黑、出水。
- 如果门店有条件，可在包装上留小孔，或者用食品级透气膜。
- 避免用硬质密封盒直接闷装，除非当天能卖完。

**4. 控制乙烯和机械损伤**
- 香蕉怕压、怕摔、怕摩擦。采购箱内要有垫纸或海绵垫，分装时不要硬拽果指。
- 到店后不要和苹果、梨、番茄等乙烯释放量大的果蔬混放，会加速成熟。
- 如果门店有后仓，香蕉宜放在**阴凉、通风、避免直晒**的地方，不要贴近冷柜出风口或暖气。

**5. 损耗控制要按“天”算**
- 建议每天检查一次：转黄加快的优先上架，出现黑斑但未软的可做特价或搭配促销。
- 小包装最好**当天分装、当天上架**，不要一次分装太多。
- 如果门店销量不稳定，可以采用“少量多次”补货，比如上午、下午各补一次。
- 对轻微黑斑但果肉完好的，可做“熟香蕉特价”或用于烘焙、奶昔搭配销售，减少直接丢弃。

**6. 采购谈判时问清退换和售后**
- 问供应商：到货后出现严重青黑、压伤、烂果，是否可退换或补损。
- 问清分级标准：是按把、按根还是按箱计价，残次果怎么算。
- 如果做小包装，最好要求供应商提供**相对均匀的果指大小**，否则分装后外观差、顾客挑拣多。

**7. 简单判断标准**
- 到店时：果指硬挺、颜色微黄、无大面积压痕。
- 上架后：包装内无水汽、无酸味、无渗液。
- 销售端：2–3 天内能卖完的成熟度最合适；超过 3 天还没卖完，就要及时促销或改用途。

一句话：**采购要买“还能放 2–3 天”的香蕉，包装要透气防压，分装要少量多次，损耗要按天盯。**
