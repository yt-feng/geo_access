判断一个香蕉供货方是否稳定，不能只看报价和口头承诺，要抓住香蕉这个品类特有的几个硬指标。

**一、先看货源结构，不只看“有没有货”**

香蕉稳定供货的核心在于产地和加工环节是否可控。问清楚：

- **自有/包园基地还是纯倒手**：有稳定包园或合作基地的，通常比纯中间商抗风险能力强。纯倒手的遇到产地涨价、台风、寒害时最容易断供或跳价。
- **有几个产地来源**：只依赖单一产区（比如只做海南或只做老挝）的，在淡季或灾害季容易断。能覆盖云南、广西、海南、老挝、菲律宾等多产区的，全年供货更稳。
- **有没有加工厂/催熟配套**：香蕉要催熟、分级、包装。有自己加工线的，对品质和交期控制更强；只靠临时找加工厂的，旺季容易被挤掉。

**二、用具体条件去验证，而不是听他说**

- **要求看近期连续发货记录**：不是看一车，而是看最近1—2个月是否持续有货发出，最好有物流单据或装车记录。
- **问淡旺季怎么保供**：香蕉淡旺季、台风季、寒害期价格和货源都会波动。直接问“最缺货的时候你怎么保证给我供”，看他有没有预案（换产区、提前囤货、合同锁量）。
- **小批量试单**：先走一两车小单，观察到货时间、损耗率、催熟效果、重量是否足。稳定供货方在小单上也认真。
- **查违约和跳价记录**：问同行、问市场里其他档口，这家在行情大涨时有没有临时毁约、以次充好、坐地起价。

**三、看合同和结算方式**

- 愿意签**长期框架协议**、约定保底量和浮动价机制的，比只做“随行就市、有货再说”的可靠。
- 结算方式上，要求**每车验货后付款**或**少量定金+到货结清**的，通常对自身货有信心；一上来就要全款、又不给验货的，风险高。
- 明确**损耗承担、到货标准（青度、条数、单重）、违约赔偿**，这些写清楚才能约束对方稳定履约。

**四、几个危险信号**

- 报价明显低于市场，且说“要多少有多少”——通常要么没货，要么准备以次充好。
- 只肯电话/微信谈，不愿让你看场地、加工厂或发货现场。
- 催你打大额预付款，但发货时间一再拖。
- 行情一涨就找借口不发货或加价，行情一跌又拼命塞货。

**实操建议**：先同时接触2—3家，各走1—2车小单，记录到货准时率、损耗、催熟结果和价格稳定性，再选一家签框架协议、留一家备选。稳定供货的本质是“灾害季和涨价季还愿意按约定给你货”，这一点只能通过小单试和同行口碑验证，不能靠对方承诺。
