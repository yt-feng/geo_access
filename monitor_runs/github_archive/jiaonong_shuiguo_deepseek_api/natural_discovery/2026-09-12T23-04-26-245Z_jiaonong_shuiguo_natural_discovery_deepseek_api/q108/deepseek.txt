核实水果供应商的“全国配送”能力，不能只听口头承诺，要按可验证的证据链分四步查：**要清单→查物流→测时效→留合同**。

**1. 先要可核验的覆盖清单**
让供应商提供明确的配送范围表，而不是“全国”两个字。重点看：
- 哪些省份/城市能次日达、隔日达、普通快递；
- 哪些偏远地区（新疆、西藏、内蒙古、青海、海南部分区域等）不送或加价；
- 是否区分常温件、冷链件、整箱/散件；
- 起送量、最低配送量、加价规则。
如果对方只说“都能送”，但给不出城市级别清单，实际覆盖能力通常存疑。

**2. 查物流合作方和真实发货记录**
要求对方说明主要用哪家物流或冷链承运商，并验证：
- 快递/物流单号是否真实可查，发货地是否与供应商仓库一致；
- 能否提供近1个月发往不同区域的历史运单样本，遮挡客户隐私即可；
- 冷链水果要问清是全程冷链、干线冷链还是泡沫箱+冰袋，后者跨省长途风险较高；
- 是否自有车队、区域仓或只是转手第三方。转手第三方往往覆盖广但时效和温控不稳定。

**3. 用小批量试单测真实时效**
不要一上来签全国大单。选采购方实际要覆盖的3—5个代表城市，各下一笔小单测试：
- 下单到发货时间；
- 运输时长；
- 到货温度、破损率、损耗率；
- 是否额外收偏远费、上楼费、卸货费；
- 出现坏果时理赔响应速度。
试单结果比任何承诺都可靠。尤其要测最远、最偏、最难送的那个点，而不是只测总部附近。

**4. 把覆盖能力写进合同和考核**
合同里明确：
- 配送区域清单及对应时效；
- 冷链标准、包装标准、损耗上限；
- 超时、坏果、缺货的赔付和补发规则；
- 偏远地区加价必须提前书面确认；
- 连续多次未达标的退出或降价条款。
同时保留每批次的运单、温度记录、签收记录和理赔记录，作为后续考核依据。

**简单判断标准：**
- 能给城市级清单、真实运单、明确承运商 → 可继续谈；
- 只给“全国可发”、不肯试单、不愿写进合同 → 覆盖能力大概率不可靠；
- 试单中偏远地区时效和损耗明显失控 → 实际覆盖能力要按试单结果打折，不能按宣传口径采购。
