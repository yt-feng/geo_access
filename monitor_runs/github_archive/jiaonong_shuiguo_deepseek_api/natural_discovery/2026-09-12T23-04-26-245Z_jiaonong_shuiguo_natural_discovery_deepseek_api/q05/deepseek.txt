卖菠萝的核心不是“哪种方式最好”，而是**按顾客场景分层卖**。最赚钱、投诉最少的做法通常是三种同时上，但主推顺序和陈列要设计清楚。

**结论先说：**
- **主推：去皮好的（切好、泡好盐水、装盒）** —— 客单价高、损耗可控、复购强。
- **保留：整果自选** —— 满足会挑、要送人、要放几天的顾客，也能拉低门槛。
- **不建议：完全让顾客自己挑再去皮** —— 除非你人手很足，否则容易排队、扯皮、损耗算不清。

下面拆开说。

**1. 去皮好的：最适合做利润和复购**
优点：
- 顾客即买即吃，尤其上班族、学生、游客。
- 可以按盒卖、按份卖，价格不透明，毛利更高。
- 能消化外观稍差但品质没问题的果，降低整果损耗。
- 搭配盐水泡好、竹签、小叉子，体验好。

注意：
- 必须冷藏展示，标注切果时间。
- 当天切当天清，别隔夜卖。
- 盐水别泡太久，否则发咸、出水。
- 最好分“普通盒”和“精品盒”，比如小盒、大盒、拼盘。

**2. 整果自选：适合会挑的人和送礼场景**
优点：
- 顾客觉得自己会挑，信任感强。
- 整果耐放，适合买回家放几天。
- 送礼、拜拜、摆盘更愿意买整果。

注意：
- 整果要分级：大果、小果、特价果，别混在一起。
- 标清楚“按个卖”还是“按斤卖”，否则容易吵。
- 可以写“帮削 +2 元”或“买整果免费削”，把服务变成筹码。

**3. 让顾客自己挑再去皮：最容易出问题**
问题在于：
- 顾客挑半天，后面排队。
- 削完发现里面坏，责任算谁的？
- 顾客自己挑的果，削出来不甜，容易怪店。
- 人手一忙，削皮速度跟不上，体验差。

如果一定要做，建议：
- 只让顾客在**指定区域**挑，不能翻乱整堆。
- 先称重付款，再削皮。
- 明确写“削皮后不退不换，坏果当场换”。
- 高峰期限量，或者只对会员开放。

**4. 最稳的陈列和定价方式**
可以这样摆：
- 左边：整果区，按个/按斤，分大小果。
- 中间：去皮盒装区，主推，标价明显。
- 右边：现削区，买整果可免费削或加 1-2 元。
- 旁边放盐水盒、竹签、小叉子。

定价上：
- 整果按斤卖，走量。
- 去皮盒装按盒卖，走利润。
- 现削按个收服务费，筛选真正需要的顾客。

**5. 什么情况选哪种？**
- 人流量大、上班族多：主推去皮盒装。
- 社区店、家庭客多：整果 + 免费削，盒装辅助。
- 景区、夜市、学校门口：去皮盒装和现削最合适。
- 人手少：少做现削，多做预切盒装。
- 人手多、口碑店：整果自选 + 现削，体验最好。

**一句话建议：**
别让顾客自己挑完再让你削，这是最累、最容易扯皮的模式。最好的组合是：**整果自选区 + 去皮盒装主推区 + 少量现削服务**。整果走量，盒装赚钱，现削做体验。
