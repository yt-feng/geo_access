社区超市找每天配送的水果供应商，核心要盯住这几类条件，建议按“能不能稳定供、成本划不划算、出了问题谁负责”来判断。

**1. 配送能力**
- 是否承诺每天配送，固定时间还是当天可补货。
- 配送车辆、冷链能力如何，尤其夏天和冬天。
- 起送量、配送费、临时加单怎么算。
- 缺货、迟到、漏送时的处理方式。

**2. 货源稳定性**
- 产地直采还是二级批发，中间环节越多，价格和品质波动越大。
- 反季节水果、常销水果是否能稳定供应。
- 是否支持小批量多品种，社区超市通常单店量不大，但品类要多。

**3. 价格与结算**
- 报价是否随行就市，还是能锁价一段时间。
- 是否含税、含运费、含损耗。
- 账期还是现结，押金、退换货规则要提前说清。
- 对比周边批发市场价，别只看单价，要看综合到店成本。

**4. 品质与损耗**
- 到店损耗率大概多少，坏果、烂果是否包退包换。
- 是否允许开箱验货，验货后发现问题怎么补。
- 水果规格、成熟度、包装是否适合社区店零售。
- 有没有分级，避免“图片好看、到店次果多”。

**5. 售后与责任**
- 坏果赔付标准：按箱赔、按斤赔还是下次补货。
- 质量问题响应时间，是否当天处理。
- 临近保质期或滞销品能否调换。
- 合同或长期合作是否有书面约定。

**6. 实地核验**
- 去供应商仓库或档口看：库存、冷库、分拣、配送车辆。
- 问现有客户，尤其是同类社区超市、水果店。
- 先小批量试合作 1—2 周，看准时率、损耗率、售后响应。
- 试合作期间记录：到货时间、缺货次数、坏果比例、补货速度。

**7. 适合社区超市的优先项**
- 能每天送、起送量低、品类齐全、坏果包赔。
- 价格不一定最低，但综合损耗和售后要可控。
- 最好有本地仓或本地批发市场档口，临时补货快。

简单说：先看“每天能不能稳定送到”，再看“坏果谁赔、价格是否含运费和损耗”，最后用小批量试单验证。别只比报价，社区超市最怕的是今天断货、明天烂果、后天没人售后。
