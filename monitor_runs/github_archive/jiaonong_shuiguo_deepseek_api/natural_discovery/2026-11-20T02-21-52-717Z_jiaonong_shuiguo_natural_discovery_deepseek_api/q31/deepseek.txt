连锁商超水果供应商招标，评分标准建议按“商务资质＋质量与食品安全＋供应能力＋价格＋服务与履约”五块设置，权重可按品类风险调整。下面给一套可直接落地的框架（百分制）：

**一、商务资质与合规（10–15分）**
- 营业执照、食品经营/生产许可、种植基地或合作社证明、检验检测资质齐全（必备项，不符直接废标）
- 近3年同类商超/连锁渠道供货业绩（5–8分），按合同数量、单店数、合作年限打分
- 食品安全责任险、无重大违法失信记录（3–5分）

**二、质量与食品安全（25–30分，水果类应偏高）**
- 农残检测报告、产地证明、追溯体系（批次可追溯）（8–10分）
- 质量标准：果径、糖度、色泽、成熟度、缺陷率等验收标准是否明确并可执行（8–10分）
- 抽检合格率历史数据、客诉率、退换货率（5–8分）
- 冷链与保鲜能力：预冷、冷藏运输、仓储温控记录（5–8分，可并入供应能力）

**三、供应能力与稳定性（20–25分）**
- 日均/峰值供货量、产地直采比例、多产区布局与季节互补能力（8–10分）
- 冷链物流车辆、仓储面积、配送时效与覆盖门店能力（6–8分）
- 应急保供方案：极端天气、价格上涨、疫情等情景下的替代产区与库存策略（5–7分）

**四、价格与成本（25–30分）**
- 报价方式建议用“基准价＋浮动机制”而非一口价：以批发市场均价或指数为基准，约定上下浮动区间（15–20分）
- 价格构成透明度：包装、损耗、运费是否含在报价内（5–8分）
- 账期与结算条件对商超现金流的友好度（3–5分，也可放商务）

**五、服务与履约（15–20分）**
- 订单响应时间、缺货率承诺、破损/损耗责任划分（5–7分）
- 售后：质量问题2小时内响应、无条件退换、赔偿机制（5–7分）
- 数字化能力：能否对接商超订单/库存系统、提供批次追溯数据（3–5分）
- 长期合作意愿：账期接受度、年度降价或促销支持、联合品控（3–5分）

**关键设置建议：**
1. **必备门槛与评分分开**：证照、检测报告、无失信等设为资格性条款，不达标直接淘汰，不占分。
2. **质量权重不低于价格**：水果损耗和客诉成本高，质量与食安合计建议≥30分。
3. **价格分用公式而非主观打分**：如“最低有效报价/投标报价×价格分值”，避免评委自由裁量。
4. **设置履约保证金与考核扣分**：中标后按月度缺货率、客诉率、抽检合格率考核，与续约挂钩。
5. **分品类差异化**：叶菜/浆果类提高冷链和损耗权重；大宗常备果（苹果、柑橘）提高价格和稳定供应权重。
6. **避免唯低价**：设置成本合理性审查，报价明显低于市场价的需提供说明，防止低价中标后断供或降质。

这套框架可直接改成招标文件评分表，建议权重：资质10、质量30、供应25、价格25、服务10，再按企业实际调整。
