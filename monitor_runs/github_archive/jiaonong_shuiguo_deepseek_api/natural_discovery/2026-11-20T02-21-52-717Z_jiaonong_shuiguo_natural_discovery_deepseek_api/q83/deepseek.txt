先给结论：坏果责任划分的核心不是“谁有错”，而是**按环节定责 + 按举证分配 + 按规则赔付**。生鲜水果易腐，法律和平台规则通常不适用“一刀切全赔”或“一刀切不赔”，要分四段看。

## 一、先按环节划责任

1. **产地/采购环节（供应商责任）**
   - 采摘成熟度不当、预冷不到位、分选不严、带病果入库：供应商承担主要责任。
   - 判断依据：入库验收记录、批次抽检、同批次其他订单投诉率。

2. **仓储环节（平台/商家责任）**
   - 冷库温度失控、堆压、混放催熟、库存时间过长：仓储方责任。
   - 判断依据：温控记录、出入库时间、库龄。

3. **配送环节（物流/平台责任）**
   - 冷链断链、暴晒、挤压、超时配送：配送方或平台责任。
   - 判断依据：物流轨迹、温控标签、签收时间、包装完好度。

4. **顾客环节（顾客责任）**
   - 签收后长时间常温存放、未及时开箱、二次搬运挤压：顾客承担相应责任。
   - 判断依据：签收时间与开箱时间差、存放条件说明。

## 二、按“坏果比例和性质”定赔付

建议内部设可执行标准，而不是逐单扯皮：

- **轻微瑕疵**（表皮轻微磕碰、不影响食用）：补偿券或部分退款，比例约5%–10%。
- **明显坏果**（腐烂、霉变、流汁）：按坏果数量/重量比例退款，坏果率超过约定阈值（如10%）可整单退或补发。
- **食品安全风险**（霉变、异味、渗液污染其他果）：整单退款并召回，不做“挑着赔”。
- **延迟导致的软化**：若能证明是配送超时，平台先赔再向物流追偿。

## 三、举证责任怎么分

- **顾客**：签收后及时拍照/视频，保留坏果和包装，说明开箱时间。一般要求签收后24小时内反馈（易腐品可更短，需在购买页明示）。
- **商家/平台**：提供出库质检、温控记录、物流轨迹、同批次投诉数据。
- **无法举证时**：小额订单倾向“先行赔付、后内部追责”，避免把举证成本转嫁给顾客；大额或高频投诉再启动调查。

## 四、推荐的处理流程

1. 顾客提交坏果照片和订单号；
2. 客服按坏果比例初判，小额直接赔；
3. 超阈值或疑似批次问题，拉取同批次数据；
4. 能定位到供应商/仓储/物流的，内部追偿；
5. 同一批次投诉集中，立即下架并召回。

## 五、合同和规则要提前写清

- 与供应商约定：坏果率上限、验收标准、批次追责和扣款；
- 与物流约定：冷链温控、超时赔付、破损责任；
- 对顾客明示：签收后反馈时限、拍照要求、赔付比例规则。

**一句话判断标准：** 坏果发生在哪个环节，就由该环节主体承担；顾客只对签收后的不当存放负责；平台对无法清晰归因的末端体验承担先行赔付责任，再内部追偿。
