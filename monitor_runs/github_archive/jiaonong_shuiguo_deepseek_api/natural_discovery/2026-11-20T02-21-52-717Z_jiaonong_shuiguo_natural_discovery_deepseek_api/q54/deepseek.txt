优先看成熟度，价格其次。

**判断标准：**
1. **做香蕉蛋糕最适合的成熟度**：表皮大面积出现黑斑、果肉软但未流汁、闻起来有明显甜香。这个阶段淀粉转糖充分，甜度和香气最好，还能减少配方里的糖量。
2. **过于生青**：香气弱、甜度低、口感发涩，烤出来香蕉味不足，还可能要额外加糖，反而不划算。
3. **过熟到果肉液化、有酒味或酸味**：不要用于出品，适合报废或做内部测试，不能靠低价大量采购。

**采购建议：**
- **按用途分级采购**：当天/次日要用的买“黑斑成熟蕉”；提前2–3天备货的可买“黄熟带少量斑点”，在店里自然催熟。
- **价格只作为同成熟度下的比较项**。同一成熟度，比单价、损耗率和出肉率；不同成熟度不要只比单价。
- **算实际成本**：用“可食用果肉成本＝采购价÷出肉率”，并考虑催熟时间和损耗。便宜但太生的香蕉可能糖酸比不够，需要加糖和香精，综合成本未必低。
- **控制批量**：成熟香蕉不耐放，按2–3天用量分批买，避免低价囤货导致过熟报废。

一句话：**先定成熟度窗口，再在同窗口里比价格和出肉率。**
