优先建议：**先上“小把装”为主，单根作为补充测试，整袋暂不作为主陈列。** 对便利店来说，这通常最平衡销量、损耗和客单价。

判断框架：

1. **主推小把装（2–3根）**
   - 适合便利店“即时买、少量吃”的场景。
   - 比单根更有客单价，又比整袋更容易卖完。
   - 建议定价用“按把计价”，减少称重和排队。
   - 陈列上放在收银台附近或早餐/酸奶旁边，做搭配购买。

2. **单根作为补充，但要有条件**
   - 适合写字楼、学校、交通枢纽等“一个人马上吃”的场景。
   - 损耗最低，但客单价低、挑拣多、陈列容易乱。
   - 如果上单根，建议只保留少量，并选外观好、成熟度适中的，避免被反复翻拣。

3. **整袋不建议作为主推**
   - 便利店客流多为1–2人即时消费，整袋购买频次通常低于小把。
   - 整袋一旦成熟度控制不好，滞销和黑斑损耗会明显增加。
   - 如果周边有家庭客群，可少量尝试“家庭袋”，但不要压货。

**可执行的上架测试方案：**
- 第1周：小把装占70%，单根占20%，整袋占10%。
- 每天记录：销量、报废量、毛利率、顾客询问。
- 连续观察7–14天，若单根复购明显且损耗低，可提高到30%；若整袋周销量低于小把的1/3，就下架。
- 成熟度控制：主陈列选“今天到明天可吃”的，偏青的作为后备库存，避免一次性全熟。

**结论：小把装为主，单根小量补充，整袋只做测试。** 如果门店在社区、家庭客多，可把整袋比例临时上调，但仍以损耗数据决定去留。
