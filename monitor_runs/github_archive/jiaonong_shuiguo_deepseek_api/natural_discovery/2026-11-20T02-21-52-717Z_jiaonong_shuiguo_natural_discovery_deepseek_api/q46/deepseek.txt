直接结论：**优先鲜果，其次冷冻果丁，果泥只用于特定场景**。果茶里菠萝主要提供“香气+果肉口感+酸甜”，三者取舍看你的店型和出杯量。

**1. 鲜果（推荐首选）**
- 适合：现切现做、主打新鲜感、客单价中高、有备料人手。
- 优点：香气和口感最好，能做果肉块、装饰片；顾客感知“新鲜”。
- 缺点：损耗高、切配耗时、季节性波动大、批次酸甜不稳定；需要泡盐水/糖渍控涩，菠萝蛋白酶会让部分人口腔刺感，也可能影响奶制品。
- 采购判断：出杯量够大（每天能用完整批）、有稳定切配人手，就买鲜果。

**2. 冷冻果丁（性价比和稳定性最好）**
- 适合：连锁/外卖占比高/出杯量大/人手紧。
- 优点：规格统一、损耗低、开袋即用、风味稳定，冷冻菠萝香气保留不错；能直接做果肉感。
- 缺点：解冻后出水、口感略软，需控水；部分产品糖渍偏甜，要调配方。
- 采购判断：如果你想要“稳定出品+少损耗”，冷冻果丁通常是茶饮店最实用的选择。选无额外糖渍或轻糖渍的，看配料表。

**3. 果泥（只作辅助，不建议单独做主料）**
- 适合：做冰沙、打底调色增酸、季节性快速上新、标准化要求极高。
- 优点：标准化、出杯快、成本可控。
- 缺点：几乎没有果肉口感，香气偏“加工感”，顾客对“鲜果茶”的期待会打折；用量不当容易糊嘴、沉淀。
- 采购判断：不要用它替代果肉；可“果泥打底+少量果丁/鲜果块”组合。

**可执行方案**
- 小店、日销低、主打手作：**鲜果为主**，少量冷冻果丁应急。
- 中等以上出杯量、外卖多：**冷冻果丁为主，鲜果做装饰/招牌款**。
- 做冰沙或需要极致稳定：**果泥打底+果丁增口感**，并在菜单上避免暗示“纯鲜果”。

**采购验收要点**
- 鲜果：闻香气、看成熟度均匀、切开无黑心；到店先测糖酸，定糖渍/盐水比例。
- 冷冻果丁：看配料表是否加糖、解冻失水率、果丁完整度；试解冻后香气。
- 果泥：看果汁/果浆含量和配料顺序，试与茶汤搭配是否发闷、沉淀。

一句话：**要新鲜感买鲜果，要稳定省损耗买冷冻果丁，果泥只当配角。**
