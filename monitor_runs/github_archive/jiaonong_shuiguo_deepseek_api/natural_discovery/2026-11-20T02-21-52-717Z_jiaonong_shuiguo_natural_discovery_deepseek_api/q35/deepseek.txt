# 连锁超市合同里约定坏果赔付的要点

核心思路：**把“坏果率”从模糊概念变成可计算、可举证、可扣款的条款**，并按到货检验、在架损耗、批次追溯三个环节分别设计。建议按以下结构写进合同：

## 一、先定义，再约定赔
- **坏果定义**：明确列举（腐烂、霉变、软烂流汁、异味、虫蛀、机械伤超限、冻伤等），并配可量化标准，如“单果腐烂面积≥1/4”“同批次霉变≥2个”。
- **统计口径**：以“箱/批次”为单位抽检还是全检；抽检比例（如每批次抽检≥10%）；不合格判定（如抽检坏果率≥3%即整批可退）。
- **计量基准**：按件数还是按重量；赠品、尾货、促销品是否计入。

## 二、分环节设赔付
1. **到货验收环节**（最易执行）
   - 坏果率≤约定值（如2%）正常收货；
   - 超出部分：可整批拒收，或按“超出比例×该批货值”扣款；
   - 严重超标（如≥10%）：整批退货，供应商承担运费及门店已发生的上架成本。
2. **保质期内（在架期）损耗**
   - 约定“到货后X天内坏果率累计不超过Y%”，超出部分由供应商补货或按货值赔付；
   - 明确是否包含自然损耗，避免扯皮。
3. **批次追溯与召回**
   - 同一SKU连续N批次超标，触发整改或终止合作条款；
   - 因坏果引发的客诉、食品安全事件，供应商承担赔偿及处理费用。

## 三、赔付方式与结算挂钩
- 优先**货款抵扣**（最可执行），约定扣款计算式、对账周期和异议期（如3个工作日内书面提出，逾期视为认可）。
- 补货条款：明确补货时限、补货品质量要求，补货不合格是否可再次索赔。
- 违约金与赔偿上限：区分“质量扣款”和“违约赔偿”，避免供应商以赔偿上限抗辩。
- 检测与举证：约定以门店验收记录、拍照/视频、第三方检测报告为证据；明确谁承担检测费（不合格由供应商承担）。

## 四、几个容易漏的细节
- **季节性差异**：叶菜、浆果等易损品类单独设阈值，不要一刀切。
- **运输责任划分**：明确装车、运输、卸货各环节的温度和时限要求，坏果归因不清时按“谁控制谁负责”。
- **数据留痕**：要求门店按统一格式记录批次、到货时间、抽检结果，作为扣款依据，否则条款难以落地。
- **争议解决**：约定复检机制和时限，防止供应商拖到对账期过后再异议。

**一句话建议**：合同里至少写清“坏果定义＋抽检规则＋分环节阈值＋扣款公式＋货款抵扣＋举证方式”六项，缺一项都容易在结算时变成口水仗。
