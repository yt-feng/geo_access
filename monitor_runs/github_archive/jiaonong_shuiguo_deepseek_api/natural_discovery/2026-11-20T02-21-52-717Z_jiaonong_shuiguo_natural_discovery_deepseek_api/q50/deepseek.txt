甜度和出汁率不是二选一，优先级取决于你拿菠萝做什么。可先按用途判断：

**1. 鲜果茶、水果茶、菠萝块装饰：甜度优先**
- 顾客直接吃到果肉，甜度不够会显得酸、生、廉价，靠糖浆补救会掩盖茶香。
- 但甜度要配合“酸甜比”，不能只看糖度；过熟发软、发褐的菠萝出汁高但口感差。
- 这种用途建议：**甜度/风味 > 出汁率**。

**2. 打浆、做菠萝汁底、冰沙、果酱：出汁率优先级更高**
- 出汁率直接影响出杯量、成本和风味浓度；甜度可以通过糖浆、品种拼配调整。
- 但出汁率高的品种往往水分大、风味淡，要同时看可溶性固形物（糖度）和香气。
- 这种用途建议：**出汁率 > 甜度**，但设甜度下限。

**3. 门店通用采购：先定最低甜度线，再比出汁率**
可执行做法：
- 先按产品定一个**最低甜度标准**（比如鲜食块要求更高，打浆用可略低）。
- 在达标批次中，再选出汁率高的，降低单杯成本。
- 同时看**成熟度、纤维粗细、黑心/水心病、损耗率**，这三项常比单纯甜度或出汁率更影响门店体验。
- 不要只买最甜的：过熟菠萝出汁高但易软烂、氧化快、切配损耗大。

**结论：**
- 卖果肉、鲜果茶：**甜度更重要**。
- 榨汁、打浆、做基底：**出汁率更重要**。
- 门店综合采购：**先设甜度合格线，再在合格批次里选出汁率高、损耗低的**。
