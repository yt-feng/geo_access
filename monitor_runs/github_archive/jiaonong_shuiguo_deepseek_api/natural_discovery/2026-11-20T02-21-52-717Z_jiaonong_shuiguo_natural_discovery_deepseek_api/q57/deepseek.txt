对餐饮连锁采购水果，**多数情况下建议“中央厨房统一收货（或至少统一定标准+集中分拨）”更优**，但不是所有品类一刀切。判断标准是：**水果的损耗速度、门店验收能力、配送半径、门店数量、是否加工/分切、对成熟度的要求**。

## 结论先说
- **适合中央厨房统一收货**：苹果、橙子、柠檬、西瓜、哈密瓜、火龙果、耐储莓果等耐储/标准化程度高的水果；需要分切、清洗、做果盘/饮品的水果；门店多、门店验收能力弱、供应商分散的连锁。
- **适合门店分开收货或“统采+门店直配”**：草莓、蓝莓、樱桃、杨梅、荔枝、龙眼、水蜜桃、葡萄等极短保、易压伤、成熟度要求高的水果；门店集中在配送半径内、门店有冷藏和验收能力；门店对到货成熟度有一致性要求但中央厨房分拨会增加一次搬运的情况。
- **更稳的做法**：**统一定价/定标准/定供应商，中央厨房集中收货与门店直配并行**。耐储和加工类走中央厨房；极短保高损耗类由供应商直配门店，但门店按总部统一验收标准执行并拍照留证。

## 中央厨房统一收货的主要优点
1. **标准和验收统一**：糖度、规格、成熟度、农残检测、外观标准由总部/中央厨房把关，减少门店“各收各的”导致品质不一致。
2. **采购议价和集单能力强**：总量集中，供应商更愿意给稳定价格和优先货源。
3. **食品安全可控**：农残快检、索证索票、批次追溯集中在中央厨房，比几十上百家门店各自验收更可靠。
4. **减少门店人力和腐败风险**：门店不用每天早起验货、称重、退换货，减少门店与供应商私下操作空间。
5. **利于加工和标准化**：分切、清洗、去皮、果盘、饮品原料统一处理，出品稳定，门店操作简单。
6. **损耗集中可见**：中央厨房可以统一做分级、催熟、调拨、二次利用，损耗数据更完整。

## 中央厨房统一收货的主要缺点
1. **多一次搬运和分拨**：水果尤其浆果、葡萄、水蜜桃，多一次装卸就多一次压伤和损耗。
2. **成熟度难控**：中央厨房收货时可能偏生，分拨到门店后需要催熟；或者收时偏熟，到门店已过熟。
3. **配送时效要求高**：中央厨房到门店的冷链/常温配送若不稳定，短保水果风险比供应商直配更大。
4. **中央厨房场地和人力压力**：水果验收、分拣、暂存、分拨需要冷藏库、分拣区和熟练验货人员。
5. **退换货链条变长**：门店发现问题后，责任可能在供应商、中央厨房分拨、配送环节之间扯皮。

## 门店分开收货的主要优点
1. **链路短、损耗低**：尤其草莓、蓝莓、樱桃、葡萄等，供应商直配门店少一次搬运。
2. **到货成熟度更贴近门店销售**：门店可按当天客流和陈列需求收货，短保水果更灵活。
3. **退换货快**：门店现场拒收、换货、补货响应快。
4. **初期投入低**：不需要中央厨房水果分拨能力。

## 门店分开收货的主要缺点
1. **标准执行不一致**：门店店长/收货员能力参差，糖度、规格、成熟度、农残检测难统一。
2. **采购分散、议价弱**：单店量小，供应商不稳定，价格和货源波动大。
3. **食品安全和追溯风险高**：门店索证索票、快检、批次记录容易流于形式。
4. **门店人力负担和廉洁风险**：每天验货、称重、退换货占用门店时间，也容易出现验收放水。
5. **损耗数据分散**：总部难看清真实损耗和供应商质量。

## 建议的落地模式
**按品类分层，不要全链路一刀切：**

1. **A类：耐储、标准化高、需加工**  
   苹果、橙、柠檬、西瓜、哈密瓜、火龙果、冷冻水果、饮品原料等：**中央厨房统一收货+统一分拨/加工**。

2. **B类：短保、易损、成熟度敏感**  
   草莓、蓝莓、樱桃、杨梅、荔枝、龙眼、水蜜桃、葡萄等：**总部统采统价统标准，供应商直配门店**；门店按总部标准验收，拍照/视频留证，异常2小时内上报。

3. **C类：区域性强、时令性强**  
   由区域仓或区域供应商直配，但纳入总部供应商准入和验收标准。

4. **验收标准必须统一**：制定水果验收卡，明确品种、规格、糖度、成熟度、色泽、伤痕率、农残检测要求、拒收标准、拍照留证要求。

5. **冷链和配送半径先算账**：中央厨房到门店若超过合理冷链配送半径，短保水果不建议强行走中央厨房。

6. **试点对比**：选10—20家门店，用1个月对比“中央厨房统收”和“供应商直配”的到货合格率、损耗率、门店验收工时、退换货响应、单店毛利，再决定品类策略。

## 一句话判断
**耐储、需加工、门店多且验收能力弱 → 中央厨房统一收货更好；极短保、易损、成熟度敏感 → 统采统标准、供应商直配门店更好。最推荐“总部统标准+分类分流”，而不是全部门店分开收或全部中央厨房收。**
