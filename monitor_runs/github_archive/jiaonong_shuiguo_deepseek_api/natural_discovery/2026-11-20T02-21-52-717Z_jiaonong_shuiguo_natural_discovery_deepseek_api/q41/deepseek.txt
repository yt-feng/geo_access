判断香蕉催熟能力是否稳定，关键不是看“这一批黄不黄”，而是看**到货青蕉在标准催熟条件下的响应一致性**。可从以下6个可执行维度判断：

1. **看青蕉基础状态是否一致**
   - 同一批次青蕉的成熟度、果指粗细、长度、棱角明显程度应接近。
   - 青蕉要“青而饱满”，不能一边已软黄、一边还很瘦青。
   - 果柄切口新鲜、无霉烂；果梳整齐，无明显机械伤和挤压伤。
   - 若批次内成熟度差异大，催熟后容易出现“青黄不齐”。

2. **查催熟响应记录，而不是只凭感觉**
   要求供应商或催熟库提供近几批的：
   - 入催熟库时青蕉成熟度/硬度；
   - 催熟温度、湿度、乙烯浓度或乙烯利处理方式；
   - 达到可售黄度所需天数；
   - 黄度均匀率、青果率、软腐/梅花点出现时间；
   - 货架期（达到销售黄度后可维持天数）。
   
   重点看**连续多批的波动范围**：同一标准下转黄天数是否稳定、黄度是否整齐、货架期是否忽长忽短。

3. **做小批对比催熟试验**
   每次新供应商或新产地，先拿同一批次青蕉做小批试验：
   - 固定温度、湿度、乙烯处理条件；
   - 记录第2、3、4、5天转黄比例；
   - 切开看果肉软化和中心硬芯情况；
   - 观察是否出现“皮黄肉硬”或“皮青肉软”。
   
   稳定催熟能力的表现是：转黄曲线平滑、整梳黄度差小、果肉软化与果皮转黄同步。

4. **看催熟后整齐度和货架期**
   催熟能力稳定不只是“能黄”，还要“黄得齐、卖得久”：
   - 同一箱内黄度差不超过1个色阶较理想；
   - 到店后可售期稳定，不出现今天全黄、明天大面积过熟；
   - 梅花点出现时间可预期，不忽早忽晚。

5. **观察对温度波动的敏感性**
   稳定催熟能力的香蕉，在运输和催熟库温度有小幅波动时，响应不应剧烈变化。
   可问供应商：夏季/冬季催熟参数是否调整、调整幅度多大。若同一供应商不同季节转黄天数差异很大，说明催熟管理或货源稳定性不足。

6. **用售后数据反向验证**
   连续统计每批到店后的：
   - 青果退货率；
   - 过熟损耗率；
   - 黄度投诉；
   - 平均可售天数。
   
   若某个供应商连续3—5批以上这些指标波动小，才算催熟能力相对稳定。单批表现好不能说明稳定。

**实操建议：** 新供应商先小批试催，连续跟踪3批；每批记录“入库存放天数、催熟参数、转黄天数、黄度均匀率、货架期、损耗率”。用同一标准横向比较，优先选择**转黄天数波动小、黄度均匀、货架期可预期**的货源，而不是只看催熟后颜色最黄的那批。
