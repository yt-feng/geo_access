# 学校食堂水果供应商选择建议

## 一、先明确准入条件（硬门槛）

1. **证照齐全**：营业执照、食品经营许可证（经营范围含食用农产品/预包装食品）、供货商还需提供产地证明或进货凭证。要求能追溯来源。
2. **能开票、能签合同**：学校采购一般走对公结算，供应商须能开增值税发票、接受账期（如月结）。
3. **有配送能力**：能按学校要求的时间（通常早于开餐前2–3小时）送到食堂，并有冷藏/常温运输条件。
4. **食安责任**：能提供每批次农残检测报告或承诺抽检合格，愿意在合同中承担食品安全责任。

## 二、按品类分别看重点

- **香蕉**：最怕催熟不均和运输碰伤。选能控制成熟度（到货7–8成熟、校内自然催熟）、有周转筐配送、损耗包换的供应商。香蕉损耗率高，报价要问清"到货合格率"和破损处理方式。
- **苹果**：耐储、标准化程度高，重点看**规格分级**（如80#果）和产地稳定性。建议选能长期稳定供货、按等级报价的，避免"样品好、大货差"。
- **橙子**：季节性明显，重点看**产地直采能力**和酸甜度/化渣度。可要求先送样品试吃，再定等级标准。反季节橙子价格波动大，合同里要约定调价机制。

## 三、实操筛选流程

1. **询价至少3家**：本地批发市场商户、产地合作社/基地、专业生鲜配送公司各找1–2家对比。三者各有优劣：批发市场灵活但溯源弱，基地价格优但配送弱，配送公司服务好但加价。
2. **实地看货**：看仓库、看周转筐清洁度、看有没有混放化学品，抽看现货等级。
3. **试供1–2周**：先小批量试供，记录到货合格率、损耗率、准时率。
4. **比价要比"到货净价"**：把运费、损耗、退换成本算进去，别只看单价。
5. **签框架合同**：约定品类等级标准、价格调整机制（如随批发市场均价浮动±X%）、验收标准（不合格拒收/换货）、账期、违约责任。

## 四、验收与日常管理（容易被忽略但最关键）

- 到货**当场验收**：称重、看外观、抽检，不合格当场上报换货，不留到第二天扯皮。
- 建立**供应商评分表**：质量、准时、价格、售后四项打分，季度淘汰末位。
- **不要只依赖一家**：香蕉、苹果、橙子可各留1家主供+1家备选，防止断供或坐地起价。
- 保留每批次**检测报告和送货单**，应付检查和追溯。

## 五、避坑提醒

- 警惕"报价明显低于市场价"的供应商，常见问题是等级虚标、以次充好、缺斤短两。
- 合同里写清**验收标准要可量化**（如苹果单果重、橙子糖度范围、香蕉无黑斑比例），否则验收全靠嘴说。
- 学校采购涉及廉政风险，建议走公开比选或至少三方询价留痕，避免单一来源指定。
