年度合同里最容易踩坑的，通常不是“价格”本身，而是价格背后的**计价口径、损耗归属、验收标准、账期和返利**。连锁超市签水果年度合同，建议重点盯住以下条款：

**1. 价格与调价机制**
- 坑：只写“随行就市”，没有基准价、调价频率、触发条件和审批流程。
- 建议：明确基准市场/报价来源、调价周期（如每周/每旬）、涨跌幅阈值、双方确认方式；促销价、特价、临期处理价单独约定，不自动纳入结算。

**2. 规格与验收标准**
- 坑：只写“新鲜、无腐烂”，没有品种、等级、单果重、糖度、着色、农残、包装规格。
- 建议：把验收标准做成附件，按品种列明感官指标、理化指标、抽检比例、不合格判定和拒收/降级处理规则。

**3. 损耗与退货归属**
- 坑：运输损耗、仓储损耗、门店损耗混在一起，最后超市承担大部分。
- 建议：分段约定到货前损耗、验收后损耗、滞销损耗由谁承担；明确退货条件、退货比例上限、退货费用和补货时限。水果尤其要写清“到货验收后多长时间内发现内在质量问题可追溯”。

**4. 账期与结算**
- 坑：账期起算点模糊，对账依赖口头，扣款项目不透明。
- 建议：写清对账日、开票要求、付款日、逾期付款责任；所有扣款（质量扣款、缺货罚款、促销费用）须有书面确认或系统记录，避免“月底一刀扣”。

**5. 返利与费用条款**
- 坑：年返、陈列费、促销费、进场费名目多，计算基数不清，是否含税、是否含促销额不明确。
- 建议：逐项列明费用名称、计算基数、税率、支付方式、发生条件；返利按含税还是不含税销售额计算要写死，避免年底争议。

**6. 供货保障与缺货责任**
- 坑：只写供应商应保证供应，没有最低供货量、备货要求、缺货违约金和替代方案。
- 建议：约定年度/月度最低供货量、紧急补货响应时间、缺货通知义务和违约责任；同时给供应商合理免责情形（如极端天气、产地减产），但要有证明和协商机制。

**7. 质量安全与追责**
- 坑：农残超标、食品安全事故的责任边界不清，超市被监管处罚后能否全额追偿不明确。
- 建议：要求供应商提供检测报告、产地证明、承诺符合食品安全标准；约定抽检不合格的处罚、下架召回费用、监管罚款和消费者赔偿的追偿责任。

**8. 独家/排他及渠道限制**
- 坑：供应商同时给竞品供货，或超市要求独家但未给保底量。
- 建议：如要独家，必须绑定采购量或保底金额，并明确违约后果；反之，若供应商要求排他，超市要评估自身门店覆盖和销量承诺。

**9. 合同期限与退出机制**
- 坑：一年一签但无提前解约、无淡旺季调整、无不可抗力细化。
- 建议：设置试用期/观察期、季度复盘机制、提前终止条件（连续质量不合格、缺货率超标、价格严重偏离市场）；不可抗力要列明情形和通知、举证、减损义务。

**10. 争议解决与证据留存**
- 坑：口头沟通多，验收单、对账单、扣款通知没有固定模板和签收规则。
- 建议：约定对账和异议期限，明确电子邮件/系统订单的法律效力；验收单、退货单、扣款确认单统一格式并由双方授权人签认。

**最优先处理的三个坑：**
1. **验收标准附件化**——没有附件，后面全是扯皮。
2. **损耗分段归属**——水果合同的最大利润漏点。
3. **返利和扣款的计算基数**——年底争议高发区。

实操上，建议在合同后附《品种规格验收表》《价格调整确认单》《对账扣款确认单》三个模板，比正文写多少“双方友好协商”都管用。
