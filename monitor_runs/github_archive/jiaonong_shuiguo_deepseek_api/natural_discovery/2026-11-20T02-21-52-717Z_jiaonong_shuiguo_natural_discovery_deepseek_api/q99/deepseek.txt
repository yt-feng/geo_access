选择下午茶水果供应商，重点不是“水果最好吃”，而是**批量配送稳定、损耗可控、结算省心**。可以按下面几个维度筛：

1. **先定采购规则**
   - 数量按人头×1.2～1.5份估算，避免不够。
   - 选“易分装、耐运输、不需要现场加工”的品类：香蕉、橘子/砂糖橘、圣女果、葡萄（盒装）、苹果、梨、小番茄、切盒西瓜等。
   - 少选：草莓、蓝莓、荔枝、水蜜桃等易压伤、易变质、价格波动大的水果，除非供应商能当天冷链并接受坏果赔付。

2. **优先找“做企业团餐/下午茶”的供应商**
   比普通水果店更合适，因为通常具备：
   - 批量分装能力（按份装盒/装袋）
   - 固定配送时段
   - 企业月结/开票
   - 坏果补发或扣款机制
   可以在本地搜“企业水果配送”“团餐水果供应商”“下午茶水果切盒配送”，或问同写字楼行政群推荐。

3. **必须提前问清6件事**
   - 起送量和配送费：多少份起送？楼层/园区是否加价？
   - 送达时间：能否在下午茶开始前30分钟到？迟到怎么处理？
   - 分装方式：是否按份独立包装？是否配叉子/纸巾/垃圾袋？
   - 损耗赔付：坏果、压伤、少斤两怎么赔？拍照后是否当场补送或下次抵扣？
   - 价格锁定：当季水果价格波动时，报价有效期多久？
   - 结算凭证：能否开票、支持对公转账/月结、提供配送单。

4. **先小单试配，再签长期**
   第一次不要直接订大单。选20～30人份试一次，重点看：
   - 到货时间是否准时
   - 实际净重和宣传是否一致
   - 坏果率是否低于5%
   - 分装是否整齐、是否好分发
   - 临时加量/减量是否配合
   试配满意后再谈周配或月配。

5. **合同/订单里写清楚**
   建议在订单备注或简易协议中写明：品类、规格、净重、份数、送达时间、坏果赔付标准、临时变更截止时间、发票类型。批量采购最怕口头承诺，写下来能减少扯皮。

6. **备选方案**
   不要只依赖一家。可以“主供应商+本地水果店/生鲜平台”双渠道：主供应商负责常规周配，临时加量或主供应商出问题时用备选补位。

简单判断标准：**能按份分装、准时送到、坏果敢赔、能开票月结的，优先；只便宜但不负责分装和售后的，不建议长期用。**
