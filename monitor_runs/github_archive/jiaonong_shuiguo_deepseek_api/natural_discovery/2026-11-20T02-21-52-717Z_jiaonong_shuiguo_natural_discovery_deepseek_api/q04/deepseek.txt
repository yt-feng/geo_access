直接按“**青一点进货、分段催熟、按天分批到货**”来要求供应商，最实用。

采购时可以这样写进要求：

1. **熟度要求**
   - 主批次采购：**7成熟左右**，果身硬、棱角明显、表皮整体青绿或仅轻微转黄，**不要有黑点、不要软塌、不要已明显出香**。
   - 少量即卖批次：可要**8成熟**，表皮微黄、手感略软，但当天能卖完的量才进。
   - 明确拒收：**表皮超过1/3转黄、果柄发黑、果身有压伤/裂口、整把软、有酒味或明显香味**的货。

2. **到货时间与批次**
   - 不要一次全到，改成**每周2—3次、小批量到货**。
   - 要求供应商**按“青果/微黄果”分开装箱**，并标注采摘或催熟日期。
   - 到货尽量安排在**早上营业前**，方便当天分拣、上架和催熟管理。
   - 节假日或高温天，要求**缩短在途时间**，优先近仓/近产地发货。

3. **包装与运输**
   - 要求**透气箱、分层码放、不要密封闷装**，避免运输中发热催熟。
   - 香蕉**不要和苹果、梨等释放乙烯的水果混装**。
   - 到货温度尽量控制在**13—15℃**，避免暴晒和冷害。

4. **合同/订单里建议加一句**
   - “香蕉以7成熟为主，允许少量8成熟；到货时青果比例不低于70%，无黑点、无软果、无压伤；按门店销售节奏分2—3批到货，熟度不符或过熟批次可拒收。”

5. **店内配合**
   - 到货后**先分拣**：青果放阴凉通风处，微黄果单独放，优先卖。
   - 想加快转黄可放**密闭催熟箱+少量乙烯源**，但别整批闷；想减慢就**通风、避光、别冷藏**。

一句话采购口径：**“要7成熟、青果为主、分批小量到、早上到货、过熟和压伤拒收。”**
