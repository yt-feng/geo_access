社区超市做每日水果配送，筛选供应商时建议重点看下面几类条件，按“先保供稳、再保品质、最后压成本”的顺序判断。

1. **配送能力是否真能做到每日**
   - 是否有固定冷链车、配送路线和时间窗，能否覆盖你所在片区。
   - 每日到店时间是否稳定，能否接受早于营业前送达。
   - 节假日、雨天、爆单时有没有备用车辆和应急方案。
   - 起送量、配送费、临时补货是否加价，要提前问清。

2. **货源稳定性和季节替代能力**
   - 是产地直采、一级批发还是二级贩子，层级越多损耗和加价越高。
   - 常卖单品是否有稳定基地或长期合作档口。
   - 某个单品断货时，能否快速给同价位替代品，而不是临时涨价。
   - 是否支持小批量多频次补货，适合社区店低库存周转。

3. **品质标准和验收规则**
   - 看样品不如看连续一周的到货：大小、成熟度、糖度、表皮瑕疵、箱内上下是否一致。
   - 要求明确验收标准：坏果率、压伤率、规格误差、净重是否足秤。
   - 坏果、短斤少两怎么赔：现场扣款、下次补货还是退货，必须写进合作约定。
   - 是否允许开箱抽检、拍照留证，售后响应时限多长。

4. **价格和结算是否透明**
   - 报价要含税、含运费、含包装，避免“低价进货、损耗补回”。
   - 对比同规格净重单价，不要只看箱价。
   - 账期能否接受，现结是否有折扣，押金和违约金怎么算。
   - 价格随行就市时，提前多久通知调价。

5. **损耗控制能力**
   - 是否提供小包装、分级果、适合社区店的规格。
   - 能否按你的销量建议订货量，减少压货。
   - 有没有临期果处理方案，比如换货、特价支持。
   - 冷链是否全程覆盖，尤其夏季叶菜、浆果、荔枝类。

6. **资质和食品安全**
   - 营业执照、食品经营许可或食用农产品相关资质。
   - 农残检测报告或承诺抽检机制。
   - 运输车辆卫生、装箱容器是否清洁，是否混装异味商品。

7. **合作条款和退出机制**
   - 先试配送7—14天，按实际到货合格率、准时率、损耗率评估。
   - 约定最低供货品类、断货赔偿、质量问题处理时限。
   - 不要一次性押大量货款，先小单验证。
   - 保留1—2家备选供应商，避免单一依赖。

实操建议：让2—3家供应商同时试送一周，每天记录“到店时间、净重、坏果率、缺货率、售后响应”，一周后按数据选，不要只凭报价和样品决定。
