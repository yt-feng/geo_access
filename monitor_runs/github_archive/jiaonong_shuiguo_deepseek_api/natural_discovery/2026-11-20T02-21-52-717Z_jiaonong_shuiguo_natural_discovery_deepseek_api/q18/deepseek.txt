买香蕉想“到店刚好”，核心是：**按你打算吃的日期选成熟度 + 到店先看表皮和手感 + 不一次买同一成熟度**。给你一套可执行的判断法。

### 1. 先定“什么时候吃”
- **当天/明天吃**：选**通体金黄、少量芝麻点**的。
- **2～3天后吃**：选**黄中带绿、两端还略绿**的。
- **4～5天后吃**：选**明显偏绿、硬挺**的，回家常温放。
- **想分批吃**：同一把里挑**成熟度不一致**的，或买两小把不同成熟度。

### 2. 到店看这4点
1. **颜色**：  
   - 全绿＝很生；  
   - 黄带绿尖＝2～3天；  
   - 全黄＝马上吃；  
   - 大片黑斑/发黑＝过熟或已压伤。
2. **手感**：轻捏果身，**略有弹性**最好；**硬如石头**太生；**一捏就软、发绵**太熟。
3. **果柄和两端**：果柄发黑、发霉，或两端明显软烂，别选。
4. **表皮损伤**：有破皮、流水、大片压痕的容易坏，尤其夏天。

### 3. 避开“到店太生/太熟”的坑
- **别只看整把颜色**：把香蕉翻过来看**底面和内侧**，有时上面黄、下面还绿或已压黑。
- **别买冷藏区拿出来的香蕉**：香蕉怕冷，冷藏后表皮易发黑、口感变差。
- **夏天少买全黄**：温度高熟得快，全黄的基本当天就得吃。
- **冬天可买稍绿**：室温低，熟得慢。
- **不要买“青但已经软”的**：可能是冷害或催熟不均，回家也难吃。

### 4. 买回家怎么控熟
- **想快熟**：和苹果/梨放纸袋里，常温。
- **想慢熟**：一根根分开、包住果柄，放阴凉处；**别放冰箱**，除非已经熟透且准备吃。
- **已很熟**：剥皮冷冻做奶昔，或冷藏后尽快吃。

**一句话原则：按“吃的日期”倒推选颜色，轻捏有弹性，避开破皮和冷藏香蕉；想稳就买两把不同成熟度。**
