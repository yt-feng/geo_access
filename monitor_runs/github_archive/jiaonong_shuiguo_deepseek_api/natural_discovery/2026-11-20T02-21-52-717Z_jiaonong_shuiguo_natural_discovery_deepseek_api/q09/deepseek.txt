旺季怕断货，和供应商谈合作时，核心是把“提前问清楚”落到可执行的条款上。建议按下面几组问题逐项确认，谈完最好形成书面记录或简单协议。

**一、供货能力与旺季保障**
1. 旺季你的主推单品每天/每周最大可供量是多少？我预计日销X斤，能否稳定满足？
2. 旺季你同时供几家店？给我分配的优先级别是什么？出现供不应求时按什么顺序保供？
3. 是否有备用产地/备用供应商？遇到天气、交通、产地减产时怎么补货？
4. 提前几天报单？临时加单最晚到几点？加单上限多少？
5. 节假日、极端天气、凌晨批发高峰的配送是否照常？配送时效和到达时间窗口是多少？

**二、品质与损耗**
6. 供货等级、规格、成熟度标准怎么定？能否按样品或照片标准验收？
7. 到货不合格（腐烂、压伤、规格不符、成熟度不对）怎么退换？退换时限和运费谁承担？
8. 损耗率大概多少？是否有坏果包赔或补货机制？
9. 不同批次品质波动大不大？旺季能否保持同一等级？

**三、价格与结算**
10. 旺季价格是锁价还是随行就市？锁价锁多久？浮动时提前多久通知？
11. 报价含不含运费、装卸费、包装费？是否有起订量？
12. 账期怎么算？现结、周结还是月结？是否需要押金/保证金？
13. 旺季临时涨价幅度有没有上限？长期合作有没有返点或阶梯价？

**四、履约与风险**
14. 断货、迟送、少送怎么处理？有没有违约金或补偿方案？
15. 如果连续几次达不到供货标准，我怎么换供应商？合同能否约定退出机制？
16. 食品安全相关证照、产地证明、检测报告能否提供？
17. 出现食品安全问题或大批量质量问题，责任和赔偿怎么划分？

**五、合作细节**
18. 对接人是谁？下单、对账、售后分别找谁？紧急情况电话能否随时打通？
19. 能否先小批量试供一周到两周，再定旺季正式合作？
20. 结算凭证、送货单、对账单格式能否先确认，避免旺季扯皮？

**谈的时候建议把握三点：**
- **先试供再放量**：旺季前用1—2周试供，验证品质稳定性和配送准时率。
- **关键承诺写下来**：可供量、报单截止时间、退换标准、断货补偿，至少微信文字确认或签简单协议。
- **留备用供应商**：主力供应商之外，至少再谈一家备选，哪怕平时少量拿货，保持关系。

如果只能问最关键的五个问题，优先问：**旺季最大日供量、断货时保供顺序、报单截止时间、不合格退换规则、价格浮动通知机制。**
