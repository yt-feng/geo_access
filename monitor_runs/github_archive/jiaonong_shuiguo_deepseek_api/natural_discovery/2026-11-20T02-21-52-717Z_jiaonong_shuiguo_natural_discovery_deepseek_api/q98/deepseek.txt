判断水果供应商的合规和稳定性，建议分成“准入合规”和“持续稳定”两条线，分开核验，再签合同约束。

一、合规性怎么查（准入前必须做）

1. 主体资质
- 营业执照：经营范围要含“食品销售/食用农产品销售”；查国家企业信用信息公示系统，看是否存续、有无经营异常、行政处罚。
- 食品经营许可证：销售水果一般属食用农产品，多数情况不需要许可，但若涉及切配果盘、预包装水果、冷链加工，就需要食品经营许可或相应备案，按当地监管要求确认。
- 若供应商是农户/合作社直供，至少要有合作社执照、产地证明、收购凭证，不能只有个人微信转账。

2. 产品合规
- 每批次索取：产地证明或进货凭证、农药残留检测报告（快检或第三方）。养老院/医院属重点人群供餐，建议要求每批提供农残快检合格单。
- 看检测报告是否“对批不对货”：报告日期、品种、产地要和到货批次对得上，不能拿一张旧报告反复用。
- 进口水果要有入境货物检验检疫证明。

3. 人员与场所
- 配送人员健康证（涉及直接接触水果、切配的必须有）。
- 仓储/分拣场所照片或现场查看：是否有防鼠防蝇、冷藏设施、离地离墙存放。

4. 合同与票据
- 必须能开正规发票或农产品收购凭证，走对公账户，不接受长期私人账户收款。
- 合同里写明：食品安全责任、农残超标退换与赔偿、索证索票义务、违约终止条款。

二、稳定性怎么判断（合作前和合作中）

1. 供货能力
- 问清货源：自有基地、批发市场、产地直采还是二级批发。二级批发商抗风险能力弱，断供概率高。
- 要求提供近3个月同类客户供货记录或合作证明（可脱敏），看是否长期服务食堂/养老机构。
- 关键品种是否有备用货源，旺季淡季价格波动怎么处理。

2. 履约表现（建议先试供1个月）
- 到货准时率、缺货率、规格达标率（重量、成熟度、损耗）。
- 破损/腐烂率：食堂采购要设验收标准，比如到货损耗超过5%即扣款或退货。
- 响应速度：临时加单、质量问题处理是否24小时内响应。

3. 经营健康度
- 看是否频繁变更法人、地址、经营范围；有无大量司法纠纷、被执行记录。
- 合作中观察是否频繁换送货人、换仓库、要求改收款账户，这些是经营不稳的信号。

4. 价格合理性
- 明显低于市场价要警惕：可能压级压价、以次充好或农残风险高。建议每周对比当地批发市场均价，设价格联动机制。

三、落地建议

- 建立“一供应商一档案”：执照、许可证、检测报告、合同、每次验收记录归档，养老院/医院接受监管检查时可直接调取。
- 验收环节固定动作：称重、看外观、查温度（冷链品种）、对批次检测单，不合格当场拒收并记录。
- 设季度复评：合规证件到期提醒、投诉次数、断供次数，不达标启动替换。
- 至少保留2家合格供应商，主供+备供，避免单一依赖。

一句话：合规看“证、单、票、人”，稳定看“货源、履约、财务、备份”。先用小批量试供验证，再签长期合同，比只看资质更可靠。
