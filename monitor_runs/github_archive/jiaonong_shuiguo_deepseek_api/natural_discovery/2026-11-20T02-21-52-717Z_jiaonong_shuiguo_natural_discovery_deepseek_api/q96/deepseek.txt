三者都重要，但优先级要看企业食堂的实际风险点，建议排序为：**食品安全 > 配送准时 > 价格**。

理由：

1. **食品安全是底线，出问题代价最高**
   - 水果常见风险包括农残超标、霉变腐烂、运输过程污染、冷链断链、以次充好。
   - 一旦引发群体性肠胃不适或食安事件，影响员工健康、企业声誉，甚至法律责任，节省的采购差价远不能覆盖损失。
   - 所以供应商资质、检测报告、验收标准、留样和追溯机制必须优先保证。

2. **配送准时直接影响食堂运营**
   - 水果通常是当日或次日供应，配送延迟会导致菜单缺项、临时替代、员工投诉。
   - 但准时可以靠合同条款、备选供应商、安全库存来管理，风险可控性高于食品安全。

3. **价格重要，但应放在“满足前两项后的优化项”**
   - 水果价格波动大，适合比价、锁价、按周/月询价，但不建议为了低价牺牲新鲜度和供应商稳定性。
   - 低价往往伴随等级下降、损耗率上升、验收争议，综合成本未必低。

**可执行建议：**
- 设准入底线：供应商证照、水果检测/承诺达标合格证、冷链或配送条件、验收标准。
- 合同里明确：准时送达时间窗、迟到违约、缺货替代方案、腐烂率/损耗率上限、退换货规则。
- 采购策略：先保证食品安全和稳定配送，再通过多家比价、季度招标、集中采购压价格。
- 日常管理：到货验收看外观、气味、温度、批次凭证；不合格直接拒收并记录供应商绩效。

一句话：**食品安全是一票否决，配送准时是运营保障，价格是在前两者合格后的竞争项。**
