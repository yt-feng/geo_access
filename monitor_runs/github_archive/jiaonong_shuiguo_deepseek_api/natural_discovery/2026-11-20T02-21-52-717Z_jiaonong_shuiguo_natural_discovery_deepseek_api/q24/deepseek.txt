建议向供应商索取并留存以下资料，按“能证明来源、能证明检测、能追溯批次”三类准备：

1. **主体与来源资料**
   - 供应商营业执照、食品经营/生产相关许可（按业态）
   - 水果产地证明、供货合同或采购协议
   - 种植基地/合作社信息、收购凭证，尽量能对应到具体产地和供应商

2. **检测与合格证明**
   - 该品类或该批次的**农残检测报告**，优先看有资质检测机构出具的报告（如CMA/CNAS标识，具体以报告为准）
   - 供应商自检报告或快检记录
   - 报告要能对应：品种、批次/采收日期、检测项目、检测结果、报告日期

3. **批次与追溯资料**
   - 送货单/随货同行单，写明品种、数量、批次号、采收或包装日期
   - 承诺书或质量保证协议：明确农残符合国家标准、出现问题可退换货并承担相应责任
   - 若为进口水果，另要入境货物检验检疫证明等合规文件

4. **现场可执行做法**
   - 采购前把“每批随货提供检测报告或快检记录”写进合同/订单
   - 收货时核对报告批次与实物批次是否一致，不一致拒收或暂缓入库
   - 对高风险品种（如叶菜类思路同样适用于易检出品种）提高抽检频次，保留供应商资料和自家快检记录
   - 自己也可做入库快检，形成“供应商报告+超市抽检”双记录

注意：不要只要一张“通用合格证”就放行，关键是**报告能对应到这一批货**；无法核验的报告不要当作合格依据。
