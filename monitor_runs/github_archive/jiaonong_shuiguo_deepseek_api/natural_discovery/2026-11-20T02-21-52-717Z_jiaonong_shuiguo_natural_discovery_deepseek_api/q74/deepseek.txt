做餐饮客户，菠萝和香蕉的核心是**稳定、好加工、少损耗**，规格要围绕出杯/出餐标准化来定，不要按零售果摊思路备货。

## 菠萝：餐饮客户重点看“出肉率”和“加工省事”

建议准备这几档：

1. **鲜切菠萝块/菠萝丁（主力）**
   - 规格：2–3 cm 方块或1 cm 小丁
   - 用途：炒饭、咕噜肉、披萨、沙拉、饮品店
   - 要求：成熟度7–8成，酸甜稳定，不带黑心，真空或保鲜盒装，按2.5 kg/5 kg/10 kg分装
   - 这是最容易起量的餐饮规格。

2. **整只鲜菠萝（中果/大果）**
   - 规格：单果1.2–1.5 kg 为主，另配1.5–2 kg大果
   - 用途：后厨现切、烧烤、饮品店现榨
   - 要求：同批次成熟度一致，不要大小混杂；餐饮后厨不爱处理太小果。

3. **菠萝果肉/菠萝蓉（冷冻或冷藏）**
   - 规格：1 kg/袋、5 kg/袋
   - 用途：饮品店、烘焙、酱汁、糖水
   - 要求：无添加或轻糖，标注固形物含量；适合连锁客户锁配方。

4. **小菠萝/香水菠萝（可选差异化）**
   - 规格：单果300–500 g
   - 用途：泰餐、烧烤、果切拼盘
   - 不作为主力，但可做特色餐饮客户。

**菠萝避坑：** 餐饮客户最怕黑心、成熟度不齐、切后出水。批发档口要能承诺“同一批次成熟度一致”，并给样品试菜。

## 香蕉：餐饮客户分“直接入口”和“加工用”两类

1. **加工用香蕉（主力）**
   - 规格：青转黄、7–8成熟，单根120–150 g，整箱按13–15 kg
   - 用途：香蕉奶昔、烘焙、炸香蕉、甜品店
   - 要求：可带轻微青肩，耐运输；不要全黄软果，后厨无法周转。

2. **即食/果切用香蕉**
   - 规格：单根150–180 g，8–9成熟，无碰伤
   - 用途：果切、酒店早餐、奶茶店装饰
   - 要求：表皮干净、无黑斑大面积、同箱成熟度一致；最好按把分装。

3. **小香蕉/粉蕉（特色餐饮）**
   - 规格：单根80–120 g
   - 用途：泰餐、甜品、儿童餐
   - 可作为补充SKU，不建议主力备货。

4. **冷冻香蕉果肉/香蕉泥（可选）**
   - 规格：1 kg/袋、5 kg/袋
   - 用途：饮品连锁、烘焙
   - 适合有稳定大客户的档口做锁客产品。

**香蕉避坑：** 餐饮客户最怕今天黄明天黑、批量催熟不匀。建议按“7成熟加工用”和“8.5成熟即食用”分开报价、分开存放。

## 给档口的实操建议

- **首批主推组合：** 鲜切菠萝块2.5 kg/5 kg装 + 中果整菠萝1.2–1.5 kg + 7–8成熟加工香蕉13–15 kg整箱。
- **报价方式：** 不要只报斤价，餐饮客户更接受“按箱/按袋/按净肉公斤”报价，并明确出肉率或损耗。
- **样品策略：** 每个餐饮客户先送1 kg鲜切菠萝块+1把加工香蕉试菜，比口头推销有效。
- **客户分层：** 饮品店推菠萝蓉/冷冻香蕉泥；中餐馆推鲜切菠萝丁；泰餐/烧烤推小菠萝和粉蕉；酒店早餐推即食香蕉和果切菠萝。

一句话：**菠萝主推鲜切块和中等整果，香蕉主推7–8成熟加工用整箱，另配即食档；先按餐饮用途分规格，不要按水果摊大小分。**
