大型超市水果供应商要同时过“食品安全合规关”和“冷链物流履约关”。可分下面几类能力来准备和判断。

一、食品安全能力（硬门槛）

1. 主体与许可合规
- 营业执照、食品经营许可证（或食品生产/流通相关许可，按当地监管口径），经营范围覆盖水果销售/初加工/分装。
- 若涉及清洗、切分、鲜切果、预包装，需按“即食鲜切果蔬”或相应品类管理，具备更严格的许可与车间条件。
- 进口水果需有入境货物检验检疫证明、报关单等；国产水果需有产地证明或承诺达标合格证。

2. 农残与污染物控制
- 建立供应商准入和产地审核：果园/合作社备案、农业投入品使用记录、采摘安全间隔期。
- 批批或按风险抽检农残，重点覆盖高频检出农药；有快速检测室或委托第三方检测协议。
- 重金属、真菌毒素等按品类风险监测；检测报告可追溯到批次。

3. 追溯与召回
- 一批一码或批次台账：产地、采摘/收购日期、检测、入库、分拣、出库、配送门店全链路可追。
- 具备召回预案和演练记录，能在约定时限内锁定并下架问题批次。

4. 仓储与分拣卫生
- 仓库防鼠防虫防鸟、温湿度监控、离墙离地、先进先出。
- 分拣区清洁消毒制度、人员健康证与晨检、工器具清洗消毒、破损果隔离。
- 鲜切或清洗果需有洁净区、消毒设施、水质检测、微生物监控。

5. 包装与标识
- 包装材料食品级，有合格证明；预包装标识符合法规（品名、产地、生产者/供应商、日期、贮存条件等）。
- 避免过度包装和交叉污染，周转筐定期清洗消毒。

6. 体系与记录
- 建议具备ISO22000/HACCP或等效体系；至少要有进货查验、出厂检验、不合格品处置、投诉处理、培训、虫害控制等记录。
- 食品安全员配备和“日管控、周排查、月调度”类制度按当地要求落实。

二、物流与冷链能力

1. 冷链覆盖
- 根据品类配置：叶菜/浆果/鲜切果通常0–4℃或按品类工艺；热带水果如香蕉、芒果等需防冷害，分区温控。
- 冷藏车、冷库、门店交接全程温度记录，异常报警与处置记录可查。

2. 运输与配送
- 自有或稳定合同运力，车辆食品级、清洁消毒、不得与有毒有害物混装。
- 配送时效匹配超市档期，具备夜间配送、预约卸货、门店排队应对能力。
- 周转筐/托盘循环管理，防挤压、防日晒雨淋。

3. 仓储分拣与库存管理
- WMS/ERP批次管理、效期管理、先进先出；损耗率可控并有数据。
- 退货、破损、临期品隔离处置流程。

4. 应急与履约保障
- 缺货替代方案、产区切换、天气/交通中断预案；节假日和大促保供能力。
- 食品安全事件和温度失控的应急响应，包括隔离、通报、补货。

三、超市通常如何审核（可用来自检）
- 资质文件审核 + 现场审核（仓库/车间/冷链）+ 样品检测 + 试配送考核。
- 重点看：检测报告与批次对应、温度记录连续性、追溯能否在几小时内完成、召回演练、虫害与人员卫生、配送准时率和损耗率。

四、给供应商的落地建议
- 先做“资质清单+批次追溯表+检测计划+温度监控方案”四件套。
- 鲜切业务单独建洁净车间和微生物监控，不要与毛果混线。
- 与超市确认品类温控标准、验收标准、召回时限、赔付条款，写进合同附件。
- 保留至少覆盖一个召回周期的记录，接受飞行检查。

简言之：食品安全上要“资质全、检测准、追溯清、现场净、记录真”；物流上要“温控不断链、批次不混、时效稳、应急有预案”。这两条都过硬，才具备大型超市水果供应商的基本资格。
