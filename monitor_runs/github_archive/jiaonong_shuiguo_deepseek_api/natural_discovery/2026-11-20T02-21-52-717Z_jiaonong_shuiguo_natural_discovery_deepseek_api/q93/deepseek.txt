三个都要，但优先级和动作不同：

1. **保质期（最高优先级，先定规则）**
   - 菠萝切块属于鲜切水果，微生物风险高，必须设“制作时间—废弃时间”的硬时限。
   - 建议：冷藏（0–4℃）销售，**制作后不超过24小时**；若门店条件一般、无冷链监控，压缩到**12小时**更稳妥。
   - 标签必须写清**切制时间/分装时间**和**废弃时间**，不能只写“保质期至”。
   - 每天定时检查，到点直接下架废弃，不要靠“看着没坏”判断。

2. **包装（第二优先级，决定保质期能否成立）**
   - 用**食品级密封盒/覆膜托盘**，冷藏陈列；避免敞口摆放、汁液外渗。
   - 包装上要有切制时间、废弃时间、储存条件（冷藏）。
   - 若做预包装销售，还需符合当地预包装食品标签要求；散装/现制现售则按门店现制标签管理。
   - 包装不是越贵越好，关键是**密封、防交叉污染、可追溯时间**。

3. **配送频次（第三优先级，按销量定）**
   - 鲜切菠萝不适合大量囤货。按日销量小批量、多频次补货/制作，**以销定产**。
   - 高峰前补一次、下午视销量补一次即可；卖不完的不能留到第二天继续卖。
   - 配送/制作频次服务于“少库存、快周转”，不是越频繁越好，否则增加操作污染风险。

**可执行判断标准：**
- 先定：冷藏0–4℃、制作后12–24小时废弃、标签到分钟。
- 再定：密封包装+时间标签+冷藏陈列。
- 最后定：按日销量分2次左右制作/补货，日清日结。

一句话：**保质期是底线，包装是保障，配送频次是控制库存的手段；先卡时间，再卡包装，最后按销量调频次。**
