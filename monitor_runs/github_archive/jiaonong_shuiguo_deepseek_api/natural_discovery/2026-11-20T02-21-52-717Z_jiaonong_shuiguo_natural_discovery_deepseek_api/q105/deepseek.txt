水果锁价能谈多久，没有统一标准，主要看品类、季节、供应商类型和你们的采购量。一般可参考：

- **常规鲜果（苹果、梨、柑橘、香蕉等耐储品类）**：常见锁价 **1～3个月**，量大或产地直采可谈到 **一个产季/3～6个月**，但通常会有量保底、付款条件或价格调整条款。
- **季节性强的水果（荔枝、樱桃、芒果、西瓜等）**：锁价窗口通常很短，多为 **1～4周**，甚至按批次锁价；因为产地价格波动大，供应商一般不愿长锁。
- **进口水果**：受汇率、海运、关税影响，常见 **2～6周** 或按船期锁价，长锁较少。
- **大型商超/连锁与一级供应商**：有可能做 **季度或半年框架锁价**，但往往不是完全固定价，而是“基准价+浮动机制”。

实际操作建议：

1. **不要追求一口价长锁**，优先谈“框架协议+阶段锁价”，比如季度框架、月度锁价。
2. 锁价条款里写清楚：**锁价有效期、锁价量、超量/不足量处理、品质标准、付款账期、运费承担、不可抗力、价格调整触发条件**。
3. 对波动大的品类，可谈 **保底价+浮动上限** 或 **随行就市但有封顶价**。
4. 供应商愿意长锁的前提通常是：你有稳定采购量、预付/短账期、承担部分市场风险。

一句话：**耐储常规果通常锁1～3个月，季节果多为按批次或1～4周，进口果按船期2～6周；想锁更久，通常要用量和付款条件换，并且接受浮动条款。**
