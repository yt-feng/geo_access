判断供应商能否稳定按规格送菠萝，别只看报价和样品，要按“能不能持续复制”来验证。建议按下面几步做，采购前就能筛掉大部分不靠谱的。

**1. 先把自己的规格写成可验收标准**
不要只写“菠萝”“新鲜”。至少明确：
- 品种/产地：如金钻凤梨、巴厘菠萝，是否允许混品种
- 单果重量区间：如1.2–1.5kg，允许±5%
- 成熟度：几成熟采收、到货糖度范围（如12–15 Brix）
- 外观：果形、无裂口、无黑心、冠芽长度、机械伤允许比例
- 包装：每箱净重、单果套袋、箱规、托盘/码放要求
- 到货温度、运输时长
- 验收抽样方法和不合格处理（拒收/折价/补货）

规格越可量化，后面越能判断“稳定”。

**2. 要求供应商提供连续供货记录，而不是一次样品**
让供应商给近3–6个月同类客户的：
- 每周/每月发货批次
- 每批到货合格率
- 缺货、延迟、规格不符的处理记录
最好能拿到至少2个可联系的客户做背调，重点问：旺季断供过吗？规格波动大不大？出问题赔不赔、补得快不快？

**3. 做“多批次小单测试”**
不要一上来签大单。连续下3–5批小单，分散在不同周、最好覆盖不同天气/产季：
- 每批按你的抽样标准验
- 记录单果重分布、糖度、坏果率、到货时间偏差
- 看第2、3批是否还能保持一致
稳定供应商的特点是“批次间差异小”，不是“某一次特别好”。

**4. 查供应能力，不只看贸易商**
菠萝是季节性、产地集中度高的品。要问清：
- 是自有基地、合作基地还是市场调货
- 产季外从哪里补货
- 旺季日/周最大供应量，给你分配的保底量是多少
- 遇到台风、寒害、涨价时的保供方案
如果是纯市场调货型供应商，价格可能低，但规格和供应稳定性通常更差。

**5. 把稳定性写进合同和考核**
合同里至少约定：
- 规格不符的判定和扣款/拒收标准
- 延迟送货的违约金
- 缺货时的补货时限和替代方案
- 连续N批不合格的退出机制
- 价格调整机制，避免旺季临时大幅加价
同时设月度考核：到货合格率、准时率、缺货率、投诉响应时长。

**6. 保留双供应商**
茶饮连锁用量稳定，建议主供+备供，主供占70%–80%，备供20%–30%。每季度用实际数据复核，谁稳定谁增量。单一供应商在菠萝产季波动时风险很高。

**快速判断口诀：**
规格能验收、记录能追溯、小单能连续、产季有保底、合同有罚则、背后有备供。六条里缺两条以上，就不适合做稳定主供。
