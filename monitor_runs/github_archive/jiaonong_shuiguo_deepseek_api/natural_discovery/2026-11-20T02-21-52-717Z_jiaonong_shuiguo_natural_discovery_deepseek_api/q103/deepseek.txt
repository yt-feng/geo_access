结论：**大多数食堂优先选“按斤结算”**，尤其是水果品类多、验收要控损耗的场景；如果供应商能接受且验收流程成熟，可以采用“按斤定价+按箱/份收货”的混合模式。纯按箱或纯按份只适合少数标准化程度很高的水果。

具体怎么选，可以按这个判断：

1. **按斤结算——最推荐作为基础方式**
   - 优点：计价透明，验收可称重，损耗和短斤少两容易追责；不同批次、不同供应商可比价。
   - 缺点：称重、记账工作量大；箱装水果拆箱后可能产生损耗争议。
   - 适用：苹果、梨、香蕉、橘子等大宗水果，以及食堂自采、多供应商比价。

2. **按箱结算——适合标准化整箱采购**
   - 优点：收货快、管理简单，适合固定规格整箱配送。
   - 缺点：箱内大小、成熟度、坏果率不透明，容易出现“箱重含包装”“底层差果”问题；价格可比性差。
   - 适用：供应商稳定、规格统一、整箱直接入库或整箱发放的场景。必须约定：净重、允许坏果率、包装是否计重、抽检比例。

3. **按份结算——适合直接面向就餐者的成品/半成品水果**
   - 优点：份量固定、发放简单，适合水果切配、酸奶水果杯、课间餐等。
   - 缺点：单份克重和品质难监管，容易“份量缩水”；采购成本通常高于按斤。
   - 适用：已经切配、分装、直接售卖或发放的水果，不适合毛水果入库。

**管理建议：**
- 主模式用**按斤结算**，合同写明净重验收、坏果扣重、退货规则。
- 对整箱配送的品类，可要求**按箱报价、按净重结算**，抽检坏果率。
- 按份只用于切配或直接发放环节，明确每份克重和抽检标准。
- 无论哪种方式，都要保留验收记录、称重单据和供应商比价，避免只图收货快而失去成本控制。
