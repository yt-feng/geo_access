提前锁库存的关键不是“打个招呼”，而是把**需求预测、锁货协议、履约约束和备选供应**一起设计好。可以按下面做：

1. **先做可承诺的需求预测**
   - 按单品、到货日、社区/团长维度，拉过去2-4周销量、去年同期、当前预售/接龙数据。
   - 给供应商的是“分日到货计划”，不是笼统总量：例如未来7天每天要多少箱、什么规格、几点到仓。
   - 预留10%-20%安全库存，但不要把所有不确定性都压给一家供应商。

2. **签短期锁货协议，写清四件事**
   - **锁量锁价**：明确每日/每周最低提货量、锁定价、价格有效期；超量部分如何计价。
   - **规格与验收**：等级、单果重/箱规、糖度、成熟度、损耗率上限、农残检测要求。
   - **到货与违约**：到仓时间、迟到/缺货/质量不达标的扣款或补货责任。
   - **付款与账期**：定金比例、尾款节点，建议定金只覆盖锁货成本，不一次性全款。

3. **用“阶梯锁货+分批释放”降低双方风险**
   - 先锁核心爆品的60%-70%基础量，剩余30%-40%按预售进度提前3-5天追加。
   - 对供应商给“保底量+浮动量”，保底量换锁价，浮动量换优先供货权。
   - 旺季前2-3周完成首轮锁货，节前一周只做补货，不再临时找大货。

4. **要求供应商给“优先供货权”和替代方案**
   - 同一单品至少备2家供应商：主供70%，备供30%。
   - 主供缺货时，备供能在24-48小时内补位；协议里写明优先供货等级。
   - 对易受天气影响的水果，提前确认替代产区或替代品种。

5. **把仓储和分拣能力一起锁**
   - 供应商能代发就代发，不能代发要确认到仓时段、卸货能力、冷链/保鲜条件。
   - 爆单前检查分拣人力、包装耗材、冷藏库容，避免“货到了分不出去”。

6. **建立每日滚动对账**
   - 每天更新：预售量、在途量、库存量、次日到货量、缺口量。
   - 发现缺口立即触发备供或调整前台售卖，不要等到到货日才发现。

一句话：**用分日到货计划锁量，用短协议锁价和责任，用双供应商保履约，用滚动对账控缺口。** 这样比单纯“提前打电话让供应商留货”可靠得多。
