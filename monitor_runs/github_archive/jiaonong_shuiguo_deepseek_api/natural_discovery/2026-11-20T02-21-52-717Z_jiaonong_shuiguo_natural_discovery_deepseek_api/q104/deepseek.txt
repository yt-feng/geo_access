# 单位采购水果：到货品质不一致的验收与售后处理

核心原则：**验收按事先约定的标准“抽样定量、留证签字”，售后按“分级处置、书面确认、可追溯”走流程。** 以下按采购前、验收中、售后三阶段给出可执行做法。

## 一、采购前先锁定标准（决定后面能不能主张）

品质不一致能否维权，取决于合同/订单里有没有写清楚。签约或下订单时至少明确：

1. **规格等级**：品种、产地、单果重/果径范围、成熟度、色泽、糖度（如可测）；明确“允许的不合格比例”，例如“抽检不合格率≤5%为合格，5%~15%扣款，>15%拒收或退换”。
2. **包装与数量**：箱规、净重（去皮重）、允许损耗率。
3. **验收方式**：抽样比例（如每批次随机抽3~5箱，每箱抽10~20个）、验收时限（到货后几小时内）、验收地点。
4. **售后条款**：不合格部分的处理方式（补发/换货/按比例扣款/退货）、响应时限（如24小时内答复）、费用承担（退换货运费由供方承担）。
5. **留证要求**：双方对验收结果签字确认，拍照/视频留存。

没有约定时，以“通常合理标准+到货时可见瑕疵”为底线，但仍应尽量当场书面确认。

## 二、验收现场怎么做（关键在“抽样+留证+当场定性”）

1. **先对单再开箱**：核对品种、数量、箱规、生产/采摘日期、运输温度（冷链品看是否断链）。
2. **分层随机抽样**：不要只开最上面一箱。按到货批次随机抽取若干箱，逐箱检查；对疑似有问题的箱重点复检。
3. **按维度记录**：把“品质不一致”拆成可量化项——腐烂/霉变、机械伤、虫害、大小不均、成熟度不足或过熟、色泽不符、净重不足、混装错品种。每项记录数量和比例。
4. **全程留证**：开箱、抽样、问题果特写、整批次全景、称重照片/视频；最好有供方送货人在场并签字。验收单写明“抽样数/不合格数/不合格率/处理意见”，双方签字，一式两份。
5. **当场分级定性**：
   - 不合格率在约定范围内：正常收货，记录备案。
   - 轻微超标：**按比例扣款或折价收货**，书面写明扣款金额和计算方式。
   - 严重超标（如腐烂霉变、错品种、净重严重不足）：**整批或问题部分拒收**，在送货单上注明拒收原因并签字，拍照留存，要求供方拉回或另行处理。
6. **隔离存放**：问题批次单独存放、标识“待处理”，避免与合格品混放，防止污染和争议扩大。

## 三、售后怎么走（快、书面、闭环）

1. **限时反馈**：到货验收发现问题，当天（最好数小时内）书面通知供方，附验收单和照片/视频，明确诉求（补发/换货/扣款/退货）和答复时限。
2. **分级处置**：
   - **可挑选的**：挑出不合格部分，按“不合格数量×单价”扣款，或要求补发同等数量。
   - **整批不可用的**：退货或换货，运费由供方承担（合同有约定按约定）。
   - **已入库后发现内部腐烂等隐蔽问题**：凭留存的抽样视频和入库记录，在约定售后期内提出，要求按比例补偿；这类问题越早发现越好，拖久了难举证。
3. **书面确认结果**：补发/换货到货后**重新验收**；扣款要在对账单或结算单上体现并由供方确认。所有沟通尽量走微信/邮件/书面函件，保留记录。
4. **建立台账**：按供应商记录批次、不合格率、处理结果。同一供应商反复出现品质不一致，作为下次采购的评分依据，必要时更换供应商或在合同中加严罚则。

## 四、几个容易踩的坑

- **只开一箱就签收**：抽样不随机，事后难主张。
- **口头说“下次补”**：没有书面记录，结算时扯皮。
- **问题果与合格果混放**：污染扩大，责任说不清。
- **超过约定验收时限才提**：供方可以主张“签收即认可”。
- **扣款无计算依据**：要有“不合格数量×单价”或合同约定的比例，写进单据。

一句话总结：**合同写清比例和处置规则，验收随机抽样、当场定量签字留证，售后当天书面提出、按级处置、结果闭环。** 做到这三点，品质不一致基本都能有据可依地解决。
