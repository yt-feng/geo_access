水果礼盒想好卖，关键不是“把四种都塞进去”，而是 **按价格带和送礼场景做2—3个固定款式**，让顾客一眼能选。苹果、橙子、香蕉、菠萝这四样都耐放、辨识度高，适合做组合，但香蕉和菠萝体积/气味会拖后腿，建议这样搭配：

**1）主推款：88—128元“平安橙意”礼盒**
- 苹果6个 + 橙子6个 + 香蕉1小把（约500g）
- 苹果选红富士/花牛，橙子选脐橙，香蕉选短把精品蕉
- 卖点：苹果=平安，橙子=心想事成，适合探亲、看病人、日常送礼
- 香蕉不要整串大把放，容易压伤、显廉价，用独立小把或蕉托固定

**2）走量款：68—88元“日常水果组合”**
- 苹果4个 + 橙子4个 + 香蕉1小把
- 不放菠萝，控制成本和重量，适合社区团购、员工福利、自提
- 用透明开窗盒或牛皮纸盒，显得干净实惠

**3）高客单款：138—168元“凤梨纳福”礼盒**
- 苹果6个 + 橙子4个 + 菠萝1个（选小果/金钻凤梨）+ 香蕉1小把
- 菠萝寓意“旺来”，适合开业、乔迁、节日送礼
- 菠萝必须单独用泡沫网+底托固定，避免刺破其他水果；盒内加隔板

**不建议做的搭配：**
- 四种水果等量混装：成本高、重量大、视觉乱，香蕉易压坏，菠萝气味影响其他水果。
- 香蕉和菠萝放太多：香蕉不耐压、成熟快；菠萝带刺且气味重，容易让礼盒“掉档次”。

**实操建议：**
- 固定2个主款+1个高端款，不要现场随意拼，降低损耗和决策成本。
- 礼盒内垫纸丝或拉菲草，苹果橙子擦干、贴标签；香蕉最后放，避免压伤。
- 标价签写清“净重/个数/寓意”，比如“6果+6橙+1蕉，约3.5kg”。
- 先小批量试卖：每款先做10—15盒，记录3天内售罄率和损耗，再调整配比。
- 如果门店客流以社区家庭为主，68—88元走量款为主；如果靠近医院/写字楼/礼品店，主推88—128元款。
