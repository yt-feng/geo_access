问品牌方时，重点不是泛泛问“有没有区域保护”，而是把**授权边界、保护机制、违约认定、处罚与退出**问成可写进合同的条件。可以按下面顺序问，并要求对方给书面答复或合同条款。

**1. 授权与区域保护**
- 我这个代理/经销权是**独家、排他还是普通授权**？保护范围按省/市/区县还是按渠道（商超、水果店、批发市场、电商）划分？
- 保护期内，品牌方自己、其他代理商、直营电商、社区团购、直播渠道能不能在我区域内销售？线上销售算不算跨区？
- 授权期限多久？续约条件是什么？完不成任务是否自动降级或取消独家？
- 区域内出现第二家同品牌授权商，我有什么救济？是品牌方负责清退，还是只协调？

**2. 串货认定与处理**
- 什么情况算串货：跨区域批发、线上低价销售、下游客户跨区倒货、团购/直播发货，分别怎么认定？
- 串货由谁举证？品牌方是否提供批次码、追溯码、物流流向查询？我能否申请查货？
- 发现串货后，品牌方处理时限是多久？处理措施包括警告、罚款、断货、取消授权中的哪些？对我有没有补偿？
- 如果串货来自品牌方直营线上或大客户，是否同样处理？这条一定要问，否则保护只约束小代理。

**3. 价格与渠道秩序**
- 品牌方是否设指导价/最低限价？对乱价、低价倾销怎么处理？
- 电商、直播、社区团购是否单独授权？这些渠道的发货区域是否受限制？
- 促销活动是否提前通知区域代理？品牌方自促是否冲击我的库存和价格？

**4. 任务、库存与风险**
- 年度/季度任务量、考核口径是按回款、进货量还是实际动销？完不成怎么处理？
- 是否压货？临期、滞销、质量问题的退换货比例和时限是什么？
- 区域保护是否与任务挂钩？任务未完成时，品牌方能否在我区域内再开客户？

**5. 合同与证据**
- 要求把区域范围、独家性、线上渠道限制、串货认定标准、处理时限、违约责任、退出机制写进合同，不接受只口头承诺。
- 问清楚现有区域内已有多少授权客户、线上店铺、直供大客户，并要求披露。
- 保留聊天记录、报价单、授权书、发货批次信息，后续维权用。

**最该盯住的四个问题：**
1. 保护是独家还是普通授权，范围写到什么颗粒度；
2. 品牌方自营电商和直播是否受区域限制；
3. 串货谁认定、谁举证、多久处理、怎么赔；
4. 任务完不成时，区域保护是否失效。

如果对方对“线上渠道是否受区域限制”和“品牌方直营是否同样受约束”含糊其辞，基本说明区域保护力度有限，要谨慎签约。
