# 水果到货不合格，怎样约定补货才不影响营业

核心思路：**把“验收标准、补货时限、断货兜底”三件事写进采购合同或供货单，而不是靠口头沟通。** 具体可分四层约定：

## 一、先定“不合格”的判定标准（避免扯皮）

- 按品类列明验收指标：外观（腐烂、碰伤、虫眼比例）、成熟度（如芒果7-8成熟到货）、规格（单果克重、果径）、糖度（可选，用糖度计抽检）、农残检测报告随货。
- 约定**抽检比例和判定规则**：例如每批随机抽10%，不合格率超过5%即整批可拒收；单果腐烂/霉变直接计为不合格。
- 约定**到货时间窗**：要求供应商在门店营业前（如早8:00前）送达，留出验收和应急处理时间。

## 二、约定补货的“时限+方式+责任”

- **补货时限**：不合格部分，供应商须在**X小时内**（建议4-6小时，覆盖当日营业高峰前）补送到店；或约定“当日营业结束前补齐”。
- **补货方式**：明确是“换货”还是“补量”，补货水果的品质标准与首批一致。
- **费用归属**：补货运费、因不合格导致的报废损失由供应商承担；可约定按不合格货值的一定比例（如10%-20%）作为违约补偿。
- **验收留证**：到货当场拍照/录像、填写验收单双方签字，作为补货和扣款依据。

## 三、断货兜底条款（最关键，直接决定营业是否受影响）

- **应急采购授权**：若供应商未在约定时限内补货，门店有权自行就近采购同等品质水果，**差价由供应商承担**（从货款中扣除）。这条能保证营业不中断。
- **备选供应商**：合同里注明“供应商连续2次或月度累计3次未按时补货，门店可终止合作并启用备选供应商”，同时自己维护1-2家备用货源。
- **安全库存约定**：对高频核心水果（如柠檬、芒果、草莓），约定门店保持半天至一天的周转库存，供应商对紧俏品提前备货。

## 四、结算与考核挂钩

- 货款按月结算，**不合格批次暂不付款**，待补货完成验收后结算。
- 设月度考核：准时率、合格率、补货响应速度，达标可给返点或优先排单，不达标扣款或降级。

## 落地建议

1. 把以上内容做成一页《水果供货验收与补货约定》，作为采购合同附件，双方签字。
2. 门店配一个简易验收工具包：电子秤、糖度计（可选）、拍照手机、验收单。
3. 首次合作先小批量试供2周，验证其补货响应能力再放量。

一句话总结：**标准写清、时限卡死、断货可自行采购且差价由对方承担**——这三条到位，补货问题基本不会影响营业。
