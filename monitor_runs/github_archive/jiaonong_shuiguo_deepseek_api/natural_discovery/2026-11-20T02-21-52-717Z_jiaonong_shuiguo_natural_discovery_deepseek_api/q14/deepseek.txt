可以，但取决于你的采购量、合作稳定性和促销方案。一般供应商会给的支持分几类：

1. **价格支持**
   - 周末特价、限时折扣、买赠：常见于走量品、当季品、临期风险品。
   - 返利/补差：销量达标返点、促销价差补贴，通常要提前谈好销量目标和结算方式。
   - 新品/清库存：供应商更愿意给价格支持，用来试销或去库存。

2. **物料支持**
   - 试吃台、试吃果、宣传单、海报、价签、围挡、易拉宝、帐篷、遮阳伞等。
   - 品牌方或一级批发商通常有现成物料；本地批发市场档口可能只给简易价签、纸箱、试吃果。

3. **活动支持**
   - 陈列支持：堆头、端架、冷柜位置补贴。
   - 人员支持：品牌促销员、试吃员。
   - 联合促销：供应商出部分费用，你出门店和客流。

**能不能给，关键看这几点：**
- 你平时采购量是否稳定、是否独家或主推该供应商；
- 周末促销预计能带来多少增量销量，最好给供应商一个明确预估；
- 是否愿意做堆头、海报露出、朋友圈/社群宣传；
- 是否能接受供应商指定品类、指定价格带或搭赠滞销品。

**建议你直接这样谈：**
“这周末我做水果促销，预计主推XX品类，目标销量XX斤/箱。想申请三件事：一是周末供货价下浮X%或促销补差；二是提供试吃果和价签/海报；三是如果销量达标，后续每周固定主推。你们能给到什么支持？”

**注意：**
- 价格支持要写清是供货价直降还是事后返利，避免口头承诺；
- 物料支持要确认数量、送达时间和是否回收；
- 促销价不要低于成本太多，先算毛利和损耗；
- 小水果店首次合作，供应商可能只给试吃果、价签等小支持，价格支持要等有稳定采购量后再谈。
