# 核实水果供应商“全国配送”的实际覆盖能力

“全国配送”这个说法本身没有标准含义，很多供应商指的是“能发快递到大部分城市”，而不是“能保证时效、温控和到货品质”。采购方应把模糊承诺拆成可验证的具体项，建议按以下顺序核实：

## 1. 先问清“覆盖”的定义
直接要求对方书面说明：
- 是**自有冷链网络**覆盖，还是**依赖第三方物流/快递**？
- 哪些省份/城市**不能到**或**加价**？要求给出**明确的不覆盖清单**，而不是“基本都能到”。
- 偏远地区（新疆、西藏、内蒙部分、海南部分岛屿等）是否配送、时效和费用如何。
- 是**门到门**还是到物流点自提。

让对方把这些写进报价单或合同附件，口头承诺不算数。

## 2. 要求提供可核验的配送证据
- 最近 1–3 个月的**真实发货记录**：可脱敏的运单号、目的地城市、签收时间。随机抽几条自己查物流轨迹，看是否真的送达、时效是否匹配。
- 询问其**主要合作物流商**（顺丰冷运、京东冷链、中通冷链、区域冷链专线等），并核对对应物流商在该线路的时效承诺。
- 要求提供**冷链能力证明**：冷库/预冷设施、保温箱或冷藏车、温控记录方式（是否有温度记录仪）。

## 3. 用“小批量试单”做实测
这是最可靠的方式。选 2–3 个你实际要覆盖的**代表性城市**（含一个偏远或二线城市），下小批量试单：
- 记录**下单到签收时长**、是否按承诺时效到达；
- 检查到货**温度、损耗率、品相**；
- 看是否出现“承诺能到、实际转普通快递”的情况。
试单结果比任何资质文件都直接。

## 4. 核查资质与履约能力
- 营业执照经营范围是否含道路货物运输/冷链相关；
- 是否有食品经营许可、冷链运输相关资质；
- 问清**旺季（如节前、产地集中上市期）运力**如何保障，是否有备用物流方案——很多供应商平时能发，旺季就掉链子。

## 5. 合同里写清可追责条款
把“全国配送”落到条款：
- 明确**覆盖城市清单和不覆盖地区**；
- 约定**时效标准**（如 X 小时内送达）和**温控/损耗标准**；
- 约定**违约处理**：延误、变质、超范围发货的责任和赔付方式；
- 保留试单和抽检的权利。

## 判断要点
一句话：**不要接受“全国配送”这种笼统表述，要求对方给出“不覆盖清单 + 运单证据 + 试单实测”三样东西**。三样都能对上，覆盖能力才基本可信；只给口头保证、拿不出运单或拒绝试单的，按“覆盖能力存疑”处理。
