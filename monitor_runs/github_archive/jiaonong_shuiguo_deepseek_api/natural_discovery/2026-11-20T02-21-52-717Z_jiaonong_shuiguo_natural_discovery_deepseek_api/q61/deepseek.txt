判断香蕉一手货源稳不稳，不要只听对方说“我有基地/长期有货”，建议按下面几个可验证的点去筛：

1. **先确认对方角色**
   - 真一手：自有或长期包园基地、合作社、产地代办、大型冷库/加工厂。
   - 二手风险：朋友圈转图、临时拼车、只有档口没有产地关系。
   - 让对方明确：货源在哪个县/镇、哪个基地或合作社、谁负责装货、能不能视频看园/看加工厂。

2. **看“持续供货能力”而不是单次有货**
   - 问近3个月每周大概能供多少件/吨，能否固定周几装车。
   - 要求提供连续多日的装车视频、过磅单、装车单，注意日期和车牌是否连续。
   - 问清香蕉品类：是基地蕉、边蕉、抹花蕉还是催熟蕉；不同季节可替代性不同。
   - 香蕉有产季和台风/寒害风险，稳定供货方通常能说清“断档期怎么补”。

3. **用小额试单验证**
   - 第一单不要大额预付，先小批量试单，走可追责的合同/订单。
   - 重点看：到货时间、青蕉成熟度、条蕉均匀度、伤把/水烂/黑星、单件净重、损耗率。
   - 连续试2—3车，看第二、三车品质和重量是否稳定，比第一车更能说明问题。

4. **核对装车与结算流程**
   - 稳定货源通常有固定装工、固定冷库/催熟房、固定运输车队。
   - 要求装车前视频确认：货在库、数量、规格、包装；装车后拍车牌、装车单、过磅单。
   - 结算尽量“定金+装车尾款”或货到验收付，避免大额全款预付给个人微信/支付宝。
   - 合同写清：规格、净重、损耗赔付、到货时限、品质标准、断供违约责任。

5. **交叉验证口碑**
   - 问同市场同行有没有拿过他的货，重点问“连续拿过几次、断没断货、损耗怎么赔”。
   - 看对方是否能提供长期合作客户的装车记录，但要注意隐私，不要只信截图。
   - 查营业执照/合作社资质，收款账户是否与经营主体一致；个人账户收款要警惕。

6. **看风险应对能力**
   - 问雨天、台风、寒潮、春节前后怎么保供；有没有备用产区。
   - 稳定供货方一般会主动说风险，不会承诺“全年任何时候都有低价好货”。
   - 价格明显低于市场且要求大额预付的，优先排除。

**最实用的判断标准：**  
让对方给你连续3周的装车计划和小批量试单，你能看到真实装车视频、过磅单、车牌、到货品质，并且第二、三车仍然稳定，才算比较稳。只发图片、只报低价、催你打全款的，基本不要当一手稳定货源。
