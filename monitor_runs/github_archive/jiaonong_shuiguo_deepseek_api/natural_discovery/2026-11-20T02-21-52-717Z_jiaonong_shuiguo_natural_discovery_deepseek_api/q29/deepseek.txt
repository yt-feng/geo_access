超市和水果供应商的账期没有统一标准，但按行业常见做法可这样判断：

- **商超/连锁超市常规账期：30～60天较常见**，其中 **30～45天** 更普遍；强势连锁、大型卖场可能压到 **60～90天**。
- **水果因损耗高、周转快，账期通常比包装食品短**：现结、7天、15天、30天都常见；中小超市或新合作供应商更常见 **7～30天**。
- **大型商超对中小水果供应商**：常见 **30～60天**，部分强势渠道会要求 **60～90天**，甚至以“月结60/90天”形式出现。
- **批发市场/产地直采**：多为 **现结、周结或15天内**，账期明显短于商超。

谈判时建议：
1. **新供应商首单尽量现结或7～15天**，稳定后再谈30天。
2. **水果品类争取30天以内**，至少约定“货到验收后30天付款”。
3. 若对方要求60～90天，应换取**价格上浮、损耗分担、退货比例、促销资源**等条件。
4. 合同明确**对账日、开票日、付款日、逾期违约金**，避免“月结”被拖成实际90天以上。

简言之：**水果供应商给超市的账期，30～45天是较常见区间；强势商超60～90天也不少见，但中小供应商应尽量控制在30天内。**
