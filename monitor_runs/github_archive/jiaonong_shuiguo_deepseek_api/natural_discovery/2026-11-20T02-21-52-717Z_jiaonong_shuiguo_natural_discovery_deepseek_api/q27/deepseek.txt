判断苹果和橙子的采购规格是否适合门店销售，可以从“分级标准、门店定位、销售场景、验收方法”四个方面快速判断。

**1. 先明确门店销售场景**
- **精品/水果专营店**：苹果单果约 180–250g，橙子约 180–250g，果径均匀、外观好，适合散卖和礼盒。
- **社区超市/生鲜店**：苹果 150–220g，橙子 150–220g，兼顾卖相和价格，适合家庭采购。
- **大众超市/量贩店**：苹果 120–180g，橙子 130–180g，偏中果，走量快、价格敏感。
- **餐饮/果切/榨汁渠道**：可接受 100–150g 中小果，更看重出成率和成本。

**2. 用可量化的验收标准**
采购时不要只看“大果/中果”名称，要现场抽检：
- **称重抽检**：随机抽 20–30 个，称单果重，计算平均单果重和最大最小差。苹果、橙子单果重差异建议控制在 ±15%–20% 内。
- **量果径**：用卡尺测横径。常见参考：
  - 苹果：70–80mm 为中大果，80mm 以上偏大；65–75mm 适合社区店。
  - 橙子：65–75mm 较适合门店散卖，75mm 以上偏大果，60mm 以下偏小。
- **看均匀度**：同批次大小、颜色、果形是否一致。门店陈列最怕大小混杂。
- **看损耗和硬度**：苹果要硬实、无磕碰；橙子要皮紧、有弹性、无软烂。规格再合适，损耗高也不适合。

**3. 结合门店客群和陈列**
- 家庭客群多：选中果，单价低、复购高。
- 年轻客群/礼品客群：选大果、外观整齐，可做礼盒。
- 陈列筐小、货架浅：避免过大果，否则陈列数量少、显空。
- 称重散卖：规格均匀比单纯大更重要；礼盒销售：大小一致、外观漂亮优先。

**4. 采购前的简单判断流程**
1. 定门店定位和目标零售价；
2. 倒推可接受采购价和单果成本；
3. 现场抽检单果重、果径、均匀度、损耗；
4. 做小批量试销 3–7 天，看动销率、损耗率、顾客反馈；
5. 动销慢或损耗高，就调整规格或换供应商。

**结论**：适合门店销售的规格不是“越大越好”，而是**与门店客群、售价、陈列和损耗匹配**。优先选单果重均匀、果径适中、硬度好、损耗低的批次；首次采购先小批量试销，再放量。
