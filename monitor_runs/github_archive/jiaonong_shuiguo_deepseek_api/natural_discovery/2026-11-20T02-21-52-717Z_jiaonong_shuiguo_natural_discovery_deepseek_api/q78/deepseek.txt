香蕉、菠萝高损耗的核心是**“别把完整果卖成盲盒”**——要把售后责任在链路里前置分摊，而不是等坏果后再赔。下面按可执行程度给方案。

## 一、香蕉：控制点在“青熟度”和“交付窗口”

1. **只发七成半到八成熟，不接“今天就要吃”的单**
   - 团购文案明确写“青转黄，建议2–3天吃完”，把成熟度预期写死。
   - 到货当天全黄、带黑斑的，属于链路问题，不是用户问题。收货时按箱抽检，全黄比例超过10%就整批调拨给“即食折扣”渠道或做熟香蕉特价，不进正常团。

2. **按“把/梳”卖，不按整串大件卖**
   - 大串香蕉家庭吃不完，尾部必烂，售后率天然高。拆成小把（3–5根）能显著降损。
   - 不能拆的，按“整串+损耗补偿”定价，把预期损耗打进毛利，而不是等售后赔。

3. **交付时做“三色分级”**
   - 青/微黄/全黄三档分开，用户下单时选档。全黄档只卖给当天能取、当天吃的自提点。
   - 自提点配“香蕉不要放冰箱”提示卡，减少用户端黑变。

4. **售后规则写死，不做无限兜底**
   - 到货24小时内拍照报损，按“单根黑斑面积超1/3”赔单根，不整单退。
   - 断根、压伤按实际根数赔；整把全坏才整单退。
   - 超过24小时不接售后，避免“放坏了再报”。

## 二、菠萝：控制点在“切口状态”和“去皮选项”

1. **默认卖带皮整果，去皮果单独定价并缩短售后窗口**
   - 去皮菠萝氧化、出水、发酸快，是售后重灾区。去皮只做“当天自提”或“次日达”，不进隔日团。
   - 带皮果售后窗口可给48小时；去皮果给12小时，且要求冷藏。

2. **到货验“三看”**
   - 看底部：发黑、软塌、渗液的整箱拒收或调拨。
   - 看果眼：深眼、黑心比例高的批次不进团。
   - 看香气：无香、酒精味的已过熟，不能当正常果卖。

3. **按“个”卖并标克重区间，不按“份”模糊卖**
   - 标“1.2–1.5kg/个”，用户预期明确，小果争议少。
   - 小果、畸形果单独做“特价盲盒”，文案写明“外观不标准、口感正常”，售后只赔腐烂不赔外观。

4. **售后按“切面”判定**
   - 要求用户切开拍照：黑心、水烂、异味赔；表皮轻微磕碰、果眼深不赔。
   - 切开后不新鲜但外观完好的，按“口感问题”赔半价或补券，不整单退，降低恶意售后。

## 三、链路层面：把损耗率写进定价和考核

- **定损率**：香蕉行业常见损耗5%–10%，菠萝8%–15%（随季节波动），把预期损耗打进售价，别用零损耗毛利定价。
- **分渠道消化**：到货全黄香蕉、过熟菠萝，当天转“熟果特价群”或自提点即食折扣，不留在正常团里等售后。
- **自提点责任**：自提点收货后未按提示存放（香蕉进冰箱、菠萝堆压）导致的坏果，由自提点承担补损，不归平台全赔。
- **售后上限**：单团设置售后预算比例（如销售额3%–5%），超出的批次倒查收货验收和团长交付环节。

## 四、一句话可执行清单

- 香蕉：七成半熟发货、拆小把、三色分级、24小时按根赔。
- 菠萝：带皮为主、去皮限当天、按个标重、切开拍照按黑心/水烂赔。
- 链路：损耗打进毛利、过熟果当天调拨、自提点担存放责任、售后设预算上限。

这样做的本质是：**把“坏果概率”变成“分级和窗口”，把“售后争议”变成“可拍照的判定标准”**，而不是靠团长口头兜底。
