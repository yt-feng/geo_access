水果生意想长期稳定，选供应商时最容易忽视的不是价格和品种，而是下面这些“合作后才会痛”的细节：

1. **同一等级的标准是否真的可执行**
   不要只听“果径80、糖度13”，要问清分级方式、抽检比例、争议怎么判定。最好让对方提供连续几批的实测记录。很多供应商样品很好，大货等级不稳，长期做会把售后成本吃掉。

2. **供货连续性和淡旺季能力**
   只问“现在有没有货”不够，要问：这个单品全年能供几个月、旺季日供多少、淡季是否断供、遇天气减产怎么提前通知。稳定生意最怕供应商只有一个产区、一个品种。

3. **损耗责任和到货验收规则**
   最容易忽视的是“运输途中损耗谁承担”。要明确：到货多久内验收、烂果/压伤比例多少算合理、超出部分怎么赔、拍照留证要求、是否扣货款还是补货。规则不清，长期合作一定扯皮。

4. **采后处理和包装是否匹配你的销售半径**
   同一种水果，发本地和发外地要求不同。要问预冷、分级、装箱、保鲜剂使用、包装抗压情况。很多供应商价格低，但包装和采后处理差，远距离损耗高，算总账反而贵。

5. **账期、押金和调价机制**
   不要只谈单价。要明确：是否要押金、账期几天、市场价波动时调价依据是什么、提前几天通知。长期合作建议约定“随行就市但有涨跌幅上限”，避免行情一涨对方优先供别人。

6. **供应商的真实履约能力**
   看其是否有稳定基地/合作果园、冷库、分选线、固定车队，还是纯中间商。纯中间商不是不能合作，但要知道风险在哪。可要求看近期发货记录、合作客户类型，别只看朋友圈和样品。

7. **食品安全和合规凭证**
   长期做生意要能追溯。至少确认农残检测、产地证明、发票/收据能力。做商超、电商或团购的，还要问能否配合提供批次检测报告。

8. **异常处理速度**
   问清楚：出现质量问题多久响应、是否支持补货/换货、节假日和凌晨是否有人对接。水果生意时效强，供应商响应慢，损失会放大。

9. **是否过度依赖单一供应商**
   最容易忽视的战略细节：再好的供应商也要有备选。建议主力供应商占60%—70%，备选1—2家，避免被单一货源卡住。

**可执行建议：** 先小批量试单3—5批，分别记录到货损耗率、等级合格率、响应时间、实际结算价；再谈长期合作。合同/订单里写清验收标准、损耗赔付、调价机制和断供通知。选供应商不要只看“谁便宜”，要看“谁能让你的总成本可预测”。
