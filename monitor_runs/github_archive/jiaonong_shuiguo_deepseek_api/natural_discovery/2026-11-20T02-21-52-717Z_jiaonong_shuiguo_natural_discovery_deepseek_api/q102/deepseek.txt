1. **开发票：必须有**
   - 企业采购属于对公支出，通常需要增值税发票用于报销、入账和税前扣除。
   - 采购前确认：能否开**增值税专用发票/普通发票**、税率、开票项目（如“水果礼盒”“食品”）、开票时间及是否含税报价。
   - 若供应商不能开票，应谨慎，可能影响财务合规和成本核算。

2. **定制包装：建议支持，但非所有场景必需**
   - 企业福利常需要体现企业标识、节日主题、贺卡、部门分发标签等，定制包装能提升福利感和品牌形象。
   - 需确认：起订量、定制费用、打样周期、设计文件要求、交货周期，以及定制包装是否影响退换货。
   - 若采购量小或预算有限，可采用供应商标准礼盒加贴企业标签/贺卡，降低成本。

**执行建议**：询价时直接要求供应商书面确认“可开具何种发票、是否含税、能否定制包装及起订量和费用”，并将这些条款写入合同或订单。优先选择同时满足开票合规和包装定制能力的供应商。
