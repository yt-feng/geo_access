酒店采购水果盘原料时，建议把“规格标准”和“外观标准”写成验收条款，并明确允许偏差、拒收条件和责任。可按以下执行：

**一、通用验收原则**
1. 每批到货附送货单，注明品名、产地、等级、采摘/分装日期、数量、重量、批次。
2. 抽检比例建议：大批量按每批不少于5%抽检，小批量不少于10件且不低于3件；异常批次加倍抽检。
3. 验收在收货现场完成，拍照留证；不合格品可整批拒收或按约定折价、换货。
4. 到货温度：冷藏水果建议0–8℃（热带水果按品种另定，如香蕉、芒果不宜低温），冷冻原料≤-18℃；冷链断链可拒收。

**二、规格标准（按品类写进合同）**
1. **重量/个头**：按品种规定单果重量或单果横径范围，如草莓单果≥15g、圣女果单果8–12g、橙子横径70–80mm；写明“不低于下限，不超过上限”，超范围比例≤5%。
2. **成熟度**：到货成熟度适合酒店当日/次日使用。即食水果应达到可食用成熟度但不软烂；需存放的可略生，但不得青涩难食。
3. **新鲜度**：采摘后时限按品种约定，如叶菜类24–48小时内、浆果类48小时内；不得有隔夜反复冷藏导致的失水、发黏。
4. **净重与损耗**：明确“净重”还是“毛重”计价；规定允许损耗率，如叶菜≤5%、浆果≤3%，超出部分扣重。
5. **农残与安全**：供应商应提供符合国家食品安全标准的承诺或检测报告；不得使用禁用农药，不得有腐烂、霉变、虫害。
6. **包装规格**：按酒店要求分箱/分盒，单件重量便于搬运；标签注明品名、批次、日期、供应商。

**三、外观标准（可量化）**
1. **色泽**：具有品种应有的色泽，色泽均匀；不得明显褪色、发黑、褐变。
2. **形状**：果形端正，无明显畸形、机械伤、裂口、日灼、冻伤。
3. **表面**：无腐烂、霉斑、虫眼、虫卵、明显药斑、泥土污染；果蒂新鲜，不干枯发黑。
4. **大小一致性**：同批次大小均匀，最大与最小单果差异不超过约定范围（如±10%）。
5. **硬度与手感**：轻压有弹性，不软塌、不流水；不得有发酵味、酸败味、异味。
6. **清洁度**：无泥沙、无杂物、无头发、无包装碎屑；即食类应达到可清洗后直接摆盘的要求。

**四、建议写入合同的拒收/索赔条款**
1. 以下情况可拒收：腐烂霉变率超过约定比例（如>2%）、农残检测不合格、冷链断链、规格偏差超限、异味或虫害。
2. 到货验收不合格，供应商应在约定时限内换货；因原料不合格导致酒店客诉或损失，供应商承担相应责任。
3. 每周/每月汇总验收合格率，连续不达标可终止合作。

**五、随货文件建议**
送货单、产地/批次信息、检测报告或合格承诺、冷链温度记录（如适用）。酒店可保留抽样送检权利。

一句话：把“单果重量/横径、成熟度、新鲜时限、净重损耗率、腐烂率上限、色泽形状、清洁度、冷链温度”逐项写进采购合同和验收单，按批抽检、拍照留证，才能可执行、可追责。
