水果店遇到坏果，处理核心是：**先固定证据、再按合同/约定定责、最后在货款中扣减或换货赔付**。没有合同或约定不清时，优先协商“坏果部分不计价/补货”，不要整单拒付。

### 1. 到货当场验货，先别急着签收
- 抽样开箱，重点看底层、箱心、贴面果。
- 拍照/录像：整车或整批全景、外包装标签、坏果特写、坏果数量称重或点数。
- 让司机或送货员在送货单上注明“发现坏果X件/X斤，待确认”，并签字；对方不签就自己备注并拍照留存。
- 能当场分拣的，坏果单独堆放，不要和好果混放，避免责任说不清。

### 2. 看合同或交易习惯怎么约定
- **有合同**：按合同里的验收标准、损耗率、赔付比例、扣款方式执行。
- **无书面合同**：看长期交易习惯，比如行业常见做法是“坏果部分不计价”或“按坏果比例折价”，少数约定固定损耗率由门店承担。没有约定时，不要默认整批退货，先按坏果实际数量谈扣减。
- 注意：生鲜有自然损耗，轻微磕碰和腐烂变质要区分，腐坏、霉变、内部烂心通常由供应商担责。

### 3. 及时书面通知供应商
- 最好到货当天或约定验收期内发微信/短信/邮件，写清：批次、到货时间、坏果数量、照片、诉求（换货/扣款/补货）。
- 保留聊天记录和通话录音。拖太久供应商容易主张“是你储存不当”。

### 4. 结算时怎么扣
- **换货**：坏果退回或销毁拍照后，供应商补同等数量好果，运费一般由责任方承担。
- **扣款**：按坏果数量×进货单价扣减；如果整批品质不达标，可按协商比例折价，比如坏果率10%就扣10%货款，但要有照片和数量依据。
- **退货**：只有整批严重腐坏、无法销售时才整批退，且要保留退货凭证。
- 扣款前书面确认金额，避免供应商不认账。

### 5. 谈不拢怎么办
- 先按“无争议部分先结、争议部分暂扣”处理，别把所有货款都压住。
- 保留送货单、验收记录、照片、聊天记录、付款凭证，向当地市场监管部门投诉或按合同约定仲裁/诉讼。
- 金额小的，优先协商折价或下次补货，诉讼成本不划算。

### 6. 长期防坑
- 固定供应商签简单供货协议，写明验收时限、坏果率上限、赔付方式。
- 每批到货抽检留样，建立坏果台账。
- 大额进货可约定“先付部分货款，验收合格后结清尾款”。

一句话：**坏果不签收、证据留全套、按实际坏果数量谈扣款或换货，争议部分暂扣、无争议部分照结。**
