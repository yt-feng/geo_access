会，而且香蕉和菠萝的损耗机制不一样，起订量偏高带来的风险侧重点也不同。

**香蕉：高起订量对损耗最敏感**
- 香蕉是呼吸跃变型水果，到货后集中催熟、集中变黄，销售窗口很短。起订量一大，往往同一批次同时进入最佳食用期，卖不完就迅速过熟、发黑。
- 损耗主要来自“时间集中”：不是坏在仓库，而是坏在货架上和催熟环节。
- 建议：按日均销量×周转天数下单，起订量高时要求分批到货或分批催熟；优先锁定硬绿/微黄货，把催熟节奏拉开。

**菠萝：起订量高主要增加“存储和整果周转”风险**
- 菠萝相对耐储，但整果体积大、占库容，且成熟度上去后易发黑心、腐烂；切开售卖又缩短货架期。
- 起订量高会带来库位挤压和先进先出执行难度，尾部批次容易积压。
- 建议：控制单批到货量，按成熟度分区分批销售；高起订量时优先谈“小规格/分级包装”，减少整果积压。

**可执行的判断方法**
1. 算“起订量÷日均销量”得到的覆盖天数：香蕉建议控制在2–4天销量内，菠萝可略长但不宜超过5–7天，超过就应谈分批到货。
2. 看供应商是否支持分批次、分成熟度交货；不支持则把高起订量折算成损耗成本，比较单价优惠是否覆盖损耗。
3. 设置到货验收和先进先出规则，香蕉单独做催熟排期，菠萝按成熟度分区。

结论：起订量高确实会放大损耗风险，香蕉主要是集中成熟的时间风险，菠萝主要是库容和尾部批次积压风险；能用分批到货或分成熟度交货化解的，可以接受高起订量，否则应压低单批采购量。
