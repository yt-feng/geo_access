# 学校食堂采购香蕉如何避免熟过头浪费

核心思路是**按成熟度分批采购 + 用成熟度倒推使用顺序 + 控制单次到货量**。具体可执行的做法如下：

## 1. 采购环节：控制成熟度与批量
- **要求供应商按“七成熟左右”供货**：表皮偏绿、无黑斑，到货后还有 3～5 天自然后熟空间，避免一到货就集中变黄。
- **小批量、多频次**：按日均用量分 2～3 次到货，而不是一次囤一周。香蕉是呼吸跃变型水果，一旦开始后熟会集中变软，单次量越大越容易同时熟过头。
- **合同中约定成熟度标准**：例如“绿熟期”“微黄”分级，超过约定成熟度可拒收或要求调换。

## 2. 收货与储存：延缓后熟
- **到货先分级**：按青、微黄、全黄分开，不要混放。
- **未熟香蕉常温存放，远离苹果、梨等释放乙烯的水果**，避免催熟。
- **已开始变黄的香蕉可放入冷库/冷藏（约 12～13℃）**，低温能明显延缓后熟，但注意不要低于 10℃，否则会冻伤发黑。
- **悬挂或单层平放**，减少挤压伤；挤压部位会加速腐烂。

## 3. 使用环节：先进先出 + 成熟度调度
- **贴日期/成熟度标签，先进先出**。
- **按成熟度安排菜单**：全黄香蕉优先用于直接发放、水果沙拉、奶昔；微黄的可再放 1～2 天；出现少量黑斑的立即转做香蕉面包、香蕉饼、蒸糕等加工品，而不是继续当鲜果发。
- **每天固定时间检查一次**，把“明天可能过熟”的挑出来，提前转加工或调整到当天餐次。

## 4. 应急与兜底
- 与供应商约定**少量调换或退货机制**，应对集中后熟。
- 食堂内部建立**香蕉加工预案**（香蕉奶昔、香蕉松饼、香蕉燕麦粥），把临期香蕉消化掉。
- 记录每周实际消耗与损耗，**用历史数据反推采购量**，逐步把单次采购量压到“2～3 天用量”以内。

**一句话判断标准**：如果到货时香蕉已经全黄甚至带黑斑，说明成熟度控制失效，应调整供应商标准或缩短采购周期；如果损耗主要来自“一次到货太多”，就改成小批量多频次。
