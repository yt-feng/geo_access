更适合线上卖的优先级，通常可按 **冷冻原料 > 切配 > 整果** 来判断，但前提是看你的客群和履约半径。更准确地说：

- **主推冷冻菠萝原料/冷冻果块**：最适合线上规模化卖。
- **切配鲜菠萝**：适合同城/前置仓/短保即时零售，不适合全国普通快递。
- **整果菠萝**：适合产地直发、低价引流、家庭整颗购买，但损耗、售后和体验波动最大。

### 判断依据

1. **履约稳定性**
   - 冷冻原料：保质期长、标准化高、破损少，适合快递和囤货。
   - 切配：短保、易出水、易变质，必须冷链，履约半径短。
   - 整果：耐运输相对好，但成熟度不可控，易出现“到手没熟/过熟/黑心”，售后多。

2. **损耗和退货**
   - 冷冻原料损耗最低，退货率通常最低。
   - 切配损耗中等偏高，开封后保质期极短。
   - 整果损耗和售后最高，尤其夏季和跨区域运输。

3. **客单价和复购**
   - 冷冻原料适合做烘焙、饮品、餐饮小B和家庭囤货，复购逻辑强。
   - 切配适合即时消费、办公室/家庭小份，客单低但履约成本高。
   - 整果客单可低可高，但复购依赖价格和品质稳定性。

4. **线上平台匹配**
   - 全国电商/直播/社区团购：优先冷冻原料，其次整果产地直发。
   - 同城即时零售/前置仓：切配和整果都可以，切配更体现便利性。
   - 餐饮供应链/小B端：冷冻原料最匹配。

### 建议的组合打法

- **冷启动主推冷冻菠萝块/菠萝丁**：做标准规格，强调无添加、适合饮品烘焙、冷链到家。
- **同城渠道做切配鲜菠萝**：限定配送半径，明确“当日切配、冷藏短保”。
- **整果作为引流品**：只做产地直发或季节性爆品，严格控成熟度和售后规则。

如果只能选一个线上主推品，选 **冷冻原料**；如果做同城即时零售，选 **切配**；如果做产地直发低价爆量，选 **整果**，但不要把它当利润和复购主力。
