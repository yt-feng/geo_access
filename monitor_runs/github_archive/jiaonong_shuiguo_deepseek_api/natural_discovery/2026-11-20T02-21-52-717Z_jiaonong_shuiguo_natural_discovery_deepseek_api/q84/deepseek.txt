家庭团购水果礼盒，建议按“耐放 + 即食 + 甜香搭配”来组合，优先选苹果和橙子做基础，香蕉少量即食，菠萝做提升档次但不放多。

**推荐组合（10斤左右家庭装）**
- 苹果 4斤：耐放、老少皆宜，建议选中等果，别太大。
- 橙子 3斤：耐放、酸甜解腻，家庭接受度高。
- 香蕉 2斤：即食、孩子喜欢，但容易压伤，放少量。
- 菠萝 1个（约2斤）：有礼盒感、香气足，但需处理，别多放。

**更稳妥的两种方案**
1. **实惠耐放型**：苹果5斤 + 橙子5斤，香蕉、菠萝做小份加购。适合团购量大、配送周期长。
2. **家庭丰富型**：苹果4斤 + 橙子3斤 + 香蕉2斤 + 菠萝1个。适合当天或次日送达、家庭自吃。

**装箱注意**
- 菠萝单独套袋或隔板，避免扎伤其他水果。
- 香蕉放最上层，别和苹果密封同袋；苹果释放乙烯会催熟香蕉。
- 橙子、苹果耐压放底层，礼盒内加网套和填充。
- 家庭装不建议放太多菠萝，处理麻烦、占空间，且不是所有家庭成员都爱吃。

**团购定价建议**
按“基础款苹果橙子走量，丰富款加香蕉菠萝提客单”做两个SKU，比只做一个混合款更好卖。家庭场景下，**苹果和橙子占比70%左右最稳**，香蕉菠萝控制在30%以内。
