茶饮店控制水果供应商食品安全风险，建议把“准入资料”和“批次到货资料”分开管理。

**一、供应商准入阶段建议要求提供**
1. **营业执照**：经营范围覆盖水果销售/农产品销售。
2. **食品经营许可证**或仅销售预包装食品备案信息（按当地监管要求；销售食用农产品虽常按农产品管理，但茶饮店应结合属地监管确认）。
3. **供货商/合作社/种植基地资质**：如为合作社、家庭农场、种植基地，提供相应主体证明；如为批发市场档口，提供档口租赁/经营证明。
4. **产地证明或采购来源证明**：如产地证明、购销合同、进货凭证、供货清单，能追溯到具体产地/批次。
5. **检测报告**：至少提供近期第三方或供应商自检的农残检测报告，重点覆盖高风险水果；报告应有样品名称、检测项目、检测结果、检测日期、检测机构。
6. **承诺书/质量保证协议**：明确农残、重金属、霉变、腐烂、异物、包装运输卫生等责任，以及不合格退换货和赔偿条款。
7. **配送与储存能力说明**：冷藏/常温运输条件、周转箱清洁消毒、防虫防鼠措施。
8. **从业人员健康证明**（如供应商涉及直接接触即食水果的切配、包装环节）。

**二、每批次到货建议索取/留存**
1. **送货单/销售凭证**：写明品名、规格、数量、产地、批次、日期、供应商盖章或签字。
2. **批次检测报告或快检记录**：优先要农残快检合格记录；高风险品种可要求批批检或定期第三方检测。
3. **承诺达标合格证**：食用农产品生产者/收购者按相关规定可出具，适合作为产地和质量安全凭证。
4. **运输温度/卫生记录**：需冷藏水果应有冷链温度记录；周转箱清洁记录。
5. **验收记录**：茶饮店自己做感官验收，记录色泽、气味、腐烂霉变、虫害、异物、包装污染等，并拍照留档。

**三、茶饮店内部管理要点**
- 建立**供应商档案**和**进货台账**，做到票、货、报告对应，建议保存不少于6个月，按属地要求可更长。
- 对高风险水果（如草莓、葡萄、切果类）提高检测频次；不能只依赖供应商报告。
- 到货先验收后入库，腐烂霉变、破损污染、来源不明的拒收。
- 水果清洗、切配、暂存按即食食品要求管理，避免交叉污染。
- 每年对供应商做一次复审，出现农残超标、来源不清、频繁质量问题应暂停供货。

简言之：**证照+来源证明+检测报告+质量协议**是准入底线；**每批送货单+合格证明/快检+验收记录**是日常追溯底线。具体证照名称和检测频次，建议再向当地市场监管部门确认属地要求。
