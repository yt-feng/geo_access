水果采购合同里，坏果率赔付触发点通常按“验收时点”和“品类耐储性”分档，没有统一法定数值。可执行建议如下：

1. **常见合同区间**
   - 易腐水果（草莓、蓝莓、樱桃、荔枝、芒果、桃等）：验收坏果率超过 **3%～5%** 即可要求赔付或扣款。
   - 普通水果（苹果、梨、柑橘、葡萄等）：超过 **5%～8%** 触发赔付。
   - 耐储水果（柚子、橙子、苹果冷藏货等）：可放宽到 **8%～10%**。
   - 若合同写“允许损耗”，建议把允许损耗和赔付触发分开：例如“允许损耗≤3%，超过3%的部分按比例扣款；超过10%可拒收或整批退货”。

2. **赔付计算建议写清楚**
   建议条款写成：
   > 验收时坏果率超过X%的，超出部分按坏果重量×采购单价扣减货款；坏果率超过Y%的，买方有权拒收整批或要求换货，并由卖方承担退换货运费及因此产生的合理损失。

   例如：坏果率5%触发，超过5%的部分按“实际坏果重量×单价”扣款；超过10%可整批拒收。

3. **关键是把“坏果”定义写死**
   合同里应明确：腐烂、霉变、虫蛀、严重压伤、开裂流汁、异味等算坏果；轻微表皮瑕疵、色泽差异不算。并约定验收时间（如到货后24小时内）、抽检比例（如随机抽3箱/批）、复检机制和拍照留证。

4. **不要只写一个百分比**
   单写“坏果率超过5%赔付”容易扯皮。建议同时写：触发比例、计算基数（按重量还是按件数）、扣款公式、拒收权、运费承担、复检期限。

**结论：** 谈判时可先报“易腐3%、普通5%、耐储8%”作为触发线；合同里至少写清“超过部分按比例扣款，超过10%可拒收”。具体数值按品类、运输距离和验收周期调整。
