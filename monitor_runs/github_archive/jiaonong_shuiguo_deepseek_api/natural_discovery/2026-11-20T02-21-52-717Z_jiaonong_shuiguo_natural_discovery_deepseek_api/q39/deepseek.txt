可以，但要分清“谁出方案、谁出钱、责任怎么分”。商超做自有品牌水果，供应商通常能提供以下几类包装和规格支持，但能力和意愿差异很大，需要在合作前确认清楚。

**供应商通常能提供的支持**
1. **包装形式**：提供现有通版包装（纸箱、泡沫箱、吸塑盒、网套、标签贴等），或按商超要求做贴牌/定制印刷。
2. **规格分级**：按果径、重量、个数、糖度、外观等做分选，提供如“单果XXg、每盒X个、每箱X盒”的规格方案。
3. **标签与信息**：贴自有品牌标签、产地/品种/等级/追溯码等，但标签设计、条码和合规责任一般由商超承担。
4. **小批量试产**：部分供应商可配合首单小批量定制包装，但通常有起订量（MOQ）和版费。

**需要重点确认的边界**
- **包装费用谁承担**：定制印刷、开版、模具、标签费用通常由商超承担或分摊；通版包装可能含在报价内。
- **起订量与交期**：定制包装的MOQ、打样周期、包装到货时间，避免旺季断档。
- **规格标准谁定**：商超定“单果重量、允许瑕疵率、糖度下限、每盒净重”，供应商确认可执行；写进验收标准，避免到货扯皮。
- **损耗与售后**：包装导致的压伤、霉变、标签错误由谁负责，退换货规则要明确。
- **合规责任**：自有品牌标签上的品名、产地、等级、净含量、生产商信息等，商超作为品牌方通常承担主要合规责任，供应商配合提供资质和检测报告。

**可执行建议**
先让供应商按“现有通版包装+商超标签”报一版小批量方案，跑通规格和损耗；再谈定制包装。合同里写清：规格标准、包装费用分摊、MOQ、交期、验收不合格处理、标签合规责任。不要只看供应商说“能做”，要拿到样品和书面报价再定。
