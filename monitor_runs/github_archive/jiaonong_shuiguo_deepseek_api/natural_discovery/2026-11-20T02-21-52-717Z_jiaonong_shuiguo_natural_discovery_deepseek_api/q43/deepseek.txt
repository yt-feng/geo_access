评估水果供应商仓配对连锁门店的覆盖，建议按“先画网络、再算能力、最后做压力测试和试点”四步走，避免只看供应商宣称的覆盖城市。

**1. 先把门店和温层需求画出来**
- 按城市/商圈整理门店清单：日均销量、SKU结构（叶菜/浆果/瓜果/苹果梨等）、最低起订量、收货时段、卸货条件。
- 按水果温层分类：常温、冷藏（0~8℃）、冰鲜/易损（如浆果、荔枝），分别统计需求量和门店占比。
- 标出“必须直送”和“可中转”的门店，例如高端商圈店、鲜切门店对时效和品相要求更高。

**2. 核验供应商仓配网络是否真覆盖**
重点看四点：
- **仓的位置和类型**：区域仓、城市仓、前置仓分别服务哪些城市，到门店的直线/实际配送半径是多少。
- **冷链能力**：冷藏车数量、温控记录、是否全程温控、断链应急方案；水果最怕“干线冷链、城配常温”。
- **配送频次和截单时间**：能否支持日配/隔日配，门店下单截止时间与到店时间是否匹配早市或营业高峰。
- **跨城与末端能力**：跨城干线是否自有或稳定外包；末端是自送还是落地配，谁负责卸货、验收、退货。

**3. 用可量化指标算“覆盖质量”**
建议至少算这几项：
- **门店覆盖率**：可服务门店数/总门店数，并按城市、温层、销售占比加权。
- **时效达成率**：承诺到店时间与实际到店时间对比，重点看早于营业前到店的比例。
- **履约半径与成本**：每店每单配送成本、单店最低起订量是否导致小门店凑单或断货。
- **损耗与品质**：到店损耗率、温控超标次数、因品相拒收率。
- **弹性能力**：大促、节假日、极端天气下的加车能力和备用仓/备用线路。

**4. 做压力测试和试点**
- 选2~3个代表性城市（核心城市、卫星城市、偏远门店）做1~2个月试点，按真实订单跑，不按供应商样板线路跑。
- 模拟旺季加量30%~50%、单店临时加单、跨城调拨、车辆故障等场景，看响应时间和替代方案。
- 合同里写清SLA：到店时间窗、温控标准、损耗上限、缺货赔付、跨城调拨响应时限、数据回传要求。

**判断结论可以这样下**：如果供应商能覆盖门店销售占比80%以上、核心城市支持日配、冷链全程可追溯、试点时效达成率≥95%、损耗在可接受范围，且小门店不被最低起订量卡住，才算“覆盖可用”；否则应按城市分层，采用“区域主供应商+城市补充供应商+本地应急供应商”的组合，而不是追求单一供应商全国覆盖。
