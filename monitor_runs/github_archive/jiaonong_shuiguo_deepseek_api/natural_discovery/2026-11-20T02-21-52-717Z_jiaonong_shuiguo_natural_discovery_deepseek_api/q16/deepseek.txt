建议按“品类特性 + 门店规模 + 补货频率”分开决策，不要只选一种渠道。

**结论：**
- **香蕉：优先本地批发/本地熟蕉渠道**，因为香蕉成熟度变化快、损耗高、周转要求高，需要频繁小批量补货和现场看货。
- **苹果：优先稳定供应商**，因为苹果耐储存、等级和口感稳定性更重要，适合按标准批量采购、固定周期配送。
- **更稳妥的做法：双渠道组合。** 苹果以稳定供应商为主、本地批发做补充；香蕉以本地批发为主，但筛选1家能稳定供货的本地供应商作为备选。

**判断标准：**

1. **看损耗和周转**
   - 香蕉：2～3天卖不动就容易出问题，适合“少量多次”。本地批发能快速补货、现场挑成熟度。
   - 苹果：可存放更久，适合一次采购稍多，减少频繁跑批发的成本。

2. **看品控稳定性**
   - 苹果顾客对大小、脆度、甜度、外观一致性敏感，稳定供应商更能保证等级稳定。
   - 香蕉顾客对“今天能不能吃、放几天”敏感，本地现场看货更可靠。

3. **看起订量和配送**
   - 社区超市单店销量有限，稳定供应商如果起订量高、配送慢，反而不如本地批发灵活。
   - 如果稳定供应商能周配2～3次、起订量低、坏果有赔付，苹果可以优先给它。

4. **看价格结构**
   - 不要只比单价，要算“到店成本”：采购价 + 运费 + 损耗 + 人工 + 坏果处理。
   - 香蕉损耗通常高于苹果，本地批发即使单价略高，综合成本可能更低。

**可执行方案：**

- **先试2周：**
  - 香蕉找2家本地批发，比较到货成熟度、坏果率、补货速度。
  - 苹果找1家稳定供应商 + 1家本地批发，比较同一等级苹果的到店成本和7天损耗。
- **设简单指标：**
  - 香蕉：到店可售率、3天损耗率、缺货次数。
  - 苹果：7天损耗率、顾客复购/投诉、等级一致性。
- **采购比例建议：**
  - 苹果：稳定供应商70%～80%，本地批发20%～30%应急和比价。
  - 香蕉：本地批发70%左右，稳定本地供应商30%左右兜底。
- **合同/口头约定要明确：**
  - 坏果赔付、到货成熟度、最低起订量、配送频次、临时补货响应时间。

**一句话：香蕉重“新鲜周转”，偏本地批发；苹果重“稳定标准”，偏稳定供应商；单店最怕押单一渠道，最好主渠道+备选渠道并行。**
