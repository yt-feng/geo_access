做小区团购，水果供应商能不能支持下面这些服务，直接决定你后面好不好做。按优先级给你列：

## 一、必须支持（没有就很难做）

1. **小批量、多频次配送**
   - 能接受每次几十斤到一两百斤的小单，而不是必须整箱整车起批。
   - 能每周稳定送 2～3 次，甚至支持你头天下单、第二天到货。
   - 问清楚：起送量、配送费、配送范围、送达时间窗。

2. **分级报价和稳定供货**
   - 能给你明确的批发价/团购价，而不是每次临时报价。
   - 同一品种能稳定供货，不会今天有明天断。
   - 能提前告诉你当季主推品和大概价格区间，方便你设计团购套餐。

3. **品质分级与售后**
   - 能按等级供货（如大果/中果/小果），并说明规格、产地、甜度/成熟度。
   - 坏果、烂果、缺斤少两能**包赔或补货**，最好有明确的售后规则和拍照理赔流程。
   - 这点最重要：小区团购靠口碑，售后不兜底，你只能自己贴钱。

4. **支持少量多品种拼单**
   - 一次能拼几个品种，每个品种量不大也能配。
   - 能给你提供组合装/套餐建议，比如“39.9元水果拼箱”。

## 二、强烈建议支持（决定你省不省心）

5. **代分装/代打包**
   - 能按你的团购份数提前分装成小份，贴好标签。
   - 哪怕只支持整箱到店、你自己分装，也要问清楚是否收分装费。

6. **提供图片、文案和价格素材**
   - 能给你产品图、规格说明、卖点文案，方便你发群和做接龙。
   - 最好能提供每日/每周报价单。

7. **退换货和临期处理**
   - 当天卖不完或品质有问题的货，能否退换、折价处理或有兜底方案。
   - 明确生鲜损耗谁承担。

8. **账期或结算灵活**
   - 支持现结、周结，或先少量押金试合作。
   - 刚开始建议小额现结，稳定后再谈账期。

## 三、加分项（有更好）

9. **支持预售/按单采摘**
   - 你群里接龙多少，供应商按量备货，减少你的库存压力。

10. **冷链或保鲜配送**
    - 夏季高温时能保证水果到店新鲜度。

11. **独家小区保护**
    - 同一小区不直接供货给你的竞争对手，或至少不恶意低价冲击。

12. **试销支持**
    - 首批小量试卖、样品支持、卖不动可换品。

## 你谈供应商时要直接问的清单

- 起送量多少？配送费多少？一周能送几次？
- 价格是固定价还是每天浮动？能不能提前给报价单？
- 坏果怎么赔？多久内反馈有效？要不要拍照？
- 能不能按份分装？分装费多少？
- 能不能拼品种？最小起订量按品种还是按总金额？
- 卖不完能不能退换？损耗谁承担？
- 能不能给图片和文案？
- 首批能不能小量试合作？

**一句话建议**：先找 1～2 家能“小批量配送 + 坏果包赔 + 给报价素材”的供应商试跑两周，重点看配送稳定性和售后爽不爽快，再决定长期合作。
