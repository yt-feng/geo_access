可以按“引流款+利润款+场景组合”来做，不要只简单打折。香蕉、菠萝、苹果的组合促销建议如下：

1. **组合套餐：水果拼盘家庭装**
   - 香蕉2把 + 菠萝1个 + 苹果6个，定为“家庭一周水果包”，套餐价比单品合计低8%—12%。
   - 目的：提高客单价，同时让顾客感觉省事、省钱。
   - 定价时先算单品毛利，套餐让利控制在总毛利仍为正，避免香蕉亏太多。

2. **香蕉做引流，苹果做利润，菠萝做搭配**
   - 香蕉单价低、购买频次高，可做“加1元换购苹果2个”或“买香蕉满10元加5元换菠萝半个”。
   - 苹果毛利相对稳，适合放在套餐主体里。
   - 菠萝客单贡献高，适合做组合中的“升级项”，如“套餐+3元换购菠萝”。

3. **按场景做三个价格带**
   - **9.9元尝鲜组合**：香蕉3根+苹果2个+菠萝小块，适合下班顺手买，拉低尝试门槛。
   - **19.9—29.9元家庭组合**：香蕉1把+苹果4—6个+菠萝1个，主推提高客单价。
   - **39.9元以上聚会组合**：香蕉2把+苹果8个+菠萝2个，配果切盒或酸奶蘸料，适合家庭聚会。

4. **陈列上做“关联购买”**
   - 把香蕉、菠萝、苹果相邻陈列，套餐用统一手提袋或保鲜盒打包。
   - 价签写清楚“单买合计XX元，套餐价XX元”，让顾客直接感知优惠。
   - 菠萝可现场切半展示，降低顾客“不会处理”的顾虑。

5. **限时机制提高转化**
   - 每天17:00—20:00推“下班水果包”，套餐额外送1根香蕉或小盒果切。
   - 周末推“家庭装第二件减3元”，但仅限苹果或菠萝，保护香蕉引流价。

6. **控制损耗**
   - 香蕉熟度高时优先放入套餐，菠萝按销量分批切盒，苹果选耐放规格做家庭装。
   - 套餐每天限量，比如30份，避免为了冲客单价造成滞销损耗。

建议先选一个主推套餐测试7天，观察三个指标：**套餐销量、客单价提升幅度、水果区损耗率**。如果套餐销量好但损耗上升，就减少菠萝整果、增加苹果和香蕉比例；如果客单价没提升，就把套餐价差拉大到10%以上，并放在收银动线附近。
