结论先说：**多数甜品店用鲜菠萝现切的总损耗更低，但前提是“销量稳定、后厨能按计划切配、边角料能再利用”**；如果单量小、波动大、人手紧，**直接买成品果丁的实际损耗常常更低**。要判断你们店哪种更低，按下面3步算一次就知道。

## 先分清两种“损耗”
- **鲜果现切**：去皮去眼、修边、切丁、氧化变色、切多卖不完、冷藏变味。
- **成品果丁**：规格不匹配的报废、开封后氧化出水、保质期短卖不完、解冻/渗液、配送不稳定导致的临期处理。

很多人只比较“菠萝去皮出成率”，忽略了成品果丁的**开封后报废**和鲜果的**边角料再利用**，所以会误判。

## 快速判断规则
满足以下 **3条以上**，鲜果现切通常损耗更低：
1. 菠萝类甜品/饮品**日销量稳定**，每天至少能消化 2–3 个整果；
2. 后厨能在高峰期前**分批切配**，不是一次切一大盆；
3. 菠萝芯、边角料能用于**果酱、糖水、饮品、装饰**；
4. 店内有人愿意做**去皮修整**，且人工不算紧张；
5. 对果丁大小要求不极端统一，允许手工丁有轻微差异。

满足以下 **2条以上**，成品果丁实际损耗往往更低：
1. 每天用量小且波动大，经常“切了用不完”；
2. 后厨人手紧，现切会挤占高峰出品；
3. 成品果丁规格正好匹配配方，几乎无二次修整；
4. 供应商稳定，能小批量、高频配送；
5. 店内冷藏条件一般，开封后容易出水变味。

## 用一周数据算“真实损耗率”
分别记录鲜果和成品果丁：
- **鲜果**：采购总重 → 可售果丁净重 → 未售报废重量  
  真实损耗率 =（采购总重 − 实际用于出品的果丁净重）÷ 采购总重
- **成品果丁**：到货总重 → 实际用于出品重量 → 开封报废/临期报废重量  
  真实损耗率 =（到货总重 − 实际用于出品重量）÷ 到货总重

同时把**人工成本**折算进去：鲜果现切的人工修整时间 × 时薪，加到鲜果侧；成品果丁则加上开封分装和临期管理的时间。比较“每公斤可用果丁的综合成本”，而不是只比原料单价。

## 实操建议
- **销量稳定的大单品**：鲜菠萝现切，分批切、边角料做果酱/糖水，通常最划算。
- **多SKU小用量、单量波动大**：成品果丁更稳，重点是**小包装、高频配送、开封标注时间、先进先出**。
- **混合策略**：主力产品用鲜果现切，少量装饰/应急用成品果丁，既控损耗又保出品稳定。
- **别忽略氧化**：鲜切菠萝冷藏也会出水变味，按“半天用量”切配，比一次性切一天更控损耗。

一句话：**损耗高低不取决于“鲜果还是成品”，而取决于你们的销量稳定性、切配节奏和开封管理。** 用一周真实出品数据算一次综合成本，答案就很清楚。
