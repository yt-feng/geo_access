谈酒店早餐水果供应，核心是把“稳定”拆成可约定的条款，别只谈价格。重点注意这几块：

1. **明确品类和规格**
   - 按早餐实际用量列清单：苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等，分别约定单果重量/果径、成熟度、甜度范围、外观瑕疵容忍度。
   - 西瓜、哈密瓜这类要约定切果还是整果、去皮与否、到货温度。
   - 写清“同等品质替代品”规则，避免缺货时被动接受降级货。

2. **稳定供应的硬约束**
   - 约定每日/每周供货量、下单截止时间、送达时间窗口（早餐高峰前必须到）。
   - 缺货、延迟、品质不达标的违约责任和补货时限。
   - 节假日、极端天气、产地断供时的应急预案，比如备用产地、备用供应商、提前备货量。
   - 要求供应商提供近几个月的供货稳定性说明，不要只听口头承诺。

3. **价格与结算**
   - 不要只锁单价，约定价格调整机制：调价周期、参考市场价依据、提前通知期。
   - 明确是否含税、含运费、含卸货到指定冷库/厨房。
   - 账期、对账方式、发票类型写进合同。
   - 警惕明显低于市场价的报价，往往靠降规格或断供找补。

4. **验收标准可执行**
   - 制定验收单：品种、数量、单果重、成熟度、腐烂率上限、农残检测报告/承诺。
   - 约定拒收标准和不合格品处理方式：当场退换还是扣款。
   - 到货温度要求，尤其切果和浆果类。
   - 留样和记录制度，便于追溯。

5. **食品安全与资质**
   - 查验营业执照、食品经营许可证、产地证明、检测报告。
   - 明确农残、重金属等检测责任和频次，要求定期提供报告。
   - 切果供应商需有相应加工资质和冷链能力。
   - 约定食品安全事故的责任划分和赔偿。

6. **合同细节**
   - 合作期限、试供期、退出机制。
   - 独家还是多源供应：早餐水果建议至少保留一个备用供应商，避免被单一供应商卡脖子。
   - 保密和禁止商业贿赂条款。
   - 争议解决方式。

7. **先试供再签约**
   - 建议先跑2—4周试供，重点看：到货准时率、验收合格率、缺货次数、临时加单响应速度。
   - 试供期数据作为正式合同量和考核依据。

一句话：把“稳定”写成可验收的指标和违约后果，同时保留备用供应渠道，比压价更重要。
