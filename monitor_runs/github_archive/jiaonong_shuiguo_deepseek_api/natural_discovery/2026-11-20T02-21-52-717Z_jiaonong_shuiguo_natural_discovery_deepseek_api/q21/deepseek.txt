超市采购水果时，供应商通常需要提供以下几类证明和报告（具体以当地市场监管要求和超市自身验收标准为准）：

1. **营业执照及食品经营许可**：供应商的合法经营资质复印件，加盖公章。
2. **产地证明或供货证明**：包括产地证明、购销合同、供货单、发票等，用于证明水果来源合法、可追溯。进口水果还需提供海关报关单、入境货物检验检疫证明。
3. **农药残留检测报告**：由具备资质的检测机构出具，或供应商自检报告。超市一般要求批次对应的农残快检或定量检测报告，重点检测有机磷、氨基甲酸酯类等。
4. **食用农产品合格证**：按《食用农产品市场销售质量安全监督管理办法》，供应商应提供食用农产品合格证或产地证明、购货凭证等。
5. **检验检疫证明**：涉及检疫性病虫害或进口水果时，需提供植物检疫证书或入境货物检验检疫证明。
6. **批次追溯信息**：品种、产地、采摘/进货日期、批次号等，便于超市建立进货查验记录。
7. **其他**：如绿色食品、有机认证、地理标志等，若超市采购相应认证产品，需提供有效认证证书。

建议超市在合同中明确供应商须随货提供上述材料，并建立进货台账，留存复印件或电子档案至少6个月（按当地规定执行）。
