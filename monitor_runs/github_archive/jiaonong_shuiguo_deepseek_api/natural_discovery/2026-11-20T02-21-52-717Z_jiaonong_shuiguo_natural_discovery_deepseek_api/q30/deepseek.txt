超市水果到货后发现品相不好，售后流程建议在采购合同或到货验收单里提前约定清楚，核心是：**验收标准、异议期限、处理方式、责任划分、留证要求**。可按下面条款思路写：

1. **明确验收标准**
   - 按品类约定外观、大小、成熟度、腐烂/碰伤/裂果比例、新鲜度等。
   - 例如：霉烂、异味、严重碰伤、裂口渗汁、明显失水萎蔫等判为不合格；允许轻微外观差异但不得影响销售。
   - 最好附样品标准或照片，避免“品相不好”主观争议。

2. **约定到货验收和异议期限**
   - 到货后当场抽检/全检，记录数量、批次、温度、包装状况。
   - 约定“到货后X小时内提出外观异议，X小时内提出开箱后发现的内伤/腐烂异议”；生鲜建议当日或24小时内，避免过期失权。
   - 逾期未提异议是否视为验收合格，要写清楚。

3. **约定处理方式**
   可按不合格比例分档：
   - 轻微不合格：折价接收；
   - 比例较高：换货、补发；
   - 严重不合格或腐烂变质：拒收、退货退款；
   - 已上架后发现批量问题：下架、召回、供应商按比例赔偿。
   同时约定换货/补货的到货时限和运费承担。

4. **责任和费用划分**
   - 运输途中因温度、挤压、延误造成的损耗由谁承担；
   - 到货验收前风险由供应商承担，验收合格后由超市承担；
   - 因供应商原因导致退货、下架、损耗、客诉的，供应商承担相应损失；
   - 可约定质量保证金或从货款中直接扣减。

5. **留证和流程**
   - 到货拍照/录像：整车、包装、批次、抽检过程、不合格品特写；
   - 保留验收单、称重单、温度记录、沟通记录；
   - 售后流程：门店/收货部提出异议→供应商确认→协商折价/换货/退货→形成书面处理单→财务结算扣款。
   - 约定供应商响应时限，例如24小时内回复，逾期视为认可超市处理方案。

6. **争议解决**
   - 明确抽检比例和判定方法；争议时可送第三方检测，费用由责任方承担。
   - 约定对“品相”争议以到货时留证和合同标准为准，避免事后扯皮。

简单说，售后条款要写成可操作的闭环：**到货多久内提、按什么标准判、不合格怎么赔/换/退、谁出费用、怎么留证、多久响应**。这样既保护超市，也让供应商有明确预期。
