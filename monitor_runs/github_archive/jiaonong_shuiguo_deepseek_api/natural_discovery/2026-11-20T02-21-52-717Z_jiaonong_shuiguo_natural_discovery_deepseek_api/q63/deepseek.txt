判断菠萝哪个规格更容易出货，不要只看“最近谁问得多”。更可靠的是用“成交速度 + 利润 + 损耗”三个维度一起看。给你一套可直接落地的判断方法：

**1. 先给规格分层，不要按“大中小”模糊卖**
建议按重量和用途同时分层，例如：
- 小果：800g–1000g，适合家庭零买、水果摊
- 中果：1000g–1250g，适合社区团购、商超
- 大果：1250g–1500g，适合餐饮/果汁店/礼品
- 特大果：1500g以上，适合加工或特定渠道  
同时记录品种（如金钻、香水菠萝）、成熟度、是否催熟、表皮品相。

**2. 用“出货速度”做核心指标**
统计每个规格最近连续7–10天的：
- 日均出货量（件/斤）
- 从入库到售罄的天数（周转天数）
- 询价到成交的转化率
- 返单率（老客户第二次拿同规格的比例）

**最容易出货的规格，通常是“周转天数最短 + 返单率最高”的那个**，不是单日销量最高的那个。

**3. 算“规格的真实毛利”，不要只看单价**
公式：
`单件真实毛利 = 售价 - 进价 - 损耗成本 - 分拣/包装成本 - 运费分摊`
菠萝损耗很关键：大果如果磕碰多、熟度高，损耗会吃掉利润。把每个规格的损耗率单独统计，再比较。

**4. 看渠道匹配，不要全渠道推同一个规格**
- 社区团购/家庭：中果、小果更容易出
- 水果店/摊贩：中果、大果走量稳
- 餐饮/果汁店：大果、特大果更受欢迎
- 礼品/电商：品相好、大小均匀的中大果更好卖  
所以“哪个规格容易出货”要分渠道回答，不能只给一个总数。

**5. 做一个小测试，而不是凭感觉压货**
选3–5个核心客户，每个规格各给少量试销，记录：
- 3天内售罄比例
- 客户反馈（大小是否合适、熟度是否好控）
- 是否主动返单  
测试后再决定主推规格和备货比例。

**6. 关注“出货快但利润低”的陷阱**
有些小果出货快，但单价低、分拣费高、损耗也不低，实际不赚钱。判断标准建议用：
`规格优先级 = 周转速度 × 返单率 × 单件真实毛利`
三项都靠前的规格，才是真正“更容易出货且值得主推”的规格。

**直接可用的结论模板：**
- 主推规格：周转天数最短、返单率最高、真实毛利为正的那个
- 辅推规格：能覆盖不同渠道、帮助清库存的规格
- 控制规格：出货慢、损耗高、客户返单少的规格，减少备货或只做订单式采购
