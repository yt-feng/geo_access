这四个维度不是并列关系，应该按“经营目标”排优先级：

**1. 切果损耗（最该先关注）**
如果超市卖的是**鲜切菠萝/果切**，损耗直接决定毛利。要关注：
- 出肉率：同等进货价下，出肉率每差5%，毛利差很多；
- 坏果率/黑心率：菠萝黑心、水烂是隐性损耗；
- 去皮去眼的人工成本；
- 切后保鲜期和报损率。

**建议：** 先算出“可售果肉成本 = 进货价 ÷ 出肉率 + 人工分摊”，再反推售价。损耗控制不住，甜度再高也可能不赚钱。

**2. 甜度**
甜度决定**复购和口碑**，尤其鲜食品类。但不要只凭口感，最好有可判断标准：
- 固定品种和产地；
- 到货抽测糖度（如用手持糖度计）；
- 记录“甜度—退货/投诉—复购”的关系。

**3. 外观**
外观影响**首次购买转化**，但对外观要求应分场景：
- 整果销售：外观权重高；
- 鲜切销售：外观只影响“能否出成”，果形歪一点未必是问题。

**4. 大小**
大小主要影响**定价带和陈列**，不是核心品质指标。大果不一定甜，小果也可能出肉率差。应按规格分级定价，而不是一味追大。

**结论：**
- **做鲜切/果切：切果损耗 > 甜度 > 外观 > 大小**
- **做整果零售：甜度 ≈ 外观 > 大小 > 切果损耗**
- **最稳的做法：** 用“出肉率+坏果率”控成本，用“糖度抽检”控品质，用“分级陈列”控价格带。
