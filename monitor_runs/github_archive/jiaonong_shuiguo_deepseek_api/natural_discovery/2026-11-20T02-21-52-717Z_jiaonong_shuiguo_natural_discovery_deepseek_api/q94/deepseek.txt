很重要，而且不只是在“降低进货风险”这一层。

**结论：对便利店水果这种高损耗、需求波动大的品类，供应商能否支持小批量试卖，是关键能力之一，优先级很高。**

判断理由主要有四点：

1. **水果损耗会直接吃掉毛利**
   便利店水果销量不稳定，最大的问题不是“少赚”，而是卖不动就烂、报废、占用冷柜。小批量试卖能把首次进货风险压到可接受范围，先验证门店真实动销。

2. **不同门店、不同商圈差异大**
   同一城市里，写字楼店、社区店、学校附近店的购买时段和品类偏好差别很大。批量压货等于用总仓判断替代门店判断，试卖是低成本获取门店真实数据的方式。

3. **试卖是筛选供应商的试金石**
   愿意支持小批量、多频次补货的供应商，通常意味着它有一定分拣能力、冷链配送能力和愿意共担风险的意愿。只会要求起订量的供应商，后续遇到临期、品质波动时也很难协同。

4. **小批量不等于长期小批量**
   试卖的目的是跑出稳定动销后再放量。可以和供应商约定：前2—4周小批量试销，按门店动销数据决定后续订货量；达到约定销量后转为正常批量。这样供应商也有放量预期，不是无限期迁就。

**可执行建议：**
- 先选3—5家代表性门店做2周试卖，每次每SKU控制在少量、可当日或次日售完的量。
- 明确试卖条件：最小起订量、补货频率、损耗承担、退换货规则、价格是否因小批量上浮。
- 用“动销率、损耗率、毛利额”三项判断是否放量，而不是只看销量。
- 如果供应商完全不愿小批量试卖，可以保留但不宜作为主力水果供应商；优先找愿意“小批量+高频补货+损耗共担”的合作方。

所以答案是：**很重要，应该把它作为选择水果供应商的硬指标之一。**
