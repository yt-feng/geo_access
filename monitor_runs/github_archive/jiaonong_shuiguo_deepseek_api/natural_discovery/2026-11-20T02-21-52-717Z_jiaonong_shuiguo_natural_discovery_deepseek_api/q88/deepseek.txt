# 采购端降低坏果率和口感波动的可执行做法

核心思路：**坏果和口感问题大部分在采购时就决定了，不能靠售后补救。** 按下面几个环节抓：

## 1. 选品先定“可卖标准”，不按“市场通货”标准收
- 按品类明确分级：果径/单果重区间、糖度下限（如柑橘类可要求可溶性固形物≥某值，按品种自定）、成熟度区间、着色比例、允许的机械伤/日灼/裂口比例。
- 把“卖相标准”和“口感标准”分开写：外观达标但糖度不够的货，不要因为便宜就收，那是差评主要来源。
- 对易波动品类（草莓、蓝莓、桃、荔枝、葡萄），标准要更细，宁可少品类也不要全品类都做通货。

## 2. 产地直采 + 固定合作，减少批次差异
- 优先和固定产区、固定果园/合作社签长期协议，明确采摘成熟度、采后处理要求。
- 同一品种尽量锁定 1–2 个主供应商，换供应商等于重新赌一次口感。
- 要求供应商提供采摘日期、批次、产地地块，便于差评时追溯。

## 3. 按“运输半径和时效”反推成熟度
- 近场配送（同城/次日达）可收八成熟以上；跨省长途必须收七成熟左右或做催熟处理，**不要为了“到货即甜”收全熟货走长途**，那是烂果重灾区。
- 明确采后预冷时限：浆果、荔枝、桃等采后尽快预冷，冷链断链一次坏果率就明显上升。
- 运输方式写进合同：温区、包装方式（单果托、气调、冰袋配置）、堆码层数限制。

## 4. 到货验收做“抽检 + 留样”，不靠肉眼一扫
- 每批按比例抽检：坏果率、软果率、糖度（用手持糖度计抽测）、单果重、着色。
- 设定拒收/扣款阈值：如坏果率超过约定比例整批拒收或折价，写进采购合同。
- 每批留样拍照+记录，出现差评时可判断是采购批次问题还是配送/存放问题。

## 5. 包装和分装环节控损
- 按品类选包装：浆果用单果托+透气盒，柑橘类防挤压，葡萄防掉粒。
- 分装时二次挑果，把软果、伤果挑出，**不要指望消费者自己挑**。
- 控制单份规格：一次买太多吃不完导致的“放坏”也会算到差评里，小规格复购更稳。

## 6. 库存周转和上架节奏
- 水果按批次先进先出，设定最长在库时间，超时下架或转特价，不混批销售。
- 高损耗品类控制单批次采购量，宁可少量多次补货。
- 天气/节假日备货要保守，节后积压是坏果和口感投诉的高峰。

## 7. 用评价数据反推采购
- 把差评按“坏果/不甜/太酸/过熟/大小不符”分类，对应到供应商和批次。
- 连续出现口感类差评的供应商，降级或替换；坏果率高的批次直接追溯扣款。

**一句话判断标准：** 采购时如果说不清这批货的成熟度、糖度下限、采后预冷和运输温区，就不要指望上架后评价稳定。先把这四项写进采购单，坏果和口感波动能压下一大半。
