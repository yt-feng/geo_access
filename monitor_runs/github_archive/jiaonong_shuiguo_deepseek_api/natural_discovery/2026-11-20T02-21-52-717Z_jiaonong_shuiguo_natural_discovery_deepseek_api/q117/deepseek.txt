先给结论：**没有统一“标准试卖量”，最稳的做法是按“最小可陈列量 + 2~4周售罄周期 + 可承受损耗额”倒推试卖量**，而不是按供应商报的起订量直接拿。

### 可以直接用的计算框架

**试卖量 ≈ 单店日均预计销量 × 试卖天数 + 安全陈列量**

其中建议：
- **试卖天数**：水果保鲜期短，一般 **7~14天**；耐储品类可到 **21天**。
- **安全陈列量**：至少能摆满一个陈列位，但不超过 **3天销量**，避免“摆不满看不出效果、摆太多卖不掉”。
- **单店首次试卖**：通常控制在该品类 **现有日均销量的10%~20%**，或单店 **1~3箱/1~2个周转筐**起步，先看动销。
- **多店试点**：不要全渠道铺开，选 **3~5家代表性门店**先试，再决定是否扩量。

### 采购方判断“稳”的3条线

1. **损耗线**：预计试卖期损耗金额，不超过该单品预计毛利的 **30%~50%**，超过就减量。
2. **售罄线**：试卖结束应基本售罄或剩少量尾货；若7天动销低于进货量 **50%**，不建议正常上架。
3. **补货线**：试卖期内出现 **2~3次正常补货**，说明有真实动销；只有首日靠促销卖动不算。

### 更稳的操作建议

- **首批少量、缩短账期或争取售后**：和供应商谈试销支持，如坏果赔付、未售罄可调换、少量多批次发货。
- **先做小陈列测试**：给一个端头或1~2个陈列位，不做全场铺货。
- **记录4个数据**：日均销量、损耗率、毛利率、复购/补货频次，再决定正式采购量。
- **按品类调整**：叶菜/浆果类试卖量更小、周期更短；苹果、柑橘等耐储品类可适当放大。

一句话：**首次试卖以“一周左右能卖完、损耗可承受、能看出真实动销”为上限，宁少勿多，卖断再补。**
