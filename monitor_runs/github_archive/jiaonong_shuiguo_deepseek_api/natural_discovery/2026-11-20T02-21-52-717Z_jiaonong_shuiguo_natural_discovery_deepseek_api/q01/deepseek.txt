判断香蕉和菠萝供应商靠不靠谱，建议分“先验资质、再看货、试单验证、长期约束”四步走，别只看报价。

**1. 先看资质和稳定性**
- 是否有固定档口/仓库/加工场地，能否随时去看；只有电话和微信、没有实体的要谨慎。
- 营业执照、食品经营相关资质是否齐全；做水果批发至少要有稳定货源和运输能力。
- 问清楚：香蕉主要来自哪里、菠萝品种和产区、多久到一次货、缺货时怎么补。答不上来的多半是倒手中间商。
- 看它主要服务哪些客户，是否有稳定给水果店、商超供货的经验。

**2. 重点看香蕉和菠萝的到货质量**
香蕉不能只看黄不黄，要看：
- 成熟度是否适合你门店销售周期：你卖得快可以要略熟，卖得慢要偏青。
- 果指饱满度、有没有明显机械伤、黑斑、断指、霉变。
- 催熟是否均匀，有没有“青硬不熟”或“过熟发软”混装。
- 到货损耗率，问清楚运输中压伤、掉把怎么算。

菠萝重点看：
- 品种是否稳定，同一品种不同产区口感差异大。
- 果形是否端正、果眼深浅、是否有烂心、黑心、水心病。
- 成熟度是否一致，能不能按你要求的成熟度发货。
- 到货后坏果率、烂果是否包赔。

**3. 用试单验证，不要一上来长期大单**
建议先小批量试 2—3 次，每次记录：
- 实际到货重量是否足秤，箱装是否有“皮重”猫腻。
- 坏果率、损耗率。
- 到货时间是否稳定，临时加单能不能响应。
- 出现质量问题时，对方处理速度：是补货、扣款还是推诿。

可以故意问一次售后：“这箱有压伤/烂果怎么处理？”看对方是否爽快给方案。靠谱供应商一般有明确赔付标准。

**4. 长期合作前把规则写清楚**
- 单价随行就市可以，但计价方式、箱皮重量、运费、卸货费要明确。
- 约定质量标准：香蕉成熟度、菠萝品种规格、坏果率上限。
- 约定售后：坏果率超过多少怎么赔，是补货还是折价。
- 账期和结算方式先小后大，不要一开始赊大额。
- 保留每次到货照片、称重记录和聊天记录，出问题有依据。

**简单判断口诀：** 有实体、能看货、敢试单、售后爽快、称重透明、质量稳定，才值得长期合作。报价最低但催着你要大单、不让看货、售后含糊的，风险最高。

另外，香蕉和菠萝对运输和仓储要求不同，最好分别找主做这两类的供应商，或者至少确认对方有对应温控和周转能力，不要只看“什么水果都做”的综合贩子。
