社区超市做小包装香蕉，采购和包装要围绕“少批量、快周转、控催熟、降碰伤”来做。重点注意这几类问题：

1. **采购规格**
   - 优先选已经分梳、去轴、单根或2–3根小把的货源，减少门店二次分切造成的伤口。
   - 小包装单份建议200–400克，按社区家庭一餐或两天量定规格；先小批量试销，不要一次压太多。
   - 采购成熟度控制在“青黄到微黄”，到店后能撑1–2天销售；不要采全黄或已起黑点的货做小包装。

2. **包装形式**
   - 用透气保鲜袋、开孔袋或网套+托盘，别用完全密封袋，香蕉呼吸产热、闷湿容易加速发黑和腐烂。
   - 袋上打孔或选微孔膜，避免冷凝水积聚；盒装要留透气孔，不要用深底密封盒。
   - 标签贴在袋面或托盘侧面，避免直接贴果皮；贴纸撕口处容易伤果。
   - 小把香蕉可用纸托或泡沫网套保护果指弯曲处和果柄切口，减少挤压伤。

3. **分切与伤口处理**
   - 尽量采购已分好的小把，门店少动刀；必须分切时用锋利刀具，切口平整，及时清理果轴黏液。
   - 分切后不要水洗，保持表面干燥；伤口明显的不要进小包装，改做当日特价或熟食加工。
   - 果柄切口可包一小段保鲜膜或纸胶带，减少汁液外渗和交叉污染。

4. **损耗控制**
   - 按日销量订货，小包装香蕉建议“少量多次”补货，日配或隔日配，避免后仓积压。
   - 到店先做成熟度分拣：青的放常温阴凉处，微黄的摆前场，全黄或起斑点的当天促销或转做香蕉奶昔原料。
   - 小包装不要堆叠过高，单层或两层摆放，避免下层压伤；前场避免阳光直射和空调风口直吹。
   - 建立“先进先出”和每日两次挑拣，发现黑斑、软烂、渗液立即下架，防止传染同袋。

5. **冷链和温湿度**
   - 香蕉对低温敏感，未成熟果不要放冷库低温存储，易冷害发黑；零售陈列以常温阴凉为主。
   - 后仓保持通风、干燥，避免和苹果、梨等释放乙烯多的果蔬混放，防止催熟过快。
   - 夏季高温时缩短订货周期，减少后仓停留；冬季避免靠近暖气或门口冷风。

6. **供应商与验收**
   - 要求供应商提供稳定的小把规格和成熟度分级，先签小批量试销协议，观察3–7天损耗率再放量。
   - 验收看果指饱满度、果柄新鲜度、有无机械伤和霉点；拒收水烂、冻伤、果轴发黑严重的货。
   - 记录每批到货成熟度、销量、报损量，按“损耗率超过5%–8%就调整规格或订货量”的思路复盘。

简单说：采购要小把、微黄、无伤；包装要透气、有托、不密封；陈列要少堆、阴凉、勤挑；订货要少量多次，用试销数据定包装克重和补货频率。
