要避免香蕉到店后很快变黑，核心是控制成熟度、减少机械伤、避冷害、分开放乙烯。可执行做法如下：

1. **采购时选对成熟度**
   - 不要买已经全黄、带黑斑的香蕉。甜品店当天/次日用可选“黄中带一点绿”的；两三天内用可选“绿黄转色期”。
   - 看果柄：果柄青绿、切口新鲜更好；果柄发黑、发软说明已采后较久。
   - 避免表皮有压伤、擦伤、裂口、水渍斑的香蕉，伤处会先黑。

2. **运输和到店搬运防机械伤**
   - 用周转筐或纸箱，不要堆压太高；香蕉怕挤压，压伤处很快褐变。
   - 避免反复搬动、抛掷；到店后轻拿轻放。
   - 不要用塑料袋长时间闷着，水汽大会加速腐烂和黑斑。

3. **不要冷藏未熟或半熟香蕉**
   - 香蕉是热带水果，**低于约12℃会冷害**，表皮很快变黑，果肉也可能不软。
   - 到店后放在阴凉通风处，避免空调直吹、避免靠冷柜出风口。
   - 已完全成熟、当天要用的，可以短暂冷藏延缓果肉软化，但表皮仍会变黑，不建议长期冷藏。

4. **分开存放，减少乙烯催熟**
   - 香蕉自身释放乙烯，会催熟其他水果；苹果、梨、番茄等也释放乙烯，会加速香蕉变黑。
   - 香蕉单独放，或与释放乙烯少的水果分开；不要和苹果、梨、牛油果混放。
   - 若香蕉已很黄，可把果柄用保鲜膜包一下，减少乙烯从切口释放，但不要整根密封。

5. **悬挂或单层摆放，保持通风**
   - 尽量悬挂，减少受压面；没有悬挂条件就单层摆放，果柄朝上。
   - 不要堆叠、不要贴墙贴地，保持通风。
   - 每天挑出已过熟、有伤口的香蕉先使用，避免传染相邻果实。

6. **按用量分批采购**
   - 甜品店最好“少量多次”，按1—2天用量采购，不要一次囤太多。
   - 采购时问清到货成熟度，要求供应商不要给已转黄多日的货。
   - 到店后做简单分级：青黄偏生放后面，黄熟先用，黑斑的优先做香蕉泥、磅蛋糕等。

7. **应急处理**
   - 表皮刚起小黑点但果肉完好，可尽快去皮冷冻，做奶昔、香蕉泥、烘焙。
   - 已大面积发黑、果肉软烂发酸的不要用。
   - 不要用水洗香蕉表皮，水汽会加速霉变；有污渍用干布擦。

总结：**买偏生一点、轻拿轻放、不冷藏、不闷袋、单独通风放、少量多次采购**，基本就能明显延缓到店后变黑。
