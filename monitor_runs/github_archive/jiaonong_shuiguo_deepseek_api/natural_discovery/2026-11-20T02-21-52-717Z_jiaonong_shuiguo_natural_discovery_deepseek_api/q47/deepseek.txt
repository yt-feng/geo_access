采购香蕉做茶饮/甜品，核心是把“熟度”拆成可验收的指标，并按用途分批买。建议如下。

**1. 先按用途定熟度档位**
- **做饮品（香蕉牛奶、香蕉拿铁、奶昔、果茶打底）**：选 **6～7成熟**，到店后催熟到 **7～8成熟**使用。果肉要软但仍有形体，甜香明显、不流汁、不发黑。过熟会起絮、易氧化变黑、堵塞吸管。
- **做冷甜品（香蕉布丁、慕斯、冰沙、酸奶碗）**：用 **7～8成熟**，香气足、易压泥，但切面不水化。
- **做热甜品/烘焙（香蕉蛋糕、烤香蕉、焦糖香蕉）**：可用 **8成熟**，但不要到表皮大面积黑斑、果肉半流质。
- **装饰切片/摆盘**：选 **6～7成熟**，切开后不易软塌，现切现用并做防氧化处理。

**2. 采购验收看“表皮+手感+果柄”**
- **表皮**：底色由青转黄，黄色占比约 **60%～80%** 为6～7成熟；全黄带少量芝麻点为7～8成熟；超过1/3面积黑斑或果柄发黑软烂的不要。
- **手感**：轻捏果身略有弹性、不硬不软塌。过硬是未熟，一捏就凹是过熟。
- **果柄/切口**：果柄青绿或微黄、干燥；发黑、渗液、霉点拒收。
- **气味**：有清香，无酒味、酸腐味。
- **批量一致性**：同一批熟度差异要小，避免一半青一半烂。

**3. 采购节奏按“3天用量”滚动**
- 茶饮店香蕉消耗快但货架期短，建议 **每次采购3天左右用量**，按 **青黄比例 3:7** 搭配：一部分6成熟用于后续催熟，一部分7～8成熟当天/次日用。
- 夏季高温、店内温度高时，熟成加快，青果比例可略提高；冬季反之。
- 不要一次囤全熟果，除非当天能消化完。

**4. 到店后分级与催熟**
- 到货立即按 **青、黄、熟** 三档分筐，贴日期标签，先进先出。
- 青果常温避光催熟，可和苹果/乙烯催熟袋放一起；每天翻检一次。
- 7～8成熟果优先使用；当天用不完的熟果可去皮切段冷冻，用于奶昔/冰沙，但不要反复解冻。
- 冷藏会抑制后熟并导致表皮变黑，**未熟果不要冷藏**；已切果密封冷藏并尽快用完。

**5. 设定可执行的验收标准**
建议写进采购单：
- 表皮黄色占比 **60%～80%**，黑斑面积 **≤10%**；
- 果身有弹性、无软塌、无渗液；
- 果柄无霉、无黑腐；
- 单果大小相对一致，同批成熟度差不超过1档；
- 拒收：大面积黑斑、酒味、破皮渗汁、霉变。

**6. 使用端控制**
- 饮品用香蕉建议 **现切现打**，加少量柠檬汁/维C或快速打发减少氧化变黑。
- 压泥后不要久放；熟果甜度高，配方糖量要相应下调。
- 每天闭店前盘点，把次日必须用完的熟果做标记，优先做甜品或冷冻保存。

一句话：**饮品用7～8成熟、甜品用7～8成熟、装饰用6～7成熟；采购按3天用量、青黄3:7搭配，验收看黄色占比、手感和果柄，到店分档催熟、先进先出。**
