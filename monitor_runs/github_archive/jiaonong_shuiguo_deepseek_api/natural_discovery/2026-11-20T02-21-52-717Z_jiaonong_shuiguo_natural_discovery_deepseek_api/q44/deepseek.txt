判断供应商有没有“稳定的售后响应”，不要只听承诺，要用 **历史表现 + 流程约束 + 小单测试 + 违约成本** 四件事交叉验证。对菠萝、香蕉这类生鲜尤其要看“到货后24—48小时内的问题处理能力”，因为损耗窗口很短。

可按下面执行：

**1. 先问清楚售后标准，不接受模糊承诺**
要求供应商书面写明：
- 哪些算售后：到货腐烂、黑心、压伤、成熟度不符、重量短缺、规格不符、农残/检测异常等；
- 响应时限：例如接到反馈后2小时内回复、24小时内给处理方案、48小时内补货或退款；
- 处理方式：补货、折价、退货、换货，分别适用什么比例；
- 责任边界：运输谁负责、卸货后损耗怎么算、签收后发现质量问题多久内可提；
- 对接人：固定业务+备用联系人+负责人电话，不能只有一个微信。

**判断点**：说不清时限和责任边界的，基本等于没有稳定售后。

**2. 查历史售后记录，而不是听“我们服务很好”**
让供应商提供近3个月同类商超客户的售后记录样例，至少看：
- 平均首次响应时间；
- 质量问题解决周期；
- 补货/赔付是否按约执行；
- 是否有反复出现的同类问题。

同时向同行或市场商户侧面打听：出问题时是“先扯皮”还是“先处理”。没有记录、只口头保证的，降级考虑。

**3. 用试单制造一次真实售后场景**
首单不要大，故意在合同中保留明确验收条款。到货后按标准验收，发现问题立即按约定流程提报，观察：
- 是否在承诺时间内回复；
- 是否主动给方案，而不是反复让你“拍照片再说”；
- 补货/折价是否按时兑现；
- 对接人是否稳定，是否换人失联。

**建议做2—3次小单测试**，其中至少一次覆盖周末或节假日到货，因为生鲜售后最怕非工作时间没人管。

**4. 把售后写进合同和结算条件**
可执行条款包括：
- 售后响应超时，按当批次货款一定比例扣款；
- 质量问题补货不到位的，直接从货款中抵扣；
- 连续两次售后不达标，采购方有权终止合作；
- 保留一定比例质保金或账期，作为售后履约约束；
- 固定对接人和备用联系人，变更需提前书面通知。

**5. 看供应商的货源和冷链能力**
菠萝、香蕉售后稳定与否，很大程度取决于前端能力：
- 香蕉是否有催熟/温控能力，到货成熟度是否可控；
- 菠萝是否有分级、预冷、包装和运输防护；
- 旺季是否能稳定供货，缺货时是否提前通知。

货源不稳的供应商，售后通常也不稳，因为出了问题只能拖。

**6. 给供应商做简单评分**
可按季度评估：
- 首次响应及时率；
- 售后解决时长；
- 补货/赔付履约率；
- 同类问题重复率；
- 对接人稳定性。

连续不达标的，减少采购份额或淘汰。

**最简判断口径**：愿意书面承诺时限、能提供历史售后记录、小单测试中响应和赔付兑现、合同里有违约扣款——四项都满足，才算有稳定售后响应。只有口头说“有问题随时找我”的，不算。
