直接结论：**优先“整果让顾客自己挑 + 现场代削”**，不要默认卖去皮好的。

判断依据和做法：

1. **整果自己挑最合适**  
   菠萝成熟度差异大，顾客自己挑能看外观、闻香味、按软硬，满意度更高，也减少“你帮我挑的不好”的售后争议。

2. **去皮好的只适合少量备货**  
   去皮菠萝方便，但暴露后容易失水、氧化、变味，且顾客无法判断新鲜度。可以少量现削展示，不建议大量提前去皮。

3. **最佳模式：整果挑选 + 免费/低价代削**  
   顾客挑整果，店员现场削皮、去眼、切块装盒。这样既保留挑选权，又提供便利，还能带动客单价和复购。

4. **操作建议**
   - 整果按大小/成熟度分价区，标清楚“即食”和“放1-2天”；
   - 提供“帮挑”服务，但让顾客确认；
   - 去皮果只做当天现削，标注削皮时间，当天卖不完打折或自用；
   - 削皮服务可免费，也可满额免费，作为引流手段。

所以：**主卖整果让顾客挑，辅以现场代削；去皮好的只做少量现削补充，不提前大量备货。**
