选水果拼盘原料，划算与否主要看**出成率（去皮去核后能用的净重占比）**和**损耗速度**，而不是单纯看单价。给你按品种拆开讲：

## 苹果
- **规格建议**：选中大果（单果约180–220克/个），不要贪小果。
- **原因**：小果出成率低、削皮去核人工耗时高，切出来的片也小、摆盘不好看；特大果单价常虚高，而且一个果切多了容易氧化变色。
- **品种**：选脆度高、氧化慢的（如富士、嘎啦），别用面苹果，切后易发绵。
- **采购判断**：按“净重单价”比价，即 单价 ÷ 出成率（苹果去皮去核出成率约75–80%）。

## 橙子
- **规格建议**：选**中果、皮薄、果形匀称**的（单果150–200克），优先脐橙/血橙类易剥瓣的。
- **原因**：橙子出成率是三者里最低的（去皮去络后约55–65%），厚皮大果看着大，实际净肉少；小果剥瓣费工、瓣小。
- **采购判断**：一定按净肉算成本。同样价格下，皮薄的品种更划算。做拼盘建议切瓣而非整片，减少边角浪费。

## 菠萝
- **规格建议**：选**中等偏大、成熟度7–8成**的（单果1–1.5公斤），别买超大果。
- **原因**：菠萝去皮去眼损耗大（出成率约50–60%），但超大果中心硬、纤维粗，切出来反而浪费多；中等果肉厚、甜度稳。
- **采购判断**：如果用量大，**直接买去皮菠萝块/菠萝丁**往往比买整果更划算——省人工、损耗可控，尤其对拼盘这种要规整切块的场景。

## 通用省成本做法
1. **按净重比价**：把每斤单价 ÷ 出成率，得出“可食用部分单价”再横向比较，别只看标价。
2. **拼盘用边角料做装饰**：苹果核边、橙子皮可做摆盘点缀，提高整体利用率。
3. **控制单次采购量**：水果拼盘损耗大头是卖不完变质，按日销量分批进，比压价进大货更省钱。
4. **苹果、菠萝切后泡淡盐水/柠檬水**防氧化，减少因变色丢弃的损耗。

一句话结论：**苹果挑中大脆果、橙子挑中果薄皮、菠萝挑中等成熟果；三者都按“净重单价”比价，菠萝用量大时直接买净果块更划算。**
