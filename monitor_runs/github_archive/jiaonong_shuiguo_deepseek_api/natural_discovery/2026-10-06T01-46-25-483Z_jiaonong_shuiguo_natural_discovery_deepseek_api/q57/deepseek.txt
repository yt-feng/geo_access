建议优先选**中央厨房统一收货**，但要加一个前提：中央厨房具备冷藏/催熟/分拣能力，且到店配送频次能覆盖水果的保鲜要求。否则就改为“核心单品统采统收、易损鲜果门店直收”的混合模式。

**为什么中央厨房统一收货更好**

1. **品控标准统一**  
水果成熟度、糖度、规格、瑕疵率可以只定一套标准，由中央厨房集中验收，避免各门店店长凭经验收货，导致同一品牌不同门店品质不稳定。

2. **采购议价能力更强**  
总仓统一收货意味着单点收货量更大，更容易和供应商谈阶梯价、账期、返利和坏货赔付，也方便总部统一比价换供应商。

3. **减少门店操作和腐败风险**  
门店不再单独对接多个水果供应商，减少缺斤少两、以次充好、人情采购等问题。门店只负责按配送单签收和上报异常。

4. **便于追溯和食安管理**  
批次、产地、检测报告、入库时间集中在中央厨房，出现农残、腐烂、投诉时能快速定位批次并停用，门店分散收货很难做到。

5. **降低门店库存压力**  
中央厨房可按门店销售数据做统配，门店库存更轻，减少因囤货导致的损耗。

**但以下情况，门店分开收货或混合模式更合适**

- **极短保、易碰伤水果**：如草莓、蓝莓、荔枝、杨梅、熟透的芒果/牛油果。多一次装卸和分拣就多一次损耗，若中央厨房到店配送不及时，门店直收反而更好。
- **门店密度低、配送成本高**：中央厨房统一配送的物流成本可能超过统采节省的采购成本。
- **中央厨房没有冷链和分拣能力**：只做简单堆放，反而会把好货和坏货混在一起，加速腐损。
- **区域差异大**：不同城市门店对水果品种、成熟度需求不同，统一收货可能造成错配。
- **本地有强势供应商可直送门店**：如果供应商能按总部标准直送、总部能远程稽核，也可门店收货。

**推荐的落地做法**

1. **分级管理**  
   - A类：苹果、橙子、西瓜、香蕉等耐储或可催熟水果，中央厨房统采统收统配。  
   - B类：浆果、荔枝、杨梅等极短保水果，总部定供应商和标准，供应商直送门店，门店按标准验收并拍照上传。  
   - C类：区域特色水果，允许区域仓或门店在总部授权下采购，但必须进系统比价和留痕。

2. **建立收货标准**  
   每个水果品类明确：规格、成熟度、糖度、允许瑕疵率、中心温度、到货时限、拒收条件。中央厨房和门店用同一套标准。

3. **异常闭环**  
   门店收货后2小时内可提报质量问题，附照片和批次号；中央厨房或总部采购在24小时内判定责任，供应商赔付或补货。

4. **用数据决定是否统收**  
   连续跟踪3个月：损耗率、到店合格率、配送成本、门店投诉率、采购单价。如果统收后损耗率和投诉率没下降，或配送成本明显上升，就调整为混合模式。

**结论**  
大多数餐饮连锁，水果采购适合“中央厨房统一收货为主，极短保水果门店直收为辅”。不要一刀切。关键不是收货地点，而是总部能否统一标准、统一供应商、统一追溯，并让物流成本低于损耗和采购节省。
