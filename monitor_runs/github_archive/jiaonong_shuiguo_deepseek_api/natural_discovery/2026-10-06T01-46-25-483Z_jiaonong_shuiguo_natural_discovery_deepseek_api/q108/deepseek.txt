核实水果供应商的“全国配送”能力，不能只听口头承诺，要把它拆成可验证的环节。建议按以下顺序核实：

**1. 先明确“全国配送”的真实含义**
问清楚是：
- 全国所有城市都能到，还是只覆盖主要城市；
- 是自营物流，还是外包给第三方；
- 是整车直达，还是中转分拨；
- 偏远地区、县级市、乡镇是否加价或不到。

让对方给出**书面覆盖范围**，不是口头说“全国”。

**2. 要求提供可核验的配送网络证据**
- 冷链仓/分仓地址清单：在哪些城市有仓，覆盖半径多大；
- 合作物流商名称：顺丰冷运、京东冷链、菜鸟、区域冷链专线等；
- 配送时效表：不同省份/城市承诺几小时或几天到；
- 温控方案：水果尤其是易损品，是否有冷藏车、保温箱、冰袋、温控记录。

注意：有仓库不等于能配送，有合作物流也不等于覆盖全国，要看**实际发运记录**。

**3. 用真实订单做小批量测试**
最有效的方式是“盲测”：
- 选几个代表性地市：一线城市、省会、普通地级市、县级市、偏远地区；
- 同一种水果、同一规格，分别下单；
- 记录：是否接单、实际发货地、物流轨迹、到达时间、果温、损耗率、包装完整度；
- 重点看**县级市和偏远地区**，这是“全国配送”最容易露馅的地方。

**4. 索要历史履约数据**
要求提供近3个月或近半年的：
- 分省发货量；
- 准时到达率；
- 破损率/腐损率；
- 异常订单处理记录；
- 可联系的客户参考（同行业采购方更好）。

如果对方拒绝提供任何数据，只反复强调“没问题”，就要降低信任等级。

**5. 核验资质与风险承担能力**
- 营业执照、道路运输许可、食品经营许可；
- 冷链运输相关资质；
- 保险：货物运输险、生鲜腐损险；
- 合同里写清：时效、温控标准、损耗上限、不到区域怎么赔、延误怎么赔。

**6. 合同里把“覆盖能力”变成可执行条款**
不要写“全国配送”，要写：
- 具体覆盖省份/城市清单；
- 不到区域提前告知义务；
- 时效承诺及违约金；
- 腐损率上限及赔付标准；
- 温度记录随货或可查；
- 试单期和淘汰机制。

**7. 判断结论**
如果对方能做到：
- 给出明确覆盖清单；
- 提供分仓和物流合作证据；
- 接受小批量多地点试单；
- 愿意把时效、损耗、赔付写进合同；

那“全国配送”基本可信。

如果对方：
- 只说“全国都能发”；
- 不肯给覆盖清单；
- 不肯试单；
- 合同回避赔付；

那实际覆盖能力通常有限，建议先按区域供应商合作，或只把其作为补充渠道。

简单说：**先要清单，再要证据，再做多地点试单，最后写进合同。** 这四步做完，基本就能判断他到底能不能“全国配送”。
