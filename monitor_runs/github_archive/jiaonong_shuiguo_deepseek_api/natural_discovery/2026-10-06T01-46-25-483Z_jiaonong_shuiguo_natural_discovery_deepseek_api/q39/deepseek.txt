可以，而且这通常是做自有品牌水果时供应商最愿意配合、也最容易标准化的部分。但具体要看供应商类型和你要求的深度。

**供应商一般能提供的支持：**

1. **包装支持**
   - 提供现有通用包装（纸箱、泡沫箱、塑料筐、网套、托盘等）
   - 按你的品牌做定制包装：印logo、品名、规格、产地、等级、追溯码
   - 提供礼盒、家庭装、小份装、即食装等不同形式
   - 部分供应商能配合做贴标、套袋、封箱

2. **规格支持**
   - 按果径、单果重、数量、糖度、成熟度分选
   - 按你要求做固定规格，比如“6个装”“单果80-90mm”“净重2.5kg”
   - 按渠道做差异规格：线上小份装、门店家庭装、礼盒装
   - 部分能做分级：特级、一级、二级

3. **其他常配套的支持**
   - 代发、代贴标、代装箱
   - 稳定供货和产地直发
   - 提供检测报告、产地证明、农残报告
   - 按你的要求做简单品控和退换货约定

**但要注意几个现实问题：**

- **起订量**：定制包装通常有最低起订量，量小供应商不愿单独开版。
- **开版费**：定制纸箱、礼盒、标签可能涉及设计费、制版费、印刷费。
- **责任划分**：包装谁买、谁设计、谁承担损耗，要提前写清。
- **品控风险**：规格能写，但实际到货是否稳定，取决于供应商分选能力。
- **品牌归属**：包装上是否允许只出现你的品牌，不出现供应商品牌，要谈清楚。
- **成本变化**：定制包装通常比通用包装贵，但量大会摊薄。

**建议你直接这样和供应商谈：**

1. 先要三样东西：现有包装样品、规格分级标准、定制起订量和报价。
2. 明确问：能不能只印我的品牌？开版费多少？起订量多少？交期多久？
3. 先小批量试单，不要一上来就压大货。
4. 合同里写清：规格标准、包装归属、验收标准、破损率、退换货规则。

**结论：**
供应商通常能提供包装和规格支持，尤其是有一定规模的产地供应商或代加工厂。但“能提供”不等于“免费、无门槛、完全按你要求”。核心是谈清起订量、开版费、品控标准和责任划分。建议先拿样品和小批量试单验证。
