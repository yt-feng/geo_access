判断批发档口能不能长期合作，核心不是听对方怎么说，而是看他**有没有稳定的货源组织能力**和**愿不愿意让你验证**。可以从下面几个可执行的维度去筛。

## 一、先问清楚他的"身份"，不同身份稳定性差别很大

| 类型 | 稳定性 | 特征 |
|---|---|---|
| 产地代办/经纪人 | 中等 | 手里对接多个蕉园，货源灵活但看行情，行情好时可能不优先给你 |
| 大型蕉园/合作社直供 | 较高 | 自有基地，产量可控，但通常有最低起订量和季节波动 |
| 一级批发商/进口商 | 较高 | 走量稳定，尤其进口蕉（如菲律宾、厄瓜多尔）有固定船期 |
| 二手贩子/信息中介 | 低 | 转手加价，断供风险高，尽量别作为主供应商 |

**关键动作**：问他要**产地证明、合作蕉园名称、进口的要看报关单/检疫证**。给不出来的，基本可以排除。

## 二、看这四个"硬指标"判断供货能力

1. **供货周期和频率**
   - 稳定供货的人能明确告诉你"几天一车、每周几发"。
   - 如果回答含糊（"有货就发""看情况"），说明他自己也在等货。

2. **能否保证规格和品质一致**
   - 香蕉看：条重、梳数、成熟度、有无药害/黑星病、催熟是否可控。
   - 让他提供**连续几批的实拍或样品**，对比规格是否稳定。忽大忽小=货源杂。

3. **淡旺季的供货承诺**
   - 香蕉有季节性（台风、寒害、产地换季会影响）。
   - 直接问："旺季和淡季你分别能保多少量？断的时候怎么补？" 有预案的才靠谱。

4. **价格机制是否透明**
   - 稳定供应商价格随行情浮动，但**报价逻辑清晰**（跟哪个产地价、加多少）。
   - 如果价格忽高忽低且说不清依据，多半是炒货的。

## 三、必须做的"验证动作"（别只谈不做）

- **先小批量试单**：走1-2车，看实际到货的规格、损耗率、时间准不准。
- **突击看货**：条件允许直接去他的仓库/档口看库存和走货量，眼见为实。
- **问同行**：在批发市场打听一下这个人/这家在圈子里的口碑，尤其是"断供历史"。
- **查结算方式**：要求现款现货的，可能是资金紧张或不敢赊；愿意给账期的，通常对自己的货和回款有信心（但也别盲目扩大账期）。

## 四、几个危险信号，遇到要警惕

- 报价明显低于市场价 → 要么货有问题，要么准备跑量后断供。
- 催你大量打预付款 → 资金盘/骗定金风险。
- 无法提供任何产地或资质证明。
- 样品和实际到货差距大 → 典型"样品货"套路。
- 只肯口头承诺，不肯写进合同或订单。

## 五、建议的合作方式

1. **不要只压一家**：主供应商 + 1-2家备选，分散断供风险。
2. **签简单供货协议**：写明规格、数量、时间、质量标准、违约处理。
3. **留验货和拒收条款**：到货不合格怎么处理，提前说清。

**一句话总结**：稳定供货 = 有真实产地资源 + 能说清供货节奏 + 经得起小批量试单和实地验证。只靠嘴说的，先用试单和突击看货去证伪。
