旺季断货的核心不是“供应商不给你货”，而是**你没有提前锁定优先级和违约责任**。和供应商谈的时候，重点问清楚这几类问题：

**一、保供能力**
- 旺季你每天/每周最多能给我供多少？最低能保证多少？
- 你目前还有哪些大客户？旺季会不会优先保他们？
- 如果市场缺货，我排在第几优先级？按什么规则分配？
- 遇到天气、产地减产、物流中断，你的备选货源在哪里？

**二、价格与锁价**
- 旺季价格是随行就市，还是可以提前锁价？
- 如果锁价，锁多久？超量部分怎么算？
- 报价含不含运费、装卸、损耗？到店价还是产地价？
- 如果市场价跌了，我能不能按更低的市场价走？

**三、品质与验收**
- 规格、等级、成熟度、单果重按什么标准？
- 损耗率超过多少算你的责任？怎么赔？
- 到货发现烂果、次果，是补货、退款还是折价？
- 验收标准能不能写进合同，避免口头扯皮？

**四、下单与配送**
- 每天几点前下单？多久送到？
- 旺季能不能加急？加急费怎么算？
- 配送频率能不能从隔天改成每天？
- 临时加单、减单，提前多久通知不算违约？

**五、结算与账期**
- 现结、周结还是月结？旺季能不能给账期？
- 押金、预付款要不要？能不能用预付款换优先供货？
- 如果断货导致我损失，怎么赔？赔多少？

**六、违约与退出**
- 你断货超过几次，我可以换供应商或扣款？
- 我临时取消订单，要不要赔？
- 合作期限到旺季结束，还是长期？旺季结束后价格怎么调？

**实操建议：**
不要只谈一家。旺季至少谈2-3家，明确“主供+备供”，把主供的优先供货权、锁价、赔付写进简单协议。哪怕不签正式合同，也要在微信里让对方确认关键条款，留好记录。

最该问的一句是：**“旺季你最忙的时候，凭什么优先保我？”** 对方答不上来，就别把旺季押在他一家。
