建议**优先做“小把（3–5根）”，再搭配“单根”作为补充，整袋只作为少数场景的可选项**。理由和判断方法如下：

1. **便利店卖的是“即时消费”，不是家庭囤货**
   - 便利店顾客多是临时想买、当场吃或当天吃。
   - 整袋香蕉通常更适合家庭采购，便利店场景弱，容易剩货、压库存。
   - 单根最灵活，但客单价低、损耗和人工处理成本相对高。
   - 小把既能满足“买一点”的需求，又能提高客单价，是比较平衡的形态。

2. **香蕉损耗高，包装越大风险越高**
   - 香蕉成熟快，整袋一旦卖不动，很容易一起过熟、发黑。
   - 小把可以按成熟度分批上架，卖相和周转更好控制。
   - 单根虽然灵活，但容易因顾客挑拣、碰伤造成损耗。

3. **不同门店位置，选择会不同**
   - **写字楼、地铁口、学校附近**：优先单根 + 小把。顾客多是一个人吃，追求方便。
   - **社区、住宅区附近**：小把为主，整袋可少量试销。
   - **医院、交通枢纽、景区**：单根和小把更合适，整袋基本没必要。
   - **高端社区或家庭客群明显**：可以尝试小把和整袋，但整袋要小规格，比如 5–6 根，不要做大袋。

4. **实操建议**
   - 主力：**小把 3–5 根**，定价按根折算后略高于单根，但让顾客觉得“一把刚好”。
   - 辅助：**单根**，放在收银台或即食区，方便冲动购买。
   - 试销：**整袋只做小规格、低库存测试**，比如每天 2–3 袋，看是否有人买。
   - 管理：按成熟度分“青一点/黄一点/即食”上架，减少挑拣和损耗。
   - 观察指标：看 **日销量、损耗率、客单价、复购**。如果小把损耗明显低于单根且销量稳定，就扩大小把；如果单根卖得最快，就增加单根比例。

一句话：**便利店上香蕉，主推小把，单根补位，整袋慎上；先小批量测试，再按门店客群调整。**
