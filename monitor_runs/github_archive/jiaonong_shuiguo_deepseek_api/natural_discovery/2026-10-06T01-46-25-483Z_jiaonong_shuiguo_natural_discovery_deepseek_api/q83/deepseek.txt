生鲜水果到货坏果的责任划分，核心看**坏果发生在哪个环节**、**谁承担运输风险**、**有没有约定验收标准**。实务上可以按下面判断：

**一、先看交易模式**

1. **平台自营/商家发货，快递到顾客**
   - 一般由商家对消费者承担首要责任。
   - 消费者收到坏果，通常可以直接找商家/平台要求退款、补发或赔偿。
   - 商家若认为责任在快递、仓储、产地，可再向相应合作方追偿，但不能先拿“快递问题”推给消费者。

2. **平台只提供信息撮合，实际由第三方商家销售**
   - 先由实际销售商家承担责任。
   - 平台若未尽到审核、披露、售后协助等义务，可能承担相应责任；若平台有“先行赔付”承诺，则按承诺处理。

3. **社区团购/团长自提**
   - 若团长只是代收，责任通常在供货方/平台。
   - 若团长负责选品、分拣、保管，且坏果因团长保管不当造成，团长可能承担相应责任。

**二、再看坏果原因**

1. **运输途中损坏、时效延误**
   - 若商家包邮并选择快递，通常风险在交付消费者前由商家承担。
   - 商家可依据快递合同向快递公司追偿，但消费者一般找商家。

2. **产地采摘/分拣时已坏**
   - 责任在供货商、产地或商家，属于商品质量问题。

3. **顾客收货后存放不当**
   - 比如高温放置、挤压、超过合理存放时间，责任在顾客。
   - 但商家需证明坏果是收货后造成的。

4. **水果本身特性**
   - 如熟度较高、易软易烂，若商家已明确提示且顾客接受，责任划分会结合提示是否充分。
   - 若未提示或承诺“硬果”“耐运输”，仍可能由商家担责。

**三、关键判断标准**

- **交付前风险**：一般由商家承担。
- **交付后风险**：一般由消费者承担，但质量问题除外。
- **是否及时验收**：顾客应在合理时间内开箱检查、拍照留证。
- **是否超过合理售后期限**：不同水果不同，通常越快越好。
- **是否有约定**：如“坏果包赔”“签收后24小时内反馈”等，按约定执行，但约定不能不合理免除商家责任。

**四、常见处理建议**

- 顾客：第一时间拍照/视频，保留快递面单、开箱记录，联系商家申请售后。
- 商家：先处理消费者售后，再根据物流记录、分拣记录向快递或供应商追偿。
- 平台：有先行赔付规则的按规则赔付，再向商家追偿。
- 若协商不成：可向平台投诉、12315投诉，必要时走诉讼/仲裁。

**一句话总结：**
对消费者而言，通常先找卖水果的商家/平台；商家不能简单把责任推给快递。最终责任在商家、快递、供货商还是顾客之间划分，要看坏果发生在交付前还是交付后、由谁造成、合同怎么约定。
