酒店采购水果盘原料时，供应商应保证的规格和外观标准可按以下维度约定，并写入采购合同或验收标准：

**一、规格标准**

1. **单果重量/大小分级**
   - 按品种明确单果克重范围（如苹果180–220g/个，橙子200–250g/个）。
   - 或按直径/横径分级（如西瓜、哈密瓜按横径cm；草莓按单果g）。
   - 同一批次内大小偏差一般不超过±10%。

2. **成熟度**
   - 约定可食用成熟度，要求到货时可即切即用，或指定后熟天数。
   - 如牛油果、芒果需明确“硬熟/软熟”状态。

3. **可食率/出成率**
   - 明确去皮去核后的出成率下限，例如西瓜≥60%、菠萝≥45%、橙子≥50%。
   - 对切盘用果，可要求“净果规格”，即供应商预加工后的净重。

4. **包装规格**
   - 按酒店需求分箱、分袋，如每箱5kg、每盘用量分装。
   - 标注品名、产地、等级、净重、采摘/包装日期。

**二、外观标准**

1. **色泽**
   - 具有该品种成熟时应有的正常色泽，色泽均匀，无明显青白、暗淡或褐变。

2. **形状**
   - 果形端正、匀称，无明显畸形、偏斜、双头等影响切盘美观的问题。

3. **表面**
   - 果皮光滑或具品种正常特征，无大面积疤痕、虫眼、药斑、机械伤、裂口、霉斑。
   - 允许轻微自然瑕疵，但不得影响切开后品质和摆盘外观。

4. **新鲜度**
   - 果梗/果蒂新鲜，无萎蔫、干枯、脱落（视品种要求）。
   - 无发酵味、酸败味、异味。

5. **内部品质**
   - 切开后无空心、黑心、褐变、冻伤、虫蛀。
   - 果肉细腻、汁水正常，无过度纤维化。

**三、安全与合规标准**

1. **农残与污染物**
   - 符合GB 2763《食品中农药最大残留限量》及GB 2762《食品中污染物限量》。
   - 供应商应提供批次检测报告或承诺符合标准。

2. **新鲜度与温控**
   - 冷链品种到货中心温度符合要求（如0–4℃或8–12℃，按品种）。
   - 到货剩余货架期不低于约定天数，如不少于3–5天。

3. **无禁用处理**
   - 不得使用违规催熟剂、保鲜剂、染色剂；允许使用的需符合GB 2760并明示。

**四、验收与责任建议**

- 约定抽样比例，如每批抽检5%–10%。
- 明确不合格判定：感官不合格、规格偏差超标、农残超标、新鲜度不足等。
- 约定退换货、扣款、补货时限。
- 要求供应商提供产地证明、检测报告、发票及追溯信息。

**可直接写进合同的简版条款示例：**
“供应商保证所供水果符合GB 2762、GB 2763及国家相关标准；单果规格、成熟度、色泽、果形、新鲜度符合双方确认的样品及规格书；无霉变、虫蛀、异味、机械伤及违规处理；到货剩余货架期不少于___天；不合格批次无条件退换并承担酒店损失。”
