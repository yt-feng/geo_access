水果属于生鲜品类，价格受季节、产地气候、库存和运输影响很大，所以“锁价”一般不是锁一个绝对价格，而是**锁一个定价机制或价格区间**。能锁多久，主要看品类和合作方式：

**1. 常规鲜果（苹果、橙子、梨等耐储水果）**
- 一般能锁 **1～3个月**，比较常见的是 **1个月**。
- 如果是当季大量采购、供应商有稳定库存，可以谈到 **一个产季**，比如3～6个月。
- 但通常也会附带条件：比如锁量、锁规格、锁付款周期，或者约定如果产地价波动超过一定幅度可以调价。

**2. 应季水果（荔枝、樱桃、西瓜、桃子等）**
- 很难锁长期，通常只能锁 **1～2周**，甚至按批次锁价。
- 这类水果价格一天一变，供应商一般只愿意给 **短期报价**，或者只锁“当天/当周”的价格。

**3. 进口水果（车厘子、榴莲、山竹等）**
- 一般锁 **1～2周**，或者按船期/柜期锁价。
- 受汇率、海运、关税和到货量影响大，长期锁价难度高。
- 比较常见的是锁 **一个柜** 的价格，而不是锁几个月。

**4. 连锁/大型采购**
- 如果采购量大、付款好、合作稳定，可以谈到 **季度锁价**，甚至 **半年框架协议**。
- 但通常不是完全固定价格，而是：
  - 基准价 + 浮动调整；
  - 最高限价；
  - 随行就市但给予固定折扣；
  - 价格保护条款：跌价补差、涨价共担。

**实操建议：**
- 不要只谈“锁多久”，要谈 **锁价+锁量+质量标准+调价触发条件**。
- 对耐储水果争取 **1～3个月**；对应季水果按 **周或批次** 锁。
- 可以要求供应商给 **价格上限**，而不是固定价，这样供应商更容易接受。
- 如果对方坚持短期锁价，可以改用 **阶梯价或保底价+浮动** 的方式。
- 最好在合同里写清楚：什么情况下可以调价、调价幅度上限、提前几天通知。

简单说：**耐储水果常见锁1～3个月，应季和进口水果通常只锁1～2周，量大可谈季度框架但多带浮动条款。**
