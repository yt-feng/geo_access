提前要资料的核心目标是：**能把“这批水果从哪来、有没有检测、出了问题找谁”串成一条可追溯链路**。建议至少索取以下几类，并在采购合同/订单里写明“随货提供、缺一项可拒收或扣款”。

**1. 主体与资质类**
- 供应商营业执照、食品经营许可证（或食品生产许可证，视其角色而定）。
- 若供应商是贸易商而非种植方，要求其提供上游果园/合作社/基地的资质或供货证明。
- 供货商联系人、质量负责人及应急联系方式。

**2. 批次溯源类**
- 本批次水果的产地证明、果园/基地名称与地址。
- 采收日期、包装日期、批次号。
- 运输记录或冷链记录（如适用）。
- 要求“一批一码/一批一单”，避免用旧报告覆盖新批次。

**3. 检测报告类**
- **农残检测报告**：优先要本批次或覆盖本批次的报告，而不是一年前的通用报告。
- 报告应含：样品名称、批次/生产日期、检测项目、检测方法、结果、判定依据、检测机构、报告编号、签发日期。
- 重点看是否覆盖常见高风险项目，如有机磷、氨基甲酸酯、拟除虫菊酯等；不同水果风险点不同，可要求按品类加测。
- 若供应商只有自检，要求提供自检记录；自检不能完全替代第三方报告，但可作为日常佐证。
- 第三方报告最好来自具备 CMA/CNAS 资质的检测机构。

**4. 承诺与责任类**
- 质量安全承诺书：承诺不使用禁用农药、农残符合 GB 2763 等国家标准。
- 不合格召回与赔偿条款：明确抽检不合格时退货、销毁、赔偿检测费/罚款/商誉损失。
- 同意超市或监管方抽检，并配合提供追溯资料。

**5. 可执行的采购动作**
- 首次合作：要全套资质 + 近批次第三方农残报告。
- 日常进货：每批要随货证明、批次号、自检或快检记录；第三方报告按风险定期要。
- 高风险品类或新产地：提高抽检频次，可自建快检，也可送第三方复检。
- 合同里写清：**无本批次检测/溯源资料，超市有权拒收；抽检不合格，供应商承担全部责任。**

**简单判断标准**
- 只有营业执照，没有批次检测和溯源：风险高。
- 有报告但批次对不上、日期太久：不能作为本批依据。
- 能提供“资质 + 批次溯源 + 本批检测 + 承诺赔偿”：基本可进入正常采购流程。
