三者都重要，但如果必须排序，建议是：

**食品安全 ＞ 配送准时 ＞ 价格**

理由很直接：

1. **食品安全是底线，出问题代价最大**
   - 企业食堂是集体用餐，水果一旦农残超标、霉变、腐败或来源不明，可能引发群体性肠胃问题。
   - 一旦出事，不只是赔偿，还会影响员工信任、企业声誉，甚至面临监管处罚。
   - 所以采购水果首先要看：供应商资质、检测报告、进货台账、新鲜度、储存条件。

2. **配送准时决定食堂能不能正常供餐**
   - 水果通常有固定供应时段，配送晚了会影响当天菜单、员工取餐和食堂运营。
   - 尤其高温季节，配送不及时还会加速水果损耗。
   - 因此要关注：配送频次、冷链能力、应急补货机制、迟到处理方案。

3. **价格重要，但不应排在第一**
   - 价格太低往往意味着品质、规格或新鲜度有问题。
   - 水果采购更适合追求“合理价格下的稳定品质”，而不是单纯最低价。
   - 可以比价，但要在食品安全和配送稳定的前提下比。

**实际采购建议：**
- 先设食品安全门槛：资质、检测、验收标准。
- 再定配送要求：时间、频次、冷链、缺货补送。
- 最后谈价格：按周/月询价，签框架协议，保留调价机制。
- 验收时重点看：新鲜度、规格、重量、破损率、温度。

**一句话总结：**
食品安全是一票否决，配送准时是运营保障，价格是优化项。企业食堂采购水果，应该先保安全、再保供应，最后再谈省钱。
