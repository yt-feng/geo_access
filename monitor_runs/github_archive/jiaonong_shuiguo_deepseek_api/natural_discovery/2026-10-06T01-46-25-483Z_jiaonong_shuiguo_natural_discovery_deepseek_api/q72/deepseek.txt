做稳定大客户，水果供应商要解决的核心不是“账期给多长”，而是**把账期和额度做成一套可风控、可退出、可迭代的交易结构**。下面按实操层面拆解。

## 一、先判断：你面对的是哪类批发商

不同批发商，谈判逻辑完全不同：

| 类型 | 特点 | 账期策略 |
|---|---|---|
| 超市/生鲜连锁 | 走量稳、回款有流程、但账期长 | 可给账期，但必须控额度、要合同 |
| 二级批发商 | 价格敏感、回款看下游 | 短账期+低额度起步 |
| 电商/社区团购 | 波动大、平台账期不确定 | 尽量现结或极短账期 |
| 餐饮配送商 | 相对稳定、单量中等 | 可给中等账期，绑定采购量 |

先问自己：**这个客户跑路成本高不高？他下游是谁？他有没有固定资产/门店/长期合同？** 这些决定你敢给多少。

## 二、账期怎么谈：用“阶梯”代替“一口价”

不要一上来就谈“30天还是60天”，而是设计成**与采购量、合作时间挂钩的阶梯**：

- **首月**：现款现货，或最多7天账期，额度控制在单周货值的1倍以内
- **合作1-3个月、回款正常**：账期放到15天，额度提到月采购额的50%
- **稳定合作6个月以上**：账期30天，额度提到月采购额的70%-100%
- **核心大客户**：可谈45-60天，但必须配套担保或保证金

谈判话术示例：
> “我们可以给账期，但账期和额度是跟着合作深度走的。前三个月现结或7天，回款没问题，第四个月开始给你15天，半年后可以到30天。这样对你现金流也是逐步优化的过程。”

这样既给了对方预期，又没把自己暴露在风险里。

## 三、额度怎么定：三条硬线

额度不是拍脑袋，按这三条取**最小值**：

1. **月采购额的一定比例**：新客户不超过月采购额的30%-50%，老客户不超过80%
2. **你的风险承受线**：单客户敞口不超过你月流水的10%-15%，或不超过你自有流动资金的20%
3. **对方违约成本线**：如果对方欠你这些钱，他会不会为了这点钱放弃跟你合作？额度要低于他“换供应商的成本”

举例：对方月采购20万，你月流水100万，自有流动资金50万。
- 按采购额50%：10万
- 按月流水10%：10万
- 按流动资金20%：10万
→ 首期额度定10万，账期15天，跑顺了再提。

## 四、必须配套的风控条款

光谈账期额度不够，合同里要写清楚：

- **对账周期**：每周/每半月对账一次，签字确认，避免月底扯皮
- **逾期罚则**：逾期按日万分之五到千分之一计息，或直接停供
- **停供权**：超过额度或逾期超过X天，立即暂停发货，不视为违约
- **担保措施**：大额度要求法人个人连带担保、保证金或房产抵押
- **价格联动**：账期客户单价可比现结客户高2%-5%，把资金成本转嫁出去

## 五、实操建议：先小后大，用数据说话

1. **第一单**：现结或7天，观察对方付款是否准时、是否挑剔质量
2. **第二个月**：给15天账期，额度=月采购额40%，同时每周对账
3. **第三个月**：如果回款100%准时，提到30天，额度提到60%
4. **半年后**：可谈45天，但要求对方承诺年采购量，并签年度框架协议

**关键动作**：每次提额前，查一次对方的下游回款情况、有没有新开门店、有没有被其他供应商追债。水果行业信息传得快，多问同行。

## 六、一句话总结

> 账期给的是“信任的进度条”，额度给的是“风险的止损线”。用阶梯换稳定，用合同锁底线，用停供权保命。
