这个问题要看你的**客群、损耗控制能力、人力成本**，不是单纯哪个更好。直接给结论和判断标准：

## 结论

- **社区店、客流稳定、有人手** → 主推「去皮好的」+ 保留少量整果
- **水果摊、路边店、客单价敏感** → 主推「整果，顾客自己挑」
- **多数水果店最优解**：整果堆头 + 现场代削（可选包削），别把去皮果当主力

## 三种模式对比

**1. 卖整果、顾客自己挑**
- 优点：损耗最低、不用人力、顾客有挑选掌控感，价格可以标低吸引进店
- 缺点：翻拣造成磕碰损耗，卖相变差
- 适合：人流大、走量、价格敏感的店

**2. 卖去皮好的（预包装）**
- 优点：方便、溢价高、即买即走
- 缺点：**损耗最大**——削完当天卖不掉就氧化、出水、发酸，基本报废；需要冷链或冰柜；削皮人工贵
- 适合：写字楼、商场、便利店场景，客单价高、周转快的地方

**3. 顾客自己挑 + 现场代削**
- 这是最稳的组合：整果降损耗，代削做服务溢价
- 关键是「代削」要单独收费或加价，否则白搭人工

## 怎么判断

问自己三个数：
1. **日销能不能当天清完去皮果？** 不能 → 少做或不做好去皮
2. **有没有人手现场削？** 没有 → 别承诺代削
3. **客人是图便宜还是图方便？** 图便宜→整果；图方便→去皮

## 实操建议

- 整果做**低价引流**，堆头摆放，允许挑
- 去皮果**只做少量、当天做当天清**，卖不完的别硬留
- 代削服务**明码标价**（比如整果 8 元/个，代削 +2 元）
- 去皮果一定要放**冰柜或碎冰**，不然下午就废

一句话：**整果保利润和损耗，去皮果做便利和溢价，别把去皮果当主力库存。**
