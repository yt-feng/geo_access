要固定，但不要只固定“产地”或“批次”一个维度。更稳的做法是：**固定供应商 + 固定品种/等级 + 固定加工规格 + 每批验收标准**，而不是简单地把产地锁死。

### 1. 只固定产地，风险仍然很大
同一产地不同果园、不同采摘期、不同成熟度，酸甜度、香气、出汁率都会波动。  
只固定批次也不现实：水果是农产品，批次之间天然有差异，且长期只用一个批次无法持续供应。

### 2. 更有效的采购策略
- **固定供应商，而不是只固定地图上的产地**：要求供应商有稳定基地、分选能力和冷链。
- **固定品种和等级**：比如指定品种、果径、成熟度、糖酸比范围。
- **固定加工规格**：鲜果、冷冻果浆、果茸、浓缩汁、NFC果汁，稳定性完全不同。
- **固定验收指标**：糖度、酸度、香气、颜色、出汁率、异物和农残检测。
- **允许多产地备份**：主产地 + 备用产地，避免减产、涨价或断供。

### 3. 按用途决定固定程度
- **招牌产品、核心口味**：建议固定供应商和规格，甚至做定制批次或冷冻果浆，优先级最高。
- **季节性新品**：可以接受一定波动，但要做杯测和小批量试产。
- **普通辅料水果**：不必过度锁定产地，重点控制糖酸度和出成率。

### 4. 最实用的做法
1. 先确定你真正要稳定的指标：甜度、酸度、香气、颜色、纤维感、出汁率。
2. 让供应商按这些指标供货，而不是只写“某地水果”。
3. 每批到货做快速检测和试饮，不合格就退换或调整配方。
4. 对核心产品准备 2 个供应方案：一个主供，一个备供。
5. 如果鲜果波动太大，直接改用冷冻果浆/果茸/NFC，通常比追产地更稳。

**结论：**
采购时要固定，但固定的是**供应商、品种等级、加工规格和验收标准**；产地可以作为参考，批次只能作为追溯手段。核心产品优先用标准化原料，普通产品保留一定弹性。
