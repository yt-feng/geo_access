判断的核心是：**不要只听供应商承诺，要看它有没有“把非标水果做成标准品”的加工和计划能力。** 菠萝是生鲜，天然有大小、成熟度、季节波动，稳定按规格送货本质是供应商有没有能力把波动“截留”在自己环节。

可按以下顺序判断：

**1. 先明确“规格”到底指什么**
茶饮用的菠萝通常要求：品种/产地、单果重量区间、成熟度（糖度/酸度）、是否去皮切块、块型尺寸、冷冻/冷藏/常温、包装方式。把这些写成可验收的参数，供应商才有判断标准。规格越模糊，后期越容易扯皮。

**2. 看供应结构：是自加工还是纯倒手**
- 有自有/合作加工厂，能分级、去皮、切丁、速冻、分装的，稳定性明显高。
- 纯贸易商靠市场收货再转卖，旺季能凑货，淡季或品质波动时最容易断供或降级。
- 可问：原料来自几个产区？跨产区能否接续？加工产能多少？有没有备用工厂？

**3. 看“分级能力”而不是“有没有货”**
稳定按规格送货的关键是供应商能把菠萝按重量、成熟度、糖酸度分级。
可要求：
- 提供分级标准文件；
- 看分选线或人工分级流程；
- 抽检到货批次里规格符合率、成熟度一致性；
- 问不合格品怎么处理，是退回、降级还是混装。

**4. 看计划与订单响应机制**
- 能否提前给采购计划，按周/日滚动下单？
- 最小起订量、提前期、改单截止时间是多少？
- 旺季/节假日/台风季有无保供方案？
- 是否有安全库存或锁量协议？
- 冷链和物流是自营还是外包，断链时谁负责？

**5. 用“小批量试单”验证**
先给 2–4 周的中小批量订单，按以下指标打分：
- 到货准时率；
- 规格符合率；
- 批次间糖度/成熟度波动；
- 损耗率、解冻/出汁表现；
- 异常响应速度；
- 临时加单/减单的配合度。

**6. 看合同和赔付条款是否可执行**
合同里要写清：
- 规格参数、验收方法、抽检比例；
- 不合格判定和退换货责任；
- 延迟交付、断供的违约金；
- 价格调整机制，避免旺季随意涨价；
- 质量事故追溯和赔偿。

**7. 几个危险信号**
- 只报低价，不愿提供分级标准；
- 样品很好，大货明显降级；
- 没有固定产区或加工点，靠临时收货；
- 旺季前频繁改价、改交期；
- 冷链记录不完整；
- 合同只写“按行业标准”，不写具体参数。

**实操建议：**
先定规格 → 审加工与产区 → 小批量试单 → 用准时率、符合率、损耗率打分 → 合格后再签锁量协议。对茶饮连锁来说，最好同时保留 1 家主供应商 + 1 家备用供应商，避免单一依赖。
