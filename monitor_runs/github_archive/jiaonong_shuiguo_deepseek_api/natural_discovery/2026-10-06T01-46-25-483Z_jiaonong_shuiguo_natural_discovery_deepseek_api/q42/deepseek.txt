压低采购成本但不牺牲品质，核心不是“把价格砍下去”，而是**改变谈判的筹码结构和交易条件**。先给结论，再给可执行方法。

## 一、先明确一条底线

**品质标准必须先量化，再谈价。**  
否则供应商会用“降价就降级”来反击，你也没法判断是否被坑。

建议每类水果锁定这几个指标：

- 品种/产地：如“海南妃子笑”而不是笼统“荔枝”
- 规格：单果重、果径、每箱个数
- 成熟度：糖度、着色度、硬度
- 损耗容忍：到店后可售率、烂果率上限
- 包装：箱规、净重、是否含冰瓶/托盘
- 到货时效：采摘后多少小时到仓

把这些写成**验收标准**，谈价时只谈“符合这个标准的价格”。

## 二、真正有效的压价方式（不靠硬砍）

### 1. 用“量+稳定”换价格
供应商最怕的不是低价，而是**订单不稳定**。  
你可以承诺：

- 年度/季度采购量
- 固定频次（如每周二、五到货）
- 主推档期提前锁定
- 淡季也保持基础量

换取：
- 阶梯价
- 返点
- 免运费
- 优先拿好货

话术示例：  
“这个单品我们计划做全年主推，月均X吨，能接受固定周单。你给我一个阶梯价，量到哪一档返多少，我们按季度结算。”

### 2. 用“付款条件”换价格
现金/短账期对供应商价值很大。

可谈：
- 现款现货 vs 账期30天，价差通常有空间
- 预付定金锁价
- 季度返利代替单次压价

注意：不要为了低价把账期拉太长，否则好货优先给别人。

### 3. 用“规格分级”换价格
不是所有水果都要一级果。

- 门店引流款：可接受二级果，但口感达标
- 礼盒/精品区：一级果
- 切果/果汁：可用外观次但内在合格的果

这样你能用**分级采购**压低整体成本，而不是逼供应商把一级果降价降质。

### 4. 用“产地直采/联合采购”换价格
- 绕过一批商，直接对接产地合作社或大型基地
- 多家门店联合集单，凑量拿价
- 加入区域采购联盟

但要注意：直采需要你承担分选、损耗、物流，算总账不一定便宜。

### 5. 用“竞争+备选”换价格
不要只谈一家。

- 同一单品至少2–3家合格供应商
- 报价按统一规格表提交
- 定期比价，但不频繁换供应商

目的是让供应商知道你有替代方案，而不是恶意压价。

### 6. 用“损耗共担”换价格
水果真实成本 = 采购价 + 损耗 + 运费。

可谈：
- 到店烂果率超过约定，供应商补货或扣款
- 临期/尾货打折处理
- 物流温度、到货时间写进合同

有时采购价高一点，但损耗低，总成本反而更低。

## 三、谈判时的具体步骤

1. **先定标准**：规格、糖度、损耗率、到货时间。
2. **再算总成本**：采购价+运费+损耗+人工分选。
3. **准备筹码**：量、账期、档期、长期合作、联合采购。
4. **要阶梯报价**：不要只问“最低多少钱”，要问“不同量、不同规格、不同账期分别什么价”。
5. **谈返利和罚则**：达标返点，不达标扣款/补货。
6. **小批量试单**：先试一周，验证品质和损耗。
7. **季度复盘**：用数据谈下一轮价格。

## 四、不要做的几件事

- 不要只比“单价最低”，忽略损耗和运费。
- 不要频繁换供应商，好货会优先给稳定客户。
- 不要口头约定品质，必须写进订单或合同。
- 不要一次性把价格压到供应商没利润，否则他会用次果、延迟发货找回来。
- 不要在旺季前临时压价，那时你几乎没有筹码。

## 五、一句话策略

**用稳定订单、短账期、分级采购、联合集量和损耗共担，去换供应商的阶梯价和好货优先权；品质标准量化并写进验收，价格才有意义。**
