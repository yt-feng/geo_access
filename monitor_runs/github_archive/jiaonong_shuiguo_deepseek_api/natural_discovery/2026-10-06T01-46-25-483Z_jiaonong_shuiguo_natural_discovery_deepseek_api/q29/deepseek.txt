超市和水果供应商的账期没有统一标准，但可以按供应商类型和超市规模来分。

**常见账期区间**

- **产地直采/大型供应商**：30～60天较常见，部分大型连锁超市能谈到60～90天
- **批发市场/中小供应商**：通常15～30天，甚至现款现货或7天内结算
- **进口水果供应商**：因资金占用大，常见30～45天，强势供应商可能要求预付或货到付款

**影响账期的关键因素**

1. **水果品类**：叶菜类、浆果类损耗快，供应商更倾向短账期；苹果、橙子等耐储品类可谈更长
2. **供应商议价能力**：品牌供应商、独家货源通常要求更短账期
3. **采购量**：量大且稳定，超市议价空间更大
4. **合作阶段**：新供应商一般先短账期甚至现结，合作稳定后再延长
5. **超市规模**：大型连锁超市账期普遍比中小超市长

**实操建议**

- 先了解同行账期作为谈判参照
- 不要一味压长账期，水果损耗高，供应商资金压力大，账期过长可能导致供货质量下降或断供
- 可以用"缩短账期换更低进货价"或"延长账期但接受略高价格"做权衡
- 合同里明确对账日、付款日、逾期违约责任
