评估连锁门店的水果供应商仓配覆盖，核心不是看“供应商有没有仓”，而是看它能否稳定满足你门店对**时效、损耗、成本、弹性**的综合要求。建议按下面6个维度做评估。

**1. 仓网布局与门店匹配度**
- 看供应商仓/中转仓到各城市门店的距离、配送半径、是否覆盖你所有门店城市。
- 重点看：哪些城市是直配，哪些要跨城调拨，哪些依赖第三方中转。
- 判断标准：门店越密集的城市，越应优先选择本地或区域仓覆盖；偏远、低密度城市要评估是否值得单独开线。

**2. 配送时效与频次**
- 水果品类对时效敏感，要确认：
  - 下单到到店多少小时/天；
  - 是否支持日配、隔日配、一周多配；
  - 高峰期、节假日、恶劣天气是否降频或断供。
- 评估时最好按门店分层：核心商圈店、社区店、远郊店分别看时效是否达标。

**3. 冷链与温控能力**
- 水果不是全品类都需强冷链，但叶菜、浆果、切果、热带水果等要求不同。
- 要看：
  - 仓内是否有分区温控；
  - 运输是否全程温控或保温；
  - 到店温度记录、断链处理机制。
- 没有温控数据或无法追溯的供应商，覆盖再广也要谨慎。

**4. 损耗率与履约质量**
- 水果仓配最大的隐性成本是损耗。
- 重点问：
  - 行业/同类客户平均损耗率；
  - 破损、压伤、腐烂、短少谁承担；
  - 到店验收标准是否清晰；
  - 退换货响应时间。
- 建议用“到店合格率、损耗率、缺货率、准时率”四个指标做试运行考核。

**5. 订单弹性与门店扩张支持**
- 连锁门店会新开、关停、调品类，供应商仓配要能跟得上。
- 评估：
  - 最小起订量是否适合小店；
  - 临时加单、减单、改地址是否支持；
  - 新城市开仓/开线周期多长；
  - 是否支持多温区、多品类合并配送。
- 如果供应商只接受大批量、固定路线，门店扩张时容易成为瓶颈。

**6. 成本结构与可复制性**
- 不要只看单公斤运费，要看总落地成本：
  - 干线+支线+仓储+分拣+配送+损耗+退货；
  - 是否按门店数、件数、重量、体积计费；
  - 跨城调拨是否加价；
  - 低销量门店是否被高起送价拖累。
- 可复制性是指：从一个城市复制到另一个城市时，成本和服务是否还能成立。

**实操建议：**
1. 先画一张“门店城市分布图”，标出密度、销量、时效要求。
2. 让供应商按城市给出：仓位置、配送半径、时效、频次、温控方式、损耗承诺。
3. 选2-3个代表性城市做1-2个月试运行，重点盯准时率、损耗率、缺货率、退货响应。
4. 对未覆盖或覆盖弱的城市，评估“区域供应商+本地前置仓”还是“全国供应商+第三方落地配”。
5. 最终不要只选一家，建议“核心区域主供应商+边缘区域补充供应商”，降低断供风险。

一句话判断：**能覆盖门店不等于能稳定履约；要按城市密度、时效、冷链、损耗、弹性和总成本综合打分，再用试运行数据验证。**
