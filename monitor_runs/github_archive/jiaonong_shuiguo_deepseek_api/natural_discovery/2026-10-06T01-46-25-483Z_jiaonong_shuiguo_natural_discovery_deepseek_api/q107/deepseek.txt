会，而且香蕉和菠萝的损耗风险会明显不同。核心判断是：**起订量越高，越容易把“正常损耗”放大成“滞销损耗”，但真正决定风险大小的是品种耐储性、成熟度、周转速度和销售渠道。**

可以按这几项判断：

1. **香蕉**
   - 香蕉后熟快，到货后通常还会继续变黄、起斑点。
   - 如果起订量高，但日均销量跟不上，很容易出现集中成熟、集中变黑。
   - 风险点：催熟批次集中、库温波动、挤压伤、乙烯积聚。
   - 相对可控的条件：有冷库或空调库、能分批次催熟、有加工渠道（奶昔、果切、烘焙）。
   - 高风险条件：常温堆放大批量、门店销量小、只能靠自然熟。

2. **菠萝**
   - 菠萝比香蕉耐放一些，但整果和鲜切差异很大。
   - 整果常温通风可放几天到一两周，低温可延长，但怕冷害、怕堆压。
   - 一旦切开，损耗速度会大幅上升。
   - 风险点：黑心、水心病、内部褐变、切口变质、低温冷害。
   - 相对可控的条件：整果周转、通风存放、按需鲜切、有果汁或餐饮渠道。
   - 高风险条件：一次性进大量已熟果、鲜切销量不稳定、冷藏温度不当。

3. **起订量本身怎么影响**
   - 采购价可能更低，但总损耗金额可能更高。
   - 库存天数超过安全周转期，损耗会从“可接受”变成“不可控”。
   - 高起订量还会占用冷库、货架和现金流，间接增加经营压力。
   - 如果供应商不拆批、不调货，滞销风险基本由采购方承担。

4. **建议的实操判断**
   - 先算安全库存：过去7天日均销量 × 目标周转天数。
   - 起订量不要超过安全库存的1.5倍；香蕉建议更保守，1.2倍以内。
   - 香蕉优先小批量、多频次；菠萝可适当放大，但整果和鲜切分开算。
   - 要求供应商提供不同成熟度批次，不要一次全给同熟度。
   - 设置损耗红线：比如香蕉损耗超过8%～10%、菠萝整果超过5%～8%，就要下调起订量或换渠道。
   - 如果起订量无法降低，先确认是否有二级渠道：果切、果汁、餐饮、员工福利、促销组合。

5. **结论**
   - 会。起订量太高会增加损耗风险。
   - 香蕉风险通常高于菠萝，因为香蕉后熟更快、更集中。
   - 如果销量稳定、冷链和加工渠道具备，高起订量可以摊薄采购成本；如果销量波动大、储存条件一般，高起订量很可能得不偿失。
   - 最稳妥做法：**香蕉小批量高频，菠萝可适度批量但控成熟度，所有起订量都以周转天数为上限。**
