结论：**出汁率更重要，但甜度不能太低；两者要按你的产品定位排序。**

如果是茶饮店常规采购，建议判断顺序：

1. **出汁率优先**
   - 茶饮店菠萝原料多数用于打汁、捣果肉、做果茶。
   - 出汁率低会直接导致：
     - 单杯用料增加
     - 损耗高
     - 出杯效率低
     - 成本被放大
   - 对门店来说，**稳定性、出杯效率、单杯成本**比“原料本身很甜”更关键。

2. **甜度其次，但不能差**
   - 甜度低不一定致命，因为茶饮店可以靠：
     - 糖浆
     - 果酱
     - 菠萝浓缩汁
     - 复配水果
     来调整甜度。
   - 但如果甜度太低且酸涩重，会带来：
     - 需要加更多糖
     - 风味变假
     - 压不住酸涩
     - 成本反而上升

3. **更准确的采购标准**
   不要只看“甜度”或“出汁率”单个指标，建议看：
   - **出汁率**：决定成本和效率
   - **糖酸比**：决定风味是否平衡
   - **纤维粗细**：决定口感，太粗会塞吸管、影响体验
   - **香气**：决定像不像新鲜菠萝
   - **批次稳定性**：决定门店能不能标准化出杯
   - **加工适配性**：鲜果、冷冻果肉、果泥、浓缩汁要求不同

4. **按产品类型选**
   - **做鲜果茶、捣果肉**：出汁率和果肉感更重要，甜度中等即可。
   - **做菠萝汁、冰沙**：出汁率最重要。
   - **做低成本果茶**：可用浓缩汁/果酱补甜，原料更看出汁率和香气。
   - **做高端鲜果茶**：甜度、香气、糖酸比、出汁率都要看，但出汁率仍影响成本。

简单说：  
**出汁率决定你赚不赚钱，甜度决定你好不好喝。**  
如果只能二选一，选**出汁率高、甜度中等、糖酸比平衡**的原料，甜度后期可以调，出汁率后期很难补。
