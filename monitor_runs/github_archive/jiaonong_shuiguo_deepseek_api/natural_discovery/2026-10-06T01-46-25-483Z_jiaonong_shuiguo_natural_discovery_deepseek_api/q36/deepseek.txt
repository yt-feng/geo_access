建议不要二选一，而是以**整果为主、切果为辅，按门店客流和损耗能力做组合**。判断核心不是“哪种更好卖”，而是**哪种毛利扣掉损耗后更高、周转更快**。

**直接结论**

- **社区店、中老年客群多、下班高峰家庭采购多**：整果为主，切果少量试销。
- **商圈店、写字楼店、年轻人/单人家庭多、即买即吃需求强**：切果占比可以提高。
- **没有冷藏陈列、日清执行差、客流不稳定**：少做或不做切果，优先整果。
- **菠萝旺季、单价低、走量大**：整果冲销量，切果做增量。
- **菠萝淡季、单价高、想提客单**：切果更适合做便利性和即食场景。

**怎么判断你们门店适合哪种**

1. **看损耗**
   - 整果损耗主要来自压伤、熟过头、腐烂。
   - 切果损耗来自削皮去眼、氧化、出水、当天卖不完报废。
   - 如果切果报废率超过10%—15%，基本要谨慎；超过20%，除非溢价很高，否则不划算。

2. **看人工**
   - 切果会占用员工时间，还要清洗、消毒、装盒、冷藏。
   - 如果门店人手紧，切果会拖累其他生鲜操作，不一定划算。

3. **看客群**
   - 家庭客多：整果更合适，一次买一个，回家自己削。
   - 单身、上班族、游客多：切果更合适，买完就能吃。
   - 如果门店靠近学校、医院、写字楼，切果通常更好卖。

4. **看陈列条件**
   - 切果必须冷藏陈列，最好当天切当天清。
   - 没有冷藏柜或温度不稳定，不建议做切果。

5. **算一笔账**
   - 整果：进价、售价、自然损耗、毛利。
   - 切果：进价、削皮后净重、人工、包装、冷藏、报废、售价、毛利。
   - 关键看**每公斤可售部分的毛利**，不是看整果单价或切果单价。

**比较稳妥的操作方案**

- **整果做引流和家庭装**：正常陈列，按个卖或按斤卖，保证新鲜度。
- **切果做便利和试吃**：小盒装，少量多次切，主推即食场景。
- **切果不要一次切太多**：按小时补货，卖完再切，减少报废。
- **整果和切果错位定价**：切果要有明显便利溢价，但不能高到顾客觉得不划算。
- **用数据决定比例**：连续观察1—2周，记录整果销量、切果销量、切果报废量、客单价变化，再调整。

**简单判断标准**

- 切果毛利率明显高于整果，且报废可控：提高切果比例。
- 切果只是好卖但不赚钱：只做少量试销或不做。
- 整果周转快、损耗低、家庭客多：整果为主。
- 即食需求强、年轻人多、冷藏条件好：切果可以占更高比例。

一句话：**整果保销量和家庭客，切果提便利和客单；先小批量试，按损耗和毛利决定扩不扩。**
