看你说的“更合适”，主要取决于你更怕哪一种损失：**进货价高一点**，还是**品质/断货不稳定**。

给你一个直接判断：

**小店进货量不大，通常优先找固定供应商；但前期可以先去批发市场摸底比价。**

更具体一点：

1. **如果你卖的是标品、易补货、价格透明**
   比如纸巾、饮料、常见日用品、普通零食。
   - 可以批发市场拿货，谁便宜拿谁。
   - 因为产品差异小，换供应商风险低。

2. **如果你卖的是非标品、靠品质和稳定性**
   比如生鲜、水果、熟食原料、特色小吃、服装、饰品、美妆。
   - 更适合固定供应商。
   - 小店的命脉往往是回头客，品质忽好忽坏比进价贵一点更伤。

3. **如果你刚开店、量还不稳定**
   - 先去批发市场跑几趟，了解行情价、起订量、退换货规则。
   - 同时接触 2～3 个供应商，不要只绑一家。
   - 先小批量试单，看品质、送货速度、缺货时怎么处理。

4. **如果你已经有一些稳定客源**
   - 尽快转向固定供应商。
   - 固定供应商的好处是：价格可谈、账期可谈、缺货能优先给你、品质更稳、补货更及时。
   - 但不要只找一个，至少留一个备选。

**简单决策标准：**
- 产品越标准、越比价 → 批发市场更合适。
- 产品越靠品质、越怕断货 → 固定供应商更合适。
- 小店量不大时，最优解通常是：**固定供应商为主，批发市场为辅，保留备选。**

**实操建议：**
先找 2～3 家固定供应商，分别小批量试单一个月。重点看：
- 同品质下价格差多少
- 送货及不及时
- 缺货率
- 次品能不能换
- 能不能月结或压一批货款

最后选一家主供、一家备供。批发市场只用来补急货、比价、找新品。这样既不会完全被一家供应商拿捏，也不至于每天到处找货。
