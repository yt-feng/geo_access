茶饮店控制食品安全风险时，水果供应商通常需要提供以下几类证明，具体取决于当地监管要求和采购规模：

**1. 主体资质类**
- 营业执照（经营范围含水果种植/销售/批发）
- 食品经营许可证（若供应商从事水果销售、分切等食品经营活动）

**2. 产品合格类**
- 农产品质量安全检测报告（农残检测，如有机磷、氨基甲酸酯类等）
- 若为进口水果：入境货物检验检疫证明、海关报关单
- 若为分切水果（即食类）：还需符合即食食品的微生物检测报告

**3. 源头与过程类**
- 产地证明或供货证明（种植基地信息、合作社证明）
- 承诺达标合格证（部分地区对食用农产品要求）
- 冷链运输记录（如水果需冷藏运输）

**4. 批次追溯类**
- 每批次送货单/随货同行单，注明品名、数量、产地、日期
- 检测报告应与实际供货批次对应，不能长期用一份旧报告替代

**实操建议：**
- 首次合作审核全套资质，后续每批次索取检测报告或合格证
- 建立供应商档案，留存证照复印件并定期更新
- 对高风险水果（如即食分切、进口水果）提高检测频次
- 合同中明确食品安全责任、退换货及赔偿条款

如果当地市场监管部门有具体清单要求，以官方规定为准。
