到店买香蕉，核心不是“挑最黄”，而是按你打算几天内吃完来选成熟度。可直接照下面做：

1. **当天或第二天吃**
   - 选：通体金黄、少量褐色糖斑、果柄略黄。
   - 避开：果柄发黑、整串发软、有酒味或酸味。
   - 这种最甜，但再放就容易过熟。

2. **2～4天内吃**
   - 选：黄色为主、两端或果柄带一点绿、捏起来微软但不塌。
   - 这是最稳的“到店不熟、回家刚好”的状态。
   - 如果超市冷气足、香蕉偏硬，可以买这种。

3. **4～7天吃**
   - 选：整体偏绿、黄绿相间、手感硬。
   - 不要选：已经局部发黄但果肉很软，这种可能是“催黄但内部过熟”。
   - 回家后放室温，别马上冷藏。

4. **想更准确判断**
   - 看**果柄**：果柄全绿偏生，转黄偏熟，发黑偏过熟。
   - 捏**中段**：硬=生，微软=刚好，软塌=熟。
   - 闻**果柄附近**：有清香可买，有酒味别买。
   - 看**棱角**：棱角明显偏生，圆润饱满偏熟。

5. **采购策略**
   - 不要只买一串同成熟度。最好买一串偏黄、一串偏绿，错开吃。
   - 如果超市只有很生的，买回家和苹果/香蕉放一起可加速成熟。
   - 如果已经偏熟，回家立刻冷藏。冷藏会让皮变黑，但能减缓果肉继续熟。
   - 到店太生别硬买“看起来黄但捏着硬”的，可能放很久仍发涩。

一句话：**当天吃选金黄带糖斑，三天内吃选黄中带绿微软，想放一周选绿黄硬挺。**
