生鲜平台做水果一件代发，供应商的仓配能力不是“能发货”就行，而是要能稳定支撑**多SKU、小批量、高频次、温控和时效要求高**的订单。重点看以下几项：

**1. 仓储能力**
- **多温区管理**：水果常需常温、冷藏、催熟/暂存等分区，不能混放。比如香蕉、芒果等对温度敏感，苹果、梨等可常温但怕挤压。
- **分区与动线**：收货区、预冷区、分拣区、打包区、发货区要分开，避免交叉污染和串味。
- **库存准确率**：一件代发最怕超卖。供应商需有WMS系统，能实时对接平台订单和库存，支持批次、效期、产地管理。
- **损耗控制**：水果损耗高，仓储要能按批次先进先出，有次品隔离和报废流程。

**2. 加工与包装能力**
- **分拣分级**：能按果径、糖度、外观做分级，按平台订单规格发货。
- **预冷与保鲜**：采摘后快速预冷，发货前按品类做保鲜处理。
- **包装适配**：能提供防震、透气、保温等包装方案。一件代发通常要求“一单一包”，不能混装错发。
- **贴标与面单**：能贴平台要求的标签、溯源码、快递面单，支持定制化包装。

**3. 配送与时效能力**
- **快递资源**：至少对接2-3家快递，能发全国，偏远地区也要有方案。水果对时效敏感，需明确承诺时效。
- **冷链/温控运输**：高价值或易损水果需冷链或保温箱+冰袋，能根据季节和目的地调整。
- **发货时效**：通常要求下单后24小时内出库，大促期间也要有产能保障。
- **异常处理**：破损、延迟、拒收、退换货要有明确流程和赔付标准。

**4. 系统与数据能力**
- **订单对接**：支持API/EDI对接平台，自动抓单、回传单号、同步库存。
- **轨迹回传**：能实时回传物流轨迹，方便平台和消费者查询。
- **数据报表**：能提供发货及时率、破损率、损耗率、客诉率等数据。

**5. 售后与赔付能力**
- **坏果包赔**：能按平台规则做坏果赔付，最好有图片审核和快速退款流程。
- **退换货处理**：一件代发退换货成本高，需明确是否支持、谁承担运费。
- **客诉响应**：有专人对接，能24小时内响应平台客诉。

**简单判断标准：**
如果供应商能做到：**多温区仓储 + 实时库存对接 + 24小时出库 + 全国快递/冷链 + 坏果包赔 + 系统回传单号**，基本就具备一件代发能力。否则只能做批量发货，不适合直接做一件代发。

建议平台在合作前做一次**试单测试**：选3-5个典型城市，下小批量订单，看发货时效、包装完整度、到货品质和售后响应，再决定是否长期合作。
