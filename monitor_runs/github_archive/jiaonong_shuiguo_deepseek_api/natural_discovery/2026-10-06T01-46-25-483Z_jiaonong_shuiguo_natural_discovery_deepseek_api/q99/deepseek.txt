选择下午茶水果供应商，核心看三点：**批量配送稳定性、水果损耗控制、结算和售后是否省事**。可以按下面步骤筛选。

## 1. 先明确自己的需求

- **人数和份量**：按人头算，一般每人 200–300g 净水果比较合适；夏天可偏清爽，冬天可加柑橘类。
- **配送频率**：每周几次、固定周几、几点前送到。
- **形式**：整果、果切拼盘、还是按份独立包装。办公室场景通常**独立小份或果切**更省事，但要注意冷链和卫生资质。
- **预算**：按人均 5–15 元是常见区间，具体看城市和水果品类。
- **特殊要求**：是否要开票、是否要送到楼层、是否有忌口（芒果、菠萝等易敏水果）。

## 2. 优先找哪类供应商

| 类型 | 适合场景 | 注意点 |
|---|---|---|
| 本地水果批发商/配送商 | 量大、长期、成本低 | 确认是否支持小批量分装、准时配送 |
| 生鲜电商企业购 | 中小公司、要发票、要售后 | 价格略高，但履约稳定 |
| 连锁水果店 | 临时采购、近距离 | 批量价谈判空间小 |
| 团餐/下午茶综合服务商 | 想连水果带点心一起解决 | 打包价方便，但水果品质要盯 |
| 产地直发 | 单品大量、当季水果 | 配送批次大，不适合小办公室频繁要 |

## 3. 重点核验这几项

1. **配送能力**：有没有冷链车、能否固定时段送达、迟到或漏送怎么赔。
2. **分装能力**：能否按部门/人数分袋、贴标签、独立包装。
3. **损耗规则**：坏果、压伤、不新鲜是否包退换，多久内反馈有效。
4. **报价方式**：是按斤、按份还是按箱；是否含配送费、分装费、切果费。
5. **资质**：营业执照、食品经营许可证，做果切的话还要看卫生条件。
6. **试单**：先下 1–2 次小单，观察新鲜度、准时率、售后响应。

## 4. 建议的筛选流程

1. 列出 3–5 家候选：本地配送商 + 生鲜企业购 + 一家水果店。
2. 同一标准询价：人数、频次、品类、是否果切、是否开票。
3. 各试单一次，重点看：
   - 到货时间是否稳定
   - 坏果率是否低于 5%
   - 售后是否当天处理
   - 实际人均成本
4. 选 1 家主供应商 + 1 家备用，避免单一供应商临时掉链子。

## 5. 谈判时可以争取的条件

- 固定周配，给账期或月结
- 坏果按比例退款或下次补送
- 免费分装、免费送到楼层
- 每周菜单可调整，当季水果优先
- 临时加单的响应时间

## 6. 简单判断标准

如果一家供应商能做到：**准时送到、坏果少、能分装、售后快、能开票**，即使单价贵 5%–10%，通常也比便宜但经常出问题的更值得长期合作。
