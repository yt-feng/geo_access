社区超市找每天配送的水果供应商，核心看“稳定、损耗、账期、响应”四件事。建议按下面条件筛选：

1. **配送能力**
   - 是否支持每天固定时段送达，比如早6点前到店。
   - 是否有冷链车或保温箱，尤其是夏季叶菜、浆果、切果类。
   - 节假日、雨天、凌晨能否正常送。
   - 临时补货、加单、换货的响应时间。

2. **货源与品类**
   - 是否有稳定产地或一级批发市场档口，不是临时拼货。
   - 能不能覆盖你店里的常销品：苹果、香蕉、橙子、梨、西瓜、葡萄、时令水果等。
   - 是否支持小批量多品类混配，而不是只卖大单品。
   - 能否按你的销售数据推荐每周主推品。

3. **价格与结算**
   - 报价是否含税、含运费、含装卸。
   - 是否每天随行就市，还是周价/半月价；调价有没有提前通知。
   - 账期是现结、周结还是月结，押金和退货怎么算。
   - 有没有“保底起送量”，低于起送量是否加运费。

4. **质量与损耗**
   - 到货合格率、坏果率、缺斤少两怎么赔。
   - 是否允许开箱验货、当场退换。
   - 售后时效：当天反馈当天补，还是次日补。
   - 是否提供分拣、催熟、清洗、切果等增值服务。

5. **资质与安全**
   - 营业执照、食品经营许可证、产地证明或检测报告。
   - 农残检测、进货台账是否齐全。
   - 是否有食品安全责任险。
   - 冷库、分拣场地是否卫生规范。

6. **合作稳定性**
   - 合作过哪些社区超市、便利店、生鲜店，能否实地看配送。
   - 是否只依赖单一产区，遇到天气、灾害时有没有替代货源。
   - 老板或业务员是否稳定，换人频繁容易断供。
   - 合同里是否写清违约、断供、质量赔偿条款。

7. **试合作建议**
   - 先签1个月试配，不要一上来长期锁价。
   - 每天记录到货时间、损耗率、缺货率、售后处理速度。
   - 重点看：准点率、坏果率、临时加单成功率、月底对账是否清楚。
   - 同时保留1家备选供应商，防止主供断货。

简单判断标准：  
**能每天准时到、坏果少、可退换、账期能谈、临时补货快、资质齐全**，就可以进入试合作；连续2-4周数据稳定，再签长期协议。
