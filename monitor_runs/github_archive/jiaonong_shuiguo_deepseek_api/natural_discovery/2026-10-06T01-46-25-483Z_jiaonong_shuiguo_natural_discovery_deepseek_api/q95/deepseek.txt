选学校食堂水果供应商，核心看四件事：稳定供货、食品安全可追溯、价格可控、售后能兜底。香蕉、苹果、橙子都属于高频大宗水果，重点不是找“最便宜”，而是找“最稳且可追责”的。

**一、先明确采购标准**
- 香蕉：要求成熟度可分批到货，避免同一天全熟；表皮无明显黑斑、无腐烂、无药水催熟异味。
- 苹果：要求品种、规格、单果重相对统一，脆度正常，无大面积磕碰、虫眼、蜡感异常。
- 橙子：要求酸甜比稳定、皮薄汁多、无干瘪、无霉变，单果大小分档明确。
- 通用要求：农残检测合格、可提供产地或批次信息、冷链或通风运输条件合格、损耗率可约定。

**二、优先找哪类供应商**
1. **本地一级批发商或产地直供商**：价格和新鲜度通常更好，适合苹果、橙子这类耐储水果。
2. **连锁水果配送商**：服务稳定、票据规范、售后快，适合学校这种要求票据和验收流程的单位。
3. **大型农批市场优质档口**：适合多品种小批量试单，但要注意其资质和检测能力。
4. **产地合作社或基地**：适合橙子、苹果等单品大批量采购，但合同、检测、物流要写清楚。
不建议只找一家，也不建议只找最便宜的流动摊贩。

**三、供应商准入要看哪些材料**
- 营业执照、食品经营许可证或相关流通资质。
- 水果农残检测报告，最好能按批次提供。
- 供货案例，尤其是学校、机关、企业食堂案例。
- 仓储和运输条件说明。
- 开票能力，能否开增值税发票或合规票据。
- 食品安全责任承诺和赔付方案。

**四、比价不要只看单价**
要算“可食率成本”：
- 单价 ÷ 可食率 = 实际成本。
- 还要加上损耗率、配送费、退换货成本。
- 例如便宜但损耗高、大小不均、催熟过度的香蕉，实际成本可能更高。
建议按周或按月询价，设定参考价，避免单一供应商长期锁价。

**五、合同和验收要写清楚**
- 品种、规格、单果重、成熟度、产地、批次。
- 到货时间、频次、最低供货量。
- 验收标准和不合格处理：退货、换货、扣款、暂停供货。
- 农残超标或食品安全事故的责任和赔偿。
- 价格调整机制，比如随行就市但需提前书面确认。
- 账期和结算方式。
- 备用供应商机制。

**六、实操建议**
1. 先选 3—5 家供应商试供 2—4 周。
2. 每次到货按批次验收，记录重量、损耗、口感、投诉。
3. 每月做一次评分：质量、价格、配送、售后、票据。
4. 保留 1—2 家备用供应商，防止断供。
5. 香蕉可要求“青熟分批”，苹果橙子可要求“分规格装箱”，减少食堂二次分拣。

**简单判断标准：**
能提供资质和检测、能稳定按批次送货、能接受验收扣款、能开票、出问题能当天处理，就比单纯报价低但不可追溯的供应商更值得选。
