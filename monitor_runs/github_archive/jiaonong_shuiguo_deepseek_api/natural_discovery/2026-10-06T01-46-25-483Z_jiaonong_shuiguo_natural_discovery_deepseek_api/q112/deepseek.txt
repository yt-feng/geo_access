水果采购合同里，**坏果率超过多少可以要求赔付**，法律上没有统一固定比例，主要看合同约定；如果合同没写，通常按行业习惯、验收标准和实际损失来主张。

实务里可参考这个判断：

1. **合同有约定：按合同执行**
   - 常见约定：
     - 坏果率≤3%～5%：正常损耗，不赔；
     - 超过5%～10%：按超出部分扣款或换货；
     - 超过10%～20%：可要求退货、换货、赔偿；
     - 超过20%～30%：可拒收、解除合同并索赔。
   - 具体比例取决于水果品种、运输距离、季节、包装方式。

2. **合同没约定：可这样主张**
   - 坏果率超过 **5%**：就可以先提出扣款、补货或协商赔偿。
   - 坏果率超过 **10%**：通常已明显超出合理损耗，可要求较明确赔付。
   - 坏果率超过 **20%**：一般可认为货物质量不合格，可拒收、退货并要求赔偿实际损失。

3. **赔付怎么算更合理**
   - 按坏果部分货值赔付：  
     `赔付金额 = 采购单价 × 坏果数量`
   - 按超出约定比例部分赔付：  
     `赔付金额 = 采购单价 × 总数量 ×（实际坏果率 - 约定可接受坏果率）`
   - 还可加上：分拣费、运费、冷藏费、误工费、二次运输费等实际损失。

4. **建议写进合同的条款**
   - 明确验收时间：到货后几小时内验收。
   - 明确抽样方法：抽几箱、怎么取、谁见证。
   - 明确坏果定义：腐烂、发霉、压伤、冻伤、破裂、异味等是否算。
   - 明确阶梯赔付：
     - 坏果率≤5%，不赔；
     - 5%＜坏果率≤10%，按超出部分货值扣款；
     - 10%＜坏果率≤20%，按超出部分双倍扣款或换货；
     - 坏果率＞20%，可拒收并赔偿实际损失。
   - 明确争议检测：送第三方或双方共同抽样确认。

简单说：**合同有约定就按约定；没约定时，超过5%就可以谈赔付，超过10%通常较有依据，超过20%一般可拒收并索赔。** 最稳妥的是在合同里写清“坏果率分级处理”和赔付计算方式。
