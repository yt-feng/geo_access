这四个指标都要关注，但**优先级取决于你的超市定位和客群**。如果只能排一个顺序，通常建议：

**切果损耗 > 甜度 > 大小 > 外观**

原因是超市卖菠萝最大的利润杀手不是“不好看”，而是**切开卖不完、坏得快、损耗高**。

具体拆开看：

1. **切果损耗**：最关键
   - 如果你做鲜切菠萝、菠萝杯、拼盘，损耗直接决定毛利。
   - 要关注：出肉率、黑心/水心病比例、切后氧化、冷藏后变味、当天卖不掉的比例。
   - 建议：先小批量试切，记录“进货斤数—切出可售斤数—报废斤数”，算出真实出肉率和损耗率。

2. **甜度**：决定复购
   - 菠萝不甜，顾客买一次就不买了，尤其是鲜切。
   - 但超市现场很难逐个测糖，实操上可看品种、产地、季节、成熟度。
   - 建议：优先选稳定品种，要求供应商给糖度范围；到货抽测，低于标准就降级做特价或加工，不要按正价鲜切卖。

3. **大小**：影响定价和场景
   - 大果适合家庭整颗买，小果适合一人食、鲜切杯。
   - 大小不整齐会增加分级、称重、陈列难度。
   - 建议：按大小分级定价，别混卖；鲜切优先用大小均匀、出肉率稳定的果。

4. **外观**：影响第一眼购买，但不是核心利润指标
   - 外观好能引流，但外观好不等于甜、不等于出肉率高。
   - 建议：外观用于陈列和分级，不要只看外观就定高价。

**实操判断标准：**
- 做整颗卖：甜度、外观、大小更重要，损耗相对次要。
- 做鲜切/果切：切果损耗第一，甜度第二，大小第三，外观第四。
- 如果损耗超过 25%～30%，通常说明选品、成熟度或加工流程有问题，要先解决损耗。

一句话：**超市卖菠萝，先算切果损耗，再保甜度，然后用大小做分级，最后用外观做陈列。**
