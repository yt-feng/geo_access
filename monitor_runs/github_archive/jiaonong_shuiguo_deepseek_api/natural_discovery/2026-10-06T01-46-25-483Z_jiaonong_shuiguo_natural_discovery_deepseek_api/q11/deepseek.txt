会的，但影响大小取决于你的销售方式和客户群体。核心不是“大小不一样”本身，而是**大小不一致带来的分级、定价和损耗问题**。

**1. 对销售的主要影响**

- **散卖/论斤卖**：影响相对小。顾客挑大个的多，小个的剩到最后，容易压货、变黑、损耗增加。
- **整箱/整件卖**：影响较大。顾客会觉得“一箱里有大有小，不划算”，复购和口碑会受影响。
- **礼盒/精品果切**：影响最大。大小不齐会显得不专业，必须分拣后再用。
- **水果捞、榨汁、餐饮供货**：影响较小，甚至更适合。这类渠道对大小要求低，更看价格和成熟度。

**2. 实际操作建议**

- **进货时先问清楚**：这箱是“统货”还是“分级货”。统货便宜但大小混，分级货贵但整齐。
- **到店后必须分拣**：至少分成大、中、小三级，不要混在一起卖。
- **分级定价**：
  - 大果：正常价或略高价，适合散卖、礼盒。
  - 中果：主力价，走量最快。
  - 小果：降价、做果切、榨汁、水果捞，或搭配促销。
- **整箱卖要提前说明**：如果按箱卖，最好标注“统货，大小混装”，避免顾客预期落差。
- **控制采购比例**：如果你主要做精品散卖，少进统货；如果做果切、榨汁、团购，可以多进统货压成本。

**3. 判断标准**

如果大小差异在**肉眼可接受范围内**，比如同一品种正常大小波动，影响不大。  
如果出现**明显大小两级分化**，比如一半大一半小，那就必须分拣，否则小果会拖累整体销售和利润。

简单说：**大小不一不会直接卖不掉，但会逼你多做一道分拣和定价的功夫。不做分级，损耗和客诉就会上来。**
