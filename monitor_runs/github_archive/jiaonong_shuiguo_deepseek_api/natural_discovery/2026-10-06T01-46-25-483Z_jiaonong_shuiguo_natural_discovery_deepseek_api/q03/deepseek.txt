夫妻店第一次找水果供货商，试单的核心目标是：**验证品质稳定性、算清真实损耗、确认供货配合度**，而不是一上来压到最低价。建议按下面做：

**1. 先确定试单量**
- 香蕉、苹果、橙子各拿 **1箱~2箱**，不要整批压。
- 香蕉本身损耗和成熟度波动大，第一次只拿 **1箱** 观察。
- 苹果、橙子相对耐放，可各拿 **1~2箱**，但也要分批次卖。
- 试单周期建议 **3~7天**，看卖相、口感、损耗、顾客回头。

**2. 试单前先问清关键条件**
不要只问“多少钱一斤”，要问：
- 是否含箱皮、筐皮、冰瓶、纸箱重量？是不是**净重**？
- 是否送货上门？起送量多少？配送费怎么算？
- 坏果、烂果、冻伤、压伤怎么赔？是**包退包换**还是下批补？
- 香蕉是青蕉还是催熟蕉？能不能按你的销售速度分次催熟？
- 苹果、橙子是什么规格、产地、等级？大小是否均匀？
- 结款方式：现结、周结还是月结？有没有压货？

**3. 到货必须当场验**
重点看：
- **香蕉**：青度是否适合你店客流，有没有黑斑、裂口、水烂；催熟后是否很快发黑。
- **苹果**：大小是否均匀，有没有碰伤、虎皮、发面、内部褐变。
- **橙子**：皮是否新鲜，手感是否过软，有没有干疤、烂点、酸度是否稳定。
- 称重：抽一箱去箱去皮称净重，看和供应商说的差多少。
- 拍照留证：到货、开箱、坏果都拍，方便后面谈赔付。

**4. 试单期间重点记录**
建议简单记一张表：
- 进货价、净重、实际成本/斤
- 到货坏果率
- 3天、5天、7天损耗
- 售价、每天卖多少
- 顾客反馈：甜不甜、酸不酸、大小是否接受
- 供应商响应速度：补货快不快、售后推不推

**5. 判断是否继续合作**
可以继续合作的标准：
- 实际净重和报价一致，没有靠箱皮压秤。
- 坏果率能接受，售后愿意补。
- 品质稳定，不是这次好下次差。
- 送货准时，临时补货能响应。
- 你算完损耗后还有合理毛利。

如果出现这些，建议换：
- 报价低但箱皮重、净重少。
- 坏果多还推责任。
- 香蕉催熟后卖不动，损耗全算你的。
- 送货经常迟到，缺货不提前说。

**6. 夫妻店最稳的试单策略**
- 不要只试一家，找 **2~3家** 同时小量试。
- 同一品种分两天到货，对比新鲜度和催熟效果。
- 先谈“小批量、多频次”，跑顺后再谈账期和价格。
- 香蕉可以少量多次，苹果橙子可适当囤，但别超过你3~5天销量。
- 第一次合作尽量 **现结或小额定金**，不要一上来压大账期。

一句话：**第一次试单不是比谁便宜，而是比谁让你少烂货、少压秤、少扯皮。** 先把净重、损耗、售后这三件事验清楚，再决定长期合作。
