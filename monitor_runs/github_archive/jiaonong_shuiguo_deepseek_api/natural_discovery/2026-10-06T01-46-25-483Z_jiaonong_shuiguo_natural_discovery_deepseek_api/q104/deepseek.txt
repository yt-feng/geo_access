单位采购水果遇到到货品质不一致，核心是把“验收标准前置 + 到货留证 + 分级处理 + 售后闭环”四件事做扎实。下面按可执行步骤说明。

## 一、采购前先把标准写进合同/订单

到货扯皮，多半是事前没写清楚。下单时至少明确：

1. **品种、规格、等级**：如“红富士苹果，单果直径80-85mm，一级果”。
2. **成熟度、新鲜度**：如“香蕉到货成熟度7成，无黑斑”。
3. **允许的次品率**：如“外观瑕疵、软化、碰伤合计不超过5%”。
4. **包装与运输要求**：如“冷链运输，箱内无挤压”。
5. **验收时限和方式**：如“到货2小时内现场验收，抽检比例不低于10%”。
6. **售后条款**：不合格如何退换、补货时限、扣款或折价比例。

## 二、到货验收怎么做

### 1. 当场验收，别先签收再慢慢看
- 送货单、订单、合同三方对照，确认品种、数量、规格一致。
- **先验后签**。如果必须签收，在签收单注明“外观未细验，保留质量异议权”，并拍照。

### 2. 抽检要有代表性
- 按批次、按箱、按筐抽检，不能只翻最上面一层。
- 建议抽检比例：批量小的抽10%-20%，批量大的按上、中、下、边角多层抽样。
- 重点看：大小是否均匀、有无腐烂霉变、碰伤压伤、成熟度是否一致、有无异味。

### 3. 分三类处理
- **合格**：正常入库。
- **轻微不一致**：如少量偏小、成熟度略差，可折价接收，写清折价金额。
- **严重不合格**：如腐烂、霉变、品种不符、数量短缺，拒收或要求整批退换。

### 4. 留证要完整
- 拍全景照、开箱照、问题果特写、称重或计数照片。
- 保留送货单、聊天记录、通话录音、验收单。
- 最好让送货人现场确认问题并签字；对方不签，就在验收单上写明“送货人拒绝签字”，并拍照或录像。

## 三、售后怎么谈、怎么闭环

### 1. 当天反馈，书面提出
发现问题当天就通知供应商，别拖。用微信、邮件或书面函件写清：
- 订单号、到货时间、批次；
- 问题类型和数量/比例；
- 你的处理要求：退货、换货、补货、折价、扣款；
- 要求回复时限，如“24小时内答复，48小时内补换”。

### 2. 处理方式按严重程度选
- 少量瑕疵：折价接收，按比例扣款。
- 部分腐烂或规格不符：只退不合格部分，合格部分正常结算。
- 整批不符：整批退回，要求重新发货，运费由供应商承担。
- 影响使用：如食堂供餐，可要求紧急补货并保留索赔权利。

### 3. 扣款或索赔要有依据
- 优先按合同约定的次品率、折价标准执行。
- 合同没写，就按实际不合格数量、市场价差、造成的额外成本协商。
- 协商不成，保留证据走投诉、平台仲裁或法律途径。

### 4. 形成记录，反向管理供应商
- 每次验收和售后都登记：到货日期、供应商、合格率、问题、处理结果。
- 连续多次不合格的供应商，列入观察名单或减少订单。
- 把高频问题写进下次合同，比如“腐烂率超过3%整批退”。

## 四、一个简单可用的验收流程

1. 到货前：核对订单标准。
2. 到货时：对照订单，抽检拍照，分合格/折价/拒收。
3. 验收后：填写验收单，送货人签字，不合格当天书面通知。
4. 售后：按合同要求退换补或折价，限时闭环。
5. 归档：留存证据，记录供应商表现。

**一句话原则：标准写在前面，问题拍在当场，处理落在书面，结果记进档案。** 这样既能减少扯皮，也能让售后有据可依。
