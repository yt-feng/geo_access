超市采购水果时，供应商通常需要提供的检测报告或进货证明，主要取决于**水果品类、是否进口、超市自身验收要求、当地市场监管要求**。一般可按下面几类准备：

1. **营业执照**
   - 供应商合法经营主体证明。
   - 如果是农产品生产者个人，可能提供身份证明、产地证明或合作社证明。

2. **食品经营许可证/食品生产许可证**
   - 预包装水果制品、果切、果汁等通常需要。
   - 初级农产品如整箱苹果、橘子等，各地要求不完全一致，但超市通常会要求供应商具备相关经营资质。

3. **食用农产品进货凭证**
   - 包括供货单、销售单、发票、收据、采购合同等。
   - 应能体现：品名、数量、单价、进货日期、供应商名称、联系方式。
   - 超市需要凭此建立进货查验记录。

4. **产地证明或合格证**
   - 常见形式：
     - 食用农产品合格证
     - 产地证明
     - 合作社/基地出具的供货证明
   - 对散户供应商尤其常见。

5. **检测报告**
   - 一般为第三方检测机构出具的合格检测报告，或供应商自检报告。
   - 常见检测项目：
     - 农药残留
     - 重金属
     - 霉菌毒素（如适用）
     - 食品添加剂（如水果制品）
     - 微生物（果切、即食水果）
   - 超市通常要求：
     - 同一品种、同一产地、同一批次对应报告
     - 报告在有效期内
     - 有CMA/CNAS资质更稳妥

6. **进口水果额外材料**
   - 海关进口货物报关单
   - 入境货物检验检疫证明
   - 中文标签或中文标识
   - 跨境电商或口岸相关证明视渠道而定

7. **承诺达标合格证/追溯凭证**
   - 越来越多地区要求食用农产品带证上市。
   - 可以是纸质或电子追溯码。

8. **其他可能要求**
   - 无公害、绿色、有机认证证书，如超市采购对应认证产品。
   - 地理标志、品牌授权等，视产品而定。
   - 冷链运输温度记录，适用于部分易腐水果。
   - 果切类还需符合即食食品要求，提供微生物检测、加工环境证明等。

**实务建议：**
- 如果是**整果初级农产品**：重点准备营业执照、食用农产品合格证/产地证明、进货单、农残检测报告。
- 如果是**进口水果**：重点准备报关单、入境货物检验检疫证明、进货凭证。
- 如果是**果切、预包装水果**：按预包装食品或即食食品管理，资质和检测要求更严。
- 最稳妥做法：直接向目标超市的采购或质检部门索要《供应商准入资料清单》，按其清单准备。

**一句话总结：**
超市采购水果，供应商通常至少要提供：营业执照、相关经营许可、进货凭证、产地/合格证明、农残等检测报告；进口水果还要报关和检验检疫证明；果切等加工水果要求更严。
