# 多门店、小单量超市的水果供货模式建议

## 先说核心判断

你的痛点本质是**「分散小批量 + 高频补货 + 损耗敏感」**，所以不适合传统大批发/产地直发的重模式，而应该走**「中间层集散 + 小批量高频」**的路线。

## 推荐的几种模式（按优先级）

**1. 区域水果集散商 / 二级批发商（最推荐起步）**
- 这类供应商从一级市场或产地拿货，再拆零配送给中小超市。
- 你能拿到：起订量低、可多品种拼车、次日达。
- 代价：单价略高（比产地直发高10%~20%），但省去损耗和资金压力。
- 适合：门店10~50家、单店日销水果几百到几千元。

**2. 本地批发市场自采 + 第三方配送**
- 自己或雇人在当地农批市场选货，用货拉拉/城配车队分送各店。
- 优点：选品灵活、能看货控质量。
- 缺点：需要1~2个懂水果的人，人力成本和管理复杂度上升。
- 适合：门店集中在一个城市、你有采购能力。

**3. 水果供应链平台（如美菜、蜀海类、区域生鲜B2B）**
- 线上下单、按店配送，部分支持一日一配。
- 优点：省心、有系统对接、账期相对规范。
- 缺点：品质波动、爆品常缺货、议价空间小。
- 适合：想快速统一供货、不想自建采购团队。

**4. 产地/合作社直发（谨慎用）**
- 只对**1~2个爆款单品**（如某产地苹果、柑橘）做直发，其余走集散商。
- 全品类直发对你这种小单量门店是灾难：起订量高、损耗大、资金占用重。

**5. 联采/门店联盟集单**
- 联合其他非竞争超市一起凑量，向产地或一级商谈价。
- 适合：你有一定门店规模或同行资源，能显著降本。

## 关键运营建议

- **分级供货**：爆款单品走直发/集散商锁价，长尾品类走本地批发市场灵活补。
- **一日一配或隔日配**：小批量高频，降低门店库存和损耗。
- **统采统配 + 门店要货制**：总部集单，按店分拣配送，避免各店乱采。
- **损耗对赌/退货条款**：跟供应商谈清楚残次品退换比例，水果这行损耗是利润杀手。
- **先跑通1个城市**：多门店但分散时，配送半径决定成本，别跨城硬铺。

## 一句话结论

**起步阶段找「区域水果集散商 + 本地批发市场补货」的组合最稳；规模上来后再对爆款做产地直发、对同行做联采集单。** 不要一上来就全品类产地直发。
