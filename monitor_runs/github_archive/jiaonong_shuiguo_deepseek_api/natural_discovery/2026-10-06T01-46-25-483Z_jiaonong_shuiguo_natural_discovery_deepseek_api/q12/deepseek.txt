水果店采购菠萝，核心不是“买最熟的”，而是**按预计售卖周期倒推采购熟度**：到店后还能放几天，就买对应成熟度的果。菠萝损耗主要来自两点：一是过熟后很快黑心、出水、发酒味；二是太生卖不动，切开酸、口感差，顾客不回购。

下面给你一套可现场判断的做法。

**1. 先定采购熟度：按销售速度分三档**

- **当天到货、2～3天内能卖完**：可采**七八成熟**，果皮由青绿转黄绿，底部开始泛黄，香味刚出。
- **常温要卖4～5天**：采**六七成熟**，整体偏青绿，只有果眼间隙微黄，几乎无香味。
- **要放一周左右或天气热、走货慢**：采**五六成熟**，青绿为主，硬，无香味。到店后分批催熟或按成熟度分区摆放。

夏天温度高，熟度要往生一点采；冬天或冷柜条件好，可以适当熟一点。

**2. 现场判断菠萝熟度的实用指标**

- **看底色**：不是看果眼，而是看果皮基部到中部的底色。由青转黄绿，再到金黄，越黄越熟。全青通常生，全黄且发暗通常过熟。
- **闻香味**：靠近果柄或果底闻。没有香味=生；淡淡清香=合适；浓甜香、酒味=过熟，损耗风险高。
- **按硬度**：用手轻按果身，硬得像石头=生；略有弹性=合适；明显软塌、局部凹陷=过熟或内部开始坏。
- **看果柄和底部**：果柄新鲜青绿、切口不干黑，说明采摘不久；底部发黑、渗汁、长霉，直接不要。
- **看果眼**：果眼扁平、间隙大，通常成熟度较高；果眼尖突、排列紧，偏生。但这不是唯一标准。
- **掂重量**：同样大小，偏重的水分足、果肉饱满；明显轻的可能失水或黑心。

**3. 采购时最好做的分级动作**

不要整批一个熟度。建议：

- **70%采生一点**，用于后续几天卖。
- **30%采熟一点**，到店即可切果、做果切或促销。
- 到店后按成熟度分筐：青的放常温，黄的优先摆面，过熟的立刻切果或打折。
- 每天翻筐，把开始黄、开始香的挑出来前置销售，避免整批同时熟。

**4. 避坑要点**

- 不要只看叶子绿不绿，叶子绿不代表果肉没熟或新鲜，很多是运输后状态。
- 不要买“已经全黄+浓香+底部渗汁”的，除非当天能切完。
- 不要一次全采同一熟度，除非你能当天卖完。
- 气温超过28℃时，菠萝后熟很快，采购熟度至少降一档。

**5. 简单执行标准**

你可以直接用这个口诀：

**青硬无香→放；黄绿微香→卖；金黄浓香→切；发软酒味→折价清。**

如果只能记一个判断：**采购时选“果底开始转黄、淡淡香味、手按略弹”的，量控制在2～3天能卖完；其余采青绿硬果，到店分批催熟。**这样通常能把菠萝损耗压下来。
