结论先说：**在商超水果这个品类里，通常“损耗低”对最终毛利的影响更大，而且往往比采购价低几个百分点更关键。**  
但如果你的采购价已经高到明显偏离市场，那“价格低”会先决定你有没有毛利空间。

可以拆成三个层面判断：

**1. 水果毛利的核心公式**
最终毛利 ≈ 销售额 × 毛利率 − 损耗金额 − 运营费用  
其中损耗不是只损耗“成本”，它会同时吃掉：
- 采购成本
- 物流/仓储/人工分摊
- 本来可以卖出去的销售机会

所以损耗率每上升几个点，对毛利的杀伤通常比采购价便宜几个点更直接。

**2. 为什么“损耗低”通常更重要**
水果是高频、短保、非标品。  
同样一批货：
- 采购价低 5%，可能只多出 5% 的成本优势；
- 损耗从 15% 降到 8%，可能直接多出 7% 的可售货量，而且减少报损、折价、清仓。

现实中，很多门店水果毛利做不起来，不是进货贵，而是：
- 订货不准
- 陈列过量
- 温控差
- 先进先出没执行
- 晚上不敢折价清货
- 把损耗算成“正常”，没有追责

这些都会让低采购价带来的优势被损耗吃掉。

**3. 但采购价低也不能忽视**
如果采购价高得离谱，比如比周边竞品高 10%—15%，那再低的损耗也很难救回毛利。  
采购价低的价值在于：
- 给你定价空间
- 让你敢做促销
- 让你在损耗发生时还有缓冲

所以更准确的判断是：

**采购价决定毛利的上限，损耗决定毛利的实际兑现率。**  
在商超水果里，大多数情况下，**损耗低比价格低更能决定最终毛利**。

**实操建议：**
1. 先算“综合毛利”，不要只看进价。  
   综合毛利 = 售价 − 采购成本 − 损耗成本 − 折价清仓损失。
2. 重点盯三个指标：  
   - 损耗率  
   - 生鲜折价率  
   - 库存周转天数
3. 如果只能优化一个，优先优化损耗。  
   因为损耗改善通常不需要重新谈供应链，靠订货、陈列、温控、出清就能见效。
4. 如果损耗已经很低，比如叶菜/浆果控制在 5%—8%以内，再去死磕采购价，边际收益才明显。

一句话：**低采购价让你“可能多赚”，低损耗让你“真的赚到”。在水果品类，后者通常更影响最终毛利。**
