能，但通常不是“自动给”，而是取决于你的采购量、合作稳定性和谈判方式。水果供应商常见的周末促销支持有三类：

1. **价格支持**
   - **短期特价**：针对某个单品，周末给你比平时低 5%～15%，或直接给一个“周末专供价”。
   - **阶梯返利**：周末进货满多少件/多少金额，返现金、返货或下批抵扣。
   - **爆品补贴**：供应商主推的应季水果，可能愿意贴一部分差价，让你做引流价。
   - **临期/清库支持**：如果是耐放或接近成熟高峰的货，可能给更低价格，但品质和损耗要自己控。

2. **物料支持**
   - 包装箱、手提袋、保鲜膜、标签、海报、价签、展台围挡等。
   - 有些供应商会提供印有品牌或产地信息的宣传物料。
   - 试吃盒、试吃签、一次性手套、托盘等，也可能给。
   - 如果是品牌水果，可能提供品牌海报、吊旗、堆头物料。

3. **其他支持**
   - 账期放宽：周末进货，允许下周结款。
   - 优先供货：周末给你留好货、大果、礼盒货。
   - 退换支持：卖不完或品质不达标时，允许部分退换。
   - 联合活动：供应商出部分费用，你出场地和客流，做“产地直供周末特卖”。

**能不能拿到，主要看这几点：**
- 你平时采购量是否稳定、是否长期合作。
- 周末促销是否主推他的货，能不能帮他走量。
- 你是否愿意做堆头、海报、朋友圈/社群宣传。
- 你谈的是“单品爆量”还是“全店促销”。单品爆量更容易拿到支持。
- 是否提前谈，而不是周五下午临时要货要价。

**比较实用的谈判说法：**
“这周末我准备把某某单品做成门店爆款，预计进 X 箱，做堆头+社群推广+试吃。你这边能不能给个周末专供价，或者支持点海报/包装/试吃物料？如果效果好多，后面我固定每周推。”

**注意：**
- 价格支持最好写清楚：是直接降价、返货还是下批抵扣。
- 物料支持要问清是否收费、是否要回收、是否带供应商品牌。
- 不要只压价，也要给供应商看到销量和曝光。
- 如果供应商不给支持，可以换一家问，或者用“组合采购”换支持。

简单说：**一般能谈，但前提是你能给量、给稳定预期、给推广资源。** 小水果店临时要支持，难度较大；长期合作、周末固定做爆品，最容易拿到价格和物料。
