判断哪个规格更容易出货，核心看**周转速度**，而不是单纯看利润高低。批发场景下，可执行的做法是：

1. **按规格分组记录**
把菠萝按常见规格分：小果（约 800g-1kg）、中果（1-1.5kg）、大果（1.5kg 以上），或按箱规分。每天记录每个规格的：
- 进货量
- 出货量
- 剩余量
- 当天实际成交价

连续记 7-10 天，哪个规格“当天进、当天走”的比例最高，哪个就更容易出货。

2. **看三个硬指标**
- **动销率**：某规格日出货量 ÷ 当日进货量。越高越容易出货。
- **周转天数**：某规格库存 ÷ 日均出货量。越短越好。
- **补货频率**：如果某个规格隔一两天就需要补，说明下游拿货勤。

3. **观察下游客户结构**
- 水果店、社区团购：通常中果最好走，大小适中、卖相稳。
- 餐饮、果汁店：更看重出肉率和价格，中果到大果都可能好走。
- 路边摊、散客批发：小果低价好走，但利润薄。
- 礼盒、精品超市：大果更受欢迎，但要求外观一致。

4. **用简单对比法快速判断**
同一时间段内，如果：
- A 规格每天都能清掉 80% 以上；
- B 规格经常剩 30%-50%；
- C 规格虽然单价高，但 3 天都走不完一车；
那优先主推 A，B 做搭配，C 只接预定单或少进。

5. **注意季节和天气**
菠萝在气温升高、节假日前后、夏季饮品旺季走得快，中果通常最稳。连续阴雨天、气温低时，整体动销都会下降，这时小果低价可能更快清货。

6. **最直接的验证方法**
选 2-3 个规格，各进一小批，放在同一位置、同一时间卖，连续试 3 天。哪个规格先卖完、补货次数最多，哪个就是当前最容易出货的规格。

结论：**不要只看哪个规格利润高，要看哪个规格动销率最高、周转天数最短、补货最频繁。** 对多数批发场景，中果通常是出货最稳的规格，但最终要用自己档口的 7 天销售数据来定。
