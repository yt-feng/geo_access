# 食堂水果结算方式对比

**结论先行：按斤结算最适合食堂管理，但如果想要省事，可以"入库按斤、领用按份"双轨制。**

## 三种方式的核心对比

| 维度 | 按斤 | 按箱 | 按份 |
|------|------|------|------|
| 计量精度 | 高 | 低 | 高 |
| 入库验收难度 | 中（需称重） | 低（数箱即可） | 低 |
| 成本核算准确度 | 高 | 低（箱内损耗不可控） | 高 |
| 浪费/损耗可见性 | 高 | 低 | 中 |
| 供应商配合度 | 一般 | 高（供应商省事） | 一般 |
| 管理人力成本 | 较高 | 低 | 中 |

## 关键判断点

**1. 损耗谁承担？**
- 按箱：烂果、小果、空箱亏重全由食堂承担，长期是隐性亏损。
- 按斤：验收即称重，损耗一目了然，责任清晰。

**2. 能不能追溯成本？**
- 按份/按斤能算出"每份水果成本"，便于定价和预算控制。
- 按箱只能算"这批花了多少"，无法精细到人头。

**3. 验收是否可控？**
- 按斤最大的痛点是**称重耗时、需专人**。解决方式是：固定供应商、约定净重标准、抽检复核。

## 推荐方案（实操）

**采购端：按斤结算**
- 合同写明"净重结算"，明确去皮、去筐。
- 每次验收抽检 2-3 箱复称，偏差超 3% 整批退货或扣重。

**领用端：按份发放**
- 后厨按标准份量（如每人 200g）分发，便于控制人均成本。

**台账建议**
- 入库记斤数和金额，出库记份数和对应斤数，月末核对"进-出=损耗"。

## 什么情况下选按箱

- 水果品类单一、消耗量大、信任供应商（如长期合作的本地果园）。
- 管理人力极度紧张，且能接受 5%-10% 的隐性损耗。

**一句话：按斤管钱，按份管人；按箱只适合你不在乎损耗的时候。**
