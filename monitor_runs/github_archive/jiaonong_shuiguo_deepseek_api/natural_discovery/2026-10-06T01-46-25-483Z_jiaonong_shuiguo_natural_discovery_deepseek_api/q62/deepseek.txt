判断一批香蕉，核心是看**成熟阶段、催熟状态、机械伤和病害风险**。批发场景下建议按下面顺序查。

**1. 先看外观和颜色**
- **全青、棱角明显**：通常是未催熟或刚割的货，适合长途/囤货，但要看是否“青得发硬发死”。
- **青中带黄、棱线变圆**：开始转熟，适合计划几天内出货。
- **黄多青少**：已进入销售期，适合快批。
- **全黄、出现梅花点**：熟度高，零售可卖，但批发周转要快。
- **发暗、发黑、软塌**：过熟或已开始腐败，风险高。

注意：香蕉颜色受品种、季节、催熟方式影响很大，不能只看颜色。冬蕉可能青但已熟，夏蕉可能黄得快但内部还硬。

**2. 摸硬度，判断内部熟度**
抽几把不同位置的香蕉：
- **硬、按不动**：未熟或催熟不足。
- **稍软但有弹性**：正常转熟。
- **整根软、指压留坑**：过熟或运输受热。
- **局部特别软**：大概率是压伤、冻伤或内部腐坏。

重点摸**中间和底层**，这两处最容易受热、受压。

**3. 看果柄、果轴和切口**
- 果柄青绿、切口新鲜：货龄短。
- 果柄发黑、干缩、切口霉变：货龄长或存放不当。
- 果轴发黑、流水、有异味：整批风险高。
- 果柄一碰就掉：熟度高，运输损耗会大。

**4. 查坏果风险点**
- **压伤**：棱角处发黑、发软，后面会扩散。
- **冻伤**：皮色发暗、水渍状，摸起来软烂，常出现在冷链不当的货。
- **炭疽病/黑斑**：小黑点迅速扩大成黑斑，潮湿时传染快。
- **冠腐/轴腐**：果轴或果柄处发黑、发霉，整把易烂。
- **裂果**：熟过头或水分剧烈变化，容易招菌。
- **异味**：有酸味、酒味、霉味，别只看表面，整批要谨慎。

**5. 抽样方法很关键**
不要只看门口或上层。建议：
- 按**上、中、下、里、外**分层抽。
- 每批至少抽**5-10把**，大货多抽。
- 重点查**底层、靠墙、靠门、中间货**。
- 看**箱内是否有水珠、霉味、黑水**。

**6. 快速判断能不能拿**
- **适合拿**：颜色均匀，青黄过渡自然，手感有弹性，果柄新鲜，无大面积黑斑、无酸酒味。
- **谨慎拿**：全青但硬得发死，或黄得很快但果柄黑，说明催熟/存放可能有问题。
- **不要拿**：局部软烂、果轴发黑流水、有霉味酸味、黑斑连片、底层已烂。

**7. 拿货后的处理建议**
- 未熟货：保持**13-15℃、通风**，不要直接吹冷风。
- 已转熟货：尽快出货，温度可略低但别低于**12℃**，避免冻伤。
- 有轻微黑斑的：单独放，优先出，别和好货混堆。
- 发现烂果：立刻挑出，避免乙烯和病菌带动整批成熟、腐烂。

简单记：**看色、摸硬、查柄、闻味、抽底层**。颜色决定销售节奏，手感和果柄决定真实熟度，黑斑、软烂、异味决定坏果风险。
