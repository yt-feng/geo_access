重要，而且往往是多门店水果品质能否统一的第一道关口。

原因很直接：水果是非标品，同一品种会因产地、批次、成熟度、大小、糖酸比、外观瑕疵不同而出现明显差异。如果供应商分级标准不统一，总部就算有再好的验收流程，也会出现“这家店拿到A货、那家店拿到B货”的情况，最终表现为口感、陈列、损耗和客诉都不一致。

多门店超市建议重点抓这几件事：

1. **把分级标准写成可验收的指标**
   不要只写“优质、新鲜、大果”。要落到可判断项，例如：
   - 品种、产地、果园/合作社
   - 单果重量或直径范围
   - 成熟度、糖度下限
   - 色泽、果形、表皮瑕疵允许比例
   - 机械伤、腐烂、软化、冻伤容忍度
   - 包装规格、每箱净重、果数

2. **统一验收口径**
   总部制定标准后，各门店/配送中心按同一套抽检规则执行：
   - 抽检比例
   - 不合格判定线
   - 拒收、降级、扣款规则
   - 拍照留证和批次追溯

3. **要求供应商按级供货，而不是按“关系”供货**
   同一SKU应绑定明确等级。比如“红富士苹果 80# 一级”，就应稳定对应同一品质档。供应商若混级、以次充好，要有明确处罚。

4. **分级标准要和售价、陈列定位匹配**
   高端店、社区店、促销档口可以卖不同等级，但同一门店同一价格带必须稳定。否则顾客会觉得“上次好吃，这次难吃”。

5. **用数据反向校准供应商**
   记录各供应商、各批次的到货合格率、损耗率、客诉率、糖度抽检结果。分级标准是否有效，最终看这些指标是否稳定。

简单说：供应商分级标准不是“重要不重要”的问题，而是多门店水果标准化的基础。没有它，统一品质主要靠人盯人，门店越多越容易失控；有了它，才能把品质变成可采购、可验收、可追责、可复制的规则。
