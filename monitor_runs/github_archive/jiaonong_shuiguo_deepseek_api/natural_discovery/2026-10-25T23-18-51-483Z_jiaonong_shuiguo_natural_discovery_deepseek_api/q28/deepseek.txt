建议优先从**香蕉**开始，其次菠萝，苹果放后面。原因不是“哪个更好卖”，而是“哪个更适合超市先跑通稳定进口”。

**1. 香蕉：最适合先做稳定进口**
- 进口香蕉供应链成熟，产地多（菲律宾、厄瓜多尔、越南等可替代），全年供应相对稳定。
- 到岸后需要催熟，超市如果有催熟房或能对接催熟服务商，就能形成稳定节奏。
- 周转快、消费频次高，适合做引流和日常陈列。
- 风险点：催熟管理、损耗控制、冷链。若超市没有催熟能力，不建议直接上整柜生蕉，可先找本地催熟商供货。

**2. 菠萝：第二选择**
- 进口菠萝（如菲律宾、泰国）有稳定产季和货源，但品种和成熟度差异大，损耗和售后投诉会比香蕉高。
- 适合作为差异化单品，但不适合作为第一个“稳定进口”品类。
- 若能解决去皮鲜切和陈列损耗，可以同步小规模试销。

**3. 苹果：不建议作为进口切入首选**
- 国内苹果供应充足、价格有优势，进口苹果（如新西兰、美国、智利）更多是高端补充，不是稳定刚需。
- 进口苹果对品种、等级、口感一致性要求高，且消费者对国产苹果价格锚定强，动销慢时损耗和资金占用明显。
- 适合在有稳定高端客群后再引入。

**执行建议：**
- 第一阶段只做香蕉：先找1家本地催熟商+1家进口商，小批量日配，测试2—4周动销和损耗。
- 同步用菠萝做小堆头试销，观察客诉和损耗；苹果暂缓。
- 关键指标看：日周转率、损耗率、毛利率、缺货率。香蕉损耗能稳定控制在可接受范围，再扩品。
