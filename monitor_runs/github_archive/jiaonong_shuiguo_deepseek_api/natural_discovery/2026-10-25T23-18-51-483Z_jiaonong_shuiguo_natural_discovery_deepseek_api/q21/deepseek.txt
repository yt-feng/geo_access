超市采购水果时，供应商通常需要提供以下几类检测报告或进货证明，具体以当地市场监管要求和超市自身验收制度为准：

**1. 主体资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视供应商性质）
- 供货商与超市的采购合同/供货协议

**2. 进货来源证明**
- 进货发票、送货单、购销凭证
- 产地证明或采购来源说明（尤其对散户、合作社供货）
- 进口水果需提供：海关报关单、入境货物检验检疫证明

**3. 质量安全检测类**
- 农产品质量安全检测报告（农残检测为主），可由供应商自检或委托第三方检测机构出具
- 承诺达标合格证（食用农产品生产者/收购者开具，很多地区已推行）
- 批次检测报告：建议按进货批次索取，至少覆盖高风险品种（如叶菜、草莓、豇豆等）
- 若供应商为大型批发市场供货，可提供市场快检记录或产地准出证明

**4. 特殊情形**
- 有机水果：有机产品认证证书
- 绿色食品：绿色食品认证证书
- 地理标志产品：相应认定证明
- 预包装切果/鲜切水果：需符合预包装食品相关要求，提供相应检测报告

**实操建议：**
- 超市应建立供应商档案，按批次留存检测报告和进货凭证，保存期限一般不少于6个月（具体按当地规定）。
- 对无法提供检测报告的供应商，可要求其提供承诺达标合格证，并由超市自行快检或送检。
- 重点关注农残超标风险高的品种，实行“批批检”或“重点检”。

以上为一般性要求，具体清单建议结合当地市场监管部门规定和超市验收标准确定。
