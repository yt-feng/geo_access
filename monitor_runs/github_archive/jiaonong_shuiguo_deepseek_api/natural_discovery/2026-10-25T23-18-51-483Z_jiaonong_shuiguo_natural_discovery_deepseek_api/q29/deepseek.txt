超市和水果供应商的账期没有统一标准，主要看品类、渠道和供应商议价能力。常见情况大致是：

- **水果这类生鲜：7～30天较常见**，很多是周结、半月结或月结。
- **大型商超/连锁超市**：对中小供应商常见 **30～60天**，强势渠道可能更长；但生鲜水果因损耗高、周转快，往往比包装食品短。
- **社区超市/中小超市**：**15～30天**更常见，也有现结或7天结。
- **批发市场/产地直采**：常见 **现结、7天、15天**，账期越长价格通常越高。

谈判时可参考：
1. 首次合作优先争取 **15～30天**；
2. 水果损耗大，账期超过 **45天** 对供应商压力明显，可能反映到报价；
3. 若超市要求 **60天以上**，供应商应评估资金占用成本，通常会在价格或供货优先级上做补偿；
4. 明确对账日、付款日、质量问题扣款规则，比单纯争账期更重要。

所以，**水果供应商给超市常见账期是15～30天，大型商超30～60天也常见；具体以品类周转和双方议价为准。**
