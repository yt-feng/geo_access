核心是**按你打算吃的时间，反推熟度选香蕉**，不要只看“黄不黄”。

可执行做法：

1. **先定吃的时间**
   - 今天/明天吃：选**全黄、带少量小褐点**的，甜度好、能马上吃。
   - 2～3天内吃：选**黄中带一点青肩**的，室温放熟刚好。
   - 4～7天后吃：选**偏青、硬一点**的，别买已经全黄带斑的。

2. **到店看三个位置**
   - **看两端**：发黑、渗液、软塌的不要。
   - **看棱角**：棱角明显、整体偏硬=偏生；圆润饱满但捏着有弹性=刚熟；一捏就陷=过熟。
   - **看斑点**：零星小褐点可以；大面积黑斑、连成片、果柄发黑的不建议。

3. **按采购量分开买**
   - 不要一次全买同一熟度。
   - 买“**一根今天吃 + 几根2天后吃 + 几根放久点**”的组合，比整把一样熟更稳。

4. **别被超市灯光和整把包装误导**
   - 整把香蕉常把熟的和生的混在一起，**逐根看两端和硬度**。
   - 如果包装里已有软烂、黑斑的，整把别拿，容易互相催熟。

5. **回家后控熟**
   - 偏青：室温放，别进冰箱；想慢一点就分开、通风。
   - 刚熟：室温尽快吃。
   - 已熟但吃不完：剥皮冷冻做奶昔，或冷藏延缓1～2天，但表皮会变黑，不影响果肉。

一句话：**今天吃买全黄微斑，2～3天吃买黄带青肩，想放几天买偏青硬身；逐根捏两端，软塌发黑不要。**
