和品牌方谈代理，区域保护和串货这两块，建议拆成下面几组问题，逐条要书面答复，别只听口头承诺。

**一、区域保护**
1. 我这个代理区域具体边界是什么？按省/市/区县，还是按渠道（商超、水果店、电商）划分？
2. 区域内还授权了哪些经销商？现有几家、各自覆盖什么渠道？我进来后会不会再新增？
3. 品牌方自己或总代在区域内直营/线上销售，算不算跟我抢？线上订单发到我区域怎么处理？
4. 区域保护写进合同哪一条？违约怎么赔、怎么退出？
5. 保护期多长？续约条件和业绩考核标准是什么？没达标会不会被缩区或取消？

**二、串货**
1. 品牌方对串货的定义是什么？跨区销售、线上低价、调货给外区客户，分别怎么算？
2. 发现串货后，处理流程是什么？我举证要提供什么（订单、物流单、批次码）？多久给答复？
3. 处罚标准：扣保证金、罚款、取消返利、终止代理，具体金额和触发条件？
4. 品牌方有没有货品追溯手段（批次码、区域专供包装、一物一码）？没有的话怎么查串货？
5. 我被别人串货冲击时，品牌方承担什么责任？有没有补偿或调价机制？
6. 我自己跨区调货的边界在哪？比如客户主动来我区域提货、我发快递到外省，算不算？

**三、配套要确认的**
1. 价格体系：建议零售价、最低限价、线上售价谁定，乱价怎么管？
2. 返利和保证金：保证金多少、什么情况扣、怎么退；返利跟销量还是跟守规矩挂钩？
3. 合同期限、退出机制、库存回购或滞销处理。
4. 所有口头承诺写进合同附件，签字盖章。

**问法建议**：别一上来就问“你们怎么防串货”，容易被当成潜在串货方。可以这样说：“我打算长期做这个区域，想把规则先弄清楚，避免以后跟其他经销商起冲突，也方便我按规矩投入。” 然后要求对方把区域边界、串货认定、处罚标准写成书面条款。

核心判断标准：**区域边界清不清楚、串货有没有可执行的追溯和处罚、品牌方自己守不守规矩**。这三条含糊，代理风险就大。
