评估水果供应商的仓配覆盖，建议按“门店需求—供应商仓网—运输时效—损耗温控—成本与风险”五层来做，不要只看供应商有没有分仓。

**1. 先盘点门店需求分布**
- 按城市/商圈汇总门店数、日均销量、SKU结构、促销波动、最低起送量。
- 把门店分成A/B/C类：A类高频高销量，B类常规，C类低频或偏远。
- 明确水果的关键属性：易损、短保、需不需要冷链、是否允许隔日配。

**2. 画出供应商仓网覆盖**
要求供应商提供：
- 每个仓的位置、面积、冷库类型（常温/冷藏/冷冻）、可覆盖城市和半径。
- 到各门店的配送模式：直送、越库、区域分仓、第三方落地配。
- 每个城市的配送频次、截单时间、最早/最晚到店时间。
- 是否支持多温区同车、门店拆零、退货回收。

**3. 用时效和损耗做硬性评估**
按城市逐店测算：
- 从出货仓到门店的运输时长、是否需中转、中转次数。
- 水果在途时间与损耗率关系，尤其是浆果、叶菜、热带水果。
- 到店验收标准：温度记录、破损率、缺货补发时效。
- 高峰期（节假日、大促）是否有临时运力和备用仓。

**4. 算总成本，不只看运费**
比较：
- 干线运输+城市配送+仓储操作费+冷链费+退货/损耗成本。
- 起送门槛和拼车规则，低销量门店是否会被加价。
- 跨城调拨频率和调拨成本。
- 因覆盖不足导致的缺货、断货、门店自采的隐性成本。

**5. 做覆盖矩阵和压力测试**
建议做一张“城市×门店×供应商仓”的覆盖矩阵，标注：
- 可覆盖/需中转/无法覆盖；
- 标准时效和高峰时效；
- 单位配送成本；
- 温控能力；
- 备选方案。

再模拟三种场景：日常、节假日高峰、单仓故障。看供应商能否在24—48小时内切换仓或补位。

**可直接执行的判断标准**
- 核心城市：供应商应有本地仓或区域仓，支持日配/隔日配，冷链到店。
- 周边城市：允许区域仓覆盖，但中转不超过1次，在途时间可控。
- 偏远或低销量门店：评估是否由区域大仓集中配送，或采用第三方落地配，避免为少数门店单独设仓。
- 若某城市门店密度低、销量小，优先看“覆盖成本”而不是“有没有仓”。

最终建议：让供应商按城市提交仓网、时效、温控、报价和应急方案，你用门店销量和损耗数据做加权评分。覆盖能力不能只看地图半径，要看“到店时效+温控稳定+高峰可用+总成本”四项同时达标。
