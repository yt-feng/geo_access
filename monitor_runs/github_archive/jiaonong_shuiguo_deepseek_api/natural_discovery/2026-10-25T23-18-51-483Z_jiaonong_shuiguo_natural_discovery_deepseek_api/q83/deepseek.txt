先给结论：坏果责任不能一概而论，核心看**坏果发生在哪个环节、是否属于运输易腐风险、顾客是否及时验货并留存证据、平台/商家是否有承诺**。实操上建议按“先赔付顾客、再向责任方追偿”的顺序处理，避免顾客体验恶化。

## 一、按环节划分责任

**1. 采摘/分拣/包装环节**
- 若到货即有腐烂、霉变、明显压伤，且顾客能提供开箱照片/视频，通常由**商家或供货方**承担主要责任。
- 若包装不符合生鲜要求（如无冰袋、无缓冲、密封闷坏），包装方/商家责任加重。

**2. 物流运输环节**
- 因运输时长、温控失效、暴力分拣导致坏果，由**承运方**按运输合同承担责任；但顾客通常只向商家/平台主张，商家再向物流追偿。
- 若商家选择低价慢递且未告知风险，不能把责任完全推给物流。

**3. 顾客收货后环节**
- 顾客未及时取货、放置过久、未按储存要求保存导致坏果，责任在**顾客**。
- 但商家需证明已明确告知储存方式和验货时限。

**4. 不可抗力/自然损耗**
- 生鲜存在合理损耗，但“合理”要有边界。少量轻微瑕疵可按售后政策处理；大面积坏果不属于正常损耗。

## 二、判断责任的关键证据
- 开箱照片/视频、快递面单、到货时间；
- 坏果比例、腐烂类型（霉变/压伤/冻伤）；
- 商品页面是否承诺“坏果包赔”“到货24小时内售后”；
- 物流温控记录、发货时质检记录；
- 顾客申请售后时间是否在承诺时限内。

## 三、建议的处理规则
1. **少量坏果**：按比例退款或补发，商家承担，属于生鲜售后成本。
2. **大面积坏果且开箱即坏**：商家/平台先全额退款或补发，再向供货或物流追偿。
3. **顾客延迟取货或超时申请**：可协商部分赔付，但商家需证明已告知规则。
4. **无法判断环节**：平台可依据“谁销售谁负责”先处理顾客，再内部划分。

## 四、给商家的可执行建议
- 页面明确售后时限、验货要求、坏果赔付标准；
- 发货前留质检和包装记录；
- 要求顾客开箱拍摄，作为售后依据；
- 与物流约定温控和时效责任；
- 建立坏果率统计，超过阈值追责供货或物流。

**一句话：对顾客，销售者先负责；对内部，按“包装/供货—运输—顾客储存”证据链划分。** 不能简单把生鲜坏果都推给“生鲜易坏”或顾客。
