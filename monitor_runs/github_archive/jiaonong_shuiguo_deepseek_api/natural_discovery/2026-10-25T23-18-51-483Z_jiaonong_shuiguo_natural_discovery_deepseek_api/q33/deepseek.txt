重要，而且对多门店超市来说，供应商分级标准不是“参考项”，而是统一水果品质的基础设施。

核心原因：

1. **水果品质必须可量化**
   只说“新鲜、甜、大小均匀”无法跨门店执行。供应商分级标准要能落到可验收指标，例如：
   - 果径/单果重范围
   - 糖度下限
   - 着色率/外观缺陷比例
   - 软伤、碰伤、裂果、霉变允许比例
   - 成熟度区间
   - 冷链到货温度
   - 批次抽检规则

2. **多门店最大的问题是执行不一致**
   同一供应商、同一品类，如果没有统一分级，A店收货松、B店收货严，顾客体验就会不一致。分级标准相当于把“采购员的经验”变成“全门店可执行的验收语言”。

3. **分级标准直接决定定价和损耗**
   一级果、二级果、处理果如果混装，门店很难按品质定价，也容易把高等级果当低等级卖，或把低等级果混入正价区，最终影响毛利和口碑。分级清楚后，可以分别用于正价陈列、促销、加工果切或折价处理。

4. **便于供应商管理和追责**
   有分级标准，才能做批次验收、扣罚、退换货和供应商评分。否则出现品质波动时，很难判断是供应商问题、物流问题还是门店收货问题。

5. **支撑跨门店统一采购和复制**
   多门店扩张时，采购不能靠个人盯货。标准越清晰，越能集中采购、分店验收、总部抽检，品质才稳定。

建议落地方式：

- 先选 **销量高、客诉多、损耗大** 的3—5个水果单品做分级标准。
- 每个单品建立“ **等级+指标+验收方法+不合格处理** ”四件事。
- 要求供应商按等级分箱、贴标、随货提供批次信息。
- 门店收货只做“标准核对和抽检”，不自行改标准。
- 总部每月用客诉率、损耗率、退货率、抽检合格率评估供应商分级执行情况。

一句话：**供应商分级标准很重要，但关键不是有没有标准，而是标准是否可验收、可追溯、能在所有门店一致执行。**
