建议把“熟度”和“到货时间”写成采购验收标准，不要只说“别太熟”。可按下面执行：

1. **按销售节奏定熟度**
   - 当天到当天主卖：到货以**黄绿、能看出黄色但果柄仍偏绿**为主，适合2～3天内卖完。
   - 次日或隔日主卖：到货可**七八成熟、果身微黄、果肉尚硬**，避免全黄。
   - 不建议水果店常规采购“全黄、已起糖斑”的香蕉作为主库存；这种只适合当天促销或加工。

2. **采购时明确写验收熟度**
   建议在订单/验收单写：
   - “到货香蕉以**黄绿至微黄、果身硬、果柄绿、无明显糖斑和压伤**为主。”
   - “**全黄果比例不超过10%～15%**，青果/黄绿果占多数。”
   - “不得混入已软熟、果皮发黑、机械伤、水烂果。”
   具体比例可按你店销量调，但一定要有“全黄比例上限”。

3. **要求到货时间**
   - 优先要求**清晨或开门前到货**，便于当天分拣、上架、控温。
   - 避开**午后高温时段到货**；夏季尤其要要求冷链或遮阳运输。
   - 采购频次建议“**少量多次**”：销量稳定就每天或隔天到一次，不要一次压太多。

4. **按批次分开到货**
   同一批不要全是同一熟度。可要求供应商：
   - **70%～80%黄绿/微黄果**：先放库或后场上架；
   - **20%～30%偏黄果**：当天陈列主推；
   - 熟度分开放、分架卖，先进先出。

5. **到货后立刻做动作**
   - 拆箱散热，别闷在纸箱里；
   - 青果常温催熟/存放，黄果尽快上架；
   - 香蕉不要和苹果、梨等释放乙烯多的水果混放太多，除非你想加快催熟；
   - 每天挑出软果、伤果，打折或做果切，别等整串坏。

一句话采购要求：**“少量多次、清晨到货、以黄绿至微黄硬果为主，全黄果比例设上限，拒绝软熟和压伤果。”**
