可以提前向供应商索要以下几类资料，并做交叉核验：

1. **主体与资质资料**
   - 营业执照
   - 食品经营许可证/食品生产许可证（如适用）
   - 供货商与种植基地/合作社的关系证明或授权书

2. **产地与种植管理资料**
   - 产地证明或基地备案信息
   - 农药采购、领用、使用记录
   - 安全间隔期执行记录
   - 种植过程记录（施肥、用药、采收日期）

3. **检测资料**
   - 近批次或近周期的农残检测报告，最好带CMA/CNAS标识
   - 报告需能对应到具体品种、批次、产地和采样日期
   - 供应商自检报告可作为辅助，但不能替代第三方检测
   - 如采购高风险品种，可要求批批附检测报告或承诺抽检合格后放行

4. **追溯与承诺资料**
   - 批次追溯信息：产地、采收日期、入库日期、批次号
   - 质量安全承诺书或供货协议中的农残超标责任条款
   - 不合格产品召回和赔偿约定

5. **现场与体系资料（可选但有用）**
   - 基地或加工厂照片、视频
   - 良好农业规范认证、绿色食品/有机认证等（如宣传相关卖点）
   - 过往抽检不合格记录说明

**执行建议：**
- 不要只看一张“合格报告”，要核对报告上的**品种、批次、日期、检测项目**是否与本次到货一致。
- 对新供应商先小批量试采，并自行送检一次；对高风险品种提高抽检频次。
- 在合同中写明：农残抽检不合格时，供应商承担检测费、退货、销毁及因此产生的监管处罚和商誉损失。
- 保留每批资料的归档，形成“一批一档”，便于监管抽查时说明已履行进货查验义务。
