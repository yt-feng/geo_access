# 超市水果到货品相不好的售后流程约定

核心思路：**把“品相不好”拆成可判定的标准和时限，写进合同或采购单，避免事后扯皮。** 建议按以下结构约定：

## 一、先定义“品相不好”（最容易起争议）

不要只写“品相不佳可退”，要量化：

- **验收标准**：按品种、等级写明规格（单果重、果径、色泽、糖度、成熟度、允许瑕疵比例等），最好附样品照片或行业标准（如等级国家标准/行业惯例）。
- **瑕疵分级**：明确哪些算“轻微瑕疵可折价接收”，哪些算“严重瑕疵可拒收/退货”。例如腐烂率、压伤率、裂口率超过 X% 即整批不合格。
- **抽样方法**：约定抽检比例（如每批随机抽 5% 箱数）和判定规则，避免“一箱坏就整批退”或“表面好里面坏”的争议。

## 二、售后时限与动作

- **验收期限**：到货后 X 小时内（生鲜通常 2–24 小时，越短越好）完成验收并书面/系统反馈，逾期视为验收合格（对采购方不利，需权衡）。
- **隐蔽瑕疵**：开箱后发现内部腐烂的，约定在到货后 X 天内可追溯，但需保留原包装、照片、批次号。
- **反馈方式**：书面（验收单签字、系统工单、带时间戳的照片/视频），口头无效。

## 三、处理方式（给选项而非只有退货）

按瑕疵程度约定阶梯方案：

1. **拒收**：严重不合格整批退回，运费/损耗由供货方承担；
2. **折价接收**：轻微瑕疵按比例扣款（如按瑕疵率扣减货款 X%）；
3. **换货/补货**：约定补货时限（如 24–48 小时内）；
4. **退货退款**：明确退款时限和方式。

## 四、责任与费用

- 明确**运输损耗、冷链断链**导致的品相问题归谁；
- 退换货的**运费、装卸费、报废处理费**归属；
- 因品相问题引发的**客诉、下架损失**是否可追偿（可选，视合作深度）。

## 五、争议解决与留证

- 约定**第三方检测或双方共同复检**机制；
- 要求到货即拍照/录像留存，作为争议依据；
- 明确违约累计次数达到 X 次可终止合作。

## 落地建议

把以上内容做成**一页《到货验收与售后确认单》**，随每批货附带，双方签字即生效。比在合同里写大段条款更可执行——生鲜纠纷大多输在“没标准、没留证、没时限”。
