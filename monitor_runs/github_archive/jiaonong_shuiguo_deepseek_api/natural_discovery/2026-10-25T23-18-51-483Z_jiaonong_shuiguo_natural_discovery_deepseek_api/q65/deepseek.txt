这要看你面对的**波动类型、资金实力、下游合同结构和货源稳定性**，不能简单二选一。比较可执行的做法是：

**1. 先判断你怕的是哪种风险**
- 怕“今天不锁价，明天进货涨”：适合**锁一部分远期价**。
- 怕“签了固定价，行情跌了被套”：适合**缩短锁价周期或分批锁价**。
- 下游是商超、食堂、团购等**固定售价合同**：上游应至少锁定对应量，否则价格倒挂风险很大。
- 下游是随行就市、当天走货：可以更多采用**每日议价/随行就市**。

**2. 不建议“全量每天议价”**
水果批发价格波动大、损耗高、账期和物流都要提前安排。每天议价的问题：
- 采购量大的时候，临时议价议价能力反而弱；
- 行情上涨时容易抢不到货；
- 行情下跌时库存成本高；
- 人员和沟通成本高。

**3. 也不建议“全量长期锁价”**
长期固定价在行情大跌时会明显吃亏，在行情大涨时供应商可能履约意愿下降，出现质量下降、缺斤少两、优先供别人等问题。

**4. 更稳妥的是“核心量锁价 + 机动量随行就市”**
可以按这个比例操作：
- **60%—70% 基础销量**：签较短周期价格，比如 **7—15天**，或按周定价；
- **20%—30% 机动量**：每日或隔日议价，跟随市场；
- **10% 安全库存/应急采购**：用于突发缺货或大客户临时加单。

如果单品价格波动特别剧烈，锁价周期进一步缩短到 **3—7天**；如果价格相对平稳，可延长到 **15—30天**，但最好设置**价格调整机制**。

**5. 签价格时不要只签“死价格”**
合同里尽量加入：
- 质量等级和验收标准；
- 最低供货量和最高供货量；
- 价格随主流批发市场均价浮动的公式；
- 涨跌超过一定幅度可重新议价；
- 违约、缺货、质量不达标的处理；
- 账期和损耗承担方式。

**6. 给一个直接判断标准**
- 你下游有固定售价合同、且毛利率低于10%：**必须锁价，至少锁对应量**。
- 你做的是快进快出、当天基本清库：**每日议价更合适**。
- 你单量大、有稳定老客户：**周定价或半月定价 + 机动补货**最稳。
- 你对行情判断没把握：**分批锁价**，不要一次锁满。

结论：**不要每天全量议价，也不要长期全量锁价。优先采用“短周期锁价 + 部分随行就市 + 价格调整条款”的组合策略。**
