判断“合理波动”不能只看涨跌幅度，要把它拆成**可解释的波动**和**需要警惕的异常**。给你一套可直接落地的判断框架。

## 一、先建立“价格合理性”的判断标尺

每天报价变动本身正常，关键是看波动是否**有来源、有范围、可复现**。建议从四个维度判断：

1. **波动幅度是否在历史区间内**
   - 用该单品过去30/60/90天的成交价，算日均波动率和最大回撤。
   - 例如某水果日常日波动在2%–5%，某天突然报涨15%，就属于异常，需要供应商解释。
   - 没有历史数据的，用同类水果、同产区、同等级做横向参照。

2. **波动方向是否有市场依据**
   - 产地天气、采收季起止、节假日备货、运输成本、期货或批发市场行情，都是可解释因素。
   - 能对应上公开或可核验的信息（如批发市场均价、产地行情），才叫合理波动。
   - 只有供应商口头说“今天涨了”，没有依据，不能直接接受。

3. **波动是否与质量、等级、规格匹配**
   - 同一品种不同规格、等级、包装，价差本来就大。
   - 要确认报价对应的是同一等级、同一产地、同一包装单位，否则“波动”可能是偷换规格。

4. **波动是否具有普遍性**
   - 同一天多问2–3家供应商，或看当地批发市场同品均价。
   - 只有一家涨、市场没涨，属于个体报价行为，不是市场波动。

## 二、建立日常判断机制（可直接执行）

**1. 建价格台账**
每天记录：日期、品名、规格等级、产地、供应商、报价、成交价、市场参考价、涨跌幅、波动原因。连续记录1–2个月就能看出正常区间。

**2. 设波动阈值**
按单品设定：
- 日波动≤5%：正常，按流程执行；
- 5%–10%：要求供应商书面说明原因，并对照市场价；
- ＞10%：暂停下单，比价+核验产地/批发市场行情后再定。

阈值可按品类调整，叶菜、时令水果可放宽，耐储水果应更严。

**3. 要求报价附“波动说明”**
在采购协议里约定：报价单需注明当日价格变动原因（产地收购价、天气、运输、节日等），并保留可核验依据。没有说明的涨价，不自动执行。

**4. 多家比价+市场锚点**
每天至少取2–3家报价，或用一个公开批发市场均价做锚。偏离锚点超过约定比例的，触发复核。

**5. 约定调价规则**
合同里写清楚：调价依据（如某批发市场均价、产地收购价指数）、调价频率、提前通知时间、单次最大调幅。把“每天变”变成“按规则变”。

## 三、需要警惕的异常信号

- 只涨不跌，或跌得远慢于市场；
- 涨价无任何可核验原因；
- 报价频繁但成交价与报价长期脱节；
- 同一天对不同采购方报价差异过大；
- 借“规格升级”“包装更换”变相涨价。

## 四、一句话结论

**合理波动 = 在历史区间内 + 有可核验原因 + 与市场同向 + 规格未变。** 采购方要做的不是预测每天价格，而是建立台账、设阈值、要依据、多比价，把供应商的“随口报价”变成“可解释、可追溯、可约定”的价格机制。
