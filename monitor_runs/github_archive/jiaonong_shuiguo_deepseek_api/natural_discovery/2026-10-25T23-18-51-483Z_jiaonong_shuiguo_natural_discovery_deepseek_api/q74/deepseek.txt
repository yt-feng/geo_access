批发档口做餐饮客户，核心不是“多上规格”，而是先按餐饮客户的用货场景分层。菠萝和香蕉建议这样准备：

## 菠萝

餐饮客户主要分四类：饮品店、烘焙/甜品、水果捞/沙拉、餐厅后厨。

1. **鲜切/饮品店**
   - 主推：**单果1.2–1.5kg的中大果**，成熟度7–8成，适合现切、榨汁、做水果茶。
   - 备货：**1.5kg以上大果**少量，出肉率高，适合中央厨房。
   - 不建议主推太小果，削皮损耗高。

2. **水果捞/沙拉/甜品**
   - 主推：**1–1.2kg中果**，成熟度8成，果眼浅、果形端正。
   - 可备少量**小果0.8–1kg**做整果装饰或小份零售。

3. **餐厅后厨/热菜**
   - 主推：**1.2–1.8kg大果**，耐储、出肉多，适合菠萝炒饭、咕咾肉等。
   - 成熟度可略低，7成左右，便于后厨存放。

4. **规格表达建议**
   - 按餐饮习惯标：**单果重量区间 + 成熟度 + 是否带冠/去冠 + 箱装净重**。
   - 例如：中果1.2–1.5kg/个，8成熟，去冠，净重约10kg/箱。
   - 餐饮客户更关心**出肉率、损耗率、稳定供货**，不是只看单价。

## 香蕉

餐饮客户主要是饮品店、烘焙店、餐厅、食堂。

1. **饮品店/烘焙店**
   - 主推：**单根120–150g的中号蕉**，成熟度5–6成到货，便于催熟和排期使用。
   - 备少量**150g以上大蕉**做鲜食或装饰。
   - 饮品店更偏好**大小均匀、无黑斑、货架期稳定**。

2. **餐厅/食堂**
   - 主推：**单根130–180g**，成熟度6–7成，适合直接配送后熟。
   - 可备**整箱净重稳定**的规格，方便按箱结算。

3. **水果捞/甜品**
   - 主推：**单根100–130g小中蕉**，切片均匀、卖相好。
   - 成熟度到货5–6成，客户自己催熟到7–8成使用。

4. **规格表达建议**
   - 按：**单根重量 + 每把根数 + 箱装净重 + 到货成熟度**。
   - 例如：中号蕉120–150g/根，5–6把/箱，净重12kg，到货5–6成熟。
   - 餐饮客户通常更接受**按箱稳定净重、可定期送**，而不是每天挑规格。

## 建议档口先配的SKU

不要一上来铺太多，先配：

- 菠萝：**中果1.2–1.5kg**、**大果1.5kg以上**两个规格；
- 香蕉：**中号120–150g/根**、**大号150g以上/根**两个规格；
- 再根据客户反馈增加小果或特定成熟度。

## 谈餐饮客户时重点问清

1. 用途：鲜切、榨汁、热菜、甜品、食堂；
2. 单果/单根重量要求；
3. 到货成熟度；
4. 箱装净重要求；
5. 每周用量和配送频次；
6. 损耗谁承担、是否要分级挑果。

**结论：**菠萝先备“1.2–1.5kg中果”和“1.5kg以上大果”，香蕉先备“120–150g中号”和“150g以上大号”，成熟度按客户用途分5–6成、7–8成两档。这样既能覆盖饮品、烘焙、水果捞和后厨，又不会把档口SKU压得太散。
