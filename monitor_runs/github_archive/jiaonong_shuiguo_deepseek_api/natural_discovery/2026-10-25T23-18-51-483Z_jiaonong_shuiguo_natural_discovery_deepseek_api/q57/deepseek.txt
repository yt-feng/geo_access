多数餐饮连锁采购水果，建议**以中央厨房统一收货为主，门店直收作为例外补位**。但最终取决于水果品类、门店密度、配送半径和门店加工能力。

**一、中央厨房统一收货更适合的情况**
- 水果用于标准化出品，如茶饮果切、甜品、沙拉、酱料，需要统一规格、成熟度和验收标准。
- 门店数量多且集中，配送半径可控，中央厨房有冷藏/分拣/催熟/分级能力。
- 需要集中议价、集中索证索票、统一农残检测和批次追溯。
- 想降低门店验收差异、串货和损耗责任不清的问题。

**优点**：采购议价强、品质标准统一、食安追溯集中、门店操作简化、损耗责任更清晰。  
**代价**：多一道分拣和短驳，增加中央厨房人工、冷库和配送成本；对配送时效和冷链要求高，易出现“中央厨房验收合格、到店已损”的责任争议。

**二、门店分开收货更适合的情况**
- 水果是高频、短保、强体验品类，如鲜果切、果盘、现榨，门店需要按当日客流和成熟度灵活补货。
- 门店密度低或配送半径大，中央厨房统一配送不经济。
- 当地有稳定批发市场或供应商，能小批量、多频次直送。
- 门店具备验收和简单加工能力，且能执行统一验收标准。

**优点**：补货灵活、周转快、短保损耗低、配送成本可能更低。  
**代价**：品质和价格不统一，门店验收能力参差，食安追溯和供应商管理难度大，容易出现门店与采购串通、虚报损耗。

**三、可执行的建议**
1. **按品类分层**：标准化程度高、耐储运的苹果、橙子、柠檬、冷冻果浆等走中央厨房统采统配；高损耗、短保、成熟度敏感的草莓、蓝莓、芒果、鲜切水果等可“中央厨房定供应商和价格，门店直收”或区域仓配送。
2. **统一验收标准**：无论谁收货，都用同一套规格、糖度、成熟度、农残证明、破损率、温度记录和拍照留证标准。
3. **设定损耗责任线**：明确中央厨房出库合格标准、到店验收时限和差异归属，避免“离仓即损”扯皮。
4. **先试点再铺开**：选一个区域或一个品类，对比3个月的总成本，包括采购价、分拣人工、冷链配送、损耗、门店工时和客诉，再决定是否推广。
5. **保留门店应急直采权限**：设置金额和品类白名单，事后补单审核，避免断货影响营业。

**结论**：如果门店集中、水果标准化程度高、食安要求强，优先中央厨房统一收货；如果水果短保高频、门店分散、配送不经济，采用“中央厨房统一定标准/供应商+门店或区域仓直收”的混合模式更稳。
