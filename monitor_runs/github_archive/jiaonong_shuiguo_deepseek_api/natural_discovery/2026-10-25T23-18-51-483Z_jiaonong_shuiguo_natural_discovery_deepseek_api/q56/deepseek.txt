茶饮店控制水果供应商食品安全风险，核心是“资质合规＋检测合格＋来源可追溯＋验收留痕”。建议要求供应商提供以下证明，并按风险分级管理。

**一、主体资质类（准入必备）**
1. 营业执照（经营范围含水果/农产品销售或相关）。
2. 食品经营许可证或食品生产许可证（视其经营模式：销售预包装/散装食品、初加工等；仅销售食用农产品的情形按当地规定核验，但营业执照和供货凭证仍要留存）。
3. 法定代表人/负责人身份证明及授权委托书（如由业务员对接）。
4. 供货商为贸易商时，应能提供上游产地/合作社/加工厂的相关资质或供货关系证明。

**二、产品合格与检测类**
1. 每批次水果的产地证明或购货凭证/销售单（含品名、数量、日期、供货商）。
2. 农药残留检测报告：优先要批次对应的快检报告或第三方检测报告；至少对高风险品种（如草莓、葡萄、桃、叶菜类水果等）提高抽检频次。
3. 第三方全项检测报告（按年度或品种更新），重点看农残、重金属等指标。
4. 若供应商自行分切、鲜切水果，还需符合即食果蔬加工要求，提供加工环节的卫生检测/环境检测及从业人员健康证明。

**三、追溯与过程管理类**
1. 产地/基地信息：果园或合作社名称、地址、联系人，便于追溯。
2. 种植环节用药记录或承诺书（合理使用农药、遵守安全间隔期）。
3. 运输与储存条件说明：冷链温度记录（如需要冷藏的水果）、运输车辆卫生情况。
4. 包装标签信息：品名、产地、生产/采摘日期、保质期、储存条件。

**四、人员与制度类**
1. 接触直接入口水果的从业人员健康证明。
2. 供应商食品安全管理制度或质量承诺书（含不合格品召回、投诉处理）。

**五、茶饮店内部配套动作（否则证明无效）**
1. 建立供应商档案和合格供应商名录，资质到期前提醒更新。
2. 每批到货验收：查证、看外观、测温度、留样/拍照，记录批次和检测报告编号。
3. 对高风险水果定期送检或快检，保留检测记录。
4. 索证索票齐全，做到“一批一证一票”，确保可追溯。

**优先级建议**：先卡住营业执照、食品经营/生产许可、批次购货凭证和农残检测报告四项；鲜切水果供应商再增加加工卫生和人员健康证明。无法提供批次检测或追溯信息的供应商，不建议作为长期主力供应商。
