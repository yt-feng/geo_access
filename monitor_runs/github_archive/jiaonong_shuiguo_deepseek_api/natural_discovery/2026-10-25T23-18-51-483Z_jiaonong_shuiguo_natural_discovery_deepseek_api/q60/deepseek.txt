# 水果到货不合格，补货约定要点

核心思路：**把“补货时效”和“免营业中断”写进合同/订单条款，而不是靠口头承诺。** 建议在供货协议（或每次订单附条款）中至少约定以下内容：

## 1. 验收与判定标准
- 明确验收时间：到货后 **30–60 分钟内**完成抽检（到店即验，避免占压）。
- 量化不合格标准：如腐烂/压伤比例超过 X%、糖度低于 X、单果重量不达标、品种不符等，避免“看情况”扯皮。
- 拍照留证 + 双方线上确认（微信群/邮件），作为补货依据。

## 2. 补货时效（关键）
- **当日补货**：约定“验收确认不合格后 X 小时内送达”，例如上午到货不合格，下午营业高峰前补到。
- **分档约定**：按不合格比例设不同响应——少量不合格当场换货；大批量不合格则 **当日内补足 + 次日优先排产**。
- 明确补货**免运费、不额外加价**，且不占用下一批订单额度。

## 3. 营业不中断的保障机制
- **安全库存条款**：要求供应商对高频水果（柠檬、橙、芒果等）保持一定备货量，或你方自留 1–2 天安全库存，合同里约定供应商对紧急缺货承担调货义务。
- **替代方案约定**：若补货无法按时到，供应商需协调同品质替代货源，或按缺货金额赔付（如缺货部分货款的 1.5–2 倍），覆盖临时采购差价。
- **优先补货权**：旺季/节假日约定供应商对你的补货请求优先响应。

## 4. 结算与违约
- 不合格批次**不计入结算**，已付款的可冲抵下批货款。
- 补货逾期按日计违约金（如货款的 0.5%/天），连续两次逾期可终止合作。
- 保留**扣款权**：从当月货款中直接扣除损失，避免事后追讨。

## 5. 操作建议
- 条款写进**书面供货协议**，每次下单用固定格式订单确认（品种、数量、到货时间、验收标准、补货时限）。
- 建立**到货验收记录表**，每次拍照存档，作为索赔证据。
- 关键水果**不要单一供应商**，保留 1 家备选，补货谈不拢时能立刻切换。

一句话：**验收标准量化 + 补货时限精确到小时 + 逾期赔付可执行 + 保留备选供应商**，这四点写清楚，补货基本不会拖累营业。
