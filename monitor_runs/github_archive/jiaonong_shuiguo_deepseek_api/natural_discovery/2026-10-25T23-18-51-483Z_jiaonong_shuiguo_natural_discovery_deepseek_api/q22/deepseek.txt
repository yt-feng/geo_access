香蕉、菠萝、苹果适合做“引流+提客单+组合装”三层促销，不要只做单一打折。可按下面执行：

1. **香蕉做引流，不直接降到底**
   - 香蕉单价低、购买频率高，适合做“加价购”入口。
   - 例：买任意水果满15元，加3.9元换购1把香蕉；或香蕉单买恢复原价，买组合装才享优惠。
   - 目的：用香蕉把人带到水果区，但不让低毛利单品拉低整体客单。

2. **苹果做主力利润款，按规格分层**
   - 设“家庭装/精品装/尝鲜装”三档，家庭装做主推。
   - 例：苹果2斤装原价，3斤家庭装立减3元；或“苹果+香蕉”早餐组合价，比单买省2—3元。
   - 苹果耐储、适合囤货，适合承担客单价提升。

3. **菠萝做组合搭档，降低单买门槛**
   - 菠萝客单较高但处理麻烦，适合做“已削皮+搭配”组合。
   - 例：“菠萝+苹果”果切组合、“香蕉+菠萝”奶昔组合，或买菠萝加5元换购苹果2个。
   - 如果门店有果切能力，优先推果切组合，毛利和客单都更好。

4. **主推三个组合价，别让顾客自己算**
   - **早餐组合**：香蕉1把+苹果3个，组合价低于单买2—3元。
   - **家庭果盘组合**：苹果3斤+菠萝1个+香蕉1把，设“满39元减5元”或固定组合价。
   - **加价购组合**：买苹果家庭装，加价换购香蕉或小菠萝。

5. **陈列和话术要配合**
   - 三个品相邻陈列，组合装用统一托盘/网袋，价签写“单买XX元，组合省X元”。
   - 主推位放家庭组合，香蕉放入口端架做加价购提示。
   - 每天限定时段推“组合装特价”，制造决策紧迫感。

6. **控制风险**
   - 香蕉损耗快，加价购限量、分时段投放，避免压货。
   - 菠萝按削皮能力推，不能削皮就少做果切承诺。
   - 组合价要保证整体毛利，不要三个品同时深度打折。

优先落地顺序：先做“苹果家庭装+香蕉加价购”，再上“苹果+菠萝+香蕉家庭果盘组合”，最后根据销量调整组合价和限量。
