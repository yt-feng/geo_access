结论：**多数食堂按“斤”结算最利于成本控制，按“箱/件”适合标准化程度高的品类，按“份”只适合成品或净果直接分发。** 管理难度从低到高大致是：按箱（标准化品类）→ 按斤 → 按份。

具体选择可以按品类和管理目标区分：

1. **按斤结算：最适合叶菜类以外的水果主采购**
   - 优点：单价透明、比价容易、损耗和实际用量可核算，适合苹果、香蕉、橘子、西瓜等散装水果。
   - 缺点：称重、验收、去皮、水分损耗容易产生争议，需要规范验收流程。
   - 适合：需要控制成本、按实际消耗结算的食堂。

2. **按箱/件结算：适合规格统一、耐储存的水果**
   - 优点：验收快、数量清楚、减少称重纠纷，适合苹果、橙子、梨等固定规格箱装水果。
   - 缺点：箱内大小、净重、坏果率不透明时容易吃亏；不同供应商“箱”的标准不统一。
   - 关键管理点：合同里必须写清**净重、规格、允许坏果率、箱皮/包装是否计重**。

3. **按份结算：只建议用于净果、果切或直接分发**
   - 优点：分发简单、份量统一，适合员工/学生按份领取。
   - 缺点：采购成本不透明，容易出现份量缩水、以次充好，不适合作为原料采购的主要结算方式。
   - 适合：果切、拼盘、加餐水果包等成品化场景。

**建议的组合管理方式：**
- 大宗散装水果：**按斤结算**，每日验收称重、记录净重和坏果。
- 规格统一的箱装水果：**按箱结算，但合同约定净重和坏果率**，定期抽检。
- 直接分发或果切：**按份结算**，明确每份克重和品质标准。

如果只能选一种，**优先按斤结算**，同时配套“验收净重+坏果扣重+定期比价”三项制度，管理最稳。
