社区超市卖水果，控制新鲜度和库存，核心就一句话：**按销量订货、按成熟度分级卖、快到期的提前处理掉**。下面按可执行动作分几块说。

### 1. 订货：别凭感觉，按“日均销量×订货周期”下单
- 先记两周数据：每个单品每天卖多少、周末比工作日多多少。没有系统就用本子或手机表格记。
- 订货量 = 近7天日均销量 ×（订货间隔天数+1天安全量），再按天气和节假日微调。下雨天叶菜、水果销量通常下降，别照常订。
- 少量多次：易坏单品（草莓、葡萄、叶菜、香蕉）宁可一天订两次或隔天订，也不要一次压三天。
- 设定单品上限：比如草莓最多放两天量，超过不订。把“最多库存天数”写下来贴在订货本上。

### 2. 收货：当场分拣，不合格直接退
- 收货时抽检底层和中间层，看有没有压伤、霉点、过熟。有问题的当场退或折价，别收进来再慢慢挑。
- 按成熟度分开放：青的、刚熟的、熟透的分区。熟透的当天摆到最前面或做特价，青的放后面。
- 香蕉、芒果、猕猴桃等后熟水果，别和苹果、梨放太近（乙烯催熟），分开存放。

### 3. 陈列：少量勤补，别堆大堆
- 台面只摆半天到一天的量，卖完再从库房补。堆得越高，底层压坏越多。
- 易坏水果用小托盘、浅筐，别用深筐压着。
- 冷藏水果（蓝莓、草莓、切果）全程冷链，别在常温台面放太久。
- 每天早晚各翻检一次，把软的、有斑的挑出来，别等烂了才处理。

### 4. 库存：先进先出 + 每日盘点
- 库房和台面都执行“先进先出”，新货放里面，旧货放外面。
- 每天闭店前盘一次易坏单品，记下剩余量，第二天订货直接参考。
- 设红线：某单品剩余超过“两天销量”，第二天停止订货并启动促销。
- 库房别堆太满，留出通风和翻检空间；水果怕闷，纸箱别长期密封。

### 5. 快到期的怎么处理：提前降价，别等烂
- 按成熟度设阶梯价：刚熟正价，偏熟9折，熟透7折或做果切/拼盘，有损伤的当天特价清掉。
- 每天固定时段（比如傍晚）做“今日鲜”特价区，把临近最佳食用期的集中卖。
- 能加工的做果切、果汁、水果捞，但必须当天加工当天卖，且注意卫生和冷藏。
- 和周边餐饮、奶茶店、食堂谈临期批量出货，哪怕微利也比烂掉强。

### 6. 几个容易忽略的点
- **损耗要记账**：每天扔了多少、降了多少价，记下来，一周复盘哪个单品总亏，就减量或换品。
- **别一次上太多新品种**：新品先小量试销，看三天动销再决定是否加量。
- **天气和节假日提前备**：高温天减少叶菜和浆果订货；节假日提前一两天增量，但节后第一天立刻回落。
- **员工责任到人**：谁负责翻检、谁负责下单，写清楚，避免“都以为别人会管”。

总结成日常动作：**每天记销量、每天翻检、每天盘易坏品、超两天量就停订并促销**。坚持两周，库存和损耗就能明显压下来。
