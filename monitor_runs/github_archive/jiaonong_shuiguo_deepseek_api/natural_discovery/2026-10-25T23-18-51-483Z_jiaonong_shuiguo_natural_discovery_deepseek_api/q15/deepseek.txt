水果店遇到坏果，核心原则是：**先分清责任和损耗类型，再按合同/约定结算，不要直接用“整批扣款”代替验收记录。** 下面按可执行流程说。

## 1. 先判断坏果属于哪一类
通常分三种，处理方式不同：

1. **到货验收时就发现的坏果**
   - 属于供应商交付质量问题，应当场拍照、称重、记录数量，并在送货单上注明“坏果X斤/箱，拒收或折价”。
   - 能拒收的尽量拒收；不能拒收的，按约定折价或扣款。

2. **收货后1—3天内出现的腐坏**
   - 如果是水果本身成熟度过高、内部腐烂、冷链不到位导致，通常仍可向供应商主张赔付。
   - 需要保留进货批次、到货时间、储存条件照片，证明不是门店自己存放不当。

3. **门店储存不当或超过保鲜期造成的坏果**
   - 一般由门店自行承担，不能转嫁给供应商。
   - 除非合同明确约定“包售后损耗”或供应商承诺“坏果包赔”。

## 2. 结算时的常见处理方式
按优先级从高到低：

- **有书面合同/供货协议**：按合同里的质量条款、损耗率、赔付标准执行。
- **有长期交易习惯**：比如行业惯例“到货坏果按实扣重”“坏果率超过3%部分由供应商承担”，按双方以往结算方式处理。
- **无明确约定**：先协商，通常采用：
  - 当场拒收坏果，只结算好果；
  - 已收货的，按坏果实际重量/金额在下一笔货款中抵扣；
  - 少量坏果可要求换货，而不是直接扣全款。

## 3. 赔付怎么算更合理
建议用“可核验的数量×进货单价”计算，而不是拍脑袋扣款：

- 赔付金额 = 坏果数量 × 该批次进货单价
- 若坏果导致整箱无法销售，可按整箱进货价扣减，但应保留坏果或照片、称重记录
- 若只是部分影响，按实际坏果重量扣减
- 若供应商同意换货，则“坏果退回、好果补发”，一般不再重复扣款

## 4. 操作上必须留的证据
发生争议时，以下材料最关键：

- 送货单/进货单，注明批次、品种、数量、单价
- 坏果照片/视频，最好带日期和称重画面
- 坏果称重记录或封存样品
- 与供应商的微信/聊天记录，确认对方知悉并同意处理方案
- 冷链温度记录、到货时间、入库记录（证明不是门店储存问题）

## 5. 建议的沟通话术
可以直接说：

> “这批货到货后发现X箱/ X斤坏果，已拍照和称重，属于到货质量问题。按我们之前约定/本次协商，建议这部分按进货价扣减，或在下次货款中抵扣；如果你们方便，也可以换货。请今天确认处理方式，避免影响后续结算。”

## 6. 避免三个坑
- **不要先销售再事后大面积报损**：供应商容易质疑责任归属。
- **不要没有记录就直接扣款**：容易引发对账纠纷。
- **不要把门店损耗全部算给供应商**：长期看会破坏供货关系，也不符合责任划分。

**一句话总结：到货坏果当场验、拍照称重、单据注明；能拒收就拒收，不能拒收按实际坏果数量和进货价扣减或换货；门店自身储存损耗自行承担。**
