压低成本又不掉品质，核心不是“硬砍价”，而是把价格谈成条件组合：用确定性、账期、规格、包装、损耗分担换价格，同时把品质写进验收和扣罚。下面给你一套可直接用的谈判打法。

**一、先做成本拆解，别只谈“单价”**
- 把报价拆成：果径/等级、产地、包装、运费、损耗率、账期、退换货、促销支持。
- 同一品种让供应商报三档：A级、B级、统货，明确各档到店成本。
- 用“到店可售成本”比较：单价 + 运费 + 包装 + 预计损耗 - 返利，而不是只看采购价。

**二、用“增量+确定性”换价，而不是压品质**
- 承诺销量或包园/包批次：例如“这个月固定走X吨，但价格按阶梯给”。
- 用账期换价：现结/短账期通常能拿到更好价，但要把现金流算进去。
- 集中SKU：减少供应商数量，把量集中给1-2家，换年度返利或季度返利。
- 错峰采购：提前锁价、尾季补货、产地直发，避开节日高价。
- 包装简化：散装、周转筐替代精包装，省下的包材费让利到单价。
- 运费共担：自提、拼车、集中到仓，明确谁承担装卸和短驳。

**三、品质不能只靠口头，写进合同和验收**
- 验收标准量化：果径、糖度、色泽、软硬度、瑕疵率、农残检测报告。
- 设“品质扣罚”：到店抽检不合格按比例扣款、退货或补货，损耗超过约定由供应商分担。
- 分级定价：不要用A级价格收统货，也不要让供应商用B级充A级；每档价差写清楚。
- 试单机制：新供应商先小批量试单，连续合格再放量。
- 留样和拍照记录：到货即抽检，问题批次留证，避免扯皮。

**四、谈判话术可以直接用**
- “我不是单纯要低价，我要的是到店可售成本最低。你把运费、包装、损耗算进去，给我一个到店价。”
- “量我可以集中给你，但价格要按阶梯走；品质按验收标准扣罚，合格我长期走。”
- “现结可以，但单价要让；账期长也可以，但你要承担损耗和退换。”
- “这批统货可以收，但按统货价，瑕疵率超过X%我拒收或扣款。”

**五、别踩的坑**
- 不要只压单价导致供应商降级供货、掺次果。
- 不要口头承诺销量却不写进合同，供应商不会真让价。
- 不要把所有风险压给供应商，否则优质供应商会退出。
- 不要忽略隐性成本：损耗、退换、账期资金占用、频繁换供应商的品控成本。

**可执行建议：** 先选2-3个走量单品做成本拆解，和现有供应商谈“阶梯价+账期+验收扣罚”组合；同时找1家产地直发做试单对比。目标是到店可售成本降3%-8%，而不是采购单价降10%却把损耗和客诉拉上去。
