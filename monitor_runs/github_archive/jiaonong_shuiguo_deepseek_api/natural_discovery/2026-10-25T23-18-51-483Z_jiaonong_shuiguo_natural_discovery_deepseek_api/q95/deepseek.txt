选学校食堂水果供应商，重点不是“找最便宜的”，而是**先定准入标准，再比价，最后用小批量试供验证**。常见水果供应商可按下面做。

**一、先明确食堂采购的特殊要求**
1. **资质齐全**：营业执照、食品经营许可证/食用农产品销售相关资质；能提供每批次检测报告或承诺书。
2. **可追溯**：能说清产地、批次、采摘/进货日期，出现农残或质量问题能追责。
3. **配送稳定**：学校通常固定时间到货，要求供应商有冷链或通风运输能力，香蕉、苹果、橙子分开码放，避免压伤。
4. **退换货机制**：烂果、碰伤、成熟度不符要能当场退换，不扯皮。
5. **价格透明**：报价含税、含运费、含损耗处理，避免低价中标后加价。

**二、供应商渠道怎么找**
- **本地一级批发商/水果配送公司**：适合学校日常量，响应快，退换方便。
- **产地合作社或大型果品企业**：适合苹果、橙子这类耐储水果，可谈长期协议，但要有本地仓储或配送能力。
- **商超供应链/团餐配送商**：资质规范，适合对合规要求高的学校，但价格通常略高。
- **不要只找单个小贩**：除非量很小且学校能严格验收，否则供应稳定性、票据和追溯都弱。

**三、比选时看什么**
建议让供应商按“品种、规格、等级、产地、到货价、损耗率、配送频次、结算方式”报价，统一标准再比。
- **香蕉**：看成熟度（到货青黄适中，适合2—3天用完）、单把重量、碰伤率。
- **苹果**：看规格（如75/80果）、脆度、糖度、表皮完整度，耐储性要好。
- **橙子**：看产地和品种、酸甜度、果径、出汁率，避免皮厚干水。
- **共性指标**：农残检测、腐烂率、大小均匀度、包装完好、到货温度。

**四、最有效的办法：小批量试供**
先选2—3家，各试供1—2周，每天记录：
- 到货合格率、烂果率；
- 实际损耗和退货响应速度；
- 价格是否稳定；
- 配送是否准时；
- 票据和检测报告是否齐全。

试供后再签季度或学期框架协议，约定**质量标准、浮动调价机制、退换货时限、违约处理**。不要一次签太长，水果价格波动大。

**五、简单可执行的筛选顺序**
1. 收资质和报价单，筛掉证照不全、不能追溯的；
2. 选2—3家本地配送商试供；
3. 用“合格率+损耗+响应速度+价格”打分；
4. 签短期协议，保留第二供应商备用。

一句话：**学校食堂选水果供应商，先看合规和可追溯，再看配送和退换，最后比价格；用试供数据说话，别只看报价。**
