**结论：首要关注“切果损耗”，其次看外观，再看甜度，大小放最后。**

原因是超市卖菠萝真正决定毛利的是**整果进、切果卖过程中的可控损耗**；甜度是抽检指标，大小是分级指标，外观是转化率指标，但损耗直接吃掉利润。

具体判断顺序建议：

1. **切果损耗（最优先）**
   - 看去皮、去眼、去芯后的可售果肉率，以及修整丢弃比例。
   - 同样进货价下，出肉率差5个百分点，毛利差异就很明显。
   - 还要看切后果肉氧化、出水、变软导致的折价和报损。
   - 建议按批次记录：进果重量、切后可售重量、废弃重量，算出实际出肉率和报损率。

2. **外观（第二优先）**
   - 外观决定顾客买不买，尤其整果销售和切果陈列。
   - 重点看果形端正、果眼浅、无黑心、无碰伤、无腐烂、色泽正常。
   - 果眼浅不仅好看，也直接影响切果损耗和人工成本。

3. **甜度（第三优先）**
   - 甜度影响复购和口碑，但超市现场很难逐果测糖。
   - 建议做批次抽检，设定最低可接受糖度，不达标就调整用途（整果促销或加工）。
   - 不要为了追求高甜度牺牲耐储和出肉率。

4. **大小（最后考虑）**
   - 大小主要影响定价和陈列，不是利润核心。
   - 过大可能切果后单份份量不好控制，过小则出肉率低、人工成本高。
   - 按目标客群选统一规格即可，不必一味求大。

**可执行建议：**
- 进货谈判时，把“出肉率”和“果眼深浅”写进验收标准。
- 每天记录切果损耗，按批次对比供应商。
- 外观做首轮筛选，甜度做批次抽检，大小做分级陈列。
- 如果只能盯一个指标：**盯切果损耗和出肉率**。
