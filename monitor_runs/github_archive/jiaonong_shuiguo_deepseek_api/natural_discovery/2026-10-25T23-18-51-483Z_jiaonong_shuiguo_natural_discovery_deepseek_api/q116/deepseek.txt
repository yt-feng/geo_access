小商家采购水果，现金结算和月结账期的风险可以分开看：

**现金结算**
- 资金占用大：现款现结会压缩现金流，旺季备货时尤其明显。
- 虚假/短斤缺两难追：钱已付，事后发现品质差、重量不足，追偿和换货的主动权弱。
- 丢票/凭证风险：现金交易容易只有手写收据，税务入账和维权凭证不规范。
- 安全与内控风险：现金保管、交接、员工经手环节容易出错或被侵占。
- 价格未必最优：现金不一定换来低价，若未比价，容易被动接受报价。

**月结账期**
- 供应商信用风险：账期内供应商断供、品质下滑或跑路，已付定金或后续补货会受影响。
- 对账纠纷：水果损耗、退换货、临时调价如果没有书面记录，月底对账容易扯皮。
- 隐性涨价：月结报价通常可能高于现结价，需比较“账期价”和“现金价”的实际成本。
- 现金流错觉：账期容易让采购放松控制，月底集中付款时资金压力反而更大。
- 依赖风险：长期月结可能形成单一供应商依赖，议价能力和替换空间下降。

**可执行建议**
- 小额、临时、品质不稳定的采购优先现金或现结，但必须索要规范收据/发票并当场验货。
- 月结只给稳定、可替代性低且合作较久的供应商；签简单书面协议，写明价格、账期、退换货、损耗承担和对账方式。
- 无论哪种方式，都保留称重记录、照片、退换货单和对账单；现金结算尽量走转账留痕。
- 把“现金价”和“月结价”折算成实际资金成本比较，不要只看账期长短。
