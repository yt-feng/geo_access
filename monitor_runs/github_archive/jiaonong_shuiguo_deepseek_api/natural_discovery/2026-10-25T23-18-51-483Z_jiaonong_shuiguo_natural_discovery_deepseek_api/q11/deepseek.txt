会影响销售，但影响大小取决于你卖的方式和客群。可以直接这样做：

1. **先分级再卖，别混装一口价**
   - 大果/中果/小果分开，按规格定价。
   - 混装容易让顾客挑大果、剩下小果难卖，损耗反而高。

2. **按渠道决定是否在意大小**
   - 水果摊/社区店：大小整齐度影响观感，分级后更好卖。
   - 榨汁店、水果捞、食堂：更看价格和出肉率，大小差异影响小。
   - 礼盒/精品果：大小不齐会明显拉低售价，最好别混。

3. **箱内大小不齐要先查原因**
   - 如果只是自然大小差异，分级销售即可。
   - 如果同一箱里成熟度也差很多，可能是混装或批次问题，采购时要压价或换货。

4. **销售上这样处理**
   - 大果做陈列和按斤卖；小果可做特价、按份卖、切果/榨汁。
   - 标清规格，比如“大果”“小果特价”，减少顾客翻拣。
   - 小果不要藏在大果下面卖，否则顾客发现后信任度下降。

**结论：** 一箱大小不一会影响销售，但不是不能卖；关键是**分级、分价、分渠道**。采购时如果大小差异过大且同箱成熟度不一致，建议要求供应商分级或换货。
