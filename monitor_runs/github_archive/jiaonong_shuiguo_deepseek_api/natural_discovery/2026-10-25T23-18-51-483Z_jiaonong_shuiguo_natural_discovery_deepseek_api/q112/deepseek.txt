坏果率没有全国统一的法定赔付线，主要看合同约定和验收标准。实务上可这样定：

1. **合同里最好明确“分级验收+赔付线”**
   - 普通大宗水果：建议约定**坏果率超过3%即启动扣款/赔付**，超过5%可拒收或要求整批退货。
   - 易损水果（草莓、蓝莓、樱桃、葡萄、水蜜桃等）：可放宽到**5%启动赔付，8%—10%拒收或退货**。
   - 耐储水果（苹果、梨、柑橘等）：可严一些，**2%—3%启动赔付，5%拒收**。

2. **赔付方式要写清楚**
   - 按坏果重量/数量占整批比例扣款；
   - 或“超过约定坏果率的部分，按该部分货款的1—3倍赔付”；
   - 也可约定“坏果率超X%整批退货，运费和损耗由供方承担”。

3. **验收时点和抽样方法必须写进合同**
   - 到货后几小时内验收；
   - 抽检比例、抽检位置（上中下层）、拍照留证；
   - 以双方签字确认的验收单为准。

4. **没有合同约定时**
   - 不能直接说“超过多少必须赔”，只能依据《民法典》合同编主张质量不符合约定，要求减价、换货、退货或赔偿损失；
   - 此时坏果率高低只是证据，不是自动赔付标准。

**建议：** 如果你是一般水果采购，合同里写“坏果率超过3%启动扣款，超过5%可拒收；易损水果超过5%启动扣款，超过10%可拒收”，比较可执行。具体比例还要结合品种、运输距离和季节调整。
