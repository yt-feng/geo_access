建议把三种方式做成组合，而不是只选一种：

1. **主推整果，让顾客自己挑**
   - 菠萝顾客很在意成熟度、香味、有没有黑心，自己挑参与感强、纠纷少。
   - 整果损耗最低，毛利最好。
   - 适合放在显眼位置，标清“可现场免费削皮/切块”。

2. **提供去皮好的，但做成“加工服务”和“便利品”**
   - 去皮果适合赶时间、不会削、买来马上吃的顾客。
   - 不要提前大量去皮陈列，容易氧化、出水、损耗高；建议**顾客挑好整果后现场削**，或少量预制备用。
   - 去皮装盒要冷藏陈列、当天售完，并明确“加工后不退换”的规则，避免口感纠纷。

3. **让顾客自己挑是核心，但给筛选标准**
   - 可挂个小提示：看叶冠新鲜、闻底部有香味、按压略软、无酒味。
   - 店员可帮看黑心、过熟，减少售后。

**落地建议：**
- 整果占陈列主位，去皮果只做少量便利装；
- 默认“顾客自选整果 + 免费现场削皮”，去皮装盒作为补充；
- 去皮果定价可略高覆盖人工和损耗；
- 高峰期提前备少量，但不要过量。

这样既保损耗和毛利，又满足便利需求，比三选一更稳。
