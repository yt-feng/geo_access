做生鲜一件代发水果，供应商的仓配能力重点不是“能发货”，而是**在低客单、易损耗、时效敏感条件下稳定履约**。建议按以下维度评估，并设置可验收标准。

### 1. 仓储能力
- **专业温区**：至少有保鲜库/冷藏库，能按水果品类分温区存放；香蕉、芒果等后熟型需单独催熟/存放区。
- **日处理产能**：按平台日单量峰值评估，供应商日拣货打包能力建议≥峰值单量的1.5倍。
- **库存准确率**：要求≥99.5%，支持批次、效期、产地管理，能先进先出。
- **质检与分级**：入库质检、坏果剔除、按规格分级，能提供抽检记录和坏果率数据。
- **包装能力**：有水果专用包装方案，防撞、防压、透气、控温，能按平台SKU做定制化包装。

### 2. 配送履约能力
- **发货时效**：下单后24小时内出库，截单时间明确；大促有加班产能预案。
- **快递资源**：与至少2家以上快递/冷链物流合作，重点区域可次日达或隔日达；能提供物流轨迹回传。
- **冷链能力**：对草莓、蓝莓、荔枝、樱桃等易腐品，具备冷链干线+保温箱/冰袋方案；普通水果可常温但需控温运输。
- **覆盖范围**：明确可发区域、禁发区域、偏远地区时效和加价规则。
- **异常处理**：丢件、破损、延迟、变质有明确赔付和补发流程。

### 3. 订单与系统能力
- **系统对接**：支持API/ERP/WMS对接，能自动接单、回传单号、同步库存。
- **库存同步**：实时或准实时库存同步，避免超卖。
- **面单与溯源**：支持平台电子面单，能提供批次溯源信息。
- **售后数据**：能按SKU回传坏果率、破损率、延迟率，便于平台考核。

### 4. 品控与售后能力
- **坏果率承诺**：建议合同约定签收后坏果率上限，如≤5%，超出按比例赔付或补发。
- **售后响应**：售后工单2小时内响应，24小时内给出处理方案。
- **补发/退款机制**：明确举证方式，如开箱视频、照片，避免扯皮。
- **保险**：易腐品建议有货损险或履约险。

### 5. 弹性与合规
- **产能弹性**：能应对平台活动峰值，临时增加打包人力。
- **合规资质**：营业执照、食品经营许可/食用农产品相关资质、产地证明或检测报告。
- **应急预案**：爆单、快递停发、极端天气、疫情管控时有替代方案。

### 建议验收指标
可直接写进合作门槛：
- 日峰值发货能力≥平台预估峰值1.5倍；
- 订单24小时出库率≥98%；
- 库存准确率≥99.5%；
- 物流轨迹回传率≥99%；
- 签收坏果率≤5%；
- 售后2小时响应、24小时闭环；
- 支持API对接和电子面单。

**结论**：供应商至少应具备“分温区仓储+分级质检+定制包装+稳定快递/冷链+系统对接+坏果赔付”六项核心能力；缺任何一项，一件代发水果的履约风险和售后成本都会明显上升。
