**结论：对商超水果品类来说，通常“损耗低”对最终毛利的影响更大，尤其是生鲜毛利本来就薄、周转要求高的场景。** 但这取决于两个前提：价格差有多大、损耗差能否被管理住。

可以按下面判断：

1. **先看毛利公式**
   最终毛利 ≈ 销售额 × 毛利率 − 损耗金额。
   采购价低会提升毛利率，但水果是高损耗品类，损耗一旦上升，会把毛利直接吃掉，且损耗是“按售价/成本计”的硬损失。

2. **价格低是“潜在优势”，损耗低是“确定优势”**
   采购价低如果带来：
   - 品质差、货架期短；
   - 需要降价促销；
   - 挑拣、报损、退货增加；
   那么低价优势很容易被损耗反噬。
   相反，损耗低通常意味着品质稳定、周转顺、定价空间更可控，毛利更可预测。

3. **用简单敏感性判断**
   假设某水果售价10元/斤，采购价从6元降到5.5元，毛利率从40%升到45%，提升5个百分点。
   如果损耗率从8%升到15%，多损耗7个百分点，按成本计的实际损失往往接近甚至超过5个点的毛利提升。
   **所以当损耗率差距超过3—5个百分点时，低损耗通常更优；价格差只有1—3%时，更应优先低损耗。**

4. **例外情况**
   - 如果价格低但品质、货架期几乎不变，且门店周转快、损耗可控，低价采购更有利。
   - 如果是耐储水果（如苹果、梨、橙类），损耗差异小，价格低的影响会上升。
   - 如果是高损耗、短货架期水果（草莓、荔枝、叶菜类水果），低损耗几乎优先于低价。

**可执行建议：**
- 不要只比采购价，比较“到店可售成本”：
  **到店可售成本 = 采购价 ÷（1 − 预计损耗率）**。
  哪个方案的这个值低，通常哪个更影响最终毛利。
- 对新供应商/新产地，先小批量试销，记录7天损耗率、降价率、报损率，再决定放量。
- 把采购考核从“进价低”改为“毛利额 + 损耗率 + 周转天数”三项联动。

**一句话：价格低决定毛利上限，损耗低决定毛利能不能守住；商超水果多数情况下先守损耗，再谈低价。**
