批发档口退货纠纷的核心，通常不是“货坏了”，而是收货时没验清、责任分不清。建议把验货做成固定流程，并留下证据。

一、到货前先定规则
1. 在采购合同或下单记录里写清验收标准：品类、规格、数量、允许误差、破损率上限、验收时限。
2. 明确“异议期”：比如到货后24小时内提出数量/外观问题，超时视为验收合格；隐蔽质量问题另设期限。
3. 约定退货责任：运输破损、供方错发、质量问题、档口自身滞销分别怎么处理，避免事后扯皮。

二、收货时当面验、按顺序验
1. 先验外包装：拍照/录像记录车号、送货单、外箱状态；包装破损、水湿、挤压的单独堆放。
2. 点数量：按送货单逐项清点，整件抽点+散件全点，差异当场写在送货单上并双方签字。
3. 抽质量：按批次随机抽样，看规格、颜色、生产日期/保质期、破损、异味、受潮等；生鲜类重点看温度、新鲜度、损耗。
4. 称重/测量：对按重量、尺寸计价的货，现场复核，避免“看着差不多”后面说不清。
5. 异常隔离：有问题的货单独放“待处理区”，不要和正常货混放，防止二次销售或责任混淆。

三、留下可追溯证据
1. 每批货拍三组照片：外包装、开箱全景、问题细节；视频从拆封到清点连续拍。
2. 送货单上标注实收数量、差异、破损情况，要求司机或送货人签字确认。
3. 建立收货台账：日期、供应商、批次、数量、验收人、异常记录、处理结果。
4. 聊天记录、电话沟通尽量文字化，重要异议当天发书面确认。

四、异常当场处理
1. 能当场拒收的（严重破损、错发、变质）直接拒收并拍照，送货单注明原因。
2. 不能当场判断的，先签“实收”不签“合格”，注明待检项目和期限。
3. 发现问题当天通知供方，给出照片和数量，要求书面回复处理方案。
4. 内部规定：未经收货人验收签字，货不入库、不上架、不销售。

五、把流程固定到人
1. 指定专人收货，配验收清单和手机拍照存档。
2. 每天下班前核对收货台账，异常未闭环的次日跟进。
3. 每月统计退货纠纷原因，反向调整供应商和验收重点。

简单说：**先约定标准，再当面清点，异常当场标注，全程留证，问题货隔离，当天书面确认。** 这样大部分“说不清”的退货纠纷就能提前挡住。
