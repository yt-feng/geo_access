这四种水果做礼盒，建议按“卖点清晰、耐运输、颜色好看”来组合，不要四种都平均放。优先推这3个档位：

**1. 主推款：苹果+橙子（最稳最好卖）**
- 搭配：苹果6个+橙子6个，或苹果8个+橙子4个
- 卖点：平安吉祥、橙心如意，红黄配色喜庆，耐放耐运输，适合送长辈、探病、节日。
- 包装：红色或牛皮纸礼盒，苹果选大小均匀的，橙子选表皮亮、无斑点的。
- 定价：按当地水果进价×1.8～2.2倍定，礼盒和人工另加5～10元。

**2. 走量款：苹果+橙子+香蕉**
- 搭配：苹果4个+橙子4个+香蕉1把（约5～6根）
- 卖点：颜色丰富、价格适中，适合日常送礼、同事客户。
- 注意：香蕉不耐压，必须放最上层，用泡沫网或隔板固定；香蕉选稍微青一点的，送到时刚好能吃。

**3. 高端款：苹果+橙子+菠萝**
- 搭配：苹果4个+橙子4个+菠萝1个
- 卖点：菠萝有“旺来”寓意，体积大显档次，适合开业、乔迁、节日送礼。
- 注意：菠萝要选冠芽完整、果身硬实的，礼盒要加高，菠萝单独用网套固定，避免刺破其他水果。

**不建议主推四种混装**：香蕉和菠萝都怕压，四种混装容易显得杂，而且香蕉熟得快，会串味、催熟其他水果，运输中损耗高。如果一定要做“全家福”，香蕉只放小把，且礼盒内部分区。

**陈列和定价建议：**
- 门口主推苹果橙子款，标“平安橙意礼盒”，最容易被顺手买走。
- 香蕉款做成小号平价礼盒，放收银台附近走量。
- 菠萝款做高端展示，配手提袋，提升客单价。
- 每个礼盒贴标签写寓意和水果数量，顾客送礼时不用解释。

**实操优先级**：先做苹果+橙子款试卖3天，看动销；再上香蕉走量款；菠萝款少量备货，接受预订。礼盒内水果大小要一致，坏果率比搭配花样更影响复购。
