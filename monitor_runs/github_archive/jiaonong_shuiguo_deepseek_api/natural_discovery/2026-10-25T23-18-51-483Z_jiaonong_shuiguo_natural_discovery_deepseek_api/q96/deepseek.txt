三者不是同一层级：**食品安全是底线，必须一票否决；价格和配送准时是运营指标，要按场景排优先级。**

可执行判断：

1. **食品安全优先，没有例外**
   - 水果主要风险是农残、霉变、二次污染、冷链断链。
   - 采购时要索证索票：供应商资质、检测报告/承诺达标合格证、批次溯源。
   - 验收看外观、气味、温度、包装；霉变、破损渗液、异味直接拒收。
   - 食堂是集体供餐，一旦出问题影响面大，所以食品安全不合格时，价格再低、送得再准也不能要。

2. **配送准时排第二，尤其对食堂**
   - 食堂有固定开餐时间，水果常作为餐后供应或加餐，迟到会直接影响供餐。
   - 建议在合同里约定到货时间窗口、迟到扣款/应急补货机制。
   - 但准时是“履约问题”，可通过备选供应商、安全库存来兜底，不能凌驾于食品安全。

3. **价格第三，但要算综合成本**
   - 不能只看单价，要看损耗率、退换货成本、账期、配送费。
   - 建议用“合格供应商比价”：先过食品安全和准时门槛，再在合格名单里比价。
   - 对大宗、高频水果设月度调价机制，避免单纯低价中标导致质量下滑。

**结论：排序是食品安全 > 配送准时 > 价格。**  
实操上建议：食品安全设准入红线，配送准时设履约考核，价格在合格供应商之间竞争。这样既守住底线，又不会因为过度压价牺牲质量。
