水果生意想长期稳定，选供应商时最容易忽视的，不是价格，而是下面这些“平时不显眼、出事很致命”的细节：

1. **只看大货样，不看连续到货质量**
   - 容易忽视：首批样品很好，后面批次波动大。
   - 建议：至少连续观察3—5批到货，记录规格、成熟度、损耗率、口感稳定性。供应商能不能稳定，比偶尔精品更重要。

2. **不核验产地和分级标准**
   - 容易忽视：只问“哪里产的”，不问具体产区、果园、采摘批次、分级口径。
   - 建议：明确果径、糖度、色泽、成熟度、允许瑕疵比例，最好写进采购标准，避免“好果坏果混装”。

3. **不问采后处理和时间**
   - 容易忽视：采摘后多久预冷、是否分级、运输温度、到货时货架期还剩多久。
   - 建议：问清采摘日期、预冷方式、冷链记录、运输时长。水果损耗很多不是买贵了，而是货架期被吃掉了。

4. **忽略损耗责任和验收规则**
   - 容易忽视：口头说“包售后”，实际到货后扯皮。
   - 建议：写清验收时限、抽检比例、烂果/压伤/规格不符的赔付方式，以及谁承担退货运费。

5. **不评估供应商的“缺货应对能力”**
   - 容易忽视：旺季或天气异常时，供应商优先保大客户，小客户被断供。
   - 建议：了解其合作果园数量、冷库能力、替代产区资源，最好有备选供应商，不要单一依赖。

6. **只看报价，不算综合到货成本**
   - 容易忽视：低价货损耗高、分拣人工多、售后扯皮成本大。
   - 建议：按“到货可用果成本”核算：采购价 + 运费 + 损耗 + 分拣人工 + 售后损失。

7. **不查供应商的结算和资金习惯**
   - 容易忽视：账期、押金、临时涨价、票据问题。
   - 建议：明确报价有效期、涨跌价机制、结算方式。长期合作要有价格调整规则，不能每次临时谈。

8. **不观察供应商是否“懂你的客户”**
   - 容易忽视：供应商只按自己的分级卖，不匹配你的销售场景。
   - 建议：告诉对方你做商超、社区团购还是水果店，需要的成熟度、包装规格、货架期不同，能配合调整的供应商更值得长期合作。

9. **不建立供应商档案和月度复盘**
   - 容易忽视：凭感觉换供应商，问题重复发生。
   - 建议：记录每批到货的合格率、损耗率、售后率、准时率、价格稳定性，每月打分。长期稳定靠数据，不靠关系。

10. **忽略合规和食品安全细节**
   - 容易忽视：农残检测、包装标识、冷链卫生、发票资质。
   - 建议：至少保留检测报告或承诺书，包装标签规范，避免抽检和客诉风险。

一句话总结：**选供应商不要只选“这次货好、价格低”的，要选“批次稳定、规则清楚、出事能担责、缺货有预案”的。** 最容易忽视的，往往就是验收标准、损耗责任和持续供货能力。
