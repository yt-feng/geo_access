香蕉怕压、怕冷、怕乙烯，配送中要做到“少挤压、控温度、控气体、快周转”。可执行建议如下：

1. **按成熟度分仓发货**
   - 线上售卖时标注“青蕉/微黄/即食熟蕉”，不同成熟度分开库存和配送。
   - 配送距离远的发青一点，近距离或即时零售发微黄、熟蕉。
   - 熟蕉不要和苹果、梨、番茄等乙烯释放大的果蔬混装。

2. **包装防压**
   - 用带隔槽的瓦楞纸箱或塑料周转筐，单层摆放，香蕉之间用纸板/泡沫网套隔开。
   - 每根香蕉套防摩擦网套，尤其是蕉指连接处。
   - 箱内留少量缓冲，但不要过松导致滚动；可用瓦楞隔板固定。
   - 不要堆叠过高，重物不能压在香蕉上。

3. **控制温度，避免冷害**
   - 香蕉适宜储运温度大致在 **13–15℃**，不要低于 **12℃**，否则易冷害变黑。
   - 夏季配送避免暴晒和车厢高温；冬季避免贴近冷源。
   - 即时配送用保温袋时，不要直接放冰袋接触香蕉，可用隔层隔开。

4. **控制乙烯和湿度**
   - 包装箱可留少量通风孔，避免密闭闷热。
   - 不要与高乙烯水果混放。
   - 可考虑使用乙烯吸收剂，但要按供应商说明使用，不能替代温控和周转。
   - 湿度不宜过高，避免箱内结露；可在箱底加薄吸水纸，不要直接包塑料膜。

5. **减少转运次数和跌落**
   - 香蕉属于易损品，尽量走“仓—前置仓—骑手”短链路，减少分拣次数。
   - 分拣线避免高落差跌落，箱体标注“请勿重压、避免倒置”。
   - 骑手配送箱内用隔板固定，避免刹车时滚动碰撞。

6. **设置验收和赔付规则**
   - 商品页明确“轻微表皮斑点不影响食用”和严重压伤/黑腐的赔付标准。
   - 要求用户收货后及时开箱，熟蕉尽快食用或冷藏保存。
   - 对高频投诉路线复盘包装和成熟度，按线路调整发货成熟度。

7. **小规模测试再放量**
   - 选2—3条典型线路做7—14天测试，记录压伤率、黑变率、客诉率。
   - 重点比较：网套+隔板 vs 仅纸箱；青蕉 vs 微黄蕉；保温袋有无隔冷层。
   - 用客诉率和损耗率决定包装升级，不要一开始全量换包材。

核心原则：**远发青、近发黄；单层隔槽不堆压；13–15℃不挨冰；少转运、快送达；包装测试后再放量。**
