茶饮店用香蕉，核心是按**用途分熟度采购**，并在门店做“到货熟度分级+短期催熟/抑制”管理。香蕉是呼吸跃变型水果，采购熟度不是越黄越好，而是要看你是做冰沙/奶昔、捣泥、切片装饰、烘焙甜品还是炸香蕉。

下面按可执行标准说。

## 1. 先按用途定采购熟度

| 用途 | 推荐到货熟度 | 外观/手感 | 理由 |
|---|---|---|---|
| 香蕉奶昔、冰沙、捣泥入饮品 | 7～8成熟 | 表皮大部分黄、两端略绿或刚转黄；轻按有弹性但不软烂 | 甜度够、香气足，打泥细腻，不至于发黑出水 |
| 切片装饰、顶部摆盘 | 6～7成熟 | 黄中带绿，手感偏硬；剥皮后不易塌 | 切片成形好，氧化慢一些 |
| 香蕉甜品、布丁、蛋糕夹层 | 8～9成熟 | 全黄、少量糖斑；手感软但果肉完整 | 香气和甜度高，适合捣泥/夹馅 |
| 香蕉派、烤香蕉、炸香蕉 | 7～8成熟 | 黄色均匀，略硬 | 加热后不易烂，成形好 |
| 香蕉面包/磅蛋糕 | 9成熟以上 | 皮有黑斑、果肉软 | 甜度高、香气浓，适合压泥 |

**不建议门店常规采购全黑熟蕉**，除非当天就要做香蕉面包或立即消耗；黑斑蕉适合加工，不适合切片和外卖饮品。

## 2. 采购时看“到货熟度”，不要只看颜色

到货验收建议用“颜色+手感+果指状态”三项：

- **颜色**：7成熟大约是黄色占70%～80%，两端仍有一点绿；8成熟基本全黄；9成熟出现少量糖斑。
- **手感**：轻捏果身有弹性，不硬邦邦，也不一按一个坑。
- **果指**：果指饱满、棱角不明显；棱角很突出的通常偏生。
- **果柄**：果柄新鲜、不干枯；果柄发黑不一定是坏，但要结合果身判断。
- **伤果**：拒收明显压伤、裂口、渗汁、大面积黑斑软烂的货。

## 3. 采购量按“3天窗口”控制

香蕉熟得快，门店不要一次压太多货。建议：

- **常规饮品店**：按2～3天用量采购，夏季可缩到1～2天。
- **到货分批**：同一批货里最好有7成熟和8成熟两档，先卖黄的，绿的再放1～2天。
- **天气调整**：夏季高温、后厨温度高时，减少8～9成熟采购比例；冬季可适当增加到货熟度。

## 4. 门店熟度管理

- **分开存放**：按熟度分筐，标注到货日期和熟度，先进先出。
- **催熟**：偏青香蕉放室温、避光、通风处；可和苹果/梨同袋密封催熟，但每天开袋透气，避免水汽导致霉变。
- **抑制过熟**：已经达到使用熟度的香蕉，放阴凉通风处；不要整串堆压。需要延缓时，可冷藏**熟蕉**，但冷藏后表皮会变黑，果肉仍可用，适合当天打泥，不适合展示。
- **不要低温存生蕉**：未熟香蕉冷藏会停止成熟并易变黑。
- **剥皮后处理**：果肉易氧化，现剥现用；打泥可加少量柠檬汁或维生素C溶液护色，但注意不要影响饮品风味。

## 5. 简单验收标准

收货时抽检：

1. 70%以上果指达到你定的目标熟度；
2. 无明显压伤、裂口、渗汁；
3. 果身饱满、手感有弹性；
4. 同批熟度差不超过1个等级；
5. 生蕉比例不超过20%，除非你计划分2～3天使用。

**一句话：饮品打泥选7～8成熟，切片装饰选6～7成熟，烘焙/香蕉面包选9成熟；采购按2～3天量、分批熟度进店，门店分筐先进先出。**
