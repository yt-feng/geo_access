便利店做水果，核心不是“品类越多越好”，而是**用最少SKU覆盖高频需求，用订货量和陈列量控损耗**。给你一套可直接落地的做法：

## 1. 品类控制：先做“6+4”结构

小门店水果建议控制在 **8–12个SKU**，最多不超过15个。结构如下：

**必保6类（高频、刚需）**
- 香蕉：引流款，周转快
- 苹果：耐放、大众
- 橙子/柑橘：耐放、季节性强
- 梨：耐放
- 圣女果/小番茄：小包装好卖
- 应季单品1个：夏天西瓜/葡萄，冬天砂糖橘

**可选4类（看商圈）**
- 提子/葡萄：办公区、年轻客群
- 芒果：社区店可试
- 火龙果：耐放、颜值高
- 切果/果切：只做1–2款，且必须当天清

**直接砍掉**：榴莲、山竹、车厘子、蓝莓等高单价高损耗品，除非有稳定预定客群；叶菜类水果（如草莓）初期不建议上。

## 2. 采购量控制：按“日销×周转天数”订货

- **耐放品**（苹果、梨、橙）：订货量 = 日均销量 × 3–5天
- **中周转品**（香蕉、圣女果）：订货量 = 日均销量 × 1.5–2天
- **高损耗品**（葡萄、芒果、果切）：订货量 = 日均销量 × 1天，宁少勿多
- 新店前两周：每个SKU只订**最小包装/最小箱**，用实际销量校准，不要凭感觉压货。

## 3. 陈列控损耗：少量多次、勤补货

- 陈列量只放**半天到一天销量**，卖完再补，不要一次堆满。
- 香蕉、葡萄等易损品用**小托盘/小筐**分装，减少翻拣。
- 每天早晚两次挑拣，把轻微瑕疵品**打折区**处理，不要混在正价区。
- 果切只做展示样品，现切现卖，闭店前1小时打折清货。

## 4. 损耗管理的硬指标

- 水果整体损耗率控制在 **5%–8%** 以内；超过10%说明品类或订货有问题。
- 每天记录：进货量、销量、报损量、打折量。连续3天某SKU销量低于订货量的一半，直接下架或减半订货。
- 设“止损线”：单品连续一周毛利覆盖不了损耗，就淘汰。

## 5. 采购渠道建议

- 小门店优先**本地批发市场+少量供应商配送**，不要一次从多个渠道进同品类。
- 香蕉、苹果等耐放品可固定供应商；葡萄、草莓等易损品少量多次拿货。
- 能和周边餐饮、果汁店做尾货合作更好，但不要为清货强行扩品。

**一句话原则：品类做减法，订货做小批量，陈列做少量多次，每天用销量数据淘汰不动销单品。** 先跑2–3周数据，再逐步加到10–12个SKU。
