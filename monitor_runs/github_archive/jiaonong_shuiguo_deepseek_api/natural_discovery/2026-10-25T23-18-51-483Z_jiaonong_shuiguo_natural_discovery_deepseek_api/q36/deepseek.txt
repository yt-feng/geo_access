建议优先做“整果为主、鲜切为辅”，不要二选一。判断标准主要看门店客群、损耗控制能力和动销速度。

**更适合卖整果的情况**
- 社区店、家庭客群为主，顾客有回家自己削菠萝的习惯。
- 门店人手紧，鲜切后厨/冷藏陈列条件一般。
- 菠萝进货价低、整果毛利空间足，且能做出堆头陈列。
- 整果耐放、损耗可控，适合走量。

**更适合卖鲜切的情况**
- 商圈店、写字楼店、年轻客群/即时消费客群多，图方便。
- 门店有干净操作间、冷藏陈列和较快动销能力。
- 能控制“当日切、当日清”，否则鲜切损耗和食品安全风险会吃掉利润。
- 鲜切可做小份装、组合果盒，提升客单价和冲动购买。

**实操建议**
1. **整果做引流和走量**：选1—2个高性价比品种，做堆头、试吃、整果特价。
2. **鲜切做增量**：只切动销最快的量，小份装、日清，剩余果心/边角可做试吃或员工餐，不建议隔夜再卖。
3. **看数据再定比例**：先试运行1—2周，记录整果和鲜切的日销量、损耗率、毛利额。若鲜切损耗率明显高于整果毛利增量，就收缩鲜切。
4. **按客流分门店策略**：社区店整果占比高，商圈/写字楼店鲜切占比可提高；同一连锁不必所有门店一个模型。
5. **采购端配合**：整果要耐储运、成熟度可控；鲜切要选果形规整、出肉率高、酸甜稳定的批次，避免为鲜切专门进过熟果。

结论：**多数商超以整果为主更稳，鲜切作为便利性补充；商圈年轻客群店可提高鲜切比例，但必须以日清和损耗可控为前提。**
