供应商介绍产品时，别从品种名和产地讲起，要从“商家拿去怎么卖、能赚什么、会踩什么坑”讲起。商家只熟悉大品类，本质是缺三样东西：**这东西卖给谁、跟谁摆一起、和熟品比有什么不同**。

给一个可直接套用的说法结构：

1. **一句话对位**：先说它相当于商家熟悉的哪个品类，再点出差异。  
   - 例：“这个不是让你替代香蕉，它是放在菠萝旁边的**高客单尝鲜款**，顾客买菠萝时顺手带一盒。”  
   - 避免“这是某某品种、糖度多少”开场，先建立熟悉坐标系。

2. **说清三个经营数字**：进价、建议售价、毛利空间；再补损耗和周转。  
   - “一箱进价X，建议按Y卖，毛利大概Z%；常温能放几天，冷藏几天，坏果率大概多少。”  
   - 商家最怕不是不懂品种，是怕压货和损耗。数字比形容词有用。

3. **给陈列和搭配方案**：直接告诉他摆哪儿、跟谁搭、卖给谁。  
   - “放菠萝端头，做‘菠萝+它’组合装；主推下午茶和家庭客，切盒比整果好走。”  
   - 最好给一张“陈列位置+推荐话术+组合价”的小卡片。

4. **拿熟品做对比，但只讲顾客能感知的差异**：  
   - 口感：比菠萝更甜/更软/更酸？  
   - 吃法：要不要削皮、是否好切盒、能不能直接吃？  
   - 场景：适合果切、礼盒、餐饮供货还是家庭囤货？  
   - 别讲太多专业术语，商家记不住，也没法转述给顾客。

5. **主动讲风险和改进办法**：  
   - “这个品怕冷，别放风幕柜最冷处；先小批量试销，三天看动销，不好走就转切盒或组合装。”  
   - 供应商先替商家想好退路，商家更敢下单。

6. **用试销降低决策门槛**：  
   - “先拿半箱/小件试摆三天，我给你配陈列卡和推荐话术；动销不行下次换品。”  
   - 对不熟悉品类的商家，“小单试销+陈列支持+损耗兜底方案”比低价更有说服力。

一句话总结：**用熟品定位、用毛利和损耗算账、用陈列场景告诉他怎么卖、用小单试销降低风险。** 供应商少讲“这是什么”，多讲“你拿去怎么赚钱、怎么不亏”。
