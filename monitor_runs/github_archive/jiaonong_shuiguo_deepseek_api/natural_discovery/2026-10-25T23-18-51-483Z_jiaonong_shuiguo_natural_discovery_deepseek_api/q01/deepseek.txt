判断水果供应商靠不靠谱，核心看五件事：稳定性、货损承担、账期与结算、信息透明度、替代能力。香蕉和菠萝都是“催熟/损耗敏感型”水果，标准要比普通水果更严。

**1. 先看稳定性，不看单次便宜**
- 连续试供2—4周，而不是只进一次货。看每周到货时间是否稳定、规格是否一致、成熟度是否可控。
- 香蕉重点看：到货青度是否统一、催熟后是否整齐转黄、有没有“青皮不熟”或“一箱里熟度差三档”的情况。
- 菠萝重点看：品种是否固定、单果重是否稳定、黑心/水心病/过熟比例高不高。
- 问清楚：货源是产地直发、一级批发还是拼货。拼货商价格可能低，但断货和品质波动更大。

**2. 看货损和售后怎么处理**
靠谱供应商敢明确规则：
- 到货当场验货，坏果、黑心菠萝、严重机械伤怎么赔，是补货、扣款还是下次抵扣。
- 香蕉催熟失败或成熟不齐，是否认账。
- 售后响应时间，是当天处理还是拖到下次。
如果对方只说“放心，没问题”，但不愿写清赔付规则，风险较高。

**3. 看账期与结算是否清楚**
- 先做现结或短账期试供，别一上来压大额账期。
- 问清价格是否含运费、装卸费、筐箱押金、催熟费。
- 报价是否随行就市，调价提前多久通知。
- 有没有最低起送量、临时加单是否加价。
结算清楚、调价有规则的供应商，长期合作更省心。

**4. 看信息透明度**
靠谱供应商能说清：
- 香蕉产地、品种、当前批次到货时间、建议催熟条件。
- 菠萝品种、产地、成熟度、适合几天内卖完。
- 近期行情和风险，比如产地涨价、天气影响、批次偏熟。
不是要求对方什么都透露，但至少不回避关键问题。

**5. 看替代和应急能力**
- 节假日前、天气异常时能不能保供。
- 临时少要或加要，是否灵活。
- 出现批次问题时，能不能快速换货或推荐替代品。
长期合作最怕“平时便宜，断货时找不到人”。

**实操建议：**
先选2家供应商并行试供3—4周，每周记录：到货准时率、坏果率、催熟合格率、售后处理速度、实际结算价。香蕉和菠萝分开打分。连续稳定的那家再逐步加大采购比例，但不要只留一家，保留一个备用供应商。

一句话：**敢让你验货、敢写赔付、连续几周品质稳、价格规则清楚的供应商，才值得长期合作；只靠低价和口头保证的，先小批量试。**
