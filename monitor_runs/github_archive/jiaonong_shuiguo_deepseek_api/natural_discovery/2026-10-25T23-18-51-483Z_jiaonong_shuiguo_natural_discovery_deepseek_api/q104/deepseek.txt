# 单位采购水果：品质不一致的验收与售后处理

## 一、验收前的准备

1. **把标准写进合同/订单**：不要只写"新鲜优质"。明确品名、品种、产地、规格（单果重/果径范围）、成熟度、允许瑕疵率（如≤5%）、糖度区间（如适用）、包装方式、到货时限。验收依据以订单标准为准，口头约定容易扯皮。
2. **约定抽检规则**：如"每批次随机抽检不少于3箱/总件数的5%，以抽检结果判定整批"，避免逐箱翻检耗时或供应商只认单箱。
3. **明确验收时限**：到货后多少小时内完成验收（建议生鲜当天完成），超时视为合格，防止事后追责无据。

## 二、到货验收怎么做

**现场四步：**

1. **核对单据与数量**：品名、规格、数量、批次与订单一致；称重核对（注意带箱重与净重之别）。
2. **分层抽检**：不能只看上层。按箱号随机抽取，重点查箱底、中层，防止"上好下差"。
3. **逐项记录**：
   - 外观：腐烂、霉变、碰伤、裂口、虫眼
   - 成熟度：过生/过熟比例
   - 规格：单果重或果径是否在约定范围
   - 口感/糖度：按需抽测
   - 温度与包装：冷链品查到货温度，包装是否破损受潮
4. **拍照留证**：问题果与整箱同框拍照，记录箱号、时间；抽检过程可录像。**证据是售后的前提。**

**判定方式：**
- 按约定的允许瑕疵率判定：超标即判不合格或降级。
- 区分"整批不合格"与"部分箱不合格"：前者拒收或整批退换，后者按箱退换并扣减货款。
- 现场填《验收记录单》，双方签字确认不合格数量与处理意见，避免离场后不认账。

## 三、分级处理原则

| 情况 | 处理 |
|---|---|
| 轻微瑕疵在约定范围内 | 正常收货，记录备查 |
| 部分箱超标 | 该部分拒收/退换，按实收数量结算 |
| 整批明显不达标（腐烂、规格错、品种错） | 整批拒收，要求限期补货；影响使用的可解除该批次 |
| 已收货后发现内部质量问题 | 在约定时限内凭证据提出，要求换货或折价 |

## 四、售后与索赔

1. **第一时间书面提出**：在约定时限内以书面形式（邮件/验收单/聊天记录）通知供应商，写明批次、数量、问题、诉求（换货/退货/折价/补发），附照片。
2. **明确诉求优先级**：单位食堂/福利发放通常要"保供"，优先要求**限期补换合格品**；无法补货的再谈退货退款或折价。
3. **折价参考**：按不合格比例扣款，或按实际可用数量结算；腐烂等不可用部分应全额扣除，运费/损耗责任按合同约定。
4. **留尾款约束**：合同中约定质保/尾款条款（如验收合格后付95%，余款一周后无质量问题结清），是最有效的售后杠杆。
5. **累计问题升级**：同一供应商多次不合格，记录在案，作为后续采购评审或更换供应商的依据；合同可设"连续X次不合格可终止合作"。

## 五、给采购人的实操建议

- **首次合作小批量试单**，稳定后再放量。
- **验收人固定、标准固定、记录固定**，避免每次口径不一。
- **生鲜当天验收、当天反馈**，隔夜后责任难界定。
- **保留样品**（问题果冷藏留存至售后结束），作为争议时的实物依据。

核心一句话：**标准前置到合同，证据固化在验收现场，诉求书面化并在时限内提出，用尾款和累计记录约束供应商。**
