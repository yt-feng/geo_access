找水果供应商，核心不是“谁报价低”，而是“谁能稳定每天送到、坏果少、结算清楚”。建议按下面几类条件筛选：

**1. 配送稳定性**
- 能否承诺每天固定时段送达，迟到怎么处理。
- 是否有冷藏车/保温箱，夏天和雨天是否照常配送。
- 节假日、极端天气是否有备货和替代方案。
- 起送量、配送费、临时加单截止时间。

**2. 货源与品质**
- 是产地直采、批发市场档口，还是二级分销；二级分销价格通常更高、稳定性更差。
- 能否提供当日或近两日到货批次，是否有农残检测或进货凭证。
- 坏果率、损耗赔付标准要写清楚：例如到货24小时内拍照报损，按比例补货或抵扣。
- 是否支持试销小批量、每周调整品类。

**3. 价格与结算**
- 报价是否含税、含运费、含包装。
- 价格随行就市时，提前多久通知调价。
- 账期还是现结；现结是否有返点，账期是否有押金。
- 对账方式：每日送货单、微信对账还是系统下单，避免口头价。

**4. 品类匹配度**
- 能否覆盖你店销量前20的常销水果，而不是只推高毛利单品。
- 是否按你的客群做小规格包装，比如家庭装、单身装、果切原料。
- 旺季能否保量，淡季是否强制搭售。

**5. 资质与风险**
- 营业执照、食品经营许可或食用农产品相关资质。
- 是否有固定经营场所和冷库，能否实地看货。
- 合同里写明：配送时间、品质标准、报损赔付、调价机制、违约退出条款。

**实操建议：**先找2—3家同时试供两周，每天记录到货时间、坏果率、缺货次数、对账是否清楚。重点看“连续7天是否准时”和“报损是否痛快赔付”，这两项比单价更能决定你店里的实际毛利。签约前最好去对方冷库和分拣现场看一次。
