商超会员日水果活动要落地，供应商要把“货、价、陈列、履约、应急”五件事提前锁死：

1. **提前锁量和锁货**
   - 按门店预估销量给分仓/分店备货，会员日主推品提前3-5天到仓，避免当天断货。
   - 对易损耗水果（草莓、蓝莓、榴莲、车厘子等）单独确认成熟度、批次和到店时间。
   - 明确安全库存和补货触发点，比如上午售罄率超70%即启动二次补货。

2. **价格和促销政策提前确认**
   - 会员价、限购价、第二件折扣等规则提前书面确认，避免收银系统和价签不一致。
   - 确认供应商是否承担促销差价、损耗补贴、赠品支持。
   - 价格保护期覆盖活动前3天到活动后1天，防止顾客比价投诉。

3. **品质标准和验收规则**
   - 提前给到糖度、规格、果径、颜色、瑕疵率标准，比如车厘子J级、草莓单果克重。
   - 约定到店验收不合格的处理方式：现场拒收、折价接收还是优先补货。
   - 活动前1天完成首批货抽检，留样拍照。

4. **包装、分拣和陈列支持**
   - 主推品做预包装或标准化果篮，减少门店现场分拣压力。
   - 提供陈列物料：价签、爆炸牌、试吃台、托盘、保鲜冰袋。
   - 安排驻店或巡店人员，高峰时段协助补货、理货、试吃引导。

5. **物流和到店时间**
   - 会员日当天首配要在开门前2小时到店，二次补货约定最晚到店时间。
   - 明确司机、联系人、异常到货沟通群，堵车或缺货30分钟内反馈。
   - 冷链品确认温控和到店测温记录。

6. **售后和损耗兜底**
   - 约定坏果包赔、临期折价、当日未售完处理方式。
   - 供应商准备备用货源，主推品断货时2小时内可替换同价位单品。
   - 活动后1天内完成对账，明确促销费用和损耗承担。

简单说，供应商提前要交四张表：**备货分货表、促销价格确认单、品质验收标准、应急补货联系人表**。这四样齐了，会员日水果活动基本不会出大乱子。
