最应该先问**售后**，其次核验**配送**，最后再谈**价格**。

原因很直接：团购团长卖的是“信任+履约”，水果又是高损耗、非标品，出问题时如果供应商不兜底，损失和口碑都会落在团长身上。

建议按这个顺序判断：

1. **先问售后：决定你会不会亏钱、丢客**
   - 坏果、烂果、重量不足怎么赔？按比例赔还是整单赔？
   - 理赔时限是收货后几小时？需要拍照/视频吗？
   - 是补发、退款还是抵扣下次货款？
   - 损耗率超过多少由供应商承担？
   - 团长垫付退款后，供应商多久结算？

2. **再核验配送：决定你能不能稳定开团**
   - 几点前下单、几点到自提点？迟到怎么处理？
   - 是冷链还是普通车？夏天/雨天怎么保证？
   - 起送量、配送费、临时加单接不接？
   - 缺货、少发时是否提前通知？能否按实际到货结算？
   - 破损率、迟到率能不能给历史数据或试团验证？

3. **最后谈价格：价格必须建立在售后和配送可履约上**
   - 不要只比单价，要算“到手可售成本”：进货价+损耗+赔付+配送+退款人工。
   - 要求试团1—2次，用真实履约结果再定长期价。
   - 价格低但售后差，最后通常是团长赔钱、群友流失。

一句话：**先问售后保底线，再验配送保体验，最后用价格做筛选。** 供应商如果回避售后细则，价格再低也不建议合作。
