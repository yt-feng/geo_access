会，而且香蕉、菠萝都属于“起订量一高，损耗风险明显放大”的品类，但两者原因和风险点不完全一样。

**香蕉：起订量高，损耗风险最敏感**
- 香蕉是呼吸跃变型水果，到货后还会继续成熟，销售窗口短。
- 起订量高会带来集中到货、集中催熟、集中上架，若门店销量跟不上，很容易从“青黄”快速滑到“过熟、黑斑、软烂”。
- 风险不只是坏掉，还包括为了清库存被迫打折，毛利被吃掉。
- 判断标准：看“到货后3—5天可售完量”是否覆盖起订量；如果起订量超过日均销量×可售天数，就要谨慎。

**菠萝：起订量高风险主要在储存和品质波动**
- 菠萝相对耐放一些，但整箱起订量高会占库容、增加堆压和通风不良风险。
- 菠萝有后熟和腐烂问题，尤其底部、果眼、机械伤部位容易出问题；批量大时抽检和翻堆不及时，坏果会扩散。
- 如果门店动销慢，菠萝会出现“外表还行、内部已过熟”的隐性损耗。
- 判断标准：看库容、翻检频率和周转天数；起订量超过7—10天销量时，风险明显上升。

**实操建议**
1. **按可售天数倒推起订量**：香蕉建议控制在3—5天销量内，菠萝控制在5—7天销量内；超过就拆分订单或换小规格。
2. **算综合损耗账**：不要只看单价便宜。起订量增加带来的损耗率上升，可能抵消采购折扣。
3. **分批到货**：和供应商谈“总量锁价、分批送货”，比一次性大起订更稳。
4. **设置预警线**：香蕉出现批量黄熟、菠萝出现底部软烂或异味时，立即促销或调拨，不要等坏果扩大。
5. **小批量试销**：新品或旺季前，先按小起订量跑1—2周动销数据，再决定是否放大。

结论：**会。香蕉的损耗风险最直接，菠萝次之但也不能忽视。起订量应优先服从“可售天数+库容+翻检能力”，而不是单纯追求采购单价。**
