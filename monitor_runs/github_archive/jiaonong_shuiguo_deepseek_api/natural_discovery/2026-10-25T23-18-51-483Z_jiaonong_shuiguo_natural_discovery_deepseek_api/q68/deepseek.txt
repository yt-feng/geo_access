判断“能不能按时到车”，核心是看**车证是否闭环、货源是否在手、装车是否排定、异常是否可追溯**。给你一套批发商能直接用的判断方法：

## 1. 先问清“到车”定义
让供应商明确：
- 到车时间：具体到**几点前到市场/档口**
- 到车地点：哪个市场、哪个门、是否限行时段
- 车型车长：几米车、载重、是否为冷藏/高栏
- 装车地：产地还是中转仓
- 是否含卸货：到车后谁卸、卸货排队谁承担

**不能只接受“明天到”“这两天发”这种模糊承诺。**

## 2. 看四个硬凭证
要求供应商提供可核验的东西：

1. **车辆信息**：车牌号、司机电话、车型
2. **装车计划**：哪天几点装、装车地点、装车负责人
3. **货源状态**：香蕉是已订园/已入库/已催熟，还是“还在找货”
4. **运输合同或派车单**：有派车记录比口头承诺可靠

如果对方只能给“放心”“肯定到”，但给不出车牌和装车时间，按时到车风险就高。

## 3. 判断货源是否真的在手
香蕉供应常见延误不是车的问题，是货没到位。重点问：
- 香蕉现在在**树上、产地仓、催熟库还是车上**
- 已装车比例多少
- 装车工人和包装是否已安排
- 雨天/寒潮是否影响砍蕉和装车

**货没到手，车到了也没用；货源没锁定，准时到车就是空话。**

## 4. 看供应商的排车能力
可以问：
- 这车是**自有车、长期合作车队还是临时找车**
- 最近三天发过几车、到车准点率如何
- 如果车临时放空，备用车多久能补上
- 装车地到市场正常运输时长和堵点

临时找车的供应商，遇到运价波动、司机爽约，延误概率明显更高。

## 5. 设置可执行的跟车节点
不要等到发车后才问。建议约定三个回报节点：
1. **装车前**：确认车牌、司机、装车时间
2. **装车中**：拍装车现场、过磅单/装车单
3. **发车后**：报高速入口时间、预计到达时间，途中每4—6小时更新位置

到车当天提前确认市场排队和卸货安排。

## 6. 合同/聊天里写清延误责任
至少写清：
- 约定到车时间
- 延误多久算违约
- 车未到或货未到，定金/预付款怎么退
- 因延误产生的市场空档、二次调车费用谁承担
- 香蕉质量因延误受损怎么处理

## 7. 一个简单判断表
满足以下多数项，可判为“较可靠”：
- 有明确车牌和司机电话
- 有装车时间和装车地点
- 货源已锁定，不是“还在找”
- 有派车单/运输记录
- 供应商近期有稳定发车记录
- 愿意接受节点回报和延误责任

**如果车牌、装车时间、货源状态三项里有两项说不清，就不要按“能按时到车”安排销售计划。**

最稳的做法：**先小批量试一车，记录其准点率，再决定是否给大单和预付。**
