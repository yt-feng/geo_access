# 判断香蕉这批货的熟度和坏果风险

批发环节判断香蕉，核心看**颜色、硬度、果指形态、果柄/切口、气味、箱内环境**六项，再结合季节和运输距离判断“能不能放、能放几天”。

## 一、看颜色定熟度

香蕉熟度一般按色卡分 1–7 级（全绿到全黄带褐斑）。批发常用判断：

- **全绿、棱角明显**：1–2 级，需催熟，适合长途或自己催熟，但太生时怕冷害和“死青”（催不熟）。
- **绿中带黄、棱角开始圆润**：3 级，最适合批发走货或短途催熟。
- **黄多绿少、棱角模糊**：4 级，已开始转熟，适合 1–3 天内出货。
- **全黄、果指饱满**：5 级，零售正好，批发压货风险大。
- **黄带少量褐斑（芝麻斑）**：6 级，必须当天/次日走完。
- **大面积褐斑、发黑**：7 级，坏果风险高，只能低价快出或加工。

**关键判断：** 看整箱是否“颜色均匀”。一箱里如果上层黄、下层绿，或个别果指先黄，说明受热/受压不均，后熟会不一致，坏果率会偏高。

## 二、摸硬度

- 果指**硬挺、按不动**：生，耐放。
- **略有弹性、不软塌**：适熟，正常走货。
- **按压明显下陷、发软**：过熟，批发风险高。
- **局部软斑**：碰撞伤或开始腐坏，重点挑出。

注意：香蕉怕冷，摸起来“冰凉发硬”且颜色发暗，可能是冷害，催熟后容易发黑、不转黄。

## 三、看果柄和切口

- 果柄**青绿、切口新鲜**：采收和运输较新。
- 果柄**干缩、发黑、切口褐变**：存放久或运输时间长。
- 果柄处**发霉、渗液**：冠腐病/霉菌风险，整箱要警惕。
- 果指连接处（果梳接口）**发黑软烂**：容易从接口开始烂。

## 四、看果指形态和表面

- 果指**饱满、棱角圆**：发育好，后熟品质稳定。
- 果指**瘦长、棱角尖**：偏生或营养不足，催熟后容易“硬心”。
- 表面有**明显机械伤、压痕、裂口**：坏果高风险，尤其裂口处易感染。
- 有**黑色小点但果肉不软**：可能是正常芝麻斑；若斑点周围发软渗水，就是腐坏前兆。

## 五、闻气味、查箱内

- 正常：清淡青草味或轻微果香。
- **酒味、酸味、发酵味**：已过熟或箱内发热，坏果风险很高。
- 开箱看**箱底、垫纸是否潮湿、有汁液**：有渗液说明已有烂果污染整箱。
- 摸箱内**温度是否明显发热**：发热会加速后熟和腐烂，尤其夏季长途货。

## 六、抽样和风险判断

不要只看上层。建议**随机抽 3–5 箱，每箱看上层、中层、底层**，重点查：

1. 颜色是否一致；
2. 底层有无软果、渗液；
3. 果柄接口有无霉变；
4. 箱内有无酒味/酸味；
5. 按压测试软果比例。

**粗略风险分级：**

- **低风险**：3 级左右、颜色均匀、果柄新鲜、无软果无渗液、无异味。可正常批发，预计 3–5 天走货（视温度）。
- **中风险**：4 级、少量软果或个别褐斑、箱内轻微闷味。建议快进快出，1–2 天内出货，挑出软果。
- **高风险**：5 级以上、颜色不均、底层软烂、有酒味/渗液/霉变。要么当天低价处理，要么拒收；不要压货。

## 七、结合季节和运输

- **夏季高温**：后熟快，4 级货可能一天就变 6 级，宁拿生一点（3 级）。
- **冬季/冷链**：注意冷害，颜色发暗、果柄干黑、摸起来硬但不转黄的不要拿。
- **长途货**：看切口和果柄新鲜度，运输超过 5–7 天的货，底层坏果概率明显上升。

**一句话原则：** 批发香蕉宁可拿“颜色略生、均匀、果柄新鲜、箱内干爽”的货，不要拿“颜色好看但底层软、有酒味”的货；后者坏果会成箱扩散。
