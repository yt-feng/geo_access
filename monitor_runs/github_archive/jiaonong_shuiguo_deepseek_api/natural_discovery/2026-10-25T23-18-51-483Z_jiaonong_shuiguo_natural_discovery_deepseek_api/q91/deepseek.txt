建议按“主力+补充”来配，不要只选一种：

1. **主力选单根**
- 适合便利店“即时消费、顺手买”的场景。
- 降低顾客决策门槛，减少整把/整袋卖不完的损耗。
- 适合早餐、加班、临时充饥。

2. **补充选小把（2～3根）**
- 适合家庭少量采购、办公室分享。
- 客单价高于单根，但比整袋灵活。
- 建议只占香蕉陈列的较小比例。

3. **整袋谨慎上**
- 只适合社区型、家庭客群明显的门店，或做促销组合。
- 香蕉易压伤、成熟快，整袋损耗和售后风险更高。
- 若上整袋，选耐储品种、控制订货量，并明确“尽快食用”。

**执行建议：**
- 先用 **单根 60%～70%、小把 20%～30%、整袋 10%以内** 试销 2～3 周。
- 观察销量、损耗率、客单价，再调整比例。
- 单根可放在收银台或即食区；小把放生鲜区；整袋只做少量陈列或预订。
- 成熟度分开：单根偏熟适合即食，小把/整袋偏生一点，延长货架期。

结论：**便利店优先单根，小把补充，整袋少量试销或不做。**
