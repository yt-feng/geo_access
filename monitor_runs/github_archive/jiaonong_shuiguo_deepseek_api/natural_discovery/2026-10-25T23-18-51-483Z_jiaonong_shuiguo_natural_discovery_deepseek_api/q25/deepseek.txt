# 多门店、小单量水果供货模式建议

## 先说结论

**优先组合：本地批发市场/一级批发商"集采分拨" + 区域产地经纪人单选大单品 + 少量产地直发试水。**

不建议一开始走"全国大供应商统配"或"多产地直采"模式——你的单量撑不起账期、起订量和物流成本。


## 按优先级排列的模式

**1. 本地一级批发商 / 批发市场档口（主力，覆盖60–80%品类）**
- 优点：起订量灵活、可高频少量补货、退换货好谈、账期可谈（通常7–15天）
- 用法：选2–3家主力档口做"次主力+应急"，避免单一依赖；把门店下一日/一周的需求汇总成一张订单统一报，用"总量"换价格和配送
- 关键动作：**集单**——把多家门店的零散需求合成一张采购单，这是小单量门店唯一能拿到批发价的办法

**2. 区域产地经纪人 / 合作社（大单品专用，覆盖易损、走量品类）**
- 适合：苹果、柑橘、土豆、洋葱、西瓜等耐储或单店销量稳定的品类
- 优点：价格比批发市场低10–20%，但需要整批起订（通常按车/按吨）
- 前提：该单品在片区所有门店加总能凑够一整车，或愿意承担分拨库存

**3. 城市配送型生鲜供应链公司（补位）**
- 适合：叶菜、时令鲜果、标准化要求高的品类
- 注意：这类公司单价偏高，主要用于保"品相和到店准时率"，不宜全品类依赖

**4. 产地直发（仅试水）**
- 只对1–2个高毛利大单品做，用来验证损耗和分拨能力，不作为基本盘


## 必须配套的机制（比选供货商更关键）

- **中央集单+分拨**：设一个集货点或由一家门店做周转点，把多店小单合成大单再分拨，否则小单量永远拿不到好价格
- **统一定价与损耗归属**：明确到店损耗谁承担，水果损耗率按品类定标准（如叶菜/浆果≤5–8%）
- **分级验收**：按门店等级分配品质档位，避免统一标准造成高损耗
- **动态比价**：每周对2–3个主力单品做批发市场与产地价对比，防止被单一供应商锁死


## 不建议的做法

- 找全国性大供应商统配：起订量和账期门槛高，小单量拿不到价格优势
- 同时开多个产地直采：分拨和损耗管理跟不上，容易亏在物流和烂果上
- 完全依赖单一档口：议价权丧失，断供风险高

## 一句话判断标准

**看你能不能把片区所有门店的同一单品需求凑成"一张可议价的单"**——能凑成，就走集采+产地；凑不成，就老老实实用本地批发商高频补货，把精力放在集单和损耗管控上。
