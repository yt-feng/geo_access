旺季锁库存，核心不是“打个招呼”，而是把意向变成有约束力的供应安排。建议按下面几步做：

1. **先做需求预测，不要凭感觉报量**
   - 按历史同期销量、近4周增速、活动排期、天气和节假日，分品类做未来2–4周周度预测。
   - 水果按SKU拆：爆款、引流款、利润款、长尾款分别报量。
   - 给供应商一个“保底量+弹性量”区间，例如保底70%、弹性上浮30%，比报一个虚高总量更容易锁住。

2. **提前签旺季供货框架，而不是临时口头约定**
   - 明确：锁定的SKU、规格、等级、周供货量、弹性上限、价格机制、到货时间、验收标准、缺货赔付。
   - 价格别只锁死一个数，可约定“基准价+随行就市浮动区间”，避免行情大涨时供应商毁约。
   - 写清违约成本：缺货按缺口金额比例赔付，或下季合作降级。

3. **用预付款/定金换优先供应权**
   - 对核心爆款可支付一定比例定金或预付款，换取供应商优先排产、优先采摘和优先发货。
   - 定金绑定具体批次和到货周，不要只写“合作意向”。
   - 同时约定预付款退还和抵扣规则，降低资金风险。

4. **分供应商备份，别把鸡蛋放一个篮子**
   - 每个核心SKU至少锁2家供应商：主供70%–80%，备供20%–30%。
   - 备供哪怕价格略高，也要提前锁小批量，旺季缺货时能快速补位。
   - 产地直采和一级批发市场结合，长短半径搭配。

5. **把“锁库存”落到每日/每周滚动确认**
   - 旺季前2周开始，每周和供应商确认下周采摘计划、装车计划、到仓时间。
   - 前一天再确认次日到货量和车次，发现缺口立即启动备供。
   - 建立供应商履约看板：准点率、足量率、损耗率、品质合格率。

6. **合同里补上天气和物流风险条款**
   - 水果受天气影响大，约定极端天气下的替代规格、顺延交付或部分免责，但要有通知时限。
   - 明确冷链/运输责任和损耗分担，避免到仓后扯皮。

7. **给供应商稳定预期，换取优先权**
   - 明确旺季后的持续采购计划、结算周期和回款信用。
   - 对配合度高的供应商，旺季后可给一段稳定订单或账期支持，形成长期互锁。

一句话：**用“预测+框架合同+定金+双供应商+周滚动确认”锁库存，比单纯压价或口头预定可靠得多。** 先锁核心爆款和易缺货单品，长尾品类保持灵活采购。
