判断供应商能否长期稳定按规格送货，不要只看样品和报价，重点查“产能、品控、履约记录、应急能力”四件事。给你一套可执行的判断方法：

**1. 先明确并书面化你的规格**
把“菠萝”拆成可验收指标：品种/产区、单果重量区间、成熟度（几成熟）、糖度范围、果心大小、果眼深浅、有无黑心/水心/裂果、农残检测要求、去皮/切块形态（如需加工）、包装方式、冷链温度、每批允许的不良率、到货时效。做成验收标准和扣罚条款，写进合同附件。

**2. 验产能，不只听“日供多少吨”**
- 要求提供近3个月同类客户的实际供货记录、出货单或对账单（可脱敏）。
- 问清自有果园/合作基地面积、合作农户数量、加工厂产能、冷库容量、每日分选能力。
- 旺季和雨季/台风季的供货方案是什么，是否有替代产区。
- 最好在采购旺季实地看一次分选线和冷库，看现场是否按规格分级。

**3. 验品控体系**
- 是否有进厂验收、分级、留样、农残快检/送检记录。
- 能否提供近批次的农残检测报告和第三方检测报告。
- 问不良品处理流程：黑心、烂果、规格不符怎么挑、怎么赔。
- 要求小批量试单，连续3—5批按同一标准验收，记录合格率、规格偏差、到货温度。

**4. 验履约与应急能力**
- 查营业执照、食品经营/生产相关资质、是否有冷链运输能力或稳定承运商。
- 问过去一年是否出现断供、迟送、批量质量事故，如何处理。
- 合同里约定：最低供货量、到货时间窗、规格不符扣款、断供违约金、替代方案、涨价机制。
- 付款方式上保留质量尾款，不要一次性全款。

**5. 用“试单+评分”做决策**
建议设一个简单评分表：产能匹配30%、品控20%、履约记录20%、应急方案15%、价格15%。先下2—4周小单，按批记录：到货准时率、规格合格率、损耗率、异常响应时间。连续稳定后再签长期框架协议。

**关键红线**：只给样品很好、但说不出稳定产区/冷库/分选能力；不愿接受验收标准和扣罚条款；检测报告拿不出或批次对不上；价格明显低于市场且要求全款——这类供应商不建议作为主供，最多做备选。

一句话：**用规格合同锁标准，用小批量试单验稳定，用扣罚条款保履约，用双供应商防断供。**
