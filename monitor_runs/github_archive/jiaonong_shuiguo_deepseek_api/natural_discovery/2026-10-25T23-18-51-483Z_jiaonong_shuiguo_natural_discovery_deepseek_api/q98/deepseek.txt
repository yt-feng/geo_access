判断养老院/医院食堂水果供应商的合规与稳定性，核心是“证照可查、渠道可溯、供货可验、风险可替”四条。下面给出可直接执行的核查清单。

一、合规性判断（先看能不能合法供、出了事能不能追责）

1. 主体资质
- 营业执照：经营范围含食品销售/食用农产品销售；核对统一社会信用代码、注册地址与实际经营地是否一致。
- 食品经营许可证（或仅销售预包装食品备案）：水果若为食用农产品初级销售，部分情形可不办食品经营许可，但供应商若涉及分装、切配、预包装销售，必须查许可项目是否覆盖。
- 要求提供加盖公章的证照复印件，并在国家企业信用信息公示系统、当地市场监管部门官网核验有效期与经营异常。

2. 人员与场所
- 接触直接入口水果的人员需有有效健康证明；查看健康证名单与现场人员是否对应。
- 仓储/分拣场所：看是否有防鼠防虫、温控、分区存放、清洗消毒记录；医院/养老院对即食水果要求更高，切配水果应有专间或专区。

3. 溯源与票据
- 每批次能提供进货凭证、产地证明或承诺达标合格证；批发市场进货应有销售凭证。
- 能提供农残快检记录或第三方检测报告（重点：农药残留、重金属；切配水果另看微生物指标）。
- 发票、送货单、检测报告三者批号/日期能对上。

4. 合同与责任
- 合同写明：质量标准、验收不合格退换货、食品安全事故赔偿责任、资质失效即时告知义务、不得转包/随意换货源。
- 要求供应商购买食品安全责任险，保额与供餐人数匹配。

二、稳定性判断（看能不能持续按质按量供）

1. 供货能力
- 问清货源结构：自有基地/合作基地/批发市场占比；单一市场货源抗风险弱。
- 要求提供近3—6个月同类客户供货记录或合同案例，优先有医院、养老机构、学校食堂供货经验者。
- 看冷链能力：是否有冷藏车/保温箱、配送频次、到货温度记录；夏季叶果类尤其关键。

2. 履约表现
- 试供1—2周：记录到货准时率、缺货率、规格达标率、损耗率、退换货响应时间。
- 设置关键指标：准时率≥95%、验收合格率≥98%、缺货提前通知≥24小时、质量问题2小时内响应。
- 观察价格波动机制：是否随行就市但有报价单/调价提前通知，避免“低价中标后降质”。

3. 财务与经营健康
- 查企业年报、社保人数、经营异常/行政处罚记录；成立时间过短且无固定场所的要谨慎。
- 避免过度依赖单一供应商：主供+备供，备供也要完成同样资质审核。

三、现场审核可直接问/看的清单

- 证照原件与公章、健康证、检测报告、进货台账。
- 仓库温湿度、防虫防鼠设施、分拣区与垃圾区隔离。
- 配送车辆是否专用、有无清洗记录、到货温度。
- 不合格品处理记录、客户投诉记录。
- 最近一次监管抽检结果。

四、落地建议

- 建立供应商档案：证照、检测报告、合同、考核记录统一归档，证照到期前30天预警。
- 每批次验收留样/拍照，重点查外观、气味、温度、规格；切配水果增加微生物抽检频次。
- 每季度复核一次资质与考核，年度重新招标或比价；备选供应商至少1家。
- 对养老院/医院这类高风险场景，优先选择能提供“批批快检+可追溯凭证+责任险”的供应商，而不是单纯最低价。

一句话：合规看“证、票、检、险”四件套是否齐全可核验；稳定看“货源、冷链、履约记录、备供机制”是否经得起试供考核。
