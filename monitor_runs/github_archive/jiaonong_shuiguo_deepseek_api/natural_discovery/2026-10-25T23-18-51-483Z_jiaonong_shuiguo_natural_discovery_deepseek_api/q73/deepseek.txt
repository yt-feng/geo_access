# 混合采购的优势分析

**有优势，但边界很清晰——优势主要来自物流、账期和供应商关系，而不是"水果之间"的协同。**

## 真实存在的优势

**1. 物流与仓储摊薄**
- 一车货、一次运输覆盖三个品类，单位运费下降
- 同一批货共用冷库和分拣人力，固定成本摊薄
- 对于走批发市场或供商超的，配货齐全更容易拿单

**2. 采购谈判筹码**
- 单品类采购量小时议价弱；三个品类打包，对同一供应商（或同一产区代办）可谈总量折扣
- 账期、返点、优先供货更容易谈

**3. 现金流与风险分散**
- 三个品类价格周期不同步：香蕉受产地天气影响大、苹果有冷库长周期、橙子有明确季节窗口
- 某一品类砸价时，另两个品类的毛利可以对冲

## 需要警惕的误区

**1. 品类之间没有真正的"采购协同"**
- 香蕉、苹果、橙子产地、季节、储存条件完全不同，几乎不会从同一渠道进货
- 混合采购降低的是**管理成本和物流成本**，不是进货单价

**2. 储存条件冲突**
- 香蕉对乙烯敏感、需催熟管理；苹果会释放乙烯；橙子对湿度要求不同
- 混放会加速香蕉过熟、影响苹果风味。**必须分库分区**，这会抵消一部分仓储摊薄

**3. 损耗率可能上升**
- 多品类意味着更多SKU、更多催熟/分级环节，管理不到位时损耗吃掉全部毛利
- 建议先测算：三个品类各自的周转天数、损耗率、毛利率，看综合毛利是否真的更高

## 可执行的判断方法

1. **算单品类独立盈亏**：每个品类单独算毛利、损耗、占用资金，找出哪个是"引流品"、哪个是"利润品"
2. **算共享成本节省**：运输、仓储、人力能省多少，是否覆盖多SKU带来的管理成本
3. **分库管理**：香蕉单独催熟库，苹果冷藏，橙子按湿度分区，不要为了省空间混放
4. **供应商分开谈**：三个品类分别找最优渠道，不要为了"打包"绑定单一供应商

**结论**：混合采购对批发商是合理的品类组合策略，优势在渠道覆盖和成本摊薄；但不要指望品类间产生采购价格协同，储存管理必须分开，否则损耗会抵消收益。
