第一次合作、小批量试单的核心目标不是“赚钱”，而是**用最低成本验证供应商是否靠谱、果品是否稳定、履约是否省心**。试单设计建议围绕下面几件事来做。

## 一、先明确试单要验证什么

把试单拆成5个验证项，每项都要有判断标准：

1. **品质稳定性**：同一批货不同箱之间大小、成熟度、伤果率差异大不大。
2. **规格真实性**：承诺的果径、单果重、糖度、品种是否对得上。
3. **损耗与保鲜**：到货后2—3天内腐烂、软化、失水情况。
4. **履约能力**：是否按约定时间到货、包装是否规范、单据是否齐全。
5. **沟通与售后**：出问题时响应速度、是否认账、补货或退款是否爽快。

## 二、试单规模怎么定

建议“**小批量、多品类少SKU、短周期**”：

- **总量**：按你正常单次采购量的 **10%—20%**，或够卖 **2—3天** 的量。不要一次压太多，但也不要少到看不出问题。
- **SKU**：选 **1—2个主力单品**，最好是你能快速出手、周转快的品种。
- **批次**：同一供应商至少分 **2次下单**，第一次验基础履约，第二次看稳定性。两次间隔1—2周。
- **包装规格**：尽量按你下游实际销售规格来订，比如整箱、5斤装、礼盒装，验证对方分装能力。

## 三、试单合同/约定要写清

即使小批量，也要用微信或简易采购单确认以下内容：

- 品种、等级、果径/单果重范围、糖度下限、成熟度要求；
- 单价、包装方式、箱规、每箱净重；
- 交货时间、交货地点、运输方式、运费谁承担；
- **验收标准**：伤果率、烂果率、规格不符比例超过多少算不合格；
- **售后条款**：坏果怎么赔、补发还是扣款、响应时限；
- 付款方式：首次合作建议 **少量定金+到货验收合格后付尾款**，不要全款预付。

## 四、验收怎么做

到货当天就验，别拖：

1. **抽检比例**：每批至少抽 **10%—20%的箱数**，大货可随机抽5—10箱。
2. **记录指标**：单果重/果径、色泽、成熟度、伤果率、烂果率、箱内净重。
3. **拍照留证**：开箱、称重、坏果特写、整批货堆头都拍。
4. **做台账**：每个供应商建一张表，记录批次、到货时间、抽检结果、售后处理。

## 五、判断是否继续合作的标准

建议设一个简单门槛：

- **合格**：规格符合率≥95%，烂果率≤2%—3%，到货准时，售后24小时内响应 → 可进入第二次试单或正常小批量合作。
- **观察**：规格偶有偏差但售后配合 → 缩小单量再试一次，重点盯同一问题是否重复。
- **淘汰**：烂果率明显超标、规格严重不符、拖延售后、二次下单仍出同样问题 → 停止合作。

## 六、付款和风险控制

- 首次合作 **不押大额预付款**，宁可单价稍高一点。
- 试单阶段尽量 **一单一结**，不要被“包月/包年优惠”诱导加大单量。
- 保留聊天记录、采购单、验收照片，出问题时有依据。
- 同时接触 **2—3家备选供应商**，试单期不要只绑一家。

## 七、一个可执行的试单节奏

- 第1周：谈2—3家，各下1个小单，选1—2个主力单品；
- 到货当天：按标准验收、拍照、记录；
- 第2周：对合格供应商下第二次小单，重点看稳定性；
- 第3—4周：根据两次结果决定是否转为常规小批量采购，同时保留备选供应商。

一句话：**试单要小到亏得起，但标准要严到能看出问题；第一次合作看履约，第二次合作看稳定。**
