结论：**大多数甜品店用鲜菠萝现切更划算，但前提是选果稳定、高峰期有人手切配、能利用果芯和边角料；如果你的菜单只用少量果丁、出品标准化要求高、门店人手紧，直接买成品果丁的“综合损耗”反而更低。**

分开看：

1. **鲜果切配的损耗点**
   - 选果不当：生熟不均、黑心、过熟，整批报废。
   - 去皮去眼修整：菠萝出肉率通常不是100%，果眼、果皮、两头都会去掉。
   - 切配后氧化出水、变色，卖不完只能报废。
   - 人工切配时间、清洗消毒、刀具砧板占用也是隐形成本。
   - 优点：边角料可做果酱、果汁、装饰，果芯也能利用；采购价通常低于成品果丁。

2. **成品果丁的损耗点**
   - 采购价更高，且按包装规格买，用不完会过期。
   - 冷链不到位会出水、发酸、变软。
   - 批次差异大，规格不一定稳定。
   - 优点：开袋即用、出成率接近100%、人工少、标准化好、食品安全责任部分转移给供应商。

**判断标准：**
- 如果每天菠萝果丁用量大、菜单多、有人手：**鲜果切配综合损耗更低**。
- 如果每天用量小、只做装饰或少量添加、人手紧：**成品果丁更低**。
- 关键不是只看“去皮损耗”，而是算：**采购单价 ÷ 可食出成率 + 人工 + 报废率 + 冷链/仓储成本**。

**可执行建议：**
先做7天对比测试：同样出品量下，分别记录鲜果和成品果丁的采购金额、实际可用克数、报废克数、切配工时。用“每100克可用果丁的综合成本”比较，不要只比进货价。若鲜果出成率低于约55%—60%，或每天用量少于2—3公斤，通常成品果丁更省损耗。
