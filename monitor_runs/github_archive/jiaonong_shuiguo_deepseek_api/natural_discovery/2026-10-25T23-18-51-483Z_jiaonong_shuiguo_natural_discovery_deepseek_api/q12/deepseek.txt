采购时不要追求“到店即熟”，而是按**预计售卖速度分级采购**：大部分进“七八分熟”、少量进“接近全熟”用于当天走量。菠萝没有后熟优势（采后甜度基本不再明显上升，主要是变软、变色、风味变化），所以采购熟度判断很关键。

**可执行的判断方法：**

1. **看外观**
   - 果皮由青转黄、黄色占三分之一到三分之二，适合1—3天内卖完，属于比较稳的采购熟度。
   - 全青果可以放更久，但酸味重、口感差，只适合做特价引流，不建议大量进。
   - 全黄、果眼明显发亮、底部有酒味或软塌的，当天必须处理，损耗风险高。

2. **闻底部**
   - 底部有清甜果香但不过浓：熟度合适。
   - 有明显酒味、发酵味：过熟，别进。
   - 完全没味道：偏生，可少量进但别占大头。

3. **按果眼和果皮**
   - 果眼扁平、果皮紧实：偏生，耐放。
   - 果眼鼓胀、果皮略软但有弹性：熟度较好，及时卖。
   - 轻按就陷下去、流水：过熟。

4. **看叶片和果柄**
   - 冠芽青绿、果柄切口新鲜：新鲜度好。
   - 冠芽枯黄、果柄干黑：存放久，熟度不可靠。

5. **掂重量**
   - 同样大小，偏重的通常水分足、果肉紧实；明显偏轻的可能失水或过熟空心。

**采购比例建议：**
- 按日销量估算：**60%—70%进七八分熟**，**20%—30%进接近全熟**当天/次日卖，**10%以内进偏生**做特价或备用。
- 夏季高温、店内无冷柜时，全熟比例再降低；冬季或周转快可适当提高。
- 到店后按熟度分区摆放，全熟果切开试吃、做果切或促销，别和生果混放。

**简单标准：** 手按微弹、底部清香、黄色占三分之一以上、无酒味——这个熟度适合大多数水果店采购。
