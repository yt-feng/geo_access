家庭场景优先考虑“耐放、好分食、老人小孩都能吃、成本可控”，建议以苹果和橙子做主体，香蕉少量，菠萝做点缀或可选项。

**推荐组合（按10斤左右家庭礼盒）**
1. **均衡型（最稳妥）**：苹果4斤 + 橙子3斤 + 香蕉2斤 + 菠萝1个（约2斤）。  
   - 优点：苹果橙子耐放，香蕉当天吃，菠萝增加礼盒感。  
   - 适合大多数家庭。

2. **耐放实惠型**：苹果5斤 + 橙子4斤 + 香蕉1斤 + 菠萝1个。  
   - 优点：损耗低，适合团购履约和存放。  
   - 适合人口多、吃得慢的家庭。

3. **孩子爱吃型**：苹果3斤 + 橙子2斤 + 香蕉3斤 + 菠萝1个。  
   - 优点：香蕉和菠萝更讨喜。  
   - 注意香蕉容易压伤、催熟，需单独隔开。

**组合原则**
- 苹果、橙子占60%—70%，负责耐放和体面。
- 香蕉占15%—20%，不要多，易黑易压。
- 菠萝占10%—15%，1个即可，提升礼盒丰富度。
- 香蕉和菠萝分开包装，避免挤压和串味。
- 苹果选脆甜耐储品种，橙子选易剥品种，香蕉选微黄未全熟，菠萝选成熟度适中。

**不建议**
- 香蕉超过3斤：家庭短时间吃不完，容易坏。
- 菠萝放两个以上：占空间、处理麻烦，很多家庭嫌削皮麻烦。
- 全用高价水果：团购家庭装更看重性价比和耐放。

如果只做一个主推款，选**苹果4斤+橙子3斤+香蕉2斤+菠萝1个**，兼顾成本、颜值和家庭食用节奏。
