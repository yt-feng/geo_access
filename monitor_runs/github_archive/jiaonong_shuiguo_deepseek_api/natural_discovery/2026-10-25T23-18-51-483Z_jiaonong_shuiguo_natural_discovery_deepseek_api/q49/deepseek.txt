旺季菠萝用量突然变大，和供应商约定临时补货，核心不是“临时打一通电话”，而是提前把**补货触发条件、响应时限、价格上限、品质标准和违约责任**写进补充协议或订单条款。可以按下面做：

**1. 先锁定需求预测和补货窗口**
- 按门店/仓库未来7天、14天滚动预测菠萝用量，区分鲜果和冷冻果浆/果块。
- 明确旺季补货的“触发条件”：例如日库存低于3天用量，或周销量超过基准量20%。
- 约定补货提前期：鲜果建议提前24—48小时下单，加工品按供应商产能提前3—7天。

**2. 签一份“旺季临时补货补充协议”**
重点写清：
- **补货量区间**：每日/每周最小起订量、最大供应量，防止供应商临时说没货。
- **响应时限**：收到补货通知后几小时内确认、几小时内发货、最迟到店时间。
- **价格机制**：约定基准价+浮动上限，例如按当日批发市场均价上浮不超过X%，或旺季固定价锁到某日期，避免坐地起价。
- **品质标准**：品种、规格、成熟度、单果重量、坏果率、农残检测要求；不合格的退换货时限和费用承担。
- **物流与损耗**：谁负责运输、到货温度/时效要求、途中损耗由谁承担。
- **违约责任**：供应商未按时按量供货的赔偿；采购方临时取消订单的补偿比例。
- **替代方案**：鲜果短缺时是否可用冷冻果浆/果块替代，替代品的价格和品质标准。

**3. 用“框架协议+滚动订单”操作**
- 签年度/季度框架协议，锁定供应能力和价格区间。
- 旺季每周发滚动订单，前3天为确认订单，后4天为预测订单，供应商按确认订单备货。
- 每次补货用书面形式（微信/邮件/系统订单）确认，避免口头承诺。

**4. 设置备选供应商和库存缓冲**
- 至少保留1—2家备选供应商，旺季前完成样品和资质审核。
- 安全库存按旺季日均用量的3—5天设置，鲜果不宜过多，可搭配冷冻果浆缓冲。

**5. 谈判话术**
可以这样和供应商谈：“旺季我们用量会明显上升，但愿意提前给滚动预测和确认订单，希望锁定你的产能和价格上限；如果临时补货，我们接受合理加急费，但需要明确响应时限和品质责任。”

**关键判断标准**：如果供应商不愿约定响应时限、价格上限或违约条款，只愿意“到时候再说”，说明旺季断供风险较高，应降低对其依赖并启用备选供应商。
