不重要，但有用。对档口水果生意来说，供应商能否提供促销素材属于“锦上添花”，不是“雪中送炭”。

**为什么不是决定性的**
- 你的客户主要是路过客和周边熟客，成交靠的是水果新鲜、价格清楚、摆放顺眼、老板会招呼，不是海报多漂亮。
- 档口空间小，海报、展架、吊旗能用的位置有限，素材多了反而杂乱。
- 促销素材很容易同质化，隔壁档口也能拿到同样的图，形成不了差异。

**什么时候有用**
- 新品类上市、产地故事、检测报告、礼盒装，这类素材能帮你解释“为什么值这个价”。
- 供应商提供现成的价格牌、爆炸贴、朋友圈九宫格图，能省你制作时间，尤其适合早上忙不过来的时候。
- 做社群或朋友圈预售时，有统一素材比你自己拍得歪歪扭扭强。

**更该看重供应商什么**
1. 货稳不稳定、损耗谁承担、坏果怎么赔。
2. 价格有没有优势、起订量是否适合档口。
3. 能不能按你的销售节奏小批量补货。
4. 促销素材能否按你的店名、价格改，而不是只能原样用。

**可执行建议**
- 选供应商时，促销素材只作为加分项，不作为筛选门槛。
- 如果供应商有素材，只挑两样用：价格牌和朋友圈图，其他不要堆在档口。
- 自己拍实货照片、手写价格牌，往往比供应商的精美海报更接地气、更可信。
- 把“能否提供可修改的素材”写进合作沟通里，但别为这个让掉价格或账期条件。

一句话：供应商给促销素材，能省事就用；不给，也不影响你把水果卖好。核心还是货和价格。
