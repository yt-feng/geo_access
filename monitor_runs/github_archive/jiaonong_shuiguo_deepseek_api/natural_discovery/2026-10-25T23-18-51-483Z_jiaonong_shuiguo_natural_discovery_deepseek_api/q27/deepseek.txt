判断门店销售规格，重点不是“越大越好”，而是看**目标客群、陈列方式、损耗和定价带**。可按下面做可执行判断：

**苹果**
- **单果重/果径**：门店常用参考  
  - 小果：约160–180g/个或70–75mm，适合社区店、散客、低价引流。  
  - 中果：约180–220g/个或75–85mm，最适合日常家庭消费，主推规格。  
  - 大果：220g以上或85mm以上，适合精品陈列、礼盒、高客单客群。  
- **看整齐度**：同一陈列筐内大小差异不要太大，否则顾客挑拣、造成损耗。  
- **看硬度与果面**：硬脆、无磕碰、无明显药斑和裂口，比单纯大果更重要。  
- **看品种适配**：富士、嘎啦等脆果偏中果好卖；礼盒可上大果，但普通散卖大果过多容易剩货。

**橙子**
- **果径**：门店常用  
  - 小果：65–70mm，适合低价散卖、榨汁。  
  - 中果：70–80mm，家庭鲜食主力，最好卖。  
  - 大果：80mm以上，适合礼品、精品陈列，但皮厚汁少风险要试吃判断。  
- **看皮薄、手感重**：同样大小，手感重、皮紧细的通常汁多。  
- **看整齐度和颜色**：颜色均匀、无青斑、无软烂和油胞破损。  
- **看货架期**：橙子较耐放，但门店若走量慢，不要一次上太大规格或太高价带。

**门店采购判断表**
1. **定客群**：社区家庭为主→苹果中果、橙子中果为主；精品/礼品→可配大果礼盒。
2. **定陈列**：散卖筐装选整齐中果；礼盒选大果但需分级。
3. **定价格带**：设“引流小果/主销中果/利润大果”三档，避免只进一个规格。
4. **试销验证**：先小批量各进1–2个规格，观察3–5天动销、挑拣损耗、客诉。
5. **验收标准**：苹果看硬度、果径、伤果率；橙子看手感重、皮紧、软烂率。伤果率建议控制在3%–5%以内，超过则压价或拒收。
6. **损耗预警**：若某规格连续2–3天挑拣多、剩货多，降价清或停采，不要继续补大果。

简单说：**社区日常销售以中果为主，小果做引流，大果做礼盒/精品；苹果重硬度和整齐度，橙子重手感和皮紧度。**
