旺季谈水果供应，核心是把“断货风险”提前拆成可约定的问题。建议按下面几组问，并尽量落到数量、时间、责任上。

**1. 供应能力与优先级**
- 旺季每天/每周能稳定给我多少货？最低保供量是多少？
- 高峰期你有几个客户？我排第几优先级？断货时先保谁？
- 你自有果园/基地还是多级批发？主供品种和替代品种分别是什么？
- 遇天气、节假日、产地减产，提前多久通知我？

**2. 品质与规格**
- 每个品种的等级、果径、成熟度、糖度、允许损耗率怎么定？
- 到货验收标准是什么？坏果、次果、规格不符怎么算？
- 是否支持样品确认、首批小批量试供？
- 包装规格、每箱净重、是否带冰/保鲜措施？

**3. 价格与结算**
- 旺季价格是锁价、随行就市还是保底+浮动？调价提前几天通知？
- 有没有旺季临时加价、运费、装卸费、包装费？
- 账期多久？押金/保证金要不要？断货或质量问题怎么扣款？
- 返利、损耗补贴、滞销处理有没有政策？

**4. 配送与时效**
- 每天几点前下单、几点送达？能否固定时段？
- 临时补货最快多久到？起送量多少？
- 运输温控怎么做？夏季高温/雨季有没有保鲜方案？
- 缺货时是否支持同品替代或跨品种调剂？

**5. 风险与违约**
- 断货超过约定量怎么赔？连续断货能否解除合作？
- 质量问题（农残、腐烂、以次充好）责任和赔付标准？
- 价格暴涨暴跌时，双方有没有调价机制？
- 合作期限、独家/区域保护、旺季保供协议能不能写进合同？

**6. 备选与验证**
- 你目前最大日供量是多少？能否提供近期供货案例或老客户参考？
- 除你之外，我是否需要再备1—2个二级供应商？你能否接受“主供+备供”？
- 首批试供能否按旺季真实节奏跑一周？

谈的时候建议带一张表：品种、日需求量、最低保供量、规格、价格机制、送达时间、违约赔付，逐项让对方确认。口头承诺尽量写成微信确认或合同附件，尤其是“保供量、断货赔付、调价提前期”这三项，是旺季最关键的抓手。
