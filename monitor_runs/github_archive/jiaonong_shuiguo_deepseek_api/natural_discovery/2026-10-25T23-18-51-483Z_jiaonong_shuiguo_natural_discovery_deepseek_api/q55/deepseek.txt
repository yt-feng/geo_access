选规格的核心不是“哪种更便宜”，而是**按出成率和拼盘用途反推采购规格**。下面按三种水果分开说，最后给一个组合采购建议。

**苹果：优先选中小果，按个数算成本**
- 拼盘一般切瓣或切块，苹果单块大小取决于切法，大果不一定省。大果果核占比也大，且切开后氧化面积大、边角料多。
- 更划算的做法：选**70–80mm 的中果**做切瓣拼盘；做雕花或整片摆盘才用大果。按“每个苹果出多少瓣”算单瓣成本，比按斤比价更准。
- 餐厅用量稳定时买**整箱统货**通常比散装便宜，但要抽检大小是否均匀，大小不一会影响切瓣标准化。

**橙子：选皮薄、中等偏大果，按出汁/出瓣率算**
- 拼盘多用橙瓣，要求**瓣形完整、皮薄易剥**。太大的橙子瓣宽，摆盘不精致且单瓣成本高；太小的剥瓣费工。
- 建议选**中等偏大、果形均匀**的规格，重点看皮厚和籽少。脐橙、血橙看用途，普通甜橙做拼盘更稳。
- 按“每箱能剥出多少完整瓣”估算，而不是只看每斤单价。皮厚的规格再便宜也可能不划算。

**菠萝：选中等果，按去皮损耗算**
- 菠萝去皮去眼损耗大，**过大果损耗比例不一定低，过小果出肉少、费工**。做拼盘选**中等规格、成熟度适中**的更稳，太熟切块易烂、摆盘差。
- 如果用量大且后厨人手紧，可比较**整果 vs 已去皮菠萝**：整果单价低但耗人工，去皮品单价高但出成稳定。按你店的人工成本折算，通常小批量用去皮、大批量用整果更划算。
- 优先选果眼浅、芯小的品种，同样重量出肉更多。

**组合采购建议**
1. 先定拼盘标准：每份几块、每块多大、每份成本上限多少。
2. 用“**可售份数 ÷ 采购重量/个数**”算出每种规格的**单份成本**，再比价。
3. 苹果和橙子按个数规格采购更易标准化；菠萝按重量采购但要实测去皮出成率。
4. 少量多规格试采一轮，记录出成率和损耗，再定长期规格，比一次性压价更可靠。

一句话：**苹果选中等果按瓣算，橙子选皮薄均匀果按完整瓣算，菠萝选中等果并实测去皮损耗；最终用“单份拼盘成本”而不是“每斤单价”做决策。**
