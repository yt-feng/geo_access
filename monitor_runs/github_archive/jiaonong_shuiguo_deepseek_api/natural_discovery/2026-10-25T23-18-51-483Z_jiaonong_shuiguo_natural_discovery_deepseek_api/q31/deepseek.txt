连锁商超水果供应商招标，评分标准建议按“**资格门槛+技术/服务能力+商务报价+履约保障**”四段设置，权重可按品类风险调整。下面给一套可直接落地的框架。

## 一、先设资格门槛（不计分，不满足即淘汰）
1. 营业执照、食品经营/生产许可、种植基地或合作社证明。
2. 近2年无重大食品安全处罚、无严重失信记录。
3. 具备冷链运输能力，或固定合作冷链物流。
4. 能提供农残检测报告，承诺批批检测或按批次抽检。
5. 产能/供货能力证明：日均供货量、旺季保供方案。
6. 有商超、生鲜电商或大型餐饮供货案例（可要求至少1—2个）。
7. 接受账期、退换货、质量赔付等合同基本条款。

> 门槛不宜设“注册资金必须多少”这类容易排斥中小优质供应商的条件，除非品类确实需要。

## 二、评分维度与建议权重

| 维度 | 建议权重 | 核心考察点 |
|---|---:|---|
| 产品质量与食品安全 | 25—30分 | 农残检测、产地证明、等级标准、损耗率、追溯体系 |
| 供货能力与稳定性 | 20—25分 | 产能、旺季保供、缺货率承诺、替补货源、冷链覆盖 |
| 价格与成本 | 20—25分 | 报价竞争力、价格调整机制、账期、运费承担 |
| 服务与响应 | 10—15分 | 订单响应、退换货、售后赔付、驻场/对接人员 |
| 履约保障与风险 | 10—15分 | 保证金、保险、违约责任、应急预案 |
| 可持续与合规 | 5—10分 | 绿色种植、包装合规、用工合规、环保 |

总权重可设为100分。若采购的是叶菜、浆果等易损耗品类，可把“质量与供货稳定性”提高到50分以上；若采购的是苹果、柑橘等耐储品类，可适当提高价格权重。

## 三、各维度细化评分建议

### 1. 产品质量与食品安全（25—30分）
- 检测能力：自有检测室或第三方批检报告，5—8分。
- 质量标准：果径、糖度、成熟度、外观、腐烂率等可量化标准，5—8分。
- 追溯体系：批次可追溯、产地可查，5—7分。
- 损耗控制：承诺到店损耗率及赔付方案，5—7分。
- 认证加分：绿色食品、有机认证、GAP等，3—5分，不宜过高。

### 2. 供货能力与稳定性（20—25分）
- 日均/峰值供货能力，5—7分。
- 旺季与节假日保供方案，5—7分。
- 缺货率承诺及替补货源，5—6分。
- 冷链仓储与运输覆盖，5分。

### 3. 价格与成本（20—25分）
- 报价按品类基准价下浮率或市场采价对比评分，10—15分。
- 价格调整机制是否透明，3—5分。
- 运费、包装、损耗承担方式，3—5分。
- 账期接受度，2—3分。

> 价格分不宜简单“最低价得满分”，建议用“基准价下浮率”或“随行就市+封顶价”机制，避免低价中标后质量下滑。

### 4. 服务与响应（10—15分）
- 订单响应时间、紧急补货能力，4—5分。
- 退换货和质量问题赔付承诺，4—5分。
- 对接团队、驻场服务、信息化对接能力，2—5分。

### 5. 履约保障与风险（10—15分）
- 履约保证金或质量保证金，3—5分。
- 食品安全责任险，3—4分。
- 违约责任与退出机制接受度，3—4分。
- 自然灾害、疫情等应急预案，2—3分。

### 6. 可持续与合规（5—10分）
- 包装环保、可回收，2—3分。
- 种植环节绿色防控，2—3分。
- 用工合规、无童工等声明，1—2分。
- 不建议把这类加分设得过高，避免形式化。

## 四、评标操作建议
1. **样品盲评**：让供应商提供同规格样品，编号后由品控、门店、采购共同打分，避免看牌子给分。
2. **现场/视频审核**：对拟中标供应商核查基地、分选线、冷库。
3. **试供期**：中标后设1—3个月试供，试供不合格可顺延下一名。
4. **价格联动**：合同中设市场采价机制，避免固定价导致断供或质量下降。
5. **评分表量化**：每个评分项写清“得几分需要什么证据”，减少评委自由裁量。

## 五、一个简版分值示例
- 质量安全：28分
- 供货稳定：22分
- 价格成本：22分
- 服务响应：12分
- 履约保障：11分
- 可持续合规：5分
- 合计：100分

如果你们是区域连锁、单品类采购量大，可把“供货稳定”提到25分；如果是高端精品超市，可把“质量安全和认证”提到35分，价格降到15—18分。核心原则是：**门槛保底线，评分拉开差距，试供验证真实能力。**
