优先谈**账期**，其次把**售后（坏果/短斤少两的赔付规则）**写清楚，最后用**配送**做运营保障。理由和谈法如下：

1. **账期最优先**
   - 水果损耗高、价格波动大，账期直接决定你的现金流和议价空间。
   - 长期合作可争取：月结30天起步；旺季或大额订单争取45天；新供应商先做“周结/半月结”再过渡到月结。
   - 关键条款：对账日、付款日、逾期是否影响供货价、是否收取资金占用费、节假日顺延规则。

2. **售后第二优先，必须量化**
   - 水果非标，售后规则比口头承诺重要。重点谈：
     - 坏果率容忍线（如到货24小时内按箱抽检，坏果率超3%整箱赔付或补货）；
     - 缺斤少两按实称补差，还是按比例赔付；
     - 补货/退款时效（如48小时内处理）；
     - 责任边界：运输损耗、仓储损耗、自然失水分别谁承担。
   - 不要只谈“包售后”，要落到可执行的赔付标准和时限。

3. **配送最后谈，但要有硬指标**
   - 配送是履约保障，不是核心利益点。重点约定：
     - 固定配送频次和截单时间；
     - 到货时间窗（如每日6:00前到店）；
     - 延迟送达的补偿（如影响营业按单减免运费或扣款）；
     - 临时加单/减单的响应时间。
   - 如果供应商配送能力强，可把配送作为换取账期的筹码；如果配送弱，优先保证账期和售后。

**谈判顺序建议**：先锁账期框架 → 再定售后赔付标准 → 最后确认配送时效和异常处理。三者都写进合同或框架协议，避免长期合作后“先货后款”变成被动。
