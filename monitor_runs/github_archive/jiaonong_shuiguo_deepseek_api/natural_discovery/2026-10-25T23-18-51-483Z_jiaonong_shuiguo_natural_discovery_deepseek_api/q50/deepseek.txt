甜度和出汁率不是二选一，优先级取决于你用它做什么产品。可直接按下面判断：

**结论：多数茶饮店应把“出汁率/可用果肉率”放在第一位，甜度放在第二位，但必须设甜度底线。**

原因：
- **出汁率决定成本和出杯稳定性**：同样进价，出汁率低意味着每杯实际用果更多、损耗更大，毛利波动更明显。
- **甜度可以用糖浆、果酱微调**：茶饮本身有糖度体系，甜度不足相对好补；但出汁率低、纤维粗、酸涩重，很难低成本修正。
- **但甜度不能无底线**：太酸或甜度太低会逼你加更多糖浆，掩盖果味，且不同批次波动大。

**按产品分：**
1. **鲜果茶/菠萝果肉型产品**：优先看**出汁率+果肉率+纤维口感**，甜度设最低标准即可。
2. **菠萝汁/打汁类饮品**：优先看**出汁率**，同时关注酸甜比，甜度低可通过配方调整。
3. **直接吃果肉或做顶料**：优先看**甜度和口感**，出汁率次要。
4. **做菠萝果酱/糖浆基底**：优先看**风味浓度和酸度**，出汁率不是核心。

**采购时可执行的标准：**
- 先定产品类型，再定原料等级。
- 要求供应商提供**可溶性固形物（糖度）范围、出汁率范围、酸度范围**。
- 小批量试做：按固定配方测**每杯原料成本、出杯风味稳定性、氧化变色速度**。
- 甜度设一个可接受区间，低于下限不采购；出汁率低于你测算的成本线不采购。
- 不要只看单次样品，至少对比2—3个批次，避免批次波动。

一句话：**做茶饮原料，出汁率优先，甜度设底线；做果肉顶料，甜度优先。**
