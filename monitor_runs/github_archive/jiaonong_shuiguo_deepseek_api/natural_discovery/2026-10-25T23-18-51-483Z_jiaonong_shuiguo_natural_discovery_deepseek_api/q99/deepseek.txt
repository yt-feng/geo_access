选择适合批量配送的水果供应商，重点看“稳定性、配送能力、验收标准、售后”，而不是只看单价。可按下面几步做。

**1. 先明确采购条件**
下午茶水果通常是批量、定时、多人分食，先定清楚：
- 人数和预算：按每人一份还是公共果盘？预算按人均还是总价？
- 配送频次：每天、每周几次、临时补货？
- 送达时间：必须下午茶前多久到？是否要求固定时段？
- 品类要求：只要苹果香蕉橙子这类耐放水果，还是也要切果/果切？
- 场地条件：有无冷藏、洗切条件、是否要求独立小包装？

**2. 供应商类型怎么选**
- **本地水果批发商/配送商**：适合量大、品类多、价格可控，但要看是否支持小批量分装和准时配送。
- **生鲜平台企业购**：流程规范、发票和售后较好，适合稳定但品类受平台限制。
- **连锁水果店/社区水果店**：响应快、临时补货方便，适合中小批量，但高峰期配送能力有限。
- **专业果切/下午茶供应商**：省去洗切分装，适合直接分发，但要注意冷链、保质期和卫生资质。

**3. 重点核验这6项**
- **批量供应能力**：问清同一品类一次能给多少箱/多少斤，避免临时缺货换品。
- **配送时效**：是否固定车辆、能否承诺送达时间段、迟到怎么处理。
- **验收标准**：明确坏果率、大小规格、成熟度、是否允许混装；最好写进订单或合同。
- **售后规则**：坏果、漏送、迟到如何补发/退款，响应时间多久。
- **资质与卫生**：营业执照、食品经营许可；如果供果切，还要看冷链和操作卫生。
- **开票与结算**：能否开票、账期、是否支持对公转账，避免后续报销麻烦。

**4. 建议的筛选流程**
1. 找3—5家供应商，统一发一份需求表：人数、预算、品类、配送时间、频次、验收要求。
2. 要求报价包含：单价、分装费、配送费、税费、起送量。
3. 先小批量试单1—2次，重点看准时率、坏果率、实际份量。
4. 试单合格后再签月度/季度框架，约定固定品类池和替换规则。
5. 保留2家供应商，主供+备供，防止单一供应商断供。

**5. 下单时写清楚这些条款**
- 送达时间窗口和迟到赔付；
- 坏果率上限，比如超过多少可整批退换；
- 缺货替换需提前确认，不得擅自换品；
- 分装规格、是否清洗、是否独立包装；
- 对账周期和开票要求。

**简单判断标准**：能稳定按时送、坏果少、出问题有人及时处理、价格透明的供应商，就适合长期合作；只报低价但配送和售后说不清的，不建议作为主供。
