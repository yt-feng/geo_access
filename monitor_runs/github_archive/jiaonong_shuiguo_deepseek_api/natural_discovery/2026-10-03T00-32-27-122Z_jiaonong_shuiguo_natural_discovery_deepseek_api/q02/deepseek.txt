对小水果店来说，这四项**不是并列选一个**，而是有优先级，而且会随店铺阶段变化。更实用的排序是：

**坏果率 ＞ 熟度 ＞ 送货速度 ＞ 价格**

但具体要分情况。

**1. 坏果率最重要**
香蕉是后熟型水果，坏果率一高，损耗会直接吃掉利润。  
小水果店本来周转量不大，一箱里烂几根、黑几根，可能当天毛利就没了。  
所以进货时最该看的是：到货后能卖的比例有多少。

**2. 熟度决定你能不能卖**
香蕉太生，顾客当天不买；太熟，当天卖不掉就砸手里。  
小水果店最好进**微黄、带一点青**的蕉，回店后还能放 1～3 天。  
如果当天客流快，可以适当进熟一点的；如果客流慢，宁可进生一点的。

**3. 送货速度影响损耗和补货**
香蕉怕压、怕闷、怕反复搬运。送货慢、装卸粗，坏果率会上升。  
但送货速度不是越快越好，而是**稳定、准时、少折腾**更重要。  
今天早明天晚，你没法安排陈列和促销。

**4. 价格不能排第一**
价格便宜但坏果多、熟度差，最后往往更贵。  
小水果店要算的是**到手可卖成本**，不是进货单价。  
比如：  
A 家 3 元/斤，坏果 20%，实际可卖成本约 3.75 元/斤；  
B 家 3.3 元/斤，坏果 5%，实际可卖成本约 3.47 元/斤。  
B 家反而更划算。

**建议你这样选供应商：**

- **首选坏果率低、熟度稳定的**
- **其次看能不能按时送、搬运是否规范**
- **最后再谈价格**
- 如果刚开始做，优先找**能少量多次补货**的供应商，别一次压太多货
- 每次进货记录：到货熟度、坏果数、卖出速度、实际损耗  
  连续记 2～3 周，你就知道该选谁了

一句话：  
**小水果店进香蕉，先保“能卖、少烂”，再保“好卖、不断货”，最后才压进价。**  
价格是谈判项，坏果率和熟度是生存项。
