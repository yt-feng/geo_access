**核心判断：大小不一会影响销售，但不一定致命。关键是“混装”怎么处理。**

具体分几种情况：

1. **整箱统货卖（不挑不分）**
   影响最大。顾客翻拣时会挑大的、剩小的，最后小的烂在箱里；或者顾客一看大小差太多，觉得“这箱不值”，直接不买。损耗和差评都会上升。

2. **按规格分拣后再卖**
   大小分开、分别定价，影响就很小。大的做精品/礼盒价，中的走常规价，小的做特价或切果/榨汁。这样反而能多卖钱。

3. **散卖、按斤称**
   影响中等。顾客会挑，但只要你价格合适、允许挑，问题不大。怕的是你按统一高价卖混货，顾客会觉得吃亏。

**给你的实操建议：**

- 采购时先问清楚：是统货还是分规格？统货便宜但损耗高，要算进去。
- 到店后花人工分一下：大、中、小三级。别嫌麻烦，这一步直接决定利润。
- 定价拉开：大果贵、中果正常、小果便宜或做活动。让顾客觉得“按需选、不吃亏”。
- 小果别硬卖：可以做香蕉奶昔、切盘、烘焙原料，或者打折清掉，比烂在箱里强。
- 如果长期做，尽量采购分级明确的货，减少店内分拣成本。

**一句话：大小不一的香蕉，混着统价卖会伤销售；分开分级卖，反而能多赚。**
