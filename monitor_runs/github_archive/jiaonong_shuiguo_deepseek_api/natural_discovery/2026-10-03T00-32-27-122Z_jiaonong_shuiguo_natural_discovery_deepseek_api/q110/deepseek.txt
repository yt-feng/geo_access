不一定更便宜，关键要看“直采”替代的是哪一层、以及你的采购规模和履约条件。

**通常会便宜的情况：**
- 你替代的是多级批发/中间商，且采购量足够大，能凑整车、整柜或稳定走量。
- 产地集中上市、供大于求时，产地端有出货压力，价格弹性大。
- 你能接受产地标准：规格不统一、包装简单、账期短甚至现款，损耗和售后自己承担一部分。
- 物流由你或供应商高效组织，空返少、冷链匹配，运输成本没有反噬。

**不一定便宜、甚至更贵的情况：**
- 你的单次采购量小、频次低，产地直采拿不到好价，还要承担小批量物流费。
- 产地直采只替代了最上游，但供应商仍要加代收、分选、包装、冷链、垫资、售后等成本。
- 水果是非标品，直采常伴随等级混杂、成熟度不一致、损耗高，综合到货成本可能更高。
- 你要求账期、退换货、稳定日配，这些服务本身有成本，产地供应商未必比批发商便宜。
- 产地信息不透明时，你以为的“产地价”可能只是产地经纪人报价，未必低于批发市场。

**判断方法：**
不要只比“单价”，要比 **综合到货成本**：
> 采购价 + 包装 + 分选 + 冷链 + 运输 + 损耗 + 资金占用 + 售后风险

可以拿同一个品种、同一规格、同一到货时间，让产地直采和现有渠道各报一次“到仓价”，连续比 2–3 个批次。如果直采综合成本低 5%–10% 以上，且质量稳定，才值得切换。

**实操建议：**
- 小批量、多品种、要求高服务：优先本地批发或专业供应链，不必迷信直采。
- 大批量、少品种、能自己消化损耗：产地直采更容易便宜。
- 先小批量试单，重点看到货合格率、损耗率和实际结算价，再决定是否长期合作。
- 合同里明确规格、糖度/成熟度、损耗承担、到货时限和异常处理，否则“便宜”很容易被损耗吃掉。
