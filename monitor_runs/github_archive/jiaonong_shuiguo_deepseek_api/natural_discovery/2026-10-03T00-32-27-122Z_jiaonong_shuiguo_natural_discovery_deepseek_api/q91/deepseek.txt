要看你们店的客群和损耗管理能力，通常建议 **主推小把（3～5根），搭配少量单根，整袋只做补充**。理由如下：

1. **小把最稳**
   - 客单价适中，顾客拿起来没压力。
   - 比单根好称重、好陈列、少挑拣。
   - 比整袋更容易控制熟度，减少“一袋全熟”的损耗。

2. **单根适合补场景**
   - 适合上班族、学生、单人租房客。
   - 但单根容易被翻挑，品相掉得快，损耗和人工都会上升。
   - 建议只放少量，作为“随手买”补充，不要作为主力。

3. **整袋适合特定客群**
   - 适合家庭客、办公室拼单、健身人群。
   - 但香蕉后熟快，整袋一旦熟透，门店很难快速消化。
   - 如果做整袋，最好选略生一点的货，并配合折扣清货。

**实操建议：**
- 主力：**小把 3～5 根**，按根重或按把定价。
- 辅助：**单根**，放在收银台或入口冲动消费位。
- 补充：**整袋**，只针对家庭/办公区门店，且控制库存。
- 陈列：按熟度分区，黄熟即食、青黄可放、过熟打折。
- 订货：香蕉别一次上太多，少量高频补货，比一次性堆满更控损。

如果你们店在社区、家庭客多，可以适当增加小把和整袋；如果在写字楼、单人客多，就单根和小把为主。
