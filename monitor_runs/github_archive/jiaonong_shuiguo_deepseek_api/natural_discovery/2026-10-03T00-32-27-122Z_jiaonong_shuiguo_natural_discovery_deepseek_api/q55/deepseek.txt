选水果拼盘用的苹果、橙子、菠萝，核心不是买最便宜的，而是按“出成率、切后卖相、损耗、单份成本”来选规格。给你一套直接可执行的判断方法：

**1. 苹果：选中大果，别选太小或太大的**
- 推荐规格：单果 **180–250g** 左右，果径 **75–85mm** 比较合适。
- 太小的苹果：削皮去核后剩得少，切出来片小，拼盘显得不饱满。
- 太大的苹果：单价高，而且一个果切太多，切开后氧化、剩料损耗更大。
- 品种上优先选：脆度高、切开不易发绵的，比如红富士、嘎啦、阿克苏等。餐厅拼盘更看重切后挺括、颜色好看。
- 划算逻辑：按“可切净果肉成本”算，不是按斤价算。比如同样10元，出肉多的更划算。

**2. 橙子：选中等偏大、皮薄、汁多但不过软**
- 推荐规格：单果 **200–300g**，果径 **70–80mm** 左右。
- 太小的橙子：剥皮/切瓣费工，摆盘量不够，单份要用更多个。
- 太大的橙子：皮可能厚，单价也高，切瓣后容易散。
- 优先选：脐橙、伦晚、赣南脐橙这类皮薄、瓣整齐、颜色好的。
- 如果做橙片装饰，选果形圆、横切面好看的；如果做橙瓣，选易剥皮、少籽的。
- 划算逻辑：橙子要看“可剥净瓣率”。皮厚、籽多、白瓤厚的，再便宜也不划算。

**3. 菠萝：选中等个头、成熟度适中，优先考虑去皮菠萝**
- 推荐规格：带皮菠萝单果 **1.2–1.8kg** 比较合适。
- 太小的菠萝：出肉少，削皮去眼后剩得更少。
- 太大的菠萝：一次用不完，切开后保存差，容易发酵、出水。
- 如果餐厅销量稳定，直接买**去皮菠萝/菠萝块**往往更划算，因为省人工、损耗低、规格稳定。
- 如果自己削：选果眼浅、成熟度刚好的，太生酸、太熟软，都不适合拼盘。
- 划算逻辑：菠萝要算“去皮去眼后的净肉率”。带皮菠萝净肉率通常不高，人工也是成本。

**4. 最划算的通用选法**
- **按净料成本算**：  
  净料成本 = 采购价 ÷ 出成率  
  比如苹果出成率70%，橙子55%，菠萝50%，都要换算后再比。
- **按单份拼盘反推**：  
  先确定一份拼盘需要多少克苹果、多少克橙子、多少克菠萝，再倒推每个水果能出几份。
- **优先选规格统一**：  
  大小一致的水果，切出来整齐，摆盘好看，损耗也稳定。
- **销量小就别囤大果**：  
  大果单价高、切开用不完，反而浪费。
- **销量大就选稳定中号果**：  
  中号果通常出成率和价格最平衡，适合长期采购。

**5. 直接建议**
- 苹果：**180–250g/个，果径75–85mm，脆甜型**。
- 橙子：**200–300g/个，果径70–80mm，皮薄少籽**。
- 菠萝：**1.2–1.8kg/个**；若销量稳定，直接买**去皮菠萝块**更省事划算。
