直接建议：**优先买冷冻/冷藏的菠萝果丁或果泥，不建议用鲜果现切做主力原料。**

分情况说：

**1. 鲜果**
- 优点：新鲜感强、可做装饰、卖点好。
- 缺点：菠萝去皮去眼费人工、出杯慢、批次酸甜不稳定、损耗高、旺季价格波动大。
- 适合：高端现制店、主打“手捣鲜果”概念，且客流不大、有专门备料人力。
- 不建议：出杯量大的店拿它当主力，效率和稳定性都吃亏。

**2. 果丁（冷冻/糖渍/罐头）**
- 优点：开袋即用、颗粒感强、适合做“果肉感”果茶，标准化好，损耗低。
- 缺点：口感不如鲜切，糖渍款要算进配方糖度。
- 适合：**大多数茶饮店做菠萝果茶的首选**，尤其是需要果肉咀嚼感的产品。
- 注意：选冷冻果丁要看解冻后是否出水、是否发软；选糖渍/罐头要减糖。

**3. 果泥（冷冻果泥/浓缩果泥）**
- 优点：风味稳定、出杯快、易调甜酸、适合做基底，损耗最低。
- 缺点：没有果肉感，部分产品香精感重，需选纯果泥。
- 适合：**走量款、外卖款、需要稳定出品的连锁店**，或和果丁搭配使用。
- 注意：看配料表，优先“菠萝+糖/水”或纯菠萝，少选香精色素重的。

**最实用的采购组合：**
- 主力：冷冻菠萝果丁 + 冷冻菠萝果泥
- 果丁负责口感，果泥负责风味和稳定
- 少量鲜果只做点缀或季节限定款

**判断标准：**
- 日出杯 50 杯以上、外卖多、人手紧 → 果断选果丁/果泥
- 主打鲜果概念、客单价高、有备料人力 → 鲜果 + 果泥搭配
- 想兼顾成本和口感 → 果丁为主，果泥调底

一句话：**做常规菠萝果茶，买冷冻果丁和果泥最稳；鲜果是加分项，不是效率项。**
