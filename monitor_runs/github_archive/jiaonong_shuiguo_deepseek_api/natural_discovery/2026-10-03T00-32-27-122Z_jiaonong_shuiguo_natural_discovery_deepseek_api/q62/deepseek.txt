判断一批香蕉，核心是 **“看颜色、摸硬度、查棱角、翻箱底、闻气味”**。香蕉是呼吸跃变型水果，一旦开始转黄后熟，快慢和坏果风险会迅速放大。

**一、先定用途，再定该拿什么熟度**

- **要马上卖/当天用**：拿黄熟蕉，果皮黄、果肉软甜。
- **要放 3–7 天卖**：拿微黄转色蕉，青黄相间、棱角开始变圆。
- **要囤几天再催熟**：拿青硬蕉，全青、硬、棱角明显。
- **做烘焙/奶昔**：可以拿熟度高的，但必须当天处理坏果。

**二、现场判断熟度**

1. **看颜色**
   - 全青：未熟，耐放，但后续要催熟。
   - 青中带黄、黄中带青：转色期，适合批发周转。
   - 通体黄：已熟，货架期短。
   - 出现黑斑但果肉未烂：熟度高，适合即食，不适合远运。
   - 大面积发黑、发褐：高风险。

2. **摸硬度**
   - 硬如石头：生，耐放。
   - 稍软但有弹性：转熟中，较理想。
   - 一按一个坑、回弹慢：过熟，坏果风险高。
   - 局部特别软：很可能内部已烂。

3. **看棱角**
   - 棱角分明、截面近似多角形：生。
   - 棱角变圆、果身饱满：熟度上来。
   - 果身鼓胀、棱角几乎消失：过熟或存放过久。

4. **看果柄和果轴**
   - 果柄青绿、切口新鲜：采后时间短。
   - 果柄发黑、干缩、发霉：存放久或冷链有问题。
   - 果轴发黑、渗液：整箱风险高。

5. **闻气味**
   - 青味重：生。
   - 有正常香蕉甜香：熟度合适。
   - 有酒味、酸味、发酵味：内部已开始变质。

**三、判断坏果风险，重点翻箱底**

不要只看上面一层，必须：

- **翻到底层和中间层**：压伤、闷伤、水烂通常从底层开始。
- **看箱内有无汁液、黑水、霉斑**：有则整批风险高。
- **查有没有“水烂头”**：果柄处发黑、发软、渗水，通常会快速传染。
- **查炭疽病斑**：小黑点迅速扩大、凹陷，运输中会蔓延。
- **查冷害**：皮色发暗、发灰、出现水渍状斑，摸起来软烂，后面很难正常后熟。
- **查压伤**：局部凹陷、发暗、变软，放一两天就烂。
- **随机抽检**：至少抽 3–5 箱，每箱看上下层，不能只验样品箱。

**四、快速决策标准**

- **可拿**：颜色均匀、硬度一致、果柄新鲜、箱内干燥、无酒味、坏果率低于 2%–3%。
- **谨慎拿**：已有少量黑斑、底层个别软果、熟度不均。适合压价、快进快出。
- **不要拿**：有酒味/酸味、箱底渗液、大面积水烂、冷害斑、果柄发霉、坏果率明显超过 5%。

**五、拿货后的处理建议**

- 青蕉：放在 13–15℃ 左右通风处，避免低于 12℃ 冷害。
- 已转黄：尽快销售，减少堆压，保持通风。
- 不要和苹果、乙烯利等催熟源混放，除非你就是要催熟。
- 当天挑出坏果，尤其是水烂、发霉、渗液的，避免传染。
