判断菠萝哪个规格更容易出货，核心看**你的下游客户是谁、怎么卖、什么季节**。批发场景下，通常不是“越小越好”或“越大越好”，而是**规格与渠道匹配**。

下面给你一套可直接用的判断方法。

## 1. 先按渠道分，不同渠道主流规格不同

| 渠道 | 常见走量规格 | 原因 |
|---|---|---|
| 水果店/社区店 | 中果为主 | 单颗价格适中，顾客好拿，损耗低 |
| 商超 | 中大果、外观整齐 | 陈列好看，按个卖有卖相 |
| 路边摊/三轮车 | 小果、中果 | 单价低，走量快 |
| 餐饮/果汁店 | 大果、次果 | 按斤要果肉，对卖相要求低 |
| 电商/社区团购 | 中果、小果 | 控制单件重量和物流成本 |
| 礼盒/精品店 | 大果、均匀果 | 卖相和规格一致性最重要 |

所以你先别问“哪个规格好卖”，先问：**我现在主要供哪类客户？**

## 2. 看三个硬指标：斤价、颗数、损耗

批发出货快不快，往往由这三个决定：

### ① 单颗斤价
- 小果：单价低，但人工、包装、运费摊下来不一定划算
- 中果：通常最好走，价格和分量平衡
- 大果：单价高，遇到对价格敏感的客户就压货

### ② 每箱颗数
同样重量下：
- 颗数多 → 客户觉得“数量多”，适合零售
- 颗数少 → 单颗大，适合按个卖或送礼

比如 20 斤箱：
- 8-10 颗：偏大果，商超、精品店喜欢
- 10-12 颗：中果，最通用
- 12-14 颗以上：偏小果，走低价渠道快

### ③ 损耗率
菠萝容易坏、怕压、怕熟过头。
- 大果如果熟度高，批发风险大
- 小果如果皮厚肉少，客户复购差
- 中果通常最稳，因为容错率高

**结论：多数批发市场里，中果通常是出货最稳的规格；但如果你做餐饮或果汁渠道，大果可能更快。**

## 3. 用“试销法”判断，不靠感觉

你可以拿 3 个规格各放一批，比如：
- A：小果
- B：中果
- C：大果

记录 3 天数据：

| 规格 | 到货量 | 3天出货量 | 剩货 | 询价次数 | 退货/损耗 |
|---|---:|---:|---:|---:|---:|
| 小果 | 100箱 | 60箱 | 40箱 | 20 | 5箱 |
| 中果 | 100箱 | 85箱 | 15箱 | 35 | 3箱 |
| 大果 | 100箱 | 45箱 | 55箱 | 18 | 8箱 |

判断标准：
- **出货率高**：3天出货 > 70%
- **询价多**：说明有需求
- **损耗低**：说明规格适配
- **剩货少**：说明不是价格问题，而是规格问题

最容易出货的规格，通常是：**出货率高 + 损耗低 + 询价多**的那个。

## 4. 看季节和产地

- **旺季集中上市**：中果、小果走量快，因为价格敏感
- **反季或精品期**：大果、均匀果更好卖
- **天气热**：小果、中果周转快，大果容易熟过头
- **天气冷**：大果耐放一点，礼盒需求可能上来

## 5. 最实用的判断顺序

你可以按这个顺序判断：

1. **先定客户**：水果店、商超、餐饮、电商，还是路边摊？
2. **再看客户怎么卖**：按个、按斤、按箱、做果汁？
3. **再看价格带**：客户能接受单颗多少钱？
4. **再看损耗**：哪个规格剩货少、坏得少？
5. **最后试销 3 天**：用数据决定主推规格。

## 6. 直接给你的经验结论

如果没有特殊渠道，一般规律是：

- **最好出货：中果**
- **次之：小果**（低价渠道、电商、路边摊）
- **再次：大果**（商超、礼盒、餐饮）
- **最难出货：规格不齐、大小混杂的统货**

所以，批发菠萝想稳出货，优先做**中果、规格均匀、成熟度适中**的货。  
如果你主要供果汁店或餐饮，就主推**大果**；如果供社区团购或路边摊，就主推**小果和中果**。

一句话：**不是哪个规格绝对好卖，而是哪个规格最匹配你当前客户的卖法。先用 3 天试销数据验证，再决定主推。**
