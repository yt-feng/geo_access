建议按“经营目标”排序，而不是只看单一指标：

1. **切果损耗优先**
   - 超市卖菠萝，很多利润不是被售价决定，而是被损耗吃掉。
   - 重点看：去皮去眼后的出肉率、坏心/黑心比例、熟度不均导致的报废。
   - 如果做果切，损耗高1个百分点，可能比甜度高1度更影响毛利。

2. **甜度第二**
   - 甜度直接影响复购和差评，尤其是即食果切。
   - 但甜度不能只看进货时测糖，还要看批次稳定性：同一批有的很甜、有的很酸，客诉反而更高。
   - 可要求供应商按成熟度分级，避免“看着黄、吃着酸”。

3. **外观第三**
   - 外观决定陈列吸引力和是否容易被挑走。
   - 但超市场景下，外观主要用于分级：整果卖要外观好，果切可把外观略差但内质好的做成切果，减少报废。
   - 不要为了外观牺牲太多出肉率。

4. **大小最后，但要分渠道**
   - 整果零售：大小均匀、适合家庭一次消费更重要。
   - 果切/餐饮供应：大小不是核心，出肉率和切配效率更关键。
   - 太大可能单价高、动销慢；太小可能出肉少、顾客觉得不划算。

**实操判断顺序：**
- 做果切：切果损耗 > 甜度 > 外观 > 大小
- 做整果：甜度 ≈ 外观 > 大小 > 切果损耗
- 做促销引流：外观和大小影响第一眼，但必须用损耗和甜度兜底，否则越卖越亏

**简单结论：**
如果只能选一个，超市卖菠萝应优先关注**切果损耗**；如果整果为主、果切为辅，则优先关注**甜度稳定性和外观分级能力**，再用大小做陈列和定价。
