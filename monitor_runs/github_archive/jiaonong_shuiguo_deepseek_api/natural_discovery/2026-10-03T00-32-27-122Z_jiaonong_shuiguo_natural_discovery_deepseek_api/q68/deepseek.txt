判断供应商能不能按时到车，核心不是听他“保证”，而是看**有没有可验证的排车依据 + 历史履约记录 + 违约成本**。可以按下面几步做：

1. **先问清楚“车从哪来、谁的车、现在什么状态”**
   - 是自有车、长期合作车队，还是临时找车？
   - 车牌号、司机电话、当前所在位置、预计装货时间。
   - 如果对方只说“明天能到”，但给不出车牌和司机，基本不可靠。

2. **要求提供装车节点，而不是只问到货时间**
   - 比如：今天几点到产地、几点开始装、几点装完、几点发车、走哪条路线、预计几点到市场。
   - 关键看“发车时间”能不能卡住。发车都不确定，到车更不确定。

3. **查历史履约**
   - 之前合作过几次，迟到率多少，迟到后怎么处理。
   - 问同行、市场其他档口，这个供应商是不是经常“放空车”或临时换车。
   - 新供应商第一次合作，不要给大单，先小批量试。

4. **看有没有替代方案和违约约束**
   - 合同或微信里写清：到车时间、迟到几小时扣多少钱、超过多久可拒收或降价。
   - 定金不要全款，最好车到市场验货后再结大部分。
   - 问一句：“如果这车来不了，你多久能补一车？”能马上给出补车方案的，通常更稳。

5. **临到车前做二次确认**
   - 发车前确认一次：车牌、司机电话、装货照片或视频。
   - 途中确认一次：司机位置、是否堵车、预计到达时间。
   - 到市场前 2—3 小时再确认一次。如果这时候司机电话打不通、位置对不上，就要警惕。

6. **几个危险信号**
   - 价格明显低于市场，还承诺准时到车。
   - 不肯给车牌、司机电话、装车视频。
   - 总说“在路上”，但说不清从哪出发、走了多久。
   - 要求全款或大额定金才发车。
   - 同一车货同时报给多个买家。

简单判断标准：  
**能给车牌 + 能给司机电话 + 能说清装车发车时间 + 有历史履约 + 有违约扣款 + 有补车方案 = 相对可靠。**  
缺得越多，按时到车的风险越大。第一次合作，最好把“到车时间”和“验货后付款”绑在一起。
