水果生意想长期稳定，选供应商时最容易忽视的不是价格、产地这些明面条件，而是一些**平时不出问题、一出问题就断货或砸口碑**的细节。按重要性给你排一下：

**1. 只谈价格，不谈“稳定供货能力”**
- 很多供应商报价低，但旺季自己都拿不到货，或优先供大客户。
- 要问清楚：你订的货是自有货源、产地直采，还是市场倒手？倒手商在缺货时最先牺牲小客户。
- 可执行判断：让他说出固定合作基地/果园数量、日均可稳定供应量。

**2. 忽视“分级标准”是否统一**
- 同一供应商今天发的果和下周发的果，大小、熟度、糖度可能完全不同。
- 长期店最怕顾客这次买好吃、下次买难吃。
- 要约定明确标准：单果重区间、成熟度、糖度下限、外观瑕疵容忍度，并写进合作条件。

**3. 不考察“损耗率”而不是只看进价**
- 进价低 10%，但损耗高 20%，实际成本反而更高。
- 要问清：运输损耗、到货后 3 天损耗、坏果是否包赔、怎么赔。
- 可执行判断：先小批量试 2–3 次，自己算“到货可售率”和“3 天损耗率”。

**4. 忽视“结算方式和账期”背后的风险**
- 只谈供货，不谈押金、账期、退换货，出问题时很被动。
- 要明确：现结还是账期、坏果怎么扣款、临时取消订单怎么处理。
- 对长期稳定生意，账期清晰比单纯低价更重要。

**5. 不看“冷链和运输责任”**
- 水果断链一次，整批货可能全废。
- 要问：谁负责冷链、温度记录有没有、到货温度超标谁承担。
- 尤其是叶菜、浆果、荔枝、樱桃这类，冷链比价格关键得多。

**6. 忽视“替补供应商”**
- 只靠一家供应商，一旦对方涨价、断货、换老板，你立刻被动。
- 长期稳定做法：主供应商 + 1–2 家备用供应商，平时小量维护关系。
- 不要等断货才去找第二家。

**7. 不记录“供应商履约数据”**
- 靠感觉合作，最后说不清谁好谁坏。
- 建议简单记：到货准时率、坏果率、规格达标率、缺货次数、售后响应速度。
- 连续记 1–2 个月，比任何口头承诺都准。

**8. 忽视“季节切换能力”**
- 夏天卖得好，冬天可能完全供不上或品质差。
- 要问：淡季替代品类是什么、能否提前锁量、价格怎么变。
- 长期生意不能只靠一个季节的爆品。

**9. 不签简易书面约定**
- 不用复杂合同，但至少要有：品名、规格、等级、数量、价格、交货时间、验收标准、坏果赔付、账期。
- 微信聊天记录也可作为辅助，但关键条款最好单独确认。

**10. 忽视“供应商的下游客户结构”**
- 如果他的大客户和你的定位冲突，比如他主要供低价批发，你的精品店可能拿到混级货。
- 要了解他主要服务谁，是否愿意为你单独分拣或定制包装。

**最实用的筛选动作：**
先别谈长期，先做 **3 次小批量试单**，每次记录：
- 到货可售率
- 3 天损耗率
- 规格是否一致
- 缺货/迟到次数
- 售后是否痛快

三次数据稳定，再谈长期账期和锁量。  
长期稳定的核心不是找“最便宜”，而是找 **品质波动小、缺货少、赔付清楚、你能随时替换** 的供应商。
