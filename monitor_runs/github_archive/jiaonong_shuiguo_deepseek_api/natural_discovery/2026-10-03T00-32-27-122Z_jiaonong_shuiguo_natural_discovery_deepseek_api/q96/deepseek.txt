三者不是“选一个”，而是有优先级顺序的：

**食品安全是底线，配送准时是保障，价格是优化项。**

更具体点：

1. **食品安全最优先**
   - 企业食堂是集中供餐，一旦水果农残超标、霉变、腐烂污染，影响的是几十到几百人，属于群体性风险。
   - 所以采购时先看：供应商资质、检测报告/承诺达标合格证、进货查验、储存条件、运输温控、有无腐烂霉变。
   - 这一项不合格，价格再低、送得再准都不能要。

2. **配送准时第二重要**
   - 水果是生鲜，食堂按餐次使用，送晚了会影响当天供应，送早了又可能积压变质。
   - 尤其夏季、切果/果盘场景，对到货时间和冷链要求更高。
   - 所以要看：固定配送时段、临时加单响应、缺货补送、异常处理能力。

3. **价格第三，但不能不看**
   - 企业采购通常有成本考核，价格当然要控制。
   - 但正确做法不是“谁便宜选谁”，而是在**食品安全达标、配送稳定**的供应商里比价。
   - 同时算综合成本：损耗率、退换货、账期、结算便利、售后扯皮成本，往往比单价差几分钱更重要。

**实际决策建议：**
- 先设食品安全准入线：资质、检测、验收标准、退换货规则。
- 再设配送硬指标：到货时间、频次、迟到/缺货处理。
- 最后在合格供应商中比价，按季度或月度评估“质量+准时+价格”。
- 如果非要排序：**食品安全 > 配送准时 > 价格**。

一句话：**食品安全决定能不能合作，配送准时决定能不能稳定合作，价格决定长期合不合作。**
