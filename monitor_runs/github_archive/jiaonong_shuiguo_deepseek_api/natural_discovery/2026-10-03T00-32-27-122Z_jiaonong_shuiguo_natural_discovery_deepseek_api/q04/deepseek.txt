为了减少香蕉在店里放坏，采购时要重点控制两点：**到货熟度**和**从砍蕉到到货的时间**。建议按下面标准去要求供应商：

1. **到货熟度**
   - 要求到货时以 **青蕉、硬身、无明显黄斑** 为主，适合门店再自然催熟或短期销售。
   - 一般可要求：
     - 表皮绿色或微转黄；
     - 果指硬，轻按不软；
     - 无黑斑、无裂口、无发软；
     - 蕉柄完整、颜色青绿。
   - 如果门店客流快、只想卖 1～3 天，可以接受 **微黄、刚转色**；如果预计 3～5 天卖完，最好选 **青硬蕉**。
   - 不要一次性全进同一种熟度，最好 **青蕉为主，少量微黄蕉搭配**，分批卖。

2. **到货时间**
   - 要求供应商明确：**砍蕉后尽快冷链/通风运输，到店时间越短越好**。
   - 建议要求：
     - 砍蕉到到货 **不超过 2～3 天**，夏季最好 **1～2 天内到店**；
     - 运输过程避免高温、暴晒、闷箱；
     - 到店时蕉身不烫手、不滴水、不闷热。
   - 如果是长途运输，要求使用 **13～15℃左右** 的适温运输，不要低于 10℃ 太久，否则容易冻伤变黑。

3. **采购时可以直接提的要求**
   - “到货要青硬，只带少量微黄，熟度统一，不要过熟。”
   - “砍蕉后 2 天内到店，夏天尽量 1 天内到。”
   - “运输要通风或冷链，不能暴晒、闷热。”
   - “有黑斑、软身、裂口、冻伤的不要装车。”
   - “每次到货帮我分 2～3 个熟度等级，方便我分批上架。”

4. **到店后配合做法**
   - 先开箱散热，别马上堆在闷热角落。
   - 青蕉放阴凉通风处，微黄蕉优先上架。
   - 香蕉不要和苹果、梨、西红柿等释放乙烯多的水果混放，否则会熟得更快。
   - 夏季少量多次采购，别一次压太多货。

简单记：**采购要“青硬到货、快运到店、分批熟度、夏季少量多次”**。这样最能减少香蕉放坏。
