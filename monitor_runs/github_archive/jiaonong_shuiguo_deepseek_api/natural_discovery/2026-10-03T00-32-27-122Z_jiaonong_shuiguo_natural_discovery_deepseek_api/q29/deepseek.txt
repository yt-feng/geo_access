超市和水果供应商的账期没有统一标准，主要取决于**品类特性、超市规模、供应商实力、合作阶段**。给你一个可参考的范围：

**常见账期区间**

- **7～15天**：多见于叶菜、浆果、荔枝、杨梅等保质期极短、损耗高的品类，或者供应商比较强势、超市急需货源时。
- **15～30天**：生鲜水果行业较常见的区间，尤其是本地供应商、季节性单品、中小超市。
- **30～45天**：大型连锁超市、全国性供应商或长期稳定合作时较常见，通常伴随月结（每月固定日期结算上月货款）。
- **45～60天甚至更长**：多见于强势大型商超对中小供应商，或进口水果、冷链品类。但对水果这种高损耗品类，超过45天供应商压力会很大。

**实际谈判中要注意的点**

1. **结算方式比天数更重要**  
   “30天账期”可能指：到货后30天付款、月结30天、对账后30天，实际回款可能差出半个月。一定要把起算点和付款日写清楚。

2. **损耗和退货怎么算**  
   水果损耗高，超市常要求“滞销退货”“损耗分担”。账期越长，供应商越会把损耗和资金成本算进报价，最终还是超市买单。

3. **分品类定账期**  
   叶菜、浆果可以短账期甚至现结；苹果、橙子、进口水果耐储，可以谈更长账期。

4. **新供应商 vs 老供应商**  
   新合作通常先短账期（7～15天）建立信任，稳定后再逐步延长。

**给你的建议**

如果是中小超市或新合作，**15～30天**是比较现实、也容易谈成的区间；如果是大型连锁且供应商愿意配合，可以争取**30～45天**。但不要只盯天数，把**对账周期、付款日、损耗承担、退货规则**一起谈清楚，比单纯拉长账期更有价值。
