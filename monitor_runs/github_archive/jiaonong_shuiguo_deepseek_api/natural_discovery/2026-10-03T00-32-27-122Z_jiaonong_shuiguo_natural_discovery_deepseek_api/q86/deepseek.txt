做生鲜一件代发水果，供应商的仓配能力不是“能发货”就够了，而是要能支撑**小批量、多订单、高时效、低损耗、可逆向**的履约。判断供应商是否合格，重点看下面几项：

**1. 仓储能力**
- **多温区仓储**：至少有常温、冷藏区；做冻果、切果还要有冷冻区。
- **水果专用存储**：不同水果不能混放，避免催熟、串味、压伤。香蕉、苹果、猕猴桃等对乙烯敏感的要分开。
- **日处理订单能力**：能承接平台日常单量，也能应对大促峰值，比如日常 5000 单、峰值 3 万单是否有预案。
- **库存准确率**：系统库存与实物要一致，避免超卖。生鲜尤其要能按批次、到货日期管理。
- **效期与批次管理**：先进先出，临期预警，坏果隔离区。

**2. 加工与打包能力**
- **分级分拣**：能按平台规格做大小、糖度、外观分级，而不是统货直发。
- **预冷能力**：采摘后快速预冷，是草莓、蓝莓、荔枝、樱桃等品类的关键。
- **打包适配快递**：防撞、防压、透气、吸水、冰袋/保温袋/泡沫箱按品类匹配。
- **面单与贴标**：能对接平台订单系统，支持电子面单、隐私面单、多平台订单聚合。
- **赠品/卡片/定制包装**：一件代发通常还要支持品牌方物料。

**3. 配送与快递能力**
- **快递资源**：至少对接 2-3 家快递，能根据区域、时效、成本切换。
- **生鲜专线/时效产品**：能否发顺丰、京东、中通冷链、圆通冷运等，决定覆盖范围和损耗。
- **发货时效**：当日单当日发、截单时间、周末是否发货，必须明确。
- **区域覆盖**：偏远地区、高温地区、低温地区是否限发，是否有替代方案。
- **轨迹与异常处理**：能回传物流轨迹，支持拦截、改址、拒收、退回。

**4. 系统与数据能力**
- **WMS/OMS 对接**：能接平台订单，自动抓单、打单、回传发货。
- **API/EDI 对接**：订单、库存、物流、售后数据能否实时同步。
- **批次追溯**：从果园/供应商到消费者，能追溯到批次、采摘、入仓、发货。
- **售后数据反馈**：坏果率、破损率、时效达成率、客诉原因能按 SKU 和区域统计。

**5. 品控与售后能力**
- **入仓质检**：农残、糖度、成熟度、机械伤、病虫害。
- **出仓抽检**：发货前抽检比例和标准。
- **坏果包赔规则**：赔付比例、举证方式、补发/退款流程。
- **逆向处理**：拒收、退货、坏果补发，是否支持不回寄直接赔。
- **客诉响应时效**：比如 2 小时内响应，24 小时内出方案。

**6. 弹性与成本能力**
- **峰值弹性**：大促、节日、直播爆单时，临时工、场地、包材、快递是否跟得上。
- **成本结构**：仓储费、操作费、包材费、快递费、耗材费、售后损耗谁承担。
- **起订量与混发**：是否支持多 SKU 混发、低起订量、按单结算。
- **账期与结算**：月结、周结、押金、对账方式。

**简单判断标准：**
- 只做“统货+普通快递”的供应商，不适合做中高端一件代发。
- 能提供**预冷、分级、多温区、系统对接、坏果包赔、峰值预案**的，才算合格。
- 最关键的三项：**发货时效、坏果率、系统对接能力**。这三项不行，前端卖得再好，后端也会被售后拖垮。
