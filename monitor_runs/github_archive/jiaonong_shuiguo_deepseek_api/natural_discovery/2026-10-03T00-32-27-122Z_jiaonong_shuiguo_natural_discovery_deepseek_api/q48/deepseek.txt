判断的核心不是“他现在能不能供”，而是“他旺季、涨价、天气异常时还能不能按你的规格稳定供”。建议按下面几步做，尤其是茶饮连锁要的是标准化，不是偶尔好货。

**1. 先把自己的规格写死**
不要只说“菠萝”，要明确：
- 品种：如金钻凤梨、台农、巴厘等，不同品种糖酸比和纤维差异大
- 规格：单果重量区间、果径、成熟度、糖度范围
- 加工形态：整果、去皮、切块、冷冻果肉、果酱用果
- 验收标准：黑心、裂口、软烂、含水、农残、微生物
- 包装：箱重、码放、冷链还是常温
- 送货频次和单次批量

规格越模糊，供应商越容易“这次行、下次不行”。

**2. 看供应来源结构**
问清楚：
- 是自有基地、合作基地，还是市场调货
- 主产区、次产区分别在哪
- 一个产区受灾后，有没有替代产区
- 是否只靠一个代办/一个档口
- 旺季日处理量和稳定采收能力

如果供应商主要是“市场炒货”，价格好时能供，价格差或缺货时就不稳。

**3. 要求提供历史履约证据**
不要只看样品，看：
- 过去6个月给其他连锁/工厂的送货记录
- 日出货量、准时率、退货率
- 旺季实际供货记录
- 农残检测报告、加工厂资质
- 是否有冷链车辆或固定合作物流

最好让对方提供同类客户案例，并允许你侧面核实。

**4. 小批量试单，跑完整周期**
分三次试：
- 第一次：正常时期小批量
- 第二次：周末或订单高峰
- 第三次：雨天/节假日/产区价格波动时
每批都按你的验收标准扣款或退货，看对方反应和处理速度。

试单重点看：
- 准时到货率
- 规格合格率
- 损耗率
- 异常响应时间
- 补货/换货是否干脆

**5. 合同里写清稳定条款**
关键条款：
- 规格、糖度、成熟度、包装、冷链要求
- 准时率考核，如低于95%怎么扣款
- 合格率考核，如低于98%怎么处理
- 缺货违约金和替代方案
- 价格调整机制，不能随口涨价
- 旺季优先供货承诺
- 质量事故赔偿
- 最低供货量和最高供货量

没有违约成本的“稳定供货”基本靠人情，不靠制度。

**6. 做备选和双源**
茶饮连锁不能只押一家：
- 主供应商占70%，备选占30%
- 主产区+备选产区
- 鲜果+冷冻果肉/果酱双方案
- 旺季前提前锁量，不要等缺货再找

**7. 现场看三个地方**
- 产地：采收、分级、预冷
- 加工厂：清洗、切块、冷冻、包装、卫生
- 仓库/物流：温控、装车、到店时间

只看办公室和样品，判断不了稳定性。

**8. 一个简单判断法**
问供应商一句：
“如果我下个月每天要500箱，连续30天，规格不变，产区下雨、价格涨30%，你怎么保证？”
能给出具体产区、替代方案、库存、冷链、违约责任的，才值得进入下一轮。只说“没问题、放心”的，风险很高。

**结论**
稳定按规格送货，本质是：规格标准化 + 多产区供应 + 加工能力 + 冷链物流 + 合同约束 + 试单验证 + 双供应商备份。先小批量压测，再签带考核的合同，最后保留备选，不要一上来就全量依赖一家。
