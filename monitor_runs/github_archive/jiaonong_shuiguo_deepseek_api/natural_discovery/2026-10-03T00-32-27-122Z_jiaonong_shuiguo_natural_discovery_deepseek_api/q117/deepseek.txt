先给一个稳妥的量化思路：**新品试卖量 ≈ 单店/单渠道 3～7 天销量 × 1.2 安全系数**。水果怕压货、怕损耗，所以核心不是“进多少”，而是“先小批量测动销”。

可以按场景直接套：

1. **完全没卖过的新品**
   - 单店先试 **1～2 箱**，或 **20～50 斤/件**，具体看包装规格。
   - 如果是高端、小众、单价高的水果，先拿 **1 箱样品 + 少量可售货**。
   - 目标：测 3 天。看：
     - 顾客问不问
     - 试吃后买不买
     - 复购有没有
     - 损耗快不快

2. **社区水果店/单店**
   - 首单建议 **2～3 箱**。
   - 如果单箱 10kg，就是 **20～30kg**。
   - 卖得好，第 3～5 天补货；卖不动，第 2 天就做试吃、搭售、降价清。

3. **连锁门店/多店**
   - 不要一次全铺。
   - 先选 **3～5 家代表性门店**试卖。
   - 每店 **1～2 箱**，总试卖量控制在 **5～10 箱**。
   - 跑 5～7 天再决定是否扩店。

4. **线上社群/团购**
   - 先开 **1 团，限量 20～50 单**。
   - 不要按供应商起订量硬吃。
   - 看履约：坏果率、退款率、复购率。

5. **批发档口**
   - 首单可以比零售大胆一点，但也不要超过 **半天到一天正常动销量**。
   - 比如平时同类单品一天走 20 箱，新品先拿 **5～10 箱**。
   - 批发最怕砸价，先试水不丢人。

判断标准可以很简单：

- **3 天动销率 ≥ 50%**：可以补货。
- **3 天动销率 30%～50%**：先促销，不补。
- **3 天动销率 < 30%**：基本判死刑，清货止损。
- **损耗率 > 10%**：要么供应链有问题，要么这个品不适合你。

另外，采购前一定要和供应商谈清楚：

- 试卖支持：小起订量、混拼、样品价
- 售后：坏果包赔、损耗补贴、滞销调换
- 账期：最好先货后款或部分押款
- 价格保护：试卖期后如果降价，前期库存补差

最稳的一句话：**首单不超过你 3 天能卖掉的量，最多 1.2 倍。卖得好再追，卖不好能清。**  
如果供应商连小批量试卖都不支持，这个新品风险就偏高，不建议直接压大货。
