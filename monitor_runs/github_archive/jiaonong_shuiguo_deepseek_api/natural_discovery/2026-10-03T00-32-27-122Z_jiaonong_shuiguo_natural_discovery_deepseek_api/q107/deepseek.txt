会，而且香蕉和菠萝的损耗风险对“起订量太高”特别敏感，因为两者都属于后熟型或易腐水果，采购批量一旦超过实际周转能力，损耗通常不是线性增加，而是明显放大。

具体来看：

**1. 香蕉的损耗风险更高**
- 香蕉是典型的后熟型水果，采购后还会继续成熟。
- 起订量太高时，如果不能在最佳成熟窗口内卖完，很快就会从“可售”变成“催熟、发黑、软烂”。
- 香蕉对温度、乙烯、挤压都敏感，堆压、通风差、周转慢都会加速损耗。
- 所以香蕉的高起订量，往往直接带来“前段卖得动、后段集中报废”的问题。

**2. 菠萝相对耐放，但也不是没风险**
- 菠萝比香蕉耐储存一些，完整果相对不容易短时间内迅速腐败。
- 但起订量太高仍会增加：
  - 仓储和堆压损伤；
  - 成熟度不一致导致的集中熟化；
  - 表皮碰伤后感染腐烂；
  - 切开或鲜切产品的保质期压力。
- 如果是鲜切菠萝，损耗风险会接近甚至超过香蕉。

**3. 判断会不会增加损耗，关键看这几个条件**
- **日均销量**：起订量是否超过 3～7 天的实际销量。
- **补货周期**：如果一周只能订一次，高起订量更容易压货。
- **仓储条件**：是否有冷藏、通风、分区存放条件。
- **成熟度**：到货是青果还是已熟果，差别很大。
- **销售渠道**：整果零售、鲜切、餐饮供货，对周转速度要求不同。
- **加工能力**：能否及时做果汁、果切、烘焙等转化。

**4. 可执行建议**
- **香蕉**：起订量尽量控制在预计 2～4 天销量内；如果必须大批量采购，优先要求分批次到货或不同成熟度混装。
- **菠萝**：整果可适当放宽到 5～7 天销量，但鲜切用途要按 1～3 天周转控制。
- **设置安全库存**：不要只看采购单价，要算“采购价 + 预计损耗 + 仓储成本”的综合成本。
- **小批量试单**：先按当前起订量跑 1～2 个周期，记录实际损耗率，再决定是否接受高起订量。
- **谈判替代方案**：要求供应商拆批送货、混搭品种、调整成熟度，或把高起订量换成“锁价不限量”。

**结论**
起订量太高，大概率会增加香蕉和菠萝的损耗风险，香蕉尤其明显。能不能接受，不取决于起订量本身，而取决于你的周转速度、仓储条件和销售转化能力。如果日均销量撑不起这个量，高起订量省下的采购成本，通常会被损耗吃掉。
