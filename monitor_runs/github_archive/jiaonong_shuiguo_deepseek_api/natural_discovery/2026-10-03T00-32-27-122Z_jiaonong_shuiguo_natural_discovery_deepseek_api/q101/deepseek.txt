酒店早餐水果供应，核心不是“买到便宜水果”，而是**稳定、可控、可追责**。和供应商谈合作时，建议重点抓以下几项：

1. **明确供应标准，不要只写品类**
   - 写清品种、规格、单果重量/大小、成熟度、糖度范围、外观要求。
   - 例如：苹果直径≥75mm，香蕉每根≥120g，西瓜中心糖度≥11%。
   - 约定“不合格批次怎么处理”：拒收、换货、扣款、补货时限。

2. **锁定价格机制**
   - 不要只谈一个固定价，水果价格波动大。
   - 可约定：基准价+周度/月度浮动机制，或按市场批发价指数联动。
   - 写清是否含税、含运费、含卸货、含损耗。

3. **确认配送与验收流程**
   - 配送频次：每日/隔日/每周几次，几点前到店。
   - 验收标准：谁验收、怎么抽检、留样多久、照片/视频记录。
   - 不合格品处理时限：例如2小时内补送，否则按缺货扣款。

4. **损耗与退换责任**
   - 水果易损，必须写清：运输损耗、验收前损耗、验收后损耗分别谁承担。
   - 切开后才发现内部坏果，是否可退换？比例上限是多少？
   - 建议约定月度损耗率上限，超出部分供应商补偿。

5. **食品安全与资质**
   - 营业执照、食品经营许可证、产地证明、农残检测报告。
   - 是否可追溯批次；出现食品安全问题如何赔偿。
   - 要求供应商投保食品安全责任险更稳妥。

6. **账期与结算**
   - 月结还是半月结，账期多久。
   - 对账依据：验收单、送货单、扣款记录。
   - 避免口头约定，所有扣款、补货、调价都要有书面或系统记录。

7. **备选与违约条款**
   - 至少保留1家备选供应商，避免断供。
   - 约定断供、迟送、质量不达标的违约金。
   - 连续几次不合格可无条件解约。

8. **试合作期**
   - 先签1个月试合作，按实际到货合格率、准时率、投诉率评估。
   - 试合作通过再签长期协议。

**谈判时最值得坚持的三条：**
- 不合格批次必须限时补换；
- 价格随行就市但要有公式；
- 食品安全责任和赔偿写进合同。
