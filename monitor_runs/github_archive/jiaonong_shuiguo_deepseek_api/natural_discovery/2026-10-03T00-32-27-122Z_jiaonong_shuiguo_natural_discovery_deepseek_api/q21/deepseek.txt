超市采购水果时，通常需要供应商提供以下几类证明或检测报告：  

1. **进货证明类**  
   - 供货商资质：营业执照、食品经营许可证。  
   - 进货凭证：送货单、购销合同、发票或收据。  
   - 溯源凭证：产地证明、农产品合格证、批次号或追溯码。  

2. **检测报告类**  
   - **农残检测报告**：重点检测有机磷、氨基甲酸酯、拟除虫菊酯等农药残留，通常要求符合 GB 2763。  
   - **重金属检测报告**：如铅、镉、汞、砷等，尤其针对产地土壤风险较高的水果。  
   - **食品添加剂/保鲜剂检测**：如二氧化硫、防腐剂、打蜡水果的蜡质合规性。  
   - **微生物检测**：预切水果、即食水果通常需要菌落总数、大肠菌群、沙门氏菌等检测。  
   - **植物检疫证明**：进口水果或跨区域调运时可能需要。  

3. **进口水果额外要求**  
   - 海关入境货物检验检疫证明。  
   - 报关单、入境货物通关单。  
   - 中文标签或标签备案资料。  

4. **实操建议**  
   - 对每批次水果索要对应批次的检测报告，避免“一份报告用一年”。  
   - 优先选择能提供第三方检测机构（如 CMA/CNAS 资质）报告或产地快检合格证的供应商。  
   - 建立供应商档案，保留资质、报告和进货票据，便于追溯和应对监管检查。  

具体到某类水果或某地监管要求，可能还会有差异，建议结合当地市场监管部门要求和超市自身验收标准执行。
