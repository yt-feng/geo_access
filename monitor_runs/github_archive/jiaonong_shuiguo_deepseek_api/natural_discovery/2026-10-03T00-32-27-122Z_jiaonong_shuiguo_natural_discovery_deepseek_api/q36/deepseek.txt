结论先说：**如果门店客流稳定、有冷链和现场加工条件，优先做“整果+切好”双陈列；如果只能选一种，多数商超更适合以整果为主，切好作为补充。**

原因如下：

**1. 整果更适合作为主力**
- **毛利和损耗更可控**：整果保质期相对长，压货风险小，不需要当天必须卖完。
- **采购和运营简单**：不用额外人工、刀具、包装、冷藏陈列，损耗主要来自自然腐烂，可分级处理。
- **适合家庭囤货和价格敏感客群**：菠萝单价不高，整果更有“划算感”，也方便做促销。
- **可现场加工增值**：顾客买整果后，门店可提供有偿或满额免费削皮服务，兼顾体验和毛利。

**2. 切好更适合作为补充和增量**
- **适合即时消费人群**：上班族、单人家庭、年轻顾客更愿意买切好的，省事。
- **能提升客单价和冲动购买**：切好的菠萝通常按盒/份卖，单价折算往往高于整果。
- **能消化次果、小果**：外观稍差但品质没问题的菠萝，切盒后能减少整果报损。
- **但损耗和食安压力大**：切好后必须冷藏、当日或短保销售，操作不卫生容易出问题，人工成本也高。

**3. 关键看门店条件**
- **有冷柜、有果切操作间、客流大**：适合整果+切盒一起做，切盒能明显提销售。
- **只有普通货架、没冷链、客流一般**：以整果为主，最多做少量现场削皮，不建议大量预切。
- **高端社区/写字楼店**：切好比例可以提高，甚至做小份装、拼盘。
- **菜市场型/家庭采购多的店**：整果更稳，切好只是补充。

**4. 实操建议**
- **整果**：做引流和家庭装，按大小分级定价，配合“免费削皮”提升体验。
- **切好**：只做当天量，冷藏陈列，标注加工时间，优先用外观瑕疵但成熟度合适的果。
- **控制比例**：初期切果占比控制在总菠萝销量的 **20%—30%**，看动销再调整。
- **避免一刀切**：不要全部预切，否则损耗和食安风险会吃掉利润。
- **看数据决策**：连续观察1—2周，记录整果销量、切盒销量、报损率、人工耗时，再决定是否扩大切果。

**一句话：整果是基本盘，切好是利润和便利性补充。多数商超最优解不是二选一，而是“整果为主、切好为辅、按客流和冷链定比例”。**
