生鲜水果到货后出现坏果，责任划分通常不能简单说“全怪商家”或“全怪顾客”，关键看**坏果发生在哪个环节、是否可归责于某一方、以及有没有及时验收和留证**。

可以按下面几个层面判断：

**1. 到货时就已经坏了**
如果顾客签收时或开箱后短时间内发现明显腐烂、发霉、压烂、异味，一般应由商家或平台承担主要责任。  
因为生鲜在发货前就应做好分拣、成熟度控制、防压包装和冷链运输。  
常见处理：退款、补发、按坏果比例赔付。

**2. 运输过程中造成的损坏**
如果是快递暴力分拣、冷链中断、配送超时导致变质，责任通常在商家或平台一方，商家再向物流追偿。  
顾客一般不需要直接找物流，除非是顾客自己指定物流且商家能证明包装合格。

**3. 顾客签收后放置过久**
如果水果本身到货时没问题，但顾客没有及时开箱、没有按说明冷藏，导致后续腐烂，责任通常顾客自己承担。  
尤其是一些易熟、易腐水果，如草莓、荔枝、杨梅、水蜜桃等，对时效要求很高。

**4. 顾客自身保存或处理不当**
比如把该冷藏的放在高温处、把未熟果和已熟果混放、清洗后长时间不吃完等，造成坏果，一般不由商家负责。

**5. 无法判断坏果发生时间**
这是最常见的争议点。  
如果顾客没有开箱视频、没有及时拍照、拖了很久才投诉，商家可能会主张“签收时是好的”。  
这时平台往往会看：  
- 签收时间到投诉时间有多久；  
- 是否有开箱照片/视频；  
- 坏果比例和腐烂程度；  
- 商品页面是否有“坏果包赔”承诺；  
- 物流时效是否异常。

**6. 实操上比较合理的划分**
- 签收后短时间内发现大面积坏果：商家/平台赔。
- 少量坏果且比例在承诺范围内：按比例赔。
- 个别坏果但顾客拖延数天才反馈：协商处理，商家责任较轻。
- 顾客保存不当导致：顾客承担。
- 无法举证且超过合理反馈时间：平台通常不会支持全额赔付。

**7. 给顾客的建议**
- 收货后尽快开箱，最好拍连续开箱视频。
- 坏果单独拍照，保留外包装、快递面单、物流记录。
- 尽早联系商家或平台，不要拖到几天后。
- 不要直接扔掉全部坏果，先留证再处理。

**8. 给商家的建议**
- 商品页明确坏果赔付规则和反馈时限。
- 对易腐水果做好冷链、防压、透气包装。
- 要求顾客提供开箱证据，但也不能一律推给顾客。
- 对明显运输或分拣问题，先赔后追偿，避免差评扩大。

一句话总结：  
**到货即坏或运输导致，商家/平台主责；签收后因顾客保存不当导致，顾客主责；无法举证时按反馈时效、坏果比例和平台规则协商划分。**
