在水果采购合同里，**没有一个法定的“统一坏果率赔付线”**，关键看合同约定和验收标准。实务上可以这样判断：

1. **有合同约定时，按合同执行**
   - 常见约定是：**坏果率超过 3%、5%、8% 或 10%** 时，超过部分由供方赔付、补货或折价。
   - 生鲜水果因品种、运输距离、季节差异大，**5%～10%** 是比较常见的索赔触发区间。
   - 易损水果（如草莓、樱桃、荔枝、水蜜桃）可能约定到 **8%～15%**；耐储水果（如苹果、橙子、柚子）常会压到 **3%～5%**。

2. **没有明确约定时，看是否构成质量不合格**
   - 如果坏果率明显超出行业通常可接受范围，导致不能实现合同目的，可以依据《民法典》主张：
     - 要求减少价款；
     - 要求赔偿损失；
     - 严重时拒收、解除合同。
   - 但“超过多少算违约”仍要结合：合同用途、验收时间、运输责任、双方交易习惯来判断。

3. **建议直接写进合同的标准**
   可以写成类似条款：
   > 到货验收时，坏果率≤3%的，按合格处理；超过3%的部分，供方按该部分货值的100%赔付；超过10%的，需方可拒收整批或要求退货，并由供方承担运费及损失。

   更稳妥的写法是：
   - 约定**验收地点**：产地装车、到货地卸货前还是卸货后；
   - 约定**验收时间**：到货后几小时内；
   - 约定**抽样方法**：随机抽几箱、每箱抽多少；
   - 约定**坏果定义**：腐烂、发霉、压伤、冻伤、裂口是否都算；
   - 约定**赔付方式**：补货、扣款、折价还是现金赔偿；
   - 约定**运费和责任**：运输中坏果由谁承担。

4. **如果现在只是要一个谈判参考**
   - 你可以先提：**坏果率超过5%开始赔付，超过10%可拒收**。
   - 如果是高端精品水果或礼盒果，可压到 **3%**。
   - 如果是大宗批发、易损品种，可接受 **8%～10%** 起赔。

所以，核心不是“超过多少法律强制赔”，而是**合同有没有写清楚**。如果还没签，建议把起赔线、抽检方法和赔付公式都写进去；如果已经签了但没写，就按实际损失和行业通常标准去协商或主张。
