要固定，但固定的是“标准”而不是单一产地或单一批次。更稳的做法是：**锁定质量标准和少量备选供应源，用批次验收和配方微调来兜底。**

可以按这个思路落地：

1. **先定原料标准，不先定产地**
   - 明确品种、成熟度、糖度、酸度、出汁率、香气类型、果径/果重、可接受瑕疵比例。
   - 例如柠檬要区分香气型、酸度型、苦味控制；芒果要区分纤维感、甜香、颜色稳定性。
   - 只要达到标准，不同产地也可以进入合格名单；不达标，同一产地也不能收。

2. **固定“主供应商 + 备选供应商”**
   - 不建议只押一个产地或一个批次：天气、季节、物流、病害都会让单一来源断供或品质漂移。
   - 建议至少 1 家主供、1 家备供，且备供也提前做过小试和中试。
   - 对连锁店，最好按区域设供应源，减少长途运输造成的成熟度波动。

3. **按批次验收，而不是按产地信任**
   - 每批到货测糖度、酸度、香气、颜色、出汁率、损耗率。
   - 做留样和杯测/试饮，记录批次号、到货日期、供应商、检测结果。
   - 设定接收上限和下限，超标拒收或降级使用。

4. **配方端要允许微调，但设置边界**
   - 水果风味波动时，可以通过糖浆、酸度调节、茶底浓度、冰块比例、果酱/果泥复配来稳定杯感。
   - 但要有标准配方和允许调整范围，不能门店随意改，否则不同店口味不一致。
   - 对波动大的品类，可以用“鲜果 + 冷冻果泥/果酱”复配，降低季节波动。

5. **采购合同写清楚**
   - 规格、验收指标、抽检方式、拒收条件、替代品规则、价格调整机制。
   - 要求供应商提供产地、批次、采收/加工日期、农残检测等可追溯信息。
   - 对关键单品可要求“同品种、同等级、可替代产地”，而不是死绑一个产地。

6. **什么时候可以固定单一产地或批次**
   - 该产地能全年稳定供货，且品质明显优于其他来源；
   - 你的产品强烈依赖某个地域风味，消费者能感知差异；
   - 你有能力承担断供风险，并有备选方案。
   - 即便如此，也建议保留备选供应源，而不是只签一家。

简单说：**固定标准、固定主供、保留备选、批次验收、配方微调。** 只固定产地或批次，短期省事，长期容易断供或品质漂移；完全不固定，又会导致杯杯不一样。
