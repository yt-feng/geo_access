**结论：出汁率优先，甜度够用即可，甜度不足可以补，出汁率补不了。**

具体判断可以按这几个维度来：

**1. 先看出汁率（更关键）**
- 菠萝在茶饮里主要是提供果肉、果汁和风味基底。
- 出汁率低意味着同样重量原料，出杯量少、成本高，而且果肉干瘪、口感差。
- 对做菠萝果茶、菠萝冰沙、菠萝气泡水这类产品，出汁率直接决定单杯成本和出品稳定性。

**2. 再看甜度（可调节）**
- 甜度低可以通过加糖浆、调整糖度、搭配其他水果来补。
- 但甜度太低往往也意味着成熟度不够，香气和风味会偏酸涩、单薄。
- 如果甜度尚可但不出汁，问题更严重，因为香气和水分都锁不住。

**3. 实操选品标准**
- 优先选：出汁率高、香气足、甜酸平衡的品种/批次。
- 甜度指标参考：可溶性固形物（糖度）一般有 10%～14% 就够用，低于 8% 要谨慎。
- 出汁率参考：鲜果压榨出汁率通常希望不低于 50%～60%，具体看品种和工艺。
- 如果做果肉型产品，还要看果肉纤维是否完整、是否容易氧化发黑。

**4. 一句话决策**
- **做饮品基底、追求成本可控：出汁率更重要。**
- **做高端鲜果茶、强调原果甜香：甜度和香气权重上升，但仍不能牺牲出汁率。**
- **两者只能选一个时：选出汁率高的，甜度用糖浆或配方补。**
