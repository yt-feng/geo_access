判断供应商售后响应是否稳定，不能只看承诺，要落到**合同条款+历史记录+压力测试**三方面。可以按下面几步操作：

**一、签约前先查“硬证据”**
1. **要历史售后台账**：让对方提供近3个月至少5笔售后记录，含时间、问题类型（烂果/短重/迟到）、响应时长、解决方式。注意看是否只有“已处理”没有时间戳。
2. **问清响应承诺**：明确是“2小时内回复”还是“24小时内解决”，要区分**响应**和**解决**。生鲜类建议要求：到货后2小时内可提异议，24小时内给方案。
3. **查人员配置**：问售后是专职还是销售兼管。兼管的基本晚上和周末找不到人，生鲜到货常在凌晨，这点很关键。

**二、用“小单+异常场景”做压力测试**
1. **先下小批量试单**，故意在非工作时间（比如晚上10点）发一条售后消息，看多久回。连续测2-3次。
2. **制造一次真实小异议**：比如报一箱香蕉有压伤，看对方是直接推诿、要求你先拍照走流程，还是主动给补货/扣款方案。重点看**是否要你反复催**。
3. **看补货速度**：生鲜售后最终看能不能快速补上，而不是只赔钱。问清“补货最晚多久到”。

**三、合同里写死可执行条款**
1. 售后响应时限：如“工作时间内2小时响应，非工作时间4小时响应”。
2. 解决时限：如“确认问题后24小时内补货或退款”。
3. 违约后果：如“超时一次扣当批次货款5%”或“累计3次可无条件解约”。
4. 指定对接人+备用联系人，写进合同，避免换人后失联。

**四、长期看两个指标**
- **首次响应达标率**：抽查10次售后，看几次在承诺时间内回。
- **一次解决率**：是否需要你催第二次、第三次。反复催才解决的，稳定性差。

**简单判断口诀**：敢给历史记录、非工作时间能回、小异议不扯皮、合同有超时罚则——四条都满足，售后基本稳；缺两条以上，慎用。
