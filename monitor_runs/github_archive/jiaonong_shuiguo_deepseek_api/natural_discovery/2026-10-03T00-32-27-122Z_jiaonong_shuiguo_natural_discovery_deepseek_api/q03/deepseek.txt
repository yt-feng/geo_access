夫妻店第一次找水果供货商，试单的核心不是“先少拿点看看”，而是**用最小成本验证三件事：货能不能稳定、损耗你能不能扛、账期和退换有没有坑**。香蕉、苹果、橙子这三类正好代表三种不同风险，建议分开试。

下面给你一套可直接执行的试单方法。

## 一、先明确试单目标

第一次合作，不要只看“便宜不便宜”，重点看：

1. **到店品质**：和看货/图片是否一致
2. **实际损耗**：坏果、压伤、青熟不均、大小不齐有多少
3. **补货稳定性**：第二天、第三天还能不能拿到同样货
4. **售后态度**：坏果认不认、怎么赔、多久补
5. **账期与结算**：现结还是压款，压几单，有没有隐形费用

试单量不要大，单一品种先拿 **1箱到2箱**，或者按你店里1到2天能卖完的量拿。目的是验证，不是压价。

## 二、三类水果怎么试，重点不同

### 1. 香蕉：试“成熟度”和“催熟控制”

香蕉最容易亏，因为它是后熟水果，到店后还会继续熟。

试单要点：
- 不要拿已经全黄的，除非你当天就能卖完
- 优先拿**微黄带绿**或**青黄**的，回店后能放1到2天
- 问清楚：是产地直发、催熟房出货，还是批发市场转手
- 看有没有**药水催熟过重**、柄部发黑、表皮起黑点
- 试单后记录：第1天卖相、第2天软硬、第3天是否发黑

判断标准：
- 如果到店当天就太熟，第二天开始黑，说明供货商不适合你
- 如果青得发硬，放3天还不熟，也不适合夫妻店快周转

建议试单量：
- 先拿 **1箱**，或者 **20到30斤**，别按整大件压
- 分两天卖，观察成熟速度

### 2. 苹果：试“等级一致性”和“压伤”

苹果相对耐放，但问题常在**大小不均、以次充好、底层压伤**。

试单要点：
- 明确要什么规格：70、75、80、85果，还是统货
- 问清楚是**净果**还是**毛重**，箱皮、纸托、垫板算不算重量
- 开箱看上层和底层是否一致
- 随机翻几个，看有没有暗伤、碰伤、发面
- 试单后放3到5天，看是否起沙、发绵、腐烂

判断标准：
- 如果上层大果、下层小果，直接扣分
- 如果箱重里纸托占太多，实际单价会变高
- 如果3到5天就大量发面，说明货龄偏大

建议试单量：
- 先拿 **1箱到2箱**
- 最好同一天从两家各拿1箱对比

### 3. 橙子：试“水分、酸甜度和表皮”

橙子重点是**失水、干疤、酸度不稳定、表皮打蜡**。

试单要点：
- 问清楚品种和产地：脐橙、冰糖橙、血橙、伦晚等，季节不同差别大
- 看表皮：过于油亮可能打蜡，干皱说明放久了
- 切开或剥开试：水分足不足，酸不酸，有没有酒味
- 问清楚是否分级，还是统货
- 试单后放5到7天，看失水速度和腐烂率

判断标准：
- 如果切开干、白囊厚、酸度高，顾客复购差
- 如果表皮有软斑、酒味，说明内部已经开始坏
- 如果5天内失水明显，说明仓储或运输有问题

建议试单量：
- 先拿 **1箱到2箱**
- 橙子可以稍微多拿一点，因为耐放，但第一次别超过3箱

## 三、试单具体流程

### 第1步：找2到3家候选供货商

渠道：
- 本地批发市场档口
- 产地代办
- 同行推荐
- 社区团购上游
- 水果批发平台

不要只找一家。夫妻店没有议价能力，必须对比。

### 第2步：先问清楚再拿货

直接问这8个问题：
1. 今天什么价，明天会不会变
2. 是净果还是毛重
3. 坏果怎么赔，比例多少
4. 能不能退换，多久内有效
5. 起送量多少，运费谁出
6. 是现结还是可以压一单
7. 能不能固定每周几送
8. 如果品质不稳定，能不能换货

对方回答含糊的，先少拿。

### 第3步：小量试单

建议第一次这样配：
- 香蕉：1箱或20到30斤
- 苹果：1到2箱
- 橙子：1到2箱

总金额控制在你能承受的范围内，比如 **300到800元**，看你的店大小。

不要第一次就混拿很多品种。先把这三样试清楚。

### 第4步：到店立刻验收

验收时做这几件事：
- 拍照：到货整体、开箱、底层、坏果
- 称重：抽1箱称净重，看和承诺差多少
- 计数：坏果几个，压伤几个
- 记录：到货时间、温度、成熟度

最好做个简单表格：

| 品种 | 供货商 | 到货日期 | 数量 | 坏果数 | 净重 | 第2天状态 | 第3天状态 | 是否复购 |
|---|---|---|---|---|---|---|---|---|
| 香蕉 | A |  |  |  |  |  |  |  |
| 苹果 | A |  |  |  |  |  |  |  |
| 橙子 | A |  |  |  |  |  |  |  |

### 第5步：卖3到7天再判断

不要当天就决定长期合作。至少观察：
- 香蕉：2到3天
- 苹果：5到7天
- 橙子：5到7天

看实际损耗率。夫妻店常见可接受范围：
- 香蕉：5%到10%以内算正常，超过15%就偏高
- 苹果：3%到5%以内较好，超过8%要谈
- 橙子：3%到5%以内较好，超过8%要谈

这是经验范围，不是绝对标准，具体看你的售价和客流。

## 四、怎么判断要不要继续合作

继续合作的条件：
- 品质和看货一致
- 损耗在可接受范围
- 坏果愿意赔或补
- 价格不是最低，但综合成本可控
- 送货时间稳定
- 不强制压大量库存

停止合作的条件：
- 第一次就以次充好
- 坏果不认，或者推给运输
- 毛重净重玩文字游戏
- 催你大量拿货
- 第二天价格随意涨
- 送货经常迟到

## 五、夫妻店最实用的试单策略

1. **同品种找两家对比**：比如苹果A家1箱、B家1箱，卖完看哪家好。
2. **先试耐放的，再试易坏的**：橙子、苹果可以先试，香蕉控制量。
3. **不要一次压太多**：第一次总库存不超过2到3天销量。
4. **把售后写在微信里**：不要只口头说，留下文字记录。
5. **用实际损耗算真实成本**：进价低但损耗高，等于进价高。
6. **稳定后再谈账期**：第一次最好现结或少量压款，别一上来就欠大额。

## 六、一句话总结

香蕉试**成熟度和催熟**，苹果试**规格和压伤**，橙子试**水分和失水**；每家先拿1到2箱，卖3到7天，记录坏果和损耗，再决定是否长期合作。第一次合作，宁可量小、现结、多对比，也不要贪便宜压大货。
