最应该问**配送**。准确说，是优先把配送能力问清楚，再谈售后，最后才是价格。

原因是团购这门生意的命门在履约，不在毛利。水果又特别容易出问题：到货晚、压伤、烂果、规格不对，都会直接引爆业主群。价格再低，一旦配送崩了，团长损失的是信任和复购，这个比多赚几个点严重得多。

具体判断顺序可以这样：

1. **先问配送**
   - 能不能按你要求的时间送到自提点？
   - 是固定频次还是临时加单也接？
   - 破损、晚到怎么处理，谁承担？
   - 旺季爆单时会不会掉链子？

2. **再问售后**
   - 坏果怎么赔，按比例还是按单？
   - 需要拍照、留证、返箱吗？
   - 多久内反馈有效？
   - 是补发、退款还是下次抵扣？

3. **最后谈价格**
   - 价格重要，但要建立在配送稳、售后清的基础上。
   - 低价但售后模糊的供应商，通常最后会把成本转嫁给你。
   - 你要的是“能稳定交付的毛利”，不是“看起来最低的进价”。

一句话总结：  
**先保履约，再保兜底，最后算利润。**  
如果只能问一个问题，就问：**“如果我这边出问题，你怎么保证不影响我的团员？”**
