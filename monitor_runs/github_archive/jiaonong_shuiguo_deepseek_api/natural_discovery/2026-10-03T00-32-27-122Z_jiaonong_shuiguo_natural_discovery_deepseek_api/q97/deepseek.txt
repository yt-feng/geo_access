酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准里，避免只写“新鲜、优质”这类模糊表述。下面按常见品类和通用要求说明。

## 一、通用规格标准

1. **品种与产地明确**
   - 写清具体品种，如“红富士苹果”“海南贵妃芒”“智利车厘子JJ级”，不要只写“苹果”“芒果”。
   - 同一批次品种、产地、等级应一致，不能混批。

2. **大小/单果重分级**
   - 按酒店果盘切配需求定规格，例如：
     - 苹果：单果 180–220g，横径 75–85mm
     - 橙子：单果 200–250g，横径 70–80mm
     - 西瓜：单果 4–6kg
     - 哈密瓜：单果 1.5–2.5kg
     - 葡萄：单串 400–600g，果粒均匀
     - 草莓：单果 15–25g，长度 3–4cm
   - 规格允许误差一般控制在 ±10% 以内，超差应拒收或折价。

3. **成熟度**
   - 果盘原料通常要求“八至九成熟”，到店后 1–3 天内可切配使用。
   - 香蕉、芒果、牛油果等后熟型水果，可按“到货成熟度”约定：如芒果到货 7–8 成熟，可存放 2–4 天。
   - 过生、过熟、发软、出水、发酵的应拒收。

4. **新鲜度与货架期**
   - 到货时剩余货架期建议不少于总货架期的 2/3。
   - 叶菜类、浆果类、切花类水果更严格，最好当日或次日使用。
   - 不得有冷藏超期、反复解冻、长期库存迹象。

5. **安全与合规**
   - 农药残留符合 GB 2763 等国家食品安全标准。
   - 提供批次检测报告、产地证明、合格证或追溯信息。
   - 预包装水果标签符合 GB 7718；进口水果有入境货物检验检疫证明。
   - 不得使用催熟剂、保鲜剂超范围或超限量。

6. **包装与运输**
   - 使用食品级周转箱、纸箱或保鲜袋，内衬清洁。
   - 运输温度按品类控制：浆果 0–4℃，热带水果 10–13℃，叶菜 0–4℃。
   - 不得与生鲜肉、水产品、化学品混装。
   - 到货中心温度符合约定，并有冷链记录。

## 二、通用外观标准

1. **整体外观**
   - 果形端正、大小均匀、色泽正常、成熟度一致。
   - 无畸形、无严重偏色、无大面积斑点。
   - 同一批次颜色、大小、成熟度差异小，便于摆盘。

2. **表面与果皮**
   - 果皮完整、光滑或符合品种特征，无破损、裂口、虫眼、病斑、霉变。
   - 允许轻微自然瑕疵，但不能影响切配和出成率。
   - 苹果、梨等允许少量轻微果锈，但不能超过约定比例。

3. **新鲜度表现**
   - 果梗新鲜、青绿或符合品种特征，不干枯、不发黑。
   - 无萎蔫、皱皮、失水、软烂、渗液。
   - 切口或果蒂处无霉变、无异味。

4. **气味与内部品质**
   - 有该品种正常香气，无酸败、发酵、酒味、霉味。
   - 切开后无褐变、空心、黑心、虫蛀、冻伤。
   - 糖度可按品类约定，如西瓜中心糖度≥10–11%，橙子≥10%，葡萄≥16%。

5. **洁净度**
   - 无泥土、无大量灰尘、无残留枝叶。
   - 无虫体、虫卵、蜗牛、蜘蛛网等。
   - 预切水果应符合即食标准，微生物指标合格。

## 三、验收与拒收建议

建议采购单写清：

- **抽样比例**：每批次抽检 5%–10%，问题批次加倍抽检。
- **拒收条件**：
  - 霉变、腐烂、虫蛀、异味；
  - 规格超差超过 10%；
  - 成熟度不符合约定；
  - 农残检测不合格或证明缺失；
  - 冷链断链、包装污染。
- **扣款/换货**：轻微不合格可折价，严重不合格整批退货。
- **留样**：每批次留样 24–48 小时，便于追溯。

## 四、可直接写进采购单的简化条款

> 供应商应保证水果原料品种、产地、等级与订单一致；大小均匀，单果重/横径符合约定规格，误差不超过±10%；成熟度八至九成，到货后剩余货架期不少于2/3；外观新鲜、无腐烂、霉变、虫蛀、异味、严重机械伤和冻伤；农残符合GB 2763，随货提供合格证明或检测报告；采用食品级包装，冷链运输不断链。验收按5%–10%抽检，不合格批次酒店有权拒收、换货或扣款。
