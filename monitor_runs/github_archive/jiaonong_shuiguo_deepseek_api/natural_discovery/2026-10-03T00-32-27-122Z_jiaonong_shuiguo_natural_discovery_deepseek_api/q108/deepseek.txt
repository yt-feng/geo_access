核实水果供应商的“全国配送”能力，不能只听口头承诺，可以从下面几个可验证的维度逐项确认：

1. **要求提供配送范围清单**
   让对方给出可配送省份 / 城市 / 区县清单，最好具体到“哪些地区不送、哪些地区只能隔日达、哪些地区需要自提或中转”。如果对方只说“全国都能送”，但拿不出清单，基本不可信。

2. **核实冷链与仓储节点**
   水果对温控和时效要求高。重点问：
   - 在哪些城市有自有或合作仓？
   - 冷链车、冷库、中转仓分别在哪里？
   - 到偏远地区是直发还是中转？
   没有区域仓和冷链节点，却承诺全国次日达，通常不现实。

3. **做小批量实测**
   不要一上来就大额下单。选几个代表性目的地，比如：
   - 一线城市
   - 中部省会
   - 偏远省份或地级市
   - 你实际要铺货的三四线城市
   各发一小单，记录下单到签收时间、包装完好率、温度、损耗率、是否额外收费。

4. **查真实客户案例和物流单号**
   让对方提供近期发往不同地区的物流单号或客户案例，最好能联系到 2–3 个非关联客户核实。注意区分“发货地直发”和“真正全国网络覆盖”。

5. **确认费用与责任边界**
   问清楚：
   - 偏远地区是否加收运费？
   - 中转、二次配送谁承担？
   - 出现烂果、延误、丢件怎么赔？
   - 是否支持指定快递或冷链承运商？
   这些写进合同或订单条款，才能判断“覆盖能力”是否包含成本可接受的服务。

6. **看资质与承运合作**
   查看营业执照、食品经营许可、道路运输相关资质，以及和顺丰冷运、京东冷链、中通冷链等承运商的合作协议或系统对接截图。有稳定承运合作，比口头“全国配送”可信得多。

7. **用地图和时效反推**
   让对方按你提供的收货地址，给出预计送达时效和运费报价。如果同一省份不同城市报价、时效差异极大，说明网络并不均衡。

**简单判断标准：**
- 能提供分省分市清单 + 区域仓/冷链节点 + 可实测小单 + 可核实客户案例 = 基本可信。
- 只有一句“全国配送”，拿不出清单、时效、案例和赔付方案 = 风险很高，建议先小单测试或换供应商。
