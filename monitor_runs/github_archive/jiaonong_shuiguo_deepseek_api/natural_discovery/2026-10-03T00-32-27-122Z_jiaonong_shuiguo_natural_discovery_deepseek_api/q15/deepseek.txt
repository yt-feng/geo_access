水果店遇到坏果时，核心原则是：**先固定证据，再按合同/行业惯例协商扣款或补货，不要等到卖完或扔完才找供应商。**

具体可以分几步处理：

1. **收货当场验收**
   - 生鲜水果一般要求在送货单上签字前开箱抽查。
   - 发现坏果，当场拍照、拍视频，记录品种、数量、批次、车牌/送货人、时间。
   - 在送货单上注明“发现坏果XX件/斤，待处理”，不要直接签“数量无误”。

2. **区分坏果比例和原因**
   - **少量坏果**：通常按实际坏果数量扣款，或下次补货时补回。
   - **批量坏果**：可要求整批退货、换货，或按坏果比例折价结算。
   - **运输/冷链问题**：如果合同约定由供应商负责运输和保鲜，损耗一般由供应商承担。
   - **自己存放不当**：比如到店后没及时冷藏、堆放压坏，通常不能全怪供应商。

3. **按合同或口头约定结算**
   - 有合同：按合同里的“损耗率”“验收标准”“退换货条款”执行。
   - 没合同：按行业常见做法，比如：
     - 坏果率在3%—5%以内，可能双方各让一点；
     - 超过约定比例，供应商补货或扣款；
     - 严重腐烂、无法销售，整批退换。
   - 结算方式常见有：
     - 直接扣减当批货款；
     - 下批补货抵扣；
     - 供应商退款；
     - 换货。

4. **保留证据再协商**
   - 照片、视频、送货单、聊天记录、转账记录都要留。
   - 最好当天或24小时内通知供应商，越早越好。
   - 协商结果用微信文字确认，比如“本次坏果XX斤，扣款XX元，下批补XX斤”。

5. **如果供应商不认**
   - 先看合同有没有违约责任和争议解决条款。
   - 没有合同，可以找批发市场管理方、行业协会调解。
   - 金额大且证据充分，可走法院小额诉讼或起诉。
   - 以后合作建议签简单供货协议，写明验收标准、损耗承担、退换货和结算方式。

一句话总结：**坏果赔付通常按“实际坏果数量×进货单价”扣款，或要求补货/换货；关键是在收货时验货、留证、及时通知，并按合同或约定比例处理。**
