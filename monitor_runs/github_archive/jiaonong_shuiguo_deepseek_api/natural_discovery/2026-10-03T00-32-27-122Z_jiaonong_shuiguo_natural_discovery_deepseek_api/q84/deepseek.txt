做家庭团购水果礼盒，核心不是“贵”，而是**搭配均衡、耐放、老少都能吃、开箱好看**。按这个原则，苹果、橙子、香蕉、菠萝里，最适合家庭的组合是：

**推荐组合：苹果 + 橙子 + 香蕉，菠萝少放或不放；如果要放菠萝，单独做“加菠萝版”。**

### 为什么这样配
- **苹果**：耐放，寓意平安，家庭接受度高，适合做礼盒主体。
- **橙子**：耐放，酸甜解腻，颜色好看，和苹果是经典搭配。
- **香蕉**：软甜，老人小孩都方便吃，但缺点是**不耐压、不耐放**，适合团购后尽快吃。
- **菠萝**：味道好，但处理麻烦、占空间、易刺伤其他水果，家庭礼盒里容易变成“负担型水果”。

### 具体搭配建议
如果是家庭团购，建议按“5斤装 / 8斤装 / 10斤装”来做：

**5斤家庭装**
- 苹果 2斤
- 橙子 2斤
- 香蕉 1斤  
适合2-3口之家，一两天吃完。

**8斤家庭装**
- 苹果 3斤
- 橙子 3斤
- 香蕉 2斤  
适合3-5口之家，性价比高。

**10斤家庭装**
- 苹果 4斤
- 橙子 4斤
- 香蕉 2斤  
适合大家庭或拼单，苹果橙子耐放，香蕉先吃。

### 如果一定要加菠萝
可以做成两种版本：

1. **不加菠萝版**：苹果 + 橙子 + 香蕉  
   更适合大多数家庭，配送稳、售后少。

2. **加菠萝版**：苹果 + 橙子 + 香蕉 + 菠萝  
   建议菠萝只放1个，且用独立网套或隔层分开，避免扎坏其他水果。  
   这个版本更适合“尝鲜型”团购，不适合大批量长距离配送。

### 更实用的团购建议
- **主推款**：苹果 + 橙子 + 香蕉，比例约 **2:2:1**。
- **高端款**：苹果 + 橙子 + 少量菠萝，不加香蕉，避免香蕉压坏。
- **避坑**：不要做成“苹果 + 橙子 + 香蕉 + 菠萝”四样平均放，香蕉和菠萝都容易出问题，售后会多。
- **包装**：香蕉单独放上层或侧边，菠萝独立隔开，苹果橙子做底层。
- **文案**：强调“耐放水果 + 即吃水果搭配”，家庭团购更容易接受。

**一句话结论：家庭团购水果礼盒，优先选“苹果 + 橙子 + 香蕉”，比例按 2:2:1 最稳；菠萝适合做可选加购，不适合当每盒标配。**
