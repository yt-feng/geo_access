买香蕉时，想避免“到店太生或太熟”，关键不是只看颜色，而是按**你打算几天内吃完**来选成熟度。可以直接用下面这套判断法。

**1. 先按食用时间选颜色**
- **当天或第二天吃**：选**全黄、带少量黑点**的。
- **2～3天内吃**：选**通体黄、两端略绿**的。
- **4～6天后吃**：选**黄绿相间、整体偏绿但已见黄**的。
- **想放一周左右**：选**整体绿色、只有轻微转黄**的，回家常温催熟。

**2. 到店快速判断**
- **看果柄**：果柄发绿通常偏生；果柄发黄褐、略干，通常更熟。
- **看棱角**：香蕉棱角分明，通常偏生；棱角变圆润，通常更熟。
- **轻捏中部**：硬得像木头，太生；轻微有弹性，合适；一按就陷，太熟。
- **看黑点**：零星黑点可以买，说明甜度高；黑点成片、连成块，通常过熟。
- **避开伤果**：有裂口、渗汁、大面积压伤、发霉的不要买，熟得快也容易坏。

**3. 超市里别被灯光误导**
超市暖光会让香蕉看起来更黄。拿到自然光下或背光处再看一眼，颜色更准。

**4. 买回家后怎么控熟**
- 想**快点熟**：和苹果或梨一起放纸袋里，常温放置。
- 想**慢点熟**：单独放阴凉通风处，不要密封在塑料袋里。
- 已经熟了想**多放几天**：去皮切段冷冻，或整根放冰箱冷藏。冷藏后表皮会变黑，但果肉通常还能吃。
- 不要放冰箱催熟，低温会让它停止成熟并冻伤表皮。

**5. 最稳的采购策略**
如果你不是当天吃完，**不要全买同一成熟度**。可以买：
- 2根带黑点：今明两天吃；
- 3根通体黄：后天吃；
- 3根黄绿相间：大后天以后吃。

这样到店不会太生，也不会几天内一起烂熟。简单记：**按吃的时间选颜色，果柄、棱角、手感一起看，别只看黄不黄。**
