单位采购水果到货品质不一致，验收和售后可以按下面这套流程处理，核心是：**先固定证据、再按标准分级、最后按合同/约定索赔或退换**。

## 一、到货前先明确验收标准

不要等到货再争论“算不算好”。采购时就要在订单或合同里写清楚：

1. **品种、规格、等级**：如苹果直径、火龙果单果重、车厘子J级/XL级等。
2. **成熟度、色泽、新鲜度**：是否允许轻微瑕疵、允许比例多少。
3. **糖度/口感要求**：如有需要，写清可抽检。
4. **包装、净重、损耗率**：如允许破损率≤3%、烂果率≤1%。
5. **验收时限**：到货后几小时内验收，逾期视为合格还是仍需处理。
6. **售后规则**：不合格部分如何退换、补发、折价、扣款。

## 二、到货验收怎么做

### 1. 当场清点数量
- 核对品种、箱数、件数、净重。
- 随机抽箱，不要只验最上面一层。
- 拍照/录像记录到货状态、车牌、批次、外包装。

### 2. 抽样检查品质
按批次分层抽样，建议：
- 大批量：每批抽5%—10%，或至少抽3—5箱。
- 小批量：逐箱检查。
- 重点看：烂果、压伤、霉变、虫蛀、异味、过熟、未熟、规格不符。

### 3. 分类记录
把到货分成：
- **合格**：符合约定标准。
- **轻微不合格**：可折价接收，如少量压伤、个头偏小。
- **严重不合格**：拒收或要求退换，如大量腐烂、霉变、货不对板。

### 4. 形成验收单
验收单至少写：
- 到货时间、批次、供应商；
- 采购数量、合格数量、不合格数量；
- 不合格类型和照片；
- 处理意见：接收/折价/退货/补发；
- 双方签字确认。

## 三、售后怎么处理

### 1. 先按合同约定走
有约定按约定：
- 不合格率在允许范围内：折价接收；
- 超过允许范围：退换、补发、扣款；
- 严重货不对板：整批拒收。

### 2. 没有明确约定时，可这样谈
- **轻微不一致**：按不合格比例折价，比如扣减对应货款。
- **部分腐烂/压伤**：供应商补发同等数量，或按比例退款。
- **整批品质差**：要求退货退款，运费由供应商承担。
- **影响使用**：如食堂、接待、福利发放，可要求赔偿因此产生的合理损失，但要有依据。

### 3. 售后时效
水果易腐，建议：
- 到货后**2—4小时内**完成初验；
- **24小时内**书面提出异议；
- 保留问题样品和照片，直到处理完毕。

## 四、建议的实操话术

对供应商可以这样说：

> 本次到货抽查XX箱，其中XX箱存在烂果/压伤/规格不符，不合格比例约XX%，已拍照记录并留存样品。请按合同第X条，在X小时内安排补发/退换/折价处理，否则我们将按不合格部分扣减货款。

## 五、最关键的三件事

1. **先定标准**：验收标准写进订单，避免扯皮。
2. **当场留证**：照片、视频、抽样记录、验收单。
3. **及时书面提出**：不要拖到水果放坏了再说。
