和小批量试单的核心目的不是赚钱，而是在**低风险**下验证几件事：**到货质量稳定性、规格是否一致、损耗率、发货时效、售后响应、价格是否有真实优势**。所以试单设计要围绕"可验证、可对比、可退可谈"来。

下面是一套可直接执行的试单方案。

## 一、先明确试单要验证什么

设计前先想清楚，否则容易变成"随便进一车货"：

1. **品质稳定性**：同一等级水果是否每次一致，还是首批好、后面掉。
2. **规格真实性**：承诺的果径、糖度、成熟度、包装重量是否达标。
3. **损耗与货架期**：运输后损耗多少，到你手上还能放几天。
4. **时效与物流**：发货是否按时，冷链/包装是否到位，到货是否新鲜。
5. **售后态度**：出问题时是推诿还是补货/退款。
6. **价格空间**：这个价能不能长期做，还是试单价。

## 二、试单规模怎么定

建议从**你能承受全损的最小量**起步：

- **金额**：控制在单次可承受损失范围内，比如 2000～5000 元，视你体量定。
- **数量**：够覆盖 2～3 个批次、能对比即可，不必整柜整挂。
- **品类**：先选**1～2 个你主力且耐运输的品种**，别一次上五六个品，否则变量太多说不清问题。
- **频次**：同一供应商建议连续做 **2～3 单小单**，单次看不出稳定性。

## 三、合同/约定要写清的关键项

哪怕是小单，也要把这些落到文字（微信确认也算证据）：

| 项目 | 要求示例 |
|---|---|
| 等级规格 | 果径 mm、单果重、糖度、成熟度 |
| 包装 | 箱规、净重、每箱个数、包装材质 |
| 价格 | 单价、是否含运费、是否随行就市 |
| 发货 | 发货时间、物流方式、冷运要求 |
| 验收标准 | 允许损耗率（如≤5%）、次果比例 |
| 售后 | 超损耗怎么补/赔，几天内反馈有效 |
| 结算 | 先款后货还是货到付款、账期 |

## 四、验收与记录（这步最关键）

试单的价值全在数据，不做记录等于白试。

1. **到货当场验**：称重、数箱、抽检果径糖度、统计坏果。
2. **拍照留证**：开箱、磅秤读数、坏果、包装，带时间。
3. **算三个数**：
   - 实际损耗率 = 坏果重量 / 总重
   - 实际到手成本 = 总付款 / 实际合格果重量
   - 货架期 = 从到货到明显变质的天数
4. **反馈给对方**：用数据谈，而不是"感觉不好"。

## 五、对比测试更靠谱

如果同时谈 2 家，**同品种、同规格、同期**各下一单，横向比：

- 到手成本
- 损耗率
- 品质一致性
- 售后响应速度

这样你才有议价和选择的依据。

## 六、试单节奏建议

1. **第1单**：最小量，验证基本流程和品质。
2. **第2单**：数量略增，看稳定性，刻意观察有无"首单好、复单差"。
3. **第3单**：接近正常采购量，测试其供货能力和时效。
4. 三单通过后，再谈**长期价、账期、独家/返点**。

## 七、几个要警惕的信号

- 只肯发一次好货，复单品质下滑 → 稳定性差。
- 拒绝书面约定损耗标准 → 售后必扯皮。
- 价格明显低于市场且要求全款 → 风险高，可能是以次充好或骗单。
- 物流信息含糊、临时改发货时间 → 履约能力差。

## 八、一句话决策标准

试单结束时，如果满足：**到手成本有优势 + 损耗率可接受 + 连续2～3单品质稳定 + 出问题肯负责**，就可以放量；任一不达标，先别加量。
