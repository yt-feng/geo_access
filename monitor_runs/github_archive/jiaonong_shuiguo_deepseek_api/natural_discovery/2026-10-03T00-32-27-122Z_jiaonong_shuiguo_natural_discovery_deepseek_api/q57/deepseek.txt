结论先说：**绝大多数餐饮连锁，水果应由中央厨房（或区域配送中心）统一收货、统一验收、统一分拨到门店；不建议门店分开收货。** 但有一种例外——极度依赖“当日鲜、本地短保”的高端现切水果/果盘业态，可以考虑“中央厨房统采+门店直送”的混合模式。

下面给你判断框架和可执行建议。

## 一、为什么中央厨房统一收货更好

**1. 品质标准统一**
水果最大的痛点是批次差异大。中央厨房集中收货，可以统一验收标准（糖度、成熟度、规格、色泽、损耗率），避免各门店各自为政、标准松紧不一。

**2. 议价和采购规模**
集中采购量大有议价权，能签产地直采或一级批发，单价通常比门店零散采购低。门店单独买，量小、价格高、还容易被供应商区别对待。

**3. 食品安全可追溯**
统一收货意味着统一索证索票、统一检测（农残快检）、统一台账。门店分开收货，追溯链条碎、责任分散，一旦出问题很难定位。

**4. 损耗和库存可控**
水果易损耗。中央厨房可以按门店销售数据做统配，减少门店盲目囤货；还能对品相不佳的果做二次利用（榨汁、切配、员工餐），降低整体损耗。

**5. 减少门店操作负担**
门店最该专注的是出品和服务，不是每天凌晨接货、验货、扯皮。集中收货能把门店从采购事务里解放出来。

## 二、什么情况下门店分开收货反而更合理

只有满足以下**多个条件**时才考虑：

- 水果是**核心卖点**，对新鲜度极度敏感（如高端果切、鲜榨果汁专门店）
- 门店分散且离中央厨房远，配送后鲜度明显下降
- 单店销量大，能独立形成采购规模
- 有本地优质产地/批发市场，直送比统配更快更便宜
- 门店具备验货能力和责任人

即便这样，也建议**统采定价 + 本地直送履约**的混合模式，而不是完全放任门店自采。

## 三、推荐落地模式（按连锁规模）

| 规模 | 推荐模式 |
|---|---|
| 1–5 家店 | 总部统采，少量门店直送 |
| 5–30 家店 | 中央厨房/区域仓统一收货+统配 |
| 30 家店以上 | 区域配送中心（RDC）+ 产地直采 |
| 高端鲜果业态 | 统采定价 + 产地/本地直送 + 门店验收 |

## 四、关键控制点（无论选哪种）

1. **统一验收标准**：规格、成熟度、糖度、破损率、农残。
2. **明确损耗归属**：配送前损耗归中央厨房，到店后归门店。
3. **冷链和时效**：水果配送温区、到店时间、周转天数要写进 SOP。
4. **数据驱动订货**：按门店销量和库存自动补货，别靠店长拍脑袋。
5. **供应商分级**：主供应商+备选，避免单一依赖。
6. **追溯台账**：批次、产地、检测报告一一对应。

## 一句话决策

**只要你的连锁有中央厨房或区域仓，水果就统一收货、统一分拨；只有“鲜度是命脉且统配会明显降质”的业态，才用统采+直送混合模式。**
