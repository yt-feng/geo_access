可以直接按“临时补货”单独约定，不要只靠口头加单。核心是把 **触发条件、数量、价格、到货时间、质量标准、违约责任** 写清楚。

**1. 先定触发和提前期**
- 约定旺季临时补货触发：比如日常订货量基础上，单次追加超过 **20%** 或 **50公斤** 时，走临时补货流程。
- 提前期写死：例如供应商收到书面/微信/系统订单后 **24小时或48小时内** 到店。
- 截单时间：比如每天 **下午3点前** 下单，次日到；3点后顺延一天。

**2. 数量要分档**
- 常规量：按原合同价。
- 临时补货量：可设阶梯价，例如：
  - 追加50公斤以内：原价；
  - 50–100公斤：上浮不超过5%；
  - 100公斤以上：双方当天确认价。
- 这样避免供应商旺季临时坐地起价，也避免你方随意加单导致对方拒供。

**3. 价格机制**
- 最好约定：临时补货价 = 当日市场批发价 + 固定服务费/运费，或 = 原合同价上浮不超过X%。
- 如果无法固定价，至少约定“报价有效期”：供应商报价后 **2小时内** 你确认即锁价。

**4. 质量与验收**
- 菠萝规格写清楚：品种、单果重量、成熟度、有无黑心、破损率上限。
- 到店验收：抽样称重、切开检查。不合格可拒收或要求 **2小时内补换**。
- 临时补货最容易出问题的是“熟度不够/过熟”，所以验收标准不能省。

**5. 违约和保障**
- 供应商未按时到货：按迟到小时扣款，或承担你临时采购差价。
- 你方临时取消：超过约定时间取消，可承担部分损耗，比如按货值10%–20%。
- 旺季可要求供应商预留**安全库存**，比如每天为你店预留 **X公斤**，你未提货也需提前几小时通知。

**6. 操作上建议**
- 建一个“临时补货群”或固定对接人，避免多人乱下单。
- 每次补货用固定模板：日期、品种、数量、到货时间、单价、验收人。
- 保留聊天记录、转账记录、验收照片。
- 如果用量波动大，可签一份 **旺季补充协议**，只针对6–9月或旺季月份生效。

**最简单可落地的条款写法：**
“旺季期间，甲方可临时追加菠萝订单，单次追加不超过XX公斤；乙方应在收到订单后24小时内送达。临时补货价格按原合同价上浮不超过X%。到货后甲方按约定规格验收，不合格乙方2小时内补换。乙方逾期到货，按每小时XX元或当次货值X%承担违约金；甲方确认后取消，按货值X%承担损耗。”
