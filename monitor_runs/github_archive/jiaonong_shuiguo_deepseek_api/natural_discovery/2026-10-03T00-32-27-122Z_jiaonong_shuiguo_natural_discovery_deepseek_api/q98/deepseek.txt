判断水果供应商是否合规、稳定，建议分两条线看：先看“资质与合规”，再看“履约与稳定性”。对养老院、医院食堂这类场景，还要额外关注食品安全追溯和应急保供能力。

**一、合规性怎么查**

1. **主体资质**
   - 营业执照：经营范围应包含水果批发/零售/农产品销售等。
   - 食品经营许可证：如果供应商提供的是预包装或散装食品，通常需要；若只是销售食用农产品，各地监管口径可能不同，应以当地市场监管部门要求为准。
   - 若供应商声称是“产地直供”“合作社”，也要核对其是否具备相应经营主体资格。

2. **产品合规与追溯**
   - 要求提供每批次水果的产地证明、进货凭证或购销台账。
   - 重点看农残检测报告：最好是第三方检测报告或供应商自检记录，且能对应到具体批次。
   - 对高风险水果，如草莓、葡萄、叶菜类伴生水果等，可要求更频繁的检测或抽检。
   - 有条件的，可要求供应商提供“承诺达标合格证”或类似产地准出证明。

3. **人员与仓储合规**
   - 配送人员是否有健康证明。
   - 仓库、冷库、运输车辆是否清洁、温控是否达标。
   - 是否做到生熟分开、防鼠防虫、离地离墙存放。

4. **合同与票据**
   - 合同里明确：品名、规格、等级、单价、数量、配送时间、验收标准、退换货规则、违约责任。
   - 每次配送必须带送货单，能开具发票或合规票据。
   - 保留验收记录、检测报告、票据，至少按食堂食品安全管理要求存档。

**二、稳定性怎么判断**

1. **看供应能力**
   - 是否有稳定货源：自有基地、长期合作产地、批发市场档口，还是临时调货。
   - 是否有冷库、冷链车、分拣场地。
   - 旺季、淡季、节假日、极端天气时能否保供。

2. **看履约记录**
   - 要求提供近半年或一年的合作单位名单，最好能联系现有客户核实。
   - 重点问：迟到率、缺货率、坏果率、退换货响应速度。
   - 可先小批量试供1—2周，再决定是否签长期合同。

3. **看价格与结算**
   - 价格是否随行就市但又有合理区间，避免明显低于市场价。
   - 是否接受月结、账期、对账机制。
   - 是否愿意把“缺货替代方案”写进合同，比如指定替代品种或提前通知。

4. **看应急能力**
   - 是否有备用供应商或备用产地。
   - 突发情况下能否24小时内补货。
   - 是否支持临时加单、减单、改单。

**三、实操建议**

- **先查证，再试供，后签约**：不要只看报价，先核资质和检测报告。
- **建立验收标准**：比如外观、成熟度、单果重、糖度、坏果率上限。
- **双供应商机制**：主供应商+备用供应商，避免单一依赖。
- **定期评估**：每月或每季度打分，指标包括质量、准时率、价格、服务、投诉处理。
- **留痕管理**：每批次票据、检测报告、验收单、照片都存档，便于追责和监管检查。

**四、特别提醒**

养老院和医院食堂服务对象特殊，建议优先选择：
- 能提供批次检测报告的供应商；
- 有冷链能力的供应商；
- 愿意接受食堂现场验收和抽检的供应商；
- 能配合留样、追溯、应急保供的供应商。

如果对方只能给“口头保证”，拿不出票据、检测报告或稳定客户证明，合规和稳定性风险都比较高，不建议直接长期合作。
