学校食堂采购水果，选供应商的核心不是“找最便宜的”，而是找**能稳定供货、质量可控、票据齐全、出了问题能追责**的。香蕉、苹果、橙子属于高频大宗水果，建议按下面思路做。

## 1. 先定采购标准，再找供应商

不要先问供应商“你有什么”，而是先写清楚食堂要什么：

- **品种/规格**：如苹果要红富士、单果直径75-80mm；橙子要赣南脐橙或冰糖橙；香蕉要未催熟或半熟、单根长度和把型要求。
- **成熟度**：香蕉到货不能太熟，苹果要脆，橙子要酸甜适中。食堂通常要求“到货后还能放2-3天”。
- **外观和损耗**：坏果率、压伤率、霉变率上限，比如到货验收坏果率不超过3%-5%。
- **农残和票据**：要求提供承诺达标合格证、检测报告或产地证明，能开正规发票。
- **配送要求**：每周送几次、几点前到、临时加单多久能补、谁卸货、破损谁赔。

这些标准写进询价单或采购需求里，供应商才知道怎么报价。

## 2. 供应商类型怎么选

常见有几类：

| 类型 | 优点 | 风险 |
|---|---|---|
| 批发市场档口 | 价格低、品种多、起送灵活 | 质量波动大，票据和追责弱 |
| 产地合作社/果园 | 价格和新鲜度可能好 | 配送不稳定，小单不接，售后慢 |
| 本地水果配送商 | 配送及时、售后方便 | 价格略高，需查资质 |
| 大型食材供应链平台 | 票据全、流程规范、可追责 | 价格偏高，小食堂可能不划算 |
| 商超/生鲜平台 | 质量稳定、开票方便 | 价格高，不适合大批量 |

对学校食堂，比较稳妥的是：**本地配送商为主，产地或批发市场为辅，大型平台作为应急备份**。不要只依赖一家。

## 3. 重点看哪些资质和条件

至少要核验：

- 营业执照、食品经营许可证或相关备案；
- 能开正规发票；
- 水果来源可追溯，能提供产地或批次信息；
- 有冷链或遮阳配送能力，尤其夏天；
- 有固定仓配和售后人员，不是临时倒手；
- 同意签合同、押质保金或接受月度结算；
- 过往是否给学校、医院、企事业单位供过货。

如果供应商说“票没有”“检测报告没有”“坏了下次补”，这种要谨慎。

## 4. 比价不要只看单价

水果报价要看**综合成本**：

- 单价；
- 损耗率；
- 实际可食用率；
- 配送费；
- 退换货是否及时；
- 结算周期；
- 缺货时能否补位。

比如A报价低但坏果多、需要自己挑拣，实际成本可能比B更高。建议让供应商按“净果到货价”或“验收合格后结算价”报价。

## 5. 建议的筛选流程

1. **列需求**：品种、规格、数量、频次、配送时间、结算方式。
2. **找3-5家**：本地配送商、批发市场大户、产地合作社、供应链平台各找一点。
3. **要报价和样品**：同一标准下比价，别拿不同规格比。
4. **试供1-2周**：看准时率、新鲜度、坏果率、补货速度、态度。
5. **验收评分**：质量、价格、配送、售后、票据五项打分。
6. **签合同**：明确标准、价格调整机制、违约责任、食品安全责任。
7. **保留备选**：主供应商+备选供应商，避免断供。

## 6. 合同里必须写清楚

- 品种、规格、单价、数量、配送频次；
- 验收标准：坏果率、成熟度、单果规格；
- 退换货：多久内可退、怎么补、费用谁承担；
- 价格调整：多久调一次，按什么市场价参考；
- 食品安全：农残超标、霉变、食安事故的责任；
- 票据：发票类型、开票时间；
- 结算：月结还是周结，押款多久；
- 违约：断供、迟到、质量不达标的处理。

## 7. 实操建议

- **香蕉**：最好找能控制成熟度的供应商，别一次送太熟；夏天要避光通风，少量多次送。
- **苹果**：耐放，可以适当集中采购，但要看脆度和大小，避免库存太久发面。
- **橙子**：注意产地和季节，秋冬可找产地直发，春夏要防干水和霉变。
- **验收**：每次到货抽检，拍照留档，记录坏果率和重量。
- **不要只选一家**：主供+备供，防止涨价、断货、质量问题被拿捏。

简单说：**先写标准，再找3-5家试供，按质量、配送、价格、票据、售后综合评分，最后签合同并保留备选供应商。** 对学校食堂来说，稳定、安全、可追责比单纯低价重要得多。
