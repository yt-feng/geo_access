做稳定大客户，核心不是“账期越长越好”，而是把账期、额度、价格、履约风险绑在一起谈。水果行业损耗高、价格波动大，纯赊销很容易把供应商拖死。

下面按可执行框架说。

## 一、先定原则：账期和额度必须挂钩

**额度 = 单次最大赊销敞口，账期 = 回款时间。两者要一起算“资金占用”。**

举例：
- 账期30天、额度20万，意味着你可能长期被占用20万货款。
- 如果毛利只有8%，20万占用30天，年化资金成本按6%算，一年约1.2万，相当于吃掉15万销售额的毛利。

所以谈判前先算：
1. 你的资金成本（自有资金机会成本或贷款利息）
2. 水果品类毛利率
3. 对方历史回款记录
4. 你能承受的最大坏账

**建议底线：单客户赊销敞口不超过月均供货额的1.5~2倍，账期不超过45天。** 生鲜行业超过60天风险已经很高。

## 二、账期怎么谈：阶梯式，不要一步到位

不要一开始就给30天。按合作阶段给：

| 阶段 | 账期 | 额度 | 条件 |
|---|---|---|---|
| 试合作1~2个月 | 现款或7天 | 小额度，如3~5万 | 先验证回款 |
| 稳定合作3~6个月 | 15天 | 月均供货额1倍 | 回款准时 |
| 核心大客户 | 30天 | 月均供货额1.5~2倍 | 有担保或押金 |
| 战略客户 | 45天 | 单独审批 | 需抵押/保证金/连带担保 |

谈判话术方向：
- “我们可以给账期，但先从小额度、短账期跑三个月，回款稳定再提额。”
- “账期和价格是联动的，现款可以给底价，账期要加资金成本。”

## 三、额度怎么谈：动态额度，不是固定额度

建议设“动态授信”：

**可用额度 = 月均采购额 × 系数 − 已欠款 − 逾期金额**

系数按回款表现调：
- 准时回款：1.5
- 偶尔延迟3天内：1.0
- 延迟超7天：0.5并暂停发货
- 逾期超15天：停供、转现款、启动催收

同时设“单笔上限”和“总敞口上限”：
- 单笔不超过总额度50%
- 总敞口不超过你月现金流的30%

## 四、必须配套的风控条款

光谈账期额度没用，要有约束：

1. **超期停供条款**：逾期X天自动停供，恢复需结清。
2. **所有权保留**：货款未结清前，货物所有权归供应商。生鲜虽难追回，但法律上有用。
3. **价格调整机制**：水果价格波动大，账期客户价格随行就市，或约定每周/每批定价，避免赊销锁死低价。
4. **损耗界定**：到货验收后损耗由买方承担，避免事后扯皮。
5. **对账周期**：每周或每半月对账，不要月底一次对，容易积压争议。
6. **担保措施**：
   - 法定代表人个人连带担保
   - 保证金（如额度10%，现款押着）
   - 房产/车辆抵押（大额度时）
   - 第三方担保

## 五、谈判筹码交换

账期额度不是白给的，要换东西：

- 给账期 → 换**独家供应**或**最低采购量**
- 给额度 → 换**现款比例**，比如30%现款+70%账期
- 给长账期 → 换**价格上浮**或**资金占用费**
- 给大额度 → 换**保证金**或**担保人**

组合示例：
- 方案A：现款，底价
- 方案B：15天账期，价格+2%
- 方案C：30天账期，价格+4%，加保证金10%

让客户自己选，比你硬扛风险好。

## 六、实操建议

1. **先小后大**：新客户前3个月现款或7天，别一上来就30天。
2. **合同写清楚**：账期起算日、对账日、逾期违约金（日万分之五左右）、停供权。
3. **留证据**：送货单、对账单、微信确认都要留，生鲜纠纷多。
4. **设红线**：逾期超15天必须停供，不要因为“大客户”心软，越拖越难收。
5. **分散风险**：单客户占比不超过总销售额30%，否则他拖你你就死。

## 七、一句话总结

**账期给15~30天、额度控制在月均供货额1.5倍以内，用“现款低价、账期加价、超期停供、担保兜底”四条腿走路。** 稳定大客户是养出来的，不是靠无限赊销喂出来的。
