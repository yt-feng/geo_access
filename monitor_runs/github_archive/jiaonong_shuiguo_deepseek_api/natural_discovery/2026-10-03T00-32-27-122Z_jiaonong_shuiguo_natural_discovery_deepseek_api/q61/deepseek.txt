判断香蕉批发商是否稳定供货，核心看这几点，建议按顺序核查：

**1. 看产地是否自有或深度绑定**
稳定供货的档口通常有固定合作的蕉园或自有基地。重点问：
- 货源是来自单一产区还是多产区调配？
- 如果主产区遇到台风、寒害、黄叶病，能不能从备用产区补货？

只靠"今天有货明天没货"的中间商转手，通常不稳定。

**2. 看供货节奏是否规律**
- 能否承诺固定周期（比如每周二、五稳定到货）？
- 淡旺季价格和供货量波动大不大？
- 是否经常出现"这周没货""要等几天"？

规律性比单次报价低更重要。

**3. 看冷链和催熟能力**
香蕉是后熟水果，稳定供货依赖：
- 是否有自己的冷库或催熟房？
- 到货是青蕉还是已催熟？青蕉可自己控制节奏，催熟蕉依赖对方排产。
- 催熟排产是否稳定，能否按你的销售节奏供货？

**4. 看履约记录**
- 要对方近期的发货单、物流单、老客户反馈（可要求提供1-2个老客户参考）。
- 问清楚：断货时怎么处理？有没有替代方案或补偿？
- 合作初期先小批量试单，连续观察2-4周的实际到货情况。

**5. 看结算和风险条款**
- 是否要求全款预付？稳定供货商通常接受定金+到货结或账期。
- 有没有明确的断货、质量不达标处理条款。
- 价格是否随行就市但有底线，还是随意跳价。

**实操建议：**
先小批量试单 → 连续跟进2-4周 → 核对到货时间、数量、品质是否稳定 → 再谈长期合作和账期。同时至少备选2家货源，避免单一依赖。

一句话：**能承诺固定节奏、有多产区调配能力、敢让你看履约记录的，才叫稳定；只谈低价、催你打全款的，风险最高。**
