对餐饮店来说，少量水果的核心痛点不是价格，而是**稳定、省事、损耗低**。所以选供应商的思路，和大量采购完全不同。

**优先考虑这几类，按省心程度排序：**

**1. 本地水果批发市场的固定档口（最推荐）**
- 找一个离家/店近、能固定合作的档口，谈好"每天/隔天送一次，少量也送"。
- 优势：品类全、可随时换品种、价格透明、当天到货新鲜。
- 关键动作：固定一个老板，长期合作后他会帮你留好货、挑熟度合适的。比零散买省心得多。

**2. 生鲜配送平台（如美菜、快驴、当地生鲜B2B）**
- 优势：线上下单、次日达、起送量低、账期和发票规范。
- 劣势：品控参差，水果这种非标品容易踩雷，建议先小量试。
- 适合：完全没有采购人力、想纯线上解决的小店。

**3. 社区水果店 / 连锁水果店合作**
- 优势：就在附近，可电话让老板留货、送货，量小也灵活。
- 劣势：单价略高，品类受店内库存限制。
- 适合：每天就几斤、用量极小的店。

**4. 产地/二级批发商直供（不太适合少量）**
- 除非用量上去，否则起订量、物流、账期都不划算，不建议小店用。

**判断供应商是否"省心"的4个标准：**
1. **能不能少量送**：明确问"每天3斤、5斤送不送"，很多批发商不接。
2. **熟度能不能配合**：餐饮用水果要"当天能用"，太生太熟都浪费。
3. **缺货/换货怎么处理**：旺季断货、品相不好能否当天补换。
4. **结算是否清楚**：日结/周结、能否开发票、称重是否当面或拍照。

**实操建议：**
- 别只找一家，**主供应商 + 备用水果店**双保险，防止断货。
- 先小量试跑1~2周，重点看**到货新鲜度**和**是否有缺斤少两**。
- 把每天要的品种、数量、送达时间固定下来，越规律越省心。
