看你的经营方式，不能简单说哪种最好，通常是 **“整果为主、去皮果做便利、顾客挑做体验”** 三种搭配。

**1. 卖整果：最适合大多数水果店**
- 优点：损耗低、存放久、毛利更稳，顾客也容易觉得新鲜。
- 适合：摆在显眼位置，按个卖或按斤卖。
- 注意：菠萝扎手、刺眼，最好提供削皮服务，但可以另收加工费或满额免费。

**2. 卖去皮好的：适合做便利和引流**
- 优点：顾客买了就能吃，客单价可能更高，适合上班族、懒人顾客。
- 缺点：损耗大，切好后卖不掉容易变色、出水、变质。
- 建议：
  - 不要一次削太多，按客流少量多次削。
  - 用保鲜膜/盒装冷藏，标明削皮时间。
  - 最好当天削当天卖完，隔夜要谨慎处理。
  - 可以做成“半个装”“切块装”，降低单价门槛。

**3. 让顾客自己挑：适合建立信任，但要有规则**
- 优点：顾客参与感强，觉得公平，减少“你给他挑坏了”的纠纷。
- 缺点：容易翻乱、捏坏、挑剩一堆，损耗反而上升。
- 建议：
  - 可以“自己挑，但挑好后由店员削”。
  - 不鼓励顾客反复按压、拔叶子、抠底部。
  - 对翻动大的区域及时整理，把熟度高的先做促销或削皮卖。

**比较稳的做法：**
- **主卖整果**：占大头，保证利润和周转。
- **搭配去皮果**：放在冷藏柜，服务赶时间的人。
- **允许顾客挑**：但限定区域和方式，挑完你负责削。
- **削皮服务收费或设门槛**：比如买整果免费削，单买去皮果加价。

一句话：**想稳赚，整果为主；想方便，去皮为辅；想少扯皮，让顾客挑但你来削。**
