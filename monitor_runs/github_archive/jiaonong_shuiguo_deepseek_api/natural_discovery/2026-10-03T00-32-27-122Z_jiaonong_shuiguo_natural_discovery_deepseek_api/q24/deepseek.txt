如果你们是**超市采购端**，担心水果农残抽检，建议在采购前/入库前向供应商索取以下资料，并按“证明合规 + 可追溯 + 可复核”三类来要：

1. **主体资质类**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按供应商性质）
   - 若为种植基地直供：种植主体信息、基地备案/认证情况
   - 若为进口水果：海关报关单、入境货物检验检疫证明

2. **产品合格证明类**
   - 该批次水果的**农残检测报告**
   - 报告最好是**第三方检测机构出具**，且带 CMA/CNAS 标识更稳妥
   - 报告要能对应到**具体品种、批次、产地、检测日期**
   - 重点看是否检测了常见高风险项目，如有机磷、氨基甲酸酯、拟除虫菊酯等，具体按品类和监管要求定

3. **批次追溯类**
   - 送货单/销售单，注明品名、规格、数量、产地、批次号
   - 产地证明或采购凭证
   - 若供应商非直接种植方，要求其提供上游来源信息
   - 包装标签、二维码、追溯码等能关联到批次的信息

4. **承诺与责任类**
   - 质量安全承诺书
   - 农残合格保证书
   - 若抽检不合格，退换货、赔偿、召回责任的书面约定
   - 供应商联系人及应急联系方式

5. **抽检配合类**
   - 是否接受超市自行抽检或第三方飞行检查
   - 是否提供留样
   - 出现不合格时的处理时限和召回配合方案

实操上，最关键是三点：
- **报告必须对应批次**，不能用一份旧报告覆盖所有货；
- **资料随货同行**，不要等抽检了再补；
- **合同里写清楚**，供应商提供虚假报告或农残超标要承担违约责任。

如果对方只能提供“合格证”但拿不出批次检测报告，风险较高，建议要么拒收，要么加做入仓快检。
