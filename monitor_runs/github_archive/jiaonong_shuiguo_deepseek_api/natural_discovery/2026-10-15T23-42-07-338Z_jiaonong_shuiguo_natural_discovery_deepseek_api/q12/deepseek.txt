水果店卖菠萝，损耗主要来自“过熟烂掉”和“生果卖相差/口感差”两头。采购时建议按**销售节奏**来定熟度，而不是只挑最熟或最生。

**1. 先定采购熟度比例**
- 如果当天到货、当天到次日卖完：可采**7～8成熟**，一部分**8～9成熟**用于现场试吃、即买即吃。
- 如果周转要2～3天：主采**6～7成熟**，少量**8成熟**。
- 如果做外卖/切果盒：可要**8～9成熟**，但必须冷链、当天处理。
- 如果门店只能常温放：尽量控制在**7成熟左右**，避免一车全是熟果。

**2. 判断菠萝熟度的实用方法**
- **看果皮**：青绿转黄、底色由青转黄绿，通常开始成熟；全青偏生，全黄偏熟。金菠萝、香水菠萝等品种本身偏青也可能可食，要结合品种。
- **看果眼**：果眼变平、间距显得开，成熟度较高；果眼尖、紧密，偏生。
- **闻底部**：菠萝底部香气明显、甜香足，通常较熟；无味偏生，酒味/发酵味说明过熟。
- **按压果身**：轻按有弹性、不硬得像石头，成熟适中；一按就软陷，过熟。
- **看叶片**：冠芽青绿挺立较新鲜；叶片枯黄、基部发黑，存放偏久。
- **掂重量**：同样大小，手感重的水分足；但过熟有时也重，要结合香气和按压。
- **看切口/底部**：底部发黑、渗汁、霉点，直接不要。

**3. 采购现场怎么操作**
- 不要整批一个熟度。建议：**60%～70% 6～7成熟，20%～30% 8成熟，10% 9成熟**，根据你店销量调整。
- 按“先熟先卖”分区：熟果放前排、做试吃、切盒、促销；生果放后排或阴凉处后熟。
- 问清产地采摘时间和运输天数。运输久、天气热，实际熟度会比看着高。
- 夏季高温、门店无冷柜，采购熟度整体降半级到一级。
- 冬季或空调房，可适当提高熟度，减少后熟等待。

**4. 降低损耗的配套做法**
- 到货后立刻分级：熟、中、生分开。
- 熟果当天做试吃、切果盒、特价，不要等。
- 中生果常温阴凉通风，别堆太厚，避免压伤。
- 切开的菠萝必须冷藏，尽量当天售完。
- 记录每天销量和报废量，连续记1～2周，就能算出适合你店的采购熟度比例。

简单说：**主采6～7成熟，搭配少量8～9成熟，按销量和天气调整；现场看颜色、闻底部、按弹性、看果眼和底部状态。**
