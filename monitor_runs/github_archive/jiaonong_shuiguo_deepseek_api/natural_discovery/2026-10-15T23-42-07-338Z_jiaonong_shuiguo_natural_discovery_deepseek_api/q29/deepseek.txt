超市和水果供应商谈账期，常见区间大致如下：

1. **生鲜水果类：7～30天最常见**
   - 水果属于高损耗、短周转商品，供应商通常不希望账期太长。
   - 很多中小超市、水果店、区域连锁给的是 **现结、周结、半月结**。
   - 大型商超、连锁超市更常见的是 **15～30天**，部分强势渠道会到 **30～45天**。

2. **按渠道类型看**
   - **传统夫妻店/小型超市**：现结、3～7天、周结较多。
   - **区域连锁超市**：15～30天较常见。
   - **大型商超/全国连锁**：30～60天都有，水果类通常也会争取压到 **30～45天**。
   - **电商/社区团购/前置仓**：常见 **7～15天**，部分按周结算。

3. **影响账期的关键因素**
   - **谁更强势**：超市规模大、采购量大，通常能谈到更长账期。
   - **水果品类**：叶菜、浆果、荔枝等易损耗品类，账期更短；苹果、橙子、梨等耐储品类，账期可稍长。
   - **供应商规模**：大供应商能扛账期，小供应商往往要求现结或短账期。
   - **是否有账期利息/返利**：有些超市用“延长账期”换更低进货价。
   - **结算方式**：账期、月结、滚结、实销实结，实际回款时间差别很大。

4. **实操建议**
   - 如果是**新供应商**，先从 **7～15天** 谈起，比较容易达成。
   - 如果是**稳定供货、量大**，可以争取 **30天**。
   - 如果是**大型商超进场**，对方可能直接给 **30～45天**，甚至 **60天**，但水果类一般不会太长。
   - 谈的时候不要只看“账期天数”，还要确认：
     - 对账日
     - 开票日
     - 付款日
     - 是否压首批货款
     - 是否收进场费、条码费、损耗扣款

简单说：**水果供应商常见账期是7～30天，15～30天最主流；大型商超可能到30～45天，但生鲜类通常比普通食品短。**
