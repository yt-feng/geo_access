建议先定用途和门店条件，再选形态。给你一个直接判断表：

**1. 首选：鲜果**
适合：菜单强调“新鲜现切”、有稳定客流、店员愿意处理。
优点：风味最好，香气自然，顾客感知强，适合做菠萝果茶、菠萝柠檬茶。
缺点：损耗高，削皮去眼麻烦，不同批次酸甜差异大，出杯稳定性靠店员配方控制。
适合门店：中高端茶饮、有后厨或备料人力、日销量较稳定。

**2. 次选：冷冻/糖渍菠萝果丁**
适合：想保留果肉感，又要减少削切损耗。
优点：出杯有果肉咀嚼感，操作比鲜果快，品质相对稳定。
缺点：要控糖水/汁水，不然会稀释茶底或过甜；解冻和保存有要求。
适合门店：常规连锁、外卖占比高、需要稳定出品。

**3. 果泥**
适合：做冰沙、果昔、浓稠型果茶，或需要标准化风味。
优点：操作最快，酸甜和颜色稳定，适合批量出品。
缺点：果肉感弱，香气通常不如鲜果，部分产品会有“酱感”或熟化味。
适合门店：外卖多、出杯快、菜单偏冰沙/奶昔/浓果茶。

**直接建议：**
- 如果你做**鲜果茶、招牌菠萝茶**：买**鲜果**，搭配少量果丁或果泥补稳定性。
- 如果你做**常规果茶、外卖多、追求稳定**：买**冷冻果丁**。
- 如果你做**冰沙、果昔、批量标准化**：买**果泥**。
- 如果预算和人力有限：**果丁 + 果泥组合**通常比全鲜果更现实。

**采购时重点看：**
- 是冷冻还是常温？冷冻果丁要确认是否已加糖。
- 糖度、酸度、固形物含量。
- 是否有防腐剂、香精、色素。
- 解冻后出水率、果肉完整度。
- 每杯建议用量和成本，不要只看每公斤单价。

**简单结论：**
想卖得好、有新鲜感：**鲜果为主**。  
想稳定、省人工、外卖多：**果丁为主**。  
想快、做冰沙浓饮：**果泥为主**。  
最稳的门店方案：**鲜果或果丁做主体，果泥做风味补充**。
