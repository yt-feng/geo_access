核实水果供应商的“全国配送”能力，不能只听口头承诺。建议采购方按以下顺序做可验证的核查：

1. **先拆解“全国配送”的定义**
   - 问清楚：是常温干线配送、冷链配送，还是只发快递？
   - 覆盖范围：是全部省份、地级市，还是只到部分城市？
   - 时效：下单后多久发货、多久到店/到仓？
   - 温控：水果是否需要冷链，全程温控还是只加冰袋？
   - 起送量：单次最低多少件/多少公斤才配送？
   - 偏远地区：新疆、西藏、青海、内蒙古、海南等是否加价或不到？

2. **要求提供可核验的配送网络证据**
   - 仓库/中转仓清单：地址、面积、冷藏库容量、所在城市。
   - 合作物流合同或合作证明：顺丰、京东、中通冷链、当地冷链车队等。
   - 冷链车辆清单：数量、车型、温控记录方式。
   - 配送系统后台截图：能显示覆盖城市、线路、时效的界面。
   - 注意：截图可以伪造，所以要结合合同、发票、现场核查。

3. **做“盲测”或小批量试单**
   - 选几个有代表性的目的地：一线城市、省会、地级市、偏远地区。
   - 同时下单，记录：接单时间、发货时间、到达时间、包装温度、损耗率。
   - 试单量不用大，但目的地要分散，最好包含你未来真正要覆盖的区域。
   - 试单时不要提前告知具体考核点，避免对方临时安排。

4. **核查实际到货质量，而不只是“能到”**
   - 水果配送的核心是损耗和新鲜度。
   - 记录：到货温度、果温、外观、压伤、腐烂比例、重量是否足。
   - 对比承诺时效：延迟多久、是否影响销售。
   - 如果对方说“全程冷链”，要求提供温度记录仪数据或车载温控记录。

5. **核实售后和异常处理能力**
   - 偏远地区出问题怎么赔？
   - 延误、腐烂、丢件谁承担？
   - 是否有当地售后人员或只能电话客服？
   - 退换货流程多久能走完？
   - 这些要写进合同，不能只靠口头承诺。

6. **查工商和履约风险**
   - 用国家企业信用信息公示系统、天眼查/企查查等查：成立时间、注册资本、行政处罚、司法纠纷、经营异常。
   - 重点看：是否有运输合同纠纷、买卖合同纠纷、被执行记录。
   - 如果对方是中间商，还要查它实际合作的一级物流或产地供应商。

7. **要求提供真实客户案例并回访**
   - 让对方给 2—3 个现有客户，最好和你品类、区域相近。
   - 直接问客户：实际覆盖哪些城市、时效如何、损耗多少、售后是否及时。
   - 注意：对方可能只给关系好的客户，所以最好自己再找行业内的其他采购同行交叉验证。

8. **合同里写清楚可考核条款**
   - 配送范围：具体到省/市/区，或明确“不到区域需提前书面确认”。
   - 时效标准：发货时限、到达时限、延误赔偿。
   - 温控标准：运输温度区间、是否全程冷链、温度记录提供方式。
   - 损耗标准：正常损耗率、超标赔偿。
   - 异常处理：响应时间、赔付时限。
   - 试单考核：先小批量试运行，达标后再放量。

**最有效的组合是：**
先问清定义 → 要网络证据 → 做多目的地盲测试单 → 回访真实客户 → 合同写考核条款。

如果对方只能提供“快递单号能到”，但说不出冷链、时效、损耗和售后，那“全国配送”基本只是快递覆盖，不等于水果供应链配送能力。
