判断水果供应商靠不靠谱，香蕉和菠萝这种长期进货的品类，核心看三件事：**货稳不稳、价实不实、人赔不赔**。你可以按下面这套方法去筛。

**一、先看硬指标**

1. **能不能稳定供货**
   问他：一周能固定给你多少件？旺季、台风季、节假日能不能保证？香蕉和菠萝都有明显产季和天气风险，靠谱的供应商会提前告诉你“下周产地下雨，到货会少/熟度不稳”，而不是等你催。

2. **有没有稳定产地和加工能力**
   香蕉看催熟房。靠谱供应商通常有自己的催熟库，能按你要的熟度发货。没有催熟能力的，多半是倒手，价格和品质都不稳。
   菠萝看产地和分选。问他是广东徐闻、海南、云南还是菲律宾/泰国货，能不能按规格分选，比如同等大小、成熟度一致。

3. **损耗怎么算**
   直接问：坏果、烂果、黑心菠萝、青香蕉催不熟，怎么赔？靠谱的会给明确标准，比如到货24小时内拍照，按件赔或下批补。只口头说“放心”但不写规则的，要谨慎。

**二、用三次小批量试单验证**

不要一上来就大额长期合作，先做三次试单：

- 第一次：少量拿货，看准时率、外观、熟度。
- 第二次：故意要一个偏紧的到货时间，看他能不能配合。
- 第三次：出现小问题时，看他处理速度。比如香蕉到货太青、菠萝有黑心，看他是否认账、多久补。

三次都稳定，再谈长期价和账期。

**三、现场或视频看几个关键点**

- 香蕉：催熟房温度记录、蕉条均匀度、有没有大量青硬蕉或过熟黑斑蕉。
- 菠萝：切口是否新鲜、果眼深浅、有没有异味、底部是否发霉。
- 仓库：分拣区干不干净，有没有把烂果混装。烂果混装是典型不靠谱信号。
- 物流：夏天有没有冷藏车或通风车，冬天有没有防冻。香蕉怕冻，菠萝怕闷。

**四、价格和账期怎么判断**

- 不要只比单价。算“到货可用率”：比如100斤里有85斤能卖，和90斤能卖，成本差很多。
- 问清楚是否含运费、卸货费、损耗赔付。
- 账期方面，新供应商建议现结或短账期。一上来就给你很长账期，不一定靠谱，可能是拿你的量去压上游，资金链反而危险。
- 如果报价长期明显低于市场，要警惕：可能是次果、催熟过度、产地尾货，或者后面要涨回来。

**五、几个危险信号**

- 只说“绝对没问题”，不让你看仓库或催熟房。
- 每次到货规格都不一样，大小、熟度全靠运气。
- 出问题就推给物流或产地，自己不承担。
- 催你大量囤货，说“下周一定涨价”。
- 没有固定电话或经营地址，只靠微信随时换号。

**六、最实用的合作方式**

先签一个简单供货协议，哪怕只是一页纸，写清：
- 品类、规格、熟度要求；
- 每周大致数量；
- 价格随行就市还是锁价几天；
- 损耗赔付标准；
- 到货时间和验收方式；
- 出问题多久内响应。

香蕉和菠萝长期做，建议至少备两个供应商，一个主供、一个备用。主供占70%，备用占30%。这样一家出问题，你店里的货架不会空。

一句话：**能让你看现场、敢小批量试、出问题肯赔、旺季不消失的，才值得长期合作。**
