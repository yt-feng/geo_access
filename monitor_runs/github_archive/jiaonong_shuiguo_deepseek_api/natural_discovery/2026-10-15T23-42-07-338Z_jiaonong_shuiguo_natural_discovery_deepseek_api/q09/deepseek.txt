水果店旺季最怕的不是价格高，而是该有货的时候没货、送来的货不对版。和供应商谈之前，先把下面几类问题问透，比单纯压价更重要。

**一、保供能力**
1. 旺季你一天最多能给我供多少量？如果我临时加量30%～50%，提前几小时说能安排？
2. 你主要从哪个产区/批发市场上货？那个产区旺季时会不会也紧张？
3. 如果某个单品断货，你有没有替代货源或替代品种推荐？
4. 节假日、极端天气、物流停运时，你一般怎么处理？

**二、价格与结算**
5. 报价是含税含运费吗？送到店还是自提？
6. 旺季价格怎么浮动？是随行就市，还是可以锁一个区间？
7. 量大有没有阶梯价？长期合作有没有返点或账期？
8. 付款方式：现结、周结还是月结？押金或保证金要不要？

**三、品质与验收**
9. 等级怎么分？大中小果比例大概多少？允许的坏果率是多少？
10. 样品能不能先发一箱？以后大货和样品不一致怎么办？
11. 到货后多久内可以提出质量异议？坏果、烂果、次果怎么赔、怎么补？
12. 包装规格是多少？毛重还是净重？箱皮、托盘算不算重量？

**四、配送与时效**
13. 每天几点前下单、几点送到？能不能固定时间段？
14. 临时补货、加急送怎么收费？起送量是多少？
15. 运输是冷链还是普通车？夏天高温怎么保证不坏？
16. 送货司机能不能配合卸货、清点、签字确认？

**五、售后与责任**
17. 货不对版、短斤少两、迟到影响销售，怎么赔付？
18. 出现食品安全或农残问题，责任怎么划分？你有没有检测报告？
19. 退换货流程是什么？多久内处理完？

**六、合作稳定性**
20. 你同时给哪些店供货？旺季会不会优先保大客户，把我排后面？
21. 能不能签旺季保供协议，把供货量、价格区间、违约赔偿写进去？
22. 如果合作不顺，提前多久通知可以终止？有没有捆绑采购要求？

**谈的时候重点抓三件事：**
- **保供承诺写进合同**：口头说“没问题”不算，要写明旺季每日最低供应量、加量响应时间、断货赔偿。
- **先试单再放量**：旺季前先小批量试2～3次，看品质、时效、售后是否稳定。
- **留备选供应商**：主力供应商之外，至少再谈1～2家备用，哪怕价格略高，关键时刻能救急。

一句话：旺季合作，先保“有货、对版、能赔”，再谈“便宜”。
