要减少香蕉放坏，采购时核心是 **“按销售速度分批次控熟度 + 控制到货节奏”**，不要一次全进同一熟度。具体可以这样要求：

1. **按预估销量分批要不同熟度**
   - **当天到货就能卖的部分**：要 **3～4 成熟**，青黄色、手感硬，适合再放 2～4 天。
   - **2～3 天内主推的部分**：要 **4～5 成熟**，黄中带绿，适合 1～2 天进入最佳销售期。
   - **当天就要促销/特价的部分**：要 **6～7 成熟**，大面积转黄、少量糖斑，适合当天或次日卖完。
   - 不建议水果店常规采购 **8 成熟以上**，除非当天有明确促销或加工用途，否则损耗会很高。

2. **明确到货时间要求**
   - 最好要求 **早上开市前到货**，这样当天能挑拣、分级、上架，坏的能及时处理。
   - 避免 **下午晚到或闭店前到货**，因为香蕉在运输箱里继续升温催熟，到第二天可能直接过熟。
   - 如果供应商只能下午送，要求 **冷藏车或控温运输**，并尽量缩短在店外停留时间。

3. **要求供应商控温运输和分装**
   - 香蕉运输适宜温度大致在 **13～15℃**，不要低于 12℃，也不要长时间高于 20℃。
   - 要求 **按熟度分箱、分批次装**，箱外标注到货熟度和建议销售顺序。
   - 不要用完全密封、不透气的包装长期闷着，最好有通风孔，减少催熟过快。

4. **采购时写清验收标准**
   - 青香蕉：果皮青绿、棱角明显、手感硬，无黑斑、无软烂。
   - 转黄香蕉：黄中带绿，果柄不干枯，果指饱满，无大面积压伤。
   - 熟香蕉：黄色均匀，允许少量糖斑，但不能有酸味、酒味、流水、黑腐。
   - 到货后立即抽检：**摸硬度、看棱角、闻有无酒味**。有酒味说明已经开始过熟。

5. **按“少量多次”下单**
   - 香蕉损耗主要来自一次进太多、熟度太集中。
   - 建议把一周采购拆成 **2～3 次**，每次按未来 1～2 天销量下单。
   - 如果某批已经偏熟，优先上堆头、做特价、切果盒或做香蕉奶昔等加工品，不要继续压在箱里。

简单说，采购时可以直接对供应商说：

> “我要分三档：3～4成熟一批，4～5成熟一批，6成熟少量当天促销用；全部早上到货，控温13～15℃，按熟度分箱标注。不要全给同一熟度，也不要下午晚到。”

这样做的目的是让店里始终有 **青的能放、黄的能卖、熟的快清**，而不是所有香蕉同一天一起熟、一起坏。
