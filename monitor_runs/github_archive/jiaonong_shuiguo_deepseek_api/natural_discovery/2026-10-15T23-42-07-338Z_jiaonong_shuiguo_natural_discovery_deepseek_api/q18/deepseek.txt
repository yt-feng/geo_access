要在超市买到“到家刚好能按计划吃”的香蕉，核心是：**按你准备吃的时间，选不同成熟度，而不是只看黄不黄。**

### 1）先定“什么时候吃”
- **今天/明天就吃**：选**通体黄、少量棕色斑点**的。
- **2～3天后吃**：选**黄中带一点绿**，尤其是两端还略绿的。
- **4～5天后吃**：选**明显偏绿、但已经饱满**的。
- **想放一周左右**：选**绿硬**的，回家常温催熟。

### 2）到店怎么判断
- **看颜色**：  
  - 全绿：很生，通常还要几天。  
  - 绿黄相间：适合过几天吃。  
  - 全黄：基本马上能吃。  
  - 黄带黑斑：最甜，但只能当天到第二天吃。
- **看果柄和两端**：  
  - 果柄青绿、切口新鲜：通常更耐放。  
  - 果柄发黑、发干：熟得快，甚至可能已经过熟。
- **轻捏中部**：  
  - 硬：生。  
  - 稍有弹性：刚好。  
  - 一按就软：熟透，尽快吃。
- **看棱角**：  
  - 棱角分明：偏生。  
  - 圆润饱满：成熟度高。
- **闻味道**：  
  - 有淡淡香蕉香：可以吃。  
  - 酒味、酸味：已经过熟或开始坏。

### 3）最实用的买法
- **不要只买同一成熟度**：  
  买一把“黄中带绿”的，再买2～3根“全黄带点斑”的。这样今天有得吃，过几天也有得吃。
- **如果超市只有很生的**：  
  可以买，回家和**苹果或熟香蕉**放同一个纸袋里，能加快催熟。
- **如果已经太熟**：  
  当天吃、做奶昔、香蕉面包，或去皮冷冻。
- **如果买多了**：  
  熟到刚好时，把其中一部分放冰箱冷藏。冷藏后皮会变黑，但果肉能多撑几天。

### 4）回家后怎么放
- **没熟**：常温、通风，别进冰箱。  
- **刚熟**：常温放1～2天。  
- **熟透**：冷藏或冷冻。  
- **别和苹果、梨长期放一起**：它们会释放乙烯，让香蕉更快熟。

一句话：**今天吃选黄带斑，过两天吃选黄带绿，过几天吃选绿硬；想稳一点就混着买。**
