水果采购合同里，**法律上没有统一的“坏果率超过多少必须赔付”标准**，关键看合同约定、验收方式和货物用途。实务上可以这样判断：

1. **合同有约定的，按合同**
   - 如果合同写了“坏果率≤3%”“超过5%可拒收”“超过约定比例按比例扣款/赔偿”，就按约定执行。
   - 所以签合同时最好明确：  
     - 坏果率计算方式：按个数、重量还是件数  
     - 验收时间：到货后几小时内  
     - 抽检比例：全部检还是抽检  
     - 处理方式：扣款、补货、退货、赔偿

2. **合同没约定时，常见行业参考**
   - **鲜果批发/采购**：坏果率超过 **3%—5%**，通常就可以提出扣款、补货或索赔。
   - **商超/电商发货标准**：往往更严，超过 **2%—3%** 就可能要求赔付或拒收。
   - **加工用果**：如果用于榨汁、果酱等，容忍度可能高一些，超过 **5%—10%** 才较常见地主张赔付。
   - 这些不是法定标准，只是实务参考，最终仍看合同和证据。

3. **更稳妥的写法**
   可以在合同里约定：
   - 坏果率≤3%：正常验收；
   - 3%＜坏果率≤5%：按坏果重量/金额扣款；
   - 坏果率＞5%：买方有权拒收、要求补货或退货；
   - 坏果率＞10%：视为根本违约，可解除合同并索赔；
   - 因坏果导致的运费、分拣费、损耗等由卖方承担。

4. **注意**
   - 如果坏果是运输途中造成的，要看合同约定的交货方式和风险转移点。  
   - 如果是买方储存不当导致，通常不能要求卖方赔。  
   - 发现坏果后要**及时拍照、录像、保留称重和验收记录**，否则后续索赔容易扯皮。

**建议：**  
不要只问“超过多少赔”，而应在合同里直接写明：**坏果率标准、验收期限、计算方式、赔付比例和拒收条件**。  
如果对方不写，至少争取写：**坏果率超过5%按实际坏果金额扣款，超过10%可拒收并索赔。**
