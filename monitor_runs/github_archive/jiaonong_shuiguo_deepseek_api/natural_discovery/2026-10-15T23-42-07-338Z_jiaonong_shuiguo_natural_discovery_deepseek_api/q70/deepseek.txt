批发商要防“货到损耗高、坏果扯皮”，合同里不能只写一句“坏果由卖方负责”，要把**验收时点、标准、比例、举证、扣款/补货、拒收**写清楚。建议按下面结构写：

1. **明确质量标准和允许损耗**
   - 写明品种、等级、规格、成熟度、单果重量/直径、糖度/硬度（如适用）、包装方式。
   - 区分“自然失水/轻微机械伤”与“腐烂、发霉、破裂、冻伤、压烂、异味”等坏果。
   - 约定一个**合理允许损耗率**，例如到货抽检坏果率不超过3%—5%视为合格；超过部分由供货方承担。具体比例按品类和运输距离定，不要照搬。

2. **明确风险转移和验收时点**
   - 关键写法：**“货物到达买方指定卸货地点并完成开箱抽检前，风险由卖方承担；验收合格后风险转移。”**
   - 如果必须货到即签收，要加一句：**“签收仅代表收到货物，不代表认可质量；买方有权在签收后X小时内开箱验收。”**
   - 约定验收期限，例如到货后4小时/8小时/24小时内完成，逾期未提异议视为合格，但隐蔽瑕疵除外。

3. **明确抽检和定损规则**
   - 约定抽检比例，例如按件数抽5%—10%，或按重量抽检。
   - 写明定损方式：按坏果重量/件数占比计算，还是按整批折价。
   - 建议写：**“抽检不合格的，按抽检坏果比例推算整批坏果比例；双方对抽检结果有异议的，可共同委托第三方检测，费用由责任方承担。”**

4. **明确责任承担方式**
   - 可组合写：
     - 超过允许损耗率的部分，卖方按**坏果对应货款的X倍**赔偿；
     - 或卖方**免费补发**同等数量合格货物；
     - 或买方有权**直接扣减相应货款**；
     - 坏果率超过**X%**，买方有权**拒收整批**，卖方承担退货运费、装卸费和买方合理损失。
   - 注意：扣款、补货、拒收最好设不同档位，避免一律拒收导致纠纷。

5. **明确举证和通知**
   - 买方发现坏果后，应在约定时间内通知卖方，并提供照片、视频、过磅单、抽检记录。
   - 卖方应在收到通知后X小时内回复并处理，逾期视为认可买方定损结果。
   - 双方可约定保留样品，必要时送检。

6. **明确运输和包装责任**
   - 如果卖方负责运输：运输途中因温度、通风、挤压造成的坏果由卖方承担。
   - 如果买方自提或指定物流：要写清装车时质量确认方式，以及运输环节责任归属。
   - 包装不符合约定导致损耗的，由包装责任方承担。

7. **建议直接写入合同的条款示例**

> 1. 卖方交付的货物应符合本合同约定的品种、等级、规格及质量要求。坏果包括腐烂、发霉、破裂、冻伤、压烂、异味等不符合食用或销售标准的情形。
> 2. 货物到达买方指定地点后，买方应在____小时内开箱抽检。抽检比例不低于____%。抽检坏果率不超过____%的，视为合格；超过部分由卖方负责。
> 3. 签收不代表买方认可质量。买方在约定验收期内提出异议的，卖方应承担相应责任。
> 4. 坏果率超过允许比例的，买方有权选择：按坏果对应货款____倍扣减；要求卖方补发合格货物；或对超过____%的部分拒收。拒收产生的运费、装卸费及合理损失由卖方承担。
> 5. 双方对坏果比例有争议的，可共同委托第三方检测机构检测，检测费用由责任方承担。
> 6. 卖方应在收到买方异议通知后____小时内处理，逾期未处理视为认可买方提供的抽检和定损结果。

最后提醒：坏果责任条款要配合**采购订单、物流单、验收单、照片视频**一起用。合同写得再细，如果没有到货抽检记录，后面也很难扣款。建议把“允许损耗率”和“超标处理方式”作为谈判重点，而不是只写“坏果包赔”。
