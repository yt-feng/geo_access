如果只能选一个核心指标，应该优先关注**切果损耗**。但实际经营中要按这个顺序看：

**1. 切果损耗（最优先）**
超市卖菠萝通常不是整颗卖，而是去皮、切块、串签、装盒。损耗直接决定毛利。

要重点看：
- 去皮去眼后净重剩多少
- 黑心、水心、烂心比例
- 切出来后当天卖不掉会报废多少
- 员工削切效率

一颗菠萝进价再便宜，如果削完只剩一半，或者黑心多，实际成本会非常高。甜度和外观再好，损耗大也难赚钱。

**2. 甜度**
甜度决定复购。超市切果是即食消费，顾客买一次不甜，下次就不买了。
但甜度不能只靠嘴尝，最好要求供应商提供批次糖度参考，或者到货抽测。一般鲜食菠萝可溶性固形物在 12% 以上较好，具体看品种。

**3. 外观**
外观影响整颗销售和陈列吸引力。
- 果形端正、冠芽新鲜、无大面积黑斑
- 表皮金黄或品种对应成熟色
- 无软塌、渗汁、霉点

但外观好不等于内里好，菠萝容易出现“外好内坏”，所以不能只看外观。

**4. 大小**
大小主要影响定价和切果规格。
- 太大：单颗价高，顾客犹豫；切盒分量不好控
- 太小：出肉率低，削切人工摊薄不了
- 均匀度差：陈列乱，标准化难

所以大小不是第一指标，但要稳定。做切果最好选大小适中、出肉率稳定的规格。

**实际采购判断顺序：**
1. 先看批次切果损耗和黑心率
2. 再抽测甜度
3. 再看外观和成熟度
4. 最后看大小是否适合你的售价和切盒标准

**一句话结论：**
超市卖菠萝，**切果损耗决定赚不赚钱，甜度决定回不回头，外观决定好不好卖，大小决定好不好定价**。如果只能盯一个，盯损耗。
