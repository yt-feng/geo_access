**主要影响：**
1. **价格卖不上去**：大小不匀的香蕉如果按整箱或整把卖，顾客会觉得"花钱买了一堆小的"，压价或挑拣。
2. **损耗增加**：大香蕉熟得快、小香蕉熟得慢，同一箱里成熟度不同步，容易一部分先坏。
3. **分级困难**：散卖时顾客会挑大的，小的剩下来更难出手。

**但可以化解，关键看你怎么卖：**

- **散卖/按根卖**：大小混装反而问题不大，顾客各取所需，小的便宜点也能走量。
- **做分级销售**：大果、中果、小果分开定价，比整箱混卖利润更高。
- **整箱批发给下游**（如奶茶店、食堂、果汁店）：他们通常不在意大小，只在意重量和成熟度，反而好出手。
- **加工用途**：走榨汁、做香蕉干、烘焙的渠道，大小完全不敏感。

**采购建议：**
- 如果顾客对品相敏感（社区精品水果店），尽量采购规格整齐的，宁可单价高一点。
- 如果走量、做促销或供餐饮渠道，混装低价拿货更划算。
- 拿货时问清产地分拣标准，一般按"每根重量/每把根数"分级，选和你销售方式匹配的等级。

一句话：**大小不匀不是致命问题，致命的是拿混装货却按精品价卖。** 匹配好渠道和定价，混装照样能赚钱。
