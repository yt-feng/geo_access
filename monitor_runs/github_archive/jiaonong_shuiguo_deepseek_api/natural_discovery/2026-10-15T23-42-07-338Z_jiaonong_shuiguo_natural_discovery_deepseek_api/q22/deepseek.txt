可以按“**高频带低频、低毛利带高毛利、重量组合提客单**”来做，核心不是单纯降价，而是让顾客从“买一样”变成“买一篮”。

### 1. 组合策略：做3档，而不是1个套餐

**A. 引流款：香蕉 + 苹果**
- 香蕉是高频、价格敏感、决策快；苹果是家庭常购、耐放。
- 做法：**香蕉1把 + 苹果3个/1袋**，定价略低于单买合计，但设置“任选搭配”。
- 目的：提高购买件数，客单从“只买香蕉”变成“香蕉+苹果”。

**B. 利润款：菠萝 + 苹果**
- 菠萝单价高、毛利空间通常更好，但处理麻烦、购买频次低；苹果能中和决策压力。
- 做法：**菠萝1个 + 苹果1袋**，主打“周末果盘/家庭分享”。
- 可提供付费或免费削皮服务，削皮后溢价更容易被接受。

**C. 高客单款：香蕉 + 菠萝 + 苹果**
- 做法：**三件组合装**，例如“早餐果篮”“一周水果包”。
- 定价建议：单买合计约 **30元**，组合价 **25.9—27.9元**，让顾客感觉省3—5元，但实际客单明显高于只买香蕉。
- 陈列上放在一起，标“组合更划算”，不要只标单品价。

### 2. 具体促销玩法

**玩法1：第二件半价/加价购**
- 买香蕉1把，加 **3.9元** 换购苹果3个；加 **6.9元** 换购菠萝1个。
- 比直接打折好，因为能控制让利幅度，还能清库存。

**玩法2：满额升级**
- 买任意水果满 **15元**，加 **2元** 换购香蕉1把；
- 满 **25元**，加 **5元** 换购菠萝半个或小菠萝1个。
- 目的是把原本10元左右的客单推到20元以上。

**玩法3：场景化组合**
- “早餐组合”：香蕉 + 苹果，适合上班族。
- “周末果盘”：菠萝 + 苹果 + 香蕉，适合家庭。
- “减脂轻食”：苹果 + 菠萝，突出清爽。
- 场景命名比“特价组合”更容易提升客单。

**玩法4：称重组合，不固定个数**
- 比如“香蕉2斤 + 苹果2斤 + 菠萝1个，组合价XX元”。
- 适合水果价格波动大的超市，避免固定个数导致毛利失控。

### 3. 陈列和话术

- 三个品项相邻陈列，不要分散。
- 价签写清楚：
  - 单买合计：XX元
  - 组合价：XX元
  - 立省：X元
- 话术用“搭配买更划算”“一个组合够全家吃3天”，不要只说“便宜”。
- 香蕉可放最外侧引流，菠萝和苹果放在组合区内侧，动线自然带到高客单商品。

### 4. 关键控制点

- **毛利**：组合价不能低于三者加权毛利的底线，建议整体毛利不低于单卖的80%。
- **损耗**：香蕉易熟，组合里香蕉比例不要过高，避免顾客因香蕉熟度放弃整组。
- **库存**：菠萝和苹果库存大时，加大组合力度；香蕉库存大时，做加价购引流。
- **测试**：先做7天，看三个指标：
  1. 客单价是否提升；
  2. 组合购买占比；
  3. 三者总销量和损耗是否同步改善。
- 如果组合价降太多但客单没涨，就改成“加价购”而不是直接套餐降价。

### 5. 推荐先落地的方案

**主推：香蕉1把 + 苹果1袋 + 菠萝1个 = 组合价25.9元**
- 单买约30元，立省4元左右。
- 同时设：
  - 买组合加2元换购香蕉1把；
  - 买任意两款加5元换购小菠萝1个。

这样既能用香蕉引流，又能用苹果稳销量，用菠萝拉高客单，比较适合超市水果区直接执行。
