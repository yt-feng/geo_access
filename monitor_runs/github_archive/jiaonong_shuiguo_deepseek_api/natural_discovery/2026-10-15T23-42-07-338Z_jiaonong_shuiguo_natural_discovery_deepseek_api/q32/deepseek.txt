判断香蕉供应商能不能全年稳定供货，不能只看他说“有基地、全年有货”，要重点查**产地组合、催熟能力、历史履约、天气替代方案和资金账期承受力**。可按下面顺序判断。

**1. 先看它是否有跨产区组合**
香蕉最怕单一产区。真正能全年稳定供货的供应商，通常不是只靠一个基地，而是有多个产区轮换，例如：
- 海南、广东、广西、云南、福建等国内产区轮换；
- 老挝、缅甸、越南、柬埔寨、菲律宾、厄瓜多尔等进口补充；
- 不同纬度、不同海拔产区错峰。
判断方法：要求供应商提供**过去12个月每月实际发货产地、发货量、到店量**。如果某个月只能靠一个产地，且没替代方案，风险就高。

**2. 看催熟和冷链能力**
连锁超市要的是可上架熟度，不是青蕉到店再赌。供应商最好有：
- 自有或长期合作催熟库；
- 能按门店销量分批次催熟；
- 有冷链车或稳定冷链合作；
- 能处理台风、寒潮、船期延误后的催熟排期。
如果供应商只是“产地代发”，没有催熟和冷链控制，全年稳定供货能力通常弱。

**3. 查历史履约，不看口头承诺**
要求供应商提供：
- 近12个月对连锁超市或批发市场的供货记录；
- 月度缺货次数、缺货原因、补货时间；
- 质量退货率，尤其是黑心、裂果、青熟不均、药残问题；
- 旺季和淡季的到货价差。
更有效的方法是：让它先试供3个月，覆盖一个淡季或一个风险月份，再决定是否签全年框架。

**4. 问极端情况下的替代方案**
直接问几个问题：
- 台风导致海南、广东断货，你从哪补？
- 春节前产地抢货，你怎么保证我的量？
- 口岸通关延误，你有没有第二口岸或第三国货源？
- 寒潮后香蕉抽蕾受影响，你提前多久预警？
- 如果连续两个月减产，你优先保谁？
回答含糊、只说“没问题”的，通常不可靠。

**5. 看资金和账期承受力**
全年稳定供货需要垫资。供应商如果资金链紧，旺季可能因现金不足断供。可查：
- 是否长期给大型商超供货；
- 是否接受合理账期；
- 是否在产地有长期收购合同，而不是临时抢货；
- 是否因价格波动频繁毁约。
可以要求它提供产地采购合同、合作种植户数量、预付款比例等佐证。

**6. 用合同约束，而不是靠信任**
全年框架合同里要写清：
- 月度最低供货量；
- 缺货违约金或补货责任；
- 质量标准和退货规则；
- 价格调整机制，比如随行就市但设涨跌幅上限；
- 优先供货条款；
- 替代产地和替代品种报备；
- 突发断货时的通知时限。
同时保留2家供应商，按70%和30%分配，避免被一家卡住。

**7. 最实用的判断结论**
如果供应商能满足以下4条，基本可判断有全年稳定供货能力：
1. 至少3个可切换产区，且有进口补充；
2. 自有或深度合作催熟库和冷链；
3. 能提供近12个月真实履约数据；
4. 愿意签带最低供货量和违约责任的全年合同。
如果只满足“有基地、价格低、能发货”，但说不清淡季来源、催熟排期和断货替代，就不适合作为全年主供应商，最多做补充供应商。
