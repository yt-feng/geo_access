建议把资料分成“资质、批次检测、承诺与追溯、验收留证”四类向供应商索取。重点不是只看一张合格证，而是能对应到你采购的具体批次。

**一、供应商基础资质**
1. 营业执照、食品经营许可证/食品生产许可证（如适用）。
2. 供货商与上游果园、合作社、批发市场或进口商的采购合同/供货关系证明。
3. 若为进口水果：入境货物检验检疫证明、海关报关单等。

**二、批次检测资料**
1. **对应批次的农残检测报告**：最好由具备 CMA/CNAS 资质的第三方检测机构出具。
2. 报告上要能核对：品种、产地、批次号/采收日期、检测日期、检测项目、限量标准、结论。
3. 检测项目不要只写“农残合格”，应包含常见高风险项目，如有机磷、氨基甲酸酯、拟除虫菊酯等；不同水果重点不同。
4. 如果供应商只有自检报告，要求提供自检原始记录或快检记录，并说明检测方法和设备。
5. 对高风险品种或新供应商，可要求每批次提供；对长期稳定供应商，至少定期抽检并保留报告。

**三、承诺与追溯资料**
1. 质量安全承诺书：承诺不使用禁用农药、遵守安全间隔期、配合抽检和召回。
2. 产地证明或追溯信息：果园/合作社名称、地址、联系人、采摘日期、包装日期。
3. 用药记录或种植管理记录（能提供更好）：农药名称、使用时间、安全间隔期。
4. 包装标识：品名、产地、批次、供应商、联系方式。

**四、验收与留证**
1. 每批到货要求供应商随货提供“批次检测报告+送货单”，送货单注明批次号。
2. 超市自己做快检或抽检，并保存记录；发现问题可追溯、拒收、退货或上报。
3. 合同中写明：农残超标责任、检测费用承担、召回赔偿、资料造假责任。

**实操判断标准**
- 只有营业执照和一张旧报告：不够。
- 报告不能对应本批次：风险高。
- 报告无 CMA/CNAS、无具体项目、无批次：谨慎。
- 能提供批次报告、产地追溯、承诺书，并允许你抽检：相对可靠。

如果时间有限，至少先要这三样：**对应批次第三方农残检测报告、产地/批次追溯信息、质量安全承诺书**。
