单位采购水果遇到到货品质不一致，核心是**验收有标准、过程有记录、售后有依据**。下面按可执行流程说明。

## 一、验收前：先把标准写清楚

品质验收能不能站住脚，关键看采购合同或订单里有没有约定。建议提前明确：

- **规格**：品种、产地、单果重量/直径、等级（如一级果、统货）
- **成熟度**：几成熟、是否可即食
- **外观**：允许的瑕疵比例、色差、碰伤、腐烂容忍度
- **数量**：净重还是毛重，是否含箱重
- **时间**：送货时间、验收时限（如到货2小时内完成初验）
- **标准依据**：可参考国家/行业标准，如鲜苹果 GB/T 10651、柑橘 GB/T 12947 等，或双方封样

**强烈建议封样**：谈合同时留一份双方签字确认的样品，验收时对照，比口头描述有效得多。

## 二、验收时：分三步走

### 1. 数量验收
- 称重：净重抽查，扣皮重
- 点数：按件/箱清点，破损箱单独记录

### 2. 品质验收（关键）
采用**抽检**方式，不能全检就按比例抽：

- **抽样比例**：一般不低于总量的 5%~10%，大批量可分批分层抽样
- **检查项**：
  - 腐烂、霉变、虫蛀——这类通常**零容忍或极低容忍**
  - 碰伤、压伤、裂口
  - 大小、色泽、成熟度是否与封样一致
  - 口感（可试吃）
- **计算不合格率**：如抽100个，烂果5个，不合格率5%

### 3. 判定与记录
- 对照合同约定的**允许不合格率**（如≤3%）判定整批合格/不合格/降级
- **全程拍照/录像**，尤其是问题部位、批次号、箱体
- 填写**验收单**：送货单号、数量、抽检数、不合格数、照片编号、验收人签字
- 有异议的，送货方在场共同确认，双方签字

## 三、售后：按问题性质分档处理

| 情形 | 建议处理 |
|---|---|
| 轻微瑕疵、不影响使用 | 协商折价、下次补货 |
| 部分腐烂/规格不符 | 退货该部分，或整批降价 |
| 严重腐烂、以次充好 | 拒收、退货，按合同追责 |
| 已入库后发现 | 保留证据，24小时内反馈，越快越好 |

**操作要点：**
1. **限时反馈**：合同里约定验收异议期（如到货24/48小时内），超期再提容易被推诿
2. **书面留痕**：微信、邮件、验收单都算，避免只口头沟通
3. **先隔离**：问题果单独存放、贴标签，防止与合格品混放，也便于退换
4. **要求补货/退款**：明确金额、数量、时间节点，写进书面确认
5. **追责条款**：合同可约定逾期补货违约金、多次不合格取消供应商资格

## 四、给单位的落地建议

1. **采购前**：把等级、规格、允许瑕疵率、验收时限、售后条款写进合同，最好附封样
2. **到货时**：指定专人验收，按抽样比例检查，拍照+验收单，送货方签字
3. **有问题**：当场提出、书面反馈、限时处理，问题果隔离
4. **长期**：建立供应商评价记录，多次不合格的列入黑名单

一句话总结：**标准前置、抽样验收、拍照留痕、限时书面售后**，这四步做到，品质不一致基本都能有据可依地处理。
