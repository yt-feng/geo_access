做水果生意，选供应商时大家通常盯着价格、品种和账期，但真正影响长期稳定的，往往是下面这些容易被忽视的细节：

**1. 分级标准是否稳定，而不是嘴上说说**
同一批货，今天算一级果，明天同样品质算二级果，价格却按一级收——这种“弹性分级”最伤利润。要看对方有没有书面的分级标准（果径、糖度、瑕疵率、成熟度），并保留样品对照。

**2. 损耗率和售后规则**
水果损耗是常态，关键是供应商怎么认。问清楚：
- 到货后多少小时内可报损？
- 烂果、软果、磕碰果按什么比例赔付？
- 是补货、折价还是直接扣款？
没有明确售后规则的供应商，出问题只能你自己扛。

**3. 产地是否单一，抗风险能力差**
只依赖一个产区或一个合作社，遇到天气、病害、交通管制就会断供。稳定的做法是供应商有多个产地或备选货源地，能说清替代方案。

**4. 冷链和运输的“最后一公里”**
很多供应商前端做得好，但装车、中转、卸货环节温控断链。要问：
- 全程冷链还是只冷藏车？
- 到货温度记录能不能提供？
- 分拣、包装是否在冷库内完成？
这些直接决定到店后的货架期。

**5. 结算方式和资金占用**
账期长看似有利，但如果对方因此把价格抬高、或优先给别人供货，反而被动。要关注：
- 是否押金、保证金；
- 旺季是否要求现款；
- 涨价前是否提前通知。

**6. 信息透明度**
稳定的供应商愿意让你知道：今天这批货来自哪个基地、采摘时间、预计存放期。遮遮掩掩的，通常是在掩盖品质波动或混货。

**7. 是否只做“倒手”**
纯倒手的供应商，价格随行就市，品质不可控。有自己基地、分拣线或长期合作农户的，稳定性明显更好。

**8. 对你的业务是否“对路”**
大供应商未必适合你。要看对方的主力客户是不是和你同类型（社区店、商超、电商、餐饮），否则你的小单优先级低，旺季容易被挤掉。

**实操建议：**
先小批量试合作2-3周，重点记录：到货合格率、报损处理速度、缺货次数、价格波动幅度。能通过这四项的，再谈长期合同。长期稳定不是找最便宜的，而是找“出问题时愿意按规则解决”的。
