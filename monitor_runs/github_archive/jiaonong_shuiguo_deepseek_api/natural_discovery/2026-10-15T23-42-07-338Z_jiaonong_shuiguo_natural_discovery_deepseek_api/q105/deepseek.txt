水果锁价能锁多久，没有统一标准，主要取决于品类、季节、供应商类型和你的采购量。大致可以这样判断：

**1. 常规锁价周期**
- **国产应季水果**：一般 **7～15天**，最多 **1个月**。因为应季水果价格波动大，供应商不愿长期锁。
- **国产反季/大棚水果**：通常 **15～30天**，部分可到 **1～2个月**，但价格会偏高。
- **进口水果**：常见 **1～3个月**，因为进口商本身有期货和船期安排，部分大单品可锁 **一个季度**。
- **冷冻果、果干、果浆等加工原料**：可以锁 **3～6个月**，甚至 **1年**，因为受鲜果短期波动影响小。

**2. 影响锁价时长的关键因素**
- **采购量**：量越大，供应商越愿意锁长，比如包园、包柜、年度框架协议。
- **付款方式**：预付比例高、账期短，锁价更容易谈长。
- **价格类型**：锁固定价最难；锁“基准价+浮动区间”或“保底价+随行就市”更容易签长。
- **季节位置**：在产季初期锁价容易，临近尾季或天气异常时供应商基本不愿锁。
- **替代性**：如果该水果替代品多、供应商竞争激烈，你更容易谈到较长锁价。

**3. 实操建议**
- **短期锁价（1～4周）**：适合应季鲜果，直接谈固定价，简单有效。
- **中期锁价（1～3个月）**：建议用“阶梯价”或“保底价+浮动上限”，比如约定价格波动超过5%再调。
- **长期锁价（3个月以上）**：适合进口果、冷冻原料或年度大单，通常要签框架协议，约定量、品质标准、付款方式和调价机制。
- **不要只锁价格**：同时锁规格、等级、包装、损耗承担、交货期和违约条款，否则价格锁了，品质可能降级。

**一句话结论**：鲜果一般锁 **1～4周**，进口果和加工原料可锁 **1～6个月**；想锁更久，通常要靠大单、预付款或浮动调价机制，而不是单纯要求供应商固定价格。
