连锁商超水果供应商招标，评分标准要围绕“长期稳定供货”这个核心来设计，不能只看报价。建议采用**百分制**，按以下框架设置：

## 一、总体权重建议

| 评分维度 | 建议权重 | 核心考察点 |
|---|---|---|
| 价格与成本 | 25%–35% | 报价竞争力 + 成本透明度 |
| 产品质量与标准化 | 20%–25% | 品质稳定性、分级标准 |
| 供应链与供货能力 | 15%–20% | 产地、冷链、产能、抗风险 |
| 品控与食品安全 | 10%–15% | 检测、溯源、认证 |
| 服务与响应 | 5%–10% | 订单响应、退换货、驻场 |
| 企业资质与信誉 | 5%–10% | 资质、业绩、财务健康 |

价格权重不宜超过35%，否则容易招到“低价低质、后期断供”的供应商。

## 二、各维度细化评分点

**1. 价格与成本（25–35分）**
- 报价与市场均价对比（不得低于成本价，防止恶性低价）
- 是否接受价格联动机制（随产地行情浮动、季度调价）
- 物流、损耗、包装费用是否含在报价内
- 账期接受度（商超通常要求30–60天）

**2. 产品质量与标准化（20–25分）**
- 能否提供统一的分级标准（大小、糖度、成熟度、外观）
- 样品盲测评分（口感、新鲜度、一致性）
- 不同批次品质稳定性（看历史供货记录或试供）
- 包装规格是否符合门店/线上销售需求

**3. 供应链与供货能力（15–20分）**
- 自有基地或稳定合作产地（加分项）
- 冷链仓储与运输能力（车辆、冷库、温控）
- 旺季/淡季保供方案，灾年应对预案
- 日均/峰值供货量和覆盖门店能力

**4. 品控与食品安全（10–15分）**
- 农残检测报告、第三方检测频率
- 可追溯体系（批次可查、产地可追）
- 相关认证（绿色食品、GAP、HACCP等）
- 质量事故赔付承诺

**5. 服务与响应（5–10分）**
- 下单到到货时效
- 退换货与损耗赔付条款
- 是否配备专属对接人/驻场服务
- 促销期、节假日加急供货能力

**6. 企业资质与信誉（5–10分）**
- 营业执照、食品经营许可等合规资质
- 过往商超/大型渠道合作业绩
- 财务健康度（防止中途资金断裂）
- 有无重大质量或失信记录

## 三、几个关键设计建议

1. **设置“一票否决”项**：食品安全事故记录、资质造假、重大失信，直接废标，不进入打分。

2. **价格分用公式而非主观打分**：例如以有效报价最低价为基准，按比例计算，避免评委随意性。

3. **加入试供期考核**：中标后设1–3个月试供，试供不合格可终止，把“长期”落到实际验证上。

4. **长期合同配动态考核**：季度/年度按到货合格率、缺货率、投诉率打分，与续约、份额挂钩。

5. **区分品类**：叶菜、根茎、进口果、应季果的评分侧重不同，应分品类设置权重，不要一套标准打天下。
