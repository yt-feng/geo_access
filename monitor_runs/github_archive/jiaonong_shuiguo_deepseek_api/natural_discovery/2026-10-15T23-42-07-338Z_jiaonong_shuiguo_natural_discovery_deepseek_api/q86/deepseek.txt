生鲜平台做水果一件代发，供应商的仓配能力至少要能支撑“单件拣货、保鲜、防损、时效、逆向”这几件事。具体可以按下面几个维度判断：

**1. 仓储能力**
- **多温区或至少控温仓储**：水果品类差异大，香蕉、芒果等需要催熟/常温，蓝莓、荔枝、樱桃等需要冷藏，供应商要有对应温区，不能混放。
- **日处理订单能力**：日均单量、峰值单量、爆单时能否加人加场地，直接决定大促会不会崩。
- **库存准确率**：一件代发最怕超卖和缺货，库存准确率建议不低于99.5%，最好能对接平台系统实时同步。
- **批次与效期管理**：水果保质期短，要能按批次先进先出，临期预警，避免发旧货。

**2. 加工与包装能力**
- **分拣分级**：能按规格、果径、重量、成熟度分级，减少“大小不一、熟度不一”的投诉。
- **预冷能力**：采摘后快速预冷，是延长货架期的关键，尤其浆果、叶菜类水果。
- **包装适配**：防震、防压、透气、保温/冰袋方案要匹配品类和快递时效，不能一套包装发所有水果。
- **定制化能力**：能否贴平台标、放卡片、做组合装、节日礼盒。

**3. 配送与时效能力**
- **快递资源**：是否对接顺丰、京东、中通等，能否拿到生鲜专线价格和优先中转。
- **发货时效**：当日单当日发或次日发，截单时间是否稳定，能否承诺48小时/72小时达。
- **区域覆盖**：全国发还是区域发，偏远地区是否加价或停发，要提前明确。
- **冷链能力**：如果是冷藏水果，是否有冷链快递、冰袋+泡沫箱+保温袋方案，以及温控记录。

**4. 防损与售后能力**
- **损耗率控制**：行业里一件代发水果损耗率通常要控制在3%-8%以内，具体看品类，超过这个范围平台很难盈利。
- **坏果包赔**：能否按比例赔付、补发、退款，售后响应时效多长。
- **逆向处理**：烂果是否退回、是否就地销毁、凭证怎么留，流程要清晰。
- **保险/理赔**：是否投保物流险，出现批量坏果时能否快速理赔。

**5. 系统与协同能力**
- **ERP/WMS对接**：能否与平台订单系统打通，自动抓单、回传单号、同步库存。
- **面单与轨迹**：电子面单、物流轨迹回传是否稳定。
- **数据反馈**：能否提供发货时效、破损率、售后率等数据，方便平台考核。

**6. 资质与合规**
- **食品经营许可证/生鲜资质**：水果虽多属初级农产品，但平台通常仍要求相关资质。
- **产地证明/检测报告**：农残检测、产地直供证明，能提升平台信任。
- **发票与合同**：能否开票、账期、结算方式要明确。

**简单判断标准：**
如果供应商只能做到“有仓库、能发快递”，但做不到控温、预冷、分级、坏果包赔和系统对接，那基本不适合做水果一件代发，更适合做批量供货。真正能长期合作的一件代发供应商，核心看四点：**库存准、发货快、损耗低、售后爽快**。
