做水果拼盘时，苹果、橙子、菠萝的“规格划算”核心不是单价最低，而是**可食用率、切块出品率、外观稳定性**三者平衡。下面按品类给建议。

## 1. 苹果：选中大果，不要盲目追大
- **推荐规格**：单果 **180–250g**，直径 **75–85mm** 左右。
- **为什么**：
  - 太小的果（如70mm以下）削皮去核后损耗大，切出来块小，拼盘显得不饱满。
  - 太大的果单价常更高，但可食用率提升有限，且一个果切太多，氧化和剩余管理更麻烦。
- **划算判断**：
  - 看**每斤出净肉率**。苹果去皮去核损耗约 **35%–45%**。
  - 优先选果形端正、无磕碰的，畸形果虽然便宜，但切块废料多。
- **品种建议**：红富士、嘎啦、蛇果都可，拼盘常用红富士，颜色稳、脆度好。

## 2. 橙子：选中果，重点看皮厚和籽少
- **推荐规格**：单果 **180–220g**，直径 **70–80mm**。
- **为什么**：
  - 橙子太大皮往往也厚，切瓣或去皮后净肉不一定多。
  - 太小则切瓣短，摆盘不好看。
- **划算判断**：
  - 优先选**皮薄、无籽或少籽**的品种，如脐橙、血橙、部分夏橙。
  - 如果做“橙子切片/切瓣”带皮摆盘，皮薄色亮的更划算，因为不用去皮，损耗低。
  - 如果做纯果肉，必须算去皮损耗，通常 **25%–35%**。
- **避坑**：不要只看低价橙，皮厚、籽多、干水的橙子实际出品率很低。

## 3. 菠萝：选中等偏大、成熟度一致的
- **推荐规格**：单果 **1.2–1.8kg** 比较合适。
- **为什么**：
  - 太小的菠萝削皮去眼后净肉少，人工成本高。
  - 太大的菠萝虽然净肉多，但一次用不完，切开后保存和氧化风险高。
- **划算判断**：
  - 菠萝去皮去眼损耗约 **40%–50%**，所以要看**净肉价**，不是毛重价。
  - 选果眼浅、皮色黄中带绿、香味明显的，出肉率更高，口感也稳。
  - 如果餐厅用量大，可直接买**去皮菠萝/菠萝块**，对比人工和损耗后有时更划算。
- **避坑**：生青菠萝虽然便宜，但酸涩，拼盘接受度低；过熟菠萝切块易烂。

## 4. 综合采购建议
| 水果 | 推荐单果规格 | 关键看 | 一般损耗 |
|---|---:|---|---:|
| 苹果 | 180–250g | 果形正、脆度好 | 35%–45% |
| 橙子 | 180–220g | 皮薄、少籽 | 25%–35% |
| 菠萝 | 1.2–1.8kg | 果眼浅、成熟度 | 40%–50% |

## 5. 最划算的选法
1. **按净肉成本算**，不要按毛重单价算。  
   公式：`净肉成本 = 采购价 ÷ 可食用率`
2. **拼盘用果优先统一大小**，切块规格一致，减少废料和返工。
3. **苹果和橙子选中果**，出品稳定；**菠萝选中大果**，净肉率更合适。
4. 如果日均用量大，直接对比**鲜果 vs 预切果**，把人工、损耗、冷藏成本一起算进去。

简单记：  
**苹果 180–250g，橙子 180–220g，菠萝 1.2–1.8kg。**  
优先选皮薄、果形正、成熟度一致的，按净肉成本判断，通常最划算。
