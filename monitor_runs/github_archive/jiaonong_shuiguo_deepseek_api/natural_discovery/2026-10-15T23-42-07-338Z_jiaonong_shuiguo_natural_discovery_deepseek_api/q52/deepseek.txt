要避免香蕉到店后很快变黑，核心是控制**乙烯、温度、机械损伤和湿度**。采购时和到店后可以这样做：

1. **采购时选成熟度低的香蕉**
   - 优先选**青黄交接、整体偏硬**的香蕉，不要选已经出现黑点、软熟、柄部发黑的。
   - 如果甜品店当天或次日就要用，可以选**微黄、无斑点**的；如果要放2–3天，选**青一点**的更稳。

2. **避免买“已经催熟过头”的货**
   - 香蕉柄发黑、果身有压伤、箱内有明显酒味或酸味，说明已经成熟过度，到店后会很快变黑。
   - 采购时检查箱底和中间，不要只看最上面一层。

3. **运输和搬运减少磕碰**
   - 香蕉怕压、怕摔。叠放不要过高，避免重物压在上面。
   - 到店后轻拿轻放，受伤部位会释放更多乙烯，并很快褐变。

4. **到店后立刻分散、通风、降温**
   - 不要整箱闷着放。打开箱子，把香蕉摊开或挂起来，保持通风。
   - 适合存放温度大约是**13–15℃**。不要放冰箱冷藏，除非已经熟透且马上用；低温会让香蕉皮很快变黑。
   - 远离暖气、烤箱、阳光直射和热操作台。

5. **隔离乙烯来源**
   - 香蕉本身会释放乙烯，不要和苹果、梨、番茄、芒果等一起放，它们也会催熟。
   - 如果店里有多批香蕉，把成熟度高的和青的分开，避免互相催熟。

6. **按使用节奏分开放**
   - 当天用的放常温操作区附近。
   - 明后天用的放阴凉通风处。
   - 更久才用的尽量保持低温、通风、未损伤状态。

7. **不要提前清洗或剥皮**
   - 表皮有天然保护层，洗掉后更容易坏。用之前再处理。
   - 如果只要果肉，剥开后尽快用柠檬汁、糖水或真空/密封冷藏减缓氧化。

8. **已经偏熟的尽快处理**
   - 一旦出现少量黑点，说明已经适合马上使用。可以优先做香蕉泥、奶昔、烘焙、酱料。
   - 熟透果肉可去皮后冷冻保存，后续做甜品仍可用。

简单判断：
- **想放得久**：买青一点、无伤、别冷藏、通风、远离其他水果。
- **想当天用**：买微黄无斑、手感稍硬。
- **已经黑点多**：别再等，直接优先加工或冷冻。
