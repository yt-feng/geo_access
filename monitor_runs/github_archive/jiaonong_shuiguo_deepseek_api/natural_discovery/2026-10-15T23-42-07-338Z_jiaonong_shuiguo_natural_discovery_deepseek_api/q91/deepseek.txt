便利店卖香蕉，优先建议 **小把（2–4根）为主，单根作为补充，整袋谨慎上架**。原因和具体做法如下：

1. **小把最匹配便利店场景**
   - 便利店客群多是即时消费、单人/双人食用。
   - 2–4根一把，客单价适中，拿取方便，也减少“买一整袋吃不完”的顾虑。
   - 比单根更有毛利空间，损耗也更容易控制。

2. **单根适合做补充和应急**
   - 适合只想吃一根、临时解馋或搭配早餐的顾客。
   - 但单根毛利偏低，称重、贴标、陈列都更费人工。
   - 可以只在高峰期或靠近收银台少量陈列。

3. **整袋不适合作为主推**
   - 整袋更适合家庭采购，和便利店“小量、即时”的定位不太匹配。
   - 容易压货，香蕉熟得快，卖不完损耗大。
   - 除非门店在社区门口、家庭客多，或有明显价格优势，否则不建议主推。

4. **更稳妥的组合建议**
   - 主力：小把 2–4 根，定价按根或按把。
   - 补充：单根，放在收银台附近。
   - 试销：整袋只做少量测试，观察 1–2 周动销。
   - 陈列：按成熟度分开放，青一点的放里面，黄熟的放前面优先卖。
   - 损耗控制：每天检查，过熟的可做折扣区或搭配酸奶、早餐组合卖。

简单说：**主推小把，单根补位，整袋只试销**。如果门店家庭客特别多，再考虑增加整袋比例。
