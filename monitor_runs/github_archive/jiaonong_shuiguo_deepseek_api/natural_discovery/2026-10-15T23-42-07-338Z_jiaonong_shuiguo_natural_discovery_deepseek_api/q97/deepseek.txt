酒店采购水果盘原料时，建议在采购合同或验收标准中明确以下规格和外观要求。具体数值可按酒店档次、水果盘定位和当地市场情况调整。

## 一、通用规格标准

**1. 重量/大小分级**
- 按品种设定单果重量区间，如苹果 180–220g、橙子 200–250g、火龙果 400–500g。
- 同一批次大小尽量均匀，避免一盘里个头差异过大。
- 明确“允许偏差范围”，例如单果重量偏差不超过 ±10%。

**2. 成熟度**
- 到货时达到“即食”或“1–2 天内可食用”的成熟度。
- 明确可接受成熟度区间：太生（涩、硬）或过熟（软烂、发酵）均应拒收。
- 对需要后熟的水果（如芒果、猕猴桃、牛油果）可约定“到货成熟度 + 可后熟”。

**3. 新鲜度**
- 采摘/收货后存放时间有上限，避免长期冷藏导致风味下降。
- 叶菜类配果（如薄荷、装饰叶）要求当天或 24 小时内新鲜到货。

**4. 安全与合规**
- 农残检测合格，符合当地食品安全标准。
- 提供产地证明、检测报告或合格证（按酒店要求）。
- 无非法催熟、染色、打蜡等处理；如打蜡须为食用级并提前告知。

## 二、外观标准

**1. 形状**
- 果形端正，无明显畸形、扁平、双胞胎果等。
- 允许轻微自然差异，但不接受明显影响切配的畸形。

**2. 色泽**
- 具有该品种成熟时应有的色泽，着色均匀。
- 无明显青斑、褪色、暗沉或异常发亮（可能打蜡/染色）。

**3. 表面**
- 果皮完整，无破损、裂口、刺伤、压伤、虫眼。
- 无霉斑、腐烂、软烂、渗液。
- 无明显药斑、污渍、泥土过多。

**4. 瑕疵控制**
- 外观瑕疵面积和数量设上限，例如：单果瑕疵面积不超过 5%，每箱瑕疵果比例不超过 5%–10%。
- 不影响切配和出品的轻微瑕疵可接受，但需在合同中写明。

## 三、按品类补充要求

| 品类 | 重点规格/外观 |
|---|---|
| 苹果、梨 | 无碰伤、无黑心，果柄完整或修整一致 |
| 橙、柑、柚 | 皮薄易剥或易切，无浮皮、无干枯 |
| 西瓜、哈密瓜 | 成熟度适中，无裂口、无软腐，糖度可约定 |
| 葡萄、提子 | 果粒饱满、无掉粒，果梗新鲜青绿 |
| 草莓、蓝莓 | 无压伤、无霉变，蓝莓要求果粉完整 |
| 火龙果、芒果 | 无黑斑、无软烂，成熟度一致 |
| 猕猴桃、牛油果 | 到货硬度可控，便于后熟管理 |
| 菠萝 | 无黑心、无裂口，成熟度一致 |
| 装饰叶/薄荷 | 叶片完整、无黄叶、无萎蔫 |

## 四、包装与运输要求

- 使用食品级、清洁、无异味的包装箱/周转筐。
- 分层分隔，避免挤压、碰撞。
- 运输温度按品种要求：热带水果避免低温冻伤，浆果类需冷链。
- 到货温度记录可要求随货提供或现场抽测。

## 五、验收与拒收建议

**可拒收情形：**
- 霉变、腐烂、渗液、异味。
- 大面积压伤、裂口、虫蛀。
- 成熟度严重不符（过生或过熟）。
- 规格偏差超出约定范围。
- 无合格证明或检测报告（如合同要求）。

**验收方式：**
- 每批次抽检，记录重量、数量、成熟度、瑕疵率。
- 拍照留证，异常批次可整批退换。
- 建立供应商评分，连续不达标可减少订单或更换。

## 六、写入合同的建议条款

1. 品种、产地、等级、单果重量/大小区间。
2. 成熟度、新鲜度、糖度（如适用）。
3. 外观瑕疵允许比例和拒收标准。
4. 农残及食品安全合规要求。
5. 包装、运输温度、到货时限。
6. 验收抽检比例、退换货规则、违约责任。
