社区超市找每天配送的水果供应商，建议重点看这几个条件：

1. **配送频率和时效**
   - 是否能真正做到每日配送，而不是“隔日达”或“凑单才送”。
   - 送达时间是否固定，比如早上6—8点前到店，方便开门前上架。
   - 临时补货、节假日加单能不能响应。

2. **货源稳定性**
   - 是否有稳定产地或一级批发渠道，不是临时倒货。
   - 应季水果和常销水果能不能长期供齐，比如苹果、香蕉、橙子、西瓜等。
   - 缺货时是否有替代方案，还是直接断供。

3. **价格和结算**
   - 报价是否含运费、装卸费、损耗补贴。
   - 是否随行就市，还是能签短期锁价协议。
   - 结算方式是日结、周结还是月结，能否开票。

4. **品质和损耗**
   - 到店新鲜度、成熟度是否适合社区店当天销售。
   - 坏果、压伤、烂果怎么赔，是否包退换。
   - 损耗率大概多少，谁来承担。

5. **品类匹配度**
   - 能不能按社区消费习惯配货，比如小份装、家庭装、高端果和特价果搭配。
   - 是否支持少量多品种，而不是一次必须进很多箱。

6. **冷链和仓储能力**
   - 叶菜类、浆果类、切果类是否需要冷链。
   - 夏天高温时能不能保证品质不快速下降。

7. **售后和沟通**
   - 有没有固定对接人，出问题多久回复。
   - 退换货流程是否简单，会不会扯皮。
   - 能否提供检测报告、产地证明等。

8. **合作门槛**
   - 起订量多少，首次合作要不要押金、加盟费。
   - 是否允许先试供一周，再决定长期合作。

实际筛选时，建议先让2—3家供应商各试供3—7天，重点记录：到货时间、坏果率、缺货次数、补货响应、结算是否清楚。试供后再谈长期合作，比只看报价更靠谱。
