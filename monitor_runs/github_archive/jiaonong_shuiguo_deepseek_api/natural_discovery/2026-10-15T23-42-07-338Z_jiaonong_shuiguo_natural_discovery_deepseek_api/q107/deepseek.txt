具体看：

1. **香蕉**
- 香蕉通常是青果采购、后熟销售，起订量太高会带来：
  - 后熟集中在同一时间段，来不及卖就过熟、发黑；
  - 对温度、乙烯控制要求高，库存一挤压，损耗会明显上升；
  - 一旦催熟节奏没排好，容易出现“前面不够卖、后面集中烂”的情况。
- 所以香蕉对**到货批次、催熟排期、日均销量**非常敏感。

2. **菠萝**
- 菠萝相对耐放一些，但起订量过高仍有风险：
  - 成熟度高的菠萝存放期短，容易黑心、发酵、腐烂；
  - 整果占空间，库存积压会影响通风和翻堆；
  - 如果门店或仓库温度高、湿度大，损耗会加快。
- 菠萝的风险通常比香蕉略低，但**大批量集中到货**仍然会放大损耗。

3. **为什么起订量高会放大损耗**
- 库存周转天数变长；
- 先进先出执行难度变大；
- 温湿度、催熟、翻堆等管理压力上升；
- 一旦销售不及预期，只能降价处理，利润被吃掉。

4. **怎么判断风险高不高**
可以重点看这几个指标：
- 日均销量 vs 起订量：如果起订量超过 3～7 天销量，风险通常偏高；
- 到货成熟度：越熟，越不能压库存；
- 仓储条件：有没有冷藏、通风、分拣和催熟能力；
- 补货频率：能不能小批量、多批次补；
- 损耗率历史：如果同类品过去损耗已高，提高起订量会更危险。

5. **实操建议**
- 香蕉：尽量按**销售节奏和催熟周期**下单，不要只看采购单价；
- 菠萝：可以适当提高单次采购量，但优先控制成熟度，并保证通风和翻堆；
- 和供应商谈：小批量试单、混合规格、分批发货、缩短交期；
- 如果起订量降不下来，就同步准备：促销、加工用途（果切、果汁、烘焙）、调拨或临时冷库。

结论：**会。起订量太高会显著增加香蕉和菠萝的损耗风险，香蕉通常比菠萝更敏感。** 判断的核心不是“起订量高不高”，而是它是否超过了你的**周转能力、储存能力和销售速度**。
