结论先说：**如果目标是“好管理”，通常按箱结算最省事，按斤结算最准但最费人工，按份结算适合标准化单品/套餐，不适合大多数散装水果。**

具体怎么选，看你的食堂规模和水果品类：

| 结算方式 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|
| 按斤结算 | 成本最真实，按实际消耗付费，便于比价 | 验货、称重、记录、损耗核算都麻烦；容易扯皮 | 采购量大、有专人验收、想精细控成本 |
| 按箱结算 | 流程最简单，验收快，对账容易 | 箱内大小、成熟度、损耗不透明；单价可能偏高 | 中小食堂、固定供应商、追求省人力 |
| 按份结算 | 最省管理，直接对应到人/餐 | 只适合苹果、香蕉、橘子等标准单品；品种一多就乱 | 水果作为固定加餐、每人一份 |

**实操建议：**

1. **主品类按箱，辅品类按斤**
   - 苹果、橙子、香蕉这类耐储存、规格稳定的，按箱结算。
   - 葡萄、草莓、西瓜等损耗大、规格不稳定的，按斤结算。

2. **合同里写清“箱规”**
   - 每箱多少斤、允许误差范围、坏果率上限。
   - 例如：苹果每箱20斤±0.5斤，坏果超过5%则扣款或补货。

3. **验收用“抽检+称重”结合**
   - 按箱结算也要抽检1-2箱称重，防止长期缺斤少两。
   - 按斤结算则必须每批过秤，并记录皮重。

4. **按份结算只用于固定加餐**
   - 比如每天每人一个苹果，直接按人数订份，管理最轻。
   - 但一旦换成多种水果，份数、规格、价格都难统一。

**一句话总结：**
想省人力选按箱，想控成本选按斤，想发到人选按份。大多数食堂最优解是：**主力水果按箱，易损水果按斤，固定加餐按份。**
