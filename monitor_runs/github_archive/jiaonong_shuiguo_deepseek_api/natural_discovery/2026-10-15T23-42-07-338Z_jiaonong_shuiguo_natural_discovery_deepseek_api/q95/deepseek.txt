学校食堂采购水果，核心不是“找最便宜的供应商”，而是找**能稳定供货、质量可控、票据齐全、出问题能追责**的供应商。香蕉、苹果、橙子这类常见水果，建议按下面几步做。

**1. 先定采购标准，再谈价格**

不要只写“香蕉、苹果、橙子若干”，要写清楚：

- 香蕉：成熟度、单根重量范围、无黑斑或轻微黑斑可接受、到货后几天内可食用。
- 苹果：品种、果径、色泽、硬度、无碰伤腐烂、糖酸比大致要求。
- 橙子：品种、果径、皮厚、汁水、无干瘪霉变。
- 包装：箱装/筐装、净重、是否允许损耗、破损率上限。
- 配送：每周几次、几点前到、临时补货响应时间。
- 票据：每批次提供检验合格证明、进货凭证、发票。

标准越清楚，后面验收和换供应商越容易。

**2. 供应商来源优先顺序**

建议按这个顺序找：

1. **本地大型农产品批发市场里有固定档口的商户**  
   优点是品类全、价格透明、可现场看货；缺点是质量波动大，要签好验收标准。

2. **水果产地合作社或种植基地直供**  
   适合苹果、橙子这类耐储水果，价格和品质更稳。香蕉通常不是本地直接种，更多是批发商或催熟商。

3. **专业食堂食材配送公司**  
   优点是票据、配送、售后较规范，能一站式供多种食材；缺点是单价可能高一些。

4. **大型商超或生鲜平台的企业采购渠道**  
   适合临时补充或小批量，但长期食堂采购成本通常不占优。

5. **线上B2B生鲜平台**  
   可作为比价和应急渠道，但要确认是否支持学校要求的资质和对公结算。

**3. 重点核验哪些资质**

至少要求供应商提供：

- 营业执照；
- 食品经营许可证或相关流通许可；
- 如果是产地直供，提供合作社/基地证明；
- 每批次水果的合格证明或快速检测报告；
- 对公账户、发票开具能力；
- 配送人员健康证明（如涉及直接接触食品）；
- 食品安全责任险或类似保障更好。

学校食堂还要考虑当地教育局、市场监管部门对大宗食材采购的具体要求，有些地区要求集中定点采购或招标。

**4. 比价不要只看单价**

要算“可食用成本”：

- 到货净重是否足；
- 损耗率多少；
- 坏果是否包退换；
- 是否需要食堂自己分拣；
- 配送频率和运费是否另算；
- 账期和结算方式。

比如A供应商苹果便宜0.5元/斤，但每箱损耗10%，B供应商贵0.3元/斤但损耗3%，实际B可能更划算。

**5. 建议先试供再定长期**

做法：

- 选2—3家供应商同时试供1—2周；
- 每次到货按同一标准验收；
- 记录重量、损耗、口感、配送准时率、售后响应；
- 让食堂管理员、厨师、学生代表或膳食委员会参与评价；
- 综合评分后再签季度或学期合同。

**6. 合同里必须写清楚**

- 品种、规格、单价或调价机制；
- 配送时间、频率、临时补货要求；
- 验收标准和不合格处理；
- 坏果、短斤少两的退换和赔偿；
- 食品安全责任；
- 票据提供；
- 违约和退出机制；
- 价格随行就市时，约定参考哪个市场或平台的价格。

**7. 常见水果的供应商选择侧重**

- **香蕉**：重点看催熟能力、到货成熟度、配送频率。香蕉不耐存，适合少量多次配送。
- **苹果**：重点看产地、冷库储存能力、果径和硬度，适合找基地或大型批发商。
- **橙子**：重点看产季、品种、汁水和损耗，产季内可找产地直供，反季则找专业配送商。

**8. 最实用的起步方案**

如果现在没有供应商，可以这样推进：

1. 先列采购标准和验收表；
2. 到本地批发市场、周边合作社、食材配送公司各找2—3家；
3. 要求报价并送样；
4. 同时试供2周；
5. 按质量、价格、配送、售后打分；
6. 选1家主供、1家备供；
7. 签学期合同，每月复盘一次。

一句话：**常见水果选供应商，优先选能稳定供货、接受验收标准、票据齐全、坏果包退的；不要只选报价最低的。**
