餐饮店每天少量水果，想省心，核心不是找“最便宜的”，而是找**履约稳定、能小批量、处理售后快**的供应商。优先顺序可以这样排：

1. **本地水果批发市场里的固定档口**
   - 优点：品种全、当天可补货、能谈小批量配送。
   - 适合：每天用量不大，但品类会变。
   - 省心要点：固定1-2家档口，加微信，前一天发清单，约定早上几点送到。不要每天临时换档口。

2. **本地生鲜配送平台/食材B2B平台**
   - 优点：线上下单、有售后、能开票，省沟通。
   - 适合：用量稳定、品类固定，比如柠檬、橙子、苹果、圣女果。
   - 省心要点：看是否支持“少量起送”和“缺货替换”。缺货自动换同等价位水果，比临时没货强。

3. **周边水果店/连锁水果店长期合作**
   - 优点：距离近、临时缺货能救急、起送门槛低。
   - 适合：每天只要几斤，且不想囤货。
   - 省心要点：谈月结或周结，约定按批发价或固定折扣。缺点是价格通常比批发市场高一点。

4. **产地/一级批发商直供**
   - 优点：价格低、品质稳定。
   - 缺点：通常起订量大，少量不划算。
   - 适合：某一种水果用量大且稳定时，单独找单品供应商。

**最省心的组合建议：**
- 主供应商：本地批发市场固定档口，负责日常大部分水果。
- 备用供应商：周边水果店或生鲜平台，负责临时补货、缺货救急。
- 单品供应商：用量大的单品，比如柠檬、橙子，再单独找更稳定的渠道。

**筛选供应商时重点问这几句：**
- 每天最少起送量是多少？
- 能不能前一天下单、第二天早上送？
- 坏果、烂果怎么赔？是补货还是退款？
- 缺货时能不能提前通知并替换？
- 能不能开票、月结？
- 送货时间能不能固定在营业前？

**不建议找的：**
- 只有低价但经常迟到、缺货的。
- 不能小批量、必须整箱压货的。
- 售后要扯皮的。
- 每天换一个临时摊贩的。

一句话：**找本地固定档口做主供，再留一个附近水果店做备用，基本最省心。**
