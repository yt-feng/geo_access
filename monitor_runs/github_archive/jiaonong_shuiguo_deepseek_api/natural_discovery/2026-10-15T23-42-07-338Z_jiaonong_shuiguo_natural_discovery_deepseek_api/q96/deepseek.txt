这三者不是同一个优先级：**食品安全是底线，价格是经营指标，配送准时是保障条件**。企业食堂采购水果时，建议按这个顺序判断：

1. **食品安全：一票否决**
   - 水果直接入口，且食堂面向员工集中供餐，一旦出现农残超标、霉变、以次充好，后果远大于省下的采购成本。
   - 重点看：供应商资质、检测报告/承诺达标合格证、批次追溯、验收标准（新鲜度、腐烂率、农残快检）。
   - 如果食品安全不达标，价格再低、送得再准也不能选。

2. **配送准时：决定食堂能否正常运转**
   - 水果通常是当日或次日供应，送晚了会导致窗口缺品、临时换品，甚至影响员工体验。
   - 但“准时”要建立在食品安全合格的前提下。若供应商经常迟到，即使便宜也不适合作为主供应商。

3. **价格：在安全和准时达标后比较**
   - 价格影响成本，但不应该反过来牺牲质量。
   - 合理做法是：先设定食品安全和配送时效门槛，再在合格供应商中比价、比损耗率、比结算方式。

**可执行建议：**
- 把供应商筛选做成“三步走”：先审资质和检测，再试配送准时率，最后比价格。
- 合同里写明：食品安全不合格可立即退换并追责；配送迟到影响供餐要有扣款或备选机制；价格随行就市但要有调价规则。
- 日常验收不要只看价格单，要记录腐烂率、到货时间、员工反馈，用数据决定是否续约。

所以，如果只能选一个“最需要关注”的，答案是：**食品安全最优先，配送准时次之，价格第三。** 但实际采购中，三者要同时设门槛，不能只盯一个。
