超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果品类、采购渠道和超市自身要求：

**一、基础资质证明**
1. **营业执照**：供应商合法经营主体证明。
2. **食品经营许可证**或**食品生产许可证**（如涉及加工/分装）。
3. **供货合同/采购协议**：明确双方责任。

**二、进货凭证类**
1. **进货单据/销售凭证**：记录品种、数量、批次、日期、供应商信息。
2. **产地证明**：如来自种植基地，可提供产地证明或基地备案信息。
3. **检疫证明**：部分水果（如进口水果、柑橘类等）可能需要植物检疫证书。
4. **进口水果**还需：
   - 海关报关单
   - 入境货物检验检疫证明
   - 中文标签（预包装水果）

**三、检测报告类**
1. **农药残留检测报告**：最常见，通常由供应商或第三方检测机构出具，项目包括有机磷、氨基甲酸酯类等。
2. **重金属检测报告**：如铅、镉、砷等（部分超市会要求）。
3. **食品添加剂/防腐剂检测**：如使用保鲜剂、打蜡等，需符合标准。
4. **微生物检测**：鲜切水果或预包装水果更常要求。
5. **快速检测报告**：部分超市自建快检室，会要求供应商提供或配合抽检。

**四、批次与追溯要求**
- **批次合格证明**：每批货对应检测报告或合格证。
- **追溯信息**：能追溯到产地、种植户/合作社、采收日期等。
- **承诺书/质量保证书**：供应商对质量安全作出承诺。

**五、超市常见操作**
- 大型连锁超市通常要求供应商提供**每批次农残检测报告**，并保留**进货台账**。
- 部分超市要求**第三方检测报告**（如SGS、华测等），有效期通常为半年或一年。
- 对高风险水果（如草莓、葡萄、豇豆等）会加大抽检频次。

**建议**：
- 作为供应商，提前准备**近期的第三方检测报告**和**每批次快检报告**，并建立可追溯台账。
- 作为超市采购，应在合同中明确检测项目、报告有效期、抽检不合格处理方式，并留存供应商资质和每批进货凭证。

具体清单最好以当地市场监管部门要求和超市内部采购标准为准。
