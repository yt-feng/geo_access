小面积便利店做水果，核心原则是：**把水果当“引流+即食”品类，而不是当生鲜超市做全品类。** 品类要少、单品要精、补货要勤、损耗要日清。

下面给你一套可以直接执行的控制方法：

**一、品类控制：只做3类，不超过8-12个SKU**

1. **高频刚需类**：香蕉、苹果、橙子/柑橘。  
   - 作用：稳定客流，耐放，认知度高。  
   - 建议占水果SKU的40%。

2. **即食便利类**：切好的果切、小盒蓝莓、圣女果、小黄瓜、即食猕猴桃。  
   - 作用：毛利高、冲动购买、适合便利店场景。  
   - 建议占30%，但必须冷链和当日清。

3. **季节引流类**：夏天西瓜/葡萄，冬天砂糖橘/草莓。  
   - 作用：制造季节感和爆点。  
   - 建议只选1-2个单品，不要铺开。

**不要做的**：榴莲、山竹、车厘子等高客单、高损耗、难储存的品类，除非你店门口有稳定高消费客流，否则不要碰。

**二、采购量控制：按“日销”倒推，不按“陈列好看”进货**

- 先记录3-7天真实销量，算出每个单品的**日均销量**。
- 首次采购量 = 日均销量 × 1.2，不要超过1.5倍。
- 叶菜类、果切、草莓、蓝莓这类，按**半天销量**补货。
- 香蕉、苹果、橙子可按**1-2天销量**备货。
- 设定安全库存：低于日均销量50%时补货，高于日均销量1.5倍时停止进货。

**三、损耗控制：从收货到出清，做5个动作**

1. **收货验货**：当场拆箱，拒收压伤、过熟、发霉、冻伤果。  
   - 香蕉不要全黄，苹果不要有磕碰，柑橘不要发软。

2. **分级陈列**：  
   - 好果做正常陈列。  
   - 轻微瑕疵果立刻做果切或特价区。  
   - 过熟果当天做成果切、果汁或员工餐，不要留到第二天。

3. **先进先出**：新货放里面，旧货放外面，每天开店前翻堆一次。

4. **温控分区**：  
   - 香蕉、芒果、木瓜常温避风。  
   - 蓝莓、草莓、果切、葡萄冷藏。  
   - 不要把所有水果塞同一个冷柜，香蕉冷藏会发黑。

5. **日清机制**：  
   - 每天闭店前1小时做“损耗出清”：果切7折、微瑕果5折、过熟果直接报损。  
   - 报损要记录，第二天采购量按报损率下调。

**四、用“小批量、多频次”代替“大批量、低单价”**

- 不要因为批发便宜就一次进太多。  
- 小面积店的最大成本不是进价，而是**卖不掉扔掉的损耗**。  
- 如果供应商愿意，尽量做到**每周2-3次小批量补货**，而不是一周一次大进货。  
- 对果切、蓝莓、草莓这类，最好**每日或隔日补**。

**五、一个简单可执行的日报表**

每天记录：

- 单品进货量
- 销售量
- 报损量
- 剩余量
- 次日建议采购量

公式：  
**次日采购量 = 前3天日均销量 × 1.2 - 当前库存**  
如果连续3天报损超过10%，直接砍掉这个单品或减半进货。

**六、小面积店最稳的水果组合建议**

- 香蕉：1个SKU
- 苹果：1-2个SKU
- 橙子/柑橘：1-2个SKU
- 圣女果/小黄瓜：1个SKU
- 蓝莓/猕猴桃：1个SKU
- 果切：2-3种，当日清
- 季节单品：1个，只做爆款

总计控制在**8-12个SKU**，超过就容易乱和损耗。

**一句话总结**：  
小面积便利店水果采购，**品类做窄、单品做爆、补货做勤、损耗做日清**。先跑通3-5个稳定单品，再考虑加季节品，不要一开始就追求全。
