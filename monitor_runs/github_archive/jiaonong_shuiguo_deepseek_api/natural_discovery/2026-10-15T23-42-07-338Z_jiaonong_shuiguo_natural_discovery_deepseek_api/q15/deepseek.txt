水果店遇到坏果，和供应商怎么结算或赔付，核心看**你们事先约定的验收和损耗规则**。没有统一法定标准，但行业里通常按下面几种方式处理。

## 一、先分清坏果发生在哪个环节

1. **到货验收时就发现坏果**
   - 这是最有利于水果店的情况。
   - 正常做法：当场清点、拍照、录视频，按坏果数量**直接扣减当批货款**，或要求供应商**补货/换货**。
   - 如果整批坏果比例很高，可以拒收整批或要求整批退货退款。

2. **入库后短时间内才坏**
   - 要看是否在双方约定的“保质期/售后期内”。
   - 例如约定到货后24小时、48小时内可反馈，就按约定处理。
   - 超过约定时间，供应商通常不再认，除非能证明是到货前就存在的问题。

3. **正常销售损耗**
   - 水果本身有自然损耗，比如压伤、熟过、局部霉变。
   - 这部分一般由水果店自己承担，除非合同里明确写了“包损耗”或“坏果包赔”。

## 二、常见结算和赔付方式

### 1. 按坏果数量扣款
最常见、最直接：
- 当批货款 = 合格果数量 × 单价
- 坏果部分不结算，或按比例扣减
- 例如：进100箱，发现8箱坏果，就只结92箱的钱，或要求补8箱。

### 2. 补货/换货
适合长期合作供应商：
- 坏果不扣钱，但供应商下次补同等数量好果。
- 要注意写清楚补货时间、规格、是否折价。

### 3. 按比例分摊
有些供应商会要求共同承担损耗：
- 例如坏果率在3%以内由水果店承担，超过部分供应商赔。
- 这种规则一定要事先书面或微信确认，否则事后容易扯皮。

### 4. 整批退货退款
适合坏果率高、品质严重不达标：
- 整批退回，供应商退款或换货。
- 运费谁承担要提前说清，通常是谁的责任谁承担。

### 5. 折价结算
坏果还能降价卖：
- 双方协商一个折扣价，比如按原价7折结算。
- 适合轻微瑕疵、不影响食用的果子。

## 三、实操建议：怎么谈、怎么留证据

1. **进货前先约定规则**
   - 坏果率多少以内自担，多少以上供应商赔。
   - 验收时限是几小时还是几天。
   - 是扣款、补货还是退货。
   - 最好写在订单、合同或微信里。

2. **到货当场验收**
   - 开箱抽检或全检，拍照、拍视频。
   - 记录时间、批次、数量、坏果情况。
   - 让送货员签字确认，或立刻发给供应商确认。

3. **及时反馈**
   - 不要拖几天才说，越早越好。
   - 微信、短信、通话录音都可以作为证据。

4. **协商不成怎么办**
   - 先看合同/订单约定。
   - 没有约定就按交易习惯和公平原则协商。
   - 金额大、对方不认，可以走市场监管投诉或民事诉讼，但要有证据。

## 四、一句话总结

**到货验收发现的坏果，通常由供应商承担，按坏果数量扣款、补货或退货；入库后正常损耗一般由水果店自己承担。关键不是“坏了就赔”，而是看你们事先怎么约定验收标准、时限和赔付方式。**
