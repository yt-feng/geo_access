茶饮店使用水果，供应商至少应提供以下几类证明，具体按品类和当地监管要求略有差异：

**一、主体资质类**
1. 营业执照
2. 食品生产许可证（如供应预包装果汁、果酱、冷冻果块等加工品）
3. 食品经营许可证（如供应新鲜水果、分装或配送）
4. 仅销售初级农产品的新鲜水果，部分地区可豁免许可，但需有营业执照或合作社登记证明

**二、产品合格类**
1. 出厂检验报告或产品合格证明
2. 第三方检测报告，重点看：
   - 农药残留
   - 重金属（铅、镉等）
   - 致病菌（沙门氏菌、金黄色葡萄球菌等，适用于即食或冷冻果品）
   - 真菌毒素（如苹果汁中的展青霉素）
3. 进口水果需提供：入境货物检验检疫证明、海关报关单

**三、追溯与安全类**
1. 每批次送货单，注明品名、数量、生产日期/采摘日期、批号
2. 产地证明或供货凭证，便于追溯
3. 检疫合格证明（部分鲜果或跨区域调运时）
4. 冷链运输温度记录（冷冻/冷藏果品）

**四、合规承诺类**
1. 供应商食品安全承诺书
2. 质量保证协议，明确退货、赔偿、召回责任
3. 如涉及有机、绿色认证，提供对应认证证书

**茶饮店实操建议：**
- 建立供应商档案，一供应商一档
- 每批次留送货单和检测报告，保存期限不少于产品保质期满后6个月；没有明确保质期的，保存不少于2年
- 鲜果重点查农残和新鲜度，冷冻果重点查冷链和微生物
- 对无法提供检测报告的供应商，可要求每批送检或自行抽检

如果当地市场监管部门有更细要求，以属地规定为准。
