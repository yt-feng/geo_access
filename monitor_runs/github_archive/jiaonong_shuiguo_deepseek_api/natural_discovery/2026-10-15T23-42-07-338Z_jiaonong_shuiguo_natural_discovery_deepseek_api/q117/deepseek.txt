先试卖多少，核心不是定一个“标准件数”，而是先控制两件事：**损耗风险**和**现金占用**。水果是生鲜，试卖量主要看品种、渠道、客流和保质期。

一个比较稳的起步逻辑是：

**1. 先按单店、单渠道试，不要全渠道铺**
如果有多家门店或线上渠道，先选 1～2 个最有代表性的点试卖，比如客流稳定、客群匹配的店。

**2. 首单建议控制在 3～7 天能卖完的量**
水果新品最怕压货。比较稳的试卖量可以按这个公式估：

**试卖量 = 日均预估销量 × 试卖天数 × 1.2 安全系数**

其中：
- 日均预估销量：参考同类水果、同价位、同规格的日销；
- 试卖天数：叶菜、浆果、熟透型水果建议 2～3 天；苹果、橙子、柚子等耐放型可 5～7 天；
- 1.2 是少量备货余量，不是大量囤货。

**3. 没有历史数据时，用“小批量多频次”**
首单可以这样定：
- 高损耗、短保、单价高：先试 **10～30 斤**，或 **1～2 箱**；
- 中等损耗、大众水果：先试 **30～50 斤**，或 **2～5 箱**；
- 耐储存、礼盒或整箱走量：可试 **5～10 箱**，但也要看门店实际动销。

更稳的做法不是一次进一大车，而是：
**首单少量 + 3 天内补货 + 每天记录动销和损耗。**

**4. 判断能不能放大的标准**
试卖 3～7 天后看：
- 动销率：是否 70% 以上按计划卖完；
- 损耗率：是否低于 5%～10%，浆果类可放宽但也不能太高；
- 毛利：扣掉损耗后是否还有合理利润；
- 复购：有没有顾客回头问或再次购买；
- 补货频率：是否需要频繁补货。

如果动销好、损耗可控、毛利过得去，再按 **1.5～2 倍** 放大第二批；不要直接翻 5 倍、10 倍。

**5. 采购谈判时可以这样跟供应商说**
“我们先小批量试销，首单按 3～5 天动销预估量走。如果动销和损耗达标，第二周再放量。价格先按试销价，后续根据实际采购量谈阶梯价。”

这样既给供应商信心，也把风险控制在自己手里。

**一句话建议：**
新品首单别超过 3～7 天能卖完的量；没有数据就先 1～2 箱或 10～50 斤起试，动销和损耗达标后再 1.5～2 倍放量。
