商超做会员日水果活动，供应商的准备工作核心是：**提前锁量、锁价、锁品质、锁到货节奏，并配合门店做陈列和损耗控制。** 具体可按下面几项准备。

**1. 提前确认活动方案**
- 确认活动时间、会员价、预估销量、参与门店范围。
- 确认是统采统配，还是分店直送。
- 确认促销形式：爆品直降、买赠、第二件半价、满额换购、试吃等。
- 确认供应商是否承担部分促销费用、损耗补贴或广告分摊。

**2. 锁定货源和产能**
- 对活动主推单品提前锁定产地或批发市场货源，避免活动前被其他渠道截货。
- 预估销量要按平时销量的2到5倍准备，爆品可更高。
- 提前安排采摘、分拣、打包、冷链和物流车辆。
- 避开节假日、雨天、产地缺货等风险，准备替代单品。

**3. 锁定价格和成本**
- 提前和采购确认活动供货价、正常供货价、调价机制。
- 明确包干价、到仓价、到店价，避免运费、损耗、加工费扯皮。
- 对价格波动大的水果，约定浮动区间或替代方案。
- 确认促销费用、堆头费、条码费、损耗承担比例。

**4. 保证品质和规格**
- 按商超要求的等级、果径、糖度、成熟度、包装规格供货。
- 活动前做农残检测、品质抽检，提供合格证明。
- 避免活动期间以次充好，否则容易引发客诉和退货。
- 对易损耗水果，如草莓、蓝莓、荔枝、桃，要控制成熟度和运输温度。

**5. 安排到货节奏**
- 不要活动当天集中到货，容易压车、压仓、影响上架。
- 按门店销量分批次到货，活动前1到2天先铺底，活动期间每日补货。
- 明确到货时间窗口，避开门店早高峰和收货拥堵时段。
- 对远距离门店，提前测试物流时效。

**6. 配合门店陈列和物料**
- 提供或配合准备试吃台、试吃果、价签、爆炸牌、围挡、堆头物料。
- 按商超陈列要求做预包装、小份化、组合装，方便会员拿取。
- 安排促销员或试吃员，尤其主推单品。
- 培训门店员工或促销员，讲清卖点、保存方式、食用建议。

**7. 做好损耗和售后预案**
- 提前约定坏果、烂果、压伤、退货的处理标准。
- 活动期间安排专人巡店，及时处理品质问题。
- 对滞销或临期水果，提前准备折价、加工果切、员工内购等方案。
- 保留批次记录，便于追溯。

**8. 活动后复盘**
- 统计实际销量、损耗率、退货率、客诉情况。
- 对比预估销量，找出偏差原因。
- 复盘价格、物流、陈列、试吃哪个环节拉动最大。
- 为下一次会员日调整供货量和活动单品。

简单说，供应商要提前做到：**方案确认、货源锁定、价格锁定、品质达标、分批到货、物料到位、损耗兜底、活动后复盘。** 其中最关键的是：**别断货、别爆仓、别品质翻车、别价格扯皮。**
