最该先问**售后**，其次才是**配送**，最后才是**价格**。顺序反了很容易踩坑。

原因是团购团长本质是“替邻居担责的人”：水果到货烂了、酸了、缺斤少两，邻居不会找供应商，只会找你。售后不行，你赚的那点差价不够赔口碑。

具体判断标准：

**1. 售后（第一优先）**
要问清楚这几点：
- 坏果怎么赔？是按个数赔，还是按比例赔？
- 需要拍几张照片、多久内反馈？超过时限还认不认？
- 赔的是现金、补发，还是只能抵扣下次货款？
- 是供应商直接赔给团员，还是先赔给你、你再处理？

如果对方说“生鲜难免”“特价不售后”“超过24小时不管”，这种供应商价格再低也别长期做。水果团购的利润很薄，一次烂果潮就能把几单利润吃光。

**2. 配送（第二优先）**
问：
- 送到小区还是送到你手上？谁卸货？
- 几点到？能不能配合你晚上发团、第二天早上到？
- 破损、迟到、漏送怎么算？
- 冷链水果有没有保温箱/冰袋？

配送不稳，售后问题会成倍增加。尤其夏天，配送晚半天，售后能翻倍。

**3. 价格（第三优先）**
价格当然要看，但要放在“同等售后和配送条件下”比。
要问：
- 报价含不含运费、包装费、损耗？
- 起送量多少？能不能混批？
- 今天报价明天变不变？锁价多久？
- 次品率大概多少？

低价但次品率高的供应商，实际成本往往更高。

**一句话结论：**
先筛“售后敢兜底”的，再筛“配送稳”的，最后在剩下的里面比价格。只比价格的团长，最后大多是在用售后和口碑补贴低价。
