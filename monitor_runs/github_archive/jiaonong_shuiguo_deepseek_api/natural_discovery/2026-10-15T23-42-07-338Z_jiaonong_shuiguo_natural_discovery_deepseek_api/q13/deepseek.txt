小水果店做附近小区团购，水果供应商最好能提供下面这些服务。重点不是“能不能供货”，而是能不能帮你把团购的**损耗、时效、售后、价格波动**这几件事兜住。

**1. 稳定供货与分级报价**
- 能按团购批次稳定供货，而不是今天有、明天没。
- 支持按品质分级报价，比如普通果、精品果、团购专供果。
- 对爆品能提前锁量，避免开团后断货。
- 价格最好有短期保护，比如当天报价当天有效，或承诺团购周期内不随意涨。

**2. 小批量、多频次配送**
- 支持小批量起送，适合小区团购先试水。
- 能按你设定的截单时间次日或当日配送到店。
- 最好能分拣好，按小区或按团购订单打包。
- 如果你要做预售，供应商要能配合“今天订、明天到”的节奏。

**3. 品控与标准化**
- 有基本品控：无严重磕碰、腐烂、以次充好。
- 能提供规格标准，比如单果重量、箱重、个数、成熟度。
- 对团购常见爆品能长期保持同一品质，不然小区复购会掉。
- 最好支持坏果包赔或按比例补损。

**4. 售后与损耗承担**
- 坏果、烂果、缺斤少两有明确赔付标准。
- 支持拍照理赔，流程简单，不用反复扯皮。
- 能补发、退款或下次供货抵扣。
- 对团购这种集中售后，供应商响应要快，最好当天处理。

**5. 价格与账期支持**
- 支持团购价、阶梯价，量越大价格越有优势。
- 能接受短期账期或押金制，减轻你垫资压力。
- 对高频复购品能给稳定底价，别每次都要重新谈。
- 如果能提供建议零售价和团购价区间，会更省事。

**6. 包装与物料支持**
- 提供适合小区自提的包装，比如纸箱、网套、保鲜袋。
- 能贴标、分装、按团购套餐打包。
- 如果需要，能提供简易宣传图、文案或产品卖点。
- 包装要能扛住短途运输，不然到小区就压坏了。

**7. 数据与对账支持**
- 每批货有清晰单据：品名、规格、数量、单价、金额。
- 支持微信、表格或系统对账，别只靠口头。
- 能提供每日/每周供货清单，方便你核库存和算利润。
- 如果做预售，最好能按订单汇总发货，减少你二次分拣。

**8. 选品与季节建议**
- 能告诉你当下什么水果适合团购：耐运输、易分装、复购高。
- 能提前提醒季节转换、价格波动、产区切换。
- 能配合做爆品组合，比如“9.9元引流款+利润款”。
- 对临期或尾货，能提前说明，不要混在正价货里。

**9. 配送时效与应急能力**
- 能保证截单后按时到店，不耽误小区自提。
- 遇到缺货能提前通知，并给替代方案。
- 节假日、天气异常时也有应急配送安排。
- 最好有固定对接人，出问题能马上找到人。

**10. 合作门槛与试单机制**
- 支持先试单，不用一上来就压大量库存。
- 能接受小水果店的低起订量。
- 试单后再谈长期价格和账期。
- 有明确退换货规则，而不是出了问题才临时定。

**你筛选供应商时，重点问这8个问题：**
1. 起订量多少？能不能小批量多频次送？
2. 团购爆品能不能锁量锁价？
3. 坏果怎么赔？多久处理？
4. 能不能按小区或订单分拣打包？
5. 截单后多久能到店？
6. 有没有分级报价和团购专供规格？
7. 能不能试单？试单政策是什么？
8. 对账和售后对接人是谁？

**最适合小水果店做小区团购的供应商，通常不是最便宜的，而是：**
- 品质稳定
- 配送准时
- 售后爽快
- 能小批量配合
- 价格透明

如果你刚开始做，建议先找1-2家本地批发商或产地供应商试单，重点测试**坏果率、到货时效、售后响应**。这三项过关，再谈长期合作和账期。
