优先谈 **账期**，其次 **售后**，最后 **配送**。  
但前提是：先判断你现在最怕的是“现金流被拖死”、还是“货损扯皮”、还是“门店缺货”。

可以按这个顺序判断和谈：

1. **账期最值得优先谈**
   - 水果是高频、易损耗、价格波动大的品类，长期合作里账期直接决定你的现金流压力。
   - 如果供应商要求现款现货或账期很短，你规模越大越容易被压资金。
   - 优先争取：  
     - 从现结改为 **7天/15天/30天**  
     - 月结固定日  
     - 首期先小批量试账期，稳定后延长  
   - 判断标准：  
     - 你能否用账期覆盖从进货到回款的时间差。  
     - 如果账期谈不下来，其他条件再好也可能把你拖死。

2. **售后第二优先**
   - 水果非标、损耗高，售后规则不清，长期合作一定扯皮。
   - 重点不是“能不能退”，而是 **怎么判定、多久响应、怎么补**。
   - 优先谈清楚：  
     - 坏果率标准：按箱、按斤、按件还是按金额  
     - 到货24小时内反馈有效，还是48小时  
     - 补货、退款、下次抵扣，哪种方式  
     - 缺斤少两、规格不符、成熟度不够是否算售后  
   - 判断标准：  
     - 售后规则越模糊，后面越容易变成你单方面承担损耗。

3. **配送第三优先**
   - 配送重要，但通常可以通过换物流、自提、调整下单时间部分替代。
   - 真正要谈的是：  
     - 固定送达时间  
     - 迟到、漏送、错送的赔付  
     - 冷链/保鲜责任  
     - 起送量、配送费、临时加单怎么算  
   - 判断标准：  
     - 如果配送不稳定直接影响你销售和损耗，那它要提到售后前面。  
     - 如果配送只是慢一点但不致命，就放在第三。

**最实用的谈判顺序：**
- 先谈账期：争取月结或至少15天。
- 再谈售后：把坏果、缺货、规格不符的赔付写进合作规则。
- 最后谈配送：固定时间、固定频次、迟到处理。
- 如果供应商很强硬，可以用“账期换价格”“账期换独家”“账期换起订量”来交换。

**一句话结论：**
长期合作先谈账期，因为它影响你的命；再谈售后，因为它影响你的利润；最后谈配送，因为它影响你的效率。  
但如果配送直接导致你断货或大量损耗，就把配送提到售后前面。
