茶饮店用香蕉做饮品或甜品，采购熟度控制的核心是**按用途分等级采购，不要只买一个熟度**。因为香蕉从青到过熟变化很快，同一批货在不同天数会呈现完全不同的风味和操作性能。

## 先按用途定熟度

**1. 做香蕉奶昔、冰沙、香蕉牛奶**
- 目标熟度：**7～8成熟**，表皮黄、带少量青肩，捏起来有弹性但不软塌。
- 原因：太生涩味重、香气弱；太熟容易氧化发黑、甜腻，打出来颜色差。
- 操作建议：到店后常温放1～2天再使用，冷藏会抑制熟化但也会让表皮变黑。

**2. 做香蕉果泥、酱料、烘焙夹心**
- 目标熟度：**8～9成熟**，表皮全黄、出现少量糖斑，果肉软但不变水。
- 原因：这时甜度和香气最足，压泥顺滑，不需要额外加太多糖。
- 操作建议：去皮后尽快加柠檬汁或维C护色，冷藏保存不超过24小时。

**3. 做香蕉块、装饰、水果茶里的果肉**
- 目标熟度：**6～7成熟**，黄中带青，果肉硬挺。
- 原因：太熟切块易烂、泡水后浑浊；偏生一点能保持形状。
- 操作建议：切片或切块后现做现用，不建议长时间浸泡。

**4. 做炸香蕉、烤香蕉、焦糖香蕉**
- 目标熟度：**7～8成熟**，外形完整、内部开始变甜。
- 原因：太熟下锅易散，太生口感硬且不甜。

## 采购时的具体控制方法

**分级下单**
- 把需求拆成“即用型”和“催熟型”。
- 即用型：直接买7～8成熟，到店当天或次日用。
- 催熟型：买5～6成熟，常温存放2～4天，按每天用量分批催熟。

**看外观判断**
- 5～6成熟：绿黄相间，果肉硬。
- 7成熟：黄为主，两端略青，轻捏有弹性。
- 8成熟：全黄，少量糖斑，捏起来软。
- 9成熟以上：大量黑斑，果肉软烂，适合当天做泥，不适合切块。

**控制到货频率**
- 香蕉熟化快，建议**每2～3天到货一次**，不要一次囤一周量。
- 夏天熟得更快，可缩短到1～2天；冬天可适当拉长。

**分开存放**
- 未熟香蕉：常温、阴凉、通风，不要冷藏。
- 已熟香蕉：冷藏可延缓过熟，但表皮会变黑，不影响果肉使用。
- 想加速催熟：和苹果或梨放同一纸袋，利用乙烯催熟。
- 想减缓：单独放，减少挤压，避免堆叠太厚。

**每天分拣**
- 每天挑出过熟香蕉，优先做果泥、酱料或烘焙，不要继续放。
- 出现渗液、酸味、霉点直接废弃，不要用于饮品。

## 简单可执行的采购标准

| 用途 | 采购熟度 | 到店后可用时间 |
|---|---|---|
| 奶昔/冰沙 | 7～8成熟 | 1～2天内 |
| 果泥/酱料 | 8～9成熟 | 当天或次日 |
| 切块/装饰 | 6～7成熟 | 当天 |
| 炸烤香蕉 | 7～8成熟 | 1～2天内 |

**一句话总结：** 不要按“香蕉”统一下单，要按“奶昔用、果泥用、切块用”分别定熟度；到店后每天分拣，过熟的转做泥，偏生的继续催熟，才能稳定出品、减少损耗。
