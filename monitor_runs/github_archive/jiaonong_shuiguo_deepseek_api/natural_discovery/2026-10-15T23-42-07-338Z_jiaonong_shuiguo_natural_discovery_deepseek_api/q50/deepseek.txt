优先看 **出汁率**，其次才是甜度。原因很直接：

1. **出汁率决定你实际能卖出多少杯、成本能不能控住**
   - 菠萝在茶饮里通常不是“直接吃果肉”为主，而是做菠萝果茶、菠萝气泡、菠萝冰茶、菠萝冻等。
   - 如果出汁率低，你买回来一大箱，真正能用的果汁/果泥少，损耗、人工、冷链、仓储都摊进去，单杯成本会明显上升。
   - 出汁率不稳定，还会导致同一款产品今天偏浓、明天偏淡，出品标准化很难做。

2. **甜度可以调，出汁率很难“救”**
   - 甜度不够，可以用糖浆、果酱、风味糖、菠萝浓缩汁补。
   - 但出汁率低，你没法凭空把汁变多；硬加水会稀释风味，加浓缩汁又会改变口感和成本结构。
   - 所以从经营角度看，出汁率是“硬约束”，甜度是“软约束”。

3. **但甜度也不能完全不看**
   - 如果甜度太低、酸涩感太重，即使出汁率高，也会增加你调味成本，甚至影响风味干净度。
   - 如果甜度太高，可能适合纯果茶，但不适合做需要茶感、气泡感、清爽感的产品。
   - 所以更准确的标准是：**先筛出汁率达标，再在达标原料里选甜酸比适合你产品定位的。**

**实际采购建议：**
- 先定你的产品类型：
  - 做**清爽型果茶**：出汁率优先，甜度中等、酸感清晰更好。
  - 做**浓郁型果泥/冰沙**：出汁率和果肉感都要看，甜度可以稍高。
  - 做**低成本走量款**：出汁率权重最高，甜度靠糖浆补。
- 让供应商提供或自己测：
  - 出汁率/出泥率
  - 糖度（Brix）
  - 酸度
  - 香气表现
  - 解冻后稳定性、是否易褐变、是否分层
- 如果只能二选一：**选出汁率高的。**  
  因为甜度是配方问题，出汁率是原料和成本问题。
