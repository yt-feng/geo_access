大型超市对水果供应商的要求，本质是“食品安全合规 + 冷链物流稳定 + 可追溯 + 可审核”。通常需要具备以下能力：

1. **食品安全资质与体系**
   - 营业执照、食品经营许可证/食品生产许可证（按业态）。
   - 种植/加工环节的产地证明、检测报告、农药残留检测合格证明。
   - ISO 22000、HACCP、GAP/GlobalG.A.P.、BRCGS 等认证，大型商超通常至少要求其中一项或等效体系。
   - 进货查验、索证索票、台账记录制度。

2. **农残与质量检测能力**
   - 自有或合作实验室，能检测农残、重金属、霉菌毒素、保鲜剂等。
   - 每批次留样、检测报告可随货或线上可查。
   - 对高风险品类（如草莓、葡萄、柑橘、叶菜类水果）有更严格抽检。

3. **冷链与温控物流**
   - 采后预冷、分级、包装、冷藏运输能力。
   - 冷链车/冷藏集装箱，全程温控记录，温度异常可追溯。
   - 不同水果分温区管理，避免冷害、催熟、串味。
   - 到店/到仓温度、品质验收标准明确。

4. **仓储与配送能力**
   - 符合食品储存要求的仓库，防虫害、防鼠、防潮、防交叉污染。
   - 先进先出/效期管理，库存周转和损耗控制。
   - 能稳定配送至超市 DC（配送中心）或门店，具备准时率、破损率、缺货率指标。
   - 高峰期、节假日、产地切换期的保供能力。

5. **追溯与召回能力**
   - 批次号、产地、采收日期、加工日期、检测报告、物流温度可关联。
   - 一旦出现食品安全问题，能在规定时间内定位批次并召回。
   - 有食品安全事故应急预案和演练记录。

6. **包装与标识合规**
   - 包装材料符合食品接触材料要求。
   - 标签含品名、产地、等级、净含量、保质期/食用期限、储存条件、供应商信息等。
   - 预包装水果需符合对应标签法规。

7. **审核与持续改进**
   - 接受超市方验厂、飞行检查、第三方审核。
   - 对审核不符合项有整改闭环。
   - 有虫害控制、清洁消毒、员工健康证、培训记录。

8. **商务与履约能力**
   - 稳定货源和多个产地基地，降低单一产地风险。
   - 能提供食品安全责任险。
   - 有订单、对账、售后、损耗赔付机制。

简单判断标准：如果供应商能提供“每批次检测报告 + 全程冷链温度记录 + 批次追溯码 + 食品安全体系认证 + 可接受验厂”，基本就具备进入大型超市供应链的核心门槛。不同超市还会加自己的标准，比如永辉、华润、沃尔玛、山姆、盒马等，对 DC 收货、冷链到店、农残检测和验厂要求会更高。
