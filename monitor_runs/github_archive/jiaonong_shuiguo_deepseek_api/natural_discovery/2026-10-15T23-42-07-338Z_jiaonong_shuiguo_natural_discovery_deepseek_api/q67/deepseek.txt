批发商在谈水果品牌代理时，区域保护和串货是必问的核心条款，问得越具体越能减少后续纠纷。以下是可直接使用的提问框架。

## 一、区域保护怎么问

**1. 区域界定**
- 我的代理区域是按省、市、区县，还是具体到某些渠道（如商超、电商、批发市场）划分？边界要写进合同吗？
- 区域内是否还有别的代理商？如果有，怎么划分地盘，是按品类还是按渠道？
- 品牌方自己或直营团队会不会在我区域内直接卖货？如果会，怎么保护我？

**2. 独家性**
- 我拿的是独家代理还是非独家？独家的话有没有销量考核门槛，达不到会不会被取消？
- 区域内出现第二家代理，品牌方怎么处理，我有没有优先权或补偿？

**3. 保护期限**
- 区域保护有效期多久？续约条件是什么？
- 如果我完成或超额完成任务，保护范围能不能扩大？

## 二、串货（跨区销售）怎么问

**1. 认定标准**
- 怎么定义串货？是货物流入非授权区域就算，还是以销售行为发生地为准？
- 同品牌不同产地的货互相流通算不算串货？

**2. 处罚与举报机制**
- 发现串货后，品牌方有没有明确的处罚标准（罚款、断货、取消代理资格）？
- 举报流程是什么？需要什么证据（物流单、发票、监控）？多久给答复？
- 串货方被处罚后，对我有没有补偿或价格保护？

**3. 价格体系**
- 品牌方给各区域供货价是否一致？如果不一致，低价区域串货怎么防？
- 有没有全国统一零售指导价或最低限价？线上平台（拼多多、直播）价格怎么管？

**4. 线上渠道**
- 品牌方自己做不做电商？如果做，发往我区域的订单算不算串货？
- 授权电商店铺之间、电商与线下之间怎么划界？

## 三、谈判时建议写入合同的条款

| 事项 | 建议条款 |
|------|----------|
| 区域范围 | 明确到地理边界+渠道类型 |
| 独家性 | 独家/非独家，考核指标，违约后果 |
| 串货认定 | 定义、举证责任、处理时限 |
| 处罚机制 | 罚款金额、断货、取消资格 |
| 补偿机制 | 串货造成的损失如何赔 |
| 价格保护 | 供货价一致性、限价规则 |
| 争议解决 | 仲裁或诉讼地，处理周期 |

## 四、实操提醒

1. **别只听口头承诺**，所有保护条款必须落到合同文字里。
2. **问清品牌方现有代理结构**，如果已经有好几家在抢区域，说明保护可能形同虚设。
3. **要求提供历史串货处理案例**，看品牌方是否真的执行过处罚。
4. **水果有季节性和损耗特点**，还要问清：滞销货能否退换、跨区调货是否算串货、临期货处理规则。
5. **保留证据**：进货单、物流记录、区域销售数据，万一发生纠纷时是维权依据。

如果品牌方对以上问题含糊其辞、拒绝写进合同，通常意味着区域保护执行力弱，代理风险较高，需要谨慎评估。
