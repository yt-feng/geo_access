要，但不能只靠“固定产地/批次”这一个动作。更准确的做法是：**固定的是风味标准和验收指标，产地和批次作为达到标准的手段来管理。**

### 为什么不能只固定产地或批次

- 水果是农产品，同一产地不同年份、季节、果园、成熟度都会有差异。
- 同一批次如果储存、运输、催熟没做好，风味照样波动。
- 只固定一个产地或供应商，遇到减产、涨价、品质下滑时，容易被卡脖子。
- 茶饮店最终要的是“杯杯稳定”，不是“采购单看起来稳定”。

### 建议的采购策略

**1. 先定风味标准，再谈产地**

把每种水果的关键指标写清楚，比如：

- 糖度范围
- 酸度范围
- 香气类型
- 出汁率/出肉率
- 颜色
- 成熟度
- 是否有异味、发酵味

例如百香果不能只写“广西产”，而要写“糖度 14–16、酸度适中、香气浓、无发酵味”。

**2. 固定“核心供应批次”作为基准样**

每季度或每个产季保留一份标准样，新到货和标准样做对比。门店或中央厨房可以快速做感官判断：香气、酸甜、颜色、口感。

**3. 主供应商 + 备用供应商**

- 主供应商固定产地或产区，保证大部分稳定供应。
- 备用供应商选择不同产区，但必须能过同一套验收标准。
- 这样既稳定，又不会被单一产地绑死。

**4. 按产季切换，而不是全年硬固定**

很多水果不同产区、不同季节品质差异很大。可以制定“产季切换表”：

- 几月到几月用 A 产区
- 几月到几月用 B 产区
- 切换前先做小批量测试，再逐步替换

**5. 采购合同里写清验收和退换规则**

包括糖酸度、成熟度、腐烂率、规格、到货温度、抽检方式。不达标就退货或降级使用，避免“产地对了但货不行”。

**6. 门店端用配方和操作兜底**

即使原料有轻微波动，也可以通过：

- 标准糖浆比例微调
- 水果预处理统一化
- 每日风味抽检
- 员工盲测

来减少出品差异。

### 结论

**要固定，但固定的是“标准 + 基准样 + 验收流程”。产地和批次可以相对固定，但必须保留备用方案和产季切换机制。**

如果只固定产地或批次，却不做验收和风味校准，水果一波动，茶饮店还是会被动。
