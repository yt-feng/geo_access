节假日水果需求暴增，核心矛盾是“短时间、大单品、高损耗”，锁定货源要从**提前锁量、锁价、锁品质、锁物流**四条线同时下手。下面给一套可执行的打法。

## 一、先预测：把“暴增”量化，而不是凭感觉

1. **拉历史数据**
   - 过去2-3年同节假日前15天、节中、节后的日销量/单品。
   - 重点看增长率，而非绝对值：如礼盒装、车厘子、砂糖橘、苹果、葡萄等。
2. **按品类分层**
   - 引流爆品：苹果、香蕉、橙子、砂糖橘（量大、价稳）。
   - 利润爆品：车厘子、阳光玫瑰、蓝莓、进口提子（价高、波动大）。
   - 礼盒/送礼：精品礼盒、进口水果组合。
3. **定“保底量+弹性量”**
   - 例如预估销售额100万，按保底70%、弹性30%下达。
   - 弹性部分靠预售、临时补货、替代品兜底。

## 二、提前锁量：用“订单+定金”绑定供应商

1. **提前30-45天下意向订单**
   - 对核心爆品锁定基础量，支付10%-30%定金。
   - 合同写明：可追加量、可调规格、可分批提货。
2. **多源采购，不押单一供应商**
   - 主供应商占60%-70%，备选2-3家占30%-40%。
   - 产地直采+批发市场+进口商组合，避免断供。
3. **签“浮动价+封顶价”**
   - 约定价格随行就市，但设最高限价，防止节前坐地起价。
4. **锁定冷链和加工能力**
   - 提前预订冷库、分拣、打包、配送车辆。
   - 节假日人工紧张，提前签临时用工或外包协议。

## 三、锁品质：把验收标准写进合同

1. **明确规格**
   - 单果重、果径、糖度、成熟度、包装方式、损耗率上限。
2. **约定验收和赔付**
   - 到货抽检，不合格可拒收、换货或扣款。
   - 约定“到店损耗率超过X%由供应商承担”。
3. **分批到货**
   - 节前3天集中到货风险大，按日分批，减少库存积压和损耗。

## 四、锁物流：节假日最容易被忽视的断点

1. **提前确认运力**
   - 产地直发、冷链车、城市配送都要提前排期。
   - 节假日高速拥堵、司机返乡，至少预留20%运力冗余。
2. **设置中转仓/前置仓**
   - 大区仓提前备货，门店按需补货，避免门店爆仓。
3. **应急预案**
   - 主线路中断时，启用备用供应商、备用物流、周边批发市场补货。

## 五、门店端配合：锁住货源还要卖得动

1. **预售/团购**
   - 节前一周开礼盒预售，用订单反推采购量，降低库存风险。
2. **动态定价**
   - 节前保毛利，节中冲销量，节后及时清仓。
3. **替代品策略**
   - 某爆品缺货时，用同价位、同场景水果替代，避免客流流失。
4. **控损耗**
   - 小批量、多频次补货；易损品先陈列先销售；临期做果切、果汁、组合装。

## 六、一张执行清单（可直接照做）

| 时间节点 | 动作 |
|---|---|
| 节前45天 | 历史数据复盘，定爆品和预估量 |
| 节前30天 | 与主供应商签意向订单，付定金，锁价锁量 |
| 节前20天 | 确认备选供应商、冷链、仓配、临时工 |
| 节前10天 | 开预售/团购，按订单调整采购 |
| 节前3-7天 | 分批到货，抽检入库，门店陈列准备 |
| 节中 | 每日复盘销量，动态补货，启动替代品 |
| 节后 | 清库存，复盘供应商履约，结算赔付 |

## 关键原则

- **不要临时找货**：节假日临时采购，价格高、品质差、物流没保障。
- **不要只锁一家**：主备结合，才能抗风险。
- **不要只锁量不锁价**：量价一起锁，否则成本失控。
- **不要忽略损耗**：水果毛利薄，损耗吃掉利润，合同里必须写清责任。
