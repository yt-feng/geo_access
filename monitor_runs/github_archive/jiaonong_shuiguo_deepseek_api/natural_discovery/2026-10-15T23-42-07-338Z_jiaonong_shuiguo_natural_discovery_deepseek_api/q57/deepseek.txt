**结论：绝大多数餐饮连锁，水果优先“中央厨房/配送中心统一收货”，而不是门店分开收货。**  
但如果你们的门店数量少、水果品类以整箱耐储水果为主、且没有真正意义上的中央厨房，则门店直收也可能更划算。

下面给你一个可判断的标准。

## 一、为什么通常中央厨房统一收货更好

### 1. 品质标准更容易统一
水果最大的问题是成熟度、规格、糖度、外观不稳定。  
中央厨房统一收货可以做到：

- 统一验收标准：规格、成熟度、净重、损耗率
- 统一拒收标准：烂果率、压伤率、到货温度
- 统一分级：直接出品、切果、榨汁、装饰用

如果让门店各自收货，同一批水果可能A店收、B店拒，最后变成供应商扯皮。

### 2. 采购议价能力更强
总部/中央厨房统一收货，等于把各门店需求集中成一个采购量。  
对供应商来说：

- 订单更稳定
- 配送更集中
- 损耗责任更清晰

通常能拿到更好的价格、账期和售后。门店分散收货会削弱总部议价权，甚至出现门店私下换供应商。

### 3. 食品安全和追溯更可控
水果涉及农残、霉变、冷链、切果后微生物风险。  
统一收货可以做：

- 批次留样
- 供应商资质统一审核
- 到货检测或快检
- 问题批次统一召回

门店分开收货时，批次追溯往往断掉，一旦出问题很难定位。

### 4. 减少门店操作负担
门店核心任务是销售和服务，不是验收、分拣、催货、退换货。  
统一收货后，门店只负责：

- 按需领用/下单
- 到店复核数量
- 反馈品质异常

这能减少店长和员工被供应商、物流、损耗问题牵扯。

### 5. 更利于控制损耗和库存
中央厨房可以根据各店销售数据做统一下单、分拨。  
尤其是切果、果切、饮品用水果，中央厨房还能做：

- 集中催熟
- 集中分拣
- 集中切配
- 按门店销量精准配送

门店单独收货容易各店库存不均：有的烂掉，有的缺货。

## 二、什么情况下门店分开收货更好

不是所有情况都适合统收。以下场景可以考虑门店直收：

1. **门店数量少**：比如3—5家，且距离近，中央厨房不成熟。
2. **水果以整箱耐储为主**：如苹果、橙子、西瓜，不需要精细分级。
3. **配送半径大、冷链弱**：统一收货后再二次配送，反而增加压伤和时效问题。
4. **门店有强现场验收能力**：店长能稳定判断成熟度和品质。
5. **供应商本身能直配到店且价格更优**：总仓中转反而增加成本。
6. **水果是门店现制饮品/甜品核心卖点**：需要门店根据现场销售灵活调整成熟度。

但即使门店直收，也建议总部统一控供应商、控价格、控标准，门店只执行收货。

## 三、更优的常见模式：总部统采 + 中央厨房统收 + 门店按需领用

这是大多数连锁餐饮的推荐模式：

- **总部**：定供应商、定标准、定价格、定账期
- **中央厨房/配送中心**：统一收货、验收、分拣、催熟、切配、配送
- **门店**：下单、收货复核、反馈品质、按标准存放使用

如果水果不需要切配，也可以简化为：

- **总部统采统收，配送中心越库配送**
- 或 **总部统采，供应商直送门店，但总部统一结算和考核**

## 四、判断公式

你可以用这4个问题判断：

| 判断项 | 偏向中央厨房统收 | 偏向门店分开收货 |
|---|---|---|
| 门店数量 | 多，10家以上 | 少，3—5家以内 |
| 水果用途 | 切果、榨汁、甜品、标准化要求高 | 整果售卖、简单摆盘 |
| 损耗和食安风险 | 高 | 低 |
| 配送条件 | 有冷链、有配送中心 | 无冷链、配送分散 |

如果门店多、水果加工多、食安要求高，选中央厨房统收。  
如果门店少、水果耐储、配送条件差，门店直收更现实。

## 五、直接建议

**建议采用：总部统一采购 + 中央厨房统一收货 + 门店按需领用。**  
但保留一个例外通道：对于极少数必须现场判断成熟度的水果，比如某些即食牛油果、芒果、草莓，可以由总部指定供应商直送门店，但必须执行总部统一验收标准和统一结算。

一句话：  
**水果采购权要集中，收货权尽量集中；如果配送条件不允许，至少做到“总部控标准、控供应商、控价格”，门店只负责执行验收。**
