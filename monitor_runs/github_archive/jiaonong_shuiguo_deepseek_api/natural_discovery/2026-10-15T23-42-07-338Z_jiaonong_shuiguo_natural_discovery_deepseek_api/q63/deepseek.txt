判断哪个规格更容易出货，核心不是看“哪个规格最好”，而是看**你的下游客户是谁、他们怎么用菠萝**。批发环节的“好出货”通常取决于周转速度、损耗率和价格接受度。

给你一套可执行的判断方法：

**1. 先按下游渠道分**
- **水果店/社区团购**：偏好中等规格，单果重量适中、外观整齐，顾客按个买，太大不好卖，太小显得不划算。
- **餐饮/果汁店/烘焙**：偏好大果或固定规格，出肉率高、加工方便，对颜值要求低，对价格和稳定性要求高。
- **路边摊/流动商贩**：偏好小果或中果，进货成本低、好搬运，但要求价格便宜。
- **超市**：偏好规格统一、外观好，等级要求高，但结账周期可能长。

**2. 看三个硬指标**
- **周转天数**：同样进一车，哪个规格能在3天内卖完，哪个就是好出货。
- **损耗率**：菠萝容易熟过头、压伤。大果虽然出肉多，但如果卖得慢，损耗会吃掉利润。
- **价格带接受度**：你的客户是走量还是走利润。走量客户对单价敏感，中果、小果往往更快。

**3. 用最小测试验证**
不要凭感觉压货。选2-3个规格，各进少量，记录：
- 到货后第1天、第2天、第3天分别卖出多少
- 哪些客户主动问哪个规格
- 哪个规格退货、投诉、压货最多

连续测2-3批，就能看出哪个规格周转最快。

**4. 常见规律**
- 如果做**批发给水果摊**：中果通常最稳，因为单价和卖相平衡。
- 如果做**餐饮供货**：大果更容易出货，因为出肉率高。
- 如果做**低价走量**：小果更快，但利润薄。
- 如果做**精品超市**：统一规格的中大果更好，但门槛高。

**5. 最终判断标准**
不是“哪个规格最大”，而是：
**哪个规格在你现有客户手里，周转最快、损耗最低、回款最稳。**
