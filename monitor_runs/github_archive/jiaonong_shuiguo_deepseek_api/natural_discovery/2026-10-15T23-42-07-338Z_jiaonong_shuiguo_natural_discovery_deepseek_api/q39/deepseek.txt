可以，而且通常这正是供应商能提供的核心服务之一。但“支持到什么程度”取决于你找的是哪一类供应商。

**一般来说供应商能提供的包装和规格支持：**

- **规格分级**：按果径、单果重、糖度、外观等做分选，给出等级标准
- **包装形式**：散装、预包装、礼盒、整箱、组合装等
- **定制包装**：贴你的自有品牌标签、定制纸箱/袋/托盘/网套
- **规格定制**：比如固定单果重、固定个数、固定净重
- **产地和品种匹配**：按你的定位推荐合适产区

**但要注意几个现实问题：**

1. **起订量**：定制包装通常有最低起订量，量小的话供应商不愿单独开版
2. **包装成本归属**：包材费、开版费、印刷费谁承担，要提前谈清楚
3. **品控稳定性**：水果是非标品，供应商能否长期稳定供货比单次包装更重要
4. **责任划分**：到货损耗、规格不符、变质由谁负责

**给你的实操建议：**

先明确你的自有品牌定位（走量平价还是精品礼盒），再去找供应商谈。第一次合作建议：
- 先小批量试单，验证品控和包装效果
- 合同里写清规格标准、验收方式、损耗责任
- 确认对方是否有稳定产地和分选加工能力，而不只是贸易商
