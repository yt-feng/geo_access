判断一批香蕉，核心是 **“看颜色、摸硬度、闻气味、查果柄和棱角、抽箱试催熟”**。不要只看表面颜色，香蕉批发最容易踩的坑是：表面好看，里面已经软伤、发黑、断指或催熟过头。

### 1. 先看颜色
- **全青、硬**：适合长途运输和贮藏，但要看有没有“青得发黑”的冻伤或闷伤。
- **青黄相间**：通常处于催熟前期或中期，适合批发后短期出熟。
- **黄多青少**：接近可售，但坏果风险开始升高，适合快进快出。
- **全黄、带糖斑**：熟度高，货架期短，适合立即分销，不适合再压货。
- **发暗黄、灰黄、褐斑多**：可能过熟或受过冷害/闷伤，坏果风险高。

### 2. 摸硬度和弹性
- 轻捏果身：**硬实**说明熟度低；**微软有弹性**说明正在熟；**一按就陷、发软**说明过熟或内部已伤。
- 摸整把：如果中间软、两头硬，或局部明显软塌，可能是运输挤压、闷箱或病斑。
- 注意：香蕉怕冷，**受冷害后不一定马上变色，但会发硬、发暗、后熟异常**。

### 3. 闻气味
- 正常：淡淡青味或果香。
- 催熟过度/过熟：有明显酒味、酸味、发酵味。
- 闷伤/腐烂：有霉味、酸臭味。
- 有酒味的一批货，通常已经开始内部变质，风险很高。

### 4. 查果柄、棱角和表皮
- **果柄**：发黑、发霉、干缩、断裂多，说明不新鲜或运输受损。
- **棱角**：香蕉越熟，棱角越圆；青硬时棱角明显。棱角模糊、果身发软，通常熟度高。
- **表皮**：
  - 少量芝麻斑：正常，可能接近最佳食用期。
  - 大片黑斑、水渍斑、凹陷斑：坏果风险高。
  - 擦伤、压伤、裂口：容易从伤口开始腐烂。
- **果指连接处**：如果连接处发黑、发霉，整把容易传染。

### 5. 抽箱检查，不要只看上层
批发看货一定要：
- 随机抽几箱，最好抽**底层和中层**。
- 看箱内是否有**水汽、霉味、汁液**。
- 看是否有**断指、压烂、发黑、霉变**。
- 看整箱成熟度是否均匀，有没有“上熟下生”或“外熟内生”。
- 估算坏果率：随便取一箱，数100根或整箱分拣，坏果超过5%就要压价或谨慎；超过10%风险已经很高。

### 6. 判断熟度和用途
- **青硬、无伤**：可囤，适合长途或自己催熟。
- **青黄、微软**：适合计划2-4天内出货。
- **黄熟、少量斑点**：适合1-2天内快速分销。
- **全黄、软、酒味、黑斑多**：只能当天处理，坏果风险高。

### 7. 简单实操判断法
拿一根代表性的香蕉：
1. 看颜色是否均匀；
2. 轻捏果身，是否局部软陷；
3. 闻果柄和果身，有无酒酸味；
4. 掰开看果肉，是否发黑、透明、水化；
5. 再看同箱其他果，是否同样问题。

如果**颜色黄但捏着软、闻着有酒味、果柄发黑**，基本可以判定熟过头或内部变质，不建议按好货收。

### 8. 收货建议
- 要求供应商说明：**采摘时间、催熟情况、运输温度、到货时间**。
- 优先选**成熟度均匀、果柄青绿、果身硬实、无酒味、无霉斑**的货。
- 对高风险货：先抽箱分拣，按坏果率谈价，不要整批按统货收。
- 入库后：**青蕉可适当通风、避免低温；熟蕉尽快出货，别闷箱**。香蕉对低温敏感，一般不宜长期放在过低温度环境。

一句话：**青硬无伤可囤，黄软有酒味快出，黑柄黑斑霉味压价或拒收。**
