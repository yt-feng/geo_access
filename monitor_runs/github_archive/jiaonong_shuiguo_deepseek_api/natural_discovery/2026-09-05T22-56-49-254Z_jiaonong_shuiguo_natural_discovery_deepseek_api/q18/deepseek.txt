超市采购香蕉要避免太生或太熟，可以记住这三点：

1. **看颜色和斑点**：不要选整体还是**通体绿色**（太生）的，也不要选**大部分变黑、有大量褐色斑点**（过熟）的。最佳状态是**果皮呈均匀黄色、带少量绿色边缘**，或者**表面有一点点芝麻大小的褐色斑点**（这代表刚好熟透、香甜）。

2. **捏手感**：轻轻捏一下香蕉的**中部和两端**。太生的香蕉**硬邦邦、捏不动**；太熟的则**软塌塌、像空心的**。理想的香蕉是**轻轻一按略有弹性、但不凹陷**。

3. **看果柄和连接处**：果柄如果新鲜翠绿，说明刚采摘不久，可能偏生；果柄如果是深褐色、干枯，往往偏熟。如果要在未来2-3天内吃完，就选果柄稍黄、微微有弹性的；如果打算囤好几天，可以选稍带绿边的。

另外，**不要选有瘀伤、裂口或表面有发黑霉斑的香蕉**，这类虽然有时表面看不出来，但内心容易变质。

**最后一招**：如果超市整把装好，可以摸一摸最中间那根（通常最熟），如果中间的都熟了，其他会更安全。如果允许，直接买**不同成熟度的几把**搭配，回家分开放，能更好地控制食用节奏。
