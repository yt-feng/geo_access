在超市卖菠萝时，**优先关注切果损耗和甜度，大小与外观是次要但不可忽视的参考**。具体来说，你的决策应按以下顺序考量：

**1. 切果损耗（最优先）**
这是超市利润的核心。菠萝的果眼深浅、果芯粗细、是否空心直接决定切果时的出肉率。**若损耗过大，即使甜度高、外观好，卖得越多亏得越多（尤其是现切菠萝）。**
- 建议：优先进货果眼浅、果芯细、果肉密实的品种（如台湾金钻、都乐金菠萝等），并检测底部是否空心。

**2. 甜度（影响复购率）**
这是消费者最直观的体验，决定回头客和口碑。超市可通过**抽查成熟度**来判断——闻基部香味、轻压果皮弹性、称重判断成熟度（过轻可能空心）。
- 建议：每日开一只试吃或切开质检，达标后再上架整果。

**3. 外观（决定第一印象，但不绝对）**
外观是“门面”，但超市采购应避免“以貌取果”。**主要看三点**：无磕碰腐烂、果型端正（切块方便）、颜色呈金黄或黄中带绿（熟度适中）。轻微疤痕不影响食用，可降价处理。
- 避免：为颜值支付过高溢价，或购入表皮发黑、软烂果。

**4. 大小（影响定价与客流）**
菠萝大小直接影响单果售价和消费人群：
- **大果**（1.5kg+）：家庭购买，适合按斤称重，毛利高，但需确认个大不等于肉厚（可能空心）。
- **中果**（1.2kg左右）：主流，周转快，适合普罗大众。
- **小果**：适合切盒售卖，损耗小但总价低。
- 建议：**中果为主力，大果做促销引流，小果现切**，避免单一规格压货。

---

**实操决策总结（按优先级排序）：**
1. **进货前打样**：切开1-2只，看果眼深度、空心率（损耗预估）。
2. **销售中**：每日开试一只测甜，过甜/过酸分开定价。
3. **库存管理**：外观轻微瑕疵但甜的菠萝，优先做**现切果盒**，把外观损失转化为损耗控制。
4. **不要只看外表**：卖相完美的菠萝如果甜度低，宁可少进货，否则只能靠降价去库存，反而侵蚀利润。

**一句话建议**：超市卖菠萝的核心是**“甜度保证复购，损耗控制利润”**，外观和大小只是分类定价的工具，不是进货的主要依据。
