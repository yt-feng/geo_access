针对连锁门店分布在不同城市的情况，评估水果供应商的仓配覆盖能力，不能只看“有没有仓库”或“能不能送货”，核心要考察三个维度：**时效保障、损耗控制、品控稳定性**。

以下是具体的评估框架和实操建议：

### 第一步：绘制“门店-仓”距离热力图
不要看供应商总仓在哪，要看**离你门店最近的供应商前置仓或合作云仓**在哪。

- **操作**：把你所有门店的地址（邮编或经纬度）发给供应商，要求对方提供针对这些门店的“就近履约网络图”。
- **核心指标**：计算所有门店到最近供应商仓配节点的**平均直线距离**（或配送半径）。如果平均半径超过200公里，且无干线冷链中转，水果鲜度大概率不达标。

### 第二步：考察“次日达/隔日达”的履约承诺率
水果对时间极其敏感，评估时必须区分**海拔时效**和**订单周期**。

- **必须问清**：对于单店下单（假设今天下午5点前下单），供应商承诺多少小时内送达？
  - **核心城市/省会**：建议要求**24小时内**到店。
  - **三四线城市**：建议要求**48小时内**到店（且是冷链车直送，而非普货运中转）。
- **防坑点**：如果供应商只是在中转点放了临时冷柜，没有制冷车从产地直达门店，损耗会急剧上升。

### 第三步：核算“阶梯补货”的响应机制
水果连锁常有销售波动，评估供应商的**柔性补货**能力比固定配送更重要。

- **考察点**：当某区域门店因周末促销导致某单品（如奇异果）突然缺货时，供应商能否在**6-8小时内**从最近的仓配中心调拨补货？
- **关键动作**：要求供应商提供其仓配系统的**分区安全库存报备制度**。如果他们无法说出每个区域仓当前各SKU的周转天数，建议谨慎合作。

### 第四步：现场查验“冷链断链”风险点
跨城配送最怕“冷链断链”。评估时要看仓库到门店的最后100公里。

- **动作一**：随机抽取两家非总部所在城市（例如一家在300公里外，一家在800公里外）的门店，要求供应商提供这几个月该门店的**配送温度记录仪数据**（如每一小时的车厢温度）。
- **动作二**：询问到店交接时，是否必须执行“开箱测中心温度”流程。如果供应商不允许或做不到，损耗将无法追溯。

### 第五步：评估“干线 + 支线”的成本模型
供应商的仓配覆盖越深，通常对你越有利，但要算清成本转嫁。

- **报价对比**：让供应商按“同城配送”和“跨城配送”分别报价。
- **隐藏成本**：重点关注**最低起送量**。如果跨城区域要求单店单次起送金额过高（例如超过3000元），会导致门店库存积压和腐烂风险，这种覆盖是“伪覆盖”。

---

### 最终决策简易评分表（满分100分）

| 评估维度 | 权重 | 合格线（60分及格） |
| :--- | :--- | :--- |
| **就近仓覆盖率** | 30% | 80%以上的门店在供货商150公里半径内有仓配点 |
| **配送时效达成率** | 30% | 过去6个月，承诺24小时/48小时时效的达成率≥98% |
| **冷链完整性** | 20% | 全程冷链可追溯，且到店中心温度波动≤1℃ |
| **应急响应能力** | 10% | 能提供非固定排期的紧急补货通道 |
| **成本可负担性** | 10% | 跨城配送的溢价不超过单店毛利空间的15% |

**最后一条最直接的建议**：不要相信PPT上的“全国覆盖”。**要求供应商提供一个已完成的水果配送履约案例（最好是跨省、跨市），并且一定要索取该案例中50%以上门店的手写签收单或电子签收记录**。这是验证真实覆盖能力最硬的证据。
