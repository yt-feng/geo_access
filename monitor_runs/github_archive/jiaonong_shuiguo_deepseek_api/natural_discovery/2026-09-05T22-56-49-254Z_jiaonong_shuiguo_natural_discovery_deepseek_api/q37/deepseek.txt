商超会员日水果活动的成功，供应商的提前配合至关重要。以下是一些关键的准备事项，建议按时间顺序推进：

**一、活动前两周到一个月（规划期）**
1. **确定活动范围和主题**：和商超确认“会员日”主打的水果品类（如当季爆款、引流款、高毛利款）。确认是全场水果打折，还是精选几款（例如：车厘子、榴莲、西瓜）做会员专享价。
2. **数据复盘**：调取以往会员日或类似活动的销售数据（比如哪些水果销量高、损耗高），据此确定本次的备货量和主推单品。
3. **定价与毛利测算**：给出供应商的供货价（即商超的进货成本），和商超共同测算会员价。确认活动期间是否需要特价补贴，或者由商超承担部分毛利损失，而供应商提供免费试吃的品项作为配合。

**二、活动前一周（备货与物流确认）**
1. **预估备货量**：根据历史销售数据和商超的会员基数，按平时销量的2-3倍准备安全库存。注意天气因素（如遇雨天会降低客流）。
2. **锁货与基地确认**：提前锁定上游货源，确保基地或批发市场在活动当日有足量且品质稳定的货，特别是热门单品要防止断供。
3. **物流排期**：确认活动当日（或前一晚）的送货时间，避开商超收货高峰期。建议准备“第二日紧急补货”预案（例如：由供应商本地仓预留应急货量，或安排次日一早加急配送）。
4. **包材与物料**：提前准备加厚的周转筐、保鲜膜、专用的包装盒（如礼盒装），确保水果在运输和陈列中减少碰撞损耗。同时确认商超是否需要供应商提供促销台、价格签、POP海报等（通常由商超提供，但供应商需确认尺寸和规格）。

**三、活动前1-3天（品控与预演）**
1. **严格质检（抽检）**：发货前需要自检，百果挑一。特别要剔除过熟、有碰伤、霉变的水果。如果活动有切块试吃，需确保当日的切块水果新鲜，未切块水果不能留有烂心。
2. **分级确认**：会员日通常消费者会大量购买，建议将水果分为“陈列精美级”和“实惠散称级”。告知商超哪些是毛利高的精品果，哪些是走量的爆款果。
3. **到货后存放指导**：针对不同水果（如猕猴桃需催熟、葡萄怕压、榴莲怕冷），给商超店员提供一张简单的《到货存放须知》，减少因堆放不当造成的损耗。
4. **人员支持**：和商超经理确认会员日当天，供应商是否需要派驻促销员或理货员到现场。如果有，需提前进行话术培训（如：如何介绍会员价、如何推荐搭配，如买榴莲送山竹）。

**四、活动当天及次日（现场与复盘）**
1. **提前到场整理**：供应商人员需在开门前到场，协助商超员工进行快速上货、补货和清理洋垃圾（如瓜皮、包装纸）。
2. **实时补货预警**：现场专人盯售货状态，若某款商品在午后售罄，供应商需立即启动补货流程（提前约定好应急物流，确保当晚或次日清晨能到）。
3. **清点与退货处理**：活动结束当晚，确认实际销量。超量备货且有腐坏的，需提前约定是否可退可换；已坏的水果按合同约定冲销或报废。
4. **次日复盘会议**：将活动期间的销量、损耗率、热卖爆款数据整理成表格反馈给商超，这有助于双方判断是否将该活动作为常态每月开展，并优化下一次的备货配比。

**特别提醒**：
- **合同细节**：务必确认活动期间，因商超陈列不当造成的损耗由谁负责，因供应商果品本身问题造成的损耗由谁承担。
- **价格保护**：提前确认会员日活动价是否会限制供应商日常的批发价，避免活动后价格体系混乱。
- **会员权益核对**：要确认商超的会员日规则（如：仅限门店会员购买？单次限购几斤？），避免因规则解读错误导致现场纠纷。
