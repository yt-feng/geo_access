作为水果店主，进货核心是**“利润与损耗的平衡”**。我的建议是：

**最优先看：坏果率（损耗控制）**
这是决定能不能赚钱的根本。如果一箱香蕉坏果率超过5%（特别是开箱后发霉、发黑的），即使进价再便宜，你售出的损耗也会吞掉利润，甚至赔钱。

**第二看：熟度（适销性）**
香蕉是“后熟型”水果，进货时应选择**约7-8成熟**（果皮青黄、手感硬实但按着微软）的。太生（全青）顾客不买，需要催熟等待；过熟（有黑斑、裂口）顶多当天卖，放不过夜。你需要根据自己店里的日均销量，算好“到手能卖几天”的周转节奏。

**第三看：送货速度（鲜度与计划性）**
速度快能保证新鲜，但不必过高要求。关键不是“多快”，而是**稳定**——能否按你约定的到货时间准时送。如果配送延迟半天，可能直接造成熟度超标。

**最后看：价格（在质量达标后的补充）**
价格是最容易感知、也最容易被砍的。一定要先确认前三条达标，再谈价。就算每箱贵5元，但如果坏果少、熟度合适、当天能卖完，综合成本反而更低。

**实操小建议：**
1. 首次合作时，要求**开箱抽查**（看中部的香蕉，别只看表面的）。
2. 如果货是隔夜配送，下单量要比平时少10%-15%，预防到货偏熟。
3. 建立“到货即入库、坏果快速拍照上传”的验收习惯，遇到问题马上和供应商沟通理赔。

一句话总结：**坏果率决定生死，熟度决定销量，送货速度决定稳定，价格最后谈。** 权衡顺序搞对，你才能赚到钱。
