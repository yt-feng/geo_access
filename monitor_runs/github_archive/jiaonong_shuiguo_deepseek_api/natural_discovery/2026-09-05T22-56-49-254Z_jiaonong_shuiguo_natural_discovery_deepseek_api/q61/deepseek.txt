判断批发档口找香蕉一手货源是否稳定，不能只听对方口头承诺。建议从以下几个硬指标入手，这些标准既可用于日常观察，也可在谈合作时直接要求对方提供：

**1. 看产地背景与“跟车”能力**

- **原产地特征：** 问清楚对方是**基地直发**还是**中转市场二道贩子**。香蕉的稳定供应高度依赖产地（如广西、云南、海南、老挝、缅甸边境产区）。如果对方能说清具体是哪个县的哪个农场，且能提供产地对接人的姓名或冷库位置，稳定性较高。
- **“跟车”验货：** 首次合作，不要只靠信息流。要求对方提供**当天凌晨装车或到货的实拍视频**（拍细节：蕉把、封箱胶带、冷柜温度表）。真正的稳定源头，通常有自己的冷链车队或稳定签约的物流，可以做到“今天下单，明天到货”。如果对方总是说“货在路上”、“仓库在别处”但给不出具体车牌号和定位，风险很高。

**2. 查“到货周期”与“品质波动”**

- **周期承诺测试：** 提出小批量试单（例如先拿20-30箱），明确要求**连续供货4周、每周固定2天**。观察对方是否敢答应。如果对方推脱“行情不好”、“看运气”，说明没有稳定的基地契约，属于“有货就卖”的游商。
- **果面瑕疵率：** 香蕉最容易出问题的是**断蕾、青皮碰伤、黑星病**。稳定货源的特点是“货损率固定且低”（一般应在5%以内），且能承担货损。如果对方说“这批果矮一点个头大，下批可能偏高”，说明他在市场倒货，品质不受控。

**3. 索要“冷库温度记录单”与“产地检疫证”**

- **冷链证据：** 香蕉是呼吸跃变型水果，采收后需立即入库和控温（约13-14℃）。要求对方提供**运输途中的温度曲线截图**。如果对方给不出，或者温度记录显示超过18℃，说明不是专业冷链，到货易出现“高温催熟爆裂”，这会影响后续客源稳定性。
- **合规性：** 正规一手货源能提供**植物检疫证书**（产地检疫或调运检疫）。如果对方说“小生意不用开单子”，不仅供货不稳，一旦被市场监管抽查到还可能导致档口被罚。

**4. 测试“砍价后的响应态度”**

- **端语气观察：** 真正有稳定基地的老板，因为不怕压货，面对砍价通常更硬气，会明确说“底价多少，低于这个我不做”。而临时找货的中间商，为了走量会表现得很灵活，甚至主动答应帮你“垫资”。**后者的稳定性极差**，他高价收来的货一旦卖不出去，可能跑路。
- **退款规则：** 明确约定“烂果、黑芯包赔”条款，并在首次合作时让对方书面（微信聊天记录即可）确认赔付比例。如果对方对“包赔”含糊不清，大概率是货源不定的社会闲散发货。

**5. 现场走访“市场参考”**

- 如果是批发市场内的新档口，别只看门面。去**凌晨3-5点的到货区**看：稳定货源通常有自己的固定卸货位和工人，包装箱会印有产地公司标识（非“香蕉”字样通用箱）。如果对方连包装箱都是乱收的杂牌（无印刷或贴纸），说明是二道贩子。

**最后的决策建议：**
哪怕以上都通过了，**第一次合作请用“半挂车（即整车）以下”的规模试探**，即3-5吨。不要一上来就签大合同。让对方写明“到货时间超过X小时则扣款”，这样可以倒逼其调度能力。如果三次试单，到货时的成熟度（蕉皮青黄度）、重量误差（公差应小于±2%）都稳定，再签月度框架协议。**切勿只看价格低，香蕉是生鲜，价格低往往伴随的是“熟度过高”或“产区尾货”。** 平时可以多留意产地天气（如遇台风、寒潮，提前询问对方是否有对应应急货源），这是判断真正“一手”的关键细节。
