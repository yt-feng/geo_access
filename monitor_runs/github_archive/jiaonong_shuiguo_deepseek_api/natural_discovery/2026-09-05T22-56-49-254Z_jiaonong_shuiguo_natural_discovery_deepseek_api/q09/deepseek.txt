水果店旺季备货最忌讳的是“货到了但品质不对”或“价格变了但没提前锁定”。和供应商谈判前，建议你重点问清以下5类问题，每一类都直接关系到你的库存风险和利润：

**一、供应能力与稳定性**
1. “你们在这个品类/旺季的最大日供应量是多少？能保证连续几天不断供？”
2. “如果临时加单50%甚至100%，需要提前多久通知？有没有可能临时调配？”
   *（判断对方是否有稳定货源或冷库储备，防止你在旺季断货时才急找货源）*
3. “旺季里，你们是否有替补供货渠道？如果你们自己缺货，会怎么处理？”

**二、价格与涨价规则**
4. “这个价格锁定期是多久？如果要涨价，需要提前几天通知我？通知方式是什么？”
5. “签了合同的话，价格是按合同价还是随行就市？如果行情暴涨，你们有封顶价吗？”
   *（旺季水果价格波动可能一天一变，一定要明确报价有效期和涨价缓冲期）*
6. “大批量采购能不能有阶梯折扣？比如每周固定拿多少量能返点或降价？”

**三、品质与规格标准**
7. “这批货能达到什么甜度、糖度或成熟度？有没有分级标准？果径、损伤率怎么约定？”
8. “到货后发现坏果或次果，退换货的标准和时限是什么？按几分之一的比例免赔？”
   *（旺季供应商常混采未熟果，一定要有书面验收标准，口说无凭）*
9. “能不能提供样品？样品和大货批次能维持同一品质吗？”

**四、物流与损耗承担**
10. “运费谁承担？如果是冷链车，运输途中的温度控制怎么保证？坏了算谁的？”
11. “到货后如果延迟，你们有违约赔偿吗？比如延迟1天怎么处理？”
    *（旺季货车紧张，延迟一天可能导致你整柜烂果）*

**五、结算与账期**
12. “账期是多少天？能不能先付一部分定金，货到验收合格后结清？”
13. “旺季资金回笼快，如果现金结款能不能再给2%-3%折扣？”
    *（旺季你现金流充足，现金议价是谈判筹码）*

**终极建议：**
别只问不吃。**旺季前至少提前2周，让供应商寄一次同品质的试售批次**，实际测损耗率和顾客反馈——这时候“谈”不如“试”。谈判时把“稳定性”和“可追溯规则”写进合同备注，口头承诺一律补一句：“这个咱们写进单子里吧。”
