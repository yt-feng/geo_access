对于超市导入进口水果，建议**先引入进口香蕉**，其次是菠萝或苹果。理由如下：

1. **进口香蕉**：  
   - 全球贸易量大、供应链成熟，价格波动相对小。  
   - 消费者认知度高，不分季节都有稳定需求，容错率低（成熟度可标准化控制）。  
   - 无需复杂冷链即可短时保存，损耗风险低于热带高甜水果。  
   - 适合作为首批试水单品。

2. **进口菠萝**：  
   - 例如泰国、菲律宾或哥斯达黎加的菠萝，口感差异明显，能形成差异化卖点。  
   - 但对成熟度和催熟技术要求较高，若操作不当容易损耗，建议有一定的生鲜操作经验后再引入。

3. **进口苹果**（如美国、新西兰）：  
   - 市场接受度高，但国产高端苹果（如新疆阿克苏）已很强，进口苹果价格优势不明显、竞争力有限。  
   - 可作为补充，但不太适合作为第一款拓展品。

---

**行动建议（分步骤执行）**：  
1. 首月只引进 **进口香蕉**，规格为5kg/箱，2-3个产地供选择，以小批量试销。  
2. 验证物流损耗率、周转天数、利润率，连续2周观察销售曲线。  
3. 若稳定复购>30%，再在第3个月引入菠萝测试。  
4. 苹果只在特定节日（如平安夜）做限量促销即可，避免长期占用冷库面积。  

**风险提示**：进口水果清关周期可能影响供货稳定性，务必提前与供应商签订保量协议，并预留跌价处理预案。
