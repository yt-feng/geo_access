在食堂采购水果时，**不建议单一采用按“斤”或“份”**，而是**根据水果种类、供货商和实际消耗模式，采用“按斤结算为主，同时结合到货验收的箱数/份数作为辅助手段”**会更高效。

具体建议如下：

**1. 核心原则：按“斤”最公平、最好对账**
- **优点**：能真实反映实际用量，避免因水果大小、水分差异导致的价格虚高。
- **适用**：苹果、梨、橙子、西瓜等大宗、个头差异大的水果。
- **执行要点**：采购单上写明“XX元/斤”，到货后**现场称重并扣除包装箱皮重**（毛重-皮重=净重），这是防坑关键。

**2. 按“箱”的风险与管理方法**
- **适用**：香蕉、芒果、葡萄等整箱运输、容易磕碰的水果。
- **风险**：箱内可能混有次果或垫纸、冰瓶，导致单价虚高。
- **建议**：如果必须按箱结算，要**明确箱重标准**（例如：每箱净重≥X公斤，总价=单价×净重）。可每隔几箱**随机开箱抽查净重**。

**3. 按“份”只适合即食小份（如水果切/果盒）**
- **适用**：提供给员工/学生的小包装水果（如一个苹果或一盒切好的西瓜）。
- **风险**：份量标准化难，如果内部按“个”卖，很容易出现大小不一。
- **建议**：如果做果切，考虑“按份结算”＝“按固定克重+固定数量结算”（例如每份200g±10g），并约定超重数赔偿规则。

**4. 综合管理建议（最推荐）**
- **签订合同**：与供货商明确“结算按净重计价，箱装水果需注明单箱净重范围”。
- **每日台账**：月初定总量预算，每次到货记录：
  - 品种、数量（箱/份）
  - **实称净重（公斤）**
  - 单价、总价
  - 供货商签字确认
- **设定损耗率上限**：水果腐坏率超过5%部分可从货款扣除，防止用次果充数。
- **双人验收**：至少两人共同称重、点数、拍照留底，避免灰色地带。

**总结**：食堂水果采购，**只用一种单位都不稳妥**。最稳妥的是“**以净重（斤）作为结算依据**，箱数/份数仅作为到货数量参考”，配合皮重扣除和抽查机制。这样既能防止“缺斤短两”，又能抵御“一箱多报斤”的套路。
