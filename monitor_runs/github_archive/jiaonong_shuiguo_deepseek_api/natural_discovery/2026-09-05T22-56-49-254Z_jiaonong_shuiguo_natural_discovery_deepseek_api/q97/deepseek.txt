在酒店采购水果盘原料时，供应商通常需要承诺以下规格和外观标准。这些标准直接影响出品质量、摆盘效果和食品安全：

**一、基础规格标准（可量化）：**
1. **成熟度**：供应商需注明按“即食”或“后熟”区分。例如：
   - 芒果、木瓜：8-9成熟，切开后甜度稳定；
   - 香蕉：禁出青色（需当天熟透），可分批供“微黄带青”或“全黄”；
   - 牛油果：需达到按压微软但无黑斑状态（按酒店要求区分硬熟或软熟）。
2. **单果/单片重量公差**：例如整果误差不超过±10%；切片类（如西瓜、哈密瓜）需按净重发货，并提供去皮去籽后的出成率参考（≥75%为佳）。
3. **尺寸分级**：草莓直径≥2.5cm；蓝莓果径≥12mm；葡萄单粒≥10g；避免“统货”掺次。

**二、外观标准（目视可检）：**
1. **无损伤**：无明显压痕、挤伤、机械伤、表皮破损（尤其是浆果类）。
2. **无病虫害**：无虫眼、霉点、白粉病斑；苹果、梨需无黑心病迹象。
3. **色泽均匀**：整体颜色达标且一致；禁用局部褪色、青红不均（如西瓜白瓤），及表面有黑色瘀块。
4. **形状端正**：严禁畸形果（如双联体草莓、歪瓜）过多混入，每批畸形率应≤5%。
5. **清洁度**：无泥土、农药残留可见物、蜡质残留。

**三、包装与卫生标准：**
1. 使用食品级塑料筐/盒，内衬吸水纸或泡沫垫；禁止使用报纸或非食品袋直接接触。
2. 运输全程冷链（到酒店温度应为5~8℃），冷链断链记录需可追溯。
3. 每批次提供农残检测报告或产地证明（必要时附带第三方抽检）。

**四、可执行验收建议：**
- 要求供应商每次随货附**“收货标准卡”**，列明品种、净重、外观等级（可按酒店内部A/B级）。
- 验收时可执行**“开箱3-5%，整批不低于10%的比例抽查”**，若外观不达标（如单批烂果率>3%），有权整批拒收或要求按比例赔偿。
- 针对高损耗品类（如葡萄、荔枝），建议合同约定“到货后24小时内损耗率≤2%”的条款。

如有特定场合（如自助餐切盘、VIP果盘雕刻），还需额外约定“果型周正度”和“无疤痕”的更高规格，供应商需在报价中注明是否加价。
