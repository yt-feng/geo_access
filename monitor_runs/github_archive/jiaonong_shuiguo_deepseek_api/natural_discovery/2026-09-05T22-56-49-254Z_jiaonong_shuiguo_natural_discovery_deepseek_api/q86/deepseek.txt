做生鲜平台的一件代发水果，供应商的核心仓配能力主要围绕**“鲜”**与**“损”**两大原则。如果平台主打高复购、高客单，关键不在于仓库大小，而在于**时效控制和损耗控制**。

以下是从实操角度出发，供应商必须具备的五大仓配能力清单（可直接用来对标检查）：

**1. 冷链仓储能力（前置仓/中转仓）**
- **温区配置**：水果品类复杂，必须有**分温区储存**能力。例如：常规水果（苹果、柑橘）的常温保鲜区、热带水果（香蕉、芒果）的催熟/恒温区（12-15℃）、以及极易腐坏的浆果（草莓、蓝莓）或进口水果（车厘子）的冷藏区（0-4℃）。
- **催熟与冷藏库**：**必须具备催熟库**（释放乙烯或控温催熟），因为平台发出去的货如果“没熟”或“熟了烂掉”都会产生极高客诉。没有催熟库的供应商，很难做香蕉、猕猴桃、芒果等高需求单品。

**2. 分级分拣与定重能力**
- **自动化/半自动分拣线**：不是简单过秤，而是要能按**果径、克重、糖度**进行分级。平台标品（如一盒5斤大果）要求误差一定要小，分拣不标准会导致大批量售后。
- **二次质检与毛重控制**：必须能完成“挑果-去坏果-套袋-装盒”全流程，且能将发货**净重控制在标准误差内**（不能为了补足重量塞入垫纸或小果）。

**3. 时效性打包与预冷能力**
- **预冷设备（核心）**：水果采摘/到仓后热量很高，如果直接装箱入快递车，车厢内发热会催熟所有果子。**必须具备强制预冷能力**（如冷库预冷或压差预冷），摘下来后2-4小时内将果心温度降至5℃以下，这是减少运输途中损耗的胜负手。
- **配套包材仓**：需要常备**气泡柱、珍珠棉网套、防震纸箱、透气膜**，不能每次临时找包装，且需要能针对不同快递（顺丰/京东/中通）做适配打包测试，确保暴力分拣下果不烂。

**4. 快递协同与截单能力**
- **多快递接口**：不能只绑定一家快递。必须具备与**顺丰（高价值礼品果）、京东（时效承诺）、邮政极速鲜（偏远地区）**等的电子面单对接能力，可以随时切换。
- **当天发出（当日达效）**：**核心指标是“截单点”**。供应商必须能在每日下午2点-4点前完成当日订单的分拣打包并交接给快递干线车辆，确保水果能在**48小时内**从产地到消费者手上（新疆、西藏除外）。如果截单晚，第二天发货水果多腐烂一天，仅退款率就会飙升。

**5. 灵活的小批量B端供货能力（小包裹模式）**
- 生鲜平台一件代发通常是**零散订单**，不是整车发货。供应商需要能处理“单日几千单但SKU复杂、收件人非特定”的情况。
- 必须有**批量打印面单、波次拣货**的系统能力（如使用旺店通、聚水潭），否则订单多时极易错发漏发。

**给您的实操建议（供应商筛选金标准）：**
如果您是平台方去对接供应商，建议先要求对方提供三项证明：
1.  **近7日发货单量截图**（看他们是否能配合平台大促）；
2.  **样品寄送测试**（发一箱从产地到您的城市，开箱看坏果率和品相，并顺丰发5个偏远地址测试暴力件）；
3.  **售后赔付标准**：必须明确“包赔范围”（如坏果包赔、重量不足包赔、拒签包赔），**尤其要确认“超时发货赔付比例”**，以防供应商爆单后崩盘。

**特别注意一个坑**：很多供应商有仓库和冷库，但**没有真正意义上的内部冷链交接体系**。有些供应商打包区没装空调，夏天打包时水果在常温下暴露2小时，直接影响货架期。实地考察时，**重点看打包间温度是否恒定在15-20℃以下**，这是判断专业与业余的分水岭。
