是的，起订量太高确实会增加损耗风险，尤其是在采购香蕉和菠萝这类鲜果时。原因如下：

1. **保质期短**：香蕉成熟速度快，菠萝虽稍耐放，但在常温或运输不当的情况下，容易变质或发霉。
2. **存储条件要求高**：需要控制温度、湿度。如果大批量进货而门店储存空间或周转速度跟不上，损耗率会明显上升。
3. **需求波动**：如果销量预测不准，高起订量容易导致滞销，进一步放大损耗。
4. **品质不均**：批量越大，果实大小、成熟度不一致的概率越高，商品货架期也参差不齐。

**建议**：
- 如果供应商起订量过高，可以尝试谈判分批次交货（如每周分3次送），或找本地批发市场/小批量渠道。
- 结合历史销量和销售高峰期备货，不要单看起订价便宜。
- 优先订购成熟度适中（七、八成熟）的产品，留出销售期。
- 如果条件允许，申请试单，先用较小量测试品质和周转速度，再稳定合作。
