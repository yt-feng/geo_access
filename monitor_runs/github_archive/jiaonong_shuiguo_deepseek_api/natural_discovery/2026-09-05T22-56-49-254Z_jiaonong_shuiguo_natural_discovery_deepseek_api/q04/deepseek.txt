针对水果店香蕉易损耗的问题，采购时的**核心原则是“宁青勿熟、分批到货、冷链交接”**。以下是具体可操作的采购要求建议：

### 一、 对熟度（色卡等级）的硬性要求

不要直接说“要生的”或“要熟的”，应使用国际通用的**香蕉色卡（1-7级）**进行沟通：

| 等级 | 外观 | 适合状态 |
|------|------|----------|
| 1-2级 | 全青 | 不适合门店销售，需催熟 |
| **3级** | **绿多黄少（约1/4黄）** | **最适宜的采购起点** |
| 4级 | 黄多绿少（约1/2黄） | 适合当日或次日销售 |
| 5-6级 | 全黄、果皮有少量芝麻点 | 仅限当天极速清货 |

**采购硬性要求：**
- 到货时**整箱必须全部处于3级或4级初期**，坚决拒收超过5级（全黄变软）的货。
- 要求供应商提供“色卡承诺”，并在合同中写明“到货色卡等级区间为3-4级”。

### 二、 对到货时间（周转率）的要求

香蕉在门店的平均可售期只有 **2-4天**（从到货到全黄发黑）。

1. **采购频次**：不要一次性进一周的货。
   - 单店日销量若低于 5箱（约90公斤），建议**每2天进货一次**。
   - 如果做不到2天一次，则要求供应商提供“**分批送货**”服务：周二送到货为3级，周四送到货为2-3级，平均分摊风险。

2. **到货时段**：要求在**每日营业开始前（如8:00前）或下午客流低谷**（14:00-15:00）到货。
   - 严禁晚上打烊前后到货，因为夜间存放若温差大，会导致次日缩水或成熟过度。
   - 到货后立即开箱散热，绝对不能闷在纸箱里过夜。

### 三、 对仓储及运输条件的附加要求

即使熟度达标，错误存放也会让香蕉24小时内全部变黑。采购时可要求：

1. **箱内须有“防压隔层”**：要求供应商采用开孔塑料薄膜+纸板间隔，防止下层香蕉被压伤产生催熟乙烯刺激。
2. **夏天运输必须选“冷链车（15℃-18℃）”**，冬天选“保温车（不低于14℃）”：
   - 如果供应商做不到，必须要求其在箱内放置**冰袋**（注意不能直接接触果皮，需隔离）。
3. 在下单时问清供应商的**冷藏库房温度**，若对方库温高于20℃，则该批货不要进太多（建议最多2天的量）。

### 四、 谈判与验收“落地话术”（可直接用）

1. **熟度话术**：“老板，这批要3级偏4级（微黄带绿的），我这边卖得快，你送全黄的过来我当天卖不完就烂了，下次我肯定不结这种货的钱。”
2. **时间话术**：“这箱帮我备注‘明天早上必须到’，如果拖到下午我就拒收，因为下午来货我换不上价了。”
3. **验收动作**：到货时**开箱抽查**（至少抽2箱），摸果柄是否发软、看头尾是否有褐变点。若整箱大量出现5级果，可以直接拍照拒收，或要求供应商当场调换成青色补货。

### 五、 附加避损建议

- **备“催熟柜”**：如果只能拿到更青的货（1-2级），采购时可以要求“供应商赠送/低价配售少许5级熟果”，用来自然催熟周边青果。
- **调整陈列**：到货后优先卖4级果，3级果次日卖。如果3级果放不住，可要求供应商做“以旧换新”的周结协议，降低损耗率至5%以内。

**特别提醒**：不要为了压低批发价一次性屯货。香蕉的损伤不可逆，多花少许单价买“3级果+快送”的稳定供给，远低于烂掉整箱的隐性成本。
