在超市采购水果时，从合规性和食品安全角度出发，**供应商必须提供的资质与证明文件**通常包括以下几类。不同地区或不同品类的具体要求可能略有差异（例如进口水果），但下面是最核心的清单：

### 一、 基础经营资质（必备）
1. **营业执照**（复印件加盖公章，需具有生鲜或水果经营范围）。
2. **食品经营许可证**（如果是预包装/散装水果，需在有效期内）。

### 二、 产品检测报告（关键）
1. **法定农残检测报告**：由第三方有资质的检测机构出具（如CMA、CNAS认证机构），**重点检测项目**：有机磷、氨基甲酸酯类等高危农残，以及重金属（铅、镉）是否超标。
   - **注意**：报告需与**本次进货批次**一致（或说明样品批次），一般要求报告出具日期不早于供货前3个月（部分超市要求每批次提供）。
2. **食用农产品合格证**：由生产企业或农户自行开具的“承诺性合格证明”，标注产品名称、产地、检测信息等，这是目前部分产地直采的简化替代文件。

### 三、 产地与追溯证明
1. **产地证明**（如当地农业农村部门或村委会开具的产地信息）。
2. **进货凭证/发货单**（需列明货品名称、规格、数量、送达日期，盖供货商公章）。
3. **若为品牌水果**：需提供**品牌授权书**，证明非假冒伪劣。

### 四、 特殊品类额外要求
1. **进口水果**：需提供 **入境货物检验检疫证明**（或电子凭证），以及**海关签发的报关单**（查看原产国、HS编码信息）。
2. **有机/绿色认证水果**：需提供对应的**认证证书**（有机证书编号需在有效期内，且需与产地信息匹配）。
3. **冷鲜/易腐水果（冷冻果）**：需提供冷链运输的**温度记录单**，确保全程冷链合规。

### 五、 超市收货时的补充动作（虽然非供应商文件）
- **批批验收抽查**：即便有报告，建议超市收货员现场抽测外观、异味，并随机抽样送第三方快筛（如胶体金法检测农残）。
- **留样与台账**：保留供应商的全部资质复印件，并按法规建立**进货查验记录台账**，保存期限不少于产品保质期满后6个月（无明确保质期的，保存不少于2年）。

---

**实操建议**：
- 若供应商为大中型专业合作社或公司，一般会主动提供以上文件；若是散户或地摊供货，必须要求其提供至少**个人身份证复印件+产地证明+检测小票**，否则严守“无证不收货”原则。
- 若无法从供应商处获得最核心的**检测报告**，超市应坚决拒收，因为一旦出现农残超标，超市作为销售方负有首要赔偿责任（法规依据：《食品安全法》第136条）。
