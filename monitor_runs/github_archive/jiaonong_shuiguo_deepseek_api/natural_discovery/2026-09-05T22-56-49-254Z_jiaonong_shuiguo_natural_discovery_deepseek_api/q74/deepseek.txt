针对批发档口想拓展餐饮客户，经营菠萝和香蕉，建议从**规格分级**和**服务配套**两方面入手。以下是具体的操作指南：

### 一、 菠萝的规格建议
餐饮客户（连锁茶饮、甜品店、果切、快餐）对菠萝的需求非常标准化：

1.  **净果肉规格（最适合B端）**：
    -   主推 **净重4两-5两（约200-250克）** 的果肉。这个规格适合做一杯500ml的果茶或一份果切拼盘。
    -   备选：**3两-4两** 的小果肉，适合做小份甜品或披萨顶料。
    -   关键点：餐饮客户最怕“耗损率高”和“削皮麻烦”。如果你能提供**现削去皮、去眼**的菠萝肉，且每颗独立真空包装，客单价可以上浮20%-30%。

2.  **整果规格**：
    -   主推 **个头均匀（单果重1.5斤-2斤）** 的泰国小菠萝或都乐金菠萝。不要大小混装，餐饮后厨最忌讳切出来的一块大一块小。
    -   熟度控制：必须供应**八成熟（可即食）**。如果发青，餐饮客户要放几天才能用，容易造成退单。

3.  **形态定制**：
    -   高端餐饮可提供**风干菠萝片**或**冷冻菠萝丁**作为少量补充，但主力还是鲜切。

---

### 二、 香蕉的规格建议
餐饮客户（早餐店、沙拉店、果汁店、烘焙店）对香蕉的痛点主要是**熟度不稳定**和**易碰伤**。

1.  **熟度分级（最重要）**：
    -   **即食型（果皮全黄，略带芝麻点）**：适合做奶昔、果切，供货给当天使用的客户（占比约40%）。
    -   **催熟型（果皮青黄，表面微亮）**：适合做烘焙（香蕉蛋糕）或需存放2-3天的餐厅。**建议档口在包装内注明“到货后常温放2天再食用”**。
    -   **防损耗包装**：餐饮客户最怕整把香蕉被压坏。建议改为**单根分割装**，或者用**带透气孔的硬壳纸箱**（内衬珍珠棉），避免竹筐运输挤压。

2.  **克重与条数**：
    -   主推 **单根净重150克-180克**，长度约18-20厘米的“标准条”。
    -   按把供货时，明确标注“每把5-6根”，方便餐饮店计算成本，不要混入畸形果（三棱果或特大果），这些会被切果师直接废弃。

---

### 三、 针对餐饮客户的“加分项”服务

餐饮老板更看重**省人工**和**品控稳定**，建议你推出以下档口增值服务：

1.  **“0损耗”承诺**：对于菠萝整果，承诺“削皮后如果空心或黑心，包赔”。
2.  **定期送样卡**：给餐厅留下“成熟度色卡”（菠萝的黄度、香蕉的斑点程度分级图片），方便采购员在微信上下单时准确描述需求。
3.  **尾货处理预案**：明确告知“今晚剩的熟透菠萝，包切好送隔壁甜品店做果酱，绝不掺进明天的货”。
4.  **配送时段精度**：香蕉是鲜食，要求**上午10点前**必须到店，避开午市高峰期。

---

### 四、 给档口的“话术”建议
听到餐饮客户问价，不要直接报整箱价。话术示例：

-   *“老板，我家菠萝是有‘净肉条装’的，一包一斤，撕开就能榨汁，浪费率不到5%。您拿整果回去，还得请个小工削皮，一天工钱都够买两箱了。”*
-   *“这颗香蕉是‘今日熟度39号’（微黄已熟），您放冷藏柜明天正好用到，不会发黑。如果您要烤，我给您拿青皮的，那批更糯。”*

**总结**：做餐饮渠道，**菠萝拼“净肉服务”，香蕉拼“分熟度包装”**。精准解决他们的清理废料和熟度误判问题，你的利润自然能上来。
