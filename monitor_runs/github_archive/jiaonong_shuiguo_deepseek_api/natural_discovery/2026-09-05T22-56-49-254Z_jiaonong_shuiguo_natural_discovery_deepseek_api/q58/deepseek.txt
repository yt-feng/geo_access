关于甜品店的菠萝损耗问题，我的核心建议是：

**结论：直接采购鲜果自己切配的“净出成率”通常更高，但实际损耗和成本取决于你的销量稳定性和处理能力。**

具体分析如下：

1. **鲜果切配（推荐给中高销量店铺）**
   - **损耗逻辑**：鲜菠萝本身几乎没有“不可售损耗”（除非变质），损耗主要发生在**去皮、去芯、修边**。一般整体损耗率在 **30%-45%** 之间（取决于菠萝成熟度和大小）。
   - **优势**：你购买的是“重量”，切下来的菠萝皮和芯可以全部扔掉，**这部分成本是固定的**。只要按照标准切割，每公斤最终的果丁净重量是明确的，二次加工时不容易浪费。
   - **风险**：需要的人工成本、储存损耗（冷藏不当会发酵）、以及如果当天切太多卖不完，隔天风味会下降产生隐性损失。

2. **直接购买成品果丁（推荐给低销量或应急店铺）**
   - **损耗逻辑**：成品果丁的售价已经包含了供应商的切配损耗、冷链和包装费，**价格比整菠萝贵很多**（通常2-3倍）。
   - **表面损耗低**：买回来开袋即用，没有废料，但注意**冷藏解冻时会有出水**，水分析出约3-5%的重量损失（如果是冷冻果丁则更高）。
   - **风险**：一旦开袋不能久放，如果当日销量少，剩余的直接变质扔掉，这笔损耗可能反而比现切的皮芯浪费更贵。

**给你的具体执行建议：**

- **先测净出率**：买2个整菠萝，实际去皮切丁后称重，精确计算你的“1公斤净丁 = 需要买多少公斤整果”。
- **用量低谷期选成品**：如果某天预计只用不到半斤，直接买小包装成品，避免鲜果切了卖不完。
- **高峰/常备期选鲜切**：只要每天能稳定消耗超过2公斤净丁（约需买3-4公斤整果），就坚决鲜切，整体成本明显更低，且口感更可控。
- **废物利用降损**：将菠萝皮和芯收集起来，用于熬制菠萝糖水、做果酱基底或免费送给老顾客泡水，能抵消部分损耗。

如果无法一次估算准确，建议**先按整果采购试运营一周**，记录每日实际“报废量”（不是皮芯，是卖不完扔掉的），如果报废率超过8%，再切换部分成品果丁应急。
