这是一个很实际的采购决策。**没有绝对的标准答案，关键在于你的定位、出杯速度和成本控制。** 以下是按场景的详细对比和采购建议：

### 1. 核心区别速览

| 维度 | 鲜果 | 果丁（冷冻/罐头） | 果泥（冷冻/常温） |
| :--- | :--- | :--- | :--- |
| **成本** | 贵（含损耗、去皮去芯） | 中等 | 最便宜（但需注意品质） |
| **口感/果肉感** | 最真实，纤维感强 | 有颗粒咀嚼感 | 顺滑，无纤维感（或极细腻） |
| **出杯速度** | 慢（削皮、切块） | 快（解冻即用） | 最快（直接挤/挖） |
| **保质期/储存** | 易坏，需冷藏 | 冷冻保存，周期长 | 冷冻或常温（依赖灭菌工艺） |
| **风味稳定性** | 不稳定（季节性酸涩） | 相对稳定 | 最稳定（标准化） |
| **操作损耗** | 高（削菠萝损耗约30-40%） | 低 | 极低 |

### 2. 按你的茶饮店类型推荐

- **如果你主打“鲜果茶”概念，且有吧台人工富余：选鲜果。**
    - **原因**：消费者能看到真果肉，价值感最高。适合做“满杯凤梨”、“爆打凤梨”类产品。**关键技巧**：菠萝果芯纤维太粗且酸涩，必须剔除，只保留果肉部分；切块后需用盐水或糖水短泡去除麻嘴感。
    - **注意**：尽量选**都乐金菠萝**（无刺，甜度高）或**徐闻菠萝**（香气浓但需处理刺眼），损耗需计入定价。

- **如果追求出杯速度和操作标准化，同时要有咀嚼感：选果丁（冷冻）**。
    - **原因**：最适合做“大块果肉”类果茶，或者和普通茶叶底搭配。开袋即用，定量使用。
    - **注意**：采购时**务必看包装标明的“固形物含量”和“糖度（Brix）”**。好的果丁应该有完整果肉块而不是碎渣，糖水或果汁浸泡的比单纯白水浸泡的甜感更自然。不建议用罐头果丁（防腐剂味重且过软）。

- **如果你做的是“杨枝甘露”底、奶昔、沙冰类，或者需要浓郁果香但不想太占地方：选果泥**。
    - **原因**：果泥能提供稳定的菠萝香气和酸甜底味，特别适合做**凤梨冰沙、金菠萝冰淇淋**，或者作为基底和鲜果拼配增香。
    - **注意**：市面上果泥分“纯果泥”和“调配果泥”。**建议选“无添加蔗糖”或“低糖”的**，否则容易导致饮品过甜。采购时要求供应商提供**“非浓缩还原（NFC）或鲜榨冻藏”**的批次，避开勾兑果浆。

### 3. 最稳妥的“组合拳”采购策略

对于多数想控制风险的中小型茶饮店，建议**混搭**：

- **主料用果丁**：解冻后出杯，解决果肉量和速度问题。
- **辅料用果泥**：在果丁风味不足时（如用罐头果丁），加入30-50ml果泥打底，增加醇厚感和香气。
- **样品用鲜果**：如果做新品研发或高客单价产品线，单独用鲜果试做。

### 4. 采购时最重要的3个硬核避坑点

1.  **不要只看价格**：低价果丁往往混入**果芯**（又硬又没味道）或**果皮边角料**。到手后取100g不加热解冻，直接尝是否有“罐头味”或“水煮味”。
2.  **看保质期与冷链**：冷冻果丁/果泥要求全程**-18℃**以下，如果供应商在夏季用常温车配送，到店容易化冻变软，复冻后口感全毁。
3.  **试做后再定大货**：拿小样做一杯“不加糖、只加茶和冰块”的纯饮测试，**甜度、酸度、纤维粗细**是否符合你菜单的定价逻辑。

### 结论速答

- 要**最快上量、成本可控、口感均衡** → 选**冷冻果丁（+少量果泥增香）**。
- 要**极致真实感和高毛利** → 选**鲜果**（但需接受损耗）。
- 千万别买**常温果泥**（为了保质期通常加大量山梨酸钾或高糖），除非你做的是低端走量产品。

建议首批采购采用“果丁+果泥”二合一方案，测试一周后根据顾客对“果肉颗粒”的评价再微调比例。
