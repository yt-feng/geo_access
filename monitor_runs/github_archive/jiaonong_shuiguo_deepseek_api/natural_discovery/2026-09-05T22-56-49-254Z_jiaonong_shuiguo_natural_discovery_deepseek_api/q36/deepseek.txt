针对商超采购菠萝，究竟是卖整果还是卖切好的，取决于门店的定位、客单价目标、损耗控制能力和周边消费习惯。**最稳妥的做法通常是“整果为主，切果为辅”的组合销售模式**。

下面给出具体的决策维度和执行建议：

**一、 核心决策依据（按权重排序）**

1.  **客单价与毛利（决定性因素）**
    *   **卖整果**：单价高（如19.9元/个），客人决策时间长，**单笔毛利高**，但若客人回家不会处理（尤其是没买过菠萝的新手），极易产生“低价引流但转化失败”或口感投诉。
    *   **卖切好的**：单价低（如9.9元/盒），**客单价低但毛利率高**（切盒损耗算入成本后，毛利率通常可达50%以上，而整果毛利一般30%左右）。切好菠萝更符合**即时消费场景**（办公室、下午茶、即买即吃）。

2.  **损耗控制（菠萝是高风险损耗品）**
    *   **整果损耗**：长时间摆放会失水干瘪、表皮变褐。如果门店日客流低于500人，整果积压风险大。
    *   **切好的损耗**：切开后必须在**2小时内**售出，否则褐变、腐败极快。切好的损耗风险更高，但对销售能力强的门店，可通过“卖相好”掩盖部分青果表皮瑕疵。

3.  **消费场景与人群**
    *   **社区店/家庭客群**：更倾向买整果，因为“看得见的完整”和“回家自己切最新鲜”。若客群为拖家带口的，整果更合适。
    *   **写字楼店/商业区白领**：几乎只接受切好的。他们没时间处理，且一次只吃一盒。**如果你在商业区只卖整果，几乎死路一条。**

4.  **采购与催熟能力（关键约束）**
    *   市场上很多菠萝到店时并非完全成熟（尤其海南菠萝常是青皮）。
    *   如果整果还酸涩就被切开卖，投诉会瞬间拉低门店口碑。
    *   **整果**可以通过“催熟剂（乙烯利）+常温放置”控制到最佳口感再上架。**切好的**要求果子到货当天必须达到**9成熟以上且完全转黄**才能出肉。这就要求采购必须对果源成熟度判断精准。

**二、 实战建议（针对绝大多数商超）**

1.  **混卖比例参考**：建议**整果占比60%，切盒占比40%**。整果做引流和走量，切盒做利润和体验。

2.  **切盒的“黄金处理”规则**：
    *   **必须削皮去眼**，保留果肉完整或切块装盒。
    *   **必须用盐水或淡糖水浸泡后沥干**再装盒，提升甜度和去涩味。
    *   **盒子上贴“建议X小时内食用”**，并使用专门的**气调包装（充氮/减少氧气）**可延长至1天。

3.  **识别“可切”的信号**：
    *   整果一旦出现**表皮变软、果眼发黑**，或**有明显的“菠萝蜜”香味**（说明过熟了），立刻转入切果区，止损变利润。

4.  **一个影响销量的细节**：
    *   商业区的店，切果区必须**靠近收银台或出入口**，且上方要有灯光照射（亮黄色灯光照射果肉，视觉效果极佳，能直接促单）。
    *   社区店，切果可以放在生鲜冷柜中，但**要避免和剥好的柚子、芒果混放太久**。

**三、 结论（给直接判断）**

*   **如果你周边是人口密集的成熟社区，且你有冷藏展示柜** → **主推整果**（旁边配一个“免费帮切”服务台，引导顾客买整果，凭小票免费切块），这样既保毛利又解决顾客动手难。
*   **如果你在写字楼、学校周边或便利店型超市** → **必须卖切盒**，且优先用小盒单人装。
*   **如果你只能二选一，且门店很小** → **切好的更稳妥**。因为切好的菠萝只要卖相好，复购率极高，且能快速出清，不压库存。而整果一旦卖不动，占场地且熟透后价值归零。

**补充提醒**：无论选哪种，**千万不要售卖“已去壳但未切块、整根泡水”的菠萝**（这是早些年超市常见做法，消费者买回去用手抓着啃，不仅污染且毫无价值感，已被淘汰）。
