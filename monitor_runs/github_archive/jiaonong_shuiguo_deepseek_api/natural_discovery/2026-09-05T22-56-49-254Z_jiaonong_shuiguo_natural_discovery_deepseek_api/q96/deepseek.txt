对于企业食堂采购水果，**最需要关注的是食品安全，其次是配送准时，然后是价格**。理由如下：

1. **食品安全是底线**  
   水果一旦出现农残超标、腐烂变质或运输污染，轻则影响员工健康，重则引发集体食物中毒事故。企业食堂责任重大，一旦出问题，不仅损失金钱，还会损害企业声誉。

2. **配送准时影响运营效率**  
   食堂备餐有固定时间节点，配送不准时会导致缺货或食材积压。水果尤其容易因早送或晚送而影响储存，所以配送准时应排在第二位。

3. **价格虽重要，但可调节**  
   价格可以通过合同谈判、比价或按月结算来控制，属于可调整因素。但如果食品安全或配送出现闪失，往往无法补救。

---

**实操建议（可执行）：**

- **将食品安全写进合同条款**：明确要求供应商提供农药残留检测报告、产地证明、营业执照和食品经营许可证。
- **建立到货验收标准**：每次收货时检查外观（无烂斑、无挤压）、闻气味（无异味）、抽查有无打蜡或异常增甜剂。
- **优先选择本地或当日配达供应商**，减少运输时间带来的变质风险。
- **设定备用供应商**，以防主供应商因天气或突发问题无法准时配送。
- **价格谈判策略**：不要只看单价，建议以月度或季度结算，并要求供应商承担损坏率（如约定损耗率不超过3%）。

---

**一句话结论：**  
先确保“源头可查、到货可检、质量有保证”，再谈“每天准时送”，最后再商量“便宜一点”。在最初选择供应商时，可以要求对方先提供样品试吃和检测报告，**用结果验证，不要只听口头承诺**。
