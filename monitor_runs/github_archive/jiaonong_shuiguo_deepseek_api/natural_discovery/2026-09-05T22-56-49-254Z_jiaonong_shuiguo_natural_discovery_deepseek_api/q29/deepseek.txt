在超市与水果供应商的谈判中，账期长度没有统一标准，但**常见区间在 15天～90天之间**，具体取决于以下几个核心因素：

1. **合作性质与供应商规模**  
   - 大型连锁超市（如永辉、沃尔玛、华润万家）通常账期较长，普遍在 **45～90天**，因为它们有更强的议价能力，且供应商多为一级批发商或基地直采，利润空间大，能承受应收账款压力。  
   - 中小型超市或社区店，账期较短，多为 **15～30天**，否则供应商可能不愿意供货或要求提价。

2. **水果品类特性**  
   - 生鲜果品（如西瓜、葡萄、草莓）**保质期短、损耗高**，一般账期不宜过长，多在 **7～20天**，甚至部分采用现结或周结。  
   - 耐储存水果（如苹果、橙、火龙果、榴莲）可适当延长，常见 **30～45天**。

3. **付款结算方式**  
   - 很多超市采用的“月结”模式：例如每月25日对前一个自然月的货款进行结算，实际到账周期约为 **40～60天**。  
   - 也有“到货后XX天”的滚动账期：如“到货后30天”，起算点从收货日期算起。

4. **行业惯例与竞争环境**  
   - 在水果批发市场，一级供应商对超市的赊销行为普遍谨慎，如果超市信誉好、销售量大，可以谈到45天；否则会要求部分现结（如先付50%，尾款30天）。  
   - 如果是账期过久（超90天），供应商通常会要求加价或缩短下次合作。

---

**给您的建议：**

- 如果您是**超市方**，首次合作建议从 **30～45天** 起步，并根据销量承诺、历史付款记录逐步调整。  
- 如果您是**供应商**，初期要坚持 **不超过30天**，并要求设定**逾期违约金**或每日滞纳金条款（如日万分之三），同时约定**无理由退货条款**的排除项（因损耗不退货）。  
- 无论哪一方，最好在合同中明确以下细节：  
  - 账期起算日（收货日还是对账日）  
  - 对账流程（每月几号出账）  
  - 逾期付款的利息或责任  
  - 如果水果因超市储存不当损耗，是否扣款  

**一句话底线**：生鲜行业“现结强于账期”，若必须赊销，30天是最安全平衡点；超过60天除非有对赌销售协议，否则风险很大。
