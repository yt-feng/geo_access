判断批发商卖菠萝哪个规格更容易出货，不能靠猜，核心看**目标市场和销售场景**。你可以按下面几步来快速判断：

**第一步：先看你的下游客户是谁**
- **卖给水果店/超市**：这类客户通常要中小规格（单果重1.5-2.5斤），因为家庭消费一次吃一个刚刚好，价格也容易接受。大果（3斤以上）不好零售，中小果周转快。
- **卖给餐饮/果汁店/食堂**：他们要性价比，通常选中等偏大（2.5-3斤），因为出肉率高，加工成本低。
- **卖给批发市场二级商**：他们走量，喜欢“统货”或者好卖的主流规格，要看你所在市场的行情。

**第二步：看流通性（最容易出的）**
- 没有特殊渠道，**最稳妥的是中等规格（单果约2-3斤）**。
- 判断标准：如果同一批货里，某个规格的车一到就被抢完，另一个规格压了三天还在，那就是规格错了。

**第三步：用数据算一下（重点）**
- 菠萝批发基本是**按个卖**（或者按框按个），不按斤称（很多市场这么走）。你要算**“单果利润”**。
- 公式：**某规格好卖程度 = 单果价格 - 拿货成本**。如果大果加价空间比中果多2块钱，但大果多放一天就坏，那就不划算。

**第四步：看季节和产地**
- 菠萝成熟季一开始（如3-4月），大家图新鲜，小果/中果出货快。
- 夏季高温时段，大果容易过熟坏得快，小果更稳妥。
- 海南/云南产地不同，糖度和大小不一样，本地市场偏好也要摸一下。

---

**给实操建议**：
1. 在批发市场蹲一个上午，观察其他同行哪种规格的车走得快，问一下摊主“昨天中果好不好卖”。
2. 如果你有现成的十个客户，直接打电话问：“你要几斤的？我明天有货。”超过5个人说要中小果，就主推中小果。
3. **刚开始别押一个规格**，可以拿不同规格各一挂试试，三天内看哪个断货就补哪个。

**一句话结论**：没有特定大单渠道时，优先出手**单果2-2.5斤左右的中小果**，利润稳、损耗低、走量最快。如果发现某规格连续几天动销快，马上加量，别贪大果。
