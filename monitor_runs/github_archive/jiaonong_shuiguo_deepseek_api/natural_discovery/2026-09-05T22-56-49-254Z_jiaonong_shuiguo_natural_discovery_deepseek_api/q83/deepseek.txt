生鲜电商水果到货后出现坏果，责任划分主要取决于**损坏原因、收货时效、储存和物流环节**，具体可以这样判断：

---

**一、责任划分的核心逻辑：谁有过错，谁担责**

1. **收货时已经损坏（源头问题）**  
   - 如果顾客签收或开箱时，水果已经明显腐烂、压坏，且包装完好（非人为破坏），责任在**商家/采摘分拣环节**。  
   - 常见情形：发霉、软烂、虫蛀、包装挤压导致变形。  
   - 责任方：商家需退款、补发或赔偿。

2. **运输途中损坏（物流环节）**  
   - 如果水果在快递运输中因碰撞、温度过高、暴力分拣导致坏果，但包装标签完好，责任在**物流承运方**（快递公司）。  
   - 需要商家先行赔付顾客，再由商家向物流追偿（因为顾客与物流无直接合同关系）。

3. **收货后储存不当（顾客责任）**  
   - 如果顾客签收后，放置过久（超过平台约定的“签收后24-48小时”黄金保鲜期），或放在高温、潮湿环境导致变质，责任在**顾客**，商家可拒绝赔付。  
   - 但注意：商家必须给出明确的储存提示，且要提供合理的坏果举证期限。

4. **混合原因（如运输延迟+天气高温）**  
   - 如果属于不可抗力（极端天气、疫情封控）导致的派送延误，且已提前通知，通常双方均无重大过错，建议**商家承担一定补偿**（如优惠券、部分退款）以维护口碑。

---

**二、实操建议：如何处理投诉**

1. **第一时间固定证据**  
   - 顾客：拍下坏果和包装箱的整体照片/视频，最好带快递单号、时间水印；保留好订单编号。  
   - 商家：要求顾客提供清晰照片，核对是否属于运输包装破损（外箱变形、水渍）还是内部变质。

2. **按“售后时效”和“商品标准”核对**  
   - 查看商品详情页是否注明了“签收后XX小时内可售后”或坏果率赔付标准（例如坏果率≤5%不赔付，超过则按比例赔）。  
   - 平台（如京东、盒马、每日优鲜等）一般有“坏果包赔”规则，通常要求顾客在签收后24小时内发起投诉，超过期限不处理。

3. **协商处理方案**  
   - 轻微损坏（1-2个坏果）：通常按比例退款或补发等价商品。  
   - 大面积损坏（超过50%）：建议全额退款，无需退货（避免二次物流浪费和传染）。  
   - 顾客拒收或要求上门取件退货，也属合理诉求。

4. **留好转运沟通记录**  
   - 在平台内沟通（避免微信外流），明确“谁提出、谁同意”的关键话术，防止后续纠纷升级。

---

**三、常见争议点提示**

- **“到货次日损坏”**：如果水果是熟果（如香蕉、牛油果），顾客放置一天内自然成熟变软，不属于质量问题，商家可不全赔，但可给部分安抚。  
- **“包装内垫纸湿透”**：若湿透说明冷链失效，责任在商家或物流，商家需负责。  
- **“坏果率极低”**：如整箱20个只有1个坏，且未超5%标准，商家有权拒绝全额退款，但建议给优惠券换好评。

---

**总结一句：**  
- 开箱即坏→商家赔；路途损坏→商家先赔再找物流；签收后超过保鲜期变坏→顾客自负。

如果顾客投诉激烈且涉及金额较小，建议商家为了口碑选择补偿（哪怕责任不在己），因为差评损失远大于退款成本。如果金额较大，务必按平台规则和电商法处理，保留所有证据。
