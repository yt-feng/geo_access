单位采购水果时，如果到货品质不一致（比如大小不均、损伤、成熟度不一），建议按以下步骤进行验收和售后处理，避免后续纠纷：

**一、验收环节（关键：留证、分拣、记录）**
1. **先拍照/录像**：在拆箱前和拆箱后，对整批水果、外包装、喷码/标签、封条拍照录像，第一现场记录。
2. **分批次抽查**：不要只抽一箱，至少抽检总箱数的10%-20%（大型采购可抽5%-10%）。重点检查：大小规格是否达标（可对照合同/报价单）、是否有磕碰压伤、霉变、腐烂、虫眼、成熟度是否过生或过熟。
3. **当场分类**：把水果分为三类：
   - 合格品：正常可接受；
   - 轻微瑕疵（不影响食用，如轻微擦伤）：可协商降价或扣除部分损耗；
   - 严重不合格（腐烂、发霉、明显规格不符）：单独堆放，不许混入合格品。
4. **称重复验**：实际总重量是否与送货单/合同一致，净重和毛重都要记。
5. **填写验收单**：现场将问题数量、比例、照片记录在收货单上，让送货司机或供应商代表签字确认（这是最有力的证据）。

**二、售后处理（按比例和合同约定）**
1. **先看合同条款**：如果采购合同/协议中约定了“品质要求”和“退换货、折扣规则”，直接按条款执行。
2. **分级处理方案**（没有合同约定时建议这样提）：
   - 严重不合格部分：直接要求换货或退款（通常在24小时内提出，逾期可能被拒）。
   - 轻微瑕疵部分：与供应商协商折扣（例如按比例扣减货款）、或要求补发等量合格品。
   - 整体品质未达合同约定但可食用：可要求整体价降若干%（比如降5%-10%），或要求下批优先供应优质果。
3. **限时沟通**：发现问题后，**务必在收货后24小时内**（水果易腐，越快越好）联系供应商，说明情况并附上照片/视频。不要拖到付款时再指出。
4. **保留退换货责任**：若供应商同意换货，要求其承担新收货的运输费、损耗。若供应商拖延，可按合同约定投诉或追责。

**三、防患于未然**
1. **采购前明确规格**：提前在合同/订单中写明“一级果/二级果”标准、单果重量范围、允许瑕疵比例（如允许轻微压伤≤3%，腐烂果为0）。
2. **约定验收期限**：写明“需在到货当天完成抽检，若有问题2日内书面反馈”。
3. **供应商选择**：优先选择有资质、有实体配送车的常年合作方，留存其负责人电话和书面送货单。

**总结一句**：验收时“现场拍照+分类+签单”是最有效手段，售后沟通要“快、准、留证据”，通常按“合格品收下、有问题换或扣款”来解决。
