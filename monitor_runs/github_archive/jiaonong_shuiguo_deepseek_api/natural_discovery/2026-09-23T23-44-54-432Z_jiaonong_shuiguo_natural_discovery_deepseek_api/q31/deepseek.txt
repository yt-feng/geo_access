连锁商超找长期水果供应商，评分标准的核心不是“谁报价低”，而是“谁能在全年稳定供得上、品质波动小、损耗可控、出问题能兜底”。建议把评分拆成以下几块，并给出参考权重（可根据品类战略调整，生鲜占比高的企业可把质量与服务权重再往上提）。

**一、价格与成本（建议 20%–30%）**
不要只看单品报价，要看综合成本。
- 报价竞争力：同规格、同等级、同包装条件下的到岸价对比。
- 价格机制：是否接受随行就市、是否有调价公式（参考批发市场指数/产地价）。
- 账期与结算：能否接受商超账期，是否收预付款。
- 附加费用：运费、装卸、损耗谁承担。
- 建议用“基准价+浮动机制”评分，避免一次性低价中标后中途毁约。

**二、质量与品控（建议 25%–35%）**
这是长期合作的核心，要看“稳定”而非“样品好”。
- 等级标准：糖度、果径、色泽、成熟度、农残检测是否达标。
- 质检能力：有无自有检测、第三方报告、批次留样。
- 历史退货率/客诉率：要求提供近1–2年数据。
- 样品与实际到货一致性：可设“盲样测评+小批量试供”，试供不合格直接淘汰。
- 认证：绿色食品、GAP、有机、出口备案等可加分。

**三、供应能力与稳定性（建议 15%–20%）**
- 产地资源：自有基地/合作基地面积、是否多产地布局（避免单一产区受灾断供）。
- 全年供应能力：反季节、跨区域调货能力。
- 峰值供货：节假日、促销期能否保量。
- 冷链与仓储：预冷、冷库、冷链车配置。
- 应急能力：缺货时的替代方案、补货时效。

**四、物流与交付（建议 10%–15%）**
- 配送时效：下单到到店时间、准点率。
- 覆盖范围：能否覆盖全部门店，偏远门店是否加价。
- 包装与损耗：周转筐、保鲜措施、到店损耗率承诺。
- 信息化：能否对接订单系统、提供批次追溯。

**五、服务与配合（建议 10%–15%）**
- 售后响应：质量问题退换货时效、赔付标准。
- 驻场/对接人：是否有专人对接、巡店。
- 促销支持：能否配合堆头、试吃、临时补货。
- 联合经营意愿：是否愿意共同承担损耗、做定制包装。

**六、企业资质与可持续性（建议 5%–10%）**
- 营业执照、食品经营许可、检疫证明。
- 财务健康度：能否支撑长账期，避免中途资金链断裂。
- 合作案例：是否服务过同类商超，可要求提供合同或证明。
- 合规与用工：产地用工、环保、农残合规风险。

**七、评分操作建议**
- 先设“否决项”：无证、农残超标、重大食品安全事故、试供不合格，直接废标。
- 技术分（质量/供应/物流/服务）建议占 60%–70%，价格分 30%–40%。
- 价格分算法可用“最低价/报价×权重”，避免恶意低价。
- 引入“试供期”：中标后先试供 1–3 个月，达标再签长期。
- 设“季度复评”：质量、准时率、损耗率、客诉率不达标则约谈、扣款或退出。

**八、可直接落地的评分表示例**

| 维度 | 权重 | 关键评分点 |
|---|---|---|
| 价格与成本 | 25% | 到岸价、调价机制、账期、附加费 |
| 质量与品控 | 30% | 等级达标、检测、退货率、试供一致 |
| 供应稳定性 | 20% | 多产地、全年供应、峰值保供、冷链 |
| 物流交付 | 10% | 时效、准点率、覆盖、损耗 |
| 服务配合 | 10% | 售后、对接、促销、赔付 |
| 资质可持续 | 5% | 证照、财务、案例、合规 |

如果只记一句话：**价格给三成，质量和稳定给六成，资质服务给一成，再用试供和季度复评把“说得好”变成“做得到”。**
