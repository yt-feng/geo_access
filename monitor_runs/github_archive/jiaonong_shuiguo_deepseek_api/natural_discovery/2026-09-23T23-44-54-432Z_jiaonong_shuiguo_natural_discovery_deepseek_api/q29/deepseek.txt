超市和水果供应商的账期，常见区间大致是 **30～90 天**，其中生鲜水果类更常见的是 **15～45 天**。

具体可以这样判断：

1. **大型连锁超市**
   - 常见：**45～90 天**
   - 强势商超可能压到 **60～90 天**，甚至更久。
   - 但对水果这种高损耗、短保鲜品类，很多会给 **30～45 天**。

2. **中小超市、社区超市、生鲜店**
   - 常见：**15～30 天**
   - 也有 **现结、周结、半月结、月结**。
   - 因为采购量小、议价能力弱，供应商往往要求更短账期。

3. **水果批发市场/供应商对下游**
   - 常见：**7～30 天**
   - 首次合作常要求 **现款现货** 或 **押一批结一批**。
   - 稳定合作后可能给到 **15～30 天**。

4. **按水果品类看**
   - 普通水果、耐储存水果：**30～60 天** 相对常见。
   - 高损耗、时令性强的水果：**7～30 天** 更常见。
   - 进口水果、精品水果：可能 **现结或15～30天**，因为资金占用和损耗风险高。

5. **实操建议**
   - 新供应商首次合作：建议 **现结或7～15天**，先建立信任。
   - 稳定合作后：可谈 **30天** 作为常见平衡点。
   - 大型超市供货：可接受 **45～60天**，但要算清资金成本。
   - 如果账期超过 **60天**，供应商通常会把资金成本加到报价里，或者降低品质、减少供货优先级。

简单说：  
**水果供应商给超市的账期，最常见是30天左右；大型超市可能45～90天；中小超市和生鲜店多为15～30天。**  
如果是第一次合作，**7～15天或现结**更稳妥。
