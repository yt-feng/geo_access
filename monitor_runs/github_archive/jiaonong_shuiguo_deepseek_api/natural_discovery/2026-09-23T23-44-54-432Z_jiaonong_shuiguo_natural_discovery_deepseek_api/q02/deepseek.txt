对小水果店，**不能只选一个“最看重”，而是要分优先级**。更实用的排序是：

**1. 熟度 → 2. 坏果率 → 3. 价格 → 4. 送货速度**

但会随你的经营方式变化：如果你当天就能卖完、只做线下，熟度最重要；如果做外卖/果切/促销，速度和价格权重会上升。

### 为什么这样排

**1. 熟度排第一**
香蕉是后熟水果，进货太生，几天不黄、口感差、顾客不买；太熟，当天卖不掉就快速发黑、出水、报废。  
对小店来说，熟度直接决定：
- 能不能当天上架卖
- 顾客复购和口碑
- 损耗速度

理想做法是：**按销售节奏进不同熟度**，不要一次全进一个成熟度。比如：
- 今天主卖的：黄中带一点青，或刚转黄
- 明后天卖的：青一点
- 做特价/果切的：偏熟但没坏

**2. 坏果率排第二**
香蕉损耗高，坏果率一高，再便宜也可能亏。  
要重点看：
- 是否有压伤、裂口、黑斑、霉点
- 箱内是否大小严重不均
- 是否催熟过度或运输受热

建议每次到货抽检，记录坏果率。如果长期超过你能承受的范围，就该换供应商。

**3. 价格排第三，不是不重要，而是不能单独看**
便宜但熟度差、坏果多，实际成本更高。  
你要算的是：**到手可卖成本 = 进价 ÷ 可卖比例**。  
比如：
- A家进价低，但坏果20%，可卖80%
- B家进价高10%，但坏果5%，可卖95%
往往B家更划算。

**4. 送货速度排第四，但特殊情况可前移**
如果你做外卖、果切、社区团购，或者经常临时补货，送货速度就很重要。  
如果只是线下慢慢卖，送货慢一点但品质稳定，可以接受。

### 给小水果店的实操建议

- **日常主供货商**：选熟度稳定、坏果少、能按你要的成熟度发货的。
- **备选供货商**：选价格低或送货快的，用于促销、补货、果切。
- **每次进货**：不要只进一个熟度，按“今天卖 / 明天卖 / 后天卖”搭配。
- **考核供应商**：记录三项就够：坏果率、到货熟度、实际可卖比例。
- **价格判断**：只比“可卖成本”，不要只比每斤进价。

一句话：**先保熟度和坏果率，再谈价格；送货速度看你的销售模式决定权重。**
