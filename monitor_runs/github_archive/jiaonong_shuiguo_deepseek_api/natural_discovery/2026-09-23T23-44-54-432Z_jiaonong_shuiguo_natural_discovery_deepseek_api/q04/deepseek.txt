如果目标是**减少香蕉在店里放坏**，采购时要同时管住“到货熟度”和“到货节奏”，核心是让香蕉在店里还有足够货架期，而不是到店即卖或到店即坏。

可以直接这样要求供应商：

1. **按销售速度定熟度**
   - **快销店/客流大**：可要到货熟度 **3.5～4.5成**，颜色偏绿、微黄，适合1～3天内陆续转黄销售。
   - **普通水果店**：建议 **3～4成**，青绿为主，少量转黄，给门店留出2～4天销售窗口。
   - **客流慢/天气热**：建议 **2.5～3.5成**，更生一点，避免到店后集中催熟。
   - 如果供应商用“几号色”或“青/微黄/黄熟”描述，要求写进订单：**到货以青绿为主，允许少量微黄，不允许大面积黄熟、起黑点、果柄发黑。**

2. **要求到货时间配合销售节奏**
   - 最好要求 **清晨到货或上午到货**，不要下午晚到、晚上到。
   - 理由：上午到货可当天上架、分拣、控温；晚上到货往往闷在仓库或车厢里，第二天成熟度会跳升。
   - 如果一天多次补货，要求 **少量多次**，不要一次压太多货。
   - 周末、节假日前可适当提前，但熟度要更生；节后或雨天要减量、降熟度。

3. **明确运输和到货温度**
   - 要求 **冷链或阴凉运输**，避免暴晒、闷热。
   - 香蕉怕冷也怕热：一般运输储存建议 **13～15℃左右**，不要低于12℃太久，也不要高温闷放。
   - 到货时如果车厢温度高、果身发热，说明催熟或闷熟风险大，要拒收或折价。

4. **验收标准写清楚**
   采购单或微信下单时最好写明：
   - 到货熟度：**以青绿为主，微黄不超过约10%～20%**。
   - 拒收标准：**大面积黄熟、黑斑多、果柄发黑、发软、有酒味、裂果、冻伤**。
   - 单把重量/规格稳定，不要大小混太严重。
   - 允许轻微青涩，但不能“硬得发白”或“已经软熟”。

5. **按销量反推采购量**
   - 不要只盯熟度，还要控制量。
   - 例如：日销10把，到货熟度3～4成，通常一次到货 **1～1.5天销量**较稳；天热时甚至按 **半天到1天销量**补。
   - 快转黄的放前面，青的放后面，先进先出。

6. **和供应商约定调整机制**
   - 可要求：**“到货太熟可退换/补差”**。
   - 连续几次到货过熟，就要求下一批降熟度、改早到、减量。
   - 如果供应商只能给固定熟度，就改为 **增加采购频次、每次少拿**。

一句话采购要求可以这样发：

> “香蕉请按3～4成熟到货，以青绿为主，微黄不超过两成；上午到货，冷链/阴凉运输，不要下午晚到。大面积黄熟、黑斑、发软、有酒味的不要。先按我们日销量的1～1.5天少量多次补，天气热再减量降熟度。”

这样做的逻辑是：**用更低熟度换货架期，用更早到货换操作时间，用更小批量换周转速度**，三者一起才能明显减少放坏。
