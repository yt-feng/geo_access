判断水果供应商靠不靠谱，核心不是听他怎么说，而是用“小批量试单 + 固定标准验收 + 连续复盘”去验证。给你一套可直接执行的方法。

**一、先明确你长期要的硬标准**
香蕉和菠萝的验收重点不同：

香蕉重点看：
- 到货成熟度是否稳定：太生、太熟、青黄不均都影响销售。
- 是否有催熟处理说明：是否按你的销售节奏供货。
- 单串/单根重量、条数是否稳定。
- 碰伤、黑斑、裂口、掉把比例。
- 产地和季节切换是否提前告知。

菠萝重点看：
- 品种是否稳定，比如同一品种不要今天一个明天一个。
- 果形、单果重、成熟度是否一致。
- 黑心、水心、烂心、裂果比例。
- 到货时是否已经过熟，损耗多大。
- 是否支持按规格分档，比如小果、中果、大果。

你先把这些写成一张验收表，后面所有供应商都用同一张表打分。

**二、用试单验证，不要一上来压大货**
新供应商先做 2—3 次小批量试单，每次不要超过你正常单次进货量的 20%—30%。

重点观察：
1. 报价是否清楚：是否含运费、是否含税、是否含损耗补偿。
2. 到货是否准时：迟到几个小时、几次。
3. 品质是否稳定：不是看最好的一箱，而是看最差的一箱。
4. 损耗怎么算：坏了是否补、怎么补、多久补。
5. 沟通是否顺畅：临时加单、减单、改规格时反应如何。
6. 缺货时怎么办：是提前说，还是到货前才告诉你没货。

**三、连续记录，别凭感觉**
每次到货记录这些数据：
- 到货时间
- 总件数/总重量
- 不合格数
- 实际损耗率
- 可售比例
- 售价和毛利
- 售后处理结果

比如香蕉到货 100 斤，挑出碰伤、黑斑、过熟 12 斤，损耗率就是 12%。如果连续三次都超过你设定的上限，比如 8%，这个供应商就不适合长期合作。

**四、问几个关键问题，看他是否专业**
可以直接问：
- 香蕉是哪里产的，什么季节切换，催熟到什么程度发货？
- 菠萝是什么品种，一级果和二级果怎么分？
- 如果到货损耗超过约定比例，怎么赔？
- 能不能固定每周几送，临时补货多久能到？
- 价格随行情怎么调，提前几天通知？
- 能不能先发一箱样品，运费怎么算？

靠谱供应商通常会给你明确答复，而不是含糊说“放心”“都很好”。

**五、看风险信号**
出现这些情况要谨慎：
- 报价明显低于市场价，但品质解释不清。
- 不让你看样，或者样品和大货差距大。
- 损耗赔偿口头承诺，不愿写进单据。
- 经常迟到、缺货、临时换品种。
- 到货好坏波动很大，靠运气。
- 出问题后推责任，不处理售后。

**六、最终判断标准**
一个供应商能不能长期合作，看四点：
1. 品质稳定，不是偶尔好。
2. 损耗可控，算上损耗后仍有利润。
3. 供应稳定，旺季淡季都能按时给货。
4. 售后明确，出问题有规则可依。

建议你同时保留 2 家供应商，一家主供、一家备用。香蕉和菠萝最好分开找更专业的供应商，不要指望一家什么都最强。先用小单跑一个月，按验收表和损耗率决定是否转为长期主供。
