水果店遇到坏果，结算或赔付通常取决于**合同约定、验收节点、坏果比例和坏因归属**。实操上可以按下面这套规则处理。

## 1. 先分清责任节点

**到货验收时发现的坏果**
- 一般由供应商承担。
- 常见做法：当场拍照、视频、称重、记录箱号/批次，按坏果数量扣款，或要求补货。
- 如果合同写的是“到岸合格率”，比如到货合格率低于95%，超出部分由供应商赔。

**验收后存放期间发现的坏果**
- 要看坏因：
  - 供应商发货时已潜伏的腐烂、熟度过高、冷害：仍可找供应商，但要有证据。
  - 门店储存不当、挤压、温度不对、超期：通常门店自担。
- 很多生鲜合同会约定“验收后24小时/48小时内提出异议有效”，超过时限难追责。

**销售过程中顾客退回的坏果**
- 对顾客：门店一般应退换或赔偿，这是门店对消费者的责任。
- 对供应商：能否追偿，取决于是否属于批次质量问题，以及合同有没有“售后坏果分担”条款。

## 2. 常见结算方式

**按比例扣款**
- 例如：到货100箱，抽检发现8箱坏果，按8箱货款扣减。
- 更严谨的是：按坏果重量/件数占该批次比例，扣减对应货款。

**补货冲抵**
- 供应商下次送货时补同等数量或金额。
- 适合长期合作、坏果比例不高的情况。

**折价接收**
- 坏果不退回，但按残值或折扣价结算。
- 例如：好果按原价，坏果按30%结算，或直接扣掉坏果部分。

**退货退款**
- 坏果比例很高、整批不合格时，可要求退货并由供应商承担运费。
- 若已付款，可要求退款或冲抵后续货款。

**按合同违约金/质量保证金扣**
- 有些供应商合同会约定质量保证金、批次罚款、合格率不达标扣款。
- 有约定从约定，但扣款金额要合理，不能随意超额。

## 3. 赔付时通常怎么算

可以按这个顺序谈：

1. **只赔坏果本身**：坏多少赔多少，最简单。
2. **赔坏果+运费/损耗**：如果整批退货，供应商承担来回运费。
3. **赔坏果+门店损失**：如果因坏果导致顾客投诉、下架、报废，可协商额外补偿，但要有依据。
4. **按合格率结算**：  
   - 应付货款 = 总货款 × 实际合格率  
   - 或：扣款 = 总货款 × 坏果比例

举例：  
进货1000元，抽检坏果10%，若约定坏果由供应商承担，则可扣100元，实付900元；若约定坏果按50%折价，则扣50元。

## 4. 关键证据要留好

- 到货时间、批次、车牌/送货单
- 开箱前外包装照片
- 坏果开箱照片、视频
- 坏果称重记录、数量清点
- 抽检比例和抽检方法
- 与供应商的聊天记录、电话录音、书面确认
- 顾客退货记录、销售损耗记录

没有证据，事后很难让供应商认账。

## 5. 建议的合同写法

以后和供应商合作，最好写清楚：

- 验收标准：品种、规格、成熟度、合格率
- 验收时限：到货后几小时内提出异议
- 坏果处理：扣款、补货、退货、折价，选一种或组合
- 坏果比例阈值：例如超过3%由供应商承担
- 运费承担：退货、补货运费谁出
- 付款方式：验收合格后付款，或先扣质量保证金
- 争议处理：以照片、视频、第三方检测为准

## 6. 实际谈判建议

- 小比例坏果：优先补货或下次扣款，别把关系搞僵。
- 大比例坏果：先书面通知供应商，暂停付款，保留退货权利。
- 长期合作：建立“批次质量台账”，每月汇总扣款，比每次扯皮更有效。
- 如果供应商不认：可依据合同、送货单、聊天记录协商；协商不成再考虑投诉、诉讼或行业调解。

一句话：**验收前坏果通常供应商担，验收后要看坏因和合同；结算上优先按坏果数量/比例扣款或补货，整批严重不合格才退货退款。**
