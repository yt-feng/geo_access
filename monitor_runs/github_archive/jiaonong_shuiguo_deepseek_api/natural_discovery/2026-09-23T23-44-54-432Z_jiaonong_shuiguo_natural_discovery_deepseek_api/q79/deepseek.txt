**先问售后，再问配送，最后才谈价格。**

排序理由很简单：水果是**高损耗、非标、强时效**的品类，团长最怕的不是进货贵一点，而是**烂果、缺斤少两、迟到、售后扯皮**。这三项里，售后决定你會不會自己贴钱赔客户，配送决定客户体验和复购，价格只决定你赚多赚少。

更具体判断：

1. **售后必须先问清**
   - 烂果、压伤、漏发、少重怎么赔？
   - 是补发、退款，还是按比例赔？
   - 售后时效多久？超过多久不认？
   - 需要拍照/视频吗？团长先垫赔还是供应商直接赔？
   - 损耗率超过多少算供应商责任？
   - 这点不问清，最后往往变成团长自己承担。

2. **配送第二问**
   - 几点到？能不能按团购截单时间送？
   - 送到自提点还是送到团长手上？
   - 冷链还是普通车？夏天/冬天怎么处理？
   - 破损、延误谁负责？
   - 临时加单、改量能不能配合？
   - 配送不稳，客户第一次就可能流失。

3. **价格最后谈，但要谈“综合价”**
   - 不只看单价，要算：进货价 + 损耗 + 售后赔付 + 配送费 + 时间成本。
   - 低价但售后差，通常最贵。
   - 可以要求阶梯价、账期、坏果包赔比例，而不是只砍单价。

**一句话建议：**
先拿售后条款筛掉不靠谱的，再用配送能力筛掉不稳定的，最后在剩下的人里比价格。顺序反了，容易选到“便宜但赔钱”的供应商。
