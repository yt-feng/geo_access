判断供应商能不能按时到车，核心不是听承诺，而是看他**当下的货、车、人、流程是否已经锁定**。你可以按下面这套方法快速判断。

**一、问关键节点，不听“大概”**
直接问这4个问题：
1. 货现在在哪？是地里、装车点、还是已经在路上？
2. 车定了没有？车牌号、司机电话、车型载重是多少？
3. 什么时候装车？什么时候发车？预计到市场几号几点？
4. 如果延误，最晚什么时候到？怎么赔？

能马上给出车牌、司机电话、装车时间的，可信度高；只说“明天给你发”“放心”的，风险大。

**二、看是否“车货已匹配”**
按时到车的关键是：**货已备好 + 车已到位 + 装车时间已定**。
- 货没砍、没装、还在等价格，基本容易拖。
- 车没定，只说到时找车，旺季很容易耽误。
- 装车时间含糊，比如“这两天”，通常不可靠。

**三、查历史履约**
合作前问：
- 最近3车香蕉分别发到哪里？
- 能不能给最近合作客户的电话？
- 之前有没有延误？什么原因？
不是看他说得多好，而是看他是否敢给可核实的记录。

**四、用合同和定金约束**
至少写清：
- 品种、数量、成熟度、装车标准；
- 车牌号或最晚定车时间；
- 发车时间、到达时间；
- 延误赔偿，比如每延误一天扣多少钱或承担市场损失；
- 定金和尾款支付节点。
没有约束，口头承诺基本不可靠。

**五、看天气和产区情况**
香蕉产区遇到台风、暴雨、道路中断、春节前后运力紧张，都会影响发车。你要判断：
- 产区最近是否有恶劣天气；
- 装车地到市场是否经过易堵、易断路段；
- 当前是不是运力紧张期。
供应商如果主动提示风险并给备选方案，反而更靠谱。

**六、留备用方案**
不要只押一个供应商。至少准备：
- 一个备用供应商；
- 一个备用司机或车队；
- 如果延误，能否从附近市场临时补货。
这样即使一车没按时到，也不至于断货。

**简单判断标准：**
- 能立刻给出车牌、司机电话、装车时间、到达时间：较可信。
- 只说“明天发”“放心”：不可信。
- 不愿签延误赔偿：风险高。
- 主动说风险并给备选：相对靠谱。

最稳的做法是：**先小批量试合作一车，验证他的履约，再放量。**
