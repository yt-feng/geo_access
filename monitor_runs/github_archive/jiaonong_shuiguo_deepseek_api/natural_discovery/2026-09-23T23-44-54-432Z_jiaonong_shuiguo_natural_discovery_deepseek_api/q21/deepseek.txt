超市采购水果时，供应商通常需要提供以下几类检测报告或进货证明，具体以超市的供应商准入要求和当地市场监管要求为准：

**一、主体资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视经营性质而定）
- 若为进口水果，还需海关报关单、入境货物检验检疫证明

**二、进货凭证类**
- 供货凭证/销售单据（注明品名、数量、日期、供货方）
- 进货台账或“一票通”凭证
- 从批发市场采购的，可提供市场出具的销售凭证

**三、检测报告类**
- **农药残留检测报告**：这是水果最核心的检测项，通常要求提供批次检测报告或供货方自检报告
- **产地证明或合格证**：部分品类（如“三品一标”产品）需提供无公害、绿色、有机认证证书
- **快速检测合格证明**：部分超市要求供应商提供农残快检结果
- **第三方检测报告**：超市可能要求定期（如每季度/每批次）提供有资质机构出具的检测报告

**四、其他可能要求的材料**
- 供货商与超市签订的采购合同/质量保证协议
- 产地检疫证明（部分水果如柑橘类可能涉及）
- 包装标签合规证明

**实操建议：**
1. 先向超市采购部门确认其具体的准入清单，不同超市要求差异较大。
2. 农残检测报告一般要求与供货批次对应，注意报告时效性。
3. 进口水果的检验检疫证明必须与批次一致，否则可能被拒收。
4. 保留好每次供货的凭证和检测报告，便于追溯。
