香蕉配送中最容易出的两个问题：机械伤（压坏、蹭黑）和成熟过快（变黑）。控制思路要从**采购成熟度、包装、温控、配送节奏**四段一起抓。

**1. 采购：不要用全熟蕉发远单**
- 同城/半日达：可用 3～4 号色（微黄带绿），到手后还能放 1～2 天。
- 跨城/次日达：用 2～3 号色（青绿转色期），到消费者手里刚好开始黄。
- 完全黄熟、带黑斑的香蕉只适合即时零售短途，不适合快递。
- 采购后先预冷到 13～15℃，不要低于 12℃，否则冷害会让皮发黑、口感变差。

**2. 包装：防压 + 防摩擦 + 缓冲**
- 单根或小把用**珍珠棉网套/气柱袋**包裹，重点包住蕉指弯曲处和果柄。
- 盒内用**蜂窝纸板或珍珠棉隔层**固定，避免晃动互相摩擦。
- 外箱选**抗压五层瓦楞纸箱**，不要用软快递袋直接装。
- 箱内留少量通气孔，不能完全密封，否则水汽积聚会加速发黑。
- 蕉柄切口可用食品级蜡或保鲜膜包一下，减少乙烯和汁液外渗。

**3. 温控：13～15℃最稳**
- 配送途中尽量保持 13～15℃，夏天用冰袋时**必须隔一层纸或气泡膜**，不能让香蕉直接贴冰袋，否则局部冻伤发黑。
- 冬天低于 10℃时要加保温棉，避免冷害。
- 不要和苹果、梨、番茄等释放乙烯多的果蔬混装，会催熟变黑。

**4. 配送节奏：缩短在途时间**
- 同城优先用**即时配送/半日达**，减少中转分拣。
- 快递件尽量走**航空或直达干线**，避免多次装卸。
- 分拣时贴“易压、勿倒置、避冷冻”标签，但不要只依赖标签，包装本身要抗压。

**5. 到货体验：给用户明确预期**
- 页面标注“收到为青黄蕉，常温 1～2 天变黄，口感最佳”。
- 附一张小卡片：不要放冰箱，挂起来或平放阴凉处，远离苹果。
- 如果用户想延缓变黑，可建议用保鲜膜包住蕉柄，能多撑 1～2 天。

**最实用的组合方案：**
- 同城：3 号色 + 网套 + 隔层盒 + 13～15℃ + 即时配送。
- 跨城：2 号色 + 气柱/珍珠棉 + 五层箱 + 冰袋隔纸 + 次日达。

这样能把压坏和变黑率明显压下来。核心是：**别发太熟的蕉、别让蕉直接贴冰、别让箱内晃动、别拖在途时间。**
