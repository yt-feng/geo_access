旺季锁库存的核心不是“打个招呼让供应商留货”，而是用**可执行的合同或资金机制**把口头承诺变成有违约成本的硬约束。具体可以分四步走：

**1. 提前锁定，用“保底量+预付款”换优先权**

- 和供应商签一份《旺季保供协议》，明确：保底采购量、锁定期（如某月到某月）、单价浮动区间、每日/每周最低供货量。
- 支付预付款或定金（通常10%–30%），约定供应商若断供需双倍返还或按差额赔偿。没有资金约束的“留货”在爆单时基本靠不住。
- 对核心单品（如当季爆款水果）可以签独家或优先供应条款，避免被同行高价截胡。

**2. 多源备份，不把鸡蛋放一个篮子**

- 同一单品至少对接2–3家供应商，主供应商拿70%量，备选拿30%。主供应商断供时能快速切换。
- 提前和备选供应商也签小额定金协议，保持“热备”状态，而不是临时找货被宰。

**3. 用数据换信任，让供应商愿意优先保你**

- 把往期旺季销量、复购率、履约记录给供应商看，证明你是稳定大客户，而不是旺季来薅一把就走。
- 承诺淡季也保持基础采购量，用全年合作换旺季优先权。供应商最怕的是“旺季要货、淡季消失”。

**4. 盯紧产地和天气，提前做预案**

- 水果受天气、产地减产影响大。提前1–2个月了解主产区气候、上市时间、减产预期，必要时提前锁产地货源。
- 合同里写明“不可抗力”范围，但也要约定替代方案（如换品种、换产地、按比例供货），避免临时扯皮。

**可判断标准：**
- 如果供应商只肯口头承诺、不愿签协议或收定金，说明他也没把握，不能作为唯一依靠。
- 如果预付款比例超过30%且无履约保障，风险偏高，建议分散。
- 锁库存的最佳时机是旺季前1–2个月，太早占用资金，太晚没货。

一句话：**用合同锁量、用定金锁心、用备份锁安全。**
