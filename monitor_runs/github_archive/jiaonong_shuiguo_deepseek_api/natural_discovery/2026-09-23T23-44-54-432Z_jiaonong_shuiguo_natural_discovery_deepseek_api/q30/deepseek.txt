超市水果到货后发现品相不好，售后流程要提前在采购合同或收货标准里约定，核心是把“什么算不合格、多久内提、怎么处理”写清楚。可以按下面框架约定：

**1. 验收标准和时限**
- 明确品相标准：品种、规格、成熟度、色泽、大小均匀度、破损率、腐烂率、虫害、机械伤、异味等。
- 约定验收时限：例如到货后2小时内完成抽检，或当天完成全检；超过时限视为验收合格，避免事后扯皮。
- 约定抽检比例和判定规则：如按到货箱数抽检10%，不合格率超过5%即整批可退。

**2. 不合格分类处理**
- 轻微瑕疵：如少量压伤、外观不佳但不影响食用，可约定折价接收，例如按比例扣款。
- 中度不合格：如腐烂、虫害、成熟度过高或过低，可要求换货或补发。
- 严重不合格：如大面积腐烂、异味、农残超标风险，应约定整批拒收，并由供应商承担退货运费及损耗。

**3. 提报和取证流程**
- 到货后立即拍照、录像，保留带时间水印的凭证。
- 填写验收异常单，列明批次、数量、问题类型、抽检结果。
- 在约定时限内书面通知供应商，例如微信、邮件、系统工单，并保留送达记录。
- 双方可约定现场共同确认；若供应商不到场，超市单方验收结果可作为依据。

**4. 责任和费用**
- 明确退、换、补、折价四种方式及适用条件。
- 明确运费、分拣费、损耗、冷藏费由谁承担。
- 约定因品相问题导致无法销售时的损失计算方式，例如按采购价加合理运费赔偿。
- 约定付款抵扣：可从当期货款或保证金中直接扣除，避免供应商拖延。

**5. 时效和争议解决**
- 约定售后提报时效：如到货后24小时内提出，生鲜类可缩短到2至6小时。
- 约定处理时效：供应商应在24小时内回复，48小时内完成换补或退款。
- 约定争议解决方式：先协商，协商不成可提交合同约定地法院或仲裁机构。
- 保留样品：争议批次可封存样品，必要时送第三方检测。

**6. 建议写进合同的条款示例**
“乙方所供水果应符合附件《验收标准》。甲方在到货后2小时内抽检，不合格率超过5%的，有权拒收或要求换货。乙方应在接到通知后24小时内处理，逾期视为同意甲方按不合格部分货款的150%扣款。因品相问题产生的运费、损耗及合理费用由乙方承担。”

简单说，就是：**标准先定、时限要短、取证要快、处理方式分级、费用责任写明、付款可抵扣。** 这样到货发现品相不好时，超市按约定流程走，供应商也难推诿。
