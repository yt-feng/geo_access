结论先说：**大多数餐饮连锁采购水果，中央厨房统一收货更好**；但如果水果主要用于门店现切、现榨、摆盘，且配送半径大、门店多，**“中央厨房统采统控 + 门店二次验收”**通常是最优解。纯门店分开收货一般只适合少数场景。

可以按下面几个维度判断：

1. **食品安全与品质稳定性**
   - 中央厨房统一收货：验收标准统一，农残、成熟度、规格、损耗判定更一致，适合连锁。
   - 门店分开收货：门店执行差异大，容易出现“这家收、那家退”的标准漂移。
   - 水果如果是**直接入口、鲜切、榨汁**，统一收货优势明显。

2. **采购成本与议价能力**
   - 中央厨房统一收货：集中采购量大，议价强，能锁规格、锁价格、锁产地。
   - 门店分开收货：单店量小，价格和账期通常更差，还容易出现串货、回扣、私采。
   - 如果水果是高频大宗，比如柠檬、橙子、西瓜、苹果，统一采购通常更省。

3. **损耗与库存**
   - 中央厨房统一收货：可以做分级、催熟、分拣、预处理，把损耗集中在可控环节。
   - 门店分开收货：门店缺乏仓储和保鲜能力时，损耗反而更高。
   - 但水果保质期短，若中央厨房到门店配送链太长，也会增加二次损耗。

4. **配送与时效**
   - 门店密集、配送频次高：中央厨房统一收货更合适。
   - 门店分散、跨城、配送半径大：纯中央厨房可能不如“区域仓/区域中央厨房 + 门店验收”。
   - 对时效要求极高的鲜果，如草莓、荔枝、杨梅，最好设区域分仓，而不是全国一个中央厨房硬扛。

5. **运营效率**
   - 中央厨房统一收货：减少门店收货工作量，门店更专注前厅和后厨。
   - 门店分开收货：门店要投入人力验收、称重、退货、对账，管理成本高。
   - 连锁越大，统一收货的规模效益越明显。

6. **责任归属**
   - 中央厨房统一收货：责任集中在供应链和中央厨房，便于追溯。
   - 门店分开收货：责任分散，出现品质问题容易扯皮。
   - 但中央厨房也要避免“只收货不质检”，否则会把风险压到门店。

建议的落地模式：

- **主模式：中央厨房统一采购、统一验收、统一分级，再配送到门店。**
- **门店做二次验收：** 只检查到店后的温度、数量、外观、成熟度和破损，不重新定义采购标准。
- **区域化布局：** 门店跨区域时，设区域中央厨房或区域分仓，不要一个点覆盖全国。
- **高风险鲜果例外：** 极短保水果可由区域供应商直送门店，但必须用统一标准、统一系统、统一对账。
- **系统支持：** 采购订单、收货标准、质检结果、损耗数据都进同一套系统，否则统一收货也会变成形式。

一句话判断：
**门店少、同城、水果用于后厨加工，优先中央厨房统一收货；门店多、跨区域、水果用于门店鲜切现售，优先“区域中央厨房统一收货 + 门店二次验收”。纯门店分开收货，通常不是连锁化的最优选择。**
