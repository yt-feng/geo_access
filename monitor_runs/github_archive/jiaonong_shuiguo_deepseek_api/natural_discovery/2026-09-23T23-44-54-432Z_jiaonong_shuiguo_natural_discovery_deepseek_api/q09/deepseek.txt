水果店旺季最怕的不是价格高一点，而是关键货断、品质不稳、临时加价。和供应商谈合作时，建议把问题分成六类提前问清，并尽量写进订单或协议里。

**一、供货能力**
1. 旺季每天/每周能稳定给我供多少量？最少起订量是多少？
2. 我临时加单，提前几小时/几天通知你能接？加单上限是多少？
3. 你自己有几个产地/仓库？如果主产地受灾或涨价，有没有备用货源？
4. 爆款单品（如西瓜、荔枝、车厘子、砂糖橘）旺季能不能优先保我？

**二、价格与调价**
5. 报价是口头价还是锁价？锁多久？旺季会不会临时涨？
6. 涨价提前几天通知？我不接受的话能不能取消当批订单？
7. 不同规格、等级、包装分别什么价？次果、统货、精选果差价多少？
8. 运费、装卸费、损耗谁承担？到店价还是产地价？

**三、品质与验收**
9. 品种、产地、规格、成熟度、甜度、单果重能不能按标准写清？
10. 允许的坏果率/损耗率是多少？超出部分怎么赔、怎么补？
11. 到店验收不合格，是拒收、换货还是扣款？处理时限多久？
12. 能不能先发样品或小批量试单？试单不合格能否终止合作？

**四、配送与时效**
13. 每天几点前下单、几点送到？旺季会不会延迟？
14. 冷链还是普通车？温度、包装、防压防冻怎么做？
15. 缺货、漏发、错发时，多久补发？补发运费谁出？
16. 节假日、极端天气、交通管制时怎么保供？

**五、结算与风险**
17. 是现结、周结还是月结？要不要押金/保证金？
18. 出现质量问题、断供、临时加价，违约责任怎么定？
19. 能不能签书面协议或至少微信确认订单？对账以什么为准？
20. 如果旺季你供不上，我能否临时从别家调货而不算违约？

**六、合作策略**
21. 能不能签“保量协议”：我承诺旺季总采购量，你承诺优先供货和锁价？
22. 能不能做“主供应商+备用供应商”组合，避免把鸡蛋放一个篮子？
23. 量大能否给返点、账期、免费配送或损耗补贴？
24. 淡季能不能也照顾一下，换取旺季优先权？

**谈判时重点抓三条：**
- **保供条款**：旺季优先供货、最低供应量、缺货赔偿。
- **锁价条款**：锁价周期、调价通知期、临时涨价可取消。
- **验收条款**：坏果率标准、赔付方式、补货时限。

**实操建议：**
不要只谈一家。旺季至少谈2—3家，分为主供、备供、应急供。先小批量试单，再逐步放量。所有关键承诺尽量落到文字：微信聊天记录、订单确认、简单协议都行。口头说的“肯定给你留货”，旺季往往靠不住。
