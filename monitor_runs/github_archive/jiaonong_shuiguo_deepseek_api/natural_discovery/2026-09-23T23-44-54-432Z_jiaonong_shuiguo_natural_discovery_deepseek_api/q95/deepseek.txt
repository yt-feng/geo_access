选学校食堂水果供应商，重点不是“找最便宜的”，而是 **稳定供货 + 安全可追溯 + 损耗可控 + 结算规范**。可以按下面这套标准来筛。

## 一、先定采购要求

1. **品类和规格**
   - 香蕉：要求成熟度可控，不能一到货就全熟或发青。
   - 苹果：按大小分级，比如70#、75#、80#，避免大小混装。
   - 橙子：按果径、酸甜度、皮厚薄做要求。
   - 最好写清：单果重量/直径、成熟度、允许坏果率、包装方式。

2. **配送要求**
   - 每周送几次，是否支持临时加单。
   - 到货时间是否固定，比如早上6:30前送到食堂。
   - 是否送货到库房，是否协助卸货。

3. **验收标准**
   - 坏果率一般控制在**3%—5%以内**，超过部分退换或扣款。
   - 农残检测报告、产地证明、批次合格证要能提供。
   - 到货现场抽检：看、闻、切、称重。

## 二、供应商来源怎么找

优先顺序建议：

1. **本地大型水果批发市场里有固定档口的商户**
   - 优点是品类全、调货快。
   - 缺点是质量波动大，要签好验收和退换条款。

2. **产地合作社或果园直供**
   - 适合苹果、橙子这类耐储水果。
   - 香蕉一般不是本地直供，多经过催熟环节，要找有催熟能力的供应商。

3. **专业食堂食材配送公司**
   - 能开票、能追溯、配送稳定。
   - 价格通常略高，但管理成本低。

4. **电商/集采平台**
   - 适合应急或小批量，不建议作为唯一主供应商。

## 三、筛选供应商的实操步骤

### 1. 先要资料
让供应商提供：
- 营业执照
- 食品经营许可证
- 水果农残检测报告或承诺书
- 供货案例，尤其是学校、医院、机关食堂案例
- 开票信息和对公账户

### 2. 要样品试吃
不要只看报价。让2—3家同时送样品：
- 苹果：看硬度、糖度、碰伤率
- 香蕉：看催熟均匀度、到货后能放几天
- 橙子：看水分、酸甜比、坏果率

### 3. 小批量试供
先试供2—4周，重点观察：
- 是否准时
- 质量是否稳定
- 坏果是否按约定退换
- 临时加单响应速度
- 对账是否清楚

### 4. 比价方式
不要只比单价，要比“综合到货成本”：
- 单价
- 损耗率
- 退换货比例
- 配送费
- 是否含税
- 账期

比如A报价低但损耗高、经常缺斤少两，实际成本可能比B更高。

## 四、合同里必须写清的条款

1. **质量标准**
   - 按品类写清规格、成熟度、坏果率上限。

2. **验收和退换**
   - 到货抽检不合格，整批退换还是按比例扣款。
   - 退换响应时间，比如2小时内答复，当天补送。

3. **价格机制**
   - 是固定价还是随行就市。
   - 如果浮动，约定参考哪个市场价，比如当地批发市场均价，多久调一次。

4. **食品安全责任**
   - 因水果质量问题导致食安事故，供应商承担全部责任。
   - 保留每批次检测报告和进货凭证。

5. **结算方式**
   - 月结还是周结。
   - 必须对公转账，提供发票。
   - 对账周期和异议处理时间。

6. **违约和退出**
   - 连续几次质量不达标，学校可无条件终止。
   - 临时断供的违约责任。

## 五、建议的供应商结构

不要只选一家，建议：

- **主供应商1家**：负责日常大部分水果，价格和配送稳定。
- **备选供应商1—2家**：应急补货、比价、防止主供应商拿捏。
- **产地直供1家**：针对苹果、橙子等耐储品类，降低成本。

香蕉因为涉及催熟和运输，最好选有稳定催熟能力的本地配送商。

## 六、简单判断标准

一个供应商是否靠谱，看这几点：
- 能不能提供检测报告和正规票据
- 能不能接受坏果率写进合同
- 能不能稳定准时送到
- 出问题后能不能当天补换
- 价格是不是透明，不靠缺斤少两赚钱

如果这几条都满足，基本可以作为长期供应商。学校食堂最重要的是**安全、稳定、可追责**，不是单纯追求最低价。
