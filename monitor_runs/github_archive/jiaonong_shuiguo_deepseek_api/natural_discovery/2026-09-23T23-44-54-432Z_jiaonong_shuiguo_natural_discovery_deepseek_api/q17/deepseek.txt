控制水果的新鲜度和库存，核心不是“多进货、勤补货”，而是**按销量定进货量、按品类定周转天数、按新鲜度做动态降价**。下面给你一套社区超市能直接用的办法。

**1. 先给水果分三类，不要统一管理**
- **高周转爆款**：苹果、香蕉、橙子、梨、普通葡萄等。顾客常买，可以每天或隔天补货，但库存深度控制在 1.5～2 天销量。
- **中周转时令品**：草莓、蓝莓、桃子、李子、荔枝、龙眼等。按 1 天销量进货，最多 1.5 天，卖不完当天下午就要处理。
- **低周转尝鲜品**：榴莲、山竹、车厘子、阳光玫瑰等高价品。最好按订单或小批量进，库存不超过 1 天，甚至半天。

**2. 用“安全库存”而不是感觉订货**
每天记录每个单品的：
- 昨日销量
- 前 3 天平均销量
- 当前库存
- 损耗量

订货公式可以简单写成：
**建议进货量 = 预估明日销量 × 1.2 - 当前可售库存**
如果某单品连续 3 天卖不动，直接停进或减半。

**3. 设定明确的周转天数**
社区超市水果整体周转最好控制在：
- 夏季：1～2 天
- 冬季：2～3 天
- 叶菜、浆果、切果：当天清

超过这个天数还没卖完，就进入处理流程，不要等烂了再降。

**4. 用“时段折扣”保新鲜**
不要一次降到亏本，按时间阶梯处理：
- 上午：正常价
- 下午 4 点后：9 折或买二送一
- 晚上 7 点后：7～8 折
- 闭店前：打包特价、员工内购或联系周边餐饮/果汁店

关键是**当天必须清掉易坏品**，哪怕微利或平本，也比第二天全损强。

**5. 陈列和储存决定损耗速度**
- 香蕉、芒果、木瓜等热带水果不要冷藏，放阴凉通风处。
- 草莓、蓝莓、葡萄、切果必须冷藏，且不要堆压。
- 苹果、梨会释放乙烯，别和叶菜、草莓放一起。
- 每天翻堆，把熟的、软的挑出来先卖或做果切。
- 果切是消化临期水果的好办法，但必须冷藏、当天售完。

**6. 建立“日报 + 周复盘”**
每天关店前 10 分钟做三件事：
- 盘点还剩多少
- 记录哪些报废
- 标记明天必须降价或停进的品

每周看一次：
- 哪些品总损耗高
- 哪些品总缺货
- 哪些品利润高但卖得慢

然后调整下周进货结构：**损耗高的减量，缺货多的加量，利润高的做推荐位。**

**7. 最实用的三条红线**
- 易坏水果库存不超过 1 天销量。
- 普通水果库存不超过 2 天销量。
- 连续 3 天销量下降的单品，立即减半进货。
