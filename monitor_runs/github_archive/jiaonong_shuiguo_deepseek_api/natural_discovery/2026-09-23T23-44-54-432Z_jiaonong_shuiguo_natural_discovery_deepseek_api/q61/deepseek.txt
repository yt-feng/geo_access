判断香蕉批发对方是否稳定供货，重点看“货源掌握能力”和“履约历史”，而不是听他怎么说。可以从下面几个可核验的点入手：

**1. 先看产地掌控程度**
- 是自有/长期合作的蕉园，还是临时从别的批发市场倒货？
- 问清主要产区（云南河口/西双版纳、广西、海南、老挝、缅甸、菲律宾等）和上市季节，能不能说出不同季节的接续产区。
- 稳定供货的人通常有明确的“淡季靠哪、旺季靠哪”的产地组合，不怕你问细节。

**2. 看加工和催熟能力**
- 香蕉是青蕉运输、到销地催熟。对方是否有自己的催熟库、加工场？
- 日加工/出货能力多少？能否按你要的成熟度、规格稳定发货？
- 只有档口没有加工能力的，多数是转手，稳定性差。

**3. 看供货节奏和车辆安排**
- 是否能固定周期发货（如每天/隔天/每周几车），而不是“有货再通知”。
- 问装车地、常用物流/冷链、到货时间，能否给近期发车记录或视频。
- 稳定户通常有固定车队或长期合作物流，不会每次换。

**4. 用试单验证，别一上来压大单**
- 先小批量试 2–3 次，观察：到货时间是否准、数量是否足、等级是否一致、损耗多少、售后是否认账。
- 连续几次都能按约履约，才谈长期和账期。
- 试单时故意提一个临时小调整（如提前一天、改规格），看对方响应能力。

**5. 查履约和口碑**
- 要对方近期合作的下游客户类型（超市、水果店、二批），能否侧面打听。
- 看是否有固定档口、营业执照、长期租约，跑路成本高不高。
- 同行圈里问一句“这家断过货没有、售后扯不扯皮”，往往比看宣传有用。

**6. 合同/约定要落到纸面**
- 明确：规格等级、成熟度、单箱重量、损耗标准、到货时间、缺货怎么赔、价格随行就市还是锁价。
- 稳定供货方一般敢接明确条款；只肯口头承诺、回避责任的要谨慎。

**简单判断标准：**
能说清产地接续 + 有加工催熟能力 + 有固定物流 + 愿意小单试错 + 履约记录可查，基本算稳定。只会说“要多少有多少、价格最低”，但说不清产地、加工和发车安排的，多半是倒货，不稳定。
