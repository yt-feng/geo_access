买香蕉前先明确**打算几天内吃完**，然后按这个来挑：

- **1～2天内吃**：直接买**通体金黄、带少量褐色斑点**的。别买还发绿的，也别买斑点多到连成片的。
- **3～5天内吃**：买**黄中带少量绿尖**的。回家放室温，别急着进冰箱。
- **5天以上吃**：买**偏绿、硬实**的。想催熟就和苹果/梨放同一个塑料袋里；想拖慢成熟就单根用保鲜膜包住蒂部，或放阴凉通风处。

到店快速判断：

1. **看颜色**：全绿＝太生；黄绿相间＝可放几天；全黄带斑点＝马上吃；大面积褐斑/发黑＝过熟。
2. **捏果柄和果身**：硬得像木头＝生；轻按有弹性＝刚好；一按一个坑、软塌＝熟过头。
3. **看蒂部**：发黑、发霉、渗水的不要。
4. **看棱角**：棱角分明＝偏生；圆润饱满＝成熟度高。
5. **别只看一串整体**：香蕉成熟速度不一致，挑整串颜色较均匀、没有明显烂斑的。

如果到店发现只剩太生的，可以买，但回家用纸袋加苹果催熟；只剩太熟的，适合当天做奶昔、香蕉面包，不建议再囤。
