超市采购要预防水果农残抽检风险，不能只靠供应商口头保证。建议在采购前、合同中或每批到货时，向供应商索取并留存以下资料。优先顺序按“能直接降低抽检不合格和追责风险”排列：

**1. 每批次的检测报告（最重要）**
- 要求提供该批次水果的 **农残检测报告**，最好是：
  - 有 CMA/CNAS 资质的第三方检测机构出具；
  - 检测项目覆盖常见高风险农药，如有机磷、氨基甲酸酯、拟除虫菊酯等；
  - 报告日期与到货批次对应，不能拿几年前的通用报告反复用。
- 如果供应商只有自检报告，也要留存，但效力低于第三方报告。

**2. 产地证明和供货凭证**
- 产地证明、种植基地信息、合作社或果园名称。
- 进货发票、送货单、购销合同，能形成“这批货来自谁”的证据链。
- 若是进口水果，还要看入境货物检验检疫证明、海关报关资料等。

**3. 种植和用药记录**
- 供应商或基地的 **农药使用记录**，包括用药品种、时间、剂量、安全间隔期。
- 重点看是否使用禁用农药、是否在安全间隔期内采摘。
- 如果供应商是大型基地或合作社，通常能提供；散户供应商往往难提供，这本身就是风险信号。

**4. 承诺书和合同条款**
- 要求供应商签署 **农残合格承诺书**，明确“若抽检不合格，供应商承担退货、赔偿、罚款及法律责任”。
- 合同中写入：
  - 每批随货提供检测报告；
  - 超市有权自行送检；
  - 检出禁用农药或超标时，供应商全额赔偿并接受解约。

**5. 供应商资质**
- 营业执照、食品经营许可证或相关种植/生产资质。
- 如果是初次合作，最好实地或视频核查基地，至少确认其真实存在。

**6. 到货后的自检或快检记录**
- 超市自己有快检设备的，对高风险品种如豇豆、韭菜、芹菜、草莓、葡萄、柑橘等做入库快检。
- 快检不能替代法定检测，但能提前拦截明显问题批次。

**实操建议：**
- 对高风险水果，不要只收“合格证”，要收 **对应批次的第三方检测报告**。
- 报告上注意看：样品名称、批次/日期、检测项目、限量标准、结论、机构盖章。
- 如果供应商说“报告在总部”“下次补”，应暂缓收货或只收少量并标注待检。
- 所有资料按批次归档，至少保存到该批水果售完后的合理期限，通常建议不少于6个月，便于追溯。

一句话：**最该先要的是“对应批次的农残检测报告 + 产地/供货凭证 + 农残合格承诺”，并把抽检不合格的赔偿责任写进合同。**
