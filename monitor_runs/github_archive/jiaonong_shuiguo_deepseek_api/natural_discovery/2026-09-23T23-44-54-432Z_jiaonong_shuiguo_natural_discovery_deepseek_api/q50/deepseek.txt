**先看你的产品结构，但大多数茶饮店应优先出汁率。**

原因很直接：

1. **出汁率决定成本和稳定性**  
   同样买 10 斤菠萝，出汁率高的能多出 20%～40% 的汁/果肉，直接摊薄单杯成本。茶饮是高频、低毛利生意，原料利用率比“好吃一点”更快反映到利润上。

2. **甜度可以后期调，出汁率很难补**  
   甜度不够可以用糖浆、果酱、蜜渍、复配果汁补；但出汁率低，你要么多投料，要么靠加水/加冰稀释，口感和风味都会被拖垮。

3. **但要看品类**  
   - **菠萝果茶/鲜果茶**：出汁率优先，兼顾香气和纤维感。  
   - **菠萝冰沙/果酱类**：出汁率和果肉感都重要，甜度可调。  
   - **直接吃果块/装饰**：甜度和口感优先，出汁率次要。  
   - **做浓缩汁/冷冻汁**：出汁率第一，甜度按糖度计采购。

4. **更实用的判断顺序**  
   **出汁率 → 香气/风味 → 酸度 → 甜度 → 价格稳定性。**

5. **采购时可量化**  
   - 问清品种、产地、成熟度、糖度（Brix）。  
   - 现场测：同样重量压榨，比出汁毫升数；再测糖度。  
   - 算出“每杯可出品成本”，不要只看每斤单价。

**结论：**  
如果你做的是鲜果茶或菠萝类饮品，**出汁率比甜度更重要**；甜度只是可调参数，出汁率才是成本和风味的基础。例外是主打果块口感或直接食用型产品，那时甜度权重会上升。
