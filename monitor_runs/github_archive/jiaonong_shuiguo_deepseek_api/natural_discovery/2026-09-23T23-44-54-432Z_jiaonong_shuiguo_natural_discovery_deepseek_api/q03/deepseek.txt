夫妻店第一次试单，核心目标不是“拿到最低价”，而是用最小成本验证三件事：**货的质量稳定性、供货商是否靠谱、你们自己的损耗和周转能不能扛住。** 所以不要把香蕉、苹果、橙子当成一回事试，它们的风险点完全不同。

**一、试单前先定好原则**

1. **首次只试1家，最多2家。** 同时试3家以上，你根本分不清是货的问题还是人的问题。
2. **每样只拿1-2箱，或按最小起订量拿。** 目的是看货，不是压价。
3. **不要第一次就谈账期。** 先现金或现结，验的是货和履约，不是资金关系。
4. **明确退货规则。** 坏果怎么算、到货几小时内可反馈、谁承担运费，提前问清楚。

**二、按品类分别试，重点不同**

**香蕉：试的是“熟度控制”和“到货后能放几天”**
- 不要拿全青或全黄的，拿**微黄带一点青**的，看它到你店里后几天转熟。
- 记录：到货当天状态、第2天、第3天分别什么样，哪天开始出黑斑、哪天必须打折。
- 香蕉最容易暴露供货商问题：催熟过头、运输压伤、把快熟的塞给你。
- 试单量控制在**1箱**，因为香蕉周转快、损耗也快。

**苹果：试的是“等级是否稳定”和“有没有以次充好”**
- 重点看**大小是否均匀、有没有暗伤、有没有打蜡过重、箱底有没有塞小果次果**。
- 苹果耐放，可以拿**1-2箱**，放一周观察有没有内部发面、发糠。
- 试单时故意问一句：“这箱是哪个等级的？”看他回答是否含糊。含糊的，后面容易混装。

**橙子：试的是“水分、酸甜度和表皮新鲜度”**
- 重点看**皮是否发皱、有没有软塌、切开水分足不足**。
- 橙子容易遇到“看着好、切开干”的情况，所以一定要**当场切2-3个**，不要只看表面。
- 拿**1箱**，观察3-5天，看有没有开始长霉、发软。

**三、试单时具体怎么操作**

- **到货当场验：** 开箱、翻底、切样。不要等搬进店再拆。
- **拍照留证：** 每箱拍整体、拍箱底、拍坏果，方便后续沟通。
- **记录一张简单表：** 品名、到货日期、数量、进价、到货状态、第3天状态、损耗几个、卖完用了几天。
- **问清楚补货节奏：** 比如香蕉几天送一次、能不能少量补、临时加单多久能到。
- **观察送货态度：** 迟到、不按约定、坏果推诿的，第一次就要警惕。

**四、怎么判断这家能不能继续合作**

满足下面几条，可以考虑第二次加大试单：
- 到货质量和样品一致，没有明显混装。
- 坏果比例在你可接受范围内，且愿意按约定处理。
- 送货时间稳定，沟通不费劲。
- 你算下来**毛利扣掉损耗后还有得赚**。

如果出现下面情况，直接换：
- 第一次就混次果、箱底塞烂货。
- 坏果不认、找理由推。
- 说好的时间反复变。
- 价格明显低于市场但货不对版。

**五、给你一个最简试单方案**

第一次找供货商，可以这样下单：
- 香蕉：1箱
- 苹果：1箱
- 橙子：1箱
- 全部现结，约定到货验货、坏果拍照反馈。
- 卖完后再决定第二单，第二单再试他能不能稳定补货。

一句话：**第一次试单，试的不是价格，是“这家的货到你手里还剩多少能卖”。** 把损耗和周转算清楚，比砍下几毛钱重要得多。
