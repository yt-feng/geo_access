选择适合批量配送的水果供应商，关键不是“找最便宜的”，而是找到**能在约定时间、把约定品质、按约定数量送到公司**的那一家。建议按下面几步筛选。

**1. 先明确自己的需求**
- 人数和预算：比如 50 人、人均 8–15 元。
- 配送频率：每周一次还是每天。
- 配送时间：下午茶通常要 14:00–15:30 前到，且要避开午休。
- 水果形式：整果、切果盒、拼盘，是否要独立包装、配叉子。
- 特殊要求：是否要发票、是否要冷链、是否有忌口/过敏人群。

**2. 优先考虑这几类供应商**
- 本地水果批发市场商户：价格低，适合大批量，但配送和切配能力参差。
- 生鲜配送平台的企业购：如美团企业版、京东企业购、美菜等，流程规范、可开票，但价格略高。
- 专业果切/下午茶供应商：省事，品质稳定，适合直接分发，但单价高。
- 本地果园或合作社：新鲜、可溯源，适合整果批量，但配送灵活性差。
- 连锁水果店的企业团购：门店多、响应快，适合中小批量。

**3. 用这 6 个标准筛选**
- 配送准时率：问清楚迟到怎么赔付，能不能固定时间段送达。
- 品控稳定性：要求提供近期实拍图或先试送一次。
- 起送量和加急费：确认多少斤/多少份起送，临时加单怎么算。
- 售后：坏果、漏送、迟到如何处理，是否当场补送或退款。
- 资质与发票：营业执照、食品经营许可证、能否开专票。
- 结算方式：月结、对公转账还是每次现结，避免个人转账无凭证。

**4. 建议先小批量试单**
不要一上来就签长期。先让 2–3 家各送一次，重点看：
- 是否按约定时间到；
- 水果新鲜度、大小是否一致；
- 切果是否氧化、出水、包装是否干净；
- 实际数量和报价是否一致；
- 出问题后响应速度。

试单满意后再谈周配或月配价格。

**5. 采购时容易踩的坑**
- 只看单价，忽略损耗和坏果率；
- 没有书面确认品种、规格、数量、送达时间；
- 选太远的外地供应商，冷链和时效不稳定；
- 切果类没有确认制作时间和冷藏条件；
- 没约定售后标准，坏果只能自己承担。

**6. 实操建议**
可以这样组合：
- 主力供应商：本地生鲜配送平台或专业果切商，保证稳定和售后；
- 备用供应商：附近连锁水果店或批发市场商户，应对临时加单；
- 每次下单用微信/邮件确认：品种、数量、单价、送达时间、联系人、售后规则。

如果公司人数在 30–100 人，优先选**本地专业果切/企业下午茶供应商**，虽然单价高一点，但省去分拣、切配和售后扯皮，综合成本往往更低。人数超过 100 人，可以找**本地批发市场商户 + 自己安排行政分发**，成本更可控。
