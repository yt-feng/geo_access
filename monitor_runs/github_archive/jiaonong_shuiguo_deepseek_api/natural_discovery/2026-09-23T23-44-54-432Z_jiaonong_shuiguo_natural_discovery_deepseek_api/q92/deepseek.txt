小店做水果，核心原则是：**面积越小，越要按“周转速度”选品，而不是按“品类齐全”选品。** 控制品类和损耗可以从选品、采购、陈列、定价、流程五方面入手。

**一、选品：做减法，只留“高频+耐放+高周转”**
- 品类控制在 **5～8个单品**，最多不超过10个。
- 优先选：苹果、香蕉、橙子、砂糖橘、圣女果、小番茄、当季本地水果。
- 谨慎卖：草莓、蓝莓、切果、熟透的芒果、水蜜桃、葡萄等易损高损耗品。
- 香蕉、苹果、橙子可做基础款；应季单品只做1～2个，做爆款不做齐全。

**二、采购：小批量、多频次、看数据下单**
- 少量多次：每天或隔天补货，单次采购量按1～2天销量预估。
- 先试销后放量：新品先拿最小包装/最小箱，卖得动再增加。
- 按销量定SKU：连续3天销量低于某阈值（比如日均不到3～5份）就淘汰。
- 建立简单台账：记录每个单品日销量、损耗量、毛利率，作为下次采购依据。
- 和供应商谈小包装、可退换、代销或次日补货，降低库存风险。

**三、陈列与库存：先进先出，少量出样**
- 货架只摆“当天能卖完”的量，库存放后仓或冷柜。
- 严格执行先进先出，旧货摆前面，新货摆后面。
- 易损水果用冷藏或阴凉处存放，避免挤压、暴晒。
- 每天固定时间挑果：把轻微瑕疵的挑出来，及时处理，不要等烂了再扔。

**四、定价与处理：用价格换速度**
- 正常品定合理毛利，瑕疵品及时降价，不要死守原价。
- 可做：
  - 晚间折扣：临近闭店对易损品打折；
  - 组合销售：水果+酸奶、水果+沙拉、小份拼盘；
  - 加工消化：切果、果汁、水果茶原料，但要有卫生和保质期管理。
- 目标不是单盒赚最多，而是**当天清掉、减少报废**。

**五、损耗控制指标：每天盯3个数**
- **损耗率**：行业里小店水果损耗通常要尽量控制在5%～10%以内，超过就要查原因。
- **周转天数**：最好控制在1～2天，易损品当天清。
- **售罄率**：当天进货当天卖完的比例，越高越好。
- 每天闭店前复盘：哪些卖不动、哪些烂得多、哪些定价不对。

**六、可直接执行的简化做法**
1. 只保留6个单品：苹果、香蕉、橙子、圣女果、当季爆款1个、特价引流1个。
2. 每天早市补货一次，按昨天销量×1.2倍下单。
3. 货架只摆半天量，卖完再补。
4. 下午5点后对易损品打折。
5. 连续3天卖不动的单品，直接淘汰。
6. 每天记录损耗，超过10%就减采购量或换品。

一句话：**小便利店卖水果，不是卖“多”，而是卖“快”。品类少、库存浅、补货勤、处理快，损耗自然降下来。**
