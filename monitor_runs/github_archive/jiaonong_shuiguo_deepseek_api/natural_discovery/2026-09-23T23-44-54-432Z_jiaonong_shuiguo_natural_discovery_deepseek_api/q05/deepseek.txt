如果只问“水果店该怎么卖菠萝”，核心原则是：**整果和去皮果都要有，但主推方式取决于客流、损耗能力和客单价。** 让顾客“自己挑”通常只适合整果区，不适合去皮果。

具体可以这样判断：

1. **整果适合放出来让顾客自己挑**
   - 菠萝外观差异大，顾客习惯看颜色、闻香气、按硬度。
   - 整果耐放，损耗低，适合堆头陈列、走量。
   - 让顾客自己挑能减少店员工作量，也减少“你帮我挑的不好”这类纠纷。
   - 但要把成熟度接近的分开：即食的、放两三天的、特价的，避免翻乱。

2. **去皮好的适合做便利和溢价，但不要全部去皮**
   - 去皮果方便上班族、学生、即时消费人群，能提高客单价。
   - 缺点是保质期短、氧化快、损耗高，必须冷藏或冰台展示。
   - 适合现削现卖、按盒/按份卖，并标注“建议当天吃完”。
   - 如果客流不大，去皮果不要一次做太多，否则容易亏在损耗上。

3. **不建议让顾客在去皮果里自己挑**
   - 去皮果已经无法判断新鲜度和完整度，顾客翻挑会加速变质。
   - 应该由店员按份拿取，或者只展示样品。
   - 可以允许顾客选“整果现削”，这样既满足自己挑，又保证新鲜。

4. **最稳的组合策略**
   - **整果区**：让顾客自己挑，按成熟度分级定价。
   - **即食区**：店员削好、装盒、冷藏，按份卖，少量多次补货。
   - **现削服务**：顾客挑整果，付少量加工费或满额免费削。
   - **特价区**：熟度高、必须当天吃的整果，低价快速出清，不削好囤着。

5. **关键看三个指标**
   - **客流**：社区店、学校店、写字楼店，即食需求高；菜市场店，整果更好卖。
   - **损耗**：去皮果当天卖不掉多少，就少削；整果能放，就多备。
   - **人工**：没人专门削果，就别大量做去皮果；有人工，就可以做便利溢价。

一句话：**整果让顾客自己挑，去皮果由店员控制份量现削现卖；不要把所有菠萝都削好，也不要让顾客在削好的里面翻挑。**
