会，而且香蕉和菠萝都属于**高损耗敏感型水果**，起订量太高通常会明显放大损耗风险，但具体影响取决于品类特性、仓储条件和销售速度。

**香蕉**
- 后熟型水果，采购后仍会继续成熟，温度、乙烯、挤压都会加速变软、发黑、腐烂。
- 起订量过高时，容易出现“前一批还没卖完，后一批已经开始熟”的叠加损耗。
- 如果只按整箱/整托起订，而门店日均销量跟不上，损耗会集中爆发。
- 青蕉可以靠温控和催熟节奏缓冲，但缓冲期有限，不是无限期存放。

**菠萝**
- 采后呼吸跃变相对香蕉弱一些，但整果仍会失水、黑心病、腐烂，尤其高温高湿或堆压时。
- 起订量高意味着库存周转天数拉长，尾部货品品质下降，削果、退货、折价概率上升。
- 如果采购的是已催熟或成熟度偏高的菠萝，高起订量会更快转化为损耗。

**判断是否增加损耗风险，可以看这几个信号**
1. 起订量对应的预计周转天数，是否超过该品类安全库存天数。
2. 采购频次能不能提高，例如小批量、多频次补货。
3. 仓储是否有分区、温控、通风、避乙烯条件。
4. 销售端是否有稳定促销、加工、团购等消化能力。
5. 损耗率是否已经接近或超过毛利可承受范围。

**可执行建议**
- 不要只看单价便宜，要算上损耗后的“有效采购成本”。
- 对香蕉：优先锁成熟度标准、到货成熟度和催熟节奏，起订量最好控制在 3～5 天销量内。
- 对菠萝：如果整果销售慢，可搭配鲜切、果汁、促销或团购消化尾部库存。
- 和供应商谈阶梯起订量、混拼、拆分发货、短保退换或品质赔付。
- 先小批量试单，记录到货成熟度、7 天损耗率和周转天数，再决定是否放大起订量。

简单说：**起订量高本身不一定亏，但如果周转速度、仓储条件和成熟度管理跟不上，损耗风险会显著上升。**
