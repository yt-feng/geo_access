判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看**果径是否匹配门店客群、陈列方式、定价带和损耗控制**。采购时建议按下面几步做。

## 1. 先定门店销售场景

不同门店适合的规格不同：

| 门店类型 | 更适合的规格方向 | 原因 |
|---|---|---|
| 社区生鲜店 | 中果、中大果 | 家庭日常购买，单价敏感，走量快 |
| 精品水果店 | 大果、特大果 | 礼盒、送礼、客单价高 |
| 商超堆头 | 中大果、整齐度高的果 | 陈列好看，方便挑拣 |
| 便利店/小业态 | 中果、小果 | 单次购买量小，便于即买即吃 |
| 团购/企业采购 | 大果、统一规格 | 送礼属性强，要求外观一致 |

所以采购前先明确：**卖给谁、怎么卖、按斤还是按个、是否做礼盒**。

## 2. 苹果怎么判断规格

苹果常见按**果径**分级，单位通常是毫米。

常见参考：
- 小果：约 65–70mm
- 中果：约 70–75mm
- 中大果：约 75–80mm
- 大果：约 80–85mm
- 特大果：85mm 以上

判断是否适合门店：
1. **看果径是否均匀**  
   同一批货大小差太多，陈列乱，顾客挑拣严重，损耗高。
2. **看单果重量**  
   苹果不能只看横径，还要看重量。比如 80mm 但偏轻，可能水分不足、口感差。
3. **看果型**  
   高桩、端正、无明显偏斜更适合门店；严重扁圆、畸形适合低价处理。
4. **看表皮和硬度**  
   有磕碰、裂口、黑点、软身的，不适合正常货架销售。
5. **匹配包装**  
   如果做 8 个装礼盒，就要选大小一致、果型端正的；如果散卖，中果更容易走量。

建议：
- 社区店散卖：70–80mm 比较稳
- 精品店/礼盒：80–85mm 或以上
- 低价引流：65–75mm，但要注意口感和损耗

## 3. 橙子怎么判断规格

橙子也常按**果径**分级，但还要看品种和皮厚。

常见参考：
- 小果：约 55–60mm
- 中果：约 60–65mm
- 中大果：约 65–70mm
- 大果：约 70–75mm
- 特大果：75mm 以上

判断是否适合门店：
1. **看果径区间是否集中**  
   同一箱里 60mm 和 80mm 混在一起，不适合精品陈列。
2. **看单果重量和手感**  
   同样大小，越重通常水分越足。轻飘飘的可能干水、皮厚。
3. **看皮厚和可食率**  
   有些大果皮特别厚，看着大，实际果肉少，顾客复购差。
4. **看表皮和新鲜度**  
   油胞细腻、颜色自然、无严重浮皮、无腐烂、无压伤更好卖。
5. **看品种定位**  
   - 冰糖橙、脐橙：中果到大果常见
   - 沃柑、砂糖橘类：更看重口感和甜度，不是单纯大
   - 礼盒橙：要求大小一致、外观漂亮

建议：
- 社区散卖：60–70mm 较稳
- 精品/礼盒：70–75mm 或以上，且均匀
- 引流促销：55–65mm，但要控制酸度和皮厚问题

## 4. 采购现场可直接执行的判断方法

### 第一步：抽样
不要只看最上面一层。从不同位置随机抽 10–20 个。

### 第二步：量果径
用果径圈或卡尺量横径，记录最大、最小、平均。
判断标准：
- 最大和最小差距最好控制在 5–10mm 内
- 超过 10–15mm，说明分级差，门店损耗会高

### 第三步：称重
同一规格单果重量是否稳定。
如果大小差不多但重量差很多，说明品质不匀。

### 第四步：看外观
- 颜色是否一致
- 是否有病斑、虫眼、压伤、裂口
- 果蒂是否新鲜
- 表面是否有药斑、污渍

### 第五步：试吃
至少试 2–3 个。
看甜度、酸度、水分、化渣性、是否有异味。
门店销售最终靠复购，口感不行，规格再漂亮也没用。

### 第六步：算损耗和毛利
问自己：
- 进货价按斤还是按箱？
- 预计挑出多少残次果？
- 损耗率能不能控制在 5%–10% 内？
- 售价能不能覆盖损耗和人工？

如果规格太大导致单价过高，社区店可能卖不动；规格太小导致顾客觉得不划算，也难复购。

## 5. 简单判断口诀

**苹果看果径，也看果型、硬度和重量。**  
**橙子看果径，也看皮厚、手感和水分。**  
**门店销售看均匀度、口感、损耗和价格带。**

## 6. 最终建议

采购时不要只问“这是几号果”，要同时确认：
1. 果径范围是多少毫米？
2. 大小是否均匀？
3. 单果重量多少？
4. 残次率大概多少？
5. 口感如何？
6. 适合散卖还是礼盒？
7. 门店目标客群能不能接受这个价格？

适合门店销售的规格，标准是：**大小整齐、口感稳定、损耗可控、价格带匹配客群**。不是单纯越大越好，也不是越小越便宜越好。
