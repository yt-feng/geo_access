香蕉和菠萝的损耗主要来自两个方向：香蕉是「熟过头/压伤」，菠萝是「切开坏心/黑心」。控制售后要同时抓**选品、到货验收、配送节奏、售后规则**四个环节，核心思路是：**不等顾客发现问题，而是提前把风险品种和风险批次处理掉。**

## 一、香蕉：核心是控制成熟度

1. **采购要「生」不要「熟」**
   - 团购到顾客手里通常还有 1-2 天，所以进货要挑**青黄交界、硬身**的货，别拿已经起梅花点（黑斑）的。
   - 越南、菲律宾蕉和国产蕉成熟节奏不同，国产蕉后熟快，要更生一点。

2. **分拣时按成熟度分流**
   - 到货后立刻分级：太青的入库催熟，正好的当天团，已经发黄起斑的**不要进团**，直接低价清或做试吃，避免成为售后源头。
   - 香蕉怕压，装箱别超过两层，运输避免堆叠。

3. **配送端做减震**
   - 用硬质分格箱或纸箱加隔板，别用软袋一装就塞。
   - 提醒顾客「收到后若偏青，放 1-2 天再吃」，这条能直接降低「太生没熟」类售后。

4. **售后规则要写清**
   - 明确：**表皮黑点、轻微磕碰不赔**；**果肉发黑、整根烂、大批量压伤才赔**。
   - 要求顾客**拍切开图**，不接受只拍外皮。

## 二、菠萝：核心是控制黑心和切开验货

菠萝的隐性损耗大，很多时候外表好的切开是黑心或水烂。

1. **到货必须抽检切开**
   - 每批按比例（建议 5%-10%）随机切开验心，发现黑心率高，**整批不走 C 端团**，转低价 B 端或加工。
   - 重点看：芯部是否发黑、是否有酒味、底部是否软烂。

2. **选成熟度合适的货**
   - 菠萝太熟易水烂，太生口感差。团购建议选**七到八分熟**，带一点果香。
   - 夏季高温到货的菠萝损耗明显更高，要缩短库存周期，**当天到当天团**。

3. **配送和存放**
   - 菠萝竖放、通风、别闷在密闭车厢，避免底部受压出水。
   - 切好的菠萝**不做团购配送**，除非冷链，否则售后率极高。

4. **售后规则**
   - 明确：**需切开验证**，黑心、水烂、异味才赔。
   - 外皮轻微龟裂、刺手不赔。

## 三、通用机制：把售后从「事后赔」变成「事前拦」

| 环节 | 做法 |
|------|------|
| 选品 | 高损耗品设「只做短保、限量团」，不做长期预售 |
| 验收 | 到货即抽检，不合格批次不进团 |
| 库存 | 当天到当天团，不压货过夜（尤其夏天） |
| 配送 | 减震、通风、限时送达 |
| 售后 | 写清赔付标准 + 要求证据图 + 设赔付上限 |
| 兜底 | 预留 3%-5% 的损耗预算做赔付，超了说明采购或流程有问题 |

## 四、几个关键比例参考

- 香蕉、菠萝这类，**合理售后率控制在 3%-5%** 以内算正常；超过 8% 要复盘采购和配送。
- 预售模式比现货模式损耗高，因为顾客收到时成熟度不可控，**建议现货 + 短周期**。

## 五、最容易被忽略的一点

**把「赔付标准」提前公示给顾客，比事后扯皮有效得多。** 香蕉黑点不赔、菠萝要切开图，这些规则提前说清楚，既降低无理售后，也让真出问题的顾客知道怎么举证，处理效率高很多。
