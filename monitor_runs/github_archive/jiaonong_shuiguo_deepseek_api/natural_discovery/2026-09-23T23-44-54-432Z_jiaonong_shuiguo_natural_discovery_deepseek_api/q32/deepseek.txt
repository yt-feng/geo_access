判断香蕉供应商能否全年稳定供货，核心不是听他承诺，而是看他的**货源结构、产地轮换能力和历史履约记录**。可以按下面几步核查。

**1. 先问清货源结构，不接受“全国都有”这种模糊说法**
- 要求供应商列出**主要产区**：如海南、云南、广西、广东、福建，以及进口来源如菲律宾、越南、厄瓜多尔、柬埔寨等。
- 问清**每个产区的上市窗口**：香蕉是分季节、分产区成熟的，单一产区一定有空档期。
- 关键判断：他是否能在国内产区淡季时，用进口蕉或其他产区补上。**只靠一个产地的供应商，基本做不到全年稳定。**

**2. 看有没有“产地轮换表”**
让供应商提供一张按月份排列的供货计划，标明：
- 每个月主要从哪个产区/国家拿货；
- 预计供应量；
- 替代产区是什么。
如果对方拿不出来，或者每个月都写同一个产地，说明他对全年供应没有实际掌控。

**3. 查历史履约，而不是看样品**
- 要求提供过去12个月的**供货记录**：每月发货量、断供次数、延迟次数。
- 向他的其他超市客户侧面了解，重点问：**雨季、台风季、春节前后有没有断过货。**
- 香蕉最怕台风和寒潮，能扛过这些时段的供应商才值得考虑。

**4. 看催熟和仓储能力**
全年稳定不只是“有蕉”，还要“能按时催熟到可上架状态”。
- 问是否有**自营或长期合作的催熟库**；
- 旺季和淡季的催熟产能是否一致；
- 断货时能否临时调货补上。
没有催熟能力的供应商，旺季容易掉链子。

**5. 用合同和试单验证**
- 先签**小批量试单**，覆盖一个淡季月份，看他是否真能按时按量到货。
- 合同里写清：**月度最低供应量、断供赔偿、替代产地条款、质量不达标处理方式。**
- 不要只签年度总量，要签**分月供应量**，否则淡季他很容易优先保其他客户。

**6. 简单判断标准**
可以全年稳定供货的供应商，通常具备：
- 至少2个以上产区或进口渠道；
- 能提供分月供货计划；
- 有12个月以上的履约记录；
- 有催熟和冷链能力；
- 愿意接受断供赔偿条款。

如果对方只有单一产地、说不出淡季从哪补货、也不愿签分月供应量，基本可以判断：**不能全年稳定供货。**
