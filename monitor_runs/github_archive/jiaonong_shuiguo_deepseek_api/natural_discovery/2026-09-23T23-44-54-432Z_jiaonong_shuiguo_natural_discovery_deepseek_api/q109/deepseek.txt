优先谈 **售后**，其次 **账期**，最后 **配送**。  
原因很直接：长期合作里，真正决定你会不会“越做越亏”的，通常不是配送快半天，而是坏果、少货、规格不符、临期尾货这些售后责任能不能算清楚。

**1）售后最该优先谈**
水果是非标品，损耗和品质波动是常态。如果售后规则模糊，后面会出现：
- 坏果谁承担、怎么认定、按箱还是按比例赔
- 少货、错发、规格不符怎么补
- 临期、尾货、次果是否混发
- 赔付是补货、扣款还是返现
- 多长时间内可提异议，过期是否不受理

建议谈成：**到货48小时内可提异议；坏果率超过约定比例按实赔付；补货优先；月结时可直接抵扣。**  
这条谈不下来，账期和配送再好都可能被售后损耗吃掉。

**2）账期第二重要**
账期直接关系到你的现金流，但要在售后规则清楚后再谈。否则可能出现“账期给了，但售后不赔，只能自己吞”。  
建议谈：**先短账期试用，稳定后再延长；逾期付款是否有费用；对账周期和付款日固定。**  
比如从现结/周结，逐步谈到15天、30天。不要一上来只要长账期，供应商可能把价格或品质找补回去。

**3）配送最后谈**
配送重要，但通常最容易替代和优化。优先确认：
- 固定配送日、截单时间
- 迟到、漏送怎么处理
- 临时加单是否接、费用谁承担
- 冷链和到货温度要求

如果配送影响你门店营业，那可以提前，但一般仍排在售后之后。

**一句话顺序：先保品质和赔付，再保现金流，最后优化履约效率。**  
谈判时最好打包谈：**售后规则清晰 + 账期逐步延长 + 配送稳定**，而不是只压其中一项。
