商超做会员日水果活动，供应商要配合的重点不是“供货”，而是把**货量、品质、价格、陈列、补货节奏**提前锁死。建议按下面清单准备：

1. **提前确认活动方案**
   - 活动时间、门店范围、会员价/折扣力度、限量规则、是否叠加券。
   - 主推单品、引流单品、利润单品、凑单单品分别是什么。
   - 日销量目标、分门店预估销量、线上到家是否同步。

2. **锁货与备货**
   - 按预估销量的 **1.2—1.5 倍**准备安全库存，引流爆品可到 **1.5—2 倍**。
   - 明确分仓/门店配送计划，避免活动当天集中到货导致压车、断货。
   - 对易损耗水果设置备用货源，防止天气、产地、物流波动。
   - 活动前 1—2 天完成首批到货，活动日按预估分时段补货。

3. **品质标准前置确认**
   - 和采购确认糖度、规格、成熟度、着色、单果重、包装方式。
   - 会员日最怕“低价但品质差”，要提前做样品确认和到货验收标准。
   - 对香蕉、芒果、牛油果等后熟水果，控制到店成熟度，避免当天过熟或太生。
   - 明确残次品、压伤、腐烂的退换货规则和责任归属。

4. **价格与费用确认**
   - 供货价、促销扣点、损耗补贴、陈列费、DM/线上推广费提前书面确认。
   - 确认是否含税、含运费、含卸货，避免活动后对账扯皮。
   - 若做“会员专享价”，要确认供应商是否承担差价及承担比例。

5. **包装与陈列支持**
   - 提前提供统一规格的箱规、周转筐、托盘、保鲜袋、价签物料。
   - 爆品最好做预包装或家庭装，减少门店现场称重压力。
   - 配合门店做堆头、端架、冷链柜陈列，提供陈列图或建议。
   - 需要试吃、叫卖、直播的，提前准备试吃装、道具和人员。

6. **物流与补货机制**
   - 确认活动日配送频次，最好做到“一日多配”或门店间调拨。
   - 设置补货触发线，比如库存低于当日预估销量 30% 就补货。
   - 明确紧急补货联系人、响应时间、车辆安排。
   - 对线上订单爆量，单独准备拣货友好包装，避免缺货和差评。

7. **人员配合**
   - 供应商安排促销员/理货员驻场，重点门店活动首日必须到岗。
   - 提前培训门店员工：品种卖点、保存方式、催熟方法、推荐话术。
   - 活动期间安排专人巡店，处理品质异议、补货、调价和退换。

8. **风险预案**
   - 天气异常、产地涨价、物流延误、到货品质不达标时的替代单品。
   - 爆品断货后的替代陈列和话术，避免顾客空手离开。
   - 损耗超标时，提前约定补贴或退换机制。
   - 活动结束后及时复盘：销量、毛利、损耗、缺货率、客诉。

简单说，供应商要提前配合的就是：**方案确认、锁量锁价、品质封样、分仓到货、陈列物料、驻场补货、退换规则、风险预案**。其中最关键的是：**爆品不断货、低价不低质、补货跟得上、费用说清楚**。
