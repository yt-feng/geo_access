企业采购水果礼盒时，供应商**通常需要同时支持开发票和定制包装**，但具体要求取决于企业采购用途、财务制度和送礼场景。

**1. 开发票：基本是刚需**

企业采购一般都要走报销、入账、抵扣或成本列支流程，所以供应商能否开票很关键。需要提前确认：

- 能否开**增值税专用发票**或**普通发票**；
- 发票类目是否匹配，常见是“水果”“食品”“农副产品”“礼盒”等；
- 是否支持对公转账、合同、采购清单；
- 开票时间是否及时，能否先票后款或款到开票。

如果供应商不能开正规发票，很多企业财务无法入账，通常不建议选。

**2. 定制包装：看采购用途**

如果是员工福利、客户礼品、节日慰问，定制包装往往很有必要，能体现企业标识和仪式感。常见定制包括：

- 外盒/手提袋印企业 logo、祝福语；
- 加贺卡、封签、丝带；
- 按预算分档配置水果；
- 按部门或人数分装。

但定制通常有门槛，比如：

- 起订量要求；
- 额外打样费、版费；
- 交期更长；
- 退换货限制更严格。

如果只是内部简单发放，也可以接受供应商标准包装，未必必须定制。

**3. 实操建议**

采购前建议直接向供应商确认这几点：

1. 是否支持开具企业所需发票类型；
2. 定制包装的起订量、费用、周期；
3. 水果品种、净重、损耗和售后标准；
4. 是否支持多地址配送；
5. 能否提供合同、报价单和验收单。

**结论：**
开发票一般必须支持；定制包装不一定是所有企业的硬性要求，但如果是员工福利或客户礼赠，通常建议选择能支持定制包装的供应商。最稳妥的是找**既能开票、又能定制、还能稳定配送和售后**的供应商。
