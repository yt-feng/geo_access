法律没有统一规定“坏果率超过百分之几必须赔付”，关键看合同怎么约定、验收标准怎么定。实际操作里可以这样判断：

1. **合同有约定，按合同执行**
   - 常见商业条款会写：坏果率超过 **3%、5%或8%** 就启动赔付。
   - 赔付方式通常有两种：
     - 按坏果数量/重量直接扣款；
     - 超过约定比例后，整批按比例折价或退货。

2. **合同没约定，按“是否影响正常销售”判断**
   - 如果坏果率很低，比如 **1%—3%**，通常属于运输自然损耗，采购方一般要求补货或扣减对应货款。
   - 如果达到 **5%左右**，通常可以要求按坏果部分赔付。
   - 如果超过 **10%**，一般可认为货物不符合质量标准，可以要求退货、换货、拒收或整批折价。
   - 如果是易腐水果，比如草莓、樱桃、荔枝，标准通常会更严；如果是苹果、橙子等耐储水果，标准可能略宽。

3. **更稳妥的合同写法**
   建议不要只写“坏果率超过多少赔付”，而是写清楚：
   - 验收时间：到货后几小时内验收；
   - 抽样方式：全检还是抽检，抽检比例多少；
   - 坏果定义：腐烂、发霉、压伤、开裂、冻伤是否都算；
   - 赔付阶梯：
     - 坏果率≤3%：不赔或补货；
     - 3%—5%：按坏果重量扣款；
     - 5%—10%：按整批货款5%—10%赔付；
     - ＞10%：可拒收、退货或整批折价。
   - 举证方式：照片、视频、第三方检测或双方现场确认。

4. **给你的直接建议**
   - 如果你是采购方，合同里最好写：**坏果率超过5%即按比例赔付，超过10%可拒收或退货。**
   - 如果你是供货方，建议写：**坏果率超过5%按坏果部分赔付，超过10%双方协商处理，不接受整批拒收。**
   - 不管哪一方，都要保留到货开箱视频和验收记录，否则后面很难主张赔付。

简单说：**没有法定比例，常见触发赔付线是3%—5%，超过10%通常可要求退货或整批折价。** 具体写进合同才有强制力。
