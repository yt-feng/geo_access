水果锁价没有统一标准，主要看品类、季节、供应商类型和你的采购量。一般可以这样判断：

**1. 常规鲜果：7～30天**
- 苹果、梨、柑橘、香蕉这类全年或长季水果，供应商较容易接受 **15～30天** 锁价。
- 叶菜、浆果、荔枝、龙眼、水蜜桃等强季节、易腐、价格波动大的，通常只能锁 **3～7天**，甚至只锁单批货。
- 进口水果受汇率、海运、关税影响，一般 **7～15天**，很少锁一个月以上。

**2. 大宗/长期合作：1～3个月**
如果你采购量大、账期好、能接受保底量，供应商可能愿意锁 **1～3个月**。
但通常会附带条件：
- 锁量不锁价，或锁价但可调价；
- 遇到极端天气、产地暴涨、运费大涨可重新议价；
- 你承诺最低采购量；
- 预付定金或缩短账期。

**3. 半年到一年：很少见，通常不是真锁价**
能锁半年以上的，多半是：
- 罐头、冷冻果、果干等加工原料；
- 有期货/套保机制的大企业；
- 合同里写“基准价+浮动条款”，不是完全固定价。

**谈判时建议这样操作：**
- 先问供应商：“这个价能保几天？保价期内我每天/每周提多少？”
- 把锁价写成：**固定单价 + 锁价期限 + 最低采购量 + 异常调价条件**。
- 对波动大的水果，用“分批锁价”：比如每月锁一次，而不是一次锁半年。
- 如果供应商不愿锁价，可以谈“保最高价”或“涨跌超过5%再调”。

**一句话结论：**
普通水果锁 **7～30天** 比较现实；量大长期合作可谈 **1～3个月**；超过3个月基本要接受浮动条款或期货套保，不太可能拿到真正固定价。
