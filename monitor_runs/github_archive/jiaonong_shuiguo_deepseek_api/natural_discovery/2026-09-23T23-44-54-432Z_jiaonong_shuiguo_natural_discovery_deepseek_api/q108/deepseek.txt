核实水果供应商的“全国配送”能力，不能只听口头承诺，要分成**配送网络、冷链能力、时效范围、成本边界、异常处理**几个维度去验证。可以按下面步骤做。

**1. 先要求供应商提供可核验的配送范围清单**
让对方给出：
- 可配送省份/城市清单，最好精确到区县或偏远地区是否加价；
- 哪些地区不送、哪些地区只送市区、哪些地区需要中转；
- 配送方式：自有物流、第三方快递、冷链专线、落地配、航空/陆运；
- 起送量、最小起订量、整车/零担/快递的切换条件。

如果对方只说“全国都能发”，但拿不出区县级别清单，基本要打问号。

**2. 用真实地址做试单测试**
不要只问客服，直接拿采购方实际要覆盖的地址做测试：
- 选几个代表性区域：一线城市、省会、地级市、县级市、乡镇、偏远地区；
- 每个区域下真实订单，看是否接单、多久揽收、多久送达；
- 记录是否额外加收偏远费、中转费、冷链费、上楼费；
- 测试时间最好覆盖旺季和淡季，水果旺季物流压力差别很大。

试单是最直接的办法。能发一单不代表能稳定发全国，但连试单都不愿意配合的，风险很高。

**3. 核查冷链和温控能力**
水果对温度、湿度、时效敏感，重点问：
- 哪些品类走冷链，哪些走常温；
- 冷链是全程冷链，还是“泡沫箱+冰袋”；
- 是否有温控记录、断链如何处理；
- 夏季高温、冬季低温线路是否停发或加价；
- 中转环节是否开箱、是否重新包装。

如果供应商说“全国配送”但冷链只覆盖几个大城市，实际能力就不等于全国。

**4. 核查时效承诺和签收标准**
要求对方明确：
- 不同区域的时效承诺，比如一线城市24小时、省会48小时、偏远地区72小时以上；
- 时效从发货还是揽收开始算；
- 节假日、天气、疫情、交通管制时是否顺延；
- 签收时是否允许开箱验货，坏果怎么判定。

没有时效承诺的“全国配送”，采购方很难做库存和销售计划。

**5. 核查异常处理和赔付机制**
问清楚：
- 破损、腐烂、延迟、丢件怎么赔；
- 赔付比例、免赔额、举证方式；
- 是否保价，保价费谁承担；
- 售后响应时间；
- 是否支持拒收、改址、退回。

水果损耗高，异常处理能力比“能不能发”更重要。

**6. 查第三方信息和历史案例**
可以要求供应商提供：
- 近期的物流面单或系统截图，隐去客户信息；
- 合作客户案例，尤其是同品类、同区域客户；
- 物流商合作证明，如顺丰、京东、中通冷链、鲜配专线等；
- 营业执照、道路运输许可、食品经营许可等资质。

同时可以自己查：
- 企业信用信息公示系统；
- 裁判文书、投诉平台、黑猫等；
- 问同行是否用过、实际覆盖如何。

**7. 做小批量多区域试运行**
正式合作前，建议：
- 选3到5个目标区域；
- 每个区域下2到3单；
- 连续测试1到2周；
- 记录准时率、破损率、温度异常率、客服响应时间；
- 再决定是否扩大合作。

**8. 合同里写清楚，不要只靠口头**
合同或附件中应明确：
- 配送区域清单；
- 时效标准；
- 冷链要求；
- 费用结构；
- 异常赔付；
- 数据对账方式；
- 违约处理。

**简单判断标准：**
- 能提供区县级别清单 + 愿意试单 + 有冷链记录 + 有异常赔付方案，可信度较高；
- 只说“全国可发”、不愿试单、时效模糊、赔付含糊，实际覆盖能力通常有限。

最有效的核实方式就是：**要清单、拿地址试单、测冷链、看异常处理、写进合同。**
