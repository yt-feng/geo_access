批发档口想拓展餐饮客户，菠萝和香蕉的规格要按餐饮用途来定，不能只按零售思路备货。下面按“餐饮客户实际怎么用”给你一套可执行的备货规格。

## 一、菠萝：餐饮客户主要看品种、成熟度、切法

餐饮用菠萝一般分三类客户：饮品店、甜品/烘焙店、中餐/火锅/烧烤店。规格重点不同。

### 1. 饮品店（茶饮、果汁）
- **品种**：香水菠萝、金钻菠萝优先，香气足、酸甜稳定。
- **规格**：
  - 单个重 **1.2–1.8斤**：适合现切、单杯出品。
  - 单个重 **1.8–2.5斤**：适合榨汁、批量切块。
- **成熟度**：**8–9成熟**，到店后1–2天用完，太生酸、太熟易发酵。
- **形态**：
  - 带皮整果：适合有后厨的店。
  - 去皮去眼真空袋：适合饮品店，省人工。
  - 冷冻菠萝块/果丁：适合连锁店做标准化。
- **包装**：整果按 **10–12个/件** 或 **20斤/件**；去皮真空按 **5斤/袋、10斤/箱**。

### 2. 甜品/烘焙店
- **品种**：金钻、台农17号，甜度高、纤维细。
- **规格**：单果 **1.5–2.5斤**，要求果眼浅、无黑心。
- **成熟度**：**9成熟**，到店即用或冷藏1天。
- **形态**：整果或去皮切丁真空装，切丁规格常见 **1cm×1cm、1.5cm×1.5cm**。
- **包装**：整果 **10–15个/件**；果丁 **5斤/袋**。

### 3. 中餐/火锅/烧烤
- **品种**：普通菠萝即可，成本优先。
- **规格**：单果 **2–3斤**，出肉率高。
- **成熟度**：**7–8成熟**，耐放，可切片、切块、做菠萝饭。
- **形态**：整果为主，也可供去皮大块。
- **包装**：**20–30斤/件**，按筐或箱。

**菠萝备货建议**：
- 初期先备：金钻/香水整果 **1.5–2斤** 和 **2–2.5斤** 两个规格。
- 再配一款去皮真空果丁，专门打饮品店和甜品店。
- 不要只备一个规格，餐饮客户最怕“大小不一、成熟度不稳”。

## 二、香蕉：餐饮客户主要看成熟度、大小、是否催熟

餐饮用香蕉分：饮品店、甜品店、西餐/早餐店、火锅/烧烤店。香蕉比菠萝更敏感的是**成熟度和到货状态**。

### 1. 饮品店（香蕉奶昔、果昔）
- **品种**：香芽蕉、巴西蕉，香气浓、甜度高。
- **规格**：
  - 单根 **120–150克**：适合单杯。
  - 单根 **150–200克**：适合批量打浆。
- **成熟度**：**7–8成熟**，到店后2–3天用完；太生涩、太熟发黑。
- **形态**：整串或单根，也可冷冻香蕉块。
- **包装**：**20–25斤/箱**，按串或单根分装。

### 2. 甜品/烘焙店
- **品种**：香芽蕉，要求无斑、无压伤。
- **规格**：单根 **150–180克**，长度均匀。
- **成熟度**：**8成熟**，到店即用或冷藏1–2天。
- **形态**：整根、切片、泥状冷冻。
- **包装**：**15–20斤/箱**，精品可 **10斤/箱**。

### 3. 西餐/早餐/火锅/烧烤
- **品种**：普通香蕉即可，成本优先。
- **规格**：单根 **120–180克**，耐放。
- **成熟度**：**6–7成熟**，可自然催熟，减少损耗。
- **形态**：整串为主。
- **包装**：**25–30斤/箱**。

**香蕉备货建议**：
- 初期备两个成熟度：**6–7成熟**（耐放）和 **7–8成熟**（即用）。
- 规格按单根 **120–150克** 和 **150–180克** 分。
- 餐饮客户最在意“到店后还能放几天”，所以不要全发熟蕉。

## 三、给批发档口的实操组合

### 菠萝
- 金钻/香水整果：**1.5–2斤/个**，**10–12个/件**
- 金钻/香水整果：**2–2.5斤/个**，**8–10个/件**
- 去皮真空果丁：**1cm–1.5cm**，**5斤/袋**
- 普通菠萝整果：**2–3斤/个**，**20–30斤/件**

### 香蕉
- 香芽蕉：**120–150克/根**，**20斤/箱**，6–7成熟
- 香芽蕉：**150–180克/根**，**20斤/箱**，7–8成熟
- 普通香蕉：**120–180克/根**，**25–30斤/箱**，6–7成熟
- 冷冻香蕉块/泥：**5斤/袋**，给饮品和甜品店

## 四、判断能不能做餐饮客户的标准

餐饮客户下单前，你最好能明确回答：
1. **品种**：金钻、香水、香芽蕉、巴西蕉，别只说“菠萝”“香蕉”。
2. **单果/单根重量区间**：餐饮要稳定，不要“大小混装”。
3. **成熟度**：6–7成、7–8成、8–9成，分别对应不同客户。
4. **包装规格**：每件多少斤、多少个、是否真空、是否冷冻。
5. **损耗承诺**：坏果率、黑心率、压伤率怎么处理。
6. **配送频率**：餐饮客户通常要每周2–3次，不是一次性大批发。

## 五、最稳的起步方案

先不要全品类铺开，按这个组合试：
- 菠萝：**金钻整果1.5–2斤** + **去皮真空果丁5斤/袋**
- 香蕉：**香芽蕉150–180克/根，7–8成熟，20斤/箱**
- 再备少量：**普通菠萝2–3斤/个**、**普通香蕉6–7成熟**

这样能覆盖饮品店、甜品店、中餐/火锅店三类餐饮客户，也方便你根据反馈再调规格。
