判断菠萝供应商能不能稳定按规格送货，核心不是看他样品多好，而是看他**货源组织能力、分级能力和履约记录**。可以按下面几步做尽调：

**1. 先明确你们的“规格”到底是什么**
不要只说“要菠萝”，要拆成可验收的指标：
- 品种：如金钻凤梨、巴厘菠萝、台农等
- 单果重范围：如1.2–1.5kg/个
- 成熟度：几成熟采收，到店后催熟还是即用
- 糖度：可溶性固形物≥多少
- 果眼深浅、是否需去眼、去皮损耗率
- 包装：箱装/筐装、每箱个数、净重
- 到货状态：整果、去皮、切块、冷冻果肉
- 验收标准：次品率上限、磕碰率、黑心/水心比例

规格越细，越能判断供应商是否真的能稳定供。

**2. 看上游货源是否稳定**
重点问：
- 是自有基地、合作基地，还是市场调货？
- 主产区在哪里，是否跨产区调配？
- 菠萝有季节性，淡季怎么供？
- 遇到台风、寒害、集中上市期，怎么保供？
- 是否只靠一个代办/一个批发商？
如果供应商只是“市场倒货型”，价格可能低，但稳定按规格送货能力通常弱。

**3. 看分级和加工能力**
稳定按规格送货，关键在采后分级：
- 是否有固定分选线或固定分选工人？
- 是否按重量、糖度、成熟度分档？
- 能否提供同一规格连续批次，而不是这批大下批小？
- 去皮/切块供应商是否有冷链和卫生资质？
没有分级能力的供应商，往往靠人工挑，批次波动会很大。

**4. 要求试单，不要只看样品**
建议做 3 轮试单：
- 第1轮：小批量，验规格、糖度、损耗、到货时间
- 第2轮：正常批量，连续 2–3 周
- 第3轮：旺季或天气异常时再试一次
每轮记录：
- 准时到货率
- 规格合格率
- 次品率
- 实际净重/损耗
- 缺货或临时换规格次数
连续 3 批都稳定，才谈得上稳定供应。

**5. 查履约记录和违约处理**
让供应商提供：
- 近 3–6 个月给其他茶饮/餐饮客户的供货记录，可脱敏
- 是否有固定配送车辆和冷链
- 临时缺货时多久能补
- 规格不符时怎么赔、怎么退、怎么换
- 是否接受押金、账期、质量保证金
愿意把违约条款写进合同的，通常比只口头承诺的可靠。

**6. 合同里必须写清楚**
- 规格标准：单果重、糖度、成熟度、次品率上限
- 验收方式：到货抽检比例、不合格判定
- 交付：频次、时间窗、最低起送量、临时加单响应
- 价格机制：随行就市还是锁价，涨跌触发条件
- 替代方案：主产区断供时用什么品种/产区替代，需不需要提前确认
- 违约责任：延迟、缺货、规格不符的扣款或赔偿

**7. 一个实用判断法**
你可以直接问供应商三个问题：
1. “如果我连续 4 周，每周要 5 吨同一规格，你怎么保证？”
2. “如果下周台风导致主产区断货，你从哪里补？”
3. “上一批到货如果 10% 不符合规格，你怎么处理？”
回答含糊、只说“没问题”的，风险高；能说清产区、分级、替代方案和赔付的，相对可靠。

**结论：**
判断供应商稳不稳，看四点：**上游是否可控、分级是否到位、试单是否连续稳定、违约是否有约束**。样品好不等于供货稳，能连续多批次按同一规格送到店，才是真稳定。
