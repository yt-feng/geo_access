如果餐饮店每天只需要少量水果，想省心，核心不是找“最便宜”，而是找**稳定、可退换、能按需送、不压库存**的渠道。可以按下面优先级选：

1. **本地水果批发市场里的固定档口**
   - 适合：每天用量不大，但希望新鲜、能挑货。
   - 做法：固定找1—2家档口，谈好每天或隔天送货，约定“坏果包换/补”。
   - 优点：价格通常比零售低，品类灵活，旺季能拿到好货。
   - 注意：要确认是否愿意小量配送，很多档口只做批发自提。

2. **生鲜配送平台/餐饮供应链平台**
   - 适合：最省心，想要线上下单、第二天送。
   - 常见类型：美菜、快驴、地方生鲜配送公司、美团/饿了么相关供应链等。
   - 优点：起送量低、可开发票、售后相对规范、不用自己跑市场。
   - 缺点：价格可能略高，品质稳定性看平台和季节。
   - 建议：先试1—2周，重点看准时率、坏果率、售后速度。

3. **本地果园/种植基地直供**
   - 适合：有固定主推水果，比如西瓜、草莓、橙子、圣女果等。
   - 优点：新鲜、成本可能低、可做“当日采摘”卖点。
   - 缺点：品类单一，季节性强，小量配送不一定愿意接。
   - 做法：可以和周边果园谈“每周固定送几次”，而不是每天送。

4. **社区团购/大型商超供货**
   - 适合：极少量、临时补货。
   - 优点：方便、门槛低。
   - 缺点：长期成本高，品质和规格不稳定，不适合作为主渠道。
   - 建议：只作为应急备用。

5. **同行拼单/联合采购**
   - 适合：周边几家餐饮店用量都不大。
   - 做法：几家店联合向一个批发商或平台下单，凑起送量，分摊配送费。
   - 优点：能拿到更好的价格和配送条件。
   - 缺点：需要有人牵头对账、分货。

**最省心的组合建议：**
- 主渠道：选1家本地生鲜配送平台或批发市场固定档口，签简单供货约定。
- 备用渠道：留1家社区团购/商超/同行拼单，应急补货。
- 采购方式：不要每天现找，固定“每周报价+每天下单+隔天送”或“每天送一次”。
- 关键约定：起送量、送达时间、坏果标准、是否可退换、是否开发票、临时加单怎么处理。

**判断供应商是否省心，重点看4点：**
1. 能不能小量送；
2. 坏果能不能及时补；
3. 价格是否每周稳定报价；
4. 送货时间是否固定、不耽误备餐。

如果用量真的很少，比如每天几斤到十几斤，优先选**生鲜配送平台**或**同行拼单**，通常比自己去批发市场更省心。
