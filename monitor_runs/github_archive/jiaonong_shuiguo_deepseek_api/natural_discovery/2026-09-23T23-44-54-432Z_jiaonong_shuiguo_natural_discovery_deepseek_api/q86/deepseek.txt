生鲜平台做一件代发水果，供应商的仓配能力至少要能支撑“单件起发、按单拣配、保鲜时效、售后可追溯”这几件事。具体可以拆成以下几类来判断。

**1. 仓储能力**
- **多温区或适配水果的存储条件**：不同水果对温度、湿度要求差异大，至少要有常温、冷藏分区，部分浆果、荔枝、车厘子等需要冷藏甚至冷链。
- **分拣打包能力**：支持按订单拣选单件/多件，能处理不同规格包装，比如礼盒、家庭装、单果装。
- **库存准确性**：一件代发最怕超卖和错发，供应商需要有WMS或至少进销存系统，能实时同步库存。
- **效期与批次管理**：水果保质期短，要能按批次先进先出，避免发旧货。

**2. 配送能力**
- **快递或落地配资源**：能对接主流快递，且针对水果有生鲜专线或优先派送能力。
- **发货时效**：通常要求下单后24小时内出库，部分平台要求当日截单前下单当日发。
- **覆盖范围**：能否发全国、偏远地区是否可达、是否支持平台指定区域。
- **包装与防护**：防震、防压、防潮、透气，易损水果需要独立缓冲和温控包材。
- **冷链能力**：如果做高端水果或远距离配送，需要泡沫箱+冰袋、干冰或冷链快递，能承诺到货温度。

**3. 订单与系统对接能力**
- **API/ERP对接**：能接平台订单，自动回传运单号、库存、发货状态。
- **面单与物流轨迹**：支持电子面单，物流信息可回传，方便平台和消费者查询。
- **异常订单处理**：缺货、地址异常、改址、拦截等能及时响应。

**4. 品控与售后能力**
- **到货品质标准**：成熟度、糖度、大小、外观有分级标准，能按平台要求发货。
- **坏果包赔能力**：能承担或配合平台处理坏果、烂果、少件、错发，有明确赔付流程。
- **售后举证**：能提供发货前照片、称重记录、批次信息，方便定责。
- **退换货处理**：生鲜通常不支持无理由退货，但要有坏果补发、退款、补偿的执行能力。

**5. 产能与稳定性**
- **日发货峰值**：至少能支撑平台活动期的单量，比如日常500单、峰值5000单是否接得住。
- **人力与场地弹性**：大促、节假日能否临时增人增仓。
- **爆款单品供应稳定性**：一件代发最怕断货，供应商要有稳定果园或一级采购渠道。

**6. 合规与保险**
- **食品经营许可证/营业执照**：经营生鲜食品的基础资质。
- **产地证明或检测报告**：部分平台和类目会要求农残检测、产地直供证明。
- **物流保险**：是否购买货运险或生鲜险，降低运输损耗纠纷。

**简单判断标准：**
如果供应商只能“有货、能发快递”，但做不到库存实时、发货时效、坏果赔付、系统对接，那就不适合做一件代发。比较理想的供应商是：**有生鲜仓、有WMS、能API对接、24小时发货、有冷链或生鲜快递、能坏果包赔、日峰值产能可验证。**

平台在筛选时，建议先小批量试单，重点看：发货时效、到货坏果率、物流轨迹完整度、售后响应速度。这四项比单纯看报价更能决定一件代发能不能跑通。
