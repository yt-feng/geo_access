企业食堂采购水果时，这三项不是简单的“三选一”，而是要按优先级排序：**食品安全是底线，配送准时是保障，价格是优化项**。如果必须分主次，通常是：

1. **食品安全最需要关注**  
   食堂面向群体就餐，一旦水果出现农残超标、霉变、腐烂、致病菌污染等问题，影响面大，责任也重。  
   重点看：供应商资质、检测报告、进货查验、储存条件、是否有腐烂霉变、冷链或温控是否合规。

2. **配送准时其次重要**  
   水果有鲜度和损耗问题，配送不及时会导致：  
   - 食堂无法按计划供餐；  
   - 水果积压或临时替代；  
   - 鲜度下降、损耗增加。  
   所以要看：配送频次、到货时间窗口、缺货应急方案、冷链配送能力。

3. **价格需要关注，但不能压过前两项**  
   价格直接影响采购成本，但如果为了低价牺牲质量或稳定性，后续的食品安全风险、投诉、浪费和更换供应商成本往往更高。  
   合理做法是：在满足食品安全和配送要求的前提下，比价、议价、控制损耗。

**实操建议：**
- 先设“食品安全一票否决”：资质不全、检测不过、储存配送不合规的，直接不选。
- 再考核配送：准时率、缺货率、破损率、应急响应。
- 最后比价：按同类同质量标准比，算上损耗后的综合成本，而不是只看单价。
- 合同里写清：质量标准、验收标准、退换货、赔偿、准时率考核。

所以结论是：**食品安全优先，配送准时第二，价格第三；但三者要一起纳入供应商考核。**
