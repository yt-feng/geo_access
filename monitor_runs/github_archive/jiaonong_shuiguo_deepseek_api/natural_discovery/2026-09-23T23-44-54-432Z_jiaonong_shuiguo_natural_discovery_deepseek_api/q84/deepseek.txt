如果面向家庭团购水果礼盒，建议按“好吃、耐放、分量不压手、颜色好看”来组合。苹果、橙子、香蕉、菠萝这四种里，最适合家庭的是：

**推荐组合：苹果 + 橙子 + 香蕉，菠萝做可选升级**

### 1. 基础家庭款：苹果 + 橙子 + 香蕉
- **苹果 4-5个**：耐放，老人小孩都接受，寓意也好。
- **橙子 4-5个**：酸甜解腻，颜色亮，和苹果搭配很稳。
- **香蕉 1把，约5-6根**：软糯，适合孩子和老人，但熟得快，不适合放太久。

这个组合适合大多数家庭，价格也容易控制。

### 2. 想显得更实惠/更丰富：苹果 + 橙子 + 香蕉 + 菠萝
- **苹果 4个**
- **橙子 4个**
- **香蕉 5根**
- **菠萝 1个**

优点：看起来大、丰富、有节日感。  
缺点：菠萝处理麻烦，带皮占体积，家庭如果不会削菠萝会觉得不方便。  
建议：团购时最好说明“菠萝可代削”或“送削菠萝工具”，否则体验会打折。

### 3. 如果家庭人口少，建议去掉菠萝
小家庭、两口或三口之家，菠萝一个往往一次吃不完，还容易扎嘴。  
更实用的是：

**苹果 3个 + 橙子 3个 + 香蕉 4根**

总价低，损耗小，吃完不压力大。

### 4. 组合时注意这几点
- **香蕉不要和苹果、橙子长期混放**：苹果、橙子释放乙烯，会催熟香蕉。最好香蕉单独装袋，或者礼盒里做隔层。
- **菠萝不要和香蕉紧挨着**：菠萝也容易让周围水果加速成熟或受潮。
- **橙子选皮厚一点的**：更耐运输，团购路上不容易坏。
- **苹果选脆甜型**：比如富士、嘎啦，家庭接受度高。
- **礼盒重量建议控制在 2.5-4公斤**：太轻显得不划算，太重家庭吃不完。

### 5. 最适合家庭团购的方案
如果只选一个方案，我建议：

**苹果 4个 + 橙子 4个 + 香蕉 5根，菠萝作为加价换购项。**

这样：
- 成本可控；
- 家庭实用；
- 颜色好看；
- 不会因为菠萝处理麻烦影响口碑；
- 想吃菠萝的家庭可以额外加，不想吃的不用被迫接受。
