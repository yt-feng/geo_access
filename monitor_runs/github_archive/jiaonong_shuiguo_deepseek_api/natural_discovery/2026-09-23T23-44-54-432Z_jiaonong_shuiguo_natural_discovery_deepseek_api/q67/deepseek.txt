批发商在谈代理时，区域保护和串货是核心利益点，建议把这些事项在合同里写清楚，而不是只停留在口头承诺。可以从以下几个方向去问：

**一、区域保护**

1. **独家还是非独家**  
   “我这个区域是独家代理，还是多家并存？如果多家并存，怎么划分渠道？”

2. **区域范围如何界定**  
   “保护范围是省、市、区县，还是具体到某些渠道（商超、水果店、电商）？边界按行政区域还是按门店清单？”

3. **线上归属**  
   “我区域内产生的电商订单、社区团购订单算谁的？品牌方自营电商会不会直接卖到我区域？”

4. **保护期限与考核**  
   “区域保护有效期多久？续约条件是什么？有没有最低进货量、销售额考核？完不成会不会取消保护？”

5. **新开渠道的约束**  
   “品牌方在我区域内新开直营店、加盟店或授权其他经销商，是否需要经过我同意？有没有补偿机制？”

**二、串货问题**

1. **串货定义**  
   “什么算串货？跨区域销售、低价倾销、电商乱价，是否都算？认定标准是什么？”

2. **货源追溯**  
   “产品有没有区域码、批次码、防窜货标签？能不能查到货是从哪个经销商流出的？”

3. **处罚机制**  
   “发现串货怎么处理？扣保证金、取消返利、断货、取消代理资格，具体标准是什么？”

4. **举报与举证**  
   “我举报串货需要提供什么证据？品牌方多长时间内处理？处理结果是否书面反馈？”

5. **受害者补偿**  
   “我被串货冲击后，损失怎么补偿？是调价、补货，还是给费用支持？”

6. **自身约束**  
   “我自己如果被迫跨区销售，比如客户在邻区但来我这儿提货，算不算串货？怎么报备？”

**三、合同必须落地的条款**

- 区域范围、渠道范围、线上归属；
- 独家/非独家及排他程度；
- 最低采购量、考核周期、未达标后果；
- 串货认定标准、处罚标准、举报流程；
- 品牌方直营/电商是否受区域限制；
- 保证金、返利、市场支持与串货处罚的挂钩方式；
- 争议解决方式和管辖地。

**四、谈判建议**

- 不要只问“有没有区域保护”，要问“保护到什么程度、怎么执行、违约怎么办”。
- 要求品牌方提供现有经销商地图或授权清单，避免区域重叠。
- 把串货处罚写成可量化标准，比如“第一次扣保证金X%，第二次取消返利，第三次终止合同”。
- 如果品牌方回避书面承诺，说明其渠道管控可能较弱，要谨慎。

核心一句话：区域保护问“边界和排他”，串货问“认定、追溯、处罚、补偿”。这两块写进合同，比任何口头承诺都重要。
