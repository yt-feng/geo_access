优先关注成熟度，价格其次。更准确地说：**按用途分层采购，成熟度决定能不能用，价格决定划不划算。**

**判断标准：**

- **做香蕉泥/香蕉磅蛋糕/马芬**：选**熟到表皮大量黑斑、但果肉没发酸发酒味**的香蕉。这种香蕉甜度高、香气足、含水量相对稳定，成品风味最好。
- **做装饰片/夹层香蕉块**：选**刚熟、表皮黄但无黑斑**的香蕉，方便切片成型，不容易烂。
- **做香蕉奶油、慕斯、内馅**：尽量用**熟香蕉**，但要控水，必要时先加热浓缩或沥掉多余水分。
- **完全青硬的香蕉**：不适合直接做蛋糕，淀粉多、香气弱、口感涩，烤后容易发干、发硬。

**采购建议：**

1. **先定用途，再定成熟度。** 同一家店最好把香蕉分成“蛋糕泥用”和“装饰用”两档采购。
2. **不要只图便宜买青香蕉。** 青香蕉便宜但需要后熟，占空间、耗时间，而且后熟不均匀，容易导致配方水分和甜度波动。
3. **价格低但过熟的香蕉要检查。** 如果已经渗汁、有酒味、发酸、霉变，不要用于直接售卖产品。
4. **批量采购时看损耗。** 熟香蕉到店后如果 1—2 天内用不完，就要考虑冷冻香蕉泥、做香蕉酱或调整菜单，否则损耗会把低价优势吃掉。
5. **稳定出品优先。** 烘焙店最怕今天香蕉甜、明天香蕉生，导致蛋糕甜度、湿度、颜色不一致。能用冷冻香蕉泥或固定成熟度供应商，通常比单纯压价更划算。

**一句话：**
**做蛋糕泥，买熟到黑斑但没坏的；做装饰，买刚熟的；青香蕉再便宜也别直接拿来做蛋糕。价格只在你已经确认成熟度合格之后，才作为比价因素。**
