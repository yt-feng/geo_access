判断菠萝哪个规格更容易出货，核心不是“哪个规格最好卖”，而是看**你的下游客户是谁、走什么渠道、什么季节、什么价格带**。批发商要盯的是“动销速度 + 损耗 + 毛利”三者平衡。

下面给你一套可执行的判断方法：

### 1. 先按渠道分，不同渠道吃不同规格

| 渠道 | 常见偏好规格 | 原因 |
|---|---|---|
| 水果店/社区店 | 中大果，单果1.2–1.8斤左右 | 卖相好，按个卖，顾客觉得划算 |
| 商超 | 中果，规格均匀，1.5–2斤 | 标准化，陈列好看，损耗可控 |
| 路边摊/流动摊 | 小果或中果 | 进货价低，按个卖，走量快 |
| 餐饮/果汁店 | 大果或统货 | 出肉率优先，不太看外观 |
| 电商/社区团购 | 中果，1.5–2斤，标准化 | 图片好看，履约稳定，差评少 |
| 加工厂/罐头厂 | 小果、次果、统货 | 只看重量和价格，不看卖相 |

所以你先问自己：**我这批货主要卖给谁？** 如果下游是水果店，中大果通常更快；如果是果汁店，大果统货更快；如果是团购，中果标准件更快。

### 2. 看三个硬指标：动销、损耗、毛利

不要只看“哪个问的人多”，要看：

1. **动销速度**：同样放3天，哪个规格先卖完？
2. **损耗率**：哪个规格烂得快、压伤多、退换多？
3. **单件毛利**：不是单价高就好，而是“卖得快 + 损耗低 + 每箱赚得多”。

建议你连续记录7–10天：

- 每个规格每天出货箱数
- 剩余箱数
- 损耗箱数
- 客户询价次数
- 实际成交价

然后算：

**日动销率 = 当日出货箱数 ÷ 当日总库存箱数**

**有效毛利 = 销售额 - 进货成本 - 损耗成本 - 运费/人工分摊**

动销率高、有效毛利高的规格，就是更容易出货的规格。

### 3. 看季节和产地

- **旺季刚上市**：中果、大果通常更好卖，因为尝鲜客多，水果店要卖相。
- **大量上市期**：价格敏感，小果、统货走量快，尤其是摊贩和果汁店。
- **尾季**：消费者更看重便宜，小果和统货更容易清货。
- **天气热**：大果切开卖或果汁需求上升，但损耗也快；中果相对稳。
- **天气凉**：水果店按个卖，中大果更受欢迎。

### 4. 看价格带，而不是只看规格

同样叫“中果”，不同产地、品种、成熟度，出货速度差很多。你要判断的是：

- 这个规格的**拿货价**，在下游能不能卖出合理价差？
- 下游客户卖这个规格，**好不好定价**？
- 如果下游卖不动，会不会退回来？

比如：
- 大果进货贵，水果店按个卖，顾客嫌大、嫌贵，反而慢。
- 小果便宜，但水果店嫌卖相差，不愿摆。
- 中果往往最安全，因为适用渠道最广。

### 5. 实操判断法：小批量试销

不要一上来押一个规格。可以这样做：

1. 同一批货里，把中果、大果、小果各留一部分。
2. 分别报给3–5个不同类型的下游客户。
3. 记录24–48小时内谁回消息、谁下单、谁嫌贵、谁要退货。
4. 哪个规格“询价后成交率最高 + 退货最少”，就加大哪个。

**成交率 = 下单客户数 ÷ 询价客户数**

这个比“感觉好卖”可靠得多。

### 6. 一个简单结论

如果你没有具体渠道数据，一般经验是：

- **中果最稳**：适用水果店、商超、团购、摊贩，动销通常最快。
- **大果看渠道**：果汁店、餐饮、加工厂走得快；普通水果店不一定快。
- **小果看价格**：价格足够低时，摊贩、果汁店、加工厂走得快；否则容易压货。

所以，批发商判断哪个规格更容易出货，最实用的顺序是：

**先定下游渠道 → 再看动销率和损耗 → 最后算有效毛利 → 小批量试销验证。**
