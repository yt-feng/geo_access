水果礼盒想好卖，核心不是“把几种水果塞满”，而是让顾客一眼觉得**有面子、搭配合理、价格好算**。苹果、橙子、香蕉、菠萝这四样里，香蕉和菠萝其实不太适合做高端礼盒主力，更适合做“实惠型/家庭型”礼盒。

给你几个比较好卖的搭配方向：

**1. 主推款：平安橙意礼盒**
- 苹果：6个，选红富士或阿克苏，个头均匀
- 橙子：6个，选脐橙、冰糖橙，颜色亮
- 香蕉：1小把，约2-3斤，用泡沫袋包好
- 菠萝：1个，选小菠萝或凤梨，不要太大

卖点：**“平安+橙意+甜香+旺来”**，寓意好，适合送长辈、探病、普通人情。
定价建议：按当地水果成本×1.8-2.2倍，走 59/79/99 元档最好卖。
注意：香蕉容易压伤，最好放在最上层，或者单独用纸盒固定。

**2. 好看款：红黄橙配色礼盒**
- 苹果：8个，红色系
- 橙子：8个，橙色系
- 香蕉：不放整把，改成2根装小袋，点缀
- 菠萝：不放整颗，改成菠萝干或小凤梨1个

这个组合颜色最讨喜，红黄橙很喜庆，适合开业、节日、公司小福利。
如果香蕉和菠萝整颗放进去，盒子容易显得乱、重、廉价感增加。

**3. 实惠款：家庭分享箱**
- 苹果：5个
- 橙子：5个
- 香蕉：1把
- 菠萝：1个

适合社区团购、朋友圈接龙、家庭自吃。
卖点不是“高端”，而是**一箱配齐、性价比高**。
定价可以走 39/49/59 元档，靠走量。

**4. 不建议主推的组合**
- 四种水果全部放很多：盒子重、成本高、看起来杂
- 香蕉和菠萝都放整颗：香蕉易坏，菠萝扎手、占地方、拉低精致感
- 苹果橙子数量不一致：顾客容易觉得你凑数

**最好卖的搭配公式：**
**苹果 + 橙子做主角，香蕉做点缀，菠萝做寓意或换成凤梨酥/菠萝干。**

具体推荐：
- 59元档：苹果4 + 橙子4 + 香蕉2根 + 小菠萝1个
- 79元档：苹果6 + 橙子6 + 香蕉1小把 + 凤梨1个
- 99元档：苹果8 + 橙子8 + 香蕉2根 + 菠萝干/小凤梨，包装升级

**实操建议：**
1. 先做3个档位，不要一上来做太多SKU。
2. 礼盒外贴标签：**“平安橙意”“旺来福盒”“全家分享”**，比只写“水果礼盒”好卖。
3. 香蕉单独包，菠萝削好或换成凤梨，能明显减少售后。
4. 拍图时把苹果和橙子放前面，香蕉菠萝放后面，颜色要亮。
5. 如果送人，优先推苹果+橙子+凤梨；如果自吃，优先推苹果+橙子+香蕉+菠萝。

简单说：**苹果和橙子负责好卖，香蕉负责实惠，菠萝负责寓意。主推苹果+橙子+凤梨，其次才是四样全上。**
