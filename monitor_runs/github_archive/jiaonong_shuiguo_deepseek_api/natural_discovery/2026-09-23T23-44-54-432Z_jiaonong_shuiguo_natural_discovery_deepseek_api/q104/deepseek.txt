单位采购水果（尤其是工会福利、食堂、慰问品等）遇到到货品质不一致，核心是**事前把标准写死、事中按比例抽检留证、事后按差异分级处理**。下面给你一套可直接执行的验收和售后流程。

## 一、采购前先把“验收标准”写进合同/订单

这是最容易被忽略、但决定后面能不能维权的一步。没有约定标准，验收时只能扯皮。

建议明确写清：

1. **品种、规格、等级**：如“红富士苹果，单果直径80mm以上，果面着色≥80%，无病斑、无碰伤”。
2. **成熟度/新鲜度**：如“到货为八九成熟，硬度达标，无软化、无发酵味”。
3. **允许的次品率**：约定“单批次不合格果不超过5%”，超出部分怎么赔。
4. **包装与运输**：冷链、防压、到货温度要求。
5. **到货时限**：从采摘/发货到签收的时间上限。
6. **验收方式**：抽检比例、不合格判定标准、异议提出时限（如到货24小时内）。

## 二、到货验收：按流程抽检留证

**1. 到货当场核对**
- 数量：过磅或点数，与订单核对。
- 外观：包装是否破损、有无挤压、有无异味、有无明显腐烂。
- 温度：生鲜类可测中心温度，判断是否断冷链。

**2. 分层抽检，不能只看表面**
- 按批次、按箱分层抽样，不能只翻最上面一层。
- 建议抽检比例：整批的5%–10%，量小时至少抽3箱/3个点位。
- 每箱从上、中、下取果，避免“上好后差”。

**3. 逐项判定并记录**
对抽检果逐项打分：大小、色泽、成熟度、碰伤、腐烂、虫害、口感。用统一表格记录，最好拍照/录像。

**4. 当场形成验收结论**
- 合格：正常签收。
- 部分不合格：按比例估算整批不合格率，双方签字确认。
- 严重不合格：可拒收或部分拒收，当场书面记录。

**关键动作：所有结论双方签字，照片带时间水印，样品可封存。**

## 三、品质不一致怎么分级处理

按“不合格比例”和“影响程度”分档：

| 情况 | 建议处理 |
|---|---|
| 轻微差异（如大小略小、色泽差） | 协商折价，按差异比例扣款 |
| 部分腐烂/碰伤（如5%–15%） | 扣除对应货款，或要求补发同等数量 |
| 大面积腐烂/变质（>15%或整批性） | 拒收、退货，要求换货并承担运费 |
| 涉及食品安全（霉变、异味、农残存疑） | 立即封存、停止发放，必要时送检并追责 |

**注意**：腐烂果会传染，验收时发现腐烂要**立即挑出隔离**，不能混放，否则好果也会加速坏。

## 四、售后维权的具体做法

**1. 第一时间书面提出异议**
- 不要口头说说，用微信/邮件/函件留痕。
- 写明：订单号、到货时间、问题描述、抽检数据、照片、诉求（补发/退款/折价）。

**2. 保留证据链**
- 采购合同或订单截图
- 到货验收单（双方签字）
- 现场照片/视频（带时间）
- 抽检记录表
- 沟通记录
- 必要时封存样品

**3. 明确诉求，给供应商选择**
- 补发合格品（最快，适合急用）
- 折价结算（省事）
- 退货退款（问题严重）
- 赔偿损失（如已发放、影响活动）

**4. 约定处理时限**
要求供应商在24–48小时内答复并给出方案，避免拖延。

**5. 供应商不配合时**
- 依据合同扣款或拒付尾款
- 向平台/上级采购部门投诉
- 涉及食品安全可向市场监管部门反映
- 保留法律追责权利

## 五、给单位的实操建议（可直接落地）

1. **验收至少两人在场**：采购+使用部门/工会代表，避免单人说了算。
2. **做一张验收单模板**：品种、数量、抽检数、不合格数、不合格率、处理意见、双方签字。
3. **到货当天完成验收**：生鲜拖久了责任难界定。
4. **腐烂果单独装袋称重拍照**：这是索赔最有力的证据。
5. **大额采购留5%–10%尾款**：验收合格后再付，掌握主动权。
6. **优先选可溯源供应商**：有基地、有质检、有售后承诺的，比单纯比价更省事。

**一句话总结**：标准写进合同，到货分层抽检，问题当场签字留证，按不合格比例分级索赔，尾款留一手。这样品质不一致时，你既有依据也有主动权。
