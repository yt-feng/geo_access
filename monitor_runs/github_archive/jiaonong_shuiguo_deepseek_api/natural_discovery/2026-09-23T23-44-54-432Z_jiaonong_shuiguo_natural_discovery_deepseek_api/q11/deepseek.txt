**关键判断：**
- **整箱统货卖**：大小不一影响很大。顾客会挑大的，剩小的，损耗高、周转慢。
- **分拣后卖**：影响很小，甚至能多赚钱。大果、中果、小果分开定价，各有买家。

**具体影响：**
1. **挑拣损耗**：大小混装时，顾客翻捡会导致香蕉碰撞、掉把、破皮，损耗增加。
2. **卖相**：同一堆里大小差太多，显得不整齐，顾客容易觉得“这箱质量一般”。
3. **定价困难**：统一定价，大的觉得亏，小的卖不动；分开定价又费人工。
4. **熟度不一致**：如果大小差异还伴随成熟度差异，有的已经熟了，有的还青，更难统一处理。

**可执行建议：**
- 采购时问清楚：是统货还是分级货。做零售建议优先选分级货，哪怕单价高一点。
- 如果已经进了统货，到店后按大小分2-3档：
  - 大果：正常价或略高价，单独陈列。
  - 中果：主力走量，做促销或搭配。
  - 小果：低价快出，或者做果切、奶昔、香蕉干。
- 陈列时不要堆太厚，减少顾客翻捡。
- 如果小果比例长期超过20%-30%，说明这个供应商的统货不适合你，换供应商或改采购标准。

**一句话结论：**
大小不一的香蕉不是不能卖，而是不能“混着统价卖”。分拣定价、快速周转，就能把影响降到最低。
