判断供应商售后是否稳定，核心是“先看制度承诺，再验历史记录，最后用小单测试”。可以按下面几步做。

**1. 先问清楚售后条款，不要只听口头承诺**
直接要求供应商书面确认：
- 质量问题响应时限：比如到货后几小时内反馈、多久给处理方案
- 退换货规则：坏果、烂果、短斤少两、规格不符怎么赔
- 赔付方式：补货、退款、下批抵扣还是现金
- 责任划分：运输损耗、到货验收后损耗分别谁承担
- 对接人和备用联系人，是否24小时可联系

如果对方只说“放心，有问题找我”，但不愿写进合同或订单确认单，售后稳定性通常不可靠。

**2. 要求提供近期售后记录**
让供应商给出最近1到3个月的真实处理案例，重点看：
- 是否有固定售后对接人
- 平均响应时间
- 投诉后是拖延、推责，还是能给出明确方案
- 是否有重复出现的同类问题

可以要求提供聊天记录截图、售后登记表或客户证明，但要注意脱敏。若对方完全拿不出记录，只能算“未知”，不能算“稳定”。

**3. 用历史合作和同行口碑交叉验证**
- 问同行采购：这家出问题后多久回复、赔不赔、是否经常换业务员
- 查是否有频繁更换公司名称、联系人、收款账户
- 看其是否长期做商超渠道，长期做商超的供应商通常更熟悉验收和售后流程

**4. 用小单和异常单做压力测试**
不要一上来就大额采购。可以先下小单，并故意设置几个可验证场景：
- 到货后当天反馈一个轻微质量问题，看多久回复
- 提一个退换货要求，看是否按约定执行
- 在非工作时间发一次紧急问题，看备用联系人是否有效
- 观察补货是否及时、是否主动跟进

真正稳定的售后，不是“从不出问题”，而是出问题后有人接、有流程、有结果。

**5. 合同里加可执行的售后条款**
建议写清：
- 响应时限：如2小时内响应，24小时内给方案
- 赔付标准：如坏果率超过3%按比例赔付
- 违约处理：超时未处理可扣款或终止合作
- 售后联系人及备用联系人
- 每月售后汇总对账

**6. 对菠萝和香蕉要特别关注**
这两种水果售后高发点不同：
- 菠萝：黑心、烂心、成熟度不均、到货后快速腐坏
- 香蕉：催熟不一致、青硬、裂果、运输擦伤、到货后转色过快

采购时要提前约定：验收标准、成熟度、到货温度、运输时长、损耗率上限。否则售后争议会很大。

**简单判断标准：**
只要供应商能做到“书面条款清楚、有固定对接人、历史问题有记录、小单测试响应及时、异常能按约赔付”，就可以认为售后响应相对稳定。反之，口头承诺多、记录拿不出、测试时拖延推责，就不适合作为稳定供应商。
