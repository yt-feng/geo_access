茶饮店遇到水果到货不合格，核心不是“让对方补”，而是**先把不合格那批从营业链条里摘出去，再约定补货责任和时限**。

建议按下面 4 步处理，并在采购合同/送货单/微信确认里写清楚：

**1. 当场验收，先留证据**
- 送货时当场开箱抽检：数量、重量、规格、成熟度、腐烂/压伤/异味。
- 不合格品单独堆放，拍照/拍视频：整体、批次、标签、坏果特写、称重结果。
- 送货单上直接备注：“本批次XX不合格，暂不结算/拒收，待补货。”
- 让送货司机或供应商文字确认，微信也算。

**2. 补货约定要写“时限+方式+责任”**
不要只写“尽快补”，要写成可执行条款，例如：
- “不合格批次拒收后，供应商须在当日 18:00 前或次日 10:00 前补足同规格同数量合格品。”
- “补货到店并验收合格前，该批次货款不结算。”
- “因补货不及时导致门店缺货、下架、退款、客诉的，供应商承担相应损失或按日扣款。”
- “补货仍不合格的，门店有权取消该批次订单并要求退款。”
- “补货的运费、损耗由供应商承担。”

**3. 不影响营业的实操办法**
- **先保营业**：不合格品别等补货，先用备用库存、附近市场/同行调货、调整菜单或临时下架相关产品。
- **分批次补**：急用品类要求“先补一部分保营业，剩余次日补”，避免全等。
- **替换规格**：合同里可约定“同品种可替换为同等或更高等级规格，价格按原价结算”。
- **备用供应商**：平时至少备 1 家应急供应商，不合格时能当天切换。
- **结算挂钩**：把补货合格作为付款前提，供应商才会重视。

**4. 最好提前写进采购合同/订货单**
可加一条：
> 到货验收不合格的，门店有权拒收并要求供应商在约定时限内补足合格品；补货完成并验收合格前，门店有权暂缓支付该批次货款。因补货延迟或补货仍不合格导致门店营业损失的，供应商应承担相应赔偿责任。

**简单说：**
当场拒收留证 → 书面约定补货时限 → 合格前不结算 → 同时启动备用货源保营业。这样既不影响卖货，也能把补货责任压给供应商。
