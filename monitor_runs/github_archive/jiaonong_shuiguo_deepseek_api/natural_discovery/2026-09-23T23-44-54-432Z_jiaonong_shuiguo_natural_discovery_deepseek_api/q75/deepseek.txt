第一次合作，核心目标不是省钱，而是**用最小成本验证对方是否靠谱**。建议按下面这套框架设计试单。

## 一、先明确试单要验证什么

试单不是"随便进一点货"，而是带着验证清单去：

| 验证维度 | 具体看什么 |
|---|---|
| 品质稳定性 | 到货与样品/描述是否一致，损耗率多少 |
| 规格诚信 | 大小、等级、成熟度、净重是否达标 |
| 包装与物流 | 是否抗压、防碰伤，到货完好率 |
| 交期可靠 | 是否准时，临时缺货怎么处理 |
| 结算与票据 | 对账是否清晰，能否开票 |
| 售后态度 | 出问题是否认账、补偿是否痛快 |

## 二、试单规模怎么定

**原则：小到亏得起，大到能看出问题。**

- **金额**：控制在你单次正常采购量的 **10%–20%**，或总金额几百到一两千元（按你的品类和资金定）。
- **品类**：选 **1–2 个你最有把握、最好卖的主打单品**，不要一次铺开多个品种。品种越多，越难判断是货的问题还是市场的问题。
- **数量**：至少覆盖 **1 个完整销售周期**（比如一周能卖完的量），否则看不出周转和损耗。
- **不要**：第一次就订整柜/整批，也不要订你完全不熟的冷门品。

## 三、试单要卡住的关键条款

合作前用文字（微信/合同）确认清楚，避免扯皮：

1. **规格标准**：品种、等级、单果重/直径范围、成熟度、糖度（如适用）、净重还是毛重。
2. **价格与费用**：单价、是否含运费、装卸费、损耗谁承担。
3. **结算方式**：首次建议 **货到验收后付款** 或 **预付小额定金+尾款验货付**，避免全款预付。
4. **交期**：明确发货时间和到货时间，迟到怎么处理。
5. **验收标准与售后**：允许的损耗率（例如≤5%），超标如何补货/退款/折价。
6. **样品确认**：先要样品或视频/照片，**样品即标准**，到货对照样品验。

## 四、执行流程（建议照做）

1. **先要样品**：让对方寄样，确认品质和规格。
2. **小单试订**：按上面规模下单，全程留痕（聊天记录、订单、付款凭证）。
3. **到货验收**：当场开箱抽检，拍照/录像，记录损耗、规格偏差、重量。
4. **快速销售测试**：看市场接受度、实际损耗、真实毛利。
5. **复盘打分**：对照第一部分的验证清单打分，决定是否加量、换供应商或再试一单。

## 五、几个容易踩的坑

- **只看价格**：低价往往对应次果或短斤少两，算上损耗未必便宜。
- **全款预付**：首次合作尽量不做到货前全款。
- **口头约定**：所有规格、售后必须落到文字。
- **一次订太多**：水果损耗和价格波动大，试单要小。
- **忽略隐性成本**：运费、装卸、损耗、退换货成本都要算进真实成本。

## 六、一句话总结

**选1–2个主打品，下正常量10%–20%的小单，先要样品、货到验收付款、文字锁定规格和售后，跑完一个销售周期后打分再决定加量。** 这样即使踩坑，损失可控，也能快速判断这个供应商值不值得长期合作。
