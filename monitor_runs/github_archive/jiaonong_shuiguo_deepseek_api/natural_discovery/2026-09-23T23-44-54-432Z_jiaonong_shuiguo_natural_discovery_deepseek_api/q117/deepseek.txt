建议分三步定“首单试卖量”，核心是**小批量、可回滚、看动销**。

**1. 先定一个保守首单量**
没有历史数据时，可按：
- **单店首单：3～5天预估销量**
- **多店试卖：选2～3家代表性门店，每店少量铺货**
- **总试卖量：控制在正常单品周销量的20%～30%**

如果该品类客单价低、损耗低，可以偏上限；如果是高价水果、易损水果、季节性强，就压到下限。

**2. 按场景给参考量**
- **社区水果店/单店**：先试 **10～30斤** 或 **1～3箱**
- **中小连锁，3～5家店**：总试卖 **50～150斤** 或 **5～15箱**
- **商超/档口**：先试 **1～2个陈列位**，约 **30～50斤/店**
- **高损耗、高单价新品**：先试 **半箱～1箱/店**，卖完再补

**3. 设定判断标准**
试卖3～7天后看：
- **动销率**：是否达到同品类平均销量的70%以上
- **损耗率**：是否超过5%～10%
- **毛利**：扣损后是否还有合理利润
- **复购**：是否有顾客主动问、回头买
- **补货速度**：是否能在2～3天内卖完

**4. 执行建议**
- 先谈**小批量、可退换/可调换、账期或代销**，降低首单风险
- 要求供应商提供**样品、报价、损耗承诺、冷链/到货标准**
- 首单不要一次性铺满所有门店，先选**客流匹配的2～3家店**
- 卖得好再按 **首单的1.5～2倍** 补货，不要直接翻很多倍

一句话：**没数据时，先按3～5天销量试，单店1～3箱，多店选点铺，卖完再补。**
