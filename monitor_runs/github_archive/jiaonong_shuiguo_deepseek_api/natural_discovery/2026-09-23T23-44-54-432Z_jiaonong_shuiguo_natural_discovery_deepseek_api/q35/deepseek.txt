连锁超市要把门店坏果率压下去，合同里不能只写一句“坏果赔付”，而要把**验收标准、责任归属、赔付计算、扣款方式、举证和争议处理**拆开写清楚。建议按下面结构约定：

**1. 先定义什么叫“坏果”**
不要只写“腐烂、变质”，要列明可判定情形：
- 霉变、腐烂、软化、出水、异味；
- 机械伤、压伤、裂口、冻伤、日灼伤；
- 虫蛀、虫卵、活虫；
- 规格不符、成熟度不符；
- 农残或食品安全指标不合格；
- 包装内隐蔽性坏果。

同时约定：**以门店收货验收时点为准，还是以到店后24小时内为准**。生鲜类通常建议约定“到店验收时发现”和“上架前发现”两个节点。

**2. 约定验收方式和抽检规则**
合同里要写：
- 到货后多久内完成验收；
- 抽检比例，比如每批次抽检5%—10%；
- 抽检发现坏果率达到多少，判定整批不合格；
- 不合格批次是拒收、退货、换货，还是折价接收；
- 门店是否有权对整批进行二次分拣。

建议写成分档：
- 坏果率≤2%：正常收货，不予赔付；
- 2%＜坏果率≤5%：按实际坏果数量扣款或折价；
- 5%＜坏果率≤10%：整批折价，供应商承担分拣费；
- 坏果率＞10%：拒收或退货，供应商承担运费和门店损失。

具体比例可按品类调整，叶菜、浆果类可放宽，根茎类可收紧。

**3. 赔付计算方式要可执行**
不要只写“按损失赔偿”，要写公式。常见有三种：

**方式一：按坏果数量赔付**
赔付金额 = 坏果数量 × 采购单价 × 赔付倍数
赔付倍数可约定1—3倍。比如坏果本身货值1倍，另加违约金1倍。

**方式二：按整批折价**
结算价 = 采购价 × 合格率
合格率 = 合格数量 ÷ 总数量
这种方式适合整批质量不稳定但可折价接收的情况。

**方式三：按门店损失赔付**
适用于已经上架后才发现坏果：
赔付金额 = 坏果货值 + 已产生的分拣人工费 + 报废处理费 + 因此产生的客诉赔偿
但这类损失要有单据或系统记录支撑，不能随口报。

**4. 扣款方式要写死**
建议约定：
- 优先从当月货款中直接扣除；
- 货款不足时，供应商在7—15日内补付；
- 逾期补付的，按日加收违约金，比如万分之五；
- 超市有权暂停后续订单，直到赔付完成。

这样比事后追讨更有效。

**5. 责任归属要分清**
要区分：
- 产地采摘、包装、运输、仓储、门店陈列分别由谁负责；
- 到店前坏果由供应商承担；
- 到店后因门店冷藏不当、堆压、超期陈列造成的坏果，由超市承担；
- 无法判断时，按验收记录、温控记录、监控或第三方检测来定责。

**6. 举证和争议处理**
合同里要写：
- 验收单、照片、视频、系统入库记录、温控记录可作为证据；
- 供应商可要求复检，但要在约定时间内提出；
- 争议大时送第三方检测，费用先由申请方垫付，最终由责任方承担；
- 检测结果不合格的，检测费由供应商承担。

**7. 建议加入的惩罚性条款**
为了真正降低坏果率，可以加：
- 月度坏果率超过约定上限，按当月供货金额的1%—5%扣款；
- 连续2—3次超标，超市有权减少订单或终止合作；
- 因坏果导致食品安全事故或客诉的，供应商承担全部赔偿及品牌损失；
- 供应商需提供产地证明、检测报告、冷链记录，缺一项即可拒收。

**8. 合同里最关键的几句话可以这样写**
“乙方交付的商品坏果率超过2%的，甲方有权按实际坏果数量×采购单价×2倍从当月货款中扣除；坏果率超过5%的，甲方有权整批拒收或折价接收，并由乙方承担分拣、运输及报废费用；因乙方商品质量问题导致顾客投诉、行政处罚或食品安全事故的，乙方承担全部赔偿责任。”

**9. 最后提醒**
坏果率条款不能只靠合同，还要配套：
- 门店验收拍照留痕；
- 系统自动统计坏果率；
- 按月对供应商排名；
- 扣款和订单量挂钩。

合同写清楚只是第一步，真正降坏果率，靠的是**验收标准统一、数据可追踪、扣款能执行、供应商有压力**。
