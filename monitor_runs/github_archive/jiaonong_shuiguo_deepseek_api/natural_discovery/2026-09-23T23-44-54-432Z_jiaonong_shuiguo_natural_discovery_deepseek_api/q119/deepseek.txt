做水果生意，选供应商时大家通常盯着价格、账期、坏果包赔，但真正决定长期稳定的是下面这些容易被忽视的细节：

**1. 供应能力的“弹性”而非“峰值”**
- 只问“最多能供多少”没用，要问“我临时加30%的量，几天能到”“旺季断货时你有没有备选产区”。
- 关键看：同一品种是否有跨产区后备（比如苹果有山东、陕西、甘肃多源），单一产地的供应商在灾年会让你直接断供。

**2. 分级标准的稳定性，而非口头承诺**
- 口头说“一级果”没意义，要看他是否按可量化的标准分级：果径范围、糖度、着色度、允许瑕疵率。
- 最容易被忽视的是**批次一致性**：这一批好、下一批差，比一直中等更伤客。要求看历史多批次的质检记录或抽检照片。

**3. 采后处理能力**
- 有没有预冷、分选线、气调库，直接决定损耗和货架期。很多小供应商价格低，但没预冷，运输途中就烂一批，综合成本反而高。
- 问清楚：采摘到装车隔多久、冷链是否全程不断链。

**4. 结算与风险的实际执行，而非条款本身**
- 坏果包赔要看**执行口径**：是按发货量赔、按到货量赔，还是按你实际售出损耗赔？举证责任在谁？多久到账？
- 口头答应赔，实际每次扯皮，是最消耗现金流的隐性成本。

**5. 供应商的下游依赖度**
- 如果你的供应商主要客户是大的商超或批发市场，你在旺季永远排在后面。
- 反过来，只依赖你一家的小供应商，抗风险能力差，一场病或一次资金链断裂就消失。理想是彼此都占对方一定比例但不过度。

**6. 信息透明度**
- 能否实时给你产地天气、行情、减产预警？愿意让你知道“这批为什么贵/便宜”的供应商更可长期合作。
- 只报价格、遮产地的，通常中间层加价多，出问题时也难追溯。

**7. 人的稳定性**
- 对接人频繁更换意味着内部管理乱。今天谈好的价，明天换个人不认，是长期合作的暗雷。

**可执行的判断方法：**
- 首次合作不要只看样品，要**小批量试3个批次**，专门看一致性。
- 建一张供应商记分卡：准时率、批次合格率、赔付执行天数、旺季履约率。
- 每类水果至少保留2个合格供应商，旺季前做一次“压力测试”（临时加单看反应速度）。

一句话：价格决定你赚多少，**一致性和履约弹性决定你能不能一直赚**。
