要避免香蕉到店后很快变黑，核心不是“买到永远不黑的香蕉”，而是控制**成熟度、温度、机械损伤和乙烯暴露**。甜品店采购时可以按下面做：

1. **按使用节奏买成熟度**
   - 当天/次日用：可买**微黄、刚转黄**的香蕉。
   - 2–3天用：买**青黄、硬身**的香蕉。
   - 不要一次全买“已经全黄、带黑点”的，那种到店后很快继续黑。
   - 如果供应商能分规格，优先选**同一批成熟度一致**的，方便分批催熟和使用。

2. **采购时检查有没有压伤、擦伤**
   - 香蕉变黑常从**磕碰处、果柄、果尖**开始。
   - 拒收明显挤压、破皮、发软、渗汁、箱底有烂果的货。
   - 要求供应商用**硬质周转筐或加隔板**，不要用软袋重压。

3. **到店后先散热，不要闷着**
   - 香蕉运输中会发热，到店后如果整箱闷放，很快发黑。
   - 到店后开箱、通风、摊开或分筐，放在**阴凉通风处**。
   - 不要直接放冷库深处或贴地、贴墙闷放。

4. **温度控制：未熟和已熟分开**
   - **青香蕉**：适合约 **13–15℃** 存放，低于约 12℃ 容易冷害，之后会更快变黑。
   - **已黄香蕉**：适合约 **12–14℃**，尽快用；不要放 0–4℃ 普通冷藏，容易冻伤黑变。
   - 如果店里只有冷藏，已熟香蕉可短时间放**冷藏最上层/蔬果格**，但要用纸袋或保鲜膜 loosely 包，且尽快使用。
   - 不要放冷冻，除非要做冷冻香蕉泥。

5. **减少乙烯影响**
   - 香蕉自身会释放乙烯，也会被乙烯催熟。
   - 不要和苹果、梨、番茄、牛油果等一起闷放。
   - 已熟香蕉和青香蕉要分开，否则青的会被催熟，熟得更快。
   - 如果量大，可用**乙烯吸收剂**或通风降低乙烯浓度。

6. **悬挂或分把存放**
   - 整串悬挂能减少受压，比堆叠好。
   - 分把后，果柄切口可用保鲜膜包一下，减少乙烯释放和污染。
   - 但不要包得太严，否则水汽大、易霉。

7. **先进先出，按成熟度排产**
   - 到店立刻贴日期/成熟度标签。
   - 最黄的先做香蕉泥、奶昔、烘焙；青的留后。
   - 每天挑出开始发黑的，及时去皮冷冻或做熟制甜品，别等整箱传染。

8. **和供应商约定验收标准**
   - 写明：无严重压伤、无烂果、成熟度均匀、运输温度不过低。
   - 夏季要求冷链但**不能低于约 12℃**；冬季要求防冻。
   - 到货温度最好在 **13–18℃** 左右，青蕉不要低于 12℃。

**最实用的到店操作：**
开箱 → 通风摊凉 → 按成熟度分筐 → 青蕉 13–15℃、黄蕉 12–14℃ → 远离苹果梨 → 悬挂/少堆叠 → 每天挑熟 → 最黄先做甜品。

如果只能记一句话：**别买太熟、别压伤、别低温冻、别和催熟水果闷一起，到店先通风分筐。**
