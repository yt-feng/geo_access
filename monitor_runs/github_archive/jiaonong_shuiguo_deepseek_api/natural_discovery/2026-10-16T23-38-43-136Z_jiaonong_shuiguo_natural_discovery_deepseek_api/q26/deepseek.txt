社区超市做小包装香蕉，核心是“按根/按小串卖、减少顾客挑拣造成的机械伤、把损耗压到可接受范围”。采购和包装上重点看这几件事：

1. **规格先定死**
   - 建议做 2～3 个规格：单根、3～4 根小串、5～6 根家庭装。
   - 单根适合即食客群，小串适合小家庭，别都做成大串再拆，拆多了伤口多。
   - 采购时直接要求供应商按你定的根数/串重分装，减少门店二次分切。

2. **成熟度要分批次**
   - 小包装周转快，但香蕉后熟也快。采购不要全拿一个成熟度。
   - 建议：青一点（1～2 天后熟）占 60%，微黄（1 天内可卖）占 30%，即食黄（当天卖）占 10%。
   - 社区店客流稳定但单量小，宁可少进勤补，也不要一次堆太多。

3. **包装材料要兼顾透气、防压、可视**
   - 不要用完全密封的塑料袋，容易闷出黑斑和酒味。
   - 可用带透气孔的 PE 袋、网套+托盘、或纸浆托盘+收缩膜打孔。
   - 小串最好有托盘或硬底，避免堆叠压伤。
   - 标签别贴在蕉指中部，贴在手柄或包装膜边缘，减少撕标伤果。

4. **采购时验货重点**
   - 看蕉指是否饱满、棱角不明显，说明成熟度合适。
   - 看有没有水烂、黑腐、裂口、压伤、冻伤。
   - 看果柄切口是否新鲜，发黑发霉的不要。
   - 摸硬度：太硬可放，太软只能当天特价。
   - 问清产地、采收期、运输温度，香蕉一般怕冷，低于 12～13℃容易冷害。

5. **损耗控制**
   - 门店收货后立刻分级：好果做正常小包装，轻微斑点做特价，严重伤果直接报损或做果切/烘焙原料。
   - 小包装不要提前太久做，最好当天包装当天上架，最多提前 1 天。
   - 货架不要堆高，香蕉怕压，叠 2～3 层就够。
   - 每天多次挑拣，把过熟、发黑、破袋的及时下架，避免传染。
   - 可以设“香蕉特价区”，把 2～3 天内必须卖掉的集中处理。

6. **和供应商谈的条款**
   - 要求按规格分级报价，不要统货价。
   - 明确损耗责任：运输压伤、冷害、水烂谁承担。
   - 争取小批量、多频次配送，比如每周 2～3 次，而不是一次大量。
   - 如果供应商能提供已分装小串，优先考虑，但要把包装成本算进毛利。

7. **简单算账思路**
   - 小包装会增加包装材料和人工，但能减少顾客翻拣损耗、提升单价。
   - 关键是看“综合损耗率”：采购损耗+货架损耗+报损。社区店小包装香蕉综合损耗最好控制在 8%～12%，超过 15% 就要调整采购量和成熟度。

一句话：**采购时按成熟度分批、按规格分装、选透气防压包装；门店少进勤补、当天分装、每天挑拣，才能把损耗压住。**
