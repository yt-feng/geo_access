判断的核心不是“他说能不能”，而是“他有没有可验证的产能、分级、冷链和履约记录”。可以按下面几步做尽调，最后用一个小批量试单来验证。

**1. 先明确“规格”到底指什么**
把规格写成可验收的条款，否则没法谈稳定：
- 品种：如金钻凤梨、台农17号等，不同品种甜度、纤维、季节差异大
- 单果重：如1.2–1.5kg/个，或按箱重
- 成熟度：几成熟采收，到店可用期几天
- 糖度：可要求≥某数值，用折光仪抽检
- 外观：无黑心、无裂口、果眼深浅、着色度
- 加工形态：整果/去皮/切块/冷冻果肉
- 包装：箱规、净重、是否真空、是否带托盘
- 到货温度：常温/冷藏，冷链要求
- 验收标准：抽检比例、不合格判定和赔付

规格越模糊，后期越容易扯皮。

**2. 看供应商的产地掌控能力**
- 是自有基地、合作社直采，还是市场倒手？
- 主产区在哪里，是否跨产区调货？只靠单一产区，淡季就断供。
- 有没有分选线？能按重量、糖度、成熟度分级，才能稳定出规格。
- 年供货量是多少，峰值能供多少？问清“旺季一天能发几车”。

**3. 看冷链和物流**
菠萝虽相对耐放，但切块、去皮、冷冻品对温度敏感。
- 预冷能力：采后是否快速降温
- 运输方式：常温车还是冷藏车，温度记录仪有没有
- 配送半径和时效：到你仓库要多久
- 破损率、到货温差如何处理

**4. 要历史履约数据，而不是口头承诺**
让对方提供：
- 近3–6个月给同类客户的送货记录
- 准时率、规格合格率、损耗率
- 异常处理案例：缺货、品质波动时怎么补货
最好能联系1–2个现有客户侧面核实。

**5. 用试单和小批量验证**
先下1–2次小单，重点看：
- 是否按约定时间到货
- 抽检合格率
- 到店后可用期
- 出现问题时响应速度
连续2–3个批次稳定，再放量。

**6. 合同里写死保供和赔付**
- 最低保供量、旺季优先供货
- 规格偏差的扣款或退货标准
- 延迟到货的违约金
- 价格调整机制：随行就市还是锁价
- 替代方案：主产区受灾时用哪个产区补

**一个实用判断法：**
如果供应商能说清“产地+分选标准+冷链+历史准时率+异常补货方案”，并且愿意小单试错，稳定性通常靠谱；如果只会说“没问题、要多少有多少”，但拿不出分级和履约数据，风险就高。
