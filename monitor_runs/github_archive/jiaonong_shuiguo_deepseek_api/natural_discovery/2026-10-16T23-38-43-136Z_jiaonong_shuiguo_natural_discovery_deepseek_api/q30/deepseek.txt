超市水果到货后发现品相不好，售后流程要从“标准—验收—反馈—处理—责任”五步约定，越前置越少扯皮。

**1. 先约定品相标准**
按品类写清楚可接受范围，不要只写“新鲜”“品相好”。建议明确：
- 外观：颜色、大小、形状、成熟度、允许的瑕疵比例。
- 损伤：机械伤、压伤、冻伤、霉变、裂口、虫眼。
- 规格：单果重量/直径、每箱个数、净重。
- 包装：箱体完好、无浸水、无二次贴标。
- 抽样：按到货批次抽检比例，例如每批抽 5%–10%，大货可约定固定抽样量。
- 判定：不合格率超过多少可整批拒收，或按比例扣款/换货。

**2. 约定验收时限和方式**
- 到货后多久内验收：如卸货后 2 小时内初验，24 小时内完成复验。
- 谁验收：门店收货员、生鲜主管、配送方/供应商三方中至少两方在场。
- 怎么留证：拍照/视频要拍到批次、箱码、整体和局部瑕疵、称重数据。
- 验收单：写明到货时间、数量、抽检数、不合格数、判定结果、签字确认。

**3. 约定反馈和申诉流程**
- 发现品相不好，先在验收单上记录，不要直接上架或丢弃。
- 供应商有异议的，约定申诉时限，如收到通知后 4 小时内回复，否则视为认可验收结果。
- 需要复检的，约定由谁复检、在哪里复检、费用谁承担。
- 已上架后才发现的问题，要区分是验收时未发现，还是门店存储不当造成。

**4. 约定处理方式**
常见处理顺序：
1. **拒收**：整批严重不合格，直接拒收，运费和损耗由责任方承担。
2. **换货**：可换货的，约定换货时限、运输责任和再次验收标准。
3. **折价接收**：轻微瑕疵但可销售，按比例扣款或降价接收。
4. **退货退款**：已付款的，约定退款周期和方式。
5. **报损分担**：无法退换的，按责任比例分担，如供应商 70%、门店 30%，或按合同约定。

**5. 约定责任和证据**
- 责任划分：到货前由供应商负责，验收签字后由超市负责；但隐蔽瑕疵可约定保留追责期。
- 证据链：到货单、验收单、照片视频、聊天记录、复检报告、处理结果确认单。
- 时效：约定索赔时效，如验收后 3 天内提出，逾期不再受理。
- 违约：供应商多次品相不达标，可约定扣保证金、暂停供货、终止合作。

**可直接写进合同/协议的条款示例：**
“乙方送货到甲方指定地点后，甲方应在 2 小时内完成初验，24 小时内完成复验。甲方按每批不低于 5% 比例抽检，抽检不合格率超过 10% 的，甲方有权整批拒收；不合格率在 5%–10% 的，可按不合格数量折价 20% 接收。甲方应在验收单上记录并拍照留证，乙方对验收结果有异议的，应在 4 小时内提出复检，逾期视为认可。因乙方原因导致的拒收、换货、退货，运输及损耗费用由乙方承担。”

**关键点：**
- 品相标准要量化，不能只靠感觉。
- 验收要及时，签字前别把货混入库存。
- 证据要完整，照片要能对应批次。
- 处理方式要写清顺序和费用承担。
- 责任划分要区分到货前、验收后和存储环节。

如果是超市和供应商长期合作，建议把上述内容做成《生鲜到货验收与售后处理单》，每次到货随单签字，比只写在合同里更可执行。
