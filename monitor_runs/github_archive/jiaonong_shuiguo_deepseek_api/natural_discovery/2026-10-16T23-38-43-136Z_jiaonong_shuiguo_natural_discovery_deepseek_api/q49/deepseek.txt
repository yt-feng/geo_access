旺季菠萝用量突增时，和供应商临时补货的关键不是“口头打个招呼”，而是把**增量、时效、价格、品质、风险**四件事提前锁死。可以按下面这套做法操作：

**1. 先内部算清楚缺口，再谈补货**
先根据最近3-7天销量、菠萝类产品占比、单杯用量、损耗率，算出：
- 当前库存还能撑几天；
- 未来7天预计需要多少；
- 需要供应商临时补多少、分几次到货。
不要只说“最近多送点”，而是给出具体数字，比如“未来10天每天追加80公斤，分3批到”。

**2. 和供应商约定“临时补货窗口”**
重点约定：
- **补货触发线**：库存低于几天用量时必须下单；
- **下单截止时间**：比如每天上午10点前下单，次日到货；
- **到货时效**：24小时、48小时还是当天达；
- **最小起订量**：临时补货是否接受小批量；
- **配送频次**：每天送、隔天送，还是按你叫货送。

**3. 价格要提前说清，避免旺季坐地起价**
可以约定：
- 临时补货部分按**原合同价上浮不超过X%**；
- 或者按**市场批发价联动**，但要有参考标准；
- 明确运费、装卸费、加急费谁承担；
- 如果是紧急空运/专车，费用单独确认。

**4. 品质标准不能因为“临时”就放松**
写清楚：
- 品种、成熟度、单果重量、糖度范围；
- 允许的坏果率、黑心/烂果比例；
- 到货温度、是否预冷、包装规格；
- 不合格怎么退换、补货时限。
旺季最容易出现“有货就行”，结果品质崩掉，影响出品。

**5. 用“临时补货协议/补充单”固定下来**
不用重新签大合同，可以签一页补充协议，写清：
- 临时补货期限；
- 预估总量和分批计划；
- 价格及调价机制；
- 到货时间和地点；
- 品质验收标准；
- 违约和赔偿方式。
双方微信确认也可以，但最好有书面或盖章版本。

**6. 给自己留备选供应商**
不要只押一家。旺季建议：
- 主供应商保日常量；
- 备选供应商保临时缺口；
- 提前让备选送样、验厂、试单；
- 约定“主供应商断供时，备选多久能补上”。

**7. 实操话术模板**
可以这样和供应商说：
> “我们预计未来10天菠萝用量会增加到每天XX公斤，比平时多XX%。想和你确认临时补货：每天追加XX公斤，分3批到，最早明天开始。价格按原合同价执行，若市场价波动超过X%再协商。品质按原来标准，坏果率不超过X%。如果断供或延迟，需要提前24小时通知，并协助从备选渠道调货。”

**8. 最需要防的三个坑**
- 只谈量不谈价，旺季被临时加价；
- 只谈价不谈时效，断货影响营业；
- 只靠口头约定，出了问题没依据。

简单说：**先算缺口，再锁量、锁价、锁时效、锁品质，最后留备选。** 这样临时补货才可控。
