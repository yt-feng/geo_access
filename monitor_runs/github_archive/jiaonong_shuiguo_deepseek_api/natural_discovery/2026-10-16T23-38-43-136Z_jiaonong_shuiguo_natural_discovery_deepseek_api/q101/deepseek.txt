酒店早餐水果供应，核心不是“买到便宜水果”，而是**长期稳定、品质一致、损耗可控、账期清楚**。和供应商谈合作时，建议重点盯以下几类问题：

1. **先明确自己的需求标准**
   - 每天/每周用量、旺季淡季波动、早餐时段用量。
   - 需要哪些品类：苹果、香蕉、橙子、西瓜、哈密瓜、圣女果、火龙果等。
   - 规格要求：大小、甜度、成熟度、是否切果、是否去皮。
   - 验收标准：新鲜度、无腐烂、无压伤、成熟度一致、农残检测/合格证明。
   - 如果做切果，还要问是否具备清洗、切配、冷藏配送能力。

2. **供应稳定性**
   - 是否有固定基地、批发市场档口或多个产地渠道。
   - 节假日、台风、寒潮、雨季时如何保供。
   - 缺货时替代方案是什么，是否提前通知。
   - 是否支持每天送、隔天送、紧急补货，最晚下单时间和送达时间。

3. **价格和调价机制**
   - 不要只谈一个“低价”，要谈**报价周期**：周价、半月价还是月价。
   - 是否随行就市，调价提前几天通知。
   - 是否含运费、装卸费、税费、切配费、包装费。
   - 损耗谁承担：到店验收前损耗归供应商，验收后归酒店。
   - 是否可以约定价格上限或临时锁价，避免旺季暴涨。

4. **品质和验收**
   - 每天按样品验收，最好留样或拍照记录。
   - 明确拒收标准：烂果、裂果、过熟、太小、异味、农残不合格。
   - 不合格是补货、换货还是扣款，响应时间多久。
   - 定期做月度评分：新鲜度、准时率、缺货率、投诉次数。

5. **账期和结算**
   - 月结、半月结还是现结，账期多长。
   - 对账方式：送货单、验收单、发票是否齐全。
   - 是否开票，税率多少，能否开专票。
   - 退款、扣款、补货如何冲账。

6. **食品安全和合规**
   - 营业执照、食品经营许可证、检验合格证明。
   - 水果是否有农残检测报告或承诺达标合格证。
   - 配送车辆是否清洁、冷藏，是否与生鲜、化学品混装。
   - 切果供应商还要看加工环境、人员健康证、冷藏条件。

7. **合同里要写清楚**
   - 品名、规格、单价、数量、送货时间、验收标准。
   - 调价机制、缺货赔偿、质量赔偿、账期。
   - 食品安全责任、违约条款、终止合作条件。
   - 最好有试合作期，比如1个月，再决定是否长期签。

8. **谈判策略**
   - 先小批量试供，别一上来签长期大单。
   - 同时找2-3家供应商，主供+备供，避免被一家卡住。
   - 用“稳定用量”换“稳定价格”和“优先配送”。
   - 把早餐水果和宴会、员工餐水果打包谈，量越大议价空间越大。
   - 不要只压价，压太低容易换来降级货，最后损耗和投诉更高。

简单说，谈的时候抓住四个字：**标准、稳定、价格、责任**。把验收标准、缺货处理、调价规则、损耗归属写进合同，比单纯谈便宜更重要。
