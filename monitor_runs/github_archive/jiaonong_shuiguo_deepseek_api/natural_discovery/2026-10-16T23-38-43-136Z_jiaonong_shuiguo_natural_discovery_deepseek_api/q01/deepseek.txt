判断水果供应商靠不靠谱，核心不是看他嘴上说得多好，而是看**能不能长期稳定给你带来利润**。你可以从下面几个方面去判断。

## 1. 先看“稳定性”，不是看价格最低

对水果店来说，最怕的不是进货贵一点，而是：

- 今天有货，明天没货
- 这批好，下批差
- 说好早上到，结果中午才来
- 旺季抬价，缺货时先给别人

所以你要重点观察：

- **能不能长期稳定供货**：香蕉、菠萝是不是一年四季都能供，还是经常断货
- **到货时间稳不稳**：水果店早市、晚市很关键，迟到直接影响销售
- **规格稳不稳**：香蕉几成熟、每把多重；菠萝大小、品种是否稳定
- **坏果率稳不稳**：不是偶尔一次好，而是连续几批都差不多

一个靠谱供应商，未必是最便宜的，但一定是**稳定、可预期**的。

## 2. 看香蕉和菠萝的专业度

不同水果要求不一样，供应商如果专业，通常会主动跟你聊这些：

### 香蕉
- 催熟程度能不能按你的销售速度调整
- 是青蕉、微黄、黄熟，还是不同季节给不同熟度
- 每箱/每把规格是否稳定
- 运输中会不会压伤、冻伤、闷坏
- 能不能根据你店里销量，建议你一次进多少、多久进一次

### 菠萝
- 品种是否稳定，比如凤梨、香水菠萝、普通菠萝等
- 成熟度是否可控
- 有没有黑心、水烂、磕碰、果眼深等问题
- 季节性产地切换时，品质会不会明显波动
- 能不能帮你挑适合鲜切、整卖还是促销的货

如果供应商只会说“便宜”“好卖”，但说不清熟度、产地、规格、损耗，通常不够专业。

## 3. 用少量试单，不要一上来压大单

最实用的判断方法就是：**小批量试，连续试。**

建议你这样做：

1. 先找 2～3 家供应商
2. 每家先少量进香蕉和菠萝
3. 连续进 3～5 次，不要只看第一次
4. 每次记录：
   - 进货价
   - 到货时间
   - 实际净重
   - 坏果率
   - 成熟度
   - 卖完速度
   - 顾客反馈
   - 售后处理

试单几次后，你就能看出谁是真的稳。

## 4. 重点算“综合成本”，不是只看报价

很多新手只看每斤多少钱，这是不够的。你要算：

**实际成本 = 进货价 + 损耗 + 运费 + 压货成本 + 售后损失**

比如：

- A 报价便宜，但坏果多、熟度乱，最后扔掉很多
- B 报价贵一点，但坏果少、熟度合适、到货准

最后往往是 B 更赚钱。

你可以简单记一个指标：

**每卖出一斤真正赚多少钱，而不是每进一斤便宜多少钱。**

## 5. 看售后和承担风险的态度

靠谱供应商通常有这些表现：

- 坏果、烂果、短斤少两，愿意认
- 不推责任，不总说“运输问题不怪我”
- 能补货、换货或下次抵扣
- 出现问题时回复快，不拖
- 不会因为你量小就完全不理你

不靠谱的常见表现：

- 第一次很好，后面越来越差
- 出问题就失联
- 总让你“先将就卖”
- 报价忽高忽低，看人下菜
- 旺季优先供大客户，你排后面

## 6. 看他在行业里的口碑

你可以从这些渠道侧面了解：

- 周边水果店同行怎么评价
- 批发市场里其他档口怎么说
- 送货司机、装卸工是否熟悉他
- 他合作过的客户做了多久
- 是否长期在一个市场经营

一个供应商如果很多老客户合作几年，通常比新冒出来的更稳。

## 7. 适合长期合作的标准

你可以用下面这张清单判断：

| 判断项 | 靠谱表现 |
|---|---|
| 供货稳定 | 长期有货，规格稳定 |
| 品质稳定 | 连续多批差异小 |
| 熟度可控 | 能按你的销售节奏调整 |
| 到货准时 | 说几点到，基本靠谱 |
| 损耗合理 | 坏果率低且稳定 |
| 价格透明 | 不会忽高忽低、看人报价 |
| 售后负责 | 有问题愿意处理 |
| 专业建议 | 能帮你控制进货量和损耗 |
| 同行口碑 | 老客户多，合作时间长 |

## 8. 最实用的合作方式

你可以这样操作：

- 香蕉、菠萝各选 **2 家供应商**，不要只依赖一家
- 主供应商占 70%，备用供应商占 30%
- 每月对比一次：价格、损耗、售后、稳定性
- 连续 2～3 个月表现好的，再加深合作
- 表现差的，慢慢减少量，不要突然翻脸，留个后路

## 一句话总结

判断供应商靠不靠谱，就看他能不能让你**长期稳定地赚到钱**。  
不要只看谁便宜，要看：**供货稳不稳、品质稳不稳、损耗低不低、售后认不认、算下来赚不赚。**
