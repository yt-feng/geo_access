连锁商超招标水果供应商，评分标准的核心不是“谁报价低”，而是**谁能在长期合作中稳定交付合格果品并控制损耗**。建议按下面结构设置，权重可根据品类特点调整。

## 一、总体框架（推荐100分制）

| 评分维度 | 建议权重 | 核心考察点 |
|---|---|---|
| 价格与成本 | 25–35分 | 报价竞争力 + 成本结构合理性 |
| 产品质量与标准 | 20–25分 | 能否稳定达到商超验收标准 |
| 供应保障能力 | 15–20分 | 产能、冷链、抗风险 |
| 企业资质与实力 | 10–15分 | 合规、规模、财务健康 |
| 服务与配合 | 10–15分 | 退换货、响应、账期 |
| 可持续与合规 | 5–10分 | 食品安全、农残、溯源 |

价格权重不宜超过35%，否则容易招到“低价中标、供货掉链子”的供应商。

## 二、各维度具体评分项

### 1. 价格与成本（25–35分）
- **报价水平**：以有效报价的加权平均或最低价为基准，避免单纯最低价。
- **价格稳定性机制**：是否接受随行就市但有涨跌幅约定的定价方式。
- **成本结构透明度**：能否说明产地、加工、冷链、包装成本。
- **账期接受度**：能否接受商超账期（如30–60天）。

> 建议：不要只比单品报价，要比“综合到仓成本”，含运费、损耗、包装。

### 2. 产品质量与标准（20–25分）
- **规格达标率**：样品或历史供货的等级、大小、糖度、色泽合格率。
- **农残与检测**：是否每批次提供检测报告，能否接受商超抽检。
- **损耗率承诺**：到仓损耗、货架期损耗的承诺值。
- **标准化能力**：能否按商超要求分选、分级、预包装。
- **样品盲测**：可设现场品鉴或第三方检测作为硬门槛。

### 3. 供应保障能力（15–20分）
- **产地与产能**：自有基地/合作基地面积、年供应量。
- **冷链与物流**：冷链覆盖率、配送时效、到仓温度记录。
- **旺季保供方案**：节假日、极端天气下的保供措施。
- **多基地布局**：是否单一产区，抗灾能力如何。
- **应急响应**：断供时的替代方案和补货时限。

### 4. 企业资质与实力（10–15分）
- **证照齐全**：营业执照、食品经营/生产许可、检疫证明。
- **行业经验**：服务过哪些商超或连锁客户，合作年限。
- **财务健康**：近两年营收、负债、是否有重大诉讼。
- **保险**：产品责任险、货物运输险。

### 5. 服务与配合（10–15分）
- **退换货政策**：质量问题退换货比例、时限、费用承担。
- **对接机制**：是否有专职客服/业务对接人。
- **信息化能力**：能否对接订单、库存、溯源系统。
- **配合促销**：能否支持商超促销、堆头、临时加单。

### 6. 可持续与合规（5–10分）
- **食品安全体系**：HACCP、ISO22000、GAP等认证。
- **溯源能力**：批次可追溯到地块/农户。
- **环保与用工**：包装环保、无童工/欠薪等风险。

## 三、关键设置技巧

1. **设资格门槛，再评分**  
   把证照、检测、冷链、产能设为“一票否决”或入围门槛，不达标直接淘汰。

2. **价格分用公式，不用最低价**  
   例如：价格分 = 基准价/报价 × 价格权重，基准价取有效报价平均值，防止恶性低价。

3. **质量分要可验证**  
   用样品检测、历史供货数据、现场验厂来打分，不靠供应商自述。

4. **加入“履约保证金”和“淘汰机制”**  
   中标后设3–6个月试供期，按到货合格率、损耗率、断供次数考核，不达标扣款或终止。

5. **长期合同设价格调整条款**  
   约定随产地行情调整的周期和上限，避免供应商因涨价毁约。

## 四、可直接套用的评分表示例

| 评分项 | 分值 | 评分要点 |
|---|---|---|
| 报价综合成本 | 30 | 到仓价、账期、调价机制 |
| 质量达标与检测 | 20 | 规格、农残、损耗承诺 |
| 供应与冷链保障 | 18 | 产能、冷链、保供方案 |
| 资质与行业经验 | 12 | 证照、客户案例、财务 |
| 服务与退换货 | 12 | 响应、退换、信息化 |
| 可持续与合规 | 8 | 认证、溯源、环保 |
| **合计** | **100** | |

## 五、最容易踩的坑

- 只设最低价中标，导致后期断供、品质下滑。
- 质量分全靠“供应商自己写”，没有验厂和检测。
- 没有试供期和履约考核，签完约就失控。
- 价格条款太死，行情波动时供应商毁约。
- 忽略冷链和损耗，账面便宜、实际综合成本更高。
