社区超市找每日配送的水果供应商，核心不是“找最便宜的”，而是找**能稳定履约、损耗可控、账期可承受**的。建议重点看以下条件：

1. **每日配送能力**
   - 是否承诺每天固定时间送达，比如早市前到店。
   - 节假日、雨天、旺季是否能保证不断供。
   - 临时加单、改单的截止时间和响应速度。
   - 是否有备用车辆或备用仓，避免单点故障。

2. **货源稳定性**
   - 是产地直采、批发市场代采，还是二级批发。
   - 同一品种能不能长期稳定供货，而不是今天有明天没。
   - 是否受季节、天气、产区切换影响大。
   - 最好要求看近期真实供货案例，而不是只看宣传。

3. **品控和验收标准**
   - 是否接受按你方的验收标准退货、补货。
   - 烂果、压伤、成熟度不一致的比例怎么控制。
   - 是否支持开箱抽检、拍照留证。
   - 出现质量问题后，是补货、扣款还是退货，责任要写清。

4. **价格和结算方式**
   - 报价是否含运费、装卸费、包装费。
   - 是否随行就市，调价频率和通知时间是多少。
   - 是否支持月结、周结，还是必须现结。
   - 押金、起送量、最小起订量是多少。

5. **损耗和售后**
   - 水果损耗谁承担，尤其是运输损耗和到店后短时间变质。
   - 售后响应时间，比如几小时内处理。
   - 是否愿意先小批量试供一到两周。
   - 试供期重点看：准时率、缺货率、损耗率、售后态度。

6. **资质和食品安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 是否有农残检测或产地证明，至少能提供批次信息。
   - 运输车辆是否清洁、是否冷链或保湿运输。
   - 包装是否规范，能否避免挤压和污染。

7. **合作灵活性**
   - 能不能根据你店里的销量调整品类和数量。
   - 是否只推高毛利货，还是愿意配齐日常刚需水果。
   - 是否允许你保留一两家备用供应商，避免被单一供应商卡住。

实际筛选时，建议这样做：

- 先找 3 家候选，分别要报价单、配送范围、售后规则。
- 每家试供 7 到 14 天，记录准时率、缺货次数、损耗率、退换速度。
- 优先选“配送稳定、售后不扯皮”的，而不是单纯报价最低的。
- 合同或订单里写清：送达时间、验收标准、退换规则、调价机制、结算周期。

一句话判断标准：**能每天准时送到、坏果有人认、价格波动有规则、结算不压死现金流，才适合社区超市长期合作。**
