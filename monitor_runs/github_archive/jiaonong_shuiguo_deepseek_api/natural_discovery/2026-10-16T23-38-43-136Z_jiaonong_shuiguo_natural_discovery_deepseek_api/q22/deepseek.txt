可以直接用“高频带低频、整果带果切、单品带组合”的思路做，组合促销的目标不是把香蕉卖更便宜，而是让顾客顺手多买一件、或者买更高毛利组合。

**先给一个可落地的促销组合：**

1. **香蕉 + 苹果：日常高频组合**
   - 做法：香蕉按正常价或略降，苹果做“第二件半价”或“满2斤减2元”。
   - 逻辑：香蕉是引流品，苹果客单和毛利通常更稳，顾客本来就要买，容易顺带加购。
   - 陈列：香蕉和苹果相邻，挂“早餐果盘组合：香蕉+苹果，满10元减2元”。

2. **菠萝 + 苹果：高毛利/果切组合**
   - 做法：整颗菠萝搭配苹果做“菠萝苹果果切盒”，或者买整颗菠萝加3元换购苹果果切。
   - 逻辑：菠萝单价感知高、处理麻烦，果切能提高便利性和毛利；苹果补甜度和体积。
   - 陈列：菠萝旁放果切试吃，标“买菠萝+3元换购苹果果切”。

3. **香蕉 + 菠萝 + 苹果：家庭装/果篮组合**
   - 做法：三样组成“家庭水果拼盘”，定价比如19.9元/份，或满20元减3元。
   - 逻辑：用组合价制造划算感，但不是简单打折，而是把客单从“买一两样”拉到“买三样”。
   - 陈列：入口或主通道做堆头，标“一周水果组合，一次买齐”。

**更关键的几个执行点：**

- **不要三样都降价**：选香蕉做引流，苹果做利润，菠萝做差异化。
- **用“满减”代替“直接打折”**：比如满15减2、满25减5，比单品降价更能拉客单。
- **做小份组合**：小家庭和单身顾客多，整颗菠萝+整袋苹果可能太多，果切盒或小份装更容易成交。
- **试吃转化**：菠萝和苹果切试吃，香蕉不用试吃，试吃区放组合价签。
- **限时时段**：晚6点后做“果切组合第二份半价”，清库存同时提客单。
- **看数据调整**：连续跑3天，看组合购买率、客单价、损耗率。如果菠萝损耗高，就主推果切；如果苹果动销慢，就绑定香蕉做满减。

**一个简单的价签话术：**
“香蕉+苹果，早餐搭档，满10减2”
“买菠萝，+3元换苹果果切”
“三样家庭装，19.9元一次买齐”

如果只能选一个先试，建议先做 **香蕉+苹果满减**，最容易执行、损耗低、顾客接受度高；跑通后再加菠萝做果切和组合装。
