茶饮店控制食品安全风险时，水果供应商通常需要提供以下几类证明和文件。具体以当地市场监管部门要求和你的进货查验制度为准：

**一、主体资质类**
1. 营业执照（经营范围含水果销售/农产品销售）
2. 食品经营许可证（若供应商销售的是预包装或需许可的食品；纯食用农产品销售部分地区可豁免，需按当地规定确认）
3. 若为进口水果，还需进出口相关资质

**二、产品合格类**
1. 食用农产品承诺达标合格证（很多地区对果蔬类要求提供）
2. 产地证明或购货凭证
3. 检验检测报告：
   - 农药残留检测报告（重点）
   - 重金属等污染物检测报告（视品类和风险）
   - 报告应由有资质的检测机构出具，且在有效期内

**三、进口水果专项**
1. 海关入境货物检验检疫证明
2. 报关单
3. 中文标签（预包装进口水果制品需要）

**四、批次与追溯类**
1. 每批次送货单/销售凭证，注明品名、数量、日期、供应商
2. 产地、采摘或加工日期等追溯信息
3. 检疫合格证明（如柑橘等特定品类可能要求）

**五、其他建议**
1. 与供应商签订质量保证协议，明确农残、异物、腐烂等责任
2. 保留供应商联系方式，便于追溯和召回
3. 到货时做感官验收（色泽、气味、有无霉变虫害），并留存记录
4. 定期索取更新检测报告，不能只靠一次报告长期使用

**实操判断标准：**
- 能证明“谁卖的、卖的是什么、这一批合不合格、出了问题能追到谁”
- 农残检测报告和批次凭证是最核心的两项
- 如果供应商只能提供营业执照、拿不出检测报告或合格证，风险较高，建议更换或要求补检

各地监管口径不同，建议同时咨询当地市场监管部门，按其要求建立进货查验和索证索票台账。
