判断苹果和橙子的大小规格是否适合门店销售，核心不是“越大越好”，而是看**目标客群、销售场景、损耗和毛利**是否匹配。可按下面几步判断。

## 一、先定门店销售场景

不同门店，适合的规格不同：

1. **社区生鲜店/水果店**
   - 更适合中等规格，家庭一次买几个，价格敏感。
   - 苹果：单果 180–250g 较常见。
   - 橙子：单果 180–280g 较常见。

2. **精品水果店/高端超市**
   - 可接受大果、礼盒果、外观统一果。
   - 苹果：单果 250–350g。
   - 橙子：单果 250–350g。

3. **便利店/小超市**
   - 适合小规格、单次消费、即食。
   - 苹果：单果 150–220g。
   - 橙子：单果 150–250g。

4. **餐饮/果汁/团购渠道**
   - 更看出汁率、性价比，不一定要大果。
   - 橙子：单果 150–250g 往往更经济。

## 二、用可执行指标判断

采购时不要只问“70、75、80”，要同时看这些指标：

### 1. 单果重量
最直观。随机抽 10–20 个称重：
- 看平均单果重；
- 看最大最小差异；
- 差异过大，门店陈列和定价会乱。

### 2. 横径/果径
苹果、橙子常用“果径”分规格。
- 苹果常见：65、70、75、80、85、90mm。
- 橙子常见：60、65、70、75、80mm 等。

门店销售建议：
- 普通水果店：苹果 70–80mm，橙子 65–75mm 较稳。
- 精品店：苹果 80mm 以上，橙子 75mm 以上可做高端。
- 小果、次果：适合促销、榨汁、切果，不适合正价陈列。

### 3. 大小均匀度
同一批货里，大小是否整齐，比单纯大小更重要。
- 均匀：好陈列、好定价、好做标准份。
- 不均匀：要分级卖，否则顾客挑拣严重，损耗上升。

### 4. 果形和外观
- 苹果：果形端正、无明显畸形、无严重锈斑、无碰伤。
- 橙子：果形圆整、表皮细腻、无严重浮皮、无压伤。
- 大小达标但外观差，仍不适合正价门店销售。

### 5. 硬度、皮厚、成熟度
- 苹果太软、发绵，不适合门店久放。
- 橙子皮太厚、浮皮，出汁率低，顾客复购差。
- 太生或太熟，都不适合正常货架期。

### 6. 损耗率
采购前做小测试：
- 抽一箱，挑出碰伤、腐烂、畸形、失水果。
- 损耗超过 5%–8%，要重新谈价或降级销售。
- 精品店对损耗更敏感，最好控制在 3%–5%以内。

## 三、简单判断公式

可以按这个逻辑判断：

**适合门店销售 = 目标客群接受的大小 + 大小均匀 + 外观合格 + 损耗可控 + 毛利够**

如果只满足“大”，但损耗高、价格高、顾客不买，就不适合。

## 四、采购现场实操建议

1. **先抽样，不要只看样品**
   - 从不同箱、不同层随机抽。
   - 至少抽 3 箱，每箱抽 10 个。

2. **称重并记录**
   - 平均单果重；
   - 最大、最小；
   - 合格率。

3. **按门店定位定规格**
   - 社区店：中果为主，搭配少量大果。
   - 精品店：大果、均匀果为主。
   - 促销区：小果、二级果做特价。

4. **算毛利和损耗**
   - 采购价 + 运费 + 损耗 + 包装 = 成本。
   - 售价要覆盖成本并有合理毛利。
   - 如果大果采购价高但卖不动，不如中果周转快。

5. **先小批量试销**
   - 新规格先拿少量试卖 3–7 天。
   - 看动销、挑拣、损耗、顾客反馈。
   - 数据好再放量。

## 五、结论

苹果和橙子是否适合门店销售，不能只看“大不大”，要看：

- **规格是否符合门店客群**；
- **大小是否均匀**；
- **外观和内部品质是否合格**；
- **损耗和货架期是否可控**；
- **毛利和周转是否合理**。

一句话：**中等偏大、均匀、外观好、损耗低、毛利够，通常最适合门店正价销售；特大果做精品，小果做促销或加工。**
