选规格的核心不是“越大越划算”或“越小越便宜”，而是看**出成率、损耗、人工和摆盘效果**。水果拼盘里，这三种水果的选法差别很大。

**苹果**
- 优先选中大果，单果约200–300克，果形周正、大小一致。
- 不要选太大：一个太大，切瓣后每片过宽，摆盘不好看，剩下半颗也容易氧化。
- 不要选太小：削皮去核后出成率低，人工还高。
- 餐厅用建议按“每份拼盘用1/4–1/2个苹果”倒推采购量。如果一份用半个，就选200–250克规格，最稳。

**橙子**
- 优先选中等偏大、皮薄、汁多、易剥的规格，单果约180–250克。
- 太小：切出来瓣小，摆盘显得少，出成率也低。
- 太大：皮厚、白瓤多，切瓣后损耗大，还容易压秤。
- 如果做“橙子切片”或“橙瓣”，选大小均匀的，摆盘效率最高。
- 如果只榨汁或做装饰，可以选稍小果，但拼盘不建议。

**菠萝**
- 优先选成熟度合适、果眼浅、去皮损耗小的品种。
- 规格上，单果1.2–1.8公斤通常比较适合餐厅：太大一次用不完，切好后存放易变味；太小去皮去眼后出肉少。
- 如果拼盘用量大，选大果更划算，但必须配合当天用完。
- 如果拼盘用量小，选小果或直接买去皮菠萝，减少损耗和人工。

**划算判断公式**
按“可食用部分成本”算，而不是按斤价算：

可食用部分成本 = 采购单价 ÷ 出成率

例如：
- 苹果出成率约70%–80%
- 橙子出成率约50%–65%
- 菠萝出成率约40%–55%

谁的可食用部分成本低，谁才真正划算。

**餐厅实操建议**
1. 苹果：选200–250克、大小均匀的中大果。
2. 橙子：选180–250克、皮薄易剥的中大果。
3. 菠萝：选1.2–1.8公斤、成熟度一致的果；用量小就买去皮果。
4. 拼盘用果优先看“切出来是否整齐”，不是单纯看单价。
5. 如果每天用量稳定，直接找供应商定“拼盘专用规格”，比临时买大果或小果更省损耗。

一句话：**苹果选中大果，橙子选中大皮薄果，菠萝按用量选1.2–1.8公斤或直接买去皮果；最终按出成率算可食用部分成本。**
