# 多店小量水果供货模式建议

## 核心矛盾

门店多=需要覆盖能力，单店量小=议价能力弱、配送成本高。所以要找的是**能拼单、能小批量高频配送、账期灵活**的供货方。

## 优先考虑的几种模式

**1. 区域批发市场 + 自采/代采**
- 适合：门店集中在同一城市、有车或能安排人
- 优势：品类全、当天可补、无起订量压力
- 关键：固定1-2个靠谱档口，谈好"长期合作价+优先拿好货"，比到处比价更实际

**2. 本地水果供应链公司/配送商（B2B生鲜配送）**
- 适合：门店分散、不想自己管采购
- 优势：能按店配送、支持小批量、有分拣
- 注意：通常有起送额或配送费，要算进成本；重点谈**按门店分拣配送**和**缺货/损耗赔付**

**3. 产地/一级批发商 + 拼单集采**
- 适合：有总部仓或能集中收货再分拨
- 做法：把多店需求汇总成整车/整批，降低单价，再由总部或第三方分到各店
- 前提：你得有**集单和分拨能力**，否则省的钱被物流吃掉

**4. 联采/联盟采购**
- 和本地其他非竞争超市、社区店联合下单，凑量拿低价
- 适合：单打独斗议价弱时

**5. 单品爆款直采 + 其余走配送商**
- 少数走量单品（如香蕉、苹果、应季爆品）直接找产地或一级商
- 长尾品类交给配送商，平衡成本和省心

## 判断标准（按优先级）

| 维度 | 要问清楚 |
|------|----------|
| 起订量 | 单店最小起送量/金额是多少 |
| 配送频次 | 能否隔天/每天配，能否分店配送 |
| 损耗赔付 | 坏果谁承担，怎么赔 |
| 账期 | 现结还是月结，影响现金流 |
| 价格稳定性 | 是否随行就市，有无保底 |
| 品类覆盖 | 一站配齐还是分几家 |

## 实操建议

1. **先集中1-2家主力供应商**，别铺太散，否则每家量都小、谁都不重视你
2. **把采购权收到总部或区域**，门店只报需求，用总量换价格
3. **建个简单集单表**（各店每日/隔日需求汇总），这是你谈判的筹码
4. **主力供应商 + 批发市场补缺**组合，避免被单一供应商卡脖子
5. 谈判时强调"**门店多、长期稳定、持续增量**"，而不是"我量小"

## 最不推荐的

- 每家店各自找小贩零采：价格乱、品质不稳、无法管理
- 一味追求最低价找远距离产地直发：量小摊不平物流和损耗

**一句话结论**：优先找**本地B2B水果配送商做主力**（解决多店小量配送），再用**批发市场/产地拼单**补价格和爆品，核心是把多店需求集中起来当筹码。
