采购香蕉时，建议按**用途和到货后能放几天**来倒推熟度，不要只按“香蕉好不好看”来买。

**1. 先定用途**
- **做冰沙、奶昔、香蕉牛奶**：用**熟到带少量黑点、香气浓、甜度高**的香蕉。生香蕉会有涩味和淀粉感，打出来发青、不香。
- **做香蕉泥、果酱、蛋糕夹心**：用**全黄偏软、黑点较多**的香蕉，甜度和香气最好。
- **做装饰切片、果粒**：用**刚全黄、无黑点或极少黑点**的香蕉，切面整齐，不容易烂。
- **做炸香蕉、烤香蕉**：用**黄熟但还稍硬**的，太软下锅容易散。
- **做冷饮顶部装饰**：临出品再切，采购用**黄熟偏硬**，避免氧化发黑和软塌。

**2. 采购熟度怎么判断**
可以简单分：
- **1级：青绿硬**——适合囤货，不适合马上用。
- **2级：黄绿相间**——还要放1—3天。
- **3级：全黄、手感微软**——适合大多数饮品、甜品。
- **4级：全黄带黑点、明显软**——适合香蕉泥、奶昔、烘焙。
- **5级：大面积发黑、过软**——只能做香蕉面包/蛋糕，不建议做饮品。

**3. 按用量和周转控采购**
- 如果每天用量稳定：**主力采购3级，少量4级当天用，少量2级做后备**。
- 如果客流波动大：多买**2—3级**，到店后自己催熟，减少当天用不完就烂掉。
- 如果门店不能控温：夏天香蕉熟得快，尽量买**2—3级**，别买4级囤货；冬天可以适当买熟一点。
- 如果第二天就要大量用：买**3级为主，4级少量**；需要隔天用的，买**2—3级**。

**4. 到货验收标准**
- 看：颜色均匀，无大面积黑斑、无霉点、无裂口。
- 摸：按用途选软硬。切片要偏硬，打泥要偏软。
- 闻：有自然香蕉香，无酒味、酸味。
- 查：果柄发黑腐烂、果身流水、表皮破损的不要收。
- 抽检：同批次切开看，如果芯发黑、发硬、发酸，整批慎用。

**5. 到店后管理**
- **青的**：常温避风存放，别冷藏，可和苹果/梨放一起催熟。
- **刚全黄的**：常温阴凉处，优先排班先用。
- **熟透的**：去皮分装，冷藏1—2天或冷冻做冰沙；冷冻香蕉适合奶昔，不适合装饰。
- **切开的**：尽量当班用完；必须保存时，用保鲜膜贴面+冷藏，并尽快使用。
- **先进先出**：按熟度贴标签，比如“今日用”“明日用”“催熟中”。

**6. 建议的采购策略**
可以写成一句话：
**“主力买3级，搭配2级做周转，4级只按当天泥/奶昔用量买，装饰用3级偏硬。”**

如果你们菜单里香蕉饮品和甜品占比高，最好固定一个供应商，并约定到货熟度等级；同时每天记录用量和损耗，一般跑1—2周就能算出适合你们门店的“黄熟/黑点/青蕉”采购比例。
