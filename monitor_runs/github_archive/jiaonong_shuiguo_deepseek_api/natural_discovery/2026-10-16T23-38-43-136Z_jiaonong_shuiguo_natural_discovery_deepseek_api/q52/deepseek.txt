买香蕉时，核心是**买熟度合适的，而不是买最黄最好看的**。

具体可执行的做法：

1. **按到店后计划使用时间选熟度**
   - 当天或第二天就用：买**通体黄、带少量糖斑**的，能立即用。
   - 2～3 天内用：买**黄中带一点青、两端还略绿**的，到店后刚好熟成。
   - 3 天以上才用：买**整体偏青、硬**的，慢慢后熟。
   如果采购时全是全黄甚至带黑斑的，到店后基本一定会很快变黑。

2. **整串采购，不拆散**
   拆开的香蕉会释放更多乙烯，互相催熟更快。整梳/整串买，回来再按需分切。

3. **看果柄和果蒂**
   果柄发黑、发软、有霉点的不要。果柄青绿、饱满的通常更新鲜、耐放。

4. **避免机械伤**
   磕碰、挤压后的香蕉局部会先发黑腐烂。运输和上架时不要堆压。

5. **到店后先做降温处理**
   香蕉不能直接进冰箱冷藏，低温会冻伤发黑。正确做法是：
   - 放在**阴凉、通风、避光**处，理想约 **13～15℃**。
   - 夏天如果室温很高，可放空调房或冷柜附近，但不要低于 12℃。

6. **挂起来或果蒂朝上放**
   减少受压面，能延缓发黑和腐烂。

7. **隔离乙烯**
   香蕉不要和苹果、梨、番茄等一起放，这些会释放乙烯催熟。需要暂存时，可用保鲜膜包住果柄，或单独放在纸箱里，留一点通风。

8. **已经偏黄时，分用途处理**
   - 马上做香蕉奶昔、蛋糕、果酱的：可以接受糖斑。
   - 还要摆柜或做装饰的：把过熟的和未熟的挑开，避免互相催熟。
   - 实在快熟透：去皮后冷冻，之后做冰沙或烘焙。

9. **采购上少量多次**
   甜品店用香蕉如果每天用量稳定，最好按 2～3 天用量分批采购，而不是一次囤一周。香蕉是后熟型水果，囤货越久损耗越高。

简单记：**青一点买，整串拿，别挤压，阴凉通风放，远离苹果梨，快熟就冷冻或加工。**
