想买到熟度合适的香蕉，关键是**看颜色、摸手感、看用途分情况**，不要只看“黄不黄”。

**到店挑选时看这几点：**

1. **按用途选颜色**
   - **当天吃/1天内吃**：选全黄、带少量褐斑的最好。
   - **2～3天后吃**：选黄中带一点绿尖的。
   - **想放5天以上**：选整体偏绿、只有微黄的。
   - **马上做香蕉奶昔/烘焙**：选有黑褐斑、手感软的更甜。

2. **摸果柄和果身**
   - 果柄发绿、果身硬：偏生，适合放几天。
   - 果柄微黄、果身有弹性：熟度适中，适合近期吃。
   - 果身很软、局部凹陷：过熟或碰伤，不建议买。

3. **看棱角**
   - 棱角分明、很硬：偏生。
   - 棱角变圆、手感饱满：成熟度较好。
   - 太圆太软：偏熟。

4. **避免买这些**
   - 表皮大面积发黑、流水、有酒味：已经过熟或变质。
   - 果柄发霉、长毛：不要买。
   - 整串颜色差异极大：成熟不均，回家后有的太生有的太熟。

**如果买回家发现太生：**
- 和苹果或熟香蕉一起放进纸袋，室温放1～2天，能加快催熟。
- 不要直接放冰箱，低温会让香蕉变黑、停止成熟。

**如果买回家发现快太熟：**
- 立即冷藏果肉可以延缓继续变软，但表皮会变黑，不影响里面吃。
- 剥皮后切段冷冻，之后做奶昔很方便。
- 熟透的可以做香蕉面包、煎香蕉。

**最稳的采购策略：**
一次买两种熟度：**少量全黄带斑的现在吃，多数微黄带绿尖的后面吃**。这样到店不会太生，回家也不会几天内全熟烂。
