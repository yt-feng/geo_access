连锁超市要把门店坏果率压下来，合同里建议把**验收标准、责任归属、赔付方式、扣款执行**四件事写死，否则最后容易变成“扯皮式赔付”。

**一、先把“坏果”定义清楚，不然后面没法赔**

合同里不要只写“坏果”，要写可判定的标准，例如：

- 腐烂、发霉、软烂渗液
- 机械伤面积超过果面多少
- 裂口、压伤、冻伤、日灼
- 异味、虫蛀、空心、黑心
- 不符合约定的成熟度、规格、等级

最好约定：**以收货门店现场验收为准，必要时拍照/视频留证，争议时以第三方检测或双方共同复检为准。**

**二、赔付要分环节，不要只写一个总比例**

坏果可能来自：

1. 供应商采摘、分选、包装问题
2. 物流运输温控、挤压问题
3. 门店收货后储存、陈列问题
4. 正常损耗

合同里应写：**供应商责任导致的坏果，由供应商赔；门店自身原因导致的，不能扣供应商。**

**三、赔付方式建议写这几种组合**

1. **直接扣款**
   - 按坏果数量×采购单价扣款
   - 或按坏果重量×当日结算价扣款
   - 可加“处理费/分拣费”，例如每公斤加收X元

2. **补货替换**
   - 供应商在约定时间内补发同等数量、同等品质商品
   - 逾期未补，转为扣款

3. **整批退货**
   - 坏果率超过约定阈值，如5%、8%、10%，超市有权整批拒收或退货
   - 退货费用、运费、损耗由供应商承担

4. **质量保证金**
   - 供应商缴纳质量保证金
   - 月度坏果率超标，直接从保证金扣
   - 合作结束无争议再退

5. **阶梯赔付**
   - 坏果率≤3%：正常验收
   - 3%＜坏果率≤5%：按实际坏果扣款
   - 5%＜坏果率≤10%：扣款+补货+警告
   - ＞10%：整批退货+扣款+暂停供货/终止合同

**四、合同里建议直接写的核心条款**

可以写成类似：

> 乙方交付商品经甲方门店验收，若发现腐烂、变质、机械伤、规格不符等不合格果品，甲方有权按实际不合格数量×采购单价进行扣款；不合格率超过5%的，乙方应在24小时内补货；超过10%的，甲方有权整批拒收，由此产生的运费、分拣费、损耗及门店损失由乙方承担。乙方对坏果责任有异议的，应在收到通知后24小时内提出并共同复检，逾期视为认可。

**五、扣款执行要写清楚**

- 扣款依据：验收单、照片、视频、系统记录
- 扣款时间：月度对账时扣，或次日直接扣
- 通知方式：邮件、系统、微信群、书面确认
- 争议处理：先复检，再协商，协商不成按合同争议条款
- 对账确认：供应商逾期不确认，视为认可

**六、防止供应商扯皮的几个关键点**

1. **验收时限**：收货后几小时内完成验收，过期再提坏果不认。
2. **举证责任**：谁主张谁举证，但供应商要证明不是自己的责任。
3. **责任倒置**：门店收货时已拍照，供应商若说门店储存不当，要自己举证。
4. **数据留痕**：每批货的坏果率、扣款金额、补货记录都进系统。
5. **月度考核**：把坏果率和供货资格、账期、返利挂钩。

**七、最实用的建议**

不要只谈“赔多少钱”，要谈：

- **坏果率目标**：比如月度综合坏果率≤3%
- **超标怎么赔**：按实际坏果扣款+补货
- **严重超标怎么处理**：整批退货、暂停供货、终止合同
- **门店原因怎么排除**：验收后坏果由门店承担，验收前由供应商承担

一句话：**合同里要写“按验收结果赔、按坏果数量扣、超标可退货、争议要复检、逾期视为认”。** 这样门店坏果率才有抓手，赔付也才落得下去。
