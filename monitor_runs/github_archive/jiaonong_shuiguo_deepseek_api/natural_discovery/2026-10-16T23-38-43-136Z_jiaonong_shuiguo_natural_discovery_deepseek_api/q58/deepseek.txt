通常情况下，**直接买成品果丁的损耗更低**，但这个结论要看你怎么定义“损耗”和“成本”。

### 1. 只看原料损耗率：成品果丁更低

鲜菠萝切配的损耗包括：

- **外皮、果眼、果心**：约 **40%～60%** 不能用于果丁，具体看品种、成熟度和刀工。
- **修整损耗**：为了切出规整果丁，还要再去掉边角。
- **熟度不稳定**：太生太酸、太熟易烂，都会增加报废。
- **操作损耗**：切多了用不完、氧化出水、冷藏后出水变质。

所以鲜菠萝买 10 斤，最后能用的果丁可能只有 **4～6 斤**，甚至更低。

成品果丁是工厂集中去皮、切丁、分选后的结果，你买到的基本就是“可用部分”，门店端损耗主要变成：

- 解冻/开袋后的出水
- 当天用不完的报废
- 冷链或储存不当导致的变质

从**门店现场可感知的损耗**看，成品果丁明显更低。

### 2. 但“损耗低”不等于“总成本低”

成品果丁通常单价更高，因为供应商承担了：

- 原料损耗
- 人工
- 冷链
- 包装
- 品控

所以你要比较的是：

**鲜菠萝总成本 = 采购金额 ÷ 可用果丁重量 + 人工切配时间 + 垃圾处理 + 报废风险**

**成品果丁总成本 = 采购金额 + 解冻/储存损耗 + 报废风险**

如果鲜菠萝很便宜、员工空闲时间多、每天用量大且稳定，自己切可能更划算。
如果人工贵、用量不稳定、后厨空间小、品控要求稳定，成品果丁更省心，综合成本未必更高。

### 3. 关键判断建议

你可以这样选：

- **损耗率优先、出品稳定优先**：选成品果丁。
- **成本优先、每天用量大且稳定、有人工切配**：选鲜菠萝。
- **用量小、菜单不固定、不想压人工**：选成品果丁。
- **想做“新鲜现切”卖点**：选鲜菠萝，但要接受损耗和人工。
- **果丁规格要求高、要统一大小**：成品果丁更稳。

### 4. 实操建议

建议你做一次 3 天测试：

1. 买一批鲜菠萝，记录：采购重量、去皮后重量、切丁后重量、废弃重量、耗时。
2. 买同规格成品果丁，记录：到货重量、沥水后重量、报废重量。
3. 算出每 100g 可用果丁的真实成本。
4. 再对比出品速度、口感、投诉率、保存时间。

结论一般是：

**门店端损耗：成品果丁更低。**
**综合成本：用量大且人工便宜时鲜菠萝可能更低；否则成品果丁更稳。**
