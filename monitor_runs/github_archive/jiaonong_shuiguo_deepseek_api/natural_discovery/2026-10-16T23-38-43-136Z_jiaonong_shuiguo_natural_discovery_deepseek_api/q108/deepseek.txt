核实水果供应商“全国配送”的真实覆盖能力，关键是把口头承诺拆成可验证的环节：**到不到、多久到、坏不坏、谁负责**。可以按下面几步做。

**1. 先问清“全国配送”的定义**
让对方书面明确：
- 覆盖范围：是全国所有省市，还是只到地级市/主城区？偏远地区、乡镇、海岛是否配送？
- 配送方式：顺丰/京东等快递，还是自有冷链干线+落地配？不同方式覆盖和时效差别很大。
- 起送量：一箱也送，还是必须整车/整批？小批量是否加价？
- 时效：承诺几小时/几天到？是到城市，还是到门店/仓库？

**2. 用真实地址做“盲测”**
不要只问销售，直接给几个有代表性的收货地址让其报方案和价格，例如：
- 一线城市主城区
- 二三线城市
- 县级市/县城
- 乡镇或偏远地区
- 你实际要发货的地址
让对方对每个地址给出：能否送、时效、运费、是否冷链、是否加收偏远费。能给出具体报价和路由的，可信度更高。

**3. 要求提供可核验的物流凭证**
- 近期发往不同地区的运单号，你自己去快递/物流官网查轨迹。
- 冷链运输的温控记录、到货温度数据。
- 落地配合作方名称，必要时直接联系落地配确认。
- 过往客户的收货地址清单（可脱敏），但要有真实城市和签收记录。

**4. 做小批量试单**
这是最有效的方式。选2—3个不同区域各下一小单，重点观察：
- 实际时效是否和承诺一致
- 包装是否抗压、是否加冰袋/保温箱
- 到货损耗率、烂果比例
- 出现问题后售后响应速度和赔付方式

**5. 查资质和履约能力**
- 营业执照、道路运输/食品经营相关资质。
- 是否有自有冷库、冷链车、分拣中心，还是纯转包。
- 问清楚旺季、节假日、疫情/天气异常时的保供方案。
- 看合同里是否写明覆盖区域、时效、损耗标准、赔付责任，而不是只写“全国配送”。

**6. 重点识别几个话术陷阱**
- “全国都能发”≠“全国都能冷链直送”，可能只是普通快递，水果损耗会很高。
- “和顺丰合作”≠所有地区都冷链，可能只是普通件。
- “偏远地区也能送”要问清加价多少、时效多久。
- 只给全国统一报价、不敢按地址细算的，通常实际覆盖有限。

**建议动作**：让对方按你提供的5个不同层级地址出具书面配送方案和报价，同时要3—5个近期真实运单号自查，再选2—3地试单。试单合格后再签长期合同，并把覆盖区域、时效、损耗率、赔付标准写进合同。这样基本能判断其“全国配送”是真实能力还是销售话术。
