超市卖菠萝，**核心要看“综合经营价值”，不是单一指标**。如果必须排优先级，我建议这样判断：

1. **切果损耗优先**  
   超市卖菠萝，真正吃掉利润的往往不是进货价，而是损耗：  
   - 去皮、去眼、切块后的出成率  
   - 切好后卖不掉、氧化、出水、变味  
   - 员工操作不熟导致浪费  
   所以先看：**同样进价下，哪个品种/规格切出来更划算、更好卖。**

2. **甜度第二**  
   甜度决定复购和口碑。  
   - 太酸的菠萝，试吃转化差，切果也不好卖  
   - 但甜度不能只看“闻着香”，要看批次稳定性  
   超市最好用**糖度计抽检**，或者固定供应商按成熟度分级供货。

3. **外观第三**  
   外观影响“能不能卖上价”，但不如损耗和甜度致命。  
   - 果形端正、颜色金黄、冠芽新鲜，适合整果陈列  
   - 外观差但甜度好的，可以转切果、果切杯、促销  
   所以外观是**分级销售依据**，不是唯一采购标准。

4. **大小第四**  
   大小主要影响定位和定价：  
   - 大果适合家庭装、整果促销  
   - 中果适合日常走量  
   - 小果适合切果杯、一人食  
   大小本身不决定赚钱，关键看**和目标客群、售价、出成率是否匹配**。

**实操建议：**
- 整果区：看外观+大小，做分级陈列。
- 切果区：看甜度+出成率+损耗，优先选稳定、易切、出肉率高的批次。
- 采购时：先小批量试销，记录“进价、出成率、糖度、日损耗、售罄时间”，再决定主推哪个规格。
- 如果只能选一个指标：**先盯切果损耗和出成率**，因为它直接决定毛利。  
- 如果做社区超市、水果店：**甜度稳定比外观更重要**，因为复购靠口感。

一句话：**损耗决定赚不赚钱，甜度决定回不回头，外观和大小决定卖什么价。**
