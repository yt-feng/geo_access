小面积便利店做水果，核心原则可以概括为：**少品类、高频次、小批量、快周转、强预警**。下面按可执行程度分层给你建议。

## 一、品类控制：先做“减法”而不是“加法”

小门店陈列位有限，水果品类超过 **8～12 个** 通常就开始互相挤占、增加损耗。

**建议结构（按角色分，而不是按品种分）：**

| 角色 | 占比建议 | 举例 | 作用 |
|---|---|---|---|
| 引流款 | 1～2 个 | 香蕉、苹果 | 认知度高、价格敏感、带客进店 |
| 利润款 | 2～3 个 | 芒果、提子、蓝莓 | 毛利高、差异化 |
| 即食款 | 1～2 个 | 切果盒、小番茄、圣女果 | 冲动消费、客单价高 |
| 应季款 | 2～3 个 | 当季主推 | 制造新鲜感、季节流量 |
| 试销款 | 最多 1 个 | 新品 | 小批量测反应，不行立刻撤 |

**硬性规则：**
- 每个品类只保留 **1 个SKU**，不要同时上三个苹果品种。
- 试销款一次只进 **1 箱或最小起订量**，卖不动 3 天内下架。
- 不卖需要“养熟”“催熟”的复杂品类（如需要后熟的猕猴桃、牛油果），小店没精力管。

## 二、采购量控制：用“天数”倒推，而不是凭感觉

**核心公式：**
> 单次采购量 ≈ 该品类近7天日均销量 × 计划售卖天数 ×（1 - 可接受损耗率）

小门店建议：
- **高频品类（香蕉、苹果、橙子）：** 按 **2～3 天** 销量采购
- **中频品类（芒果、提子）：** 按 **1～2 天** 销量采购
- **易损品类（草莓、蓝莓、切果）：** 按 **1 天甚至半天** 销量采购
- **叶菜型水果（如果涉及）：** 当天清

**实操判断：**
- 新品类第一周：先按“预估日销 × 1天”试，卖完再加。
- 连续 3 天日销稳定后，才允许按 2～3 天量补货。
- 任何品类 **当日售罄率低于 70%**，第二天减量 30%。

## 三、损耗控制：从“事后扔”改成“事前拦”

### 1. 收货环节
- 到货当场抽查：烂果、压伤、过熟直接拒收或折价。
- 记录每个供应商的“到货损耗率”，连续高的换掉。

### 2. 陈列环节
- 水果 **不要堆太满**，堆头超过两层容易压伤底层。
- 易损水果放阴凉处，避免门口暴晒位。
- 香蕉、芒果等后熟水果 **不要和苹果、梨放一起**（乙烯催熟）。

### 3. 分级销售
- 好果：正常价
- 轻微瑕疵：做 **切果盒 / 特价区**
- 过熟：做 **果汁 / 果切 / 搭配酸奶**（如果条件允许）
- 不可食用：立即报损并记录

### 4. 日报损机制
每天固定时间（建议闭店前1小时）做三件事：
1. 挑出次日不能正常卖的水果
2. 能切的切、能特价的特价
3. 记录报损金额和品类

**报损率警戒线：**
- 整体水果损耗率 **控制在 5%～8%** 算正常
- 超过 **10%** 说明采购量或品类结构有问题，必须调

## 四、一个可以直接用的小店采购节奏

**建议节奏：**
- **每天早上一补**：香蕉、切果、易损品
- **隔天补一次**：苹果、橙子、常规品
- **每周两次**：利润款、应季款
- **每周复盘一次**：看哪些品类连续报损高，直接砍掉

**砍品规则：**
> 连续 7 天，某品类日均销量低于 3 份，或损耗率高于 15%，就下架。

## 五、最容易被忽略但最关键的一点

小门店做水果，**不是靠“进得便宜”，而是靠“转得快”**。  
宁可每天补两次小量，也不要一次进三天的量省事。  
陈列位有限时，**每多一个品类，就多一份损耗风险**。
