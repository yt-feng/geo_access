如果目标是**稳定成交 + 让客户真实感知到便宜**，多数情况下优先用**阶梯价**；如果目标是**锁量、压库存、控乱价、便于后续谈判**，则用**返利**更合适。最优做法通常不是二选一，而是“前台阶梯价 + 后台返利”组合。

**怎么判断**

1. **客户最在意当下单价，选阶梯价**
   - 适合：中小团购客户、比价明显、采购决策快、要求报价单直接有吸引力。
   - 优点：直观，好成交，客户马上看到“买得多更便宜”。
   - 风险：价格一旦给低，后续很难涨回去；容易扰乱价格体系。

2. **客户有持续采购能力，选返利**
   - 适合：大客户、长期合作、年度框架采购、对方采购负责人需要业绩或降本指标。
   - 优点：不直接破坏标价，能绑定全年采购量，方便设置考核条件。
   - 风险：客户感知弱，现金流压力大，年底兑现容易扯皮。

3. **供应商想控价、防窜货，选返利**
   - 阶梯价会让每个客户都盯着最低档，容易对外传播底价。
   - 返利可以把优惠藏在后台，前台价格统一，更适合有渠道体系的供应商。

4. **客户价格敏感且一次性采购，选阶梯价**
   - 返利对一次性客户没意义，兑现周期太长。
   - 阶梯价能直接刺激本次下单量。

**推荐组合方案**

- 前台：给 2—3 档阶梯价，但最低档不要直接到底。
- 后台：设置季度/年度返利，按累计采购额、回款、品类结构给。
- 条件：返利要和回款绑定，避免只压货不付款。
- 边界：阶梯价管“单次大单”，返利管“长期累计”。

**简单决策表**

| 情况 | 更适合 |
|---|---|
| 一次性团购、比价强、要快速成交 | 阶梯价 |
| 长期采购、年度框架、大客户 | 返利 |
| 标品、价格透明、竞争激烈 | 阶梯价为主 |
| 非标品、渠道多、怕乱价 | 返利为主 |
| 想同时锁量和保价盘 | 阶梯价 + 返利组合 |

**关键提醒**
- 返利比例别拍脑袋，要算清毛利底线和回款周期。
- 阶梯价档位不要太多，2—3 档最有效；太多客户会只盯最低价。
- 返利必须写清：计算基数、回款条件、兑现时间、是否含税、是否可抵扣。
- 如果客户只关心“这次能便宜多少”，返利基本无效；如果客户关心“全年能省多少”，返利更有效。
