线上水果销售要减少坏果和口感不稳定，核心不是“采购时挑得仔细一点”，而是把采购变成一套能筛选、能验收、能追责、能复购的标准流程。可以从下面几层做。

**1. 先定“可卖标准”，不要只凭感觉收货**
按品类写清楚：
- 单果重量/果径范围，比如 80–90mm、单果 250–300g
- 成熟度：几分熟采、到手几分熟
- 糖度/酸度范围：如糖度≥12°Brix
- 外观缺陷容忍度：裂口、虫眼、压伤、日灼、黑心允许比例
- 口感底线：脆度、化渣、香气、酸涩感、纤维感

没有标准的采购，最后一定变成“这批还行，下批看运气”。

**2. 选对产地和供应商，而不是只选低价**
优先看：
- 产区是否匹配品种：同一品种不同产区口感差异很大
- 供应商是否有分级、预冷、冷藏、包装能力
- 是否能稳定供货，而不是只靠一季爆款
- 是否愿意提供采摘批次、采摘时间、糖度抽检数据
- 历史售后率、坏果率、口感投诉率

对线上销售来说，**稳定比极致便宜更重要**。低价但波动大的货，售后和差评成本往往更高。

**3. 采购时重点控“成熟度”和“采后时间”**
坏果和口感不稳定，很多不是产地问题，而是：
- 采太生：到手酸、硬、没味
- 采太熟：运输中软烂、发霉、出水
- 采后太久：失水、风味下降、腐烂率上升

建议：
- 明确“采摘后多少小时进入预冷”
- 明确“从采摘到发货”的最长时间
- 远距离发货选耐运输成熟度，近距离可适当提高成熟度
- 要求分批次采摘，不要混采、混装

**4. 到货验收必须抽检，不能只看表面**
每批到货至少抽检：
- 坏果率：霉变、裂口、压伤、虫蛀
- 软果率：过熟、出水、塌陷
- 规格合格率：重量、果径、颜色
- 糖度：用手持糖度计抽测
- 口感：试吃脆度、甜酸比、香气、涩味
- 中心温度：冷链是否断过

建议设定红线，例如：
- 坏果率超过 3%–5% 直接拒收或重谈
- 软果率超过 5% 不建议上线
- 糖度低于标准且成熟度不足，不整批收
- 同一供应商连续两批不达标，降级或暂停

**5. 包装和物流要按品类设计**
采购再好，包装不行也会差评：
- 草莓、樱桃、蓝莓：小盒+缓冲+冰袋/保温
- 芒果、猕猴桃：单果套网+防震+催熟说明
- 柑橘、苹果：透气+抗压，避免闷坏
- 夏季高温：控温运输，减少中转时间
- 冬季防冻：保温，避免冻伤后口感发苦

同时要在详情页写清楚：
- 收货后怎么判断熟没熟
- 要不要催熟、怎么催熟
- 哪些情况算正常，哪些可售后
这样能减少“没熟就给差评”的情况。

**6. 用数据反向管理采购**
每批货都记录：
- 供应商、产地、采摘批次
- 到货坏果率、糖度、口感评分
- 售后原因：坏果、不熟、过熟、酸、没味、大小不符
- 差评关键词

然后做供应商分级：
- A级：稳定复购
- B级：可备用，但需加强抽检
- C级：只做短期促销或直接淘汰

**7. 最实用的采购动作清单**
采购前：
- 定品类标准
- 看产区、看天气、看采摘期
- 确认分级、预冷、包装、物流能力

采购中：
- 要求按成熟度分批
- 要求提供糖度和抽检
- 不混采、不混级、不压价压到供应商以次充好

到货后：
- 抽检坏果、软果、糖度、口感
- 不达标拒收或降级
- 记录批次，和售后差评关联

一句话：**线上水果的采购，不是买一批货，而是买一套稳定的标准、供应链和验收机制。** 坏果靠冷链和包装降，口感稳定靠品种、产区、成熟度和批次管理来保。
