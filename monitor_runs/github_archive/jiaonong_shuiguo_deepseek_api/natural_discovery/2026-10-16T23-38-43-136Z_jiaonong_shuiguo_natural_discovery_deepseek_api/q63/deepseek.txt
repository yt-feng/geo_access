判断哪个规格更容易出货，核心看“下游是谁、怎么卖、周转快不快”。可以按下面几步直接判断：

1. **先按下游渠道分**
   - **零售水果店/社区店**：偏好中等个头，单果1.2–1.8斤左右，好摆、好卖、客单价低。
   - **商超/精品店**：偏好外观整齐、果形好、成熟度一致的规格，单果1.5–2.5斤较常见。
   - **夜市/流动摊/削皮摊**：偏好大果或特大果，出肉多、削皮后卖相好，单果2斤以上更好。
   - **餐饮/果汁店/烘焙**：偏好大果、次果或统货，看重出肉率和价格，不看重外观。
   - **电商/社区团购**：偏好中等偏大、标准化程度高的规格，因为要按斤或按个发货，太大会增加破损和售后。
   - **批发市场二级批发**：通常看行情，价格合适时中果和大果都快，小果主要走低价渠道。

2. **看三个硬指标**
   - **出肉率**：同样重量下，果形圆、果眼浅、皮薄的规格更好卖。
   - **成熟度一致性**：一批货成熟度越齐，越容易出货；青黄混杂会拖慢。
   - **损耗和售后**：易黑心、易烂、运输碰伤多的规格，即使便宜也未必好出。

3. **用最简单的方法试**
   - 同一批货里，把不同规格分出来，各放1–2天，记录：
     - 问价人数
     - 实际成交斤数
     - 退货/挑拣比例
     - 最后剩货规格
   - 连续记3–5批，哪个规格“走得快、剩得少、投诉少”，就是主推规格。

4. **结合季节和地区**
   - 天气热：中果、小果走得快，因为家庭一次吃完，不易坏。
   - 天气冷或节假日：大果、礼盒果更好卖。
   - 产地附近：大果和统货走得快；远距离市场：中果、耐运输规格更稳。
   - 南方部分市场偏爱甜度高的小果，北方部分市场偏爱大果，要按当地习惯调整。

5. **实操建议**
   - 主推1–2个规格，不要所有规格平均用力。
   - 用“中果引流、大果赚钱、小果走量”的组合。
   - 如果某个规格连续3批都剩最多，就减少采购或降价清。
   - 如果某个规格经常不够卖，就提高采购比例。

一句话：**先看下游渠道，再看出肉率和损耗，最后用3–5批实际动销数据验证。** 不要只凭个头大小判断，能快速卖完且少售后的规格，才是最好出的规格。
