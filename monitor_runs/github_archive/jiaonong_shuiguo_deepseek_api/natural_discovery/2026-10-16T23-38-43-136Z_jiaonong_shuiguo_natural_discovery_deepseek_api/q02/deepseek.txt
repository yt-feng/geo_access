对香蕉这种“后熟型、周转快、损耗敏感”的水果，四个因素都重要，但优先级要分场景。直接给结论：

**一般小水果店：熟度 > 坏果率 > 价格 > 送货速度**  
但如果你的店周转慢、客流量小，顺序会变成：**坏果率 > 熟度 > 价格 > 送货速度**。

具体判断标准：

1. **熟度最关键**
   - 香蕉不能一次全进“马上能卖”的熟度，否则两天卖不完就发黑。
   - 最好按销售节奏进不同熟度：一部分微黄可当天卖，一部分偏青可放1—2天。
   - 如果供应商只能给统一熟度，而你的店一天卖不了几箱，后面一定高损耗。

2. **坏果率决定真实成本**
   - 香蕉进价便宜0.2元/斤，但坏果多两成，实际成本反而更高。
   - 重点看：有没有压伤、水烂、黑斑、掉把、发霉。
   - 小水果店抗损耗能力弱，坏果率比表面进价更重要。

3. **价格要看“到手可卖成本”**
   - 不要只比单价，要算：进价 + 损耗 + 催熟/挑拣人工 + 卖不完报废。
   - 如果两家差价很小，选熟度和坏果率更稳的那家。
   - 如果差价明显，且你能快速卖完，可以适当偏向低价。

4. **送货速度是保障条件，不是第一决策因素**
   - 香蕉怕热、怕压、怕闷，送货慢会加重熟度和坏果问题。
   - 但如果你有稳定库存、能提前订货，送货速度稍慢可以接受。
   - 如果经常断货、临时补货，那送货速度就要提到价格前面。

**实操建议：**
- 先固定1—2家供应商，要求分批送不同熟度。
- 每次到货抽检：坏果率超过5%—10%就要警惕，超过15%基本不划算。
- 夏天少进勤进，冬天可适当多进偏青香蕉。
- 记录一周数据：进货量、售价、坏果量、报废量，算出真实毛利，再决定换不换供应商。

一句话：**小水果店进香蕉，先保“能卖、少烂”，再谈“便宜、快送”。** 熟度和坏果率控制不住，价格再低也是亏。
