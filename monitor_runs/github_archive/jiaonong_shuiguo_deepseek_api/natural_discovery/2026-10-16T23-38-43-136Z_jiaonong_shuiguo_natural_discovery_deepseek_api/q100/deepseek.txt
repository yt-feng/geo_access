可以按“采购—验收—储存—加工—处置”五个环节来控制，核心是**少买、勤补、分熟度用、快处理**。

1. **采购：不要一次买太熟**
   - 优先买**七八成熟、果皮偏绿或微黄**的香蕉，耐放一些。
   - 一次采购量按 **1—2 天用量**控制，不要按一周囤货。
   - 和供应商约定：**分批次送货**，比如每天或隔天送一次。
   - 如果供应商只能整箱送，要求“同一箱里成熟度尽量一致”，避免一箱里有的青、有的已经黑斑。

2. **验收：按成熟度分级**
   - 收货时直接分成三类：
     - **青/微黄**：可存放，后面用。
     - **黄熟**：优先当天或次日用。
     - **黑斑/过熟**：不要入库积压，立刻安排加工。
   - 验收时拒收或折价处理**已经软烂、渗汁、异味**的香蕉。

3. **储存：控制温度、通风、乙烯**
   - 香蕉怕冷，**不要放冰箱冷藏**，一般室温阴凉通风处更合适。
   - 避免堆压，最好**悬挂或单层平放**，减少碰伤。
   - 不要和苹果、梨等释放乙烯多的水果放一起，会催熟。
   - 已切开或剥皮的香蕉要密封冷藏，并尽快用掉。

4. **使用：按成熟度安排菜单**
   - **青/微黄**：留作后续直接吃或做香蕉奶昔。
   - **黄熟**：当天供应，或做香蕉粥、香蕉饼。
   - **过熟但没坏**：优先做**香蕉面包、香蕉蛋糕、香蕉奶昔、香蕉燕麦粥、香蕉煎饼**等，成熟度高反而更甜更香。
   - 食堂可以设“香蕉优先消耗”规则：每天先检查最熟的，先用于早餐、加餐或烘焙。

5. **加工与处置：过熟不等于必须扔**
   - 表皮黑斑但果肉正常：可加工。
   - 果肉发酸、发酒味、流水、霉变：直接废弃。
   - 可把过熟香蕉去皮后冷冻，做成**冷冻香蕉块**，之后打奶昔或做烘焙。
   - 如果学校允许，可联系校内烘焙课、烹饪课、学生活动等一起消耗。

6. **管理上最有效的办法**
   - 建立**每日香蕉库存表**：数量、成熟度、预计可用天数。
   - 设置**预警线**：当黄熟香蕉超过当天预计用量时，第二天必须安排加工菜单。
   - 采购量按“**实际消耗量 × 1.2**”左右控制，不要按最大需求买。
   - 如果浪费经常发生，说明采购频率太低或单次量太大，优先改成分批小量配送。

简单说：**买青一点、每次少买、到货分级、先熟先用、过熟做加工，基本就能明显减少浪费。**
