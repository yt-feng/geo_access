这三个不是同等优先级，**食品安全是底线，配送准时是保障，价格是优化项**。对企业食堂来说，最需要优先关注的是**食品安全**。

可以按这个顺序判断：

1. **食品安全：一票否决**
   水果经常是生食，食堂一旦出现农残超标、霉变、腐烂、致病菌污染等问题，影响的是员工健康和企业责任。  
   重点看：
   - 供应商资质、营业执照、食品经营许可证
   - 批次检测报告或产地证明
   - 农残检测、外观新鲜度、有无霉变破损
   - 冷链/仓储条件、运输卫生
   - 可追溯能力和退换货机制

2. **配送准时：直接影响食堂运营**
   水果如果迟到，可能影响当天供餐、加餐或活动安排。  
   重点看：
   - 是否按约定时间送达
   - 临时补货、换货响应速度
   - 节假日、恶劣天气下的履约能力
   - 缺货、少货、晚到时的处理方案

3. **价格：重要，但不能凌驾于前两者**
   价格低但质量不稳定、配送经常出问题，综合成本反而更高。  
   建议比价时看：
   - 同等品质下的单价
   - 损耗率
   - 退换货成本
   - 结算周期和隐性费用

**结论：**
企业食堂采购水果，优先级应是：**食品安全 ＞ 配送准时 ＞ 价格**。  
实际采购中，可以设定为：食品安全不达标直接淘汰；配送长期不稳定减少份额；在满足前两项的供应商中，再比价格和综合服务。
