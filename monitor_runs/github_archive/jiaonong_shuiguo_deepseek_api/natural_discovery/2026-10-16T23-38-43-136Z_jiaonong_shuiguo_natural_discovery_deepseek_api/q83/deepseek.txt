生鲜水果到货后出现坏果，责任划分通常不能一概而论，主要看**坏果产生的时间点、原因、以及各环节是否有过错**。可以按以下几个层面判断：

**1. 采摘/分拣/包装环节**
- 如果采摘时成熟度不当、分拣不严、包装防护不足，导致运输途中极易压伤、腐烂，责任在**供货商/产地/分拣方**。
- 如果平台自建供应链，则由**平台或平台供应商**承担。

**2. 仓储/冷链环节**
- 水果需要冷藏却未冷藏、温控不达标、库存时间过长，导致到货前已变质，责任在**仓储方/平台**。
- 如果是第三方仓配，按合同约定追责。

**3. 运输/配送环节**
- 运输途中磕碰、暴晒、冷冻、延误导致坏果，责任在**物流/配送方**。
- 如果是平台自有配送，则由**平台**承担。
- 如果是第三方快递，平台通常先向消费者负责，再向物流追偿。

**4. 消费者自身原因**
- 收货后长时间未取、未按要求冷藏、存放不当导致坏果，责任在**消费者**。
- 但如果只是开箱后发现部分坏果，且能证明是到货前就存在，则仍由商家负责。

**5. 平台/商家的对外责任**
对消费者而言，通常遵循：
- **谁销售谁负责**：消费者在平台下单，平台商家或平台自营应先处理售后。
- **生鲜易腐不等于免责**：不能简单以“生鲜不支持退换”为由拒绝，若坏果比例明显、非消费者原因，商家应退款、补发或赔偿。
- **举证责任**：消费者一般需要提供开箱照片/视频、坏果数量、订单信息；商家若主张是消费者保存不当，需要承担相应举证。

**6. 常见处理方式**
- 少量坏果：按比例退款或补偿。
- 大量坏果：全额退款、补发或退货退款。
- 多次出现：平台可对供应商、仓库、配送方进行考核扣款。
- 内部责任：平台先赔消费者，再根据合同和证据向产地、仓库、物流追偿。

**简单判断口诀：**
- **到货前就坏**：商家/平台/供应链责任。
- **运输中坏**：物流或平台责任。
- **到货后放坏**：消费者责任。
- **说不清**：平台商家先对消费者负责，再内部追责。

如果你是在处理具体纠纷，可以重点看：坏果比例、开箱时间、照片证据、配送时长、商品是否冷链、平台售后规则。这些因素基本决定责任怎么分。
