单位采购水果遇到到货品质不一致，建议按下面这套流程处理，能验收、能留证、能索赔。

**一、验收前先准备**

1. 拿出合同或订单，确认约定标准：品种、规格（如单果重、果径）、等级、成熟度、产地、数量、包装、到货时间。
2. 明确验收人，最好两人以上共同验收，避免单人说了算。
3. 准备工具：电子秤、卷尺/卡尺、糖度计（如约定糖度）、拍照设备、验收单。

**二、现场验收怎么做**

1. **先看整体，再抽检**
   - 整车/整批先看有无挤压、腐烂、异味、冻伤、日灼。
   - 按比例抽检，比如每批抽 5%–10%，大货可分层抽样（上中下、里外）。
2. **对照标准逐项核**
   - 数量：过秤或点数，缺斤少两当场记录。
   - 规格：单果重、果径、色泽、成熟度是否达标。
   - 品质：腐烂率、碰伤率、虫害、病斑、空心、裂果等。
   - 包装：是否按约定分装、有无破损。
3. **分档记录**
   - 合格、不合格、可折价接收，三类分开。
   - 不合格部分单独堆放、拍照、贴标，避免混放后说不清。
4. **当场确认**
   - 验收单写清：到货时间、批次、数量、抽检结果、不合格比例、处理意见。
   - 送货人签字确认；拒签就拍照录像并让在场同事见证。

**三、品质不一致怎么处理**

1. **轻微不一致**：可协商折价接收，按不合格比例扣款。
2. **部分不合格**：合格部分正常收，不合格部分拒收或换货，写明期限。
3. **严重不一致**：整批拒收，要求补货或退款，并保留追责权利。
4. **已入库才发现**：立即封存、拍照、通知供应商，尽量当天反馈，别拖到几天后。

**四、售后和索赔要点**

1. **第一时间书面通知**：微信、邮件、函件都行，写清批次、问题、照片、诉求（换货/退款/赔偿）。
2. **给整改期限**：比如 24–48 小时内补货或退款，逾期按合同追责。
3. **留全证据链**：合同、订单、验收单、照片视频、聊天记录、称重记录、退货物流单。
4. **按合同索赔**：有约定按约定；没约定可主张退货、换货、减少价款、赔偿实际损失。
5. **供应商不配合**：先走采购平台投诉或单位内部供应商管理流程；金额大、争议大再考虑法律途径。

**五、建议写进采购合同的条款**

- 明确品质标准和验收方法（抽检比例、判定规则）。
- 约定不合格处理：折价、换货、退货、赔偿比例。
- 约定反馈时限：到货后多少小时内提出有效。
- 约定逾期补货、退款的违约责任。
- 约定争议解决方式。

**一句话原则**：当场验、当场记、当场确认；不合格单独放、拍照留证、书面通知、按合同处理。这样既不会扯皮，也方便后续售后索赔。
