可以，但要看你跟供应商的合作层级和谈判方式。水果供应商在周末促销上通常能给的支持，主要分三类：

**1. 价格支持**
- 最常见的是“促销专供价”或“周末特价”，比日常进货价低几个点到十几个点不等，具体看单品和采购量。
- 也可能是“返利形式”：平时正常价进货，周末走量后按销量返点。
- 对时令、易损耗、供应商手里库存多的品项，压价空间更大；对紧俏或进口单品，空间小。

**2. 物料支持**
- 果园/品牌方的海报、价签、吊旗、围挡、展架、试吃盒、包装袋等。
- 有些供应商愿意提供陈列筐、促销台、冷链周转箱短期借用。
- 品牌水果（如某些产地品牌、进口品牌）物料支持通常更规范，杂货类供应商则偏灵活。

**3. 其他支持**
- 账期放宽：周末促销压货，允许延后几天结算。
- 损耗分担：约定促销期内坏果按比例补货或折价。
- 联合推广：供应商出人做试吃、驻场，或共同投本地社群/朋友圈广告。

**能不能拿到，关键看这几点：**
- 你的采购量是否稳定、是否是他的重点客户；
- 促销单品是不是他主推或想清库存的；
- 你是否愿意帮他做品牌露出、销量数据反馈；
- 谈判时是否把“周末走量”作为筹码，而不是只哭穷要低价。

**实操建议：**
提前3-5天跟供应商谈，明确说清：促销时间、主推单品、预计采购量、需要什么支持（价格/物料/账期/损耗）。最好一次谈成一个“周末促销包”，而不是零散要。第一次合作可以先小批量试，用销量数据换下次更大支持。

一句话：能，但支持力度取决于你的采购分量和谈判筹码，不是所有供应商都会主动给。
