建议优先卖整果，切果作为补充，而不是二选一。判断逻辑如下：

**优先整果更稳的原因**
1. **损耗更低**：菠萝整果耐放，切好后保质期短、氧化出水、易污染，报损率通常明显更高。
2. **毛利更可控**：整果按个/斤卖，定价简单；切果要覆盖人工、包材、损耗，定价低了不赚钱，定价高了顾客不买。
3. **顾客教育成本低**：很多家庭习惯买整果回家自己削，尤其价格敏感型客群。
4. **采购和库存简单**：整果可堆头、可促销、可放常温/冷藏，周转压力小。

**但切果也有明确价值**
- 适合**即时消费、办公室、单身/小家庭、不会削皮或嫌麻烦**的顾客。
- 能提升客单价和冲动购买，尤其在**入口、收银台、水果区端头**。
- 可以消化外观稍差但内部完好的果，降低整果报损。

**更推荐的做法：整果为主，切果为辅**
- 整果占菠萝陈列和库存的大头，做正常价和促销价。
- 切果只做**小份、当日现切、当日清**，比如盒装/杯装，控制在半天到一天内售完。
- 切果优先用**成熟度高、马上要软熟或外观不完美**的果，不要用最好的整果去切。
- 如果门店客流小、没有稳定现切条件，**不要强推切果**，否则损耗会吃掉利润。

**简单决策标准**
- 客流大、年轻客群多、有现切操作间：整果 + 切果并行。
- 社区店、中老年客群多、人手紧：以整果为主，切果少量试。
- 高端/便利型门店：切果可以占比更高，但必须小份、勤切、严控时间。

一句话：**整果是基本盘，切果是增量；先保整果周转和毛利，再用切果做便利和冲动消费。**
