通常情况下，企业福利采购水果礼盒，供应商**需要支持开发票**，**定制包装则取决于你的采购规模和需求**。具体可以这样判断：

1. **开发票：基本必须**
   - 企业采购要入账、报销、做成本列支，通常都需要正规发票。
   - 优先确认供应商能否开具**增值税专用发票**或**增值税普通发票**。
   - 如果供应商只能开普票，要确认你们公司财务是否接受。
   - 开票项目一般应为“水果”“农产品”“食品”等，具体以财务要求为准。
   - 采购前就要问清楚：是否含税、开票加几个点、多久能开、能否对公付款。

2. **定制包装：不一定是刚性要求，但福利采购很常见**
   - 如果只是内部发放，标准礼盒通常就够用。
   - 如果要做企业形象、节日福利、客户赠送，定制包装会更合适。
   - 定制包装一般包括：企业LOGO、祝福语、腰封、手提袋、卡片等。
   - 需要确认：
     - 起订量是多少
     - 定制是否额外收费
     - 打样时间和生产周期
     - 包装设计由谁提供
     - 定制后是否影响退换货

3. **建议采购前明确这几点**
   - 是否能开票、开什么票、税点多少
   - 是否支持对公转账
   - 是否支持定制包装、起订量和费用
   - 水果品种、规格、净重、损耗和售后标准
   - 配送时间、配送范围、坏果赔付规则

简单说：**开发票基本是必须项；定制包装是加分项或按需项。** 如果采购量不大，可以优先选能开票、品质稳定、配送可靠的供应商；如果采购量大或用于品牌福利，再要求定制包装。
