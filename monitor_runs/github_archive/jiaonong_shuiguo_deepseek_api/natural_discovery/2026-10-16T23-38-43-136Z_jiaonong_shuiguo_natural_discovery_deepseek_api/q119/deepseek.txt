水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格高不高”，而是那些会直接影响损耗、现金流和复购的细节。挑几个最关键的：

**1. 只问“今天多少钱”，不问“到货合格率”**
很多供应商报价低，但到货后次果、烂果、规格不达标比例高。真正要问的是：  
- 到货合格率大概多少？  
- 次果怎么赔、怎么补？  
- 是按整车/整批结算，还是按实际合格斤两结算？

**2. 忽视“稳定供货能力”，只看单次货源**
今天有货、明天断货的供应商，价格再低也不能长期合作。要确认：  
- 这个单品一年能稳定供几个月？  
- 旺季、雨季、节假日会不会断供？  
- 有没有备选产地或备用供应商？

**3. 不重视“采后处理”和“冷链”**
水果损耗大头常在采后。要问清楚：  
- 是否预冷、分级、打冷？  
- 运输是常温、冷藏还是冷链？  
- 从产地到你仓库大概多久？  
同样一批货，采后处理差，到你手里可能多烂 20%。

**4. 忽略“规格一致性”**
做门店或社区团购，最怕这批大、下批小，这批甜、下批酸。要固定：  
- 果径、重量、糖度、成熟度标准；  
- 包装规格、每箱净重；  
- 允许的误差范围。  
没有标准，就会不断退货、客诉、压库存。

**5. 不看“账期和结算方式”**
水果现金流快，账期很关键。要明确：  
- 现结、周结还是月结？  
- 押金、保证金怎么算？  
- 出现质量争议时，货款怎么扣？  
很多小生意不是没利润，是被账期和坏账拖死。

**6. 忽视“售后响应速度”**
出问题不可怕，怕的是没人管。合作前最好确认：  
- 发现问题几小时内响应？  
- 补货、退款、换货流程是什么？  
- 谁承担运费和损耗？  
最好写进简单协议或聊天记录里，别只靠口头。

**7. 只合作一家，没有备胎**
长期稳定不能把命脉交给一个供应商。建议：  
- 主力供应商 1 家；  
- 备用供应商 1—2 家；  
- 同一单品至少掌握 2 个产地或渠道。  
这样对方涨价、断货、质量波动时，你有腾挪空间。

**8. 不算“综合成本”，只算“进货价”**
低价货可能带来更高损耗、更多客诉、更慢周转。真正要比的是：  
**综合成本 = 进货价 + 损耗 + 运费 + 退换货 + 客诉损失 + 资金占用。**  
有时候贵 5% 的货，反而更赚钱。

**9. 不关注供应商的“下游客户结构”**
如果他把好货都给了大客户，给你的常是尾货，长期一定不稳定。可以侧面了解：  
- 他主要供超市、批发市场还是团购？  
- 你在他的客户里算什么级别？  
- 好货优先给谁？

**10. 忽略“季节和产地切换”**
水果有周期。要提前问：  
- 这个产地结束后，下一站是哪里？  
- 切换期品质会不会波动？  
- 价格大概怎么走？  
提前规划，才不会一到换季就断货或翻车。

**一句话总结：**  
选水果供应商，别只盯着“今天便宜多少”，要盯 **合格率、稳定性、采后冷链、规格标准、账期、售后和备选渠道**。长期稳定，靠的是可预期，不是单次低价。
