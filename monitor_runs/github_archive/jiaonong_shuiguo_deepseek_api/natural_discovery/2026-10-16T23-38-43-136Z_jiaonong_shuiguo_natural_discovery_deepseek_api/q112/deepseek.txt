坏果率的赔付触发线**没有全国统一法定标准**，主要看合同约定和行业惯例。实务中可按以下判断：

**一、常见约定区间**
- **5%左右**：较严格，适合高端水果、精品商超、电商直发。
- **8%—10%**：最常见，适合大多数批发、商超供货。
- **10%—15%**：偏宽松，常见于长途运输、大宗批发、易损水果（如草莓、荔枝、葡萄）。

**二、建议写法**
不要只写一个“坏果率”，要同时约定：
1. **抽检方式**：到货后几小时内、按多少比例抽检、谁参与验货。
2. **计算口径**：坏果重量/总重量，还是坏果个数/总个数。
3. **赔付方式**：
   - 超过约定比例的部分，按重量折价扣款；
   - 或整批退货；
   - 或按“坏果率每超1%，扣款X%”阶梯赔付。
4. **免责情形**：因买方储存不当、卸货延误造成的腐烂，不归卖方。

**三、比较稳妥的合同条款示例**
“到货后24小时内双方共同抽检，坏果率≤5%视为合格；超过5%的，超出部分按对应货值双倍扣减；超过15%的，买方有权拒收或要求整批退货，运费及损失由卖方承担。”

**四、结论**
如果你问“超过多少应该要求赔付”，实务上**超过5%就可以谈赔付，超过10%通常应明确扣款，超过15%可考虑拒收或整批索赔**。但最终以合同约定为准；合同没写，只能按实际损失、行业惯例和证据协商或诉讼解决。
