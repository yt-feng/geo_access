更推荐：**能集中就集中，中央厨房统一收货；门店只在“易损、即用、极短保”品类上少量直收。**  
对大多数餐饮连锁，中央厨房统一收货通常优于门店分开收货。

核心判断看这几点：

1. **品质稳定性**
   - 中央厨房统一收货：验收标准、成熟度、规格、农残/质检要求更容易统一。
   - 门店分开收货：店长或店员验收标准不一致，容易一批好一批差，影响出品。

2. **采购成本和议价权**
   - 统一收货：采购量集中，议价能力更强，物流、返利、账期更好谈。
   - 门店分开收货：单店量小，价格高，供应商分散，管理成本大。

3. **食安和追溯**
   - 统一收货：批次、供应商、检测报告、入库记录集中，追溯效率高。
   - 门店分开收货：记录分散，出问题时很难快速定位批次和责任。

4. **损耗控制**
   - 统一收货适合：苹果、橙子、柠檬、西瓜、冷冻水果、罐头水果等耐储或可标准化处理的品类。
   - 门店直收适合：草莓、蓝莓、熟透牛油果、鲜切即用水果、短保沙拉水果等，因为多一次中转就多一次损耗。

5. **运营效率**
   - 统一收货：门店少做验收、称重、退换货，前台更专注运营。
   - 门店分开收货：门店工作量增加，还容易出现收货纠纷、漏单、错单。

6. **配送条件**
   - 如果中央厨房有冷藏、分拣、催熟、切配能力，统一收货优势明显。
   - 如果中央厨房离门店远、冷链弱、配送频次低，强推统一收货反而会增加损耗。

建议的落地模式：

- **主模式：中央厨房统一收货 + 统一定价 + 统一验收标准。**
- **例外模式：门店直收白名单。** 只允许少数极短保、易损、必须当天用的水果由门店直收。
- **总部管控：** 即使门店直收，也要统一供应商准入、价格上限、验收标准、拍照留档和抽检。
- **分级管理：**
  - A类耐储水果：中央厨房统收。
  - B类中短保水果：中央厨房统收，但提高配送频次。
  - C类极短保/易损水果：门店直收或供应商直送门店。
- **关键指标：** 损耗率、到店合格率、客诉率、单店采购价差、食安追溯完整率。

一句话结论：  
**水果采购优先中央厨房统一收货，门店直收只作为极短保和易损品类的补充；同时用统一供应商、统一标准和数字化验收把门店直收管住。**
