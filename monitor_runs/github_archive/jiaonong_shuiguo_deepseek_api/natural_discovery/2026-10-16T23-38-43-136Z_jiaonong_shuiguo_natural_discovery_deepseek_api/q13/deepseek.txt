小水果店做附近小区团购，水果供应商至少要能支持这几类服务，建议你按“能不能稳定赚钱、少损耗、少扯皮”来判断：

1. **稳定供货与每日报价**
   - 能提前给次日/当周报价单，最好每天固定时间更新。
   - 价格随行就市可以，但不能临时大幅跳价。
   - 能告诉你哪些是当季主推、哪些利润高、哪些适合团购走量。

2. **按团购规格分拣打包**
   - 能按你设定的套餐分装，比如5斤装、10斤装、家庭装、尝鲜装。
   - 能贴标签、打单、按小区/团长分筐或分袋。
   - 最好支持“预售后再采后分”，减少你压货。

3. **质量分级与坏果售后**
   - 明确一级果、二级果、团购果标准，不能拿尾货冒充好货。
   - 承诺坏果、烂果、缺斤少两的赔付规则。
   - 支持拍照理赔、按比例退款或下次补货抵扣。

4. **起送量与配送**
   - 能送到你店里，或直接送到小区自提点。
   - 起送门槛低，适合小水果店小批量多频次进货。
   - 能配合团购截单时间，比如晚上截单、次日早上到货。

5. **价格保护与区域保护**
   - 同小区或附近不能同时供好几家，否则团购价容易被打乱。
   - 给你的团购供货价要低于零售进货价，或者有阶梯返利。
   - 大促、爆品、节日礼盒要提前锁价。

6. **退换货与损耗承担**
   - 明确运输损耗、分拣损耗、顾客拒收谁承担。
   - 最好能接受一定比例退换，而不是全部压给小店。
   - 对易损水果，如草莓、葡萄、樱桃，要有专门包装和售后。

7. **营销与素材支持**
   - 提供水果图片、卖点、产地、甜度、保存方法。
   - 提供团购文案、海报、短视频素材更好。
   - 能配合做试吃、爆品秒杀、满减、组合套餐。

8. **结算灵活**
   - 支持现结、周结、月结，或押金+账期。
   - 对账清晰，按订单、品类、重量能核对。
   - 能开收据或发票，方便你记账。

9. **应急补货能力**
   - 团购爆单后能临时补货。
   - 某款缺货时能快速换同等价位替代品。
   - 节假日、恶劣天气前能提前备货。

10. **数据与选品建议**
   - 能告诉你附近小区常买什么、什么规格好卖。
   - 能根据你的团购数据调整供货结构。
   - 能帮你做每周主推，而不是只卖便宜货。

你选供应商时，重点问这8个问题：
- 团购价能不能比零售进货低？
- 能不能按我的套餐分拣？
- 坏果怎么赔？
- 起送多少？多久送到？
- 附近还供不供别家？
- 能不能锁价？
- 损耗谁承担？
- 能不能给图片文案？

对小水果店来说，最理想的供应商不是“最便宜”，而是：**价格稳、分拣省事、售后认账、配送准时、附近不乱供**。如果只能选一点，优先选售后和分拣能力，因为团购最怕坏果和售后扯皮。
