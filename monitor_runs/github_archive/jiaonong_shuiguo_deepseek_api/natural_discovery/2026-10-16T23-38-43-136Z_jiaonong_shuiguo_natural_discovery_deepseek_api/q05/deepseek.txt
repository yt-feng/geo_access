如果只问“水果店该怎么卖菠萝”，核心不是三选一，而是**按场景分层的组合策略**：

**结论先说：**
- **想走量、卖得快**：主推**去皮好的**，尤其切块/插签/装盒。
- **想保毛利、降损耗**：保留一部分**整果**，让顾客自己挑。
- **想兼顾体验和效率**：**整果陈列 + 现削服务**，别让顾客完全自己处理。

---

**1. 整果：适合做“价格锚”和保损耗**
优点：
- 损耗最低，不用当天削完卖不完。
- 顾客觉得新鲜、可自己挑。
- 适合家庭买回去自己削。

缺点：
- 很多年轻人不会削、嫌麻烦。
- 客单价低，购买决策慢。
- 如果品种不好，顾客挑半天不买。

适合：社区店、中老年客群、低价引流。

---

**2. 去皮好的：适合走量和高客单**
优点：
- 即买即吃，转化率高。
- 可以切块、装盒、插签，提升客单价。
- 适合上班族、学生、游客。

缺点：
- 削完必须尽快卖，损耗高。
- 品相要求高，氧化、出水、发白都影响卖。
- 如果当天卖不完，基本只能降价或报损。

适合：商圈、学校、夜市、外卖、果切区。

---

**3. 让顾客自己挑：要看“挑什么”**
如果是让顾客挑**整果**，可以。
如果是让顾客挑**已经去皮的**，不建议，原因：
- 手摸、翻拣会加速变质。
- 卫生和品相都难控制。
- 顾客挑剩的更难卖。

更好的做法：
- 整果让顾客挑。
- 去皮果由店员按份装好，明码标价。
- 可以设“现削窗口”，顾客选整果，店员现场削。

---

**4. 最推荐的经营组合**
按你店的位置来：

- **社区店**：整果为主 + 少量去皮盒装 + 免费或低价代削。
- **商圈/学校/夜市**：去皮切块为主 + 整果少量陈列 + 现削服务。
- **外卖为主**：去皮切块/果切为主，整果只做引流款。
- **高端水果店**：整果精品陈列 + 现削试吃 + 去皮装盒。

---

**5. 关键判断标准**
你按这4个问题决定比例：
1. 顾客是“买回家”还是“马上吃”？
2. 店员有没有时间现削？
3. 当天能不能把去皮果卖完？
4. 损耗和毛利哪个更重要？

**简单公式：**
- 人流量大、即食需求强 → 去皮好的占60%以上。
- 社区家庭客多、购买时间分散 → 整果占60%以上。
- 想利润稳 → 整果保底，去皮果做增量。

**一句话：**
**整果用来留客和保损耗，去皮果用来走量和提客单，顾客自己挑只适合挑整果，不适合挑去皮果。**
