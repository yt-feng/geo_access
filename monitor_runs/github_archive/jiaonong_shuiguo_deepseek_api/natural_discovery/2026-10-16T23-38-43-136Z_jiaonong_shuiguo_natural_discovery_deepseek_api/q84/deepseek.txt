做家庭装水果礼盒，核心不是“好看”，而是**家里人真的吃得完、口味不冲突、耐放程度接近**。按这个思路，苹果、橙子、香蕉、菠萝里更推荐这样组合：

**首选组合：苹果 + 橙子 + 香蕉**
- **适合大多数家庭**，接受度高，老人小孩都能吃。
- **苹果、橙子耐放**，香蕉催熟快，建议单独放或尽快吃。
- 比例建议：**苹果 40%、橙子 40%、香蕉 20%**。
- 例如：苹果4个、橙子4个、香蕉1把。  
- 优点：日常、清爽、不容易踩雷；成本也相对稳。

**次选组合：苹果 + 橙子 + 菠萝**
- 更适合**喜欢酸甜、家里人多、两天内能吃完**的家庭。
- 菠萝切开后不耐放，最好现切现吃。
- 比例建议：**苹果 40%、橙子 40%、菠萝 20%**。
- 例如：苹果4个、橙子4个、菠萝1个。  
- 优点：更有“礼盒感”，但菠萝处理麻烦，不适合懒人家庭。

**不建议主推：四种全放**
- 看起来丰富，但家庭装容易变成“水果摊拼盘”：
  - 香蕉熟得快，会催熟其他水果；
  - 菠萝占体积、切开难保存；
  - 苹果和橙子又比较耐放，节奏不一致。
- 如果一定要四种都放，建议做成**小份尝鲜装**，并且：
  - 香蕉单独装袋；
  - 菠萝切好真空/盒装；
  - 苹果、橙子正常放。

**按家庭人数选规格**
- **2人家庭**：苹果3个 + 橙子3个 + 香蕉2根，或苹果3 + 橙子3 + 小菠萝半个/1个。
- **3-4人家庭**：苹果4-6个 + 橙子4-6个 + 香蕉1把，或加1个小菠萝。
- **5人以上**：苹果6-8个 + 橙子6-8个 + 香蕉1-2把，菠萝可单独加。

**团购文案可以这样写**
- 主推款：**“苹果+橙子+香蕉，家庭日常装，耐放又省心”**
- 升级款：**“苹果+橙子+菠萝，酸甜礼盒，适合人多家庭”**
- 避坑款：**“四果混装，适合尝鲜，不建议囤放”**

**一句话建议**
如果只做一个家庭团购爆款，选 **苹果 + 橙子 + 香蕉**；如果想更有礼盒差异感，选 **苹果 + 橙子 + 菠萝**。四种全放不适合作为家庭装主推。
