酒店采购水果盘原料时，供应商应保证的规格和外观标准，建议在采购合同或验收标准中写清楚。可按以下维度要求：

**一、规格标准**
1. **品种与等级**：明确具体品种、产地或等级要求，如“一级果”“精品果”，避免以次充好。
2. **单果重量/尺寸**：按品种规定单果克重或直径范围，例如苹果直径80–85mm、橙子单果200–250g。
3. **成熟度**：要求适合即食或短存，通常7–8成熟，避免过生或过熟。
4. **数量与净重**：按箱/件标明净重、个数、允许误差，如每箱净重误差不超过±2%。
5. **可食率**：对西瓜、菠萝、哈密瓜等，可约定可食率下限。

**二、外观标准**
1. **新鲜度**：果蒂鲜绿、果皮饱满有光泽，无萎蔫、皱缩、发软。
2. **完整性**：无裂口、破损、虫蛀、病斑、机械伤。
3. **色泽**：具有该品种成熟时应有的色泽，着色均匀。
4. **形状**：果形端正，无明显畸形、偏心、双果等。
5. **洁净度**：无泥土、药斑、污物、异味，必要时要求预清洗。
6. **大小均匀度**：同批次果个大小、色泽基本一致，便于摆盘美观。

**三、食品安全与合规**
1. 提供农残检测合格证明或承诺书。
2. 符合国家食品安全标准，无腐烂、霉变、异味。
3. 预切水果还应符合即食果蔬卫生要求，冷链温度通常0–4℃。
4. 包装材料清洁、无毒、无异味，标签信息完整。

**四、验收与退换**
1. 到货抽检比例，如每批抽检5%–10%。
2. 不合格判定：腐烂、虫害、严重碰伤、规格不符比例超过约定值，可整批拒收或按比例扣款。
3. 约定退换货时限，如到货2小时内提出，供应商24小时内补换。
4. 冷链到货温度记录，如冷藏水果到货中心温度不高于8℃（具体按品种定）。

**五、建议写入采购单的简版条款**
“供应商须保证水果为新鲜一级果，无腐烂、虫蛀、病斑、机械伤及异味；单果规格、成熟度、色泽符合约定标准；同批次大小均匀；提供农残合格证明；到货抽检不合格率超过5%时，酒店有权拒收或要求退换。”
