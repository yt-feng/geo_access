结论:**优先找本地“餐饮配送型”水果供应商**，而不是水果店、批发市场散户或生鲜电商。最省心的组合通常是:**本地B2B生鲜配送商 + 一个备用档口/批发商**。

下面按省心程度和适用情况给你判断标准。

**1. 最省心:本地B2B生鲜/餐饮配送商**
适合:每天用量小、品类固定、不想自己采购。
优点:能每天送、按订单配、可开发票、售后相对明确;通常还能顺带送蔬菜、鸡蛋等。
缺点:单价可能比批发市场高5%-15%,起送门槛常见100-300元。
判断标准:
- 是否支持“每日固定时间配送”
- 是否接受小单/混搭
- 缺货、坏果是否当天补或退款
- 是否可月结
- 能否固定品项和规格

**2. 次省心:本地水果批发市场里的固定档口**
适合:你店附近有批发市场，且能接受自己或员工早起取货。
优点:价格低、品类灵活。
缺点:需要人每天去、品质不稳定、售后麻烦。
省心做法:固定一家档口，加微信，让它按你的标准留货，你每天固定时间去拿。不要每天换摊。

**3. 可考虑:水果店/社区团购长期合作**
适合:量非常小，比如每天几斤。
优点:近、灵活。
缺点:单价高，配送和开票不一定规范。
判断标准:能否每天按你要求的时间送到店，而不是你去拿。

**4. 不建议作为主供应商**
- 生鲜电商平台:价格波动大，小单配送费高，售后响应慢。
- 流动摊贩/临时批发:品质和供货不稳定，食品安全追溯难。
- 多个小供应商同时供:对账和沟通成本高。

**实操建议**
1. 先定需求:每天用量、常用品类、可接受单价、送达时间、是否需要发票。
2. 找3家本地餐饮配送商比价，要求试送3天。
3. 试送期重点看:准时率、坏果率、缺货处理、对账是否清楚。
4. 选定1家主供 + 1家备用，避免断供。
5. 约定固定品项和验收标准，比如“苹果直径80mm以上，坏果超过5%整批退换”。
6. 尽量月结，保留每次送货单和验收记录。

**一句话选择**
- 想最省心:选本地餐饮生鲜配送商，接受略高单价。
- 想省钱且有人手:选批发市场固定档口。
- 量特别小:找附近水果店长期合作，但要求送到店。
