# 超市采购水果农残抽检，提前应向供应商索取这些资料

## 一、核心必备资料（重点）

1. **农产品质量安全承诺达标合格证**
   - 这是最基础的凭证，证明供应商承诺产品符合农残等安全标准。
   - 要求：与当批次货物对应，有供应商名称、产品名称、数量、开具日期。

2. **第三方检测报告（农残）**
   - 必须是**有资质（CMA/CNAS）的检测机构**出具。
   - 关键看：
     - 报告是否覆盖**当批次或近期批次**（一般要求同批次，或3个月内同产地同品种）
     - 检测项目是否包含当地常检的农残指标（如有机磷、氨基甲酸酯类等）
     - 结论是否为"合格"
   - 注意：报告和货物要对得上，避免"一张报告用一年"。

3. **产地证明 / 供货凭证**
   - 证明水果来源可追溯：产地、种植户/合作社、收购记录。
   - 便于抽检不合格时溯源。

## 二、加分/风控资料

4. **供应商资质**
   - 营业执照、食品经营许可证（如适用）、种植/加工相关许可。

5. **进货查验记录**
   - 供应商自己的进货台账，证明其上游可控。

6. **自检或快检记录**
   - 有条件的供应商提供的农残快检结果，作为辅助参考。

7. **包装标识信息**
   - 品名、产地、生产日期/采摘日期、保质期、供应商联系方式。

## 三、实操建议（可直接执行）

- **签订采购合同时**，写明：供应商须随货提供合格证+对应批次检测报告，否则可拒收。
- **每批次留档**：把合格证、报告、送货单按批次归档，抽检时可快速调取。
- **定期换报告**：要求检测报告与批次对应，不接受长期复用。
- **重点品类加严**：叶菜、草莓、豇豆等高风险品类，要求逐批检测或提高抽检频次。
- **抽检不合格时**：凭留档资料向供应商追责，并可要求其承担相应损失。

## 四、一句话总结

> 最关键是：**当批次对应的《承诺达标合格证》+ 有资质机构出具的农残检测报告 + 可溯源的产地/供货凭证**，三者配套、批次对得上，才能有效应对抽检和后续追责。
