超市采购水果时，供应商通常需要提供以下几类证明和检测报告。具体取决于水果品类、超市自身风控要求以及当地市场监管规定：

**一、主体资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视经营形态而定）
- 若为进口水果，还需进出口经营权相关资质

**二、进货凭证类**
- 供货凭证/销售单：载明品名、数量、单价、日期、供货方与采购方信息
- 增值税发票或合规收据
- 若是从批发市场采购，需提供批发市场的进货凭证或交易单据

**三、检测报告类**
- **农残检测报告**：这是最核心的一项，通常要求符合 GB 2763《食品中农药最大残留限量》。可以是供应商自检报告，也可以是第三方检测机构出具的报告。
- **产地证明或合格证**：部分农产品需附具产地证明、合格证，或食用农产品达标合格证。
- **重金属、真菌毒素检测**：针对特定品类（如某些浆果、干果）可能要求。
- **进口水果**：需提供入境货物检验检疫证明、海关报关单。

**四、追溯与承诺类**
- 食用农产品进货查验记录
- 质量安全承诺书或供货协议中的质量条款
- 可追溯信息（产地、批次、采摘/加工日期）

**五、实操建议**
1. 优先要求供应商提供**近批次**的农残检测报告，报告日期与供货批次对应，避免“一份报告用一年”。
2. 对高风险品类（叶菜、草莓、葡萄等）可要求每批次检测或抽检。
3. 保留进货台账，至少保存至产品保质期满后6个月，无明确保质期的不少于2年。
4. 若供应商无法提供检测报告，超市可自行快检或委托第三方抽检，并将结果存档。

不同地区市场监管部门对食用农产品进货查验的具体要求可能略有差异，建议以当地最新规定和超市内部采购制度为准。
