茶饮店水果到货不合格，补货约定要抓住一个核心：**先保营业，再谈责任**。不能只靠口头“下次补”，否则容易断货、扯皮。

建议按下面方式约定：

1. **到货验收当场定级**
   - 收货时30分钟内完成抽检：烂果、压伤、异味、成熟度不合格、重量不足分别记录。
   - 拍照/视频留证：整箱、问题果、快递单/送货单、时间水印。
   - 验收单写明：品名、规格、数量、不合格数量、处理方式。

2. **补货分“紧急补”和“常规补”**
   - **紧急补货**：影响当天/次日营业的，供应商须在约定时间内送到，例如：
     - 同城：2—4小时内送达；
     - 外地：次日营业前送达；
     - 否则同意茶饮店自行采购替代，差价由供应商承担。
   - **常规补货**：不影响当天营业的，可随下一批次补，但必须写清到货日期。

3. **补货不能只补“数量”，要补“可用量”**
   - 不合格水果按实际不可用数量补，不是按到货总数量补。
   - 例如到货100斤，挑出30斤不能用，应补30斤合格果，而不是补100斤再让门店二次分拣。
   - 若损耗率高，约定损耗上限，例如单批次不合格率超过5%即整批退换。

4. **写清补货时效和违约责任**
   - 供应商未按时补货，门店有权自行采购，差价、运费由供应商承担。
   - 因断货导致门店临时下架产品，可约定按实际损失或固定金额扣款。
   - 多次延迟可约定：第一次警告，第二次扣款，第三次可终止合作。

5. **付款方式要卡住主动权**
   - 不建议全款预付。
   - 可约定：验收合格后付70%，补货完成后付尾款；
   - 或月结，但合同中写明不合格批次可暂扣对应货款。
   - 这样供应商更愿意及时补货。

6. **合同/订单里直接写模板**
   可以写成：
   > “乙方交付水果经甲方验收不合格的，乙方应在影响甲方营业时于___小时内补足合格同规格产品；不影响营业的，应于___年___月___日前补足。逾期未补，甲方有权自行采购替代，产生的差价、运费及营业损失由乙方承担。不合格批次货款甲方有权暂扣，待补货验收合格后支付。”

7. **日常操作建议**
   - 固定1—2家备用供应商，避免一家断货就停摆。
   - 门店常备少量冷冻果泥/罐头作为应急替代。
   - 每次到货都按同一张验收表记录，方便月底对账和索赔。

简单说：**紧急补货写时效，常规补货写日期；补可用量，不补总数；逾期可自采，差价供应商担；货款留尾款或暂扣。** 这样既不影响营业，也能把责任压给供应商。
