旺季断货的核心风险通常不在“供应商有没有货”，而在**优先级、锁价、锁量、违约成本**这四件事上。和供应商谈之前，建议按下面几类问题逐条问清，最好落到书面或聊天记录里。

**一、货源与产能**
1. 旺季期间你每天/每周能稳定给我多少量？这个量是承诺量还是预估量？
2. 你主要从哪些产地/基地拿货？如果主产地受灾或减产，备选货源在哪？
3. 同一单品你有几个供货渠道？断了一个能不能顶上？
4. 旺季你最紧张的是哪几个品？哪些品我别指望你保量？

**二、锁量、锁价与优先级**
5. 能不能提前签旺季供货协议，约定保底量和最高价？
6. 价格随行就市，还是可以锁一个浮动区间？涨跌规则是什么？
7. 如果市场缺货涨价，你优先保老客户还是价高者？我在你的客户里排第几？
8. 我提前下订单，你能不能给我留货？留货要付定金吗？

**三、订单与交付**
9. 每天最晚几点前下单，第二天能到？临时加单接不接？
10. 配送是我自提还是你送？运费、损耗谁承担？
11. 到货时间能不能固定？早市和晚市分别怎么保障？
12. 缺货时提前多久通知我？有没有替代品推荐？

**四、品质与验收**
13. 等级标准怎么定？大小、糖度、成熟度、外观按什么验收？
14. 坏果、烂果、短斤少两怎么赔？是补货还是扣款？
15. 旺季品质会不会下降？如果降级，价格怎么调？

**五、结算与风险**
16. 结算是现结、周结还是月结？旺季要不要预付定金？
17. 如果我临时取消订单，违约金怎么算？你断供或迟交，怎么赔？
18. 价格波动超过多少，可以重新谈价？谈不拢怎么办？
19. 能不能签个简单协议，把保量、锁价、违约、验收写进去？

**六、备选与底线**
20. 如果我这边销量突然翻倍，你能不能临时加量？加量部分价格怎么算？
21. 你有没有推荐的同行或二级批发商，万一你这边断了，我能找谁应急？
22. 旺季前我要提前多久备货、打款、确认订单？

**谈判时重点抓三件事：**
- **保底量**：写清每天/每周最低供多少。
- **锁价或限价**：至少约定涨价上限和调价提前通知时间。
- **违约条款**：他断供怎么赔，你临时减量怎么算，避免口头承诺。

另外，别只谈一家。旺季至少准备**一个主供应商 + 一个备选供应商**，哪怕备选价格稍高，也能在断货时救急。自己店里也要对耐储存的单品提前做安全库存，比如苹果、橙子、西瓜等，能压货的适当提前备。
