先给结论：**最该先问配送，其次售后，最后才是价格。**

原因是团购团长的核心风险不在“进货贵一点”，而在**履约翻车**。水果是高频、易损、时效敏感品类，一旦配送不稳，售后和价格优势都会被吃掉。

更具体地说，优先级应该是：

1. **配送：先问清楚，决定你能不能接单**
   - 能不能按你要求的时间送到？比如上午到、下午到、固定时段到。
   - 送到哪里？送到小区、团长自提点，还是只到城市仓/批发市场？
   - 谁卸货？团长自己搬、司机搬，还是加钱？
   - 破损、压伤、晚到怎么算？是否当场补送？
   - 旺季、节假日、恶劣天气能不能保供？
   - 起送量、配送费、是否拼车、临时加单接不接？
   配送不稳，你会在群里被骂，而不是供应商被骂。

2. **售后：决定你能不能长期做**
   - 坏果、烂果、少斤两、规格不符怎么赔？
   - 是拍照即赔，还是要退回？退回运费谁出？
   - 赔付时效多久？当天、次日还是拖一周？
   - 是补货、退款还是抵扣下次货款？
   - 售后响应是找业务员、客服还是群内对接？
   水果售后不可避免，关键不是“有没有问题”，而是**出问题后谁承担、多快承担**。

3. **价格：重要，但不能先问**
   - 价格低但配送差、售后赖，最后你赚的差价不够赔口碑。
   - 比价时要问：是否含运费、含税、含损耗、含售后？
   - 要求看同规格、同等级、同时间的报价，不然低价可能是次果。
   - 最好先小批量试单，再谈长期价和账期。

一句话判断标准：

- **配送决定你能不能卖。**
- **售后决定你能不能复购。**
- **价格决定你赚多少。**

所以选供应商时，建议顺序是：  
**先筛配送能力 → 再压售后条款 → 最后谈价格和账期。**  
如果只能问一个问题，先问：**“出问题怎么赔、多久赔、谁来处理？”** 因为这背后同时暴露了配送和售后的真实水平。
