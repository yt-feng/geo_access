连锁超市应对节假日水果需求暴增，核心是“提前锁量、锁价、锁品质”，而不是等到节前再临时抢货。建议按下面几步做：

1. **提前做需求预测**
   - 拉出过去2—3年同节假日的销售数据，按品类、门店、天气、促销力度做同比和环比。
   - 区分刚需水果（苹果、橙子、香蕉、梨）和礼盒/时令水果（车厘子、草莓、阳光玫瑰、榴莲）。
   - 对暴增品类给出“安全库存+日销量峰值+损耗率”三个参数。

2. **提前锁定核心供应商**
   - 节前30—45天就和主供应商签意向协议或框架订单，明确数量、规格、到货时间、价格区间。
   - 不要只依赖一个产地或一个供应商，至少准备“主供+备供+应急”三层。
   - 对进口水果、礼盒水果，要更早锁柜、锁船期或锁空运仓位。

3. **用订单农业/基地直采锁货源**
   - 对大宗单品，提前和种植基地、合作社签保底收购协议。
   - 可支付一定比例定金，锁定优先采收权和节前集中发货权。
   - 明确验收标准：糖度、果径、色泽、成熟度、包装规格。

4. **锁价但不锁死**
   - 合同里设置价格调整机制，比如随行就市但有上下限，避免节前价格暴涨或暴跌带来违约。
   - 对易波动单品，可采用“保底价+浮动价”或“分批定价”。

5. **建立多产地备份**
   - 同一单品至少布局2—3个产区，避免单一产地因天气、疫情、物流中断断供。
   - 例如橙子可同时看赣南、湖南、湖北；苹果可看山东、陕西、甘肃。

6. **提前锁物流和仓储**
   - 节前运力紧张，要提前锁定冷链车、航空舱位、港口提柜计划。
   - 对耐储水果提前入仓，对易损水果安排节前1—3天到店。
   - 和第三方仓配签节假日保障协议，明确违约赔付。

7. **门店端做分级备货**
   - A类高销门店多备，B类常规门店稳备，C类社区店少备但勤补。
   - 礼盒类提前陈列、预售、团购锁定，减少节中临时缺货。
   - 设置动态补货线，日销超过阈值自动触发加单。

8. **用预售和团购提前回笼需求**
   - 节前10—15天开启水果礼盒预售、企业团购、社区团购。
   - 用预售量反向指导采购，降低盲目备货风险。
   - 对爆款设置限购或分批次放量，避免超卖。

9. **合同里写清违约和应急条款**
   - 明确延迟交货、品质不达标、临时涨价的处理方式。
   - 约定替代品种、替代规格和赔偿标准。
   - 保留一部分“现货采购预算”，用于节前突发补货。

10. **节中实时监控和快速调拨**
   - 每天跟踪销量、库存、损耗、到货准时率。
   - 发现某单品断货风险，立即从周边门店或区域仓调拨。
   - 对确实缺货的品类，用替代水果做组合销售，减少客流流失。

一句话总结：**节前45天锁协议，30天锁货源，15天锁物流，7天锁陈列和预售，节中靠调拨和替代品兜底。**  
最关键的是：不要只锁量，还要锁价、锁品质、锁到货时间，并准备备选供应商。
