水果店采购菠萝，核心是**按“卖得快不快”来定熟度**，不要只按“好不好吃”定。因为菠萝是后熟型水果，采购时越熟，损耗和售后风险越大。

可以按这个思路判断：

1. **看用途和周转速度**
   - 当天能卖完、走量快：可以采**七八成熟**，香气明显、果眼略黄，顾客买回家1天内吃正好。
   - 正常2-3天卖完：采**六到七成熟**，外观偏青黄，果身硬，回家放1-2天再吃。
   - 周转慢、天气热：尽量采**五六成熟**，青一点更耐放，但口感会偏酸，需要控制库存。

2. **看外观**
   - 果皮由青转黄，尤其**底部开始泛黄**，说明在熟。
   - 果眼大而平、间隙明显，通常成熟度较高。
   - 全青且果眼很紧，偏生；全黄、底部发软，已经偏熟，损耗风险高。
   - 有裂口、渗汁、局部褐变、霉点的不要采。

3. **闻香气**
   - 没香味：偏生，适合再放。
   - 靠近底部有淡淡果香：比较合适，适合门店短期销售。
   - 香气很浓、带酒味或发酵味：过熟，容易坏，不建议采购。

4. **按压和掂重**
   - 轻按果身：硬实为好；底部明显软陷说明过熟。
   - 同样大小，手感偏重说明水分足；太轻可能失水或内部品质差。
   - 摇晃没有明显松动感，避免内部已经空腔或过熟。

5. **看季节和运输**
   - 夏季高温：采购熟度要降一档，最好青黄交界，减少在店损耗。
   - 冬季或空调环境：可以适当采熟一点。
   - 长途运输：采生一点；短途当天到店：可以采熟一点。
   - 到店后不要堆太厚，保持通风，底部容易压伤、发霉。

6. **实操建议**
   - 把采购分两批：
     - **主销批**：六到七成熟，青黄、硬实、微香，适合2-3天卖。
     - **即食批**：七八成熟，底部泛黄、香味明显，当天或次日主推。
   - 每天挑出最熟的先切果盒、做特价或试吃，别等它坏。
   - 如果顾客普遍买回家就吃，可以适当提高熟度；如果顾客喜欢放几天，就降低熟度。

简单记：**看底部转黄、闻淡香、按着硬实、掂着有分量，就是门店比较合适的采购熟度。太青不好卖，太黄损耗大。**
