这三个不是三选一，优先级要分场景：**先卡保质期和包装，再定配送频次**。如果只能选一个，核心是 **保质期管理（尤其开封/加工后计时）**，包装和配送频次都是为它服务的。

具体判断：

1. **保质期是底线**
   - 菠萝切块属于鲜切水果，风险主要在微生物繁殖和氧化变质。
   - 关键不是“菠萝本身能放多久”，而是 **切块后开始计时**：冷藏条件下通常建议当天售完，最多不超过 24 小时；如果门店做不到严格冷链，时限要更短。
   - 必须做 **先进先出**、贴加工时间标签、到点下架，不能靠“看起来没坏”判断。

2. **包装决定实际能放多久**
   - 裸卖或简单保鲜膜：失水、氧化、污染都快，基本只能短时售卖。
   - 密封盒/气调包装：能延长一点，但前提是全程冷藏，且包装不能鼓包、漏气、渗液。
   - 包装还影响顾客判断：有生产/切配时间、保质期、储存条件的标签，比单纯“包起来”更重要。

3. **配送频次是补货策略，不是保质手段**
   - 配送频次高，能减少门店库存积压，让切块更新鲜，但 **不能替代门店的效期管理**。
   - 如果门店销量小、冷链弱，应该 **减少单次配送量、提高配送频次**，而不是一次送很多慢慢卖。
   - 如果销量稳定、冷链可靠，配送频次可以适当降低，但门店仍要按切配时间下架。

**可执行建议：**
- 优先建立：切配时间标签 + 冷藏温度记录 + 到期下架。
- 包装选密封、防漏、可贴标签的容器，避免裸卖长时间暴露。
- 配送按销量走： **高频少量**，尤其夏季和销量不稳定门店。
- 如果出现异味、发黏、渗液、颜色发暗，直接废弃，不要降价促销。

一句话：**保质期是红线，包装是保障，配送频次是减少压货的手段；三者里先管住保质期，再谈包装和配送。**
