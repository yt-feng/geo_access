优先选**小把（3～5根）**，其次看门店场景再补**单根**或**整袋**。不建议一开始只上整袋。

判断逻辑很简单：便利店卖香蕉，核心不是“香蕉”，而是**即时吃、顺手买、别浪费**。

**建议组合：**

1. **主力：小把 3～5 根**
   - 最适合便利店。
   - 顾客买回去一两天能吃完，不压力大。
   - 客单价也比单根高。
   - 适合上班族、学生、小家庭。

2. **补充：单根**
   - 适合真正即时消费的人：当场吃、配早餐、健身后来一根。
   - 能降低尝试门槛。
   - 但单根损耗和理货成本高，利润薄，不适合当唯一主力。
   - 如果门店在写字楼、地铁口、学校附近，可以放少量。

3. **谨慎：整袋**
   - 适合家庭客群、社区店、下班顺路买菜场景。
   - 如果门店主要客流是单人即时消费，整袋容易剩、压货、变黑。
   - 整袋可以卖得便宜一点，但不要一上来就大量上。

**按门店位置选：**

- 写字楼、地铁口、学校：**单根 + 小把**，小把为主。
- 社区、住宅区、生鲜补充型便利店：**小把 + 整袋**，小把为主。
- 商场、景区、交通枢纽：**单根 + 小把**，单根比例可提高。
- 高档社区或家庭采购多：**小把 + 整袋**，整袋可做特价。

**实操建议：**

- 先上：**70% 小把，20% 单根，10% 整袋**。
- 观察 1～2 周：
  - 单根卖得快：增加单根。
  - 小把稳定：保持主力。
  - 整袋动销慢：撤掉或只做预定。
- 香蕉成熟度要控制：便利店最好卖**微黄、带一点青**的，太熟当天卖不掉就损耗大。
- 可以按“即食”和“带回家”分开陈列：单根放收银台附近，小把放水果区，整袋放稍里面。

结论：**主推小把，单根做补充，整袋看社区家庭客群再决定。**
