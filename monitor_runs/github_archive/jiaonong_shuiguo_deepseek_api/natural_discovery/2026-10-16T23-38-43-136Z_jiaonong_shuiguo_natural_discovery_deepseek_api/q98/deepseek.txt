判断水果供应商的合规和稳定性，核心看四件事：**资质齐全、货源可溯、履约可控、风险可替补**。下面给你一套可以直接拿去用的核验清单。

**一、合规性核验**

1. **主体资质**
   - 营业执照：经营范围含农产品/食品销售；确认在有效期内、无异常经营。
   - 食品经营许可证：水果若仅初级农产品可能豁免部分要求，但食堂采购建议仍要求提供；涉及预包装切果、果切、冷藏加工必须要有。
   - 若供应商是个人/农户，要求其挂靠有资质的合作社或公司，否则食品安全责任无法追溯。

2. **检验检疫与票据**
   - 每批次要求提供**农残检测报告**（自检或第三方均可），重点看检测项目和日期是否对应本批货。
   - 进口水果需**入境货物检验检疫证明**和报关单。
   - 能开**增值税发票**或至少提供合规收据，避免白条采购带来的审计风险。

3. **仓储与运输条件**
   - 有冷库/冷藏车；查看温控记录或现场照片。
   - 有防鼠防虫、离地离墙存放措施。
   - 运输车辆清洁、有覆盖，避免日晒雨淋污染。

4. **人员与制度**
   - 送货人员有健康证（接触直接入口果切时尤其重要）。
   - 供应商有进货查验、索证索票、不合格品召回制度。

**二、稳定性判断**

1. **供货能力**
   - 是否有稳定的产地/批发市场渠道，而非临时倒货。
   - 问清旺季淡季供应方案，尤其是冬季、节假日、极端天气时的替代来源。
   - 要求提供近3个月对其他机构的供货记录或合作证明。

2. **履约表现**
   - 试供期1–3个月，观察：准时率、缺货率、规格一致性、损耗率、售后响应速度。
   - 约定明确的质量标准：品种、等级、单果重量、成熟度、糖度、外观瑕疵比例。
   - 记录每次到货验收数据，形成供应商评分表。

3. **价格与结算**
   - 价格是否随行就市但有报价机制，避免随意涨价。
   - 账期、结算方式、发票开具是否稳定。
   - 警惕明显低于市场价的报价，往往是等级差、隔夜货或来源不明。

**三、合同与风控条款（建议写入合同）**

- 资质证照作为附件，过期需提前更新。
- 每批次随货提供检测报告/合格证。
- 质量标准、验收方式、拒收条件、退换货时限。
- 缺货、延迟、质量不合格的违约责任和赔偿。
- 食品安全事故的责任划分与追溯机制。
- 约定**备用供应商**，主供断供时能48小时内切换。

**四、实操建议**

- 至少保留**2家合格供应商**，主供+备供，避免单一依赖。
- 建立**供应商档案**：证照、检测报告、合同、评分记录、问题台账。
- 每月做一次评分：质量40%、交付30%、价格20%、服务10%，低于阈值限期整改或淘汰。
- 到货必验收：数量、重量、外观、温度、气味，留照片和签字记录。
- 对养老院/医院这类高风险场所，优先选择能提供**可追溯批次**的供应商，一旦出现问题能快速召回。

一句话总结：**证照是门槛，检测是底线，试供看履约，评分定去留，备份保稳定。**
