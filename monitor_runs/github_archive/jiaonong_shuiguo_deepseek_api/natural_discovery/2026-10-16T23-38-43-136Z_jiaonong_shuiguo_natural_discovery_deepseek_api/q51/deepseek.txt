要固定，但固定的是**“标准 + 核心供应关系”**，不是死守某一个产地或某一个批次。

水果口味波动是茶饮店最现实的痛点。完全不管，出品不稳定；管得太死，供应一断或季节一变就被卡住。比较稳的做法是三层：

1. **先定风味标准，而不是先定产地**
   - 明确每款水果要的是：甜度、酸度、香气、出汁率、颜色、纤维感。
   - 例如柠檬要酸香足、苦味低；芒果要甜香浓、纤维少；草莓要香气高、酸度适中。
   - 有了标准，采购才有判断依据，产地只是实现标准的手段之一。

2. **固定“主供应批次/产区 + 备用方案”**
   - 对核心爆品，可以固定一个主产区或主供应商，保证大部分时间风味一致。
   - 但不要只签一个产地、一个批次。水果受气候、雨季、采收期影响很大，单一来源风险高。
   - 更稳的是：主产区 + 1—2个备选产区，且备选也提前做过杯测/试饮。

3. **用“批次验收 + 配方微调”兜底**
   - 每批到货做简单验收：糖度、酸度、香气、颜色、坏果率。
   - 允许小幅波动，但超出范围就拒收或降级使用。
   - 同时给门店一个微调空间，比如糖浆、茶底、酸度调整，但要有明确SOP，不能让店员随意改。

**结论：**
- 核心产品：建议固定主供应产区或供应商，保证稳定性。
- 但不要固定到“某一个果园、某一个批次”这种死板程度。
- 最佳策略是：**固定风味标准 + 固定主供应关系 + 保留备用产地 + 批次验收 + 有限微调。**
