旺季锁库存的核心不是“提前打招呼”，而是**用确定性和钱换优先级**。水果供应商旺季最怕两件事：你临时砍量、你临时加量。所以锁库存要围绕“降低对方风险”来设计。

**1. 提前锁定，但给供应商“可执行的时间表”**
不要只说“旺季大概要多少”。要给出：
- 分周/分日的预估量（哪怕有±20%浮动）
- 提前7-10天确认最终量的机制
- 爆单时的追加上限和截止时间

供应商敢备货，是因为他知道什么时候备、备多少、卖给谁。

**2. 用预付款或保证金换优先权**
旺季供应商的库存是稀缺资源，口头承诺没用。常见做法：
- 预付30%-50%货款，锁定对应货量
- 或交一笔可抵扣的保证金
- 明确违约条款：你砍量，预付款不退或扣比例；供应商缺量，按差价赔偿

钱到位，供应商才会把你排在前面。

**3. 签“阶梯量+保底量”协议**
不要只签一个固定数字。建议：
- 保底量：你承诺至少拿多少，供应商必须保证
- 弹性量：最多可追加多少，提前几天通知
- 超量部分：价格可以略高，但要有上限

这样既锁住基本盘，又保留爆单空间。

**4. 给供应商“排产/采摘信号”**
水果不是标准品，有采摘期、成熟期、冷链档期。你要提前告诉供应商：
- 你的主推品种和预估爆款
- 每天大概几点要货、到什么仓
- 包装规格、分级标准、损耗承担方式

越具体，供应商越敢把货留给你。

**5. 多供应商+主次绑定**
不要只锁一家。建议：
- 主供应商：锁60%-70%，给预付款和保底量
- 备用供应商：锁20%-30%，平时也走小单维持关系
- 应急渠道：批发市场或产地直发，用于极端爆单

主供应商缺量时，备用能顶上；备用平时有单，旺季才愿意帮你。

**6. 用“数据”换信任**
如果你有历史数据，直接给供应商看：
- 去年旺季日均单量、峰值、复购率
- 哪些单品爆、哪些滞销
- 退货率和损耗率

供应商最怕你拍脑袋报量。数据越真实，他越愿意给你留货。

**7. 合同里写清楚关键条款**
- 质量标准：糖度、大小、成熟度、瑕疵率
- 交付时间：迟到几小时怎么赔
- 缺货处理：优先补货还是退款
- 价格机制：旺季浮动范围、锁价周期
- 损耗分担：运输/仓储损耗谁承担

**8. 实操节奏**
- 旺季前45天：谈意向，给预估量
- 前30天：签协议，付预付款
- 前15天：确认首周排产
- 前7天：每日滚动确认未来3天量
- 旺季中：每天同步销售数据，让供应商看到你在帮他消化产能

一句话：**锁库存=锁时间+锁钱+锁责任**。只靠关系，旺季一定被插单；把预付款、保底量、弹性追加和违约条款做扎实，供应商才会把你当优先级客户。
