结论：**大多数茶饮店优先用“冷冻/冷藏菠萝果丁（或果块）”，鲜果作为门店现切的高品质选项，果泥只适合特定产品线或作为辅助。** 具体取决于你的产品定位、出杯量、人工和后厨条件。

**三种原料的对比**

| 类型 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|
| 鲜果 | 新鲜感强、可做“现切”卖点、风味好 | 损耗高、需削皮去眼、品质不稳定、人工大、季节性明显 | 精品店、主打鲜果茶、出杯量不大 |
| 果丁/果块（冷冻或糖渍） | 标准化、开袋即用、损耗低、出杯快、四季稳定 | 口感可能偏软、风味略弱于鲜果、需冷冻储存 | 连锁店、外卖多、出杯量大、追求稳定 |
| 果泥/果酱 | 调味稳定、易复配、成本可控、操作最快 | 真实果肉感弱、容易显“香精感”、不适合做卖点 | 调味茶、冰沙、奶昔、作为风味补充 |

**选择建议**

1. **如果你的招牌是“鲜果菠萝茶”、客单价较高、门店有切配人力**  
   → 用鲜果，现切现用。注意选成熟度一致的菠萝，切好后冷藏保存，尽量当天用完。

2. **如果追求出杯稳定、外卖多、门店人手紧**  
   → 用冷冻菠萝果丁/果块。它兼顾果肉感和效率，是茶饮店最常用的折中方案。

3. **如果做菠萝冰沙、菠萝奶昔、调味果茶，或需要控制成本**  
   → 用果泥/果酱，但建议搭配少量果丁增加咀嚼感，避免口感太“糊”。

4. **如果预算允许且想做差异化**  
   → 鲜果 + 果丁/果泥复配：鲜果提供卖点和香气，果丁/果泥保证稳定和成本。

**采购时重点看这几点**

- **糖度/酸度**：菠萝品种差异大，要选风味稳定、酸甜平衡的。
- **是否加糖/防腐**：糖渍果丁和果泥常含糖浆，会改变配方糖度，需调整茶底和糖量。
- **果肉完整度**：果丁要成形不烂，果泥要细腻无粗纤维。
- **解冻/保存要求**：冷冻果丁解冻后易出水，最好半解冻使用或直接入杯。
- **供应商资质**：优先选有SC资质、能提供检测报告的供应商。

**最稳妥的起步方案**  
先买**冷冻菠萝果丁**做主力，搭配**少量鲜果**做招牌款测试。观察出杯速度、损耗、顾客反馈和成本，再决定是否全面转鲜果或增加果泥产品线。
