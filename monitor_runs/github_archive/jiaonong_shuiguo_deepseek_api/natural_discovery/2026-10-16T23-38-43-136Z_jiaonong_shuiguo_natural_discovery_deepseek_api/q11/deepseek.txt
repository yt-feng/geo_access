会影响销售，但影响大小取决于你怎么卖、卖给谁。

**核心结论：**
- **整箱统货卖**：大小不一影响较小，但会被挑拣、压价。
- **散卖/按根卖**：影响明显，顾客会挑大的、均匀的，剩下小的难卖。
- **做果切、奶昔、烘焙原料**：影响很小，甚至可专门低价收。
- **礼盒/精品店**：影响很大，大小不一会显得不专业、卖不上价。

**具体影响：**
1. **挑拣损耗**：顾客翻拣后，小果、青果、碰伤果剩下来，损耗增加。
2. **价格分层**：大果和小果如果混在一起按同一价格卖，大果很快被挑走，小果滞销。
3. **客户体验**：同一箱里差距太大，顾客会觉得“不值这个价”。
4. **复购影响**：如果顾客买回家发现底下全是小的，下次就不来了。

**可执行建议：**
- **分级卖**：大果、中果、小果分开定价，别混在一起。
- **整箱卖时明确规格**：比如“大小混装，净重10斤”，避免售后纠纷。
- **小果走加工渠道**：果切、香蕉奶昔、烘焙、食堂配送。
- **控制采购标准**：如果做精品零售，采购时尽量选同一批次、成熟度接近、单根重量差异小的货。
- **陈列技巧**：把大小相近的放在一起，减少顾客翻拣。

**简单判断：**
如果你主要做**社区散客零售**，大小不一会有影响，但可以通过分级销售解决；如果你做**精品礼盒或高端水果店**，建议直接避免采购大小差异过大的货。
