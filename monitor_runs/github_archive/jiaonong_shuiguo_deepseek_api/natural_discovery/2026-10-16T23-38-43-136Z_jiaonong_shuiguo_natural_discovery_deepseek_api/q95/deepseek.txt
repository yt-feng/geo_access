选学校食堂水果供应商，核心不是“找最便宜的”，而是找**能稳定供货、质量可控、票据齐全、出问题能追责**的供应商。香蕉、苹果、橙子都属于高频大宗水果，建议按下面几步做。

**1. 先定采购标准，再去谈供应商**
不要只说“要香蕉、苹果、橙子”，要写成可验收的标准：
- 香蕉：成熟度适中，无黑腐、无严重压伤，单把重量和根数相对稳定，适合当天或次日食用。
- 苹果：果径分级明确，如70mm、75mm、80mm；无大面积碰伤、虫眼、腐烂，口感脆度稳定。
- 橙子：果径、糖酸比、皮厚薄、出汁率有基本要求；无干疤、霉变、冻伤。
- 统一要求：农残检测合格、新鲜度、到货温度、包装无污染、可追溯产地或批次。

**2. 供应商类型怎么选**
常见有三类：
- **批发市场档口**：价格灵活、起送量低，适合小批量试单；但稳定性、票据和追溯较弱。
- **产地合作社/种植基地**：苹果、橙子适合直采，价格和批次稳定性好；但需要自己有验收和仓储能力。
- **专业生鲜配送商**：服务学校经验多，能按周配送、开发票、提供检测报告；价格通常略高，但省心、可追责。

学校食堂优先选：**有学校或企事业单位配送经验的生鲜配送商 + 产地直采作为补充**。不要只依赖一个临时档口。

**3. 重点核验这几项资质和材料**
- 营业执照、食品经营许可证或相关流通许可。
- 水果农残检测报告，至少能按批次提供。
- 进货凭证、产地证明或承诺达标合格证。
- 配送车辆和仓储卫生条件。
- 是否能开正规发票。
- 是否有食品安全责任险或类似保障。
- 过去服务过哪些学校、食堂、单位，能否提供案例。

**4. 报价不能只看单价**
让供应商按“到食堂价”报价，包含：
- 水果单价
- 运费
- 损耗怎么算
- 退换货规则
- 临时加单费用
- 包装费
- 税率和发票类型

特别要问清：**烂果、碰伤、规格不符怎么处理？是补货、换货还是扣款？多久内响应？**

**5. 建议用“试单 + 月度评分”选**
不要一次签很久。先让2—3家供应商各试供1—2周，按同一标准验收：
- 到货准时率
- 验收合格率
- 重量是否足秤
- 口感稳定性
- 退换货响应速度
- 票据和检测报告是否齐全
- 价格波动是否透明

试单后选综合分最高的1家主供，再保留1家备选。香蕉、苹果、橙子可以同一家供，也可以分开：苹果、橙子找产地或专业配送，香蕉找周转快的本地配送。

**6. 合同里必须写清**
- 品名、规格、等级、单价或调价机制
- 配送频次、到货时间、验收地点
- 质量标准和拒收条件
- 退换补货时限
- 食品安全责任
- 发票和结算周期
- 违约和终止条款
- 价格随行就市时，怎么提前报备、怎么比对市场价

**7. 最实用的选择顺序**
1. 先写验收标准。
2. 找3家左右：1家专业配送、1家批发市场、1家产地或合作社。
3. 每家试供1—2周。
4. 按合格率、准时率、价格、票据、售后打分。
5. 选1家主供、1家备选，签短期合同，季度复盘。

一句话：**学校食堂选水果供应商，优先选能稳定供货、能开票、能提供检测报告、出问题能退换赔的；价格放在质量、安全和可追责之后。**
