单位采购水果遇到品质不一致，处理核心是：**验收时把差异固定成证据，售后时按合同和证据谈处理方案**。下面是可直接执行的流程。

## 一、到货验收怎么做

**1. 先对单，再开箱**
- 核对送货单、订单、合同：品种、规格、等级、数量、单价、产地、采摘/包装日期。
- 数量按箱/筐抽点，不要只点总数，防止以次充好、缺斤少两。

**2. 抽样规则**
- 大批量按批次抽：一般抽 **5%–10%**，少于50箱可抽5–10箱，超过200箱抽10–20箱。
- 每箱从上、中、下三层各取果，不能只看表层。
- 同一批次、同一品种单独记录，不同批次分开验。

**3. 重点检查项**
- 外观：大小、色泽、成熟度是否一致；
- 损伤：挤压、碰伤、裂口、腐烂、发霉；
- 成熟度：过硬/过熟、青果/烂果比例；
- 重量：单果重、整箱净重是否达标；
- 温度/新鲜度：叶菜、浆果类看是否萎蔫、出水、异味。

**4. 现场记录（关键）**
- 拍照/录像：整批全景、问题箱特写、称重过程、标签和送货单同框。
- 填写验收单：合格数、不合格数、不合格原因、比例。
- 让送货人签字确认；对方不签，就在单上注明“送货人拒绝签字”，并让其工牌/车牌/姓名入镜。
- 全程最好两人以上在场，一人验收一人记录。

**5. 判定标准要提前写进合同**
- 例如：腐烂率≤3%，碰伤率≤5%，大小偏差不超过±10%，成熟度按约定等级。
- 超过标准的部分，按“拒收 / 折价 / 换货 / 补货”处理。

## 二、发现品质不一致时的处理顺序

1. **先隔离**：不合格品单独堆放，避免和合格品混放，防止继续腐坏和争议。
2. **当场定性定量**：算出不合格比例，比如“抽检10箱，3箱有腐烂，腐烂果占12%”。
3. **按合同走**：
   - 轻微差异：折价接收，按实际合格量结算；
   - 明显差异：要求换货或补发；
   - 严重差异：整批拒收，并要求退换或赔偿。
4. **书面确认**：验收单、微信/邮件、电话录音都要留。口头承诺不算数。

## 三、售后怎么谈

**1. 先给方案，不要只投诉**
可以直接提三选一：
- 换货：限时补送合格品；
- 折价：按不合格比例扣款；
- 退货：不合格部分退回，运费由供方承担。

**2. 结算挂钩**
- 验收合格后才付款；有争议的部分暂缓结算。
- 合同里最好写明：质量不达标可扣款、可退货、可索赔，逾期换货有违约金。

**3. 留好证据链**
- 订单/合同 → 送货单 → 验收记录 → 照片视频 → 沟通记录 → 处理结果。
- 这些是后续投诉、索赔、换供应商的依据。

## 四、建议写进采购合同的条款

- 品种、规格、等级、产地、单果重、成熟度标准；
- 腐烂率、碰伤率、大小偏差上限；
- 验收方式、抽样比例、异议提出时限；
- 不合格处理方式：折价、换货、退货、赔偿；
- 送货时限、补货时限、违约责任；
- 付款条件：验收合格后付款。

## 五、一句话操作口诀

**对单 → 抽样 → 拍照 → 记录 → 签字 → 隔离 → 按合同处理 → 书面确认。**

如果你们没有合同或验收单，建议至少先用微信/邮件把“品种规格、验收标准、不合格怎么处理”确认一遍，再让送货人现场签字，这样售后才有抓手。
