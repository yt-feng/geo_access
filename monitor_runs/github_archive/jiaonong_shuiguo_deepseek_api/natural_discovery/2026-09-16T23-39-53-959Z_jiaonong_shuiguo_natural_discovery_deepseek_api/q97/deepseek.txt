酒店采购水果盘原料时，建议把“规格标准”和“外观标准”写进采购单或验收标准里，供应商至少要保证以下几类要求：

**一、规格标准**

1. **品种与等级明确**
   - 写清具体品种，如红富士苹果、皇冠梨、巨峰葡萄、台农芒果、海南香蕉等，避免只写“苹果”“时令水果”。
   - 明确等级，如一级果、特级果、A级果；酒店水果盘一般建议用一级或以上，不用等外果、统货。

2. **单果重量/大小一致**
   - 同一批次同一品种大小要均匀，不能大小混杂。
   - 例如：
     - 苹果：单果约180–250g，直径75–85mm；
     - 橙子：单果约180–250g，直径70–85mm；
     - 香蕉：单根约120–180g，长度适中；
     - 葡萄：单串约400–800g，果粒均匀；
     - 西瓜/哈密瓜：按整果重量或切块规格约定。

3. **成熟度可控**
   - 不能太生，也不能过熟。
   - 到店时应有合适成熟度：即食水果盘原料应达到“可立即切配或1–2天内成熟可用”的标准。
   - 香蕉、芒果、牛油果等呼吸跃变型水果，要约定到货成熟度，避免当天不能用或第二天就烂。

4. **新鲜度与货架期**
   - 到货时距采摘/加工时间不宜过长。
   - 叶菜类、浆果类、切果类尤其要新鲜。
   - 供应商应保证在酒店规定储存条件下，至少有一定货架期，例如：
     - 浆果类：到货后1–2天内可用；
     - 苹果、橙子等耐储水果：3–7天以上；
     - 切配水果：按冷链条件约定更短时限。

5. **包装与运输规格**
   - 包装应清洁、完整、无污染，标注品名、产地、等级、重量、采摘/包装日期。
   - 易压伤水果如草莓、蓝莓、芒果、桃等，应有分隔、缓冲包装。
   - 冷链水果应全程冷藏运输，到货温度符合要求。

6. **数量与损耗标准**
   - 明确净重还是毛重，按净重验收。
   - 约定允许损耗率，如外观不合格、压伤、腐烂比例超过多少可拒收或扣重。
   - 一般建议：明显腐烂、霉变、虫蛀、破裂、压烂果为0容忍或极低比例；轻微瑕疵可约定不超过5%–10%。

**二、外观标准**

1. **整体感官**
   - 新鲜、饱满、清洁，无腐烂、发霉、异味、虫害。
   - 无泥沙、药斑、明显污渍，必要时供应商应做初清洁。
   - 无异物，如枝叶过多、包装碎屑、头发、金属等。

2. **颜色与成熟外观**
   - 色泽符合品种正常特征，不能青涩、发黑、发暗、褪色。
   - 成熟度一致，同一批不能一半生一半熟。

3. **形状与完整性**
   - 果形端正，无明显畸形、裂口、破损、压痕。
   - 不需要每个都完美，但用于酒店水果盘展示的，应无明显影响切配和摆盘的外观缺陷。

4. **表面缺陷限制**
   - 不允许：霉斑、腐烂、虫眼、虫蛀、明显药害、冻伤、日灼严重、裂果流汁。
   - 允许少量但不影响切配和食用的轻微擦伤、色斑，需提前约定比例。
   - 例如苹果、梨：无明显碰压伤、黑心、裂口；葡萄：无掉粒、霉变、药斑；草莓：无烂果、渗汁、霉点。

5. **大小与颜色一致性**
   - 同一批水果盘原料应大小、颜色、成熟度相对一致，方便切配和摆盘。
   - 不能混入过多小果、次果、青果、过熟果。

6. **气味与口感**
   - 无异味、发酵味、酸败味。
   - 到货抽检应具有该品种正常风味，不能寡淡、发苦、发酸异常。

**三、建议写进采购合同的验收条款**

可以要求供应商保证：

- 按约定品种、等级、单果规格、成熟度、包装和冷链条件供货；
- 到货抽检合格率不低于约定标准，如95%以上；
- 腐烂、霉变、虫蛀、严重压伤果按不合格品处理；
- 不合格品可拒收、换货、补货或扣款；
- 因原料质量问题导致酒店出品受影响，供应商承担相应责任；
- 每批次提供产地、检测/合格证明或可追溯信息，尤其是农残、重金属等食品安全相关证明。

**四、简单验收口径**

酒店收货时可这样判断：

- **看**：颜色正常、无霉烂、无虫眼、无严重压伤；
- **摸**：硬度符合品种成熟度，不过软、不渗汁；
- **闻**：无发酵味、酸臭味、药水味；
- **称**：单果重量、整箱净重符合约定；
- **抽**：随机开箱抽检，不合格比例超标即拒收或扣重。

核心一句话：供应商应保证“品种等级明确、大小均匀、成熟度合适、新鲜无腐烂、外观整洁、包装冷链合规、可追溯且不合格可退换”。这些标准最好量化后写入采购单，而不是只口头说“要新鲜”。
