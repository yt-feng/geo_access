水果店卖菠萝，损耗主要来自“到店太生卖不动”和“到店过熟很快坏”两头。采购时判断熟度，核心是**按你预计卖出速度来决定采购熟度**，而不是一味挑最熟或最生。

## 一、先定采购策略

- **当天或1-2天能卖完**：可以采**8-9成熟**，香气明显、果眼变浅，能直接吃。
- **2-4天卖完**：采**7-8成熟**，到店后逐步转熟，减少当天过熟损耗。
- **4天以上或天气热、周转慢**：采**6-7成熟**，偏青但已开始转色，回去后熟。
- **夏季高温**：整体降半档到一档，宁生勿过熟。
- **冬季低温**：可适当提高熟度，因为后熟慢。

## 二、现场判断菠萝熟度的几个实用指标

### 1. 看果皮颜色
- 全青：约5-6成熟，后熟空间大，但卖相和即食性差。
- 青中带黄、果眼周围开始泛黄：约7成熟，适合多数水果店。
- 三分之一到一半转黄：约8成熟，香气开始明显。
- 大面积金黄、底部发橙：约9成熟以上，适合快销，不适合压货。

注意：不同品种差异大，比如金钻凤梨、台农、巴厘菠萝转色表现不同，不能只看颜色。

### 2. 闻底部香气
- 几乎无香：偏生。
- 底部有淡淡甜香：7-8成熟，比较理想。
- 香气浓、带酒味或发酵味：过熟或开始坏，慎采。

### 3. 看果眼和鳞片
- 果眼尖锐、紧密、发青：偏生。
- 果眼变平、间隙变大、颜色转黄褐：偏熟。
- 果眼周围有汁液渗出、发暗：可能过熟或内部损伤。

### 4. 摸硬度
- 硬得像石头：很生。
- 轻按有弹性、不软塌：7-8成熟。
- 一按就凹、底部软：过熟，损耗风险高。

### 5. 看底部和冠芽
- 底部发黑、发霉、软烂：不要。
- 冠芽青绿、挺立：较新鲜。
- 冠芽枯黄、易拔：存放久或熟过头。

### 6. 掂重量
同样大小，**偏重**通常水分足、果肉好；明显轻飘可能失水或内部空。

## 三、采购时建议这样组合

不要只采一个熟度，可以按比例配：

- 60%-70% 采7-8成熟，用于未来2-3天销售；
- 20%-30% 采8-9成熟，用于当天现切或促销；
- 10% 采6-7成熟，作为后备，天气热或周转慢时多留这种。

如果做现切菠萝，可以适当多采8成熟，因为出肉率和口感更好；如果是整果堆头，7成熟更耐放。

## 四、到店后的简单处理

- 偏生的放在常温通风处后熟，不要直接冷藏，否则后熟慢甚至变黑。
- 已熟或切开的必须冷藏，尽快卖。
- 每天翻堆，把熟度高的挑出来先卖或促销。
- 底部朝下放，减少压伤；不要堆太高。
- 发现底部软、有酒味的立即隔离，避免传染。

## 五、最实用的判断口诀

**“看色、闻底、按硬度，掂重、看眼、查底部。”**

采购时优先选：**果皮青中带黄、底部有淡香、按着有弹性、果眼开始变平、底部干净不软**的菠萝。这个熟度通常最适合水果店周转，既能较快卖，又不至于当天就烂。
