超市水果到货后发现品相不好，售后约定建议按“**先验货、再分级、后赔付**”来写，核心是把主观的“品相不好”变成可判断的标准。可以这样约定：

**一、验收时限**
1. 到货后当场或 **2小时内** 完成外包装、数量、明显腐烂破损验收。
2. 开箱后才发现品相问题，建议约定 **24小时内** 提出，生鲜类越短越好。
3. 逾期未提异议，视为外观验收通过，但不免除隐藏质量问题责任。

**二、品相判定标准**
不要只写“品相好”，要写明：
- 果径/单果重量范围；
- 色泽、成熟度；
- 允许的碰伤、压伤、虫眼、裂口比例；
- 腐烂、发霉、异味为不合格；
- 不合格比例超过多少可整批拒收或部分扣款。

例如：  
“碰伤、压伤果不超过5%；腐烂果不超过2%；超过部分按实际不合格数量扣款；腐烂超过10%的可整批退货。”

**三、处理方式**
按问题程度分档：
1. **轻微瑕疵**：不影响销售，可协商折价收货。
2. **部分不合格**：按不合格数量退款、补货或扣款。
3. **严重不合格**：整批拒收，供应商承担退换货及运费。
4. **已上架后发现问题**：立即下架、拍照留证，按批次追溯。

**四、责任与费用**
- 到货前运输、包装导致的品相问题，由供应商承担。
- 超市存储不当导致的，由超市承担。
- 退换货运费、损耗、二次分拣费，按责任方承担。
- 若供应商拒绝处理，可约定从货款中直接扣除相应损失。

**五、证据要求**
售后申请应提供：
- 到货时间、批次、数量；
- 现场照片/视频；
- 不合格比例抽检记录；
- 双方确认的验收单。

**六、最好写进合同或采购单的条款**
> 水果到货后，超市应在24小时内验收。发现腐烂、霉变、严重碰伤、成熟度不符等品相问题，应在验收期内书面通知供应商。轻微瑕疵按不合格数量折价结算；不合格比例超过__%的，超市有权拒收或要求换货；因供应商原因导致的退换货费用及损耗由供应商承担。逾期未提异议视为外观验收合格，但不影响隐藏质量问题的追责。

简单说：**时限要短、标准要量化、分档处理、留证扣款**。这样既方便超市执行，也能减少和供应商扯皮。
