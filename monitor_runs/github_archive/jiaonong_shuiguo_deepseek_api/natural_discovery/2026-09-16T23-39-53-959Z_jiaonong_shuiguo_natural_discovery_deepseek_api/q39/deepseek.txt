可以，但要看供应商类型和你的合作深度。给你一个可判断的框架：

**1. 包装支持：多数能提供，但分三种情况**

- **纯种植/产地供应商**：通常只能提供周转筐、大货箱，不一定能做零售小包装。想做自有品牌包装，往往要你自己找包装厂或让供应商代采。
- **产地合作社/加工厂**：通常能提供分选、称重、贴标、装盒，甚至按你的品牌做彩盒、吸塑盒、网套、标签。这是最适合做自有品牌的一类。
- **一批/批发商**：包装能力弱，更多是转手，定制意愿和配合度低。

**2. 规格支持：能谈，但要你定标准**

供应商能按你要求做分级，比如：
- 单果重：如 80–90g、90–100g
- 果径/等级：大果、中果、小果
- 包装规格：2 个装、4 个装、500g 盒、1kg 袋
- 糖度、外观、成熟度等验收标准

但前提是你要给出明确的 **验收标准**，否则供应商会按自己的习惯分，最后损耗和投诉都算你的。

**3. 做自有品牌，供应商实际能配合到什么程度**

- **能配合**：分选、称重、贴你的标签、装你的盒子、按你的规格发货、代贴条码。
- **不一定能配合**：单独为你开发新包装、承担包装模具费、承担品牌库存风险、做小批量多 SKU。
- **通常要你承担**：包装设计、制版/开模费、最小起订量、包材库存、品牌授权和条码申请。

**4. 建议你先确认这 5 件事**

1. 供应商是否愿意接 **自有品牌标签**，还是只能做中性包装。
2. 包装是 **供应商代采** 还是你指定包材厂，费用谁出。
3. **最小起订量** 和 **最小包装批量**，水果季节性很强，别压一堆包材。
4. 规格标准写进合同：单果重、果径、糖度、外观、允许次品率。
5. 损耗和售后怎么分：运输烂果、到店变质、消费者投诉谁承担。

**5. 更稳的做法**

先选 1–2 个单品试，比如苹果、橙子、猕猴桃这类耐储运的。让供应商按你的规格做 **小批量试包装**，跑一遍门店和线上，再决定是否放量。不要一上来全品类铺自有品牌，水果非标品，供应链和损耗会先把你拖住。

一句话：**包装和规格，供应商基本都能支持；但自有品牌的核心不是供应商能不能做，而是你能不能定标准、控损耗、担包材和品牌责任。**
