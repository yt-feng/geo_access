核心就一句：**按“预计卖完的时间”倒推采购熟度，别按“到货时最好看”来定。**

香蕉从青到坏，熟度变化大致是：

**青硬 → 转黄 → 黄带绿肩 → 全黄 → 起糖斑 → 发软发黑**

水果店最常犯的错，是采购时要求“到货已经七八成熟、金黄金黄”，结果当天卖不完，第二天就开始起斑，第三天直接报废。

采购时建议这样要求：

1. **按销量分批次定熟度**
   - 当天或次日就能卖完：可要到货 **黄带一点绿肩**，卖相好，也还能放1—2天。
   - 预计2—3天卖完：要到货 **青黄之间、绿肩明显**，到店后自然转黄。
   - 预计3—5天卖完：要到货 **偏青、硬身、无黄斑**，自己控温催熟或慢慢放熟。
   - 做促销、果汁、烘焙用：可以要高熟度或糖斑蕉，但当天必须消化掉。

2. **到货时间要求**
   - 最好要求 **清晨或上午到货**，给当天上架、分拣、挑出伤蕉留时间。
   - 避免 **傍晚到货**。傍晚到货后直接过夜，第二天熟度变化很大，尤其夏天。
   - 如果分多批卖，要求供应商 **一周分2—3次小批量到货**，而不是一次来一大车。少量多次比一次性压价更省钱。

3. **采购时直接说清楚的话术**
   - “我要后天开始卖，给我青黄之间的，绿肩明显，不要全黄。”
   - “这批是三天内卖完，到货请控制在七成熟以下，能放两三天。”
   - “请早上到货，不要下午或晚上到，夏天路上温度高，到了就熟过头。”
   - “不要泡药或催得太猛的，我要自然转黄的。”
   - “如果有轻微擦伤、水烂、黑把的，不要混进来。”

4. **到货验收要看这些**
   - 蕉把是否发黑、发霉。
   - 蕉身是否有压伤、裂口、水烂。
   - 熟度是否一致，别一箱里有的青有的黄。
   - 摸起来是否过硬或已经发软。
   - 闻起来有没有酒味、酸味，有就说明过熟或开始坏。

5. **到店后怎么减少放坏**
   - 不要整箱堆在热的地方，放阴凉通风处。
   - 青蕉可常温催熟，熟蕉可进冷库或冷藏柜，但香蕉怕冻，别低于13℃左右。
   - 把已经黄的、有斑的挑出来先卖或做特价。
   - 香蕉别和苹果、梨等释放乙烯多的水果混放，会加速成熟。
   - 上架少量多次，卖完再补，别一次全摆出来。

简单说，采购要求就是：

**“按销售速度定熟度，少量多次，早上到货，青黄之间、绿肩明显，不要全黄，不要晚上到。”**
