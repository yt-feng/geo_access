判断一批香蕉，核心是看 **颜色、手感、棱角、果柄、果身和气味**，再结合你打算几天内出货来决定能不能拿。

**1. 先看颜色，定大概熟度**
- **全绿、硬**：生蕉，适合长途运输或催熟后再卖。
- **绿带微黄**：开始转熟，通常还要 1–3 天。
- **黄多绿少**：接近可售，适合 1–2 天内出货。
- **全黄**：已熟，适合马上卖或做促销。
- **黄带黑斑**：熟度高，甜，但货架期短。
- **大面积黑斑、发黑发暗**：坏果风险高，谨慎拿。

**2. 摸手感，判断实际熟度和压伤**
- **硬邦邦**：生，耐放。
- **略软有弹性**：熟度合适。
- **局部特别软**：可能有压伤、冻伤或内部腐坏。
- **整体过软、按下去不回弹**：熟过头，损耗大。

**3. 看棱角，判断成熟阶段**
香蕉越熟，棱角越不明显。
- **棱角分明**：偏生。
- **棱角变圆**：正在熟。
- **整体圆润**：已熟。
- **圆润且软塌**：过熟。

**4. 查果柄和果身，判断坏果风险**
- **果柄发黑、发霉、腐烂**：整串或整箱风险高。
- **果柄干枯但果身正常**：不一定坏，但存放时间可能偏长。
- **果身有裂口、渗液、霉点**：直接算坏果或高风险。
- **果皮有凹陷、水渍状斑**：可能是冷害或压伤，后熟后容易变黑烂。
- **果指连接处发黑**：容易从内部烂开。

**5. 闻气味**
- **清香**：正常。
- **酒味、酸味、发酵味**：已经过熟或开始腐坏。
- **霉味**：不要拿。

**6. 抽样判断整批货**
不要只看表面。
- 从**箱内不同位置**抽几串。
- 看**底层、靠边、靠冷源或热源**的货。
- 随机切开 1–2 根，看内部是否发黑、空心、褐变。
- 如果一箱里坏果超过 **5%–10%**，就要压价或拒收；超过 **10%** 通常风险很大。

**7. 结合你的出货节奏**
- **2–3 天卖完**：可以拿黄多绿少、略软的。
- **5–7 天卖完**：拿绿带微黄、硬一点的。
- **当天促销**：可以拿全黄带少量黑斑的，但必须便宜。
- **想放一周以上**：只拿全绿、硬、无伤、无冷害的。

**简单判断口诀：**
**看颜色定熟度，摸软硬定货架期，查果柄定坏果，闻气味定能不能要。**

如果一批货出现：**果柄发霉 + 局部软陷 + 酒味 + 底层黑斑多**，基本可以判定坏果风险高，不建议按正常价拿。
