判断商超供应商的售后响应是否稳定，重点不是听承诺，而是看它有没有制度化、可验证、可追责的响应机制。可以从下面几个方面核查。

**1. 先看合同里有没有可执行的售后条款**
- 是否写明响应时限，比如到货后几小时内受理、24小时内给处理方案。
- 是否写明质量问题处理方式：退货、换货、补货、扣款、赔偿，不能只写“协商解决”。
- 是否明确责任边界：比如菠萝黑心、香蕉催熟不均、到货压伤、温度不达标分别怎么算。
- 是否有售后对接人和备用联系人，不能只留一个业务员微信。

**2. 用小批量试单验证响应速度**
- 先下一批小单，故意设置一个可验证的问题场景，比如要求到货后反馈温度记录、拍照留证、异常2小时内回复。
- 观察供应商是否按约定时间回复、是否主动给方案、是否推给物流或产地。
- 试单阶段就能看出它有没有售后流程，还是全靠业务员个人临时处理。

**3. 看它有没有固定的售后流程和记录**
- 是否有售后工单、异常登记表、处理台账。
- 是否能提供过往类似问题的处理记录，比如某批次菠萝黑心怎么赔、香蕉到货青硬怎么补。
- 是否愿意在送货单、对账单上标注售后处理结果，方便后续追溯。

**4. 看物流和产地配合能力**
菠萝和香蕉都属于生鲜，售后往往涉及物流、仓储、催熟环节。
- 供应商是否能协调物流方共同响应，而不是让商超自己找司机。
- 香蕉是否涉及催熟库，催熟出问题后供应商是否承认并处理。
- 菠萝是否按成熟度、规格、糖度分级发货，出现不达标是否有替换方案。

**5. 看历史合作和同行口碑**
- 问同行商超：出问题时对方多久回复、是否容易扯皮、赔偿是否到位。
- 看供应商有没有长期合作的商超客户，合作时间短、客户频繁更换的要谨慎。
- 可以要求提供近几个月的售后处理案例，注意是具体案例，不是口头保证。

**6. 设置可量化的考核指标**
合作前就约定：
- 售后首次响应时间，比如2小时内。
- 方案给出时间，比如24小时内。
- 退换补货到店时间，比如48小时内。
- 月度售后解决率、重复投诉率。
- 未达标的扣款或终止合作条件。

**7. 重点问几个具体问题**
- 如果到货菠萝黑心率超过5%，你们怎么处理？
- 香蕉到店后催熟不均，责任怎么判？
- 周末或节假日出问题，谁值班回复？
- 物流原因导致压伤，你们是否先赔再追物流？
- 上次出现类似问题是什么时候，怎么解决的？

**简单判断标准：**
- 稳定售后：合同有条款、有专人、有备用联系人、有工单记录、试单响应快、同行评价一致。
- 不稳定售后：只靠口头承诺、联系人单一、出问题就推物流或产地、没有处理记录、试单就拖延。

建议先用小批量试单加一次模拟异常反馈来验证，再决定是否扩大采购。对菠萝和香蕉这类生鲜，售后响应稳定性比单纯报价低更重要。
