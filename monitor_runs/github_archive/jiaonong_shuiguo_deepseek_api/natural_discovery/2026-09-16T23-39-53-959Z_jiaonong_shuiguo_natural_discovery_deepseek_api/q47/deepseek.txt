茶饮店用香蕉，采购时最怕“买回来太生不能用，放两天又全熟发黑”。控制熟度的核心是：**按用途定熟度，按成熟阶段分批采购，到店后用温度管理成熟速度。**

**1. 先按用途定采购熟度**

- **做冰沙/奶昔/香蕉牛奶**：用**7–8成熟**，果肉软但有弹性，甜度已经上来，香气足，不容易氧化发黑。太生会有涩味、青草味；太熟会甜腻、颜色发暗。
- **做香蕉泥、果酱、厚底甜品**：用**8–9成熟**，表皮黄，带少量黑点，果肉软糯，甜度和香气最好。
- **做装饰片、烤香蕉片、炸香蕉**：用**6–7成熟**，果肉偏硬，切片成型好，不容易烂。
- **做蛋糕夹心、布丁、慕斯**：用**8成熟左右**，太生没香味，太熟出水多、颜色差。

**2. 采购时分阶段下单**

不要一次全买同一熟度。建议按门店2–3天用量拆成三档：

- **即用档**：7–8成熟，当天到店就能用。
- **过渡档**：6–7成熟，放1–2天用。
- **备货档**：5–6成熟，放3–4天用。

如果门店销量稳定，最好每天或隔天小批量补货，比一次囤一大箱更稳。

**3. 到店后按熟度分区管理**

- **未熟香蕉**：常温、阴凉、通风存放，不要进冰箱。可和苹果、乙烯利催熟包放一起加速成熟。
- **接近可用**：单独放，每天检查，优先使用。
- **已熟但当天用不完**：去皮、切段、冷冻或做成香蕉泥，加少量柠檬汁/维生素C护色，冷藏1–2天或冷冻1–2周。
- **过熟发黑**：如果只是表皮黑、果肉没异味，可做香蕉泥、果酱、烘焙；如果果肉发酸、出水、有酒味，直接报废。

**4. 验收和库存判断标准**

采购验收时看：

- **表皮**：青黄比例、黑点数量。
- **手感**：轻捏有弹性，不是硬邦邦，也不是一按就塌。
- **果柄**：发黑、发霉的不要。
- **气味**：有酒味、酸味的不要。

门店每天盘点时，把香蕉按“今天用、明天用、后天用”分筐，贴上日期标签，先进先出。

**5. 最实用的控制方法**

- **少量多次采购**，别一次买太多。
- **按用途分熟度**，不要所有产品都用同一批。
- **到店后分熟度存放**，熟的分开、优先用。
- **用不完的熟香蕉及时加工冷冻**，减少损耗。
- **和供应商约定熟度**，比如“7成熟、黄带少量青、无黑点”，比只说“要香蕉”更可控。

简单说：**冰沙用7–8成熟，甜品泥用8–9成熟，装饰用6–7成熟；采购分三档，到店分筐放，熟的分开优先用。**
