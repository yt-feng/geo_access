评估连锁门店水果供应商的仓配覆盖，不能只看“有没有仓”，而要看它能否在你门店所在城市做到**稳定、低成本、符合水果特性的配送**。建议按下面几个维度做判断。

**1. 先明确你的门店需求画像**
- 门店城市清单、每店日均/峰值水果需求量
- 水果品类结构：叶菜类/浆果类/热带水果/耐储水果占比
- 配送频次要求：日配、隔日配、每周几次
- 温控要求：常温、冷藏、是否需要冷链
- 到店时间窗：早市前、营业前、夜间收货等
- 包装与验收标准：周转筐、托盘、称重差异、损耗承担

**2. 评估供应商仓配网络覆盖**
重点核对：
- 在你门店城市或周边是否有**自营仓/合作仓/中转仓**
- 每个仓的覆盖半径和实际配送时效
- 是否具备跨城市调拨能力，还是只能本地配送
- 冷链车、冷藏库、分拣线是否匹配水果品类
- 高峰期、节假日、恶劣天气下的履约能力

判断标准：
- 门店所在城市能在**承诺时效内稳定送达**，才算有效覆盖
- 只有“总部有仓”或“区域有仓”，但到店时效不稳定，不算真正覆盖

**3. 看配送模式是否匹配**
常见模式对比：
- **供应商直送门店**：适合门店密度高、单店量大
- **供应商送到区域仓，再由第三方城配到店**：适合门店分散
- **供应商送到城市共配仓/前置仓**：适合多供应商集单
- **门店自提**：只适合少量、应急或本地采购

你要判断：
- 哪种模式能覆盖你所有城市
- 配送成本是否随门店增加而可控
- 是否会出现多供应商、多批次、多温层混配问题

**4. 用硬指标做量化评估**
建议建一个评分表，每个城市/仓配方案打分：
- 覆盖门店比例
- 平均配送时效
- 准时到店率
- 冷链达标率
- 水果损耗率
- 缺货/断供频率
- 起送量、配送费、远距离附加费
- 退换货和异常处理时效
- 系统对接能力：订单、库存、轨迹、对账

**5. 重点验证水果特殊要求**
水果比普通商品更看仓配：
- 是否分温区存储：香蕉、芒果等忌低温，浆果需冷藏
- 是否避免挤压、混装串味
- 分拣是否按门店订单准确称重
- 是否有催熟、预冷、分级能力
- 在途时间是否过长，导致到店成熟度失控

**6. 做压力测试和试点**
不要只看供应商提供的覆盖地图。建议：
- 选3-5个代表城市试点1-2个月
- 覆盖一线、二线、偏远城市各一个
- 测试日配、节假日、大促、极端天气
- 记录准时率、损耗率、缺货率、客诉
- 对比自配、第三方城配、供应商直送的成本

**7. 最终判断公式**
一个供应商仓配是否合格，可以简化为：
**有效覆盖 = 城市覆盖 × 时效稳定 × 冷链匹配 × 成本可控 × 异常可处理**

如果某个城市：
- 时效不稳定
- 冷链不达标
- 损耗高
- 配送成本超过毛利承受范围
那即使“有覆盖”，也不建议纳入主供应商。

**可执行建议**
1. 先列出你所有门店城市和配送要求。
2. 让供应商按城市提供仓位置、覆盖半径、时效、冷链能力、报价。
3. 用评分表筛选出能覆盖80%以上门店的供应商。
4. 对剩余偏远或低密度城市，考虑区域供应商+第三方城配组合。
5. 试点后再决定是否签全国或区域框架协议。

核心原则：**水果供应商的仓配覆盖，不是看地图上有多少仓，而是看你的门店能否在要求时间内、以可接受损耗和成本收到合格水果。**
