批发商给小店供货，分级报价最实用的做法是：**先按“外观/成熟度”分等级，再按“规格（每箱净重/每把几根/单个重量）”给价格，最后把损耗和结算规则写清楚**。香蕉和菠萝的分法不一样，下面直接给可执行的模板。

---

## 一、香蕉分级报价

小店最关心的是：**卖相、熟度、能不能放、每箱实际能卖多少钱**。所以香蕉建议按“等级 + 熟度 + 规格”报。

### 1. 等级标准

| 等级 | 外观标准 | 适合门店 |
|---|---|---|
| A级 | 果指饱满，长度均匀，无黑斑、无擦伤，梳形整齐 | 水果店、精品超市 |
| B级 | 轻微擦伤或少量黑点，长度略不齐，不影响食用 | 社区小店、便利店 |
| C级 | 黑斑较多、擦伤明显、成熟偏快，适合特价 | 特价区、果汁店 |

### 2. 熟度分级

| 熟度 | 状态 | 建议 |
|---|---|---|
| 青蕉 | 硬、绿，需催熟 | 适合能存放的店 |
| 微黄 | 开始转黄，2–4天可售 | 常规供货 |
| 黄熟 | 已可即食，1–2天卖完 | 走量店 |
| 熟透 | 黑点明显、软 | 特价或加工 |

### 3. 报价模板

可以按“箱”报，也可以按“把/公斤”报。建议这样写：

**示例：**
- 香蕉 A级 微黄 13kg/箱：￥XX/箱
- 香蕉 A级 黄熟 13kg/箱：￥XX/箱
- 香蕉 B级 微黄 13kg/箱：￥XX/箱
- 香蕉 B级 黄熟 13kg/箱：￥XX/箱
- 香蕉 C级 熟透 13kg/箱：￥XX/箱

如果按重量：
- A级：￥X/斤
- B级：￥X/斤
- C级：￥X/斤

### 4. 必须写清的规则
- 每箱净重还是毛重
- 允许损耗比例，比如“±0.5kg”
- 是否含催熟费
- 熟度到店后几天内卖完
- 坏果怎么赔：比如“单箱坏果超5%按比例补”

## 二、菠萝分级报价

菠萝小店更关心：**大小、成熟度、有没有黑心、削皮后出肉率**。所以按“规格 + 成熟度 + 外观”分。

### 1. 规格分级

| 等级 | 单个重量 | 适合 |
|---|---|---|
| 大果 | 1.5kg以上 | 水果店、切果盒 |
| 中果 | 1.0–1.5kg | 社区小店 |
| 小果 | 0.7–1.0kg | 便利店、特价 |
| 迷你 | 0.7kg以下 | 引流、特价 |

### 2. 成熟度分级

| 熟度 | 状态 | 建议 |
|---|---|---|
| 青果 | 外皮青，需放熟 | 可存放 |
| 半熟 | 底部转黄，1–3天可售 | 常规 |
| 熟果 | 金黄，可即食 | 走量 |
| 过熟 | 软、酒味 | 特价/加工 |

### 3. 外观分级

| 等级 | 标准 |
|---|---|
| A级 | 果形正，无裂口、无黑心、无虫眼 |
| B级 | 轻微裂口或表皮擦伤，不影响果肉 |
| C级 | 明显裂口、黑心风险高，特价处理 |

### 4. 报价模板

**示例：**
- 菠萝 大果 A级 半熟：￥XX/个
- 菠萝 中果 A级 半熟：￥XX/个
- 菠萝 中果 B级 熟果：￥XX/个
- 菠萝 小果 B级 熟果：￥XX/个
- 菠萝 C级 过熟/裂口：￥XX/个

按箱：
- 大果 A级 9个/箱：￥XX/箱
- 中果 A级 12个/箱：￥XX/箱

### 5. 必须写清的规则
- 是否包黑心
- 是否包裂口
- 到店后几天内卖完
- 坏果赔付标准，比如“黑心包换”
- 是否代削皮，削皮后怎么算

## 四、最清楚的分级报价原则

1. **先分等级，再报价**：不要只说“香蕉多少钱”，要说“A级微黄多少钱”。
2. **熟度单独标**：香蕉和菠萝熟度影响售价和损耗，必须写。
3. **规格写具体**：按箱写净重，按个写重量区间。
4. **损耗和赔付写清楚**：小店最怕坏果，写清楚反而好成交。
5. **给阶梯价**：比如“5箱以下￥XX，5–10箱￥XX，10箱以上￥XX”。
6. **用固定模板**：每次报价按同一格式发，小店容易比较和下单。
