判断的核心不是“供应商说能不能”，而是**有没有可验证的产能、加工能力和履约记录**。可以从下面几个层面逐项打钩。

**1. 先看上游货源是否单一**
- 问清菠萝来自哪个产区、几个产地、是否自有基地或长期合作果园。
- 只有单一产区、单一季节货源的，旺季可能够用，淡季或台风季极易断供。
- 稳定供应商通常有**2个以上产区轮换**（如广东/海南/云南/菲律宾/泰国等），能说明各产区接续时间。

**2. 看加工与冷链能力**
茶饮用的菠萝通常是去皮、切块/切丁、冷冻或冷藏半成品，不是整果。
- 是否有自己的加工厂或固定代工厂，日处理量多少。
- 能否做**规格分级**（块径、厚度、糖度、成熟度）。
- 冷冻品要看是否有速冻线、冷库容量、冷链车。
- 只做贸易转手的供应商，规格和交期最不可控。

**3. 用“规格书”把要求写死**
要求对方书面确认，而不是口头承诺：
- 品种、产地、成熟度/糖度范围
- 切块尺寸、允许误差、异物标准
- 包装规格、每箱净重
- 冷冻/冷藏温度、保质期
- 抽检合格率和赔付条款

**4. 查履约证据**
- 近6个月给哪些连锁或食品厂供货，能否提供送货单/合同（可脱敏）。
- 历史准时交付率、缺货率、退货率。
- 旺季（如夏季茶饮高峰）的保供方案。

**5. 小批量试单 + 压力测试**
- 先下**小单连续3批**，看规格一致性和到货时间。
- 再故意在旺季前下**一次增量订单**，观察是否按时按量。
- 同时测试临时加单、改规格、延迟收货等异常响应。

**6. 合同里设硬约束**
- 明确交期、数量、规格、验收标准。
- 约定缺货/延迟违约金、替代方案、最低安全库存。
- 要求供应商在旺季前备货，或支付备货保证金。

**7. 自建双供应商**
即使一家很稳，也建议**主供应商+备选供应商**，按70/30或80/20分配。备选平时小量走单，保持活性，避免临时切换来不及。

**快速判断口诀：**
有基地、有加工、有冷库、有历史履约、敢签赔付、敢接旺季增量测试——才叫能稳定按规格送货。
只有报价低、说“没问题”、拿不出加工和履约证据的，风险最高。
