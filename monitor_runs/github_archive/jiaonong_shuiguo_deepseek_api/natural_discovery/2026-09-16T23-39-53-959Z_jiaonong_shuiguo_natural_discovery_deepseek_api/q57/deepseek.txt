多数餐饮连锁采购水果，**更推荐中央厨房/区域配送中心统一收货，再统一分拣、分级、配送至门店**；但前提是水果品类、冷链能力、门店密度和损耗管理跟得上。若门店分散、单店用量小、水果保质期极短或门店有强现场加工需求，则可对部分品类采用“门店直收”作为补充。

下面按判断维度给你可执行建议。

## 一、优先中央厨房统一收货的情况

适合：

- 门店数量多，单店水果用量稳定但不大
- 水果用于统一产品，如沙拉、果茶、甜品、拼盘
- 需要统一规格、成熟度、糖度、切配标准
- 有冷藏/冷链车辆和分拣场地
- 总部想控采购价、控供应商、控食安

优点：

1. **采购议价更强**  
   总部集中下单，量大，价格和账期更好谈。

2. **品质标准统一**  
   可统一验收糖度、规格、成熟度、瑕疵率，避免各店标准不一。

3. **食安和溯源更可控**  
   供应商资质、检测报告、批次追溯集中在中央厨房，风险更低。

4. **减少门店收货压力**  
   门店不用每天验货、称重、退货、对账，店长精力回到运营。

5. **降低门店腐败和串货空间**  
   统一收货能减少门店私自换供应商、虚报损耗等问题。

6. **便于加工和分级**  
   中央厨房可做清洗、切配、分装、催熟、分级，再按门店需求配送。

缺点：

1. **增加一次搬运和冷链成本**
2. **对中央厨房保鲜和分拣能力要求高**
3. **配送频次不够时，水果新鲜度可能下降**
4. **门店临时缺货、突发用量调整不灵活**

## 二、适合门店分开收货的情况

适合：

- 水果保质期极短，如草莓、蓝莓、鲜切果、部分热带水果
- 门店单店用量大，且每天需要多次补货
- 门店有现场加工、现切、现榨需求
- 门店密度低、配送成本高
- 中央厨房距离远，配送后反而更不新鲜
- 某些地方特色水果需要本地采购

优点：

1. **补货快，新鲜度可能更好**
2. **门店可灵活调整品种和数量**
3. **减少中央厨房分拣和二次配送压力**
4. **适合本地化采购和应急采购**

缺点：

1. **采购价格分散，议价弱**
2. **验收标准不统一，品质波动大**
3. **门店收货、对账、退货工作量大**
4. **食安追溯和供应商管理难度高**
5. **容易产生飞单、虚报损耗、私采**

## 三、更优的常见模式：混合采购

实际连锁餐饮里，通常不是二选一，而是：

### 1. 核心水果统一收货
如苹果、橙子、柠檬、西瓜、哈密瓜、火龙果等耐储或标准品，由中央厨房统一采购配送。

### 2. 易损短保水果门店直收或区域直配
如草莓、蓝莓、树莓、鲜切果、部分叶菜类水果，由区域供应商直送门店，总部定供应商、定价格、定标准。

### 3. 总部控供应商和价格，门店只负责验收
即使门店收货，也应：
- 总部签框架协议
- 统一验收标准
- 门店拍照上传收货
- 系统录入批次和损耗
- 总部抽查和飞检

## 四、怎么判断你们该选哪种？

可以用这几个问题快速判断：

1. **水果是否用于统一标准产品？**  
   是，优先中央厨房统一收货。

2. **单店日均水果用量是否足够大？**  
   大，可考虑门店直收；小，统一收货更划算。

3. **水果是否短保易损？**  
   是，门店直收或区域直配更合适。

4. **中央厨房到门店配送是否能在24小时内完成？**  
   能，统一收货可行；不能，慎用。

5. **门店是否有冷链暂存条件？**  
   没有，统一配送按需到店更稳。

6. **总部是否具备强供应商管理和系统验收能力？**  
   有，混合模式最好；没有，先统一收货。

## 五、建议方案

如果你问的是“一般餐饮连锁怎么选”，我的建议是：

**主模式：中央厨房/区域配送中心统一收货 + 门店按需配送。**  
**补充模式：短保易损水果由总部指定供应商直送门店。**  
**底层原则：总部统一供应商、统一价格、统一标准、统一追溯，门店只执行验收和使用。**

这样既能拿到集中采购的规模和食安优势，又能保留短保水果的灵活性。

如果你能补充：门店数量、城市分布、水果品类、是否有中央厨房和冷链、单店日均用量，我可以帮你判断具体哪些水果走统配、哪些走直送。
