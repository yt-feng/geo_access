社区超市卖小包装香蕉，核心不是“把香蕉分小”，而是要把采购、催熟、分装、陈列、折价串成一条损耗可控的链路。下面按你实际能执行和判断的点来说。

## 1. 先定包装形态，再倒推采购

小包装常见有三种，损耗和操作难度不同：

- **整根单支装**：适合1-2人即食。损耗最低，但客单低。
- **2-3根一把装**：最推荐社区店。兼顾即食和家庭，分装快，损耗可控。
- **净果切段/盒装**：损耗最高，必须冷藏，适合写字楼或年轻客群，社区店慎做。

采购时要先问供应商：**能不能按“小把”或“小串”供货**。如果只能整箱大串进，就要自己分装，那损耗和人工都要算进去。

## 2. 采购时重点看什么

- **成熟度**：不要采全黄熟。社区店周转慢，建议采“微黄带青”或“青黄交接”，到店后能放2-3天再转黄。
- **果指粗细和长度**：小包装适合选中等偏小果指，太粗太长一根就饱，不好卖；太细显得品质差。
- **串型完整度**：优先整串、无断指、无裂口。断指和裂口果只能做折价或切段，别当正常小包装卖。
- **表皮状态**：无黑斑、无压伤、无冻伤。香蕉对低温很敏感，运输中如果受过冷，到店后会发黑不转黄。
- **箱内成熟度一致性**：一箱里如果有的青有的黄，分装后成熟节奏不一致，损耗会明显上升。

## 3. 包装上要注意的细节

- **不要密封死**：香蕉会释放乙烯，密封袋里容易闷熟、出水、发黑。用带孔袋、开口袋或透气膜。
- **标签别贴果皮**：价签贴果柄或包装袋上，贴果皮撕下来会伤表皮，很快发黑。
- **分装时间**：最好在香蕉还偏青时预分装，而不是等全黄再分。全黄后分装、搬动、贴标都会增加压伤。
- **单包重量**：社区店建议控制在300-500克/包。低于300克客单太低，高于500克又失去“小包装”意义。
- **陈列方式**：不要堆叠重压。用浅筐、阶梯陈列或悬挂，减少压伤。
- **温度**：香蕉不宜冷藏。短期陈列在12-15℃左右较稳，夏天避免空调直吹和阳光直射。

## 4. 损耗控制的关键动作

- **先进先出**：每天开门先检查前一天的黄熟包，优先陈列或折价。
- **分级销售**：微青做正常价，全黄做即食推荐，起黑斑的做折扣包或切段，不要混在一起卖。
- **少量多次分装**：一次别分太多。按当天预估销量的1.2倍分装，卖完再补。
- **记录损耗率**：按“进货重量 - 售出重量 - 折价重量”算。小包装香蕉如果损耗超过8%-10%，就要调整采购成熟度或分装量。
- **和供应商谈退换/补损**：尤其是夏季或远途运输，争取到货后24小时内可报损补货。

## 5. 采购量怎么估

社区店可以先按这个逻辑试：

- 先试销3-5天，记录每天小包装卖出多少包、什么时间段卖得快。
- 首单不要大进，按平时香蕉销量的60%-70%换算成小包装试。
- 如果下午6点后还剩超过30%，第二天就减少采购或提前折价。
- 如果上午就卖空，再逐步增加，但不要一次加太多，香蕉成熟速度很快。

一句话：**小包装香蕉的利润不在售价，而在损耗控制。采购时优先选成熟度可控、串型完整、能小串供货的货；包装要透气、轻拿轻放、先进先出；卖不动就及时折价，不要等全黑再处理。**
