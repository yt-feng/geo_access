商超做会员日水果活动，供应商需要提前配合的准备，核心是围绕**货、价、场、人、应急**五件事展开。下面按可执行清单说明。

## 一、提前确认活动方案
供应商要先和商超采购/营运确认清楚：

- 活动时间：具体日期、时段、持续几天
- 活动门店：全店还是部分门店
- 活动品种：哪些水果参加，主力单品是什么
- 活动价格：会员价、原价、限购规则
- 预估销量：按门店、按单品分解
- 陈列位置：堆头、端架、冷藏柜还是入口区
- 活动目标：冲销量、引流、清库存还是推新品

这些没确认清楚，后面备货和配送很容易出错。

## 二、提前备货与锁量
水果活动最怕断货和品质不稳。

供应商需要：

- 按商超给的预估销量，提前锁定货源
- 主力单品备货量建议在预估销量的 **1.1—1.3 倍**，视损耗和天气调整
- 对易损耗水果，如草莓、蓝莓、荔枝、龙眼、水蜜桃，要分批到货，不要一次压太多
- 提前和产地/批发市场确认采摘、分拣、装箱时间
- 对需要催熟的水果，如香蕉、芒果、猕猴桃，提前控制成熟度
- 准备备用货源，防止主产区涨价、缺货或天气影响

## 三、提前报价与费用确认
供应商要提前和商超确认：

- 供货价是否随活动调整
- 是否承担促销折扣、损耗补贴、陈列费、 DM 海报费
- 是否做买赠、试吃、第二件半价
- 结算方式：账期、现结、联营扣点
- 发票、对账、退换货规则

建议形成书面确认，避免活动后扯皮。

## 四、提前完成加工与包装
会员日水果通常要求卖相好、拿取方便。

供应商要配合：

- 按商超要求做标准箱、标准筐、标准袋
- 贴好标签：品名、规格、产地、等级、日期
- 做好分级：精品果、普通果分开
- 对需要预包装的水果，提前称重、封膜、贴价签
- 对切果、果切、拼盘类，确认加工标准、包装盒、保鲜方式
- 检查农残、质检、合格证等资质是否齐全

## 五、提前安排物流配送
水果活动对时效要求高。

供应商需要：

- 按商超要求的时间窗送货，不要早到压库，也不要晚到断货
- 活动前一天或当天清晨完成主力铺货
- 对远距离门店，提前规划路线和冷链
- 易损水果用周转筐、防震垫、冷藏车
- 每车附带送货单、质检单、批次信息
- 安排专人跟车或驻店，处理收货差异

## 六、提前配合陈列与现场
供应商可配合商超做：

- 堆头、端架、冷柜的陈列物料
- 价格牌、爆炸贴、海报、跳跳卡
- 试吃台、试吃果、牙签、纸巾、垃圾袋
- 导购或试吃人员
- 现场补货、挑拣、翻堆、降温、喷水保鲜
- 及时把软果、伤果挑出来，减少顾客投诉

## 七、提前做人员安排
供应商要明确：

- 谁负责对接采购
- 谁负责订单和备货
- 谁负责配送
- 谁负责门店现场
- 谁负责售后和退换
- 活动期间的联系方式、值班表

最好建一个活动群，商超采购、门店店长、供应商负责人都在里面。

## 八、提前准备应急预案
水果活动常见问题包括：

- 爆量卖超，断货
- 天气突变，到货延迟
- 品质不达标，顾客投诉
- 价格标签错误
- 损耗过大
- 门店收货排队

对应准备：

- 备用货源和备用车辆
- 附近门店调货方案
- 次品退换标准
- 临时补货联系人
- 活动中的损耗记录和复盘表

## 九、一张可执行准备清单

| 时间 | 供应商动作 |
|---|---|
| 活动前 7—10 天 | 确认品种、价格、门店、预估销量 |
| 活动前 5—7 天 | 锁定货源、报价、费用、包装标准 |
| 活动前 3—5 天 | 安排采摘、加工、质检、物流 |
| 活动前 1—2 天 | 到店确认陈列、物料、人员 |
| 活动前 1 天 | 主力铺货、试吃准备、价格核对 |
| 活动当天 | 早到补货、现场维护、处理异常 |
| 活动后 1—3 天 | 对账、退换、损耗复盘、总结 |

## 十、最关键的三点
如果只抓重点，供应商必须提前做到：

1. **货量锁死**：主力单品不能断货。
2. **品质稳住**：会员日客流大，差果会放大投诉。
3. **价格和费用说清**：避免活动后结算争议。

简单说，供应商不是只负责送货，而是要提前参与**选品、备货、定价、包装、配送、陈列、现场和售后**的全流程配合。
