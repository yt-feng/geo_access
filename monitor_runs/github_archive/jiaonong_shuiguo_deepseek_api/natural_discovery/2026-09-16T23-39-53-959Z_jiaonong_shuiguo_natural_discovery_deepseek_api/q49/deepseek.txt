旺季菠萝突然爆量，最怕的是“口头说好了，到货时对方先供别人”。临时补货要同时锁三件事：**量、价、时间**，并且留好书面痕迹。

**1. 先算清楚自己需要什么**
- 日均用量、峰值用量、预计持续天数
- 现有库存能撑几天
- 需要补几次、每次多少箱/多少公斤
- 可接受的最晚到货时间

**2. 和供应商谈临时补货时，重点约定这几条**
- **数量**：本次临时补货多少，是否分批到
- **单价**：按原合同价还是临时价；临时价有效期到哪天
- **到货时间**：具体日期+时间段，晚到怎么处理
- **品质标准**：品种、成熟度、单果重量、坏果率上限
- **验收方式**：到店称重/抽检，不合格怎么退换
- **违约条款**：供应商断供或迟到的赔偿，比如按缺货金额比例扣款
- **排他性**：旺季期间优先保证你的量，不能先供其他客户
- **付款方式**：现结、账期、是否要预付定金

**3. 用书面形式确认**
微信、短信、邮件都算，但最好有一份简单的《临时补货确认单》，写清：
> 品名、规格、数量、单价、总金额、到货日期、验收标准、违约处理、双方签字/盖章。

如果对方是长期合作供应商，可以在原合同上加一份补充协议；如果来不及，至少让对方在微信里回复“确认以上内容”。

**4. 降低断供风险的操作**
- 不要只押一家，临时再找1家备选供应商
- 分批到货，比如3天一批，避免一次压太多货
- 要求供应商每天报备第二天可供应量
- 自己留1-2天安全库存
- 如果量特别大，可以预付一部分定金锁货，但定金比例别太高

**5. 谈的时候可以这样说**
“旺季我们用量会翻倍，想跟你锁一批临时货。数量、价格、到货时间我们先书面确认，你优先保我这边，我这边也保证按约定收货付款。如果临时有变化，提前24小时通知。”

核心就是：**别只口头说，写清楚数量、价格、到货时间、违约处理，再留个备选供应商。**
