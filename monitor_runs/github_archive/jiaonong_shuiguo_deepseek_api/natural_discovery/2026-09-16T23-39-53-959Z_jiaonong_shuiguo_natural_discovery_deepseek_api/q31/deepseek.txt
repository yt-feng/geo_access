连锁商超水果供应商招标的评分标准，建议按“资格门槛 + 技术/商务评分”两层设计。水果品类损耗高、季节波动大、食品安全风险高，评分权重不能只压价格。

**一、先设资格门槛（不满足直接淘汰）**
- 营业执照、食品经营许可证、种植/养殖资质或合作社证明
- 近2年无重大食品安全事故、无严重违法记录
- 具备冷链仓储与配送能力（自有或稳定合作）
- 能开增值税专用发票，账期可接受
- 有商超或连锁渠道供货经验（可要求至少1—2个案例）

**二、评分表建议（总分100分）**

| 维度 | 权重 | 关键评分点 |
|---|---|---|
| 产品质量与安全 | 25—30分 | 农残检测报告、可追溯体系、分级标准、到货合格率承诺 |
| 供应稳定性 | 20—25分 | 产地/基地资源、季节替代方案、缺货应急机制、历史履约率 |
| 价格与成本 | 15—20分 | 报价竞争力、价格调整机制、账期、运费与损耗承担 |
| 冷链与物流 | 10—15分 | 冷链覆盖率、配送频次、到店时效、损耗率承诺 |
| 售后服务 | 10分 | 退换货响应、质量问题赔付、对账结算效率 |
| 企业实力与经验 | 10分 | 注册资本、合作商超案例、检测能力、团队配置 |
| 可持续与合规 | 5—10分 | 环保包装、劳动合规、产地社会责任 |

**三、几个关键设置建议**
1. **价格权重别超过20%**。水果非标品，低价往往伴随等级混装、熟度不稳、损耗转嫁。
2. **把损耗率写进评分和合同**。例如承诺到店损耗≤3%得满分，每超1%扣分，超5%可终止。
3. **设置季节性替补条款**。单一产地供应商在淡季容易断供，评分时应看其是否有跨产区调配能力。
4. **样品盲测+试供期**。招标评分之外，增加2—4周试供，按到货合格率、投诉率决定是否转正。
5. **价格调整机制要明确**。可挂钩批发市场均价或产地指数，约定调价周期和幅度上限，避免长期锁价后断供。
6. **账期与保证金**。长期供应商可要求质量保证金，账期建议30—60天，过长会推高报价。

**四、推荐权重组合（可直接用）**
- 质量安全30%、供应稳定25%、价格18%、冷链物流12%、售后8%、企业实力7%。

这样既能筛掉纯贸易商和低价搅局者，也能让真正有基地、有冷链、能长期稳定供货的供应商脱颖而出。
