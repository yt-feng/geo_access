选择适合批量配送的水果供应商，重点不是找“最便宜”，而是看它能不能稳定处理**公司下午茶这种场景**：数量中等、时间固定、多人分食、对品相和新鲜度有要求。

可以从下面几个维度判断和筛选：

**1. 先明确采购场景**
- 人数：30人、100人、300人，选法不同。
- 形式：整果、果切拼盘、独立小盒。
- 预算：按人均8元、15元、25元，供应商层级不同。
- 配送时间：必须卡在下午茶前送到，不能影响活动。
- 地点：写字楼是否允许送货上楼、是否有冷藏柜、前台能否代收。

**2. 优先找这几类供应商**
- **本地果切/下午茶配送商**：适合直接送盒装果切，省去洗切分发。
- **批发市场档口**：适合整果采购，价格低，但需要自己分装。
- **生鲜平台企业购**：如美团企业版、饿了么企业订餐、京东企业购等，流程规范，售后相对好。
- **本地水果店长期合作**：适合中小公司，灵活、可月结，但要看配送稳定性。
- **农场/基地直供**：适合大批量、长期固定采购，价格和新鲜度好，但起送量高。

**3. 重点核验供应商能力**
- **批量配送经验**：有没有服务过公司、学校、活动下午茶。
- **准时率**：能否固定时间段送达，迟到如何处理。
- **品控**：坏果率多少，是否支持拍照售后、补送或退款。
- **分装能力**：能否按人数分盒、贴标签、配叉子。
- **冷链能力**：夏天送果切、莓果、切瓜类必须有冷藏。
- **发票与结算**：能否开票、对公转账、月结。
- **食品安全**：果切类要看是否有食品经营许可证、操作间是否规范。

**4. 建议的筛选流程**
1. 先列3—5家本地候选：水果批发档口、果切店、生鲜企业购、长期合作水果店。
2. 统一发需求：人数、预算、时间、地点、是否需要分装、是否需要发票。
3. 让每家报同一套方案，比如“100人，人均15元，下午2点前送到，独立盒装”。
4. 先试单一次，不要一上来签长期。
5. 试单看四点：是否准时、水果新鲜度、分装是否整齐、售后是否爽快。
6. 试单合格后再谈长期价、账期和固定配送时间。

**5. 不同预算怎么选**
- **人均5—10元**：当季整果为主，如香蕉、橘子、苹果、小番茄，找批发档口或水果店。
- **人均10—20元**：整果+少量果切，找本地果切配送商或生鲜企业购。
- **人均20元以上**：精品果切、莓果、进口水果拼盒，找专业下午茶供应商。

**6. 避坑点**
- 不要只看报价低，低价常见问题是小果、熟过头、坏果多。
- 不要选没有固定配送团队的微商或个人，临时放鸽子风险高。
- 果切类不要选无法提供冷链和资质的。
- 合同或聊天记录里写清：送达时间、数量、规格、坏果赔付、发票、临时加单规则。
- 夏天避免大量采购易压坏的莓果、切开的西瓜，除非冷链可靠。

**简单结论：**
中小公司优先选**本地果切配送商或生鲜企业购**，省心；大批量、长期采购优先找**批发市场档口或基地直供**，成本低；无论选哪类，都先小单试配送，重点看准时、新鲜、分装和售后。
