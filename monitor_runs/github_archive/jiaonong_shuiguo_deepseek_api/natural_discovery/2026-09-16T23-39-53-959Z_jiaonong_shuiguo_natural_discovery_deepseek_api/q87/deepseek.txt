社区团购旺季爆单时，水果供应商的库存和价格都会紧张，锁定库存的关键是**提前 + 书面 + 带钱 + 有量**。可以按下面几步做：

**1. 提前锁定周期**
水果旺季通常提前 2～4 周就要开始锁货，节假日（春节、中秋、国庆）甚至提前 1～2 个月。越晚越只能拿现货价。

**2. 用预付款/定金锁量**
只口头说“我要多少”没有约束力。做法是：
- 签简单的采购意向/框架协议，写明品项、规格、数量、单价区间、交付时间；
- 支付 **10%～30% 定金**，约定供应商不得转卖该批次；
- 约定如果供应商违约，双倍返还定金；如果你违约，定金不退。这样双方都有约束。

**3. 给供应商一个“保底量 + 浮动量”**
比如：
- 保底采购 5000 箱；
- 旺季可追加 20%～30%；
- 追加部分价格按约定公式（如当日批发价 ± 固定差价）执行。
这样供应商敢给你留货，你也不会被死库存压住。

**4. 价格锁定方式选一种**
- **固定价**：适合你判断行情会涨，供应商也接受；
- **保底价 + 随行就市**：适合行情波动大，约定最高不超过某个价；
- **代销/联营**：你出渠道，供应商出货源，按实际销量分成，适合没把握的品项。

**5. 要求供应商给“优先发货权”**
在合同里写明：旺季期间，你的订单优先级高于散客和其他小客户；每天/每批次到货先满足你的保底量。

**6. 多供应商备份**
不要只锁一家。主力供应商锁 60%～70%，备用 2～3 家各锁 10%～15%。主力断供时能立刻切换，避免爆单时断链。

**7. 到货质检和损耗条款要写清**
水果损耗高，必须约定：
- 到货验收标准（甜度、大小、成熟度、坏果率）；
- 坏果率超过多少由供应商补货或扣款；
- 运输损耗谁承担。

**8. 用数据换锁货条件**
把你们的历史销量、复购率、社群人数、预测销量给供应商看，证明你不是随口要货。供应商更愿意给稳定大客户留库存。

**一句话总结：**
> **提前 2～4 周谈，付定金签书面协议，给保底量+浮动量，约定优先发货和违约条款，同时准备 2～3 家备用供应商。**
