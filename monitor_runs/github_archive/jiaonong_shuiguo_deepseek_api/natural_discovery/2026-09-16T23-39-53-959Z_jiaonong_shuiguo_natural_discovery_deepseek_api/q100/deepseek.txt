食堂采购香蕉避免熟过头，核心是把“采购—验收—存放—使用”四件事分开管，尤其不要一次全买成同一成熟度。

**1. 采购时控制成熟度**
- 优先买“青黄相接”、果柄还偏绿、手感硬的香蕉，不要买已经带黑点、果柄发黑、整串发软的。
- 分批采购：日常用量按 1—2 天消耗量买，不要一次囤一周。
- 如果供应商能分级，要求“七成熟左右”，不要混进熟果。

**2. 验收要卡标准**
- 可以按成熟度分三级：
  - 青硬：可放 3—5 天；
  - 黄硬：1—2 天内用；
  - 带黑点/软：当天必须处理。
- 验收时把熟果单独挑出来，先送厨房或先供应，不要和新果混放。

**3. 存放要分开、控温、通风**
- 香蕉不要冷藏，低温会冻伤发黑；放在阴凉、通风、避光处。
- 不要整串堆压，最好挂起来或单层摊开，减少压伤。
- 青香蕉和熟香蕉分开放；熟香蕉会释放乙烯，催熟旁边的青香蕉。
- 如果食堂有空调间或 13—15℃ 左右阴凉库，可短存；没有就少量多次买。

**4. 使用上做“先进先出”和二次加工**
- 每天先检查一遍，把最熟的挑出来当天用。
- 熟过头但没坏的香蕉可以：
  - 做香蕉奶昔、香蕉粥、香蕉饼、烘焙；
  - 切块冷冻后做冰沙；
  - 搭配酸奶、燕麦做早餐。
- 已经发黑腐烂、有异味的不要继续食用。

**5. 建立简单台账**
- 记录每天进货量、成熟度、消耗量、剩余量。
- 连续记 1—2 周，就能看出食堂每天实际需要多少，后续按量采购。
- 如果某天剩得多，第二天采购量直接减掉。

**最实用的做法：**
少量多次采购 + 验收分级 + 熟果先出 + 青熟分放 + 熟过头做加工。只要做到这五点，食堂香蕉浪费会明显下降。
