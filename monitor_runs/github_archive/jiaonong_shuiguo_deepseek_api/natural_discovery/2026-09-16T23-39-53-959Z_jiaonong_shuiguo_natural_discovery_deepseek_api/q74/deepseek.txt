批发档口想拓餐饮客户，菠萝和香蕉不要按零售思维备货，要按“餐饮后厨怎么用”来定规格。下面按品类拆开说，并给出可执行的备货优先级。

## 一、菠萝（餐饮客户主要用途：果切、饮品、烘焙、炒菜/咕咾肉、自助餐）

餐饮客户对菠萝的核心诉求是：**出肉率稳定、酸甜稳定、去皮省人工、规格统一**。

### 建议准备的规格

1. **鲜果整果（主推）**
   - 规格：单果 1.2–1.8 斤（中果）、1.8–2.5 斤（大果）
   - 用途：饮品店、果切店、自助餐、后厨现切
   - 品种优先：台农、金钻、香水菠萝（甜度高、纤维少，适合鲜食和饮品）
   - 要点：按“个头均匀度”分等级，不要大小混装。餐饮客户最怕今天大明天小，影响出杯和成本核算。

2. **去皮菠萝 / 菠萝块（高价值主推）**
   - 规格：去皮整果、切块（2–3 cm 方块）、切片（0.5–1 cm）
   - 包装：真空袋或保鲜盒，5 斤/袋、10 斤/箱
   - 用途：饮品店、果切、烘焙、食堂
   - 要点：这是拓餐饮客户的关键产品。餐饮客户愿意为“省人工、少损耗”付溢价。你要能稳定供应去皮货，比只卖整果更容易绑定客户。

3. **冷冻菠萝块 / 菠萝丁**
   - 规格：1–2 cm 丁、2–3 cm 块，1 kg/袋、10 kg/箱
   - 用途：饮品、烘焙、预制菜、炒饭
   - 要点：适合对季节波动敏感、用量大的客户。冷冻品毛利可能低，但能补淡季和稳定客户。

4. **菠萝罐头（半成品）**
   - 规格：切片、碎块、丁，按标准罐装
   - 用途：烘焙、披萨、咕咾肉、甜品
   - 要点：如果客户是连锁或标准化要求高，罐头比鲜果更稳定。你可以作为补充品类，不必主推，但要有渠道能调货。

### 菠萝备货优先级
- 第一优先：鲜果整果（中果/大果分级）
- 第二优先：去皮菠萝块/片（真空或保鲜装）
- 第三优先：冷冻菠萝丁/块
- 补充：罐头

### 报价和话术要点
- 不要只报“多少钱一斤”，要报“出肉率”和“每份成本”。
- 例如：整果 2 元/斤，出肉率 55%，则净肉成本约 3.6 元/斤；去皮块报 5 元/斤，客户一算就明白省人工。
- 问客户：你是做饮品、果切、烘焙还是炒菜？不同用途推不同规格。

## 二、香蕉（餐饮客户主要用途：果切、饮品、烘焙、早餐、食堂）

餐饮客户对香蕉的核心诉求是：**成熟度可控、大小均匀、耐存放、催熟稳定**。

### 建议准备的规格

1. **生蕉 / 青蕉（主推给需要催熟的客户）**
   - 规格：按把或按箱，单根 100–150 g、150–200 g
   - 用途：食堂、早餐、需要自己催熟的连锁客户
   - 要点：生蕉耐存放，适合客户自己控制成熟度。但你要能提供催熟指导，否则客户容易催坏。

2. **催熟香蕉（即食型，主推给果切/饮品）**
   - 规格：单根 120–180 g，成熟度 3–5 级（黄带少量绿点到全黄）
   - 用途：果切、饮品、早餐、自助餐
   - 要点：餐饮客户要的是“今天到货明天能用”，成熟度必须稳定。太生不能用，太熟损耗大。最好按“到货后 1–3 天使用”来定成熟度。

3. **小香蕉 / 小米蕉**
   - 规格：单根 50–80 g
   - 用途：果切拼盘、高端餐饮、自助餐
   - 要点：单价高、卖相好，适合做差异化，但量不一定大。

4. **冷冻香蕉 / 香蕉泥**
   - 规格：冷冻香蕉段、香蕉泥，1 kg/袋、10 kg/箱
   - 用途：饮品、烘焙、冰沙、甜品
   - 要点：适合饮品店和烘焙客户。香蕉泥能解决鲜果损耗和成熟度问题，但需要冷链。

5. **香蕉片（烘干/脆片）**
   - 用途：烘焙、零食、餐饮装饰
   - 要点：不是餐饮刚需，可作为补充。

### 香蕉备货优先级
- 第一优先：催熟香蕉（即食型，按成熟度分级）
- 第二优先：生蕉/青蕉（给能自己催熟的大客户）
- 第三优先：冷冻香蕉段/香蕉泥
- 补充：小香蕉、香蕉片

### 报价和话术要点
- 香蕉按“根”或“把”报价，比按斤更贴近餐饮客户使用习惯。
- 问客户：你是当天用、第二天用还是第三天用？根据使用时间定成熟度。
- 如果你能做催熟，这是核心优势。很多批发档口只卖生蕉，餐饮客户还要自己催，很麻烦。你能提供“催熟到指定成熟度”，客户粘性会高很多。

## 三、拓餐饮客户的通用备货策略

1. **先分客户类型，再定规格**
   - 饮品店：菠萝块、冷冻菠萝丁、香蕉泥、催熟香蕉
   - 果切店：去皮菠萝、催熟香蕉、小香蕉
   - 烘焙店：菠萝丁、香蕉泥、罐头
   - 食堂/自助餐：整果菠萝、催熟香蕉、按份规格
   - 炒菜/预制菜：菠萝块、冷冻菠萝丁

2. **样品先行**
   - 不要一上来就压货。先送样品：去皮菠萝块 1 袋、催熟香蕉 1 把、冷冻菠萝丁 1 袋。
   - 让客户实测出杯、出餐、损耗，再谈长期供应。

3. **规格标准化**
   - 菠萝：按单果重量分 2–3 级，去皮块按 cm 规格。
   - 香蕉：按单根重量和成熟度分级。
   - 餐饮客户最怕“这批和上批不一样”，标准化比低价更重要。

4. **算账给客户看**
   - 菠萝：整果价 + 出肉率 + 人工 = 净肉成本；对比去皮块报价。
   - 香蕉：生蕉价 + 催熟损耗 + 时间 = 即食蕉成本；对比催熟蕉报价。
   - 客户只要觉得你帮他省事、省钱、稳定，就会长期合作。

## 四、最小可执行起步清单

如果你现在就要备货，建议先按这个清单：

**菠萝**
- 鲜果整果：中果 1.2–1.8 斤，大果 1.8–2.5 斤，各备一批
- 去皮菠萝块：2–3 cm，真空 5 斤/袋
- 冷冻菠萝丁：1–2 cm，1 kg/袋

**香蕉**
- 催熟香蕉：单根 120–180 g，成熟度 3–5 级
- 生蕉/青蕉：单根 100–200 g，按箱
- 冷冻香蕉段或香蕉泥：1 kg/袋

先拿这些去跑 5–10 家目标餐饮客户，送样、问用途、记反馈，再决定主推哪几个规格。不要一次性把所有规格都压满，按客户反馈逐步加。
