连锁超市和水果供应商签年度合同，最容易踩坑的地方集中在“价格机制、损耗归属、验收标准、账期与返利、履约弹性”这几块。下面按风险高低列出常见坑点和可执行建议。

**1. 价格条款：只锁年度价，或只写“随行就市”**
- 坑：水果价格波动大，锁死全年价供应商可能毁约或降质；只写随行就市，超市又失去成本可控性。
- 建议：采用“基准价+浮动机制”。约定以某权威批发市场/指数周均价为基准，设涨跌触发带（如±5%内不动，超出部分按比例分担），并明确调价频率、生效时间和书面确认方式。

**2. 损耗与验收：责任边界模糊**
- 坑：只写“按国家标准验收”，但水果没有统一可操作标准；损耗率、拒收后的处理、运输途中腐烂归属不清。
- 建议：附《品类验收标准表》，按品种写清糖度、单果重、色泽、机械伤比例、成熟度。明确到货验收时限（如卸货后2小时内），验收前损耗由供应商承担，验收后由超市承担；约定拒收品的退换、折价或就地处理规则。

**3. 账期与返利：口头承诺不入合同**
- 坑：账期、进场费、条码费、节庆费、返利只口头说，年底对账扯皮；返利基数是否含税、是否含促销折让不清。
- 建议：所有费用写进合同附件，明确计算基数、税率、结算周期和支付方式。返利条款要写“以含税/不含税进货额为基数”“退货部分是否冲减返利”。

**4. 最低采购量与独家条款：把自己绑死**
- 坑：承诺年度最低采购量，但没写市场变化时的调整机制；签独家后供应商断货或涨价，超市无替代。
- 建议：最低量设为“预估量”而非硬性承诺，或约定完成率区间（如80%–120%）内互不追责。独家条款要加“断供、质量不达标时超市可临时外采且不违约”。

**5. 履约与违约：只罚供应商，不写自己**
- 坑：违约条款单方面苛刻，供应商可能拒签或在质量上找补；缺不可抗力、政府管控、极端天气的处理。
- 建议：双向对等约定违约责任，明确迟延交货、质量不达标、擅自涨价的赔偿标准；不可抗力要具体列举并约定通知期限和减损义务。

**6. 季节性品种与替代：合同覆盖不全**
- 坑：年度合同只列常规品种，旺季爆品、临时补货没价格依据，容易临时被抬价。
- 建议：设“动态品类清单”，约定新增品种的定价流程和最惠价格条款，即供应商给超市的价格不高于同期给同区域同级客户的价格。

**7. 食品安全与追溯：出事后责任不清**
- 坑：只写“符合食品安全法”，但农残超标、批次追溯、召回费用谁承担没写。
- 建议：要求每批次提供检测报告或合格证，约定追溯时限和召回配合义务，明确因供应商原因导致的罚款、赔偿、下架损失由其承担。

**8. 合同期限与退出：到期自动续约埋雷**
- 坑：写“到期自动续约一年”，想换供应商时发现已自动续上。
- 建议：改为到期前60天双方书面确认是否续约，未确认则终止；约定提前解约条件和过渡期供货义务。

**一句话总结**：水果年度合同的核心不是“锁价”，而是把价格浮动、验收损耗、费用返利、履约弹性这四件事写成可执行的规则。签约前最好让采购、财务、法务一起过一遍附件，尤其是验收标准和费用清单。
