# 普通水果 vs 品牌水果：毛利与复购差异

## 一、毛利率：普通水果通常更高，但要看品类

**普通/散装水果（无品牌溢价）**
- 毛利率一般在 **20%–35%**，走的是"低进低出、靠周转赚钱"。
- 优势：采购价低、定价灵活，可以做"引流款"（如9.9元3斤）。
- 风险：损耗率高（15%–30%），一旦滞销直接吃掉毛利。

**品牌水果（如佳沛奇异果、都乐香蕉、褚橙等）**
- 毛利率通常 **10%–25%**，甚至更低，因为进价透明、消费者会比价。
- 优势：损耗相对可控（标准化分选、耐储存），周转稳定。
- 劣势：价格被品牌方和电商锚定，你很难加价。

> 结论：**单看毛利率，普通水果占优；看"毛利额×周转×损耗"后的净毛利，品牌水果未必差。**

---

## 二、复购：品牌水果更稳，普通水果更靠运营

| 维度 | 普通水果 | 品牌水果 |
|---|---|---|
| 复购驱动力 | 价格、新鲜度、门店体验 | 品牌信任、品质稳定、送礼场景 |
| 复购稳定性 | 波动大，看当期性价比 | 稳定，认牌子就买 |
| 客群 | 价格敏感、日常刚需 | 品质敏感、中高收入、送礼 |
| 拉新 | 容易（低价诱饵） | 较难（价格无优势） |
| 留存 | 难，容易流失到更便宜的渠道 | 易，形成"指定购买" |

**关键点：**
- 普通水果复购靠**"每次都要赢"**——今天不新鲜、明天贵了，客户就走。
- 品牌水果复购靠**"认知锁定"**——客户认佳沛就只买佳沛，你不卖他去别处。

---

## 三、实操建议（可直接执行）

1. **组合策略，别二选一**
   - 普通水果做**引流+走量**，贡献客流和基础毛利。
   - 品牌水果做**利润稳定器+信任背书**，提升客单价和复购。

2. **按角色分配SKU**
   - 引流款（普通）：占比约60%–70%的陈列面积，定价贴近市场最低。
   - 利润/信任款（品牌）：占比20%–30%，突出正品、产地、规格。

3. **用数据判断，而非感觉**
   - 每周记录每个SKU的：**进价、售价、损耗率、动销天数、复购次数**。
   - 计算真实毛利 = 售价 − 进价 − 损耗成本 − 人工分摊。
   - 淘汰"高毛利但高损耗+低复购"的伪赚钱品。

4. **普通水果要控损耗**
   - 小批量高频补货，宁可缺货别压货。
   - 临期做果切、果汁、特价，止损而非硬扛。

5. **品牌水果要拿授权/稳定货源**
   - 正品渠道才能支撑复购和口碑，串货短期便宜但伤客。
   - 可搭配"品牌+自有分装"提升溢价。

---

## 四、一句话总结

**普通水果：高毛利、高损耗、复购靠运营，适合引流走量。**
**品牌水果：低毛利、低损耗、复购靠信任，适合稳客提价。**
**最优解是两者搭配，用普通水果拉人、用品牌水果留人。**
