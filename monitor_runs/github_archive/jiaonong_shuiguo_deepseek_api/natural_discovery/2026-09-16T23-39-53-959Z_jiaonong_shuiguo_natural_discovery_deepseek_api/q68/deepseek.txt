判断供应商能不能按时到车，核心不是听他怎么说，而是看他“有没有货、有没有车、有没有履约记录”。可以从下面几个可操作的维度去核。

**一、先看硬条件：货和车是否已经落实**

1. **问具体产地和装车点**
   - 不要只听“广西香蕉”“云南香蕉”，要问到县、乡镇甚至代办名字。
   - 如果供应商说不清具体装货位置，大概率货还没定死。

2. **问装车时间**
   - 要求给出具体时间点，比如“今天下午4点装车”，而不是“这两天发”。
   - 装车时间越模糊，到车风险越大。

3. **问车牌或司机电话**
   - 真正有车的供应商，通常能提供车牌号、司机电话或物流单号。
   - 如果一直说“车在安排”“马上找车”，说明运力还没落实。

4. **问是否已付定金给果农/代办**
   - 供应商如果已经给产地付了定金或全款，货被放鸽子的概率会低一些。
   - 如果他自己都还没锁货，你的到车时间就没有保障。

**二、看履约记录和合作历史**

1. **老供应商看历史准点率**
   - 过去5次到车，有几次准时、几次延迟、延迟原因是什么。
   - 偶尔因天气延迟正常，经常性延迟就要警惕。

2. **新供应商要查背景**
   - 问同行、市场档口、产地代办是否认识他。
   - 让他提供最近几车的装车视频、过磅单、司机联系方式。
   - 如果连一车真实记录都拿不出来，不建议直接打大额定金。

3. **看是否愿意签简单协议**
   - 哪怕微信确认也行：品种、数量、质量标准、装车时间、到车时间、车牌、违约责任。
   - 愿意明确写违约责任的，通常更靠谱；一味催你打款、不愿写时间的，风险高。

**三、用“时间节点”倒推风险**

假设你要求明天早上到车：

- **今天上午**：供应商应已确定产地、代办、装车点。
- **今天中午前**：应能给出车牌或至少确定车型、司机。
- **今天下午**：应开始装车，并能发装车视频。
- **今天晚上**：车应已上高速，能提供位置或司机电话。
- **明天凌晨到早上**：正常到车。

如果到了今天下午还说“正在找车”“果还没摘”，基本不可能按时到。

**四、要求关键证据**

可以让供应商提供：

- 装车视频，最好带时间、地点、车牌；
- 过磅单或装箱数量；
- 司机电话，直接和司机确认位置；
- 高速通行记录或定位截图；
- 产地代办电话，必要时侧面核实。

注意：视频和过磅单也可能造假，最好和司机、代办交叉验证。

**五、付款方式上控制风险**

1. **不要一次性全款**
   - 常见做法：先小额定金，装车后付部分，到车验货后付尾款。
   - 如果供应商坚持全款才发车，要衡量他的可信度。

2. **定金比例别太高**
   - 新供应商尤其要控制定金，避免货没到、钱难追。

3. **约定延迟处理**
   - 比如延迟几小时怎么扣款，超过多久可以拒收，烂货、次货怎么赔。
   - 口头说没用，微信文字确认也有一定作用。

**六、几个高风险信号**

- 价格明显低于市场价，还催你快打款；
- 说不清产地、代办、装车点；
- 一直不给车牌、司机电话；
- 装车视频模糊、重复用旧视频；
- 每次都说“马上装”“明天一定到”，但从没准过；
- 要求全款、私账、不可追溯付款。

**七、实操建议**

你可以直接这样问供应商：

1. 货在哪个县哪个镇？代办是谁？
2. 今天几点装车？装车点具体在哪？
3. 车牌号多少？司机电话多少？
4. 现在货是否已经定好？给果农付了多少定金？
5. 能不能发装车视频和过磅单？
6. 如果明早到不了，怎么赔？

如果这几个问题对方回答含糊，或者关键信息给不出来，就不要把到车时间押在他身上。最稳的办法是：**新供应商小单试合作，老供应商也保留备选货源，定金别给太重。**
