优先谈 **账期**，但前提是你已经确认这家供应商在 **配送稳定性和售后响应** 上没有硬伤。更准确的排序是：

**先保配送 → 再谈账期 → 最后抠售后条款。**

原因是这三项的性质不同：

1. **配送最值得优先确认，但通常不是“谈”出来的，而是“筛”出来的**  
   水果是生鲜，配送不稳会直接导致损耗、缺货、客诉。  
   如果长期合作供应商经常晚到、漏送、品质波动大，账期再长也没意义。  
   所以第一步不是压价，而是把配送标准写清楚：  
   - 下单截止时间  
   - 送达时间窗口  
   - 缺货/漏送怎么补  
   - 冷链/温控要求  
   - 旺季和节假日的保供能力  

2. **账期最值得优先谈，因为它直接影响现金流**  
   在配送和售后基本可靠的前提下，账期是长期合作里最能改善你经营杠杆的条款。  
   建议优先争取：  
   - 从现结/周结改到 **15天、30天**  
   - 设置 **阶梯账期**：月采购量达到某档，账期延长  
   - 明确 **对账日、开票日、付款日**，避免“账期30天”变成“货到后45天”  
   - 逾期付款是否影响供货，也要写清  

   但要注意：如果对方是小供应商或资金紧张，硬压账期可能导致他优先供别人、品质下降，甚至断供。所以账期要跟采购量、合作稳定性绑定谈。

3. **售后最值得“固化”，但优先级略低于前两项**  
   水果售后常见争议是：磕碰、腐烂、规格不符、重量短缺。  
   售后如果只靠口头承诺，后面很容易扯皮。  
   重点不是谈得多优惠，而是谈得可执行：  
   - 收货后几小时内可报损  
   - 需要提供照片/视频/称重凭证  
   - 补货、退款、下次抵扣选哪种  
   - 损耗率在多少以内不赔，超过怎么赔  
   - 是否包退换运费  

**实操建议：**
- 如果这家供应商配送已经稳定，**第一优先谈账期**。
- 如果配送偶尔出问题，**先把配送考核和售后赔付绑定进合同，再谈账期**。
- 如果只能谈一项，选 **账期**，因为配送和售后可以通过换供应商、加备份供应商来解决，账期直接决定你的现金流。
- 最理想是一起谈：**“我承诺稳定采购量，你给30天账期 + 固定配送时效 + 明确售后赔付。”**

一句话：**配送决定能不能合作，账期决定合作值不值，售后决定合作久不久。长期合作里，先谈账期，但必须把配送和售后写成可执行条款。**
