超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果种类、采购渠道和超市自身的要求：

**一、基本资质与进货证明**
1. **营业执照**：供应商的合法经营资质。
2. **食品经营许可证**（或食品流通许可证）：销售食品的法定许可。
3. **供货合同或订单**：明确品名、数量、批次、价格等。
4. **发票或送货单**：作为进货凭证，便于追溯。
5. **产地证明或采购凭证**：证明水果来源，如产地证明、收购凭证、批发市场单据等。

**二、质量与安全检测报告**
1. **农药残留检测报告**：最常见且核心，通常要求符合GB 2763《食品安全国家标准 食品中农药最大残留限量》。
2. **重金属及污染物检测报告**：如铅、镉等，依据GB 2762。
3. **食品添加剂检测报告**：如保鲜剂、蜡等使用情况。
4. **微生物检测报告**：针对即食或易腐水果，如沙门氏菌、大肠菌群等。
5. **植物检疫证书**：跨区域调运或进口水果时可能需要，防止病虫害传播。
6. **进口水果还需**：海关入境货物检验检疫证明、报关单等。

**三、特定情形下的额外要求**
1. **有机/绿色/无公害认证**：若宣称相应等级，需提供有效认证证书。
2. **地理标志产品**：需提供相应授权或证明。
3. **批次检测报告**：超市通常要求每批次或定期提供，而非仅一份长期报告。
4. **供应商自检或第三方检测**：大型超市往往要求CNAS/CMA认证机构出具的检测报告。

**四、实际操作建议**
- **提前确认超市要求**：不同超市（如永辉、沃尔玛、盒马）标准不同，有的要求每批次检测，有的接受定期报告。
- **保留追溯链条**：从产地到货架的完整记录，便于问题产品召回。
- **关注时效性**：检测报告通常有有效期（如半年或一年），过期需重新检测。
- **电子化存档**：便于快速提供和查验。

**总结**：核心是“资质+进货凭证+农残检测报告”，进口水果加检疫证明，特殊认证加对应证书。建议供应商在合作前直接向超市采购部门索取《供应商准入清单》，按清单准备最稳妥。
