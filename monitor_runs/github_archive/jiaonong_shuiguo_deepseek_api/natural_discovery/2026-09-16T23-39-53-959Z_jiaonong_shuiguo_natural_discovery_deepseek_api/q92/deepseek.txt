便利店卖水果，核心不是“品类多”，而是**周转快、损耗低、毛利稳**。面积小的情况下，建议按下面这套思路控制品类和损耗。

## 一、先定原则：少SKU、高频、小批量

小店水果不要按超市做，建议控制在 **6～12个单品**，最多不超过15个。  
原则是：

1. **只卖高频刚需**：香蕉、苹果、橙子、梨、葡萄、小番茄、黄瓜、柠檬。
2. **少量尝鲜**：每次最多1～2个应季爆品，比如西瓜、草莓、荔枝。
3. **不卖难周转的**：榴莲、山竹、车厘子、进口奇异果等高价低频品，除非附近有明确高消费客群。
4. **不卖易压伤的**：水蜜桃、熟芒果、软柿子等，除非当天能清掉。

## 二、品类结构建议

可以把水果分成四类：

| 类型 | 作用 | 举例 | 建议占比 |
|---|---|---|---|
| 引流款 | 拉客、显眼 | 香蕉、西瓜、小番茄 | 20%～30% |
| 利润款 | 提毛利 | 葡萄、橙子、精品苹果 | 30%～40% |
| 便利款 | 即买即吃 | 香蕉、圣女果、切果盒 | 20% |
| 应季款 | 制造新鲜感 | 草莓、荔枝、橘子 | 10%～20% |

小店最稳的组合通常是：  
**香蕉 + 苹果 + 橙子 + 小番茄 + 葡萄 + 应季1～2款 + 柠檬/黄瓜**。

## 三、采购怎么控制

### 1. 按“日销量”倒推采购量
不要按感觉进货。先记录3～7天销量，再定采购量。

公式：  
**次日采购量 = 最近3天平均日销量 × 调整系数**

调整系数建议：
- 工作日：0.8～1.0
- 周末/节假日：1.2～1.5
- 雨天：0.5～0.7
- 新品类：先拿正常量的30%～50%试销

### 2. 小批量、多频次
- 叶菜类、草莓、葡萄：每天或隔天补。
- 苹果、橙子、梨：2～3天补一次。
- 香蕉：少量多次，因为后熟快。
- 西瓜：整颗和切半结合，切半当天必须清。

### 3. 采购时间
- 早上拿当天要卖的，避免前一天库存堆压。
- 如果供应商能下午补货，上午只拿60%～70%，下午看销售再补。
- 下雨天、周一到周四，采购量主动下调。

### 4. 建立“禁采清单”
以下情况直接不采或少采：
- 连续2天销量为0的新品。
- 损耗率超过15%的单品。
- 需要特殊陈列、冷藏、催熟管理的。
- 单价过高、顾客问得多但买得少的。

## 四、损耗控制的具体做法

### 1. 收货就分拣
到货后立刻：
- 去掉烂果、裂果、压伤果。
- 按成熟度分开：今天卖、明天卖、特价清。
- 香蕉不要和苹果、梨放一起，乙烯会催熟。

### 2. 陈列少量多次
小店最忌讳堆一大盘。
- 每盘只摆一层到两层。
- 卖掉一半再补，保持“满而不堆”。
- 易损水果用小筐、纸托、分隔盒。
- 葡萄、草莓不要反复翻动。

### 3. 温度管理
- 香蕉、芒果、火龙果：常温，别冷藏。
- 苹果、梨、橙子、葡萄：阴凉或冷藏。
- 切果盒：必须冷藏，且当天清。
- 小番茄、黄瓜：冷藏更稳。

### 4. 每天两次打折清理
建议：
- 上午11点：检查一次，挑出轻微瑕疵品。
- 下午5～6点：对当天必须清的水果做“特价盒”或“买一送一”。
- 晚上闭店前：能切盒的切盒，不能留的报损并记录。

### 5. 把损耗变成可控成本
可以设：
- **正常损耗率**：5%～10%
- **警戒线**：10%～15%
- **停售线**：单品连续3天损耗超15%，下架或换供应商

## 五、小店最实用的SKU模板

如果面积很小，可以直接用这个：

**固定款：**
1. 香蕉
2. 苹果
3. 橙子/耙耙柑
4. 小番茄
5. 葡萄/提子
6. 柠檬

**季节款：**
7. 夏天：西瓜、桃子
8. 冬天：砂糖橘、草莓
9. 全年：黄瓜、即食水果盒

**谨慎款：**
- 车厘子：只做预售或节日礼盒
- 榴莲：不做整颗，最多做小盒
- 草莓：只拿当天量
- 切果：只做2～3种组合

## 六、一句话执行建议

**少进、勤补、快清、勤记录。**  
每天记录每个单品的“进货量、销量、损耗量”，一周后砍掉最后3名，把位置留给周转最快的单品。小店水果赚钱，靠的不是品类全，而是**当天进、当天卖、坏得少**。
