判断香蕉供应商能否全年稳定供货，核心不是看他“有没有货”，而是看他有没有**跨产区调度能力 + 催熟/仓储能力 + 可核验的历史履约记录**。可以按下面几步做尽调。

## 1. 先问清他的货源结构，而不是只问“能不能供”

香蕉是典型的多产区轮换品类。单一产区供应商几乎不可能全年稳定。你要问：

- 主要合作产区有哪些？国内（海南、云南、广西、广东、福建）还是进口（菲律宾、越南、厄瓜多尔、柬埔寨等）？
- 各产区的上市窗口分别是什么时候？
- 当某个产区因台风、寒害、病害减产时，他用哪个产区补？
- 进口渠道是自营进口、一级代理，还是转手贸易商？

**可判断标准：** 能明确说出“几月到几月主发哪里、淡季靠哪里补、极端情况备用哪里”的，才算有全年调度思路。只回答“我们常年都有货”的，基本不可信。

## 2. 看催熟和仓储能力

连锁超市要的是**可上架的熟度一致的香蕉**，不是青蕉。全年稳定还依赖催熟排产。

要核实：

- 有没有自有或长期合作的催熟库？库容多大、几间房？
- 能否按你的门店节奏做“分批催熟、定时到店”？
- 旺季和节假日能不能加量？
- 冷链/常温运输怎么安排，到店熟度能否稳定在你要的档位？

**可判断标准：** 能提供催熟排产表、日处理量、到店熟度标准的，稳定性更强。

## 3. 要可核验的履约记录

不要只听承诺，要看数据：

- 过去12个月，每月实际供货量、断供次数、缺货原因；
- 服务过哪些连锁超市/大型渠道，能不能给参考客户；
- 有没有因质量或断供被扣款、退货的记录；
- 旺季（春节、中秋、暑期）的供货表现。

**可判断标准：** 愿意提供连续12个月供货台账、且断供有合理解释和补救方案的，可信度高。

## 4. 做小规模压力测试

在签全年框架前，先做2—3个月的试供：

- 故意在淡季或天气异常时段下一次加急单；
- 观察他补货速度、替代产区切换能力、熟度一致性；
- 记录到货合格率、损耗率、门店投诉。

**可判断标准：** 试供期断供超过1次、或熟度波动大到影响陈列的，不建议签全年独家。

## 5. 合同里必须锁定的条款

- **最低月供量 + 旺季增量承诺**；
- **断供违约责任**，比如按缺货金额比例赔偿；
- **替代产区/替代品级预案**，允许他换产地但必须提前告知并保证品质；
- **价格调整机制**，避免他因行情涨就优先供别人；
- **质量与熟度标准**，明确到货糖度、颜色、条重、伤损率。

## 6. 一个简单判断口诀

> 只报一个产地的，不稳；  
> 说不清淡季从哪里补的，不稳；  
> 没有催熟库或固定催熟合作的，不稳；  
> 拿不出12个月履约记录的，不稳；  
> 不愿做试供和签断供条款的，不稳。

如果这几项都过，基本可以判断他具备全年稳定供货能力。对连锁超市来说，最稳妥的做法是**主供应商 + 备用供应商**双轨，而不是把全年押在一家身上。
