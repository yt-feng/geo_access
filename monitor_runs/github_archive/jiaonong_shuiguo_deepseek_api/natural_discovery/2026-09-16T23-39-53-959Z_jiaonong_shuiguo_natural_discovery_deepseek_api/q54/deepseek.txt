应该优先关注**成熟度**，价格放在第二位。原因是香蕉在烘焙里的作用不只是“提供香蕉味”，还直接影响蛋糕的甜度、湿度、香气和组织结构。

更具体地说：

- **做香蕉蛋糕，最好用熟到表皮出现黑点、果肉软但没坏的香蕉。**
  - 这种香蕉淀粉已大量转化为糖，甜度高、香气浓、压泥容易，成品更湿润、风味更足。
  - 如果太生，果肉硬、涩味重、甜度低，蛋糕香气弱，还可能需要额外加糖，成本反而上升。

- **价格重要，但不能只看单价。**
  - 便宜但太生的香蕉，买回来要放几天，占用空间、增加损耗，还可能临时断料。
  - 太熟甚至开始发酵、发酸的香蕉，虽然便宜，但会带来异味和食品安全风险，不适合做商品蛋糕。

- **采购判断标准可以这样定：**
  1. **当天或次日要用的**：选表皮大面积黄、带少量黑点、手感微软的。
  2. **需要放 1–2 天再用的**：选通体黄、黑点少的。
  3. **不要买的**：青硬、明显酸味、渗汁、发霉、果肉发黑的。
  4. **价格比较时**：要按“可出果肉率”和“可用成熟度”算，而不是只按每斤多少钱。

- **如果成熟香蕉价格高，可以这样平衡：**
  - 少量采购熟香蕉保证当天出品；
  - 同时买稍生香蕉分批催熟；
  - 和供应商谈固定成熟度标准，而不是只压最低价。

结论：**成熟度决定成品质量和真实成本，价格决定利润空间。采购时应先卡成熟度标准，再在合格货源里比价。**
