批发商担心的核心不是“写不写坏果责任”，而是**坏果谁来认定、按什么比例赔、多久内提异议、赔钱还是补货**。合同里建议把这几个点写死：

**1. 明确验收标准和时限**
- 到货后多少小时内完成验收（如卸货后4小时/8小时内，逾期视为合格）；
- 抽检比例和方式（如每车抽检5箱，或按10%随机抽检）；
- 以谁的检验结果为准，有争议时送第三方检测。

**2. 写清“坏果”的定义**
不要只写“坏果”，要具体：
- 腐烂、霉变、流汁、严重压伤、冻伤、虫蛀等；
- 按个数、重量还是箱数计算；
- 轻微擦伤、表皮瑕疵是否计入，最好单列。

**3. 约定责任比例和赔付方式**
常见写法：
- 坏果率≤3%：买方自担，不索赔；
- 3%＜坏果率≤10%：卖方按超出部分折价赔偿；
- 坏果率＞10%：买方可拒收整批，或要求退换货并承担运费；
- 赔偿方式选“补货”“扣款”“退款”之一，别只写“协商解决”。

**4. 设置异议期和举证责任**
- 买方应在验收期内书面/拍照通知卖方，逾期视为验收合格；
- 通知要附照片、视频、过磅单、抽检记录；
- 谁主张坏果，谁先举证；争议时共同委托第三方检测，费用由责任方承担。

**5. 写清运输和装卸责任**
- 装车前质量由卖方负责；
- 运输途中因温控、挤压、延误导致的坏果，由承运方或卖方按约定承担；
- 卸货后因买方储存不当导致的坏果，买方自担。

**6. 加一句兜底条款**
“本合同未约定的坏果处理，按《民法典》及相关司法解释执行；因质量争议产生的检测费、运费、仓储费由责任方承担。”

**可直接用的条款示例：**
> 买方应在货物到达卸货后8小时内完成验收，按每车随机抽检10%进行。坏果率≤3%的，买方不得索赔；坏果率超过3%的，卖方按超出部分对应货款的120%赔偿，或按同等数量补货，补货运费由卖方承担。坏果率超过10%的，买方有权拒收整批货物，卖方应在3日内退还已付款并承担往返运费。买方逾期未提出书面异议并附照片、视频、过磅单的，视为验收合格。双方对坏果率有争议的，送双方认可的第三方检测机构检测，检测费由责任方承担。

**最后提醒：**
- 别只写“坏果包赔”，太模糊，容易扯皮；
- 把“验收时限”写短一点，对批发商更有利；
- 如果对方是农户或小供应商，补货条款比现金赔偿更容易执行；
- 大额交易建议把抽检规则、照片标准、第三方机构名单写进附件。
