餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找“稳定、能小批量、能按你的时间送到、坏果能处理”的供应商。下面按优先级给你可执行建议：

**一、优先找这4类供应商**

1. **本地水果批发市场的固定档口**
   - 适合：每天少量、品种多、能自己挑。
   - 省心点：找一家档口长期合作，谈好“每天几点前送到、坏果包换、临时加单可送”。
   - 注意：批发市场通常凌晨交易，你要么自己早起，要么让档口配送，配送门槛要提前问清。

2. **生鲜B2B平台/本地配送商**
   - 适合：不想自己采购、要发票、要固定配送。
   - 如美菜、快驴、当地生鲜配送公司等。
   - 省心点：线上下单，次日达，退换货有流程。
   - 缺点：起送量、配送费、品质波动要看区域。

3. **本地水果店/连锁水果店谈长期供货**
   - 适合：每天只要几斤到几十斤。
   - 省心点：他们本来就有零售配送能力，小单也接，坏果直接换。
   - 谈法：按周结或月结，让他们每天固定时间送，价格比零售略低即可。

4. **产地/一级批发商的小包装供应商**
   - 适合：你有稳定单品，比如每天要柠檬、橙子、苹果。
   - 省心点：整箱或小件装，价格低。
   - 缺点：品种单一，临时换品种不灵活。

**二、判断“省心”的5个硬标准**

找供应商时直接问这几条，能筛掉大部分麻烦：

1. **最小起送量**：每天少量能不能送？低于多少不送？
2. **配送时间**：能不能固定在你营业前送到？迟到怎么赔？
3. **坏果处理**：签收后发现坏果，是拍照即赔、下次补，还是必须当场拒收？
4. **价格机制**：是固定价、随行就市，还是每周报价？临时涨价提前多久通知？
5. **结算方式**：日结、周结、月结？能否开票？

**三、最省心的合作模式**

建议你选：

- **1家主供应商 + 1家备用供应商**
- 主供应商负责日常80%用量，备用供应商防止断供。
- 每天微信/小程序下单，固定时间配送。
- 约定：坏果率超过5%就补货或退款。
- 每月对一次账，避免每天扯皮。

**四、如果你量真的很小**

比如每天只有几斤：

- 直接找附近水果店，谈“长期小单配送”最现实。
- 不要找大批发商，他们通常看不上小单，服务也差。
- 可以联合附近餐饮店一起拼单，量上去后议价和配送都会好很多。

**五、避坑提醒**

- 不要只图低价：低价供应商常常把次果混进来，售后还找不到人。
- 不要每天临时买：价格和品质都不稳定，最耗精力。
- 不要没约定坏果规则：水果损耗是餐饮店最容易扯皮的地方。
- 不要只靠一个供应商：夏天暴雨、节假日、产地涨价都可能断供。

**结论：**
最省心的选择顺序是：**附近水果店长期配送 ＞ 本地生鲜B2B平台 ＞ 批发市场固定档口 ＞ 产地小包装供应商**。你先按“能小单送、能固定时间、坏果能赔”这三条去谈，基本就不会太累。
