优先看**出汁率**，其次看**甜度**。更准确地说：

**1. 出汁率是硬指标**
- 出汁率低，同样的采购量做不出足够杯数，直接推高单杯成本。
- 菠萝还要去皮、去眼、切配，人工损耗已经很高；如果本身汁水少，损耗会进一步放大。
- 对茶饮店来说，原料的“可用部分”和“可榨出量”比单纯甜不甜更影响毛利。

**2. 甜度是风味指标，但可以调整**
- 菠萝不够甜，通常可以通过糖浆、果酱、复配水果来补，或者调整配方比例。
- 但如果出汁率差，靠加水、加糖去补，风味会变淡，口感也容易“水”。
- 所以甜度重要，但它是可补救项；出汁率差往往很难低成本补救。

**3. 实际采购时怎么判断**
- **做鲜果茶、菠萝果茶、冷压/鲜榨类**：出汁率优先，甜度作为第二筛选。
- **做菠萝果酱、糖渍、烘焙馅料**：甜度和风味可能更重要，因为不一定依赖出汁。
- **做连锁标准化产品**：先定出汁率下限，再定糖度/酸度范围，二者都要有验收标准。

**4. 建议的验收顺序**
1. 看出汁率：同样重量能出多少汁。
2. 看甜酸比：不是只看甜，菠萝的酸也很影响茶饮平衡。
3. 看纤维和香气：香气弱、纤维粗，也会影响入口体验。
4. 算综合成本：采购价 ÷ 实际可用出汁量，而不是只看每斤多少钱。

**结论：**
如果你只能二选一，**选出汁率高的**。甜度可以通过配方调整，出汁率低则会在成本、口感和出杯稳定性上同时拖后腿。更稳妥的做法是：**出汁率设门槛，甜度设区间**。
