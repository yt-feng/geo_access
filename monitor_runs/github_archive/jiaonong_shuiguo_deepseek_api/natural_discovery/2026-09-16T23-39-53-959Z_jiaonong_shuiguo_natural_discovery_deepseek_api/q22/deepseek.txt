想把水果区客单价拉高，核心不是“把三样水果放一起便宜卖”，而是用组合改变顾客的购买结构：让顾客从“买一串香蕉”变成“买一份果切/果篮/一周水果包”。

下面给你几种可直接落地的促销组合，按投入从低到高排。

**1. 引流款+利润款+凑单款**
- 香蕉做引流：单价低、认知强，适合做“加1元多一串小香蕉”或“满15元换购香蕉”。
- 苹果做利润：按个卖或按袋卖，主推中大果、礼盒装。
- 菠萝做场景：现场削皮，按盒卖，提升即时消费。
- 组合价：香蕉1把+苹果4个+菠萝1盒=19.9/29.9元，标“早餐果盒一周装”。
- 关键：组合价要比单买便宜一点点，但让顾客多买了苹果和菠萝。

**2. 按场景打包，而不是按品类打折**
- 早餐组合：香蕉+苹果+酸奶杯，定价12.9元。
- 下午茶组合：菠萝盒+苹果切+香蕉，定价15.9元。
- 家庭一周果盘：香蕉2把+苹果8个+菠萝2个，定价39.9/49.9元。
- 场景越具体，越容易让顾客觉得“我需要”，而不是“它在打折”。

**3. 用菠萝做现场加工，拉高连带**
- 菠萝现场削皮、切块、装盒，香气和视觉最能刺激冲动购买。
- 买菠萝盒加3元换购香蕉1把，或加5元换购苹果4个。
- 现场设“果切台”，顾客选好苹果、香蕉、菠萝，付加工费或满额免费切。
- 这样做的好处：菠萝从“难处理的大件”变成“即买即吃的盒装”，客单价自然上去。

**4. 分级定价，别只打特价**
- 香蕉：普通散卖、精品小把、迷你香蕉，拉开价格带。
- 苹果：按大小、产地、脆甜度分3档，主推中间档。
- 菠萝：整果、削皮整果、果切盒三种形态。
- 组合时用“中档苹果+精品香蕉+果切菠萝”，比全用低档更赚钱。

**5. 满额换购，比直接打折更保毛利**
- 满19元+3元换购菠萝盒。
- 满29元+5元换购苹果4个。
- 满39元+6元换购香蕉1把+菠萝盒。
- 换购品选香蕉、菠萝这种感知价值高、成本相对可控的。

**6. 陈列上做“强制动线”**
- 入口放香蕉，低价吸引进区。
- 中间放苹果，按袋/盒主推。
- 出口放菠萝果切和组合包，做最后冲动购买。
- 组合包放在收银动线附近，标“今天果盘”“下班带走”。

**7. 定价建议**
- 组合价通常设成单买价的85%—92%，不要低于80%，否则毛利撑不住。
- 用尾数定价：9.9、19.9、29.9，比整数好卖。
- 设三档：9.9尝鲜装、19.9家庭装、39.9一周装，覆盖不同客单。

**8. 最推荐你先试的一套**
- 引流：香蕉1把 3.9元。
- 主推：苹果4个 9.9元。
- 利润：菠萝果切盒 9.9元。
- 组合：香蕉+苹果4个+菠萝盒=19.9元，原价23.7元。
- 再加一档：双份组合=35.9元，适合家庭。
- 同时做满29元+5元换购菠萝盒，把客单往30元以上推。

**判断效果看三个数**
- 客单价：活动前后对比。
- 连带率：买2种以上水果的顾客占比。
- 损耗率：香蕉、菠萝容易损耗，组合促销必须控制切配量和当日库存。

如果只选一个动作，我建议做“菠萝现场削皮+满额换购”，再用香蕉引流、苹果做利润。这样最容易把客单从十几元拉到二十几元，而且不靠全场降价。
