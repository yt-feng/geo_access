旺季最怕的不是价格谈不拢，而是**货到不了、品质不稳、临时涨价**。和供应商谈的时候，重点问清这几类问题：

**一、供货能力**
- 旺季每天/每周最多能稳定供多少？爆款单品有没有上限？
- 如果我要的量突然翻倍，你能提前几天确认能不能接？
- 你有几个产地/渠道？单一产地断供时有没有备用来源？

**二、品质与规格**
- 同一品种不同批次，甜度、大小、成熟度怎么保证一致？
- 验货标准是什么？次果率控制在多少？
- 是产地直发还是经过批发市场？中间转了几手？

**三、价格与结算**
- 旺季价格是锁死还是随行就市？如果涨，提前几天通知？
- 有没有阶梯价？量大能不能再谈？
- 账期怎么算？现结、周结还是月结？押金/预付款要不要？

**四、物流与损耗**
- 谁负责运输？冷链还是普通车？到店时间能不能固定？
- 路上损耗算谁的？到店后发现坏果怎么赔？
- 能不能支持紧急补货？当天补还是次日补？

**五、售后与风险**
- 出现质量问题，是补货、退款还是折价？多久内有效？
- 旺季如果优先供别人导致我断货，有没有违约或补偿机制？
- 能不能签个简单的旺季保供协议，把关键条款写进去？

**六、备选方案**
- 除了你，我还应该找谁做备用供应商？备用渠道平时要不要小批量走单维系关系？

谈的时候别只问“能不能便宜”，要问“**断货了怎么办、品质差了怎么办、临时加量怎么办**”。最好把口头承诺落到书面，哪怕微信文字确认也行。另外，自己也要提前备1-2个备选供应商，旺季不能把命脉押在一家身上。
