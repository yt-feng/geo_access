选学校食堂水果供应商，核心不是“找最便宜的”，而是先保证**稳定供货、食品安全可追溯、损耗可控、结算规范**。香蕉、苹果、橙子都属于高频大宗水果，建议按下面这套标准来筛。

## 一、先明确学校食堂的特殊要求

学校食堂和普通餐饮、水果店不一样，重点看这几条：

1. **必须能开正规发票**，最好是一般纳税人或能代开专票。
2. **食品安全责任要能追溯**：营业执照、食品经营许可证、供货凭证、检测报告或承诺达标合格证。
3. **供货要稳定**：不能今天有、明天没，尤其香蕉、苹果、橙子这类每天都要用的。
4. **价格要能随行就市但有机制**：不能一口价锁死，也不能每天随意涨。
5. **损耗要有人承担或分摊清楚**：香蕉最容易出问题，青黄不接、压伤、冻伤都常见。

## 二、供应商来源渠道

可以优先从这几类里找：

1. **本地一级批发市场的大档口**
   - 优点：货源多、价格透明、配送快。
   - 缺点：个体户多，票据和检测报告不一定规范。
   - 适合：预算紧、采购量中等、学校有能力验收。

2. **水果配送公司 / 食材配送公司**
   - 优点：票据规范、能签合同、配送稳定、售后明确。
   - 缺点：单价比批发市场略高。
   - 适合：大多数学校食堂，尤其是寄宿制、用餐人数多的。

3. **产地合作社或大型果园直供**
   - 优点：苹果、橙子这类耐储水果价格有优势，溯源好。
   - 缺点：香蕉通常不是本地优势，配送和分拣能力要求高。
   - 适合：采购量大、有冷库、能整车或大批量收货的学校。

4. **大型商超或生鲜平台的团餐渠道**
   - 优点：合规性强、售后好。
   - 缺点：价格通常偏高。
   - 适合：小规模学校、临时应急、对合规要求特别高的场景。

## 三、重点看供应商的硬资质

让供应商提供并核验：

1. 营业执照
2. 食品经营许可证，或食用农产品销售相关合法资质
3. 近期的水果农残检测报告，或承诺达标合格证
4. 配送车辆和仓储照片，看是否有冷藏、防雨、防污染措施
5. 开票信息、对公账户
6. 食品安全责任险，有则更好
7. 过往学校、机关、企业食堂供货案例

注意：食用农产品有时不强制要求食品经营许可证，但学校采购最好仍要求对方具备合规经营和可追溯能力。

## 四、按品种分别看供应商能力

### 1. 香蕉
香蕉最容易暴露供应商水平。

重点问：
- 是广西、云南、海南还是进口蕉？
- 发货是青蕉还是熟蕉？
- 有没有催熟库？催熟工艺是否规范？
- 配送时温度怎么控制？
- 出现黑斑、压伤、冻伤怎么退换？

建议：
- 优先选有催熟能力、能按学校用量分批次配送的供应商。
- 不要一次送太多，香蕉最好按 2—3 天用量配送。
- 合同里写清楚成熟度标准，比如“到货时微黄，可存放 2—3 天”。

### 2. 苹果
苹果相对耐储，适合做稳定供应。

重点问：
- 是红富士、嘎啦、黄元帅还是其他？
- 规格是 70、75、80 还是统货？
- 是冷库果还是新季果？
- 脆度、糖度、着色、碰伤率如何？
- 能否长期稳定供同一品种和规格？

建议：
- 苹果可以选产地直供或大型批发商，重点看规格统一和损耗率。
- 食堂用果不一定追求精品，但要求大小均匀、无大面积碰伤、无腐烂。

### 3. 橙子
橙子要看季节和品种。

重点问：
- 是脐橙、冰糖橙、沃柑还是夏橙？
- 产地是江西、湖南、湖北、四川还是其他？
- 酸度、化渣性、皮厚、水分如何？
- 是否打蜡？打蜡是否合规？
- 耐储运能力怎么样？

建议：
- 橙子尽量按季节选主产区，反季节果价格高、口感不稳定。
- 如果给学生直接吃，优先选易剥皮、酸甜适中的品种。

## 五、比价不能只看单价

建议用“综合成本”比较：

1. 到货单价
2. 损耗率
3. 退换货是否及时
4. 配送费是否包含
5. 是否要最低起送量
6. 账期和结算方式
7. 发票税率
8. 分拣、称重、坏果赔付规则

举例：
A 供应商苹果 4.5 元/斤，损耗 8%，坏果不赔；
B 供应商苹果 4.8 元/斤，损耗 3%，坏果拍照即赔。
实际 B 可能更便宜、更省事。

## 六、建议的采购机制

1. **不要只选一家**
   - 主供应商 1 家，备选供应商 1—2 家。
   - 防止单一供应商涨价、断供或质量下滑。

2. **先试供 2—4 周**
   - 试供期重点看：到货时间、新鲜度、损耗、退换速度、开票是否及时。

3. **每周或每两周询价**
   - 香蕉、橙子季节波动大，苹果相对稳定。
   - 可以约定参考当地批发市场均价，上下浮动不超过一定比例。

4. **验收要留记录**
   - 每次到货称重、拍照、记录品种、规格、数量、坏果数。
   - 验收单要双方签字，作为结算和索赔依据。

5. **合同写清关键条款**
   - 品种、规格、产地、成熟度
   - 单价或调价机制
   - 配送频次和时间
   - 损耗和坏果赔付
   - 食品安全责任
   - 发票和账期
   - 违约和退出机制

## 七、简单可执行的筛选标准

你可以用这张表打分：

| 项目 | 权重 | 说明 |
|---|---|---|
| 资质合规 | 20% | 证照、票据、检测 |
| 供货稳定 | 20% | 每天/每周能否稳定送 |
| 质量与损耗 | 20% | 新鲜度、坏果率、退换 |
| 价格 | 15% | 综合到货成本 |
| 配送能力 | 10% | 准时、冷链、分拣 |
| 售后 | 10% | 退换、赔付、响应 |
| 结算配合 | 5% | 发票、账期、对账 |

总分高的做主供应商，第二、第三名做备选。

## 八、最实用的建议

如果学校食堂采购量稳定，优先找**本地食材配送公司或大型水果批发商**，要求：
- 能签合同
- 能开专票
- 能提供检测或合格证
- 能按学校用量分批次配送
- 坏果能拍照退换
- 香蕉有催熟和配送能力
- 苹果、橙子能稳定供同一规格

如果采购量很大，再考虑苹果、橙子产地直采，香蕉仍建议找专业催熟配送商。这样组合通常最稳、最省事。
