做家庭水果礼盒，组合原则是：**耐放、好吃、有层次、不互相催熟、整箱看起来饱满**。按这个标准，苹果+橙子+香蕉+菠萝里，最推荐这样配：

**推荐组合：苹果4 + 橙子4 + 香蕉1把 + 菠萝1个**
- 苹果：耐放、寓意平安，适合做礼盒主果。
- 橙子：颜色亮、耐放、性价比高，和苹果撑体积。
- 香蕉：熟得快，建议放1把即可，别多放。
- 菠萝：1个就够，有“旺来”寓意，但占空间、处理麻烦，家庭装不宜多。

**更稳的家庭版比例：**
- 苹果 40%
- 橙子 40%
- 香蕉 10%
- 菠萝 10%

也就是：**苹果和橙子做主力，香蕉和菠萝做点缀**。这样成本可控，损耗低，家庭收到后也容易分着吃。

**如果按人数选：**
- 3口之家：苹果4个、橙子4个、香蕉1把、菠萝1个。
- 4-5口之家：苹果6个、橙子6个、香蕉1把、菠萝1个。
- 6口以上：苹果8个、橙子8个、香蕉2把、菠萝1个。

**包装建议：**
- 苹果、橙子放底层和四周，起支撑和饱满作用。
- 香蕉放上层，避免压伤。
- 菠萝单独用网套或纸包，竖放或斜放，避免扎破其他水果。
- 如果礼盒不大，菠萝可以换成小菠萝，或者直接不放，改成苹果+橙子+香蕉+猕猴桃/火龙果，更省空间。

**注意：**
香蕉会释放乙烯，容易催熟其他水果。如果团购后不是马上送，香蕉最好单独装袋，袋口别完全密封。苹果也会释放乙烯，但比香蕉弱，通常问题不大。

**最推荐的家庭团购方案：**
**苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个**，总价适中、颜色好看、家庭实用，也比全放贵水果更容易走量。
