茶饮店水果到货不合格，核心是把“补货”约定成可执行的流程，而不是只写一句“有问题包换”。建议按下面几层来约定，能最大程度不影响营业。

**1. 先约定验收标准，别等扯皮**
合同或供货单里写清楚：
- 品类、规格、成熟度、糖度、单果重量范围；
- 允许的损耗率，比如到货次品率不超过3%～5%；
- 哪些情况算不合格：腐烂、发霉、压伤、冻伤、未熟/过熟、农残超标、规格不符；
- 验收时间：到货后30分钟内完成，超时视为合格，避免事后争议。

**2. 补货要分“紧急”和“常规”**
- 紧急补货：影响当天出杯的，供应商需在2～4小时内送达，或按约定用同城配送/跑腿，费用由责任方承担。
- 常规补货：不影响当天营业的，可并入下一批次，但最迟不超过24小时。
- 如果供应商做不到紧急补货，要约定替代方案：按不合格部分货值的1.5～2倍现金抵扣，或允许门店自行采购同品质水果，差价由供应商承担。

**3. 补货不能影响营业，关键在“先补后赔”**
不要约定“先退回、再补货”，因为退回和补货之间会有空档。建议写成：
- 不合格部分先拍照、视频留证，门店可先处理掉易腐部分，不必等供应商到场；
- 供应商在约定时间内补足同等数量、同等品质的货；
- 若补货迟到，按每小时或每单营业损失约定违约金，或直接从当月货款里扣。
这样门店不用停工等货。

**4. 结算上要留抓手**
- 每月货款中预留5%～10%作为质量保证金，合作稳定后再降低；
- 不合格批次对应货款可暂缓支付，补货合格后再结；
- 连续两次或一个月内三次不合格，门店有权单方减少订单量或终止合作。

**5. 写进合同的一句话模板**
“供应商交付的水果不符合约定验收标准的，门店有权拒收不合格部分，供应商应在2小时内响应、4小时内补足同等品质数量；逾期未补足的，门店可自行采购，差价及因此产生的营业损失由供应商承担，并可从当月货款中直接扣除。”

**6. 日常执行建议**
- 每次到货拍开箱视频和称重照片，当天发群里确认；
- 固定一个对接人，避免口头补货没人认；
- 保留2～3天安全库存，尤其对易断货的鲜果；
- 对高频出杯的水果，最好有备选供应商，不把营业押在一家身上。

这样约定的好处是：责任清楚、补货有时限、门店有替代权、结算有扣款抓手，基本不会因为一批水果不合格就停摆。
