这取决于你门店的客群和运营能力，但多数商超更稳的做法是：**整果为主，切果为辅，按场景分渠道卖**。不要二选一。

**整果更适合的情况**
- 客群以家庭为主，买回去当天或第二天吃。
- 门店没有封闭冷藏柜、没有专人频繁处理。
- 想控损耗、控人工、控食品安全风险。
- 菠萝本身成熟度好、外观好，能靠堆头试吃带动。

整果的优势：损耗低、操作简单、毛利可控、顾客可自己判断新鲜度。  
整果的劣势：年轻人嫌削皮麻烦，冲动购买弱，客单价低。

**切果更适合的情况**
- 门店在商圈、写字楼、学校、交通枢纽附近，即买即吃需求强。
- 有冷藏展示柜和规范切配流程。
- 能控制“当日切、当日清”，卖不完可转果切拼盘或员工餐。
- 客单价和毛利通常更高，但损耗和人工也更高。

切果的优势：方便、冲动购买强、客单价高、适合小家庭和单身客群。  
切果的劣势：损耗大、保质期短、食品安全要求高、人工成本高。

**建议的采购和陈列策略**
1. **整果做引流和基本盘**：占菠萝销量的60%—70%，做堆头、试吃、整果促销。
2. **切果做利润和便利**：占30%—40%，放在冷藏柜、收银台附近或水果区端头。
3. **按时间段卖**：上午多上整果，下午和晚间多上切果，匹配即时消费。
4. **按门店类型调比例**：
   - 社区店：整果70%，切果30%。
   - 商圈/写字楼店：整果40%—50%，切果50%—60%。
   - 学校/交通店：切果可到60%以上。
5. **切果只做小规格**：小盒、单人份，减少卖不完的损耗。
6. **用整果价格锚定切果**：整果便宜、切果方便，让顾客自己选。

**关键判断标准**
- 如果门店没有冷藏条件、切配人手不足，就主推整果。
- 如果周边即时消费强、有冷藏柜、能控损耗，就提高切果比例。
- 如果两个条件都有，就整果和切果同时做，动态调整。

一句话：**整果保销量和低损耗，切果提毛利和便利性。先看客群，再看冷链和人工，最后定比例。**
