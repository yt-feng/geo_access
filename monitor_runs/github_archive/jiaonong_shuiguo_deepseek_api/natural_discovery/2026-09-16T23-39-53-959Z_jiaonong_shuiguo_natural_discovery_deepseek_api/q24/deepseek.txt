可以按“主体资质 + 批次合格证明 + 检测项目 + 追溯与责任”四类资料来要，重点盯**批次对应**，不要只看一张年度报告。

**一、供应商主体与准入资料**
1. 营业执照、食品经营许可证或食品生产许可证（如适用）。
2. 若供应商是代办/贸易商，要其与种植基地、合作社或一级供应商的采购合同或授权链条。
3. 供货商质量承诺书/食品安全承诺书。
4. 近一年内的供应商审核记录或第三方审核报告（如有）。

**二、批次合格证明（最关键）**
1. **该批次**的农药残留检测报告：报告日期、样品名称、批号/采收日期、供应商名称要能和你采购的货对应。
2. 检测报告应由具备 **CMA/CNAS** 资质的检测机构出具；至少要有 CMA。
3. 如果是供应商自检，要其自检原始记录、快检结果和自检能力说明，但不能完全替代法定检测。
4. 入境水果还要：海关入境货物检验检疫证明、报关单、标签及中文标识。

**三、检测项目要覆盖高风险农药**
不要只写“农残合格”，要具体看项目：
1. 常见重点：有机磷类、氨基甲酸酯类、拟除虫菊酯类、杀菌剂、除草剂等。
2. 结合水果品类盯高风险项：如柑橘类关注毒死蜱、丙溴磷等；叶菜类关注氧乐果、克百威等；浆果类关注腐霉利、烯酰吗啉等。
3. 报告应列明：检测项目、方法、检出限、结果、判定依据（如 GB 2763）。
4. 最好有**近 3 个月或近 1 个月**的批次报告，而不是过期报告。

**四、追溯与责任资料**
1. 种植基地/合作社名称、地址、联系人，以及采收日期、批次号。
2. 供货清单/送货单，能和检测报告批号对应。
3. 质量保证协议：约定农残超标时的退换货、赔偿、检测费承担、下架召回责任。
4. 若供应商不能提供批次报告，可要求其签署“先检后收/每批随货附检”的补充条款。

**实操建议**
- 采购前先发一份《水果供应商资料清单》，要求随货或到货前提供。
- 收货时做“三查”：查报告批次是否对应、查检测机构资质、查检测项目是否覆盖。
- 对高风险水果或新供应商，超市可自行送第三方抽检，费用在合同中约定由谁承担。
- 保留所有报告、送货单、聊天记录，至少保存 2 年，便于监管抽检时追溯。

一句话：**要营业执照和许可证，更要该批次 CMA 农残检测报告、检测项目清单、基地追溯信息和质量责任协议。**
