判断“大小规格是否适合门店销售”，核心不是只看单个果子大小，而是看**目标客群、陈列方式、定价带、损耗和周转**能不能匹配。可以按下面几步判断。

**1. 先定门店销售场景**
不同门店适合的规格不同：
- 社区生鲜店/便利店：适合中等个头，方便即买即吃，单价不能太高。
- 精品水果店：可以卖大果、礼盒果，但要求外观、甜度、包装更好。
- 商超堆头：适合规格整齐、耐翻动、周转快的统货或分级货。
- 餐饮/果汁/果切：更看重出肉率、酸甜比和成本，不一定要大果。

**2. 苹果怎么看规格**
常见可按横径或单果重分级：
- 小果：适合低价引流、家庭煲汤/做辅食，但门店直接卖可能显得不划算。
- 中果：通常最适合社区店和商超日常销售，大小适中、价格带好接受。
- 大果：适合精品店、礼盒、节日销售，但进价高，必须匹配客群。
- 特大果：除非有礼盒或高端客群，否则容易压货。

判断要点：
- 同一批次大小是否均匀，直径差最好控制在小范围内。
- 果形是否端正，歪果、畸形果多会影响陈列和售价。
- 表皮是否光洁，有无锈斑、碰伤、裂口。
- 硬度是否够，太软说明成熟度高，门店货架期短。
- 单果重是否稳定，比如 80–90mm 对应什么重量，要和采购价、售价一起算。

**3. 橙子怎么看规格**
橙子通常也按横径或单果重分级：
- 小果：适合榨汁、做果切，或低价促销，但直接卖可能显得小气。
- 中果：最适合日常零售，握感好、剥皮方便、价格适中。
- 大果：适合礼品、精品陈列，但皮厚可能影响出肉率。
- 特大果：要看出肉率和甜度，不能只看大。

判断要点：
- 大小是否均匀，一箱里不要混太多等级。
- 果皮是否细腻、有光泽，太粗糙或失水会影响卖相。
- 手感是否沉，沉说明水分足。
- 有无软果、霉斑、油胞下陷、冻伤。
- 切开看皮厚和出肉率，尤其大果不能“大而空”。

**4. 用门店经营指标反推**
采购前建议算清楚：
- 目标售价带：顾客能接受多少钱一个/一斤。
- 毛利空间：进价 + 损耗 + 包装 + 人工后是否还有利润。
- 货架期：预计几天卖完，规格太大或太小是否影响周转。
- 陈列效果：同规格整齐码放是否好看，混装是否显得廉价。
- 损耗率：碰伤、软果、霉变多，规格再好也不能采。
- 客群习惯：家庭装、单身客、送礼客、餐饮客需求不同。

**5. 简单可执行的判断标准**
可以按这个顺序做：
1. 先确定门店卖給谁：社区日常、精品礼盒、餐饮果切还是促销引流。
2. 再看同批次大小是否均匀，直径/重量是否集中。
3. 再看外观、硬度、水分、出肉率、甜度。
4. 最后算售价、毛利、损耗和周转。
5. 小批量试销 1–2 天，看顾客反馈和实际损耗，再决定是否放量。

**一句话总结：**
适合门店销售的规格，是**目标顾客愿意买、陈列好看、损耗可控、算下来有利润、能在货架期内卖完**的规格，而不是单纯越大越好或越小越便宜。
