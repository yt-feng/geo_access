结论先说：**价格敏感型团购客户，优先用「阶梯价」而不是「返利」；但更稳的做法是「低门槛阶梯价 + 有条件返利」组合使用。**

下面给你可直接判断的逻辑。

## 一、先看本质区别

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 客户感知 | 立刻便宜，价格透明 | 事后拿钱，感知弱 |
| 刺激下单 | 强，直接冲量 | 中，偏长期绑定 |
| 现金流 | 当期让利 | 后期兑现 |
| 适用客户 | 价格敏感、比价型 | 忠诚型、长期合作型 |
| 风险 | 价格体系被打穿 | 年底集中兑付、扯皮 |

**价格敏感客户最在意的是「我现在这单能便宜多少」，不是「年底可能返多少」。** 所以纯返利对这类客户吸引力弱。

## 二、什么时候选阶梯价

满足以下任意两条，用阶梯价：
- 客户明确比价，谁便宜跟谁走
- 采购决策快，看单次报价
- 单量波动大，需要即时刺激
- 客户规模小、账期短

阶梯价设计要点：
- 档位别太多，**3档最合适**（如 100 件 / 500 件 / 1000 件）
- 相邻档位价差要有感，至少 **3%~8%**
- 最低档要留利润底线，别为冲量亏本

## 三、什么时候选返利

满足以下任意两条，用返利：
- 客户已合作、有黏性，想加深绑定
- 你想引导**全年总量**而非单次大单
- 需要控制当期价格、不想打乱公开价
- 客户是经销商/渠道，要维护价格体系

返利设计要点：
- 挂钩**累计采购额**或**回款额**，不是下单额
- 分季度/半年兑现，别全压年底
- 设封顶，避免返利吃掉全部利润

## 四、最优解：组合拳

对价格敏感的团购客户，推荐：

**「即时阶梯价（保底吸引力）+ 年度返利（绑定复购）」**

示例：
- 单次：100件9.5折，500件9折，1000件8.5折
- 年度累计满50万，再返2%；满100万返3%

这样客户：
- 当下看到便宜 → 愿意下单
- 长期想拿返利 → 愿意复购

## 五、一句话决策

- **只做一次性/比价型团购 → 阶梯价**
- **做长期复购/渠道型 → 返利为主**
- **价格极度敏感又想绑定 → 阶梯价打底，返利加钩子**
