水果生意想长期稳定，选供应商时最容易忽视的，往往不是价格和品种，而是那些会直接影响损耗率、现金流和客户复购的细节。下面这些点最值得重点看。

1. **供货稳定性比单次价格更重要**  
很多人先比价，但低价供应商经常断货、规格不稳、旺季优先给大客户。要问清楚：  
- 每周能稳定供多少量  
- 旺季能否保供  
- 有没有备用产地或冷库  
- 缺货时是补货、换品还是退款

2. **分级标准是否真实可执行**  
“大果、中果、精品”如果只靠口头说，很容易扯皮。要看是否按重量、直径、糖度、着色、伤疤比例等可量化标准分级。最好让供应商提供实物样箱，并写进订单。

3. **损耗责任怎么分**  
水果损耗高，最容易忽视的是运输、装卸、到货后腐损由谁承担。要明确：  
- 到货验收时限  
- 坏果率超过多少算供应商责任  
- 是补货、扣款还是退货  
- 冷链断链、压伤、冻伤怎么认定

4. **是否真正有冷链能力**  
不是有冷藏车就行，要看产地预冷、分拣环境、运输温度记录、到货温度。尤其做连锁或线上，断链一次就可能毁一批货和口碑。

5. **账期和结算方式是否匹配你的现金流**  
供应商账期太短，你压货压力大；账期太长，可能后期涨价或降质。要谈清：  
- 现结、周结还是月结  
- 押金、返利、损耗扣款怎么算  
- 价格随行就市时，提前多久通知

6. **产地和季节切换能力**  
单一产地依赖风险高。稳定供应商通常能随季节切换产区，比如国产转进口、南转北，且能保证口感差异不大。要问：  
- 主产区受灾时怎么办  
- 替代产地的品质是否稳定  
- 切换期价格和规格如何过渡

7. **是否愿意配合你的客户结构**  
做社区店、商超、电商、团购，对包装、规格、成熟度要求不同。比如线上要耐运输，商超要外观统一，团购要性价比。供应商能否按渠道分拣、贴标、定制包装，很关键。

8. **信息透明度**  
好的供应商愿意提供产地、采摘时间、批次、检测报告、农残情况。如果一问就含糊，长期合作风险大。

9. **售后响应速度**  
水果问题往往在到货后几小时到一两天内爆发。要看对方是否有专人对接、多久回复、能否快速补货。慢半天的售后，可能让你丢客户。

10. **别只签一家，也别频繁换**  
长期稳定通常靠“主供应商 + 备用供应商”组合。主供占 60%–70%，备用占 30%–40%，既保供又保留议价权。频繁换供应商看似灵活，实际会让品质和账期都不稳定。

简单判断标准：  
**能稳定供货、标准可量化、损耗责任清楚、冷链不断、账期匹配、售后快、愿意配合渠道。**  
如果只满足“便宜、有货”，通常做不长久。
