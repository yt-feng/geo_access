小批量试单的核心目的不是“赚一笔”，而是**用最低成本验证供应商是否值得长期合作**。所以设计思路是：把试单当成一次“压力测试”，同时测品、测人、测流程。

## 一、先明确试单要验证什么

按优先级排序：

1. **品质稳定性**——同一批货里好坏是否一致，而不是只看样品
2. **规格真实性**——大小、等级、成熟度是否和承诺一致
3. **损耗率**——到货后实际能卖的比例
4. **履约与响应**——发货是否准时、出问题是否认账
5. **价格与结算**——报价是否含水、账期是否可谈

第一次合作，**不要一次测太多品类**，选1–2个你最有把握出货、也最能看出问题的单品。

## 二、试单规模怎么定

原则：**小到亏得起，大到能暴露问题。**

- 金额上，控制在你能承受全损、且不影响现金流的范围，很多批发商会用“一车/一柜的零头”或几千到一两万的货值起步
- 数量上，要够你观察一整批的一致性，通常至少覆盖**一个完整包装单位或一个托盘级别**，否则样本太小看不出问题
- 品类上，优先选**周转快、你已有下家意向**的货，避免压手里

## 三、试单条款要提前谈死

第一次合作最容易扯皮的就是这些，务必书面确认：

| 项目 | 要确认的内容 |
|---|---|
| 规格 | 具体到品种、等级、单果重/直径范围、成熟度 |
| 包装 | 箱规、每箱净重、包装方式 |
| 价格 | 是否含运费、是否含税、是否含损耗 |
| 发货 | 发货时间、物流方式、到货时效 |
| 验收 | 到货后多少小时内可提异议、怎么取证 |
| 售后 | 坏果/短重怎么赔，是补货还是退款 |
| 结算 | 预付比例、尾款条件、账期 |

**关键动作：所有口头承诺落到文字（微信、合同都行），并保留样品或图片作为标准。**

## 四、验收流程要标准化

到货当天就做，别拖：

1. **称重**：抽几箱称净重，看是否短重
2. **开箱**：随机抽箱，看上下层是否一致（这是最常见的坑）
3. **分级**：按约定规格挑，统计不合格比例
4. **计损耗**：坏果、软果、霉变各占多少
5. **留证**：拍照、录视频、记录时间和批次

建议做一张简单的验收表，把上面几项数字记下来。**没有数据，后面谈判全靠感觉。**

## 五、判断是否继续合作

试单结束后问自己几个问题：

- 实际可售比例是多少？和报价时的预期差多少？
- 出问题时，对方是积极解决还是推诿？
- 综合算下来，这批货的实际成本是否还有利润空间？
- 如果放大10倍量，这个品质和履约能撑住吗？

只要有一项明显不达标，先别急着放量，要么换供应商，要么小步再试一单。

## 六、几个常见误区

- **只看样品就下大单**：样品往往是挑过的，代表不了大货
- **只比价格**：低价常常靠短重、混级、高损耗找回来
- **不测售后**：故意提一次合理异议，看对方反应，这比货本身更能看出是否值得长期合作
- **一次试太多品**：问题会混在一起，分不清是品的问题还是供应商的问题

---

一句话总结：**小批量试单 = 小金额 + 明确规格 + 标准验收 + 主动测售后**。把它当成筛供应商的过滤器，而不是省钱的采购。如果你能告诉我具体品类（比如苹果、柑橘、进口果）和你的下游渠道，我可以帮你把试单数量和验收标准定得更具体。
