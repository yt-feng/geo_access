最应该先问**售后**，其次问配送，最后才是价格。

原因很简单：水果是**高损耗、非标品、强时效**的品类。团购团长真正的风险不在“进货贵一点”，而在“坏果、少件、延迟到货”之后，供应商赔不赔、怎么赔、多久赔。价格再低，只要售后不行，最后都是团长自己贴钱、贴信任。

**判断顺序建议：**

1. **售后优先问**
   - 坏果率超过多少包赔？按颗、按斤还是按整单？
   - 拍照报损后多久处理？直接补发、退款还是下次抵扣？
   - 少件、错发、压伤算谁的？
   - 生鲜腐坏是否支持“签收后24小时内报损”？超时怎么算？

2. **配送其次问**
   - 是否冷链/泡沫箱/冰袋？夏天和冬天方案一样吗？
   - 到团点的时间是否稳定？迟到导致团长被投诉谁负责？
   - 起送量、配送费、偏远团点加价怎么算？
   - 破损和延误是否计入售后？

3. **价格最后谈**
   - 价格要建立在“售后和配送都明确”之后再比。
   - 低价但售后扯皮的供应商，实际综合成本 often 更高。
   - 要比“到手综合成本”：进货价 + 损耗 + 赔付 + 团长时间成本。

**一句话决策：**
先选售后条款清楚、赔付爽快的供应商；再筛配送稳定、时效可控的；最后在同档售后和配送里选价格更优的。  
如果只能问一个问题，就问：**“坏果、少件、延误，你们具体怎么赔，多久赔？”**
