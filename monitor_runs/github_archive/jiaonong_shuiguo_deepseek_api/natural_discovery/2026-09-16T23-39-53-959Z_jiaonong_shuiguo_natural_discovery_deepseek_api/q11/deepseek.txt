会影响销售，但影响大小取决于你打算怎么卖。

**核心结论：**
- **散卖/按斤称重卖**：大小不一是常态，影响较小，顾客会自己挑。关键是别让太小的混在里面显得整箱不值钱。
- **按箱卖/礼盒/团购**：影响很大。大小不均会让顾客觉得“掺了差的”，投诉和退货率会上升。
- **做果切、榨汁、甜品原料**：基本不影响，反而适合消化大小不均的货。

**具体判断标准：**
1. **大小差异是否明显**：如果只是略有差异，顾客能接受；如果一半大一半小，散卖也会被挑剩。
2. **成熟度是否一致**：比大小更影响销售的是成熟度。大小不一但都黄熟均匀，问题不大；大小均匀但有的生有的熟，反而更难卖。
3. **表皮品相**：斑点、压伤、裂口比大小更致命。

**建议操作：**
- 采购时问清楚是“统货”还是“分级货”。统货便宜但需要自己分拣，分级货贵但好卖。
- 到店后按大小分成两档：大的做精品散卖或礼盒，小的做促销、果切或榨汁。
- 定价上拉开差距，让顾客觉得“小的便宜也合理”，而不是“花一样的钱买到小的”。
- 如果线上卖，主图不要用大小均匀的网图，否则差评率会高。

**一句话：**
大小不一定会毁掉销售，但“不分拣、不说明、混着卖”会。
