小水果店做附近小区团购，水果供应商至少要能支持下面几类服务。你可以拿这份清单直接去问供应商，能对上大部分，才适合长期合作。

**1. 稳定供货与品质保障**
- 能按约定时间、约定量供货，不缺货、不临时涨价
- 有分级标准：大小、甜度、成熟度、外观尽量一致
- 坏果、烂果、次果有赔付或补货机制
- 能提供当日或前一日采摘/到货的新鲜货

**2. 团购专属价格与起批量**
- 支持小批量起订，不要动辄几百斤起批
- 给团购价、阶梯价，量越大价越低
- 价格相对稳定，避免今天报低价、明天涨很多
- 能提前给报价单，方便你发群预售

**3. 分拣、打包、贴标**
- 能按小区团购规格分装，比如5斤装、10斤装
- 能帮忙套袋、装箱、贴标签
- 最好能按不同小区或不同团长分开打包
- 减少你回店后再二次分拣的工作量

**4. 配送与到货支持**
- 能送到店里、指定自提点，或直接送到小区
- 支持定时配送，比如上午到货、下午自提
- 冷链或保鲜运输，尤其是草莓、荔枝、樱桃等易坏水果
- 临时加单、补货能不能配合

**5. 售后与损耗处理**
- 坏果包赔，最好有明确比例和流程
- 支持拍照理赔，不用反复扯皮
- 缺斤少两能补
- 滞销或临期水果能否换货、调货或折价处理

**6. 选品与营销支持**
- 能推荐适合团购的爆款、应季水果
- 提供图片、文案、团购素材
- 能配合做试吃、秒杀、满减、拼团活动
- 愿意开发独家款或小区专供款

**7. 结算与订单配合**
- 支持先货后款、周结、月结等灵活结算
- 能对账清楚，按订单、按批次结算
- 支持你预售后再采购，降低库存压力
- 能提供发票或收据

**8. 风险与应急能力**
- 天气、节日、爆单时能优先保供
- 某款断货时能快速替换同级水果
- 有备用产地或备用供应商
- 出现食品安全问题时能追责、召回、赔付

**你筛选供应商时，重点问这8个问题：**
1. 最小起批量多少？
2. 团购价怎么算，能不能先报价？
3. 能不能按小区分装贴标？
4. 配送到店还是能到小区？
5. 坏果怎么赔，多久处理？
6. 能不能先预售再进货？
7. 结算周期怎么定？
8. 爆单和断货时怎么保供？

**最适合小水果店做小区团购的供应商，通常不是价格最低的，而是：**
- 起批量低
- 分装配送省事
- 售后爽快
- 价格稳定
- 能配合预售和爆单

如果你刚开始做，建议先找1家主力供应商 + 1家备用供应商，先跑通一个小区，再扩到周边小区。
