会，而且通常是很直接的风险。对香蕉和菠萝来说，起订量（MOQ）太高，主要会从下面几个环节放大损耗。

**1. 香蕉：成熟节奏很难压住**
香蕉是典型的呼吸跃变型水果，采后还会继续后熟。起订量太大时，问题往往不是“卖不完”，而是“来不及卖完就已经过熟”：
- 同一批货到仓后，成熟度不一定完全一致，堆在一起会互相催熟。
- 温度、乙烯浓度控制稍有波动，很快就会从“青”转到“黄”，再转到“起黑点”。
- 如果销售速度跟不上，最后一段通常只能降价、做加工或报损。
所以香蕉的 MOQ 风险，核心是**成熟窗口太短**，不是单纯的库存积压。

**2. 菠萝：相对耐放，但高起订量会放大其他问题**
菠萝比香蕉耐储一些，但也不是没有风险：
- 整果怕冷害、怕挤压、怕通风不良，堆存时间长会出现黑心、腐烂、果眼褐变。
- 高 MOQ 往往伴随更长的分拣和销售周期，尾部货品的外观和商品率会下降。
- 如果采购的是成熟度偏高的菠萝，可售窗口会更短。
所以菠萝的风险更多是**品质劣变和周转压力**，不像香蕉那样集中爆发。

**3. 高起订量真正增加损耗的机制**
一般可以归为四类：
- **销售速度不匹配**：到货量超过单位时间销量，尾货自然变老。
- **仓储条件被拉爆**：冷库容量、分拣人力、货架空间不够时，损耗会上升。
- **批次质量不均**：大货里难免混有成熟度不同、等级不同的果，统一处理会拖累好货。
- **价格被迫下行**：为了清货降价，毛利被吃掉，报损比例也可能上升。

**4. 怎么判断“起订量是否过高”**
可以用一个简单口径判断：
- 先算你的**日均销量**和**安全周转天数**。
- 再看这批货在理想条件下能放几天。
- 如果“预计售完天数”明显超过“可售窗口”，MOQ 就偏高。
对香蕉尤其要按成熟度分批算，不能只看总库存。

**5. 降低风险的做法**
- **拆批采购**：哪怕单价略高，也优先选能分批到货的供应商。
- **要求成熟度分级**：香蕉按青、微黄、黄分批；菠萝按成熟度分等级。
- **先进先出 + 动态催熟**：香蕉不要一次性全催熟，按销售节奏分批处理。
- **设置止损线**：比如香蕉开始起黑点、菠萝出现软腐迹象时，提前转促销或加工渠道。
- **算总成本，不只看采购单价**：MOQ 带来的低价，可能被损耗和降价吃掉。

**结论**：会。香蕉的损耗风险尤其高，因为后熟窗口短；菠萝相对好一些，但高 MOQ 仍会通过周转慢、品质下降和清货降价增加损耗。判断关键不是“起订量高不高”，而是**预计售完天数是否超过可售窗口**。如果超过，就应该拆批、分级或换供应商。
