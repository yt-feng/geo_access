优先选 **小把（3～5根）**，其次是 **单根**，整袋/整串最后考虑。核心判断标准是：便利店卖香蕉不是卖“家庭囤货”，而是卖“即时吃、顺手买”。

具体建议：

1. **小把 3～5 根：最适合便利店**
   - 客单价适中，顾客容易顺手买。
   - 不像整串那么多，减少熟过头、压坏、滞销损耗。
   - 适合上班族、学生、单人或两口之家。

2. **单根：适合做补充，不建议只做单根**
   - 优点：门槛最低，冲动购买强，适合搭配早餐、酸奶、咖啡。
   - 缺点：称重、贴标、收银、补货麻烦；损耗和人工成本可能更高。
   - 如果做单根，最好用固定价，比如“1根2元/3元”，不要现场称重。

3. **整袋/整串：通常不适合作为主包装**
   - 除非你面对的是家庭客群、社区型便利店，或者价格明显便宜。
   - 整串香蕉成熟快，便利店客流不像大卖场，容易剩到发黑。
   - 若要做，建议只做少量，并放在靠近收银台或入口冲动消费区。

**实操建议：**
- 主力：3根装小把，定价简单，比如5～8元/把，按当地行情定。
- 辅助：单根，固定价，放在收银台附近。
- 少量测试：整袋只针对社区店或晚间家庭客流。
- 控制熟度：上架选微黄带一点绿的，太熟的当天促销或做香蕉牛奶搭配。
- 陈列：不要堆压，香蕉怕压、怕冷，别放冷藏柜旁边。

一句话：**便利店卖香蕉，优先小把，单根补充，整袋慎上。**
