选下午茶水果供应商，核心看四点：批量稳定性、配送时效、损耗售后、报价透明度。可以按下面步骤判断。

**1. 先明确采购约束**
- 人数与预算：按人头算，通常每人 150–250g 水果；20 人约 3–5kg，50 人约 8–12kg。
- 配送时间：下午茶一般要求 14:00 前送达，写明“迟到扣款或取消”。
- 场地条件：有无冰箱、是否需要切果、是否要独立分装。

**2. 优先选“批量配送型”供应商，而不是普通水果店**
适合的类型：
- 本地水果批发商/配送商：价格低，适合大批量，但分装和售后弱。
- 企业团餐/下午茶配送商：能按份分装、带切果和餐具，省事但单价高。
- 生鲜电商企业购：时效稳定、发票规范，适合中小批量。
- 本地农场/合作社：适合应季单品，但配送稳定性要确认。

不建议只找社区水果店临时送，批量大时容易缺货、品质不均、无法准时。

**3. 用 5 个问题快速筛选**
问供应商：
1. 今天下单，明天下午能否固定时段送到？迟到怎么处理？
2. 同一批次水果规格是否统一？坏果率多少？坏果怎么赔？
3. 是否支持按份分装、切果、配叉子/湿巾？加价多少？
4. 报价是否含配送、包装、发票？能否开专票？
5. 临时加 10–20 份，最晚什么时候确认？

**4. 看样品和试单**
首次合作不要直接大单：
- 先下 1 次小单试配送，重点看准时率、坏果率、分装质量。
- 要求提供当日到货实拍，不接受网图。
- 约定验收标准：坏果率超过 5%–10% 补送或退款。

**5. 合同/订单里写清楚**
- 品种、规格、数量、单价、总价
- 送达时间、地点、联系人
- 坏果赔付标准
- 发票类型
- 临时增减单规则

**6. 性价比选择建议**
- 20 人以内：生鲜电商企业购或下午茶配送商，省心。
- 20–100 人：本地批量配送商 + 每周固定 2 次配送，成本更优。
- 100 人以上：找批发商或团餐供应商，谈周结/月结和固定账期。

**避坑点**：不要只看单价低；低价供应商常在规格、坏果赔付和准时率上缩水。优先选能承诺“准时送达 + 坏果包赔 + 固定规格”的供应商。
