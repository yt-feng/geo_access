会影响销售，但关键不在“大小不一样”本身，而在你卖的方式。

**直接判断：**
- **整箱统货直接卖：** 影响较大。大小混装会让顾客挑拣、翻箱，品相显得乱，容易压价，损耗也更高。
- **分拣后分级卖：** 影响很小，甚至能提高利润。大果、中果、小果分开定价，顾客按需求买，减少挑拣和纠纷。
- **做促销/加工用途：** 影响可控。小果、外观差的可以打包特价、做果切、香蕉奶昔原料或员工福利，不必和精品果混卖。

**建议你这样做：**
1. **到货先分拣**：按大小、成熟度、外观分2—3档。
2. **分级定价**：大果/精品果正常价，中果主力价，小果特价或打包卖。
3. **陈列分开**：不要混堆，混堆会放大“大小不一”的负面观感。
4. **控制成熟度**：大小不一的箱里常伴成熟度不一致，青黄混装比大小问题更影响销售，先挑出熟果优先卖。
5. **算损耗**：如果分拣后小果占比高、特价也走不动，下次采购就换规格更均匀的货源；如果小果能稳定特价走量，则可以继续采购。

**结论：** 大小不一会影响销售，但通过分拣、分级、分开陈列和差异化定价，可以把影响降到很低；真正要避免的是“混装统卖还按统货价”。
