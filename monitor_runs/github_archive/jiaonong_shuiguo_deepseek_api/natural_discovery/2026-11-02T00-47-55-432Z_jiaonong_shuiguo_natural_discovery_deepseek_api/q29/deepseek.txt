超市和水果供应商谈账期，常见区间大致是 **7～30天**，水果这类生鲜通常更偏短，**7～15天最常见，15～30天多见于有规模、合作稳定的超市或供应商**。如果是叶菜、浆果、鲜切水果等损耗高的品类，很多会做到 **现结、周结或3～7天**；苹果、柑橘、根茎类等耐储水果，账期相对可以拉到 **15～30天**。

判断时重点看四个因素：  
1. **品类损耗**：越易腐越短，鲜切/浆果偏现结或周结。  
2. **供应商规模**：小供应商现金流紧，通常接受不了长账期；大供应商可给15～30天。  
3. **超市规模与信用**：连锁超市议价强，但新供应商首单常要求现结或缩短账期。  
4. **合作阶段**：新合作建议先 **7天或周结**，稳定后逐步拉到 **15天**，不要一上来压30天。

可执行建议：新供应商首单 **现结或7天**；稳定供货后谈 **15天**；强势连锁超市可争取 **30天**，但要明确对账日、付款日、质量扣款规则和逾期利息。水果行业账期不宜盲目拉长，**超过30天容易推高供货价或导致好货优先供给别家**。
