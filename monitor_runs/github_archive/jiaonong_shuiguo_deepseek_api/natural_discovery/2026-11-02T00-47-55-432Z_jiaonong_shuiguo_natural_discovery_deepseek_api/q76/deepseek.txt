香蕉配送损耗主要来自两方面：机械压伤和温度/乙烯导致的催熟变黑。控制思路是“分级采收＋硬防护＋控温控气＋快周转”，分开施策。

**1. 采收与入库**
- 用七到八成熟青香蕉发货，不要等转黄再发；黄香蕉在途两天就很容易出黑斑。
- 采后尽快预冷到13–15℃，不要低于12℃，低温会冷害发黑。
- 入库前剔除有伤果，单果有伤会传染整箱。

**2. 包装防护（最关键）**
- 用瓦楞纸箱＋内部隔档，单果套网套或纸浆托，避免果与果直接接触。
- 箱内留缓冲层，但不要塞太满，香蕉受压会出压痕黑斑。
- 整箱限高，堆码不超过3–4层，重物不压箱顶。
- 长途可用气柱袋或泡沫箱内衬，减少运输振动。

**3. 温控与气体**
- 全程13–15℃冷链，避免日晒和空调直吹。
- 纸箱开透气孔，防止乙烯积聚；可放乙烯吸附剂。
- 不要和苹果、梨等乙烯释放大的水果混装。
- 若做短保同城配送，可常温但必须当天达，避免闷在车厢。

**4. 配送环节**
- 同城优先“当日达/半日达”，缩短在途时间。
- 配送箱内加隔板，骑手箱内不要叠压。
- 到货后提醒用户不要放冰箱冷藏，常温阴凉处悬挂或平放。
- 轻微青果可配催熟说明，减少“没熟就退货”的纠纷。

**5. 售后与选品**
- 对压伤、黑斑设置明确赔付标准，比如黑斑面积超1/3可赔。
- 先小批量测试包装方案，记录不同线路的损耗率，再定包装成本。
- 高损耗线路可改发“青果＋催熟袋”模式，降低在途转黄风险。

核心原则：**青果发货、单果隔离、限高限压、13–15℃、越快越好**。先把包装和时效做到位，温控和气体管理再叠加，损耗能明显下降。
