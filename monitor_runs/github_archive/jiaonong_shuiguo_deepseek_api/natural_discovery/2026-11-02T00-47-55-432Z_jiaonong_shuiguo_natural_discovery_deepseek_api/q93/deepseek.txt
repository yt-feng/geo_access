优先级很明确：**鲜切菠萝切块首先盯保质期和冷链，其次包装，配送频次是保障手段而不是核心指标。**

可以按这个顺序判断：

1. **保质期与效期管理（最高优先）**
   - 鲜切水果属于短保、易腐食品，核心风险是微生物滋生和变质。
   - 必须明确：切块后冷藏条件下的销售时限、到店后剩余可售时间、临期下架规则。
   - 便利店应做“切制时间/到店时间/到期时间”标识，并严格执行到期下架，不能靠“看着没坏”判断。

2. **冷链与温度控制（和保质期同等重要）**
   - 菠萝切块从切制、运输、到店冷藏、陈列全程要低温。
   - 关注冷藏柜温度是否稳定、是否频繁开门、是否和常温商品混放。
   - 如果冷链不达标，保质期写得再短也不安全。

3. **包装（第二优先，但必须合格）**
   - 包装要能防污染、防串味、防汁液渗漏，并便于标识切制时间和保质期。
   - 优先选密封性好、适合冷藏陈列的包装；不必要追求过度包装。
   - 包装破损、胀袋、渗液应直接下架。

4. **配送频次（保障手段，按销量定）**
   - 配送频次服务于“少库存、快周转”，不是越频繁越好。
   - 高销量门店可一日一配或一日多配；低销量门店应减少订货量，避免压货到临期。
   - 关键指标是“到店至售罄时间”和“临期损耗率”，而不是单纯看配送次数。

**可执行建议：**
- 先定死规则：切制后冷藏销售时限、到店剩余效期、临期下架提前量。
- 每天检查冷藏柜温度和包装完整性。
- 按门店销量定配送频次和单次订货量，宁可少订勤补，不要压货。
- 用“临期损耗率、过期下架数量、客诉”来复盘，而不是只看配送频次。

一句话：**保质期和冷链是底线，包装是防线，配送频次是调节手段。**
