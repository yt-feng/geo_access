# 社区超市水果：控新鲜度 + 控库存的实操做法

核心思路：**水果不是“库存品类”，是“流速品类”**。管理目标不是“库存准确”，而是“当天/隔天能卖完”。下面按可执行顺序说。

## 一、先定品类结构，不要什么都进

按周转速度把水果分三档，进货和陈列策略完全不同：

| 档位 | 例子 | 策略 |
|---|---|---|
| 快周转（1–2天） | 香蕉、葡萄、草莓、荔枝、桃 | 小批量、高频补，宁缺勿压 |
| 中周转（3–5天） | 苹果、梨、橙、柚 | 正常备货，可做堆头 |
| 耐储（7天+） | 土豆式根茎、部分柑橘 | 可适当压量做促销 |

**关键动作**：每个品类设“最大在店天数”，超过就进促销/处理通道，不跟新品混卖。

## 二、进货：少量多次，按销量倒推

- **按近7天日均销量 × 1.5 天** 作为单次进货量上限，新品类先试小量。
- 和批发商谈**小批量、多频次**配送（社区店量小，宁可每2–3天补一次，也别一次压一周）。
- 进货时**现场验货**：看果柄、看底部、捏硬度、闻气味；要求“到店可售期”至少留2/3货架期。
- 建立**供应商淘汰机制**：同一供应商连续两次到货损耗高，换人。

## 三、到店后的保鲜动作（比进货更影响损耗）

- **分级上架**：到货先分“立即卖 / 可存1–2天 / 需催熟或处理”，不要整箱直接倒上货架。
- **温区分开**：香蕉、芒果、番茄类**不要冷藏**；草莓、葡萄、叶菜类冷藏；苹果、梨会释放乙烯，**别和易熟水果混放**。
- **少摆勤补**：货架只摆半天量，其余放后仓；后仓按“先进先出”贴日期标签。
- **每天两次翻检**：早开店、晚闭店各一次，挑出软伤果，当场降价或做果切，不要等烂了再扔。

## 四、库存和损耗的硬控制

- **设损耗红线**：水果整体损耗率控制在 **5%–8%** 以内（叶菜/浆果可略高），超线就查是进货过量还是保鲜不当。
- **当日清尾机制**：闭店前1–2小时对临期果做“晚间特价/果切/搭配促销”，**当天处理掉，不进第二天正价区**。
- **记录三件事**：每日进货量、销售量、报损量。一周就能算出每个品的真实流速，第二周按数据调进货，不靠感觉。
- **小批量试销**：新品先上一箱，卖得动再放量；卖不动立刻停，不追加。

## 五、几条最容易被忽略的

1. **陈列量≠进货量**：堆头好看但压货，社区店客流有限，堆头越大损耗越高。
2. **果切是止损工具，不是利润工具**：临期果做果切可以，但别为了果切去进便宜烂果。
3. **促销要提前，不要等烂**：八成熟、轻微软伤就降价，比烂掉后扔掉损失小得多。
4. **和周边餐饮/果汁店建立尾货渠道**：每天固定时间低价出临期果，能显著降损耗。

**一句话总结**：进货按“日均销量×1.5天”卡上限，到店分级、分温区、少摆勤补，每天两次翻检+闭店清尾，用一周数据校准下一周进货——库存就不会压在店里。
