大型超市水果供应商要把“食品安全”和“物流交付”同时做成可审核的能力，而不是只靠承诺。通常必须覆盖以下方面：

**一、食品安全能力**

1. **合法资质与产品合规**
   - 营业执照、食品经营/生产相关许可（按实际业态）、种植/养殖基地证明或采购合同。
   - 每批次水果的产地证明、检测报告、承诺达标合格证；进口水果需报关单、入境货物检验检疫证明。
   - 农药残留检测能力或稳定第三方检测合作，能按超市标准做批批检或高频抽检。

2. **基地与源头管理**
   - 基地备案、土壤/水源/周边污染源评估。
   - 农药、化肥等农业投入品统一采购、登记、休药期/安全间隔期管理。
   - 可追溯体系：批次号能关联到基地、地块、采收日期、投入品记录、检测报告和发货记录。

3. **采收、加工与包装卫生**
   - 分级包装场所的清洁消毒、防虫防鼠、人员健康证与卫生操作。
   - 不与有毒有害物品混存；包装材料食品级合规。
   - 预冷、清洗、打蜡、催熟等环节有工艺标准和残留控制。

4. **仓储与运输食品安全**
   - 冷库/常温库温湿度监控和记录，定期校准温控设备。
   - 不同品类分区存放，防交叉污染；腐烂果及时隔离处理。
   - 运输车辆专车专用或彻底清洗消毒，冷藏车有温度连续记录。

5. **质量安全体系与追溯召回**
   - 建立进货查验、出厂检验、不合格品处置、客诉处理制度。
   - 能提供HACCP、ISO 22000、GAP等体系认证者通常更受大型超市认可，但不是唯一门槛。
   - 具备批次追溯和召回能力：出现问题能在约定时限内定位批次、下架、召回并提交原因分析。

6. **保险与责任承担**
   - 食品安全责任险、产品责任险；明确质量违约和赔偿条款。

**二、物流与交付能力**

1. **冷链与温控能力**
   - 按品类配置预冷、冷藏、保温运输；浆果、叶菜、热带水果等分温区管理。
   - 冷藏车、冷库、温度记录仪及异常报警；能向超市开放温控数据。

2. **仓储与分拣加工能力**
   - 具备与超市供货量匹配的收货、分级、包装、暂存和越库能力。
   - 支持按门店/DC订单分拣、贴标、码盘、预约送货。

3. **运输与配送网络**
   - 自有或稳定合作车队，覆盖超市DC或门店；具备高峰期、节假日、恶劣天气保供方案。
   - 送货准时率、订单满足率、破损率、冷链断链率等可量化指标。

4. **库存与订单协同**
   - 能对接超市采购/供应链系统，处理电子订单、ASN预约、批次和效期信息。
   - 有安全库存和紧急补货机制，缺货提前预警。

5. **时效与损耗控制**
   - 采收后快速预冷、最短中转、先进先出；明确各品类到货新鲜度标准。
   - 对压伤、冻伤、失水、霉变等有包装和装载规范，降低途损。

6. **应急与追溯物流**
   - 断链、延误、车辆故障、疫情/灾害封控等应急预案。
   - 物流记录能与批次追溯打通，支持问题批次精准拦截。

**三、大型超市通常会重点审核的硬指标**

- 资质证照齐全且在有效期内；
- 批批可追溯、检测报告可随货或线上提供；
- 冷链温度记录完整可查；
- 送货准时率、订单满足率、破损/损耗率达标；
- 不合格品处理和召回响应时限明确；
- 有食品安全责任险；
- 能接受超市或第三方飞行检查。

**判断供应商是否合格，可以要求其提供：** 证照清单、基地备案与投入品记录、近批次检测报告、追溯演练记录、冷库/车辆温控记录样例、召回预案、近一年超市或第三方审核报告、配送时效与损耗数据。没有这些可验证材料，仅口头承诺“有冷链、有检测”通常不足以进入大型超市供应链。
