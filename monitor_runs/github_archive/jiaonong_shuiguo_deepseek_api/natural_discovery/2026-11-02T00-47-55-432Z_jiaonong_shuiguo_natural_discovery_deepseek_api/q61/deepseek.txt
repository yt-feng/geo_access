判断香蕉一手货源是否稳定，建议按“资质—产地—履约—风险”四步核验，不要只看报价低。

**1. 先确认是不是“一手”**
- 要求对方提供：产地合作社/种植基地证明、收购合同、装车照片或视频、包装厂/催熟库信息。
- 问清是“基地直发”“产地代办”还是“市场倒手”。只给微信报价、不愿视频看货、说不清产地的，大概率不是一手。
- 香蕉通常涉及产地采收、催熟、冷链，真正稳定的一手方一般能说清：主产区、月供量、规格（条数/把重/青熟度）、包装方式、发车周期。

**2. 核验产地和季节供应能力**
- 问对方主产区在哪里、当前是否处于该产区上市期，能否在换季时切换产区。
- 要求提供近1—3个月的发货记录：发车数量、目的地、回单或装车单。注意打码可接受，但不能完全不给。
- 香蕉怕寒、怕热、怕运输损伤，稳定供货方应能说明：催熟库、冷链车、到货成熟度控制、损耗处理。

**3. 用小单试履约**
- 先下1—2车小单或拼车单，重点看：是否按时装车、规格是否一致、青熟度是否达标、破损率、到货后催熟表现。
- 约定验收标准：条数/把重、青度、机械伤、烂指比例、温差要求。到货不合格如何补货、扣款、退货要写进聊天记录或简易合同。
- 看对方对问题的反应：稳定供货方会给处理方案；倒手方常推给司机、天气或市场。

**4. 查资金和风险信号**
- 优先对公账户或可核验的经营主体，避免长期大额私户预付。
- 警惕：报价明显低于产区行情、要求全款锁价、催你打定金、不给视频看货、频繁换电话/微信、只发网图。
- 可要求视频连线看库房/装车，或让当地朋友/代办实地看货。

**5. 建立备选和合同**
- 至少保留2个不同产区的备选货源，避免单一依赖。
- 首次合作用“小单+分批付款+明确验收”控制风险；稳定后再谈账期或锁量。
- 关键条款写清：规格、数量、价格随行就市还是锁价、装车时间、运输责任、损耗标准、违约处理。

简单判断：**能说清产地、能视频看货、能给近月发货记录、敢接小单并按标准验收、出问题有处理方案的，才值得逐步放量。** 只靠低价和口头承诺的，不建议直接大额合作。
