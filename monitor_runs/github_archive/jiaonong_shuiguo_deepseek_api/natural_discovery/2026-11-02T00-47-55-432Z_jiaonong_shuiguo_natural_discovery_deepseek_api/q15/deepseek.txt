水果店遇到坏果，核心是先分清“谁承担损耗”，再按合同/约定结算。没有统一法定比例，关键看验收节点和证据。

**一、先判断责任节点**
1. **到货验收前发现**：供应商负责，按约定扣款、换货或补发。
2. **验收签字后才发现**：通常由水果店承担，除非能证明是隐蔽瑕疵（如外表正常、切开内部腐烂）且在约定异议期内提出。
3. **运输损耗**：看谁安排运输、谁承担运费和风险；一般由发货方或承运方按约定承担。
4. **自然损耗/正常失水**：行业通常有允许损耗率，按合同约定处理，不宜全部算供应商责任。

**二、结算和赔付的常见做法**
- **扣款结算**：本批货款中直接扣除坏果金额，按“坏果数量×进货单价”计算，必要时加合理运费/处理费。
- **换货补发**：坏果比例较高时，要求下一批补发同等数量，结算时冲抵。
- **折价接收**：轻微瑕疵但可销售，按约定折扣结算。
- **退货退款**：整批严重腐烂、无法销售，退回并拒付该批货款。
- **保证金/账期扣减**：有长期合作的，从质量保证金或下期账款中扣。

**三、操作上要留证据**
- 到货当场拍照/录像：整车、包装、坏果特写、数量清点。
- 保留送货单、验收单、聊天记录、合同/报价单中的质量条款。
- 在约定异议期内书面提出（微信也算），写明批次、数量、金额、处理诉求。
- 不要先签字确认“数量质量无误”再事后追责，除非保留隐蔽瑕疵证据。

**四、合同没写清楚时怎么谈**
- 按行业惯例主张“到货验收不合格部分由供应商承担”，但不要扩大到正常损耗。
- 小额坏果可协商下批补货或折让，避免影响长期合作。
- 频繁出现坏果的供应商，改为“验收合格后付款”或提高验收标准、缩短账期。

**建议**：先看采购合同/送货单有没有质量条款和异议期；没有的话，固定证据后按“坏果数量×进货单价”提出扣款或补发，正常损耗部分自行承担。
