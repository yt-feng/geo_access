选水果供应商，核心不是“找最便宜的”，而是把**质量稳定性、价格机制、配送能力、食品安全责任**四件事写进规则里。可按下面执行。

## 1. 先定采购标准，再谈供应商
对香蕉、苹果、橙子分别写清楚验收标准，避免“看着还行”扯皮：

- **香蕉**：成熟度按用途定。食堂当天吃，选7～8成熟、到货可立即食用的；避开青硬或已出黑斑的。规定每把/每箱允许的机械伤比例。
- **苹果**：明确品种、果径范围、色泽、硬度、碰伤率。苹果最怕“外观好、里面糠”，要抽检切开看。
- **橙子**：明确品种、果径、糖酸度大致要求、表皮无腐烂无霉变，抽检看是否干水。
- **通用**：腐烂率、碰伤率、大小均匀度、异物、农残合格证明、可追溯批次。验收时按比例抽检，不合格整批退换。

## 2. 供应商类型怎么选
常见有三类，建议组合使用：

- **一级批发商/产地直供**：价格有优势，适合量大、单品集中的苹果橙子；但要确认其分拣和仓储能力。
- **本地果蔬配送商**：配送灵活、退换货快，适合香蕉这类成熟度变化快的水果；重点是看其是否长期稳定供货。
- **大型商超/供应链平台**：票据规范、食品安全责任清晰，价格通常偏高，适合作为备选或应急渠道。

不建议只选一家。至少“主供+备供”两家，防止断供和坐地起价。

## 3. 询价和定价机制要写死
不要只比一次报价。建议：

- 要求按**固定周期报价**，比如每周或每半月报一次，写明产地、品种、规格、含税/含运费单价。
- 约定**价格调整规则**：以当地批发市场同类同规格均价为参考，涨跌超过一定比例才调价，避免随意涨价。
- 明确**送货价是否含运费、卸货费、包装回收**。
- 约定**退换货**：腐烂、碰伤、成熟度不符、规格不符的，多少小时内补换，费用谁承担。

## 4. 食品安全和资质不能省
至少核验并留存：

- 营业执照、食品经营相关许可或备案；
- 每批次农残检测合格证明或承诺书；
- 进货票据和批次记录，做到可追溯；
- 配送车辆和周转筐的清洁情况；
- 合同里写清食品安全责任和违约赔偿。

## 5. 实地看和试供
正式签约前建议：

- 看供应商的仓库、分拣场地、冷链或通风条件；
- 要求**试供2～4周**，重点看准时率、损耗率、退换货响应速度；
- 记录每次到货的合格率，作为续约依据。

## 6. 简单可执行的评分表
可按100分评：

- 质量与验收合格率 30分；
- 价格及调价合理性 25分；
- 配送准时与应急能力 20分；
- 资质与食品安全 15分；
- 退换货和售后 10分。

试供后按实际数据打分，不凭感觉定供应商。

**一句话建议**：先写验收标准和调价规则，再找“主供+备供”两家试供，用合格率、准时率、退换货速度三个数据决定去留。
