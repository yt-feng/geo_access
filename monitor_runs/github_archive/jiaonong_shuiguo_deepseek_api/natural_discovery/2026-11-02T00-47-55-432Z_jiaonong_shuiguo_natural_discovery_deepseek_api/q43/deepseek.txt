评估水果供应商仓配能否覆盖你的连锁门店，建议按“门店需求—仓网结构—履约能力—成本风险—验证落地”五层拆解，不要只看供应商有没有分仓。

**1. 先量化门店需求**
- 按城市/门店列出：日均销量、SKU结构、单品温层要求、补货频次、单店最小起订量。
- 区分常温和冷链：水果尤其要标出需冷藏/催熟/易损的SKU。
- 计算每个城市的“日需求体积/重量/箱数”，这是判断仓配覆盖的基础。

**2. 评估供应商仓网结构**
要求供应商提供：
- 全国仓、区域仓、城市前置仓/中转仓的位置清单；
- 每个仓覆盖的城市和门店半径；
- 仓到店是直配、干线+城配、还是第三方落地配；
- 是否支持多仓分单、跨仓调拨、门店间调拨。
关键判断：门店所在城市是否在“有效配送半径”内，而不是只在供应商宣传的覆盖地图上。

**3. 看履约时效和冷链能力**
重点核验：
- 常态配送频次：每周几配、能否日配、截单时间；
- 到店时效：从下单到到店的小时/天数，是否稳定；
- 冷链完整性：产地预冷、冷藏车、温控记录、门店交接温度；
- 水果损耗控制：周转天数、破损率、缺货率、临期处理机制；
- 旺季/节假日/天气异常时的运力保障。
对水果来说，时效和温控比“仓库数量”更关键。

**4. 算覆盖成本**
不要只比供货价，要算“到店总成本”：
- 配送费、起送门槛、偏远城市附加费；
- 多仓分单带来的拆单费；
- 冷链包装/耗材费；
- 因损耗、缺货、断货造成的门店销售损失；
- 退货、换货、临期折价成本。
可做一张“城市×门店×SKU”的到店成本表，比较不同供应商。

**5. 用试点和压测验证**
- 选2—3个代表性城市（核心城市、偏远城市、门店密集城市）做1—2个月试点；
- 压测旺季、促销日、极端天气下的履约；
- 要求供应商提供近3—6个月的实际到店准时率、损耗率、缺货率数据，并抽查门店收货记录；
- 合同里约定覆盖城市清单、时效SLA、温控标准、缺货/损耗赔付和运力不足退出条款。

**判断标准**：如果供应商能在你门店所在城市做到稳定日配/隔日配、冷链全程可追溯、旺季运力有备份、到店总成本可接受，才算真正覆盖；否则只是“名义覆盖”。建议优先选择在你门店密集区域有实体仓、且能提供门店级履约数据的供应商，而不是仅看全国仓数量。
