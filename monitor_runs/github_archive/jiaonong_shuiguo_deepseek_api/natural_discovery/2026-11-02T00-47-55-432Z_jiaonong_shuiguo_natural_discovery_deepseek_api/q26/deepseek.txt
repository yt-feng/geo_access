可以优先按“小份量、快周转、少磕碰”来做。采购和包装时重点看这几项：

1. **规格别太小**
   - 建议单包 **2～3 根、约 400～600g**，太小分拣和包装成本高，也容易显得不新鲜。
   - 同一包尽量大小相近、成熟度一致，避免一包里有熟有生。

2. **按成熟度分批采购**
   - 门店现卖选 **7～8 成熟**，到店后 1～2 天进入适售期。
   - 不要一次全采同一成熟度，按日销量分 2～3 批到货，减少集中过熟。
   - 采购时明确要求供应商按成熟度分级，青蕉、黄蕉分开。

3. **包装要透气、防压**
   - 用带透气孔的薄膜袋或开孔吸塑盒，不要完全密封，避免水汽积聚导致发黑、长霉。
   - 袋装可留小孔，盒装注意不要压住蕉身。
   - 包材成本控制在售价的合理范围内，别为了包装过度加价。

4. **减少机械伤**
   - 香蕉怕压、怕摩擦，采购箱内要有间隔或衬垫，避免整箱堆压。
   - 门店分装时轻拿轻放，不要反复倒箱；有伤、裂口、断柄的挑出来做特价或加工，不要混进小包装。
   - 小包装尽量在陈列前分装，减少反复搬动。

5. **控制单包陈列量**
   - 小包装适合“少量多补”，每次上架不要太多，卖完再补，降低货架期损耗。
   - 熟度高的放前排先卖，青一点的放后面。

6. **采购合同/验收要写清楚**
   - 验收看：成熟度、蕉指完整、无严重压伤、无腐烂、柄部无霉。
   - 约定到货成熟度和可接受损耗比例，避免把供应商运输损耗转嫁到门店。
   - 小包装若由供应商预包装，要确认透气孔、净含量和标签合规。

7. **损耗管理**
   - 每天挑出过熟、碰伤的单包，及时拆包处理：可做特价、果切或员工内部处理，不要继续陈列。
   - 记录每天进货量、销量、报损量，按 2～3 天滚动调整采购量。
   - 夏季和节假日前后要更保守，香蕉损耗对温度很敏感。

简单说：**采购按成熟度分批、单包 2～3 根、包装透气防压、陈列少量勤补、验收写明成熟度和损耗责任**，这几项做好，小包装香蕉的损耗会明显下降。
