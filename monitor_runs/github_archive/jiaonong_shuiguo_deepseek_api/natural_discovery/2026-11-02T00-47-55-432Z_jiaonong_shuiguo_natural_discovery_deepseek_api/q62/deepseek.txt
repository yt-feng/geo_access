# 香蕉批发验货判断法

## 一、看外观

**1. 颜色**
- **青绿**：生蕉，适合长途运输或囤货，但流通周期长，对冷库要求高。
- **黄绿相间**：七成熟左右，适合接下来3–5天出货。
- **全黄**：八到九成熟，通常2–3天内必须出手或加工。
- **黄带黑点（芝麻蕉）**：最佳食用期，但货架期很短，当天到次日就要走货。
- **大面积黑斑/发黑**：过熟或已开始腐坏。

**2. 果指饱满度**：棱角明显说明偏生；果指圆润饱满说明成熟到位。太软、按压不回弹说明过熟。

**3. 果柄与果轴**
- 果柄青绿硬挺为正常；发黑、发软、有汁液渗出说明腐坏或机械伤。
- 整梳果轴变黑、发霉是最危险的信号之一。

## 二、查坏果风险（重点）

**1. 开箱抽查**：不要只看表层。每批至少抽3–5箱，翻到底层和中间层，检果柄处和果指接触面。

**2. 摸**
- 果指硬挺：风险低。
- 局部软塌：机械伤或已开始腐坏，要挑出。
- 整箱发黏、有汁液：整箱风险高，建议拒收或大幅压价。

**3. 闻**：正常是清甜果香；有酒味、酸味、发酵味说明内部已过度成熟或腐烂。

**4. 切口/断面**：看果柄切口是否发黑、有无霉丝，判断采后存放时间和冷链情况。

## 三、结合季节和运输判断

- **夏季高温**：熟得快、坏得快，青绿货也建议按“黄绿”估期，订货量要保守。
- **冬季/冷链运输**：青绿货可囤，但要注意冷害——果皮发暗、出现水渍状斑块，说明运输温度过低。
- **长途到货**：优先看果柄和箱底水汽，湿度过高易催腐。

## 四、可执行的分级建议

| 状态 | 判断 | 操作 |
|---|---|---|
| 青绿硬挺、无伤 | 生货 | 可接，控制库存周期 |
| 黄绿、少量芝麻点 | 适销 | 正常接，3–5天内出货 |
| 全黄、局部软 | 快销 | 压价接，当天/次日走 |
| 大面积黑斑、酒味、果柄发黑 | 高风险 | 拒收或只接可挑出的部分 |

**一句话原则：先看颜色定成熟度，再翻箱摸果柄定坏果风险，最后结合季节和你的出货速度决定接不接、什么价接。**
