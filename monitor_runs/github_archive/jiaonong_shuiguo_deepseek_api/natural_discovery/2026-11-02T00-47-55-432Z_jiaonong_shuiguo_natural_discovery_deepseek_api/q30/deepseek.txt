超市水果到货品相不好的售后，建议在采购合同或收货标准里事先约定，核心是“可判定、可举证、有时限、有分担”。可以按下面框架写：

1. **明确验收标准**
   - 按品类写清楚：大小、色泽、成熟度、机械伤、腐烂率、畸形率、病虫害、冻伤/压伤等。
   - 量化容忍度：如“单批次腐烂率≤2%，机械伤果≤3%，低于标准部分按比例扣款或退货”。
   - 区分“外观瑕疵”和“质量不合格”：轻微外观差异可折价接收，腐烂、变质、异味必须拒收或退换。

2. **约定验收时限和方式**
   - 到货后多长时间内验收，如“卸货后2小时内完成抽检”。
   - 抽检比例和判定方法，如“按批次随机抽检5%，不合格率超阈值即整批可退”。
   - 要求留存照片/视频、称重记录、抽样封样，双方签字确认。

3. **售后处理方式分档**
   - 轻微品相问题：折价接收，按不合格比例扣款。
   - 中度问题：换货或补发，运费由责任方承担。
   - 严重腐烂/变质：拒收或整批退货退款。
   - 已售出后发现问题的：约定召回、下架、消费者赔付责任由供应商承担的范围。

4. **时限和响应机制**
   - 到货验收异议应在约定时间内提出，逾期视为验收合格，但隐蔽质量问题除外。
   - 供应商响应时限，如“24小时内给出处理方案，48小时内完成补换货”。
   - 生鲜易腐品要约定“先拍照留证、先隔离存放，再协商”，避免扩大损失。

5. **责任和费用分担**
   - 运输途中压伤、冻伤、高温腐烂的责任归属。
   - 退换货物流费、销毁费、门店损耗由谁承担。
   - 因品相问题导致消费者投诉、赔偿的，供应商承担相应责任。

6. **结算挂钩**
   - 质量保证金或账期扣款机制：不合格批次可从货款中直接扣减。
   - 月度/季度质量评分，连续超标可暂停供货或终止合同。

7. **证据和争议解决**
   - 约定以到货照片、视频、抽检记录、第三方检测为证据。
   - 争议先协商，协商不成按合同约定仲裁或诉讼。

实操上，最关键是三点：**标准量化、验收留证、扣款/退换规则写进合同**。不要只写“品相不好可退”，否则容易扯皮。建议做成一张《到货验收单》，把品类、抽检数、不合格数、处理方式、双方签字固定下来。
