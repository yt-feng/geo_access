判断水果供应商的合规和稳定性，可以分“硬资质、可验证的履约能力、现场与样品、合同约束”四层来做，尤其是养老院和医院食堂，食品安全和断供风险都要重点看。

**一、合规性：先查硬资质，别只看营业执照**
1. 主体资质：营业执照经营范围含水果/食用农产品销售；有食品经营许可证（如涉及预包装或切配）。
2. 产品合规：要求提供每批次水果的产地证明或进货凭证、农药残留检测报告（快检或第三方）；进口水果要有入境货物检验检疫证明。
3. 人员与场所：送货人员健康证、配送车辆消毒记录、仓储场所照片或现场核查。
4. 票据合规：能开正规发票，做到票、货、款一致，便于追溯。
5. 特殊要求：医院/养老院食堂一般按食品安全管理要求做供应商建档，可要求其提供食品安全承诺书、近一年无重大行政处罚声明（可到国家企业信用信息公示系统、信用中国核验）。

**二、稳定性：看“能不能持续按你的标准供”**
1. 货源：是否有稳定产地/一级批发市场档口/合作社直采，是否单一货源。单一货源风险高，最好有备选。
2. 供应能力：日均供货量、旺季淡季差异、节假日和极端天气的保供方案。
3. 冷链与配送：是否有冷藏车或保温箱、配送频次、到货时间窗口、缺货补货响应时间。
4. 品控：是否有分拣标准（大小、成熟度、损耗率）、退换货规则、农残自检能力。
5. 财务与经营：合作前可要求提供近半年主要客户名单或合作证明；通过企业信用信息查经营异常、司法风险、行政处罚。成立时间短、频繁变更法人或地址的要谨慎。
6. 试供期：先签1—3个月试供，按月评估到货合格率、缺货次数、投诉处理速度，再决定是否长期合作。

**三、现场与样品：最有效的验证**
1. 实地看仓储、分拣场地、冷链设备，重点看是否有交叉污染风险。
2. 连续3—5批次样品检测：外观、新鲜度、农残快检；记录到货重量与损耗。
3. 暗访或询问其现有客户（尤其是医院、学校、养老机构类客户）的履约口碑。

**四、合同约束：把稳定性写成条款**
1. 明确品名、规格、等级、单价浮动机制（随行就市要有报价依据）。
2. 约定到货合格率、缺货违约金、24小时补货、退换货责任。
3. 要求每批次随货附检测报告或产地凭证，保留追溯权。
4. 设置退出条款和备选供应商机制，避免独家依赖。

**实操建议**：养老院和医院对食品安全容忍度低，优先选有同类机构供货经验、能提供批次检测报告、有冷链配送能力的供应商；同时保持“一主一备”，每季度做一次供应商复评。判断核心不是价格最低，而是**资质可查、批次可追溯、断供有预案、违约有约束**。
