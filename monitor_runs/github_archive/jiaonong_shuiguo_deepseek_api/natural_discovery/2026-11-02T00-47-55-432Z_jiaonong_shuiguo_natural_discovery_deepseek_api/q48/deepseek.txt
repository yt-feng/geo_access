要判断菠萝供应商能否稳定按规格送货，不能只看样品和报价，要按“规格可量化、产能可验证、交付可追溯、异常有兜底”四条线去查。下面是可以直接执行的判断方法。

**1. 先把规格写成可验收标准**
不要只说“要菠萝”，要明确到可检测项：
- 品种/产地：如金钻凤梨、巴厘菠萝，是否允许混品种。
- 单果重量区间：例如1.2–1.5kg/个，允许偏差比例。
- 成熟度：糖度范围、果目展开度、有无青果/过熟果。
- 外观：果形、果眼深浅、黑心/水心/裂果/机械伤允许比例。
- 加工形态：是否去皮、切块规格、中心温度、是否盐水浸泡、真空包装。
- 农残与检测：每批随货检测报告或第三方抽检频次。
- 包装与装载：箱规、每箱净重、托盘/冷链要求、到货温度。
- 验收规则：抽样比例、不合格判定、扣款/退货/换货时限。

规格越可量化，后面越能判断供应商是否“真能稳定送”。茶饮连锁用量大，建议把“到货合格率、规格偏差率、短缺率、迟到率”写进合同。

**2. 验证产能和货源稳定性**
- 问清是自有基地、合作基地还是市场调货。市场调货的稳定性通常弱于基地直供。
- 要求提供近3–6个月同类客户供货记录，至少看连续供货周数和单周最大供货量。
- 核实产地季节：菠萝有主产季和淡季，供应商能否在淡季持续供货，靠的是跨产区调配能力还是冷库储存。
- 看其是否有分级线、清洗去皮线、冷库和冷链车。只做贸易转手的供应商，规格波动和断供风险更高。
- 要求给出“日产能、周产能、应急产能”，并说明旺季同时服务多少客户。

**3. 用试单和小批量压测**
不要一上来放大量。建议分三阶段：
- 首批试单：连续送2–3周，每周2–3次，按正式验收标准抽检，记录每批合格率。
- 压力测试：在周末或旺季下一次比日常高30%–50%的订单，看能否按时按量到货。
- 异常测试：临时改一次送货时间或追加小单，观察响应速度和补救能力。

重点看三个指标：**到货准时率、规格合格率、短缺补货时长**。如果试单期合格率低于95%、补货超过24小时，就不适合作为主供应商。

**4. 查冷链和加工合规**
茶饮用的菠萝常涉及去皮切块，风险点在微生物和温度：
- 到货中心温度是否在要求范围，冷链车是否有温度记录。
- 加工环境是否有食品生产或经营相关资质，是否有清洗消毒流程。
- 每批是否有农残检测、感官验收记录，能否追溯到产地批次。
- 包装标签是否含品名、批次、生产日期、保质期、储存条件。

不能提供批次追溯和检测记录的供应商，不建议进入核心供应。

**5. 合同里设“稳定交付”条款**
- 约定周/月供货计划及提前下单时间。
- 约定规格偏差允许范围和超标处理：扣款、退货、换货时限。
- 约定断供违约金和替代方案，例如供应商需在几小时内补货或承担紧急采购差价。
- 约定价格调整机制，避免旺季随意涨价或优先供高价客户。
- 约定主供/备供比例，例如主供70%、备供30%，防止单点断供。

**6. 现场审一次**
至少去一次加工/分拣现场，看：
- 分级是否按重量和成熟度实际执行，还是靠人工目测。
- 冷库容量和库存周转，是否有积压果。
- 当天出货记录与订单能否对上。
- 不合格品如何处理，是否有隔离区。

**判断结论可以很简单：**
连续试单3周，到货准时率≥98%、规格合格率≥95%、短缺能在24小时内补齐、批次检测和追溯齐全，可列为主供应商；任一指标反复不达标，只做备供。不要因为样品好、价格低就直接给大单，茶饮连锁的损失主要在断货和规格不稳造成的门店操作浪费。
