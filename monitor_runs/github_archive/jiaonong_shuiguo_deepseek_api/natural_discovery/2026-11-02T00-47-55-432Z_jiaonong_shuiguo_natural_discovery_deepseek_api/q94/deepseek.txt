很重要，而且往往不是“锦上添花”，是便利店能不能把水果做成稳定品类的前置条件。

核心原因：

1. **便利店水果需求本身波动大**
   门店客流、天气、周边办公/社区结构、促销都会影响销量。首单或新品如果必须大批量进货，很容易出现两种情况：卖不动导致损耗，或不敢订导致缺货。小批量试卖能把“判断失误的成本”压到可承受范围。

2. **水果损耗高，试错成本不对称**
   水果保质期短、品相要求高，滞销后折价空间有限。供应商支持小批量，等于把首单风险从门店单方面承担，变成双方共同验证需求。没有这个支持，门店理性选择就是少上或不上新品。

3. **小批量试卖是选品和补货的数据来源**
   只有真实卖过，才能判断动销速度、复购、损耗率、客单价和高峰时段。没有试卖，订货只能靠经验拍脑袋，销量自然不稳定。试卖两到四周后再决定是否放量，比一次性压货科学得多。

4. **供应商支持小批量，也是合作质量的信号**
   愿意小批量试卖的供应商，通常更重视门店动销和长期合作，而不是只做一锤子买卖。反过来，只接受大批量、不配合调换货或拆零的供应商，适合做成熟爆品，不适合做新品导入。

但也要注意边界：小批量不是无限拆零。门店需要给供应商明确条件，否则供应商履约成本过高，支持不可持续。可执行的做法是：

- 约定试卖周期，比如2—4周；
- 约定最小起订量和拆零规格；
- 约定损耗分担、调换货或退货比例；
- 用动销率、损耗率、缺货率三个指标决定是否放量或下架；
- 试卖门店选2—3家代表性门店，不要全店铺开。

结论：**供应商能否支持小批量试卖，对便利店水果品类非常关键。** 它直接决定新品导入风险和补货精度。如果供应商完全不愿配合，建议只把它作为成熟单品的补充渠道，不要指望靠它把水果销量做稳。
