判断供应商能不能按时到车，核心不是听他口头保证，而是看“可验证的履约能力”。给你一套可落地的判断方法：

**1. 先看他的货源组织方式**
- 自有基地/长期合作蕉园：到车稳定性较高。
- 靠临时在市场调货：变数大，尤其节假日、雨季、行情上涨时容易跳单。
- 问清“这车货现在在哪、谁在装、装了几成”，能具体到地点和人，可信度更高。

**2. 看历史履约记录，不看单次承诺**
- 连续合作3次以上，记录“承诺到场时间 vs 实际到场时间”，偏差超过2小时就要警惕。
- 新供应商要求提供近1个月发车记录或装车视频/照片，不能提供就降低预期。
- 问同行、市场档口对他的评价，重点问“有没有临时加价、换车、拖车”。

**3. 用合同和定金锁死责任**
- 合同写明：车型、车牌、装车时间、发车时间、到场时间、迟到违约金。
- 定金不要一次给足，按“装车后付一部分、到场验货后付尾款”拆分。
- 约定“迟到超过X小时可拒收或压价”，并写清由谁承担损耗。

**4. 到车前做过程跟踪**
- 装车当天要装车视频，确认货已上车。
- 发车后要车牌、司机电话，自己或让司机发定位。
- 到场前6小时再确认一次位置，异常早发现早补救。

**5. 看风险信号，出现就换备选**
- 反复说“放心”“肯定到”但给不出具体车牌和装车地点。
- 报价明显低于市场价，往往靠拖车或换货找补。
- 节假日、雨天、涨价期临时要求加价才发车。
- 司机信息频繁变更、装车时间一再推迟。

**一句话判断标准：** 能说清货在哪、谁在装、车牌是谁、迟到怎么赔的供应商，才值得按“能按时到车”来安排；只说“没问题”的，一律按备选方案准备。建议同时锁2家供应商，主供+备供，别把一车货压在一个口头承诺上。
