对茶饮店来说，**甜度优先于出汁率**；但出汁率不能太低，否则成本会失控。判断顺序可以这样：

1. **先看甜度是否稳定、够不够**
   - 茶饮店菠萝多用于果茶、冰沙、果酱、果肉，甜度直接决定**成品风味稳定性和糖浆用量**。
   - 甜度不稳定会导致同一产品批次口味波动，店员还要反复调整糖度，出品效率低。
   - 甜度低的水果通常需要更多糖或更多果肉来补味，反而增加配方成本。

2. **再看出汁率，设一个最低门槛**
   - 出汁率影响**出杯量、原料损耗和单杯成本**。
   - 如果是榨汁型产品，出汁率权重会上升；如果是果肉型产品，果肉率和香气、纤维口感比纯出汁率更重要。
   - 建议不要选“甜但几乎不出汁”的原料，除非你只做装饰或少量果肉。

3. **实际采购建议**
   - **做果茶、果肉型产品**：甜度/风味 ≥ 出汁率，重点看果肉率、香气、纤维感。
   - **做果汁、冰沙基底的店**：出汁率权重提高，但仍要先保证甜度底线。
   - **最佳做法**：先定甜度标准（如糖度范围），再在达标原料里选出汁率更高、单价更优的。
   - **算一笔单杯成本**：单杯原料成本 = 采购单价 ÷ 可用果肉/果汁产出率；不要只看每斤价格。

一句话：**甜度决定产品好不好卖，出汁率决定你赚不赚钱；先保甜度底线，再在合格原料里选出汁率高的。**
