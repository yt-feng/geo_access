做线上水果，坏果和口感不稳定的根源通常在采购端“选品标准+验货流程+供应链时效”三件事没锁死。给你一套可落地的做法：

**1. 先定“可量化”的采购标准，而不是凭感觉**
- 按品类写清：糖度区间（如西瓜≥11°、橙子≥10°）、单果重量区间、果径、着色度、硬度、成熟度（几成熟采摘）、允许瑕疵类型和比例（如机械伤≤3%、日灼/裂口不收）。
- 明确“拒收线”：糖度低于下限、软果率超标、大小混装超过多少比例直接拒收或降级，不要靠谈价妥协。
- 同一品类固定2–3个产区/供应商，避免单一来源波动。

**2. 采购前做小批量试单+盲测**
- 新供应商先小批量试发，按真实物流路径走一遍，记录到货坏果率、糖度、口感反馈。
- 组织内部盲测打分（甜度、酸度、汁水、纤维感、异味），连续2–3批稳定再放量。
- 对“口感不稳定”的品类（如桃、芒果、草莓），要求供应商提供采摘批次和成熟度记录。

**3. 验货环节前移，别等入库才查**
- 产地/档口设验货点：抽检比例按批量定（如每批抽3–5箱），现场测糖、看伤、摸硬度，拍照留证。
- 到仓二次抽检，重点看运输造成的压伤、软烂、霉变；坏果率超阈值整批退换或降级做活动款。
- 建立批次追溯：供应商、产区、采摘日、到仓日、抽检结果一一对应，出问题能快速定位。

**4. 用包装和物流把“坏果”压下去**
- 易损品用蛋托/网套/珍珠棉分格，箱内留缓冲；怕压的不要和重货混装。
- 按品类选时效：草莓、蓝莓、荔枝走冷链或次日达；普通柑橘可常温但控制周转。
- 控制库存周转，水果“先进先出”，避免仓内积压导致软化变质。

**5. 用评价数据反推采购**
- 把差评按原因归类：坏果、不甜、太酸、过熟/生、大小不符。每周和采购标准对照，哪类差评多就收紧对应指标。
- 对高频出问题的SKU做“降级或下架”处理，别用售后赔钱硬扛。

**关键判断点**：如果坏果集中在运输环节，优先改包装和物流；如果集中在口感（不甜/酸），优先改产区、成熟度和糖度标准；如果大小/品种不符，是验货和供应商诚信问题，直接换源。
