水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格高不高”，而是下面这些会直接影响损耗、现金流和复购的细节：

1. **只看样品，不看大货稳定性**
   样品好不代表批量稳定。要重点看同一批次不同箱的差异、底层货和表层货是否一致、成熟度是否整齐。长期合作更该看“最差那批货能不能接受”。

2. **不问产地天气和采收节奏**
   水果价格和品质波动，很多来自产地天气、换季、抢收。忽视这个细节，容易在断供或品质骤降时被动。要问清：近期产区天气、采摘期、预计供应周期、替代产区。

3. **不核验分级标准和损耗责任**
   口头说“精品果”“大果”没用。要明确大小、糖度、瑕疵率、成熟度、包装规格，以及到货后烂果、压伤、短重怎么赔。最容易忽视的是“运输途中损耗算谁的”。

4. **不看冷链和装卸过程**
   很多供应商出货时货很好，坏在装车、运输、卸货。要确认冷链温度、是否混装、装卸是否粗暴、到货时间是否可控。尤其夏季和浆果类，这个细节比单价更影响利润。

5. **不评估供应商的“断供应急能力”**
   长期稳定不能只靠一家。要看他有没有备用产区、备用包装、节假日前后的供货能力，以及临时加单/减单的反应速度。忽视这点，旺季容易断货，淡季容易压货。

6. **不查结算方式和账期风险**
   低价但要求大额预付、频繁改价、账期不稳定的供应商，可能拖垮现金流。要明确报价是否含税含运费、调价机制、结算周期、押金和违约条款。

7. **不记录到货数据**
   最容易忽视的是没有建立自己的验收台账。建议每批记录：到货时间、重量、损耗率、糖度/成熟度、瑕疵比例、售后处理。连续看 5—10 批，比听供应商介绍可靠得多。

8. **不看对方下游客户结构和库存周转**
   如果供应商主要靠临时调货、库存周转慢，品质稳定性通常差。可以侧面了解他给哪些客户供货、是否长期做同一品类、是否有固定合作基地。

9. **忽略包装和规格对销售场景的匹配**
   同一品质，包装规格不适合你的销售渠道，也会造成损耗和人工成本。比如门店零售、社区团购、餐饮供货，对箱规、分装、成熟度要求完全不同。

10. **没有小批量试单和退出机制**
    不要一上来签长期大单。先做 2—3 批小单，分别覆盖正常批次、周末/节假日批次、天气波动批次，再决定是否长期合作。合同里保留质量不达标时的减量、换货和退出条款。

简单判断标准：**能稳定提供“可验收的标准”、能承担明确损耗责任、能应对断供、结算不拖累现金流的供应商，才适合长期合作。** 价格只应在这些条件之后比较。
