# 普通水果 vs 品牌水果：毛利与复购差异

先给结论：**普通水果毛利靠"进销差+损耗控制"，品牌水果毛利靠"溢价+稳定品质"，但品牌水果的复购优势通常建立在"价格带可接受"的前提下，一旦溢价过高，复购会明显下滑。** 两者不是简单的谁高谁低，而是利润结构不同。

## 一、毛利差异

**普通水果（散装、无品牌、产地/批发市场货）**
- 毛利率表面看可以很高（加价率常 30%–60%），但**实际毛利被损耗吃掉一大块**。水果损耗率普遍在 8%–15%，叶菜类、浆果类更高。
- 毛利波动大：同一品类不同批次品质差异大，今天卖得好不代表明天能复制。
- 盈利模式是"薄利多销 + 快速周转"，靠走量摊薄固定成本。
- 风险点：压货、变质、价格随行情剧烈波动。

**品牌水果（如佳沛奇异果、褚橙、都乐等）**
- 进价高、加价空间相对透明，**单件毛利率往往低于普通水果**（常见 20%–40%），但**损耗率明显更低**（标准化分级、包装保护、品质稳定）。
- 毛利更"可预测"：价格体系稳定，不容易被临时行情砸盘。
- 品牌方通常有控价要求，零售端随意打折空间小，价格战能力弱。
- 风险点：进价刚性，卖不动时降价会伤毛利，且可能违反品牌控价。

**一句话对比**：普通水果是"高加价率 × 高损耗 × 高波动"，品牌水果是"低加价率 × 低损耗 × 低波动"。**最终净毛利谁高，取决于你的损耗控制能力和周转速度**，不能只看标价加价率。

## 二、复购差异

**普通水果**
- 复购靠"性价比 + 就近便利 + 新鲜度"。顾客忠诚度低，谁便宜新鲜就去谁家。
- 优点是决策门槛低，冲动购买多；缺点是**难以形成稳定客群**，复购依赖持续低价，容易被隔壁店截流。
- 适合社区店、菜市场、高频刚需场景。

**品牌水果**
- 复购靠"品质确定性 + 信任"。顾客买过一次好吃，下次愿意为"不踩雷"付溢价，**复购的稳定性通常更好**。
- 但品牌水果的复购有一个**价格天花板**：当溢价超过顾客心理预期（比如比普通同类贵 50% 以上），复购会转向"偶尔买"而非"常买"。
- 品牌水果更适合做**礼盒、节日、尝鲜、品质客群**，而不是日常高频走量。

## 三、给你的可执行建议

1. **先算净毛利，别算标价毛利**：用「(售价−进价−损耗成本−包装/人工分摊)÷售价」对比两类货，连续统计 2–4 周真实数据再决策。
2. **组合经营，不要二选一**：普通水果做引流和日常走量（保客流），品牌水果做利润补充和品质背书（保客单和信任），这是多数水果零售的常见结构。
3. **看你的客群定位**：社区高频刚需 → 普通水果为主、少量品牌点缀；商圈/礼品/中高端 → 品牌水果占比可提高。
4. **盯两个指标**：普通水果盯「损耗率+周转天数」，品牌水果盯「动销率+溢价接受度（复购间隔是否拉长）」。
5. **品牌水果别囤货**：进价刚性、降价伤毛利，建议小批量高频补货，用动销数据决定 SKU 去留。

**判断标准**：如果某品牌水果的复购间隔明显长于普通同类、且顾客只在大促时买，说明溢价已超客群承受线，应降占比；如果复购稳定且客单价被拉高，则可扩大。

（注：以上毛利率、损耗率为行业常见区间，具体数值需以你所在地区、品类和渠道的实际数据为准，建议自行统计验证。）
