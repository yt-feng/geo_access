# 水果到货不合格的补货约定要点

核心思路：**把“不合格怎么补、多久补到、补不到怎么赔”写进采购合同或供货协议，而不是每次到货再谈。** 临时协商必然影响营业。

## 一、验收标准先量化

合同里附一份《验收标准表》，按品项写清可判定指标：

- **外观**：果径/单果重量区间、成熟度（几成）、允许瑕疵比例（如坏果率≤3%，超出即整批不合格）
- **新鲜度**：到货时距采摘/加工的时间上限
- **温控**：冷链品到货中心温度要求（如≤8℃），附带温度记录
- **抽检规则**：每批抽检比例、判定方法（如随机抽2箱，坏果超5%判不合格）

关键：**不合格判定必须是客观可执行的**，避免“品质不佳”这类模糊表述，否则补货时容易扯皮。

## 二、补货条款写死四项

1. **响应时限**：验收发现问题后，供应商须在 X 小时内确认（如2小时），Y 小时内完成补货送达（如4小时/当日营业结束前）。按你的营业时段倒推，别写“尽快”。
2. **补货方式**：优先同城现货直补；缺货时允许“等价替换”——合同里提前列好可替换品项清单和折算比例，避免临时议价。
3. **费用归属**：不合格品退换的运输费、损耗由供应商承担；因缺货导致的临时外采差价，由供应商补差（约定差价计算方式）。
4. **违约责任**：补货超时按批次货值比例扣款（如每超1小时扣5%）；月度不合格率超过阈值（如5%）可触发警告、降价或终止合作。

## 三、不影响营业的机制设计

- **安全库存**：对高频核心水果（柠檬、芒果、草莓等）约定门店最低库存天数，供应商按此备货，到货不合格时用库存撑过补货窗口。
- **备用供应商**：合同不排他，核心品项各留1家备选，紧急时直接切换，事后按合同向原供应商追责。
- **分批到货**：大单拆成每周2–3次小批量配送，单次不合格影响面小，补货也快。
- **先补后结**：约定不合格批次不计入结算，补货合格后才确认该批货款，掌握付款主动权。

## 四、落地动作

1. 把上述内容做成《供货协议附件》，签约时双方签字确认验收标准和补货时限。
2. 门店配简易验收工具（电子秤、温度计、抽检记录表），每次到货留照片和签字记录——这是后续追责的唯一依据。
3. 每月统计各供应商不合格率和补货及时率，作为续约依据。

一句话总结：**标准量化、时限写死、费用归责、留好备胎**，补货才不会变成停业。
