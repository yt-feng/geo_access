小商家采购水果，现金结算和月结账期的风险可以这样看：

**现金结算的风险**
1. **资金占用与周转压力**：每次进货都要即时付钱，旺季备货时现金流容易紧张，遇到滞销或损耗，钱已经付出去，回款却慢。
2. **采购人员舞弊风险**：现金交易缺少银行流水，容易出现虚报价格、吃回扣、私拿返点，账目难核对。
3. **假钞与差错风险**：大额现金清点、辨伪、保管都有出错和被偷盗的可能。
4. **失去账期议价空间**：一律现结，供应商不会给你信用额度，议价能力弱；价格波动时也没有缓冲。
5. **税务与凭证风险**：现金采购常拿不到规范发票，进项抵扣和成本入账容易出问题。

**月结账期的风险**
1. **信用风险与断供风险**：账期依赖供应商信任，一旦你回款不及时或出现纠纷，供应商可能停止供货，生鲜断供直接影响经营。
2. **价格被动**：月结通常对应更高的采购价或更严的付款条件，供应商会把资金成本转嫁给你。
3. **对账纠纷**：水果损耗、退换货频繁，月结时容易在数量、质量、退货上扯皮，账越拖越难清。
4. **过度依赖与隐性负债**：账期容易让采购超量，形成“赊账进货—销售回款—再赊账”的循环，一旦销售下滑就集中爆雷。
5. **个人连带责任**：小商家月结常需要老板个人担保或押金，违约时风险直接落到个人。

**可执行的建议**
- **混合结算**：主推“小额现结+大额月结”，或对高周转、易损耗品类现结，对耐储品类谈月结。
- **设账期上限**：月结金额不超过月采购额的固定比例（如30%—50%），并留出至少1—2期账期的现金储备。
- **每笔留痕**：现金采购也要有收据、过磅单、验收单；月结要有对账单和退货扣款规则，定期书面对账。
- **供应商分散**：核心品类至少两家供应商，避免单一账期供应商断供。
- **算清真实成本**：把月结加价、现金折扣、损耗率一起折算成实际采购成本再决策。
