旺季菠萝用量突然变大，补货约定要抓“量、价、时、质、责”五个字。下面给你一套可直接落地的方法。

## 一、先做内部测算，再谈供应商

谈判前先算清楚，避免被供应商拿捏：

1. **预估缺口量**：按近7天实际菠萝消耗量×旺季剩余天数×（1+安全系数10%~20%），减去已下订单和库存。
2. **明确到货节奏**：不要只报总量，要拆成“每周/每几天到多少箱”，因为菠萝不耐久放。
3. **设定保底线**：最低可接受到货量=保证门店不断货的量，低于此量就要启动备选供应商。

## 二、和供应商约定时，必须写进合同/订单的条款

| 要素 | 具体约定方式 |
|---|---|
| **临时补货触发条件** | 约定“当周实际用量超过常规订单量20%时，可提前3天发出临时补货通知” |
| **补货量上限** | 约定单次补货不超过常规周量的X%，防止供应商无限加价或你方盲目囤货 |
| **价格机制** | 临时补货价格=基础价+约定浮动上限（如不超过市场批发价5%），或按“旺季统一价”锁定，避免坐地起价 |
| **到货时限** | 明确“通知后48小时内到货”，逾期按日扣款或可取消订单 |
| **质量标准** | 写明成熟度、单果重量、坏果率上限（如坏果率≤3%），到货当场抽检 |
| **付款与违约** | 临时补货可约定“货到验收后7天内付款”；供应商断供需提前X天告知并承担违约金 |

## 三、操作层面建议

1. **签一份“旺季临时补货补充协议”**，不要只在微信里口头说，把上面条款固定下来。
2. **保留一个备选供应商**，哪怕平时不用，旺季前先小批量试单，确保断供时有退路。
3. **每天记录到货和消耗数据**，作为触发补货和后续对账的依据。
4. **提前3~5天发补货通知**，给供应商留采购和运输时间，不要等断货才急call。

## 四、话术示例

> “旺季我们用量会上浮，想跟你约定：每周三前我报下周临时补货量，你48小时内送到，价格按我们锁定的旺季价走，单次补货量在常规量50%以内。如果你那边货源紧张，提前3天告诉我，我好安排。这样双方都好排产。”

**核心原则：把“临时”变成“有规则的临时”**——提前约好触发条件、价格上限和到货时限，既保证不断货，也避免旺季被临时加价。
