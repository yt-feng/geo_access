采购香蕉做甜品，想避免到店后很快变黑，关键不是“买最黄的”，而是控制成熟度和后熟速度。给你一套可直接执行的做法：

1. **采购时选“青黄交接”的香蕉**
   - 优先选：**果身黄、两头略青、无黑点**的香蕉。
   - 不要选：**通体深黄、带黑斑、果柄发黑**的，这种到店后很快过熟变黑。
   - 轻按果身：**略有硬度但不硬邦邦**，太软说明已后熟。

2. **按用量分批买，别一次囤太多**
   - 甜品店香蕉变黑，常见原因是库存周转慢。
   - 建议按**2～3天用量**采购，旺季少量多次补货。

3. **运输和到店后不要闷在塑料袋里**
   - 香蕉会释放乙烯，闷在袋里会加速成熟变黑。
   - 到店后立即**拆袋、通风、摊开**，不要堆压。

4. **储存温度要避开冷藏**
   - 未熟或半熟香蕉**不要放冰箱**，低温会导致表皮快速变黑。
   - 放在**阴凉通风处，12～15℃左右**较合适；夏天可放空调房或通风库房。
   - 已熟透、当天要用的可冷藏，但表皮仍可能变黑，影响卖相。

5. **悬挂或单层摆放，减少压伤**
   - 压伤处会先黑。
   - 用挂钩悬挂，或单层平铺，避免叠放。

6. **把果柄包起来，减少乙烯扩散**
   - 用保鲜膜包住香蕉**果柄**，可减缓后熟。
   - 注意只包柄，不要整根密封。

7. **和苹果、梨等催熟水果分开**
   - 苹果、梨、番茄等释放乙烯多，会加速香蕉变黑。

8. **先进先出，熟蕉优先做熟制甜品**
   - 已偏熟的香蕉优先用于**香蕉派、香蕉蛋糕、奶昔、焦糖香蕉**等，不要继续等。
   - 轻微表皮黑点不影响果肉，但出现**果肉软烂、酒味、渗液**就不要用。

9. **到店验收标准**
   - 抽检：果柄青绿或微黄、果身无大面积黑斑、无压伤、无酒味。
   - 发现过熟批次单独存放，优先使用。

**最稳妥的组合：买青黄交接的香蕉 + 少量多次采购 + 到店拆袋通风 + 阴凉悬挂 + 包果柄 + 先进先出。**  
如果你们店用量大，可以固定要求供应商送**七成熟左右**的货，比买全黄蕉更耐放。
