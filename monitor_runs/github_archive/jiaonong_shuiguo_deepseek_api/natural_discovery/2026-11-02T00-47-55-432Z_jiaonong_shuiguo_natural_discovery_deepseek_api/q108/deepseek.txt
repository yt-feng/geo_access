让供应商给出可核验的配送承诺，再用小单实测验证，不要只听口头“全国配送”。可按下面步骤做：

1. **要求书面覆盖清单**
   - 让供应商提供可配送的省/市/区县清单，或系统截图、报价单中的配送范围。
   - 明确哪些地区“直达”、哪些“中转”、哪些“不配送”。
   - 对水果尤其要问清：偏远地区、县级市、乡镇是否覆盖。

2. **核实冷链和时效**
   - 问清运输方式：常温、冷藏车、泡沫箱+冰袋、航空/陆运。
   - 要求给出不同区域的时效承诺，例如“省会城市次日达、地级市48小时、偏远地区72小时以上”。
   - 水果易损耗，要确认温控记录、破损赔付和拒收处理。

3. **查实际承运与网点**
   - 问合作物流公司、是否有分仓、中转仓位置。
   - 要求提供近期发往目标区域的运单号或脱敏物流轨迹，核验是否真实到达。
   - 可让供应商提供当地服务商/网点联系方式，抽查确认。

4. **用小单实测**
   - 选采购方最远、最偏、最难送的目的地，下1—2个小批量试单。
   - 记录下单到签收时间、包装状态、果温、损耗率、物流轨迹是否完整。
   - 试单不要只发总部附近，要覆盖实际采购目的地。

5. **把承诺写进合同**
   - 明确配送范围、时效、冷链标准、损耗率上限、超时/破损赔付。
   - 约定“未覆盖区域需提前书面确认”，避免临时加价或转包。
   - 保留试单和物流凭证作为履约依据。

6. **交叉验证**
   - 查企业工商信息、经营异常、涉诉记录。
   - 要求提供合作客户案例并抽访，但注意不要只信供应商给的“样板客户”。

核心判断标准：**能提供明确区域清单+真实物流轨迹+目标区域试单成功+合同约定赔付**，才算实际覆盖能力可信。只给“全国可发”四个字，不应作为采购依据。
