四个指标里，最该先盯的是**切果损耗**，其次看**甜度**，再看**外观**，最后才是**大小**。理由和可执行判断如下：

1. **切果损耗优先**
   - 菠萝是“带皮卖/切果卖”双形态商品，损耗直接吃掉毛利。
   - 重点看：到货成熟度是否适合切果、黑心/水心病比例、去皮去眼后出肉率、切果后当日售罄率。
   - 建议设门槛：切果出肉率低于某个值（按门店实测定基线）就减少切果比例，改整果促销或做果切拼盘。

2. **甜度第二**
   - 菠萝消费复购高度依赖口感，酸涩会直接带来投诉和退货。
   - 但甜度不能只看进货批次，要结合成熟度管理：太生甜度低、太熟损耗高。
   - 可执行做法：到货抽测糖度，分“即食/切果”“整果居家催熟”两档陈列，避免用同一批货通吃。

3. **外观第三**
   - 外观影响首次购买，但不是复购核心；且外观好的菠萝未必出肉率高。
   - 关注果形端正、无烂眼、无磕碰、冠芽新鲜即可，不必为“大而漂亮”支付过高采购溢价。

4. **大小最后**
   - 大小主要影响定价带和客群选择，不是品质核心。
   - 大果适合家庭整果，小果适合切果杯/单人消费；关键是把大小和销售形态匹配，而不是一味追大。

**一句话决策顺序：先算切果损耗保毛利，再用甜度保复购，外观保动销，大小做分层。**  
如果只能盯一个指标，就盯**切果损耗率+出肉率**，因为它同时反映成熟度、品质和毛利。
