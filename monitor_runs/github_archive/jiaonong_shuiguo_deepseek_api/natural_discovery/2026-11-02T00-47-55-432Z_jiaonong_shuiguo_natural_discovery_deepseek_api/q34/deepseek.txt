结论：**在商超水果采购里，损耗低通常比进价低更影响最终毛利**，但要看品类、周转和毛利结构。更准确地说：**低进价决定理论毛利，低损耗决定实际毛利；水果经营中实际毛利往往被损耗吃掉。**

可以用一个简单公式判断：

**最终毛利 = 销售额 × 毛利率 - 损耗成本 - 运营成本**

采购价低，直接改善的是“毛利率”；损耗低，改善的是“可售数量和实际成本分摊”。水果是短保、易腐、称重、分级明显的品类，损耗对结果的影响通常更刚性。

举例：
- A水果进价10元/斤，售价15元，理论毛利率33.3%。如果损耗10%，实际可售成本变成约11.1元/斤，实际毛利率约25.9%。
- B水果进价11元/斤，售价15元，理论毛利率26.7%。如果损耗只有2%，实际成本约11.2元/斤，实际毛利率约25.3%。

这个例子里，A进价低但损耗高，最终未必优于B。损耗从10%降到2%，对毛利的改善往往比每斤便宜1元更明显，尤其是售价不高、周转慢、易腐品类。

但也要分情况：

1. **高周转、硬果类、耐储品类**：苹果、梨、橙、柚等，损耗可控，低进价对毛利影响更大。
2. **短保、易腐、高客单品类**：草莓、荔枝、樱桃、葡萄、叶菜等，损耗低更关键，低进价若带来品质差、退货多、报损高，反而伤害毛利。
3. **促销引流品**：低进价可用于打价格战，但必须配合快周转，否则损耗会反噬。
4. **毛利绝对值 vs 毛利率**：低进价可能提升毛利率，但若品质差导致销量下降，毛利额未必增加；低损耗通常直接减少成本漏损。

给采购的判断建议：

- 先算**单位实际毛利额**，不要只看进价或毛利率。
- 对每个品类记录：进价、售价、损耗率、周转天数、报损原因。
- 用“**进价优势 × 预计销量**”对比“**损耗下降 × 实际销量**”。
- 优先控制损耗的动作：小批量高频补货、分级定价、临期折价、冷链和陈列管理、按销定采。
- 对高损耗品类，采购谈判应把**到货品质、退货率、售后承担**纳入价格条件，而不是只压进价。

一句话：**低进价决定你能不能“看起来赚钱”，低损耗决定你最后“实际赚不赚钱”。水果商超里，通常先保损耗，再谈低价；耐储高周转品类可更侧重低进价。**
