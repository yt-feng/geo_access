超市担心水果农残抽检，向供应商要资料的核心是：**能追溯到批次、能证明该批次经过合格检测、能界定责任**。建议按下面清单提前索取，并在采购合同/质量协议中写明“随货提供、缺项拒收”。

## 一、必查的主体与资质资料
1. **营业执照**（供应商/合作社/种植主体）
2. 若为生产型企业：**食品生产许可证**；若为经营企业：**食品经营许可证**（或仅销售预包装食品备案凭证，视当地要求）
3. **供货商与上游种植基地的关系证明**：基地直供协议、合作社供货证明、产地证明等，避免“来源不明”
4. 进口水果另需：**海关入境货物检验检疫证明**、报关单等

## 二、按批次必须随货提供的资料（重点）
1. **该批次农残检测报告**
   - 优先要 **CMA/CNAS 资质检测机构**出具的报告；
   - 报告要能对应：**品名、产地、生产/采摘日期、批次号、检测项目、检测结果、报告编号、检测日期**；
   - 注意报告是否“张冠李戴”：批次、日期、品种对不上的一律不认。
2. **产地证明/承诺达标合格证**
   - 农产品质量安全承诺达标合格证是产地准出常用凭证，可作为来源与责任线索；
   - 要求合格证信息与到货批次一致。
3. **进货凭证/销售单据**
   - 发票或送货单上写明品名、规格、产地、批次、数量、日期，便于追溯和抽检不合格时倒查。

## 三、建议额外索取的资料
1. **供应商质量控制承诺书/质量保证协议**：明确农残超标时的退货、赔偿、检测费承担、召回配合责任。
2. **种植基地清单与用药管理记录**（尤其高风险品种、反季节、叶菜类/草莓/葡萄等）：农药品种、安全间隔期执行情况。
3. **近3—6个月同类品种的检测记录**：判断供应商稳定性，不替代批次报告。
4. **第三方抽检/飞行检查记录**（如有）。
5. **包装标识信息**：产地、生产者、采摘日期、批次码，便于超市建立进货台账。

## 四、操作上的判断标准
- **一批一报告**：不能拿一份旧报告覆盖全年所有批次；
- **报告项目要覆盖常见高风险农残**，并与该品种常用农药相符；
- **报告日期早于到货、晚于采摘**才合理；
- 对高风险品种可要求 **到货前预检** 或超市自行快检/送检，费用和责任在合同中约定；
- 资料不全的批次**暂缓收货**，不要先收后补。

## 五、合同里建议写明的条款
- 随货资料清单及缺项处理；
- 农残抽检不合格的**退货、销毁、赔偿、检测费及监管处罚责任**由供应商承担；
- 供应商须配合追溯至基地，并在规定时限内提供上游资料；
- 因供应商资料虚假导致的超市损失由其全额承担。

一句话：**资质看主体，报告看批次，合格证看产地，单据看流向，合同看责任。** 其中“对应批次的农残检测报告+承诺达标合格证+可追溯送货单”是最不能少的三角资料。
