连锁超市降低门店坏果率，合同里要把“质量标准—验收—损耗归责—赔付计算—扣款/退换—追溯与终止”写成可执行的条款，而不是只写“坏果包赔”。建议按以下结构约定：

1. **明确“坏果”定义和验收标准**
   - 按品类写清成熟度、色泽、大小、软烂、霉变、机械伤、冻伤、虫害、异味等判定标准；能量化的尽量量化（如单果缺陷面积、整批允许缺陷比例）。
   - 约定验收抽样方法：抽样比例、抽检点位、以到店验收还是配送中心验收为准、复检时限。
   - 区分“外观瑕疵”和“可食用性缺陷”，避免门店把所有瑕疵都算坏果。

2. **约定允许损耗率与超标赔付**
   - 按品类设“自然损耗率/允许坏果率”，例如叶菜、浆果、根茎类分别设阈值，不要一刀切。
   - 超过阈值部分按“超标数量×结算单价×赔付倍数”赔付；也可约定“超标即整批退换+违约金”。
   - 赔付基数用含税采购价还是不含税价、是否含运费，要写清。
   - 建议设置单次赔付上限和月度累计上限，同时保留严重质量问题的整批退货权。

3. **区分责任环节**
   - 到店验收前坏果：供应商责任，退换或扣款。
   - 验收后因门店陈列、温控、翻堆、保质期管理不当造成的坏果：门店/超市承担，避免供应商无限兜底。
   - 运输环节若由供应商或其承运商负责，写清温度记录、到货时限和异常举证责任。

4. **退换货与扣款机制**
   - 约定“先退换、后扣款”或“直接扣款”的适用情形；退换货时限、补货时限、运费承担。
   - 扣款从货款中直接抵扣的授权条款，以及月度对账单确认机制。
   - 避免只靠口头报损：要求门店留存照片、称重记录、批次号、验收单，供应商有异议的复核期限。

5. **批次追溯与举证**
   - 每批附产地、采摘/包装日期、批次号、冷链温度记录；到店扫码或单据关联。
   - 约定坏果争议的举证顺序：验收单+照片/视频+称重记录优先；供应商可申请复检，逾期视为认可。
   - 对霉变、农残、异物等食品安全问题单列“一票退货/解约”条款。

6. **考核与终止**
   - 设月度坏果率考核，连续超标或单次严重超标可提高赔付倍数、暂停供货、扣保证金直至解约。
   - 把赔付与账期、返利、保证金挂钩，但注意不要写成变相罚款而缺乏合同依据。

7. **表述上避免的坑**
   - 不要只写“坏果率不超过X%”，要写清分子分母、统计周期、按重量还是按件数。
   - 不要写“一切损耗由供应商承担”，否则门店管理责任无法区分，实际执行也容易争议。
   - 赔付条款要和验收条款、退货条款互相引用，形成闭环。

简单说：合同里应写成“分品类标准+抽样验收+允许损耗阈值+超标按量赔付+责任环节区分+单据追溯+考核退出”，这样门店坏果率才有可执行的合同抓手。具体阈值和赔付倍数需结合品类、采购价和供应商谈判地位设定。
