按“出品稳定性、损耗、人工”来选，比只看单价更划算。直接给你可执行建议：

1. **苹果**
   - 选**80–85mm 左右、单果 180–220g**的中大果，做拼盘切块外观整齐、出成率高。
   - 不要选太小果：切块后边角多、显廉价；也不要超大果，单价高且一个用不完易氧化。
   - 餐厅可优先选**富士/嘎啦/花牛**等耐放、色泽稳定的品种。
   - 划算判断：按“可用块数/个”算，不按“斤价”算。单果切出可用果肉率能到 80%以上就算合格。

2. **橙子**
   - 选**70–80mm 果径、单果 180–250g**的脐橙/血橙/沃柑类，皮薄、瓣整齐、好剥。
   - 做拼盘建议用**无籽或少籽**品种，减少人工挑籽。
   - 不要选过小果：剥瓣后碎、出品少；过大果皮厚也可能不划算。
   - 划算判断：按“可剥出完整瓣数/个”和“废皮率”算。废皮率低于 25%–30% 较理想。

3. **菠萝**
   - 选**单果 1.2–1.8kg 左右、成熟度 7–8 成**的菠萝，出肉率和切块稳定性较好。
   - 太小果出肉少、削皮人工占比高；太大果一次用不完，切开后损耗和氧化风险高。
   - 餐厅若销量稳定，优先用**去皮菠萝/菠萝块**半成品，按可用净重算成本，往往比整果更省人工。
   - 划算判断：整果按“净出肉率”算，普通菠萝净出肉率约 45%–55%；低于这个区间就不划算。

**采购组合建议：**
- 小餐厅/低销量：苹果、橙子选中等规格，菠萝买半成品净果，减少损耗。
- 中高销量：苹果 80–85mm、橙子 70–80mm、菠萝 1.2–1.8kg 整果批量采购，但要求供应商稳定同一规格。
- 砍价时不要只问“多少钱一斤”，要问：**单果规格、净出成率、可不能用次果、是否无籽/耐氧化、送货频次**。

**最划算的核算公式：**
> 每份拼盘成本 = 采购单价 ÷ 净出成率 ÷ 每份用量 + 人工分摊 + 损耗率

优先选**规格稳定、净出成率高、少人工处理**的货，而不是表面单价最低的货。
