连锁商超招标长期水果供应商，评分标准建议围绕“长期稳定供货能力”设计，而不是只看报价。可按100分制设置，核心权重如下：

**1. 产品质量与安全 25–30分**
- 果品规格、成熟度、糖度、外观、农残检测报告
- 食品安全资质：营业执照、食品经营许可证、种植/加工环节检测
- 退换货与质量赔付机制
- 可设置否决项：农残不合格、无法提供检测报告直接废标

**2. 供应稳定性与产能 20–25分**
- 自有基地/长期合作基地面积、产地数量
- 年供货能力、峰值日供应量
- 多产区布局、季节性替代方案
- 历史供货履约记录、违约情况
- 冷链仓储与运输能力

**3. 价格与成本 20–25分**
- 不要只比单价，建议采用“综合报价+价格调整机制”
- 报价包含税费、运费、损耗、包装
- 设置价格波动规则：随行就市但有上限，或按月度/季度调价
- 对异常低价要设成本合理性审查，防止低价中标后断供或降质

**4. 配送与履约服务 10–15分**
- 到店/到仓时效、配送频次
- 冷链覆盖率、温控记录
- 紧急补货响应时间
- 损耗率承诺、缺货赔付
- 信息化对接能力：订单、库存、追溯系统

**5. 企业资质与财务能力 5–10分**
- 注册资本、成立年限、近三年营收
- 财务报表、抗风险能力
- 社保、纳税、诉讼与失信记录
- 可要求提供履约保函或质量保证金

**6. 售后与长期合作 5–10分**
- 专职服务团队、问题响应时限
- 年度降本或新品导入能力
- 可持续供应方案、应急保供预案
- 合作意愿与账期接受度

**建议的废标/否决项：**
- 无食品经营相关资质
- 提供虚假检测报告
- 近三年重大食品安全事故
- 失信被执行人
- 无法满足最低日供应量或冷链要求

**评标方法建议：**
采用“综合评分法”，技术+供应保障权重不低于50%，价格权重控制在20%–30%。长期供应合同不宜最低价中标，应设置“质量与供应保障一票否决”和“履约保证金”。同时把关键承诺写进合同：缺货赔付、质量不合格扣款、价格调整公式、年度考核退出机制。

这样设置的核心是：**价格可竞争，但质量、产能、冷链和履约能力必须设门槛**，避免中标后出现断供、降质或季节性涨价失控。
