# 香蕉、菠萝、苹果组合促销方案

## 先明确一个判断

这三样都是**低单价、高感知价格**的引流型水果，单靠“打折”几乎提不动客单价。想提客单价，核心不是把这三样卖贵，而是**用它们当“钩子”，把顾客的购买篮从“单买一样”变成“组合+搭配”**。所以组合促销要围绕三个动作设计：**打包、加购、凑单**。

## 方案一：分级组合包（主推，直接拉客单）

设计三档组合，价格锚点清晰：

| 档位 | 内容 | 定价思路 |
|---|---|---|
| 小份尝鲜包 | 香蕉2根 + 苹果2个 + 菠萝1/4个 | 定在日常单买总价略低，制造“划算感”，吸引原本只买一样的人 |
| 家庭分享包 | 香蕉1把 + 苹果4个 + 菠萝半个 | 定在比小份明显划算的单价上，主力拉客单 |
| 办公室/囤货包 | 香蕉1把 + 苹果6个 + 整只菠萝 | 配一个“买整箱/整把更省”的价，冲高单笔 |

**关键点：** 组合价一定要让顾客能一眼算出“比分开买省多少”，在价签上直接标“单买合计X元，组合价Y元”。

## 方案二：加购凑单（提客单最有效）

- **满额换购**：买任意水果满一定金额，加少量钱换购香蕉一把或菠萝一只（香蕉、菠萝成本低、感知价值高，适合做换购品）。
- **主品带加购**：买苹果/菠萝，加价加购香蕉；或买香蕉，加价换购切好的菠萝块。
- 作用是把“只买苹果”的顾客往“苹果+香蕉+菠萝”上推。

## 方案三：场景化搭配（提高连带）

- **早餐/果盘场景**：香蕉+苹果做“每日果盘包”，贴“早餐/办公室”标签。
- **菠萝当加工品卖**：现场切菠萝卖果切，果切毛利和客单都高于整只，还能带动香蕉、苹果做混合果切盒。
- 混合果切盒是提客单的隐形利器：一份盒装里放三种水果，单价上去，损耗也降。

## 执行要点（决定成败）

1. **陈列联动**：三样水果相邻摆放，组合包用统一包装/标签集中陈列，别分散。
2. **价签讲清对比**：每个组合都标“分开买合计多少、组合省多少”。
3. **控制损耗**：香蕉、菠萝易损，组合包按日销量小批量出，卖不完的转果切，别压货。
4. **设一个引流款**：比如香蕉做低价引流，把人流引到组合包和果切上，利润从组合和加工品里出。
5. **限时限量**：组合包做“每日限量”，制造紧迫感，避免变成长期低价。

## 一句话结论

**别把这三样当利润品打折，要把它们做成“组合包+加购钩子+果切加工”的三层结构**：组合包直接抬单笔金额，加购凑单提升连带率，果切把低毛利整果转成高毛利商品。先跑两周看组合包占比和客单价变化，再调档位和价格。
