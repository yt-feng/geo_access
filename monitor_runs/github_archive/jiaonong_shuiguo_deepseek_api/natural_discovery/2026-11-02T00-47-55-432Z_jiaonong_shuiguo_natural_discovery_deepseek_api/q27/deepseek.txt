判断苹果和橙子的规格是否适合门店销售，可以从“可量化标准 + 门店场景 + 验收动作”三层来做，不需要只凭感觉。

## 一、先定门店销售规格标准

按门店客群和售卖方式定规格，不要所有门店一个标准。

| 品类 | 常见规格判断 | 适合场景 |
|---|---|---|
| 苹果 | 按单果重/果径分：小果、中果、大果、特大果 | 中果最适合散卖和家庭装；大果适合礼盒/精品陈列；小果适合特价或餐饮渠道 |
| 橙子 | 按果径和单果重分：小果、中果、大果 | 中果最适合日常散卖；大果适合礼盒和精品；小果适合榨汁或特价 |

建议门店先确定：
- **散卖主销规格**：苹果、橙子各定1个主销规格，避免同一陈列位混多个规格。
- **礼盒/精品规格**：单独定上限规格。
- **特价/引流规格**：单独定下限规格。

## 二、用可执行指标验收

采购时不要只看“大不大”，要同时看以下指标：

1. **单果重**：随机抽20—30个称重，算平均单果重和最大最小差。同一批货单果重差异过大，说明分级不稳。
2. **果径**：用果径圈或卡尺抽测，确认是否在约定区间内。苹果、橙子都应按果径分级。
3. **整齐度**：同一箱内大小是否一致。门店陈列最怕一箱里大小混杂，影响卖相和定价。
4. **外观缺陷率**：抽检统计碰伤、裂口、日灼、病斑、畸形果比例。散卖果缺陷率应控制得较低，礼盒果要求更严。
5. **新鲜度**：看果柄、果皮光泽、硬度、有无异味。橙子还要看皮是否过软、有无霉变。
6. **成熟度**：苹果看底色和硬度，橙子看皮色和手感。门店销售要选适合货架期内的成熟度，不能太生也不能过熟。

## 三、结合门店销售场景判断

规格是否适合，最终看门店怎么卖：

- **散卖陈列**：优先中果，大小整齐、单果重量稳定，顾客挑选方便，损耗可控。
- **家庭装/袋装**：规格可以略统一，重点是单袋总重和个数稳定，便于定价。
- **礼盒/精品**：选大果、外观好、整齐度高，但要看门店客群是否接受溢价。
- **特价引流**：小果可以，但缺陷率不能高，否则影响口碑。
- **餐饮/榨汁渠道**：橙子可接受小果，但出汁率和新鲜度要重点看。

## 四、采购现场可直接执行的动作

1. 先向供应商要**分级标准**：果径区间、单果重区间、允许缺陷率。
2. 到货随机抽3—5箱，每箱抽10个，记录果径、单果重、缺陷数。
3. 算**平均单果重、规格合格率、缺陷率、大小极差**。
4. 对照门店主销规格，判断：
   - 合格率高、整齐度好：可做主销陈列；
   - 大小混杂但品质不差：降级做特价或袋装；
   - 缺陷率高、过软、霉变：拒收或退货。
5. 首次合作先小批量试销，看**动销速度、损耗率、顾客反馈**，再决定是否放量。

## 五、简单判断口径

- **适合门店主销**：规格整齐、单果重稳定、缺陷率低、新鲜度好、符合门店定价带。
- **不适合主销但可降级**：大小不齐或略小，但品质正常，可做特价、袋装、榨汁。
- **不适合门店销售**：缺陷率高、过熟、霉变、规格严重偏离约定、货架期短。

核心原则：**先定门店主销规格，再用抽检数据验收，最后用小批量试销验证动销和损耗。**
