**一般能争取到的支持：**
1. **价格支持**：周末特价供货、满量返利、临时补贴、搭赠（买N箱送1箱）、尾货折价。
2. **物料支持**：海报、价签、爆炸贴、展架、试吃台、包装袋、围裙、帐篷/遮阳伞（看品牌方）。
3. **人员/活动支持**：试吃员、导购、促销员，品牌方做地推时更常见。
4. **账期/退换支持**：临时延长账期、滞销品调换、损耗补偿，这个难度较高，适合长期合作。

**适合周末促销的品类**：应季水果、供应商主推品、库存压力大的品、新品试销。进口水果、品牌水果更容易拿到物料；本地批发市场的散货供应商价格能谈，但物料少。

**谈判建议：**
- 提前3-7天沟通，别周五才找。
- 明确说清：促销时间、预计销量、陈列位置、是否发朋友圈/社群、是否做试吃。
- 用“增量”换支持：比如“我周末两天预计卖X箱，能否给特价/搭赠/物料”。
- 优先找长期合作、走量大的供应商；新供应商先用小单试。
- 把支持写进订单或微信确认：价格、数量、物料清单、送达时间、是否可退换。

**判断标准：**
- 供应商愿意给价差或搭赠，说明支持真实。
- 只给海报不给价格，价值有限。
- 要求你压货、承诺销量但不愿给退换的，要谨慎。
