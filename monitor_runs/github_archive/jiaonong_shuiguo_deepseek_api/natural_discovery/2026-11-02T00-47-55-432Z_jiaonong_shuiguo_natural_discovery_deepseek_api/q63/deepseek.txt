判断哪个规格更容易出货，不要只看“哪个问的人多”，要同时看**成交速度、走量、退货/损耗、价格接受度**。可按下面做：

1. **先分规格记录真实成交**
   - 按重量/果径/箱规分档，例如：小果、中果、大果、精品果。
   - 每档记录：询价数、成交单数、成交箱数、平均成交价、从入库到售罄天数、退货/坏果率。
   - 重点看两个指标：**售罄天数**和**成交转化率**。询价多但成交少，不算好出货。

2. **看下游客户结构**
   - 水果店/社区团购：通常中果、小果走量快，价格敏感。
   - 餐饮/果汁店：更看出肉率和单斤成本，中大果可能更稳。
   - 礼盒/精品店：大果、外观好的规格利润高但量小。
   - 如果同一规格被同类客户反复补货，说明它更容易出货。

3. **看价格带和替代品**
   - 把每档规格换算成**单斤价、单果价、每箱毛利**。
   - 如果某规格只比上一档便宜一点，但品质差很多，往往不好卖。
   - 如果某规格价格接近凤梨/其他热带水果，出货会变慢。

4. **做小批量测试**
   - 每档规格各留固定数量，比如各20箱，同一周期、同一片区试销。
   - 记录3—7天内售罄比例。先售罄且补货频繁的规格优先加量。
   - 不要一次压太多，菠萝损耗和熟度变化快。

5. **看损耗和售后**
   - 菠萝容易有黑心、过熟、碰伤。某规格虽然卖得快，但退货率高，实际不一定赚钱。
   - 用“**每箱净毛利 = 售价 - 进价 - 损耗 - 售后 - 运费**”比较，而不是只看售价。

6. **简单判断规则**
   - 售罄最快 + 补货最多 + 退货低 = 主推规格。
   - 询价多但成交慢 = 价格或品质不对，需调整。
   - 利润高但售罄慢 = 控制库存，做精品小批量。
   - 两个规格差不多时，优先选**周转快、损耗低**的，不要只选单价高的。

实操上建议你连续记7—10天，每个规格一张表：询价数、成交箱数、售罄天数、退货率、每箱净毛利。数据出来后，最容易出货的规格通常很清楚。
