社区超市找日配水果供应商，重点看下面几类条件，按“先保供应稳定，再保损耗可控，最后谈价格”的顺序判断。

**1. 配送能力**
- 是否每天固定配送，能否指定到店时间，比如早6—8点，赶在开门前上架。
- 是否覆盖你所在区域，配送车辆、冷链条件如何；夏季高温时是否有冷藏车或保温箱。
- 缺货、临时加单、节假日能否响应，最小起订量和加急费用怎么算。
- 是否支持少量多品配送，社区超市通常单品种量不大但品类要多。

**2. 货源与稳定性**
- 是产地直采、一级批发还是二级分销。层级越少，通常价格和新鲜度越有优势，但也要看其供应能力。
- 主营品类是否匹配你的客群：高频刚需如苹果、香蕉、橙子、梨、西瓜、时令果。
- 是否有稳定基地或合作市场，换季时能否持续供货，断货替代方案是什么。
- 要求提供近期供货案例，最好能看其他社区店或小超市的配送记录。

**3. 品质与验收标准**
- 明确规格：单果重量、等级、成熟度、糖度、外观瑕疵容忍度。
- 约定验收标准：坏果率、磕碰率、腐烂率上限，比如到店验收坏果超过3%—5%如何处理。
- 是否支持开箱验货、当场拒收，拒收部分如何补货或扣款。
- 试配送至少1—2周，观察不同品类和不同天气下的稳定性。

**4. 价格与结算**
- 报价是否含税、含运费、含包装，是否随行就市每天报价。
- 价格调整机制：按批发市场价浮动还是固定周期调价，避免行情下跌时仍按高价结算。
- 账期和结算方式：现结、周结还是月结，是否需要押金。
- 对比2—3家供应商同品类到店价，不只看单价，要算上损耗和配送费后的实际成本。

**5. 损耗与售后**
- 坏果、滞销果能否退换，退换时限和流程是什么。
- 是否允许少量尾货处理或调换，社区店销量波动大，这点很关键。
- 出现品质问题时的响应时间，比如当天补货或下次配送抵扣。

**6. 资质与合规**
- 营业执照、食品经营相关资质是否齐全。
- 水果是否有农残检测或产地证明，至少能提供批次来源信息。
- 配送人员健康证、车辆卫生情况，这些在日常经营和检查中会用到。

**7. 合作条款**
- 先试配送再签长期协议，试配期明确品类、频次、验收和结算。
- 合同写清配送时间、缺货违约责任、品质标准、价格调整方式、退换货规则。
- 不要一次性押大量货款，账期和押金控制在自己能承受的范围。

**实操建议：** 先找2—3家同时试配两周，每天记录到货时间、坏果率、缺货次数、实际毛利。社区超市最怕的不是单价高一点，而是天天断货和损耗失控。优先选配送准时、售后响应快、能做小批量多品类的供应商，再逐步谈价格。
