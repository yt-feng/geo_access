# 节假日水果需求暴增的货源锁定方案

## 一、提前锁定在时间上要抓三个窗口

1. **节前3-4个月：签框架协议**
   按去年同期的销量峰值上浮20-30%（节假日+促销叠加），与主供应商签订保量协议，明确"保底量+弹性增量上限"，先锁量不锁死价格。此时供应商愿意给量，价格谈判空间也最大。

2. **节前4-6周：锁定具体品项和到货节奏**
   把框架协议拆成到货计划，按节前7天、3天、节中每日分批次排产。避免一次性大量到货造成的损耗。

3. **节前7-10天：签订储备补货协议**
   预留1-2家后备供应商，谈好"48小时能补多少货"，作为应急兜底。

## 二、多源布局，降低单点断供风险

- **产地直采 + 区域批发市场 + 本地合作社**三条腿走路。核心爆款（如车厘子、砂糖橘、草莓、礼盒水果）至少2个产地、2家供应商。
- 易受天气和物流影响的品项（进口水果、冷链品），提前确认船期和冷链运力，节前物流紧张是断供的高发环节。
- 对包装礼盒类，提前锁包装材料供应商，否则货到了装不出来。

## 三、用合同条款把"锁货"变成"锁得住"

- 约定**违约保供条款**：供应商未能按量到货时的赔偿/替换义务。
- 约定**价格调整机制**：随行就市但设上下限，避免节日期间坐地起价。
- 支付**预付款或定金**换取优先供货权，这是最直接的锁定手段，但要注意核对对方资质、分批付、留尾款。

## 四、内部配套动作

- **按SKU做需求预测**：用近2-3年节假日单店/单品类销量数据建模，而不是拍脑袋。
- **设置安全库存和补货触发线**：节前提前把库存拉到安全线以上。
- **建立每日到货跟踪表**：对核心品项逐日核对到货量、在途量，发现缺口立即启动后备供应商。
- **冷链和仓储提前预订**：节日期间冷库和运输资源同样紧张。

## 五、可判断的执行标准

节前6周应满足：核心爆款每个SKU有≥2家签约供应商；已签保量协议的覆盖需求量的80%以上；后备供应商补货响应时间≤48小时；核心品项安全库存到位率100%。达不到就继续谈、继续找源。

**一句话总结**：早签协议锁量（3-4个月前）、多源布局防断供、预付款+违约条款锁得住、按数据预测而不是按感觉备货。
