和水果供应商谈酒店早餐合作，重点不是先把价格压到最低，而是先确保“每天稳定、品质一致、出问题能补位”。建议按下面几件事准备和谈。

**1. 先明确自己的需求，再谈条件**
- 确定每日/每周用量：按品种、箱数、斤数列清楚，比如苹果、香蕉、橙子、西瓜、圣女果等。
- 明确供货频次：每天送还是隔天送；早餐高峰前几点到货。
- 明确验收标准：成熟度、大小、外观、甜度、破损率、农残检测要求。
- 明确可替换品种：某品种缺货时，允许供应商用哪些等价水果替代，避免临时断供。

**2. 重点谈“稳定性”，不是只谈单价**
- 问清楚货源结构：自有基地、一级批发、产地直采还是多市场调货。多市场调货的供应商抗缺货能力通常更强。
- 问旺季/淡季、节假日、恶劣天气下的保供方案。
- 要求备选供应商或备货机制，比如酒店附近有应急补货点。
- 约定缺货、迟到、品质不达标的处理方式：补货时限、扣款、替代方案、终止合作条件。

**3. 把品质标准写进合同或订单**
- 按品种写验收标准，不要只写“新鲜”“优质”。
- 约定允许的损耗率和退换货规则：比如到货破损超过多少比例，供应商免费补换。
- 要求随货提供农残检测报告或合格证明，至少能追溯批次。
- 水果规格要稳定，早餐切片水果和整果对大小、成熟度要求不同，提前分开约定。

**4. 价格和结算要留出弹性**
- 不要只锁死一个单价。水果价格波动大，可谈“基准价+随行就市调整机制”，并约定调价周期和参考市场。
- 明确是否含税、含运费、含卸货到指定冷库或厨房。
- 结算周期、对账方式、发票类型提前谈清，避免财务扯皮。
- 可以要求账期，但不要过度压账期，否则供应商可能用低品质货源找补。

**5. 配送和验收流程要可执行**
- 约定到货时间窗口，迟到超过多久算违约。
- 谁来验收、用什么单据、当场拍照留证、异常怎么签字确认。
- 生鲜验收最好双人在场，避免口头扯皮。
- 要求供应商固定对接人和应急电话，不能只靠一个业务员。

**6. 先小批量试供，再签长期**
- 建议先试供2—4周，覆盖工作日、周末和一次节假日。
- 试供期重点看：到货准时率、破损率、缺货次数、临时补货速度、发票和对账配合度。
- 试供合格再谈长期协议，不要一上来签死长约。

**7. 合同里必须有的风险条款**
- 食品安全责任：因水果农残或变质导致客人投诉、监管处罚，责任和赔偿怎么承担。
- 缺货违约责任和替代供货义务。
- 价格调整机制和争议解决方式。
- 终止合作和过渡期安排，避免换供应商时断供。

**谈判时最该坚持的三条：**
1. 每天能按时到货，缺货有替代和补货方案；
2. 品质标准可验收、可退换，食品安全可追溯；
3. 价格随行就市但有调整规则，不靠压价换低质。

如果酒店早餐用量不大，可以优先找本地一级批发商或做酒店渠道的配送商，比直接找产地更现实；用量大且品种集中，再考虑产地直采或基地合作。
