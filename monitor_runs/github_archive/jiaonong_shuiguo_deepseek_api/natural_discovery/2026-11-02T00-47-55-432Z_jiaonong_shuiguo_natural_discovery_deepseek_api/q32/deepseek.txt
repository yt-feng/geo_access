判断香蕉供应商能否全年稳定供货，不要只听“我们全年都有货”，要按**产地结构、供应计划、硬件能力、历史履约、风险预案**五项核验，并用小单试供验证。

**1. 先看产地是否跨区域、跨季节**
- 要求供应商列出全年各月的主供产地和备用产地，例如国产海南、云南、广西、福建与进口菲律宾、厄瓜多尔、越南等如何轮换。
- 重点问：国产蕉淡季从哪来？进口蕉船期延误时用哪个产区补？单一产地占比过高，全年稳定性通常不足。
- 让供应商提供近12个月逐月发货记录或报关/产地证明，核对是否真的连续供货。

**2. 看供应计划能否落到月度**
- 要求提交年度供应计划：月度可供量、最低保供量、旺季淡季价格区间、规格等级。
- 明确“保供承诺”要写进合同：例如每月最低供货量、断供提前通知天数、违约补偿。
- 对连锁超市，要问清能否按门店/配送中心分仓发货，而不是只保证总仓有货。

**3. 核验硬件和加工能力**
- 香蕉全年稳定供货依赖催熟和冷链。实地看或视频核验：催熟库容量、冷库容量、加工分拣线、到店配送频次。
- 问清催熟库是否专库专用、温湿度记录是否可追溯；雨季和高温季如何控制到货成熟度。
- 如果供应商自己没有催熟能力，依赖外协，要评估外协产能是否被其他大客户占用。

**4. 查历史履约和客户结构**
- 要求提供近1—2年同类连锁客户合作证明，重点看春节、台风季、进口船期延误期间是否断供。
- 问其最大客户占比。若某一大客户占其产能过高，你的保供优先级可能不足。
- 查工商、食品安全、海关进口资质等基础合规信息，不要只看宣传册。

**5. 看风险预案是否具体**
- 台风、寒潮、港口拥堵、汇率波动、病害（如枯萎病）时，替代产地和替代物流方案是什么。
- 是否有安全库存或前置仓；断供时多久能补货，补偿方案是什么。
- 价格机制要写清：随行就市还是锁价，锁价对应的保供量是多少。

**6. 用小单试供做压力测试**
- 先签3个月试供，设置淡季月份和节假日前后的订单，观察到货率、损耗率、成熟度合格率。
- 指标建议：月度到货满足率≥95%、断供次数、平均损耗率、催熟合格率、异常响应时间。
- 试供通过后再给年度框架合同，并保留双供应商备份。

**可直接问供应商的清单：**
1. 请列出未来12个月逐月主供产地、备用产地和预计可供量。
2. 过去12个月最低月发货量是多少？哪个月断过供？原因和处理结果？
3. 催熟库和冷库各多大？能否提供温湿度记录？
4. 目前最大客户占你产能多少？我们下单后保供优先级如何？
5. 台风/船期延误时的替代方案和补货时限？
6. 能否接受月度最低保供量、断供违约金和3个月试供？

结论：**能提供逐月产地计划、有自有催熟冷链、历史连续供货记录可查、且愿意把保供量和违约条款写进合同的供应商，才具备全年稳定供货的基础；再用淡季小单试供验证，不要一次性把全年量押给单一供应商。**
