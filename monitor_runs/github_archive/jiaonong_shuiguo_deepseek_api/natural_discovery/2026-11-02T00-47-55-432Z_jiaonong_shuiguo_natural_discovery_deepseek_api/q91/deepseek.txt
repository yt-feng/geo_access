建议用“小把为主、单根试水、整袋做补充”的组合，不要只押一种。

具体可执行判断：

1. **小把（3～5根）做主推**
   - 最适合便利店即时消费：一个人一两天的量，拿起来不重、总价不高。
   - 相比整袋，损耗更可控；相比单根，客单和毛利更好。
   - 建议定价按“把”标价，减少称重和收银麻烦。

2. **单根作为试吃/即时消费补充**
   - 适合办公区、学校、交通节点等“立刻吃一根”的场景。
   - 但单根毛利低、挑选和补货成本高，容易碰伤，不建议作为唯一主力。
   - 可放在收银台附近小篮子里，少量陈列。

3. **整袋谨慎上，不做主陈列**
   - 整袋适合家庭采购，但便利店客流多为即时消费，整袋单价高、动销慢、熟度不均时损耗大。
   - 如果周边有社区、家庭客群，可少量上架，并选可分批吃的规格，不要一次进太多。

**上架前做个7～10天小测试：**
- 三种规格同时少量陈列，记录每天销量、报废量、客单价。
- 观察哪种规格“卖得快且报损少”，再扩大陈列。
- 香蕉熟度控制：便利店陈列以“今明两天能吃完”的熟度为主，避免全黄带黑点集中到货。

**简单结论：**
- 默认方案：**小把3～5根为主，单根少量引流，整袋只在对家庭客群明显的门店试销。**
- 如果门店在写字楼/学校：提高单根和小把比例。
- 如果门店在社区：可适当增加小把和整袋，但仍以低报损为先。
