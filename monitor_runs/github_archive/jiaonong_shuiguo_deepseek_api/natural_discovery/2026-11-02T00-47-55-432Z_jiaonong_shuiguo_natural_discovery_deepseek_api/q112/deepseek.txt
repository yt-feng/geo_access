坏果率赔付没有统一法定比例，关键看合同约定和验收标准。给你可执行建议：

1. **合同里最好明确写“坏果率”定义**
   - 例如：腐烂、霉变、虫蛀、明显压伤、异味、渗汁等计入坏果；轻微表皮瑕疵是否计入要写明。
   - 按重量还是按件数计算也要写明，避免争议。

2. **常见可谈的赔付触发线**
   - **坏果率≤3%**：一般作为正常损耗，不赔付。
   - **坏果率3%—5%**：可要求按坏果重量扣款或补货。
   - **坏果率超过5%**：可要求整批按比例扣款、换货，甚至拒收。
   - **坏果率超过10%**：通常可视为严重质量问题，要求退货/拒收并索赔。
   
   这不是法定标准，而是采购合同里较常见的谈判区间。易腐水果、长途运输、不同品种可以适当调整。

3. **建议合同写成阶梯条款**
   - 坏果率≤3%：不赔付；
   - 3%＜坏果率≤5%：按坏果重量×单价扣款；
   - 5%＜坏果率≤10%：按坏果重量双倍扣款或补货；
   - 坏果率＞10%：买方有权拒收/退货，卖方承担运费及损耗。
   
   同时约定：**抽样比例、验收时限、拍照留证、第三方检测或复检规则**。

4. **不要只写“超过多少赔付”**
   还要写清：
   - 谁来验收、何时验收；
   - 抽样方法，比如每批随机抽几箱、每箱抽几公斤；
   - 赔付是扣款、补货还是退货；
   - 运费、冷藏费、销毁费谁承担；
   - 争议时以哪方检测为准。

**结论：** 合同里建议把**3%作为正常损耗上限、5%作为扣款/补货触发线、10%作为拒收或重大索赔线**来谈；最终以双方合同约定为准，不要依赖行业默认比例。
