香蕉和菠萝做社区团购，售后控制的重点不是“出了问题怎么赔”，而是把损耗挡在交付之前。核心思路：**按成熟度分级卖、缩短链路、把售后规则前置写清楚、用少量可控赔付换口碑**。

**1. 选品和到货标准先卡死**
- 香蕉不要进“已黄熟”的货，团购交付周期通常1–2天，进**青转黄、七成半熟**的货，到自提点刚好可吃或放1天可吃。整串带轴，减少断果。
- 菠萝选**成熟度7–8成、无软腐、无黑心**的果，夏季尽量选耐运输品种；到货抽检切开2–3个看黑心、水心病。
- 和供应商约定**到货损耗率上限**（如香蕉≤5%、菠萝≤8%），超出部分供应商补货或扣款，别把上游损耗全背到自己身上。

**2. 交付节奏缩短**
- 香蕉、菠萝**当天到、当天或次日提**，不做长预售。预售越久，香蕉过熟、菠萝发酵的风险越高。
- 自提点存放：香蕉**常温阴凉、不冷藏、不压堆**；菠萝**通风、避免堆叠挤压**。夏季高温时控制单团量，别一次压太多货。
- 分拣时把**已过熟、碰伤、软果**挑出来，不进入正常提货，避免“顾客拿到坏果再售后”。

**3. 售后规则前置，别等纠纷**
开团页面和群里明确写：
- 香蕉：**表皮黑斑、轻微碰伤不影响食用不售后**；断果、严重压烂、果肉变质可售后。
- 菠萝：**外表青黄不均不售后**；切开黑心、软腐、异味可售后，需**切开拍照**。
- 售后时效：**提货后24小时内**，生鲜类过期不补；赔付方式优先**下一团抵扣/补发**，少量直接退款。
- 明确“**不切开不判菠萝售后**”，避免凭外观扯皮。

**4. 用“分级+组合”降低赔付压力**
- 香蕉可做**整串装和单根装**，熟度高的单根低价快清，不压库存。
- 菠萝可做**整果和切盒**，切盒当天卖完，卖不完的不隔夜。
- 对高频售后客户，用**补发/抵扣**替代现金退款，控制赔付成本，但质量问题该退就退，别拖。

**5. 留证据、做复盘**
- 每团留**到货抽检照片、分拣挑出坏果照片、提货签收记录**。
- 每周统计：**售后率、主要售后原因（过熟/压伤/黑心/断果）、供应商批次**。同一供应商连续两批售后率超标就换货或降量。
- 目标参考：香蕉售后率控制在**3%以内**，菠萝**5%以内**；超过就说明选品成熟度或交付节奏有问题，先改链路再谈赔付。

一句话：**高损耗品不靠售后兜底，靠“青熟到货、当天交付、切开才判、规则写死、供应商共担”把售后压到最低。**
