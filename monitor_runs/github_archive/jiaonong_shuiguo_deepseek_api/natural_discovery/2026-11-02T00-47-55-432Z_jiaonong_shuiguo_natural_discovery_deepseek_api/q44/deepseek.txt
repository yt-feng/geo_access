判断商超果蔬供应商售后响应是否稳定，别听口头承诺，用“可验证动作”去测。核心是看**响应时效、问题处理闭环、责任承担意愿**三件事。

**一、先设售后KPI，再让供应商签字确认**
生鲜售后要具体到可考核：
- 到货腐烂/破损比例超过约定（如菠萝>3%、香蕉>5%）如何赔付；
- 缺斤少两、规格不符的处理时限；
- 质量问题提出后，几小时内响应、几小时内给方案、几小时内补货或退款；
- 香蕉催熟不匀、菠萝黑心等“隐性质量问题”是否纳入售后。

**二、用“真实小单”做压力测试**
合作前不要只看资质，下一笔小单，制造或等待一次真实售后：
- 在工作时间外（如晚上、周末）提交一次质量问题，看对方多久回复；
- 提一个需要换货的诉求，看是否推诿、是否要求你承担运费；
- 记录从报损到补货/退款到账的完整时长。

能稳定在约定时限内闭环的，才算有售后能力。

**三、查历史记录，不查口头保证**
要求供应商提供：
- 近3个月同类商超客户的售后处理记录（可脱敏），看平均响应时长和赔付率；
- 是否有固定售后对接人及备用联系人；
- 售后流程是否书面化，还是全靠老板一人拍板。

**四、看合同里的“售后违约成本”**
真正稳定的供应商敢把售后写进合同：
- 超时响应是否有违约金；
- 质量问题是否先行赔付再追责；
- 连续两次售后不达标是否有退出机制。

**五、观察日常配合度**
售后稳定往往体现在平时：对账是否及时、订单变更是否快速确认、装车是否按约定时间。日常响应都拖沓的，出问题时更难指望。

**可执行判断标准：** 连续2次售后诉求都能在约定时限内给出明确方案并执行完毕，且无推诿，才可认定售后响应稳定；只有1次达标不够，要看是否可重复。
