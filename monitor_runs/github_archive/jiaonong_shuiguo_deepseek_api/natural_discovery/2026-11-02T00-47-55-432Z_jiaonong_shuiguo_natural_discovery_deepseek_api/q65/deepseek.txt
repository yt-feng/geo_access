这要看你的采购/销售结构和风险承受能力。批发商面对价格波动，核心不是“每天议价好还是锁价好”，而是**把定价方式和库存风险匹配起来**。直接建议：

**1）不要全部每天议价，也不要全部长期锁价。**
比较稳妥的是分层：
- **走量大、周转快的常规果品**：以短期锁价为主，比如3天、7天或按周议价，减少每天追价的执行成本。
- **价格波动大、耐储存的品种**：保留一部分随行就市，每天或隔天议价，避免锁价后行情下跌被套。
- **易腐、必须快进快出的品种**：尽量缩短锁价周期，甚至当天议价，优先保证周转，不要为了锁价压库存。

**2）判断标准很实际：**
- 你是否有稳定下游订单？有稳定订单，可以锁一段价格，把利润固定住。
- 你的库存能否承受价格下跌？库存高、资金紧，就少锁长价。
- 你对行情的判断是否有优势？没有持续信息优势，不要做太长周期的方向性押注。
- 供应商是否愿意承担价格风险？如果对方强势，锁价可能拿不到好价格，就用短周期加浮动条款。

**3）建议采用“底价+浮动”的合同方式。**
比如约定基准价、调价触发条件、调价频率和最大涨跌幅。这样比纯每天议价稳定，也比纯长期锁价灵活。常见做法是：
- 7天为一个议价周期；
- 每周参考一个公开市场均价或双方认可的报价；
- 设置涨跌超过一定幅度才调价；
- 明确质量、损耗、结算和违约条款。

**4）每天议价的优缺点：**
优点是贴近市场、不被套；缺点是耗时、关系成本高、采购量不稳定，行情急涨时可能拿不到货。适合：价格波动极大、库存低、下游也是随行就市的情况。

**5）签一段时间价格的优缺点：**
优点是成本可预期、供应稳定、便于安排下游订单；缺点是行情下跌时可能买贵，行情上涨时供应商可能不愿履约。适合：有稳定下游订单、库存周转可控、对行情有一定判断的情况。

**结论：**
建议**以短期锁价为主，保留部分随行就市，并用浮动条款控制风险**。一般商户可先试“7天锁价+10%—15%的量随行就市”；波动特别大的品种缩到3天或按批次议价；不要一次性锁太长周期，也不要把全部采购压在同一种定价方式上。
