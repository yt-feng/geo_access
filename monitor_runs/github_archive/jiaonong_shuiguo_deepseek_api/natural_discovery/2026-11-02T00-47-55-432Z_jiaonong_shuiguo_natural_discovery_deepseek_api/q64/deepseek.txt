批发档口退货纠纷，大多不是因为货差，而是因为**收货时没把“责任”当场固定下来**。核心做法是：**先验后签、当场记录、标准前置、异常留证**。下面按可执行步骤说。

## 一、收货前先定规则

1. **把验收标准写进采购单/合同**
   - 明确允许的破损率、短装率、色差/尺寸公差范围。
   - 明确“签收后多少小时内提异议有效”，超时视为验收合格。
   - 明确退换条件：只退质量问题，还是也接受滞销退换；运费谁承担。

2. **给供应商发固定验收口径**
   - 到货当日开箱抽检/全检，异常当天书面反馈。
   - 反馈必须带：批次号、货号、数量、问题照片/视频、开箱视频。
   - 不接受“口头说有问题”，一切以留证为准。

## 二、到货当场怎么做

1. **先别签“完好”**
   - 外包装有明显破损、水湿、挤压，先在签收单上注明“外包装破损，待开箱验货”，再签。
   - 能当面开箱的，当面开；不能当面的，拍完整开箱视频后再签或签“待验”。

2. **拍开箱视频**
   - 从快递面单、封箱完整状态开始拍，连续拍到开箱、清点。
   - 视频里口播：日期、批次、箱号、总件数。
   - 这是后续纠纷最硬的证据。

3. **按批次抽检或全检**
   - 高价值、易碎、易混款：全检。
   - 常规款：按比例抽检，比如每批抽 10%–20%，发现异常扩大抽检。
   - 重点查：数量、货号/颜色/尺码是否混装、破损污渍、做工明显缺陷、吊牌/包装是否齐全。

4. **当场点数、对单**
   - 实际数量 vs 送货单 vs 采购单，三单对齐。
   - 短装、多装、错款当场记在送货单上，双方签字或拍照发对接人确认。

## 三、异常怎么留证

每笔异常固定“五件套”：

1. 送货单/快递面单照片；
2. 开箱视频；
3. 问题部位特写照片（带尺子或参照物）；
4. 清点数量照片（整箱摊开拍）；
5. 书面异常单：批次、货号、数量、问题描述、诉求（补发/换货/扣款/退货）。

**当天发给供应商并让其回复确认**，微信/邮件都行，保留记录。不要拖到几天后再提。

## 四、内部流程防扯皮

- 设**专人收货**，验货人和采购人分开，避免自己采自己验。
- 建**收货验收台账**：日期、供应商、批次、到货数、合格数、异常数、处理结果。
- 异常货**单独隔离区**存放，贴标签，不混入正常库存。
- 签收单上统一印一行：**“未当场提出的数量/外观异议，事后不予受理；质量问题按约定时限书面反馈。”**

## 五、对下游客户也前置规则

批发档口的退货纠纷不只来自上游，也来自下游客户。收货验货做好后，发货时同步：

- 出货前拍照/视频留底，记录款号、数量、包装状态。
- 随货单注明验收时限和退换条件。
- 客户反馈问题时，要求提供开箱视频和问题照片，避免“卖出去几天后说不清”。

## 一句话执行版

**外包装异常先备注再签；全程开箱录像；当场点数对单；异常当天出书面单并让供应商确认；验收标准写进采购单。** 做到这五条，退货纠纷会明显下降。
