排序应该是：**配送 > 售后 > 价格**。但更准确地说，最该先问的是**配送稳定性**，因为它决定你这门生意能不能持续；售后决定口碑和复购；价格决定利润空间，但不该排第一。

具体判断标准可以这样看：

1. **配送最优先问**
   - 能不能按你团购的到货时间、频次稳定送到？
   - 水果破损、挤压、延迟、少件怎么处理，责任怎么划分？
   - 团长是自提点，配送迟到会直接导致团员等你、差评、退款。
   - 水果是生鲜，配送不稳，售后和价格都救不回来。

2. **售后第二问**
   - 坏果、烂果、缺斤少两的赔付标准是什么？
   - 是拍照即赔、按比例赔，还是必须整箱退回？
   - 售后响应时间和责任归属要问清楚。
   - 团长的核心资产是信任，售后扯皮会直接伤复购。

3. **价格第三问，但不是不重要**
   - 价格要结合损耗率、配送费、售后赔付一起算真实成本。
   - 只问价格容易选到低价但配送差、售后差的供应商，最后亏在退款和流失上。
   - 应该问：这个价格对应的规格、净重、损耗谁承担、是否含配送。

**可执行建议：**
先让供应商承诺配送时效和异常处理规则，再确认售后赔付标准，最后比较“到团综合成本”，不要只比报价。最该问的一句话是：**“如果配送迟到或坏果超过约定比例，你们怎么赔、多久赔、谁承担运费？”**
