会，而且香蕉和菠萝的风险点还不一样。起订量过高通常会增加损耗风险，核心原因是**订货量超过短期实际销量，而这两种水果货架期短、后熟过程难控**。

可判断的影响：

1. **香蕉**
   - 香蕉是后熟型水果，到货后还会继续成熟。起订量高会拉长库存周转天数，容易从“可售成熟度”快速进入过熟、起斑、软烂阶段。
   - 若门店/仓配的催熟、温湿度控制不一致，高起订量会放大批次间成熟度差异，增加报损。
   - 香蕉对挤压、温差敏感，库存堆叠和多次搬运也会增加机械损伤。

2. **菠萝**
   - 菠萝相对耐储一些，但高起订量仍会带来问题：夏季高温下易内部褐变、果眼腐烂；冬季或冷库温度过低又可能冷害。
   - 整果周转慢时，外观失水、冠芽萎蔫、底部发霉会降低商品性。
   - 若做鲜切，起订量高意味着削皮后未及时售完的果肉损耗风险更高。

**判断建议：**
- 用“起订量 ÷ 日均销量”估算覆盖天数。香蕉建议尽量控制在**2—4天销量**内，菠萝可略长，但也不宜超过**5—7天**，具体看温控和周转。
- 若起订量导致覆盖天数明显超过上述范围，损耗风险会上升，应谈分批到货、降低MOQ、拼单采购或调整促销。
- 重点看：到货成熟度、库温、堆码方式、日均销量波动、是否鲜切。任一环节弱，都应压低起订量。

结论：**会。起订量太高会显著增加香蕉和菠萝的损耗风险，香蕉更敏感；建议按周转天数而不是单纯按单价或起订折扣决策。**
