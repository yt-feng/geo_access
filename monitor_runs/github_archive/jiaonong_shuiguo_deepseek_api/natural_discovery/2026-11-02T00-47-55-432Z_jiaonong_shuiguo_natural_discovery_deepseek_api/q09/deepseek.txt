跟供应商谈旺季合作，核心是别只问“能不能供货”，而要把供货稳定性、价格、品质、账期和违约处理都提前锁死。建议重点问这几类问题：

1. **旺季供应能力**
   - 旺季每天/每周最多能稳定供多少？平时和高峰期分别多少？
   - 你主要从哪些产地/渠道拿货？遇到天气、产地减产时怎么保供？
   - 有没有备选产地或合作基地？
   - 节假日前是否需要提前报单？提前几天？

2. **缺货和延期怎么处理**
   - 如果某单品缺货，提前多久通知我？有没有替代品推荐？
   - 断货或延迟送货怎么补偿？能否写进合同？
   - 旺季是否优先保老客户？我这个量级能排到什么优先级？

3. **价格与波动机制**
   - 报价是固定价还是随行就市？调价提前几天通知？
   - 旺季会不会临时涨价？有没有锁价期或保价量？
   - 大单、长期合作有没有阶梯价？运费、装卸费谁承担？

4. **品质标准与验收**
   - 规格、等级、成熟度、糖度、大小怎么定？能否按样品标准供货？
   - 坏果、烂果、次果比例控制在多少？超出怎么赔？
   - 到货后多久内可提出质量异议？退换货流程是什么？

5. **配送与时效**
   - 送货时间能否固定？旺季是否加车？最小起送量多少？
   - 迟到多久算违约？冷链或保鲜措施怎么做？
   - 临时补货能否当天响应？

6. **结算与账期**
   - 是现结、周结还是月结？旺季能否给账期或铺底货？
   - 押金、预付款是否必须？退合作时怎么结算？
   - 发票、对账周期怎么处理？

7. **合作保障**
   - 能否签旺季保供协议？关键条款能否写进合同：保供量、价格上限、品质标准、违约赔偿、通知时限？
   - 有没有合作保证金或互保机制？
   - 出现纠纷怎么处理，管辖和违约条款是否明确？

谈的时候建议你带上近几个月销量、旺季预估量和主推单品，让对方按“单品+周供货量+价格区间+配送时效”给书面方案。口头承诺尽量落到合同或微信书面确认里，尤其是保供量、缺货通知时限、品质赔付和临时调价规则。
