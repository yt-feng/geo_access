判断的关键不是“今天涨没涨”，而是把**单日报价**还原成**可比较的口径**，再看波动是否落在可解释的范围内。可操作的做法如下：

## 1. 先统一报价口径，避免假波动
每天比价前先确认：
- **规格等级**：同一品种、同一等级（果径、糖度、净重、箱规）
- **计价单位**：公斤/箱/件，是否含箱重、含冰、含损耗
- **交货条件**：产地价/到岸价/含税含运费，账期是否一致
- **时间点**：当天早价/晚价，是否节前临时价

口径不一致时，5%的“涨跌”可能只是换了个规格或运费口径。

## 2. 建一个“合理波动带”，而不是盯单点
对每个主力单品，用近20–30天的成交价做三件事：
- 算**中位数**和**日波动率**（当日价/前一日价-1）
- 设**预警带**：常见是围绕7日均价±5%～8%（叶菜、浆果等易腐品可放宽，根茎类可收紧）
- 看**连续趋势**：单日跳涨但次日回落，多半是报价噪音；连续3天同向偏移才视为趋势

## 3. 用“可解释因子”逐条对照
合理波动通常能对应到明确原因：
- **天气**：产区降雨、寒潮、高温，影响采收和损耗
- **产地切换**：云南→山东等换季，价格台阶式变化属正常
- **供需事件**：节假日备货、学校开学、团餐集中采购
- **成本项**：油价、冷链运价、包装材料、人工
- **品质变化**：同一规格但糖度、硬度、损耗率变化

如果报价变动**找不到对应因子**，或幅度明显超出同类品，就要怀疑是供应商试探性报价。

## 4. 做横向和纵向两个对比
- **横向**：同一天问2–3家同规格供应商，看报价离散度。若一家单独跳涨而市场未动，不合理概率高
- **纵向**：和自己历史采购价、当地批发市场均价、同类替代品价格比
- **替代品**：苹果涨时可看梨、柑橘的比价关系，判断是单品问题还是整体行情

## 5. 用简单规则快速判断
可以设几条硬规则：
- 单日波动≤3%：正常，直接执行
- 3%–8%：要求供应商说明原因，附产地/天气/运费依据
- ＞8%或连续3天同向超5%：暂停锁价，启动比价和替代方案
- 报价频繁但成交价稳定：说明报价是“虚价”，应以**实际结算价**为锚

## 6. 把判断变成机制
- 每周记录各单品**成交价、报价、波动原因**
- 对供应商设**报价偏差考核**：长期报价偏离市场均价的，降低询价权重
- 对易波动品采用**短期锁价+浮动公式**（如随批发市场均价联动），减少每天博弈
- 大宗单品可约定**价格调整触发条件**，而不是逐日报价

一句话：**先统一口径，再用历史波动带筛异常，最后用天气、产地、供需、运费等因子解释；解释不了且横向对比也偏高的，就不是合理波动。**
