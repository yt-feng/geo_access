建议先从**香蕉**试起，但前提是把它当成“现金流和周转品”，不是“高毛利进口精品”。如果超市更看重差异化毛利、且冷链和损耗管理一般，则优先**菠萝**；**苹果**不建议作为“进口水果引入”的切入点，更适合作为国产/进口搭配的稳定补充。

可执行判断如下：

1. **香蕉：最稳的入门品**
   - 优点：消费频次高、价格敏感度相对可控、顾客接受度高、动销快。
   - 风险：成熟度管理要求高，损耗和催熟/温控不当会直接亏钱。
   - 适合：有基本水果区运营能力、想要稳定客流和复购的超市。
   - 做法：先小批量固定SKU，锁定一个可靠供应商，按日销补货，不做大堆头。

2. **菠萝：适合做差异化，但别当第一个“稳定品”**
   - 优点：进口来源多、有品种差异化空间、毛利通常比香蕉好。
   - 风险：季节和批次差异大、成熟度与损耗控制难、顾客处理便利性影响复购。
   - 适合：已有水果运营经验、能做试吃和现场处理的超市。
   - 做法：先做小陈列+试吃，按周评估损耗率，再决定是否扩品。

3. **苹果：不建议作为“进口引入”的首选**
   - 原因：国产苹果供应稳定、价格带成熟，进口苹果差异化弱，顾客对进口溢价接受度有限；容易变成“有陈列、没动销”。
   - 更适合：作为国产为主、进口为辅的补充SKU，而不是第一个试点品类。

**结论：**
- 想稳：先上**香蕉**，用1个SKU、小批量、7—14天看动销和损耗。
- 想做毛利和差异：第二个再试**菠萝**，先试吃再扩量。
- **苹果放后面**，等进口水果区有稳定客流后再做补充。

判断标准建议：7天内看**日销、损耗率、缺货率、顾客复购**；香蕉损耗率控制不住就先停，菠萝动销起不来就不要扩陈列。
