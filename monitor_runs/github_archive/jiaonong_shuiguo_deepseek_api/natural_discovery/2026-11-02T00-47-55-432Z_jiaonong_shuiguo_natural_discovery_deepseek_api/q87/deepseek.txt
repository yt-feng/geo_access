社区团购旺季锁水果库存，核心是“早于需求峰值锁量、锁价、锁赔付”，而不是只口头预留。可执行做法：

1. **提前做需求预测和分级锁量**
   - 按近2—4周销量、去年同期、活动排期，做单品日销预测。
   - 把水果分A/B/C级：A级爆品提前7—15天锁60%—80%需求量；B级锁40%—60%；C级按周滚动补。
   - 给供应商“保底量+弹性量”：例如保底80%，旺季前3天可追加20%，既让对方敢备货，也避免压货。

2. **签书面锁库协议，不靠口头**
   协议至少写清：品名规格、锁定数量、锁价/浮动价规则、到货时间、分批次交付、质量标准、损耗率、缺货赔付、涨价处理、退换货。可付10%—30%定金锁货，尾款按到货验收结算。

3. **用“分级定金+违约金”约束供应商**
   - 小额定金锁货源，大额订单分批付。
   - 约定缺货按差额或订单金额比例赔付；临时涨价需提前书面通知并设上限。
   - 对核心爆品可签“优先供货权”，旺季期间优先满足你的订单。

4. **多供应商备份，避免单点断供**
   每个爆品至少2家供应商，主供70%、备供30%。提前让备供小批量试单，验证品质和履约。

5. **锁定物流与到货节奏**
   明确产地直发/仓配到货时间，旺季按日或隔日分批到仓，避免一次性压库导致损耗。约定到货窗口和迟到赔付。

6. **用预售和团长端反推锁量**
   开团前先做预售/意向单，用真实订单+安全库存系数向供应商锁量，减少盲目备货。安全库存可按3—5天销量设置。

7. **建立每日履约看板**
   跟踪锁量、已发、未发、到货合格率、缺货率；一旦供应商发货低于承诺80%，立即启动备供并书面追责。

关键判断标准：供应商是否接受“书面数量+定金+赔付+分批交付”四件事。只愿意口头承诺、不愿写缺货责任的，不适合作为旺季主供。
