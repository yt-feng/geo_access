企业食堂采购水果，三个因素都重要，但优先级取决于食堂的**风险成本**和**日常运营场景**。直接给结论：**食品安全是底线，配送准时是保障，价格是优化项。** 建议按这个顺序设置采购权重：食品安全一票否决，准时为硬约束，价格在满足前两者基础上比价。

具体判断如下：

1. **食品安全：优先级最高，必须一票否决**
   - 水果多为生食，食堂就餐人数多、集中供餐，一旦出现农残超标或变质，后果是群体性事件，损失远超采购差价。
   - 可执行动作：要求供应商提供每批次的农残检测报告或承诺书；建立收货 quick 检查（外观、气味、成熟度、有无霉变）；对高风险品类（如草莓、葡萄、切果）提高验收频次；保留样品和批次记录，便于追溯。

2. **配送准时：硬约束，直接影响食堂运营**
   - 水果通常是餐食搭配或加餐，配送迟到会导致菜单临时调整、窗口断供，影响员工体验和食堂信誉。
   - 可执行动作：在合同中明确配送时间窗口和迟到违约责任；对供应商设置准时率考核（如月度准时率低于95%触发约谈或替换）；保留1家备用供应商应对突发断供。

3. **价格：重要但排在后面，适合在合规供应商之间比价**
   - 水果价格波动大，单纯追求低价容易换来品质下降或供货不稳定。建议用“同品质比价”，而不是“最低价中标”。
   - 可执行动作：设定参考价或月度调价机制；对大宗常用水果（苹果、香蕉、橙子）做周期性比价；把价格权重放在食品安全和准时率达标之后。

**一句话总结：先卡食品安全，再保配送准时，最后在合格供应商里谈价格。** 如果食堂规模小、供应商稳定，可适当简化检测流程，但食品安全底线不能省；如果食堂供餐人数多或曾出过食安问题，食品安全权重应进一步加大。
