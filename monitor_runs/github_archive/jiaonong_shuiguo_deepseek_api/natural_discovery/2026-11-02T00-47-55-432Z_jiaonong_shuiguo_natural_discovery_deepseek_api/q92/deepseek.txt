便利店面积小，水果经营的核心不是“品类齐全”，而是**少SKU、快周转、强控损耗**。建议按下面几个层面控制：

### 1. 品类控制：只做“高频+耐放+即食”
- **总SKU控制在8～15个**，按货架/冷柜实际容量定，超过就砍。
- 优先选：苹果、香蕉、橙子、柑橘、梨、葡萄/提子、小番茄、黄瓜（果蔬兼用）等。
- 少量做：当季爆品1～2个，如夏季西瓜切盒、冬季砂糖橘。
- **不做**：低频高价果、易碰伤果、需要现场加工的大件果、消费者教育成本高的稀有果。
- 结构建议：**60%常青款 + 30%当季款 + 10%试销款**，试销款两周不动销就下架。

### 2. 采购量：小批量、多频次
- 按“日均销量×1.5～2天”订货，不要一次压3天以上库存。
- 新店或新品首单只进**最小包装/半箱**，卖动再补。
- 与供应商谈**少量多配**，哪怕单价略高，也比损耗低。
- 建立简单日报：昨日销量、当前库存、今日订货量，按数据补货，不凭感觉。

### 3. 损耗控制：从收货到出清全流程
- **收货验**：当场挑出碰伤、软烂、霉点果，能拒收就拒收，不能拒收单独标记。
- **陈列控量**：前台只摆半天到一天的量，后备库存放阴凉/冷柜，卖一点补一点，减少翻拣和挤压。
- **分级销售**：外观稍差的做切盒或特价区，不要和正价果混放。
- **切果管理**：切盒只做1～2个爆款，现切现卖，冷藏不超过当天；切果损耗要单独记账。
- **日清机制**：闭店前1～2小时对临期果做组合折扣或员工内购，设定固定折扣规则，避免临期才手忙脚乱。
- **先进先出**：补货时旧货在前、新货在后，每天早晚各翻检一次。

### 4. 用数据定生死
- 每个SKU记录：进货量、销量、报损量、毛利率。
- 连续7天日均销量低于某个阈值（如少于3份/盒）就淘汰。
- 损耗率目标：小便利店水果综合损耗建议控制在**5%～8%**以内，超过就查订货量和陈列量。
- 每周复盘一次：哪个品卖得快、哪个品总报损，下周直接调整订货。

### 5. 面积小可用的替代做法
- 主推**小包装、即食化**：2～3个装、切盒、果切杯，降低购买门槛。
- 用**预包装替代散装**，减少顾客翻拣造成的碰伤。
- 水果与酸奶、沙拉、早餐场景做组合陈列，提高连带率，加快周转。
- 如果门店没有冷藏条件，就只做耐放品类，不做切果和浆果类。

一句话原则：**品类少而准，订货勤而少，陈列少而快，临期早出清。** 先把损耗率和高频单品跑通，再考虑扩品类。
