香蕉和菠萝分级报价，关键是把“等级标准、计价单位、报价口径、附加费用”四件事分开写清楚，避免小店老板只看单价误解。可以按下面做：

**一、先定分级标准（写进报价单）**

**香蕉**
- A级：条直饱满、无黑斑/机械伤，成熟度7成左右；单条规格可写“每把4–6条、单条120g以上”这类可验收标准。
- B级：轻微斑点、少量擦伤，成熟度略高，适合快销。
- C级/处理级：黑斑较多、断条、表皮损伤，明确“仅建议当日促销或加工”。
- 报价时统一写：**元/箱或元/公斤**，并注明净重、毛重、每箱把数/条数、成熟度。

**二、菠萝分级**
- 按果径/单果重分级：如大果（1.2kg以上）、中果（0.9–1.2kg）、小果（0.6–0.9kg），外加“无冠/带冠”说明。
- 按外观：A级无裂口、无烂心、色泽均匀；B级有轻微日灼/擦伤；C级明确瑕疵类型。
- 报价写：**元/个或元/公斤**，注明是否带冠、是否催熟、到货成熟度、箱装个数。

**三、报价单统一口径**
建议每个品每级一行，列清楚：
1. 品名/等级
2. 规格（重量、果径、条数/个数）
3. 计价单位（箱/公斤/个）
4. 单价
5. 起批量
6. 是否含税、含运费/卸货费
7. 损耗与退换规则（如到货24小时内验货，烂果按比例补）
8. 报价有效期

**四、实操建议**
- 香蕉用“箱+净重+每箱条数/把数+成熟度”报价；菠萝用“个+单果重区间+带冠与否”报价，最不容易扯皮。
- 分级不要只写A/B/C，要配可验收的量化指标，否则小店会按自己的理解压价。
- 同一等级报“到店价”和“自提价”两个口径，运费、卸货、短途配送单独列。
- 首次合作可给“混级试销价”，但必须写明混级比例和不可挑拣，避免后续争议。

这样报价单一眼能看出“什么货、什么规格、多少钱、含不含费用、坏了怎么处理”，小店老板也容易比较和下单。
