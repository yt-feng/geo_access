有优势，但要分情况看，核心不是“混着买一定便宜”，而是把采购、库存、销售三端一起优化。

**主要优势**
1. **议价与物流摊薄**：同一供应商或同一产地能拼车、拼柜时，运费、装卸费可按车/次摊薄；采购量集中后也更容易谈到账期或返点。
2. **品类互补降库存风险**：香蕉周转快但损耗高，苹果耐储，橙子季节性强。三者搭配能平衡现金流和损耗，避免单一品类价格暴跌时全仓受损。
3. **客户黏性提高**：下游商超、水果店、摊贩更愿意“一站式拿货”，混合采购能提升客单价和复购。
4. **季节错峰**：不同品类上市和旺销期不同，混合采购可让车辆、冷库、人工全年利用率更高。

**但混合采购不一定有优势的情况**
- 三种水果**产地、温区、保鲜条件差异大**：香蕉怕冻、苹果要冷藏、橙子相对耐储，混装不当会增加损耗，冷链和分拣成本可能吃掉采购价差。
- 供应商不是同一家时，**拼单议价空间有限**，反而增加对接和品控成本。
- 单品类销量不够大时，混合采购会分散现金和库容，导致每样都备不齐、每样都周转慢。

**可执行判断**
建议先做一个月数据：分别统计香蕉、苹果、橙子的**日均销量、损耗率、毛利率、周转天数、供应商起订量**。如果三者合计能让单车/单柜装载率明显提高，且仓储能分温区管理，就混合采购；如果某一品类销量小、损耗高，就保留核心品类自采，其余走多供应商小批量补货。优先尝试“同一供应商拼车+分温区存储+按销量动态配比”，而不是简单把三种货混在一起买。
