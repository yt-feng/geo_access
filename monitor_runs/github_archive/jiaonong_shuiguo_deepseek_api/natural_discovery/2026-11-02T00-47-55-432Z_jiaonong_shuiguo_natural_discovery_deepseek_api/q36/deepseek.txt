结论：**两种都要，但主陈列以整果为主，切好（鲜切/果切）作为高毛利补充和引流方式配套销售。** 对大多数商超来说，纯卖整果或纯卖鲜切都不是最优。

**一、整果为主的原因**
- **损耗低、毛利可控**：整果耐放，采购后可在门店催熟、分级销售，烂果风险主要靠库存周转管控；鲜切一旦切开，当天卖不掉基本报废。
- **单价感知低、走量快**：菠萝整果单价低、家庭采购和促销走量明显，适合做爆品和堆头。
- **便于分级定价**：按大小、成熟度分成普通果、精品果、促销果，提升整体毛利。
- **操作门槛低**：门店只需会挑果、催熟、削皮代加工，不依赖高卫生标准操作间。

**二、鲜切适合作为补充的原因**
- **提升客单和毛利**：切好的菠萝单价通常按份卖，折算斤价高于整果，毛利率可做得更高。
- **满足即时消费场景**：上班族、小家庭、学生、即食需求强，鲜切能抓住“不想削皮、即买即吃”的客群。
- **减少顾客决策障碍**：菠萝削皮麻烦、带刺，鲜切降低购买门槛。
- **可组合销售**：拼果切、酸奶搭配、下午茶场景，带动关联销售。

**三、关键判断标准**
- **客流结构**：社区店、家庭客多→整果为主；写字楼、学校、商圈店→鲜切比例可提高。
- **门店操作条件**：有冷藏展示柜、果切操作间、专人负责→可做鲜切；否则整果+代削皮更稳。
- **损耗管控能力**：鲜切必须“少量多次、当日清”，按小时补货，闭店前折价处理。
- **季节和价格**：菠萝旺季整果引流，淡季或高价期用鲜切提升客单。

**四、可执行建议**
1. 主堆头放整果，做分级：促销果、普通果、精品果。
2. 提供**免费或低价代削皮**服务，兼顾嫌麻烦的顾客，减少鲜切损耗。
3. 鲜切按小份试销，先每天限量，观察下午和晚间动销，再决定扩量。
4. 鲜切严格执行当日制作、冷藏陈列、闭店折价，避免隔夜。
5. 用整果做价格形象，用鲜切做毛利和场景补充，二者不互相替代。

一句话：**整果保流量和周转，鲜切提毛利和体验；先以整果为基本盘，鲜切小步试销、按数据扩量。**
