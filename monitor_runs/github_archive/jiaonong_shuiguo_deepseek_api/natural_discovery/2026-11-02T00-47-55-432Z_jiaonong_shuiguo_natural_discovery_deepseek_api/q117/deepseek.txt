先给结论：**首次试卖不要按“供应商起订量”拍脑袋，建议按“1–2 周能卖完、损耗可控、不占压过多现金”的量来定。**对多数水果门店/餐饮采购，稳妥区间通常是：

- **单店单SKU首单：3–7天预计销量**
- **新品首次总量：不超过该品类日均销量的1.5–2倍日销 × 7天**
- **金额控制：首单不超过该门店生鲜周采购额的5%–10%**
- **最小起订量谈不下来时，宁可先小规格/拼柜/代销，也不要一次压2周以上**

### 可直接执行的试卖公式
**首单量 = 日均预估销量 × 试卖天数 ×（1 + 安全系数）**

建议参数：

1. **试卖天数：3–5天**（易腐水果3天，耐储水果5–7天）
2. **日均预估销量**：参考同价位、同品类老品日销的30%–50%，不要按供应商吹的爆款预期
3. **安全系数：20%–30%**
4. **损耗红线**：试卖期损耗率超过8%–10%，暂停加单；超过15%基本说明定价/品质/客群不匹配

举例：某店苹果日均卖20斤，新品是高端苹果，预估能到老品30%即6斤/天，试卖5天：  
**6 × 5 × 1.2 = 36斤**。若起订50斤，可接受但要先谈好残次退换；若起订200斤，不建议首单直接吃。

### 分品类建议
- **草莓、蓝莓、荔枝、桃等易腐高损品**：首单3天量，最多5天，优先小盒装
- **苹果、梨、橙、柚等耐储品**：首单5–7天量，可略高
- **进口/高客单新品**：先1–2箱或最小陈列单位，做试吃再补
- **餐饮/果汁店原料**：按3天生产用量首单，确认出杯率/出汁率后再锁周单

### 采购谈判要同步做的4件事
1. **谈试销政策**：小起订、残次包退换、7天内可补货
2. **约定验收标准**：规格、糖度、成熟度、到货温度、损耗赔付
3. **先小陈列试吃**：不要一上来堆头，先端架/收银台小陈列
4. **设补货触发点**：3天售罄率>70%再补；动销慢于预期50%立即促销清货

**一句话：首单按3–5天真实动销备货，金额控制在周生鲜采购额10%以内，损耗超10%就停。**这样最稳。
