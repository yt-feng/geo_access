**账期最值得优先谈**，其次是售后，最后是配送。

原因很直接：

1. **账期直接决定你的现金流和议价空间**  
   长期合作下，账期从“现结”谈到“月结30天/45天”，相当于供应商给你一笔无息周转资金。水果损耗高、周转快，现金流比单次进价更影响经营安全。优先谈账期，同时把“逾期供货/质量问题时的账期抵扣”写清楚。

2. **售后决定损耗谁承担，是隐性成本大头**  
   水果非标、易腐，售后条款比配送频率更影响实际毛利。重点谈：到货验收标准、坏果率上限、拍照留证时限、补货/退款/抵扣方式、责任划分（运输途中 vs 到货后）。售后不清晰，账期再长也会被损耗吃掉。

3. **配送是运营效率问题，通常可标准化**  
   配送时效、频次、起送量、临时加单费用等，在长期合作中相对容易调整，且替代供应商的切换成本低于账期和售后条款。可以放到第二或第三轮谈，用“配送稳定性”换“账期让步”反而更划算。

**谈判顺序建议：**  
先谈账期框架（现结→周结→月结），再锁定售后责任和损耗承担，最后用配送频次/起送量做交换筹码。如果供应商账期坚决不让，至少争取“售后问题货款可暂扣/抵扣”，这比单纯延长账期更实用。
