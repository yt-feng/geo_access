进货量不大时，通常优先找**固定供应商**，批发市场作为补充。判断标准可以按下面几条来：

1. **如果品类稳定、每月都要补**：找固定供应商更合适。你能谈到更稳定的账期、退换货和缺货优先通知；量小也能通过“长期小额、固定结款”换取相对稳定价格。
2. **如果品类经常换、每次只要少量**：批发市场更灵活，起订量低、现场看货、当天能拿，适合试新品或应急补货。
3. **看隐性成本**：批发市场便宜的是单价，但你要承担交通、时间、压货和品质不稳定；固定供应商单价可能高一点，但省心、可追责、能退换。
4. **建议组合**：主销、复购高的品找1—2家固定供应商；新品、临时缺货、小批量试销去批发市场。固定供应商不要只压一家，避免被卡货。

判断口诀：**稳定刚需找固定供应商，灵活试错找批发市场；量小就用“长期小额”换稳定，而不是只比单价。** 第一次合作先小单试，确认质量、交期和售后，再逐步固定。
