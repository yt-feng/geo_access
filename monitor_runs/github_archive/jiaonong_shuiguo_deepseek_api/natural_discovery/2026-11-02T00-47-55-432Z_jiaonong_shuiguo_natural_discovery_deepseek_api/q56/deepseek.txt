茶饮店控制水果供应商食品安全风险，建议按“资质证明 + 检测报告 + 随货凭证 + 冷链与追溯”四类材料索证，并保留复印件或电子件备查。具体可要求供应商提供以下证明：

1. **主体资质**
   - 营业执照（经营范围含水果/农产品销售或相关项目）
   - 食品经营许可证（若供应商以预包装食品、散装食品或食品销售方式经营；仅销售食用农产品的，按当地监管要求确认是否需许可）
   - 仅销售食用农产品的供应商，至少提供营业执照和产地/供货证明

2. **产品合格与检测证明**
   - 水果的农药残留检测报告（第三方检测或供应商自检报告，报告应与供货品种、批次对应）
   - 产地证明、食用农产品合格证或承诺达标合格证（按当地推行情况索取）
   - 进口水果需提供海关入境货物检验检疫证明、报关单等
   - 对高风险品种（如草莓、葡萄、柑橘类等）可提高检测报告频次或要求批批附检测

3. **随货凭证与追溯材料**
   - 每批送货单/销售凭证，注明品名、数量、产地、批次、送货日期
   - 供应商联系人及联系方式
   - 种植基地或上游供货商信息，便于追溯
   - 如为配送商，提供与上游基地/批发市场的采购凭证

4. **冷链与储运证明**
   - 需冷藏水果的运输温度记录或冷链配送证明
   - 运输车辆/容器清洁消毒记录（可要求供应商提供或纳入合同约定）
   - 到货验收温度记录由茶饮店自行留存

5. **合同与质量承诺**
   - 供货合同中明确食品安全责任、验收标准、不合格退换货及赔偿条款
   - 供应商食品安全承诺书
   - 定期更新证照和检测报告的约定

**可执行建议：**
- 建立供应商档案，证照到期前提醒更新；检测报告按品种/批次归档，保存期限不少于产品保质期满后6个月，或按当地监管要求执行。
- 每批到货做感官验收（腐烂、霉变、异味、虫害）并记录；发现异常立即拒收并留证。
- 对供应商实行年度或半年评审，重点看证照有效性、检测合格率、到货质量投诉和冷链记录。
- 若供应商无法提供检测报告，可要求其送检或由茶饮店自行抽检，费用和责任在合同中约定。

注意：各地对食用农产品销售、合格证、检测报告的具体要求可能不同，建议以当地市场监管部门要求为准。
