# 夫妻店第一次找水果供货商：试单方法

**核心原则：先小批量试，别一次性压货，用一批货同时测“质量稳定性”和“供货商靠谱度”。**

## 一、试单前的准备

1. **先摸清自己的量**：按日销估算，香蕉一天卖多少把/斤，苹果、橙子一天各多少斤。第一次试单按 **1～2天的销量** 下单，别按一周的量。
2. **多找2～3家备选**：本地批发市场档口、产地代办、二级批发商都问一遍，拿同样的品种规格报价对比，不要只认一家。
3. **明确要什么规格**：苹果要什么果径（比如75/80）、橙子要什么规格和产地、香蕉要什么成熟度（青蕉还是黄蕉到店）。规格说不清，试单就没法比较。

## 二、三类货的试单重点不一样

**香蕉**
- 试单重点看**到货成熟度和催熟控制**：到店是青的还是已经转黄？几天能卖完？
- 第一次少量拿，观察它在店里2～3天的转色和损耗（黑斑、烂指）。
- 问清楚：是催熟蕉还是自然蕉、路上走几天、坏了怎么处理。

**苹果**
- 试单重点看**硬度、果径是否均匀、有没有碰伤和暗伤**。
- 苹果耐放，可以一次试多一两个规格，比较哪种好卖。
- 到货后开箱抽检底层，别只看面上那层。

**橙子**
- 试单重点看**新鲜度（果蒂、表皮）、酸甜口感、有没有干水**。
- 橙子怕放，第一次按小量拿，2～3天内看走量和口感反馈。

## 三、试单时要问供货商的关键问题

- 起送量/起批量是多少？能不能拼车或混装？
- 价格是按斤还是按箱？箱皮、损耗怎么算？
- 送货时间、运费谁承担？
- **坏果、烂果怎么赔？**（缺斤少两、坏果包赔的比例，一定要事先说清，最好留个微信记录）
- 能不能退换？下次拿货价格会不会变？

## 四、试单怎么判断成败

拿到货后按这几点打分：

| 维度 | 看什么 |
|---|---|
| 质量 | 坏果率、规格是否和说的一致 |
| 新鲜度 | 到店状态、2～3天后的损耗 |
| 价格 | 含运费、含损耗后的实际成本 |
| 服务 | 送货是否准时、出问题是否认账 |
| 稳定 | 第二次拿货是否还是这个品质 |

**建议：同一批货至少试2～3次再定长期合作。** 第一次好不代表稳定，第二次、第三次的品质一致性才是关键。

## 五、给夫妻店的实操提醒

- **香蕉和橙子先小量试，苹果可以稍多一点**，因为苹果耐放、试错成本低。
- 第一次别谈长期独家，保持2家备选，谁稳定用谁。
- 每次到货**当场验货、拍照留证**，尤其坏果和规格不符，方便后续理赔。
- 把钱和账记清楚：每批货的进价、损耗、实际卖出，算出真实毛利，再决定加大哪家的量。

一句话：**试单就是花小钱买信息——用一两天的量，测出这家供货商的品质稳不稳、出问题认不认账。**
