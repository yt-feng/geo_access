更该看重**坏果率和熟度**，价格和送货速度排后面。原因是香蕉是典型的高损耗、强时效水果，小水果店的核心风险不是“进贵了一点”，而是“卖不完、烂得快、口碑差”。

可按这个优先级判断：

1. **坏果率第一**
   - 香蕉一旦有机械伤、黑斑、霉点，坏得很快，还会传染催熟整批。
   - 进店前要明确：开箱抽查、坏果怎么赔、当天发现问题能否退换。
   - 小水果店议价能力弱，坏果率高的低价货通常最贵。

2. **熟度第二**
   - 你要看的是“到店后 1—3 天能不能卖完”的熟度，不是单一“越黄越好”。
   - 最好进青黄交接、可自己控熟的货；如果当天就要卖，才拿偏熟的。
   - 夏天熟得快，宁可略生；冬天可略熟。一次别进太多。

3. **价格第三**
   - 价格要在坏果率和熟度可接受的前提下比。
   - 不要只看每箱单价，要算“可售果成本”：进价 ÷ 可卖比例，再加上损耗和人工。

4. **送货速度第四**
   - 速度快是加分项，但如果送来得晚、熟度不合适、坏果多，快也没意义。
   - 更该看“稳定准时”和“能不能按你要的熟度分批次送”，而不是单纯快。

实操建议：小水果店先少量多批试供应商，连续 2—3 次记录每批的到货熟度、坏果率、可售比例、卖完天数，再决定长期合作。香蕉宁可少进勤进，也别为低价一次压太多货。
