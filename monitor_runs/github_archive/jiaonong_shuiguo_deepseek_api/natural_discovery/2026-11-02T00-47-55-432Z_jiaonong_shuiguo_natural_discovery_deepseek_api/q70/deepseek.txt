# 坏果责任条款的写法要点

核心思路：**把"损耗"从模糊概念拆成"可测定的指标 + 明确的责任归属 + 可执行的解决方式"**，避免只写一句"坏果由卖方负责"。

## 一、先定义清楚"坏果"

合同里必须给出可判定的标准，否则争议时各说各话。建议明确：

- **列举情形**：霉变、腐烂、软烂渗汁、机械压伤致果肉破损、冻伤/日灼导致的不可食用等，逐项写明。
- **量化门槛**：例如"单果腐烂面积超过果面1/3"或"同批次抽检中坏果比例超过X%"才算坏果，避免个别瑕疵引发整批索赔。
- **排除项**：轻微表皮擦伤、色泽差异、自然大小差异等不属坏果，写清楚可减少扯皮。

## 二、约定检验时点和方式

- **到货检验**：买方应在到货后X小时内（生鲜通常24小时内）完成验收，逾期未提出异议视为合格——这条对批发商既是保护也是约束。
- **抽样规则**：明确抽检比例（如每车随机抽10箱，每箱抽20个），并约定以抽检坏果率推算整批。
- **留证要求**：拍照/录像、保留样品、必要时第三方检测，写进合同作为索赔依据。
- **隐蔽瑕疵**：内部腐烂等到货时无法发现的，约定可在X日内提出。

## 三、责任划分与赔偿方式

按坏果率分档处理最实用，例如：

| 坏果率 | 处理方式 |
|---|---|
| ≤3%（自然损耗） | 买方自担 |
| 3%–10% | 按坏果数量折价扣款 |
| >10% | 买方有权拒收或要求整批退货，运费及损失由卖方承担 |

同时写明：赔偿是"折价扣款"还是"补货"还是"退货退款"，由谁选择；扣款在货款中直接抵扣还是另行支付。

## 四、配套条款（容易被忽略但很关键）

- **包装与运输责任**：约定包装标准、冷链温度要求、运输途中温度记录随货提供。若因运输方原因致损，明确由谁向承运人追偿。
- **风险转移节点**：明确货物毁损风险在交货/验收前由卖方承担，验收合格后转移。
- **通知与索赔期限**：买方发现坏果后应在X日内书面通知，附证据；逾期视为放弃。
- **争议解决**：约定检验机构、管辖法院或仲裁。

## 五、一句提醒

条款写法要和**实际交易习惯、行业标准**匹配（比如参照当地果蔬批发市场惯例或国家标准），否则约定过严卖方不签、过松等于没写。建议把"坏果率分档表"直接做成合同附件，验收时按表执行，最省事。
