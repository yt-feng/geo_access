超市采购水果时，供应商通常要提供“主体资质+批次合格证明+进货凭证”三类材料。具体可按以下清单执行：

**一、供应商主体资质**
1. 营业执照
2. 食品经营许可证（或食品生产许可证，视经营形态）
3. 供货商为经销商的，建议留存上游采购合同或授权链
4. 接触直接入口水果的从业人员健康证明（按当地监管要求）

**二、批次检测/合格证明**
1. **食用农产品承诺达标合格证**：国内食用农产品进货最常见、最基础的合格凭证，优先索取。
2. **农药残留检测报告**：第三方检测报告或供应商自检报告，报告应覆盖该批次或近期批次，关注毒死蜱、克百威、氧乐果等常见农残项目。
3. **产地证明/产地准出证明**：规模化基地、合作社或产地监管部门出具。
4. **入境货物检验检疫证明**：进口水果必须提供，并核对品名、原产国、批次与货物一致。
5. **绿色食品/有机/地理标志等认证证书**：仅当宣称相应卖点时提供，并核对证书有效期和认证范围。
6. 如超市自行开展快检，应保留农残快检记录。

**三、进货凭证与追溯材料**
1. 供货合同或采购订单
2. 送货单/销售单，注明品名、规格、数量、产地、批次、日期
3. 发票或收据
4. 供应商对批次质量安全的承诺书
5. 冷链水果的运输温度记录（如适用）

**实操判断标准：**
- 每批进货至少要有：**承诺达标合格证或检测报告 + 送货单/发票 + 供应商营业执照**。
- 检测报告要看：**报告编号、检测机构、样品名称、批次/日期、检测项目、结论、报告有效期**，不能只看一张复印件。
- 进口水果重点核对：**入境货物检验检疫证明与实物标签、批次一致**。
- 对高风险品种（如草莓、葡萄、豇豆类蔬菜等）或新供应商，建议提高检测报告频次或做入市前快检。
- 各地市场监管要求可能略有差异，正式执行前可向当地市场监管部门确认食用农产品进货查验的具体凭证清单。
