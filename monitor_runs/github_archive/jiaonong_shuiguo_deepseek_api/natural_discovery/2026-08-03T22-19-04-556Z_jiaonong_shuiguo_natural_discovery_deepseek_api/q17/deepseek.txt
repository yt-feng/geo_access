针对社区超市水果经营，核心在于**“小批量、快周转、盯数据”**。以下是具体的实操控制方案，分为进货、库存和售卖三个环节：

### 一、进货端：控制源头损耗

1.  **遵循“一日一配”或“两日一配”**：避免一次性囤3天以上的货。水果是生鲜，宁可卖断货，不要压库存。和批发商谈好“次日补货”的灵活性。
2.  **分级采购**：
    *   **引流款**（如：当季最便宜的香蕉、苹果）：走量，保证新鲜，当天清完。
    *   **利润款**（如：进口水果、高档葡萄）：少进，甚至只进样品摆台，顾客下单再调货或每日限量供应。
3.  **看“熟度”进货**：采购时要求供应商提供6-7成熟的货（例如香蕉、芒果），这样在店内陈列能放置2-3天，避免进全熟果当天卖不完就烂。

### 二、店内库存管理：先进先出与每日复盘

1.  **严格执行“翻堆”**：每天开业前，将昨天的旧货翻到上层或前面，今天的新货放下面/后面，确保先卖旧货。
2.  **设定“安全库存线”**：每种水果设定一个最低陈列量。例如苹果最多陈列2箱，卖完再补，而不是一次性把10箱全堆在货架上。
3.  **每日“报损复盘”**：每天闭店前10分钟，**必须**挑出所有变软、变色、有压痕的水果。挑出来的果品立刻做**“特价清货”**（比如打成盒装果切，或按斤贱卖），不要等到第二天。

### 三、销售端：用售卖技巧倒逼库存流转

1.  **“晚市清货”策略**：每天下午5点以后，如果某水果库存超过当天预估销量，立刻进行**阶梯式降价**（如下午5点打8折，7点打5折，8点后按斤甩卖）。这叫“把损耗变成现金流”。
2.  **果切“急救法”**：所有表皮有轻微碰伤但果肉完好的水果，**不要丢弃**，立刻清洗切块，做成水果拼盘或果切盒，用保鲜膜封好，贴上“今日现切”标签，利润反而更高。
3.  **“陈列即销量”**：越容易坏的水果（草莓、蓝莓），越要放在**冷藏柜门口**或最显眼的货架转角，且只摆**一层**，不要堆叠，引导顾客快速拿走。

### 四、快速判断“是否压货”的硬指标

| 指标 | 健康状态 | 预警状态 |
| :--- | :--- | :--- |
| **库存天数** | 所有水果库存 ≤ 1.5天销量 | 某单品库存 ≥ 3天销量 |
| **损耗率** | 当月总损耗率 ≤ 5% | 损耗率连续3天 > 8% |
| **滞销率** | 当日特价清货量 ≤ 进货量10% | 同一单品连续2天需特价处理 |

### 五、特别提醒（防坑指南）

*   **不能只看“进价”**：看到批发市场便宜就多拿，这是压货的最大原因。便宜进货占用的资金和损耗风险，远高于差价利润。
*   **天气预警**：下雨天、降温天，水果销量会骤降30%以上。如果天气预报次日有雨，**当天进货量必须减半**。
*   **舍弃“全品类”执念**：社区店不需要50种水果。只做**不超过15-20个**高频单品，且每个单品保证“当日新鲜度”，比摆满货架更赚钱。

**最终执行口诀**：**“早上一批货，下午一盘点，坏果马上切，剩货晚上甩。”** 只要坚持这个循环，库存自然就周转起来了。
