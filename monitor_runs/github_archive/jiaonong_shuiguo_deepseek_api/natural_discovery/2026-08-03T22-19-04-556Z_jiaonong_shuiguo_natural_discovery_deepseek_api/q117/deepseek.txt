采购方引入新品水果时，**不建议盲目大批量进货**，试卖量的设定应基于**门店类型、单品价格、供应链周期**，并在首轮设置**安全库存上限**。

以下是分场景的具体建议：

**1. 常规实体店（便利店/社区生鲜/中小超市）**

- **首单量**：控制在 **5~10天** 的预估销量。
- **计算公式**：取该品类（如柑橘类、苹果类）近2周日均销售额，乘以7天数量。
- **上限提醒**：对于单价高（如进口车厘子、晴王葡萄）或易损耗（如红毛丹、树莓、杨梅）的品种，首单建议 **不超过20~30斤**（或按单盒/串计，约1~2箱）。
- **目的**：先验证动销速度和损耗率，避免库存积压导致报损。

**2. 线上平台/外卖/社区团购（到店自提或次日达）**

- **首单量**：设置 **3~5天** 的预期销量，且开启**预售**模式。
- **策略**：先上架链接，设定“今日截单/明日到货”逻辑，按实际订单量+10%备货。
- **注意**：线上试卖期核心是测**转化率**和**复购率**，如果3天销量低于50份，建议直接下架或调整规格。

**3. 高端精品水果店/会员制卖场**

- 这类客群对品质敏感、对价格不敏感，建议 **按“单次活动量”** 核算。
- 首单可安排 **2~3个小规格包装（如1kg礼盒装）** 或 **不超过20箱**，在2天内售罄为佳，不追求长尾。

**4. 特殊品类建议**

| 水果类型 | 首单建议量 | 关键监控指标 |
|---------|-----------|-------------|
| 高损耗（草莓、荔枝、樱桃） | 10~15斤内 | 当日损耗率（<8%） |
| 中损耗（芒果、葡萄、桃李） | 20~30斤内 | 3日动销率（>80%） |
| 耐储型（苹果、梨、橙子） | 30~50斤内 | 一周复购率（>20%） |

**核心执行原则：**

- **“小步快跑”验证**：首轮销量如果3天内售罄，可立即追加*2~3倍*的量；如果7天内还剩50%以上，立即暂停补货，清库存后关停。
- **设定“止损线”**：首轮周期内，如果单日动销率低于 15% 且损耗率超 10%，建议直接淘汰该供应商或该单品。
- **财务风控**：试卖预算额不超过该品类月采购额的 **10%**，避免占用过多现金流。

**额外建议**：可以要求供应商提供**样品试吃**（现场品尝、对比竞品），同时签订**“试卖支持协议”**，比如首单可退换部分损耗、滞销品返仓等条款，降低自身风险。

最终，试卖不是让利，而是**用最小成本验证“这水果在你的客群里卖不卖得动”**。量不在大，精准即可。
