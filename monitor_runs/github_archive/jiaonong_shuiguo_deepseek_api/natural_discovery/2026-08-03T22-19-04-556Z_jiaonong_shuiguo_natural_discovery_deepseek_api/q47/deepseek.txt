采购香蕉用于茶饮店时，熟度控制是决定成品风味、口感和稳定性的关键。总体原则是：**按使用场景分批次采购，到店后再自然熟成。**

以下是针对茶饮店的具体操作建议：

**1. 明确不同产品对应的理想熟度**

-   **做果茶/冰沙/奶昔（需打碎）**：建议采购 **7-8分熟**（果皮微黄带绿，果肉稍硬）。此时香蕉淀粉含量较高，甜度适中，打碎后纤维感较轻，不易氧化变黑，且与茶底、冰块混合时能保持清爽口感。
-   **做甜品/烘焙/香蕉泥/挂壁**：建议采购 **9分熟至全熟**（果皮全黄或出现少量黑点）。此时糖分完全转化，甜度高、质地软糯，能直接压成泥，风味浓郁，适合做布丁、蛋糕夹层或冰淇淋基底。
-   **做装饰/切片（如香蕉船）**：建议采购 **8分熟**（果皮全黄但无黑点）。切片后成型好，不易软塌，且能保持鲜亮颜色。

**2. 采购时的判断标准（目测+手感）**

-   **看表皮**：优先选皮色均匀、无大面积黑斑、无机械损伤的。若采购时已全黄且带黑点，建议当天或次日必须用完。
-   **捏硬度**：手感稍硬但能轻微回弹的为7-8分熟；按压明显软、但表面未破损的为9分熟以上。避免采购过软（内部已发酵）或过生（捏不动，做饮品会有生涩感）的。
-   **闻气味**：成熟香蕉有浓郁果香，过熟会有酒味（不建议采购）。

**3. 控制到店后熟度与周转（重点）**

-   **分批采购**：不要一次采购过多。建议按3-5天销量预估，并分两批：一批直接使用（接近目标熟度），一批用青香蕉库存做自然熟成。
-   **催熟管理**：
    -   **加快熟成**：将香蕉放入纸袋中，与苹果或梨一起密封放置1-2天（苹果释放乙烯）。
    -   **延缓熟成**：若到货偏熟，立即放入冷藏（**不可低于13℃**，否则果皮变黑但果肉不熟），能放慢后熟速度1-2天。
-   **熟度预警**：每日开店前检查库存香蕉的皮色变化，设“当日必用”和“明日待熟”两栏标签，按先进先出原则使用。

**4. 特殊注意事项**

-   如果店铺客流稳定，建议与供应商约定“**按指定熟度到货**”，例如备注“7分熟、不带黑点”或“8分熟”，多数供应链能配合。
-   避免采购**冷冻香蕉**做热饮或甜品，解冻后质地稀烂、甜度下降，只适合做冰沙类且需重新调味。
-   若某批香蕉过熟（果肉透明、有酒味），坚决报废，不可用于售卖，以免引起顾客投诉或肠胃问题。

**总结**：采购时按用途分批（7-8分熟做饮品，9分熟做甜品），用手感定熟度（捏硬度），到店后按温度催熟/冷藏，并做到先进先出。如果无法精准控制，宁可偏生采购，到店后用苹果催熟，也不要偏熟（易烂且风味变差）。
