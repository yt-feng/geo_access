大型超市对水果供应商的要求通常非常严格，核心在于**安全可追溯**和**高效保鲜**两大维度。以下是必须具备的关键能力，分为食品安全和物流两大板块：

### 一、食品安全能力（核心底线）

1.  **基地与源头管理**
    -   **标准化种植/养殖体系**：具备自有或紧密合作的标准化种植基地，有完整的农事操作记录（如施肥、施药时间与用量）。
    -   **产地环境检测**：能够提供产地土壤、水源的定期检测报告，确保无重金属或化学污染。
    -   **农残控制**：严格执行国家规定的农药安全间隔期，并配备**快速农残检测设备**或在入库前委托第三方进行定量检测。

2.  **分拣与包装规范**
    -   **分拣标准**：拥有符合超市定级标准（如大小、糖度、外观）的分选线，剔除腐烂、霉变果。
    -   **包装安全性**：使用符合食品级标准的包装材料（如保鲜膜、贴标），防止二次污染。对于切分水果（如鲜切果盒），必须有**冷鲜加工车间**（控温、消毒、防尘）。

3.  **仓储与冷链控制**
    -   **温区管理**：必须具备**预冷能力**（采后迅速降温），并根据不同水果（如香蕉、苹果、榴莲）提供不同的温湿度仓储条件（通常在0-15℃之间调节）。
    -   **冷库卫生**：定期对冷库进行消毒和除霜，避免微生物滋生及水果间串味。

4.  **批次与追溯体系**
    -   **全链路追溯码**：从田间批次号、加工日期、物流车辆到门店，必须具备“一果一码”或“一批一码”的追溯系统，能在发生食品安全问题时**快速下架并定位问题批次**。
    -   **检测报告随行**：每批次产品需附带出厂质量合格证明，以及必要时海关检疫证明（进口水果）。

---

### 二、物流与供应链能力（保障新鲜度）

1.  **全程冷链运输**
    -   **温控车队**：配备带温度记录仪的冷藏车（温度波动范围需稳定，一般±1℃以内），并安装**GPS+温控探头**，确保从产地到门店的“不断链”。
    -   **装卸效率**：具备站台对接或快速装卸能力，减少在常温下的暴露时间（通常要求10分钟内完成装载）。

2.  **高频次与快速响应**
    -   **多温层配送**：能支持**一日一配**或**两日一配**的高频次配送，缩短门店库存周期。
    -   **缺货应急预案**：在水果滞销或突发性需求增加时，有备用供应商或调货通道，能在24-48小时内完成补货。

3.  **分拣与加工物流**
    -   **预包装处理**：在配送中心具备自动称重、贴标、打包的能力，减少门店二次加工损耗。
    -   **催熟能力**：针对香蕉、芒果、木瓜等后熟型水果，供应商需具备**专业催熟库**（乙烯气体控制），确保到店时达到最佳食用熟度，而非生硬或过熟。

4.  **信息化与数据对接**
    -   **库存可视**：供应商的ERP系统应与超市系统打通，提供实时库存和到货预报。
    -   **损耗数据反馈**：有能力追踪门店端损耗率，并据此反向优化前面环节的包装和物流参数（如调整包装透气孔）。

---

### 总结判断建议

如果您是**采购方**（超市）在做评估，建议重点核查三点：
1.  **看资质**：是否具备《食品经营许可证》、种植基地的有机/绿色认证。
2.  **看现场**：实地查看其预冷设备和分拣车间的温控与卫生条件。
3.  **看单据**：随机抽检一批水果，要求现场出具此批次的**出厂检验报告**和**运输温度记录曲线**。

如果“人货混装”或“无预冷直接装车”这类情况存在，则不具备基本的大型超市供应资格。建议初次合作采取**小批量试单**（如先供3-5家门店一个月），验证其实际履约和品控能力后再全面铺开。
