商超菠萝销售，整果和切好的果切各有优劣。**建议采用“整果为主、果切为辅”的组合策略**，具体取决于门店定位、客流和损耗控制能力。

以下是详细对比和建议：

**1. 整果销售（推荐主打）**
- **优点**：毛利高，损耗低（外壳是天然保护层），顾客可自行挑选，适合家庭周末采购。菠萝作为“季节性引流品”，整果价格透明，容易吸引客流量。
- **适用场景**：社区型大卖场、周末客流高峰、有较强陈列面积的门店。
- **操作要点**：要配备削皮机或现场削皮服务，以解决顾客“嫌麻烦”的痛点。包装上可标注“新鲜带皮，回家现削”以及简单食用指南。

**2. 果切销售（推荐辅推）**
- **优点**：客单价较高（毛利率可达50%以上），满足即食需求，能消化部分外形稍有瑕疵的果实，减少报损。
- **适用场景**：写字楼商圈、工作日晚间时段、年轻客群占比高的门店；适合作为晚间打折处理平台。
- **操作要点**：**必须做到“现切现卖”**，并实行“日清”或“半日清”原则，包装盒标注具体切制时间。果切必须严格冷链（4℃以下），防止细菌滋生。

**3. 关键决策指标**
- **看损耗**：菠萝常温储存期约3-5天。如果整果销量不大、周转慢，建议主推果切，因为果切可以通过打折日清，整果烂掉只能报损。
- **看竞争**：周边如有大量水果连锁店，可增加果切比重，打差异化；如果周边以菜市场为主，整果更受欢迎。
- **看人力**：果切需要固定人工和标准操作台。若门店人员紧张，**建议只卖整果+提供免费或收费削皮服务**，这是成本最低、风险最小的模式。

**4. 实操建议（最优做法）**
- **陈列比例**：整果占70%（主陈列位），果切占30%（冷柜或出入口）。
- **去皮服务**：在水果区设置“现削现卖”摊位，现场削好整果（套保鲜膜）和果切（盒装）同步卖。
- **试吃引流**：将果切切成小块做试吃，能显著带动整果销售。

**最终结论**：**如果只能选一种，优先卖整果**。因为损耗可控、操作简单，且菠萝作为大众水果，顾客更倾向于买“看得见的完整新鲜”。若要提升业绩和客单价，则必须增加“果切+试吃”作为补充。
