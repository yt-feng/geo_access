第一次找水果供货商，**最核心的原则是：小量多次，先看品质，再谈价格，最后定长期合作。** 千万别一上来就大车进货或签独家协议。

针对香蕉、苹果、橙子这三种“硬通货”，试单策略完全不同，我帮你拆解成“三步走”：

### 第一步：控制首单量（宁缺毋滥）
夫妻店资金和仓储压力大，首单量建议控制在 **“3-5天的销货量”**，且每种水果分开计算：

- **香蕉（进口/国产）**：首单 **1-2箱**（约13-15公斤/箱）。原因是香蕉催熟度变化快，一旦卖不动损耗极大。你要观察的是到货时的“青度”，以及2-3天内能否在店里自然催熟。
- **苹果（红富士/花牛等）**：首单 **1-2箱**（净重约10-20公斤/箱）。苹果耐放，但不同产区甜度差异大（如烟台脆、陕西甜），你要测的是“口感稳定性”。
- **橙子（脐橙/甜橙）**：首单 **1-2筐（或1箱）**。橙子水分和酸甜度受产地影响极大，且运输途中易碰伤，首单少进，重点看“表皮完好率”和“出汁率”。

**操作建议**：直接告诉供货商：“我这是新开的夫妻店，先每个品种拿1箱试销，卖得好马上补单。” 如果对方强制要求拿整板（如24箱起），直接换下一家。

### 第二步：试单时“验货”必须盯死这几点
这比谈价格更重要，因为水果是“非标品”：

1. **香蕉**：要摸“棱”和“皮”。试单时如果到手是黄透的，说明供货商压货太久；如果是全绿的，且果皮有棱（饱满的棱），说明新鲜度高。回家放1-2天，若能在室温下慢慢变黄，且果肉糯甜，就是好货。
2. **苹果**：看“梗”是否翠绿。到货后摘一个，苹果把儿如果是绿且湿润的，说明是刚下树；如果是干褐色的，是冷库陈货。试单时尝脆度，如果口感发面（粉），直接放弃这个供应商。
3. **橙子**：看“水分”与“酸度”。切开一个，看果肉外皮的“白瓤”厚度，薄且紧密为佳。尝味道时重点问一句“这批果是哪个产地的？”——如果对方含糊其辞，比如只说“好产地”，你就要警惕。

### 第三步：设计“试单对赌”策略（关键技巧）
这一步能帮你识别批发商是否诚信：

- **口头承诺留痕**：付款前问清楚“如果这批果到店后，出现大面积坏果或口感不符，能退换吗？” 如果对方满口答应“包退换”，你就试单；如果支支吾吾说“水果生鲜不退换”，那你必须在付款前就挑明损耗标准（例：整箱损耗超过10%的部分，按原价退）。
- **二次补单测试**：第一单卖完后（通常3-5天），如果你觉得品质不错，**不要立刻大批量进货**，而是第二次拿“双倍量”试单。如果第二次品质明显下降（如香蕉变烂货、苹果甜度下降），说明供货商混装发货，这种不稳定供货商直接淘汰。

### 额外的“避坑”提醒
- **不要被“包甜包脆”忽悠**：水果季节性强（如冬橙夏芒果）。试单前，先让供货商报出**产地+当前霜冻/雨季情况**，如果对方说不出，说明是倒手货。
- **对比价策略**：试单时问清“净果价”还是“带箱价”。很多零售店吃亏在皮箱重量上（一个纸箱能占到4-5斤），要求供货商扣皮后称重。
- **时间点**：试单最好选在**周一或周二**，这样如果周五卖完，你对整周的损耗率、顾客反馈有完整认知，周末才敢加量。

**最后总结一句话**：第一次合作，把他当成“一次性买家”来防，把他当“长期伙伴”来谈。试单3-5天，你会发现这个供应商的“真实面目”——是良心批发商（会主动提醒你哪批货不稳），还是只管赚钱的搬运工。祝开张大吉！
