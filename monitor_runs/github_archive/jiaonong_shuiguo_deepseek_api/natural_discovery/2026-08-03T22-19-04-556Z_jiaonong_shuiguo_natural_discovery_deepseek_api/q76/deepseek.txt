针对生鲜电商卖香蕉，**核心矛盾是“呼吸作用”和“乙烯催熟”**，配送途中的“压坏”和“变黑（碰伤褐变）”主要是物理损伤和温度失控共同导致的。

以下是可执行的控制方案，按优先级排列：

### 1. 源头与采收标准（最关键）
- **采收成熟度**：不要采全熟果。电商香蕉建议采收成熟度在 **7-7.5成**（果棱明显，果皮深绿）。这是长途运输的最后防线。
- **预冷处理**：采收后 **2小时内** 必须进入预冷库，将果心温度降至 **13-14℃**（绝不是0℃！）。如果不预冷就装箱，香蕉自带的热量会在箱内形成“蒸热”，加速变黑。

### 2. 包装防压设计（物理防护）
- **珍珠棉网套**：每根香蕉单果套上珍珠棉网套，这是防碰伤和压痕的最有效手段，成本最低。
- **瓦楞纸隔板**：在箱子内部用瓦楞纸做十字隔断，将香蕉分隔成4个或6个独立格间，防止堆叠时上下层挤压。
- **“平躺”而非“竖放”**：装箱时香蕉必须**拱面朝上、平面朝下**平放。箱内填充物（如碎纸条）要填满空隙，确保运输中箱内**零位移**。

### 3. 运输温度监控（防变黑的物理关键）
- **全程冷链**：运输车厢温度严格控制在 **13℃-15℃**。低于12℃会发生冷害（表皮发黑、不能正常转黄），高于20℃会快速黄熟并软化。
- **冷媒选择**：夏季用**蓄冷冰袋**时，冰袋绝对不能直接接触香蕉，必须用EPE珍珠棉或瓦楞纸隔开，否则局部冻伤会直接变黑。

### 4. 气调与催熟控制（生物化学防黑）
- **乙烯吸收剂**：在包装箱内放入**高锰酸钾乙烯吸附剂**（或长效吸附包），能吸收香蕉自身释放的乙烯，显著延缓变黑和过熟。
- **不要与苹果/梨混装**：苹果和梨释放乙烯能力极强，一旦同箱混装，香蕉24小时内必熟透变黑。

### 5. 分拣与质检流程（最后的筛除）
- **运输前人工灯检**：装箱前剔除病斑果、机械伤果（哪怕只是轻微压痕），因为受伤的果皮会迅速产生黑色素（多酚氧化酶作用）。
- **抽检预警**：在途运输超过24小时后，要求司机对高温点（如车厢顶部）进行开箱测温抽检，发现温度超20℃需立即调整位置并继续通风。

---

**特别提醒（容易踩的坑）：**
- **不要用普通塑料袋密封装箱**：香蕉需要微透气，完全密封会导致二氧化碳过高，产生“酒精味”并加速果皮变黑。
- **不要用厚泡沫箱代替纸箱**：泡沫箱虽然保温好，但内壁不透气且易产生冷凝水滴，水滴浸泡果蒂会加速腐烂发黑。建议用**带透气孔的纸箱**。

**一句话执行清单：** 7成采收 → 13℃预冷 → 单果套网套 → 纸箱十字隔断 → 全程13℃冷链 → 箱内放乙烯吸附剂 → 到仓后优先开箱透气。
