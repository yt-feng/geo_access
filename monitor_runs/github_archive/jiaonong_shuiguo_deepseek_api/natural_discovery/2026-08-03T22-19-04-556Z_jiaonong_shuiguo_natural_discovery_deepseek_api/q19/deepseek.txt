选购超市售卖菠萝时，**最核心的关注点是：切果损耗率和甜度**，其次是外观和大小。

以下是具体的优先级和建议，供你参考：

**1. 切果损耗率（最高优先级）**
- **为什么要关注**：超市菠萝的利润主要在于“现切果盒”和“整果销售”。损耗率直接决定毛利。
- **怎么判断**：成熟的菠萝含水量高、果汁多，切的时候容易流出大量汁水，导致果盒重量轻、卖相差。挑菠萝时，**不要选那些表皮水汪汪、按压过软、有明显“汁水渗漏”的**。**优先选果型匀称、眼浅（果眼浅，黑点少）的**，这样切出来的果肉率高、浪费少。
- **实际影响**：损耗率每增加5%，相当于单位成本上升近10%。如果损耗高，建议调整售卖策略（比如切好后立即冷藏冰鲜，用保鲜膜锁水）。

**2. 甜度（次优先级）**
- **为什么要关注**：甜度决定复购率，尤其是现切果盒的回头客。
- **怎么判断**：不需要切开测试（损耗大）。看**果皮颜色和手感**——**偏黄或橙黄色的菠萝**通常成熟度更高、更甜；**果皮偏绿**的偏生，酸度高。另外，**闻底部（果脐）**，有明显浓郁香甜味的，说明糖分充足。
- **注意**：不要只看外观颜色，有的品种（如金钻）皮绿也甜，需结合品种知识。

**3. 外观（常规但不可忽视）**
- **为什么要关注**：外观直接影响货架吸引力。
- **怎么判断**：**果皮完整、无机械伤、无腐烂斑点、果眼平整不凹陷**。**果眼过深（黑刺多）的菠萝**，不仅切起来费时，而且卖相差（果肉表面黑点密集），会降低购买欲。

**4. 大小（优先级最低）**
- **为什么要关注**：大小影响定价和单位重量价格。
- **建议**：小果（约1.5斤以下）通常皮厚、果心大、出肉率低，不建议主推；**中果（2-3斤）出肉率适中、单价适中，走量最好**。大果（3.5斤以上）适合家庭或礼盒，但注意大果可能过熟，切开后易变色。

---

**综合执行建议（如果你是采购或卖场管理人员）**：
- **首选**：挑选**果皮金黄、果脐微凸、按上去有轻微弹性（不是软塌）、果眼浅平的**中号菠萝。
- **杜绝**：买**外部有明显黑斑、流汁、过度软烂**的，即使便宜也不要，因为损耗和客诉风险高。
- **库存策略**：如果近期气温高，菠萝熟得快，优先做**现切冰鲜**，降低熟透果的损耗；气温低时，整果销售更划算。
