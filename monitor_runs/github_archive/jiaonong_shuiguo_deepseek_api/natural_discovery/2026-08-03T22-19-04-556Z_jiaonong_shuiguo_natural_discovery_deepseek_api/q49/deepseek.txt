在茶饮店旺季突然面临菠萝用量激增的情况时，处理临时补货的关键在于**明确需求、锁定价格、确认质检、约定时效和风险分担**。以下是一套可直接使用的沟通与条款建议：

**第一步：提前24-48小时书面通知（而非口头）**
不要只打电话，务必通过微信聊天记录或邮件发送《紧急补货需求单》，内容包括：
- 具体数量（如：500公斤去皮鲜菠萝块）
- 质量标准（如：成熟度7-8成、无黑心、糖度≥12度、切块规格2cm×2cm）
- 到货时间（精确到日/时）

**第二步：明确“临时补货”的三项核心约定（建议原话沟通）**
1. **价格锁定**：“本次为紧急加单，请按上周的采购单价执行，若原料市价上涨超过5%，需提前报备我重新确认，不得私自改价。”
2. **品质承诺**：“本批菠萝到货时，我会按原有验收标准抽检。若因赶工出现黑心、发软超过5%，我不接受，供应商需无条件换货或退款。”
3. **时效与违约责任**：“如果不能在约定时间到货，每延迟1小时，扣减该批货款的2%；若导致我断货停售，损失由你方承担。”

**第三步：同步启动“应急备份”**
- 立即向其他1-2家备选供应商询价同规格菠萝，形成“竞争性压力”，防止老供应商坐地起价。
- 在沟通中明确告知：“如果这批加急货品无法满足，我将启用备用渠道，后续旺季大货仍继续合作。”这能显著提高供应商履约积极性。

**第四步：收货时的双人复核**
到货后，请仓管和店长一同验收：
- 过磅确认数量（扣除包装筐/箱重量）
- 开箱抽查（抽3箱看底部，避免“表好内烂”）
- 拍照留证，签收单上注明“待检验后结算”

**最后的兜底话术（可直接复制）**
“李总，这次突然加量也是因为生意好，后续肯定有更多长期单。这次你帮我把货备齐、质量稳住，结算时我主动提前打款；如果质量出问题，下个月订单很可能就转给别人了。你这边今天能回复我确切到货时间和价格吗？”

**核心原则：** 临时补货最容易吃亏的是“口头承诺”，务必用文字锁定。即使关系再好，也要在合同中或聊天记录里写明“紧急采购补充条款”，避免旺季过后扯皮。如果对方无法满足时效，立刻启动备选，不要等断货再补救。
