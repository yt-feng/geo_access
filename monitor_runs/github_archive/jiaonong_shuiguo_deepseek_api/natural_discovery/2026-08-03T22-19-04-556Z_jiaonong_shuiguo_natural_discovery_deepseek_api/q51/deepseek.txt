针对茶饮店水果口味波动的问题，**采购时强烈建议固定产地和供应批次**，但需结合灵活预案。

**为什么必须固定产地/批次？**

1. **风味一致性**：水果的甜度、酸度、香气对茶饮口感影响极大。同一品种（如芒果、草莓）在不同产地（如海南 vs 越南）、不同海拔、不同季节，糖酸比、含水率、纤维感差异巨大。固定产地能确保你的招牌饮品“味道不变”。
2. **品质稳定性**：同一批次的果园，在采摘成熟度、分拣标准、冷链处理后，出品率更可控，减少因果肉软硬、褐变速度差异导致的退货和客诉。
3. **定价与成本核算**：固定产地便于锁定合作价格，避免在大宗果价波动时被中间商随意抬价。

**具体操作建议（可执行）**：

- **建立“产地-品种-成熟度”标准卡**：例如，芒果选“海南贵妃芒，7-8分熟采摘，产后40小时内到店”；草莓选“丹东红颜，单颗15-20g”。不要只看“进口”或“国产”这种宽泛标签。
- **锁定1-2个核心供应基地或一级批发商**：签订框架协议，明确“同一地块/同一采摘周期优先供应”。如果是非基地区域，要求供应商提供每次的“果园编号+采后批次码”。
- **验收时做“感官抽检”**：每批到货时，随机开箱试吃或测糖度（用手持糖度计，几十元一个），并记录最高/最低值。若偏离标准超过10%，有权拒收或要求调换批次。
- **设立“替补清单”**：即便是固定产地，也有极端气候（如连续阴雨）导致品质下降。提前准备2-3个备选产地（如酸度稍高的产地），并预先调整配方（如增加一点糖浆或果酱来平衡）。

**注意点**：固定产地不等于“永远只买一家”。如果该产地品种遭遇病虫害或减产，你必须有B计划。固定批次的另一个含义是“固定采收窗口”，而非死磕自然规律。

**一句话结论**：**固定是必须的，但要固定“标准”而非“名字”——即锁定能够提供稳定风味和可追溯批次的供应商，同时准备可替换的合格备选方案。**
