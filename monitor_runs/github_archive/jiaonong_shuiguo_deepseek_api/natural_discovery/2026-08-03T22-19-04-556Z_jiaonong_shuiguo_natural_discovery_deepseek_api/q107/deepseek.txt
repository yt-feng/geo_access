是的，起订量太高会增加损耗风险，尤其对于香蕉和菠萝这类**易腐、季节性波动大**的水果。具体风险如下：

1. **保质期短**：香蕉（常温约3-7天，冷藏易变黑）和菠萝（采摘后约7-10天）货架期有限。起订量过高，若未在保质期内售完，会直接腐烂。
2. **催熟不可控**：香蕉需乙烯催熟，一旦开始熟化，窗口期极短；菠萝成熟后糖分上升，存放易发酵变质。大批量进货会放大“过熟”风险。
3. **需求波动**：若实际销量低于预估，多余库存只能打折或废弃，损耗率可能从正常的5%飙升至20%以上。
4. **冷链中断**：大批量运输若分拣、配送不及时，中途温度失控会加速变质。

**建议做法**：
- 设定**7天滚动预测**：按近一周日均销量的1.2-1.5倍订货，而非一次订购半个月量。
- 与供应商协商**分批到货**，或采用“最小起订量+补货协议”。
- 优先选择产地直采（缩短运输时间），或选用成熟度稍低的批次。
- 对菠萝可采用“带皮整果”存储（可延长3-5天），香蕉则可挂放通风处抑制大面积软化。

如果起订量是供应商固定门槛，可尝试联合周边商户拼单，分摊风险，并预留15%的安全冗余量做促销或加工（如菠萝切块销售）。
