在便利店上架香蕉，**最推荐“单根和小把（2-3根）混搭组合”，尽量避免整袋包装为主。**

主要原因是便利店的目标客群和购物场景与超市不同，具体建议如下：

**1. 首选：单根（约500g以内）或按“根”计价**
- **理由**：便利店顾客多为即时消费（早餐、加餐、下午茶），通常只买1根路上吃。单根方便拿取、容易估算价格，且周转快。
- **定价建议**：按根定价（如5-6元/根），比按斤更直观，避免顾客在柜前算账。

**2. 次选：2-3根的小把预包装**
- **理由**：适合家庭少量补充或办公室囤货。小把能降低个体损耗（一根坏了不影响整袋），且轻量包装适合放在冷藏柜或货架侧面。
- **注意**：必须贴好价签和重量，方便自助扫码。

**3. 不推荐：整袋（5-10根）或大包装**
- **原因**：便利店单店人流量有限，大包装香蕉极易滞销发黑；且占据宝贵货架空间，顾客也不愿在便利店提着一大袋香蕉。

**具体执行建议：**
- **包装形式**：用透明保鲜膜包单根，贴条码；小把用网袋或纸绳捆扎。
- **陈列位置**：放在收银台旁的独立果篮，或冷藏柜上层，不要放在常温主通道（易碰伤）。
- **损耗控制**：每天定时挑出黑斑或过熟香蕉，打折促销（如“今日特价”），绝不能和新鲜香蕉混放。
- **替代做法**：如果担心损耗，可以试销期只放单根，观察一周销量再决定是否加小把。

**最后提醒**：务必在价签上标注“产地”（如菲律宾、云南），并注意进货量——便利店香蕉的黄金售卖期只有2-3天，宁少勿多。
