针对批发商担心货到后损耗高的问题，在合同中应重点围绕**责任划分、损耗标准、验收流程、风险转移时点**四个核心环节来约定。以下为可直接写入合同条款的实操建议：

### 一、明确“合理损耗”与“超常损耗”的界限
这是责任划分的基础，必须量化。
- **约定标准**：建议写明“生鲜类商品自然失重及运输途中正常水分蒸发损耗率不超过 **2%** （或根据品类约定具体比例），因包装破损、挤压、霉变、腐烂等非自然因素导致的损耗不在此列。”
- **备注**：若货物品类特殊，建议附上《货物品质标准附件》，用文字描述或图片界定“坏果”标准（如腐烂面积超过1/3）。

### 二、约定验货时间与单方拒收权
防止货到后“概不认账”。
- **约定验收期**：“买方应在货物到达指定地点后 **24小时内** 完成抽样验收（抽样比例不低于总箱数的10%），超时视为验收合格。”
- **快速异议**：“验收时如发现整箱腐烂率超过 **5%**，买方有权就地拒收该批次，并拍照留存证据，24小时内书面通知卖方，未通知视为默认接受。”

### 三、锁定“风险转移”时点（核心）
这决定了货损由谁承担。
- **推荐写法**：“自卖方将货物交付给**承运人**（物流公司）时起，货物毁损、灭失的风险由卖方转移至买方。但买方委托卖方代办运输的，卖方应确保交付承运人时货物完好，运输途中发生的一切腐烂、破损由买方自行承担，与卖方无关（除非有证据证明发货时即存在质量缺陷）。”
- **风险提示**：若卖方负责送货上门，则改为“风险自买方签收时转移”。**建议在合同中明确写清“签收”即视为货物外观及数量合格。**

### 四、针对“高损耗”品类的兜底条款
若担心批次性质量问题，可增加以下条款：
- **质量担保**：“卖方承诺交付的货物为当季采摘/加工，符合国家食品安全标准，且出库时甜度、新鲜度符合约定标准。如因卖方发货前冷藏不到位、使用非冷链车（或不符合约定运输方式）导致的批量腐烂，卖方需承担退货责任并赔偿买方因此产生的装卸费、仓储费。”

### 五、结算与扣款机制（实操上最有效）
- **约定规则**：“货款结算时，按实际验收合格数量结算。若最终坏果率（按剔除腐烂部分后的重量计算）低于约定标准，买方按实际重量付款；若超过约定标准，买方有权在货款中直接扣除超额损耗对应金额的 **1.5倍** 作为违约金（或直接扣除该部分货物货款）。”

---

**特别提醒**：
1. **证据固定**：合同须写明“验收时需双方共同签字确认《货损确认单》”，且明确“买方主张损耗时，须提供含时间水印的现场照片或视频，卖方有权在3日内核查”。
2. **运输选择**：如果是跨省运输，建议在合同中约定“运输方式及保温要求”，否则一旦发生耗损，责任极难判定。
3. **法律边界**：若合同约定“货到后坏果与卖方无关”，可能因显失公平被认定无效（民法典第497条），建议至少保留“因包装或发货前质量问题导致的损耗”由卖方承担的责任。

建议将上述条款整合成独立的“质量验收与损耗处理”章节，并附上双方的验收签字模板。起草后最好请执业律师审核一遍，特别是关于“合理损耗比例”的约定，需结合当地批发市场惯例。
