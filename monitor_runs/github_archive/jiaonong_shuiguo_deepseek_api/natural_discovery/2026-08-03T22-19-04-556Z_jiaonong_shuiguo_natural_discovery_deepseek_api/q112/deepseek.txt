在水果采购合同中，关于坏果率的赔付标准，没有一个全国统一的固定数值，主要取决于水果品种、运输距离、季节以及双方谈判结果。但根据行业惯例和常见合同条款，可以给你以下参考：

**1. 常见行业标准（建议合同约定值）**
- **一般鲜果（如苹果、梨、柑橘）**：坏果率（包括腐烂、霉变、严重机械伤）通常约定在 **5% - 10%** 之间。
- **高价值/易损耗水果（如草莓、樱桃、荔枝、葡萄）**：因自然损耗大，通常约定在 **8% - 15%**。
- **长途冷链运输**：建议将坏果率压在 **5%以下**，超过即需赔付。

**2. 赔付方式（违约条款）**
- **阶梯赔付**：例如坏果率超过5%但≤10%，按超出部分货值的1.5倍赔偿；超过10%，按全部货值的50%赔偿。
- **直接拒收**：如果坏果率超过 **20% - 30%**（视品种），买方可整批拒收，并要求退还全款。

**3. 关键提醒（实操建议）**
- **必须写明“坏果”定义**：包括腐烂、霉变、软烂、长斑、压碎等，不能只写“坏果”。
- **明确验收时间**：收货后24小时内开箱查验，超过时限视为认可。
- **保留证据**：要求对方提供现场照片、双方签字确认的验收单。

**4. 若无明确约定时**
如果合同没写，法律上一般按《民法典》关于质量不符合约定的规定处理，但需证明质量不符。实务中，建议至少按 **5%** 为底线谈判，高于此即要求换货或退款。

**结论建议**：无论什么水果，**坏果率超过5%就应设置赔付条款**（若是草莓等特易损水果可放宽到10%以内）。合同签订前，一定要把“坏果”的定义和验收期限写清楚，否则后续很难索赔。
