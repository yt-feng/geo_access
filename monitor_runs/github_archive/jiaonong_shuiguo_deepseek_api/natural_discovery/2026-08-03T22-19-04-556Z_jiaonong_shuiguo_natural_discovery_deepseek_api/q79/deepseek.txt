选水果供应商时，**最应该优先问的是“售后”**，其次是配送，最后才是价格。原因如下：

1. **售后（最关键）**：水果是易损耗品，运输和存放中极易出现坏果、熟度不均等问题。  
   - 问清：坏果包赔的标准是什么？（是按颗赔、按斤赔，还是整箱重发？）  
   - 哪些损失算供应商的，哪些算团长的？（比如消费者自己放坏了谁负责？）  
   - 售后响应速度如何？（是否当天反馈、当天处理？）  

   **原因**：售后直接决定你的客诉率和复购率。如果售后模糊，你不仅会亏钱，还可能得罪团员，损失信任。

2. **配送（次关键）**：  
   - 问清：起订量是多少？配送范围覆盖哪里？多久能到？  
   - 是否支持分批补货？（例如第一次少订，第二天再送一批）  
   - 冷链运输还是常温？破损率大概多少？  
   **原因**：配送影响你的到货时间和损耗。如果配送慢或范围有限，会影响你的开团节奏，但配送问题往往可以通过提前备货或调整自提点来补救，比售后更可控。

3. **价格（最后问）**：  
   - 对比市场价即可，但不要单纯追求低价。  
   - 问清：是否含税、含运费？整箱规格是否固定？（有的供应商低价但果子小或品质差）  
   **原因**：水果品质和售后才是长期复购的核心，压价太狠容易逼供应商降低品控，反而得不偿失。

**总结建议**：  
- 先问售后规则（能不能赔、怎么赔），再问配送能力（速度、范围），最后谈价格。  
- 如果供应商能给出明确的书面售后条款（哪怕简单几句话），通常更靠谱。  
- 初次合作建议小批量试单，验证售后和配送的实际情况，再谈长期合作。
