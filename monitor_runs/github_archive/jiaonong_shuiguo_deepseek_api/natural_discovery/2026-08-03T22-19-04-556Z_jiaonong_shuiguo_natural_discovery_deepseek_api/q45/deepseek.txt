签订年度合同是好事，能锁定货源和价格，但也是最容易出纠纷的环节。以下是我梳理的高风险条款和避坑要点，你签之前务必逐条核对。

**一、价格与调价机制（这是最大雷区）**
1. **固定价≠真固定**：很多合同写“年度固定价”，但没写质量等级标准。供应商可能会按标准果的价格签，发货时全给次级果。建议明确：合同价对应的品级（如直径、糖度）、允许的果径浮动比例，以及不符合标准时的折扣公式。
2. **缺失调价触发条件**：水果价格波动大。如果合同只写“甲乙双方协商”，那基本等于没写。应明确：当市场收购价上涨/下跌超过X%（如15%）时，任何一方可书面申请调价，并约定参考数据源（如批发市场每日报价）。
3. **违约金基数**：最好明确“违约金 = 未供货量 × 当前市场差价”，而不是“按合同总金额的X%”，这样对双方都公平。

**二、质量标准与验收（最容易扯皮）**
1. **“以样品为准”的陷阱**：样品只代表签约时的状态，无法代表后续批次。建议把验收标准写成书面文件（包括农残检测值、成熟度、允许的磕碰比例），而不是口头说“参照样品”。
2. **验收权和时效**：明确“到货后24小时内验收”，逾期视为合格。但也要约定：若发现内部腐烂，可在收货后7天内提出异议（因为内部损伤有时肉眼无法立刻看出）。避免“入库后概不负责”的霸王条款。
3. **退换货机制**：写明不合格果的处理流程——是当场拒收，还是扣价接收？拒收后的运输费由谁承担？最好约定“批次不合格率超10%，整批有权拒收”。

**三、供货量弹性与销售预测**
1. **“旱涝保收”条款**：如果合同写“供应商保证月供货100吨”，但超市实际销量只有80吨，供应商可以起诉你违约。反过来，如果超市要求“按需供货”，供应商也会拒绝。建议采用**阶梯式保底+弹性**：比如月保底60吨，上浮不超过20%，双方提前15天书面确认下月计划量。
2. **不可抗力范围**：注意把“极端天气、虫灾、疫情管控”列入不可抗力条款，并约定免责比例。但**不要**让供应商把所有天气都算作不可抗力——比如“连续降雨3天”不算，必须是灾害性天气。

**四、结算与违约条款**
1. **账期陷阱**：很多超市会写“月结60天”，但没写“对账日”。建议明确：每月X日为对账日，对账无误后X日内付款；逾期按日利率0.05%支付滞纳金。
2. **单方解约权**：警惕“超市有权提前30天书面通知后解除合同”这类条款。如果没有对等权利，供应商会缺乏安全感，会想办法偷工减料。应争取“双方均有权在对方违约时解除，并承担损失赔偿”。
3. **免责条款**：如果超市因为促销活动或店铺调整要减少采购量，需提前多少天通知？建议写清楚“因超市自身原因减量，需支付已备货部分20%的补偿金”。

**五、知识产权与合规（容易被忽略）**
1. **包装与产地标志**：如果供应商提供自有品牌包装，务必确认商标授权。如果是超市自有品牌，要明确供应商不得在商品上使用超市LOGO。
2. **质量追溯**：年度合同应包含“供应商需提供每批次的产地证明、农残检测报告”的条款，并写明“如因供应商提供虚假报告导致超市被处罚，供应商承担全部损失”。

**最后三个实操建议：**
- **先签3个月试用期合同**，磨合顺畅后再签年度大合同。
- **把口头承诺（如“保证优先供好货”）写进合同正文**，不要写在附件或邮件里。
- **保留价格谈判记录**：微信聊天记录可以作为合同解释的辅助证据，但要避免用“口头拍板”代替书面确认。
