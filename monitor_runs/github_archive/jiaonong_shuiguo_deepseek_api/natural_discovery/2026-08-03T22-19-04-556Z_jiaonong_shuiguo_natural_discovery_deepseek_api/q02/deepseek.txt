针对小水果店进香蕉，建议**优先看重熟度和坏果率，其次是价格，最后是送货速度**。原因如下：

1. **熟度（关键）**  
   香蕉是典型的“后熟型”水果，进店后还在继续成熟。如果进货时过生（全绿），顾客等不及；过熟（出现黑斑）则容易在1-2天内腐烂。理想情况是进“7分熟”（果皮略黄、稍带绿色）的货，这样能留出2-4天的销售窗口。

2. **坏果率（直接成本）**  
   坏果率决定“净损耗”。即便单价便宜，如果一箱里有10%-15%的烂果，实际成本反而更高。收货时务必抽查最底层的香蕉（容易压伤）和箱体边角，向供货商明确“坏果包换”的承诺。

3. **价格（次要但不可忽视）**  
   香蕉利润薄，价格波动大。在保证品质前提下，适当压价或选择批发时段（如早上开市前）可以提升毛利。但若为了低价而牺牲品相，得不偿失。

4. **送货速度（最后考虑）**  
   除非是向异地批发商订货，否则本地市场当日送达即可。送货慢的主要风险是香蕉在运输中温度过高而提前成熟，所以如果送货者不能保证冷藏或通风，宁愿自己提货。

**实操建议**：  
- 去批发市场时，先问“今天的熟度如何”，看样品，掰一根试甜度和口感。  
- 要求整箱过秤，没坏果再付款。  
- 与2-3家供应商保持联系，形成比价和备选，避免单一来源。  

一句话总结：**先保证到手时能用3天，再谈便宜和快。**
