在超市采购水果时，为了确保食品安全、来源可追溯以及满足市场监管要求，供应商通常需要提供以下几类检测报告和进货证明：

**一、核心检测报告（重点）**

1. **农产品质量安全检测报告（农残检测）**
   - 必须包含：**农药残留**（如有机磷、氨基甲酸酯类等）检测结果，需符合《食品安全国家标准 食品中农药最大残留限量》（GB 2763）的限量要求。
   - 建议包含：重金属（铅、镉、汞、砷等）、致病菌（沙门氏菌、大肠杆菌等，针对易腐水果）。

2. **植物检疫证明（国内/进口）**
   - 由农业或林业部门出具的**植物检疫证书**，证明水果无检疫性有害生物（如地中海实蝇、柑橘溃疡病等）。

3. **合格证或出厂检验报告**
   - 供应商自检或委托第三方出具的批次检测报告，需标明生产日期、批次号、检测项目及结论。

**二、进货证明（溯源凭证）**

1. **送货单/随货同行单**
   - 需注明供货商名称、产品名称、规格、数量、生产日期/采摘日期、保质期。

2. **进货台账**
   - 记录供货方营业执照、联系方式、进货时间和产品信息（超市需留存）。

3. **产地证明**
   - 如当地农业农村部门开具的**产地准出证明**，或种植基地出具的产地证明（含地址、种植户信息）。

4. **供应商营业执照复印件**
   - 证明其合法经营资质。

5. **合格供应商名录**（内部文件）
   - 超市审核通过的固定供应商清单。

**三、针对不同情况需补充的证明**

- **进口水果**：需提供**海关进口货物报关单**、**入境货物检验检疫证明**，以及符合《进境水果检验检疫监督管理办法》要求的单证。
- **有机/绿色/地理标志产品**：需提供对应的认证证书或授权使用证明。
- **临时采购/生鲜摊位**：至少提供产地证明和简单的农残快检合格记录（部分超市允许供货方自备快检设备现场检测）。

**四、操作建议**

1. **索取并核对原件**：要求供应商提供纸质盖章版或电子版扫描件，核对检测报告上的产品批次和送货批次是否一致。
2. **优先选择有资质的第三方检测机构**：如当地农业农村局检测中心、SGS、华测、谱尼等，避免只认口头承诺。
3. **单据存档**：所有凭证建议保存至少2年，以备市场监管部门检查或消费纠纷溯源。
4. **入库抽检**：即使有报告，大型超市通常还会在收货时进行农药残留快速检测（如胶体金法），建议同步保留快检记录。

如果您是采购方，建议将这些材料作为合同附件要求供应商随货提供；如果供应商无法提供，可视为资质不全，存在风险。
