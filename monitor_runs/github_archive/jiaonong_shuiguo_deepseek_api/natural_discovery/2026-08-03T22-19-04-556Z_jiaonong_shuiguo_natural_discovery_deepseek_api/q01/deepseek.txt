开水果店选长期供应商，不能只看“便宜”，香蕉和菠萝又是损耗和品质波动比较大的水果，判断靠谱要抓**硬指标**。以下给你一套**可核验的筛选标准**，按重要性排序：

### 一、先看这3个“硬核实据”（最能暴露问题）

1. **要求提供“产地证明”和“农残检测报告”**  
   - 正规供应商必须能随车或随票提供（产地证、检验报告复印件）。  
   - 如果对方说“全市场都没有”，**直接换人**，这不仅是合规问题，更是日后出问题后追责的依据。

2. **试货要看“整箱”而非“选品”**  
   - 让他们拿整箱打开检查：  
     - **香蕉**：看把柄是否发黑、果身是否有“梅花点”（炭疽病）、是否过熟（表皮发黑变软）。  
     - **菠萝**：闻底部是否有酒味（发酵）、看芽眼是否凹陷发黑、果柄是否潮湿发霉。  
   - **重点：** 如果供应商只给你“挑得好的一箱”看，却说“整批都这样”，**大概率压货了**。

3. **明确“损耗/退换货”规则并写入条子**  
   - 靠谱供应商会主动承诺：  
     - 到货24小时内，因**腐烂、变质**导致的损耗按比例赔付（通常按重量算）。  
     - 如果是**运输磕碰**造成的，一般有免责条款（你要衡量你所在城市到供应商的距离）。  
   - 如果对方说“水果出门概不负责”，**别碰**，长期合作必亏。

### 二、再看“经营细节”（决定他是否稳定）

1. **要看他的“冷库”**  
   - 香蕉是呼吸跃变型水果，必须控制乙烯；菠萝也是热带水果，不能常温久放。  
   - 如果供应商没有冷库，或者冷库温度计显示超过15℃，说明他周转慢，给你的往往是存了好几天“硬熟”的货。

2. **问“进货频率”和“现在这批到的日期”**  
   - 靠谱供应商进香蕉基本**3-5天一批**，菠萝**7天一批**左右。  
   - 如果他说“这批是上周的”，你算算到店时间，基本就能预测损耗。

3. **看他对“同行”的口碑**  
   - 别只听他说，去附近水果批发市场问几个**卖散货的摊主**，他们最清楚哪个供应商压货、哪个退换爽快。  
   - 或者直接问同一条街其他水果店老板（非竞争区域也行），单子小但要长期，口碑更真实。

### 三、给你一个“检验公式”（直接照做）

> **下单时只订“一小车”试销1-2次**  
> 到货后做“入库称重+坏果称重”记录。  
> 两周内算一笔账：  
> - **实际售出率**（卖出去的钱 ÷ 进货总重量）  
> - **退换顺畅度**（出问题后对方多久回话、赔多少）  
> 如果售出率低于85%或退换拖过48小时，直接换供应商，别心疼之前的交情。

### 四、额外提醒（香蕉和菠萝各有雷区）

- **香蕉**：问对方是否提供“催熟服务”或建议。靠谱供应商会根据你店里销售速度给熟度建议（比如你要3天熟，他会给你配8成熟）。如果他说“都熟了，拿回去卖”，那你自己控制不了损耗。
- **菠萝**：问“是海南的还是台湾的”？**台湾凤梨**和**海南菠萝**价格差一倍，别被拿“台农17号”挂羊头卖狗肉。要包装箱上的产地标签，没有标签的按散货压价。

**最后一句总结**：
靠谱供应商 = **敢开箱验货 + 敢承诺损耗 + 有冷库 + 按规矩退换**。  
如果你的供应商只能做到其中2条，友情提醒：换他。
