在酒店采购水果盘原料时，为了确保出品质量、食品安全以及视觉呈现，供应商需要明确保证以下**规格标准**和**外观标准**。建议将以下要求写入采购合同或验收标准中：

### 一、规格标准（尺寸、重量、成熟度）

1. **成熟度统一**：同一批次水果的成熟度应一致，不能出现生熟混搭。例如，西瓜需达到“沙瓤”或“脆沙”标准，香蕉要求表皮呈黄色、无青头，芒果需软硬适中。
2. **果实重量/周长**：针对特定水果（如苹果、橙子、火龙果）需规定单果重量范围。例如，苹果单果不低于180克，橙子直径不小于7厘米，防止以次充好。
3. **果肉饱满度**：切开后应无空心、无萎缩，果肉与果皮贴合紧实。
4. **可食用率**：去核、去皮、去蒂后的净果肉占比应达到特定比例（例如带皮水果可食用率≥85%）。

### 二、外观标准（颜色、表面、形状）

1. **色泽自然均匀**：颜色必须符合品种特征，无异常褪色或人工染色痕迹。
   - 例如：葡萄需呈紫黑色或青绿色且粒粒饱满；哈密瓜网纹清晰、底色金黄。
2. **表面无瑕疵**：
   - **无机械伤**：禁止有磕碰、压伤、划伤、破皮。
   - **无病斑/虫眼**：不得有霉变、腐烂、黑斑或虫蛀孔洞。
   - **无碰落物**：叶类水果（如草莓）应带新鲜果蒂。
3. **形状端正**：果实形状符合品种典型特征，忌畸形果（如双头草莓、缺口苹果）。
4. **表面洁净**：无残留农药、泥土、蜡质（非食用蜡）或包装残留物。

### 三、卫生与安全附加标准

- **无化学残留**：供应商需提供当批次的农残检测报告，或承诺符合GB 2763国家标准。
- **无附着异物**：水果表面不得有昆虫、毛发、粉尘等。
- **包装规范**：内包装需为食品级材料，外箱需有溯源信息（产地、采摘日期）。

### 四、验收常用判断方法

| 项目 | 简易判断方法 |
|------|-------------|
| 新鲜度 | 果柄切口无失水干枯，叶片（如有）翠绿挺括 |
| 脆度 | 轻按果身，回弹迅速且无软榻区 |
| 内部质量 | 抽样切开1-2个，检查果核无霉变、果肉无褐变 |
| 成熟度 | 针对西瓜敲击听“卟卟”实声，榴莲闻气味是否浓郁 |

### 建议执行动作

1. **制定拒收条款**：明确“单批次外观不合格率超过5%可整批退货”。
2. **提供标准样品**：请供应商提供一份“标准品”封样，比对验收。
3. **冷藏车运输**：夏季确保全程冷链（0-4℃），防止途中升温导致外观变差。

如果需要，可提供一份可打印的《水果盘原料验收明细表》模板。
