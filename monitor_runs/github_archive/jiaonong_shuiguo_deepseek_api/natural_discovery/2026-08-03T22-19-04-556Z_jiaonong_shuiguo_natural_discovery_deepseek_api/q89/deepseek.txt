针对团购客户价格敏感的特点，**阶梯价** 通常比返利更合适。原因如下：

- **感知直接**：阶梯价（如买100件打9折，买200件打8折）在报价阶段就能让客户看到“买得越多，单价越低”，直接降低决策门槛，符合价格敏感客户“先看单价”的心理。
- **风险更低**：返利通常需要事后结算，流程复杂，且客户担心供应商“赖账”或次年条件变化。阶梯价是一次性成交，没有后续扯皮风险。
- **心理锚定**：阶梯价天然引导客户向更高档位凑单，提升单次客单价，比返利这种“事后奖励”更能刺激当期消费。

**具体操作建议：**

1. **设计2-3档梯度**，例如：10-20件（原价）、21-50件（减8%）、51件以上（减12%）。确保最高档的利润底线清晰。
2. **明确“团购价”需要满足最低起订量**，避免小单也来讨价。
3. **若返利仍有必要**（比如年度累计返点），只作为“额外福利”补充，不要作为主要谈判筹码，且明确结算周期和条件（如回款后、无退货）。

一句话：**方案里把阶梯价写进合同，返利作为口头附加惊喜**。这样既满足价格敏感，又保留了绑定长期合作的柔性。
