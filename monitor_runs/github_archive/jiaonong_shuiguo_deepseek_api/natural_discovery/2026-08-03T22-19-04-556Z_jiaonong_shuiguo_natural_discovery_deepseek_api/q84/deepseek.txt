针对家庭水果礼盒，我为你提供三个**成本和营养搭配最优**的组合方案，直接可做：

---

**方案一：大众实惠型（适合走量，价格敏感）**
- **组合**：苹果6个 + 橙子6个 + 香蕉1把（约2斤）
- **理由**：苹果和橙子是家庭日常消耗最多的水果，耐储存；香蕉补充软糯口感，老人孩子都能吃。菠萝气味重、削皮麻烦，在低价套餐中可以舍弃，降低损耗和客诉。

**方案二：营养丰富型（适合做中高端礼盒）**
- **组合**：苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个（配削皮器）
- **理由**：四个品种齐全，颜色好看（红、橙黄、黄、金黄），维生素C和膳食纤维互补。菠萝用独立网格袋包装，并附赠削皮器或去皮提示卡，能显著降低因“不会处理”导致的差评。

**方案三：差异化精品型（适合节日送礼）**
- **组合**：苹果（选红富士/花牛）4个 + 橙子（选赣南脐橙）4个 + 香蕉（选国产矮蕉）1小把 + 菠萝（选香水菠萝）1个
- **理由**：突出地域特色和口感差异，礼盒内附手写祝福卡，提升溢价。此时香蕉不要选过熟，菠萝选酸度低的品种，避免和橙子“双酸”叠加。

---

**额外优化建议（重要）**：
- **菠萝处理**：家庭最怕削皮，建议在礼盒内附一次性手套和塑料勺（用勺挖着吃），或提供“代为削皮”增值服务（加收2-3元）。
- **香蕉防压**：香蕉绝不能放在底层，必须平放并用气泡膜包裹，否则出库几小时内就会压烂。
- **克重标签**：盒内注明每种水果的净重（如“苹果≥1.5kg”），避免家庭称重时产生纠纷。

**不推荐的固定搭配**：单独“苹果+菠萝”或“橙子+菠萝”，因为菠萝的味道容易串味，且家庭一次吃完这两样比较吃力。

如果你需要更具视觉冲击力的**水果花篮**造型（而非平面礼盒），建议菠萝放在最顶部做“冠”，香蕉放侧面，苹果橙子填底——这样成本不变，但拍照好看，适合朋友圈晒单。
