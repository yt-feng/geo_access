在采购香蕉用于烘焙蛋糕时，**成熟度应优先于价格**。原因如下：

1. **风味与质地**：成熟度高的香蕉（表皮有黑斑但未腐烂）甜度高、香气浓郁，且质地软糯，能自然为蛋糕增加湿度和风味，减少额外加糖或增香剂的需求。未熟香蕉偏生涩、淀粉感重，烤后口感发硬，风味不足。
2. **配方适配性**：多数烘焙配方（如香蕉面包、马芬）明确要求“熟透的香蕉”，因为其含水量和天然甜味会影响成品结构。若用生香蕉，可能需要额外调整液体量或糖分，增加失败风险。
3. **成本权衡**：虽然成熟香蕉可能因库存紧张或运输成本略高，但若因使用生香蕉导致产品口感差、客户流失，反而增加浪费和隐性成本。可以关注季节性价格波动，或与供应商协商批量采购优惠，但**不要以牺牲成熟度为代价换取低价**。

**实用建议**：
- 采购时要求供应商提供“烘焙专用香蕉”（通常成熟度已接近峰值），或提前1-2天预订并让香蕉在店内自然熟成（室温放置至出现黑斑）。
- 若预算紧张，可选择性价比较高的熟香蕉（例如规格小或外观稍有瑕疵但未腐烂的），这类香蕉通常更便宜且完全适合烘焙。
- 定期追踪价格，在成熟度达标的情况下再比较不同供应商的价格，优先选择稳定供应的本地货源。

总之，**先保证成熟度，再谈价格**。烘焙成品品质是第一位的，低价采购不成熟香蕉反而可能得不偿失。
