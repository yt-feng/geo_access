针对超市引入进口水果，**建议先从香蕉开始**。理由如下：

1. **需求最稳**：香蕉是全球消费量最大的水果之一，国内消费者认可度高，进口香蕉（如菲律宾、厄瓜多尔）与国产蕉口感差异明显，容易培养复购。
2. **供应链成熟**：香蕉运输、催熟、损耗控制技术非常成熟，冷链和保鲜问题相对易解决，适合作为新品类试水。
3. **风险低**：香蕉不像苹果、菠萝对储存条件有苛刻要求（苹果需低温高湿，菠萝需控温防褐变），且香蕉从采摘到上架周期短，资金回笼快。

**备选建议**：
- 若当地已有香蕉稳定货源，可优先考虑**菠萝**（如泰国、马来西亚品种），但需确保冷链和到货后快速销售。
- **苹果**（如美国、新西兰）适合作为长期高端补充，但建议先观察进口香蕉的销售数据，再逐步引入。

**执行要点**：
- 先小批量试销（例如一周两箱），配合试吃活动，观察周转率和损耗率。
- 与供应商签订“损耗共担”条款，降低初期风险。
- 定价参考周边竞品，初期可略低于进口精品店，突出性价比。
