水果店做周末促销时，供应商通常是可以提供支持的，但这取决于你的进货量、合作深度以及供应商的利润空间。以下是具体的可能性及建议：

**1. 价格支持（最常见）**
- **可行情况**：如果你和供应商有长期稳定合作，采购量大（比如按箱或按车进货），供应商通常愿意在周末促销时让利2%-10%。你可以直接要求“这次周末我要做活动，能不能在原价上再给个几毛的优惠？”
- **不建议直接要求**：如果只是临时少量拿货，供应商利润薄，几乎不会让价。

**2. 物料支持（多用印有品牌名称的物料）**
- **常见支持**：供应商一般会提供**促销海报、价签、货架贴纸、水果箱宣传单**，上面印有他们品牌的logo和产品信息。这相当于免费帮你打广告，他们也乐意。
- **不常见**：免费提供防撞棉、泡沫网套、专用礼品袋这类成本较高的物料，一般需要你大批量进货才有。

**3. 其他支持形式**
- **试吃样品**：供应商可能会提供一箱小样给你做现场试吃，但通常要求你展示他们的品牌。
- **联合促销**：如果供应商有新品或库存压力大的品种，可能愿意和你一起搞“买一送一”或“第二件半价”，双方分摊成本。

**4. 怎么谈才能拿到最多支持？**
- **提前预约**：周四、周五提前沟通，周末前供应商更有空库存或调货，谈判空间大。
- **用数量说话**：告诉他“这周末我们小区活动，预计能走X箱”，如果数量大，对方会主动降价或送物料。
- **多品牌对比**：表示“隔壁家的供应商给了9折还送海报”，通常能激发对方让利。

**5. 注意点**
- 不要只问“有没有支持”，要具体问“**价格降多少**”和“**物料送什么**”，模糊提问容易被敷衍。
- 拿到支持后，促销时最好在店内张贴供应商的logo，维护关系，下次合作更容易。

**总结**：只要你进货量够，或合作固定，供应商给价格和物料支持是常态；如果拿不到优惠，先检查自己是否能承诺更多销量，或者换一家更灵活的供应商试试。
