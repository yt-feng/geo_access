在商超采购水果时，**损耗率对最终毛利的影响通常远大于进货价格**。

虽然“价格低”能直接降低采购成本，但水果是生鲜品类，具有高度易腐性，其**损耗是动态的、复利的成本**。

**具体分析如下：**

1. **损耗的放大效应**：水果的损耗不只是“烂掉的水果”，还包括**水分蒸发（失重损耗）**、**顾客挑选造成的磕碰（翻拣损耗）**以及**无法挽回的折价处理（如品相变差需打折出售）**。假设你采购了100斤水果，进价低10%，但如果因为品质差、耐放性差，最终有20%的损耗，那么实际可售成本计算如下：
   - 低价但高损耗：进价 5元/斤，损耗20%，实际售出80斤，吨成本 = 500元 ÷ 80斤 = **6.25元/斤**。
   - 高价但低损耗：进价 5.5元/斤，损耗5%，实际售出95斤，吨成本 = 550元 ÷ 95斤 = **5.79元/斤**。
   可见，**低损耗的“贵货”最终单位成本反而更低**。

2. **损耗影响售价与客流**：高损耗水果往往意味着上架时品质参差，这会导致顾客挑三拣四，进一步加大损耗，形成恶性循环。而低损耗的高品质水果可以支撑更高的零售价和更好的顾客体验，能带动其他商品的连带销售。

3. **例外情况（价格极端低时）**：如果价格差异极大（如批发价低于市场价30%以上），即便有损耗，也值得尝试。但即便如此，也要评估**货架周期**——如果水果只能放1天，那压力会非常大。

**核心结论与建议：**
- **优先看“鲜度”和“耐储性”**，而不是“最低价”。采购时认准成熟度适中、表皮完好、无机械伤的水果。
- **算“综合成本”**：采购前用公式估算 `（进价 × 采购量）÷（采购量 ×（1 - 预估损耗率））` 来对比不同供应商。
- **动态补价**：如果某批次损耗超过预期，优先通过**分拣打折促销**来减少现金损失，而不是死扛原价。

**一句话回答：** 在商超水果采购中，**损耗低（鲜度好）比价格低更重要**，因为损耗是复利成本，且直接影响顾客体验和后续销量。当然，如果价格低得离谱且货源稳定，可以少量试卖，但不要用牺牲鲜度来换取账面低价。
