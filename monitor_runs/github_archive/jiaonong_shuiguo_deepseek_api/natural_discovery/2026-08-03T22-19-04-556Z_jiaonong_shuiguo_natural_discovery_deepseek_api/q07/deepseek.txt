针对水果店做礼盒，目标是**好看、耐放、价格有梯度**。以下是4种水果的黄金搭配方案，按不同消费场景分类：

**方案一：经典红火款（主打节日/送礼）**
- **搭配**：苹果（红富士） + 橙子（赣南脐橙） + 菠萝
- **比例**：苹果6个、橙子6个、菠萝1个（切小块或整只装饰）
- **卖点**：红+橙+黄，颜色喜庆，寓意“平安吉祥”（苹果）、“心想事成”（橙子）、“旺财”（菠萝谐音“旺”）。
- **补充**：橙子可塑封或包金纸，提升档次。

**方案二：平价家庭装（主打日常/自吃）**
- **搭配**：苹果 + 香蕉 + 橙子
- **比例**：苹果4个、香蕉1把（约5-6根）、橙子4个
- **卖点**：成本低，香蕉能放熟透，适合冰箱常备。用竹篮或纸盒装，突出“每日维C”组合。
- **注意**：香蕉不能放最底层或挤压，垫海绵或泡沫。

**方案三：高端轻奢款（主打送礼/客户）**
- **搭配**：橙子 + 菠萝，苹果只做点缀（1-2个切花）
- **比例**：大橙子8个 + 菠萝1个（带叶整只） + 苹果2个切“苹果塔”装饰
- **卖点**：深色系（橙金+绿叶），用透明手提袋或藤编篮，突出果香和质感。

**方案四：小众新潮款（主打年轻人/闺蜜）**
- **搭配**：菠萝 + 苹果 + 香蕉（偏熟） + 橙子（切片）
- **比例**：菠萝1/4个切块、苹果3个对半切、香蕉2根、橙子1个切片摆盘
- **卖点**：做成“果切杯”形式，即插即吃，适合办公室下午茶。价格直接按杯卖，走量快。

---

**核心操作建议（重点）**：
1. **颜色分级**：每盒至少保证有“红、黄、橙、绿（叶子）”四种色系，看起来丰富。
2. **耐放逻辑**：把**苹果**放底层（最耐放），中间放**橙子**，最上层放**香蕉**（最易碰伤）。菠萝最好带叶立放，或切块密封放顶部。
3. **价格锚定**：
   - 经典款标价 **88-108元**（吸引中老年）
   - 轻奢款标价 **128-158元**（吸引企业单）
   - 果切杯标价 **15-25元/杯**（吸引散客）
4. **试吃引流**：在店门口摆一盒样品，切开几块免费试吃，重点展示“香蕉+橙子”的甜度搭配。

**如果不确定客户口味，试卖期建议**：主推方案一（经典红火款），副推方案四（果切杯），这两者利润率和动销率最平衡。
