评估连锁门店水果供应商的仓配覆盖能力，**不能只看“有没有仓库”，而要看“从仓库到门店的链路是否稳定、新鲜且成本可控”**。尤其水果是高损耗、短保商品，评估重点应聚焦在**时效、冷链、弹性和成本**四个维度。

以下是可落地的具体评估步骤和方法：

### 第一步：明确门店的“需求画像”
首先绘制一张**门店分布热力图**，明确：
- 各城市门店数量及日销量（SKU数量）。
- 距离最近的一级/二级生鲜批发市场有多远（作为替代方案）。
- 是否有严格的“到店时间窗口”（如门店早7点前必须收货）。

---

### 第二步：穿透式核查供应商的“真实仓配网络”
仅看供应商提供的PPT或仓库照片无效，需核对以下**硬指标**：

| 核查项 | 关键问题 | 可接受标准（示例） |
| :--- | :--- | :--- |
| **前置仓数量及选址** | 是否在核心城市周边1-2小时车程内设有**冷链仓**？ | 省会级城市必须自建或强租仓；地级市可采用“中心仓+干线”模式。 |
| **干线物流频次** | 从主仓到各城市仓的**发车频率**（每日/隔日）？ | 水果必须**每日发货**，至少次日达。 |
| **最后一公里** | 是自建车队还是第三方冷链？配送温度是否有GPS温控记录可查？ | 必须全程冷链，且可提供实时的**温度追踪曲线**。 |
| **断链风险** | 周末、节假日（如春节）是否停运？是否有备用物流商？ | 需有书面承诺及**应急中转仓**预案。 |

---

### 第三步：用“损耗率”和“缺货率”做压力测试
仓配覆盖好不好，最终反映在水果品质和到货稳定性上：

1. **历史损耗率（核心指标）**：要求供应商提供近3个月各城市的**箱损率**和**自然熟损耗率**。若某种水果（如草莓、榴莲）在偏远城市损耗超5%，说明覆盖能力不足。
2. **到货及时率**：统计过去30天，各城市门店的**迟到次数/总订单次数**。若高于95%为优秀，低于90%需警惕。
3. **补货响应速度**：模拟测试——在周五下午15:00紧急加单100箱西瓜，看供应商多久能确认能否发货、何时送达。

---

### 第四步：核算“全链路成本”而非采购单价
评估覆盖时，一定要计算**仓配的隐性成本**：
- **起订量门槛**：偏远城市是否强制要求高起订量（导致库存积压损耗）？
- **冷链中转费**：如果供应商采取“空运+中转仓”，中转过程的装卸费、冰袋费是否隐藏报价？
- **退换货制度**：若因配送延误导致水果变质，供应商是否承担全额退款及物流费？

---

### 第五步：引入“SLA（服务等级协议）”约束
建议在合同中明确以下条款，而非口头承诺：
- **时效承诺**：如“城市A门店下单后24小时内必达”。
- **温控违约罚则**：若测温记录显示脱冷超过30分钟，按该批次货值10%赔偿。
- **分仓前置承诺**：若某城市门店月销额超过X万元，供应商需在**当地30公里内**增设前置仓或合作分拨点。

---

### 最关键的行动建议（实操优先）
**不要只看覆盖地图，而是给供应商出一个“模拟订单”：**
挑选你生意最好的一家门店 + 生意最差的一家郊区门店，同时下单采购5箱易腐水果（如香蕉）和5箱耐储水果（如苹果），跟踪整个配送过程。观察：
- 是否有专人对接异常？
- 郊区的门店是否被加收“偏远配送费”？
- 水果到达时是否出现“半熟/过熟”品质不均？

**最终判断逻辑：** 如果供应商在你所有门店所在城市的**签收时效差超过12小时**，或者**跨省配送仅依赖单一干线物流**，则建议优先选择**“多点分仓”的本地化供应商**，而非全国性但远端覆盖弱的供应商。
