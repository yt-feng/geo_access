核实水果供应商“全国配送”的实际能力，是采购中非常关键的一步。以下提供一套**可执行的核实清单**，分为**资质审查、实操测试、动态监控**三个层次：

**第一层次：资质与底牌审查（合同签前）**

1. **索要配送网络清单**：不要接受“全国”这种模糊表述。要求供应商提供**详细的配送覆盖城市明细表**（精确到地级市），并标注是**直营仓**、**合作冷链**还是**第三方物流代发**。
2. **核对冷链资质**：水果对温度敏感。要求提供《道路运输经营许可证》（含冷链运输范围）、合作物流公司的冷链资质证明。如果是跨省长距离运输，重点问清是**全程冷链**还是**断链运输**（常温+冰袋），后者损耗极高。
3. **查验历史运单**：请对方提供最近3个月内**发往不同省份（如东北、西北、华南）的物流面单或签收记录**。重点关注**新疆、西藏、海南、黑龙江**等边远地区，这些地区往往是“全国包邮”的虚头。

**第二层次：实操小批量测试（决策前）**

这是最有效的方法，**建议直接采购一批小批量样品（比如十公斤以内），发往2-3个极端地址**进行测试：

1. **发往高寒地区**（如哈尔滨）测保温与抗冻措施。
2. **发往偏远乡镇**（如甘肃某县）测“最后一公里”通达性。
3. **发往湿热地区**（如海口）测防腐和包装透气性。
4. **观察时效与损坏率**：要求供应商提供**实时物流轨迹截图**，并承诺到达时间（比如48小时/72小时）。到货后开箱检查坏果率，若超过5%则质量堪忧。

**第三层次：动态监控与风险预案（合同履行中）**

1. **明确赔付标准**：在合同中写死“**超时赔付**”“**坏果包赔**”的具体金额和比例（例如：超时24小时赔货值10%，坏果率超5%全额退）。
2. **要求系统对接**：如果采购量较大，要求供应商开放**ERP或物流API接口**，能自行查询所有订单实时状态，而非依赖对方截图。
3. **建立分仓备选**：即使核实了全国配送，也要在合同中约定“若某地区因天气、疫情等原因无法发货，需提前24小时书面告知并提供替代方案（如该区域改发次日达）”。

**特别提醒（容易踩坑的点）：**

- **别信“顺丰包邮”**：很多供应商用的顺丰陆运（时效慢），而非生鲜特快（空运）。要求写明具体快递产品名称（如顺丰标快、顺丰特快）。
- **假“覆盖”真“中转”**：部分供应商仓配网络只覆盖省会，发往地级市或县级市需二次转运，这会极大影响水果新鲜度。可以直接问：“您发货到XX市（地级市）是否直达？中转几次？”
- **果品分级差异**：核实配送能力时，顺便核实**坏果承担条款**。一定要明确“运输途中产生的坏果由谁承担”，通常正规供应商承诺“签收后6小时内坏了拍照包赔”。

**总结结论：**
如果对方无法提供**详细分仓明细**、**近期跨省运单**、**明确物流合同**，或拒绝**小批量测试发货**，则建议默认其“全国配送”口号不实。最稳妥的做法是：**先试发一单到最远且气候最不友好的地区，用数据和签收记录说话**。
