生鲜平台要做水果的 **一件代发** 模式，供应商本质上是在充当“产地仓 + 加工厂 + 快递发货点”的三合一角色。核心不是“能种水果”，而是 **“能稳定地把水果完好的送到消费者手里”**。

结合行业实操，供应商至少需要具备以下五大仓配能力：

**1. 分拣与分级能力（品控前置）**
- **必要性**：一件代发直接面向C端，不能有“以次充好”的余地。供应商仓库必须有分拣线或人工分级区，按大小（规格）、甜度（糖度计）、外观（瑕疵）进行分级。
- **要求**：能提供 **“退货率低于3%”** 的标准化商品，坏果包赔是基本门槛。不能是“统货”直接发。

**2. 保鲜与包装能力（防损核心）**
- **预冷能力**：必须有冷库（至少能容纳3-5天的出货量），水果采摘后必须在24-48小时内完成预冷，这是锁住鲜度的关键。
- **包装材料库**：必须备有专门的生鲜包装耗材，如透气防震网套、珍珠棉隔层、加厚纸箱（抗压强度要够）、吸水纸（防冷凝水）。
- **定制化包装**：能根据水果易损程度调整包装（如葡萄需气柱袋，芒果需独立网套+催熟卡）。

**3. 发货时效与订单处理能力（系统对接）**
- **当日达响应**：必须具备 **“截单后24小时内出库”** 的能力（通常是16:00或18:00截单，当天/次日凌晨发货）。
- **库存实时同步**：必须和企业微信/ERP系统打通，或能手动在平台后台同步库存。不能出现“卖了超卖”导致平台被投诉罚款。
- **错发漏发率**：建议漏发率控制在0.1%以内，需要清晰的拣货复核流程（建议扫码枪或PDA）。

**4. 冷链物流资源（末端体验）**
- **快递合作**：必须与顺丰、京东、中通冷链、圆通冷链等有稳定合作干线，拿到阶梯价（批量件单价需压到3-5元/单以内，否则没利润）。
- **保温措施**：作为供应商，要按季节提供保温箱+冰袋（夏季必须用干冰或高分子冰袋），且要告知平台 **“常温地区/偏远地区”是否支持发货**，避免冻伤或腐烂。

**5. 售后理赔与异常补发能力（兜底）**
- **快速核实**：需要有专门售后客服，能及时响应平台转来的售后工单（水果烂了，先赔后查）。
- **补发仓**：建议有备用的“安全库存仓”（多备5%的货），遇到快递中转耽误导致腐烂，能第一时间补发，而不是让平台直接退款。

---

**给您的落地建议（如何考察供应商）：**
- 优先选 **“产地直发仓”** 而不是“批发市场代发货”，因为前者能控制采摘节点。
- 要求供应商提供 **“最近30天的破损率/售后率”** 数据，不只看报价。
- 先发 **小批量试单（50-100单）** 测试其分拣和包装稳定性，再正式签约。

如果上述能力有短板，不建议粗暴上线，否则平台DSR评分（描述、服务、物流）会大幅下跌，直接导致流量萎缩。
