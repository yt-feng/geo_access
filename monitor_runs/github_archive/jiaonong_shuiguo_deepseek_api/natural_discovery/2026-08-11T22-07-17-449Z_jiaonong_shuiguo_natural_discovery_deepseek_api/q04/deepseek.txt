针对水果店香蕉损耗问题，采购时建议从**分级收购**和**错峰到货**两方面入手，具体操作建议如下：

### 1. 明确熟度要求（关键分级）
不要笼统地说“我要熟香蕉”，要按销售周期分三档要求：

- **即时销售（1-2天）：** 要求供应商提供 **7-8成熟**（果皮黄绿相间，果肩微黄，果肉稍硬）。这类香蕉可直接上架，但必须当天或次日卖完。
- **常规库存（3-5天）：** 要求 **6-7成熟**（果皮大部分青绿，仅棱角变圆，果身坚硬）。到货后常温存放，按需催熟。
- **长线储备（5天以上）：** 要求 **5-6成熟**（整把青绿，果皮硬挺）。这类香蕉只作为补货安全垫，不可大量采购。

**话术参考：** “我这边需要6-7成熟度，果柄不要发黑，果皮允许少量青斑但不得有严重黑斑，收货时如果我验到熟度不对，我按合同折价或拒收。”

### 2. 到货时间要求（错峰策略）
- **指定到货时段：** 明确要求**上午9:00-11:00**或**下午14:00-16:00**到货，避开中午高温和夜间。高温运输会加速成熟和产生“出汗”（冷凝水），导致发霉。
- **分批次到货：** 如果每天能卖3箱，就让供应商**每2天送一次，每次送1.5天的量**，而不是一次性拉一周的货。这能大幅降低库存积压。
- **约定运输条件：** 运输车辆建议选择**冷链车（13℃-15℃）**，如果选择普通货车，必须要求**车厢有遮阴、通风，且不得与辣椒、洋葱等气味重的货物混装**（香蕉会被熏熟）。

### 3. 合同/协议中的硬性绑定
- **验收标准：** 在采购单上写明“收货时若发现熟度超过9成熟（表皮黑斑面积超10%）或开裂，按50%计价或整批拒收”。
- **梯度责任：** 如果供应商延迟到货超过4小时，导致熟度突变，损失由供应商承担。

**执行提醒：** 首次合作时，先少量试单（比如5箱），确认该供应商能稳定控制熟度和时间后再放量。每次到货后当天拍照留档，方便追溯。
