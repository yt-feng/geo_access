选择适合批量配送的水果供应商，可以从以下几个关键维度来评估，避免踩坑：

**一、 核心筛选标准（按优先级）**

1.  **配送能力与时效（最关键）**
    -   必须要求“次日达”或“当日达”。下午茶通常有固定时间（如15:00-16:00），明确要求供应商在指定时间段内送达。
    -   询问**断货补货机制**：如果当天有水果损坏或不够，能否在1小时内紧急补送？

2.  **损耗与售后标准（防止扯皮）**
    -   批量水果不可避免有碰伤。事先约定**“损耗率标准”**（如超过5%的部分由供应商承担）。
    -   明确赔付方式：是直接退款，还是下次配送时免费补足？最好有合同或书面记录。

3.  **水果新鲜度与成熟度控制**
    -   **不要选全熟果**：批量采购建议选择**7-8成熟**的水果，这样在公司放置半天到一天刚好可食，不会因过熟而烂掉。
    -   要求供应商提供**当日到货的检测报告**（尤其是有机、农残检测），长期合作可要求每月提供一次。

4.  **品类调整灵活性**
    -   下午茶水果建议选择**易分食、不脏手**的品类（如：圣女果、蓝莓、青提、切好的哈密瓜/西瓜拼盘）。
    -   询问是否支持**每周更换菜单**，以及能否根据季节性水果（如杨梅、荔枝）灵活调整，避免常年单一。

**二、 具体找供应商的渠道类型对比**

| 类型 | 优点 | 缺点 | 适合公司 |
|------|------|------|----------|
| **本地水果批发市场档口** | 价格最低，可现场看货 | 需自己承担运费、搬运，品质仅限当日 | 公司有专门行政或司机 |
| **区域生鲜电商B端平台**（如美菜、快驴等） | 线上下单，次日达，售后有系统记录 | 品质波动大，切配果盘可能不新鲜 | 小型公司或临时需求 |
| **专业水果连锁定制**（如百果园企业版等） | 品质稳定，切配干净，售后好 | 单价略高，起订量有门槛 | 注重员工体验的中大型公司 |

**三、 实操避坑清单（采购前必问）**

-   **问清“克重”而非“个数”**：防止供应商用个头小的果子充数。例如：规定“每盒蓝莓净重125g”而不是“一盒蓝莓”。
-   **要求“独立包装”优先**：如果是整箱配送，务必要求内衬泡沫或气柱，否则挤压损耗极高。
-   **试单测试**：先下**1-2次小批量订单**（比如20人份），检验实际送达时间、水果新鲜度、客服响应速度，再签长期合同。
-   **合同备注“节假日无休”**：如果下午茶逢节假日或周末，务必确认供应商是否配送，以及是否加收“节假日服务费”。

**四、 推荐最优策略**

建议优先联系**本地的大型水果批发市场的“配送档口”**（而非零售店）。因为：
1.  他们通常有自己的冷库，可以提前一天备货。
2.  价格比品牌连锁低15%-30%。
3.  现场洽谈时，**直接要求对方开一张“配送路线图”**，如果他们的配送范围覆盖你们公司所在的园区，说明效率有保障。

**总结一句话**：不要只看单价，签合同时把“损耗率”和“补货时限”写清楚，才是省钱省心的关键。
