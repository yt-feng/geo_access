大型超市对水果供应商有非常严格的要求，主要分为**食品安全**和**物流**两大维度。以下是最核心、必须具备的能力：

### 一、食品安全能力（生命线）

1.  **资质与合规认证**
    -   **必备资质**：营业执照、食品经营许可证、农产品合格证明。
    -   **体系认证**：通过ISO9001（质量）、ISO22000或HACCP（食品安全）体系认证。对于有机水果销售，需持有有机认证证书。

2.  **源头管理与追溯**
    -   与正规种植基地签订合同，记录农事操作（用肥、用药）完整档案。
    -   具备**全批次可追溯**能力：从采收、分拣、包装、出厂，每一环节有二维码或条码，扫码可查产地、农户、检测报告。

3.  **农残与质量检测**
    -   必须配备**快速农残检测设备**，每批次出货前自检。
    -   能提供第三方权威机构（如SGS、华测）的定期全项检测报告（针对不同品项）。

4.  **仓储与卫生控制**
    -   分拣车间有防虫、防鼠、防尘设施，符合卫生标准。
    -   区分生熟、干湿区域，保持低温或恒温，防止交叉污染。

---

### 二、物流能力（交付保障）

1.  **冷链全链条覆盖**
    -   **冷藏车**：具备温控记录仪（GPS温度监控），运输途中温度稳定（如香蕉13-15℃、苹果0-4℃）。
    -   **冷库设施**：拥有独立的预冷库和周转冷库，到店前能即时降温。

2.  **高效分拣与包装**
    -   具备自动化或半自动化的分拣线，按超市标准进行分级（大小、甜度、外观）。
    -   包装材料符合食品级标准，透气性好，能减少运输损耗。

3.  **准时与高频配送**
    -   拥有**次日达或当日达**的核心城区配送网络，满足超市每日订单。
    -   具备**门店直配能力**，能将货物直接送至各个超市收货区，而非只送至总仓。

4.  **损耗控制与弹性应对**
    -   能在运输中控制损耗率（通常要求低于3%-5%）。
    -   有应对恶劣天气、节假日爆单的备用车辆和仓储方案。

---

### 实操建议（超市采购经理视角）

-   **验厂**：要求供应商提供冷链车内的温度记录仪数据，并随机抽检到货车辆的货厢温度。
-   **看报告**：要求每批次随货附上**当日或前一日**的农残快检报告。
-   **签订对赌协议**：在合同中明确损耗率上限、到货准点率（低于99%扣款）以及食品安全连带责任条款。

**总结**：简单来说，必须做到 **“从田间到货架”全程看得见的品控** 和 **“温不断链”的全程冷链**。否则，即使水果品质好，也无法进入大型超市的供应链体系。
