水果店采购香蕉时，如果一箱里面大小不一致，确实会对销售产生一定影响。影响程度取决于你的销售模式和目标客户群。以下是具体分析和应对建议：

### 1. 可能带来的负面影响（主要风险）
- **顾客感官差**：顾客购买时，如果看到箱内香蕉大小参差不齐，容易觉得品质不均，影响购买欲（尤其是整箱购买或高端顾客）。
- **定价困扰**：如果按“斤”卖，大小差异不会直接导致亏损，但按“个”卖则可能出现大果贵、小果便宜，容易引发顾客抱怨或挑拣。
- **损耗增加**：大小差异可能意味着成熟度不一，小果可能先熟后烂，或大果后熟导致积压，增加鲜果损耗。
- **库存管理复杂**：不同大小的香蕉出库时可能需要分类标注，增加员工工时。

### 2. 哪些情况下影响不大或可以接受
- **批发走量**：如果客户是餐饮店、食堂或榨汁店，他们更关注总价和重量，对大小不敏感，影响较小。
- **低端走量路线**：如果店铺主打性价比，顾客对大小容忍度较高。
- **整箱出售**：如果是整箱卖给熟客或线上团购，只要价格合理，多数人不会拆开逐根挑剔。

### 3. 实际采购和应对策略
- **采购时明确规格**：在进货单上注明“大果（每斤3-4根）”或“统货”，并与批发商约定混装比例（如大果占比≥70%），避免全部是小果。
- **分拣销售**：到货后，如果差异明显，花10分钟按大小分成两堆（或两箱），分别标价（大果稍贵，小果稍便宜），既满足不同顾客需求，也减少挑拣麻烦。
- **宣传话术**：如果是统货，可以标注“新鲜到货，天然大小不一，自选更实惠”，主动降低顾客预期。
- **把控供应商**：如果长期合作，可以要求供应商每次发货前拍视频抽检，或下次换一家品控更稳定的供应商。

### 4. 建议底线
- 原则上不建议采购“大小差异极大”（比如一半是拇指粗细的未熟小块）的香蕉，这类货很难卖，容易造成亏损。
- 如果价格明显低于市场价，可以少量试采，但要预估损耗比（比如可能多损失5%-10%）。

---

**一句话总结**：大小不一致不会直接导致卖不掉，但会影响顾客体验和损耗率。如果价格合适，可以采购；但如果利润薄，且你是零售单卖，建议要么分拣售卖，要么要求供应商提供均匀度更好的货。
