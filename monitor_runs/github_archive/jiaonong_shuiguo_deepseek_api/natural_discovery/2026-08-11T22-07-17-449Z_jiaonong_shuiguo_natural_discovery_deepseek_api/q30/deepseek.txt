针对超市水果到货后品相不佳的问题，售后流程的约定应兼顾**快速核验**与**权责清晰**，同时避免因生鲜易腐特性产生的扯皮。以下是一套可执行的流程建议，供直接参考或修改：

---

### 一、售后流程框架（五步法）

**第一步：收货即验收，拍照留证（0-2小时内）**
- **操作：** 货到后，指定专人（如店长或收货员）在**2小时内**开箱核对。重点检查外观、颜色、软化、破损、霉变等。
- **留证要求：** 对整箱及异常部位拍照或录像，包含“货物全貌+异常特写+时间水印（如用相机APP）”。
- **关键节点：** 若超过2小时未提出，视为“常规品相”验收通过（但后续出现变质问题另有约定）。

**第二步：分类定责（明确责任归属）**
- **运输途中损伤（如挤压、磕碰、包装破损）：** 供应商负责。
- **到货时就已变质（如发霉、内部腐坏）：** 供应商负责。
- **储存不当造成（如冷库温度异常后变质）：** 超市自担。
- **轻微瑕疵（如个别斑点、大小不均，但可销售）：** 建议双方协商折扣入账，不视为售后事由。

**第三步：书面提报（24小时内提交清单）**
- **表单内容：** 供应商名称、批次号、到货日期、问题箱数/数量、损失预估金额、附上验收照片。
- **通知方式：** 通过微信/邮件发送，同时抄送采购负责人，确保可追溯。

**第四步：协商处理方式（按比例或折价）**
- **方案A（常用）：** 按“问题果重量 / 总重”比例扣款或退货退款。  
  **公式：** 应退款 = 问题果数量 × 到货单价（若已付款则直接扣款）。
- **方案B：** 若部分果子可做加工（如榨汁、熟食），双方可协商折价30%-50%收购，减少浪费。
- **方案C：** 全批退货（仅限严重到无法分拣时），运费由供应商承担。

**第五步：时效与仲裁**
- **处理期限：** 供应商需在接收售后通知后**48小时内**回复处理意见，否则默认接受超市提出的退款方案。
- **争议解决：** 若无法协商，可约定“以收货门店所在区域农产品批发市场当日批发价为准，核算损失金额”；或提交采购合同约定仲裁机构。

---

### 二、重点约定（合同条款建议）

在采购合同中可加入以下三条硬性条款：

1. **“48小时异议期”**  
   乙方（供应商）在收到甲方（超市）售后通知及照片后，须在48小时内确认处理结果；逾期未复，视为同意甲方提出的扣款或退货方案。

2. **“自然损耗免责但不免责变质”**  
   - 默认自然损耗（如水分蒸发、轻微擦伤）在3%以内甲方自行承担；  
   - 超过3%的部分，且属于人为可防控因素（如运输挤压、温度不当）导致，由乙方承担全部责任。

3. **“第三方检测兜底”**  
   若双方对品质争议无法达成一致，可委托当地农业农村局检测中心或第三方机构检测（费用先由申请方垫付，败诉方承担）。检测主要针对：农残、病斑、内部腐烂率。

---

### 三、实操提示

- **建议设立“准入清单”**：首次供应商合作前，要求提供最近3次发货的果品规格照片，作为后续对比基准。
- **避免口头沟通**：所有售后沟通留存文字记录（如工作群、邮件），防止事后不认账。
- **可设“小额免赔”**：单次损失低于100元（或约定金额），超市可自行消化，不再走售后流程，提高效率，避免摩擦。
