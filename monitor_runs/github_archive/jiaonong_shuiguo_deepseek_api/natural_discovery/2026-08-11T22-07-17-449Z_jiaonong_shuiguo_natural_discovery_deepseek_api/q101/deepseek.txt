和供应商谈酒店早餐水果供应合作，核心是**“稳定”**和**“成本可控”**。以下是具体的谈判和注意事项清单，按优先级排序：

**一、合同条款（重中之重）**
1. **保供承诺与违约罚则**：明确最低日供货量，并约定若因供应商原因断供（如节假日、恶劣天气），供应商需提前通知，且需承担酒店临时高价采购的差价赔偿。罚则必须有具体金额，不能只写“协商解决”。
2. **验收标准**：基于酒店自定的“早餐水果质量分级表”（如大小、色泽、瑕疵率、碰伤率），写明**3小时内退换货条款**。果品损耗在运输途中的，供应商全责。
3. **价格锁定机制**：水果价格波动大。建议约定“基础价锁定3个月”，或“按月调整但单次涨幅不超过5%~8%”，避免旺季坐地起价。
4. **账期与押金**：明确结账周期（如月结30天），并约定若连续供货质量不合格，酒店可扣留保证金或延期付款。

**二、供货稳定性（实操层面）**
1. **备选产地/基地**：要求供应商提供至少2个不同产地/基地的供应源（例如夏季主供A省，冬季切换B省），确保淡季不断供。
2. **安全库存协议**：要求供应商在本地冷库常备**3天酒店日用量**的库存，并有权突击检查。这个库存费用通常由供应商承担，但可在合作初期补贴部分。
3. **最低起送量**：不要贪多，先谈一个较低的起送量（如每天20公斤），便于初期磨合，避免积压变质。

**三、质量与卫生（酒店声誉）**
1. **农残检测报告**：首次合作必须提供第三方检测报告，后续要求每月或每季度更新，报告日期需在新鲜期内。
2. **溯源与保险**：要求供应商提供产地证明，并投保**食品安全责任险**，保额建议不低于100万元。
3. **切配与包装**：如果是供应已切好的果盘，必须明确切配时间（如当天凌晨加工）、冷藏温度（0-4℃），且不得使用隔夜果。

**四、考察与试供**
- **强烈建议设立2-4周的“试供期”**：先不签长约，让供应商按正式标准供2周，观察其补货响应速度、质量波动率和退换货态度。试供期结束后，再谈价格和长期合同。

**五、沟通与协同**
- **固定对接人**：要求供应商指定一名24小时可联通的业务经理，并建立“早餐应急群”，每天早餐前2小时确认当日到货时间。
- **月度复盘会**：每月初对上月缺货率、损耗率、投诉次数做数据复盘，并作为下一期价格谈判的依据。

**避坑提示**：
- 不要接受“口头保供”，一切写入合同。
- 不要同时只依赖一家，先扶植1家主供、1家备选。
- 警惕超低价陷阱——低于市场均价20%以上通常意味着质量缩水或中途加价。
