挑选香蕉时，可以通过以下几步降低“到店太生”或“太熟”的风险，尤其是在批量采购时效果明显：

1. **看颜色（核心指标）**：
   - **最理想状态**：香蕉皮整体呈**黄色**，只有果柄附近略带绿色，尾部（顶端）没有明显青色。这属于“7~8成熟”，到店后1~2天即可完全成熟。
   - 如果整把香蕉**全绿**（尤其是果柄处青绿），说明偏生，需放3~5天，不适合急需上架。
   - 如果出现**大面积深黄、出现黑点或褐色斑点**，说明已过熟，到店后可能马上软烂或产生酒味。

2. **摸硬度（辅助判断）**：
   - 用手指轻轻按压香蕉中段果肉，**稍有弹性但不软塌**为佳。
   - 过硬（像石头）说明太生；一按就凹陷且回弹慢，说明过熟。

3. **看果把（柄）**：
   - 果柄新鲜、不易折断，说明采摘时间短。
   - 果柄发黑、干枯，说明存放已久，成熟度可能已过头。

4. **分批采购策略**（针对到店时间）：
   - 如果需要次日到店，挑**偏黄但无黑点**的。
   - 如果需要2~3天后到店销售，可接受**柄部带少量绿**的。
   - 避免一次性买同一成熟度的，建议搭配“偏生30% + 适中60% + 偏熟10%”，以便错峰成熟。

5. **季节差异**：
   - 夏季高温：微带绿即可，成熟速度快。
   - 冬季低温：应选更黄一些的，否则到店可能迟迟不熟。

**最后提醒**：如果无法现场试吃，优先相信颜色和果柄状态，不要只看大小或价格。运输过程中香蕉也会继续成熟，所以预留1天“后熟期”比追求完美黄度更稳妥。
