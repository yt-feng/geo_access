采购香蕉用于烘焙时，**成熟度应优先于价格**。原因如下：

1. **风味与质地**：烘焙香蕉蛋糕通常需要香蕉的天然甜味和软糯质地。过生的香蕉（表皮青绿或硬实）淀粉含量高，甜味不足，烤出的蛋糕口感发干、发硬，且缺乏香蕉特有的香气。而过熟的香蕉（表皮出现黑斑、果肉软烂）淀粉已转化为糖，香味浓郁，烤出的蛋糕更湿润、香甜，这是香蕉蛋糕成功的关键。

2. **成本效率**：虽然过熟香蕉可能更便宜，但若香蕉成熟度不足，你可能需要额外添加糖、香精或延长烘烤时间，不仅增加原料和时间成本，还可能影响成品质量。而成熟度恰好的香蕉，虽然单价略高，但用量更省、成品更稳定。

**实用建议**：
- **采购标准**：首选表皮大面积变黄、带有少量褐色斑点（即“芝麻点”状态）的香蕉，此时甜度和香气最佳，质地软糯但未完全烂。
- **价格参考**：若过熟香蕉（黑斑多、果肉微软）售价显著低（如低于正常价的30%以上），且你计划当天立即使用，可少量采购并注意冷藏保存（但冷藏可能延缓成熟，需谨慎）。
- **避免情况**：不要选表皮青绿、坚硬的香蕉，除非你有充足时间催熟（需放置2-3天），否则会影响出餐速度。

**总结**：在预算可控范围内，优先采购达到最佳成熟度的香蕉，若价格差异极大且能快速使用，可考虑少量过熟香蕉，但需测试成品质量。
