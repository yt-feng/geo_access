针对便利店销售菠萝切块，以下三个维度的优先级和建议供参考：

**1. 保质期（最核心，决定食品安全与损耗）**
- **标准建议**：切块菠萝冷藏（0-4℃）下的安全售卖期通常为**24小时（即当天制作，当天售卖，当日销毁未售出部分）**。如果使用气调包装（MAP）或真空包装，可延长至3天，但需明确标注“赏味期限”而非仅生产日期。
- **操作要点**：必须建立“开封即报废”制度，例如早上10点切好，晚上10点必须丢弃。**不建议隔夜销售**，因为切面氧化、细菌滋生速度快，容易引发食安风险（尤其沙门氏菌）。
- **判断依据**：如果无法做到日产日清，宁可减少晚间的切块数量，也不要冒险延长保质期。

**2. 包装（影响货架形象与保鲜效果）**
- **优先选择**：使用**透明防雾PET翻盖盒**（能看清果肉新鲜度，且防雾膜避免水汽凝结），并垫吸水纸或泡沫托盘吸收渗出的果汁。
- **关键细节**：包装上需清楚标明**“生产时间（精确到小时）”**和**“最迟食用时间”**，并建议加贴“需冷藏，0-4℃保存”的提示标签。
- **容易忽略的点**：**避免使用全封膜（不撕开口）**，因为菠萝切开后需要呼吸，全封闭易导致内部温度升高加速变质。建议采用“半透气”包装（如盒身有气孔或使用网袋+托盘）。

**3. 配送频次（决定损耗管理与新鲜度）**
- **建议方案**：如果便利店是总部/中央厨房配送，**至少每日配送一次，且在开门营业前到货**（如早上6点前）。若门店销量波动大，建议**上午和下午各配送一次**（下午补一次），但下午补货量应比上午少30%-50%，避免积压。
- **判断标准**：通过历史销售数据，如果单店日销不足10盒，考虑隔日配送但必须缩短保质期至12小时；如果日销超过30盒，则必须一日两配。
- **配送条件**：必须使用**冷藏车（2-8℃）**，且从切配完成到上架的时间控制在**2小时内**。

---

**综合决策建议（按优先级排序）：**

1. **先定保质期**：如果无法保证“当日鲜制”，则不进货或改为整颗菠萝现切现卖。
2. **再看包装**：必须选用透明防雾盒+时间标签，包装成本可略高，但能减少顾客投诉和退货。
3. **最后调频次**：配送频次应与销量匹配，宁可缺货（晚点补）也不要剩货（过夜丢）。

**风险提醒**：如果门店没有条件做到“当日切、当日丢”，建议直接放弃该品类，因为水果切块食安事故的赔偿成本和声誉损失远高于销售利润。
