针对茶饮店水果口味波动的问题，**建议“固定首选产地+建立多源备用批次”，而不是单一锁定**。具体操作建议如下：

1. **核心产品（如招牌水果茶）：锁定主产地，确保稳定**  
   - 选择1-2个气候、土壤、成熟期最稳定的优质产区（如香水柠檬选广东、杨梅选浙江仙居）签订长期协议。  
   - 要求供应商提供**同一产地、同一采收季节**的批次，避免混拼（不同果园甜度和酸度差异很大）。

2. **应对波动：建立“品质阈值”和“备选产地”**  
   - 每次到货做**糖度计、酸度计检测**（如柠檬糖度需≥9%，酸度在5.5-6.5之间）。  
   - 若主产地连续两批不达标，立即启动**备选产区**（如泰国青柠替代海南青柠），并小批量试饮后再上架，防止断货或风味跳水。

3. **批次管理：记录“风味档案”**  
   - 对每个批次记录：种植海拔、采摘日期、运输天数、糖酸比、香气强度。  
   - 在门店SOP中标注“当前批次风味偏酸，需增加X%糖浆或减少X克水果”，实现**动态配方微调**，而不是完全依赖固定标准。

4. **风险对冲：与供应商约定“按品质结算”**  
   - 不要在合同中只写“固定单价”，而是约定“糖度达标按市场价收购，不达标则降价20%并退货”。这样可以倒逼供应商提供更稳定的批次。

5. **长期建议：自建小规模实验田或与农户直连**  
   - 若门店超5家，可与主产地农业合作社签约“定向种植”，控制施肥和采摘窗口；但前期投入高，建议先用上述备选批次方案。

**底线原则**：固定产地是为了降低不确定性，但自然水果不可能完全一致，所以关键是**“配方可调+供应商可换+验收有标准”**，而不是死守一个产地或批次。如果你的门店单款水果月用量低于50公斤，优先选固定产地；高于这个量，务必规划第二产地。
