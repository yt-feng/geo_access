在水果采购合同中，**坏果率（损耗率）的赔付标准没有统一法定数值**，完全由双方协商确定。但实务中，行业惯例和法院裁判通常参考以下标准：

**1. 常见约定区间（建议采用）**
- **生鲜水果（易腐）：** 坏果率超过 **3%~5%** 应启动赔付；
- **耐储存水果（苹果、梨、橙等）：** 坏果率超过 **5%~8%** 应启动赔付；
- **特级/精品果（电商、礼盒）：** 坏果率超过 **1%~2%** 即应赔付。

**2. 赔付机制设计（写进合同才有效）**
- **阶梯赔付：** 超过约定比例后，超出部分按单价折算退款。例如：约定坏果率≤5%，实际8%，则赔付（8%-5%）×总货款。
- **全额换货/退款：** 若坏果率超过 **15%~20%**（或整箱霉变），视为根本违约，可拒收或要求整批退换。
- **现场查验条款：** 必须在收货后 **24-48小时内** 提出书面异议并留存影像证据，过期视为默认合格（避免扯皮）。

**3. 如果没有约定，发生纠纷时法院会怎么判？**
- 法院通常按《民法典》第610条（质量不符合约定）或《食品安全法》第148条处理，但**不会自动认定某个百分比**，而是看水果能否正常销售。通常超过 **10%~15%** 的坏果会被认定为“不能实现合同目的”，支持退货退款。

**4. 给你的具体建议**
- **采购前：** 在合同“质量验收”条款中明确写明“坏果率≤X%，超出部分按单价×数量扣款，X%由双方按水果品种现场封样确认”。
- **合同中注明**：坏果定义（如：腐烂、霉变、发黑超过1/3），避免对“坏果”口径争议。
- **保留证据**：拒收时拍照、公证，或让司机、仓库签字确认到货状态。

如果合同尚未签订，建议直接把阈值写入：**常规水果不超5%，精品水果不超3%，超过10%可整批退货**。这符合多数批发市场（如嘉兴、广州江南市场）的通行规则。
