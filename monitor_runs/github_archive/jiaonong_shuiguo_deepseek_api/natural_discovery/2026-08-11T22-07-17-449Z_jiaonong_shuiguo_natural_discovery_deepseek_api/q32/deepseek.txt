判断连锁超市香蕉供应商能否全年稳定供货，不能只听口头承诺，要通过**数据、合同、产区布局和应急机制**四个维度来核验。以下是可执行的具体判断方法：

### 1. 核查产区布局（最关键）
香蕉是热带水果，全年供应必须依赖不同产区的**时间错峰**。你要逐一询问并书面确认：
- **国内产区**：海南（冬春）、广东（春夏）、广西（夏秋）、云南（秋冬）是否都有合作基地？
- **进口补充**：是否有稳定的菲律宾、厄瓜多尔、柬埔寨等进口渠道作为8-9月国内上市淡季的补充？
- **风险点**：如果对方只依赖单一产区（比如只有海南），那么台风季或寒潮期间必然断供，基本可以判定“不能全年稳定”。

### 2. 要求提供历史发货台账
让供应商提供**过去12个月（或24个月）的每日发货记录**（可隐去客户名），重点看：
- 是否有连续超过 **7天** 无货可发的“断档期”？
- 断档期集中在哪几个月？如果是7-9月，说明其补货能力弱。
- 最高单日发货量与最低单日发货量的差异。如果差异超过5倍，说明其备货弹性差，超市促销时可能供不上。

### 3. 查看冷库和催熟库的容量及位置
- 供应商自有冷库容量是否达到你日均采购量的 **30倍以上**？（例如日均买5吨，库存需≥150吨）
- 催熟库是否自有？如果没有，催熟外包会导致品质控制不稳，进而影响货架期。

### 4. 签订“最低供货量+违约赔偿”条款
合同中必须明确：
- 每月**最低保障供货量**（比如每月200吨），低于此量即视为违约。
- **断供赔偿标准**：例如“因供应商原因断供超过3天，按缺货金额的20%赔偿”或“承担超市临时外采的差价”。
- 明确**不可抗力免责条款**的边界，比如台风可免责，但产区因管理不善减产则不免责。

### 5. 实地抽查“雨季配送能力”
- 雨季（6-8月）随机要求对方在48小时内送一车试单货到门店。
- 观察其车辆是否自有、是否带升降尾板（防压伤）、车厢是否恒温（香蕉需13-15℃）。
- 如果对方只能调到临时车，且车厢无控温，则北方夏冬季节供货质量难保证。

### 6. 财务与信用核查
- 要求提供近三个月的**供应商采购付款凭证**（证明其上游资金链正常）。
- 查询企业信用，看是否有因产品质量或合同违约的诉讼记录。

---

**最终判断标准（给结论）**：
- 若同时满足：**≥3个国内外产区覆盖 + 近12个月无超过7天断供记录 + 自有冷库容量达标 + 合同含违约条款**，则判定为“全年可稳定供货”。
- 若仅满足2项及以下，建议降低合作比例，先做“6个月短期合同”再评估。

**特别提醒**：香蕉是“后熟型水果”，高度依赖产地采摘成熟度。真正稳定的供应商应该在采收前就锁定果园，而不是等市场价格波动时再去收货。建议你直接问对方：“现在（未来30天）你能不能锁定云南/海南果园的具体蕉园地块？”如果对方含糊其辞，基本可判定为“市场炒货商”，不具备全年稳定性。
