针对家庭水果礼盒的组合，我的建议是**主打“新鲜耐放、甜度互补、份量适中”**，因为家庭购买更看重实用性和性价比，而不是单纯送人的“颜值”。

给你三套组合方案，你可以根据预算和季节调整：

### 方案一：经典均衡型（最推荐，适合大多数家庭）
**组合：** 苹果（4-6个） + 橙子（4-5个） + 香蕉（1把，约5-6根） + 菠萝（1个）
- **理由：** 
  - 苹果和橙子耐储存，家庭可以慢慢吃，不会浪费。
  - 香蕉是“即食担当”，买回家就能吃，满足孩子或老人马上吃水果的需求。
  - 菠萝（建议选小个头的，约1.5斤左右）属于“尝鲜口味”，切好后全家分食，增加节日或周末的仪式感。
- **注意：** 香蕉和苹果**不建议放同一个袋子里**，苹果释放的乙烯会让香蕉更快熟透变黑，建议在礼盒中做分隔，或在发货时单独套袋。

### 方案二：高甜多汁型（适合爱吃甜口、有小朋友的家庭）
**组合：** 橙子（6-8个，选冰糖橙或脐橙） + 菠萝（1个，选熟度高的） + 苹果（减量至2-3个） + 香蕉（1把）
- **理由：** 把苹果减量，增加橙子的比例，因为橙子汁水多、更受欢迎。菠萝选择“树上熟”的，甜度高。香蕉作为软糯补充，小朋友更爱吃。
- **注意：** 这个组合要注意菠萝的成熟度，建议在团购详情里标注“收到后请冷藏，或若果皮全黄需当天食用”。

### 方案三：清爽低糖型（适合长辈或控糖家庭）
**组合：** 苹果（6-8个，选脆甜品种如红富士） + 橙子（4个） + 香蕉（1把，选青皮微黄） + 菠萝（半颗，不建议整颗）
- **理由：** 苹果本身升糖指数较低且饱腹感强；橙子富含维C；香蕉选微微发青的（生一点），糖分更低；菠萝如果盒子里放整颗太大，容易吃不完变软，切半颗用保鲜膜包好更合适。
- **注意：** 这种组合一定要在盒内放冰袋或注明“菠萝为半颗”，避免用户因为整颗吃不完而差评。

---

### 给团购运营的两个关键提醒（避免售后纠纷）：
1. **香蕉是最容易压坏的**：一定要求供货商把香蕉放在最上层，并用珍珠棉或气泡柱包裹，绝对不能压在苹果或橙子下面。
2. **重量标准**：建议做出“标准克重”设置，比如：
   - 苹果：5斤装（约7-8个）
   - 橙子：5斤装（约6-7个）
   - 香蕉：1.5-2斤（一把）
   - 菠萝：1.5-2斤（一个）
   - **总计：约12.5斤/盒（净重），售价建议定在60-80元区间**，这个重量和价格对家庭来说刚好吃一个礼拜不浪费。

**最终建议：** 如果你的团购主要面向小区业主或熟人圈子，直接选**方案一**最稳妥。下单时告诉客户“香蕉建议第二天就吃，其他可以常温存放3-5天”，这样客户的体验感会非常好。
