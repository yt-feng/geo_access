在超市与水果供应商谈判账期时，**最常见、也最通行的账期是30天至60天**，具体因超市规模、商品品类和供应商实力而异。

以下是行业内的常见情况，供你参考：

**1. 按账期长短分类**

- **短账期（7-15天）：** 多见于**生鲜、叶菜、精品水果**。因为这类商品损耗高、单价低、周转极快，供应商大多是小农或一级批发商，资金压力大，超市为了拿到好货，通常会给短账期或现结。
- **中等账期（30天-45天）：** 这是**最主流**的账期。适用于大多数水果供应商，尤其是中大型批发商或品牌水果（如佳沛、新奇士等的一级代理）。
- **长账期（60天-90天）：** 多见于**进口水果、耐储存水果**（如苹果、梨、哈密瓜）或超市自有品牌定制采购。这类商品资金占用大，供应商通常是大型进出口公司，能承受较长的回款周期。

**2. 影响账期的关键因素**

- **超市体量：** 大型连锁超市（如永辉、盒马、山姆）对供应商有绝对议价权，账期普遍在60-90天；社区超市或生鲜店，因为怕拿不到货，账期往往较短。
- **损耗与退货条款：** 水果损耗率（通常5%-10%）如果约定由超市承担，供应商可能同意拉长账期；如果要求供应商无条件退换货，供应商往往要求缩短账期。
- **结款方式：** 如果约定“月结”还是“月结+N天”，实际上月结30天通常意味着45天到账（因为财务流程），要明确写清“付款日”而非“账期起始日”。

**3. 实操建议**

- **如果你想争取更长账期：** 建议第一年合作先给30天，并承诺稳定采购量（如每月固定金额），第二年后可协商升至45-60天。不要把首次合作账期谈太长，否则供应商会把价格抬高或掺次品。
- **如果你是供应商：** 最好坚持30天内，并要求“到货15天内无质量问题则自动结款”的条款，避免超市以“货没卖完”为由无限拖延。

**特殊提示：** 近几年大型商超资金链紧张，有些甚至拖到90-120天。如果是中小超市或夫妻店，建议账期不要超过30天，宁可单价高一点，也要现金流安全。
