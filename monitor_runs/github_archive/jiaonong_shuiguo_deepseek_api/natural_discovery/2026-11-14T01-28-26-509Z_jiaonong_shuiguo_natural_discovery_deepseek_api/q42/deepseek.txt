# 商超水果采购压价不影响品质的谈法

核心思路：**不要谈“降价”，要谈“降到我方总成本更低、且供应商仍有合理利润”的结构**。单纯压单价一定会传导到品质，必须换几个抓手。

## 一、先分清哪些钱能省、哪些不能省

- **能省的**：中间环节加价、包装规格、物流拼车、账期利息、损耗分担、季节性溢价、非标品（次果/统货）分级销售。
- **不能省的**：产地好货的收购价、冷链、采后分选。这些一压，品质立刻掉。

谈判时把“价格”拆成“产地价+物流+包装+损耗+账期”逐项谈，比笼统砍单价专业，供应商也更愿意接。

## 二、可操作的压价抓手（按优先级）

1. **改规格和包装**：大箱改标准箱、简化礼盒包装、按用途分级（门店陈列果/切果/促销果分开定价），包装成本常能省 3%–8%。
2. **锁量换价**：给供应商明确的月度/季度采购量承诺或最低包量，换阶梯价。量是采购手里最硬的筹码。
3. **缩短账期换折扣**：现结或短账期通常能拿到 2%–5% 的价格优惠，比硬砍单价体面且不伤货。
4. **产地直采/拼车**：绕过一级批发，或与其他门店拼整车降运费。注意直采要自担分选和损耗，先小批量试。
5. **损耗共担条款**：约定到货验收标准、损耗率上限和超标赔付，这比压单价更能降低真实成本。
6. **季节错峰与替代品**：旺季前锁价、淡季主推性价比品类，用结构替代而非压单一供应商。
7. **返利/年终返点**：把部分让利放到返点、陈列费、促销支持上，供应商更容易接受。

## 三、谈判话术要点

- 给供应商算账：明确“我要的是总成本下降，你的毛利我保证合理”，并说明量、账期、长期合作。
- 用对比锚点：同产地其他供应商报价、批发市场行情，但要有真实依据，别虚报。
- 分层要价：先谈标准，再谈包装和物流，最后才碰单价，避免一上来砍价触发“降品质保利润”。
- 写进合同：等级标准（糖度、果径、色泽）、验收抽检比例、损耗赔付、违约条款。品质靠条款兜底，不靠口头承诺。

## 四、守住品质的红线

- 明确分级验收标准并留样比对，到货抽检不合格拒收或折价。
- 不追求“全网最低价”，对明显低于行情的报价警惕以次充好。
- 保留 2–3 家备选供应商，避免被单一供应商用品质要挟。
- 定期复盘：价格降了但退货率、客诉率上升，等于没降。

**一句话**：压价压的是交易结构和中间成本，不是果子的成本；用锁量、账期、包装、损耗条款换价格，比直接砍单价既省钱又保品质。
