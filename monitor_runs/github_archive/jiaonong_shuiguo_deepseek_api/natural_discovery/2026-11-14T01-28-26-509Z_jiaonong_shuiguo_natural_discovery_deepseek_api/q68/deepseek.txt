判断供应商能否按时到车，不要只听口头承诺，重点查“**车源是否锁死、装载进度、历史履约、异常预案**”。给你一套批发商可直接用的判断方法：

1. **问清“车在哪、谁的车、几点装”**
   - 不要问“能不能按时到”，要问：车牌号、司机电话、车型载重、当前所在位置、计划装货时间、预计发车时间、到货时间。
   - 有车牌和司机电话，且司机能直接确认，才算较可靠；只说“车安排好了”但给不出车牌，风险高。

2. **关键节点要照片/视频**
   - 装车前：空车到场的照片或视频，含车牌。
   - 装货中：装车进度视频，看已装多少、还剩多少。
   - 发车后：过磅单、出库单、司机发车定位或高速入口照片。
   - 香蕉怕压、怕闷、怕温度波动，还要确认装载方式、通风/冷藏条件是否匹配。

3. **查历史履约，不查“关系”**
   - 让供应商提供近几次同类线路的发车、到车记录。
   - 问固定合作司机多不多、是否临时叫车。
   - 新供应商先小批量试单，不要一上来压大单。

4. **看供应商是否敢锁责任**
   - 合同/聊天记录写清：装车时间、发车时间、到货时间、迟到处理、货损责任。
   - 问清迟到怎么办：是否补差价、承担压车费、市场掉价损失如何分。
   - 愿意明确写违约责任的，通常比只拍胸脯的可靠。

5. **提前识别高风险信号**
   - 临到装车才说“车临时换了”。
   - 反复改车牌、改司机电话。
   - 装车视频只拍局部、不拍车牌和车厢。
   - 报价明显低于市场，可能靠拼车、压车或临时找车。
   - 雨天、节假日、产区集中上市期，车源紧张，要更早锁车。

6. **自己留后手**
   - 同一批次不要只押一个供应商。
   - 关键档期提前1—2天确认车源，发车前半天再复核一次。
   - 保留备选车源或备选供应商。
   - 到车时间按市场销售节奏倒推，别只按“发车时间”判断。

一句话：**能给出车牌、司机直联、装车视频、明确违约责任的，才算可信；只给承诺不给节点的，按高风险处理。**
