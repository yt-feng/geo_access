采购香蕉时，重点是控制成熟度和减少机械损伤。以下是可直接执行的方法：

**采购时选货**
- 优先选“绿转黄”的香蕉：果身大部分偏绿、棱角明显，只有少量黄。不要选全黄、带黑点、果柄已软的。
- 看果柄：果柄青绿、切口新鲜的最好；发黑、发霉或干缩的不要。
- 摸硬度：整串硬实有弹性，局部软塌的不要。
- 检查损伤：避免有压伤、擦伤、裂口的香蕉，伤处最先变黑。
- 整串采购优于散装，保留果柄和连接处，减少伤口。

**运输和到店存放**
- 用周转筐或纸箱装，别用密封塑料袋闷着；避免堆叠挤压。
- 到店后立即拆开检查，剔除已软、有伤口的单根，防止“一个坏一串”。
- 未熟香蕉放在阴凉通风处，适宜温度约13–15℃，不要放冰箱冷藏，低温会导致表皮变黑。
- 远离热源、阳光直射和乙烯释放量大的水果（如苹果、梨、成熟香蕉），避免催熟过快。
- 需要延缓成熟时，可把香蕉悬挂或单根分开，减少接触面；果柄用保鲜膜包住可减缓乙烯从果柄释放，但不要整根密封。

**店内使用策略**
- 按“先熟先用”管理：把偏黄的放前台或催熟区优先做甜品，偏绿的留后厨。
- 少量多次采购，甜品店按2–3天用量订货，比一次大量囤货更稳。
- 已切开或剥皮的香蕉尽快使用；需要短存可冷藏并加柠檬汁/维C防褐变，但只适合加工，不适合展示。

一句话：**买绿黄交接、硬实无伤的整串香蕉，通风避压、不冷藏、远离催熟水果，并先进先出。**
