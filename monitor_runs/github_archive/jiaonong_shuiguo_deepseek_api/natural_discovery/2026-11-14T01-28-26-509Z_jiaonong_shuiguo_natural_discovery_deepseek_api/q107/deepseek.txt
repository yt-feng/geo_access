会，而且香蕉和菠萝的损耗风险性质不同，需要分开判断。

**结论先说：起订量过高会显著放大损耗风险，香蕉比菠萝更敏感；如果销量预测不准或周转天数偏长，高起订量很可能把“采购便宜”变成“损耗更贵”。**

### 1. 香蕉：高起订量风险最高
- 香蕉是呼吸跃变型水果，后熟快，黄熟后货架期很短。
- 起订量高会导致：到货集中、催熟/转黄集中、门店来不及卖完，容易出现黑斑、软烂、压伤。
- 尤其夏天、运输距离长、冷链不稳定时，高起订量带来的损耗会明显上升。
- 判断建议：如果起订量对应的可售天数超过 **3～5 天**，风险就偏高；香蕉通常应按更短周转周期订货。

### 2. 菠萝：风险中等，但看品种和加工能力
- 整果菠萝比香蕉耐放，但高起订量仍会带来：集中成熟、果眼发黑、底部腐烂、运输压伤。
- 如果门店有鲜切/果汁加工能力，高起订量的损耗风险会下降；如果没有加工能力，卖相变差后很难消化。
- 判断建议：如果起订量对应的可售天数超过 **5～7 天**，且没有加工或促销消化能力，风险偏高。

### 3. 关键不是“起订量绝对值”，而是这几个指标
采购前建议算：
- **预计可售天数 = 起订量 ÷ 日均销量**
- **损耗敏感期**：香蕉看转黄后天数，菠萝看到货成熟度和储存温度
- **消化能力**：是否有促销、鲜切、果汁、员工餐等二级渠道
- **到货批次质量**：成熟度、机械伤、冷链断链情况
- **补货频率**：高起订量若导致补货间隔拉长，损耗风险更高

### 4. 可执行建议
1. **香蕉**：优先小批量、高频补货；起订量尽量控制在 **2～3 天销量**，最多不超过 5 天。
2. **菠萝**：整果可按 **3～5 天销量**控制；若无加工能力，不要超过 5～7 天。
3. **要求供应商分级供货**：香蕉按成熟度分批到货，菠萝控制成熟度一致性和机械伤。
4. **设置止损线**：可售天数超过阈值、或到货成熟度偏高时，拒绝高起订量或改为分批送货。
5. **用数据复盘**：连续记录起订量、到货成熟度、日均销量、损耗率，找出自己的“起订量—损耗”拐点。

简单判断：**起订量若让你不得不压货超过正常周转天数，就会增加损耗风险；香蕉尤其如此，菠萝次之。**
