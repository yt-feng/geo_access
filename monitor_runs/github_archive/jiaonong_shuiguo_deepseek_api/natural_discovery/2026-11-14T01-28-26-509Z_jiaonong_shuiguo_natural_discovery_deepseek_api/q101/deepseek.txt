和水果供应商谈合作，核心是先把“稳定”拆成可考核的条件，再谈价格和账期。建议按下面几项准备：

1. **明确需求量和规格**
   - 给出每日/每周用量、旺季淡季波动范围、最少起订量。
   - 写清品种、等级、单果重量/大小、成熟度、允许瑕疵率。早餐水果通常要求外观稳定、易分切、损耗低。
   - 明确送货时间、验收地点、卸货责任。

2. **稳定性要写进合同**
   - 要求供应能力和备货方案：产地/批发市场来源、替代品种规则、缺货提前通知时间。
   - 约定缺货、迟送、质量不达标的违约责任和补偿方式。
   - 不要只依赖一家：可设主供应商+备用供应商，或要求供应商有备用货源。

3. **质量验收标准可执行**
   - 到货验收：数量、重量、外观、成熟度、腐烂/压伤比例、农残检测报告或承诺。
   - 约定抽检比例和不合格处理：拒收、换货、折价、扣款。
   - 早餐水果若需切配，要确认是否可提供清洗、去皮、切块等加工服务及相应卫生资质。

4. **价格与账期**
   - 水果价格波动大，建议约定计价方式：固定周期报价、随行就市但设上限、或按品类锁价。
   - 明确是否含税、含运费、含卸货，避免后期加价。
   - 账期结合酒店现金流谈，常见月结，但要和履约保证金/质量标准挂钩。

5. **资质与食品安全**
   - 核验营业执照、食品经营许可、检测报告、从业人员健康证等。
   - 明确冷链/保鲜运输要求，特别是夏季和浆果类。
   - 约定食品安全事故的责任划分和追溯机制。

6. **试供与考核**
   - 先签短期试供协议，比如2—4周，按到货准时率、合格率、损耗率、投诉响应速度考核。
   - 考核合格再签长期合同，并把考核指标写进月度评估和退出机制。

7. **沟通与对账机制**
   - 固定对接人、下单截止时间、临时加单规则、异常反馈时限。
   - 每批送货单、验收单留档，按月对账，避免数量和质量争议。

一句话：先用量化标准锁定“稳定”，再用试供和备用供应商降低风险，最后才谈价格和账期。
