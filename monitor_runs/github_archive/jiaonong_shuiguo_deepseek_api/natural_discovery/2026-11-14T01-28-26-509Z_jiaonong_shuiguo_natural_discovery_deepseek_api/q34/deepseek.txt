**结论：对商超水果而言，损耗低通常比采购价格低更影响最终毛利；但要看品类和损耗可控性。**

可以用一个简单公式判断：

> **最终毛利 = 销售额 × 毛利率 − 损耗金额**  
> 而采购价低主要改善“毛利率”，损耗高低则直接吃掉销量和毛利。

### 1. 为什么损耗通常更关键
水果是典型高损耗品类。假设同样卖10000元：

- A采购价低，但损耗率15%：损耗约1500元
- B采购价高3%，但损耗率5%：采购成本多约300元，损耗少约1000元

**B往往更赚钱。**  
因为损耗不仅损失商品成本，还损失了本可产生的销售额和毛利。

### 2. 价格低在什么情况下更重要
- 品类耐储、损耗率本来很低，如苹果、梨、橙子等
- 采购价差足够大，比如低10%以上，且品质稳定
- 有稳定快销能力，当天能卖完
- 低價来源稳定，不是一次性尾货

这时压低采购价对毛利提升更直接。

### 3. 决策建议
采购时优先看**“综合毛利贡献”**，不要只看进价：

1. **先看品类损耗率**：叶菜、浆果、熟度高的水果，损耗优先；耐储水果可更看价格。
2. **算落地成本**：采购价 + 运输 + 分拣 + 损耗 + 退货，而不是单看进货价。
3. **看周转**：日均销量能否在保鲜期内卖完。卖不完的低价货，就是高损耗。
4. **看品质稳定性**：低价但批次不稳，会带来客诉、降价处理和复购下降。
5. **设红线**：对高损耗品类，宁可进价高一点，也要选耐放、成熟度合适、供应稳定的货。

### 一句话判断
**高损耗品类，损耗低优先；低损耗、快周转品类，价格低优先。整体上，商超水果最终毛利更常被损耗拖累，而不是被进价决定。**
