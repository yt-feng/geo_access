最该先问**配送**，其次**售后**，价格放最后比。原因很实际：水果团购的利润和口碑，首先死在配送时效和损耗上，不在进价贵一毛。

判断顺序可以这样：

1. **配送先问死**
   - 几点截单、几点到团点，迟到怎么赔
   - 是供应商直送还是中转，夏天有没有冷链/保温
   - 破损、压伤、失水谁承担，签收时能不能当场拒收
   - 起送量、临时加单/减单怎么处理
   水果是生鲜，配送不稳，价格再低也是你替供应商背投诉。

2. **售后问清楚规则**
   - 坏果率超过多少算批次问题，怎么补/退
   - 是拍照即赔，还是要退回、要等审核
   - 售后响应时限，谁对接团长
   - 缺斤少两按什么标准补
   团长最怕的不是赔一单，是售后流程拖，团员直接流失。

3. **价格最后谈，但别只比单价**
   要问含不含配送、含不含损耗补贴、账期和结算方式。低价但配送差、售后扯皮的供应商，综合成本更高。

一句话：**配送决定你能不能按时交付，售后决定你出事时能不能兜住，价格决定你赚多少。顺序不能倒。** 如果配送和售后都过关，再压价；如果配送不行，价格再低也别选。
