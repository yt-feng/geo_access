# 社区超市水果：控新鲜度 + 控库存的实操方法

核心思路：**水果不是"备货生意"，是"周转生意"**。宁可一天断货两次，也不要一次压三天。下面按"选品—订货—陈列—临期处理—数据复盘"五步给可执行动作。

## 一、选品：先砍SKU，再谈周转

- **SKU控制在25–35个**。社区店客流有限，品类越多，每个单品动销越慢，烂得越快。
- 结构按"3+5+2"配：
  - 3成**高频刚需**（苹果、香蕉、橙子、梨）——保客流、耐放；
  - 5成**当季热销**（按季节轮换，如夏天的西瓜、荔枝）；
  - 2成**引流/尝鲜**（小份装、切果、特价爆品）——少量进、快进快出。
- **易损品（草莓、葡萄、荔枝、桃）只做小批量**，且必须对应"当天能卖完"的量，不参与囤货。

## 二、订货：按"日销×天数"算，不做感觉订货

- 订货量 = **近7天日均销量 × 计划售卖天数 × 安全系数（1.1–1.2）**。
- 分品类定"最大在店天数"：
  - 耐放类（苹果、橙、梨）：3–5天；
  - 中损类（香蕉、柑橘、瓜类）：2–3天；
  - 高损类（草莓、葡萄、桃、叶菜式水果）：**当天进当天清，最多1天**。
- **固定订货节奏**：每天早上补一次、下午视动销补一次小单；高损品按"上午半量+下午看剩货补"。
- 跟供应商谈**小批量、多频次、可退换/调换**，把损耗风险往上游分一点；能日配就不隔日配。

## 三、陈列与保鲜：让货"卖得快"比"放得久"更重要

- **少量多次上货**：台面只摆"半天量"，卖完再补，避免整箱摊开加速失水。
- **先进先出**：新货放里/下，旧货放外/上；每天开店前翻台一次，把临期往前排。
- **分区控温**：香蕉、芒果等热带果**不进冷柜**（会黑变）；草莓、葡萄、切果进冷藏；叶菜类水果喷雾保湿但别积水。
- **挑拣常态化**：每天至少2次（开门后、闭店前）挑出伤果，**伤果当场分流**，不要留在台面拉低整体观感、传染其他果。
- **切果/果切做"损耗转化"**：临期但完好的果做成小份果切或拼盘，是消化库存最有效的出口，但必须当天做当天卖、冷藏、标时间。

## 四、临期处理：设"止损线"，别等烂了才动

给每个品类设**降价节点**，到点就降，不犹豫：

- 剩余保质期过一半 → 原价转"组合装/小份装"；
- 剩1/3 → **8折**并前置到收银台/门口引流位；
- 当天必须清 → **5折或打包特价**，闭店前1小时清尾；
- 确实卖不掉的 → 做果切、员工内购、或联系周边餐饮/果汁摊，**当天出清，不进第二天**。

关键原则：**降价的钱远小于烂掉的钱，也小于占着台面卖不动、挡住新品的机会成本。**

## 五、数据复盘：用一张表管住库存

- 每天记3个数：**进货量、销量、报损量**（按单品）。
- 每周算**单品周转天数 = 平均库存 ÷ 日均销量**，周转超过设定天数的单品，下周直接减订或砍掉。
- 盯**报损率**：社区水果店健康区间大约**3%–8%**，连续两周超10%的单品，要么减量、要么换供应商、要么下架。
- 建"**黑名单**"：连续报损高、动销慢的单品，停进2–4周再试，别反复踩坑。

## 一页纸执行清单

1. SKU砍到30个左右，高损品只做当天量；
2. 订货按"日均销量×天数×1.1"算，日配为主；
3. 台面少量多次补，每天翻台2次挑伤果；
4. 设降价节点，临期当天清，果切做转化出口；
5. 每天记进/销/损，每周砍周转慢的单品。

一句话：**水果生意的利润不在"进价低"，在"周转快、损耗少"。** 把订货量压到"卖得完"的水平，比任何保鲜技巧都管用。
