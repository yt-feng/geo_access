做餐饮客户（尤其是饮品店、甜品店、烘焙店、食堂和酒店后厨），菠萝和香蕉的核心不是“越多规格越好”，而是先分用途，再定 2～3 个主推规格，避免档口损耗和客户挑选成本。

**菠萝建议准备的规格**

1. **鲜切/饮品店用：去皮去眼净果**
   - 规格：净重 1kg/袋、2kg/袋；或按片/块分装。
   - 适合：奶茶店、果汁店、甜品店。
   - 要点：成熟度 7～8 成，酸甜稳定，出汁率好；必须冷链，标注加工日期和保质期。

2. **后厨/食堂用：整果中果**
   - 规格：单果 1.2～1.8kg 为主，按箱装 9～12 头/箱。
   - 适合：食堂、酒店后厨、现切果盘。
   - 要点：耐储、去皮出成率稳定，不要大小差异过大。

3. **甜品/烘焙用：小果或凤梨型**
   - 规格：单果 0.8～1.2kg，或按“凤梨”单独列规格。
   - 适合：甜品装饰、披萨、烘焙馅料。
   - 要点：香气足、纤维细；如果客户要“菠萝不涩”，可主推凤梨并明确品种差异。

4. **高端餐饮/酒店：精品大果**
   - 规格：单果 1.8kg 以上，按个卖或礼盒装。
   - 适合：酒店自助、果盘展示。
   - 要点：外观完整、冠芽新鲜，价格带单独设置。

**香蕉建议准备的规格**

1. **饮品店/甜品店：中把香蕉，按把或按斤**
   - 规格：单根 120～150g，成熟度 6～7 成发货，到店后 1～2 天转黄。
   - 适合：奶茶店、果昔店、甜品店。
   - 要点：餐饮客户最怕当天全熟，建议做“青黄搭配”或按成熟度分档报价。

2. **后厨/食堂：大把香蕉，按箱**
   - 规格：单根 150～200g，整箱 10～13kg，按箱走量。
   - 适合：食堂、酒店早餐、团餐。
   - 要点：耐运输、规格统一，减少断把和黑斑。

3. **烘焙/加工用：熟香蕉或二级果**
   - 规格：按箱或按公斤，成熟度高、外观要求低。
   - 适合：香蕉面包、蛋糕、果泥。
   - 要点：必须明确“加工果”定位，价格低、周转快，避免和鲜食果混卖。

4. **高端/果盘用：精品小把**
   - 规格：单根 100～130g，小把装，外观整齐。
   - 适合：酒店果盘、精品水果店。
   - 要点：卖相优先，单独定价。

**档口实操建议**

- 主推组合：菠萝“整果中果 + 去皮净果”两档；香蕉“中把鲜食 + 加工熟果”两档。先跑 2～4 周，看餐饮客户复购再扩规格。
- 报价方式：餐饮客户更看重稳定供货和出成率，建议按“净重/箱/把”报价，同时给“去皮净果”溢价规格。
- 必标信息：品种、单果/单根重量区间、成熟度、加工日期、保质期、储存条件。鲜切类必须冷链。
- 先问客户用途：做饮品、果盘、烘焙还是食堂，用途不同，规格完全不同；不要一开始铺太多 SKU，否则损耗会吃掉利润。
