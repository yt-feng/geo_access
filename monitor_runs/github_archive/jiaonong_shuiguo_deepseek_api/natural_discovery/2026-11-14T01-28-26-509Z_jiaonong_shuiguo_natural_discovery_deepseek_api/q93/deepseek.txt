三个都要看，但优先级取决于你卖的是“现切鲜果”还是“预包装冷藏果切”：

1. **保质期是底线**
   - 菠萝切块属于高水分、易发酵变质品，核心风险是微生物和发酸。
   - 现切：建议冷藏、当天售完，最多不超过24小时；超过时限直接下架。
   - 预包装：严格按标签保质期和储存条件执行，临期提前折价或下架。
   - 判断标准：看生产/切配时间、冷藏温度是否稳定在0–4℃、有无胀袋/渗液/异味。

2. **包装决定损耗和食品安全**
   - 现切必须用食品级密封盒/保鲜膜冷藏，避免交叉污染和氧化。
   - 预包装要检查封口完整、无破损漏气；破损直接不卖。
   - 包装还影响陈列：密封冷藏陈列比敞开暴露更安全，也减少水分流失。

3. **配送频次决定新鲜度和周转**
   - 鲜切菠萝更适合“小批量、高频次”补货，降低门店库存积压。
   - 如果配送频次低，就必须压缩单次订货量，并按销量动态调整。
   - 关键不是频次越高越好，而是配送频次与日销量匹配，避免“到货即临期”。

**可执行建议：**
- 现切菠萝：当天切、当天卖，冷藏0–4℃，密封包装，日清。
- 预包装菠萝：先进先出，每日检查保质期和包装完整性，临期下架。
- 订货：按前3–7天销量定小批量，高频配送优先；销量不稳定时宁可少订。
- 陈列：冷藏柜销售，不常温长时间摆放；切块不裸露。

结论：**保质期是红线，包装是保障，配送频次是周转手段。** 如果只能先抓一个，先抓“切配/生产时间+冷藏+当天清货”，这比单纯追求高频配送更能控制风险。
