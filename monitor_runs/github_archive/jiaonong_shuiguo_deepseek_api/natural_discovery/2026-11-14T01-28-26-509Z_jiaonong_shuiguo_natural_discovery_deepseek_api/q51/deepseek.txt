要，但不要“只固定一个产地/批次”，更合理的做法是：**固定供应标准 + 主备两个产地/批次 + 每批验收和留样**。

茶饮店水果口味波动会直接影响出品稳定性，采购上建议这样判断和执行：

1. **必须固定的是标准，不只是产地**
   - 固定品种、成熟度、糖度/酸度范围、规格、到货温度、破损率。
   - 例如柠檬固定品种和单果规格，草莓固定成熟度和糖酸比范围。
   - 只固定产地但不管成熟度，口味照样波动。

2. **主产地/主批次要固定，但保留备用来源**
   - 设一个主供应商或主产地，保证日常风味基线稳定。
   - 同时准备一个备选产地/批次，应对断货、雨季、产季切换。
   - 不建议长期只靠单一产地，否则遇到减产、涨价、天气异常会很被动。

3. **按“批次”管理比按“产地”管理更细**
   - 同一产地不同批次也可能差异很大，尤其是季节性水果。
   - 每批到货做感官验收：颜色、香气、酸甜度、出汁率、软硬度。
   - 对关键水果做简单糖度检测，记录批次数据，形成自己的验收档案。

4. **配方和操作要留调整空间**
   - 对口味波动敏感的产品，糖度、酸度、果酱/果汁复配比例要有小范围调整SOP。
   - 新品或季节性水果先小批量测试，再放门店。
   - 每批留样，出现客诉时能追溯。

5. **采购合同里写清楚**
   - 品种、规格、成熟度、糖酸度范围、到货温度、批次一致性要求。
   - 不合格批次的退换货规则。
   - 供应商需提前告知产地切换或产季变化。

**结论：**
要固定，但固定的是“品种+规格+成熟度+糖酸度+验收标准”，并采用“主供应产地/批次 + 备用来源”的方式。只固定单一产地风险高；完全不固定，口味和出品稳定性会更难控制。
