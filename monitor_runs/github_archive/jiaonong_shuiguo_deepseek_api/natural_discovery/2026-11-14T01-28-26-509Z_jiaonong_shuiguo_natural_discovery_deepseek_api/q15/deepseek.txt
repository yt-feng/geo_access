水果店遇到坏果，结算和赔付可以先按“证据留存—分级处理—按合同/约定结算”的顺序走。

**1. 先固定证据**
- 到货当场或开箱时拍照/录像：整车/整箱外观、坏果比例、坏果特写、批次标签、送货单。
- 记录数量：总进货箱数/重量、坏果箱数/重量、可销售部分。
- 尽量让司机或供应商在场确认，并在送货单上备注“发现坏果X箱，待协商”，双方签字。
- 保留聊天记录、订单、报价单、合同、付款凭证。

**2. 按坏果程度分级**
- **轻微瑕疵**：可降价销售，按折价结算，比如扣减5%—15%，具体看品类和约定。
- **明显腐烂/不可销售**：该部分不计入结算，要求补货、换货或扣款。
- **整批严重坏果**：可拒收或要求退货退款，运费和损耗按合同约定承担。
- **隐蔽坏果**：开箱后才发现，应在约定异议期内提出；没有约定就尽快提出，别拖到付款后很久。

**3. 结算方式优先看合同/订单约定**
常见做法：
- **扣款结算**：本批货款中直接扣除坏果对应金额，按进货单价×坏果数量计算。
- **补货/换货**：供应商补同等数量合格果，坏果退回或就地处理。
- **折价结算**：整批按协商折扣结算。
- **退货退款**：严重不合格时整批退回，供应商退款并承担约定运费。
- **质量保证金/账期扣款**：有长期合作的，可在下期货款中抵扣，但最好书面确认。

**4. 赔付范围**
一般可主张：
- 坏果对应货款；
- 已支付的运费/卸货费中合理分摊部分；
- 因坏果导致的合理直接损失，如已产生的分拣人工、冷藏费；
- 合同约定的违约金或质量赔付条款。

注意：预期利润、客源流失等间接损失通常较难主张，除非合同明确约定。

**5. 沟通话术**
“本批X月X日到货X箱，开箱发现X箱存在腐烂/压伤，照片和送货单备注已发您。按进货单价X元计算，坏果金额X元。建议本批扣款X元，或您补发X箱合格果。请今天内确认，以便我们安排后续销售。”

**6. 避免踩坑**
- 不要先签字确认“数量质量无误”再开箱。
- 不要把所有坏果直接扔掉而不留证。
- 不要只口头协商，至少微信文字确认扣款金额和方式。
- 长期供应商应在合同里写清：验收标准、异议期、坏果赔付比例、运费承担、补货时限。

如果没有合同，就按行业惯例和双方长期交易习惯协商；协商不成，可凭送货单、照片、聊天记录和付款记录主张扣减或赔偿。
