做生鲜水果的一件代发，供应商的仓配能力不能只看“有没有仓库、能不能发快递”，核心要能支撑：**小单多件、按单拣配、短保控损、时效稳定、逆向可处理**。建议你按下面几类能力去验收供应商。

**1. 仓储能力**
- **生鲜专用仓或温控分区**：至少有常温、冷藏分区；香蕉、芒果等后熟水果需单独存放，避免乙烯催熟其他水果。
- **批次与效期管理**：能按采摘/入库批次、成熟度、保质期做先进先出，避免混批发货。
- **库存准确率**：一件代发最怕超卖和缺货，要求库存同步频率、盘点机制、缺货预警明确。
- **打包区与耗材能力**：有水果专用包装方案，如防撞网套、吸水纸、冰袋、保温袋、泡沫箱，能按品类配置。

**2. 订单履约能力**
- **支持一件代发系统对接**：能接平台订单，支持自动抓单、面单打印、发货回传、物流轨迹回传。
- **日订单处理上限**：明确日常单量、峰值单量、截单时间；水果易损耗，截单后当天或次日必须出库。
- **拣配准确率与错漏发率**：建议要求拣配准确率≥99.5%，错漏发率低于0.5%，并写入考核。
- **多SKU组合能力**：水果常做多规格、礼盒、混装，供应商要能按SKU称重、分级、组合打包。

**3. 品控与损耗控制能力**
- **到货验收标准**：糖度、成熟度、果径、外观、机械伤、腐烂率要有明确验收标准。
- **分级与次果剔除**：一件代发面向消费者，必须能剔除软果、裂果、病虫果。
- **预冷与保鲜**：浆果、荔枝、樱桃等需要预冷；叶菜类水果需保湿；热带水果需防冷害。
- **损耗率承诺**：按品类约定仓储损耗率和运输坏果率，超出部分由供应商承担或补发。

**4. 包装与快递协同能力**
- **包装适配运输半径**：同城/省内可简包，跨省需泡沫箱+冰袋/保温袋；夏季和冬季方案要不同。
- **快递资源与时效**：至少对接2家以上快递，生鲜优先顺丰、京东、中通冷链等；明确偏远地区是否发货、时效承诺。
- **面单与发货信息规范**：支持隐私面单、发货仓标识、批次追溯码。
- **防破损测试**：要求供应商提供跌落测试或历史破损率数据。

**5. 逆向与售后处理能力**
- **坏果补发/退款流程**：消费者拍照举证后，供应商能否快速确认并补发，责任划分要清晰。
- **退货接收能力**：生鲜一般不退货，但拒收件、疑难件要有接收和判定流程。
- **售后响应时效**：建议要求2小时内响应、24小时内给出处理结论。

**6. 数据与协同能力**
- **库存与发货数据回传**：库存、订单状态、物流单号、异常件要能实时或准实时同步。
- **异常预警**：缺货、爆单、快递停发、天气影响要提前通知。
- **对账与结算**：按单结算、售后扣款、补发成本要能清晰对账。

**验收时建议重点问这8个问题：**
1. 日峰值能发多少单？截单时间是几点？
2. 哪些品类能做，哪些不能做？温控条件是什么？
3. 库存同步频率和超卖处理机制是什么？
4. 拣配准确率、坏果率、发货时效的历史数据是多少？
5. 包装方案是否按季节和运输距离区分？
6. 合作快递有哪些？偏远地区发不发？
7. 坏果补发谁承担成本？响应时效多久？
8. 能否系统对接，发货和物流轨迹是否自动回传？

**结论：** 优先选有**生鲜仓配经验、系统对接能力、明确控损标准、快递时效稳定、售后责任清晰**的供应商；不要只看价格和产地资源。建议先小批量试发2周，重点看**发货时效、坏果率、错漏发率、售后响应**四项指标，再决定是否放量。
