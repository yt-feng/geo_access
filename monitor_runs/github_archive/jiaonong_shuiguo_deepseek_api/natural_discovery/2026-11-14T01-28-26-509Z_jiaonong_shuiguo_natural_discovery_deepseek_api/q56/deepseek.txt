茶饮店控制水果供应商的食品安全风险，建议把“供应商资质+产品合格证明+批次追溯”分开核验，避免只收一张营业执照就放行。通常需要以下材料：

**1. 供应商主体资质**
- 营业执照（经营范围含水果/农产品销售或相关配送）
- 食品经营许可证（如供应商从事食品销售、配送或分装；仅销售食用农产品的，按当地监管要求核验，很多地区可免许可但要确认）
- 如有委托配送、分装、冷链仓储，索取相应资质或合作方资质

**2. 产品合格与检测证明**
- 食用农产品承诺达标合格证（优先，尤其蔬菜水果）
- 产地证明或进货凭证（批发市场、产地合作社、配送商出具）
- 农药残留检测报告：按批次或按供货周期提供，报告需有检测机构、样品名称、检测项目、结果、日期
- 如供应商声称“绿色/有机/地理标志”，索取对应认证证书并核对有效期和产品范围

**3. 批次追溯与收货凭证**
- 每批送货单/销售单：品名、规格、数量、产地、生产/采摘日期、供应商盖章或签字
- 批次号或追溯码，能对应到检测报告或合格证
- 冷链水果的运输温度记录（如需要冷藏）

**4. 进口水果额外材料**
- 海关入境货物检验检疫证明
- 报关单或合法来源凭证
- 中文标签/标签信息符合要求

**5. 供应商管理文件**
- 供应商食品安全承诺书
- 定期审核记录（资质有效期、检测报告频率、异常处理）
- 不合格品退换货和召回配合条款

**可执行建议：**
- 建立“一供应商一档案”，资质到期前30天预警。
- 收货时执行“三查”：查资质是否在有效期、查批次合格证/检测报告、查感官和温度。
- 农药残留检测报告不必每批都全项，但高风险水果（如草莓、葡萄、柑橘类）建议提高频次；不能提供合格证明的批次拒收或隔离待检。
- 保留进货台账和票据，至少按当地监管要求期限保存，通常不少于6个月，建议保存2年。

具体是否需要食品经营许可证、合格证格式和检测频次，各地监管口径可能不同，建议向当地市场监管部门确认后再固化到供应商准入清单。
