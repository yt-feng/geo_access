会影响销售，但关键不在“大小不一样”本身，而在于**是否混得太明显、是否影响顾客挑选和定价**。香蕉一箱大小不一是常态，处理得当影响不大；处理不好会直接拉低售价和复购。

**会带来的主要影响：**
- **顾客挑拣严重**：大小混装时，顾客会反复翻找“大的、好看的”，导致损耗上升、陈列变乱。
- **定价困难**：同一箱里大小差异大，按统一价卖，大果显得亏、小果难卖；按等级卖又增加分拣人工。
- **卖相下降**：大小参差、成熟度再不一致，会让整堆看起来不整齐，降低购买欲。
- **客诉风险**：如果整箱或整把售卖，顾客会认为“以小充大”，尤其社区店复购客更敏感。

**可执行建议：**
1. **到货后先分级**：按大、中、小分成2—3档，分别陈列、分别定价；别把大小差异明显的混在同一把里。
2. **尽量按把/按根卖，少整箱卖**：让顾客按需购买，减少“整箱里大小不一”的心理落差。
3. **小果做特价或加工**：小香蕉可做特价引流、切盘、香蕉奶昔原料，或搭配促销，不要硬按大果价卖。
4. **把大小差异控制在“同一把内”**：同一把香蕉尽量粗细、长短接近，顾客对单根差异容忍度更高。
5. **采购端提要求**：和供货商约定分级标准，至少做到“同箱内差异不过大”；如果价格很低、允许混装，就要提前按混装销售策略准备。

**判断标准：**
- 如果只是同一箱里略有粗细长短差异，分级后正常卖，影响很小。
- 如果大小差异明显到顾客一眼挑拣、同把里悬殊，就会明显影响销售和毛利，必须分拣或改销售方式。

简单说：**大小不一不是不能卖，而是不能混着按一个标准卖。** 分级、分价、分场景处理，影响就可控。
