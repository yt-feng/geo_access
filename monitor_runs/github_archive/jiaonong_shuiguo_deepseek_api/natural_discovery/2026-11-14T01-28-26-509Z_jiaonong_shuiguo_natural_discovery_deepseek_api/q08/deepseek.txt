进货量不大时，通常更建议“固定供应商为主、批发市场为辅”，而不是二选一。原因很实际：

**1. 小批量去批发市场的问题**
- 单价未必低，档口对散客和小客户报价通常偏高。
- 起批量、混批规则容易卡你，拿少了不给好价。
- 品质和供货稳定性靠运气，换档口就要重新试错。
- 每次采购花的时间、交通、沟通成本，摊到小批量上不划算。

**2. 固定供应商更适合小店的点**
- 可以谈小批量、多频次补货，减少压货。
- 价格和账期相对稳定，方便你算毛利。
- 出质量问题有人负责，退换货有依据。
- 长期合作后，对方更愿意给你留货、提醒新品和缺货。

**3. 更合适的做法**
- **主品类找1—2家固定供应商**：先小批量试单，看准时率、次品率、退换态度，再逐步放量。
- **批发市场用来补缺口和试新品**：临时缺货、节日备货、想看新款式时去，不当主力渠道。
- **同类供应商保留备选**：别只压一家，避免被拿捏或断供。
- **把条件谈清楚**：最小起订量、补货周期、次品处理、是否包邮、价格有效期，最好有文字记录。

简单判断：**如果你卖的是稳定复购的品类，优先固定供应商；如果是款式变化快、需要经常看新货的品类，批发市场的比重可以高一些，但仍建议沉淀1—2家固定供应商兜底。**
