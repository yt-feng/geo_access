采购菠萝时，别按“当下最好吃”的标准挑，而要按“到店后2～4天能卖完”的节奏选熟度。水果店控损耗，核心是**分批采购、按销售速度配熟度**。

可执行判断如下：

1. **按销售周期定熟度**
   - 2天内能卖完：可选**七八成熟**，果香初显、按压略软。
   - 3～4天卖完：以**六七成熟**为主，果身硬实、香气淡。
   - 当天促销或做果切：可少量拿**八九成熟**，香气明显、按压稍软，但当天处理。
   - 不建议大批量拿全熟菠萝，除非有稳定果切/果汁消化能力。

2. **看外观**
   - 果皮颜色：青绿偏黄、黄色面积约1/3～1/2，通常适合周转2～4天；整体金黄、底部发橙的偏熟，要快卖。
   - 果眼：果眼浅而饱满、分布均匀的成熟度较稳；果眼深陷、发黑或渗汁的易坏。
   - 果形：选短粗、端正、底部平整的；细长或底部尖的果肉少、损耗感强。
   - 表皮：干燥、无软塌、无黑斑扩散、无汁液渗出。底部发黑发软的直接不要。

3. **闻香气**
   - 靠近底部闻：**淡香**适合周转；**浓香扑鼻**说明偏熟，需1～2天内卖完；**发酵味、酒味、酸味**是过熟或开始坏。

4. **按压和掂重**
   - 轻按果身：硬实有弹性适合放几天；局部明显软陷、按下去不回弹的不要。
   - 同样大小掂着沉手的通常水分足；过轻可能失水或内部空心。

5. **看冠芽和底部**
   - 冠芽青绿、挺立、不干枯为好；冠芽极易拔脱可能过熟。
   - 底部切口干燥、无异味、无霉点为好；底部湿软、发酸、长毛的直接淘汰。

6. **采购结构建议**
   - 一次采购别全拿一个熟度：例如60%六七成熟做周转，30%七八成熟做近两天销售，10%八九成熟用于试吃、果切或促销。
   - 到店后**按熟度分区摆放**，熟的交错陈列在前排优先卖；不要堆压，底部注意通风。
   - 建立简单记录：每次到货熟度、数量、售完天数、损耗数，连续记2～3周就能定出适合你门店的采购比例。

一句话：**采购选“淡香、硬实、黄中带青、底部干燥”的六七至七八成熟菠萝，按销售速度分批配熟度，比追求当下最甜更能降损耗。**
