需要。企业福利采购水果礼盒，供应商通常应同时支持开发票和定制包装，但两者要求性质不同：

1. **开发票：基本准入条件**
   - 企业采购用于员工福利，通常需要增值税发票用于入账、报销和税前扣除。
   - 采购前确认：能否开票、发票类型（增值税普通发票/专用发票）、税率或征收率、开票内容（水果/礼盒/食品等）、是否支持先票后款或票到付款。
   - 若供应商为小规模纳税人，专票抵扣有限，需提前确认企业财务要求。

2. **定制包装：福利场景常见需求，但非所有供应商默认支持**
   - 常见定制包括：企业LOGO、贺卡、腰封、外箱贴纸、祝福语、统一礼盒规格等。
   - 需确认：起订量、打样费、设计确认周期、定制加价、交货周期，以及定制包装是否影响退换货。
   - 若采购量小，可优先选择支持“贴纸/腰封/贺卡”轻定制而非完全开版定制，成本更低。

**建议在采购合同中明确：**
- 发票类型、税率、开票时间及开票内容；
- 包装定制内容、打样确认、验收标准、加价及交期；
- 水果品质标准、破损赔付和售后责任。

结论：**开发票应作为硬性筛选条件；定制包装按企业福利形象需求确定，建议至少支持轻定制。**
