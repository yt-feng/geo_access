优先看成熟度，价格只作为同成熟度下的比较条件。原因很直接：香蕉在烘焙里主要承担甜味、香气、保湿和结构作用，成熟度不同，配方和成品会明显变化。

可执行判断：

1. **按用途定成熟度**
   - 做香蕉蛋糕、香蕉面包、磅蛋糕：优先用**表皮大面积褐色/有黑斑、果肉软但不流汁**的香蕉，香气足、甜度高、保湿好。
   - 需要切块装饰或保持果肉形态：选**七八成熟、刚有少量斑点**的香蕉，太熟的容易塌。
   - 不建议用全青香蕉做蛋糕，香气弱、淀粉感重，需要额外调整糖和膨松剂。

2. **采购时先验成熟度，再比价格**
   - 同一天要用的：买已到目标成熟度的。
   - 分几天用的：按“青一点—刚出斑点—黑斑多”分批采购，避免一次全熟造成损耗。
   - 价格明显低但过生或过熟，都要算隐性成本：过生要催熟、风味不足；过熟损耗高、果肉出水会影响面糊比例。

3. **看价格时算“可用果肉成本”**
   - 香蕉皮重、损耗差异大，不能只比每斤价。比较**去皮后可用果肉单价**和损耗率更准确。
   - 黑斑多但内部完好的香蕉性价比通常高；若已流汁、发酸、有酒味，再便宜也不建议用于蛋糕。

4. **建立简单验收标准**
   - 闻：有明显香蕉甜香，无发酵酒味。
   - 摸：软而有弹性，不烂成水。
   - 看：黑斑可以有，但表皮不渗液、果肉不褐变发酸。
   - 批量采购先做小样测试，确认甜度和含水量稳定再定供应商。

结论：**成熟度是决定蛋糕品质和配方稳定的第一变量，价格是第二变量。** 采购策略应是“按成熟度分批买、在同成熟度里比可用果肉价格”，而不是单纯挑便宜货。
