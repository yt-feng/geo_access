对餐饮连锁采购水果，**大多数情况下“中央厨房统一收货”更好**，但不是绝对；关键看水果品类、配送半径、门店加工能力和损耗责任。建议用“分类收货”而不是二选一。

**结论先说：**

- **主推：中央厨房统一收货 + 分级配送**
- **例外：易损、短保、门店现制现售占比高的水果，可门店直收或“中央厨房验收、供应商直送门店”**
- **不建议：所有水果一律门店分开收货**

---

## 一、中央厨房统一收货的优势

1. **品质标准统一**
   - 糖度、规格、成熟度、瑕疵率可按连锁标准统一验收。
   - 避免各店店长/厨师凭经验收货，标准漂移。

2. **采购议价和集单能力强**
   - 总量集中，供应商更愿意给稳定价格和优先供货。
   - 可做统采统配、产地直采、年度框架。

3. **食品安全和追溯更可控**
   - 农残检测、索证索票、批次记录集中在中央厨房。
   - 出现问题时能快速锁定批次和门店。

4. **减少门店收货人员和空间压力**
   - 门店不用每天早高峰验货、搬货、挑果。
   - 后厨面积小、无冷藏条件的门店更适合。

5. **损耗责任更清晰**
   - 中央厨房验收后，运输损耗、门店储存损耗可分段考核。

**适合统一收货的水果：**
- 苹果、梨、橙、柠檬、西瓜、哈密瓜等耐储运品类；
- 标准化程度高的切果、果切原料；
- 用量大、SKU少、供应商稳定的核心单品。

---

## 二、门店分开收货的优势

1. **短保易损水果更新鲜**
   - 草莓、蓝莓、荔枝、杨梅、水蜜桃、葡萄等，少一次中转就少一次损伤。

2. **门店可按当日客流灵活补货**
   - 现制饮品、果切、甜品店客流波动大，门店直收更灵活。

3. **减少中央厨房分拣和二次配送成本**
   - 小批量、多频次配送时，统一收货可能增加人工和物流成本。

4. **成熟度可按门店销售节奏调整**
   - 有的门店当天用，有的门店次日用，直收可要求不同成熟度。

**适合门店直收的水果：**
- 高损耗、短货架期、怕挤压品类；
- 单店用量小但频次高的门店；
- 距离中央厨房远、配送覆盖不经济的区域；
- 需要门店现场挑选成熟度的鲜果。

---

## 三、两种模式的主要风险对比

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 品质标准 | 更统一 | 易漂移 |
| 采购成本 | 更有优势 | 分散议价弱 |
| 食品安全追溯 | 更强 | 较分散 |
| 新鲜度 | 多一次中转 | 更直接 |
| 损耗 | 分拣和运输损耗集中 | 门店验收和储存损耗分散 |
| 门店操作 | 轻 | 重 |
| 灵活度 | 较低 | 较高 |
| 管理难度 | 中央厨房压力大 | 总部管控难 |

---

## 四、建议的落地模式

### 方案A：中央厨房统一收货为主
适用于：门店数量多、区域集中、水果SKU相对稳定、中央厨房有冷藏和分拣能力。

做法：
- 中央厨房设专职水果验收岗；
- 按“品类+成熟度+门店用途”分级；
- 耐储水果统收统配，易损水果供应商直送门店但由中央厨房统一验收标准；
- 建立批次追溯和门店损耗反馈。

### 方案B：分类收货
这是最推荐的连锁实操方式：

1. **耐储统配类**：苹果、橙、柠檬、瓜类 → 中央厨房统一收货。
2. **易损直送类**：草莓、蓝莓、荔枝、杨梅、葡萄 → 供应商直送门店，总部统一标准、中央厨房抽检。
3. **核心大单品**：统采统收，保证价格和品质。
4. **区域特色小单品**：区域仓或门店直收，但纳入统一供应商名录。

### 方案C：门店直收但总部强管控
适用于：门店分散、中央厨房配送半径过大。

必须配套：
- 统一验收标准和拍照留证；
- 供应商准入和淘汰机制；
- 门店收货数据实时上传；
- 总部/区域巡检和神秘抽检；
- 损耗率与门店考核挂钩。

---

## 五、判断你该选哪种的5个问题

1. 水果SKU多不多？耐储占比高不高？
2. 门店离中央厨房多远？冷链配送是否覆盖？
3. 中央厨房有没有冷藏、分拣、质检能力？
4. 门店有没有冷藏空间和专职收货人员？
5. 水果损耗目前主要发生在哪一段：采购、运输、仓储还是门店？

**如果这5个问题里，门店多、区域集中、SKU稳定、中央厨房有能力，选统一收货；如果易损短保占比高、门店分散、配送半径大，选“分类收货+门店直送”。**

---

## 最终建议

**不要一刀切。最佳方案是：中央厨房统一收货为主，易损短保水果供应商直送门店，但验收标准、供应商、价格和追溯由总部统一管理。**

这样既保留集采和食安优势，又避免易损水果多一次中转造成损耗。
