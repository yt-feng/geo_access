建议按“**先小把、再整袋、单根做补充**”的顺序测试，而不是一开始三选一压重注。理由和执行判断如下：

1. **首选小把（2–3根）作为主包装**
   - 便利店是即时消费场景，小把最符合“现在吃、当天吃、一个人或两个人吃”的需求。
   - 相比单根，小把有客单价，且减少顾客挑选时反复触碰、折损。
   - 相比整袋，小把试错成本低，不容易因熟度问题整袋报废。

2. **整袋只适合做“家庭补充装”**
   - 如果门店周边有社区、家庭客群，可上少量整袋，但必须控制进货量和熟度。
   - 整袋的优点是客单价高、陈列整齐；缺点是香蕉后熟快，一旦过熟，整袋损耗大，且便利店顾客对“大袋水果”购买频次通常低于即食小包装。

3. **单根适合作为“即食引流品”，但不建议做主陈列**
   - 单根最适合放在收银台或鲜食区旁边，满足“顺手买一根”的需求。
   - 问题是客单价低、损耗和人工挑选成本相对高，且单根容易被顾客捏、碰，卖相下降。
   - 可以做，但建议限量、每日少量补货，作为补充而非主力。

**可执行的上架方案：**
- 主力：小把2–3根，定价按根均价比整袋略高，突出便利性。
- 补充：整袋3–5根，面向社区家庭，控制库存。
- 引流：单根放收银台，只摆少量，当天未卖完及时处理。
- 观察2周：看销量、损耗率、客单价。若小把销量占比最高且损耗可控，就扩大小把；若整袋复购明显，再增加整袋；单根若损耗高于毛利，就撤掉或改为预约/现拿。

**判断标准：**
- 损耗率超过10%–15%的包装形式，先缩量。
- 小把卖得动、整袋也有复购，就保留组合，不要只做一种。
- 夏天或门店冷藏条件有限时，更偏向小把和单根，减少整袋后熟风险。
