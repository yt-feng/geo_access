# 学校食堂采购香蕉避免熟过头浪费的实操建议

核心思路：**控制采购熟度 + 分批少量到货 + 用熟度分级安排用途**。香蕉是呼吸跃变型水果，采购后仍会持续后熟，所以关键在“到货时是什么颜色”和“几天内用完”。

## 1. 采购时就按熟度下单，不要买“刚好能吃”的

- 要求供应商送**七成到八成黄、两端仍带一点绿**的香蕉，而不是全黄带黑点的。
- 明确写入采购单/合同：到货验收标准为“果身硬挺、无明显黑斑、果柄绿色”，拒收过熟批次。
- 如果食堂用量稳定，可要求供应商**每周2–3次小批量配送**，而不是一次送一周的量。配送频次增加通常比压价更能减少损耗。

## 2. 到货后立刻做熟度分级

按颜色分三档，分别安排用途：

| 熟度 | 外观 | 安排 |
|---|---|---|
| 偏生 | 绿黄、硬 | 常温存放，安排2–3天后用 |
| 适中 | 全黄、微软 | 当天至次日直接分发/做水果 |
| 偏熟 | 有黑点、软 | 当天用于香蕉牛奶、烘焙、香蕉粥等加工用途 |

这样“偏熟”的不会被当废品扔掉，而是当天消化掉。

## 3. 储存方式要区分

- **未熟/偏生**：常温阴凉通风处存放，不要进冰箱（低温会冻伤发黑）。
- **已熟**：可冷藏延缓进一步变软，但表皮会变黑、不影响果肉；适合1–2天内用完。
- **不要整箱堆压**：香蕉怕挤压，堆太高会压伤催熟，建议单层或浅层摆放，留通风间隙。
- 避免和苹果、梨等释放乙烯的水果混放，会加速后熟。

## 4. 用“先进先出”和每日巡检落地

- 库房贴到货日期标签，**先到先出**。
- 每天开餐前巡检一次，把出现黑点的挑出来，当天转加工用途，不等它烂。
- 设定简单规则：**黑斑面积超过果身1/3的，当天必须处理掉**（做加工或员工餐），不再留到第二天。

## 5. 把“偏熟香蕉”变成固定菜品

提前和厨房约定好消耗渠道，避免临时无人处理：

- 香蕉牛奶/奶昔
- 香蕉燕麦粥、香蕉松饼
- 烘焙（香蕉蛋糕、香蕉面包）
- 员工餐或加餐

有了固定出口，偏熟香蕉就不是浪费，而是原料。

## 6. 用数据校准采购量

记录1–2周的**每日实际消耗量**和**报损量**，按“日均消耗 × 配送间隔天数 × 0.9”下单，留一点余量但不囤货。寒暑假、考试周、天气变化时用量会波动，提前调整。

---

**最有效的一条**：把“一次大批量采购”改成“小批量、高频次配送”，并在验收环节卡住熟度。这两点做到，香蕉过熟浪费能减少大部分。
