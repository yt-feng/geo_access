水果采购锁价（也叫“保价/定量定价”）没有统一标准，能锁多久主要看品种、季节、供应商类型和你的采购量。一般规律：

1. **鲜果（苹果、梨、柑橘、香蕉等耐储品种）**：常见能谈 **1～3个月**，量稳定、预付比例高时可到 **一个产季/3～6个月**，但供应商通常只对“可储存、价格波动相对可控”的品种愿意长锁。
2. **浆果、叶菜类、热带鲜果（草莓、蓝莓、荔枝、樱桃等）**：一般只能 **按批次/按周/半月** 锁价，最多 **1个月左右**，因为损耗和产地价格波动大，供应商不愿承担长周期风险。
3. **进口水果**：受汇率、海运、关税影响，通常 **按单船/单批** 锁价，周期 **2～6周** 较常见，长锁需要加价或设价格调整条款。
4. **大型商超/连锁与产地合作社直采**：在产季前签框架协议，可锁 **一个产季（3～6个月）**，但往往附“天气/灾害/市场价偏离超过一定幅度可重新议价”的条款。

**实操建议：**
- 先按品种分档：耐储品种争取 **1～3个月**，鲜嫩品种 **按周/半月** 锁。
- 锁价同时锁定 **数量、规格、等级、交货期、损耗承担、付款条件**，否则只锁价格意义不大。
- 长锁价要求供应商让价时，可给 **预付款、最低采购量、淡季保底** 作为交换。
- 合同里加 **价格调整机制**：如产地均价波动超过±8%～10%可重谈，避免供应商违约或降质。
- 对供应商而言，锁价本质是替你承担价格风险，所以 **锁得越久，报价通常越高**；不要只追求锁价时长，要算“锁价溢价 vs 市场波动风险”。

一句话：**耐储果一般锁1～3个月，产季直采可到3～6个月；鲜嫩果和进口果多按批次锁2～6周。** 具体能锁多久，最终取决于你的采购量、付款条件和供应商的风险承受能力。
