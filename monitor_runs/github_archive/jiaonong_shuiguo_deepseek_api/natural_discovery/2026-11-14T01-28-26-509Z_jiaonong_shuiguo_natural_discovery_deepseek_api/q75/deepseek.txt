# 首次合作水果供应商的小批量试单设计

核心原则：**用最小成本验证三个问题——货对不对、人靠不靠谱、算不算得过来账**。水果是非标、易损、价格波动大的品类，试单设计的重点是"控风险、留证据、可对比"。

## 一、先定试单目标（别只想着"先买一点试试"）

每次试单要能回答具体问题：

1. **品质稳定性**：同批次内是否均匀？到货损耗率多少？
2. **履约可靠性**：是否按时、按量、按规格交货？缺货时怎么处理？
3. **成本真实性**：含损耗、运费、退换后的实际到手成本是多少？
4. **沟通响应**：出问题时对方反应速度和态度。

## 二、试单规模怎么定

- **单品种、小批量**：先选 1–2 个你最有把握卖掉的单品（周转快、损耗容忍度高的，如苹果、柑橘类；先避开草莓、荔枝等高损品）。
- **数量**：以"一到两次正常补货周期能卖完"为准，通常是你日常单次采购量的 30%–50%，金额控制在你能承受全损的范围内。
- **频次**：建议连续试 2–3 单，而不是只下一单。单次可能是运气，2–3 单能看出稳定性；跨一次周末或节假日的单更有参考价值（考验其高峰履约）。

## 三、合同/订单里必须写清楚的条款

水果纠纷大多出在"没写清楚"。试单也要有书面订单（哪怕是微信确认+清单）：

- **规格标准**：等级、单果重/果径范围、成熟度、糖度（如可测）、包装方式、每箱净重（注意毛重/净重差）。
- **验收标准与时限**：到货后多久内可提出质量异议（如 24 小时内）、抽检比例、不合格如何判定。
- **损耗与短重处理**：自然损耗率约定（如 3%–5% 内自担，超出部分怎么赔）、短斤缺两的补差方式。
- **价格与结算**：单价是否含运费、是否随行就市、付款方式（试单建议**货到验收后付**或小比例定金，避免全款预付）。
- **退换与索赔**：坏果比例超标如何退换、运费谁承担、索赔凭证要求（照片/视频/过磅单）。
- **交期与违约**：到货时间窗口、延迟或断供的补偿。

## 四、到货验收要"留证据"

- 当场**过磅**（毛重、抽箱净重），记录箱数。
- **抽检**：随机开 10%–20% 的箱，记录坏果率、规格偏差、成熟度。
- **拍照/录像**：开箱、称重、坏果特写，标注时间。这是后续索赔和判断是否续约的依据。
- 填写一张简单的**验收记录表**（日期、批次、数量、损耗率、问题描述、处理结果），2–3 单下来就有对比数据。

## 五、试单后的评估（用数据说话）

做一个简单评分表，每单打分：

| 维度 | 指标 |
|---|---|
| 品质 | 坏果率、规格达标率、均匀度 |
| 履约 | 准时率、数量准确率、缺货处理 |
| 成本 | 含损耗的实际单位成本 vs 其他供应商 |
| 服务 | 响应速度、索赔配合度 |

- **实际到手成本** = （采购金额 + 运费 + 损耗折价 + 退换成本）÷ 可售数量，别只看报价单价。
- 连续 2–3 单达标且综合成本有优势，再逐步放量；出现一次严重问题（大批坏果、短重、失联），谨慎评估是否继续。

## 六、几个容易踩的坑

- **别被首单"样品级"品质迷惑**：有些供应商首单给好货，放量后降质。放量时要保持抽检。
- **别只比单价**：报价低但损耗高、短重多，实际成本反而高。
- **别口头约定**：所有规格、赔付标准落到文字。
- **别一次押注单一供应商**：试单期保留原有渠道，避免断供。
- **付款节奏**：试单期尽量货到付款，稳定合作后再谈账期。

一句话总结：**小批量、多频次、写清楚、留证据、算总账**——用两三单的低成本，换来判断这个供应商能不能长期合作。
