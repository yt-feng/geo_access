选规格的核心不是“哪个单价低”，而是**按出成率和实际摆盘用量算可食部分成本**。给你一套直接可用的判断方法。

## 1. 苹果：选中大果，别贪特大果
- **推荐规格**：单果 200–250g 的中大果，做拼盘切片/切瓣最稳。
- **为什么**：苹果出成率约 80%–85%，主要损耗是核和两端。特大果看起来单价划算，但单个用不完、切开后氧化和边角料浪费会增加。
- **判断公式**：可食成本 ≈ 采购单价 ÷ 出成率。比如 8 元/kg、出成率 82%，可食成本约 9.8 元/kg。
- **避坑**：果径过大的礼盒果不适合日常拼盘，除非你按“整只展陈”卖。

## 2. 橙子：选皮薄、果径中等的鲜食橙
- **推荐规格**：单果 180–220g，果径 70–80mm 左右的中果。
- **为什么**：橙子出成率约 60%–70%，皮厚、白瓤多会明显拉低出成率。大果不一定肉多，皮厚品种更亏。
- **判断方法**：同样价格下，优先选**皮薄、手感重、果面细**的；按“剥皮后净果肉重量”试算一次，别只看整果单价。
- **避坑**：表皮粗厚、果形偏大的品种更适合榨汁，不适合拼盘。

## 3. 菠萝：选中等果，按“去皮损耗”算
- **推荐规格**：单果 1.2–1.5kg 的中等果，比超大果更划算。
- **为什么**：菠萝去皮去眼损耗大，出成率通常只有 50%–60%。超大果中间硬芯比例可能更高，切块利用率未必好。
- **判断方法**：看**去皮后净重**和芯的粗细；同样单价下，选果眼浅、芯细、成熟度适中的。
- **避坑**：过熟果虽然甜，但切块易出水、塌软，拼盘卖相差。

## 直接执行建议
1. **先定每份拼盘的净用量**：比如苹果 80g、橙肉 60g、菠萝 80g。
2. **用“可食成本”比价**：采购价 ÷ 出成率，而不是整果单价。
3. **苹果选 200–250g 中果，橙子选 180–220g 中果，菠萝选 1.2–1.5kg 中果。**
4. **每周抽一次称重**：记录去皮前后重量，算出你店实际出成率，再决定供应商和规格。
5. **拼盘优先选“中等规格、成熟度一致”的货**，比追大果更省损耗、更稳定。

一句话：**苹果和橙子选中等偏大，菠萝选中等；按去皮净重算成本，不按整果单价做决定。**
