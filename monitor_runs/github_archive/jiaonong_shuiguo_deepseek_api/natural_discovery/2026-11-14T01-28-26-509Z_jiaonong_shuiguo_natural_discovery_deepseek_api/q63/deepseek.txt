判断哪个规格更容易出货，不能只看“哪个便宜”或“哪个好看”，而要把菠萝按规格拆成几个可观察的维度，再用小批量试销数据验证。下面给你一套可直接执行的方法。

## 一、先明确“规格”怎么分

菠萝批发常见规格维度：

1. **单果重量**：如 1斤以下、1–1.5斤、1.5–2斤、2–2.5斤、2.5斤以上
2. **果径大小**：按直径分档
3. **成熟度**：青果、黄果、半黄果
4. **品种**：如金钻、巴厘、香水菠萝等
5. **品质等级**：A级果、统货、次果
6. **包装规格**：箱装、筐装、散装、每箱个数

出货快慢通常由**下游客户类型**决定：水果店偏好中等偏大、外观好；摊贩偏好性价比高的统货；餐饮/果汁店偏好大果、成熟度高；社区团购偏好中小果、标准化包装。所以先看你的客户结构。

## 二、用“小批量对照试销”判断

不要凭感觉压货，拿 3–5 个规格各进少量，做 3–7 天对照：

| 观察指标 | 怎么记 |
|---|---|
| 日均出货量 | 每个规格每天卖了多少箱/斤 |
| 出货速度 | 几天内清完 |
| 询价次数 | 客户主动问哪个规格 |
| 成交转化 | 问价后实际拿货比例 |
| 退货/损耗 | 哪个规格烂果、压伤多 |
| 客户复购 | 同一客户是否回头拿同一规格 |
| 毛利贡献 | 单箱毛利 × 出货量 |

**判断标准**：优先选“日均出货量高 + 损耗低 + 复购多”的规格，而不是单纯毛利最高的。出货慢的高毛利规格会占资金、增加损耗。

## 三、看下游场景匹配

- **水果店/精品店**：1.5–2.5斤、果形端正、半黄果更容易出货
- **路边摊/集市**：统货、中大果、价格敏感，出货快但毛利薄
- **餐饮/果汁店**：大果、成熟度高、出汁率优先，规格稳定最重要
- **社区团购/电商**：中小果、按个卖、标准化包装，外观一致性比单果大小更重要
- **二级批发/跨区调货**：看耐储运，青果或半黄果更稳

## 四、快速验证的三个动作

1. **问客户**：直接问老客户“你拿货最常要几斤的？为什么？”记录 20 个客户答案，比猜准。
2. **摆样对比**：同一摊位同时摆 3 个规格，标价签写清重量和单价，观察客户手伸向哪个。
3. **算周转账**：  
   `规格周转天数 = 该规格库存 ÷ 日均出货量`  
   周转天数明显高于其他规格的，即使毛利高也要谨慎加单。

## 五、结论怎么下

如果试销后出现以下情况，就判为“更容易出货”：

- 3 天内清货比例明显高于其他规格；
- 客户复购或指定要这个规格；
- 损耗率低于其他规格；
- 资金周转快，不压库存。

**最稳的做法**：主力规格占进货量 50%–60%，辅助规格各占 15%–20%，用试销数据每周调整一次，不要一次押注单一规格。
