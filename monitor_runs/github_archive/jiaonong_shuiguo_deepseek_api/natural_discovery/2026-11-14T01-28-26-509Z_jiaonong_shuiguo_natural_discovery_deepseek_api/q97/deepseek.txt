酒店采购水果盘原料时，建议把要求写进订单/验收单，按“规格+成熟度+外观+安全+包装”五类验收。可直接采用以下标准框架：

1. **规格标准**
- 按品种明确单果重量/直径/长度范围，如苹果直径75–85mm、橙子单果180–220g、西瓜单瓜4–6kg。
- 同批次大小均匀，允许偏差建议不超过±10%。
- 明确可食率、去皮损耗上限，如菠萝去皮损耗≤45%、西瓜可食率≥60%。
- 切配类原料明确切块尺寸、厚度、每份克重，如水果盘每份净重200g±5g。

2. **成熟度标准**
- 到货成熟度以“当天可切配、2–3天内可用”为准，避免过生或过熟。
- 香蕉、芒果、牛油果等后熟水果按“青熟/黄熟”分级，明确到货颜色和硬度。
- 草莓、蓝莓、葡萄等即食水果要求充分成熟但无软烂、渗汁。

3. **外观标准**
- 果实完整、形状正常，无畸形、裂口、机械伤、虫眼、病斑、霉变。
- 表面洁净，无泥土、药斑、明显水锈；允许轻微自然瑕疵但不影响切配和卖相。
- 色泽符合品种正常颜色，无大面积青斑、褐变、日灼。
- 叶菜类配叶新鲜、无黄叶、萎蔫；装饰用薄荷、迷迭香等香草要求叶片完整、无黑斑。

4. **食品安全与理化标准**
- 农残符合GB 2763《食品安全国家标准 食品中农药最大残留限量》，供应商提供批次检测报告或承诺书。
- 重金属、霉菌毒素等符合对应国标；不得使用非法保鲜剂、染色剂、甜蜜素浸泡。
- 预切水果原料应符合即食类卫生要求，冷链到货温度建议0–4℃，并记录温度。
- 供应商具备营业执照、食品经营/生产许可，进货票据和批次可追溯。

5. **包装与交付标准**
- 使用食品级周转箱或包装，内衬清洁，无破损、无污染；标明品名、产地、批次、到货日期。
- 冷藏/常温运输要求分开，避免挤压、日晒、雨淋和串味。
- 到货验收抽检比例建议不低于10%，重点查成熟度、软烂、霉变、异味和温度记录。
- 不合格处理：轻微瑕疵可折价或挑拣使用；霉变、异味、农残超标、严重机械伤应整批拒收。

建议在采购合同中附《水果原料验收标准表》，按品种列明单果规格、成熟度、允许缺陷比例（如次果率≤5%、霉变率为0）、检测报告要求和拒收条款，验收时按表逐项签字确认。
