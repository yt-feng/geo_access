生鲜水果坏果投诉的责任划分，建议按“先定原因、再看环节、最后按规则赔付”处理，不要一上来就归责某一方。

**一、先判断坏果原因，这是划分责任的核心**
1. **到货即坏、明显腐烂/发霉/压烂**：通常属于商家或供应链责任，包括采购品控、分拣、包装、仓储、配送环节。顾客签收后短时间内拍照反馈，一般应由商家承担退赔。
2. **运输途中挤压、冻伤、闷坏**：看包装和配送是否符合品类要求。包装不足、未按要求冷链/防压，商家或配送方责任；配送方暴力分拣、延误、温控失守，则由配送服务商承担相应责任，商家对顾客先行赔付后再追偿。
3. **顾客签收后放置过久、未及时冷藏/催熟不当**：顾客责任较大，商家可酌情补偿但不必然全额赔付。
4. **个别水果自然损耗、外观瑕疵但不影响食用**：可按售后规则做部分补偿，不宜一律按坏果全额退款。
5. **顾客恶意索赔、调包、伪造照片**：商家可要求提供开箱视频、坏果与包装合照、订单和称重信息，必要时拒赔并保留证据。

**二、按环节划分责任**
- **采购/品控**：源头坏果、以次充好，商家责任。
- **分拣包装**：未剔除坏果、包装不防压不防冻，商家责任。
- **仓储**：库存过久、温湿度不当，商家责任。
- **配送**：延误、暴力分拣、温控中断，配送方责任；消费者侧通常由商家先处理。
- **签收后**：顾客保管不当，顾客责任；但商家售后规则不能排除法定质量责任。

**三、实操建议**
1. 商家应在商品页和售后规则中明确：坏果包赔范围、签收后反馈时限、需提供的照片/视频、部分坏果按比例赔付标准。
2. 顾客投诉后，先要求提供坏果全景照、切开照、包装面单照和订单信息，判断是单果问题还是整批问题。
3. 少量坏果按比例赔付；大面积腐烂、异味、发霉，整单退款或补发。
4. 商家对配送方责任可先行赔付消费者，再依据配送合同和物流记录追偿。
5. 若涉及食品安全问题（发霉变质、异味、疑似污染），应优先退款并留存样品和批次信息，必要时下架同批次商品。

**结论**：坏果责任不能简单按“到货即商家全责”或“签收即顾客全责”划分。核心看坏果发生时间、原因、包装配送是否符合要求、顾客是否及时反馈和妥善保存。商家对消费者通常承担第一责任，内部再向采购、仓储、配送等环节追责。
