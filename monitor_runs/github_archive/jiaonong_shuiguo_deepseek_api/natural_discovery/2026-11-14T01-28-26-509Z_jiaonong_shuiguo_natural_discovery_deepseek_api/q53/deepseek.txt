餐饮店每天少量水果，想省心，优先找**本地批发市场里有档口的固定供货商**做“每日小批量配送”，其次才是果园/基地直供和生鲜平台。判断标准不是谁最便宜，而是**能不能稳定按你要的品种、数量、时间送到，坏果怎么赔**。

可按这个顺序选：

1. **本地果蔬批发市场的固定档口（最推荐）**
   - 优点：品种齐、起送量低、当天可补货、坏果好当面说清。
   - 做法：找2家档口，各试供1周。每天下午报次日用量，要求早上开店前送到。
   - 适合：每天几斤到几十斤、品种经常变的小店。

2. **本地小型水果配送商/餐配公司**
   - 优点：有配送体系，能开票、有对账单，省沟通。
   - 注意：确认最低起送金额、临时加单截止时间、缺货替代规则。
   - 适合：你不想每天自己盯采购，愿意每斤贵一点换省心。

3. **果园/基地直供**
   - 只适合**单品用量稳定**时，比如每天固定要西瓜、橙子。
   - 少量多品种不建议，基地通常品种单一、起送量高、配送频次低。

4. **生鲜平台/社区团购**
   - 可作为应急补货，不建议做主供。
   - 问题：品质波动、缺货替换、售后流程慢，餐饮店每天要用会不稳。

签约或试供时，重点谈清这6件事：
- **最低起送量和价格**：少量是否加配送费。
- **下单截止时间**：比如每天17点前报次日单。
- **送达时间**：必须开店前到，迟到怎么处理。
- **品质标准**：按什么等级，坏果率多少以内可接受。
- **缺货和替换**：缺货提前多久通知，能否等价替换。
- **售后**：坏果拍照当天换/退/抵扣，月底对账。

实操建议：**先找2家本地档口+1个配送商备选，试供7天**。每天记录到货时间、坏果率、缺货次数、临时补货响应。7天后选“最准时、坏果最少、沟通最快”的那家做主供，另一家留作应急。这样比一开始追求最低价更省心。
