通常**直接买成品果丁的“原料损耗率”更低，但不一定总成本更低**。要看你把“损耗”算到什么口径。

### 结论
- **只看可食部分损耗/出成率**：成品果丁更低。  
  鲜菠萝要去皮、去眼、去芯，出成率通常明显低于成品果丁；成品果丁已经把这些不可食部分在供应商端去掉了。
- **看综合损耗（含报废、过期、品质不稳、二次污染）**：鲜果切配和成品果丁各有风险，成品果丁不一定绝对低。  
  成品果丁的风险主要在**保质期短、到货品质波动、开袋后氧化出水、用不完报废**；鲜果切配的风险主要在**人工切配损耗、切配不标准、存放氧化、员工操作污染**。

### 怎么判断你店该选哪个
用这个简单公式算：

**综合损耗率 =（采购重量/金额 − 实际用于出品的重量/金额）÷ 采购重量/金额**

把以下都算进去：
1. 去皮去芯损耗；
2. 切配后未用完报废；
3. 氧化、出水、变色导致的弃用；
4. 到货不合格退货或降级使用；
5. 人工切配时间成本（鲜果才有的隐性成本）。

### 实务建议
- **日销量稳定、菠萝用量大**：鲜果切配更可控，长期成本往往更低，但要把切配标准和出成率管住。
- **用量小、品种多、人工紧张、后厨空间小**：成品果丁综合损耗通常更低，因为不用承担整果不可食部分和切配人工。
- **成品果丁一定要测**：到货净重、沥水后重量、开袋后24小时出水率、保质期内报废率。很多店忽略“果丁出水”造成的实际可用量下降。
- **鲜果一定要定出成率**：按批次称重记录“毛重→去皮去芯后净重→切丁后可用重”，算出真实出成率，再和成品果丁的净可用成本比较。

**一句话：原料损耗上成品果丁通常更低；综合损耗和总成本要看你的销量、人工和周转速度。用量大且周转快，鲜果切配常更划算；用量小且人工贵，成品果丁更稳。**
