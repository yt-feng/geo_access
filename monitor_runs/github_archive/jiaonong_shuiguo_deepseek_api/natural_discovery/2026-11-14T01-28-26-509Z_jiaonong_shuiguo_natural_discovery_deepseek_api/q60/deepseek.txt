# 水果到货不合格的补货约定要点

核心思路：**把“不合格”的判断标准、通知时限、补货时限、缺货期间的替代方案都写进采购合同或供货确认单**，到货时按条款执行，就不用临时扯皮影响营业。

## 一、先约定“不合格”的判定标准（避免争议）

- **量化验收标准**：按品类写明（如水果外观、大小、成熟度、糖度、腐烂率上限、虫害、异味等），最好附验收标准表作为合同附件。
- **抽检规则**：明确抽检比例（如每批次抽检10%）、不合格判定阈值（如抽检不合格率超过5%即整批拒收）。
- **验收时限**：到货后多久内完成验收（如2小时内），超时未提出视为合格——这对双方都有约束。

## 二、约定补货机制（关键条款）

1. **补货时限**：不合格批次须在“通知后X小时内”补送到店（如当日营业高峰前，或24小时内），并写明起算点（以书面/微信通知时间为准）。
2. **补货优先级**：约定供应商对不合格批次“优先补货”，不得因其他订单延后。
3. **补货方式**：换货、补发或退款三选一，由店方根据缺货情况选择；紧急缺货时店方可先行自采，差价由供应商承担（需约定自采价格上限或比价规则）。
4. **二次不合格处理**：补货仍不合格的，店方有权取消该批次并索赔，或终止合作。
5. **费用承担**：不合格品的退换货运费、损耗由供应商承担。

## 三、保障“不影响营业”的配套条款

- **安全库存与备用供应商**：合同约定供应商保证常用品类的最低供货量；店方自己保留1–2家备用供应商，合同里不必写，但运营上要有。
- **紧急替代授权**：约定缺货时店方可用同类替代品，供应商承担差价（设上限）。
- **违约金/扣款**：补货超时的，按批次金额比例扣款或赔付停售损失（写清计算方式，如按该品类日均销售额×缺货天数）。
- **通知方式**：明确微信、邮件、电话哪种有效，保留到货照片、验收记录作为证据。

## 四、落地建议

- 把这些条款做成**一页纸的《到货验收与补货确认单》**，每次送货随单签字，比长篇合同更实用。
- 首次合作先小批量试供，观察补货响应速度再谈长期条款。
- 所有不合格记录留档，作为后续压价或换供应商的依据。

一句话：**标准量化、时限写死、替代方案备好、违约有代价**，补货就不会拖累营业。
