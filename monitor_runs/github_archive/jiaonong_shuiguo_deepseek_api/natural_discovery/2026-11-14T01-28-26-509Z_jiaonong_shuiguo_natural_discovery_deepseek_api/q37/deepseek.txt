商超做会员日水果活动，供应商至少要提前配合六类准备，重点是“锁定货量、品质、价格、到货节奏和现场支持”，避免活动当天缺货、品质波动或价格穿帮。

**1. 货量与备货计划**
- 按商超给出的会员日预估销量、历史同期数据和主推单品，提前锁定货源。
- 对易缺货单品准备备选产地/备选规格，明确“主供+备用”比例。
- 提前确认采摘、分选、包装、发运周期，尤其是进口果、高端果和短保果。
- 活动前1—2天完成到货，避免当天集中到货造成验收拥堵。

**2. 价格与促销政策**
- 提前锁定会员日供货价、促销价、毛利空间和费用承担方式。
- 明确是否含税、含运费、含损耗，避免结算争议。
- 确认价格保护周期，防止活动前或活动中其他渠道低价冲击。
- 对限量、秒杀、买赠等玩法，明确供应商承担比例和库存上限。

**3. 品质标准与验收**
- 提前书面确认规格、等级、糖度、果径、成熟度、色泽、瑕疵率、包装方式。
- 活动专供果建议提前送样确认，避免“样品好、大货差”。
- 明确验收标准、扣罚规则、拒收和补货责任。
- 短保水果要控制成熟度，避免活动前段偏生、后段过熟。

**4. 到货节奏与物流**
- 按门店或DC拆分到货计划，明确到货时间窗、卸货预约和车辆要求。
- 活动高峰期建议分批次到货，主推单品至少准备一轮补货。
- 明确冷链/常温运输要求、温控记录和异常处理联系人。
- 准备应急补货方案，明确补货响应时间和最小补货量。

**5. 包装、陈列与物料**
- 提前准备活动装、家庭装、果切/礼盒等适配包装。
- 提供陈列建议、POP素材、卖点话术、试吃物料或试吃果。
- 对主推单品可安排促销员/理货员驻场支持，尤其是高单价或需试吃转化的品类。
- 包装日期、产地、等级、追溯信息要合规清晰。

**6. 人员对接与应急预案**
- 提前指定供应商活动负责人，与商超采购、门店、DC收货保持单一对接。
- 活动前完成库存、价格、到货、品质四项确认会。
- 准备缺货替代方案、品质异常补货方案、天气/交通延误预案。
- 活动期间安排值班，确保早高峰前和补货节点能快速响应。

**可执行检查清单：**
活动前7天锁货量和价格；前5天确认品质标准和包装；前3天确认到货计划与门店分配；前1天完成到货或首轮补货；活动当天安排驻场或值班；每天复盘销量、缺货和品质问题，及时调整次日补货。

最关键的是把“供货价、货量、品质标准、到货时间、补货责任”五项写成书面确认，避免口头承诺。
