线上卖水果，坏果和口感不稳定主要不是“运气问题”，而是采购标准、产地选择、采收成熟度、包装物流四个环节没卡住。可以按下面做：

**1. 先定可验收的采购标准，不要只说“要好的”**
- 按品种写清：单果重/果径、糖度下限、酸度范围、着色度、软硬度、瑕疵允许比例。
- 例如坏果率、机械伤率、裂果率、日灼斑、虫眼，分别设上限；到货抽检不合格就拒收或扣款。
- 口感用“糖酸比+成熟度”控制，不只看甜度。太甜但发软、没香气，线上复购照样差。

**2. 产地和供应商要选“稳定”而不是“最低价”**
- 优先选有分级线、冷库、预冷能力的合作社/基地，而不是临时散户拼货。
- 同一品种固定2—3个供应商，主供+备供，避免单一产地天气波动导致断供或降标。
- 要求供应商提供采收批次、采摘日期、分级记录；连续跟踪到货合格率，按数据淘汰。

**3. 采收成熟度按物流距离倒推**
- 远距离发货选耐储运品种和七至八成熟采收；同城/短途可适当提高成熟度换口感。
- 不要为了“到货刚好熟”统一催熟所有批次，催熟不均会直接造成口感波动。
- 易软品种做预冷，采后尽快降温，减少田间热。

**4. 包装和物流按“抗压+防震+透气”设计**
- 单果网套/纸托+分格，避免果与果直接碰撞；箱内留缓冲，不晃动。
- 浆果类加吸水纸、透气孔，防冷凝水导致霉变；不要密封闷箱。
- 夏季避开高温时段发运，优先冷链或次日达；偏远地区设发货限制，别硬接单。

**5. 到货和售后数据要反哺采购**
- 每批抽检记录：坏果率、软果率、糖度、口感反馈、客诉原因。
- 把“坏果赔付率”“口感差评率”按供应商/产地/批次统计，连续两批超标的降级或停采。
- 售后不要只赔钱了事，要区分是采购成熟度问题、包装问题还是物流延误，否则问题会重复。

**6. 用SKU策略降低风险**
- 新手先做耐储运、口感容错高的单品，如苹果、橙子、梨；浆果、软桃、荔枝等高损耗品先小批量测试。
- 预售制+按单采货，减少库存积压；对高损耗品设置区域和时效限制。

核心一句话：**采购时把“坏果率、糖酸度、成熟度、抗压包装、到货时效”写成可抽检的合同标准，并用批次数据淘汰不稳定供应商。** 这样差评才会从“不可控”变成“可管理”。
