做小区团购，水果供应商最关键不是“能不能供货”，而是能不能支撑你低损耗、可预售、能履约。建议重点确认以下服务：

1. **小批量、多频次配送**
   - 能否支持每天/隔天送，单次起送量多少。
   - 能否送到店里或指定自提点，配送费怎么算。
   - 临时加单、减单的截止时间。

2. **预售锁货与库存保障**
   - 团购通常是先收款后采购，供应商能否按你的截单量锁货。
   - 缺货时是否提前通知，能否同价替换或补发。
   - 爆单时有没有稳定备货能力。

3. **分拣与预包装服务**
   - 能否按“每份/每袋/每盒”分装，贴标签。
   - 能否做团购标准份，比如5斤装、家庭装、尝鲜装。
   - 分拣费、包装费谁承担，损耗怎么算。

4. **品质分级与售后兜底**
   - 明确果径、甜度、成熟度、瑕疵率标准。
   - 坏果、烂果、缺斤少两怎么赔，是否包退换。
   - 售后响应时限，能否先赔后补，避免你在群里被客户追。

5. **价格与账期支持**
   - 团购价是否稳定，是否给小区团专属价。
   - 是否支持货到付款、周结、月结或押金合作。
   - 价格波动时提前多久通知。

6. **退换货和尾货处理**
   - 当天未卖完或品质不达标的货能否退换。
   - 尾货能否调换其他品类，降低你的损耗。

7. **营销素材与选品支持**
   - 能否提供水果图片、视频、卖点、产地信息、保存方法。
   - 能否按季节推荐适合团购的爆品和组合套餐。
   - 是否支持试吃样品。

8. **冷链与保鲜能力**
   - 易坏水果是否有冷链或保鲜配送。
   - 夏季高温、冬季防冻有没有对应措施。
   - 到货时间是否避开你分拣和配送高峰。

9. **稳定供应与应急能力**
   - 主推单品断货时有无替代方案。
   - 节假日、天气异常时能否保供。
   - 是否有备用产地或备用供应商。

10. **对账与数据支持**
   - 每批货能否提供明细单：品名、规格、数量、单价、损耗、售后。
   - 能否按团购批次对账，方便你核算毛利和佣金。

你真正要谈进合同或合作确认单里的，建议是这5条：**起送量和配送频次、分拣包装标准、坏果赔付标准、缺货替换规则、结账账期**。这五项定清楚，小区团购才不容易被售后和损耗拖垮。
