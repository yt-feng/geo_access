判断一批香蕉，核心看“颜色—手感—果指状态—切口—气味”五项，并结合季节和运输方式判断坏果风险。以下是可现场执行的方法。

## 1. 看颜色：判断整体熟度
- **全绿、棱角明显**：生蕉，适合长途运输或催熟后批发；但若温度低、受冷，可能出现“僵蕉”不熟。
- **绿中带黄、果身开始变圆**：开始转熟，通常适合计划3–5天内出货。
- **黄多绿少、果指饱满**：已进入可售熟度，适合短线快批；需看是否已出现糖斑。
- **全黄带少量糖斑**：熟度高，适合尽快出货；糖斑多且扩大，坏果风险上升。
- **大面积黑斑、果柄发黑、果指软塌**：过熟或已开始腐烂，不建议大批拿。

> 注意：夏天或运输温度高时，看似“黄绿”的货可能内部已软；冬天或冷链过冷时，绿蕉可能外表正常但内部冻伤。

## 2. 摸手感：判断内部软硬和是否冻伤
- 轻捏果指中段：
  - **硬挺有弹性**：正常生到半熟。
  - **均匀微软**：熟度合适，但要看批次用途。
  - **局部软、发水、发绵**：可能压伤、冻伤或内部开始坏。
  - **整把发软、果柄软**：过熟，坏果风险高。
- 摸果身温度：明显冰凉且手感发水，警惕冷链过冷或冻伤。

## 3. 看果指和果柄：判断机械伤与腐烂风险
- **果柄**：青绿、干燥、无霉点为好；发黑、发霉、渗液说明伤口感染风险高。
- **果指棱线**：棱角明显偏生；果身圆润偏熟。
- **果指表面**：少量黑点可能是正常糖斑；但黑点凹陷、扩大、连片，或流汁，是坏果信号。
- **果指之间有压痕、破皮、裂口**：机械伤会在1–3天内转黑腐烂，尤其夏季。
- **整把是否过紧**：过紧且果指间潮湿，容易闷出霉。

## 4. 看切口和箱内情况：判断批次风险
- 切口新鲜、无褐变、无霉毛为好。
- 箱底、纸垫、包装袋内是否有汁液、黑水、霉点：有则说明已有坏果污染。
- 抽底层和中间层：表层常被挑过，底层更能反映真实风险。
- 同一箱内若已有多个果指软塌、流汁，整箱坏果扩散风险高。

## 5. 闻气味：快速识别隐性坏果
- 正常：清淡青味或果香。
- **酒味、酸味、霉味**：内部已发酵或霉变，整批需谨慎。
- 有酒味但外观尚可，常见于高温闷过的货，后续坏果会快速增加。

## 6. 按季节和运输判断风险
- **夏季/高温运输**：熟得快，黄蕉风险高；优先拿绿中带黄、果身硬挺、无压伤的货，缩短周转。
- **冬季/冷链过冷**：警惕冻伤。冻伤香蕉外表可能正常，但手感发水、果心发黑，催熟后易烂。
- **长途运输**：拿棱角明显、绿度高的货，但需确认未受冷。
- **短途快批**：可拿黄多绿少、少量糖斑的货，但当天或次日要出货。

## 7. 现场抽样建议
- 每批至少抽 **3–5箱**，每箱看表层、中层、底层。
- 每箱随机捏 **5–10根**，重点捏果指中段和果柄附近。
- 记录：颜色级别、软硬、黑点类型、切口、气味、箱内汁液。
- 若抽样中 **软塌/流汁/霉变果超过约5%**，整批坏果风险明显偏高，应压价、拒收或要求换货。

## 快速结论
**优先拿：** 果柄青绿干燥、果身硬挺有弹性、绿中带黄、棱角尚存、切口干净、无酒味、箱内干燥的货。  
**谨慎或拒收：** 果柄发黑发霉、果指局部软塌流汁、黑点凹陷连片、箱底有黑水、有酒味酸味、手感发水冰凉的货。
