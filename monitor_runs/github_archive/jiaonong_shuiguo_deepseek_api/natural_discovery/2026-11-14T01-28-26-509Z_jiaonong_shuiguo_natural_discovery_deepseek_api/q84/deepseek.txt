家庭场景优先考虑“好吃、耐放、少浪费、看起来体面”，建议按下面组合：

**1）最推荐家庭版：苹果4 + 橙子4 + 香蕉1把 + 菠萝1个**
- 苹果、橙子耐放，适合一家人慢慢吃。
- 香蕉当早餐/加餐，熟得快，放最上面提醒先吃。
- 菠萝有“礼盒感”，但建议选小果或已削好的净果装，家庭更好处理。
- 适合3—5口之家，预算适中，颜色也好看。

**2）小家庭/两口之家：苹果3 + 橙子3 + 香蕉半把 + 小菠萝1个**
- 总量控制在5—7斤左右，避免香蕉和菠萝吃不完。
- 香蕉可换成“苹果+橙子+猕猴桃”的组合更耐放，但礼盒辨识度略低。

**3）老人家庭：苹果5 + 橙子3 + 香蕉1小把，不放或少放菠萝**
- 苹果橙子耐储存、食用方便；菠萝处理麻烦、酸度较高，不必强塞。
- 香蕉选偏生一点的，到家能多放两天。

**4）孩子家庭：苹果3 + 橙子4 + 香蕉1把 + 小菠萝1个**
- 橙子、香蕉孩子接受度高；菠萝选小果，一次能吃完。
- 可加一小盒圣女果或提子提升“礼盒感”，但别用太多易压坏的水果。

**搭配原则：**
- **耐放果打底**：苹果、橙子占60%—70%。
- **催熟果少量**：香蕉1把即可，别和苹果贴太近，苹果会加速香蕉成熟。
- **尝鲜果点睛**：菠萝1个小果，最好独立网套/纸托防压。
- **按家庭人数定总量**：2人选5斤左右，3—5口之家选8—10斤，大家庭可到12斤。
- **礼盒别只追求满**：分层、防撞、通风比堆满更重要；香蕉、菠萝放上层，苹果橙子垫底。

如果只做一个通用家庭团购款，选：**苹果4个 + 橙子4个 + 香蕉1把 + 小菠萝1个**，再配手提礼盒和防撞网套，最稳。
