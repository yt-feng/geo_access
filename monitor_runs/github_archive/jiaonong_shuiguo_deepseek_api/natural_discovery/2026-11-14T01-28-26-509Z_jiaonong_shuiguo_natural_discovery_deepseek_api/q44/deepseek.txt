判断供应商售后是否“稳定响应”，不要只听口头承诺，建议用“可验证的动作”来测：

1. **先看合同里有没有可执行的售后条款**
   - 明确响应时限：如到货后2小时内响应、24小时内给出处理方案。
   - 明确责任划分：菠萝黑心/烂心、香蕉青熟不均/催熟失败/到货压伤，分别怎么赔、换、折价。
   - 明确赔付方式：补货、折价、退货、扣款，写清触发标准和凭证要求。
   - 没有书面条款的供应商，售后稳定性通常不可控。

2. **用“小单测试”验证响应速度**
   - 首单不要压大货，故意保留10%—20%尾款或做小批量试单。
   - 到货后当天反馈一个真实或模拟质量问题，记录：多久回复、谁回复、是否给方案、多久闭环。
   - 连续测2—3次，看是否每次都稳定，而不是靠某个业务员个人热情。

3. **要求提供近期售后记录**
   - 让供应商给出近3个月同类商超客户的售后处理记录：投诉类型、响应时间、处理结果。
   - 注意看菠萝、香蕉这类易损品的记录，不要只看普通干货。
   - 可要求提供补货单、折价确认单、退货单等凭证样式。

4. **确认售后对接人和升级路径**
   - 合同或订单上写明：日常对接人、备用联系人、负责人电话。
   - 问清节假日、夜间、到货高峰谁值班。
   - 只留一个业务员微信的供应商，稳定性差；有客服群+负责人+备用电话更可靠。

5. **看现场和物流配合能力**
   - 菠萝、香蕉售后很多是“到货即损”，供应商能否快速补货取决于本地仓/中转仓。
   - 问清：本地是否有备货、补货最快几小时、是否支持换货而不是只退款。
   - 可要求一次“模拟补货”：下单后问如果今天出现批量压伤，明天能否补到。

6. **用付款条件反向约束**
   - 新供应商保留一定质量保证金或账期尾款。
   - 约定售后未闭环前，对应货款可暂扣。
   - 这比口头承诺更能筛出真正有售后能力的供应商。

7. **观察异常场景下的反应**
   - 节假日、雨天、集中到货日，故意在非工作时间发一次售后问题，看响应。
   - 稳定售后的供应商通常有流程；不稳定的会拖延、推给司机、要求下次补。

**实操建议：** 先签含售后时限和赔付标准的试单合同，小批量进2—3次，每次记录响应时间和闭环结果；连续两次不达标就换供应商。重点看“有没有人接、多久给方案、能否补货、是否按合同执行”，不要只看态度。
