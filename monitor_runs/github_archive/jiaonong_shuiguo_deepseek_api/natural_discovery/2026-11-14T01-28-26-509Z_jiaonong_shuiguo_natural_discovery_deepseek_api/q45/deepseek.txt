连锁超市和水果供应商签年度合同，水果品类有鲜度损耗、价格波动、季节供给和食品安全几个特殊风险点。最容易踩坑的条款大致有这几类：

**1. 价格与调价机制**
- 只签“年度框架价”却不定调价规则，旺季或减产时供应商要么断供要么逼你接受涨价。
- 建议写明：基准价 + 参考哪个公开行情（如当地批发市场均价、产区收购价指数）+ 调价触发幅度（如波动超5%方可调）+ 调价提前通知期（如7天）+ 双方确认方式。
- 警惕“随行就市”四个字，没有量化标准等于没约定。

**2. 质量标准与验收**
- 只写“符合国家标准”太粗，水果要写具体：品种、规格（单果重/直径）、糖度、成熟度、外观缺陷率、农残检测要求。
- 验收环节最容易扯皮：谁验、在哪验、多长时间内提出异议、不合格怎么处理（拒收/降级/折价）、损耗率在途由谁承担。
- 建议约定验收时限（如到货2小时内）、异议提出方式（书面+照片），以及“超过时限未提异议视为合格”的边界。

**3. 损耗与退换货**
- 水果损耗高，必须明确：运输途中损耗率上限（如3%以内供方承担）、门店端自然损耗由谁承担、临期或变质品的退换货责任和时限。
- 避免笼统写“质量问题包退换”，要区分是供货质量问题还是门店储存问题。

**4. 供货量与最低采购承诺**
- 超市常被要求“年度最低采购量”，但水果受季节和销售波动影响大。若承诺量过高，卖不动也要按量付款，风险很大。
- 建议：最低采购量设弹性区间，或按季度/月度分解并允许一定比例的调整；同时约定供应商的保供义务（缺货违约金、替代品方案）。

**5. 账期与结算**
- 账期、对账周期、发票开具时间、逾期付款责任要写清。水果供应商多为中小户，账期过长可能影响其供货稳定性，反过来拖累你。
- 注意“质量扣款”“损耗扣款”的扣款规则和上限，避免结算时单方随意扣减。

**6. 食品安全与责任**
- 农残超标、食安事故的责任划分和赔偿机制必须明确，包括供应商的检测报告义务、追溯配合义务、事故赔偿上限或按实际损失赔。
- 建议要求供应商提供每批次检测报告，并约定抽检不合格的处理（退货、罚款、解除合同）。

**7. 独家/排他条款**
- 供应商可能要求“区域独家供货”，这会限制你比价和备选供应商。若非必要不签排他；要签就限定品类、区域和期限，并保留“供应商断供或质量不达标时可另寻货源”的例外。

**8. 合同期限与退出机制**
- 年度合同要写清：提前解约条件、违约金、库存处理、未履行订单的处理。水果季节性强，最好允许按季度评估、约定不达标的退出路径。

**9. 不可抗力与天气风险**
- 水果受天气、灾害影响大，不可抗力条款要具体（哪些情形算、通知义务、是否免责、是否可调价或减量），避免供应商借“不可抗力”随意断供或涨价。

**10. 争议解决与管辖**
- 约定管辖法院或仲裁机构，尽量选自己所在地，降低维权成本。

**实操建议**：签约前把“价格公式、验收标准、损耗分担、最低采购量弹性、食安责任”这五条作为谈判重点逐条落到数字和流程上；合同中避免“另行协商”“合理损耗”“市场价”这类模糊表述，凡是能量化的都写数字，凡是流程都写清时限和书面形式。
