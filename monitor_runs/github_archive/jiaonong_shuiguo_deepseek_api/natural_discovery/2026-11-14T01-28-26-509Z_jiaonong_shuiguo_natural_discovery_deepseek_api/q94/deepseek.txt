很重要。对便利店来说，供应商能否支持小批量试卖，直接决定水果品类能不能把损耗和缺货同时压下来。

判断上可以看两点：

1. **水果销量不稳定的核心是损耗，不是进货价。**  
   水果保质期短、单店日均销量波动大。一次性大批量进货，卖不动就是报损；只按保守量进，又容易缺货、丢销售。小批量试卖是用较低成本换真实动销数据。

2. **小批量支持不只是“少送一点”，还要看配套条件。**  
   真正有用的是：起订量低、配送频次高、可拆零、允许短期调换/补货、有明确报损责任或退换机制。只降低起订量但配送跟不上，试卖意义也有限。

所以供应商支持小批量试卖很重要，但重点不是“能不能少量进”，而是**能否用低门槛、较高频次、可调整的供货方式，帮你测出单店真实动销并控制损耗**。如果供应商只能整箱压货、配送周期长、不退不换，那试卖价值就很低。
