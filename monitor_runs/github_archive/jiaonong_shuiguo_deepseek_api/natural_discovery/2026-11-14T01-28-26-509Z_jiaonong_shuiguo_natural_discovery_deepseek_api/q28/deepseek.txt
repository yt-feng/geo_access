建议先从**香蕉**试起，但前提是把它当作“流量和周转测试品”，而不是高毛利品。更稳的组合是：**香蕉做引流和周转，苹果做稳定毛利，菠萝后置或小批量试销**。

判断顺序：

1. **香蕉：最适合先引入**
   - 消费频次高、认知门槛低，顾客不需要教育。
   - 周转快，能直接检验超市的进口水果供应链、到货成熟度、损耗控制。
   - 风险点：成熟度难控、货架期短、损耗高。建议先小批量、高频补货，控制催熟和陈列温度，不要一次性压大货。

2. **苹果：适合作为第二个稳定品类**
   - 货架期长、损耗低、价格带容易做，适合建立稳定毛利和复购。
   - 进口苹果品种多，先选1—2个辨识度高的单品，不要铺太宽。
   - 风险点：国产苹果替代性强，必须靠稳定品质、分级和陈列说明差异，否则容易变成价格战。

3. **菠萝：不建议最先做**
   - 损耗和操作要求更高，成熟度、去皮/鲜切、售后投诉都更复杂。
   - 如果超市没有鲜切能力或稳定冷链，先上菠萝容易把损耗吃掉利润。
   - 可以做小批量试销或鲜切引流，但不要作为首个稳定进口单品。

可执行建议：
- **第一周**：只上1个进口香蕉SKU，小批量日配，记录到货成熟度、日销量、损耗率、缺货次数。
- **第二到四周**：若香蕉周转稳定，加入1个进口苹果SKU，做中高价格带，观察毛利和复购。
- **一个月后**：用香蕉+苹果的稳定销量再评估菠萝，优先考虑鲜切或小规格包装，避免整果损耗。
- **核心指标**：损耗率、日均周转、缺货率、毛利额，不只看毛利率。香蕉看周转和损耗，苹果看毛利和复购，菠萝看鲜切转化和投诉率。

一句话：**先香蕉测供应链，再苹果稳毛利，菠萝最后小步试。**
