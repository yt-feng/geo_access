建议以“整果为主、切果为辅”，但要看你的门店类型、客流和损耗管理能力。判断标准如下：

**更适合卖整果的情况**
- 社区店、菜市场型门店：顾客更看重价格和耐放，整果周转快。
- 菠萝产地或批发优势明显、进货价低：整果毛利和价格竞争力更好。
- 人手少、鲜切卫生和冷藏条件一般：整果损耗可控，操作风险低。
- 促销走量：整果适合做引流单品。

**更适合卖切果的情况**
- 商圈店、写字楼店、年轻客群多：即食需求强，切果溢价高。
- 门店有冷藏陈列和规范切配操作：能控制食品安全和氧化损耗。
- 菠萝品质不稳定、整果外观差：可分级处理，把次果转鲜切减少报损。
- 做果切组合、下午茶场景：切果更能带动客单价。

**实操建议**
1. **整果做基本盘**：占菠萝陈列和销量的60%—70%，负责引流和走量。
2. **切果做增量**：占30%—40%，只做当天量，小盒装、带盖冷藏、标注切配时间。
3. **分级销售**：好果整卖；外观瑕疵但品质正常的做鲜切；熟度高的做特价切果或试吃。
4. **看数据调整**：连续2—3周记录整果与切果的销量、毛利、报损率。切果报损超过10%—15%就收缩；整果周转慢、外观投诉多就增加切果比例。
5. **卫生是底线**：切果必须专用刀具砧板、冷藏陈列、当日售清，不要为了溢价牺牲食品安全。

一句话：**没有冷链和切配管理能力，先卖整果；有商圈即食客流和规范操作，再做切果增量。**
