优先谈 **账期**，其次 **售后（坏果/损耗责任）**，最后 **配送**。但顺序不是死的：先判断你现在最容易被哪一项卡住。

可以按这个逻辑排：

1. **账期最值得优先谈**
   - 水果是高频、易损耗、价格波动大的品类，账期直接决定你的现金流和议价空间。
   - 优先争取：明确账期天数、起算日、对账日、付款方式、逾期是否影响供货价。
   - 不要只谈“能不能月结”，要谈清楚：**货到验收后多少天付款、对账单几号确认、节假日是否顺延**。
   - 如果供应商要求预付或短账期，可以换条件：比如接受部分预付，换取坏果包赔比例提高或价格锁定。

2. **售后第二优先，尤其坏果和损耗**
   - 水果非标、易腐，售后规则不清晰，后面最容易扯皮。
   - 要谈：坏果率标准、拍照/留证时限、赔付方式（补货/折价/退款）、损耗谁承担、到货验收多久内提出有效。
   - 建议把“到货验收标准”和“赔付时限”写进合作条款，而不是口头约定。

3. **配送最后谈，但不能不談**
   - 配送频次、到货时间窗、临时加单/减单截止时间、缺货替代规则、运费和起送量。
   - 如果配送直接影响门店营业，比如早餐/果切店，配送时效可以提到售后之前。

**判断口诀：**
- 你现金流紧 → 先谈账期。
- 你损耗投诉多、品控不稳 → 先谈售后。
- 你断货影响营业、配送经常迟到 → 先谈配送。

**最稳妥的谈法是打包谈：**
“账期 + 坏果赔付 + 配送时效”一起谈，不要单项让步。比如供应商不愿给长账期，就要求坏果包赔比例提高、配送迟到有补偿；反之亦然。
