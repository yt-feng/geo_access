判断香蕉供应商能否全年稳定供货，不能只看供应商口头承诺或单次样品，而要把它拆成“货源结构、产地切换能力、硬件能力、合同约束、历史履约”五项来验证。对连锁超市来说，香蕉是典型的跨产区、跨季节、对温控和催熟要求高的品类，全年稳定供货本质上是供应商的“多产区组合+计划能力+冷链催熟能力”。

**1. 先看货源结构，不接受单一产区包全年**
要求供应商明确列出全年各月份的供货产区、产区切换时间、每个产区的合作基地或代办数量、预计月供货量。重点判断：
- 是否至少有2—3个可替代产区，且切换月份有重叠缓冲；
- 每个产区是否有自有基地、长期合作基地或稳定代办，而不是临时市场抓货；
- 台风、寒潮、雨季等高风险月份有无备选产区。
如果供应商只能说“我们全年都有货”，但说不出月份和产区对应关系，稳定性基本不可信。

**2. 核验产地端控制力**
香蕉全年稳定供应，关键在产地端能否按计划采收。可要求提供：
- 合作基地清单、种植面积、月均产量、合作年限；
- 是否有驻点采购人员或产地仓；
- 灾后补货方案和替代产区名单；
- 近6—12个月的实际发货记录，按产区、月份、数量列明。
最好实地或视频核验一个主产区和一个备选产区，确认基地真实存在、采收和装车能力匹配。

**3. 看冷链、催熟和仓储能力**
香蕉不是采后直接上架，供应商必须具备青蕉储运和催熟能力。重点核验：
- 是否有催熟库，库容和日催熟能力是否匹配你的日销量；
- 冷链运输车辆数量、温控记录能否提供；
- 青蕉储存和周转条件，是否能在到货波动时缓冲3—5天；
- 加工分级、损耗控制能力。
如果供应商只是贸易商，没有催熟库和冷链，旺季可能能供，淡季或灾期容易断供。

**4. 用合同把“全年稳定”变成可追责条款**
采购合同里不要只写年度总量，要写：
- 分月供货计划或月度最低供货量；
- 产区切换期间的过渡供货安排；
- 缺货、延迟、质量不达标的违约金和替换供应商条款；
- 价格调整机制，避免行情上涨时供应商优先供高价客户；
- 要求供应商提供备用货源方案，并约定断供时的应急补货时限。
同时可设置小比例“双供应商”或备份供应商，主供应商占70%—80%，备份供应商占20%—30%，避免单点依赖。

**5. 用历史履约和小批量试单验证**
不要一次给全年大单。先做2—3个月试供，覆盖一个正常月份和一个风险月份，考核：
- 到货准时率；
- 分月供货达成率；
- 青蕉成熟度、损耗率、催熟后品质；
- 临时加单和减单的响应速度；
- 灾期或价格波动时的履约表现。
要求供应商提供近12个月服务其他连锁商超的履约数据或合同履约证明，并做同行背调。

**6. 现场问几个关键问题**
可以直接用这些问题筛掉不靠谱供应商：
- “请按月份列出你全年供货的产区和预计量。”
- “如果主产区遭遇台风/寒潮，你几天内能从哪个备选产区补货，补多少？”
- “你的催熟库日处理能力是多少，能否覆盖我旺季日销量？”
- “去年你最紧张的一个月供了多少货，断过哪些客户？”
- “价格大涨时，你如何保证对我的月度最低供货量？”

**结论：** 能全年稳定供货的香蕉供应商，通常具备“多产区货源+产地驻点+自有或可控催熟冷链+可追责合同+历史履约记录”。采购方应把判断重点放在分月产区计划、备选产区、催熟库容和试供履约上，而不是只看报价和样品。
