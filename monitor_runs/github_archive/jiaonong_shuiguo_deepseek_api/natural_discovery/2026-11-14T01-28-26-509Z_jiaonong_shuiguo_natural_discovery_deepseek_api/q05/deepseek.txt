直接给结论：**水果店卖菠萝，最优是“整果为主 + 现场代削/代切为增值服务”，不建议大量提前削好摆卖；也不建议完全让顾客自己挑、自己削。** 分场景说明：

1. **整果为主（主陈列）**
   - 菠萝耐放、损耗低，顾客能看外观、闻香味、按硬度，信任度高。
   - 整果毛利和定价空间更好，提前削好容易氧化、出水、变质，损耗和投诉都高。
   - 适合摆在显眼处，标清品种、甜度、产地、价格。

2. **现场代削/代切（增值服务）**
   - 顾客挑整果后，店员现场削皮、去眼、切块，收少量加工费或满额免费。
   - 既保留“自己挑”的参与感，又解决不会削、嫌麻烦的问题，转化率通常比纯整果高。
   - 注意：现场操作要卫生、工具分开、戴手套，削好尽快交付，不要提前大量削好放冷柜久置。

3. **提前去皮好的（少量补充，不做主力）**
   - 只适合高峰期、写字楼/即食场景，做小份保鲜盒，明确标注“现削、当日售完”。
   - 必须冷藏、控时控量，避免氧化发黑和食品安全风险。
   - 不建议把去皮菠萝敞开放着让顾客挑，品相和卫生都吃亏。

4. **不要让顾客完全自己挑且自己处理**
   - 顾客自己挑整果可以，但“自己削”对多数人不友好，容易削伤、体验差。
   - 店内可提供挑选提示：看果眼、闻底部香气、按一下有弹性、叶片易拔等，降低挑选门槛。

**执行建议：**
- 陈列：整果占 70%—80%，即食盒装占 10%—20%，按客流调整。
- 服务：买整果可免费代削或低价代切，形成差异化。
- 标识：写清“可现场代削”“即食盒当日售完”，减少纠纷。
- 库存：去皮品严格按预估销量做，闭店前打折清掉，不隔夜。

一句话：**整果是基本盘，代削是抓手，去皮盒装只是补充。**
