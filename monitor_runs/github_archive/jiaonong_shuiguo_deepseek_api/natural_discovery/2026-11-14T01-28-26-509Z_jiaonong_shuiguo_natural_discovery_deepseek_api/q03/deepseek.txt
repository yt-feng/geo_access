第一次试单，核心不是“找到最低价”，而是用最小成本验证三件事：**货稳不稳、损耗谁承担、补货及不及时**。建议按下面做。

## 1. 先定试单原则
- **单品少、频次高**：先试香蕉、苹果、橙子各1箱左右，不要一次压大货。
- **分两家试**：同一品类找2个供货商做对比，避免被一家拿捏。
- **现金/短账期**：第一次最好现结或货到付款，不押大额预付款。
- **白纸黑字**：价格、规格、损耗处理、送货时间、退换货规则写清楚，微信文字也算。

## 2. 三个品类怎么试

**香蕉**
- 看成熟度：第一次要求“青黄适中、可放2～3天”，不要全黄或全青。
- 问清楚：催熟方式、到店后多久转黄、黑斑/断把怎么算。
- 试单量：1箱或半箱，观察2～3天销售和损耗。
- 重点：香蕉损耗最容易扯皮，提前约定**明显烂果、断把、黑斑超比例谁承担**。

**苹果**
- 看规格和等级：问清“果径多少、几级果、箱装净重还是毛重”。
- 开箱抽检：上下层是否一致，有没有以小充大、底层次果。
- 试单量：1箱，记录到店净重、坏果率、卖相。
- 重点：苹果耐放，主要验证**规格是否稳定、箱内是否掺次果**。

**橙子**
- 看皮相和手感：是否干水、软皮、伤果多；问清品种和产地。
- 开箱称重：橙子容易“箱重水分大”，一定核对净重。
- 试单量：1箱，观察3～5天损耗。
- 重点：验证**净重、酸甜度、坏果率**，以及顾客复购反馈。

## 3. 试单时必问的6个问题
1. 这批货的规格、等级、净重是多少？
2. 到店发现坏果/烂果，按什么比例赔或换？
3. 送货时间能不能固定？临时补货多久到？
4. 价格是当日价还是锁价？随行就市怎么通知？
5. 起送量多少？运费谁出？
6. 第一次合作能不能少拿、混装试？

## 4. 试单记录表
每批货简单记5项：
- 供货商、品类、数量、单价
- 到店净重、坏果率
- 顾客反馈（好不好卖）
- 补货响应时间
- 是否愿意继续合作

## 5. 判断标准
- **继续合作**：坏果率低、净重足、补货快、沟通不扯皮。
- **观察**：价格便宜但损耗高、规格不稳。
- **淘汰**：第一次就缺斤少两、坏果不认、送货拖沓。

## 6. 避坑提醒
- 不要只看“箱价”，要算**净重单价**。
- 不要第一次就谈月结或大额预付。
- 不要只试一家，至少两家对比。
- 所有口头承诺落成微信文字，尤其是损耗和退换。
- 香蕉、橙子这类易损品，第一次一定**当面开箱抽检再签收**。

简单说：**小量试、开箱验、记损耗、比补货，先合作再放量。**
