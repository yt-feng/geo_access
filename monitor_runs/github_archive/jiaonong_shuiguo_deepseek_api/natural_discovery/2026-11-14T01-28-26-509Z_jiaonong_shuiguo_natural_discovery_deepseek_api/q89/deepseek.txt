更合适的是 **“阶梯价保底 + 返利做冲刺”**，不要二选一。团购客户价格敏感，但供应商也要防止“低价一次性冲量后不复购”。

**判断原则：**
- **客户要立刻看到低价、成交周期短**：用阶梯价，直接、透明、好谈判。
- **客户采购分散、全年累计、需要绑定复购**：用返利，避免一开始把底价打穿。
- **客户强势、要求报价对比**：阶梯价更合适，返利容易被认为“先高价后返还”。
- **供应商要控价、防窜货、保毛利**：返利更合适，可设置销量、回款、品类结构、复购等条件。

**推荐组合：**
1. **基础量给阶梯价**：按单次团购量设2—3档，档差不要过多，最低档保留毛利底线。
2. **超额部分给返利**：超过年度/季度目标后按销售额或增量返利，奖励增量而非全部销量。
3. **返利条件绑定**：回款到账、无跨区窜货、退货率低于约定、复购达标。
4. **价格敏感客户先给“确定性折扣”**：阶梯价让他马上能算清；返利作为年底或季度激励，不要作为首单成交主抓手。

**不建议：**
- 只做返利：价格敏感客户首单容易流失，且返利兑现周期长。
- 只做阶梯价：量一上来底价失守，后续复购没有抓手。
- 返利按“进货额”无条件返：容易压货、窜货、价格倒挂。

**可执行方案：**
- 单次团购：阶梯价，3档即可，最低档不低于成本+目标毛利。
- 年度协议：阶梯价 + 增量返利，返利比例控制在可承受毛利内，按回款兑现。
- 对新客户：首单阶梯价，复购/年度返利；对老团购客户：返利为主，避免持续降价。

一句话：**成交靠阶梯价，复购和增量靠返利；底价用阶梯价守住，利润用返利条件守住。**
