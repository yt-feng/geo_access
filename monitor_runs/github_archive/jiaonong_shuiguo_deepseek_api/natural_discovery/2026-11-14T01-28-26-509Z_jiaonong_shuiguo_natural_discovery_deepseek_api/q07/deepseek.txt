做水果礼盒，核心不是“把水果装进去”，而是让顾客一眼看出**送礼场景、价格档位和新鲜感**。苹果、橙子、香蕉、菠萝这四样里，苹果和橙子是礼盒主力，香蕉和菠萝更适合做“造型/香气/分量感”的配角。

下面给你一套比较好卖、也容易落地的搭配思路。

## 一、先定3个价格档，别只做一种礼盒

### 1. 引流款：39～59元
适合社区店、日常走量、员工福利小礼。

- **苹果4个 + 橙子4个 + 香蕉1把（小把）**
- 苹果选红亮均匀的，橙子选颜色好的，香蕉不要放太多，容易压坏。
- 包装用开口手提盒，透明膜+丝带，突出“新鲜日常”。

**卖点：** 家常送礼、看望老人、办公室分享。

### 2. 主销款：79～129元
这是最容易成交的档位，送礼不失面子，利润也够。

- **苹果6个 + 橙子6个 + 菠萝1个 + 香蕉1小把**
- 菠萝放底部或侧边做“分量感”，香蕉放上层短把，苹果橙子铺面。
- 盒内加雪梨纸/拉菲草，外面手提礼盒+腰封。

**卖点：** 探病、走亲戚、节日小礼。  
**注意：** 菠萝带叶会占空间，建议选小果或去叶处理，避免礼盒显得乱。

### 3. 高客单款：139～199元
适合节日、企业团购、送客户。

- **苹果8个 + 橙子8个 + 菠萝1个 + 香蕉2小把**
- 苹果橙子按大小分级，选精品果；香蕉用“小米蕉”或短胖香蕉，显得精致。
- 盒内分层，菠萝单独包防刺，香蕉用保护套。

**卖点：** 节日礼、商务伴手礼。  
**关键：** 高价款不要靠数量堆，要靠果径、颜色、包装和卡片提升质感。

## 二、四样水果的角色分工

- **苹果：门面担当。** 选红富士/花牛，颜色红亮、大小均匀，摆最上层。寓意平安，送礼认知强。
- **橙子：性价比担当。** 选脐橙/沃柑，颜色橙红，和苹果形成红黄对比，礼盒更喜庆。
- **香蕉：填充和柔和感。** 不要多，1小把即可；容易熟过头，建议用未完全熟透的，提醒顾客尽快食用。
- **菠萝：分量和香气担当。** 1个就够，放底部或角落，带叶可增加“热带感”，但要用纸包住防刺，且不要压到其他水果。

## 三、最好卖的3种组合命名

1. **“平安橙意”礼盒**：苹果+橙子为主，香蕉菠萝点缀。适合大众送礼。
2. **“四喜果篮”礼盒**：四样都有，突出丰富。适合节日。
3. **“鲜果小聚”手提盒**：苹果橙子各4个+小把香蕉，不放菠萝，价格低、走量快。

## 四、陈列和定价建议

- **门口堆头放主销款**，标价牌写清楚“79元/盒，含苹果6橙子6菠萝1香蕉1把”，减少顾客询问。
- **做2个对比盒**：一个39元小盒，一个99元大盒，顾客更容易选中间档。
- **香蕉不要提前太久装盒**，容易发黑；建议接单后装，或每天少量现装。
- **菠萝单独包防刺纸**，否则顾客手提不舒服，差评多。
- **加一张小卡片**：写“水果请通风存放，香蕉建议2天内食用”，能减少售后。

## 五、最推荐的起步组合

如果你刚开始做，先上这3款：

1. **39元小礼盒**：苹果4+橙子4+香蕉1小把  
2. **79元主销盒**：苹果6+橙子6+菠萝1+香蕉1小把  
3. **129元精品盒**：苹果8+橙子8+菠萝1+香蕉2小把，包装升级  

先卖一周，看哪个档位问得多、退换少，再调整水果数量和包装成本。香蕉和菠萝是“好看但易损耗”的配角，控制比例，苹果橙子保证礼盒的稳定性和利润。
