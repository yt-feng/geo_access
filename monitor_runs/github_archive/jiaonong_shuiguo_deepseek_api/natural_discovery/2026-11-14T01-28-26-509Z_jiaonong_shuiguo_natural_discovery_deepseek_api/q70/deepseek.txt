# 坏果责任条款的写法建议

核心思路：**把“谁承担、按什么标准认定、怎么赔”三件事写清楚，避免“损耗”这个模糊词**。

## 一、先定义，再分责

**1. 明确“坏果”的认定标准**
不要只写“坏果”，要量化，例如：
- 腐烂、霉变、软化流汁；
- 机械伤面积超过单果表面积 X%；
- 虫蛀、开裂、冻伤等；
- 可按品类分别定标准（如叶菜、浆果、根茎标准不同）。

**2. 区分损耗发生的环节**
- **装车前的产地/包装环节**：由供货方负责；
- **运输途中**（温度、挤压、时长导致）：明确由谁投保、谁承担；
- **到货验收环节**：约定验收时限（如到货后 24 小时内开箱抽检），逾期视为合格，避免事后扯皮。

## 二、约定验收与抽检方法

- 抽检比例（如每车随机抽 X 箱，或按 5%–10%）；
- 抽检方式（开箱、过秤、拍照/视频留证）；
- 双方到场或远程视频确认；
- 异议提出期限和方式（书面/微信记录也算，写进合同）。

## 三、写清赔偿计算方式

建议用“梯度赔付”而非一刀切，例如：

| 到货坏果率 | 处理方式 |
|---|---|
| ≤3%（自然损耗） | 买方自担，不索赔 |
| 3%–8% | 按坏果重量扣减货款 |
| >8% | 买方有权拒收整批或要求按比例折价 |
| 严重腐烂/食品安全问题 | 全额退货，运费及损失由责任方承担 |

同时写明：**赔款从货款中直接抵扣**，或约定赔付时限（如验收后 7 日内）。

## 四、几个容易被忽略但关键的条款

1. **包装与运输责任归属**：若供货方负责物流，写清“运输途中损耗由供货方承担至买方签收”；若买方自提，则签收即转移风险。
2. **保险**：大额批次可约定由供货方投保货物运输险，或明确保险赔付不足以覆盖时的补足责任。
3. **举证责任**：约定“以到货开箱视频/照片为准”，谁主张谁举证，或约定共同委托第三方检测。
4. **不可归责情形**：因买方延迟卸货、储存不当造成的坏果，供货方免责——这条对批发商也是保护，要写进去。
5. **批次隔离**：坏果集中处理，不与其他货物混放，避免扩大损失并便于定责。

## 五、一句话模板

> “货物到货后 24 小时内，买方按每车随机抽取 5% 箱数开箱验收并录像留证。坏果率≤3% 视为自然损耗由买方承担；3%–8% 部分按坏果实际重量扣减货款；超过 8% 买方有权拒收该批货物，供货方承担退货运费并按合同价 95% 退款。运输途中损耗由负责承运的一方承担。因买方延迟卸货或储存不当导致的坏果，供货方不承担责任。”

**提醒**：条款要和你实际的交易模式（谁发货、谁承运、账期多长）匹配；如果是长期合作，建议把抽检标准和赔付梯度作为合同附件，按品类分别约定，执行时更少争议。
