判断香蕉一手货源是否稳定，别听对方口头承诺，用下面几个可核验的动作去筛：

1. **先看“产地身份”是否真实**
   - 要求对方提供产地证明、种植基地照片/视频、合作社或代办资质。
   - 最好视频连线看货场、冷库、加工线，而不是只看图片。
   - 问清楚是自有基地、包园、代办还是二道贩子；二道贩子不是不能合作，但稳定性通常弱于直接对接产地代办/合作社。

2. **看供货能力是否匹配你的量**
   - 问日均可供量、最大供量、最小起批量，并让他给出近一个月的实际发货记录（可打码，但看得到频次、车型、目的地）。
   - 旺季/雨季/节假日能不能保量，让他说清楚替代方案。
   - 小批量试单：连续下3—5次小单，看是否按时、按质、按量。

3. **看品质和损耗承诺**
   - 明确香蕉等级、成熟度、条数/箱、单果重、青黄比例、机械伤允许范围。
   - 问清楚催熟责任在谁、运输温控怎么做、到货损耗超过多少怎么赔。
   - 稳定供货商敢写进合同或订单确认里，不稳定的只会说“放心”。

4. **看履约和结算方式**
   - 优先选能接受“小单现结+稳定后账期”的，不要一上来就大额预付。
   - 查收款账户是否与公司/合作社名称一致，避免打私人账户。
   - 要求提供至少2—3个现有批发客户可回访（对方愿不愿意给很关键）。

5. **看抗风险能力**
   - 问产地天气、病害、换季时怎么保供；有没有多个产区/多个基地备选。
   - 有没有冷库、加工线、固定车队或合作物流。
   - 价格随行就市可以，但要看他报价是否明显低于市场——异常低价往往意味着品质或履约不稳。

6. **用合同锁定关键条款**
   - 写清规格、数量、交付时间、验收标准、损耗赔付、违约处理。
   - 先小单后大单，先现结后账期，逐步放量。

**最实用的判断标准：** 愿意让你看现场、给小单试、给老客户回访、把损耗和赔付写清楚的，稳定性通常高；只催你打款、只发精修图、回避产地和履约细节的，先别大额合作。
