判断“适不适合门店销售”，核心不是只看大小，而是看**规格一致性、陈列适配、顾客接受度、损耗风险、毛利结构**。采购时按下面几步判断即可：

**1. 先按门店类型定规格带**
- 社区生鲜店/水果店：苹果单果常见以**75–85mm**为主力，橙子以**中果70–80mm**或按重量分级；太小显廉价，太大单价高、动销慢。
- 商超散装区：规格可略宽，但要分档陈列，避免大小混卖。
- 精品/礼盒：苹果**80–90mm**、橙子**大果**更合适，但必须整齐、无瑕疵。
- 餐饮/团购：更看性价比和出成率，不必追求超大果。

**2. 现场量“三率”**
- **均匀率**：随机抽30–50个，最大与最小差不超过一个规格档；苹果横径差建议控制在5mm内，橙子按同分级标准看。
- **残次率**：碰伤、日灼、病虫斑、畸形果超过5%就要压价或换货。
- **失水/软果率**：苹果捏起来硬实、橙子皮紧有弹性；软果多说明货龄长。

**3. 看陈列与拿取适配**
- 散装堆头：单果过大会堆不稳、顾客一次拿太多；过小则显得碎。
- 预包装：按袋/盒装时，规格要能整齐码放，袋内大小一致。
- 秤重销售：单果重量稳定比“绝对大”更重要，避免同价不同量引发投诉。

**4. 算动销和毛利**
- 用门店近7–14天同品类销量倒推：主力规格应覆盖**60%–70%销量**。
- 大果适合做毛利款，小果适合做引流款，但**同一价位带内不要混规格**。
- 算上损耗：苹果损耗率通常低于橙子，但碰伤多、库温不当都会放大损耗；规格越大，单果损耗金额越高。

**5. 快速验收标准**
- 苹果：果形端正、色泽一致、硬度好、梗洼干净；同箱横径差小。
- 橙子：皮紧、油胞细、无浮皮、无霉蒂；同批果重差小。
- 抽检至少3箱，每箱随机取10个，记录最大/最小/平均直径和残次个数。

**结论**：适合门店销售的规格，是**门店主力价格带内、均匀率高、残次低、陈列拿取方便、动销快**的规格，而不是单纯“越大越好”。采购前先定门店分级标准，再按抽检数据决定是否进货和压价。
