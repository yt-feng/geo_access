三者的优先级要看食堂场景，不能并列。对“企业食堂采购水果”，通常的顺序是：

**1. 食品安全优先（一票否决）**
食堂是集体供餐，水果多为生食或简单清洗后分发，一旦农残超标、霉变、运输污染，影响面大且难追溯。应先卡住：
- 供应商资质、检测报告/承诺达标合格证；
- 农残检测或快检能力；
- 冷链/防污染运输、验收标准（霉变、破损、异味拒收）；
- 可追溯批次和留样/记录。

食品安全不过关，价格再低、配送再准时都不能选。

**2. 配送准时其次（保障供餐秩序）**
水果通常是每日/每周固定配送到食堂，迟到会直接影响餐次安排、验收和库存周转。尤其鲜果保质期短，准时和到货质量强相关。应关注：
- 约定到货时间窗和迟到处理；
- 临时补货响应；
- 节假日/旺季运力保障。

**3. 价格第三（在合规与稳定供应基础上优化）**
水果价格波动大，食堂采购应追求“合理性价比”而不是最低价。低价往往伴随等级下降、损耗上升、以次充好。可用比价、周期性调价、损耗率考核来控制总成本。

**可执行判断：**
- 先用食品安全做**准入筛选**；
- 再用配送准时和履约稳定性做**日常考核**；
- 最后在合格供应商中比价，按“到货合格率+准时率+综合单价（含损耗）”评标，而不是只看报价。

如果企业食堂规模小、供应商少，可简化为：**安全一票否决 → 准时保供 → 价格比选**。
