选择下午茶水果供应商，关键看“批量配送稳定性”而不是“水果最好吃”。可按下面顺序筛选和判断：

**1. 先明确采购约束**
- 人数、人均预算、配送时间窗口、是否需要切果/分装、是否有忌口（芒果、菠萝、猕猴桃等易过敏）。
- 下午茶场景优先选：易分食、不易氧化、不需要现场处理的水果，如小番茄、葡萄、砂糖橘、香蕉、苹果、梨、蓝莓盒装；少选切开的西瓜、哈密瓜等易变质品类。

**2. 供应商类型选择**
- **本地水果批发商/配送商**：适合20人以上、固定周期配送，价格和批量稳定性较好。要求其有分拣场地和冷链车。
- **生鲜平台企业购**：适合中小批量、临时采购，履约稳定但价格略高，注意起送量和开票。
- **附近水果店长期合作**：适合20人以内、步行可达，灵活性高，但批量大时品控波动。
- **中央厨房/团餐供应商**：如果需要洗净切配、独立分装，优先选有食品经营许可和冷链能力的。

**3. 必须核验的资质和能力**
- 营业执照、食品经营许可证（涉及切果必须有）。
- 是否有冷链配送车辆或保温箱，配送全程温度能否控制。
- 能否提供当日或前一日分拣、按份分装、坏果包赔。
- 是否支持固定时间送达、临时加单、节假日配送。
- 能否开票、对公付款、签简单采购协议。

**4. 用小批量试单判断**
先下1—2次试单，重点看：
- 到货时间是否准；
- 重量是否足称；
- 坏果率是否低于5%；
- 分装是否干净、有无挤压；
- 售后响应是否及时。
试单通过后再签月度或季度框架。

**5. 合同和验收要点**
- 写明品种、规格、净重、单价、配送时间、坏果赔付标准。
- 验收时抽检重量和坏果，拍照留证；约定24小时内反馈售后。
- 避免只比单价，要按“可食用净重成本”比较。

**实操建议**：优先找本地有冷链的批发配送商，要求提供2—3个企业客户案例；先试单一次，按坏果率、准时率、分装质量打分，再决定长期合作。批量配送最忌讳临时换供应商，固定1家主供应商加1家备选最稳。
