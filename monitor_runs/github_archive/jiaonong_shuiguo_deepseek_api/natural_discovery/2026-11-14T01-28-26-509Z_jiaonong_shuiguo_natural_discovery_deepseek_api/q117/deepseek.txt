先给一个稳妥框架：**新品不要一次性按“正式进货量”压，先用小批量试卖，以 2~4 周为一个观察周期，售罄率 70%~85% 时再放量**。具体试卖量可以按下面公式估：

**建议首批试卖量 = 单店日均预估销量 × 试卖天数 × 1.2~1.5 倍安全系数**

其中：

1. **日均预估销量**
   - 没有历史数据：先按同类水果日均销量的 **20%~30%** 估。
   - 有相似替代品数据：按替代品日均销量的 **30%~50%** 估。
   - 高端/小众/高单价新品：再打 **5~7 折**。

2. **试卖天数**
   - 易腐水果：**3~5 天**一批，少量多次补。
   - 耐储水果：**7~14 天**。
   - 完整观察期：**2~4 周**。

3. **首批量控制**
   - 单店首单建议控制在 **正常日均销量的 3~5 天量**。
   - 多店采购时，先选 **2~3 家代表性门店**试卖，不要全部门店同步铺。
   - 总试卖金额建议不超过该品类月采购额的 **10%~15%**。

4. **放量判断标准**
   - 售罄率 **≥80%**、损耗率 **≤5%~8%**、复购/补货请求明显：可放量到试卖量的 **1.5~2 倍**。
   - 售罄率 **60%~80%**：维持或小幅调整。
   - 售罄率 **<60%** 或损耗偏高：暂停放量，先查定价、陈列、品质和客群匹配。

5. **采购合同上要加的保护**
   - 先小批试销，后续按周下单。
   - 明确到货成熟度、规格、损耗赔付和退换货规则。
   - 要求供应商提供试卖期支持，比如坏果补货、陈列物料、阶梯价。
   - 不要被“首单优惠”绑定大库存。

一句话：**首单按 3~5 天销量试，选 2~3 家店，2~4 周看售罄率和损耗，达到 80% 售罄再放量。** 这是比较稳的做法。
