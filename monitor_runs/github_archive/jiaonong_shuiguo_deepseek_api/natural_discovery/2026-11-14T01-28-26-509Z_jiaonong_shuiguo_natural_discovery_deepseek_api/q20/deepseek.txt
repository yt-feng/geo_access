社区超市选“每天配送”的水果供应商，建议按下面几类条件逐项核，重点不是只看价格，而是看**稳定日配能力**和**损耗可控性**。

### 1. 配送能力
- **是否真能每日配送**：确认固定发车时间、到店时间、节假日是否照常。
- **配送半径和路线**：离你越近越稳，问清是否顺路配送、临时加单是否接。
- **起送量和频次**：每天最低起送金额/重量是多少，少量补货是否愿意送。
- **应急补货**：当天临时缺货能否几小时内补，费用怎么算。
- **冷链条件**：浆果、切果、叶菜是否冷藏车或保温箱配送。

### 2. 货源与品类稳定性
- **主供品类**：是否有稳定基地或一级批发渠道，常供品类是否覆盖你的畅销品。
- **季节性替代方案**：某品类断货时能否提前告知并给替代品。
- **规格一致性**：同一品类每天规格、等级、成熟度是否稳定。
- **产地和检测**：能否提供产地证明、农残检测或进货凭证。

### 3. 质量与损耗条款
- **验收标准**：明确大小、成熟度、瑕疵率、腐烂率上限。
- **坏果赔付**：到货坏果、短斤少两怎么赔，是补货、扣款还是下次抵扣。
- **售后时限**：发现问题后多久内反馈有效，是否要求拍照留证。
- **损耗承担**：运输损耗、储存损耗分别谁承担，避免“到店即免责”。

### 4. 价格与结算
- **报价方式**：每日报价还是周报价，是否随行就市，涨跌有没有通知。
- **价格对比**：至少拿2—3家同品类报价对比，别只比单价，要比到店净成本和损耗后成本。
- **账期**：现结、周结还是月结，押金和违约条款。
- **返点/促销支持**：是否有滞销品调换、节日促销支持。

### 5. 资质与合规
- **营业执照、食品经营许可**：水果属食用农产品，但配送方最好有合法经营资质。
- **开票能力**：能否开票，税点多少。
- **保险与车辆**：配送车辆是否固定，有无货损责任约定。

### 6. 试合作验证
建议先做**7—10天试配送**，重点记录：
- 到店准时率；
- 缺货/断货次数；
- 坏果率和赔付是否爽快；
- 临时补货响应速度；
- 实际到店成本。

### 简单判断标准
优先选：**本地有仓、每日固定路线、坏果包赔、能小批量补货、报价透明**的供应商。  
谨慎选：报价明显偏低但起送量高、不能日配、坏果责任模糊、只做电话口头承诺的供应商。

最后建议至少保留**1家主供+1家备供**，避免单一供应商断货影响门店日常销售。
