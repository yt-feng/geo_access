茶饮店采购香蕉，核心不是“买一种熟度”，而是**按用途分熟度采购、分批到货、按天控量**。香蕉后熟很快，采购熟度错了，损耗会很高。

## 1. 先按用途定熟度

| 用途 | 推荐采购熟度 | 判断标准 | 到店后可用时间 |
|---|---|---|---|
| 香蕉牛奶/香蕉果昔/冰沙 | 7～8成熟 | 通体黄、两端微绿、手感偏硬，按压有轻微弹性 | 1～2天后最佳 |
| 捣泥做果酱底、奶昔顶料 | 8～9成熟 | 全黄、带少量糖斑、手感软但不变形 | 到店当天至第2天用 |
| 甜品装饰、切片摆盘 | 7～8成熟 | 黄而挺，切面不易发黑变烂 | 当天切当天用 |
| 香蕉泥馅料、烘焙 | 9成熟以上 | 皮有黑斑、果肉软甜、香气浓 | 当天必须处理 |

**不建议茶饮店常备全熟香蕉**：全熟香蕉去皮捣泥出杯快，但货架期极短，夏天可能半天就过熟。

## 2. 采购时看“到货可售期”，不要只看当天

下单时按**预计到店日期**倒推熟度：

- 今天到货、明天用：采购**8成熟**，到货即可用。
- 今天到货、后天用：采购**7成熟**，到店后常温催熟1天。
- 今天到货、3天后用：采购**6.5～7成熟**，避免到货即熟。
- 周末高峰：周五到货的香蕉不要全买8成熟，应**7成熟+8成熟混批**。

## 3. 控制采购量：按“两日用量”而非“一周用量”

香蕉不耐储，建议：

- **日常采购量 = 次日预计用量 × 1.3～1.5**
- 高温天或门店无空调储存区：**按1天用量采购**，最多备1.5天。
- 香蕉类饮品占比低时，宁可少买、隔天补货，不要囤。
- 新品测试期先按**每日5～10公斤小批量**试销，再放量。

## 4. 到货验收标准

收货时随机抽检：

1. **颜色**：青黄到全黄按批次区分，不要一箱里熟度差太多。
2. **手感**：轻按有弹性，不能软塌、出水、破皮。
3. **果柄**：果柄新鲜、不干枯发黑。
4. **表皮**：允许少量糖斑，但不能大面积黑斑、裂口、霉点。
5. **温度**：夏季到货摸箱内温度，发热明显说明后熟过快，要优先使用。

## 5. 到店后的熟度管理

- **未熟香蕉**：常温、阴凉通风存放，不要冷藏，冷藏会停止后熟并导致表皮变黑。
- **已熟香蕉**：优先使用；可去皮分装冷冻，用于冰沙和奶昔，但装饰用途不能用冻香蕉。
- **每天早晚各分拣一次**：把8～9成熟的挑出来标注“优先使用”，7成熟的留作次日。
- **先进先出**：按到货批次贴日期标签，不要混放。

## 6. 实操建议

茶饮店最稳妥的做法是：

- **主力采购7.5～8成熟**，到店1～2天内用完；
- **每天少量补货**，不一次性囤3天以上；
- **熟度分三档管理**：偏青催熟、适中使用、过熟转冷冻/果酱；
- **夏季减量20%～30%**，冬季可略增；
- 与供应商约定**按熟度分批送货**，而不是整批同熟度。

一句话：**采购看用途，到货看手感，库存按天算，过熟就转冷冻或果酱，不要等它坏。**
