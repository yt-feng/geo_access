可以提前要这几类资料，重点是把“批次可追溯”和“检测责任”落到纸面：

1. **供应商资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按实际业态）
   - 若为种植基地直供：基地相关资质、供货授权或合作协议

2. **批次检测报告（最关键）**
   - 要求提供**与到货批次对应的农残检测报告**，不要只给一份年度通用报告
   - 报告应含：样品名称、批次/采收日期、检测项目、检测方法、检测结果、检测机构、报告编号、签发日期
   - 优先要**CMA资质检测机构**出具的报告；快检报告只能作辅助，不能替代法定检测
   - 重点看是否覆盖高风险项目：有机磷、氨基甲酸酯、拟除虫菊酯等，具体按水果品类和当地监管要求

3. **承诺书/质量保证协议**
   - 供应商书面承诺：所供批次符合农残限量标准；出现抽检不合格时承担退货、销毁、罚款、商誉损失等责任
   - 明确“随货同行检测报告”或“到货前提供报告”的时限

4. **溯源资料**
   - 产地证明、采收批次记录、种植基地名称/地址
   - 进货台账所需信息：品名、规格、数量、生产日期/批号、供货者名称及联系方式
   - 如为进口水果：海关入境货物检验检疫证明、报关单等

5. **快检/自检记录（如有）**
   - 供应商自检或第三方快检记录可作为前置筛查，但要注明不能替代法定检测报告

6. **不合格处置与召回资料**
   - 供应商召回制度、不合格批次处置记录模板
   - 约定抽检不合格时的配合复检、下架、召回流程

**可执行做法：**
- 在采购合同里写明：**“每批次随货提供对应农残检测报告，未提供不予收货”**
- 收货时核对报告批次号与实物标签是否一致
- 对高风险水果（如草莓、葡萄、柑橘、苹果等）提高抽检频次，保留留样
- 建立供应商档案，报告按批次归档至少保存至保质期满后6个月（按当地监管要求执行）

一句话：**别只要“资质”，一定要“批次对应的农残检测报告+质量承诺+溯源信息”三件套。**
