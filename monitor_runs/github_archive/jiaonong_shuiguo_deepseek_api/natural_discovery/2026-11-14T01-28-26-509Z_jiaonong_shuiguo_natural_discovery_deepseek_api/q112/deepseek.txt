# 坏果率赔付门槛的实务建议

**先给结论：法律没有统一规定的"标准坏果率"，赔付门槛由合同约定。实务中常见做法是：**

- **5%以内**：一般视为合理损耗，不赔付（很多批发/商超采购合同用这个作为"免赔额"）
- **超过5%**：开始按比例扣款或折价
- **超过10%**：可要求整批退货、换货或按重量折算赔偿
- **超过15%–20%**：属于严重质量不符，可主张退货退款并索赔损失

但这几个数字不是法定标准，只是行业惯常区间，具体要看品类、运输距离、包装方式和交易地位。

## 分品类参考

| 品类 | 常见免赔/起赔线 | 说明 |
|---|---|---|
| 耐储水果（苹果、柑橘、梨） | 3%–5% | 损耗低，阈值可以定严 |
| 浆果类（草莓、蓝莓、葡萄） | 5%–8% | 易腐易压，阈值适当放宽 |
| 热带水果（芒果、荔枝、香蕉） | 8%–10% | 后熟和运输损耗大 |
| 长途冷链运输 | 在基准上加3%–5% | 明确责任划分：运输方还是供货方 |

## 比"定一个数"更重要的三件事

1. **明确验收时点和抽样方法**：到货后多长时间内验收、抽检比例（如每车抽10箱）、由谁认定。否则"坏果率"本身就会扯皮。
2. **区分"自然损耗"与"质量瑕疵"**：腐烂、霉变、虫害属于质量瑕疵，应赔付；轻微磕碰、失水属于正常损耗，可约定不赔。
3. **约定赔付计算方式**：是按坏果重量折算扣款，还是按整批比例折价，还是允许退货换货。只写"超过X%赔付"而不写怎么算，等于没约定。

## 谈判建议

- 作为**采购方**：争取"超过5%即按坏果重量双倍扣款，超过10%可整批退货"，并要求供货方承担退货运费。
- 作为**供货方**：争取设置5%–8%的免赔额，并限定验收时限（如到货24小时内提出异议，逾期视为合格），避免买方事后翻账。
