判断茶饮连锁的菠萝供应商能否稳定按规格送货，不能只看报价和样品，要按“规格定义—产能验证—履约证据—试单考核—合同约束”五步走。下面是可以直接执行的做法。

## 1. 先把“规格”写成可验收的硬指标

茶饮用的菠萝通常分鲜果、冷冻果块/果丁、果酱/浓缩汁、糖水罐头等，不同形态验收标准不同。采购前至少明确：

- **品种与产地**：如金钻凤梨/巴厘菠萝，产区、季节窗口。
- **成熟度与糖酸度**：可溶性固形物（Brix）范围、酸度、糖酸比。
- **果径/单果重**：鲜果分级；果块则明确切丁尺寸（如10×10mm）、长度偏差。
- **出成率**：去皮去芯后可用果肉比例，茶饮店最关心这个。
- **冷冻/加工形态**：IQF单体速冻还是块冻、是否糖渍、包装规格（如1kg/袋、10kg/箱）。
- **感官与安全**：色泽、纤维感、异味、农残、微生物、重金属等检测要求。
- **包装与冷链**：内袋材质、标签、箱规、运输温度（冷冻≤-18℃）、到货中心温度。
- **到货时效与批量**：单次起订量、送货频次、到仓时间窗、卸货要求。

把这些写成《采购规格书》和《验收标准》，作为询价、试单和合同的附件。规格越可量化，后面越容易判断供应商是否“稳定”。

## 2. 验证产能与供应链，而不是只听承诺

重点问和查：

- **原料来源**：自有基地、合作社还是市场收购？市场收购型供应商在旺季或天气异常时最容易断供。
- **加工能力**：日处理量、冷冻库容、生产线数量、是否代工。要求提供近3个月同类客户出货记录或产能台账。
- **季节对冲**：鲜果有产季，供应商是否有冷冻/罐头备货能力，能否全年供同规格产品。
- **质量体系**：是否有SC/食品生产许可、HACCP/ISO22000、农残检测报告；冷冻品看冷链记录。
- **物流能力**：自有冷链车还是外包，到茶饮仓的线路、备用车辆。
- **财务与经营稳定性**：成立年限、注册资本、涉诉与行政处罚可公开查询；避免只靠一个产季的贸易商。

## 3. 用“小批量试单”做履约压力测试

不要一次下大单。建议分3轮：

- **首单小批量**：按正常送货频次连续送2—3次，记录到货合格率、规格偏差、温度、包装破损。
- **加量测试**：在首单合格后，把单次量提高到计划量的50%—80%，看是否仍能按时按质交付。
- **旺季/异常测试**：在产季高峰或节假日前下一单，观察其排产和物流抗压能力。

试单期间建立简单考核表：准时交付率、规格合格率、批次合格率、短溢装率、异常响应时间。连续2—3轮达标再谈长期。

## 4. 要求提供可核验的履约证据

让供应商提供：

- 近6个月同类产品出货单/送货单（可脱敏）；
- 第三方检测报告（农残、微生物、重金属）；
- 冷链运输温度记录样本；
- 主要客户合作证明或访谈对象；
- 质量异常处理记录和召回预案。

对关键客户可做背景访谈，但要注意商业保密，不做虚构背书。

## 5. 合同里写死“稳定送货”的约束

- **规格附件**：验收标准、抽样方法、不合格判定。
- **交付条款**：送货频次、时间窗、最低/最高供货量、短溢装比例。
- **质量违约**：批次不合格的退换货、扣款、停单整改；连续不合格解除合同。
- **断供应急**：供应商需提前报备产能异常，设置安全库存或备选供应商条款。
- **价格机制**：随行就市时设调价公式和提前通知期，避免旺季坐地起价。
- **考核与退出**：月度/季度评分，连续低于阈值触发整改或退出。

## 6. 茶饮连锁还要多做一层：备选与库存

- **双供应商**：主供70%—80%，备供20%—30%，备供也要走试单。
- **安全库存**：鲜果按3—5天用量，冷冻果块按2—4周用量，视仓储条件定。
- **到货抽检**：每批查温度、包装、感官、规格，定期送第三方检测。
- **异常台账**：记录每次迟到、短量、规格不符，作为季度评估依据。

**一句话判断标准**：供应商能提供可量化的规格书、可核验的产能与检测证据，并通过连续3轮小批量试单（含一次加量或旺季测试）仍保持准时率和合格率达标，才可认定为“能稳定按规格送货”。
