对茶饮店来说，**出汁率通常比甜度更重要**，但判断要看用途和成本结构。可以按这个优先级决策：

1. **先看出汁率**
   - 茶饮店用菠萝多为榨汁、捣果肉、做果酱/糖浆基底。
   - 出汁率低意味着同样一杯饮品要用更多原料，损耗、人工、冷藏空间都上升。
   - 出汁率高的菠萝通常更稳定，出品成本可控。

2. **甜度不是越高越好，而是要看“糖酸比”**
   - 纯甜但酸度低的菠萝，做水果茶容易发闷、缺层次。
   - 茶饮更看重风味稳定：甜中带酸、香气足，比单纯高甜度更适合搭配茶底。
   - 如果门店靠加糖浆调甜，原料甜度的重要性会下降。

3. **按产品类型区分**
   - **鲜果茶、捣果肉类**：出汁率、果肉率和香气优先，甜度适中即可。
   - **鲜榨菠萝汁**：出汁率第一，糖酸比第二。
   - **菠萝果酱/糖浆基底**：可以接受甜度稍高，但要看加工稳定性和风味。
   - **装饰切片**：外观、成熟度和切损率优先。

4. **实操建议**
   - 让供应商同时给**出汁率、糖度（Brix）、酸度、果肉率、规格**。
   - 用小批量盲测：同样配方下比较出杯成本、风味稳定性和顾客接受度。
   - 别只按“甜”采购，否则旺季批次差异会让饮品口味波动。

结论：**出汁率是成本底线，甜度/糖酸比是风味上限。茶饮店采购应优先保证出汁率和风味稳定，再在可接受糖酸比范围内选甜度合适的原料。**
