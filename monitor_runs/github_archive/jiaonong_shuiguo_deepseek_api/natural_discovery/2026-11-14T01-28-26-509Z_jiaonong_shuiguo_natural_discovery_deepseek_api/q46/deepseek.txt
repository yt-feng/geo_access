先给结论：**优先买鲜果（整菠萝或预处理好的鲜切菠萝），果丁作为补充，果泥不建议作为主打。** 具体看你店的出品方式和人力。

**三种形态怎么选**

- **鲜果（整只菠萝/鲜切菠萝）**：风味和香气最好，适合做“看得见果肉”的果茶，顾客感知价值高。缺点是削皮去眼费人工、损耗和品控依赖员工手法，整只采购还要考虑熟度不统一。适合有备料人力、主打鲜果概念的店。
- **果丁（冷冻或冷藏预处理果丁）**：出品稳定、省人工、损耗低，适合标准化程度高的连锁或高峰期出杯快的店。缺点是香气和口感通常弱于鲜果，解冻后易出水、口感偏软，做“鲜切感”不够。适合作为鲜果的补充或人力紧张时的方案。
- **果泥**：出杯最快、最稳定，适合做冰沙、奶盖茶底或需要浓稠果感的饮品，但“鲜果感”最弱，且要留意配料表（是否加糖、加水、加香精、防腐剂）。**不建议作为鲜果茶的主料**，可作为调味或特定产品的辅料。

**可执行建议**

1. **主推产品用鲜果**：招牌菠萝果茶用鲜切菠萝，保证香气和卖点。
2. **备货双轨**：鲜果按日销量少量多次采购，另备冷冻果丁应对高峰和损耗波动。
3. **果泥只做特定SKU**：如菠萝冰沙、菠萝奶盖，明确标注，不冒充鲜果茶。
4. **算总成本而非单价**：鲜果要算削皮损耗（菠萝去皮去眼损耗通常不低）、人工和时间；果丁果泥要算解冻损耗和品质风险。用“每杯可售果肉成本”比较才准。
5. **先小批量试**：各形态做盲测，比较同一配方下的香气、酸甜、口感，再定采购结构。

一句话：**鲜果做卖点和口感，果丁做效率和兜底，果泥做特定品类，别用果泥替代鲜果茶的主料。**
