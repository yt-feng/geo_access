供应商介绍产品，要让普通商家“一听就懂、一算就明白、一开口就能卖”，不要先讲品种学名和产地故事，而要按“品类—用途—卖给谁—怎么卖—赚多少—风险多大”的顺序说。可以直接套下面这套话术。

**1. 先用商家熟悉的大品类做挂钩**
不要一上来就说“这是金钻凤梨/台农几号”，先说：
- “这是菠萝类里偏甜、适合直接鲜食的一款。”
- “这是香蕉类里偏小、适合做精品果切和单根售卖的一款。”
- “这是橙子类里偏酸香、适合榨汁和餐饮渠道的一款。”

商家先知道“它属于我熟悉的哪一类”，才听得下去。

**2. 用一句话说清和普通货的区别**
格式：“和普通菠萝比，它最大的区别是____，所以适合____。”
例子：
- “和普通菠萝比，它不用泡盐水、切开就能吃，适合做办公室果切和高端水果店。”
- “和普通香蕉比，它个头小、单根卖相好，适合便利店按根卖和儿童早餐场景。”
- “和普通橙子比，它皮薄汁多、出汁率高，适合奶茶店和餐饮榨汁。”

**3. 直接说卖给谁、怎么卖**
普通商家最关心“我拿回去卖给谁”。供应商要主动给场景：
- 鲜食零售：水果店散卖、精品盒装、社区团购。
- 果切/餐饮：奶茶店、果汁店、食堂、酒店自助餐。
- 礼盒/节庆：企业团购、节日礼盒。
- 加工：烘焙、果酱、果干。

最好配一句陈列或售卖建议，比如“按3个一盒做家庭装”“按根卖放收银台旁边”“切开做试吃转化最快”。

**4. 把账算给商家听**
不要只说“好吃、好卖”，要说：
- 进货价、建议零售价、毛利空间。
- 一斤能出几盒/几杯/几份。
- 损耗大概多少，怎么降低。
- 最小起订量、混装政策、退换货规则。

例子：“这箱净重10斤，按每盒半斤装可以做20盒，建议卖9.9元一盒；损耗控制在两盒以内，毛利大概在__%。第一次可以少拿两箱试卖。”

**5. 主动说风险和适合谁**
商家怕压货。供应商要主动说：
- “这个货适合有果切能力的店，纯散卖动销慢。”
- “熟度到货是几分熟，放几天最好卖，卖不完适合转果切还是榨汁。”
- “第一次不建议拿多，先试一箱，卖得动再加量。”

**6. 给一张“商家能记住的卡片”**
每个产品配一张简单标签：
- 一句话定位：甜鲜食菠萝，免泡盐水。
- 适合渠道：水果店/果切/团购。
- 卖点：切开即食、甜度高、个头适中。
- 建议卖法：3个家庭装、半斤果切盒。
- 价格带：进货__，建议零售__。
- 风险提示：熟度高，建议3天内主推。

**最实用的开场模板：**
“老板，这是一款菠萝类里免泡盐水、切开就能卖的鲜食品种，和您现在卖的普通菠萝是一个大类，但更适合做果切和精品盒装。一箱10斤大概能做20盒半斤装，建议卖9.9元一盒。第一次您拿一箱试卖，卖不动可以转果切，损耗比普通菠萝低。您主要做社区店还是果切？我按您的渠道给您配货。”

核心原则：**少讲品种，多讲场景；少讲口感形容词，多讲怎么卖、赚多少、压不压货。** 商家听懂的是“和我现有生意怎么接上”，不是“这个品种有多专业”。
