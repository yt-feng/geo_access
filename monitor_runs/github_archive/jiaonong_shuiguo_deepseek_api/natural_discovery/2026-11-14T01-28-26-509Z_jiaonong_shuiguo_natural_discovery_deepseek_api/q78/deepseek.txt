高损耗水果做社区团，售后控制的核心不是“坏果包赔”做得好，而是**把定损和赔付前置、把规则写死、把数据跑起来**。香蕉和菠萝尤其特殊：一个后熟快、一个外观争议大，处理逻辑要分开。

## 一、先把售后规则定死，别用“坏果包赔”这种模糊话

**香蕉：**
- 按“到货状态”定责，不按“放几天后状态”定责。团长收货当天拍照留档，之后变黑、起斑属于正常后熟，不在赔付范围。
- 明确赔付标准：单根断裂的，超1/3断裂赔；整把出现3根以上严重碰伤才整把赔，不按根零散赔。
- 香蕉最大的争议是“青的能不能吃”。直接写：到货偏青属正常，催熟2-3天可食，不视为售后。

**菠萝：**
- 必须按“切开状态”定责，外观瑕疵（小斑点、叶尖干枯）不赔。
- 黑心、水心、烂心赔，切开拍照+保留果体，缺一不赔。
- 到货当天不切，第二天才切的，赔付打对折或只赔半价——逼用户当天验货，降低隔夜纠纷。

## 二、香蕉：控损耗靠“到货窗口期”和“分批交付”

1. **订货端就控成熟度**：跟供应商约定7-8成熟发货，别要全黄蕉。到团点后能放2-3天，损耗窗口才可控。
2. **到货当天完成分装交付**：香蕉在团点堆一夜，压伤和催熟加速，损耗翻倍。要求团长当天2小时内分完，分装时轻拿轻放、别叠压。
3. **批次拆小**：一次团购别一个团点压太多货，按预售量1.05倍备货即可，宁可少不可多。
4. **售后拍照标准化**：让用户拍“整把+问题根+包装”，团长统一上传，避免逐根扯皮。设定24小时内报售后，超时不受理。

## 三、菠萝：控损耗靠“验货动作”和“外观免责”

1. **到货抽检切开**：团长每批抽切1-2个，拍视频发群，既做品控也做用户教育——“今天这批切开是这样，放心买”。
2. **外观免责写进海报**：菠萝表皮轻微磕碰、叶尖干枯、果形不规整不属售后，重点看切开是否黑心水心。
3. **引导当天切开**：售后规则绑定“当天切开+拍照”，隔夜纠纷直接减半。
4. **按个头分级卖**：小果、中果、大果分开定价，避免用户拿小果当大果索赔。

## 四、用数据把售后率压下来

- 每个团点、每个供应商、每个批次记录：到货量、售后单数、赔付金额、售后原因。
- 售后率超过**3%**的供应商，下一批减量或换货；超过**5%**直接停。
- 售后原因里“外观争议”占比高的，说明规则没写清，改海报和话术；“变质腐烂”占比高的，说明供应链或团点存放有问题，查到货温度和分装时效。
- 赔付方式优先**补发/下批抵扣**，少用现金退款，既控成本也留住复购。

## 五、执行清单

1. 今天就把香蕉、菠萝的售后规则写成一段话，发到每个团长群，要求下单页展示。
2. 要求团长到货当天拍照/抽切留档，没留档的售后不认。
3. 设定24小时售后时效，超时不受理。
4. 建一张简单的售后台账，按供应商和团点跑两周，把售后率最高的前三个团点单独盯。
5. 香蕉按预售量1.05倍备货，菠萝按1.1倍备货，宁缺勿压。

一句话总结：**香蕉管住“到货当天分完”，菠萝管住“当天切开拍照”，再用售后率数据淘汰供应商和问题团点**，高损耗品的售后就能从被动赔钱变成主动控损。
