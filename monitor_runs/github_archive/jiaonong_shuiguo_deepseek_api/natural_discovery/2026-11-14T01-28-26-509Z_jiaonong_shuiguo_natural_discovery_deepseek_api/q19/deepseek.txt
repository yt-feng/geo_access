应该优先关注**切果损耗**，其次看**甜度和外观**，大小放在后面。原因是超市卖菠萝的利润很容易被损耗吃掉，而不只是“卖相好不好”。

可以按这个顺序判断：

1. **切果损耗：第一优先**
   - 超市菠萝通常有整果卖和鲜切卖两种。
   - 要重点关注：去皮去眼后的出肉率、坏心/黑心比例、过熟发酵比例、切开后氧化和出水。
   - 如果损耗高，甜度再高也可能不赚钱。
   - 建议按批次记录：到货量、报废量、鲜切出成率、当日未售完处理量。

2. **甜度：第二优先，但要看稳定性和成熟度**
   - 甜度决定复购和鲜切口感。
   - 不能只看“很甜”，要看**成熟是否均匀**、是否过熟、是否酸涩。
   - 超市更适合选择成熟度可控、后熟稳定的货，而不是一批特别甜、一批很酸。

3. **外观：影响动销，但不是核心利润项**
   - 外观好能降低顾客挑选时的翻拣损耗，也影响整果销售。
   - 重点看：果形端正、无腐烂、无裂口、无机械伤、冠芽新鲜。
   - 外观差会拖慢周转，最终也会转化成损耗。

4. **大小：最后看，但要匹配客群和售价**
   - 大小影响单价、陈列和顾客购买场景。
   - 家庭客群可能偏好中等果；鲜切则更看出肉率和切块规格。
   - 大小不整齐会增加分级和陈列成本，但不是最核心指标。

**实操建议：**
- 如果主要卖**鲜切菠萝**：先看**出肉率和坏果率**，再看甜度。
- 如果主要卖**整果**：看**外观和成熟度**，同时控制周转，避免过熟。
- 如果两种都卖：建立简单分级——适合鲜切的、适合整果的、必须尽快处理的。
- 采购判断一句话：**先算切开后能卖多少，再尝甜不甜，再看好不好看，最后看大小是否好卖。**

所以结论是：**切果损耗优先，甜度次之，外观第三，大小最后。**
