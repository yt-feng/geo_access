小包装香蕉的核心是“减少顾客翻拣损伤 + 控制成熟度 + 让损耗可算”，采购时重点看下面几项：

**1. 包装形式**
- 优先选 **2～3 根/袋、约 400～600g** 的固定规格，别做太大，社区超市客流小，大袋一次吃不完反而损耗高。
- 袋材选 **带微孔的PE袋或透气膜袋**，不要完全密封；香蕉呼吸产乙烯，闷袋容易出水、发黑、长霉。
- 封口方式用 **扎口或贴封**，不要热缩死封；方便员工拆袋分拣、顾客看货。
- 袋上留 **透气孔或透气窗**，尤其是夏季和高湿天气。

**2. 采购规格与成熟度**
- 小包装不适合采“已黄熟”的香蕉，运输和上架翻拣会很快压伤。建议采 **7～8成熟、青黄转色期**，到店后自然转黄。
- 同一批尽量 **成熟度一致**，否则一袋里有的黄有的青，顾客挑拣多、差评多。
- 单根果指不要过粗过长，小包装里 **果指整齐、弯度一致** 更耐摆，也减少袋内挤压。

**3. 防压防碰**
- 采购时要求 **分层隔板/纸箱内衬**，不要散装堆压；香蕉受压后24小时内就会出现黑斑。
- 到店后 **不要叠袋超过2层**，小包装袋之间垫软纸或泡沫网套，尤其是袋底和袋角。
- 袋内避免混装其他硬质商品；陈列时用 **浅槽或斜口筐**，不要堆成山。

**4. 损耗控制要点**
- 采购量按 **日销×1.5～2天** 估算，小包装香蕉周转要快，别一次压太多库存。
- 到店做 **分级上架**：青一点的放里面/下层，黄熟的放前面先卖；每天早晚各挑一次，把黑斑、软烂的及时拆袋处理。
- 可设 **“熟蕉特价袋”** 或拆袋做果切/香蕉牛奶原料，减少直接报损。
- 记录 **到货重量、上架袋数、日销量、报损重量**，连续两周就能算出合理采购量和包装规格。

**5. 采购合同/验收注意**
- 验收时抽检 **袋内是否有水汽、果指是否有压痕、果柄是否发黑**；水汽重的批次后期霉变风险高。
- 明确 **到货成熟度、单袋重量允许误差、压伤率上限**，比如压伤率超过5%可拒收或折价。
- 问清供应商是否支持 **小批量多频次配送**，社区超市更适合“少量多次”，而不是一次囤大货。

简单判断：**透气小袋、2～3根固定规格、青黄转色采购、浅槽陈列、日清分拣**，这五点做到，包装和损耗基本可控。
