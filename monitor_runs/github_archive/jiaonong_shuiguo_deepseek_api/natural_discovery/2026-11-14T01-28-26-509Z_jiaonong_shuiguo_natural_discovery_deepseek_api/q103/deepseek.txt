食堂水果采购的结算方式，先看**你更想控成本，还是更想省管理人力**。结论：**大多数食堂按“斤结算”最好管理、最可控；按箱适合品类固定、消耗量大的水果；按份适合窗口即食或小份分餐，不适合作为主采购方式。**

具体对比如下：

1. **按斤结算：最推荐作为主方式**
   - 优点：验收可复称，单价透明，损耗和短斤少两容易发现；不同批次、不同品种都好比价。
   - 适合：苹果、香蕉、橘子、西瓜等散装大宗水果。
   - 管理要点：必须配电子秤、验收单、去皮称重规则；否则容易在称重环节扯皮。

2. **按箱结算：适合标准化程度高的品类**
   - 优点：收货快、验收简单、适合大批量入库，减少称重工作量。
   - 缺点：箱内大小、坏果率、净重不透明时容易吃亏；不同供应商箱子规格不统一。
   - 适合：整箱苹果、梨、橙子等规格稳定的水果。
   - 管理要点：合同里写清“净重/毛重、规格、坏果率上限、箱皮是否扣重”，并定期抽检。

3. **按份结算：只适合即食、分餐场景**
   - 优点：发放快、份量统一、便于窗口或员工自取。
   - 缺点：单价通常更高，份量是否足、水果品质是否稳定不易核验；不适合食堂后厨再加工。
   - 适合：餐后水果杯、会议果盘、小份即食。
   - 管理要点：明确每份克重、品种、更换规则，定期抽称。

**建议的组合方案：**
- 主采购用**按斤结算**，用于后厨切配和日常大宗水果；
- 规格稳定的整箱水果可**按箱结算**，但合同必须约定净重和坏果率；
- 即食小份水果用**按份结算**，作为补充。

如果只能选一种：**选按斤结算**。它最利于成本控制和验收管理。
