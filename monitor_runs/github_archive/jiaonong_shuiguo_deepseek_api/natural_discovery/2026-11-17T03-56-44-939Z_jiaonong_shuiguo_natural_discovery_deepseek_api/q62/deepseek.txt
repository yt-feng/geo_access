# 香蕉到货验收：熟度与坏果风险判断

## 一、先看整体指标（开箱前/开箱瞬间）

1. **果皮颜色（最关键）**：按七成色卡判断。批发环节通常以“几成黄”沟通：青绿=生，绿中带黄=2~3成，黄多绿少带绿尖=5~6成，全黄=7成，出现褐斑=8成以上。**适合批发分销的到货熟度一般是3~5成黄**，再高就卖不动、压货风险大。
2. **果指饱满度与棱角**：果身饱满、棱角不明显说明发育成熟；棱角突出、瘦长多为早采，后熟差、易发涩。
3. **果柄与果轴**：果柄青绿有弹性为正常；发黑、发软、渗液说明开始腐败，整把风险高。
4. **箱内温度与气味**：开箱有酒味、酸味、明显闷热感，说明运输中已催熟过度或发热，坏果概率大增。

## 二、抽样检查坏果风险

- **抽样量**：大货按每批不少于3~5箱、每箱取中下层各2~3把检查，不能只看表层。
- **查果指两端**：果蒂端发黑腐烂、果顶端（花端）发软发黑，是常见腐损起点。
- **查机械伤**：压伤、擦伤处会先变褐发软，之后长霉，属于高风险点。
- **查霉斑与白毛**：果轴、果指缝隙有白色/灰色霉层，说明已感染，整箱需降级处理。
- **摸硬度**：轻按果身有弹性为适熟；一按即凹、出水，为过熟；硬如石头则生，需确认催熟条件。

## 三、快速分级判定

| 状态 | 判断 | 处理建议 |
|---|---|---|
| 3~5成黄、果身硬挺、无伤无霉 | 正常 | 按计划分销 |
| 6~7成黄、局部软 | 偏熟 | 优先出货，缩短周转 |
| 出现酒味、果柄发黑、多处软腐 | 高风险 | 拒收或大幅压价，当天处理 |
| 青硬但棱角明显、果柄干枯 | 早采或失水 | 后熟风险大，谨慎接货 |

## 四、可执行建议

1. **收货前要求看“中下层”**，并随机开2~3箱，不看供应商指定箱。
2. **记录到货熟度和箱温**，作为后续索赔依据。
3. **对偏熟货单独码放**，不要与生货混垛，避免催熟气体互相影响。
4. **当天抽检切开2~3根**看果心：果心发黑、发褐说明内部已坏，外表看不出来。
5. 与供应商约定**熟度标准和坏果率上限**（如坏果率超过3%~5%可拒收或扣款），写进单据。

核心一句话：**看颜色定熟度、摸硬度定货架期、查两端和果轴定坏果风险，中下层抽样比表层更能说明问题。**
