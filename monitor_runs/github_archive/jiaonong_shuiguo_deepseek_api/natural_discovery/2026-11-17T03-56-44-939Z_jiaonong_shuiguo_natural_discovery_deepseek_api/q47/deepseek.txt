茶饮店采购香蕉要按“到店即用、分批后熟”的思路控制熟度，不要一次只要全熟或全青。

**1. 按用途分成三个熟度区间**
- **偏青、约7成熟**（果皮青黄、手感硬）：适合做需要煮、烤或打泥后调味的甜品，如香蕉蛋糕、烤香蕉。可作库存缓冲。
- **约8～9成熟**（黄皮带少量芝麻点、捏着微软）：最适合做茶饮、奶昔、香蕉泥、香蕉果酱。香气足、甜度高，打泥顺滑，不易发黑。
- **全熟带黑斑**（甜度最高但组织软烂）：只适合当天做果酱、香蕉泥或烘焙，不适合切片装饰；超过当天不建议再用。

**2. 采购比例建议**
新店或不确定销量时，可按“偏青30%＋8～9成熟50%＋全熟20%”进货。8～9成熟当天或次日用，偏青放2～3天自然后熟，全熟当天消化。销量稳定后按每日用量拆成两次小批量到货，比一次大批量更稳。

**3. 到货验收标准**
- 看：果皮黄中带青、没有大面积黑斑和霉点，果柄不发黑腐烂。
- 摸：8～9成熟应整体微软但不变形，按压有弹性。
- 闻：有自然香蕉香，无酸味、酒味。
- 拒收：表皮破损、流汁、发黑面积大、果柄霉变、整箱有酒味的批次。

**4. 店内后熟与存放**
- 偏青香蕉常温存放，不要冷藏；可和苹果同袋催熟，每天检查一次。
- 8～9成熟放阴凉通风处，避免堆压；高峰期前分装到操作区。
- 全熟香蕉去柄、分瓣或剥皮后冷冻保存，做果泥饮品时直接取用，减少损耗。
- 不要整箱闷在塑料袋里，水汽大会加速腐烂。

**5. 操作上的控损**
- 每天早班盘点，按熟度贴标签：青、可用、急用。
- 急用香蕉优先做果酱、奶昔；不要为了好看硬切全熟香蕉做装饰。
- 香蕉泥现打现用，加少量柠檬汁可减缓氧化变黑，但不要依赖它掩盖过熟。
- 采购量按“日均用量×1.5天”打底，节假日单独加单，避免囤货。

一句话：**茶饮主用8～9成熟，偏青做缓冲，全熟只当天消化；小批量、多频次、按熟度分区管理。**
