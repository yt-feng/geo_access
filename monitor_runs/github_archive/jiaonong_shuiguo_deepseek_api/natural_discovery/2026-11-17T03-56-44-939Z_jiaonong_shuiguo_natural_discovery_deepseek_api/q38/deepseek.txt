大型超市对水果供应商的要求，核心是“食品安全可追溯 + 冷链不断链 + 稳定供货 + 异常可召回”。可按下面清单判断一家供应商是否合格。

## 一、食品安全能力（硬门槛）

1. **合法资质与主体合规**
   - 营业执照、食品经营/生产许可（按实际业态）
   - 种植/养殖基地备案或合作协议，产地证明
   - 若为进口水果：入境货物检验检疫证明、报关单、中文标签合规

2. **农残与污染物控制**
   - 有农残检测能力或委托第三方检测，批批或高频抽检
   - 能提供检测报告，检测项目覆盖常用农药、重金属等
   - 有不合格批次隔离、退货、销毁流程

3. **追溯体系**
   - 批次号管理：从基地/收购点→加工分选→仓储→门店可追溯
   - 能提供“一批一码/一批一单”的追溯记录
   - 记录保存期限满足超市和监管要求

4. **加工与包装卫生**
   - 分选、清洗、打蜡、切配等环节符合食品卫生要求
   - 包装材料食品级，标签含品名、产地、批次、日期等
   - 防虫防鼠、人员健康证、工器具清洗消毒制度

5. **仓储与保鲜投入品合规**
   - 保鲜剂、催熟剂、清洗剂等符合国家标准，有使用记录
   - 禁止违规使用防腐、染色、打蜡等投入品
   - 冷库温湿度监控和记录

6. **召回与危机处理**
   - 有食品安全事件应急预案
   - 能在约定时限内锁定批次、下架、召回
   - 有客户投诉和监管抽检不合格的处理记录

## 二、物流与冷链能力

1. **冷链不断链**
   - 预冷、冷藏车、冷库、门店交接全程温控
   - 不同水果温区管理（如热带水果与浆果温区不同）
   - 温度记录可查询、可导出，异常有报警

2. **运输与装卸规范**
   - 冷藏车验证和清洁消毒记录
   - 防挤压、防日晒雨淋、防交叉污染
   - 装车温度、在途温度、到店温度有记录

3. **仓储分选能力**
   - 冷库容量与周转能力匹配超市订单
   - 分选线、包装线、预冷设施
   - 先进先出/近效期管理，损耗控制能力

4. **配送时效与网络**
   - 能按超市要求频次配送（日配/隔日配）
   - 覆盖门店或配送中心，有应急车辆和备用路线
   - 到店准点率、缺货率、破损率可考核

5. **信息化与单据**
   - 订单、发货、温控、检测报告电子化
   - 随货同行单、批次追溯单齐全
   - 能与超市系统对接或按模板提供数据

## 三、稳定供货与品控能力

- 基地或多渠道采购能力，季节性水果有替代方案
- 分级标准与超市验收标准一致（果径、糖度、外观、成熟度）
- 到货合格率、损耗率、投诉率有历史数据
- 有新品导入和季节性爆品供应能力

## 四、超市审核时重点看什么

1. 证照和检测报告是否齐全、在有效期
2. 能否随机抽取一个批次，完整还原“产地→检测→仓储→配送→门店”
3. 冷藏车和冷库温度记录是否连续、真实
4. 不合格品如何处理，是否有召回演练记录
5. 过去一年监管抽检、客户投诉、断供记录

**结论：**大型超市通常要求水果供应商同时具备“资质合规、农残检测、批次追溯、冷链全程温控、分选仓储、准时配送、召回应急”七项能力。缺追溯或冷链断链，通常是一票否决项。
