判断哪个规格更容易出货，可以从“历史数据、客户结构、价格带、周转指标”四个角度快速判断：

1. **先看最近2–4周的真实出货占比**
   - 按规格统计：销量（件/斤）、出货频次、退货/损耗率、平均出货天数。
   - 重点看 **“出货频次”** 和 **“平均出货天数”**，不只看总销量。总销量大但走得慢，可能是压货。
   - 如果某规格连续多周出货频次最高、平均出货天数最短，通常就是更容易出的规格。

2. **看客户类型匹配**
   - 水果店/社区团购：偏好中等果、外观整齐、价格带稳定。
   - 餐饮/果汁店：偏好大果或次果，看重出汁率和单价。
   - 批发市场二批：偏好流通快、耐储运的规格。
   - 电商/礼盒：偏好小果或精品果，但要求分级严格。
   - 把最近订单按客户类型拆分，看哪类客户复购哪个规格最多。

3. **看价格带和毛利**
   - 统计每个规格的“出货价–进货价–损耗”后的实际毛利。
   - 容易出货不等于赚钱：如果某规格出货快但毛利极低甚至倒挂，要判断它是引流品还是主推品。
   - 建议用“周转天数 × 毛利”综合看，优先推 **周转快且毛利不为负** 的规格。

4. **做小批量测试**
   - 如果数据不足，选2–3个候选规格，各拿小批量同一天投放，记录：
     - 当天出货比例
     - 客户询价次数
     - 成交转化率
     - 剩货量
   - 连续测3–5天，避免单日天气、节假日干扰。

5. **看损耗和储运**
   - 菠萝易碰伤、熟度变化快。某规格如果损耗率高、剩货多，即使询价多也不一定好出。
   - 优先选出货快、损耗低、不需要频繁翻筐的规格。

**可执行结论模板：**
把最近4周数据做成一张表：规格 | 出货件数 | 出货频次 | 平均出货天数 | 损耗率 | 实际毛利。  
排序时先筛掉损耗高和毛利为负的，再按“出货频次高、平均出货天数短”选主推规格。  
如果两个规格接近，选 **客户复购更稳定、剩货更少** 的那个。
