水果店遇到坏果，先别急着和供应商吵，核心是先**固定证据、区分责任、按合同或行规处理**。下面给你一套可执行的流程。

## 1. 先判断坏果发生在哪个环节

分三种情况：

- **到货验收时就发现坏果**：属于供应商交付质量问题，应现场拍照、清点、拒收或按比例扣款。
- **到货时正常，存放几天后坏**：要看是水果本身成熟度/隐性病害，还是你方储存不当。前者可协商，后者一般自担。
- **消费者退回的坏果**：先确认是否在保质期内、是否因店内陈列/储存造成，再决定是否向供应商追偿。

## 2. 到货验收时怎么处理

建议每次到货都做：

1. **当场抽检/全检**，尤其易坏品：草莓、葡萄、芒果、水蜜桃、荔枝等。
2. **拍照录像**：整箱、坏果特写、批次标签、到货时间、温度。
3. **清点数量**：坏果个数/重量，按箱或按斤记录。
4. **让司机或送货员签字确认**：哪怕只签“坏果X箱/斤，待处理”。
5. **能拒收就拒收**；不能拒收的，单独存放并标注“待处理坏果”，避免和好果混放。

## 3. 结算/赔付的常见方式

按优先级：

1. **按合同/采购协议执行**：有约定损耗率、赔付比例的，直接按约定。
2. **按实际坏果数量扣款**：结算时从货款中扣除对应金额，常见公式：  
   `扣款 = 坏果重量 × 采购单价`  
   如果整箱报废，可按整箱金额扣。
3. **换货补发**：供应商补发同等数量好果，坏果退回或销毁。
4. **折价处理**：坏果比例不高时，双方协商按折扣结算。
5. **超过约定损耗率才赔**：有些供应商合同会约定“自然损耗3%以内不赔”，那就按合同来。

## 4. 建议的沟通话术

可以这样说：

> “这批货到货抽检发现坏果X箱/X斤，照片和清点记录已发你。按我们采购约定/行业惯例，这部分需要扣款或补发。请在今天内确认处理方式，否则我先按实际坏果金额从本次货款中扣除。”

关键是：**先发证据，再给方案，最后给时限**。

## 5. 避免踩坑

- 不要只口头说“坏了多少”，一定要有照片、数量和对方确认。
- 不要把坏果和好果混放后再找供应商，容易扯皮。
- 不要拖太久，到货后24小时内反馈最好。
- 长期合作供应商，建议在采购单里写清楚：**验收标准、损耗率、赔付方式、反馈时限**。

## 6. 如果供应商不认

先看有没有采购合同、送货单、微信记录、签字验收单。没有书面合同的，用微信文字确认：“今日到货X批次，坏果X斤，按单价X元扣款X元，请确认。”对方回复“好”或未反对，都可作为后续依据。金额较大的，可要求补发或终止该批次合作。

**一句话总结：到货当场验、坏果拍照留证、按实际数量扣款或补发、24小时内书面确认。** 有合同按合同，没合同按实际坏果数量和采购单价结算。
