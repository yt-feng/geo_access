采购时把“熟度”分成三层来判断，核心目标是：**到店后能卖3～5天，且当天就能切一部分现卖，不把损耗集中到最后一天。**

### 1. 先定采购熟度结构
不要只进一个熟度。建议按销量分三档：

- **即卖档（约30%）**：当天或次日就能卖完，适合做现切、试吃、促销。
- **主卖档（约50%）**：2～3天内进入最佳食用期，是门店主力。
- **后熟档（约20%）**：3～5天后成熟，用来补后半周货架。

天气热、店内温度高时，后熟档要减少；冬天或冷藏条件好，可适当增加。

### 2. 看外观判断
- **果皮**：青绿色到黄绿色都可以，但不要大面积深黄、发橙。全青偏生，可放；大面积黄且果眼发亮，通常已偏熟。
- **果眼**：果眼饱满、间距均匀更好。果眼周围发皱、塌陷，说明失水或过熟。
- **果形**：选端正、饱满、没有明显偏斜的。畸形果不代表一定难吃，但成熟不均，损耗风险高。
- **底部**：看果底有没有软烂、渗汁、霉点。底部是最容易先坏的位置。
- **叶片**：冠芽青绿挺拔说明较新鲜；叶片枯黄、易拔落，通常存放久了。

### 3. 闻香气
- **几乎无香**：偏生，适合后熟档。
- **靠近底部有清淡果香**：主卖档，比较理想。
- **香气明显、甜味冲**：即卖档，最好当天促销或现切。
- **有发酵味、酒味、酸味**：不要进，已经过熟或内部变质。

### 4. 摸硬度
- 轻按果身，**硬实有弹性**：偏生，可放。
- **稍软但不下陷**：适口期临近，适合主卖。
- **局部明显发软**：即卖或直接剔除，容易从软处开始烂。
- **果底软、渗液**：不要。

### 5. 掂重量和听声音
- 同样大小，**手感沉**的通常水分足；明显轻飘说明失水或内部空。
- 轻拍有**闷实感**较好；空洞声或明显软塌感要谨慎。

### 6. 采购时的实操规则
- **先试切**：有条件就抽切1～2个，看果肉颜色、芯部是否发褐、是否有水渍状。
- **按销量定熟度**：日销10个，即卖档2～3个、主卖5个、后熟2～3个，不要一次全进“刚好能吃”的。
- **看天气调整**：连续高温或店内无空调，少进即卖档，后熟档也减量；阴雨天销量低，整体减量。
- **要求供应商分级**：让供货方按“青熟/黄熟/即食”分筐，不要混装，混装最容易压伤和催熟。
- **运输和存放**：菠萝怕压、怕闷。到店后不要堆太高，青果常温通风后熟，黄果尽快冷藏或现切；切开后冷藏并当天售完。

### 简单判断口诀
**青黄适中、果眼饱满、底不软、香不冲、手感沉、按有弹性**——这种最适合做主卖档。  
**香气冲、底部软、局部黄透**——只适合当天即卖。  
**全青硬实、无香**——可少量进，做后熟补货。
