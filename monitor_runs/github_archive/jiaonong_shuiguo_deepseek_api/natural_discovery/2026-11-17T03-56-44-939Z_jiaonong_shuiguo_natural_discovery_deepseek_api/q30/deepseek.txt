# 超市水果到货品相不好的售后流程约定

核心原则：**把“什么算品相不好、谁来判、多久内提、怎么赔”四件事写进合同或订单条款**，避免事后扯皮。建议按以下框架约定：

## 一、验收标准（先定义“品相不好”）

不要用“新鲜”“好看”这类主观词，要可量化：

- **分级标准**：按品种写清规格（单果重量/直径、色泽、成熟度），约定“合格品率”下限，如到货合格率≥95%，低于即触发售后。
- **明确拒收情形**：腐烂、霉变、机械伤、冻伤、虫害、异味、严重萎蔫、规格不符的比例阈值（如单批次不合格率＞5%可整批拒收或部分拒收）。
- **抽样方法**：约定抽检比例（如每批次随机抽3箱/按5%抽检）和判定规则，避免“你挑坏的、我挑好的”各说各话。
- **参照物**：以样品、封样或双方确认的图片标准为准，附在合同后。

## 二、到货验收与异议期

- **当场验收**：到货后买方应在约定时限内（如2小时内/卸货时）完成外观验收，双方签字确认到货状态。
- **异议期**：约定“隐蔽瑕疵”（如内部腐烂、催熟不均）的提出期限，如到货后24小时内书面（含拍照/视频）提出，逾期视为验收合格。生鲜易腐，异议期不宜过长。
- **留证要求**：异议须附照片/视频、批次号、抽检记录，最好双方共同复检。

## 三、责任判定与处理方式

按不合格程度分档约定：

| 情形 | 处理方式 |
|---|---|
| 轻微品相问题（不影响销售） | 折价接收，按比例扣款 |
| 部分不合格（如10%–30%） | 按不合格数量退货退款，或整批折价 |
| 严重不合格/整批腐烂 | 整批拒收，卖方承担来回运费及损耗 |
| 卖方原因导致 | 补货、换货或退款，约定补货时限 |

同时约定**运费与损耗承担**：因品相问题退货的，往返运费由供货方承担；买方保管不善导致的变质由买方担责。

## 四、赔付与结算挂钩

- 明确赔付计算方式：按不合格数量×单价扣减，或约定违约金比例。
- 与账期挂钩：争议批次货款可暂缓支付，待处理完毕再结，避免“钱付了货烂了”。
- 约定累计不合格率超阈值时的后续措施（如警告、减少订单、终止合作）。

## 五、流程时限（写成可执行的节点）

1. 到货 → 买方2小时内验收并签收单
2. 发现问题 → 24小时内书面提出+举证
3. 卖方 → 24–48小时内答复并给出处理方案
4. 双方复检/协商 → 3个工作日内闭环
5. 扣款/补货在下一结算周期体现

## 六、建议补充条款

- **不可抗力与自然差异**：明确天气、运输等造成的轻微外观差异是否免责，避免滥用。
- **争议解决**：约定复检由第三方（如双方认可的质检机构）判定。
- **书面留痕**：所有异议、处理结果走书面/系统记录，微信沟通也应留存。

**一句话总结**：用“量化验收标准+短异议期+分档处理+举证留痕+结算挂钩”五件事把流程锁死，比事后争论“这算不算品相不好”有效得多。具体阈值（合格率、异议时长、扣款比例）需按水果品类和双方议价能力在合同中谈定。
