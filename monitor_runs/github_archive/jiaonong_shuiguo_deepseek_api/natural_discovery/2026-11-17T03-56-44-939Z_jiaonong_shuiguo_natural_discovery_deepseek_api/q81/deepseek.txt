**结论：即时零售平台卖水果，供应商应支持小批量高频补货，但必须按品类、销量和履约能力设门槛，用数据驱动补货。**

可执行判断如下：

1. **优先支持三类商品**
   - 高周转、易损耗：草莓、蓝莓、切果、香蕉、荔枝等。
   - 爆款和引流品：平台重点推的单品。
   - 预测波动大的时令品：天气、节假日、促销影响明显的水果。

   这些商品小批量高频补货能降低损耗、减少缺货，提升即时零售的履约体验。

2. **不宜无条件支持的情况**
   - 低周转、长保质期：苹果、梨、橙子等可适当加大批量、降低频次。
   - 供应商距离远、冷链成本高：高频小批量会把物流成本推高，应设最低起补量或集单配送。
   - 供应商履约能力弱：先要求其达到到货准时率、缺货率、损耗率等指标，再逐步提高频次。

3. **供应商侧应设的规则**
   - 分级补货：A类高频小批量，B类中频中批量，C类低频大批量。
   - 最低起补量：按门店/前置仓设置，避免单次配送成本失控。
   - 补货窗口和截止时间：明确下单、拣货、到仓时间。
   - 动态安全库存：按销量、天气、促销、保质期自动计算补货量。
   - 成本分担：高频补货增加的配送成本，可通过配送费、阶梯价或平台补贴明确分摊。

4. **平台侧要给的支撑**
   - 提供销量预测和库存可视化。
   - 设置缺货率、损耗率、到货准时率考核。
   - 对高频补货供应商给予流量、账期或配送补贴激励。
   - 允许供应商按区域集单，避免“一店一送”造成成本失控。

**一句话建议：支持小批量高频补货，但用“品类分层 + 最低起补量 + 补货窗口 + 成本分担 + 数据考核”落地，不能一刀切。**
