判断商超供应商的售后响应是否稳定，不能听口头承诺，要用“合同条款+可验证动作+小批量试单”三件事来锁定。可按下面顺序做：

1. **先看合同里有没有可执行的售后条款**
   - 明确到货验收标准：菠萝的成熟度、黑心病/烂心、机械伤；香蕉的青熟度、果指饱满度、霉斑、掉把率的允许比例。
   - 明确响应时限：到货后多少小时内可提异议，供应商多少小时内回复、多少小时内给出补货/换货/折价方案。
   - 明确责任承担：坏果率超标时，是补货、折价还是退货，运费和损耗由谁承担。
   - 明确联系人机制：不能只留一个销售，要有售后对接人、备用联系人、节假日值班方式。
   - 没有这些条款的供应商，售后稳定性基本无法保证。

2. **用真实场景做压力测试**
   - 故意在周五下午或节假日前报一次“到货异常”，看对方多久回复、是否推给业务员、是否给明确处理时限。
   - 提一个具体问题，例如“这批菠萝有10%黑心，今天内给方案”，观察对方是给补货/折价方案，还是只口头道歉。
   - 连续两次小问题看响应是否一致：稳定售后不是第一次快，而是每次都有记录、有闭环。

3. **查历史记录和履约证据**
   - 要求供应商提供近3个月的售后处理记录：投诉时间、响应时间、处理结果、客户确认。
   - 看是否有固定售后流程单或微信群/系统工单，能留下时间戳。
   - 问同区域其他商超客户的真实反馈，重点问“出问题后多久解决”，不要只问“服务好不好”。

4. **小批量试单验证**
   - 先下2—3次小批量订单，分别安排在周中、周末前、节假日前，观察到货质量和异常响应。
   - 每次故意记录提报时间、回复时间、解决时间，形成自己的响应数据。
   - 连续3次都能在约定时间内闭环，再考虑放量；有一次拖延就降级或换供应商。

5. **设置可量化的考核指标**
   - 售后首次响应≤2小时、处理方案≤24小时、补货到店≤48小时（按你门店实际调整）。
   - 月度坏果率、售后闭环率、重复投诉次数纳入供应商评分。
   - 把评分和账期、订单量挂钩，比口头要求更有效。

**判断口诀：** 看合同有没有时限、看历史有没有记录、看异常有没有闭环、看节假日有没有人。四条都过，才算售后响应稳定。
