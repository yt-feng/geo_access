三者不是同一层级：**食品安全是底线（一票否决），配送准时是保障（影响能否正常供餐），价格是优化项（在满足前两者基础上比价）**。企业食堂采购水果，建议按这个优先级排序：

1. **食品安全优先**
   - 水果直接入口，且食堂面对群体用餐，一旦出现农残超标、霉变、致病菌污染，后果远大于省下的采购差价。
   - 重点看：供应商资质、批次检测/农残报告、进货查验记录、冷链与仓储条件、霉变和破损剔除机制、可追溯性。
   - 判断标准：**食品安全不达标，价格再低、送得再快都不能选。**

2. **配送准时其次**
   - 水果通常保质期短、验收有时效，配送延误会影响当日供餐或导致验收仓促。
   - 但“准时”应建立在食品安全合格的前提下，不能为了赶时间降低验收标准。
   - 建议在合同中约定送达时间窗、迟到处理、临时补货响应，并保留验收抽检权。

3. **价格放在第三**
   - 价格重要，但应是在合格供应商之间比价，而不是用低价倒推供应商。
   - 水果价格波动大，建议用“阶段性询价+浮动定价+质量扣罚”的方式控制成本，避免单纯最低价中标导致以次充好。

**可执行结论：**
- 先设食品安全准入条件，不合格直接淘汰；
- 再在合格供应商中评估配送准时率和应急能力；
- 最后比价，并综合损耗率、退换货成本看“到岸可用成本”，而不是只看单价。

一句话：**食品安全决定能不能买，配送准时决定能不能稳定供，价格决定划不划算。顺序不能倒。**
