社区超市卖小包装香蕉，采购和包装上要重点抓“成熟度、分装方式、温湿度、周转速度”四件事。下面按可执行要点给你：

1. **采购成熟度要偏生一点**
   - 小包装周转慢于散卖，建议采购7～8成熟、果指硬、棱角明显的香蕉，到店后自然转熟。
   - 避免采购已出梅花点、果柄发黑、果指发软的货，分装后当天就容易压伤。
   - 按门店日销量拆批到货，别一次压太多库存。

2. **包装优先“透气+防压+小份”**
   - 用带透气孔的保鲜袋、网袋或开孔吸塑盒，不要完全密封；密封容易闷出水汽，加速黑柄和腐烂。
   - 小包装建议3～5根/份，按家庭一两次吃完的量定，避免大份卖不完反复搬动。
   - 盒装要在盒底加吸水纸或透气垫；袋装不要扎死口，留透气口。
   - 标签贴在袋面或盒盖，不要直接缠果指，避免胶带撕伤果皮。

3. **分装和陈列要减少机械伤**
   - 分装时轻拿轻放，不要拎果柄整串甩；果指间用软纸隔开，防止相互摩擦。
   - 陈列别堆高、别叠压，单层或两层斜放；避免放在冷柜出风口和阳光直射处。
   - 香蕉对低温敏感，不宜进冷藏柜；常温阴凉通风陈列，夏季控制门店温度，避免闷热。
   - 每天翻检，把转熟快的先卖或做促销，别等出黑点再处理。

4. **损耗控制要抓“先进先出+日清”**
   - 到货按批次贴日期，先进先出；小包装当天分装、当天优先卖，避免反复拆包。
   - 设定分级：青硬、转黄、适熟、过熟。适熟做正常小包装，过熟及时打折或转做果切/员工处理，别继续留在货架。
   - 记录每日销量和报损，按“日销量×1.2～1.5”备货，逐步校准采购量。
   - 运输和店内搬运避免挤压、雨淋、暴晒；到货后先通风散热再分装，别带着运输热气直接套袋。

5. **采购合同和验收要写清楚**
   - 验收看果柄、果指硬度、有无机械伤和黑腐；抽检箱内中层，不只看表层。
   - 和供应商约定到货成熟度、单根长度/粗细范围、允许损耗比例和退换货规则。
   - 优先选能小批量、多频次配送的供应商，降低门店库存压力。

简单说：**买偏生、装小份、袋透气、盒防压、常温通风、先进先出、按日销量小批量补货**。这样小包装香蕉的压伤、闷坏和过熟损耗会明显下降。
