# 坏果责任条款写法建议

核心思路是：**把损耗责任从"货到后扯皮"变成"交付节点+验收标准+分级处理"可操作的条款**。建议合同里写清以下几层：

## 1. 先定义"坏果"和"损耗率"

不要只写"坏果"，否则验收时各说各话。建议按等级界定：

- 腐烂、霉变、流汁、严重压伤致不可销售的，计为坏果；
- 轻微擦伤、外观瑕疵但可正常销售的，不计入坏果（或单独约定折价）；
- 约定计算口径：坏果重量 ÷ 该批次总重量 = 坏果率，按整批或按车/按托盘抽检折算。

## 2. 明确交付节点与风险转移

写清风险在哪个节点转移：

- **产地交货**：装车/出库并经买方（或买方委托的验货人）签字确认后，损耗风险转移给买方；
- **到货交货**：以到达指定地点开箱验收合格为交付，途损由卖方承担。

批发商如果担心的是"到货后损耗"，通常应争取**到货验收为交付节点**，或至少约定"运输途中非买方原因的损耗由卖方承担"。同时明确运输方式、温控要求（如冷链温度区间）由谁负责，因为很多损耗源于运输环节，责任要挂到实际控制方。

## 3. 设置验收流程和时限

- 到货后 X 小时内（生鲜建议 2–6 小时）完成抽检，逾期未提异议视为验收合格；
- 抽检比例（如每车随机抽 3–5 箱/托盘）和争议时的复检方式；
- 验收需双方签字确认的验货单，作为结算和索赔依据。

## 4. 分级处理机制（关键）

按坏果率分档约定后果，避免一刀切：

| 坏果率 | 处理方式 |
|---|---|
| ≤ 约定容忍值（如 2%–3%） | 正常收货，不追责 |
| 超过容忍值但在上限内 | 按坏果重量扣减货款，或按比例折价 |
| 超过上限（如 10%） | 买方有权拒收该批次，或要求换货/退货，运费及损失由卖方承担 |

同时约定**索赔时限和举证方式**（照片、视频、第三方检验），以及扣款是在当批货款中直接抵扣还是另行结算。

## 5. 几个容易漏的点

- **包装责任**：因包装不合格导致的压损、闷坏，责任归供货方，写进条款；
- **不可归责情形**：买方指定运输、买方延迟卸货、买方仓储不当造成的损耗，卖方不担责；
- **累计与单批**：是单批次考核还是月度累计考核，写清楚；
- **违约金上限**：约定赔偿以该批次货款为限，避免无限责任争议。

## 实操建议

条款谈判时，批发商可争取"到货验收+坏果率分档扣款"的组合；供货方则可争取"装车确认即转移风险+合理容忍值"。关键是**验收时限、抽检方法、坏果率阈值**这三个数字必须在合同里写死，否则条款再漂亮也难执行。

具体阈值要结合你的品类（叶菜、浆果、根茎耐储性差异大）和过往实际损耗数据来定，建议用近几个月的到货损耗率作谈判依据。
