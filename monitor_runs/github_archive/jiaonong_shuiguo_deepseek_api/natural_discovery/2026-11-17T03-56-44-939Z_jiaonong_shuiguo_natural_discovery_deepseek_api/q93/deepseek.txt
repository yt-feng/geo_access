三个都要关注，但优先级不是并列：**先定保质期和配送频次，再定包装**。菠萝切块是高风险鲜切水果，核心目标是“在可售窗口内卖完且不变质”。

可执行判断如下：

1. **保质期是底线**
   - 鲜切菠萝通常应冷藏销售，保质期按门店实际冷链、加工卫生和售卖条件验证后定，不能凭感觉写“几天”。
   - 建议做小批量保质期测试：同一批次分别在第1天、第2天、第3天观察色泽、气味、出水、发酸、发黏，确定可接受的最短安全售卖期。
   - 标签上要有加工/分装时间、保质期截止时间、贮存条件。临期必须下架，不能靠“看起来没坏”继续卖。

2. **配送频次决定损耗和新鲜度**
   - 鲜切菠萝更适合“小批量、高频次”配送，而不是一次送很多压库存。
   - 如果门店日均销量低，配送频次过高会增加物流成本；频次过低则保质期压力大、损耗高。建议按“日均销量 × 保质期天数 × 安全系数”倒推每次配送量，再定每周配送几次。
   - 优先保证冷链不断链：运输和门店冷藏温度要稳定，配送频次再合理，断冷链也会直接毁掉保质期。

3. **包装是保障，不是第一决策**
   - 包装主要解决防污染、防干耗、防串味和冷藏陈列问题。应选食品级、密封性合适、能冷藏的包装，并避免切块长期泡在汁水里。
   - 包装不能替代冷链，也不能把短保质期产品“包成”长保质期。若包装导致冷凝水多、透气差，反而加速变质。
   - 先确定保质期和配送节奏，再用包装去匹配：小份预包装适合便利店即买即走；大盒分装适合现场分切但销售慢的门店要谨慎。

**结论：保质期 > 配送频次 > 包装。**  
便利店最该先做的是：小批量高频配送、冷藏陈列、明确短保质期和临期下架规则；包装选食品级密封冷藏包装即可，不要本末倒置。
