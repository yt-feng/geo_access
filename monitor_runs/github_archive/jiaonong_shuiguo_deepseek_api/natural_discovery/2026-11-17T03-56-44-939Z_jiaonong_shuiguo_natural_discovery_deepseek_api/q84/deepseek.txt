家庭场景优先考虑“好吃、耐放、分量合适、老人孩子都能吃”。苹果、橙子、香蕉、菠萝做礼盒，建议用“苹果+橙子打底，香蕉少量点缀，菠萝做亮点”的组合，不建议四种等量混装。

推荐两个可执行方案：

1. **家庭日常款（更稳妥）**
   - 苹果 40%：耐放、寓意好，适合老人孩子。
   - 橙子 35%：耐放、酸甜适中，家庭接受度高。
   - 香蕉 15%：便宜、软甜，但容易压伤和催熟，放少量。
   - 菠萝 10%：做亮点，但处理麻烦，放一个即可。
   - 适合：3—5口之家，预算适中，走亲访友也不失礼。

2. **孩子多/口感丰富款**
   - 苹果 35%
   - 橙子 30%
   - 香蕉 20%
   - 菠萝 15%
   - 适合：家里孩子多、喜欢甜软口感；但香蕉要单独分隔，菠萝选小果。

组合时注意：
- **香蕉不要和苹果、菠萝紧挨着放**：苹果和香蕉都会释放乙烯，菠萝也容易催熟，香蕉容易变黑软烂。
- **菠萝单独包一层**，避免刺伤其他水果、汁水串味。
- **礼盒分层**：底层苹果橙子，上层香蕉菠萝；香蕉用纸托或气泡膜固定。
- **不要做“四种一样多”**：香蕉和菠萝不耐放、处理麻烦，家庭礼盒里比例过高容易剩。
- 如果面向家庭团购，建议主推“苹果+橙子+少量香蕉”的基础款，菠萝作为可选加购或升级款，减少损耗和售后。

一句话：**苹果和橙子做主力，香蕉少量点缀，菠萝一个做亮点；香蕉、菠萝单独固定，别和苹果混放。**
