# 茶饮店水果到货不合格：怎样约定补货才不影响营业

核心思路：**把"验收—补货—兜底"三段写进合同和采购单，让不合格品在门店营业前就被拦掉，而不是到店后才扯皮。**

## 一、验收标准前置（最关键）

- **规格写量化**：每个品类写明品种、单果重量区间、糖度下限（如柠檬糖度≥8%）、成熟度（几成熟）、无腐烂/无压伤比例上限（如抽检100个，次品≤3%）。
- **验收方式写清**：到货当场抽检、拍照留证；不合格判定标准双方签字确认样照，避免"我觉得不新鲜"的口头争议。
- **验收时限**：卸货后30分钟内完成验收，超时未验收视为合格（防止供应商拖时间，也保护你自己别拖）。

## 二、补货条款这样约定

1. **不合格品处理**：整批退货或按次品比例扣款，二选一写死，不要留"协商"。
2. **补货时限**：写明"验收判定不合格后 X 小时内送达"——按你的备货节奏定，建议**4–6小时**（覆盖当天营业高峰前），并注明"补货计入正常供货，不额外收费、不加运费"。
3. **补货质量**：补货批次同样适用验收标准，二次不合格可**拒收并转其他供应商**，且不免除供应商违约责任。
4. **替代方案兜底**：约定"供应商无法按时补货时，允许门店自行就近采购，差价由供应商承担"——这条最实用，保证营业不断档。

## 三、营业连续性兜底

- **安全库存**：合同里约定供应商按你的日均用量提供**1–2天备货量**常备库存，或你自己保留1天安全库存，到货不合格直接调用。
- **双供应商**：主力+备用，备用供应商每周小批量下单维持关系，断供时能立刻切换。
- **赔付条款**：因缺货导致门店停售某单品，按实际损失或约定违约金赔偿（金额写具体，如每次500元或当日该品类营业额）。

## 四、落地的两个动作

1. 把上述条款做成**一页纸采购单附页**，每批次到货由店长签字验收，拍照存档。
2. 合同里加一句**"本条款与供应商报价单冲突时以本合同为准"**，防止对方用格式条款架空。

一句话总结：**标准量化、时限写死、差价兜底、库存备份**——补货就有保障，营业就不会被一批烂水果卡住。
