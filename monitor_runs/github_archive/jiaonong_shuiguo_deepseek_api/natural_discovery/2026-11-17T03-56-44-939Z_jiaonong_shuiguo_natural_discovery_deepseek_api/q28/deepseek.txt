建议先从**香蕉**开始，但前提是你们能接受它的“稳定”主要体现在供应和周转上，而不是高毛利。

判断顺序可以这样排：

1. **香蕉：最适合作为第一步试水**
   - 需求稳定，顾客接受度高，不需要教育市场。
   - 周转快，适合测试进口水果的订货、催熟、陈列和损耗管理。
   - 但香蕉对**催熟和温控**要求高，损耗也集中在这里；如果超市没有稳定冷链和催熟管理能力，香蕉反而容易变成损耗品。
   - 建议先做小批量、固定供应商、固定周转天数，重点看损耗率和动销，不要一开始追求大陈列。

2. **菠萝：可以作为第二步**
   - 客单价和毛利通常比香蕉好，适合做进口差异化。
   - 但菠萝的成熟度、品种稳定性和顾客处理便利性会影响复购；需要搭配试吃、切果或去皮服务。
   - 如果超市有较好的生鲜加工能力，菠萝比苹果更容易做出差异。

3. **苹果：不建议作为“进口稳定品”的突破口**
   - 苹果本身国产供应强、价格透明，进口苹果的差异化有限。
   - 顾客对苹果价格敏感，进口苹果容易和国产苹果直接比价，毛利和动销都不容易做出优势。
   - 除非你们定位高端、有稳定进口苹果渠道和明确客群，否则不建议先上。

**可执行建议：**
- 第一阶段只引入香蕉，选1—2个SKU，小批量试销2—3周。
- 每周看三个指标：**损耗率、周动销率、毛利率**。损耗率压不住就先解决催熟和订货，不要扩品。
- 香蕉跑通后，再引入菠萝做第二品类，搭配试吃和切果服务。
- 苹果放在最后，等进口水果客群和供应链稳定后再评估。

一句话：**先香蕉试供应链和损耗管理，再菠萝做差异化，苹果最后看客群定位。**
