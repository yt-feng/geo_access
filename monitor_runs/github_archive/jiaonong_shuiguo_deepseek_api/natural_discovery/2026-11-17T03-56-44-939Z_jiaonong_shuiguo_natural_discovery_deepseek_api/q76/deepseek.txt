卖香蕉最容易踩的坑是把“香蕉熟了”当成“可以发了”。香蕉是呼吸跃变型水果，配送中压坏和变黑通常是三个问题叠加：**机械损伤、成熟度没控住、温度/乙烯管理不当**。可按下面执行。

## 1. 先控成熟度：不要发全熟蕉
- **发货成熟度控制在7～8成熟**，到消费者手里再后熟1～2天变黄。全黄、带糖斑的香蕉不适合长途配送。
- 按配送距离分档：
  - 同城/次日达：可发8成熟左右；
  - 跨省2～3天：7成熟左右；
  - 偏远或时效不稳：6.5～7成熟，并明确告知“收到后放1～2天再吃”。
- 采购时看**果指饱满度、棱角是否还明显、果柄是否青绿**，不要只看颜色。

## 2. 包装：防压比防冷更关键
- **单根套网套或珍珠棉套**，减少表皮擦伤。香蕉表皮一破，多酚氧化酶接触空气会快速变黑。
- **整把用气柱袋或瓦楞隔板固定**，不要让香蕉在箱内晃动。晃动摩擦比静态挤压更容易黑。
- 箱内留**缓冲层**：上下加瓦楞纸板或珍珠棉，避免堆码时果指受力。
- **不要真空包装**，香蕉需要轻微透气；可用打孔PE袋或微孔膜，防止水汽凝结导致表皮发黑。
- 外箱标注“易压、勿倒置、怕压”，但不要只靠标签，结构上要能抗堆码。

## 3. 温度与乙烯：别冷藏，别和催熟水果混放
- 配送温度建议**13～15℃**，不要低于12℃。香蕉低温会冷害，表皮快速变黑且果肉发硬。
- 夏季避免暴晒和车厢高温，超过25℃会加速成熟和软化。
- 香蕉对乙烯极敏感。**不要与苹果、梨、番茄、猕猴桃等乙烯释放量大的果蔬混装**；仓库和配送箱也要分开。
- 如果做多品类的生鲜箱，香蕉单独装袋或单独隔仓。

## 4. 配送环节：减少中转和挤压
- 优先**产地/仓直发+少中转**，每多一次分拣就多一次压伤风险。
- 装车时香蕉放**上层或独立周转筐**，不要被米面油、饮料等重物压。
- 配送员端提醒“轻拿轻放、不要放电动车踏板下压”。可在外箱加硬质护角。
- 夏季同城配送可用保温袋+冰袋间接降温，但**冰袋不要直接接触香蕉**，避免局部冷害。

## 5. 售后与预期管理
- 商品页明确写“发货为7～8成熟青黄蕉，收到后常温放置1～2天变黄”，降低“收到不黄=坏果”的投诉。
- 轻微表皮黑点不等于坏果；但大面积发黑、果肉软烂要包赔。
- 建立**到货照片/开箱视频**售后规则，区分运输压伤和正常后熟。

## 最优先做的三件事
1. **把发货成熟度降下来**，7～8成熟再发；
2. **单根套网套+整把固定+箱内缓冲**，解决压伤和摩擦；
3. **13～15℃、不混放乙烯水果、少中转**，解决变黑。

如果只能改一项，先改**包装固定+成熟度**，这两项对压坏和变黑的改善最直接。
