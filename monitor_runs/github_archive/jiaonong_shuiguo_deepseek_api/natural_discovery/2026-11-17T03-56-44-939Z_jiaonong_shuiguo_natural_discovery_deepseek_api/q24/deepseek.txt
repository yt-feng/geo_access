建议先要“可核对、能追溯到批次”的资料，不要只看一张合格证。优先顺序如下：

1. **本批次农残检测报告**
   - 要求报告日期覆盖本供货批次，列明检测项目、方法、结果、判定依据。
   - 最好由具备CMA资质（或CATL等相应资质）的检测机构出具；至少能核对报告编号、样品名称、抽样日期、生产/供货单位。
   - 注意“报告对应样品”是否就是你要采购的品种和批次，不能拿通用报告或长期有效报告代替。

2. **供应商资质与主体责任资料**
   - 营业执照、食品经营许可证/食品生产许可证（按供应商类型）。
   - 供应商与种植基地/合作社/批发市场的采购合同或供货关系证明。
   - 供应商食品安全承诺书、农残控制措施说明。

3. **产地与批次追溯资料**
   - 产地证明、种植基地信息、采收日期、包装日期、批次号。
   - 进货凭证、送货单，单据上要有品种、数量、批次、供应商盖章或签字。
   - 如从批发市场进货，索取市场开具的销售凭证和快检记录。

4. **快速检测/入场检测记录**
   - 供应商或产地的农残快检记录，最好含检测日期、项目、结果、检测人。
   - 超市自身也可做入场快检，保留记录；快检不能替代法定检测，但可作为筛查和追溯依据。

5. **承诺与问题处理文件**
   - 质量保证协议：明确农残超标时的退货、赔偿、复检费用和法律责任。
   - 不合格品召回/处理流程、异常批次通知机制。

**执行建议：**
- 采购前把“每批次随货提供检测报告或快检记录+批次追溯单”写进合同或订单条款。
- 收货时核对：品种、批次、报告日期、检测机构、结论是否一致；不一致就拒收或暂缓入库。
- 对高风险品种（如叶菜、草莓、豇豆等）提高抽检频次，并保留留样。
- 不要接受“报告复印件无批次”“合格证无检测项目”“长期有效报告”作为唯一依据。
