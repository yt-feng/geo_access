更影响最终毛利的是**损耗低**，但准确说是：**先看损耗能不能控住，再看价格低不低**。对商超水果这种高损耗、短保质期品类，低价通常只是“毛利看起来高”，损耗会把它吃回去。

可以按一个简化公式判断：

**最终毛利 ≈ 销售额 × 毛利率 − 损耗成本 − 运营成本**

水果采购里，低价和低损耗的影响差异主要看三点：

1. **损耗弹性通常大于进价弹性**
   - 水果损耗从 5% 降到 3%，看似只差 2 个点，但对净毛利影响很直接。
   - 进价便宜 5%，如果带来更多次果、短保质期、动销慢，损耗可能反而上升 5%—10%，最终毛利更差。

2. **低价常常伴随更高隐性损耗**
   - 低价货源可能存在成熟度高、规格不匀、产地远、包装差、批次不稳等问题。
   - 商超水果不是“买进来就赚钱”，而是“卖出去且不烂掉才赚钱”。低进价如果导致陈列损耗、挑拣损耗、临期折价增加，最终毛利会被反噬。

3. **低损耗更容易转化为确定毛利**
   - 损耗可控意味着订货准确、周转快、鲜度和陈列稳定，售价和销量都更稳。
   - 对商超来说，稳定低损耗比单次低价采购更可持续。

**实操判断建议：**

- 如果两个供应商对比，不要只比进价，算：
  **单斤综合成本 = 进价 + 预估损耗分摊 + 挑拣/加工成本 + 退货折价风险**
- 优先选：**损耗率低、批次稳定、可退换、到货成熟度合适**的货源。
- 只有在以下情况，低价优先级才上升：
  - 该单品动销极快、周转天数很短；
  - 你有强促销能力，能在损耗发生前卖完；
  - 货源质量稳定，损耗可预估且不高于原供应商；
  - 低价带来的是可持续采购优势，不是尾货/次货。

**结论：**
对商超水果最终毛利，**损耗低通常比价格低更关键**。低价决定“理论毛利空间”，低损耗决定“能不能把毛利留下来”。采购决策应先控损耗，再谈低价；如果低价不能带来同等或更低的综合损耗，就不应优先。
