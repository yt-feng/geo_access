建议先做小规模测试，但默认优先选 **小把装（2–3 根）**，其次单根，整袋放最后。判断标准主要是：损耗率、客单价、购买场景和门店客流结构。

**1. 小把装：最适合便利店的主推**
- 便利店是即时消费场景，顾客常买“现在吃”的量，2–3 根刚好。
- 比单根更有客单价，又比整袋更容易卖完。
- 适合放收银台附近或鲜食区，作为早餐/加餐搭配。
- 建议定价按根折算后略低于单根，强化“小把更划算”。

**2. 单根：适合做引流和低门槛试买**
- 对独居、学生、只想尝一根的顾客友好。
- 但单根毛利低、称重/贴标/收银效率低，且容易因拿取造成机械损伤。
- 适合客流大、年轻客群多、有自助收银的门店；可作为小把的补充，不建议唯一形态。

**3. 整袋：谨慎上架**
- 整袋适合家庭采购，但便利店顾客家庭囤货需求弱。
- 香蕉后熟快，整袋一旦卖不动，损耗会明显放大。
- 除非门店位于社区、家庭客群强，或有预订/团购渠道，否则不建议作为主包装。

**可执行建议：**
- 首期按 **小把70%、单根20%、整袋10%** 的陈列量试 2 周。
- 每天记录销量、报废量、毛利率；若单根损耗高，就缩到只做收银台小篮。
- 香蕉按成熟度分级：青黄果做小把，熟果做单根促销或搭配酸奶/面包做套餐。
- 小把用透气保鲜膜/扎带，避免完全密封；整袋不要堆叠挤压。
- 若门店社区家庭客占比高，再增加整袋，但控制订货量，宁少勿多。

一句话：**便利店优先小把，单根做补充，整袋只在家庭客群明确时小量试。**
