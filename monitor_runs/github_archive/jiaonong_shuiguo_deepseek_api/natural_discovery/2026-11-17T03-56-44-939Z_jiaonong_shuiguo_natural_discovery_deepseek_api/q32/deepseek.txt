判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要按“来源能力—硬件设施—历史记录—合同约束”四层核验。

**1. 先看产地与货源组织能力**
- 问清香蕉来自哪些产区，是单一产区还是多产区组合。香蕉供应受季节和天气影响大，能全年稳定供货的供应商通常有跨产区调配能力，例如国内云南、广西、海南、广东等产区轮换，必要时补充进口货源。
- 要求提供最近12个月的逐月发货记录，看淡季月份是否仍有稳定出货，避免只展示旺季数据。
- 了解催熟和加工能力：是自有催熟库还是外协。自有或长期合作催熟库更可控，外协要确认产能和排期。

**2. 核查硬件与冷链**
- 香蕉对温度敏感，重点看供应商是否有预冷、冷藏运输和催熟库能力。
- 要求提供冷库/催熟库容量、温控记录方式、运输车辆温控配置。
- 可以实地或视频查看关键设施，重点看淡季是否仍正常运转，而不是临时租用。

**3. 用历史履约数据验证**
- 要求提供近12个月对你同类客户的供货记录，包括月度供货量、缺货次数、到货合格率。
- 可向其现有客户做背景核实，重点问淡季断供频率、质量波动、突发补货响应速度。
- 超市可先做3—6个月小批量试单，覆盖至少一个淡季月份，再决定是否签全年框架。

**4. 合同里写清稳定供货条款**
- 约定月度最低供货量和旺季增量响应时间。
- 设置缺货违约责任和替代货源报备义务。
- 明确质量标准、验收规则和价格调整机制，避免旺季临时涨价或降质。
- 要求供应商提供备用产区或备用加工方案，写入合同附件。

**快速判断结论：** 如果供应商只能说出单一产区、没有自有或稳定合作的催熟/冷链设施、拿不出连续12个月发货记录、也不愿接受淡季试单和缺货条款，就不宜认定为能全年稳定供货。建议先小批量试单覆盖淡季，再签全年框架。
