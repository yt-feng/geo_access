结论：**如果只能选一个指标，优先看“出汁率”，但真正决定好不好用的是“出汁率 × 甜度（或糖酸比）”的组合；甜度可以靠糖浆调整，出汁率很难补救。**

具体判断：

1. **出汁率更重要**
   - 茶饮店用菠萝通常是为了果肉感、果汁和香气。
   - 出汁率低，意味着同样出品要切更多菠萝、损耗更大、成本更高，而且果肉可能发干。
   - 甜度不够可以用糖浆、果酱调整；出汁率低很难靠配方弥补。

2. **但甜度不能完全不看**
   - 甜度太低、酸涩重，会拉高糖浆用量，掩盖果香。
   - 更该看**糖酸比和成熟度**：太生的菠萝酸涩、酶感强，出品不稳定。
   - 如果做鲜果茶、菠萝冰，甜度稳定会直接影响出品一致性。

3. **按用途分**
   - **做鲜果茶、果肉型饮品**：出汁率优先，兼顾糖酸比。
   - **做果酱、糖浆腌制、复配型饮品**：甜度权重可提高，因为后续可加工。
   - **做高价鲜果主打**：两者都要，且更看香气、纤维粗细、黑心率和批次稳定性。

4. **采购实操建议**
   - 先定最低出汁率门槛，再在合格样品里选糖酸比合适的。
   - 现场测：去皮称重→榨汁称重算出汁率；测糖度；尝酸涩和纤维感。
   - 不要只看“甜”，要看**甜酸平衡、香气、果肉纤维和坏果率**。

一句话：**出汁率决定成本和口感底子，甜度决定风味上限；采购时先卡出汁率，再用糖酸比选批次。**
