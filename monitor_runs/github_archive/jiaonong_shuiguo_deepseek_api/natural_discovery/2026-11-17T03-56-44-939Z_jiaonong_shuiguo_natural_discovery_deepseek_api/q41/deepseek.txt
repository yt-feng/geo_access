判断香蕉催熟能力是否稳定，核心是看**到货批次的一致性 + 催熟过程的可控性 + 催熟后的货架表现**。商超采购可以按下面几层做可执行的判断：

1. **看供应商的批次稳定性**
   - 要求供应商提供近几批的到货记录：同一产地、同一季节、同一包装规格的香蕉，到货时的青度、果指大小、梳形、饱满度是否接近。
   - 稳定催熟的供应商，通常能做到“同批青度一致、果指粗细均匀、无大量早黄果混入”。批次间差异大，催熟房就很难统一出房。
   - 优先选择有固定催熟合作工厂或自有催熟库的供应商，而不是临时拼货。

2. **看到货青果状态**
   - **青度一致**：同箱、同托香蕉颜色接近，不能一半青一半已转黄。
   - **饱满但不软**：果指饱满、棱角稍圆，说明成熟度够，催熟响应通常更稳定；太瘦的果催熟后容易软而不香。
   - **无机械伤和病斑**：碰伤、割伤、炭疽病斑会在催熟后集中爆发，导致“催熟不均匀”的假象。
   - **果柄切口新鲜**：切口干缩、发黑严重，说明采收或运输时间长，催熟后货架期短。
   - **冷害迹象**：表皮灰暗、有凹陷斑、催熟后不转黄或转黄发暗，说明可能受冷，催熟能力不可控。

3. **做小批试催熟**
   - 每换供应商或换产地季，先拿 1～2 箱做试催熟，记录：入房青度、温度、乙烯浓度/熏蒸方式、湿度、出房时间、转黄均匀度。
   - 稳定的表现是：**同批果转黄时间差不超过半天到一天，颜色从青到黄均匀，果肉软硬一致，没有大量“青头”或“黄身青蒂”**。
   - 连续 3 批试催熟结果接近，才可认为催熟能力稳定。

4. **看催熟房和操作可控性**
   - 催熟能力稳定不只是香蕉本身，还包括催熟条件是否可复制：温度、湿度、乙烯浓度、通风、码垛密度是否每次一致。
   - 如果供应商或催熟库每次靠“经验估”，没有记录温度、乙烯用量、出房时间，稳定性就难保证。
   - 采购可以要求供应商提供催熟记录，至少包括入房时间、温度曲线、乙烯处理方式、出房颜色等级。

5. **看出房后的货架表现**
   - 稳定催熟的香蕉出房后，**转黄均匀、果柄和果指连接处不先烂、货架 2～3 天颜色和软硬变化可预测**。
   - 如果出房当天很黄，第二天就大量软烂或出现“青头不熟”，说明催熟过程不稳定。
   - 观察同一托盘中上下层、内外层差异：差异大说明催熟房气流或码垛有问题。

6. **用数据建立供应商评分**
   - 每次到货记录：青度等级、均匀度、机械伤比例、试催熟转黄天数、出房均匀度、货架期损耗。
   - 连续跟踪 5～10 批，比较标准差。标准差小、损耗稳定，才算催熟能力稳定。
   - 采购谈判时可以把“批次均匀度”和“试催熟合格率”写进验收标准，而不只看价格和单果规格。

简单判断口诀：**同批青度齐、果身饱满无伤、试催3批结果近、出房转黄匀、货架损耗稳**。满足这些，基本可以认为催熟能力稳定。
