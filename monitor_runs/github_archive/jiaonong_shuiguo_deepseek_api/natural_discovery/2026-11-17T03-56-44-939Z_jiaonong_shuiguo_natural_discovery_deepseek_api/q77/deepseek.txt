结论：大多数生鲜电商更适合以**整果为主、切配为辅、冷冻做差异化补充**。如果只能选一个主推，优先**整果**。

**1. 整果：最适合做主销**
- **损耗更可控**：菠萝耐储运性相对较好，整果没有切开后的氧化、出水、微生物风险。
- **履约更简单**：不需要冷链切配环境，普通仓配即可，售后争议少。
- **毛利和定价空间更好**：可按规格、产地、品种做分层，适合做爆款和复购。
- **适合线上售卖**：用户对“整果到家”接受度高，图片展示和产地故事也好做。
- **注意点**：要解决“不会削、怕酸、怕不熟”的顾虑，可配开果教程、成熟度说明、坏果包赔。

**2. 切配：适合做补充，不适合作为唯一主力**
- **优点**：即食方便，适合办公室、烘焙、餐饮小商户、懒人场景，客单价可做高。
- **缺点**：保质期短、易出水氧化、需冷链、损耗和售后高；切配后重量和品相争议多。
- **适合条件**：你有中央厨房/净菜资质、稳定冷链、订单密度高，且能当天或次日达。
- **建议**：先小范围测试，做“鲜切菠萝盒”作为加购品，不要一上来铺大仓。

**3. 冷冻原料：适合B端和差异化，不适合普通C端主推**
- **优点**：保质期长、损耗低、适合烘焙/饮品/餐饮客户，标准化程度高。
- **缺点**：C端家庭购买频次低、需要冷冻履约、口感和“鲜”心智弱，普通生鲜电商卖不动。
- **适合条件**：你有B端客户、冷冻仓配能力，或做“冷冻菠萝块+饮品配方”组合。
- **建议**：作为利润补充和B端渠道品，不作为线上C端主销。

**可执行建议**
- **主推整果**：占SKU销量70%左右，做2-3个规格，强调成熟度、坏果包赔。
- **切配小步测试**：占20%左右，只在你冷链覆盖范围内卖，设置短保和售后规则。
- **冷冻做补充**：占10%左右，优先卖给餐饮、烘焙、饮品客户。
- **判断标准**：看损耗率、售后率、复购率。整果损耗低于5%、切配售后高于3%就应收缩切配；冷冻若B端复购稳定再扩。

一句话：**整果打市场，切配提客单，冷冻做B端和差异化。**
