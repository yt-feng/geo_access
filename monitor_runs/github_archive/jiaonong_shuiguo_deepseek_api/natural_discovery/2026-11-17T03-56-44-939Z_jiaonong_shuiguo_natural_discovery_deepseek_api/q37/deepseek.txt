商超做会员日水果活动，供应商需要提前配合的核心是：**把“活动要卖爆”翻译成可执行的商品、库存、价格、陈列、履约和风险预案**。建议按下面清单提前准备。

### 1. 活动商品与货盘确认
- **明确活动单品/爆品结构**：引流款、利润款、形象款各占多少，避免只靠低价单品。
- **确认规格和品质标准**：果径、等级、成熟度、包装规格、允许瑕疵比例，最好书面确认。
- **锁量锁价**：提前约定活动供货量、阶梯价格、价格有效期，防止临近活动涨价或断供。
- **备选替换品**：主推水果受天气、产区、物流影响时，供应商需提供同价位替代方案。

### 2. 库存与产地组织
- **提前备货**：按预估销量的1.2—1.5倍准备安全库存，爆品单独锁定货源。
- **分批次到货**：水果损耗高，不建议一次性压库，按活动前1—2天和活动当天分批到店/到仓。
- **成熟度控制**：根据售卖节奏安排不同成熟度批次，避免活动首日未熟、次日过熟。
- **产地/加工厂产能确认**：分拣、打包、贴标、预冷能力要提前排产。

### 3. 价格与费用配合
- **活动供价明确**：含税/不含税、到仓价/到店价、运费承担方写清楚。
- **促销费用分担**：堆头费、试吃费、损耗补贴、临期折价由谁承担，提前确认。
- **价格保护**：活动前后不得出现供应商给其他渠道更低供价导致商超价格形象受损。
- **结算方式**：账期、返利、活动后库存处理方式提前约定。

### 4. 包装、标识与合规
- **活动专属包装/贴标**：会员日标识、价格签、产地信息、等级标识按商超要求提前到位。
- **称重与条码**：预包装商品条码、称重码、价签信息必须与系统一致。
- **合规证照**：检测报告、产地证明、农残检测、进口水果报关及检疫资料备齐。
- **标签规范**：品名、规格、产地、等级、保存方式、保质期/食用建议清晰。

### 5. 物流与到店履约
- **到货时间窗**：按商超收货时间提前预约，避免集中到货造成排队和品质下降。
- **冷链/保鲜措施**：冷链车、周转筐、预冷、防挤压包装提前准备。
- **卸货与交接**：谁卸货、谁验收、异常破损如何补货，明确责任人。
- **应急补货机制**：活动当天设置补货联系人，2—4小时内可响应补货或调拨。

### 6. 陈列与现场支持
- **陈列物料**：堆头围挡、价签、POP、试吃台、试吃果品提前送到门店。
- **试吃支持**：试吃人员、试吃损耗量、试吃果切标准提前安排。
- **理货支持**：爆品门店安排供应商理货/补货人员，尤其是高峰时段。
- **陈列标准**：颜色搭配、先进先出、挑拣残次果的频率和责任人明确。

### 7. 质量与损耗预案
- **到货验收标准**：明确拒收标准，如腐烂率、压伤率、成熟度超标。
- **残次品处理**：活动期间出现品质问题，是补货、折价还是下架，提前约定。
- **损耗补贴**：水果活动损耗高，提前谈好损耗承担比例和结算口径。
- **天气与突发预案**：产区降雨、物流延误、竞品截货时的替代方案。

### 8. 销售预测与数据协同
- **提供历史数据参考**：供应商结合同类门店、同类单品历史销量给商超备货建议。
- **活动前联合复盘**：确认预估销量、补货阈值、售罄时间点。
- **活动后复盘**：销量、损耗、缺货、客诉、毛利，形成下次活动改进清单。

### 最简执行清单
供应商活动前至少完成：
1. 锁单品、锁规格、锁价格、锁货量；
2. 备安全库存并分批到货；
3. 证照检测和活动包装到位；
4. 确认到货时间窗和补货联系人；
5. 陈列物料、试吃支持、理货人员到位；
6. 明确验收标准、损耗承担和异常处理机制。

建议商超把以上内容做成一张**供应商会员日准备确认表**，活动前3天逐项打勾确认，能明显降低断货、品质翻车和费用扯皮。
