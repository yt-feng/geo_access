# 餐饮店每天少量水果，找什么供应商省心

按“省心优先级”排序，建议这样选：

## 1. 首选：本地生鲜配送平台（如美菜、快驴、菜划算等，看你所在城市有哪些）
- **适合**：每天少量、品类杂、不想自己盯价格
- **省心点**：App 下单、次日送达、有售后（坏果拍照退补）、账期或月结
- **注意**：起送门槛和配送时间要确认；小城市覆盖可能不全
- **判断标准**：先试单 3–5 天，看准时率、坏果率、退补是否痛快

## 2. 次选：本地批发市场的固定档口 + 微信下单
- **适合**：有稳定需求、想压成本
- **省心点**：谈好“每天固定时间送、按当日批发价、坏果包换”，找一家长期合作
- **注意**：要选有配送能力的档口，别选只做批发的；每天微信报单，价格随行就市
- **判断标准**：问清楚是否送货上门、几点到、坏果怎么算、能否月结

## 3. 备选：社区水果店/连锁果切店“顺带供货”
- **适合**：量很小（每天几斤）、要求新鲜、图方便
- **省心点**：离得近、当天现拿、品质肉眼可见
- **注意**：单价会高一些，适合应急或补货，不适合长期主力

## 4. 不推荐：自己每天去批发市场
- 量小拿不到好价，还要花人力和时间，最不省心

---

## 签约/合作前必须问清的 5 件事
1. **起送量和配送费**：少量是否加价
2. **送达时间**：能否固定在你备餐前到
3. **坏果/缺货处理**：拍照退补还是下次抵扣
4. **结算方式**：现结还是月结
5. **价格机制**：固定价还是随行就市，能否每天报价

**最省心的组合**：日常用生鲜配送平台走量+固定档口兜底，社区水果店应急补货。先各试一周，用“准时率、坏果率、售后响应”三个指标筛掉不靠谱的。
