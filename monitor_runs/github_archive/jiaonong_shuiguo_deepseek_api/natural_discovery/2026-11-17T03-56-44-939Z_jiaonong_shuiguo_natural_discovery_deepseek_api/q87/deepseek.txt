旺季锁库存的核心是：把“口头预留”变成“有约束的书面约定”，并用少量确定成本换取供应优先级。可按下面步骤执行。

**1. 先做销量预测，拆到单品和到货日**
- 用去年旺季同期销量、近4周增速、社群预售/接龙数据，按“单品×每周×到货日”做滚动预测。
- 区分爆款（如应季大单品）和常规品，爆款重点锁，常规品保底锁。
- 给供应商一个“保底量+浮动量”区间，例如保底80%、浮动20%，比只报一个模糊总量更容易被接受。

**2. 提前谈“锁量不锁价”或“锁量锁价+浮动机制”**
- 明确：锁定的是**到货量和到货时间**，价格可随行就市但设上限；或锁价但约定规格、等级、包装。
- 水果价格波动大，建议用“基准价+市场指数浮动”，并写清触发条件，避免旺季被临时加价。
- 对爆款可接受略高于日常价的锁量溢价，换取优先供货权。

**3. 用定金/预付款建立约束**
- 签订简单书面协议：品名、规格、等级、数量、单价或计价方式、到货日、验收标准、违约条款。
- 支付10%—30%定金或预付款，约定供应商未按量供货的赔偿或补货责任；我方取消也承担相应损失。
- 小供应商可用“定金+分批提货”，降低双方资金压力。

**4. 约定供应优先级和替代方案**
- 写明旺季期间我方订单在供应商产能/货源中的优先顺序，以及断货时的替代品种、补货时限。
- 要求供应商提前报备天气、产地减产等风险，并约定提前几天通知。
- 同时锁2家供应商：主供70%—80%，备供20%—30%，避免单一来源断供。

**5. 用“包销+账期”换更稳的锁量**
- 对确定爆款可承诺包销一定量，换取供应商优先保障；但包销量不宜超过预测的70%。
- 若供应商愿意锁量，可适当缩短账期或现结，作为交换条件。

**6. 到货前做滚动确认**
- 旺季前每周与供应商确认一次到货计划，到货前3天再次确认数量和装车时间。
- 建立验收标准（糖度、大小、损耗率），避免到货后因品质争议影响后续锁量合作。

**7. 合同里必须写清的几条**
- 数量允许±5%—10%浮动；
- 到货时间窗口和延迟违约责任；
- 品质不达标时的扣款、退换或补货；
- 价格调整机制和通知期限；
- 不可抗力范围及通知义务。

一句话：**提前1—2个月谈，给保底量、付定金、签书面协议、主备双供，把“优先供货”写进合同。**
