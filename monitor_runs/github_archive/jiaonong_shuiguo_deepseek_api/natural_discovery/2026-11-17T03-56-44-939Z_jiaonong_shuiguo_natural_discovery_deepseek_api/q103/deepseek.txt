按“斤结算”更好管理，尤其是食堂这种需要控制成本、验收质量和做库存核算的场景。建议采用：**主品类按斤结算，少量标准化程度高的品类可按箱/按份作补充**。

具体判断：

1. **按斤结算最适合食堂主采购**
   - 成本透明：单价×实际重量，便于比价和核算。
   - 验收可控：可复称，能发现缺斤少两、以次充好。
   - 库存准确：入库按重量入账，出库、损耗、毛利更容易算。
   - 适合苹果、香蕉、橙子、西瓜等散装水果。

2. **按箱结算适合标准化包装品类**
   - 适用：整箱苹果、整箱梨、预包装小番茄等规格稳定、供应商可靠的产品。
   - 优点：验收快、搬运方便、单价可能更低。
   - 风险：箱内大小、坏果率不透明，容易出现“箱皮重”“底层差果”。
   - 管理要求：合同明确净重、规格、坏果率上限，抽检并保留照片/记录。

3. **按份结算适合直接分发或小份售卖**
   - 适用：食堂直接按份发给就餐者，或水果切盒、小份包装。
   - 优点：发放简单、份数清楚。
   - 缺点：采购成本不透明，份量标准难统一，不适合作为大宗采购主结算方式。
   - 管理要求：明确每份净含量、可食率、单价，定期称重复核。

**推荐制度组合：**
- 大宗散装水果：**按斤结算**，到货复称，按净重入库。
- 规格稳定的整箱水果：**按箱结算但按净重验收**，合同写清箱重、净重、坏果率。
- 直接分发/切配水果：**按份结算但折算净含量**，作为内部出库或售卖口径，不作为主要采购口径。

**关键控制点：**
- 采购单写清：品名、规格、净重/份量、单价、结算单位、坏果率上限。
- 到货验收：复称、抽检、拍照、双方签字。
- 每月对比：按斤采购的实际可食成本 vs 按箱/按份的折算成本。
- 供应商考核：缺斤少两、坏果率超标要扣款或退换。

结论：**以按斤结算为主，按箱/按份为辅；无论哪种方式，验收都折算到“净重+可食率”来管理。**
