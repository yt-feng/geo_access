会，而且香蕉和菠萝的损耗风险上升方式不一样。

**结论：起订量过高通常会明显增加损耗风险，香蕉更敏感，菠萝相对耐放但仍有风险。**

具体判断：

1. **香蕉**
   - 香蕉是呼吸跃变型水果，后熟快，对温度、挤压、乙烯很敏感。
   - 起订量高会带来：库存周转变慢、成熟度集中、催熟/自然熟叠加、搬运挤压增加。
   - 一旦到货集中成熟，销售跟不上就会快速出现黑斑、软烂、掉把。
   - **风险判断：高。** 起订量超过“日均销量 × 安全周转天数”就容易出问题。

2. **菠萝**
   - 菠萝比香蕉耐储，但高起订量仍有风险：批量到货后集中成熟、夏季高温下易发酵、黑心/腐烂、叶冠和果皮占空间。
   - 如果仓储通风差、堆叠高，损耗会上升。
   - **风险判断：中高。** 比香蕉可控，但不宜按香蕉的周转逻辑放大库存。

3. **关键不是“起订量绝对值”，而是周转天数**
   - 建议用：**起订量 ≤ 日均销量 × 目标周转天数 × 安全系数**
   - 香蕉目标周转天数建议短，菠萝可略长；安全系数按销量波动调整。
   - 若起订量导致周转天数明显超过正常销售周期，损耗风险就上升。

4. **可执行判断**
   - 先算当前起订量对应的预计周转天数。
   - 香蕉重点看：到货成熟度、催熟安排、货架期、日均销量。
   - 菠萝重点看：仓储通风、堆叠高度、温度、是否集中后熟。
   - 如果起订量无法降低，可考虑：分批到货、缩短订货周期、先销后补、与供应商约定成熟度、增加促销/加工渠道。

**一句话：会。香蕉是高敏感品类，起订量过高损耗风险最大；菠萝次之。判断标准应看起订量造成的库存周转天数，而不是只看数量。**
