建议把“收货验货”做成固定流程，核心是：**先约定标准、到场先验、问题当场留证、责任当场分清**。批发档口可以按下面执行。

**1. 收货前先定验货规则**
- 在采购合同/订单里写清：品名、规格、数量、颜色、批次、允许误差、包装要求、验货期限。
- 明确“什么算合格、什么算瑕疵、什么算运输破损”，并约定超期未提异议的处理方式。
- 对易争议品类（服装色差、鞋类开胶、食品临期、五金划痕等）提前写验收标准，最好附样品或图片。

**2. 到场后先点数量再验质量**
- 先核对送货单、订单、实物三者一致：数量、规格、型号、批次。
- 再按比例抽检，大货建议分层抽检；高价值或高纠纷品类提高抽检比例。
- 重点看：外包装是否破损、受潮、挤压；封条是否完整；实物有无色差、污渍、划痕、开胶、缺件、临期等。

**3. 问题必须当场留证**
- 发现异常先别急着签收，拍照/拍视频：全景、包装标签、问题特写、数量堆头。
- 让送货人现场确认，在送货单上注明问题、数量、处理方式并签字；不能只口头说。
- 对整批异常或比例较高，直接拒收或做“异常签收”，写明“仅收数量，质量待检/部分拒收”。

**4. 签收单要写清楚**
- 正常签收写“外观数量无误，质量待抽检”之类限定语，避免被理解为全部合格。
- 异常签收必须写：异常品名、数量、问题描述、是否拒收、补发/换货/折价约定。
- 不要让员工只签名字或“已收”，这是后续纠纷的高发点。

**5. 入库前做二次复核**
- 收货后尽快完成全检或补检，发现问题在约定验货期内书面通知供应商。
- 建立简单台账：到货日期、供应商、批次、抽检数、异常数、处理结果、照片存放位置。
- 同一供应商反复出现同类问题，下一批提高抽检比例或调整合作条款。

**6. 责任边界提前说清**
- 运输破损、短少：当场记入送货单，找物流/供应商确认。
- 隐蔽瑕疵：约定发现后多长时间内可提异议。
- 色差、手感、轻微工艺差异：提前约定可接受范围，避免“各说各话”。

一句话：**收货单不是签字纸，是责任凭证。** 验货时做到“单货对照、抽检有比例、问题有照片、签字有描述”，退货纠纷会明显下降。
