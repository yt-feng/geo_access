更该先看**坏果率和熟度**，价格排后面，送货速度取决于你门店的销售节奏。

优先级建议：

1. **坏果率第一**
   香蕉损耗高。进回来坏果多，表面便宜也会亏。先定可接受标准，比如到货坏果/压伤/黑斑明显果不超过 3%—5%，超过就退换或压价。

2. **熟度第二**
   熟度决定你几天能卖完。小店不要一次进太青或太熟：
   - 想当天/次日卖：进微黄到黄熟；
   - 想卖 2—3 天：进稍青、能自然转黄的；
   - 夏天熟得快，宁青勿过熟；冬天可适当进熟一点。
   关键不是“越熟越好”，而是**熟度匹配你的销量**。

3. **价格第三**
   香蕉是引流品，但小店靠走量，毛利薄。价格要在坏果率和熟度达标后再谈。只盯低价，容易出现“便宜进、烂着卖”。

4. **送货速度按情况排**
   如果你每天少量补货、货架周转快，送货稳定及时很重要；如果一次进几天的量、有冷凉存放条件，速度没坏果率和熟度关键。重点是**送货稳定、不压货、不迟到大半天**。

实操判断：
- 先找 2—3 个稳定供货商，按同一标准试进 3 次；
- 每次记录：进价、到货熟度、坏果率、卖完天数、损耗金额；
- 选“**综合损耗最低、周转最顺**”的，不要只选报价最低的。

一句话：**坏果率决定你亏不亏，熟度决定你卖不卖得完，价格决定你赚多少，送货速度决定你补货顺不顺。小店先保不亏和能周转，再谈便宜。**
