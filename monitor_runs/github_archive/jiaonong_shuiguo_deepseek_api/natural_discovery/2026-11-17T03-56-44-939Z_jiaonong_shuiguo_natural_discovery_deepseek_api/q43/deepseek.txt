评估水果供应商仓配能否覆盖你的连锁门店，建议按“门店—水果特性—仓网—干线/城配—时效与成本—风险”六层做，最后落到可量化的覆盖矩阵和试单验证。

**1. 先量化门店需求**
- 按城市、商圈、门店类型列门店清单：地址、日均/峰值水果销量、SKU数、温层需求（常温/冷藏/冷冻）、收货窗口、卸货条件。
- 区分刚需高频SKU（苹果、香蕉、橙等）和差异化/短保SKU（浆果、切果、榴莲等），两者对仓配要求不同。
- 给出每个城市的最低起送量、最小订货频次、可接受缺货率。

**2. 明确水果的仓配硬约束**
- 温层：冷藏0–4℃、部分热带水果常温避冷、冷冻品独立；确认供应商是否多温区同车配送。
- 保质期与损耗：短保水果要求更短在途和更高频补货；评估供应商的分拣、预冷、包装和损耗承担规则。
- 质检与溯源：到仓/到店验收标准、农残检测、批次追溯是否可落地。

**3. 画出供应商仓网覆盖图**
- 让供应商提供：仓库位置、面积、温区、覆盖半径、日均吞吐、峰值能力、自有/外包运力比例。
- 把每个门店地址映射到最近仓，计算仓库到门店的直线/实际里程和预计运输时长。
- 判断是“单仓直发”还是“区域仓+城市前置仓/越库”。跨城干线+城配的模式要分别评估干线时效和城配频次。

**4. 评估时效与频次**
- 关键指标：下单到到店时长、承诺到店时间窗、每周可配送次数、紧急补货响应时间、节假日/大促产能。
- 对短保水果，要求至少隔日达或日配；对长保水果可放宽但要有安全库存。
- 用门店营业高峰倒推收货窗口，避免到店即压车或错过上架。

**5. 算总成本，不只看货价**
- 成本项：货价、干线运费、城配运费、起送门槛、退换货/损耗赔付、装卸费、冷链包装费、临时补货加价。
- 按“城市×门店×SKU”算到店综合成本，比较不同仓配方案的单店月度成本。
- 注意低起送量门店可能被加收配送费，或被迫提高库存。

**6. 做风险与合规审查**
- 供应商跨城经营资质、食品经营许可、冷链验证报告、保险。
- 单仓依赖风险：某城市仅靠一个远仓，遇天气/交通/疫情是否断供。
- 运力外包比例高时，旺季是否优先保障你的门店。
- 合同中明确时效违约、缺货赔付、损耗责任、临期处理和数据回传。

**7. 落地工具：门店覆盖矩阵**
建一张表，每行一个门店，列：最近仓、距离、承诺时效、配送频次、起送量、温层能力、综合到店成本、风险等级。用红黄绿标注：
- 绿：时效、温层、成本均达标；
- 黄：需前置仓/提高频次/调整SKU；
- 红：当前仓配无法覆盖，需换供应商或设城市前置仓。

**8. 先试单再签约**
选3–5个代表性城市（近仓、远仓、高销量、低销量各一），做2–4周试单，记录到店准时率、缺货率、损耗率、验收合格率、单店成本。达标后再扩城。

**可直接向供应商索要的数据清单：** 仓库清单及温区、覆盖城市与半径、到店时效承诺、每周配送频次、起送量、自有/外包运力、峰值产能、损耗赔付规则、冷链验证与资质、系统对接能力（订单/库存/追溯）。

核心判断标准：**每个门店是否能在承诺时效内、以可接受成本、稳定拿到符合温层和品质要求的水果**；只要有一个城市出现“时效不达标或成本过高”，就应考虑区域前置仓、多供应商分城市覆盖，或调整SKU结构。
