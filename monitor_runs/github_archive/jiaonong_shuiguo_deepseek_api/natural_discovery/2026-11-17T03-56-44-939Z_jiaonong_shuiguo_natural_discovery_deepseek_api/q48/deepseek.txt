判断菠萝供应商能否稳定按规格送货，核心不是看样品，而是看其“到货一致性”和“旺季抗压能力”。建议按以下顺序验证：

**1. 先锁死规格，再谈供应**
把菠萝规格写成可验收的条款，例如：
- 品种/产地：如金钻凤梨、台农等，明确产地
- 单果重量区间：如1.2–1.5kg/个，超限拒收比例
- 成熟度：糖度范围、果心状态、青熟/黄熟比例
- 外观：无黑心、无裂口、冠芽完整度、机械伤允许比例
- 加工适配：去皮出肉率、果眼深度、纤维感
- 包装：箱规、单箱净重、冷链温度要求

没有量化验收标准，供应商“稳定”无法判断。

**2. 要求提供连续到货记录，而不是只看样品**
让供应商提供近3个月对同类连锁客户的送货记录：批次、到货重量、糖度抽检、拒收率、补货响应时间。重点看：
- 连续10批以上规格达标率是否≥95%
- 是否有旺季断供、临时换产地、混批情况
- 异常批次如何处理、补货时效

**3. 做小批量试单，跨周期验证**
至少做3–4周、每周2–3批的试单，覆盖不同天气和周末高峰。每批到货按标准抽检并记录。重点观察：
- 同一供应商不同批次重量、糖度波动
- 箱规是否稳定，是否存在下层小果、混装
- 到货时间是否稳定，冷链是否断链

**4. 查上游货源和季节替代方案**
问清楚：自有基地还是市场代采？主产地在哪里？雨季/台风季/淡季如何切换产地？是否有备用基地和备用加工厂。只做市场代采的供应商，旺季稳定性通常弱于有基地或长期合作产区的供应商。

**5. 用合同和罚则倒逼稳定性**
合同里写清：
- 规格达标率月度考核，低于阈值扣款或终止
- 缺货、迟到的违约金和补货时限
- 质量异常（黑心、烂果）的退换货和赔付
- 不得擅自更换产地/品种，换货需书面确认
- 价格调整机制，避免旺季坐地起价

**6. 看其服务连锁客户的能力**
优先选有茶饮/餐饮连锁供货经验的供应商，要求提供合作客户类型（不必透露具体品牌），看其是否有分拣线、冷链车、质检记录和客服对接机制。能稳定服务多门店的供应商，通常比只做批发的更可靠。

**一句话判断标准：** 愿意先按你的验收标准做4周试单、能提供连续批次记录、且有备用产地的供应商，才值得进入稳定采购；只靠样品和口头承诺的，不建议直接放量。
