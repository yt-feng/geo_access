小面积便利店做水果，核心不是“品类齐全”，而是**少SKU、快周转、强控损**。建议按下面几条执行：

**1. 品类控制：只做“高频、好挑、耐放、即食”**
- 首选：苹果、香蕉、橙子、砂糖橘/沃柑（季节）、梨、圣女果、葡萄/提子（小包装）。
- 少量做：西瓜（切盒或小果）、菠萝（切盒）、芒果（小台芒/小份装）。
- 慎做：草莓、蓝莓、荔枝、杨梅、水蜜桃等娇嫩高损品，除非能日清且冷链稳定。
- SKU建议：**常驻8-12个，季节品2-3个**，不要超过15个。每个品类只留1-2个规格。

**2. 采购量：按“日销×1.5”订货，少量多次**
- 用最近7天同星期销量做基数，首次少量试销。
- 叶菜式水果和切盒类：**日订日清**；耐放类：2-3天补一次。
- 香蕉、葡萄、切盒水果占比控制在总水果销量的30%以内，避免损耗集中。

**3. 陈列和包装：小份化、场景化**
- 全部做**小份装/单人份**，减少挑拣和翻动。
- 香蕉挂放、苹果梨橙常温通风、葡萄和切盒冷藏。
- 设“今日鲜果”“9.9元任选”小堆头，快进快出，不压库存。
- 切盒只在预计2小时内能卖完的时段做，标注制作时间。

**4. 损耗控制：定标准、日盘点、快处理**
- 每天早晚各挑一次，把轻微瑕疵品**立即打折或做果切**，不要等坏透。
- 设损耗红线：水果整体损耗率控制在**5%-8%**，超过就砍SKU或减订货。
- 每天记录：进货量、销量、报损量、打折量。连续3天卖不动的品项直接下架。
- 供应商尽量选本地批发市场或可小批量配送的，争取**次品可换、少量起送**。

**5. 简单可执行的订货公式**
> 明日订货量 = 最近7天日均销量 × 1.2～1.5 － 现有库存 － 在途量  
> 新品首次订货不超过2天预估销量；雨天、工作日下调20%-30%。

**6. 不建议做的**
- 不要追求全品类水果店模式；
- 不要大批量囤耐放品；
- 不要在没有冷藏条件时做高价娇嫩水果；
- 不要用“降价硬卖”处理已经明显变质的水果。

一句话：**小便利店水果只赚周转和便利的钱，SKU少、份量小、日清快、损耗天天看。**
