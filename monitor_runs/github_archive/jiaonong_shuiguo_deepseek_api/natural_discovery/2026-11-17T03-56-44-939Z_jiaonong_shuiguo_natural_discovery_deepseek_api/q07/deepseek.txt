水果礼盒想好卖，核心不是“水果越贵越好”，而是**组合有明确卖点、成本可控、顾客一眼知道送谁**。苹果、橙子、香蕉、菠萝这四样很适合做“大众价位、颜色喜庆、寓意好”的礼盒。

### 推荐搭配方案

**1. 主推款：88—128元“平安如意”礼盒**
- 苹果 6个：寓意平安，选均匀大果
- 橙子 6个：寓意心想事成，颜色亮
- 香蕉 1把：约1—1.5斤，增加饱满感
- 菠萝 1个：寓意旺来，提升礼盒体量
- 包装：红金配色，苹果橙子摆上层，香蕉菠萝放底层或侧边
- 适合：看病人、走亲戚、普通商务伴手礼

这个组合最好卖，因为**苹果橙子撑寓意，香蕉撑体积，菠萝撑“贵感”**，成本也不容易失控。

**2. 走量款：58—78元“小圆满”礼盒**
- 苹果 4个
- 橙子 4个
- 香蕉 1小把
- 不放菠萝，或放小菠萝1个
- 适合：社区团购、员工福利、随手礼

**3. 高毛利款：128—168元“旺来福果”礼盒**
- 苹果 8个
- 橙子 8个
- 菠萝 2个
- 香蕉做点缀，不占主位
- 加一张手写贺卡、红色丝带
- 适合：节日送礼、开业、乔迁

### 搭配技巧
- **颜色要红黄绿搭配**：苹果红、橙子橙、香蕉黄、菠萝绿叶冠，视觉上喜庆。
- **硬果打底，软果点缀**：苹果橙子耐放，香蕉容易压伤，放上层或单独隔开。
- **不要塞太满**：礼盒看起来满即可，香蕉过多会显得廉价，也容易坏。
- **按场景命名**：比“水果礼盒”更好卖，比如“平安果礼盒”“探病慰问盒”“开业旺来盒”。
- **做两个价格锚点**：一个58—78元走量，一个98—128元主推，顾客更容易选中间款。

### 最建议你先试的组合
先做 **98元档：苹果6 + 橙子6 + 香蕉1把 + 菠萝1个**，红金包装，主打“平安如意、旺来送福”。同时配一个 **68元小盒：苹果4 + 橙子4 + 香蕉1小把** 做社区走量。

### 注意
- 香蕉和菠萝会催熟其他水果，最好用隔板分开，别让香蕉直接压苹果橙子。
- 礼盒不要提前大量装好，水果呼吸和挤压会影响卖相，按订单现装或少量陈列。
- 定价前先按你当地进价算：**包装成本控制在售价的8%—12%**，损耗预留5%—8%，毛利才有保障。
