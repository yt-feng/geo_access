# 酒店水果盘原料的规格与外观标准

酒店采购水果盘原料时，建议把要求写进采购合同或验收标准，并区分“通用基础要求”和“按品类细化的规格”。以下可直接作为验收依据使用。


## 一、通用验收标准（所有水果适用）

**1. 新鲜度**
- 到货时无萎蔫、皱皮、软烂、渗汁、异味；果柄切口新鲜不褐变。
- 采收至到货时间要求：易腐类（浆果、芒果、木瓜等）建议冷链到货，全程2–8℃；运输无断链。
- 成熟度按“酒店预期使用时间”约定：当日出品用八至九成熟；需存放2–3天用七至八成熟。供应商须按约定成熟度供货，不能一批混装。

**2. 外观与大小**
- 同批次大小、色泽、成熟度基本一致，单果规格在约定区间内（如直径、单果重上下限）。
- 果形周正，无明显畸形、偏斜、双头、裂口、日灼斑、机械伤。
- 表面洁净，无泥土、药斑、果汁残留；有蜡处理的须说明。

**3. 缺陷与病虫害**
- 无腐烂、霉变、虫蛀、虫卵、活虫；无检疫性有害生物。
- 允许的轻微缺陷需在合同中量化，例如：单果机械伤面积≤5%、不影响切面使用；批次不合格率≤3%–5%。

**4. 安全与合规**
- 农残符合销售地法规（如中国GB 2763），供应商提供批次检测报告或承诺书；进口水果提供检验检疫证明。
- 不得使用违禁保鲜剂；催熟剂使用须符合规范并如实告知。

**5. 包装与标识**
- 内包装透气防压，分层衬垫，无挤压变形；外箱标注品名、产地、等级、采收/包装日期、批次号。
- 冷链运输车辆温度记录可查；到货温度抽检合格。

**6. 感官抽检**
- 按批次随机抽检（建议每批不少于3–5箱/件），切开抽检内部品质：无褐心、空心、黑心、异味，糖度符合约定下限（如西瓜≥10°Brix、哈密瓜≥12°Brix，可按酒店出品需要约定）。


## 二、按品类的细化规格（示例，采购时按实际菜单调整）

| 品类 | 关键规格 | 外观/成熟度要求 |
|---|---|---|
| 西瓜 | 单果重区间、皮薄、无空心 | 瓜形端正、纹路清晰、瓜蒂新鲜；切面无白筋、无过熟起沙 |
| 哈密瓜/网纹瓜 | 单果重、网纹完整 | 无裂口、无软斑；八至九成熟，香气明显 |
| 菠萝 | 单果重、冠芽完整 | 无黑心、无烂底；叶冠鲜绿不干枯 |
| 芒果 | 单果重、品种明确（如台农、贵妃） | 无黑斑、无炭疽病斑；按使用日定成熟度 |
| 火龙果 | 单果重、果鳞鲜绿 | 无软腐、无碰伤；红心/白心分开标注 |
| 提子/葡萄 | 串重、果粒均匀、果霜完整 | 无掉粒、无裂果、无霉；果梗绿 |
| 草莓 | 单果重、果形均匀 | 无压伤、无白粉病；八成熟，当日用 |
| 蓝莓 | 果径分级、果粉完整 | 无软果、无霉；冷链到货 |
| 橙/柑橘 | 果径分级、皮薄 | 无浮皮、无油斑病；可带叶但叶须新鲜 |
| 猕猴桃 | 单果重、软硬一致 | 无碰伤；按使用日约定后熟程度 |
| 香蕉 | 梳/把规格 | 无黑斑、无断指；按出品日约定催熟进度 |

**切配用与整果出品用要分开约定**：切配用可接受轻微外观瑕疵但内部品质必须达标；整果摆盘用外观标准从严。


## 三、建议写入合同的供应商义务

1. **批次一致性**：同批次规格、成熟度、色泽一致，不接受混级混装。
2. **到货验收与退换**：明确抽检比例、不合格判定规则（如不合格率超5%整批退换）、到货后多少小时内可提出质量异议。
3. **溯源与证照**：每批提供产地/批次信息、检测报告；进口品类提供检疫证明。
4. **冷链责任**：运输温度记录随货提供，断链导致品质问题由供应商承担。
5. **季节替代方案**：约定缺货时的替代品类与提前通知时限，避免酒店临时改菜单。
