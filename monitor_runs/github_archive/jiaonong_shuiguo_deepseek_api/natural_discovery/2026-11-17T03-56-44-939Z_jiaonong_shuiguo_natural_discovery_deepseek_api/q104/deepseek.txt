# 单位采购水果：到货品质不一致的验收与售后处理

核心原则：**分拣定级、按级计价、有据可查、限时索赔**。水果是生鲜，验收必须在到货当场完成，事后扯皮基本无法举证。

## 一、到货前先立规矩（合同/订单里写清）

验收能不能谈得拢，取决于采购时有没有约定。至少要写进合同或订单：

1. **质量标准**：按品种明确规格（单果重量区间、果径）、成熟度、允许瑕疵率（如坏果率≤3%，虫眼、压伤、腐烂分别定义）。
2. **验收方式**：抽检比例（一般每批抽5%~10%，大货分批抽）、抽检发现超标时的整批判定规则。
3. **计价与结算**：按等级分价（优级/合格/次品分别单价），或整批按合格率折算付款。
4. **售后条款**：到货后多少小时内提出异议有效（生鲜通常24小时内）、坏果包赔方式（补货/折价/退款）、退货运费谁承担。
5. **留样**：约定双方各留样品和照片，作为争议依据。

## 二、到货验收怎么做

**1. 当场验、当面签**
送货人到场时验收，不让司机先走。验收单双方签字，注明到货时间、数量、抽检结果。

**2. 分层抽检，不只看表层**
- 按箱/按筐随机抽取，重点抽底层和中间层（供应商常把好果放上面）。
- 记录：抽检总数、不合格数、不合格类型（腐烂/压伤/规格不符/未熟/过熟）。

**3. 分拣定级，现场过秤**
把抽检结果推算到整批，与供应商现场确认三个数字：合格数量、次品数量、拒收数量。次品单独堆放、拍照，避免和合格品混放后无法区分。

**4. 证据固定**
- 照片/视频：整批、开箱、特写（带日期水印或当场拍摄）。
- 验收单写明不合格情况和处理意见，双方签字；对方拒签的，在单据上注明"送货人拒签"并留存影像。

**5. 现场给出处理结论**（三选一或组合）
- 合格部分正常收货入库；
- 次品降价接收（按约定次品价）；
- 严重不符的整批拒收，写明拒收理由。

## 三、售后怎么处理

按"先协商、后扣款、再追责"的顺序：

1. **限时反馈**：验收发现问题当天书面（微信/邮件/验收单）通知供应商，附照片和数量，要求其在约定时限内答复处理方案。
2. **处理方式优先级**：补货 > 折价 > 退货退款。单位食堂/福利发放对时效敏感，优先要求补货，避免影响使用。
3. **结算挂钩**：不合格部分从当期货款中扣除，或按合同约定的合格率折扣结算；不要先全额付款再谈赔偿。
4. **重复出现即升级**：同一供应商短期内多次品质不符，按合同违约条款处理（扣保证金、列入不良供应商名单、终止合作）。
5. **保留追偿依据**：所有验收单、照片、沟通记录归档，作为扣款和后续采购评估的依据。

## 四、几个容易踩的坑

- **只验表层**：一定要抽底层，否则售后时对方不认。
- **先入库后验收**：货一进库房，责任就说不清了，必须"验收合格才入库"。
- **口头承诺**：供应商说"下次补给你"，没有书面记录，下次换个人就不认账。
- **没有次品价**：合同只写"保证新鲜"，没写瑕疵率和处理方式，出问题只能扯皮。

一句话总结：**验收当场分拣、双方签字、拍照留证；售后书面提出、结算扣款、重复违约就换供应商。** 前提是采购时把质量标准和售后条款写进合同，否则验收再认真也缺乏依据。
