# 学校食堂水果供应商选择建议

## 一、先定“门槛条件”（一票否决项）

在比价之前，先筛掉不合格的：

- **证照齐全**：营业执照、食品经营许可证（经营范围含食用农产品/预包装食品），能提供每批次**产地证明或进货凭证**、农残检测报告
- **配送能力**：有冷链或常温保鲜车辆，能按学校指定时间（通常早于开餐1–2小时）送达
- **应急能力**：缺货/质量问题能在2–4小时内补货或调换
- **可追溯**：能说清货源来自哪个批发市场/基地/合作社，出问题能追到批次

## 二、按水果品类分开选，不要“一家通吃”

香蕉、苹果、橙子的供应链逻辑不同：

| 品类 | 特点 | 选供应商侧重 |
|---|---|---|
| 香蕉 | 后熟快、易碰伤、损耗高 | 选有催熟/控温经验、能按天分批送货的；要求到货成熟度可控（七八成熟），别一次送一周量 |
| 苹果 | 耐储、标准化程度高 | 可找产地直供或一级批发商，重点看规格分级、硬度、无霉心病；适合签周/月度框架协议 |
| 橙子 | 季节性强、易失水 | 按产季选主产区供应商，重点看新鲜度、果径均匀、无浮皮；非产季可考虑冷藏果但需明确标注 |

**建议**：主供应商1家（覆盖苹果等耐储品）+ 香蕉/时令水果专项供应商1–2家，避免单一供应商断供。

## 三、比价与定价机制

- **询价方式**：至少3家报价，按“同规格同等级”比，不能拿一级果价对比统货价
- **定价周期**：水果价格波动大，建议**每周或每两周**按当地批发市场均价（可参考本地农产品批发市场价格监测）核定一次，写进合同调价条款
- **计价单位**：统一按净重（去箱去冰）计价，明确损耗率和退货规则

## 四、验收标准写进合同（最关键）

- 到货**抽检**：每批随机抽10%–20%，看外观、硬度、气味、有无霉变；香蕉看棱角与色泽，苹果看有无磕碰和果心褐变，橙子看有无软腐
- **退换条款**：不合格率超过约定比例（如5%）整批退换，费用供应商承担
- **索证索票**：每批留检测报告和送货单，保存不少于6个月（学校食堂留档要求通常更严，按当地市场监管要求执行）
- **留样**：按食堂留样制度执行，水果类至少留可追溯批次信息

## 五、实操流程

1. 发布采购需求（品类、规格、周用量、送货频次、验收标准）
2. 资质初审 → 现场看仓储/分拣场地（有条件的话）
3. 小批量试供2–4周，考核到货准时率、合格率、补货响应
4. 试供合格后签框架合同（3–6个月），设月度考核和退出机制
5. 每学期重新比价或至少复核一次价格

## 六、容易踩的坑

- 只比单价不比**净重和等级**，实际成本反而高
- 香蕉一次性大批量配送，损耗全算学校头上——合同要约定损耗分担
- 供应商无冷库、夏天用普通货车送，橙子失水、香蕉催熟失控
- 没有备选供应商，开学季或极端天气断供
