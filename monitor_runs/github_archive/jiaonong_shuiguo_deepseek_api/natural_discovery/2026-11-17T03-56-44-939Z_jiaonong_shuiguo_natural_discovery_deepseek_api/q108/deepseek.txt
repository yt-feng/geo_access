核实“全国配送”不能只听口头承诺，建议按“资质—网络—实测—合同”四步验证，并把关键承诺写进合同。

**1. 先核配送资质和主体**
- 查营业执照经营范围是否含道路货物运输、冷链运输或配送服务；涉及冷链的看是否有冷链运输资质或合作方资质。
- 要求提供实际承运主体：是自营车队、分公司，还是外包给第三方物流。外包的要列出合作物流公司名称和覆盖区域。
- 核对食品经营许可证/食用农产品相关合规材料，水果配送尤其关注仓储和运输温控。

**2. 要“可验证”的网络清单**
- 让对方提供：已服务城市/区县清单、各区域仓库或中转仓地址、常用干线线路、日均配送单量、冷链车辆数量。
- 不接受只给“全国”两个字；要求按省—市—区县列明“直送、次日达、中转自提、不覆盖”四类。
- 对偏远地区、县级市、乡镇单独问清：是否送到门、是否加价、时效几天、破损谁承担。

**3. 做小批量实测**
- 选3—5个有代表性的收货地址：一线城市、普通地级市、县级市/乡镇、偏远地区，各下一笔小单。
- 记录：下单到揽收时间、实际承运商、轨迹是否完整、到货时效、包装和温控、破损率、异常处理速度。
- 同时用物流单号到承运商官网或官方客服二次核验，防止供应商用“假轨迹”或转包后失联。

**4. 交叉验证与合同约束**
- 要求提供2—3个现有客户的配送案例，最好能联系确认；查看近3个月的物流签收记录或异常率数据。
- 合同写明：覆盖区域清单及附件、时效标准、冷链温控要求、破损/延误赔付、偏远地区加价规则、转包需事先告知、月度考核与退出机制。
- 约定试运行期，按实际签收率和投诉率结算，不达标可终止或扣款。

**快速判断信号：** 能立刻给出分省区县覆盖表、仓库地址、承运商名称和异常处理流程的，可信度较高；只强调“都能送”、回避具体区县和承运方、拒绝小单试跑的，要谨慎。
