供应商介绍产品时，关键是**把“品种名”翻译成商家能感知的“卖点、风险、利润”**。可按这个顺序说：

1. **先对应到商家熟悉的品类**
   - “这不是普通菠萝，是介于普通菠萝和凤梨之间的品种，主打免削眼、甜度高。”
   - “这是香蕉里的短保高甜款，不是普通大路货。”

2. **用一句话说清差异**
   不要先说学名、产地故事，先说：
   - 比普通款甜多少/酸多少
   - 要不要泡盐水、削眼、催熟
   - 货架期几天
   - 损耗高不高
   - 适合鲜食、榨汁、烘焙还是礼盒

3. **直接给商家算账**
   - 进货价 vs 普通款
   - 建议零售价
   - 毛利大概多少
   - 损耗后还能不能赚钱
   - 适合什么门店：水果店、餐饮、档口、社区团购

4. **主动说风险**
   - 几天内必须卖完
   - 怕不怕压
   - 熟度到了怎么处理
   - 哪些地区/季节不适合推
   商家反而更敢下单。

5. **给试销方案**
   - “先拿一箱试卖，按这个话术陈列：免削眼凤梨，切开即吃。”
   - “前三天建议促销价，卖得动再补货。”

一个可直接套用的介绍模板：

> “张老板，这个不是普通菠萝，是免削眼、甜度高的凤梨型品种。顾客拿回家切开就能吃，不用泡盐水。进货价比普通菠萝高一点，但建议零售价能高30%左右，损耗也低。先拿一箱试卖，我给您配个陈列牌：免削眼、切开即吃。卖不动我教您调整陈列和价格。”

核心原则：**少讲品种，多讲顾客为什么买、商家怎么赚钱、卖不动怎么办。**
