# 超市门店多但单店量不大：水果供货模式建议

## 核心矛盾
- 门店多 → 需要覆盖广、配送频次高、品类统一
- 单店量小 → 单店直采没议价权，供应商不愿意小批量多频次送货
- 水果 → 损耗高、非标、价格波动大、对新鲜度要求极高

所以关键不是“找大供应商”或“找小贩”，而是**把多店需求集中起来，用一套供应链服务多店**。


## 推荐模式（按优先级）

### 1. 区域集采 + 统仓分拨（首选）
找一个**区域性的水果批发商/配送商**，由总部统一谈价、统一订货，供应商送到**一个集中仓/中转点**，再由你们（或第三方城配）分拨到各店。

- 适合：门店在同一城市或同一区域
- 优点：集中需求有议价权；供应商只面对一个收货点，愿意接小单；品控可集中做
- 关键动作：设一个 100–300㎡ 的中转仓（可租可共享），配 1–2 辆冷藏/常温城配车
- 注意：多一道分拨就多一道损耗和成本，单店量太小时要算清“集采省的钱 > 分拨成本”

### 2. 本地批发市场“代采 + 配送”合作
找批发市场里**有配送能力的档口/买手**，签“代采协议”：你们每天汇总各店订单给他，他按需采购并分送各店，收代采费或加价。

- 适合：门店分散、单店量小、暂时不想建仓
- 优点：轻资产、起量快、品类灵活
- 缺点：品控依赖对方、价格不透明、旺季可能被优先供应大客户
- 关键动作：约定品控标准、损耗承担、每日报价机制、账期

### 3. 产地/基地直采 + 第三方城配（只做大单品）
对**走量相对稳定的 2–3 个单品**（如苹果、香蕉、柑橘）做产地直采，整车发到区域仓，再城配分发；其余品类走本地批发。

- 适合：有稳定动销单品、能凑够整车
- 优点：大单品毛利高、品质可控
- 缺点：只适合耐储单品，叶菜/浆果类不适合
- 关键动作：先跑通 1–2 个单品，别全面直采

### 4. 供应商“多店小批量统配”合同
直接找**有城配能力的中型配送商**，合同约定：每日/隔日按门店订单统配，设最低起送额和配送费规则。

- 适合：门店 5–30 家、单店日销几百到一两千元
- 关键动作：把多店订单合并成一张总单给他，而不是每店各自下单；约定缺货替代、损耗赔付

### 5. 联采/共享仓（同行抱团）
和周边非竞争业态（餐饮、社区团购团长、其他小超市）**联合采购、共享中转仓和配送**，把单量凑大。

- 适合：自身量确实太小、又想要集采价
- 注意：选非直接竞争伙伴，明确分账和品控责任


## 不建议的模式
- **每店各自找本地小贩直送**：价格乱、品控乱、无法沉淀议价能力
- **全面产地直采**：单店量小、品类多，直采只会压库存、增损耗
- **纯平台下单（如某些生鲜 B2B）**：可作为补充，但价格和稳定性通常不如自谈的区域配送商


## 落地建议（可执行步骤）
1. **先算账**：统计各店近 3 个月水果日均销量、SKU 数、损耗率、当前采购价，找出前 5 大单品（通常占销量 60%+）。
2. **定结构**：前 5 大单品走“集采/直采”，长尾品类走“本地批发代采统配”。
3. **设一个中转点**：哪怕只是共享仓的一个库位，先跑通“集中收货—分拨”流程。
4. **统一订单**：所有门店前一晚报量，总部合并成总单给供应商，避免各店零散下单。
5. **约定规则**：品控标准（分级、糖度、外观）、损耗分担、缺货替代、每日报价、账期、退换货。
6. **先试点 3–5 家店**，跑 2–4 周对比损耗率和毛利，再推广。

## 一句话结论
**“区域集采 + 集中仓分拨 + 长尾本地代采统配”** 最适合门店多、单店量小的超市；先把多店订单合并成一张总单，是拿到议价权和配送服务的前提。
