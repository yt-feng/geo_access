判断供应商能不能按时到车，核心不是听承诺，而是看“可验证的履约条件”。建议按下面几步做，能在进货前把风险压下来。

1. **先问清“到车”定义**
   明确是到市场、到档口、到冷库，还是到指定高速口；几点前算按时；压车、卸货谁负责。定义不清，后面一定扯皮。

2. **看产地和线路是否匹配**
   问清香蕉从哪个产区、哪个县市装车，走哪条线路，正常车程多少小时。产区到销地距离、是否要过海、是否途经易堵路段，直接决定准点率。供应商说不清产地和线路的，谨慎。

3. **要“已落实”的证据**
   不是“明天装车”，而是：车号、司机电话、装车地点、装车时间、预计发车时间。装车前可要求拍空车到场、装车过程、封车和磅单。没有车号和装车计划的“口头保证”含金量低。

4. **查车源是否自有或稳定合作**
   自有车队或长期合作车队的准点率通常高于临时叫车。问一句“这车是你们自己的还是临时找的”，临时车要看是否已付定金、是否签了运输约定。

5. **看历史履约记录**
   优先选合作过、有到车记录的供应商。新供应商可要求提供近期同类线路的到车记录，比如最近几车实际到达时间。注意是“实际到达”，不是计划时间。

6. **合同里写清违约条款**
   写明最晚到车时间、延误几小时怎么处理、压车费谁承担、香蕉因延误变质或催熟风险谁负责。条款越具体，供应商越会认真排车。

7. **装车后动态跟踪**
   装车后要司机电话和定位，发车后每隔几小时确认位置。发现异常早做预案：联系备用车、调整销售计划、必要时就近转货。

8. **留备用方案**
   对时效要求高的批次，不要只压一个供应商。可同时问一家备用供应商的车期，哪怕不用，也能在延误时有退路。

一句话判断：**能给出车号、司机、装车地点和时间，且愿意把到车时间写进约定并承担延误责任的，才叫“能按时到车”；只说“放心，没问题”的，不算。**
