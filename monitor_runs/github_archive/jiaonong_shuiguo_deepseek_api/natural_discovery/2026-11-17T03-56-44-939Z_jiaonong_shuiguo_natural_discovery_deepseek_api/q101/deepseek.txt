和水果供应商谈酒店早餐合作，核心是**把“稳定”写进合同和日常管理**，而不是只谈价格。重点注意以下几方面：

**1. 先明确自己的需求边界**
- 确定每日/每周用量、早餐时段、可接受的水果品类范围（如苹果、香蕉、橙子、西瓜、圣女果等基础款为主，减少易损耗高价水果）。
- 明确验收标准：品种、规格（单果重量/直径）、成熟度、外观、农残检测要求、包装方式。
- 明确送货时间窗口（如早餐前1–2小时到货）和卸货地点。

**2. 供应稳定性是谈判重点**
- 要求供应商说明产地来源和淡旺季替代方案，避免单一产地断供。
- 约定缺货时的替代品种、提前通知时限和违约责任。
- 了解供应商是否有冷链、仓储和备用货源；最好有备选供应商。
- 合同中写清最低供货保障和紧急补货响应时间。

**3. 质量与验收机制**
- 设定抽检和验收流程：到货称重、外观检查、成熟度抽检，不合格的退换货规则。
- 要求提供农残检测报告或合格证明，明确食品安全责任。
- 约定损耗率范围和异常处理，避免“到货即损耗”扯皮。

**4. 价格与结算**
- 不要只谈单价，要谈**价格调整机制**：随行就市时提前几天报价、涨跌幅上限、是否含税含运费。
- 明确结算周期、发票类型、对账方式，避免账期过长影响供应积极性。
- 可约定月度/季度用量阶梯价，但不要为低价牺牲稳定性和质量。

**5. 合同关键条款**
- 供货品种、规格、数量、价格、送货时间、验收标准、退换货、违约责任、食品安全责任、解约条件。
- 约定试供期（如2–4周），试供合格再签长期。
- 明确不可抗力、临时加量/减量的通知时限。

**6. 日常管理配套**
- 指定专人对接，建立每日到货记录和异常反馈群。
- 每月复盘缺货率、损耗率、投诉次数，作为续约依据。
- 保留1–2家备选供应商，避免被单一供应商卡脖子。

**7. 现场考察与资质核验**
- 看供应商的仓储、分拣、冷链和配送能力，核验营业执照、食品经营许可、检测报告。
- 问清上游采购渠道，避免中间商层层加价或断供。

一句话：**价格可以谈，但稳定供应、验收标准、缺货责任和备选方案必须落到书面。** 先小批量试供，再签长期合同。
