建议优先选择**中央厨房统一收货**，但要按品类和门店距离分层设计，而不是一刀切。

**一、统一收货更适合大多数连锁**
1. **品质与验收标准统一**：水果熟度、规格、农残检测、损耗判定由中央厨房一套标准执行，避免各店验收松紧不一。
2. **采购议价与供应稳定**：集中订单量更大，便于和产地/一级批发商锁量锁价，减少门店自行采购的串货和价格失控。
3. **食品安全可追溯**：统一索证索票、批次留样、检测记录，出问题能快速定位批次。
4. **损耗与库存可控**：中央厨房可按各店次日预估销量分拣、分级，减少门店囤货和过期损耗。
5. **减少门店操作**：门店只做“接货—上架”，降低店长采购能力和腐败风险。

**二、这些情况适合门店分开收货**
- 门店距中央厨房远、冷链配送成本高，且当地批发市场品质更优；
- 水果品类极度依赖“当日鲜度”，如草莓、荔枝、杨梅等，长途二次分拣反而增加损耗；
- 单店销量小、门店密度低，集中配送不经济；
- 有本地化特色水果需求，中央厨房统采无法覆盖。

**三、推荐落地方式**
- **A类高频大宗**（苹果、橙子、香蕉、西瓜等）：中央厨房统一收货、统采统配。
- **B类高损耗鲜果**（草莓、蓝莓、荔枝、杨梅）：中央厨房定标准和供应商，门店或区域仓“直发直收”，但必须按统一验收标准执行。
- **C类区域特色**：区域仓统一收货，不放开单店自采。
- **制度上**：中央厨房设验收岗，门店到货只做复核；所有供应商准入、价格、合同由总部采购统一管理；门店自采仅限临时应急且需审批。

**判断标准**：如果你们门店数量多、单店水果销量稳定、中央厨房已有冷链分拣能力，统一收货的综合成本更低、风险更小；如果配送半径大、鲜果占比高，就采用“统采+分区直发”的混合模式。
