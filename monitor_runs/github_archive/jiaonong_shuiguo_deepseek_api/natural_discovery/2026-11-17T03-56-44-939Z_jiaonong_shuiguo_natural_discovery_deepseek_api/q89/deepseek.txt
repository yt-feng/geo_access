**结论先说：给团购客户，通常优先用“阶梯价”，返利作为第二层补充更合适。** 但取决于三个关键点：客户是否长期复购、订单是否可预测、你是否需要控价保价盘。

**一、为什么团购客户优先阶梯价**

团购客户价格敏感，核心诉求是“当下这笔订单便宜”。阶梯价直接、可感知、好谈判：

- **即时让利，成交转化快**：客户能看到“量大就便宜”，决策链条短。
- **规则透明，减少扯皮**：按数量/金额分档，双方都容易核算。
- **便于销售现场报价**：团购客户往往一次性采购，需要当场比价。
- **保护价格体系**：阶梯价可以按订单量给，不轻易形成长期低价基准。

**二、什么情况下返利更合适**

返利适合“量难预测、需要绑定长期关系、或不想直接降标价”的场景：

- **客户长期复购但单次量不稳定**：用累计返利鼓励持续下单。
- **需要保护公开价格体系**：标价不降，年底按业绩返，避免其他客户比价。
- **供应商想绑定客户全年采购份额**：返利可以设门槛，如年采购额达标才返。
- **客户对现金流不敏感、更看重年度总成本**：大团购客户或企业采购可能接受。

**三、建议的组合策略**

对团购客户，推荐“**阶梯价为主 + 返利为辅**”：

1. **首单/单次大单用阶梯价**：按数量或金额分3档，比如满10万、30万、50万各降一档，直接促成成交。
2. **长期合作客户叠加返利**：设置年度累计采购返利，门槛略高于其自然采购量，激励增量。
3. **返利只返“增量部分”**：避免客户把本来要下的单拆成返利单，侵蚀利润。
4. **返利形式优先选“下次采购抵扣”或“服务/物料支持”**，少用现金返，既锁定复购又减轻现金流压力。

**四、判断口诀**

- **一次性团购、比价激烈、要当场成交** → 阶梯价。
- **长期复购、年框采购、要稳价盘** → 返利。
- **两者都有** → 阶梯价成交，返利锁年。

**注意**：无论选哪种，先算清“最低成交价对应的毛利底线”，阶梯价的最低档和返利的最高返点都不能击穿这条线。返利条款要写清统计口径、结算周期、是否含税、退货是否冲减，否则后期容易争议。
