连锁商超招长期水果供应商，评分标准建议按“资格门槛+评分项”两层设计：先设硬门槛过滤，再用评分选长期伙伴。核心原则是：**不只比价格，更要比稳定性、品质一致性和食品安全能力**。

## 一、资格门槛（不满足直接淘汰，不计分）

- 营业执照、食品经营/生产许可、种植基地或合作社证明
- 近2年无重大食品安全事故、无严重违法失信记录
- 具备冷链仓储/运输能力（或明确合作方）
- 能提供农残检测报告、产地证明/溯源材料
- 具备商超或大型渠道供货经验（可设最低年限或类似案例数）
- 能接受账期、退换货、质量赔付等合同条款

## 二、评分项建议（100分制参考）

**1. 产品质量与稳定性（25–30分）**
- 样品/试供品质（外观、口感、规格一致性）：10–15分
- 批次质量稳定性、标准化分级能力：5–8分
- 品种/产地资源、反季节或全年供应能力：5–8分

**2. 食品安全与溯源（20–25分）**
- 农残检测制度、检测频次、第三方报告：8–10分
- 溯源体系（产地、批次、种植记录）：5–8分
- 食品安全管理体系认证（如HACCP、GAP等）：4–7分

**3. 供应保障与履约能力（20分）**
- 产能/货源稳定性、灾害或旺季应对方案：6–8分
- 冷链与物流配送能力、到货及时率承诺：6–8分
- 缺货替代、紧急补货、退换货响应机制：4–6分

**4. 价格与成本（15–20分）**
- 报价水平（建议用“基准价偏离度”计分，避免唯低价）：8–12分
- 价格调整机制是否透明合理（随行就市/锁价周期）：4–5分
- 包装、损耗、账期等综合成本：3–5分

**5. 服务与协同（10–15分）**
- 对接团队、响应速度、问题处理机制：4–6分
- 配合促销、定制包装、新品开发能力：3–5分
- 信息化对接（订单、库存、对账）能力：3–4分

**6. 企业实力与长期合作意愿（10分）**
- 财务健康、经营年限、基地/仓储规模：4–5分
- 类似商超合作案例与履约评价：3–4分
- 长期合作承诺、专用资源投入：2–3分

## 三、关键设置建议

- **价格分不宜过高**：水果损耗和品质波动大，低价供应商往往履约差，建议价格权重控制在15%–20%。
- **设置试供/样品环节**：样品分和试供考核分要占实打实权重，最好引入门店实测。
- **用“承诺+违约条款”绑定评分**：到货及时率、损耗率、农残合格率等写进合同，与评分承诺挂钩。
- **区分品类**：叶菜/浆果等易损耗品类提高冷链和稳定性权重；大宗耐储品类可适当提高价格权重。
- **避免唯资质论**：有认证但无稳定货源的供应商，要在产能和案例上压分。

一句话：**门槛看合规和安全，评分看品质稳定、供应保障和长期协同，价格只作参考项而非决定项。**
