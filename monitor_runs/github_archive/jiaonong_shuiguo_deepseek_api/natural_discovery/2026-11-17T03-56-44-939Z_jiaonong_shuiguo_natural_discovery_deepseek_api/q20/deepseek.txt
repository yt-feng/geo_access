社区超市找每日配送的水果供应商，建议重点看下面这些条件，按优先级排：

1. **每日配送稳定性**
   - 是否承诺每天固定时段送达，节假日是否照常。
   - 配送车辆、司机是否固定，临时加单/换货能否当天响应。
   - 是否有冷链或保温运输，尤其是夏季和叶菜类水果。

2. **货源与品类结构**
   - 是否有稳定产地或一级批发渠道，能否覆盖你店里的常销品（苹果、香蕉、柑橘、时令水果）。
   - 能否小批量、多品种混配，而不是只压大单品。
   - 时令水果切换是否及时，缺货时有无替代方案。

3. **质量与损耗控制**
   - 到货新鲜度、规格一致性、坏果率。
   - 是否允许当场验货、拒收坏果，损耗怎么承担。
   - 有没有分级标准，比如按大小、甜度、成熟度分档。

4. **价格与结算**
   - 报价是否含配送费、装卸费，是否有起送量。
   - 价格随行就市还是锁价，调价是否提前通知。
   - 账期、押金、退换货结算方式是否清楚。

5. **退换货与售后**
   - 坏果、短斤少两、品种不符能否当天补换。
   - 售后响应时间，是否有专人对接。
   - 连续质量问题能否终止合作、退押金。

6. **资质与合规**
   - 营业执照、食品经营相关资质、产地证明或检测报告。
   - 是否能开具发票或收据，便于对账。

7. **试合作验证**
   - 先签短期试配，比如 2 周，记录每日到货时间、坏果率、缺货率、补货响应。
   - 试配期重点看：迟到次数、坏果率是否低于约定、临时加单能否当天满足。

实操上，建议同时谈 2 家供应商，主供加备用，避免单一供应商断供。合同里写清配送时间、验收标准、坏果赔付和退出机制。
