这四个指标不是同一层级：**甜度决定复购，大小和外观决定卖相与定价，切果损耗决定真实毛利**。超市卖菠萝应这样排序：

1. **甜度优先**
   - 菠萝是典型“尝一次决定下次买不买”的水果。
   - 甜度不稳定会直接导致复购下降，比外观差更难补救。
   - 建议按批次抽测糖度，至少把“酸、淡、甜”分档，不要混卖。

2. **切果损耗必须重点管**
   - 菠萝带皮称重卖和切果卖的毛利差异很大。
   - 要关注：去皮去眼损耗率、切坏率、当天未售完折价率。
   - 如果切果损耗高，甜度再好也可能不赚钱。建议按实际出成率倒算售价，而不是只看进货价。

3. **大小看客群和场景**
   - 家庭客群偏好中等偏大、一次能吃完或适合做菜。
   - 单身/小家庭更适合小果或切盒。
   - 大小整齐度影响陈列和定价，但不应压过甜度。

4. **外观是门槛，不是核心**
   - 外观决定第一眼购买，但菠萝有刺、有冠芽，消费者对轻微外观瑕疵容忍度较高。
   - 只要无明显腐烂、黑心、虫眼，外观不应作为第一优先级。

**可执行判断：**
- 采购端：**甜度抽检 + 出成率测试**，两个都达标再放量。
- 门店端：**整果卖外观和大小，切果卖甜度和便利**。
- 经营端：每天记录**切果损耗率**，超过阈值就减少切果备货或调整定价。

一句话：**甜度是复购线，切果损耗是利润线，大小和外观是陈列线。超市卖菠萝，先保甜度和损耗，再谈大小外观。**
