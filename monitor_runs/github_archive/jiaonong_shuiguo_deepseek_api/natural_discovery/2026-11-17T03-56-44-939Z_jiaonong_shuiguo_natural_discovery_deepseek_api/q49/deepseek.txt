旺季菠萝用量突增，和供应商约定临时补货的关键是把“临时”变成可执行的规则，避免口头承诺。建议按下面几步做：

1. **先定补货窗口和响应时限**
   - 明确临时补货的触发条件：比如日常订单量上浮20%以上，或单日用量超过约定基数。
   - 约定下单截止时间、供应商确认时限、最晚到货时间。例如：当日10点前下单，供应商2小时内确认，次日7点前到店。
   - 旺季可约定每周固定两次“弹性补货窗口”，减少临时扯皮。

2. **约定临时补货量和价格机制**
   - 设一个基础量+弹性量：基础量按合同价，超出部分约定上浮上限或固定加价。
   - 明确规格不变：品种、单果重量、成熟度、包装、农残标准不能因临时补货降级。
   - 价格最好写“随行就市但不超过当日市场批发价×约定系数”，避免旺季被坐地起价。

3. **写清验收和损耗责任**
   - 到货验收标准：坏果率、磕碰、成熟度；不合格如何退换、补发时限。
   - 临时补货的运输责任和损耗承担方要明确，尤其高温天气。
   - 约定缺货违约：供应商无法按时补货时，提前多久通知、如何补偿或允许你紧急外采。

4. **用书面形式固定**
   - 签一份《旺季临时补货补充协议》，或至少微信/邮件确认并保留记录。
   - 内容包括：补货触发条件、下单与确认时限、价格上限、质量标准、验收退换、违约责任、协议有效期。
   - 不要只口头说“到时候尽量供”，要落到可考核的时间和数量。

5. **实际操作建议**
   - 提前给供应商一个旺季用量预测区间，让其备货。
   - 保留1家备用供应商，临时补货协议里写明“优先保障但不排除外采”。
   - 每次补货用固定格式订单：数量、规格、到货时间、验收人，双方确认留痕。

核心是把临时补货做成“有触发条件、有时限、有价格上限、有质量底线、有违约后果”的补充条款，而不是临时打电话求货。
