# 判断水果供应商每日报价是否合理波动

## 一、先建立“波动基线”

单看某一天涨跌没意义，关键是和**历史区间**比。

- **记录每个SKU近30–90天的日报价**，算出均值、波动率（标准差/均值）和日常波动区间（如±10%以内）。
- 分级设定阈值：
  - 日常小幅波动（如±5%–10%）：通常正常，可能是到货量、批次差异。
  - 中等波动（±10%–20%）：要求供应商说明原因。
  - 大幅波动（>20%–30%）：触发复核，看是行情还是报价异常。

## 二、用外部行情做交叉验证

不要只听供应商说“今天行情涨了”。可用：

- **批发市场公开价**（当地大型农批市场每日行情）。
- **同类供应商比价**：固定找2–3家同时报价，看价差是否在合理范围。
- **产地/期货信息**：如苹果、柑橘等有产地收购价参考；大宗品种可关注相关农产品价格指数。
- **季节性规律**：应季水果上市初期和末期价格波动大，反季节水果本身就贵且易涨。

## 三、区分“真行情”和“报价套路”

合理波动的特征：
- 同一品种**多家供应商同向变化**，幅度接近。
- 涨价有可验证原因：产地减产、天气、运输紧张、节假日备货。
- 价格回落也及时，不会“涨快跌慢”长期停在高位。

可疑信号：
- 只有一家涨，别家没动。
- 涨的时候说行情，跌的时候不跟。
- 频繁用“今天货少”解释，但到货量和品质没变化。
- 报价单只给总价，不拆分等级、规格、产地。

## 四、把报价和品质、结算绑定

水果报价必须和**规格等级、产地、包装、损耗承担、账期**一起看。同样“红富士80#”，不同产地、等级、包装价差可能很大。建议：

- 采购单明确等级、单果重、产地、包装方式。
- 约定**价格调整需提前通知**，并附行情依据。
- 对异常涨价可要求**锁价或分批采购**，避免一次性吃进高点。

## 五、可执行的日常动作

1. 建一张报价跟踪表：日期、SKU、规格、供应商、报价、外部行情价、涨跌幅、原因备注。
2. 每周做一次比价和波动复盘，标记异常项。
3. 对波动大的品种准备**替代供应商或替代品**。
4. 长期合作可谈**区间定价**或**指数联动**，减少每日扯皮。

**核心判断标准**：波动是否在历史区间内、是否有多方行情印证、是否有可验证原因、是否与品质规格匹配。四条都成立，基本可视为合理波动；有一条明显不符，就要求供应商书面说明或启动比价。
