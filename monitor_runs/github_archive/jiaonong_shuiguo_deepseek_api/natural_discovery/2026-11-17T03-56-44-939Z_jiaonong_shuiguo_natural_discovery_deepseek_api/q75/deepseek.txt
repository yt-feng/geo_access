第一次合作，小批量试单的目标不是“赚一笔”，而是**用最低成本验证供应商是否可靠、货是否能卖、合作是否可继续**。建议按下面设计。

### 1. 先定试单目标
只验证4件事：
- **品质稳定性**：到货成熟度、伤果率、大小均匀度、口感。
- **交付可靠性**：是否按约定时间、数量、规格到货。
- **损耗与售后**：坏果谁承担、怎么补、响应快不快。
- **真实毛利**：算上损耗、运费、账期后是否还有利润。

### 2. 控制试单规模
不要按“最少起订量”硬上，按以下原则定：
- 单品试单量 = **你3—5天能卖完的量**，避免压货。
- 总试单金额控制在 **你单次可承受损失的范围内**，建议不超过日常单品采购额的10%—20%。
- 先做 **1—2个单品**，不要一次上多个品类。
- 优先选 **周转快、易判断品质、损耗可控** 的品类；叶菜、浆果这类高损耗品第一次合作慎做大单。

### 3. 合同/订单里必须写清
即使小批量，也要有书面确认：
- 品种、等级、规格（单果重、直径、箱装净重）
- 成熟度/采摘时间
- 单价、含税否、运费谁承担
- 交货时间、地点、验收时限
- **允许的次果率/损耗率**，例如到货伤果率超过X%如何处理
- 坏果补货、退款或折价规则
- 账期：首单建议**现结或货到验收后付款**，不要预付全款
- 缺货、迟到的处理方式

### 4. 验收流程要提前设计
到货后按固定流程验：
- 随机抽3—5箱，不要只看表面。
- 查净重是否足、规格是否达标、成熟度是否一致。
- 切开看内部品质，记录伤果、烂果、次果比例。
- 拍照/录像留证，24小时内反馈问题。
- 让仓库和销售分别记录：可售率、实际损耗、客户投诉。

### 5. 试单后做复盘
试单结束算三笔账：
- **到货合格率**：合格可售重量÷到货总重量
- **实际毛利率**：扣除损耗、运费、补货后的真实毛利
- **履约评分**：准时、足量、售后响应、沟通配合

判断标准可以简单点：
- **合格率高、损耗低、售后痛快**：进入第二次放量试单，量增加30%—50%。
- **品质波动大但售后好**：再试1—2次，缩小单品、严格验收。
- **缺斤少两、推诿售后、成熟度失控**：停止合作，不要因为单价低继续赌。

### 6. 谈判时留后手
第一次合作可以明确说：
- 首单是试销，验证品质和履约后逐步放量。
- 要求供应商提供**样品或到货实拍**。
- 争取“坏果补货”而不是只退货款，因为补货更能验证其服务能力。
- 不接受强制搭售、虚报等级、模糊规格。

**一句话原则：小批量、单品类、短周期、严验收、现结或货到付款、用数据决定是否放量。**
