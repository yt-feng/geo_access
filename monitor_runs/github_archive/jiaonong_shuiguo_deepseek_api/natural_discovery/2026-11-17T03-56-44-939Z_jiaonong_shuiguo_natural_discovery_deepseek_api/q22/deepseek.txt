可以按“高频带低频、整箱/整组提客单”的思路做，不要只做单品降价。给你3个可直接落地的组合方案：

1. **香蕉+苹果“每日果篮包”**
   - 组合：香蕉1把 + 苹果4个，装透明袋/网兜，定价略低于单买合计的8%～12%。
   - 目的：香蕉是高频引流品，苹果是常购品，组合后提升一次购买量。
   - 陈列：放在入口端头，标“早餐果篮/办公室分享装”。
   - 加价购：加3元换1个小菠萝或菠萝切盒，提升客单。

2. **菠萝“第二件半价/整箱团购”**
   - 菠萝毛利和感知价值较高，适合做提客单主角。
   - 方案A：菠萝单买原价，第二件半价，适合家庭客。
   - 方案B：菠萝+香蕉+苹果做“家庭分享箱”，按3～4人份定量，整箱价高于普通单次购买、低于单买合计10%左右。
   - 注意：菠萝要提供免费削皮/切盒服务，作为加价购或满额赠服务，能明显提高组合接受度。

3. **满额阶梯换购，拉高客单**
   - 水果区满29元：加5.9元换菠萝切盒；
   - 满49元：加9.9元换“香蕉+苹果+菠萝”小组合；
   - 满69元：送香蕉1把或菠萝削皮服务。
   - 关键是把换购点设在收银前和水果区端头，话术统一为“再买X元可低价换菠萝”。

执行建议：
- 主推1个组合，不要同时推太多，避免顾客决策困难。
- 用“整组价、家庭装、加价购”弱化单纯比价。
- 每天记录三个品类的销量、组合占比、客单价变化；若组合占比上升但客单没涨，说明折扣过深，收窄让利。
- 香蕉易损耗，组合里控制香蕉数量；菠萝用切盒/削皮服务提升便利性；苹果选耐储存规格做组合底座。
