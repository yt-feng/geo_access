最该先问**售后**，再问**配送**，最后才谈**价格**。原因是团购团长的核心风险不是“进货贵一点”，而是“坏果、少件、售后扯皮”会直接伤团长信用和复购。

优先级建议：

1. **售后**：先问清楚坏果率怎么算、拍照举证要求、多久内响应、坏果是补发还是退款、损耗谁承担、整批质量问题能否退换。  
2. **配送**：问固定到货时间、迟到怎么处理、是否送到团长点、临时改量是否接单、冷链/夏季保鲜措施、少件漏件怎么补。  
3. **价格**：价格要问，但应在售后和配送规则明确后谈，重点问阶梯价、起订量、运费、损耗是否含在报价里、账期/结算方式。

一句话：**先用售后筛掉不靠谱供应商，再用配送确认能不能稳定履约，最后用价格做比较。** 只问价格容易选到“便宜但坏果多、迟到多、售后拖”的供应商，团长最后赔的是口碑。
