判断香蕉一手货源稳不稳，别只听对方说“我有基地”，按下面几项做可验证的核查，基本能筛掉大部分不稳定供货商。

**1. 先核实“一手”身份**
- 要求对方提供：种植基地地址、基地照片/视频（带定位和时间水印）、合作社或公司营业执照、香蕉收购/代办资质。
- 视频通话看现场：蕉园、装蕉工、催熟库或打包场是否真实存在。
- 问清是自种、代收还是调货。自种+代收的代办通常比纯调货稳，但也要看规模。

**2. 看供货季节和产地跨度**
- 香蕉主产区有季节性。问对方：你主要做哪个产区？旺季月供多少？淡季从哪补货？
- 稳定供货商通常有多个产区衔接（如云南、广西、海南、老挝/缅甸进口等），能说清各产区上市月份和切换逻辑。
- 只靠单一产区、单一果园的，淡季容易断供。

**3. 查历史出货能力**
- 要求看近1–3个月的出货记录：装车单、物流单、过磅单、发货视频，重点看是否连续、量是否稳定。
- 问日加工/装车能力：几条打包线、日均装几车、冷库/催熟库容量。
- 最好让对方提供2–3个长期合作档口的联系方式做背调，问：断供过吗？质量波动大吗？售后处理快吗？

**4. 用小单试供验证**
- 先下1–2车小单，别一上来签大合同。
- 重点看：装车是否按时、规格是否一致、青蕉成熟度是否均匀、损耗率多少、坏货是否按约定补。
- 连续试2–3批，观察不同批次质量是否稳定，这比任何承诺都可靠。

**5. 看合同和风险条款**
- 明确：规格标准、成熟度、允许损耗率、断供违约责任、价格随行就市还是锁价、运费和装车费谁承担。
- 稳定供货商敢写断供赔偿和补货时限；只肯口头承诺、不愿写违约条款的要警惕。

**6. 现场或第三方验货**
- 首次大单建议自己去装车现场，或委托当地代办/验货员盯装车，防止“看货是好货、装车换次货”。
- 检查催熟库和打包场卫生、香蕉梳形和条蕉均匀度、机械伤比例。

**快速判断口诀：** 能视频看基地、能说清淡旺季补货来源、有连续出货单据、敢做小单试供、敢写断供条款——五项里缺三项以上，就别当主力供应商。
