可以，但通常不是“默认给”，而是看你的采购量、合作关系和活动方案。水果供应商在周末促销上常见的支持方式有：

1. **价格支持**
   - 周末特价供货：对1-3个引流单品给临时进货折扣。
   - 满量返利/阶梯价：比如周末两天某单品累计采购满多少箱，返差价或下批抵扣。
   - 搭赠：买10箱送1箱，或滞销/临期品搭赠。
   - 费用分摊：特价单品的降价成本供应商承担一部分。

2. **物料支持**
   - 周转筐、纸箱、保鲜袋、标签、海报、价签、试吃盒等。
   - 品牌方或一级批发商可能有现成促销海报、展架、围裙、遮阳棚。
   - 水果产地的宣传物料、试吃活动物料。

3. **人员与活动支持**
   - 供应商业务员周末到店帮忙陈列、试吃推广。
   - 提供试吃品、赠品、小礼品。
   - 联合做“产地直采”“周末爆品”活动。

**能不能拿到，关键看：**
- 你是不是稳定客户，平时采购量够不够；
- 促销单品是不是供应商主推或库存压力大的品；
- 你有没有明确的促销方案、预计销量和陈列位置；
- 是否愿意给供应商露出：海报署名、朋友圈宣传、堆头位置、长期合作承诺。

**建议你直接这样谈：**
“我这周末做水果促销，计划把XX和XX做引流爆品，预计每个单品周末采购X箱。想申请周末特供价/买赠，同时需要价签、海报、试吃盒。活动期间我在店里和朋友圈给供应商做露出，后续这个单品也优先从你家走。你看能支持到什么程度？”

**判断标准：**
- 小额试单、临时拿货：一般只有少量搭赠或物料，价格支持有限。
- 稳定采购、提前报计划：更容易拿到周末特价、返利和物料。
- 连锁或大店：可直接找一级批发商/品牌经销商谈联合促销。
- 社区小店：优先找本地批发商谈“爆品搭赠+物料”，别一上来要现金返点。

注意：价格支持最好落到书面或微信确认，写清品名、规格、数量、活动时间、结算方式，避免周末结束后扯皮。
