可以从“采购—验收—储存—加工—处置”五个环节控制，重点是少买、勤补、分开存、及时用。

1. **采购：少量多次，按成熟度分批下单**
- 按食堂每日实际消耗量下单，香蕉容易熟，不要一次囤太多。
- 与供应商约定香蕉到货成熟度：以“表皮金黄、少量芝麻点、果肉尚硬”为宜，避免送已经大面积黑斑、软塌的货。
- 要求分批配送，比如每天或隔天送一次，减少库房积压。
- 采购量可按“当天用量＋次日早段用量”控制，不要按一周用量一次性采购。

2. **验收：按成熟度分级，不合格拒收或折价**
- 到货时检查：果柄是否发黑、表皮黑斑面积、是否软烂、是否有酒味或霉点。
- 把香蕉分成“青黄可存放”“即食必须优先用”“过熟只能加工”三类，分别标识。
- 对已过熟、压伤、腐烂的香蕉，按合同拒收、换货或折价，不要让“勉强收下”变成后续浪费。

3. **储存：不要冷藏，分开放、控温通风**
- 未熟或刚黄的香蕉放在阴凉通风处，适宜温度大约13—15℃，避免阳光直射和暖气旁。
- 不要放冰箱冷藏，低温会导致表皮变黑、果肉变软。
- 香蕉会释放乙烯催熟，尽量与苹果、梨等也释放乙烯的水果分开；已黄的香蕉可用保鲜膜包住果柄，减缓成熟。
- 成串香蕉可拆开存放，减少互相挤压和集中催熟；发现黑斑的及时挑出优先使用。
- 库房执行“先进先出”，每天翻检一次，把最熟的放到食堂窗口或加工间优先消耗。

4. 使用：先熟先用，开发即食和加工用法
- 食堂窗口优先摆放已熟香蕉，设置“今日熟香蕉”提示，引导先取。
- 熟到表皮有黑点但果肉未坏的，可用于制作香蕉牛奶、香蕉燕麦、香蕉饼、香蕉面包、水果沙拉等，但要做感官检查，有酒味、酸味、霉点、流汁的不要用。
- 与早餐、加餐、烘焙间建立“熟香蕉优先领用”机制，避免窗口只挑好看的，熟的反被剩下。

5. 处置：建立预警和记录
- 每天记录到货量、消耗量、剩余量和报废量，找出采购量偏大的日期，下周相应减量。
- 设“临期香蕉”预警：表皮黑斑超过一定比例或开始变软时，立即转为加工或内部特价供应，不等烂了再处理。
- 若浪费反复出现，可与供应商协商“按实际消耗结算”“小批量高频配送”或“熟度分级供货”。

核心原则：**香蕉不追求一次买够，而是小批量、高频补货；不混放囤积；按成熟度分级使用；熟香蕉提前转到加工和窗口优先消耗。**
