年度合同里最容易踩坑的，通常不是价格本身，而是**价格调整、质量标准、损耗归属、账期和返利**这五类条款。按风险从高到低说：

**1. 价格与调价机制**
- 只写“随行就市”最容易扯皮。要明确基准价、调价触发条件（如产地批发价波动超过x%）、调价频率、谁发起、多久生效、历史订单是否追溯。
- 促销价、特价品、新品定价是否单独约定，否则供应商可能拒绝供货或以次充好。
- 建议设“价格保护期”和“单方调价需提前书面通知”的条款。

**2. 质量标准与验收**
- 不能只写“符合国家标准”，水果要写具体：品种、规格（单果重/果径）、糖度、成熟度、色泽、农残检测要求、包装规格。
- 验收标准要写明抽检比例、不合格判定规则、复检机制。否则到货后“算不算合格”全靠门店说了算，供应商和采购都会吃亏。
- 明确农残超标、食品安全事故的责任和赔偿，这是法律风险最高的部分。

**3. 损耗与退换货**
- 水果损耗大，必须约定：到货损耗率上限、门店陈列损耗谁承担、临期/变质品的退换货比例和时限。
- 常见坑是“无条件退换”写得太宽，供应商成本转嫁到报价；或者反过来写“签收即认可”，门店后期损耗全自己扛。建议按品类设阶梯损耗率。
- 明确退货的运输费用和销毁责任归属。

**4. 账期、结算与返利**
- 账期天数、起算日（到货日还是对账日）、对账周期、发票要求要写死，避免“月结”变“拖结”。
- 返利/通道费/促销费要区分是**按进货额**还是**按销售额**计算，是否含税，未达标是否补差，年底是否可追溯。
- 注意“账期+返利+费用”叠加后的实际毛利，很多合同单看价格便宜，算完费用并不划算。

**5. 供货保障与违约责任**
- 写清最低供货量、缺货违约责任、旺季优先供应义务。水果季节性强的品类尤其要约定断供的处理。
- 违约金要可执行：固定金额、按缺货金额比例、或扣减返利，避免写成“协商解决”。
- 同时约定不可抗力（天气、疫情、物流）的认定和免责范围，否则一方拿天气当万能借口。

**6. 容易忽略的**
- **排他/最低采购量**：是否限制从其他供应商采购，未达标是否有罚则。
- **知识产权与包装**：定制包装、品牌标识归属。
- **合同期限与续约**：自动续约条款、提前解约条件。
- **争议解决**：管辖法院或仲裁地，尽量约定在超市所在地。

**可执行建议**：签前做一份“条款风险清单”，把上述每项落到具体数字和责任人；价格、损耗、返利三项最好用附件表格量化，主合同只写机制。谈判时优先锁定质量验收和损耗归属，这两项对实际利润影响最大。
