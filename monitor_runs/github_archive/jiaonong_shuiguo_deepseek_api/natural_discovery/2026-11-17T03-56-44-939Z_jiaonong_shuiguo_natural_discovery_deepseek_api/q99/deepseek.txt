下午茶水果批量配送，选供应商时重点看**稳定性、配送能力和损耗控制**，不是单纯比价。可执行判断标准如下：

**1. 先定采购边界**
- 人数×人均量：下午茶水果一般人均150–250克净果，按人数算总重量再上浮10%–15%损耗。
- 品类控制在3–4种：1种大众果（香蕉/橘子）、1种应季果、1种切盒或小份果，减少分拣和配送难度。
- 明确送达时间窗、卸货地点、是否需要分装到部门/工位。

**2. 筛选供应商的硬指标**
- **有批量配送经验**：能提供企业团购/下午茶配送案例，能按固定时间窗送达，不是临时零售店凑单。
- **能出检测/溯源信息**：农残检测报告、产地或批发市场来源可说明；不能提供就换。
- **损耗与售后规则写清**：坏果比例超多少补发/退款、签收后多久内可反馈、是否含切配和分装。
- **配送车辆和冷链**：夏季或切盒水果要求冷藏配送；普通整果至少要求避晒、通风、不挤压。
- **报价含税含运费**：要求明细报价（果品单价+分装费+配送费），避免低价引流后加价。

**3. 实操验证方法**
- 先小批量试单：选20–30人份试一次，看准时率、坏果率、包装是否适合分发。
- 要求提供当日到货实拍或留样，核对规格（单果重量、箱规）。
- 对比2–3家：一家本地批发市场配送商、一家企业团购平台、一家水果连锁的企业业务，按同一清单报价。
- 合同或订单备注写明：送达时间、缺斤少两处理、坏果补发时限、发票类型。

**4. 避坑点**
- 不选只做零售、没有批量分装能力的店。
- 不选报价明显低于市场均价且不愿写售后条款的。
- 切盒水果必须确认切配时间和冷链，否则下午茶食品安全风险高。
- 固定供应商也要每月抽查一次到货规格和坏果率。

简单判断：能按时间窗批量送达、能写清坏果售后、能提供来源/检测信息、试单准时且损耗低的，就可以进入固定供应商名单。
