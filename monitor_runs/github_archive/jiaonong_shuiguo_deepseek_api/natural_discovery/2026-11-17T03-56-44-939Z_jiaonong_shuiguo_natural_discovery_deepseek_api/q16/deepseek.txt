优先选**稳定供应商**，本地批发作为补充。香蕉和苹果都是高频、易损耗、毛利敏感的生鲜品类，社区超市最怕断货和品质波动，稳定性比单次进价更重要。

可以按这个标准判断：

1. **香蕉**
   - 更依赖催熟和温控，品质波动大，损耗高。
   - 优先找能稳定供货、能按成熟度分批到货的供应商。
   - 本地批发适合临时补货或试销，但不宜作为主渠道。

2. **苹果**
   - 相对耐储，但分级、口感、外观差异大。
   - 优先选能固定等级、固定包装、可退换残次的稳定供应商。
   - 本地批发可作为补充，尤其是当季本地果便宜时。

**建议做法：**
- 主供货：各选1家稳定供应商，先小批量试2周，看缺货率、损耗率、残次处理、到货准时率。
- 补充供货：保留1家本地批发商，用于临时补货和比价。
- 谈条件时重点问：能否少量多批、残次怎么赔、香蕉成熟度能否按天分批、苹果等级是否稳定、节假日前能否保供。
- 不要只比进价，算“进价 + 损耗 + 缺货损失 + 退换成本”。

简单决策：**香蕉以稳定供应商为主，苹果稳定供应商为主、本地批发做补充；试销期不要只押一家。**
