判断水果供应商靠不靠谱，重点不是“他说得多好”，而是能不能长期稳定地给你**可预期的货、可追责的问题处理、可算清的账**。你可以按下面这套方法筛选和验证。

## 1. 先看“稳定性”，再看价格
长期做香蕉和菠萝，最怕断货和品质大起大落。问供应商四个问题：

- **货源是否稳定**：香蕉主要看产区/催熟能力，菠萝看品种和产季衔接。让他说明不同季节从哪拿货、断货时怎么补。
- **每天/每周能稳定供多少**：先小批量试，不要一上来压大单。
- **送货时间是否固定**：水果店最怕早上该到不到。约定到店时间窗口，迟到怎么处理。
- **损耗和售后怎么算**：坏果、青果、过熟、黑心菠萝、香蕉催熟不均，分别怎么赔、怎么换。

靠谱供应商会主动讲清楚这些；不靠谱的通常只会说“放心，没问题”。

## 2. 用三次小批量试单验证
不要靠一次看货就定长期合作。建议分三次试：

- **第一次**：小批量，看准时率、数量足不足、外观和成熟度。
- **第二次**：隔几天再要，观察稳定性，是否同一品质。
- **第三次**：故意提一次售后，比如有坏果，看他处理速度和态度。

重点记录：
- 到货准时率
- 缺斤少两情况
- 坏果率
- 香蕉催熟是否均匀、货架期几天
- 菠萝黑心率、酸甜度、大小是否稳定
- 售后是否推诿

三次都稳定，才考虑长期合作。

## 3. 看他的“专业度”
香蕉和菠萝都有明显经营门槛：

**香蕉**：问催熟方式、到店是青的还是黄的、适合几天卖完、夏天和冬天催熟差异。靠谱供应商能说清楚，并愿意按你的销量调整成熟度。

**菠萝**：问品种、产地、是否催熟、黑心怎么赔、不同季节口感差异。只会说“便宜”“都好”的，要谨慎。

## 4. 看账期和合同意识
长期合作必须把规则写清楚，哪怕只是微信确认：

- 价格怎么定：随行就市还是锁价，涨跌提前多久通知
- 结算方式：现结、周结还是月结
- 缺货、迟到、品质不达标怎么处理
- 退换货时限
- 是否允许你临时改单

不肯明确规则、只靠口头承诺的供应商，长期风险高。

## 5. 看同行口碑和现场
- 问他现在供哪些店，最好能侧面了解
- 有条件去他的档口/仓库看：货堆是否整齐、冷库是否干净、工人分拣是否规范
- 看他处理其他客户售后时的态度

## 6. 最简单的判断标准
合作一个月后，用三个指标打分：

1. **准时足量率**是否稳定在95%以上
2. **坏果率**是否在你能承受的范围，且售后不扯皮
3. **价格波动时**是否提前通知、不临时坐地起价

三项都稳，才值得长期绑定。任何一项反复出问题，就不要因为便宜几毛钱继续合作。

**建议你第一步这样做**：同时找2家供应商，各试单3次，用同一套记录表对比。不要只留一家，香蕉和菠萝最好各有主供和备供，避免被单一供应商卡脖子。
