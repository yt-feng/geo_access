采购时按“耐放程度”选货，而不是只挑最黄的。可执行做法：

1. **买成熟度偏低的香蕉**：选表皮黄中带一点绿、没有明显黑斑的。做甜品当天用可买稍熟；备货2–3天就买偏绿一点的，到店后自然转熟。
2. **避开“催熟陷阱”**：整串颜色过于均匀、通体亮黄、个别已有小褐点的，往往熟得快。优先选果指饱满、棱角稍明显、果柄完整的。
3. **减少机械伤**：香蕉怕压怕碰。采购时不要和苹果、梨等释放乙烯多的水果混放；运输中用纸箱分隔，避免堆叠挤压。果柄开裂、表皮擦伤的要先挑出优先用。
4. **到店后立刻“分串、去膜、通风”**：把整串分成小串，去掉塑料膜/袋，放在阴凉通风处，理想温度约 **13–15℃**，不要放冰箱冷藏（低温会冻伤发黑）。成熟后可移入冷藏，但表皮仍会变黑，果肉短期可用。
5. **控乙烯**：把已熟香蕉和未熟香蕉分开；熟蕉尽快用掉或做成果泥冷冻。不要在密闭空间大量堆放。
6. **采购节奏**：按“当天用量 + 2天备用量”分批买，少量多次，比一次囤货更稳。
7. **应急处理**：表皮刚发黑但果肉完好的，可优先做香蕉泥、烘焙、奶昔等；果肉发软发酸的不要用。

一句话：**买偏绿、少碰伤、分串通风、13–15℃存放、熟蕉隔离并优先消耗。**
