第一次试单，核心不是“找到最便宜的”，而是**用最小成本验证供货商稳不稳、货损高不高、结款和补货靠不靠谱**。夫妻店建议按下面做。

**1. 先定试单原则**
- 只试单品、少量：香蕉、苹果、橙子各先拿**1—2箱/件**，不要一次铺满。
- 分2—3家供货商交叉试，不要只押一家。
- 先问清：起送量、配送费、到店时间、结款方式、坏果怎么赔、能不能退货换货。
- 不要第一次就谈长账期；现结或短账期更容易拿到真实报价。

**2. 三类货分别怎么试**
- **香蕉**：最看成熟度和周转。试单看送到时青黄比例、有没有机械伤、催熟是否均匀。第一次少量拿，记录到店后第1天、第2天、第3天卖相和损耗。
- **苹果**：看规格是否统一、硬度、碰压伤、果面。试单时随机翻箱看底层，不要只看上面一层。问清是产地直发还是市场调货。
- **橙子**：看新鲜度、失水、大小均匀度、酸度。试单可拿小果和中果各一箱对比毛利和动销，别只看大果好看。

**3. 试单当天要做的检查**
- 到店先称重、抽检：每箱随机翻3—5个，看底层和边角。
- 拍照留证：箱规、果径、坏果、压伤、成熟度。
- 记录：到货时间、实际重量、坏果率、报价、配送费。
- 问清补货频率：当天能不能补、缺货怎么处理、节假日是否涨价。

**4. 用一周数据决定是否续单**
试单后看四个指标：
- **坏果率**：香蕉、橙子超过5%—8%就要警惕，苹果碰压伤多也要压价或换供应商。
- **动销**：三天内能不能卖动，尤其是香蕉。
- **毛利**：按实际损耗算，不是按进货价算。
- **履约**：是否准时、缺货是否提前说、售后是否痛快。

**5. 给供货商的话术**
可以直接说：“我们夫妻店第一次合作，先小量试单，香蕉、苹果、橙子各一件，现结。到货我们抽检，坏果按比例赔或换。稳定的话后续固定从你这补。”

**6. 避坑**
- 不要第一次就大量压货，尤其香蕉。
- 不要只看报价低，算上损耗和配送费再比。
- 不要接受“坏果不管”的口头承诺，至少微信留文字。
- 不要只试一家，至少留一个备选。

简单说：**少量、多品、交叉试、当天抽检、按损耗算账，一周后留下最稳的那家。**
