节假日水果需求暴增，锁货源的核心不是“多打几个电话”，而是把**需求预测、合同锁定、产地直采、库存缓冲、替代方案**做成一套可执行的机制。建议按下面几步做：

1. **提前做节假日需求预测，按单品拆到门店**
   - 用过去2—3年同节假日的销量、客流、客单价、天气、促销活动做基线。
   - 按“必爆品/常规品/形象品”分类：礼盒果、车厘子、阳光玫瑰、榴莲、柑橘类等分别定安全库存。
   - 预测到SKU和门店，避免只给采购一个总量，导致畅销店断货、滞销店压货。

2. **提前30—45天锁定核心货源**
   - 对节假日必爆单品，提前与主供应商签**框架采购+最低供货量+价格区间**协议，不要只做口头预留。
   - 合同里明确：供货量、到货时间、品质标准、缺货违约责任、价格调整机制。
   - 对高度依赖单一产区的单品，至少锁定**2家主供应商+1家备用供应商**。

3. **产地直采与批发市场双通道并行**
   - 大宗爆品可提前对接产地合作社、龙头企业做产地直发，锁定采摘期和装车计划。
   - 同时保留区域批发市场作为快反补货通道，用于节前临时补量和品质替换。
   - 直采比例不宜一次性拉满，建议核心单品直采占60%—70%，其余用批发市场兜底。

4. **用“订单农业+定金”提高供应商履约率**
   - 对紧缺单品支付合理定金或预付款，换取优先供货权。
   - 要求供应商按周报备产量、采摘进度、装车能力。
   - 对履约好的供应商给予节后持续订单，形成稳定合作，而不是节前临时抢货。

5. **建立节前库存缓冲和到货节奏**
   - 节前7—10天逐步提高到货量，不要等需求爆发当天才集中到货。
   - 易损耗水果控制单次到货量，增加到货频次；耐储水果可适当提高安全库存。
   - 配送中心设“节假日应急库存”，只用于门店紧急补货，避免门店各自囤货。

6. **准备替代单品和动态调价机制**
   - 每个爆品设1—2个替代SKU，比如某进口果缺货时用国产优质产区替代。
   - 建立缺货分级响应：主供应商延迟→备用供应商补→区域市场调货→替代品上架。
   - 价格波动大的单品，提前设定零售价区间和毛利底线，避免节前被动跟价。

7. **节前做一次供应链压力测试**
   - 模拟“主供应商少供30%”“物流延迟1天”“某爆品到货品质不达标”三种情况，看补货路径是否跑得通。
   - 明确采购、配送、门店三方的补货审批和调拨权限，节假日期间缩短决策链。

**最可执行的落地动作：** 节前45天完成核心单品供应商锁量签约；节前30天确定直采装车计划；节前15天把安全库存和替代方案下发到门店；节前7天启动每日到货和库存复盘。这样比临时加价抢货更稳，也更能控制毛利。
