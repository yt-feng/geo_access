降低门店坏果率，合同里不能只写“坏了赔”，要把**验收标准、责任归属、赔付计算、处理时限、举证和扣款方式**写清楚，才能真正可执行。建议按下面结构约定：

## 1. 先定义“坏果”
合同中明确坏果判定标准和验收方法，避免扯皮。例如：

- 腐烂、霉变、流汁、异味；
- 机械伤导致果肉外露、明显压伤、开裂；
- 冻伤、日灼、失水皱缩超过约定程度；
- 单果直径/重量/糖度/色泽低于约定等级；
- 病虫害、农残超标；
- 包装破损导致污染。

同时约定：
- **抽检比例**：如每批次随机抽检不少于3箱/5%，大货按比例抽检；
- **合格判定**：坏果率≤约定比例（如3%）为合格；超过即整批可拒收或按比例赔付；
- **计量口径**：按重量、件数还是货值计算，必须写死。

## 2. 分环节约定责任
坏果可能发生在产地、运输、仓储、门店。合同要按环节划分：

- **到仓验收前**：供应商承担，包括运输损耗；
- **验收合格入库后**：因超市仓储温湿度、陈列、理货不当造成的，供应商不承担；
- **门店收货时**：门店应在约定时限内验收，逾期未提出异议视为验收合格；
- **保质期内非人为变质**：供应商承担，但超市需按约定储存条件举证。

建议附《验收标准》《温湿度要求》《陈列规范》作为合同附件。

## 3. 赔付方式要可计算
不要只写“按实际损失赔偿”，建议设阶梯式赔付：

| 情形 | 处理 |
|---|---|
| 坏果率≤3% | 正常验收，不赔付 |
| 3%＜坏果率≤5% | 按坏果重量×采购单价×1.2赔付，或按比例扣款 |
| 5%＜坏果率≤10% | 整批按坏果比例折价，另扣该批次货值5%违约金 |
| 坏果率＞10% | 超市有权拒收/退货，供应商承担运费，并按该批次货值10%-20%支付违约金 |
| 同一供应商月度累计3次超标 | 超市有权暂停供货、扣减保证金或解除合同 |

还可以约定：
- **保底赔付**：单次赔付不足约定金额的，按保底金额赔；
- **连带损失**：因坏果导致顾客投诉、下架、监管处罚的，供应商承担合理损失，但需超市提供凭证；
- **质量保证金**：从货款中留3%-5%作为质保金，季度结算。

## 4. 处理流程和时限
写清楚可操作流程：

1. 门店收货后**24小时内**完成验收并拍照/录像；
2. 发现超标，**48小时内**书面通知供应商；
3. 供应商**24小时内**响应，可到场复验；
4. 逾期未响应，视为认可超市验收结果；
5. 赔付优先从**当月货款中直接扣除**，不足部分从保证金扣；
6. 退货/换货完成时限，如**3个工作日内**补货。

## 5. 举证和争议解决
- 验收以双方签字确认的验收单为准；
- 照片、视频、第三方检测报告可作为证据；
- 对坏果原因有争议的，可约定送第三方检测，费用由责任方承担；
- 明确异常天气、自然灾害等不可抗力是否免责，但供应商不能以“运输损耗”一概免责。

## 6. 建议的核心条款示例

> 乙方交付商品坏果率不得超过3%。甲方在收货后24小时内按附件标准验收。坏果率超过3%的，甲方有权按坏果重量×采购单价×1.2从货款中扣除；超过5%的，甲方有权拒收该批次，乙方应在3个工作日内换货，并承担往返运费；超过10%的，乙方另按该批次货值10%支付违约金。同一供应商月度累计3次超标的，甲方有权暂停采购或解除合同。因甲方储存、陈列不当导致的坏果，乙方不承担责任。

**一句话总结：合同要写清“什么算坏、谁来赔、赔多少、怎么扣、多久处理”，并用附件固定验收标准和温湿度要求。** 这样既能让门店敢收货、敢索赔，也能避免供应商把超市自身损耗转嫁回来。
