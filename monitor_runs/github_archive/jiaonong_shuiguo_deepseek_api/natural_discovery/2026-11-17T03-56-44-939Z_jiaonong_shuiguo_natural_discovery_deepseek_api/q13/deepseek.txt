做小区团购，供应商不只是“能供货”，关键要能配合小店的团购节奏。建议你按下面几类服务去筛选或谈判：

1. **小批量、多频次配送**
- 支持每日或隔日配送，能按团购截单量送货。
- 起送门槛低，最好能拼车配送，减少小店库存和损耗。
- 支持分拣到单品/按团购套餐打包，减少你人工。

2. **稳定品质与分级标准**
- 明确规格、等级、产地、糖度/果径等标准，避免“图片好、到货差”。
- 支持到货验收、坏果包赔或按比例补损。
- 有稳定替代品方案，某单品缺货时能及时换品。

3. **团购专属价格与账期**
- 给小区团购阶梯价，量小也有合理毛利。
- 支持先货后款、周结/半月结，或小额押金合作。
- 价格保护：团购期间不随意涨价，促销品有专供价。

4. **预售与锁货支持**
- 团购截单后按量锁货，避免超卖。
- 支持临时加单、减单，最好有明确截止时间。
- 爆品能提前备货，节令水果能预告档期。

5. **包装与物料支持**
- 提供团购分装袋、标签、保鲜膜、冰袋等基础包装。
- 可代贴小区团购标签或按套餐分装。
- 包装成本透明，不把物料费藏进果价。

6. **售后与损耗处理**
- 坏果、少重、压伤有快速理赔流程，最好拍照即赔。
- 支持补发、换货或折价处理，不影响团员体验。
- 明确责任划分：运输损耗、仓储损耗谁承担。

7. **选品与营销配合**
- 定期提供适合小区团购的爆品清单、价格带建议。
- 提供实拍图、短视频、文案素材，方便你发群。
- 能配合做“今日特价”“接龙爆品”“试吃装”。

8. **冷链与保鲜能力**
- 易腐水果有冷藏车或泡沫箱+冰袋配送。
- 夏季能控制到货温度，冬季防冻。
- 配送时间可配合你小区到货和分拣时段。

9. **退换货与应急响应**
- 缺货、延迟、品质异常时有专人对接。
- 能当天响应售后，不拖到下一团。
- 有备用供应商或备货仓，节假日不断供。

10. **合规与票据**
- 能提供营业执照、食品经营/流通相关资质。
- 可开票或提供进货凭证，方便你记账和售后追溯。

**谈判时最该盯住的三件事：**  
① 起送量和配送频次能不能匹配你的团购单量；② 坏果包赔是否干脆；③ 团购价是否给你留出20%—30%左右的毛利空间。  
建议先小批量试合作2—3个单品，跑一轮“截单—配送—分拣—售后”，再决定是否长期合作。
