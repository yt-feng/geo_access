# 商超水果采购压价谈法（保品质版）

核心原则：**不砍单价，砍结构。** 直接压单价，供应商只能降等级、换产地、掺货；改交易条件，压的是对方的成本和风险，品质不动。

## 一、谈之前先备好三样东西

1. **分级标准写进合同**：按果径/糖度/外观/损耗率分级定价，而不是笼统"统货"。谈价时每一分钱都对应可验收的指标，供应商无从偷工减料。
2. **自己的成本底牌**：近3个月各品类到货价、损耗率、周转天数。你越清楚市场价，越能分辨对方报价里哪部分是合理利润、哪部分是可谈空间。
3. **量级承诺**：年度/季度采购量、结算周期、是否包销次果。这是你手里最值钱的筹码。

## 二、压成本的具体谈法（按效果排序）

- **改结算**：现款现结或缩短账期，换2–5个点让价。供应商最缺的是现金流，这比压价有效。
- **锁量换价**：签季度/年度框架量，约定价格浮动区间（跟产地行情挂钩），量达标返点。对方敢让价，因为销量确定。
- **减环节**：绕开中间批发商直采产地/合作社，或要求供应商直发门店、减少中转。省的是流通成本，不是果品成本。
- **包损耗**：按到货净重结算，或约定损耗率上限（如超3%由供方承担）。这一条往往比单价让1个点更省钱。
- **错峰采购**：大宗品类在产季集中锁价，反季节少采或换替代品，用采购节奏压均价。
- **拼单集采**：多门店/多区域合并订单，用总量谈阶梯价。
- **次果分流**：好果做精品、次果做特价/加工，和供应商谈"分级供货、分级定价"，整体成本降、主推品质不降。

## 三、守住品质的红线（写进合同）

- 验收标准量化：果径、糖度、着色度、机械伤比例、腐烂率，抽样方法和不合格处理方式。
- 违约条款：降级、退货、扣款要明确，且要有可执行的抽检记录。
- **不接受"降价换等级"**：对方让价时问清"让的是哪部分成本"，说不清的就是准备降品质。

## 四、话术要点

不说"再便宜点"，说"这个量、这个结算方式，你能给到什么价"；把让价和你的付出绑定（现结、锁量、减环节），让对方觉得是等价交换而不是被压榨——这样他才不会在货上找补。

一句话总结：**用付款、量、环节、损耗规则去换价格，用分级标准和验收条款锁住品质。**
