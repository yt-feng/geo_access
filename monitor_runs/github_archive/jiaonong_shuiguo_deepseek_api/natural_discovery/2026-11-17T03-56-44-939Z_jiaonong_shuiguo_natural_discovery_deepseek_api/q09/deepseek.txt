旺季怕断货，和供应商谈合作时，核心是先把“能不能稳定供、断了我怎么办、价格怎么锁”问清楚。建议按下面几组问题提前问，并尽量写进书面约定。

**一、供货能力**
1. 旺季你每天/每周能稳定给我供多少货？最低和最高供应量分别是多少？
2. 哪些品类旺季容易缺？缺货时你会提前多久通知我？
3. 你有几个产地/仓库/备用渠道？主供地受灾或物流中断时，替代方案是什么？
4. 供货是固定配额还是先到先得？老客户和我的优先级怎么排？

**二、品质与规格**
5. 果径、甜度、成熟度、产地、包装规格按什么标准验收？
6. 到货坏果率超过多少算不合格？怎么补货、换货或扣款？
7. 旺季会不会用次级果混装？出现品质波动怎么提前告知？

**三、价格与锁价**
8. 旺季价格怎么定？是随行就市还是可以锁价？锁价期限多长？
9. 涨价前提前几天通知？我已下单未发货的货按哪个价格算？
10. 量大有没有阶梯价？长期合作有没有返点或运费补贴？

**四、订单与配送**
11. 每天几点前下单、几点到货？临时加单最晚什么时候提？
12. 配送范围、运费、起送量怎么算？旺季会不会延迟？
13. 缺货或延迟到货，怎么补偿？有没有违约金或优先补货承诺？

**五、结算与风险**
14. 结算是现结、周结还是月结？押金、账期怎么定？
15. 断货导致我门店缺品，你有没有备用供应商推荐或调货支持？
16. 合作终止或旺季结束后，库存尾货怎么处理？

**谈的时候重点争取三件事：**
- **书面锁量**：旺季核心单品约定最低日供量。
- **断货预警**：缺货提前24—48小时通知，并给替代方案。
- **品质兜底**：坏果率超标包退换，明确补货时限。

最后提醒：不要只谈价格，先确认对方旺季真实供货能力，最好要求提供近期供货记录或老客户参考，并先小批量试单再放量。
