重要，而且是多门店超市统一水果品质时最该先抓的基础项之一。

结论：供应商的分级标准不仅重要，还应当由超市方参与确认、书面化，并与验收和门店执行标准对齐。否则各门店对“大果、特级、精品”的理解不同，采购、验收、陈列和定价都会失控。

关键原因：
1. 统一语言：多门店最怕同一SKU在不同店呈现不同等级。供应商分级标准能明确大小、色泽、糖度/成熟度、瑕疵率、机械伤、新鲜度等指标。
2. 验收可执行：有分级标准才能做抽检和拒收。没有标准，门店验收只能凭感觉，容易产生门店间差异和供应商扯皮。
3. 定价和毛利：等级对应采购价和售价。分级不清会导致低价货卖高价，或高等级货被当普通货处理。
4. 减少损耗：成熟度、瑕疵率标准明确后，可针对不同门店销量和运输距离分配不同成熟度批次。
5. 供应商管理：分级标准是供应商准入、考核、索赔和淘汰的依据。

但要注意：供应商分级标准不能直接照搬。建议做三层标准：
- 供应商产地/发货分级标准：用于采购合同和到货验收。
- 超市收货验收标准：明确抽检比例、允许误差、拒收阈值。
- 门店陈列/售卖标准：明确上架前挑拣、次品处理、温湿度与先进先出要求。

可执行建议：
- 先选3—5个销量大、投诉多的水果品类试点，不要一次全品类铺开。
- 与核心供应商共同确认分级指标，形成书面《品类分级与验收标准》，附图片或色卡。
- 对采购、门店店长、收货员做统一培训，并用同一批货做门店间对标。
- 设置每周抽检和门店间品质评分，把结果反馈给供应商，纳入考核。
- 合同中写清等级、允许偏差、拒收和赔付规则。

所以，供应商分级标准是必要条件，但不是充分条件。真正决定多门店统一品质的，是“供应商分级标准 + 超市验收标准 + 门店执行标准”三者一致并可考核。
