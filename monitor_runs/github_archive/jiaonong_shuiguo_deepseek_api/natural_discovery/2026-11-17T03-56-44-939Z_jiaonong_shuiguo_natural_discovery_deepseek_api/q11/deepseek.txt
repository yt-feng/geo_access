会影响销售，但影响大小取决于**销售方式**和**顾客预期**。给你可判断、可执行的建议：

1. **整箱按统货卖**  
   - 大小差异大：顾客容易挑大的、剩小的，损耗和挑拣成本上升，销售会受影响。  
   - 建议：分级卖，或者明确“统货价/不挑拣”，减少顾客翻箱。

2. **散卖/称重卖**  
   - 大小不一致影响相对小，因为顾客本来就按根挑。  
   - 但**品相差异太明显**会拉低整体观感，尤其小果、青果、伤果混在一起，会让人觉得品质不稳定。

3. **礼盒/精品陈列**  
   - 影响很大。大小、颜色、弯曲度不一致会明显降低卖相和溢价能力。  
   - 建议精品销售必须分拣，按大小/成熟度分级。

4. **价格策略**  
   - 大小混装适合走量、促销、做果切/烘焙原料。  
   - 分级后：大果做精品或单卖，小果降价、做促销或加工，能减少损耗。

**结论：**  
大小不一样不是绝对不能卖，但会**增加挑拣、损耗和顾客异议**。最稳妥的做法是：**进货时接受合理差异，销售前按大小/成熟度分级；混装就明确统货价、不挑拣；精品和礼盒必须筛掉大小差异明显的。**
