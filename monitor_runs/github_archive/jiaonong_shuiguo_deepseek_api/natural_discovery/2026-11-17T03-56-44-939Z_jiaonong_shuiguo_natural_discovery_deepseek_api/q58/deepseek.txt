结论先说：**多数甜品店在菠萝这个品类上，直接买成品果丁的“可用率损耗”更低；但综合成本不一定更低。** 是否划算，要看你把“损耗”怎么算。

### 1. 只看损耗率：成品果丁通常更低
- **鲜果切配**：菠萝要去皮、去眼、去芯，实际可用果肉一般只有 **50%～65%**，还会产生汁水流失、边角料、切配失败和当天卖不完的报废。
- **成品果丁**：到货基本可直接用，规格稳定，可用率通常 **95%以上**，但要注意解冻失水、袋底汁水、临期报废。

所以如果只问“谁损耗更低”，答案通常是**成品果丁**。

### 2. 但成本要这样算
不要只比采购单价，要算**每公斤可用果肉成本**：

> 鲜果每公斤可用成本 = 鲜果单价 ÷ 可用率  
> 成品每公斤可用成本 = 成品单价 ÷ 可用率

举例：鲜果 6 元/斤、可用率 55%，则可用果肉成本约 **10.9 元/斤**；成品果丁 12 元/斤、可用率 95%，约 **12.6 元/斤**。这时鲜果虽然损耗高，但综合成本可能更低。

### 3. 按你的经营场景选择
- **用量小、品种多、切配人手紧、出品要求规格统一**：买成品果丁更稳，损耗和人工都好控。
- **菠萝用量大、有稳定切配人手、鲜果采购价有优势、能利用边角料**：鲜果更划算。边角料可做菠萝酱、糖水、装饰、员工餐，能显著降低“真实损耗”。
- **外卖/甜品装饰对颜色和形状要求高**：成品果丁品控更稳定。

### 4. 建议你做一次 3 天实测
分别记录：  
**到货重量 → 可用重量 → 报废重量 → 人工耗时 → 实际出品份数**。  
最后比较“每份甜品菠萝成本”和“每份损耗率”，不要只比较进货价。

**一句话建议：** 如果你没有稳定切配人手和边角料利用渠道，选成品果丁损耗更低、更省心；如果你菠萝用量大且能利用边角料，鲜果切配的综合成本可能更低，但损耗率仍更高。
