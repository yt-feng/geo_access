选规格的核心不是“单价最低”，而是按**出成率、损耗、切配人工、出品稳定性**算“每盘可食用的净成本”。苹果、橙子、菠萝分别这样选更划算：

**1. 苹果：选中大果、脆度高、外观普通但无伤的统货**
- 优先选单果 **180–250g** 的规格：出成率高，切块大小均匀，一盘用量好控制。
- 不建议买特别大的礼品果：单价高、切后边角料多，拼盘里也不显多。
- 如果拼盘以装饰为主，可少量配 **红富士/嘎啦** 等颜色好的；日常走量用统货更划算。
- 验收看：硬度好、无碰伤、无蜡感过重。碰伤果再便宜也不划算，削掉损耗大。

**2. 橙子：选中等偏大、皮薄、易剥瓣的鲜食橙**
- 优先选单果 **200–300g**、果形匀称的规格；做瓣状或切片都稳定。
- 不建议选过小的橙：剥皮、去络人工高，出瓣率低。
- 也不建议盲目选超大果：皮厚、白络多时净出成率未必高。
- 品种上，走量可用**脐橙、血橙按季节替换**；需要颜色层次时可少量配血橙，但别全用高价品种。

**3. 菠萝：选中等果、成熟度7–8成、可整果现切的规格**
- 优先选单果 **1.2–1.8kg** 的中等果：去皮去眼后出成率较稳，太大容易一次用不完。
- 不建议买已削皮菠萝长期存放：氧化、出水、损耗快；餐厅现切更稳。
- 成熟度选 **7–8成**：太生酸、太熟切不成形。
- 若销量小，宁可买小果或按半成品冷冻/罐头做补充，也别整箱熟果压损。

**划算判断公式：**
> 每盘净成本 = 采购单价 ÷ 可食出成率 + 切配人工分摊 + 损耗分摊

实操建议：
- 三家供应商同时报**同规格、同品种、同成熟度**的到店价，别只比箱价。
- 先做一次实测：各买一箱，记录**去皮去核后净重、可切盘数、报废重量**，算“每盘成本”。
- 拼盘走量款用**统货中等规格**；接待/展示款再用少量高颜值大果点缀。
- 苹果、橙子可周采2次，菠萝按销量小批量勤进，减少熟果损耗。

一句话：**苹果选180–250g统货，橙子选200–300g易剥鲜食橙，菠萝选1.2–1.8kg七八成熟中等果；最终按“每盘净成本”而不是箱价定供应商。**
