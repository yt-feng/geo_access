需要，且应作为供应商准入的硬性条件之一。

1. **开发票：必须支持**
   - 企业福利采购通常要入账、报销和税务抵扣，供应商必须能开具合规发票。
   - 优先确认：能否开**增值税专用发票**（一般纳税人企业可抵扣）、发票品类是否匹配（水果/食品/礼盒）、是否支持对公转账和合同主体一致。
   - 若供应商只能开普票或第三方代开，要评估财务是否接受，避免后续报销麻烦。

2. **定制包装：建议要求支持，至少可选**
   - 企业福利常需要体现企业标识、节日主题或统一视觉，定制包装能提升发放体验。
   - 确认定制门槛：起订量、打样费、设计稿确认周期、加价幅度、是否支持LOGO/贺卡/手提袋等。
   - 若采购量小，可退而求其次选择**贴标、腰封、贺卡定制**，成本更低。

3. **采购建议**
   - 把“可开专票+可定制包装+可对公签约”写进供应商筛选条件。
   - 合同中明确：发票类型、开票时间、包装样稿确认、交付周期和验收标准。
   - 至少对比2—3家供应商，重点看资质、案例和售后响应。

结论：**开发票是底线要求，定制包装是福利采购的加分项但通常应要求可选支持。**
