做餐饮客户（尤其是茶饮、甜品、烘焙、快餐/食堂）时，菠萝和香蕉的规格要按**用途**定，不要只按“批发市场常见规格”备货。建议先小批量试供，再按客户菜单稳定规格。

**菠萝：主推3档规格**
1. **鲜切/茶饮/甜品用：单果1.0–1.5kg，果形端正，7–8成熟**  
   - 适合门店现切、做菠萝块、菠萝茶饮。  
   - 要求：无黑心、无裂口、果眼浅，到货可放1–2天达到适熟。
2. **餐饮后厨/炒菜/咕咾肉用：单果1.5–2.0kg，7成熟左右**  
   - 出肉率高，适合后厨切块、炒制、做酱。  
   - 可接受外观略粗皮，但必须无腐烂、无黑心。
3. **果汁/果酱/中央厨房用：单果1.5kg以上或散装统货，成熟度8–9成**  
   - 适合集中榨汁、熬酱，价格优先。  
   - 必须明确“当日/次日必须用完”，避免过熟发酵。

**香蕉：主推3档规格**
1. **茶饮/甜品现切用：单根120–150g，条长适中，6–7成熟到货**  
   - 到店后1–2天转黄，适合做香蕉块、香蕉泥、甜品装饰。  
   - 要求：无机械伤、无严重黑斑，整把整齐。
2. **烘焙/果泥/中央厨房用：单根150–200g，7成熟到货，允许外观轻微瑕疵**  
   - 出肉率高，适合做香蕉泥、蛋糕、果酱。  
   - 可接受表皮少量花皮，但不能软烂、破皮。
3. **快餐/食堂/果切档用：单根100–130g，6.5–7成熟，整箱规格统一**  
   - 便于按根计价和快速分发。  
   - 要求：成熟度一致，避免一箱里有的青有的软。

**备货建议**
- 首批不要全押大果。餐饮客户更看重**稳定出成率和成熟度可控**，不是单果越大越好。
- 菠萝建议按“鲜切用”“后厨用”“加工用”分筐标识；香蕉按“6–7成熟”“7–8成熟”分箱，并标注到货日期。
- 给餐饮客户报价时，最好同时报：**规格、单果重、成熟度、允许瑕疵、起批量、配送频次**。
- 先找2–3家茶饮/甜品/食堂试供，记录对方每天用量和损耗，再决定主推规格。

简单说：**菠萝主推1.0–1.5kg鲜切档和1.5–2.0kg后厨档；香蕉主推120–150g茶饮甜品档和150–200g加工档。** 成熟度比大小更关键。
