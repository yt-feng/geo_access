# 生鲜水果坏果投诉的责任划分

## 核心原则：看"坏在哪一步"

责任划分的关键是**确定腐烂发生的时间点和原因**，而不是简单按"谁弱谁有理"。

---

## 一、常见责任归属

### 1. 商家/平台担责（占多数）
- **发货前就有坏果**：品控不严、混入次果、未预冷/未分级
- **包装不当**：无缓冲、无冰袋、挤压伤，运输中捂坏
- **冷链断裂**：应冷链却常温发，或到达后未及时配送
- **承诺不符**：宣传"现摘现发"实为积压货
- **未提示风险**：如未告知"熟果易损""可食率"等

→ 这类基本由商家承担，通常按坏果比例赔付或补发。

### 2. 物流方担责
- 运输中野蛮装卸、长时间滞留、冷链失效
- 注意：**消费者通常只对商家主张权利**，商家赔偿后再向物流追偿。消费者无需自己找快递扯皮。

### 3. 消费者担责
- 未按提示及时取件/签收，导致闷坏（如到柜后隔几天才取）
- 收货后未及时冷藏、自行处置不当
- **无法举证**且明显超过合理售后时效

### 4. 风险分担（需具体判断）
- 自然损耗 vs 质量问题：轻微表皮瑕疵、个别软化属正常，通常有"坏果包赔比例"约定
- 签收时外观完好、开箱才坏：需看是否在保鲜期内、是否按说明储存

---

## 二、实操判断流程

1. **看时效**：到货多久投诉？是否超过平台售后期限（常见24–48小时）
2. **看证据**：开箱视频/照片、坏果与包装同框、称重记录
3. **看比例**：坏果占比多少？是否达到"包赔"门槛
4. **看原因**：是捂坏（包装/冷链）、压坏（物流）、还是本身次果（品控）
5. **看约定**：商品页/售后规则里对坏果赔付的承诺

---

## 三、给双方的建议

**消费者**：到货第一时间开箱拍视频，保留包装和坏果，48小时内申请售后，按坏果比例索赔或补发；不要自行丢弃证据。

**商家**：明确坏果包赔规则（比例、时效、举证要求），做好分级包装和冷链，保留发货质检记录，便于区分自身责任与物流责任。

**一句话结论**：**发货前和运输环节的问题由商家（及物流）承担；签收后因消费者保管不当造成的由消费者承担；界限不清时以证据和售后约定为准，商家对消费者负第一责任。**
