优先谈**账期**，但要先把“账期”谈成一套可执行条款，而不是只谈天数。原因：

1. **账期直接决定现金流和议价空间**  
   长期水果供应里，配送和售后通常是“出问题再解决”，账期是每天都占用资金。水果损耗高、价格波动大，账期一松，你的现金压力会持续放大。

2. **账期最容易量化，也最能检验供应商实力**  
   愿意给合理账期，通常说明对方资金和供货稳定；只肯现结或短账期，你要重点看它是否靠低价抢单、履约不稳。

3. **配送和售后可以后置用规则补齐**  
   配送频次、到货时限、温控、验收标准，售后赔付比例、补货时限，这些可以写成标准条款，谈判难度通常低于账期。但如果没有账期约束，配送和售后出问题时你缺少制衡手段。

建议谈判顺序：

**第一优先：账期 + 结算条件**
- 明确账期起算点：到货验收合格后起算，不是发货后起算。
- 明确对账周期和付款日，避免“月结30天”变成拖60天。
- 争取阶梯账期：首月现结或短账期，稳定合作2—3个月后延长。
- 约定质量争议部分的暂扣或抵扣机制。

**第二优先：售后与损耗责任**
- 到货验收标准：规格、成熟度、破损率、腐烂率。
- 超出标准的赔付、补货、退货时限。
- 价格波动时的调价机制，避免“售后赔一点、单价涨回来”。

**第三优先：配送**
- 配送频次、截单时间、到货时间窗。
- 冷链和温控要求，迟到或断供的违约责任。
- 旺季和节假日的保供方案。

一句话结论：**先谈账期，把现金流和结算规则锁住；再用售后条款兜住质量风险；配送作为履约保障补充谈。** 如果供应商账期完全不让，至少要求“验收合格后付款+质量争议抵扣”，不要接受发货即起算。
