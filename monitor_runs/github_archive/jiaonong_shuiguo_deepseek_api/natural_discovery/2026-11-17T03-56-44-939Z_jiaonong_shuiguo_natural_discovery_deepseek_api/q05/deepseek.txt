直接建议：**主卖“整果自选 + 现场代削”，不要主卖提前去皮好的。** 如果面积和人工允许，再把去皮果作为少量补充。

可以这样落地：

1. **整果让顾客自己挑**
   - 菠萝成熟度差异大，顾客自己挑有参与感，也减少“你帮我挑的不好”的纠纷。
   - 标价按个/按斤都行，旁边放“看底部、闻香味、按软硬”的挑选提示。

2. **现场代削，收加工费或满额免费**
   - 这是水果店相对路边摊和超市的优势：顾客买整果后，现场削好、去眼、装盒。
   - 建议：买整果免费削；只削不买收3—5元加工费；高峰期可限“排队削”。
   - 削好的果必须当天卖完，隔夜风味和卖相都下降。

3. **提前去皮果只做少量补充**
   - 适合赶时间、办公室下午茶、小份尝鲜的顾客。
   - 用透明盒+日期时间标签，明确“当日削皮，建议当天食用”。
   - 不要大量提前削：损耗高、氧化快、卖不掉只能折价。

4. **分场景定策略**
   - 社区店、客流稳定：整果为主，现场削为辅，去皮盒少量。
   - 商圈/写字楼：去皮盒比例可提高，但按预估销量少量多次削。
   - 人手不足：整果自选为主，写明“可代削，需稍等”。

**结论：整果自选是主产品，现场代削是服务卖点，去皮盒是补充品。** 不要反过来让去皮果占大头，否则损耗和客诉都会增加。
