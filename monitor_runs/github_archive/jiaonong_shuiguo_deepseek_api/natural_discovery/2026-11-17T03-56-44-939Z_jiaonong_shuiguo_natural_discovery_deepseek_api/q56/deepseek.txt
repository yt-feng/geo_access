茶饮店控制水果供应商食品安全风险，建议把“准入证明”和“批次随货证明”分开管。核心不是只收一张营业执照，而是能证明：主体合法、水果来源可追、农残/重金属等风险有控制、运输储存符合要求、出事能召回。

### 1. 供应商准入阶段：首次合作必须收集
建议要求水果供应商提供以下材料，并留存盖章复印件或电子版：

1. **营业执照**
   - 确认经营范围包含水果种植、销售、农产品批发、食品销售等相应内容。
   - 核对名称、地址、统一社会信用代码与合同、发票一致。

2. **法定代表人/负责人身份证明及授权书**
   - 非法人本人对接的，要有授权委托书和对接人身份证明。

3. **食品经营许可证或食品生产许可证（如适用）**
   - 仅销售食用农产品通常不一定需要食品经营许可证，但若供应商从事切果、鲜切水果、预包装水果制品、果汁等加工，应要求相应食品生产/经营许可。
   - 不要机械要求“所有水果供应商都必须有食品经营许可证”，要看其实际经营形态。

4. **食用农产品合格证或产地证明**
   - 优先索取《食用农产品合格证》或承诺达标合格证。
   - 也可接受产地证明、购销凭证、种植基地证明等能实现来源追溯的材料。
   - 对无法提供合格证的小散户，应提高抽检频次并保留收购凭证。

5. **产地/基地信息**
   - 品种、产地、种植户或合作社、采收时间、联系人。
   - 若是进口水果，要有入境货物检验检疫证明、报关单等。

6. **检测报告**
   - 首次合作提供近期的第三方检测报告，项目至少覆盖农药残留；根据品种关注重金属、真菌毒素等。
   - 检测报告要与品种、产地、供应商对应，不能拿一份报告覆盖所有水果。
   - 对高风险品种（如直接带皮入口、鲜切使用、以往抽检不合格品种）提高检测频次。

7. **质量与食品安全承诺书/供货合同**
   - 明确农残、重金属、感官、新鲜度、腐烂率、运输温度、到货时限、退换货和召回责任。
   - 明确不得使用禁用农药、不得违规催熟、不得混入霉烂果。

8. **运输与贮存能力证明**
   - 冷链水果需提供冷藏运输能力说明、车辆温度记录或温控设备证明。
   - 常温水果也要说明防雨、防潮、防污染、防交叉污染措施。

9. **从业人员与卫生管理（如供应商涉及分拣、鲜切）**
   - 健康证明、卫生管理制度、清洗消毒记录等。

### 2. 每批次到货：随货必须核对
不要只做“一次准入”，每批到货要有随货材料：

1. **送货单/销售凭证**：品名、产地、数量、采收或生产日期、供应商盖章或签字。
2. **食用农产品合格证/产地证明**：批次与送货单对应。
3. **检测合格证明或供应商自检记录**：高风险品种每批或高频抽检。
4. **冷链温度记录**：需冷链的品种提供运输温度记录。
5. **感官验收记录**：颜色、气味、腐烂、霉变、虫害、异物、包装污染等。
6. **快速检测记录**：茶饮店有条件可对农残做快检，保留记录和留样。

### 3. 茶饮店内部要配套做的动作
- 建立**合格供应商名录**，每家供应商一档。
- 索证索票和进货台账保存期限不少于产品保质期满后6个月；没有明确保质期的，建议不少于2年，具体按当地监管要求执行。
- 每批水果可追溯：供应商—产地—批次—到货日期—使用日期。
- 发现农残超标、霉变、疑似催熟或来源不明，立即停用、封存、通知供应商，必要时召回并报告监管部門。
- 鲜切水果要额外控制：专用清洗消毒区、刀具砧板分区、人员手部卫生、冷藏时限和当日使用管理。

### 4. 最简可执行清单
首次合作收：**营业执照、许可证明（如适用）、食用农产品合格证/产地证明、近期检测报告、供货合同/承诺书、运输温控说明**。  
每批到货收：**送货单、合格证/产地证明、检测或快检记录、温度记录、验收记录**。

判断标准：如果一批水果出问题，你能在10分钟内说清楚“从哪家供应商、哪个产地、哪一批次来的，有没有合格证明和检测记录，卖给了哪些门店或用于哪些产品”，这套证明体系才算基本合格。
