建议**以整果为主，切果做补充**，不要只选一种。判断逻辑是：整果负责走量和毛利，切果负责提升客单、降低食用门槛和处理尾货。

**更适合卖整果的情况**
- 菠萝当季、到货成熟度可控，整果外观好、叶冠新鲜。
- 门店有试吃、削皮服务或明显堆头，能解决“不会削、嫌麻烦”的问题。
- 客群以家庭采购为主，对价格敏感，整果按个卖更容易冲量。
- 整果损耗主要来自压伤和过熟，可通过分级销售处理：好果整卖，熟果切盒，次果做特价或加工。

**更适合切好的情况**
- 门店在写字楼、社区年轻客群、即食场景强，消费者愿意为方便付溢价。
- 整果成熟度偏高、外观有瑕疵但果肉正常，切果能减少报损。
- 有冷藏陈列和当天售罄能力，能做“现切+短保”管理。
- 切果能带动小份购买，适合下午茶、水果拼盘、酸奶搭配等场景。

**实操建议**
1. **整果为主SKU**：按大小分2档，标价清晰，提供免费或低价削皮服务。
2. **切果做增量**：只做当天现切、冷藏陈列、明确当日食用；可做小盒和家庭盒两档。
3. **用整果做引流，切果做利润**：整果价格敏感，切果体现便利溢价，但切果加价率不要高到顾客直接买整果。
4. **动态调整比例**：先按整果70%、切果30%试销1—2周，看销量、损耗、客单和复购再调。若切果损耗高，就缩量改为主推整果+现场削皮。
5. **控制切果风险**：切果保质期短，必须冷链、当日清；不要用不新鲜整果“藏瑕疵”，否则影响复购。

结论：**多数商超更稳的组合是“整果为主、切果为辅、现场削皮服务兜底”**；只有即食需求特别强、冷链和日清能力好的门店，才适合把切果占比明显提高。
