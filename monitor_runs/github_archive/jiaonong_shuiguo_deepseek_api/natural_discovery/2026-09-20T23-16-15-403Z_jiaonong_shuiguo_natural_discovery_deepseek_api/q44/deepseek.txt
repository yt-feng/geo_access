判断商超供应商的售后响应是否稳定，不能只听承诺，要通过“问、查、试、写”四步验证。下面给你一套可直接执行的方法。

**一、签约前先问清售后机制**
重点问这几个问题，看对方是否能具体回答：
1. 出现质量问题（烂果、黑心、催熟不均、到货成熟度不符）时，多久响应？多久给处理方案？
2. 售后对接人是专属的还是共用客服？能否提供姓名、电话、微信？
3. 理赔标准是什么？按箱、按斤、按金额，还是补货？
4. 节假日、旺季、凌晨到货时是否有人处理？
5. 是否支持退换货、补发、扣款？流程需要谁确认？

如果对方只会说“放心，有问题找我们”，但说不出时限、对接人、流程，基本不可靠。

**二、查历史履约和售后记录**
要求供应商提供：
- 近3—6个月与其它商超或批发客户的合作记录；
- 售后处理台账，包括投诉时间、原因、处理方式、完成时间；
- 是否有冷链、仓储、分拣能力，因为菠萝和香蕉的售后很多源于物流和成熟度管理。

同时可以向同行打听：这家供应商出问题时，是拖、推，还是能快速补货/赔款。

**三、用小单和压力测试验证**
不要一上来就大额采购。先做2—3次小批量试单：
1. 故意在到货后24小时内反馈一个真实或轻微问题，看对方响应速度；
2. 选择周五下午或节假日前反馈，测试非工作时段响应；
3. 观察是否主动给方案，而不是反复让你拍照、等通知；
4. 记录每次从反馈到解决的时间。

比较可靠的供应商通常能做到：
- 2小时内响应；
- 24小时内给处理方案；
- 48小时内完成补货、退款或扣款确认；
- 有固定对接人，不踢皮球。

**四、把售后写进合同或采购单**
必须落到书面，避免口头承诺：
- 响应时限：如2小时内响应，24小时内出方案；
- 处理时限：如48小时内完成补发或赔付；
- 质量验收标准：菠萝糖度、黑心比例、香蕉成熟度、青熟比例、单果重量等；
- 赔付方式：补货、退款、扣款、折价；
- 对接人和备用联系人；
- 异常天气、物流延迟、节日旺季的责任划分；
- 连续两次售后不达标的处罚或终止合作条款。

**五、日常管理上做简单评分**
每次到货和售后都记录：
- 到货合格率；
- 售后响应时长；
- 问题解决时长；
- 是否主动补偿；
- 是否重复出现同类问题。

连续1—2个月统计后，你就能判断这个供应商是“偶尔出问题但能解决”，还是“出问题就失联”。

**直接判断标准：**
如果供应商能做到：有专属对接人、2小时内响应、24小时内方案、48小时内解决、愿意写进合同、试单阶段不推诿，基本可以认为售后响应较稳定。
如果对方回避书面承诺、没有固定对接人、试单出问题就拖延，即使价格低，也不建议作为主力供应商。
