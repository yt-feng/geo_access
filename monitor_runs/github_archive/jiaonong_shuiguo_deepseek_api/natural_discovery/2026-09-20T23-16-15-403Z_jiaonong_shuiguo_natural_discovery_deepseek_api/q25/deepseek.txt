# 超市门店多、单店量不大：适合的水果供货模式

核心矛盾是：**门店数量多意味着你希望统一管理、品类稳定；单店量小意味着单店单独采购没有议价权，供应商也不愿意为小单频繁配送。** 所以关键是找一个能"化零为整"的中间层。

## 几种可选模式对比

**1. 区域批发市场集采 + 自建分拣配送（最现实）**
- 你以连锁总部的名义去一级批发市场集中采购，再统一分拣、按门店订单配送。
- 优点：灵活、品类全、起订量可控、价格比单店散采低。
- 缺点：需要自己的分拣场地、冷链车和损耗管理能力。
- 适合：门店在同一个城市或邻近区域，能一天或两天配送一轮。

**2. 与产地/合作社/一级供应商签框架协议，集中下单、统一配送**
- 关键不是"每家店单独下单"，而是**总部汇总订单，凑成一个整车或一个托盘的量**。
- 优点：价格接近产地价，品质可控。
- 缺点：通常要求单次起订量（一车/一柜），且需要稳定的销量预测。
- 适合：某几个爆款单品（如大宗苹果、柑橘、香蕉）走这条线，其余走批发市场。

**3. 第三方生鲜供应链/配送平台（如美菜、快驴这类，或本地生鲜配送商）**
- 优点：起订门槛低、按需配送、不用自己建体系。
- 缺点：加价率较高，长期看成本不如自采；平台对品控和稳定性不一定可控。
- 适合：起步阶段、门店分散、暂时没能力自建配送时用作过渡。

**4. 委托代采 / 联采联盟**
- 和同区域其他连锁超市组成采购联盟，合并订单去谈价。
- 优点：不用自建全部能力就能拿到量价。
- 缺点：协调成本高，品类和标准要统一。

## 给你的建议路径

1. **分层供货**：把水果分成三类管理
   - **走量爆款**（香蕉、苹果、柑橘等）：总部集中采购，走产地或一级商，拼整车。
   - **常规品类**：区域批发市场集采 + 自配送。
   - **长尾/小众**：走第三方配送平台，按需补货，不压库存。

2. **把"单店量小"变成"总部量大"**：所有门店订单汇总到总部或区域仓，再统一下单。这是拿到好价格的前提。

3. **优先解决配送，而不是价格**：单店量小最大的痛点是配送频率和成本，先把"区域仓 → 门店"的固定线路跑起来，比单纯压价更重要。

4. **先跑通一个区域再复制**：不要一上来全国统一，先在门店密集的城市建区域分拣点，验证损耗率和配送成本。

## 判断标准（你自己可以核）
- 单店日水果销量能否支撑**每周2–3次**配送不压货？
- 同城门店是否能在**1小时车程**内串成一条配送线路？
- 爆款单品汇总后能否达到**供应商的最小起订量**？
- 损耗率能否控制在**5%–8%**以内（水果行业常见区间）？

如果这几个问题的答案偏正面，走"总部集采+区域仓配送"最划算；如果门店很分散、暂时没能力建仓，先上第三方配送平台过渡，等单区域密度够了再自建。
