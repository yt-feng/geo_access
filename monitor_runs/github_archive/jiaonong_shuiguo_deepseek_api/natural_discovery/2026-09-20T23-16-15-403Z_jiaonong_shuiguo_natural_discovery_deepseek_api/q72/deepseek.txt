# 水果供货账期与额度谈判思路

水果行业有特殊性：**高损耗、价格波动大、现金流紧**，所以账期和额度不能照搬其他品类。核心原则是——**用可控的风险换稳定的量**。

## 一、先想清楚：你能承受的底线

谈判前先算三笔账：

1. **现金流底线**：你每月能垫多少货款而不影响正常进货？这是额度上限。
2. **坏账容忍度**：最多能接受多少应收挂账？水果一旦滞销，客户可能拖款甚至跑路。
3. **账期成本**：30天账期 = 你免费借钱给对方。按年化8%算，10万货款压30天≈650元成本，要能覆盖在差价里。

## 二、额度怎么谈（分层给，别一次给满）

| 阶段 | 额度策略 | 目的 |
|---|---|---|
| 合作初期 | 现款现货，或**小额试单**（如单次≤5000元） | 验人品、验走货速度 |
| 稳定1-2月 | 给**周结额度**，如单周累计≤2万 | 观察回款习惯 |
| 稳定3-6月 | 给**月结额度**，如≤5万 | 绑定为主力供应商 |
| 大客户 | 额度=**月均采购额的0.5-1倍**，封顶 | 既支持对方周转，又不失控 |

**关键动作**：额度写进书面协议，明确“超额度需现款”或“超额部分预付”。

## 三、账期怎么谈（用条件换条件）

不要白给账期，每一档账期都绑定一个交换条件：

- **给7天账期** → 要求对方最低月采购量
- **给15天账期** → 要求专供某几个品类，或价格上浮1-2%
- **给30天账期** → 要求预付款10-20%，或提供担保/押金
- **想再长** → 让对方用**承兑、房产/车辆抵押、第三方担保**来换

**话术示例**：
> “张总，30天账期我可以给，但咱们得绑个量。您月采购到X万，我给您月结；量不到，就按15天结。这样我也好跟上游交代。”

## 四、几个必须写进合同的保护条款

1. **对账周期**：每周/每月固定对账，避免扯皮。
2. **逾期条款**：逾期按日万分之几计息，或暂停供货。
3. **质量异议期**：水果易腐，约定“收货24-48小时内提出异议”，过期视为合格，防止对方事后拿烂果赖账。
4. **价格调整机制**：行情波动大时，账期内的价格怎么算要提前说清（一般按发货日价）。
5. **终止条款**：连续逾期X次，额度自动归零。

## 五、实操建议

- **先小后大**：别一上来就给月结5万，先周结跑2-3个月。
- **看回款不看承诺**：说得好没用，连续3次准时回款才升级额度。
- **分散风险**：大客户占比别超过你总出货的30-40%，否则被一个客户拖死。
- **留证据**：送货单、对账单、微信确认都要留，水果行业打官司全靠这些。

---

**一句话总结**：额度=月采购额的0.5-1倍封顶，账期用“量、价、担保”来换，先小后大、看回款升级，所有条件写进合同。
