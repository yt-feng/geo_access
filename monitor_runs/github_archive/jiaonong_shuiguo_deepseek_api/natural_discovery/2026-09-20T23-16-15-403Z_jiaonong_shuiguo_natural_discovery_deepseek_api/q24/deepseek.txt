先分清两个层面：**抽检是否合格，最终以监管或第三方检测报告为准，供应商提供的资料只能作为筛选和追责依据，不能代替你自己抽检。**

### 一、优先要的资料（核心）
1. **近期检测报告**
   - 农残检测报告，最好是 **CNAS/CMA 资质机构**出具。
   - 报告应覆盖你要采购的**具体水果品种**，不是只写“蔬菜水果”这种笼统类别。
   - 关注检测项目是否包含常见高风险农残，如有机磷、氨基甲酸酯、拟除虫菊酯等，以及是否按 **GB 2763** 判定。
   - 报告日期越近越好，通常建议 **3个月内**，叶菜、浆果类等高风险品类更短。

2. **产地证明/供货凭证**
   - 产地证明、基地证明、合作社或种植户信息。
   - 进货凭证、购销合同、发货单，能追溯批次。

3. **承诺达标合格证**
   - 国内很多农产品推行**食用农产品承诺达标合格证**，可要求供应商随货提供。
   - 它能证明供应商对农残等指标作出承诺，但不等于检测报告。

4. **供应商资质**
   - 营业执照、食品经营许可证或相关备案。
   - 如果是进口水果，还要报关单、入境货物检验检疫证明。

### 二、加分资料（用于降低风险）
- **基地备案/良好农业规范认证**：如 GAP、绿色食品、有机认证等。
- **批次追溯信息**：采摘日期、包装日期、批次号、运输温度记录。
- **自检记录**：供应商自己的快检或实验室检测记录。
- **农药使用记录**：种植环节用药清单、安全间隔期执行情况。
- **第三方抽检历史**：近半年监管抽检是否合格。

### 三、合同里要写清楚
- 供应商保证农残符合 **GB 2763**。
- 出现抽检不合格时，供应商承担退货、赔偿、监管处罚及商誉损失。
- 每批次随货提供合格证或检测报告，否则超市有权拒收。
- 超市可自行抽检，费用承担和不合格处理方式要约定。

### 四、实操建议
- **高风险水果重点管**：草莓、葡萄、柑橘、苹果、梨、桃、樱桃等，重点看对应报告。
- **不要只看一张报告**：要按品种、按批次对应。
- **报告要验真**：看机构资质、报告编号、样品名称、检测日期、判定依据。
- **自己快检**：超市可配农残快检设备，对每批或高频批次筛查，异常再送检。
- **留样**：每批留样到保质期后一段时间，便于复检和追责。

一句话：**要“近期、对应品种、有资质、按 GB 2763 判定”的农残检测报告，再配合合格证、产地证明、批次追溯和合同责任条款。**
