结论：**按斤结算最适合食堂水果采购的总成本管控，但管理成本最高；按箱适合标准化程度高的水果和追求效率的场景；按份基本只适合终端分发环节，不适合作为采购结算方式。**

具体判断要看你的管理目标：

**1. 按斤结算**
- 优点：单价透明，便于比价、核算成本、控制损耗，财务对账最清晰。
- 缺点：每次验收都要称重，人工耗时；水分损耗、筐重、去皮等问题容易扯皮。
- 适合：大宗、散装水果，如苹果、香蕉、橘子、西瓜等；食堂有专人验收、有电子秤。

**2. 按箱结算**
- 优点：验收快，流程简单，适合批量采购和长期供应商。
- 缺点：箱内品质不透明，容易“上面好下面差”；不同批次重量差异大，实际单价难比较。
- 适合：标准化包装水果，如整箱苹果、橙子、猕猴桃；供应商稳定、有退换货约定。
- 关键控制点：合同里必须写明**规格、净重、单果标准、坏果率上限、退换规则**，否则容易吃亏。

**3. 按份结算**
- 优点：分发方便，适合窗口售卖或按人配餐。
- 缺点：采购端无法控制真实成本，供应商容易在份量上做手脚；不适合作为采购结算。
- 适合：只用于**内部发放或售卖环节**，比如“每人一份水果”，采购仍应按斤或按箱结算。

**实操建议：**
- 主采购用**按斤结算**，尤其是叶菜类、散装水果；
- 对标准化水果可**按箱结算，但折算成斤价对比**；
- 内部发放可以**按份管理**，但采购合同不要按份签；
- 无论哪种方式，都要保留**验收记录、称重照片、坏果扣款标准**。

一句话：**采购端按斤或按箱，分发端按份；想管住成本，优先按斤。**
