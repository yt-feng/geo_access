结论：**多数情况下直接买成品果丁的综合损耗更低，尤其是中小型甜品店；但如果你的销量很大、后厨有稳定切配人力，鲜果自切的损耗也可以压到接近成品。关键不是“鲜果一定损耗高”，而是鲜果把损耗转移到了人工、时间和报废环节。**

下面按可判断的维度拆开说。

## 1. 鲜果切配的损耗在哪里

菠萝鲜果的典型损耗包括：

- **去皮、去眼、去芯**：菠萝出肉率通常在 **40%—60%** 左右，取决于品种、成熟度和刀具熟练度。  
  比如一个 1.5kg 的菠萝，切出 0.75kg 果肉不算差，但很多新手只能到 0.5—0.6kg。
- **修边和氧化报废**：切好后放久了发酸、出水、变色，当天用不完就可能报废。
- **人工损耗**：切配时间、清洗、案板刀具消毒，都是成本。
- **品质波动**：生一点酸、熟一点烂，影响出品稳定性。

所以鲜果自切的“损耗低”往往只在一种情况下成立：**当天能全部用完，且切配人员熟练。**

## 2. 成品果丁的损耗在哪里

成品果丁不是没有损耗，而是损耗形态不同：

- **采购规格损耗**：买的是“净果丁”，但可能带糖水、防腐液或多余水分，沥水后实际可用量会少。
- **冷链和保质期损耗**：开封后用不完会坏，尤其小批量门店。
- **品质不稳定**：不同批次大小、软硬、酸甜度可能不一致。
- **单价更高**：你付的是别人替你承担损耗后的价格。

但它的优势是：**到店即用，几乎不产生切配报废，人工占用极低。**

## 3. 怎么判断你的店该选哪个

可以用一个简单公式判断：

> **鲜果实际成本 = 鲜果采购价 ÷ 实际出肉率 + 人工切配成本 + 报废成本**  
> **成品实际成本 = 成品单价 ÷ 沥水后实际可用比例 + 开封报废成本**

如果算下来鲜果只比成品便宜一点点，但每天要花 20—30 分钟切、还经常剩，那就应该买成品。

### 建议优先买成品果丁的情况

- 日用量小，比如每天 1—3kg 以内
- 后厨人手紧，没人专门切水果
- 出品对大小、软硬一致性要求高
- 冷链条件一般，鲜果买多了容易坏
- 菜单里菠萝只是配角，不是主打

### 可以考虑鲜果自切的情况

- 日用量大且稳定，比如每天 5kg 以上
- 有熟练切配人员，出肉率能稳定在 50% 以上
- 当天能基本用完，冷藏管理到位
- 你对新鲜度、果香、无添加有明确卖点
- 能拿到稳定且便宜的产地鲜果

## 4. 实操建议

1. **先测 3 天**：买鲜果称重，切完再称净果丁，算出你的真实出肉率。
2. **再称成品**：开封后沥水称重，算实际可用比例。
3. **把人工算进去**：如果切 1kg 菠萝要 10 分钟，按工时折算，不要忽略。
4. **小批量店优先成品**：损耗更低、管理更简单，综合成本通常更稳。
5. **大批量店可鲜切**：但必须做到“当天切、当天用、冷藏密封、少量多次”。

一句话：**小用量、人手少、要求稳定，选成品果丁；大用量、有人切、能当天用完，鲜果自切才可能更划算。**
