小面积便利店做水果，核心不是“品类越全越好”，而是**少SKU、快周转、强关联、敢止损**。下面给你一套可直接执行的控制方法。

**一、先定原则：把水果当“引流+搭配”，不是当生鲜超市做**

小店面水果区通常只有1-2个货架或一个冷藏柜，目标应是：

- 服务即时消费：上班族、社区居民、过路客
- 搭配便利店主食：饭团、三明治、酸奶、沙拉、面包
- 只做高频、好处理、不易烂的品类

**二、品类控制：5-8个SKU足够，按角色分工**

建议把水果分成4类，每类只留1-2个：

1. **引流款**
   - 香蕉、苹果、橙子
   - 特点：认知高、价格透明、周转快
   - 作用：让顾客觉得“这家店有水果”

2. **即食款**
   - 盒装西瓜、切好的菠萝、圣女果、蓝莓
   - 特点：毛利高、冲动购买
   - 注意：必须冷藏，当天切当天清

3. **搭配款**
   - 柠檬、牛油果、小番茄
   - 特点：和饮品、沙拉、早餐搭配
   - 作用：提高客单价

4. **季节款**
   - 夏天：西瓜、葡萄、桃子
   - 冬天：砂糖橘、草莓、车厘子
   - 原则：只做1个爆款，不铺开

**不建议小店面做的：**
- 易压伤的：水蜜桃、芒果、猕猴桃
- 需要现场切配的：菠萝、哈密瓜整果
- 低频高价：榴莲、山竹、进口稀奇水果
- 散称易挑拣的：散装葡萄、樱桃

**三、采购量控制：用“1.5天销量”倒推**

小店面最怕一次进太多。建议：

- **首次进货**：每个SKU只进最小包装，比如1箱或1托
- **日常补货**：按前3天平均日销量 × 1.5天
- **周末/节假日**：按前一个同星期销量 × 1.2
- **天气差/下雨**：直接减半

简单公式：

> 明日采购量 = 近3天日均销量 × 1.5 - 当前库存

如果某品连续2天卖不动，第3天直接停采。

**四、损耗控制：从“进、存、摆、清”四个环节卡死**

1. **进货环节**
   - 固定1-2个供应商，要求小批量、多频次配送
   - 验收标准：不熟、破皮、发软、异味直接拒收
   - 优先选耐放品种：苹果、橙子、香蕉、柠檬

2. **存储环节**
   - 冷藏柜温度：4-8℃
   - 香蕉、芒果不要冷藏，放阴凉通风处
   - 水果不要堆太高，避免压伤
   - 先进先出，新货放里面，旧货放外面

3. **陈列环节**
   - 少量多次上架，不要一次摆满
   - 坏果立即挑出，避免传染
   - 即食盒装水果放收银台附近，冲动购买
   - 用“搭配推荐”代替降价：酸奶+蓝莓、饭团+香蕉

4. **清货环节**
   - 每天固定2个时间点挑损：上午开门后、晚上8点
   - 轻微瑕疵：做试吃、搭配套餐、员工餐
   - 明显变质：直接报损，不要继续摆
   - 设置“当日清”标签，晚上7点后打折

**五、每天必做的4个动作**

1. **早班**：验收、挑坏果、上架
2. **午间**：补货一次，检查冷藏温度
3. **傍晚**：把次日易坏的做折扣或搭配
4. **闭店**：记录销量、损耗、库存，决定明天进什么

**六、关键指标，盯住3个就够**

- **损耗率**：控制在5%以内，超过8%说明品类或采购有问题
- **周转天数**：水果平均1-2天卖完
- **动销率**：每个SKU每天至少卖1份，连续2天为0就淘汰

**七、最实用的起步配置**

如果你现在不知道进什么，先按这个来：

- 香蕉：1把
- 苹果：6-8个
- 橙子：6-8个
- 圣女果：2盒
- 蓝莓：2盒
- 柠檬：4-6个
- 季节爆款：1种，少量

总SKU控制在6-8个，卖得好再加，卖不动就砍。小店面水果不是靠“多”赚钱，是靠“快”和“搭配”赚钱。
