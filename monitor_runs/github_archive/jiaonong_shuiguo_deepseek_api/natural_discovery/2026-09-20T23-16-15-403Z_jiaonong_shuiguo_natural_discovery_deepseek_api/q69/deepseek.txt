# 香蕉、菠萝分级报价的实用做法

批发商给小店报价，关键是让老板**一眼看懂“什么货、什么价、拿多少”**，避免口头扯皮。建议按“等级+规格+单位+价格”四要素来报。

## 一、香蕉分级

香蕉主要看**条重、梳形、成熟度、外观**。

| 等级 | 标准 | 常见叫法 |
|---|---|---|
| 特级 | 梳形整齐，条重足，无黑斑、无机械伤，青绿转黄 | 精品/一级 |
| 一级 | 梳形较好，允许少量轻微花皮 | 通货上 |
| 二级 | 条重偏小或梳形散，有少量黑斑、擦伤 | 通货 |
| 三级 | 散条、熟度高、伤多，适合促销或加工 | 处理货 |

报价示例：
- 特级：X元/箱（约XX斤）
- 一级：X元/箱
- 二级：X元/箱
- 散条：X元/斤

**要点**：香蕉一定按**箱**报，并注明**净重**和**每箱条数/梳数**，因为同样一箱重量差很多。

## 二、菠萝分级

菠萝主要看**单果重、成熟度、外观、品种**。

| 等级 | 标准 | 常见叫法 |
|---|---|---|
| 特级 | 单果2斤以上，果形正，无裂口、无黑心 | 大果/精品 |
| 一级 | 单果1.5–2斤，外观较好 | 中果 |
| 二级 | 单果1–1.5斤，允许轻微瑕疵 | 小果 |
| 三级 | 单果1斤以下或有裂口、熟度高 | 处理果 |

报价示例：
- 大果（2斤以上）：X元/个 或 X元/斤
- 中果（1.5–2斤）：X元/个
- 小果（1–1.5斤）：X元/个
- 统货：X元/斤

**要点**：菠萝最好**按个报，同时给一个参考斤重**，因为小店老板更关心“一个能卖多少钱”。

## 三、报价单建议格式

```
品名：香蕉
等级：一级
规格：约20斤/箱，每箱5–6梳
单价：XX元/箱
起订：5箱起
备注：当日到货，次日可送

品名：菠萝
等级：中果
规格：1.5–2斤/个
单价：XX元/个
起订：20个起
备注：可代削皮，另加X元/个
```

## 四、避免纠纷的3个细节

1. **写清计量单位**：是按箱、按斤还是按个，别混着说。
2. **注明验收标准**：比如“黑斑超过3处降一级”“单果低于1.5斤算小果”。
3. **保留调价机制**：水果价格波动大，报价单注明“当日有效”或“随行就市，提前一天通知”。

这样分级报价，小店老板能自己算利润，你也少解释、少扯皮。
