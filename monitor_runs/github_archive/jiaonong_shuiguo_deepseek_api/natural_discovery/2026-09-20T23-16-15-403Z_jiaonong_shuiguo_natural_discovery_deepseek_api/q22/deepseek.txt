先明确一个判断：**靠“水果互相搭配打折”很难显著提高客单价，真正有效的是用高频刚需的香蕉做引流，用苹果做利润承接，用菠萝做场景连带，并且把组合设计成“多买一件”而不是“买两件更便宜”。**

下面给你一套可直接落地的组合促销方案。

## 一、三个品类的角色定位

| 品类 | 角色 | 原因 |
|---|---|---|
| 香蕉 | 引流品 | 高频、价格敏感、家庭常买，适合做钩子 |
| 苹果 | 利润/客单承接品 | 单价较高、耐储存、易做分级和礼盒 |
| 菠萝 | 连带/场景品 | 客单中等，适合切果、拼盘、餐后场景，但决策频率低于香蕉苹果 |

核心逻辑：**香蕉负责让人进水果区，苹果负责把客单拉高，菠萝负责增加购买件数。**

## 二、推荐组合促销方式

### 方案1：香蕉引流 + 苹果满额升级
- 香蕉：整把特价，限购1把，制造“便宜”感知。
- 苹果：买满2斤，送菠萝切块尝鲜券或直接减2元。
- 目标：顾客本来只买香蕉，看到苹果满2斤更划算，顺手加购苹果。

可设：
- 香蕉 2.98元/斤，限购1把；
- 苹果 5.98元/斤，买2斤减2元；
- 买苹果满2斤，加3元换购菠萝半个。

这样客单从“只买香蕉约5元”提升到“香蕉+苹果+换购菠萝约18-22元”。

### 方案2：三品拼盘/果切组合
适合年轻人和上班族：
- 香蕉2根 + 苹果1个 + 菠萝1/4个，组合价9.9元或12.9元；
- 单独买总价约12-15元，组合价略低，但**提高了购买件数和单次消费额**。
- 重点：果切毛利通常高于整果，能抵消折扣。

### 方案3：家庭装阶梯满赠
- 满15元：送香蕉1根；
- 满25元：送菠萝切块1盒或苹果1个；
- 满35元：送水果保鲜盒/购物袋。
- 香蕉、苹果、菠萝都参与满额，但赠品用低成本香蕉和菠萝边角料控制成本。

### 方案4：场景组合
- 早餐组合：香蕉 + 苹果，定价9.9元；
- 餐后解腻组合：菠萝 + 苹果，定价12.9元；
- 周末家庭组合：香蕉1把 + 苹果2斤 + 菠萝1个，定价29.9元。
- 场景命名比“组合优惠”更能让顾客觉得需要买。

## 三、陈列和执行要点

1. **香蕉放入口或端头**，但不要和苹果、菠萝堆在一起，避免催熟影响。
2. **苹果做分级**：普通散卖、精品装、礼盒装，拉高价格带。
3. **菠萝主推切好、泡好盐水的**，降低顾客处理门槛，提升连带率。
4. **组合价要简单**：9.9、12.9、19.9、29.9，避免复杂计算。
5. **标签写结果，不写过程**：  
   - 差：苹果满2斤减2元  
   - 好：买2斤苹果，加3元换菠萝半个，省6元
6. **每天盯三个数**：客单价、购买件数、组合渗透率。  
   - 组合渗透率 = 买组合的客数 / 水果区总客数。  
   - 低于10%，说明组合没吸引力；高于25%，说明可以继续放大。

## 四、最推荐先试的一套

如果你只想先上一个简单方案，建议用这个：

**香蕉特价引流 + 苹果满2斤减2元 + 加3元换购菠萝半个。**

理由：
- 香蕉负责拉人；
- 苹果负责提高客单；
- 菠萝负责增加件数和场景感；
- 执行简单，员工容易解释，顾客容易理解。

预期效果：水果区客单价通常能提升10%-20%，但前提是香蕉真的便宜、苹果品质稳定、菠萝换购价有明显感知。否则就只是“三个都打折”，客单不一定涨，毛利反而下降。
