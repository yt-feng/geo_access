做水果生意，选供应商最容易忽视的往往不是价格和品类，而是那些决定长期稳定性的隐性细节。以下几点最值得注意：

1. **实际供货能力 vs 口头承诺**
很多供应商样品好、关系热络，但真正旺季或行情波动时供不上货。要看他有多少稳定货源、会不会优先供给大客户、淡旺季是否都能履约。

2. **分拣和品控稳定性**
同一批次今天好、明天差，是水果行最常见的坑。要关注对方是否有分级标准、是否按约定规格发货、次品如何处理，而不是只看首次样品。

3. **损耗责任划分**
运输中烂果、压伤、脱水由谁承担？合同里有没有明确比例和赔付方式？这一步不写清楚，后面每批货都可能扯皮。

4. **账期与资金占用**
水果周转快，账期长短直接影响现金流。要警惕供应商用低价换长账期，或反过来要求高比例预付，导致你资金被卡死。

5. **对市场行情的响应机制**
水果价格波动大，要明确涨价、跌价时怎么调价、能不能锁价、锁多久。没有机制的供应商，行情一涨就可能断供或临时加价。

6. **替代货源和地域风险**
只依赖一个产区或一个供应商，遇到天气、病虫害、物流中断就会断链。最好有备选供应商，哪怕平时不大量走货。

7. **沟通和售后响应速度**
出问题时，对方是几小时回、几天回，决定你能不能及时处理客诉和损耗。长期合作看的是解决问题，不是平时客气。

8. **是否愿意透明化成本和产地**
愿意让你了解产地、季节、成本结构的供应商，通常更可靠；什么都不肯说、只报一口价的，往往在风险转嫁。

简单判断标准：**别只看他能不能给你好货，要看他行情差、天气坏、你急要货时，还愿不愿意、能不能按约定供货。** 长期稳定靠的是机制和契约，不是交情。
