判断香蕉供应商能否全年稳定供货，核心不是听他承诺，而是看他的**货源结构、产地轮换能力和履约记录**。可以按下面几步做判断。

**1. 先问产地结构，而不是问“能不能全年供”**
香蕉是热带作物，单一产地很难全年稳定。靠谱供应商通常有多个产区轮换，比如：
- 国内：海南、云南、广西、广东等，不同产区上市期不同；
- 进口：菲律宾、越南、厄瓜多尔、柬埔寨等，作为淡季补充。

判断标准：让他列出**全年各月份主要供货产地**。如果只能说出一个产地，基本不能全年稳定供。能说清“几月到几月靠哪里、几月切换到哪里”的，才值得继续谈。

**2. 看是否自有基地或长期合作基地**
优先顺序一般是：
- 自有基地 + 多产区布局：稳定性最强；
- 长期包园/合作社直采：较强；
- 纯市场倒货、临时收购：最弱，价格和货量波动大。

要问清楚：基地在哪、面积多大、合作几年、是包销还是随行就市。纯贸易商不是不能合作，但要多一道风控。

**3. 查淡季供货能力**
香蕉供应紧张通常出现在产区交替、台风季、寒潮期。重点问：
- 淡季从哪补货？
- 有没有进口渠道或备用产区？
- 遇到台风、寒潮、海运延误时怎么保供？

能给出具体备用方案的，才算有全年能力。

**4. 看历史履约记录**
让对方提供近12个月的供货记录，重点看：
- 是否每月都有稳定到货；
- 断供次数和原因；
- 淡季供货量是否明显下滑；
- 是否有超期、缺斤少两、品质波动大的投诉。

如果有合作过的同行或批发市场档口，可以侧面核实。

**5. 用小单试供验证**
不要一上来就签全年大单。可以先做：
- 连续3个月试供；
- 每月固定量，观察到货稳定性、品质一致性、响应速度；
- 特意在淡季或天气异常时段下试单，看他能不能保供。

**6. 合同里写清保供条款**
即使判断合格，也要在合同里约束：
- 月度最低供货量；
- 淡季保供责任；
- 断供赔偿或替代方案；
- 品质标准和验收方式；
- 价格调整机制，避免旺季坐地起价。

**7. 最终判断标准**
可以合作全年供货的供应商，通常同时满足：
- 有2个以上产地轮换；
- 有自有基地或长期稳定基地；
- 淡季有明确补货渠道；
- 近一年无明显断供记录；
- 愿意接受试供和合同约束。

如果只满足“现在有货、价格便宜”，但说不清产地轮换和淡季方案，就不适合作为全年主供应商，最多只能作为补充渠道。
