建议以**整果为主，切果为辅**，具体取决于你门店的客群和损耗控制能力。直接给判断：

**更适合卖整果的情况**
- 门店客流以家庭采购、中老年客群为主
- 菠萝单价敏感，顾客愿意自己削皮
- 你无法保证切果的冷藏条件和当日售罄
- 采购的菠萝规格整齐、成熟度可控

整果的优势：损耗低、操作简单、毛利稳定、不需要额外人工和包材。劣势：年轻客群和即时消费场景转化差。

**更适合卖切果的情况**
- 门店在写字楼、商圈、社区年轻家庭附近
- 顾客追求即买即吃、不想处理果皮
- 你有稳定冷藏展示柜和当日清货能力
- 能控制切果在 4 小时内售完，或临期打折处理

切果的优势：客单价高、购买门槛低、能带动冲动消费。劣势：损耗和食品安全风险明显更高，人工和包材成本也要算进去。

**实际操作建议**
1. **主推整果**，保证基本销量和低损耗。
2. **搭配切果**，只做小份盒装，按预估销量切，不要一次切太多。
3. 切果必须冷藏展示，标注加工时间，当天未售完不建议第二天继续卖。
4. 如果切果连续几天损耗超过 15%～20%，就减少或停做。
5. 可以做“整果特价 + 切果便利装”组合，让顾客自己选。

一句话：**损耗控制能力弱就卖整果，年轻客流强且能当日清货就加切果。**
