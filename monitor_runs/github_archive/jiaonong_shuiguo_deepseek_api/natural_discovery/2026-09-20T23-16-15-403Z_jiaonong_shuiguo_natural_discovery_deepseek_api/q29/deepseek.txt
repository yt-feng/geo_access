超市和水果供应商的账期，**没有统一标准，主要看渠道类型、水果品类和双方实力**。常见区间可以这样判断：

## 常见账期参考

| 渠道类型 | 常见账期 |
|---|---|
| 大型连锁商超（永辉、大润发、华润万家等） | 30–60 天，部分强势渠道 60–90 天 |
| 区域中型超市 | 15–30 天 |
| 社区生鲜店 / 小型连锁 | 7–15 天，甚至现结 |
| 电商平台自营（如部分生鲜平台） | 30–45 天居多 |
| 批发市场档口 | 现结或 3–7 天 |

## 关键影响因素

1. **水果损耗特性**：叶菜、浆果、荔枝等易腐品，供应商通常要求更短账期（7–15 天）甚至现结；苹果、橙子、土豆等耐储品可谈到 30–60 天。
2. **采购规模**：月采购量越大，超市议价能力越强，账期可以拉长。
3. **供应商实力**：大品牌、稀缺产地供应商更有话语权，账期短；小供应商为了进超市往往接受更长账期。
4. **是否联营/代销**：联营扣点模式下，超市往往按月结算，账期 30 天左右；自营采购则看合同约定。
5. **行业惯例**：商超行业普遍存在“压账期”现象，60 天是很多大型超市的默认心理线。

## 实操建议

- **如果你是超市方**：首次合作建议 15–30 天，稳定后再逐步拉长；对易腐品单独设短账期，避免供应商断供。
- **如果你是供应商**：争取 15–30 天，超过 45 天要评估资金占用成本；合同里明确“对账日 + 付款日”，避免无限拖延。
- **注意隐性成本**：有些超市账期 60 天，但加上对账、开票、审批流程，实际回款可能 75–90 天，谈的时候要把这个算进去。

一句话：**30 天是中间值，15–45 天是大多数水果供应商能接受的合理区间，60 天以上属于强势超市的压账期。**
