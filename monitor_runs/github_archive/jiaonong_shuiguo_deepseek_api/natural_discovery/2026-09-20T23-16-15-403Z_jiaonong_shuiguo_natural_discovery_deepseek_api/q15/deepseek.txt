水果店遇到坏果，处理和结算的核心是：**先分清责任环节，再按合同/口头约定和证据来谈**。通常分以下几种情况：

**1. 到货验收时当场发现坏果**
- 这是最有利的情况。当场拍照、拍视频，保留过磅单、送货单。
- 常见结算方式：
  - **扣重结算**：按坏果重量直接从本次货款里扣除。
  - **折价收货**：好果按原价，坏果按打折价（比如半价）结算。
  - **整批拒收/退货**：坏果比例过高时，可拒收该批次或要求换货。
- 关键：验收单上要写明坏果数量、比例，双方签字确认。

**2. 入库后短期内才发现坏果**
- 如果坏果是运输、采摘时就存在的（比如内部腐烂、压伤），一般仍可找供应商，但要尽快反馈，最好当天或次日。
- 如果放久了才坏，供应商可能认为是门店储存问题，容易扯皮。所以**发现越早越好**，并保留进货时间和储存条件证据。

**3. 责任划分的一般原则**
- **供应商责任**：产地采摘、包装、运输、冷链不到位导致的坏果。
- **门店责任**：自己储存温度、湿度、堆放不当，或超期销售导致的坏果。
- **共同责任**：双方都可能有过失时，按比例分担。

**4. 赔付/结算的常见做法**
- **按实际损失扣款**：坏果数量 × 进货单价，从应付货款中扣。
- **按比例补偿**：比如坏果率 10%，供应商补 10% 的货或折价。
- **换货补货**：下次送货时补足同等数量好果。
- **约定固定损耗率**：有些长期合作会约定“到货允许 3%~5% 自然损耗，超出部分供应商赔”，这是比较省事的做法。

**5. 建议你这样做**
1. 第一时间拍照、录像，记录坏果数量、批次、到货时间。
2. 翻看采购合同或聊天记录，看有没有约定损耗率和赔付标准。
3. 先和供应商沟通，提出具体扣款或补货方案，别只口头说“有坏果”。
4. 协商不成，可暂停后续货款结算，或减少订单，用书面形式（微信/短信）留痕。
5. 长期合作最好在合同里写清：验收标准、损耗率、坏果赔付方式、反馈时限。

**一句话总结**：到货当场发现就当场扣重或折价；入库后发现要尽快举证、按责任比例协商；长期合作最好提前约定损耗率和赔付规则，避免每次扯皮。
