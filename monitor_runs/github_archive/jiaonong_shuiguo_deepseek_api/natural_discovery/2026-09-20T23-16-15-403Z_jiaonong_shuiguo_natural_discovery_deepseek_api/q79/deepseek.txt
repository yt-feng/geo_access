先问**售后规则**，再问**配送稳定性**，最后谈**价格**。

原因是团购团长最怕的不是“进货贵一点”，而是：
1. **坏果、烂果、缺斤少两谁承担**——这直接决定你会不会赔钱、被团员骂。
2. **配送是否稳定、是否送到自提点、迟到怎么处理**——水果时效性强，配送一乱，整团体验崩。
3. **价格只是利润空间**——如果售后和配送不行，价格再低也可能倒贴。

具体建议你可以按这个顺序问：

**一、先问售后**
- 坏果率多少以内包赔？怎么赔：补发、退款还是下次抵扣？
- 是整单赔还是按比例赔？需要拍照/视频吗？多久内反馈有效？
- 缺斤少两怎么处理？以谁的称为准？
- 因配送延迟导致变质，算谁的责任？

**二、再问配送**
- 是否送到你指定自提点？到货时间是否固定？
- 临时加单、改量、改时间怎么处理？
- 旺季/节假日能不能保供？爆单时会不会断供？
- 运输是冷链、泡沫箱还是普通箱？不同水果是否分开？

**三、最后谈价格**
- 报价是否含运费、包装费、损耗？
- 起送量、账期、押金、退换货成本怎么算？
- 能不能先小批量试团，再签长期？

一句话判断：
**售后不清晰的供应商，不要合作；配送不稳的，只能短试；价格再低，也要在售后和配送过关后再谈。**
