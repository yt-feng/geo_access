判断供应商能不能按时到车，核心不是听他“保证”，而是看**可验证的履约条件**。可以按下面几步做：

1. **先问具体时间节点**
   不要只问“明天能不能到”，要问：
   - 今天几点装车？
   - 从哪个产地/仓库发车？
   - 全程多少公里？
   - 预计几个司机、是否歇人不歇车？
   - 到市场/冷库的准确时间？
   如果对方回答含糊，比如“差不多”“争取”，风险就高。

2. **看是否已有车、是否已装车**
   最可靠的是：
   - 已经装车，并能发装车视频、车牌、司机电话；
   - 车辆已定，能提供行驶证/司机信息；
   - 不是“还在找车”。
   香蕉是生鲜，等车、压车都会影响催熟和损耗，不能只听口头承诺。

3. **核实车辆和司机**
   拿到车牌后，可以让司机发定位、拍车内香蕉和车牌。
   注意核对：
   - 车牌是否和供应商说的一致；
   - 装货地点是否合理；
   - 司机是否知道收货地址和联系人。
   如果供应商不愿给司机电话，只说“我来对接”，通常可控性差。

4. **看过往履约记录**
   优先和合作过、按时到过车的供应商做。
   新供应商可以问：
   - 最近发过哪些市场；
   - 能不能给一两个老客户参考；
   - 之前有没有压车、迟到、换车记录。
   不是要听他夸自己，而是看有没有稳定线路和固定车队。

5. **用合同/微信把关键条款写死**
   至少写清：
   - 品种、数量、规格、单价；
   - 装车时间、发车时间、到达时间；
   - 迟到怎么处理，比如扣款、补损耗、承担市场空档损失；
   - 香蕉成熟度、冷柜/保温/通风要求；
   - 到车后验收标准和异常处理。
   微信文字也算证据，别只语音。

6. **设置可判断的预警点**
   比如：
   - 约定装车后2小时没视频，开始追问；
   - 发车后4小时没定位，要求司机发位置；
   - 预计到达前6小时，确认是否延误；
   - 如果延误超过约定时间，立刻启动备选供应商或调整销售计划。

7. **新供应商先小单试**
   第一次合作不要压大单。先走一车小批量，验证：
   - 是否按时装车；
   - 是否按时到车；
   - 香蕉质量是否稳定；
   - 出问题后是否负责。
   试单靠谱，再放量。

8. **几个高风险信号**
   出现这些要谨慎：
   - 价格明显低于市场，还承诺很快到车；
   - 一直不给车牌、司机电话、装车视频；
   - 装车时间一拖再拖；
   - 要求先打全款；
   - 说“路上查车/堵车/换车”但给不出证据；
   - 到车时间靠“大概”“应该”。

简单说：**能按时到车的供应商，通常能立刻给出装车视频、车牌、司机电话和明确时间；不能按时到车的，往往只剩口头保证。** 你可以把“装车视频+车牌+司机电话+到达时间+迟到赔付”作为是否下单的硬门槛。
