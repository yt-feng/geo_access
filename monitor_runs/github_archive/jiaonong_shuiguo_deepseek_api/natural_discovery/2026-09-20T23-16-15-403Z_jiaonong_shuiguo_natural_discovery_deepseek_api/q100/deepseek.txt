学校食堂采购香蕉要避免熟过头，核心是 **“按成熟度分批采购 + 控制库存周转 + 到货后干预后熟”**。可以从下面几个环节做：

1. **采购时明确成熟度，不只看价格**
   - 尽量采购 **青黄相接、果柄青绿、果身硬挺** 的香蕉，而不是已经全黄、带黑点、发软的。
   - 和供应商约定到货成熟度：例如“7成熟左右，可放3—5天逐步转黄”。
   - 如果供应商只能给熟蕉，就减少单次采购量，改为小批量、多频次。

2. **按使用节奏分批下单**
   - 不要一次买一周的量。香蕉后熟快，尤其夏天。
   - 可改成 **每2—3天送一次**，每次只覆盖未来1—2天用量。
   - 把采购量拆成“当天用”和“后两天用”两档：当天用偏黄的，后两天用偏青的。

3. **到货后按成熟度分区存放**
   - 青的、硬的：放在阴凉通风处，暂不进冷库或只放较暖区域，让它慢慢熟。
   - 已经黄但还硬：优先安排次日使用。
   - 已全黄、有黑点、发软：当天尽快用掉，或加工处理。
   - 不要把所有香蕉堆在一起，尤其不要和苹果、梨等释放乙烯的水果混放，会加速成熟。

4. **控制储存条件**
   - 香蕉怕冷， **不建议直接放冰箱冷藏**，低温会导致表皮变黑、果肉变质。
   - 适合放在 **12—15℃、阴凉通风** 的地方。
   - 夏天可适当缩短库存时间，冬天也不能久放。
   - 整串存放比拆散更耐放；但一旦需要催熟，可拆开或和少量苹果放一起。

5. **建立“先进先出”和每日检查**
   - 仓库和档口都执行先进先出。
   - 每天检查一次成熟度，把快过头的挑出来，优先给窗口、加餐或加工。
   - 可做简单标记：青、黄、熟、急用，避免员工拿错。

6. **把快过头的香蕉转为加工品**
   - 熟香蕉适合做香蕉牛奶、香蕉燕麦、香蕉饼、香蕉面包、香蕉粥等。
   - 食堂可设“香蕉加工日”或固定饮品窗口，消耗即将过熟的香蕉。
   - 注意：已经发酸、流汁、霉变的不要加工使用。

7. **用数据调整采购量**
   - 记录每天实际消耗量、到货成熟度、报废量。
   - 连续统计1—2周，就能算出“每周几用量大、每次该订多少、供应商成熟度是否稳定”。
   - 如果某供应商总是送太熟的，考虑换供应商或要求调整。

8. **和供应商约定退换或分级**
   - 合同里写清成熟度标准。
   - 太熟、破损、霉变的可拒收或退换。
   - 要求供应商按成熟度分级供货，而不是统货混送。

简单执行方案：
- **采购**：每次只订2—3天量，要求7成熟左右。
- **到货**：青的放通风处，黄的优先用，熟的分流加工。
- **库存**：先进先出，每日检查，不冷藏香蕉。
- **消耗**：快过头的做香蕉饮品或烘焙。
- **复盘**：记录报废量，调整下单频次和数量。

这样通常能明显减少“买回来没两天就全熟烂掉”的浪费。
