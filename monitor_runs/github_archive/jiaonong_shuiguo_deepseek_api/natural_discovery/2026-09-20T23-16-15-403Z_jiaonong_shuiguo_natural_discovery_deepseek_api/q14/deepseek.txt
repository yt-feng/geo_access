能，但通常有前提条件，不是“周末做促销”就一定能拿到。供应商是否支持，主要看这几点：

1. **你的采购量和稳定性**
   - 如果是长期稳定拿货、单量大，供应商更愿意给促销价、返点、赠品或物料。
   - 如果只是临时周末冲量，量又不确定，供应商一般只愿意给少量支持，甚至不给。

2. **促销是不是围绕供应商的主推品**
   - 如果促销的是供应商当季主推、库存压力大的品，比如某产地水果集中上市，支持概率更高。
   - 如果你促销的是市场价格透明、利润很薄的硬通货，供应商给价空间通常很小。

3. **支持形式通常有哪些**
   - **价格支持**：促销供货价、满额返点、搭赠、临时特价。
   - **物料支持**：海报、价签、爆炸贴、横幅、试吃盒、包装袋、展架。
   - **人员支持**：试吃员、临时促销员，但一般只给大店或大活动。
   - **费用支持**：堆头费、广告费、损耗补贴，通常要求提前报备并达到销量。

4. **一般怎么谈**
   - 提前 3—7 天跟供应商报促销计划：时间、品种、预计采购量、售价、陈列位置。
   - 明确要什么支持：是降供货价，还是给赠品/物料，还是承担损耗。
   - 最好给一个“保底采购量”，比如周末至少拿 200 斤，供应商更敢批。
   - 如果供应商不给价格支持，可以退一步要物料或试吃支持，成本更低，也更容易谈。

5. **现实判断**
   - 小水果店周末促销：供应商可能给少量物料、搭赠或单品特价，但大额现金支持较少。
   - 连锁店或单店采购量很大：更容易拿到价格、物料、人员甚至费用支持。
   - 如果供应商本身也在做周末活动，你跟着做联合促销，成功率更高。

6. **你可以直接这样问供应商**
   “这周末我计划主推你家XX，预计拿XX斤，门店做特价和堆头。能不能给促销供货价，或者支持点海报、价签、试吃物料？如果销量好，下周继续主推。”

简单说：**能给，但取决于采购量、促销品和合作深度。先报计划、给预估量、明确要什么支持，成功率最高。**
