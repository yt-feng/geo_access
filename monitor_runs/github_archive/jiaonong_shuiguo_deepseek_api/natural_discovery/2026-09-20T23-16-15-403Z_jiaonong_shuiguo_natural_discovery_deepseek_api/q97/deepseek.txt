酒店采购水果盘原料，建议把“规格标准”和“外观标准”分开写进采购单或验收标准里。供应商至少应保证以下几类要求：

**一、规格标准**
1. **品种与等级明确**  
   写清具体品种、产地或等级，如“红富士苹果，一级果”“海南贵妃芒，中果”。不要只写“苹果”“芒果”。

2. **单果重量/尺寸**  
   按酒店水果盘常用切配需求约定，例如：  
   - 苹果：单果 180–220g，横径 75–85mm  
   - 橙子：单果 180–250g，横径 70–85mm  
   - 西瓜：单果 4–6kg，成熟度 8–9 成  
   - 葡萄：单串 400–600g，果粒均匀  
   - 圣女果：单果 12–18g，横径 20–25mm  
   规格要能直接验收，避免“大小均匀”这种模糊表述。

3. **成熟度**  
   水果盘原料通常要求“即用或 1–2 天内可用”。  
   - 香蕉：成熟度 4–5 级，到货后 1–2 天可食用  
   - 芒果：7–8 成成熟，到货后 1–2 天软熟  
   - 牛油果：硬熟或微熟，按使用时间倒推  
   过生、过熟都不合格。

4. **新鲜度与货架期**  
   到货时应有合理剩余货架期，例如叶菜类、浆果类至少 2–3 天，苹果、橙子等至少 5–7 天。不得用临期、尾货、库存果充数。

5. **安全与合规**  
   农残符合 GB 2763，污染物符合 GB 2762，不得使用违规催熟、染色、打蜡或保鲜剂。进口水果需有入境货物检验检疫证明、报关单等。

6. **包装与运输**  
   按品种使用周转筐、泡沫箱、冷藏车等。浆果类、切配用果应冷链运输。包装不得挤压、受潮、异味污染。

**二、外观标准**
1. **整体外观**  
   果形端正，大小均匀，色泽符合品种正常成熟特征，无畸形、无严重偏色。

2. **表面缺陷**  
   允许极轻微不影响切配的瑕疵，但应明确限度：  
   - 无腐烂、发霉、软化、流汁  
   - 无虫蛀、虫眼、活虫  
   - 无裂口、严重碰伤、压伤  
   - 无日灼、冻伤、药害斑  
   - 无明显疤痕、黑斑、锈斑  
   可写“单果瑕疵面积不超过 5%，且不在切配面”。

3. **洁净度**  
   无泥土、无过多枝叶、无农药残留异味、无包装污染。即食类水果应达到可清洗后直接切配的卫生要求。

4. **一致性**  
   同一批次颜色、大小、成熟度基本一致，便于摆盘和标准化出餐。

**三、验收建议**
- 到货抽检比例：一般不低于 10%，高风险或高价水果可提高到 20%–30%。
- 验收方法：称重、卡尺、目测、手感、切开抽检。
- 不合格处理：明确退货、换货、扣款标准。
- 留样：每批次留样 24–48 小时，便于追溯。

**四、可直接写进采购合同的条款示例**
“供应商应保证所供水果为约定品种及等级，单果规格、成熟度、新鲜度符合酒店验收标准；外观端正、大小均匀，无腐烂、霉变、虫蛀、严重碰伤及异味；农残及污染物符合国家食品安全标准；到货剩余货架期不少于约定天数。验收不合格的，酒店有权拒收、要求换货或扣款。”
