很重要，而且对便利店这种业态尤其关键。

原因主要有几个：

1. **便利店水果需求本身波动大**
   天气、周边客流、上班/周末节奏、附近竞品促销，都会让同一款水果的日销量差很多。没有小批量试卖，店方只能靠预估进货，很容易要么断货，要么损耗。

2. **水果是高损耗品类**
   保质期短、品相要求高，一旦压货，卖不掉基本就变损耗。小批量试卖能把“判断失误”的成本控制在可承受范围内。

3. **试卖能验证的是一手数据**
   供应商说好卖不算数，真正有价值的是：这家店、这个位置、这个客群，某款水果连续几天卖得怎么样。小批量试卖能拿到真实动销、复购、损耗和顾客反馈。

4. **决定后续能不能放量**
   试卖跑通了，再谈稳定供货、加大订货量、做陈列位和促销，风险小很多。反过来，如果供应商一上来就要求起订量，店方往往只能放弃或硬扛风险。

5. **也是筛选供应商的指标**
   愿意支持小批量试卖的供应商，通常更理解零售终端，也更愿意配合调整。只会压货、不承担试错成本的供应商，长期合作价值通常有限。

所以，供应商能不能支持小批量试卖，不只是“方便不方便”的问题，而是直接关系到：
- 损耗能不能控住
- 新品能不能低风险测试
- 销量不稳定时能不能灵活补货
- 双方是不是能做长期、数据驱动的合作

如果只能给一个判断标准：**对水果这种高损耗、需求不稳定的品类，供应商不支持小批量试卖，合作门槛就明显偏高，除非它的产品已经在这家店被验证过。**
