要减少香蕉放坏，采购时核心是：**按“预计卖完的时间”倒推采购熟度和到货时间，不要只按“今天要货”下单。**

可以这样要求供应商：

1. **按销售节奏分批要不同熟度**
   - 计划当天到、1—2天卖完：要**青黄相接、刚转黄**的香蕉，果柄还偏青，果面没有黑点。
   - 计划2—3天卖完：要**微黄、无明显糖斑**，适合再放1—2天。
   - 计划马上做促销、当天大量走货：才要**黄熟、少量糖斑**的货。
   - 不要一次全要“已经黄熟”的货，否则第二天就开始快速起黑点。

2. **明确到货时间**
   - 最好要求**早上开门前到货**，让门店有整白天销售时间。
   - 避免下午或晚上到货，因为香蕉到店后还会继续后熟，夜间温度变化也容易加快变质。
   - 如果门店晚上客流少，尽量不要晚上补香蕉。

3. **要求供应商控制催熟程度**
   - 采购时直接说：“不要全熟，给我**青黄阶段、果柄青、果身刚转黄**的货。”
   - 如果是催熟蕉，要求“**催熟后不要过熟，到店还能放2—3天**”。
   - 可以约定：**到货时青果比例不低于多少、黄熟果不超过多少**。例如：青黄果70%，微黄果30%。

4. **要求运输和包装条件**
   - 要求**冷链或阴凉运输**，不要暴晒、不要闷在高温车厢。
   - 要求**纸箱或通风筐装**，不要用密封塑料袋长时间闷着。
   - 到货后检查：有没有压伤、水烂、果柄发黑、大面积糖斑。有这些情况的，说明运输或熟度已经过头。

5. **采购量和频次**
   - 香蕉不要一次囤太多，改成**小批量、多频次**。
   - 例如：原来一次进10箱，可改成隔天进5箱，或者每天进3—4箱。
   - 按“前3天平均销量 × 1.2”左右预估采购量，天气热时再下调。

6. **和供应商约定验收标准**
   - 到货熟度：以青黄为主，少量微黄，无大面积黑点。
   - 到货时间：上午营业前。
   - 损伤要求：无明显压伤、水烂、冻伤。
   - 售后：如果到货已过熟或第二天大面积坏，能否换货或补差。

简单说，采购时直接这样提要求：

> “我要上午到货，香蕉不要太熟，以青黄为主，果柄带青，微黄不超过三成，到店还能放2到3天。不要全黄、不要有糖斑和黑点，运输要阴凉通风，按小批量多批次送。”

这样做的本质是：**把香蕉的“后熟时间”算进销售周期里，让它在店里变黄，而不是在仓库或路上就熟过头。**
