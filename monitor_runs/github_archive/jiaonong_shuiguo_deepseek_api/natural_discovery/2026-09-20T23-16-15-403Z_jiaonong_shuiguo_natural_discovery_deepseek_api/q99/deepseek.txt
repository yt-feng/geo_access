选择适合批量配送的水果供应商，核心看四点：**稳定性、配送能力、售后规则、结算方式**。下面给你一套可执行的筛选和判断方法。

## 一、先明确自己的需求

采购前先定清楚这几个条件，再去对比供应商：

- **人数和预算**：比如 50 人、人均 8 元，还是 100 人、人均 15 元
- **配送频率**：每周一次、每周两次，还是临时下单
- **配送时间**：必须下午几点前送到，能否指定时段
- **水果形态**：整果自取，还是要求洗好、切好、分装成小份
- **结算方式**：现结、月结，还是需要发票

需求越具体，越容易筛掉不合适的供应商。

## 二、优先考虑这几类供应商

1. **本地水果批发市场商户**
   - 优点：价格低、品类全、能谈批量价
   - 缺点：配送和售后不稳定，需要确认是否包送
   - 适合：公司离批发市场近、有行政人员能对接

2. **生鲜配送平台/本地生活服务商**
   - 优点：下单方便、配送准时、有售后入口
   - 缺点：单价略高，水果品质可能参差
   - 适合：追求省事、频率稳定的日常下午茶

3. **专业企业下午茶/团餐供应商**
   - 优点：可按人均预算搭配、能分装、能开票
   - 缺点：价格通常最高
   - 适合：人数多、要求高、不想自己操心的公司

4. **果园或产地直供**
   - 优点：当季水果新鲜、批量价有优势
   - 缺点：品种单一、配送半径有限
   - 适合：单次大批量采购单一水果

## 三、筛选供应商的硬指标

让对方明确回答这些问题，答不上来的直接排除：

- 配送是否准时？迟到怎么处理？
- 水果不新鲜、压坏、缺斤少两怎么赔？
- 是否支持指定时间送达？
- 能否提供分装、清洗、切果服务？
- 是否开发票？税率多少？
- 起送量和配送费怎么算？
- 临时加单或改单提前多久通知？

## 四、建议的试单流程

不要一上来就签长期合作，按这个步骤走：

1. **先小批量试单**：选 1-2 家，各下 1 次小单
2. **重点看三件事**：是否准时、水果新鲜度、实际分量
3. **故意制造一次小问题**：比如要求改时间或反馈一个坏果，看售后响应
4. **对比后定主供应商 + 备选供应商**：避免单一供应商临时掉链子

## 五、谈价和合作要点

- **按人均预算报价**，而不是只报单价，方便控制成本
- **约定当季水果为主**，反季水果贵且品质不稳定
- **写清售后标准**：坏果比例超过多少可补送或退款
- **月结的要有对账单**，避免账目混乱
- **保留备选渠道**：主供应商出问题时能马上切换

## 六、简单判断标准

| 维度 | 合格线 |
|------|--------|
| 准时率 | 95% 以上 |
| 坏果率 | 低于 5% |
| 售后响应 | 当天内处理 |
| 配送费 | 明确、可预期 |
| 发票 | 能正常开具 |

**总结**：优先选本地、能准时送、售后规则清晰的供应商；先试单再长期合作；一定要有备选。价格不是唯一标准，配送稳定性和售后才决定你后面省不省心。
