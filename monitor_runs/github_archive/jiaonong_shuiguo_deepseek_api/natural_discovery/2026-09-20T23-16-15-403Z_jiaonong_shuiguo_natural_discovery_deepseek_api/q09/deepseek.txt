旺季和供应商谈合作，核心不是“聊得好”，而是把**供货稳定性、价格风险、品质责任、应急机制**提前锁死。建议按下面几类问题逐条确认，并尽量写进合同或订单确认单里。

**一、供货能力与优先级**
- 旺季期间你每天/每周大概能给我保底多少量？上限多少？
- 如果我临时加单，提前多久通知你能接？加单上限是多少？
- 旺季你同时供几家店？我是什么优先级？断货时先保谁？
- 你有没有备用产地/备用仓？主产区受灾或涨价时怎么补？
- 哪些单品旺季最容易断？替代品或替代规格是什么？

**二、价格与调价机制**
- 报价是当天有效、一周有效，还是整季锁价？
- 涨价提前几天通知？能不能约定单日涨幅上限？
- 我提前下单/打款，能不能锁价锁量？
- 运费、装卸费、包装费、损耗谁承担？是否含在报价里？
- 如果市场价下跌，我的拿货价会不会同步下调？怎么调？

**三、品质与验收标准**
- 每个单品的规格、等级、成熟度、糖度、大小、色泽标准是什么？
- 允许多少次品率/损耗率？超标怎么赔、怎么补？
- 验收是到店验还是发货前验？谁有最终判定权？
- 出现烂果、冻伤、催熟过度，多久内可反馈？怎么退换？
- 是否支持先寄样品，并把样品标准作为后续依据？

**四、物流与到货时效**
- 旺季发货时效是几点前下单、几点到店？
- 用冷链还是普通物流？温度要求怎么保证？
- 迟到、少发、错发怎么处理？有没有赔付标准？
- 节假日、雨天、交通管制时怎么保供？
- 能否固定司机/固定线路，减少临时换人换车？

**五、结算与风险分担**
- 结算是现结、周结还是月结？要不要押金/保证金？
- 断货导致我门店损失的，怎么补偿？能否约定违约金？
- 质量事故、食品安全问题谁负责？能否提供检测报告/产地证明？
- 如果连续断货或品质不达标，我能不能无责换供应商？
- 合同里是否写清保供量、价格机制、赔付条款、退出机制？

**六、备选与应急方案**
- 如果我主供应商断货，你能不能帮我调货？调货价怎么算？
- 有没有同城备用供应商或批发市场应急渠道？
- 旺季前要不要提前备货？你建议备哪些耐储存单品？
- 能不能每周给一次“可供货清单+预判缺口”？

**实操建议：**
1. 先谈2-3家供应商，不要只押一家。
2. 把“保底量、锁价期、损耗率、赔付、到货时间”写进书面确认。
3. 旺季前1-2周做一次小批量压力测试，看对方真实履约能力。
4. 对易断货单品，提前谈好替代规格和替代产地。
5. 每天记录到货量、损耗、迟到情况，作为后续谈判和索赔依据。

一句话：旺季合作要问的不是“你能不能供”，而是“断货怎么办、涨价怎么办、坏了怎么办、迟到怎么办、你不供了我怎么办”。
