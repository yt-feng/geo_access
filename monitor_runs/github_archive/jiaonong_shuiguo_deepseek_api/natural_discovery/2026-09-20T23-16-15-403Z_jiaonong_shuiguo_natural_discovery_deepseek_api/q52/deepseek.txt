要避免香蕉到店后很快变黑，核心是控制**乙烯、温度、机械损伤和湿度**。甜品店采购时可按下面做：

1. **买成熟度合适的香蕉**
   - 不要买已经全黄、带黑点、柄部发黑的。
   - 优先选**微黄带一点绿**或**黄但两端还带绿**的，到店后还能撑几天。
   - 如果当天就要大量用，买熟一点的；如果要放 2–3 天，买偏生一点的。

2. **采购时减少挤压和磕碰**
   - 香蕉怕压、怕摔，表皮一伤就很快黑。
   - 整箱采购时不要码太高，不要和硬物混装。
   - 提货时尽量拿箱体，不要捏果身。

3. **到店后立刻拆箱、分散**
   - 不要长时间闷在纸箱或塑料袋里，乙烯积聚会催熟。
   - 到店后摊开放在阴凉通风处，别堆成一堆。
   - 如果箱内有已经熟透或发黑的，立刻挑出来，避免催熟其他香蕉。

4. **控制温度**
   - 最适合短期存放的是**12–15℃**左右。
   - 不要放冰箱冷藏，尤其未熟香蕉，容易冻伤变黑。
   - 夏天如果室温太高，可放空调房或冷柜边缘，但别低于 10℃。
   - 已经熟透、准备当天用的，可以冷藏，但表皮仍可能变黑，不影响果肉。

5. **减少乙烯影响**
   - 香蕉不要和苹果、梨、芒果、番茄等释放乙烯多的水果放在一起。
   - 如果需要延长保存，可以用保鲜膜包住香蕉柄部，减少乙烯从柄部释放。
   - 不要整根密封死，容易闷坏。

6. **悬挂或弓背朝上放置**
   - 有条件就悬挂起来，减少受压面。
   - 平放时让香蕉弓背朝上，减少与台面接触的压伤。

7. **按用量分批采购**
   - 甜品店最有效的方法不是“存”，而是**少量多次采购**。
   - 根据销量预估 1–2 天用量，避免一次囤太多。
   - 熟透香蕉可及时加工成香蕉泥、蛋糕、奶昔等，减少损耗。

8. **到店检查和处理**
   - 收货时检查：有没有压伤、裂口、发黑、发霉。
   - 有伤的先挑出当天用。
   - 表面轻微黑点但果肉正常，可尽快加工使用。

简单记：**买偏生一点、别挤压、别闷箱、别冷藏、别和催熟水果混放、少量多次采购。**  
如果已经到店，优先做的是：**拆箱、摊开、挑出熟果、放 12–15℃ 通风处。**
