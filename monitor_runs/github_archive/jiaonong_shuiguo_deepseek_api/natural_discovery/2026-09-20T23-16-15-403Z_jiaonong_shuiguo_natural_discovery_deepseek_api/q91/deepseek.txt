优先选 **小把（通常 3~5 根）**，其次再考虑 **单根**，整袋要谨慎上。

理由很直接：

1. **小把最符合便利店场景**
   - 顾客多是即时消费，买来当天或一两天内吃。
   - 3~5 根的量不大，决策负担低，客单价又比单根高。
   - 比整袋更灵活，不容易因为吃不完而放弃购买。

2. **单根适合做补充，不适合做主陈列**
   - 优点是低门槛、试吃型购买，适合写字楼、地铁口、医院等单人即时消费场景。
   - 缺点是损耗高、称重/贴标麻烦、客单价低，而且香蕉单根拿取后容易留下“挑剩感”，卖相下降快。

3. **整袋通常只适合特定渠道**
   - 适合家庭客群明显的社区店、生鲜店，或做促销搭配。
   - 便利店如果整袋上，容易压库存，香蕉熟得快，一旦卖不动就集中报损。
   - 除非你有稳定家庭客群或能做预售/团购，否则不建议作为主包装。

**更稳的做法：**
- 主力：**小把 3~5 根，统一定价**，比如按把卖，减少称重环节。
- 补充：**单根**，放在收银台附近或即食区，针对单人顾客。
- 整袋：先小批量测试，只放在社区型门店，或做“第二件优惠”清库存。

**判断标准很简单：**
- 门店客流以单人/上班族为主：单根 + 小把。
- 门店客流以家庭/社区为主：小把 + 少量整袋。
- 如果只能选一个：**选小把**。
