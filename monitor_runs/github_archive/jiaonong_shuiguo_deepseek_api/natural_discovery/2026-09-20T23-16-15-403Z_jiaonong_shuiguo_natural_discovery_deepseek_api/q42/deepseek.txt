压低采购成本而不牺牲品质，核心不是“把价格砍下来”，而是**把谈判焦点从单价转移到总成本和可验证标准上**。以下是可以直接执行的做法。

## 一、先算清“真实成本”，再谈价

不要只盯着每斤报价。先建立单品成本模型：

- 采购价
- 损耗率（运输、上架、挑拣、临期）
- 到店可售率
- 账期与资金占用
- 退换货比例

**可执行动作：**
对每个大单品，算出“可售每斤成本 = 采购价 ÷ 可售率”。  
例如：A果进价3元/斤，可售率85%，实际可售成本是3.53元；B果进价3.2元/斤，可售率95%，实际可售成本是3.37元。  
**此时压A的价，不如换B或要求A提升可售率。**

谈判时直接说：“我按可售成本比价，不按挂牌价比价。”

## 二、用“分级定价+标准前置”代替单纯压价

供应商最怕的是“先高价进，再被挑刺扣款”。你可以反过来：

**谈判话术：**
“我不要求你整体降价，我要求按等级分开报价，并且标准写进合同。达标就按价收，不达标按约定扣罚或退货。”

具体做法：
- 明确糖度、单果重、着色度、硬度、机械伤比例
- 明确允许的次果率
- 明确到店验收时限
- 明确不合格处理方式：退货、折价、补货

这样供应商知道你不会“事后乱扣”，才愿意在达标等级上让价。

## 三、用“量+稳定性+账期”换价格

供应商让价通常来自三个确定性：

1. **量的确定性**：年度/季度框架协议，而不是每次临时询价
2. **时间的确定性**：固定每周几车、提前几天报量
3. **回款的确定性**：账期稳定，不拖款

**可执行动作：**
- 把分散的小单合并成周单
- 提前3—7天给滚动预测
- 承诺核心单品70%—80%采购量给主供应商
- 用“稳定账期”换“阶梯价”

谈判时不要说“你便宜点”，要说：
“我每个月稳定走X吨，账期30天不拖，你给我三档阶梯价：低于X吨什么价，X到Y吨什么价，超过Y吨什么价。”

## 四、用“竞标+保留第二供应商”制造压力

不要只跟一家谈到底。保留2—3家合格供应商，定期比价。

**可执行动作：**
- 每季度对前20大单品做一次密封报价或线上比价
- 主供应商拿70%，第二供应商拿30%
- 明确告诉对方：份额随价格、品质、到货率动态调整

**注意：**
比价要同等级、同规格、同到货条件。否则就是假比价，容易把品质比崩。

## 五、谈“非价格条款”，往往比压价更有效

这些条款不直接降价，但能显著降低总成本：

- **运费谁承担**：到店价还是产地价
- **损耗谁承担**：运输损耗超过约定比例由供应商补
- **退换货**：坏果、次果是否包退包换
- **包装**：是否含筐、含箱、可回收
- **到货时间**：是否避开高温时段，降低损耗
- **结算方式**：现结、周结、月结对应不同价

**可执行动作：**
把“到店价、含损耗、含退换”作为统一比价口径。  
很多供应商单价低，但运费和损耗算进来反而更贵。

## 六、用“品质对赌”替代“一刀切压价”

如果供应商不肯直接降价，可以谈：

- 达标率超过95%，给奖励或增量
- 达标率低于90%，折价或减量
- 连续两批不达标，暂停供货

**话术：**
“价格我不压你，但品质标准我写死。你达标，我给你稳定量；你不达标，我按合同扣。这样你敢不敢接？”

这比单纯要求降价更容易被优质供应商接受，也能筛掉靠低价低质抢单的供应商。

## 七、具体谈判步骤

1. **先内部定标准**：每个单品定可售率、糖度、规格、损耗上限
2. **再算可售成本**：用可售成本比价，不用挂牌价比价
3. **准备三档方案**：目标价、可接受价、底线价
4. **引入竞争**：至少2—3家同等级报价
5. **谈框架**：量、账期、到货、退换、损耗
6. **写进合同**：标准、扣罚、补货、调价机制
7. **试单验证**：先小批量跑2—4周，再放量

## 八、一句话原则

**压价不压标准，压价压的是供应商的确定性和你的总成本，不是他的品质底线。**
