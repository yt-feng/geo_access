可以按“先保供、再谈价、留证据”的顺序处理。旺季临时补货最怕的是供应商口头答应但优先供别人，所以要把关键条款落到可执行的订单/微信确认里。

**1. 先判断缺口，不要直接问“能不能补”**
先算清楚：
- 未来7天预计用量、现有库存、在途量；
- 缺口是每天多少箱/件，还是某个到货日断档；
- 能接受的最晚到货时间（比如每天上午10点前）。

然后给供应商一个明确需求，例如：“本周三到周日，每天补X件，上午10点前到店，连续5天。”这比“最近菠萝不够，能多送点吗”有效得多。

**2. 临时补货协议要约定这6项**
- **数量与规格**：每天/每批多少件，单件重量、品种、成熟度、是否去皮/切块。
- **价格**：临时补货价是否按原合同价，还是随行就市；如果浮动，约定参考哪个市场、谁确认、涨幅上限。
- **到货时间与频次**：具体到日期和时段，迟到是否影响当天营业。
- **质量验收**：坏果率、黑心/烂心、成熟度标准；不合格怎么退换、补货时限。
- **优先供应**：旺季期间供应商应优先保障你的量，不能因别人出价高就砍你的单。
- **违约责任**：缺货、迟到、质量不达标时，按缺货金额比例扣款或赔偿，并保留临时换供应商的权利。

**3. 用“框架+临时订单”的方式约定**
如果原合同还在，可以签一份补充协议或微信确认：
- 原合同基础价和账期不变；
- 旺季临时增量部分单独列价；
- 每次补货以“临时订单”为准，供应商回复“确认”即生效；
- 当日未确认的，视为不接受，你可立即找备用供应商。

**4. 付款和账期要提前谈清**
旺季供应商也怕压款。可以给一点激励：
- 临时补货现结或缩短账期；
- 连续稳定补货后，超出部分给小额奖励；
- 但不要轻易接受“先打全款再发货”，除非对方长期可靠。

**5. 一定要有备用方案**
临时补货不能只靠一家。至少准备：
- 1家本地批发市场档口；
- 1家周边果园或加工厂；
- 1家同类茶饮店/同行拼单渠道。
这样供应商临时涨价或断供时，你有替代选项，谈判也不会被动。

**6. 实际操作话术**
可以这样发：
“王老板，本周三到周日我们预计每天缺X件菠萝，想请你临时补货。要求：每天上午10点前到店，规格和原来一致，价格按原合同价；如果市场价波动超过X%，提前一天书面确认。能保证优先供应的话，我们这5天增量都从你这里走，货款可以现结。你确认一下每天能供多少。”

**7. 关键提醒**
- 所有临时约定尽量留下文字记录，微信、短信、订单截图都算；
- 不要只谈总量，要谈“每天到货时间”；
- 不要只谈价格，要谈“断供怎么办”；
- 如果供应商要求涨价，先确认是短期旺季价还是长期调价，避免旺季过后降不回来。

简单说：把临时补货当成一份短期小合同来谈，明确数量、时间、价格、质量、优先权和违约后果，同时准备好备用供应商。这样既能保供，也不容易被临时拿捏。
