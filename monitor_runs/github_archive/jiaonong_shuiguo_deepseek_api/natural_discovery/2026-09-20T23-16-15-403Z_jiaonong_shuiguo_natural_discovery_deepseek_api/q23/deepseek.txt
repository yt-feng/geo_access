可以，但通常不是“供应商单方面免费全包”，而是按合作方式分几种情况。

**1. 陈列支持**
供应商一般能提供：
- 陈列道具、堆头、端架物料
- 陈列图/摆放建议
- 临时理货员或促销员协助
- 试吃台、试吃盘、牙签、手套等物料

但超市是否允许，取决于：
- 门店陈列位是否收费
- 是否影响其他品类
- 供应商是否愿意承担费用或让利

**2. 海报支持**
供应商通常可以提供：
- 商品图片、卖点文案
- 促销价签、爆炸贴、吊旗、展架
- 堆头围挡、地贴
- 部分供应商可分担海报印刷费或 DM 投递费

如果要做超市统一海报，通常需要：
- 提前确认档期
- 提供合规价格和活动机制
- 超市审核后才可上线

**3. 试吃支持**
试吃是水果促销很有效的方式，但要求最严：
- 供应商可提供试吃果、一次性用品、试吃员
- 超市通常要求报备，涉及食品安全、卫生、消防
- 需要明确试吃损耗由谁承担
- 部分门店会收试吃位费用或要求保底销量

**4. 实际能不能落地，关键看合同和费用**
常见合作方式：
- 供应商免费提供物料，超市给好位置
- 供应商承担部分海报/试吃费用，超市配合引流
- 联合促销，按销量或毛利分成
- 超市收取陈列费、DM 费、促销服务费

**建议你直接这样谈：**
1. 先问供应商能提供哪些免费物料和支持。
2. 再确认超市门店是否允许试吃、堆头、海报。
3. 明确费用谁出：物料、人工、损耗、场地费。
4. 写进促销确认单：档期、位置、价格、销量目标、费用分担。
5. 试吃尤其要确认食品安全责任和现场管理责任。

简单说：**能提供，但通常要谈条件；免费支持常见，全面支持一般需要费用分担或销量对赌。**
