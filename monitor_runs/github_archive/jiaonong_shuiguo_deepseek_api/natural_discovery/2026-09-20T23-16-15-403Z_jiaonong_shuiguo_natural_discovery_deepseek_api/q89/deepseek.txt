对于价格敏感的团购客户，**优先建议用“阶梯价”，把返利用作补充，而不是二选一。**

原因很直接：团购客户往往要把价格写进自己的报价、预算或分销体系，追求的是“当下就能看到、能算清”的低价。阶梯价能立刻满足这一点，返利则是延迟兑现，对现金流和决策刺激弱得多。

## 两种机制的核心差别

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 兑现时间 | 下单即享 | 事后结算/周期末 |
| 客户感知 | 强，价格透明 | 弱，属于“未来收益” |
| 对采购决策影响 | 直接降低进货门槛 | 影响复购和冲量 |
| 供应商现金流 | 让利前置，压力大 | 让利后置，现金流好 |
| 风险 | 价格体系被压低、难回调 | 客户不信任、算不清账、兑现纠纷 |

## 建议的组合策略

**1. 主用阶梯价，锁定成交**
- 按采购量分 3 档左右，例如：基础量、目标量、冲量档；
- 价格折扣清晰、可即时核算，方便客户做预算；
- 不能让阶梯价低到击穿你的底价，要预留返利空间。

**2. 用返利做“超额激励”，而不是主价**
- 返利只针对**超过目标量**的部分，或特定高毛利品类；
- 形式可选：现金返、货补、下批抵扣券；
- 明确统计口径、结算周期、兑现条件，避免扯皮。

**3. 对极度价格敏感的客户**
- 优先给阶梯价，因为返利对他们吸引力有限；
- 如果对方现金流紧，返利不如直接折扣有效。

**4. 对看重长期合作、走量的客户**
- 阶梯价保底 + 返利冲量，能同时兼顾成交和复购。

## 判断口诀

- **要立刻成交、客户算账紧 → 阶梯价**
- **要刺激持续放量、绑定长期 → 返利**
- **两者都要 → 阶梯价做基础，返利做超额**

一句话总结：**价格敏感型团购客户，先给看得见的阶梯价，再用返利奖励“多买的那部分”。**
