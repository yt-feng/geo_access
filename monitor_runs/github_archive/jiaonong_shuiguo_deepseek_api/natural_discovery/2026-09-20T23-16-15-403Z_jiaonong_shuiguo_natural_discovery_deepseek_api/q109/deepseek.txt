优先谈 **账期**，但前提是先把 **售后责任** 用一句话锁死；配送放在第二位谈。

更具体地说，按优先级排序是：

1. **售后**：先定规则，不一定要谈很细，但必须明确“坏果、少件、延误、规格不符”谁负责、怎么赔。
2. **账期**：长期合作里最直接影响你现金流和议价空间的条款，值得重点谈。
3. **配送**：影响体验和损耗，但通常可以通过固定频次、时间窗、起送量来优化，不一定一开始就死磕。

为什么这么排：

- **售后不先定，账期越长你越被动**。水果是非标品，损耗和品质波动大。如果售后规则模糊，账期再长，最后也可能被扣款、扯皮、补货争议吃掉利润。
- **账期是长期合作的核心利益**。现结、周结、月结、半月结，对现金流影响远大于每斤便宜几毛钱。长期供应商如果愿意给稳定账期，说明信任和实力都更强。
- **配送重要，但可替代性相对高**。除非是冷链、时效要求极高的品类，否则配送问题往往可以通过约定到货时间、验收标准、临时加急规则来解决。

建议你这样谈，顺序别乱：

**第一步：先谈售后，用一句话定框架**
“以后所有到货，按验收单为准。坏果率超过 X%，当天拍照确认，下次补货或直接扣款；少件按实际数量补；延误超过 X 小时，当次运费或部分货款怎么处理。”
先把这条谈成，再往下聊。

**第二步：重点谈账期**
不要只问“能不能月结”，要给方案：
- 先试探： “我们长期做，能不能从现结改成周结/半月结？”
- 再交换： “如果账期给到 30 天，我可以把月采购量稳定在 X，或者接受固定每周 X 次配送。”
- 最后定底线： 如果对方不同意长账期，就争取“部分账期 + 部分现结”，比如 70% 月结、30% 现结，比全现结好。

**第三步：最后谈配送**
重点不是“送不送”，而是：
- 固定每周哪几天送；
- 几点前到；
- 临时加单提前几小时说；
- 起送量多少；
- 迟到、漏送怎么补。

一句话总结：**先锁售后，再攻账期，最后优化配送。** 如果只能先谈一个，就谈账期；但谈账期之前，必须先把售后规则用文字确认下来。
