普通商家对菠萝、香蕉有概念，但对新品种、新规格、新等级往往没有判断框架。供应商介绍时，不要先讲品种名和产地故事，而要**把新产品挂到商家已有的认知上**，让他立刻知道“这是什么东西、卖给谁、怎么卖、赚多少”。

可以按下面这个顺序说。

**1. 先用一句话对标大品类**
公式：**“这就是XX的升级版/平替版/差异版。”**

例如：
- “这就是菠萝，但是不用削、不用泡盐水，切开就能吃的凤梨。”
- “这就是香蕉，但是更小、更甜、适合做儿童零食的皇帝蕉。”
- “这就是橙子，但是皮更薄、汁更多、适合榨汁店的沃柑。”
- “这就是苹果，但是个头小、脆甜、适合办公室下午茶的迷你苹果。”

商家一听就知道该放进哪个货架、哪个场景。

**2. 说清楚和普通货的三个区别**
不要讲太多，只讲商家最关心的三点：
- **外观区别**：大小、颜色、包装、整齐度。
- **口感/使用区别**：更甜、更酸、更香、更方便、更耐放。
- **损耗区别**：好不好存、掉不掉秤、坏果多不多。

例如：
“和普通香蕉比，这个个头小一半，甜度高，皮不容易黑，摆一周卖相还在。”

**3. 直接说卖给谁、怎么卖**
商家最怕不知道怎么卖。供应商要给出场景：
- 卖给谁：年轻人、小孩、老人、送礼、餐饮店、果汁店、社区团购。
- 怎么卖：按个卖、按盒卖、按份卖、做引流款、做利润款、做搭配套餐。
- 怎么陈列：堆头、冷柜、收银台、水果捞原料区。

例如：
“这个不是走量款，是利润款。你放在收银台旁边，按盒卖，一盒6个，适合白领顺手买。”

**4. 用算账代替形容词**
不要只说“好吃、新鲜、高端”，要帮商家算：
- 进价多少
- 建议售价多少
- 一斤/一盒赚多少
- 损耗大概多少
- 一天大概能卖多少

例如：
“进价一箱80，里面20盒，合4块一盒。你卖9块9，一盒赚5块9。一箱卖完赚118，损耗算两盒，还能赚100左右。”

商家听到数字，比听“品质很好”更容易下单。

**5. 给一个低风险试单方案**
普通商家最怕压货。供应商可以说：
“你先拿一箱试，不用多。我教你怎么摆、怎么定价。卖得好再补，卖不动我帮你调换其他品。”

这样降低决策压力。

**6. 现场最好带对比样品**
如果有条件，把普通菠萝和凤梨、普通香蕉和皇帝蕉放在一起：
- 看外观
- 闻味道
- 切开试吃
- 称重量
- 算毛利

商家能直接感知，不用靠想象。

**一句话模板：**
“张老板，这个你就当成XX来卖。它比普通XX个头小、更甜、更耐放。你的客户主要是年轻人和小孩，放收银台按盒卖，一盒进价4块，卖9块9。你先拿一箱试，卖不动我帮你换。”

核心就是：**用商家已知的大品类做锚点，用场景告诉他卖给谁，用数字告诉他怎么赚钱，用试单降低他的风险。**
