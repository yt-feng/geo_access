做家庭水果礼盒，组合的核心不是“品种多”，而是**耐放、口感有层次、分量不浪费，且家里人各有所爱**。按这个思路，苹果、橙子、香蕉、菠萝可以这样搭：

**推荐组合：苹果 + 橙子 + 香蕉，菠萝按需少量加**

具体比例可以参考：

- **苹果 40%**：耐放、寓意好、老少都能接受，是礼盒的“底”。
- **橙子 30%**：颜色亮、解腻、和苹果一样比较耐放，适合家庭日常吃。
- **香蕉 20%**：软糯、孩子和老人爱吃，但熟得快，不能放太多。
- **菠萝 10%**：有热带水果的亮点，但处理麻烦、占体积、不耐放，适合作为点缀。

如果是 **5kg 左右家庭装**，可以这样分：

- 苹果：2kg，约 6–8 个
- 橙子：1.5kg，约 6–8 个
- 香蕉：1kg，约 5–7 根
- 菠萝：1 个，约 1–1.5kg

**为什么不建议菠萝放多？**
菠萝在礼盒里有两个问题：一是带皮占地方、显得礼盒大但实际果肉少；二是家庭一次吃不完，切开后不好保存。放 1 个作为“惊喜款”就够了。

**如果目标是送家庭客户，优先选这个版本：**
苹果 + 橙子 + 香蕉 + 1 个小菠萝。整体颜色好看，红黄橙都有，寓意也稳，成本比全放贵价水果低，家庭收到后基本都能吃完。

**如果对方家里有老人小孩，微调一下：**
香蕉可以稍多一点，菠萝减到半个或换成小菠萝；橙子选易剥皮的品种，苹果选脆甜型，别选太面的。

**如果对方是年轻家庭，想显得高级一点：**
可以减少香蕉，增加橙子或苹果，菠萝保持 1 个；再配一点小番茄或提子做视觉填充，但别让填充果占太多重量，否则家庭会觉得“看着多、能吃的不多”。

简单说，家庭礼盒的黄金公式是：**苹果和橙子做主力，香蕉做亲和力，菠萝做亮点但少量。** 这样既好看、又耐放，也最不容易踩雷。
