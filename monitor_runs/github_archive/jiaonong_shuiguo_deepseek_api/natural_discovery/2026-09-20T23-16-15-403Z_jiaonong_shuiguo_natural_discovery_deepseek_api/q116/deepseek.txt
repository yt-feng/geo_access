小商家采购水果时，现金结算和月结账期各有不同的风险，核心区别在于**资金压力方向不同、信任风险方向也不同**。

**一、现金结算的风险**

1. **资金占用大、周转压力高**  
   每次进货都要立刻付钱，现金流被压在库存上。水果损耗快、销售周期短，一旦当天或几天内卖不动，现金就变成烂果。

2. **采购量受限，议价能力弱**  
   现金有限时只能小批量进货，拿不到批量价，也难锁定好货。旺季或紧俏品种容易被别人先拿走。

3. **现场交易风险**  
   现金结算容易出现：  
   - 称重、等级、规格看走眼，钱付完再发现问题，追回难；  
   - 收据、凭证不规范，后续质量争议说不清；  
   - 携带现金有丢失、被盗风险。

4. **对供应商依赖被动**  
   如果长期只跟一家现金拿货，对方临时涨价、断供，你很难快速切换，因为新供应商未必肯赊账。

**二、月结账期的风险**

1. **信用风险：供应商跑路或断供**  
   月结本质是供应商给你垫资。如果对方经营不稳，可能突然要求提前结清、停止供货，甚至收钱后不发货。

2. **对账和坏账争议**  
   水果非标品，等级、损耗、退换货容易扯皮。月结时如果单据不全，月底对账容易多算、错算，甚至被迫承担不该承担的损耗。

3. **现金流错觉，容易过度采购**  
   月结让你感觉“手里还有钱”，可能放大采购量。一旦销售不及预期，月底集中付款时现金流断裂。

4. **价格可能更高**  
   供应商提供账期，通常会把资金成本、坏账风险打进报价。表面单价差不多，实际可能比现金价高几个点。

5. **关系绑定与退出成本**  
   长期月结容易形成依赖。想换供应商时，旧账未清、新供应商不信任，切换成本高。

**三、更稳妥的做法**

- **现金为主、月结为辅**：日常走现金拿好价，月结只用于稳定、可信、量大且能快速周转的品种。
- **月结必须签简单协议**：写清账期、对账日、付款日、质量异议期、退换货规则。
- **每笔货留凭证**：称重单、等级照片、送货单、聊天记录都保存，月底对账才有依据。
- **控制月结额度**：月结总额不超过你一周到十天能回笼的现金，避免集中付款爆雷。
- **分散供应商**：至少有两家可替代货源，避免被单一账期绑死。

一句话总结：**现金结算怕压资金和看走眼，月结怕信用崩、对账乱和集中付款。** 小商家最好用现金保命、用月结放大，但月结额度必须卡死。
