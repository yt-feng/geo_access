茶饮店用香蕉，采购熟度要按“当天用还是备货用”分开控，核心是：**买青一点入库，用前催熟到刚好，熟到位的当天必须用完或转冷冻/熬酱。**

### 1. 先定用途，再定熟度
- **做香蕉奶昔、冰沙、香蕉牛奶**：用**7~8成熟**。  
  特征：表皮基本黄、少量青肩，捏起来微软但不变形，香气清甜。太生会涩、发硬；太熟会甜腻、发黑、氧化快。
- **做香蕉果酱、香蕉泥、 topping**：用**8~9成熟**。  
  特征：全黄、有少量糖斑，手感软，香气浓。甜度和风味最好，但必须当天加工。
- **做装饰切片、烤香蕉片、摆盘**：用**7成熟左右**。  
  特征：黄中带一点青，硬度够，切片不烂。
- **做冷冻香蕉块、破壁基底**：可以买**8~9成熟**，去皮切段冷冻，避免门店熟透报废。

### 2. 采购时怎么判断
- **看颜色**：  
  - 青肩明显：约5~6成熟，适合入库催熟。  
  - 全黄无斑：约7~8成熟，适合1~2天内用。  
  - 出现芝麻状糖斑：约9成熟，最好当天用。  
  - 大面积黑斑、渗液：不要收，除非立即做酱。
- **摸手感**：  
  - 硬：生，需催熟。  
  - 微软有弹性：刚好。  
  - 一按一个坑：过熟，只能加工。
- **闻气味**：  
  - 无明显香气：偏生。  
  - 有清甜香蕉香：合适。  
  - 发酵酒味：已过熟，不建议做鲜饮。

### 3. 采购量和熟度搭配
建议不要一次全买同一种熟度，按“**青黄搭配**”采购：
- **当天用**：7~8成熟，占日用量约50%。
- **1~2天后用**：6~7成熟，占30%。
- **3~4天后用**：5~6成熟，占20%，放常温催熟。
- 夏天香蕉熟得快，青蕉比例要提高；冬天可适当多买黄蕉。

### 4. 到店后的熟度管理
- **常温催熟**：放在通风阴凉处，不要堆太厚，避免压伤。
- **别直接冷藏生香蕉**：低温会冻伤，表皮变黑、内部难熟。  
  已经熟到位的香蕉可以冷藏1~2天，但风味会下降。
- **分开放**：熟香蕉会释放乙烯，催熟其他香蕉和水果，别和草莓、葡萄等易熟水果混放。
- **每天挑拣**：  
  - 7成熟：继续常温。  
  - 8~9成熟：优先排班使用。  
  - 过熟：立刻去皮冷冻或熬酱。

### 5. 最实用的门店标准
可以给员工定一个简单卡：
- **青肩硬**：不能用，继续催熟。
- **全黄微软**：做奶昔、冰沙、切片。
- **糖斑软香**：做酱、香蕉泥，当天用完。
- **黑斑渗液**：报废或立即加工，不做鲜饮。

### 6. 一句话采购原则
**不要买“已经全熟”的香蕉做主力库存，买6~8成熟；到店后按颜色和软硬分批用，熟透的当天转加工或冷冻。**  
这样既能保证饮品香气和口感，又能减少黑斑、烂损和报废。
