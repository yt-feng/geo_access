在水果采购合同里，**法律上没有一个统一的“超过多少就必须赔”的法定比例**。关键看两点：

1. **合同有没有约定验收标准和坏果率容忍线**；
2. **没有约定时，按行业惯例、交易习惯和“合理损耗”来谈，通常需要双方协商或由法院/仲裁根据具体情况判断。**

实务中比较常见的写法是：

- **坏果率 ≤ 3%～5%**：视为合理损耗，一般不单独赔付，按合格果结算；
- **坏果率 5%～10%**：超出部分可要求**扣款、折价或补货**；
- **坏果率 > 10%**：通常可以要求**按比例赔付、退货、换货，甚至解除合同**；
- **生鲜易损水果**，如草莓、樱桃、荔枝、杨梅等，容忍线可能略高；
- **耐储水果**，如苹果、橙子、柚子等，容忍线通常更低。

更稳妥的合同写法不是只写一个“坏果率”，而是写清楚：

> 到货验收时，随机抽检不少于总箱数的 10%。坏果率≤3%为合格；超过3%的部分，按实际坏果重量对应货款的 1.5～3 倍扣减；超过10%的，买方有权拒收该批次或要求全额退款并赔偿运费。

所以，如果你问“超过多少应该要求赔付”，比较有操作性的答案是：

- **超过 3%～5% 就可以开始主张扣款或折价；**
- **超过 10% 通常可以主张明显赔付、退货或解约；**
- **具体数字一定要在合同里事先约定，否则事后容易扯皮。**

建议你在合同里直接写明：**抽检方法、坏果定义、容忍比例、超出后的赔付计算方式、运费和损耗由谁承担**。这比只写一个比例更有用。
