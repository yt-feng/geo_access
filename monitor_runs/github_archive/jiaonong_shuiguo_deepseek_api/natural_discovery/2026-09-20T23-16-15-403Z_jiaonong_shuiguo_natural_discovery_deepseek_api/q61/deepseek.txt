判断香蕉批发对方是不是稳定供货，不要只听他说“我这边常年有货”，要看几个能验证的硬指标。下面按可操作性给你一套判断方法。

**一、先看货源背景**

- **是产地直发还是倒手**：稳定供货方通常能说清楚是云南河口/金平、广西、海南、老挝、缅甸、菲律宾还是厄瓜多尔等具体产区，且有合作的种植基地或长期代办。
- **有没有自有或包销基地**：自有基地、长期包园、和代办有稳定合作，比“今天有货就收、明天没货就停”的二道贩子稳。
- **淡旺季怎么供**：香蕉有产区轮换，国内云南、广西、海南、老挝、缅甸、菲律宾接力。能讲清楚“这个产区下市后从哪个产区接上”的，才是真稳定。

**二、看供货能力的具体证据**

- **日/周供货量**：问他每天能稳定发几车、每车多少件、多少吨，是否长期稳定而不是偶尔有。
- **加工能力**：有没有自己的催熟库、加工棚、打包线。只有催熟加工能力跟得上，才能稳定按你的节奏出货。
- **冷库和运输**：有没有冷库、自有车队或固定物流合作。香蕉怕热怕冻，运输不稳，货再好也白搭。
- **历史记录**：让他提供近1-2个月的发货记录、装车视频、磅单、物流单号，能连续提供比口头承诺可信。

**三、用“小单试供”验证**

这是最有效的办法：

1. **先下一小单**，比如1-2车或几吨，不要一上来就压大单。
2. **看三个东西**：
   - 到货时间是否准时；
   - 重量、件数、等级是否和约定一致；
   - 催熟后颜色、口感、货架期是否稳定。
3. **连续试2-3次**，每次都换不同时间点（比如旺季、雨天、节假日前后），看是否还能稳定。
4. **观察异常处理**：故意问一次“临时加量/推迟两天/换等级”，看他能不能配合、有没有备用货源。

**四、看合同和结算是否规范**

- 是否愿意签**购销合同**，写清品种、等级、数量、单价、交货时间、验收标准、损耗承担、违约处理。
- 是否接受**对公账户、发票或正规收据**。只收现金、不愿留凭证的，风险高。
- 是否敢承诺**缺货赔付或补货**。稳定供货方通常有备用产区，敢写进合同。

**五、几个“不稳定”的危险信号**

- 报价明显低于市场，催你打全款；
- 说不清具体产区，只说“云南/广西都有”；
- 没有固定加工点、冷库、物流；
- 催熟后青头、黑心、软腐多，或货架期特别短；
- 一问他“下个月还能不能供”就含糊；
- 只肯发一次大货，不肯小单试。

**六、实操建议**

- 同时找2-3家供货方，不要只押一家；
- 每家先小单试供，记录到货时间、损耗率、催熟效果；
- 稳定合作后，再谈账期、返点、专属等级；
- 关键节点（雨季、春节、产区换季）提前备货，别等断货才找。

一句话：**能说清产区、有加工和冷库、敢小单试供、连续几次到货都稳定、合同结算规范，才叫稳定供货。** 只靠嘴说“常年有货”的，先按不稳定处理。
