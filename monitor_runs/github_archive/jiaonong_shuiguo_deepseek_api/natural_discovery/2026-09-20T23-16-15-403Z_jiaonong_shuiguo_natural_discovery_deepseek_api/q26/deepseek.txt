社区超市卖小包装香蕉，核心矛盾是：**香蕉本身极易后熟、怕压、怕冷，而小包装又会放大损耗和投诉**。采购和运营时要重点盯这几项：

**1. 先定包装形态**
- 优先选 **2–3 根装、整串不拆散**，用托盘+保鲜膜或透气袋，不要用完全密封袋。
- 若做单根装，必须用 **硬托盘或吸塑盒**，否则运输和陈列中极易压伤。
- 包装上留 **透气孔**，避免水汽积聚导致发黑、长霉。
- 标签不要直接贴在蕉皮上，贴包装膜或托盘，减少撕标伤皮。

**2. 采购规格要明确**
- 要求供应商按 **成熟度** 分级：青蕉、微黄、即食黄。小包装最好采购 **微黄或青中带黄**，到店后还能卖 2–3 天。
- 约定 **单根长度、单串重量、每盒根数**，避免大小混装。
- 明确 **到货成熟度**，不要采购已经全黄、起芝麻点的货做小包装，损耗会很高。
- 优先选择 **蕉指饱满、棱角不明显、无机械伤** 的货源。

**3. 损耗控制关键点**
- **温度**：香蕉怕冷，**不要进冷库、不要低于 12–13℃**。夏天可放阴凉通风处，冬天避免靠门口冷风。
- **催熟管理**：青蕉到店后如需催熟，要单独区域，不能和即食黄蕉混放。
- **先进先出**：小包装按到货批次贴日期，先卖成熟度高的。
- **分级销售**：微黄做正常价，起斑点的做特价或切段做果切，全黑及时下架。
- **陈列量**：小包装一次上架不要太多，少量多次补货，减少翻动和压伤。
- **防压**：堆叠不超过 2–3 层，重物不能压香蕉。

**4. 和供应商谈的条款**
- 明确 **损耗赔付**：到货压伤、发黑、霉变的比例怎么算。
- 约定 **退换货**：严重青蕉不熟或到货即烂的处理方式。
- 要求 **分级包装**，不要大串混小串、好坏混装。
- 小包装若由供应商预包装，要确认 **包装成本、标签合规、保质期标注**。

**5. 门店执行建议**
- 每天至少 **2–3 次挑拣**，把过熟、压伤、发霉的挑出。
- 小包装最好 **当日包、当日卖**，不要提前包太多。
- 定价时把 **预计损耗 10%–20%** 算进去，尤其是夏天。
- 如果社区客流偏老年或家庭，**3 根装**通常比单根装更好卖；如果偏单身年轻人，可试 **1–2 根装**，但包装成本会更高。

简单判断：**小包装香蕉能不能做，关键看你能不能稳定拿到微黄、无伤、可分级的小串货源，以及门店能不能做到低温不冷、少量勤补、每天挑拣。**
