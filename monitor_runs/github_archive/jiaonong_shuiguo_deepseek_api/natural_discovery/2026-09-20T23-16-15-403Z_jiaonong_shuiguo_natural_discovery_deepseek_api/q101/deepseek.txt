酒店早餐水果供应，核心是“稳定+可控+算得清账”。和供应商谈合作时，重点盯住以下几件事：

**一、先明确自己的需求**
- **品种与规格**：早餐常用西瓜、哈密瓜、橙子、苹果、香蕉、圣女果、火龙果等。要约定单果重量、成熟度、切配要求（整果还是净果）。
- **用量与频次**：按入住率波动给区间，比如日均50kg、周末80kg，避免供应商按固定量送货造成浪费。
- **送货时间**：早餐通常6:30前到货，必须写清楚，迟到要有处罚或补货机制。

**二、价格与结算**
- **报价方式**：要求按“元/斤”或“元/公斤”报价，并注明是否含税、含运费、含切配。
- **价格调整机制**：水果价格波动大，建议约定每周或每两周根据市场价调整一次，并保留比价权。
- **账期**：常见月结30天，新供应商可先做周结或半月结，降低风险。

**三、质量与验收**
- **验收标准**：写清外观、成熟度、无腐烂、无虫害、农残达标。最好附样品照片或封样。
- **验收流程**：到货后由厨房或库管当场抽检，不合格可拒收或要求补送。
- **退换货**：约定坏果率超过多少（如3%）就整批退换，费用由供应商承担。

**四、稳定供应保障**
- **备选货源**：要求供应商有备用产地或二级供应商，避免断供。
- **安全库存**：酒店自己保留1-2天应急量，尤其是香蕉、苹果这类耐存水果。
- **违约条款**：断供、迟到、质量不达标要有明确扣款或赔偿标准。

**五、合同与合规**
- **资质**：营业执照、食品经营许可证、检验检疫证明、农残检测报告。
- **食品安全责任**：明确因水果问题导致客人投诉或食物中毒，供应商承担相应责任。
- **合同期限**：先签3-6个月试合作，稳定后再签年度框架。

**六、成本控制建议**
- 优先选当季水果，反季水果成本高且供应不稳。
- 西瓜、哈密瓜等可要求供应商按酒店需求切配，减少后厨人工。
- 每周复盘用量和损耗，及时调整订单量。

**谈判时可以直接问供应商的问题：**
1. 你们的主产地在哪里？断供时怎么补？
2. 送货迟到怎么处理？
3. 坏果率超过多少可以退换？
4. 价格多久调一次？依据是什么？
5. 能否先试供两周？

简单说：**把用量、时间、质量、价格调整、违约处理这五件事写进合同，再保留1-2家备选供应商，基本就能稳定。**
