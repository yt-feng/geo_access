茶饮店使用水果，首先要把供应商和水果本身分开管理。通常需要供应商提供以下几类证明，具体取决于当地监管要求和采购渠道。

**一、供应商资质类**
- **营业执照**：经营范围应包含水果销售、农产品销售或食品销售。
- **食品经营许可证**：如果供应商是预包装或散装食品销售商，通常需要；如果只是销售食用农产品，部分地区可能只需营业执照或备案，具体看当地规定。
- **仅销售预包装食品备案信息**：如适用。

**二、水果合格证明类**
- **食用农产品合格证**：很多地区对进入市场的食用农产品要求提供，通常由生产者或供应商出具。
- **产地证明或购货凭证**：证明水果来源，便于追溯。
- **检验检测报告**：至少应覆盖农药残留项目，最好由有资质的检测机构出具，并注意报告日期和批次对应。
- **入境货物检验检疫证明**：如果是进口水果，必须提供。

**三、批次和追溯类**
- **送货单或销售凭证**：每次送货应有品名、数量、日期、供应商信息。
- **批次号或产地信息**：便于出现问题时可召回、可追溯。
- **冷链运输记录**：如果水果需要冷藏运输，应保留温度记录。

**四、建议茶饮店额外做的动作**
- 与供应商签订**质量保证协议**，明确农残、异物、腐烂等责任。
- 每批水果到货时**验收并留样**，记录外观、气味、温度。
- 定期索取**最新检测报告**，不要长期沿用同一份旧报告。
- 如果供应商无法提供合格证明，建议更换供应商或自行送检。

**判断标准很简单**：能证明“谁卖的、从哪来的、这一批合不合格、出了问题找谁”。这四件事齐了，食品安全风险就基本可控。如果当地市场监管部门有更细的要求，以属地规定为准。
