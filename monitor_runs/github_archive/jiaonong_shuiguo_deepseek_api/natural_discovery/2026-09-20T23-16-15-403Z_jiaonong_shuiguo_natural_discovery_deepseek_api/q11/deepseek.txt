会影响销售，但影响程度取决于你的客群和卖法。

**核心结论：**
- 同一箱香蕉大小不一，**整箱卖影响较小**，**拆开散卖影响较大**。
- 如果大小差异明显，顾客挑拣会变多，损耗和纠纷也会增加。

**具体影响：**

1. **散卖时最明显**
   - 顾客会挑大的、挑好看的，剩下小的难卖。
   - 小的最后要么降价，要么烂掉，实际利润被吃掉。

2. **整箱/整把卖时影响小**
   - 如果按箱、按把定价，顾客对大小不均的容忍度更高。
   - 但前提是整体外观、成熟度过得去。

3. **影响定价和口碑**
   - 大小混装如果没提前说明，顾客容易觉得“被坑”。
   - 一旦被贴上“货不匀”的标签，复购会下降。

**可执行建议：**

- **采购时**：尽量选规格相对统一的货，尤其是做散卖。
- **已经进了混装箱**：
  - 按大小分级：大的正常价，小的做特价或搭配促销。
  - 整把卖时把大小搭配好，别让一把里全是小的。
  - 熟的先卖，避免大小没卖完先烂。
- **销售方式**：
  - 散卖就明确标价、分级；
  - 整箱卖就提前说明“大小混装，按箱计价”，减少售后纠纷。
- **控制损耗**：小的可以做香蕉奶昔、果切、特价篮，别硬等原价卖。

**一句话：**
大小不一定会让你卖不掉，但会**增加挑拣、降低均价、抬高损耗**。能分级就分级，能整卖就整卖，别混在一起按统一高价散卖。
