该关注的是**切果损耗**，其次才是甜度、外观，大小排最后。

理由很直接：超市卖菠萝，利润不是靠“单个卖得贵”，而是靠**整果进、切果出、损耗控得住**。

### 判断顺序

1. **切果损耗最关键**
   - 菠萝有皮、眼、芯，出肉率通常只有 **50%～65%** 左右，差的时候更低。
   - 损耗高，哪怕进价便宜、卖价高，也可能不赚钱。
   - 要重点看：去皮后净重、修眼损耗、芯是否可利用、切块/切片报废率。

2. **甜度决定复购**
   - 菠萝不甜，顾客买一次就不买了，切果损耗再低也没用。
   - 但甜度不能只靠“尝一个”，要看批次稳定性。
   - 对超市来说，甜度稳定比偶尔特别甜更重要。

3. **外观决定动销**
   - 外观好，整果和切果都更好卖。
   - 但外观是表层指标，不能替代出肉率和口感。
   - 果形端正、无黑心、无烂点、成熟度均匀，比单纯“大”更重要。

4. **大小不是核心**
   - 大果不一定出肉率高，也不一定甜。
   - 过大可能芯粗、纤维多；过小可能出肉少、切果难看。
   - 应按目标客群选规格：家庭装偏中大果，果切杯/拼盘偏均匀中果。

### 可执行建议

- **先算出肉率**：随机抽 5～10 个，去皮去眼去芯后称净重，算出平均出肉率。
- **再定损耗红线**：例如出肉率低于 55% 的批次，要么压价，要么不切果卖。
- **甜度做批次抽检**：用糖度计或试吃，低于标准就不要主推切果。
- **外观分级**：好果做整果陈列，次果做切果或促销，烂果直接剔除。
- **大小服务场景**：整果卖选均匀好看，果切卖选出肉率高、芯小的。

一句话：**超市卖菠萝，先算切果损耗，再管甜度，再看外观，大小按场景配。**
