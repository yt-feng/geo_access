买香蕉时想避开“太生”或“太熟”，核心是**按你打算几天内吃完来选成熟度**，别只看颜色。可以按下面做：

1. **先定吃的时间**
- **今天/明天吃**：选已经黄、带少量黑点的，最甜最软。
- **2～3天吃**：选整体黄、两端还略青、没有黑点的。
- **3～5天吃**：选黄中带明显青色、摸起来硬的。
- **更久**：选青绿、很硬的，回家自己催熟。

2. **看颜色，不只看黄不黄**
- 太生：通体青绿，摸起来像石头。
- 刚好偏生：黄中带青，硬。
- 刚好可吃：黄，微软，无或极少黑点。
- 太熟：大面积黑点、发黑、发软，甚至渗汁。

3. **摸手感**
- 硬邦邦：偏生。
- 轻按有弹性：适合1～2天吃。
- 一按就陷、发软：已经熟，最好当天吃。

4. **看果柄和两端**
- 果柄青绿、切口新鲜：通常偏生、较耐放。
- 果柄发黑、干枯：可能放久了。
- 香蕉两头开始发黑：熟得快。

5. **看有没有碰伤、裂口、发霉**
- 有黑斑但果肉不软，通常是熟，不一定坏。
- 有裂口、渗液、霉点、酸味：别买。

6. **按用途选**
- 直接吃：黄、微软、少量黑点。
- 做奶昔/烘焙：熟一点，带黑点更好。
- 想放几天：青黄、硬。
- 想马上吃又不想太软：黄、无黑点、轻按微软。

7. **买回家后控制成熟速度**
- 想快点熟：和苹果/梨放同一个纸袋里，室温。
- 想慢点熟：拆开、别闷在塑料袋里，放阴凉通风处；成熟后冷藏。
- 冷藏会让皮变黑，但熟香蕉果肉通常还能吃几天。

简单判断：
- **青绿硬** = 生，能放。
- **黄无黑点微硬** = 2～3天吃。
- **黄带少量黑点微软** = 今天明天吃。
- **大面积黑软** = 已太熟，尽量别买，除非马上做烘焙。
