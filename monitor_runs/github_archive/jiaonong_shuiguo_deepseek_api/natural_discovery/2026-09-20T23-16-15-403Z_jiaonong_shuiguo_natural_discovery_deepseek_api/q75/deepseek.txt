第一次合作时，小批量试单的核心目标不是“赚一笔”，而是**用最低成本验证供应商是否值得长期合作**。所以试单设计要围绕三个可验证项展开：货能不能稳定达标、履约靠不靠谱、账能不能算得过来。

下面给一个可以直接照做的框架。

**一、先定试单目标，不要只定“拿点货试试”**

建议把试单目标写成 4 条，结束后逐条打分：

1. 到货品质是否稳定，和样品/约定标准差多少；
2. 交期是否准时，缺货/延迟时怎么处理；
3. 损耗率、次品率、实际到手成本是否可接受；
4. 沟通和售后是否顺畅，出问题能不能快速解决。

**二、试单量怎么定**

不要按“供应商最低起订量”直接下单，也不要为了压价一次拿太多。

建议按以下方法确定：

- 以你**单个主力单品正常一周销量的 10%～20%** 作为试单量；
- 如果水果易腐，试单量控制在 **3～5 天内能卖完**；
- 如果供应商要求整箱/整件起订，就选 **1～2 个箱规**，不要混太多 SKU；
- 第一次只试 **1～2 个单品**，优先选你销量最大、周转最快、品质标准最容易判断的品种。

例如你平时一周卖 100 箱苹果，试单可以拿 10～20 箱；如果是草莓这种高损耗品，试单量压到 3 天内能卖完的量。

**三、选品怎么选**

优先试“你的主力款”，而不是供应商推荐的利润款或清货款。

原因很简单：主力款你熟悉标准、有历史数据、能快速判断好坏，也最容易看出供应商真实水平。

建议：

- 试 **1 个主销单品 + 1 个次主销单品**；
- 两个单品最好来自同一供应商，方便看整体履约；
- 不要第一次就试高端礼盒、小众品种、季节性极强的尾货。

**四、合同/订单里必须写清的 7 项**

哪怕只是微信下单，也要把下面内容确认成文字：

1. **规格标准**：品种、产地、单果重/果径、糖度、成熟度、箱规；
2. **等级标准**：一级/二级、允许次品比例；
3. **价格与费用**：单价、运费、装卸费、包装费、是否含税；
4. **交期**：下单后几天发货、到货时间、物流方式；
5. **验收方式**：到货后几小时内验收、怎么拍照、怎么计数；
6. **售后规则**：次品/损耗怎么赔、补发还是扣款、响应时间；
7. **付款方式**：建议试单采用“货到验收后付”或“30% 定金 + 到货验收付尾款”，不要第一次就全款预付。

**五、验收怎么做才有效**

试单一定要做验收记录，否则白试。

到货后建议按下面做：

- 随机抽 3～5 箱，不要只开最上面一箱；
- 记录：到货时间、总箱数、抽检箱数、次品数、损耗重量；
- 拍照/视频：外包装、开箱、果面、果底、称重；
- 算三个数：
  - 次品率 = 次品数 ÷ 抽检总数；
  - 损耗率 = 损耗重量 ÷ 到货总重量；
  - 实际到手单价 = 总付款 ÷ 实际可售重量。

这三个数出来后，你才能判断“便宜”是不是真便宜。

**六、试单后的判断标准**

建议设一个简单门槛，达不到就不进入正式合作：

- 次品率：一般水果控制在 **5% 以内**，易损品可放宽到 **8%～10%**，具体看品类；
- 交期：延迟不超过 **24 小时**，且提前告知；
- 售后：问题反馈后 **24 小时内**给方案；
- 实际到手成本：不高于你现有渠道同品质成本，或虽高但品质明显更稳；
- 沟通：至少 2 次异常处理中响应正常。

如果试单出现“以次充好、延迟不告知、售后推诿”中任意一项，建议直接换供应商，不要因为价格低就继续。

**七、第一次试单的推荐动作清单**

可以直接按这个顺序做：

1. 明确 1～2 个试销单品；
2. 要样品并确认规格标准；
3. 按 3～5 天销量定试单量；
4. 书面确认价格、运费、交期、售后；
5. 付款方式选货到验收付或部分定金；
6. 到货后抽检、拍照、算次品率和损耗率；
7. 试单结束后给供应商打分；
8. 达标再谈第二批放量，不达标就停止。

**一句话总结：**
第一次试单，量要小到 3～5 天能卖完，品要选你最有判断力的主力款，单要写清规格/交期/售后，验收要算出次品率和实际到手成本。达标再放量，不达标就换。
