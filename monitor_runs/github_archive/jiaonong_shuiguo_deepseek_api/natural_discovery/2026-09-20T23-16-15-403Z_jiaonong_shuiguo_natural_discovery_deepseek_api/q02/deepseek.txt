对小水果店来说，这四个因素不能平均用力，通常建议按这个优先级判断：

**1. 熟度最关键**
香蕉是后熟型水果，进货时的熟度直接决定你还能卖几天、能不能赶上销售节奏。
- 太青：要放几天才能卖，占地方、压资金，还可能突然集中变黄。
- 太熟：当天卖不掉就很快起黑斑、发软，损耗高。
- 最理想：进“能卖 2～3 天”的货，根据你店里客流和销量分批进。

**2. 坏果率决定真实成本**
香蕉怕压、怕闷、怕冷。坏果率高，哪怕进价便宜，最后算上挑拣、丢弃、顾客体验差，往往更亏。
- 重点看：柄部霉变、表皮压伤、黑斑、断指、催熟不均。
- 如果一批货坏果率明显高，即使单价低，也不建议长期合作。

**3. 送货速度影响损耗和现金流**
香蕉从批发市场到店里，时间越短越好。送货快，意味着：
- 熟度更可控；
- 压伤和闷坏更少；
- 你可以更接近销售节奏补货，减少库存。
如果供应商送货慢，就要被迫多备货，香蕉又容易坏，风险会放大。

**4. 价格不是第一，但要算“到手可卖成本”**
不能只看进货价，要算：
**实际可卖成本 = 进货价 ÷ 可卖比例 + 损耗 + 运费/时间成本**
便宜但熟度差、坏果多、送货慢的货，通常不是真便宜。

**实操建议：**
- **固定 1～2 家主力供应商**，优先选熟度可控、坏果少、送货稳的。
- **每天少量多次进**，比如按前 2～3 天销量预估，不要一次压太多。
- **按用途分级**：青一点的做陈列，熟一点的做促销/果切/特价，减少损耗。
- **记录 1～2 周数据**：进货价、到货熟度、坏果率、送货时间、实际售完天数。很快就能看出哪家最划算。

一句话：**熟度 > 坏果率 > 送货速度 > 价格。**  
但如果价格低到能覆盖损耗，并且熟度、坏果率、送货都达标，那才是值得长期合作的好货。
