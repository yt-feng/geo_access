核实水果供应商的“全国配送”，重点不是听他怎么说，而是把“覆盖范围、时效、冷链、损耗责任、结算边界”拆成可验证项。

**1. 先要配送范围清单，不要只要一句“全国”）**
让供应商提供：
- 可配送省份/城市清单；
- 哪些地区不送、偏远地区是否加价；
- 县级市、乡镇、园区、商超仓、前置仓是否到；
- 是否需要采购方自提或中转。

判断方法：拿你实际收货地址逐条对照，而不是看“全国”两个字。

**2. 用真实地址做试单**
选你最有代表性的收货点，比如：
- 一线城市总仓；
- 二三线城市分仓；
- 偏远县域或乡镇门店；
- 需要冷链的品类收货点。

让供应商按正常流程报价、排车、出单。试单不要只试一个最优质地址，要试最难覆盖的地址。

**3. 核实时效和运输方式**
问清楚：
- 下单到发货多久；
- 到货时效是自然日还是工作日；
- 是直发、干线+落地配、还是第三方中转；
- 中转几次、在哪中转；
- 是否全程冷链，还是只干线冷链、落地配常温。

如果水果对温控敏感，重点看“最后一公里”是否冷链，而不是只看干线。

**4. 核实冷链和温控凭证**
要求提供：
- 冷链车辆或保温箱证明；
- 温度记录仪数据样例；
- 不同品类建议温区；
- 夏季/冬季方案是否不同。

不能只看“有冷链”，要看能否提供可追溯温度记录。

**5. 核实异常处理能力**
全国配送真正的短板通常在售后。问：
- 延误、破损、腐损怎么赔；
- 报损时限和凭证要求；
- 是补发、退款还是折价；
- 偏远地区是否免责；
- 天气、交通、疫情等不可抗力如何界定。

最好写进合同或订单条款，不要停留在口头承诺。

**6. 查实际承运和落地配资源**
让供应商说明：
- 自有车队还是外包；
- 合作承运商有哪些；
- 目的城市落地配是谁；
- 能否提供承运合同或合作证明；
- 是否支持指定物流。

如果对方只说“我们合作很多物流”，但说不出具体承运商和落地配，覆盖能力通常要打折。

**7. 做小批量多区域压测**
选3—5个不同区域，小批量下单，记录：
- 接单响应时间；
- 发货时间；
- 实际到货时间；
- 到货温度；
- 损耗率；
- 售后处理速度。

连续试2—3次，比一次试单更能看出稳定性。

**8. 用合同锁定覆盖承诺**
把以下内容写进采购合同或补充协议：
- 配送区域明细；
- 时效标准；
- 冷链要求；
- 损耗率上限；
- 超区、延误、腐损的赔付标准；
- 数据回传和温度记录要求；
- 试单不达标时的退出机制。

**9. 交叉验证**
可以要求供应商提供：
- 近3个月发往不同区域的运单号样例；
- 合作客户或案例，但注意隐私和真实性；
- 让其承运商直接确认覆盖范围。

如果对方拒绝提供任何可验证信息，只反复强调“全国都能送”，建议按“覆盖能力不足”处理。

**一句话判断标准：**
能给出具体区域清单、具体承运商、具体时效、具体冷链记录、具体赔付规则，并愿意用小批量多区域试单验证的，才叫实际覆盖能力；只给“全国配送”口号的，不能直接采信。
