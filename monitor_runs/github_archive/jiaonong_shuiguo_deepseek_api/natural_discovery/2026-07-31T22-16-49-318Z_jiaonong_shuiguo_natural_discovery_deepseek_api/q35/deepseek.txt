连锁超市降低门店坏果率，通常需要采购合同和门店运营管理双管齐下。在合同层面，主要应围绕**质量验收标准、检验期、换货/退货流程、违约赔偿计算方式**来设计条款。

以下是具体的合同约定建议：

### 一、明确“坏果”的具体标准（质量验收条款）
合同不能只写“不得有坏果”，要写清楚判断标准，否则后期容易扯皮。

- **等级标准**：明确生鲜果蔬的等级（如一级果、二级果），约定单果重量、果径、成熟度、色泽等硬性指标。
- **坏果定义**：明确列举（如腐烂、霉变、机械损伤、严重软化、异味等），并规定**坏果率上限**（例如：“单批次坏果率不得超过3%，糖度低于X度视为不达标”）。
- **特别提示**：对于存储要求高的水果（如草莓、荔枝），需增加“冷链运输温度记录”作为验收依据。

### 二、设置收货端的“验收与异议期”条款
这是降低坏果率的第一道闸口。

- **验收期限**：约定收货后 **24小时内** 完成抽检（或全检），逾期视为质量合格。
- **抽样比例**：明确抽检比例（如按件数抽10%，不足1件的按整件检）。
- **异议提出**：若发现坏果率超标，须在 **48小时内** 向供货方发送书面（或系统）质量异议通知，并保留证据（照片、视频）。
- **关键**：约定“未在约定时间内提出异议的，视为验收合格”，防止扯皮。

### 三、约定“分级赔付”机制（核心条款）
坏果赔付应按“供货方责任”还是“超市存储责任”分开约定，或约定无条件部分赔付。

- **责任划分**：
  - **运输/交付前责任**：送货至门店时发现坏果，直接由供货方承担。
  - **存储/售卖期责任**：到店后因超市冷库问题导致的损坏，超市自负，供货方不赔（此点需明确，防止供货方推责）。
- **赔付标准**（建议采用阶梯式）：
  - 坏果率 ≤ 3%：正常结算（视为损耗合理）。
  - 坏果率 3% ~ 5%：按坏果数量的 **1.2倍** 扣减货款（或换货）。
  - 坏果率 5% ~ 10%：扣减该批次 **10%** 货款，并限期换货。
  - 坏果率 > 10%：超市有权 **拒收该批次** 并有权要求退货，且供货方需赔偿超市直接损失（如运费、临时采购差价）。
- **兜底条款**：即使超市未及时发现，若在保质期内（到货后3天内）发生大面积腐烂（如超过环比），供货方仍应承担“隐蔽瑕疵担保责任”，按照上述阶梯标准赔付。

### 四、加入“换货与补货”的时效性约定
坏果率高的门店往往是因为补货不及时导致积压。

- **换货期限**：约定确认质量问题后，供货方应在 **24-48小时内** 提供换货（或补充优质果）。
- **超时违约金**：若超时未补，每超一天按该批次货值的 **0.5%~1%** 支付违约金，或直接按缺货损失扣款。

### 五、引入“批次扣款与追偿”条款
- **月度汇总**：约定每月对各门店的坏果赔付金额进行汇总，直接从当月货款中扣除。
- **保证金**：可约定供货方缴纳部分履约保证金（如月结款的10%），专门用于赔付质量事故，合同期满无事故则退还。

### 六、关键提醒（法律与实操）
1.  **电子留存**：合同应约定“验收数据通过系统上传或邮件确认”，避免口头异议无效。
2.  **避免模糊用语**：避开“酌情”“协商”等词，尽量使用数字（如“3%”、“48小时”、“1.2倍”）。
3.  **保存记录**：超市方务必保留每个门店的**收货单（注明实收件数、坏果件数）**及**照片水印证据**，否则即使合同有约定，诉讼中也可能因举证不力败诉。
