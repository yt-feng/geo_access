为社区超市挑选每日配送的水果供应商，建议优先考察以下几个核心条件，确保稳定、新鲜和利润空间：

**1. 供应稳定性与响应速度（最关键）**
- **能否做到全年不中断**：很多个体果农只能供应当季，你需要考察对方是否有冷库或跨区调货能力，避免断供。
- **每天配送时效**：询问最早几点到货（通常要求早上6-7点前到店），以及遇到极端天气（暴雨、台风）是否有备选方案。
- **缺货替补机制**：如果预定的苹果突然没货，对方能否在2小时内用品质相近的其它品种替代，而不是让你缺货。

**2. 产品品质与损耗率**
- **看货标准**：要求对方提供分级标准（如特级/一级果），建议你亲自到对方分拣场地看一次，重点看是否有烂果、虫眼混装。
- **损耗承担**：合同里要明确“交货时因运输或挤压造成的破损率超过5%，由供应商承担”之类的条款。每日配送最怕当天卖不完的水果隔日继续混卖。

**3. 价格与账期灵活性**
- **对标批发价+合理加价**：社区超市毛利率一般在30%以上，供应商报价建议比当地一级批发市场均价高出10%-15%以内为合理区间。
- **支持“先卖后结”或周结**：最好谈成“压一批货”的模式（如今天配送，明天前结清今天货款），不要一次性预付大量现金，降低资金风险。

**4. 门店售后与补损服务**
- 确认对方是否有专门对接你家门店的客服或业务员，而不是只留一个总机电话。
- 明确“当日收到货发现质量问题，是否支持拍照后24小时内补货或扣款”，这是防止扯皮的核心。

**5. 本地化与合规**
- **产地距离**：优先选择车程在2小时内的产地/批发商，距离越短，水果损耗和运输成本越低。
- **证照核验**：要求对方提供营业执照、食品经营许可证，水果属于食用农产品，如果对方能出示农药残留检测报告（哪怕每月一次），会更有保障。

- 签合同时，把“每日最低配送量”“迟到罚款”“质量问题赔付”写清楚，防止口头承诺不作数。
