做水果生意，想长期稳定发展，选对供应商是核心中的核心。很多人在选供应商时，主要看价格和果品新鲜度，但最容易忽视的往往是那些决定“生死”的隐性细节。

结合行业经验，以下是我认为最容易忽视的 **5 个关键细节**：

**1. 供货的 “稳定性” 和 “履约率”（而非单批质量）**
很多新手只盯着某一次到货的果子好不好，而忽略了供应商**长期供货的“准时率”和“足量率”**。

-   **细节**：你要考察他是否承诺了今天到货就一定能到，以及遇到雨天、节假日时，他是否还有充足的货源调配能力。哪怕他果子贵5分钱，只要他能保证**全年不断供**，你的门店就不会因为断货流失客源。

**2. 损耗与分级的“透明度”**
水果生意最大的隐形亏损来自**中途损耗**和**好坏混装**。

-   **细节**：不要只听他说“一箱5斤净重”。你要明确：
    -   **皮重**：他给你的塑料筐、包装纸有多重？有没有故意压秤？
    -   **分级标准**：他说的“大果”“中果”实际规格是多少？是否存在“上大下小”或“中间夹次果”的情况？建议首次合作时，要求 **“开箱抽检”** ，并约定好抽检不合格的赔付比例。

**3. 资金结算的“账期”与“售后担当”**
水果是生鲜，难免有磕碰。很多供应商口头承诺“包售后”，但真正发生问题时却百般推诿。

-   **细节**：一定要明确**“售后时限”**。比如，到货后 **24小时内** 报损有效，超时不认。此外，账期（压款天数）是你的现金流核心，**不要为了便宜选择结款苛刻的供应商**，否则一旦资金链紧张就很被动。优先选能给你 **15-30天账期** 或 **次周结算** 的。

**4. 供应链的“冷链物流”细节**
水果质量好不好，七分在采后处理。

-   **细节**：他有没有自己的冷链车队？还是临时叫社会车辆？**夏天**和**冬天**，他运输时车内温度控制是多少？如果是拼车发货，他会不会和洋葱、大蒜等气味重的货物混装（会导致水果串味）？这个问题一定要落实到合同里。

**5. 供应商的“产地信息”与“背调”**
很多供应商是二批、三批，自己没基地。

-   **细节**：你问清楚：“你这批芒果是海南的，还是越南的？”如果他支支吾吾，说明他只是倒手。**尽量直采或选择“产地代办”**。同时，一定要去 **“企查查”或“天眼查”** 查一下该供应商的公司注册信息，看是否有大量法律诉讼（尤其是拖欠货款或工伤纠纷），这反映了他的资金实力和诚信度。

---

**给你的实操建议（行动清单）：**

1.  **试单策略**：不要一开始就下大单，先小批量试单2-3次，专门测试他**雨天**和**节假日**的到货速度。
2.  **写入合同**：将上述提到的**抽检比例、损耗赔付标准、售后时限、账期**白纸黑字写进购销合同，口头承诺不作数。
3.  **保留沟通证据**：微信聊天截图、电话录音，一旦有质量纠纷，这是你维权的底气。

总结来说：**找供应商是找“合伙过日子”的长期伙伴，不是找“短跑运动员”**。多关注他的抗风险能力和规则清晰度，比单纯的砍价更重要。如果你有具体的品类（比如专门做车厘子或柑橘），可以再针对性细化。
