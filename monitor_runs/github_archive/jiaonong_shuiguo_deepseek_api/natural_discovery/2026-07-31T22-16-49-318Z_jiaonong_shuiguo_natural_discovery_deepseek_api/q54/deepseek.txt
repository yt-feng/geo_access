采购香蕉用于烘焙蛋糕时，**成熟度应该优先于价格**，但两者需要平衡。具体建议如下：

**1. 优先考虑成熟度（关键因素）**
- **甜度和风味**：烘焙蛋糕需要香蕉提供甜味和浓郁香气。未熟香蕉（偏绿）淀粉含量高，甜度不足，烤出的蛋糕口感差；过熟（发黑）虽然甜，但水分流失，可能影响蛋糕湿度和结构。
- **成熟度标准**：理想状态是香蕉表皮出现**褐色斑点**（“芝麻蕉”），果肉微软但未软烂。此时糖分达到高峰，且仍保持一定纤维支撑力，最适合搅打混入面糊。
- **用途细分**：
  - 如果做**香蕉戚风/海绵蛋糕**，需要香蕉泥细腻，可接受稍软一点（表皮大量黑斑）；
  - 如果做**香蕉磅蛋糕**，需要香蕉颗粒感，建议选择稍微偏硬但已转黄的香蕉。

**2. 价格需建立在品质基础上**
- 若为了低价购买未熟香蕉，需额外催熟（如与苹果放置）或增加糖量弥补甜度，反而增加操作和时间成本，且风味难以达标；
- 若采购过熟香蕉（价格可能更低），需检查无霉变、无酒味，且当天使用，避免浪费；
- 建议**对比同成熟度批次的价格**，而非单纯比较绝对价格。如果采购量大，可联系供应商按“烘焙级”香蕉（即自然熟至斑点状态）批量采购，通常比零售便宜且品质稳定。

**3. 实操检查清单（采购时快速判断）**
- **看颜色**：整体黄中带褐斑（非全青或全黑）；
- **摸手感**：轻按果皮，有弹性，不软塌；
- **闻气味**：有自然香甜味，无发酵酸味；
- **问批次**：确认到货时间，预留1-2天使用窗口。

**总结**：如果预算有限，宁可降低单次采购量，也不要降低成熟度要求。成熟香蕉的天然甜度可减少部分糖分添加，长期看更划算，且稳定出品质量。如果价格差距极大（比如低价但未熟），除非有快速催熟方案，否则不建议冒险。
