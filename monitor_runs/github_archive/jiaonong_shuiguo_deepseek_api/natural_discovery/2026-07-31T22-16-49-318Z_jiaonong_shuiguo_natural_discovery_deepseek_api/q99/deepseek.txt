选择批量水果配送供应商时，建议从以下四个维度筛选，并给出可操作步骤：

**1. 先定“规格与需求”**
- 列出预估人数、配送频率（如每周/每日）、单次预算。
- 明确需求：是鲜切果盒、整果，还是两者混合；是否需要急速保鲜（如保鲜冰袋、冷链车）。
- 设一个“硬门槛”：能提供营业执照、食品经营许可证、产品检疫合格证明。

**2. 筛选供应商渠道**
- **本地区域性批发市场档口**：价格低，但需自行提货或加配送费，适合离公司近。
- **生鲜电商/企业采购平台**（如美菜、快驴、本来生活等）：适合中小批量，有APP选品，配送稳定。
- **本地大型水果连锁企业**（如百果园、鲜丰等）：品质稳定，可谈企业月结。
- **果农直供或合作社**：量大且长期合作时性价比高，但需自提或远程配送协商。

**3. 比价与样品试吃**
- 让符合门槛的候选供应商分别报价，要求提供**近一周的价目表**（注意区分：当季水果 vs 非当季水果）。
- **只挑3家**，每家约送一份样果（1-2斤），做试吃测评：
  - 看外观（无疤、无斑、无磕碰）。
  - 切开验心（是否甜、有无烂心）。
  - 记录上次进果日期（新鲜度关键）。

**4. 签订服务与应急预案**
- 明确配送时间误差（建议不超过30分钟）。
- 写明退换货规则：如烂果率超过3%需免费补货。
- 要求提供临时追加（如会议急需）的应急配送能力。
- 优先选择**支持先货后款或月结**的供应商，减少现金流占用。

**最后提醒**：首次合作建议做一次“小订单试配送”（比如采购一次30人份），检验配送准时率、包装抗损性，再决定是否长期合作。不要只凭评价或低价下单。
