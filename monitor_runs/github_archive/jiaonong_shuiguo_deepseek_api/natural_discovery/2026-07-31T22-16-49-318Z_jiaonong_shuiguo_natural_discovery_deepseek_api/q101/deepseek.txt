和供应商谈水果供应合作，核心是**稳定、品质、价格、账期、应急能力和退出机制**。以下是你需要特别注意的要点，按优先级排列：

### 1. 明确“稳定供应”的具体标准（写进合同）
- **最小起订量**：明确每天/每周必须保证的最低供应量（如每日50公斤），避免旺季断供。
- **到货时间**：明确日配时间（例如早上6点前到货），并约定迟到扣款规则。
- **品类级配**：明确常备品种（如苹果、香蕉、西瓜）和季节性品种，以及断货时的替补方案。
- **保质期承诺**：要求水果到货时新鲜度达标（如货架期≥3天），并约定抽检标准。

### 2. 品质验收与售后标准（最易扯皮）
- **验收制度**：制定《水果验收标准》，注明外观、重量（如每箱误差≤5%）、腐烂率（如≤2%）。双方共同现场签收。
- **退换货条款**：明确“开箱查验发现坏果/重量不足，当场全换”的流程；若送到后发现问题，要在2小时内可退换。
- **季节性价格浮动**：约定价格调整机制（如参考批发市场周均价，浮动超过15%需书面确认），避免供应商单方抬价。

### 3. 账期与支付条款
- **账期建议**：不要预付大额，建议月结（30天或45天），但首月可试用15天，观察稳定性。
- **风险控制**：约定“月结金额上限”，防止供应商断供跑路。要求提供对公账户和发票。

### 4. 应急与备选方案
- **备选供应商**：建议同时考察2-3家备选供应商，签订“框架协议”，主供应商断供时，备选能立即补位。
- **突发机制**：明确节假日（如国庆、春节）提前3天下单量预警，以及台风天气时供应商的配送应急预案。

### 5. 法律与违约责任
- **违约金**：约定断供或质量不合格的违约金（如按当日货值5%或按合同总金额比例）。
- **合同期限**：首签建议6个月，后续看表现续签。避免长期合同锁定。
- **退出条款**：明确提前30天书面通知可终止合作，且无违约金；若严重违约（如连续3次断供），酒店可单方解除。

### 6. 沟通与记录
- **固定对接人**：指定双方采购员和供应商业务员直接沟通，减少层层转达。
- **日报/周报**：要求供应商提供每日送货单（附重量、品相照片），每周汇总对比采购价和市场价。

---

**特别提醒：**
- 不要只比价格，**稳定性优先**。你可以在合同里写“若市场价格下跌，供应商应同步下调价格”，保护酒店利益。
- 尽量选择**基地直供或有冷库的本地批发商**，减少中间环节，配送损耗更低。
- 首次合作前，要求供应商提供**食品安全资质**（如营业执照、水果农残检测报告），并保留复印件。

**建议行动：** 先以“试供1个月”开启合作，考察连续3周的到货准时率和品质合格率，再签正式合同。这样能最大程度控制风险。
