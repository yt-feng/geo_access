对于茶饮店控食品安全风险，水果供应商需要提供以下核心证明及材料，以形成完整的合规闭环：

1. **营业执照**：证明其合法经营主体资格，且经营范围需包含水果销售或配送。
2. **食品经营许可证**：如为预包装/散装食品销售，需具备有效的食品经营许可证；若供应商为农户直供，则需提供产地证明或农户身份证明及自产自销证明。
3. **产品合格证明/检验报告**：每批次水果需提供由供应商自检或委托第三方检测的**农残检测报告**，重点检测有机磷、氨基甲酸酯类等常见高毒、高风险农残项目，并确保检测在有效期内。
4. **进货查验记录**：供应商应提供其向下游提供的**供货凭证**（送货单、销售清单），单据上需列明品名、数量、生产日期/采摘日期、供应商盖章或签字，便于溯源。
5. **食用农产品承诺达标合格证**：这是当前国家推行的关键证件，要求供应商对水果质量安全做出承诺，证明其符合食用农产品合格证制度要求。

**补充建议（针对茶饮店端）：**
- **每日索证索票**：要求供应商每次送货时随货附带“每批次检验报告”和“供货凭证”，并将票据归档保存至少6个月。
- **现场或飞行抽查**：建议要求供应商提供其种植基地或进货渠道的**产地环境证明**（如土壤、水源检测报告），并至少有**冷链运输记录**（若为冷藏水果）。
- **风险管控重点**：对于茶饮店常用的柠檬、橙子、草莓等易带皮食用或高农残水果，必须重点核验其农残检测中是否包含**多菌灵、吡虫啉、高效氯氟氰菊酯**等茶饮常用品类的检测项目。

**执行提示**：若供应商无法提供以上任一核心文件（尤其是农残报告），应视为不合格供应商，当即停用并更换，同时保留换货及索赔的合同依据。如果水果用于鲜榨或直接入口（不加热），务必避免采购未附承诺达标合格证的散装水果。
