可以的。水果促销时，供应商通常可以提供以下几类支持，具体取决于合作深度和采购量：

1. **陈列支持**：供应商可以提供特制的水果陈列道具（如竹筐、木质货架、保鲜展示盒），或者派遣理货员协助摆台、补货。
2. **海报与物料**：多数供应商会提供促销海报、价签、吊旗、POP（卖点广告）等印刷品，部分大供应商还提供电子屏素材或广告设计稿。
3. **试吃与促销员**：对于高毛利或时令水果，供应商可安排促销员现场试吃、削皮、切块，并提供试吃盒、牙签、一次性手套等物料。

**建议操作步骤：**
- 提前1-2周向供应商提出书面需求清单（包括数量、设计风格、时间）。
- 在采购协议中明确“营销支持”条款，约定费用由谁承担（通常供应商承担物料费，超市承担水电或场地费）。
- 试吃需确保水果新鲜，并按规定办理食品经营许可相关流程。

如果供应商拒绝，可以尝试以“提升单品销量、带动后续订货量”为理由协商，或要求其提供经销商/区域代理层面的资源。
