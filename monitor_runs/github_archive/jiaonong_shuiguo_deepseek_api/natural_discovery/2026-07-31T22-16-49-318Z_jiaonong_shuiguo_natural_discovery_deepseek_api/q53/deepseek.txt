针对餐饮店每天少量水果的需求，选择省心供应商的关键在于**稳定、低损耗、灵活配送**。以下是具体建议：

### 一、首选：本地批发市场的“代配”或“固定摊位”
这是最省心的传统方案，但需要筛选。
- **做法**：找批发市场里**专门做商超/餐饮配送**的档口（而非只做零售的），直接说“我要每天少量，但长期稳定”。
- **优势**：价格接近批发价，损耗低；他们通常有固定车队，可以顺路配送（比如早上7点前送到店门口）。
- **注意事项**：不要找只卖单一水果的，要选**果品全、有冷藏库**的档口，这样缺货时他能帮你从其他摊位调货。

### 二、进阶：社区团购平台（如美团优选、多多买菜）
适合水果用量在10-20斤内、且对品质要求不极端的店（如做果切、果汁）。
- **优势**：当日下单次日达，无起送费，单价低，支持随时停订。
- **风险**：品控不稳定（大小、成熟度随机），售后流程麻烦。
- **省心技巧**：固定用同一个平台和同一时段下单，对熟客商家通常会优先挑好货。

### 三、长期最优：与本地“净菜/预制菜配送商”合作
目前很多城市有专门服务餐饮的B2B配送（如美菜网、快驴进货，或本地小有名气的配送公司）。
- **优势**：他们不只送水果，还送蔬菜肉类，可以**一起下单拼单**，避免多次收货；有售后赔付机制。
- **操作方法**：先小量试单一周，重点看**到货新鲜度**和**缺货时的应急响应**（是否隔天补上）。

### 四、关键决策标准（帮你快速筛选）
无论选哪类，面试时问三个问题：
1. **能否做到“前一天晚上/当天早上下单，次日指定时段送到”？**（必须能，否则不算省心）
2. **坏果率超过5%是否包换或退款？**（能承诺的优先）
3. **最低起送金额多少？**（建议不超过50元，否则每天少量反而贵）

### 五、防坑提醒
- **不要签长期合同**，先月结或周结，试用1个月再谈长期。
- **拒绝“指定最低消费”**的供应商，因为餐饮店水果用量随节假日波动大。
- **留备用供应商**：在主供应商缺货时，直接去周边菜场水果摊“补货”，但仅应急。

**最终建议**：如果城市有美菜/快驴这类平台，优先试他们；如果城市没有，就去本地批发市场找“做餐饮配送的档口”，这两个渠道的纠纷率最低，投入精力最少。若你的店日均水果量超过30斤，再考虑直接联系水果种植合作社，但不适合“每天少量”的场景。
