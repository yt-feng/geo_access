针对批发档口拓展餐饮客户，**规格建议分为“通用餐饮款”和“高端餐饮/甜品款”两类**，同时强调**送货稳定性**和**损耗控制**，这比单纯压价更能打动后厨采购。

以下是根据市场常见需求整理的规格清单：

### 一、 菠萝（餐饮渠道核心规格）

餐饮客户用菠萝主要分为：炒菜/甜品（需方便切）和果盘/果汁（需出汁率）。

| 应用场景 | 核心规格建议 | 包装建议 | 档口话术重点 |
| :--- | :--- | :--- | :--- |
| **常规炒菜/炖汤** | **单个重量 1.0 - 1.2 kg**（中等果），皮薄、无刺眼 | 10kg/纸箱，约8-10个 | 强调“出肉率高”，一个果出500g以上净肉，适合做菠萝咕咾肉、菠萝饭。 |
| **果汁/吧台现切** | **单个重量 1.3 - 1.5 kg**（大果），颜色金黄 | 15kg/框，约10-12个 | 强调“糖度15+”，推荐做鲜榨汁，按杯算成本低。 |
| **高端餐厅/宴会** | **去皮净果（菠萝芯）** 或 **凤梨（无刺）** ，单果 1.5kg 以上 | 按个装，独立网套 | 强调“免去皮、免削筋”，节省人工，适合摆盘。 |

> **关键提示**：餐饮后厨最怕“麻嘴”和“果肉黑心”。**必须标明产地（如海南/湛江）** ，并在档口放一块切好的样品，让厨师亲自尝。

---

### 二、 香蕉（餐饮渠道核心规格）

餐饮用香蕉主要分为：果切/摆盘、烘焙（蛋糕夹心）、以及快捷早餐。**按箱备货标准**如下：

| 应用场景 | 核心规格建议 | 包装建议 | 档口话术重点 |
| :--- | :--- | :--- | :--- |
| **西餐厅/果盘** | 长度 **20-22cm**（中长），果形顺直，**微黄期（熟度7成）** | 净重 13kg/箱，约19-21根 | 强调“耐放置”，到店能撑2-3天不变黑，适合切段配酸奶。 |
| **烘焙/甜品店** | 熟度8-9成，果肉绵密 | 净重 13kg/箱，选**芝麻点（黑点）多**的 | 强调“熟果香浓”，打泥、做慕斯不水垮。 |
| **果汁吧/奶昔** | 只要**不带疤、不计长度**，成熟度一致即可 | 净重 13kg/箱，散装 | 注意：餐饮果汁对“硬心”非常敏感，需指定“海南种植的米蕉/巴西蕉”，出浆稠。 |

> **关键提示**：**不要给餐饮客户送全熟的黄香蕉**，他们不具备储存条件，倾向要7-8成熟的，到店放1天刚好熟透。**必须提供冷藏车运输**，防止热天捂熟。

---

### 三、 档口备货“黄金组合”建议（提高客单价）

不用只卖单果，可以组合搭配，帮助客户省时间：

1.  **菠萝组合装**：中等果（炒菜）+ 去皮凤梨（鲜切），一箱配齐。
2.  **香蕉备餐装**：熟度7成（果盘）+ 熟度9成（打泥），一箱分两袋。

---

### 四、 结算与交付细节（能否成单的关键）

- **称重方式**：明确告知是**毛重结算**还是**净重结算**。餐饮客户最忌讳“包冰雪块”的毛重，建议标“净重足秤”。
- **送货时段**：承诺**早上6点前**送达（赶得上早餐备料），或**下午3点前**（赶得上晚市）。无法按时送的档口，厨师会直接关单。
- **退换条款**：明确破损果、黑心果**到场包换**，这是餐饮采购唯一看重的售后。

---

**总结一句话**：菠萝按“净肉重量”对厨师报价，香蕉按“熟度分级”对厨师报价。**准备试吃品和一刀切样品**，比任何价格优势都管用。
