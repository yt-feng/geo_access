判断供应商能不能按时到车，核心是看“履约能力”和“违约成本”，而不是听口头承诺。可以按下面几步做：

**1. 先看历史履约记录**
- 问最近3个月给哪些市场/档口发过车，能不能给2-3个可核实的联系人。
- 重点问：准点率、迟到一般多久、有没有临时换车/换货/坐地起价。
- 新供应商如果没有任何可核实记录，第一次别给大单。

**2. 看货源和装车组织能力**
- 香蕉是否自有基地、长期合作基地，还是临时市场调货。临时调货的最容易掉链子。
- 有没有固定装车工、固定车队。旺季找不到车、装工不够，都会导致延迟。
- 问清楚：从砍蕉/催熟到装车要多久，是否受天气、节假日影响。

**3. 合同里把“按时到车”写死**
- 明确到车时间，最好精确到“某日几点前到某市场”。
- 写清延迟赔付：比如每延迟几小时扣多少、超过多少小时可拒收或降价。
- 写清替代方案：车坏/堵车/天气原因时，供应商多久内告知、是否负责调备用车。
- 写清违约成本要高于他临时高价卖给别人赚的差价，否则约束力不够。

**4. 用定金和付款节奏控制风险**
- 不要全额预付。常见做法：小额定金+到车验货后付尾款。
- 第一次合作可要求货到市场、验完质量再付大部分款。
- 如果供应商坚持全款才发车，说明他要么资金紧，要么对你没信心，风险偏高。

**5. 发车前做三次确认**
- 装车前1天：确认货源、车号、司机电话、预计发车时间。
- 装车当天：要装车视频/照片、过磅单、车牌。
- 发车后：每4-6小时更新位置，临近到车前2小时再确认。
- 只要有一环含糊，比如不给车号、不给司机电话、反复说“快了”，就要警惕。

**6. 看几个危险信号**
- 报价明显低于市场，还承诺随时有车。
- 不愿签合同、不愿写到车时间和赔付。
- 要求全款、私账转账、不给公司主体信息。
- 发车前临时说“要加钱才走”或“换一车”。
- 司机和供应商说法不一致，车号反复变。

**7. 最稳的做法**
- 新供应商先小批量试一车，验证准点率和质量。
- 同时备1-2个备用供应商，别把旺季押在一家。
- 大单可以派人到装车现场，或找当地靠谱代办盯装车。

一句话：**能提供可核实历史、敢签准点赔付、愿意小单试合作、发车前信息透明的供应商，才相对可靠。** 只靠口头保证的，默认按高风险处理。
