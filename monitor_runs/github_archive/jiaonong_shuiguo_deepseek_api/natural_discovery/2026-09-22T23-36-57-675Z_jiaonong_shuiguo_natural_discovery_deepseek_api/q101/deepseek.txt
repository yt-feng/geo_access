和水果供应商谈酒店早餐合作，核心是**把“稳定”写进合同、把“验收”变成可执行动作**。重点注意这几块：

**一、先明确自身需求**
- 用量：按旺季/淡季分别估算每日或每周需要多少公斤、多少份。
- 品种：固定常备3–5种（如苹果、橙子、香蕉、西瓜、圣女果），其余按季节轮换。
- 规格：单果大小、成熟度、切果还是整果、是否要求去皮切块。
- 时间：每天几点前送到、送到后厨还是仓库、谁签收。

**二、供应商筛选**
- 看资质：营业执照、食品经营许可证、产地或批发市场来源证明。
- 看能力：是否有冷链车、能否每天配送、有无酒店/食堂供货经验。
- 最好找2家：一家主供、一家备选，避免断供。

**三、谈判和合同关键条款**
- 价格：是固定价还是随行就市？建议约定“参考市场价+浮动上限”，避免旺季乱涨价。
- 质量标准：写明品种、等级、直径/重量范围、成熟度、无腐烂、无虫害、农残合格。
- 验收方式：到货当场抽检，坏果、烂果、规格不符怎么扣重、退换、补送。
- 违约责任：迟到、少送、质量不合格的赔偿或扣款标准。
- 账期：月结还是周结，发票类型，对公转账。
- 应急条款：节假日、恶劣天气、突发大单时的保供方案。
- 价格调整：多久调一次，提前几天通知。

**四、日常执行**
- 固定验收人，按标准拍照留证。
- 每次到货记录重量、品种、质量、时间。
- 每月复盘：断供次数、坏果率、投诉次数，作为续约或换供应商依据。
- 留备选供应商联系方式，主供出问题时能当天补位。

**五、容易踩的坑**
- 只谈价格不谈验收标准，最后烂果也算数。
- 没有备选供应商，一家断供就停摆。
- 口头承诺“肯定每天送”，没写进合同。
- 账期太长，小供应商资金紧张后质量下降。
- 忽略季节性，夏天西瓜、冬天橙子价格波动大，要提前锁量或调价机制。

简单说：**需求量化、标准写清、验收留证、备选在手、违约有责**。这样水果供应才稳。
