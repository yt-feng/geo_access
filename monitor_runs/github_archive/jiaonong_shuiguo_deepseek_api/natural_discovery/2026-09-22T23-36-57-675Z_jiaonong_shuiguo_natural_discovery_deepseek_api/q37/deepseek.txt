商超做会员日水果活动，供应商要提前配合的重点不是“多送点货”，而是把**爆量、损耗、价格形象、现场不断货**这四件事兜住。可按下面清单准备：

1. **确认活动方案与单品**
   - 明确活动日期、时段、限购规则、会员价/组合价。
   - 确认引流款、利润款、形象款分别是哪些水果。
   - 对每个单品确认规格、等级、产地、包装形式。

2. **提前锁定货源与产能**
   - 活动前至少提前7—15天锁定主力单品货源，进口/反季品更早。
   - 确认产地天气、采摘、加工、物流是否会影响到货。
   - 对爆款准备备用产区或替代规格，避免临时断供。

3. **按活动量备货，而不是按日常量备货**
   - 根据商超预估销量、去年同期、门店数、会员数，分解到各店。
   - 生鲜按“活动预估量+安全库存”备，但不宜一次性压太多，防止损耗。
   - 对叶菜类、浆果类、切果类，安排多批次到货。

4. **分批次、分门店配送**
   - 活动前1—2天先到基础陈列量。
   - 活动当天早晨补高峰量，避免前一天全部到店导致损耗。
   - 对远距离门店优先安排，保证开门前完成上架。

5. **品质标准提前统一**
   - 明确糖度、果径、成熟度、色泽、瑕疵率、单果重等验收标准。
   - 到店成熟度要适合当天销售，不能太生也不能太熟。
   - 对易压伤水果加强托盘、隔层、防震包装。

6. **包装与预加工配合**
   - 如果做会员专享装、家庭装、果切、拼盘，提前确认包材、标签、条码。
   - 预包装水果要提前完成称重、贴标、封口，减少门店现场压力。
   - 确认会员价标签、促销爆炸贴、价签由谁提供。

7. **价格与费用确认**
   - 明确供货价、活动价、毛利承担、损耗承担、返利或补贴方式。
   - 确认是否收取进场费、堆头费、DM费、试吃损耗费。
   - 所有价格和费用最好书面确认，避免活动后扯皮。

8. **人员与现场支持**
   - 爆量门店安排供应商促销员、理货员或督导。
   - 提前培训试吃、叫卖、补货、挑拣、折价处理流程。
   - 明确谁负责开箱、上架、挑烂、补货、收档。

9. **试吃与营销物料**
   - 提前准备试吃果、牙签、手套、托盘、垃圾桶。
   - 提供产品卖点：甜度、产地、口感、适合人群、食用建议。
   - 配合商超做堆头、端架、冷柜陈列，突出会员价。

10. **损耗与应急预案**
   - 约定临期、破损、滞销果的处理方式：折价、果切、员工内购、退货。
   - 准备备用车辆、备用货源、备用包材。
   - 如果出现断货，优先保引流款和会员专享款。

11. **数据与复盘准备**
   - 提前确认要统计的数据：到货量、销量、损耗、售罄时间、缺货门店。
   - 活动后24—48小时内复盘，判断哪些单品值得下次继续做。
   - 对表现好的单品锁定下一档期资源，对损耗高的调整订货模型。

简单说，供应商要提前做到：**货锁死、量分好、质达标、价说清、人到场、损耗有出口、断货有预案**。其中最关键的是：爆款不断货、品质稳定、损耗可控、费用不扯皮。
