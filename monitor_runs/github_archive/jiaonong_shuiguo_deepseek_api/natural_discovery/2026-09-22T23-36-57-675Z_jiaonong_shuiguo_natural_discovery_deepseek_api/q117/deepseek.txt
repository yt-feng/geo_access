先试卖多少，没有一个固定数字，核心不是“先定多少斤”，而是先定**试卖周期、试卖点数量、损耗和复购判断标准**。给你一个可直接执行的判断框架：

**1. 起步量按“最小可测试单位”来**
- 单个门店/档口：先拿 **1—3 箱**，或 **20—50 公斤**，具体看单箱规格。
- 如果只在一个点试：控制在 **1—2 天能卖完**的量，不要压 5—7 天。
- 如果多店同时试：单店仍按 1—3 箱，不要因为总量大就单店加量。

**2. 更稳的做法是“少量多次”**
- 第 1 次：只订 **1 箱/1 件**，看外观、口感、损耗、顾客问不问。
- 第 2 次：如果 1 天内卖完且没有明显投诉，加到 **2—3 箱**。
- 第 3 次：如果连续 2—3 天动销稳定，再考虑按正常采购量的 **20%—30%** 试跑一周。

**3. 判断能不能加量的硬指标**
- 动销：上架后 **24—48 小时内卖出 70% 以上**。
- 损耗：腐烂、压伤、失水等报损 **低于 5%—8%**。
- 复购：有顾客问“还有没有”或重复购买，比单纯说好吃更有价值。
- 毛利：扣掉损耗后仍有合理毛利，不是靠低价硬拉。
- 售后：投诉率低，没有集中反映口感、成熟度、大小不符。

**4. 这些情况不要加量**
- 48 小时卖不到一半。
- 损耗超过 10%。
- 顾客只夸便宜，不问复购。
- 供应商要求一次拿大批量才给低价。
- 新品和现有主力品类严重打架，只是左手倒右手。

**5. 和供应商谈试卖时的建议**
- 先谈 **小批量试销价**，不要一上来锁大货。
- 明确售后：坏果怎么赔、损耗谁承担、几天内可退换。
- 问清到货成熟度、储存温度、最佳售卖期。
- 如果供应商愿意配合，最好做 **两批到货**，而不是一次发一大批。

**一句话结论：**
单店第一次试卖，控制在 **1—3 箱或 1—2 天能卖完的量**最稳；卖得动再加到 **2—3 箱**，连续稳定后再按正常量的 **20%—30%** 放量。真正决定稳不稳的，不是首单多少，而是 **48 小时动销、损耗率、复购和售后**这四个指标。
