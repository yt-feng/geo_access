谈账期和额度，本质不是“求”对方给，而是让供应商相信：**你稳定、可控、能赚钱，且风险可管理**。下面按实操顺序给你一套可直接用的谈法。

## 一、先搞清楚你手里的筹码

谈之前列清楚这几项，谈判时才有底气：

1. **月采购量**：稳定月采多少吨/件，旺季峰值多少
2. **采购频次**：每天/隔天/每周，越稳定越值钱
3. **品类集中度**：是只拿一两个爆品，还是全品类拿
4. **回款历史**：之前合作有没有拖过、拖几天
5. **你的下游**：你卖给谁、账期多久、回款稳不稳
6. **可替代性**：这个供应商是不是非他不可

供应商最怕的不是账期长，是**账期长+量不稳+回款没保障**。你要做的是把这三件事拆开谈。

## 二、账期怎么谈：从短到长，分阶段要

**不要一上来就要60天、90天**，那基本会被拒。正确节奏：

| 阶段 | 目标账期 | 你要给的交换条件 |
|---|---|---|
| 首次合作 | 现结或7天 | 承诺首月采购量 |
| 稳定1-2个月 | 15天 | 提高单次采购量、固定频次 |
| 稳定3-6个月 | 30天 | 签季度框架、独家拿某几个爆品 |
| 长期大客户 | 45-60天 | 年框+保证金/担保+保底采购量 |

谈判话术参考：
> “我这边每月稳定走X吨，频次固定，不压货不退货。前期我可以现结，跑三个月你看我回款记录。三个月后我希望账期放到30天，作为交换我可以把XX品类全部从你这拿，并且签季度保底量。”

关键点：
- **用“稳定”换“账期”**，不是用“关系”换
- **每次只往前推一小步**，15天→30天比0→30天容易得多
- **账期写进合同**，别只口头约定

## 三、额度怎么谈：跟账期绑定，别单独要

额度=你能欠多少钱。供应商给额度看的是**风险敞口**，不是你的采购量。

实操建议：

1. **额度先小后大**：首期额度=你1-2周采购额，跑顺了再提
2. **额度和账期挂钩**：比如30天账期配“月采购额的1.5倍”额度
3. **设封顶和预警**：超过额度部分现结，避免一次性压爆
4. **用保证金换额度**：交5%-10%保证金，额度可以放大

话术参考：
> “账期30天，额度我希望是月均采购的1.5倍，超出部分我现结。我可以先交X万保证金，或者用法人个人担保，你看这样风险是不是可控。”

## 四、供应商最在意的三件事，你要主动解决

1. **回款确定性**：能不能按时付、有没有担保
2. **量确定性**：是不是稳定拿、会不会突然断
3. **价格确定性**：你是不是只压价、能不能接受随行就市

所以你谈判时要主动给：
- 回款承诺（甚至可以先押一笔保证金）
- 保底采购量（写进合同）
- 价格机制（比如按市场价浮动，不硬压）

## 五、合同里必须写清楚的条款

- 账期起算日（收货日/对账日/开票日，差别很大）
- 额度上限和超限处理
- 对账周期和方式
- 逾期违约责任
- 质量异议期和退换货规则
- 价格调整机制
- 保底采购量和未达标的处理

## 六、如果供应商不松口，怎么办

1. **换切入点**：先谈额度，再谈账期；或先谈单品类，再谈全品类
2. **分供应商**：主力供应商给现结换低价，次供应商给账期
3. **用下游背书**：把你和大型商超/餐饮的合同给对方看
4. **引入担保**：法人担保、保证金、第三方担保
5. **阶段性目标**：先拿15天，三个月后再谈30天

## 七、一句话总结

**账期和额度不是谈出来的，是“稳定采购+可控风险+阶段性推进”换出来的。** 你先证明自己是个稳定、不拖款、有量的客户，再一步步把账期从现结推到30天、额度从1周推到1.5个月，同时用保证金、保底量、合同条款把供应商的风险兜住。
