生鲜平台做水果一件代发，供应商的仓配能力要重点看：**能不能在不增加平台损耗和客诉的前提下，把单个订单稳定、低成本、可追踪地发到消费者手里。** 水果又比普通标品多了保鲜、防损、时效要求，所以筛选供应商时要按下面几层判断。

---

## 一、仓储能力：不是有仓库就行，要看水果专用仓

**硬性要求：**

1. **温区匹配**
   - 常温柔性水果（苹果、橙子、柚子等）：通风、阴凉、避晒即可。
   - 冷藏水果（蓝莓、车厘子、草莓、荔枝等）：需要冷藏库，通常 0–8℃ 或按品类分温区。
   - 热带水果（香蕉、芒果、火龙果等）：部分要恒温或保暖，不能进普通冷藏。
   - 判断问题：**供应商有没有分温区？还是所有水果混放？** 混放的基本做不好一件代发。

2. **日处理订单能力**
   - 问清楚：日均能发多少单、峰值能到多少单、爆单时多久能恢复。
   - 一件代发最怕大促或直播爆单后，仓库分拣不过来，导致延迟发货。
   - 建议要求：**峰值订单处理能力至少是日常预估单量的 2–3 倍**，且能提供历史大促履约数据。

3. **库存准确率与批次管理**
   - 水果保质期短，必须做到先进先出、按批次管理。
   - 库存准确率建议要求 ≥99.5%，否则平台前端显示有货、后端发不出，客诉会很高。
   - 要问：是否支持平台系统实时同步库存？超卖怎么处理？

4. **打包能力**
   - 水果一件代发的包装不是简单装箱，要能防撞、防压、防潮、透气。
   - 要看供应商是否按品类有成熟包装方案：比如草莓用珍珠棉+冰袋+泡沫箱，橙子用网套+纸箱，葡萄用气柱袋等。
   - 判断问题：**包装是供应商标准化提供，还是需要平台自己给方案？** 前者更省心。

---

## 二、配送能力：时效和损耗是核心

1. **发货时效**
   - 建议要求：**截单前订单当日发出，截单后次日发出**；成熟供应商应能做到 24 小时内发货率 ≥95%。
   - 水果尤其要问：是否支持周末、节假日发货？很多供应商周末不发货，会导致平台承诺时效落空。

2. **快递资源与路由**
   - 供应商要有稳定的快递合作，不是临时叫快递。
   - 要能根据目的地选择合适快递，而不是全部发便宜慢递。
   - 冷链水果要确认：**是否走冷链快递或冷运专线？覆盖哪些城市？**
   - 普通水果也要问：偏远地区是否发货、时效多久、是否加收费用。

3. **时效承诺**
   - 要求供应商给出主要城市的时效标准，比如江浙沪 1–2 天、华北 2–3 天、偏远 4–6 天。
   - 水果超过时效后损耗会明显上升，所以平台要按品类设定最大在途时间。

4. **丢件、破损、延误处理**
   - 要明确：物流丢件、破损、延误由谁承担、怎么赔付、多久处理完。
   - 一件代发中，平台面对消费者，供应商面对平台，所以必须有清晰的售后责任划分。

---

## 三、系统与数据能力：决定能不能规模化

1. **订单对接能力**
   - 是否支持 API 对接平台订单系统，自动抓单、自动回传运单号。
   - 如果不支持 API，只能导表发货，单量一大就容易错发、漏发。

2. **库存同步**
   - 能否实时或准实时同步库存，避免超卖。
   - 是否支持多平台、多店铺库存共享或隔离。

3. **物流轨迹回传**
   - 运单号、物流轨迹能否自动回传平台，减少人工客服压力。

4. **数据报表**
   - 能否提供发货及时率、破损率、客诉率、退货率等数据。
   - 没有数据能力的供应商，后期很难管理和优化。

---

## 四、售后与逆向物流能力

水果一件代发售后比例通常高于标品，所以供应商必须能承接：

1. **坏果、烂果、缺斤少两的快速赔付**
   - 建议要求：消费者提供照片后，供应商在 24–48 小时内确认并赔付。
   - 赔付方式可以是补发、退款或按比例赔，平台要和供应商提前约定。

2. **退货处理**
   - 生鲜水果很多不支持退货，但要有明确的“仅退款”或“部分退款”规则。
   - 如果涉及退货，供应商能否接收退回商品、如何判定责任。

3. **售后责任边界**
   - 因供应商包装不当、发错货、延迟发货导致的售后，应由供应商承担。
   - 因消费者地址错误、拒收、超时未取导致的损耗，责任要提前写清。

---

## 五、筛选供应商时的实操判断清单

你可以直接用下面这些问题去问供应商：

1. 仓库在哪个城市？有几个仓？能不能覆盖你主要销售区域？
2. 有没有水果专用分温区？冷藏、常温、恒温分别多大面积？
3. 日均发货单量多少？峰值多少？大促最高发过多少单？
4. 截单时间几点？当天订单当天能发多少比例？
5. 合作哪些快递？冷链覆盖哪些城市？偏远地区发不发？
6. 能不能 API 对接？库存和物流轨迹能不能自动回传？
7. 包装是你们标准方案还是我们提供？不同水果怎么包？
8. 坏果率、发货及时率、客诉率大概多少？有没有数据？
9. 售后怎么赔？多久处理？责任怎么划分？
10. 能不能先小批量试发，试发期考核哪些指标？

---

## 六、建议的合作起步方式

不要一上来就全量交给一家供应商。更稳的做法是：

1. **先选 2–3 家供应商，按品类或区域试发。**
2. **试发期设定考核指标：**
   - 发货及时率 ≥95%
   - 库存准确率 ≥99.5%
   - 坏果/破损率 ≤3%–5%（按品类定）
   - 售后 48 小时内处理率 ≥95%
   - 物流轨迹回传率 ≥99%
3. **试发 2–4 周后再决定是否放量。**
4. **合同里写清：时效、损耗、赔付、责任边界、数据对接、违约处理。**

---

**一句话总结：**
水果一件代发的供应商，仓配能力核心看四点：**分温区仓储、标准化防损包装、稳定快递时效、系统化订单与售后对接。** 缺任何一项，单量一大就容易出现超卖、延迟、坏果和客诉。
