做水果生意，供应商选择最容易忽视的往往不是“价格”或“产地”，而是那些日常不显眼、但一旦出问题就会导致持续损耗的细节。按重要性排序，主要有这几类：

1. **实际到货稳定性，而不是样品质量**
   很多供应商样品很好，但批量发货时等级混杂、成熟度不一。要看他能不能做到同一批次内规格一致，而不是只看首单。

2. **采后处理与冷链衔接**
   水果损耗大头在采后。问清楚：采摘后多久预冷、是否分级、包装是否带冰袋/冷链车、运输途中温度记录。没有预冷和冷链，再好的果子也会在途中软烂。

3. **账期与结算灵活性**
   长期合作最怕现金流被压死。要明确：是现结、周结还是月结，是否支持部分退换，坏果怎么扣款。很多小供应商口头答应，实际结算时扯皮。

4. **坏果赔付标准是否可执行**
   不要只听“包赔”，要问：按箱赔还是按斤赔？需要拍照还是必须退回？赔付时效多久？标准模糊的，最后往往是你自己承担损耗。

5. **供货的季节性替代方案**
   只靠一个产地或一个品种，淡季就断供。好的供应商能提前告诉你：这个品下市后，替代品是什么、价格区间多少、品质差异在哪。

6. **包装与物流适配你的销售场景**
   你如果做社区团购，需要小规格、耐搬运；如果做水果店，需要陈列好看。供应商的包装是否匹配你的渠道，直接影响上架效率和损耗。

7. **沟通响应速度与异常处理态度**
   长期合作中，突发情况（天气、物流延误、品质波动）必然出现。看他是否主动预警，而不是等你发现后再解释。响应慢的供应商，一次断货就可能流失客户。

8. **是否愿意共享市场信息**
   靠谱的供应商会告诉你今年产区气候、产量预期、价格走势，帮你提前备货或调整品类。只报价、不交流的，你永远被动。

简单判断方法：不要只看他给你的报价单，要看他过去三个月给其他客户的发货记录、退赔记录和异常处理记录。能提供这些的，通常更值得长期合作。
