便利店上架香蕉，建议优先选 **单根 + 小把（2–3根）组合**，整袋只作为补充，不建议作为主包装。理由如下：

1. **便利店消费场景是“即时、少量、单人”**
   - 顾客进便利店买香蕉，通常是马上吃、一个人吃、顺手带。
   - 单根最好卖，决策成本最低，适合收银台旁、便当区、酸奶区旁边做冲动消费。
   - 小把（2–3根）适合两个人吃或搭配早餐，客单价略高。

2. **整袋适合家庭，但便利店客流不匹配**
   - 整袋（5–6根以上）更适合社区生鲜店、超市、家庭采购。
   - 便利店如果放整袋，容易卖不完，香蕉熟得快，损耗会明显上升。
   - 除非门店在住宅区、下班人流大，且能稳定日清，否则整袋风险高。

3. **香蕉损耗是核心问题**
   - 香蕉后熟快，表皮变黑、压伤、掉把都会影响售卖。
   - 单根和小把更容易按成熟度分级：青一点的做小把，熟一点的拆单根促销。
   - 整袋一旦其中一根坏了，整袋都难卖。

4. **建议的具体做法**
   - **主推单根**：定价略高于按斤折算，顾客能接受，因为方便。
   - **搭配小把 2–3 根**：用保鲜膜或扎带固定，放在早餐、酸奶、三明治旁边。
   - **整袋少量试销**：只放在住宅区门店或晚间家庭客流明显的时段，且控制在 3–5 根小袋。
   - **按成熟度动态调整**：青的做小把，熟的拆单根，过熟的做香蕉奶昔原料或打折清货。

5. **如果只能选一种**
   - 选 **单根**。便利店最稳的是低决策、低损耗、即时消费。
   - 如果门店在社区且家庭客多，再逐步加 **小把**，最后才考虑整袋。

简单判断：  
**单根保销量，小把提客单，整袋看社区。** 便利店起步，先上单根和小把，整袋谨慎试。
