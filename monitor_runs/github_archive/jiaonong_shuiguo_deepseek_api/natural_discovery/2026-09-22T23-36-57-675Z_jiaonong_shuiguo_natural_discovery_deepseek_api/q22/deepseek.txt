可以做“引流品+利润品+关联品”组合，但关键不是简单捆绑，而是用香蕉引流、菠萝做场景、苹果做毛利承接。下面给你一套可直接落地的方案。

**一、组合逻辑**
- **香蕉**：价格敏感、购买频率高，适合做引流和凑单。
- **菠萝**：有场景感，适合做“切好即食/搭配酸奶/烧烤解腻”，能拉高客单。
- **苹果**：日常刚需、耐储存，适合做家庭装、礼盒装、加购装，承担利润。

**二、3个可执行促销组合**

**1. 家庭果盘组合：香蕉+菠萝+苹果**
- 内容：香蕉1把 + 菠萝1个（可代削）+ 苹果4个
- 定价：比单买合计便宜10%—15%，但设置“加3元换购酸奶/果切盒”
- 目的：从“买一样”变成“买一套”，再用换购拉高客单。
- 适合：周末、晚间家庭采购时段。

**2. 早餐/减脂场景组合：香蕉+苹果+即食菠萝**
- 内容：香蕉3根 + 苹果3个 + 菠萝切盒1盒
- 定价：做成固定价，例如9.9/12.9/19.9元，按门店客群定
- 目的：打“早餐、代餐、办公室下午茶”场景，提升便利性溢价。
- 适合：社区店、写字楼附近门店。

**3. 分级促销：香蕉引流，苹果赚钱，菠萝加购**
- 香蕉：限时低价，每人限购1把，负责把人拉进来。
- 苹果：买3斤送1斤，或第二件半价，主推家庭装。
- 菠萝：凡买香蕉+苹果满额，加5元换购菠萝切盒或整果。
- 目的：香蕉不赚钱甚至微亏没关系，靠苹果和菠萝把客单拉起来。

**三、陈列和话术**
- 陈列：香蕉放端头引流，苹果放主通道，菠萝和切盒放收银动线附近。
- 标识：不要只写“特价”，要写场景，例如：
  - “早餐三件套：香蕉+苹果+菠萝”
  - “买苹果满20元，加5元换菠萝”
  - “家庭果盘组合，比单买省X元”
- 员工话术：  
  “香蕉今天特价，苹果家庭装也划算，再加5元可以换菠萝切盒，回去直接吃。”

**四、避免踩坑**
- 不要三个都降价，否则毛利撑不住。
- 不要强制捆绑难卖品，菠萝要提供代削/切盒，否则很多人嫌麻烦。
- 组合价要算清损耗，尤其香蕉和菠萝损耗高。
- 每天看三个指标：组合购买率、客单价、毛利额。若客单价涨但毛利额不涨，说明折扣过深。

**五、最推荐先试的一版**
“香蕉特价引流 + 苹果满20元 + 5元换购菠萝切盒”。  
这套最简单，执行成本低，能同时测试引流、加购和客单提升效果。
