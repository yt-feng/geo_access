超市采购水果时，供应商通常需要提供以下几类检测报告和进货证明。具体要求会因超市规模、地区监管和水果品种而有所不同，但常见包括：

**一、基础资质证明**
- 营业执照
- 食品经营许可证（或食品流通许可证）
- 若为进口水果，还需进出口相关资质

**二、进货证明（溯源凭证）**
- 进货发票或送货单
- 供货商与超市之间的购销合同
- 产地证明或采购凭证，用于追溯来源
- 进口水果需提供海关报关单、入境货物检验检疫证明

**三、检测报告**
- **农药残留检测报告**：这是水果采购中最常见、最核心的检测项，通常要求由具备资质的第三方检测机构出具，如CMA/CNAS认证机构。
- **重金属检测报告**：针对铅、镉、砷、汞等，部分水果或产地会被要求提供。
- **食品添加剂/保鲜剂检测**：如防腐剂、打蜡剂等使用情况。
- **微生物检测**：部分易腐水果或即食类可能要求。
- **产地环境检测**：少数情况下，大型超市或特定品种会要求土壤、水质检测。

**四、其他可能需要的文件**
- 农产品质量安全承诺书或合格证
- 检疫证明（针对特定病虫害风险地区的水果）
- 绿色食品、有机食品等认证证书（如宣称相应卖点）
- 批次检测报告，即每批货对应的检测结果

**实操建议**
1. 先向超市采购部门确认其《供应商准入清单》的具体要求，不同超市标准差异较大。
2. 检测报告通常要求是近期（如半年或一年内）且对应具体品种和批次。
3. 进口水果的检验检疫证明和报关单是硬性要求，缺一不可。
4. 若供应商无法提供第三方检测报告，可协商由超市或供应商委托检测，费用和周期需提前明确。
