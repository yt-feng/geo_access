连锁商超找长期水果供应商，招标评分标准建议按“资格门槛 + 综合评分”两层设计：先用资格门槛筛掉不达标的，再用评分选最优的。水果和普通标品不同，损耗高、季节波动大、品质不稳定，评分权重要向“品质稳定性、供应保障、损耗控制、长期合作能力”倾斜，而不是单纯比价格。

下面给一套可直接套用的框架。

## 一、先设资格门槛（不达标直接淘汰）

这些不作为评分项，作为准入条件：

1. 具备合法经营资质：营业执照、食品经营许可证、种植/养殖相关资质（如自有基地）。
2. 有稳定货源：自有基地或长期合作基地，能说明产地、品种、面积/产能。
3. 有商超或大型渠道供货经验：至少1-2个同类客户，能提供合同或证明。
4. 有检测能力或第三方检测报告：农残、重金属等符合国标。
5. 有冷链/仓储/配送能力：能覆盖目标门店，承诺到货时效。
6. 无重大食品安全事故、无严重失信记录。

## 二、综合评分建议（100分制）

### 1. 价格与成本（20-25分）
- 报价合理性、价格构成是否透明（产地价、包装、运费、损耗分担）。
- 是否接受价格联动机制：随季节/行情调整，而不是一口价。
- 注意：水果价格波动大，不建议“最低价中标”，否则后期容易断供或降质。

### 2. 品质与稳定性（25-30分，权重最高）
- 品种规格是否符合要求（糖度、大小、色泽、成熟度）。
- 供货品质稳定性：是否有分级标准、抽检合格率、历史退货率。
- 是否提供样品并接受盲测/试销。
- 农残检测、溯源能力。

### 3. 供应保障与履约能力（20-25分）
- 产能是否匹配商超需求量，旺季能否保供。
- 配送时效、冷链覆盖率、缺货应急方案。
- 是否有替代产地/备用货源，抗自然灾害和季节波动能力。
- 历史履约记录：准时交付率、订单满足率。

### 4. 损耗控制与物流方案（10-15分）
- 包装方式、冷链方案、到店损耗率承诺。
- 是否接受损耗分担或退换货机制。
- 配送频次与门店覆盖能力。

### 5. 合作与服务能力（10-15分）
- 是否愿意长期合作，接受账期、结算方式。
- 售后服务：质量问题响应速度、退换货处理。
- 是否有专人对接、信息化对接能力（订单、库存、溯源）。
- 能否配合促销、定制包装、新品导入。

### 6. 企业实力与可持续性（5-10分）
- 基地规模、资金实力、抗风险能力。
- 食品安全管理体系、认证（如GAP、ISO22000）。
- 社会责任、环保、可持续种植等加分项。

## 三、评标时建议注意的几点

1. **价格分不要过高**：水果非标品，低价往往意味着后期降质或断供，建议价格权重不超过25%。
2. **设置试供期**：中标后先试供1-3个月，按实际到货合格率、损耗率、履约率考核，再决定是否转长期合同。
3. **评分要可量化**：比如“品质稳定性”不要只写“好”，要写“抽检合格率≥98%得满分，每低1%扣X分”。
4. **引入动态考核**：长期合同不是一签了之，建议按季度/年度考核，设淘汰和替补机制。
5. **多家并存**：可设主供应商+备选供应商，避免单一依赖，尤其水果受季节和天气影响大。
6. **明确验收标准**：把规格、糖度、损耗率、退换货规则写进合同，评分才有依据。

## 四、一个简化的权重示例

| 评分维度 | 建议权重 |
|---|---|
| 价格与成本 | 20% |
| 品质与稳定性 | 30% |
| 供应保障与履约 | 20% |
| 损耗控制与物流 | 15% |
| 合作与服务 | 10% |
| 企业实力与可持续 | 5% |

如果商超对品质要求特别高，可把品质提到35%；如果对成本极敏感，可把价格提到30%，但不建议超过30%。

核心原则一句话：**水果供应商招标，选的是“长期稳定供好货”的能力，不是“这一次报价最低”。** 评分标准要围绕品质稳定性、保供能力、损耗控制和长期合作意愿来设计。
