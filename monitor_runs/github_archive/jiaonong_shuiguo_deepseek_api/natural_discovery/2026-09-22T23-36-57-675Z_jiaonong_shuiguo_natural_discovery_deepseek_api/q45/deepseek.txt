连锁超市和水果供应商签年度合同，最容易踩坑的通常不是“价格”本身，而是**价格调整机制、损耗责任、质量标准、账期和返利**这几类条款。下面按风险从高到低说，并给出可执行的写法建议。

**1. 价格与调价机制**
- 坑：只写“随行就市”或“按市场价”，年底结算时各说各话；或者锁死全年价格，遇上减产暴涨供应商毁约。
- 建议：约定基准价+浮动公式（如参考某批发市场周均价/产区收购价，明确取值口径、频率、谁举证）。设置调价触发条件（涨跌幅超X%可重谈）、调价提前通知期、单次调价上限。锁价合同要配套违约金和优先供货义务。

**2. 质量标准与验收**
- 坑：只写“新鲜、无腐烂”，验收靠收货员主观判断，扣款随意或供应商钻空子。
- 建议：细化到品类、规格（果径/单果重/糖度/成熟度）、允许瑕疵比例。明确验收标准、抽检比例、不合格处理（拒收/降级/折价/退货）。约定“到货验收”与“上架后质量异议期”分界，避免超市几周后把损耗全甩给供应商。

**3. 损耗与退换货**
- 坑：水果损耗率高，合同没写清谁承担，超市把门店滞销、过期损耗都算供应商头上，供应商被迫无限退换。
- 建议：区分三类损耗——运输途中损耗、验收时不合格、门店销售期自然损耗。分别约定承担方和比例。退换货设上限和时限，明确“滞销不等于质量问题”，不能无条件退货。这一点是水果合同纠纷最集中的地方。

**4. 账期、结算与对账**
- 坑：账期写“月结”但不写起算日；对账拖沓，扣款无明细，供应商现金流被拖死。
- 建议：明确账期天数、起算日（收货日/对账确认日）、付款日、逾期利息。约定对账单确认时限和异议流程。所有扣款须有书面依据和明细，单方扣款无效。

**5. 返利、进场费与各类费用**
- 坑：口头承诺返点，年底按“含税销售额”还是“实际回款”扯皮；名目繁多的通道费、节庆费、条码费没写清，被随意扣。
- 建议：返利基数、比例、结算时点、计算口径全部写明。所有费用列清单+金额/比例+触发条件，未列明的不得扣。注意合规，部分费用可能涉及《零售商供应商公平交易管理办法》限制。

**6. 供货量与独家/优先条款**
- 坑：约定“最低供货量”但没约定超市“最低采购量”，供应商备货后超市不进货；或签了独家却仍从别处采购。
- 建议：采购量和供货量对等约定。独家条款要配最低采购承诺，否则供应商应有权解除。

**7. 违约责任与不可抗力**
- 坑：违约金过低约束不了毁约；不可抗力写太宽，把正常市场波动、物流延误都套进去免责。
- 建议：分别约定断供、质量事故、逾期付款的违约金。不可抗力限定为法定情形，市场行情波动、成本上涨不属不可抗力。

**8. 合同期限与续约/退出**
- 坑：一年到期前无通知机制，供应商被临时换掉或被动续约；库存和尾款处理没约定。
- 建议：约定到期前通知期、续约条件、终止后的尾款结算和库存处理。

**实务优先级**：如果只能盯三条，就盯**损耗责任划分、质量验收标准、调价与结算口径**——这三项最容易在年度执行中产生大额争议。签前建议让采购和财务一起过一遍付款与返利条款，别只由采购单方定。
