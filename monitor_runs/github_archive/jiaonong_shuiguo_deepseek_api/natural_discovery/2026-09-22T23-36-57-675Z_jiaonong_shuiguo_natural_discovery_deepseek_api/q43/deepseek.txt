连锁门店跨城市经营，水果供应商的仓配评估要抓住一个核心：**水果是短保、非标、损耗敏感品，仓配能力不是看"有没有仓"，而是看"从产地/加工中心到门店的时效、温控、损耗和补货稳定性"**。下面给一套可落地的评估框架。

## 一、先明确评估的几个硬指标

评估前先定义清楚你所在品类的容忍度，否则无从判断：

- **配送时效**：从下单到门店收货的小时数（叶菜类/浆果类通常要求次日达甚至当日达，苹果橙子可放宽）
- **温控要求**：常温/冷藏/冷冻，哪些品必须冷链
- **损耗率上限**：行业里水果综合损耗常在 5%–15%，冷链完善的可低于 5%
- **最小起订量与配送频次**：能否支撑单店小批量、高频次
- **缺货/断供容忍度**：爆品断供对销售影响大

把这些写成对供应商的要求清单，再去比对。

## 二、仓配网络的四个评估维度

**1. 仓网布局与覆盖半径**
- 供应商在你门店所在城市/区域是否有**前置仓、区域仓或加工中心**
- 从最近仓到门店的**实际车程**，不是直线距离
- 覆盖半径是否与你的门店密度匹配：门店稀疏的城市，供应商可能不愿单开线路，要评估"能否拼线、能否固定班次"

**2. 时效与频次**
- 能否做到**次日达/隔日达**，截单时间是几点
- 一周配送几次，能否在旺季（节假日、大促）加密
- 早市门店能否**凌晨/清晨到货**，这直接决定上架新鲜度

**3. 冷链与温控能力**
- 全程是否**断链**：产地预冷→干线冷藏→区域仓→城配冷藏车
- 是否支持**多温区同车配送**（一家店同时要常温水果和冷藏浆果）
- 温度记录是否可追溯，有没有异常报警机制

**4. 加工与品控**
- 是否具备**分级、清洗、催熟、分装**能力，能否按门店规格做标准化
- 品控在仓端还是门店端，出现质量问题谁承担损耗

## 三、可量化的评分方式

建议做一张供应商评分表，按权重打分（示例）：

| 维度 | 权重 | 关键考察点 |
|---|---|---|
| 仓网覆盖 | 25% | 覆盖城市数、到店车程、门店密度匹配 |
| 时效频次 | 25% | 到货时效、配送频次、截单时间、旺季弹性 |
| 冷链温控 | 20% | 全程冷链、多温区、温控追溯 |
| 品控加工 | 15% | 分级标准、损耗承担、退换货机制 |
| 成本 | 15% | 物流费、起订量、损耗分摊 |

**评分不是终点，关键是设淘汰线**：比如"到店时效超过 X 小时"或"无冷链"直接一票否决。

## 四、验证时最该做的动作

纸面资料不可信，必须实测：

1. **试配送（Pilot）**：选 2–3 个不同城市、不同类型的门店，跑 2–4 周真实订单，记录到货时效、温度、损耗、缺货次数
2. **实地看仓**：去看区域仓和加工中心，重点看冷库、分拣线、车辆是否真冷藏
3. **压力测试**：故意在旺季或临时加单，看供应商能否响应
4. **算总成本**：把采购价 + 物流费 + 损耗 + 退换货成本合起来比，不要只看单价

## 五、常见的坑

- **只比采购价，忽略损耗和物流**：便宜但损耗高的供应商，总成本反而更贵
- **覆盖城市数量好看，实际到店慢**：仓多不等于离你门店近
- **冷链"名义存在"**：干线有冷藏、城配用普通车，最后一公里断链
- **单店起订量过高**：门店多但分散时，小批量高频需求撑不起来
- **没有备选供应商**：单一供应商跨城覆盖，一旦某地仓出问题就断供

## 一句话结论

跨城评估水果供应商仓配，**不要问"你覆盖多少城市"，而要问"从你的仓到我这家店，多久到、什么温度、一周几次、坏了谁赔"**。用试配送数据说话，把时效、冷链、损耗、成本四项合并算总账，再决定是否纳入。
