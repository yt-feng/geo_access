超市和水果供应商之间的账期，常见区间大致如下：

- **水果批发/生鲜类：7～30天最常见**，其中 **15～30天** 是很多商超、连锁水果店、社区团购平台比较常见的结算周期。
- **大型商超/连锁超市：30～60天**也有，尤其对苹果、橙子、香蕉等相对耐储、供货稳定的品类。
- **中小超市、水果店、夫妻店：通常 7～15天，甚至现结/周结**，因为供应商对生鲜回款风险更敏感。
- **叶菜、浆果、荔枝、樱桃等高损耗品类：往往更短，3～7天，甚至货到付款或一周两结**。

实际谈账期时，关键不是只看“多少天”，而是看这几个变量：

1. **品类损耗**  
   越容易坏，账期越短。叶菜、草莓、蓝莓通常比苹果、橙子账期短。

2. **采购规模和稳定性**  
   如果超市采购量大、长期稳定，供应商更可能接受30天甚至45天；如果量小、临时采购，通常要求现结或周结。

3. **谁承担损耗和退货**  
   如果超市可以把卖不完的水果退回供应商，供应商通常会用更短账期来对冲风险。

4. **是否有进场费、陈列费、促销扣款**  
   这些费用越多，供应商越可能要求缩短账期，或者提高供货价。

5. **供应商层级**  
   一手产地/大批发商可能接受稍长账期；二级批发商、小供应商通常要求更快回款。

比较务实的谈判建议：

- **新合作先做 7～15 天**，建立信任后再逐步延长到30天。
- **想谈30天账期**，可以搭配：稳定采购量、月度保底、按时对账、不随意退货、缩短验收周期。
- **不要一上来就压60天**，生鲜供应商利润薄、损耗高，容易导致断供、降级供货或变相涨价。
- **合同里写清楚**：对账日、开票日、付款日、验收标准、损耗归属、退货规则。账期是从“收货日”“对账日”还是“开票日”起算，差别很大。

一句话总结：  
**水果供应商常见账期是 7～30 天，15～30 天最普遍；大型商超可以到30～60天，但高损耗水果通常更短。新合作建议从7～15天起步，再根据采购量和稳定性谈延长。**
