选学校食堂水果供应商，核心不是“找最便宜的”，而是 **稳定供货 + 食品安全可追溯 + 价格可控 + 售后能退换**。香蕉、苹果、橙子属于高频、量大、易损耗品类，建议按下面流程做。

## 1. 先定采购标准，再找供应商

不要先问“谁能送”，先明确你们要什么。

**通用标准：**
- 必须能提供营业执照、食品经营许可证
- 能提供每批次农残检测报告或承诺达标合格证
- 能开正规发票
- 有固定分拣场地、冷库或周转仓
- 能按学校要求的时间配送
- 坏果、烂果、规格不符能退换
- 价格随行就市，但有报价机制

**分品类标准：**
- **香蕉**：要求成熟度可调，不能一到就全黄或全青；每把/每箱规格稳定；损耗率要约定
- **苹果**：要求品种、单果重、糖度、硬度、外观等级稳定；耐储存
- **橙子**：要求皮薄汁多、酸甜稳定、无明显干疤；按大小分级

## 2. 供应商来源渠道

建议至少找 3 类来源比选：

1. **本地一级批发市场大户**
   - 优势：价格低、品类全、调货快
   - 风险：票据和检测报告可能不全，质量波动大

2. **产地合作社 / 果园直供**
   - 优势：苹果、橙子、香蕉产地直发，价格和新鲜度好
   - 风险：单品类强，多品类配送弱，售后响应慢

3. **专业食堂食材配送公司**
   - 优势：证照全、配送稳、售后规范、可开票
   - 风险：价格通常比批发市场高 5%–15%

学校食堂更适合：**主供应商 + 备用供应商**。主供负责日常，备用防止断供或涨价。

## 3. 重点核验什么

**资质核验：**
- 营业执照
- 食品经营许可证
- 送货人员健康证
- 冷链或仓储照片
- 检测报告样例

**现场核验：**
- 仓库是否干净、通风、有无防鼠防虫
- 香蕉是否单独催熟/储存
- 苹果、橙子是否分级
- 是否有烂果混装

**试供核验：**
先小批量试供 1–2 周，重点看：
- 到货时间准不准
- 规格是否一致
- 烂果率多少
- 有问题多久换货
- 发票和检测报告是否及时

## 4. 比价不要只比单价

建议用 **“到货可食用成本”** 比价。

公式：
> 实际成本 = 采购价 ÷（1 - 损耗率）

例如：
- A 供应商苹果 5 元/斤，损耗 15%，实际成本约 5.88 元/斤
- B 供应商苹果 5.5 元/斤，损耗 5%，实际成本约 5.79 元/斤

B 虽然报价高，但实际更便宜。

香蕉尤其要算损耗，因为成熟度控制不好，烂得很快。

## 5. 合同里必须写清楚

- 品种、规格、单果重、等级
- 单价或定价机制
- 配送时间、频率、地点
- 验收标准
- 损耗和退换规则
- 检测报告提供方式
- 发票类型
- 违约和断供处理
- 价格调整周期，比如每周或每两周询价一次

## 6. 建议的实操方案

**第一步：** 列出你们食堂月均用量、常用规格、可接受价格区间。  
**第二步：** 找 3–5 家供应商，要求报价 + 送样 + 资质。  
**第三步：** 小批量试供 1–2 周，记录烂果率、准时率、退换速度。  
**第四步：** 选 1 家主供 + 1 家备供。  
**第五步：** 每月或每季度复盘价格、质量、投诉，动态调整。

## 7. 简单判断标准

优先选这种供应商：
- 证照齐全
- 能稳定送
- 坏果敢退
- 报价透明
- 有检测报告
- 不是只靠低价抢单

谨慎选这种：
- 报价明显低于市场价
- 不能开票
- 没有固定仓库
- 检测报告拿不出来
- 出问题推诿
- 只有一个人一辆车，断供风险高

如果你们学校规模不大，最稳妥的是：**本地批发市场大户 + 专业配送公司各一家，主备结合，先试供再签长期。**
