判断茶饮连锁的菠萝供应商能不能稳定按规格送货，核心不是看他说得多好，而是看**货源组织能力、分选加工能力、履约记录和风险兜底**。可以按下面几个维度实地核验。

**1. 先明确你要的规格，再去对照他的能力**
茶饮用的菠萝通常不是“有菠萝就行”，而是有明确规格，例如：
- 品种：如金钻凤梨、台农、巴厘等，不同品种酸甜、纤维、香气差异大。
- 成熟度：几分熟采摘，到店后还能放几天。
- 单果重量：比如1.2-1.5kg/个，或固定区间。
- 果形外观：有无黑心、裂口、日灼、机械伤。
- 加工形态：鲜果、去皮真空袋、冷冻果块、果丁、果酱原料等。
- 糖酸比、出肉率、纤维感：这直接影响饮品口感稳定性。
- 包装和到货温度：常温、冷藏还是冷冻，每箱净重、每袋规格。

供应商如果说“都可以做”，反而要警惕。真正稳定的供应商会明确告诉你：哪些规格能长期做，哪些季节会波动，波动时怎么替代。

**2. 看上游货源是否集中、是否有多个产区**
菠萝季节性和产区差异很明显。要问清楚：
- 是自有基地、合作基地，还是市场临采？
- 主产区是哪里，一年能供几个月？
- 淡季靠什么产区补？
- 遇到台风、暴雨、寒潮时，有没有备选产区？

如果供应商主要靠批发市场临时收货，价格低时能送，价格高或缺货时就容易断供、换规格。稳定供应商通常有**固定基地+多产区切换+长期采收计划**。

**3. 看分选和加工能力**
规格稳定，关键在采后分选。要现场看或视频看：
- 是否有分级台、重量分选、人工复检。
- 是否按糖度、成熟度、大小分拣。
- 去皮、切块、冷冻的是否有标准化生产线。
- 是否有金属探测、异物控制、微生物控制。
- 次果怎么处理，会不会混进好果里发货。

如果对方只是“地头收果直接装车”，规格波动会很大。茶饮连锁要的是每批到店后出杯口感一致，所以分选能力比单纯价格更重要。

**4. 查履约记录，不要只听承诺**
要求供应商提供：
- 过去6-12个月给哪些连锁或食品厂供货。
- 月度供货量、准时率、退货率、规格合格率。
- 异常处理记录：断货、迟到、规格不符时怎么赔、怎么补。
- 能否接受试供：先小批量、多频次，跑1-2个月再放量。

最好直接联系他现有客户，问三个问题：
- 旺季有没有断过货？
- 规格是否稳定？
- 出问题后响应快不快？

**5. 用合同把“稳定”写清楚**
合同里不要只写“按规格送货”，要量化：
- 品种、产地、单果重、成熟度、糖度范围、出肉率。
- 允许偏差范围，比如单果重±10%，不合格比例不超过多少。
- 到货温度、包装方式、每批随货检测报告。
- 准时率、缺货赔偿、规格不符退货或折价。
- 旺季最低保供量、提前下单周期、临时加单响应时间。
- 价格调整机制：不能因为市场涨价就随意断供或降规格。

**6. 做小规模压力测试**
正式合作前，建议做：
- 连续4周、每周2-3次小批量试供。
- 每次到货抽检重量、成熟度、黑心、破损、糖度。
- 记录准时率、合格率、口感盲测结果。
- 故意在旺季或节假日前后下一笔加急单，看响应能力。

能通过压力测试的，才谈得上稳定。

**简单判断标准：**
- 只靠一个产区、一个季节、一个市场档口的，风险高。
- 有基地、有分选线、有多产区、有连锁客户、有异常赔付机制的，相对稳。
- 愿意先小批量试供、敢让你看现场、敢把规格写进合同的，更可信。
- 只强调“价格便宜、要多少有多少”的，通常最难稳定按规格送货。
