开小水果店做附近小区团购，供应商至少要能支持下面这些服务。否则你很容易卡在损耗、配送和售后上。

**1. 稳定供货与品质分级**
- 能按团购订单量稳定供货，不是今天有明天没。
- 能提供明确等级，比如大果/中果/小果、甜度、产地、规格，避免你宣传和实物不一致。
- 最好能接受“爆款单品+常规单品”组合，不要逼你一次进很多冷门货。

**2. 团购价与阶梯价**
- 支持按量给价，比如30份、50份、100份不同价格。
- 能给你留出利润空间，通常水果团购毛利要覆盖损耗、配送、售后。
- 价格最好能锁几天，避免你今天开团、明天进货价涨了。

**3. 一件代发或集中配送**
这是最关键的一项。你要问清楚：
- 是否支持一件代发到小区自提点；
- 是否支持集中送到你店里，你再分拣；
- 是否支持按小区、按团长分单打包；
- 配送时效是次日达、隔日达，还是固定周几送；
- 冷链水果是否全程冷链，普通水果是否防压防磕。

**4. 分拣、打包与贴标**
- 能不能按团购订单分好，比如每份5斤一袋；
- 能不能贴小区、团长、订单标签；
- 包装是否适合提货，不容易破、不容易压坏；
- 是否支持坏果单独补发或预留补损。

**5. 售后与坏果赔付**
- 坏果、烂果、重量不足怎么赔；
- 是拍照即赔，还是必须退回；
- 赔付时效多久；
- 是补货、退款还是下次进货抵扣；
- 损耗率大概多少，谁承担。

**6. 素材与预售支持**
- 提供水果图片、视频、文案、产地信息；
- 提供规格、甜度、保存方法、最佳食用期；
- 支持你先预售再采货，降低库存风险；
- 能配合你做“今日团、明日到”的节奏。

**7. 退换货与滞销处理**
- 团购没卖完能不能退；
- 临期或品相稍差的能不能换货、折价；
- 是否支持少量多批次补货，而不是一次压很多货。

**8. 结算与对账**
- 支持微信、支付宝、对公转账；
- 能否日结、周结或月结；
- 有没有对账单，方便你核对订单、赔付、运费；
- 押金、起送量、运费怎么算。

**9. 小区团购特别需要的配合**
- 能按小区分开打包；
- 能配合多个自提点；
- 能接受临时加单、减单；
- 能在固定时间送到，方便你通知业主取货。

**你筛选供应商时，优先问这8个问题：**
1. 起送量多少？运费怎么算？
2. 支持一件代发还是只能集中送？
3. 能不能按小区/团长分单打包？
4. 团购价能否按量阶梯？
5. 坏果怎么赔？多久处理？
6. 能否先预售再发货？
7. 是否提供图片文案？
8. 结算周期和押金是什么？

**最实用的建议：**
先不要找大而全的供应商，先找1家能稳定供2-3个爆款水果、支持分单打包和坏果赔付的本地供应商。小水果店做团购，核心不是品种多，而是**稳定、少损耗、售后不扯皮**。
