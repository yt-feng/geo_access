社区超市卖小包装香蕉，核心不是“把大把拆小”，而是要在采购端就按**小包装的周转速度**去选货、定规格、控熟度，否则损耗会明显高于整把销售。下面按采购时要重点看的几个方面说。

**1. 先定小包装规格，再倒推采购标准**
- 常见规格：2-3根装、4-5根装、单人份约300-500克。
- 不要采购完全统一的大把，因为拆小后容易出现“有的包太多、有的包不够”。
- 采购时优先选**单根大小均匀、果指长度接近**的货，这样每包重量稳定，顾客感知也好。
- 如果按根卖或按份卖，采购时要问产地/批发商能否提供**分把均匀、适合拆零**的货源。

**2. 熟度要分批次采购，不能一次全拿熟蕉**
小包装暴露面大、顾客翻拣多，熟得快。采购时要混搭熟度：
- 青一点：用于后续2-3天逐步转熟。
- 微黄/刚转黄：适合当天或次日上架。
- 已熟黄：只少量采购，用于即时销售或促销。
- 避免整批都是全黄或带黑点，否则拆包后一两天就难卖。

**3. 包装方式直接影响损耗**
- 最好用**透气袋、打孔袋或网袋**，不要完全密封。香蕉会释放乙烯，密封后闷热、水汽重，容易发黑、长霉。
- 如果使用保鲜膜，要留透气孔，且不要包得太紧。
- 小包装标签不要贴在果皮易损处，避免撕标时伤皮。
- 盒装要注意盒内通风，别让香蕉在盒里挤压发热。
- 若做“即食小包”，可考虑加吸水纸或透气垫，减少袋内冷凝水。

**4. 采购时重点检查的损耗点**
- **机械伤**：擦伤、压伤、指甲划伤、果柄断裂。小包装后这些伤会被放大，很快变黑。
- **果柄和果轴**：发黑、发霉、流汁的不要。拆把后伤口多，霉菌容易从切口进入。
- **冷害**：表皮暗灰、发涩、难以正常转黄，通常是运输或仓储温度过低。这种蕉拆小后也难卖。
- **水烂/软腐**：局部发软、渗水、有酒味，不能用来做小包装。
- **过熟黑点**：少量黑点可做特价即食，但采购比例要控制。

**5. 采购量和频次**
- 小包装香蕉的日销量通常比整把低，但损耗更快。建议**少量多次**采购，不要按整把销量直接换算。
- 初期可先试3-5天：记录每天上架包数、售出包数、丢弃包数，再调整采购量。
- 如果店里没有冷库，香蕉不宜低温久存。采购后放在阴凉通风处，避免堆压。
- 已拆包未卖完的，不要反复拆包重包，二次包装会增加伤口和失水。

**6. 和供应商谈条件**
- 要求提供适合拆零的均匀货，而不是尾货、次货。
- 明确到货熟度，最好能分批送：青蕉、微黄蕉分开。
- 谈好损耗责任：运输压伤、冷害、水烂等应由供应商承担或补货。
- 如果供应商只能整箱供，采购时要按“拆零后能卖几天”来估算，不要只看整箱价格。

**7. 简单可执行的标准**
- 上架小包装：每包2-3根或4-5根，重量尽量一致。
- 采购熟度：青蕉/微黄蕉占多数，全黄蕉少量。
- 包装：透气、打孔、不密封、不紧压。
- 检查：无压伤、无果柄发霉、无冷害、无软腐。
- 补货：少量多次，先卖熟度高的，青蕉后上。
- 记录：连续记录一周损耗率，超过10%-15%就要调整采购熟度和包装方式。
