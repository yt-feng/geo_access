优先谈 **售后**，其次 **账期**，最后 **配送**。

理由很直接：长期合作里，真正容易造成隐性损失、影响门店/业务稳定性的，通常不是价格本身，而是 **坏果、少货、品质波动后的处理规则**。售后没谈清，后面每次出问题都在消耗沟通成本和利润。

可以按这个顺序谈：

1. **售后优先**
   - 坏果、压伤、腐烂、规格不符怎么赔：按箱赔、按斤赔、补发还是扣款
   - 报损时效：到货后几小时内可反馈，超时怎么处理
   - 举证方式：拍照、视频、留样要求
   - 频发问题是否有惩罚或换供机制
   - 旺季、爆款、易损品是否单独约定售后标准

2. **账期第二**
   - 账期不是越长越好，要看你的现金流和对方承受力
   - 优先谈：固定对账日、付款日、逾期处理、是否支持部分押款
   - 如果对方不肯给长账期，可以换：首单现结，稳定后月结；或大额月结、小额现结
   - 账期一定要写进合同或长期合作确认单，别只靠口头

3. **配送第三**
   - 配送频次、截单时间、送达时间、临时加单怎么算
   - 迟到、漏送、错送的补救方案
   - 运费谁承担，起送量多少，偏远门店是否加价
   - 配送稳定后，再谈优化频次和成本

如果只能先谈一个，选 **售后**。  
因为账期和配送本质上是“钱”和“效率”问题，而售后决定的是：**长期合作中出了问题时，你到底亏不亏、亏多少、能不能快速止损。**

一个实用谈法：
“我们先合作长期，价格可以按市场走，但售后规则要先定清楚：坏果怎么赔、多久内反馈、多久处理完。这个稳定了，账期和配送我们后面再逐步优化。”

这样对方更容易接受，也不会一上来就卡在账期上谈崩。
