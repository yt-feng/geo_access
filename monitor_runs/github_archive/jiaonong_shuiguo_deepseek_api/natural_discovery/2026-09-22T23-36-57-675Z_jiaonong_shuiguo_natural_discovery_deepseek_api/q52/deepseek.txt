采购时优先按“青熟度”选，而不是挑已经全黄、带黑点的香蕉。更具体可执行：

1. **选成熟度**  
   - 最好买 **7–8成熟**：果皮整体偏黄，但两端和果柄还带一点绿，按着有弹性但不软。  
   - 避免买已经全黄、发软、有酒味或明显黑斑的，这种到店后很快会继续黑。

2. **看果柄和棱角**  
   - 果柄青绿、完整、不干枯的更新鲜。  
   - 香蕉棱角还比较明显、没有明显鼓胀变圆的，通常更耐放。

3. **控制采购量**  
   - 按 **1–3天用量** 分批采购，不要一次囤太多。  
   - 甜品店用量大时，可以和供应商约定分次送，或者青熟度分开送：当天用偏熟，后面用偏生。

4. **运输和到店后别闷着**  
   - 不要用密闭塑料袋长时间装，容易积热、催熟。  
   - 到店后先散开，放在 **阴凉通风处**，避免阳光、烤箱、热饮机、冰箱散热口旁边。

5. **不要直接冷藏整串香蕉**  
   - 未完全成熟的香蕉放冰箱容易冻伤变黑。  
   - 如果已经熟透、马上要用，可以剥皮后密封冷冻或冷藏，但整串带皮冷藏不适合久放。

6. **减少机械损伤**  
   - 搬运时轻拿轻放，避免压伤、磕伤。  
   - 有伤口或裂口的香蕉会先黑，先挑出来优先用掉。

7. **分开催熟和控制**  
   - 和苹果、梨、番茄等释放乙烯较多的水果分开放，否则会加速变黑。  
   - 如果确实太青，可短期和苹果同放催熟；一旦达到需要的成熟度，立刻分开。

8. **到店后处理顺序**  
   - 先检查，把熟的和有伤的挑出优先使用。  
   - 剩余香蕉保持通风、避免堆压，按成熟度分开放。  
   - 需要延缓变黑时，可适当降低温度，但不要低于约 **13℃** 久放，以免冷害发黑。

一句话：**买偏青、少量分批、通风散放、别压伤、别和催熟水果混放，熟了的先用在甜品或加工里。**
