判断水果供应商靠不靠谱，核心看**稳定性、品质一致性、账期与售后、价格透明度**。你可以按下面这套方法去筛，基本能避开大部分坑。

**1. 先看货源稳不稳**
- 问清楚：香蕉、菠萝是国产还是进口？主要产地是哪里？一年中哪些月份会断货或换产地？
- 靠谱供应商能明确告诉你：现在这批货来自哪、下一批大概什么时候到、替代产地是什么。
- 如果对方只说“都有货”“放心”，但说不清产地和季节，通常不稳。

**2. 看品质是否稳定，而不是只看一次**
- 香蕉重点看：催熟程度是否可控、到店后几天转黄、有没有青硬或过熟、损耗率多少。
- 菠萝重点看：品种是否统一、糖度是否稳定、黑心/水心病多不多、果眼深浅是否一致。
- 不要只拿一次样品就定。连续拿2—3次，最好跨不同批次，看烂果率、大小均匀度、成熟度是否一致。

**3. 看损耗和售后怎么算**
- 直接问：坏果、烂果、黑心菠萝怎么赔？是拍照秒赔，还是下次补货？有没有起赔数量？
- 靠谱的会给出明确规则，比如“到货24小时内拍照，按个数赔”或“次批补损”。
- 如果对方说“水果都有损耗，不赔”，除非价格特别低，否则长期做会很吃亏。

**4. 看价格和账期是否透明**
- 问清楚：报价是毛重还是净重？含不含运费、卸货费、筐箱费？
- 账期方面：是现结、周结还是月结？压货多不多？
- 靠谱供应商价格会随行就市，但不会今天一个价、明天乱涨，也不会在秤上做手脚。

**5. 看配送和响应**
- 香蕉、菠萝都属于周转快、损耗敏感的商品，配送不准时很致命。
- 观察：说好早上到，是否经常拖到下午？临时加单能不能补？出问题多久回复？
- 连续几次迟到或失联，基本可以换人。

**6. 看市场口碑和实地**
- 去批发市场打听：这家给其他水果店的货怎么样？有没有经常换老板、换牌子？
- 如果能去档口或仓库看，重点看：冷库干不干净、香蕉催熟房是否规范、菠萝堆放有没有大量烂果。
- 一个档口如果自己地上烂果一堆，通常不会给你好货。

**7. 小批量试合作**
- 先别签长期。拿2—3次小批量，分别记录：
  - 到货时间
  - 烂果率
  - 香蕉转黄天数
  - 菠萝糖度/黑心比例
  - 售后处理速度
- 两次以上都稳定，再考虑长期。

**简单判断标准：**
- 能说清产地和季节：加分
- 连续批次品质稳定：加分
- 坏果有明确赔付：加分
- 价格透明、秤准：加分
- 配送准时、响应快：加分
- 只会催你多拿、不解决售后：直接淘汰

对你开水果店来说，香蕉和菠萝都是引流转客的关键品。供应商不一定要最便宜，但一定要**货稳、损耗可控、售后不扯皮**。建议至少备2家供应商，一家主供、一家备用，避免被一家卡住。
