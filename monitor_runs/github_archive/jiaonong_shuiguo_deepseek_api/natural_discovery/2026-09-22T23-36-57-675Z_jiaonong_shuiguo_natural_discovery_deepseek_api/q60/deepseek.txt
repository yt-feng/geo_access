核心不是“让对方补货”，而是把补货做成不影响门店出杯的流程，关键在三点：**验收即锁定责任、补货与替代双轨并行、按损耗和时限算账**。具体可以这样约定：

**1. 验收当场定性，别等入库后再扯皮**
- 收货时按约定标准拍照/视频，记录品种、数量、成熟度、坏果率、温度。
- 双方现场确认不合格比例，签字或聊天记录确认。
- 明确“不合格部分不计入本次合格交付量”，避免后面被算成已收货。

**2. 补货要分“紧急补”和“常规补”**
- 紧急补：约定到货后 X 小时内（如 2–4 小时）补到位，适用于当天营业必需的水果。
- 常规补：X 个工作日内补，适用于可暂缓的品类。
- 关键：补货只补“不合格数量”，还是补“影响当日营业的缺口”，要写清楚。建议按后者谈，因为门店损失不只是一箱水果。

**3. 允许替代，避免断货**
- 约定同品质、同价位的替代水果或替代规格。
- 如果供应商没货，允许其承担门店临时采购差价。
- 替代方案要事先写进合同或订单备注，否则临时协商容易拖时间。

**4. 补货不影响营业的操作设计**
- 先补“能马上用的”，不要等整批换完。
- 不合格品单独封存，不占操作台、不混入合格品。
- 补货时间避开门店高峰，比如约定上午 10 点前或下午 2–4 点。
- 供应商补货时直接送到门店指定收货点，减少二次搬运。

**5. 把损失算进去**
可约定：
- 逾期补货按不合格货值的 X% 支付违约金；
- 因缺货导致门店临时采购的差价由供应商承担；
- 因水果不合格导致报废、客诉、停售的，按实际损失或约定金额赔偿。
注意：违约金和赔偿要合理，过高可能不被支持。

**6. 合同/订单里建议写这几句**
- “验收不合格部分，甲方有权拒收，乙方应在 X 小时内补足同等品质数量。”
- “乙方未按时补足的，甲方可自行采购，差价及合理费用由乙方承担。”
- “补货不影响甲方正常营业，补货时间应避开营业高峰。”
- “不合格品由乙方负责退换，相关运输费用由乙方承担。”

**7. 最实用的判断标准**
如果一种水果是门店核心产品、当天必须用，就约定“小时级补货 + 替代方案 + 差价赔偿”。
如果是非核心、可替代的，就约定“次日补货 + 折价使用或退款”。

一句话：**补货条款要写成“时限 + 数量 + 替代 + 赔偿 + 不影响营业”的组合，而不是只写“下次补上”。**
