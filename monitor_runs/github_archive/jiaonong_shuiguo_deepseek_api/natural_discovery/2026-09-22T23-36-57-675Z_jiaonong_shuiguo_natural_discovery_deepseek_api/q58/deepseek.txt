通常情况下，**直接买成品果丁的综合损耗更低**，尤其是你店里销量不算特别大、后厨人手紧、菠萝周转不稳定时。但“更低”要看你怎么定义损耗。

### 直接买成品果丁
**优势：低损耗、省人工、品质稳定。**
- 到货基本是净重，拆袋即用，几乎没有去皮、去眼、切丁的废料。
- 不需要处理菠萝皮、菠萝芯、边角料，也不会因为员工刀工差多切掉果肉。
- 库存按需订货，临期和过期风险相对可控。
- 损耗主要来自：解冻/沥水、开封后没用完、冷藏变质。

**劣势：**
- 单价通常高于鲜菠萝。
- 风味、口感、酸度可能不如现切鲜果，尤其是高端甜品。
- 部分成品果丁会加糖水或防腐处理，配方要确认。

### 鲜果切配
**优势：新鲜度、风味、卖点更好。**
- 现切菠萝香气和口感通常更自然。
- 可以自己控制成熟度、糖酸比和切丁大小。
- 对主打“现切水果”的甜品店更有宣传价值。

**劣势：**
- 实际损耗很高：去皮、去眼、去芯、修边，出肉率通常只有 **40%—60%** 左右。
- 人工成本高，切配时间、清洗消毒、冷藏保存都要算进去。
- 菠萝成熟度不好时，生果酸、熟果易烂，废料更多。
- 切好后氧化、出水、串味，当天用不完就容易报损。

### 怎么判断你该选哪个
可以按下面几个条件判断：

1. **日均用量小、品种多、后厨忙**  
   选成品果丁，损耗和人工都更容易控制。

2. **日均用量大、专门做菠萝类爆品**  
   鲜果切配可能更划算，因为出肉率稳定后，原料成本优势会体现出来。

3. **主打高端、现切、新鲜**  
   选鲜果切配，但要做标准出成率和每日用量计划。

4. **外卖多、出品稳定性要求高**  
   选成品果丁更稳，口味波动小。

### 简单算账方法
不要只比“一斤多少钱”，要比 **可食用部分成本**：

- 鲜菠萝：进货价 ÷ 出肉率 = 实际可用果肉成本  
  例如 8 元/斤，出肉率 50%，实际果肉成本就是 16 元/斤，还没算人工。
- 成品果丁：到货净重价格 + 解冻/沥水损耗 + 开封报废。

如果成品果丁折算后不超过鲜菠萝实际果肉成本的 **1.3—1.5 倍**，通常选成品更省心，综合损耗也更低。

### 结论
- **只看物料损耗：成品果丁更低。**
- **看综合成本：小用量、人手紧选成品；大用量、能标准化切配选鲜果。**
- **看产品定位：高端现制可保留鲜果切配，普通甜品和外卖优先成品果丁。**
