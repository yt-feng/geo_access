选哪种，主要看你**门店销量规模、出杯效率、风味定位和损耗控制能力**。直接给结论：

**大多数普通茶饮店：优先选冷冻菠萝果丁/果块，搭配少量鲜果做装饰或高端款。**
**鲜果适合销量大、有切配人力、主打新鲜现切的店。**
**果泥适合做稳定标准化、但通常香气和果肉感较弱，更适合打基底或混合饮品。**

下面按维度对比：

| 类型 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|
| 鲜果 | 香气自然、卖点强、可现切装饰 | 损耗高、切配耗时、季节波动大、品控难 | 销量大、有后厨、主打新鲜 |
| 冷冻果丁/果块 | 出杯快、品质稳定、损耗低、有果肉感 | 需冷冻储存、部分产品解冻后口感略软 | 多数连锁/中小店，做果茶主料 |
| 果泥/果浆 | 标准化强、操作快、风味稳定 | 果肉感弱、部分产品香精感重、含糖/添加剂需注意 | 做基底、冰沙、混合果茶、外卖稳定出品 |

**建议这样选：**

1. **如果你日销菠萝果茶不到 30 杯**  
   不建议大量买鲜果，损耗会吃掉利润。选**冷冻菠萝果丁**，再少量买鲜果做顶部装饰即可。

2. **如果你日销 50 杯以上，且有人手切配**  
   可以用**鲜果为主**，但要做 SOP：去皮、去眼、切丁大小、盐水处理、冷藏时限都要固定。

3. **如果你追求出杯速度和外卖稳定性**  
   选**冷冻果丁 + 少量果泥/果汁调基底**。果丁提供咀嚼感，果泥补风味和酸甜稳定。

4. **如果你做低价走量款**  
   用**果泥/果浆 + 少量果丁**，成本更可控，但要注意标签和糖度，避免风味太“工业”。

5. **如果你做高端款**  
   用**鲜果现切 + 少量冷冻果丁备用**，主打“新鲜菠萝”，但定价要覆盖人工和损耗。

**采购时重点看这几个指标：**
- 是“果丁”还是“果酱”：果丁偏向果肉，果酱含糖高。
- 冷冻果丁的**固形物含量**和**解冻后出水率**。
- 果泥的**果汁含量、是否加糖、是否有香精/防腐剂**。
- 菠萝品种：常见有巴厘、金钻、台农等，香气和酸度不同，先拿样测试。
- 包装规格：小门店选 1kg 小包装，避免反复解冻。

**最稳的组合：**
- 主料：冷冻菠萝果丁
- 辅料：少量菠萝果泥/浓缩汁调酸甜
- 装饰/高端款：鲜果现切
- 先拿 2–3 家样品做盲测，比香气、果肉感、出杯速度、24 小时后的风味变化。
