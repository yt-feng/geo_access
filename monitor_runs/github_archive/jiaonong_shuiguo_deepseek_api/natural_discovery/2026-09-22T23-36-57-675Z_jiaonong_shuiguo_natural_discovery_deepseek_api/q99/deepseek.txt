批量配送水果，核心不是“找最便宜的”，而是找**能在指定时间、把稳定品质、损耗可控地送到公司**的供应商。可以按下面几个维度筛选。

**一、先明确自己的需求**
1. **人数和预算**：比如80人，人均8–15元，决定采购量和档次。
2. **配送频次**：每天、每周几次、还是每月一次。频次越高，越需要稳定供应商。
3. **配送时间**：下午茶通常要下午2–4点前送达，必须确认对方能否固定时段送到。
4. **形式**：整果、果切、果盘、独立小包装。果切省事但损耗和食品安全风险更高。
5. **场地条件**：有没有冰箱、能不能存放、是否需要分装到工位。

**二、优先考虑这几类供应商**
- **本地水果批发商/农批市场商户**：价格低，适合量大；但配送和售后不稳定，要确认能否开发票、按时送。
- **生鲜电商企业购**：如京东企业购、美团企业版、盒马企业采购等，配送稳定、售后规范，价格略高。
- **专业果切/下午茶供应商**：适合直接配送果盘，省人工，但要看资质和冷链。
- **本地连锁水果店**：适合中小公司，沟通快、可长期合作，但批量价格未必最优。
- **员工福利/企业下午茶服务商**：通常打包能力强，能按人数配比，适合不想操心的公司。

**三、筛选供应商的硬指标**
1. **配送能力**：能否固定时间送达、是否冷链车、迟到怎么处理。
2. **品质稳定性**：要求先试单，看水果新鲜度、成熟度、大小是否一致。
3. **损耗和售后**：坏果、烂果、少送是否包赔，多久内反馈有效。
4. **食品安全资质**：营业执照、食品经营许可证；做果切还要看是否具备相应许可和操作规范。
5. **报价是否透明**：是否含配送费、包装费、切配费、税费，避免低价引流后加价。
6. **结算方式**：能否月结、开发票、对公转账，这对公司采购很重要。

**四、建议的采购流程**
1. 先定预算、人数、配送频次和形式。
2. 找3–5家供应商同时报价，要求给“同预算下的搭配方案”。
3. 每家先试单一次，重点看：是否准时、水果新鲜度、坏果率、包装是否方便分发。
4. 试单后按“品质40%+配送30%+价格20%+售后10%”打分。
5. 选1家主供应商+1家备选，避免临时掉链子。
6. 签简单协议或确认单，写清配送时间、标准、售后和结算。

**五、避坑提醒**
- 不要只比单价，要算**实际可食用部分**。比如香蕉、西瓜看着便宜，但损耗和分切成本可能更高。
- 夏季慎选易压伤、易腐水果，如草莓、蓝莓、荔枝，除非冷链和配送时间有保障。
- 果切虽然方便，但一定要确认是**当天切、冷藏配送、有资质**。
- 第一次不要签长期大单，先试单2–3次再定。
- 要求供应商提供**到货照片或签收单**，方便行政核对。

**六、适合批量配送的水果搭配**
- 稳妥型：香蕉、橘子、苹果、梨、小番茄。
- 夏季型：西瓜、哈密瓜、葡萄、李子、桃子。
- 省事型：独立包装的小番茄、香蕉、橘子、苹果。
- 提升感型：蓝莓、车厘子、阳光玫瑰等，但预算要高，且要冷链。

简单说：**先试单，再比价；看配送和售后，不只看单价；主供应商+备选供应商最稳。**
