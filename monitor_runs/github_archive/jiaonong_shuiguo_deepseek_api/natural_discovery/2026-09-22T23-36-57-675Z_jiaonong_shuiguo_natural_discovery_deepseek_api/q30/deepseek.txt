超市水果到货后发现品相不好，售后流程的关键不是等出问题再扯皮，而是提前把“什么算问题、多久内提、怎么处理、谁承担费用”写清楚。可以按下面几个环节约定：

**1. 验收标准和时限**
- 到货后当场或约定时间内（如2小时内、当日营业结束前）完成验收。
- 明确品相不好的具体情形：腐烂、压伤、冻伤、开裂、异味、成熟度过高/过低、规格不符、大小不均、颜色异常等。
- 最好按比例约定：例如单箱坏果率超过5%可拒收或换货，超过10%可整批退货。
- 生鲜有特殊性，超过时限再提，供应商可只承担部分责任或不予处理，所以时限要写死。

**2. 取证方式**
- 到货即拍照/录像：外包装、封签、批次、整体货况、问题果特写。
- 保留称重记录、验收单、送货单、聊天记录。
- 大额或长期合作可约定双方共同验收，或发现问题后通知供应商到场确认。
- 单方取证容易被争议，最好约定“照片/视频可作为初步依据，供应商有异议应在几小时内回复”。

**3. 提出异议的方式**
- 约定必须通过书面或可留痕渠道提出，如订单系统、邮件、微信工作群，并指定对接人。
- 写明异议内容：订单号、批次、品名、数量、问题类型、照片、要求处理方式。
- 口头通知容易失效，不建议只靠电话。

**4. 处理方式**
常见可选：
- 补发：供应商在约定时间内补足合格货。
- 换货：整批或问题部分更换。
- 退货退款：问题部分或整批退回，运费由责任方承担。
- 折价扣款：按坏果比例、等级下降幅度协商扣款。
- 销毁处理：若生鲜无法退回，约定由超市就地处理并留存证据，供应商按约定退款或补货。

**5. 费用和责任**
- 因品相问题产生的退换货运费、分拣费、销毁费，一般由供应商承担。
- 若超市未在约定时限内验收或保存不当导致问题扩大，扩大部分可约定由超市承担。
- 不可抗力、运输途中正常损耗要有单独约定，不能和品相问题混在一起。

**6. 结算和违约**
- 约定问题未处理完前，对应货款可暂缓支付或按比例扣留。
- 约定供应商逾期不处理时，超市可自行折价、退货或从货款中扣除。
- 多次出现品相问题的，可约定警告、降低采购比例、暂停合作或终止合同。

**7. 建议写进合同或订单的条款示例**
“买方应在到货后2小时内验收。发现腐烂、压伤、冻伤等品相问题，应在验收时间内拍照并书面通知卖方。坏果率超过5%的，买方有权要求补货、换货或按比例扣款；超过10%的，有权整批退货，运费及处理费用由卖方承担。卖方应在收到通知后24小时内回复处理方案，逾期视为同意买方按实际损失扣款。”

简单说：**时限要短、标准要具体、取证要留痕、处理方式要可选、费用要归责、结算要能扣款。** 这样水果到货品相不好时，超市才有明确依据走售后，不容易变成口头扯皮。
