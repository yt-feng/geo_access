茶饮店使用水果，供应商通常需要提供这几类证明，按重要程度排序：

**1. 主体资质类（必备）**
- 营业执照
- 食品经营许可证（或食品生产许可证，看其业态）

**2. 产品合格证明类（必备，按批次）**
- 该批次水果的检验合格报告（出厂检验或第三方检测报告）
- 食用农产品：可提供产地证明、购货凭证或合格证

**3. 食用农产品追溯类**
- 产地信息/供货凭证
- 承诺达标合格证（部分地区推行，由生产者出具）

**4. 重点检测项目（茶饮店应关注的）**
- 农药残留检测（重点项）
- 重金属（铅、镉等）
- 致病菌（如即食水果，关注沙门氏菌、大肠杆菌等）

**5. 运输与储存相关**
- 冷链运输记录（针对需冷藏水果，如切好的果切、易腐水果）
- 收货时的温度记录

**6. 检疫证明（仅特定情形）**
- 进口水果：入境货物检验检疫证明
- 若涉及需检疫的品类，按海关要求

**给你的实操建议：**
- 固定供应商，签订采购合同，明确质量责任和退换货条款。
- **每批进货都索票索证**，保留检验报告和进货单据，留存期限一般不少于产品保质期满后6个月（无保质期的不少于2年）。
- 对即食水果（直接入杯的），要求供应商提供更严格的微生物检测报告，并做好到店后的清洗消毒。
- 定期对供应商做评估，避免只用“口头承诺”而无凭证。

如果你要的是**最精简版**：营业执照 + 食品经营许可证 + 每批次农残合格报告，这三样是底线，其他根据水果是否即食、是否进口、是否需冷藏来补充。
