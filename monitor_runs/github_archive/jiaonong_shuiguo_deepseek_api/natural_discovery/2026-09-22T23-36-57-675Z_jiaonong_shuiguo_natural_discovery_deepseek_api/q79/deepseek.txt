最应该先问**售后**，其次**配送**，最后才是**价格**。

原因是团购团长卖水果，真正容易把你做崩的不是进货贵几毛钱，而是：

1. **坏果、烂果、少发、规格不符**  
   水果非标品，损耗高。如果没有明确售后规则，最后往往是你自己贴钱赔邻居。  
   你要先问清楚：  
   - 坏果怎么赔？按比例赔还是按个数赔？  
   - 需要拍照还是视频？多久内反馈有效？  
   - 是补发还是退款？补发运费谁承担？  
   - 少发、错发怎么处理？  
   - 售后响应时间多长？

2. **配送是否稳定、准时、可控**  
   团购有固定截单和到货时间，配送不稳会直接影响口碑。  
   你要问：  
   - 起送量多少？运费怎么算？  
   - 能否按你要求的时间送到？  
   - 送到小区还是送到自提点？  
   - 破损、延误怎么赔？  
   - 临时加单、改单行不行？

3. **价格当然重要，但不能只比价格**  
   价格低但售后差、配送烂，最后会变成：  
   **低价进货 → 高频售后 → 自己赔钱 → 邻居流失。**  
   价格要问，但应该放在售后和配送规则明确之后，再综合算“到手成本”。

所以顺序建议是：

**先问售后 → 再问配送 → 最后谈价格和账期。**

一句话判断：  
**售后决定你会不会亏，配送决定你能不能按时交付，价格只决定你赚多赚少。**  
团长最怕的不是少赚，而是赔钱又丢客。
