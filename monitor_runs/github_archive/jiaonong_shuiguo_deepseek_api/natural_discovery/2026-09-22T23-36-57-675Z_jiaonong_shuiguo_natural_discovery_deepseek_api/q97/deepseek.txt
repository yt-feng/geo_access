酒店采购水果盘原料时，建议把要求写成可验收的标准，分“规格等级、成熟度、外观、安全、包装配送”五类。下面是一份可直接放进采购单或验收表的通用标准，具体数值可按酒店档次和菜单调整。

**一、通用规格与等级标准**
1. **品种与产地**：明确品种、产地、品牌/基地。例如“海南贵妃芒”“智利车厘子JJ级”“阳光玫瑰葡萄”。
2. **大小/重量**：按单品约定单果重量或直径。例：
   - 苹果/橙子：单果 180–250g，直径 75–85mm；
   - 西瓜：单果 4–6kg；
   - 草莓：单果 15–25g；
   - 蓝莓：果径 14–18mm；
   - 车厘子：JJ 级 28–30mm，JJJ 级 30–32mm。
3. **等级**：特级/一级/二级要写清。酒店果盘通常用一级或特级，不允许混级。
4. **成熟度**：要求“即食成熟度”或“到货后 1–2 天可成熟”。牛油果、芒果、猕猴桃等需单独约定硬度或糖度。

**二、外观标准**
1. **新鲜度**：果皮饱满、有光泽，无萎蔫、皱缩、干疤。
2. **色泽**：符合品种固有色泽，转色均匀，无青肩、花脸、褪色。
3. **形状**：果形端正，无明显畸形、偏斜、双头。
4. **表面缺陷**：
   - 不允许：腐烂、霉变、虫蛀、裂口、渗液、异味；
   - 限制允许：轻微机械伤、日灼、轻微擦皮，且不影响切配和出品；
   - 一般要求单果病斑/虫眼/疤痕面积不超过果面 5%，且不得集中在切面。
5. **洁净度**：无泥土、无药斑、无蜡感过重、无枝叶杂质。
6. **切配适用性**：果肉颜色正常，无褐变、空心、黑心、纤维过粗。

**三、食品安全与合规标准**
1. **农残**：符合 GB 2763 食品安全国家标准 食品中农药最大残留限量。
2. **污染物**：符合 GB 2762。
3. **致病菌/微生物**：即食水果应控制沙门氏菌、金黄色葡萄球菌、大肠杆菌等；若供应商提供鲜切，需符合即食果蔬卫生要求。
4. **证明文件**：每批次提供产地证明、检测报告、合格证、进货票据；进口水果提供入境货物检验检疫证明。
5. **可追溯**：批次号、采摘/加工日期、供应商名称可查。

**四、包装与配送标准**
1. **包装**：食品级周转箱或纸箱，内衬洁净；易压伤水果用蛋托、泡沫网套、隔板。
2. **温度**：
   - 热带水果：12–15℃；
   - 浆果、切配水果：0–4℃；
   - 叶菜类配果盘：2–8℃。
3. **时限**：采摘到到货不超过约定天数；鲜切水果从加工到送达不超过 4–6 小时，全程冷链。
4. **标识**：品名、等级、净重、产地、批次、生产日期、保质期、贮存条件。
5. **禁混装**：水果不得与生肉、水产、化学品混装。

**五、验收与退换货条款**
1. **抽检比例**：每批次抽检 5%–10%，大批量按 GB/T 2828.1 抽样。
2. **拒收条件**：
   - 腐烂、霉变、虫害超过 1%；
   - 规格不符超过 5%；
   - 成熟度严重不符、无法在 24 小时内使用；
   - 无证、证物不符、冷链断链。
3. **退换货**：不合格品 2 小时内响应，4 小时内补货；费用由供应商承担。
4. **扣罚**：可约定按不合格比例扣款，或整批退货。

**六、建议写进合同的关键句**
> 供应商应保证所供水果符合 GB 2762、GB 2763 及国家相关食品安全标准，外观新鲜、无腐烂霉变虫蛀，规格等级符合订单约定，到货成熟度适合酒店果盘即时或 24 小时内使用。每批次随货提供合格证明和检测报告。验收不合格，酒店有权拒收、退货或要求补货，并由供应商承担相应损失。
