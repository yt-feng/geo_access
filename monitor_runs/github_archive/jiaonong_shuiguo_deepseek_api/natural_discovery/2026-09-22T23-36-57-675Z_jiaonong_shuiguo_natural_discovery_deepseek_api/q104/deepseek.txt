单位采购水果要避免"到货品质不一致"扯皮，核心是把验收标准前置到合同里，验收时按证据留痕，售后按约定追责。下面按流程给可执行建议。

## 一、采购前：把标准写进合同/订单

验收能顺利进行的前提是"有据可依"，否则现场只能各说各话。

1. **明确规格等级**：写明品种、产地、单果重量/直径范围、成熟度、色泽、糖度（如可测）、允许的瑕疵比例。
2. **约定到货标准**：例如"同批次大小均匀，霉变、压伤、腐烂果不超过 X%，单果不符规格不超过 Y%"。
3. **约定验收方式**：抽样比例（如每批随机抽 5%~10%）、验收时限（到货后几小时内）、验收地点。
4. **约定售后条款**：不合格如何退换、补货时限、扣款比例、运费承担方。
5. **保留样品**：封样留存，作为后续比对的实物基准。

## 二、到货验收：怎么操作

1. **当场验收、限时验收**：冷链或易腐水果建议到货即验，别拖到第二天。
2. **随机抽样，不挑好的**：从不同箱/不同层随机抽取，避免供应商只在表层放好果。
3. **分区判定**：
   - 合格区
   - 不合格区（腐烂、压伤、规格不符）
   - 待定区（争议果）
4. **量化记录**：称重、计数、拍照/录像，记录不合格数量和比例，双方签字确认。
5. **整车/整批不一致时**：区分是"个别箱差异"还是"系统性以次充好"，前者可按比例扣款，后者可整批拒收。

## 三、售后处理：怎么追责和补救

1. **按合同执行**：不合格部分退货、换货、补发或折价扣款，明确时限。
2. **分级处理**：
   - 轻微不符：折价接收
   - 部分腐烂/规格不符：按比例扣款或补货
   - 严重不符/以次充好：整批拒收，运费和损失由供应商承担
3. **留证索赔**：验收照片、视频、签字单、称重记录，是扣款或索赔的依据。
4. **建立供应商评价**：多次品质不一致的供应商降级或淘汰，写进后续采购规则。

## 四、给单位的实操清单

- [ ] 合同里写清规格、等级、瑕疵比例、验收时限
- [ ] 到货当场随机抽样验收，全程拍照留证
- [ ] 不合格部分单独隔离、称重计数、双方签字
- [ ] 按约定折价/退换/扣款，限期补货
- [ ] 记录本次问题，纳入供应商考核

**一句话原则**：标准写在前、验收当场做、证据留齐全、售后按合同。这样品质不一致时才有据可依，不会变成扯皮。
