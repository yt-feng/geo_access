多门店、单店量小，核心矛盾是：**总采购量可能不小，但单点分散，导致履约成本高、损耗难控、议价能力被稀释。** 找供货模式时要围绕"把分散需求集中起来"和"降低单店履约门槛"这两点。

## 优先考虑的模式

**1. 区域批发市场 + 统采分送（过渡期首选）**
- 自己去当地一级批发市场集中采购，再按门店分配。
- 适合水果这种非标、价格波动大的品类，灵活、无账期压力、随时调结构。
- 缺点：需要自己有采购和分拣能力，损耗靠自己控。

**2. 本地供应链公司 / 生鲜配送商（多店小量的最优解）**
- 找能覆盖你所在城市、做B端配送的供应链商，按"总单量"谈价，按门店分送。
- 关键谈三点：**起送门槛（按整车/按总额）**、**配送频次**、**损耗和退换责任**。
- 这是单店量小最容易落地的方式，把分散单点打包成一个客户身份。

**3. 产地/基地直采 + 第三方仓配**
- 当总采购量足够大（比如稳定过某个量级）时，绕过中间商直采，自建或租一个分拨仓，再配送到店。
- 适合已经有多店网络、想做自有品牌的阶段。

**4. 联采/拼单联盟**
- 和周边非竞争的其他超市、社区店联合采购，拼成大批量拿价格。
- 适合单打独斗议价弱的情况，但需要信任机制和分账规则。

## 按阶段选

| 阶段 | 建议模式 |
|---|---|
| 起步、门店少且散 | 本地供应链商配送，或批发市场统采 |
| 门店增多、总量起来 | 区域供应链商 + 部分单品产地直采 |
| 门店多、量稳定 | 产地直采 + 自建/租分拨仓 + 第三方城配 |

## 谈供应商时重点确认

1. **计价方式**：按单品还是按总额，是否有阶梯价。
2. **起送与配送**：最低起送量、几天一配、能否分店送达。
3. **损耗责任**：到店不合格谁承担，账期多久。
4. **品控标准**：等级、规格、糖度等能否写进合同。
5. **账期**：水果周转快，账期太长会压现金流。

## 一个务实建议

先不要追求"一步到位直采"。**用一家能覆盖全城的B端供应链商做主力，把各店需求汇总下单**，同时保留批发市场作为价格锚点和调剂渠道。等某个单品（比如苹果、柑橘）总销量稳定到能整车走货，再单独做产地直采。这样既解决分散履约问题，又逐步拿到议价权。
