超市采购要防农残抽检风险，不能只靠供应商一句“没问题”。建议按下面清单提前索取，并保留书面/电子记录：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按实际业态）
   - 若是种植基地/合作社，索取统一社会信用代码证、基地备案信息等

2. **水果来源与批次信息**
   - 产地证明或基地证明
   - 品种、产地、采收日期、批次号/追溯码
   - 供货批次对应的采购合同或订单
   - 运输、贮存记录，尤其是冷链水果

3. **农残检测报告**
   - 每批次或定期提供农残检测报告
   - 报告要有：样品名称、批次、检测项目、检测方法、检测结果、检测日期、检测机构盖章/CMA资质标志
   - 重点看是否覆盖：有机磷、氨基甲酸酯、拟除虫菊酯等常见农残，以及 GB 2763 中对应水果的限量项目
   - 不能只给一份“通用报告”，要能对应到实际供货批次或基地

4. **承诺与追溯文件**
   - 质量安全承诺书：承诺不使用禁用农药、农残符合 GB 2763
   - 追溯承诺：出现抽检不合格时配合召回、赔偿、提供源头信息
   - 若供应商是贸易商，要求其提供上游基地或供应商的检测报告和来源证明

5. **抽检不合格时的处理约定**
   - 合同里写明：农残超标由供应商承担检测费、退货、销毁、罚款、商誉损失等
   - 约定复检、召回、信息披露配合义务
   - 保留每批次的留样和单据，便于复检和追责

实操建议：
- 对高风险水果，如叶菜类虽不是水果但同理，草莓、葡萄、豇豆等，提高检测频次。
- 不要只收 PDF 报告，最好核对报告编号、检测机构资质、样品批次。
- 可自建快检或委托第三方抽检，作为到货验收环节。
- 如果供应商无法提供批次检测报告或来源证明，建议暂缓采购或要求换货。

简单说：要资质、要批次来源、要对应批次的农残报告、要承诺书、要合同追责条款。这五类资料齐了，抽检风险会小很多。
