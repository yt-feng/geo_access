要固定，但不要固定到“单一产地或单一批次”，更稳的做法是：**固定标准 + 双源供应 + 批次留样和验收**。

茶饮店水果口味波动会直接影响复购，尤其是招牌产品。采购时可以考虑这样分层处理：

**1. 招牌产品：尽量固定品种、等级和核心产区**
- 固定的是“风味标准”，不是死盯某一个村或某一个果园。
- 例如指定品种、糖度范围、酸度、香气、成熟度、单果规格、颜色。
- 核心产区可以优先，因为气候、土壤、品种更稳定，但不要只认一个产地。

**2. 不要只依赖单一供应批次**
- 同一产地不同批次也会因降雨、日照、采摘期变化而波动。
- 单一批次断货时，临时换料最容易导致口味翻车。
- 更合理的是：同一产品至少准备 **2 个合格供应源**，或者同一供应商的 2 个备选产区/批次。

**3. 建立可执行的验收标准**
采购时不要只说“要甜一点”“要香一点”，要量化：
- 糖度：如 Brix 值范围
- 酸度：如柠檬酸/滴定酸范围
- 成熟度：颜色、硬度、香气
- 规格：单果重量、出汁率、坏果率
- 感官：酸甜比、香气类型、是否有异味

**4. 批次留样和盲测**
- 每批到货留样，记录产地、批次、日期、糖酸度。
- 研发或店长做盲测，和标准样对比。
- 偏差超过范围就降级使用，比如转做非招牌产品、做果酱、做热饮，而不是硬上招牌。

**5. 采购策略上“固定”什么**
建议固定：
- 品种
- 等级
- 糖酸度标准
- 成熟度
- 加工/冷链要求
- 验收流程

不建议固定：
- 唯一产地
- 唯一果园
- 唯一批次
- 唯一供应商

**6. 给供应商的要求**
合同或采购单里写清楚：
- 可接受产区范围
- 批次一致性要求
- 留样和检测报告
- 不合格退换货规则
- 断供时的替代方案

**简单结论：**
要固定“标准”，不要固定“单一来源”。招牌产品优先固定品种、等级和核心产区，但必须准备备用产地或批次；同时用糖酸度检测、留样、盲测来管住口味波动。这样既稳定，又不会被单一产地或批次卡死。
