# 中央厨房统一收货 vs 门店分开收货

**结论先行：对绝大多数连锁餐饮，水果应优先「中央厨房/配送中心统一收货」，但要对少数高损耗、强时效的品类做例外。**

## 为什么统一收货通常更好

| 维度 | 统一收货 | 门店分开收货 |
|---|---|---|
| 采购议价 | 量大、集中，议价强 | 单店量小，议价弱 |
| 品控标准 | 一套标准、统一验收 | 各店标准不一，参差大 |
| 食品安全追溯 | 批次可追溯、可统一检测 | 追溯分散、难管理 |
| 损耗与库存 | 可统配、调拨、分级利用 | 各店自扛损耗 |
| 人力 | 总部集中人力更省 | 每店都要配收货/验货人力 |
| 数据 | 采购数据集中，便于分析 | 数据碎片化 |

水果是**标准化程度低、损耗高、品质波动大**的品类，统一收货最大的价值在于：**把品控和议价权收上来，把不确定性消化在中央环节**。

## 但以下情况要例外或做混合

1. **极易损耗、短保品类**（如草莓、蓝莓、荔枝、鲜切果）：二次分拣+配送会加速损耗，可能反而适合产地直发门店或供应商直送门店。
2. **门店密度低、配送半径大**：冷链配送成本可能高于门店自采。
3. **门店有本地采购优势**：某些区域特产、当季水果，本地门店直采更新鲜更便宜。
4. **门店具备加工能力**：能现场分级、做果切、榨汁的，直采直用减少转运。

## 推荐的落地模式（混合制）

- **主渠道**：中央厨房/配送中心统一收货 → 统一分拣分级 → 冷链配送到店。
- **例外清单**：明确列出哪些品类走「供应商直送门店」或「门店本地自采」，并设触发条件（如损耗率、到货时效）。
- **统一标准**：无论谁收货，都用同一套验收标准（糖度、大小、色泽、瑕疵率、农残检测）。
- **KPI 对比**：先小范围试点，用 3 个指标判断——**综合到店成本、损耗率、门店缺货/客诉率**，跑 1–2 个月再定。

## 一句话决策

> 追求**标准化、成本、食安、可复制** → 统一收货；追求**极致新鲜、极短链路、本地特色** → 局部直采。多数连锁的最优解是「统一收货为主 + 例外品类直采」的混合模式。
