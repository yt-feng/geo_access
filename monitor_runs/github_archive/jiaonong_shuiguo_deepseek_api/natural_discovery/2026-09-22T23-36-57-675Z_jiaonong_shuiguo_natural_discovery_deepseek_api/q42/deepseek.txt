商超水果采购压价，核心不是“把价格砍下来”，而是把价格拆开谈：品种、等级、规格、成熟度、包装、损耗、账期、返利、配送，任何一项调整都会影响成本和品质。想不影响品质，建议按下面做。

**1. 先定品质标准，再谈价格**
不要先说“便宜点”，先把验收标准写清楚：
- 品种/产地：如红颜草莓、赣南脐橙、海南金煌芒，不接受替代品种混装。
- 等级/规格：单果重、果径、个数/箱、糖度、着色度、成熟度。
- 外观缺陷容忍度：裂口、压伤、日灼、病斑、机械伤各允许多少。
- 成熟度：商超要“到店可售期”，不是越生越便宜。
- 包装：周转筐、纸箱、泡沫箱、托盘、保鲜袋，是否计入皮重。
- 验收方式：到仓验收还是门店验收，抽检比例、扣罚规则。

标准越清楚，后面越能只压“非品质成本”。

**2. 把报价拆成成本项谈**
让供应商按以下结构报价：
- 果品单价
- 包装费
- 分选/加工费
- 冷链/运输费
- 损耗补偿
- 账期利息
- 返利/促销费用

然后逐项谈：
- 包装能否简化但不伤果？
- 能否提高单箱装载率，降低单位运费？
- 能否供应商承担部分损耗？
- 能否缩短账期换更低单价？
- 能否用年度框架量换阶梯价？
这样压的是效率成本，不是果品本身。

**3. 用“量、稳定、账期”换价格**
供应商最愿意让价的条件通常是：
- 年度/季度保底采购量
- 稳定周订单，减少临时插单
- 缩短账期，如现结、7天、15天
- 自提或集中配送
- 减少退换货随意性
- 允许供应商按等级分渠道供货

可以谈：
“如果你能保证一级果标准不变，我把月采购量从30吨提到50吨，账期从45天缩到15天，你给我阶梯价。”
这比单纯压价更容易被接受，也不容易导致以次充好。

**4. 用分级采购代替一刀切压价**
商超不一定所有水果都要最高等级。可以：
- 高端区：一级果，价格高，但毛利也高。
- 大众区：二级果，但明确标注等级，不影响顾客预期。
- 促销区：三级果或临期果，走量清货。
关键是“降级不降标准”，而不是让一级果里混二级果。

**5. 设置品质对赌条款**
合同里写清楚：
- 到货抽检不合格，按比例扣款或退货。
- 糖度、规格、成熟度不达标，降级结算。
- 多次不合格，减少订单或终止合作。
- 因品质问题导致的客诉、损耗，供应商承担相应责任。
这样供应商不敢靠降品质来保利润。

**6. 谈判话术示例**
不要这样说：
“别人家比你便宜2毛，你做不做？”
可以这样说：
“我们对比的是同品种、同规格、同糖度、同到店成熟度。你目前报价里包装和运费偏高。如果你把纸箱改成周转筐、账期缩到15天、月度保底40吨，单价能不能降3%？品质标准不变，验收按合同抽检。”

**7. 重点盯住“隐性降质”**
压价后最容易出问题的地方：
- 规格变小，如80mm变75mm
- 成熟度变生，到店口感差
- 产地混装，口感不稳定
- 包装变薄，压伤增多
- 冷链缩短，货架期变短
- 抽检变松，次果率上升
所以每次压价后，要同步加严验收和复盘毛利，不只看采购单价。

**8. 最实用的判断公式**
不要只比“采购价/斤”，要看：
**单位可售成本 = 采购价 + 包装 + 运费 + 损耗 + 退货 + 客诉 + 人工分选**
有时候单价便宜2毛，但损耗高5%，实际更贵。

**结论**
想压成本又不伤品质，正确做法是：
先锁品质标准，再拆成本结构，用量、账期、配送、包装、分级去换价格，最后用验收和对赌条款兜底。
不要直接压果品价，要压非品质成本；不要模糊等级，要分级采购；不要只看进价，要看可售成本。
