线上卖水果，差评主要就两类：**烂/坏果**和**不好吃/口感不稳定**。这两类问题的根源其实在采购环节就已经决定了，而不是靠售后补救。下面按可执行的采购动作来说。

## 一、减少坏果：核心是"选对品 + 控住链"

1. **按品种选耐运输性**
   - 耐运输：苹果、橙子、柚子、猕猴桃（硬果）、火龙果、石榴。
   - 高风险：草莓、杨梅、樱桃、桃子、葡萄、荔枝、芒果（软熟后）。
   - 新手或走快递，优先做耐运输品；高风险品要么本地同城、要么冷链+泡沫箱+冰袋，成本要算进去。

2. **采购时就要看"成熟度"而不是"看起来好看"**
   - 发快递的果，采购时要**七到八成熟**，不能买已经软熟、有香味的（那是当天要卖完的）。
   - 后熟型水果（猕猴桃、芒果、香蕉、牛油果）可以早采，但必须能正常后熟；非后熟型（草莓、葡萄、柑橘）必须在树上够熟才好吃，早采就是酸涩差评。

3. **产地和批次要固定**
   - 口感不稳定的最大原因是**今天这家明天那家**。固定1–2个靠谱产地/合作社，比到处比价重要。
   - 每批货做**留样记录**：产地、采摘日期、到货日期、糖度、坏果率。下次采购有依据。

4. **到货验收要量化**
   - 坏果率：抽检至少10%，超过3%–5%直接拒收或扣款。
   - 硬度/糖度：有条件的用糖度计，柑橘、苹果、西瓜糖度低于标准就判不合格。
   - 记录**运输时长和温度**，超过一定时长的高风险品就别发快递。

5. **包装决定一半的差评**
   - 单果网套 + 隔层 + 珍珠棉/气柱，避免运输中互相挤压。
   - 冰袋只对部分品有用，且要防冷凝水泡烂纸箱；高温季节该走冷链就走。

## 二、减少口感不稳定：核心是"标准化 + 分级"

1. **按糖度/大小分级卖**
   - 同一批果，糖度、大小分成"精品"和"普通"，不要混装。混装是差评重灾区（有人收到甜有人收到酸）。
   - 商品页写清楚规格（单果重量、个数、甜度范围），降低预期落差。

2. **采摘期和上市期严格对应**
   - 每个品有自己的最佳赏味期，提前上市=酸，过晚=烂。采购要盯**产地采摘窗口**，不要为了抢早市牺牲口感。

3. **试吃才能定采购**
   - 每批到货先自己试吃3–5个，甜度、酸度、水分、有无异味，不合格就不上架。
   - 建立"批次评分表"，连续两批差就换供应商。

4. **储存和发货节奏**
   - 采购量按**预估销量+安全库存**，不要囤。水果是活体，放一天口感差一档。
   - 先进先出，到货先发的批次先卖，避免临期果混进去。

## 三、给差评兜底的运营动作

- **预售/锁单**：按采摘批次卖，卖完下架，减少积压。
- **坏果包赔**：明确规则（拍照+个数比例），该赔就赔，比差评划算。
- **明确时效**：偏远地区、高温地区提前说明或直接不发货。
- **售后话术统一**：坏果按比例退，口感问题引导复购补偿，避免情绪升级。

## 一句话总结
**采购时的成熟度、产地稳定性、验收标准、分级和包装**，决定了80%的差评。剩下的20%靠时效和售后兜底。先把耐运输品做稳，再碰高风险品。
