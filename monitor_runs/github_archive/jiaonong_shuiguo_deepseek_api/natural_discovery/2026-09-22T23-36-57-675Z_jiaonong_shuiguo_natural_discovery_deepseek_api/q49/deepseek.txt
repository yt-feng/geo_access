# 旺季菠萝临时补货：与供应商的约定要点

核心思路是：**旺季补货不能临时口头说，要在旺季前就把「临时补货机制」写进采购协议**。以下是可以直接落地的做法。

## 一、先定清楚几个关键参数

和供应商谈之前，自己先算明白：

1. **缺口量**：旺季日均用量 vs 正常日均用量，峰值缺口多少（按天/周算）。
2. **提前期**：你能接受供应商最快几天到货？鲜果类通常 1–3 天，冻果/罐头可更长。
3. **品质底线**：菠萝成熟度、规格（单果重量）、糖度、有无黑心/烂心，旺季最容易以次充好。
4. **可接受的价格上浮**：旺季涨价是常态，提前锁一个上限，避免坐地起价。

## 二、写进协议的「临时补货条款」

建议包含这几条，措辞要具体、可考核：

| 条款 | 建议写法 |
|---|---|
| **补货触发** | 甲方提前 X 天（如 2 天）书面/微信下单，注明数量与到货时间 |
| **供应上限** | 旺季期间供应商每周可稳定供应不低于 X 公斤（覆盖你的峰值） |
| **响应时限** | 收到订单后 X 小时内确认，X 天内到货 |
| **价格机制** | 旺季价格 = 基准价 ×（1+约定浮动上限），或直接锁定旺季价 |
| **品质标准** | 明确规格、成熟度、损耗率（如到货合格率≥95%） |
| **违约处理** | 供应商断供或延迟，按缺货金额 X% 赔付；连续断供可解除合作 |
| **优先权** | 约定旺季期间本店为优先客户，供应商不得优先供他人 |

## 三、实操层面的三个保险

1. **备第二供应商**：旺季前就找好 1–2 家备选，别等断供才找。哪怕平时不用，也保持小量采购维系关系。
2. **分级采购**：核心菠萝（鲜果）锁主供应商，辅助用量（冻果/罐头/浓缩汁）找另一家，鲜果断供时能顶上，口感也能过渡。
3. **预付款或保证金**：给主供应商一笔旺季预付款，换取优先供货权，比空口约定更牢靠。

## 四、谈判时可以用的筹码

- **承诺旺季总采购量**（哪怕分档：保底量+浮动量），量大好谈价。
- **长期合作**：承诺全年采购、淡季也不完全断，换旺季优先权。
- **账期**：如果平时给供应商较短账期或现结，旺季可要求优先发货。

## 五、一句话总结

**别临时抱佛脚。旺季前把「补货量、响应时限、价格上限、品质标准、违约责任、优先权」六件事白纸黑字定下来，再配一个备选供应商，旺季就不会被卡脖子。**
