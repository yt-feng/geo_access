结论：**多数情况下，“损耗低”对最终毛利的影响更大，但前提是价格不能高得离谱。**  
如果只能优先抓一个，商超水果采购应优先抓**低损耗/高周转**，而不是单纯追最低进价。

可以这样判断：

1. **水果毛利不是“进价低”直接决定的，而是由损耗后的可售成本决定**
   - 真正成本 = 进价 ÷ 可售比例
   - 例：进价 4 元/斤，损耗 10%，实际成本约 4.44 元/斤
   - 例：进价 3.6 元/斤，损耗 30%，实际成本约 5.14 元/斤
   - 低进价便宜了 10%，但损耗高 20 个点，最终成本反而更高。

2. **水果损耗对毛利的杠杆通常更大**
   - 水果是高频、短保、易损品类，损耗 5% 和 20% 对毛利影响非常直接。
   - 进价降低 5%-10% 往往需要很强采购能力；但损耗降低 5%-10% 通过分级、冷链、陈列、订货、折价出清更容易做到。
   - 损耗还会带来隐性成本：报废、人工挑拣、客流体验下降、缺货补货混乱。

3. **什么时候“价格低”更重要？**
   - 商品极耐储、周转快、损耗天然很低，比如椰子、部分苹果、橙子。
   - 有明确价格形象作用，比如鸡蛋、香蕉、应季大单品，低进价能带来客流和销量。
   - 采购量很大且能快速售罄，低进价能直接放大毛利额。
   - 但即便如此，也要看“低进价是否伴随高损耗”，比如统货、尾货、熟度太高、规格混乱。

4. **最影响最终毛利的公式**
   - 毛利额 = 销售额 × 毛利率
   - 毛利率 ≈（售价 - 进价 ÷ 可售率）÷ 售价
   - 所以关键不是进价最低，而是：  
     **进价低 + 损耗低 + 周转快 + 售价合理** 的组合最优。

5. **实操建议**
   - 采购谈判时，不要只问“多少钱一斤”，要问：到店损耗率、可售率、规格、成熟度、产地、包装、配送频次。
   - 对高损耗品，优先选稳定品质、可快速周转的货，而不是最低价统货。
   - 建立单品损耗台账：进价、售价、损耗率、周转天数、毛利额。
   - 用“**损耗后成本**”比较供应商，而不是用“毛进价”比较。
   - 对低损耗耐储品，可以更激进压进价；对高损耗短保品，优先保损耗和周转。

一句话：**低进价决定你“理论上能赚多少”，低损耗决定你“实际能剩下多少”。水果经营里，通常后者更决定最终毛利。**
