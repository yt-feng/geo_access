想避免买到太生或太熟的香蕉，关键不是“挑颜色”这么简单，而是**按你打算几天内吃完来选成熟度**。下面给你一套到店就能用的判断法。

**一、先定用途，再定颜色**
- **当天吃**：选**通体金黄、少量棕色斑点**的，最甜最软。
- **1～2天内吃**：选**金黄但两端略带一点绿**，或黄中带一点青。
- **3～5天吃**：选**整体偏绿、但已经能看出黄色**，也就是从青转黄初期。
- **超过5天吃**：选**青绿色、硬实**的，回家常温放熟。
- **要做奶昔、烘焙**：可以选带黑斑的熟蕉；要切片煎，选偏硬一点。

**二、到店看这4个部位**
1. **看整体颜色**  
   全青=很生；青中带黄=会继续熟；全黄=接近即食；黄带黑斑=很快要吃完。
2. **看果柄和两端**  
   果柄发绿通常更生；两端发黑、发软说明熟过头或存放久了。
3. **轻捏中部**  
   硬得像石头=生；轻按有弹性=刚好；一按就凹=太熟。
4. **看棱角**  
   香蕉棱角分明、很方=偏生；棱角变圆润=成熟。这个比只看颜色更准。

**三、避开两个坑**
- **不要只看“黄不黄”**：有些香蕉是催熟或用低温“保色”，看着黄但中间还硬。
- **不要买已经裂口、渗水、大面积黑斑的**：除非你当天就吃或做烘焙。

**四、如果买回家发现不对**
- **太生**：和苹果或熟香蕉一起放纸袋里，常温1～2天会快熟；别放冰箱。
- **太熟**：立刻冷藏可延缓继续变黑，但表皮会变深；果肉还能吃。也可以剥皮冷冻，之后做奶昔。
- **想拖几天再吃**：买偏青的，回家先常温放；一旦变黄，再放冰箱冷藏，能多撑几天。

**最稳的买法**：如果你计划3天内吃完，就买“金黄带一点点绿”的；如果当天吃，买“金黄带少量糖斑”的；如果要放一周，买“青黄相接”的。这样基本不会到店太生或太熟。
