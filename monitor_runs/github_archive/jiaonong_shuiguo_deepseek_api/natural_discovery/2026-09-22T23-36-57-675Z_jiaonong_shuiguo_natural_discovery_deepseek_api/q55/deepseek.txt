做水果拼盘时，规格选择的核心不是“越大越划算”或“越小越省”，而是看**出成率、损耗、切配效率和顾客感知**。按餐厅常用做法，可以这样判断：

**1. 苹果：选中大果，别选特大果**
- 建议规格：单果 200–280 克左右，口径 75–80mm 比较稳。
- 原因：太大果核比例不一定低，切开后每片宽度大，拼盘摆盘容易显得笨重；太小则削皮去核后出成率低，切出来片小、数量多，费人工。
- 划算点：按“净肉率”算，不是按斤价算。中等偏大果通常净肉率更稳定，损耗可控。
- 注意：如果做薄片卷花，选脆度高、大小均匀的；如果做块状，选稍大一点更省刀工。

**2. 橙子：选中果，皮薄、汁多、大小均匀最重要**
- 建议规格：单果 180–250 克，横径 70–75mm 左右。
- 原因：橙子太大，皮厚、白瓤多的情况常见，切瓣后修边损耗大；太小则切出来瓣短，拼盘显得不饱满。
- 划算点：优先看“可食率”和出汁后是否容易散瓣。餐厅做拼盘通常去皮切瓣或切片，要求瓣形完整、不流汁太多。
- 如果做橙子片围边，选大小一致的中果，摆出来整齐，比大小混用更省时间。

**3. 菠萝：选成熟度合适的中大果，按“去皮后净重”算**
- 建议规格：单果 1.2–1.8 公斤比较常用。
- 原因：太小去皮去眼后净肉少，出成率低；太大虽然单价可能低，但一次用不完，切开后氧化、出水、损耗会吃掉利润。
- 划算点：如果餐厅用量大，买整果自己削更省；如果用量不稳定，买已去皮菠萝或菠萝块更划算，因为减少报废和人工。
- 注意：菠萝出成率通常只有 40%–55% 左右，算成本时要按净肉算，不能按毛重算。

**通用判断公式：**
> 实际划算度 = 净可用果肉重量 ÷ 采购毛重 × 单价  
> 再叠加：切配人工 + 报废损耗 + 摆盘效果

**餐厅最稳的选法：**
- 苹果：75–80mm 中大果，脆度好、大小匀。
- 橙子：70–75mm 中果，皮薄、瓣完整。
- 菠萝：1.2–1.8kg 中大成熟悉果，按净肉率算。
- 如果拼盘固定份量，优先买**规格统一**的，而不是单纯买最便宜的。统一规格切出来一致，损耗低、摆盘快、顾客感知也更好。

**简单结论：**
苹果选中大、橙子选中、菠萝选中大；都按“去皮去核后的净肉成本”比较，不按毛重单价比较。用量大买整果，用量小或人工紧买净果/半成品。
