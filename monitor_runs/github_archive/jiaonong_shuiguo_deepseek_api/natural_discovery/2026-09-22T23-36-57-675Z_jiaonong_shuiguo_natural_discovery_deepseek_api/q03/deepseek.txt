夫妻店第一次找水果供货商，试单的核心目标不是“拿到最低价”，而是**低风险验证供货商是否靠谱**。建议按下面几步做。

## 1. 先定试单原则

第一次不要压价压太狠，也不要一次进太多。重点是看四件事：

- **到货品质稳不稳**
- **损耗大不大**
- **缺货/晚到怎么处理**
- **结算和售后是否痛快**

常见货里，香蕉、苹果、橙子正好可以分别测不同能力：

| 品类 | 主要测什么 | 试单建议 |
|---|---|---|
| 香蕉 | 催熟、到货成熟度、损耗 | 少量试，重点看颜色、硬度、青黄比例 |
| 苹果 | 分级、硬度、碰伤、耐储 | 可稍多试，看大小是否均匀、有无暗伤 |
| 橙子 | 酸甜度、皮厚、水分、大小 | 中等量试，看口感稳定性和坏果率 |

## 2. 试单量怎么定

第一次建议：

- 香蕉：**1-2箱**，别多，成熟度变化快
- 苹果：**2-3箱**，相对耐放，可测稳定性
- 橙子：**2-3箱**，测口感和坏果
- 总金额控制在你能承受“全亏也不影响经营”的范围内

如果是本地批发市场拿货，可以当天少量拿；如果是产地或平台供货，第一次最好**小批量+要求发样或看实拍**。

## 3. 试单前必须问清的问题

找供货商时直接问，不要怕显得外行：

1. **今天这批货是什么等级？** 统货、一级、精品果？
2. **香蕉是青的、黄的，还是催熟好的？** 到店后能放几天？
3. **苹果是哪个规格？** 70、75、80、85？箱重多少？
4. **橙子是哪个品种？** 脐橙、冰糖橙、沃柑？酸甜大概什么口感？
5. **坏果怎么赔？** 是按比例补，还是下次抵扣？
6. **少货、晚到、品质不对怎么处理？**
7. **起送量多少？配送费谁出？**
8. **能不能先看实拍或视频？**
9. **今天什么价，明天会不会变？**
10. **结算是现结、周结还是月结？**

## 4. 到货后怎么验收

一定要当场或第一时间验，别等卖完再说。

### 香蕉
- 看青黄比例：太青要放很久，太黄容易当天黑斑
- 摸硬度：过硬、过软都不好
- 看有没有裂口、发黑、水烂
- 记录：到货成熟度、第2天、第3天变化

### 苹果
- 看大小是否均匀
- 看有没有碰伤、暗伤、软点
- 切开几个看内部是否发面、黑心
- 称一箱净重，看是否带箱压秤

### 橙子
- 看大小、皮色、是否有烂点
- 切开试吃：水分、酸甜、化渣
- 坏果单独放，拍照记录
- 看一箱里坏果几个，算坏果率

## 5. 试单期间怎么记录

建议简单记一张表：

| 日期 | 品项 | 进货量 | 进价 | 坏果数 | 损耗率 | 卖价 | 售完天数 | 售后处理 |
|---|---|---|---|---|---|---|---|---|
| 第1天 | 香蕉 | 2箱 |  |  |  |  |  |  |
| 第1天 | 苹果 | 3箱 |  |  |  |  |  |  |
| 第1天 | 橙子 | 3箱 |  |  |  |  |  |  |

重点看：
- **实际能卖的钱**
- **坏掉扔掉的量**
- **顾客有没有回头买**
- **供货商售后是否及时**

## 6. 判断要不要继续合作

可以继续合作的标准：

- 坏果率低，常见货控制在**5%以内**比较理想，超过10%就要警惕
- 到货成熟度适合你店里的客流速度
- 缺货、晚到能提前说
- 售后不扯皮，补货或退款痛快
- 价格不是最低，但综合损耗后划算

不建议继续的情况：

- 第一次就压货、逼你多拿
- 坏果不认，说是你存放问题
- 规格和说好的不一致
- 香蕉到货已经快烂，根本卖不及
- 结算前后态度差别大

## 7. 实操建议

第一次可以同时找**2-3家**供货商，各拿一点：

- A家：拿香蕉+橙子
- B家：拿苹果+橙子
- C家：备用，先加微信看报价

同一品类对比后，再决定主力供货商。不要一开始只绑一家，也不要同时铺太多家，否则售后和记账会很乱。

一句话：**少量试、当场验、记录损耗、看售后，第二次再放量。**
