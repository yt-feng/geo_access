判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要从**产地结构、硬件设施、合作案例、风险预案**四个维度交叉验证。

## 一、看产地结构是否多元

香蕉是典型的季节性+区域性问题水果，单一产地必然有断供期。

- **国内主产区**：广西、云南、海南、广东、福建，各自上市期不同。海南约2-5月，云南约3-6月，广西约8-12月。如果供应商只依赖一个产区，夏季或冬季大概率断供。
- **进口来源**：菲律宾、越南、厄瓜多尔、老挝等。全年稳定供货的供应商通常同时做国产+进口，用进口补国产空档。
- **关键提问**：请对方列出全年各月份的主要供货产地，并说明切换逻辑。答不上来的基本可以排除。

## 二、看硬件和供应链能力

- **有没有自有或长期合作的催熟库**。香蕉必须催熟后到店，没有催熟能力的供应商，旺季能供、淡季就供不上。
- **冷库和冷链运输能力**。香蕉对温度敏感，全程13-15℃。没有冷链的供应商，夏季损耗大、供货不稳定。
- **种植基地是自有还是收购**。自有基地面积、合作农户数量、年产量数据，能反映货源厚度。纯“倒手”的贸易商抗风险能力弱。

## 三、验证真实供货记录

- **要求提供过去12个月的供货台账**，看是否有断供、量波动。
- **查合作客户**：是否给其他连锁超市、生鲜平台长期供货，供了多久。可以侧面打听。
- **试用期验证**：先签3-6个月小单，重点观察淡季（比如夏季国产蕉退市时）是否还能按量按质供货。这是最硬的检验。

## 四、看风险预案

问对方三个问题：

1. 主产区遭遇台风/寒潮/病害时，备用货源在哪？
2. 进口通道（口岸、船期）出问题怎么补？
3. 春节、台风季等特殊时段，如何保证量和价？

能给出具体替代产地、替代渠道和应急库存方案的，才算合格。

## 实操建议

- **不要独家依赖**：至少储备2-3家供应商，主供+备供，按比例分配订单。
- **合同里写清**：月度最低供货量、断供违约责任、价格波动机制。
- **建自己的小台账**：记录每家供应商每月实际到货量、合格率、断供次数，半年就能筛出真正稳定的。

一句话总结：**全年稳定 = 多元产地 + 催熟冷链硬件 + 可查的历史记录 + 明确的应急方案**，缺一项都要打问号。
