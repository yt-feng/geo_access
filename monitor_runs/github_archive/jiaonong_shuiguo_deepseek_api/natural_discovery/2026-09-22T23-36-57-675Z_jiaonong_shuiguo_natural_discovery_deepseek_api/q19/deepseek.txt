这四者不是并列关系，**先分主次**：

1. **切果损耗**：这是最该先关注的经营指标。  
   对超市来说，菠萝是低单价、高损耗品类。损耗高，甜度再高也可能不赚钱。重点看：去皮去眼后的出肉率、坏果率、切后氧化/变质速度、当天切果报废量。

2. **甜度**：决定复购和口碑。  
   但超市很难逐个测糖。实操上看品种、产地、季节、成熟度，配合试吃或抽测。甜度不稳定，顾客买一次不甜，下次就不买。

3. **外观**：影响首次购买和陈列。  
   外观好能引流，但菠萝有厚皮，外观和内部品质不完全一致。不能只看颜值，否则容易“好看不好吃”，反而增加投诉。

4. **大小**：影响定价和场景。  
   大小决定按个卖还是按斤卖、适合家庭还是即食。太大可能单价高、一次吃不完；太小出肉率低、切果不划算。应结合客群选规格。

**建议的优先级：**
- 如果是**整果销售**：甜度/成熟度 ≥ 外观 ≥ 大小 ＞ 损耗  
- 如果是**切果销售**：切果损耗 ≥ 甜度 ≥ 大小 ≥ 外观  
- 如果只能盯一个指标：**盯切果损耗和出肉率**，因为它直接决定毛利。

**可执行做法：**
- 每批到货抽 3～5 个测：去皮后净重、出肉率、糖度、坏心率。
- 记录“进货量—切果量—报废量”，算出真实损耗率。
- 甜度不稳定的批次，优先做试吃、切果或促销，不要硬按整果高价卖。
- 外观差但内质好的，转切果；外观好但口感差的，不要主推。
