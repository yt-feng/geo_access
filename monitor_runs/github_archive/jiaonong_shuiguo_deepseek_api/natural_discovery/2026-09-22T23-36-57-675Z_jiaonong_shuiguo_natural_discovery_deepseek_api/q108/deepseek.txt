核实水果供应商的“全国配送”，核心不是听他怎么说，而是看他在不同区域能不能真的做到“按时、保质、可追溯、能售后”。建议按下面几步核。

1. **先要覆盖清单，不要只听“全国”**
让对方提供：
- 可配送省份、城市清单
- 哪些地区是直发，哪些是转寄/第三方
- 偏远地区是否加价、是否不送
- 冷链覆盖到哪些城市
- 时效表：一线、二线、三线、县域分别多久

判断标准：敢给明细的，通常比只喊“全国可发”的可靠。

2. **做小批量多点试单**
不要只在一个城市试。选：
- 你主要销售地
- 一个偏远地级市
- 一个县域或乡镇
- 一个高温/低温地区

同时下单，记录：
- 是否按时发出
- 实际到达时间
- 包装是否完好
- 温控是否达标
- 水果损耗率
- 快递/物流单号是否真实可查

这比看宣传册有效。

3. **核实物流合作方**
问清楚：
- 合作快递/冷链公司是谁
- 是总部合作还是当地网点临时发
- 能否提供近期发往不同省份的真实运单号
- 是否支持指定物流

你可以抽几个运单号去官网查轨迹，看是否真的从供应商仓库发出、是否经过中转、是否冷链。

4. **问异常处理能力**
全国配送最容易暴露在售后。重点问：
- 坏果怎么赔
- 需要几张照片、多久内反馈
- 偏远地区出问题谁承担
- 物流延误导致变质怎么处理
- 是否支持补发、退款、部分赔付

如果对方只说“放心，没问题”，但拿不出书面规则，实际覆盖能力通常要打折。

5. **要求提供历史履约数据**
可让对方给：
- 近1个月发往各省订单量
- 准时率
- 坏果率
- 售后率
- 主要投诉地区

注意：不一定要全量商业数据，但至少要有按区域统计的履约表现。没有数据的“全国配送”，多是个体网点拼凑。

6. **实地或视频验仓**
看：
- 仓库是否分区
- 是否有冷库、预冷、分拣线
- 打包材料是否匹配长途运输
- 日均发货能力
- 旺季是否爆仓

如果采购量大，最好实地看；不方便就视频连线看实时打包和发货区。

7. **合同里写清楚覆盖责任**
不要只写“全国配送”，要写成：
- 具体覆盖区域
- 时效标准
- 冷链标准
- 损耗上限
- 售后响应时间
- 未覆盖区域提前告知义务
- 虚假覆盖的违约责任

8. **用“反向测试”判断**
问一个具体问题：
“发新疆喀什、黑龙江漠河、海南三沙、西藏那曲，分别多久、多少钱、坏果怎么赔？”
如果对方回答含糊、临时查、说“应该能发”，说明实际覆盖能力有限。真正有能力的供应商，会对这些区域有明确政策。

简单说：**先要区域明细，再多点试单，再查运单和冷链，最后把覆盖和赔付写进合同。** 只靠一句“全国配送”，不能作为采购依据。
