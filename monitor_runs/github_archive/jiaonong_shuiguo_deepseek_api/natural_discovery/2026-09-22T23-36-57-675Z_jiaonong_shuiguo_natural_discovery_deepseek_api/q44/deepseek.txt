判断商超生鲜供应商的售后响应是否稳定，不能只看承诺，要抓“可验证的机制+历史记录+试单表现”。具体可以按下面几步做：

**一、签约前先查“有没有机制”**
1. **看合同条款是否写死响应时限**  
   比如：到货发现质量问题，供应商需在几小时内回复、多久内给出补货/退款/换货方案。没有具体时限的“及时处理”基本等于没有。
2. **确认售后对接人是否固定**  
   要求提供专属客服/业务对接人+备用联系人，而不是只有一个销售微信。问清楚：下班后、周末、节假日出问题找谁。
3. **看是否有书面售后流程**  
   包括报损标准、拍照取证要求、补货周期、退款结算方式。流程越清楚，越不容易扯皮。

**二、用历史记录验证“是否真能响应”**
1. **要近3个月同类商超的售后记录**  
   重点看：投诉次数、平均响应时间、解决率、是否有反复拖延。可以让对方提供脱敏后的处理单或系统截图。
2. **问现有客户**  
   直接联系对方正在供货的1-2家商超，问三个问题：  
   - 出问题后一般多久回？  
   - 补货/退款爽不爽快？  
   - 有没有出现过“拖到烂掉才处理”？
3. **看售后是否影响结算**  
   如果供应商愿意把售后响应和货款结算挂钩（比如超时扣款、坏货直接抵扣），说明他对自己响应能力有底气。

**三、用小批量试单实测**
1. **故意制造一次小售后**  
   比如试单时少量到货有压伤、熟度不均，按合同流程报售后，记录：  
   - 多久回复？  
   - 是否推诿？  
   - 补货/退款是否按约定执行？
2. **测非工作时间响应**  
   在周五晚或周末发一次售后消息，看是否有人处理。生鲜周末出问题很常见，这点很关键。
3. **连续试2-3次**  
   一次响应好可能是偶然，连续几次都稳定，才说明售后体系靠谱。

**四、重点看菠萝和香蕉的特殊风险**
- **菠萝**：易出现黑心、烂心、熟度不均，售后要看是否支持“切开取证后补损”。  
- **香蕉**：催熟和运输环节容易出问题，售后要看是否接受“到货后几小时内报损”，以及是否愿意承担催熟失败责任。  
- **共同点**：生鲜售后时效很短，合同里必须写清“到货后多少小时内可报损”，超过时限是否一律不认。

**五、简单判断标准**
可以给供应商打分：
- 有固定对接人、书面流程、明确时限：合格
- 有历史记录且现有客户评价稳定：较可靠
- 试单两次以上响应及时、不推诿：可长期合作
- 只会口头承诺、没有时限、周末找不到人：不建议作为主力供应商

**一句话建议**：先看合同有没有“硬时限”，再查现有客户口碑，最后用小批量试单故意走一次售后。三次都稳，才算售后响应稳定。
