采购香蕉时，核心是**按用途分熟度**，不要只按"黄不黄"判断。

**1. 按用途定熟度**

- **做冰沙/奶昔/香蕉牛奶**：用**7–8成熟**，表皮黄、略带青肩，果肉硬挺。太生有涩味，太熟打完容易发黑、发酸。
- **做香蕉泥、酱料、蛋糕夹层**：用**8–9成熟**，表皮金黄、少量糖斑。甜度高、香气足，压泥顺滑。
- **做装饰切片、烤香蕉、焦糖香蕉**：用**6–7成熟**，果肉硬，切片不烂，烤后形状好。
- **做香蕉面包、磅蛋糕**：可用**9–10成熟**，表皮大量黑斑、果肉软，风味最浓，还能减少糖量。

**2. 采购时看什么**

- **看颜色**：青黄适合存放；金黄可近期用；带黑斑要马上用。
- **摸硬度**：轻按有弹性但不塌陷最好。塌陷说明过熟。
- **看棱角**：棱角明显偏生；圆润饱满偏熟。
- **看果柄**：果柄发黑、发软，通常已过熟或存放久。
- **闻气味**：有明显酒味、酸味，不要采购。

**3. 控制到货节奏**

- 不要一次全进同熟度。按**未来1–3天用量**进金黄果，**3–5天用量**进黄中带青果。
- 夏季高温催熟快，采购熟度要**降一档**；冬季可**升一档**。
- 香蕉怕压、怕冷。到货后**常温、通风、避光**存放，不要直接放冷藏，除非已经全熟且要延缓继续熟化。

**4. 门店简单催熟/延缓方法**

- 想快熟：和苹果或乙烯利包放一起，常温密封，但每天检查。
- 想慢熟：全熟后拆袋通风，或冷藏果肉已剥皮的香蕉，但带皮冷藏会发黑。
- 已过熟：立刻去皮冷冻，做冰沙或香蕉泥，不要继续常温放。

**5. 验收标准建议写进采购单**

可以规定：
- 冰沙用：黄皮带青肩，硬度中等偏硬。
- 甜品泥用：金黄，少量糖斑，轻按有弹性。
- 装饰用：黄皮带青，果肉硬，无压伤。
- 拒收：大面积黑斑、渗汁、酒味、果柄霉变、严重压伤。

简单说：**生一点的用来打、切、烤；熟一点的用来压泥、做酱、烘焙。采购时按用途分批进，别只看"黄不黄"。**
