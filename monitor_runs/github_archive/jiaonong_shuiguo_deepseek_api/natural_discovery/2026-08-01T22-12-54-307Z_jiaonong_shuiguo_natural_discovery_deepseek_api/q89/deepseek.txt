针对团购客户价格敏感，**阶梯价（数量折扣）通常比返利更合适**，尤其是在初次谈判和快速成交阶段。原因和具体建议如下：

**1. 为什么阶梯价更合适：**
- **即时感知**：客户能立刻看到“买越多省越多”，直观满足“占便宜”心理，降低决策门槛。
- **降低双方沟通成本**：价格透明，无需事后计算返利，避免客户因“返利兑现周期长”而产生不信任。
- **锁定订单规模**：阶梯价能激励客户最大化单次采购量（如达到500件单价降5%），直接推高团购订单金额。

**2. 什么时候可以辅以返利：**
- **作为二次激励**：如果客户已经达到最高阶梯价，且坚持要求再优惠，可以承诺“季度返利”或“年度返利”作为增值承诺。
- **针对长期大客户**：如果客户持续复购且年采购量大，可用返利绑定年度合作，但前提是**合同需明确返利门槛、核算周期和支付方式**（如次年一季度结算）。

**3. 关键执行建议：**
- **阶梯设计要“越级明确”**：建议设置3档（如100/300/500件），阶梯差价建议在3%-8%之间，不宜超过10%，否则影响毛利。
- **返利需设门槛**：如果确实用返利，不要无限期通用，建议是“单次订单满X万元，次月可等额抵扣下一单货款”，这样能减少现金流压力。
- **话术重心**：面对价格敏感客户，先强调阶梯价的“锁价”优势——高阶梯价在合同期内（如3个月）保持不变，避免后续涨价风险。

**4. 特别提醒：**
- 如果客户采购量非常大（如超过供应商产能的20%），且要求返利，需警惕**客户集中度过高风险**，务必计算底价，避免亏本成交。
- 无论选哪种，建议先问清客户的**预算上限**和**单次可决策量**，再决定报价策略，不要盲目给低价。
