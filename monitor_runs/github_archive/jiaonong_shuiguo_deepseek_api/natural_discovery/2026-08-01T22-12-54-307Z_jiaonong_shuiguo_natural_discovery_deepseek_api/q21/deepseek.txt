在超市采购水果时，为确保食品安全和质量，供应商通常需要提供以下检测报告或进货证明：

1. **检测报告（质量检测）**：
   - **农残检测报告**：最常见，需证明农药残留符合国家限量标准（如GB 2763）。
   - **重金属检测报告**：如铅、镉、汞等，尤其对产自工业区或特定土壤的水果。
   - **微生物检测报告**（部分水果如鲜切水果）：需检测大肠杆菌、沙门氏菌等。

2. **进货证明（合法性）**：
   - **供应商营业执照**：确认合法经营资质。
   - **水果产地证明**：如由农业合作社、产地村委会或农业部门出具的产地证明，或“一村一品”证明。
   - **合格证/合格证明书**：部分地方要求附带“食用农产品合格证”，说明产地合格和自检合格。

3. **溯源资料**：
   - **进货台账/出货单**：标明品种、数量、来源地、供应商信息，便于追溯。
   - **运输证明**（跨区域时）：如冷链运输记录，确保水果在运输中未变质。

4. **其他关键文件**：
   - **进口水果**：需提供《入境货物检验检疫证明》和《海关进口货物报关单》。
   - **有机/绿色认证**（如有宣称）：需提供有效认证证书复印件。

**建议**：超市可要求供应商在每次供货前附上近期（如一个月内）的检测报告原件或复印件，并留档备查。同时，建议超市自行做快检抽检（如农残快速检测试纸），双保险保障。

若供应商无法提供上述基本证明，超市应谨慎采购，避免食品安全风险。在实际操作中，不同地区和超市内部标准可能略有差异，以当地市场监管部门要求为准。
