商超采购菠萝时，“卖整果”和“卖切好的”**并不是二选一**，而是应该**“双渠道并行，按场景和时段差异化主推”**。具体建议如下：

### 1. 核心结论：两者都要做，但定位不同
- **整果**：适合追求“新鲜感、仪式感、送礼、家庭囤货”的顾客。毛利较高，损耗风险取决于周转速度。
- **切好的（果切盒）**：适合“即买即食、办公室白领、单人食、怕处理麻烦”的顾客。毛利更高，但损耗控制是关键。

### 2. 按门店类型/时段动态调整
- **社区店 / 家庭客流为主**：建议**以整果为主（占比60-70%）**，切好的作为补充（30-40%）。因为家庭用户更愿意自己削，且对价格更敏感。
- **写字楼 / 人流密集的商圈店**：建议**以切好的为主（占比60-70%）**，整果做展示引流。白领午休、下班时段（11:00-13:00，17:00-19:00）是果切销售高峰。
- **周末/节假日**：整果销量会上升（家庭采购），果切销量下降（外食减少），需提前调整备货比例。

### 3. 必须规避的“坑”与执行建议
- **鲜切菠萝的保鲜难题**：菠萝切开后极易氧化变味，**不建议提前大量备货**。建议采用“**现场削皮+严控售卖时长**”模式：切好后放入冷藏展示柜，**售卖超过4小时必须打折或报损**，否则顾客投诉率极高。
- **定价策略**：果切盒的克重毛利应高于整果（例如整果毛利30%，果切毛利需达到50%才能覆盖人工和损耗）。按“果切价格 = 整果价格 × 1.5倍左右”制定，但不能过度高价导致滞销。
- **展示与教育**：整果区放“削皮器”免费试用的演示视频；果切盒上必须标注“切制时间”，增强信任度。
- **供应链协同**：采购时明确要求供应商提供适合鲜切的品种（如台农17号、都乐金菠萝），这类菠萝纤维短、甜度高，切块后风味更稳定。普通大青芒等皮厚品种不适合做果切。

### 4. 关于“损耗”的落地管控
- 整果损耗主要靠“快周转”：每日早晨到货后，将表皮有瑕疵的主动转为“特价整果”或“现场削皮果切”。
- 果切损耗靠“小批量多频次”：每次只切2-3个，卖完再切，宁可断货也不要积压。

### 5. 如果非要二选一（预算/人力有限时）
优先选**卖切好的**。原因：
1. 客单价更高（果切盒通常定价20-30元，整果一般15-20元）。
2. 坪效更高（同等面积，果切陈列毛利贡献更大）。
3. 更符合年轻消费趋势，且能规避“顾客买回去不会挑甜度导致投诉”的问题。

但前提是：**门店必须配置冷藏设备和熟练的切配人员**。如果没条件，就老实卖整果，避免因氧化变质引发食安投诉。

**最终建议**：采用“整果引流 + 果切增收”的组合策略。每天上午主推整果，下午3点后主推果切，并根据当日客流动态调整加工量。
