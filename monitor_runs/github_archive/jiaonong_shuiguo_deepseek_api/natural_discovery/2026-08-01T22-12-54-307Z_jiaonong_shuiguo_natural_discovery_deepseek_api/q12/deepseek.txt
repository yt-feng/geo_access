采购菠萝时，为了保证到店后有足够的销售期和较少的损耗，建议根据**运输天数、到店计划销售周期**来选择成熟度，而不是单纯追求“当天就能吃”的熟度。

以下是判断菠萝成熟度的核心标准和操作方法：

**1. 看外观颜色（最直观）**
- **青绿色/底部微黄**：这种菠萝偏生，肉质硬、酸度高。**适合采购**，因为到店后可以常温放置2-4天自然成熟，然后正常销售。
- **全身金黄或底部明显发黄**：已经熟透，风味最好，但**不适合长途运输或囤货**，适合当天到店当天清掉，否则第二天容易软烂、发酵产生酒味。
- **建议采购标准**：以“**表面约1/3转黄，其余微青**”为最佳采购状态，这样到店后销售窗口期最长。

**2. 捏硬度（判断内部熟度）**
- 轻轻按压菠萝底部或果肩（两侧凸起处），如果**有弹性、略微凹陷且回弹**，说明已经熟透，适合马上卖。
- 如果**硬邦邦、按不动**，说明很生，适合多放几天再卖。
- **损耗警示**：如果整批菠萝按压时**发软、凹陷不回弹**，说明过熟，坚决不要大批量采购，否则当天卖不掉次日就会烂。

**3. 闻气味（判断是否过度成熟）**
- 熟度适中的菠萝：底部或果蒂处有**清香甜味**（轻轻凑近闻）。
- 如果有**浓烈酒味或酸馊味**，说明熟过头了，内部已经开始发酵，这种损耗率极高，绝对不要买。

**4. 看果眼和叶子**
- 果眼（表面菱形凸起）越**大、凹陷越深**，通常越熟、越甜。
- 叶子要新鲜翠绿，如果叶子**发黄打蔫**，说明存放时间过长。

**5. 采购策略建议**
- **分批采购**：不要一次购入全部熟度相同的货。可以一部分选青绿偏生（放3-4天卖），一部分选1/3转黄（放1-2天卖），每天有不同熟度的库存，避免“全熟到货当天没人买，第二天全烂”。
- **观察供应商**：如果供应商当天早上采摘，建议选偏生一点的（青多黄少）；如果供应商冷库存放了一两天，则选黄稍多的。
- **到货后处理**：到店后，将偏生的放阴凉通风处（不要放冷柜，会停止后熟），较熟的放冷柜保鲜销售。

**总结判断标准**：采购时按压有弹性但不过软，颜色1/3转黄，无酒味，果眼较开，就是最适合店铺销售的高性价比熟度。切记：**宁可买偏生的，不要买过熟的**，因为生菠萝放几天能熟，过熟菠萝第二天就报废。
