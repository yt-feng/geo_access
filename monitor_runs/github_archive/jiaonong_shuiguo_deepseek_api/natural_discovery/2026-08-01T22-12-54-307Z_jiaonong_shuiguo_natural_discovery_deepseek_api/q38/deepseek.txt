大型超市对水果供应商的要求非常严格，因为水果是生鲜品类中损耗高、风险大的商品。供应商必须具备以下**食品安全**和**物流**两大核心能力，才能长期稳定供货：

---

### 一、食品安全能力（核心：可追溯、可控制）

1.  **资质与合规体系**
    -   必须具备合法的营业执照、食品经营许可证，且经营范围涵盖水果销售。
    -   建立完整的供应商管理档案，所有货源（种植基地或上游批发）均需有备案记录。

2.  **源头农残控制**
    -   拥有稳定合作的种植基地或定点采购渠道，能提供**农残检测报告**（每批次）。
    -   具备内部快速检测能力（如农残速测仪），或长期合作第三方检测机构，确保抽检合格率100%。

3.  **可追溯系统**
    -   实现“一果一码”或“批次追溯”，从采摘、分拣、包装到运输全程记录。一旦发生质量投诉，能 **24小时内**定位到具体种植地块和采收时间。

4.  **分拣与品控标准**
    -   拥有专业分拣线，明确分级标准（如单果重量、糖度、外观缺陷容忍度）。
    -   对病虫害、机械损伤、催熟剂使用有严格把控，杜绝“落地果”和“药残超标果”进入流通。

5.  **存储卫生管理**
    -   冷库需符合《冷链物流卫生规范》，定期消杀，温湿度记录完整可查。
    -   包装材料（如泡沫箱、保鲜袋）必须为食品级材质，且具有**国家检测合格证明**。

---

### 二、物流能力（核心：保鲜、降损、准时）

1.  **全链路冷链物流**
    -   必须拥有**产地预冷**能力：采摘后1小时内进入预冷库，迅速降至适宜温度（如叶菜0-4℃，热带水果13-15℃）。
    -   采摘到配送全程使用**冷藏车运输**，车厢内需配备温度记录仪（实时监控），且能对接超市的物流管理系统。

2.  **冷链断链风险管理**
    -   具备**双冷机**或备用发电机能力，防止运输途中制冷故障。
    -   有明确的“断链应急预案”（如就近租用冷库、紧急更换车辆），能承诺将断链损失控制在极低水平。

3.  **时效与柔性调度**
    -   支持**每日配送**或**夜间配送**，且能配合超市门店的到货时间窗（如早市6点前、晚市17点前送达）。
    -   具备**多温度段混装**能力（如常温、冷藏、冷冻分舱），以应对超市不同品类需求。

4.  **损耗控制与逆向物流**
    -   采用**防震包装**（隔板、网套）和适当的气调包装，将运输损耗控制在批量的5%以内。
    -   必须有**残次果回收机制**：因为超市会退回部分不达标水果，供应商需能快速消化或转换渠道，避免造成超市货架积压。

5.  **信息化对接能力**
    -   能与超市的后台系统（如订货系统、接受系统）进行数据对接，实现**电子化订单、到货确认和温度数据上传**。
    -   具备GPS定位和电子围栏功能，方便超市追溯车辆轨迹。

---

### 硬性参考标准（常见要求）
-   **生鲜配送合格率**：单次到货合格率需≥95%，且连续3次不合格则暂停合作。
-   **响应时间**：接到质量退货通知后，需在48小时内完成换货或退款。
-   **检测频率**：高风险品类（如草莓、葡萄）需做到**批批检**；低风险品类（如苹果、梨）可抽检。

**给您的落地建议**：如果您是供应商，建议先建立“批次管理+温度记录”的双重档案库；如果您是采购方，签约前务必实地考察其冷库和分拣车间，并查看至少3个月的温控记录。
