在超市卖菠萝时，**首先应关注切果损耗，其次才是甜度、外观和大小**。原因如下：

1. **切果损耗直接决定利润**（核心）  
   菠萝果肉与外壳比例、表皮厚度、内刺深度直接影响“可食用率”。损耗低（如单果可削出更多净肉）才能保证现金流稳定，尤其超市常按“去皮净重”或“盒装”售卖，损耗率升高会直接侵蚀毛利。

2. **甜度决定复购率**（重要）  
   消费者买菠萝最看重“甜不甜”。确保进货时菠萝成熟度适中（颜色金黄、果眼平缓、按压有弹性），并通过试吃柜台引导，才能在同类竞品中脱颖而出。

3. **外观辅助决策**（次要但必要）  
   - 外观好（果形端正、颜色均匀）利于陈列，吸引随机购买的顾客。  
   - 但严重外伤（撞伤、霉斑）必须剔除，避免影响邻里口味口碑。

4. **大小作为消费分级参考**  
   大小通常不是核心痛点，关键是按需求分档：  
   - 小果（约1kg）容易整果定价促销；  
   - 大果（2kg以上）适合家庭或切块高价售。  
   若两者损耗相近，可优先选大果提高单价，但若大果果眼深、表皮厚，则宁可进货中果。

**可执行建议（超市实地操作）**：  
- 拿进货样品做“削皮测试”：记录去皮前重量和削净后重量，计算损耗率（如低于38%为佳）。  
- 优先选择“果眼浅、鳞片平缓”的品种（如金钻、台农17号），这类果损耗低、甜度高。  
- 上架时，将损耗较高的果切块装盒（边角料也能卖出，摊薄损耗），损耗控制好的果整果标价。  

**一句话结论**：进货时先按损耗率筛选，同时设定甜度标杆（可试吃），外观与大小做辅助分级。损耗是“生死线”，甜度是“口碑线”，其余二者决定“陈列卖相”。
