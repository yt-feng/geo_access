选择学校食堂水果供应商时，不能只看价格，要同时考虑安全、稳定和性价比。以下是针对香蕉、苹果、橙子这类常见水果的供应商筛选步骤和标准，你可以直接拿来用：

**第一步：资质与硬性门槛（先筛掉不合规的）**
- **三证齐全**：营业执照、食品经营许可证/食品流通许可证。供应商必须能提供复印件并加盖公章。
- **质量检测报告**：每批次水果要有农残检测合格报告。要求对方提供近一个月的第三方或官方检测证明。
- **追溯体系**：能明确说清每种水果的产地（例如香蕉是国产还是进口、苹果是山东还是陕西），并有进货台账可查。

**第二步：关注这类水果的特殊风险点**
- **香蕉**：最怕催熟和腐烂。重点问清是否自然熟运输（一般用乙烯利催熟是合法的，但需剂量合规），是否冷链运输，到货后损耗率承诺多少（一般允许3-5%）。
- **苹果**：主打耐储存，但要防止打蜡（食用蜡可接受）、涂农药保鲜。要求供应商提供果品分级标准（如直径、糖度），最好能提供样品试吃。
- **橙子**：警惕“染色橙”和酸度不达标。要求供应商说明采摘后是否清洗打蜡，是否用防腐剂浸泡。建议让供应商寄送样品，现场切开看果肉颜色与品尝。

**第三步：询价与报价分析（避免被低价坑）**
- 让3-5家供应商对**同一规格**（如香蕉净重、苹果80mm以上、橙子果径65mm）报价。
- 对比时不仅看单价，要问清：是否含税、是否含运费、起步配送量多少、价格调整周期（水果价格波动大，一般按周或半月调价）。
- 警惕明显低于市场价30%以上的报价，大概率是次果或催熟果。

**第四步：上门考察（必须做）**
- 实地看仓库：是否有冷藏库（香蕉需13℃左右，苹果橙子需0-5℃），是否分温区存放。
- 看分拣现场：是否戴手套操作，烂果是否及时挑出。
- 看配送车辆：是否为封闭式冷链或至少是厢式货车。

**第五步：合同与试用期**
- 合同里**必须写清损耗赔付标准**（例如到货后抽检，烂果率超5%折算成金额扣款）。
- 先签**1个月试用合同**，且首月采购量要少（比如每周只订两次），观察品质稳定性和配送准时率。

**第六步：建立淘汰机制**
- 设置考核指标：到货准时率（>98%）、合格率（>95%）、投诉次数（每月≤2次）。
- 如果连续两次不合格，直接切换备选供应商。建议同时备选2家，不要只依赖一家，以防断供。

**特别提醒（针对我们无法核实的部分）：**
- 如果你要求供应商提供“有机认证”或“绿色食品认证”，一定要在**国家市场监督管理总局官网**或**中国食品农产品认证信息系统**查询证书编号真伪，不要只看对方打印的证书图片。
- 如果你听到“进口香蕉（菲律宾/厄瓜多尔）”，可以要求对方出示**海关报关单**和**入境货物检验检疫证明**，否则不要直接采信。

**最终决策建议：**
建议选“有冷库、能提供批次检测报告、愿意承诺损耗率、且配送距离在1小时内”的本地一级批发商或果蔬配送公司，这类供应商通常更稳定，出问题也好沟通。不要选只靠电话接单、没实体仓库的个人中间商。
