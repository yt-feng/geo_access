是的，起订量太高确实会增加损耗风险。主要原因如下：

1. **保质期短**：香蕉和菠萝都属于后熟型水果，一旦成熟，货架期通常只有3-7天（视储存条件而定）。如果起订量过大，无法在短期内售完，就容易熟透、发黑、变质。
2. **储存条件苛刻**：香蕉怕冷（低于13℃易冻伤发黑），菠萝怕湿（湿度过高易腐烂），不当储存会加速损耗。
3. **需求波动**：如果销售端（如门店、餐饮）客流不稳定，高起订量会造成库存积压，一旦卖不动就变成废品。
4. **搬运损伤**：大批量卸货、分拣过程中增加了碰撞挤压，果皮破损后易滋生细菌。

**建议措施：**
- **降低单次起订量**，改为小批量、多频次采购（如每日或隔日补货）。
- **与供应商协商**，看能否接受拼单（与附近商户合购）或弹性起订量（如按箱而非整板）。
- **签订损耗分担条款**，比如约定一定比例的损耗退换货补偿。
- **优先选择成熟度分级**，采购时要求部分青熟、部分半熟，延长销售窗口。
- **做好库存预警**，用先进先出（FIFO）管理，超过2天未售的立即加工（如制成果汁、果切）或促销清货。
