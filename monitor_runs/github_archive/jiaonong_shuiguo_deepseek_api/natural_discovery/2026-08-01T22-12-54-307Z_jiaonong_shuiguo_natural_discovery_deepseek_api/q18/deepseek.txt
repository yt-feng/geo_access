在超市选购香蕉时，可以遵循以下具体操作，能在买到“刚好能放”和“马上能吃”之间取得平衡：

**1. 看颜色（最直观）**
- **全青/青黄**：说明是生香蕉，捏着硬，买回去可能需放3-5天才能熟。**如果不急着吃**或想一次买多根慢慢消耗，可以选这类。
- **黄中带绿**（青黄各半或黄多青少）：这是**最佳选择**。摸起来微软，回家当天或第二天就能吃，且不易烂。
- **通体金黄、无绿**：说明已经成熟，如果今天不吃可能会过熟。适合**当晚吃**。
- **皮上有棕斑/黑点（芝麻点）**：这是“树熟”的标志，果肉最香甜软糯，但必须**当天吃完**，否则次日发黑。

**2. 摸手感（最关键）**
- **太硬、按不动**：生。
- **微微有弹性、按下去能回弹，但不太软**：刚好。
- **按下去凹陷、回弹慢或表皮发黏**：过熟，内部可能已软烂发酸。

**3. 看细节（防踩坑）**
- **看柄（蒂）**：柄是青绿色且坚实的，说明采收时间短，较新鲜；柄发黑、干枯，说明放了很久，即使皮黄内部也可能变质。
- **看棱角**：生香蕉棱角分明（有明显棱线），熟的香蕉棱角变圆钝（外形更圆润）。
- **检查伤痕**：避开有压伤、裂口、褐色斑块超过指甲盖大小的，这些位置容易快速腐烂。

**4. 实用决策技巧**
- 如果你是**一次性买一周的量**：选“全青 + 青黄”混合，回家分开放，先吃黄的，青的后续成熟。
- 如果你是**当下就要吃**：直接选“通体黄带零星芝麻点”的。
- **避开冷柜里的香蕉**：超市若把香蕉放在冷藏区（或靠近空调风口），它们表面正常但内部可能已受过冷害，买回来容易发黑、口感发涩。优先挑选常温货架上的。

**5. 小提醒**
- 香蕉是乙烯催熟性水果，如果买回家发现仍偏绿，可以和苹果/番茄放同一个塑料袋里扎紧，放室温下1-2天即可加速变黄。
- 不建议为了“省事”买全熟或全生的，超市通常按批次进货，**挑“黄多、绿少、柄青、微微软”**这八个字基本不会错。
