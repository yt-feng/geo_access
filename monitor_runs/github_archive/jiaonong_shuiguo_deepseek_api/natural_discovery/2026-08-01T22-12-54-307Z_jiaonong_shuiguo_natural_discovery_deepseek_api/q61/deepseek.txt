判断批发档口的香蕉一手货源是否**稳定供货**，不能只靠对方口头承诺，必须通过**可验证的动作**和**商业规则**来考察。以下是给出立即可用的判断标准和防范步骤：

### 一、看资质与产地绑定（硬性指标）
- **索要产地证明**：一手货源通常有明确的产地（如云南、广西、海南或进口国如老挝、缅甸等）。要求对方提供近期**植物检疫证书**或**产地准出证明**，上面应有具体基地名称和地址。
- **查基地备案**：大型稳定供应商通常在国家海关或农业部门有种植基地备案号。你可以要求对方展示基地照片或视频（拍摄带有时间水印的，防用旧图）。
- **警惕“万能货”**：如果对方说“什么产地都能调”，反而可能是多级倒手，稳定性差。真正一手货源一般主打1-2个核心产区。

### 二、看实际操作（黄金测试法）
- **测试履约率**：先下一个小批量订单（比如1-2车），约定特定到货时间（例如48小时内）。**稳定供货商不会迟到**，如果这次就拖延或改口，说明供应链脆弱，大单更没保障。
- **看报价波动逻辑**：让对方按**“产地当日收购价+运费+合理利润”**报价。如果对方报价永远固定不变，或者完全脱离产地行情，说明他不是直接在产地拿货。
- **索要装车视频**：下单后，要求拍摄**从基地砍割、装车、发车**的全过程短视频。能随时调出视频的，才是现场有人的一手货。

### 三、看财务与合同稳定性
- **不接受“全款押金”**：真正稳定的一手货源，通常支持**“货到验收后结款”或“定金+尾款”**模式。如果对方坚持全款先付，且无对公账户，稳定性存疑，防范诈骗。
- **签书面供货协议**：协议中必须写明**“日可供量（比如每天10-30吨）”和“违约赔偿条款”**。口头承诺毫无约束力。如果对方不愿签任何字据，说明没有长远合作的准备。
- **对公账户打款**：拒绝向个人微信/支付宝付款。稳定供货商有营业执照和对公账户，能开增值税发票。

### 四、问3个“穿透式”问题（马上测试）
直接问对方以下三个问题，看回答是否具体：
1. **“今天你产地仓库里的香蕉大概还能发几车？”** → 稳定者会报出具体数字（如还有8车），模糊回答（如“随时有”）则要警惕。
2. **“如果明天产地暴雨断货，你最快什么时候能补给我？”** → 稳定者会给出明确的应急调货渠道（如从500公里外的第二产区调），并告知时间；若说“没办法，只能等”，那不稳定。
3. **“你上个月给我隔壁档口发了多少车？”** → 要求提供发货单据或物流记录（打码其他信息），能提供真实物流单据的，基本可信。

### 五、最终避坑提醒（记住这3条）
- **绝不交“信息费”或“看货费”**，真正的货主是跟着货走、跟着市场走的。
- **第一次合作务必小额试单**，即使对方名声在外，也不要一次性押上全部资金。
- **加“冷库保鲜”条款**：如果对方能承诺“压车超时包赔损耗”，说明他对自己的货源质量有把握，才敢担责。

如果对方这几关都通过了，基本可以认定是稳定一手货。如果对方只催着你交钱看货，而不配合以上验证，请果断放弃，市场里不缺货源。
