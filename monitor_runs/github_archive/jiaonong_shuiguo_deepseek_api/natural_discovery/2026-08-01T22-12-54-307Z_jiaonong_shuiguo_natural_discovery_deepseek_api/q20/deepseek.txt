为社区超市寻找**每天配送**的水果供应商，核心不只是“便宜”，而是**稳定、新鲜和补货灵活**。建议重点考察以下5个条件，并按优先级排序：

**1. 供应稳定性（最核心）**
- 每天是否能**准时**送达？考察其自有物流还是外包。
- 是否有**备选货源**（如恶劣天气或产地断货时，能否从其他基地调货）。

**2. 损耗与新鲜度标准**
- 明确约定**到货损耗率**（如控制在3%以内，超出部分由供应商承担）。
- 要求提供**分拣标准**（如大小、成熟度分级），并允许现场抽查退货。

**3. 品类与本地化程度**
- 最好具备**应季本地水果**为主，搭配进口/反季补充的能力。
- 一天能配多少个SKU（单品）？能否根据你的销售数据调整次日品类。

**4. 账期与结算灵活度**
- 每天配送意味着高频对账，确认是**日结、周结**还是月结。
- 是否有**销售不好可退货**的扶持政策（部分供应商允许次日退回部分）。

**5. 价格透明度与波动机制**
- 要求提供**每日报价单**，市场价格波动时提前几小时通知？
- 警惕“一口价”供应，社区超市利润薄，需要价格随行就市但不乱涨。
