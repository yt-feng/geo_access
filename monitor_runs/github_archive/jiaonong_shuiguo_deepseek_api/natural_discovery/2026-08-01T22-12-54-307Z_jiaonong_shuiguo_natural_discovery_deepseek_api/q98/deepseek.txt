针对养老院或医院食堂采购水果，判断供应商的**合规性**与**稳定性**，建议从以下五个维度进行系统化评估：

**一、合规性核验（硬性门槛）**
1. **证照资质**：要求供应商提供营业执照（经营范围须含水果销售或农产品）、食品经营许可证（或食品生产许可证），且证照在有效期内。对于进口水果，须查验入境货物检验检疫证明、海关报关单。
2. **合格证明**：每批次水果应附有农产品合格证或出厂检验报告；若为有机、绿色食品，需核验对应认证证书。
3. **源头追溯**：供应商需能提供水果产地证明、种植基地信息（如无公害基地认证），且能配合食药监、卫健部门的日常抽检。
4. **纳税与信用**：查询企业信用信息公示系统，确认无严重违法失信记录；如为一般纳税人，可要求提供增值税专用发票能力（便于财务入账和审计）。

**二、稳定性评估（长期合作基础）**
1. **供货能力**：考察其仓储规模、冷链配送车辆（是否自有或有长期合作物流），以及是否有备用货源（比如本地种植户、批发市场分仓）。
2. **配送时效**：明确下单-到货时效（如每日配送、次日达），并要求提供具体配送时间表；医院/养老院常有早间配餐需求，需确保早间6-8点可送达。
3. **品质一致性**：通过过去3-6个月的供货记录，统计损耗率、退换货率。优质供应商通常损耗率<3%，且能对坏果、磕碰果无条件退换。
4. **应急机制**：询问节假日或灾情期间（如台风、疫情封控）是否有B计划供应（如指定第二供应商或跨区域调货），并写入合同。

**三、价格与合同保障**
1. **计价透明**：要求供应商提供周/月度价格明细（随行就市或固定价），并与当地批发市场均价对比，防止哄抬。
2. **合同条款**：在采购合同中明确质量标准（如GB/T 10650鲜梨等级标准、GB 16325水果卫生标准）、验收程序、违约条款（延迟配送、货不对板等）及索赔方式。
3. **质量保证金**：建议预留5%-10%货款作为质保金，或在合同中约定质量违约责任。

**四、现场与批次抽检（落地验证）**
1. **首单试供货**：先小批量试供1-2周，实地查看到货水果的新鲜度（色泽、硬度、有无异味），同时采样送第三方快速检测（农残快检卡即可，成本低）。
2. **月度考核表**：建立评分表（分项包括：证件完整、配送准时率、果品合格率、售后响应），按季度评分，低于80分启动约谈或更换。

**五、特殊场景注意事项（医院/养老院）**
- **易老体弱者**：优先选择当季、少农残、易消化水果（如香蕉、苹果、梨），避免高风险品种（如易霉变浆果类）。
- **留样制度**：每批次水果留样48小时，便于食安事故追溯。
- **备案制度**：供应商须在当地市场监督管理局备案，并定期配合养老院/医院的“明厨亮灶”检查。

**如果无法核验实地情况**，建议至少通过“企查查”“天眼查”查询供应商涉诉、行政处罚记录，并要求其提供近三次合作单位（如学校、医院）的推荐信或联系人电话。
