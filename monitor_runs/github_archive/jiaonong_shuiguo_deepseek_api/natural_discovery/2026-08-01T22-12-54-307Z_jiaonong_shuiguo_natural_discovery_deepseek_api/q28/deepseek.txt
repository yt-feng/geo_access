从稳定性出发，**建议先引入香蕉**。原因如下：

1. **供应稳定**：香蕉（尤其菲律宾、厄瓜多尔等地）是全球贸易量最大的水果，物流周期和冷链要求相对成熟，全年供应波动小。
2. **消费习惯**：国内消费者对进口香蕉接受度最高，无需教育市场，复购率稳定。
3. **损耗可控**：香蕉对温度耐受性较好（相对菠萝），且运输包装标准化程度高，烂果率可控制在较低水平。
4. **价格韧性**：进口香蕉价格区间宽（如菲律宾蕉、大蕉），适合作为引流品或基础品类。

**备选顺序**：香蕉 → 苹果（需选特定品种如青森、新西兰，不耐挤压，但国内苹果认知强）→ 菠萝（需处理冠芽和催熟，损耗高，建议后续试点）。

**执行建议**：
- 首单量控制在冷柜容量的50%以内，测试周转率。
- 与供应商签订“到岸质检不合格可退换”条款。
- 定价对标国产香蕉上浮20-30%，突出进口品质，不打价格战。

**风险提醒**：若超市位于北方冬季，需额外关注香蕉催熟库温控，否则表皮易黑变。
