针对连锁门店分布在不同城市的水果供应商仓配覆盖评估，不能只看“有没有仓”，而是要看**“能不能在卖得动的时间内，把货送到卖得动的位置”**。水果是短保、易损耗商品，仓配评估的核心是**时效、损耗率和成本**的三角平衡。

以下是可落地的评估框架，分为**五个维度**和**踩坑提示**：

### 1. 时效覆盖能力（最关键）
**核心指标：** 从供应商仓库发货到门店收货的**在途时间（小时）**，以及到店后的**剩余货架期**。
*   **评估动作：**
    *   拉出你所有门店所在城市，要求供应商标注**每个城市的自有仓/合作仓**位置。
    *   测试**隔日达**（48小时）和**次日达**（24小时）分别能覆盖多少城市门店。
    *   **重点关注“销地仓”**：如果供应商只在产地（如云南、海南）发货，到华东/华北的干线时间超过48小时，则仓配覆盖严重不足，因为水果的新鲜度会断崖式下跌。
*   **判断标准：** 至少保证**80%的门店**能实现“当日下单、次日/后天上午到店”，且到货后仍有3天以上可销售期（根据不同水果品种调整）。

### 2. 冷链“最后一公里”能力
水果仓配不同于干货，**常温车和冷链车完全是两种体系**。
*   **评估动作：** 随机抽查供应商配送车辆，查看是否为**独立制冷车（非泡沫箱+冰袋）**，并要求提供**全程温控记录**。
*   **判断标准：** 
    *   **短保浆果（蓝莓、草莓）**：必须全程0-4℃冷链，且最后一公里需用冷藏车直接配送到店。
    *   **热带水果（香蕉、芒果）**：若推入冷库或冷藏车不当，会导致“冻伤”或“黑心”，要求供应商对这类品提供**控温通道**而非强制低温。
    *   如果供应商在偏远城市只能发**常温快递或普货物流**，直接判定为不覆盖。

### 3. 分批多频次配送能力（补货灵活性）
水果的日销量波动极大，一次性大量配送会造成门店积压损耗。
*   **评估动作：** 询问供应商在特定城市（如上海、广州）是否支持**“一周多配”**，例如：一周送3次（周一/三/五），或针对高动销门店支持“隔日达+急单加急”服务。
*   **判断标准：** 核心门店（月销售额TOP30%）的城市，必须能实现**“周配3次及以上”**；非核心门店至少保证“周配2次”。如果只能“周配1次”，水果到店第5-7天损耗会大幅增加。

### 4. 生鲜损耗兜底条款
仓配覆盖再快，也难免运输震荡或温控瑕疵。供应商是否愿意为“非门店原因造成的到店损耗”负责，是检验其仓配质量的**试金石**。
*   **评估动作：** 合同里明确约定“到货损耗率”标准（如榴莲、山竹到店损耗率≤3%），并要求供应商对**因运输、仓储不当导致的坏果**进行无条件换货或冲抵货款。
*   **判断标准：** 如果供应商态度含糊，只愿意“退坏果”不愿意“补足重量”，说明其对自己的仓配水平没信心，覆盖能力存疑。

### 5. 补货响应机制（应急能力）
*   **评估动作：** 模拟一次台风或节日促销前的高峰下单，测试供应商在**下午3点前**下达的紧急订单一是否能当晚发货，次日上午送达。
*   **判断标准：** 仓配覆盖良好的供应商，通常配备**区域调度员**，而非只有总部坐席。若无法提供对应城市的本地仓配对接人，应急补货基本落空。

---

### ⚠️ 避坑指南（针对水果品类的特殊陷阱）

*   **警惕“分仓”陷阱：** 很多供应商宣称“全国建仓”，但可能只是在核心城市建了**中转站**，货还是得从主仓干线调拨。务必要求供应商提供**每个分仓的“现货库存SKU数”**，如果分仓长期只备畅销果（苹果、香蕉），而缺少特色果（杨梅、晴王葡萄），说明分仓覆盖能力有限。
*   **核对“最后一公里”外包情况：** 很多供应商在偏远城市会外包给当地物流公司，**外包车辆是否配冷链**、是否按时，需要随机抽查三次以上实际到货时间（而非口头确认）。

### 最终建议执行方案：
**对现有供应商进行一次“仓配压力测试”**：
1.  选取3个不同省市的典型门店（如省会、地级市、县级市）。
2.  在同一周内，分别下单2种不同保质期的水果（如鲜荔枝+普通苹果）。
3.  记录到货时间、到货温层、烂果率、售后响应速度。
4.  对比这三个城市的测试结果，即可客观评判该供应商真实的仓配覆盖能力。

如果测试结果显示，**超过30%的城市门店**在途时间超过3天，建议该供应商不适合作为核心水果供应商，只需作为局部补充。因为水果生意的本质是“鲜”，仓配覆盖不够深，最终损耗和差评都会由你的门店承担。
