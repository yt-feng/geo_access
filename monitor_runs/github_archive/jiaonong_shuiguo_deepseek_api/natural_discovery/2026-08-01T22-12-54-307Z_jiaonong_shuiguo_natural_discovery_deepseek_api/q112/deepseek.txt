在水果采购合同中，关于坏果率（损耗率）的赔付标准没有统一的法定数字，主要取决于**双方协商**以及**交易惯例**。

以下是实务中常见的约定标准和操作建议：

**1. 常见的行业参考标准**
- **一般精品水果（如车厘子、草莓、阳光玫瑰等）**：建议将坏果率上限约定在 **3%-5%**。超过此比例，超出部分按质量问题处理。
- **普通大宗水果（如苹果、橙子、西瓜等）**：可约定在 **5%-8%**。考虑到运输和周转，超过8%通常视为不正常损耗。
- **特价果、处理果或次级果**：双方可单独约定较高上限（如10%-15%），但必须在合同中明示“特价处理，坏果率上限为XX%”。

**2. 赔付计算方式**
建议在合同中明确计算公式，避免纠纷。常见方式为：
- **公式一（补货/折价）**：赔付金额 = （实际坏果率 - 约定上限）× 该批次总货款。
- **公式二（重量折抵）**：按坏果重量直接折价，即：坏果重量 × 单价。
- **公式三（阶梯赔付）**：坏果率超过10%、15%、20%等不同档位，对应不同赔付比例（如全额退款、半价、补偿运输费）。

**3. 合同必写条款（重要）**
你必须注意以下三点，否则即使约定再高也可能无法执行：
- **验收期限**：约定收货后 **24小时或48小时内** 提出书面异议（需拍照或视频留证），逾期视为验收合格。
- **运输责任划分**：明确“发货时品质合格但运输途中腐烂”由谁负责，一般建议约定由采购方承担到货风险，或要求供应商使用冷链。
- **免责情形**：如因采购方储存不当、二次搬运造成的坏果，供应商不承担赔付。

**4. 如果对方拒赔怎么办？**
- 保留证据（到货开箱录像、坏果特写、物流签收单）。
- 若合同约定了仲裁或诉讼条款，按条款走；未约定则向采购地法院起诉。
- 小额纠纷可先向当地市场监督管理局或消费者协会投诉（若你属于消费者）或走“12315”平台。

**结论建议**：
- **如果你们是首次合作或大额交易**，建议协商设定 **5%** 为安全线，并要求到货后双方共同开箱抽检。
- **如果对方提供的是“包赔”承诺**，必须白纸黑字写明“坏果率超8%无条件退款”等字眼，口头承诺无效。
