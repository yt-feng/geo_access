对于餐饮店来说，选择供应商最核心的考量是**稳定性**、**新鲜度**和**配送及时性**，而“每天少量”这个特点，决定了你**绝对不能找需要起订量大的批发商**。

直接给你筛选标准和省心操作建议：

**1. 首选：本地“净菜配送公司”或“餐饮生鲜供应链”（最推荐）**
- **为什么省心**：这类公司专门服务餐饮客户，支持极低起订量（几斤都送），直接按你的需求分拣好，送到就是净重，不用自己再挑拣。
- **怎么找**：用地图搜“XX市餐饮配送”“生鲜供应链”，或者直接问隔壁生意好的同行用的是哪家，通常本地都有2-3家做这类服务的。
- **注意**：初期让他们送3次，盯紧到货时间是否准时、缺货率是否高。

**2. 备选：本地大型农贸市场的“固定档口”老板（不换人）**
- **为什么省心**：锁定**同一家**水果档口，每天微信报需求，约定“早晨开门前送到店门口”。别今天这家明天那家。
- **技巧**：跟老板谈“我每天要，量小但稳定”，直接要求他帮你挑好的、过称减皮（纸箱重量扣除），并要求“送次品包换”。和一家绑定，他为了长期生意不会坑你。

**3. 坚决避开：**
- 社区团购平台（美团优选/多多买菜）：虽然便宜，但品控不稳，缺货率高，且必须自己去取货点拿，不适合餐饮。
- 大型批发市场零买：凌晨去拿货耗费时间，回来还要自己洗、切，不省心。

**具体操作给3个“免坑”建议：**

- **谈“到店价”**：直接问“送到店多少钱”，不要只问市场批发价，因为运费和包装损耗都在里面。
- **固定清单**：把每天需要的水果种类和大致用量固定写下来（比如每天苹果3斤、香蕉2斤），让供应商按单配，一周微调一次。
- **付款周期**：建议谈“月结”或“周结”，这样供应商会更有动力保证质量，因为扣他钱主动权在你手里。

**总结一句**：**找“净菜配送平台”+锁定1个本地档口做替补**，是你每天少量进货最省心的组合拳。如果店里对水果卖相要求不高（比如只是做果切或榨汁），甚至可以问配送公司有没有“尾货”或“统货”，价格能再低20%。
