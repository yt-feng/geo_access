超市采购水果时，一般应索取并留存以下证明和检测材料。具体以属地市场监管要求和供应商类型为准：

1. **供货资质**
   - 供应商营业执照
   - 食品经营许可证（或仅销售预包装食品备案；水果属于食用农产品时按当地要求核验）
   - 产地证明或购销合同、供货单

2. **进货凭证**
   - 进货发票、送货单、销售单
   - 供应商盖章的供货清单，注明品名、数量、产地、批次/采摘日期、供货商信息
   - 批发市场进货的，可留存市场交易凭证或“食用农产品进货凭证”

3. **合格证明**
   - 食用农产品合格证（承诺达标合格证）
   - 产地准出证明或产地检疫/植物检疫证书（涉及跨区域调运、地方规定品种时）
   - 供应商自检报告或第三方检测报告

4. **检测报告重点**
   - 农药残留检测：有机磷、氨基甲酸酯类等，按国家标准和属地快检要求
   - 重金属：铅、镉等（视品种和产地风险）
   - 禁用农药、限用农药残留
   - 进口水果另需：海关入境货物检验检疫证明、报关单等

5. **超市自身应做的**
   - 建立进货查验记录，保存凭证和报告
   - 对高风险品种做快速检测或抽检
   - 索证索票留存期限一般不少于6个月，具体按当地规定

实操建议：采购前让供应商提供“营业执照+食品经营许可证+合格证/检测报告+送货单”四件套；对叶菜、草莓、豇豆等高风险品种，要求批次检测报告或自行快检。各地对食用农产品索证索票要求略有差异，建议向属地市场监管部门确认模板。
