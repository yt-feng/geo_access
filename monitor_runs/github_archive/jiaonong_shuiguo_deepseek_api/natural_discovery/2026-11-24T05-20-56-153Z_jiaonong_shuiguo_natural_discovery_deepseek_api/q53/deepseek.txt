结论：优先找“本地二级水果批发商/专业配送商”，其次社区生鲜平台的企业客户渠道；不要找一级大批发商或果园直供，也不要在早市临时采购。

判断标准：能让对方按你每天的用量分拣、固定时间送到店、缺货提前说、坏果能补，这四件事做到就算省心。

建议的供应商类型，按省心程度排序：

1. **本地水果配送商（最优先）**
   - 找本地做“餐饮/食堂配送”的二级批发商，通常有面包车按路线送货。
   - 适合每天少量：可以要“小包装配送”，一箱几斤到十几斤均可。
   - 谈的条件：固定送货时间（如每天9点前）、固定品类清单、允许按实际到货量结算、坏果当天拍照补货。
   - 怎么找：在本地批发市场问“做餐饮配送的”，或让附近同行推荐；美团/饿了么商家版、本地餐饮群也常有人推。

2. **社区生鲜平台的企业客户渠道**
   - 如本地生鲜配送平台、美菜类食材配送平台的水果品类。
   - 优点：线上下单、次日达、有售后；缺点：品类和规格可能不稳，适合作为补充。
   - 适合每天用量在10斤以内的小店。

3. **附近水果店/社区团购团长（小量应急）**
   - 每天几斤、品类单一的话，可以固定一家水果店按批发价拿，让老板留货。
   - 优点省事；缺点是价格不一定最优、品类受店内库存限制。

不建议的方式：
- 一级大批发市场：量小拿不到好价，还要自己早起、分拣、搬运，不省心。
- 果园直供：起送量大、品类季节性强、配送不稳定。
- 每天临时早市采购：品质和价格波动大，无法固定菜单。

落地做法：
- 先列一张“每天必用水果清单+最小用量+可接受替代品”，例如苹果5斤、柠檬2斤、圣女果3斤。
- 同时谈2家：一家主供、一家应急，主供断货时能补。
- 合同或微信里写清楚：送货时间、验收标准（坏果率不超过多少）、补货时限、结算周期（建议周结）。
- 先试送一周再定长期，重点看“迟到次数”和“坏果处理爽不爽快”。
