# 判断检测报告是否对应当前批次的方法

**核心逻辑：报告必须能唯一锁定"这一批货"，而不是只证明"这个供应商有合格报告"。**

## 一、先看报告上的批次标识

1. **生产/采摘日期**：是否落在本批次的采收或加工时间范围内。报告日期通常应早于或等于发货日期，且不能早于采摘期。
2. **批号/批次号**：报告上的批号要与送货单、装箱单、外箱标签上的批号一致（逐字核对，注意字母数字易混）。
3. **规格与品种**：品名、品种、规格（如70mm以上、5kg/箱）要与订单一致，不能是"同类产品"的通用报告。

## 二、核对报告与实货的对应关系

- **抽检基数**：报告是否写明抽检数量、抽样方法；抽检量应能代表本批次规模。
- **抽样时间与地点**：抽样地点（产地、加工厂、仓库）与供货来源一致。
- **检测机构与报告编号**：报告编号可在检测机构官网或CMA/CNAS查询平台核验真伪；注意报告是否被PS修改。
- **CMA/CNAS标志**：有资质认定标志的报告才具法律效力。

## 三、看报告类型和时效

- **型式检验报告**（定期全项检测）通常不能代替**批次检验报告**。供应商拿年度报告应付每批货，是常见问题。
- **报告有效期**：多数农残检测报告只对该批次有效，不应跨批次使用。
- **检测项目覆盖**：是否覆盖本品种的高风险项目（如豇豆的克百威、草莓的烯酰吗啉等），以及采购合同约定的项目。

## 四、交叉验证手段

1. **要求提供抽样照片/视频**：抽样现场、封样、送样过程的影像，能证明报告对应本批货。
2. **比对运输单据**：报告抽样日期与出库单、物流单的时间链是否吻合。
3. **自检或第三方复检**：对高风险品类，采购方可自行快检或送检，与供应商报告比对。
4. **建立批次档案**：送货单、报告、外箱标签、物流记录四者编号对齐归档，出问题时能追溯。

## 五、常见"不对应"的坑

| 情形 | 识别方法 |
|---|---|
| 用旧批次报告充数 | 报告日期早于本批次采摘期，或批号不符 |
| 用年度报告代替批次报告 | 报告无具体批号、抽样日期 |
| 报告品种/规格不符 | 品名写"蔬菜"而非具体品种 |
| 报告被篡改 | 编号查不到、机构电话核实、图片有拼接痕迹 |
| 抽样不代表整批 | 抽样量过小、抽样地点与货源不符 |

## 实操结论

**一票否决项**：批号对不上、报告日期与采摘/发货时间矛盾、报告编号无法核验、无CMA/CNAS资质——出现任一，要求重新提供本批次报告或自行送检。

**建议写入采购合同**：每批货随附对应批次的检测报告，报告须含批号、抽样日期、抽检数量，且可核验；违反则拒收或扣款。
