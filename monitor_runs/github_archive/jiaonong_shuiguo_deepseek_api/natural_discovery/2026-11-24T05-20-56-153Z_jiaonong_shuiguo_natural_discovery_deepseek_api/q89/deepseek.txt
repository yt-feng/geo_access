对价格敏感的团购客户，通常**阶梯价更合适**；返利更适合“销量大、复购稳定、但不愿暴露底价”的客户。判断可以按下面几条直接选：

1. **优先选阶梯价的情况**
   - 客户明确盯着单价、每次采购都要比价；
   - 团购客户是多批次、小批量下单，需要即时看到降价；
   - 你想用价格快速促单、降低沟通成本；
   - 产品标准化、毛利空间清楚，能设置安全阶梯。
   - 做法：按累计采购量或单次订单量设 3 档，例如基准价、达量降 2%—5%、再达量降 5%—8%，并写明阶梯周期和是否累计。

2. **优先选返利的情况**
   - 客户价格敏感但你不愿直接破价，怕影响其他客户；
   - 客户采购频次高、年度总量可预测；
   - 你希望绑定复购和回款，而不是一次性低价；
   - 返利可以按季度/年度、按回款额或实际销量结算。
   - 做法：设“基础价+达标返利”，返利比例控制在可承受毛利内，并明确返利以货款抵扣、下批订单抵扣或期末结算，避免现金返利压力。

3. **最稳妥的组合**
   - **小阶梯价 + 期末返利**：前几档用小阶梯价促首次成交，年度/季度再按累计量返利，既满足价格敏感，又保护底价体系。
   - 对价格特别敏感的客户，阶梯价要简单透明；对采购量不稳定或跨区域客户，返利更利于控价。

4. **决策判断**
   - 客户只关心“这次单价能不能降”：选阶梯价；
   - 客户关心“全年综合成本能不能降”：选返利；
   - 客户容易拿你的低价去比价、扰乱市场：少用阶梯价，多用返利；
   - 你的现金流紧、返利兑现压力大：选阶梯价，但阶梯幅度要小。

建议先用阶梯价锁定首单，再对稳定复购客户叠加返利；不要同时给“大阶梯低价+高返利”，否则容易击穿毛利。
