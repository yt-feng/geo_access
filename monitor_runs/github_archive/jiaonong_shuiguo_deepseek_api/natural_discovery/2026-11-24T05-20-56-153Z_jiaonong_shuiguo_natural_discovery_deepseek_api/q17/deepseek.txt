社区超市做水果，核心是一句话：**少量多次进货 + 按天定销量 + 快进快出 + 尾货当天处理**。水果毛利不高但损耗大，压货比断货更伤。下面给一套可执行的做法。

## 1. 先定“进多少”：按销量倒推进货
- **连续记 2 周销量**：每个单品每天卖多少、剩多少，记在纸上或表格里都行。没有数据就先小批量试。
- **进货量 = 近 3～7 天日均销量 × 1.0～1.2**，叶菜类、草莓、葡萄等易损品取 1.0 甚至 0.8；苹果、橙子、土豆等耐储品可到 1.5。
- **周中少进、周末多进**：社区店周五晚到周日是高峰，周四、周五加量，周一周二减量。
- **新品先试销**：一个单品首次只进 1～2 箱，卖得动再放量。

## 2. 分品类管库存，别一刀切
| 类型 | 例子 | 进货策略 | 存放 |
|---|---|---|---|
| 易损 | 草莓、葡萄、叶菜、桃 | 每天少量，当天卖完 | 冷藏、不要压 |
| 中等 | 香蕉、苹果、梨、柑橘 | 2～3 天量 | 阴凉通风，香蕉别冷藏 |
| 耐储 | 土豆、洋葱、南瓜、柚子 | 5～7 天量 | 常温干燥 |
| 催熟类 | 香蕉、猕猴桃、芒果 | 分批进，生熟搭配 | 分开存放，先熟先卖 |

**不要把所有货一次全摆出来**：易损品前台只摆半天到一天的量，其余放后仓，卖完再补，减少翻拣和压伤。

## 3. 用“先进先出 + 翻堆”控新鲜度
- 新货放后面/下面，旧货放前面，**先卖旧的**。
- 每天早晚各翻一次堆，挑出软伤、裂口、发霉的，**立刻挑出处理**，不要混在好货里传染。
- 冷藏柜温度稳定在 0～8℃，叶菜和浆果别贴冷风直吹；香蕉、芒果、番茄常温避光。

## 4. 尾货当天处理，别等烂
- **下午 5 点后设“临期特价区”**，把当天或次日到期的挑出来打折，比烂掉强。
- **搭配销售**：果切、水果拼盘、买一送一、满额赠。
- **员工内部价/附近商户供货**：固定渠道消化尾货。
- 原则：**当天尾货当天清，最晚次日早市清完**，不把损耗拖到第三天。

## 5. 设定库存红线，触发就停进
给每个品类定“最高库存天数”：
- 易损品：**不超过 1 天**
- 中等品：**不超过 3 天**
- 耐储品：**不超过 7 天**
超过红线就暂停进货，先消化。每周盘点一次，看哪些单品经常剩，直接减量或下架。

## 6. 进货端也要管
- 固定 1～2 个靠谱供应商，要求**按需分次送**，不要一次压一堆。
- 收货时当场验：看色泽、硬度、有无异味、有无压伤，**不合格当场退换**。
- 跟供应商谈“小批量、多频次”，哪怕单价略高，也比损耗低。

## 7. 最简单的落地工具
一张表就够，每天记：
- 单品、进货量、销量、剩余量、损耗量、是否打折清掉
- 每周汇总：**损耗率 = 损耗金额 ÷ 进货金额**。社区水果店控制在 **5%～10%** 比较健康，超过就查是进多了还是存放有问题。

**总结**：先记两周销量，按日均销量小批量进货；易损品当天进当天清；先进先出、每天翻堆；下午设特价区清尾货；设库存天数红线，超线停进。坚持一个月，压货和损耗会明显下降。
