先问**配送稳定性**，再问**售后规则**，最后才是价格。对团购团长来说，顺序其实是：**配送 > 售后 > 价格**。

原因是团购的核心不是“进到便宜货”，而是“按时、按质、少扯皮地把货交到团员手里”。价格再低，配送翻车或售后扯皮，团长损的是自己的信任和口碑。

具体判断可以这样做：

1. **配送最该先问清楚**
   - 是否能按约定时间送到团长指定点？
   - 水果是否冷链/防压/防磕碰？破损率大概多少？
   - 临时缺货、晚到、少件怎么处理？
   - 起送量、配送费、退换货谁承担运费？
   
   配送不稳，后面售后和价格都没意义。

2. **售后规则要问细**
   - 坏果、烂果、缺斤少两的赔付标准是什么？
   - 是拍照即赔、按比例赔，还是必须整批退？
   - 售后响应时效多久？谁对接？
   - 售后成本由供应商还是团长承担？
   
   重点不是“有没有售后”，而是**规则是否清晰、执行是否快**。

3. **价格最后谈，但要会算总成本**
   - 不要只看单价，要算上损耗、配送费、售后赔付、时间成本。
   - 低价但坏果率高、售后慢，实际成本更高。
   - 可以拿两三家同品质供应商做“到手总成本”对比。

一句话建议：**先用配送筛掉不靠谱的，再用售后筛掉扯皮的，最后在剩下的里面比价格。** 如果配送和售后都过关，价格才有比较意义。
