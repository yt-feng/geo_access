优先看成熟度，其次才是价格。原因和可执行判断如下：

**1. 成熟度直接决定出品**
- **7成熟左右（略硬、青黄）**：适合需要保持果肉块形状的装饰、夹馅，但香气弱、甜度低。
- **8—9成熟（通体黄、略有麻点）**：最适合做蛋糕体、香蕉泥、香蕉奶油，香气和甜度平衡好。
- **过熟（大面积黑斑、软烂）**：香气最浓、甜度高，适合香蕉磅蛋糕、香蕉面包、马芬；但不易切块，损耗和操作难度大，且要警惕发酵酒味和霉变。

**2. 价格只在“同成熟度档位内”比较**
用不同成熟度的香蕉比单价没意义：过熟香蕉便宜，但损耗高、出成率低、风味不稳定；偏生香蕉便宜，但香气不足，可能要额外加糖或催熟，反而增加成本。

**3. 采购建议**
- 按用途分档采购：**蛋糕体/香蕉泥买8—9成熟；装饰用买7—8成熟；当天要用的过熟蕉可低价采购但当天消耗。**
- 看货时检查：果指完整、无霉斑、无渗液、无强烈酒味；黑斑可以接受，但大面积发黑发软要折价或拒收。
- 算**可食率**而不是只看单价：去皮、去伤部后的净重更关键。
- 小批量多批次采购，配合催熟或冷藏延缓后熟，减少损耗。

**结论：先定用途和成熟度要求，再在同档位里比价格。** 成熟度不对，再便宜也不划算；成熟度合适时，价格才是第二决策因素。
