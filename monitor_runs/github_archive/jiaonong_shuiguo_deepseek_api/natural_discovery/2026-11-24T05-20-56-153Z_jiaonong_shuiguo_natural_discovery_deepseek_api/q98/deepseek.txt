判断水果供应商的合规与稳定性，建议分“硬资质—可追溯—履约能力—财务与风险—试运行验证”五层来做，别只看报价和样品。

**一、合规资质（先筛掉不合格的）**
- 营业执照经营范围含水果/农产品销售；食品经营许可证（如涉及预包装或切配水果）；种植/合作社类要有产地证明或合作基地证明。
- 索证索票：每批次提供供货凭证、产地或检测报告；重点看农残检测报告是否由具备资质的检测机构出具，报告批次与到货批次能对应。
- 配送人员健康证、运输车辆卫生与温控条件（尤其夏季和切配水果）。
- 合同里明确食品安全责任、退换货、召回、赔偿和违约条款。

**二、可追溯与质量控制**
- 能否做到“批次可追溯”：产地、采摘/进货日期、检测记录、送货单、入库记录一条线。
- 是否有稳定的分级标准（大小、糖度、外观、损耗率约定），避免到货质量波动。
- 对养老院/医院这类高风险场景，建议要求供应商提供近期农残检测记录，并保留我方抽检权利。

**三、稳定性判断（比资质更关键）**
- 货源结构：是自有基地、长期合作产地，还是临时市场调货。临时调货型供应商价格可能低，但断供和品质波动风险高。
- 仓储与冷链：有无冷库、分拣场地、配送车辆和备用车辆；旺季/节假日能否保供。
- 人员与客户结构：配送团队是否稳定，现有客户中是否有同类机构（医院、养老院、学校），可要求提供合作证明或实地考察。
- 应急能力：恶劣天气、产地涨价、临时加量时的替代方案和响应时间。

**四、财务与经营风险**
- 查企业信用信息：经营异常、行政处罚、涉诉记录、被执行信息。
- 判断是否过度依赖单一客户或单一产地；账期要求是否异常；是否存在频繁更换法人/地址等风险信号。
- 对小规模供应商，可要求履约保证金或缩短账期，降低跑路和断供风险。

**五、试运行验证（最有效）**
- 先签3个月试供合同，按周评估：到货准时率、验收合格率、损耗率、缺货次数、投诉响应时间。
- 设定量化指标，例如准时率≥98%、验收合格率≥95%、损耗率在约定范围内、紧急加单4小时内响应。
- 试供期内保留2家备选供应商，避免单一依赖。

**实操建议：** 建立供应商档案（证照、检测报告、合同、考核记录），每季度复核一次；采购时坚持“先验资质、再小批量试供、后放量”，并把食品安全和断供责任写进合同。这样既能满足监管检查，也能筛掉“报价低但不稳定”的供应商。
