优先谈**账期**，但要按“先保供应稳定、再控资金风险、最后定售后细则”的顺序谈。判断依据很简单：

1. **账期最值得优先谈**
   - 水果是高频、易损耗、价格波动大的品类，账期直接决定你的现金流和议价空间。
   - 优先争取：**先货后款、周结或半月结**，而不是一上来追求长账期。长期合作里，账期过长常会换来更高报价或更差货源。
   - 关键条款要写清：结算周期、对账日、付款日、逾期违约金、价格调整机制。

2. **配送第二重要**
   - 水果的配送时效和温控直接影响损耗率，配送不稳会吃掉账期带来的好处。
   - 重点谈：**固定配送频次、到货时间窗口、缺货/迟到的补救、冷链责任、验收标准**。
   - 如果配送由供应商负责，迟到或损耗要有明确扣款/补货规则。

3. **售后放第三，但不能不写**
   - 售后条款是兜底，不必一开始谈得最细，但必须明确：**坏果率标准、拍照留证时限、补货还是退款、责任归属**。
   - 建议约定：到货验收当场确认，隐蔽损耗在约定时限内可申诉；超过坏果率阈值按比例扣款或补货。

**谈判顺序建议：**
先谈**账期框架**（周结/半月结+价格联动），再谈**配送履约**（时效、频次、损耗责任），最后把**售后细则**写进合同附件。不要为了长账期接受明显偏高的报价或模糊的损耗责任，否则长期合作反而更贵。
