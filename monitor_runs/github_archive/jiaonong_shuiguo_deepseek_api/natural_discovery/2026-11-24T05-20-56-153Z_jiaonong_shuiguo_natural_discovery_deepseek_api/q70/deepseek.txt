合同里不要只写“坏果由卖方负责”这种空话，要把坏果的**认定标准、检验时点、责任比例、扣款或补货方式、争议处理**写清楚。建议按下面条款设计：

1. **明确质量标准**
   - 写明品种、等级、单果规格、成熟度、色泽、损伤允许范围。
   - 坏果定义可包括：腐烂、霉变、明显压伤、裂口、异味、严重失水皱缩、病虫害等。
   - 约定“坏果率”计算方式：坏果重量÷当批到货总重量，或按件/箱抽检折算。

2. **约定检验时点和方式**
   - 到货后多长时间内检验，例如“卸货后24小时内完成抽检并书面通知”。
   - 抽检比例、抽样方法写清楚，避免双方各说各话。
   - 超过约定期限未提出异议，视为数量和质量初步合格，但不免除隐蔽瑕疵责任。

3. **坏果责任分档**
   - 例如：坏果率≤3%由批发商自担；3%—8%按超出部分扣款；超过8%可要求补货、换货或退货。
   - 也可约定按坏果重量直接扣减货款，或按坏果金额的1—2倍赔偿。
   - 因运输造成的坏果，若由卖方负责运输，则卖方承担；若买方自提或指定物流，则需看风险转移节点。

4. **补货、换货和扣款**
   - 明确买方可以选择：扣减货款、要求补发同等数量合格货、整批退货。
   - 补货期限、运费承担、二次验收标准写清楚。
   - 扣款公式建议直接写进合同，例如“扣款金额=坏果重量×该批货物单价×1.5”。

5. **风险转移和保险**
   - 写清交货地点和风险转移时点。卖方送货到仓的，到仓验收前风险由卖方承担；买方自提的，装车后风险转移，但卖方对装车前已有隐蔽瑕疵负责。
   - 长途运输建议约定投保或由承运方承担，避免坏果责任全部压给一方。

6. **争议处理和证据**
   - 约定验收时拍照、录像、保留样品，双方签字确认。
   - 有争议可委托双方认可的第三方检验机构检测，费用由责任方承担。
   - 约定通知方式，如微信、邮件、书面函件均有效。

7. **兜底条款**
   - 写明“本合同未约定的坏果责任，按《民法典》买卖合同相关规定处理”。
   - 避免只写“质量合格”而不写验收标准和违约责任。

实操上，批发商最该争取的是：**到货后24—48小时内可抽检、坏果率分档扣款、超过阈值可退货或补货、扣款公式明确、验收证据可固定**。如果卖方强势，至少要把“坏果率超过X%可拒收或按比例扣款”写进去，不要接受“概不负责”或“以发货时质量为准”的条款。
