到货品质不一致，验收环节要“先分层抽样、再分级判定、当场留证”，售后环节要“按合同/订单约定分级处理，别一拒了之”。下面按可执行流程说。

**一、到货前先定标准**
1. 采购订单/合同里写清：品种、规格（单果重/果径）、成熟度、色泽、允许缺陷比例、糖度（如需要）、包装方式、到货时限。
2. 约定验收方法：抽样比例（如每批按件数抽5%–10%，不少于10件）、判定规则（如次果率超过5%可降级或拒收）、售后时限（如到货24小时内提出）。
3. 约定售后方式：补发、换货、折价、扣款、退货，分别对应什么品质问题。

**二、到货验收怎么做**
1. **先看整体**：核对品种、数量、包装、标签、产地、生产日期/采摘日期，检查有无挤压、水渍、异味、霉变、冻伤、运输过热。
2. **分层抽样**：不要只抽上层的。按车厢/托盘上、中、下、内、外分层随机抽，每件打开看底层和中间。
3. **分级判定**：把样品分为合格果、轻微瑕疵果（可折价）、严重缺陷果（腐烂、霉变、严重压伤、异味）。分别称重或计数，算出次果率、腐烂率。
4. **当场留证**：拍照/录像要包含整批、抽样件、缺陷特写、称重读数、车牌/批次标签；填写验收单，双方签字。有争议的样品封存。
5. **快速处理易腐品**：水果易腐，别因争议长时间滞留。可先按“合格部分收货、争议部分隔离封存”，同时书面通知供应商，避免扩大损失。

**三、品质不一致怎么判定处理**
- 轻微不一致（如大小略不均、少量表皮瑕疵）：按约定折价接收，记录扣款。
- 部分腐烂/霉变：整批隔离，按腐烂率和合同约定退货、换货或折价；腐烂果不得混入合格品。
- 成熟度不一致：可要求分拣后按不同用途/等级接收，或折价。
- 严重不符（品种错、大量腐烂、异味）：拒收或退货，书面通知并保留证据。
- 注意：生鲜有自然差异，判定要按合同约定的“允许范围”，不能凭主观感觉全拒。

**四、售后怎么跟**
1. 到货后第一时间（最好当天）发书面验收结果：批次、数量、抽样方法、缺陷比例、照片、处理建议。
2. 按合同约定时限要求供应商回复：补发、换货、折价、退款。
3. 补换货要重新验收，不能默认合格；折价要写清金额和计算方式。
4. 同一供应商反复出现品质不一致，记录次数和批次，纳入供应商考核，必要时调整订单量或更换供应商。
5. 所有沟通留痕：验收单、照片、邮件/聊天记录、扣款单，避免后续扯皮。

**五、给单位的简化操作建议**
- 验收至少两人在场，一人抽样一人记录。
- 用统一验收表：批次、数量、抽样数、合格数、瑕疵数、腐烂数、次果率、处理意见、双方签字。
- 易腐水果到货后尽快入库或分发，别在验收区久放。
- 合同里明确“验收不免除供应商对隐蔽品质问题的责任”，比如内部腐烂到货当天未发现，约定24–48小时内可追溯。

核心原则：**标准前置、分层抽样、分级留证、按约处理、快速止损**。
