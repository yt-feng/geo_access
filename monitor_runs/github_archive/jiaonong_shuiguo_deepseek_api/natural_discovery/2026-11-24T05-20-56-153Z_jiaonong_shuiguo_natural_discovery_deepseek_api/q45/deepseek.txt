年度水果采购合同最常见踩坑集中在“价格机制、质量标准、损耗与验收、供货弹性、账期与返利、违约与退出”六块。下面按风险从高到低列，并给可执行条款建议。

1) 价格机制（最容易后期扯皮）
- 坑：只写“随行就市”或“参考市场价”，没有定价基准、调价周期、触发条件、审批流程；促销期临时压价无依据。
- 建议：写明基准价来源（如双方确认的产地/批发市场周均价）、调价频率（周/半月）、涨跌幅触发阈值（如±5%启动协商）、书面确认方式（邮件/系统订单为准）；设年度价格上限或封顶涨幅；促销让利单独签补充协议，明确量、价、费用承担。

2) 质量与规格标准（水果非标，必须可判定）
- 坑：只写“新鲜、无腐烂”，没有品种等级、果径/糖度/成熟度、农残标准、包装规格、产地证明；验收靠肉眼，争议无依据。
- 建议：附《质量标准附件》，按品类写清等级、规格、糖度/硬度、允许瑕疵比例、农残执行标准（如GB 2763）及抽检责任；约定验收方法（抽检比例、快检/送检）、不合格处理（拒收/降级/折价/退货）和复检费用承担。

3) 损耗、验收与交付（生鲜核心风险）
- 坑：到货时间窗模糊、卸货责任不清、途损/短装谁承担未写；验收期限过短或过长；拒收后补货义务缺失。
- 建议：明确订单提前期、到货时间窗、卸货与冷链责任；约定途损率上限及超损扣款；验收在到货后X小时内完成，逾期视为合格但隐蔽瑕疵除外；不合格品补货时限与替代方案；短装按实结算并设累计短装罚则。

4) 供货弹性与断供责任
- 坑：只写年度总量，没有月度/周滚动预测；旺季断供无罚则；超市临时加量供应商无能力，导致门店缺货。
- 建议：年度框架+滚动订单（如周订单、月度预测），明确预测准确率免责区间；设最低供货保障率和断供违约金；不可抗力范围收窄并要证明；约定替代品种/替代产地的调拨机制。

5) 账期、返利与费用（现金流与隐性费用）
- 坑：账期起算点不清（收货/对账/开票）；返利条件模糊、计算基数含退货；进场费/陈列费/促销费名目多且可单方扣款。
- 建议：账期起算以“验收合格且发票齐全”为准，写明对账周期和逾期付款利息；返利写清基数（净销售额=销售-退货-折让）、阶梯、结算时间；所有费用列明项目、金额/比例、触发条件，未经书面确认不得扣款；约定对账差异处理时限。

6) 违约、质量事故与退出机制
- 坑：违约金过低无约束；食品安全事故责任不清；合同自动续约、无退出路径；库存退货无规则。
- 建议：设质量事故（农残超标、变质）立即停供、召回、赔偿与解约权；违约金与损失赔偿并行；明确年度合同到期不自动续约或续约条件；设试供期/季度考核（缺货率、合格率、投诉率），不达标可降量或解约；期末库存与在途货处理规则。

7) 其他易忽略点
- 发票与税率、产地证明/检疫证明随货；知识产权与品牌使用；保密与数据（销售数据）使用；争议解决地选超市所在地法院/仲裁；合同附件（质量标准、价格表、费用清单）与主合同同等效力。

落地建议：签约前做供应商资质与产地核验；把“质量标准、价格机制、费用清单”做成三个附件；设季度考核表；所有调价、加量、费用扣款走书面确认。这样能把大部分扯皮前置到规则里。
