采购香蕉时，按用途分层控制熟度：**当天现用、短期周转、后熟备货分开买，不要只按“黄不黄”判断。**

### 1. 先按用途定熟度
- **做冷饮、果泥、奶昔、香蕉牛奶**：选**6～7成熟到8成熟**，表皮大部分黄、略带少量青肩，捏起来略有弹性。香气够、甜度上升，但不过软，适合打泥，也不容易发酸。
- **做甜品浇头、切片装饰、烤香蕉**：选**7～8成熟**，通体黄、少量芝麻黑点即可。切片成形好，甜度也够。
- **做香蕉面包、磅蛋糕、熟蕉甜品**：可用**9成熟**，表皮大面积黑点但果肉没坏，甜度高、香气足。
- **不建议采购**：青硬无香、表皮完整但果肉已软烂、破皮渗汁、有酒味或霉点的。

### 2. 采购时现场判断
不要只看颜色，按这四步：
1. **看棱角**：棱角明显=偏生；棱角变圆=开始成熟；过圆且软=偏熟。
2. **看表皮**：少量青肩可接受；芝麻黑点适合2～3天内用完；大面积黑斑要谨慎。
3. **捏中部**：轻捏有弹性、不硬不塌最好；一捏就陷说明过熟。
4. **看果柄和破口**：果柄发黑、断口渗液、表皮破损的容易提前坏，茶饮店不建议大批量收。

### 3. 采购节奏建议
- **日常销量稳定**：按“** today用7～8成熟 + 明天用6～7成熟 + 备用少量偏生**”三档下单。
- **夏季/高温天**：整体下调半成熟度，减少一次进货量，增加频次。
- **冬季/低温天**：可适当收偏生一点，室温后熟。
- **新店或新品测试**：先小批量试3天，记录每批从到货到可用的天数，再定安全库存。

### 4. 到店后的简单管理
- 香蕉**不要冷藏**，低温会黑皮、影响风味；放阴凉通风处。
- 偏生香蕉和苹果/梨同放可加速后熟，但要每天检查。
- 按熟度分筐：**偏生区、可用区、今天必须用完区**，避免整批一起熟。
- 高峰期前2小时挑出当天要用的量，过熟或破皮的优先做果泥，不用于装饰。

**一句话标准：茶饮用蕉买“黄中带一点青肩、捏着有弹性”的7成熟左右；甜品装饰可到8成熟；熟蕉只少量备货并当天优先消耗。**
