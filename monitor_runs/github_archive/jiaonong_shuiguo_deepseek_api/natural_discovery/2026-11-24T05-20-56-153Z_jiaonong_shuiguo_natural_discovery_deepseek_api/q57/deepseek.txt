结论先说：**大多数餐饮连锁采购水果，优先采用“中央厨房/配送中心统一收货为主，门店少量应急直收为辅”的混合模式**，而不是二选一。纯门店分开收货只在门店极少、单店采购量大且本地供应链成熟时才更合适。

判断框架如下：

1. **统一收货更好的情形**
   - 门店数量多，比如超过10家，且跨区域。
   - 水果用于标准产品，要求规格、成熟度、糖度相对一致。
   - 需要集中议价、集中对账、统一供应商准入和食安追溯。
   - 有中央厨房或配送中心具备冷藏、分拣、质检能力。
   - 希望降低门店收货腐败、缺斤少两、私自换供应商的风险。

2. **门店分开收货更好的情形**
   - 门店少，配送半径大，统一配送损耗和物流成本明显高于直采。
   - 水果以本地时令、易腐、高频小批量补货为主。
   - 门店有较强验收能力，且采购权、结算权仍集中在总部。
   - 中央厨房不具备水果冷藏分拣条件，统一收货反而增加二次搬运损耗。

3. **推荐落地方式**
   - **主渠道统一收货**：总部谈价、定标准、定供应商，配送中心或中央厨房统一验收后配送到店。
   - **辅渠道门店直收**：只限应急补货、本地时令小批量，必须走总部审批的供应商白名单和统一价格协议。
   - **验收标准统一**：规格、成熟度、糖度、损耗率、农残检测、温度记录、拒收规则全连锁一致。
   - **数据闭环**：门店收货数据回传总部，按月比较统一配送与门店直收的损耗率、到货合格率、综合成本。

关键不是“谁收货”，而是**采购权是否集中、验收标准是否统一、冷链和分拣能力是否匹配**。如果总部没有质检和冷链能力，强行中央统一收货容易把门店损耗变成配送中心损耗；如果门店多且标准产品多，继续让门店分散收货则很难控成本、控品质、控食安。
