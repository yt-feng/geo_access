建议把“分级标准 + 计价单位 + 报价表 + 损耗规则”四件事分开写清楚，小店一眼能判断进哪档、多少钱。

**1. 先定分级标准**

香蕉按“外观+成熟度+单根规格”分：
- A级：果指饱满、无大面积黑斑、无机械伤，成熟度适合2–3天销售
- B级：轻微擦伤或少量斑点，1–2天内可售
- C级：明显斑点、表皮损伤，适合当天促销或加工

菠萝按“果重+外观+成熟度”分：
- A级：果形端正、无裂口、无软烂，单果重达标
- B级：轻微偏形或小瑕疵，不影响食用
- C级：明显畸形、裂口、软伤，限当天处理

每级最好配一句“允许什么、不允许什么”，避免口头扯皮。

**2. 报价单位要固定**

香蕉建议按“箱/件”报价，同时注明每箱净重、根数区间、成熟度；菠萝按“箱/件”报价，注明每箱个数和单果重区间。不要一会按斤、一会按件，容易算错。

**3. 报价表这样列**

| 品项 | 等级 | 规格 | 计价单位 | 单价 | 备注 |
|---|---|---|---|---|---|
| 香蕉 | A | 净重约X斤/箱，成熟度X | 元/箱 |  | 2–3天销售 |
| 香蕉 | B | 同上 | 元/箱 |  | 1–2天销售 |
| 菠萝 | A | 每箱X个，单果X–X斤 | 元/箱 |  | 果形端正 |
| 菠萝 | B | 每箱X个 | 元/箱 |  | 轻微瑕疵 |

**4. 提前写清损耗和退换规则**

比如：到货24小时内，C级和明显腐烂可按比例补货或折价；B级轻微瑕疵不退货；香蕉成熟度以到货当天状态为准。这样报价才“清楚且可执行”。

实际报价时，把同一品项A/B/C三档并列，不要只报一个价；小店会根据销量选档，你也减少后续争议。
