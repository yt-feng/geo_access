旺季怕断货，和供应商谈的时候重点不是“能不能多给点”，而是把**保供条件、违约代价、替代方案**提前问死。建议按下面几组问题逐条确认，最好写进合同或微信文字留痕。

**一、先问保供能力**
1. 旺季你每天/每周最多能稳定给我供多少货？按品类、规格分别说。
2. 你现在的货源是自有基地、产地直采还是市场调货？旺季会不会被上游截走？
3. 去年旺季你给其他水果店断过货吗？断货时怎么处理的？
4. 如果我临时加量，提前多久告诉你，你能保证？加量上限是多少？
5. 天气、节假日、物流紧张时，你的备货和调货预案是什么？

**二、问价格和锁价**
6. 旺季价格怎么定？是随行就市还是提前锁价？锁价锁多久？
7. 如果市场价大涨，你会不会优先供高价客户、给我减量或拖单？
8. 报价含不含运费、装卸、损耗？到店价还是产地价？
9. 起订量多少？达不到起订量怎么算？
10. 长期合作有没有阶梯价或旺季保供价？

**三、问品质和损耗**
11. 供货标准是什么？大小、甜度、成熟度、瑕疵率怎么算？
12. 到店损耗超过多少算你的？怎么赔？是补货、折价还是退款？
13. 坏果、次果怎么处理？能不能当场拒收？
14. 旺季会不会拿尾货、冷库货充新货？怎么保证批次稳定？

**四、问配送和时效**
15. 每天几点前下单、几点送到？送不到怎么赔？
16. 临时补货最快多久能到？有没有备用车辆/备用仓？
17. 运费谁承担？旺季会不会临时加运费？
18. 你放假或司机紧张时，谁替班？能不能提前告知？

**五、问断货责任**
19. 如果我提前下了确认单，你没供上，怎么赔？按缺货金额比例赔，还是补差价让我去别处调货？
20. 连续断货几次可以终止合作？已付定金/预付款怎么退？
21. 你有没有备用供应商推荐？或者能不能帮我对接你的同行应急？

**六、问结算和合作条件**
22. 结算是现结、周结还是月结？旺季要不要押金或预付款？
23. 预付款能不能抵扣？如果断货，预付款多久退？
24. 退换货流程是什么？谁承担来回运费？
25. 能不能签旺季保供协议，把数量、价格、时效、违约写清楚？

**谈的时候记住三个动作：**
- **先小单试供**：旺季前先下几次小单，看准时率、损耗率、品质稳定性。
- **留文字记录**：微信里让对方确认“每天保底X箱、缺货按X赔”，别只听口头。
- **备一个二供**：哪怕主供答应得好，也要提前找好第二家，旺季断货时能立刻补位。

最该盯死的一句话是：**“我提前确认的订单，你断货了怎么赔、多久补上、补不上我怎么调货。”** 这句问清楚，比问“能不能便宜”重要得多。
