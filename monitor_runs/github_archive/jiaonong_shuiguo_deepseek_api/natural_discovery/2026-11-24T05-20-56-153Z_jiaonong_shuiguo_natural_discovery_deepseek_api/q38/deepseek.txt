大型超市的水果供应商，通常不是“能供货”就行，超市会按**食品安全合规 + 冷链物流履约 + 追溯召回 + 品控稳定**四条线做准入。以下是可执行的清单，采购或供应商自查都可以直接对照。

## 一、食品安全能力（准入底线）

1. **主体与许可合规**
   - 营业执照、食品经营/生产许可（按业态）、法定代表人及质量负责人信息。
   - 种植/养殖端：产地证明、农业投入品使用记录；若为合作社或基地，需有基地备案或合同。
   - 进口水果：海关报关单、入境货物检验检疫证明、标签合规。

2. **检测与报告**
   - 每批次或按超市要求的频次提供农残检测报告；重点品种（叶菜、草莓、葡萄等）加密检测。
   - 具备自检实验室或与第三方检测机构签订长期协议；能按GB 2763等标准判定。
   - 对重金属、真菌毒素、保鲜剂/蜡、催熟剂等风险有专项控制。

3. **质量体系与现场审核**
   - 通过HACCP或ISO 22000、FSSC 22000等体系认证（大型超市通常优先）。
   - 能接受超市或第三方进行的**飞行检查/现场审核**：分选包装场所、冷库、清洗消毒、虫害控制、人员健康证。
   - 有不合格品隔离、召回、投诉处理程序。

4. **追溯与召回**
   - 批次号/采收日期/基地/加工线可关联，做到**正向追踪、逆向溯源**。
   - 能在约定时限内完成召回（行业常见要求为2–4小时内启动、24小时内完成流向控制，具体以合同为准）。
   - 保留进货查验、销售流向、检测记录至少保质期后6个月（法规通常要求不少于6个月）。

5. **包装与标签**
   - 食品级包装材料，索取包装材料合规证明。
   - 预包装水果标签符合GB 7718；散装水果有产地、生产者/供货者、采收/包装日期等信息。

## 二、物流与冷链能力

1. **冷链硬件**
   - 冷藏车/保温车，具备温度记录仪和**全程温度曲线**；果蔬按品类控温（如浆果0–4℃、热带水果10–13℃、叶菜0–4℃）。
   - 冷库、分选车间、装卸月台温控；有备用制冷和应急发电。

2. **运输管理与时效**
   - 能按超市DC（配送中心）预约窗口到货，准时率、缺货率、破损率可考核。
   - 运输过程防挤压、防日晒雨淋、防串味；周转筐清洗消毒记录。
   - 具备多温区配送能力，能混载不同温区水果。

3. **仓储与库存管理**
   - WMS/ERP批次管理，先进先出；临期、变质品隔离。
   - 库存周转和损耗率可追踪，能提供每日库存与到货预报。

4. **应急与履约**
   - 旺季、节假日、极端天气的保供方案；备用车辆和备用基地。
   - 食品安全事件、温控超标、交通中断的应急预案和演练记录。

## 三、超市通常还会重点看的“软能力”

- **标准化分级**：按超市规格做大小、色泽、糖度、瑕疵率分级，有验收标准书。
- **农残与品质双控**：到货抽检不合格的退换货机制、赔付条款。
- **信息化对接**：能对接超市订单、ASN到货通知、批次追溯和电子检测报告。
- **责任保险**：食品安全责任险、货物运输险。
- **持续改进**：客诉率、退货率、检测合格率月度复盘。

## 四、快速判断供应商是否达标

让对方提供一套“准入包”：许可证照、体系证书、最近3–6个月检测报告、冷链温度记录样例、追溯演练记录、召回程序、保险单、主要客户合作证明。再安排一次**现场审核 + 试单**，试单重点看：到货温度、批次信息完整性、破损率、检测报告与实物是否对应。

一句话：大型超市要的是**可追溯、可检测、可冷链、可召回、可考核**的稳定供应商，而不只是价格低。
