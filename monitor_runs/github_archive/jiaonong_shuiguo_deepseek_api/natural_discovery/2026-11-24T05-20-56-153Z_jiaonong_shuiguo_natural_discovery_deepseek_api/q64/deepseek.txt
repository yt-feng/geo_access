批发档口退货纠纷，绝大多数不是货本身有问题，而是“收货时没验清、事后各说各话”。建议把验货做成收货当场的固定动作，重点是**当场验、留证据、写结论、双方确认**。

**一、收货前先定规则**
1. 在采购合同/订单/微信确认里写清验收标准：品类、规格、数量、允许误差、色差范围、瑕疵定义、破损率上限。
2. 明确验收期限：例如“收货当场验货，最迟不超过X小时；逾期视为数量无误，质量问题按约定处理”。
3. 明确退货边界：哪些能退（破损、错发、短装、严重质量问题），哪些不退（轻微色差、合理误差、已拆标使用、二次销售影响）。
4. 约定证据形式：现场照片/视频、验货单签字、物流签收单备注。

**二、收货当场按“四步验”**
1. **先验外包装**：看有无破损、水湿、挤压、二次封箱。有问题先拍照，再在物流单上备注“外包装破损，待开箱验货”，不要直接签“完好”。
2. **点数量**：按箱/件/扎清点总数，抽箱核对每箱数量，发现短装当场记录箱号、数量、差异。
3. **抽质量**：按比例抽检（如每批抽10%—20%，大货至少抽3—5箱），看规格、颜色、做工、瑕疵、批次一致性。发现异常扩大抽检，不要只看一箱就下结论。
4. **拍证据**：拍“全景+箱号+问题特写+数量标签”，视频从开箱到发现问题连续拍，能证明是同一批货。

**三、当场填写验货单**
验货单至少写：到货日期、批次/箱号、数量、抽检比例、发现问题、处理结论（全收/部分收/拒收/换货/补发）、双方签字。微信沟通也要发一条文字确认：“今日收到X批，验货发现X问题，处理为X，请确认。”

**四、分类处理，别一刀切**
- 外包装破损但内货完好：拍照留证，正常收。
- 短装/错发：当场标注，要求补发或扣款，书面确认。
- 轻微瑕疵/色差：按合同约定折价或挑拣使用，避免事后扯皮。
- 严重质量问题：拒收或隔离存放，拍视频封存，通知供应商，不混入销售库存。

**五、内部管理跟上**
1. 固定验货人和验货时间，不让“谁有空谁收”。
2. 验货单按供应商、批次归档，退货时直接调取。
3. 对高频出问题的供应商，提高抽检比例、缩短验收期限，必要时换供应商。
4. 销售端保留批次信息，客户退货时能追溯到收货验货记录。

核心一句话：**收货当场验、问题当场记、结论当场签、证据当场留**。把“事后争议”变成“当场确认”，退货纠纷会明显下降。
