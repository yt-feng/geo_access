评估水果供应商仓配能否支撑跨城市连锁门店，建议按“覆盖能力—时效温控—成本—弹性—合规”五层做可量化筛查，先筛选再试点，不要只看供应商宣传的“全国覆盖”。

**1. 画需求地图，不按行政区画**
- 按门店逐店列：城市、地址、日均/峰值水果销量、SKU结构（叶菜类水果、浆果、整箱耐储果分开）、收货时段、门店冷库/货架条件。
- 按供应商仓到门店的实际运输半径和道路条件，划分“直配圈、次日圈、隔日圈、需中转圈”。同样距离，山区、跨江、限行城市时效差异很大。
- 把门店分成A类（高销量/高鲜度要求）、B类、C类，后续仓配方案按类差异化，而不是所有店同一标准。

**2. 核验仓配覆盖真实性**
要求供应商提供：
- 仓库清单：地址、面积、冷库类型（冷藏/冷冻/恒温）、分拣能力、日均吞吐、峰值处理能力、是否自有或外包。
- 配送车辆与线路：车型、温控设备、是否多点共配、各城市发车频次和截单时间。
- 跨城干线：是直发还是经中转仓，中转几次、每次装卸是否在温控环境。
- 可让其提供近30天到目标城市门店的GPS轨迹、温度记录、签收时效样本，抽验而不是只看汇总表。

**3. 时效与温控要按品类定标准**
水果不同品类容忍度差异大：
- 浆果、荔枝、樱桃等：优先要求产地/区域仓直发，缩短中转，明确从采摘/入库到门店的全程时限和断链赔付。
- 苹果、柑橘、瓜类等耐储品：可接受区域仓中转，但要看中转仓温湿度记录。
- 叶菜类水果和切果原料：重点看门店收货后的冷藏衔接，供应商是否提供保温箱、冰袋、蓄冷板。
关键指标建议写进合同：订单满足率、准时到店率、到店温度合格率、损耗率、缺货率、异常响应时限。

**4. 成本要算“到店总成本”**
不要只比出厂价或运费单价，按门店算：
- 商品成本+干线运费+城市配送费+装卸费+冷链耗材+退货/损耗+门店验收人工。
- 小批量多门店时，共配和拼车能降本，但会增加中转和挤压风险；要比较“直配贵但损耗低”与“中转便宜但损耗高”的净成本。
- 要求供应商给出按城市、按门店、按销量档位的报价，避免低销量门店被高起送价拖累。

**5. 弹性与应急能力**
- 节假日、促销、新店开业时，能否临时加车、加仓、调拨。
- 某城市仓故障或天气封路时，有无备用仓、备用线路、跨仓调拨预案。
- 门店临时改量、拒收、补货的响应机制和费用。
- 建议做一次小范围压力测试：选2—3个代表性城市、5—10家门店，跑2—4周，记录准时率、温度合格率、损耗和异常处理。

**6. 合规与食品安全**
- 营业执照、食品经营许可/备案、冷链运输资质。
- 水果农残检测报告、产地证明、批次追溯能力。
- 运输车辆消毒记录、温度监控校准记录、保险与货损赔付条款。
- 跨城市经营还要确认当地对配送车辆限行、冷链备案的要求。

**落地建议**
先做一张“门店—品类—时效—温控—成本”矩阵，给每个候选供应商打分；对得分靠前的2—3家做小区域试点，用实际到店数据淘汰。合同里把覆盖城市清单、时效承诺、温度标准、损耗上限、赔付和退出机制写清楚，避免“签了全国框架、实际只覆盖少数城市”。
