重要，而且对多门店超市来说，供应商分级标准不是“参考项”，而是统一水果品质的基础设施。没有统一分级，门店越多，品质波动和客诉越难控。

**为什么重要**
1. **统一品质的前提是统一语言**：各门店对“大果/中果/小果、精品/统货”的理解不一致，会导致同一SKU在不同门店呈现不同规格和口感。
2. **采购定价和结算需要依据**：分级标准明确后，才能按级定价、按级验收、按级扣罚，避免“好货坏货一个价”。
3. **降低门店验收争议**：有可量化的分级标准，门店收货时能快速判断合格与否，减少总部、供应商、门店三方扯皮。
4. **支撑品类管理和陈列**：不同级别对应不同销售渠道，如精品门店、社区店、线上特价，避免好货贱卖或次货进精品区。
5. **倒逼供应商稳定供货**：标准明确后，供应商知道什么货能进场，长期会按标准做采后分选，品质稳定性提升。

**建议的可执行做法**
- **先定核心品类标准**：不要一次覆盖所有水果，优先对销量大、客诉高、价格差异大的5—10个品类制定分级标准。
- **标准要可量化**：至少包含规格（单果重/直径）、外观（着色度、瑕疵面积）、成熟度、糖度（重点品类）、新鲜度（果梗、失水）、包装规格。
- **分级与用途绑定**：明确A/B/C级分别进哪些门店、做什么陈列、是否允许线上销售。
- **验收可操作**：给门店一张“验收卡”，写清抽检比例、合格判定、扣罚规则，避免凭感觉收货。
- **供应商准入和考核挂钩**：把分级合格率纳入供应商月度评分，连续不达标降级或淘汰。
- **小范围试点再推广**：先选2—3家门店和1—2家供应商试运行1个月，校准标准后再全渠道推行。

**判断标准**
如果目前多门店已经出现“同一水果不同店口感/大小不一、门店间调货困难、供应商送货质量靠关系、客诉集中在品质不稳定”，那供应商分级标准就是优先要补的短板。反之，如果品类少、门店少且供应商单一，可以先做简化版验收标准，再逐步升级为完整分级体系。
