社区超市卖小包装香蕉，采购和包装要抓住“少进货、快周转、控机械伤、稳催熟”四个点。可执行建议如下：

1. **包装规格**
   - 主推 **2–3 根/袋（约 300–500g）**，再配少量 **1 根装或 4–5 根家庭装**；先小批量试销，按日销量定规格。
   - 优先选 **带透气孔的薄膜袋/网袋+标签**，不要完全密封；袋上打孔或选微孔膜，减少水汽积聚。
   - 袋口留松，不要紧勒果指；用托盘或纸盒做外包装，避免堆压。
   - 标签直接贴袋或挂签，别用订书钉、硬扎带勒伤果柄。

2. **采购成熟度**
   - 小包装周转慢于散装，采购成熟度要比散卖略低：**青黄阶段、果指饱满但未软**，到店后自然转黄。
   - 避免采购已出现黑斑、果柄发黑、果指发软的货；同批成熟度要一致，便于按天分级上架。
   - 问清产地催熟方式、采摘和到货天数。社区店单次采购量建议按 **1–2 天销量** 控制，夏季再压缩。

3. **机械伤和冷链**
   - 香蕉怕压、怕擦、怕冻。采购时检查箱内是否有挤压变形、果指擦伤、断柄；断柄和破皮果不要进小包装。
   - 运输和店内暂存保持 **13–15℃左右、通风**，不要放冷藏柜；避免和苹果、梨等释放乙烯多的果蔬混放，防止过熟。
   - 到店后先散热再装袋，热果直接套袋易结露、长霉。

4. **损耗控制**
   - 小包装按 **“少量多次”** 补货，上午、傍晚各理一次货；把转黄的袋装香蕉放前排，青一点的放后排。
   - 设 **临期/过熟折扣区**：出现零星黑斑但果肉未坏的，及时打折或做香蕉牛奶搭配促销，别等整袋报废。
   - 每天记录各规格销量和报损，连续几天卖不动的规格就减量或停做。
   - 袋内出现水珠要及时换袋或擦干；发现霉点整袋隔离，避免传染。

5. **采购合同和验收**
   - 明确验收标准：果指完整、无断柄、无明显压伤、成熟度一致、袋内无积水。
   - 约定到货损耗率和退换货规则，比如机械伤、烂果超一定比例可退换；首次合作先小批量试单。
   - 要求供应商按小包装需求分级，别把散装尾货直接塞进小袋。

一句话：**小包装赚的是便利溢价，采购端必须用更低成熟度、更小批量、更轻包装和更快折价来对冲损耗。**
