结论先说：**大多数食堂按“斤”结算最容易管理、最经得起审计；按箱适合耐储存、规格统一、整箱验收的品类；按份只适合即食水果或固定套餐。** 最好不是三选一，而是**分类结算＋统一验收标准**。

**三种方式对比**

| 结算方式 | 优点 | 主要风险 | 适用场景 |
|---|---|---|---|
| 按斤 | 计量公平、便于比价、损耗可核算 | 称重和验收工作量大，需防缺斤短两 | 大宗水果、散装采购、叶菜类水果 |
| 按箱 | 验收快、流程简单、单价易谈 | 箱内品质不均、烂果损耗责任难界定、箱子重量和规格争议 | 苹果、橙子、西瓜等规格稳定的整箱品类 |
| 按份 | 管理最省事、成本固定、便于定价 | 份量缩水、品质波动、比价困难、审计依据弱 | 切好即食水果、固定套餐、小份零售 |

**建议做法**

1. **主品类按斤**：苹果、香蕉、梨、橘子等散装大宗水果，按斤结算，方便比价和核算损耗。
2. **耐储整箱品类按箱**：必须写明**箱规、净重、品种等级、产地、破损率上限**，验收时抽检并称净重，不能只数箱数。
3. **即食或套餐按份**：只对切果盒、固定配餐使用，合同里明确每份克重、水果种类和最低品质标准。
4. **统一验收**：到货称重、抽检品质、记录损耗；按箱的抽检比例建议不低于10%—20%，按份的定期称重复核。
5. **比价口径统一**：都折算成“元/斤净重”或“元/份标准克重”比较，避免箱装单价低但净重不足造成误判。

**最省管理的组合**：**大宗散装按斤＋规格稳定整箱按箱＋即食套餐按份**，并在采购合同里写清净重、破损率、退换货和验收规则。这样既控制成本，也便于食堂日常管理和审计。
