生鲜水果坏果责任划分，先看“坏在哪一环、有没有证据、是否在合理时效内”。实务上可按下面判断：

1. **先定责任类型**
   - **商家/平台责任**：到货即腐烂、发霉、虫害、明显压伤，或商品描述与实物严重不符；冷链/包装不当导致变质；缺斤少两、以次充好。
   - **物流责任**：外箱严重破损、挤压、暴晒、延迟配送导致变质；但需区分是物流造成还是发货前已有问题。
   - **顾客责任**：签收后长时间未取/未冷藏、存放不当、超时后才投诉、人为损坏。
   - **不可归责/自然损耗**：少量轻微碰伤、个别果实成熟度差异，通常按售后规则部分补偿，不宜全部归责。

2. **关键判断点**
   - **签收时是否验货/拍照**：外包装、面单、坏果整体和局部照片/视频。
   - **投诉时效**：一般应在签收后尽快反馈；易腐水果越早越好，具体以平台售后规则为准。
   - **坏果比例**：个别坏果通常按比例退款或补发；大面积腐烂可全额退款/补发。
   - **是否影响食用安全**：发霉、异味、汁液污染其他果实的，建议整单退换，不要只赔单个。

3. **建议的责任划分方式**
   - 到货即发现且证据充分：**商家/平台承担主要责任**，按坏果比例退款、补发或整单退换。
   - 外箱明显破损且当场拍照：**商家先售后，再向物流追偿**；顾客不必自行找物流扯皮。
   - 顾客延迟取货或存放不当：**顾客承担相应责任**，商家可协商部分补偿。
   - 轻微自然损耗：**双方协商部分补偿**，按平台规则处理。

4. **可执行处理流程**
   - 顾客：保留面单、开箱视频、坏果照片，尽快申请售后，写明坏果数量和比例。
   - 商家：先核实证据和时效，符合规则就快速退款/补发；同时留存发货质检、包装、冷链记录，便于向物流追责。
   - 平台：按售后规则判责，避免让顾客在商家和物流之间来回举证。

**一句话结论**：到货即坏且证据充分，主要由商家/平台对顾客负责，物流问题由商家事后追偿；顾客因延迟取货或保存不当导致的坏果，顾客承担相应责任；轻微自然损耗按比例协商补偿。
