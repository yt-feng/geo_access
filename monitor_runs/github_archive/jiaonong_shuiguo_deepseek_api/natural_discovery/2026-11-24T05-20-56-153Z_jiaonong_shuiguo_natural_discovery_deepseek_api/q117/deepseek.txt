没有统一数字，但可以用一个“小到亏得起、又能看出问题”的试卖量。建议按下面判断：

**1. 先定试卖量级**
- **单店/单档口**：新品水果先试 **3～5天销量**，通常按 **20～50公斤/件的小批量** 起，易损耗水果取低值，耐储水果取高值。
- **连锁多店**：先选 **2～3家代表性门店**，每店按 **1～2天预估销量** 试卖，不要全渠道铺开。
- **高客单/礼盒类**：先试 **10～20箱**，主要看退货、破损和复购。
- **叶菜类、浆果类等极短保鲜品**：首单更小，建议 **半箱到1箱/店**，宁可次日补货。

**2. 用公式算更稳**
试卖量 ≈ **预计日销量 × 试卖天数 × 0.5～0.7**
例如预估每天卖20公斤、试3天，首单约 **30～42公斤**。这样即使卖不动，损耗也可控。

**3. 先问清供应商这几个条件**
- 最小起订量、是否可拆件
- 坏果率/损耗赔付标准
- 到货成熟度、可存放天数
- 补货时效：次日能否补
- 试卖期是否支持调换或退部分货

**4. 判断是否加量的标准**
试卖3～5天后看：
- **售罄率≥80%**、损耗≤5%：可加量到正常采购的50%
- **售罄率60%～80%**、损耗5%～10%：维持小量再试一周
- **售罄率<50%** 或损耗>10%：暂停，换规格或换品

一句话：**首单控制在“3～5天能卖完、亏了也不心疼”的量，先小范围试销，再按售罄率和损耗决定加量。**
