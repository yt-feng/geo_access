要支持，但不应无条件、全品类地支持；应按品类和门店设置分层的小批量高频补货规则。

理由很直接：即时零售的需求特点是订单碎片化、履约时效短、损耗敏感。水果又是短保、非标、价格波动大的品类。供应商如果把补货门槛设得过高，门店要么缺货丢单，要么被迫压库存、增加损耗，最终双方都受损。所以支持小批量高频补货，是提升动销和降低损耗的必要能力。

但要避免三个坑：

1. **成本失控**：小批量高频的物流、分拣、单据成本会上升。供应商需要设最低起补金额/件数、按区域合并配送、对超高频补货收阶梯配送费，或把成本折进供货价。
2. **非标品质波动**：高频补货容易把尾货、次果混入。必须明确验收标准、批次追溯和退换货规则，否则门店客诉会反噬供应商。
3. **平台把库存风险全转嫁**：如果平台要求“随叫随到、卖不完退货”，供应商会亏。合理做法是约定责任库存、临期处理规则和损耗分担比例。

可执行建议：

- **A类高频刚需果品**（香蕉、苹果、橙子、应季爆款）：支持每日甚至一日多次补货，设较低起补量，供应商备安全库存。
- **B类中周转果品**：支持隔日补货，设中等起补量。
- **C类长尾/高损果品**（榴莲、精品礼盒、小众水果）：不建议小批量高频，改为预售、周配或按门店定向补货。
- **机制上**：用历史销量加天气/促销/节假日做补货预测；设置缺货率、损耗率、履约准时率三个指标共同考核；小批量补货的额外成本通过阶梯价或配送费透明化，而不是隐性涨价。

一句话：**要支持，但必须是“有规则、有门槛、有成本分担”的支持，而不是无条件随叫随到。**
