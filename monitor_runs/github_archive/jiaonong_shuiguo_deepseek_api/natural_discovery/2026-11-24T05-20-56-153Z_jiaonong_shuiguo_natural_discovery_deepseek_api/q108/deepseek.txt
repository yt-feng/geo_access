不要只听“全国配送”这句话，要把它拆成可验证的条件：哪些城市、什么时效、什么品类、起订量、冷链能力、异常处理、赔付。建议按下面顺序核实。

**1. 先让对方书面明确“全国配送”的定义**
要求供应商提供一份配送范围表，至少包含：
- 可配送省份/城市清单，以及是否区分市区/偏远地区
- 各区域时效：次日达、隔日达、2—3天、普通快递
- 起订量/最低配送金额
- 哪些水果支持冷链，哪些只能常温
- 节假日、雨雪天气、偏远地区是否停发
- 破损、腐烂、延误的赔付标准

口头承诺不算，要求盖章报价单或合同附件。

**2. 用真实订单做小批量测试**
不要只发一个本地或邻近城市。选3—5个目标城市，覆盖：
- 核心城市
- 偏远或低线城市的实际收货地址
- 高温地区或长途线路

每单记录：下单时间、发货时间、到达时间、包装状态、果温、破损率、签收体验。测试单最好用实际采购品种和包装规格，不要用样品单。

**3. 核查物流合作方和路由**
问清楚：
- 合作快递/物流公司名称
- 是自有仓直发，还是多地分仓
- 从哪个仓发到目标城市
- 冷链是全程冷链、泡沫箱+冰袋，还是到目的地转常温
- 能否提供物流单号全程轨迹

如果对方说不清发货仓和路由，所谓“全国配送”通常只是普通快递覆盖，不等于水果配送能力。

**4. 要求提供可验证的客户案例**
让对方给出2—3个与采购方规模、品类、区域相近的客户案例，并允许你联系核实。重点问：
- 实际到货时效
- 损耗率
- 旺季是否爆仓
- 售后响应速度
- 是否有临时加价或停发

**5. 核查资质与责任能力**
- 营业执照经营范围是否含食品销售/道路运输相关资质
- 食品经营许可证或食用农产品相关合规文件
- 是否有货物运输保险
- 合同里是否明确时效违约、腐损赔付、不可抗力边界

**6. 用试单数据做判断**
建议设定可量化门槛，例如：
- 目标城市试单准时率达到95%以上
- 腐损率低于行业可接受水平，并在合同中约定上限
- 售后24小时内响应
- 连续2—3次试单稳定

**7. 合同里写清楚“覆盖能力”**
把配送范围表、时效承诺、冷链方式、赔付标准、停发通知义务写进合同附件。约定：供应商新增或缩减配送区域需提前通知；因物流原因导致腐损的赔付比例；旺季运力保障责任。

**结论：** 核实“全国配送”最有效的方式是“书面范围表 + 多城市真实试单 + 物流路由核查 + 合同赔付约束”。只提供一张全国地图或口头说都能发，不足以证明实际覆盖能力。
