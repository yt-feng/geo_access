商超做会员日水果活动，供应商要提前配合的重点不是“多送货”，而是把**货源、价格、品质、陈列、履约、应急**六件事在活动前锁定。建议按下面清单执行。

## 1. 活动前 7–10 天：确认方案与锁量
- **确认活动单品/爆品**：明确品种、规格、等级、包装形式、活动价与正常价。
- **预估销量并锁货**：按门店数、日均销量、活动增幅、天气因素做分店分日需求预测；供应商书面确认可供量。
- **锁定产地/加工厂产能**：尤其是叶菜、草莓、蓝莓、榴莲、车厘子等易波动品，避免临时缺货。
- **确认价格有效期**：活动价覆盖时间段、补货价是否同价、调价机制写清。
- **明确退换货与损耗承担**：烂果、压伤、规格不符、到货不新鲜的处理规则。

## 2. 活动前 5–7 天：品质与包装准备
- **提前做品质标准确认**：糖度、果径、成熟度、色泽、瑕疵率、农残检测报告等逐项确认。
- **包装与预包准备**：会员日客流大，优先做预包装、称重贴标、统一规格，减少门店现场分拣压力。
- **标签与物料**：活动价签、产地/等级标签、追溯码、促销围挡或堆头物料由谁提供要明确。
- **样品确认**：活动前提供样品，商超采购/门店验收确认后封样，避免到货扯皮。

## 3. 活动前 3–5 天：履约与物流排期
- **确认送货计划**：分店、到货时间、频次、车辆、卸货口、联系人逐店确认。
- **避开高峰**：会员日门店忙，建议错峰到货，生鲜早配、补货定时。
- **冷链与保鲜**：需冷链的提前确认车辆温控、周转筐、冰袋、防压包装。
- **应急补货方案**：准备备用货源、备用车辆、临时加急配送联系人。

## 4. 活动前 1–2 天：门店落地配合
- **陈列支持**：供应商是否派人协助陈列、试吃、补货、理货，提前排班。
- **试吃与推广**：如需试吃，确认果品、工具、人员、食品安全要求。
- **门店培训/沟通**：让门店知道到货规格、存放条件、售卖话术、品质异常反馈路径。
- **库存检查**：商超检查门店冷库/货架容量，供应商确认首批到货量不压仓。

## 5. 活动期间：响应机制
- **每日销售与库存反馈**：商超把动销、缺货、品质问题反馈给供应商，供应商按约定频次补货。
- **品质巡检**：供应商配合巡店，及时处理软果、压伤、变质。
- **价格与库存保护**：避免活动期间断货后高价补货，提前约定补货价。
- **异常处理时限**：如到货不合格，几小时内换货/补货，谁承担费用要提前写清。

## 6. 活动后：复盘与结算
- **损耗与退换货核对**：按约定处理活动尾货、损耗。
- **销售数据复盘**：哪些单品卖爆、哪些缺货、哪些品质投诉，形成下次备货依据。
- **结算凭证**：活动价、补货单、退换货单、费用承担确认齐全。

## 最关键的 8 个确认项
1. 活动单品、规格、等级、价格锁死；
2. 分店分日可供量书面确认；
3. 品质标准和封样确认；
4. 预包装/贴标由谁做；
5. 分店到货时间和频次；
6. 冷链与防压包装；
7. 缺货/品质异常的换补货时限和费用承担；
8. 活动期补货价格不变或调价规则。

一句话：**供应商要在活动前把“货够不够、价稳不稳、品质达不达标、几点送到哪家店、出问题谁多快处理”全部书面确认，会员日水果活动才不容易翻车。**
