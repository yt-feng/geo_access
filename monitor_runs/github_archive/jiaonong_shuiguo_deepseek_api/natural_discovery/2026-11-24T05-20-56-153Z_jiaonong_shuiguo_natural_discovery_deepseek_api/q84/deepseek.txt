家庭场景优先“好吃、好分、耐放、成本稳”，建议不要四种等量混装，而是做 **2个主力 + 2个点缀** 的组合。

**最推荐：家庭分享装**
- 苹果 4个
- 橙子 4个
- 香蕉 1把（约5-6根）
- 菠萝 1个
- 适合3-5口之家，总价容易控制，颜色也好看。
- 苹果、橙子耐放，香蕉和菠萝负责“礼盒感”和香气。

**更稳妥的耐放型**
- 苹果 5个
- 橙子 5个
- 香蕉 1小把（3-4根）
- 菠萝 不放或换小菠萝1个
- 适合团购履约：香蕉少放，减少催熟和压伤；菠萝整颗对老人小孩处理门槛偏高，可改成“菠萝切盒”作为加分项。

**更讨小孩喜欢型**
- 苹果 3个
- 橙子 3个
- 香蕉 1把
- 菠萝 1个（可配切果器或切盒）
- 苹果橙子不必多，香蕉和菠萝是记忆点，但成本波动要留余量。

**组合原则**
1. **苹果、橙子做重量和耐放担当**，占比约60%-70%。
2. **香蕉做视觉和即时食用担当**，但量要少，避免团购到货后过熟。
3. **菠萝做礼盒亮点**，整颗显档次但处理麻烦；家庭团购更建议“整颗+切盒二选一”，或整颗配简易切法说明。
4. 礼盒内做好**分层防压**：苹果橙子底层，香蕉上层，菠萝单独固定。
5. 定价上把香蕉、菠萝的损耗算进去，别按理论克重定毛利。

如果只选一个方案，选 **苹果4 + 橙子4 + 香蕉1小把 + 菠萝1个**，家庭接受度最高，也最容易讲清楚“分享装”的卖点。
