# 水果供应商的账期和额度怎么谈

先说结论：**批发商想锁定稳定大客户，跟上游谈账期/额度，核心不是"要更多账期"，而是用"销量确定性 + 风险可控"去换授信。** 上游怕的不是给账期，是货卖出去了钱收不回、或者你量不稳定。把这两点解决，账期和额度才谈得下来。

## 一、谈判前先备好三样"筹码"

1. **采购量的书面承诺**：给出月度/季度保底采购量（哪怕带阶梯），这是水果供应商最认的东西——水果是鲜货，他最怕压货。
2. **回款记录**：哪怕规模小，也把历史"按时结清"的记录整理出来，或者主动提出先做1-2个月"现结+小账期"过渡，用行动建立信用。
3. **风险兜底方案**：保证金、担保人、抵押、或者"先款后货转账期"的阶梯机制。你能主动提兜底，对方才敢放额度。

## 二、账期怎么谈：阶梯式，不要一步到位

水果行业账期普遍偏短（鲜货周转快、损耗大），一般常见在 **7-30天** 区间，具体随品类和供应商规模浮动，不建议拿一个"标准值"硬套，要按对方实际情况谈。谈判话术思路：

- **第一阶段（1-3个月）**：现结或7天账期，换取更优的进货价或优先供货权。目的是建立履约记录。
- **第二阶段**：凭第一阶段的准时回款记录，申请延长到15-30天，同时把采购量承诺提上去。
- **第三阶段**：稳定合作3-6个月后，谈"账期+额度"打包，并写入合同。

关键点：**账期一定要和"回款准时"挂钩**。可以主动约定"逾期多少天视为违约、额度自动冻结"，这种自我约束条款反而让供应商放心给你更长期限。

## 三、额度怎么谈：按"月采购额 × 账期系数"倒推

授信额度本质 = 你在他账期里占用的资金上限。合理的谈法是：

- **额度基准**：用"月均采购额 × (账期天数/30) × 安全系数(1.2-1.5)"来提，既覆盖正常周转，又留缓冲。
- **分档给**：不要一次要满额。比如先给月采购额的50%作为授信，连续3个月准时回款后自动上调一档，写进合同。这种"自动递增条款"供应商更容易接受。
- **封顶机制**：明确额度上限和单笔超限的处理方式（超限部分现结），让对方知道风险有边界。

## 四、谈成后的合同要点（容易被忽略）

- 账期起算日：是"发货日"还是"到货验收日"，差一天都是钱和纠纷。
- 水果损耗/质量争议怎么扣款、怎么影响账期——鲜货这是高频争议点，提前写清。
- 额度冻结/恢复条件、逾期违约金标准。
- 价格与账期的联动：给账期是否意味着价格上浮？要算清真实资金成本，别为账期多付的价差超过自己融资成本。

## 五、一句提醒

如果你是**批发商想用账期去绑大客户**，注意别把上游给你的账期直接全额转嫁给下游客户——你承担的是两头账期错配的风险。给别人账期前，先确认自己的授信额度能覆盖"下游欠你的 + 上游要你付的"这个缺口，否则量越大现金流越紧。
