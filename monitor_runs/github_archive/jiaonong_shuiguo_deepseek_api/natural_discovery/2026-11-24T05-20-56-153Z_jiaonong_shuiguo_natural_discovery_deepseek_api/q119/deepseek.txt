做水果长期生意，选供应商时最容易忽视的不是价格和品类，而是下面这些“平时不出事、出事就伤客”的细节：

1. **稳定供货能力，而非单次到货质量**
   要看供应商在淡季、节假日、天气异常时还能不能稳定供货。很多供应商平时不错，一到旺季就优先供大客户，你的货被挤掉。
   **可判断动作**：问清楚他的日/周稳定供货量、几个主要客户、异常天气时的替代货源。

2. **批次一致性**
   水果最怕“这批好、下批差”。同一品种的甜度、大小、成熟度、包装规格是否稳定，直接影响复购。
   **可判断动作**：连续拿3-5批小样，记录糖度、损耗率、规格差异，不要只看第一批。

3. **损耗责任和售后规则**
   到货后烂果、压伤、成熟度不对，谁承担？很多合作开始时没写清楚，出问题就扯皮。
   **可判断动作**：合作前明确验收标准、拍照留证时限、赔付比例、换货条件。

4. **采后处理和冷链细节**
   同样产地，采后预冷、分级、包装、运输温控不同，货架期差很多。忽视这点会导致“到货看着好，两天就坏”。
   **可判断动作**：问到采摘时间、预冷方式、运输温度、包装透气性，最好实地看一次。

5. **成熟度控制是否配合你的销售节奏**
   供应商如果只按自己方便发货，给你太生或太熟，都会影响销售。长期生意要能按你的日均销量和货架期分批供。
   **可判断动作**：要求按销售节奏分规格、分成熟度供货，并测试到货后第1/3/5天状态。

6. **产地真实性和混货风险**
   以次充好、产地混装、等级混装很常见。长期做口碑，一旦被顾客发现，损失的是信任。
   **可判断动作**：固定包装标识、要求批次可追溯，定期抽检，不长期只靠口頭承诺。

7. **结算方式和涨价机制**
   只谈单价不够，要看账期、押金、临时涨价规则、运费谁承担。旺季突然涨价或改账期，会打乱现金流。
   **可判断动作**：书面约定价格调整提前通知期、运费承担、账期上限。

8. **供应商的客户结构**
   如果他的大客户和你的销售渠道冲突，比如也做社区团购或批发，可能压你价格或抢你客户。
   **可判断动作**：了解他主要供哪些渠道，是否和你区域重叠。

9. **应急替代方案**
   长期稳定不是永不断货，而是断货时有没有预案。只靠一个供应商风险很高。
   **可判断动作**：至少保留一个备用供应商，核心单品准备两套货源。

10. **合作意愿和沟通响应**
    出问题时能不能及时处理，比平时报价低几毛更重要。回复慢、推责任的供应商，长期会消耗你大量精力。
    **可判断动作**：故意在小问题上测试响应速度和解决态度，再决定是否放量。

一句话建议：**先用小批量、多批次试供，把“验收标准、损耗赔付、稳定供货量、价格调整规则”写清楚，再逐步放量。** 长期水果生意，供应商的核心价值是“稳定可预期”，不是最低价。
