判断苹果和橙子的规格是否适合门店销售，可以从“可验收、可陈列、可定价、可复购”四个维度快速判断。下面给出一套可在收货现场直接执行的判断方法。

## 一、先定门店的销售场景

同样规格在不同门店适配度不同，先明确：

1. **主销方式**：散称、预包装、礼盒、果切/餐饮供货。
2. **客群**：社区家庭、写字楼白领、学校/医院周边、高端社区。
3. **价格带**：主推平价走量，还是中高端品质。
4. **陈列条件**：货架层高、堆头容量、冷柜/风幕柜是否够用。

规格不适合，常见不是“大小不好”，而是“和销售方式不匹配”。例如大果散称易剩、小果礼盒显廉价。

## 二、苹果：用“横径+单果重+整齐度”判断

### 1. 现场测量
- 用卡尺或带孔分级板测**横径**，随机抽30—50个，记录最小、最大、平均值。
- 用电子秤抽测**单果重**，算平均单果重和波动范围。
- 看**大小整齐度**：同一箱内最大与最小横径差最好控制在5—8mm内；散称可略放宽，礼盒要更严。

### 2. 适配门店的参考判断
- **社区散称走量**：横径75—85mm、单果重180—250g通常较好卖；过大易按个卖不动，过小显得没性价比。
- **精品/礼盒**：横径80—90mm，果形端正、色泽一致、无伤，整齐度优先。
- **果切/餐饮供货**：更看重出成率、耐储和成本，规格可略放宽，但需稳定。
- **预包装**：按袋/盒定价时，重点看**每袋个数和总重是否稳定**，避免同价不同量。

### 3. 苹果还要看
- 果径是否与标签一致，避免“标80实际75”。
- 硬度、糖酸比、虎皮/磕碰/水心病等缺陷比例。
- 品种差异：富士、嘎啦、元帅等同样横径的手感和单果重不同，不能只凭目测。

## 三、橙子：用“横径+单果重+皮厚/出汁率”判断

### 1. 现场测量
- 同样抽测**横径**和**单果重**，记录均匀度。
- 切开2—3个看**皮厚、籽量、汁水**；鲜食橙和榨汁橙标准不同。
- 摸表皮：过粗厚、干瘪、软塌会影响复购。

### 2. 适配门店的参考判断
- **社区散称鲜食**：横径65—75mm、单果重150—220g较适中；太小剥皮麻烦，太大单价高。
- **精品果/礼盒**：横径70—80mm，果面干净、颜色均匀、大小一致。
- **榨汁/果切**：更看出汁率和皮厚，规格可放宽，但需稳定供货。
- **预包装**：按份定价时，确保每份个数、总重、可食率稳定。

### 3. 橙子还要看
- 品种与季节：脐橙、血橙、冰糖橙、夏橙的适销规格不同。
- 皮厚和枯水：皮厚、中心柱大、汁少会拉低复购。
- 损耗：软果、霉变、压伤比例要现场抽检。

## 四、到货现场可直接用的验收动作

1. **随机抽样**：每批抽3—5箱，每箱抽10—20个，不只看上层。
2. **测三项**：横径、单果重、缺陷率。
3. **算两项**：平均单果重、大小极差；极差过大说明分级不稳。
4. **做陈列测试**：拿一箱实际摆到门店货架/堆头，看层高、容量、拿取是否方便。
5. **做定价测试**：按预计售价算毛利，扣除损耗后是否成立。
6. **小批量试销**：新规格先试销3—7天，看动销、损耗、客诉和复购。

## 五、快速判定“不适合门店销售”的信号

出现以下情况，建议拒收、降级或换销售方式：
- 标签规格与实际横径明显不符，大小混杂严重。
- 同箱最大最小差距过大，无法稳定按份/按个定价。
- 缺陷率偏高：磕碰、霉变、软果、裂口、日灼等超过可接受范围。
- 陈列困难：过大放不进货架、过小显得空箱、堆头易塌。
- 算上损耗后毛利不成立，或同价竞品规格明显更优。

## 六、建议门店建立自己的规格卡

给每个主销品种建一张简单规格卡，写清：
- 品种/产地/季节
- 目标销售方式
- 横径范围、单果重范围
- 整齐度要求
- 缺陷率上限
- 建议售价与毛利
- 试销结论

这样采购时不用每次凭感觉，直接对照规格卡验收即可。

总结：**苹果看横径、单果重、整齐度和硬度；橙子看横径、单果重、皮厚出汁和新鲜度。最终是否适合，要用门店实际陈列、定价、损耗和试销数据来验证。**
