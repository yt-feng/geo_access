要减少香蕉熟过头浪费，核心是“按成熟度分批采购、分批使用”，而不是只靠延长保存。可执行做法：

1. **分规格采购**
   - 同一批不要全买“黄熟”香蕉。建议按用量拆成：
     - 青黄蕉：2–3天后用；
     - 黄熟蕉：当天、次日用；
     - 少量带斑点蕉：立即做香蕉牛奶、烘焙、水果沙拉。
   - 采购单上写明“到货成熟度”，不要只写数量。

2. **控制单次到货量**
   - 按食堂每日实际消耗量下单，香蕉类建议以“1–2天用量”为主，避免一次进3–5天量。
   - 夏季或室温高时进一步缩短到“当天+次日”量。

3. **收货时分级**
   - 到货后立刻分三筐：青、黄、熟。
   - 青蕉放阴凉通风处；黄蕉优先摆到取餐区；熟蕉立即转厨房加工。
   - 不要把香蕉堆压、装密封袋，容易加速腐烂。

4. **储存避坑**
   - 放阴凉通风处，避免阳光、暖气、灶台附近。
   - 不要冷藏整串未熟香蕉；已熟可短时冷藏但表皮会变黑，适合尽快加工。
   - 香蕉不要和苹果、梨等释放乙烯的水果混放，会催熟。

5. **菜单联动消耗**
   - 设“熟蕉优先”加工窗口：香蕉奶昔、香蕉粥、香蕉饼、烘焙、水果拼盘。
   - 每天上午检查一次成熟度，把次日可能过熟的香蕉提前转给厨房，不要等全黑了再处理。

6. **建立简单台账**
   - 记录：到货日期、数量、成熟度、每日消耗、报损。
   - 连续记录2–4周后，就能看出“周几用量大、一次该进多少”，再调整采购量。

7. **供应商约定**
   - 要求分批送货，比如每周送2–3次而不是一次送一周。
   - 合同中约定到货成熟度标准和过熟拒收比例。

最有效的组合是：**少量多次采购 + 到货分级 + 熟蕉当天转加工 + 台账校准用量**。如果只能做一件事，先做“按1–2天用量下单、熟蕉当天转厨房”。
