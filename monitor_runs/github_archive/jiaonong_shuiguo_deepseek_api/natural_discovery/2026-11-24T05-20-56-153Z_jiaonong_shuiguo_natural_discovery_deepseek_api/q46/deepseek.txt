优先选**鲜果（整菠萝/去皮鲜切菠萝）**，其次才看果丁、果泥。判断顺序可以这样执行：

1. **如果你要突出“新鲜果茶”卖点、门店有切配能力**  
   **买鲜果最合适**。  
   - 优点：香气和口感最好，能做装饰片、果肉块，顾客感知强。  
   - 缺点：要自己削皮、去眼、切配，损耗和人工高；成熟度不稳定。  
   - 适合：菠萝果茶、带果肉的产品、门店有备料间或员工能稳定切配。

2. **如果门店忙、切配不稳定，但产品仍要果肉感**  
   **选果丁**。  
   - 适合做杯底果肉、摇茶、果肉果茶。  
   - 重点看：是**鲜切果丁**还是**糖渍/冷冻果丁**。  
     - 鲜切果丁：接近鲜果，但保质期短、配送频次要求高。  
     - 冷冻果丁：稳定性好、损耗低，但香气和鲜感弱一些。  
     - 糖渍果丁：甜度高，适合甜品化果茶，不适合主打“清爽鲜果”。

3. **如果你要做标准化、出杯快、口味稳定，且不需要明显果肉**  
   **选果泥**。  
   - 适合：菠萝冰茶、菠萝气泡、复合果茶、连锁标准化出品。  
   - 优点：甜酸稳定、出杯快、损耗低。  
   - 缺点：鲜果香气和咀嚼感弱，容易“像饮料不像果茶”；要看清是**原浆/果泥**还是**果酱/糖浆**，后两者糖分高、果含量低。

**建议的实际采购组合：**  
- 主打鲜果茶：**鲜果为主 + 少量果泥调稳定酸甜**。  
- 外卖多、人工紧：**冷冻果丁或果泥为主**，鲜果只做装饰。  
- 先小批量测试：同一配方分别用鲜果、果丁、果泥做盲测，比较香气、酸甜、果肉感、出杯速度、损耗成本，再定主采购。

**避坑判断：**  
- 看配料表：果泥/果丁排第一位应是菠萝，而不是水、糖浆。  
- 问清“果肉含量、糖度、是否含防腐剂、冷冻还是常温”。  
- 不要只比单价，要算**每杯可出品的净成本**，鲜果要算削皮去眼损耗和人工。
