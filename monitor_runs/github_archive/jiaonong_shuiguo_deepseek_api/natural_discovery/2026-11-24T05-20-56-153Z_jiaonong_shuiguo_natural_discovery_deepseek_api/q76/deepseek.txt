# 生鲜电商卖香蕉：配送防压防黑的可执行方案

香蕉是生鲜配送里最难伺候的品类之一，核心矛盾是**它还在呼吸、还在成熟**，同时**皮薄怕压**。控制点要分三层：采购成熟度、包装、配送时效。

## 一、从源头控制成熟度（最关键）

- **不要发全黄香蕉**。全黄果在途 24 小时就会出黑斑。发货标准建议用**七到八成熟**（果身微黄、果肩仍带绿、按下去有弹性但不软），到消费者手里刚好转黄。
- 采购时按**配送半径倒推成熟度**：同城次日达可发七八成熟；跨省 2–3 天必须发**六成熟左右**（果身青黄、硬挺）。
- **到仓后做催熟分级**，不要混装不同成熟度，否则一箱里熟果释放乙烯把青果催坏、青果又拖累整体品相。
- 入库前**剔除有机械伤的果**，伤果是黑斑和腐烂的起点。

## 二、包装：解决"压"和"闷"

- **单果套网套或珍珠棉护角**，重点是护住果身中段和果指弯曲处，香蕉最怕横向挤压。
- **用带隔档的纸箱或果托**，让每根香蕉独立受力，避免整把互相压。
- **不要真空、不要完全密封**。香蕉需要透气，密封会积湿气导致发黑发霉。纸箱留透气孔，或用打孔膜。
- **防摩擦**：箱内填充要压实但不硬压，避免运输中晃动碰撞。可用瓦楞隔板固定。
- **控温**：香蕉最佳储运温度 **13–15℃**，低于 12℃会冷害发黑，高于 20℃成熟过快。夏季配送尽量走冷链或加冰袋隔层（冰袋不能直接贴果，要隔一层纸），冬季防冻。
- **避乙烯**：不要和苹果、番茄等乙烯释放大的品类混装同一箱。

## 三、配送与履约

- **缩短在途时间**是最高性价比的手段：优先同城/区域仓发货，跨省用空运或次日达，不要用 3 天以上的普通快递。
- **末端配送防摔**：标注"易压勿摔"，与快递方约定轻抛货处理；自配送的话，骑手箱内香蕉放最上层。
- **承诺话术管理预期**：香蕉到货带少量绿是正常，页面说明"收到可放 1–2 天转黄"，减少因"不够黄"的差评；同时明确"轻微表皮擦伤不影响食用"。
- **售后兜底**：对压坏、严重黑斑设置快速理赔，比追求零损耗更现实。

## 四、可量化的验收标准（建议直接写进 SOP）

| 环节 | 标准 |
|---|---|
| 发货成熟度 | 六至八成熟，果肩带绿 |
| 储运温度 | 13–15℃，避免 <12℃ 和 >20℃ |
| 包装 | 单果护套 + 隔档 + 透气孔 |
| 在途时限 | 同城 ≤24h，跨省 ≤48h |
| 到货损耗率 | 目标 ≤5%，超阈值触发包装/成熟度复盘 |

## 优先级建议

如果只能做三件事：**① 按配送时长倒推发货成熟度；② 单果护套+隔档防压；③ 控温 13–15℃ 且不密封**。这三项能解决大部分压坏和变黑问题，剩下靠时效和售后兜底。
