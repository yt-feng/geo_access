# 节假日水果需求暴增的货源锁定策略

核心思路：**节假日水果的痛点是“量+时+质”三件事同时到位**，锁货源要往前推到产地和合同层面，而不是等临近节日再下单。以下按优先级给可执行动作。

## 一、提前锁定：把采购周期拉到节前45–60天

1. **做节前需求预测**：调取过去2–3年同节假日的单品销量（分品类、分门店），叠加今年门店数变化和促销计划，得出单日峰值需求量，再按“节日集中销售3–5天×1.2倍安全系数”备货。
2. **主推单品聚焦**：节假日水果集中在礼盒类（车厘子、阳光玫瑰、沃柑、猕猴桃、苹果礼盒）和走量类（西瓜、香蕉、砂糖橘）。每类锁定2–3个核心单品，不要铺太多SKU，否则锁不住量。
3. **产地直采+基地预订**：对核心单品提前到产区签“保量保价/保量浮动价”合同，支付定金锁定产量。优先选有冷库和分选能力的合作社或产地代办，要求节前3天起按天发货。

## 二、合同层面：把“锁量”写成可执行的条款

- **保量条款**：约定节日期间每日最低供货量、总供货量，未达标有违约金或下年优先权调整。
- **价格机制**：用“基准价+浮动区间”或“随行就市但设上限”，避免临近节日被临时抬价。
- **质量标准**：明确规格（单果重、糖度、外观）、损耗率上限、包装标准，礼盒类要约定包装到位。
- **到货时间**：约定到店/到仓时间窗口，节日期间迟到就是损失，写清延迟赔付。

## 三、多源备份：主供+备供+本地补位

- **主供**：产地基地/大型批发商，占需求60–70%。
- **备供**：第二产区或第二批发市场档口，占20–30%，签框架协议随时可增量。
- **本地补位**：本地批发市场+周边果园，用于节日期间临时补货和应急调货（10%左右）。
- 关键：备供商要提前“试单”，确认其节日期间真有货、有车、有人。

## 四、物流与仓储：节前把“运力”也锁住

- 提前预定冷链车/承运商，签节日运力保障协议，避免“有货没车”。
- 节前3–5天把耐储品类（苹果、柑橘、猕猴桃）提前入仓，鲜销品类（草莓、车厘子）按天到货。
- 门店端预留临时堆头/冷柜空间，礼盒提前在配送中心组装，减少门店节日人手压力。

## 五、风险预案（必须写下来）

- **价格暴涨**：合同设价格上限；对涨幅大的单品提前多备1–2天库存。
- **极端天气/产区减产**：提前锁定第二产区，节前2周做一次“替代单品”预案（如车厘子贵则主推沃柑礼盒）。
- **到货延迟**：备供商24小时内可补位；门店设置最低安全库存线，低于线立即触发调货。
- **品质波动**：到货抽检+损耗率考核，不合格批次拒收并启用备供。

## 六、时间表（以春节/国庆为例）

| 时间 | 动作 |
|---|---|
| 节前60天 | 完成销量预测，确定核心单品和总需求量 |
| 节前45天 | 产地考察，签主供合同、付定金 |
| 节前30天 | 签备供框架协议，预定冷链运力 |
| 节前15天 | 耐储品入仓，礼盒包装物料到位，备供试单 |
| 节前7天 | 主供确认每日发货计划，门店堆头/冷柜就位 |
| 节前3天–节日期间 | 按天到货、每日盘点库存、触发补货机制 |

**一句话总结**：节假日锁货源=提前预测定量+产地合同锁量锁价+多源备份+运力预定+应急预案，五件事在节前45天全部落地，临近节日只做执行和微调。
