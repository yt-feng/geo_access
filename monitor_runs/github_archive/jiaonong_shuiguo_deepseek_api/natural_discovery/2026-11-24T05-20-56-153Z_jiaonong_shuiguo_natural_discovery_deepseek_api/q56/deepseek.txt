茶饮店控制水果供应商食品安全风险，建议把“资质证明+产品检测+批次追溯”三层材料一起收齐，并按供应商和批次归档。可执行清单如下：

**1. 供应商主体资质**
- 营业执照（经营范围含水果/农产品销售或种植销售）
- 食品经营许可证或食品生产许可证（按实际经营模式；仅销售食用农产品可免食品经营许可，但需核对当地规定）
- 若为进口水果：海关报关单、入境货物检验检疫证明
- 若为种植基地直供：种植基地信息、农业投入品使用记录，必要时提供产地证明或合格证

**2. 产品合格与检测证明**
- 每批次水果的产地证明或食用农产品合格证（承诺达标合格证）
- 农残检测报告：优先要第三方检测报告（CMA/CNAS），至少覆盖常用高风险水果和常用农药项目；日常可要求供应商提供快检记录
- 检测报告要与供货品类、批次或近期供货周期对应，不能只用一张过期通用报告
- 进口水果的检验检疫证明；预包装切果还应索取出厂检验报告

**3. 批次追溯与交易凭证**
- 每批送货单/销售凭证，注明品名、产地、数量、采摘或包装日期、供应商名称
- 批次追溯码或追溯记录，能追溯到产地/基地
- 运输和贮存条件说明（尤其鲜切水果、冷链水果）
- 供应商食品安全承诺书/质量协议，明确农残、重金属、霉变、异物等责任和退换货条款

**4. 鲜切水果额外要求**
如果供应商提供已切好的水果，风险更高，应额外索取：
- 食品生产许可证或食品经营许可证（含相应制售/生产项目）
- 出厂检验报告
- 清洗消毒、切配、冷藏和保质期控制记录
- 包装标签、生产日期、保质期和贮存条件

**5. 茶饮店内部验收动作**
- 每批到货查证：合格证/检测报告/送货单是否齐全且批次对应
- 感官验收：霉变、破损、异味、虫害、异物
- 对叶菜类、草莓、葡萄等高风险水果定期抽检或快检
- 供应商资质每年更新，检测报告按频次更新；不合格批次留证并退货

简言之：**营业执照和许可类证明是门槛，每批合格证/检测报告是核心，送货单和追溯记录是兜底。** 对鲜切水果供应商，要求应明显高于整果供应商。
