判断水果供应商靠不靠谱，别只看第一次报价和样品。长期做香蕉、菠萝，重点盯下面几项，能较快筛掉不靠谱的。

**1. 先看“稳定性”而不是“便宜”**
- 连续问3次报价：同规格香蕉、菠萝的价格波动是否有解释？天气、产地换季、运费上涨可以波动，但每次说法要能对上。
- 问固定货源：香蕉主要来自哪里、菠萝是哪个产区，是否有稳定合作基地或一级批发商。说不清产地的，长期风险大。
- 看能不能稳定供同规格：香蕉的条数/把重/成熟度，菠萝的果径/净重/成熟度，每次是否一致。

**2. 用“小单+连续试”验证**
- 先下3次小单，不要一次压大货。每次记录：到货时间、损耗率、成熟度、大小均匀度、口感。
- 香蕉重点看：青蕉到货成熟度是否适合你店销售节奏，催熟后是否整齐，有没有大量断把、压伤、黑斑。
- 菠萝重点看：果径和净重是否达标，黑心/水心/烂心比例，表皮损伤，酸甜度是否稳定。
- 连续3次都稳定，再谈长期价和账期。

**3. 看损耗和售后态度**
- 直接问：坏果、烂果、压伤怎么算？是补货、扣款还是下次抵扣？多久内反馈有效？
- 靠谱供应商一般敢明确规则；只口头说“放心，有问题找我”但不肯写清楚的，要谨慎。
- 试单时故意如实反馈一次小问题，看对方处理速度。推诿、拖到下次、要求你承担大部分损耗的，不适合长期。

**4. 看履约细节**
- 送货是否准时，临时加单/减单是否配合，旺季缺货是否提前说。
- 装车和包装是否规范：香蕉有没有防压、防寒/防热措施；菠萝是否按成熟度分装。
- 是否有固定联系人，出问题能否当天联系上。长期供货最怕“卖完找不到人”。

**5. 看价格是否透明**
- 让对方报清楚：产地、规格、包装、运费、卸货费、是否含税/开票。
- 长期合作可以谈账期，但新供应商不建议先给长账期。先现结或短账期，稳定后再谈。
- 报价明显低于市场且说不清原因的，通常会在规格、成熟度或损耗上找回来。

**6. 实地或视频看货**
- 有条件去对方档口/仓库看：香蕉催熟房或存储条件、菠萝堆放是否通风、有没有大量积压货。
- 看他对别的客户怎么发货，是否按成熟度分货。只给你看最好样品、发货却混装的，不可靠。

**实操建议：**
先选2家供应商各试3次小单，用同一套标准记录：到货准时率、损耗率、规格合格率、售后响应。3次后选综合最稳的那家做主力，另一家保留小量备用。香蕉和菠萝都怕单一货源，长期合作也建议保留一个备选供应商。

一句话判断：**报价清楚、规格稳定、连续三次小单不掉链子、出问题敢按规则赔的，才值得长期合作。**
