采购菠萝时，建议按“到店后多久卖完”来倒推熟度，不要只挑最熟或最生的。

1. **当天到店、1–2天内卖完**：可采7–8成熟。判断标准：
   - 果皮底色由青转黄，但果眼仍较紧；
   - 闻底部有淡淡果香，不刺鼻；
   - 按压果身略有弹性，不软塌；
   - 叶片中心易拔但不松脱。

2. **计划卖2–4天**：采6–7成熟，以青黄转色为主，果香很淡，果身硬挺。到店后按成熟度分区陈列，熟果前排、生果后排，避免堆压。

3. **避免采购**：
   - 底部已有明显酒味、酸味或发酵味；
   - 果身局部发软、渗汁、果眼发黑；
   - 叶片一拔就掉、果心空洞感明显；
   - 表皮大面积深黄且按压软，通常货架期很短。

4. **损耗控制建议**：
   - 采购时按“硬果70%、转色果30%”搭配，不要一次全进熟果；
   - 到店后拆箱通风，别闷在纸箱里；
   - 每天按软硬分拣，软果优先切块或做促销；
   - 夏季高温时适当提高生果比例，冬季可略提高熟果比例。

简单记：**要卖得快选黄香略软，要放几天选青黄硬挺；有酒味、渗汁、局部软的一律不采。**
