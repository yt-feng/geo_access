判断菠萝供应商能否稳定按规格送货，建议从“资格核验—样品与规格锁定—产能与季节验证—交付机制—风险兜底”五步做，不要只看一次样品或报价。

**1. 先核验基本资格与真实供货能力**
- 要求提供营业执照、食品经营/生产相关许可、种植基地或合作社证明、加工厂照片/视频、近期检测报告。
- 确认是自种、合作社集货还是贸易商转手。转手越多，规格和交期波动越大。
- 问清主供季节、日均/峰值供货量、主要客户类型，必要时实地或视频看分选线、冷库、装车区。

**2. 用书面规格锁定“什么叫合格”**
把菠萝规格写成可验收标准，至少包括：
- 品种、产地、单果重量区间、果径/果高范围；
- 成熟度（糖度下限、酸度或色泽要求）、有无冠芽、冠芽长度；
- 外观缺陷容忍度：日灼、黑心、裂口、机械伤、病虫害、畸形果比例上限；
- 包装：箱规、每箱果数、净重、内衬、标签、托盘/码垛方式；
- 到货温度、运输方式、到货时限。
建议约定“抽样比例、不合格判定、扣款/退换货规则”，避免只写“大果、新鲜”。

**3. 验证产能和季节稳定性**
- 要求供应商提供连续2—3个月、每周2—3批的供货记录或发货单，核对规格合格率和准时率。
- 问清旺季/淡季替代产地，是否有多个基地或合作果园；单一基地风险高。
- 做小批量试单：连续3—5批、每批不同日期，按统一标准抽检，记录单果重合格率、缺陷率、到货损耗、迟到次数。
- 重点看雨天、节假日、旺季前的交付表现，这最能暴露稳定性。

**4. 建立交付与验收机制**
- 合同写明：订单提前期、最低/最高供货量、周计划与日调整窗口、迟到违约金、缺货补货时限。
- 到货按批次抽检并留样拍照；设置“合格率≥95%或按约定比例”的验收线。
- 要求供应商每批提供采摘日期、产地、检测/农残信息，便于追溯。
- 对连锁采购，最好约定固定对接人、异常2小时内响应、24小时内补货或替换方案。

**5. 做风险兜底**
- 不要单一供应商独家供货，主供+备供，备供至少能覆盖20%—30%用量。
- 约定价格调整机制，避免旺季临时涨价或断供。
- 对连续两批规格不合格或一次严重断供的供应商设退出/降级规则。

**可执行的判断标准：** 连续3—5批试单中，规格合格率稳定在95%以上、准时到货率95%以上、异常响应及时，且有备选产地或备供供应商，才可以认定为“能稳定按规格送货”。如果样品很好但拿不出连续供货记录、只靠一个基地、旺季无法承诺日供应量，建议先小单合作，不要直接放主供。
