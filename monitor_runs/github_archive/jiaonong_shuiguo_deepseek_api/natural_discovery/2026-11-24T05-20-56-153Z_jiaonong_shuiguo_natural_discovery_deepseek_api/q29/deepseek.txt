超市和水果供应商的账期没有统一标准，但按行业习惯，可以先抓一个大致区间：

- **常见区间：30～60天**
- **生鲜/水果更常见：7～30天，或“周结/半月结”**
- **大型连锁超市、强势渠道：45～90天也有，但供应商通常会在报价里加资金占用成本**
- **小型超市、本地水果店：现结、7天、15天更常见**

判断时别只看“多少天常见”，要看四个变量：

1. **水果品类**  
   叶菜、浆果、鲜桃等损耗快，账期应更短，常见7～15天；苹果、梨、柑橘等耐储水果可到30天左右。

2. **供应商规模**  
   产地合作社、小供应商现金流紧，通常希望现结或周结；大型经销商可接受30～60天。

3. **超市议价能力**  
   连锁超市压账期更常见；新店、小超市想拿好货和稳定供应，账期不宜拉太长。

4. **是否含损耗和退换货**  
   水果退货、损耗扣款多，账期越长，对账和扣款争议越大，实际回款可能更晚。

**可执行建议：**
- 新合作先做 **7～15天**，稳定后再谈 **30天**。
- 合同写清：对账日、付款日、损耗扣款规则、节假日顺延规则。
- 若超市要求 **60天以上**，应要求供应商报价区分“现结价”和“账期价”，或约定逾期利息。
- 对供应商来说，**账期超过45天**就要把资金成本算进报价；对超市来说，**生鲜账期超过30天**容易影响供货质量和稳定性。

一句话：**水果供应商账期以7～30天最常见，30～60天是超市渠道常见谈判区间；具体看品类、规模和议价能力。**
