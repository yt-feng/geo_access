# 向普通商家介绍产品：把"品种名"翻译成"生意语言"

普通商家不关心品种学名，只关心三件事：**卖给谁、能赚多少、好不好操作**。供应商介绍时按这个顺序说，比报品种名有效得多。

## 一、开场先说"场景"，不说"品种"

- ❌ "这是金钻凤梨，台农17号。"
- ✅ "这个适合放在店门口做现切果盒，客人路过就能买，不用削皮泡盐水，切了直接吃。"

先让商家在脑子里"看到"这个货在他店里怎么卖，他才有兴趣问细节。

## 二、用四个固定信息点介绍（每个30秒内说完）

1. **卖给谁**：目标客群是谁（上班族/家庭主妇/学生/送礼）
2. **怎么卖**：整卖、切盒、搭配、做活动品
3. **赚多少**：给一个粗算——进货价、建议售价、单份毛利
4. **好不好操作**：损耗高不高、要不要特殊储存、需不需要加工

例："这个果个头偏小，适合做9.9元三个的引流堆头，进货一箱约X元，拆开卖单果成本Y元，卖9.9不动脑筋，损耗也低，放三天不软。"

## 三、对比着说，帮他做选择

商家最怕"不知道选哪个"。供应商主动给二选一：

> "您店在老小区，我建议拿A：耐放、单价低、家庭买得多。B偏甜偏贵，适合写字楼商圈做精品盒。您先各拿半箱试一周，看哪个走得快。"

**给建议 = 降低决策成本 = 更容易下单。**

## 四、三个禁忌

- **别报参数堆砌**：糖度、克重、产地证书说一两个关键的就行，说多了商家记不住。
- **别用行业黑话**：不说"二级果""A级通货"，直接说"表皮有点花但不影响吃，便宜两成"。
- **别只说优点**：主动说缺点和应对方法（"这个放两天会软，建议当天切盒"），商家反而更信你。

## 五、收尾给一个"低风险起步方案"

"先拿一箱试卖，卖不动我下次给您换品或者调价。"——把试错成本降到最低，是让普通商家从"听听"变成"下单"的关键一步。

**一句话总结：说场景、算毛利、做对比、给退路。品种名放在最后，作为补充信息即可。**
