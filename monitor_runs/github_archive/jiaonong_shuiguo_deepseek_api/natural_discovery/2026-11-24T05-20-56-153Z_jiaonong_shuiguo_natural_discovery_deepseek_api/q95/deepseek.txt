选食堂水果供应商，核心不是“找最便宜的”，而是**稳定性、可追溯、结算合规、损耗可控**四项同时过关。建议按下面步骤做。

## 1. 先定采购标准，再谈供应商
先把需求写成可验收的清单，供应商才有得比：

- **品类与规格**：香蕉按每根/每箱重量和成熟度；苹果按单果直径、品种、产地；橙子按单果大小、糖酸比、表皮完整度。
- **验收标准**：腐烂率、碰伤率、大小均匀度、成熟度（香蕉尤其要控催熟和到货成熟度）、农残检测报告要求。
- **配送要求**：到货时间、频次、最小起订量、临时加单响应时间、冷链或常温运输条件。
- **结算与票据**：能否开票、账期、对账方式、价格调整机制。
- **食品安全责任**：不合格品退换、食安事故责任、检测报告随货或定期提供。

## 2. 供应商来源优先顺序
食堂场景建议优先这几类，而不是只找个体水果摊：

1. **本地农产品批发市场里有固定档口、能开票的商户**：响应快、价格透明，适合日常配送。
2. **水果产地合作社或一级批发商**：苹果、橙子这类耐储水果可谈产地直供，价格和稳定性更好。
3. **有食堂/学校配送经验的生鲜配送公司**：服务和票据规范，但价格通常略高。
4. **大型商超或电商企业购渠道**：适合应急和少量补充，不建议作为主供。

香蕉建议单独找有催熟和配送能力的供应商，因为成熟度控制不好，食堂损耗会很高。

## 3. 必须做的资质与现场核验
- 营业执照、食品经营许可证或相关经营资质。
- 进货凭证、产地证明、农残检测报告；能提供批次追溯的优先。
- 仓储和分拣现场：看是否分区存放、是否有腐烂果混放、是否按食堂要求分拣。
- 配送车辆和人员：是否固定、是否清洁、能否按约定时间到货。
- 问清**不合格品处理**：是现场退换还是下次补，是否影响结算。

## 4. 用“试供+打分”而不是一次定终身
建议先选 2—3 家试供 2—4 周，按同一标准打分：

| 维度 | 看什么 |
|---|---|
| 质量稳定 | 到货合格率、腐烂率、大小一致性 |
| 配送稳定 | 准时率、临时加单响应 |
| 价格 | 同规格比价，不只看单价，看净重和损耗 |
| 票据合规 | 发票、对账单、检测报告是否及时 |
| 售后 | 退换是否爽快、问题处理速度 |

试供期重点记录**到货合格率和实际可用率**。水果采购的真实成本 = 采购价 ÷ 可用率，损耗高的低价供应商往往更贵。

## 5. 合同和日常管理要点
- 合同写清：规格、验收标准、价格调整规则、退换货、食安责任、违约处理。
- 价格别锁死：约定随行就市，但要有比价机制，比如每周参考本地批发市场价。
- 验收双人签字，拍照留档，不合格当场记录。
- 香蕉、苹果、橙子可分品类定供应商，不必一家通吃。
- 避免长期单一供应商，保留 1 家备用供应商。

## 6. 简单可执行的建议
如果现在就要启动：先整理一份**品类规格和验收标准表**，然后从本地批发市场固定档口、学校配送经验的生鲜公司、产地合作社各找 1—2 家，要求报价并试供两周。试供期间只按“到货合格率、准时率、票据合规、售后响应”四项打分，淘汰明显不合格的，保留 2 家主供+备供。

这样选出来的供应商，通常比单纯比价更稳，也更容易通过学校食品安全和审计要求。
