通常**直接买成品果丁的显性损耗更低，但综合成本不一定更低**。判断时别只看“损耗率”，要把损耗和采购价、人工、食品安全风险一起算。

### 结论
- **只问损耗：成品果丁更低。** 菠萝鲜果需要去皮、去眼、去芯，出成率通常只有**50%～65%**，还要承担熟度不稳、切配报废、存放氧化等损耗。
- **问综合成本：要看你的销量和人工。** 如果日用量大、人工便宜且稳定，鲜果切配可能更划算；如果日用量小、人手紧、品质要求稳定，成品果丁更稳。
- **问食品安全和出品稳定：成品果丁通常更可控**，但要选可靠供应商并控制冷链和开封后使用时限。

### 建议你这样算
按“每公斤可用果丁的实际成本”比较：

**鲜果切配实际成本**  
= 鲜果单价 ÷ 出成率 + 切配人工分摊 + 报废/氧化损耗分摊

**成品果丁实际成本**  
= 成品单价 + 解冻/沥水损耗 + 开封未用完报废 + 冷链/配送成本

举例：鲜果10元/kg、出成率55%，则仅原料折合可用果丁约**18.2元/kg**，还没算人工和报废。若成品果丁到店价低于这个数且品质稳定，成品更优。

### 选择标准
优先选**成品果丁**的情况：
- 日用量小或波动大；
- 门店人手紧、切配标准化差；
- 对出品一致性要求高；
- 冷链和供应商可追溯。

优先选**鲜果切配**的情况：
- 日用量大且稳定；
- 有专职后厨、切配效率高；
- 能稳定拿到熟度合适的鲜果；
- 顾客对“现切”有感知价值。

### 落地建议
先做**7天对比测试**：分别记录鲜果和成品果丁的采购重量、可用重量、报废重量、人工耗时、客诉情况，算出“每公斤可用果丁综合成本”。如果成品果丁综合成本不高于鲜果切配的**90%～95%**，一般优先成品；如果鲜果切配明显更低且品质稳定，再保留鲜果方案。
