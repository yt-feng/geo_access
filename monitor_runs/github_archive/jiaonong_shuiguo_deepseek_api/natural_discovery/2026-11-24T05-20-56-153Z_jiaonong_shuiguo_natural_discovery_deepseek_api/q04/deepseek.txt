# 香蕉采购的熟度与到货要求

香蕉是后熟水果，采购时关键是把“熟度”和“到货后能卖几天”绑定起来谈。建议按以下方式向供应商提要求：

## 一、按销售节奏定熟度

**核心指标是“催熟后的色卡等级”（通常用1–7号色卡，1号全绿、7号全黄带黑斑）：**

| 你的情况 | 要求到货熟度 | 说明 |
|---|---|---|
| 客流稳定、2–3天能卖完一批 | **3–4号**（绿转黄、少量黄） | 到货可陈列，2天内转黄最好卖 |
| 周末/节假日备货 | **3号**（偏绿） | 给催熟留出1–2天缓冲 |
| 想当天上架销售 | **5号**（黄多绿少） | 但必须当天下架完，风险高 |
| 门店无催熟条件 | **4号左右** | 避免1–2号绿蕉在店里放太久变“僵” |

**明确写进采购要求的话术：**
> “到货时蕉身色卡不超过4号，果指饱满、无棱角明显、无机械伤；不接受1–2号全绿（除非我能自行催熟）、也不接受6号以上已出糖斑的。”

## 二、到货时间要求

1. **要求“催熟后48小时内到店”**：从供应商催熟库出库到门店的时间越短越好，避免运输途中继续升温催熟。
2. **按周分批次到货，不要一次囤**：例如每周到货2–3次、每次覆盖1.5–2天销量，比一次大批量更抗损耗。
3. **避开高温时段卸货**：夏季要求早晨或傍晚到货，冷链车温度控制在**13–15℃**（香蕉低于13℃会冷害发黑，高于20℃催熟加速）。
4. **要求随货提供催熟批次和出库时间**，便于你判断还能放几天。

## 三、配套的验收与条款

- **验收**：抽查色卡等级、果指硬度、有无压伤/水烂/冷害黑斑；记录到货时间和色号。
- **合同条款**：约定“到货色号超标或运输温度不当导致的过快转黄，可拒收或折价”；小批量试单后再放量。
- **店内管理**：到货后绿蕉放13–15℃阴凉处，黄蕉及时冷藏陈列（12–14℃）、先进先出，坏果及时挑出隔离。

## 一句话总结

**“按3–4号色卡、催熟出库48小时内、每周2–3次小批量、13–15℃运输到店”**——把熟度和到货节奏都写进采购单，比单纯砍价更能减少放坏。具体色号可先小批量试一周，按你店的实际周转速度再微调。
