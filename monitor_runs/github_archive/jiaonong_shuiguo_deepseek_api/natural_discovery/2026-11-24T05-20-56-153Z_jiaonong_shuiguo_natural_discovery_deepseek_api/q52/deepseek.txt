采购时优先选**七成熟、表皮整体黄色但两端略带一点青、无磕碰**的香蕉；不要选已经出现少量黑斑的“熟香蕉”，那种到店后黑得更快。  
到店后按下面做，能明显延缓变黑：

1. **先别急着拆把**
   - 整把香蕉连根部一起存放，减少伤口和乙烯释放。
   - 有断裂、碰伤的先挑出来优先用掉，避免传染其他香蕉。

2. **包住根部**
   - 香蕉变黑主要受乙烯影响，根部释放最多。用保鲜膜包住整把香蕉的根部，能延缓成熟。

3. **常温阴凉通风存放，不要冷藏未熟香蕉**
   - 未完全成熟的香蕉放冰箱会表皮发黑、口感变差。
   - 放在阴凉、通风、避免阳光直射的地方，远离烤箱、热饮机、成熟水果。

4. **悬挂或单层平放，避免挤压**
   - 不要堆压，压伤处会先黑。
   - 有挂钩就悬挂，减少接触面。

5. **分开成熟度存放**
   - 偏青的放一起，偏黄的放一起。
   - 已经较黄的放冷藏或优先做甜品、奶昔、香蕉面包。

6. **到店当天做一次分拣**
   - 青的：常温存放。
   - 黄的：优先排进当日/次日出品。
   - 有伤的：立即去皮冷冻，做果泥或奶昔，别等它变黑。

7. **需要延长到2—3天时**
   - 表皮已全黄但没黑斑的，可以放冰箱冷藏；表皮会变深，但果肉能延缓软烂，适合甜品加工。
   - 去皮后加少量柠檬汁冷冻，适合做香蕉泥。

采购量上建议：**按2—3天用量分批采购**，不要一次囤太多；甜品店如果用量稳定，可以和供应商约定“黄中带青、无黑斑、硬一点”的货，比单纯挑黄香蕉更耐放。
