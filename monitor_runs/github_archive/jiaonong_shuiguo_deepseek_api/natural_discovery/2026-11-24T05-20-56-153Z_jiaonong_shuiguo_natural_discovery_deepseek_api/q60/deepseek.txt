核心是把“补货”写成可执行的交付义务，而不是只写“及时补货”。建议在采购合同或每次订货单里约定以下几项：

1. **验收标准和时限**
   - 到货后当场验收，写明不合格情形：腐烂、压伤、成熟度不符、规格不符、农残检测不合格、温度/冷链不符等。
   - 验收不合格的，当场拍照、录像并让送货人签字确认；拒收或隔离存放，避免混入原料区。

2. **补货触发和时限**
   - 明确“验收不合格即触发补货”，不依赖供应商口头承诺。
   - 约定补货到店时限，例如：当日上午验收不合格的，当日营业高峰前补到；下午验收不合格的，次日上午开店前补到。具体按你的营业时段写。
   - 写明补货必须送到门店指定收货点，不能只写“尽快发出”。

3. **替代方案，避免断货影响营业**
   - 约定供应商无法按时补货时，你有权自行采购同等规格水果，差价和合理运费由供应商承担，或从货款中直接扣减。
   - 也可约定供应商提供同品质替代品，但需经你方书面/微信确认，不能单方替换。

4. **补货数量和质量**
   - 补货数量应覆盖不合格数量，并考虑损耗；写明补货水果须符合原订单规格、成熟度和食品安全标准。
   - 因补货不合格再次拒收的，供应商应承担二次补货责任，并约定违约金或扣款。

5. **责任和扣款**
   - 写明因不合格水果导致营业中断、客诉、废弃处理等损失由供应商承担，但金额可设合理上限，便于实际执行。
   - 约定不合格批次货款可暂扣，补货验收合格后再结算。

6. **证据和沟通留痕**
   - 合同里约定微信、邮件、订货单均可作为通知方式，但补货要求要留文字记录。
   - 每次验收单写明批次、数量、不合格原因、补货时限和签字。

实操上，最关键是两条：**不合格当场拒收并留证；补货不到时你有权自行采购、差价由供应商承担。** 这样既不影响营业，也避免只靠口头催货。
