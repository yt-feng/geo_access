做水果礼盒，先明确一条原则：**礼盒卖的是“体面、好拎、不易坏、看起来满”，不是水果越多越好。** 苹果、橙子、香蕉、菠萝这四种里，香蕉和菠萝最拖后腿，搭配时要做“少量点缀”，主结构用苹果和橙子。

## 建议主推3个价位

**1）走量款：88～108元**
- 苹果6个 + 橙子6个 + 香蕉1小把 + 菠萝1个（小果）
- 定位：员工福利、邻里送礼、探病随手礼
- 卖点：颜色齐、分量足、价格不吓人
- 注意：香蕉用5～6根的小把，别放整串；菠萝选小果，否则盒子显挤

**2）主推款：138～168元（最好卖）**
- 苹果8个 + 橙子8个 + 香蕉1小把 + 菠萝1个（中果）
- 或苹果6 + 橙子6 + 菠萝1 + 香蕉少量 + 加2个猕猴桃/火龙果做色彩提升（如果允许扩品）
- 定位：送客户、送长辈、节日礼
- 卖点：苹果橙子耐放、寓意好（平安、橙心如意），香蕉菠萝负责“热带感”和视觉冲击
- 这个价位最容易成交，礼盒要显得满，空隙用拉菲草/纸丝填

**3）高端款：198～258元**
- 苹果选大果/精品果8个 + 橙子选精品8个 + 菠萝1个 + 香蕉只做点缀3～4根
- 重点不在数量，在果径、贴标、包装和卡片
- 加一张手写贺卡/祝福卡，企业团购很吃这套

## 搭配上的关键判断

- **苹果是主心骨**：耐放、寓意好、撑盒子，占比可以到40%。
- **橙子是第二主力**：颜色亮、耐放、成本可控，占比30%左右。
- **香蕉只做点缀**：容易压伤、变黑，放多了礼盒第二天就难看。用小把香蕉，且放在上层或侧边。
- **菠萝最多1个**：带冠芽好看但占空间，刺手，建议选小果，冠芽朝上做视觉中心，底部垫纸防扎。
- **别四种等量**：等量搭配像批发箱，不像礼盒。比例建议苹果4：橙子3：香蕉1：菠萝1（按视觉占比）。

## 好卖的细节

1. **盒型选手提式硬盒**，透明开窗或半开窗，顾客一眼看到颜色搭配。
2. **固定水果**：用雪梨纸单个包苹果橙子，防摩擦；香蕉用气泡膜垫底。
3. **做两个SKU就够**：一个走量款、一个主推款，别一开始铺太多，压货。
4. **节日换卡不换果**：春节加“平安大吉”，中秋加“橙心如意”，企业单加LOGO贴纸。
5. **现装现卖**：香蕉菠萝不耐放，礼盒最好接单后装，或每天少量出样。
6. **标价签写清楚**：果品数量、净重、建议食用顺序（先吃香蕉菠萝，苹果橙子耐放）。

## 避坑

- 香蕉和菠萝不要贴着苹果放太久，香蕉释放乙烯会加速其他水果成熟；短期礼盒问题不大，但别提前几天装好。
- 菠萝冠芽容易戳破包装，底部和侧面要加护角。
- 走量款别用太大盒子，空隙多显空，顾客觉得不值。

**一句话结论：主推“苹果+橙子撑量，香蕉小把点缀，菠萝一个提视觉”，定价138～168元的主推款最好卖；走量款压到百元内，高端款靠果径和包装提价。**
