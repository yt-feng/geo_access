判断哪个规格更容易出货，不要只看“哪个便宜”或“哪个好卖”的主观感觉，建议用下面这套可执行方法，先用一周到两周数据做小闭环。

**1. 先统一定义“规格”和“出货”**
- 规格按可执行口径分：单果重量段（如800–1000g、1000–1200g、1200g以上）、果径、成熟度、箱规（每箱个数/净重）、等级（外观、糖度、黑心风险）。
- “容易出货”至少看三个指标：**日均出货箱数、出货天数占比、动销天数**（进一车货几天卖完）。不要只看出货量，压货多的规格也可能量大。

**2. 用最近7–14天做规格动销表**
每个规格记录：
- 到货量、累计出货量、剩余库存；
- 日均出货箱数；
- 首次出货时间、清完时间/当前库存天数；
- 退货/损耗箱数；
- 成交均价、议价次数；
- 主要客户类型（二批、水果店、商超、团购、路边摊）。

判断规则可直接用：
- **动销天数 ≤ 2天**：强势规格，优先保供；
- **2–4天**：正常规格，按订单备货；
- **>4天或出货天数占比低**：弱规格，减少进货或改箱规/分级；
- 同时看**损耗率**，损耗高的规格哪怕出货快，也未必赚钱。

**3. 看客户结构，而不是只看总出货**
- 二批/小贩偏好：价格敏感、单果中等、箱规灵活，出货快但压价多；
- 水果店/商超偏好：外观整齐、重量稳定、箱规标准，退货要求高；
- 团购/电商偏好：小果或中果、标准化程度高；
- 加工/餐饮偏好：大果或次果，价格低但量大。
把规格和客户类型交叉统计，能看出“哪个规格被哪类客户接走”。如果某规格只靠一两个客户，不算稳定出货。

**4. 做小规模对比测试**
同一时间段内，选2–3个规格各进少量货，保持相同陈列和报价策略，观察：
- 24小时、48小时出货比例；
- 客户询价后成交率；
- 是否出现退货、挑果、扣称争议。
测试时不要同时改价格和箱规，否则无法判断原因。

**5. 关注季节和到货质量**
菠萝规格偏好会随季节、产地、成熟度变化。再容易出货的规格，如果到货成熟度过高、黑心多、果面差，也会变成滞销规格。建议把**损耗率**和**出货速度**放在同一张表里看，优先保留“动销快且损耗低”的规格。

**6. 最简判断口径**
你可以直接给每个规格打分：
- 日均出货箱数排名；
- 动销天数排名；
- 损耗率排名；
- 客户复购/重复询价次数。
综合排名靠前、且不依赖单一客户的规格，就是更容易出货的规格。若两个规格出货量接近，选**动销天数更短、损耗更低、箱规更灵活**的那个。
