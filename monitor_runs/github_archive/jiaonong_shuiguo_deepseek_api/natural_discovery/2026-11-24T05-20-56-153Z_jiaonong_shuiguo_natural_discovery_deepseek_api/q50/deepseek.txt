结论先说：**如果只能二选一，甜度优先；但真正决定成本和稳定性的，是“甜度达标前提下的出汁率”。**

可按用途判断：

1. **鲜果茶、菠萝果肉款**
   - **甜度更重要**。菠萝本身酸涩、批次波动大，甜度不够会直接破坏杯型风味，需要额外加糖浆或混合果汁，反而增加成本和操作复杂度。
   - 但果肉要看出肉率、纤维粗细、黑心/水心病比例，不能只看甜度。

2. **菠萝汁、打碎做基底、果酱/糖浆复配**
   - **出汁率更重要**。出汁率直接决定每公斤原料能出多少杯，影响毛利。
   - 但前提是甜度达到你的配方基线，否则靠加糖补，成本会吃掉出汁率优势。

3. **门店实际采购建议**
   - 先定一个**最低甜度标准**（例如糖度达到多少，按你所在批次实测）。
   - 再在达标原料里选**出汁率高、损耗低、稳定性好**的。
   - 同时锁定：品种、产地、成熟度、单果规格、到货成熟度、坏果率。
   - 不要只比较“甜不甜”或“汁多不多”，要算**每杯可用果肉/果汁的净成本**：到货价 ÷ 可用部分出成率。

一句话：**甜度是门槛，出汁率是利润；先过甜度门槛，再选出汁率高的。** 如果做果肉型鲜果茶，甜度权重更高；如果做果汁基底，出汁率权重更高。
