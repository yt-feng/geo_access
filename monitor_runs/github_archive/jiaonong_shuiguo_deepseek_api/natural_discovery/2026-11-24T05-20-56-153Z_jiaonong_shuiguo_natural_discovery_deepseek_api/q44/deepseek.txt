判断供应商售后响应是否稳定，不要只听口头承诺，建议用“事前问清规则、事中做小单测试、事后留证据”三步验证。

1. **事前把售后规则问成可执行条款**
   - 明确什么情况可退换：烂果率、成熟度不达标、重量短缺、到货温度/品相异常等，分别怎么赔。
   - 明确响应时限：报损后多久回复、多久给处理方案、多久补货或退款。
   - 明确责任边界：运输损耗谁承担、签收后几小时内可报损、是否需要拍照/视频/留样。
   - 要求写进合同或订单确认单，不接受“到时候再说”。

2. **用小单和异常单做测试**
   - 首单不要给大单，先做2—3次小批量，故意覆盖不同到货时段。
   - 到货后按约定流程报一次小异常，例如少量压伤、成熟度不均，观察对方是否在承诺时限内响应、是否推诿、是否给书面方案。
   - 记录每次响应时间、处理结果、是否按约补货/赔付。连续2—3次都能稳定处理，才算初步可信。

3. **看对方有没有售后承载能力**
   - 问清售后由谁负责：业务员、客服还是专人；是否只在工作时间响应，节假日和早市到货谁处理。
   - 菠萝和香蕉都是易腐、成熟度敏感的品，重点问清催熟/未熟、黑心、机械伤、批量软腐的判定标准。
   - 要求提供近期同类商超客户的售后处理记录或案例，但注意核验，不要只看对方自述。

4. **保留证据并设退出机制**
   - 每次到货拍照、称重、留样，报损走文字渠道，避免只打电话。
   - 合同里约定连续响应超时或赔付不到位的处理办法，例如扣款、暂停下单、终止合作。
   - 先给较小采购份额，稳定后再放量，避免被单一供应商卡住。

一句话：**稳定售后不是听出来的，是用小单异常测试出来的；关键看承诺是否写清、响应是否按时、赔付是否兑现。**
