社区超市找“每天配送”的水果供应商，核心不是只看价格，而是看**日配稳定性、损耗控制、退换机制和结算风险**。建议按下面条件逐项筛：

1. **日配能力和线路覆盖**
   - 是否固定每天送，几点前到店，能否按你营业时间避开高峰。
   - 配送车辆、冷库/冷链条件，夏天和雨天是否照常。
   - 你所在区域是否在固定线路内；临时加单、改单截止时间。
   - 最好要求看近7天同线路配送记录，而不是只听口头承诺。

2. **货源稳定与品类结构**
   - 常供品类是否覆盖你店销量前20的水果，而不是只供少量爆品。
   - 产地/批发市场来源是否稳定，缺货时有无替代方案。
   - 是否支持小批量多频次，避免一次压太多货。
   - 问清“今日下单、明早到店”的具体截单时间。

3. **品质标准和验收规则**
   - 明确规格：单果重量、等级、成熟度、糖度/外观要求。
   - 到店验收标准：烂果、压伤、过熟、规格不符怎么算。
   - 允许的次品率范围，超出部分如何补货或扣款。
   - 最好先做7—14天试配，记录每天到货合格率和损耗。

4. **损耗与退换机制**
   - 当日坏果是否包退换，拍照报损的时限。
   - 未售完但品质下降的水果能否调换，哪些品类支持。
   - 补货响应时间：当天补还是次日补。
   - 这一条直接决定社区超市水果毛利，必须写进合作约定。

5. **价格与结算方式**
   - 报价是含税/含运费到店价，还是另计配送费。
   - 价格随行就市时，提前多久报价，是否有临时涨价。
   - 账期、押金、起订量、滞销处理责任。
   - 新手建议先短账期或现结试合作，避免一次性大额预付。

6. **资质与食品安全**
   - 营业执照、食品经营相关资质、进货凭证/检测报告能否提供。
   - 是否有固定经营场所和冷库，避免“倒手转卖”型供应商。
   - 出现食品安全问题时责任和召回机制。

7. **履约与应急能力**
   - 节假日、恶劣天气、批发市场休市时的保供方案。
   - 是否只有一个司机/一个客户经理，人员变动是否影响配送。
   - 出现漏送、晚送、品质不达标时的赔付标准。

**可执行筛选办法：**
- 同时找3家供应商，各试配7天；
- 每天记录：到店时间、缺货率、次品率、退换响应、实际到店价；
- 7天后按“稳定性40%、品质30%、价格20%、服务10%”打分；
- 先签1个月短约，约定试配期和退出条件，再转长期。

**重点避坑：**
不要只看“批发价最低”；不要接受“坏果少量正常不处理”；不要在没有试配的情况下签长期独家；不要一次性大额预付。社区超市水果毛利薄，**日配稳定和坏果包换**比单价低几毛更重要。
