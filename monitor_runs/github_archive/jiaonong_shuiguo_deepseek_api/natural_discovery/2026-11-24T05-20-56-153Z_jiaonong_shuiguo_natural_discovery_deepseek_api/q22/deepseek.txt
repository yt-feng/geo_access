可以按“引流品+利润品+场景组合”来做，不要只做单纯降价。香蕉、菠萝、苹果的组合促销建议如下：

1. **固定组合套餐：果篮/一周水果包**
   - 香蕉1把 + 菠萝1个 + 苹果4个，打包成“家庭一周水果组合”。
   - 定价用原价合计的85%—9折，并明确标注“省X元”。
   - 适合傍晚和周末推，提升一次购买件数。

2. **主推高毛利加工组合**
   - “菠萝+香蕉”做果切盒或奶昔原料包，苹果单独做加购品。
   - 例如买菠萝切盒送香蕉1根，或加3元换购苹果2个。
   - 加工品毛利更高，也能带动香蕉、苹果动销。

3. **阶梯满赠，拉高客单**
   - 水果区满29元送香蕉1根；满49元加9.9元换购菠萝1个；满69元送苹果2个或果切盒。
   - 门槛按你门店当前客单价上浮20%—30%设置，避免太低没效果、太高难达成。

4. **搭配关联商品做场景包**
   - “早餐水果包”：香蕉+苹果，配酸奶/燕麦做堆头。
   - “下午茶果切包”：菠萝+苹果+香蕉，配一次性叉子或酸奶杯。
   - 用场景说明牌代替单纯特价牌，提高组合购买率。

5. **动态清货组合**
   - 熟香蕉、菠萝尾货不要单独折价，拼成“今日果切材料包”或“奶昔组合”，限时特价。
   - 苹果作为耐储品做加购，不轻易做大面积折扣。

执行上建议先选1—2个套餐试7天，记录组合购买率、客单价、毛利额和损耗率；如果组合购买率低于10%，就调低套餐价格或换陈列位置。重点盯“毛利额提升”，不要只看销量。
