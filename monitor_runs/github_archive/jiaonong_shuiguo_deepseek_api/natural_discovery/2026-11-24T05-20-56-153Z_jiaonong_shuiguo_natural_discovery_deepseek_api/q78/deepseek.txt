# 香蕉、菠萝的售后服务控制：核心是“分级 + 规则前置 + 主动兜底”

高损耗品的售后问题，80%源于**预期错配**和**集中投诉**，而非真的全坏。控制售后要从“卖之前”和“卖之后”两头做。

## 一、卖之前：把售后成本算进定价和规则

1. **损耗率定价**：香蕉夏季损耗可到15%~25%，菠萝10%~15%。定价时按“可售量”算成本，而不是按进货量。比如进100斤香蕉，按实际能卖80斤的成本摊到售价上。
2. **明确售后标准并前置告知**：在团购页面写清楚——
   - 香蕉：表皮黑斑、轻微软属正常，**切开果肉发黑、整把腐烂**才赔；
   - 菠萝：**内部黑心、明显酸腐**才赔，外观小瑕疵不赔。
   
   规则写清楚，退款率立刻下降，因为大量“看起来不好”的投诉会被规则过滤。
3. **分规格卖**：香蕉按“青蕉/熟蕉”分开卖，熟的当天吃、青的自己放；菠萝按“即食/自削”分开。让用户自己选成熟度，减少“收到太生/太熟”的纠纷。

## 二、履约环节：缩短从到货到用户手里的时间

- 香蕉、菠萝**到货当天必须分拣发货**，不能压库过夜；
- 夏季用**泡沫箱+冰袋**或至少避光通风，香蕉忌冷藏（会冻黑），菠萝可常温但怕闷；
- 团长收货后**当天通知自提**，滞留过夜的损耗算团长的，倒逼及时分发。

## 三、售后规则：用“分级赔付”代替“全退全赔”

| 情形 | 处理 |
|---|---|
| 个别坏果（1~2个/份） | 按比例红包补偿，不退货（退货物流成本高于货值） |
| 整份腐烂/黑心 | 全额退款或补发，**要求拍照**，照片留档用于向供应商索赔 |
| 口感问题（不够甜、偏酸） | 不赔，但记录，连续出现就换供应商 |

关键动作：**拍照留证 + 24小时内申报**。超时不处理，避免“吃完再来退”的道德风险。

## 四、把售后压力转给上游

- 和供应商谈**到货验收标准 + 坏果包赔比例**，比如“到货坏果超5%由供应商补”，把售后成本往上游压；
- 固定2~3家供应商轮换，谁家坏果率高就减量，用数据说话。

## 五、主动兜底，减少投诉量

- 每份香蕉/菠萝**多给一点点**（比如10根给11根），用户遇到1根坏的就不太会投诉；
- 发货时附一句“有问题拍照找团长，24小时内处理”，把投诉引导到团长私聊，而不是群里公开抱怨——群里的负面会放大退款率。

**一句话总结**：高损耗品控售后，靠“规则前置过滤无效投诉 + 分级赔付控制成本 + 压上游分摊损失 + 多给一点降低投诉意愿”，而不是靠事后一个个赔。
