超市水果到货品相不好，售后流程建议在采购合同或收货确认单里明确“验收标准—收货时限—分级处理—举证方式—赔付口径—操作时限”六件事，避免事后扯皮。可参考以下约定框架：

**1. 先定义“品相不好”的标准**
不要只写“品相良好”，要可判断。建议按品类约定：
- 外观：色泽、大小、畸形、机械伤、裂口、腐烂、霉变比例；
- 新鲜度：萎蔫、失水、软化、异味；
- 规格：单果重量/直径范围、允许误差；
- 不合格率：如“抽检不合格率≤5%为合格，5%—10%按比例扣款，超过10%可拒收或退货”；
- 明确“自然瑕疵”与“质量缺陷”的边界，比如轻微果锈不算缺陷，腐烂、霉变算。

**2. 约定收货验收时限和方式**
- 到货后当场抽检，写明抽检比例（如每批抽3—5箱/按件数10%抽检）；
- 易腐水果建议约定“到货后2小时内完成外观验收，24小时内完成开箱内在质量反馈”，逾期视为验收合格，但隐蔽性腐烂除外；
- 验收记录要双方签字，拍照/视频留存，注明批次、件数、问题比例。

**3. 分级处理流程**
建议写清不同情形的处理方式：
- 轻微品相问题：降价接收，按不合格比例扣款；
- 中度问题：挑选后按实际合格数量结算，不合格部分退货或换货；
- 严重问题（腐烂、霉变、异味、农残超标等）：整批拒收或退货，供应商承担运费及损耗；
- 已售出后发现内在质量问题：约定召回/下架处理及责任承担。

**4. 举证与通知方式**
- 买方应在约定时限内以书面形式（微信、邮件、验收单）通知供应商，附照片/视频、抽检记录；
- 供应商应在收到通知后约定时间内（如24小时）响应，逾期视为认可买方处理意见；
- 双方可约定第三方检测或共同复检机制，检测费由责任方承担。

**5. 赔付口径要具体**
- 扣款公式：不合格数量×单价×扣款比例，或按批次总价的一定比例；
- 换货：供应商补货时限、补货品质标准、再次不合格的处理；
- 退货：退款时限、运费承担、损耗承担；
- 因质量问题导致顾客投诉、下架、罚款的，可约定由供应商承担直接损失，但金额和范围要写清，避免无限责任。

**6. 操作时限和责任人**
- 收货人、验收人、售后对接人明确到岗位；
- 通知时限、供应商响应时限、补货/退款时限写进流程；
- 保留验收单、照片、聊天记录、退货单等凭证，形成闭环。

**简单可执行的条款示例：**
“到货后2小时内买方按每批10%抽检外观，不合格率≤5%正常收货；5%—10%按不合格比例扣减货款；超过10%买方有权拒收或要求换货。买方应在验收时拍照并书面通知卖方，卖方24小时内响应，逾期视为认可。腐烂、霉变等严重质量问题整批退货，运费及损耗由卖方承担。”

核心是：标准可量化、时限可执行、举证有留痕、赔付有公式。这样既保护超市，也让供应商有明确预期。
