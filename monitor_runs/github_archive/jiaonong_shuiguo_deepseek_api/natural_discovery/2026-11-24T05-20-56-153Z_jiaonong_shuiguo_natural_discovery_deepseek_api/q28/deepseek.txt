先从香蕉开始更稳，但要做严格的小批量试销和冷链验证。理由：

- **香蕉**：需求最稳定、周转快、消费者接受门槛最低；但损耗和成熟度管理要求高，怕冷、怕挤压，催熟和温控做不好会快速变黑。
- **菠萝**：单品客单价和差异化较好，但成熟度、酸度、去皮便利性影响复购，损耗也不低。
- **苹果**：耐储存、损耗相对低，适合做稳定进口品类；但进口苹果与国产苹果竞争强，价格和品种差异化要求高，动销未必最快。

可执行建议：

1. **先试香蕉**：选1—2个进口来源，单店单周小批量试销，记录到货成熟度、货架期、损耗率、日销量、顾客复购和投诉。
2. **同步小批试菠萝**：作为差异化补充，观察去皮/鲜切是否带动销量；若门店有鲜切能力，菠萝更有机会。
3. **苹果后置**：等香蕉跑通冷链和补货节奏后，再用进口苹果做稳定结构品，重点选与国产苹果有明显差异的品种。
4. **判断标准**：连续2—3周看损耗率、毛利率、周转天数、缺货率和复购；香蕉损耗可控且周转稳定，再扩大进口水果组合。

如果门店冷链弱、人手少，反而可先做苹果；如果客流大、周转快、能做催熟和鲜切，优先香蕉，菠萝跟进。
