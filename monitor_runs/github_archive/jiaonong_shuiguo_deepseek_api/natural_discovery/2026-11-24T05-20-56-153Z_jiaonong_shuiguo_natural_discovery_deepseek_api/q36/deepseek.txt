建议以“整果为主、切果为辅”，并且切果只做小份、当日内售完。判断依据如下：

1. **整果更适合作为商超菠萝主销形态**
   - 损耗低：菠萝整果耐存放、耐搬运，果皮本身起保护作用。
   - 毛利和定价空间更稳：整果可按个、按斤卖，便于做促销引流。
   - 适合家庭采购：顾客可自行判断成熟度，回家削皮或让门店代削。
   - 商超客流中家庭采购占比高，整果更符合“买回家吃”的场景。

2. **切果适合作为补充，但不宜作为主形态**
   - 优势：即食、方便，适合上班族、小家庭、年轻顾客和冲动消费。
   - 风险：切后氧化、出水、变味快，保质期短，损耗和食品安全管理要求高。
   - 如果做切果，建议：
     - 只做小份盒装，避免大份卖不完；
     - 现场切制或冷藏陈列，明确标注切制时间；
     - 当日未售完及时折价或下架，不要隔夜继续正价卖；
     - 选择成熟度适中、果形规整的菠萝做切果，避免用快坏果“消化库存”。

3. **更稳妥的组合策略**
   - 整果占陈列和销量的主要部分，做堆头、促销价、买赠；
   - 切果放在即食水果区，小份试销，观察动销；
   - 提供“免费代削/代切”服务，兼顾便利性和低损耗；
   - 根据门店客群调整：社区店、家庭客多的店偏整果；商圈店、写字楼店、年轻客多的店可适当增加切果比例。

结论：**多数商超门店应以整果为主，切果作为便利性补充；先小份试销，用动销和损耗数据再决定切果占比。**
