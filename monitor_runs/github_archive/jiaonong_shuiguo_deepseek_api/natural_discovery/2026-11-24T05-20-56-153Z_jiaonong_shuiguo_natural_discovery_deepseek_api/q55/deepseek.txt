选规格的核心是：**按“可食部分成本”算，不要按整果重量或单价直觉选。** 水果拼盘对苹果、橙子、菠萝的规格要求不一样，建议分开定：

### 1. 苹果：选中大果，别追特大果
- **推荐规格**：单果 **180–220g** 左右，果径约 **75–80mm**。
- **原因**：这个规格出成率稳定、切片整齐、氧化和边角料可控；特大果单价常更高，但核心出肉率提升有限，切拼盘还容易一片过大。
- **判断方法**：按“去皮去核后净重 ÷ 采购重量”算净料率。拼盘优先选净料率高且大小均匀的，不选最大果。
- **不划算的情况**：特级大果溢价明显、果形不正、碰伤多，做拼盘反而损耗大。

### 2. 橙子：选中果偏大，优先看皮薄和出汁/出肉
- **推荐规格**：单果 **200–250g** 左右，果径约 **75–85mm**。
- **原因**：太小切瓣少、摆盘费工；太大皮厚或白瓤多时，净肉率不一定高。拼盘用橙子要切瓣或去皮取肉，**皮薄、籽少、易剥**比单纯大果更划算。
- **判断方法**：同样称重后去皮去籽，比较净肉率；再看出汁和瓣膜完整度。
- **不划算的情况**：只按箱价便宜选小果，人工切配成本会上来；选超大果但皮厚白瓤多，净料率反而低。

### 3. 菠萝：选中大果、成熟度稳定，优先净肉率
- **推荐规格**：单果 **1.2–1.8kg** 比较适合餐厅拼盘。
- **原因**：太小削皮去眼后损耗大、出肉少；太大一次用不完，切开后存放损耗和氧化风险高。餐厅要看**单果可利用率和当天周转**，不是越大越好。
- **判断方法**：按“去皮去眼后净肉重量 ÷ 毛重”算净料率；同时看眼深浅、成熟度是否一致。
- **不划算的情况**：超大果单价低但一次用不完、隔夜损耗高；或者眼深、削皮损耗大。

### 直接可执行的采购规则
1. **先定拼盘每份标准克重**：苹果、橙子、菠萝各多少克，倒推每份毛料需求。
2. **每种水果连续测3批净料率**：净料率 = 可摆盘净重 ÷ 采购毛重。
3. **比较“每份拼盘的水果成本”**，而不是每斤采购价。
4. **规格选择**：
   - 苹果：180–220g/个，均匀度优先；
   - 橙子：200–250g/个，皮薄籽少优先；
   - 菠萝：1.2–1.8kg/个，净肉率和当天周转优先。
5. **签采购标准**：写明单果重量区间、允许碰伤率、成熟度、到货温度；到货抽检净料率，低于标准就换规格或换供应商。

一句话：**苹果看均匀和净料率，橙子看皮薄出肉，菠萝看净肉率和周转；用“每份拼盘成本”比价，最不容易选错。**
