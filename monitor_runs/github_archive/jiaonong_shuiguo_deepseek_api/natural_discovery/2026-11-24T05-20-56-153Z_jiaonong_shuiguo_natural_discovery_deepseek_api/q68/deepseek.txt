判断供应商能不能按时到车，关键不是听承诺，而是看“可验证的发车条件”。可以从下面几层做判断：

**1. 先问清“按时到车”的定义**
- 到车时间具体是几点？到哪个市场/档口？
- 是供应商自己的车，还是临时调车？
- 装车地点、装车时间、预计路程、是否中转？
- 逾期怎么处理？最好在订单里写清到车时间和违约扣款。

**2. 看货源是否已经落实**
- 香蕉是否已经砍收/催熟/装箱？问“今天装还是明天装”。
- 让供应商发**果园或包装场的实时视频**，能看到香蕉、包装箱、车牌或装车现场。
- 问清“这一车是否专供你”，还是和别的客户拼车。拼车最容易拖。

**3. 看车源是否真实可控**
- 要**车牌号、司机电话、车辆定位或装车视频**。
- 问是自有车、长期合作车还是临时叫车。临时叫车变数最大。
- 装车后让司机发**高速入口照片/过磅单/定位**，比供应商口头说“已发车”可靠。

**4. 用历史记录筛人**
- 问最近三车分别发往哪里、几点到、有没有迟到。
- 找同行或市场档口打听该供应商的到车口碑。
- 新供应商第一单不要押大单，先小批量试一车。

**5. 合同和付款上留抓手**
- 写明到车时间、迟到扣款、车皮/货损标准。
- 不要一次性全款，至少留尾款到车验收后付。
- 要求装车后提供**装车单、过磅单、车牌和司机联系方式**。

**6. 到车前做动态跟踪**
- 装车当天确认“已装车”，发车后确认“已上高速”，途中问一次位置。
- 如果供应商反复说“马上装”“车在路上”但给不出车牌和定位，基本可判断风险高。

一句话：**能给出车牌、司机、装车视频、过磅单和明确装车时间的供应商，才值得信；只会口头保证“没问题”的，要留一手。**
