很重要，而且往往比“进价再低一点”更关键。水果销量不稳定时，供应商能否支持小批量试卖，直接决定你能不能把损耗和现金占用控制住。

可判断的几个点：

1. **试卖支持是降低试错成本的核心**
   - 水果保质期短、损耗高，一次性压大货，卖不动就直接变成报损。
   - 小批量试卖能先验证：这个品类在你们店有没有需求、哪个规格好卖、什么价格带能动销。

2. **不只看“能不能小批量”，要看四个条件**
   - **最小起订量**：是否低到你能承受，比如按箱、按半箱、按几个SKU混拼。
   - **配送频次**：能否一周多次补货，而不是一次压一周的量。
   - **换货/退损政策**：坏果、临期、滞销能否换货或部分承担。
   - **试卖周期**：给7天还是14天，期间是否允许调整品类和数量。

3. **供应商不支持小批量时，风险会转移给你**
   - 你承担库存和损耗，供应商只负责出货。
   - 销量不稳定时，这种模式很容易出现“看着毛利有，算上损耗不赚钱”。

4. **实操建议**
   - 先选2—3个高频水果做小批量试卖，不要一次上太多SKU。
   - 和供应商谈“首单小批量+周内补货+坏果换货”，比单纯压价更有价值。
   - 记录每天销量、损耗和售罄时间，用数据决定是否加量。
   - 如果供应商坚持大起订量，可以要求分批到货或由供应商承担部分滞销风险；谈不下来，就优先找能小批量配合的供应商。

结论：**很重要。小批量试卖能力是便利店水果控损和验证需求的基础条件，应该作为选供应商的硬指标之一，而不是附加福利。**
