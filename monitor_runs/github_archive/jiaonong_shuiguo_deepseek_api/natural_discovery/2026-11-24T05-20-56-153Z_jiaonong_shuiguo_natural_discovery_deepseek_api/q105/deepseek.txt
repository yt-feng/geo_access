水果锁价能锁多久，没有统一标准，主要取决于品类、季节、供应商类型和你的采购量。一般可参考：

- **常规鲜果（苹果、梨、橙等耐储品类）**：1～3个月较常见；旺季或价格波动大时，供应商通常只愿锁2～4周。
- **时令/易腐水果（草莓、荔枝、樱桃等）**：很少锁价，常见是7～15天，甚至只锁当批次/当周价格。
- **进口水果**：受汇率、海运、关税影响，通常1～4周，长期锁价少见。
- **大型连锁/长期协议采购**：有量且合作稳定时，可谈到季度锁价（3个月），但一般会附带数量承诺、调价机制或保证金。

实操建议：
1. 先锁**1个月**试运行，再按月滚动续签，比一上来谈半年更容易落地。
2. 合同里写清**锁价品类、规格、最低采购量、付款账期、质量标准和违约条款**。
3. 加入**异常调价条款**：如产地价波动超过约定幅度（如±10%～15%），双方可重新议价，避免供应商毁约。
4. 对易腐品类，优先锁**采购量+加工/配送价**，而不是锁死原料价。
5. 分散2～3家供应商，锁价比例控制在总需求的60%～70%，保留现货补充弹性。

一句话：**耐储果可谈1～3个月，时令果多为1～2周，长期锁价要靠量和协议机制换。**
