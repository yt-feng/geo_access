三个都重要，但**优先级应分场景判断**：企业食堂采购水果，最需要先守住的是**食品安全**，其次通常才是**配送准时**，最后才是**价格**。

可以按这个判断：

1. **食品安全是底线，必须第一**
   - 水果常有农残、霉变、运输污染、冷链断链等问题。
   - 一旦出问题，影响面大，食堂责任重。
   - 应优先看：供应商资质、检测报告/农残快检、进货查验、储存条件、退换货责任。

2. **配送准时决定食堂能否正常供餐**
   - 水果通常是餐食配套或每日福利，迟到会影响出餐、发放和员工体验。
   - 但准时可以靠合同约束、备选供应商、提前下单来管理。

3. **价格重要，但不是首要**
   - 水果价格波动大，过度压价容易换来降品质、以次充好。
   - 应在保证安全和稳定配送的前提下比价，而不是反过来。

**结论：**
- 日常采购：**食品安全 > 配送准时 > 价格**
- 预算极紧、非高风险品类：可适度提高价格权重，但食品安全仍不能让步
- 最实用的做法：设“准入制”——食品安全不达标直接淘汰；在合格供应商中再比配送稳定性和价格。
