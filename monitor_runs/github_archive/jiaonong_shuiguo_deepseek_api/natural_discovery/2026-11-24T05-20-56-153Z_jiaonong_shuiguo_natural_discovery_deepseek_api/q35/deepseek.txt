# 连锁超市降低门店坏果率的合同约定建议

坏果率通常来自两个环节：**到货即坏（供应商责任）** 和 **在店损耗（门店/供应链责任）**。合同要分开约定，否则后期扯皮。建议按以下结构写：

## 一、先定义清楚"坏果"和"坏果率"

- **坏果定义**：明确列举判定标准，如腐烂、霉变、严重压伤、开裂、异味、失水萎蔫等，最好附**图文判定标准**作为合同附件。
- **计算口径**：坏果率 = 坏果重量（或件数）÷ 该批次到货总重量（件数）。明确按重量还是按件、按批次还是按月汇总。
- **抽检规则**：约定抽检比例（如每批次抽检不低于5%或不少于若干箱）、抽检时点（到货验收时）、抽检人和双方签字确认方式。抽检不合格时扩大抽检或全检的规则也要写。

## 二、分环节约定责任与赔付

**1. 到货验收环节（供应商责任为主）**
- 设定**到货坏果率上限**（如≤3%，按品类分别设定，叶菜、浆果类可放宽）。
- 超限处理：整批拒收 / 按坏果数量**折价扣款** / 要求换货并承担换货物流费。
- 明确**验收期限**：到货后多少小时内完成验收，逾期视为合格（保护供应商，也倒逼门店及时验货）。

**2. 保质期内（货架期）责任**
- 约定**货架期质量保证**：如到货后X天内（按品类，如叶菜2天、根茎类5天）出现非门店保管原因导致的坏果，供应商按比例补货或赔付。
- 区分"供应商责任"与"门店保管责任"：因门店冷链断链、堆压、超期陈列导致的坏果，由门店承担，不计入供应商赔付。这条很关键，否则供应商会把所有损耗都推给门店或反之。

**3. 门店自身损耗管理（内部考核，也可写入与门店的承包/考核协议）**
- 设定门店**月度坏果率考核线**，超出部分从门店绩效或毛利中扣减；低于目标给予奖励。
- 与订货、陈列、临期打折、报损流程挂钩，形成闭环。

## 三、赔付方式要可执行

- **优先补货/换货**，其次**货款抵扣**，最后**现金赔付**。约定抵扣在下次结算时自动执行，避免追讨。
- 明确**赔付计算基数**：按采购单价、结算价还是市场价；是否含运费。
- 设定**阶梯赔付**：如坏果率3%–5%按坏果金额1倍赔，5%–10%按1.5倍，超过10%整批退货并罚违约金。
- 约定**累计考核**：月度坏果率连续超标或单月超阈值，可触发警告、扣保证金、终止合作。

## 四、配套条款

- **保证金/质量保证金**：从货款中预留一定比例，作为质量赔付的抵扣来源。
- **举证与争议**：抽检照片、视频、双方签字单作为证据；争议时约定第三方检测或复检机制。
- **数据留痕**：要求门店每批次验收、报损留记录，作为月度对账依据。
- **不可归责情形**：明确自然灾害、运输途中非供应商可控因素等的处理，避免条款被认定显失公平。

## 一句话原则

**把"坏果"定义、抽检规则、分环节责任、赔付计算基数和抵扣方式这五项写死**，其余用附件（品类标准表、阶梯赔付表）细化，合同才真正能落地执行，而不是签完仍靠扯皮。
