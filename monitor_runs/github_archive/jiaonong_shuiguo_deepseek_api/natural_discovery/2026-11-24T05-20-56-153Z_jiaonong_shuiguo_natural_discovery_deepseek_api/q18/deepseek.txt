避免香蕉“太生或太熟”，核心是**先定用途和吃的时间，再按表皮颜色选**，而不是只看“黄不黄”。

可执行做法：

1. **按计划吃的时间选颜色**
   - **当天/明天吃**：选**通体黄色、少量褐斑**的。
   - **2～3天内吃**：选**黄中带一点绿尖**的。
   - **4～5天后吃**：选**整体偏绿、棱角明显**的，回家常温放熟。
   - **不建议买**：大面积褐黑斑、果柄发黑发软、表皮一按一个坑的。

2. **看果柄和棱角**
   - 果柄青绿、切口干净：相对新鲜。
   - 香蕉棱角很分明：偏生；棱角圆润饱满：偏熟。
   - 果柄发黑、发霉或整把松散，别选。

3. **摸硬度**
   - 轻按有弹性、不软塌：适合近期吃。
   - 硬得像石头：耐放，但要放几天。
   - 一按就凹、发黏：过熟或已损伤。

4. **看整把一致性**
   - 一把里颜色差异太大，熟度不统一，容易有的没熟、有的先烂。
   - 优先选**颜色接近、无磕碰、无裂口**的一把。

5. **分开买两种熟度**
   - 想马上吃又怕后面断档：买**一把黄带少量斑** + **一把绿尖黄**，分开存放。
   - 熟的和生的**不要装同一袋密封**，熟香蕉释放乙烯会催熟旁边的。

6. **到店别买冷藏区久放的**
   - 香蕉怕低温，表皮发黑发暗、手感软的冷藏香蕉不建议买。
   - 买回家**未熟放常温**，不要急着进冰箱；已熟可短期冷藏但皮会变黑。

一句话判断：**今天吃选黄带斑，两三天吃选黄带绿尖，几天后吃选偏绿硬挺；果柄发黑、按着软塌、斑大面积发黑的不要。**
