会影响，但主要影响的是**分级销售和损耗**，不是“能不能卖”。

关键判断：

1. **大小不一会拉低整箱溢价**
   - 同一箱大小差异明显，顾客挑拣后容易剩下小果、异形果，整箱很难按统一价卖高。
   - 如果整箱统货卖，顾客会觉得“大小不一”，压价或挑货。

2. **真正影响销售的是成熟度和外观一致性**
   - 香蕉大小略有差异但颜色、成熟度一致，影响相对小。
   - 如果大小差很多，还伴随青黄不匀、机械伤、掉把，销售影响会明显放大。

3. **建议不要整箱混卖，做分级**
   - 大果/中果/小果分开，按不同价格或不同用途卖：
     - 大果：精品陈列、按根/按斤溢价；
     - 中果：常规走量；
     - 小果：特价、切果店、果汁店、员工福利或促销捆绑。
   - 这样比整箱统货更能保住毛利。

4. **采购时看“整齐度”而不是只看均价**
   - 同一箱大小差异越大，实际可售好果比例越低，损耗和挑拣人工越高。
   - 采购价便宜但整齐度差，未必划算。建议按“可售率”算成本，而不是按整箱斤价算。

5. **陈列上减少顾客挑拣**
   - 分级后分别陈列，标清规格和价格。
   - 不要大小混堆，否则顾客翻挑会加速香蕉碰伤、掉把。

**结论：** 一箱大小不一样会影响销售，主要是难统一溢价、增加挑拣和损耗；但可以通过分級销售把影响降下来。采购时优先选成熟度一致、大小相对整齐的货；差异大的货要压低采购价，并提前想好小果的出货渠道。
