# 坏果率与赔付门槛

**结论：没有法定统一比例，建议在合同中约定"到货验收坏果率超过 3%～5% 即触发赔付"，并按超出部分折算价款；超过 10% 可约定买方拒收或整批退货。**

具体建议如下：

## 1. 分段约定更实用
| 坏果率（验收时） | 建议处理方式 |
|---|---|
| ≤3%（或5%） | 视为合理损耗，正常收货 |
| 3%～10% | 按超出部分扣款：赔付金额 = 货值 ×（实际坏果率 − 免赔率） |
| >10% | 买方有权拒收整批，或要求换货并赔偿损失 |

免赔率定 3% 还是 5%，取决于品类和运输距离：叶菜、浆果等易损品可放宽到 5%～8%；耐储类（苹果、柑橘）可收紧到 2%～3%。

## 2. 合同里必须写清的三件事
- **坏果的判定标准**：腐败、霉变、腐烂、严重压伤、虫蛀等分别列明，"轻微表皮瑕疵"不计入坏果，避免扯皮。
- **验收时点和抽样方法**：到货后多少小时内验收（如 24 小时）、抽检比例（如每批次随机抽 10%）、是否允许开箱全检。
- **赔付计算方式**：按超出免赔率部分折算，并明确是否扣除运费、是否可叠加违约金。

## 3. 一句话条款示例
> "到货验收坏果率不超过 5% 的，买方正常收货；超过 5% 的，超出部分按货值比例扣减货款；超过 10% 的，买方有权拒收整批，卖方应在 X 日内退换并承担运费及因此产生的损失。"

## 4. 注意
以上比例为行业常见做法，**不是法律强制标准**，最终以双方合同约定为准。若长期合作，建议同时约定累积多批次的年度坏果率上限，防止单批"擦线合格"但整体质量下滑。
