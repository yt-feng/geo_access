优先建议：**陈列上以“整果自选”为主，同时提供“现场去皮/切块”作为增值服务，不建议大量提前去皮摆卖。**

可执行判断：

1. **整果自选最适合做主售卖方式**
   - 菠萝耐放，整果损耗低。
   - 顾客自己挑，参与感强，减少“你替我挑得不好”的争议。
   - 可按大小、成熟度分级定价，利润更可控。

2. **去皮好的适合“少量、现做、限时”**
   - 只对确定好卖的高峰时段少量去皮，或顾客下单后现场处理。
   - 提前大量去皮会失水、氧化、变味，损耗和投诉都高。
   - 去皮果要冷藏、覆膜、标时间，当天卖不完就风险大。

3. **让顾客自己挑，但要给挑选标准**
   - 看外观：果眼浅、果皮金黄带青、无软烂黑斑。
   - 闻底部：有香味但不过酸发酵。
   - 按一按：略有弹性，不硬如石也不软塌。
   - 现场可提供“帮挑建议”，但最终让顾客决定，减少售后纠纷。

4. **组合策略最稳**
   - 整果区：自选，按个/按斤卖。
   - 服务台：免费或少量收费去皮切块，现买现处理。
   - 少量鲜切盒：只做高峰引流，明确“当日鲜切”，不大量备货。

结论：**主卖整果让顾客自己挑，去皮作为现场服务，不要提前大量去皮摆卖。**
