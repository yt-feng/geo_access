建议按“资质—检测—批次追溯—承诺与违约”四类资料向供应商索取，并把“每批到货可核验”写进采购合同。重点如下：

1. **主体与资质资料**
   - 营业执照、食品经营许可证/食用农产品销售相关资质。
   - 若供应商是种植基地或合作社：产地证明、种植基地备案或合作协议。
   - 若为经销商：上游产地/基地供货证明及授权链。

2. **检测报告（最关键）**
   - 要求提供**与拟采购品种、产地、批次对应的农残检测报告**，不要只收一张“通用合格报告”。
   - 报告应含：样品名称、产地/供应商、采样或生产日期、检测项目、检测方法、结果判定、检测机构名称及资质标识（如CMA/CNAS，能核验更好）。
   - 优先要**批次检测报告**；至少要求高风险水果品种每批附检，其他品种按周/月抽检并承诺到货可抽。
   - 可要求供应商提供快检记录或委托第三方检测的委托单/发票，防止报告与货不对应。

3. **批次追溯资料**
   - 每批到货随货提供：品名、产地、采摘/包装日期、批次号、数量、运输信息。
   - 包装标签、产地证明、进货凭证要能串起来；超市端可做到“货—报告—批次”一一对应。

4. **承诺与合同条款**
   - 书面质量安全承诺：农残符合GB 2763等国家限量标准；如抽检不合格，供应商承担退货、销毁、复检、监管处罚及商誉损失等责任。
   - 约定超市有权自行或委托第三方抽检，费用承担与不合格处理流程写清楚。
   - 约定报告造假、批次不符的违约责任和解除合同权。

5. **到货验收动作**
   - 每批核对：品种/产地/批次与报告一致；报告日期合理；包装完好；必要时超市自己做快检并留样。
   - 建立供应商档案和批次台账，检测报告保存期限按当地监管要求执行，通常不少于保质期满后6个月，无明确保质期的不少于2年，具体以属地市场监管要求为准。

一句话：**不要只要“合格证”，要“对应批次、可追溯、可核验的农残检测报告+合同责任条款”**。这样既满足抽检应对，也能把风险前置到供应商。
