建议把“临时补货”做成**短周期、锁量不锁价、按日滚动确认**的补充协议，而不是只靠口头打招呼。可按下面执行：

1. **先定补货机制**
   - 和主供应商约定：旺季期间每天/每两天固定时间报次日需求，供应商在2小时内确认可供应量。
   - 设“基础日供量+弹性增量”：例如日常100公斤，旺季可上浮30%—50%，超出部分提前48小时报。
   - 明确最低起送量、配送频次、到货时段，避免临时加单被拒或加价过高。

2. **价格和品质写清楚**
   - 临时补货价可按“当日市场价/报价单价+约定服务费”执行，但必须设价格上限或提前报价确认，不能供应商单方随意涨。
   - 约定规格：品种、单果重量范围、成熟度、无腐烂率、农残合格、到货温度/包装要求。
   - 明确验收标准：不合格可拒收、换货时限、损耗承担方。

3. **锁量与违约责任**
   - 供应商承诺旺季弹性供应上限，茶饮店承诺最低采购量或保证金，双方都有约束。
   - 供应商未按确认量供货，约定替代采购差价承担或违约金；茶饮店临时取消，也承担合理备货损失。
   - 遇到极端天气、产地减产，约定提前通知和替代方案。

4. **备选供应和应急方案**
   - 至少保留1—2家备用供应商，主供应商确认不了时立即切换。
   - 约定可临时改用冷冻/罐头菠萝的触发条件，但需符合门店配方和品质要求。
   - 旺季前做一次“压力测试”：连续一周按峰值量下单，看供应商履约能力。

5. **合同形式**
   - 在主合同下签《旺季临时补货补充协议》，期限写清楚，比如某月至某月。
   - 每次补货用微信/邮件/订货单确认品种、数量、单价、到货时间，保留记录。
   - 结算周期、发票、退货扣款方式一并写明。

一句话：**把临时补货变成“提前报计划、供应商确认、价格有上限、违约有责任、备用有方案”的滚动订货机制**，比临时打电话更稳。
