**结论：在商超水果采购里，损耗低对最终毛利的影响通常更大，尤其是生鲜这种短保、价格弹性大、损耗波动大的品类。** 但“价格低”和“损耗低”不是二选一，真正决定毛利的是：

> **毛利 = 售价 × 实际可售量 − 采购成本 − 损耗成本 − 运营成本**

价格低主要影响“采购成本”，损耗低主要影响“实际可售量”。水果行业里，**损耗每高几个点，往往会把低进价带来的优势全部吃掉，甚至倒亏。**

### 为什么损耗更关键

1. **水果损耗是乘法级影响**  
   假设采购1000元水果，售价按成本加价50%：
   - 损耗5%：可售950元成本，销售额1425元，毛利425元；
   - 损耗20%：可售800元成本，销售额1200元，毛利200元。  
   损耗从5%到20%，毛利直接少一半多。低进价省下的几十元，很难抵消这种损失。

2. **低价格常伴随高损耗风险**  
   进价低可能是尾货、熟度高、规格不齐、产地远、保鲜差。采购时便宜10%，销售端损耗可能多15%—20%，最终毛利反而更差。

3. **损耗影响周转和定价**  
   损耗高的水果必须尽快降价清货，实际售价被拉低；损耗低则能维持正常售价和排面，毛利更稳。

4. **价格低有下限，损耗低有复利**  
   采购价受行情、渠道、账期约束，压价空间有限；损耗管理可通过订货、冷链、陈列、催熟、分级、及时折价持续改善，对毛利是长期复利。

### 什么时候“价格低”更重要

- 水果**耐储、标准化高、周转快**，如苹果、梨、橙子等；
- 你有稳定冷链和强动销，损耗可控；
- 低进价来自稳定产地直采，不是临期尾货；
- 用于引流品，允许低毛利但要求低损耗配合。

### 可执行判断标准

采购决策时不要只看进价，建议算 **“到店可售成本”**：

> 到店可售成本 = 采购价 ÷（1 − 预估损耗率）

例如：
- A货进价5元/斤，预估损耗8%，可售成本=5÷0.92≈5.43元；
- B货进价4.5元/斤，预估损耗20%，可售成本=4.5÷0.8=5.63元。  
**B虽然进价低，但实际可售成本更高，最终毛利更差。**

### 一句话建议

**水果采购优先控损耗，再谈低价格；用“可售成本”而不是“进价”做决策。** 对高损耗风险品类，宁可进价略高，也要选品质稳定、损耗可控的货。
