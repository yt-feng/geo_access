连锁商超选长期水果供应商，评分标准要围绕“长期稳定供货”而不是一次性低价来设计。建议采用“资格门槛+综合评分”结构，总分100分，其中价格权重不宜过高，通常30%~40%，质量与履约能力占大头。

一、先设资格门槛（不满足直接淘汰）
- 营业执照、食品经营/生产许可、产地证明或供货能力证明
- 近2年类似商超/生鲜渠道供货业绩
- 冷链运输能力、仓储条件
- 无重大食品安全事故、无严重失信记录
- 能接受账期、退换货、质量赔付条款

二、综合评分建议（示例100分）
1. 产品质量与安全 25分
   - 农残/药残检测报告、批次检测能力（8分）
   - 果品规格、糖度、外观、新鲜度标准及分级能力（7分）
   - 食品安全追溯体系、产地管理（5分）
   - 质量异常处理与赔付承诺（5分）

2. 供货稳定性与产能 20分
   - 自有基地/长期合作基地面积、产量（6分）
   - 多产区布局、反季节/断档期供应能力（5分）
   - 日/周供货能力与商超门店覆盖匹配度（5分）
   - 应急补货、灾情/旺季保供方案（4分）

3. 冷链与物流履约 15分
   - 冷链车辆、冷库容量（5分）
   - 到店时效、配送频次、门店覆盖率（5分）
   - 温控记录、损耗控制方案（5分）

4. 价格与成本 30分
   - 报价水平（15分），建议用“基准价下浮率”或“同期市场价对比”评分，避免单纯最低价
   - 价格调整机制透明度（8分），如随行就市规则、调价周期
   - 账期、运费、包装等综合成本（7分）

5. 服务与响应 10分
   - 订单响应时间、退换货处理时效（4分）
   - 专属对接团队、驻场/巡店服务（3分）
   - 促销档期、新品推荐配合度（3分）

三、加分项（不超过5分）
- 可追溯二维码/数字化对接能力
- 绿色认证、有机认证、地理标志
- 应急保供历史表现
- 与商超系统EDI/订单系统对接能力

四、关键条款要写进合同而非只评分
- 质量抽检不合格的扣款/退货/终止条款
- 断供违约金与替补供应商机制
- 价格联动公式和调价提前通知期
- 账期、损耗承担比例、门店退换货规则

五、实操建议
- 价格分不要“最低价得满分”，建议去掉最高最低后取平均价或与市场监测价对比，防止恶意低价后断供。
- 要求投标方提供近3个月真实供货批次检测报告和冷链记录，防止纸面能力。
- 设置试用期/小批量试供，试供合格再签长期框架协议。
- 同一品类至少保留2家供应商，避免单一依赖。

总体权重可参考：质量安全25%、供货稳定20%、冷链物流15%、价格30%、服务10%。如果商超定位高端或对品质要求极高，可把质量提到30%、价格降到25%。
