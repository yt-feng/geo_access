多门店、单店量小，核心矛盾是：**总需求不小，但分散到每个店、每个SKU的单次采购量小**。适合的供货模式要满足三点：**少批量、多频次、能拼单/集单，且损耗和账期可控**。

### 优先考虑的模式

1. **城市级批发市场+固定档口代采（最落地）**
   - 适合：门店在同一城市或临近区域，SKU多、单店日销量低。
   - 做法：找1–2个批发市场固定档口，按门店次日订单集中代采，早上分拨到各店；档口负责品控初筛。
   - 优点：起订量低、品类全、现金结算灵活、试错成本低。
   - 关键控制：约定损耗赔付、到货时间、分级标准；每天汇总订单统一下单，避免每店单独跑市场。

2. **区域水果供应链公司/城市配送商（次优但省心）**
   - 适合：门店数≥10家、希望减少自采人力。
   - 做法：找做商超/生鲜店配送的区域供应商，按“总仓集单+门店分拨”供货，要求日配或隔日配。
   - 优点：有分级包装、冷链和售后；可谈账期。
   - 注意：单店量小会被加价，要谈“全品类打包+最低起送额”，并把配送费、损耗率写进合同。

3. **产地/一级批发商“拼车直发”**
   - 适合：某一两个大单品（如苹果、柑橘、西瓜）季节性放量时。
   - 做法：多家门店合并成一个整车或半车订单，直发城市总仓再分店。
   - 优点：毛利高；缺点：只适合耐储单品，叶菜、浆果类不适合。

4. **本地合作社/种植基地直供（补充）**
   - 适合：周边有基地、能做“以销定采”的时令单品。
   - 做法：按周预估销量，基地按标准分级后送到总仓；不追求全品类。
   - 注意：小门店议价弱，最好几家店联合采购或加入采购联盟。

### 不建议作为主模式
- **每家店各自找供应商**：价格不统一、品控不稳、人力浪费。
- **纯平台一件代发**：水果损耗和售后扯皮多，毛利被平台费吃掉。
- **大批量低频采购**：单店量小，压货即高损耗。

### 落地建议
- 设**一个城市总仓/分拨点**，所有门店订单每晚汇总，次日统采统配；没有总仓就用“档口代采+第三方城配”。
- 供货结构：**70%区域配送商保基础品类，30%批发市场代采补时令和低价单品**。
- 合同必写：到货时间、分级标准、损耗赔付比例、缺货替代规则、账期和退换货。
- 先跑2–4周小范围试点，按“损耗率、到货准时率、毛利率”三个指标筛选供应商。

一句话：**多店小量，最适合“城市集单+区域配送商/批发档口代采+总仓分拨”，而不是让每家店单独进货。**
