连锁超市降低门店坏果率，合同里建议把“坏果率”从一个模糊概念拆成**可测量、可归责、可扣款、可退出**的条款。核心不是只写“坏果率超过X%赔钱”，而是约定：

1. **定义与统计口径**
   - 明确“坏果”：腐烂、霉变、软烂、压伤、裂口、异味、非品种特征的变色等，最好附验收标准或图片示例。
   - 明确“坏果率”计算公式：  
     `坏果率 = 抽检坏果重量（或件数）÷ 抽检总重量（或件数）×100%`  
     并约定抽检比例、抽检时点（到店验收时/上架前/门店巡检时）、抽检主体（门店、第三方、双方联合）和争议复检机制。
   - 区分**运输/到店前坏果**与**门店储存不当坏果**，否则供应商会抗辩。建议以“到店验收抽检”为主归责节点，门店签收后一定时限内（如2小时/当日）提出的异议有效。

2. **分级赔付，不要只设一个阈值**
   建议按坏果率分档：
   - ≤3%：正常接收，不赔付；
   - 3%—5%：按坏果重量对应货值的100%扣款或补货；
   - 5%—10%：坏果货值全额扣款，并按当批次货值5%—10%支付违约金；
   - ＞10%：整批拒收或退货，供应商承担退货运费，并按当批次货值10%—20%支付违约金；
   - 连续3批次或月度累计坏果率超过约定值：超市有权暂停下单、要求整改，严重时解除合同。
   具体比例要根据品类、损耗基数和采购价测算，叶菜、浆果、热带水果标准应不同，不要一刀切。

3. **赔付方式写清楚**
   建议约定优先顺序：
   - 优先**补货/换货**，且补货到店时限明确（如24小时内）；
   - 不能补货的，按坏果数量对应采购价**全额退款或货款抵扣**；
   - 另设**违约金**覆盖门店下架、客诉、人工和客流损失；
   - 月度结算时从应付货款中直接扣除，供应商不得以未开票等理由拒绝。
   注意：扣款金额要能对应计算依据，避免被认定为任意罚款。

4. **验收与证据链**
   - 约定到店验收流程：数量、温度、外观、抽检、拍照/录像、双方签字。
   - 门店发现隐蔽坏果（如内部腐烂）的，约定在签收后一定期限内可追溯，供应商应认可开箱记录和照片。
   - 约定复检：供应商对结果有异议，可在24小时内申请联合复检，复检结果为最终依据；复检费用由责任方承担。

5. **责任边界与免责**
   明确因超市冷藏/常温储存不当、超期陈列、人为损伤造成的坏果，供应商不担责。建议同时约定超市的收货后保管义务和温控记录，避免供应商反诉。

6. **质量保证金与退出机制**
   - 可设质量保证金（如月度货款的5%—10%），滚动留存，合同终止后无质量问题再退。
   - 约定累计扣款上限和解除权：如单月坏果扣款超过货值15%，或连续两个月坏果率超标，超市可单方解除合同且不承担违约责任。

7. **警惕条款可执行性**
   - 坏果率标准要写进合同附件，并按品类列明。
   - 赔付条款要与验收标准、抽检方法绑定，否则发生争议时难以举证。
   - 不要只写“坏果率过高由供应商赔偿”，应写明计算方式、触发条件、金额和扣款路径。

一句话：合同里应写成“**按品类定标准、按批次抽检、按坏果率分档扣款/补货、按月货款抵扣、连续超标可解约**”，并保留验收照片和签字记录。具体百分比建议先用历史损耗数据测算，再与供应商谈判确定。
