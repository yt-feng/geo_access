核心是：超市买香蕉要看“当天吃还是放几天吃”，并用手感和果柄判断，不要只看颜色。

**1. 先定用途再选颜色**
- **当天/第二天吃**：选**通体黄色、少量小褐斑**的，甜度够、口感软。
- **2～4天后吃**：选**黄中带绿、两端稍绿**的，回家常温放熟。
- **想放一周左右**：选**整体偏绿、但已见黄色**的；纯深绿可能熟得慢且易发涩。
- **别买**：大面积黑斑、果肉发软、果柄发黑发霉的。

**2. 现场三步判断**
- **看果柄**：果柄青绿、切口新鲜，通常较生；果柄发黑干枯，通常偏熟或放久了。
- **轻捏中部**：硬挺=偏生；略有弹性=刚好；一捏就陷=过熟。
- **看棱角**：香蕉棱角明显、手感硬，偏生；棱角变圆润，成熟度更高。

**3. 避开超市常见坑**
- 不要买**冷藏区或冷柜边**的香蕉，低温会冻伤发黑。
- 不要选**整串成熟度差异太大**的，回家熟度不一致。
- 如果超市按把卖，优先选**果柄完整、没有裂口**的。
- 已经切开的香蕉不建议买，氧化快、难判断内部。

**4. 买回家后的控制**
- 偏生：常温阴凉处放，和苹果/梨同袋可加快成熟。
- 刚好熟：尽快吃；吃不完可冷藏延缓过熟，但表皮会变黑，果肉仍可吃。
- 太熟：剥皮冷冻，做奶昔或香蕉面包。

一句话：**当天吃选黄带小斑，想放几天选黄带绿，捏着略软有弹性最稳。**
