茶饮店控制水果供应商的食品安全风险，核心是“资质合规 + 批次可追溯 + 检测合格 + 储运可控”。建议按以下清单索取并留档，且每批到货核验。

**一、供应商主体资质**
1. 营业执照（经营范围含水果/农产品销售或种植销售）。
2. 食品经营许可证；若供应商为食用农产品生产者销售自产水果，通常可免于食品经营许可，但需提供自产证明/产地证明。具体以当地监管要求为准。
3. 仅做农产品初加工、散装水果销售的，按属地监管要求确认是否需要食品经营许可，别只凭口头承诺。

**二、产品合格与检测证明**
1. 每批次水果的**承诺达标合格证**（食用农产品生产者/收购者出具）。
2. **农残检测报告**：优先每批次或按供应商风险等级定期提供；至少覆盖常用高风险水果品种和项目。报告应由具备资质的检测机构出具，注意报告日期、批次、品名与到货一致。
3. 进口水果：海关入境货物检验检疫证明、报关单等，批次对应。
4. 如供应商声称“绿色/有机/地理标志”等，另索取有效认证证书，不作为普通合规替代。

**三、溯源与交易凭证**
1. 每批送货单/销售凭证，写明品名、产地、数量、采摘/生产日期、批次号、供应商盖章或签字。
2. 产地证明或采购来源说明，能追溯到种植基地/合作社/批发市场。
3. 供应商联系人、紧急召回联系方式。

**四、储运与过程控制证明**
1. 运输车辆/冷链温控记录（需冷藏水果适用），到货测温记录。
2. 供应商食品安全管理制度、虫害控制、清洗消毒、人员健康管理等文件；小供应商可要求简版承诺。
3. 如供应商负责切果、鲜切水果，则按即食食品要求：食品经营许可、从业人员健康证、切配间卫生与冷链证明、微生物检测报告。

**五、茶饮店内部留档与验收动作**
1. 建立供应商档案：证照有效期台账，到期前提醒更新。
2. 每批到货验收：感官检查（霉变、破损、异味）、温度、数量、合格证/检测报告批次核对；不合格拒收并记录。
3. 索证索票保存期限不少于产品保质期满后6个月；无明确保质期的，保存不少于2年（以当地监管要求为准）。
4. 对高风险水果（如草莓、葡萄、柑橘类等）提高抽检频次，可自建快检或委托第三方。

**判断标准**：证照在有效期内、批次检测/合格证与到货一致、可追溯到产地、储运温度合规，才算风险可控；缺批次合格证明或检测报告与实物不对应的，不建议收货。
