优先结论：**如果主打现制果茶、门店有基础切配能力，买鲜果最稳；想省人工且出品稳定，选冷冻果丁/果肉；果泥只适合做调味、打冰沙或标准化拼配，不建议作为“菠萝果茶”的主要卖点。**

按你的场景分：

1. **鲜果**
   - 适合：招牌菠萝果茶、现切现捣、强调新鲜感。
   - 优点：香气和口感最好，顾客感知强，可做装饰。
   - 缺点：损耗高、成熟度不稳定、切配费人工，菠萝还有品种和季节差异。
   - 采购建议：选成熟度适中、香气足、纤维不要太粗的品种；到店后控熟、冷藏，按日用量订货。

2. **冷冻果丁/果肉**
   - 适合：连锁店、高峰期出杯、需要稳定甜酸和果肉感。
   - 优点：省切配、损耗低、批次稳定，解冻后可直接捣压或做果肉底。
   - 缺点：香气略弱于鲜果，解冻和保存不当会影响口感。
   - 采购建议：看配料表，优先“水果+糖/水”简单配方；试解冻后的出水、纤维感和香气；确认冷链和复冻风险。

3. **果泥**
   - 适合：做风味基底、冰沙、混合果茶、标准化调饮。
   - 优点：出杯快、甜酸稳定、几乎无切配损耗。
   - 缺点：果肉感和新鲜感弱，容易显得“酱感”，单杯成本不一定低。
   - 采购建议：看果浆含量和糖度，别只看“菠萝味”；先小样测试与茶底、柠檬、百香果的兼容性。

**实操建议：**
- 单店/少量SKU：**鲜果为主 + 少量冷冻果丁备用**，兼顾卖点和高峰稳定。
- 连锁/多SKU/高单量：**冷冻果丁做主力 + 鲜果做装饰或限定款**。
- 果泥：只作为辅助原料，不做唯一菠萝来源。

采购前先做小样对比：同一茶底、同一糖酸度下测**香气、果肉感、出杯速度、损耗率、单杯成本**，再决定组合比例。
