核心原则：**采购熟度要按“到店后能卖几天”来倒推，不要按“今天看起来最好”来选。** 对多数水果店，菠萝采购以**七八成熟**最合适：果肉已开始转黄、香气初现，但按压仍有一定硬度，到店后还能经历1–3天销售期。

### 判断熟度的可操作方法

1. **看果皮颜色**
   - 青绿为主、仅底部微黄：偏生，适合预计2–3天后才卖完或天气热、周转慢时少量采。
   - 果皮约1/3–1/2转黄，绿色仍明显：**七八成熟，通常最稳。**
   - 大面积金黄、绿很少：已接近即食，只适合当天或次日能卖完的量。
   - 出现褐斑、软塌：过熟或开始坏，不要采。

2. **看果眼和底部**
   - 果眼扁平、缝隙小，说明发育较充分；果眼很深很尖通常偏生。
   - 底部（果柄对面）微黄、干燥，问题不大；底部发黑、渗汁、有酒味，说明内部已过熟或腐烂。

3. **按压手感**
   - 轻按果身中下部：硬中带一点弹性，适合采购。
   - 明显能按下去、发软：已熟，损耗风险高。
   - 硬得像石头：偏生，需放熟，适合有催熟/陈列空间的店。

4. **闻香气**
   - 靠近底部闻：有淡淡菠萝香，说明开始成熟。
   - 香气浓、带酒味或酸腐味：过熟或变质。
   - 完全没香味：偏生。

5. **看叶片和果柄**
   - 冠芽青绿、挺立，果柄切口新鲜，说明采后时间短。
   - 叶片枯黄、果柄干黑，存放已久，熟度再合适也容易损耗。

6. **掂重量**
   - 同样大小，手感沉的水分足、果肉饱满；明显轻飘的可能失水或内部空心。

### 采购时按销售节奏定比例

- **当天能卖完的陈列量**：可采部分**八九成熟**，颜色黄、香气足，卖相好。
- **主力库存**：采**七八成熟**，果皮1/3–1/2转黄、按压微弹。
- **备货/周转慢**：采**六七成熟**，青绿为主、底部微黄，到店后分级催熟。
- **天气热、店内无冷藏**：整体降半档熟度采购，宁可稍生，不要采软果。
- **整批抽样**：每批随机拿5–10个，按“看色、按压、闻底”三项交叉判断，不要只看最上面一层。

### 降低损耗的配套动作

- 到店后**分级**：黄熟的放前台快销或做果切，青的单独存放。
- 菠萝**不要整批叠压**，果眼和底部易压伤；底部朝下、通风摆放。
- 发现底部发软、酒味、渗汁的，立即挑出，避免传染。
- 切开售卖或做果切的，优先用八九成熟的；整果零售可保留部分七八成熟的。

一句话：**采购选“黄三分之一、按着微弹、底部有淡香”的菠萝最稳；卖得慢就再青一点，卖得快再黄一点。**
