对餐饮连锁采购水果，**多数情况下更适合“中央厨房统一收货 + 门店按需配送”**，但要看水果品类、门店密度、配送能力和损耗结构。不能一刀切。

**判断建议：**

1. **优先中央厨房统一收货的情况**
   - 门店数量多、分布相对集中，配送半径可控。
   - 水果主要用于中央厨房加工、切配、榨汁、烘焙或标准化出品。
   - 采购量大，需要统一品控、统一供应商、统一账期和议价。
   - 希望集中做农残检测、验收分级、称重扣损、批次追溯。
   - 门店不具备专业验收能力，容易收货标准不一。

2. **更适合门店分开收货的情况**
   - 水果是整果、鲜食、陈列型商品，对新鲜度和卖相要求极高。
   - 门店分散、配送半径大，中央厨房二次分拣和运输会造成明显损耗。
   - 单店销量小但品类多，集中配送后容易压货或频繁拆零。
   - 门店有成熟的验收能力和冷链暂存条件。
   - 供应商可稳定直送门店，且价格、品质、时效可控。

3. **更稳妥的混合模式**
   - **中央厨房统一收货**：适合耐储、标准化、加工用水果，如苹果、柠檬、冷冻果、罐头替代类。
   - **门店直收**：适合高鲜度、易损、陈列型水果，如草莓、蓝莓、鲜切果、时令爆品。
   - **统采统签、分仓分收**：总部统一供应商和价格，中央厨房收加工类，门店收鲜食类，统一验收标准和抽检机制。

**关键决策指标：**
- 水果损耗率：中央统一收货后二次配送损耗是否低于门店直收损耗。
- 配送成本：冷链车、频次、拆零拣配成本是否可覆盖。
- 品控能力：门店能否按标准验收糖度、成熟度、农残、外观。
- 库存周转：中央厨房是否会造成门店压货和鲜度下降。
- 追溯与食品安全：统一收货更利于批次管理和责任界定。

**落地建议：**
先做 **1个月对比试点**：选2—3个代表品类和5—10家门店，对比“中央统一收货配送”与“门店直收”的到货合格率、损耗率、单店配送成本、缺货率和客诉率。若中央配送损耗增加超过3—5个百分点，或门店鲜度客诉明显上升，就应改为分类收货。总体原则是：**加工用果集中收，鲜食易损果门店收，总部统管标准和供应商。**
