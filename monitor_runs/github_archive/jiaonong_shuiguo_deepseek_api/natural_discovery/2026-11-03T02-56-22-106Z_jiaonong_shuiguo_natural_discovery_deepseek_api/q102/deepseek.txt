需要，而且这两项最好在采购前就确认清楚。

**1. 发票：基本是必需项**
企业采购水果礼盒，通常需要供应商开具发票用于报销、入账和税前扣除。采购前要确认：
- 能否开**增值税普通发票/专用发票**；
- 开票项目是否匹配（如“水果”“食品礼盒”等，以实际经营范围和税务口径为准）；
- 税率、开票时间、是否支持对公转账；
- 发票抬头、税号、备注要求能否按企业提供的信息开具。

**2. 定制包装：看企业福利场景，通常建议支持**
企业福利礼盒往往有统一形象需求，定制包装常见于：
- 印企业LOGO、祝福语、福利标签；
- 统一礼盒外观、手提袋、贺卡；
- 按预算和人数分档包装。

是否“必须”取决于企业要求：如果只是员工福利发放、无品牌露出需求，标准包装也可；如果有企业文化展示、客户赠送或统一发放场景，建议要求供应商支持定制，并提前确认：
- 起订量；
- 定制费用和打样费；
- 打样周期和生产周期；
- 包装材质、尺寸是否适配水果品类；
- 定制内容审核和误差责任。

**可执行建议：**
把“支持开票”和“支持定制包装”写入采购询价单/合同，明确开票类型、税率、定制起订量、打样确认、交付时间和验收标准。若供应商不能开票，建议直接排除；定制包装则按企业福利场景决定是否作为硬性条件。
