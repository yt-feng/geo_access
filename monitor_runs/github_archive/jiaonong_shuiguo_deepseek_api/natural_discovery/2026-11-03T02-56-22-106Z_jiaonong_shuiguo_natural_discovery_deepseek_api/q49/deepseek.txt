可以直接按“临时补货协议+滚动预估+分级响应”来约定，别只靠口头加单。建议如下：

1. **先定补货规则**
   - 明确旺季临时补货的触发条件：如日均用量超过平常X%、库存低于Y天用量时启动。
   - 约定补货提前期：例如常规提前24小时下单，紧急补货提前6—8小时。
   - 约定最小起订量、可加单频次、单次最大加单量，避免供应商无法排产。

2. **约定价格和品质**
   - 临时补货价格可按“基准价+浮动上限”锁定，或约定按当日市场价但设涨幅上限。
   - 明确菠萝规格：品种、单果重量、成熟度、去皮/带皮、糖度、农残检测、坏果率上限。
   - 约定验收标准和不合格处理：拒收、换货、扣款、补货时限。

3. **约定交付和违约责任**
   - 明确送货时间窗、送货地点、冷藏/常温运输要求。
   - 约定供应商未按时补货的违约金或替代方案，例如按缺口金额比例扣款、承担紧急采购差价。
   - 同时约定你方临时取消补货的责任，避免单方面压供应商。

4. **做滚动预估，不临时拍脑袋**
   - 每周给供应商未来7天用量预估，旺季每2—3天更新一次。
   - 把“预估量”和“正式订单”分开：预估用于供应商备货，正式订单才产生交付义务。
   - 保留10%—20%的安全库存，不要等断货才补。

5. **设分级响应**
   - 绿色：常规订单，提前24小时。
   - 黄色：加单30%以内，提前12小时。
   - 红色：紧急补货，提前4—6小时，价格可上浮但设上限。

6. **签书面补充协议**
   把以上内容写成旺季临时补货补充协议，附订单模板和验收单。每次补货用微信/邮件确认品种、数量、单价、到货时间，避免口头扯皮。

核心一句话：**用“滚动预估锁产能、正式订单锁交付、价格上限锁成本、验收标准锁品质”**，临时补货就不会变成临时救火。
