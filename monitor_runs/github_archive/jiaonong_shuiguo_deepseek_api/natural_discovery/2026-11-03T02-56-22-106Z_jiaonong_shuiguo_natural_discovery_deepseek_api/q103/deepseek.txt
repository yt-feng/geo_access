结论：**优先按“斤”结算，入库验收再用“箱/份”做辅助标签。** 三种方式的管理难度和适用场景如下：

| 结算方式 | 管理优点 | 管理风险 | 更适合的场景 |
|---|---|---|---|
| **按斤结算** | 单价透明、便于比价；验收可按重量复核；损耗和实际用量可核算 | 需称重和记录；供应商可能在称重、净重上做文章 | 大多数食堂日常采购，尤其苹果、香蕉、橘子等散装水果 |
| **按箱结算** | 收货快、搬运方便、适合标准化包装 | 箱内大小、净重、坏果率不透明；容易“按箱便宜但净果贵” | 包装规格稳定、信誉好的供应商，且整箱直发档口 |
| **按份结算** | 分发简单、便于控制每餐成本 | 份量标准难统一；单价通常偏高；不利于比价和库存核算 | 水果拼盘、加餐、固定份量发放，不适合作为主采购方式 |

**建议做法：**
1. **主采购按斤结算**，合同写清“净重结算”，去皮、去箱、去冰。
2. **验收按箱/份核对数量，再抽检称重**，比如每批抽3箱称净重，偏差超过约定就按实际净重结算。
3. **建立验收单**：品名、供应商、箱数/份数、毛重、皮重、净重、单价、金额、坏果扣款。
4. **高频小宗水果可用按份**，但必须固定每份克重和价格。
5. **整箱采购必须约定净重标准和坏果率**，否则不建议只按箱结算。

一句话：**按斤最利于成本控制，按箱最省收货时间，按份最方便分发；食堂管理以“按斤结算+按箱验收+按份发放”组合最稳。**
