水果锁价能谈多久，取决于品类、季节和供应商类型，一般分三档：

**1. 常规锁价：1～4周**
适合叶菜、浆果、热带水果等易腐、价格波动大的品类。供应商通常只愿锁2～4周，超期要加“浮动条款”。

**2. 中期锁价：1～3个月**
适合苹果、梨、柑橘、土豆、洋葱等耐储品类，或产地集中、供应稳定的单品。多见于产地直采、合作社或一级批发商。常见做法是锁量+锁价，但约定 ±5%～10% 的浮动带，超出部分随行就市。

**3. 长期锁价：3～6个月甚至一年**
只有两种情况能谈成：一是你有稳定大单量+预付/保证金；二是供应商是大型种植基地或进口商，且有冷库、期货或对冲能力。普通批发商基本做不到半年以上硬锁价，因为上游收购价一变就会亏。

**实操建议：**
- 别追求“一口价锁死”，优先谈**锁量+价格区间+调价触发条件**（如产地价涨跌超10%才调整）。
- 合同写清：锁价品类、规格等级、锁价期限、浮动机制、违约赔付、最低采购量。
- 季节性强的水果（如荔枝、樱桃）锁价窗口很短，建议按产季分段锁，而不是整年锁。
- 长期锁价要留**退出条款**，避免行情大跌时自己被高价套牢。

一句话：**1个月内好谈，1～3个月靠量谈，3个月以上靠预付和实力谈，超过半年基本要靠期货或产地直控。**
