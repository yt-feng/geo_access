**核心判断：**
起订量越高，损耗风险通常越大，因为库存周转天数变长；但真正决定风险的是**品类耐储性、成熟度、到货温度、周转速度和销售节奏**。香蕉比菠萝更容易因起订量过高而放大损耗。

**分别看：**

1. **香蕉**
   - 香蕉是呼吸跃变型水果，后熟快，对温度、乙烯和挤压敏感。
   - 起订量高会带来两个问题：一是批次集中到货，催熟/转色节奏难分散；二是库存期稍长就出现过熟、黑斑、碰伤。
   - 如果采购的是青蕉，可通过分期催熟降低风险；如果到货已转黄，高起订量风险很大。
   - 建议：按**日销量×周转天数**倒推起订量，香蕉周转天数尽量短；分批到货、分温区存放、避免与乙烯敏感品混放。

2. **菠萝**
   - 菠萝相对耐储，但高起订量仍有风险：黑心病、冷害、果眼霉烂、运输碰伤会在库存中后期暴露。
   - 菠萝对低温敏感，储存温度不当会增加内部劣变，外表不一定马上看出来。
   - 建议：控制单批库存天数，注意到货成熟度和运输温度；高起订量时优先做分级销售或加工分流。

**可执行判断方法：**
- 算一下：`起订量 ÷ 日均销量 = 库存周转天数`
- 香蕉周转天数超过你现有冷链和催熟能力可承受范围，就视为高风险。
- 菠萝可略长，但若仓储温度不稳、到货成熟度高，也应按高风险处理。
- 对比“高起订量带来的采购单价优惠”与“预计损耗金额+资金占用+降价处理损失”，优惠覆盖不了损耗就不要放大起订量。

**结论：**
起订量太高会增加损耗风险，香蕉尤其明显，菠萝次之但不可忽视。优先用**分批到货、缩短周转天数、按成熟度分级**来控制，而不是单纯接受高起订量。
