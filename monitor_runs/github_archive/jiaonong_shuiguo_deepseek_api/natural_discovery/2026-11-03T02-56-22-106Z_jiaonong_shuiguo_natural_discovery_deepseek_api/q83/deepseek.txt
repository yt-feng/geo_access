先给结论：**坏果责任不能一概而论，核心看“坏果发生在哪个环节”和“平台/商家是否已尽到告知与保鲜义务”。** 实务上可按下面几步判断和划分。

## 一、先分坏果类型

1. **运输/仓储环节造成的腐烂、压伤、冻伤、闷坏**
   - 到货即坏、外箱有明显水渍/挤压/异味、同批次多人投诉。
   - 一般由**商家/平台承担主要责任**，因为交付前风险在卖方，且生鲜对冷链、包装、时效有更高要求。
   - 平台自营的由平台担；商家入驻的，平台若仅提供交易场所，通常先由商家担，平台在未尽审核、赔付承诺或“先行赔付”规则下承担相应责任。

2. **商品本身隐蔽瑕疵（外观正常、切开内部坏）**
   - 如“外好内烂”、霉心、黑心。
   - 仍原则上由**商家承担**，因为消费者收货时难以发现，属于交付时质量不符合约定。
   - 但消费者应在合理时间内切开/食用并留存证据；拖太久才主张，举证难度上升。

3. **顾客收货后存放/处理不当**
   - 如未及时冷藏、暴晒、挤压、放置数日才投诉。
   - 由**顾客自行承担**，商家可拒绝赔付。
   - 关键看：到货时间、商品要求的储存条件、顾客是否及时开箱和保存证据。

4. **正常生鲜特性与“坏果”的边界**
   - 轻微表皮擦伤、个别小瑕疵、成熟度差异，若商家已明确标注“次果/瑕疵果/规格差异”，一般不构成质量问题。
   - 但**霉变、腐烂、异味、明显压烂**不属于正常瑕疵。
   - 商家若以“生鲜不支持退换”一概拒赔，通常不能免除其质量责任；但可约定合理的赔付比例和举证方式。

## 二、责任划分的实操规则

可以按“**交付前风险归卖方，交付后保管风险归买方，平台按角色担责**”来分：

| 情形 | 主要责任方 | 处理建议 |
|---|---|---|
| 到货开箱即发现腐烂、压坏、异味 | 商家/平台 | 拍照录像、称重/计数坏果，按坏果比例退款或补发 |
| 外箱完好但内部霉变、黑心 | 商家 | 顾客及时切开留证，商家按质量问题赔付 |
| 同批次大量投诉 | 商家/平台 | 可能涉及冷链或品控问题，平台应介入并排查 |
| 顾客延迟数日才开箱 | 顾客举证责任加重 | 视储存条件和证据协商部分赔付 |
| 顾客未按标注冷藏 | 顾客 | 商家可拒赔或部分补偿 |
| 商家已明确标注瑕疵且价格对应 | 商家责任减轻 | 按事先约定处理，但不能掩盖腐烂霉变 |

## 三、建议的处理流程

1. **顾客侧**：到货后尽快开箱，拍外箱、面单、坏果整体和特写，保留坏果，不要立即丢弃；24小时内发起售后。
2. **商家侧**：先看证据和到货时长，区分“个别瑕疵”与“腐烂变质”；能补发优先补发，不能补发按坏果比例退款。
3. **平台侧**：有“坏果包赔/坏单包退”规则的按规则执行；商家不处理的，平台可先行赔付再向商家追偿。
4. **争议大时**：看同批次投诉、物流时效、冷链记录、包装方式；必要时由平台客服或消协调解。

## 四、一句话判断

**到货时已坏或短时间内存放即坏，原则上商家/平台担责；顾客收货后因保管不当导致坏果，顾客担责；轻微瑕疵且已明确告知的，按约定处理。** 商家不能用“生鲜不退换”完全免责，顾客也不能把收货后放坏的责任转嫁给商家。
