对小水果店来说，这四项不能平均用力，建议按这个顺序判断：

**1. 坏果率（最优先）**
香蕉是易损、易催熟的水果，坏果率高会直接吃掉毛利。进价再低，烂掉两三成也不划算。应优先看：
- 到货开箱后的实际坏果比例；
- 是“表面好、里面烂”还是少量碰伤；
- 供货方是否包退换、怎么赔。

**2. 熟度（第二优先，且要匹配你的销量）**
熟度决定你能不能当天卖完。小店客流有限，进太青的香蕉回熟慢、占资金；进太黄的又容易当天卖不完变黑。建议：
- 日常进货选“微黄偏青、2～3天能卖完”的熟度；
- 夏天或客流慢时更偏青一点，冬天或周末前可略黄；
- 固定让供货方按你的销售节奏分级供货。

**3. 价格（第三优先，在坏果率和熟度合格后再比）**
香蕉价格透明、毛利薄，低价很重要，但必须建立在“坏果少、熟度可控”的基础上。否则低价只是把损耗风险买回来。比价时要算**到手可用成本**：进价÷可售比例，而不是只看每斤报价。

**4. 送货速度（看情况，通常排在最后，但要有底线）**
如果供货稳定、你每天能按需少量补货，速度要求可以低一些；如果店里库存小、靠高频补货，送货速度就很重要。关键不是“越快越好”，而是**是否稳定、是否按约定时间到**。经常迟到、打乱陈列和销售节奏的供应商，即使便宜也应降级。

**可执行做法：**
- 先定规矩：坏果率超过约定比例必须退换；熟度按你销量分档；送货迟到影响销售要有说法。
- 连续试2～3家供应商，每周记录：进价、到货坏果率、可售天数、迟到次数、退换是否爽快。
- 选“综合到手成本最低、最稳定”的那家为主，另一家做备选。

一句话：**小水果店进香蕉，先保坏果率和熟度，再谈价格，送货速度保证稳定即可。**
