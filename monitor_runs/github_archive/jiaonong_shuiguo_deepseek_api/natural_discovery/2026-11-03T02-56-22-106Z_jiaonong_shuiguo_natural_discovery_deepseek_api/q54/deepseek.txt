优先关注**成熟度**，价格是次要因素。原因是香蕉在烘焙里的作用不只是“提供香蕉味”，还影响甜度、水分、组织结构和上色：

1. **成熟度决定风味和配方调整**
   - 七分熟：偏硬、甜度低、香气弱，适合需要果肉块的装饰，但做香蕉泥蛋糕风味不足。
   - 全熟带少量黑点：甜度和香气最好，适合大多数香蕉蛋糕、马芬、磅蛋糕。
   - 过熟发黑：香气最浓、甜度最高，适合做香蕉泥，但酸味和发酵味风险增加，且要相应减糖、注意水分和保质期。

2. **价格低但成熟度不对，反而增加成本**
   - 买太生的香蕉，需要额外催熟、占用仓储时间，风味也不稳定。
   - 买过熟打折香蕉，若当天用不完，损耗和报废率会上升；做出来批次风味也容易波动。
   - 对烘焙店来说，**稳定出品比单次采购单价更重要**。

3. **可执行的采购建议**
   - 以“**表皮金黄、带少量黑点、手感稍软但不烂**”为采购标准。
   - 按用途分批采购：近期要用的买全熟；备货的买七至八分熟，在店内自然催熟。
   - 跟供应商约定成熟度等级，而不是只谈价格；到货抽检硬度、黑点比例和有无破损。
   - 如果价格明显低于市场，先确认是否过熟、碰伤或冷链受损，再决定是否用于当天打泥。

结论：**成熟度优先，价格在满足成熟度标准的前提下再比较。** 只有当你做的是需要果肉块、且后续会加工装饰的产品时，才可以适当接受偏生一点的香蕉，但仍不应把价格放在成熟度之前。
