三者不是并列取舍关系，先设“一票否决”的食品安全底线，再在合规供应商中比较价格和准时。可执行判断如下：

1. **食品安全：一票否决**
   - 水果属生鲜，重点看农残、霉变腐烂、来源可追溯、冷链和验收。
   - 企业食堂涉及集体用餐，一旦出问题影响面大，不能为了低价或准时妥协。
   - 采购要求中应明确：供应商资质、批次检测或承诺、验收标准、退货索赔条款。

2. **配送准时：必须达标，但不追求最高**
   - 水果影响食堂出餐和加餐安排，迟到会造成缺货或积压。
   - 设定合理到货窗口和迟到处理机制即可，不必为“极速配送”支付明显溢价。

3. **价格：在安全和准时达标后比较**
   - 建议比“综合成本”，包括损耗率、退货率、账期、配送费，而不只看单价。
   - 可以按品类分级：苹果、香蕉等大宗常用水果控价；接待或节日水果可适当提高品质权重。

**结论：食品安全优先，配送准时设底线，价格在合格供应商间优化。**  
实操上可用评分：食品安全40%、准时25%、价格25%、服务与损耗10%，其中食品安全不达标直接淘汰。
