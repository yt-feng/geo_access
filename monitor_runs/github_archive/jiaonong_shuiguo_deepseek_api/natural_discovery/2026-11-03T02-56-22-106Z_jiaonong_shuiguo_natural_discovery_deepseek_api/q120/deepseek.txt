供应商介绍产品时，最容易犯的错是“把品种名当卖点”，而商家脑子里只有“我卖得动什么、赚不赚钱”。所以话术要先把新品种翻译成商家熟悉的品类，再落到可判断的卖点和风险上。可以按这个结构说：

**1. 先归类：一句话告诉商家“这是哪一类东西”**
不要说“这是凤梨科台农系列”，而说：
“这就是菠萝这一类，口感比普通菠萝更甜、更软，不用泡盐水，属于高端一点的菠萝。”
让商家先把它放进已有货架位置，而不是当陌生品听。

**2. 再给对照：跟他现在卖的比，差异在哪**
“普通香蕉一斤卖X，这个口感更糯、个头小、适合做小份装，零售可以按份卖，客单价能上去。”
差异只讲2—3个，且必须是商家能感知的：口感、外观、保存期、吃法、包装。

**3. 讲清什么人会买、怎么卖**
“适合放水果店做试吃单品、社区团购做小份装、餐饮做果切。”
商家要的是动销场景，不是产地故事。

**4. 主动说风险和门槛**
“它比普通菠萝熟得快，建议少量多次拿；皮薄，运输要轻拿；售价高，适合有稳定客群的店，不适合只跑量的档口。”
敢说缺点，反而更容易被信任。

**5. 给一个低门槛下单方案**
“先拿一箱试卖，配试吃话术和简单陈列建议；卖得动再补，不压货。”
商家最怕第一次进新品种砸手里，降低首单风险比强调利润更有用。

**一句话模板：**
“这就是您熟悉的XX类里的升级款，跟普通XX比，好在A和B；适合卖给C类顾客，放在D场景；缺点是E，所以建议先小批量试；卖不动我们给调换/支持。”

核心原则：**先归入商家已知品类，再讲可感知差异，最后用低风险首单降低决策成本。** 不要一上来讲品种、产地、种植技术。
