建议先从**香蕉**试起，但把它定位为“稳定走量品”，而不是高毛利进口形象品。理由和操作判断如下：

1. **香蕉：优先试，最适合做稳定基础盘**
   - 消费频次高、价格敏感但接受度广，适合超市日常客流。
   - 供应相对连续，损耗可控的前提是抓成熟度和周转。
   - 关键风险是催熟和温控：香蕉对温度、乙烯、机械伤敏感。若超市没有稳定冷链和快周转，损耗会吃掉利润。
   - 建议小批量、固定供应商、按周复盘，先做普通进口/国产混合陈列，不要一上来做高端单品。

2. **菠萝：第二顺位，适合做差异化但别先押重**
   - 进口菠萝有品种卖点，客单和毛利可能更好，但消费频次低于香蕉。
   - 风险在成熟度不均、去皮损耗、季节性波动和消费者处理便利性。
   - 如果门店有果切/鲜切能力，菠萝更容易做出增量；没有的话先小规模试销。

3. **苹果：不建议作为“进口水果引入”的第一步**
   - 苹果国内供应强、消费者价格锚点低，进口苹果很难靠“进口”形成稳定优势。
   - 除非做特定高端品种和礼盒场景，否则容易陷入和国产苹果比价。
   - 它适合作为补充品类，不适合作为进口水果稳定化的首个突破口。

**执行建议：**
- 先选香蕉做4–6周试销：固定1–2个供应商，记录到货成熟度、损耗率、日销量、毛利率、缺货天数。
- 判断标准：损耗率能否稳定低于门店可承受线、周销量是否连续、是否出现明显价格倒挂。
- 香蕉跑通后再加菠萝，用果切或小规格降低尝试门槛；苹果最后作为高端补充，不做首推。
- 一句话：**先香蕉稳流量，再菠萝做差异，苹果只做补充。**
