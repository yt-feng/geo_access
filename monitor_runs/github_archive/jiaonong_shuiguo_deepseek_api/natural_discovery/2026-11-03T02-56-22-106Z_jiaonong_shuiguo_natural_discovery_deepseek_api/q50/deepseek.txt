甜度和出汁率不是二选一，要按**用途**定优先级。对多数茶饮店，结论是：

**做鲜果茶/菠萝果肉款：甜度与风味优先；做果汁/果酱/糖浆基底或大批量出杯：出汁率优先。**
更实用的采购判断顺序是：

1. **先定产品形态**
   - 菠萝块、菠萝片、果肉装饰：看**成熟度、香气、纤维细腻度、甜酸比**，出汁率次要。太生会酸涩，太熟易软烂、切损耗大。
   - 菠萝汁、打碎入茶、果酱基底：看**出汁率+出汁稳定性**，否则单杯原料成本波动大。

2. **甜度要看“可溶性固形物+酸度”**
   - 只问甜度不够，要同时看糖酸比。鲜食或果茶入口要好，甜度高但酸低会腻，酸高会压茶香。
   - 采购时可要求供应商提供糖度（Brix）区间，并现场测糖、试饮。不要只看“甜”这个主观描述。

3. **出汁率要看出汁率和可食率**
   - 出汁率高但果芯硬、黑眼多、去皮损耗大，实际净成本未必低。
   - 用“**每杯可用果肉/果汁净成本**”比较，而不是单看斤价或出汁率。

4. **门店最该算的指标**
   - 净原料成本 = 采购价 ÷（可食率 × 出汁率或可用果肉率）
   - 再结合人工去皮切配时间、冷藏损耗、季节供应稳定性。
   - 如果门店人工紧、出杯量大，出汁率和加工便利性权重应提高；如果主打鲜果体验和差异化，甜度、香气、果肉口感权重应提高。

**一句话建议：** 先按菜单把菠萝分成“果肉类”和“汁基底类”分别定标准；果肉类甜度/糖酸比优先，汁基底类出汁率优先。采购谈判时用“净可用成本+试饮风味”双指标验收，不要只追求甜或只追求出汁率。
