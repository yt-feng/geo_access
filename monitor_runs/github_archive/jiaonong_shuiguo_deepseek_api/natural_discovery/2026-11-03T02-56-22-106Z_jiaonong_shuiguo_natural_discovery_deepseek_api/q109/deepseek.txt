优先谈**账期**，其次**售后**，最后**配送**。但排序取决于你的品类和现金流，下面给可判断的依据。

**1. 账期最优先（现金流杠杆最大）**
- 水果是高频、易损耗、价格波动大的品类，账期直接决定你的资金周转和抗风险能力。
- 谈判空间通常最大：从现结/周结谈到月结、半月结，或阶梯账期（稳定采购量换更长账期）。
- 注意：账期不是越长越好，供应商可能把资金成本折进单价。要谈“账期+价格+质量”的组合，避免表面账期长、实际单价暗涨。

**2. 售后第二（直接决定损耗谁承担）**
- 水果核心风险是损耗、到货质量不达标、短斤缺两。售后条款不清晰，账期和配送谈得再好也会被损耗吃掉利润。
- 重点谈：坏果/烂果赔付比例、到货验收时限、拍照留证规则、补货或折价方式、责任划分（运输vs仓储）。
- 这一项谈清楚，能减少大量扯皮，比配送时效更影响实际成本。

**3. 配送第三（重要但可替代性较强）**
- 配送时效、频次、起送量、迟到处理值得谈，但多数供应商在配送上有标准能力，弹性不如账期和售后。
- 除非你是餐饮/零售对到货时间极敏感，否则配送放在前两项之后谈，避免用配送让步换掉账期或售后。

**建议谈判顺序**：先锁定售后责任（保护底线）→ 再谈账期（争取现金流）→ 最后用配送频次/起送量做交换筹码。若你现金流紧张，账期放第一；若你损耗率高、验收能力弱，售后放第一。

一句话：**账期决定你能不能活，售后决定你赚不赚，配送决定你顺不顺。**
