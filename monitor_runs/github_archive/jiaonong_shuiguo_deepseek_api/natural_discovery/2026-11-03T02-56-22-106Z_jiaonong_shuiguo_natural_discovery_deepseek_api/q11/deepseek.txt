会影响，但影响大小取决于你**怎么卖**和**卖给谁**。判断要点：

1. **影响最明显的场景**
   - 按箱/按斤统货卖：大小混杂会让顾客觉得“挑剩下的”，压价、挑拣、损耗都会增加。
   - 高端水果店、礼盒、精品陈列：大小不一会明显拉低卖相。
   - 同一价格下混装：大果被挑走、小果剩底，最后小果难卖。

2. **影响较小的场景**
   - 散客按斤自选、社区店、走量为主：顾客更看重新鲜度和价格，大小差异影响有限。
   - 明确分级卖：大果、中果、小果分开定价，反而能覆盖不同客群。
   - 用于切果、榨汁、甜品店供货：大小要求低，成熟度和口感更重要。

3. **采购建议**
   - 先问清楚箱内**规格是否均匀、是否混级**，最好开箱抽检。
   - 如果店铺定位精品，优先选分级均匀的货；如果走量，可以接受混级但必须**分开陈列、分开定价**。
   - 算账时把“挑拣损耗、剩货折价”算进成本，不要只看整箱进价便宜。
   - 香蕉还要看成熟度是否一致：大小不一常伴随成熟不均，这个比大小本身更影响销售。

**结论：** 大小不一定会毁销售，但“混在一起同价卖”会。能分级销售就影响可控；做精品或礼盒则建议直接采购均匀规格。
