做香蕉和菠萝这种高损耗品，售后控制的核心不是"出了问题怎么赔"，而是**把损耗挡在售后之前**。按环节拆：

## 一、选品和到货：从源头降低不可控损耗

**香蕉**
- 不要采购全熟蕉。到货应为"7成熟左右、带青"的状态，让它在用户手里完成最后1–2天成熟，而不是在你仓里熟。
- 按团购量分批进货，别一次囤大货。宁可少卖，不要压货——香蕉一天的过熟率就可能翻倍。
- 收货时抽检：有黑斑蔓延、指压软塌、断柄流汁的直接不入库，及时和供应商走索赔。

**菠萝**
- 优先选适合鲜食的品种（如金钻/凤梨类），避免酸涩、芯硬的普通品种，这类品种本身投诉率就高。
- 收货检查底部有无软腐、渗液、异味，这基本是烂心的前兆，别上架。

## 二、储存和履约：损耗高发就在这一段

- **香蕉**：不要冷藏（会黑皮、风味差），阴凉通风存放，挂起来或单层摆放减少挤压；分拣时轻拿轻放，断柄、压伤是主要售后来源。
- **菠萝**：直立或侧放通风，避免堆压和底部积水；切开的绝不能隔夜卖。
- **缩短从到货到用户手里的时间**：香蕉、菠萝尽量当天到、当天/次日配送，这比任何售后话术都有效。
- 分拣时**主动剔除**：把明显过熟、磕碰的挑出来，不混进正常订单。很多售后是因为"把尾货发给了用户"。

## 三、规则前置：把预期管理做在售前

- 商品页明确写清：香蕉到货带青、需自行催熟1–2天；菠萝有轻微酸涩属正常；并说明**售后标准和时限**（如签收后24小时内、提供照片）。
- 设置**合理的售后政策而非无脑全赔**：例如"坏果包赔、按比例赔（坏几个赔几个）"，而不是整单退款。政策写清楚，执行才不扯皮。
- 对高损耗品**不做夸大宣传**（"包甜""绝对不坏"最容易引来投诉）。

## 四、定价与结构：用组合和成本对冲

- 高损耗品的定价里要**预留损耗率**（香蕉、菠萝行业损耗常在5%–15%，按你的实际数据定），把损耗成本打进毛利，而不是靠砍价硬撑。
- 可以做**组合装/搭配销售**，把易损品和耐储品打包，降低单品损耗对整体利润的冲击。
- 记录每个批次的实际损耗率和售后率，倒推供应商和进货量——**数据是最有效的降损工具**。

## 五、售后执行：快、标准化

- 用户反馈坏果，**要求照片、按比例快速赔付**，不要纠结责任。高损耗品售后时效比"辩对错"更重要，快赔能保住复购。
- 建立简单台账：哪个供应商、哪批货售后高，下批就换或减量。
- 把售后数据反哺到选品和分拣标准里，形成闭环。

**一句话总结**：香蕉菠萝控售后 = 带青进货 + 快进快出 + 分拣剔除尾货 + 售前写清标准 + 按比例快赔 + 用数据倒推供应商。重点是前四项，售后只是兜底。
