判断供应商售后响应是否稳定，不能只听销售口头承诺，建议在合作前和试单期用“可验证动作”来测：

1. **合同里写清响应条款**
   - 明确售后受理渠道：电话、微信、邮件哪个算正式报障。
   - 写清响应时限：例如到货后2小时内反馈，供应商30分钟内确认，4小时内给处理方案。
   - 写清赔付标准：菠萝黑心、烂心、香蕉催熟不均/青软不一致等，按比例补货、折价还是退款，谁承担运费。
   - 写清举证方式：到货拍照、开箱视频、抽检记录，避免扯皮。

2. **首单前做“压力测试”**
   - 故意在非工作时间发一次售后问题，看是否有人接、多久回。
   - 报一个小的质量问题，观察对方是直接给方案，还是反复推诿要你找司机/找门店。
   - 要求供应商提供近3个月的售后处理记录或补货单样本，脱敏即可，看是否有真实处理痕迹。

3. **看其是否有专职售后/品控人员**
   - 问清楚对接人是不是销售兼售后。销售兼售后通常响应不稳定。
   - 要求提供品控或售后专员的姓名、电话、职责范围，并确认换人时提前通知。
   - 生鲜类供应商最好有固定装车质检和到货复检流程，能出具简单质检单。

4. **试单期设置考核指标**
   - 连续2—4周记录：报障次数、首次响应时间、解决时长、补货到位率。
   - 建议门槛：首次响应不超过30分钟，当天给方案，补货48小时内到位；达不到就降量或换供应商。
   - 每次售后都留书面记录，微信也算，月底让供应商签字或邮件确认汇总。

5. **多源验证**
   - 问同区域其他商超采购，该供应商售后是否稳定，重点问“出问题后拖不拖”。
   - 查供应商是否给大型商超供货，大客户通常有更明确的售后约束，可侧面了解其履约习惯。
   - 看其是否有冷链和催熟能力：香蕉售后很多不是“坏”，而是催熟和配送温控不稳，有稳定催熟库和冷链的供应商售后更可控。

6. **用付款和备选供应商制衡**
   - 保留一定质量保证金或账期尾款，售后未闭环不结清。
   - 同时保留1—2家备选供应商，避免单一供应商售后拖沓时影响门店销售。

实操上，最有效的是：**合同写时限和赔付 + 首单故意报一次小售后测试 + 试单期记录响应数据**。三件事做完，基本能判断对方售后是“真稳定”还是“嘴上稳定”。
