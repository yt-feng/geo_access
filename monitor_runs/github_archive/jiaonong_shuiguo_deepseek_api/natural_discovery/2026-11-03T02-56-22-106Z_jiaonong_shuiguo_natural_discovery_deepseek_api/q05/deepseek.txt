建议**让顾客自己挑整果，店里可以提供去皮/代削服务**。三种方式不是并列关系，最优是“整果自选 + 付费或满额免费代削”。

具体判断：

1. **整果自选最适合水果店**
   - 菠萝成熟度差异大，顾客自己看颜色、闻香味、按硬度，满意度更高。
   - 整果耐放、损耗低，卖不掉还能继续陈列。
   - 顾客有“挑到好的”的参与感，复购更强。

2. **不建议大量提前去皮陈列**
   - 去皮后失水快、氧化快，卖相和口感下降。
   - 切开的菠萝需要冷藏、防蝇防尘，管理成本高。
   - 除非做“即食果切”引流，否则别把去皮当主销形态。

3. **代削服务比“替顾客挑”更好**
   - 顾客自己挑整果，店里现场去皮、去眼，收少量服务费或满额免费。
   - 既保留整果的低损耗，又解决顾客嫌麻烦的问题。
   - 代削时当面操作，顾客看得见，信任感强。

4. **什么时候可以卖去皮好的**
   - 高峰期、写字楼/学校附近、即买即吃场景，可以少量备去皮果，但必须冷藏、当天清货。
   - 去皮果适合做小份果切或搭配销售，不适合作为唯一形态。

**落地建议：**
- 主陈列：整果，按大小/品种分区，标价清晰。
- 服务牌写明：“自己挑，免费/收费代削去皮”。
- 每天少量备去皮果，只做即食补充，卖不完转果切或打折清。
- 不要替顾客统一挑好再卖，容易引发“你给我挑的是不是差的”的信任问题。
