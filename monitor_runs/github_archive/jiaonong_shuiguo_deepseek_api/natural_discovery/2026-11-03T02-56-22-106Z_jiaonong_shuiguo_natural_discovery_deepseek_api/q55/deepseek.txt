做水果拼盘想更划算，核心不是买最便宜的，而是按“出成率×单份成本×稳定供货”来选规格。可以按下面判断：

1. **苹果：选中等偏大、规格整齐的散装或大箱二级果**
   - 拼盘用苹果主要看切面白净、脆度、耐氧化。单果 **180–220g** 左右最合适，太大切出来份量难控，太小削皮去核损耗高。
   - 更划算的买法：**整箱统货/二级果**，但要求果径均匀、无明显碰伤。餐厅用果不追求礼盒级外观，二级果通常比精品果便宜不少。
   - 避坑：不要买特价小果，削皮去核后出成率低；也不要买礼盒大果，溢价高。

2. **橙子：选果径均匀、皮薄易剥的当季散装中大果**
   - 拼盘橙子要切瓣或去皮，出成率关键在皮厚和籽。优先选**当季、皮薄、少籽**的品种，单果 **200–250g** 比较稳。
   - 更划算的买法：**按箱买当季统货**，现场抽检皮厚和汁水；如果只做装饰瓣，可买稍小但均匀的果，降低单份成本。
   - 避坑：进口精品橙和礼盒橙溢价高，除非菜单明确标注品种；皮太厚的橙子出成率明显低。

3. **菠萝：选固定规格的去皮/带皮整果，按出成率算**
   - 菠萝损耗最大，重点看**去皮去眼后的净重**。带皮菠萝单果 **1.2–1.5kg** 通常比较适合餐厅，太大一次用不完易氧化，太小处理麻烦。
   - 更划算的买法：如果后厨人手紧，直接对比**去皮菠萝净重价格**；如果人手够，买带皮整果通常单价更低，但要算去皮损耗。
   - 避坑：不要只看“一个多少钱”，要折算成**每100g可食用净成本**。

**直接可执行的比价方法：**
- 每种水果抽3–5个称重，记录：毛重、去皮去核后净重、坏果率。
- 算：`单份净成本 = 采购价 ÷ 可食用净重 × 每份用量`。
- 优先选：**净成本低、规格稳定、当季供应足**的规格，而不是单纯单价最低。

**简单结论：**
- 苹果：中等偏大、整箱二级果最划算；
- 橙子：当季皮薄少籽的中大果、按箱统货；
- 菠萝：带皮整果看净出成率，忙时选去皮净果。
- 三者都建议**固定果径/单果重区间**，减少切配浪费和份量波动。
