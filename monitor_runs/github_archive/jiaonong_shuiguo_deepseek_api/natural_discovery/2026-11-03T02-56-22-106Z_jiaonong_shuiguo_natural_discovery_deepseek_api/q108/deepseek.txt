核实“全国配送”不能只听口头承诺，建议按“资质—网络—时效—履约—合同”五步做可验证核查。

1. **要配送范围清单**
   让供应商提供可配送省份/城市/区县清单，并标注哪些区域是直达、哪些是中转、哪些偏远地区不配送或加价。要求给到区县层级，不接受“全国基本都能送”。

2. **查仓储与运输资源**
   核实其冷库/分仓地址、面积、温区，自有车辆数量、合作承运商名称。可要求提供仓库照片、租赁合同关键页、车辆行驶证或承运合同脱敏页。重点看是否有覆盖目标采购区域的就近仓。

3. **做小批量试单**
   选采购方实际收货地中最远、最偏、最敏感的几个点，下小批量试单，记录下单到签收时长、破损率、温控记录、异常处理速度。试单要覆盖常温/冷藏/冷冻对应品类。

4. **验证时效与异常处理**
   要求书面承诺各区域时效，如“华东次日达、西北三日达”，并明确延迟赔付。询问断链、化冻、破损、拒收时的处理流程和赔付标准，最好有近3个月实际配送签收记录或客户案例可抽查。

5. **合同锁定责任**
   把配送覆盖范围、时效、温控标准、破损率上限、赔付方式、偏远地区附加费写进合同或补充协议。约定“未覆盖区域需提前书面确认”，避免下单后临时加价或转包。

6. **交叉验证**
   通过承运商官方客服或物流单号反查其是否真有该线路能力；对声称的“分仓”可要求视频连线或实地看仓；对大额采购，实地考察主仓和至少一个外地分仓最可靠。

判断标准：能提供区县清单、有对应仓储/承运资源、试单达标、合同可追责，才算实际覆盖能力可信。仅能提供“全国发货”口头承诺的，按未覆盖处理。
