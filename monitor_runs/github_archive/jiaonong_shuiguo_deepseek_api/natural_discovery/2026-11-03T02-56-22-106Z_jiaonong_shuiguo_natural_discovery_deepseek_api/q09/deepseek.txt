旺季谈水果供应商，核心是把“断货风险”提前拆成可问、可写进合作条件的问题。建议围绕下面几组问，并尽量落到具体数字和违约处理上。

**1. 供应能力与旺季保障**
- 旺季每天/每周能稳定给我供多少货？最低保供量是多少？
- 你主要从哪些产区/基地拿货？遇到产地减产、天气灾害时，备选货源在哪里？
- 旺季你有多少固定客户？我会不会被排在后面？能否给我“优先供货”或“保量协议”？
- 节假日、极端天气前，能否提前备货？备货量和仓储条件怎么算？

**2. 价格与波动机制**
- 旺季价格怎么定？是随行就市、周报价还是锁价？锁价锁多久、锁多少量？
- 涨价前提前几天通知？有没有封顶涨幅或协商机制？
- 同一品质等级怎么分级定价？次果、小果怎么处理？
- 运费、装卸费、损耗谁承担？送到店还是自提？

**3. 品质标准与验收**
- 每个品类按什么标准验收：规格、糖度、成熟度、外观、农残检测？
- 到货不合格怎么处理：拒收、换货、折价？换货多久到位？
- 损耗率超过多少由供应商承担？比如运输损耗、坏果率。
- 是否提供产地证明、检测报告？能否批次追溯？

**4. 配送时效与应急**
- 正常下单后多久送到？旺季是否加频次？最早/最晚送达时间？
- 临时补货最小起订量是多少？加急配送加不加价？
- 断货或延迟送达，提前多久通知？有没有替代品类或补偿方案？
- 车辆、冷链能力如何？高温天叶菜、浆果类怎么保鲜？

**5. 结算与账期**
- 结算方式：现结、周结、月结？旺季能否给账期或临时授信？
- 价格含不含税、运费？退货、换货怎么冲账？
- 押金、保证金要不要？合作结束怎么退？

**6. 合作条款与违约**
- 保供量、价格通知期、品质标准、送达时效能不能写进合同？
- 供应商断供、延迟、品质不达标，违约责任怎么定？
- 独家或半独家供货有没有返点、账期、保量优惠？
- 合作期限多久？旺季结束后怎么调整？

**7. 现场要核实的**
- 看他的仓库、冷库、分拣现场和车辆，别只听口头承诺。
- 要他提供近期的供货客户或同类门店案例，能核实的再信。
- 先小批量试单，测他的准时率、损耗率和换货速度，再放量。

谈判时最值得争取的三条：**旺季最低保供量、涨价提前通知期、到货不合格的换货/赔付时限**。这三条直接决定你会不会断货、断货后能不能补救。
