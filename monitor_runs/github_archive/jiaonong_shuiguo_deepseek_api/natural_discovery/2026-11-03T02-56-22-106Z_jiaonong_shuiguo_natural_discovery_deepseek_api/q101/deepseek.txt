酒店早餐水果供应，和供应商谈合作时重点抓这几件事：

1. **明确需求标准**
   - 写清品类、规格、等级（如苹果直径、香蕉每把根数、西瓜单果重量区间）、成熟度。
   - 早餐场景要“开餐即可用”：成熟度分批到货，避免一批全熟、一批生。
   - 明确允许的破损率、次果率、农残检测要求。

2. **供应稳定性比单价更重要**
   - 要求供应商说明产地、季节替代方案、缺货时的替换规则。
   - 问清备货能力、节假日/极端天气的保供措施。
   - 约定“缺货提前多久通知”，避免当天断供。

3. **价格与结算机制**
   - 不要只谈单斤价，要谈含税、含运费、含损耗后的到店成本。
   - 约定价格调整周期和依据（如批发市场行情、产地价），避免随意涨价。
   - 明确账期、结算方式、发票类型。

4. **配送与验收**
   - 固定配送时间，确保早于早餐备餐时间到货。
   - 明确验收标准：现场称重、抽检、温度要求（如需冷藏品类）、拒收条件。
   - 约定短斤少两、以次充好的处理方式（补货、扣款、终止合作）。

5. **食品安全与资质**
   - 查验营业执照、食品经营许可证、检测报告。
   - 明确农残、重金属等检测责任和频次。
   - 约定食品安全事故的责任划分和赔偿。

6. **合同关键条款**
   - 试用期/试供期，先小批量跑1—2周再签长约。
   - 最低供货量、独家/非独家条款、违约赔偿。
   - 退出机制：提前多少天通知、尾款处理、库存处理。

7. **备选供应商**
   - 至少保留1家备选，避免单一供应商卡脖子。
   - 平时小量测试备选供应商的响应和品质。

实操建议：先让2—3家供应商按你写的规格报价并试供一周，用“到店可用的净成本+断供风险”综合比价，而不是只看报价单最低价。
