采购时重点选“青一点、硬一点、无机械伤”的香蕉，回店后按成熟度分批存放并控制温湿度，就能明显延缓变黑。

可执行建议：

1. **采购标准**
   - 选**七八成熟、表皮偏青黄、手感硬实**的香蕉，不要买已经全黄、有黑点、软塌的。
   - 看**果柄和切口**：新鲜、干爽、无霉斑；切口发黑发霉的不要。
   - 避免**磕碰伤、压伤、裂口**，这些位置最先变黑。
   - 少量多次采购，甜品店用量稳定的话建议按2—3天用量进货，不要一次囤太多。

2. **到店后立刻处理**
   - 先**拆箱、散开通风**，不要闷在纸箱或塑料袋里，乙烯积聚会催熟。
   - 按成熟度分开放：青的、微黄的、熟的不要混放。
   - **不要水洗**，表面有水容易腐烂；有污渍用干布擦。
   - 检查并剔除已经碰伤、裂口、发软的，单独先用掉。

3. **存放方式**
   - 放在**阴凉通风处**，避免阳光直射、空调直吹和靠近热源。
   - 适宜温度大致**13—15℃**；不要放冰箱冷藏，低温会导致表皮变黑、果肉变坏。
   - 悬挂或单层摆放，减少挤压；不要堆叠太厚。
   - 远离苹果、梨、番茄等释放乙烯多的水果。

4. **催熟与延缓**
   - 太青的可以跟少量苹果一起放纸袋中催熟，但要及时取出，避免过熟。
   - 已接近成熟的香蕉尽快用于制作，或去皮后冷冻保存做奶昔、烘焙。
   - 每天检查一次，先熟先用，建立“先进先出”的使用顺序。

5. **甜品店特别注意**
   - 切片后容易褐变，可在使用前再切；切后可短暂浸泡淡盐水或柠檬水，但会影响风味，需按产品测试。
   - 展示柜不要长时间高温照射香蕉成品。

简单判断：**买青硬、拆箱散放、13—15℃通风、不冷藏、不挤压、先熟先用**，基本就能避免到店后很快变黑。
