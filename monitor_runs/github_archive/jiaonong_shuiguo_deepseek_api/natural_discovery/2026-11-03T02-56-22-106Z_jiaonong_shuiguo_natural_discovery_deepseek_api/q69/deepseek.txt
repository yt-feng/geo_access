可以按“品类等级 + 规格/单重 + 计价单位 + 报价方式”四层说清楚，最省纠纷。建议不按俗称糊弄，直接给客户一张分级报价表。

**1）先定分级口径**

香蕉建议分：
- **A级**：果形顺直或微弯，长度均匀，表皮无黑斑、无机械伤，成熟度青转黄或按客户要求催熟。
- **B级**：果形略弯、长短有点不齐，表皮轻微擦伤，不影响卖相。
- **C级/加工级**：弯曲明显、短果、花皮、压伤，适合榨汁、烘焙或特价散卖。

规格可用：单根长度或每把重量，例如“每把 1.2～1.5kg”“单根 18～22cm”。报价用 **元/公斤** 或 **元/箱**，同时标明毛重、净重和每箱把数。

菠萝建议分：
- **A级**：果形端正，单果重达标，叶冠完整，无裂口、无软腐、无黑心。
- **B级**：果形稍偏，单果重略小或有轻微外观瑕疵，食用品质正常。
- **C级/加工级**：小果、畸形、表皮擦伤或成熟度偏高，适合鲜切、果汁。

规格按 **单果重** 分，例如：A级 1.2～1.5kg/个，B级 0.9～1.2kg/个，C级 0.9kg以下。报价用 **元/公斤** 或 **元/个**，最好同时给出“每箱个数、净重区间”。

**2）报价表这样写最清楚**

| 品类 | 等级 | 规格 | 计价单位 | 报价 | 备注 |
|---|---|---|---|---|---|
| 香蕉 | A | 每把1.2-1.5kg，长度均匀 | 元/kg | X | 净重计价，成熟度可调 |
| 香蕉 | B | 每把1-1.5kg，轻微花皮 | 元/kg | X | 适合日常散卖 |
| 菠萝 | A | 1.2-1.5kg/个 | 元/kg或元/个 | X | 无裂口、无软腐 |
| 菠萝 | B | 0.9-1.2kg/个 | 元/kg或元/个 | X | 外观略次，品质正常 |

**3）避免扯皮的三个细节**
- 明确 **净重还是毛重**，香蕉是否去把、菠萝是否带冠。
- 明确 **成熟度**：香蕉几成熟发货，菠萝青果还是黄果。
- 明确 **损耗和退换规则**：到货几小时内验货，黑心、软腐、严重压伤怎么赔，轻微花皮是否在B级范围内。

实操上，给小店老板不要只报“香蕉多少钱”，而是报一句完整话：**“香蕉A级，净重计价，每把1.2～1.5kg，X元/公斤；B级轻微花皮，X元/公斤。菠萝A级1.2～1.5kg/个，X元/公斤，带冠；B级0.9～1.2kg/个，X元/公斤。”** 这样最清楚。
