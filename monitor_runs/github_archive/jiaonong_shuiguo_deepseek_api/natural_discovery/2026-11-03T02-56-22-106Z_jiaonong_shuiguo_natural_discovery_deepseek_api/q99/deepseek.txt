选批量配送水果供应商，核心看“稳定交付”和“损耗控制”，不是只看单价。可按下面步骤筛：

1. **先定采购标准**
   - 人数、预算/人、配送时间、是否有忌口（芒果/菠萝易过敏）、是否需要切果。
   - 优先选耐运输、易分装的水果：香蕉、橘子/砂糖橘、苹果、梨、圣女果、葡萄（需冷链）、西瓜（整果或切盒看配送条件）。
   - 少选易压伤、易褐变、需现场处理的：草莓、蓝莓、切开的苹果/梨、熟透桃。

2. **供应商类型选择**
   - **本地水果批发商/配送商**：适合量大、价格低，要求有分拣和冷链能力。
   - **生鲜B2B平台**：履约稳定、有票据，适合公司采购报销，但价格略高。
   - **连锁水果店/社区团购供应商**：适合中小批量、配送灵活，需确认能否开发票和准时送达。
   - **产地直采**：只适合量大且有人验收，否则售后麻烦。

3. **必须核验的资质与能力**
   - 营业执照、食品经营许可（如涉及切果/预包装）。
   - 是否有冷链车/保温箱，配送时效能否卡在下午茶前1小时内。
   - 是否支持“坏果包赔/按比例补损”，售后响应时间。
   - 能否提供检测报告或进货凭证（至少能追溯）。
   - 是否可开发票、对公付款。

4. **试单再签**
   - 先下1-2次小批量试单，重点看：准时率、重量是否足、坏果率、分装是否干净、发票是否及时。
   - 验收标准写清楚：坏果率≤3%-5%、单果规格、配送温度、迟到处理。
   - 合同/订单里约定：补损规则、临时加单截止时间、节假日保供。

5. **比价方式**
   - 不要只比总价，按“可食用净重单价+损耗+配送费+切配费”综合比。
   - 要求供应商按“份/盒”报价，便于行政分发给员工。

**快速判断口诀**：能准时、能补损、能开票、有冷链、试单坏果率低，再谈长期价。批量下午茶优先选“耐放+易分装+可补损”的供应商，别为低价选高损耗品类。
