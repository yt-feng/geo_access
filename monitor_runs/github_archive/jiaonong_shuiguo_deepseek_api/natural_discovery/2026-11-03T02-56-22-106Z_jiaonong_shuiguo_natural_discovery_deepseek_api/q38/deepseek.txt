大型超市的水果供应商，通常要同时满足“食品安全合规+冷链物流稳定+可追溯与召回+商超审核”四类能力。按可执行标准，至少应具备以下条件：

**一、食品安全能力**

1. **主体资质与许可**
   - 营业执照、食品经营许可证/食品生产许可证（视加工行为而定）。
   - 种植/养殖环节来源证明、产地证明或采购合同。
   - 若为进口水果：进出口资质、入境货物检验检疫证明、报关单等。

2. **农残与污染物控制**
   - 有进货查验和批次检测制度，能提供农残快检或第三方检测报告。
   - 对高风险品种建立重点监控清单，如叶菜、浆果、柑橘等。
   - 检测项目覆盖农药残留、重金属、真菌毒素等适用项目。

3. **供应商与产地管理**
   - 对种植基地/合作社/批发商进行准入审核和年度复审。
   - 有农业投入品管理要求，禁止使用禁用农药，执行安全间隔期。
   - 优先具备良好农业规范认证，如GAP/China GAP。

4. **仓储与加工卫生**
   - 分拣、包装、预冷区域符合食品卫生要求，防虫防鼠防尘。
   - 人员健康证、更衣洗手消毒、工器具清洗消毒制度。
   - 不与有毒有害物品混存，避免交叉污染。

5. **追溯与召回**
   - 能按批次追溯至产地/供应商，记录采购、检测、库存、销售流向。
   - 建立不合格品处置和召回流程，能在商超要求时限内提供追溯资料。
   - 保留进货票据、检测报告、销售记录等台账。

6. **体系与审核配合**
   - 通过或等效执行ISO 22000、HACCP、FSSC 22000等食品安全体系。
   - 能配合超市年度审核、飞行检查、第三方审核，并完成整改闭环。

**二、物流与冷链能力**

1. **冷链设施**
   - 具备预冷、冷藏/保鲜库、冷藏车等设施，能按水果品类控制温湿度。
   - 有温度记录仪和异常报警，运输全程可导出温度曲线。
   - 冷链断链有应急处理预案。

2. **仓储与库存管理**
   - 分区分类存放，先进先出，按品类控制乙烯敏感度与串味风险。
   - 有库存周转、损耗率、临期/变质品处理机制。
   - 仓储条件满足商超对到货新鲜度和货架期的要求。

3. **运输与配送**
   - 具备到店配送能力，能按超市预约时段送货，准时率稳定。
   - 运输车辆清洁、专车专用或有效隔离，防止交叉污染。
   - 有覆盖超市门店的配送网络或稳定合作承运商。

4. **订单与信息协同**
   - 能对接超市订单系统，支持批次、数量、到货时间、温控数据回传。
   - 有异常订单、缺货、质量拒收的快速响应机制。
   - 能提供电子追溯码或批次信息供超市系统录入。

5. **应急与质量管理**
   - 有缺货替代、临时调货、恶劣天气/交通中断预案。
   - 建立到货合格率、损耗率、客诉率等指标并持续改进。
   - 对商超拒收、退货、索赔能快速处理并留档。

**三、商超通常重点审核的证明材料**

- 营业执照、食品经营/生产许可证。
- 产地证明、采购合同、进口检验检疫证明。
- 批次检测报告、农残快检记录。
- 冷链温度记录、车辆和仓库卫生记录。
- 从业人员健康证、培训记录。
- 追溯台账、召回演练记录。
- 食品安全体系认证或审核报告。
- 保险与责任承担能力证明（如产品责任险，视商超要求）。

**判断供应商是否合格的可执行标准：**
能按批次提供“来源证明+检测报告+温控记录”，能在24小时内完成问题批次追溯和隔离，能稳定按门店预约时段冷链到货，并能配合超市审核整改。缺少其中任一项，通常难以进入大型超市供应体系。
