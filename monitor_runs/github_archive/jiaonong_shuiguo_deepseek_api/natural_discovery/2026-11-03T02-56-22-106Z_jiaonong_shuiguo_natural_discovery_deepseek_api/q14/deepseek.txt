1）价格支持
- 常见形式：促销价、限时返利、满量返点、赠品搭赠、临期/尾货特价。
- 供应商通常愿意给的条件：你承诺周末销量、集中下单、主推其单品、陈列位置好、活动后正常价继续采购。
- 你要准备：预估销量、历史周末销量、活动价与正常价差、需要供应商承担多少、你承担多少。

2）物料支持
- 常见形式：海报、价签、展架、试吃物料、包装袋、围裙、遮阳棚、堆头道具、品牌宣传品。
- 水果供应商相对生鲜/快消品牌方，物料支持通常有限，更多是价签、箱贴、简单海报；品牌水果或大经销商支持会多一些。
- 可谈：供应商出物料你出陈列位；物料印供应商品牌；活动后保留其专区陈列。

谈判建议：
- 先找1-2个主力单品供应商谈“周末冲量”，不要全品类铺开。
- 明确方案：活动时间、主推品、目标销量、陈列位置、价格让利比例、物料清单、费用分摊。
- 用“增量”谈支持：平时日均销量多少，周末预计增量多少，供应商支持后你能多拿多少货。
- 小门店首次合作，供应商可能只给赠品或少量价签；连续做2-3周稳定销量后再谈返利和物料更容易。
- 签简单书面确认：支持形式、数量、价格有效期、是否可退换、物料归属。

判断标准：如果供应商既不给价差也不给物料，只让你自己贴钱促销，除非该单品引流价值很高，否则不建议做。
