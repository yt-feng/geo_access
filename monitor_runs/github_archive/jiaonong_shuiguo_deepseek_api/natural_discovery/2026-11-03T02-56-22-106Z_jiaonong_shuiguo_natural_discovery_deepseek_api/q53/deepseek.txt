优先找“本地生鲜配送商/餐饮食材供应链公司”，而不是水果店、批发市场散摊或产地直发。核心判断标准是：能否稳定按你的用量、按天送货、可退换、有对账和固定对接人。

具体按省心程度排序：

1. **本地餐饮食材配送公司（最省心）**
   - 适合每天少量、品类可能变化的需求。
   - 优点：有固定销售对接、次日或当日配送、缺货可替换、月底对账。
   - 你要确认：起送金额/最低消费、配送频次、退换货规则、是否含税开票、临时加单截止时间。

2. **本地生鲜电商/餐配平台**
   - 如美菜、快驴这类，城市覆盖和品类不同，需看你所在城市。
   - 优点：线上下单、价格透明、售后流程相对标准。
   - 注意：少量订单可能有起送门槛，品质稳定性要看具体仓配。

3. **本地水果批发商做“小店配送”**
   - 适合你已经认识靠谱批发商的情况。
   - 优点：价格通常比配送平台低。
   - 缺点：配送不稳定、售后靠人情、品类不一定全。

4. **附近水果店/社区团购长期合作**
   - 只适合极少量、应急补充。
   - 不建议作为主供：价格波动大、开票和对账麻烦、断供风险高。

**最省心的合作方式：**
- 选1家主供 + 1家备供，不要只依赖一家。
- 约定固定送货时间，比如每天上午9点前。
- 先小单试跑1–2周，重点看：准时率、坏果率、临时加单响应、退换是否爽快。
- 合同或微信里写清楚：品质标准、缺货替代规则、坏果包退、结算周期、涨价提前通知。
- 每天少量但品类有变化时，优先选“可混批、低起送”的供应商，不要选只做整箱批发的。

**避坑：**
- 不要只看报价低，少量配送的隐形成本是起送门槛和坏果损耗。
- 不要找产地直发，除非你用量大且能囤货。
- 不要长期用个人微信转账且无对账记录，后面扯皮成本高。

一句话：**先找本地餐饮食材配送商谈“每天少量、混批、可退换、月结”，试跑两周再定主供。**
