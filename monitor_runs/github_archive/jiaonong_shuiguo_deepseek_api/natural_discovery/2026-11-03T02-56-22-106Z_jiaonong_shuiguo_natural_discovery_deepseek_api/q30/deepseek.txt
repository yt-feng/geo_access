超市水果到货品相不好，售后条款建议在采购合同或到货验收单里写清楚“验收标准＋时限＋处理方式＋费用承担”，避免口头扯皮。可按下面约定：

1. **明确验收标准**
   - 写清品种、等级、规格、成熟度、色泽、大小、损伤率、腐烂率、异味、冻伤、机械伤等。
   - 建议量化，例如：腐烂果不超过1%，明显机械伤不超过3%，不符合等级比例超过5%可拒收或降级。
   - 附照片样例或封样，作为双方认可的标准。

2. **约定验收时限和方式**
   - 到货后当场抽检/全检，写明抽检比例和异议提出时限，如“卸货后2小时内提出书面异议”。
   - 超过时限未提出异议视为数量验收合格，但不免除隐蔽瑕疵责任；腐烂等隐蔽问题可约定到货后24小时内提出。

3. **分情形约定处理方式**
   - 轻微品相问题：降价接收，按比例扣款。
   - 部分不合格：挑拣后按实收合格数量结算，不合格部分退货或换货。
   - 严重不合格：整批拒收，供应商承担退货运费及因此产生的损耗。
   - 已上架后发现：能证明到货时即存在问题的，供应商补货、换货或折价赔偿。

4. **费用和责任承担**
   - 因品相问题产生的挑拣费、退换货运费、冷藏保管费、损耗由供应商承担。
   - 因超市未按约定温度、湿度储存导致变质的，由超市承担。
   - 约定赔偿上限或按批次货款比例赔付，避免争议。

5. **证据和流程**
   - 到货拍照/录像，保留验收单、聊天记录、退货单。
   - 售后流程写成：发现异常→拍照记录→2小时内书面通知供应商→供应商24小时内回复处理方案→退货/换货/折价→双方签字确认。
   - 约定逾期不回复视为认可超市处理方案。

6. **结算挂钩**
   - 不合格批次货款暂缓结算，处理完毕后再结。
   - 可约定质量保证金，如每批次扣留5%，无质量异议后返还。

建议把这些条款写进采购合同附件《到货验收及售后细则》，每次到货用统一验收单签字确认，比事后争论“品相好不好”更可执行。
