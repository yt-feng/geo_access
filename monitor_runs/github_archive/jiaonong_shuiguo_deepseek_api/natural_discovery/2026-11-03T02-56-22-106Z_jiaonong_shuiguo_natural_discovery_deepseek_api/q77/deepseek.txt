选哪个更适合线上卖，关键不在“哪个品类更好”，而在你的客单价、履约半径、损耗承受力和复购场景。按生鲜电商常见判断：

**结论优先级：整果 ≈ 切配 > 冷冻原料，但要分场景。**

1. **整果菠萝：最适合作为线上引流和标准SKU**
   - 优点：耐运输、损耗相对可控、客单价低、适合凑单和家庭囤货；消费者对“整果”信任度高，售后争议少。
   - 风险：毛利薄、同质化强、重量和成熟度难标准化；夏季高温下到货催熟、压伤、黑心等问题会增加售后。
   - 适合：社区团购、次日达、产地直发、低客单引流款。建议按果径/净重分档，明确“到货成熟度”和催熟说明。

2. **切配菠萝：线上溢价和复购潜力最高，但履约门槛最高**
   - 优点：即食、省事，适合办公室和年轻家庭；容易做组合装、果切杯、酸奶/沙拉搭配，毛利空间比整果好。
   - 风险：保质期短、冷链要求高、切配后微生物和出水问题突出；一旦配送延误，投诉和退款率高。
   - 适合：同城即时零售、前置仓、冷链能力强的商家。建议只做短保预售或当日达，严格控温，标注“冷藏即食、当日食用”。

3. **冷冻菠萝原料：更适合B端或特定C端场景，不适合作为大众生鲜主推**
   - 优点：保质期长、损耗低、适合烘焙/饮品/奶昔场景，履约稳定。
   - 风险：C端家庭渗透率低，消费者对“冷冻水果”接受度分化；需要教育使用场景，且客单价和复购频次不一定高。
   - 适合：B端餐饮、茶饮、烘焙供货，或C端做“冷冻菠萝块+食谱”组合。若没有B端渠道，不建议作为线上主SKU。

**可执行建议：**
- 如果你做**次日达/产地直发**：主推整果，切配作为同城补充，冷冻原料不做或只做小规格测试。
- 如果你做**同城即时零售/前置仓**：切配做利润款，整果做引流款，冷冻原料做长尾补充。
- 如果你做**B端供货**：冷冻原料优先，整果次之，切配不建议。
- 测试方法：用同一流量位分别上架整果、切配、冷冻小规格，观察7—14天的**履约投诉率、损耗率、复购率、毛利率**；切配若冷链投诉超过可承受线，立即收缩。

一句话：**大众线上零售先做整果打基础，有冷链能力再做切配提毛利，冷冻原料只适合有明确B端或场景化需求的渠道。**
