建议分三种情况判断，多数便利店应优先做“单根 + 小把”组合，整袋作为补充。

1. **单根：适合写字楼、学校、交通枢纽、社区流动客**
   - 即买即吃，决策成本低，适合便利店“冲动消费”。
   - 缺点是损耗高、称重和补货麻烦。
   - 如果门店客流快、香蕉周转在1—2天内，单根值得做。

2. **小把（3—5根）：多数便利店的主力**
   - 兼顾家庭/两人份和客单价，减少单根损耗。
   - 适合社区店、住宅区、混合客流门店。
   - 建议作为主陈列规格，配合“单根可拆”或“整把优惠”。

3. **整袋：只适合家庭客明显、客流稳定的社区店**
   - 客单价高、陈列整齐、损耗相对可控。
   - 但便利店核心是即时消费，整袋容易压库存，不适合客流杂、购买频次低的门店。
   - 若做，建议小袋装（5—6根）并控制订货量。

**可执行建议：**
- 先小批量试销2周：单根、小把、整袋各上一组，记录日销量、损耗率、毛利。
- 主推小把，单根补位，整袋只在周末或家庭客多的时段/门店测试。
- 香蕉成熟度分两批陈列：即食偏黄、稍青给隔天购买，降低损耗。
- 若门店没有称重条件，优先做预包装小把，避免单根称重影响收银效率。

**结论：** 多数便利店选“小把为主、单根为辅”，整袋谨慎上；社区家庭店可加小袋装，交通/办公店可提高单根比例。
