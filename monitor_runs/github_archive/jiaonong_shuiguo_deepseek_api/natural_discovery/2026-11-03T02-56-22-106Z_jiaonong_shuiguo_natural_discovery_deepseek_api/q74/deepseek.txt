做餐饮客户，菠萝和香蕉的规格要按“出成率、稳定性、加工便利”来配，不要只按零售档口的卖相来备。下面给可直接执行的规格建议。

## 一、菠萝：餐饮客户优先看加工出成和酸甜稳定
餐饮用菠萝主要分三类：鲜切水果/果盘、饮品店榨汁/打果泥、后厨热菜/咕噜肉/炒饭。

**建议常备规格：**
1. **鲜切/果盘主力：单果1.2–1.8斤，成熟度7–8成**
   - 要求：果形端正、无黑心、无裂口，糖度稳定在12–15度更稳妥。
   - 到货后能放1–3天正好熟，适合餐饮按日损耗管理。
2. **饮品店/果泥：单果2–3斤大果，成熟度8–9成**
   - 要求：汁水足、纤维少、酸甜比稳定；按箱供货，注明净重和个数。
   - 饮品客户更在意出汁率和每杯成本，建议同时给“每箱约几个、单果均重、建议到货后使用窗口”。
3. **后厨热菜/加工：单果1.5–2.5斤，成熟度7成左右**
   - 要求：耐存放、切块后不易烂；可推整箱统货，但必须去黑心、去水烂。
4. **小果/次果不要混装给餐饮**
   - 餐饮最怕一箱里大小差太多、熟度不齐。建议按“同一熟度、同一均重区间”分箱，哪怕贵一点也更容易复购。

**档口操作建议：**
- 设三档：**小果1.2–1.8斤（鲜切）**、**大果2–3斤（饮品/果泥）**、**统货1.5–2.5斤（后厨）**。
- 报价按箱报，同时标“单果均重、每箱个数、熟度、建议使用天数”。
- 首单可给餐饮客户做“今日切果测试”：现场切2–3个看黑心率和糖度，比口头承诺有效。

## 二、香蕉：餐饮客户核心是熟度和批次稳定
餐饮用香蕉主要是：果盘/自助餐、饮品店香蕉奶昔/果泥、烘焙店香蕉蛋糕、部分后厨甜品。

**建议常备规格：**
1. **果盘/自助餐：单根120–150克，7–8成熟到货**
   - 要求：条形直、无严重擦伤、无断把；到货后1–2天转黄可用。
   - 餐饮果盘不喜欢太软、黑斑多的，卖相和切面干净很重要。
2. **饮品/果泥：单根150–200克，8–9成熟**
   - 要求：香甜度高、果肉软，适合打泥；可接受少量表皮芝麻点，但不能烂。
   - 建议按“到货即可用”或“次日可用”分批次供，饮品店最怕今天太生明天全熟。
3. **烘焙/甜品：单根150–200克，9成熟偏软**
   - 要求：香气足、易压泥；可专门收表皮有零星黑点的批次，但必须无腐烂、无酒味。
4. **不要整箱同熟度全给餐饮**
   - 餐饮每天用量有限，建议“同箱分把、熟度分档”：比如一箱里7成熟和8成熟搭配，或按客户用量分“今日用/明日用”两批。

**档口操作建议：**
- 香蕉按**把/箱**卖，标明“单根均重、到货熟度、最佳使用窗口”。
- 给餐饮客户建熟度台账：今天到7成，明天8成，后天9成，按客户用量配比发货。
- 香蕉损耗主要来自压伤和过熟，装箱时分层、留通风孔，别和菠萝重压混装。

## 三、给餐饮客户的首推组合
**首次铺货建议：**
- 菠萝：小果1.2–1.8斤1箱 + 大果2–3斤1箱，各标熟度和个数。
- 香蕉：7–8成熟1箱 + 8–9成熟半箱/小箱，按客户用量定。
- 附一张简单供货卡：品名、规格、均重、熟度、建议使用天数、整箱价/斤价、售后标准（黑心、烂果怎么换）。

**判断标准：**
- 餐饮客户复购看三点：**出成率稳定、熟度可预期、坏果赔付干脆**。
- 先别追求全规格，先把“菠萝大小两档 + 香蕉熟度两档”跑顺，比铺很多规格更有效。
