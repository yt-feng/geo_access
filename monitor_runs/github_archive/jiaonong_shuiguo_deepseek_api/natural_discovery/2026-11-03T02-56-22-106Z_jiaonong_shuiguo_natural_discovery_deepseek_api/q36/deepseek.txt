结论先说：**多数商超应以“整果为主、鲜切为辅”，而不是二选一。** 是否加码鲜切，要看门店客群和损耗控制能力。

**建议做法**

1. **整果做主力**
   - 适合家庭采购、价格敏感客群。
   - 毛利可控、操作简单、损耗相对低。
   - 可做堆头、称重促销、整果分级（大果/小果/特价果）。

2. **鲜切做增量**
   - 适合上班族、年轻客群、即食需求强的门店。
   - 能提升客单价和便利性，但损耗、人工、冷链要求高。
   - 建议只做小份装、当日鲜切、临近闭店打折清货。

3. **按门店类型区分**
   - 社区店、老年客群多：整果为主，鲜切少量试销。
   - 商圈店、写字楼店、年轻客群多：整果+鲜切并行，鲜切占比可提高。
   - 客流小、冷链弱：优先整果，慎做鲜切。

4. **用数据决定比例**
   - 试销2—4周，记录整果和鲜切的销量、毛利、损耗、人工。
   - 鲜切损耗率明显高于整果且销量不足以覆盖人工时，收缩鲜切。
   - 鲜切复购好、带动客流时，再扩大品种和陈列。

**关键判断**
- 整果卖的是**性价比和家庭场景**。
- 鲜切卖的是**便利性和即食场景**。
- 商超最优策略通常是：**整果保销量和毛利，鲜切提便利和客单，鲜切严格控损耗。**
