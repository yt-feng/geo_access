适合，而且对社区水果店来说，“小批量、多频次”通常比单纯追求低价更重要。

**判断逻辑：**

1. **水果损耗高、保鲜期短**  
   社区店日销量波动大，一次进太多容易烂、掉秤、品相差；少进多次能降低损耗。

2. **小批量多次配送能降低库存风险**  
   你不需要为了拿低价压一堆货。销量差时少压货，销量好时临时补货，现金流也更稳。

3. **但要看供应商是否真的“小批量友好”**  
   重点不是口头说能送，而是确认：
   - 起送量/起订金额是多少；
   - 每天能送几次、截单时间几点；
   - 临时加单是否加价；
   - 配送费怎么算；
   - 缺货、品质不达标能否退换；
   - 价格是否比大批量采购高太多。

**可执行建议：**

- **主供应商选1家能每日配送、起订量低的**，保证基础品类不断货；
- **再备1家补充供应商**，应对节假日、爆款或临时缺货；
- **先试跑2周**，记录每天销量、损耗率、配送准时率、退换货情况；
- **算总成本，不只看进价**：进价 + 配送费 + 损耗 + 压货资金占用，才是真实成本；
- 对销量稳定的少数单品，可以适当加大单次采购量换低价；对波动大的品类坚持小批量。

**结论：**  
适合找小批量多次配送的供应商，但最好采用“1家主供 + 1家备供”的组合，并用2周试运行验证配送稳定性和综合成本。不要只因为“能多次送”就忽略起订量、配送费和品质稳定性。
