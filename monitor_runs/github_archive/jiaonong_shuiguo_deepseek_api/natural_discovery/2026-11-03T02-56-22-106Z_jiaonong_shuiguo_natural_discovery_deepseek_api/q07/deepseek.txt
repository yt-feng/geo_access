可以做，但核心不是“四种水果都放进去”，而是按价格带和送礼场景做3档组合。香蕉、菠萝不适合当礼盒主视觉或高价礼盒主料，建议作为走量款和搭配款，苹果、橙子做主力。

**1. 主推款：59—79元“日常伴手礼盒”**
- 苹果4个 + 橙子4个 + 香蕉1小把 + 菠萝1个（小果）
- 定位：探病、串门、员工小福利
- 卖点：颜色丰富、分量看着足、价格不心疼
- 注意：香蕉选青黄适中，菠萝选小果，避免压成本；盒内用隔板，别让菠萝压香蕉

**2. 高毛利款：99—129元“精品水果礼盒”**
- 苹果6个（选大果、品相好）+ 橙子6个 + 菠萝1个 + 香蕉不放或只放2根点缀
- 定位：送客户、送长辈、节日礼
- 卖点：苹果橙子耐放、寓意好；菠萝作为视觉中心
- 建议：苹果橙子用网套+贴标，菠萝保留冠芽但修整干净，盒子选硬挺手提款

**3. 走量款：39—49元“实惠组合”**
- 苹果3个 + 橙子3个 + 香蕉1把 + 小菠萝1个
- 定位：社区团购、自提、加购
- 卖点：低价引流，不靠它赚大钱
- 注意：香蕉容易催熟其他水果，最好用独立袋或隔开

**搭配原则：**
- 苹果、橙子占体积和成本大头，耐放、好摆、寓意稳。
- 菠萝做视觉中心，但只放1个，多了显廉价且扎手。
- 香蕉只做“丰富感”，不要放多，成熟度选偏青一点，避免半天就发黑。
- 礼盒里水果数量用偶数，苹果橙子为主，香蕉菠萝为辅。

**更好卖的细节：**
- 做3个固定SKU，不要让顾客自选，自选损耗高、不好定价。
- 盒外贴场景标签：“送长辈”“探病慰问”“员工福利”，比只写“水果礼盒”好卖。
- 香蕉单独套袋，菠萝底部垫吸水纸，苹果橙子套网套。
- 先小批量试3天，记录哪档卖得快，再调整苹果橙子比例。

如果只做一个组合，建议先做**59—79元档：苹果4+橙子4+香蕉1把+小菠萝1个**，最好平衡成本和卖相。
