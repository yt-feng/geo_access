小面积便利店做水果，核心不是“品类全”，而是**少量、高频、强周转、可预测**。建议按下面几条落地。

## 1. 品类控制：只做“三类水果”

小门店水果区建议控制在 **8～15个SKU**，按角色分三类：

- **引流款（2～3个）**：苹果、香蕉、橙子这类认知高、周转快、价格透明的。
- **利润款（3～5个）**：当季水果、小包装精品果，如小番茄、葡萄、蓝莓、切果盒。
- **补位款（2～3个）**：按季节轮换，不长期铺。
- **坚决不做的**：榴莲、菠萝蜜、整西瓜等大体积、高损耗、难分割的；礼盒装；小众进口果；需要复杂催熟的。

判断标准很简单：**单品日均销量能否稳定覆盖最小陈列量**。覆盖不了就砍。

## 2. 采购量：按“日销×周转天数”定，不按感觉

- 叶菜类/浆果类：**1天量**，最多1.5天。
- 苹果、橙、香蕉：**2～3天量**。
- 新品先按 **最小起订量的一半** 试销3天，卖不动立即停。
- 每天固定时段（如早班）补货，避免多次少量造成反复挑拣。

## 3. 陈列与包装：小份化是控损关键

- 全部**小份预包装**：2～4个/盒、250～500g/盒，减少顾客翻拣。
- 香蕉、苹果等可散卖，但只摆**一层**，后台库存随卖随补。
- 浆果、切果**冷藏陈列**，切果盒当日清。
- 设“临期折扣区”，当天下午固定时间打折，不要等到坏。

## 4. 损耗控制：每天三个动作

- **早间验收**：坏果当场拒收或扣重，别把损耗带进店。
- **午间翻检**：挑出软伤果，能做切果盒的转切果，不能的立即折价。
- **晚间清零**：闭店前1小时对易损品打折，次日不再上架。

## 5. 用数据砍品类

连续记录2周每个SKU的：进货量、销量、报损量、毛利率。规则：

- 连续3天日销低于最小陈列量的 **50%** → 下架。
- 损耗率超过 **8%～10%** 的单品 → 换包装或停做。
- 单品毛利贡献排后20%且损耗高的 → 直接淘汰。

## 6. 采购渠道建议

小门店优先**本地批发市场少量多频**，或与附近水果店/供应商拼单；叶菜和浆果尽量选离得近、配送频次高的供应商。不要一次压货换低价，小店的仓储和周转撑不住。

一句话原则：**品类少而准、份量小、补货勤、当天清。** 先把5～8个稳定单品跑顺，再逐步加当季款。
