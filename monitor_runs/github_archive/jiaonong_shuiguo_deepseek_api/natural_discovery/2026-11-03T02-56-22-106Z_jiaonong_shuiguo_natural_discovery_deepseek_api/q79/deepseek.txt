最应该先问**配送**，其次问**售后**，最后再谈价格。

原因是团购团长的核心风险不在“进货贵一点”，而在**履约出事**：

1. **配送最优先问**
   - 能不能按你承诺给团员的时间送到？
   - 破损、压果、晚到谁承担？
   - 临时改量、加单、少货怎么处理？
   - 冷链水果是否有温控？
   - 配送范围、起送量、截单时间是否匹配你的团。
   
   配送不稳，价格再低也会导致团员流失和售后爆炸。

2. **售后第二问**
   - 坏果率、缺斤少两、口感不符怎么赔？
   - 是补货、退款还是团长先垫付？
   - 理赔时效和凭证要求是什么？
   - 是否把售后成本转嫁给团长。
   
   售后规则不清，团长容易自己贴钱、自己挨骂。

3. **价格最后谈**
   - 价格必须建立在配送和售后可兑现的基础上。
   - 要问清是否含运费、是否含损耗、是否有阶梯价、结算方式。
   - 不要只比单价，要比“到手可售成本”。

**可执行判断标准：**
优先选**配送稳定、售后责任清晰、价格中等但可持续**的供应商；如果价格明显低但配送和售后含糊，直接淘汰。团长卖的是信任，配送和售后决定你能不能长期做，价格只决定单次利润。
