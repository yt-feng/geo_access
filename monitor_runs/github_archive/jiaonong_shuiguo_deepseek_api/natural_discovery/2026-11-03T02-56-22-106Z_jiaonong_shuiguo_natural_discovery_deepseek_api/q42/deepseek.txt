核心原则：**压价要压“可替代的成本”，不压“不可逆的品质”**。谈判前先把成本拆开，只谈自己能验证、能替换、能分担的部分，品质才守得住。

**1. 先做成本拆解，别一上来砍总价**

把报价拆成：产地收购价、分选包装、冷链运输、损耗赔付、账期资金成本、渠道毛利。谈判时明确说：“总价可以谈，但这几项我要看到依据。”重点压三类可替代成本：包装规格（如礼盒改周转箱）、物流拼车/到货频次、账期与结算方式。**不碰产地等级、成熟度、糖度、单果规格这些决定口感的硬指标。**

**2. 用“分级采购+稳定量”换价，而不是压同品质单价**

跟供应商谈：同一产地分A/B级，A级保陈列和核心客群，B级做促销/果切/特价区，整体采购量给足。供应商愿意在B级和包装上让利，A级价格反而能稳住。这是商超最常用的“以量换价、以结构换价”。

**3. 把品质条款写进价格里，压价同时锁赔付**

谈价时同步约定：到货抽检标准（糖度、硬度、霉烂率、单果重区间）、不合格扣款/退换比例、损耗分担方式。**价格降多少，赔付条款就补多少。** 供应商知道品质不达标要赔，就不会用降级货填低价单。

**4. 用账期和现金流换价，但算清资金成本**

现结/短账期通常能换2%—5%的让利，但要对比自身资金成本。若账期从60天缩到15天，省下的价差要覆盖资金占用，否则是假降价。可谈“阶梯账期”：达标批次短账期，不达标恢复长账期。

**5. 多源比价，但别只比单价**

同一单品保持2—3家合格供应商，比价时比“到店可售成本”= 单价+运费+损耗率+退货率。只比单价容易逼供应商降规格。谈判话术：“你的单价不是最低，但到店可售成本有优势，量可以给你；如果单价再降，品质标准不能降，否则我换源。”

**6. 避开三个伤品质的压价动作**

- 不要压“未成熟采收”或“降低分选标准”，这是不可逆的品质损失；
- 不要用“临时加量再砍价”逼供应商清库存，容易拿到尾货；
- 不要只谈年度返点而不谈月度品质考核，返点会变成降级动力。

**可执行动作：** 本周选3个高频单品，做一张“到店可售成本对比表”（单价、运费、损耗率、退货率、账期），拿表和供应商谈“结构让利+品质赔付”，而不是直接砍单价。这样压下来的是包装、物流、账期和分级结构的成本，品质指标不动。
