商超会员日水果活动，供应商提前配合重点是把“货、价、品质、陈列、补货、风险”六件事锁死。建议按活动前7天、前3天、前1天、活动当天四个节点推进：

**一、活动前7天：确认活动方案与资源**
1. **确认活动SKU与量级**：每个单品明确活动价、正常价、日均销量、活动预估销量、备货量、安全库存；区分引流款（低价高量）和利润款。
2. **锁价锁量**：书面确认供货价、返利/费用承担、活动价差谁承担，避免临时变价；对易波动单品约定价格保护期。
3. **确认品质标准**：规格、等级、糖度、成熟度、单果重、色泽、瑕疵率、包装方式写进供货标准，避免到货扯皮。
4. **确认到货计划**：按门店/DC分货量、到货时间、到货频次、卸货要求、验收标准提前排好。

**二、活动前3天：备货与品质预控**
1. **产地/仓库备货**：按预估量上浮10%—20%备货，易损耗单品控制上浮比例，避免活动后烂货。
2. **成熟度管理**：会员日集中销售，香蕉、芒果、猕猴桃、牛油果等需按销售节奏控制成熟度，分批到货，避免首日未熟、次日过熟。
3. **包装与预包**：提前完成预包装、称重贴标、礼盒/组合装组装，减少门店现场人力压力。
4. **质检前置**：供应商自检并出具批次质检/农残报告，重点单品做糖度抽检。

**三、活动前1天：到货与门店对接**
1. **按计划到货**：核心引流单品确保开门前到店并完成陈列；分批到货的明确第二、第三批次时间。
2. **陈列物料到位**：价签、POP、堆头围挡、试吃物料、保鲜冰袋/陈列道具由供应商或商超确认谁提供。
3. **补货机制确认**：明确活动当天补货触发点（如库存低于X%或某时段前）、补货截止时间、紧急联系人。
4. **退换货与损耗约定**：明确品质不达标、滞销、损耗的分担比例和处理方式。

**四、活动当天：驻场与快速响应**
1. **安排驻场/巡店人员**：重点门店安排供应商人员协助补货、挑拣、试吃推广。
2. **实时看销售数据**：按半天盯销量，卖快了及时调货，卖慢了提前做二级促销或调拨，避免闭店前大量剩货。
3. **品质巡检**：每2—3小时挑拣一次，及时下架软烂、裂果、霉变品。

**五、必须提前书面确认的清单**
- SKU、活动价、供货价、费用承担
- 分店分货量与到货时间表
- 品质验收标准与抽检方式
- 补货响应时限与联系人
- 损耗/退换货责任
- 陈列物料与人员支持
- 天气、物流、产地减产等预案

一句话：供应商不是只把货送到，而是要把**量、价、质、时、人、责**提前锁死，活动当天才有可控性。
