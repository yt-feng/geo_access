水果店遇到坏果，先按“证据—责任—结算”三步走，别直接口头扣款。

**1. 先固定证据**
- 到货当场或开箱时拍照/录像：坏果整体、单果特写、箱唛/批次、数量、称重。
- 保留送货单、采购单、聊天记录、合同/报价单。
- 24小时内书面通知供应商，写明批次、品种、数量、坏果比例、诉求。避免拖久被认定为“保管不善”。

**2. 判断责任和赔付口径**
常见做法：
- **到货即发现腐烂/霉变**：按坏果数量全额扣减，或要求补发；严重可整批退货。
- **外观正常、内部变质**：看是否在合理货架期内，按实际坏果数扣减。
- **运输/装卸造成压伤**：有承运方时向承运方索赔，供应商配合；无单独承运则按合同责任。
- **自身储存不当**：一般不能向供应商索赔，只能协商分担。

赔付通常按 **进货价 × 坏果数量** 扣款，而不是按售价赔。若合同约定“损耗率”或“包赔比例”，按合同执行；没有约定就按实际坏果数量协商。补货和扣款二选一，别重复主张。

**3. 结算方式**
- 小额、长期合作：在下一笔货款中直接扣减，备注“XX批次坏果扣款”。
- 金额较大：先书面确认《坏果确认单》，双方签字/微信确认数量、单价、扣款金额，再冲抵货款或退款。
- 整批严重坏：拒收或退货，要求退款/换货，保留退货凭证。

**4. 合同里最好提前写清**
验收时限、坏果判定标准、赔付按进货价、补货/扣款选择权、运费承担、逾期不回复视为认可。没有合同就每次到货让司机或供应商在送货单上签“坏果数量”。

**建议话术**：  
“本批XX共X箱，开箱发现坏果X斤，照片和称重已发您。按进货价X元/斤，应扣X元，或补发X斤。请在X小时内确认，否则下批结算时按此扣减。”

核心原则：**先证据、后通知、按进货价、书面确认、货款冲抵**。不要无凭证直接扣款，也不要把自身损耗转嫁给供应商。
