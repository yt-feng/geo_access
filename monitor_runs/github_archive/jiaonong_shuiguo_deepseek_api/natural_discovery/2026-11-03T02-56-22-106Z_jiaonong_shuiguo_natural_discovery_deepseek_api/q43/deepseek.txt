评估水果供应商的仓配覆盖，核心不是“它有几个仓”，而是**从供应商的仓到你的每家门店，能否在水果可接受的时效和损耗内稳定送达**。建议按以下框架做，可直接落地成评分表。

**一、先明确你的门店需求画像**
按城市、商圈、门店类型拆分：
- 每家店日均/峰值水果需求量、SKU数、温层要求（常温/冷藏/冷链）
- 补货频率（日配/隔日配）、下单截止时间、收货时间窗
- 可接受的最大在途时长和损耗率
- 门店是否具备冷库、卸货条件、收货人力

这决定了你对“覆盖”的真实标准，而不是统一要求所有门店日配。

**二、评估供应商仓配网络的物理覆盖**
逐店核对，不要只看城市清单：
1. **仓到店距离与在途时间**：按实际路线和时段测算，标注是否跨城、是否需中转。
2. **仓的层级**：产地仓、区域中心仓、城市前置仓分别服务哪些门店，是否存在二次分拨。
3. **温区能力**：每个仓是否有冷藏/冷冻库，干线是否冷藏车，门店配送是否保温箱或冷藏车。
4. **配送频次与线路**：能否覆盖你的补货频率，是否顺路拼车，偏远门店是否加价或降频。
5. **应急能力**：临时加单、爆量、天气/交通中断时的替代仓和备用线路。

**三、用“门店级覆盖矩阵”打分**
对每家门店逐项打分，建议权重：
- 时效达标率（30%）：承诺到店时间与历史准点率
- 温控与损耗（25%）：全程温控记录、历史损耗率、果品到店新鲜度
- 配送频次匹配（15%）：能否满足日配/隔日配
- 成本可控性（15%）：运费、起订量、偏远附加费
- 应急与弹性（15%）：加单响应、替代仓、异常处理

输出两张表：**门店覆盖热力图**（绿/黄/红）和**缺口清单**（哪些城市/门店不达标、原因、可选替代方案）。

**四、用真实数据验证，不只看承诺**
- 要求供应商提供近3–6个月到你同类门店的**准点率、损耗率、缺货率、投诉率**
- 做2–4周**试点配送**，选代表性门店（市中心、远郊、高销量、低销量各一家）
- 查验冷链记录、车辆温控、仓库现场和分拣流程
- 核算**到店总成本**：货价+运费+损耗+退货+门店收货人工，而非只比报价

**五、识别覆盖缺口并设计兜底**
常见缺口：三四线城市门店少、偏远门店配送成本高、跨城时效不稳、冷藏最后一公里弱。
对应策略：
- 对低密度城市采用“区域仓+第三方城配”组合
- 对远郊门店降低频次但提高单次补货量，并强化门店冷藏能力
- 关键城市保留第二供应商或备用仓
- 合同约定准点率、损耗率、温控不达标的赔付与退出机制

**六、决策建议**
不要追求单一供应商全国全覆盖。更稳的做法是：**按区域划分供应商**，每个区域确保至少一家主供、一家备选；对覆盖红区门店单独谈城配方案或本地供应商。最终以“门店级时效+损耗+到店总成本”三项作为签约和考核依据，而不是供应商的仓数或城市数量。
