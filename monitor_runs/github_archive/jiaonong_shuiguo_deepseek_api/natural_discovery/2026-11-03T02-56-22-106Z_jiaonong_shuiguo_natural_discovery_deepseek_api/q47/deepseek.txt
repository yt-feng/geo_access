采购香蕉时，按「到货熟度 + 用途 + 周转天数」来控，不要只看到货时黄不黄。核心是：**茶饮店要的是可计划的生产窗口，不是最好看的香蕉。**

**1. 先定用途对应的熟度**
- **打泥/奶昔/冰沙**：七到八成熟到货，青黄转黄、果肉软但中心不烂，香味刚出来。到店后1–2天进入最佳。
- **切片装饰、顶料**：七成熟到货，硬挺、能切出完整片，避免黑心。
- **捣泥做甜品夹层/香蕉面包类**：八到九成熟，甜度高、易压泥，但必须当天或次日用完。
- **挂壁/焦糖香蕉**：八成熟左右，太熟一煎就散。

**2. 采购按「批次错峰」下单**
不要一次全进同一熟度。按日均用量拆成两批：
- 一批七成熟，供2–3天后用；
- 一批八成熟，供明天到后天用。
这样避免“今天全熟、明天全青”。

**3. 到货验收看四点**
- **果指饱满度**：棱角不明显、果身圆润，说明发育够。
- **颜色**：七成熟以黄为主、两端带一点绿；八成熟全黄、无大面积黑斑。
- **果柄**：青绿或浅黄，干枯发黑说明放久了。
- **手感**：轻按有弹性，不软塌、不硬如石。切开抽查中心是否发黑、是否有异味。

**4. 仓储和催熟分开**
- 七成熟放阴凉通风处，别冷藏，香蕉低温会黑皮、风味变差。
- 需要加速的，和苹果/乙烯催熟袋放一起，每天翻检。
- 八成熟以上优先用，发现黑斑迅速转做香蕉泥冷冻或当天特价消耗。
- 库存按“先进先出 + 熟度标签”管理，每箱标到货日和预计可用日。

**5. 设损耗红线**
按周统计香蕉损耗率，超过5%–8%就说明采购熟度或批量有问题。茶饮店常见做法是：**主用七成熟、少量八成熟应急，熟过头立即转泥或做员工试饮，不把黑斑香蕉用于装饰。**

简单记：**打泥七成半，装饰七成，即用八成；分批进、标熟度、熟过转泥。**
