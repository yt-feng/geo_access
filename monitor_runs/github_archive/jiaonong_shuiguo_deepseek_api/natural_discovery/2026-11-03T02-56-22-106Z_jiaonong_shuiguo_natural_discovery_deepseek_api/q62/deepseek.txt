# 香蕉批发：判断熟度和坏果风险

判断一批香蕉能不能拿、拿多少、几天走完，核心看**"成熟度（几成熟）+ 到货时的生理状态 + 坏果的分布规律"**，不是只看表面黄不黄。下面是可现场操作的步骤。

## 一、先看成熟度（决定能不能拿、多久要卖完）

**看颜色（整批抽样看，不是看最漂亮的几个）：**

- **全青、棱角明显**：1–2成熟，适合长途/囤货，但需要催熟，坑在"闷熟不匀"。
- **青中带黄、棱线微圆**：3–4成熟，最耐放，批发拿货的主力。
- **七成黄、棱线变圆**：5–6成熟，2–4天内必须出货。
- **全黄带少量黑点（芝麻点）**：7–8成熟，当天到次日必须走完。
- **大面积黑斑、发软**：过熟，只能低价处理。

**看棱角：** 香蕉横截面从"明显五棱"变"圆润"的过程就是成熟过程。棱角越明显越生，越圆越熟。

**看蕉柄和蕉身连接处：** 发青发硬=生；变软、转黄=开始熟。

**抽样方法：** 一车/一板随机抽 5–10 箱，每箱看中间和底层的蕉（表层往往最好，底部最容易闷坏）。

## 二、判断坏果风险（这才是亏钱的地方）

**1. 摸蕉身的硬度**
- 整把硬挺：正常。
- 局部发软、能按出凹：已经开始烂，风险高。
- 一把里"外硬内软"：说明内部温度高、闷过了。

**2. 看有没有"水伤/闷伤"**
- 蕉身有油亮水渍、发暗：运输中被压或温度过高，几天内会烂。
- 蕉柄发黑、发黏：切口感染，会向上传染。

**3. 查机械伤**
- 磕碰后的黑斑、压痕：三天内演变成黑腐，属于"隐性坏果"，所以磕碰多的货要按更高比例剔损。

**4. 看底层和中间**
- 开箱看**箱底和箱心**有没有潮湿、霉点、发酵味。底部湿=闷坏开始，这是最典型的整批风险信号。
- 闻味：有酒味/酸味说明已开始发酵，整批风险大。

**5. 看包装和冷链痕迹**
- 箱体受潮、有冷凝水：温度波动大。
- 到货温度明显偏高（摸箱体发温）：熟度会加速、坏果率上升。

## 三、快速决策标准（可现场照做）

| 情况 | 判断 | 建议 |
|---|---|---|
| 3–4成熟、硬挺、无伤、箱底干爽 | 优质耐放货 | 可多拿，正常催熟 |
| 5–6成熟、少量芝麻点、无软斑 | 正常快销货 | 按销量拿，2–4天走完 |
| 有磕碰黑斑、底层发潮、局部发软 | 隐性坏果多 | 压价或减少拿货量，按 5–10% 预提损耗 |
| 有酒味/酸味、柄部发黑发黏、大面积水渍 | 高风险 | 不建议拿，或只按处理价拿且当天清 |
| 全青但箱内闷热、有冷凝水 | 闷熟风险 | 谨慎，需立即通风，催熟易不均 |

## 四、几条实操经验

- **"看底不看面"**：表层永远好，底部和中间才是真相。
- **宁要生的均匀，不要熟的漂亮**：熟货好看但走货窗口短，坏果风险高。
- **按"到货熟度+你的出货速度"决定拿多少**，不是按便宜程度。
- **谈损耗**：磕碰多、有闷伤的货，直接按预估坏果率（一般 3–10%）折算进价格。
- **先小批量试一板**，观察 24–48 小时的变化再决定是否大批拿。

核心一句话：**熟度看颜色和棱角定"卖几天"，坏果风险看硬度、箱底湿度、气味和机械伤定"会不会烂"**，两个判断分开做，再合起来算这车货的价格和量。
