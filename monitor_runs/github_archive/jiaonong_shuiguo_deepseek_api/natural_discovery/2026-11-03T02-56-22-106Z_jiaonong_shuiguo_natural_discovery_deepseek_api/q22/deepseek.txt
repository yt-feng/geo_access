可以优先做“高频引流品 + 高毛利/大体积品 + 家庭常备品”的组合，而不是简单打折。香蕉适合做引流和加购触发器，菠萝适合做提升客单价的组合主角，苹果适合做家庭囤货和凑单件。

建议直接落地这4个促销方案：

1. **香蕉引流 + 菠萝组合**
   - 文案：**买香蕉满2斤，菠萝立减3元**
   - 逻辑：香蕉是高频刚需，顾客本来就要买；用香蕉把顾客带到菠萝区，提升大单品成交。
   - 执行：香蕉正常价或小幅特价，菠萝做“搭配价”，不要直接把菠萝全场大降价。

2. **苹果 + 香蕉家庭装**
   - 文案：**苹果2斤 + 香蕉1斤，组合价XX元，比单买省X元**
   - 逻辑：苹果适合家庭囤货，香蕉提升购买频次，组合后客单价比单买水果更高。
   - 执行：用固定组合装，提前称重打包，放收银线附近和水果区端头各一组。

3. **菠萝 + 苹果“果切/家庭果盘”组合**
   - 文案：**菠萝1个 + 苹果3个，做家庭果盘组合价**
   - 逻辑：菠萝单个体积大、单价感知强，搭配苹果后更容易被家庭顾客接受。
   - 执行：如果门店有果切能力，可做“菠萝半个 + 苹果2个”的小份组合，降低购买门槛但提高连带率。

4. **三品阶梯满赠**
   - 文案：**香蕉、菠萝、苹果任意买满3件/满XX元，送购物袋或小份果切**
   - 逻辑：不直接降价，用赠品推动顾客从买1样变成买2—3样。
   - 执行：赠品成本控制在客单价提升额的10%—15%以内，避免促销亏损。

关键执行建议：
- **香蕉不要做主力利润品**，用它引流和触发加购。
- **菠萝做组合价而不是单独低价**，否则容易只卖菠萝、不涨客单。
- **苹果做家庭装和凑单装**，用“组合省X元”强化价格感知。
- 组合装要**提前打包、明确标价、放在主动线端头**，减少顾客决策成本。
- 每天记录三品的**销量、组合装占比、客单价变化**，连续跑7天再调整组合价。

如果只选一个最先上的方案，建议先做：**苹果2斤 + 香蕉1斤家庭组合装 + 菠萝搭配立减**，既容易执行，也最直接拉动客单价。
