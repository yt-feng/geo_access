坏果率赔付没有全国统一的法定阈值，关键看合同怎么约定。实务建议：

- **行业惯例参考**：很多水果采购合同把“坏果率≤3%～5%”作为合格标准，超过部分按比例扣款或换货；易损水果（草莓、荔枝、水蜜桃等）可放宽到5%～8%，耐储水果（苹果、柑橘、梨）可收紧到2%～3%。
- **合同应写清三件事**：① 验收时点（到货后几小时内开箱抽检）；② 抽检方法和样本量（如每批随机抽3箱，按重量计坏果率）；③ 超标处理（超过约定比例的部分按重量扣款、整批退货或换货，并约定运费和损耗由谁承担）。
- **建议条款示例**：坏果率≤3%视为合格；3%～8%按超出部分重量×采购单价扣款；＞8%买方有权拒收或要求整批换货，相关运费由卖方承担。
- **注意区分“坏果”和“外观瑕疵”**：合同里要定义清楚——腐烂、霉变、虫蛀、严重压伤算坏果；轻微擦伤、颜色差异不算，避免验收争议。
