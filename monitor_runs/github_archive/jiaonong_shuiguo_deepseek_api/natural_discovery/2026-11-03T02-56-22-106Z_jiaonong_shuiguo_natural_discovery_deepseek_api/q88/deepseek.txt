线上卖水果，差评主要来自两类：**坏果**和**口感不稳定**。减少这两类问题，核心不是“买更好的水果”，而是把采购从“凭经验挑货”变成“按标准收货、按批次留样、按数据淘汰供应商”。可以按下面几层做。

**一、先定可执行的收货标准，不要只写“新鲜无坏果”**

对每个主推单品做一张验收卡，至少包含：
- **规格**：单果重区间、果径、箱装净重允许误差。
- **成熟度**：按品类定，比如芒果看肩部转色和硬度，柑橘看糖酸比和果皮紧实度。
- **外观缺陷**：允许的轻微花皮比例，明确“腐烂、流汁、霉变、裂口、压伤”为零容忍。
- **口感底线**：糖度下限、酸度上限、纤维感、水分感。糖度用折射仪抽测，不要只靠尝。
- **批次一致性**：同批次糖度极差、大小极差设上限，防止“有的很甜有的很酸”。

验收卡要写成供应商能签字的标准，收货时按比例抽检，不合格整批拒收或降级，不要事后扯皮。

**二、采购端把“批次”管起来**

- **按批次编号**：每个到货批次记录产地、采摘/包装日期、供应商、运输方式、到货温度、抽检糖度和坏果率。
- **留样**：每批留 3—5 个样品，冷藏或冷冻保存，出现差评时能回溯是批次问题还是配送问题。
- **小批试销**：新供应商或新产地先小批量上架，观察 3—7 天差评率和退货率，再放量。
- **多供应商备份**：同一单品至少两家供应商，避免单一产地天气或成熟度波动导致整店口感翻车。

**三、用“到货坏果率”和“售后坏果率”分开考核**

到货抽检坏果率高，是采购/供应商问题；到货好好的但客户收到坏果多，是包装、分拣或配送问题。两个指标分开看，才能知道该换供应商还是改包装。建议设红线，比如到货抽检坏果率超过 3%—5% 就预警，超过标准拒收；售后坏果率按单品周度排名，连续两周超标的供应商降级。

**四、口感不稳定重点抓“成熟度”和“批次混装”**

口感差评很多时候不是果子坏，而是**成熟度不齐**。采购时要求供应商按成熟度分级，不要大小果、青熟果混装；需要催熟的品类，在仓内做分批催熟和糖度复测，达到标准再发货。对糖度波动大的单品，宁可按“口感稳定款”少上几个 SKU，也不要一个链接里混多个产地批次。

**五、包装和分拣也要算进采购方案**

采购谈价时把包装成本一起算：易压伤的水果用蛋托/网套+隔板，浆果类控制单箱层数，夏季加冰袋或保温袋。分拣时二次剔除软果、裂果，不要指望客户自己挑。很多坏果差评是“采购标准没问题，但分拣和包装把好果弄坏了”。

**六、用差评反推采购**

把差评按“坏果/不甜/太酸/太小/不新鲜/压伤”打标签，每周和批次号对齐。连续出现“不甜”的批次，下一轮就提高糖度抽检比例或换供应商；出现“压伤”集中，就改包装或缩短运输链路。采购考核不要只看采购价，要看**综合损耗率+售后率+差评率**。

一句话：**采购时把口感写成糖度/酸度/成熟度指标，把坏果写成抽检比例和拒收规则，按批次留样追溯，用售后数据淘汰供应商。** 这样比单纯“找好货源”更能稳住评价。
