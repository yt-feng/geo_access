香蕉配送的核心矛盾是：**它还在呼吸、还在后熟，而且怕压、怕冷、怕闷**。控制压坏和变黑要从“选品—包装—温控—配送—售后”五个环节一起做，不能只靠加厚箱子。

**1. 选对成熟度和品种**
- 配送香蕉不要用全熟果，选**七成到八成五成熟、果指硬挺、棱角还略明显**的青黄蕉；到消费者手里刚好能放2～4天。
- 优先选**抗压、果皮较厚**的品种或产区货，比如部分高山蕉、粉蕉/芭蕉类可作差异化，但主流还是香芽蕉。
- 入库后按成熟度分拣，**不要混装**，否则一箱里熟的催青的，青的还没卖就烂了。

**2. 包装：防压 + 防闷 + 防摩擦**
- 单根套**珍珠棉网套或薄EVA泡沫套**，重点保护果指中段和果柄。
- 装箱用**瓦楞纸箱 + 内部隔板**，每层之间加**瓦楞纸板或珍珠棉片**，限制晃动；箱内不要装太满，留5%～10%缓冲空间。
- 箱体开**透气孔**，不要用完全密封的塑料袋直接包整串香蕉，否则呼吸热和乙烯积聚，会加速变黑。
- 如果走快递，外箱选**五层瓦楞**，箱内空隙用纸填充，避免运输中反复碰撞。
- 不要和苹果、梨、番茄等**乙烯释放量大的果蔬混装**。

**3. 温控：怕冷也怕热**
- 香蕉最佳储运温度大约**13～15℃**，低于10℃容易冷害发黑，高于25℃后熟加快。
- 夏季用**冷藏车或保温箱+冰袋**，但冰袋不能直接贴果，要用纸或泡沫隔开，避免局部冻伤。
- 冬季防冻，短途可用保温箱，长途避免在低温环境长时间停留。
- 配送半径尽量控制在**同城或次日达**，香蕉不适合长距离多日运输。

**4. 配送环节**
- 快递面单标注“**易压、勿倒置、怕冻怕热**”，但不要只依赖面单，要和承运商约定**轻抛件、不叠压**。
- 尽量**整箱直立运输**，避免侧放和倒放，减少果指相互挤压。
- 同城即时配送用**带隔板的保温箱**，骑手箱内不要和重物混放。
- 发货前做**跌落和堆压测试**：比如1米跌落、箱上压20～30公斤静置24小时，看果指损伤率。

**5. 售后和运营兜底**
- 商品页明确写“**香蕉为后熟水果，表皮轻微黑点/青黄不均属正常**”，降低客诉预期。
- 设置**坏果赔付标准**：比如单根断裂、大面积压伤、果肉变黑按比例赔，拍照即可，不用退回。
- 记录每批货的**成熟度、包装方式、配送时效、坏果率**，连续跟踪2～4周，找出高损环节再调整。

**最优先做的三件事：** ① 发七至八成熟果；② 单根套网套+箱内隔板+透气孔；③ 同城/次日达，避免高温和低温直吹。先把这三项做到位，压坏和变黑会明显下降。
