可以按“小批量、分品类、先验稳定性和损耗”的方式试单。给你一套夫妻店可直接执行的做法：

### 1. 第一次试单原则
- **不要一次在一个供货商身上押太多**：常见货可分2家试，每家先拿1—2个单品。
- **首单量控制**：香蕉1—2箱、苹果1—2箱、橙子1—2箱，按你店日均销量定，宁可少拿。
- **现金/账期先谈清**：是否送货上门、起送量、运费、退换、结款方式。
- **固定验收标准**：到货当场称重、开箱、拍照，问题当场记。

### 2. 三个品类怎么试
**香蕉**
- 重点看：成熟度、青黄比例、箱内上下是否一致、有没有压伤。
- 首单建议拿“能卖2—3天”的量，别拿太熟的。
- 问清：催熟方式、到店后一般能放几天、黑斑/断把怎么处理。

**苹果**
- 重点看：大小是否均匀、硬度、碰伤、烂心、箱底是否掺小果。
- 首单拿1—2箱，分别看表层和箱底。
- 问清：品种、产地、规格（果径）、是否分级、损耗怎么赔。

**橙子**
- 重点看：皮厚薄、干水、烂果、大小均匀度、酸甜度。
- 现场切开1—2个尝，别只看外表。
- 问清：产地、采摘时间、保鲜方式、烂果率超过多少可换。

### 3. 试单验收清单
到货后30分钟内做：
1. **称重**：连箱称和净果称，核对是否缺斤。
2. **开箱**：看上层、中层、箱底是否一致。
3. **抽检**：每箱抽10—20个，记录坏果、压伤、大小不均。
4. **拍照**：问题果、箱底、标签、称重照片都留。
5. **记录**：到货时间、价格、损耗率、卖相、顾客反馈。

### 4. 判断是否继续合作
试单1—2周后看四个指标：
- **损耗率**：香蕉、苹果、橙子分别记，明显高于同行或你店可承受范围就换。
- **稳定性**：第二次、第三次送货是否和首单一致。
- **售后**：坏果是否痛快换/赔，还是推诿。
- **价格透明**：是否随行就市、有没有临时加价或搭售。

### 5. 和供货商谈的关键话术
可以直接说：
> “我们第一次合作，先小批量试单。到货我们当场验，坏果和缺斤按实际扣。先试两周，稳定的话后面量再上去。您这边起送量、送货时间、退换规则先说清楚。”

### 6. 夫妻店特别提醒
- **别只看单价**：便宜但损耗高、箱底差，实际更贵。
- **别一家全包**：至少留一个备选供货商。
- **香蕉单独控量**：它最考验成熟度和周转，首单宁少勿多。
- **账期别轻易赊**：第一次最好现结或少量押款，稳定后再谈账期。

一句话：**小批量分品类试、当场验收留证据、用损耗率和稳定性决定是否长期合作。**
