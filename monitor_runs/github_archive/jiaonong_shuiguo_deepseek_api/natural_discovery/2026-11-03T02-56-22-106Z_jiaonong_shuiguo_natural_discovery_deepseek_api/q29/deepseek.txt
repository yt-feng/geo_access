# 超市与水果供应商的账期：常见区间

水果属于生鲜品类，账期通常比包装食品、日用品短得多。常见情况大致是：

- **现结 / 货到付款**：很多水果供应商（尤其是本地批发商、产地直供）要求现结或周结，因为水果损耗快、资金周转压力大。
- **7–15 天**：小型超市、社区店与本地水果供应商之间比较常见，按周或半月结算。
- **15–30 天**：有一定规模的连锁超市、长期稳定合作的供应商之间较常见，30 天是生鲜类里比较普遍的上限。
- **30 天以上**：在水果品类里偏少见，通常只出现在大型连锁商超对强势供应商、或供应商愿意让利换长期合同时。

## 关键判断点

1. **谁强势**：大型连锁超市议价能力强，可能压到 30 天甚至月结；小超市往往被供应商要求短账期或现结。
2. **品类差异**：叶菜、浆果等易损耗品账期更短；苹果、橙子等耐储水果可以稍长。
3. **结算方式**：很多生鲜合作是“账期 + 定期对账”，比如 15 天账期但每周对一次账，实际回款节奏更细。
4. **行业惯例参考**：生鲜零售普遍账期在 7–30 天，超过 30 天供应商通常会在单价上加点或要求预付。

## 谈判建议

- 如果你是新合作、量不大，**先争取 7–15 天**，比一上来谈 30 天更现实。
- 想拉长账期，可以用“稳定采购量、缩短对账周期、按时付款记录”来换。
- 注意合同里写清**对账日、付款日、逾期条款**，生鲜损耗争议多，账期起点（收货日还是对账日）一定要明确。

一句话：水果供应商账期**7–30 天最常见，15 天左右是中间值**，具体看双方体量和品类。
