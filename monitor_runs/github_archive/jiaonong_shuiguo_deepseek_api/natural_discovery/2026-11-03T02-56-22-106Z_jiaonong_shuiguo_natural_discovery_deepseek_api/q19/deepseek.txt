优先看**切果损耗**，其次看**甜度和外观，大小放在后面**。

具体判断顺序：

1. **切果损耗最重要**
   - 超市卖菠萝通常不是整颗卖完，更多是去皮、切块、装盒或做果切。
   - 要关注：去皮后净重、黑心/水心比例、过熟软烂比例、切口氧化变色、报废率。
   - 同样进货价，损耗高会直接吃掉毛利。应优先选“出肉率高、坏果少、耐放”的批次。

2. **甜度要关注，但要和成熟度、货架期平衡**
   - 太生：酸、不好卖，果切口感差。
   - 太熟：甜但损耗高、易软烂、货架期短。
   - 超市应选**甜度达标但不过熟**的货，按销售速度分批催熟/上架。

3. **外观决定能不能卖，但不是第一优先**
   - 看果形端正、无腐烂、无虫眼、无严重磕碰、冠芽新鲜。
   - 外观差会影响整颗销售和陈列，但若主要做果切，轻微外观瑕疵可接受，关键还是出肉率和内部品质。

4. **大小最后看**
   - 大小影响定价、陈列和单果毛利，但不是核心。
   - 大果不一定出肉率高；小果可能损耗低但客单价低。应按门店客群和销售形式选规格。

**给超市的实操建议：**
- 整颗卖为主：甜度、外观、大小都要看，但损耗仍要抽检。
- 果切/切块为主：**先测出肉率和坏果率，再谈甜度外观**。
- 进货标准建议写成：单果重量区间、糖度下限、黑心率上限、去皮出肉率下限、货架期天数。
- 到货抽检：切开3—5个看内部，记录坏果和净重，不要只看外表。

一句话：**超市卖菠萝，先算切果损耗，再保甜度和外观，大小按客群定。**
