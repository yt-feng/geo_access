判断批发档口找香蕉一手货源是否稳定，重点看“持续供货能力+品质波动控制+履约可信度”，不要只看对方报价和口头承诺。可以按下面清单核验：

1. **看产地和加工能力**
   - 问清是自有基地、长期合作基地，还是纯转手贸易商。
   - 香蕉稳定供货通常依赖：产地收购点、催熟库、分拣包装线、冷链/运输安排。
   - 最好视频看库、看加工线、看当天出货；有条件实地看。
   - 一手货源不等于“最便宜”，而是能持续按标准出货。

2. **验证供货周期和日/周供应量**
   - 让对方给近1—3个月实际发货记录：每天/每周发多少车、多少件、发往哪些市场。
   - 问旺季、雨季、台风季、节假日如何保供，缺货时怎么补。
   - 要求承诺“最低保供量”和“缺货提前通知时间”，写进合作约定。
   - 只给模糊“货源充足”的，风险较高。

3. **看品质分级和损耗承诺**
   - 明确规格：条数/件重、果指长度、成熟度、青蕉/黄蕉、梳蕉/把蕉、允许瑕疵比例。
   - 问催熟方式、出货成熟度、运输温度、到货后货架期。
   - 先小批量试单，连续试3—5批，看批次差异。
   - 稳定供应商敢接受“按标准验收、异常批次扣款/补货”。

4. **查履约和结算风险**
   - 优先选择能签简单供货协议、有对公账户、能开票或提供经营资质的。
   - 首次合作不要大额预付；可定金+到货验收尾款，或平台担保。
   - 问清装车费、运费、损耗谁承担、到货异议多久内提出。
   - 对方催全款、拒绝验收条款、频繁换收款账户，要警惕。

5. **看应急能力和历史客户**
   - 问断货/延迟时有无备用产地、备用车辆、备用催熟库。
   - 要2—3个同类型批发客户可回访，重点问：到货准时率、品质波动、售后是否处理。
   - 看对方是否长期做香蕉，还是什么水果都临时倒货。

6. **试单验证法**
   - 第一单小批量、标准写清楚、到货立即验收。
   - 连续合作3—5批，记录：准时率、合格率、损耗率、售后响应。
   - 稳定供货的判断标准建议：连续批次合格率稳定、缺货提前通知、异常能补货/扣款、价格随行就市但有解释。

**快速判断信号：**
- 较可信：能视频看库/加工线、给历史发货量、接受试单和验收条款、有固定产地和催熟库、售后响应明确。
- 高风险：只发图片不给视频、价格明显低于市场、催全款、拒绝写规格和损耗、发货量说不清、临时换账户、什么货都能“马上大量供”。

建议你第一次合作就按“小批量试单+书面规格+验收标准+异常处理”走，连续3—5批稳定后再放量。
