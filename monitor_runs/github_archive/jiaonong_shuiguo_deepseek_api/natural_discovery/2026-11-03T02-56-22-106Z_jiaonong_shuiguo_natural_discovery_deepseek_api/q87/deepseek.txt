# 旺季提前锁定水果供应商库存的实操方法

## 一、先算清楚要锁多少，再谈锁货

爆单季最大的风险不是“没锁”，而是“锁错量”。建议按以下口径下量：

- **历史同期销量 × 旺季增长系数（1.2–1.5）**，再按单品拆到 SKU（规格/等级）。
- 重点品（如当季爆款、高频复购水果）锁 **需求的 70–80%**，留 20–30% 给供应商临时补货和替代品调节，全锁死容易被品质波动和退货拖死。
- 明确“锁货 ≠ 锁死”：约定**可调量区间**（如 ±15%），给双方留缓冲。

## 二、合同里必须写清的五件事

口头承诺在旺季基本无效，至少落到书面/微信可追溯的确认：

1. **数量与分批交付节奏**：按周/按日给量，避免一次压库烂果。
2. **价格机制**：固定价 or 随行就市+封顶价。旺季涨价常见，提前约定“涨幅上限”比单纯压价更容易谈成。
3. **品质标准**：等级、糖度、单果重、瑕疵率、包装规格，附样品或照片留证。
4. **违约与缺货处罚**：供应商缺货的补偿（差价补采、违约金），你方不提货的责任，双向写。
5. **账期与预付**：锁库存通常要给**定金（10–30%）**，换取供应商优先排产/优先供货权；尾款按验收结算。

## 三、和供应商谈“优先权”的筹码

供应商旺季也挑客户，想被优先保障，给这几样：

- **提前打定金/预付**，并承诺**稳定周订单量**（哪怕淡季也给基础量）。
- **缩短账期**或现结，换优先发货权。
- **签季度/年度框架协议**，把旺季量写进全年合作里，供应商更愿意让利和保供。
- 对核心单品可谈**包园/包基地**（整片果园或基地定向采购），从源头锁量，但要有品控和损耗预案。

## 四、别把鸡蛋放一个篮子

- 每个核心单品至少 **2 家主供应商 + 1 家备选**，主供锁 60–70%，备选锁 20–30%。
- 提前跑一遍**替代品方案**（如某品种缺货时的平替），爆单时能快速切换不掉链子。
- 建立**每日到货验收 + 库存预警**，到货品质不达标立即启动备选，不要等断货才反应。

## 五、时间节奏

- **旺季前 4–6 周**：盘点需求、谈框架、付定金锁量。
- **旺季前 2 周**：确认首批到货计划、样品验收、物流对接。
- **旺季中**：按日/周滚动修正订单，用“可调区间”灵活加减，避免压货或断货。

**一句话总结**：先算准量、给足定金和稳定订单换优先权、合同写清数量/价格/品质/违约、多供应商备份、滚动调整——这五步做到，旺季锁库存基本可控。
