# 生鲜平台做一件代发水果，供应商需具备的仓配能力

一件代发的核心是：**平台接单 → 供应商直接发货给消费者**。水果品类损耗高、时效敏感，供应商的仓配能力直接决定客诉率和毛利。建议按以下维度审核：

## 一、仓储能力

1. **专业温区仓储**
   - 具备冷藏（0–10℃）、常温、部分品类需冷冻（-18℃）的多温区库房，且能按SKU分温区存储。
   - 库内温湿度监控和记录可查（这是品控和理赔的关键证据）。

2. **产地仓或销地仓布局**
   - 水果一件代发对时效要求高，供应商需在主要销售区域有销地仓（或至少区域分仓），否则跨省直发时效和损耗都难控。
   - 产地直发模式要评估：产地到消费者的干线时效、是否发顺丰/京东等高时效快递。

3. **分拣与预包装能力**
   - 能按订单做单果分拣、称重、套袋/网套、贴标、装箱，支持平台要求的包装规范（防压、防撞、透气）。
   - 有分级标准（果径、糖度、外观），能做到“所见即所得”，减少货不对板客诉。

4. **库存与批次管理**
   - 系统能对接平台订单（API/ERP对接），实时库存同步，避免超卖。
   - 批次/采摘日期可追溯，先进先出，控制库龄。

## 二、配送能力

1. **快递资源与时效**
   - 有稳定的快递合作（顺丰、京东、中通等），能承诺发货时效（如48小时内发出）和签收时效。
   - 具备冷链快递或保温包装方案（冰袋、泡沫箱），按季节和距离匹配包装。

2. **订单履约能力**
   - 支持一件代发的打单、拣货、打包、出库全流程，日处理订单量能覆盖平台峰值（需问清日均/峰值单量）。
   - 有异常订单处理机制（缺货、地址异常、拦截）。

3. **售后与逆向物流**
   - 坏果包赔的判定标准和流程（拍照理赔、补发/退款）。
   - 能处理拒收、退回，逆向物流成本谁承担要提前约定。

## 三、系统与协同能力

- **订单系统对接**：能通过API/ERP与平台打通，自动接单、回传物流单号。
- **物流轨迹回传**：单号及时上传，轨迹可查。
- **数据能力**：能提供发货及时率、破损率、客诉率等履约数据。

## 四、审核建议（可执行清单）

合作前让供应商提供并核验：
1. 仓库地址、温区照片、温控记录样例；
2. 日均发货单量、峰值单量、发货时效承诺；
3. 合作快递及冷链方案；
4. 系统对接方式和物流单号回传时效；
5. 坏果赔付标准与历史客诉率；
6. 试单：先小批量试发，测时效、破损率和包装。

**一句话判断标准**：供应商能否做到“接单后48小时内发出、主要区域3–4天签收、破损率可承诺、坏果有明确赔付”，这四点过了，一件代发基本可跑通。
