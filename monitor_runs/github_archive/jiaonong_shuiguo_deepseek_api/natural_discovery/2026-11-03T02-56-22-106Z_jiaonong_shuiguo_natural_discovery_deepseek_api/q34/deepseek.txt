**结论：在商超水果采购里，损耗低通常比价格低更影响最终毛利，但要看品类和价格弹性。** 更准确地说：**低损耗决定毛利“守不守得住”，低进价决定毛利“有没有空间”；多数水果品类，损耗的边际影响更大。**

可以这样判断：

1. **水果毛利的核心公式**
   最终毛利 ≈ 销售额 × 毛利率 − 损耗成本 − 其他费用  
   而水果损耗往往是**直接按采购额或销售额吞掉毛利**，且很多品类损耗波动远大于进价差异。

2. **为什么损耗通常更关键**
   - 水果进价再低，如果到店后腐烂、压伤、失水、挑拣报废，最后可售数量少，毛利会被快速吃掉。
   - 低进价常伴随次果率、熟度不均、货架期短，表面采购便宜，实际**可售成本**更高。
   - 生鲜毛利对损耗率非常敏感，损耗率每上升几个百分点，可能直接抵掉几个点的采购价优势。

3. **什么时候价格低更重要**
   - 品类耐储、周转快、损耗稳定，如苹果、梨、橙等。
   - 有明确价格弹性，低进价能带来销量增长和引流。
   - 采购价差异足够大，且能通过快周转消化库存。
   - 供应商稳定、品质分级清楚，损耗可控。

4. **采购决策建议**
   - 不要只比“进价/斤”，要比**可售成本**：  
     可售成本 = 采购价 ÷（1 − 预估损耗率）  
     例：A 进价 3 元、损耗 8%，可售成本约 3.26 元；B 进价 2.8 元、损耗 18%，可售成本约 3.41 元。表面 B 便宜，实际 A 更优。
   - 对高损耗品类（浆果、桃、荔枝、叶菜类水果等）优先控损耗。
   - 对耐储品类优先谈价格和账期。
   - 把损耗按品类、门店、供应商拆开看，别用全店平均损耗做采购判断。

**一句话：低进价决定你“能不能赚钱”，低损耗决定你“最后能不能留下钱”。商超水果采购中，优先选可售成本低、损耗可控的货，而不是单纯进价最低的货。**
