做水果生意，选供应商时最容易忽视的不是价格和品类，而是下面这些“软性但致命”的细节：

1. **稳定性而非单次质量**
   只看一批货好不好没用。要问：这个供应商全年能不能稳定供货？换季时能不能平滑切换品类？遇到天气减产时，他是优先保老客户还是谁价高给谁？长期生意靠的是“断货风险”，不是“最好那一批”。

2. **损耗责任怎么算**
   到货后烂果、压伤、规格不符，谁承担、怎么赔、多久内反馈有效？很多人口头说“包赔”，实际结算时扯皮。要在合作前把验收标准、赔付比例、拍照留证流程写清楚。

3. **分级是否一致**
   同一等级的水果，今天和下周规格是否一样？大小、糖度、成熟度、外观标准有没有书面约定？供应商分级随意，会导致你卖给客户的标准忽高忽低，复购率受损。

4. **账期和资金占用**
   低价往往伴随现款现货，高价可能给账期。要算综合成本：资金占用、坏账风险、压货损耗。长期稳定合作，账期条款比单价更影响现金流。

5. **产地和季节替代方案**
   只依赖一个产地或一个单品，风险很高。好的供应商应能告诉你：这个品类下个产区什么时候接上、替代品是什么、价格大概怎么走。没有替代方案的供应商，遇到减产就会把你拖死。

6. **物流和到货时间可控性**
   水果生意里“晚到一天”可能就是全损。要关注供应商的发货频次、冷链能力、装车标准、到货时间波动。别只看他仓库里的货，要看他路上的货。

7. **售后响应速度**
   出问题时，是几小时响应还是几天？有没有专人对接？长期合作最怕“卖的时候热情，售后找不到人”。

8. **供应商的下游客户结构**
   如果他的大客户和你高度重合，可能随时变成你的竞争对手；如果他客户太分散，你的订单优先级又低。了解他把货主要卖给谁，能判断你在他那儿的议价位置。

9. **合同外的口头承诺**
   “下次给你留好货”“有问题找我”这类话，不写进合同就等于没有。长期稳定靠制度，不靠关系。

10. **退出机制**
    合作前就想清楚：如果质量连续下滑、断供、涨价离谱，你怎么换供应商？有没有备选名单？有没有过渡库存？没有退出机制的供应商关系，本质上是把命脉交出去了。

一句话总结：**选供应商，先看“最差的时候他怎么做”，再看“最好的时候他给什么价”。** 长期稳定靠的是验收标准、赔付规则、替代方案和备选供应商，而不是感情和低价。
