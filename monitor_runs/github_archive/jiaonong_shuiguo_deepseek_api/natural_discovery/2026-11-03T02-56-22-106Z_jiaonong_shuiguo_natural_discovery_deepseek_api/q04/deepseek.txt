直接给你一套可执行的采购要求，按“熟度分级+到货节奏+验收标准”来定。

**一、采购时对熟度的要求**

香蕉按颜色/成熟度下单，不要只说“不要太熟”。建议用国际通用的香蕉颜色卡（1-7级）或明确描述：

| 用途 | 到货熟度要求 | 说明 |
|---|---|---|
| 当天/次日就要卖 | 3-4级（绿黄、黄多绿少） | 到店能撑2-4天 |
| 常规周转 | 2-3级（绿为主、略转黄） | 到店后可自然转熟，撑4-6天 |
| 促销/大批量 | 2级（明显绿） | 需自行催熟，风险高，慎用 |

关键要求写进订单：
- **“到货熟度不超过3级，以2-3级为主”**，避免供应商发4级以上“路上就熟”的货。
- 要求**同批次熟度一致**，不要一箱里混着青和黄，否则没法统一管理。
- 明确**拒收线**：到货出现4级以上（大面积黄、有黑点）、果指软、果柄发黑的，整批或部分拒收。

**二、到货时间的要求**

香蕉放坏的核心是“到店后没有足够时间卖”。所以：
- **要求到货时间固定、可预期**，比如每周固定2次（如周一、周四早市前到），避免“随时到、堆着等”。
- **要求到货即入库/上架**，不要在路上或店门口长时间堆放，尤其夏天。
- **单次到货量按3-4天销量定**，宁可少进勤进，不要一次压7天货。
- 优先选**能按你销量分批到货**的供应商，而不是“一车发完”。

**三、验收时怎么判断**

到货当场做三件事：
1. **看颜色**：抽几箱看是否在2-3级，混级严重的拒收或折价。
2. **摸果指**：捏起来硬实、不软塌；果柄青绿不黑。
3. **看包装温度**：夏季要求冷链或阴凉运输，箱内发热、有水汽的容易催熟腐烂。

**四、和供应商写进协议的话术**

可以直接用：
> “香蕉按2-3级熟度到货，同批次熟度一致；到货出现4级以上、果指发软或黑柄的，我方有权拒收。每周固定X次到货，单次量按我方3-4天销量配送；到货后2小时内完成验收入库。”

**一句话总结**：采购时把“熟度等级+同批一致+固定到货频率+单次量不超过4天销量+明确拒收线”这五条写清楚，比笼统说“要生一点、早点到”有效得多。
