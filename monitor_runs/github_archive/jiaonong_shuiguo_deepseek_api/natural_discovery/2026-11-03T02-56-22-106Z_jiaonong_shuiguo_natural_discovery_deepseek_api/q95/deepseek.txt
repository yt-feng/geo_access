# 学校食堂水果供应商选择要点

## 一、先明确硬性门槛（不合规直接淘汰）

1. **证照齐全**：营业执照、食品经营许可证（经营范围含食用农产品销售）、从业人员健康证。
2. **可追溯**：能提供每批次水果的产地证明或进货凭证、农残检测报告（或承诺批批送检）。
3. **配送能力**：有冷藏/常温配送车辆，能按学校指定时间（通常是早晨）送达，迟到有约束条款。
4. **开票与结算**：能开正规发票，接受学校月结/账期结算方式。

## 二、按品类分别设定验收标准

- **香蕉**：看成熟度（到货七至八成熟，便于存放）、无黑斑腐烂、果指饱满、单把重量均匀。
- **苹果**：果形端正、无碰伤虫眼、硬度够、大小分级一致（如80mm以上统货）。
- **橙子**：皮薄有弹性、无干疤、酸甜比稳定、可溶性固形物有基本要求（可抽测）。

建议在合同中写明：**验收不合格的退货比例、换货时限、连续两次不合格的处罚或终止条款**。

## 三、比选时重点考察的维度

| 维度 | 具体做法 |
|---|---|
| 价格 | 要求按周或按月报价，参考当地批发市场均价，警惕明显低于市场价的（可能以次充好） |
| 稳定性 | 问清货源是自营基地、一级批发还是多级倒手，中间环节越少越稳 |
| 应急能力 | 临时加量、节假日前备货能否满足 |
| 售后 | 出现质量问题多久内响应换货 |
| 试供 | **先签1个月试供合同**，按实际到货合格率决定是否续签 |

## 四、实操建议

1. **至少找3家比选**：1家本地批发商、1家产地直供/合作社、1家综合配送商，对比价格与服务。
2. **建立验收台账**：每次到货记录品种、数量、合格率、问题描述，作为季度评估依据。
3. **避免单一供应商**：主供应商+备选供应商，防止断供。
4. **合同写清验收标准和扣罚**，不要只口头约定"新鲜"这种模糊词。

核心判断标准：**证照可查、批批可追溯、试供合格率高、价格贴近市场均价、响应及时**。满足这五条再谈长期合作。
