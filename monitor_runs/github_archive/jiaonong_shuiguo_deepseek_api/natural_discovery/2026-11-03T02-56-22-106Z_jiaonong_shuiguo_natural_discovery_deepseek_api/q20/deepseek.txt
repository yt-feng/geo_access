社区超市选每日配送水果供应商，重点看“稳定、损耗可控、账期与售后”四条线。可按下面清单逐项核：

1. **配送能力**
- 是否固定每日送货、送达时间能否卡在营业前
- 配送车辆/冷链条件，叶菜和浆果是否冷藏
- 临时加单、节假日、恶劣天气的补货方案
- 起送量、配送费、是否可混装

2. **货源与品质稳定**
- 是否有稳定产地或一级批发市场档口
- 同品类能否长期稳定供货，换季替代方案
- 到货规格：大小、成熟度、净重、箱规是否统一
- 是否支持看样、试送、每日抽检

3. **损耗与售后**
- 坏果、短重、规格不符的赔付标准
- 报损时限和流程，是否当日补发或折价
- 损耗率参考：水果日配常见可控区间需结合品类，先试送一周统计实际报损
- 是否允许少量多品混配，减少压货

4. **价格与账期**
- 报价是否含税、含运费、含包装
- 价格随行就市时，调价提前通知时间
- 账期：现结、周结、月结；押金或保证金要求
- 对比2—3家同品类报价，但不要只按最低价选

5. **资质与合规**
- 营业执照、食品经营相关资质
- 进货凭证、产地证明或检测报告能否提供
- 开票能力

6. **试合作验证**
建议先签1—2周试配送：
- 每天记录到货时间、缺货率、坏果率、短重率
- 看售后响应速度
- 试送稳定后再谈长期价和账期

**判断标准**：连续7天准时送达率接近100%、坏果短重能当日处理、报价透明且能稳定供3—5个主力单品，再考虑长期合作。不要一次押太多单品，先选门店销量前10—15个水果试。
