# 坏果责任条款的核心思路

关键是把「损耗风险」从模糊的行业惯例变成**可举证、可分级、可追偿**的合同义务。以下按条款结构给出写法建议。

## 一、先定标准，再定责任

合同里必须明确「什么叫坏果」，否则责任无法落地。建议约定：

- **判定标准**：以到货抽检为准，明确腐烂、霉变、软烂、机械伤、冻伤等具体情形
- **判定方法**：抽样比例（如每批随机抽3箱或按5%抽检）、抽检时点（卸货后X小时内）、双方共同在场或第三方见证
- **分级**：轻度（可折价）、中度（可退货）、重度（整批拒收），不同等级对应不同处理

## 二、责任条款的三种写法（可组合）

**1. 按比例折扣结算**
约定坏果率在X%以内由批发商自担（合理损耗），超过部分按实际坏果重量从货款中扣减，或按「坏果率×货值」打折。适合长期合作、希望快速结算的场景。

**2. 退货/换货+运费承担**
约定超过约定坏果率时，批发商有权拒收或要求换货，退货产生的运费、装卸费、冷藏费由供货方承担。适合单批次金额大、易腐性强的品类。

**3. 损失赔偿+违约责任**
对因坏果导致的二次损失（如已转售订单违约、仓储费用）约定赔偿上限，并设置违约金条款。注意赔偿范围要写得具体，否则争议时难主张。

## 三、必须配套的举证与时效条款

坏果纠纷的难点在举证。建议同时写入：

- **到货验收流程**：卸货后限时（如24小时内）开箱抽检，拍照/录像留证，超时未提异议视为验收合格
- **异议通知**：发现坏果应在X小时内书面（含微信、邮件）通知对方，附照片和抽检记录
- **第三方检测**：争议较大时可约定送检机构或由双方共同委托，费用由责任方承担

## 四、容易漏掉的两个点

- **运输环节责任划分**：明确坏果是「装车时已存在」还是「运输途中产生」，最好约定装车前双方共同验货并签字，否则责任扯不清
- **不可抗力与免责**：极端天气、疫情管控等情形下的处理方式要单独写明，避免对方以不可抗力全盘免责

## 实操建议

条款写完不算完，**执行比条款更重要**：建议首单或前几单坚持共同验货、拍照留档，把抽检流程跑顺，后续再谈比例折扣才有依据。如果对方是强势供货方，优先争取「超比例扣款+限时异议」这两条，比追求全额赔偿更现实。
