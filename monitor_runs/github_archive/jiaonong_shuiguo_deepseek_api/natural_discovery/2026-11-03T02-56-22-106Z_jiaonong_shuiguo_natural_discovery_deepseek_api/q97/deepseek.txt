酒店采购水果盘原料，建议把“验收标准”写进采购合同或订单附件，按以下维度约定，并明确抽检比例、判定规则和退换货责任。

## 一、通用规格与外观标准

**1. 新鲜度与成熟度**
- 到货时处于适宜食用或可在约定时间内后熟至适宜食用的状态。
- 不得过生（硬、涩、无风味）或过熟（软烂、发酵味、出水）。
- 明确各品种的成熟度要求，如香蕉微黄、芒果微软有香气、猕猴桃稍软等。

**2. 外观**
- 果实完整、形状正常，无明显畸形、裂口、机械伤、压伤、虫眼、病斑。
- 表面清洁，无泥土、药斑、霉点、腐烂。
- 色泽符合品种正常成熟色泽，无明显褪色、褐变。
- 果蒂新鲜，不干枯、不发黑（适用于带蒂品种）。

**3. 规格与均匀度**
- 按品种约定单果重量或横径范围，如苹果≥200g、橙子横径70–80mm等。
- 同批次大小、色泽、成熟度基本一致，便于摆盘。
- 明确允许的偏差范围，如单果重量偏差不超过±10%。

**4. 口感与内部品质**
- 无异常异味、苦味、发酵味。
- 可约定糖度下限（如西瓜≥10°Brix、橙子≥9°Brix），按抽样检测。
- 无空心、黑心、冻伤、水浸状等内部缺陷。

**5. 安全与合规**
- 农药残留符合国家食品安全标准，供应商提供合格证明或检测报告。
- 无非法添加保鲜剂、打蜡需符合允许范围。
- 预切水果原料还需符合即食食品微生物要求。

## 二、按品类补充要求

- **浆果类（草莓、蓝莓、树莓）**：无霉烂、无渗液，蓝莓果粉完整，草莓无压伤；建议冷链到货。
- **瓜类（西瓜、哈密瓜）**：外形端正，无裂口，成熟度适中，切开无异味、无过熟水浸。
- **柑橘类**：果皮无严重斑点、无干疤，不干瘪。
- **热带水果（芒果、火龙果、木瓜）**：无冻伤（热带水果忌低温冷害），成熟度按约定。
- **苹果、梨**：无碰压伤、无褐变，果柄完整。
- **葡萄**：果穗完整，果粒不脱落、不渗汁，无霉变。

## 三、包装、标签与冷链

- 包装完好、清洁，无破损、受潮、污染；内包装与水果直接接触材料符合食品级要求。
- 标签注明品名、产地、等级、净重、采摘/包装日期、供应商信息。
- 需冷藏的品种明确运输温度，如浆果0–4℃、热带水果10–13℃（视品种），到货测温记录随货。
- 到货不得有冷凝水浸泡、挤压变形。

## 四、验收与判定规则（建议写入合同）

- **抽检比例**：按到货件数抽检，如每批随机抽3–5件，每件抽若干果。
- **合格判定**：约定外观不合格率上限（如≤5%）、腐烂率上限（如≤2%），超限整批拒收或按比例扣款。
- **退换货**：腐烂、霉变、严重压伤、农残不合格的，供应商无条件退换并承担运费；因原料问题导致酒店损失的，约定赔偿责任。
- **到货时限**：明确下单后到货时间及延迟违约责任，保证新鲜度。

## 五、可执行建议

1. 制作《水果原料验收标准表》，按品种列明规格、成熟度、允许缺陷和抽检方法，收货时逐项打勾。
2. 合同中附样品照片或封样，作为外观和成熟度争议的判定依据。
3. 要求供应商每批次提供农残检测报告或承诺书，定期第三方送检。
4. 对易腐品种约定“到货剩余货架期”，如草莓到货后至少可正常存放1–2天。

以上标准需结合酒店实际菜单、摆盘要求和当地供应能力调整，关键是量化可验收、责任可追溯。
