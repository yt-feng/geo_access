判断供应商能不能按时到车，核心不是听他口头保证，而是把“到车”拆成可验证的节点，并用进货节奏和合同条款兜底。给你一套可直接用的判断方法：

**1. 先问清“到车”的定义**
- 是装好货发车、还是到你的档口卸货？两者时间差很大。
- 到车时间具体到几号几点，迟到多久算违约。
- 谁负责找车、运费谁出、路上损耗谁承担。
- 香蕉是青蕉还是黄蕉、催熟和温控要求，避免“车到了货不能卖”。

**2. 核验供应商的履约能力**
- 看近1—2个月他给其他客户的到车记录：可以要求提供发货单、过磅单、车牌号、司机联系方式。
- 问产地：是自有基地、长期合作代办，还是临时调货。临时调货的最容易放鸽子。
- 问同期在发几车、有没有固定车队。只说“没问题”但说不出发车计划的，风险高。
- 查历史违约：迟到几次、怎么赔、有没有临时加价或换货。

**3. 要求给出可执行的发车计划**
让供应商提供：
- 采摘/装车日期和地点；
- 车牌号、司机电话、预计路线和到达时间；
- 装车后拍照或视频，过磅单同步发你；
- 途中每半天报一次位置。
拿不出车牌和装车时间的“按时”，基本不可信。

**4. 用小单试合作**
新供应商不要第一次就压大单。先发一小车，按约定时间考核；连续2—3次准时，再逐步加量。同时保留1—2个备选供应商，避免被单一供应商卡住。

**5. 合同和付款上锁死**
- 写明到车时间、迟到违约金、损耗标准、质量不达标扣款。
- 付款跟节点走：装车付一部分、到车验收后付尾款，别提前全款。
- 约定不可抗力范围，防止用“堵车、下雨”当万能借口。
- 保留聊天记录、发货单、过磅单，出问题好追责。

**6. 看香蕉本身的“时间风险”**
香蕉对温度和催熟敏感。要问清运输温度、是否预冷、途中会不会闷车。车准时但货捂坏，等于没到。验收时先看车厢温度记录和蕉指状态，再卸货。

**一句话判断标准：** 能说清车牌、装车时间、路线、赔付规则，并愿意小单试合作的供应商，才值得押量；只说“放心、肯定到”的，按高风险处理。
