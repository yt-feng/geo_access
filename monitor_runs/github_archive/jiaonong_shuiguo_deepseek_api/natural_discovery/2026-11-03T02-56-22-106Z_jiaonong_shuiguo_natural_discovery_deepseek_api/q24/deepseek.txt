建议把“资料索取”分成三档：准入资质、批次合规、检测与追溯。不要只要一张检测报告就放行。

**1. 供应商与基地准入资料**
- 营业执照、食品经营/生产相关许可。
- 供货商与种植基地/合作社的关系证明：直采合同、授权书或产地证明。
- 基地信息：地址、面积、主要品种、采收季。
- 农药管理制度：允许用药清单、安全间隔期执行记录、用药记录样本。
- 若为“三品一标”或绿色/有机认证，索取有效证书及认证范围。

**2. 按批次索取的合规材料**
- 每批次的产地证明或承诺达标合格证；承诺达标合格证要能对应到具体批次、品种、产地和开具主体。
- 采收日期、发货日期、批次号。
- 运输和贮存记录，尤其是冷链水果的温控记录。
- 供应商自检报告或委托检测报告，报告应包含样品名称、批次/采样日期、检测项目、方法、结果、判定依据、检测机构资质章。

**3. 农残检测资料要看“对不对得上”**
- 检测项目至少覆盖该品种常检出和禁限用农药，不能只给一张“合格”结论。
- 报告中的样品批次、产地、供应商要与到货批次一致；复印件要加盖供应商公章。
- 优先要近期的委托检测或快检记录；快检只能作为筛查，不能替代法定或高风险项目的定量检测。
- 对高风险品种、首次合作供应商、产地不明或价格异常低的货，要求批批附检测报告或提高抽检比例。

**4. 追溯与问题处理承诺**
- 要求供应商提供可追溯链条：基地—采收—分拣包装—运输—超市收货。
- 合同中写明农残超标时的退货、销毁、赔偿、复检费用承担和报告提供时限。
- 建立供应商档案，保存每批资料；资料不全的批次暂缓收货或加严抽检。

**实操判断标准：**
资料齐全不等于安全，但没有“批次对应”的检测报告和承诺达标合格证，就不应直接收货。采购时可明确要求：首次合作提供全套准入资料；日常每批提供承诺达标合格证和批次信息；高风险品种按月或按批提供定量检测报告；出现异常立即暂停该基地供货并送第三方复检。
