大型超市对水果供应商的要求，通常高于普通批发市场，核心是“食品安全可追溯 + 冷链不断链 + 稳定供货 + 快速损耗控制”。如果要做商超渠道，至少应具备以下几类能力。

## 一、食品安全能力

### 1. 合法资质与基地管理
- 营业执照、食品经营许可证或食品生产许可证（按实际业务形态）
- 水果种植基地或合作基地的备案、合作协议、产地证明
- 农药采购与使用记录，重点控制禁限用农药
- 采收前安全间隔期管理，避免农残超标
- 重金属、产地环境风险的基础检测或第三方检测报告

### 2. 检测与验收能力
- 入场快检：农残快检，重点品种可加做糖度、酸度、成熟度
- 定期第三方检测：农残、重金属、真菌毒素等按品类风险确定
- 验收标准：外观、规格、成熟度、糖度、伤果率、腐烂率、虫害、异味
- 留样制度：每批次留样，便于追溯和复检
- 不合格品隔离、退货、销毁记录

### 3. 追溯体系
- 批次管理：从基地、采收、加工、仓储到门店可追溯
- 一码追溯或批次码：至少能查到产地、采收日期、检测结果、发货时间
- 进出库台账：数量、批次、供应商、客户、时间、温度
- 召回机制：发现问题后能快速定位批次并通知超市下架

### 4. 加工与包装卫生
- 分选、清洗、打蜡、催熟等环节符合食品卫生要求
- 包装材料符合食品接触材料标准
- 车间、人员、工具、周转筐定期清洗消毒
- 防虫防鼠、防交叉污染
- 催熟剂、保鲜剂使用合规，并有记录

### 5. 体系与认证
大型超市通常偏好或要求：
- ISO 22000 或 HACCP
- 食品安全管理体系认证
- 绿色食品、有机认证、GAP（良好农业规范）
- 出口备案基地资质（部分高端渠道）
- 第三方审核报告，如 BRC、IFS（部分外资超市）

## 二、物流与供应链能力

### 1. 冷链能力
水果品类差异大，但商超通常要求：
- 预冷：采后尽快预冷，降低田间热
- 冷藏运输：易腐水果全程冷链，温度按品类控制
- 冷库仓储：分温区存放，避免混放催熟
- 温度记录：运输和仓储全程可查，异常可报警
- 断链处理：有应急预案，断链批次需评估是否可售

### 2. 仓储与分拣能力
- 常温库、冷藏库、催熟库分区
- 先进先出或先熟先出管理
- 分拣、分级、包装能力
- 周转筐清洗消毒
- 库存周转和损耗控制能力

### 3. 运输与配送能力
- 自有或稳定合作的冷藏车、常温车
- 按门店订单定时配送，支持日配、隔日配
- 多门店配送路线优化
- 车辆卫生、消毒、防串味
- 装卸过程防挤压、防暴晒、防雨淋

### 4. 订单与信息化能力
- 对接超市采购系统，支持电子订单
- 库存、批次、温度、检测数据可共享
- 发货准确率、准时率、缺货率可统计
- 异常订单快速响应
- 支持对账、结算、票据合规

### 5. 损耗与应急能力
- 损耗率控制：按品类设定标准，如叶菜、浆果要求更高
- 滞销、临期、破损处理机制
- 缺货替代方案
- 食品安全事件应急预案
- 旺季、节假日、极端天气保供能力

## 三、大型超市通常重点审核的指标

| 维度 | 常见要求 |
|---|---|
| 资质 | 证照齐全、基地备案、检测报告 |
| 安全 | 农残合格、可追溯、留样、召回 |
| 冷链 | 预冷、冷藏运输、温度记录 |
| 质量 | 规格稳定、糖度达标、伤果率低 |
| 交付 | 准时率、缺货率、订单满足率 |
| 损耗 | 批次损耗可控、临期处理机制 |
| 信息化 | 批次追溯、数据对接、电子对账 |
| 应急 | 召回、断链、缺货、投诉处理 |

## 四、最实际的最低配置建议

如果准备进入大型超市，至少先做到：
1. 营业执照、食品经营许可、基地合作协议齐全
2. 每批次农残快检，定期第三方检测
3. 批次追溯台账，能查到产地和检测结果
4. 采后预冷，易腐水果冷藏运输
5. 冷库分温区，温度记录可查
6. 分拣包装卫生达标，周转筐消毒
7. 能按门店订单稳定配送
8. 有不合格品隔离、退货、召回流程
9. 能对接超市订单和对账系统
10. 有损耗控制和旺季保供方案

简单说，大型超市要的不是“能送水果”，而是：**安全可证明、批次可追溯、冷链不断链、交付稳定、出问题能召回**。其中食品安全追溯和冷链能力通常是准入底线，物流稳定性和损耗控制决定能否长期合作。
