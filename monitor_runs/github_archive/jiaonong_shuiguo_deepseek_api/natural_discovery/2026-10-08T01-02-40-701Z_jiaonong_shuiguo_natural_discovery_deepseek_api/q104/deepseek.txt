单位采购水果遇到品质不一致，核心是把验收标准前置、把证据留全、把售后条款写进合同。下面按采购前、到货验收、售后处理三个阶段给可执行做法。

**一、采购前约定**
- 明确品种、产地、等级、单果规格（如直径、单果重）、成熟度、糖度范围。
- 约定验收标准和允许的不合格比例，例如“同批次不合格率不超过5%”。
- 写清售后：不合格部分如何补货、退款、折价；响应时限（如24小时内）。
- 约定到货时间、运输温度，易损水果（草莓、葡萄、桃）要求冷链或防震包装。

**二、到货验收怎么做**
1. **先看单据**：核对送货单、批次、数量、品种与订单一致。
2. **抽检取样**：按批次随机抽，不要只翻表面。大批量可按5%—10%抽检，小批量多抽几个点位。
3. **分项判定**：
   - 外观：颜色、果形、有无霉斑、虫眼、机械伤。
   - 硬度/成熟度：过生、过熟分别记录。
   - 规格：抽测单果大小、重量是否达标。
   - 气味/口感：有异味、发酵味直接判不合格。
4. **分类记录**：合格、可折价、不合格三档，分别称重或计数。
5. **拍照录像**：全景、批次标签、问题特写、称重过程，最好带时间和地点水印。
6. **双方签字**：验收单上写清合格数、不合格数、处理意见，送货人签字确认。

**三、售后怎么处理**
- 当场能定的：不合格部分拒收、要求补货或按比例扣款。
- 需要复检的：封存样品，约定复检时间和方式，避免拖延。
- 已入库后发现问题的：24小时内书面/微信通知供应商，附照片、视频、验收单。
- 补货：要求同等级补足，补货再验收一次。
- 退款/折价：按不合格数量占总量的比例计算，写入结算单。
- 多次不合格：按合同扣保证金或终止合作。

**四、关键注意点**
- 验收单和照片是最重要的证据，别只口头说。
- 不合格品单独存放、标识清楚，避免混入合格品。
- 生鲜有时效，发现问题当天处理，拖久了责任难界定。
- 如果合同没写售后条款，事后只能协商，所以采购前一定要落到纸面。

简单说：标准写进合同，到货按批次抽检、分类记录、拍照签字，不合格当场拒收或约定补货退款，事后凭验收单和影像追责。
