水果店遇到坏果，结算或赔付的关键在于：**先分清责任和验收阶段，再按合同/行业惯例处理，不能一律自己承担，也不能全部拒付。**

下面按常见情况给你可直接执行的判断和处理方式。

## 一、先判断坏果发生在哪个阶段

### 1. 到货验收时当场发现
这是最容易处理的情况。

- **建议做法**：当场拍照、拍视频，记录车牌、货箱、批次、数量。
- **处理原则**：
  - 坏果比例在合理损耗内：一般由水果店承担。
  - 超过约定标准或明显质量问题：可要求供应商补货、换货、扣款或退货。
- **常见行业标准**：
  - 叶菜、浆果类损耗较高，可能约定 5%～10% 合理损耗。
  - 苹果、橙子等耐储水果，合理损耗通常更低，可能 2%～5%。
  - 具体以你们合同或口头约定为准。

### 2. 入库后短时间内发现
比如第二天开箱发现底层烂果。

- **如果合同有质量保证期**：按合同执行，供应商应负责。
- **如果没有明确约定**：
  - 能证明是运输或供货时已存在的问题，可要求供应商赔付。
  - 无法证明是供货问题的，通常协商分摊。
- **关键动作**：保留原包装、批次标签、照片、视频、入库记录。

### 3. 销售过程中陆续发现
比如卖到第三天才发现内部腐烂。

- 这类通常较难全额追责，因为可能涉及储存条件。
- 如果同一批次大面积出现，仍可找供应商协商。
- 若因水果店冷藏、堆放不当导致，责任一般在水果店。

## 二、常见结算和赔付方式

按优先顺序，通常是：

1. **补货/换货**：供应商下次送货时补同等数量好果。
2. **直接扣款**：从本次或下批货款中扣除坏果金额。
3. **折价结算**：坏果按一定折扣计入，比如按 50% 或 30% 结算。
4. **退货退款**：坏果退回，供应商退款。
5. **共同承担**：责任不清时，按比例分摊。

## 三、建议的实操流程

1. **当场验货**：不要等卸完货再验，尽量在卸货前抽检。
2. **拍照留证**：坏果、包装、批次、数量、时间都要拍。
3. **书面确认**：让司机或供应商业务员签字确认坏果数量。
4. **按合同扣款**：有合同按合同，没有合同按双方长期惯例。
5. **及时沟通**：最好当天反馈，拖久了容易扯皮。
6. **下次结算时处理**：常见做法是本次先按好果结算，坏果部分挂账，下批补货或扣款。

## 四、如果没有书面合同怎么办

可以按以下依据协商：

- 微信聊天记录、订单、送货单；
- 以往交易习惯；
- 行业合理损耗标准；
- 司机或业务员现场确认记录。

建议以后至少保留：
- 送货单上注明“坏果数量”；
- 微信确认“本批坏果 X 箱，下批补/扣款 X 元”；
- 长期合作也最好写一个简单质量条款。

## 五、简单判断表

| 情况 | 责任倾向 | 处理方式 |
|---|---|---|
| 卸货前发现大量坏果 | 供应商 | 拒收、换货、扣款 |
| 到货少量合理损耗 | 水果店 | 自行承担 |
| 入库次日发现底层腐烂 | 看证据 | 协商补货或分摊 |
| 销售多日后发现 | 较难追责 | 协商，通常自担较多 |
| 同一批次大面积坏 | 供应商可能 | 退货、扣款、索赔 |
| 因自己储存不当 | 水果店 | 自行承担 |

## 六、最建议的做法

**先验货、再签字、后结算。**
坏果不要直接混入正常结算，应该在送货单上单独注明，并约定：
- 是补货；
- 还是扣款；
- 还是折价。

如果供应商长期不认，建议：
1. 换供应商；
2. 改为货到付款并当场验收；
3. 签订简单供货协议，写明坏果处理规则。
