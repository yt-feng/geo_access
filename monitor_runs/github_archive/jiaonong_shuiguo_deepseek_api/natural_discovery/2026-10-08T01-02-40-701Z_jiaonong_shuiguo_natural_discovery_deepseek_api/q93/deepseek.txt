便利店卖菠萝切块，**这三项都要关注，但优先级不同：**

1. **保质期：最优先，属于合规和食品安全底线**
   - 菠萝切块属于鲜切水果，通常要冷藏保存，保质期很短。
   - 必须明确标注或内部管控：切配时间、冷藏条件、售卖时限。
   - 一般便利店鲜切水果建议当天切当天卖，未售完按内部规定下架，不能只靠“看起来没坏”判断。

2. **包装：第二重要，直接影响保质期和损耗**
   - 包装要能防串味、防污染、减少汁液流失。
   - 建议用食品级密封盒或封膜托盘，冷藏陈列。
   - 包装上最好有切配日期/时间、保质期或“请尽快食用”提示。
   - 如果只是简单保鲜膜包一下，容易渗漏、氧化、被污染，也会影响顾客购买意愿。

3. **配送频次：第三重要，但决定你能不能稳定卖**
   - 如果门店自己切配，配送频次不是核心，核心是店内切配和冷藏管理。
   - 如果是中央厨房或供应商配送切好的菠萝，配送频次就要匹配销量和保质期。
   - 频次太高会增加物流成本，太低会导致缺货或临期损耗。
   - 更合理的是：根据日均销量、保质期、冷藏库存，设定“少量多次”配送。

**结论：**
- 先保**保质期管理**，这是不能出问题的。
- 再优化**包装**，它决定品质和损耗。
- 最后根据销量定**配送频次**，避免缺货和报废。

如果只能选一个最关键的：**保质期。**
如果做得好、想降低损耗：**包装和配送频次一起优化。**
