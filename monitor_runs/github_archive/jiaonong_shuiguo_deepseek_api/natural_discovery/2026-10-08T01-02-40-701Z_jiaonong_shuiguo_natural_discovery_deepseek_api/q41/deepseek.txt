判断商超采购的香蕉催熟能力是否稳定，核心不是看单批次“催得黄不黄”，而是看**到货状态、催熟响应、货架表现、批次差异**四条线是否可重复。可按下面执行。

**1. 先定采购验收标准**
- 要求供应商明确：品种、产地、采收成熟度、运输温度、到货硬度/糖度范围。
- 到货蕉应为“硬绿到微黄绿”，果指饱满，棱角不明显，无冷伤、水烂、黑心。
- 同批次青蕉硬度差异越小，后续催熟越稳。抽检可测硬度或用手感分级：硬、稍软、软。

**2. 固定催熟条件做小试**
每批到货先拿1—2箱做标准催熟测试：
- 温湿度、乙烯浓度/催熟剂用量、时间、通风换气尽量固定。
- 记录：转黄时间、转黄均匀度、果柄/果顶差异、是否青硬不熟。
- 稳定表现：到第3—5天整体转黄一致，无“半边黄、半边青”，果肉软化与皮色同步。

**3. 看催熟后的货架表现**
- 催熟后24—48小时是否迅速出梅花点、发黑、软腐。
- 黄熟后能否维持2—3天商品性，而不是一黄就烂。
- 同一箱内上下层、内外层差异是否小，说明催熟穿透和果实成熟度一致。

**4. 用批次数据判断稳定性**
建立简单台账，每批记录：
- 到货硬度/颜色
- 催熟开始与结束时间
- 转黄率、均匀度、损耗率
- 货架1天/2天/3天状态
连续看5—10批：
- 如果转黄时间波动小、损耗低、货架期稳定，说明供应商催熟能力或青蕉一致性较好。
- 如果同批波动大，先查是青蕉成熟度不齐、运输冷伤，还是催熟操作不稳定。

**5. 重点排查不稳定信号**
- 同一批有的很快黄，有的长期青硬：到货成熟度不齐或冷伤。
- 催熟后表面黄但果肉生硬：催熟温度/乙烯作用不足或果实未真正后熟。
- 黄得快、烂得也快：催熟过度、温度过高或到货已偏熟。
- 每到雨季/远途批次就波动：供应链和运输环节问题大于催熟技术问题。

**6. 采购决策建议**
- 对新供应商先小批量试单，连续跟3批再放量。
- 要求供应商提供催熟记录或允许商超做标准小试。
- 把“催熟后48小时货架表现”和“同批均匀度”写进验收/扣罚标准，而不只验到货外观。
- 若连续多批波动，优先换供应商或要求分产地、分成熟度批次供货。

简单判断：**到货一致、标准条件下转黄一致、催熟后货架一致、连续批次一致**，才算催熟能力稳定。只看某一批催得好，不足以判断。
