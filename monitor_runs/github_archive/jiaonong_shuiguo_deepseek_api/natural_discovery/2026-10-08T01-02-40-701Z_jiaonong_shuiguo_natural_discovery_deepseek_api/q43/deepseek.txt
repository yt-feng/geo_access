评估跨城市连锁门店的水果供应商仓配覆盖，建议从“能不能到、到得好不好、成本是否可控、风险是否兜得住”四个维度做，而不是只看供应商有没有分仓。

**1. 先看覆盖能力：能不能送到每个门店**
- **仓网布局**：供应商在你门店所在城市/周边是否有仓、分拨中心或合作仓。重点看“距门店最近仓的距离”和“是否具备跨城调拨能力”。
- **配送半径**：水果通常要求高频、短半径配送。要确认每个仓到门店的实际配送半径，以及是否覆盖你所有门店，尤其是偏远门店。
- **门店清单匹配**：拿你的门店地址清单，让供应商逐店标注：由哪个仓发货、预计到达时间、每周可配送频次。
- **冷链能力**：水果对温控敏感，确认是否全程冷链、是否有温控记录、能否提供在途温度数据。

**2. 再看履约质量：到得好不好**
- **时效**：下单到到店的时间、是否支持次日达/当日达、截单时间是否匹配门店补货节奏。
- **频次与批量**：水果周转快，能否支持小批量、多频次配送；起送量是否过高导致门店压货。
- **损耗率**：按品类看运输损耗、到店验收合格率、破损率。水果损耗通常比标品高，要单独约定标准。
- **验收标准**：到店后的品相、成熟度、规格是否一致；是否有退换货机制和时效。
- **异常处理**：缺货、延迟、品质不达标时的补发、赔偿、替代方案是否明确。

**3. 再算成本：是否可控**
- **物流成本结构**：配送费、冷链附加费、远距离附加费、起送门槛、退换货费用分别怎么算。
- **单店单均成本**：不要只看总价，要按“每店每次配送成本”“每箱/每公斤到店成本”横向比较不同供应商。
- **隐性成本**：门店收货人力、损耗、压货资金占用、因缺货导致的销售损失。
- **规模效应**：门店越集中，配送成本越低；如果门店分散，要评估是否值得设中转仓或区域分仓。

**4. 最后看风险：兜不兜得住**
- **产能与货源稳定性**：产地是否单一、是否有替代产地、季节波动时能否保供。
- **多仓冗余**：某仓故障或疫情/天气影响时，能否从其他仓调拨。
- **信息系统**：能否对接你的采购/门店系统，提供库存、在途、签收数据，方便你监控。
- **合同约束**：把覆盖范围、时效、损耗率、赔偿标准、旺季保供写进合同，避免口头承诺。

**一个可落地的评估方法：**
1. 列出你所有门店的城市、地址、日均水果需求量、补货频次。
2. 让候选供应商按门店逐店填写：发货仓、配送方式、时效、频次、起送量、冷链情况。
3. 选 3-5 家代表性门店做 2-4 周试配送，记录：准时率、损耗率、缺货率、单均成本、异常处理速度。
4. 按权重打分：覆盖能力 30%、履约质量 30%、成本 25%、风险 15%（权重可按你业务调整）。
5. 对不达标的区域，考虑“区域供应商+全国供应商”组合，而不是强行用一家覆盖全国。

**简单判断标准：**
- 如果供应商能在你 80% 以上门店实现 24-48 小时送达、损耗率低于行业约定值、单均成本可接受，基本可视为覆盖合格。
- 如果偏远城市需要 72 小时以上、起送量过高、无冷链或损耗不可控，就不适合直接作为主力供应商，最多做补充。
