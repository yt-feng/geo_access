核心思路：**把“补货”从口头承诺变成可执行的书面条款**，同时给门店留出“先用合格品顶班”的空间，避免断货停业。下面是可落地的约定方式。

## 一、合同里必须写清的4个要素

**1. 验收标准要具体，不能只写“新鲜”**
- 写明品种、规格、成熟度、糖度范围、单果重量区间、允许的瑕疵比例。
- 例：芒果单果≥250g，成熟度7-8成，黑斑面积≤5%，同批次不合格率>10%即整批拒收。
- 附照片或样品封样，作为验收依据。

**2. 补货时限要卡死**
- 约定“接到通知后X小时内送达”，比如：上午10点前反馈，当日16点前补到；下午反馈，次日10点前补到。
- 关键：明确**补货到店时间**，不是“发货时间”。

**3. 补货方式二选一，写进合同**
- **换货**：不合格品由供应商拉走，合格品补足，运费供应商承担。
- **补货+折让**：来不及换货时，供应商按不合格数量退款，或按比例折价，门店自行采购应急。

**4. 断货责任**
- 若供应商未按时补货导致门店停售某产品，约定赔偿（如按该产品日均营业额的一定比例）。
- 这条是谈判筹码，能倒逼供应商优先处理你的补货。

## 二、不影响营业的操作机制

**建立“应急替代”条款：**
- 允许门店在补货到达前，临时使用同品类其他合格批次或替代水果，供应商不得因此拒赔。
- 或者约定供应商常备一批“安全库存”，门店可先借调，后续结算。

**分级处理：**
- 少量不合格（如10%以内）：先挑拣使用，不合格部分下次补货时抵扣。
- 大量不合格（如超30%）：整批退回，启动紧急补货，同时门店启用备用供应商。

## 三、日常执行清单

1. **到货即验**：拍照、称重、记录不合格数量，30分钟内发供应商。
2. **书面确认**：微信/邮件发《补货通知单》，写明品名、数量、到货时限，要求对方回复确认。
3. **留痕**：所有沟通保留记录，作为后续扣款或索赔依据。
4. **备用供应商**：至少备1家，防止单一供应商掉链子。

## 四、一句话总结

合同里写清**验收标准+补货时限+换货/折让方式+断货赔偿**，执行时**先验货留证、再书面通知、同时启用备用方案**，就能把水果不合格对营业的影响压到最低。
