做水果生意，供应商选择最容易忽视的往往不是价格、品种这些显性指标，而是下面这些**隐性但决定长期稳定性**的细节：

**1. 供货的“稳定性”而非“峰值能力”**
很多供应商旺季能给你好货，但一到淡季、雨天、节假日就断供或降质。要问清楚：全年供货曲线如何？有没有备选产地？断供时怎么补偿？

**2. 分级标准是否一致**
同样叫“一级果”，不同供应商的糖度、大小、瑕疵容忍度可能完全不同。要建立自己的验收标准，并让供应商书面确认，否则每次到货都在扯皮。

**3. 采摘与预冷环节**
水果损耗的大头在采后。供应商是否做田间预冷、分级包装、冷链衔接，直接决定你到手后的货架期。这一项常被忽视，却最影响复购和损耗率。

**4. 账期与结算方式**
长期合作要谈清楚：是现结、周结还是月结？押金怎么算？价格随行就市时以谁的报价为准？这些不写清楚，后期容易翻脸。

**5. 售后与损耗分担**
到货烂果率超过多少由谁承担？是补货、折价还是退货？很多供应商口头承诺好，出问题就推给物流或天气。

**6. 是否“只做你一家的备胎”**
要了解供应商的主要客户结构。如果他太依赖某个大客户，你可能是随时被牺牲的；如果他很分散，你反而有议价和优先权空间。

**7. 信息透明度**
产地、批次、农药检测、运输温度记录能否提供？愿意提供这些的供应商，通常更靠谱，也方便你做溯源和品控。

**8. 合作弹性**
节庆临时加量、临时换品种、紧急调货，对方能不能配合？这考验的是关系深度和供应链调度能力，不是价格能解决的。

**实操建议：**
- 先小批量试单，跑完一个完整季节再决定长期合作；
- 把验收标准、损耗分担、断供补偿写进合同；
- 至少保留2家供应商，主次分明，避免被单一渠道卡脖子。

总结一句：选供应商，**看的不是他最好的时候能给你什么，而是他最差的时候会不会掉链子。**
