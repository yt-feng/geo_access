要区分**“固定”到底固定什么**：固定产地或批次本身不是目的，目的是让水果风味、糖酸比、出汁率、香气稳定到饮品配方能复现。建议是：

**1. 不要只固定“产地”，要固定“品种 + 等级 + 成熟度 + 加工规格”。**
同一个产地也会因季节、降雨、树龄、采摘期不同而波动。真正影响茶饮口味的是：
- 品种是否一致，比如台农、贵妃、金煌不能混用；
- 成熟度是否一致，太生偏酸涩，太熟香气易发酵；
- 果径/果重/出汁率/糖度范围；
- 是鲜果、冷冻果泥、NFC果汁还是果酱。

**2. 供应批次要固定，但允许合理替代。**
对连锁茶饮来说，更现实的是：
- 核心产品：固定供应商 + 固定加工厂 + 固定规格，批次间做糖度、酸度、香气检测；
- 季节产品：按产季切换产区，但提前做配方校准；
- 非核心/装饰性水果：可允许多产地，但要设验收标准。

**3. 采购合同里写“可量化标准”，而不是只写产地。**
可写：
- 糖度范围，如 10–12 Brix；
- 酸度范围或糖酸比；
- 出汁率下限；
- 色泽、香气、瑕疵率；
- 农残和微生物标准；
- 批次留样和退换货规则。

**4. 最稳的做法是“双源 + 盲测 + 小批次试产”。**
不要单一产地锁死，否则遇到减产、涨价、雨季风味变差会很被动。建议：
- 主供应商占 70%，备用供应商占 30%；
- 每批到货做糖酸比和感官盲测；
- 新批次先做小批量杯测，通过后再上门店；
- 配方端保留微调空间，比如用糖浆、柠檬汁、盐或酸度调节来补偿波动。

**5. 如果门店规模小，优先固定“供应商 + 规格”，而不是固定某个果园。**
小品牌没有检测能力时，找能稳定供货的加工商更现实。鲜果直采虽然新鲜，但波动最大；冷冻果泥、NFC 果汁、罐头或果酱更容易标准化。

一句话：**要固定的是风味标准和加工规格，不是死守某个产地。产地可以作为筛选条件，但必须配合品种、成熟度、糖酸比和批次验收。**  
对核心爆品，建议固定供应批次并做每批检测；对季节性产品，建议多产地预案加配方校准。
