家庭水果礼盒的核心是**“耐放 + 好吃 + 好看 + 不串味”**。苹果、橙子、香蕉、菠萝这四种里，菠萝和香蕉最容易出问题，所以组合时要特别注意。

## 推荐组合方案

### 方案一：稳妥家庭款（最推荐）
**苹果 4 + 橙子 4 + 香蕉 2 + 菠萝 1（小菠萝）**

- 苹果、橙子耐放，撑得起礼盒主体
- 香蕉少量点缀，两三天内吃掉
- 菠萝 1 个即可，多了占地方且易压坏其他水果
- 适合 3-5 口之家，总价可控，视觉也饱满

### 方案二：偏实惠量足款
**苹果 5 + 橙子 5 + 香蕉 2 + 菠萝 1**

- 去掉菠萝后可以多放苹果橙子
- 适合更看重“量”的家庭客户
- 香蕉依然只做点缀，不主推

### 方案三：偏精致小家庭款
**苹果 3 + 橙子 3 + 香蕉 2 + 菠萝 1（小菠萝）**

- 适合 2-3 人小家庭
- 礼盒不空、不浪费
- 客单价可以做得更精致

## 为什么不建议多放香蕉和菠萝

**香蕉的问题：**
- 催熟快，两三天就发黑
- 会释放乙烯，加速其他水果成熟
- 容易被压伤，影响礼盒卖相

**菠萝的问题：**
- 体积大、带刺，容易扎破其他水果
- 一个就占很大空间
- 家庭自己削皮麻烦，体验感一般

## 组合时的摆放建议

1. **底层放苹果、橙子**——硬、耐压、撑结构
2. **中层放菠萝**——单独用纸或网套包好，避免扎伤
3. **上层放香蕉**——最后放，避免被压
4. **香蕉和苹果尽量隔开**——苹果也释放乙烯，会加速香蕉变黑

## 团购实操建议

- **香蕉单独装袋**，不要和礼盒主体混放，让客户回家自己放
- **菠萝选小果**，或者直接换成“菠萝切好装盒”，体验更好
- **苹果橙子选中等个头**，太大占空间，太小显廉价
- **礼盒标注食用顺序**：先吃香蕉、菠萝，苹果橙子可放一周
- **如果做统一规格**，建议固定为：苹果4 + 橙子4 + 香蕉2 + 小菠萝1

## 一句话结论

家庭团购水果礼盒，**苹果和橙子做主力，香蕉和菠萝做点缀**，比例控制在 **苹果:橙子 ≈ 1:1，香蕉不超过2根，菠萝最多1个小果**，这样最稳、最好卖、也最不容易售后。
