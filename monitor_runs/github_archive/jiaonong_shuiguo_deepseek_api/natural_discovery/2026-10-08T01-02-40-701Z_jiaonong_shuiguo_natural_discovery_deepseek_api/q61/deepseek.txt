判断香蕉批发商是否稳定，核心不是看他报价多低，而是看他**有没有稳定的上游基地、加工能力和履约记录**。可以按下面几步实操筛查：

**1. 先问清货源结构**
- 是自有基地、合作基地，还是纯倒手？
- 自有/长期合作基地的，稳定性通常高于临时调货。
- 问产地：广西、云南、海南、老挝、越南、菲律宾等，不同季节主产区不同，能说清“这个季节主供哪里”的更可信。

**2. 看加工与催熟能力**
- 香蕉到档口前通常要经过催熟、分拣、打包。
- 有固定催熟库、加工线的，供货和品质更稳。
- 只靠临时租库、代加工的，旺季容易掉链子。

**3. 查履约记录**
- 让他提供近3个月的发货记录、物流单、合作档口名称（可脱敏）。
- 问几个老客户，重点问：断供频率、到货成熟度、损耗率、售后处理。
- 稳定供货商一般敢给2-3个可回访客户。

**4. 小单试单**
- 先发1-2车或几吨，不要一上来大额打款。
- 观察：是否按约定时间到货、成熟度是否一致、坏果比例、补货响应速度。
- 试单2-3次再谈长期。

**5. 看资金和物流安排**
- 是否要求全款预付？稳定供货商通常能接受定金+到货结。
- 有没有固定冷链/物流合作？临时找车的，旺季容易延误。
- 问清是否包售后：到货坏果、催熟失败怎么赔。

**6. 现场或视频验厂**
- 有条件就去产地或加工厂看：库容、加工线、在库量、工人是否正常运转。
- 去不了就视频连线，看实时库存和发货现场，别只看照片。

**7. 风险信号**
- 报价明显低于市场价
- 催你大额打款、不给试单
- 说不清产地和加工环节
- 回避提供老客户或发货记录
- 承诺“全年任何时间都能大量供”但无基地

**简单判断标准：**
能说清产地季节、有固定加工/催熟能力、敢给可回访客户、接受小单试单、有明确售后条款的，基本可视为较稳定。反之，只靠低价和口头承诺的，风险高。

建议你先小单试2-3次，同时回访他给的老客户，再决定是否长期合作。
