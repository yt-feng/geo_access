线上卖水果，差评通常集中在三类：坏果/烂果、口感不一致（不甜、发酸、发绵）、以及大小/成熟度与描述不符。采购环节能解决大部分问题，核心思路是：**把“靠运气”变成“靠标准和验收流程”**。以下是可执行的做法。

## 一、先定标准，再谈采购

采购前必须写清楚可验收的规格，否则供应商和你对“好果”的理解不一致。

- **成熟度标准**：明确是“发货成熟度”还是“到货成熟度”。比如芒果发7成熟、香蕉发青、草莓全红但不软。
- **糖度/酸度指标**：能用糖度计测的就定数值，如西瓜中心糖≥11、柑橘≥10、葡萄≥16。
- **单果规格**：重量区间、直径/横径、果形。写“中大果”没用，要写“单果200–250g”。
- **外观容忍度**：允许的瑕疵比例，如轻微日灼、小斑点可接受，裂口、霉点零容忍。
- **硬度/口感**：脆桃要硬，水蜜桃要软；猕猴桃到货硬度范围。

## 二、选供应商时重点看这些

1. **产地直采优先于多层批发**：中间环节越多，存放越久，坏果和口感衰减越严重。
2. **看分选能力**：有分级机、糖度分选、冷链预冷的供应商，稳定性明显更好。
3. **看采摘和发货节奏**：是否按订单现采现发，还是提前囤货。囤货是口感不稳定的主因。
4. **要历史数据**：让供应商提供近批次的糖度、坏果率、客诉率。拿不出来的要谨慎。
5. **小批量试单**：新供应商先试1–2批，按你的验收标准打分，再决定是否放量。

## 三、到货验收怎么做才有效

1. **抽样要随机且够量**：大货按比例抽，如每批抽3–5箱，每箱抽若干果，不能只抽表面。
2. **当场测关键指标**：
   - 糖度：糖度计测；
   - 硬度：手感或硬度计；
   - 坏果：逐个翻看底层和中间层，烂果往往藏在里面。
3. **记录并留证**：拍照、称重、记批次。坏果率超过约定阈值就拒收或索赔。
4. **区分“运输坏果”和“本身坏果”**：到货即烂多是采摘/预冷/包装问题；放两天才烂可能是成熟度或保鲜问题。

## 四、减少坏果的关键动作

- **预冷要到位**：采后尽快预冷，尤其是浆果、荔枝、樱桃。没预冷的，坏果率会明显上升。
- **包装要抗压防震**：单果网套、托盘、隔层，避免运输中挤压。浆果用透气盒+冰袋，但别直接贴果。
- **控制成熟度发货**：易烂果发稍生，但要在详情页写清“需放几天后熟”，避免顾客收到就吃导致差评。
- **冷链不断链**：高温季节，普通快递发浆果基本等于赌运气。该用冷链就用。
- **缩短在库时间**：采购量按销量走，别为压价大量囤货。

## 五、减少口感不稳定的关键动作

- **按糖度分选，不按大小分选**：大小一样但糖度差很多，是口感差评的主因。有条件就做糖度分级。
- **同一SKU固定产区/品种/成熟度**：不要这批发A产区、下批发B产区，顾客会觉得“时好时坏”。
- **采摘期管理**：雨天采的果含水量高、风味淡，尽量避开雨后立即采。
- **后熟管理**：香蕉、猕猴桃、芒果等需要催熟或后熟的，要统一处理，不能一批催一批不催。
- **到货后先试吃再上架**：每批抽几个自己吃，糖酸比不对就调整发货或做促销，别硬发。

## 六、和供应商的合同/约定要写清

- 坏果率上限（如≤3%–5%，按品类定）；
- 糖度/规格不达标怎么赔；
- 到货时限和冷链要求；
- 客诉追溯：哪批出问题，供应商承担相应责任；
- 允许你方抽检和拒收。

## 七、一个简单可落地的流程

1. 定规格书（成熟度、糖度、大小、瑕疵容忍）。
2. 选2–3家供应商，小批量试单。
3. 每批到货抽检，记录坏果率、糖度、硬度。
4. 达标放量，不达标拒收或降级处理。
5. 每批自己试吃，再决定上架和文案。
6. 按周复盘客诉，反推是采购、包装还是物流问题。

**一句话总结**：采购时把“成熟度、糖度、规格、坏果率”变成可测量的验收标准，坚持小批量试单和到货抽检，坏果和口感不稳定就能大幅下降。最怕的是只凭供应商口头说“这批很甜”，没有标准和留证。
