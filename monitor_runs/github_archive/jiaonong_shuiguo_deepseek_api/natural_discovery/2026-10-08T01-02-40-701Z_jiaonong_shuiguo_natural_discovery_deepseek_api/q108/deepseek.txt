核实水果供应商的“全国配送”能力，可以从以下几个维度逐项验证，而不是只听口头承诺：

**一、要求提供配送范围清单和时效表**
- 让供应商给出可配送的省份、城市清单，以及各区域的标准时效（如次日达、隔日达、3-5天）。
- 重点问清偏远地区：新疆、西藏、青海、内蒙古、海南、云贵部分山区是否覆盖，是否加收运费或有最低起送量。

**二、核实物流合作方**
- 问清是自建物流还是外包，具体用哪几家快递/冷链公司（如顺丰冷运、京东冷链、中通冷链等）。
- 直接向该物流公司核实：该供应商是否是签约客户、其发货地能否发到你的收货地。
- 冷链水果要特别确认是否具备冷链资质，普通快递发水果容易坏。

**三、用小批量试单验证**
- 先下1-2个小单，发往你实际要覆盖的最远、最难送的地区，而不是发往总部附近的城市。
- 记录：下单到发货时间、实际到达时间、包装是否完好、水果损耗率、是否被中途转单或拒收。

**四、要求提供真实发货记录**
- 让供应商提供近1-3个月发往不同区域的实际物流单号样本，抽几个自己查轨迹，看是否真的送达、时效如何。
- 注意辨别：有些单号是发到中转仓，不等于直达终端。

**五、确认旺季和异常情况能力**
- 问清春节期间、恶劣天气、疫情管控时是否仍能配送，是否有备用方案。
- 水果有季节性，旺季运力紧张时是否优先保障你的订单。

**六、合同里写清责任**
- 把配送范围、时效承诺、损耗赔付标准、超时或无法送达的处理方式写入合同。
- 约定试单不合格可终止合作或调整价格。

**判断要点：** 如果供应商无法提供具体物流合作方、拒绝试单、或试单发往偏远地区就出问题，说明“全国配送”实际覆盖有限，可能只是能发快递，而非真正意义上的稳定配送。优先选愿意配合试单、能说清物流链路、偏远地区有明确方案的供应商。
