三者不是同一优先级，企业食堂采购水果应把 **食品安全放第一，配送准时放第二，价格放第三**。

原因很直接：

1. **食品安全是底线**
   一旦出现农残超标、霉变、腐烂、交叉污染等问题，可能引发员工集体肠胃不适甚至食源性疾病。企业食堂要承担法律责任、赔偿风险和声誉损失。水果又常是生食，风险比熟食更敏感。

2. **配送准时是保障**
   食堂供餐时间固定，水果到货晚了会影响出餐、加餐或下午茶安排。但准时必须建立在食品安全合格的基础上，不能为了准时接受来路不明或临期水果。

3. **价格重要，但不能优先**
   水果价格波动大，企业采购当然要控成本，但如果只压价格，容易买到等级低、成熟度差、农残风险高或冷链不达标的产品，后续损耗和食安成本更高。

实际操作上，可以这样排序和设条件：

- **先设食品安全门槛**：供应商资质、检测报告、进货台账、冷链条件、验收标准、留样或可追溯机制。
- **再设配送硬要求**：固定配送时间、迟到处理机制、临时加单响应、缺货替代方案。
- **最后比价格**：在合格供应商之间比价，按周或按月询价，设置最高限价和调价机制。

简单说：**食品安全是一票否决，配送准时是履约能力，价格是竞争条件。**  
企业食堂采购水果，不能先把价格放第一位。
