餐饮店每天少量水果，最省心的核心不是“找最便宜的”，而是**稳定、可退换、能按你用量配货、结算简单**。建议按这个优先级找：

1. **本地水果批发市场的固定档口**
   - 适合：每天用量不大，但希望品种能换。
   - 优点：价格比零售低，能当面看货，缺货可临时补。
   - 省心做法：固定1-2家档口，谈好“每天几点前下单、送到店/自提、坏果可换、月结或周结”。
   - 注意：不要只找一家，至少留一个备用档口，防止旺季或节假日断货。

2. **生鲜配送平台/B2B食材平台**
   - 适合：不想每天跑市场，想要线上下单、固定时间送。
   - 例如：美菜、快驴、菜划算等区域平台，具体以当地覆盖为准。
   - 优点：下单方便，有票据，退换流程相对标准。
   - 缺点：起送量、配送费、品质波动要看区域；少量可能不划算。
   - 省心做法：先试一周，重点看准时率、坏果率、售后响应。

3. **本地水果店/社区团购供货商**
   - 适合：每天只要几斤、几种，量很小。
   - 优点：灵活，能临时加单，老板好沟通。
   - 缺点：单价偏高，长期成本可能不低。
   - 省心做法：和一家店谈长期合作价，约定每天固定时间送，坏果当场退。

4. **产地/基地直供**
   - 适合：有稳定大单品，比如柠檬、橙子、西瓜，用量虽少但长期要。
   - 优点：品质和价格可能更好。
   - 缺点：通常起订量大，物流和售后麻烦，少量餐饮店不太适合。
   - 省心做法：只对1-2个用量稳定的单品做直供，其他交给本地供应商。

**最省心的组合建议：**
- 主供应商：本地批发市场固定档口或B2B平台，负责每天常规配送。
- 备用供应商：附近水果店或另一个档口，负责临时补货。
- 结算方式：优先周结/月结，减少每天对账。
- 验收标准：写清楚品种、规格、成熟度、坏果率、送达时间。
- 售后规则：坏果、烂果、缺斤少两怎么赔，提前说好。

**判断供应商是否省心，看4点：**
1. 能不能每天固定时间送到；
2. 能不能按你的少量需求配货，不强行起送；
3. 坏果能不能及时换或扣款；
4. 价格是否透明，账单是否清楚。

如果你们店每天水果用量很少，比如就几斤，**优先找附近水果店长期合作 + 一个批发市场档口备用**，通常比上大平台更灵活、更省心。如果用量稳定且稍大，再考虑B2B平台或批发市场固定档口。
