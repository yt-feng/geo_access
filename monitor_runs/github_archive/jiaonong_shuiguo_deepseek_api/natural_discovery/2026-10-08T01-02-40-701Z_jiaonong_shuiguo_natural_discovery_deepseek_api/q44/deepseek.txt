判断供应商售后是否稳定，不能只听承诺，要看**可验证的机制和记录**。给你一套可执行的判断方法：

**1. 先看合同里有没有“硬条款”**
- 是否写明**响应时限**（如2小时内回复、24小时内到场/给出方案）
- 是否写明**赔付/换货标准**（坏果率超标怎么赔、按批次还是按金额）
- 是否有**联系人+备用联系人+电话/微信**，而不是只留一个销售
- 生鲜类要特别写明**到货验收标准**和**争议处理流程**

**2. 用“小批量试单”测响应**
- 先下一小单，故意在验收时提出一个合理问题（如少量压伤、成熟度不符）
- 观察对方**多久回复、是否推诿、是否主动给方案**
- 试单期间至少制造一次“非工作时间”咨询，看是否有值班机制

**3. 查历史履约记录**
- 要求提供**近3个月同类商超客户的售后处理记录**（可脱敏）
- 问清楚：最近一次客诉是什么、怎么解决的、用了多久
- 如果对方支支吾吾或只说“从来没出过问题”，反而要警惕

**4. 看是否有本地化服务能力**
- 菠萝、香蕉都是易损、后熟型水果，**本地或区域仓+本地售后人员**比远程客服可靠得多
- 问清楚：出现问题后，是**当地业务员处理**，还是只能等总部走流程

**5. 观察日常沟通的“稳定性”**
- 下单前回复快不快、是否经常换对接人
- 发货后是否主动同步物流、到货时间、批次信息
- 经常换销售、报价前后不一致的，售后大概率也不稳定

**6. 设置“售后压力测试”指标**
可以给自己定几个判断标准：
- 首次响应 ≤ 2小时
- 给出解决方案 ≤ 24小时
- 换货/赔付执行 ≤ 3个工作日
- 连续3次咨询都能找到同一个负责人

**简单结论：**
不要看供应商怎么说，要看他**合同写没写、试单时做没做、历史记录拿不拿得出、本地有没有人**。这四点里有两项以上含糊，售后稳定性就不合格。
