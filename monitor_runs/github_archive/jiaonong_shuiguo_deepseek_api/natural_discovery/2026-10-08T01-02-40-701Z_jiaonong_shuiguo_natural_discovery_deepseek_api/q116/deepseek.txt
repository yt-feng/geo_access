# 小商家采购水果：现金结算 vs 月结账期的风险对比

## 一、现金结算的风险

**1. 资金占用大、周转压力重**
水果是高频刚需、损耗快的品类，每次进货都要即时掏钱。如果销售额不稳定（比如遇上台风天客流骤降），账上现金容易被库存"吃掉"，遇到大额订单反而没钱补货。

**2. 库存积压的隐性损失**
钱已经付出去，货却压在店里。水果保质期短，一旦滞销就是直接亏损；现金结算放大了这种"付了钱但货没卖出去"的风险。

**3. 验货后发现问题的追偿难**
现金当场结清，如果事后发现水果有内伤、打蜡、以次充好，再去找供应商换货/退钱，主动权较弱，尤其对没有书面凭证的小商家。

**4. 无账期=无信用积累**
始终现金结算，可能拿不到供应商的批量优惠或旺季优先供货。

**优点**：价格通常更低（有现金折扣）、关系清晰、不欠人情、不会被催债。


## 二、月结账期的风险

**1. 账期违约的连锁风险**
水果保质期短、毛利薄，一旦某月销售不及预期，月底凑不齐货款，容易失信于供应商，影响后续拿货甚至被断供。

**2. 容易"依赖账期"过度进货**
因为不用当场付钱，采购时容易放松预算，进货量超出实际售卖能力，导致损耗和欠款同时增加。

**3. 隐性涨价**
月结的报价往往比现金价高几个点，相当于变相支付了"资金成本"，小商家容易忽略这笔账。

**4. 对账纠纷**
水果按重量、批次结算，进出频繁，月末对账容易出现"我不记得这批货""重量对不上"的扯皮。

**5. 现金流"温水煮青蛙"**
账期让人误以为资金宽松，实际是欠款在累积，某个月集中还款时压力骤增。

**优点**：缓解短期现金压力、能先卖后付、旺季可多备货、有利于建立长期合作关系。


## 三、给小微商家的实操建议

| 场景 | 建议 |
|---|---|
| 新供应商/关系不熟 | 优先现金或**小额短账期**（如7天），先建立信任 |
| 老供应商、走量稳定 | 争取月结，但压货量不超过**1.5倍月均销量** |
| 高损耗、周转快的品类 | 现金结算，快进快出，避免压货 |
| 旺季备货 | 用账期备货，但要预留**至少1个月货款**的现金安全垫 |

**核心原则**：
1. **永远留足1个月的货款现金**，不管用哪种方式；
2. 账期不是"白用的钱"，把账期价和现金价的差额算清楚，看是否划算；
3. 优先维护**2~3家稳定供应商**，单一依赖任何一家都是风险；
4. 无论哪种结算，**保留过磅单、批次记录**，出问题才有依据。

一句话：**现金结算的风险是"钱压货"，月结的风险是"信用压现金流"**。小商家最稳的做法是——核心走量品用短账期，高损耗、试新品用现金，并始终守住现金安全垫。
