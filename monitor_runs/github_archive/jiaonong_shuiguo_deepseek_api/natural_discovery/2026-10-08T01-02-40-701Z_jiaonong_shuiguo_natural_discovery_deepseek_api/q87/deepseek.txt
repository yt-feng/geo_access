社区团购旺季和水果供应商锁库存，核心是**用确定性和风险分担换优先权**。单靠口头预订、临时加价基本锁不住，必须设计一套组合机制。

**1. 提前 30–45 天下意向单，而不是临近才下单**

水果旺季供应紧张，供应商会优先保障提前给量、给钱的客户。做法：

- 按去年旺季销量 × 1.2 倍，拆成周度预估量
- 明确品类、规格（果径、糖度、包装）、到货批次
- 给供应商一份滚动预测，每周更新未来 4 周需求

**2. 用预付款或定金锁产能**

供应商最怕的是你临时砍量。可以谈：

- 支付 10%–30% 定金，锁定对应产量
- 约定“保底量 + 浮动量”：保底量必须提货，浮动量提前 7 天确认
- 定金可抵货款，但若你违约不提货，定金不退

**3. 签保量协议，而不是只谈价格**

协议里要写清楚：

- 保底采购量、最高采购量
- 锁价周期和调价机制（比如随行就市时，涨幅不超过 X%）
- 优先供货权：断货时优先保你
- 质量标准、验收方式、坏果赔付比例
- 违约条款：供应商断供怎么赔，你砍量怎么赔

**4. 给供应商“确定性”，而不是只压价**

旺季供应商不缺订单，缺的是稳定大单。你可以提供：

- 长期合作承诺，不只做一季
- 缩短账期，甚至现结
- 共享你的销售预测，让供应商敢备货
- 接受部分非标果、二级果做引流款，帮供应商消化库存

**5. 多供应商分层，不要只押一家**

- 主力供应商：锁 60%–70% 量，签保量协议
- 备用供应商：锁 20%–30%，平时小单养着
- 应急渠道：批发市场或产地直发，补缺口

**6. 用“产地直采 + 前置仓”降低断供风险**

如果单量足够大，可以：

- 直接和产地合作社签采购协议
- 提前把货拉到前置仓或销地仓
- 对易损水果做预售制，先收款再采摘，减少库存压力

**7. 关键动作清单**

- 现在就算旺季周度销量，做滚动预测
- 筛出 2–3 家核心供应商，谈保量协议
- 付定金或预付款，锁定第一批产能
- 合同写清保底量、浮动量、调价机制、违约赔付
- 每周和供应商对一次量和到货计划
- 保留备用渠道，防止单一供应商掉链子

一句话：**锁库存的本质是让供应商相信你会稳定拿货，并且愿意为确定性付钱。** 提前量、定金、保量协议、多供应商备份，这四件事做到位，旺季断供概率会大幅下降。
