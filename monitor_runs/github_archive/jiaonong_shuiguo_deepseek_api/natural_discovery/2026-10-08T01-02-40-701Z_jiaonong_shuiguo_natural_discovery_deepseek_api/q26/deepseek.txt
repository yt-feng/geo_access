社区超市卖小包装香蕉，采购时重点盯三件事：**规格别贪大、熟度别贪黄、包装要能透气防压**。下面按可执行要点说。

**1. 规格：按“一次吃完”定，不要按斤拍脑袋**
- 常见小包装建议 **2–3 根/袋**，单根约 **120–150g**，整袋 **250–400g**。
- 如果是便利店/社区店，**300g 左右**最好卖；太大就失去“小包装”意义，太小又显得不划算。
- 采购时直接要求供应商按 **单根重量分档**，比如 120–150g、150–180g，别混装，否则一袋里大小差太多，顾客会觉得吃亏。

**2. 熟度：采购要“青一点”，不能按即食标准收**
- 小包装香蕉通常要在货架放 1–3 天，采购时建议收 **3–4 成熟** 或 **微青转黄** 的货。
- 如果收已经全黄、带糖斑的，损耗会非常高，尤其夏天一两天就发黑。
- 要求供应商做 **催熟分级**：青蕉、微黄、即食黄分开；小包装优先用 **微黄偏青**。
- 到店后如果太青，可常温催熟；如果已经黄，必须优先上架、尽快促销。

**3. 包装：核心是透气、防压、防掉把**
- **不要用完全密封的塑料袋**，香蕉呼吸会出水汽，闷着容易长霉、发黑。
- 选 **打孔 PE 袋、网袋、纸质托盘+透气膜** 都可以；社区店最实用的是 **打孔袋+托盘**，防压又透气。
- 如果做品牌感，可以用 **开窗纸盒+透气孔**，但成本高，适合客单价高的店。
- 包装上别把香蕉勒太紧，蕉柄位置容易压伤；最好让蕉指之间有一点缓冲。
- 如果按把卖，**保留蕉柄**，但要把切口修平，避免刺破袋子。

**4. 损耗控制：采购和陈列要联动**
- 采购量按 **日均销量×1.5–2 天** 来定，别一次压 3 天以上，香蕉不像苹果耐放。
- 到货后先做 **分级**：微黄的上正常货架，全黄的做特价/搭配酸奶/早餐组合，青的放后面。
- 陈列别堆叠超过 **2 层**，压伤后很快黑。
- 夏天最好 **冷藏柜外常温阴凉处** 卖，不要放太阳直射或空调出风口；冬天避开暖气。
- 每天至少 **挑一次**，把开始出糖斑、发软的挑出来做 **打折区** 或 **员工试吃**，别等烂了再扔。

**5. 采购时直接问供应商这几句**
- 这批是几成熟？能不能按 120–150g 分档？
- 小包装用的蕉是单独催熟还是统货？
- 到店后建议几天内卖完？
- 破损/黑斑超过多少可以退换？
- 能不能先小批量试单，比如 20–30 袋？

**6. 最容易踩的坑**
- 用密封袋装：水汽大，霉变快。
- 收全黄蕉做小包装：上架即损耗。
- 一袋装 5–6 根：顾客一次吃不完，反而不好卖。
- 堆叠太高压伤：黑斑从压痕开始。
- 不做分级：青的卖不动，黄的烂得快。

如果只记一句：**小包装香蕉采购，收微黄偏青、单袋 250–400g、包装必须打孔透气、按 1.5–2 天销量订货。**
