判断一批香蕉，核心是“看颜色、摸硬度、看棱角、查果柄/切口、抽箱闻味”，再结合你计划几天卖完来决定能不能拿。

**1. 先看颜色定熟度**
- **全绿、硬**：生货，适合长途或要放几天再卖。风险是催熟不均匀，冷害/药害时可能“青硬不熟”。
- **绿中带黄、果尖转黄**：开始转熟，通常1–3天进入可售期，批发最常用。
- **黄多绿少、果身黄**：已进入熟售期，适合1–2天内出货。
- **全黄、出现糖斑/黑点**：接近最佳食用期，零售好卖，但批发风险高，压一天就易烂。
- **大面积褐斑、果肉软塌**：过熟，坏果风险很高，除非当天低价清货，否则不建议拿。

**2. 摸硬度和看棱角**
- 轻按果身：**硬挺**=生；**略软有弹性**=适中；**一按一个坑**=过熟。
- 看香蕉棱角：**棱角明显、截面偏方**=生；**棱角变圆**=熟；**果身圆鼓、棱线不明显**=偏熟。
- 同一箱里如果软硬差异很大，说明熟度不匀，后熟/销售会很难控。

**3. 查果柄、切口和轴心**
- 果柄发黑、发霉、干缩：说明存放久或伤热，坏果风险高。
- 切口发黑、流汁、有酸味：可能已感染，整箱容易传染。
- 香蕉梳中间“轴心”发黑腐烂：不要拿，通常从内部坏。
- 果柄一碰就掉、果指容易脱落：过熟或受伤。

**4. 抽箱检查，不要只看表面**
- 每批至少抽几箱，翻看**底层、中间、靠箱壁**的果。
- 看有没有：压伤、裂口、水烂、霉斑、虫眼、冻伤。
- 冻伤香蕉：表皮暗灰、发黑，果肉硬心或水化，催熟也难正常变黄。
- 热伤/闷伤：果身发暗、有酒味，后熟快且易烂。
- 机械伤：局部发黑软烂，会从伤口开始感染。

**5. 闻味判断**
- 青草味：生。
- 正常甜香：开始熟。
- 酒味、酸味、发酵味：已经过熟或内部腐烂，风险高。
- 霉味：整批仓储/运输条件可能有问题。

**6. 结合销售周期拿货**
- 你**2–3天卖完**：可拿绿中带黄、少量黄。
- 你**当天或次日卖完**：可拿黄多、刚出糖斑的。
- 你**要放5天以上**：拿全绿或微黄、硬挺、无伤的。
- 如果你没有催熟条件，别拿全青硬货，容易砸手里。
- 如果你没有冷库，夏天别拿太熟，冬天注意防冷害。

**7. 快速判断坏果风险的口诀**
- 颜色越黄、斑点越多，坏果风险越高。
- 果柄/切口越黑、越湿，风险越高。
- 同一箱软硬越不匀，风险越高。
- 有酒味、酸味、霉味，直接放弃或大幅压价。
- 底层和中间比表面差很多，说明整批货不耐放。

**实操建议：**
拿货时随机抽3–5箱，每箱翻到底，按“颜色、硬度、果柄、气味、伤口”五项打分。只要出现**霉斑、酒味、轴心黑腐、大面积水烂**，这批货就不适合正常批发，除非你当天能低价清掉。对熟度不匀的货，宁可少拿，也不要贪便宜压库。
