水果锁价能锁多久，**没有固定标准**，主要取决于品类、季节、供应稳定性和双方的博弈关系。大致可以分几个档：

**1. 常规短期锁价：7～30天**
最常见。适合应季水果、价格波动快的品类（如西瓜、荔枝、草莓、叶菜类水果）。供应商一般只愿意锁 1～4 周，因为产地收购价一天一变。

**2. 中期锁价：1～3个月**
通常出现在：
- 供应端比较稳定的大宗品类（如苹果、梨、橙子、香蕉）
- 你有一定采购量、账期稳定
- 或者签的是“保底量+浮动价”的框架

**3. 长期锁价：3～6个月甚至一年**
一般是**大客户+大单量+预付款/保证金**才谈得下来。多见于进口水果、冷库果、长期合作的包装厂或大型基地。纯口头锁价很难撑这么久。

**关键点：锁价往往不是“锁死一个数”**

更现实的做法是谈这几种：
- **锁价+锁量**：价格固定，但你要承诺最低采购量，不然供应商不干
- **保底价+浮动区间**：比如基准价上下浮动 5%～10%
- **锁价但可调**：约定触发条件，比如产地价涨跌超过 15% 就重谈
- **分批锁价**：一个月一议，而不是一次锁半年

**能不能锁久，看这几个条件：**
1. 你的采购量是否足够大、是否稳定
2. 账期是否好（现结最容易谈长期）
3. 品类是否耐储存、供应是否集中
4. 是否愿意付定金或保证金
5. 供应商是产地直供还是中间商（直供更容易谈长）

**给你的实操建议：**
- 先按 **30天** 去谈，这是最容易达成的
- 想锁 3 个月以上，准备好 **最低采购量+预付** 作筹码
- 合同里写清：锁价期限、数量、质量标准、涨跌超幅重谈条款、违约处理
- 别只锁价不锁量，否则行情涨了供应商可能断供或降质

简单说：**散户能锁 1 个月不错，稳定大单 1～3 个月是常态，半年以上要靠量和钱换。**
