判断哪个规格更容易出货，核心看 **下游客户是谁、走货场景在哪、价格带能不能打**。菠萝批发里，规格通常按 **单果重量/果径** 分，比如：

- 小果：0.8–1.2斤
- 中果：1.2–1.8斤
- 大果：1.8–2.5斤
- 特大果：2.5斤以上

但真正决定出货快慢的，不只是大小，而是下面几个判断维度。

**1. 先看你的客户结构**

- **供水果店、社区团购、路边摊**：中果通常最好走。  
  因为单价适中、卖相稳定、消费者一次买一个不觉得贵。小果便宜但显得小气，大果单价高、动销慢。

- **供超市、精品水果店**：中大果更好走。  
  超市喜欢整齐、果形好、重量稳定的规格，愿意为品相付溢价。

- **供加工厂、果汁店、餐饮**：小果或统货更好走。  
  这类客户不看重单个卖相，看重出肉率、单价和稳定供应。

- **供电商、直播、社群团购**：中果和大果更容易做爆款。  
  因为要拍照、要显得划算，太小没视觉冲击，太大运费和损耗压力高。

**2. 看价格带和消费者心理**

菠萝是大众水果，消费者对单价敏感。  
一般来说：

- **10元以内能买到一个**：最好走，适合中果。
- **15元以上一个**：动销明显变慢，除非是精品大果或特殊品种。
- **按斤卖**：中果、大果差异缩小，关键看总价和果形。

所以如果你问“哪个规格更容易出货”，多数批发场景下答案是：

**中果最稳，大果看渠道，小果看加工，特大果最容易压货。**

**3. 看季节和产地**

- **旺季刚上市**：中果、大果都好走，因为尝鲜需求强。
- **大量集中上市**：中果最抗跌，小果容易砸价。
- **尾季**：小果、统货走加工更快，大果容易剩。
- **天气热**：小果、中果动销快，因为消费者买回去当天吃，大果吃不完容易坏。

**4. 看损耗和周转**

菠萝批发最怕压货。  
同样一笔资金：

- 小果：单价低，但客户可能嫌小，利润薄。
- 中果：周转最快，损耗可控，利润适中。
- 大果：利润高一点，但出货慢，损耗风险大。
- 特大果：除非有稳定精品渠道，否则不建议大量囤。

**5. 实操判断方法**

你可以用这4步快速判断：

1. **问下游**：最近三天哪个规格问的人最多、复购最多。
2. **看市场**：同市场里哪个规格摊位走得快，是整车走还是拆箱走。
3. **算周转**：同样放3天，哪个规格剩得最少、坏得最少。
4. **测价格**：把中果和大果各降0.2–0.3元/斤，看哪个先清完。先清完的，就是当前更容易出货的规格。

**6. 直接结论**

如果你做的是普通批发、客户以水果店和摊贩为主：

- **首选：中果，1.2–1.8斤**
- **次选：大果，1.8–2.5斤**
- **小果**：有加工厂或团购渠道再走
- **特大果**：除非精品渠道稳定，否则少碰

一句话：**中果最容易出货，大果看渠道，小果看加工，特大果断货风险最高。**  
但最终要按你当地市场的客户结构来测，不要只按规格拍脑袋。
