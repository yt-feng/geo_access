最应该先问**售后**，再问配送，最后谈价格。

原因是：水果是非标、易损、高损耗品类，团长真正亏钱的地方通常不是进货价高一点，而是坏果、烂果、重量不足、到货晚、售后扯皮。价格再低，如果售后不行，最后赔的钱和口碑损失会远高于省下的差价。

可以按这个顺序判断：

1. **售后**  
   重点问：
   - 坏果、烂果、压伤怎么赔？按比例赔还是全额赔？
   - 需要拍照吗？多久内反馈有效？
   - 是补发、退款还是抵扣下次货款？
   - 缺斤少两怎么处理？
   - 售后响应时间多长？

2. **配送**  
   重点问：
   - 是否冷链？还是普通车？
   - 到货时间是上午、下午还是晚上？能否固定？
   - 送到自提点还是送到团长指定位置？
   - 破损、延误谁负责？
   - 起送量、配送费、临时加单怎么算？

3. **价格**  
   价格当然重要，但要放到最后谈，而且不能只看单价。要算：
   - 到货实际净重
   - 损耗率
   - 售后赔付后的真实成本
   - 配送费摊到每单多少
   - 压货和退款风险

一句话判断标准：  
**售后不清楚的供应商，价格再低也别急着合作；配送不稳定的，会直接伤害团长口碑；价格只有在售后和配送都过关后，才值得比较。**
