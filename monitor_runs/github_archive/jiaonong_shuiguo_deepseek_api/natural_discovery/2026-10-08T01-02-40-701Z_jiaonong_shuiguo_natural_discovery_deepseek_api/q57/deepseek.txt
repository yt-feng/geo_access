对绝大多数餐饮连锁，**水果更适合“中央厨房/总仓统一收货 + 门店按需配送”**，但少数情况适合门店直收。核心判断看：水果品类、损耗风险、门店密度、供应链能力、结算方式。

## 一、优先统一收货的情况

适合：

- 门店数量多，比如 10 家以上
- 水果用于标准化产品：果茶、沙拉、甜品、果汁、套餐配果
- 采购量大，能拿到更好价格
- 希望统一品质、规格、农残检测、账期和供应商管理
- 门店没有专业收货/验货能力
- 需要做批次追溯、食品安全管控

优点：

1. **采购议价强**：总部集中采购，价格通常更低。
2. **品质标准统一**：糖度、大小、成熟度、品种更可控。
3. **食品安全可控**：农残检测、索证索票、批次追溯集中在中央厨房。
4. **减少门店腐败**：避免店长/厨师长私下采购、吃回扣。
5. **结算简单**：供应商对总部，门店内部调拨。
6. **配送计划化**：按门店销量预测分拣配送。

缺点：

1. **损耗可能增加**：多一次装卸、分拣、运输。
2. **配送要求高**：冷链、温控、时效不到位，水果容易坏。
3. **总部压力大**：中央厨房要有人负责验收、分级、催熟、周转。
4. **不够灵活**：门店临时缺货、突发客流不好补。

## 二、适合门店分开收货的情况

适合：

- 门店少，比如 1—5 家
- 水果是本地时令品，价格波动大
- 门店分布分散，统一配送成本高于直采
- 水果用于现场鲜切、摆盘，对成熟度要求每天不同
- 当地有稳定批发市场或供应商，门店能每天小批量补货
- 总部没有中央厨房或冷链能力

优点：

1. **灵活**：按当天客流、成熟度、陈列需求采购。
2. **短链新鲜**：本地直采可能更快。
3. **配送成本低**：尤其门店分散时。
4. **试错快**：新品、时令品可单店测试。

缺点：

1. **品质不稳定**：不同门店买到的货不一样。
2. **价格不透明**：容易有回扣、虚报。
3. **食品安全风险高**：检测、票据、追溯难统一。
4. **总部失控**：难以做统一菜单、统一成本。
5. **单店议价弱**：采购成本通常更高。

## 三、推荐模式：混合制

最实用的是：

### 1. 核心大单品统一收货
比如柠檬、橙子、苹果、西瓜、圣女果、冷冻果浆、果粒罐头。  
这些用量大、标准明确，适合中央厨房统一采购配送。

### 2. 本地时令/易损品门店直收
比如草莓、荔枝、杨梅、枇杷、鲜切果盒用水果。  
这些时效强、损耗高，可授权门店在总部指定供应商或价格区间内采购。

### 3. 总部定规则，门店执行
总部负责：

- 供应商准入
- 品质标准
- 价格上限/比价机制
- 验收标准
- 食品安全票据
- 每月审计

门店负责：

- 每日下单
- 到货验收
- 温度、成熟度、数量确认
- 异常拍照上报

## 四、怎么判断你该选哪种？

用这 5 个问题判断：

1. **门店数量是否超过 10 家？**  
   是：偏向统一收货。

2. **水果是否用于统一标准产品？**  
   是：偏向统一收货。

3. **水果损耗率是否超过 8%—10%？**  
   是：要重新评估配送链路，可能混合制。

4. **统一配送后到店品质是否明显下降？**  
   是：说明中央厨房分拣、冷链、时效不行，先改流程，不一定马上改门店直收。

5. **门店是否有能力验货、控损、防腐败？**  
   没有：必须统一收货。

## 五、结论

**大多数餐饮连锁：中央厨房/总仓统一收货更好。**  
**少数门店少、本地时令强、易损高的水果：可以门店直收。**  
**最优不是二选一，而是“核心统采 + 本地鲜品授权直采 + 总部强管控”的混合模式。**

如果只选一个：  
**10 家店以上、有中央厨房、水果用于标准菜单，选统一收货。**  
**5 家店以下、无中央厨房、水果强时令，选门店分开收货。**
