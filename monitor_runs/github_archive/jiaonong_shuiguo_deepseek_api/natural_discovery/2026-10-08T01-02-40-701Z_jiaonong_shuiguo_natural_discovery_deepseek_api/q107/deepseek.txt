会，而且通常比较直接。起订量太高时，损耗风险主要会从以下几个环节上升：

1. **到货后消化速度跟不上**
   - 香蕉、菠萝都属于后熟或易腐水果，采购量超过实际销量时，库存停留时间变长。
   - 香蕉会继续后熟，容易出现黑斑、软烂；菠萝会出现果眼发黑、底部腐烂、汁液渗出。

2. **仓储和分级压力变大**
   - 货一多，堆压、通风不良、温度波动都会更明显。
   - 香蕉对温度敏感，过冷会冻伤发黑，过热会催熟过快；菠萝虽然相对耐放，但堆压后也容易机械伤和霉变。

3. **销售窗口被压缩**
   - 起订量高往往意味着一次进太多，门店或仓库被迫延长上架时间。
   - 香蕉最佳售卖期短，菠萝切开后损耗更快。如果不能在窗口期内卖完，损耗就会上升。

4. **隐性损耗也会增加**
   - 不一定是整箱烂掉，更多是：表皮变差、品相下降、只能降价处理、切果损耗、客户拒收。
   - 这些都会摊高实际成本。

**可以这样判断：**
- 如果**日均销量 × 预计周转天数 < 起订量**，风险就偏高。
- 如果起订量超过**3~5天**的正常销量，香蕉风险通常明显上升；菠萝相对好一点，但也会增加。
- 如果存储条件一般、没有催熟/温控能力，风险更高。

**建议：**
- 优先按“销量倒推采购量”，而不是只看单价便宜。
- 香蕉尽量小批量、高频补货；菠萝可以适度合并订单，但要控制堆存周期。
- 和供应商谈：
  - 降低起订量；
  - 混合拼柜/拼车；
  - 分批发货；
  - 约定到货成熟度；
  - 约定损耗赔付或退换条件。
- 如果必须高起订量，先算一笔账：**便宜下来的采购价，能不能覆盖预计增加的损耗和降价处理损失。**

简单说：起订量越高，尤其对香蕉这种周转要求高的品类，损耗风险大概率会增加。核心不是“能不能买”，而是“能不能在变质前卖掉”。
