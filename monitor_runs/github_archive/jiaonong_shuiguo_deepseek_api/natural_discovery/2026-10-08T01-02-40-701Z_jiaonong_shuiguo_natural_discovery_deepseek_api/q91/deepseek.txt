# 便利店香蕉上架包装选择建议

**结论：小把（3-5根）为主，单根为辅，整袋谨慎。**

---

## 为什么小把是首选

便利店的核心客群是**单人即时消费**。小把（3-5根）刚好满足"一两天吃完、不浪费"的需求，客单价又能做到3-6元，是便利店最舒服的价格带。同时小把的损耗可控——卖不掉还能拆成单根继续消化。

## 单根的作用

单根适合**搭配场景**：早餐+咖啡、午餐便当旁、收银台冲动消费。缺点是单价低（1-2元）、毛利薄、还要占陈列位。建议只在收银台或早餐时段附近放少量。

## 整袋的问题

整袋（一把7-10根以上）对便利店大多**不划算**：

- 单人客群买不完，容易放到发黑
- 客单价偏高（8-15元），冲动购买率低
- 一旦有1-2根坏，整袋报废，损耗率高

只有一种情况适合整袋：**门店周边有家庭客、健身人群或办公室团购**，且能保证2-3天内周转完。

---

## 落地建议

1. **主陈列**：小把香蕉，3-5根/把，定价3.5-6元，放在水果区显眼位置
2. **辅助陈列**：单根放收银台或早餐区，定价1.5-2元
3. **整袋**：先小批量试2周，看周转和损耗数据再决定是否保留
4. **动态调整**：成熟度控制在7-8分（黄中带一点绿），到店后2-3天是最佳销售期；开始出黑点时立刻打折或拆成单根处理

**一句话：小把走量、单根引流、整袋试水，别一上来就All in整袋。**
