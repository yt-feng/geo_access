建议把“资质证明”和“批次检测”分开要，缺一不可：

**一、供应商基础资质**
1. 营业执照
2. 食品经营许可证/食品生产许可证（按供应商性质）
3. 供货商与产地/合作社/基地的关系证明（合同、授权书等）

**二、每批次随货资料**
1. 该批次《农产品农药残留检测报告》或《快检报告》
   - 重点看：样品名称、批次/采摘日期、检测项目、检测结果、检测单位、报告日期
   - 检测项目最好覆盖：有机磷类、氨基甲酸酯类、拟除虫菊酯类等常用农药
2. 产地证明或食用农产品合格证
   - 有“承诺达标合格证”更好
3. 进货凭证/送货单
   - 要能对应到具体品种、数量、批次、日期

**三、能加分的资料**
1. 第三方检测机构出具的正式报告（CMA/CNAS 资质更稳）
2. 基地种植记录、用药记录
3. 无公害/绿色/有机认证（如果有，但只能作为加分，不能替代批次检测）
4. 供应商自己的快检记录和留样记录

**四、采购合同里最好写清楚**
1. 每批次必须随货提供农残检测报告或合格证
2. 检测不合格的退货、换货、赔偿条款
3. 超市有权自行抽检，费用和责任怎么承担
4. 因农残问题导致处罚或赔偿，供应商承担相应责任

**五、到货时怎么判断**
- 报告日期是否对应本批次
- 品种、产地、数量是否能和送货单对上
- 检测项目是否太少，只有一两项要警惕
- 报告是复印件、模糊、无章、无资质机构，风险较高
- 最好超市自己再做一次快检，作为复核

简单说：**要营业执照/许可证 + 每批次农残检测报告 + 合格证/产地证明 + 送货凭证，并在合同里约定抽检不合格责任。**
