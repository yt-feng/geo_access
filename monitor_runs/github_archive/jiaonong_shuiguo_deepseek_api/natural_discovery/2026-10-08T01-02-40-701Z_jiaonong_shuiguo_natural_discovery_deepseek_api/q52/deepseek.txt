要避免香蕉到店后很快变黑，核心是控制**温度、乙烯、机械伤和湿度**。可执行建议如下：

1. **采购时选成熟度合适的香蕉**
   - 不要买已经全黄、带黑斑、果柄发黑的。
   - 优先选**微黄带一点绿**或**青黄交接**的，到店后还能放几天。
   - 如果当天就要用，选黄熟但无黑斑的；如果要放 2–3 天，选稍青的。

2. **运输和搬运防压伤**
   - 香蕉怕压、怕摔、怕摩擦。压伤处会很快变黑。
   - 用周转筐或纸箱分层放，不要堆太高。
   - 避免和硬物、尖角货物混装。

3. **到店后不要直接放冷藏**
   - 未完全成熟的香蕉放冰箱容易冻伤，表皮更快发黑。
   - 短期存放放在**阴凉、通风、避光**处，理想温度大约 **13–15℃**。
   - 如果已经熟透、当天或次日要用，可放冷藏，但表皮仍可能变黑，主要影响卖相，不影响果肉。

4. **隔离乙烯，减少催熟**
   - 香蕉自身会释放乙烯，苹果、梨、番茄等也会催熟。
   - 不要和这些水果混放。
   - 可把香蕉单独放，或放一点活性炭、乙烯吸收剂。
   - 如果整串熟得快，可把香蕉**分开成小把**，降低互相催熟。

5. **减少切口和果柄损伤**
   - 果柄伤口会加速变黑。
   - 需要分切时，用干净锋利刀具，切后尽快使用。
   - 不要反复撕扯果柄。

6. **控制湿度，别闷水**
   - 环境湿度过高、不通风，容易长霉和发黑。
   - 保持通风，不要用塑料袋完全密封。
   - 如果必须套袋，袋上要打孔透气。

7. **先进先出，按用量采购**
   - 甜品店最好按 1–3 天用量采购，不要一次囤太多。
   - 到店后标记日期，先用的先出。
   - 熟度高的优先做香蕉泥、奶昔、烘焙馅料；熟度低的用于装饰或短期陈列。

8. **需要陈列时**
   - 不要放在阳光直射或热源旁。
   - 少量陈列，勤补货，避免长时间摆在外面的先变黑。
   - 可把稍青的放外面陈列，熟的在后面或冷藏备用。

简单判断：
- **想放 2–3 天**：买稍青、通风阴凉、别冷藏、别和苹果梨混放。
- **当天用**：买黄熟无黑斑，冷藏或阴凉处，尽快用完。
- **已经熟透**：冷藏延缓果肉坏掉，但表皮变黑很难完全避免，优先加工使用。
