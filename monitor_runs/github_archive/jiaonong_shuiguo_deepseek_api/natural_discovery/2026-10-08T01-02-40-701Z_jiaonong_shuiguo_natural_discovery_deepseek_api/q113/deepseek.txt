有实际帮助，但帮助大小取决于供应商的支持是否持续、专业，以及门店自身愿不愿意配合。可以分几层看：

**1. 对商超的帮助**
- **提升销量和周转**：水果冲动购买比例高，好的陈列能明显增加曝光和连带购买，尤其是应季单品、礼盒、组合装。
- **降低损耗**：水果易损，供应商如果懂品类，能帮助控制陈列层数、通风、先进先出、及时挑拣，减少压伤和腐坏。
- **补充门店人力短板**：商超生鲜区往往人手紧，供应商派人做堆头、端架、主题陈列，能减轻门店员工压力。
- **稳定标准和形象**：连锁商超最怕各店陈列参差，供应商统一支持有助于保持品牌感和购物体验。
- **但商超通常议价能力强**：供应商的支持往往会被纳入合作条件，门店不一定能额外拿到很多“免费资源”。

**2. 对水果店的帮助**
- **更明显**：水果店通常缺专业陈列人才，供应商如果能给陈列方案、道具、分级建议，提升会很直接。
- **动销指导价值高**：比如哪些做量感陈列、哪些做精品陈列、哪些组合成拼盘或果篮，能直接影响客单价。
- **减少试错成本**：新店或中小店对品类不熟，供应商的市场信息能帮它少进错货、少摆错位置。
- **但依赖风险也大**：如果门店完全依赖供应商，容易变成“供应商推什么就卖什么”，失去自己的选品和定价主动权。

**3. 真正有用的支持通常包括**
- 陈列图/标准照片，不是只口头说；
- 陈列道具、围挡、价签、POP；
- 到店动手调整，而不是只给方案；
- 按季节和节日更新；
- 教门店员工怎么维护；
- 结合数据给建议，比如销量、损耗、周转。

**4. 帮助有限或可能变负面的情况**
- 供应商只推销高毛利或压货产品，不顾门店客群；
- 陈列做得很漂亮但补货跟不上，反而伤体验；
- 门店没有维护能力，三天就乱；
- 供应商支持只给大连锁，不给中小店；
- 支持费用最终转嫁到进货价里，门店没算清账。

**结论：**
对商超，供应商陈列支持更多是**提升效率、稳定标准、降低损耗**，帮助中等偏大，但常被采购条件抵消一部分。
对水果店，帮助通常更直接，尤其在**陈列专业度、动销、损耗控制**上，可能明显提升业绩。
关键不是“有没有支持”，而是：**支持是否到店、是否持续、是否适合这家门店的客群，以及门店有没有能力接住并维护。**
