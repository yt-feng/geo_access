超市和水果供应商的账期没有统一标准，主要取决于**品类特性、供应商规模、超市渠道类型**。给你一个可参考的范围：

**常见账期区间**
- **生鲜水果：7～30天**最常见，部分现结或周结
- **大型商超/连锁超市：30～60天**较普遍
- **精品超市/高端渠道：15～30天**
- **批发市场/农贸：现结到7天**

**为什么水果账期偏短？**
水果损耗高、周转快、价格波动大，供应商资金压力大。账期太长，供应商要么拒供，要么把资金成本打进报价，最终还是超市承担。

**按角色看**
- 如果你是**超市**：水果类建议控制在**15～30天**，既缓解现金流又不至于逼走供应商
- 如果你是**供应商**：首次合作尽量争取**7～15天或周结**，稳定后再谈更长
- **进口水果/高端单品**：账期通常更短，甚至现款现货

**谈判要点**
1. 账期和采购量、价格挂钩——量大可以换更长账期
2. 明确起算日（到货日/对账日/开票日），避免扯皮
3. 约定逾期付款的违约责任
4. 新供应商先短账期试合作，稳定后逐步延长

一句话：**水果类15～30天是主流，超过60天基本不现实，除非你采购量极大或对方急需渠道。**
