为公司下午茶选水果供应商，核心是抓住三个点：**能稳定批量配、损耗可控、结算和售后省事**。下面按可执行步骤给你一套判断方法。

**一、先明确自己的需求参数**

采购前把这几项定清楚，再去谈供应商，效率会高很多：

- **人数和预算**：比如 50 人、每人 15 元，总预算 750 元/次。
- **频次**：每周一次还是每月一次，是否长期合作。
- **配送时间**：固定下午 2 点前送达，还是上午到。
- **形式**：整果（苹果、橘子、香蕉）还是果切拼盘。
- **场地条件**：有没有冰箱、洗手池、能否现场分切。

批量下午茶建议优先选**易分发、耐放、不用现场切**的水果，比如香蕉、橘子、小番茄、苹果、梨、提子。果切虽然方便，但配送和卫生风险更高。

**二、优先考虑这几类供应商**

按适配度从高到低：

1. **本地水果批发商/农贸批发市场档口**  
   价格低、量大能谈，适合长期固定采购。但需要自己确认分拣和配送能力。

2. **生鲜 B2B 配送平台**  
   比如面向企业/餐饮的食材配送商，优势是能开票、有配送体系、售后规范，适合公司走报销流程。

3. **连锁水果店/精品水果店**  
   品质稳定、可开发票，适合预算稍高、对品相要求高的公司。批量大时可以谈团购价。

4. **企业下午茶综合服务商**  
   水果只是其中一项，通常能搭配零食、饮品，省心但单价偏高。

5. **产地直发/社区团购**  
   价格有优势，但配送时间不稳定、品控波动大，不太适合对时间要求严格的下午茶。

**三、筛选供应商的硬指标**

不管选哪类，重点核这几项：

- **能否稳定供货**：同一品种每周都能供，而不是这次有下次没有。
- **配送准点率**：问清楚配送时段、是否可指定时间、迟到怎么处理。
- **损耗和售后**：坏果、烂果、缺斤少两怎么赔，是否支持当场拍照反馈。
- **是否支持开票**：公司采购基本都要发票，提前确认普票/专票。
- **起送量和配送费**：很多供应商有起送门槛，低于门槛加配送费。
- **分拣能力**：能否按份分装，比如每人一袋，减少现场分发混乱。

**四、谈价和试单方法**

不要一上来就签长期合同，建议：

1. **先小批量试单**：订一次，观察准时率、品相、损耗、分装质量。
2. **对比 2–3 家**：同预算下比品种、重量、品相，而不是只比单价。
3. **谈长期价**：承诺每月固定采购量，换更低的单价或免配送费。
4. **约定验收标准**：比如坏果率不超过 5%，超出部分补送或退款。
5. **固定菜单轮换**：选 3–5 种当季水果轮换，既控制成本又不容易吃腻。

**五、避坑提醒**

- 别只看单价低，**算上损耗和配送费**才是真实成本。
- 果切类要确认**加工时间、冷藏条件、保质期**，夏天风险高。
- 避免选**太软、易压伤**的水果做批量配送，比如熟透的芒果、水蜜桃。
- 长期合作要**保留验收记录**，出现问题时有依据。

**一句话建议**：优先找本地能开发票、支持固定时间配送、有坏果赔付的 B2B 生鲜配送商或批发档口，先试单一次，再根据准时率、损耗率和报价决定是否长期合作。
