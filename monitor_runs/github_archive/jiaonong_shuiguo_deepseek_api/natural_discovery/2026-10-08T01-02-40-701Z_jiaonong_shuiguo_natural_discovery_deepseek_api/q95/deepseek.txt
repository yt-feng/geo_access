学校食堂采购水果，核心不是“找最便宜的”，而是**稳定供货 + 食品安全可追溯 + 价格可控 + 损耗低**。香蕉、苹果、橙子这类常见水果，建议按下面思路选供应商。

## 1. 先明确食堂自己的需求

选供应商前先定几个硬条件：

- **采购量**：每天/每周多少斤，是否分校区、分食堂。
- **配送频次**：每天送、隔天送，还是每周2–3次。
- **验收标准**：大小、成熟度、破损率、农残检测要求。
- **结算方式**：月结、周结，是否接受对公转账和发票。
- **应急要求**：临时加单、换品种、补货多久能到。

这些条件越清楚，越容易筛掉不合适的供应商。

## 2. 优先选哪类供应商

常见有三类：

### ① 大型水果批发商/配送公司
**适合：** 采购量大、要求稳定、需要票据和检测报告的学校。  
**优点：** 品类全、配送能力较强、可开发票、相对规范。  
**风险：** 价格未必最低，服务可能偏标准化。

### ② 本地批发市场档口
**适合：** 中小型食堂、采购灵活、能当天看货。  
**优点：** 价格灵活、起送量低、调货快。  
**风险：** 票据和检测报告可能不规范，质量波动大。

### ③ 产地合作社/基地直供
**适合：** 苹果、橙子等耐储水果，采购量较大且长期稳定。  
**优点：** 价格有优势、来源清楚。  
**风险：** 配送和售后弱，香蕉这类后熟水果不一定适合。

**建议：**  
主供应商选1家配送公司或大型批发商，辅供应商选1家本地档口或产地渠道，防止断供和坐地起价。

## 3. 重点看哪些资质和材料

至少要求供应商提供：

- 营业执照
- 食品经营许可证，若涉及食品销售
- 食用农产品合格证或产地证明
- 农残检测报告，批次可对应
- 送货单、对账单、发票
- 冷链或常温配送能力说明，香蕉对温度较敏感
- 食品安全责任承诺或合同条款

如果是学校食堂，通常还要满足教育、市场监管部门对**索证索票、进货查验、留样和追溯**的要求。

## 4. 按水果特点分别定标准

### 香蕉
- 不要选全黄熟透的，运输和存放损耗大。
- 适合选**微黄带绿、七八成熟**，到校后能放1–2天。
- 要求：无黑斑大面积、无腐烂、无冻伤、把型完整。
- 配送时避免挤压，夏天高温、冬天冻伤都要注意。

### 苹果
- 适合选耐储存、口感稳定的品种，如红富士、嘎啦等。
- 要求：大小均匀、无明显碰伤、无腐烂、无虫眼。
- 可接受一定比例小果，但必须提前约定规格，如70–80mm。
- 适合每周送2–3次，不必每天送。

### 橙子
- 要求：皮面干净、无霉斑、无严重失水、酸甜度稳定。
- 规格按直径或重量分级，如65–75mm。
- 冬季可适当增加采购，夏季注意储存和损耗。
- 橙子相对耐储，可适当集中采购，但要避免长期积压。

## 5. 比价不要只看单价

建议用“综合成本”比较：

- 单价
- 损耗率
- 配送费
- 退换货是否及时
- 是否缺斤少两
- 是否需要人工分拣
- 发票和结算成本

例如：  
A供应商香蕉3元/斤，但损耗15%；  
B供应商3.3元/斤，损耗5%。  
实际可用成本可能B更低。

## 6. 建议的筛选流程

1. **初筛**：找3–5家供应商，收资质和报价。
2. **样品测试**：每家送1–2次样品，食堂、库管、厨师一起验收。
3. **小批量试用**：试供2–4周，记录到货时间、重量、损耗、退换货速度。
4. **综合评分**：质量40%、价格25%、配送20%、售后10%、资质5%左右，可按学校实际调整。
5. **签合同**：明确品种、规格、单价、浮动机制、配送时间、验收标准、退换货、违约责任。
6. **保留双供应商**：主供占70%–80%，辅供占20%–30%。

## 7. 合同里一定要写清楚

- 水果品种、等级、规格、产地或品种要求
- 价格是否随行就市，调价需提前几天书面通知
- 配送时间、迟到处理
- 验收标准和不合格处理
- 退换货时限，如2小时内响应
- 农残检测、食品安全责任
- 结算周期和发票类型
- 断供、以次充好的违约责任

## 8. 日常管理建议

- 每次收货称重、拍照、记录批次。
- 建供应商档案，保存资质、检测报告、送货单。
- 每月统计各家损耗率、投诉次数、准时率。
- 每学期重新比价一次，但不要频繁换供应商。
- 香蕉、苹果、橙子可分开选供应商，不一定一家全包。

## 简单结论

学校食堂选水果供应商，优先找**有资质、能稳定配送、可开票、能提供检测报告、售后响应快**的供应商。  
香蕉看成熟度和配送保护，苹果看规格和耐储性，橙子看新鲜度和酸甜稳定。  
最好采用**1家主供 + 1家备供**，小批量试用后再签长期合同，综合比较价格、损耗和服务，而不是只挑最低价。
