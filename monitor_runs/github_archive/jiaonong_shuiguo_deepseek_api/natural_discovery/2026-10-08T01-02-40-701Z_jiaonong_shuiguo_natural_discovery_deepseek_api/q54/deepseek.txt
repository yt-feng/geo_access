应该**优先看成熟度，价格放在第二位**。原因很直接：香蕉在烘焙里不只是“提供香蕉味”，它同时影响甜度、水分、酸度、香气，甚至蛋糕的膨发和口感。成熟度不对，配方再准也容易翻车。

### 为什么成熟度更关键
- **太生（青皮、硬）：** 淀粉多、糖少、香气弱，做出来香蕉味很淡，还可能带涩味；果肉偏硬，不易压泥，蛋糕口感偏干、偏紧。
- **刚熟（黄皮、无斑）：** 可以吃，但烘焙香气不够，甜度也不足，通常需要额外加糖或香精补味。
- **熟透（黄皮带褐斑、微软）：** 最适合烘焙。淀粉已大量转化为糖，香气浓、甜度高、果肉软，容易压成泥，成品湿润、风味足。
- **过熟（大面积发黑、流汁、有酒味/酸味）：** 要区分情况。轻微褐斑、很软但气味正常，做香蕉蛋糕反而很好；但如果已经渗液、发酸、有发酵酒味，就不适合直接用于售卖产品。

### 价格什么时候才该影响决策
价格不是不重要，而是要在**成熟度合格的前提下**比价：
1. **优先买“黄皮带褐斑”的香蕉。**
2. 如果当天不用，可以买**刚转黄、少量斑点**的，室温放 1–2 天再 used。
3. 如果遇到**便宜但过生**的香蕉，不适合马上做蛋糕，除非你愿意催熟并承担时间成本。
4. 如果遇到**便宜但已经过熟到发酸渗液**的，不要为了省钱用，风味和食品安全风险都不划算。
5. 如果成熟度都合适，再比较单价、损耗率、出泥率。熟香蕉去皮损耗通常也不低，要按“可用果泥成本”算，而不是只看整根价。

### 采购时的实操标准
- **最佳采购状态：** 表皮黄色，带少量到中等褐色斑点，捏起来有弹性偏软，蒂部不青硬。
- **可短期存放：** 黄皮、少量斑点，室温 1–3 天会到最佳状态。
- **当天急用：** 直接选褐斑明显、香气浓、果肉软的。
- **不要选：** 青硬、发酸、渗液、霉变、有酒味的。

### 简单结论
**成熟度决定成品风味和口感，价格决定成本。采购时先卡成熟度，再在合格成熟度里选价格合适的。**  
如果只能二选一：**选成熟度对的，不要选单纯便宜的。**
