批发商要在合同里控制坏果损耗，核心是把“责任怎么分、按什么标准赔、怎么举证、多久内提异议”写清楚，而不是只写一句“坏果由卖方负责”。建议从以下几方面落条款：

**1. 明确质量标准**
- 约定果实品种、等级、规格（大小、糖度、成熟度等）。
- 明确“坏果”的定义：腐烂、发霉、压伤、冻伤、虫蛀、开裂等分别是什么程度算坏。
- 最好约定一个可接受的坏果率上限，例如“到货抽检坏果率不超过X%视为合格”。

**2. 明确责任划分节点**
- 关键是谁承担运输风险。常见写法：
  - 卖方负责送到指定地点并卸货前的一切损耗；
  - 或按贸易术语（如到货价、目的地交货）约定风险转移点。
- 要写清“以何时何地的检验结果为准”，比如卸货后X小时内、在买方仓库共同抽检。

**3. 约定检验和举证方式**
- 到货后双方共同抽样，抽样比例、抽样方法写清楚。
- 可约定第三方检测机构，费用由责任方承担或先垫付后结算。
- 照片、视频、过磅单、温度记录、运输记录等作为证据。
- 约定提异议期限，例如“卸货后24小时内书面提出，逾期视为验收合格”。

**4. 约定赔偿计算方式**
- 不要只写“按实际损失赔”，要给出可算的公式，例如：
  - 超出约定坏果率的部分，按当批货物单价×超出数量赔偿；
  - 或按“坏果重量×单价×系数”赔偿。
- 可约定整批退货、换货、补货、扣款等处理方式及适用条件。
- 明确赔偿是否包含运费、装卸费、仓储费等间接损失。

**5. 约定违约责任和争议解决**
- 卖方逾期处理、拒不赔偿的违约金或利息。
- 争议解决方式：仲裁或诉讼，管辖地尽量约定在买方所在地。
- 保留对质量问题的追索期，比如“隐蔽瑕疵在到货后X日内仍可主张”。

**6. 实务上要注意**
- 坏果率标准要结合品种和运输距离，写得太苛刻卖方可能不接受，写得太松又没保护。
- 最好把“合格率/坏果率”与“扣款比例”做成表格附在合同后。
- 如果是长期合作，可约定每批货单独验收、单独结算，避免混批扯皮。
- 所有口头承诺都要落到书面，微信、邮件确认也尽量写进合同或作为附件。

简单说，合同里要回答四个问题：**什么算坏果、什么时候验、谁来赔、怎么算钱**。把这四点写具体，批发商的损耗风险就能大幅降低。
