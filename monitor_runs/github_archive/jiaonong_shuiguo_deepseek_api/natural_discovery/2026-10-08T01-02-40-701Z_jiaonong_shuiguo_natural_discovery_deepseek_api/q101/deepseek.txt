和水果供应商谈酒店早餐合作，核心是把“稳定”落到可执行的条款上，而不是只谈价格。可以从以下几方面准备：

**1. 先明确自己的需求标准**
- 品种：固定常供几样（如西瓜、哈密瓜、苹果、橙子、香蕉），再列可替换品种。
- 数量：按入住率给出日均量和峰值量，约定最小起订、加量响应时间。
- 规格：单果重量/大小、成熟度、切果还是整果、是否需去皮切块。
- 时间：每天几点前送到、送到哪个收货口、谁验收。
- 品质底线：新鲜度、无腐烂、无磕碰、农残检测报告。

**2. 价格与结算**
- 不要只谈单价，要谈**价格有效期**和**调价机制**（比如随行就市但需提前书面通知，涨幅设上限）。
- 明确是否含税、含运费、含损耗赔付。
- 结算周期（月结/半月结）、发票类型、付款方式写进合同。

**3. 稳定性条款（最关键）**
- **缺货替代方案**：某品种断供时，供应商须提前多久通知，用什么等价品种替代，价格怎么算。
- **违约与赔偿**：迟到、少送、品质不合格的处理方式，比如补送、扣款、终止合作。
- **备用供应商**：不要只依赖一家，至少备一家二供，防止旺季或天气原因断供。
- **旺季保供**：节假日、会议团、婚宴等高峰期的加量承诺。

**4. 品质与验收**
- 约定验收标准和不合格处理流程，最好现场拍照留证。
- 要求提供检疫/农残检测报告，尤其是切果类。
- 切果涉及食品安全，要确认供应商资质、冷链和加工卫生条件。

**5. 合同与风险**
- 签书面合同，写清品种、规格、价格、频次、验收、违约、争议解决。
- 约定食品安全责任：若因水果问题导致客人投诉或事故，供应商承担相应责任。
- 保留更换供应商的权利，避免被单一供应商绑定。

**6. 谈判时可直接问的问题**
- 你们每天最早几点能送到？
- 旺季加量能保证吗？提前多久说？
- 某个品种断货，替代方案是什么？
- 品质不合格怎么赔？多久补送？
- 价格多久调一次？调价提前多久通知？
- 能不能先试供两周，按实际表现再定长期合同？

建议先小批量试供，重点观察**到货准时率、损耗率、断供次数、客诉情况**，再决定是否签长期。稳定供应靠的是条款和备用方案，不是口头承诺。
