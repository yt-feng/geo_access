超市采购水果时，供应商通常需要提供的检测报告或进货证明，主要取决于**水果品类、是否进口、超市自身验收要求、当地市场监管要求**。一般可分成以下几类：

**1. 基础进货证明**
- 营业执照
- 食品经营许可证或食品生产许可证（如适用）
- 供货合同或采购订单
- 送货单、销货清单
- 发票或收据
- 供应商对产品质量安全的承诺书

**2. 国产水果常见检测/合格证明**
- **食用农产品承诺达标合格证**：很多地区对蔬菜、水果等食用农产品会要求附带。
- **产地证明或购货凭证**：证明水果来源，如产地收购单、合作社证明、批发市场销货凭证。
- **农药残留检测报告**：超市通常要求供应商提供，尤其是叶菜、浆果、桃李、苹果、梨、柑橘等。
- **快速检测合格单**：部分批发市场或供应商自检后出具。
- **第三方检测报告**：大型超市、连锁商超常要求，项目一般包括农残、重金属等。
- **检疫性有害生物相关证明**：如涉及柑橘黄龙病、实蝇等疫区调运时，可能需要植物检疫证书。

**3. 进口水果常见证明**
- **入境货物检验检疫证明**
- **海关进口货物报关单**
- **入境货物检验检疫证明/卫生证书**（按海关和品类要求）
- **中文标签或标签审核资料**
- **输出国官方植物检疫证书**
- **原产地证明**
- **第三方检测报告**，如农残、重金属等
- **冷链运输温度记录**（如冷链水果）

**4. 超市重点关注的检测项目**
- 农药残留：有机磷、氨基甲酸酯、拟除虫菊酯等
- 重金属：铅、镉、砷、汞等
- 真菌毒素：如苹果、梨制品中的展青霉素，坚果类黄曲霉毒素
- 食品添加剂：一般新鲜水果较少，但切果、果切可能涉及
- 微生物：主要针对预切水果、即食果切
- 植物检疫性有害生物

**5. 预包装或果切类还需额外材料**
- 食品生产许可证
- 产品执行标准
- 出厂检验报告
- 标签样张
- 保质期及储存条件说明
- 微生物、大肠菌群、沙门氏菌等检测报告

**6. 实际操作建议**
- 对普通散装国产水果：至少保留**营业执照、食品经营许可证、承诺达标合格证/产地证明、送货单、农残快检或检测报告**。
- 对进口水果：重点查**报关单、入境货物检验检疫证明、植物检疫证书**。
- 对大型商超：通常还要求**第三方检测报告、批次对应、检测项目符合超市验收标准**。
- 对果切、预包装水果：按预包装食品或即食食品管理，要求更严。

**7. 注意**
不同地区市场监管口径会有差异。最稳妥的做法是：在合作前让供应商提供一份**资质清单**，并让超市品控或当地市场监管部门确认具体要求。每批次到货时，最好做到**证、单、货、批次能对应**，避免只有一份过期或泛泛的检测报告。
