采购香蕉做茶饮或甜品，核心原则是：**不要买单一熟度，要按“到货时间 + 用途”倒推采购成熟档位。**

香蕉熟度通常按颜色分档：

1. **全绿**：很硬、涩、甜度低，不适合直接出品。  
2. **绿转黄**：开始软化，适合需要运输后放几天的门店。  
3. **黄带一点绿**：适合做需要加热、捣碎、熬酱的香蕉，如香蕉果酱、香蕉泥。  
4. **全黄**：甜度上来、香气明显，适合做奶昔、冰沙、果茶捣压。  
5. **黄带黑点**：最甜、最香、最软，适合做香蕉泥、甜品夹馅、香蕉蛋糕，但不适合切片装饰。  
6. **大面积发黑**：过熟，容易发酵、出水、发酸，除非当天做香蕉面包或立刻处理，否则不建议采购。

**采购控制建议：**

- **当天或次日要用**：买全黄或黄带少量黑点的，香气和甜度最好。
- **2—3天后用**：买黄带一点绿的，放常温自然熟。
- **3—5天后用**：买绿转黄的，但不要全绿，否则后熟不均匀。
- **做装饰片**：买全黄但还偏硬的，切片不易烂。
- **做香蕉泥、果酱、奶昔**：可以买黄带黑点的，出香高、糖度好，但必须当天或冷藏短存处理。
- **做热饮或烘焙**：可用熟度更高的香蕉，甜味更突出，但要注意酸败和发酵味。

**门店收货时要检查：**

- **颜色是否一致**：同一批不能一半全绿一半全黑，否则出品不稳定。
- **手感**：轻按有弹性、不塌陷。太硬代表没熟，太软代表过熟。
- **果柄和表皮**：果柄发黑、表皮渗液、有酒味，说明过熟或开始腐坏。
- **有没有冷伤**：表皮灰黑、发暗但不软，可能是低温冻伤，香气差。
- **重量和饱满度**：太轻可能失水，果肉少。

**储存控制：**

- 未熟香蕉：常温、通风、避光，不要冷藏，否则停止后熟。
- 已熟香蕉：可冷藏1—2天延缓过熟，但表皮会变黑，不影响果肉使用。
- 过熟香蕉：尽快去皮、分装、冷冻，做奶昔或果泥。
- 不要和苹果、梨、乙烯释放量大的水果混放，会加速成熟。
- 需要催熟：可和少量苹果同放，但每天检查，避免一夜过熟。

**简单采购公式：**

- **今天卖**：全黄 / 黄带黑点。
- **明天卖**：黄带一点绿。
- **后天卖**：绿转黄。
- **做酱、泥、奶昔**：黄带黑点优先。
- **做装饰**：全黄偏硬优先。

最稳妥的做法是：**每天少量多次采购，按用途分熟度，不要一次囤同一熟度。** 茶饮店香蕉损耗主要不是买贵，而是买错熟度。
