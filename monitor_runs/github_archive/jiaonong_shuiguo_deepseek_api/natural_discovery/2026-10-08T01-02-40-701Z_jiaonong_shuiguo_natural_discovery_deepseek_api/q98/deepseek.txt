判断水果供应商的合规和稳定性，建议从“资质文件、实地能力、供货记录、合同约束”四个维度入手，不能只看报价。

**一、合规资质（先查硬门槛）**

1. **营业执照**：经营范围需含“食品销售/食用农产品销售”，确认在有效期内。
2. **食品经营许可证**：销售水果通常需要，核对许可项目与实际经营是否一致。
3. **检验检测能力**：
   - 要求提供近期（如3个月内）的农残快检或第三方检测报告；
   - 优先选择能提供每批次检测报告的供应商，而非只给一张“年度报告”。
4. **进货凭证**：要求能提供上游产地/批发市场的进货单据，证明货源可追溯。
5. **从业人员健康证**：涉及分拣、配送接触食品的人员应有健康证明。

⚠️ 常见坑：用别人的资质投标、资质过期、检测报告与所供品种对不上。核验时要看**原件或加盖公章的复印件**，并核对品种。

**二、稳定性（看真实供货能力）**

1. **是否有稳定货源基地或长期合作产地**：问清主要品种从哪来，是自营基地、产地直采还是批发市场转手。转手越多，价格和品质波动越大。
2. **仓储与冷链**：
   - 有无冷库/保鲜库；
   - 配送车辆是否冷藏或保温；
   - 夏季高温期能否保证到货品质。
3. **配送频次与时效**：能否按食堂要求的频次（如每日/隔日）稳定送达，缺货时有无补货预案。
4. **历史供货记录**：索要近半年对其他机构（医院、学校、养老院、机关食堂）的供货清单或合同，最好能电话回访1-2家。
5. **抗风险能力**：旺季、节假日、极端天气时是否有替代货源。

**三、实地考察（最有效的一步）**

- 看分拣场地是否整洁、有无防鼠防虫措施；
- 看库存周转，是否有大量积压或明显不新鲜的水果；
- 看车辆和冷库实际运行情况，而不是只听介绍；
- 随机抽一批货，对照检测报告核对品种和批号。

**四、合同与验收约束（把稳定性写进条款）**

1. **明确验收标准**：品种、规格、成熟度、损耗率、农残合格要求。
2. **设置违约与退出机制**：连续几次不合格、检测超标、断供，可扣款或终止合同。
3. **价格机制**：约定随行就市还是固定价，避免旺季随意涨价。
4. **索证索票**：每批次随货提供检测报告或合格证明，留存台账。
5. **账期与结算**：明确对账周期，避免因结算纠纷影响供货。

**五、快速判断口诀**

- 资质不全 → 直接排除；
- 只有报价没有检测和货源 → 高风险；
- 能提供批次检测 + 稳定产地 + 冷链 + 其他机构供货记录 → 相对可靠；
- 实地看过、抽检过、合同约束过 → 才算真正稳定。

如果条件允许，建议同时保留2家合格供应商，主供+备供，避免单一供应商断供影响老人和患者用餐。
