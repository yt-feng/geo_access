批发档口想拓餐饮客户，菠萝和香蕉要按餐饮端的实际用法来备规格。下面按品类拆开说，你对着备货就行。

**菠萝**

餐饮用菠萝主要分三种场景，规格差别很大：

1. **鲜切/果盘/饮品店**：要成熟度高的鲜食菠萝。建议备 1.0–1.5 kg/个的中果，果眼浅、无黑心，七至八成熟。餐饮店当天切当天用，太生口感差，太熟损耗大。这个规格出货最快。
2. **热菜/菠萝咕咾肉、菠萝炒饭**：要切块后耐炒、出水少的。建议备 1.5 kg 以上的大果，成熟度七成左右，果肉紧实、酸甜比稳定。大果出肉率高，后厨切丁损耗小。
3. **烘焙/菠萝包/果酱**：要风味浓、酸度够的，可接受稍熟。建议备 1.2–1.5 kg，八九成熟，允许表皮略黄，但要求无软腐、无酒味。

给餐饮客户的报价点：鲜食按个或按斤，加工用建议按“出肉率”谈，比如大果出肉率约 55%–65%，能帮后厨算成本。

**香蕉**

餐饮用香蕉集中在早餐、甜品、饮品、果盘，规格核心是“大小统一、成熟度可控”：

1. **饮品店/果昔**：要熟度稳定的，建议备中号（单根 120–150 g）、七至八成熟。太生涩、太熟发黑快，都会影响出品。
2. **早餐/酒店自助**：要卖相好、大小均匀的，建议备大号（单根 150–180 g）、七成熟到货，回温后正好。
3. **烘焙/香蕉蛋糕/果泥**：可以要熟度高的，建议备中号、八九成熟甚至带芝麻点，风味足、糖度高，但要求无腐烂、无断裂。
4. **果盘/宴席**：要笔直、无斑、同批次颜色一致的，建议备大号、六至七成熟，到店后自行催熟控熟。

**给餐饮客户的核心话术**

不要只报“菠萝多少钱一斤、香蕉多少钱一斤”，餐饮客户更关心三件事：

- **出成率**：菠萝按出肉率、香蕉按可用根数报价，比单纯斤价更有说服力。
- **稳定供应**：同一规格能长期稳定供货，比偶尔低价更重要。
- **成熟度可控**：能按客户要求控制到货成熟度，尤其是香蕉，这是餐饮客户最在意的。

**备货建议优先级**

先各拿 2–3 个规格试水，别一次铺太宽：
- 菠萝：主推 1.2–1.5 kg 鲜食果 + 1.5 kg 以上加工果，两个规格。
- 香蕉：主推中号七至八成熟 + 大号七成熟，两个规格。

跑一圈本地餐饮客户，问清楚他们主要做鲜食、热菜还是烘焙，再按反馈调整规格和熟度。这样备货最不容易压手里。
