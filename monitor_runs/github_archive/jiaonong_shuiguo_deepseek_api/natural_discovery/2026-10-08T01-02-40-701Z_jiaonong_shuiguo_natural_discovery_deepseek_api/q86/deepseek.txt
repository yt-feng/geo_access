生鲜平台做水果一件代发，供应商的仓配能力直接影响履约体验和损耗率。核心要考察以下几个维度：

**1. 仓储能力**
- **温区匹配**：不同水果要求不同。浆果类（草莓、蓝莓）需0-4℃冷藏；热带水果（芒果、香蕉）需12-15℃防冷害；普通水果可常温。供应商至少要具备冷藏+常温双温区，最好有三温区。
- **仓储环境**：通风、避光、防挤压，货架而非地面堆放，避免乙烯敏感水果（如猕猴桃）和释放乙烯的水果（如苹果）混放。
- **库存周转**：水果保质期短，供应商要有快进快出的周转能力，日均出货量和库存深度要匹配，避免压货导致品质下降。

**2. 分拣包装能力**
- **单果分选**：按重量、糖度、外观分级，一件代发要求单果标准一致，不能好坏混装。
- **抗压包装**：这是水果一件代发最容易出问题的环节。需要针对不同品类定制包装方案——珍珠棉网套、气柱袋、吸塑盒、防震隔层，确保快递途中不磕碰。
- **预冷处理**：采摘后快速预冷（差压预冷或冷水预冷）能显著延长货架期，供应商是否具备预冷能力很关键。

**3. 配送与快递对接能力**
- **快递资源**：是否已对接顺丰、京东、中通等生鲜专线，能否拿到生鲜件的时效和价格优势。
- **发货时效**：下单后多久出库，能否做到当日或次日发货，截单时间是什么。
- **冷链覆盖**：长途或高温季节是否走冷链干线+落地配，还是全程常温快递。这决定了可发区域和损耗率。
- **面单与系统对接**：能否对接平台的订单系统，自动打单、回传物流信息。

**4. 品控与售后能力**
- **到货损耗率**：行业里水果一件代发损耗率通常要求控制在3%-8%以内，具体看品类。供应商要能承诺这个指标。
- **售后响应**：坏果、压伤、缺斤少两的处理流程和赔付标准是否清晰，响应速度如何。
- **溯源能力**：能否提供产地、批次、采摘日期等信息，平台做品控和客诉时需要。

**5. 产能与弹性**
- **峰值承接**：大促或旺季能否快速扩产，日发单量上限是多少。
- **多SKU能力**：能否同时稳定供应多个水果品类，还是一直只做单一品种。

**实操建议**：先小批量试单，重点看三个数据——**发货时效达标率、到货损耗率、客诉率**。这三个指标过关，再谈放量。同时建议在合同里明确损耗率上限和赔付条款，把风险前置。
