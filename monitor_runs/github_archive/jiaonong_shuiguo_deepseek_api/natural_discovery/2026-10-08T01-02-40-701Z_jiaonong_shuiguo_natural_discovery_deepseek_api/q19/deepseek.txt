如果只选一个最该先关注的指标：**切果损耗**。

原因很直接：超市卖菠萝，利润不是靠“看起来好”，而是靠**进多少、卖多少、扔多少**。菠萝有几个特点：

- 整果毛利看起来还行，但损耗一高就吃掉利润；
- 顾客挑、翻、按、压，容易伤果；
- 熟度一上来，当天卖不掉就快速变质；
- 切果后如果卖不动，损耗更高。

所以优先级建议是：

**切果损耗 > 甜度 > 外观 > 大小**

具体判断：

1. **切果损耗最优先**
   - 看切口颜色、出水、发黑、软烂比例；
   - 看切果能不能当天售完；
   - 如果切果损耗超过整果利润，甜度再高也没意义。

2. **甜度第二**
   - 甜度决定复购；
   - 但甜度不能只看外表，最好结合品种、产地、季节、试吃反馈；
   - 太熟虽然甜，但损耗会飙升。

3. **外观第三**
   - 外观决定顾客愿不愿意拿起来；
   - 但超市不是精品水果店，外观只要干净、端正、无腐烂即可，不必追求完美。

4. **大小最后**
   - 大小影响定价和顾客选择；
   - 但大小不直接影响利润，除非大小和损耗、甜度强相关。

如果做经营决策，可以盯这几个数：

- 整果进货价、售价、毛利率；
- 每天切果数量、售出数量、报损数量；
- 切果损耗率 = 报损切果成本 ÷ 切果总成本；
- 试吃转化率；
- 顾客投诉里“不甜”和“坏果”的比例。

一句话：**先保损耗，再保甜度，最后才看外观和大小。** 因为超市卖菠萝，损耗控制不住，甜度和大果都只是账面好看。
