**一般情况是这样：**

- **图片**：大部分供应商能给，但常见的是手机随手拍、带箱子/磅秤/背景杂乱、无白底、无多角度。能提供“白底图+场景图+细节图”的通常是品牌方、大型基地或专业代办。
- **卖点**：供应商基本都能说几句，比如产地、品种、甜度、规格、采摘时间、发货仓。但多数是口语化描述，需要你二次整理成详情页文案。
- **规格数据**：单果重、果径、箱规、糖度、成熟度、储存方式，这些往往要你主动要，供应商不会自动给全。

**你可以这样要求供应商：**

1. **图片清单**：白底主图、切开图、手持/场景图、包装图、产地实拍。至少各1张，主图要白底或干净背景。
2. **视频**：10-15秒产地/分拣/开箱视频，现在详情页和主图视频都用得上。
3. **卖点清单**：产地、品种、口感、甜度、规格、成熟方式、发货时效、售后规则。
4. **授权确认**：明确图片和视频可否商用，避免盗图投诉。
5. **样品实拍**：如果供应商图太差，自己收到样品后补拍，这是最稳的。

**判断标准：**

- 能直接用的：白底图清晰、无杂物、有切开图、有规格数据、有商用授权。
- 需要加工的：背景乱、光线差、只有整箱图、卖点零散。
- 不能用的：明显盗图、带别家水印、图和实际规格对不上。

**建议：** 先让供应商发一套“图片+卖点+规格”模板，你按模板验收。如果供应商只能提供基础图，详情页素材最好自己补拍或找第三方拍，否则转化率会受影响。
