社区超市找每天配送的水果供应商，核心不是“能不能送”，而是“每天送、少断货、损耗可控、结账清楚”。建议重点看下面这些条件：

1. **配送频率和时效**
   - 是否承诺每天固定时间送到，比如早上6:00—9:00前到店。
   - 临时补货、节假日、恶劣天气能不能加送或调整。
   - 迟到、漏送、少送怎么赔偿，最好写进合作约定。

2. **货源稳定性**
   - 是否有稳定产地、批发市场档口或一级/二级代理渠道。
   - 单品是否经常断货，尤其是香蕉、苹果、橙子、西瓜、时令叶菜类水果。
   - 能不能提前给第二天的报价和可供应清单。

3. **价格和结算**
   - 是否每天报价，价格跟市场行情联动，还是长期固定价。
   - 有没有起送量、配送费、装卸费、退换货扣款规则。
   - 账期是现结、周结还是月结，对账是否按实际收货数量结算。

4. **品质和验收标准**
   - 明确规格：斤两、个数、箱重、成熟度、甜度、大小等级。
   - 允许抽检和拒收：烂果、压伤、过熟、未熟、以次充好怎么处理。
   - 退换货是否当天补送，还是下次配送抵扣。

5. **损耗和售后**
   - 生鲜损耗谁承担，签收前和签收后分别怎么算。
   - 出现质量问题，多久内反馈有效，能否补货或退款。
   - 是否愿意先小批量试供1—2周，再决定长期合作。

6. **配送能力和卫生**
   - 是否有冷藏车、周转筐、防压防冻措施。
   - 水果是否分品类存放，避免串味、挤压、暴晒。
   - 配送人员是否固定，能否直接对接负责人。

7. **资质和合规**
   - 营业执照、食品经营相关资质是否齐全。
   - 能否提供进货凭证、检测报告或产地证明。
   - 是否可开票，发票类型和税率是否匹配。

8. **合作灵活性**
   - 能不能按社区超市的实际销量少量多次送，而不是强行压货。
   - 是否支持代销、试销、滞销调换。
   - 旺季和淡季能否调整品类和数量。

实际筛选时，建议做三步：
- 先找3—5家供应商，各拿报价单和配送方案。
- 每家试供7—15天，重点记录：到货时间、缺货率、损耗率、售后响应。
- 最后按“稳定性、价格、损耗、售后”打分，不要只看谁报价最低。

对社区超市来说，最优先看的是：**每天能不能准时到、断货率低不低、坏果谁承担、结账清不清楚**。这四点比单纯低价更重要。
