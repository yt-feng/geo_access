核心看三点：**买的时间点、香蕉本身的状态、以及你打算几天吃完**。

**1. 先定“什么时候吃”**

- **当天或第二天吃**：选已经通体金黄、柄部略转黄、捏起来微软的。
- **2～3天后吃**：选黄中带一点青、头尾还偏绿、手感偏硬的。
- **4～5天后吃**：选明显偏青、硬挺、没有黑斑的。
- **想放更久**：买整串偏青的，别买已经散把、发软的。

**2. 到店怎么挑**

- **看颜色**：全青=很生；青黄相接=还要放；通体黄=可马上吃；有黑斑=已熟或偏熟。
- **看蕉柄**：柄部发黑、发软，通常已经熟过头或放久了。
- **看棱角**：棱角分明、很硬=生；棱角变圆、手感微软=熟。
- **看表皮**：少量黑斑是熟甜，大面积黑斑、破皮、渗水就别买。
- **闻一下**：有明显酒味、酸味，说明过熟。

**3. 避免“到店太生或太熟”的实用做法**

- **不要只买一整串**：如果超市允许，拆成两小把，一把偏青、一把偏黄，回家分批吃。
- **按天数买**：今天吃买黄的；三天后吃买青黄交接的；别买全青又指望明天吃。
- **别放冰箱冷藏**：未熟香蕉冷藏会变黑、停止成熟。室温阴凉处放。
- **想催熟**：和苹果/梨一起放纸袋里，通常1～2天变黄。
- **想减速**：成熟后单独放，别和苹果、梨放一起；已很熟可冷藏1～2天，皮会黑但肉还能吃。

**4. 一句话判断**

你要**明天吃**，就买**黄、微软、无大面积黑斑**的；你要**过几天吃**，就买**青黄交接、硬挺**的。最稳的是：**买两把不同成熟度，别赌一串香蕉刚好卡在你吃的日子。**
