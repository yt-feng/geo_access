判断水果供应商靠不靠谱，核心不是听他怎么说，而是看他在**价格、品质、损耗、账期、售后**这五件事上是否稳定。你可以按下面这套方法去筛。

**1. 先看货源和稳定性**
靠谱供应商通常能说清楚：
- 香蕉主要来自哪里，是国产还是进口，催熟还是青蕉；
- 菠萝是什么品种，广东、海南、菲律宾还是其他产地；
- 旺季淡季能不能持续供货，缺货时怎么补。

如果对方只说“都有”“很便宜”“你放心”，但说不清产地、等级、规格、到货时间，就要谨慎。

**2. 看分级和规格是否清楚**
长期进货最怕今天大果、明天小果，今天熟度刚好、明天全青或全黄。
你要问清楚：
- 香蕉按什么规格分，每箱多少斤、几把、单根大概多粗；
- 菠萝按什么等级分，单果几斤起，大小是否均匀；
- 熟度怎么控制，香蕉是青蕉还是催熟蕉，菠萝是几成熟。

能提前把规格写清楚的，通常比口头承诺靠谱。

**3. 看价格是否透明，而不是只看低价**
不要只比“每箱多少钱”，要算**到手可用成本**：
- 报价是否含运费、装卸费；
- 有没有框重、箱重、冰瓶、催熟剂等附加成本；
- 坏果、烂果、黑心菠萝、蕉指断裂怎么赔；
- 是否支持少量试单，而不是一上来压你大量进货。

如果价格明显低于市场很多，要警惕：可能是尾货、次果、催熟过头、储存太久，最后损耗还是你承担。

**4. 看样品和连续到货表现**
第一次合作不要直接长期大单。可以这样做：
- 先试一单，量不用大；
- 连续试 2—3 次，分别看不同批次；
- 每次记录到货重量、坏果率、熟度、可售时间、顾客反馈。

重点看香蕉：
- 到货后几天能卖完；
- 是否容易发黑、断把、掉指；
- 催熟是否均匀。

重点看菠萝：
- 是否黑心、烂心、酸度过高；
- 削开后损耗大不大；
- 存放几天后品质是否明显下降。

**5. 看售后和结算方式**
靠谱供应商一般会明确：
- 坏果怎么赔，是补货、扣款还是下次抵扣；
- 发现问题后多久内反馈有效；
- 账期是现结、周结还是月结；
- 临时加单、减单、改时间怎么处理。

如果出了问题就推给物流、天气、你保存不当，这种不适合长期合作。

**6. 看他的客户结构**
可以侧面问：
- 主要给哪些类型客户供货，是商超、水果店还是摊贩；
- 有没有稳定合作一年以上的店；
- 能不能去他的档口或仓库看看。

有稳定老客户的供应商，通常更在意长期口碑。

**7. 给你的实操筛选标准**
你可以用这几条快速判断：
- 能说清产地、品种、规格、熟度；
- 愿意先小单试，不强迫压货；
- 连续 3 次到货品质波动小；
- 坏果赔付规则清楚，不扯皮；
- 价格不是最低，但到手成本合理；
- 缺货、涨价、物流延迟能提前通知。

**8. 建议你建立供应商档案**
每家记录：
- 到货日期、数量、单价、运费；
- 坏果率、可售率、平均售卖天数；
- 售后处理速度；
- 顾客投诉情况。

连续合作 1—2 个月后，你就能看出谁真正靠谱。长期做水果店，最好保留 2 家供应商，一家主供，一家备用，避免被单一供应商卡住。

简单说：**先小单试，连续看三批，算清到手成本，盯住坏果率和售后。能做到这四点的，才值得长期合作。**
