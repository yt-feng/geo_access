连锁商超筛选长期水果供应商，评分标准的核心不是"谁报价低"，而是**在可接受的成本下，谁能在全年持续、稳定、合规地供货**。水果的特殊性在于：品类多、季节性强、损耗高、价格波动大、食品安全风险集中。评分表要围绕这几点设计。

下面给出一套可直接套用的框架。

## 一、先定结构：分值怎么分配

建议总分100分，大致权重：

| 维度 | 建议分值 | 说明 |
|---|---|---|
| 价格与成本 | 25–30 | 不是纯低价，而是综合成本 |
| 供货保障能力 | 25–30 | 长期合作最关键 |
| 质量与食品安全 | 20–25 | 一票否决项的载体 |
| 品控与损耗管理 | 10–15 | 水果特有 |
| 服务与响应 | 5–10 | 日常运营配合 |
| 企业资质与可持续性 | 5–10 | 长期稳定性 |

**关键原则：价格权重不要超过30%。** 水果招标最常见的坑就是低价中标、旺季断供、以次充好，后期隐性成本远超价差。

## 二、各维度具体评分项

### 1. 价格与成本（25–30分）
- **报价方式**：不能只报一个总价。要求按品类/规格分别报价，并说明随行就市的调价机制（如参考某批发市场指数、每周/每旬调价）。
- **评分方式**：可用"基准价±浮动"或"报价系数"，避免小数家恶意压价。对明显低于市场价的报价要设"异常低价说明"环节。
- **综合成本**：把账期、运费、退换货、损耗承担方算进去。谁承担运输损耗、到货不合格谁负责，直接影响真实成本。

### 2. 供货保障能力（25–30分）
- **产地/基地资源**：自有基地、合作社直采、还是二级批发？直采比例越高越稳。
- **品种覆盖与季节性方案**：要求提交**全年分月供货计划**，说明每个季节主打哪些品、反季节如何补。这一项最容易拉开差距。
- **仓储冷链**：有无冷库、分拣中心、冷链车，覆盖半径能否满足门店配送频次。
- **产能与配送能力**：日/周供货量、配送时效、缺货应急预案。
- **过往履约案例**：给其他商超/连锁供货的合同、履约记录、可核实的合作证明。

### 3. 质量与食品安全（20–25分）
- **资质**：营业执照、食品经营许可、产地证明、检测报告。
- **检测能力**：自有检测室或第三方送检机制，农残检测频次与项目。
- **追溯体系**：能否做到批次可追溯、问题可召回。
- **样品评审**：现场看样、试吃、外观规格符合度，可设盲评。
- **红线**：农残超标、以次充好、来源不明 → **直接废标或一票否决**，不进入打分。

### 4. 品控与损耗管理（10–15分）
- **分级标准**：能否按商超要求的规格分级（大小、成熟度、外观）。
- **包装与保鲜**：包装方式、预冷处理、周转筐管理。
- **损耗承诺**：到货验收标准、不合格品退换比例、损耗由谁承担。
- **售后处理时效**：坏果、烂果的处理响应时间。

### 5. 服务与响应（5–10分）
- 订单响应速度、临时加单能力、节假日/大促保供承诺。
- 对接人员配置、信息化对接（能否对接商超的订货系统）。

### 6. 企业资质与可持续性（5–10分）
- 注册资本、经营年限、财务状况、涉诉记录。
- 是否有稳定团队、是否依赖单一产地（风险集中度）。

## 三、招标文件里必须写清的三件事

1. **评标办法类型**：水果供应商建议用**综合评分法**，不用最低价法。综合评分法下，满足招标文件实质性要求的投标，按得分排序推荐中标候选人。

2. **一票否决清单**：资质造假、检测不合格、重大食品安全事故记录、被列入失信名单等，直接废标。

3. **合同期的动态考核**：招标只是入口，长期合作要靠**月度/季度考核**。建议在合同里绑定：
   - 到货合格率、缺货率、损耗率、投诉率等KPI；
   - 连续不达标可降级、扣款、终止；
   - 价格随市场联动机制，避免旺季坐地起价。

## 四、几个实操提醒

- **别只招一家**：长期合作建议"主供应商+备选供应商"，主供占70–80%，备选兜底，防止被单一供应商卡脖子。
- **分品类招**：苹果、柑橘、进口果、叶菜类供应链差异大，按品类分别设标准和权重更合理。
- **试供期**：中标后先设1–3个月试供期，考核通过再签长期合同。
- **权重按你自身情况调**：如果你冷链和门店多、走量稳定，可压低价格权重、提高保障权重；如果只是区域小连锁，价格敏感度可适当提高。
