酒店采购水果盘原料时，建议在采购合同或验收标准中明确以下规格和外观要求，核心是把“可判断、可验收”写清楚：

**一、通用规格标准**
1. **品种与产地**：明确具体品种、产地、等级，如“红富士苹果，山东产，一级果”。
2. **单果重量/大小**：按品种规定单果克重或直径范围，如苹果200–250g/个，橙子直径70–80mm。
3. **成熟度**：要求适合即食或短存，通常7–8成熟，不得过生或过熟。
4. **糖度/口感**：可约定可溶性固形物最低值，如西瓜≥10%、橙子≥11%。
5. **新鲜度**：采收后到货时间、冷链要求、保质期剩余比例，如“到货时剩余保质期不低于总保质期70%”。
6. **包装与运输**：规定装箱方式、单箱净重、防压防潮、冷链温度，如0–8℃冷藏运输。

**二、外观标准**
1. **果形**：规整、无明显畸形，符合该品种典型形状。
2. **色泽**：着色均匀，具有品种成熟应有的色泽，无大面积青白或暗沉。
3. **表面**：无腐烂、霉变、虫蛀、裂口、机械伤、冻伤、日灼斑。
4. **洁净度**：无泥土、药斑、虫卵、异物，允许轻微自然果粉。
5. **大小均匀度**：同一批次大小基本一致，便于摆盘美观。
6. **果梗/蒂部**：新鲜、不干枯、不发黑，无脱落腐烂。
7. **缺陷允许范围**：可约定轻微瑕疵比例，如“外观轻微瑕疵果不超过5%，且不影响食用和摆盘”。

**三、验收与退换**
1. **抽检比例**：按到货箱数抽检，如每批抽5%–10%。
2. **不合格判定**：腐烂、霉变、虫蛀、异味、严重压伤为直接拒收。
3. **退换货**：不合格批次应在规定时间内补货或退款，费用由供应商承担。
4. **凭证要求**：提供产地证明、检测报告、农残合格证明等。

**四、针对水果盘的额外要求**
- 优先选**易切、不易氧化、颜色搭配好**的水果，如西瓜、哈密瓜、火龙果、葡萄、橙子、猕猴桃、苹果等。
- 要求供应商**按酒店摆盘需求分规格供应**，如小番茄统一大小、葡萄整串无掉粒。
- 对**即食水果**，应要求可提供清洗、消毒、切配服务或符合即食标准。

简单说，合同里要写清：**品种等级、单果规格、成熟度、糖度、新鲜度、外观缺陷上限、冷链包装、抽检和退换规则**。这样验收时才有依据，避免扯皮。
