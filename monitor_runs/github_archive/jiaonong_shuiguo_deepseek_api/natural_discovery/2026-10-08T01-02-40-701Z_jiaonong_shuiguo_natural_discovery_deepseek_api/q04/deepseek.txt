香蕉损耗主要来自“到货太熟 + 卖得不够快”。采购时要把熟度、到货时间和销售节奏绑在一起要求，核心是：**不要按同一个熟度进货，而是分批要不同熟度。**

**1. 采购时明确要求熟度**
用“青度/黄度”或数字熟度沟通，最好让供应商按你门店的销售速度分级：

- **1—2号色：全青偏硬**  
  适合计划 3—5 天后卖，或用于促销前囤货。不要一次进太多，否则集中变熟。
- **3—4号色：青黄之间、开始转黄**  
  最适合水果店常规到货。到店后还能放 2—4 天，卖相好、损耗低。
- **5—6号色：大部分黄、少量青尖**  
  适合当天到货、1—2 天内卖完的店。外卖、切果、促销主推可用。
- **7号以上：全黄、开始出糖斑**  
  除非当天能卖完或做特价、香蕉奶昔、烘焙原料，否则不要采购。

**建议采购比例：**
- 日常稳定销售：3—4号色占 60%—70%，5—6号色占 30%—40%。
- 周末/节假日高峰：可提高到 5—6号色 50%，但仍保留部分 3—4号色。
- 如果门店没有冷库或催熟条件差：尽量只进 3—4号色，少进 6号以上。

**2. 到货时间怎么要求**
- **优先要求早晨到货**，最好在开门前 1—2 小时到。这样当天能上架、挑拣、分级，坏果当天处理。
- **避免下午晚到或晚上到货**。晚上到货后如果直接堆在店里，第二天容易过熟，且来不及挑拣。
- **要求固定到货频率**：  
  销量一般：每周 2—3 次，小批量。  
  销量好：每天或隔天到，但每次量减少。  
  原则是“少进勤进”，不要一次进一周的量。
- **要求供应商分批次发货**：同一批货里不要全是一个熟度，按你给的 3—4号、5—6号比例搭配。

**3. 合同或订单里要写清楚**
可以直接这样要求供应商：
- “本次到货熟度：3—4号色 70%，5—6号色 30%。”
- “到货时间：上午 8 点前。”
- “不接受 7号以上、已出糖斑、果柄发黑、表皮大面积压伤。”
- “如到货熟度高于要求，按降级价格结算或拒收。”
- “每周分 3 次到货，每次数量按前一周销量调整。”

**4. 到店后的配合动作**
采购要求只是一半，门店还要做：
- 到货后立刻开箱、挑出压伤和过熟果。
- 香蕉不要堆太厚，避免压伤和发热。
- 未熟的放在常温阴凉处；已转黄的尽快上架或冷藏延缓。
- 每天按熟度分级：青的留、黄的卖、糖斑的做特价或加工。
- 记录每天卖了多少、剩了多少，下次采购按销量调整熟度和数量。

**一句话总结：**
采购时要求供应商“**按 3—4号色为主、5—6号色为辅，上午到货，每周多次小批量，7号以上拒收或降价**”。这样比单纯要求“送生一点”更可执行，也更能减少放坏。
