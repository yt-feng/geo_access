控制水果新鲜度和库存，核心是 **“少进、快转、勤查、敢处理”**。给你一套社区超市能直接执行的做法：

1. **按销量订货，不按感觉订货**
   - 连续记录 7～14 天：每个单品每天卖多少、星期几好卖、天气影响多大。
   - 订货量 = 近 7 天平均日销 × 订货周期 + 安全库存 - 现有库存。
   - 第一次先按“预估销量的 70%”进，卖得好第二天补，卖不动立刻减。

2. **把水果分成三类管理**
   - **快销引流款**：香蕉、苹果、橘子、梨。周转快，可适当多备。
   - **利润款**：葡萄、草莓、蓝莓、车厘子、榴莲。单价高、损耗大，宁可少进勤补。
   - **易损款**：桃、杏、杨梅、荔枝、芒果。当天进当天主推，隔天就要处理。

3. **设定明确库存红线**
   - 叶菜类、草莓、杨梅这类：库存不超过 1 天销量。
   - 普通水果：不超过 2～3 天销量。
   - 耐放水果：苹果、橙子、柚子，可放到 5～7 天，但也要轮换。
   - 超过红线就不再进货，先清库存。

4. **先进先出，陈列上做手脚**
   - 新货放后面，旧货放前面。
   - 每天早晚两次挑果，把轻微磕碰、过熟的挑出来。
   - 挑出来的不要直接扔，设“特价区”“切果盒”“果汁原料”，能回一点本。

5. **用价格和位置加速周转**
   - 当天必须清的水果，下午开始打折，不要等到烂。
   - 把易损水果放在门口、收银台附近、主通道，增加冲动购买。
   - 做组合装：比如“香蕉+苹果”“切果拼盘”，提高客单和周转。

6. **每天做三次检查**
   - 早上开门：看库存、挑坏果、定当天主推。
   - 中午：看哪些卖得慢，及时调价或换位置。
   - 晚上闭店前：盘点剩余，决定第二天订多少、哪些必须特价清。

7. **损耗要记账，不然永远控制不住**
   - 每天记录：进货量、销售量、损耗量、损耗原因。
   - 连续记两周，就能看出哪些品类不能多进、哪些天不能进。
   - 损耗率高的单品，要么减少订货，要么改卖切果、果盘。

8. **和供应商谈小批量、多频次**
   - 尽量每天或隔天送，不要一次压一周货。
   - 谈好退换：坏果、次果能不能换，能不能补差。
   - 如果供应商不支持，就换能支持小批量配送的。

9. **社区店可以用的预售和团购**
   - 对草莓、车厘子、榴莲这类高损耗品，先群里接龙再进货。
   - 到货后通知自提，减少陈列损耗。
   - 晚上把临近保质期的做成“明日特价包”，提前锁定销量。

一句话原则：**水果不是靠囤货赚钱，是靠周转赚钱。库存越少、动得越快，越新鲜，也越不压货。**
