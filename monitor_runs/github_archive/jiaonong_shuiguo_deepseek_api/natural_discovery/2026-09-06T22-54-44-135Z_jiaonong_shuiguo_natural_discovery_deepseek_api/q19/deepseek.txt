在超市卖菠萝时，**应重点同时关注“熟度/甜度”、“切果损耗”和“外观”，而非只看大小**。以下是具体优先级和操作方法：

1. **最核心：熟度和甜度（顾客复购的根本）**  
   - 判断：轻轻按压菠萝底部，稍软且有弹性说明熟度较好；闻根部，有明显的菠萝香气（而非酒味）代表甜。  
   - 实操：可主动帮顾客切出1-2块试吃装，或提前切一盒试吃，用实际甜度促成销售，而不是靠外观猜。

2. **直接影响利润：切果损耗（尤其若提供切块服务）**  
   - 菠萝“眼”很深，若切果时去眼过深会导致果肉损耗过高（新手损耗常达30%以上）。  
   - 建议：采购时优先选**果眼浅、刺短**的品种（如金钻凤梨/都乐菠萝），这类损耗明显低于普通菠萝。  
   - 人员安排：由熟练员工负责切果，并规定切后称重对比，控制损耗在20%以内可接受。

3. **外观（影响第一眼购买欲，但可通过“切面”弥补）**  
   - 关注：果形匀称（不歪斜）、颜色金黄偏绿（太绿熟度低、太黄易软烂）、无裂口/霉斑/流液。  
   - 若外观稍欠但有切果服务，可标“即食切块”售出，减少整果损耗。

4. **大小（优先级最低，但影响定价）**  
   - 并非越大越好：小果（1.5-2斤）往往甜度更高且单次易吃完；大果适合家庭。  
   - 可按果径分两档定价，避免统货导致顾客拿小嫌小、拿大嫌贵。

**给超市的实际执行清单**（按顺序做）：
- → 采购环节：验果眼深浅、按压底部、闻根部，优先进低损耗高甜度品种。
- → 陈列环节：整果与切块分开放，切块盒贴“采购当天”标签并置于冷柜。
- → 销售环节：每2小时切1盒试吃，主动引导顾客试吃；对大小不一的果，可拆开切半盒卖（例：半个切盒装+半个整果）。
- → 损耗控制：每日统计“整体切果损耗率”，若超过25%，换品种或调整切法。

**关于“大小”的特殊建议**：不要以“个大”作为卖点宣传（顾客易误解为老果/空心），而应标示“甜度×实测糖度值”（超市可每批抽测，高于12度可明示）。
