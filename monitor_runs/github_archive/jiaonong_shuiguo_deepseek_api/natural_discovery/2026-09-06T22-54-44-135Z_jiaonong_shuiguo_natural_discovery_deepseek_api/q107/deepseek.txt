是的，**起订量过高确实会增加损耗风险**，尤其是香蕉和菠萝这类易腐产品。具体原因和应对建议如下：

**主要风险点：**
1. **自然成熟期短**：香蕉是呼吸跃变型水果，成熟快（常温下3-5天变软变甜），菠萝虽稍耐储但切开后极易变质。若一次采购过多，销售或消耗速度跟不上，极易在成熟高峰期集中腐烂。
2. **库存压力大**：高起订量意味着占压资金和冷藏空间，若周转不快，会增加维护成本和风味损失。
3. **不可控因素**：运输延误、天气变化、门店销量波动都会放大过量的损耗。

**判断标准：**
- 单次采购量应估算为“**日均销量 × 预计储存天数 + 安全缓冲量（约10-20%）**”，而不是按起订量堆货。
- 香蕉宜选七八成熟（果皮仍绿但稍转黄），无冷库则优先短周期低起订。

**实操建议：**
1. **与供应商谈弹性方案**：尽量要求“分批供货”或“按需提货”，而非一次整订。多数供应链允许把总起订量拆成几批到货。
2. **错峰采购**：如香蕉成熟度高，可与菠萝错开采购时间，避免同时积压。
3. **协同销售**：把高促销活动（如特价拼盘、果切）与这批货的到货周期同步。
4. **冷库管理**：若有冷藏条件，香蕉可冷藏抑制成熟（但不可低于13℃，否则褐变），菠萝可冷藏至8-10℃，延长货架期1-2天。

**结论**：如果无法消化，**宁可接受略高的单价或分次物流成本，也不要囤积超高起订量**。建议先通过日销量数据试运行两周，再最终确认是否接受市场行情要求的最低起订量。
