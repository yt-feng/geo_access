社区超市经营水果，控制新鲜度和库存的关键在于**“少进勤补”**和**“分级处理”**。给你一套实操性强的管理办法：

**第一步：进货源头控制（把好第一关）**

1.  **按“周转天数”定总量**：不要看一天卖多少，要看**“卖完需要几天”**。生鲜周转一般控制在1-1.5天。比如你今天预估能卖100斤苹果，今天只进80-90斤，预留10%-20%的断货空间，即使少赚一点，也绝不留隔夜大库存。
2.  **“跟车拿货”或“产地直发”**：如果条件允许，早上直接去批发市场跟车，挑**最顶手（最新鲜）**的那一车。看水果的**梗（蒂）**是否鲜绿、**硬度**是否合适，拒绝“软趴趴”的。
3.  **“分筐”进价**：进价高的精品果少拿，进价低的“统货”适当多拿，用来做引流和特价。

**第二步：店内“分级”与“先熟先出”**

水果会自然成熟和腐烂，必须区分对待：

1.  **物理隔离**：进店后，先挑出**有碰伤、有软点**的果子放在**“今日特价/立刻吃”**区，快速出货。完好的放正常货架。
2.  **“先熟先卖”排面**：成熟的（颜色深、捏着软）摆在最外层顾客最容易拿的位置，生硬的排在里层。店员补货时，**永远把新货放到后面，旧货往前挪**。
3.  **冷柜/常温分区**：对草莓、蓝莓、荔枝、樱桃这类**极度娇贵**的水果，不要全部上架，留一部分在冷库备货。台面上的卖完再从冷库补，减少高温损耗。

**第三步：每日“动态盘点”与“末位淘汰”**

1.  **每日傍晚盘点**：不要求精确到克，但要快速目测+抽称。设定**“报损红线”**，比如店里水果日损耗率超过5%就要复盘。
2.  **“日落前”清货策略**：
    -   下午4点后，对保质期短（如葡萄、小番茄）或当天进的新鲜货，如果剩得多，直接**打折（比如8折）**。
    -   晚上关门前1小时，对瓜类、苹果等耐放但剩得多的，实行**“买一送一”或“半价处理”**给街坊邻居。
3.  **不卖隔夜“鲜货”**：叶菜类、草莓、切好的果盒，如果当天卖不完，坚决在晚上送给清洁工、保安或直接扔掉，**不要第二天混在新货里卖**。一次砸锅，会毁掉整个店的口碑。

**第四步：内部管理机制（治本）**

1.  **“停售”落后单品**：如果某个单品连续3天动销很差，立刻停止进货，用2天时间特价清空，然后终身禁售（除非换供应商换品质）。
2.  **“以销定采”看天气预报**：
    -   暴雨、极热天气顾客少，进货量直接砍半，主打耐放的瓜类、梨、苹果。
    -   周末、节假日或学校放假时，进货量增加30%-40%，主攻易销的高毛利果（如进口提子等）。
3.  **“每周盘点损耗账”**：把报损的水果分类登记（碰伤/过熟/滞销），月底算出损耗金额，**做进员工绩效里**。店员比老板更怕损耗，自然会及时整理挑拣。

**核心口诀：**
**“宁要空架，不要压架；早起快卖，下午打折，晚上清完；坏果挑得快，客人才愿意再来。”**

如果超市有微信群，每天傍晚把“清货剩余”发群里，很多家庭主妇会来捡漏，这样可以快速消化库存，减少积压。
