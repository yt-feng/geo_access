企业在福利采购水果礼盒时，**建议优先选择支持开发票和定制包装的供应商**，但不是绝对必需，需要视情境权衡。具体分析如下：

1. **关于开发票：基本是必须项**  
   - 企业采购属于公司支出，必须有合规发票（增值税专用发票或普通发票）用于财务入账和抵扣（若为一般纳税人，专票可抵扣进项税）。  
   - 如果不能开发票，可能造成税务风险或无法报销。因此，**供应商必须能提供正规发票**，这是合作底线。  
   - 建议确认发票类型（普票/专票）和税点，提前沟通清楚。

2. **关于定制包装：视预算和用途而定**  
   - **有意义的情况**：若水果礼盒是用于“员工节日福利、客户答谢、贵宾伴手礼”，定制包装（印LOGO、企业标语、定制卡片）能提升品牌形象和仪式感，增强福利的诚意。  
   - **可简化的情况**：若仅是常规员工日常福利、团建自用，或预算有限，标准包装也完全可接受，不必额外加钱。  
   - 注意：定制包装可能涉及设计费、打样费、起订量，需先向供应商确认成本和周期。

3. **其他重要筛选点（不限于此）**  
   - **水果品质与售后**：确认水果新鲜度、坏果赔付承诺（是否有售后保障），比如收到货后多少小时内可包赔。  
   - **配送与保鲜**：是否冷链、能否按员工地址分批送达，是否支持企业集中配送。  
   - **账期与付款方式**：是否支持对公转账、月结等。

**最终建议**：  
- 优先找“能开专票、能满足基础定制（如印logo卡套/腰封）且起订量可承载”的供应商。  
- 若预算紧张，发票是底线，定制可从简（例如仅加一张企业祝福卡片）。  
- 签订合同时，把发票类型、包装规格、售后条款、配送时间写清楚，避免后续纠纷。
