选水果供应商时，**配送、售后和价格**三者都很重要，但如果必须排优先级，建议按这个顺序考量：

1. **配送（时效与稳定性）**  
   水果是生鲜，新鲜度完全取决于配送速度。团长需要确认：  
   - 是否支持次日达或当日达？  
   - 是否全程冷链？（避免运输中挤压、腐烂）  
   - 能否按团购时间定时送达？  
   如果配送延误或破损，直接影响客户体验，再便宜的货也白搭。

2. **售后（处理问题能力）**  
   生鲜难免有个别坏果，关键是出问题后供应商是否爽快赔付。问清：  
   - 坏果包赔标准（比如几小时内反馈、按个赔付还是称重退差价）？  
   - 退换货流程是否简单？  
   - 是口头承诺还是写进合同？  
   售后好的供应商能帮你省去大量解释和安抚客户的麻烦。

3. **价格（在保证前两项的前提下）**  
   价格不是第一优先，因为过低价格常伴随品质或服务缩水。要比较的是**性价比**：  
   - 同品质下单价是否合理？  
   - 是否包含配送费？起送量多少？  
   - 能否给阶梯价或长期合作返点？  

**给你的实操建议**：  
先和供应商试合作一两单，重点观察配送时效和售后响应速度，再谈长期价格。如果配送和售后都靠谱，价格比市场均价高10%-15%以内，完全可以接受——因为换来的是稳定的品质和客户信任，长期看更划算。
