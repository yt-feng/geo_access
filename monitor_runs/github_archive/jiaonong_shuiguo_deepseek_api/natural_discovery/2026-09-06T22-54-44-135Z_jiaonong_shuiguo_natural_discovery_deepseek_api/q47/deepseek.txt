采购香蕉做茶饮或甜品，**熟度控制的核心是“按用途分批次采购，而不是指望所有香蕉都买一个熟度”**。没有一种熟度能同时兼顾饮品和烤布蕾。

直接给你可落地的操作建议：

### 1. 先明确用途，再定“目标色卡”
- **饮品（含果昔、鲜榨、茶底）**：需要**全熟偏软（糖度最高）**。判断标准：果皮呈金黄色，带少量芝麻点，手指轻按果肉有软糯感，但**表皮无大块黑斑**。此时风味最浓，打果汁不用额外加糖。
- **甜品（布蕾、塔、烤香蕉、冰淇淋）**：需要**七八分熟（略带青头）**。判断标准：果皮整体黄，但两端或棱角处略带绿色，果肉按压偏硬但有弹性。这类香蕉在烘烤或熬煮时更容易定型，且水分少、更香甜。

### 2. 采购时按“到店后第2～3天可用”的标准拿货
如果你今天下单，明天到货就用，那采购时应选**七八分熟**。如果后天才用，可以买**九分熟**。**千万别买全熟黄透的**，因为香蕉在门店常温下熟得极快，一天内就会变黑、软烂出水，损耗极高。

### 3. 物理挑选动作（到货验收必做）
- **看棱角**：香蕉表面有五条明显的棱，棱角越尖锐越生，棱角圆润、皮与果肉间空隙明显，则接近全熟。
- **捏两端**：香蕉两端（蒂部和尖部）是最先生熟的区域。捏两端感觉发软，整体就熟了；两端硬，整体偏生。
- **闻果柄**：如果蒂部断开处有浓郁甜香，熟度已接近巅峰，只能当日用。

### 4. 常见采购误区（避坑）
- 不要按“重量”买同一种熟度。门店同时有奶昔（急用）和烤布蕾（可放两天），应该**专门下单两批不同熟度**，而不是买一批回来放冷藏折腾。
- 如果采购供应商只提供一种熟度，优先要**七八分熟**，到店后根据当天需求，把急用的摆常温催熟，不急用的放冷藏（**切勿低于12℃，会冻伤发黑**）。

### 5. 内控标准建议（给你的团队）
建议在验收单上写死：**“全黄带极少芝麻点、按压微弹”为合格**。如果这批香蕉到货时已经出现大面积黑斑或果肉发酸，直接拒收。
