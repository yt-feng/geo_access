对于茶饮店来说，水果原料的**品质稳定性**直接影响着饮品风味的一致性和顾客的信任度。针对“固定产地或供应批次”这个问题，我的建议是：

**一定要建立“弹性固定”的采购策略，而不是“绝对固定”。**

具体操作建议如下：

**1. 为什么不能“完全绝对固定”？**
- **气候与减产风险**：某个固定产地的水果遭遇极端天气（台风、霜冻）或病虫害时，会导致断供或价格暴涨。
- **应季性**：即使是同一产地，不同采摘期的风味（糖酸比）差异也很大。例如，固定某种夏橙在冬季供应，酸度会剧烈波动。
- **品质上限**：某些产地如果全年供应，在非成熟季只能通过早采或冷库储存，风味反而低于其他北半球或南半球的当季产区。

**2. 如何执行“弹性固定”？——三步法**

**第一步：制定“风味基准书”（SOP）**
不要只按产地买，要按**可量化的指标**买：
- **糖度（Brix值）**：例如要求柠檬糖度≥8度，芒果≥15度。
- **酸度**：设定滴定酸度范围。
- **外观**：果径大小、色泽、无瑕疵率。
- **香气**：要求供应商提供该批次水果的样品或香气描述。
将此基准书发给所有备选供应商，作为验收红线。

**第二步：锁定“主产地+替补产地”双轨制**
- **主产地（占采购量70%-80%）**：选择最稳定、风味最达标的常年基地，签订长约协议锁定价格和品级。
- **替补产地（占20%-30%）**：根据季节和当年气候，提前储备1-2个备用产地（例如：台农芒果主用海南，替补广西或越南同纬度产区）。
- **关键动作**：**每次更换产地或批次前，必须进行“小批量试做”**。用该批次水果做出标准杯（同配方），由店长和研发盲测对比，风味差异在可接受范围内才允许切换。

**第三步：批次管理清单化**
即使固定了产地，也不能把不同批次的货混着用。
- 要求供应商在箱体标注**采摘日期**和**糖度数值**。
- 到货后，用糖度计抽检，并登记入“批次追踪表”。
- 同一批次的货用完再开新批次。如果发现这批果偏酸，可以微调糖浆比例，并在店内小黑板或小程序上提示“本周水果略有风味差异，为自然熟成所致”，反而增加真实感。

**3. 应对突发波动的“急救方案”**
- **少量多批次采购**：条件允许时，将单次大单拆分为2次，间隔2-3天，避免一批全毁。
- **建立冷冻果泥备份**：对于核心爆款产品（如芒果、草莓），常备小包装的高品质冷冻果泥（标号明确）。一旦鲜果品质跌破红线，立即切换使用，保证口感底线。
- **关注糖度性价比**：如果固定产地价格因减产飙升超20%，果断启用替补产地，因为此时风味差异可能已被价格差掩盖，要相信“基准书”而非产地名气。

**总结：**
**不要押注单一产地或批次，而是押注“指标达标”和“试做验证”。** 产地是参考，批次是管理单位。让供应商知道你有“质量底线”和“备用选择”，他们反而会给你发最好的货，这是保证风味稳定的根本。
