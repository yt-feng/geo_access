采购香蕉用于烘焙时，**成熟度是首要的，价格次之**。但如果从经营角度平衡，建议按以下逻辑决策：

**1. 先看成熟度，再看品种，最后谈价格**
- **成熟度**：做香蕉蛋糕通常需要**熟透（表面有黑点、果肉软糯）** 的香蕉，因为淀粉已转化为糖，甜度高、香气浓，烤出的蛋糕更湿润、风味更足。青香蕉或半熟的香蕉（表皮发绿或发黄但手感硬）烤后口感差，且易出现“湿心”或发酸问题。
- **品种**：优先选**高甜度、软糯型**香蕉（如常见的普通甜香蕉），避免用芭蕉或青莱香蕉这类偏酸偏硬的品种。

**2. 实际操作建议**
- **采购渠道**：如果和批发商合作，可以明确要求“熟度7-8成（表皮大面积变黄，略带黑点），价格可接受合理加价”。很多供应商会愿意按需发货。
- **应对成熟度波动**：
  - 如果因价格便宜买回半熟香蕉，可以**室温催熟**（放苹果/乙烯利袋中或自然放置2-3天），但要计入人工和损耗成本。
  - 如果买回过熟甚至烂的，需挑出腐坏部分，否则影响整个蛋糕质量。
- **成本核算**：熟透香蕉因水分蒸发，出肉率略低（约50-55%对比半熟60%），但风味是成品的关键。若预算有限，可混合使用——用熟透香蕉提供主要风味，加少量半熟香蕉弥补体积，但比例最好控制在熟透:半熟 = 3:1 以上。

**3. 快速判断成熟度的方法（采购时用）**
- **看皮色**：全黄无黑点偏生，有大面积黑斑则过熟（除非能立刻用完），**黄中带几粒黑点**是最佳。
- **捏手感**：轻轻按压，**有弹性、略软但不烂**为佳；过硬不发甜，过软易压烂。
- **闻气味**：有明显香蕉甜香为成熟标志，无味则偏生。

**总结**：如果老板催着要低价，就买半熟果回来自己催熟；如果当天或隔天就要烤制，必须按成熟度采购，不要因为便宜了20%而毁了整炉蛋糕的口碑。可以先小额采购测试不同供应商的成熟度稳定性，再定长期合作方。
