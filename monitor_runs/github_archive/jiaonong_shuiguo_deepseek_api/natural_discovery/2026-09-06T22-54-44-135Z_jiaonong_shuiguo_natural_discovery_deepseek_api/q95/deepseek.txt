针对学校食堂采购香蕉、苹果、橙子这类常见水果，选择供应商的核心原则是：**安全可追溯、供货稳定、价格透明、服务到位**。

以下是具体的筛选和执行建议：

---

### 一、供应商资质硬性门槛（缺一不可）
1.  **必须三证齐全**：营业执照（经营范围含水果批发或鲜果销售）、食品经营许可证。如果是进口水果（如部分橙子），需提供《入境货物检验检疫证明》。
2.  **产地/源头证明**：要求供应商提供与果园或一级批发市场的长期合作合同，能说清水果的具体产地（例如是陕西苹果、赣南脐橙还是海南香蕉）。
3.  **农残检测报告**：**每批次**水果必须随货附上由第三方检测机构出具的农药残留检测合格报告，不能只看上一次的。

---

### 二、考察供应商的硬实力与软服务
建议邀请至少3家供应商报价，并实地考察其仓库或分拣场地：

| 考察维度 | 具体检查点 | 不合格信号 |
| :--- | :--- | :--- |
| **仓储环境** | 库房通风、干净，水果不直接接触地面；有冷藏库（苹果需冷藏，香蕉需催熟库或常温库）。 | 露天堆放、烂果满桶、苍蝇乱飞。 |
| **分拣能力** | 是否有独立的分拣台，能否按学校要求剔除伤果、畸形果。 | 混装混卖，大小不一。 |
| **库存周转** | 当天或前一天到的货为主，不卖长期库存（香蕉有黑斑、苹果表皮发皱）。 | 货架深处有过期积压货。 |
| **配送能力** | 是否自有冷藏车或厢式货车，能否承诺**固定配送时间**（如每日/隔日早6点前送到）。 | 委托快递或小三轮送货，时效无保障。 |
| **突发事件应对** | 能否在台风天、节假日等情况下临时增加货源并保证品质。 | 无法提供备用供应商联系方式。 |

---

### 三、针对不同水果的差异化要求
1.  **香蕉**：必须选择**有催熟库的供应商**。香蕉到货时通常是青绿色的，需要供应商提前催熟至“黄中带绿”状态送达学校，避免到货太青无法食用或太熟易烂。**严禁**采购使用违规化学催熟剂（如乙烯利超标）的香蕉，要求供应商提供催熟工艺说明。
2.  **苹果**：重点看**口感和脆度**。建议供应商提供样品试吃，明确品种（如红富士、嘎啦），拒绝“水裂纹”严重的果（易缩水）。苹果耐储存，但也要求供应商提供近期采摘证明，防止买到冷库超半年的旧果。
3.  **橙子**：必须选用**表皮紧实、底部凹进去**的脐橙或冰糖橙。警惕供应商以“酸橙”或“过季橙”冒充。秋季后应采购应季产地（湖南、江西），避免采购进口橙（可能打蜡抛光，需明确是否食用蜡）。

---

### 四、合同条款中的关键点（降低风险）
在合同中必须写明以下违约条款，否则口头承诺无效：
-   **抽检机制**：每批货抽检10%，若发现腐烂率超过5%（香蕉、橙子）或碰伤率超过3%（苹果），**整批无条件退货**，供应商承担补货及误工责任。
-   **价格锁定**：约定“以周为单位”或“以旬为单位”锁价，不接受供应商随市场价格随意涨价。付款周期建议为月结（即“先供货、月底对账付款”），既能降低食堂资金压力，也能筛选出资金实力弱的皮包公司。
-   **食安责任**：明确若因水果农残超标或变质引发学生食物中毒，供应商承担全部法律责任及医疗赔偿。

---

### 五、操作建议流程（今日可执行）
1.  **发布询价单**：通过当地教育局推荐的“阳光食堂”平台，或直接联系本地最大农产品批发市场管理方，索取3家以上候选名单。
2.  **索取报价单**：要求供应商报**净重价**（去筐、去箱皮后的价格），并对大小规格（如苹果直径80mm以上）做统一要求。
3.  **试供一周**：不要急于签大合同，先试供一周。每天抽检到货品质并拍照留证。
4.  **建立“黑名单”**：若发现供应商以次充好（如将烂果埋在中层），永久终止合作并上报学校纪检部门。

---

**最后提醒**：学校食堂采购**永远不要只贪图便宜**，最低价往往意味着在分拣、冷链或农残控制上削减成本。优先选择本地教育局或市场监管部门公示过的**“放心食材”供应商**，如果本地没有，宁可多花15%-20%成本，也要选择能提供真实批次检测报告、自有冷链的大型配送企业。
