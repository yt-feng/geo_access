这是一个非常典型且现实的问题。便利店做水果生意，核心逻辑不是“大而全”的精品超市逻辑，而是**“小而精”的高周转逻辑**。面积小意味着容错率低，所以策略上要“少进货、勤补货、重鲜度、快出清”。

以下是针对**品类控制**和**损耗控制**两个维度的实操建议：

### 一、 品类控制：从“多”到“精”，做“流量型”组合

在便利店，水果通常不是利润核心，而是**引流品**或**搭配品**。品类建议控制在 **4-6个SKU** 以内。

1.  **只做“高频、耐放、刚需”的引流款**
    -   **绝对主力（不能断货）**：香蕉、苹果（红富士/嘎啦）。香蕉是便利店水果的“王炸”，复购率高且自带香味吸引顾客；苹果耐放，损耗低。
    -   **季节爆款（限时上架）**：西瓜（夏季切盒）、砂糖橘（冬季）、草莓（尝鲜期）。这些只在旺销季卖，不追求全年有货。

2.  **放弃“高价小众”和“易损娇贵”品**
    -   **不建议碰**：山竹、榴莲、整箱提子、水蜜桃、杨梅。这些要么进货成本高、要么极度易损，一旦滞销就是纯亏。
    -   **主推“即食型”**：既然是便利店，顾客多为即买即吃。多卖**切好的果切（组合装）**，能提高客单价并处理掉微损水果（见下文损耗篇）。

3.  **严格遵循“二八法则”陈列**
    -   把最好的位置（收银台旁或进门处）让给**毛利高且周转快的爆款**（如香蕉、圣女果）。
    -   减少堆头，建议采用**小筐浅装**（底部垫海绵），防止顾客翻捡造成的物理损伤。

---

### 二、 损耗控制：核心是“动销速度”与“分级处理”

损耗控制的核心不是“冷藏”，而是**计算好“陈列时间”和“出清时间”**。

1.  **“以销定进”的极端化策略（宁缺毋滥）**
    -   **如果你是加盟店**：水果不要从总部或大仓大批量订货，尽量找周边**本地批发市场或果蔬配送商**，做到**每日一配**。
    -   **订货公式**：今日订货量 = 昨日销量 × 预估系数（如1.1）。如果昨日剩货多，今日必须减少进货，哪怕断货，也不要积压过夜。

2.  **一天的“三段式”损耗管理（时间轴）**
    -   **上午（11点前）**：只摆全果（整颗售卖），不打折。
    -   **下午（14：00-16：00）**：巡视台面，将出现轻微磕碰、发软但不影响食用的水果挑出，**现切成果切**（如西瓜盒、哈密瓜盒），用透明盒装好，卖原价。
    -   **傍晚（18：00后）**：针对**切盒水果**进行**“临期特价”**（买一送一或立减3-5元）。一定要在当日打烊前**清空所有切盒**，绝不过夜（鲜切过夜是投诉重灾区）。

3.  **“视觉损耗”与“物理损耗”的双重控制**
    -   **翻捡损耗**（最重要）：建议顾客“请勿用手捏”，但更重要的是**勤摆台**。每隔2小时把下层的鲜果翻到上层，被顾客捏软的及时下架。
    -   **分装小包装**：像葡萄、圣女果这类，不要散称，直接**提前用保鲜盒装好**（每份约300g-500g），标价出售。这能大幅减少顾客挑拣带来的损耗，同时提高客单价。

4.  **设置“止损红线”**
    -   设定一个固定的**损耗预算**（例如：每月水果损耗率控制在5%以内）。
    -   一旦单品在**货架期超过48小时**仍未售出（香蕉除外），无论是否看起来还好，立即转果切或特价清仓，不要有侥幸心理。

---

### 三、 额外的小建议（针对小店）

-   **考虑“代卖”或“拼单”**：如果店小且单量不稳定，可以找隔壁的奶茶店、快餐店拼单进货，共享物流成本。
-   **不做“全果”做主“果切碗”**：面积小，一个冷柜放满切好的混合水果碗（如：香蕉+火龙果+西瓜=10元），毛利可达50%以上，且能利用尾货。

**总结一句话**：便利店卖水果，**“能早卖出的才进货，卖不动的绝不进第二件”**。把每日进货量压到“晚上最多剩2-3份可切果”的状态，损耗就控制住了。**宁可高峰期卖断货，也绝不留着过夜等明天。**
