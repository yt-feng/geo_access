判断水果供应商是否靠谱，不能只听他口头承诺“每天都新鲜”。你可以从**稳定性、账期、售后、专业度**四个维度去“逼”他现原形。

以下是可直接上手验证的标准和实操细节：

**1. 看他的库存和周转周期（防“僵尸果”）**
- **香蕉**：问他要“树上熟”还是“催熟”的，并现场看他冷库温度（应为13-15℃）。靠谱供应商会说清楚“这批货到店后大概能放几天”，并主动告诉你最佳售卖期。如果他说“放一个月都不会坏”，那基本是忽悠你。
- **菠萝**：问他要“都乐”还是“本地土炮”，并检查菠萝果眼深度和底部是否有霉斑。靠谱的会告诉你现在是海南菠萝还是泰国小菠萝的产季，而非只报菜名。

**2. 现场签约前，先做“小单试错”**
不要一开始就定三个月大合同。先下一周小单（比如各10箱），观察这三件事：
- **破损率**：香蕉到货，烂柄、压痕超过3%就不算合格；菠萝绿叶干枯、果蒂发黑，无条件换。
- **到货时间误差**：说的早上一早到，结果拖到下午4点，这反映物流管理混乱。
- **补货灵活性**：今天卖得好想临时加量，他是否能隔天送到？如果只能死板按周计划，店庆或节假日会吃亏。

**3. 看他的“坏果赔付”规则是否白纸黑字**
靠谱供应商不怕你杠。
- 口头说“坏了包赔”没用，要求他把**损耗率、签收时效（比如到店2小时内必须反馈）**写在送货单背面或合同附加条款里。
- 真正优质的供应商会主动告诉你：“菠萝这种带皮货，我们按1%自然损耗内含，超出的拍图即补。”如果他说“生鲜果类离柜不认”，请立刻换人。

**4. 隐藏大招：看他如何处理“滞销尾声”**
这是区分新老手供应商的极限测试。
- 你问他：“如果我有一批菠萝到了最佳赏味末尾，卖不动了，你能帮我做二次催熟或换成熟度高的货吗？还是直接要求我自己承担全部损失？”
- 靠谱供应商（通常拥有自己产地或一级档口）会给出具体操作建议，比如“帮你拉回冷库做低温慢熟处理”，或者“教你做菠萝冰/果切延长货架期”。
- 只想甩清责任的，遇到水果价格大跳水时也会先坑你。

**5. 专业度检查（让你不踩坑的加分项）**
- **香蕉**：他会不会告诉你“香蕉绿熟期（偏硬）适合打包卖，黄熟期（出芝麻点）适合散称，直营店和社区店要拿不同成熟度”？能说出这个，说明懂终端。
- **菠萝**：他是否清楚“削皮的菠萝要用盐水泡20分钟才能卖，且不能提前削好放冰柜超过4小时，否则易发黑”？如果他对门店操作细节一无所知，只懂开大车拉货，合作深度有限。

---

**总结行动清单（下周就用）**：
1. **不要问“香蕉甜不甜”**，直接问：“你这批发价多少，到货果柄切口发黑能给补多少？”
2. **看他的车**：冷藏车是冷链标配。如果开普通货车后斗堆着来，夏天20度以上运输，基本可以直接淘汰。
3. **让他带你看一次他发往其他店的货**：如果他在批发市场转运的杂乱摊点发货，而非自己档口，稳定性堪忧。

最后记住：**靠谱的供应商是靠“稳定”赚钱，不靠谱的是靠“差价和忽悠”赚钱**。初期多花200元运费换来少丢3箱货、少跑10次售后，对你长期来说是最省钱的。建议先锁2-3家试合作1个月，再定主供应商和备胎。祝开业大吉！
