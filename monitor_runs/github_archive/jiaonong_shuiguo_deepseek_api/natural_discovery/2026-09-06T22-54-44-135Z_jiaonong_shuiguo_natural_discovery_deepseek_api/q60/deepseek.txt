在茶饮店遇到水果到货不合格时，**核心原则是：先保营业（应急补货），再谈责任（合同追责），书面化流程**。

以下是一套可执行的补货约定建议，分三步走：

**一、 事前（合同阶段）——把“补货条件”写进供货协议**
这是根本，建议在采购合同或供货协议中明确以下条款：

1.  **验收时限与标准**：约定“到货后**2小时内**须完成抽检”，并写明不合格标准（如霉变率超过3%、果损率超过5%、外观畸形等）。过时不提出视为合格。
2.  **补货时效承诺**：明确约定“若需补货，供货方需在收到书面通知后**4小时内**送达合格品”，并注明“若因补货不及时导致门店断货，供货方承担当天该饮品销售额的**N倍**赔偿”（N建议不低于2倍）。
3.  **机动供货商备选**：在合同中约定“若主供因质量问题无法及时补货，乙方（你方）有权从备选供应商处采购，差价由甲方承担”。

**二、 事中（到货当天）——立即启动“双线作业”**
当遇到质量问题且急需用果时，不要等对方回复，要同时进行：

1.  **一线：现场止损**：让员工立刻分拣。**能用一部分的（如切掉烂斑）立即清洗加工**，防止全面停售。同时保留坏果实物（拍照、封存），这是后续索赔依据。
2.  **二线：紧急联络与定价**：
    -   **电话直连供应商负责人**：明确告知“这批货不合格，我**现金**加急购买**30斤**（举例）合格果，请现在发货，运费我承担”。
    -   **启动备胎方案**：同步电话当地批发市场（如农产品市场商户）或同城水果电商（如美团优选等），确保商家有备用采购渠道，**双线等货**，谁先到用谁。

**三、 事后（补货抵达后）——书面确认，避免扯皮**
补货送到时，不是你口头说“到了就行”就能了事的：

1.  **现场验收**：补货到达时，同样执行开箱抽检，并让送货司机在**验收单**上签字确认“补货合格”。
2.  **冷处理与扣款通知**：当天，将不合格品的照片、数量、损耗记录及补货运费单据，做成**PDF采购异议单**，邮件或微信文字发供应商确认（不要只打电话，要有文字记录）。
3.  **约定扣款方式**：在异议单中写明：“本次不合格品费用暂缓结算，补货产生的**30元运费**及因停售造成的损失，将在下次货款中直接扣除”或“本次不合格品按半价处理，我方不退，但下次订货时请给予9折补偿”。

---

**如果现在还没签合同，或对方是熟人不好开口，该怎么办？**

给一个最小阻力的话术模版：**“这批货确实不能用了，我这边正等着用。麻烦你现在按市场价发一趟急件，运费我认了，但不合格这箱我下回算账时得减掉，行不行？”**
这样做的好处是：把矛盾从“索赔”转成“解决燃眉之急”，先让对方送货（保营业），把财务损失（运费和损耗）留到“下回结算”时处理，这是茶饮店实战中最有效的方式。

**额外提醒**：日常建议在冰箱里常备1-2种“替代果品”（如冷冻果泥、罐头水果），用于突发断货时调制不影响口感的替代饮品菜单，这是防止营业断档的最后一道保险。
