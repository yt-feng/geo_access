判断连锁超市香蕉供应商是否具备**全年稳定供货能力**，不能只听口头承诺，需要从**供应链结构、种植基地、风险管理、物流体系和财务健康**等多个维度进行交叉验证。

以下是一套可执行的筛选和评估清单：

**1. 审查“产地矩阵”而非单一产地**
香蕉是热带水果，全年供应依赖南北半球产区轮换。
*   **看地图**：要求供应商提供其全年供货的**产区规划表**。优质供应商通常会在国内海南/云南、菲律宾、厄瓜多尔或哥斯达黎加等（针对进口货源）布局至少2-3个基地或合作庄园。
*   **验证**：询问在**台风季**（国内夏秋）或**南美雨季**期间，他们的货源切换机制是什么。如果只依赖单一国家或单一港口，全年稳定的风险极高。

**2. 物流与冷链的“硬资产”核查**
*   **船期与到港频率**：询问他们每周/每月的集装箱到港数量。稳定的供应商通常与船公司签有长期协议（COA），保鲜柜资源充足。
*   **催熟库能力**：香蕉需要人工催熟。关键问题：**“你们的催熟库容量是多少？是否有GLOBALG.A.P.（全球良好农业操作规范）或ISO22000认证？”** 如果供应商没有自有催熟库或者只是随卖随熟，遇到节日备货高峰（如春节前）时会断供。

**3. 库存与“安全垫”的财务逻辑**
*   **看库存天数**：要求查看过去三年的**月末库存报表**。虽然鲜果库存不宜过长，但一般需要维持3-5天的安全周转库存。
*   **敏感问题测试**：直接问：“如果厄尔尼诺现象导致菲律宾减产50%，你如何填补我的采购缺口？” 正规供应商会提供**备选替补方案**（如转向中美洲或非洲货源），而非只重复“我们合作很久了”。

**4. 历史违约记录的“背靠背”验证**
*   **索要其他客户案例**：要求提供其为其他**大型连锁超市或便利店**（如永辉、华润万家、百果园等）连续供货的合同期限证明或订货单。
*   **旺季压力测试**：建议在**中秋或国庆前夕**下一个小额试单，观察他们能否在价格波动时按合同价足量交货。

**5. 合同硬性条款设定**
*   **锁定“浮动补损”条款**：在合同中并非只写“尽力供货”，而需明确：因供应商原因连续两周缺货，需赔付超市方替代采购的**差价损失**及**销售额损失的20%**。
*   **设立“过路费”机制**：要求供应商缴纳**年度保证金**（如合同额的5%），若发生断供则扣除保证金，这是对稳定性的最强硬约束。

**6. 现场验厂的关键细节（如果条件允许）**
*   去其**冷库和分拣线**看一眼：
    *   **看卸货平台**：是否有遮阳棚？香蕉怕高温暴晒，若卸货平台阳光直射，损耗会转嫁到售价和货架上。
    *   **看催熟房的气体控制**：检查是否有自动的乙烯气体浓度监测仪，而非人工凭感觉操作——这决定了到店香蕉的均匀熟度。

**最终建议：**
**不要只拿“采购订单”去测试，先拿“临时补货”去测试。**
在非合同期，故意向该供应商下达一个**“紧急加单30箱且次日送达”**的需求。如果该供应商能确保第二天的到货品质和价格波动在合理范围内，说明其内部调度体系是有余量的；如果其回复“今天没人摘”或“车安排不过来”，则需将其稳定性评级下调一级。

**一点提醒：** 请务必要求供应商提供**近期的官方检验检疫证明（CIQ）**及**农残检测报告**，全年稳定供货的前提是全年合规，否则一次抽检不合格就可能导致整店下架。
