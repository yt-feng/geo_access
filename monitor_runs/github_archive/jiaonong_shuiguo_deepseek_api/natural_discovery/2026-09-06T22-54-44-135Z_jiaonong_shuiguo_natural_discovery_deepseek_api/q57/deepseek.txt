针对餐饮连锁采购水果，**最核心的原则是：先看水果的“易损性”和“成熟度”，再看“配送半径”和“门店销量”。** 

在绝大多数情况下，**中央厨房统一收货（总仓模式）是更优解**，但必须辅以“产地直发”和“门店二次加工”的配合，切不可“一刀切”。

以下是详细的判断维度和操作建议，供您直接落地参考：

### 方案一：中央厨房统一收货（集中模式）—— 推荐主方案

**适用条件**：
- 城市配送半径在 **1-3小时车程** 内；
- 门店数量较多（3家以上）且分布相对集中；
- 中央厨房具备冷藏库（预冷能力）和分拣打包线。

**优势**：
1.  **品控可管**：水果烂果率最高的环节是“上车后不预冷”和“堆压”。中央厨房可以做到**到货全检、抽检、预冷、分选**，剔除坏果后再配送。
2.  **损耗可追踪**：供应商只对接总仓，责任明确。若为门店直收，店长和供应商容易因“是非烂果”扯皮。
3.  **价格与议价权**：统一收货量大，可以谈产地直采或一级批发价，比门店零散采购便宜5%-15%。
4.  **标准化切配**：可统一进行清洗、切配（如沙拉用水果），保证门店出餐一致，且减少门店后厨面积和人力成本。

**关键操作建议（必须做）**：
- **分批到货策略**：水果不是干货，不宜一次性备货3天。建议**每天或隔天由中央厨房收货**，收货后立即进入 **0-4℃ 预冷库**（气调库更好），次日凌晨配送到店。
- **防止二次损伤**：中央厨房分拣后，建议使用**标准周转筐（非纸箱）**装车，避免门店收货时纸箱受压导致的隐性压伤。

---

### 方案二：门店分开收货（产地/供应商直送）—— 推荐特殊场景使用

**适用条件**：
- **高损耗/极不耐储**的单品：如**本地草莓、杨梅、水蜜桃、当日鲜榴莲**。
- 门店距离中央厨房太远（超出配送经济半径），或跨城市开店且本地有优质供应商。

**优势**：
1.  **时效最快**：水果从采摘到上架的时间最短，能最大程度保留风味，尤其是早熟果或后熟果（如香蕉、牛油果需要门店自行催熟）。
2.  **减少倒运**：避免总仓二次分拣对娇嫩水果造成机械伤（例如整箱的巨峰葡萄在分拣筐里翻动很容易掉粒）。

**巨大风险（这是大多数连锁失败的原因）**：
- **腐败漏洞**：店长若吃回扣或与供应商串通，以次充好，总部无法管控。
- **库存不可控**：每一家店凭感觉报量，会导致有的店缺货，有的店烂在库房。**极容易出现“各店订货量相加远超总需求量”的牛鞭效应。**

---

### 最适合餐饮连锁的“混合最优解”策略

根据十年连锁餐饮供应链经验，规模化的餐饮采购水果，建议采用以下 **“三级模式”**：

1.  **普货（苹果、橙子、梨、西瓜、香蕉等耐储货）**：**必须**中央厨房统一收货。大宗采购、统一分拣、中央仓周转。供货商直送总仓，总仓每日分货到店。
2.  **高价值娇贵果（阳光玫瑰、精品樱桃、蓝莓等）**：**供应商直送总仓，但由总仓进行“轻加工”**。不进行开箱分拣，只贴码，第一时间原箱冷藏，原箱配送至门店，门店只验箱头码和抽检底层。
3.  **本地鲜果/叶类配套**：若你的门店是社区型且生意很好，**允许门店在总部SOP（标准作业流程）和指定的2-3家本地供应商名单内，小范围、单品类、临时补货**（例如周五晚上草莓卖完，周六早上补一箱）。但总部要建立**周价格审计**机制，防止买贵。

### 最终决策表（请对号入座）

| 您的实际情况 | 推荐做法 |
| :--- | :--- |
| **门店<5家，且都在1个城市** | **门店分开收货**（但需总部统一定价和指定供应商，做“虚拟总仓”），因为建中央仓的成本高于省下的损耗。 |
| **门店>10家，且集中在1-2个城区** | **绝对建议中央厨房统一收货**，建立日配机制。 |
| **主打水果现切/鲜榨果汁** | **必须中央厨房**。需要标准化蔬菜水果清洗消毒流程，门店操作容易有食安风险。 |
| **多城市、跨省连锁** | **区域中央仓模式**（重点城市建仓），区域仓统一收货，区域内门店日配。 |

**一句话总结**：**为了品控和成本，首选中央厨房；为了极致的“新鲜度和特殊品类”，对部分娇贵水果采用“直发门店”作为补充。整个过程，总部必须掌握唯一的“订货统计系统”和“供应商名录”。**
