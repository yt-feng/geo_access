大型超市水果供应商必须建立一套**覆盖全供应链的食品安全管控体系**，并具备专业化的冷链物流能力。具体能力要求可拆解如下：

### 一、食品安全能力（核心底线）

1.  **源头基地管理能力**
    -   必须拥有自有或签约的**稳定果园基地**，且基地需具备产地环境（土壤、水源）检测报告。
    -   建立**农残重金属自行监测制度**，每批水果需提供第三方检测报告，或具备快速农残自检设备（如胶体金速测）。
    -   必须能提供**追溯编码**，实现从“果园到货架”的批次信息可视化（如二维码追溯）。

2.  **采收与分拣标准能力**
    -   制定严格的采收成熟度标准（如糖度/硬度指标），防止催熟剂滥用。
    -   分拣区需具备**防交叉污染**措施，烂果、坏果必须当场剔除并隔离，严禁装箱。

3.  **仓储及保鲜技术能力**
    -   必须具备**精准气调库或冷库**（温度、湿度可自动调节），并配备温度记录仪（可留档）。
    -   对于易腐品类（如草莓、车厘子），需要预冷处理能力（采摘后几小时内预冷至0-4℃）。
    -   仓储需防止虫害、异物混入，地面与货架需有防尘、防潮设施。

4.  **单据与合规能力**
    -   需提供完整的**农产品合格证、动物检疫/植物检疫证明（如需跨省）+ 运输车辆消毒证明**。
    -   需建立不合格品召回机制，一旦抽检出问题，能锁定批次并在24小时内通知超市下架。

### 二、物流能力（决定鲜度与货架期）

1.  **全程冷链运输能力**
    -   必须配备**自有或合约冷藏车队**，车厢需具备**双温区**（如热带水果与温带水果分温区）。
    -   运输过程需配备**GPS温控追踪**，温度波动公差需控制在±1℃以内（部分高端超市要求±0.5℃）。
    -   车辆需具备**车厢消毒记录**，且装卸过程需缩短“断链”时间（从冷库到冷柜车时间不超过30分钟）。

2.  **时效与补货响应能力**
    -   需具备**“每日一配”**或**“隔日达”**的履约能力，确保水果货架期不低于行业标准（如进口香蕉到店后需有3-5天陈列期）。
    -   需建立缺货预警机制，若单品断货，需在48小时内完成补货。

3.  **分拣与包装物流能力**
    -   具备**预包装线**，可进行贴标、分小包装，减少门店二次处理造成的耗损。
    -   使用**防震缓冲材料**（如珍珠棉隔层）进行装箱，避免运输振动导致腐损。
    -   精确控制**装载率**，层叠高度需有规范，防止压伤底层水果。

4.  **逆向物流能力（退换货）**
    -   具备对临期、滞销水果的**返仓或销毁**处理流程，需要录像留证，防止变质水果回流市场。
    -   能对运输造成的碰撞、压损承担明确赔付比例。

---

### 警惕红线（超市采购必查点）
-   **不得**使用不符合国标的保鲜剂、防腐剂（如乙氧基喹啉用于苹果保鲜不得超过限量）。
-   **不得**将普通喷淋保鲜水充当“可食用果蜡”。
-   **不得**将不同批次但外观无差异的水果混装出货（极易造成追溯失败）。

**给超市的落地建议**：建议选择供应商时，要求其提供**近3个月的运输温度记录曲线**及**主要批次农残报告存档**，而非仅仅看资质证书。对于高端精品果，额外要求提供“采后处理工艺说明”（如是否经过气调处理、特艺包装），以增强损耗前置控管。
