判断茶饮连锁供应商能否稳定按规格送货，核心在于**制度、数据和历史行为**，而非口头承诺。建议从以下四个维度进行考察和验证：

### 一、 事前：合同与标准前置（防止扯皮）
1.  **写明“规格验收标准”**：合同中必须附上**图文并茂的验收标准**。
   - 例如：菠萝成熟度（墨绿色/黄绿色比例）、单果重量（误差±10%）、糖度（不低于12°Brix）、有无黑心/水伤、切削损耗率（如≤25%）。
   - **关键条款**：约定“若到货不合格率超过5%，供应商需无条件补货或折价，并承担门店停售损失”。
2.  **要求提供“批次追溯码”**：让供应商承诺每批货附带采摘或加工厂批号，确保出现问题时能反向追溯责任。

### 二、 事中：看工厂与冷链能力（决定稳定性）
建议实地考察或要求视频验厂，重点看三点：
- **冷藏仓储能力**：是否有恒温催熟库（菠萝后熟型），是否有0-4℃冷库暂存，冰袋和泡沫箱是标配还是选配。
- **分拣设备**：如果供应商声称“按规格筛选”，是否有人工分拣线或光电分级设备？若全凭人工目测，规格波动风险极高。
- **日供货量上限**：询问其“单次最大可交付量”。如果您的门店峰值需求量超过其日处理能力的70%，稳定性堪忧。

### 三、 历史数据验证（最快最准）
- **试单测试**：先下**3次小批量试单**（如每次100公斤），间隔7天。测试内容包括：
  - 到货重量是否足秤（扣除包装和压伤）。
  - 大小规格是否齐整（抽检10个称重，看变异系数）。
  - 切开后内部品质（有无白肉、黑心）是否一致。
- **索要其他连锁的月度交货记录**：让供应商提供其为其他品牌（同体量）服务的**过去6个月的准时率、缺货率、退货率**数据（可脱敏）。无法提供真实数据或含糊其辞的，应谨慎。

### 四、 引入“动态考核”机制（关键）
不要迷信一次性考核，用数据倒逼其改进：
- **设定考核公式**：每月考核 = 准时率×40% + 重量误差率×30% + 内部品质抽检合格率×30%。
- **建立“红黄牌”制度**：连续2次不合格给黄牌，需要提交书面整改报告；连续3次不合格触发降级或换供应商条款。
- **浮动溢价**：如果连续3个月合格率超过98%，可给予每吨+1%的采购补贴；如果低于95%，则自动扣减尾款。**用合同利益绑定其主观能动性**。

### 风险提示（无法核验的做法）
- **警惕**：供应商口头承诺“每天都能送5吨”但无自有冷链车、无产地代理协议的情况。若供应商是二三级批发商，其稳定性取决于上游，请要求其提供**产地直采合同或报关单/产地证明**。
- **不要**：仅凭一次送样完美就下单，菠萝是生鲜，批次差异极大。

**落地建议**：首次合作先签季度框架协议，首批货物到货后，**邀请第三方品控或安排自己的仓管在卸货现场用钢针探心法抽检内部黑心率**，并录像留证。若上述试单和验厂流程均通过，供应商的稳定性通常有保障。
