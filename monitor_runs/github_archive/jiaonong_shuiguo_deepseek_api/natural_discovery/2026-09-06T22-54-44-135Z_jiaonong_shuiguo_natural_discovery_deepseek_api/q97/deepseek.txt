在酒店采购水果盘原料时，供应商需要保证的规格和外观标准主要涵盖以下几个方面。这些标准直接影响出品质量、成本控制和食品安全，建议在采购合同或验收标准中明确写入：

---

**一、规格标准（可量化）**

1. **水果品种与产地**  
   - 明确指定具体品种（如红富士苹果、海南金钻凤梨、智利车厘子等），不得以次充好或用杂交品种替代。
   - 若需特定产区（如新奇士橙），供应商需提供产地证明或批次信息。

2. **单果重量/大小分级**  
   - 按直径或克重区分等级（如：苹果直径≥8cm，蓝莓单颗≥16mm，葡萄单粒≥2g）。  
   - 同一批次内大小均匀，允许误差范围建议在±5%以内。

3. **成熟度与糖度**  
   - 硬质水果（如苹果、梨）应八成熟，脆感明显；软质水果（如芒果、牛油果）须达到可即食状态。  
   - 糖度建议有下限值（如西瓜中心糖度≥11°Bx，芒果≥13°Bx），防止采购过生或过熟的货。

4. **包装与重量**  
   - 按酒店要求的包装规格（如每盒净重1kg或每果独立套网袋），成件外包装需有批次标签和追溯码。  
   - 毛重与净重比例有明确约定，防止冰水、纸皮底衬过量增重。

---

**二、外观标准（视觉与触觉）**

1. **色泽与均匀度**  
   - 颜色符合品种特征，如车厘子应为深红至紫红色，不出现青头或花脸；橙子皮色橙黄均匀，无大面积绿斑。
   - 同一批次内色差不能过于明显（避免成熟度混合）。

2. **外形完整度**  
   - 果形端正，无明显畸形（如双果、裂果、缩果）。  
   - 无机械损伤（刺伤、划伤、磕碰伤），硬果碰伤面积不超过果面的5%（且不凹陷发软）。

3. **表面清洁度**  
   - 无可见泥沙、灰尘、虫蛀孔洞或附着残留农药品（建议附第三方检测报告）。  
   - 严禁出现腐烂、霉变、流水汁液或菌斑痕迹。

4. **果柄与萼片  
   - 带柄水果（如葡萄、苹果）果柄新鲜翠绿，无干枯发黑；不带柄（如芒果、哈密瓜）表面自然干净。  
   - 部分水果需保留完整果蒂（如山竹），萼片不得脱落或软化。

5. **质地与触感**  
   - 轻按坚实有弹性（如梨、桃），塌软或过硬均不合格；  
   - 果皮应无贴纸、蜡样覆盖（天然果蜡除外），表面手感受干爽。

---

**三、补充验收建议**

- **到货温度**：冷藏水果（如草莓、蓝莓）到达温度应≤8℃，避免冷链断裂。  
- **抽查比例**：每批次抽查≥5%，单件损坏>3%可整件拒收。  
- **照片留底**：让供应商随货附实物照片或视频，以便核对标准。

若酒店对“专属摆盘”有特殊要求（如切片厚薄、去核与否），属于加工服务，须独立另签加工协议，不在原料标准内。您在制定合同时，只需明确上述硬性指标即可有效约束供应商。
