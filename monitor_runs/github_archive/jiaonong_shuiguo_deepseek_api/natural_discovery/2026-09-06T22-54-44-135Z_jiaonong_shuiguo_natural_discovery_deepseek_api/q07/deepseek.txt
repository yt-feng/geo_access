针对水果店做礼盒，核心逻辑是**视觉好看 + 价格分层 + 损耗可控**。

以下是三种搭配方案，分别对应不同客群和市场定位：

### 方案一：经典“平安吉祥”组合（走量款，男女老少通吃）
- **核心组合**：**苹果（红富士）+ 橙子（新奇士/赣南脐橙）**，数量占比约7：3。
- **搭配理由**：红色和橙色对比度高，视觉冲击强，寓意“平平安安、心想事成”。
- **操作建议**：
  - 苹果选**大果、色泽均匀**，橙子选**圆润、带一两片绿叶**更显新鲜。
  - 这是最安全、最不挑人的组合，客户送礼不容易出错，复购率高。
- **定价建议**：定位中低价位，作为引流款。

### 方案二：高档“热带风情”组合（利润款，主打新鲜感）
- **核心组合**：**菠萝（小凤梨更佳）+ 橙子 + 少量香蕉** + 可搭配**杨桃/青色提子**。
- **搭配理由**：菠萝和橙子的金黄色系显高档，且菠萝在北方或非产地城市有“稀罕感”，能卖出溢价。
- **务必避免**：**香蕉不要切开或叠底**，香蕉怕压且易熟，必须**单独放在最上层并用隔层纸垫好**。否则收货时香蕉发黑会引发差评。
- **卖点话术**：全进口/精选海南热带果，果味酸甜开胃，适合送孕妇或经常加班的朋友。
- **定价建议**：定价比方案一高30%-50%，主攻企业采购和节日送礼。

### 方案三：轻食“悦己”小礼盒（年轻人/办公室分享款）
- **核心组合**：**橙子 + 小苹果 + 小菠萝（切好装保鲜盒）**，分量控制在1.5kg以内，用小竹篮或透明PET盒装。
- **搭配理由**：小规格容易放办公桌或直接拎走，水果切好提高客单价。
- **技巧**：装好后，在盒边贴一张手写“今日现切，请尽快食用”的小标签，能减少香蕉/菠萝切面氧化的投诉。

---

### 关键避雷与售卖技巧：

1. **绝对不要混入“易破损”的底部**：
   - 菠萝有尖刺，必须**用泡沫网包裹严实**放在盒子底部两侧。
   - 苹果和橙子不能和菠萝直接接触，否则苹果皮的“呼吸作用”会让它变软快。

2. **要分“糖度组”还是“香气组”卖？**
   - 如果店里本地客户多，主打**苹果+橙子**（想甜就吃橙，不甜就吃苹果）。
   - 如果年轻客户或送礼为主，可以加一小串**香蕉**，但一定要用保鲜膜包住香蕉柄，**防止催熟其他水果**。

3. **展示话术（对顾客说）**：
   - 针对“怕酸”的顾客：“橙子带酸，苹果带甜，正好平衡。”
   - 针对“怕腻”的顾客：“菠萝解腻，饭后来一块特别清爽。”

4. **如果实在卖不完怎么办？**
   - 香蕉熟的太快，尽量**做到“当天早上切装”**，下午5点后如果香蕉有斑点数下降，建议把香蕉撤出礼盒，换成两个小番茄或奇异果，保证礼盒内水果都处于最佳状态。

**最终建议**：先从**方案一**做起，测试3天看动销率。如果走量好，再上方案二赚毛利。**水果礼盒利润高，但最怕“熟过头”的损耗**，所以包装前记得看一眼香蕉和菠萝柄的新鲜度。
