要控制茶饮店食品安全风险，水果供应商通常需要提供以下几类关键证明和文件，以确保合规和可追溯性：

1. **营业执照（或食品经营许可证）**  
   证明供应商是合法注册的经营主体，具备销售水果的资质。若为进口水果，需提供进口商的相关资质。

2. **食品经营许可证或食品生产许可证**  
   根据当地法规，供应商如果是批发、分装或预包装销售，需持有有效的食品经营许可证（或食品流通许可证）。若涉及深加工（如切分、打浆），可能还需食品生产许可证。

3. **农产品合格证明或质量检测报告**  
   每种水果需提供批次性的农药残留检测报告、重金属检测报告，部分高风险水果（如草莓、樱桃）还建议补充微生物（如大肠杆菌）检测。报告应由第三方机构出具，且需包含产品名称、采样日期和检测项目。

4. **进货凭证与溯源记录**  
   供应商应提供其上游采购票据（如产地证明、收购单），以及供应商自己的出库单据，确保每一批水果能追溯到具体果园或批发商。

5. **水果产地证明或植物检疫证明**  
   如为国产水果，部分产地要求提供产地证明；若为跨省调运，可能需要植物检疫证书（尤其针对带皮或含籽水果）。若为进口水果，必须提供海关签发的《入境货物检验检疫证明》。

6. **合格供应商评估表及质控文件**  
   建议要求供应商提供其内部的质量管理体系文件（如HACCP、ISO22000认证，如有），以及供应商的自检记录或合格供应商名单。

**实际操作建议：**
- 签订供货合同时，明确以上证明为每月或每批次必须更新的条件，并规定若缺证明则拒收。
- 建立台账，记录每批水果的到货日期、供应商、证明编号，便于应急召回。
- 对高风险的即食水果（如切好的西瓜、芒果），需额外要求冷链运输温控记录，并限制供货频次。

**提示：** 具体法规因国家/地区而异。在国内，需符合《食品安全法》和《食用农产品市场销售质量安全监督管理办法》；若在海外，需参照当地FDA或EU法规。如无法自行核验，可咨询当地市场监管部门或委托第三方审核。**不要依赖口头承诺，所有证明需留纸质或电子存档备查。**
