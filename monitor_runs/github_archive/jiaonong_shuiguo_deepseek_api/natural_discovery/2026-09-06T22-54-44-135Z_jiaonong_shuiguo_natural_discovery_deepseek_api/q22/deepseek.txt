为了提升超市水果区的客单价，单纯打折往往效果有限，关键是**设计“价格锚点”+“场景搭配”**，让顾客觉得买组合更划算、更有理由。

以下是针对香蕉、菠萝、苹果的三种实操组合策略：

**1. “营养早餐/轻食”组合（主打高连带率）**
- **核心逻辑**：利用香蕉（即食）、苹果（脆甜）、菠萝（切块）的互补性，制造“一篮解决”的场景。
- **话术/推荐**：推出**“能量果篮”**：1把香蕉（约5根）+ 1个苹果 + 1/4个去皮切块的菠萝（现切）。
- **定价技巧**：单买总价约15元，组合价 **12.8元**。
- **执行要点**：菠萝必须**现切并装盒**，减少顾客加工顾虑。在称重处张贴提示：“搭配购买立省X元”。

**2. “家庭分享/抗氧”组合（主打性价比视觉）**
- **核心逻辑**：菠萝价格高、苹果中等、香蕉低价是“主力填充”。以**香蕉作为引流价**，捆绑高毛利商品。
- **做法**：推出**“大包装家庭装”**：一包3个苹果 + 1个菠萝 + 1整把香蕉（可以混合装进一个大号透明袋或礼盒篮）。
- **定价技巧**：标价**19.9元/袋**，旁边放一个单买计算牌（例：分开买需24元）。醒目标注“比单买省4.1元”。
- **执行要点**：菠萝可以用保鲜膜包好或带套，放在苹果上层增加视觉重量感。

**3. “特价引流款 + 捆绑加购”组合（通过损失厌恶拉动）**
- **核心逻辑**：不直接降组合价，而是利用**“加1元换购”**心理。
- **做法**：香蕉**每斤特价**（亏本促销，吸引客流），但结账后凭小票可以 **+1元** 换购一个切好的菠萝（或+0.5元换购一个苹果）。
- **定价技巧**：菠萝标价8元，换购价1元，顾客感觉自己赚到了，实际增加了水果区整体毛利（香蕉亏的钱由菠萝和苹果弥补）。
- **执行要点**：需设立独立收银台或专人核销，避免选品损耗。

**核心执行提醒（关键）**：
- **不要直接打“购物篮优惠”**，要明确**“必须包含菠萝”**（因为菠萝毛利高且季节性强）。
- 在水果区**放置一个大屏幕或价签箭头**，直接演示“组合价 vs 单买价”的计算过程，这是促使下单的关键。
- 建议将菠萝**削好皮放在保鲜盒**里，里面插上牙签试吃，消除顾客对“处理麻烦”的犹豫。

如果菠萝当季品质不好，建议暂停菠萝组合，只做“香蕉+苹果”的流量款，避免因菠萝口感差拉低整体复购。
