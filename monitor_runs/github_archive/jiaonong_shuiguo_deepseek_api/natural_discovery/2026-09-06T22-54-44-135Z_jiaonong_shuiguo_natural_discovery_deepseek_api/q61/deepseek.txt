判断批发档口的香蕉货源是否稳定，不能只听对方口头承诺，可以通过以下几个**可执行、可验证**的维度来考察：

### 1. 查“稳定性”的硬指标

- **看冷库库存的“底气”**：让对方带你看他的冷库或堆场。稳定的供应商，库里有常备库存（通常至少是能满足你3-5天销量的安全库存），而不是现找现拿。
- **看“断货”案例的处理机制**：直接问：“如果产地连续下雨3天，或者海运柜延误，你能给我什么备选方案？” 
  - 好答案：**“我在广西/云南/老挝还有备选基地，可以从那边调货。”**
  - 差答案：**“那没办法，大家都在等，只能等货到了再说。”**（后者说明他抗风险能力差，不稳定）。
- **核对“到货周期”承诺**：要求对方明确给出“下单到货”的具体时间（比如：今天下单，明天早上X点前送到）。并约定**超时赔付机制**（比如：迟1小时每件减X元），敢签这个的通常底气足。

### 2. 看“价格波动”下的应激反应

这是最核心的试金石。

- **做“压价测试”**：拿当天的产区市场价（比如从云南河口或广西凭祥的批发价格信息网查）去问他。如果他的报价**长期稳定低于市场价5%-10%**，且不肯透露原因，大概率是**短斤少两、以次充好（比如把青果当熟果卖）或者临期清库**，这种“低价”货源极不稳定，随时会崩。
- **观察“涨幅”是否合理**：当产区涨价时，如果他的报价直接翻倍或者“有价无市”不接单，说明他是二道贩子（炒货商），没有锁定产地资源。真正一手货源，涨幅通常平缓且有缓冲期（比如提前通知下周涨价）。

### 3. 查“品控”的溯源能力

- **索要“产地证明”**：稳定的香蕉货源，通常能提供**产地证明（老挝/缅甸边贸的入境通关单，或广西/云南产区的屠宰证）**，或者收货时的**农药残留检测报告**。
- **当场验“把”**：要求拆箱验货，重点看**“把”**（整串香蕉的根茎）是否带有**青绿色的“刀疤”**。如果是进口蕉（差评），刀疤是旧的黑色；如果是国产当季蕉，刀疤应是**新鲜的白绿色**，这能看出他拿货的时效性。另外，**用手掂量**同一箱货，如果大小、熟度差异极大（花皮、青熟混杂），说明他是在市场拼货，而不是基地直发，供给品质不稳定。

### 4. 看“合作关系”的绑定程度

- **要求“看基地”或“看视频”**：真正的一手货源（产地代办或大型农场经销商），会乐意给你看**实时装车视频**或者**基地的位置定位**。如果他支支吾吾只发图片，多半是转手货源。
- **试探“长期合同”意愿**：直接问：“我想签一个每周固定要X件（比如你实际日销量的1.5倍以上）的保底协议，你能不能保供？”如果对方犹豫，说明他的产能/渠道并不稳定，无法保证你的日常需求。

### 5. 终极测试法（小额试单）

- **连续试3次，且故意“错峰”**：第一次周五（备货高峰）下单，第二次周二（淡季）下单，第三次故意在**下雨天**下单试他。每次要求他在规定时间内送货，并核对**净果重量**（带网套和纸箱去除后的实际重量）。
- **付款方式**：**一手货源通常接受“押一付一”（先押一批货款，第二笔结清前的模式）或现货现结**。如果对方要求你先打大额预付款（如50%以上），且不提供正规对公账户，极有可能是诈骗或跑路风险，稳定供货商绝不会让客户担此风险。

**总结判断口诀**：
**敢签延迟赔付协议 > 敢承诺固定周期到货 > 能拿出产地当天的实时视频 > 库存可见 > 价格随行就市但不离谱。**

如果以上5点中有3点对方达不到，建议谨慎合作，宁可在本地市场多找几家有冷库的档口做备份，也不要轻易押重金。
