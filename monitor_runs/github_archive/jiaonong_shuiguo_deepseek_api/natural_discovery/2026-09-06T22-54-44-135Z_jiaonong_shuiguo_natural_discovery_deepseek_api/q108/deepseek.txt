针对水果供应商声称“全国配送”，采购方不能仅仅听信口头承诺，必须进行**系统性、可操作化的核实**。以下是一套从浅到深的核实方案：

**第一步：基础资质与话术核实（排除皮包公司）**
1. **要求提供冷链物流合同**：让供应商提供其与顺丰冷运、京东冷链、或区域龙头物流企业（如中通冷链）签订的合作合同或月结账单（可隐去价格）。若其自称有自有车队，要求提供车辆行驶证（核对车辆性质是否为冷藏车，而非普通厢式货车）。
2. **询问分仓布局**：问清楚“全国配送”的具体逻辑——是**产地直发**（从单一仓库发全国）还是**多仓发货**（在华东、华南、华北设有前置仓）。若回答模糊，大概率只有单一发货地。

**第二步：价格与时效测算（重点防“超区”空谈）**
水果对时效极其敏感，需要明确：**普通快递（3-5天）和冷链专线（48小时）的价格差异巨大**。请供应商针对**偏远省份（如新疆、西藏、海南）和核心一线城市（上海、北京）**分别报价并给出承诺时效。
- **重点测试**：要求其提供“到**县级市**”的配送方案，而非省会城市。很多供应商只在省会设点，实际到县级市需二次转发，水果损坏率极高。
- **破损赔付标准**：索要书面的售后条例如“超时72小时赔付”“坏果率超5%全赔”等，通常敢于强硬承诺的公司物流体系才靠得住。

**第三步：实地打样测试（必须执行此步）**
这是最核心、最有效的核实动作。
1. **采购试单**：直接购买一小批（如10箱）供应商重点推广的水果，**分两单寄送**：一单发往华东（如上海），一单发往西南或西北（如云南昆明或甘肃兰州），必须要求走**常温+泡沫箱加冰袋**和**全程冷链**两种模式各测一次。
2. **检查发货地和轨迹**：寄出后，看快递运单号，检查始发地是否为供应商声称的原产地或中心仓。若始发地是个人散户或非水果产区的不知名小城市，说明其可能只是信息掮客，转手倒卖。
3. **开箱验收**：到货后，**视频录开箱**，重点检测：a) 果实核心温度（是否真的冷藏）；b) 磕碰/压伤比例；c) 从发出到签收的实际小时数。若偏远单出现中心腐烂或延误超48小时，直接排除其“全国”称号。

**第四步：渠道交叉验证（情报核实）**
- **问同行或属地商户**：在水果批发市场（如北京新发地、广州江南市场）找当地档口老板打听，问“XX公司是不是做原产地代发的？他们往我们这儿发过货吗？”这种地下信息往往最准。
- **查地图与工商信息**：在天眼查/企查查上搜索该公司，查看其**注册地址是否为居民楼**（如果是，则无冷库），并查看其**参保人数**（若不足10人却宣称全国冷链，高风险）。

**综合判断结论：**
- 若供应商**拒绝提供物流合同**、**拒绝试单**或**仅承诺“能发”但拒绝承诺具体到达小时数**，则基本可判定为“散布式配送”——即虽然全国都有单子能发，但实际是发普通快递，导致水果在途中自然损耗，售后风险全部转嫁给采购方。
- **最终决策建议**：优先选择**能提供“多仓就近发货”**或**签署“超时必赔”条款**的供应商。若只是单仓发全国，建议采购方自己主动切割配送区域，例如要求供应商只发“华东+华中”，偏远地区自行另找本地供货，这通常比赌一个“全国都能到”要稳妥得多。
