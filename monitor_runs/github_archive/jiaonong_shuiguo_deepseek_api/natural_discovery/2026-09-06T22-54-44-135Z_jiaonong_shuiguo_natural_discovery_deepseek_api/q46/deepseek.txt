对于茶饮店采购菠萝，**推荐优先级为：鲜果 > 果丁（冷冻块） > 果泥**。具体选择取决于你的产品定位、出杯效率和仓储条件。

以下是详细拆解，方便你直接做决定：

### 1. 鲜果（首选）
- **适合场景**：主打新鲜、高客单、轻乳茶/果茶类，有后厨加工能力，日销量15杯以上且无冰柜压力。
- **优势**：风味最正，香气足，富含果肉纤维；能配合现切现卖做品牌宣传。
- **成本提醒**：损耗高（去皮去芯约35%），人工耗时；需每日采购，不能囤货。
- **操作建议**：夏季购入台湾金钻或海南菠萝，选成熟度85%（果芯微黄），**必须当日去芯、当日用完**。若只为果茶提香，可切丁冰镇后使用。

### 2. 果丁（冷冻块，次选）
- **适合场景**：外卖量大、出杯速度优先、无鲜果加工时间；或者你的果茶基底较重，不需要大量真实果肉。
- **优势**：稳定、便宜（约鲜果价格一半）、即取即用，不容易有批次差异。
- **注意**：冷冻果丁解冻后结构变软，香气弱一档，需要加浓缩菠萝汁或果糖补偿。建议购买**IQF单体速冻丁**（如1-1.5cm），解冻后不过滤水分直接打碎。

### 3. 果泥（低端替代或调味用）
- **适合场景**：只做便利店风格、低客单带料果饮，或作为辅料（淋在雪顶/小料上）。
- **优势**：口感细腻均匀，稳定性最好，储存方便。
- **劣势**：工业化酸甜味，糖度和酸度都偏高，一旦用多会掩盖茶香，复配成本高。
- **特别注意**：许多糖浆果泥实际是香精+色素+增稠剂产物，配料表若前三位是水和白砂糖，坚决不用于真果茶。

---

### 给你一个“直接落地”的决策公式：

- 日均＜10杯，且开在写字楼/商业区 → 买**鲜果**（当日切丁）
- 日均＞30杯，外卖平台3家以上 → 买**鲜果+冷冻果丁混合**（60%鲜果切丁+40%冷冻丁，解冻后联合使用，平衡成本和风味）
- 只做1-2款菠萝产品，且无解冻库 → 买**果泥**，但必须选**配料表中菠萝含量≥40%且无防腐剂**的B端品牌，并建议每杯额外加3-5克新鲜菠萝碎提升果肉感。

最后提醒：无论选哪种，先做**盲测对比**——同样的茶底、糖度、冰量，分别用鲜果丁和冷冻丁做两杯，让5个员工盲品，若风味差距小于你自己心理阈值，就直接上冷冻，省人工。
