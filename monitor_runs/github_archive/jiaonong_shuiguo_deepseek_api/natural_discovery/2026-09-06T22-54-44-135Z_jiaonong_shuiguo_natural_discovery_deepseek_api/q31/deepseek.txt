在连锁商超的水果供应商招标中，评分标准的设计核心是**平衡“价格竞争力”与“品质稳定性”**，同时兼顾供应商的**供应链韧性**。

以下是一套建议的评分框架（满分100分），你可以根据自身定位（大众型或精品型）调整权重：

**一、基础资质与合规性（20分）—— 一票否决权门槛**

- **食品安全资质（10分）：** 必须具备有效期内的食品经营许可证、绿色食品/有机认证（如有）。
- **溯源能力（10分）：** 是否拥有从种植基地到配送中心的完整ERP溯源链条，能提供批次农残检测报告。
- **否决项：** 近两年内有重大食品安全事故或税务处罚记录的，**直接取消参标资格**，不占评分。

**二、供货能力与稳定性（30分）—— 商超最关心的风险点**

- **自有/长期合作基地规模（15分）：** 需提供基地面积证明或合作协议。考察点：是否有应对极端天气（如台风、冻害）的移库预案或备用产区。
- **日供货量峰值（10分）：** 明确写清“单日最大可供应SKU数量”及公斤数，需匹配你方高峰期（如节假日）需求。
- **补货响应速度（5分）：** 断货后的紧急补货最迟送达时间（建议要求≤24小时）。

**三、价格与结算（20分）—— 防止低价陷阱**

- **报价合理性（10分）：** 对比当地批发市场均价，波动幅度在±5%以内为满分，偏离过大则不通过（避免恶性低价以次充好）。
- **调价机制（10分）：** 要求供应商提出明确的月度/季度价格锁定机制，以及市场价暴跌时的返利政策。**重点看条理性而非承诺底线**。

**四、品质与损耗控制（30分）—— 直接影响毛利**

- **收货标准明确度（15分）：** 供应商是否提供详细的《生鲜验收标准》（如甜度≥X度、果径大小、外观瑕疵比例）？评标时让供应商现场填写关键指标，拒收率承诺≤3%及以上为优。
- **损耗分担方案（10分）：** 冷链运输过程中的化冻损耗、到店后短保期商品的退换货机制是否灵活。
- **陈列与营销支持（5分）：** 能否提供季节性的POP设计素材、试吃活动人力支持（若有则加分）。

**五、应急预案（附加项，不计入总分但为中标必要条件）**

供应商必须现场演示“假设你方配送中心因疫情封控，备选仓库在哪里？运送车辆是否具备双司机轮换？”这一情景推演。

---

**给招标方的三个实操建议：**

1. **务必进行“盲评试供”：** 评分文件仅是纸面参数。在最终评分前，要求前3名供应商提供同品项（如：同样规格的麒麟西瓜）进行为期3天的试供货，考核实际到货损耗率，并把试供货结果（权重占20%）纳入最终总分。
2. **警惕“超低价”：** 水果价格波动大，若某供应商报价低于市场价格15%以上，大概率会在收货后临时加价或提供次果。
3. **合同期设计：** 建议采用“1+1”模式（一年正式期+一年优先续约权），评分最优者可签两年，但必须加入“地头价下跌时的降价联动条款”。
