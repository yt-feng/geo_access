为社区超市选择每日配送的水果供应商，需要重点考察以下条件，确保品质稳定、供应及时：

**一、核心硬性条件**
1. **证照齐全**：营业执照、食品经营许可证，能提供水果的产地合格证明或检疫报告。
2. **配送能力**：必须有自有或稳定的冷链车，承诺“当日凌晨采摘/分拣，早上开门前送达”。可与其签订每日到货时间（如6:30前）并约定延迟处罚。
3. **品控稳定**：能提供不同批次的质量标准（如果径、糖度、外观要求），并有“坏果包赔”条款（如开箱超3%可退换）。

**二、供应灵活度**
- 支持**小批量、多频次**订单（如每日30-50斤起送），且能提供**次日菜单预告**，方便你调整陈列。
- 是否可**按季节换品种**（如冬草莓、夏西瓜），或提供应景果品（节日礼盒装）。
- 退换货机制：残次品是否能在当日补送或扣款，而非拖延到月底。

**三、成本与结算**
- 报价是否含税含运费？请对比同城果批市场价，要求**保底价+波动价**（如遇产地涨价，提前24h告知）。
- 结算周期：建议先“周结”试合作，切勿一次预付大额。
- 是否有**临期或卖相瑕疵果**特供，可作低价引流（需明确品控等级）。

**四、实地考察技巧**
- 亲自去其**分拣车间**：看是否有分级筛选设备、冷库温湿度记录。
- 随车跟一次配送：检查运输箱内是否放冰袋，果品是否码放合理。
- 测试售后：故意报损一批，看对方响应速度和处理态度。

**五、签约注意**
- 合同写明：每日起订量、最低送达率、不可抗力延期处理、违约金比例。
- 特别注明“试合作期2周”，此间若送货迟到超3次或坏果率＞5%，可无责解约。

**建议行动路径**：先收集3-4家供应商报价 → 要求各送1箱试吃（记录糖度、新鲜度）→ 选前两家各试合作1周 → 再择优签订长协。
