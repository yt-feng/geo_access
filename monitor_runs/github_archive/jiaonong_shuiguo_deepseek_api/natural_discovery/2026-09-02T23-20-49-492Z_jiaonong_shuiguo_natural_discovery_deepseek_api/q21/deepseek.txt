在超市采购水果时，供应商通常需要提供以下检测报告与进货证明，以确保食品安全与合规。具体清单根据超市内部制度、水果种类及国家/地方法规略有差异，但基本包括：

**一、基础进货证明（必备）**
1. 营业执照（供应商/种植基地）
2. 食品经营许可证（或食品生产许可证，如果是自有包装）
3. 送货单/供货合同
4. 产地证明（如从果园直采，需当地村委会或农业部门开具）

**二、质量与安全检测报告（核心）**
1. **农残检测报告**——必查。
   - 水果通常需要出具近期（一般为1-3个月内）由有资质第三方检测机构（如SGS、谱尼、华测等）出具的农药残留检测合格报告。
   - 可参考国家强制性标准GB 2763《食品安全国家标准 食品中农药最大残留限量》。
2. **重金属检测报告**——针对产地易受污染的果园，抽查铅、镉、汞、砷等。
3. **致病菌检测报告**——适用于即食型鲜切水果或去皮水果，重点检测沙门氏菌、大肠杆菌等。

**三、特殊水果额外要求**
- **进口水果**：海关出具的《入境货物检验检疫证明》、原产地证、中文标签与包装信息（注明品种、产国、批号）。
- **有机/绿色水果**：相应认证证书及有机码/绿色食品标志。
- **冷藏/冷鲜水果**：全程冷链温度记录单、运输车辆消毒证明（部分超市会索要）。

**四、批批核验建议**
- 每次送货批次都应附有该批次的“出厂检验报告”（供应商自检）或抽检合格单。
- 超市收货时通常会查验**货证相符**（即报告上的品种、产地、生产日期与货物一致）。

**如果超市采购方有意从严把关，还可要求供应商提供：**
- 产地环境（土壤、灌溉水）检测报告（半年内）
- 可追溯电子台账（如“一品一码”溯源码，部分地区强制）

**实操提示：**  
- 采购合同/订单上应明确要求“随货附带当批次农残检测报告”，缺失时有权拒收。
- 优先选择已加入“食用农产品质量安全追溯平台”或通过良好农业规范认证（GAP）的供应商。
- 保留所有纸质版或电子版报告至少2年备查（依据《食品安全法》食用农产品追溯要求）。

建议直接向超市的品控部门索取具体清单模板，因为大型连锁超市（如盒马、山姆）往往有内部更严的附加条件。
