针对家庭（尤其是带老人和小孩的）水果礼盒，关键在于**营养搭配、易储存、不浪费、口感均衡**。你提到的这四种水果都很常见，但组合方式直接影响食用体验。

结合团购场景，给你两个最稳妥、最实用的组合方案，**建议直接作为主推套餐**：

### 方案一：黄金“每日鲜”家庭装（最推荐，主打营养和刚需）
**组合：苹果（2-3斤） + 橙子（1.5-2斤） + 香蕉（1把）**
- **为什么去掉菠萝**：菠萝在家庭礼盒中非常**不友好**。它需要削皮、泡盐水，含菠萝蛋白酶，老人小孩吃完容易“扎嘴”。且一旦切开无法久存，家庭吃不完容易浪费。
- **搭配逻辑**：
    - **苹果**：耐储存，早中晚都能吃，几乎零过敏源。
    - **橙子**：补充维C，老人小孩常吃好处多，且橙子能放得住。
    - **香蕉**：**软糯即食**，不用洗不用切，是给老人、小孩当加餐的最佳选择，还能缓解便秘。
- **包装建议**：用分层礼盒，香蕉放上面（避免压坏），苹果橙子放下层。

### 方案二：缤纷“解腻”全家福（适合送礼或聚餐）
**组合：苹果（2斤） + 橙子（2斤） + 菠萝（1个，约1.5-2斤）**
- **为什么去掉香蕉**：香蕉**非常怕压**，和带尖刺的菠萝、偏硬的苹果橙子放一起运输，极易出现黑斑淤伤，售后风险大；且香蕉成熟过快，会影响礼盒“新鲜”的观感。
- **搭配逻辑**：苹果橙子负责“垫底”和日常消耗，菠萝作为“颜值担当”和饭后解腻水果。适合周末家庭聚餐时，现切一个菠萝当果盘。
- **注意**：菠萝必须**带皮整颗**放入，并附赠一张“食用小贴士”卡片，告知客户如何削皮及泡盐水。

---

### 针对团购的3条核心建议（帮你提高复购率）：

1.  **避开“熟果混放”坑**：**香蕉千万不要和苹果、橙子放同一个密封塑料袋里**（苹果、橙子会释放乙烯催熟香蕉，导致香蕉一夜变黑）。发货时要用防震棉或牛皮纸袋将香蕉单独包裹隔离。
2.  **提供“切配增值”**：若做**次日达**或**同城闪送**，可推出一个“加钱代切”选项，把菠萝切好并送盐水，这是家庭客户（尤其是宝妈）最愿意付费的痛点。
3.  **重量阶梯设计**：不要只做一个规格。
    - 建议推 **5-6斤（小家庭2-3人）主推方案一**。
    - 推 **8-9斤（大家庭5人+）主推苹果+橙子+菠萝+少量香蕉**。

**总结**：最稳妥的常卖组合是 **“苹果+橙子+香蕉”**，因为它是真正的“零门槛水果”，不会给客户添麻烦。如需有仪式感，再单独做 **“苹果+橙子+菠萝”** 的礼盒装。
