遇到水果到货不合格，处理关键不在于“吵架”，而在于**合同条款的预设**和**供应链的弹性**。为了不影响营业，建议你按以下三个层次来处理，优先级从“救急”到“长期”：

**第一层（救急：48小时内）——锁定“替代品”和“差额补货”**

不要纠结于“退货”再“重新采购”的思维，因为新货从产地到门店通常需要2-3天，营业会空窗。你应该立刻做两件事：

1.  **叫停使用，拍照留证**：当场拒收，并拍摄视频，重点拍箱体、果肉切面、以及批次码。
2.  **立刻启动“就近补货”**：用口头形式（或微信文字）通知供应商：**“这批货我先拒收，请你方在XX小时（比如24小时内）内，从最近的分仓或自有冷库，给我发来同等规格的合格果品。”**
    -   *注意*：不要让对方“重新去产地摘”，那来不及。要求对方用**其现有库存**来补足你的缺口。

**第二层（营业保护）——按“损耗率”而非“斤数”补差**

如果你时间紧迫，货已经卸了，且是部分不合格（如部分发霉、磕碰严重）：

-   不要按“整箱换”来谈，因为你急用。
-   建议约定：**“我方挑出不合格的X公斤，损失按X公斤的**1.5倍**（或按合同约定的溢价）折抵货款，同时你必须立刻短缺我X公斤的**同品类一级果**用于今日制茶。”**
-   如果对方无法做到“秒发”同规格，可接受**“降级使用”**（比如把做鲜果茶的A级果，降级为做果酱的B级果），前提是让利幅度必须让你在菜单上的售价不受影响。

**第三层（根治：合同与SOP）——把“补货时效”写进合同条款**

要长期杜绝影响营业，你需要将以下承诺**白纸黑字**化，而不只是口头协议：

1.  **补货时效罚则**：明确约定“验收不合格货品，供应商需在**24小时内**完成同量补货。若超时，每延误1小时，按该批货值的1%支付违约金，且我方有权临时外采，差价由对方承担。”
2.  **“自然损耗”与“严重不合格”的界定**：水果行业不能按国标食品企业来卡，需写明“**单果碰伤面积超过3%**”或“**发霉、酸败**”属于不合格，**剔除后不影响营业**；而对于“整车腐烂率超5%”这类大问题，必须触发补货机制。

**如果你不想签复杂合同，最实用的土办法是：**
**每次到货，抽出几箱切开验货后，在回执单上写一句——“验收合格，但保留抽查权利；如上机/制茶发现异常，供方需于当日结算前，按同价补发次日同量果品，否则货款顺延支付。”**

**最后提醒一个关键点：** 直接影响营业的往往是“清洗切配环节”。建议你实验期内，把**高损耗的鲜果（如草莓、杨梅）**设置为“少备货、可售罄、次日补”模式，不要囤核心单品。水果不是工业品，**小步快跑、每天补**，比大批量囤货更稳。
