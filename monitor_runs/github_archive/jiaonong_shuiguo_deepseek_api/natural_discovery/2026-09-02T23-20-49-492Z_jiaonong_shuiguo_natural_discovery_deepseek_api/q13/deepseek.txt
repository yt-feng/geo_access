你需要供应商具备“缺货及时补、烂果主动换、价格能锁定”这三类服务能力，否则团购很难做长久。

结合小区团购的特殊场景，重点看以下五个方面：

**1. 次日达/半日达的配送能力**
这是最基本的要求。团购订单通常集中在晚上截单（比如晚上8点），你第二天就要拿到货来分发。所以供应商最好能支持：
- **早班配送**：每天上午（最好9点前）送到你的小区自提点。
- **起送量低**：你初期量不一定大，要问清楚最低起送金额，比如200元还是500元分界。

**2. 挑货损耗包赔（坏果/烂品率承诺）**
小区团购口碑很重要，一旦客户拿到烂果，影响是连锁反应。所以必须谈好：
- **赔付标准**：明确“坏果包赔”或“损耗率在5%以内”，超出部分由供应商承担。
- **无忧售后**：客户投诉烂果，你只需拍照给供应商，对方要能直接退款或补货，不要让你自己垫钱。

**3. 灵活的小包装与拼货能力**
你面向的是家庭客户，不是餐饮店。所以要确认对方能提供：
- **家庭装规格**：比如苹果3斤装、蔬菜2份组合，而不是20斤起批的大筐。
- **组合拼箱**：你下单一箱货，能不能让供应商帮你把不同的水果拼在一个箱子里（比如半箱芒果+半箱火龙果），这会大幅降低你的进货风险。

**4. 价格保护（价格日清或阶段性锁价）**
团购需要价格稳定，别今天报了价明天就涨。供应商需要给出：
- **当日报价单**：每天上午或前一天傍晚给你最新的果价表，方便你朋友圈发布。
- **周期锁价**：对于香蕉、苹果这类波动小的，要求按本周一个价结算；对于应季高波动品（如车厘子），要约定提前锁价或按到货价+固定利润给你。

**5. 分拣与错发承诺**
小区团购最烦的是货不齐或缺货。供应商要承诺：
- **分拣准确**：下单10种，缺1种要在发货前通知你，而不是到货后才说。
- **标准化分装**：每一份的重量误差在合理范围（比如±0.2斤），避免你每单还要复称引发纠纷。

**给你的具体询问话术参考：**
> “我们每天大概30-60单，需要您早上9点前送过来。坏果怎么赔付？最低起送多少？如果这周订货，下周价格能锁吗？”

**最后提醒**：不要只依赖一家供应商。建议先选2-3家试用两周，重点看**售后响应速度**和**早上到货的准时率**——这两点不合格，其他服务再好也容易让你受累。
