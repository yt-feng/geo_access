茶饮店在采购水果时，为了控制食品安全风险，应要求水果供应商提供以下关键证明和文件（按重要性排序，建议逐一核查并留存复印件/电子版备查）：

1. **营业执照（副本）**  
   - 证明供应商是合法经营主体，经营范围应包含水果销售或农产品批发。

2. **食品经营许可证**（若销售食用农产品，通常需此证）  
   - 部分区域对初级农产品（如未加工水果）有豁免，但务必确认其经营合规。

3. **产品检验合格证明 / 出厂检验报告**  
   - 针对每批次水果，需提供农残、重金属（如铅、镉）、微生物等项目的检测报告（需有CMA或CNAS认证机构出具）。  
   - **特别注意**：水果易有农药残留超标风险，报告应重点涵盖《食品安全国家标准 食品中农药最大残留限量》（GB 2763）中涉及的项目。

4. **食用农产品承诺达标合格证**（重点！）  
   - 这是国家推行的重要凭证，供应商须对水果质量安全作出承诺，标注产地、生产者信息，体现自检合格。

5. **供货凭证**（如送货单、销售清单）  
   - 应包含供应商名称、产品名称、规格、数量、生产日期/采摘日期、保质期等信息，便于追溯。

6. **同批次进口水果的相关证明**（若为进口）  
   - 海关签发的《入境货物检验检疫证明》，以及中文标签（需符合预包装食品标签规定）。

7. **供应商的运输与储存资质/说明**  
   - 需确认其具备冷链运输（若为首要控制条件）、温控记录的能力，可要求提供运输车辆消毒或温度记录截图。

---

**实操建议（重要）：**

- **索证应“随货同行”**：每批进货必须有对应的检测报告和合格证明，避免过期或笼统证明。
- **建立进货查验制度**：茶饮店需自行存档以上文件，并记录进货日期、批次、数量。
- **额外自查**：若水果直接入口（如制作鲜榨果汁），建议店内自行做简单农残快检（试纸）或要求供应商每季度提供第三方检测报告。

最后提醒：**以上并非全部**。若供应商生产水果干、果酱等再加工品，还需额外的生产许可证等。建议与当地市场监管部门或食品安全员确认当地具体要求。核心原则是：**每个批次必须有可追溯来源及质量合格的凭证**。
