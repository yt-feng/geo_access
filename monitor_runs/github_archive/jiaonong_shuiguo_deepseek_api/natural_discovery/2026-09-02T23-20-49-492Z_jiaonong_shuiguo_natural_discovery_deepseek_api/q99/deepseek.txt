采购批量水果供应商时，核心是**质量稳定、损耗可控、履约及时**。以下是可操作的选择和评估步骤：

**一、明确自身需求（先算清账）**
- 人数与频率：每周几次？每次多少份？提前确定大致重量（如每人半斤到一斤）。
- 水果种类：避免单一易坏品种（如草莓、杨梅），优先选耐运输的（苹果、橙、香蕉、圣女果、梨等）。
- 配送要求：需要整箱还是切好装盒？是否需要清洗、分类？送餐时间是否固定？

**二、供应商渠道来源**
- 本地水果批发市场（批发商）：价格最低、可现场看货，适合每批量大、有自提能力的公司。
- 区域生鲜配送商 / 果品公司：送货上门、售后较好，适合中小批量。
- 大型商超供应商或线上企业采购平台（如美菜、快驴、京东企业购）：标准化高，但价格略贵、起送门槛可能低。
- 社区团购 / 果园直采：当季、性价比高，但配送到市区不稳定。

**三、硬性筛选标准（用表格打分）**
1. **看资质**：营业执照、食品经营许可证（必备）、检验检疫报告。要求对方提供近期农残检测批次证明。
2. **跑基地/门店验厂**：看库存周转（冷库是否干净、有无破损积压、先进先出否）。
3. **要试送**：连续下单2次，记录：到货时间误差（<30分钟）、果损伤率（每箱不超过3%）、成熟度是否一致。
4. **损耗赔付条款**：合同必须写明——到货后如有坏果，需在24小时内无理由补货或按比例退款。
5. **价格透明度**：不要只比单斤价——要求报“含税含运费”到货价；并要求提供至少最近一个月的批发均价作为参考，警惕过低价（可能以次充好或缺斤短两）。

**四、关于配送履约测试（一周内完成）**
- 要求周二下午配，看是否准时；要求送到3楼并开箱验货，是否配合。
- 随机抽查2箱苹果，看大小是否均匀（直径误差超过1cm建议淘汰）。
- 检查配送车辆是否有冷链或遮阳恒温设备（夏天尤其关键）。

**五、备选方案建议**
- 方案A：签2家供应商（一家主、一家备用），避免断供风险。
- 方案B：签“批发价浮动”条款，与市场当日批发价挂钩，防止供应商随意调价。

**如果你们只是偶尔几十人规模**，不建议专门联系一级批发商，优先考虑本地连锁水果店的企业团购部门，他们响应快、有现成礼盒包装。

最后一步：先签**短期（1个月）**合同考察，再谈长期折扣。不要一次性预付大额货款。
