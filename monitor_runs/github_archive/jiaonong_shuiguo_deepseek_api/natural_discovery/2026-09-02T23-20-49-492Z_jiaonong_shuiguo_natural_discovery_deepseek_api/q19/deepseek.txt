在超市销售菠萝时，**最核心的关注点是“外观”和“甜度”**，其次是切果损耗，大小作为辅助参考。具体优先级建议如下：

1. **外观（首选，决定顾客第一印象和损耗率）**  
   - 检查表皮：颜色金黄（非全青），果眼饱满，无霉斑、软烂、碰伤。  
   - 按压果身：微微有弹性（太硬未熟，太软过熟易坏）  
   - 检查果柄：新鲜湿润不干枯，这会直接减少切果后的报废率。

2. **甜度（决定复购和口碑）**  
   - 闻香气：成熟菠萝底部香气浓郁，若无香味则甜度不足。  
   - 测试糖度：可用糖度计抽样，通常可溶性固形物≥12%为佳（无需对每个顾客展示，但进货时把关）。  
   - 若现场销售，可提供“试吃块”，切小块让客人直接验证——这也能提前发现内部坏果。

3. **切果损耗（影响毛利，应重点核算）**  
   - 不是通过外观直接判断，而是进货时计算：  
     预估可售果肉率：正常整果切块损耗率约35%-40%（皮、核、黑心果眼）。若发现当日切果后黑心、空心超过预估值，立即对同批菠萝停售，改用整果打折处理。  
   - 管理建议：在收银台旁设“切果损耗登记表”，每天记录实际报废量，防止进货过量或储存不当。

4. **大小（作为辅助，不单独作为标准）**  
   - 中大型果（约1.2-1.5kg）更适合切盒售卖，避免小块装残次。  
   - 如果走“整果论个”渠道，外观大于大小；如果走“切块计重”渠道，肉率显得更重要。

**最终执行建议**：  
- 进货环节：按“外观不合格率<10%”作为验收底线。  
- 上架前：抽查2-3个剖开看内部状态（黑心、褐变）。  
- 促销时：优先推“甜度高＋果型匀称”的那批货，但把轻微瑕疵果做“当鲜切”处理，避免整果被挑剔后浪费。  

一句话总结：**先看外观保证不浪费，再尝甜度保住口碑，切果损耗按每日记录来动态调整进货量。**
