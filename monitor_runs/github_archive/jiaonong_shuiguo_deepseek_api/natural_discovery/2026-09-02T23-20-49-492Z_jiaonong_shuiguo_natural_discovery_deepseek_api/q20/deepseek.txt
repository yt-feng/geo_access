为社区超市挑选每日配送的水果供应商，建议重点考察以下几个可执行的条件，并附上具体筛选建议：

**1. 产地与供应链稳定性（最关键）**
- **产地直采能力**：优先选有固定合作果园或基地的供应商，可减少中间环节和价格波动。
- **库存缓冲机制**：问清楚对方是否备有冷库，能否应对节假日或极端天气的加量需求（例如春节、暴雨天）。

**2. 每日配送的执行细节**
- **到货时间**：明确要求“每日早晨几点前送达”，并让对方书面承诺迟到的补货或赔偿规则（如晚点1小时减2%货款）。
- **最小起送量**：确认是否支持“小批量、高频次”配送（如每日两三箱），很多供应商嫌量少不愿接。
- **车辆与保鲜条件**：要求必须是冷藏车（非普通货车），中途温控是否记录可查。

**3. 品质验收标准**
- **每日品质波动**：要求供应商提供“坏果率承诺”（如抽检损耗低于5%），并写明“当日到货腐烂果当场换新”的条款。
- **包装方式**：散装筐装易压坏，要求用带孔纸箱或分格周转箱减震。

**4. 价格结构与透明度**
- **每日报价**：是否能提前一天给第二天的报价单？是否随行就市但不坐地起价（要求价格调整需提前24小时书面通知）。
- **账期**：新供应商一般要求现结或2-3天短账期，大超市结款周期长，但对社区店来说，短账期可换取对方稳定供货。

**5. 应急与售后**
- **临时补货**：下单选错或临时缺货时，是否支持当日12点前免费补一次货？
- **退换机制**：当季水果（如荔枝）易变质，是否接受“次日反馈损坏果拍照退款”而不是只退下批货款。

**6. 资质与合同关键点**
- **证件**：必须提供营业执照、食品经营许可证，散装水果另需产地合格证明（如农残抽检报告）。
- **合同附加**：写明“每日配送缺货，有权按缺货金额的10%索赔”，甚至要求押一批尾款（如月结款的10%作为履约保证金）。

**建议行动方案**
第一周先按**小批量试送**（比如每天只送三五箱），中途突然改单一次（比如提前一天告知要加量），测试对方的响应速度和应急能力。同时同步在两三家候选供应商间切换，对比一周的坏果率和迟到率，之后再做长期合同绑定。

**特别提示**：不要只看对方报价最低。重点问一句“如果同一天你的果园摘了坏果，你选择让我优先拿走，还是优先给隔壁大超市？”——凡是想长期做社区生意的，都会愿意先保障你的翻牌率。
