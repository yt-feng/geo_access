判断连锁超市的香蕉供应商能否全年稳定供货，核心要看三点：**货源覆盖能力、供应链的韧性和商业合作机制**。以下是具体判断维度和建议操作步骤：

**1. 货源与产区覆盖（核心前提）**
- **反季产区布局**：香蕉是全球性水果，供应商是否拥有或合作南美（厄瓜多尔）、东南亚（菲律宾、越南）、以及国内海南、广西、云南等不同纬度产区。如果同一时段其供应源单一，雨季、台风季或产区病虫害时极易断供。
- **冷库与催熟库存**：询问其是否有超出日常需求的备货库存（如旺季可保存20-30天），或是否有应急调货渠道（如从其他大区市场紧急调配）。
- **产区合同**：要求提供与主要种植基地的农超对接合同或长期采购协议复印件，不只看口头承诺。

**2. 物流与品控闭环**
- **全程冷链能力**：香蕉采收后需经过田头预冷—冷柜运输—催熟房处理。让供应商出示其物流在途监控记录，并实地查看其催熟设备是否充足、技术是否成熟（能控制乙烯浓度和时间段）。
- **验收索赔标准**：确认合同中是否写明“到货损耗率”“烂果率”赔偿条款，以及断货时的违约赔偿比例。有实力的供应商通常敢签高额违约条款。
- **留样与批次记录**：查看其近六个月的供货批次记录，能追溯到每一批从哪个农场、什么日期采收、什么日期到店，有系统的才靠谱。

**3. 价格联盟与替代机制**
- **产区价格波动预案**：全年中香蕉价格波动大（如寒潮后暴涨），询问其在涨价期如何保证不减少供货量，是否愿意锁定一个基准价+浮动价机制。
- **B计划产品**：如果该供应商全年只有单一香蕉品类，风险偏高。最好要求其同时供应其他叶菜或热带水果，或证明其同时对接两种以上香蕉品种（如国产米蕉+进口大蕉），遇突发情况可切换。

**操作建议（落地动作）**：
- 进行**试运行测试**：先签订3个月、每周2次的供货小单，观察其在台风季、节假日前（如春节前一周）的反应速度和补货能力。
- 实地验厂：重点检查其**冷库温度记录表**和**催熟房日排产表**，如果这两类文件平时没有详细记录的，说明管理粗放。
- 索要保险单：要求提供物流/仓储的第三方财产险保单，证明一旦货损至少有钱赔。

**警惕信号**：
- 拒绝提供产地证明或回避实地考察。
- 报价显著低于市场均价15%以上（可能掺次或假报产地）。
- 合同中对“不可抗力”条款描述过于宽泛，把台风、涨价都算在免责里。

最后提醒：没有绝对“全年不断”的供应商。最稳妥方案是**重点培育一家主供应商（占比70%），同时与另一家小供应商达成应急备份协议**，让两家的产区能恰好错开收获期。
