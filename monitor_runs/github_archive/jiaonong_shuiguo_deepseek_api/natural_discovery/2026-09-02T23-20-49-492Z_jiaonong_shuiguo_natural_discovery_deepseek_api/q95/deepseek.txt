选择学校食堂水果供应商，核心原则是：**安全 > 品质 > 价格 > 服务**，切勿只图便宜。

以下是挑选供应商的实操建议和判断标准：

### 一、先定“硬门槛”（资质筛查）
拿到供应商名单后，先做减法，排除不符合以下条件的：
1. **资质齐全**：营业执照、食品经营许可证（必须包含水果销售）、法人身份证。
2. **供应基地/冷链**：如果有自有或长期合作的果园、冷藏库（能提供冷链运输车），优先考虑；如果是“二道贩子”（无仓库、不负责运输），直接排除。
3. **可溯源**：能提供每批次水果的产地证明（如新疆阿克苏苹果、陕西红富士）和进货凭证。

### 二、现场考察（比价格重要得多）
至少选2家候选供应商，实地看他们的仓库或档口：
- **看环境**：是否干净、通风、有防虫防鼠措施；水果是否按品种分架摆放。
- **看存放**：香蕉未成熟时应挂放，已熟的放冷库；苹果不能与香蕉混放（乙烯催熟易烂）。
- **看损耗**：允许有轻微瑕疵果（如碰伤），但拒绝选有明显腐烂、虫眼的批量货。
- **问其渠道**：问他苹果从哪里进？香蕉是几成熟采收？如果答不上来细节，说明是倒手货，风险高。

### 三、核心品控要点（不同水果标准不同）
签订合同时，要明确每个品种的具体标准：
- **香蕉**：要求“七成熟”青皮果到货（避免催熟剂过度使用），到校后自然熟；拒绝全黄或出现黑斑的。
- **苹果**：要求带袋或套袋果（表面光洁），无霉心（切开检查），酸甜比例适中。
- **橙子**：要求当季鲜果，表皮光滑无凹陷，切开试吃酸甜度，避免用“甜味剂浸泡”的。

### 四、合同与结算细节（防坑必备）
1. **索证留档**：每次送货需附当日“质检报告”（农残检测），食堂留底。
2. **明确退换货**：写上“到货后24小时内，出现烂果、冻伤、规格不符，供应商必须无条件换货或退款”。
3. **账期约定**：初期建议短账期（如月结），避免预付款。
4. **加一条补充**：如果连续3次出现质量问题，学校有权单方面解除合同。

### 五、试供期（强烈建议）
不要直接签一年合同。先签 **2-4周试供期**：
- 这段时间观察水果的新鲜度（苹果是否脆、橙子是否多汁）、损耗率（掉皮/烂果比例）、送货准时率。
- 试供期满意再转正式合同，这能筛掉大量“低价劣质供应商”。

### 六、一个额外建议
如果学校在县城/乡镇，本地菜市场大型果商往往比跨省供应商更灵活。可要求他们提供“产地直采证明”，并承诺“价格随行就市但每周报价一次”，可以更好地控制成本。

**最后提醒**：签订合同时，务必写明“如因供应商提供的水果引发食品安全事故，一切责任由供应商承担，并有权向监管部门举报”。建议食堂负责人保留样品抽检的权利。
