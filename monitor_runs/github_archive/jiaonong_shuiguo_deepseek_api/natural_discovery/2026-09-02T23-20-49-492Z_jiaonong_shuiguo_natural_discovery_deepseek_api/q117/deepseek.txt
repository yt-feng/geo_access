对于水果供应商推荐的新品，采购方“先试卖多稳”并没有固定数字，核心原则是：**“少量、多样、测控、快调”**。

结合水果损耗快、保质期短的特点，建议从以下三个维度来设定试卖量：

**1. 按“单店单日预期销量”的3-5倍备货**
不建议以“箱”为单位盲目进，而是按天算：

- **场景A（一般社区店/中小超市）：** 预估该新品在该店每天能卖10-15斤，那么首批进货建议控制在 **40-60斤**（即3-5天的销售预期量），并明确要求供应商分批配送。
- **场景B（大型商超/连锁）：** 如果有多家门店，不要一次性铺满。选 **1-2家客流稳定的标杆店** 试卖，每店首次进 **1-2箱**（约15-20公斤/箱，视品项而定），作为“样品暴露”。

**核心测算逻辑：** 试卖量的上限 = **每日保守预估销量 × 水果在柜台的最长安全陈列天数**。水果类目（如芒果、草莓、蓝莓）的最佳试卖期通常只有3-4天，超过4天损耗率会急剧上升。

**2. 根据水果品种特性分层**：
- **易损耗贵族水果（如阳光玫瑰、车厘子、荔枝）：** 首批进量不要超过 **“当天计划售罄量”的1.5倍**，甚至可以做“零库存”预售（摆样品+次日达）。
- **耐储型水果（如苹果、梨、火龙果、柑橘）：** 可相对放宽，但首批仍建议控制在 **5-7天的预计销量**，切勿贪多。
- **地标新品（如新产季的冬枣、秋月梨）：** 如果是尝鲜期，建议以 **“试吃引流”** 为主，首批进货量控制在 **2-3天销量的量**，快速测试消费者复购率。

**3. 定好“砍单”和“补单”的红线**
无论进多少，最怕“卖不动还压货”。建议与供应商约定：

- **卖得好（日清率≥80%）：** 第3天即可追加第二单（可以加量20%）。
- **卖得平（日清率50%-80%）：** 保持原剂量，第4天开始降价促销清尾。
- **卖得差（日清率<30%）：** 第2天起立刻调整陈列位置或做买赠，如果持续2天不行，余货直接退回或让供应商协助处理，**止损比压货更重要**。

**最后给个实用起步量建议（新手可抄作业）：**
- 试卖期 **总时长定为7天**。
- 首批进货量 = **试卖期间总预算的 20%-30%**。比如你计划为该新品投入5000元，首批只拿1000-1500元的货（大约相当于2-3箱的量）。
- 把剩下的预算留到验证口味和包装后，再根据数据追加。

**一句话总结：** 宁少勿多，给足试错空间；**首批控制在“3天卖完”的量最稳**。同时，记得把这批货的条码、价格、进货成本单独建账，第5天看复购数据，再决定是否签长期供货协议。
