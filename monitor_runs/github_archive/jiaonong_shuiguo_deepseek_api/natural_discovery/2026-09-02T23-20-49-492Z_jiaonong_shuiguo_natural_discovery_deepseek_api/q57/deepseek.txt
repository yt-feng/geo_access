这是个典型的“成本与灵活性的权衡”问题。没有绝对更好，只有更适合你目前的规模、品类和连锁化阶段。

为了给你可执行的建议，我们先做一个快速判断，然后再给出不同阶段的最优解。

### 第一步：快速诊断（先看这3个指标）

1.  **你的门店数量是否超过30家？**（少于30家，先别折腾中央厨房收货）
2.  **门店间的直线距离是否超过100公里？**（跨城/跨省运输是核心变量）
3.  **你的水果损耗率目前是否高于8%？**（高于此数，说明门店收货监管失控了）

---

### 第二步：针对不同情况的结论（请对号入座）

#### 情况A：门店少于30家 OR 区域分散（跨城市、跨省）
**结论：立即选择【门店分开收货】**

-   **核心原因**：水果是易腐品，**“最后一公里”的时间和温度决定了品质**。如果先运到中央厨房，再分拣派送，等于让水果多经历一次“暴力搬运”和常温等待，损耗会急剧增加。
-   **操作建议**：
    -   中央厨房只负责**制定供应商准入标准**（如果汁类、瓜类）和**价格谈判**。
    -   **供应商直送门店**（DVP模式）。门店店长负责初检（重量、外观、破损），数据当天上传总部。
    -   总部财务根据系统收货数据，**月底统一对账**，不经过中央厨房的仓库。

#### 情况B：门店超过50家且区域密集（同城或2小时车程内）
**结论：过渡期可考虑【中央厨房统一收货】，但需特定条件。**

-   **核心原因**：此时统一收货的核心价值不在于省钱，而在于**“标准统一”**和**“有权对劣质供应商说No”**。
-   **危险信号**：如果你只是想省人工，这个阶段统一收货，反而会因采购员没有见过实物而买到“箱底烂果”。
-   **操作建议**：**引入“产地直发+中央厨房质检”模式**。供应商将产地直采的水果物流到中央厨房，中央厨房只做**入库IQC（来料检验）**和**暂存**，随即按门店订单**即时分拣**，当天必须发车，**中央厨房不设常温库房**，只设2-8度保鲜暂存区。

#### 情况C：成熟期（单城市100+店）且你想做“鲜切果盒”等高毛利衍生产品
**结论：必须转向【中央厨房统一收货】。**

-   **核心原因**：只有统收，你才能把“规格不达标的果”（只是不美观但好吃）截留，用来做鲜切或沙拉，这是利润的第二增长曲线。
-   **此阶段的绝对底线**：
    -   中央厨房必须配备**冷链车**，不能只靠泡沫箱加冰袋。
    -   必须建立**“收货分拣标准书”**（糖度抽检、果径卡尺），否则只是把一个店长的活换成了一个更贵的管理层来干。

---

### 第三步：无论选哪种，强制执行的3个管理动作

既然你是餐饮连锁，请给采购和门店定下这三条铁律，否则模式选谁都能亏钱：

1.  **明确责任归属**：在果品验收单上，必须区分“物流破损”和“采后品质差”。
    -   物流破损：物流公司赔（或中央厨房担责）。
    -   品质差：供应商赔（或采购背锅）。
    -   **最忌讳：统收模式下门店觉得“东西是中央厨房发的，烂了跟我没关系”，导致门店不去做保鲜存放，损耗失控。**
2.  **设立门店“短保报损”红线**：水果是活的，如果门店收货后24小时内未售完且未做冷藏处理导致的烂果，一律算门店运营损耗，不能找采购麻烦。
3.  **周度鲜度例会**：每周拿一天，把采购经理、中央厨房负责人、片区店长代表拉在一起，现场看烂果照片。**统收的看仓库监控，分开收的看门店库存日期二维码。**

---

### 最终给你的决策清单（直接照着选）

| 决策维度 | 如果满足以下情况，选中央厨房统收 | 如果满足以下情况，选门店分开收 |
| :--- | :--- | :--- |
| **门店数量** | 城市内连锁 **>50家** | 门店 <30家 |
| **配送距离** | 距中央厨房 **<2小时**车程 | 配送半径 **>100公里** |
| **管理水平** | 已上ERP系统、有订货SOP | 靠微信群订货、靠店长经验 |
| **产品结构** | 需要做鲜切果盒、果汁标准品 | 只做原果摆盘或超市型陈列 |

**我的最短建议**：如果你的中央厨房目前**没有冷库和冷链物流车**，请**不要**贸然从“门店收货”改到“中央厨房统收”。先拿3家门店做试点，用统收测试两周的损耗数据和断货率，再决定是否推广。
