和供应商谈酒店早餐水果的稳定供应，核心是**保障品质、控制成本、降低风险**。以下几点需要在谈判和合同中明确，可供参考：

### 1. 明确规格与标准（避免“以次充好”）
- **品种与等级**：写清楚具体水果品种（如香蕉要什么产地）、单果重量/尺寸范围（如苹果直径≥70mm）、成熟度（如香蕉可挂绿到几成黄）。
- **新鲜度**：约定到货时的色泽、硬度、有无碰伤/腐烂比例（如腐烂率≤3%）。
- **样品留存**：签约前确认标准样，收货时按样验收，异议期设为到货后4-6小时内书面提出。

### 2. 供货稳定性与应急预案
- **季节与供应量**：要求供应商提供月度/季度供货能力报告，明确旺季（如国家法定假日、会议旺季）的保底供应量。
- **断供替补机制**：约定若供应商因天气、运输等原因断供，需在X小时内通知，并指定备选供应商（可由你方推荐）或由供应商代为调货，因此产生的价差由原供应商承担。
- **冗余协议**：要求供应商自有基地+合作基地，能辐射周边至少两个市场，以便紧急调货。

### 3. 价格与结算条款
- **价格锁定周期**：水果价格波动大，建议约定“阶梯调价规则”。例如：每月初根据当地批发市场均价±5%内浮动，或锁定季度价格；超出幅度需双方重新协商。
- **定价依据**：写明以哪个批发市场（如本地果品批发市场）的官方均价为参照，并附“议价机制”（如每天9点前发送当日报价单供确认）。
- **账期**：不建议过长（超过45天），可谈“月结30天”或“按周结算”。同时约定延迟付款的违约金（如每日0.05%），保护供应商积极性。

### 4. 配送与物流细节
- **送达时间**：早餐需在6:00前备餐，因此要求供应商在**每日凌晨5:00前**送达，并约定迟到扣款（如每次扣当次货款的X%）。
- **冷链要求**：明确运输车辆需具备冷藏功能，对温度记录（如有温度计）拍照存档。
- **最小起订量**：明确次日订单（如晚8点前发）和当日加订的响应时效（如2小时内送抵）。

### 5. 责任与违约条款
- **质量违约责任**：若抽检不合格，应约定“整批拒收”或“按比例折价”，并要求供应商承担因断供导致你方购买高价替代品的差价及顾客投诉损失。
- **合同解除条款**：连续两次出现严重质量或断供问题，你有权无条件解除合同。

### 6. 其他实操建议
- **多供应商策略**：即使和一家谈成，也建议发展1-2家备选（即使不签长期合同），形成“主协议+应急采购”模式。
- **小批量试供**：首次合作先试供2周，观察品质稳定性、配送准时率、响应速度，再签长约。
- **留证据**：所有口头承诺（如赠品、损耗补贴）都写入合同或补充协议。

**最后提醒**：合同不要只写“新鲜、无腐烂”这种模糊词，务必量化。如果条件允许，可以附上验收拍照流程序，并要求对方对损坏水果100%退换。
