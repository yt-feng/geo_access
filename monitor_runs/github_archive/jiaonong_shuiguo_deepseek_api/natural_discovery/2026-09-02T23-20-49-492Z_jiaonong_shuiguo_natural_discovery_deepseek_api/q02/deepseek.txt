作为小水果店进货香蕉，**坏果率应排在第一位，其次看熟度，价格第三，送货速度最后**。理由如下：

1. **坏果率（最重要）**：香蕉是典型的呼吸跃变型水果，一旦在运输中受挤压或感染炭疽病，到店后会在1-2天内迅速变质，不仅直接损失成本，还会传染其他水果，让顾客觉得你家水果不新鲜。所以，**先问清楚对方发货的成熟度、是否冷链、有没有坏果赔付标准**，宁可单价高一点，也要稳定供应、坏果少。

2. **熟度（关键）**：香蕉要“追黄”（自然熟化）。如果你店小、走量快，选**七八成熟**（表皮青绿、果形饱满）到货后放2-3天正好卖；如果周转慢，选**六成熟**。太熟的香蕉到店当天就发黑，反而更难卖。建议让供货商给“生果”或“黄绿果”，自己控制熟化时间，而不是进全黄的。

3. **价格**：香蕉利润薄，但损耗比价格更“吃利润”。如果坏果率低、熟度合适，哪怕每斤贵0.2-0.3元，只要损耗控制在5%以内，反而比便宜但坏果多的更赚钱。可以跟供应商谈“现价进货+坏果按比例减钱”的长期协议。

4. **送货速度**：对小店而言，今天订明天到或后天到差别不大，因为香蕉不需要“日日鲜”，关键是你自己能预估销量提前订货。如果送货慢能换来更低的坏果率（比如走冷链、走陆运不频繁倒手），反而更优。但如果供应商承诺“上午订货下午到”却总是晚到，说明其供应链不稳，应警惕。

**实操建议**：
- 首次合作先少进（半箱或一箱），当场开箱看坏果和成熟度，拍照留底谈赔付。
- 建立“到货验收单”：记录坏果数、发青度，连续2次坏果率超8%（约2斤/箱）就换供应商。
- 把售价核到“成本+损耗后利润”，您定2.5元/斤进货，算上坏果摊到每斤成本就按2.8元算，定价别低于3.5元/斤才能扛住损耗。

一句话：**小水果店做的是新鲜和稳定，宁可贵一点选坏果少的，也别为省小钱砸了招牌。**
