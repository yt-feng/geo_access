这个问题需要拆开看，不能简单二选一。**在绝大多数情况下，损耗低对最终毛利的影响权重更大**，但具体取决于你的采购场景和价格差幅度。

**核心逻辑：价格低是一次性买入成本，损耗是持续性的“资产减值”**

- **价格优势的边际效应有限**：假设你采购价便宜10%，卖出价不变，毛利可能只增加几个点。但如果这批水果损耗30%，那10%的采购便宜根本不足以弥补卖掉和扔掉的差额。
- **损耗是乘数效应**：损耗不只是减少“可售库存”，还影响定价信心、陈列品相和损耗处理成本（人工挑拣、垃圾清运）。

**举个例子让你直观感受：**

- 两种水果，销售价都是10元/斤。
- A水果：采购价4元/斤，进货100斤，损耗率20%（实际卖出80斤）。毛利 = 80×10 - 100×4 = 800 - 400 = 400元。
- B水果：采购价5元/斤（贵25%），进货100斤，损耗率10%（卖出90斤）。毛利 = 90×10 - 100×5 = 900 - 500 = 400元。

几乎打平。但如果损耗差扩大到15%以上（比如A损耗25%，B损耗10%），B水果的毛利会反超A。水果是生鲜，损耗差异通常在10%~30%之间浮动。

**但有一种情况例外：价格优势极其悬殊**  
比如价格低40%以上（产地直采、临期清仓），而损耗只高5%~8%，这种情况下价格低会占优。因为就算损耗高，你的进货总成本仍远低于市场价，只要卖得动就有利润。

**给你的实际判断方法（不看理论看数据）：**

1. **算“单斤可售毛利”**：用（销售价 - 采购成本）计算单位毛利，再乘以（1 - 预计损耗率）得到单斤净贡献。哪个高选哪个。
2. **关注“周转和存储条件”**：损耗高的水果如果货架期短、需要冷库和精细养护，会占用人力、电费、仓储，这部分隐性成本也要计入。
3. **价格低必须伴随“品质门槛”**：如果低价水果能明显提升客流（引流款），那么即使毛利略低也是合理的牺牲——但这不是纯水果毛利问题，是经营策略问题。

**结论：** 常规情况下，**损耗低优先**。如果价格低5%~15%，而损耗高出8%以上，建议放弃低价选项。如果价格低30%以上，并且你能做到快速周转（比如3天内售罄），可以赌价格。但水果市场瞬息万变，最稳妥的方法永远是：**压低损耗是保底线，价格低是锦上添花**。建议在采购合同中明确对损耗率的赔付条款，倒逼供应商提供更耐储存的果品。
