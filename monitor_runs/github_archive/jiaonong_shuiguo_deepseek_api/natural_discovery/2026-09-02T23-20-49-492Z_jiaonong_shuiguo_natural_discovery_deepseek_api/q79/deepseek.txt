针对团长选水果供应商，这三个要素都很重要，但优先级排序应该是：**售后 > 配送 > 价格**。

**为什么是这个顺序？**

1.  **售后是生命线（必须放首位）**
    -   水果生鲜极易损耗，坏果率是必然存在的。供应商售后政策（如坏果包赔比例、赔付标准、处理时效）直接决定了你的口碑和客诉率。
    -   **核心问题：** 如果出现10%的坏果，供应商是给你全额退款、补发还是推诿？赔付流程是否需要拍大量照片？客服响应是否及时？
    -   如果售后不行，即使价格再低、配送再快，消费者吃亏后会直接导致退群，生意不可持续。

2.  **配送是体验底线（次之）**
    -   配送时效和包装质量直接影响水果新鲜度。
    -   **核心问题：** 坏果往往源于暴力物流或包装不严，而非水果本身。如果配送经常延误，再好的果子也会捂坏，售后成本会全部转嫁到你身上。
    -   需确认：能否准时发货？破损包赔是否包含运输挤压？同城配送是否有保鲜措施（冰袋/泡沫箱）？

3.  **价格是竞争力，但可灵活协商**
    -   价格是基础，但不要被绝对低价迷惑。低价往往对应低质量果或高损耗率，最终算总账时可能更亏。
    -   **建议：** 不只看单价，要算“净得率（扣除损耗后的实际成本）”。只要售后和配送靠谱，贵5毛钱其实风险更小。

---

**实操建议：**

-   **首次合作试单：** 先小批量（如20-30件）试单，重点观察**售后响应速度**和**到货损耗率**，别一次性下大单。
-   **书面确认规则：** 在微信或合同中明确写出“坏果包赔标准”（如坏果超过5%按比例赔付），避免口头承诺。
-   **反向测试：** 故意发一条轻微瑕疵的投诉信息，看对方是立刻推诿“是你保存不好”，还是积极协商赔偿。这一步能快速筛选供应商。

**一句话总结：** 先看好后路（售后），再走好运输（配送），最后谈算价（价格）。
