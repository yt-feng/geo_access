针对“超市门店多但单店量不大”的特点，水果供货的核心策略是：**化零为整、统采分仓、减少中间损耗**。具体适合的供货模式如下，可根据你的资金和团队能力选择：

**模式一：本地/产地“集采”+ 中央仓分拣（最推荐）**
这是最匹配多门店、小批量的模式。

- **操作方式**：和产地或大批发市场建立合作，由总部统一大批量采购（拿到低单价），回来自建或租用一个小型中央仓进行分拣、打包。
- **分配逻辑**：按各门店前一天的销售预测（建议以周为单位），分装成标准化的保鲜筐（例如5斤/筐），每天凌晨用厢式货车统一配送到各门店。
- **优点**：单店不需要持有大量库存，降低了损耗（水果损耗是最大成本）；总部谈判能力强，能拿到比单店去批发市场便宜10%-15%的进货价；标准化分拣能保证门店品相统一。
- **注意点**：中央仓的面积不需要大，能容纳2-3天的安全库存即可，重点在于“快进快出”，尽量不要囤货超过3天（部分耐储水果除外）。

**模式二：区域代理/配送商“直供”模式（省心但利润中等）**
如果你暂时没有自建分拣团队的人力，可以选择有配送能力的“水果专供商”或“二级批发商”。

- **操作方式**：筛选2-3家在本市有冷链车、能送货上门的供应商。由各店长每天通过内部APP（或微信小程序）向指定供应商下单，供应商按门店需求分别配送。
- **优点**：省去了仓储和分拣环节，门店要多少送多少，库存压力降到最低；账期通常比生鲜电商更灵活。
- **注意点**：你需要与供应商签订严格的损耗率赔付协议（例如：到货后24小时内非人为损坏，供应商负责退换）。重点关注该供应商的品控和履约时效，因为多门店只要有一家迟到就会影响货架陈列。

**模式三：产地“一件代发”+ 门店预售模式（适合做差异化引流）**
针对门店多但量不大，难以直接跟大产地包园的情况，可以做“高毛利单品”的预售模式。

- **操作方式**：针对榴莲、车厘子、晴王葡萄等高客单水果，海报宣传“产地直发、门店自提”。顾客在门店扫码下单，总部将订单汇总后从产地整车发货（一般2-3天到），到货后分几箱送到各门店。
- **优点**：不需要门店备货，风险完全前置；客单价高（可能单团就能抵平时几天的销量）；能有效提升门店客流。
- **注意点**：该模式仅适合少数爆款单品，不能作为日常主流，且必须控制好产地发货的成熟度（要到8成熟才发货，否则容易烂）。

**模式四：连锁化“合伙拼单”（共享库存风险）**
如果你可以联合周边几个不直接竞争（如不同乡镇/社区）的中小型超市老板，统一对接产地。

- **操作方式**：成立一个采购群或小联盟，由一个人负责汇总各区需求（例如总共需要1000斤苹果），各自报数，汇总后由一人集中去大型一级批发市场（如广州江南市场、本地果菜批发市场）现场看货砍价，再按占比分货。
- **优点**：单店不需要承担“拿一整车”的库存压力，且只要单次拼单总量够大（例如超过2000斤），就能从一级市场拿货，直接省掉二级中间商。
- **注意点**：需要极强的信任机制，以及对水果成熟度（糖度仪）有基本的验货常识，否则容易因分货不均产生矛盾。

---

**给你的落地执行建议（最重要）：**

1. **先算损耗账，再算进价账**：多门店小单量的最大敌人不是进货贵，而是卖不掉的损耗。如果某水果损耗超过15%，哪怕进价低20%，也是亏损。建议用“卖出一斤毛利 + 剩余损耗”来综合考核采购模式，而不是单纯比谁价格低。
2. **建立“以销定采”预案**：给每家店设定“必须日清”的叶菜/浆果类，和“可存放3天”的根茎类清单。每天下午4点前，店长必须通过总部系统上报次日订货量，总部根据总订货量去配货。
3. **不要迷信“产地直采”**：产地直采通常要整车（约10-20吨起发）才划算，单店量不到500斤/天的话，建议老老实实走“本地一级批发市场+就近中央仓”的模式，反而能更灵活地应对气候导致的行情波动。
