批发档口降退货纠纷，核心不是“让客户别退”，而是**把验收标准前置、把证据留全、把责任边界说清**。收货验货建议按下面做。

## 一、验货前先定标准
先把“什么算合格、什么算问题、什么问题可退可换”写成一页纸，发给客户并在档口张贴。

- 明确外观标准：色差、线头、污渍、破洞、走线、尺寸误差、配件缺失等，哪些算瑕疵、哪些算正常工艺差异。
- 明确数量标准：按件/按包/按箱计，允许的短溢装比例写清楚。
- 明确时效：客户收货后多少小时内提异议，超时默认验收合格。
- 明确退换条件：未剪吊牌、未下水、未二次销售、原包装完整等。

## 二、收货时当场验
货物到档口或客户到店提货时，按固定流程走：

1. **先点总数再拆细**：核对大包数、箱数、件数，和发货单一致再签收。
2. **抽检+关键款全检**：爆款、高价款、易争议款全检；普通款按比例抽检，但抽检比例要固定并留记录。
3. **逐项看**：数量、颜色、尺码、面料、做工、配件、包装。
4. **当场拍照/录像**：发现问题立即拍，画面里带货物、标签、包装、发货单和日期。
5. **异常单独放**：不合格品单独区域存放，贴标签写明问题，避免混入正常货。

## 三、全程留证据
退货纠纷多数输在“说不清”。

- 发货前：拍整包外观、封口、称重、发货单。
- 收货时：拍拆包过程、清点过程、问题细节。
- 沟通时：用文字确认，不用只发语音；重要约定让客户回复“确认”。
- 建立台账：每单记录发货时间、数量、验货结果、异常照片、客户确认记录。

## 四、责任边界提前说
- 运输破损：签收前验，破损当场拒收或拍照并让物流开证明。
- 质量问题：按约定时限和证据处理，该换就换，避免拖成纠纷。
- 客户主观不满意：如颜色不喜欢、卖不动，不属于质量问题，提前说明不退不换或只换不退。
- 混批/尾货：明确“按现状销售”的范围，但质量问题仍要单独约定。

## 五、纠纷处理流程固定
设一个简单流程：客户提异议→要求提供照片/视频和单号→对照验货记录→24小时内给结论→可换可补的优先换补→争议大的保留证据再协商。

**一句话：标准写在前面，验货做在当场，证据留在全程，责任划在事前。** 这样退货纠纷会明显下降，而且真出问题时你也有据可依。
