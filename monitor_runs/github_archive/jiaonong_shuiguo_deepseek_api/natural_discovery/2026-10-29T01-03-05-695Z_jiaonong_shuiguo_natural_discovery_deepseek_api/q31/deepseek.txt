连锁商超招长期水果供应商，评分标准建议围绕“长期稳定供货能力”设计，不要只比价格。可按以下框架设置，权重可按品类风险微调：

**一、商务与资质 10–15分**
- 营业执照、食品经营/生产许可、产地证明、检测报告齐全：5分
- 食品安全责任险、冷链运输资质：3–5分
- 近3年无重大食品安全处罚、无严重失信记录：3–5分
- 可接受账期、结算方式、履约保证金：2–3分

**二、供货与产能保障 20–25分**
- 自有基地/长期合作基地面积、品种覆盖、年可供货量：8–10分
- 对商超年度/月度需求量的满足率承诺：5–6分
- 多产区布局、反季节或跨区域调剂能力：4–5分
- 应急补货响应时间、缺货替代方案：3–4分

**三、质量与品控 20–25分**
- 分级标准、农残检测能力、第三方检测频次：6–8分
- 到货合格率、损耗率承诺：5–6分
- 冷链温控、包装规格、追溯体系：5–6分
- 质量问题退换货、赔偿与召回机制：3–5分

**四、价格与成本 15–20分**
- 报价水平：8–10分，建议用“基准价下浮率”或“同期市场价对比”评分，避免绝对低价
- 价格调整机制是否透明，是否与批发市场指数/产地价联动：4–5分
- 运费、损耗、包装等综合到岸成本：3–5分

**五、履约与服务 10–15分**
- 订单满足率、准时到货率承诺：4–5分
- 售后服务、对账开票、问题处理时效：3–4分
- 配合促销、节日备货、临时加单能力：3–4分
- 信息化对接能力（订单、库存、追溯）：2–3分

**六、可持续发展与合作意愿 5–10分**
- 长期合作方案、年度降价或返利机制：3–4分
- 农残管控、绿色种植、包装减量等：2–3分
- 同类商超服务案例与客户评价：2–3分

**关键设置建议：**
1. **价格分不宜超过25%**，长期水果供应更怕低价中标后断供、降质。
2. **设置否决项**：无食品经营资质、检测不合格、重大失信、无法提供稳定货源，直接废标。
3. **用量化承诺代替主观描述**：如“到货合格率≥98%”“缺货响应≤4小时”“月度满足率≥95%”，写入合同并设罚则。
4. **分品类评标**：叶菜/浆果等易损耗品类提高冷链和损耗分；苹果/柑橘等耐储品类提高价格和产能分。
5. **样品与试供**：设置10–15分现场样品或试供评分，比纸面承诺更可靠。
6. **长期合同配套**：评分中体现年度考核、末位淘汰、价格联动，避免一次招标定死多年。

这样既能把价格压到合理区间，又能筛掉“低价投标、后续断供”的供应商。
