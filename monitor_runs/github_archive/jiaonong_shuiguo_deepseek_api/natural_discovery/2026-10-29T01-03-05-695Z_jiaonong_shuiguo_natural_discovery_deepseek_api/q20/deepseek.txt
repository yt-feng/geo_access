社区超市找每天配送的水果供应商，建议按“先保履约、再保品质、最后谈价格”的顺序看条件。

1. **配送能力**
   - 是否支持每天固定时段配送，能否覆盖你们的营业时间。
   - 是否有冷链车/周转筐，水果是否全程控温。
   - 临时补货、节假日、恶劣天气能否加急或调整。
   - 配送半径和仓库位置，距离太远会影响准时率和损耗。

2. **品控与损耗**
   - 是否有稳定产地或一级批发渠道，能否提供农残检测、产地证明。
   - 到货验收标准要明确：规格、成熟度、磕碰率、烂果率、重量偏差。
   - 是否接受坏果包赔、短少补货，赔付流程和时限要写清。
   - 能否按社区店小批量、多频次供货，避免一次压货太多。

3. **价格与结算**
   - 报价是否含税、含运费、含装卸，是否有起送金额。
   - 价格是否随行就市，调价是否提前通知。
   - 账期、押金、退换货规则要明确，避免口头承诺。
   - 对比时不要只看单价，要算上损耗率、配送费和退赔成本。

4. **品类与稳定性**
   - 能否覆盖你们常卖的苹果、香蕉、柑橘、时令水果等主力品类。
   - 爆款和应季品是否有稳定货源，缺货时能否替代。
   - 是否支持小包装、分级分规格，方便社区店陈列和定价。

5. **资质与合规**
   - 营业执照、食品经营相关资质是否齐全。
   - 是否有固定经营场所和稳定团队，避免临时中间商。
   - 能否开具发票或收据，便于对账。

6. **试合作验证**
   - 先签短期试供或小批量试单，连续观察7—14天：准时率、烂果率、缺货率、补货响应。
   - 每天记录到货时间、损耗、退赔处理，用数据决定是否长期合作。
   - 最好保留2家备选供应商，防止单一供应商断供。

简单判断标准：**能每天准时到、坏果少且赔得快、价格透明、缺货能补，这四点满足再谈长期合作。**
