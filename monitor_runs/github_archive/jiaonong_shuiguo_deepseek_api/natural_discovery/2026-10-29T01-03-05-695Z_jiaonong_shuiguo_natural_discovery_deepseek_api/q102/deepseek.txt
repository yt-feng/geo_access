**1. 开发票**
- 企业福利采购通常需要供应商开具**增值税发票**，否则财务难以入账、报销和税前扣除。
- 采购前确认：开票类型（专票/普票）、税率、开票项目（水果/礼盒/食品等）、开票时间（先票后款还是款到开票）。
- 若供应商是小规模纳税人或个体户，要确认其能否开票、开票税率及是否影响你的进项抵扣。

**2. 定制包装**
- 企业福利礼盒通常有品牌露出、节日祝福、员工关怀等需求，定制包装能提升福利感知，也便于统一发放。
- 采购前确认：起订量、定制内容（LOGO、贺卡、腰封、外箱）、打样费用与周期、包装食品安全合规（直接接触食品的包装材料需符合食品级要求）。
- 定制包装通常会影响交期和单价，需在合同中约定验收标准。

**可执行建议：**
- 询价时直接问清“是否支持开票、开什么票、税率多少”和“定制包装起订量、打样周期、费用”。
- 优先选择能同时满足开票和定制包装的供应商，减少多供应商协调成本。
- 将开票信息、包装样稿、交期、验收标准写入采购合同，避免后续争议。

如果供应商不能开票，建议谨慎合作；定制包装则可根据预算和福利规模灵活选择，不是所有场景都强制需要。
