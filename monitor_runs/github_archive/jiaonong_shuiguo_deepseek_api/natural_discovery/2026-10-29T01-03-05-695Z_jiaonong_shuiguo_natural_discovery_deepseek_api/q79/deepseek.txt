优先级是：**先说售后，再问配送，最后谈价格**。因为团长卖的是“确定性”，价格再低，售后和配送出问题，最后赔的是你的口碑和复购。

可执行判断顺序如下：

1. **先问售后（最该先问）**
   - 坏果/烂果怎么赔：按颗、按斤还是按比例？
   - 拍照时效、报损截止时间、多久到账？
   - 少发、漏发、整单延迟怎么处理？
   - 是否支持团长先行垫赔，还是必须等供应商核损？
   - 判断标准：售后规则模糊、赔付慢、要求团长自己扛的，直接降级。

2. **再问配送（决定你能不能稳定开团）**
   - 到团时间是否固定，误差多大？
   - 是送到小区自提点还是团长自提？卸货谁负责？
   - 临期/迟到怎么通知，能否分批补送？
   - 破损率、迟到率有没有历史数据？
   - 判断标准：配送时间不可控、卸货责任不清的，价格再低也别长期合作。

3. **最后谈价格（在售后和配送达标后再压价）**
   - 比价要按“到手可售成本”算：进价 + 损耗 + 赔付 + 团长时间成本。
   - 问阶梯价、账期、押金、退换货成本。
   - 判断标准：只谈低价不谈售后的供应商，通常把风险转嫁给团长。

一句话：**售后决定你能不能卖，配送决定你能不能稳卖，价格只决定你赚多赚少。** 首次合作建议小单试跑，重点记录坏果率、迟到次数和赔付响应速度，再决定是否放量。
