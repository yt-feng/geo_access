连锁超市降低门店坏果率，合同约定赔付要从“责任可界定、损失可计量、流程可执行”三方面设计，不能只写一句“坏果按价赔偿”。建议按以下结构约定：

**1. 明确坏果定义和验收标准**
- 在合同附件中列明各类果品的验收标准：外观、成熟度、机械伤、腐烂比例、规格、温度要求等。
- 区分“到店验收时已存在”和“到店后储存期内发生”的坏果，分别定责。
- 约定抽样方法和判定规则，例如每批随机抽3箱，坏果率超过约定阈值即整批按比例扣款或拒收。

**2. 约定坏果率阈值和赔付比例**
- 按品类设不同阈值，如叶菜类、浆果类、根茎类标准不同。
- 超过阈值部分按“坏果重量×结算单价×倍数”赔付，倍数可设为1.5—3倍，覆盖分拣、损耗和客诉成本。
- 设置阶梯：轻微超标扣款、严重超标整批拒收并可要求补货，连续多批超标可暂停供货或解除合同。
- 明确赔付上限和累计赔付机制，避免单次小额但长期累积。

**3. 约定到店后损耗的责任边界**
- 明确门店收货后的储存条件责任：温度、湿度、摆放、先进先出等由超市负责的，供方不承担。
- 若因供方冷链断链、包装不当导致到店后短期内集中坏果，供方仍需担责，可约定“到店后24/48小时内出现异常坏果”的追溯规则。
- 要求供方提供冷链温度记录、采摘和包装时间，作为定责依据。

**4. 约定赔付方式和执行流程**
- 赔付形式优先选货款抵扣，其次补货，现金赔付作为备选，避免流程拖长。
- 明确取证要求：收货单、验收照片/视频、抽样记录、坏果称重记录、双方签字确认。
- 约定异议期，如收货后2小时内提出，供方24小时内响应，逾期视为认可。
- 约定月度对账时统一结算赔付金额，避免每批扯皮。

**5. 设置质量保证金和退出机制**
- 可要求供方缴纳质量保证金，或每月留存一定比例货款作为质量押金，按季度结算。
- 约定连续N批坏果率超标、月度累计赔付超过阈值、同一品类反复出现问题的，超市有权暂停采购、要求整改或解除合同。
- 对恶意掺货、以次充好的，约定惩罚性赔付条款。

**6. 明确不可归责情形**
- 自然灾害、极端天气等不可抗力导致的品质波动，需提前书面告知并协商处理，不当然免责，但可调整验收标准。
- 超市自身储存不当、超期销售、二次分拣造成的坏果，供方不承担。

**落地建议：** 把验收标准、抽样规则、赔付计算公式做成合同附件《果品质量验收与赔付细则》，并在收货环节用统一表单记录，双方签字。合同条款再完整，没有可执行的验收记录和照片证据，赔付也很难落地。
