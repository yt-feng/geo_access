做餐饮客户，菠萝和香蕉的规格要按**用途倒推**，而不是按零售卖相准备。建议你分“主推规格 + 备用规格”两档备货，先把高频需求跑稳。

## 菠萝

餐饮端主要看**出成率、切配稳定性、单份成本**，不是看个头大不大。

| 规格方向 | 建议 | 适用客户 |
|---|---|---|
| 主推 | 单果1.2–1.5kg，果形端正、成熟度7–8成，耐运输 | 快餐、食堂、团餐、切果配送 |
| 备用 | 单果1.5–2kg以上，出肉率高 | 中央厨房、果汁店、菠萝炒饭类 |
| 小果 | 0.8–1.2kg | 茶饮店做鲜果装饰、小份果切 |

关键控制点：
- **品种统一**：餐饮客户最怕这批酸那批甜，优先固定一个品种和产区，别混发。
- **成熟度分级**：7成熟给后厨加工，8–9成熟给现切现卖，分开报价。
- **按箱报出成**：告诉客户“每箱净重、去皮去芯后出肉率大概多少”，比只报斤价更容易成交。
- **可做去皮真空件**：餐饮客户人力紧，去皮菠萝块/片是加价点，但要做冷藏短保说明。

## 香蕉

餐饮端香蕉分两类：**直接入口**和**加工/装饰**，规格逻辑不同。

| 用途 | 建议规格 |
|---|---|
| 食堂、快餐、酒店早餐直食 | 单根120–150g，梳蕉整齐，7–8成熟到店，可催熟 |
| 茶饮、甜品装饰 | 单根100–130g，小果型，成熟度稳定，少碰伤 |
| 加工/榨汁/烘焙 | 可接受略大或外观次一级，但要求同批成熟度一致 |

关键控制点：
- **按“根/梳/箱”报规格**：餐饮客户算的是每份成本，直接给“每箱多少根、每根约多少克”。
- **成熟度必须可调**：直食客户要7–8成到店自行催熟；茶饮客户可能要黄熟即用，最好能提供催熟或分级服务。
- **碰伤率要承诺**：香蕉餐饮投诉最多的是压伤和到货过熟，备货时按运输距离控制成熟度。

## 建议你先这样备货

1. **菠萝**：主备1.2–1.5kg/果的加工型一档，另备少量大果给果汁/中央厨房客户。
2. **香蕉**：主备120–150g/根的直食型，另备小果型给茶饮甜品客户。
3. **先做两个报价包**：  
   - 食堂/快餐包：耐储、7–8成熟、按箱净重和单份出成报价；  
   - 茶饮/甜品包：小果、成熟度稳定、可少量多频配送。
4. **首批不要铺太多SKU**：菠萝2档、香蕉2档足够，跑2–4周看客户复购和损耗，再决定是否加去皮件、催熟件。

核心判断标准：餐饮客户愿不愿意复购，取决于**同批一致性、到货成熟度、单份出成成本**，不是果子越大越好。
