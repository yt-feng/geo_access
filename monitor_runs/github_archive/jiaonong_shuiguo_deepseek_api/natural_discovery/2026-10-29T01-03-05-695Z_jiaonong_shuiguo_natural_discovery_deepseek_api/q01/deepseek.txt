长期进香蕉和菠萝，和进苹果橘子不是一回事：这两样都是“催熟型/易损型”水果，供应商靠不靠谱，核心不看他说得多好，而看他能不能稳定控制成熟度和损耗。你可以按下面几层判断。

**1. 先看他的主营结构**
靠谱的香蕉、菠萝供应商，通常有稳定的产地或一级批发渠道，库里有催熟房或固定合作催熟点。问他：
- 香蕉主要从哪几个产区走，是什么品种（如巴西蕉、威廉斯）；
- 菠萝主要做哪类（如金钻凤梨、香水菠萝、普通巴厘），产季怎么衔接；
- 淡季断货时从哪补。
如果他说“什么水果都有、什么都能便宜拿”，大概率是倒手贸易商，香蕉菠萝的成熟度和损耗他控不住。

**2. 用三次小批量试单验证**
不要一上来谈长期。分三次、隔几天进小批量，重点看：
- **香蕉**：到货青度是否一致，催熟后颜色是否均匀，有没有“青肩”“硬心”，货架期能放几天，损耗率多少；
- **菠萝**：个头是否均匀，熟度是否一致，黑心、水心、烂眼比例多少，切开后糖度和纤维感是否稳定。
每次记录到货数量、坏果数、可售天数。三次里有两批明显波动，就不适合长期合作。

**3. 看他怎么处理售后**
这是最直接的试金石。故意在试单时反馈一次质量问题，看他：
- 是否认账、多久回复；
- 是补货、折价还是推责；
- 是否愿意一起分析是催熟问题还是运输问题。
长期供应商一定会有出问题的时候，关键是他有没有稳定的赔付规则。含糊其辞、每次都“下次补”的，不要长期绑定。

**4. 看他的催熟和储运能力**
香蕉最怕催熟不当，菠萝最怕闷坏。你可以问：
- 香蕉催熟温度、湿度怎么控，催熟几天出库；
- 运输用不用冷链或通风车，夏天怎么防闷；
- 菠萝到货后怎么存放，是否建议你到货即通风。
答得具体、能说出常见问题的，通常是真做过；只会说“放心，很好卖”的要谨慎。

**5. 看价格是否“异常稳定”**
长期合作不是越便宜越好。香蕉菠萝价格随产季波动很正常。如果他在不同产季报价都明显低于市场，却说不清货源，很可能用次果、催熟过头或压级来补利润。你要问清楚报价对应的等级、规格、成熟度，最好每次下单前确认标准。

**6. 用合同或口头约定固定几条**
至少明确：规格等级、到货成熟度、坏果赔付比例、补货时限、旺季优先供货。香蕉和菠萝损耗高，没有赔付规则的“长期合作”最后容易变成你单方面承担损耗。

**一个简单判断口诀：**
> 主营聚焦、试单稳定、售后认账、催熟有数、价格合理——五条里缺两条以上，就不建议长期合作。

如果你店里香蕉和菠萝销量占比高，建议同时保留两个供应商，一个主供、一个备供，避免单一供应商在产季波动或催熟出问题时把你店里的陈列断掉。
