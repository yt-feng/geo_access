连锁超市和水果供应商签年度合同时，最容易踩坑的不是价格本身，而是**价格机制、质量标准、损耗归属、账期与返利、断供责任**这几类条款。下面按风险从高到低列，并给出可落地的写法建议。

**1. 价格条款：年度合同最容易变成“锁量不锁价”的糊涂账**
- 坑：只写“按市场价结算”或“随行就市”，没有定价基准、调价周期和争议解决机制，旺季供应商随意涨价，淡季超市又被迫按高价接货。
- 建议：明确基准价来源（如某批发市场某品类日均价）、调价频率（如每月/每旬一次）、调价触发条件（涨跌幅超过X%才调）、调价需双方书面确认；同时约定年度价格上限或封顶机制。生鲜季节性强，最好按品类分季节设参考价区间。

**2. 质量标准：只写“符合国家标准”等于没写**
- 坑：水果没有统一国标覆盖所有品类，只写“合格”会导致验收扯皮；规格、糖度、色泽、大小、农残检测标准不明确，货到后超市拒收、供应商索赔。
- 建议：附《品类质量标准表》作为合同附件，逐项写明规格（如单果重量区间）、外观、糖度、成熟度、农残检测要求及检测方式；约定验收时限（如到货后X小时内提出异议）、抽检比例、不合格处理方式（拒收/折价/退货）及费用承担。

**3. 损耗与退货：生鲜合同最大的隐性成本**
- 坑：只约定“质量问题可退货”，但没写退货比例上限、退货时限、退货运输费谁承担、已售出商品的客诉责任；供应商可能要求“整批退货”，超市实际只想退坏果。
- 建议：区分“到货验收不合格”和“上架后损耗”，分别约定处理规则；设定合理退货率上限和折价处理机制；明确退货物流费用承担方；对因质量问题引发的消费者投诉、罚款，约定供应商赔偿责任。

**4. 账期与返利：现金流和利润的隐形陷阱**
- 坑：账期写“月结30天”但起算点模糊（对账日还是到货日）；返利条件写“完成年度采购额给予返利”，但采购额按含税还是不含税、退货是否冲减、返利以货款抵扣还是现金支付都没写清。
- 建议：明确对账周期、发票开具时限、付款起算日和逾期付款责任；返利条款写清计算基数（不含税净采购额、扣除退货）、阶梯比例、结算时间和支付方式；避免“返利冲抵货款”导致供应商实际回款困难而断供。

**5. 供货保障与断供责任：年度合同不能只约束超市**
- 坑：只约定超市最低采购量，不约定供应商最低供货量和断供违约金；旺季供应商优先供高价渠道，超市缺货却无法追责。
- 建议：双向约定最低采购量和最低供货量；设置断供违约金（如按断供金额的X%或日均供货额的倍数）；约定替代供货、紧急调货机制；对季节性品类约定提前备货通知期。

**6. 独家/排他条款：签了独家却拿不到低价**
- 坑：约定某品类独家供应，但没约定价格对标机制，供应商利用独家地位抬价；或排他范围过宽，超市无法从其他渠道补货应急。
- 建议：独家条款必须搭配价格对标条款（如不高于同期同区域同类渠道供货价，否则超市有权调价或终止独家）；排他范围限定到具体品类和区域，保留应急采购权。

**7. 合同期限与退出机制：年度合同不能“进来容易出去难”**
- 坑：只写合同期一年，没写提前解约条件、解约通知期、库存处理方式；合作出问题时超市无法及时换供应商。
- 建议：约定试用期或首季度评估条款；明确重大违约（如连续X次质量不合格、断供超X天）的单方解约权；约定解约后未履行订单和库存的处理方式。

**8. 不可抗力与政策性风险：生鲜行业高发**
- 坑：不可抗力定义过宽，供应商以“天气原因”随意免责；或过窄，疫情、封控、运输管制等实际风险没覆盖。
- 建议：列举式定义不可抗力，约定通知义务和证明责任；对价格剧烈波动设置“情势变更”协商条款，但避免变成单方调价权。

**9. 食品安全与追责：底线条款不能含糊**
- 坑：只写“供应商保证食品安全”，没写检测报告提供义务、追溯配合、召回费用承担、行政处罚和消费者赔偿的最终责任方。
- 建议：要求每批次提供农残检测报告或产地证明；约定食品安全事件中的召回、下架、赔偿费用由责任方承担；明确供应商对超市因此受到的行政处罚和商誉损失承担赔偿责任。

**最优先抓的三件事**：把质量标准做成附件、把价格调整机制写死、把损耗退货规则分清。这三项没谈清楚，其他条款再漂亮，年度执行中也会持续扯皮。合同签署前建议让采购、财务、法务和门店运营各审一遍，重点核对验收流程和账期起算点是否与内部系统一致。
