第一次合作，小批量试单的核心不是“便宜拿到货”，而是用最低风险验证四件事：**货对不对、人靠不靠谱、履约稳不稳、账能不能算得过来**。建议按下面设计：

## 1. 先定试单目标
试单要能回答4个问题：
- 品质是否稳定：同一批次内差异大不大，到货与样品是否一致
- 履约是否可靠：准时率、缺货替换、损耗处理
- 成本是否真实：到岸总成本、损耗后成本、隐性费用
- 沟通是否顺畅：异常响应速度、售后态度

## 2. 选品和批量
- **只试1-2个单品**，选你周转快、易判断品质、价格透明的品种
- 批量控制在**正常单次采购量的20%-30%**，或足够铺2-3个客户/档口即可
- 避开：高损耗、高单价、季节波动大、你完全不懂品质的品类
- 要求**同一产地、同一等级、同一包装规格**，否则无法判断稳定性

## 3. 试单结构建议
可以做“**两小批**”而不是一次：
- 第1批：极小量验货、验流程
- 第2批：间隔3-7天，同规格复购，验证稳定性
这样比一次大试单更能看出供应商是否稳定。

## 4. 合同/订单里必须写清
- 规格：品种、产地、等级、单果/单件重量范围、成熟度、瑕疵允许比例
- 包装：箱规、净重、皮重、托盘/散装、标签
- 价格：单价、是否含税/运费/卸货费、损耗谁承担
- 交付：到货时间窗、迟到处理、缺货替代规则
- 验收：到货多久内提出异议、照片/视频取证要求、赔付或补货方式
- 付款：首单建议**先小比例定金+到货验收后付尾款**，或货到付款；避免全款预付

## 5. 验收要量化
到货后按固定抽样比例开箱，记录：
- 到货总重/净重
- 规格不符比例
- 腐烂、压伤、成熟过度比例
- 与样品/约定标准的偏差
- 实际到岸成本 = 货款+运费+卸货+损耗折价

**验收标准提前写进订单**，不要到货后再吵。

## 6. 试单评估表
试单结束后打分：
- 品质一致性与损耗率
- 准时交付率
- 数量准确率
- 异常响应与赔付执行
- 综合到岸成本
- 是否愿意复购

任一项明显不达标，不急着放量；两项以上不达标，换供应商。

## 7. 风险控制
- 不预付大额货款
- 不接受“试单不售后”
- 不因低价放松验收标准
- 保留样品、聊天记录、订单和到货照片
- 试单期间同步保留1家备选供应商

一句话：**小批量、单品类、两批次、标准写死、验收量化、尾款后置**。试单通过再逐步放量，不要一次把信任和库存都压上去。
