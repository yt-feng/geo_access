核实“全国配送”这类说法，重点不是听承诺，而是让对方把能力拆成可验证的环节，并用小批量试单去验证。建议按下面顺序做：

**1. 先问清“全国配送”的定义**
让对方书面说明：
- 覆盖哪些省份/城市，哪些地区不送或加价；
- 是自营冷链、干线外包，还是到达城市后转第三方落地配；
- 配送时效：同城、省内、跨省分别几天；
- 起送量、最小起订量、偏远地区附加费；
- 破损、延误、品质不达标的赔付规则。

要求提供**配送覆盖表**，而不是一句“全国都能送”。

**2. 核验资质与真实运力**
- 查营业执照经营范围是否含道路货物运输、冷链物流等；
- 若是自有车队，要求提供车辆数量、冷藏车数量、车牌或车辆清单；
- 若外包，要求说明合作物流商名称及合作证明；
- 查冷链温控记录方式：是否有车载温控、到货温度记录；
- 要求提供近3个月同类水果的跨省配送案例，最好能联系1—2个客户侧面核实。

**3. 用试单验证，不要一次性大额合作**
最有效的核实方式是小批量试单：
- 选一个距离远、非核心城市的收货地址下单；
- 选对温度敏感的水果，观察到货温度、损耗率、时效；
- 同时测试旺季/节假日前的响应能力；
- 连续下2—3单，看是否稳定，而不是偶尔能送。

试单时保留：订单记录、物流轨迹、到货照片、温度记录、损耗照片，作为后续谈判依据。

**4. 在合同里把“覆盖能力”变成责任**
合同应写明：
- 具体配送范围及不覆盖区域；
- 时效承诺及延误赔付；
- 冷链温控标准；
- 损耗率上限和赔付方式；
- 偏远地区是否加价、加价标准；
- 因物流原因导致品质问题的责任归属。

**5. 关注几个常见“伪覆盖”信号**
- 只说“全国”但拿不出覆盖城市清单；
- 没有冷链车却承诺全程冷链；
- 报价明显低于市场物流成本；
- 试单只愿意送近处，不愿送远距离；
- 出问题后把责任推给“第三方物流”。

结论：**先要覆盖清单和运力证明，再用远距离小批量试单验证，最后把时效、温控、损耗赔付写进合同。** 没有试单和书面承诺的“全国配送”，只能当作销售话术，不能作为采购依据。
