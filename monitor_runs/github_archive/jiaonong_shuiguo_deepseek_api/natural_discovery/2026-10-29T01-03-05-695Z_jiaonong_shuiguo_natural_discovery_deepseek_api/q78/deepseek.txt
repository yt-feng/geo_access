香蕉和菠萝的售后核心不在"赔得快"，而在**把损耗前置到选品、到货、分级和交付环节**，让售后只处理真正该赔的那一小部分。分四层做：

**1. 选品和规格先降风险**
- 香蕉：团购别做全熟香蕉。选7成熟左右、青转黄的货，到货后还能放2–3天。整把卖比散称好，减少翻拣损伤。避开夏季高温期大量推香蕉，或改推小份量。
- 菠萝：优先选已削皮真空装或单个中小果，整果带叶的售后争议最大（熟度不可见、切开黑心）。品种上选稳定性好的，不要贪便宜拿尾货。
- 明确写清"生鲜非标品，±10%重量/外观差异不售后"，把预期先立住。

**2. 到货验收和分级，问题在团长手里截住**
- 到货当天团长开箱抽检：香蕉看有无压伤、黑斑连片；菠萝闻有无发酵味、按压有无软塌。
- 分三档：正常品正常交付；轻微瑕疵（表皮花、小压痕）**提前告知并折价**，别等客户拆开再吵；明显坏果当场隔离，不进交付。
- 这一步能消掉大部分售后，比事后赔钱便宜得多。

**3. 交付环节控制二次损耗**
- 香蕉别冷藏、别堆压，单独放；菠萝竖放通风。自提点避免暴晒和闷热。
- 交付时口头/群公告提醒存放方式，约定"签收后24小时内、未切开可反馈"，超时或已切开的不受理（黑心除外，黑心凭切面图受理）。

**4. 售后规则写死、执行简单**
- 定标准：坏果率≤5%不赔或补小额；超过按个赔或补发；黑心菠萝、整把发黑香蕉凭图直接赔，不扯皮。
- 用"拍照+订单号"一个入口提交，团长当天处理，别让客户等。
- 每月算一次各品售后率，超过阈值的供应商换掉或降量——高损耗品的售后问题，八成是货源问题。

一句话：**香蕉控熟度和小份量，菠萝控熟度可见性和整果风险，瑕疵提前折价告知，售后只兜真正坏的那部分。**
