买香蕉的“熟度”主要看你打算**什么时候吃**。到店挑选时，用下面几步基本能避免太生或太熟。

1. **先定食用时间**
   - 当天/明天吃：买**全黄、带少量小褐点**的。
   - 2～3天吃：买**黄中带一点绿尖**的。
   - 3～5天吃：买**整体偏黄绿、棱角明显**的。
   - 想放一周：买**绿多黄少、硬实**的，回家常温催熟。

2. **看颜色，不只看黄不黄**
   - 太生：通体青绿、棱线很硬，吃起来涩。
   - 刚好：黄色均匀，果柄略绿，果身有弹性。
   - 偏熟：大面积黄、出现芝麻状褐点，适合当天吃。
   - 太熟：褐斑连片、果柄发黑、果身软塌，别买。

3. **摸果身和果柄**
   - 轻捏有弹性、不硬不软最好。
   - 果柄青绿说明还新鲜；果柄发黑、干瘪说明放久了。
   - 一捏就陷、表皮发皱，是过熟或失水。

4. **看棱角和表皮**
   - 棱角分明 = 偏生；棱角圆润 = 偏熟。
   - 表皮有破损、裂口、发霉点、明显压伤，不要。
   - 少量褐色芝麻点不是坏，是甜度高的信号；但大块黑斑、流汁就是坏了。

5. **按购买方式调整**
   - 只买一串当天吃：选黄带小褐点的。
   - 家庭分几天吃：买**一整串成熟度不一致**的，或买一把偏黄绿+一把全黄的。
   - 超市冷柜/空调风直吹处的香蕉容易表皮发黑，优先拿货架里侧、没有被压的。

6. **回家后别急着冷藏**
   - 未熟香蕉常温放，和苹果放一起可催熟。
   - 熟了就尽快吃；吃不完剥皮冷冻做奶昔。
   - 香蕉冷藏表皮会变黑，但果肉未必坏；想延缓成熟可等全熟后再冷藏。

一句话：**按“几天内吃完”选颜色，摸弹性、看果柄和棱角，少量褐点可以买，大块黑斑和软塌不要买。**
