社区团购旺季锁水果库存，核心不是“提前打个招呼”，而是把**预测、协议、定金、分级、备选**五件事同时做实。可以按下面步骤执行：

**1. 先做可承诺的销量预测，不要拍脑袋报量**
- 按单品、按周拆：过去同期销量 + 今年预售/团购接龙量 + 社群增长系数。
- 区分“确定量”和“弹性量”：例如确定要70%，另留30%作为浮动区间。
- 给供应商报“区间+周滚动更新”，比报一个虚高总量更容易拿到真实锁量。

**2. 与供应商签“锁量不锁价”或“锁量锁价+浮动条款”协议**
- 明确：品种、规格（果径/糖度/净重）、产地、包装、周供货量、最小起订量、到货时间。
- 价格条款建议：锁基础价+市场波动区间；或约定随行就市但设上限。
- 写清验收标准和不合格处理：烂果率、规格不符、延迟到货的扣款/补货/退货规则。

**3. 用定金/预付款换优先供货权**
- 对核心单品支付一定比例定金，换取旺季优先排产、优先采摘、优先装车。
- 定金对应“最低采购承诺”，但不要一次性把全年量压死，按周/按批次释放。
- 要求供应商提供“库存预留确认单”，写明预留数量、冷库位置、最晚提货日。

**4. 分级锁货，降低单一供应商风险**
- 主力供应商锁60%-70%，备选供应商锁20%-30%，再留10%机动从批发市场/产地直采补。
- 同一单品至少两家供应商，避免一家爆单或天气减产导致断供。
- 对易损耗水果（草莓、荔枝、樱桃）优先锁“近产地+冷链能力”，不要只看价格。

**5. 把物流和损耗责任前置写清**
- 明确谁承担运输损耗、冷链断链责任、到货时间窗口。
- 旺季要求供应商提供装车照片/视频、批次质检单。
- 约定“延迟到货2小时以上”的补偿或替代方案，避免团长端履约崩盘。

**6. 建立周滚动对账机制**
- 每周固定时间给供应商更新下周要货量，确认库存和装车计划。
- 用表格管理：单品、供应商、锁定数量、已付定金、最晚提货日、备选供应商。
- 对销售异常的单品及时调拨或转促销，避免锁了货卖不掉。

**可直接落地的动作清单：**
1. 今天列出旺季前4周 Top10 水果单品和预测区间。
2. 给每个单品找2家供应商，发“锁量协议模板”。
3. 对核心单品支付10%-20%定金，拿到书面预留确认。
4. 约定每周三更新下周要货量，周五确认装车计划。
5. 准备10%机动采购预算，防止临时缺口。

一句话：**用滚动预测报量、用定金换优先权、用协议写清验收和违约、用双供应商保底**，比单纯“提前说要货”有效得多。
