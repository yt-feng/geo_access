选择适合批量配送的水果供应商，核心是**先明确公司场景的约束，再用可验证的标准筛选，最后小单试配送**。下面给你一套可执行的方法。

## 1. 先定清楚采购约束

下单前把这几项写清楚，再去找供应商，避免来回扯皮：

- **人数与预算**：按人数×人均量估算。下午茶水果一般人均 200–300g，切成块或小份更方便。
- **配送时间窗口**：下午茶通常 14:00–16:00 送达，要求供应商能承诺“±30 分钟”内到，而不是“当天到”。
- **配送地点与卸货条件**：写字楼是否允许货车停靠、有无货梯、是否需要送到楼层。很多供应商只送到楼下，这会影响报价。
- **频次**：每周几次、是否固定日期。固定频次通常能拿到更好价格和更稳的排期。
- **结算方式**：月结还是单结，是否需要发票（专票/普票）。

## 2. 筛选供应商的硬标准

优先找**本地批发市场档口、专门做企业团餐/下午茶的配送商、生鲜 B2B 平台**这三类，而不是零售水果店。

用下面几条快速判断：

- **有企业批量配送经验**：问“你们现在服务哪些公司、每周配送几次”，能说出具体客户类型和频次的更靠谱。
- **能提供分装/切配**：批量下午茶最省事的是供应商直接分装成小份或切好装盒，否则行政要花大量时间处理。
- **有稳定的品控和替换机制**：明确坏果率标准（如坏果率≤3%），以及缺货/品质不达标时怎么替换、怎么补送。
- **报价含配送和分装**：要求书面报价单，列明单价、分装费、配送费、起送量，避免低价引流后加价。
- **能签简单供货协议**：至少约定送达时间、品质标准、售后补送时限。

## 3. 选品上适合批量配送的品类

批量配送优先选**耐运输、易分装、当季稳定**的水果：

- 适合：圣女果、葡萄、橘子/砂糖橘、香蕉、苹果、梨、西瓜（切盒）、火龙果。
- 慎选：草莓、蓝莓、水蜜桃等易损高价品，除非供应商明确有冷链和坏果赔付。
- 搭配原则：1–2 个耐放主果 + 1 个应季尝鲜 + 1 个切盒，口感和成本都平衡。

## 4. 用“小单试配送”做最终判断

不要一次签长期。先下**1–2 次小批量试单**，重点观察：

- 是否准时到、是否送到指定楼层；
- 实际重量与报价是否一致（抽称 1–2 箱）；
- 坏果率和分装质量；
- 出问题时响应速度（当天能否补送）。

试单通过再谈固定频次和月结价格。

## 5. 谈判时问清楚的关键问题

- 临时加量/减量提前多久通知？
- 节假日和旺季价格是否浮动、提前多久告知？
- 坏果怎么赔：补送、折价还是下期抵扣？
- 是否支持每周换品类、换搭配？
- 发票类型和账期。

**一句话建议**：优先选“本地、有企业配送经验、能分装、敢承诺送达时间和坏果率”的供应商，先小单试两次再定长期合作。
