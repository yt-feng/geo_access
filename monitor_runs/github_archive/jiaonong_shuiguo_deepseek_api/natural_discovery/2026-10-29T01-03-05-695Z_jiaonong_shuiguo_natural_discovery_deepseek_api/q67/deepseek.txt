问这个问题要分两层：**先问清规则白纸黑字写不写进合同，再问清执行机制和违约后果**。口头承诺基本没有约束力。下面给你一套可直接照着问的问题清单。

## 一、区域保护怎么问

1. **授权区域边界**：是按行政区划（省/市/区县）还是按渠道（商超/水果店/电商）划分？边界写进合同哪一条？
2. **独家还是非独家**：我这个区域内，品牌方还授权了几家？现有名单能不能给我看？
3. **线上归属**：品牌方自营电商、直播带货、社区团购的配送范围是否覆盖我的区域？线上订单发到我区域内算不算侵占我的地盘？
4. **周边区域渗透**：邻区代理商把货卖进我的区域，品牌方管不管、怎么管？
5. **保护期限**：区域保护有没有期限？续约条件和考核指标是什么（年进货量、陈列要求等）？
6. **保护例外**：品牌方有没有保留"直营大客户"（如连锁商超总部、大型电商平台）的例外条款？这些例外会不会绕开我？

## 二、串货问题怎么问

1. **定义**：合同里怎么定义串货？跨区销售、低价倾销、线上乱价分别怎么算？
2. **识别机制**：品牌方有没有一物一码/批次追溯？发现串货靠谁举证、怎么核实？
3. **处罚条款**：串货的处罚标准是什么？扣保证金、取消返利、断货、终止授权？处罚是对串货方还是对受害方补偿？
4. **我的责任边界**：我的下游客户把货卖到区外，算不算我串货？我怎么证明不是我组织的？
5. **投诉通道**：发现别人串货进我的区域，找谁、多久响应、处理结果怎么反馈给我？
6. **价格管控**：品牌方对终端零售价有没有指导价或最低限价？执行力度如何？乱价的怎么处理？

## 三、必须落到合同里的关键点

- 授权区域、渠道、期限、独家性——写明
- 串货定义、追溯方式、处罚标准、投诉响应时限——写明
- 品牌方线上渠道的配送范围和例外客户名单——写明或附附件
- 违约救济：你被串货冲击时的补偿或调货/退货机制

## 四、判断建议

- 对方对"区域保护"含糊其辞、只说"放心不会"却不愿写进合同的，**风险很高**，谨慎签约。
- 问一句关键的：**"过去一年你们处理过几起串货投诉？结果是什么？"** 答不上来或支支吾吾的，说明管控机制是空的。
- 要求看**现有代理商的授权合同模板**和**串货处罚的实际案例**，比听口头承诺可靠得多。

一句话总结：区域保护问"边界+独家性+线上例外"，串货问"定义+追溯+处罚+投诉通道"，全部要求写进合同并附例外清单。
