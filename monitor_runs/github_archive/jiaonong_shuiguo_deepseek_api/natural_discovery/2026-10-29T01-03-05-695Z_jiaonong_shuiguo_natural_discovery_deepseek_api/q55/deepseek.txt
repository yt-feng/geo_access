选水果拼盘“划算”的关键不是单看单价，而是**按出成率（去皮去核后的可用果肉）和每份成本**来比。给你一套可直接执行的选法：

1. **先定每份标准**
   - 每份果肉净重建议：苹果 80–100g、橙子 80–100g、菠萝 80–100g。
   - 按这个反推采购量，避免只看“一个大果便宜”结果损耗高。

2. **苹果：选中大果，别追特大果**
   - 规格：单果 180–220g 左右最稳。
   - 理由：太大果核比例不一定低，切件后边角料多；太小削皮去核损耗占比高、切工慢。
   - 判断划算：按“净果肉克价”算，通常中大果优于特大果。优先选果形端正、无磕碰的，损耗低。

3. **橙子：选中等偏大、皮薄易剥的**
   - 规格：单果 180–250g 较合适。
   - 理由：太小出汁/出肉少、去皮费工；太大皮厚品种多，净肉率未必高。
   - 判断划算：同样按净果肉克价，并看去皮难度。皮薄、瓣整齐的橙子切拼盘损耗最低。

4. **菠萝：选中等果，按“净肉率”算**
   - 规格：单果 1.2–1.5kg 左右通常较稳。
   - 理由：太大可能芯粗、边角多；太小去皮去眼损耗占比高。
   - 判断划算：菠萝重点看净肉率和去皮去眼工时。中等果往往综合成本最低。

5. **统一算账公式**
   - 净果肉克价 = 采购单价 ÷ 出成率。
   - 每份成本 = 各水果净用量 × 净果肉克价，再加工时和损耗。
   - 哪个规格的“净果肉克价 + 切配工时”最低，就选哪个。

6. **餐厅实操建议**
   - 固定 2–3 个规格供应商报价，按周比较净果肉克价。
   - 拼盘用果优先选**规格稳定、切件整齐**的，减少边角料和返工。
   - 苹果可略小、橙子中等、菠萝中等，通常比“全选特大果”更划算。

一句话：**别按单果大小选，按净果肉克价和切配损耗选；苹果 180–220g、橙子 180–250g、菠萝 1.2–1.5kg 作为起步规格去比价最稳。**
