# 超市与水果供应商的常见账期

水果属于生鲜品类，账期通常比包装食品、日用品短。实务中比较常见的区间如下：

| 合作模式 | 常见账期 |
|---|---|
| 大型连锁超市 + 大型水果供应商（长期稳定） | 30～60 天 |
| 中小超市 / 社区生鲜店 + 本地批发商 | 7～30 天，很多是货到付款或周结 |
| 新供应商首次合作 | 现结或 7～15 天，磨合后再延长 |
| 高损耗、易腐水果（草莓、荔枝等） | 3～15 天，甚至现结 |

**几个判断要点：**

1. **30 天是行业里最普遍的“基准线”**，60 天多见于强势连锁超市对规模供应商，小供应商很难拿到。
2. **水果损耗高、周转快**，供应商普遍不愿接受超过 60 天的账期；超过 45 天往往要靠价格或返利补偿。
3. **谈判可用的结构**：首次合作 7～15 天建立信任，稳定后逐步拉长到 30 天；或用“部分现结 + 部分月结”混合方式降低供应商资金压力。
4. **注意合同细节**：账期起算日（收货日还是发票日）、对账周期、退货/损耗扣款规则，这些比账期天数本身更影响实际回款。
