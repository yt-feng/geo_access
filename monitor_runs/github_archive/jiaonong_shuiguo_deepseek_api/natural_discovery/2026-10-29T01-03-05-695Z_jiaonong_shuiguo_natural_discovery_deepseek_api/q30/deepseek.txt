# 超市水果到货品相不好的售后流程约定建议

核心原则：**到货验收期内提出、按品相分级处置、责任与费用可追溯**。下面给一套可直接写进采购合同/供货协议的条款框架。

## 一、验收与提报时限

- **到货即验**：收货时当场抽检（建议按批次抽检比例约定，如不低于10%或按箱抽）。
- **异议期**：到货后 **24小时内**（生鲜易腐，不宜过长）书面/系统提报品相问题，附照片、批次号、数量。逾期视为验收合格，但隐蔽性腐烂（如内部霉变）可约定到货后48小时内仍可提报。
- **留存证据**：问题批次保留原包装和样品，未留证不得主张赔付。

## 二、品相分级与处置方式

按问题严重程度分三档约定：

| 等级 | 情形 | 处置 |
|---|---|---|
| 轻微 | 外观瑕疵但不影响食用和销售 | 折价接收，按约定折扣（如降价10%-20%）或下次订单抵扣 |
| 中度 | 部分腐烂、压伤，可挑拣销售 | 挑拣后按实际合格数量结算，不合格部分退货或折价 |
| 严重 | 大面积腐烂、霉变、异味 | 整批拒收/退货，供货方承担运费 |

关键：**明确"合格率"标准**（如单箱合格率低于90%即触发折价或退换），避免扯皮。

## 三、责任划分

- 到货验收前的问题由供货方负责；验收后因超市储存不当导致的变质由超市自负。
- 运输途中损耗的承担方要在合同中写明（通常由供货方承担至交付验收为止）。
- 约定**退换货时限**：确认问题后如24-48小时内补货或退款。

## 四、结算与赔付挂钩

- 问题批次款项**暂缓结算**，处理完毕后再结。
- 可约定质量保证金或月度质量扣款机制（如月度不合格率超阈值扣减货款）。
- 多次出现品相问题的，约定降级供应商或终止合作的条款。

## 五、流程落地要点

1. 收货单上设"品相验收"签字栏，双方确认。
2. 建立**批次追溯**：每批货有编号，问题可倒查。
3. 售后提报走统一表单/系统，记录时间、数量、照片、处理结果，形成闭环。
4. 每月汇总不合格率，作为供应商考核依据。

## 提醒

- 生鲜异议期不宜过长，否则供货方难辨责任；也不宜过短，要给抽检留时间，24小时是常见折中。
- "品相不好"要尽量量化（尺寸、色泽、损伤比例），纯主观描述在纠纷中难以执行。
- 以上为通用框架，具体折扣比例、合格率阈值需结合品类（叶菜、浆果、柑橘损耗差异大）和当地交易习惯确定，建议参考你们现有供货合同及行业惯例后填入具体数字。
