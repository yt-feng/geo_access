# 水果到货不合格的补货约定要点

核心思路：**把"不合格"的判断标准、补货时限、缺货期间的营业保障三件事提前写进采购合同或供货协议**，避免到货当天扯皮。

## 一、先约定"不合格"的客观标准

不要只写"质量不合格"，否则供应商会说"我觉得没问题"。建议按品类写明：

- **外观**：果径/单果重量区间、成熟度（几成熟）、无腐烂霉变、无明显机械伤、无虫眼
- **验收方式**：到货后X小时内完成抽检，抽检比例（如每批抽5%–10%）、以哪方检测为准
- **判定权**：明确"甲方（门店）验收结论为准，乙方有异议可在X小时内复检"

标准越具体，补货时越不容易被拖。

## 二、补货义务写成"三定"

| 要素 | 建议写法 |
|---|---|
| **定时限** | 不合格批次确认后，供应商须在24小时内（同城）补足合格货；急用品类（如鲜果茶常用水果）可压到12小时甚至当日达 |
| **定数量** | 补货数量=不合格数量+因缺货影响营业的备用量（可约定按不合格量的1.1–1.2倍补） |
| **定责任** | 补货运输费、加急费由供应商承担；二次补货仍不合格的，门店有权自行采购、差价由供应商承担 |

## 三、缺货期间不影响营业的保障条款

- **安全库存联动**：约定供应商需保持门店X天用量的常备库存，或门店自留1–2天应急库存，合同写明"应急库存由供应商按成本价补位"
- **替代方案**：允许门店在补货到位前，用同品类其他规格/产地水果替代出品，供应商不得以此主张违约（或约定替代差价结算方式）
- **先补后退**：不合格货先由供应商拉走或门店暂存，补货与退货同步进行，避免"退货等补货"两头空

## 四、写进合同的罚则（让条款有牙齿）

- 延迟补货按小时计违约金（如每延迟1小时扣该批次货款的X%）
- 一个结算周期内累计2–3次补货不及时，门店可单方终止合作并扣履约保证金
- 因缺货导致门店停售某款产品的，按日营业额损失约定赔偿上限

## 五、执行层面的三个动作

1. **到货即拍照留证**：开箱、抽检、称重全程录像/拍照，当天发供应商确认，形成书面记录
2. **验收单双方签字**：不合格数量、补货时限当场写清，避免口头承诺
3. **保留自行采购权**：合同里写明"供应商未按时补货，门店可自行采购，差价及加急费由供应商承担"，这是最实际的兜底

**一句话总结**：标准写细、时限压短、罚则跟上、留好自行采购的兜底权，补货就不会拖垮当天营业。
