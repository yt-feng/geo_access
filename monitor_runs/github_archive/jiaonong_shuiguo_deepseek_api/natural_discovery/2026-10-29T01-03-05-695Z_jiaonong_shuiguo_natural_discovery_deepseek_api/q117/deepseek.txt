建议先定一个“试卖批次”，而不是拍一个绝对数量。稳妥做法可以按下面几步判断：

1. **先算试卖量上限：按 3～7 天销量估**
   - 新品没有历史数据时，先按同类水果日均销量的 **30%～50%** 预估新品日销。
   - 试卖量 = 预估日销 × 试卖天数。
   - 保鲜期短的水果（莓果、葡萄、桃、荔枝等）建议 **3～5 天**；耐储水果（苹果、梨、橙等）可 **5～7 天**。
   - 首次采购量最好不超过 **正常单店 1 周销量的 50%**，避免压货。

2. **用“小批量、多批次”替代一次性大单**
   - 首单建议先拿 **1～2 个最小起订量/整箱**，比如先 2～5 箱试销。
   - 若供应商支持拆箱或小批量，优先小批量。
   - 首单卖到 **50%～70%** 时再补第二批，不要等卖完才补，也不要首单直接压满陈列。

3. **设明确止损线**
   - 到货后 **48～72 小时**观察动销：
     - 销量达到预估的 70% 以上：可补第二单；
     - 只有 40%～70%：维持小批量，调整陈列和试吃；
     - 低于 40% 或损耗明显偏高：停止补货，清库存。
   - 损耗率超过 **8%～10%**（短保水果可更严）就要重新评估。

4. **按门店规模给一个粗口径**
   - 单店小水果店/社区店：首单 **2～5 箱**或 **30～50 公斤**较常见，具体看单品单价和保鲜期。
   - 中型超市/多店采购：先选 **1～2 家门店**试卖，每店 1～2 箱，跑 3～7 天数据再铺开。
   - 高单价、小众新品：首单更小，宁可 **1 箱起试**。

5. **试卖前先和供应商确认**
   - 最小起订量、是否可混装、损耗/售后承担、补货周期、到货成熟度。
   - 最好争取“首单小批量 + 卖不动可调换/退货”的条件。

**结论：** 没有历史数据时，首单建议按 **3～7 天预估销量的 50% 以内**、且不超过 **1～2 个最小起订量**来试；短保水果取 3～5 天、耐储水果取 5～7 天。卖到一半左右再决定是否补货，并设 48～72 小时动销和损耗止损线。这样比直接定“多少箱”更稳。
