选食堂水果供应商，核心不是“找最便宜的”，而是先定标准、再验能力、最后用合同和小批量试供控风险。可以按下面步骤执行。

**1. 先定采购标准**
- **品类标准**：香蕉选成熟度可控、到货后2—3天能售完的；苹果选耐储、大小均匀、无明显磕碰；橙子选皮薄易剥或按用途定酸甜度。食堂要写清等级、单果规格、成熟度、允许坏果率。
- **验收标准**：每批抽检，坏果/烂果率建议控制在3%—5%以内，超限退换或扣款；香蕉避免过熟，苹果橙子避免冻伤、霉变。
- **配送要求**：固定频次，如每周2—3次；能按食堂用量分拣、称重、送货到库；临时加单的响应时间要写进合同。

**2. 供应商来源优先顺序**
- 本地农产品批发市场里有固定档口、能开票的经销商；
- 本地水果种植合作社或基地直供；
- 有学校、机关食堂配送经验的生鲜配送公司；
- 大型商超/生鲜供应链企业的团餐配送渠道。
优先选能提供营业执照、食品经营许可证、近期检测报告、配送车辆和仓储照片的。

**3. 重点核验四项能力**
- **稳定供货能力**：问清产地、旺季淡季替代方案，避免只靠一个产地。
- **品控能力**：是否有分拣场地、冷库或保鲜条件，坏果怎么赔付。
- **票据合规**：能否开增值税发票，能否提供批次检测或承诺书。
- **应急能力**：节假日前、天气异常时能否保供，缺货提前多久通知。

**4. 报价要比“综合成本”**
不要只比单价。让供应商按“到食堂含税含运费价”报价，同时算上损耗率、退换货成本、人工分拣成本。可以要求提供一周或两周的报价单，观察价格波动是否合理。

**5. 先小批量试供**
选2—3家各试供1—2周，重点记录：到货准时率、坏果率、规格一致性、临时补货响应、对账是否清楚。试供合格后再签季度或学期合同。

**6. 合同关键条款**
写明品名规格、单价及调价机制、送货时间、验收和退换标准、坏果扣款、食品安全责任、发票要求、违约和退出条款。调价机制建议约定“随行就市但需提前书面确认”，避免随意涨价。

**简单判断标准**：能稳定送货、坏果率低、票据齐全、出问题当天能补换的供应商，比报价最低但品控不稳定的更合适。食堂采购优先保食品安全和供应稳定，其次才是价格。
