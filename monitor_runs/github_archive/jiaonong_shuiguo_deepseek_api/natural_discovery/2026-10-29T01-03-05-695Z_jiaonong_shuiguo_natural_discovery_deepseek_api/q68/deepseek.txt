判断供应商能不能按时到车，不要只听口头承诺，要抓“可验证的履约证据”。给你一套批发商可直接用的判断方法：

1. **先看历史履约记录**
   - 优先选合作过、近3个月准时率高的供应商。
   - 让对方提供最近几次发货的“装车时间、车牌、发车照片/视频、到货时间”。
   - 新供应商要求给2—3个老客户电话，重点问“是否按约定时间到车、缺货怎么处理”。

2. **合同/订单写死时间节点**
   - 明确：装车截止时间、发车时间、预计到达时间、迟到赔付标准。
   - 不要只写“某日到”，要写到“几月几日几点前到车”。
   - 约定“迟到超X小时扣款/补差价/可拒收”，有约束才有效。

3. **装车前要求现场证据**
   - 装车当天要求发：装车现场视频、车牌号、司机电话、过磅单/装车单。
   - 视频里要能看到香蕉数量、包装、装车进度。
   - 发车后要求司机共享定位或定时报位置。

4. **看货源组织能力**
   - 问清楚：货是自有基地、固定档口，还是临时调货。
   - 临时调货型供应商迟到风险高；能明确说出“今天装哪车、谁装、几点发”的更靠谱。
   - 旺季、雨天、节假日要提前确认是否加车、是否压车。

5. **用“小单试履约”**
   - 新供应商先走一车小单或短途单，验证装车、发车、到车是否守时。
   - 连续2—3次准时再放大单量，不要一上来压大单。

6. **关键时间点主动核验**
   - 装车前1天确认货量；
   - 装车当天上午确认是否已装；
   - 发车后确认车牌和司机电话；
   - 预计到达前4—6小时确认位置。
   - 任何一环含糊，就要准备备用供应商。

7. **设置备选和止损**
   - 同一批次至少准备1家备用供应商。
   - 合同里写清：迟到超过约定时间，你有权调整价格、拒收或索赔。
   - 对经常“车在路上”“马上装”的供应商，降低合作等级。

一句话：**能按时到车的供应商，通常能提前给出装车视频、车牌、司机电话和明确时间点；只会口头保证、不给证据、临时调货的，风险最高。**
