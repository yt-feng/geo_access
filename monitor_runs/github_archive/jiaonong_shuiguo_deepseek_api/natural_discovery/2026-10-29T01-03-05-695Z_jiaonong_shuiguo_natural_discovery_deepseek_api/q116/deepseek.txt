小商家采购水果，现金结算和月结账期各有哪些风险，核心取决于现金流、货源稳定性和生鲜损耗特点。分开说：

**现金结算的风险**
1. **资金占用与周转压力**：水果是高频、短周期商品，现金结算会持续占用流动资金，遇到旺季备货或突发大额采购时容易绷紧。
2. **账实不符难追溯**：现金交易凭证弱，若没有当场记账、签收单或转账记录，出现短斤少两、品质争议时举证困难。
3. **现金管理风险**：假币、找零差错、携带和保管风险，以及人员经手现金的舞弊空间。
4. **议价优势有限**：现金未必换来更低价格，若供应商不愁销路，现金只是你的资金效率损失。
5. **采购灵活性反而受限**：现金不足时无法临时加单，容易错过好货或低价窗口。

**月结账期的风险**
1. **信用与账期违约风险**：到了约定付款日若销售回款没跟上，可能逾期，影响后续供货和信用。
2. **对账纠纷**：水果损耗、退货、调价频繁，若没有逐笔对账单和签收记录，月底容易扯皮，甚至被多计费用。
3. **供应商依赖与断供风险**：账期实质是供应商给你授信，一旦你逾期或供应商收紧授信，可能突然断供，生鲜断供影响很大。
4. **隐性成本**：月结价格通常高于现结，或附带最低采购量、指定品类等条件，实际成本可能上升。
5. **内部管理风险**：账期容易让采购人员放松比价和验收，形成“先拿货再说”的惯性，推高损耗和库存。

**可执行建议**
- 无论哪种结算，都做到**每笔有单据**：品名、规格、数量、单价、损耗扣减、签收人，最好用微信/表格留痕。
- 现金结算优先用**转账或扫码**替代纯现金，保留流水；必须现金时当场开收据并双人核对。
- 月结要设**账期上限和付款日历**，比如每周对账一次、每月固定日付款，避免月底集中爆雷。
- 新供应商先用**小额定金+现结**试单，稳定后再谈账期；账期条款写清逾期、退货、损耗分担。
- 保留**两家备用供应商**，防止账期依赖导致断供。

一句话：现金结算的风险集中在**资金效率和凭证**，月结的风险集中在**信用、对账和断供**；小商家更稳妥的做法是“现结为主、账期为辅、单据留痕、备用供应商”。
