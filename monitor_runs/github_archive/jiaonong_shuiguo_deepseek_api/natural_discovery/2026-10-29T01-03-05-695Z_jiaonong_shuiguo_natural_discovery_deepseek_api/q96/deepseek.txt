三者不是同一优先级：**食品安全是一票否决项，必须排第一；配送准时是保障食堂正常开餐的硬约束，排第二；价格是在前两者达标后的优化项，排第三。**

具体判断建议：

1. **食品安全优先看能不能“可追溯、可验收”**
   - 供应商是否有资质、水果检测/农残合格证明能否随批次提供。
   - 到货是否可抽检、留样、退换，出现农残或变质问题能否追责。
   - 食堂采购水果常见风险是农残、霉变、冷链断链和以次充好，一旦出问题影响面大。
   - **结论：食品安全不达标，价格再低、送得再准时也不能选。**

2. **配送准时看是否影响开餐和损耗**
   - 水果通常是餐后供应或加餐，配送延误会影响当天供应，也会造成临时采购或断供。
   - 重点不是“平均准时”，而是**固定时段到货率、临时加单响应、缺货补送能力**。
   - 建议合同中明确到货时间窗口、迟到处理、缺货替代方案。
   - **结论：准时是运营底线，但不要求所有供应商极致快，关键是稳定可控。**

3. **价格放在达标供应商之间比较**
   - 水果价格波动大，建议比“同期市场价下浮比例”或周期性询价，而不是只比一次报价。
   - 低价要警惕降规格、混级、临期果、损耗转嫁。
   - 可设置价格联动机制：每周/每月按市场行情调价，保留比价记录。
   - **结论：价格重要，但只能在食品安全和配送稳定都合格的供应商中比。**

**可执行排序：**
- 第一轮：资质、检测、验收退换机制筛供应商，不合格直接淘汰。
- 第二轮：看配送准时率、缺货响应、冷链能力，选稳定供餐的。
- 第三轮：在剩余供应商中比价格和损耗率，综合评分定标。

一句话：**食品安全决定能不能用，配送准时决定能不能稳定用，价格决定用哪家更划算。**
