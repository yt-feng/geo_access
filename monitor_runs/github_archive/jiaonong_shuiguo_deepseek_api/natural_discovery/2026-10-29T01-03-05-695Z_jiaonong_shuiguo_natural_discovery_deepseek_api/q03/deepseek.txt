第一次找供货商，建议把“试单”当成小批量验货+验服务，而不是先谈长期价。可以按下面做：

**1. 先定试单目标**
重点验4件事：  
- 到货品质是否稳定（熟度、大小、伤果率）  
- 报价是否含运费、卸货、损耗怎么算  
- 缺货/晚到/坏果怎么补  
- 结款方式（现结、周结、押账）

**2. 三家并行，小量试**
香蕉、苹果、橙子各找2～3家供货商，每家只试1～2箱/件，不要一次压太多。  
同一天或同一周拿货，方便对比。常见货毛利薄，别只看单价，要算“到店成本”：单价+运费+损耗+人工挑拣。

**3. 试单时明确写清标准**
- 香蕉：几成熟到店、每把/每箱净重、黑斑和断把比例可接受多少  
- 苹果：规格（如70/75/80果）、箱重、碰伤烂果率  
- 橙子：规格、皮厚薄、酸甜度、坏果率  
到货当场拍照、称重、记录坏果数，别等卖两天再扯皮。

**4. 首单控制量**
每样先拿1～2天销量，宁可第二天补，也别压货。夫妻店现金流紧，首单重点看“周转”不是“低价”。

**5. 观察供货商反应**
优先选：报价清楚、能说清产地/规格、坏果愿意补、送货时间稳定、临时加单能响应的。  
谨慎选：只报低价但不说净重、损耗不认、催款很急、送货总迟到的。

**6. 试单后做个小表**
记录：供货商、品项、单价、净重、运费、坏果率、到货时间、补货态度。连续试2～3次再定主供，最好保留一个备供。

**简单执行版：**
本周找3家，每家试香蕉1箱、苹果1箱、橙子1箱；到货称重拍照记坏果；卖3天看损耗和回头客反馈；第二次只给表现最好的1～2家加量。第一次别签长期独家，先月结或周结试稳。
