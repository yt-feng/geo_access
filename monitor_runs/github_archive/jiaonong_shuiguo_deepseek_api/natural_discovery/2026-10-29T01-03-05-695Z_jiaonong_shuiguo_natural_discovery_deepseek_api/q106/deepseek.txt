判断“合理波动”不能只看涨跌幅度，建议采购方建立一套可核验的对照体系，分四层判断：

**1. 先区分波动的类型**
- **季节性波动**：大宗水果有明确产季，换季、尾季价格上行属正常。
- **天气/灾害波动**：产地霜冻、暴雨、台风会导致短期跳涨，通常1-2周内回落。
- **成本推动**：油价、人工、包装、冷链运费变化，属可解释的渐进波动。
- **投机/信息差**：无产地事件却连续跳涨，或同一品种不同供应商报价差异过大，要警惕。

**2. 建立三组对照基准**
- **历史同期价**：对比去年同月、上月同期，看是否偏离季节性区间。
- **多源报价**：至少2-3家产地供应商+批发市场行情（如当地农产品批发市场公示价、大型批发市场日度报价），看是否只有一家在涨。
- **上游收购价**：了解产地收购价和代办费，倒推合理到货价，防止中间环节加价。

**3. 设定量化容忍区间**
按品类设阈值，例如：
- 日常波动±5%以内：直接接受；
- 5%-15%：要求供应商说明原因（产地、天气、运费）；
- 超过15%且无对应事件：暂缓下单，交叉询价。
阈值需按品类调整，叶菜、浆果波动天然大于苹果、柑橘。

**4. 用合同和流程固化判断**
- 报价单要求注明：产地、规格、等级、包装、运费、有效期。
- 约定价格调整需提前通知并提供依据（产地收购凭证、物流单据）。
- 保留每日报价台账，形成自己的价格曲线，3个月后就有可比基准。
- 对连续异常报价的供应商，启动比价或替换。

**实操建议**：先建一张“品种-季节区间-多源报价-异常阈值”的台账表，每天记录；遇到报价变动，先问“产地有没有对应事件”，再查“是否只有这一家在动”，两个问题就能过滤大部分不合理报价。核心原则：**有事件、有多源印证、在历史区间内的波动可接受；无依据、单方面、连续跳涨的要质询。**
