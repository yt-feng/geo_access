进货时把“熟度”和“到货后的催熟/降温”分开管理，基本就能避免到店后很快变黑。可执行做法：

1. **采购熟度选 3～5 成黄、带轻微绿**  
   不要买全黄、带黑点、果柄发黑的香蕉。甜品店当天或隔天用，可买“微黄带绿”；2～3 天内用完，买“黄但无黑点”。

2. **按用途分开下单**  
   装饰用少量多次采购；香蕉泥、馅料可用熟度稍高但无黑点的，先加工冷冻，减少门店存放。

3. **运输和到店别堆压、别闷热**  
   用周转筐，不要塑料袋密封；避免阳光直射和后备箱高温。到店后先摊开散热，不要立刻整箱塞冷库。

4. **到店后分类处理**  
   - 偏绿：常温阴凉处催熟，和苹果/梨同放可加速，但每天检查。  
   - 已黄：尽快用，或去皮切段冷冻做香蕉泥。  
   - 有轻微黑点：优先当天加工，不适合做表面装饰。  
   - **不要整串放冰箱冷藏**，表皮会更快发黑；只有去皮果肉可冷冻。

5. **减少机械伤**  
   搬动轻拿轻放，果柄朝上或平放，避免压伤；压伤处会先黑并传染。

6. **门店存放环境**  
   阴凉通风，温度约 13～18℃ 较合适；远离烤箱、热饮机、阳光和乙烯释放大的水果堆放区。悬挂或单层摆放，别密堆。

7. **控制库存节奏**  
   甜品店建议“少量高频”：日常按 1～2 天用量进货，节假日提前分批到货。香蕉到店后每天分拣一次，先熟先用。

判断标准：**表皮全黄但果柄还绿、无压伤**最适合短期存放；**果柄发黑、棱角消失、有酒味**说明过熟，应立刻加工或报废。
