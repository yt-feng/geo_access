判断一批香蕉，核心是“看颜色、摸硬度、查果柄和切口、抽样切开看心”，再结合季节、运输和存放条件判断坏果风险。下面是可直接执行的方法。

## 一、先判断熟度：看颜色+摸硬度

**1. 看果皮颜色（按蕉指中部颜色判断，不看果柄）**
- **全青、无黄**：生蕉，适合长途或催熟，不能直接卖。
- **青中带黄、黄占1/3~1/2**：适合批发后短期催熟或周转。
- **黄多青少、果尖略青**：接近可售，适合快批。
- **全黄、无青**：已熟，货架期短，适合就近快销。
- **出现褐色斑点（芝麻蕉）**：成熟度高，卖相和货架期下降，适合当天/次日清货。
- **大面积褐斑、发黑**：过熟或已开始坏，风险高。

**2. 摸硬度**
- 整体硬、按压无弹性：生。
- 轻按有弹性、不软塌：熟度适中。
- 按压明显下陷、发软：过熟，碰伤和腐烂风险高。
- 局部软烂：已有个别坏果，整批风险上升。

**3. 看棱角**
- 棱角明显、饱满硬挺：偏生。
- 棱角变圆、果身饱满：熟度上升。
- 果身明显失形、软塌：过熟或储存不当。

## 二、判断坏果风险：重点查这些部位

**1. 果柄和切口**
- 果柄青绿、切口新鲜：相对好。
- 果柄发黑、干枯、霉点：存放久或已感染，风险高。
- 切口有汁液渗出、发黏、异味：腐烂风险高。

**2. 果皮伤痕**
- 轻微擦伤可接受，但要看是否发黑扩大。
- 明显压伤、裂口、流汁、霉斑：容易在1~3天内扩散。
- 果尖发黑软烂：常见于过熟或冷害后腐烂。

**3. 果串内部和箱底**
- 抽中间和底层的蕉指，不要只看表层。
- 箱底有汁液、黏手、酒味/酸味：内部已坏，整批风险高。
- 包装纸或箱壁有水汽、霉点：湿度高，腐烂扩散快。

**4. 抽样切开**
- 随机抽3~5根，横切看果心。
- 果心发褐、发黑、空心、有异味：内部已坏或冷害/病害。
- 果肉局部透明、水渍状：碰伤或冻伤，货架期短。

## 三、按风险快速分级

- **低风险**：颜色青黄适中、果身硬挺、果柄青绿、切口新鲜、箱内干燥无异味。可正常批发，按计划催熟。
- **中风险**：已有少量黄斑、个别压伤、果柄略干。适合快进快出，减少压货，先卖风险高的。
- **高风险**：全黄带大面积褐斑、局部软烂、切口发黏、箱底有汁液或异味、切开果心发黑。不建议整批拿，除非能当场挑除坏果并当天清货。

## 四、结合条件判断

- **天气热、运输时间长**：熟度变化快，坏果扩散快，偏生一点更安全。
- **冷链或低温运输**：注意冷害，果皮发暗、果心发黑、果肉水渍状的要警惕。
- **已催熟货**：货架期短，必须问清催熟时间和存放温度。
- **堆放挤压**：底层和受压部位重点查，压伤后腐烂扩散快。

## 五、拿货时的实操建议

1. 不要只看表层，随机抽中层和底层。
2. 每箱抽2~3根摸硬度、看果柄。
3. 至少切开3~5根看果心。
4. 闻箱内有无酒味、酸味、霉味。
5. 对中高风险货，要求当场挑除坏果或降价，并约定坏果比例。
6. 拿货后先卖熟度高、风险高的，生蕉单独存放催熟，避免混放加速整体成熟。

一句话：**颜色看熟度，硬度和果柄看货架期，箱底和切开看坏果风险；偏生可周转，全黄带斑要快销，软烂流汁的不拿。**
