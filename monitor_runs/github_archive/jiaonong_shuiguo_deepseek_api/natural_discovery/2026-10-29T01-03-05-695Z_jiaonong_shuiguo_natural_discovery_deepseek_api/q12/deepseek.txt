采购菠萝时，熟度判断的核心是：**按“到店后还能卖几天”来定采购熟度，而不是越熟越好。** 菠萝损耗主要来自过熟、磕碰和切口腐烂，所以建议分档采购。

### 1. 采购时优先看这几个指标
- **闻底部香气**：有淡淡菠萝香即可；香气浓烈、发甜发酒味说明已过熟，适合当天卖，不适合囤。
- **按压果身**：轻按有弹性、不软塌。局部发软、出水、凹陷的不要。
- **看果皮颜色**：青绿转黄、黄色面积约1/3到1/2比较适合到店后卖2–3天；全黄甚至橙黄适合当天或次日卖。
- **看果眼**：果眼浅而平、分布均匀更好削；果眼深、发黑或渗汁的损耗大。
- **看底部切口/果心**：切口新鲜、干燥、无霉斑、无酸味。底部发黑、发软、有酒味的不要。
- **掂重量**：同等大小偏重的水分足；轻飘飘的可能失水或过熟。
- **看叶片**：冠芽鲜绿挺拔说明较新鲜，但叶片枯黄不一定是果肉坏，重点还是看果身和底部。

### 2. 按销售节奏分档采购
- **当天/次日主推**：选全黄、香气明显、轻按稍软的，少量多次补货。
- **2–3天销售**：选黄约1/3–1/2、底部微香、果身硬挺的。
- **3天以上或周转慢**：选青黄、香气很淡的，但不要选完全青硬、果眼深且无香的，后期可能成熟不均。
- **切开卖或做果切**：优先用全黄熟果，但必须当天处理；有酒味、底部发软的直接淘汰。

### 3. 控制损耗的采购动作
- **少量多次**：菠萝不是耐储水果，夏天尤其要缩短补货周期。
- **整批抽检**：每批随机闻底部、按果身、看切口，发现一箱有酒味或底部发软的，整批降级处理。
- **避免高温暴晒和挤压**：运输和店内陈列都要通风、阴凉，别堆太高。
- **分级定价**：全黄熟果当天做特价或果切，青黄果正常陈列，别等到坏了再处理。
- **记录损耗原因**：是过熟、磕碰还是切口霉变，下次采购直接调整熟度比例。

简单记：**要卖2–3天，选黄1/3到1/2、底部微香、果身硬挺的；当天卖，选全黄浓香的；有酒味、底部软、切口黑的不要。**
