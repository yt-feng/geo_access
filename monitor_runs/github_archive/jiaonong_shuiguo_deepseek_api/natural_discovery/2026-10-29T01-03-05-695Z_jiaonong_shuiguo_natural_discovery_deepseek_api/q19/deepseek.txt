这几个指标里，**最该优先关注的是切果损耗**，其次是甜度，再是大小，外观排最后。原因是超市卖菠萝和水果店卖整果不一样：超市通常有现场削皮/切块/装盒的加工环节，损耗直接决定毛利，而且菠萝损耗率不低。

具体判断顺序：

1. **切果损耗（第一优先）**
   - 看削皮后出肉率：好货出肉率通常在 55%–65% 左右，低于 50% 基本不赚钱。
   - 看黑心、水心、烂芯比例：这是菠萝最大的隐性损耗，外观好看也可能切开才发现。
   - 看切口氧化和货架期：切盒后卖相掉得快，损耗会继续放大。
   - 建议把“到货抽切开验芯”作为固定动作，别只看外表。

2. **甜度（第二优先）**
   - 超市散客复购靠口感，酸涩的菠萝切盒也卖不动。
   - 不用追求极高糖度，但要稳定；可要求供应商提供批次糖度或到货抽测。
   - 甜度不稳会导致试吃转化差、退货和口碑损失。

3. **大小（第三优先）**
   - 大小影响定价和切盒规格，但不是核心。
   - 大果适合整果促销，中小果适合切盒；关键是规格统一，方便定标准和控损。
   - 大小不均会增加分拣和加工成本。

4. **外观（最后，但非不重要）**
   - 外观决定第一眼购买欲，属于“引流项”，不是“盈利项”。
   - 外观好但芯坏的菠萝反而制造更大损耗，所以外观不能单独作为收货标准。

**可执行建议：**
- 收货标准写成三项硬指标：抽切开芯合格率、出肉率下限、糖度下限。
- 外观只做门槛项：无严重机械伤、无霉变、果形正常即可。
- 切果损耗高的批次，宁可降价快销或转整果处理，不要硬切盒。

一句话：**超市卖菠萝，先保出肉率和芯不坏，再保甜度稳定，大小和外观服务于陈列和定价，不能反过来。**
