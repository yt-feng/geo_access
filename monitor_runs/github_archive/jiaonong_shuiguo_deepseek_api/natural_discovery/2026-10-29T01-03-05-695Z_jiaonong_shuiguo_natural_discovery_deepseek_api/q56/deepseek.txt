茶饮店控制水果供应商风险，核心是“资质证明+检测证明+追溯与验收记录”三块。建议要求供应商提供或留存以下材料：

1. **主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按供应商实际业态）
   - 仅销售食用农产品时，至少核验营业执照和供货者身份信息；若供应商声称有许可证，应留存复印件并核对经营范围。

2. **产品合格与检测证明**
   - 水果的出厂检验报告或供货商自检报告
   - 农药残留检测报告：优先要第三方检测报告；至少按批次或定期提供，报告日期、品种、批次要与进货对应
   - 进口水果：海关入境货物检验检疫证明、报关单等
   - 若为预包装鲜切水果：还需产品标签、保质期、生产日期、执行标准及相应检验报告

3. **追溯与交易凭证**
   - 每批进货的送货单/发票/收据，注明品种、数量、批次、日期、供应商
   - 产地证明、种植基地信息或合作社供货证明（能做则更好）
   - 供应商联系人、联系方式及质量承诺/食品安全协议

4. **储运与验收证明**
   - 冷链运输温度记录（需冷藏的水果）
   - 到货验收记录：感官检查、温度、包装完整性、农残快检记录（如有）
   - 不合格品退换货记录

**可执行建议：**  
首次合作做供应商准入审查，收齐营业执照、许可证、检测报告和供货协议；之后每批留存送货凭证和验收记录，农残检测报告按月或按品种轮换索取。对无法提供检测报告或批次追溯的供应商，不建议纳入常规采购。
