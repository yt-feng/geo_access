压低成本但不掉品质，核心不是“把价砍下来”，而是**把价格谈在可验证的品质标准上**。做法可以分成四步：

1. **先定品质底线，再谈价**
   谈之前把验收标准写清楚：品种/产地、规格（单果重、果径）、成熟度、糖度、外观缺陷率、农残检测、到货温度、损耗率上限、包装规格。  
   谈判话术可以直接说：“价格可以谈，但糖度不低于X、次果率不超过X%、到货损耗超过X%由供方承担。”这样压价压的是供方利润和流通效率，不是品质。

2. **用“分级采购+动态返利”代替一刀切压价**
   不要只谈一个最低价，容易逼供方以次充好。可以：
   - 主推款按稳定量谈年度框架价；
   - 次果/小果单独分级定价，做促销或加工；
   - 设置季度返利：达到销量、损耗率、到货合格率后返点。  
   供方有量、有回款预期，才愿意让价。

3. **把成本压力转到非价格条款**
   直接砍价空间有限时，谈这些更有效：
   - 账期缩短换价格折扣；
   - 自提/集中配送降低物流费；
   - 指定包装简化、周转筐替代纸箱；
   - 淡季锁量、旺季优先供货；
   - 损耗分担：到货验收不合格按比例扣款或补货。  
   这些条款往往比硬压单价更可持续。

4. **用数据和竞争报价谈，不靠情绪压价**
   准备同品质竞品报价、历史采购价、市场批发价、损耗数据。谈判时说：“同规格同糖度，A供方报价低X%，但你的到货损耗低，我愿意给稳定单量，价格能否到X？”  
   同时保留2家以上合格供方，但不要频繁换低价供方，否则品质波动和隐性损耗会吃掉差价。

**判断标准**：如果谈下来的价格明显低于市场同品质均价，却不愿写清验收标准和损耗责任，大概率会在品质上找回来。真正健康的压价是：单价降一点、损耗降一点、账期和物流省一点，综合到岸成本下降，而不是只看采购单上的数字。
