出汁率更重要，甜度是次要且可调的。

**判断依据：**
- 菠萝在茶饮里通常不是“纯吃甜”，而是提供酸香、果香和口感；甜度不够可以用糖浆/果葡糖浆补，出汁率低则直接意味着原料成本高、风味提取少、损耗大。
- 出汁率低还会带来操作问题：切果、捣压、榨汁出品率低，单杯用量上升，门店备料和废弃率都变差。
- 甜度高但出汁率低的菠萝，往往果肉纤维粗或成熟度不均，做果茶口感不一定好。

**可执行标准：**
1. 先看出汁率：同价位下优先选出汁率高的品种/批次，至少做小样压榨对比“每公斤出汁毫升数”。
2. 甜度设底线：可溶性固形物（Brix）达到你产品配方需要的基础范围即可，不够用糖调。
3. 兼顾酸度：茶饮里菠萝的酸香很关键，纯甜反而容易腻；选酸甜平衡、香气足的批次。
4. 如果做“鲜果肉”类产品，再看果肉纤维和香气；如果做果酱/糖浆基底，甜度权重可略升，但出汁率仍优先。

**例外情况：** 若你的产品定位是“高甜鲜果、不加糖浆”，或菠萝只做装饰/小料且用量极少，甜度权重才可能超过出汁率。否则，采购决策应优先出汁率。
