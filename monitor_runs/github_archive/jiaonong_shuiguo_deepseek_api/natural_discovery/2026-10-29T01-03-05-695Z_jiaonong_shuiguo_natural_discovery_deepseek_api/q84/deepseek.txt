家庭团购水果礼盒，建议按“耐放程度 + 食用场景 + 成本”来组合。比较适合家庭的方案是：

**推荐组合：苹果 4 + 橙子 4 + 香蕉 1把 + 菠萝 1个**
- **苹果、橙子**耐放，适合家庭日常吃，也撑礼盒体积。
- **香蕉**适合早餐、孩子加餐，但熟得快，建议单独装袋、少放。
- **菠萝**作为“大件”提升礼盒价值感，适合周末家庭一起吃。

**更稳妥的家庭版比例：**
- 苹果 40%
- 橙子 30%
- 香蕉 20%
- 菠萝 10%

也就是：**苹果和橙子占七成，香蕉和菠萝占三成**。这样耐储存、不易坏，家庭复购更稳。

**按家庭人数调整：**
- **2-3人家庭**：苹果4、橙子4、香蕉1把、菠萝1个，总重约5-6斤。
- **4-5人家庭**：苹果6、橙子6、香蕉1把、菠萝1个，总重约8-10斤。
- **有老人小孩**：香蕉可略多，但香蕉要选稍青的；菠萝建议选小果，避免一次吃不完。

**避坑建议：**
1. 香蕉不要和苹果、橙子混放，苹果释放乙烯会催熟香蕉，最好分袋。
2. 菠萝带皮整只更耐放，但礼盒里要留空间，避免压伤。
3. 家庭团购优先选“中等果”，不要一味追求大果，大果单价高、家庭一次吃不完。
4. 礼盒内加一张“存放顺序”小卡：先吃香蕉和菠萝，苹果橙子后吃，体验更好。

**结论：** 家庭团购最推荐 **苹果+橙子为主，香蕉少量点缀，菠萝1个提档次**；比例控制在 **7:3** 左右，既耐放又实用。
