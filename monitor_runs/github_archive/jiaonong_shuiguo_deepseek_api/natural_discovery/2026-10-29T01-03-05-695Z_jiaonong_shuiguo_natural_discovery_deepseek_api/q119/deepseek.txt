水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格”和“有没有货”，而是下面这些会决定损耗、复购和现金流的细节：

1. **同一等级标准是否稳定**
   最容易只看“今天这批不错”，忽视对方是否能长期按同一糖度、规格、成熟度、瑕疵率供货。要问清分级标准，并连续抽几批对比，不是只看样品。

2. **产地与季节切换能力**
   只盯一个产地或一个单品，旺季没事，淡季或减产就断供。要看供应商是否有替代产区、替代品种，以及换产地时品质能否衔接。

3. **采后处理与冷链细节**
   问清采摘时间、预冷是否及时、运输温度、周转筐卫生、是否混装催熟水果。很多损耗不是卖出来的，是采后和运输环节埋下的。

4. **真实损耗责任怎么分**
   合同里最容易漏：到货腐烂、压伤、规格不符、重量短缺谁承担，多久内反馈有效，怎么补货或扣款。不要只听口头“包售后”，要落到可执行条款。

5. **供货高峰期的履约能力**
   节假日、爆单时能不能按时按量到货，比平时报价更重要。要看对方车辆、冷库、分拣人手，以及同时服务多少客户。

6. **账期与资金占用**
   低价现结和略高价月结，实际成本不同。要算账期、押金、退换货周期对现金流的影响，避免被低价吸引后资金被库存拖住。

7. **票据与合规**
   长期做要关注对方能否稳定开票、是否有经营资质、农残检测或产地证明是否可提供。小店容易忽视，但做大或进商超、团购渠道时会卡住。

8. **信息透明度**
   是否愿意让你看分拣现场、冷库、装车过程；出问题时是否如实说明产地减产、批次差异。长期合作最怕“每次都说没问题”，最后损耗全由你承担。

9. **小批量试单和连续跟踪**
   不要一次压大单。建议至少连续 3—5 批小单，记录到货损耗率、规格合格率、售后响应时间，再决定是否放量。

10. **退出机制**
    合作前就约定质量连续不达标时如何终止、尾款和库存怎么处理。很多水果商被“熟关系”绑住，发现问题也不敢换供应商。

可执行建议：建一个供应商评分表，固定记录“到货损耗率、规格合格率、准时率、售后响应、账期成本”五项，连续两个月打分；新供应商先小单试 3 批，再给主推单品。长期稳定靠的是可复验的标准和可执行的退换货机制，不是单纯压低进价。
