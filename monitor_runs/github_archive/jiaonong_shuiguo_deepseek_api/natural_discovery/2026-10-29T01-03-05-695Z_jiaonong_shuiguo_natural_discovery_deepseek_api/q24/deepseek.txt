建议优先向供应商要“可核验、能对应到批次”的资料，而不是只要一张泛泛的承诺书。可要求：

1. **每批次的检测报告**
   - 农药残留检测报告，最好由具备资质的第三方检测机构出具；
   - 报告要能对应到：供应商名称、水果品种、产地、采收/生产日期、抽样日期、检测项目、检测结果和报告编号；
   - 注意报告是否覆盖你采购的**具体批次**，避免用旧报告或通用报告替代。

2. **产地证明或供货证明**
   - 产地证明、种植基地信息、合作社/农户供货证明；
   - 能说明水果来源，便于出问题时追溯。

3. **供应商资质材料**
   - 营业执照；
   - 食品经营许可证或相关许可；
   - 若供应商是种植基地直供，可要求基地资质、种植管理记录等。

4. **承诺书/质量保证协议**
   - 供应商对农残符合国家标准的书面承诺；
   - 最好在采购合同中约定：抽检不合格的退换货、检测费用、违约责任和赔偿条款。

5. **进货查验和追溯记录**
   - 要求供应商提供随货同行单、批次号、发货日期、数量；
   - 超市自己保留进货台账、供应商资料和检测报告，做到“一批一档”。

6. **高风险品种加做抽检**
   - 对叶菜、草莓、葡萄、豇豆等农残风险相对较高的品种，可要求更高频次的检测报告，或超市自行送检/快检。

实操上，最关键是：**报告要真、批次要对得上、来源能追溯、合同有责任条款**。如果供应商只能提供模糊承诺或无法对应批次的报告，应谨慎采购。
