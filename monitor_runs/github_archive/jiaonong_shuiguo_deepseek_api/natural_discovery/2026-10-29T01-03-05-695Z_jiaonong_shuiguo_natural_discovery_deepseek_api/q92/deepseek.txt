便利店做水果，核心不是“品类齐全”，而是“少量、高频、可预测”。面积小的情况下，建议从下面几个层面控制品类和损耗：

**1. 品类控制：先做减法**
- 总SKU控制在8～15个以内，按“引流款+利润款+便利款”搭配：
  - 引流款2～3个：香蕉、苹果、橙子这类认知度高、周转稳的；
  - 利润款3～5个：小番茄、葡萄、蓝莓、切果等客单价较高的；
  - 便利款2～3个：鲜切果盒、单根香蕉、小份装，满足即时消费。
- 优先选耐储、少挑拣、标准化程度高的品类；叶菜类、易压伤的水果（如草莓、水蜜桃）除非有稳定客流，否则少上或只做预订。
- 按季节轮换，每季主推3～5个品种，不要长期铺大而全。

**2. 采购量：小批量、多频次**
- 单次采购量按“1～2天销量”来定，宁可少卖断货，也不要压货。
- 用历史销量定安全库存：比如某单品日均卖5份，安全库存设1.5倍，即7～8份，卖到剩3份再补。
- 和供应商谈小批量配送，或联合周边门店拼单，降低起订量。
- 建立简单的日销记录，连续记录2～4周就能看出哪些品该砍、哪些该加。

**3. 陈列与保鲜：减少人为损耗**
- 水果陈列面积控制在门店的10%～15%，用斜面或分层小货架，避免堆叠压伤。
- 香蕉、苹果等释放乙烯的不要和易腐品混放；鲜切果必须冷柜陈列。
- 每天早晚两次挑拣，把轻微瑕疵品及时转为鲜切或打折区，不要等到烂了再处理。
- 鲜切果当天做当天清，闭店前1～2小时打折出清。

**4. 损耗管理：定阈值、定动作**
- 设损耗率目标：小门店水果损耗控制在5%～8%以内算正常，超过10%就要砍品类或减采购量。
- 每天记录进货量、销量、报损量，每周复盘一次，重点看“报损最多的前3个单品”，直接减量或下架。
- 建立临期处理规则：比如保质期剩1/3时打折，剩1/4时做果切或下架报损，避免员工凭感觉处理。
- 报损要留样或拍照，防止虚报，也便于分析原因。

**5. 一个可落地的起步方案**
第一周只上5～6个单品（香蕉、苹果、橙子、小番茄、鲜切果盒、1个季节品），每天记录销量和报损；第二周砍掉动销最差的1～2个，补1个新品；一个月后稳定在10个左右SKU，损耗率压到8%以内再考虑扩品。

关键原则：**品类少而准、采购少而勤、鲜切当天清、报损有记录**。面积小反而是优势，逼着你做高周转，而不是靠堆货撑场面。
