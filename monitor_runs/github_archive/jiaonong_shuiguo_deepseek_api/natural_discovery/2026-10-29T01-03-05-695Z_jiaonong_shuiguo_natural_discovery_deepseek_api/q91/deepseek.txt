优先选 **小把（3～5根）为主，单根做补充，整袋只做少量试探**。便利店卖香蕉的关键不是“规格越全越好”，而是损耗可控、购买场景匹配。

可执行建议：

1. **主推小把装 3～5 根**
   - 最适合便利店场景：一个人吃几天、两个人分着吃、顺手买。
   - 客单价高于单根，但不像整袋那样一次买太多。
   - 建议定价按“把”标价，避免称重排队。

2. **单根作为引流和补充**
   - 适合“只想吃一根”、搭配早餐、临时购买。
   - 毛利低、人工分拣多，但能降低顾客尝鲜门槛。
   - 建议只放少量，放在收银台附近或早餐搭配区。

3. **整袋装谨慎上架**
   - 适合家庭客群或社区型便利店，但普通写字楼/街边店容易滞销。
   - 整袋香蕉成熟度不一致时，顾客挑拣会导致损耗上升。
   - 若上架，建议小袋装、明确总价、控制数量，并做“整袋略优惠”引导。

4. **按门店位置调整**
   - 社区店：小把 + 少量整袋。
   - 写字楼/学校/地铁口：单根 + 小把为主。
   - 景区/交通枢纽：单根更好卖，方便即食。

5. **控制损耗的配套动作**
   - 香蕉按成熟度分区：偏青、适熟、即食。
   - 即食香蕉放收银台，小把放端架，整袋放果蔬区。
   - 每天晚高峰后把过熟香蕉做搭配促销或及时下架，不要硬撑到第二天。

结论：**默认组合是“小把为主、单根补充、整袋少量试点”**。先试 1～2 周，看动销和报损，再决定是否扩大整袋。
