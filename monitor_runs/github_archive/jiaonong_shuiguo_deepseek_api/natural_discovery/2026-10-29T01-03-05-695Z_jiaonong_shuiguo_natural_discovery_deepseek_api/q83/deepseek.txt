先给结论：坏果投诉不能一律算顾客责任，也不能一律由平台兜底，核心看**坏果发生的时间点、可见程度、举证情况和承诺条款**。责任通常分四层：供应商/产地、仓储分拣、配送、顾客售后保管。实操上建议“先赔付顾客、再内部定责”，对外不要让顾客承担举证过重的成本。

**一、对外对顾客的责任判断（可执行）**

1. **签收前或开箱即见坏果**：一般由商家/平台承担。生鲜属于易腐品，到货验收时发现腐烂、压伤、霉变，通常按“坏果包赔/售后”处理。
2. **隐蔽性坏果（外观正常、切开才发现）**：在合理售后时效内（常见24—48小时，以页面承诺为准），商家应承担；但顾客需提供坏果照片、订单和开箱/切开证据。
3. **顾客自身保管不当**：如延迟取货、未冷藏、暴晒、超时未开箱导致变质，责任向顾客倾斜；但商家需证明已按约定方式配送且有明确提示。
4. **轻微外观瑕疵不影响食用**：可按协商补偿处理，不宜直接认定为全损。
5. **恶意索赔或明显调包**：商家可要求补充证据并拒绝超额赔付，但应有明确规则，不能随意扣“顾客责任”。

**二、内部责任划分（平台/商家内部）**

- **产地/供应商**：采摘成熟度不当、带病果、预冷不足、包装不合格，承担主要责任；可按批次抽检、到货验收记录追责。
- **仓储分拣**：未剔除坏果、混装、磕碰、冷链断链，由仓储分拣承担。
- **配送环节**：暴力分拣、延误、未冷链、未按要求放置，由配送方承担。
- **顾客端**：超时取货、保管不当，由顾客承担相应部分。

**三、建议的判定流程**

1. 顾客提交订单、坏果照片/视频、开箱时间。
2. 客服按“坏果比例+是否隐蔽+售后时效+配送记录”快速定损。
3. 优先按比例赔付或补发，避免争议升级。
4. 内部按批次和环节追责，不把内部责任转嫁给顾客。
5. 对高频投诉批次做抽检和下架，防止重复投诉。

**四、关键证据**

订单和页面售后承诺、配送签收时间、冷链记录、到货验收单、分拣记录、顾客开箱照片/视频、客服沟通记录。

一句话：**对外以“到货状态+合理时效+证据”定责，对内按“产地—仓储—配送—顾客”分段追责；顾客无明显保管过错的，坏果损失不应由顾客承担。**
