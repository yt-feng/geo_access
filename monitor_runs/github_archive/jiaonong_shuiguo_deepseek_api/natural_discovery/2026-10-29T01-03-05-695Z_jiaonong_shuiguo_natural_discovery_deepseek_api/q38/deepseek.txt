大型超市对水果供应商的要求，核心是“食品安全可追溯 + 冷链不断链 + 稳定供货 + 可追责”。可按以下能力清单判断和准备：

## 一、食品安全能力

1. **合法资质与产品合规**
   - 营业执照、食品经营/生产相关许可（按业态）
   - 食用农产品承诺达标合格证或产地证明
   - 农药残留检测报告；高风险品种按超市要求批批检或定期检
   - 进口水果需入境货物检验检疫证明等合规文件

2. **产地与投入品管理**
   - 有固定基地或稳定合作基地，能提供产地信息
   - 农药、化肥等投入品采购和使用记录
   - 遵守安全间隔期，禁用农药清单管控
   - 采收前农残自检或委托检测

3. **检测能力**
   - 自建快检室或委托第三方检测
   - 能按品种、季节、产地做农残快检
   - 检测记录可保存、可调取，异常批次能隔离处置

4. **追溯体系**
   - 批次管理：产地—采收—加工—仓储—配送—门店可追溯
   - 每批货有批次号、检测信息、出入库记录
   - 出现问题能快速召回、定位同批次

5. **加工与包装卫生**
   - 分选、清洗、包装场所卫生管理
   - 人员健康证、洗手消毒、工器具清洁
   - 包装材料符合食品接触要求
   - 防虫防鼠、防交叉污染

6. **质量与腐败控制**
   - 收货标准：糖度、硬度、色泽、规格、缺陷率
   - 腐烂、霉变、机械伤分级处理
   - 先进先出，临期和异常品隔离

7. **食品安全管理制度**
   - 进货查验、索证索票、台账记录
   - 不合格品处置和召回制度
   - 食品安全责任人和应急预案
   - 最好有ISO22000/HACCP或类似体系认证（非绝对必需，但是加分项）

## 二、物流与供应链能力

1. **冷链能力**
   - 预冷：采后尽快预冷，尤其是浆果、叶菜、热带水果需分温区
   - 冷藏车/保温车，具备温控记录和异常报警
   - 分温区仓储：不同水果适宜温度不同，不能混放导致冷害或催熟
   - 全程温度记录可导出，能随货或按批提供

2. **仓储与分拣**
   - 通风、温湿度可控的仓库
   - 防挤压、防日晒雨淋、防交叉污染
   - 分拣线或分区作业，避免机械伤
   - 库存周转和批次管理能力

3. **配送时效**
   - 能按超市门店/DC要求定时定点配送
   - 具备多门店配送路线和应急补货能力
   - 高峰期、节假日保供方案
   - 到货准时率和破损率可控

4. **包装与装载**
   - 周转筐/纸箱适配品种，防压防震
   - 装载方式避免堆压、通风不良
   - 运输工具清洁消毒记录

5. **信息化与单据**
   - 订单、库存、批次、检测报告电子化
   - 送货单、检测报告、温度记录随货可查
   - 能与超市系统对接或有规范的对账单据

6. **应急与召回**
   - 断链、温控异常、检测不合格的处置流程
   - 批次召回演练或记录
   - 缺货替代方案和备用产地/物流资源

## 三、超市通常会重点核验的材料

- 营业执照及相关许可
- 产地证明/合格证、检测报告
- 批次台账和追溯记录
- 冷链温度记录
- 从业人员健康证
- 供货合同中的食品安全责任、召回、赔偿条款
- 现场审核：仓库、分拣场、冷链车辆、检测环节

## 四、判断供应商是否合格的关键问题

可以直接问供应商：
1. 这批货的产地、批次、检测报告能否立即提供？
2. 采后多久预冷？运输和仓储温度记录能否按批导出？
3. 出现农残超标或温控断链，多久能召回同批次？
4. 高峰期日供应能力和备用基地是什么？
5. 分拣场、冷库、车辆最近一次自查或审核记录？

**结论：**大型超市水果供应商至少应具备“合规资质+产地/批次追溯+农残检测+分温区冷链+温控记录+稳定配送+召回处置”七项硬能力；体系认证、自建检测室、信息化对接是重要加分项。
