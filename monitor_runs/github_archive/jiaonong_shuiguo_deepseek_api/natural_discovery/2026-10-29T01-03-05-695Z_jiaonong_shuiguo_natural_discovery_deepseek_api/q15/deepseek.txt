水果店遇到坏果，结算和赔付的关键是：**先分清责任和货物状态，再按合同/约定处理；没有明确约定时，按行业惯例和证据协商。** 可执行做法如下：

1. **到货当场验货**
   - 坏果、烂果、压伤、霉变、规格不符，当场拍照/录像，保留送货单、批次、筐号、称重记录。
   - 能当场挑出的，直接分拣：合格品收货，坏果拒收或单独过秤记录。
   - 送货单上注明“坏果X斤/箱，待处理”，双方签字确认，避免事后扯皮。

2. **分清坏果原因**
   - **到货即坏、运输损伤、成熟过度、霉变**：一般由供应商承担，可拒收、换货、补货或按坏果数量扣款。
   - **店内存放不当、挤压、过期未售**：通常由水果店自己承担，不能要求供应商赔。
   - **隐性坏果**：如外表正常、切开内部腐烂，应在约定异议期内及时反馈，保留开箱证据，按约定比例赔付。

3. **结算方式优先看合同/口头约定**
   - 有合同：按合同里的验收标准、损耗率、赔付比例、账期扣款条款执行。
   - 无合同：按双方长期交易习惯，常见做法是：
     - 坏果部分不计价，从当批货款中直接扣除；
     - 换货补货，下一车补回同等数量；
     - 按坏果金额的约定比例赔付，如全赔或承担部分；
     - 整批质量严重不合格的，整批退货，运费和损耗由责任方承担。
   - **不要默认“整批全赔”或“一律扣30%”**，应按实际坏果数量和责任划分。

4. **保留证据再谈赔付**
   - 送货单、过秤单、坏果照片视频、聊天记录、退货单、开箱视频。
   - 最好让供应商在坏果清单上签字确认；对方不签，就用微信/短信发送“本批坏果X斤，请在X小时内确认，否则按此扣款”，保留送达记录。

5. **结算扣款要写清楚**
   - 对账单上单独列明：本批货款、坏果扣款、换货补货、上次遗留赔付。
   - 扣款前先与供应商确认，避免单方面扣款引发断供或纠纷。
   - 大额或长期合作，建议补一份简单书面约定：验收时限、坏果标准、赔付比例、异议期。

6. **争议处理**
   - 先协商；协商不成，可找批发市场管理方、行业协会调解。
   - 保留证据走合同约定或法律途径，但水果易腐，**优先快速分拣、及时处理**，避免损失扩大；扩大部分通常难以要求对方承担。

一句话总结：**合格品正常结算，坏果按实际数量和责任方扣款/换货/补货；当场验货、书面确认、对账单列明，是最稳妥的结算方式。**
