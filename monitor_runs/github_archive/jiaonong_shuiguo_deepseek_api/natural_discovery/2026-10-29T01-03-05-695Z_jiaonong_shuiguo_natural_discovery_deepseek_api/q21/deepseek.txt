超市采购水果时，供应商通常需要提供以下资料。具体以当地市场监管部门要求和超市内部验收制度为准，以下为通用清单：

**一、主体资质证明**
1. 营业执照（经营范围含水果销售/农产品销售）
2. 食品经营许可证（若涉及预包装或分装销售；仅销售初级食用农产品通常可豁免，但各地执行有差异，建议向属地市场监管所确认）
3. 供货商为生产合作社/基地的，提供产地证明或基地备案材料

**二、进货凭证**
1. 进货票据/送货单：注明品名、规格、数量、产地、供货商名称及联系方式、日期
2. 购销合同或采购订单
3. 上游供货商的经营资质复印件（批发市场档口、经销商等）

**三、质量与安全检测报告**
1. **农药残留检测报告**：最常见。可为供应商自检报告、第三方检测报告，或产地/批发市场的快检合格凭证。大型超市通常要求每批次或定期提供
2. **第三方检测报告**：针对农残、重金属等项目的型式检验报告，一般按品种或产地定期更新（如半年/一年）
3. **产地准出证明**：部分农产品主产区实行产地准出制度，附合格证
4. **承诺达标合格证**：食用农产品生产者/收购者开具，是当前监管推行的常见凭证

**四、进口水果额外资料**
1. 海关入境货物检验检疫证明
2. 报关单
3. 中文标签（预包装情况）

**五、其他**
1. 冷链运输温度记录（对冷链水果）
2. 包装标识：品名、产地、生产者、生产日期等

**实操建议**：超市应在采购制度中明确“每批索取进货票据+农残合格凭证，按品种/产地定期索取第三方检测报告”，并留存归档不少于保质期满后6个月（无明确保质期的不少于2年）。具体豁免与强制要求，建议以当地市场监管部门现行规定和超市自身食品安全管理制度为准。
