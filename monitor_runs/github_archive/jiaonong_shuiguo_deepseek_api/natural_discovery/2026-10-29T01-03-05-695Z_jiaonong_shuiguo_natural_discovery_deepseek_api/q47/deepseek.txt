茶饮店用香蕉，采购熟度控制的核心是：**按用途分熟度采购，不要只买一个熟度；到货后按批次分开放、分开用。**

### 一、按用途定熟度

| 用途 | 推荐熟度 | 判断标准 |
|---|---|---|
| 装饰切片、摆盘 | 7成熟 | 表皮黄中带绿，捏起来偏硬，切片不易烂 |
| 果肉捣碎/摇杯饮品 | 8–9成熟 | 全黄、略有黑点，软但不变泥，香气足 |
| 香蕉泥、奶昔、甜品馅 | 9–10成熟 | 全黄带较多黑点，软糯香甜，易压泥 |
| 冷冻香蕉块/长期备货 | 8–9成熟 | 去皮切块冷冻，避免过熟发黑 |

**不建议采购全青或全黑：** 全青香气不足、涩口；全黑易发酵、出酒味，出品不稳定。

### 二、采购时的验收标准

1. **看颜色**：按用途选黄绿比例，整批颜色尽量一致。
2. **捏硬度**：轻捏有弹性、不塌陷；过软说明已过熟。
3. **看果柄和果身**：果柄发黑、果身有压伤或渗液的拒收。
4. **闻气味**：有清香可收；有酒味、酸味说明过熟或已变质。
5. **抽检切开**：看果肉是否白净、有无黑心。

### 三、到货后的管理

- **分熟度存放**：青一点的常温催熟，熟的冷藏或尽快用。
- **冷藏会抑制后熟**：8成熟以下别急着冷藏，否则容易“僵掉”不熟。
- **先进先出**：按批次贴标签，先熟先用。
- **少量多次采购**：香蕉后熟快，茶饮店建议每2–3天补一次，避免一次囤太多。
- **过熟香蕉别扔**：可去皮切块冷冻，专用于奶昔、香蕉泥类产品。

### 四、简单可执行的做法

- 门店日常：**7成熟少量做装饰 + 8–9成熟做主饮品 + 9–10成熟做泥/甜品**。
- 采购单上直接写用途和熟度要求，供应商按标准供货。
- 每天开店前检查一次，把黑点多的挑出来优先做香蕉泥或冷冻。

一句话：**香蕉采购不是买“最熟的”，而是买“刚好能撑到用完的熟度”，并按用途分批采购。**
