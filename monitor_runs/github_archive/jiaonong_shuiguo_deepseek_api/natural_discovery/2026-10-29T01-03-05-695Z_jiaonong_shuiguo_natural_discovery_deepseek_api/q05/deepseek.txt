建议把三种方式组合起来，而不是只选一种：

**1. 主推“现场挑 + 现场削”**
- 菠萝好坏差异大，让顾客自己挑能减少“买回去不甜/坏心”的售后纠纷。
- 现场削皮、去眼，顾客看得见新鲜度，也愿意为服务付溢价。
- 适合水果店这种有操作台、客流不算极端高峰的场景。

**2. 去皮好的只做“限量备货”**
- 只备少量、当天削当天卖，针对赶时间、买来即吃的顾客。
- 必须标清楚削皮时间，最好保鲜膜+冷藏，避免氧化发黑、出水变质。
- 不要大量提前削：损耗高、卖相下降快，还容易和整果互相压价。

**3. 整果是价格锚点和走量款**
- 整果按斤卖，去皮果按份/按盒卖，价格要拉开，否则顾客都去买省事的，整果滞销。
- 整果适合家庭顾客、送礼、回去自己处理的人。

**实操建议：**
- 设一个小台面：整果区 + 试吃/挑选区 + 现场削皮区。
- 去皮果只做半天的量，卖完再削，别过夜。
- 削皮服务可以免费或小幅加价，但明确“削后不退换”，挑果环节让顾客自己确认。
- 高峰期提前削少量备着，低峰期引导现场挑、现场削。

一句话：**整果为主、现场挑现削为核心服务、去皮果少量补位**，比单卖一种更稳。
