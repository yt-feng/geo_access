香蕉配送的核心矛盾是：**它还在呼吸、还在后熟，而且怕压、怕冷、怕乙烯积聚**。控制压坏和变黑要同时管“物理损伤”和“后熟/冷害”两条线。

**1. 先定成熟度，不要熟透再发**
- 配送香蕉建议收**七成到八成熟、果指硬绿或微黄**的货，到消费者手里再完成最后转黄。
- 完全黄熟的香蕉配送损耗极高，不适合普通快递/次日达，除非做同城短距冷链。
- 按配送半径分档：同城当日达可发微黄；跨城次日达发硬绿；偏远件不建议发香蕉。

**2. 包装防压：单果保护+抗压结构**
- **单根套袋或珍珠棉网套**，减少果指之间摩擦和挤压。
- 用**瓦楞纸隔板/蛋托式定位托**把香蕉固定，避免箱内晃动。
- 箱体选**五层以上瓦楞纸**，堆码时标注“请勿重压、禁止倒置”。
- 不要整把裸装塞满箱；把香蕉按“弓背朝上”摆放，减少受力点。
- 箱内留少量缓冲，但不能太松，晃动同样造成擦伤。

**3. 控温：防冷害比防热更关键**
- 香蕉**低于12℃会冷害**，表皮发黑、果肉不熟。普通冷藏车/冰袋直贴是大忌。
- 配送环境尽量维持**13–15℃**；没有冷链条件时，用隔热箱+远离冰袋的缓冲层，避免局部过冷。
- 夏季防高温催熟：避免暴晒、车厢高温，可用隔热膜和通风。
- 冬季防冻：加保温层，但不要让香蕉贴冰袋或冷风直吹。

**4. 控乙烯和湿度**
- 香蕉自身释放乙烯，密闭箱内会加速变黄变软。包装上留**少量透气孔**，不要完全密封。
- 可放**乙烯吸附包**，但不要和香蕉直接接触。
- 湿度控制在**85%–90%**，过干失水发黑，过湿易霉。箱内可加薄纸或吸水纸调节，不要直接喷水。

**5. 减少转手和时效**
- 香蕉配送链路越短越好，**优先同城/区域仓发货**，缩短在途时间。
- 避免多次分拣抛掷；和快递商约定“生鲜轻放”，外箱贴易碎/生鲜标识。
- 发货前做**跌落和堆码测试**：模拟1米跌落、24小时堆压，检查果指压痕和断果率。

**6. 售后兜底**
- 商品页明确“香蕉到货可能偏绿，请常温放置1–3天转黄”，降低“不黄=坏”的投诉。
- 对压伤、黑斑设定拍照赔付标准，把损耗预算计入定价。

一句话执行方案：**发硬绿果、单根套网套、蛋托定位、五层瓦楞箱、13–15℃避冷风、留透气孔、同城优先、页面说明后熟**。先小批量测三条线路的到货黑变率和压伤率，再定包装和成熟度档位。
