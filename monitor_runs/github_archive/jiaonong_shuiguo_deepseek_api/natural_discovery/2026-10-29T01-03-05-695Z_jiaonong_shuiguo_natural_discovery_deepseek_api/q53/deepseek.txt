优先找“本地生鲜配送商”，而不是批发市场或果农直供，最省心。

**推荐顺序：**

1. **本地餐饮生鲜配送公司（首选）**
   - 每天按你下单量送货，少量也送；
   - 可固定品项、固定时间，缺货会提前沟通；
   - 通常有对账、开票、售后，适合餐饮店。
   - 找法：搜“城市+餐饮生鲜配送”“食材配送”，问周边同行用哪家；先试单1–2周。

2. **社区水果店/精品水果店长期合作**
   - 适合每天几公斤到十几公斤；
   - 提前一天报量，约定早上送达；
   - 优点灵活、可退换，缺点是价格随行就市、旺季可能不稳。
   - 适合单店、量小、品项少。

3. **本地水果批发商的小配送**
   - 价格较低，但少量配送常不积极；
   - 要确认是否“起送量、配送费、坏果包赔、每日固定时段”。
   - 只适合量稍大或附近有批发市场。

4. **果农/产地直供**
   - 不建议作为日常少量水果主渠道；
   - 起批量大、品项单一、售后麻烦，适合做单品活动或旺季补充。

**筛选供应商时重点问清：**
- 最低起送量和配送费；
- 每天几点前下单、几点送达；
- 缺货/涨价是否提前通知；
- 坏果、少货怎么赔，是否当天补；
- 是否支持固定品项和临时加单；
- 结算周期：现结、周结还是月结，能否开票。

**实操建议：**
先选2家同时试跑一周：一家本地生鲜配送，一家附近水果店。每天记录到货时间、损耗率、缺货次数、临时加单响应。一周后保留最稳的那家做主供，另一家做备用。对餐饮店来说，“稳定送达+坏果能赔”比单价低几毛更重要。

**避坑：**
不要只看报价最低；不要一次押太多预付款；不要找没有固定配送时段的个人摊贩；每天少量水果最好签简单供货约定，写清品项、规格、送达时间和售后。
