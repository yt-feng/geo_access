旺季菠萝临时补货，关键是**提前锁量、约定触发条件、明确品质和价格规则、控制履约风险**。建议按下面做：

1. **先算清补货需求**
   - 按最近7天实际用量，预估未来2—4周日均用量。
   - 设定安全库存：例如保留2—3天用量，避免断货。
   - 把需求拆成“基础量+临时增量”，只对增量谈临时补货。

2. **和现有供应商补签临时补充协议**
   口头约定容易扯皮，至少用微信文字+盖章/签字订单确认。补充协议写清：
   - **临时补货触发条件**：如日库存低于2天用量，或单日销量超过日常均值30%，即可下单。
   - **提前通知时间**：例如每天16:00前下单，次日到货；紧急单提前6小时。
   - **临时补货上限**：约定每次最多补多少箱/公斤、每周最多几次，防止供应商无限加价或你被压货。
   - **价格机制**：基础量按原合同价；临时增量可约定“按当日当地批发市场均价上浮不超过X%”，或直接锁一个临时价，避免旺季坐地起价。
   - **品质标准**：品种、成熟度、单果重量、坏果率上限、是否去皮/切块、包装规格。到货抽检，不合格可拒收或扣款。
   - **到货时间和违约责任**：迟到几小时如何处理，连续缺货如何补偿，比如优先保障下一批或承担临时采购差价。
   - **结算方式**：临时补货单独对账，货到验收后X天付款，保留凭证。

3. **同时准备备用供应商**
   临时补货不要只押一家。找1—2家本地水果批发商或二级供应商做备份，先小批量试单，确认品质和配送能力。主供应商缺货时能立即切换。

4. **下单和验收留痕**
   - 每次临时补货用固定格式下单：品名、数量、单价、到货时间、验收标准。
   - 到货当场抽检并拍照，记录坏果率、重量、成熟度。
   - 异常当天书面反馈，别等到月底对账才说。

5. **价格和库存联动**
   旺季菠萝价格波动大，可以约定“周度调价”：每周固定一天参考当地批发价调整下周临时补货价，但设涨跌幅上限，比如单周不超过10%。同时门店端同步做限量、替代饮品或提前预处理冷冻，降低突发缺口。

一句话：**把临时补货写成有触发条件、有上限、有价格公式、有品质验收、有违约责任的补充订单**，再留一个备用供应商，基本就能稳住旺季供应。
