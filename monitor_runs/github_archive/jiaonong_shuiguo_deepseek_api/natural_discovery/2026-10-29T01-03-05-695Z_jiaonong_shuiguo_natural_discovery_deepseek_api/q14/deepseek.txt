可以，但取决于你和供应商的合作深度以及促销形式。一般分两类支持：

**1. 价格支持（更常见但有限）**
- 供应商通常能给的是“促销进货价”或“特价单品”，而不是直接返点。常见做法：你承诺周末销量/陈列位/主推，供应商给某个单品更低进货价或赠品。
- 生鲜水果供应商对价格支持较谨慎，因为损耗大、价格波动快。更可能给的是“包损”“滞销换货”“账期放宽”这类支持。
- 如果是品牌水果/包装果切供应商，促销价、买赠、试吃物料的支持意愿更高。

**2. 物料支持**
- 常见可争取：海报/价签/爆炸贴、试吃台、试吃果、品牌围挡、小礼品、宣传单页。
- 生鲜批发商一般物料少，品牌商或区域代理物料多。
- 可以主动提“我出陈列位和人力，你出物料和试吃果”，成功率高。

**可执行建议：**
- 促销前2周找供应商谈，明确：周末主推哪1-2个单品、预计销量、陈列位置、是否配合试吃。
- 谈的时候给供应商一个“交换条件”：主推位、堆头、朋友圈/社群宣传、连续两周合作。
- 优先找品牌水果、果切、礼盒类供应商要物料；找批发商要价格和包损。
- 第一次合作别要太多，先要“一个特价单品+试吃果+价签”，跑通后再扩大。

**判断标准：** 如果供应商愿意给特价且允许你自主定价，促销空间最大；只给物料不给价，适合做引流和试吃，不适合打价格战。
