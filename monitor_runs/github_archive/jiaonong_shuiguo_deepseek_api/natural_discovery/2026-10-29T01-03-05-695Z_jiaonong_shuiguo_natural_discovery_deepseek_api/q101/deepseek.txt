和水果供应商谈合作，建议重点抓这几件事：

1. **先定供应标准，不要只谈价格**
   - 明确品种、规格、成熟度、甜度、外观瑕疵容忍度。
   - 早餐场景要“稳定、好处理、损耗低”，优先选耐储存、易分切、出品稳定的品类。
   - 写清验收标准：到货温度、包装、净重、坏果率上限、单个规格范围。

2. **要求稳定供货能力**
   - 问清产地、季节性替代方案、每日最大供货量、节假日和极端天气预案。
   - 要求固定对接人和补货响应时间，比如缺货几小时内补送。
   - 不要只依赖一家，至少准备一个备用供应商。

3. **价格与调价机制要透明**
   - 报价含税、含运费、含卸货到指定位置。
   - 约定价格有效期和调价触发条件，比如批发市场价波动超过一定比例才调价，并提前通知。
   - 对比报价时按“可利用率”算，不只看单价：坏果多、损耗大，实际成本更高。

4. **验收和退换货条款写进合同**
   - 到货抽检，坏果率、缺斤少两、规格不符的处理方式要明确。
   - 质量问题退换货时限、费用承担方写清楚。
   - 建议前1—2个月按周复盘损耗和投诉，再决定是否长期合作。

5. **账期与结算方式**
   - 明确月结天数、发票类型、付款节点。
   - 新供应商可先小批量试供，稳定后再给长账期。
   - 避免大额预付，尤其是不熟悉的供应商。

6. **食品安全资质**
   - 营业执照、食品经营许可、检测报告、产地证明等要留存。
   - 配送车辆和周转箱卫生、冷链要求要约定。
   - 出现食品安全问题时的责任和赔偿条款不能省。

7. **试供和考核**
   - 先签短期试供协议，比如2—4周。
   - 考核指标：到货准时率、坏果率、规格合格率、补货响应、投诉处理。
   - 达标后再谈长期价格和账期。

8. **合同细节**
   - 写清品种清单、单价、规格、验收标准、违约责任、终止条件。
   - 口头承诺全部落到书面，尤其是“随时补货”“坏果包换”这类话。

一句话：**先定标准和验收，再谈价格和账期；先小批量试供，再签长期合同。** 早餐水果的核心不是最低价，而是每天稳定到货、损耗可控、食品安全可追溯。
