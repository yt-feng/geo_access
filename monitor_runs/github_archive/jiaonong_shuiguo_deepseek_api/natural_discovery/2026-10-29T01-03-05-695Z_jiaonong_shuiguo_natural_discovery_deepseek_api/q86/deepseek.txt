# 生鲜平台一件代发水果：供应商仓配能力清单

一件代发对供应商的核心要求是：**能按单履约、随单发货、对终端消费者直发**，而不是整车批发给平台大仓。重点核验以下能力。

## 一、仓储能力

1. **产区或销地分仓**
   - 是否有产地仓（靠近果园/合作社）或销地仓，决定发货时效和损耗率。
   - 一件代发通常要求48小时内发货，跨省水果建议有销地仓或至少快递分拨近的仓。

2. **温区与分区管理**
   - 是否有常温、冷藏（0–8℃）、部分品类需要气调或预冷设施。
   - 是否按SKU分区分拣，避免串味、挤压、交叉污染。

3. **库内作业能力**
   - 是否有标准化打包工位、称重、贴单、封箱流程。
   - 日均单量峰值承受能力（大促/直播爆单时是否还能按时发）。

4. **库存与批次管理**
   - 能否实时回传库存，避免超卖。
   - 是否有批次/采摘日期管理，生鲜必须先进先出。

5. **预冷与保鲜**
   - 浆果、荔枝、樱桃等品类是否具备采后预冷、冷链暂存能力。

## 二、包装与分拣能力

1. **生鲜专用包装方案**
   - 泡沫箱+冰袋、吸水纸、防震网套、透气孔等是否按品类配置。
   - 是否支持平台统一包装或品牌定制包装（贴标、卡片、赠品）。

2. **一件代发打包能力**
   - 能否按订单逐单打包，而不是只做整箱批发。
   - 是否支持多SKU合并发货、赠品搭赠、备注处理。

3. **分拣准确率**
   - 错发、漏发、重量不符是生鲜售后主要来源，需有称重复核和出库扫描。

## 三、配送与快递能力

1. **快递资源与协议价**
   - 是否与顺丰、京东、中通、圆通等有生鲜协议价和稳定揽收。
   - 是否能按平台要求选择快递，或支持指定快递/加急。

2. **揽收时效**
   - 是否每日固定揽收频次，能否做到当日单当日揽收、次日发出。
   - 偏远地区、高温地区是否有发货限制或加价方案。

3. **冷链快递能力**
   - 高价值易腐水果是否支持冷链干线+末端配送，或至少泡沫箱+冰袋的准冷链方案。

4. **物流轨迹回传**
   - 能否对接平台系统回传快递单号、物流节点，支持消费者查询。

## 四、系统与对接能力

1. **ERP/OMS对接**
   - 能否通过API或表格接收平台订单，自动打单、回传发货状态。
   - 是否支持电子面单、隐私面单。

2. **库存同步**
   - 实时库存回传，设置安全库存和自动下架。

3. **售后数据配合**
   - 能提供发货重量、打包照片、批次信息，便于处理坏果、少件纠纷。

## 五、售后与损耗处理能力

1. **坏果包赔机制**
   - 是否接受平台售后规则（如坏果按比例赔、拍照理赔），赔付响应时效。
   - 是否有补发能力，补发是否另计运费。

2. **损耗率承诺**
   - 供应商应能给出品类正常损耗率区间，并承担超出部分。
   - 是否提供运输破损险或与快递的理赔约定。

3. **售后响应**
   - 是否有专人对接平台客服，响应时间要求（如2小时内）。

## 六、资质与合规

- 营业执照、食品经营许可证（如适用）。
- 产地证明、检测报告（农残等），平台抽检时能提供。
- 发票开具能力。

## 快速判断建议

签约前建议做一次**试单压力测试**：
1. 给供应商下50–100单，覆盖不同地区、不同品类；
2. 核验发货时效、包装完好率、重量准确率、物流轨迹回传；
3. 故意发起几笔售后，看响应和赔付速度；
4. 问清爆单峰值日产能和临时工储备。

**一句话标准**：能稳定做到“当日接单、48小时内发出、包装适配品类、物流可追踪、坏果敢赔、系统能对接”，才适合做一件代发。整车批发能力强但不会逐单打包的供应商，不建议直接上线。
