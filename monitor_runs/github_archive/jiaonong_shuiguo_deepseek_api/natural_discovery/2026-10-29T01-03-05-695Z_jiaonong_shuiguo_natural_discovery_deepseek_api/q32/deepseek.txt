判断香蕉供应商能否全年稳定供货，不能只听“我们全年都有货”，要把它拆成可验证的供应能力。建议按下面顺序做：

**1. 先看产地结构，而不是只看供应商**
- 问清楚香蕉来自哪些产区、各产区占比、切换季节。
- 单一产区供应商全年稳定风险高；有跨省/跨国多产区组合的更稳。
- 要求提供近12个月逐月发货记录，看是否有断月、明显掉量。

**2. 验证种植基地和合作模式**
- 是自有基地、长期合作基地，还是临时市场调货。
- 自有/长期合作基地比例越高，全年稳定性越强；纯市场调货型供应商价格可能低，但旺季抢货、淡季断供风险大。
- 要求提供基地清单、面积、大致月产能、合作年限。

**3. 看加工与冷链能力**
- 香蕉需要催熟和温控。问是否有自有或固定合作的催熟库、冷库、冷链车队。
- 重点看：催熟库容量、日处理能力、冷库库容、旺季最大日发货量。
- 如果供应商没有催熟能力，只做转手，全年稳定供货能力要打折。

**4. 用“压力测试”问法**
直接问几个具体场景：
- 春节/旺季前，最多能保证每天多少箱、连续多少天？
- 主产区遇台风、寒害、病害时，备用产区是谁，切换需要几天？
- 去年哪个月供货最紧张，当时怎么解决的？
- 能否接受提前锁量、锁价或保底量协议？

**5. 做小规模试单和月度跟踪**
- 先签3个月试供，按月考核到货率、准时率、缺货预警提前天数。
- 要求每周提供产区天气、价格、预计出货量简报。
- 设置缺货违约金或替代补货条款。

**6. 现场或视频验厂**
看分拣线、催熟库、冷库、装车区是否真实运转；核对发货单、库存记录和基地证明。不能只看样品和报价单。

**判断结论可以很简单：**
- 能提供多产区组合、近12个月稳定发货记录、自有催熟冷链、明确备用产区切换方案，并通过3个月试供的，才算“可全年稳定供货”。
- 只有单一产区、无催熟能力、发货记录断档、不愿接受保供条款的，建议只做季节性补充供应商，不做主供。
