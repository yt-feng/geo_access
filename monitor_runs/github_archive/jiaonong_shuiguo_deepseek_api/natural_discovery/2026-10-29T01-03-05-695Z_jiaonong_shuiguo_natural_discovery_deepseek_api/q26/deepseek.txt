社区超市卖小包装香蕉，采购和运营时重点抓这几件事：

1. **按“可售根数”而不是整箱重量算账**
   - 小包装通常 2～3 根/袋，采购时问清整箱净重、单根均重、可分出多少袋。
   - 重点看“可售率”：有碰伤、断柄、过熟、青硬不能混装的要扣掉，别只按采购价判断毛利。
   - 建议先小批量试销，记录每天分装袋数、售出袋数、报损袋数，再定采购量。

2. **包装要透气、防压，不要密封闷坏**
   - 优先用带透气孔的薄膜袋、网袋或开孔保鲜袋，避免完全密封导致水汽积聚、发黑。
   - 袋型选浅而宽，别把香蕉压叠太厚；2～3 根装比 4～5 根装更好控损。
   - 标签贴在不显眼位置，避免贴伤果皮；袋口不要勒太紧，防止勒痕和断柄。
   - 若用托盘+保鲜膜，膜上要打孔，且托盘深度要浅。

3. **采购成熟度要分开**
   - 小包装适合买“微黄至黄绿”的香蕉，到店后自然转黄，避免采购全黄果导致当天卖不完就报损。
   - 可少量配一批“即食黄”做当天动销，主力用稍青果做 1～3 天周转。
   - 不同成熟度不要混装在同一袋，否则一袋里熟度不均，顾客挑拣、投诉多。

4. **控制单袋规格和价格带**
   - 社区超市小包装更适合“一次吃完、低单价”：2～3 根/袋，定价让顾客觉得顺手买。
   - 单袋过重会劝退小家庭和单人顾客，也放大损耗。
   - 规格统一，便于称重、贴标和盘点；避免今天 3 根明天 5 根，顾客比价和员工操作都乱。

5. **到店验收重点看伤和柄**
   - 查果柄是否断裂、果指是否有压伤/擦伤/裂口、箱底是否有汁液。
   - 香蕉怕冷也怕闷：运输和暂存避免低温冷害，别放冷藏柜；放在阴凉通风处。
   - 验收时抽几袋预分装试摆，看袋内是否起水雾、是否挤压变形。

6. **陈列和补货要少量多次**
   - 小包装不要堆高，平铺或单层斜摆，避免下层压伤。
   - 按成熟度分区：稍青的放里面，黄的放前面；每天挑出过熟袋做折扣或员工处理。
   - 补货少量多次，别一次分装太多；分装后尽量当天或次日售完。

7. **损耗要单独记账**
   - 记录采购箱数、分装袋数、售出袋数、报损袋数和报损原因：压伤、过熟、断柄、顾客拆袋、失水。
   - 如果报损主要来自压伤，改包装和陈列；来自过熟，调采购成熟度和订货量；来自拆袋，改用更难拆或更小规格包装。

8. **采购合同/口头约定里明确**
   - 到货成熟度范围、碰伤和断柄的允许比例、箱内净重和单根均重、异常批次能否退换。
   - 先谈小批量、多频次补货，别一次压太多库存。

简单判断标准：**先试销 1～2 周，若单袋报损率明显高于其他水果，优先改小规格、改透气包装、降采购成熟度、缩短补货周期。**
