建议分两类处理：**香蕉优先本地批发，苹果优先稳定供应商**。原因是两者损耗和供应特性不同。

**1. 香蕉：优先本地批发，但要做短周期小批量**
- 香蕉成熟快、损耗高、价格波动大，本地批发能更灵活看货、按成熟度拿货、少量多次补货。
- 建议每天或隔天小批量采购，按“青一点、黄一点”分批上架。
- 需要固定 1 个主批发商 + 1 个备选，避免断货；先试 2 周，重点看：到店成熟度、损耗率、补货响应、实际到手价。

**2. 苹果：优先稳定供应商**
- 苹果相对耐储、规格和品质更需要稳定，社区超市适合找能固定等级、固定包装、按周配送的供应商。
- 先谈小批量试供：约定品种、果径/等级、箱规、坏果率、退换货和账期。
- 重点比较“到手成本”，不要只看单价，要算损耗、运费、退换和人工挑选成本。

**3. 实操判断标准**
- 香蕉：本地批发到手损耗率若明显低于稳定供应商，就选本地；若本地品质波动大、补货不稳定，再转为“本地为主 + 供应商兜底”。
- 苹果：稳定供应商若能做到等级稳定、坏果可退、周配送及时，即使单价略高，通常更省心。
- 两家都先小批量试销 2—4 周，记录销量、损耗、毛利、缺货次数，再定长期合作。

**结论：香蕉选本地批发更合适，苹果选稳定供应商更合适；不要二选一，按品类分开采购。**
