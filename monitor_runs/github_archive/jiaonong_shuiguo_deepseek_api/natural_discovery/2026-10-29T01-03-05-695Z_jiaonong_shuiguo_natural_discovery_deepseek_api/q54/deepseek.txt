优先看成熟度，但不能只看“越熟越好”，要按用途分档采购；价格是第二筛选条件。

可执行判断：

1. **现做现卖、当天/次日用完**
   - 选：表皮大面积金黄、带少量褐斑、果肉软但不变水。
   - 适合：香蕉磅蛋糕、玛芬、香蕉面包，香气足、甜度高。
   - 避免：表皮全黑、果肉流汁、有酒味/酸味，容易发苦、发酵味重。

2. **需要备货、2–4天内使用**
   - 选：金黄为主、两端略青、按下去有弹性。
   - 到店后常温催熟，按使用顺序分批。
   - 不要一次全买全熟，损耗会高。

3. **要做装饰片、夹心块**
   - 选：刚转黄、果肉偏硬。
   - 过熟的只适合压泥入面糊，不适合切块装饰。

4. **价格怎么判断**
   - 同样成熟度下再比价；不要为了低价买过熟或过青。
   - 过熟香蕉若当天能全部处理成香蕉泥并冷冻，可低价采购；否则不建议。
   - 青香蕉价格低但占用催熟时间和仓储，算上损耗后未必便宜。

5. **采购落地建议**
   - 按配方需求倒推：需要香蕉泥的蛋糕，优先买“褐斑期”香蕉；需要果肉的，买“金黄偏硬”。
   - 每次分两批买：一批即用熟度，一批1–2天后用。
   - 验收看：表皮颜色、手感、是否有酒味/霉点、果柄是否发黑腐烂。
   - 建立简单标准：**即用批＝金黄带褐斑；备用批＝金黄略硬；拒收＝全黑流水、异味、霉变。**

结论：**成熟度决定能不能用、好不好吃，价格只决定划不划算。先按用途定成熟度，再在同成熟度里比价。**
