判断供应商售后响应是否稳定，不要只听口头承诺，按“可验证的机制 + 小单试压 + 合同约束”三步做。

**一、先看对方有没有可验证的售后机制**
1. 问清售后对接人是谁、是否有专人/专线，不要只留一个业务员微信。
2. 要求提供书面售后流程：到货异常（烂果、青果、规格不符、短重）多久内响应、多久给处理方案、补货还是退款、换货运费谁承担。
3. 看其是否有冷库/加工/分拣能力，菠萝香蕉都是易损品，没有后端处理能力的供应商售后往往靠拖。
4. 要求提供近3个月2—3个商超客户的可联系售后案例（可让对方给联系人，你自行核实，不要只信截图）。

**二、用小单和异常场景试压**
1. 首单不要大，故意选一个可接受的“小异常”场景（如少量规格偏差、到货偏青），观察对方响应速度和是否按约定处理。
2. 记录三个指标：首次响应时间、给出方案时间、实际解决时间。稳定供应商通常当天响应、24—48小时内给方案。
3. 连续下2—3次小单，看售后是否每次都一致，而不是第一次热情、后面推诿。
4. 故意在非工作时间报一次小问题，看是否有值班或次日一早处理机制。

**三、用合同和结算条款兜底**
1. 合同写清：到货验收标准（成熟度、单果重、伤果率上限）、异常报备时限、响应时限、赔付/补货方式。
2. 设置质量保证金或账期尾款，售后未闭环前保留一定比例货款。
3. 约定“多次售后不达标可终止合作”的条款，避免被单一供应商卡住。
4. 保留到货拍照、称重、验收记录，作为售后依据。

**快速判断信号：**
- 稳定：有固定售后对接人、书面流程、愿意小单试、合同肯写响应时限和赔付。
- 不稳定：只靠口头保证、售后永远“在协调”、不愿写时限、首单就要求大额预付、异常后只拖不赔。

对菠萝香蕉这类高损耗品，建议同时保留1—2家备选供应商，售后响应能力用“小单+异常测试+合同条款”三重验证，比听承诺可靠。
