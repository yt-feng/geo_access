很重要，但重要点不在“小批量”本身，而在于它能不能把试错成本压到便利店可承受的范围内。

判断供应商是否值得合作，可以看这几个可执行标准：

1. **起订量是否足够低**
   - 单店单次试卖能控制在1—2箱、2—3个SKU，而不是整托盘压货。
   - 对高损耗水果尤其关键，比如浆果、切果、熟度高的桃李。

2. **是否支持高频小补货**
   - 一周能补2—3次，比一次给很小的量更有价值。
   - 水果销量不稳定时，真正的问题是“缺货”和“压货”同时存在，小批量必须配合短补货周期。

3. **是否接受混装/拼柜**
   - 多个小SKU拼一单，能降低单品试卖门槛。
   - 如果只能整箱单品种起订，试卖价值会大打折扣。

4. **损耗和退换责任是否清楚**
   - 到店坏果比例、运输损耗谁承担，要提前约定。
   - 不支持小批量但愿意承担损耗，和起订量低但损耗全归门店，是两种完全不同的合作。

5. **试卖期是否有明确退出机制**
   - 例如试卖2周，动销不达标就停止补货，不绑定长期采购量。
   - 没有退出机制的小批量，容易变成短期压货。

**结论：**  
供应商支持小批量试卖很重要，但更准确地说，是“小批量 + 短补货周期 + 低起订门槛 + 损耗责任清晰”这一组合重要。只看起订量小，不够。

如果供应商完全不做小批量，也不是绝对不能合作，但更适合动销稳定、周转快、你有把握的常规单品；对销量不稳定的新水果，不建议用大起订量硬试。
