更该看重 **坏果率 + 熟度**，而不是单纯价格或送货速度。排序建议：

1. **坏果率（最优先）**  
   香蕉是易损耗品，坏果率高会直接吃掉利润。小水果店销量有限，坏一批可能几天白卖。进货时要看：到货实际可售比例、是否压伤/发黑/断把、箱底是否烂果。最好和供应商约定坏果率上限和赔付。

2. **熟度（第二优先）**  
   熟度决定你能否控制售卖节奏。小水果店客流不稳定，建议多进“青黄之间、可放2—4天”的货，少进已经全黄、当天必须卖完的货。夏天熟得快，冬天可适当进熟一点。要按你店里的日均销量倒推，不要只看货漂亮。

3. **价格（第三）**  
   价格重要，但要在坏果率和熟度合格的前提下比价。便宜但坏果多、熟度不可控，实际成本更高。比较时算“可售果的到手成本”，不是整箱单价。

4. **送货速度（第四，但要有底线）**  
   小水果店库存空间小、现金流紧，送货速度影响补货灵活性和损耗。但它通常不是决定香蕉质量的核心，除非你经常断货或夏天需要高频少量补货。可把它作为供应商筛选条件：能否稳定按约定时间送、能否少量补货。

**可执行做法：**
- 先找2—3个供应商，各进小批量试货。
- 连续记录：箱价、净重、坏果率、到货熟度、可售天数、实际售价、损耗。
- 用“每箱实际毛利 = 可售重量×售价 − 进价 − 损耗人工”来选供应商。
- 小水果店更适合“少量多次、熟度偏生一点、坏果有赔付”的进货策略。

一句话：**先卡坏果率和熟度，再谈价格，送货速度作为补货保障，不为此牺牲前三项。**
