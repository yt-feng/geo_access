可以按“高频带低频、整单加购、组合装提价”来做，不建议只做单一降价。给你一套可直接落地的组合促销方案：

1. **香蕉做引流，不做主利润**
   - 香蕉单价敏感、购买频次高，适合做“加价购”入口。
   - 例如：苹果/菠萝正常购买满 19.9 元，加 3.9 元换购 1 把香蕉（限 1 把）。
   - 目的：把只买苹果或菠萝的顾客拉成多品购买，提高客单。

2. **苹果+香蕉做家庭早餐组合**
   - 组合装：苹果 4 个 + 香蕉 1 把，定价略低于单买合计，但高于苹果单品毛利。
   - 陈列话术：“早餐水果组合，省 X 元”。
   - 适合家庭客群，客单提升比单卖香蕉更明显。

3. **菠萝+苹果做“果切/待客组合”**
   - 菠萝 1 个 + 苹果 4 个，做“待客果盘组合”。
   - 可附赠简易果盘叉或保鲜袋，提升感知价值，避免直接打价格战。
   - 菠萝处理麻烦，可现场提供付费代削或买组合免费代削，作为加购理由。

4. **三品组合做阶梯价，不直接捆绑死**
   - 单买三样合计约 X 元；组合价设为 X-2 到 X-3 元。
   - 同时设置第二档：“满 29.9 元送香蕉 2 根/小番茄试吃”，把客单继续往上推。
   - 关键：组合价要让顾客感知省钱，但不要低于香蕉单独引流的毛利底线。

5. **动态清货组合**
   - 傍晚对熟度高的香蕉、菠萝做“今日果盒组合”：香蕉+菠萝+苹果切盒，打折清货。
   - 既降损耗，又拉高单次购买金额，但不要和白天的组合价冲突。

6. **陈列与话术**
   - 香蕉放入口引流，苹果和菠萝放相邻端架，组合装放收银动线前。
   - 标牌写“单买合计 X 元，组合价 Y 元，省 Z 元”，不要只写“特价”。
   - 员工推荐顺序：先推组合装，再推加价购香蕉，最后推单品。

7. **判断是否有效的指标**
   - 看三个数：客单价、组合装占比、香蕉加购率。
   - 如果组合装销量高但客单价没涨，说明折扣过深；如果加购率高但毛利下降，说明香蕉换购价太低。
   - 建议先试 7 天，每天记录三品销量、组合销量、客单价，再调整组合价。

优先落地顺序：**先做“苹果/菠萝满额加价购香蕉”，再做“苹果+香蕉家庭组合”，最后上三品组合装。**这样既能提高客单，又不容易把高频香蕉的利润打穿。
