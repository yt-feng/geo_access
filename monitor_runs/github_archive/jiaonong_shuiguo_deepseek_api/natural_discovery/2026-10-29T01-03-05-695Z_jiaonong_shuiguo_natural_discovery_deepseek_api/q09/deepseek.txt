旺季怕断货，和供应商谈的时候，重点不是“能不能给我供”，而是把**供货能力、锁量方式、缺货责任、价格波动、到货时效**这几件事提前问死。下面这些问题建议你列成清单，谈的时候逐条确认，最好落到合同或书面记录里：

**1. 旺季供货能力**
- 旺季你每天/每周最多能稳定给我供多少量？分品种说。
- 你现在的货源是自有基地、产地直采还是市场调货？调货比例多高？
- 去年旺季你有没有出现过大面积断货？断在哪些品类？
- 如果我临时加量，提前多久报计划你能安排？最多能加多少？

**2. 锁量与保供**
- 旺季能不能签保供协议或锁量协议？锁哪些品种、锁多少量、锁多久？
- 我提前下订单后，你会不会优先保我？优先级怎么定？
- 如果多个客户抢货，按什么顺序分配？
- 能不能给我留安全库存或预留份额？

**3. 缺货和违约怎么处理**
- 你断货导致我缺货，怎么赔？有没有违约金或补货补偿？
- 缺货提前多久通知我？临时断货怎么办？
- 质量不达标、到货烂损超标怎么退换、怎么赔？
- 连续断货几次我可以终止合作？

**4. 价格和波动**
- 旺季价格怎么定？是固定价、随行就市还是保底价？
- 涨价提前多久通知？有没有涨幅上限？
- 我量大能不能谈阶梯价或返点？
- 运费、装卸、损耗算谁的？

**5. 到货时效和物流**
- 下单后多久到货？旺季会不会延迟？
- 配送频次能不能按我销量调整？最早几点到店？
- 运输损耗率多少以内你负责？超了怎么处理？
- 临时补货能不能当天到？

**6. 品质和分级**
- 每个品种的规格、等级、成熟度标准能不能书面确认？
- 旺季品质会不会下降？降级怎么提前告知？
- 验收标准是什么？谁验、怎么验、争议怎么处理？

**7. 结算和合作条件**
- 结算周期是现结、周结还是月结？旺季能不能给我账期？
- 要不要押金、保证金？退的条件是什么？
- 独家或优先供货有没有条件？
- 合作期限怎么签？旺季结束后怎么续？

**8. 备选和风险**
- 如果你那边出问题，能不能介绍备用供应商？
- 你有没有冷库、分拣能力？旺季爆单怎么应对？
- 天气、产地减产时你怎么保供？

谈的时候建议你带一张表，把**品种、日需求量、旺季峰值、锁量、价格、到货时间、缺货赔付**逐项写清楚，双方签字确认。口头承诺在旺季最容易落空，能写进合同或微信书面确认的，尽量留痕。另外，旺季不要只谈一家，至少备一个第二供应商，哪怕量小，关键时候能救急。
