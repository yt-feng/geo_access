这取决于你门店的客群结构和损耗管理能力，不能一刀切。直接给判断框架和执行建议：

## 先做判断：你的门店属于哪类

**优先卖整果的情况：**
- 社区店、家庭客群为主，顾客有回家处理水果的习惯
- 门店人手少，没有稳定切果台和冷藏展示条件
- 菠萝进货价波动大，整果耐放、损耗可控
- 已有稳定的整果动销（日均能走量）

**优先卖切好的情况：**
- 商圈店、写字楼店、年轻客群/上班族为主，图方便
- 门店有冷藏展示柜、能保证切果全程冷链
- 有专人能做每日现切、控制切后当日售罄
- 周边有便利店/水果切盒竞争，不切就丢客流

## 更稳的做法：整果为主、切果为辅

多数商超最优解是**双轨**，而不是二选一：

1. **整果做走量和价格形象**，承担家庭采购和囤货需求，损耗低。
2. **切果做毛利和便利性**，用小份盒装（如半只、四分之一只）抓即时消费，定价可比整果折算单价高20%–40%。
3. **切果原料用整果里的次优果**（外观有瑕疵但内部完好的），把整果的潜在损耗转化为切果毛利，这是关键收益点。

## 必须算清的三个数

- **损耗率**：整果自然损耗通常低；切果去皮去芯损耗高（果肉得率约50%–60%），且当日卖不掉基本报废。
- **人工与冷链成本**：切果要算人工工时+冷藏电费+包装，摊不进售价就是假毛利。
- **动销速度**：切果必须当日或次日售罄，卖不动就立刻缩量，不要为了“品类齐全”硬切。

## 执行建议

- 先小批量试：整果正常陈列，切果每天只切固定小量（如5–10盒），观察3–7天动销和报损。
- 切果设**时段策略**：上午/午休前切，傍晚上架打折清尾，避免隔夜。
- 整果做**分级**：一级果正价卖，二级果转切果或做促销，减少整体报损。
- 每周复盘切果的“售罄率+报损率+毛利额”，售罄率低就减量或停切。

**一句话结论**：客群偏家庭、人手紧的门店以整果为主；客群偏年轻便利、有冷链和切果能力的门店加切果；绝大多数门店用“整果走量+次优果切盒提毛利”的组合最稳，但切果量必须按动销数据动态控制，不能凭感觉铺货。
