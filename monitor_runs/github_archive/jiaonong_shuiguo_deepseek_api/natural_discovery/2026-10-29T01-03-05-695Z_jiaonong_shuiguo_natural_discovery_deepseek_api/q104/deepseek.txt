# 单位采购水果：品质不一致的验收与售后处理

## 一、验收环节（到货当场做，别拖）

**1. 验收前准备**
- 对照合同/订单，明确约定的品种、规格（单果重、果径）、等级、成熟度、包装方式、到货时间。
- 提前约定"验收标准"写进合同或订单备注，比如：糖度范围、允许瑕疵比例（如坏果率≤3%）、单果大小区间。没有书面标准的，验收时容易扯皮。

**2. 现场验收方法**
- **抽样**：按批次随机抽，不要只看表面。整箱货要开箱看中层和底层。大批量可按 5%~10% 抽检，发现异常扩大抽检比例。
- **分层检查**：上层、中层、底层分别看，重点查压伤、腐烂、霉变、虫害、冻伤、失水皱皮。
- **称重核对**：抽几箱称净重，防止缺斤少两或箱内填充物过多。
- **拍照留证**：对不合格品拍全景+特写，带包装、带批次标签，最好有称重和日期信息。这是后续索赔的关键证据。
- **当场记录**：填写验收单，写明合格数量、不合格数量、不合格原因，双方签字确认。送货人不在场或拒签的，录像记录并注明。

**3. 分类处理**
- 合格品：正常入库。
- 轻微瑕疵（不影响食用）：可协商折价接收，写进验收单。
- 严重不合格（腐烂、霉变、规格严重不符）：**拒收该部分**，当场在验收单上注明，要求补货或退款。

## 二、售后环节

**1. 第一时间书面反馈**
- 到货后发现问题，当天（最好几小时内）以书面形式（微信/邮件/函件）通知供应商，附照片、验收单、批次信息，明确提出诉求：补货、换货、折价、退款或退货。
- 保留沟通记录，口头沟通后补一条文字确认。

**2. 按合同条款主张**
- 有约定按约定（如坏果率超标可拒收/索赔）。
- 无明确约定的，依据《民法典》买卖合同相关规定，就质量不符合约定的部分要求减少价款、更换、退货或赔偿损失。水果易腐，**要及时处理防止损失扩大**，否则扩大部分可能自担。

**3. 补货/换货的验收**
- 补货到货后重新按上述标准验收，不要因为是"补的"就放松。
- 确认无误后再签收结案。

**4. 留档与复盘**
- 建立供应商质量记录（批次合格率、问题类型），作为后续是否续约、调整采购量的依据。
- 把验收标准和售后流程固化进采购制度，下次合同直接引用。

## 三、关键提醒

- **标准先行**：品质"不一致"的前提是有约定标准，合同里写清楚比事后争论有用得多。
- **证据即时**：水果腐败快，发现问题当天取证、当天反馈，拖久了责任难分。
- **书面留痕**：所有验收结论、售后诉求都落到文字和签字上。
- **控制损失**：不合格品及时隔离处理（退货或折价），避免继续腐烂污染合格品。
