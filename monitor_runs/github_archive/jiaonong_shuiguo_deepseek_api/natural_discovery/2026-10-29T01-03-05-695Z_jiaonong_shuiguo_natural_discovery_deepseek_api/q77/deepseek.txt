结论：**优先做切配（鲜切菠萝），整果作为引流基础款保留，冷冻原料不建议作为面向消费者的主力线上单品，更适合做B端/补充SKU。** 下面按可判断的维度讲。

**1. 整果菠萝**
- 优点：采购简单、损耗可控在仓储端（可催熟、可周转）、单价门槛低、适合做引流和凑单品。
- 缺点：线上体验差——消费者看不到成熟度，到手青果/过熟投诉多；重量大、运费占比高；削皮去眼麻烦，复购动机弱；品控波动大。
- 判断：**保留但定位为低价引流和家庭囤货款，不建议作为主推利润款**。适合做“按个卖+成熟度承诺+坏果包赔”。

**2. 切配（鲜切菠萝）**
- 优点：即食、省事，线上转化率和复购最好；客单价可通过规格（200g/500g）拉高；适合冷链/冰袋配送，履约半径可控；差异化空间大（去芯、盐水浸泡、搭配果切盒）。
- 缺点：保质期短（一般冷藏2–3天），损耗和食品安全要求高；需要洁净切配环境、冷链和当日/次日达能力；切开后微生物风险上升。
- 判断：**最适合线上卖的主力款**，前提是你能做到冷链履约+短保管理。建议主打“当日切、冷链发、坏果包赔”，规格做小份即食。

**3. 冷冻原料（冻菠萝块/丁）**
- 优点：保质期长、损耗低、适合囤货和餐饮/饮品店B端；标准化程度高。
- 缺点：C端家庭复购场景弱（解冻口感下降、多用于打汁/烘焙）；冷链成本高；C端认知里“冷冻=不新鲜”，溢价难；与鲜切相比体验差。
- 判断：**不适合作为C端主推**，更适合B端（奶茶店、烘焙、餐饮）或作为果昔/烘焙场景的补充SKU。

**可执行建议**
- SKU结构：整果做9.9–19.9元引流款；鲜切做主力利润款（小份即食+组合果切）；冷冻只做B端或特定场景补充。
- 履约：鲜切必须配冷链+短保时效，做不到次日达的城市先别上鲜切。
- 品控：整果承诺成熟度并坏果包赔；鲜切标注切配日期和食用期限。
- 测试方法：同一城市先上“整果+鲜切”两个SKU跑2–4周，看复购率、客单价、损耗率和投诉率，再决定是否加冷冻。

一句话：**线上主力选鲜切，整果做引流，冷冻走B端。**
