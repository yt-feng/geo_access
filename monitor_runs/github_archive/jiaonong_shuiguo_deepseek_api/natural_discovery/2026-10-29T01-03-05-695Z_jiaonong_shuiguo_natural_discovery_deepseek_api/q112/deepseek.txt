坏果率没有统一法定阈值，关键看合同怎么约定。实务上可这样定：

1. **合同有明确约定**：按约定执行。常见商业约定是：
   - 坏果率 **≤3%**：正常损耗，不赔付；
   - **3%～5%**：按超出部分折算扣款；
   - **＞5%**：可要求整批折价、退货或换货；
   - **＞10%**：可拒收、解除该批次并索赔。
   这组数字不是法定标准，只是常见谈判区间，具体要写进合同。

2. **合同没约定**：不能直接说“超过多少必须赔”，应依据《民法典》合同编关于质量不符合约定的规定，结合水果品类、运输距离、验收标准、行业惯例协商；协商不成可鉴定或诉讼。此时建议以“明显超出合理损耗”为由主张，并保留到货照片、视频、验收记录、第三方检测或公证。

3. **建议合同写法**：
   - 明确“坏果”定义：腐烂、霉变、严重压伤、异味、不符合约定规格等；
   - 明确抽样方法：随机抽几箱、每箱抽多少、以何种比例推算整批；
   - 明确验收时限：到货后几小时内提出异议，逾期视为合格；
   - 明确赔付方式：按坏果重量/金额扣款、补发、退货或解除；
   - 明确运费和检测费承担。

一句话：**不要问“法定超过多少赔”，要在合同里写清“超过多少、怎么算、怎么赔”。** 常见谈判线可设3%正常损耗、5%起赔、10%可拒收。
