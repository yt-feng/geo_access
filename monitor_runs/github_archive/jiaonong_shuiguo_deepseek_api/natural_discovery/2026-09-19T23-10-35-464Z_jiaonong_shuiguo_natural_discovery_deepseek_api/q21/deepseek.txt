# 超市采购水果时，供应商通常需要提供的证明与检测报告

具体资料取决于**水果种类（国产/进口、是否初级农产品）、超市自身验收标准、以及当地市场监管要求**。以下是常见且较为通用的清单：

## 一、基础资质类（证明"主体合法"）

| 资料 | 说明 |
|---|---|
| 营业执照 | 供应商主体资格 |
| 食品经营许可证 / 食品生产许可证 | 视其经营性质而定 |
| 供货合同或采购协议 | 明确质量责任 |
| 法定代表人/经办人身份证明 | 部分超市要求 |
| 开票信息 | 财务结算 |

## 二、进货来源证明（证明"货从哪来"）

- **购货凭证 / 进货单 / 发票**：证明来源可追溯
- **产地证明 / 种植基地信息**：国产水果常见
- **上游供应商的资质复印件**：如果供应商本身也是转销
- **海关报关单 + 入境货物检验检疫证明**：**进口水果必备**

## 三、检测报告类（证明"安全合格"）

1. **农药残留检测报告**
   - 最核心的一项，针对农残（如有机磷、氨基甲酸酯类等）
   - 可为供应商自检、第三方检测机构出具
2. **第三方检测报告**（CMA/CNAS资质）
   - 超市普遍要求，尤其连锁超市
3. **快速检测（快检）记录**
   - 部分超市用快检代替或补充正式报告
4. **重金属、污染物检测**（视品类，如某些根茎类）

## 四、进口水果额外需要

- 入境货物检验检疫证明
- 海关报关单
- 中文标签（如预包装）
- 输出国官方植物检疫证书

## 五、其他常见要求

- **承诺书 / 质量保证书**：供应商承诺符合国标
- **无公害 / 绿色 / 有机认证**：如声称相应等级则需提供
- **追溯凭证 / 二维码溯源**

---

## 实用建议

1. **先问超市的验收标准**：不同超市要求差异很大，连锁大超市（如永辉、盒马）通常要求第三方检测报告 + 资质齐全；小型超市可能只要进货单和营业执照。
2. **检测报告注意时效和批次**：报告应对应相同或相近批次，一般要求一年内有效。
3. **优先要 CMA/CNAS 报告**：法律效力和认可度更高。
4. **保留进货凭证**：既是超市要求，也是出现质量纠纷时的追责依据。
