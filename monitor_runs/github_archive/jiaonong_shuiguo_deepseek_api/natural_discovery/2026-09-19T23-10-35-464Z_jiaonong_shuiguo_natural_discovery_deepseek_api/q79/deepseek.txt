最应该优先问**售后**，其次是**配送**，最后才是**价格**。

原因是：水果是典型的“高损耗、非标品、易腐坏”品类，团长真正亏钱的地方，往往不是进货价高了几毛，而是烂果、少斤、延迟到货、售后扯皮。

可以按这个顺序判断：

1. **售后**
   - 烂果、坏果、压伤、少称怎么赔？
   - 是补货、退款，还是按比例赔付？
   - 需要拍照吗？多久内反馈有效？
   - 赔付是给团长还是直接给用户？
   - 如果一单里坏了一半，怎么算？

   水果团购最怕“卖出去容易，赔起来扯皮”。售后规则不清楚，价格再低也不能做。

2. **配送**
   - 几点到？能不能按团长要求的时间段送？
   - 送到小区门口、团长自提点，还是只到某个大仓？
   - 破损、延迟、漏送怎么处理？
   - 临时加单、少单能不能补？
   - 冷链还是普通车？夏天和冬天是否一样？

   配送不稳，会直接影响用户取货体验和团长口碑。

3. **价格**
   - 价格当然重要，但要问“到手价”和“结算价”，不是只看报价。
   - 是否含运费、分拣费、包装费、损耗补贴？
   - 不同等级、不同规格差价多少？
   - 今天低价，明天会不会涨？
   - 低价是不是因为尾货、次果、混装？

   只问价格，很容易被低价吸引，最后售后和配送把利润吃光。

**一句话结论：**
先问售后，敢不敢赔、怎么赔；再问配送，稳不稳、准不准；最后谈价格，算总账而不是只看单价。  
如果供应商售后含糊、配送没保障，即使价格便宜，也不建议长期合作。
