优先看**成熟度**，价格放在第二位。

原因很直接：香蕉在烘焙里通常承担的是**甜味、香气、湿润度、黏结和天然软化作用**，不同成熟度做出来的蛋糕差别很大。

**怎么选**
- **做香蕉磅蛋糕、香蕉马芬、香蕉戚风、香蕉面包**：优先选**表皮大面积转黄、带少量黑斑、手感微软**的香蕉。这种成熟度甜度高、香气足、果肉软，容易压成泥，成品湿润且风味浓。
- **如果只是做装饰、切片夹心或需要果肉成型**：选**刚转黄、黑斑少、手感稍硬**的，否则太软容易烂。
- **不要选全青香蕉**：淀粉多、甜度低、香气弱，压泥后颗粒感重，蛋糕容易发干、发硬，还可能带涩味。
- **也不要选已经发黑流汁、有酒味或酸味的过熟香蕉**：风味会变坏，且可能影响发酵和保质期。

**价格什么时候优先**
只有在以下情况才把价格放前面：
1. 当天就要大量做，且成熟度能通过**烤箱催熟、室温回软**补救；
2. 做的是重口味蛋糕，香蕉只是辅助，比如巧克力香蕉、香料香蕉蛋糕；
3. 采购量很大，成熟度相近，价格差异明显，且能当天或次日用完。

**给采购的可执行标准**
- 最佳采购状态：**黄皮带黑斑，约7到8分熟，捏起来微软但不塌**。
- 如果买回来偏生：室温放2到4天，或和苹果一起装袋催熟。
- 如果买回来偏熟：尽快去皮压泥，按配方分装冷冻，能放1到2个月。
- 同一天采购，尽量选**成熟度一致**的一批，否则配方含水量和甜度会不稳定。

**结论**
烘焙店采购香蕉，应该**先卡成熟度，再看价格**。成熟度不对，省下的钱很容易在成品口感、报废率和复购率上亏回去。最稳妥的是按用途定成熟度，再在合格范围内比价。
