做水果拼盘想更划算，核心不是“买最便宜”，而是**按出成率、损耗、切配人工和卖相**来选规格。按常见餐厅场景，建议这样选：

1. **苹果：选中等偏大、个头均匀的鲜食级**
   - 规格建议：单果约 **180–220g**。
   - 理由：太小削皮去核后出成低、切出来少；太大单价高，而且一个拼盘用不完容易氧化。
   - 划算点：买 **80–90mm 果径的中大果** 通常比精品大果便宜，出成率又比小果高。
   - 注意：优先选脆度高、切开不易发面的品种，如富士、嘎啦、红玫瑰等；做拼盘要泡淡盐水或柠檬水防氧化。

2. **橙子：选皮薄、汁多、大小均匀的鲜橙**
   - 规格建议：单果约 **180–250g**，果径 **70–80mm** 左右。
   - 理由：太小切瓣少、摆盘不够饱满；太大皮厚可能压秤，但如果是按个卖、皮薄，大果反而划算。
   - 划算点：做拼盘常用 **70–75mm 中果**，成本低、切瓣数量稳定；如果要做橙片围边，选 **75–80mm** 更美观。
   - 注意：不要只看重量，皮厚、籽多、干水的橙子损耗很高。

3. **菠萝：选成熟度适中、单果约1.2–1.8kg的**
   - 规格建议：单果 **1.2–1.8kg** 最实用。
   - 理由：太小削皮去眼后剩得少；太大一次用不完，切开后保存差、损耗高。
   - 划算点：如果餐厅用量大，买 **1.5kg左右** 的整菠萝，出肉率通常比较稳；如果只是少量拼盘，直接买 **去皮菠萝果肉/菠萝块** 可能更省人工和损耗。
   - 注意：菠萝出成率一般只有 **50%–65%**，算成本时要按“可用果肉重量”算，不是按整果重量算。

**简单判断公式：**
- 苹果、橙子：看 **单个可切瓣数 ÷ 单价**。
- 菠萝：看 **去皮后净肉重量 ÷ 整果价格**。
- 拼盘综合成本 = 水果净成本 + 削切人工 + 氧化/卖不完损耗。

**最划算的采购组合通常是：**
- 苹果：中等偏大、均匀鲜食果；
- 橙子：70–75mm 中果，或 75–80mm 美观果；
- 菠萝：1.2–1.8kg 整果，量大买整果，量小买去皮果肉。
