如果只能选一个**最该优先关注**的，答案是：**切果损耗**。  
但它不是“唯一指标”，而是超市卖菠萝这种品类里最影响利润和运营的指标。

更实际地说，应该这样排优先级：

1. **切果损耗**
2. **甜度**
3. **外观**
4. **大小**

原因如下：

**1. 切果损耗最该关注**
超市卖菠萝通常不是只卖整果，还会卖去皮、切块、插签的即食菠萝。  
菠萝的损耗很高，来自：
- 去皮去眼损耗大
- 尾部、芯部、过熟部分不能卖
- 切开后出水、氧化、变质快
- 当天卖不完只能报损或折价

所以同样进价的一批菠萝，如果出肉率差，哪怕甜度高、外观好，也可能不赚钱。  
**能算出“每斤切果成本”和“出肉率”，比只看甜度更重要。**

**2. 甜度决定复购**
菠萝是典型“不好吃就没人再买”的水果。  
甜度低、酸涩、刺口，会直接导致：
- 试吃转化差
- 切果卖不动
- 顾客投诉多
- 复购下降

所以甜度不是不重要，而是它决定**卖不卖得动**。  
但甜度通常要切开才知道，不能只靠外观判断。

**3. 外观决定整果销售**
外观主要影响：
- 整果能不能吸引顾客拿起来
- 礼盒或堆头好不好看
- 是否显得新鲜

但菠萝外观和内在甜度、出肉率并不完全一致。  
果皮青一点不一定差，黄一点也可能过熟。  
所以外观重要，但不能作为唯一采购标准。

**4. 大小不是最关键**
大小影响：
- 单价感知
- 切果标准化
- 陈列效果

但太大不一定好卖，太小出肉率可能差。  
超市更应关注**大小是否均匀、是否适合切果和定价**，而不是单纯越大越好。

**实操建议：**
- 采购时先测：**出肉率、切果损耗率、切开后货架期**
- 再测：**糖度、酸度、口感**
- 然后看：**外观整齐度、成熟度一致性**
- 最后定：**按整果卖还是切果卖，定价能不能覆盖损耗**

一句话总结：  
**甜度决定顾客买不买第二次，切果损耗决定超市赚不赚钱；外观和大小是辅助判断，不能排在损耗前面。**
