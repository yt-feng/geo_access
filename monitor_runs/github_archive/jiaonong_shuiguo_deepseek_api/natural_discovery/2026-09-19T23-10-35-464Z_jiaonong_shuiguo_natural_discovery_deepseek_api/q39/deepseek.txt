可以，但通常不是“供应商全包”。要分清楚供应商能帮到哪一层。

**供应商一般能提供的支持**
1. **包装支持**
   - 提供现有通用箱、袋、托盘、网套、礼盒等。
   - 按你的要求做贴牌：印商超LOGO、品名、规格、产地、条码。
   - 做定制包装：起订量通常较高，费用可能由商超承担或摊进单价。

2. **规格支持**
   - 按果径、重量、个数、糖度、成熟度、外观分级。
   - 做不同规格：如单果重、每盒净重、每箱装数。
   - 提供分选、分级、预冷、清洗、打蜡等采后处理。

3. **供应链支持**
   - 稳定货源、产地直发、季节性替换品类。
   - 代贴标签、代打条码、代发门店或仓。
   - 提供质检报告、农残检测、产地证明等。

**但要注意**
- 不是所有供应商都能做定制包装，尤其是小供应商。
- 定制包装通常有**起订量、开版费、打样费**。
- 规格越细，损耗和成本越高。
- 自有品牌责任在你，不在供应商。包装上的品牌、标准、售后、客诉，最终由商超承担。
- 如果只换标签、不控品质，容易做成“有牌子没差异”的伪自有品牌。

**建议你先和供应商谈这几项**
1. 能不能贴商超品牌标签？
2. 最小起订量多少？
3. 包装开版费、打样费谁承担？
4. 能不能按你定的规格分级？
5. 不合格品怎么退换？
6. 能否稳定供货，尤其旺季？
7. 检测报告和产地证明能否随货提供？

**更稳的做法**
- 先做1到2个单品试点，不要一上来全品类。
- 先让供应商提供现有包装贴牌，再逐步做定制包装。
- 规格标准写成书面文件，包括果径、重量、糖度、外观、成熟度、允许损耗。
- 让供应商报“裸果价+包装费+贴标费+物流费”，不要只报一个总价。
- 如果供应商只能供货、不能做包装，你可以找第三方包装厂，但供应链管理会更复杂。

**一句话结论**
供应商通常能提供包装和规格支持，但多数是“按你的标准执行”，不是“替你定义自有品牌”。商超要自己定标准、控品质、担品牌责任。
