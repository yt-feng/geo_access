水果采购合同里，坏果率是否赔付、超过多少赔付，**不是法定统一标准，核心看合同约定**；如果合同没约定，通常按行业惯例、验收标准和实际损失来谈。

给你一个可执行判断：

1. **合同有约定，按合同**
   - 常见写法：到货验收时坏果率≤3%、5%、8%等为合格。
   - 超过约定比例，可要求：
     - 按超标部分扣款；
     - 整批降价；
     - 补货、换货；
     - 退货；
     - 赔偿分拣费、运费、延误损失等。

2. **合同没约定，常见谈判区间**
   - **≤3%**：很多精品果、商超供货、冷链果会按这个标准验收。
   - **5%左右**：普通批发、产地直发较常见。
   - **8%—10%**：部分易损水果或长途运输场景可能接受。
   - 超过这些比例，采购方通常就有理由要求扣款、补货或赔偿。
   - 但这不是法律硬性标准，只是行业常见区间。

3. **更建议这样写进合同**
   - 明确验收时间：到货后几小时内验收。
   - 明确抽检方式：抽多少箱、按重量还是按个数。
   - 明确坏果定义：腐烂、霉变、压伤、冻伤、裂口、异味等。
   - 明确赔付公式：  
     `赔款 = 超标坏果重量 × 单价 × 倍数`  
     或  
     `扣款 = 整批货款 × 超标比例 × 约定系数`
   - 明确处理方式：扣款、补货、退货、运费谁承担。
   - 明确争议处理：复检、第三方检测、照片视频留证。

4. **实操建议**
   - 如果你现在是采购方：建议把合格线写到**3%—5%**，超过部分按双倍或三倍货值扣款，并保留退货权。
   - 如果你是供货方：建议写到**5%—8%**，并约定超出部分只按实际坏果金额赔付，不承担整批责任。
   - 无论哪方，最好约定“超过多少可拒收”，例如：**坏果率超过10%，采购方有权拒收整批。**

一句话：**没有法定“超过多少必须赔”，但合同里最好明确写3%、5%或8%的验收线，并配套扣款/补货/退货条款。**
