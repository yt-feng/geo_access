食堂采购香蕉要避免熟过头浪费，核心是**控制采购成熟度、分批到货、按成熟阶段分流使用**。可以从下面几个环节做：

1. **采购时选偏生一点的香蕉**
   - 优先买“青黄交界、果肉还硬”的香蕉，别买已经全黄、带黑斑、果柄发软的。
   - 跟供应商明确到货成熟度标准，比如：果皮青绿转黄、无黑斑、手感硬实。最好写进采购验收标准。
   - 如果供应商只能给熟蕉，就要求分等级：一部分偏生，一部分即食。

2. **分批到货，不要一次囤太多**
   - 按食堂日均用量估算，比如每天吃多少根/多少斤，一次只进 2～3 天量。
   - 夏天或室温高时，香蕉后熟很快，建议一次进 1～2 天量；冬天可稍多。
   - 和供应商约定“小批量、多频次”配送，减少库存积压。

3. **入库后控温、控乙烯**
   - 香蕉未熟时不宜直接进冰箱冷藏，否则容易冻伤变黑；应放在阴凉通风处。
   - 已经成熟或接近成熟的香蕉，可放冷藏或冷柜暂存，延缓继续变软，但时间也别太长。
   - 不要把香蕉和苹果、梨、番茄等释放乙烯多的果蔬混放，会加速成熟。
   - 整串香蕉可拆开、用保鲜膜包住果柄，减少乙烯释放和水分流失。

4. **按成熟度分流使用**
   - 刚偏生的：放几天自然熟，适合直接发。
   - 已成熟但还完好的：优先当天直接供应。
   - 出现少量黑斑、但果肉没坏的：可做香蕉奶昔、香蕉粥、香蕉饼、烘焙香蕉蛋糕等，不要等烂了再处理。
   - 已经软烂、有酒味或霉变的：坚决废弃，不能加工再用。

5. **每天盘点，设置预警**
   - 每天检查一次香蕉成熟度，分“生、适中、即食、待处理”四类。
   - 对“即食”和“待处理”的香蕉贴标签，优先出库。
   - 如果第二天预计吃不完，提前改菜单，把香蕉用于加工菜品，而不是继续放着。

6. **和菜单、用量联动**
   - 如果当天水果是香蕉，按实际就餐人数略少备一点，避免“人手一根”后大量剩回。
   - 自助餐场景可切成小段供应，减少整根拿走后不吃造成的浪费。
   - 记录每周香蕉消耗量和剩余量，下次采购按数据调整。

简单说就是：**买偏生、少囤货、避乙烯、勤盘点、熟了就分流加工，烂了才扔。**  
其中最关键的是：**不要一次性采购全熟香蕉，并且按 1～3 天用量分批配送。**
