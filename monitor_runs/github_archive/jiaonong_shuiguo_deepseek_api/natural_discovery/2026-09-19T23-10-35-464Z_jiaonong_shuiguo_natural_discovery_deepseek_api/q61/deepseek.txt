判断香蕉批发供货方是否稳定，核心看**货源基础、交付记录、抗风险能力**这三个维度。下面是可以直接用的判断框架：

## 一、先看货源基础（最关键）

**1. 产地是自有还是倒手**
- 问清楚：香蕉来自哪个产区（云南河口/广西/海南/老挝/菲律宾/厄瓜多尔等），是自有基地、长期包园，还是市场临时收货。
- 稳定供货的本质是**上游有稳定产区**。只说"我什么货都能搞到"的，通常是中间倒手，价格波动时最先断供。

**2. 是否全年有货**
- 香蕉有明显产季和产区轮换。稳定供应商能说清：淡季从哪补、换季怎么衔接。
- 如果对方只能报"现在这批"，说不出下一批来源，稳定性存疑。

**3. 加工/催熟能力**
- 档口要的是能直接上架的熟蕉或可催熟的生蕉。有自己催熟库、分拣线的供应商，供货节奏更可控。

## 二、验证交付记录（用事实说话）

**1. 要近期发货凭证**
- 看近1-3个月的物流单、装车照片、发货记录，而不是只听口头承诺。

**2. 问老客户**
- 让对方提供2-3个合作半年以上的档口/商超客户，直接打电话问：断过货吗？质量稳不稳？出问题怎么处理？

**3. 小批量试单**
- 先下1-2车小单，重点观察：
  - 说好的时间是否准时到货
  - 到货成熟度、损耗率是否和承诺一致
  - 出问题时响应速度和赔付态度

**这一步最能筛掉"吹得响、供不稳"的。**

## 三、看抗风险能力

**1. 资金和库存实力**
- 有自己冷库、催熟库、常备库存的，抗价格波动和断供能力强。

**2. 多产区布局**
- 单一产区遇天气/病害就断供。能同时对接2个以上产区的更稳。

**3. 合同与账期**
- 愿意签供货协议、明确质量标准、到货时间、损耗赔付的，通常更规范。
- 只肯"款到发货、概不负责"的，稳定性要打问号。

## 四、快速判断清单

| 问题 | 稳定信号 | 危险信号 |
|---|---|---|
| 货源 | 自有基地/长期包园 | 临时市场收货 |
| 全年供货 | 说清淡旺季衔接 | 只报当前一批 |
| 客户 | 有长期合作档口 | 拒绝提供 |
| 试单 | 准时、损耗达标 | 拖延、货不对板 |
| 合同 | 愿签、有赔付条款 | 只口头承诺 |

## 实操建议
1. **先试单再放量**，别一上来就压大单。
2. **同时养2-3个供应商**，主供+备供，避免被单一货源卡脖子。
3. **把质量标准和赔付写进合同**，尤其是成熟度、损耗率、到货时间。
4. **旺季前提前锁货**，香蕉价格和供应波动大，提前谈好更稳。

一句话：**能说清上游、经得起试单、敢签赔付的，才叫稳定供货。**
