小水果店做附近小区团购，水果供应商至少要能支持下面这几类服务，否则团购很容易在履约和品控上翻车。

**1. 稳定供货与按团购节奏发货**
- 能按你设定的团购周期（比如每周2次、每次截单后次日到货）稳定供货。
- 支持小批量、多批次补货，不要一次压太多货。
- 截单后能快速确认库存和缺货，避免团购已收款却发不出货。

**2. 分级与品控**
- 能按你要求的规格分级，比如大小、甜度、成熟度、净重。
- 支持“团购专供包装”，比如5斤装、家庭装、独立小包装。
- 坏果、烂果、次果的赔付标准要明确，最好有照片/视频留证流程。

**3. 价格与结算支持**
- 能给你团购专属价，而不是零售批发混着算。
- 支持阶梯价：量小一个价、量大有返点或更低单价。
- 结算方式灵活：现结、周结、月结，或押金+账期。
- 价格波动提前通知，避免你今天开团、明天进货价大涨。

**4. 配送与到店支持**
- 能送到你的小店，而不是只送到大仓或批发市场。
- 支持约定时间送达，最好能配合你小区团购的到货日。
- 如果供应商能直送小区自提点，价值更高，但你要确认分拣、交接和售后谁负责。
- 冷链水果要有冷链配送能力，普通水果也要避免暴晒、挤压。

**5. 售后与损耗处理**
- 坏果包赔、少重补差、错发补发，规则要写清楚。
- 支持快速响应，最好当天或次日处理，不要拖到团购售后爆发。
- 能接受退货或换货，而不是只赔下一单抵扣。
- 对高风险水果（草莓、荔枝、樱桃等）要有专门售后方案。

**6. 营销与素材支持**
- 提供水果实拍图、短视频、规格说明、产地信息。
- 能配合你做团购海报、接龙文案、朋友圈素材。
- 愿意给你做“团购爆品”建议，比如当季高毛利、易配送、售后少的品。
- 能提前告诉你哪些品不适合团购，比如太熟、太娇气、运输损耗大。

**7. 数据与对账支持**
- 每批货有明细：品名、规格、数量、单价、金额、损耗。
- 支持按团购批次对账，方便你算每团利润。
- 能提供缺货、补货、售后记录，减少你和小区邻居扯皮。

**8. 灵活合作模式**
- 支持代发：你接单，供应商按单配货到店或到自提点。
- 支持联营：你负责小区团购，供应商负责供货和部分售后。
- 支持试销：先小批量试几个爆品，跑通后再放量。

**你选供应商时重点看这5条：**
1. 能不能按你的团购节奏稳定送货。
2. 坏果售后规则是否清晰、响应快不快。
3. 团购价是否真正低于你零售拿货价。
4. 能不能给图片、文案和选品建议。
5. 对账是否简单，能不能按批次算清利润。

**建议你先谈一个最小合作方案：**
选3—5个易配送、售后少的水果，比如苹果、橙子、香蕉、圣女果、梨，先跑2—3个小区团。要求供应商支持：按团购价供货、送到店、坏果包赔、提供素材、按批次对账。跑通后再扩品和谈账期。
