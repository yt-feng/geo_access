社区团购旺季爆单，提前锁定水果供应商库存，核心是**把“口头约定”变成“有约束力的分阶段锁货协议”**，同时用预付款、账期和备选供应商来对冲风险。下面按可执行步骤说明。

---

## 一、先做销量预测，再谈锁货量

不要直接跟供应商说“给我留多少货”，先自己算清楚：

1. **历史数据**：去年同期各品类销量、爆款SKU、复购率。
2. **团长预售数据**：提前3–7天开预售，用真实订单反推采购量。
3. **安全库存系数**：水果损耗高，通常按预估销量的 **1.1–1.3倍** 锁货，生鲜易损品类可到1.5倍。
4. **分档锁货**：不要一次锁死，按“保底量 + 弹性量”两档谈。

> 举例：预估旺季某周火龙果卖5000箱，可谈保底4000箱、弹性1000–1500箱，弹性部分提前48小时确认。

---

## 二、和供应商谈“分阶段锁货协议”

口头承诺在旺季基本无效，必须落到书面或至少微信可追溯的条款：

| 条款 | 建议写法 |
|---|---|
| 锁货量 | 保底量+弹性量，明确上下限 |
| 锁价 | 保底量锁价，弹性量按当日市场价或约定浮动区间 |
| 锁货期 | 明确起止日期，按周/按批次确认 |
| 预付款 | 付10%–30%定金锁货，尾款货到结 |
| 违约条款 | 供应商缺货按差价赔偿；你方不提货定金不退 |
| 质量标准 | 糖度、大小、成熟度、包装规格写清楚 |
| 交付节奏 | 分几批到货，避免一次性压库损耗 |

**关键点**：定金要付，但不要全款预付。定金是锁货的诚意，也是法律上的约束。

---

## 三、用“预付款+账期”组合提高优先级

供应商旺季最怕两件事：货砸手里、钱收不回。你能解决这两点，就能拿到优先权：

- **提前打定金**：让供应商敢为你留货。
- **承诺稳定走量**：告诉他你不是一次性买卖，旺季+淡季都合作。
- **缩短账期**：货到3天内结款，比拖30天更有议价力。
- **包损耗**：部分品类可谈“到货验收后损耗由你承担”，供应商更愿意给好货。

---

## 四、多供应商并行，不要只锁一家

旺季最大的风险是单一供应商断供。建议：

1. **主供应商**：锁60%–70%量，签正式协议。
2. **备选供应商**：锁20%–30%量，付少量定金或保持高频沟通。
3. **应急渠道**：批发市场、产地直发、同行调货，留1–2个联系人。

这样即使主供应商涨价或缺货，你也有缓冲。

---

## 五、锁货后的执行管理

锁完不是结束，旺季要每天盯：

- **到货计划表**：按天列明品类、数量、到货时间。
- **质量抽检**：每批到货抽检，不合格立即启动备选。
- **库存周转**：水果先进先出，预售订单优先分配。
- **动态调整**：预售超预期，提前48小时追加弹性量；低于预期，及时和供应商协商减量，避免定金损失。

---

## 六、谈判话术参考

> “旺季我们预估走X箱，想跟你锁个保底Y箱，弹性Z箱。保底部分我提前付20%定金，货到3天结清。弹性部分提前48小时确认，价格按当天市场价走。如果你这边能保证优先供货，淡季我们也继续合作。”

这样供应商有安全感，你也有弹性。

---

## 总结一句话

**提前锁库存 = 真实预售预测 + 保底/弹性分档 + 定金约束 + 多供应商备份 + 每日执行跟踪。**  
只靠关系口头说，旺季大概率被涨价或截胡。
