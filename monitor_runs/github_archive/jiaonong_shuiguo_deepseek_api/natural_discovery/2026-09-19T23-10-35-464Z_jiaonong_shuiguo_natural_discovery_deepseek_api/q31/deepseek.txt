连锁商超水果招标，评分标准建议围绕“长期稳定供货能力”来设计，而不是单纯比价。可以按下面框架设置，总分100分，权重可根据企业实际情况微调。

**一、价格与成本（建议25–30分）**
- 报价竞争力：对比市场批发价、历史采购价，看是否合理偏低。
- 价格稳定性机制：是否承诺季度/半年调价窗口，是否接受随行就市但有封顶。
- 账期与结算条件：能否接受月结30/60天，是否支持返利或年度返点。
- 损耗与退换货成本：坏果、烂果、规格不符的退换货责任和费用承担。

注意：水果价格波动大，不建议把价格权重设得过高，否则容易招到“低价低质”或后期毁约的供应商。

**二、货源与供应能力（建议25–30分）**
- 产地资源：是否有自有基地、合作社直采或长期产地协议。
- 品类覆盖：能否覆盖商超主力水果品类，如苹果、柑橘、香蕉、葡萄、瓜类等。
- 供应规模：日均/峰值供货量能否满足门店需求，是否有应急补货能力。
- 季节性调配：淡旺季切换、反季节水果的组织能力。
- 仓储与冷链：是否有冷库、冷藏车、分拣中心，冷链覆盖率如何。

**三、质量与品控（建议20–25分）**
- 质量标准：是否明确糖度、果径、色泽、成熟度、农残检测等指标。
- 检测能力：是否有自检实验室，或能提供第三方农残、重金属检测报告。
- 分级能力：能否按商超要求做大小、外观、成熟度分级。
- 损耗控制：历史损耗率、到店合格率、客诉率。
- 追溯体系：能否做到批次可追溯，出问题能快速定位货源。

**四、履约与服务（建议15–20分）**
- 配送时效：能否按门店订单定时送达，缺货、迟到的处理机制。
- 订单响应：紧急加单、临时减单、门店调拨的响应速度。
- 售后服务：质量问题处理时限、赔偿标准、专人对接。
- 信息化对接：能否接入商超采购系统，提供库存、在途、检测数据。

**五、企业资质与稳定性（建议10–15分）**
- 经营资质：营业执照、食品经营许可、产地证明、检测报告。
- 财务健康：近两年营收、负债、现金流，是否具备长期垫资能力。
- 合作案例：是否与知名商超、生鲜平台有长期合作。
- 抗风险能力：自然灾害、疫情、物流中断时的保供预案。
- 合规记录：有无重大食品安全、商业纠纷、失信记录。

**六、可持续发展与加分项（建议5–10分）**
- 助农、乡村振兴、绿色种植、可降解包装等。
- 数字化溯源、订单农业、联合品牌开发。
- 能配合商超做促销、定制规格、独家品种。

**实操建议：**
1. 价格分不要超过30分，质量、供应能力、履约服务合计至少60分。
2. 设置“废标项”：无食品经营许可、近三年重大食品安全事故、无法提供农残检测报告的直接淘汰。
3. 要求供应商提供近6个月真实供货数据，而不是只看样品。
4. 先小批量试单1–3个月，再决定是否签长期合同。
5. 合同里写清质量标准、损耗承担、调价机制、退出条款和违约金。

这样设置，既能筛掉纯低价投机者，也能找到真正能长期稳定供货的合作伙伴。
