要点：**香蕉到店后很快变黑，主要是“已经催熟 + 温度波动 + 挤压/密封”共同造成的。采购时就要按成熟度分级，到店后控温、控湿、减少挤压，并做少量多次补货。**

可直接执行的建议：

1. **采购时不要只买一种成熟度**
   - 选**青黄相接、果柄还偏绿**的香蕉，适合放 2–3 天。
   - 少量买**已经黄熟、无黑点**的，当天或次日用。
   - 避免买**果柄发黑、表皮有黑斑、摸起来软塌**的，这种到店后基本很快变黑。

2. **看运输和到货温度**
   - 香蕉怕冷也怕热。**未熟香蕉不宜低于 13℃左右**，熟香蕉可在较凉环境短放，但不要直接放冷藏。
   - 如果夏天到货时已经发热、箱内闷湿，后面会黑得很快。到店后先**开箱散热**，不要立刻密封堆压。

3. **到店后先分级，不要整箱闷着**
   - 按成熟度分：青的、微黄的、黄熟的。
   - 青的放阴凉通风处继续后熟；黄熟的优先用或放凉柜短存。
   - **不要整箱套塑料袋密封**，水汽和乙烯会加速变黑。需要覆盖时用透气纸或留通风口。

4. **减少挤压和堆叠**
   - 香蕉受压部位最容易先黑。堆放不超过 2–3 层，箱内用纸隔开。
   - 不要和苹果、梨、番茄等释放乙烯较多的水果放在一起，会催熟香蕉。

5. **控制湿度，别让表面凝水**
   - 环境保持通风、相对干燥一点。表皮有水珠时及时擦干或摊开晾。
   - 冷藏只适合**已熟且要短期保存**的香蕉，且容易表皮变黑，甜品店若只取果肉，可接受表皮变黑但果肉未坏；若要求外观，尽量不冷藏。

6. **采购策略：少量多次**
   - 按 1–2 天用量下单，别一次囤太多。
   - 夏天、雨季、运输时间长时，采购量再下调。
   - 和供应商约定“到货成熟度”，例如偏青、无黑点、果柄绿。

7. **到店后的快速处理**
   - 先挑出已经软熟、有黑点的，优先做香蕉泥、奶昔、烘焙馅料。
   - 表皮轻微黑点但果肉完好的，可尽快去皮冷冻保存果肉。
   - 发现一箱里有发黑腐烂的，立刻挑出，避免乙烯和霉菌影响其他香蕉。

简单判断标准：
- **想放 2–3 天**：买青黄相接、果柄绿。
- **想当天用**：买黄熟、无黑点。
- **已经大量黑斑、软塌**：不要采购，除非当天立刻加工。
