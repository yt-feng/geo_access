批量配送水果给公司下午茶，核心是“稳定、省事、少损耗”，而不是单纯比价。可以按下面几步来选。

**1. 先定标准，再找供应商**
- **数量**：按人头算，一般每人 150–250g 净果肉比较合适；比如 50 人，约 10–15 斤净果。
- **形式**：整果、切果盒、拼盘，配送和保存难度完全不同。切果盒省事但损耗和食品安全风险更高，整果更稳。
- **时间**：要求固定时段送达，比如下午 2 点前，避免太早放坏或太晚影响体验。
- **预算**：按“元/人”定，不要只按斤价，因为含切配、包装、配送后总成本差别很大。

**2. 优先看这几类供应商**
- **本地水果批发商/农批市场档口**：价格低，适合整果批量，但通常不包切配，配送要自己谈。
- **生鲜配送平台的企业购**：如美团小象、盒马、叮咚等有企业团购或大客户渠道，配送稳定，售后相对规范。
- **专业果切/下午茶供应商**：适合要切好、摆盘、分装的场景，单价高，但省人力。
- **本地连锁水果店**：可谈长期团购价，适合 20–100 人规模，灵活性高。
- **企业团餐/下午茶综合服务商**：如果公司本来就有团餐供应商，直接加水果项最省事。

**3. 重点核验这几个能力**
- **能否稳定日配/周配**：不是一次能送，而是每周同一时间都能送。
- **是否有冷链或温控**：切果必须冷链；夏天整果也要避免暴晒配送。
- **包装是否适合分发**：按部门/楼层分袋、贴标签，比一大箱混装省很多事。
- **售后规则**：坏果、漏送、晚到怎么赔，最好写进订单或聊天记录。
- **资质**：食品经营许可证、切果环节的卫生条件，切果类尤其要看。

**4. 建议的比价方式**
找 3 家同时报价，统一条件：
- 同样人数、同样水果品种、同样送达时间
- 问清楚：是否含切配、包装、配送费、税点
- 要一次试送，别直接签长期

**5. 适合批量配送的水果选择**
- **稳的**：香蕉、橘子、苹果、梨、圣女果、葡萄（需冷藏）、西瓜（切配后尽快吃）
- **慎选**：草莓、蓝莓、切好的火龙果/芒果，易压坏、易氧化，配送要求高
- **夏季**：优先西瓜、哈密瓜、圣女果，少选易烂的浆果
- **冬季**：橘子、橙子、苹果、梨更稳

**6. 实操建议**
- 先小批量试 1–2 次，观察准时率、坏果率、员工反馈。
- 固定 1 家主供应商 + 1 家备用，避免临时断供。
- 合同或订单里写明：送达时间、数量、坏果赔付、临时加单规则。
- 如果公司有行政或前台，指定一个人对接，避免多头沟通。

简单说：**整果找本地批发或生鲜企业购，切果找专业下午茶供应商；先试送，再签长期，重点看准时、损耗和售后。**
