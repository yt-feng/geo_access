第一次找水果供货商，建议按“小批量、多批次、可对比”来试单，不要一上来就压大货。夫妻店现金流和损耗都敏感，试单核心是看三件事：品质稳定性、到店损耗、结算与售后。

**一、试单顺序**
1. 先锁定3家以内供货商：
   - 本地批发市场档口1家
   - 产地或一级批发商1家
   - 同行推荐或配送平台1家
2. 每家先拿同一品种、同一规格的小批量，不要混着拿太多品。
3. 第一次试单建议只做香蕉、苹果、橙子中的2-3个品，每个品少量拿，例如：
   - 香蕉：1-2箱
   - 苹果：1-2箱
   - 橙子：1-2箱
   具体箱重按你当地批发规格来，不要按“大概”下单，要问清净重、毛重、个数/斤数。

**二、三个常见品怎么试**
- **香蕉**：重点看成熟度、青黄比例、是否催熟均匀、到店后能否放2-3天。第一次别拿全黄或全青，选适合你门店客流周转的熟度。问清是“代催熟”还是“自然熟”，损耗谁承担。
- **苹果**：重点看规格是否统一、硬度、糖度、碰伤和黑心。试单要拆箱检查上下层是否一致，避免“上面大果、下面小果”。
- **橙子**：重点看皮厚薄、酸度、水分、大小均匀度。第一次可拿不同产区或不同规格各少量，让顾客试吃反馈，再决定主推哪个。

**三、试单要问清的条件**
1. 价格：是含税/含运费到店价，还是自提价。
2. 起送量：多少箱起送，能否混拼。
3. 结算：现结、周结还是月结，有没有押金。
4. 售后：坏果、烂果、重量不足怎么赔，是补货还是扣款。
5. 退换：当天反馈还是24小时内反馈，拍照留证要求是什么。
6. 配送：几点到店，是否固定，临时补货加不加钱。
7. 等级：同一品种分几级，你拿的是哪一级，别只听“好货”。

**四、试单后怎么判断**
连续试2-3次，每次记录：
- 到店净重和标称差多少
- 坏果率大概多少
- 顾客复购和投诉
- 实际毛利
- 供货商响应速度

如果一家供货商：
- 第一次好、第二次差，说明不稳定；
- 价格低但损耗高，实际成本可能更贵；
- 售后推诿，后面很难合作。

**五、夫妻店实操建议**
- 第一次不要只找一家，也不要同时找太多，2-3家对比最合适。
- 每个品先小箱试，卖完再补，别囤。
- 香蕉和橙子可以稍多试，苹果相对耐放，但也要看门店客流。
- 把“到店价+损耗+售后”算成真实成本，不要只看报价。
- 试单期用现金或短账期，避免被压货和欠款绑住。

简单说：**同品、少量、多批次、拆箱检查、记录损耗、对比售后**。跑完2-3轮，再定主供货商和备用供货商。
