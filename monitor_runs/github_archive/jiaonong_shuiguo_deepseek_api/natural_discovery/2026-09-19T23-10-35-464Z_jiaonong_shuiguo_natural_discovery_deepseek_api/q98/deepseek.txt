判断养老院或医院食堂的水果供应商，核心是两条线：**合规资质能不能兜底，履约稳定性能不能扛住日常和突发需求**。下面给你一套可以直接落地的核查清单。

## 一、合规：先看"证"和"票"

**1. 主体资质**
- 营业执照：经营范围要包含水果销售/农产品销售，且在有效期内。
- 食品经营许可证（或食品生产/流通相关许可）：水果虽属初级农产品，但涉及清洗、分切、预包装配送的，必须有对应许可。
- 若供应商是种植基地直供：要农业相关证明，同时确认其有配送主体的合规资质。

**2. 检测与追溯**
- 农残检测报告：要求**每批次或至少每月**提供，重点看是否有第三方检测机构盖章，检测项目是否覆盖常见农残。
- 进货凭证/源头凭证：能说清水果从哪来，最好有产地证明或基地协议。
- 追溯能力：出问题时能不能快速锁定是哪一批、来自哪个基地。

**3. 票据合规**
- 能开正规发票，走公对公结算。
- 送货单、验收单、检测报告三者能对应上同一批次。

**判断口诀**：证照全、报告真、批次对得上、发票开得出。

## 二、稳定性：看"人、货、链、应"

**1. 供应能力**
- 有没有固定合作基地或稳定货源？问清产地和季节替代方案。
- 旺季/淡季、极端天气时怎么保供？有没有备选产地或备选供应商。
- 日均供货量能否覆盖你的峰值需求，而不是只够平时。

**2. 物流与冷链**
- 配送车辆是否专用、是否清洁、有无温控（尤其夏季和易腐水果）。
- 配送频次和时间是否固定，能否配合食堂备餐节奏。
- 缺货、迟到、临时加单的响应机制和时限。

**3. 品控与售后**
- 验收标准是否书面化：规格、成熟度、损耗率、坏果处理。
- 退换货规则：坏果率超过多少可退换，多久内响应。
- 有没有历史履约记录可查，比如服务过哪些同类机构。

**4. 经营健康度**
- 公司成立年限、注册资金、是否频繁变更法人或地址。
- 是否存在大量诉讼、被执行、经营异常记录（可通过公开企业信息查询）。
- 是否过度依赖单一客户，反过来也可能影响对你的稳定性。

## 三、实操验证方法

1. **索证索票**：一次性要齐营业执照、许可证、检测报告样本、发票样本。
2. **实地或视频看仓**：看仓储、分拣、冷链条件，别只看办公室。
3. **小批量试供**：先试供2–4周，记录到货准时率、坏果率、单据完整率。
4. **交叉验证**：问其现有客户（尤其是医院/养老院）的实际评价。
5. **合同兜底**：把质量标准、检测要求、退换货、断供应急、违约条款写进合同。

## 四、快速判断标准

| 维度 | 合格线 | 危险信号 |
|---|---|---|
| 资质 | 证照齐全、可开票 | 只有收据、证照过期 |
| 检测 | 有批次/月度报告 | 拒绝提供或只有口头承诺 |
| 供应 | 有备选货源和应急方案 | 只靠一个产地、说"没问题" |
| 物流 | 专用车、有温控 | 混装、无冷链 |
| 售后 | 书面退换规则 | 坏果自负、拖延处理 |
| 经营 | 记录正常、有同类客户 | 频繁变更、涉诉多 |

**一句话结论**：合规看"证、检、票"能不能闭环，稳定看"源、运、应、赔"能不能落地。先小批量试供验证，再用合同把标准和责任锁死，比只看报价可靠得多。
