餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找**稳定、能小批量、能按你要的规格处理、售后不扯皮**的供应商。可以按下面顺序选。

## 1. 优先找这4类供应商

**① 本地水果批发市场的固定档口**
- 适合：每天少量、品类不多。
- 优点：可当天补货，能挑货，价格比零售低。
- 省心做法：固定1-2家档口，谈好“每天几点前下单、几点送到、坏果怎么赔”。
- 注意：要选做餐饮供货的档口，不是只做零售的。

**② 生鲜配送平台/本地B2B配送商**
- 如美菜、快驴、地方生鲜配送公司等。
- 优点：手机下单，次日或当日送，发票、售后相对规范。
- 适合：不想每天跑市场、要省人工的店。
- 注意：少量订单可能起送价高，品质波动要看具体仓库。

**③ 专业餐饮水果供应商**
- 专门给餐厅、酒店、奶茶店、果切店供货。
- 优点：能按你的要求做清洗、切配、分装，规格稳定。
- 适合：做果盘、沙拉、甜品、赠果的店。
- 注意：通常有起送量，价格比批发市场略高，但省心。

**④ 周边水果店/社区团购团长合作**
- 适合：每天只要几斤，量很小。
- 优点：灵活、可临时补。
- 缺点：价格不一定低，长期稳定性一般。
- 适合作为备用渠道，不适合唯一依赖。

## 2. 选供应商时重点看这6点

1. **能不能小批量配送**：每天几斤、十几斤是否送。
2. **配送是否准时**：餐饮最怕早上不到货。
3. **坏果赔付规则**：拍照即赔，还是必须当场拒收。
4. **能否按规格供货**：比如苹果80-85mm、柠檬中果、西瓜固定甜度。
5. **是否支持临时加单**：周末、节假日、突然爆单时很重要。
6. **账期和发票**：月结还是现结，能否开票。

## 3. 最省心的合作方式

建议你采用：

**1家主供应商 + 1家备用供应商**

- 主供应商：本地批发市场档口或生鲜B2B，负责日常稳定供货。
- 备用供应商：周边水果店或另一个档口，临时缺货、品质差时顶上。

谈合作时直接说清楚：
- 每天几点前微信/电话下单；
- 几点前送到；
- 坏果率超过多少怎么赔；
- 连续几次品质差就换人；
- 先试供1-2周再定长期。

## 4. 不同用量下的推荐

- **每天5-10斤，1-2个品种**：周边水果店 + 生鲜平台备用。
- **每天10-30斤，3-5个品种**：本地批发市场固定档口，或本地生鲜配送。
- **每天30斤以上，或要切果/果盘**：专业餐饮水果供应商。
- **奶茶店、甜品店、果切店**：优先找能做净果、切配、分装的供应商。

## 5. 最省心的结论

如果你量不大，最省心的是：

**本地水果批发市场里做餐饮配送的固定档口 + 一个生鲜B2B平台备用。**

如果你完全不想管品质和切配，就找：

**专业餐饮水果供应商，接受价格高一点，换稳定和售后。**

不要只找一家，也不要只图便宜。餐饮水果最容易出问题的不是价格，而是**今天不送、明天不甜、坏了不赔**。先试供两周，看准时率、坏果率、售后速度，再决定长期合作。
