水果礼盒要好卖，核心不是“把好水果堆一起”，而是**让顾客一眼看懂适合送谁、多少钱、有没有面子**。苹果、橙子、香蕉、菠萝这四样里，菠萝和香蕉其实不太适合做高端礼盒，更适合做“实惠型/家庭型/开业型”。

下面给你一套能直接落地的搭配方案。

## 一、先定主次，不要平均搭配

这四种水果的角色不一样：

- **苹果**：礼盒主力，寓意平安，耐放，颜值稳，适合做主角。
- **橙子**：礼盒主力，寓意成功、吉利，颜色喜庆，和苹果是黄金组合。
- **香蕉**：适合配角，便宜、显量，但容易压伤、变黑，不适合高端礼盒。
- **菠萝**：适合做“开业/旺财”主题，个头大、有气势，但带刺、占空间、处理麻烦，不适合混太多。

所以建议：
- **主推款**：苹果 + 橙子
- **走量款**：苹果 + 橙子 + 香蕉
- **特色款**：苹果 + 橙子 + 菠萝
- **高端款**：苹果 + 橙子 + 少量进口水果，不建议放香蕉

## 二、4种具体搭配方案

### 方案1：平安成功礼盒（最好卖）
**苹果 + 橙子**

- 苹果：6个
- 橙子：6个
- 寓意：平安 + 成功
- 适合：探病、看望长辈、普通送礼、公司小福利
- 定价：中档
- 优点：耐放、好看、损耗低、四季都能卖

这是你最应该主推的款，因为苹果和橙子最稳，顾客也最容易接受。

### 方案2：家庭实惠礼盒（走量）
**苹果 + 橙子 + 香蕉**

- 苹果：5个
- 橙子：5个
- 香蕉：1把（约5-6根）
- 寓意：平安、成功、招财
- 适合：家庭自用、员工福利、社区团购
- 定价：偏低档
- 注意：香蕉要单独用纸包一下，避免压伤其他水果

这款利润薄一点，但容易走量，适合做促销引流。

### 方案3：开业旺财礼盒（有特色）
**苹果 + 橙子 + 菠萝**

- 苹果：6个
- 橙子：6个
- 菠萝：1个
- 寓意：平安、成功、旺来
- 适合：新店开业、公司送礼、乔迁
- 定价：中高档
- 注意：菠萝要选小一点、冠芽漂亮的，否则盒子很难看

这款适合做差异化，别人没有，你就有记忆点。

### 方案4：混搭丰富礼盒（不建议主推）
**苹果 + 橙子 + 香蕉 + 菠萝**

- 苹果：4个
- 橙子：4个
- 香蕉：1小把
- 菠萝：1个
- 适合：图便宜、图种类多的顾客
- 问题：香蕉易坏、菠萝占地、整体不高级

这款可以做成低价团购款，但不要当门面主推。

## 三、怎么摆更好卖

### 1. 按价格分三档
- **39-59元**：苹果+橙子+香蕉，走量
- **69-99元**：苹果+橙子，主推
- **109-159元**：苹果+橙子+菠萝，特色/开业

顾客最容易在中间档下单，所以你把**苹果+橙子**做成爆款。

### 2. 按场景贴标签
不要只写“水果礼盒”，要写：
- 平安成功礼盒
- 开业旺财礼盒
- 探病慰问礼盒
- 员工福利礼盒
- 家庭分享礼盒

顾客不是买水果，是买“送人的理由”。

### 3. 苹果和橙子要选对
- 苹果选红富士、花牛等颜色红的，不要青苹果为主
- 橙子选脐橙、沃柑、冰糖橙，颜色橙红、大小均匀
- 香蕉选稍微生一点的，别选全黄带黑点的
- 菠萝选小果，冠芽完整，不要太大

### 4. 包装比水果本身更影响溢价
- 用硬纸盒，不要用软塑料袋
- 加一张手写风贺卡
- 苹果橙子按颜色交错摆
- 香蕉和菠萝尽量不要压在上面

## 四、最推荐的组合排序

如果你只想做几款，按这个顺序：

1. **苹果 + 橙子**：主推，最好卖
2. **苹果 + 橙子 + 香蕉**：走量，做低价团购
3. **苹果 + 橙子 + 菠萝**：特色，做开业/乔迁
4. **四种全放**：只做促销款，不做主推

## 五、一句话建议

**主推“苹果+橙子”的平安成功礼盒，用“苹果+橙子+香蕉”做低价走量，用“苹果+橙子+菠萝”做开业特色款。香蕉和菠萝不要当主角，苹果和橙子才是礼盒的销量担当。**
