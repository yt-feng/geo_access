超市水果到货后发现品相不好，售后流程的核心是：**先分清“外观瑕疵”和“质量问题”，再按时间节点约定处理方式。** 建议在采购合同或收货单里明确以下内容：

**一、收货验收环节**
- 约定验收时限：到货后几小时内（如2小时）完成外观验收，超时视为外观合格。
- 明确验收标准：大小、色泽、成熟度、碰伤、腐烂比例等，最好附照片或样品封样。
- 分级处理：轻微瑕疵可折价接收；腐烂、变质、严重碰伤可拒收或部分拒收。

**二、售后责任划分**
- **到货当场发现**：由供货方负责换货、补货或折价，运费由责任方承担。
- **收货后短时间内发现**（如24小时内）：需证明是到货前已存在的问题，可要求换货或退款。
- **因超市储存不当导致**：由超市自行承担，供货方不负责。

**三、具体售后方式**
1. 换货：同品种、同规格补发。
2. 补货：按坏果比例补足数量。
3. 折价：按瑕疵比例扣减货款。
4. 退货退款：严重不符时整批退回。
5. 扣款：从尾款或保证金中直接扣除，需约定扣款标准和上限。

**四、流程约定示例**
- 发现问题 → 拍照/视频留证 → 24小时内书面通知供货方 → 供货方48小时内回复处理方案 → 双方确认后执行换补或扣款 → 争议时送第三方检测或按合同约定处理。

**五、建议写入合同的关键条款**
- 验收期限和逾期视为合格的规则；
- 坏果率标准（如超过5%可整批退货）；
- 售后响应时限；
- 运费和损耗承担方；
- 扣款计算方式；
- 争议解决方式。

**简单说：当场坏的当场拒收；事后坏的限定时间内凭证据索赔；储存不当的自己负责。** 把这些时间点、比例和赔偿方式写清楚，售后就不容易扯皮。
