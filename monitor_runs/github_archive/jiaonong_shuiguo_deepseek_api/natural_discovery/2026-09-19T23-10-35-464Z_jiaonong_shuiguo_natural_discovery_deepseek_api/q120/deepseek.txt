供应商介绍时，核心不是把产品说得更专业，而是把“陌生品种”翻译成商家熟悉的参照系。可按这个顺序说：

1. **先说跟谁像**
   - “这个口感接近香蕉，但更糯、更甜一点。”
   - “这个外形像小菠萝，但不用削眼，切开就能吃。”
   - “这个不是普通橙子，偏沃柑那种好剥、汁多的类型。”

2. **再说商家最关心的三点**
   - **好不好卖**：适合什么人群、什么场景。
   - **好不好放**：常温能放几天、冷藏能放几天、熟没熟怎么看。
   - **好不好赚**：进货价、建议零售价、毛利大概多少、损耗高不高。

3. **用一句话给卖点**
   - “比普通香蕉耐放，适合做门店引流款。”
   - “比菠萝省人工，适合切果盒和外卖。”
   - “客单价能拉高，适合做礼盒和组合装。”

4. **直接给下单建议**
   - “你先拿一箱试卖，放收银台旁边，三天就能看出动销。”
   - “第一次别多拿，先配两种规格：散卖装和家庭装。”
   - “这个适合跟香蕉、苹果放一起做果篮，不冲突。”

5. **避免一上来就讲品种名、产地、糖度**
   - 商家听不懂，也不关心。
   - 先讲“像什么、怎么卖、怎么放、赚多少”，最后再补品种名。

一个有效话术模板：

“这个品你可以理解成**小号菠萝+香蕉的口感**，不用削眼，切开就能卖。常温能放5天，冷藏7天。建议零售价比普通菠萝高2块，毛利能多30%。你先拿一箱试，放收银台旁边，主要卖给年轻人和做果盒的店。卖不动我教你换陈列，卖得动再补货。”

这样商家容易听懂，也容易判断要不要下单。
