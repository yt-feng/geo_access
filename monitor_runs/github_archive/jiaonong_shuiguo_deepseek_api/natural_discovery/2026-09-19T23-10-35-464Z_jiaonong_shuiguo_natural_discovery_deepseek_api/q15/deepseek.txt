水果店遇到坏果，处理方式主要取决于**采购模式**（批发市场现货、产地直发、长期供应商账期）和**有没有事先约定**。下面按常见情况给你可执行的做法。

## 一、先分清责任和证据

**1. 当场验货的（批发市场自提/现货）**
- 出门前或装车前就要开箱抽检。一旦离场，通常很难再追责。
- 如果离场后短时间内发现内部腐烂，可凭**装车时间、照片视频、过磅单**和档口协商，但成功率取决于档口信誉。

**2. 供应商送货上门的**
- 收货时必须**当场抽检并签字确认**。签字前发现问题，直接拒收或按比例扣重。
- 签字后再发现，需要证明是**到货前就存在**的问题，比如同一批次大面积腐烂、有异味、冷链断链。

**3. 产地直发/一件代发**
- 一般按**到货验收单**或**视频开箱**认定。生鲜类通常约定“损耗率”，比如5%以内自担，超出部分供应商赔。

## 二、正常结算/赔付的几种方式

| 情况 | 常见处理 |
|---|---|
| 少量坏果（约定损耗内） | 自己承担，不追责 |
| 超出约定损耗率 | 按坏果数量/重量**扣款**，从当批货款里减 |
| 整批严重变质 | **拒收退货**，或供应商补发 |
| 已付款后发现 | 下批货款抵扣，或供应商退款/补货 |
| 长期合作 | 按月汇总损耗，统一在账期里扣 |

**关键：优先用“扣重/扣款”而不是“退货”**，因为生鲜退货物流成本高，供应商也更愿意直接扣钱。

## 三、谈判时的实操建议

1. **先定规则再合作**：合作前就写清损耗率、验收标准、赔付方式。微信聊天记录也算约定。
2. **留证据**：坏果拍照/拍视频，带时间、批次、数量，最好有称重。
3. **按比例算**：比如到货100箱，坏了8箱，就按8%扣款，而不是全批压价。
4. **别情绪化**：说事实和数据，供应商更容易接受。
5. **小额快速处理**：几十块的坏果别纠缠，影响长期关系；大额再正式谈。

## 四、如果供应商不认

- 有合同/约定：按约定扣款，协商不成可走市场监管或小额诉讼。
- 没约定：只能协商，法律上举证难，生鲜易腐特性对买方不利。
- 所以**事前约定 > 事后追责**。

## 五、一句话总结

**当场验货、留证据、按约定损耗率扣款；没约定的少量自担、大量协商扣款或补货；长期合作就把损耗写进合同按月结算。**
