小商家采购水果，现金结算和月结的核心区别是：**现金把风险压在“当场验货”上，月结把风险压在“账期兑现和关系维护”上**。具体风险可以这样判断：

**一、现金结算的风险**

1. **验货压力全在自己**  
   钱一付，事后发现烂果、规格不符、重量不足，基本很难追回。水果是非标品，同一批货上下层质量都可能不同。

2. **没有对账缓冲**  
   当场算错价、算错重量、重复计数，回头找对方补差价很被动，尤其是流动摊贩或临时供应商。

3. **现金安全和税务凭证问题**  
   大额现金携带、保管有风险；如果没有正规发票或收据，后续记账、维权、税务处理都麻烦。

4. **容易被动接受涨价或搭售**  
   如果当天必须拿货，供应商可能临时提价、搭售次果，你议价空间小。

5. **适合场景**  
   小额、临时、现货挑货、供应商可信、你能当场验清。  
   **控制办法**：当场复秤、抽检底层、写明品种规格、要收据或转账留痕，尽量用微信/支付宝/银行转账而不是纯现金。

**二、月结账期的风险**

1. **坏账和拖欠风险**  
   水果损耗快、周转快，如果下游回款慢，你又欠着供应商，容易资金链紧张。供应商也可能突然要求提前结清。

2. **价格和账期绑定**  
   月结往往不是白给的，供应商可能把价格抬高、扣点，或者要求最低采购量。表面有账期，实际成本可能更高。

3. **对账纠纷多**  
   一个月累积多笔送货，容易出现数量、单价、退换货、损耗扣款对不上。没有送货单、签字确认，月底很容易扯皮。

4. **关系依赖风险**  
   月结通常基于熟人信任。一旦换供应商或对方资金紧张，可能突然断供；你也可能因为欠款不好意思换更便宜的货源。

5. **质量追责变难**  
   当月累积结算，某些批次烂果、缺斤少两如果没有当场记录，月底很难逐笔追溯。

6. **适合场景**  
   长期稳定、单笔金额较大、供应商正规、你能做到每笔签收和对账。  
   **控制办法**：每笔送货单写清品名、规格、数量、单价、时间，双方签字；约定退货/损耗扣款规则；每周或每半月对一次账；账期写进简单合同或微信确认；不要只靠口头。

**三、给小商家的实用选择**

- **小额临时采购**：现金或即时转账，但必须当场验货、留凭证。
- **长期主力供应商**：可以谈月结，但要用“送货单+定期对账+明确账期”控制风险。
- **最稳的方式**：部分现结、部分短账期，比如“首批现结，稳定后7天/15天账期”，不要一上来就给30天以上。
- **核心原则**：现金风险在货，月结风险在账；谁能留下可核对的单据，谁的风险就更低。

简单说：**现金怕货不对，月结怕账不认、钱不回。** 小商家最好做到“每笔有单、定期对账、账期别太长”。
