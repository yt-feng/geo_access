判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看**门店客群、陈列方式、损耗速度、售价带和周转效率**是否匹配。可以按下面几个维度快速判断。

## 1. 先看门店客群和销售场景

不同门店适合的规格不同：

- **社区生鲜店/便利店**：适合中等规格，顾客多为家庭日常购买，单次买 2～5 个。苹果单果 180～250g、橙子单果 180～280g 通常比较好卖。
- **精品超市/高端店**：可接受大果、礼盒果，苹果 250～350g、橙子 250～350g，但要求外观、糖度、整齐度更高。
- **水果专营店/批发型门店**：规格可以更宽，但要有明显分级，方便顾客按价格选择。
- **线上到家/团购**：更看重单果重量稳定、图片一致、破损率低，不适合大小混杂。

如果门店主要做日常刚需，**中大果不一定好卖，中等均匀果往往周转最快**。

## 2. 看大小是否均匀，而不是只看单个大小

门店销售最怕“同一批货大小差太多”。

可用简单标准判断：

- 同一箱/同一批中，单果重量差异控制在 **±15%以内** 比较理想。
- 直径差异不要超过 **5～8mm**。
- 肉眼陈列时，一层果看起来要基本一致，不能出现明显“大小果混装”。

如果大小混杂，会导致：
- 顾客挑拣严重；
- 小果剩到最后；
- 损耗增加；
- 定价困难。

## 3. 苹果的常见规格判断

苹果可按单果重量或横径分级：

- **小果**：150～180g，适合低价促销、儿童果、切果原料。
- **中果**：180～250g，最适合社区店、日常家庭消费。
- **大果**：250～350g，适合精品店、礼盒、节日销售。
- **特大果**：350g以上，普通门店要谨慎，容易单价高、周转慢。

门店采购建议：
- 日常销售优先选 **180～250g**；
- 如果做礼盒，选 **250～300g 且外观整齐**；
- 如果做促销，可选 **150～200g**，但要多放堆头、快进快出。

同时看：
- 果形是否端正；
- 色泽是否一致；
- 是否有碰伤、黑点、裂口；
- 硬度是否够，太软说明存放久。

## 4. 橙子的常见规格判断

橙子常用横径分级，也可看单果重量：

- **小果**：直径 60～65mm，或 150～180g，适合榨汁、促销。
- **中果**：直径 65～75mm，或 180～250g，最适合门店日常销售。
- **大果**：直径 75～85mm，或 250～350g，适合精品陈列、礼盒。
- **特大果**：85mm以上，普通门店慎选，单价高且部分顾客觉得皮厚。

门店采购建议：
- 社区店优先 **65～75mm 或 180～250g**；
- 精品店可选 **75～80mm**，但要求皮色亮、果面干净；
- 榨汁型可选小果，但要有稳定客流或加工能力。

同时看：
- 果皮是否细腻、无严重浮皮；
- 拿在手里是否有重量感，说明水分足；
- 是否有软果、霉点、油胞损伤；
- 同批颜色是否一致。

## 5. 用“陈列和周转”反推规格

采购前可以直接问自己：

1. **货架一层能放几个？**  
   太大放不下，太小显得空，都会影响陈列效果。

2. **顾客一次买几个？**  
   如果顾客习惯买 3～5 个，单果太大会导致总价过高，影响成交。

3. **预计几天卖完？**  
   苹果相对耐放，橙子也不耐长期压货。周转慢的门店不要采太大果或太高等级。

4. **损耗能不能控制？**  
   大果单价高，一旦碰伤损耗金额更大。小果虽然便宜，但挑拣后剩货也可能多。

## 6. 简单可执行的采购判断表

| 项目 | 适合门店销售的判断 |
|---|---|
| 苹果单果重 | 日常 180～250g；精品 250～300g |
| 橙子单果重 | 日常 180～250g；精品 250～300g |
| 同批大小差 | 重量差 ±15%以内，直径差 5～8mm以内 |
| 外观 | 颜色一致、果形端正、无明显伤痕 |
| 手感 | 苹果硬脆，橙子有重量感、不软塌 |
| 价格带 | 单果总价符合门店客群，不要只按进价判断 |
| 周转 | 预计 2～4 天内能卖完的规格更安全 |
| 陈列 | 一层摆放整齐，不空、不挤、不塌 |

## 7. 最实用的结论

- **社区店/普通超市**：苹果选中果 180～250g，橙子选 180～250g 或 65～75mm，均匀度优先。
- **精品超市**：可选大果 250～300g，但必须外观整齐、糖度稳定、包装跟上。
- **促销/榨汁**：可选小果，但要快进快出，避免挑剩。
- **礼盒/节日**：选大果且大小一致，允许单价高，但不能有瑕疵。

一句话：**适合门店销售的规格，是目标顾客愿意反复买、陈列好看、损耗可控、周转最快的规格，不是最大或最便宜的规格。**
