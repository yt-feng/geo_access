对绝大多数餐饮连锁来说，**水果由中央厨房统一收货更好，但前提是中央厨房具备冷藏/保鲜能力和配送能力**。如果这两项不具备，门店分开收货反而更合适。

具体判断如下：

## 一、优先选择中央厨房统一收货的情况

适合：

- 门店数量较多，比如 10 家以上
- 水果用量大、品类相对稳定
- 有中央厨房，且有冷藏库、分拣区、冷链配送
- 想统一品质、统一价格、统一食品安全

优点：

1. **采购议价能力强**  
   总部集中下单，量大，价格和账期更好谈。

2. **品质标准统一**  
   可以统一规格、糖度、成熟度、外观标准，避免各店收到不同等级水果。

3. **食品安全可控**  
   农残检测、供应商资质、收货台账集中在中央厨房管理，追溯更清晰。

4. **减少门店操作**  
   门店只负责接收和使用，不用每天验货、砍价、处理退换货。

5. **供应商管理更简单**  
   只对少数供应商，而不是几十家门店各自对接。

6. **损耗更容易统计**  
   中央厨房可以统一分拣、分级，把可用的、临期的、破损的分开处理。

缺点：

1. **配送环节增加损耗**  
   水果怕压、怕碰、怕温度波动，多一次装卸就多一次损耗。

2. **配送频次要求高**  
   叶菜、浆果、熟度高的水果不适合长距离、低频次配送。

3. **中央厨房压力大**  
   需要冷库、分拣、配送、退货处理能力，否则会变成“集中压货”。

4. **门店灵活性下降**  
   门店临时缺货、临时促销、临时换菜单时，响应不如自己采购快。

## 二、门店分开收货更好的情况

适合：

- 门店数量少，比如 1—5 家
- 水果品类多但单店用量小
- 门店分布分散，配送成本高
- 中央厨房没有冷链和水果分拣能力
- 水果用于门店现切、现榨、摆盘，成熟度要求每天调整
- 当地有成熟的水果批发市场，门店能就近采购

优点：

1. **响应快**  
   门店可根据当天客流、菜单、促销临时补货。

2. **短链配送损耗低**  
   特别是本地采购、当天到店的水果，新鲜度可能更好。

3. **配送成本低**  
   不需要中央厨房统一冷链配送到各店。

4. **适合高灵活度门店**  
   比如鲜榨果汁店、水果茶店、甜品店，对成熟度和现场品质要求高。

缺点：

1. **品质不稳定**  
   不同门店可能收到不同等级、不同成熟度的水果。

2. **采购成本高**  
   单店采购量小，议价能力弱。

3. **食品安全风险分散**  
   每个店都要验货、留证、检测，管理难度大。

4. **容易产生灰色空间**  
   门店自行采购容易出现吃回扣、虚报价格、私换供应商。

5. **总部难统一毛利**  
   各店采购价不同，成本核算和定价会混乱。

## 三、更推荐的实际方案：混合模式

大多数连锁餐企更适合“中央厨房统一采购 + 分区/门店灵活补货”：

1. **耐储水果统一收**  
   苹果、橙子、柠檬、西瓜、哈密瓜等，由中央厨房统一收货、统一配送。

2. **易损、高成熟度水果分区收**  
   草莓、蓝莓、芒果、牛油果、香蕉等，可按区域仓或门店就近收货。

3. **核心供应商总部签**  
   总部谈框架价、品质标准、账期和食品安全责任。

4. **门店只做应急补货**  
   设置限额和审批，比如单店单次不超过多少金额，且必须从指定供应商买。

5. **统一验收标准**  
   不管谁收货，都用同一套标准：规格、重量、糖度、成熟度、破损率、温度、农残证明。

## 四、直接判断标准

你可以用这 4 个问题判断：

1. **中央厨房有没有冷藏库和冷链车？**  
   没有，就别强行统一收。

2. **水果从中央厨房到门店要多久？**  
   超过 24 小时且不是全程冷链，门店分开收更好。

3. **单店水果用量大不大？**  
   单店用量大且稳定，可以门店收；单店小、门店多，统一收更好。

4. **水果是耐储还是易损？**  
   耐储统一收；易损、高成熟度，分区或门店收。

## 结论

- **门店多、用量大、有冷链中央厨房：中央厨房统一收货更好。**
- **门店少、分散、水果易损、中央厨房无冷链：门店分开收货更好。**
- **最稳妥的是混合模式：耐储水果统一收，易损水果分区或门店灵活补货，总部统一供应商和验收标准。**

如果只选一个答案：**连锁规模上去后，中央厨房统一收货通常更优；但水果这个品类不能一刀切，必须按耐储性和配送能力分层管理。**
