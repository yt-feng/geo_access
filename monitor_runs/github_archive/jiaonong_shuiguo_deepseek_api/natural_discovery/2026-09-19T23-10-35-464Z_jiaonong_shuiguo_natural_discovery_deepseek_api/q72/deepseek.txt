做稳定大客户，核心不是“把账期谈得越长越好”，而是把**账期、额度、价格、订单量、风险控制**绑成一个双方可执行的交易结构。水果生鲜损耗高、价格波动大，账期给错很容易变成你替客户承担库存和坏账风险。

下面按实操顺序讲。

## 1. 先判断：这个客户值不值得给账期

不是所有批发商都适合给账期。先看四个信号：

- **采购是否稳定**：每周/每天有固定量，还是临时要货、时有时无。
- **品类是否耐放**：苹果、橙子、土豆、洋葱等耐储品类，账期风险相对低；草莓、荔枝、叶菜等高损耗品类，账期要更短。
- **下游回款是否可靠**：他卖给超市、食堂、连锁水果店，通常回款比卖给零散摊贩更可预测。
- **历史交易记录**：先现款现货合作1-3个月，再谈账期。没有交易记录就直接要30天账期，风险很大。

如果客户只是用“我量大”来压账期，但订单不稳定、品类又高损耗，不建议给长账期。

## 2. 账期怎么谈：从短到长，用条件换

建议不要一上来给30天、60天。可以按这个阶梯谈：

| 阶段 | 账期 | 适用条件 |
|---|---|---|
| 试合作 | 现款现货 / 货到付款 | 新客户、无历史记录 |
| 稳定合作1-3个月 | 7天 | 每周固定采购、按时付款 |
| 稳定合作3-6个月 | 15天 | 月采购额达到门槛、无逾期 |
| 核心大客户 | 30天 | 签年度框架、有保证金或担保 |
| 战略客户 | 30-45天 | 仅限低损耗品类、额度封顶、有抵押/担保 |

关键话术不是“我不能给你30天”，而是：

> “账期可以给，但它是跟着采购量和结算记录逐步放的。我们先按7天跑一个月，如果每周量稳定、回款准时，第二个月调到15天，季度后再谈30天。”

这样你既表达了合作诚意，又把风险控制在可承受范围。

## 3. 额度怎么定：按“最大在途风险”算

额度不是拍脑袋，建议用这个公式：

**信用额度 ≤ 客户月均采购额 × 账期系数 × 风险折扣**

更简单的算法：

- 如果给7天账期：额度 ≈ 客户每周采购额的1.5-2倍
- 如果给15天账期：额度 ≈ 客户每半月采购额的1.5倍
- 如果给30天账期：额度 ≈ 客户月采购额的0.8-1倍，且设封顶

举例：客户月采购10万，给30天账期，额度不要直接给10万，可以先给5-8万，超出部分现款或先款后货。

同时设三条硬规则：

1. **额度封顶**：超过额度必须现款，不临时提额。
2. **逾期停供**：超过账期3天未付，暂停发货。
3. **滚动结算**：旧账未清，新账不赊。

## 4. 用条件换账期，不要白给

账期是资金成本，必须换东西。可以换：

- **更高采购量**：承诺每周/每月最低采购量。
- **更优价格**：账期客户价格可以比现款客户高2%-5%，把资金成本算进去。
- **独家/主供**：他优先从你这里采购核心品类。
- **保证金**：大额账期可要求5%-10%保证金，或押一批货作为担保。
- **担保人/合同**：个人客户要身份证、住址、紧急联系人；公司客户要营业执照、法人信息、对公账户。
- **损耗分担**：水果到货后验收标准写清楚，超过约定损耗由客户承担。

## 5. 合同里必须写清楚的条款

- 账期起算日：是发货日、到货日还是对账日？建议写“到货验收后第X天”。
- 对账周期：每周或每半月对账一次，避免月底扯皮。
- 逾期责任：逾期利息、停供条件、违约金。
- 质量异议期：到货后24-48小时内提出，过期视为验收合格。
- 价格调整机制：水果价格波动大，框架合同里写“随行就市，提前X天通知”。
- 争议解决：管辖法院或仲裁地写在你所在地，降低追款成本。

## 6. 实操建议：先小后大，先短后长

最稳的路径是：

1. **第1个月**：现款现货，观察采购频率和付款习惯。
2. **第2-3个月**：给7天账期，额度设为周采购额的1.5倍。
3. **第4-6个月**：如果回款准时，调到15天，额度适度提高。
4. **半年后**：签年度框架，给30天账期，但要求最低采购量、保证金或担保。
5. **始终保留**：逾期停供、超额度现款、旧账不清不赊。

## 7. 一句话总结

**账期用“时间”换忠诚，额度用“封顶”控风险；先短后长、先小后大，用采购量、保证金、价格和合同条款把账期绑住。** 对水果批发商来说，最好的大客户不是账期最长的，而是回款最稳、采购最持续、风险最可控的那个。
