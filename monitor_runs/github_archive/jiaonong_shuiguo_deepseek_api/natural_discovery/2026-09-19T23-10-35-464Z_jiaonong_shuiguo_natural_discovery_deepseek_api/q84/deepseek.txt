家庭团购水果礼盒，核心不是“贵”，而是**耐放、好吃、大小适中、老人小孩都能吃**。苹果、橙子、香蕉、菠萝这四个组合，建议优先做 **“苹果 + 橙子 + 香蕉”** 的基础款，菠萝作为可选升级项，不要默认全放。

**推荐组合方案**

1. **家庭稳妥款：苹果 + 橙子 + 香蕉**
   - 比例参考：苹果 40%、橙子 35%、香蕉 25%。
   - 优点：苹果耐放，橙子解腻补维C，香蕉软甜适合老人小孩。
   - 注意：香蕉不耐压、不耐放，适合团购到货后 2-3 天内吃完。

2. **家庭丰富款：苹果 + 橙子 + 香蕉 + 菠萝**
   - 比例参考：苹果 35%、橙子 30%、香蕉 20%、菠萝 15%。
   - 优点：品类丰富，有节日感，适合 4-6 人家庭。
   - 注意：菠萝处理麻烦、占体积、易扎手，礼盒里最好配削皮说明或切好装盒。

3. **不适合家庭团购的组合**
   - 苹果 + 菠萝为主：太硬、太酸，小孩和老人不一定爱吃。
   - 香蕉 + 菠萝为主：都不耐放，运输容易坏。
   - 四种等量混装：香蕉容易被压，菠萝容易扎坏其他水果。

**装箱建议**
- 苹果、橙子放底层和四周，起支撑作用。
- 香蕉放上层，用纸或泡沫网隔开，避免挤压。
- 菠萝单独用网套或纸包裹，放在一侧，不要和香蕉贴太近。
- 如果做 5 斤礼盒：苹果 2 斤、橙子 1.5 斤、香蕉 1 斤、菠萝 0.5 斤左右比较合理。
- 如果做 8-10 斤礼盒：苹果 3 斤、橙子 3 斤、香蕉 2 斤、菠萝 1-2 斤。

**团购定价和选品建议**
- 家庭团购更看重性价比，苹果和橙子选大众品种即可，香蕉选成熟度稍低的，到货后刚好能吃。
- 菠萝可以做成“加价升级项”，比如基础款三样，加 5-10 元换四样，减少损耗和售后。
- 如果目标家庭有小孩，香蕉比例可以略高；如果偏健康送礼，橙子和苹果比例更高。

**一句话结论**
家庭团购水果礼盒，首选 **苹果 + 橙子 + 香蕉**，比例约 **4:3.5:2.5**；想做丰富款再加少量菠萝，但菠萝要单独包装，且整体香蕉比例别太高。
