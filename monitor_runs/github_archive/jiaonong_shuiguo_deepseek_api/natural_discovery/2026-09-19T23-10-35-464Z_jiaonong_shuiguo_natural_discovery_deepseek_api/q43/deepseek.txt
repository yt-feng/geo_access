评估水果供应商仓配覆盖，核心不是看它“覆盖多少城市”，而是看它能不能稳定满足你门店的时效、品质和成本要求。建议按下面框架做。

## 1. 先明确自身需求画像

把门店按城市/区域分组，统计：

- 门店数量、日均/峰值订货量
- 需要的配送频次（每日/隔日/每周几次）
- 到店时效要求（如凌晨到店、开门前到货）
- 温层要求（常温、冷藏、冷冻）
- 门店收货条件（是否有冷库、收货时间窗口、卸货条件）
- 品类结构（叶菜、浆果、榴莲等对时效和损耗极敏感）

这一步决定你评估供应商时看什么指标，否则容易被“全国覆盖”这种话术带偏。

## 2. 评估供应商仓配网络的硬指标

### 仓库布局
- 供应商在哪些城市有仓？是中心仓、区域仓还是前置仓？
- 仓到你每个门店的实际距离和运输时间
- 仓的温区能力：是否有冷藏/冷冻分区，能否混配
- 仓容和峰值处理能力，是否支撑你旺季放量

### 配送能力
- 自有车队还是外包？外包的稳定性和可控性通常更弱
- 冷链车数量、温控记录能力
- 配送频次和截单时间，能否匹配你的订货节奏
- 是否支持多温层共配（一车送常温+冷藏）
- 到店准时率、破损率、缺货率的可验证数据

### 覆盖半径与时效
- 从仓到店的最长时效是多少小时
- 是否承诺到店时间窗口
- 跨城配送是否中转，中转是否影响鲜度
- 偏远城市是直送还是第三方落地配

## 3. 用可验证数据做评估

不要只看供应商提供的覆盖地图，要求提供：

- 近3–6个月你目标城市的实际配送记录
- 准时率、温度合格率、损耗率、缺货率
- 异常处理案例和响应时长
- 可试点的城市清单和试点方案

如果供应商不愿提供可验证数据，覆盖能力要打折判断。

## 4. 做分层覆盖策略

不同城市不必用同一标准：

| 门店类型 | 建议策略 |
|---|---|
| 核心城市密集门店 | 要求高频直送、多温共配、时效承诺 |
| 区域中心城市 | 区域仓覆盖，隔日或每日配送 |
| 边缘/低密度城市 | 可接受中转或第三方落地配，但需控制鲜度风险 |
| 偏远单店 | 评估是否本地采购或调整品类结构 |

## 5. 计算真实履约成本

覆盖评估要算总成本，不只看运费：

- 配送费 + 起送门槛
- 因时效不足导致的损耗
- 缺货导致的销售损失
- 门店收货人工和时间成本
- 为满足配送频次增加的库存占用

## 6. 建议的落地评估流程

1. 列出你所有门店城市和需求分级
2. 让供应商按城市填写：仓库位置、配送时效、频次、温层、截单时间
3. 抽取3–5个代表城市做试点
4. 用2–4周实测准时率、损耗率、缺货率、到店温度
5. 按城市打分，决定直送、中转、本地采购或换供应商

## 7. 关键判断标准

一个供应商仓配覆盖合格，至少要满足：

- 目标城市能在你要求的时效内到店
- 冷链温控可记录、可追溯
- 旺季和异常天气下有备用方案
- 准时率和损耗率有历史数据支撑
- 成本在可接受范围内，且不靠牺牲鲜度换低价
