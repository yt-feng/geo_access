连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是**价格联动、损耗归属、验收标准、账期与返利、独家条款**这几类。下面按风险从高到低列出来，并给出可执行的判断建议。

**1. 价格条款**
- 坑：只写“随行就市”或“参考市场价”，没有基准、调价周期、调价触发条件和争议解决方式。水果价格波动大，旺季淡季价差可能很大，最后变成供应商单方面说了算，或者超市想调价调不动。
- 建议：写明基准价来源（如某批发市场当日均价、某指数）、调价周期（如每两周一次）、调价幅度上限（如单次不超过10%）、以及双方无法达成一致时的处理方式（如按上一周期价格继续执行或临时仲裁）。

**2. 损耗与验收**
- 坑：只写“按国家标准验收”，但水果没有统一可执行的分级标准；或者损耗全部由超市承担，供应商送货后概不负责。
- 建议：约定具体验收指标，比如糖度、单果重、色泽、机械伤比例、腐烂率上限；明确验收地点（到店验收还是到仓验收）、验收时限（如到货后4小时内提出异议）、以及不合格品的退换货和费用承担。损耗要区分运输途中损耗和门店陈列损耗，分别定责。

**3. 账期与结算**
- 坑：账期写“月结30天”但起算点模糊，是收货日、对账日还是开票日；扣款项目不封顶，比如损耗扣款、促销扣款、返利扣款叠加后供应商实际回款远低于预期。
- 建议：明确账期起算日和对账确认流程；把所有扣款项目列成清单并设上限或计算方式；约定逾期付款的违约责任，避免超市无限期拖延。

**4. 返利与费用**
- 坑：年度返利按“进货额”还是“销售额”算，退货是否冲减；进场费、条码费、促销费、堆头费是否包含在返利里，容易重复计算。
- 建议：返利基数、比例、结算时间写清楚；退货要明确是否冲减返利基数；所有费用列明项目、金额或计算方式，避免“其他费用另行协商”这种开口条款。

**5. 独家与排他**
- 坑：约定供应商不得向同区域其他超市供货，但没写区域范围、期限和补偿；或者超市承诺独家采购，但实际大量从其他渠道进货，供应商可主张违约。
- 建议：排他条款要限定品类、区域、时间，并约定违反后的赔偿或解除条件。如果超市做不到独家采购，就不要签独家采购承诺。

**6. 质量安全与责任**
- 坑：只写“符合食品安全标准”，但没写农残、重金属等具体检测要求和抽检不合格的处理；出现食品安全事件时责任划分不清。
- 建议：约定供应商提供每批次检测报告或合格证明；明确抽检不合格的退货、赔偿、罚款及解除合同条件；因供应商原因导致消费者索赔或行政处罚的，由供应商承担。

**7. 供货保障与违约**
- 坑：没写最低供货量或断供责任，旺季供应商优先供高价渠道，超市缺货；或者超市承诺最低采购量但没写未达量的后果。
- 建议：约定旺季保供义务、缺货违约金或替代采购差价承担；如果超市承诺采购量，也要写明未达量的补偿方式，避免单方面约束。

**8. 合同期限与退出**
- 坑：自动续约条款隐藏，到期前未通知就自动延长一年；或者解除条件只对超市有利，供应商难以退出。
- 建议：明确续约需双方书面确认；约定解除条件对等，比如连续多少批次不合格、累计欠款超过多少天，双方均可解除。

**优先动作建议：**
1. 先确认价格联动机制和验收标准，这两项最容易在履约中产生争议。
2. 把所有扣款和返利项目做成一张表，算清供应商实际到手价，再谈合同价。
3. 排他条款和最低采购量承诺，签之前先评估自己能不能做到。
4. 保留每批次验收记录和检测报告，出现纠纷时这是最关键的证据。

如果只能抓三个重点，就是：**价格怎么调、损耗谁来担、扣款怎么算**。这三项写清楚，大部分坑就能避开。
