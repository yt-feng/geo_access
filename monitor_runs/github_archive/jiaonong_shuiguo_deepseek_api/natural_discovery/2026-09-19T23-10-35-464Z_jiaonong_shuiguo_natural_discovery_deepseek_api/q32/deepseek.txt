判断香蕉供应商能否全年稳定供货，核心不是听他承诺，而是查他的**货源结构、产地轮换能力和历史履约记录**。可以按下面几步做。

**1. 先问清他的货源是“单一产地”还是“多产地轮换”**
- 香蕉是热带作物，国内主产区有海南、广西、云南、广东，进口主要来自菲律宾、越南、厄瓜多尔、哥伦比亚等。
- 如果供应商只靠一个产地、一个季节，基本无法全年稳定。
- 要求他列明：全年12个月分别从哪些产地、哪些基地/果园采购，各月大致占比。
- 能拿出“产地轮换表”的，比只说“我们全年都有货”的可靠得多。

**2. 查他的上游掌控能力，而不是只看贸易商身份**
- 优先选有自有或合作种植基地、长期包园、产地直采能力的供应商。
- 如果他只是中间倒手，要问清一级供应商是谁、是否签了年度框架协议。
- 关键问题：台风季、寒潮季、进口国政策变化时，他靠什么补货？
- 有冷库、催熟库、加工分拣线的供应商，抗波动能力通常更强。

**3. 用历史数据验证，不看口头承诺**
- 要求提供过去12—24个月的供货记录：月供货量、缺货次数、缺货原因、补货时间。
- 重点看：春节前后、台风季、夏季高温期、进口旺季这几个节点的履约情况。
- 可以要他提供2—3家同类型超市客户的联系人，做背景核实。
- 如果对方以“商业机密”拒绝提供任何历史数据，风险要上调。

**4. 做小规模试单，跨季节验证**
- 不要一上来就签全年大单。先签3—6个月试供，覆盖一个淡旺季转换。
- 试单期间考核：到货准时率、缺货率、单批次品质波动、损耗率、异常响应速度。
- 建议设定硬指标，例如：月缺货率低于5%、到货准时率95%以上、单批损耗低于8%。
- 连续2—3个月不达标，就说明“稳定供货”能力不足。

**5. 合同里把“稳定”写成可执行条款**
- 约定月度最低供货量、最高供货量、缺货违约责任。
- 约定替代产地或替代品种的触发条件，避免一断货就彻底停供。
- 约定价格调整机制，因为香蕉价格波动大，锁死价格反而容易导致对方优先供高价客户。
- 约定质量标准和验收方式，避免用“稳定供货”掩盖“稳定供差货”。

**6. 看他的物流和催熟能力**
- 香蕉需要冷链或控温运输，到店后还要催熟。物流不稳，产地再稳也会断。
- 问清：运输方式、在途时间、冷库容量、催熟库日处理量、配送频率。
- 如果供应商同时服务多家连锁超市，要问他如何分配旺季货源，是否给你的门店设优先级。

**简单判断标准：**
- 能说清全年产地轮换 + 有历史履约数据 + 有冷链催熟能力 + 愿意试单和签违约条款 = 相对可靠。
- 只说“关系好、有货、放心” + 拒绝历史数据 + 只靠单一产地 = 全年稳定供货风险高。

最稳妥的做法是：**主供应商 + 备用供应商并行**，主供占70%—80%，备用占20%—30%，避免把全年香蕉供应押在一家身上。
