单位采购水果，到货品质不一致时，核心原则是：**先按合同/订单标准验，再按证据谈售后**。建议按下面流程处理。

## 一、验收前先明确标准

采购时最好在订单或合同里写清：

- 品种、产地、规格（单果重、果径、等级）
- 成熟度、色泽、甜度或糖度要求
- 包装方式、净重/毛重、箱规
- 允许的次果率、损耗率，比如不超过 5%
- 到货时间、验收时限
- 不合格的处理方式：补货、换货、退款、扣款

如果没有书面标准，至少要有下单时的聊天记录、报价单、样品照片，否则售后容易扯皮。

## 二、到货验收怎么做

### 1. 当场验，别拖
水果易腐，最好到货后 **2 小时内** 完成验收，最长不超过当天。拖延后再提异议，供应商容易不认。

### 2. 分层抽样
不要只看表面一层。按比例抽检，比如：
- 每批随机抽 10% 的箱
- 每箱从上、中、下分层各取几个
- 大批量采购可多抽几箱

### 3. 对照标准逐项检查
重点看：
- **数量**：实际到货箱数、净重是否够
- **规格**：大小、单果重是否一致
- **成熟度**：是否过生、过熟、软烂
- **外观**：腐烂、碰伤、虫眼、霉变、裂口
- **新鲜度**：果梗、表皮、气味
- **一致性**：是否混级、混品种、以次充好

### 4. 全程留证
这是售后关键：
- 拍开箱视频，最好从外包装完整状态开始拍
- 拍问题果特写 + 整箱全景
- 拍称重、计数过程
- 记录到货时间、车牌/物流单号、送货人
- 让送货人现场签字确认问题

### 5. 出具验收单
写明：
- 合格数量、不合格数量
- 不合格原因和比例
- 处理意见：拒收 / 部分拒收 / 让步接收 / 补换货
- 双方签字

## 三、品质不一致怎么分类处理

| 情况 | 建议处理 |
|---|---|
| 少量次果，在约定损耗内 | 正常接收，记录备案 |
| 部分腐烂、碰伤，比例超标 | 不合格部分拒收，要求补货或退款 |
| 混级、规格不符 | 要求换货，或按低等级重新计价 |
| 整体成熟度不对 | 能用的协商折价，不能用的退货 |
| 大面积腐烂、霉变 | 整批拒收，保留证据追责 |
| 与样品严重不符 | 拒收并要求退款，必要时终止合作 |

## 四、售后怎么谈

### 1. 第一时间书面通知
用微信、邮件或函件通知供应商，写清：
- 订单号、到货时间
- 问题描述和比例
- 照片/视频证据
- 你的诉求：补货、换货、退款、折价、扣款

### 2. 给出明确方案
常见诉求：
- **补货**：不合格部分补齐，运费由供应商承担
- **换货**：整批或问题部分更换
- **退款**：不合格部分按比例退款
- **折价**：还能用但品质差，按折价接收
- **扣款**：按合同约定扣违约金或损耗款

### 3. 约定时限
要求供应商在 **24—48 小时内** 回复处理方案，避免水果继续变质扩大损失。

### 4. 谈不拢怎么办
- 按合同争议条款处理
- 保留所有证据，必要时向市场监管部门投诉
- 金额大的可走法律途径
- 后续将该供应商列入观察或淘汰名单

## 五、给单位的实操建议

1. **采购前定标准**：写进合同，附样品照片。
2. **验收双人制**：采购、使用部门或仓管共同验收，避免一人说了算。
3. **先验后签**：没验收完不签收单，不付全款。
4. **留质保金**：可约定留 5%—10% 尾款，验收合格后付。
5. **固定供应商 + 备选供应商**：避免临时断供被拿捏。
6. **建立验收台账**：记录每批到货品质，便于后续追责和换供应商。

一句话总结：**标准写清楚、当场验仔细、证据留完整、售后按合同谈，不合格就补换退或折价，别拖到水果烂完再扯皮。**
