判断一批香蕉，核心不是“黄不黄”，而是看**成熟阶段、均匀度、机械伤和病斑走向**。批发场景建议按下面顺序看。

**1. 先看整体成熟阶段**
- **全青、硬**：适合远途或需要自己催熟，但太生时催熟后风味可能差。
- **青黄相间、棱角还明显**：通常是最适合批发周转的状态。
- **通体黄、棱角变圆**：已经接近或进入即食期，适合快销，不适合压货。
- **黄中带黑斑、果柄发黑**：货龄偏大，风险高。
- **局部黄、局部青很明显**：成熟不均，后续会出现“有的烂了有的还生”。

**2. 看蕉条和蕉梳一致性**
- 同一梳、同一箱颜色和硬度应大体一致。
- 如果一箱里有的已经全黄，有的还全青，说明冷链或催熟不均，后面损耗会大。
- 蕉梳断口多、散条多，通常搬运次数多，机械伤风险高。

**3. 判断坏果风险，重点查这些部位**
- **果柄和蕉轴**：发黑、发霉、渗液，说明可能已感染或存放过久。
- **果指弯曲内侧和棱线**：有压伤、裂口、水渍状，后熟时会先烂。
- **果皮擦伤**：发暗、发软，通常几天内转黑腐烂。
- **病斑**：少量小黑点可能是炭疽病初期；如果斑点凹陷、连片、有霉层，风险高。
- **果肉状态**：抽检剥开，若边缘透明、发水、发酸味，说明内部已开始劣变。
- **温度伤**：表皮暗灰、手感发僵，可能受过冷害，催熟后容易发黑不软。

**4. 现场可执行的抽检方法**
- 每批随机抽 **3—5箱**，不要只看最上面一层。
- 每箱查上、中、下三层，重点看箱底有无压伤、渗液。
- 用手轻捏：过硬适合催熟，过软说明已进入快销期。
- 闻气味：有酒味、酸味、霉味，直接判高风险。
- 剥 2—3 根代表样：看果肉是否透明、发水、褐变。
- 记录：青黄比例、软果比例、病斑果比例、断梳散条比例。

**5. 快速分级建议**
- **低风险**：青黄均匀、果柄干净、手感硬、无明显斑伤，可正常周转或催熟。
- **中风险**：少量黄果、轻微擦伤、少量黑点，适合优先出货，缩短账期。
- **高风险**：大量黄软果、果柄发黑、渗液、霉斑、酒酸味，不建议压货，应压价快清或拒收。

**6. 和熟度有关的几个误区**
- 香蕉不是越黄越安全，越黄通常货架期越短。
- 只看表皮不够，冷害和内部软化可能表皮还正常。
- 黑点不全是坏，但“凹陷、连片、发霉”的黑点要按坏果处理。
- 青香蕉不一定耐放，受过冷害的青蕉催熟后也可能发黑不软。

如果你是批发商，最实用的判断标准是：**成熟均匀、果柄干净、手感硬实、无渗液霉斑、抽检果肉不透明发水**。满足这些，坏果风险通常较低；一旦出现“黄软+果柄黑+渗液+异味”组合，就要按高风险货处理。
