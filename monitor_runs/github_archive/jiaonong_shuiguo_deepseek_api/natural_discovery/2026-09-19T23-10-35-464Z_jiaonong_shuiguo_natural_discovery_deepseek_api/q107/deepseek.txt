会，而且通常**明显增加损耗风险**，尤其是香蕉和菠萝这类后熟型、易损型水果。

核心判断：
- **香蕉**：起订量过高，最大风险是集中后熟、集中变黄变黑，卖不完就快速报损。
- **菠萝**：起订量过高，最大风险是积压后过熟、黑心、腐烂、切果品质下降。
- 两者都不是“越便宜越划算”，因为损耗会吃掉采购价优势。

具体影响如下：

1. **香蕉的损耗风险**
- 香蕉到货后仍会继续后熟，温度、乙烯、堆压都会加速。
- 起订量太大，会导致同一批次几乎同时成熟，销售窗口很短。
- 如果冷库或催熟能力不足，容易出现：
  - 青蕉来不及卖，突然集中转黄
  - 黄蕉过熟、起黑斑
  - 搬运碰伤后快速腐烂
- 香蕉一旦过熟，降价也未必卖得掉，损耗率可能从正常几个点升到很高。

2. **菠萝的损耗风险**
- 菠萝相对耐储一些，但起订量过高仍会增加风险。
- 主要问题：
  - 常温堆放时间长，内部过熟、黑心
  - 表皮碰伤后霉变
  - 切开后发现品质下降，影响鲜切和零售
  - 旺季卖不完，只能降价清货
- 菠萝损耗不一定立刻显现，可能到切开或消费者端才暴露，退货和口碑损失也会增加。

3. **什么时候起订量高更危险**
- 门店销售速度慢、客流不稳定
- 冷链、冷库、催熟条件不足
- 采购周期长，补货不灵活
- 同时采购多个易损水果，库容和人力被挤占
- 天气炎热或运输时间长
- 只看到单价便宜，没算损耗、人工、降价处理成本

4. **什么时候可以适当提高起订量**
- 有稳定销量，能按天消化
- 有冷藏、催熟、分级处理能力
- 能快速调拨到其他门店或渠道
- 有鲜切、果汁、烘焙等二次加工渠道
- 供应商能分批到货，而不是一次性压货

5. **实操建议**
- 按“日均销量 × 安全天数”定采购量，不要只看供应商起订量。
- 香蕉建议小批量、多频次补货，控制催熟节奏。
- 菠萝可适当比香蕉多备，但也要按销售速度分级采购。
- 算真实成本：
  - 采购价 + 运费 + 仓储 + 人工 + 损耗 + 降价处理
  - 对比：小批量采购价 + 更低损耗
- 如果起订量高但价格低，先做测试：
  - 先按最小起订量试一轮
  - 记录3到7天损耗率、售罄率、降价比例
  - 再决定是否放大采购
- 和供应商谈：
  - 分批送货
  - 混合拼柜
  - 不同成熟度搭配
  - 破损赔付和退换条件

结论：  
**起订量太高，大概率会增加香蕉和菠萝的损耗风险。** 香蕉更敏感，菠萝相对好一点，但都不能只看采购单价。最稳妥的是小批量、多频次、按销量和储存能力订货；如果必须大批量进，就要有冷藏、催熟、分流和二次加工能力，否则省下的采购费很可能被损耗吃掉。
