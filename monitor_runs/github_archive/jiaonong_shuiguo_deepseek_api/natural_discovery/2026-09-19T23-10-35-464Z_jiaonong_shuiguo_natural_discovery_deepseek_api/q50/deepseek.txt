结论先说：**如果只选一个作为采购首要指标，选“出汁率”更重要；甜度可以通过糖浆、调整配方来补，出汁率补不了。**

但更准确的说法是：**先卡出汁率门槛，再在合格原料里挑甜度。**

### 为什么出汁率优先级更高

1. **出汁率直接决定成本**
   - 同样买10kg菠萝，出汁率高的能多出汁，单杯原料成本更低。
   - 出汁率低，你买的是“皮、芯、水分少的果肉”，钱花在废料上。

2. **甜度可以后调，出汁率不能后补**
   - 茶饮店本来就会用糖浆、果酱、风味糖浆调甜。
   - 但榨不出汁，你没法凭空补回果汁感和果肉纤维感。

3. **出汁率影响口感和出品稳定性**
   - 出汁率高的菠萝通常成熟度、水分、果肉结构更合适。
   - 出汁率低会导致每批出品波动大，今天淡、明天浓。

4. **甜度本身波动大**
   - 不同季节、产地、成熟度都会影响甜度。
   - 如果按甜度采购，很容易被“这批很甜”牵着走，但下一批又不行。

### 但甜度也不能完全不看

甜度低到一定程度，会有两个问题：

- **糖浆加太多**：盖住菠萝本身的香气，喝起来像糖水。
- **酸涩感突出**：不是甜不甜的问题，而是酸、涩、刺口。

所以甜度要设一个**最低可接受线**，不是越高越好。

### 实操采购建议

| 指标 | 建议 |
|---|---|
| 出汁率 | 作为第一硬指标，低于标准直接淘汰 |
| 甜度 | 设最低线，合格即可，不追求最高 |
| 酸度 | 要关注，太高会刺口 |
| 香气 | 很重要，决定成品像不像真菠萝 |
| 纤维感 | 看产品类型，做果茶要有，做纯汁可低 |
| 成熟度 | 太生出汁低、太熟易发酵 |

### 简单判断标准

- **做果茶、菠萝饮品**：出汁率 > 甜度。
- **做高端鲜果茶、强调“不加糖也好喝”**：甜度和香气权重上升，但出汁率仍是底线。
- **做低价走量产品**：出汁率几乎是唯一核心，甜度靠糖浆解决。

### 一句话总结

**出汁率决定你赚不赚钱，甜度决定你好不好调。采购时先看出汁率，再在出汁率合格的原料里选甜度和香气合适的。**
