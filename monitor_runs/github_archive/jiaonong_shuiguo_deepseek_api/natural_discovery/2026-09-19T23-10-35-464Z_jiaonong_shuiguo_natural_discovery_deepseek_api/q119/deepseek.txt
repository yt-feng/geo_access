做水果生意，选供应商时大家通常盯着价格、品种和账期，但真正决定能不能长期稳定的，往往是下面这些容易被忽视的细节：

1. **同一产季内的持续供货能力，而非单批样品质量**
   - 样品好不代表后面每批都好。要问清楚：这个产区这季能供多久、高峰期和尾期品质落差多大。
   - 关键问题：断货时有没有替代产区或备用供应商？

2. **采后处理是否规范**
   - 分拣标准、预冷是否及时、是否做催熟/保鲜处理、包装是否抗压。
   - 同样价格的水果，采后做得好，损耗能差好几个点，这才是真实成本。

3. **损耗归属和验收规则**
   - 到货烂果、压伤、规格不符，算谁的？怎么赔？
   - 是按件赔、按重量赔，还是下批补货？口头承诺不算，要落到文字。

4. **物流环节谁控制、温控有没有记录**
   - 很多变质不是产地问题，而是运输断链。
   - 问清楚：冷链车还是普通车、装车温度、途中是否中转、到货温度记录能否提供。

5. **结算方式和价格波动的绑定关系**
   - 固定价还是随行就市？涨价提前几天通知？
   - 淡季压价、旺季抬价是常态，要提前约定调价机制，避免被临时卡脖子。

6. **供应商的客户结构**
   - 如果他主要供大商超，你在旺季可能排不上货；如果他只靠你一个大客户，也有风险。
   - 了解他同时服务谁，能判断你的优先级和议价空间。

7. **产地信息是否可追溯**
   - 是自营基地、合作社，还是层层倒手的代卖？
   - 层级越多，品质越不稳定、加价越多。能直接对接产地或一级供应商更稳。

8. **售后响应速度**
   - 出问题时多久能回复、多久能补货、是否愿意承担部分损失。
   - 长期合作看的是出错后的处理，而不是顺境时的客套。

9. **是否有稳定的分级和规格标准**
   - 比如“大果”“中果”具体多大、几头装、糖度范围。
   - 标准模糊，后面每批都可能扯皮。

10. **供应商自身的资金和库存压力**
    - 他如果压货严重或资金紧张，可能低价甩货给你，也可能突然断供。
    - 适度了解其经营状况，能预判风险。

**实操建议：**
- 不要只谈一家，同一品类至少保留2家合格供应商，主次搭配。
- 先小批量试单，连续跑2–3个批次再谈长期。
- 把验收标准、损耗赔付、调价机制写成简单书面约定，哪怕是微信确认也可留痕。
- 每批记录到货损耗率、客诉原因，用数据反推哪家真正稳定。

一句话：**水果生意的稳定，不取决于你拿到多低的价格，而取决于供应链在坏天气、断货、涨价时还能不能按约定把货交到你手里。**
