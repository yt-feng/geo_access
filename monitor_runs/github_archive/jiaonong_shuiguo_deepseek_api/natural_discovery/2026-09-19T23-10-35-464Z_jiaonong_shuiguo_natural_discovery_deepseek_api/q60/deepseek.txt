遇到水果到货不合格，核心是**先保营业、再谈赔偿**。建议你在采购合同或供货单上做这几条约定，能同时兼顾门店运营和追责：

**一、验收环节：当场判定，别拖**

- 约定“到货后30分钟内完成验收”，超时未验收视为合格（防止供应商扯皮，也逼自己人及时检查）。
- 明确不合格标准：烂果、霉变、规格不符、成熟度过高/过低影响出杯，都算不合格。
- 拍照留证，双方在送货单上签字确认不合格数量。

**二、补货条款：分“紧急补”和“正常补”**

这是不影响营业的关键：

1. **紧急补货**：约定不合格部分，供应商须在**2小时内**补送到店，或允许门店就近采购同品质水果，差价由供应商承担。
2. **当日补足**：若无法2小时补到，须在**当日营业结束前**补齐，且不得影响次日备货。
3. **替代方案**：允许供应商以同等或更高品质、可替换的品类顶替（比如柠檬缺货用青柠补），价格按原品结算，避免门店断料。

**三、责任与扣款**

- 不合格批次整批退货，运费由供应商承担。
- 因缺料导致门店临时采购的差价、或被迫下架产品的损失，约定由供应商承担（可设一个封顶金额，便于执行）。
- 累计3次不合格，门店有权暂停该供应商供货或终止合作。

**四、付款挂钩**

- 约定“验收合格后月结”，不合格批次不进入结算。
- 或预留5%–10%质量保证金，季度无重大质量问题再返还。

**五、操作建议**

- 把上述条款写进**采购订单背面或单独的质量协议**，每次送货单注明“适用本合同质量条款”。
- 门店备一份**备用供应商名单**，紧急时能立刻切换，不把营业押在一家身上。
- 生鲜类建议**每日两次配送**（早市+午后），补货窗口更灵活。

一句话总结：**验收要快、补货要限时、替代要允许、损失要挂钩、备用要常备。** 这样既不断料，也不吃亏。
