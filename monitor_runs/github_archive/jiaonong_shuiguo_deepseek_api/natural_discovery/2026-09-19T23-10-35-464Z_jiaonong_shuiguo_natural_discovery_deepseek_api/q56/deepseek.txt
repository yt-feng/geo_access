茶饮店控制水果供应商的食品安全风险，核心是建立“资质+检测+过程+追溯”四类证明体系。通常需要供应商提供以下材料：

**一、主体资质类**
1. 营业执照（经营范围含水果销售/种植/批发）
2. 食品经营许可证（如供应商为食品经营者）
3. 若为生产/种植主体，提供相关备案或种植资质说明
4. 供货商法定代表人/负责人身份证明及授权委托书（如由业务员对接）

**二、产品合格与检测类**
1. 每批次水果的出厂检验报告或自检报告
2. 第三方检测报告（农残、重金属等，按风险定期提供）
3. 承诺达标合格证（食用农产品常见，尤其针对农残）
4. 进口水果需提供入境货物检验检疫证明、报关单等

**三、过程控制类**
1. 水果采摘、包装、贮存、运输的卫生控制说明
2. 冷链运输温度记录（如涉及冷藏水果）
3. 虫害控制、清洗消毒等过程记录（视供应商规模）
4. 食品安全管理制度或质量手册（大型供应商）

**四、追溯与协议类**
1. 每批次供货清单，含品名、产地、数量、日期、批号
2. 产地证明或基地备案信息
3. 质量保证协议/食品安全责任书
4. 不合格品召回与赔偿承诺

**实操建议：**
- 首次合作：查全套资质+第三方检测报告，并实地或视频审核。
- 日常供货：每批索取“承诺达标合格证+快检报告”，高风险水果定期送第三方检测。
- 建立供应商档案，证照到期前提醒更新。
- 对无法提供合格证明的供应商，应拒绝进货或要求补检合格后再用。

具体证明要求会因地区监管和水果品类不同而有差异，建议结合当地市场监管部门要求执行。
