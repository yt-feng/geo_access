如果目标是“稳定导入、风险最低”，优先从**香蕉**开始，其次是**菠萝**，最后才是**苹果**。原因不是口感，而是供应链和损耗特性。

**香蕉：最适合作为进口水果试点**
- 需求稳定，消费者认知强，周转快。
- 进口香蕉（如菲律宾、厄瓜多尔等产地）已有成熟冷链和催熟体系。
- 单价适中，顾客购买频次高，容易形成稳定销量。
- 风险点：需要催熟管理，不能直接按到货状态卖。超市若没有催熟房或稳定温控，要先把这块外包或外包给供应商处理。

**菠萝：第二选择，适合做差异化**
- 进口菠萝（如菲律宾、泰国等）有稳定货源，季节波动相对可控。
- 客单价和毛利通常比香蕉高，适合做试吃和组合销售。
- 风险点：货架期比香蕉短，去皮、切果、损耗管理要求更高；如果超市没有较强的生鲜运营能力，损耗会吃掉利润。

**苹果：不建议作为第一试点**
- 虽然苹果耐储、损耗低，但国产苹果供应极强，价格和新鲜度优势明显。
- 进口苹果（如新西兰、美国、智利等）通常定位高端，销量依赖消费能力和品牌认知。
- 一旦动销慢，库存占用和冷链成本会拖累现金流。
- 风险点：不是“不稳”，而是“竞争太强、差异化不足”，容易变成高库存低周转。

**可执行建议**
1. 先做 **1 个进口香蕉SKU**，找能提供催熟和稳定周配的供应商。
2. 同时测试 **1 个进口菠萝SKU**，只做小批量、试吃驱动，观察7天动销和损耗。
3. 苹果暂缓，等香蕉和菠萝跑出稳定毛利后，再考虑进口苹果作为高端补充。
4. 判断标准：连续4周每周销量波动不超过20%，损耗率低于5%，就可以认为这个品类“稳定”。

如果只能选一个：**先做香蕉。**
