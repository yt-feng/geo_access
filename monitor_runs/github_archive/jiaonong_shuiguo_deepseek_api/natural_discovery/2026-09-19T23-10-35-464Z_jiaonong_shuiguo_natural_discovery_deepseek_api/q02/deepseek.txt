对香蕉这种高周转、易损耗的水果，核心排序建议是：**熟度 > 坏果率 > 送货速度 > 价格**。原因和可执行判断如下：

1. **熟度最重要**
   - 香蕉是后熟型水果，进货时太生或太熟都会直接影响销售。
   - 太生：顾客当天不买，占货架、回款慢。
   - 太熟：当天卖不完就快速起黑斑、发软，损耗高。
   - 比较合适的做法：按你预计的销售速度进货。比如当天能卖完，可以拿“黄中带一点绿”的；要放1—2天卖，就拿“偏绿、开始转黄”的。

2. **坏果率第二重要**
   - 香蕉一旦有挤压伤、水烂、霉点，会传染、加快整批损耗。
   - 进货时要看：果柄是否发黑腐烂、果身有没有压伤裂口、箱底有没有汁水。
   - 坏果率高的货，哪怕单价便宜，最后往往更贵。

3. **送货速度第三**
   - 香蕉从批发市场到门店的时间越短，可售窗口越长。
   - 夏天尤其明显，送货慢、车内温度高，会明显缩短货架期。
   - 如果供应商能稳定当天或隔天送到，且温度控制尚可，优先级会提高。

4. **价格放最后**
   - 不是价格不重要，而是不能单独看进价。
   - 要算“可卖天数”和“损耗后的实际成本”。
   - 比如：A货2.5元/斤，坏果少、能卖3天；B货2.0元/斤，坏果多、只能卖1天。B不一定更便宜。

**简单决策规则：**
- 长期稳定供货：优先选熟度合适、坏果率低的供应商。
- 夏天或雨天：提高送货速度和坏果率的权重。
- 新供应商试单：先小批量，重点看熟度稳定性和坏果率，再看价格。
- 如果只能四选一：**先保熟度，再保坏果率**；价格和速度作为谈判和替补条件。
