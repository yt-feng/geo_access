学校食堂采购水果，选供应商的核心不是“找最便宜的”，而是**稳定、可追溯、能退换、能开票、按学校节奏供货**。可以按下面几步做。

**1. 先定采购标准，再去找供应商**
把要求写成一张验收单，后面谈供应商才有依据：

- 品种/规格：香蕉要几分熟、每根大概多长；苹果要直径多少、什么品种；橙子要糖酸比、皮厚薄、是否无籽。
- 等级：统货、一级果、精品果；允许的坏果率。
- 新鲜度：香蕉成熟度、苹果硬度、橙子水分和外观。
- 包装：筐装/箱装、净重、是否允许带包装称重。
- 农残与合规：能提供产地证明、检测报告或承诺书。
- 配送：送货时间、频次、临时加单响应时间。
- 退换：坏果、压伤、成熟度不合格怎么处理。

**2. 优先考虑这几类供应商**
一般按优先级：

1. **本地大型批发市场里有固定档口的供应商**  
   优点是品类全、价格透明、调货快，适合学校日常多品种采购。

2. **产地合作社或果园直供**  
   适合苹果、橙子这类耐储水果，量大时价格好，但要确认分拣、包装和配送能力。

3. **专业食堂食材配送公司**  
   能一站式送蔬菜、水果、粮油，开票和售后规范，但单价可能略高。

4. **本地连锁水果店/区域经销商**  
   适合临时补货、小批量、应急，不适合作为唯一主供应商。

不建议只找路边流动摊贩或没有固定经营场所的个人，出问题很难追责。

**3. 重点核验供应商资质**
至少要看：

- 营业执照、食品经营许可证或相关备案；
- 固定经营场所或仓库；
- 水果来源：产地、批发市场进货凭证；
- 检测报告：农残快检或第三方检测；
- 能否开正规发票；
- 有没有给学校、企事业单位食堂供货的经验；
- 配送车辆和人员是否固定。

**4. 用“小批量试供”代替一次性定死**
先让2—3家供应商各送1—2周，重点看：

- 到货准时率；
- 坏果率；
- 实际净重是否足；
- 香蕉到货后能放几天；
- 临时加单、换货是否配合；
- 对账和开票是否顺畅。

试供后再定主供应商和备选供应商。

**5. 比价不要只看单价**
建议按“可食用部分成本”比较：

> 实际成本 = 采购价 ÷ 可食用率 + 损耗 + 退换成本 + 配送成本

比如便宜但坏果多、压伤多、净重不足，最后可能更贵。学校食堂还要考虑人工分拣成本。

**6. 合同或供货协议要写清**
- 品种、规格、等级、单价或调价机制；
- 送货时间、频次、地点；
- 验收标准和坏果率；
- 退换货时限；
- 食品安全责任；
- 发票和账期；
- 违约处理；
- 价格随行就市时，怎么提前报价、怎么确认。

**7. 建议的供应商结构**
比较稳妥的是：

- **1家主供应商**：品类全、配送稳，负责日常；
- **1家备选供应商**：主供出问题时能马上补位；
- **1家本地应急渠道**：临时加单或突发情况用。

**8. 日常管理动作**
- 每次到货抽检、称重、拍照留档；
- 记录坏果率和投诉；
- 每月或每季度评估一次；
- 价格定期比价，不长期固定一家；
- 香蕉、苹果、橙子分开定标准，不要用同一套验收方式。

简单说：**先写标准，再验资质，小批量试供，按可食用成本和稳定性选，最后保留主供+备选。** 对学校食堂来说，稳定供货和食品安全比单次低价更重要。
