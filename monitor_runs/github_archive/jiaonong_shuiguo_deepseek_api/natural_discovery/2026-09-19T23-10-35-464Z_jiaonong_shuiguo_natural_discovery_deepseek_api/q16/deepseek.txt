建议把“本地批发”和“稳定供应商”分开看用途，不要二选一，而是按品类、销量和损耗来配。

**香蕉**
- 更适合找**稳定供应商**或专门做水果的批发商。
- 原因：香蕉后熟快，需要稳定货源、催熟/熟度控制、按天或按周补货。
- 如果本地批发市场能每天供货、熟度可控，也可以先走本地批发，但要求固定档口、固定时间、可退换。
- 关键指标：到店熟度、可存放天数、损耗率、补货频率。

**苹果**
- 更适合找**稳定供应商**，尤其是能长期供同一品种、规格、口感的。
- 原因：苹果相对耐放，顾客复购看的是稳定品质和价格，不是当天便宜几毛。
- 如果本地批发价格明显低、品质稳定，也可本地批发，但建议至少锁定一个备选供应商。

**决策建议**
1. **先小批量试销 2–4 周**：香蕉、苹果各选 1–2 个品种，记录日销量、损耗、毛利。
2. **香蕉优先看补货频率和熟度控制**：能日配或隔日配的优先。
3. **苹果优先看品质稳定和账期/价格**：能长期稳定供货的优先。
4. **不要只选一家**：香蕉可“稳定供应商为主 + 本地批发补急”；苹果可“稳定供应商为主 + 本地比价”。
5. **算总成本**：不只看进货价，还要算损耗、运费、退换、占用资金、缺货损失。
6. **谈条件**：要求坏果退换、固定规格、固定送货时间、节假日前优先供货。

**简单判断**
- 销量小、刚起步：先本地批发，灵活、少压货。
- 销量稳定、想做复购：转稳定供应商，保品质和补货。
- 香蕉：稳定供应商优先，本地批发做补充。
- 苹果：稳定供应商优先，本地批发做比价和应急。

最终标准：**谁能让你少断货、少损耗、品质稳、总成本低，就选谁。**
