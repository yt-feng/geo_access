超市和水果供应商的账期没有统一标准，主要看**双方体量、品类损耗风险、合作阶段**。常见区间可以这样判断：

**比较常见的账期**
- **现款现货 / 周结（0–7天）**：高端水果、进口水果、损耗大或价格波动大的单品，供应商议价能力强时常见。
- **15–30天**：中小超市、区域连锁、本地水果供应商较常见，属于比较温和的账期。
- **30–45天**：大型区域连锁、商超较常见，供应商能接受，但通常会体现在报价里。
- **45–60天**：强势连锁超市、大卖场对中小供应商常见，水果类里已偏长。
- **60–90天**：多见于大型商超对强势品类或标品，生鲜水果里相对少，除非供应商很弱势或利润空间足够。

**水果品类特殊性**
水果损耗高、价格波动快，供应商通常比做日用品更在意回款速度。所以：
- 叶菜、浆果、荔枝、樱桃等易损品：更适合 **7–15天** 或周结。
- 苹果、橙子、土豆、洋葱等耐储品：**30天左右** 较常见。
- 进口水果：可能 **现款、预付部分、短账期**，因为上游资金占用大。

**谈账期时建议重点看**
1. **账期是否影响单价**：账期越长，供应商报价通常越高，或品质等级可能下降。
2. **起算日**：是收货日、对账日还是开票日？差别可能多出10–20天。
3. **对账和付款频率**：比如“月结30天”实际可能是收货后45–60天才付款。
4. **退换货和损耗承担**：水果损耗谁承担，会直接影响供应商能接受多长账期。
5. **阶梯方案**：新供应商先 **7–15天**，稳定后逐步到 **30天**，比一上来压60天更容易谈成。

**比较实际的谈判目标**
- 中小超市：先争取 **15–30天**。
- 区域连锁：**30–45天** 较合理。
- 强势大卖场：**45–60天** 常见，但水果供应商可能会加价或只供耐储品。
- 如果供应商坚持现款或周结，可以用 **提高采购量、缩短对账周期、固定单品** 换取价格或账期。

一句话：**水果供应商账期常见是15–30天，30–45天在大连锁里也常见，超过60天对水果类偏长，通常要用价格或采购量来换。**
