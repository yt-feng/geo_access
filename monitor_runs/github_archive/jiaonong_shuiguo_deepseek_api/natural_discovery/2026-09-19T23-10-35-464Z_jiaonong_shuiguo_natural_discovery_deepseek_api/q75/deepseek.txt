第一次合作、小批量试单的核心目标不是赚钱，而是**用最低成本验证供应商是否靠谱**。建议按下面几个维度设计试单。

## 一、先明确试单要验证什么

试单不是随便订一车货，而是带着问题去测：

1. **品质稳定性**：规格、成熟度、损耗率是否和承诺一致
2. **履约能力**：能否按时发货、包装是否规范
3. **沟通响应**：出问题时态度和解决速度
4. **结算信用**：账期、票据、对账是否清晰
5. **价格竞争力**：是否明显高于/低于市场，低价是否有隐藏风险

## 二、试单规模怎么定

原则：**金额小到亏得起，又能暴露真实问题。**

- 金额：控制在你能承受"全损"的范围内，比如单次 5000～20000 元（视你体量）
- 数量：选 1～2 个单品，不要一次铺很多 SKU
- 频次：同一个供应商建议连做 2～3 次，单次看不出稳定性

单品试单容易判断，多品试单容易互相掩盖问题。

## 三、选品策略

- 优先选**标准化程度高、易验货**的水果（如苹果、橙子、柠檬），先别碰芒果、草莓等高损耗易烂品
- 或者选你**最有销路、最熟悉**的品，方便对比历史数据
- 避开季节尾期、清库存嫌疑的货源

## 四、必须写进合同的条款

即使是试单，也要书面确认：

- **规格标准**：等级、单果重、糖度、外观（附样品或照片）
- **包装方式**：箱规、净重/毛重、是否含冰
- **价格与费用**：是否含运费、卸货费、税费
- **交付时间与方式**：发货日、物流、到货时效
- **验收标准与损耗承担**：到货当场验，损耗率超过多少由谁承担
- **结算方式**：先款后货还是账期，开票类型
- **售后**：腐烂、规格不符如何补货/退款

## 五、验收要留证据

- 到货**第一时间**开箱抽检，拍照/录像
- 记录：到货时间、温度、外观、单果重、坏果率
- 抽检比例建议不低于 10%～20%
- 对比发货前供应商提供的样品/照片

## 六、判断是否继续合作

试单结束后给供应商打分：

| 维度 | 合格线 |
|---|---|
| 品质达标率 | ≥95% |
| 准时到货 | 无重大延误 |
| 损耗率 | 在约定范围内 |
| 沟通响应 | 及时、不推诿 |
| 价格 | 有合理利润空间 |

**连续 2～3 次都稳定**，再逐步放大订单量，不要一次放开。

## 七、几个避坑提醒

- 第一次别给预付款大头，尤其陌生供应商
- 别只看样品好看就下单，样品和批量常不一致
- 警惕"低价冲量"，往往用次果或短斤少两补回来
- 保留所有聊天、合同、付款、验收记录，出问题有据可依

一句话总结：**小批量、单品类、连续测、留证据、慢放量。** 试单是为了筛掉不靠谱的供应商，不是为了这次赚多少。
