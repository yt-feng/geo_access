结论：**大多数商超应以“整果为主、切好为辅”组合销售；如果门店客流以上班族/即买即吃为主，则要把切果做成主力增量，但整果仍不能砍掉。**判断核心不是哪个更“好卖”，而是门店场景、损耗能力、客群和毛利结构是否匹配。

**整果更适合：**

- **家庭客群、社区店、价格敏感客群**：整果单价低、分量足，顾客觉得划算。
- **耐存放、损耗可控**：菠萝整果比切果耐放，采购和陈列压力小。
- **引流和堆头销售**：整果适合做爆品、促销价、整箱卖，能拉客流。
- **毛利不一定低**：如果采购价有优势，整果走量后毛利稳定。

但整果的问题也明显：**客单价低、顾客嫌削皮麻烦、冲动购买少**，年轻人不一定愿意买。

**切果更适合：**

- **商圈店、写字楼店、交通枢纽店、学校周边**：即买即吃，方便优先。
- **提升客单价和毛利**：切好、装盒、配叉子，能卖出加工溢价。
- **降低顾客决策门槛**：不用削、不用泡盐水，拿就走。
- **带动连带销售**：和酸奶、沙拉、其他果切组合卖。

但切果的关键风险是：**损耗高、人工高、食品安全要求高、保质期短**。如果门店销量不够，切了卖不掉，损耗会把毛利吃掉。

**实操建议：**

1. **先按门店类型分策略**
   - 社区店/家庭客流店：整果 70%，切果 30%。
   - 商圈店/写字楼店/学校店：整果 40%—50%，切果 50%—60%。
   - 高端超市/精品超市：切果、拼盘、小份装可以更高，但必须控损耗。

2. **切果不要全品项铺开**
   - 先做 1—2 个规格：小盒即食、家庭分享盒。
   - 观察 3—7 天动销，卖不动就减量或停做。

3. **用整果做价格锚点，用切果做利润**
   - 整果标低价，吸引进店。
   - 切果标方便和品质，赚加工毛利。
   - 例如整果按个卖，切果按盒卖，让顾客自己选。

4. **重点算损耗账**
   - 切果真实毛利 = 售价 - 原料成本 - 人工 - 包装 - 损耗 - 报废。
   - 如果切果报废率超过 15%—20%，且销量不稳定，就不适合当主力。

5. **采购端配合**
   - 整果采购选耐储、大小均匀、适合堆头的货。
   - 切果采购选成熟度合适、出肉率高、外观要求可略低的货，但食品安全不能降。
   - 最好分等级采购：好果卖整果，次好果做切果，但腐烂、变质果不能进切果。

**一句话判断：**
如果门店客流偏家庭、损耗控制弱，**整果为主**；如果客流偏年轻、即食、商圈，**切果为主但整果保留**。最稳的做法是：**整果保客流和基本盘，切果提客单和毛利，按门店数据动态调比例。**
