社区超市进水果，控制新鲜度和库存的关键在于**“小批量、高频次”**和**“以销定采”**。以下是具体可操作的建议，分为**进货前**、**在店中**和**临期处理**三个环节：

**1. 进货前：精准预测与源头控制**

-   **看数据说话**：记录近两周每天各类水果的**实际销量**（不是进货量）。建立简单的“日均销量表”。
-   **遵循“三三原则”**：进货量 = 预计3天销量 + 20%的损耗补偿。不要贪心一次进太多，哪怕批发价贵一点，也要保证周转率。
-   **分级采购**：把硬果（苹果、梨、橙子）和软果（香蕉、草莓、葡萄）分开。**硬果**可以多进一点，放得住；**软果**坚决少进，按天采购。
-   **选好供应商**：和固定批发商建立“次日调换”协议。如果某筐水果有烂的，下次进货时扣除损耗。

**2. 在店中：分区陈列与“先进先出”**

-   **物理隔离**：不要把所有水果堆在一起。**香蕉**要单独挂起来（乙烯催熟），**苹果**和**梨**不要与蔬菜（尤其绿叶菜）混放，防止催熟和串味。
-   **陈列技巧**：把最新鲜的放在**底层**，把前天剩下的放在**上层顾客手边**，严格执行“先进先出”。
-   **定时翻拣**：每天早中晚各抽15分钟，把表皮有黑点、碰伤的“次果”挑出来。**不要等烂了再挑**，烂一个会传染一整筐。
-   **标签管理**：在货架旁贴一个“今日到货”小牌子，写清日期。这既能增加信任，也能提醒自己哪些该先卖。

**3. 库存消化：动态定价与二次加工**

-   **“黄金6小时”法则**：水果在当天下午5点后就是临期。如果下午4点还剩下较多，立刻启动**“打折清货”**（例如原价打8折，晚上7点打6折）。
-   **果切/果汁化**：把卖相不佳但没坏的水果，去皮切块做成**果盒**（成本高、损耗大，建议做成果汁或果切拼盘），售价可以覆盖成本，这是社区店最有效的止损方式。
-   **捆绑销售**：买一盒草莓，加1元送一个苹果。用硬果的利润补贴软果的损耗。

**4. 核心决策指标（记住这一个数）**

-   **周转天数**：如果你平均3天能卖完一批货，说明库存健康。如果某类水果**超过4天**还没卖完，**立刻停止进货该类水果**，直到现有库存接近清零。
-   **坏果率**：如果每次进货到卖完，损耗超过8%，说明进货量太大或陈列有问题。

**总结一句口诀**：**“少进勤补、硬多软少、先到先卖、晚市清仓”**。社区店的利润靠的就是**周转速度**，而不是单次进货的折扣优势。
