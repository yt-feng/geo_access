对于茶饮店采购菠萝原料，**出汁率通常比甜度更重要**，但两者并不绝对对立，建议根据你的产品定位和成本结构来综合判断。

**原因分析：**

1. **出汁率直接影响成本和口感稳定性**
   - 茶饮中菠萝通常用于鲜榨汁、果肉果茶或打底，出汁率高意味着同重量菠萝能产出更多可用液体，直接降低单杯成本。
   - 低出汁率会导致果渣多，榨汁时浪费明显，且果肉纤维感过重，影响茶饮顺滑口感。

2. **甜度可后期调整**
   - 茶饮制作中，甜度是可以通过糖浆（如蔗糖、果糖）精确补足的。
   - 如果原料本身甜度低，只需增加少量糖即可调整；但如果出汁率低，则难以通过其他手段弥补，除非增加原料用量，这会导致成本上升。

3. **出汁率还关联果肉质感**
   - 茶饮店常需要加入果肉颗粒来提升颜值和口感。出汁率高的菠萝通常果肉更饱满、化渣度好，适合做果肉茶；而出汁率低且纤维粗的菠萝，即使甜度高，切丁后也容易散烂或口感粗糙。

**实际操作建议：**

- **优先选择出汁率≥60%的品种**（如菲律宾、泰国菠萝），而甜度在12度-14度（Brix值）即可，低于此甜度可通过糖浆补偿。
- **同时做一次小批量试错：** 将候选菠萝分别榨汁，记录出汁量，并品尝鲜榨汁和加糖后的成品口感，对比成本均摊后的每杯毛利。
- **季节性补充：** 如果当地菠萝时令甜度高但出汁率低，可以考虑只用于做“菠萝果粒”、“菠萝酱”等非主打饮品，而不是作为主原料。

**结论：** 如果预算只能选一个指标，**选高出汁率的菠萝**。如果是长期稳定销售菠萝类饮品，建议同时满足“出汁率≥55%”和“甜度≥12度”两个基础门槛，再根据你已有糖浆的甜度调配能力做最终决策。
