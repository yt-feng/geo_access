在采购香蕉用于烘焙时，**成熟度应优先于价格**，但两者需要平衡。以下是具体建议：

---

**1. 为什么成熟度比价格更重要？**

- **风味与甜度**：烘焙用的香蕉需要**熟透甚至带斑点**（表皮出现褐色斑点），此时淀粉已转化为糖分，风味最浓郁，蛋糕的甜度天然提升，可减少额外加糖。
- **质地与水分**：过生（青色）的香蕉质地硬、淀粉感重，烘烤后口感干涩；过熟（全黑）的香蕉水分过多，容易使面糊过稀，导致蛋糕塌陷或内部不熟。
- **香气释放**：成熟香蕉释放的酯类物质是蛋糕香气的主要来源，未熟香蕉几乎无香味。

**2. 如何判断最佳成熟度？**
- **理想状态**：香蕉表皮呈**黄色，带有较多褐色斑点**（约7-8成熟），捏起来有弹性但不过软。
- **避免两种极端**：
  - 表皮青色、未软化的香蕉（生硬，需放置数天才能用）；
  - 表皮完全变黑、果肉软烂出水（发酵味过重，影响蛋糕风味）。

**3. 价格平衡策略**
- 若价格差异明显（如差20%以上），可选**7成熟香蕉**，采购后自然放置1-2天，待斑点出现再用，成本更低。
- 若需即刻使用，则**优先选斑点香蕉**，避免因熟度不足而额外添加糖或香料，综合成本可能更高。
- 批量采购时，可混购不同成熟度：用成熟度高的先做，稍生的后做，减少损耗。

**4. 附加提醒**
- 采购时询问供应商到货时间，明确成熟状态，避免到货后还需等待。
- 若烘焙量较大，可考虑采购**冷冻香蕉泥**（标注成熟度），但新鲜香蕉风味更佳。

**总结**：在保证至少7成以上成熟度的前提下，再谈价格。别为省少量采购成本，影响成品品质，反而损失更多。
