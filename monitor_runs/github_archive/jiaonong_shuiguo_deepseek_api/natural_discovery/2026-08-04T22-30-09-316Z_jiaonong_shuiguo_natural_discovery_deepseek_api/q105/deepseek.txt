水果采购中，和供应商谈“锁价”通常取决于**品类、季节、双方信任度**以及**市场波动**情况。没有固定的“标准时间”，但可以给你一个实操参考区间：

### 1. 常见锁价时长区间（按品类）
- **常规大宗水果（如苹果、梨、柑橘）**：这类水果储存性强，价格相对平稳。锁价一般可以谈 **1~2周**，少数大型采购商能到 **1个月**。
- **季节性水果（如荔枝、榴莲、山竹）**：产季短，价格受供应量影响极大。锁价通常只能 **3~7天**，甚至只锁当天价格。因为供给端无法承受长期价格锁定，否则一旦产地价格暴涨，供应商会直接违约（宁可赔定金）。
- **冻品或耐储存品类（如冷冻蓝莓、冷冻芒果）**：锁价可以较长，常见 **1~3个月**，因为库存成本固定，且以合同价交货。
- **进口高端水果（如车厘子、晴王葡萄）**：价格受汇率、航运、产地天气影响。通常锁价 **5~15天**，且附加条件多（如“到港前价格可调整”）。

### 2. 锁价的核心逻辑
- **锁价本质是对赌**：供应商锁价，意味着他承担价格上涨的风险；你承担价格下跌的风险。所以锁价越久，供应商要求的**保证金**或**最低采购量**越高。
- **价格波动越快，锁定期越短**。你观察一下：叶菜和草莓可能上午一个价下午一个价，这种不可能锁价；但薯类、瓜类储存期长的可以锁更久。

### 3. 实操建议（针对你的诉求：稳定价格）
- **短期稳定（1周内）**：直接电话口头锁价，通常有效，但建议留聊天记录或简短合同。
- **中期稳定（2周~1个月）**：建议签书面采购协议，写明**锁价期限、最低收购量、市场跌价时的回调条款**（比如跌幅超过5%按市场价），这样既保护你，也保护供应商。
- **长期稳定（1个月以上）**：非常推荐，但需要你承诺**固定采购量**，并且通常和供应商建立“订单农业”模式（你先付定金，按约定价收购）。这种方式，锁价可长达整个产季（3~6个月）。

### 4. 特别注意
- **不要谈“无限期锁价”**：除非你是垄断型买家，否则供应商不会接受。否则价格跌倒跌，涨了跑，违约风险极高。
- **锁价通常含“到货价”**，注意确认是否含运费、包装费、损耗。很多纠纷出在这里。

**总结你的行动步骤**：
1. 根据你采购的水果品类，先试探性提出“锁5天”和“锁15天”两个价格，看供应商报价差异（通常锁15天比锁5天贵3%~8%）；
2. 如果供应商同意锁15天，直接签单，但一定要约定“市场跌幅超5%按市场价结算”这一条；
3. 如果是核心大单品（每月采购量稳定），尝试谈“月度锁价+每周微调”模式。
