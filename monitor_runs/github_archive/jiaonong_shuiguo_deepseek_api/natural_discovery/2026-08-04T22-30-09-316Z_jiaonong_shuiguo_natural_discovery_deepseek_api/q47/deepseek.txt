在茶饮店采购香蕉时，控制熟度非常关键，因为熟度直接决定了风味、口感和出品的稳定性。以下是针对采购时的具体控制方法：

**1. 明确用途分阶段采购**
- **做果汁/冰沙/奶昔**：需要**全熟或过熟**（表皮出现黑斑，果肉软糯），甜度高、香气浓，打出来更顺滑。
- **做切片装饰/topping**：需要**七八成熟**（表皮金黄、稍硬），切出来形状完整，不易断裂。
- **做烘焙或焦糖香蕉**：可稍生一些（六成熟），耐烤不易烂。

**2. 按到货成熟度梯度下单**
- 不要一次性买全部同一个成熟度。
- 理想配比建议：**30% 生果（耐放） + 40% 半熟（1-2天内用） + 30% 全熟（当天/次日用）**。
- 让供应商按“分档成熟度”打包发货，如果不行，就自己按这个比例混合签订单。

**3. 到货验收标准**
- **颜色**：表皮呈黄绿色至金黄、无大面积黑斑。有少量黑斑可接受，但若黑斑蔓延至果柄或发软出水，拒收。
- **硬度**：轻轻按压果柄或果肩，稍有弹性为佳；按压凹陷且出水则过熟。
- **气味**：有浓郁天然香蕉香，无酒精发酵味（有酒精味说明熟过头或存放过久）。
- **重量**：同体积下手感沉甸甸的，水分足；轻飘飘的可能是脱水或过熟。

**4. 到店后的熟度管理**
- 采购回来立即按用途分级存放：
  - 需要催熟的（较生）放常温通风处，或在纸箱里加两个苹果催熟。
  - 当天用的（全熟）放4-6℃冷藏（注意不能低于4℃，否则果皮变黑但果肉可用）。
- 每天开档前检查一遍，优先使用最熟的，形成“先进先用”流转制度。

**5. 应急解决方案**
- 如果遇到全熟果过多，可切块冷冻（去皮切块后速冻），用于后续做冰沙或奶昔，不影响口感。
- 如果过熟果较多，可熬成香蕉泥/香蕉酱冷藏备用（限当日或次日用完）。

**关键提醒**：香蕉熟度变化非常快（尤其夏季），建议**少量高频采购**，比如每1-2天进一次货，而不是一周一次大批量囤货。这样既能保证新鲜度，又把损耗降到最低。
