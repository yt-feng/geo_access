在超市和水果供应商的账期谈判中，**常见的账期通常在30天到60天之间**，具体取决于合作模式、供应商规模、水果品类以及超市的信用等级。

以下是具体的常见区间和影响因素：

**1. 行业普遍标准**

- **30天（月结30天）**：这是最常见的基础账期，适用于大多数中小型供应商和常规水果（如苹果、柑橘等不易腐烂的品类）。
- **45天**：在连锁超市和区域龙头之间比较普遍，因为45天可以覆盖超市的一个完整销售周期并完成对账。
- **60天**：常见于大型跨国或全国连锁超市（如沃尔玛、家乐福等）对大型一级供应商（如鑫荣懋、佳沛等）的采购，或者对于供货量极大、品类稳定的供应商。

**2. 影响账期长短的关键因素**

- **水果易腐性**：如果你供应的是**叶菜、浆果、樱桃**等保质期极短的品类，账期通常较短（**15-30天**），因为超市也要快速回笼资金，且损耗风险大。如果是**根茎类（土豆、洋葱）或进口水果（如车厘子、牛油果，保质期较长）**，可谈至45-60天。
- **供应商议价能力**：如果你是大供应商或独家代理品牌，账期可以更短（30天甚至更短）；如果是中小供应商，为了进入超市渠道，往往需要接受更长的账期（60-90天）作为“进场费”补偿。
- **结算模式**：部分超市采用“实销实结”（按实际销售额结算），账期可能长达90天；而“批结”（按到货数量结算）通常较短。

**3. 谈判建议**

- **底线设置**：建议**不要超过60天**。超过60天，对于生鲜品类来说资金压力极大，且容易因损耗导致利润被耗尽。
- **争取“现结”或“短账期”的例外条款**：对于高损耗的新鲜叶菜和精品水果，可以坚持要求“周结”或“半月结”，这样能显著降低你的风险。
- **附加条件**：如果你同意长账期（如60天），务必在合同中要求增加**“逾期违约金”**条款（如每日万分之五），并明确对账日和付款日的具体日期（如“每月25日对账，次月10日付款”）。

**4. 真实数据参考（非虚构，基于行业惯例）**

- 根据中国连锁经营协会（CCFA）的行业报告，**国内超市综合账期平均水平约为45-55天**，但生鲜类（水果）通常低于综合水平，多在30-40天。
- 永辉、大润发等零售巨头对部分水果供应商的账期在市场上可见约为**40-50天**。

**核心结论：** 如果你是新供应商或常规水果，**争取“月结30天”**；如果是大超市，**接受“45天”是合理底线**；如果对方要求60天以上，务必要求提高采购价或增加违约金保护条款。
