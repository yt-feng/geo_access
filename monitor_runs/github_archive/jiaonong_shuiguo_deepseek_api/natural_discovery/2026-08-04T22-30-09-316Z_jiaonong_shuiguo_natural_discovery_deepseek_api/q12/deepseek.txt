在采购菠萝时，判断熟度需要结合**外观、手感、气味**和**用途（即买即卖还是库存周转）**。核心原则是：**“7-8分熟”最适合到店销售**，既不易在运输和存放中腐烂，又能在顾客拿走1-2天内自然全熟。

以下是具体判断和采购操作建议：

### 1. 看外观（颜色与纹路）
- **表皮颜色**：青绿色（过生）或全金黄色（过熟，易烂）。采购时选**黄中带绿、绿中显黄**的（约7成黄），这是最佳熟度。
- **果眼（鳞片）**：果眼越深、越凹陷，说明果实越成熟。挑果眼稀疏且突出的，这类更甜但耐放性稍差；果眼紧密的一般偏生。
- **底部（蒂部）**：手指按压底部（果脐），微微发软、有弹性，说明接近熟；如果软到能按出汁水，则过熟。

### 2. 手感（重量与弹性）
- **重量**：同等大小下，重的菠萝水分足、更新鲜。轻的可能失水或空心。
- **按压**：用手掌轻按整个果身，**整体微软、有弹性**为宜。如果按下去有“空响感”或局部发软，说明内部可能已出现软烂或空心。

### 3. 闻气味（最准确的指标之一）
- 靠近果柄处闻：有**清甜的菠萝香气**且不刺鼻，说明成熟度适中。
- 气味非常浓郁甚至带酒味，说明过熟或发酵；完全无味则偏生。

### 4. 判断“快速脱手”（3天内卖完）与“库存周转”的不同选择
| 场景 | 采购建议 |
|------|----------|
| **当季旺季、客流大，当天或次日卖完** | 采购**8-8.5成熟**（表皮约8-9成黄，底部略软），顾客买回家当天可切，损耗小，卖相好。 |
| **需要存放2-3天再售（如淡季、库存缓冲）** | 采购**6-7成熟**（表皮青多黄少，果身硬挺），到店后放通风阴凉处2天自然变熟。切忌冷藏，会停止成熟且变味。 |

### 5. 避免的“陷阱”
- **反对要求“全熟”**：全熟的菠萝（全黄、果眼张开）当天卖不掉一两天就腐烂，损耗极高。
- **有碰伤或虫眼的直接排除**：果身任何伤口都会加速腐败。
- **不要买“催熟剂”加工的**：虽然外表金黄，但内部可能偏白、无香气，切开后易发黑（判断：闻着无天然果香，表皮异常均匀黄）。

### 实操建议（给采购员）
- 如果进货量大，建议抽检5-10个，切开抽查1-2个：肉色为**淡黄偏白**（约7分熟）、**金黄**（9分熟），发白或黑芯均不合格。
- 采购单上写清“成熟度7-8分”，要求供应商在筐内做**分批标注**（青果/熟果分放），到货后优先卖熟果，青果放置柜台上层自然后熟。

**一句话总结**：挑“黄多绿少、轻按微弹、果香清新”的，不要买全黄或全青的，留出2天售卖缓冲期，才是最优解。
