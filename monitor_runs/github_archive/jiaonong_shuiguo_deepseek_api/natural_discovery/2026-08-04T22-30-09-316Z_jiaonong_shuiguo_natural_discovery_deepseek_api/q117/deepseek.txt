采购方在试卖新品时，比较稳妥的做法是**小批量、多频次**。

具体建议如下：

1.  **首批试卖量（核心建议）**：
    -   **基础量**：建议控制在**单店日销量的 1/3 到 1/2** 作为首批备货。
    -   **天数**：最多准备 **3-5 天**的试卖量。
    -   **举例**：如果该门店日均水果销量是 100 斤，新品首批进货量建议在 **30-50 斤**，卖完再补，不要一次性囤 5 天以上的货。

2.  **根据风险调整**：
    -   **高风险（新奇特、贵价水果）**：如榴莲、晴王葡萄、进口车厘子等，试卖量应更低，建议**按件或按箱**进，甚至可以先做**预售**或**小份装**（如切盒）来降低损耗。
    -   **低风险（大众普货、当季应季）**：如西瓜、苹果、橙子，可以稍微放宽，但依然建议控制在 3 天内的销量，因为应季水果虽好卖但损耗也快。

3.  **关键策略：单品测试法**：
    -   不要一次性试卖多个新品。**一次只测试1-2个单品**，才能准确评估该单品的复购率和接受度。

4.  **止损线（必须明确）**：
    -   设定一个底线：**如果试卖 3-5 天内，动销率（实际销量/进货量）低于 40%**，且没有明显上升趋势，应立即停止补货，并考虑打折促销消化库存，不要拖延。

**总结一句话**：**先拿3天的货，卖一半再补一半**，这是最稳的节奏。
