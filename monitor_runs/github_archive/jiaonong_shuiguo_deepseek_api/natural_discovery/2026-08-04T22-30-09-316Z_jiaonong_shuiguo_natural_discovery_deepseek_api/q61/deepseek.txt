判断香蕉一手货源是否稳定，可以从**供应链能力、经营资质、履约记录和抗风险能力**四个维度来验证。以下是一套可执行的具体判断方法：

### 1. 看供应链硬实力（最核心）
- **自有基地或长期包地合同**：要求对方出示**土地流转合同**（承包期至少5年以上）、**种植基地的照片/视频**（近期带日期水印）或**基地定位**。如果对方是代办，需提供其与基地的**合作授权证明**。
- **冷库与分拣场地**：香蕉是呼吸跃变型水果，稳定供货必须有**充足的冷库容量**。实地查看冷库容积是否与声称的日供货量匹配（例如日供10吨，至少需有能存30吨以上的冷库）。
- **物流车队**：确认其是否有**自有冷藏车**或长期合作的物流公司合同，这决定了雨季或节假日是否能正常发运。

### 2. 查资质与市场信誉
- **营业执照**：查看经营范围是否包含**水果种植/批发**，注册时间越早越好（一般超过3年）。
- **行业背书**：向**当地农业农村局、批发市场管理方**或**同行档口老商户**打听该货主的口碑。重点问：**有没有发生过断供、货不对板、以次充好**的情况。
- **产地证明**：要求提供当批次的**产地证书**（如海南、广西、云南产地的官方证明），并核对货主是否在**中国香蕉产业网**等平台有备案。

### 3. 试单测试履约能力（关键动作）
- **小批量试单**：先下**一车（约20-30吨）或半车**的订单，观察其发货准时率（要求误差不超过24小时）、到货品质（焦把大小、成熟度一致率）。
- **特殊天气压力测试**：选择一个**台风或暴雨预警期**下试单，看对方是否能承诺并兑现“风雨无阻”的发货时间。
- **付款方式测试**：稳定供货商通常接受**“到货验货后付款”或“定金+尾款”**模式；若对方要求全款预付且无任何担保，需要警惕。

### 4. 观察抗风险能力
- **多基地布局**：询问对方在**海南、广西、云南、老挝（进口）**等是否有备用基地。如果单一产地遭遇寒潮或病害，能否立即切换货源。
- **应急合同**：要求在购销合同中写明**“断供违约责任”**（如每吨每天赔偿XX元）和**“品质不符时的扣款条款”**。稳定供货商敢于签这种条款，因为他们有履约底气。
- **资金链状况**：查看对方是否频繁借贷或拖欠货款。可以通过**天眼查/企查查**查看其涉诉记录，若有大量“买卖合同纠纷”或“失信被执行”，果断放弃。

---

### 额外提醒：
- **警惕超低价**：若报价明显低于市场价（例如比海南香蕉地头价低0.5-1元/斤），大概率是次品或产地不真实。稳定供货的前提是**合理的价格区间**。
- **视频验货**：发货当天要求**全程视频连线**，拍摄装车过程、车厢温度、堆叠高度（每层不超过4把），并核对车牌号与司机身份。
- **长期合作锁定**：经过2-3次成功试单后，可要求签订**年度框架协议**，并预付部分保证金锁定供应量，同时要求对方提供**每周供货排期表**。

**最终结论**：如果一个货主能同时拿出**土地合同+冷库实拍+近3个月的发货单据**，且愿意接受**“到货付款+断供赔偿”**条款，那么他的供货稳定性就值得信赖。反之，只靠口头承诺或朋友圈晒单的，慎选。
