小商家采购水果时，**现金结算**和**月结账期**各有明显风险，选择前需要根据自身资金、供应商关系和对水果损耗的判断来权衡。下面是具体分析和应对建议：

---

### 一、现金结算（现款现货）
**优点**：拿货稳、议价空间大、供应商优先供货。  
**风险**：  
1. **资金占用大**：水果是生鲜，保质期短，现金付了款但货卖不完或损耗高，直接亏钱。  
2. **无售后保障**：如果水果到货有质量问题（如烂果、规格不符），现金结算是“钱货两清”，要求退换货难度大，容易哑巴吃黄连。  
3. **易被“压货”**：部分供应商为了清库存，会用现金优惠诱导你多拿货，一旦卖不动，损失全在自己。  

**建议**：  
- 现金结算时，一定要当场验货（看外表、试吃、查重量），有问题的当场拒收或扣钱。  
- 不要因为便宜就超量采购，按自己3-5天的销量进货。  
- 尽量和供应商签简单协议，哪怕手写，注明质量标准和退换规则。

---

### 二、月结账期（先拿货、月底或下月结款）
**优点**：缓解短期资金压力，适合月初资金紧张的小商家。  
**风险**：  
1. **供应商风险**：如果供应商跑路或倒闭，你已拿货但没付钱，可能被追债或断供。  
2. **质量纠纷**：月底结账时，供应商可能拿“你卖不完”当作理由要求你全额付款，而你实际损耗很大，容易扯皮。  
3. **隐性成本高**：月结供应商通常单价会贵5%—10%（相当于利息），长期算下来比现金贵。  
4. **账期管理难**：如果自己记错账、算错账，月底容易多付或少付，引发信誉问题。

**建议**：  
- 月结只选**长期合作、有实体档口或口碑好**的供应商，别和没固定地址的流动商贩走账期。  
- 每次拿货必须**留凭证**：写明品名、数量、单价、日期，最好双方签字或微信确认。  
- 账期建议控制在15—30天，到期准时结算，维护信用，避免被加价。  
- 月底对账时，先把有质量问题（如烂果）的货物单独列出，协商扣减后再付款。

---

### 三、综合建议（针对小商家）
1. **混合模式最稳**：比如**70%现金采购**（新鲜、高需求品种），**30%月结**（耐放、常备品种），平衡风险和资金。  
2. **设定采购上限**：无论哪种结算，单次采购金额不要超过你3-5天营业额的1.5倍，防止囤积。  
3. **关注损耗率**：水果行业损耗通常在10%—20%，如果损耗超过20%，再便宜也别进。  
4. **合同意识**：哪怕是小本生意，也要有文字记录，别怕麻烦，这能避免多数纠纷。
