评估水果供应商的仓配覆盖能力，不能只看“有几辆车”或“仓库面积”，核心要看**时效承诺、损耗控制、以及分仓的合理性**。因为水果是易腐品，品控高度依赖冷链衔接。

针对连锁门店跨城市分布的情况，建议从以下五个维度进行系统性评估：**覆盖半径、配送时效、补货机制、温层能力、以及末端的容错率**。

**第一步：理清门店分布与销售SKU的关联**
- **高动销/高频水果**（如香蕉、叶菜、草莓）：必须依赖**产地直发或区域中心仓（RDC）**，且配送半径不超过**200-300公里**（常温）或**500公里**（冷链车），否则损耗极高。
- **中低频水果**（如进口橙、榴莲）：可接受产地仓直发门店，但需看供应商是否有**预售或冻库调节**能力来分摊集货压力。

**第二步：核查供应商的仓配网络布局（重点）**
- 要求供应商提供**分仓点位图**（最好1个中心仓覆盖3-4个城市，或者按省级设前置仓）。
- **关键指标：** 计算从供应商**最近的前置仓（FDC）**到你的**最远门店**的**车程时间**。合格标准是：常规配送车程**≤8小时**，生鲜快配车程**≤4小时**（指门店发出订单后，到达门店的时长）。
- **避坑点**：很多供应商号称全国仓网，但实际只有总部一个主仓，其他都是“代发”或“本地采购代工”，这种情况必须让其出具**分仓自有或合作仓的租赁合同/报表截图**。

**第三步：评估配送时效与截单点**
- **必须约定清楚**：不同城市的截单时间（例如华东17：00前下单，次日凌晨收货；而西南地区可能需提前到14：00前下单）。
- 建议向供应商**索要近3个月的门店收货准时率**（要求≥95%），并询问**雨季、节假日**等极端天气下的应急预案（是否有备用车路线）。

**第四步：验证温层与品控（水果行业核心）**
- 大部分水果需要**分温层**（如香蕉催熟区、苹果保鲜区、叶菜冷链区）。评估时需现场看仓，确认是否有**0-4℃、4-8℃、常温区**的物理隔离。
- **重点测试**：供应商是否能提供**到店后的“残次率/损耗率”数据**。优质供应商通常承诺**跨区配送损耗率**在**1%-3%以内**（如果是长途跨省直发，可放宽到3%-5%）。

**第五步：制定试运行与KPI量化方案（可执行建议）**
不要只听口头承诺，建议先挑**2-3个不同省份的门店**进行试点，周期**4-6周**，并设定以下硬性考核指标：
- **时效达成率**（按时到货占比）≥96%
- **拒收率**（因腐烂、成熟度不对拒收）≤2%
- **缺货率**（因仓配缺货导致的断货）≤3%
- **多城综合成本**（含损耗折算后的每箱综合成本）需低于当地临时采购价

**最后总结判断逻辑：**
如果供应商的仓网无法实现“**省会城市/核心枢纽城市有仓点**”，并且**产地直发为主的占比超过60%**，那么对于跨城市的连锁门店来说，建议放弃单一供应商模式，考虑“**核心城市自采+周边城市区域代理**”的组合方式。

**简单最终决策法则**：
- 如果全国门店数＞50家且分散在5省以上，且水果销售额占比＞20%，**必须要求供应商提供多仓或多供应商备份**。
- 如果门店集中在**同一城市群**（如长三角或珠三角），且供应商在该区域有**中心仓**，且单程配送≤300KM，可放心合作。
