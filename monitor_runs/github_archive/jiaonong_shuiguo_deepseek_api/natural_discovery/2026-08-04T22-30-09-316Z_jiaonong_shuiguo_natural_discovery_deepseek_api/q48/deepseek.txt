在茶饮连锁采购中，判断供应商能否稳定按规格送货，核心要抓 **“合同约束 + 过程验证 + 售后兜底”** 三个环节。以下是具体可执行、可判断的清单：

**第一步：合同与承诺的硬性指标（先看书面）**
- **明确规格书**：要求供应商提供《菠萝规格验收标准》，必须写清：尺寸（如单果净重500-600g）、成熟度（如可溶性固形物≥12%）、外观（无黑心/果眼腐烂）、甜度与酸度比例、温度要求（3℃-5℃冷链）。
- **阶梯式违约条款**：合同中明确“送货合格率”（例如单批次合格率≥95%），低于该标准需赔偿差价或补货，连续两次低于90%可单方解约。
- **准时率承诺**：写明到货时间窗口（例如±2小时），超时按次扣款。

**第二步：试单验证（小批量压力测试）**
- 不要直接下大单，先下 **3-5次小单**（比如每次100kg），覆盖不同星期/天气/节假日，观察：
  - **到货时间是否波动**：连续记录实际送达时间，若波动超过±1天，说明其供应链弹性不足。
  - **单批次合格率**：每次随机抽10%开箱检查，重点看尺寸是否整箱统一（若一箱大小混杂，说明分拣不专业）。
  - **补货响应速度**：模拟紧急缺货，看其能否在24小时内补发同规格货。
- **要求提供当日报关单/产地证明**：判断其货源是否稳定（若经常换产地，规格容易不稳定）。

**第三步：实地与数据核验（关键动作）**
- **实地考察分选线**：重点看是否有自动称重分选机（而非人工目测），如果靠人工，大概率规格不稳定。
- **要求调取近3个月出货记录**：看其同一规格单品的出货量是否连续（断档超过1周则不稳定）。
- **索要批次留样**：要求其在发货时保留同批菠萝样本，若到店有争议，可对比留样判断是运输损耗还是源头规格问题。

**第四步：建立双向反馈与升级机制（长期稳定）**
- 定制“到货验收单”：每次收货拍照片、记重量、测糖度，拍照发给对方业务员和品控人员，形成数据闭环。
- 每季度开一次品质复盘会：如果连续两季度合格率≥97%，可以签年度长约；如果低于90%，立即启动备选供应商（建议提前培育1家备选，避免断供）。

**如果是在没签订合同前快速判断（临时采购）**：
- 直接问对面业务员一个问题：**“如果这一批部分菠萝不够重，你们是按原规格补货，还是只退差价？”** 
- 若对方回答“只退差价”，说明其稳定性差，大概率是临时拼货；若回答“承诺原规格补货或承担到店分选人工费”，则相对可靠。

**最后提醒**：菠萝属于生鲜，**温度断裂**会导致外观合格但内部变软，务必在验收单上记录“冷链到货温度”，如果连续两次温度超过6℃，即便外观合格也要视为规格不合格（因为会影响切配出杯率）。
