在水果生意中，**长期稳定**是所有经营者的核心诉求。但很多人在选供应商时，只看价格和品相，这恰恰是最大的坑。

结合行业实际，最容易忽视但**影响生死**的细节有以下几条：

**1. 产地/货源“穿透力”**
-   **忽视点：** 只信供应商的批发市场档口背书，没核实他是否**自有基地**或**一手货源**。
-   **后果：** 遇到产地大涨价或断供期，中间商立刻断你货或临时加价，你毫无议价权。
-   **做法：** 要求对方提供产地证明、采购单据（如车辆出库单），甚至是产地果园的视频/照片。如果对方能说出当天产地天气、采摘量，说明他离源头近。

**2. 损耗与售后“免责条款”**
-   **忽视点：** 只看到手价格，不问“到货后烂果、化水、熟透”怎么赔。
-   **后果：** 水果是易损耗品，运输途中难免磕碰。如果供应商规定“离仓概不负责”，这批货的隐性成本全部转嫁给你，毛利直接被打没。
-   **做法：** 必须白纸黑字写清**“到店验收”**标准，比如：次日到货斑点果超过X%全赔或补货。这比谈价格重要10倍。

**3. 资金账期与现金流压力**
-   **忽视点：** 供应商要求“现款现货”，你能接受就忽略，但很多老板忽略**付款周期的灵活性**。
-   **后果：** 水果账期通常很短（3-7天），如果遇到春节前囤货高峰期，你的现金流会瞬间紧绷，导致你被迫高价进货或断货。
-   **做法：** 优先选能提供**“15天账期”**或**“分批付款”**的供应商（通常是大批发商）。哪怕单价贵一点，现金流安全才是长期稳定的前提。

**4. 冷链物流的“最后一公里”**
-   **忽视点：** 供应商说“有冷链”，但没核验他配送的**实际温度区间**（尤其是夏日）。
-   **后果：** 冷链断链的水果，表面看着光鲜，内部已经“发热”，到手后一两天就开始烂，无法上架。
-   **做法：** 要求查看配送车辆是否全程打冷（尤其夏季），或者提供温度记录仪数据。如果对方使用普通面包车常温运输，再便宜的货也不能要。

**5. 品种与规格的“稳定性”**
-   **忽视点：** 只订“大果”，没确认“单果克重”和“甜度批次”。
-   **后果：** 水果品质波动极大。同一家供应商，这周给你的是8两一个的麒麟瓜，下周可能就变成6两的，顾客复购率直接归零。
-   **做法：** 每次下单时，书面确认**“规格单”**（如：苹果80-85mm，单果≥300g），并要求对方发货时贴标签。稳定输出比偶尔惊艳重要。

**6. 应急替代方案的“备胎”**
-   **忽视点：** 只跟一家供应商深度合作，没有备选。
-   **后果：** 一旦这家供应商涨价、断货或关系恶化，你当天就会面临“无米下锅”。
-   **做法：** 长期合作1家主供（拿折扣），同时至少保留1家副供（拿保底）。副供不必天天进货，但必须保持联系，定期询价。

---

**最终建议（可立即执行）：**
在选定供应商前，**做一次“试单”**。不要一次性订大货，先订一周的小批量，重点观察：
1. 到货损耗率（低于5%为优）。
2. 售后响应速度（是否秒回，是否不推诿）。
3. 配送准点率。

**一句话总结：** 看价格是短期行为，看**损耗赔付机制、现金流账期、应急能力**才是长期生存的根本。
