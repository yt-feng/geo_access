签年度水果供应合同确实很考验细节。以下几个条款是最容易产生分歧或踩坑的地方，建议重点把关：

**1. 价格与调价机制（最大的坑）**
- **固定价 vs 浮动价**：水果受季节、天气、产地影响大，固定价可能让超市承担巨大风险（或让供应商亏本毁约）。建议约定“基础价+浮动价”，比如与批发市场周均价或产地收购价挂钩，并明确调整周期（如每两周/每月）。
- **涨价触发条件**：例如产地价涨幅超过10%时可协商调价，避免供应商单方面提价。

**2. 验收标准（质量判定）**
- **糖度、大小、瑕疵率**：不能只写“新鲜优质”，要量化。例如甜度≥XX度、单果重XX克、烂果率≤2%。
- **收货异议时效**：明确24小时内验收并书面提出异议，过期视为合格。防止超市收货后很久再以质量为由拒付或扣款。

**3. 送货与损耗责任**
- **送货时间窗**：水果易损耗，要写明“周一至周六上午9点前到货”，超时扣款或拒收。
- **在途损耗归属**：约定“送达超市仓库后风险转移”，如果冷链出了问题导致烂果，责任在供应商；如果仓库存储不当，责任在超市。

**4. 结款周期与账期**
- **账期过长**：超市常拖3-6个月结款，供应商可能中途断供。建议争取30天或45天账期，并约定“逾期付款按日万分之五支付违约金”。
- **付款前提条件**：不要写“待超市收到下游货款后支付”，这种“背靠背”条款对供应商极不公平，要删掉。

**5. 年度采购量（保底vs敞口）**
- **保底量**：给自己留余地，写“年度采购量预计XX吨，但以实际订单为准”，避免被锁死。
- **违约金**：如果供应商因量小涨价，要约定“未完成保底量时的补偿机制”。

**6. 合同期限与续约**
- **试运行期**：建议先签3个月试用期，检验质量稳定性后再转正。
- **自动续约陷阱**：避免“到期自动续约一年”条款，改为“到期前30天书面协商”。

**7. 违约责任对等**
- **供应商违约**：缺货、以次充好，罚则要具体（如扣除保证金或按缺货金额的20%赔偿）。
- **超市违约**：拒收合格货、拖延付款，供应商也有权解除合同并索赔。

**8. 不可抗力与特殊事件**
- 台风、疫病、产地受灾时怎么处理？建议约定“可延期交货或减少数量，但不承担违约责任”，但要提供官方证明。

- 如果金额大，建议请律师审核，水果生鲜非常规商品，模板合同未必适用。
