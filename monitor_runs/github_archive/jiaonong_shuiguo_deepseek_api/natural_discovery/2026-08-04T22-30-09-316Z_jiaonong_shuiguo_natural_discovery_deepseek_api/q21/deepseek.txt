在超市采购水果时，为确保食品安全和合规进货，供应商通常需要提供以下几类检测报告或进货证明。具体要求可能因地区法规、采购方（如超市）的内部标准以及水果种类（普通水果/进口水果/有机水果）而略有差异，但一般包括：

**1. 食用农产品合格证（或产地证明）**
这是最基本的进货凭证，证明水果来源合法、产地明确。通常由生产者或供货商出具，包含品种、数量、产地、联系方式等信息。

**2. 农药残留检测报告**
大多数超市要求供应商提供近期（如1-3个月内）的农药残留检测报告，须由具有资质的第三方检测机构（如SGS、华测、天祥等）出具，且检测结果须符合国家强制性标准（GB 2763《食品安全国家标准 食品中农药最大残留限量》）。

**3. 重金属及污染物检测报告**
对于土壤或水源可能受污染地区的水果，或特定高风险种类（如某些根茎类、叶菜类），可能需提供铅、镉、砷、汞等重金属或污染物检测报告。

**4. 进货查验记录/进货台账**
供应商应提供其向生产商或上一级供应商采购时的进货记录（含时间、品种、数量、上游供应商信息等），以形成完整的溯源链。

**5. 营业执照及许可证（供应商资质）**
如果是经销商或批发商，需提供其有效的营业执照；若是食品经营企业，可能还需提供《食品经营许可证》或相关备案证明。

**6. 进口水果的特殊证明（仅进口水果适用）**
- **入境货物检验检疫证明**（由海关出具）。
- **原产地证明**。
- **植物检疫证书**（出口国官方出具，证明无检疫性有害生物）。
- 提供进口报关单及缴税凭证等。

**7. 有机/绿色认证检测（仅认证水果适用）**
- 有机水果：需提供中国有机产品认证证书及认证检测报告。
- 绿色食品：需提供绿色食品标志使用证书及相应检测报告。

**8. 包装及标签合规信息**
- 产品标签/标识（品名、产地、采摘/包装日期、保质期、储存条件、种植者/供应商名称和联系方式等）。
- 若为预包装水果，需符合GB 7718《预包装食品标签通则》。
