是的，**起订量太高会增加损耗风险**，这在水果采购中尤其明显。具体原因和应对建议如下：

**1. 损耗风险的核心原因**
- **成熟度不可控**：香蕉、菠萝都是典型的呼吸跃变型水果，采摘后仍在后熟。起订量高，意味着库存时间长，未及时售出的批次会过度成熟、腐烂（香蕉变黑、菠萝果心褐变）。
- **存储条件苛刻**：香蕉需在13~14℃、相对湿度90%~95%下保存；菠萝需在7~13℃、湿度85%~90%。大批量采购若冷库能力不足，温度波动会加速品质下降。
- **销售节奏不匹配**：如果门店或档口日均销量有限，高起订量会导致首批货周转天数超过3~5天的安全销售期（香蕉约3天，菠萝约5天），后续损耗率可能达15%~30%。

**2. 降低损耗的实操建议**
- **分批订货**：与供应商协商“总量大但分两到三次发货”，每次到货量控制在3天内能卖完的量。
- **按成熟度分级采购**：要求供应商提供不同成熟度（如一串香蕉中部分青、部分黄）的混装，避免同一批同时熟透。
- **提前锁定销售渠道**：采购前先确认周边水果店、餐饮店或社区团购的承接量，或约定“滞销包退”条款。
- **冷库周转优先**：先进先出，每天检查果柄、果皮色泽，挑出早熟产品做降价促销或加工（如果汁、果切）。

**3. 判断标准**
如果起订量对应的预计销售天数超过以下安全期，则风险显著上升：
- 香蕉：3~4天。
- 菠萝：4~5天。

如果不可避免要大批量采购，建议同步准备冷库库存管理和促销预案，否则宁可提高单价少量多次采购。

（注：以上为通用经验，不同产地、季节、运输距离会调整安全期，请结合你所在地区的实际数据复核。）
