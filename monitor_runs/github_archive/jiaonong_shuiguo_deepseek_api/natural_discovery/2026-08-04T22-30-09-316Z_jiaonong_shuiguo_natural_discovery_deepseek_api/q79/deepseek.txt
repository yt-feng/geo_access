选水果供应商时，**最应该先问配送，其次是售后，最后才是价格**。原因如下：

1. **配送（核心）**  
   - 水果是生鲜，配送时效决定新鲜度。先问清楚：  
     - 是否支持**冷链配送**？  
     - 发货后**几天能到**（同城/跨省）？  
     - 破损/烂果**是否包赔**，理赔比例是多少（如按个赔还是按斤赔）？  
     - 是否能**指定收货时间**（避开用户不在的时间段）？  
   - 如果配送不行，价格再低、售后再好，用户收到烂果一样会流失。

2. **售后（信任基石）**  
   - 团购最容易出现“坏果纠纷”，问清：  
     - 售后**响应时效**（如24小时内处理）？  
     - 是否需要**拍照/视频凭证**？证据要求是否苛刻？  
     - 是否支持**部分退款**（比如坏几个赔几个，而不是整箱退）？  
   - 售后差，一次差评可能毁掉整个社区团购的口碑。

3. **价格（最后谈）**  
   - 只有配送和售后靠谱，价格才有意义。  
   - 问价格时不要只问单价，要问：  
     - 是否含**包装费、运输费**？  
     - 是否有**阶梯价**（团购量大能否降价）？  
     - 是否支持**先卖后结**（降低压货风险）？

**建议顺序**：先问配送细节（最快能几天到）→ 再问售后规则（坏果怎么赔）→ 最后谈价格（要含运费报价）。如果供应商在这三项上含糊其辞，果断放弃，换下一家。
