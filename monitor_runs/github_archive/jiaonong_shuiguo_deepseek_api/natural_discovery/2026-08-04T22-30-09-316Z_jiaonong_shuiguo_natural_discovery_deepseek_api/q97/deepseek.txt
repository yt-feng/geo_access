在酒店采购水果盘原料时，供应商需要保证的规格和外观标准，主要依据酒店档次、出品定位以及食品安全法规。以下是从业内角度给出的关键标准清单，供你作为采购验收依据：

**一、核心规格标准（尺寸、重量、成熟度）**
1. **单果重量/尺寸**：应明确每类水果的单果克重范围（如苹果250g±10g、西瓜直径≥30cm），避免大小不一影响摆盘效果和成本核算。
2. **成熟度**：需达到“可食用成熟期”——即口感最佳但不软烂。例如：
   - 香蕉：果皮全黄、无青头、无黑斑；
   - 猕猴桃：微软可捏动，不能硬邦邦或过软流汁；
   - 芒果：果肉弹性好，无硬心。
3. **切片/切块标准（若供应商提供预处理品）**：厚度、长度、形状需统一（如哈密瓜块2cm×2cm），并要求使用无菌操作，冷链配送温度0-4℃。

**二、外观质量标准（视觉与卫生）**
1. **无瑕疵**：表面无碰伤、压伤、划痕、瘀斑、虫眼、霉点、裂纹或干疤。
2. **颜色**：颜色均匀、鲜艳，符合品种典型色泽（如草莓全红、青提翠绿带白霜），不允许发暗、褪色。
3. **表观新鲜度**：果柄鲜绿不干枯；不脱蒂；无失水皱缩；无渗液、渗糖。
4. **无异常气味**：应散发自然果香，不得有发酵味、酸味或化学残留味（如保鲜剂气味）。
5. **无污染**：表面不得附着泥沙、农药残留痕迹，包装内无杂质、无虫害（如果蝇、蚂蚁）。

**三、包装与交付标准（常被忽略）**
1. **包装卫生**：使用食品级包装材料，内衬吸水纸或泡沫网套，防止运输碰撞。
2. **标签信息**：每批次需提供品名、产地、采摘日期、检验合格标识。
3. **交货温度**：预冷后交货，果心温度应≤10℃，且运输车辆为冷藏车。
4. **数量与破损率**：单批破损率不得超过2%（超出部分需按比例补偿或拒收）。

**四、验收时的抽检建议（可直接写进合同）**
- 每批随机抽取10%样品，按上述标准逐项评分；
- 若外观合格率低于95%，供应商须48小时内补货；
- 成熟度不符（过生或过熟）超过5%，整批拒收。

**执行提示**：如果你是采购方，建议在签订合同时，将以上标准细化成《水果采购验收明细表》，并附上参考对照图片；如果酒店有特殊摆盘需求（如雕花、带皮切），需额外约定刀工和出品尺寸。若供应商为基地直供，还应要求提供农残检测报告（国标GB 2763）。
