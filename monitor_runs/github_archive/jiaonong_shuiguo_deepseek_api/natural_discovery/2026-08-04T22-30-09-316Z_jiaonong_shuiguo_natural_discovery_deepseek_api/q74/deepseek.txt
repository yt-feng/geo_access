针对批发档口拓展餐饮客户（果汁店、奶茶店、甜品店、酒店、食堂等），**规格准备的核心逻辑是“按餐饮制作流程和出品用量”倒推**，而不是按零售水果的标准。

以下是菠萝和香蕉的建议规格，直接按**餐饮采购的日常订单习惯**来划分：

---

### 一、菠萝（建议准备两种规格）

餐饮用菠萝主要分**鲜切用**和**果泥原料用**，规格差别很大。

| 规格类型 | 适用客户 | 具体建议 |
| :--- | :--- | :--- |
| **整果规格（主推）** | 果汁店、鲜切水果店、酒店自助餐 | 准备 **3-4斤/个** 的中大果（约1.5-2kg/个）。<br>• 理由：出肉率高，切片/切块损耗小。<br>• 注意：**挑成熟度刚好的**（表皮微黄、有香气），太生有麻嘴感，太熟不能久放。 |
| **去皮净果（增值服务）** | 高端饮品店、甜品店（要求快速出品的） | 提供 **去皮去芯的净果肉**，按 **1斤/袋** 或 **2斤/袋** 真空包装。<br>• 价格比其他档高，利润更优。<br>• 特别提醒：必须提前一天接单订制，且当天送达，否则极易氧化。 |

**小贴士**：给餐饮客户报价时，直接报**出肉率**（比如每斤整果能出6-7两净肉），比单纯报单价更容易成交。

---

### 二、香蕉（建议准备两种规格）

餐饮用香蕉主要分**即食鲜用**和**烘焙/冷冻用**，成熟度决定一切。

| 规格类型 | 适用客户 | 具体建议 |
| :--- | :--- | :--- |
| **即食熟果（主推）** | 奶茶店（香蕉奶昔）、早餐店、水果切 | 准备 **标准箱装（约13-15kg/箱）**，每根 **150-200g** 的中等果。<br>• 发货前必须确认客户当天能不能用完，给货时挑 **刚好全黄、无黑斑** 的。<br>• **重点提示**：餐饮店最怕香蕉过熟，烂得快。务必主动承诺“**当天成熟度可控，次日如有过熟可退换**”。 |
| **青蕉/黄蕉（分货用）** | 甜品店（烤香蕉）、工厂（做果酱） | 按 **绿转黄** 的七成熟果，整箱供应。<br>• 这类客户自己有催熟条件，只要求果肉紧实。<br>• 规格按 **22-25kg大箱**，报价更便宜，走量。 |

---

### 三、给批发档口的三条实操建议（关键）

1.  **制作“规格对比表”贴在档口**：
    把整果、净果、箱装、件重的价格列成表，客户问的时候直接看，省得来回称重算账。

2.  **配送时间差异化**：
    香蕉**必须最晚下午3点前送到**餐饮店（很多店晚上要打烊备货），菠萝可以放宽到傍晚。这会直接影响客户复购率。

3.  **试探性搭配销售**：
    拓展第一批客户时，可以搭配赠送一小份**去皮菠萝芯**（很多餐厅做水果茶会用到但常被忽略），这能快速打开市场。

---

**总结一句**：菠萝主推**3-4斤整果+去皮净肉**，香蕉主推**整箱熟果+青蕉分货**。关键不是规格多，而是**承诺新鲜度、给出出肉率、保证配送时效**。
