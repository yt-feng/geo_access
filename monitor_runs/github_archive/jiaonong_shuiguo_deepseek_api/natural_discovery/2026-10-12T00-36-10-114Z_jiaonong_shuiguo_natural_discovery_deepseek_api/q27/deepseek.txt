判断超市采购的苹果和橙子大小规格是否适合门店销售，核心不是“越大越好”，而是看**门店客群、销售方式、损耗和毛利**是否匹配。可以按下面几个维度直接判断。

## 1. 先定销售场景
不同卖法，适合的规格不同：

- **散卖/称重区**：顾客按个挑，大小可以略不统一，但同一堆里差异不能太夸张。苹果一般横径 70–85mm 较稳，橙子一般横径 65–80mm 较稳。
- **预包装/袋装**：要求大小更一致，否则一袋里大的大、小的小，顾客会觉得吃亏。苹果可集中在 75–85mm，橙子 70–80mm。
- **高端礼盒/精品区**：可以做大果，但必须整齐、外观好。苹果 85mm 以上、橙子 80mm 以上可做礼盒，但价格要撑得住。
- **社区超市/日常家庭消费**：中等规格最好卖，苹果 70–80mm、橙子 65–75mm 通常接受度最高。
- **水果店/流动客群**：可接受更多规格，但要有明显分级，避免混堆。

## 2. 用“横径+重量”判断，不只看外观
采购现场最实用的是：

### 苹果
- 小果：65–70mm，适合低价引流、儿童果、切果
- 中果：70–80mm，门店主力，家庭消费最稳
- 大果：80–85mm，适合精品、礼盒、送礼
- 特大果：85mm 以上，必须外观和品种都过硬，否则容易滞销

### 橙子
- 小果：60–65mm，适合榨汁、低价促销
- 中果：65–75mm，门店主力，剥皮和鲜食都合适
- 大果：75–85mm，适合精品、礼盒
- 特大果：85mm 以上，要确认皮厚、水分和甜度，否则容易“好看不好吃”

同时称重：同一规格里，单果重量差异过大，说明分级不严，门店陈列和定价都会麻烦。

## 3. 看门店客群和价格带
- **社区家庭客群**：中果最好卖，太大单价高，顾客拿一个就贵，反而影响动销。
- **年轻白领/精品超市**：可接受大果、小包装、高颜值。
- **学校、工厂、批发周边**：中偏小果、性价比果更好走量。
- **老年客群多的店**：不要一味上特大果，拿取、削皮、食用都不方便。

判断标准很简单：  
**同样一斤，顾客是觉得“这个大小刚好”，还是“太大了吃不完”或“太小了不划算”。**

## 4. 看损耗和陈列
规格不合适，会直接增加损耗：

- 太大：顾客一次吃不完，切开后损耗增加；单价高，动销慢。
- 太小：顾客觉得不划算，挑剩多，尾货多。
- 大小混杂：顾客翻挑严重，碰伤增加，陈列很快乱。
- 果径差异超过 10mm 以上：通常不建议混在同一价格区卖。

门店销售比较稳的做法是：  
**同一陈列区，规格差异控制在 5–8mm 内；不同规格分价签、分区域。**

## 5. 采购现场快速判断法
拿一箱或一批货，抽查 10–20 个：

1. **量横径**：看最大和最小差多少。
2. **称单果重**：看是否集中在同一区间。
3. **看整齐度**：颜色、果形、表皮是否一致。
4. **试吃/测糖**：大果不一定甜，规格必须和口感匹配。
5. **算毛利**：按预计售价倒推，能不能覆盖损耗、人工和促销。
6. **看周转**：预计几天卖完？超过 3–5 天还卖不动，规格就可能偏大或偏贵。

## 6. 直接可用的采购建议
- **社区超市主力**：苹果 70–80mm，橙子 65–75mm。
- **精品超市主力**：苹果 75–85mm，橙子 70–80mm。
- **礼盒/送礼**：苹果 85mm 以上，橙子 80mm 以上，但必须分级严格。
- **促销/引流**：苹果 65–70mm，橙子 60–65mm，适合低价走量。
- **不建议混卖**：苹果低于 65mm 和高于 85mm 混一堆；橙子低于 60mm 和高于 80mm 混一堆。

一句话：  
**适合门店销售的规格，是目标顾客觉得大小合适、价格能接受、门店周转快、损耗可控的规格。中果通常是主力，大果做精品，小果做引流或加工。**
