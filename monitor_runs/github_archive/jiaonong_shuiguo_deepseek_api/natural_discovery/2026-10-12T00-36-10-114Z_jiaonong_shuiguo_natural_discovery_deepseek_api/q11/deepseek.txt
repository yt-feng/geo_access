会有影响，但关键不是“大小不一样”本身，而是**大小差异是否明显、是否影响卖相和定价**。

直接给你判断标准：

1. **轻微大小不一：影响不大**
   - 同一箱里只是略大略小，颜色、成熟度、果形差不多，通常不影响销售。
   - 水果店可以按统货卖，或者挑一下分级卖。

2. **大小差异明显：会影响销售**
   - 顾客挑香蕉时通常偏好大小均匀、颜色一致、无斑无伤的。
   - 大小混在一起，容易出现：
     - 顾客翻拣，损耗增加；
     - 大果被挑走，小果剩下一堆；
     - 不好统一定价，按大果价卖小果顾客不买账；
     - 礼盒、团购、单位采购更介意均匀度。

3. **真正影响销售的核心因素**
   - 成熟度是否一致：有的青、有的黄、有的已经起黑点，这个比大小更致命。
   - 是否有机械伤、压伤、裂口、掉把。
   - 果形是否正常，太弯、太细、太短会影响观感。
   - 箱内上下层是否一致，避免“上面大下面小”。

4. **采购建议**
   - 如果做**零售散卖**：轻微大小不一可以接受，但成熟度要尽量一致，价格按统货谈。
   - 如果做**礼盒、团购、高端陈列**：必须要求大小均匀，最好明确规格，比如每根多少克、每箱多少根。
   - 如果已经采购了混装货：
     - 先分级：大果、中果、小果分开；
     - 大果正常价或做精品；
     - 中果做主推；
     - 小果降价、做促销、榨汁或做香蕉奶昔原料。
   - 采购时直接问供货商：**“这箱是统货还是分级货？上下层大小差多少？成熟度几成？”**

5. **简单结论**
   - 自己散卖：轻微大小不一，不太影响。
   - 想卖得好、卖价高：大小均匀更有利。
   - 如果大小差很多，又混着卖，会影响顾客体验和损耗，建议要么压价采购，要么要求分级。
