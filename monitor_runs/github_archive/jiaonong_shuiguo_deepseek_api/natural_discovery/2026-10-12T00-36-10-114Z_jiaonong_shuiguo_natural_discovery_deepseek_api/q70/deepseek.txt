批发商要防的是“到货后损耗高、坏果责任说不清”，合同重点不是写一句“坏果由谁负责”，而是把**验收时间、验收标准、责任分界、扣款/拒收/补货机制、证据留存**写清楚。可以按下面结构写。

**一、先明确责任分界点**
建议写：
“货物毁损、变质、腐烂、坏果风险，在货物运至买方指定收货地点并由买方完成初步验收前，由卖方承担；初步验收合格后，因买方储存、保管、销售不及时造成的损耗，由买方承担。”
如果是由批发商自己安排运输，则要区分：
“运输由买方安排的，运输途中非因货物自身质量原因造成的损耗，由买方承担；但因卖方包装不符、采摘成熟度不合格、预冷不足等造成的坏果，仍由卖方承担。”

**二、约定验收期限和方式**
不要写“验收合格后概不负责”这种太粗的条款。建议：
“买方应在货物到达收货地点后____小时内完成初步验收。逾期未验收且未提出异议的，视为初步验收合格，但不免除卖方对隐蔽质量问题的责任。”
“验收方式：双方共同拆箱/抽检，按每车/每批随机抽取____%或____箱。发现坏果的，应当场拍照、录像，记录车牌、批次、时间、地点，并由双方签字确认。”

**三、写清坏果判定标准**
越具体越好，例如：
“坏果包括：霉变、腐烂、软烂、裂口流汁、异味、严重压伤、冻伤、虫蛀等影响正常销售的情形。”
“下列情形不计入坏果：轻微擦伤、自然色差、大小差异、成熟度差异但不影响销售的情形。”
“坏果率按重量或件数计算：坏果率=坏果重量/该批货物总重量×100%。”

**四、约定责任比例和处置方式**
可以设阶梯：
1. 坏果率≤____%：买方自行承担，卖方不赔。
2. 坏果率____%—____%：卖方按超出部分对应货值补偿，或按____元/箱扣款。
3. 坏果率≥____%：买方有权拒收该批货物，卖方应在____小时内补货或退款，并承担来回运费。
4. 因卖方原因导致整车/整批无法销售的，卖方应退还全部货款，并赔偿买方实际发生的合理运费、装卸费。
注意：赔偿范围要写“实际损失”或“合理费用”，不要写过高惩罚性条款，否则可能被调整。

**五、写清通知和证据义务**
“买方发现坏果后，应在____小时内书面通知卖方，并附照片、视频、抽检记录、过磅单。未在约定时间内通知，且无正当理由的，视为货物验收合格。”
“双方对坏果原因有争议的，可共同委托第三方检测机构检测，检测费用由责任方承担；无法确定责任方的，由双方各承担一半。”

**六、写清例外和免责**
“因不可抗力、买方指定运输方式或承运人、买方要求延迟卸货、买方储存温度/湿度不当造成的坏果，卖方不承担责任。”
“货物本身为生鲜易腐品，买方应在到货后及时卸货、预冷、入仓，因买方延误造成的扩大损失，由买方承担。”

**七、可直接用的条款示例**
“1. 卖方交付的货物应符合约定质量标准，坏果率不得超过____%。  
2. 买方应在到货后____小时内完成抽检，抽检比例为____%。坏果率以抽检结果按比例推算全批。  
3. 坏果率在____%以内的，买方承担；超过____%的，卖方按超出部分货值的____%补偿，或按____元/箱扣款。  
4. 坏果率超过____%的，买方有权拒收，卖方应在____小时内补货或退款，并承担因此产生的合理运费。  
5. 买方应在发现坏果后____小时内通知卖方并提供照片、视频及抽检记录。逾期未通知的，视为验收合格。  
6. 因买方储存、保管、延迟卸货或运输安排不当造成的坏果，卖方不承担责任。”

**关键提醒：**
- 不要只写“坏果包赔”，要写“坏果率多少、怎么算、谁检、多久提异议、怎么赔”。
- 最好约定“抽检比例”和“按抽检结果推算全批”，否则到货后一箱一箱验，成本很高。
- 如果卖方强势，至少争取“超过约定坏果率部分才赔”和“验收期限”，避免对方把正常损耗也算到你头上。
- 生鲜类合同，证据比条款更重要：到货拍照、录像、过磅、司机签字、及时书面通知，缺一样都可能影响索赔。
