茶饮店控制食品安全风险，向水果供应商索取证明时，建议按“资质合规 + 批次可追溯 + 检验合格 + 储运温控”四类来要，具体如下：

1. 主体资质类
- 营业执照
- 食品经营许可证或食品生产许可证（如供应商属于食品经营者/生产者）
- 若为进口水果：入境货物检验检疫证明、海关报关单等
- 若为委托加工或分装：对应受托方资质及委托协议

2. 产品合格与检验类
- 每批次产品的出厂检验报告或合格证明
- 第三方检测报告（重点看农残、重金属、致病菌等，按水果类别和风险定）
- 供货凭证：送货单/销售单，注明品名、规格、数量、生产日期或采摘日期、批号
- 承诺书/质量保证协议：明确农残、霉变、异物、非法添加等责任

3. 追溯与记录类
- 批次追溯信息：产地、加工/包装日期、批次号
- 供应商上游来源证明：基地证明、收购记录、合作社或种植户信息
- 若为冷链水果：运输温度记录、到货温度记录

4. 储运与验收类
- 冷链运输温度记录（如需要）
- 到货验收记录：外观、气味、成熟度、腐烂率、温度
- 不合格处理记录：退货、销毁、换货凭证

实操上，茶饮店可以这样做：
- 首次合作：先收齐资质，签质量保证协议，做供应商审核。
- 每次到货：至少收“送货单 + 该批次合格证明/检测报告”，并做验收记录。
- 高风险水果（如即食、鲜切、易霉变）：提高检测频次，要求农残和微生物项目。
- 进口水果：重点查检验检疫证明和中文标签。
- 鲜切水果：额外要求供应商提供洁净加工、人员健康、消毒记录等证明或审核结果。

如果供应商只能提供部分证明，至少要保证：营业执照、食品经营/生产许可、批次送货凭证、批次合格证明或检测报告、冷链温度记录（如适用）。这些是茶饮店日常监管和出问题时追溯的底线材料。
