大型超市对水果供应商的要求，通常集中在“食品安全合规能力”和“冷链物流履约能力”两条主线上。下面按可执行、可核验的维度拆开说。

## 一、食品安全能力

### 1. 主体资质与合规文件
- **营业执照、食品经营许可证/食品生产许可证**（按实际经营性质）
- **种植/养殖基地备案或合作基地证明**：超市通常要求基地可追溯，不接受来源不明的散收果
- **产品合格证明**：如产地证明、检测报告、检疫合格证（涉及进口水果时还需入境货物检验检疫证明）
- **进口水果**：海关报关单、入境货物检验检疫证明、中文标签

### 2. 农残与污染物控制
- **农残检测能力**：自有快检室或长期合作第三方检测机构
- **检测项目**：有机磷、氨基甲酸酯、拟除虫菊酯等常见农残；重金属（铅、镉、砷、汞）；真菌毒素（如展青霉素）
- **检测频次**：至少按批次或按品种周期检测，能提供近期的第三方检测报告
- **不合格处置流程**：隔离、召回、溯源、整改记录

### 3. 追溯体系
- **批次管理**：从基地/采购批次到门店销售可追溯
- **追溯信息**：品种、产地、采摘日期、检测结果、物流温度记录
- **信息化能力**：ERP/WMS系统或至少可提供电子台账，能配合超市做溯源查询

### 4. 仓储与加工卫生
- **分拣包装环境**：清洁、防虫防鼠、通风、温湿度可控
- **人员卫生**：健康证、工服、手套、口罩、洗手消毒
- **工具与容器**：食品级、定期清洗消毒
- **交叉污染控制**：生熟分离、不同品类分区

### 5. 认证与体系（加分项，大型超市常要求或优先）
- **ISO 22000 / HACCP**：食品安全管理体系
- **GAP（良好农业规范）**：基地端
- **有机认证、绿色食品认证**：对应品类
- **BRCGS / IFS**：出口或高端商超常见

## 二、物流与冷链能力

### 1. 冷链设施
- **预冷能力**：采摘后快速预冷，降低呼吸热
- **冷藏车/冷藏库**：不同水果温区不同，如：
  - 香蕉：13–15℃
  - 苹果/梨：0–4℃
  - 柑橘：4–8℃
  - 浆果：0–2℃
- **温控记录**：全程温度记录仪，可导出数据供超市核查
- **冷库分区**：按温区、品类分开，避免乙烯敏感水果与释放乙烯水果混放

### 2. 运输与配送
- **自有或稳定合作车队**：能保证准时率
- **配送频次**：根据超市门店销量，通常日配或隔日配
- **装卸要求**：防挤压、防日晒雨淋、周转筐标准化
- **在途监控**：GPS+温度监控，异常可预警

### 3. 库存与订单履约
- **订单响应**：能对接超市采购系统（EDI/API或邮件订单）
- **缺货率控制**：大型超市通常要求低于2%–5%
- **损耗控制**：水果损耗率通常要求控制在5%–10%以内（视品类）
- **退货与换货**：质量问题可快速补货或退换

### 4. 包装与标识
- **包装材料**：食品级、透气、防压
- **标签信息**：品名、产地、等级、净重、采摘/包装日期、保质期、供应商信息
- **超市要求的条码/标签**：如门店码、物流码、追溯码

## 三、大型超市通常还会看这些“软能力”

- **供应稳定性**：能否全年或按季节稳定供货
- **价格与账期承受力**：大型超市账期通常30–90天，供应商需有资金周转能力
- **食品安全事故应急预案**：召回流程、媒体应对、责任划分
- **保险**：产品责任险、货物运输险
- **合规审计配合**：能接受超市或第三方验厂、验仓

## 四、如果要做准入准备，优先补齐这几项

1. **证照齐全**：营业执照、食品经营/生产许可、进口资质（如涉及）
2. **检测报告**：近3–6个月第三方农残和重金属检测
3. **冷链证明**：冷藏车、冷库、温度记录
4. **追溯台账**：批次可查、电子化优先
5. **体系认证**：ISO 22000或HACCP，至少有一套可执行的食品安全制度
6. **履约数据**：准时率、缺货率、损耗率、退货率

简单判断：**没有冷链和批次追溯，基本进不了大型超市；没有检测报告和合规证照，连准入审核都过不了。**
