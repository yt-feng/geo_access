很重要，但要分情况看：它不是所有便利店的“生死线”，却是降低水果损耗和试错成本的关键能力。

**为什么重要：**
- 水果保质期短、损耗高，一旦试卖失败，损失比标品大得多。
- 小批量试卖能验证“这个单品在你店的位置、客群、时段”到底卖不卖得动。
- 试卖成功再放量，能减少压货、退货、降价处理。
- 对销量不稳定的店，供应商是否支持小批量、多频次、可退换，直接决定你敢不敢上新品。

**但也要注意：**
- 小批量往往意味着进货价更高、配送频率受限，供应商不一定愿意。
- 如果供应商只支持小批量但不稳定供货，意义不大。
- 真正有价值的是：小批量 + 稳定品质 + 可快速补货 + 损耗可分担。

**判断供应商是否值得合作，可以看这几点：**
1. 是否支持首单小批量试卖。
2. 试卖后补货周期多长，能否 24-48 小时补货。
3. 卖不动能否调换、退货或给损耗补贴。
4. 同品质下，小批量价格是否可接受。
5. 是否愿意按门店销售数据调整供货，而不是硬塞货。

**结论：**
对水果销量不稳定的便利店，供应商支持小批量试卖很重要，尤其是上新和季节品。但更关键的是“小批量试卖 + 快速补货 + 损耗分担”这套组合。只有小批量、没有补货和售后支持，价值会大打折扣。
