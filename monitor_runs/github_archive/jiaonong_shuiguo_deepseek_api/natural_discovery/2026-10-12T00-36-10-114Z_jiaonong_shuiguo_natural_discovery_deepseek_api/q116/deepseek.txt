# 小商家采购水果：现金结算 vs 月结账期的风险对比

## 一、现金结算的风险

**1. 资金占用压力**
- 每次采购都要即时掏钱，现金流紧张时可能错过大宗低价机会（如整批尾货、季节性低价）。
- 旺季备货需要大量现金，容易导致周转困难。

**2. 质量与数量纠纷难追溯**
- 钱货两清后，若发现短斤少两、以次充好，追偿难度大，缺乏账期作为"制衡杠杆"。
- 尤其是生鲜，验货当场不仔细，事后基本无法维权。

**3. 无法积累信用账期**
- 长期现金结算，未来想谈账期时议价筹码不足。

**4. 大额现金的保管与安全**
- 携带现金或频繁大额取现存在安全风险，也不便于留痕（税务、对账证据）。

**现金结算的主要优势**：价格通常更低（供应商愿意给现金折扣）、无负债、不被追款。


## 二、月结账期的风险

**1. 供应商违约/断供风险**
- 账期内若供应商跑路、涨价或优先供给其他客户，你的货可能被卡。
- 账期本质是"赊账"，供应商一旦收紧，你立刻断货。

**2. 隐性成本转嫁**
- 月结单价往往比现金价高，等于变相利息。
- 部分供应商会以"账期"为由压低品质或搭售滞销品。

**3. 容易过度采购、负债累积**
- 账期让人"感觉钱没花"，容易超量进货，生鲜损耗后仍要还钱。
- 一旦经营波动（如淡季、损耗大），欠款滚雪球，被追债甚至走法律程序。

**4. 对账与纠纷复杂**
- 多批次、多品类、损耗退货混在一起，月底对账极易扯皮。
- 口头约定的账期若无书面凭证，法律上举证困难。

**5. 依赖单一供应商**
- 账期绑定了你和某家供应商，切换到现金价更优的渠道时会有欠款牵制。

**月结的主要优势**：缓解短期现金流、用货款做周转、对质量有"扣款制衡"空间。


## 三、实操建议（按场景选）

| 场景 | 建议 |
|------|------|
| 初创、现金流紧 | 优先现金，但要谈现金折扣（3%~5%） |
| 稳定且信誉好的供应商 | 可用月结，但**签书面协议**写明账期、验货、退货、扣款规则 |
| 生鲜损耗大的品类 | 月结更有利（有扣款空间），但单价别被抬太高 |
| 大额备货 | 尽量"部分现金+部分账期"组合，降低单方风险 |

**核心原则**：
1. 无论哪种，都要**留痕**（收据、对账单、聊天记录），别只靠口头。
2. 账期不要集中在一家，**保持2~3家供应商比价**，保留切换能力。
3. 现金结算要主动谈折扣，账期结算要主动核单价溢价，算清楚"账期到底值不值"。
