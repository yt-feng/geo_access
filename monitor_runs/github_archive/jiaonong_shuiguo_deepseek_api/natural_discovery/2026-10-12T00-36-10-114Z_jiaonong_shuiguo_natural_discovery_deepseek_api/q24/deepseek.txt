建议优先索取这几类资料，按“能证明批次合规”来要，而不是只要一张营业执照：

1. **批次检测报告**
   - 要“农残检测报告”，最好与本次到货批次号、生产日期/采摘日期对应。
   - 重点看检测项目是否覆盖常见农残，如有机磷、氨基甲酸酯、拟除虫菊酯等；报告应由有资质机构出具，如CMA/CNAS。
   - 如果供应商只有年度报告，要求补充“本批次”报告或承诺到货后送检。

2. **产地证明/供货证明**
   - 产地证明、基地证明、合作社或种植户供货证明。
   - 用于确认货源真实，出了问题可追溯。

3. **承诺书/质量保证协议**
   - 供应商承诺所供水果符合GB 2763《食品安全国家标准 食品中农药最大残留限量》。
   - 明确若抽检不合格，供应商承担退货、赔偿、检测费及监管处罚相关责任。

4. **农药使用记录或基地管理资料**
   - 如供应商是基地直供，可要求提供用药记录、安全间隔期执行记录。
   - 小供应商可能没有，但至少要有质量承诺和批次检测。

5. **资质文件**
   - 营业执照、食品经营许可证/食品生产许可证等。
   - 若是进口水果，还要入境货物检验检疫证明、海关报关资料。

6. **追溯信息**
   - 批次号、采摘/包装日期、产地、供应商联系人。
   - 方便超市自己留样、登记和后续抽检追溯。

实操建议：
- 采购合同里写明：**每批次随货提供检测报告或合格证明；超市有权抽检；不合格全责由供应商承担。**
- 到货后超市自己做快检或送检，尤其是叶菜、草莓、葡萄、豇豆等高风险品类。
- 保留进货台账、检测报告、承诺书，至少保存到保质期满后6个月；没有明确保质期的，保存不少于2年。

如果供应商只能提供“营业执照”和口头保证，风险较高，不建议直接采购。
