食堂采购香蕉要减少“熟过头”的浪费，核心是：**控制采购成熟度 + 分批到货 + 按成熟度分流使用**。

可以从下面几个环节做：

1. **采购时不要只按数量，要按成熟度下单**
   - 优先选**青黄交接、七八成熟**的香蕉，不要一次收太多已经全黄、带黑点的。
   - 和供应商约定到货成熟度，比如“表皮青黄、无大面积黑斑、硬度适中”。
   - 如果供应商只能给较熟香蕉，就减少单次采购量，增加采购频次。

2. **分批到货，不要一次囤太多**
   - 香蕉后熟很快，食堂最好按**2—3天用量**分批到货。
   - 如果每天用量稳定，可以每天或隔天送一次，而不是一周送一次。
   - 遇到周末、假期前，提前减量。

3. **储存时区分成熟度**
   - 未熟或偏青香蕉：常温、通风、避光存放，不要马上进冷库。
   - 已黄熟香蕉：可放阴凉通风处，尽快使用；若需延缓，可适当降低温度，但香蕉怕冻，不宜过低。
   - 不要和苹果、梨等释放乙烯较多的水果混放，会加速香蕉成熟。
   - 发现个别开始变软、出黑点，及时挑出，避免影响整批。

4. **按成熟度分流使用**
   - 刚好的香蕉：直接作为餐后水果。
   - 偏熟的香蕉：用于制作香蕉奶昔、香蕉粥、香蕉饼、烘焙、水果沙拉等。
   - 很熟但未坏的香蕉：可加工成香蕉泥、冷冻保存，用于后续甜品或面点。
   - 已腐烂变质的：坚决丢弃，不能加工使用。

5. **建立简单台账和预警**
   - 记录每天到货量、成熟度、消耗量、剩余量。
   - 对“预计1—2天内会过熟”的香蕉提前贴标或单独存放，优先安排窗口消耗。
   - 根据前几周数据调整采购量，避免固定不变。

6. **和菜单、活动联动**
   - 如果当天有香蕉相关菜品、甜品或加餐，就多安排消耗。
   - 如果连续几天水果种类多，香蕉采购量要下调。
   - 大型活动、考试加餐等可提前规划，把偏熟香蕉纳入加工菜单。

7. **和供应商约定退换或调整机制**
   - 合同中可约定：到货成熟度过高、黑斑严重、压伤多的，可拒收或换货。
   - 对长期供应商，要求其按食堂消耗节奏分批配送。

简单说就是：**少采多次、控制成熟度、分类存放、快熟快用、偏熟加工、腐烂丢弃。**  
最有效的做法通常是：**采购七八成熟香蕉 + 每2—3天分批到货 + 每天检查并按成熟度分流。**
