适合家庭的团购水果礼盒，关键不是“看起来多高级”，而是**分量适中、耐放、老少都能吃、剥切方便**。按这个标准，苹果、橙子、香蕉、菠萝里，最推荐这两种组合：

**首选：苹果 + 橙子 + 香蕉**
- 适合大多数家庭，尤其是有老人小孩的。
- 苹果、橙子耐放，香蕉当天到货后尽快吃。
- 吃法简单：苹果洗了啃，橙子剥皮，香蕉直接吃。
- 建议比例：苹果 4、橙子 4、香蕉 2。比如 10 个装：4 苹果 + 4 橙子 + 2 香蕉。
- 团购卖点：日常水果包，早餐、加餐、带公司都方便。

**次选：苹果 + 橙子 + 菠萝**
- 适合喜欢切果盘、做沙拉、榨汁的家庭。
- 菠萝存在感强，礼盒显得更丰富，但需要削皮处理，不是所有家庭都愿意动手。
- 建议比例：苹果 4、橙子 4、菠萝 1。比如 9 个装：4 苹果 + 4 橙子 + 1 菠萝。
- 注意：菠萝要选小果，否则整个礼盒太重，家庭一次也吃不完。

**不太建议主推：四种全放**
- 看起来丰富，但家庭实际体验容易出问题：
  - 香蕉和菠萝都怕压，运输中容易碰伤。
  - 菠萝需要削，香蕉熟得快，家庭消耗节奏不一致。
  - 总重量偏大，团购价容易上去，但性价比感反而下降。

**如果一定要四种都放，建议做“小份混合装”**
- 苹果 2、橙子 2、香蕉 2、菠萝 1 个小果。
- 定位不是囤货，而是“尝鲜果篮”。
- 适合 3 口之家，2～3 天吃完。

**团购页面可以这样写：**
- 家庭日常款：苹果 + 橙子 + 香蕉，耐放好剥，早餐加餐都合适。
- 果盘分享款：苹果 + 橙子 + 菠萝，适合切盘、榨汁、周末聚餐。
- 尝鲜混合款：四种小份组合，适合小家庭试吃。

**采购和打包建议：**
- 香蕉不要和苹果、橙子紧挨着放，苹果会催熟香蕉。
- 菠萝单独套袋，避免扎伤其他水果。
- 苹果、橙子选中等果，不要盲目追求大果，家庭礼盒更看重数量和搭配。
- 如果团购要控成本，优先保证苹果、橙子品质，香蕉和菠萝作为搭配点缀。

总结：**家庭团购最稳的是“苹果 + 橙子 + 香蕉”，想显丰富就做“苹果 + 橙子 + 菠萝”，四种全上只适合做小份尝鲜装。**
