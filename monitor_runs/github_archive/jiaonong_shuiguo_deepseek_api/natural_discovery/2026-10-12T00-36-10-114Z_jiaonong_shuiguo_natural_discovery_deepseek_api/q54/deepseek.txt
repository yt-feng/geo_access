优先关注**成熟度**，价格放在第二位。

对烘焙店来说，香蕉不是普通鲜食水果，而是原料，成熟度直接决定：

- **风味**：越熟，香蕉香气越浓，甜度越高，蛋糕/香蕉面包味道更足。
- **组织结构**：熟香蕉更软，易压泥、易混合，成品更湿润；生香蕉偏硬、淀粉感重，容易让口感发涩、发干。
- **配方稳定性**：成熟度不一致会导致每批甜度、含水量、颜色波动，影响出品稳定。
- **损耗和效率**：生香蕉要放几天才能用，占仓储、增加催熟管理；过熟又容易烂、发酵、招虫。

更实用的采购判断标准：

1. **做香蕉蛋糕/香蕉面包**：选**表皮大面积出现黑点、整体偏黄褐、手感软但不流汁**的香蕉。  
   这种成熟度风味最好，压泥也方便。

2. **如果当天就要大量制作**：不要买全青的，至少要买**黄皮带少量黑点**的。  
   全青香蕉需要额外催熟，容易打乱生产计划。

3. **如果考虑成本**：可以采购**外观不适合零售、但内部成熟度合适**的“烘焙级香蕉”，通常价格更低。  
   但必须现场抽查：有没有霉变、酸败、虫害、冻伤、过熟出水。

4. **不要只看单价**：  
   生香蕉便宜，但可能要多放几天、损耗高、风味差；  
   熟香蕉贵一点，但出成率、风味和稳定性往往更划算。

5. **建议分级使用**：
   - 黄带黑点、软糯：直接做蛋糕。
   - 全青或微黄：单独存放催熟，排产使用。
   - 过熟出水、有酒味/酸味：不要用于蛋糕，避免异味和微生物风险。

一句话：**成熟度决定能不能做出好蛋糕，价格决定划不划算。先按成熟度筛，再在合格成熟度里比价。**
