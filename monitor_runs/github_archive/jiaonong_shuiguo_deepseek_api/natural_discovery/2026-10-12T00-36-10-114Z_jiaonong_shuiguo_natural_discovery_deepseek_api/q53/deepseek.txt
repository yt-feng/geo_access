餐饮店每天少量用水果，核心不是找“最便宜的大供应商”，而是找**能稳定、小批量、按时送到、损耗少、结账简单**的渠道。按省心程度，可以这样选：

1. **本地农贸批发市场固定摊位**
   - 适合：每天用量不大、能早起或有人顺路采购。
   - 优点：价格灵活，可以现场挑货，少量也卖。
   - 缺点：要自己跑，品质看当天行情，早市时间紧。
   - 省心做法：固定找1-2家摊位，提前微信下单，让老板按你的标准留货，你只负责取货或让他同城跑腿送。

2. **同城生鲜配送平台/本地水果配送商**
   - 适合：想要每天送、少量起送、线上对账。
   - 优点：下单方便，配送稳定，有售后。
   - 缺点：单价比批发市场略高，起送门槛要看商家。
   - 省心做法：优先选支持“每日订、次日送/当日送”的本地商家，谈好固定品类、规格、到货时间、坏果赔付。

3. **周边水果店/社区精品水果店**
   - 适合：用量很小，比如每天几斤到十几斤。
   - 优点：离得近，临时补货快，老板好沟通。
   - 缺点：价格偏高，品类不一定全。
   - 省心做法：和老板谈“长期合作价+每天预留+满额免费送”，把常用水果固定下来。

4. **产地/一级批发商直供**
   - 适合：用量已经比较稳定，哪怕单品每天十几斤以上。
   - 优点：单价低，品质稳定。
   - 缺点：通常有起订量，售后沟通成本高。
   - 省心做法：只对1-2个高频单品做直供，比如柠檬、橙子、西瓜，其他杂项仍走本地配送。

5. **净果/切果供应商**
   - 适合：餐饮店直接出餐、做果盘、饮品，不想自己洗切。
   - 优点：省人工、省损耗、规格统一。
   - 缺点：单价高，保质期短。
   - 省心做法：只对高频且人工成本高的品类用净果，比如菠萝、西瓜、芒果。

**最省心的组合建议：**
- 主供应商：本地生鲜配送商或农贸固定摊位，负责每天基础用量。
- 补充供应商：附近水果店，负责临时缺货、少量补货。
- 高频单品：如果量稳定，再找产地或一级批发直供。
- 加工类：需要切果时，用净果供应商。

**选供应商时重点看这几点：**
- 能不能小批量起送，比如每天10斤、20斤也送。
- 能不能固定时间送到，比如每天上午9点前。
- 坏果、少送、晚到怎么赔，最好提前写清楚。
- 能不能微信下单、月结或周结，减少每天对账。
- 是否只做几个稳定品类，而不是什么都卖但都不精。

**一句话：**
每天少量水果，最省心的是“本地固定摊位/周边水果店 + 同城生鲜配送”组合，不要一上来找大供应商。先固定1家主供、1家备用，谈好小批量配送和坏果赔付，基本就省心了。
