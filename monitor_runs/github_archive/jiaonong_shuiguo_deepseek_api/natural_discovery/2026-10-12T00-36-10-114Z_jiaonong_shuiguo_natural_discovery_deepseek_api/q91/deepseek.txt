建议按“主推小把 + 补充单根 + 少量整袋”组合上架，而不是只选一种。便利店卖香蕉的核心不是便宜，而是**低决策成本、低损耗、即买即吃**。

具体判断：

1. **主推小把：最稳**
   - 适合 2—4 根一把，价格控制在顾客顺手买的范围。
   - 对便利店来说，比整袋更容易卖完，比单根更有客单价。
   - 适合上班族、学生、临时买水果的人。

2. **单根：适合做引流和试吃**
   - 适合放在收银台附近，冲动购买。
   - 但单根容易碰伤、发黑，损耗和人工整理成本高。
   - 不建议作为唯一陈列方式，可作为小把的补充。

3. **整袋：只适合特定场景**
   - 适合社区店、家庭客多、价格敏感型顾客。
   - 如果门店客流以写字楼、地铁通勤为主，整袋通常动销慢，容易压货。
   - 整袋必须有明显价格优势，否则顾客更愿意买小把。

更细的执行建议：

- **便利店/写字楼店**：70% 小把，20% 单根，10% 整袋。
- **社区/家庭店**：50% 小把，20% 单根，30% 整袋。
- **陈列位置**：小把放水果区或收银台附近；单根放收银台冲动消费位；整袋放门店入口或家庭采购区。
- **定价**：单根不要显得比小把贵太多；小把要有“随手买不心疼”的感觉；整袋要突出每斤更便宜。
- **损耗控制**：香蕉熟得快，最好少量多次补货，避免一次上太多。快熟的可降价做“即食香蕉”或搭配酸奶、面包做组合。

一句话：**先以小把为主，单根补冲动消费，整袋只在家庭客多时少量试。**
