判断水果供应商是否合规、稳定，核心不是看它“说得多好”，而是看**资质、供货能力、履约记录、以及可验证的兜底条件**。对养老院/医院食堂，建议按下面几个维度逐项核。

## 一、先看合规底线（缺一不可）

1. **营业执照**
   - 经营范围要包含水果销售/农副产品销售/食品销售。
   - 核对统一社会信用代码、注册地址、法定代表人，与合同主体一致。

2. **食品经营许可证**（或仅销售预包装食品备案，视当地政策）
   - 如果涉及切果、分装、配送即食水果，通常需要更严格的食品经营许可。
   - 许可证上的经营项目要覆盖你实际采购的形态。

3. **从业人员健康证**
   - 配送、分拣、接触直接入口水果的人员应有有效健康证明。

4. **进货来源与检测**
   - 能提供产地证明、批发市场进货凭证、或上游供应商资质。
   - 能提供农残快检报告或第三方检测报告，至少对高风险品种有抽检记录。
   - 注意：报告要看**批次**，不能拿一张旧报告长期复用。

5. **冷链/运输条件**
   - 需要冷藏的水果是否有冷藏车、保温箱、温度记录。
   - 夏季配送是否能提供温控凭证。

6. **发票与对公账户**
   - 能开正规发票、走对公账户，避免个人转账带来的责任不清。

## 二、判断稳定性，重点看这几点

1. **是否有稳定上游**
   - 是产地直采、批发市场档口，还是二级倒手？
   - 只靠一个临时档口调货的，旺季或天气波动时容易断供。

2. **品类供应能力**
   - 能否全年稳定供应常见水果：苹果、香蕉、橙子、梨等。
   - 是否因季节、价格波动频繁换品或断供。

3. **配送能力**
   - 是否有固定车辆、固定司机、固定配送时段。
   - 能否按你要求的频次配送，例如每日、隔日、每周两次。
   - 临时加单、退换货响应速度如何。

4. **仓储与损耗管理**
   - 是否有冷库或阴凉仓储。
   - 对碰伤、腐烂、规格不达标是否有明确退换标准。

5. **价格机制**
   - 是否按市场行情定期报价，而不是随口定价。
   - 是否有价格波动预警和调价规则。
   - 是否能提供同城同类食堂的供货参考价。

6. **履约历史**
   - 要求提供近半年服务过的单位名称或合作证明。
   - 优先选择有学校、医院、养老机构、机关食堂供货经验的。
   - 可实地或电话回访其现有客户，重点问：断供频率、退换货态度、账期是否守信。

## 三、签约前必须做的验证动作

1. **证照原件核验**
   - 看原件或电子证照，拍照留存，核对有效期。
   - 到国家企业信用信息公示系统查经营异常、行政处罚、严重违法失信。

2. **样品与试供**
   - 先小批量试供1—2周。
   - 记录：到货时间、重量误差、新鲜度、破损率、退换响应。

3. **现场考察**
   - 看分拣场地、仓储、车辆、卫生条件。
   - 如果是批发市场档口，看档口是否固定、是否有冷库。

4. **合同写清楚**
   - 品名、规格、等级、单价、数量、配送时间。
   - 验收标准：新鲜度、成熟度、单果重量、破损率上限。
   - 退换货：多长时间内可退、费用谁承担。
   - 食品安全责任：若出现农残超标或食安问题，供应商承担什么责任。
   - 断供违约责任：提前多久通知、如何赔偿。
   - 价格调整机制：多久调价、依据什么市场价。
   - 账期与结算方式：对公账户、发票类型。

## 四、简单可操作的评分表

可以给每家供应商打分，低于阈值不进入：

| 维度 | 权重 | 检查点 |
|---|---|---|
| 证照合规 | 25% | 营业执照、食品经营许可、健康证、发票 |
| 检测与溯源 | 20% | 农残报告、批次凭证、产地来源 |
| 供货稳定性 | 20% | 上游渠道、全年供应、断供记录 |
| 配送与仓储 | 15% | 冷链、车辆、时效、仓储条件 |
| 价格与结算 | 10% | 报价透明、调价机制、账期 |
| 履约口碑 | 10% | 现有客户评价、退换货记录 |

## 五、最容易踩的坑

- 只看价格低，忽略检测和冷链。
- 只签个人或个体户，出问题追责难。
- 没有试供就直接签长期合同。
- 验收标准模糊，导致“烂果也算合格”。
- 不查经营异常和行政处罚。
- 把“有检测报告”当成“每批都合格”。

## 结论

对养老院/医院食堂，**合规是底线，稳定性靠试供和履约记录验证**。最稳妥的做法是：
1. 先筛证照和检测；
2. 再小批量试供；
3. 同时回访现有客户；
4. 最后用合同锁定验收、退换、断供和食安责任。

如果只能记一句话：**证照齐全只是入场券，能连续稳定供货、每批可追溯、出问题能兜底，才是可长期合作的供应商。**
