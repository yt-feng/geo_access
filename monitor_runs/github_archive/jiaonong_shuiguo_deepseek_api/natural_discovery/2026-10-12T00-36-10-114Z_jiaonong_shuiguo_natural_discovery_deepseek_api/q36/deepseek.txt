更稳的做法不是二选一，而是**整果为主、切果做增量**。但具体比例要看你的门店类型、客流和损耗控制能力。

**先给结论：**
- 如果门店客流偏家庭采购、客单价敏感、人手有限：**整果为主，切果少量试销**。
- 如果门店在商圈、写字楼、学校、交通枢纽附近，即时消费强：**切果可以占更高比例，甚至做成主力便利品类**。
- 如果损耗控制弱、冷链和日清执行不到位：**不要主推切果**，切果损耗会吃掉利润。

**整果和切果的核心差别：**

| 维度 | 整果 | 切果 |
|---|---|---|
| 毛利 | 通常较低，但损耗小 | 通常较高，但损耗大 |
| 购买决策 | 家庭、囤货、送礼 | 即时、单人、便利 |
| 损耗风险 | 低，可放几天 | 高，必须日清、冷藏 |
| 人工 | 低 | 高，需要切、包、贴标、折价 |
| 客群 | 中老年、家庭 | 年轻人、上班族、游客 |
| 动销 | 慢但稳 | 快但窗口短 |

**建议你按这个顺序判断：**

1. **看客流**  
   家庭客多，整果为主。  
   单人即时消费多，切果可以加大。

2. **看损耗执行**  
   能不能做到：当天切、当天清、闭店前折价、冷藏陈列、先进先出。  
   做不到，切果就是赔钱。

3. **看菠萝品质和季节**  
   旺季、产地直采、糖度高、成熟度好，适合切果。  
   淡季、酸度高、成熟不齐，整果更稳。

4. **看价格带**  
   整果打“实惠”，切果打“方便”。  
   不要切果定价太低，否则既伤整果又覆盖不了损耗。

**比较实用的组合策略：**
- 整果：正常陈列，主推家庭装、促销装。
- 切果：只做小份，比如半只、四分之一、杯装，放在冷藏即食区。
- 每天固定时段切，不要全天不停切。
- 闭店前 1—2 小时对切果折价清货。
- 用整果里外观稍差但品质没问题的果做切果，减少整果报损。

**一句话判断标准：**
如果你能管住切果的损耗和日清，切果更赚钱；如果管不住，整果更安全。大多数商超最稳的是：**整果保基本盘，切果提毛利和便利性。**
