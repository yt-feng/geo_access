判断批发档口能不能长期稳定拿香蕉，核心看“货源在谁手里、货能不能持续出、出问题谁兜底”。下面给你一套可现场核验、可直接问出口的判断标准。

**一、先分清对方是哪一类供货方**
- **产地种植户/合作社**：自有或合作蕉园，价格有优势，但受季节、台风、病害影响大，单一产地断供风险高。
- **产地代收/装车点**：整合周边蕉农，出货量较稳，但要看他和多少蕉农绑定。
- **一级批发商/口岸商**：常做进口蕉或跨区域调货，货源相对稳，但价格随行就市，账期和品质波动要盯紧。
- **二级批发/倒货商**：自己没基地也没稳定渠道，靠临时调货，最容易断供、换规格、抬价。

**二、现场必须问清的6个问题**
1. **货从哪来**：具体到县/镇/口岸/蕉园，不要只听“云南”“老挝”这种大区域。
2. **一天/一周能稳定出多少件**：让他说日常量，不是峰值量；再问淡季和雨季各能出多少。
3. **有几个供货来源**：单一蕉园风险大，至少2—3个基地或代收点轮换才稳。
4. **规格能不能固定**：比如每件净重、每把条数、成熟度、青蕉/黄蕉比例，能不能长期按同一标准发。
5. **断供了怎么办**：有没有备用货源、能不能提前几天告知、违约怎么赔。
6. **结算和账期**：现结、押车、还是周结；账期越长，对方资金压力越大，越容易在缺货时先供别人。

**三、用“小单试供”验证，不要一上来压大货**
- 先走**2—3车小单**，连续走**2—3周**，看三件事：到货时间准不准、规格一致不一致、坏果率稳不稳定。
- 每车记录：**发货时间、到货时间、净重、坏果率、催熟后颜色和口感、单件成本**。
- 如果小单都经常迟到、换规格、坏果率忽高忽低，大单一定更不稳。

**四、看这些硬信号判断稳定性**
- **有固定装车点、冷库、催熟房**：比只有一部手机到处调货的靠谱。
- **能带你看蕉园或长期合作代收点**：说明货源在掌控中。
- **愿意签简单供货协议**：写清规格、数量、时间、违约处理，比口头承诺强。
- **老客户多且合作超过半年**：可以侧面问其他档口或司机，别只信他自己说。
- **价格不是最低但波动小**：明显低于市场价、又承诺长期稳供的，多半有猫腻，常见是次果充好、临时拼车或后期抬价。

**五、最实用的判断口诀**
**“三看三试”**：
- 看基地/装车点、看冷库/催熟、看老客户；
- 试小单、试连续周、试突发加单。
连续三周小单稳定，再谈大单和账期；任何一项反复出问题，就不要把主力采购压在他一家。
