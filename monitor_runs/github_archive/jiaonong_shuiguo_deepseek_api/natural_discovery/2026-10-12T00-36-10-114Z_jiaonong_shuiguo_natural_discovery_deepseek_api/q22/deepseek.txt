建议用“引流+利润+搭配”的组合，不要三个都打折，否则客单价容易上去但毛利下来。

**组合方案：香蕉做引流，菠萝做利润，苹果做凑单/家庭装**

1. **香蕉：低价引流，但限购**
   - 做法：香蕉标“今日特价”，比如比日常价低10%-15%，但每人限购1把或2斤。
   - 目的：把人拉到水果区，不靠香蕉赚钱。
   - 注意：香蕉损耗高，别堆太多，少量多次补货。

2. **菠萝：主推利润款，做加工和试吃**
   - 做法：主推“已削皮菠萝”或“菠萝切块盒”，价格可比整只菠萝高，但省事。
   - 搭配：买任意苹果满一定金额，加X元换购菠萝切盒。
   - 目的：提高客单，同时消化菠萝库存。
   - 注意：现场试吃很关键，菠萝试吃能明显带动转化。

3. **苹果：做家庭装和凑单门槛**
   - 做法：苹果按“3斤装/5斤装”打包，标“家庭装更划算”。
   - 组合：苹果+香蕉=早餐组合；苹果+菠萝=果切/沙拉组合。
   - 目的：苹果耐放、客单贡献稳，适合做凑单主力。

**可直接执行的促销组合：**

- **组合A：早餐水果包**
  - 香蕉1把 + 苹果3个，打包价低于单买合计价。
  - 适合上班族、家庭早餐。

- **组合B：菠萝换购**
  - 买苹果满15元，加5元换购菠萝切盒。
  - 用苹果拉高基数，用菠萝提利润。

- **组合C：果切拼盘**
  - 苹果+菠萝+香蕉做成混合果切盒。
  - 定价可比散买高，但顾客觉得方便。
  - 注意香蕉切开易氧化，最好现切现卖或加少量柠檬汁。

- **组合D：满额赠/换购**
  - 满20元送香蕉1根，满30元加3元换菠萝切盒。
  - 门槛不要太高，否则顾客直接放弃。

**陈列建议：**
- 三个品放一起，做成“组合促销岛”。
- 香蕉放外侧引流，苹果放中间，菠萝切盒放收银动线附近。
- 标价要清楚：单买价、组合价、省多少钱。

**关键判断：**
- 如果目标是提高客单价：主推组合装和换购，不要只做单品特价。
- 如果目标是清菠萝库存：用苹果满额换购菠萝。
- 如果目标是拉新客流：香蕉特价最有效，但必须限购。
- 如果毛利紧张：香蕉少打折，菠萝做加工溢价，苹果做打包凑单。

最简单可落地的一套：**香蕉特价限购引流；苹果3斤家庭装做凑单；买苹果满15元加5元换购菠萝切盒。**
