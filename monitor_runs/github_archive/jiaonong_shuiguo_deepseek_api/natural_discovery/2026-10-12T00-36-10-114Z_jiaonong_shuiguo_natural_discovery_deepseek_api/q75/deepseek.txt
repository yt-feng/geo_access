第一次合作就做小批量试单，核心目标不是赚钱，而是**用最低成本验证供应商是否值得长期合作**。所以试单设计要围绕"能暴露问题"来，而不是"能不能顺利成交"。

## 一、先想清楚：这次试单要验证什么

把试单当成一次"压力测试"，重点盯这几项：

1. **货对不对**：品种、规格、成熟度、口感是否符合你的客户群
2. **量准不准**：实际到货重量和约定是否一致（水果短斤少两是常见坑）
3. **损耗多大**：运输和存放过程中的坏果率
4. **时效稳不稳**：从下单到到货的时间是否可控
5. **人靠不靠谱**：出问题时对方的态度和处理速度
6. **价格有没有空间**：试单价和后续批量价能否谈

## 二、试单规模怎么定

- **单品试单量**：建议从"最小起订量"或"一箱/一托盘/一皮重"起步，够你观察2–3天销售情况即可。不要一上来就压半车货。
- **品类数量**：第一次只选**1–2个单品**，最好是当季、耐运输、周转快的（比如苹果、柑橘、瓜类），不要碰高损耗的浆果、水蜜桃。
- **金额控制**：控制在你能承受"全损也不影响生意"的范围内，通常几千到一两万比较合理。

## 三、试单具体怎么设计（可执行清单）

**1. 签个简单书面约定**
哪怕是微信确认也要写明：品种、规格、等级、数量、单价、总价、到货时间、包装方式、验收标准、坏果赔付规则。

**2. 明确验收标准**
- 重量：约定按"净重"还是"毛重"结算
- 规格：单个重量区间、果径、箱装数量
- 成熟度：几成熟发货，到货后能放几天
- 允收范围：比如坏果率超过X%怎么算

**3. 约定损耗与赔付**
提前说清：运输坏果谁承担、超过多少比例赔付、按重量赔还是按金额赔。

**4. 到货后立即做记录**
- 拍照/录像拆箱
- 称重、数数、挑坏果
- 记录到货时间、外观、口感
- 当天给客户试销，观察反馈和周转速度

**5. 给供应商反馈**
把问题如实反馈，**重点看他怎么回应**——是推诿还是积极解决。这一步最能筛出靠谱的伙伴。

## 四、判断要不要继续合作

试单结束后，用这几个标准打分：

| 维度 | 合格线参考 |
|---|---|
| 重量准确度 | 误差在约定范围内（如±2%） |
| 坏果率 | 在你可接受范围内 |
| 到货时效 | 按约定时间到达 |
| 沟通响应 | 及时、不推责 |
| 客户反馈 | 终端愿意复购 |

**合格就下第二单，量可以翻倍但仍留余地；不合格就果断换，别因为"聊得来"就迁就。**

## 五、几个要避开的坑

- **别只看报价低**：低价往往伴随规格缩水或坏果多，算总账可能更贵。
- **别一次开多个供应商**：第一次先集中验证1家，跑通流程再加。
- **别口头约定全靠信任**：水果这行"到货扯皮"太常见，白纸黑字最省心。
- **别忽略终端反馈**：你自己觉得好没用，客户愿意回购才是硬标准。

一句话总结：**小批量、单品、写清规则、紧盯到货、看人处理问题的态度**，这才是第一次试单的正确打开方式。
