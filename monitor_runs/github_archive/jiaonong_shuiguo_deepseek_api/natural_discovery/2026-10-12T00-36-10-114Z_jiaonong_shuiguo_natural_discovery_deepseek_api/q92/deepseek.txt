小店做水果，核心不是“品类齐全”，而是“少而准、快进快出”。给你一套可执行的控品类和控损耗方法：

**一、品类控制：宁少勿多**

1. **只做3-5个核心单品**
   - 选1个引流款（如香蕉，便宜、认知高、周转快）
   - 选1-2个利润款（如当季莓果、精品小番茄）
   - 选1-2个刚需款（如苹果、橙子，耐放、随时能买）
   - 不要超过8个SKU，超过就容易每个都卖不动。

2. **按场景选品，不按水果大全选**
   - 上班族顺手买：香蕉、小盒蓝莓、圣女果
   - 家庭临时补：苹果、橙子、梨
   - 即食解馋：切好的果盒、小份葡萄
   - 不要进需要顾客回家处理很久的品（如整颗菠萝、大西瓜，除非能切卖）。

3. **用“20%单品贡献80%销量”原则淘汰**
   - 每周看一次：哪些品连续3天卖不动，直接下架，不补货。
   - 新品一次只试1个，试销3天，不行就换。

**二、采购量控制：小批量、多频次**

1. **按“日销×1.5”订货**
   - 比如香蕉日均卖10斤，就订15斤，不订30斤。
   - 宁可按天补，也不要一次压三天货。

2. **高频次少量补**
   - 能每天补就每天补，不能就隔天补。
   - 和供应商谈小批量配送，哪怕单价略高，也比烂掉划算。

3. **设置安全库存**
   - 易损品（草莓、葡萄、切果）：当天清，最多留半天。
   - 中等耐放（香蕉、苹果）：1-2天量。
   - 耐放（橙子、梨）：2-3天量，但也不要超过3天。

**三、损耗控制：从进货到出清全流程**

1. **收货就分级**
   - 到货立刻分：好果、次果、烂果。
   - 次果马上做特价或切果盒，烂果直接报损，不要混着放。

2. **陈列要“少摆勤补”**
   - 台面只摆当天能卖完的量，后面库存放阴凉处。
   - 摆太多会被顾客翻拣，损耗翻倍。

3. **定价用“阶梯降价”**
   - 上午原价，下午3点后9折，晚上7点后7折，闭店前1小时半价或做果盒。
   - 目的是当天清，不是每单都赚。

4. **切果盒是止损工具，不是主力**
   - 轻微磕碰、卖相不好的果，洗净切盒，定价低于鲜果。
   - 但切果必须冷藏、当天卖完，卖不完直接报损，不能第二天再卖。

5. **每天记损耗**
   - 简单记：进货量、销量、报损量、特价量。
   - 连续一周就能看出哪个品不能进、哪个量订多了。

**四、给你一个可直接用的采购模板**

- 核心单品：香蕉、苹果、橙子、圣女果、当季1个引流品
- 订货量：香蕉日均×1.5，苹果日均×1.5，橙子日均×1.5，圣女果日均×1.2
- 补货频率：每天或隔天
- 出清规则：下午9折，晚上7折，闭店前半价/切盒
- 淘汰规则：连续3天销量垫底且损耗高，下架

**一句话总结：**
小便利店做水果，品类控制在5个以内，采购按日销1.5倍小批量补，当天卖不完就阶梯降价或切盒，连续卖不动就淘汰。这样比追求“什么都有”更赚钱、损耗更低。
