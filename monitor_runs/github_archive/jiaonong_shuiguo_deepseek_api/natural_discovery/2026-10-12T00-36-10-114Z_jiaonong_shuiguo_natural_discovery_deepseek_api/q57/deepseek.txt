建议优先做“中央厨房统一收货”，但不要一刀切：按水果品类和门店半径分层设计。多数餐饮连锁用“中央厨房统收 + 门店少量应急/即用直配”效果最好。

**一、中央厨房统一收货更适合的情况**

适合：苹果、橙子、柠檬、西瓜、哈密瓜、火龙果、猕猴桃等耐储、标准化程度较高、可统一分拣包装的水果。

优点：
1. **品控统一**：总部定标准，中央厨房按糖度、规格、成熟度、瑕疵率验收，避免各店标准不一。
2. **采购议价强**：集中下单量大，更容易拿到稳定价格和账期。
3. **食品安全可追溯**：批次、供应商、检测报告集中管理，出问题能快速追溯。
4. **减少门店操作**：门店只负责领用或简单加工，降低店长采购腐败和损耗管理难度。
5. **配送效率高**：可随中央厨房其他食材一起统配，减少门店收货频次。

**二、门店分开收货更适合的情况**

适合：草莓、蓝莓、车厘子、荔枝、杨梅、芒果、葡萄、水蜜桃等易损、短保、成熟度敏感的水果；以及门店分散、中央厨房距离远、配送频次跟不上的情况。

优点：
1. **损耗更低**：短保水果少一次中转，成熟度和新鲜度更好控制。
2. **配送更灵活**：门店可按当日客流和菜单临时补货。
3. **本地采购优势**：某些区域门店靠近产地或批发市场，能拿到更好鲜度和价格。

缺点：
1. 品控和价格不统一。
2. 门店采购、验收、损耗管理难度大。
3. 容易产生灰色空间。
4. 总部难以做统一食品安全追溯。

**三、推荐落地模式**

1. **A类：耐储水果**  
   中央厨房统一收货、统一分拣、统一配送。  
   例如：苹果、橙子、柠檬、西瓜、哈密瓜。

2. **B类：短保易损水果**  
   中央厨房定供应商、定标准、定价格，由供应商直配门店，门店按总部标准验收并拍照回传。  
   例如：草莓、蓝莓、车厘子、荔枝、杨梅。

3. **C类：应急补货**  
   门店可在授权额度内本地补货，但必须走总部指定渠道或白名单供应商，并当日录入系统。

4. **关键控制点**
   - 总部制定水果验收标准：规格、糖度、成熟度、瑕疵率、温度、包装。
   - 中央厨房和门店都用同一套验收表，避免双标准。
   - 短保水果直配门店时，总部要保留供应商准入、价格审核和飞行检查权。
   - 损耗率按品类设定阈值，比如耐储水果低损耗，短保水果允许更高损耗，但超阈值要复盘。

**结论**

如果你的门店数量多、菜单对水果标准要求高、中央厨房配送能力成熟：**优先中央厨房统一收货**。  
如果水果以短保易损品类为主、门店分散且配送半径大：**用“中央厨房统收耐储品 + 供应商直配短保品”的混合模式**，通常比纯统收或纯门店分开收货更优。
