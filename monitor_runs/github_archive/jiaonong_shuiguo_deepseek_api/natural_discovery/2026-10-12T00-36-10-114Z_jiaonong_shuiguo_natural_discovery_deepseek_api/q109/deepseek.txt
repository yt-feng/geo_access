优先谈**账期**，其次是**售后**，最后才是**配送**。理由如下：

1. **账期最值得优先谈**
   - 直接决定你的现金流压力和资金周转效率。
   - 长期合作下，账期每延长15～30天，对现金流改善非常明显。
   - 水果是高频、易损耗品类，账期谈不好，规模越大越容易被拖死。
   - 建议优先争取：月结30天→月结45/60天，或“首批现结、后续月结”。

2. **售后第二优先**
   - 水果非标、损耗高，售后规则不清，后面全是扯皮。
   - 重点谈清楚：坏果率标准、赔付比例、补货还是退款、响应时限、举证方式。
   - 例如：到货24小时内反馈，坏果超3%按比例赔付，48小时内补货或退款。
   - 售后谈清楚，比配送快半天更重要，因为它直接决定实际采购成本。

3. **配送最后谈**
   - 配送重要，但通常可替代性最强，也最容易通过加钱或换物流解决。
   - 除非你做的是高端即时零售、餐饮高峰配送，否则配送频次和时效可以后续优化。
   - 优先确认：固定配送日、最低起送量、临时加单规则、冷链责任归属即可。

**谈判顺序建议：**
先谈账期 → 再谈售后赔付 → 最后用配送频次/起送量做交换筹码。

**一句话结论：**
长期合作里，账期决定你能不能活下去，售后决定你实际赚不赚钱，配送决定你顺不顺，但前两个更值得先谈。
