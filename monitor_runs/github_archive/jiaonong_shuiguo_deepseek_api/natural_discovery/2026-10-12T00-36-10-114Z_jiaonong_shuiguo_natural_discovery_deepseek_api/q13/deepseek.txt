做小区团购，水果供应商是否给力，直接决定你能不能留住客户。核心要盯这几项服务：

**1. 稳定供货与品质分级**
- 能否按你的团购量稳定供货，不临时断货
- 有没有明确分级（大果/中果/小果、糖度、果径），避免“图片好看、到手缩水”
- 是否支持坏果包赔，比例怎么算

**2. 价格与结算支持**
- 团购价是否比批发市场有优势，能不能按量阶梯报价
- 是否支持一件代发、次日达或定时送到店/小区
- 账期还是现结，能不能先少量试单

**3. 包装与分拣**
- 能否按份分装（比如5斤装、家庭装），减少你二次分拣
- 包装是否抗压、透气，适合水果短途配送
- 是否贴标签、放售后卡

**4. 配送与售后**
- 配送范围是否覆盖你附近小区，时效能否保证
- 破损、烂果、少发怎么处理，补发还是退款，响应速度
- 是否有专门的售后对接人

**5. 营销与数据支持**
- 能否提供每日报价单、爆品推荐、实拍图/视频素材
- 是否支持你定制团购套餐
- 能不能给你留出利润空间，而不是让你只赚跑腿费

**选供应商的实操建议：**
1. 先拿3-5个供应商试单，重点看**到货品质和售后响应**
2. 谈清楚**坏果率标准、赔付方式、配送时效**
3. 不要只比价格，要算**损耗+售后+分拣成本**后的真实毛利
4. 起步阶段尽量选**支持小批量、多频次补货**的供应商，避免压货
