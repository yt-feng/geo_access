水果店卖菠萝，采购时最稳妥的判断标准是：**按“到店后 1～3 天内能卖完”的节奏来定熟度，而不是一味挑最熟或最生。**

可以按下面几个维度判断：

1. **看外观**
   - **果皮颜色**：  
     - 青绿偏多：适合放 2～4 天再卖，适合计划慢慢出货。  
     - 黄绿相间：比较安全，通常 1～3 天内成熟，适合大多数水果店。  
     - 大面积金黄、甚至发橙：已经很熟，最好 1 天内卖掉，否则容易过熟、发酸、出水。  
   - **果眼**：果眼大而平展、间距较开，通常成熟度较高；果眼很尖、很密，偏生。  
   - **底部**：底部发黄、有香气，说明熟得快；底部仍青硬，则还能放。

2. **闻气味**
   - 靠近底部闻：  
     - 无明显香味：偏生，可放。  
     - 有淡淡菠萝香：适合 1～2 天卖。  
     - 香味浓、带甜酒味：已经偏熟，尽快处理，适合促销或切果盘。  
   - 如果闻到发酵味、酒精味，说明过熟，损耗风险高。

3. **按压判断**
   - 轻按果身：  
     - 硬实：偏生，耐放。  
     - 稍有弹性：成熟度合适，适合近期销售。  
     - 明显软、局部塌陷：过熟或开始坏，谨慎采购。  
   - 重点按底部和中部，不要只按一个点。

4. **看叶片和冠芽**
   - 冠芽青绿、挺立：通常较新鲜。  
   - 叶片发黄、干枯、易拔：可能放久了，或成熟度高但新鲜度下降。  
   - 叶片一拔就掉，不一定代表熟，有时是存放过久。

5. **掂重量**
   - 同样大小，**手感重**的通常水分足、果肉好。  
   - 明显轻飘，可能失水或内部空腔，损耗风险大。

6. **按销售方式定采购熟度**
   - **整果现卖为主**：选黄绿相间、微香、稍弹的，1～3 天能卖完最合适。  
   - **当天促销/切果盘**：可以选更熟的，香味足、颜色黄，但必须当天处理。  
   - **备货放几天**：选青绿偏多、硬实、无香或微香的，但不要全青，否则后熟慢、口感差。  
   - **天气热或店内温度高**：熟度要压低一点，否则熟得太快。  
   - **天气冷或空调足**：可适当选熟一点，减少青果难卖的问题。

7. **控制损耗的采购原则**
   - 不要一次全进同一熟度：  
     **7 成黄绿相间 + 2 成偏青 + 1 成偏熟**，分批卖。  
   - 熟果放前排、做试吃、切果盘、促销。  
   - 青果放后排或阴凉处，别堆压。  
   - 每天翻检，底部发软、香味浓、渗汁的先处理。  
   - 如果连续几天熟果损耗高，下次采购整体熟度降一档。

简单记：  
**青绿硬实无香 = 能放；黄绿微香稍弹 = 最好卖；金黄浓香发软 = 当天必须处理。**  
水果店采购菠萝，最好选**黄绿相间、底部微香、果身稍弹、手感重**的，再搭配少量偏青和偏熟，分批销售，损耗最低。
