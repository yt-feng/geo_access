要固定，但不是“只认一个产地/一个批次”，而是**固定一套可复现的采购标准 + 主供应商 + 备用供应商**。水果口味波动是茶饮店最常见的出品不稳定来源，完全不固定会很难控，固定得太死又会断供、涨价、被单一供应商卡住。

可以按这个思路做：

1. **先定“风味标准”，再定产地**
   不要一上来就说“只用某产地”。先确定你们要的感官标准：
   - 酸甜比
   - 香气类型
   - 果肉/果汁状态
   - 出汁率、可溶性固形物
   - 是否耐泡、耐摇、耐高温
   然后让采购按这个标准找产地和批次。产地只是实现标准的手段。

2. **固定“等级和规格”，比固定具体产地更重要**
   同一产地不同果园、不同成熟度、不同季节，口味也会差很多。建议固定：
   - 品种
   - 等级/果径
   - 成熟度
   - 糖酸比范围
   - 加工方式：鲜果、冷冻果浆、NFC、浓缩汁、果酱
   - 包装规格和冷链条件

3. **主供应商固定，批次可轮换但要“锁样”**
   可以固定 1 家主供应商，要求他们按你们确认的样品供货。每批到货做验收：
   - 糖度
   - 酸度
   - 香气
   - 色泽
   - 出杯测试
   不合格就退，不要靠门店临时加糖、加酸去救。

4. **至少保留 1 家备用供应商**
   水果有产季、天气、病害、物流问题。只固定一家，断供时更麻烦。备用供应商也要提前打样、测试、锁标准，不能等缺货了才临时找。

5. **能标准化就尽量标准化**
   如果鲜果波动太大，优先考虑：
   - 冷冻果浆/果泥
   - NFC 果汁
   - 定制果酱
   - 复配果浆
   这些比鲜果更容易做到批次稳定，也更适合连锁茶饮。鲜果适合做卖点，但要做到稳定，通常要配合糖酸调整和 SOP。

6. **建立“风味基准 + 允许偏差”**
   比如某款水果茶：
   - 糖度范围：10–12 Brix
   - pH 范围：3.2–3.6
   - 香气：以某支锁样为基准
   - 允许偏差：超过范围就调整配方或退货
   这样门店和采购都有判断依据。

7. **采购策略上：固定标准，动态产地**
   更稳的做法是：
   - 标准固定
   - 主供应商固定
   - 产地可以随产季切换
   - 每批锁样、验收、留样
   - 备用供应商随时可切换

**结论：**
要固定，但固定的是**品种、等级、糖酸比、加工方式、验收标准和主供应商**，不是死守某一个产地或某一个批次。最稳的是“主供应商 + 备用供应商 + 锁样验收 + 可替代的标准化原料”。如果你们店量不大，直接优先用冷冻果浆或定制果酱，比追鲜果产地更现实。
