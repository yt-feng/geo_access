水果礼盒要好卖，核心不是“把几种水果塞满”，而是让顾客一眼觉得**值、好看、有面子、送得出手**。苹果、橙子、香蕉、菠萝这四种里，菠萝和香蕉更偏“体积感/性价比”，苹果和橙子更适合做“主视觉+寓意”。搭配时可以按场景分档来做，而不是只做一个固定组合。

## 一、先定3个价位，不要只做一种

### 1）引流款：39～59元
适合走量、外卖、办公室拼单。
- 苹果 3个
- 橙子 4个
- 香蕉 1把（小把，5～6根）
- 不放菠萝，或者只放1个小菠萝

逻辑：苹果橙子撑颜色，香蕉撑数量感，成本可控。菠萝体积大，放进去容易超成本，适合做加价购。

### 2）主推款：69～99元
这是最好卖的档位，适合探病、日常送礼、员工福利。
- 苹果 4个
- 橙子 5个
- 香蕉 1把（6～8根）
- 菠萝 1个（中等大小）

逻辑：四种都有，颜色黄橙红绿齐了，看起来饱满。菠萝放中间或后面做“大件”，苹果橙子围一圈，香蕉放侧边填空。

### 3）高端款：129～199元
适合节日、商务、探望长辈。
- 苹果 6个（选大果、红度高）
- 橙子 6个（选均匀、带叶更好）
- 香蕉 1把（选精品小把，不要发青）
- 菠萝 1个（选凤梨品种，标“手撕凤梨/金钻凤梨”更好卖）
- 可加：贺卡、丝带、手提袋、少量进口水果做点缀

逻辑：不是靠数量多，而是靠**果形整齐、颜色统一、包装高级**。菠萝选凤梨，香蕉选不黑不青的，苹果橙子擦亮。

## 二、怎么搭更好卖：记住4个原则

1. **颜色要跳**
   苹果红、橙子橙、香蕉黄、菠萝黄绿。红+橙+黄最讨喜，适合送礼。不要全放青苹果、青橙，显得不熟。

2. **形状要错开**
   菠萝竖放或斜放做背景，苹果橙子圆果围边，香蕉弯形填空。全是圆果会显得乱，全是香蕉又显得便宜。

3. **寓意要写上**
   苹果=平安，橙子=心想事成，香蕉=招财/相交好运，菠萝=旺来、好运旺。标签一写，礼盒立刻从“水果堆”变成“礼品”。

4. **别让香蕉压底**
   香蕉最怕压、怕闷、怕冷。放上层或侧边，不要垫在下面。苹果橙子耐放，可以放底层和外围。

### 组合A：平安橙意礼盒（最稳）
- 苹果4 + 橙子5 + 香蕉1把 + 菠萝1个
- 适合：日常送礼、探病、员工福利
- 卖点：平安、心想事成、旺来

### 组合B：旺旺发财礼盒（节日好卖）
- 苹果6 + 橙子6 + 菠萝1个 + 香蕉1把
- 适合：开业、春节、乔迁
- 卖点：平安、旺来、招财

### 组合C：轻享小礼盒（外卖走量）
- 苹果3 + 橙子4 + 香蕉5根
- 适合：39～49元，写字楼、学生、社区团购
- 卖点：便宜、好看、不浪费

### 组合D：高端凤梨礼盒（利润高）
- 金钻凤梨1 + 大苹果4 + 进口橙4 + 精品香蕉1把
- 适合：129元以上，商务、长辈
- 卖点：凤梨=旺来，苹果=平安，橙=成功

## 四、实际陈列和定价技巧

- **菠萝不要每个礼盒都放整颗**：成本高、占地方。可以推出“加10元换购小菠萝/凤梨”。
- **香蕉用精品小把**：不要一大串，显得廉价，也容易压坏其他水果。
- **苹果橙子选大小一致的**：礼盒最怕大小不一，顾客会觉得凑数。
- **透明盒+丝带+贺卡**：比纯纸箱好卖，顾客能看到水果新鲜度。
- **标价用“39/69/99/129”**：比“38.8/68.8”更像礼品档位，也方便顾客选。
- **门口放切开样品**：橙子切一个、菠萝切一个，香味和颜色最能拉客。

## 五、如果只选一个最好卖的组合

直接做：

**69元主推款：苹果4个 + 橙子5个 + 香蕉1小把 + 菠萝1个。**

理由：四种水果都有，颜色全、体积满、寓意好，成本可控，顾客觉得“什么都有”，送礼不寒酸，自己吃也不浪费。这个组合最容易成为门店爆款。
