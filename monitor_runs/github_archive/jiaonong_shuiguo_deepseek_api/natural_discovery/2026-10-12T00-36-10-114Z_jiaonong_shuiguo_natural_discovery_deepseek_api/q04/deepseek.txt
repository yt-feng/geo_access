为了减少香蕉放坏，采购时要把握一个核心：**按你预计的销售速度决定“到货熟度”，而不是一概要求越生越好**。

可执行建议如下：

1. **按销售周期定到货熟度**
   - 如果你**2～3天内能卖完**：可以要求到货 **5～6成熟**，表皮青绿、微软、无黑点。到店后很快转黄，适合快销。
   - 如果你**3～5天卖完**：要求 **4～5成熟**，偏青、硬实、无黄斑。这样有缓冲时间，减少一两天内集中催熟。
   - 如果你**当天或次日就卖**：可以要 **6～7成熟**，微黄、香气开始出来、无黑点，直接上架。
   - 一般不要长期采购 **7成熟以上** 的香蕉，除非你当天就能走量，否则很容易第二天就起黑点。

2. **到货时间要卡“销售节奏”**
   - 最好要求 **早上开市前到货**，当天上架，当天开始按熟度分级卖。
   - 避免 **下午或晚上到货**，尤其是夏天。到货后闷在箱里过夜，温度高、乙烯积累，第二天熟度会跳得很快。
   - 如果分批次采购，建议 **小批量、多频次**，比如原来一次进10箱，改成每周2～3次、每次3～4箱，比一次进一大批更不容易坏。

3. **采购时明确写进要求**
   可以直接对供应商说：
   - “我要 **4.5～5成熟**，青绿偏硬，允许少量微黄，但不能有黑点、软伤、水烂。”
   - “**早上7点前到货**，不要前一天晚上装车闷到第二天中午。”
   - “**按箱抽检**，熟度不齐、青黄差太大的不要混装。”
   - “如果天气热，要求 **冷链或通风运输**，不要暴晒后直接送到店。”

4. **到店后的关键动作**
   - 到货先 **开箱通风**，不要一直闷在纸箱里。
   - 按熟度分三档：青的放后面/阴凉处，微黄的正常上架，黄的优先促销。
   - 香蕉怕压、怕冷、怕闷。不要放冷柜，也不要堆太厚。
   - 夏天可放 **阴凉通风处**，冬天避免靠暖气或门口冷风直吹。

5. **一个简单判断标准**
   你采购时最该问自己的不是“它现在熟不熟”，而是：
   **“这批香蕉到我预计卖完，中间有几天？”**
   - 1～2天：可要6成熟左右。
   - 3～4天：要4～5成熟。
   - 5天以上：要更青，但销售风险也更大，不建议一次压太多。
