批发商在谈水果品牌代理时，区域保护和串货是核心利益点，必须落到合同条款上，不能只听口头承诺。下面按“怎么问、问什么、怎么落到合同”给你一套可直接用的清单。

## 一、先问清楚品牌方的渠道模式

问法示例：
- “咱们这个品牌目前是走省级代理、市级代理，还是区域独家？”
- “同一区域现在有没有其他代理？如果有，是几个？各自负责哪些渠道？”
- “线上（电商、社区团购、直播）由谁做？会不会和线下代理抢区域？”

目的：判断品牌方是否真的有能力做区域保护，还是只想铺货冲量。

## 二、区域保护要问的具体问题

1. **保护范围**
   - 保护的是省、市、县，还是只保护某个批发市场/渠道？
   - 保护的是全渠道，还是只保护线下批发？
   - 商超、水果店、社区团购、电商是否算在我的区域内？

2. **独家性**
   - 我这个区域是独家代理，还是非独家？
   - 独家有没有最低进货量/年任务？完不成会怎样？
   - 品牌方能不能在我区域内再开第二家代理？什么条件下可以开？

3. **保护期限**
   - 区域保护是长期有效，还是只保前几个月？
   - 合同到期后，我有没有优先续约权？

4. **跨区销售认定**
   - 什么算串货？比如我区域内客户自己从外地进货，算不算？
   - 品牌方直营、电商发货到我区域，算不算串货？
   - 其他代理把货卖到我区域，我怎么举证、怎么投诉？

## 三、串货问题要问的具体问题

1. **品牌方怎么防串货**
   - 有没有区域编码、批次码、箱码、果标追溯？
   - 发货时是否按区域登记？能不能查到货流向？
   - 对串货代理有没有罚款、扣保证金、取消返利、终止代理的处罚？

2. **我被串货时怎么办**
   - 我举报后，品牌方多长时间处理？
   - 处理结果是否书面反馈？
   - 如果串货造成我库存积压或价格崩盘，有没有补偿机制？

3. **我自己串货的后果**
   - 罚款标准是多少？按货值还是按箱？
   - 是否扣保证金、取消年终返利？
   - 严重的是否直接取消代理资格？

4. **价格体系**
   - 品牌方有没有统一批发价、零售指导价？
   - 不同区域代理拿货价是否一致？如果不一致，低价区域很容易串货。
   - 促销、临期果、尾货怎么处理？会不会冲击我区域价格？

## 四、必须落到合同里的条款

口头承诺没用，建议要求写进合同：

1. 区域范围：明确到省/市/县/渠道，附地图或客户名单。
2. 独家条款：是否独家、例外情形（电商、直营、团购）写清楚。
3. 串货定义：什么行为算串货，谁认定，怎么举证。
4. 处罚机制：罚款、扣保证金、取消返利、终止合作的具体标准。
5. 处理时限：举报后几天内响应、几天内处理。
6. 补偿机制：因串货导致损失的补偿方式。
7. 价格保护：拿货价、建议批发价、调价提前通知期。
8. 退出机制：完不成任务、品牌方违约、串货严重时怎么退出，保证金怎么退。

## 五、谈判时的实用话术

- “区域保护我理解，但我想知道，如果别人串货到我这里，咱们具体怎么处理？有没有书面流程？”
- “这个区域是只保护线下，还是线上也归我？如果电商发到我这里，算不算串货？”
- “如果品牌方自己在我区域开店或做团购，算不算违反区域保护？”
- “串货罚款可以写进合同，那我的区域保护也请写清楚，这样对双方都公平。”
- “我不想只听承诺，咱们能不能把区域范围、串货认定和处理时限写进合同附件？”

## 六、提醒你注意的风险点

- 只谈区域保护，不谈串货处罚，等于没保护。
- 品牌方若同时做电商、社区团购、直播，区域保护很容易被架空。
- 不同区域拿货价差太大，串货几乎必然发生。
- 合同里写“原则上保护”“尽量协调”这类模糊词，基本没用。
- 保证金、返利、年终政策，往往是品牌方拿捏代理的手段，要一并问清。

总结一句话：**区域保护要问“保什么、保多久、谁不能进”；串货要问“怎么认定、怎么罚、怎么赔、多久处理”。全部落到合同，才叫真保护。**
