建议按“采购成熟度 + 运输保护 + 到店处理”三步做，能明显延缓到店后变黑。

1. 采购时别买太熟的
- 选表皮青黄、果柄偏绿、手感硬实、没有黑斑的香蕉。
- 如果当天就要用，可少量买“黄熟”的；如果备2-3天，优先买“青黄转熟”的。
- 避开已经出现梅花点、果柄发黑、局部软塌的货，这种到店后很快变黑。

2. 运输和存放要控温、防压、少乙烯
- 香蕉怕冷也怕闷。未熟香蕉可放在13-15℃左右通风处；已经熟了的放阴凉通风处，尽快用。
- 不要直接放冷藏，尤其未熟香蕉，容易冻伤后发黑。
- 运输时用周转筐，别堆压，避免磕碰；磕碰处会先黑。
- 不要和苹果、梨、番茄等释放乙烯多的水果混放，会催熟。
- 到店后先拆袋/开箱通风，别闷在塑料袋里。

3. 到店后处理
- 按成熟度分开：青一点的放后面，熟的先用。
- 不要整串平放压着，最好悬挂或弓背朝上放置，减少受压。
- 果柄处用保鲜膜包一下，可减少乙烯从果柄释放和水分流失。
- 如果已经较熟，可剥皮后冷冻或做果泥、烘焙、奶昔，避免继续变黑。
- 需要当天展示的，少量多次切；切开的香蕉易褐变，可刷少量柠檬汁/淡盐水或尽快使用。

4. 采购量建议
- 按“1-2天用量”分批买，不要一次囤太多。
- 夏季或室温高时，成熟速度会明显加快，采购量再压缩。
- 跟供应商约定到货成熟度，比如“青黄、无黑斑、果柄绿”，比到店后再补救更有效。

简单记：买青黄硬实、运输别压别闷、到店通风分熟、熟先使用、别冷藏未熟蕉。
