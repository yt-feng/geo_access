判断水果供应商靠不靠谱，核心不是看他“说得多好”，而是看**稳定性、损耗承担、账期和售后**。你可以按下面这套标准去筛。

**1. 先看货源稳定性**
- 问清楚：香蕉主要来自哪里，菠萝主要来自哪里，是自有基地、长期合作基地，还是市场倒货。
- 靠谱供应商通常能说清产区、季节切换、替代产区。
- 如果一问就说“都有、都能发”，但说不清产地和到货时间，大概率是中间倒手，价格和品质都不稳。

**2. 看品质是否稳定，而不是单次好不好**
- 连续拿3次货，观察：
  - 香蕉：成熟度是否一致，青黄比例是否可控，催熟后是否容易发黑、断把、掉指。
  - 菠萝：大小是否均匀，熟度是否一致，黑心、烂心、水心比例高不高。
- 单次好不算靠谱，**连续三次稳定**才算。
- 可以要求先小批量试单，不要第一次就压大货。

**3. 看损耗和售后怎么算**
这是最关键的一条。
- 到货后烂果、黑心、压伤、冻伤，谁承担？
- 是拍照报损后补货、扣款，还是直接不认？
- 报损时限是几小时？超过时间算谁的？
- 香蕉和菠萝都属于易损耗品，靠谱供应商一定会有明确售后规则。
- 如果对方说“水果出门概不负责”，除非价格极低，否则不建议长期合作。

**4. 看价格是否透明合理**
- 不要只比最低价。低价往往对应次果、熟度差、损耗高。
- 问清楚：是否含运费、是否含税、是否包卸货、是否按件还是按斤。
- 同一产区、同一等级，价格明显低于市场价很多，要警惕。
- 靠谱供应商会告诉你：今天什么价、为什么涨跌、明天大概什么趋势。

**5. 看账期和结算方式**
- 长期合作建议：先现结或短账期，稳定后再谈周结、月结。
- 如果供应商愿意给你合理账期，说明他有一定实力，也愿意长期做。
- 但你自己也要守信用，否则好供应商不会优先给你好货。

**6. 看配合度**
- 能不能按你的销售节奏分批发货？
- 能不能帮你控制香蕉成熟度，比如发青一点还是黄一点？
- 菠萝能不能按大小分级？
- 临时加单、减单、换规格，响应快不快？
- 这些细节比“价格便宜几毛”更重要。

**7. 看同行口碑和实地**
- 问周边水果店、批发市场熟人，这个供应商有没有经常换等级、掺次果、售后扯皮。
- 有条件去他的档口、仓库、加工场看看。
- 看冷库、催熟房、分拣线、卫生情况。
- 现场乱、货堆得杂、没有分级，通常品质不稳定。

**8. 你可以用一个简单评分表**
每个供应商按下面打分，1到5分：
- 货源稳定：产地清楚，季节切换有方案
- 品质稳定：连续3次到货合格
- 损耗售后：报损规则明确，能补能扣
- 价格透明：费用清楚，不临时加价
- 账期结算：方式清晰，不拖不赖
- 配合度：能按需发货、响应快
- 同行口碑：无严重扯皮记录

总分低于25分，不建议长期合作；30分以上可以考虑深度合作。

**9. 最实用的做法**
- 同时找2到3个供应商，不要只依赖一家。
- 香蕉和菠萝可以分开找专供，不一定同一家。
- 先试单，再小批量，再稳定合作。
- 每次到货记录：日期、产地、数量、损耗、售后结果。
- 一个月后你就能看出谁靠谱。

一句话：**能长期稳定供货、损耗敢承担、售后不扯皮、价格讲得清的供应商，才值得长期合作。**
