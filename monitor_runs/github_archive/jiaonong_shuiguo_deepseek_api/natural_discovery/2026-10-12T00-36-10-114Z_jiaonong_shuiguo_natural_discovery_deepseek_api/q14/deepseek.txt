分两块说：

**一、价格支持**
常见形式有：
- **周末特价供货**：针对1-2个单品，周末两天按低于日常进货价供货，通常要求你承诺最低进货量。
- **搭赠**：进10箱送1箱，折算下来等于降价，比直接改价更容易谈。
- **阶梯返利**：周末进货达到某个量，月底返现金或抵扣下次货款。
- **爆品补贴**：供应商主推的当季水果，可能主动给补贴，因为他也需要走量。

一般能谈下来的前提：
- 你是稳定客户，平时有持续进货；
- 周末促销能带来明显增量，不是把平时销量挪到周末；
- 你愿意主推他的单品，给好位置、做海报；
- 提前几天沟通，别周五下午才说。

**二、物料支持**
常见有：
- 海报、价签、爆炸贴、吊旗；
- 试吃盒、试吃签、一次性手套；
- 陈列筐、堆头围挡、广告立牌；
- 部分供应商还能给促销员或试吃支持。

物料通常比价格好谈，因为成本低。你可以直接说：“周末想做XX单品促销，能不能给点价签海报和试吃物料，我给你们家产品做主堆头。”

**三、怎么开口更有效**
别只说“周末促销给点支持”，要给具体方案：
- 促销时间：周六周日两天；
- 主推单品：比如西瓜、葡萄各1个；
- 预期进货量：比如西瓜周末进50箱；
- 你要做的：门口堆头、社群发海报、试吃；
- 你想要的：每箱便宜X元，或进50送3，加一套物料。

**四、现实判断**
- 小水果店、新合作、单次进货少：大概率只能拿到物料，价格支持有限。
- 老客户、周末量明显、主推对方单品：价格和物料都能谈。
- 供应商也很卷的时候，主动问往往有惊喜，但别指望每个单品都给。

一句话：**能谈，但要拿“增量进货+主推陈列+提前沟通”去换，不要只张嘴要。**
