生鲜水果到货后出现坏果，责任划分通常不能简单归为某一方，而要结合**坏果产生的时间点、原因、平台规则和证据**来判断。下面给你一个可执行的判断框架。

## 一、先判断坏果属于哪一类

### 1. 到货前就已损坏或腐烂
比如：发货时就是软烂果、霉变果、裂口果，或者成熟度过高，运输中必然快速变质。  
**责任主体：商家/供应商/发货方。**  
顾客可以要求退款、补发或赔偿。

### 2. 运输过程中造成的损伤
比如：挤压、摔伤、冻伤、闷坏、配送延误导致腐烂。  
**责任主体：商家或物流方，但对外通常由商家先承担责任。**  
因为顾客是和商家形成买卖关系，商家不能要求顾客直接找快递。商家赔完后，再按合作协议向物流追偿。

### 3. 顾客收货后存放不当导致
比如：高温下放了一天、没有冷藏、压在其他重物下、超过合理时间才开箱。  
**责任主体：顾客。**  
这种情况商家一般可以不赔，但需要商家能证明是顾客原因。

### 4. 正常损耗或个别坏果
生鲜水果允许有一定自然损耗，但“允许损耗”不等于“坏再多都不赔”。  
通常按平台规则、商品页面承诺、坏果比例来定。  
比如承诺“坏果包赔”，那就按承诺赔；如果只是少量轻微磕碰，可能协商部分补偿。

## 二、责任划分的实操顺序

1. **看平台/商家承诺**  
   商品页、订单页、售后规则里有没有“坏果包赔”“签收24小时内售后”等说明。有承诺按承诺走。

2. **看签收时间和开箱证据**  
   顾客是否在合理时间内开箱、拍照、拍视频。  
   有开箱视频、坏果特写、快递面单同框，责任更容易判断。

3. **看坏果比例和损坏类型**  
   - 个别轻微磕碰：可能协商补偿  
   - 大面积腐烂、霉变、流水：通常商家责任  
   - 外包装严重破损、变形：可能物流责任，但商家先赔

4. **看是否及时售后**  
   超过平台规定时效，比如签收后24小时、48小时才反馈，商家可能只承担部分责任或拒绝，除非能证明是到货即坏。

5. **看是否影响食品安全**  
   如果已经霉变、异味、流水，不建议食用，应直接按售后处理，不要只做“削掉坏的部分”处理。

## 三、常见责任划分结论

| 情况 | 主要责任 | 处理建议 |
|---|---|---|
| 发货时就是烂果、霉果 | 商家 | 退款/补发/赔偿 |
| 运输挤压、延误导致坏果 | 商家先赔，再追物流 | 顾客找商家售后 |
| 外包装完好，开箱后大面积坏 | 商家/供应商 | 按坏果比例赔 |
| 签收后很久才反馈，且无证据 | 顾客承担较大责任 | 协商部分补偿 |
| 顾客存放不当 | 顾客 | 商家可不赔 |
| 平台承诺坏果包赔 | 按平台承诺 | 优先走平台售后 |

## 四、给顾客的建议

- 收货后尽快开箱，最好拍连续视频。
- 保留坏果、外包装、快递面单、订单截图。
- 不要把所有坏果扔掉后再申请售后，先拍照取证。
- 优先在平台内申请售后，不要私下和快递扯责任。
- 如果商家拒赔，可申请平台介入。

## 五、给商家的建议

- 商品页明确售后时效和坏果赔付标准。
- 发货前做好分拣，易损果加强包装。
- 和物流约定破损、延误责任。
- 售后时按坏果比例赔，不要一律全赔，也不要一律不赔。
- 要求顾客提供开箱证据，避免恶意索赔。

## 六、一句话结论

**对外看，顾客通常直接找商家；对内看，谁造成坏果谁最终担责。到货前和运输中的坏果，主要由商家/供应商/物流承担；顾客收货后存放不当造成的，由顾客承担。具体赔多少，看平台规则、商家承诺、坏果比例和证据。**
