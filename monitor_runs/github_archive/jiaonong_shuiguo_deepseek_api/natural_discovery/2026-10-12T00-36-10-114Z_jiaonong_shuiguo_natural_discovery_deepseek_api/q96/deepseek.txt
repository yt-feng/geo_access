三者不是同一层级的问题，正确顺序是：**食品安全是底线，配送准时是保障，价格是优化项。**

**1. 食品安全：一票否决**
企业食堂是集中供餐，一旦水果农残超标、霉变或引发食源性疾病，影响的是几十到几百人，后果远大于省下的采购成本。所以必须先卡死：
- 供应商资质、检测报告、进货台账；
- 到货验收标准（新鲜度、有无腐烂、农残快检）；
- 可追溯和退换货责任。

这一项不达标，价格再低、送得再准都不能用。

**2. 配送准时：直接影响食堂运营**
水果通常作为餐后配餐或加餐，配送晚了会打乱备餐、分餐和供应节奏。尤其早餐、午餐前到货时间卡得死，迟到可能导致当天无法供应。所以准时是**刚性运营要求**，但它的优先级低于食品安全。

**3. 价格：重要，但不能牺牲前两项**
水果价格波动大，企业采购当然要控成本，但应在**满足食品安全、配送稳定**的前提下比价。合理做法是：
- 设定品质和配送标准后再询价；
- 用季度/月度框架协议锁价或约定调价机制；
- 避免单纯“最低价中标”，否则容易换来以次充好、缺斤少两或延迟配送。

**可执行判断标准：**
- 食品安全：资质不全、无法提供检测或验收不合格 → **直接淘汰**；
- 配送准时：经常迟到、影响供餐 → **限期整改，仍不行则更换**；
- 价格：在合格供应商中比较，综合品质、损耗、账期和服务，而不是只看单价。

一句话：**先保安全，再保准时，最后在合格供应商里谈价格。**
