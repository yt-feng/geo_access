如果只能选一个最优先的，选**保质期管理**。但实际运营里这三者是连在一起的，不能只抓一个。

简单判断：

1. **保质期是底线**
   - 菠萝切块属于鲜切水果，风险在微生物繁殖和氧化变质。
   - 便利店通常不是现切现卖，而是门店冷藏售卖，所以必须明确：
     - 切块后冷藏能放多久
     - 超过多久必须下架
     - 是否按“制作时间+小时数”贴标签
   - 如果保质期失控，包装再好、配送再勤也会出食品安全问题。

2. **包装决定保质期能不能稳住**
   - 普通敞口盒、保鲜膜随便包，失水、氧化、串味都快。
   - 合适的是：食品级密封盒或真空/气调包装，冷藏条件下能明显延长品质。
   - 包装还影响是否方便贴标签、是否容易挤压出水、是否看起来干净。
   - 所以包装不是第一优先级，但它是保质期的支撑条件。

3. **配送频次决定门店要不要压货**
   - 如果配送频次高，门店可以少备货、勤补货，临期压力小。
   - 如果配送频次低，门店就会一次进很多，保质期风险立刻变大。
   - 所以配送频次是“降低过期风险”的运营手段，不是核心指标本身。

**可执行结论：**

- 第一优先：**定死保质期规则**，比如冷藏条件下几小时内必须售完、到期直接报损。
- 第二优先：**用对包装**，保证在保质期内品质稳定。
- 第三优先：**根据销量调配送频次**，卖得快就勤配，卖得慢就少配或缩小包装。

如果只问“最该关注哪个”，答案是：**保质期**。  
如果问“怎么落地”，答案是：**保质期定规则，包装保品质，配送频次控库存。**
