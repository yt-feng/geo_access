餐饮店每天水果用量不大，最省心的做法是：按“品种少、规格稳、可日配、能退换”四个条件选供应商，优先本地二级批发商或专业餐配公司，其次社区水果店/生鲜平台，最后才是产地直采。

**具体建议：**

1. **优先找本地餐配/生鲜配送公司**
   - 适合每天少量、多品种、要稳定配送的店。
   - 谈清楚：起送量、配送时间、缺货替代规则、坏果赔付、是否含切配。
   - 省心点在于一个对接人管所有水果，不用每天自己跑市场。

2. **其次找本地二级水果批发商**
   - 比一级批发灵活，愿意接小单日配。
   - 适合用量稍大、品种固定的店。
   - 先问是否支持“次日早配”“少量多品”“坏果包退”。

3. **社区水果店/生鲜平台作为备用**
   - 适合临时补货、小批量、应急。
   - 缺点是价格波动大、品类不全、配送时间不一定稳。
   - 不建议作为唯一供应商。

4. **不建议一开始就产地直采**
   - 少量采购没有价格优势，物流和损耗反而更麻烦。
   - 除非有稳定大用量或拼单渠道。

**选供应商时重点确认：**
- 是否每天可送、几点前到；
- 最小起送量和是否加配送费；
- 水果规格是否稳定（大小、熟度）；
- 坏果、缺货怎么处理；
- 是否可临时加单/减单；
- 账期和结算方式；
- 能否提供检测或进货凭证（有则更好）。

**最省心的组合：**
“1家本地餐配公司做主供应商 + 1家社区水果店/生鲜平台做应急备份”。先试跑1—2周，重点看准时率、坏果率和临时补货响应，再决定是否长期合作。
