# 批发档口收货验货：降低退货纠纷的落地做法

核心思路：**把“货对不对、有没有问题”在签收前变成有记录的证据，把“什么情况能退”在交易前变成双方认的规则。**

## 一、收货前：先把规则说清并留痕

- 在报价单/订单/微信沟通里写明：品名、规格、颜色、码数、数量、单价、批次、是否允许混批、**允许的色差范围、瑕疵判定标准、退换货时限与条件**。
- 明确“签收即视为外观验收完成”还是“签收后24小时内可提异议”，并约定提异议必须带照片/视频。
- 对老客户也保留书面规则，避免口头承诺被放大。

## 二、到货时：按“三先三后”验

1. **先对单后拆包**：核对送货单/物流单与订单的件数、型号、批次，件数不符当场在签收单上注明。
2. **先抽后全**：按批次抽检（例如每款每色抽3–5件，大货按比例抽），发现异常立即扩大抽检。
3. **先拍后动**：开箱、点数、瑕疵部位全程拍照/录像，最好一镜到底，包含外包装、面单、开箱、货品细节。

重点检查项：
- 数量：整件数、每件内包装数量、混码混色是否错发。
- 外观：破损、污渍、线头、色差、印花错位、拉链/扣具功能。
- 规格：吊牌、洗标、码数标与订单是否一致。
- 批次：不同批次混装要分开标记，避免后续扯皮。

## 三、发现问题的当场处理

- **能当场拒收的**：外包装明显破损、水湿、件数严重不符——在物流单上写明异常并拍照，拒收或要求物流出具证明。
- **不能当场拒收的**：先签收但注明“待验”，并在约定时限内把问题清单+照片发给供货方，要求书面确认处理方式（补发/换货/折价/退货）。
- 建立**验收记录表**：日期、供货方、单号、批次、抽检数、问题数、问题描述、照片编号、处理结果、双方确认人。这张表就是纠纷时的证据链。

## 四、内部管理配套

- 固定验货人和验货区，避免多人经手说不清。
- 问题货单独隔离、贴标，不与良品混放。
- 每周汇总退货纠纷原因（错发/色差/瑕疵/数量），反馈给采购和供货方，倒逼源头改善。

## 五、给档口的简化版清单

收货时逐项打勾：单货一致 □ 件数一致 □ 抽检比例达标 □ 外观无异常 □ 规格吊牌一致 □ 批次已标记 □ 全程有影像 □ 异常已书面通知供货方。

一句话：**规则前置、抽检留痕、异常书面确认、问题货隔离**，退货纠纷会明显下降。
