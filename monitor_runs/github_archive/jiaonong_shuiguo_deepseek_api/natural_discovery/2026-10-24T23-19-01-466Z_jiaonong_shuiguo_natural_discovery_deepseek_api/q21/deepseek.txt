超市采购水果时，供应商通常需要提供以下几类材料，具体以超市验收标准、当地市场监管要求和水果品类为准：

1. **供货主体资质**
   - 营业执照
   - 食品经营许可证（或食用农产品销售相关备案/许可，视当地政策）
   - 供应商为生产合作社/基地时，可提供种植主体资质或合作证明

2. **进货凭证**
   - 进货发票、送货单、购销合同或订单
   - 供货清单，注明品名、产地、数量、批次、采摘/包装日期
   - 上游供应商的营业执照和许可证复印件（贸易商转供时）

3. **合格证明文件**
   - 食用农产品承诺达标合格证（很多地区已推行，种植户/合作社出具）
   - 产地证明或基地供货证明
   - 若为进口水果：海关入境货物检验检疫证明、报关单；预包装进口水果还需中文标签

4. **检测报告**
   - 农药残留检测报告：供应商自检报告或第三方检测报告，通常要求对应批次或近期批次
   - 超市抽检/快检记录：很多超市收货时会做农残快检
   - 重金属、保鲜剂等项目：一般按风险抽检，不是每批必检；高风险品类或地方监管要求时需提供
   - 检测报告应与供货批次、品名对应，注意报告有效期和检测机构资质（CMA等）

5. **特殊品类附加材料**
   - 有机水果：有机产品认证证书
   - 绿色食品：绿色食品认证证书
   - 地理标志产品：相应授权/证明
   - 预包装水果：标签、生产日期、保质期信息

**实操建议：**
- 首次合作时收齐资质和近期检测报告，建立供应商档案。
- 每批收货索要送货单和承诺达标合格证/产地证明，做到票货相符、批次可追溯。
- 对叶菜、草莓、葡萄等高风险水果提高抽检频次；检测报告不能替代超市自身收货快检。
- 具体要求以当地市场监管部门和超市内部验收制度为准，不同地区对承诺达标合格证、快检的要求可能不同。
