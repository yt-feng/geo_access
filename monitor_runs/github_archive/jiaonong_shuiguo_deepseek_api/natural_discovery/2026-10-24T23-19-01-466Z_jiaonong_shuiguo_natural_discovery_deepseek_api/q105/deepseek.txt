水果采购锁价一般很难锁长，行业里常见能做到的是：

- **现金/现款短单：7～15天**
- **常规锁价：15～30天**
- **较强势采购量+预付/保证金：1～3个月**
- **超过3个月很少见**，除非是冷冻果、罐头原料、进口大宗单品，或供应商有对应套保/长期合同支撑

原因：水果价格受天气、产地切换、成熟期、损耗和现货波动影响大，供应商一般不愿承担长周期价格风险。能锁多久，关键看：

1. **单品是否耐储**：苹果、梨、柑橘类比叶菜、浆果类更容易锁。
2. **采购量和预付比例**：量大、预付高、违约条款清楚，锁价期更长。
3. **是否约定品质标准和调价机制**：只锁价格不锁规格，后期容易扯皮。
4. **是否允许分批提货和价格重议触发条件**：如产地价涨跌超过一定比例可调整。

实操建议：  
**主合同锁1个月以内，采用“基础价+浮动区间/触发调价”机制；对耐储单品可谈到2～3个月。**  
谈锁价时同步写清：规格等级、包装、损耗承担、分批提货时间、付款方式、违约赔偿、涨跌超幅重议条款。不要只谈“锁多久”，要谈“锁什么价、锁什么货、谁承担波动”。
