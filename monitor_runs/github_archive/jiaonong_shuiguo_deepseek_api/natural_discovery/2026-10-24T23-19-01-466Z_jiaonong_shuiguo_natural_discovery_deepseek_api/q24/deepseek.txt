建议把“资料核验”和“到货自检”分开做。向供应商要资料时，优先要能对应到具体批次和品项的文件，不要只要一张泛泛的承诺函。

**一、优先索取的资料**
1. **批次对应的检测报告**
   - 要求报告上的品名、产地、供应商/生产主体、抽样日期、检测项目、检测结论，能和你采购的这一批次对应。
   - 重点看是否包含常见高风险农残项目，以及检测机构资质标识（如CMA/CNAS）。
   - 注意报告日期不要过久，最好是近期或本产季/本批次。
2. **产地证明或供货证明**
   - 产地证明、基地供货证明、合作社/种植户供货凭证，用来核对报告与货源是否一致。
3. **供应商资质**
   - 营业执照、食品经营许可证（如适用）、上游种植/合作社资质。
4. **承诺书/质量保证协议**
   - 写明农残超标责任、退换货和赔偿条款。承诺书不能替代检测报告，但可作为合同依据。
5. **用药与采收记录（能要到更好）**
   - 特别是基地直供或高风险品类，可要求提供农药使用记录、安全间隔期执行记录。

**二、到货时要做的核验**
- 核对检测报告与到货批次、品名、产地是否一致。
- 保留样品和到货记录，必要时送第三方快检或定量检测。
- 对叶菜、草莓、豇豆等高风险品类提高抽检频率。
- 合同中约定：抽检不合格的退货、销毁、赔偿及复检费用承担。

**三、判断标准**
如果供应商只能提供“合格证”或口头保证，不能提供批次检测报告和产地对应信息，建议不要直接放行高风险品类；至少要求补检或换有批次报告的供应商。资料的核心不是“有没有”，而是“能不能对得上这一批货”。
