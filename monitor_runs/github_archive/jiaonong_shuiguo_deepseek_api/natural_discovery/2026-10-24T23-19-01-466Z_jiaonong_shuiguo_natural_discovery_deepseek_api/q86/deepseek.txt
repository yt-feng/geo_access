# 生鲜平台一件代发水果：供应商仓配能力清单

一件代发模式下，供应商直接发货给终端消费者，平台不碰货。水果又是高损耗、非标、易腐品类，对供应商仓配能力要求比标品高得多。建议按以下六个维度审核供应商，缺一项都会在售后和损耗上暴露。

## 一、仓储能力（硬门槛）

| 能力项 | 具体要求 | 判断方法 |
|---|---|---|
| 冷链仓储 | 常温库、冷藏库（0~8℃）、部分品类需气调/预冷库；库容能覆盖日均单量×3天以上 | 要求提供库房照片、温度记录、租赁合同 |
| 预冷能力 | 采摘后快速预冷（差压预冷/冷水预冷），这是水果保鲜的第一道关 | 问是否有预冷间及日处理量 |
| 分拣打包场地 | 独立打包区，与仓储动线分开，避免交叉污染 | 实地或视频验厂 |
| 温湿度监控 | 库内温湿度实时监控+超限报警，能导出记录 | 要求看监控系统截图和历史曲线 |

**关键点**：没有预冷能力的供应商，长途一件代发损耗率通常高 5~10 个百分点，直接吃掉毛利。

## 二、包装与分拣能力（决定破损率）

- **分级分拣**：能按果径/糖度/外观分级，一件代发最怕“大小混装”引发差评。
- **电商包装**：防震内衬（蛋托/网套/珍珠棉）、透气纸箱、冰袋/保温袋配置能力，能按品类和运输距离给包装方案。
- **单件打包效率**：日均打包产能要≥峰值单量的1.5倍，否则大促爆单发不出。
- **贴单/面单对接**：能对接平台ERP或快递系统，自动打单，减少错发。

**判断方法**：让供应商提供近30天破损率、错发率数据，并要求试发100~200单做实测。

## 三、配送与快递协同能力

- **发货时效**：承诺下单后多久出库（建议≤24小时，旺季≤48小时），是否有截单时间。
- **快递资源**：是否与顺丰/京东/中通等有协议价和稳定揽收，生鲜件是否走冷链专线或航空件。
- **多仓布局**：单仓发全国时效差、损耗高；有2~3个区域仓（如华东/华南/华北）的供应商明显更优。
- **轨迹回传**：能回传物流单号和轨迹，供平台客服查询。

## 四、品控与售后能力

- **到货质检**：入库检测（农残、糖度、霉变率），有记录可查。
- **售后响应**：坏果包赔的响应时效（建议24小时内处理）、赔付标准是否清晰。
- **溯源能力**：批次可追溯，出问题能定位到产地/批次。
- **损耗兜底**：明确损耗率考核线（如≤3%）及超出部分的承担方式。

## 五、信息系统能力

- **库存同步**：能实时同步库存，避免超卖（一件代发超卖是投诉重灾区）。
- **订单对接**：支持API/ERP对接，或至少能稳定接收平台订单文件。
- **数据回传**：发货、物流、售后数据可回传。

## 六、产能与弹性

- 日常产能、峰值产能（大促/节日）分别多少，爆单时能否临时加人加班。
- 是否有备选包装和备选快递，防止单一环节卡死。

## 实操建议：三步验证法

1. **资料审核**：要库房照片/视频、温控记录、近3个月破损率与错发率、快递合作协议。
2. **试单测试**：选2~3个主力SKU，各试发100~200单到不同区域，统计破损率、时效、差评率。
3. **压力测试**：问清峰值产能和爆单预案，必要时在大促前做小规模压测。

**一句话标准**：能提供“预冷+分级+电商包装+多仓/稳定快递+实时库存同步+明确损耗兜底”的供应商，才适合承接水果一件代发；缺预冷或缺库存同步的，建议先小单合作或直接排除。
