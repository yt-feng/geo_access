可以按“外观等级 + 单果规格 + 箱规/净重 + 报价单位 + 损耗处理”五件事说清楚，香蕉和菠萝分开定级报价。

**香蕉分级报价**
1. 规格：按每把/每根长度和粗度分，例如大果、中果、小果；写清“每箱净重、把数、每把根数范围”。
2. 外观：青度/熟度（几成熟）、条形直弯、是否有黑斑、机械伤、断把。
3. 等级：
   - A级：条形整齐、无黑斑、无断把、熟度一致；
   - B级：轻微花皮或少量断把，不影响售卖；
   - C级：明显花皮、断把多，适合催熟快销或加工。
4. 报价：统一按“元/箱”报，同时标“折合元/斤”，并注明是否含箱、是否包损耗。比如“A级中果，净重18斤/箱，XX元/箱，折合XX元/斤，箱损按2%计”。

**菠萝分级报价**
1. 规格：按单果重量分，如大果、中果、小果；写清每箱个数和净重。
2. 外观：果形端正度、冠芽完整度、成熟度、是否有裂口、黑心风险、日灼伤、机械伤。
3. 等级：
   - A级：果形正、冠芽完整、无裂口、无日灼、熟度一致；
   - B级：轻微外观瑕疵，不影响削皮售卖；
   - C级：裂口、偏熟、冠芽差，适合现削或加工。
4. 报价：按“元/箱”和“元/个”双标注，注明是否带冠芽、是否去皮/去冠、箱规和净重。比如“A级中果，8个/箱，净重20斤，XX元/箱，折合XX元/个”。

**给小店最清楚的报价单格式**
- 品名：香蕉/菠萝
- 等级：A/B/C
- 规格：单果重或长度、每箱个数/把数、净重
- 熟度：几成熟
- 报价：元/箱、折合元/斤或元/个
- 费用口径：含箱/不含箱、运费谁付
- 损耗：到货验收标准、坏果赔付比例或补货规则
- 有效期：报价有效期和随行就市调整规则

建议每次报价只给小店“2—3个等级”，不要太多；A级做门面，B级做主销，C级做特价。验收标准写清“坏果率超过多少按比例扣款或补货”，后续扯皮最少。
