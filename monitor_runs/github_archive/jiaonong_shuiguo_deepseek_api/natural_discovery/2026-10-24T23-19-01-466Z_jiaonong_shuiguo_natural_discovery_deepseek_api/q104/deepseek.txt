单位采购水果到货品质不一致，核心是**验收时把“批次、比例、证据”固定下来，售后按合同/订单约定走书面流程**。建议按下面做：

## 一、到货前先定标准
采购单/合同里尽量写清：
- 品种、规格（单果重/果径）、等级、成熟度、产地
- 允许差异比例，例如“不合格果不超过5%”
- 验收方式：抽检比例、抽检方法
- 售后条款：补货、换货、退款、扣款的计算方式
- 到货时限和响应时限

没有书面标准的，至少用订单、聊天记录、样品照片确认，避免事后扯皮。

## 二、到货验收怎么做
1. **先看批次一致性**：不同箱/不同批次分开抽检，不要只抽一箱代表全部。
2. **分层抽样**：上中下层、内外包装都抽；按到货总箱数抽5%–10%，少于10箱可全检或每箱抽。
3. **现场记录**：
   - 拍全景、箱唛、批次号、生产/采摘日期
   - 拍不合格果特写，旁边放参照物
   - 称重、计数，记录不合格数量和比例
4. **分类判定**：
   - 轻微差异（大小、色泽略有不同）：可让步接收，按比例扣款
   - 明显品质问题（腐烂、霉变、压伤、未熟/过熟、异味）：拒收该批次或要求换货
   - 混批：按最差批次判定，或要求供应商分拣后重新送货
5. **双方签字确认**：验收单上写清到货数量、抽检数量、不合格数量、处理意见，送货人签字；对方不签的，拍照录像并当场发书面通知。

## 三、售后怎么处理
1. **当天书面反馈**：把验收单、照片、视频、抽检数据发给供应商，明确诉求：补货/换货/退款/扣款。
2. **按比例主张**：合同有约定的按约定；没约定的，按不合格比例对应货款扣减，腐烂变质部分要求全额退换。
3. **时限要求**：要求供应商在24–48小时内答复并给出处理方案；生鲜易腐，越早处理越有利。
4. **留样**：有争议的批次留样封存，拍照标注日期，必要时送第三方检测。
5. **多次不合格的供应商**：累计记录，纳入供应商评价，后续减少订单或要求整改。

## 四、避免踩坑
- 不要先签收再慢慢验，签收前完成抽检和记录。
- 不要只口头沟通，所有差异用文字+照片确认。
- 不要混放：不合格品单独隔离，避免污染合格品。
- 验收标准提前发给供应商，让对方知道你会怎么验。

一句话：**验收靠抽检记录和照片，售后靠书面通知和合同比例**。标准越前置，售后越简单。
