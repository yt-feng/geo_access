建议先从**香蕉**开始，但前提是你把“稳定”理解为**供应稳定、损耗可控、周转快**，而不是“毛利最高”。如果超市完全没有进口水果经验，更稳的顺序是：

**香蕉 → 苹果 → 菠萝**

理由如下：

1. **香蕉最适合做进口水果的入门品类**
   - 周转快，消费频次高，顾客接受度高。
   - 进口香蕉供应链成熟，很多供应商能做催熟、配送、陈列支持。
   - 单价低，试错成本小。
   - 但香蕉对温湿度和催熟管理要求高，必须找能稳定供货、能指导催熟的供应商，否则容易出现青黄不接或过熟损耗。

2. **苹果适合第二步**
   - 耐储存、损耗低、规格稳定，适合建立进口水果的稳定陈列。
   - 但进口苹果价格带较高，消费者对品种和产地有认知门槛，动销不如香蕉快。
   - 适合在香蕉跑通后，用来提升客单价和品类形象。

3. **菠萝不建议作为第一个品类**
   - 菠萝损耗和操作要求较高，去皮、成熟度、售后都更复杂。
   - 消费者对进口菠萝的品种认知不如香蕉、苹果普遍。
   - 除非你的门店已有较强的果切/试吃/现场服务能力，否则先做菠萝风险更高。

**可执行建议：**
- 先小批量引入进口香蕉，选1—2个稳定供应商，测试2—4周动销和损耗。
- 同步要求供应商提供催熟、陈列、损耗处理方案。
- 香蕉跑通后，再增加1—2个进口苹果SKU。
- 菠萝等前两类稳定后，以小批量果切或试吃方式引入。

一句话：**想稳，先香蕉；想低损耗，苹果第二；菠萝最后。**
