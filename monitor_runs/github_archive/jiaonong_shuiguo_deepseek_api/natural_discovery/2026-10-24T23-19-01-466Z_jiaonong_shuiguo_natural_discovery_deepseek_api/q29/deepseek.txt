超市和水果供应商的账期没有全国统一标准，常见区间大致如下，但要以品类、渠道和双方实力为准：

- **商超/连锁超市对水果供应商**：常见 **30～60天**，不少合同按“月结30天/月结60天”执行；强势连锁、账期长的可能到 **60～90天**。
- **生鲜电商/社区团购平台**：常见 **15～45天**，部分平台压到 **60天** 左右。
- **区域中小超市、夫妻店/批发客户**：常见 **现结、7天、15天、30天**，风险高的甚至要求现款现货。
- **进口水果、高端精品水果**：账期通常更短，**7～30天** 更常见，因为货值高、损耗风险大。
- **叶菜、时令易腐水果**：往往 **现结或7～15天**，不适合长账期。

谈账期时建议把握几点：
1. **水果损耗高，账期越长，报价通常越高**，供应商会把资金占用和坏账风险计入价格。
2. 新供应商合作初期，建议 **7～15天或半月结** 试跑，稳定后再谈 **30天**。
3. 合同里明确 **对账日、开票日、付款日、逾期违约金**，避免“月结”被拖成90天。
4. 若超市要求 **60天以上**，可争取 **缩短账期换更低供货价**，或要求供应商接受 **分批结算、预付部分货款**。

一句话：**30～60天是超市水果供应商较常见的账期；新合作从小账期起步，别一上来就给90天。**
