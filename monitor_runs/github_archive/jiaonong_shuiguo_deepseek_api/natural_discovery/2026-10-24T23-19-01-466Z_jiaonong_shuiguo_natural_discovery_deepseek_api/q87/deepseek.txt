旺季锁水果库存，核心是**把“口头预留”变成“有约束的合同+分批锁定+替代预案”**，而不是一次性押注一个供应商。建议按下面顺序做：

**1. 先做销量预测和分级，不要凭感觉报量**
- 用近2年同期销量+近4周增速，按品类（如柑橘、苹果、草莓、车厘子）拆到周。
- 给每个SKU定三档：保底量（必拿）、目标量（争取）、上限量（爆单才追加）。
- 只对保底量做硬锁定，目标量用框架协议，上限量留替代供应商。

**2. 提前2–4周签“锁量不锁死”的采购协议**
关键条款要写清：
- **锁量**：具体品种、规格、等级、周供货量、最晚提货时间；
- **价格机制**：固定价+浮动区间，或随行就市但设上限；
- **定金/预付款**：付10%–30%定金换优先供货权，尾款按批结；
- **违约条款**：供应商缺货按差价或违约金赔，你方不提货定金不退或按比例扣；
- **质量标准**：糖度、单果重、坏果率、包装规格，验收不合格可拒收且不计入锁量。

**3. 分批锁、滚动锁，别一次锁满季**
- 第一周锁保底量的60%–70%，留30%看实际动销；
- 每周根据团购开团数据滚动追加下周量；
- 对易腐水果（草莓、荔枝）缩短锁定期，只锁3–5天，避免砸手里。

**4. 用“预付款+包销”换优先权**
旺季供应商最怕你临时砍单。可以承诺：
- 对核心单品做**保底包销**，比如“本周至少提X吨”；
- 提前打款，换供应商把货优先留给你；
- 但包销量不超过你保底预测的80%，防止滞销。

**5. 至少备2–3家供应商，做替代清单**
- 主供应商占60%–70%，备选占20%–30%，再留10%现货市场应急；
- 提前确认备选供应商的产地、冷库、物流能力；
- 对同一单品准备可替换品种（如某柑橘缺货换另一产区），写进团购页面预案。

**6. 物流和仓配也要锁**
水果爆单卡点常在冷链和分拣。提前锁定：
- 冷库库容和分拣时段；
- 干线车辆和到仓时间；
- 到货验收人手，避免货到了卸不下、验不完。

**7. 每天盯三个数**
- 供应商确认可发量 vs 你承诺给团长的量；
- 在途库存和冷库库存；
- 单品动销率和损耗率。一旦动销低于预期，立即停止追加锁量，转向促销清库存。

**最简执行版**：本周做销量分档→找2–3家供应商谈“保底量+定金+违约条款”→先锁下周保底量的70%→每周滚动追加→同步锁冷库和车辆→备好替代品种。这样既拿到优先供货权，又不会因爆单预测失误被库存压死。
