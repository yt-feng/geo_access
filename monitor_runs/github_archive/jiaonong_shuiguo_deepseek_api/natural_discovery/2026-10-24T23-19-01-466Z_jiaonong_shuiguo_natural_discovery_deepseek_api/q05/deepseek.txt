结论：**默认卖整果，让顾客自己挑；把“去皮好的”作为加价便利选项，而不是主推形态。** 理由和可执行做法如下。

**为什么整果 + 自选是主力**
1. **损耗可控**：菠萝去皮后失水、氧化、变味快，卖不掉就是纯损耗；整果耐放，卖不完还能降级做果切或特价。
2. **顾客信任感强**：菠萝“生熟、甜不甜”外观差异大，让顾客自己挑能减少“你帮我挑的不好吃”的纠纷。
3. **价格锚点清楚**：整果按斤/按个卖，去皮另收加工费或按份卖，顾客容易比较，你也好算账。
4. **符合水果店消费习惯**：多数人买菠萝愿意现场挑，尤其家庭客。

**去皮好的适合谁**
- 赶时间、不会削、怕扎手的上班族；
- 买来当场吃或做果切、榨汁的顾客；
- 你店里已经有稳定果切客流时，可做“现削现卖”。

**建议的卖法（可直接执行）**
1. **整果区**：按个或按斤标价，写明品种、甜度/产地，让顾客自选；提供免费或低价代削服务（削好装盒，收1–2元加工费或满额免费）。
2. **去皮区**：只做**当天现削、小份装盒、明确标注削皮时间**，当天卖不完转果切或特价，不隔夜当鲜果卖。
3. **加价逻辑**：去皮果单价略高于整果（覆盖人工和损耗），但不要高太多，否则顾客觉得不如买整果。
4. **陈列**：整果堆头在前，去皮盒装在后，配“可免费代削”提示，把自选和便利都留住。
5. **减少纠纷**：整果可给“当场切开验坏，坏果包换”；去皮果标明“现削现卖，不退换”更合理。

一句话：**主卖整果自选，代削做服务，去皮盒装做补充；别把去皮果当主力库存。**
