采购菠萝时，核心不是“挑最熟的”，而是按你能在多长时间内卖完，分层控制熟度，把损耗压在前端。

**可直接执行的判断方法：**

1. **先定销售节奏，再定采购熟度**
   - 2～3天内能卖完：可采7～8成熟，果身微黄、果香初显。
   - 4～6天卖完：主采6～7成熟，果皮青黄相间、按下去略硬。
   - 当天现切现卖：可少量采8～9成熟，果香明显、轻按有弹性。
   - 不要一次全采同一熟度，按“当天卖、3天卖、5天卖”分三档进货。

2. **看外观：优先选“青黄过渡自然”的**
   - 果皮从底部向上由黄转青，底部略黄、上部偏青，通常耐放且后熟均匀。
   - 整果全青不一定生，但要看果眼和香气；整果金黄、果眼全平展的，通常已偏熟，适合快销。
   - 避免果皮有大块软斑、渗液、发黑、碰伤，这类损耗会快速扩大。

3. **闻香气：底部果香是重要信号**
   - 靠近果底闻，有淡淡果香：适合2～3天销售。
   - 香气明显、甜香重：已接近适售，需当天或次日主推。
   - 无香气且有青草味：偏生，可放，但要确认能后熟。
   - 有发酵味、酒味：不要采。

4. **按果身和果眼判断**
   - 轻按果身有轻微弹性、不软塌，适合近期销售。
   - 果眼饱满、间隙小，通常成熟度较好；果眼很深、果身很硬，偏生。
   - 果眼发黑、发软或有汁液，说明过熟或损伤。

5. **看冠芽和果柄**
   - 冠芽鲜绿、挺立，说明新鲜度较好；冠芽枯黄不一定是熟度问题，但耐放性差。
   - 果柄切口新鲜、无霉斑；切口发黑发软的要少采。

6. **采购时做“到店抽检”**
   - 每批随机切1～2个，看果肉颜色、汁水、中心是否发黑。
   - 中心发黑、果肉水渍状、有酒味，说明批次过熟或受冷害，后续要减量。
   - 记录批次、到货日、熟度、售罄天数，下一轮按数据调整，不要只凭感觉。

**简单分级建议：**
- **A档 6～7成熟**：青黄相间、果身硬、淡香，放2～4天，主库存。
- **B档 7～8成熟**：底部黄、果香初显、轻按微弹，2～3天卖，摆前排。
- **C档 8～9成熟**：香气明显、果身有弹性，当天现切或促销，少量采。

**损耗控制的关键：**
- 不采“全熟一批”，按销售速度分批到货。
- 到店后按熟度分筐，熟的在最前面，青的放阴凉通风处，不要堆压。
- 发现软斑、酒味、渗液的当天处理，不要等坏透再折价。
- 夏季高温、运输时间长时，整体熟度下调半档；冬季可适当上调。

一句话：**采购熟度要“看卖速、分批次、闻果底、按果身”，主采6～8成熟，少量高熟度快销，别让整批同时进入最佳食用期。**
