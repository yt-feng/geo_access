第一次找水果供货商，建议按“先试错、再放量”的方式做，别一上来就压大单。可执行的做法：

1. **先定试单品种和量**
- 香蕉：1—2箱，最容易看出催熟、青黄不匀、断指和损耗。
- 苹果：1箱，看大小是否均匀、碰伤、蜡感和口感。
- 橙子：1箱，看皮厚、干水、酸度、大小分级。
- 先只试这3样，别同时上五六种货。

2. **同城批发市场先找2—3家对比**
- 每家只拿小量，记录：报价、规格（斤/箱、大小等级）、到货时间、损耗率、是否可退换。
- 重点问清：是否包售后、坏果怎么赔、是否送货上门、起送量、账期还是现结。

3. **试单看四个硬指标**
- **到货新鲜度**：香蕉成熟度是否适合你店销量；苹果有无暗伤；橙子是否干水。
- **规格稳定性**：同一箱里大小差多少，别只看样品。
- **损耗率**：香蕉建议控制在5%以内，苹果橙子3%以内较理想；超过就压价或换供应商。
- **售后响应**：坏果拍照后是否当天补/赔，推诿的直接淘汰。

4. **试单周期**
- 连续试2—3次、间隔几天，看第二次货是否掉质量。第一次好不代表稳定。
- 每次只增加20%—30%量，稳定后再谈长期价和账期。

5. **夫妻店特别提醒**
- 别被“低价整箱”吸引，先算净重和损耗后的实际成本。
- 香蕉别一次进太多，按你店2—3天销量试；苹果橙子可稍多但也要控制。
- 所有承诺写进微信聊天记录：价格、规格、售后、送货时间。
- 现金结账优先，账期刚开始别谈太长，避免被绑住。

简单判断标准：**同一供应商连续3次到货，损耗可控、售后不扯皮、规格稳定，再考虑放大采购；有一次明显掉链子就换。**
