# 进货量不大，优先考虑固定供应商 + 批发市场作为补充

**直接结论：小店、进货量不大，优先找固定的二批商（固定供应商），批发市场用来补货和比价。**

原因很实际：

**1. 固定供应商更适合小量**
批发市场很多档口有起批量，量小拿不到好价，还可能被"看人下菜"。固定二批商本来就做小客户生意，起订量低，可以小批量多次进。

**2. 小店的命门是压货和现金流**
进货量不大，最怕一次压一批卖不动。固定供应商能谈"少量多次、按需补货"，降低库存风险和资金占用。

**3. 账期和退换货**
固定供应商混熟了可以谈账期、临期调换、少量补货；批发市场基本一手交钱一手交货，退换难。

**4. 批发市场的真正价值**
- 新品试销、看行情、比价格；
- 固定供应商缺货时的应急补货；
- 早期摸底、锁定靠谱供应商的渠道（逛市场是为了找"固定供应商"，不是一直逛）。

**怎么落地：**
- 先跑批发市场 2–3 次，摸清品类、价格带和几个靠谱档口；
- 从中挑 1–2 家转成长期合作，固定送货、谈小批量；
- 日常以固定供应商为主，批发市场每月逛一次比价、看新品；
- 别只绑一家，主供应商 + 备用供应商各留一个，防止断货和被拿捏。

**例外情况**：如果是季节性、款式变化快的货（如应季饰品、时令商品），批发市场的灵活性和上新速度更重要，可以偏重市场拿货；如果是标准化、复购稳定的日用货，固定供应商明显更划算。

一句话：**用小批量把固定供应商养熟，用批发市场保持信息灵通和价格压力，两者不冲突。**
