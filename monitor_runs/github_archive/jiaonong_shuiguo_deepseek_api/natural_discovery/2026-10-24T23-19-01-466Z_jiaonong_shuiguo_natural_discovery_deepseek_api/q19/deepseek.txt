优先关注**切果损耗**，其次**甜度**，再看**大小和外观**。理由很直接：超市卖菠萝真正赚钱靠的是可售果肉和损耗控制，不是单看外观。

具体判断顺序：

1. **切果损耗（第一优先）**
   - 看去皮去眼后的出肉率、坏心黑心比例、尾部腐烂、机械伤。
   - 同样进货价，出肉率高几个点，毛利差异很大。
   - 建议按批次抽切记录：出肉率、报废率、客诉率。损耗高的供应商直接降级。

2. **甜度（第二优先）**
   - 菠萝是口感型水果，甜度不够会直接压复购。
   - 不用追求极高糖度，但要稳定；酸涩、水味重会拉低复购。
   - 可结合品种和成熟度判断，避免为了耐放进太生的货。

3. **大小（第三优先）**
   - 大小影响定价和客群：家庭装偏大，即食/小家庭偏中小果。
   - 大小均匀利于陈列和定价，但不是核心利润点。

4. **外观（最后，但不能忽略）**
   - 外观影响首次购买和陈列卖相，但不是决定复购的关键。
   - 只要无明显腐烂、严重磕碰、畸形过度即可；过度追求外观会推高进货成本。

**可执行结论：**
- 采购标准写成：**出肉率/坏果率一票否决，甜度设最低线，大小分规格，外观只做底线要求。**
- 如果只能盯一个指标：盯**切果损耗和坏果率**；如果做即食切片，损耗权重还要再提高。
