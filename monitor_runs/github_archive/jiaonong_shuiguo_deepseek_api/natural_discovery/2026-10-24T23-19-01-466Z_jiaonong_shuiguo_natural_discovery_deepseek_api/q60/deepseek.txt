# 水果到货不合格时的补货约定思路

核心原则：**把“发现—通知—补货—兜底”四步写进合同或订单条款，并用门店自己的备用库存兜住补货空窗期。** 具体可这样约定：

## 一、验收标准前置写清

- 在采购合同或每次订单里列明可量化的验收标准：品种、规格（单果重/直径）、成熟度、糖度（如适用）、外观（无腐烂、无压伤、无霉变）、农残检测要求。
- 约定验收时限：到货后多长时间内提出异议有效（例如当场验收或2小时内），过期视为合格，避免事后扯皮。
- 约定不合格判定方式：拍照/视频留证 + 双方确认，单方面拍照也可作为依据（写明“以门店验收记录为准”）。

## 二、补货条款要写“时限+方式+费用”

- **补货时限**：明确“通知后 X 小时内送达”（如4小时/当日营业结束前），并区分工作日与节假日。
- **补货方式**：同品替换优先；无法同品时，允许等价替换或按缺货部分退款，由门店选择。
- **费用承担**：不合格品的退换运费、损耗由供应商承担；因补货延迟导致的营业损失，可约定按日/按次定额补偿（金额要现实，便于执行）。
- **部分不合格**：按比例补货或折价，不要求整批退换，减少营业中断。

## 三、给门店留“兜底”机制

- 合同里写明：供应商补货超时，门店可自行就近采购替代品，差价由供应商承担（设单次上限）。
- 门店侧建立**安全库存**：对高频使用的鲜果保持1~2天用量，补货空窗期先用安全库存顶上。
- 准备2家备选供应商，主供应商违约时切换，避免单一依赖。

## 四、违约责任与退出机制

- 约定连续/累计不合格次数达到阈值（如月内3次），门店可解除合同或要求降价。
- 设置质量保证金或账期扣款：不合格补货费用直接从货款中扣除，执行成本最低。

## 五、执行层面的小建议

- 每次到货用固定表格记录：时间、品种、数量、不合格项、照片、通知时间、补货到达时间，形成证据链。
- 补货条款尽量写进**长期采购框架合同**，而不是只靠口头或单次订单，否则难追责。

一句话总结：**标准量化、时限明确、费用归供应商、门店有安全库存和备选供应商**，这样补货才不会拖垮当天营业。
