面向餐饮客户，菠萝和香蕉的规格重点不是“最好看”，而是**稳定、好加工、出成率可控、按用途分级**。建议你先按餐饮用途分三类备货：饮品/甜品、后厨加工、自助/果盘，再定规格。

### 菠萝：按加工方式和出成率准备
餐饮客户更关注去皮损耗、酸度和切块稳定性。建议准备：

1. **鲜切/后厨加工用大果**
   - 单果重：**1.2–1.8kg**较稳妥，太小出成率低，太大一次用不完。
   - 成熟度：**7–8成熟**，到店后1–2天可用，适合后厨集中加工。
   - 要求：果眼浅、去皮损耗低、芯不要太硬。
   - 包装：整箱按**8–12个/箱**或按重量分档，注明单果重区间。

2. **饮品/甜品用中果**
   - 单果重：**0.8–1.2kg**。
   - 成熟度：**8成熟左右**，香气足、酸甜平衡，适合鲜榨、果茶、甜品装饰。
   - 要求：酸甜稳定，不要一批过酸一批过甜；可做“饮品专用”分级。

3. **自助/果盘用精品果**
   - 单果重：**1.0–1.5kg**，外观端正、果眼浅、颜色均匀。
   - 成熟度：**8–9成熟**，到店即可切盘。
   - 要求：大小均匀，便于切片摆盘。

4. **可选的预制规格**
   - 鲜切菠萝块/片：按**真空袋2.5kg/5kg**或餐饮常用周转箱规格。
   - 菠萝丁：适合炒饭、披萨、甜品，按**1cm/2cm丁**分级。
   - 注意：鲜切品必须明确冷藏保质期和到货频次，餐饮客户对损耗很敏感。

### 香蕉：按成熟度和用途分档
香蕉餐饮客户最怕“今天太青、明天全黑”，所以要按**到货成熟度**和**单根规格**分档。

1. **后厨/员工餐/烘焙用**
   - 规格：**单根120–160g**，整箱按**12–15kg/箱**常见。
   - 成熟度：**6–7成熟**到货，便于客户自己催熟或排期使用。
   - 用途：香蕉船、烘焙、奶昔、员工餐。

2. **饮品/甜品店用**
   - 规格：**单根100–140g**，大小均匀。
   - 成熟度：**7–8成熟**到货，2–3天内可用。
   - 要求：香气足、无严重碰伤；适合做香蕉奶昔、果茶、甜品装饰。
   - 建议：按“即用型”和“备用型”分批到货，避免一次性全熟。

3. **自助/果盘用**
   - 规格：**单根130–180g**，果指匀称、无棱角明显。
   - 成熟度：**7.5–8.5成熟**，到店即可剥皮切段。
   - 要求：表皮干净、无大面积黑斑，允许少量芝麻点。

4. **小香蕉/特色餐饮用**
   - 如小米蕉、皇帝蕉，可按**单根50–80g**做特色供应，适合东南亚菜、甜品店、儿童餐。
   - 但不要作为主推常规规格，先小批量试单。

### 给档口的实操建议
- **不要只报“菠萝/香蕉”一个价**，按“加工级、饮品级、果盘级”三档报价，餐饮客户会更容易选。
- 菠萝重点标注：**单果重区间、成熟度、去皮损耗预估、箱规**。
- 香蕉重点标注：**单根重、到货成熟度、催熟状态、箱规、碰伤率要求**。
- 首批建议：菠萝大果/中果各备少量，香蕉按7成熟和8成熟两档试供；先给餐饮客户做**小批量周配**，观察其后厨损耗和催熟能力，再放大规格。
- 合同里建议写清：**规格区间、成熟度、允许损耗比例、到货频次、退换标准**，这比单纯低价更能留住餐饮客户。
