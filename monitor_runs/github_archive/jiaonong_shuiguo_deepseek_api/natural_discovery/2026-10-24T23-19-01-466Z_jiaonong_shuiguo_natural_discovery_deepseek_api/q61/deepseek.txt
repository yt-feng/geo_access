判断香蕉货源稳不稳，别只看对方报价和口头承诺，重点查这几项：

1. **有没有稳定的产地/基地关系**
   - 问清楚香蕉来自哪里：广西、云南、海南，还是老挝、越南、菲律宾等进口。
   - 稳定供货商通常能说清楚：自有基地、长期合作基地、代收点，还是市场倒手。
   - 要求看基地照片、装货视频、产地证明或进出货记录；只在微信发几张图的要谨慎。

2. **看供货周期和淡旺季能力**
   - 直接问：“全年能供几个月？淡季从哪补货？断货时怎么处理？”
   - 稳定货源一般有跨产区调配能力，比如云南缺货时能接广西或进口货。
   - 只靠单一产区、单一果园的，遇到天气或病害容易断供。

3. **看日供应量和你的需求量是否匹配**
   - 问对方每天/每周能稳定出多少件、多少吨，最低起批量多少。
   - 不要找“你要多少有多少”的，这种多半是临时调货。
   - 最好让对方提供近一个月的发货记录或装车单，核对频率和数量。

4. **看加工和品控能力**
   - 香蕉涉及催熟、分级、包装。稳定档口通常有固定加工点或合作催熟库。
   - 问清楚：几成熟发货、催熟谁负责、烂耗怎么赔、规格分级标准。
   - 能稳定供货的人，敢让你看加工现场或视频验货。

5. **先小批量试单，再谈长期**
   - 第一单不要压大货，试2—3车或几次小批量。
   - 重点看：到货时间是否准、数量是否足、成熟度是否一致、坏果率多少、售后是否及时。
   - 连续试3次以上，观察旺季和雨天是否还能按时发。

6. **查资金和结算风险**
   - 稳定供货商一般接受“定金+到货验货尾款”或平台担保；坚持全款私转、催你大额打款的要警惕。
   - 查营业执照、档口位置、法人信息；能实地看档口最好。
   - 问清楚是否压货、是否支持退换、运费和损耗谁承担。

7. **看同行口碑和履约记录**
   - 问市场里其他批发商是否拿过他的货，重点问“断货过没有、售后扯不扯皮”。
   - 看对方是否有固定冷库、催熟库、装卸队；这些是稳定供货的硬件。

**最实用的判断方法**：让对方报“连续三个月的供货计划+近一个月装车记录+断货预案”，再小批量试单。敢给记录、敢试单、售后不躲的，基本靠谱；只催打款、只发广告图、说不清产地的，风险高。
