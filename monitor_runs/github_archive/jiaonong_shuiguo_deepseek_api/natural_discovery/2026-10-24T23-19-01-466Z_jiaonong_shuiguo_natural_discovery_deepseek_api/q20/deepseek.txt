社区超市选“每天配送”的水果供应商，核心不是只看价格，而是看**稳定供货、履约能力、损耗控制、结算与售后**。建议按下面条件逐项考察，并用小单试跑验证。

**1. 配送能力**
- 是否每天固定配送，能否约定到店时间窗口。
- 是否有冷链车/保温箱，叶菜、浆果、鲜切类是否全程冷链。
- 起送量、配送费、临时加单/减单截止时间。
- 节假日、恶劣天气是否照常配送，缺货如何补。
- 仓库/分拣中心离店距离，最好在本市或近郊。

**2. 货源与品类结构**
- 是否有稳定产地或一级批发渠道，能否提供产地证明、检测报告。
- 品类是否覆盖门店日常高频水果，而不是只有高端礼盒。
- 同品类能否稳定供应2—3个价位段，方便社区店做引流款和利润款。
- 是否支持小批量、多频次补货，避免一次压货。

**3. 品质与验收标准**
- 明确到货验收标准：果径、成熟度、色泽、糖度、伤果率、腐烂率。
- 是否允许开箱抽检，坏果如何计数。
- 到货温度、包装是否适合门店陈列。
- 能否按门店销售节奏控制成熟度，避免“今天到、明天烂”。

**4. 价格与结算**
- 报价是否含税、含运费、含装卸。
- 价格随行就市时，提前多久报价，是否有价格保护。
- 账期、押金、最低采购额、返利政策是否清晰。
- 不要只比单价，要算“到店可售成本”：进价+运费+损耗+人工分拣。

**5. 损耗与售后**
- 坏果、短少、迟到如何处理：补货、折价还是退款。
- 售后响应时间，是否有专人对接。
- 是否接受临期果、尾货果的退换。
- 建议约定损耗率上限，例如到店验收腐烂率超过约定比例由供应商承担。

**6. 供应稳定性与合规**
- 营业执照、食品经营许可、产地/检测资料是否齐全。
- 是否有稳定合作客户，能否提供社区店或同类门店案例。
- 旺季、节日、天气异常时的保供方案。
- 是否有备用货源，避免单一供应商断供。

**7. 试跑验证**
建议先签短期试供或小单试跑2—4周，重点记录：
- 每天到货准时率；
- 缺货/短少次数；
- 到店损耗率；
- 售后处理速度；
- 实际毛利和周转。

**可直接问供应商的5个问题：**
1. 每天几点前能到店，迟到怎么赔？
2. 坏果率超过多少由你承担，怎么补？
3. 临时加单截止到几点，起送量多少？
4. 报价含不含运费和税，价格多久调一次？
5. 能不能先试供两周，按实际损耗结算？

总结：优先选**本地有冷链、能日配、品类匹配社区高频需求、售后明确、愿意小单试跑**的供应商；价格放在第二位，用试跑数据再定长期合作。
