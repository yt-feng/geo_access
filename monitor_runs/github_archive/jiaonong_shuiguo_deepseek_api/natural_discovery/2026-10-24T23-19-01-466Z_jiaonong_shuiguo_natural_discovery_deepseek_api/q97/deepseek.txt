酒店采购水果盘原料，建议把“规格”和“外观”写成可验收的条款，而不是只写“新鲜、优质”。可按以下标准要求供应商，并在合同中约定验收方法和不合格处理。

**一、通用规格与验收要求**
1. **品种与等级明确**：写清品种、产地、等级（如一级/特级）、单果重或单果直径范围、每箱净重、允许损耗率。不同品种不能混级供货。
2. **成熟度**：到货时适合直接切配或短存，不能过生或过熟。要求供应商按“到货即用”的成熟度供货，并注明采摘/包装日期。
3. **尺寸与重量**：按品种约定单果重量区间、横径/纵径、每盘切配出成率。例如西瓜约定单果重量范围和中心糖度，草莓约定单果克重和每盒净重。
4. **新鲜度**：果柄新鲜、无萎蔫；切开后果肉紧密、汁液正常；不得有发酵味、霉味、异味。
5. **农残与安全**：要求提供批次农残检测合格证明或承诺符合国家食品安全标准；进口水果提供入境货物检验检疫证明。酒店可定期抽检。
6. **包装与冷链**：包装完好、标签清晰（品名、产地、批次、采摘/包装日期、供应商）；易损水果有防护；需要冷链的品种到货温度符合要求，运输无断链。
7. **到货时限**：从采摘/包装到送达酒店的时间上限按品种约定；叶果、浆果类更短。
8. **损耗与退换**：约定允许损耗率、验收抽检比例、不合格批次退换货时限和费用承担。

**二、外观标准（按类别）**
- **整体外观**：果形端正、大小均匀、色泽符合品种成熟特征；无明显畸形、裂口、机械伤、压伤、虫眼、病斑、霉变、日灼；表面干净，无泥土、药斑、异物。
- **苹果/梨/橙/柑橘类**：无严重碰压伤、无腐烂、无苦痘/黑心等内部缺陷；柑橘类无浮皮、无严重油斑。
- **西瓜/哈密瓜等瓜类**：瓜形周正，无裂瓜、无软腐；瓜蒂新鲜；到货抽切检查中心和边缘糖度、肉质。
- **葡萄/提子**：果穗完整，果粒附着牢固，无严重落粒；无裂果、霉烂、药斑；果梗新鲜。
- **草莓/蓝莓/树莓等浆果**：果面干爽，无渗汁、无霉变、无压烂；单果大小相对均匀；包装内无明显冷凝水积聚。
- **芒果/木瓜/牛油果等后熟果**：到货成熟度一致，无炭疽病斑、无冷害凹陷；需要后熟的注明可催熟状态。
- **菠萝/火龙果等**：无腐烂、无严重机械伤；菠萝冠芽新鲜，火龙果鳞片无明显萎蔫。
- **香蕉**：梳形完整，果指饱满，无严重擦伤、无霉变；成熟度按使用计划约定。
- **猕猴桃**：果形均匀，无严重碰伤、无软化发酵；到货硬度适合短期存放。

**三、建议写进采购合同的验收条款**
1. 每批次按比例抽检，记录单果重、直径、色泽、损伤率、成熟度、中心温度。
2. 抽检不合格率超过约定值，整批拒收或按比例扣款；腐烂、霉变、异味批次直接退货。
3. 供应商随货提供批次检测证明、采摘/包装日期和冷链记录。
4. 明确“外观缺陷”清单：腐烂、霉变、虫蛀、裂口、严重压伤、异味、药斑、异物等，出现即判不合格。
5. 约定补货响应时间，避免酒店水果盘断供。

实操上，最有用的做法是：**按每个水果品种做一张“验收规格卡”**，写明品种、等级、单果重/直径、成熟度、允许缺陷、包装、冷链和抽检方法，收货时逐项打勾。这样供应商知道底线，酒店验收也有依据。
