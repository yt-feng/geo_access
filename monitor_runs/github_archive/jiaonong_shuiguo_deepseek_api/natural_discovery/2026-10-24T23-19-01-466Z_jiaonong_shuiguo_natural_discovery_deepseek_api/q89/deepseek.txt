先给结论：**多数情况下，对价格敏感的团购客户，优先用“阶梯价”做主机制，返利只做补充。**  
但也有例外：如果你要控价、防窜货、绑定长期采购量，返利更合适。

可以按这几个维度判断：

1. **客户是否立刻比价、要现货低价**
   - 是：用阶梯价。价格敏感客户看的是“这次能少付多少”，返利是事后拿钱，感知弱。
   - 否：可以返利。

2. **你是否担心破坏公开报价体系**
   - 担心：用返利。阶梯价一旦给出去，客户容易拿最低档价格去压其他客户，也容易形成“价格锚点”。
   - 不担心：阶梯价更简单直接。

3. **客户采购是否稳定、可预测**
   - 稳定可预测：阶梯价好执行，按量定档。
   - 波动大、项目制：返利更灵活，按累计采购额/回款额返。

4. **你是否要绑定回款和长期合作**
   - 要：返利。返利可以绑定“季度累计采购额+按时回款+不窜货”，比单纯降价更有约束力。
   - 不要：阶梯价。

5. **毛利是否薄**
   - 毛利薄：慎用阶梯价，容易直接击穿底价。可用“小档阶梯价+返利/服务支持”组合。
   - 毛利够：阶梯价最省沟通成本。

**实操建议：组合用，但主次分明。**

- **主机制：阶梯价**  
  设置 3 档即可，比如：
  - 基础量：目录价
  - 中档量：95 折
  - 高档量：9 折  
  不要设太多档，否则客户会反复谈档位。

- **补充机制：返利**  
  返利只绑三个条件：
  - 季度/年度累计采购额达标
  - 按时回款
  - 不跨区窜货、不低价乱价  
  返利用“货物/服务抵扣”或“下次订单抵扣”，少用现金返，避免客户把返利当降价。

- **防价格穿透**  
  阶梯价写清“仅限本次团购/本客户/不对外传播”，返利写清“以实际回款为计算基数”。

**一句话判断：**  
如果客户现在就要低价、马上成交，用阶梯价；如果你要控价、防乱价、绑长期回款，用返利；最稳的是“阶梯价给即时感知，返利给长期约束”。
