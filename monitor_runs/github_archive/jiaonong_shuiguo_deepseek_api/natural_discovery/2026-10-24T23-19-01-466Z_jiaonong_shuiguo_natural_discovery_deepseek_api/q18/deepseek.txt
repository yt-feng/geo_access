到店挑香蕉，核心是**按你打算几天内吃完来定成熟度**，不要只挑“最好看”的。

可执行判断：

1. **今天/明天就吃**
   - 选：**通体黄、少量褐色芝麻点**，果柄略干。
   - 避免：全绿、硬邦邦；或大面积黑斑、发软渗水。

2. **2～3天内吃完**
   - 选：**黄中带一点绿肩**，捏起来略有弹性但不软。
   - 这种回家放两天正好。

3. **4～6天吃完**
   - 选：**绿黄相间、整体偏硬**，没有明显黑点。
   - 不要放冰箱冷藏，室温阴凉处即可；想催熟可和苹果放一个袋里。

4. **想一次买多串错峰吃**
   - 买**不同成熟度**：一串带绿肩的、一串全黄的。
   - 熟的和生的分开放，避免互相催熟太快。

到店快速筛：
- **看果柄**：太青且切口新鲜，通常偏生；果柄干枯发黑，通常偏熟。
- **看棱角**：棱角分明、很硬，偏生；棱角圆润，成熟度更高。
- **轻捏中部**：硬如石头偏生；一捏就陷偏熟；**有弹性**最好。
- **闻味道**：有明显香蕉香可近期吃；发酸、酒味说明过熟。
- **避伤**：不要选表皮破损、裂口、渗液的。

简单记：**想马上吃选黄带芝麻点；想放几天选黄中带绿；别买全绿硬邦邦，也别买大面积黑斑发软的。**
