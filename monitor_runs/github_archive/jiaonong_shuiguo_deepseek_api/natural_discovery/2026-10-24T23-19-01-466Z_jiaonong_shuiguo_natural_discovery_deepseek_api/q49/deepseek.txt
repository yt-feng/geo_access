可以，但要按“临时补货”单独约定，不能只靠口头。建议你和供应商补一份简短的《旺季临时补货确认单》或在原合同上加补充条款，重点写清下面几项：

1. **补货触发与提前期**
   - 约定旺季期间（写明起止日期）你可按周或按日发临时补货通知。
   - 写明提前多久下单，例如“每日16:00前发次日补货需求，供应商次日10:00前送达”。
   - 明确这是“临时补货”，不改变原合同的基础订货量。

2. **数量与上限**
   - 写清单次补货上限和旺季累计上限，例如“单次不超过X箱，旺季累计不超过Y箱”。
   - 约定供应商优先保障你的补货量；超出上限部分双方另行确认，避免供应商临时加价或你被拒供。

3. **价格与结算**
   - 临时补货单价按原合同价执行，或写明“不超过原合同价的X%”。
   - 明确运费、装卸费谁承担。
   - 结算周期单独写清，例如“补货货款随原合同月结，不因临时补货改为现结”。

4. **品质与验收**
   - 写明菠萝规格、成熟度、产地/品种要求，最好附验收标准。
   - 约定到货验收：坏果率超过约定比例（如5%）可拒收或按比例扣款。
   - 明确验收时限和异议提出方式，避免事后扯皮。

5. **缺货违约责任**
   - 供应商未按约定补货导致你断货的，约定违约金或赔偿方式，例如“按缺货金额的X%赔偿”或“承担因此产生的替代采购差价”。
   - 同时约定不可抗力（如极端天气、产区减产）下的通知义务和协商机制，避免条款无法执行。

6. **沟通与凭证**
   - 指定双方对接人和联系方式。
   - 每次补货用微信/邮件/订货单留痕，写明品名、数量、单价、送达时间。
   - 到货签收单由双方签字，作为结算和索赔依据。

**可执行做法：** 先和供应商确认旺季起止、日均用量、单次补货上限和提前期，形成一页补充协议；每次补货发文字订单并让对方回复确认；到货当场验收并拍照留证。这样既不影响原合作，也能把临时补货的数量、价格、时效和责任固定下来。
