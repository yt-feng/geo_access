和水果供应商谈酒店早餐合作，核心是**把“稳定”变成可执行的条款**，而不是只靠口头承诺。重点注意以下几方面：

1. **明确供应稳定性机制**
   - 要求供应商说明产地/批发市场来源、季节性替代方案、缺货时的补货时限。
   - 约定“缺货提前通知时间”（如提前24小时），以及替代品种需经酒店确认。
   - 了解供应商是否有冷库、配送车辆、备用货源；避免单一品种/单一产地依赖。

2. **锁定品质标准**
   - 按品种写清验收标准：新鲜度、成熟度、大小/果径、色泽、无腐烂/虫害/机械伤、农残检测要求。
   - 早餐常用水果（西瓜、哈密瓜、苹果、橙子、香蕉、圣女果等）分别定规格，避免“以次充好”。
   - 约定验收不合格的处理：拒收、换货时限、扣款或索赔。

3. **价格与调价机制**
   - 水果价格波动大，不要只谈一个固定价。可约定“基准价+随行就市浮动”，并明确调价周期（如每周/每半月）和参考市场（当地批发市场均价）。
   - 要求报价含税、含配送、含装卸，避免后期加价。
   - 可设月度/季度采购量阶梯价，但不要为低价承诺过量。

4. **配送与验收流程**
   - 明确配送时间（早餐前到位）、频次、临时加单响应时间。
   - 规定验收人、验收时间、称重方式（净重/毛重）、留样和记录。
   - 到货温度、包装卫生、运输车辆清洁要求要写进合同。

5. **食品安全与资质**
   - 查验营业执照、食品经营许可证、水果农残检测报告/合格证明。
   - 要求供应商购买食品安全责任险更稳妥。
   - 约定因水果质量问题导致客人投诉或食品安全事件的赔偿责任。

6. **合同期限与退出机制**
   - 首次合作可签3—6个月试合作，考核稳定后再续签。
   - 设月度考核指标：到货准时率、验收合格率、缺货次数、投诉次数。
   - 明确连续不合格或重大食品安全问题时的解约权和替补供应商过渡安排。

7. **结算与对账**
   - 约定账期（如月结30天）、对账单据（送货单、验收单、发票）。
   - 价格调整需书面确认，避免口头调价。

8. **备选方案**
   - 不要只依赖一家供应商。可保留1家主供+1家备选，或对关键品种设第二货源。
   - 酒店内部也要有临时替代菜单预案，比如某水果缺货时用罐头水果或其它品种替代。

谈判时建议先让对方提供**供货方案书**，包含货源、品种清单、规格、报价、配送能力、应急方案，再逐项落到合同附件里。最关键是：**稳定供应、品质标准、价格浮动规则、违约责任**这四项写清楚。
