优先看成熟度，价格放第二位。因为香蕉成熟度直接决定蛋糕的香气、甜度、湿润度和出品稳定性，价格省下来的钱通常抵不过风味和报废损失。

可执行判断：

1. **按用途选熟度**
   - 做香蕉蛋糕、香蕉磅蛋糕、香蕉马芬：选**表皮大面积褐斑、果肉软糯但未流汁**的香蕉，香气和甜度最好。
   - 需要切块装饰或保持果肉形态：选**刚转黄、少量斑点**的，太熟会塌。
   - 完全黑软、有酒味或酸味：不要用于出品。

2. **采购时看“成熟阶段”而不是只看当天能不能用**
   - 当天就要做：买已出褐斑的。
   - 两三天后用：买黄熟、少量斑点的，室温催熟。
   - 大量备货：分批买不同熟度，避免同一天全熟或全生。

3. **价格只在同熟度档位内比较**
   - 同熟度下再比单价、损耗率和供货稳定性。
   - 明显便宜的“过熟蕉”如果当天用不完，损耗和风味风险可能更高；明显便宜的“生蕉”需要占用催熟时间和空间。

4. **验收标准**
   - 闻起来有清晰香蕉香、无发酵酒味。
   - 果肉软但不渗水、不发黑。
   - 表皮破损少，无霉点。
   - 记录到货熟度和可用窗口，方便和供应商约定下次到货状态。

结论：**成熟度是质量变量，价格是成本变量；先锁定可用熟度，再在同熟度里谈价格和稳定供应。**
