# 连锁超市节假日水果货源锁定方案

核心思路：**把"临时抢货"变成"提前锁量+锁价+锁仓+锁运力"的契约安排**，重点抓提前期、合同条款和替代预案三件事。

## 一、提前测算需求（节前 45–60 天启动）
- **历史数据建模**：用近 2–3 年同期（同节假日、同星期结构）的分店销量，按门店×品类×单品算增量系数，再叠加当年天气、促销、客流预估修正。
- **分品分档**：耐储水果（苹果、梨、柑橘）可提前 30–45 天锁货；易损水果（草莓、车厘子、葡萄、荔枝）必须按日锁量、短周期滚动下单。
- **设安全库存与断货红线**：按"节前峰值日销量×1.3"作为单日备货上限参考，避免过量压货损耗。

## 二、多源锁货，别把鸡蛋放一个篮子
- **主供应商（占 60–70%）**：签节前保供协议，明确最低供货量、最高限价、到货时间窗。
- **备选产区（占 20–30%）**：同品类准备 1–2 个跨产区替代源（如国产替代进口、不同省份产区），应对单一产区减产或天气灾害。
- **产地直采/基地合作（占 10–20%）**：对节庆主推单品提前与合作社、种植基地签包销或预定协议，抢在批发市场涨价前锁价。
- **批发市场兜底**：保留本地批发市场渠道作为临时补货口，用于应对突发缺口。

## 三、合同条款是关键（必须写进去）
- **锁量锁价**：约定节前供货总量与单价，或采用"基准价+浮动上限"（如涨幅不超过 X%）。
- **违约与赔偿**：供应商未达供货量的违约金、超市超量不提货的责任，双向约束。
- **到货时效与验收标准**：明确每日到货时间、规格等级、损耗率上限（如到货损耗≤3%），不合格可拒收并扣款。
- **价格联动机制**：约定市场价大幅下跌时的重新议价或补偿条款，避免高价锁死后被市场价反噬。

## 四、锁运力与锁仓
- **运力**：节前冷链车紧张，提前 2–3 周与物流商签保运协议，约定车次、温控标准、延误赔付。
- **仓储**：提前预订冷库/周转仓容量，耐储品类节前分批入库，易损品类走"产地—配送中心—门店"短链路、高频补货。
- **配送频次**：节前把补货从"每周"提到"每日/隔日"，按门店销量动态调拨。

## 五、执行节奏（倒排时间表）
| 时间 | 动作 |
|---|---|
| 节前 60 天 | 完成需求测算，确定主推单品与备货量 |
| 节前 45 天 | 与主供应商、基地签保供协议，锁量锁价 |
| 节前 30 天 | 锁定备选产区与运力，预订冷库 |
| 节前 15 天 | 耐储品分批入库，启动日度补货节奏 |
| 节前 7 天 | 每日跟踪到货与销量，启用动态调拨 |
| 节日期间 | 每日复盘缺口，激活备选渠道补货 |

## 六、风险预案
- **单一产区减产/极端天气**：立即切换备选产区，提前签好"可启用"的框架协议。
- **价格暴涨**：靠锁价合同覆盖主量，剩余缺口按"限价采购+调整促销"控制毛利。
- **物流中断**：准备 2 家以上物流商，易损品预留本地短驳方案。
- **卖不动**：耐储品节后转常规促销消化，易损品控制单日下单量、宁可多次小批量补。

**一句话判断标准**：如果你的主供应商合同里没有"最低供货量+最高限价+到货时效+违约赔偿"这四项，货源就不算真正锁定。
