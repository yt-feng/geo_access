小商家采购水果，现金结算和月结账期的风险可以这样看：

**现金结算的主要风险**
1. **资金占压大**：每次采购都要立即付钱，旺季或节假日前备货会占用较多流动资金。
2. **假币、错付、找零纠纷**：现金交易容易出差错，尤其大额时；要当场点清、保留收据。
3. **无账期杠杆**：现金付了货，万一质量差、短斤少两，追回难度较大，只能靠当场验货。
4. **安全风险**：携带现金、频繁取现存在被盗抢或丢钱风险。
5. **无法积累信用记录**：对后续想争取账期、赊购帮助不大。

**月结账期的主要风险**
1. **账期违约风险**：供应商可能要求涨价、缩短账期，或在你资金紧张时停止供货。
2. **隐性成本高**：月结价格通常比现金价高，或者有最低采购量、押金、担保要求，实际成本可能更高。
3. **对账纠纷**：水果损耗、退换货、短斤少两容易在月底对账时扯皮，需要每笔留下签收单、验收记录。
4. **现金流依赖**：习惯账期后，一旦供应商收紧，短期资金压力会集中爆发。
5. **过度采购**：账期容易让人觉得“先拿货后付钱”，导致进货过量、损耗增加。
6. **法律与信用风险**：逾期付款可能影响合作关系，严重时被追款或影响后续融资信用。

**实操建议**
- 现金采购：坚持当场验货、索要收据，大额尽量转账留痕，不长期携带大量现金。
- 月结采购：合同或微信里明确账期、对账日、退货和损耗规则；每批货签收单留存；不要只依赖一家供应商。
- 混合策略：日常小额现金或现结，主供应商给短账期（如7—15天），既保留议价空间又控制现金流风险。
