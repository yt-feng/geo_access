**1. 发票：必须支持**
- 企业采购水果礼盒属于经营性支出，通常需要取得合规发票用于报销、入账和税前扣除。
- 应在合同中明确：发票类型（增值税专用发票/普通发票）、税率、开票项目（如“水果礼盒”“食品”等，按实际经营范围和税务规定）、开票时间（付款前或收货后几日内）。
- 不要接受“只能开收据”或“开票加税点”临时加价；报价时应含税并写明含税价。

**2. 定制包装：建议要求支持**
- 企业福利常需要印企业Logo、祝福语、员工姓名卡、节日主题等，定制包装能提升福利感知。
- 需明确定制范围：外箱/手提袋/内盒/腰封/贺卡，起订量，打样费，打样周期，版费是否退还，颜色误差和材质标准。
- 定制包装涉及食品接触材料时，应要求供应商提供符合食品安全相关标准的说明或检测报告。

**执行建议**
- 把“可开合规发票”设为硬性门槛，无发票直接淘汰。
- 把“定制包装”设为必选能力或至少可选项，按预算和人数确定；小批量采购要确认是否收版费、起订量是否够。
- 合同写明：发票不合规、包装与确认样不一致时的退换货和违约责任。
