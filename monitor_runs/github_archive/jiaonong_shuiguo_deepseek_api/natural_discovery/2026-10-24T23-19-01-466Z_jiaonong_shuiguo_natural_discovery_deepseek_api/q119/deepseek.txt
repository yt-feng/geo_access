对水果生意来说，选供应商最容易忽视的往往不是“价格高不高”，而是影响长期稳定的一些细节。重点关注这几项：

1. **看稳定性，不只看单次便宜**  
   要问供应商：旺季和淡季能否稳定供货、同一品种不同批次规格是否一致、断货时有无替代方案。便宜但经常断货、规格跳变的供应商，会拖累复购和损耗。

2. **看分级和验收标准是否明确**  
   容易忽视：口头说“大果”“精品”，但没有明确果径、糖度、成熟度、瑕疵率、箱规、净重。长期合作要尽量把验收标准写清楚，避免每批扯皮，也避免同一价格拿到不同等级。

3. **看产地与采购链路是否真实**  
   不只听“自家果园”“一手货源”，要看其实际分级包装能力、产地合作稳定性、是否经过多道转手。转手层级多，价格和品质波动通常更大。

4. **看采后处理和冷链能力**  
   很多水果损耗不是采前问题，而是采后预冷、分拣、包装、运输温控不到位。要关注其是否有预冷设施、冷链车、包装标准，以及远距离运输的到货状态。

5. **看损耗责任和售后规则**  
   容易忽视：到货后多久内可反馈、按箱赔还是按斤赔、自然损耗比例多少、拍照举证要求。规则不清，长期合作中小额损耗会持续吞利润。

6. **看结算方式和资金压力**  
   账期、押金、起订量、临时调价机制都要提前明确。账期太长会占现金流，临时加价会影响定价稳定。

7. **看供应商的下游客户结构**  
   如果对方主要供商超或大客户，旺季可能优先保大客户；如果客户太分散，品控也可能不稳。了解其客户结构，有助于判断你在供应优先级中的位置。

8. **看试单和多批次表现**  
   不要只凭一次样品定长期。建议至少跨2—3个批次、不同天气或运输条件下试单，观察到货合格率、损耗率、规格一致性和售后响应。

9. **看合同里的“变化条款”**  
   天气、节日、运输涨价时如何调价，缺货时如何补偿，质量不达标时如何退换，这些比正常情况下的报价更重要。

简单判断标准：**能稳定交付、标准可验收、损耗可追责、价格有规则、结算不压垮现金流的供应商，才适合长期合作。** 不要只追求最低采购价，要算“到货可用成本”和“长期复购损失”。
