要固定，但不要固定到“单一产地/单一批次”这种脆弱状态。更稳的做法是：**固定品种+固定加工规格+固定验收标准，产地和批次做“主供+备供”双轨管理**。理由和建议如下：

1. **水果口味波动是原料天然属性，靠单一产地也解决不了**
同一产地不同年份、季节、降雨、成熟度都会变。固定一个产地反而风险更大：一旦减产、涨价、品质下滑，门店没有替代方案。

2. **真正要固定的是“可量化的规格标准”**
比固定产地更有效的是把这些写进采购标准：
- 品种、等级、单果规格/糖度范围（如糖度不低于某值）
- 成熟度（几成熟采摘、到店后催熟/直接使用）
- 酸度、出汁率、可溶性固形物
- 冷链温度、到货时限、破损率上限
- 每批留样和到货抽检

3. **采购策略建议**
- **主供+备供**：主产地占70%左右，备选产地/供应商占30%，保持可切换。
- **固定“供应批次窗口”而非永久批次**：按产季锁定某个采收窗口的货，签质量协议，不长期绑死单一批次。
- **分批锁价+滚动补货**：不要一次囤太久，水果鲜度衰减快；用周度/双周度补货平衡成本与品质。
- **配方端做容错**：糖度、酸度设调整规则，比如糖浆量按批次糖度微调，减少对原料绝对稳定的依赖。

4. **什么情况下可以更“固定”**
如果某款爆品对风味极其敏感、且该产地供应稳定、有长期合同和质检背书，可以对该单品固定主产地，但仍要保留备选和切换预案。

结论：**要固定标准、固定主供关系、固定产季窗口；不要固定单一产地或单一批次。** 这样既控波动，又保留供应链弹性。
