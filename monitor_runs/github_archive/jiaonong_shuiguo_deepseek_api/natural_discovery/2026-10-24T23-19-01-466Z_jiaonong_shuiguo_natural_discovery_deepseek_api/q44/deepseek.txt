判断供应商售后响应稳不稳定，不要只听口头承诺，重点用“可验证的机制+小单测试+合同约束”来确认。可按下面几步做：

1. **先问清售后响应机制**
   - 是否有固定对接人、备用联系人、售后电话/微信群，是否承诺响应时限。
   - 质量问题（烂果、黑心、催熟不均、到货短少）如何处理：补货、换货、退款、折价，多长时间内处理。
   - 菠萝和香蕉售后差异要分开问：菠萝看黑心、烂心、机械伤；香蕉看青熟度、催熟效果、到货断把/压伤。

2. **做小单压力测试**
   - 先下2—3次小批量订单，故意观察：报损申请后多久回复、是否推诿、补货是否及时。
   - 可在正常订单中记录一次轻微质量问题，看对方处理态度和速度，但不要恶意索赔。
   - 测试时间覆盖周末/节假日到货，因为生鲜售后最怕非工作时间没人管。

3. **看历史履约证据**
   - 要求提供近几个月的售后记录样例：报损单、补货单、客诉处理记录。
   - 问合作商超或同行，重点问“出问题后多久解决”，而不是“合作好不好”。
   - 看其是否有冷链、催熟、分拣能力；售后稳定往往依赖其上游和物流稳定性。

4. **合同里写死售后条款**
   - 明确响应时限：如到货后2小时内响应，24小时内给出处理方案。
   - 明确赔付标准：菠萝黑心率、香蕉青熟度/催熟不良的折价或补货比例。
   - 明确时效：补货到店时间、退款到账时间、短少补差方式。
   - 约定售后对接人和备用联系人，避免换人后失联。

5. **用付款和合作节奏约束**
   - 初期不要给太长账期或大额预付，保留售后扣款权。
   - 连续出现售后拖延的，降低订单比例或暂停合作。
   - 对稳定响应的供应商可逐步放量，但合同条款不放松。

一句话：**看机制、做小单测试、查记录、写进合同**。能在这四件事上都经得起验证的供应商，售后响应通常更稳。
