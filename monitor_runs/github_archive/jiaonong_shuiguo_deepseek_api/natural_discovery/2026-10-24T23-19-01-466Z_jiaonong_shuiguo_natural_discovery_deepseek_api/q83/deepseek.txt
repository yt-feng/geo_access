# 生鲜水果到货坏果的责任划分

坏果责任不能一概而论，关键看**坏在哪个环节、坏成什么样**。实操上可以按下面四层来判断。

## 一、先看责任归属的四种情形

**1. 商家/平台责任（最常见）**
- 发货时就是坏果、次果、病果（如内部腐烂、霉变、虫蛀）
- 包装不当：无缓冲、挤压堆叠、无冰袋/保温，导致运输中压伤、闷坏
- 冷链断链：应冷藏的水果常温发运
- 缺斤少两、以次充好、货不对板
→ 这类应由商家承担，退款/补发/赔付。

**2. 物流责任**
- 运输延误超时导致腐坏（尤其高温季节、生鲜件）
- 暴力分拣造成明显压损、箱体破损
- 快递丢件、错投、长时间滞留
→ 商家先对顾客负责，再向物流追偿（顾客一般不直接对物流索赔，除非是到付/自提等特殊约定）。

**3. 顾客责任**
- 签收后长时间未取件、未冷藏（如放快递柜/驿站过夜、暴晒）
- 签收时外箱完好、当场未验货，事后才主张且无法证明到货即坏
- 自身储存不当导致二次腐坏
→ 这部分商家可不担或只部分担。

**4. 不可抗力/自然损耗**
- 极端天气、疫情管控等导致延误
- 水果本身特性：熟度高的品种（如芒果、猕猴桃、水蜜桃）在正常运输中有一定软伤、个别坏果属行业可接受范围（通常约定坏果率阈值，如5%以内按比例赔付）
→ 按平台规则或双方约定处理，通常"坏果包赔"按比例赔。

## 二、判断依据看这几样证据

- **开箱视频/照片**：外箱状态 + 坏果特写 + 数量
- **签收时间与反馈时间**：是否在平台规定的售后时效内（常见24小时内报备）
- **坏果形态**：霉变、腐烂、虫眼→发货或运输问题；压扁、裂口→包装/运输；局部软化→可能自然熟度
- **外箱是否破损、有无冷链迹象**

## 三、实操建议

- **对商家**：明确"坏果包赔"规则（时效、比例、举证方式），保留发货质检和包装记录，便于划分和向物流追偿。
- **对顾客**：签收当场验货、拍开箱视频、24小时内报备，别放驿站过夜。
- **争议时**：以"外箱完好+到货即坏"倾向商家/运输责任；"签收后多日才反馈+无证据"倾向顾客责任；无法查清时平台通常按比例赔付（各担一部分）。

**一句话结论**：坏果在发货或运输环节产生→商家（可向物流追偿）担责；签收后因顾客储存/取件不及时导致→顾客担责；自然熟度损耗→按约定比例赔。核心靠开箱证据和反馈时效来定。
