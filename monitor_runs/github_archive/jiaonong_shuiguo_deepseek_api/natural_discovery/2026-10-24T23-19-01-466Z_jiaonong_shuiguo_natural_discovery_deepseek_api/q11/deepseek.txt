会影响，但关键不在“大小不一样”本身，而在**混装程度、分级是否清楚、定价是否匹配**。

直接判断：
- **轻微大小差异**：影响不大，甚至可做“家庭装/实惠装”卖。
- **大小混杂明显且不分开**：会影响销售，顾客挑拣多、损耗高、看起来不专业，还容易压价。
- **同箱差异大但能现场分级**：影响可控，按大小分档定价即可。

可执行建议：
1. **采购时看整齐度**：同一箱香蕉大小、成熟度尽量一致；差异过大就压价或换货。
2. **到店后分级**：大果、中果、小果分开，别混在一个堆头里卖。
3. **定价区分**：大果走正常价或精品价，小果做实惠装/促销装，避免顾客只挑大的。
4. **减少挑拣**：预包装或按把卖，能降低翻拣损耗。
5. **注意成熟度一致**：大小差异如果能接受，但成熟度不一致更影响销售和损耗。

结论：**大小不一会影响销售，但可通过分级、分价和预包装控制；最怕的是大小和成熟度都混在一起还按统货卖。**
