对小水果店进香蕉，优先级建议是：**熟度 > 坏果率 > 送货速度 > 价格**。价格不是第一，因为香蕉是典型的“进错一批就烂一批、卖慢就黑一批”的高损耗品。

具体判断标准可以这样用：

1. **熟度最重要**
   - 你要按“预计几天卖完”来定熟度，不是越黄越好。
   - 当天/次日能卖完：可进偏黄、少量芝麻点。
   - 2～3天卖完：进微黄带绿、刚转色。
   - 3天以上：进偏绿、能后熟的货。
   - 熟度不对，价格再低也可能直接变损耗。

2. **坏果率第二**
   - 重点看：果柄是否发黑腐烂、果指是否有压伤/裂口、箱内是否有水汽、有没有异味。
   - 小水果店议价能力弱，坏果率高会吃掉所有价格优势。
   - 进货时最好能抽检箱底和中间层，不只看看表面。

3. **送货速度第三**
   - 香蕉怕闷、怕压、怕高温，送货慢会增加催熟不均和压伤风险。
   - 但送货速度只在“熟度合适、坏果可控”的前提下才有价值；送得快但货差，仍然不能要。

4. **价格放最后**
   - 价格要换算成“可售果成本”，不是只看每箱便宜几块钱。
   - 简单算：`实际可售成本 = 进价 ÷（1 - 坏果率 - 预计损耗率）`。
   - 如果便宜货坏果率高一截，实际成本往往更贵。

**可执行建议：**
- 固定2～3家供应商，不要只盯最低价。
- 每次进货记录：进价、熟度、坏果率、到货时间、售完天数、损耗率。
- 连续记录几次后，选“综合损耗最低”的供应商，而不是“报价最低”的。
- 小店单次进货量宁少勿多，香蕉宁可补货，不要压货。

一句话：**先保熟度和坏果率，再保送货稳定，最后谈价格。**
