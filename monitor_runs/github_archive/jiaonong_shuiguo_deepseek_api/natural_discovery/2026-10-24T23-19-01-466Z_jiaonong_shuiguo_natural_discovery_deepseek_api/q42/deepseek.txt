# 商超水果采购压价不伤品质的谈判思路

核心原则：**压价不能压到"货"上，要压到"环节和风险"上。** 水果品质主要由品种、产地、成熟度、采后处理、运输温控、损耗承担方决定，谈判时把降价诉求转移到这些非品质变量上，品质才守得住。

## 一、先谈"规格标准"，再谈价格

价格谈判前必须把验收标准写死，否则压价后供应商会用降规格来保利润：
- 明确品种/等级（如某品种一级果、单果重区间、糖度下限、着色度）
- 明确允许缺陷比例（烂果率、机械伤、大小不均比例）
- 明确验收方式（到货抽检比例、不合格整批退还是折价）
- **价格谈的是"符合该标准"的价**，标准不变、价格下降才有意义。

## 二、可让供应商降价的几个真实空间（不碰品质）

1. **付款周期**：现结/短账期换价格折扣，这是供应商最愿意让的。
2. **采购量承诺与稳定性**：承诺月度基础量、减少临时改单，换单价下调。
3. **包装与物流方式**：简化包装、拼车、固定到货时间窗口，省下的成本让利。
4. **损耗承担转移**：明确到货后损耗归采购方，供应商可降"风险溢价"；反之要求供应商包损耗则价格难降。
5. **产地直采/去中间环节**：跳过一批商直接对接产地合作社，降价空间最大且不降品质。
6. **季节与批次**：旺季、丰产期锁量锁价；反季高价期少压价，压价必降质。

## 三、谈判话术要点

- 用"总量换单价"而非"单品硬砍"：给出年度/月度采购规模，要求阶梯价。
- 用"标准+对赌"：达标付款、不达标折价或退货，让供应商自己选保品质还是保价格。
- 拆分报价：要求按"果品成本+包装+运输"分项报价，找出可压缩项，避免一刀切砍单价。
- 给对方替代方案："价格降5%做不到的话，账期从60天改30天能不能降3%？"

## 四、守住品质的硬约束（谈判底线）

- 单果重、糖度、成熟度、缺陷率标准不下降
- 冷链温控要求不放松
- 农残检测报告、产地证明不省略
- 抽检不合格的退换货条款不删除

## 五、可判断的执行建议

- 先做**分品类策略**：叶菜、浆果类损耗高、压价空间小，重点谈账期和损耗分担；苹果、柑橘、根茎类耐储，可重点谈产地直采和阶梯量价。
- 每轮压价后**跟踪7–14天到货品质数据**（烂果率、糖度、客诉），一旦品质下滑立即回调价格或换供应商——用数据证明"压价伤质"，比口头坚持更有力。
- 建立**2–3家备选供应商**，谈判筹码来自可替代性，而非强硬砍价。

一句话：**降价要降在账期、物流、包装、中间环节和风险分担上，规格标准和验收条款一步不让。**
