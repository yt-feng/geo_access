判断供应商能不能稳定按规格送货，重点不是听承诺，而是把“规格”变成可验收、可追溯、可惩罚的条款，并用小批量试单验证。可按下面几步做：

1. **先把规格写死**
   - 品种/产地：如金钻凤梨/巴厘，明确允许产区。
   - 单果重区间：例如1.2–1.5kg，超区间拒收或降级。
   - 成熟度：糖度范围、果眼深浅、是否允许青果催熟。
   - 外观：黑心、裂口、日灼、机械伤、冠芽长度、农残标准。
   - 包装：箱规、每箱净重、码放层数、托盘/周转筐要求。
   - 送货：到店/到仓时间窗、单次最小批量、频次、温度要求。

2. **要求供应商提供可验证的供应能力**
   - 自有基地/合作基地面积、当前可采量、日加工/分选能力。
   - 冷库容量、分选线、是否做糖度和重量分级。
   - 近3个月同类客户供货记录，最好能提供发货单或验收单样本（注意脱敏）。
   - 雨季/台风季的备货和替代产区方案。

3. **做小批量试单，至少跑3–5次**
   - 连续下3–5批小单，覆盖不同天气和不同周次。
   - 每批记录：到货时间、数量短缺率、规格合格率、损耗率、糖度抽检、黑心/腐烂比例。
   - 重点看波动：不是看最好一批，而是看最差一批是否仍可接受。

4. **用验收数据卡供应商**
   - 设定合格率门槛：如单批规格合格率≥95%，短缺率≤2%，腐烂率≤1%。
   - 连续两批不达标即暂停供货或扣款。
   - 要求每批附采收日期、产地、批次号，便于追溯。

5. **看补货和异常响应**
   - 临时加单24–48小时能否补到？
   - 出现质量问题，多久能换货/补货？
   - 是否有备用产区或备用供应商，避免单一来源。
   - 送货迟到是否有明确违约责任。

6. **合同里写清楚**
   - 规格、验收标准、抽检比例、拒收条件。
   - 短溢装比例、价格调整机制、账期。
   - 质量扣款、换货时限、断供赔偿。
   - 旺季保供量和优先供货条款。

**最实用的判断方法：先给一家供应商连续下3批小单，按同一张验收表打分。三批都稳定，再谈放量；有一批明显波动，就要求其说明原因并整改，不要直接放量。**  
如果供应商不愿接受明确规格、验收标准和扣款条款，通常说明其稳定供货能力有限。
