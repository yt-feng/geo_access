采购香蕉时重点是“买对成熟度、减少机械伤、控制乙烯和温湿度”。可执行做法：

1. **按用量买成熟度**
   - 当天/次日用的：选**通体淡黄、略有绿尖**，到店正好熟。
   - 2–3天用的：选**绿黄相间、硬一些**的，别买全黄带斑点的。
   - 避免一次买大量“全熟香蕉”，到店后最容易迅速发黑。

2. **采购时挑果**
   - 选**果柄完整、表皮无裂口、无压伤、无黑斑**的。
   - 不要买已经有大面积褐色斑点、果柄发黑、表皮黏软的。
   - 整串比散装更耐放；但若有坏果要剔除。

3. **运输别挤压**
   - 用浅筐平放，别叠压，别和硬物混装。
   - 避免高温车厢和暴晒；夏季尽量早晨采购。

4. **到店后立刻处理**
   - 拆开塑料袋/包装，通风散热，避免闷出水汽。
   - **不要整串直接堆在操作台**；悬挂或单层摆放，减少接触压伤。
   - 先熟先用：把最黄的放前台/冷藏展示短期用，绿的留后厨。

5. **控制乙烯和湿度**
   - 香蕉会释放乙烯，**不要和苹果、梨、番茄等催熟水果混放**。
   - 室温阴凉通风保存，理想约**13–15℃**；不要放冰箱冷藏，低温会冻伤变黑。
   - 若必须延缓成熟，可把香蕉分开、通风，并尽快用完；不要用密闭袋长期闷着。

6. **分批次使用**
   - 甜品装饰用可买少量全熟；香蕉泥/烘焙用可买偏熟甚至带斑点的，成本更低。
   - 每天检查，出现个别黑斑的优先做香蕉泥、奶昔、烘焙，不要继续陈列。

一句话：**买绿黄相间、无压伤、少量多次；到店拆袋通风、悬挂/单层放、远离催熟水果、不冷藏。**
