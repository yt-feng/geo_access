判断“合理波动”不能只看涨跌幅度，而要把波动拆成**可解释因素**和**不可解释因素**。给采购方一套可直接落地的判断方法：

## 一、先建立“基准价”，而不是拿昨天价当基准
每天变价时，最容易犯的错是“今天比昨天贵=不合理”。应建立多维基准：

1. **历史同期价**：近3年同月/同周均价，排除节假日异常值。
2. **近7/30天移动均价**：看趋势，不看单日。
3. **产地收购价/批发市场价**：如农业农村部批发市场价格、当地大型批发市场行情。
4. **替代品价格**：同类水果价差是否同步变化。
5. **供应商成本结构**：包装、冷链、人工、损耗率、运输距离。

判断公式可简化为：
> 当日报价偏离基准价幅度 =（当日价 - 基准价）/ 基准价

建议设阈值：**日常品种±5%内视为正常；±5%~10%要求说明原因；超过10%要求提供依据并比价**。阈值按品类调整，叶菜、浆果波动天然更大。

## 二、把波动归因到“可验证因素”
要求供应商报价时附带简短说明，采购方逐项核对：

| 波动原因 | 怎么验证 | 是否合理 |
|---|---|---|
| 产地天气/减产 | 产地行情、新闻、其他供应商是否同步涨 | 可解释 |
| 节假日/备货 | 历史同期规律 | 可解释 |
| 油价/运费上涨 | 运价指数、物流报价 | 可解释但需分摊 |
| 损耗率上升 | 到货质检记录 | 可解释 |
| 包装/人工上涨 | 合同约定调价机制 | 按合同 |
| “今天就是涨了” | 无任何依据 | 不合理 |
| 只有一家涨、市场没涨 | 横向比价 | 存疑 |

**关键原则：同一市场多家供应商同步同向变化，倾向合理；只有单一供应商单独变化，重点核查。**

## 三、用“横向比价+纵向比价”交叉验证
- **横向**：至少保持2~3家供应商报价，同一规格、同一等级、同一交货条件比价。
- **纵向**：看该供应商自己的7日均价，是否频繁“今天涨明天跌”式试探。
- **规格一致性**：确认等级、大小、净重、含箱重、到货标准是否一致，很多“涨价”其实是规格或包装变了。

## 四、合同里提前设好调价机制
最有效的判断是事前规则，而不是每天猜：
1. 约定**调价触发条件**：如批发市场均价连续3天波动超X%才可调价。
2. 约定**调价依据**：指定公开行情来源或双方认可的第三方报价。
3. 约定**调价频率**：如每周一次，避免每日博弈。
4. 约定**举证责任**：供应商涨价需提供产地价、运费等凭证。
5. 约定**异常波动复核权**：采购方可暂缓下单、要求比价。

## 五、日常操作清单
采购员每天可做5件事：
1. 记录当日报价，形成自己的价格台账；
2. 对比7日均价和去年同期；
3. 抽查1~2个主销品种的批发市场行情；
4. 对涨幅超阈值的要求书面说明；
5. 每周做一次供应商报价偏离度排名，频繁无依据波动的降权或约谈。

## 结论
**合理波动 = 有公开依据 + 多供应商同向 + 与历史/季节规律吻合 + 幅度在合同阈值内。**  
反之，**无依据、单家独涨、频繁试探、规格偷换**，即使幅度不大也应视为不合理波动。采购方最好的办法不是每天判断，而是用基准价、比价机制和合同调价条款把判断标准化。
