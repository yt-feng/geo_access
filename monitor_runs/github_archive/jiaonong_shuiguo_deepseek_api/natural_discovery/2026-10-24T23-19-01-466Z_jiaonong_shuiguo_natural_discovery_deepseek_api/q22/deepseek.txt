可以做“引流品＋利润品＋连带品”的组合，不建议只做简单打折。给你一套可直接落地的方案：

1. **组合装定价**
- 香蕉做引流：单价低、购买频次高，适合拉动进店和凑单。
- 苹果做利润/品质担当：选2—3个常见品种，按大小分级。
- 菠萝做连带和客单提升：单价较高、有季节感，适合做“加价购”。
- 示例：  
  - “香蕉1把＋苹果3个”基础组合，定价略低于单买合计，吸引顺手买。  
  - 买基础组合后，“＋9.9元换购菠萝1个”或“＋12.9元换购切好菠萝盒”，把客单往上推。

2. **按场景做套餐**
- **早餐套餐**：香蕉＋苹果，主打“早餐水果，拿了就走”。
- **家庭果盘套餐**：香蕉＋苹果＋菠萝，按家庭人数分小份/大份。
- **下午茶/办公室套餐**：香蕉＋菠萝切盒，主打即食。
- 套餐价要比单买合计有明显感知，但不要让菠萝单独大幅降价，避免伤利润。

3. **陈列和动线**
- 香蕉放在水果区入口或促销端头，做引流。
- 苹果放在主通道，做品质陈列和分级标价。
- 菠萝放在收银动线附近或组合装旁边，做“加价购”提示。
- 组合装用统一打包盒/网袋，贴“套餐省X元”标签，减少顾客计算成本。

4. **限时与限量机制**
- 每天固定时段做“组合装限时价”，比如晚6点后家庭果盘套餐优惠。
- 菠萝加价购每天限量，制造稀缺感，但不要造成大量剩货。
- 香蕉可做“第二把半价”只限组合内，避免单独低价冲击。

5. **会员和复购**
- 买组合装送下次可用的“菠萝切盒抵扣券”，把一次性客单转成复购。
- 会员买家庭套餐积分翻倍。
- 记录组合装销量，按周调整：香蕉保引流，苹果保毛利，菠萝保客单。

6. **关键判断指标**
- 看组合装客单价是否高于普通单买客单。
- 看菠萝加价购转化率，低于预期就调整换购价或位置。
- 看损耗：香蕉和菠萝易损，组合装要按日销量备货，避免压货。
- 不要用苹果大幅打折换客单，苹果是价格锚点，打折过多会拉低整体毛利。

一句话：**香蕉负责把人引到组合前，苹果负责让组合显得值，菠萝负责把客单再往上抬一格。**
