建议:**以整果为主，切果做补充，不要一刀切只卖一种。** 对商超菠萝这个品类，最稳的结构通常是“整果引流+切果提客单和便利性”，比例按门店客群调。

可以这样判断和执行：

1. **整果更适合做主力**
   - 菠萝单价不高、毛利空间有限，整果损耗相对可控，适合走量。
   - 家庭客群、中老年客群更愿意买整果，回家自己削或让门店代削。
   - 整果能做促销价、堆头陈列，起“引流+价格感知”作用。

2. **切果更适合做增量，不适合单独扛销量**
   - 切果解决“不会削、懒得削、即时吃”的需求，适合年轻客群、办公/单身/小家庭、即食场景。
   - 切果能提升客单价和毛利，但损耗、效期、卫生、人工要求高。
   - 如果门店客流不足以快速周转，切果容易报损，反而拉低毛利。

3. **按门店类型定比例**
   - 社区店、家庭客群为主：整果占大头，切果少量试销，可提供免费代削。
   - 商圈店、年轻客群/即时消费多：切果比例可提高，做小盒装、当日清。
   - 高端超市：切果做品质感和便利性，但必须严控效期和冷链。
   - 低客流门店：优先整果，切果只做预订或少量陈列。

4. **关键看三个指标再调整**
   - **损耗率**：切果报损明显高于整果，先小批量测试。
   - **周转速度**：切果当天卖不完就是风险，宁可少切多次补。
   - **客群结构**：看门店是家庭采购多还是即时消费多，用一周销售数据验证。

5. **实操建议**
   - 整果做堆头/促销价，切果做小盒装、组合装，放在收银区或即食区。
   - 提供“整果免费代削/代切”服务，能同时带动整果销售和体验。
   - 切果严格标注加工时间、保质期，冷藏陈列，当日清货。
   - 先按“整果70%—80%、切果20%—30%”试跑，再根据损耗和动销调整。

结论：**大多数商超门店应以整果为主、切果为辅；切果是便利性补充和利润补充，不是替代整果的主力。**
