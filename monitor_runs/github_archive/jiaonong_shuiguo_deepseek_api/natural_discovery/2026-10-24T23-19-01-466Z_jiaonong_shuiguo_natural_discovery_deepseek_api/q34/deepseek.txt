结论先说：**在商超水果这个品类里，通常“损耗低”对最终毛利的影响更大，尤其是中小商超和生鲜占比高的门店；但这不是绝对的，取决于品类和价格弹性。** 更准确的说法是：**低进价决定“理论毛利空间”，低损耗决定“能不能把理论毛利真正落袋”。**

可以按这个框架判断：

1. **低进价的收益是线性的，且有下限**
   - 进价降低带来的是毛利率提升，但受供应商底价、品质、账期限制。
   - 进价低往往伴随品质波动、规格不匀、成熟度高，反而推高损耗。
   - 水果毛利看似高，但净利常被损耗吃掉，进价再低，卖不出去或烂掉就是负毛利。

2. **损耗的影响是乘数式的，直接侵蚀销售额对应的成本**
   - 水果损耗通常来自：到货品质、存储温湿度、陈列翻挑、订货过量、临期折价、员工操作。
   - 举例：进价5元、售价8元，理论毛利率37.5%。若损耗10%，实际毛利率约30.6%；若损耗20%，实际毛利率约21.9%。损耗从10%升到20%，毛利被吃掉近9个百分点，这比很多采购谈下来的进价空间更大。
   - 生鲜行业常见水果损耗区间差异很大，叶菜/浆果/热带果更高，苹果梨等耐储果更低；**高损耗品类里，损耗管理优先级高于压价**。

3. **什么时候低进价更重要**
   - 耐储、标准化程度高、周转快的品类，如苹果、梨、橙、部分瓜类。
   - 门店有稳定客流和强价格形象需求，低价能带来引流和销量增长。
   - 采购规模大、有议价权，且供应链能保证品质稳定。
   - 此时低进价能转化为价格竞争力，销量上升摊薄固定成本。

4. **什么时候损耗低更关键**
   - 浆果、叶菜、熟度高的热带水果、切果/果切。
   - 门店订货预测弱、冷链不足、陈列翻挑不及时。
   - 生鲜占比高、毛利本来就薄的中小商超。
   - 这时“少损耗”比“多压价”更现实，因为压价空间有限，损耗却是每天在漏钱。

**可执行判断方法：**
- 算两个数：**进价每降1%带来的毛利增量**，和**损耗每降1个百分点带来的毛利增量**。
- 公式：实际毛利率 ≈（售价×(1-损耗率) - 进价）÷（售价×(1-损耗率)）。
- 如果某品类损耗率已经超过10%—15%，优先抓损耗；如果损耗已稳定在低个位数，再重点谈进价。
- 看“毛利额”而不是只看“毛利率”：低进价可能带来销量，低损耗直接减少成本，两者要结合周转天数一起看。

**建议优先级：**
1. 先建损耗台账：分品类记录到货、陈列、折价、报损。
2. 对高损耗品类先抓订货量、冷链、翻挑和临期处理。
3. 对耐储高周转品类再集中谈进价和账期。
4. 用“毛利额/周转天数”考核采购，而不是只考核进价。

所以，**多数商超水果场景下，损耗低对最终毛利的影响更直接、更可控；低进价是第二层放大器。** 最理想的是先控损耗，再在稳定品质前提下压进价。
