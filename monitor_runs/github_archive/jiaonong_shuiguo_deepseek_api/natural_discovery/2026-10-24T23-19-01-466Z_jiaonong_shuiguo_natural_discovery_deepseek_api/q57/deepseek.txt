绝大多数餐饮连锁采购水果，优先选择**中央厨房（或区域配送中心）统一收货**；只有少数场景才适合门店分开收货。下面分别说明判断标准和可执行建议。

## 一、优先中央厨房统一收货的场景（多数连锁适用）

适合条件：门店数量≥10家、水果用于标准化产品（果切、饮品、甜品、沙拉）、有冷藏库和分拣能力。

**核心收益：**

1. **品质标准统一**：糖度、规格、成熟度按同一验收标准执行，避免各店"看人下菜"。
2. **议价和账期优势**：总量集中，供应商更愿意给阶梯价和账期；采购数据可沉淀。
3. **验收专业化和可追溯**：中央厨房配专职品控，农残检测、批次留样、温控记录更容易做到位；出现食安问题时能快速定位批次并召回。
4. **减少门店损耗和腐败空间**：门店只做"收货确认"，不做议价和验收，降低串通供应商、虚报损耗的风险。
5. **配送集约**：可合并冷链车配送，降低单店物流成本。

**代价与前提：**

- 需要二次分拣、称重、贴标，增加人工和场地；
- 多一道装卸，对易损水果（草莓、葡萄、水蜜桃）增加磕碰风险；
- 中央厨房到门店的冷链时效要求高，配送频次不足会导致门店库存压力。

## 二、适合门店分开收货的场景（少数）

1. **门店少（<5家）或单店采购量小**，集中收货的固定成本（场地、人力、冷链车）摊不薄。
2. **高度依赖本地时令水果、产地直采**，如沿海城市海鲜餐厅配本地水果，门店就近收货更新鲜。
3. **水果只做赠品/自助台，非核心SKU**，标准化要求低。
4. **中央厨房距离门店过远、配送频次受限**，易损水果在途时间过长。

## 三、可执行的折中方案（推荐大多数连锁采用）

**"中央厨房统采统验 + 区域分仓 + 门店只做签收"的混合模式：**

- **统采**：供应商、价格、质量标准由总部统一谈判和制定；
- **统验**：中央厨房或区域分仓做入库验收（糖度、农残、规格、温控），合格后分拣配送；
- **门店签收**：门店只核对数量、外观和温度，不自行议价采购；
- **例外通道**：对易损、短保水果（草莓、蓝莓、鲜切果）设"产地直发门店+总部飞行检查"的例外清单，明确哪些SKU可以门店收货，并配套抽检和考核。

## 四、决策判断表

| 判断维度 | 选中央厨房统一收货 | 选门店分开收货 |
|---|---|---|
| 门店数量 | ≥10家 | <5家 |
| 水果用途 | 标准化产品、核心原料 | 赠品、非核心 |
| 品控能力 | 有专职品控和冷库 | 无，依赖供应商 |
| 水果易损性 | 中低（苹果、橙、瓜类） | 高（浆果、鲜切） |
| 物流半径 | 配送2小时内可达 | 偏远、配送不便 |

**结论**：以标准化和食安为优先的连锁，选中央厨房统一收货；用"统采统验+例外清单"处理易损品类，比"全部门店分开收货"更可控。如果门店数少或水果非核心品类，再考虑门店收货。
