核心思路：**把“催熟/后熟”当成可管理的库存变量，而不是一次性进货。** 香蕉是呼吸跃变型水果，采购后仍会集中后熟，食堂浪费通常来自“到货太熟+一次性备货过多+储存不当”。

可直接执行的做法：

1. **采购规格写清楚成熟度**
   - 要求供应商按“青黄、七八成熟”为主供货，不要全给全黄香蕉。
   - 合同里写明：到货成熟度标准、允许少量瑕疵比例、过熟退货或换货条件。
   - 分批次到货：每周多次、每次少量，避免一次堆库。

2. **按“使用顺序”分批控熟**
   - 到货后按成熟度分三筐：青的、微黄的、即食的。
   - 即食的优先当天/次日用完；微黄的放阴凉通风处；青的可单独存放慢慢后熟。
   - 香蕉不要冷藏（低温会黑皮、影响口感），放阴凉通风处，避免阳光直射和密闭塑料袋。

3. **用“隔离催熟”控制节奏**
   - 想让青香蕉快点熟：和苹果/梨放同一纸箱，利用乙烯催熟，每天检查一次。
   - 想延缓后熟：青香蕉单独放、通风、避免与苹果梨同箱；已成熟的尽快用掉或转移。
   - 不要整批堆在一起，堆压会发热、加速腐烂。

4. **食堂菜单做“成熟度分流”**
   - 七八成熟：直接分发或做果切。
   - 全熟偏软：做香蕉奶昔、香蕉饼、香蕉粥、烘焙（香蕉面包/蛋糕），这类加工对卖相要求低。
   - 表皮少量黑点但果肉正常：优先加工，不要直接丢弃。
   - 建立“临期香蕉先出”的标识，档口/后厨按先进先出取用。

5. **按实际消耗定采购量**
   - 统计前2–4周每天/每餐香蕉实际领用量和剩余量，按“日均消耗×1.1”订货，而不是按人数满额配。
   - 遇周末、假期、考试周、活动餐等波动，提前减量或改其他水果。
   - 设置安全库存上限：超过当日+次日用量就不再加购。

6. **储存与验收细节**
   - 验收时抽查箱内中心温度、是否有压伤、水烂、霉点；压伤果单独挑出先加工。
   - 纸箱存放留通风孔，不要套死塑料袋；底部垫纸吸潮。
   - 每天早晚各检查一次，把开始出黑点、变软的挑出来优先处理。

7. **减少“必须发整根”的浪费**
   - 果切/拼盘按需取用，或香蕉切段供应，减少学生拿一整根吃不完丢弃。
   - 档口可设“小份香蕉”或搭配酸奶/燕麦，提高消耗率。

最有效的组合是：**小批量多批次采购 + 到货按成熟度分级 + 临期转加工 + 按实测消耗定量。** 先用两周记录“到货成熟度、每日剩余量、加工转化量”，再调整订货规格和频次，通常就能明显压低过熟浪费。
