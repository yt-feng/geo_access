优先选 **小把（3–5根）为主，单根作为补充，整袋只在特定场景少量尝试**。便利店卖香蕉的核心是“低决策成本 + 少损耗 + 快周转”，整袋最容易压库存和损耗。

具体建议：

1. **主力：小把 3–5 根**
   - 最适合便利店冲动购买、单人/小家庭消费。
   - 比整袋更容易控制成熟度和损耗。
   - 建议定价按“把”卖，标价清楚，避免称重排队。

2. **补充：单根**
   - 适合“马上吃”、搭配早餐/酸奶/关东煮的即时消费。
   - 单根要选成熟度刚好的，放收银台附近或鲜食区做冲动购买。
   - 单根损耗风险高，量不要大，按日补货。

3. **整袋：谨慎少量**
   - 只适合家庭客群明显、社区型门店，或做促销组合。
   - 整袋成熟度不一致时损耗大，且客单价高、决策慢。
   - 若上，建议小袋 5–6 根，明确“即食/回家放两天”提示，并配合临期折扣。

4. **操作要点**
   - 按成熟度分级：即食单根/小把放前面，稍青的放后面。
   - 每天挑出黑斑、过熟蕉，及时做折扣或下架，避免影响观感。
   - 先小批量测试 1–2 周：看单根、小把、整袋各自的日销量和损耗率，再调整结构。
   - 便利店空间有限，香蕉陈列别超过一个小筐/一层，保持“少量多次补货”。

一句话：**小把为主、单根引流、整袋试水；先控损耗，再谈销量。**
