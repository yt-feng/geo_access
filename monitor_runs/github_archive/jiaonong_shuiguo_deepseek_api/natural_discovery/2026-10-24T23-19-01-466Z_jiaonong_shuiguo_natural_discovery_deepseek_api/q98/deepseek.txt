判断水果供应商的合规和稳定性，可以从“资质查验—实地核验—合同约束—试运行—持续监控”五个环节做，重点是可核验、可留痕。养老院/医院属高风险供餐场景，标准要比普通食堂更严。

**一、合规性核验（先查硬门槛）**

1. 主体资质：营业执照经营范围含食用农产品销售/食品销售；索要食品经营许可证（或仅销售预包装食品备案），核对名称、地址、有效期与供货主体一致。
2. 人员与场所：配送人员健康证明；仓储、分拣场所照片或现场查看，是否有防鼠防虫、冷藏设施、清洗分拣区。
3. 检测与票据：每批次能提供产地证明或进货凭证、农药残留快检报告（自检或第三方）；能开具发票或正规销售凭证，做到票货相符。
4. 特殊要求：医院/养老院常要求供应商有食品安全责任险；询问是否有食品安全事故记录、行政处罚记录（可要求供应商书面承诺，并在国家企业信用信息公示系统等官方渠道自查）。
5. 车辆与温控：运输车辆是否专用、清洁，冷藏水果是否有温控记录。

**二、稳定性判断（看履约能力）**

1. 经营年限与主营：优先选主营水果、经营2年以上、有固定档口/仓库/合作基地的供应商；警惕临时拼凑的“二道贩子”。
2. 供应来源：是否有稳定产地或一级批发市场档口，能否说明主要品类来源和季节替代方案。
3. 配送能力：配送车辆数量、冷链能力、每日配送时段、应急补货响应时间；问清节假日和极端天气的保供方案。
4. 客户案例：要求提供同类机构（医院、养老院、学校食堂）供货案例，可电话回访；观察其是否愿意接受实地考察。
5. 价格与账期：报价是否随行就市且有调价机制；账期过长可能反映资金压力，过短则影响合作意愿，需平衡。

**三、合同约束（把稳定性写进条款）**

1. 明确品名、规格、等级、单价、调价周期和依据（如批发市场均价）。
2. 质量条款：农残超标、腐烂率、缺斤短两的退换货和违约责任；约定抽检频次和不合格处理。
3. 履约保障：履约保证金或质量保证金；断供、迟送的违约金；连续不合格的解除权。
4. 票据与追溯：每批次随货附检测报告/产地证明，建立进货台账，保存不少于6个月（按当地监管要求）。
5. 食品安全责任：明确因供应商原因造成食源性事件的赔偿责任，要求提供责任险保单。

**四、试运行与评估**

先签1—3个月试用合同或小批量供货，按“到货准时率、验收合格率、缺货率、投诉响应、票据齐全率”打分；连续2—3次不合格即淘汰。养老院/医院建议保持2家合格供应商，主供+备供，避免单一依赖。

**五、持续监控**

每月汇总验收记录和投诉；每季度复核证照有效期、检测报告；每年重新评估或重新比价。发现证照过期、检测造假、频繁断供，立即暂停并启动备供。

**快速判断清单（现场可用）：**
- 证照是否齐全且在有效期内、主体一致？
- 能否当场出示最近一批次的检测报告和进货凭证？
- 有无固定仓库/档口和冷藏配送车？
- 有无同类机构供货案例且可回访？
- 是否接受试用期、保证金和退换货条款？
- 断供时的补货时限能否书面承诺？

满足以上大部分条件，基本可判断为合规且较稳定；任何一项关键资质缺失或拒绝提供票据/检测报告，建议直接排除。
