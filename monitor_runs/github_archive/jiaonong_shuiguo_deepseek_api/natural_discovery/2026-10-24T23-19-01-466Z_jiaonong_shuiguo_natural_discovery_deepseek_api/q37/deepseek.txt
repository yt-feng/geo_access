商超会员日水果活动，供应商的配合重点不是“多送货”，而是围绕**爆量、品质稳定、价格锁定、陈列物料、补货节奏、售后兜底**提前做预案。可按下面清单推进：

**1. 活动前7–10天：确认活动方案**
- 确认活动品项、活动价、供货价、毛利空间、活动量预估、限购规则。
- 明确供应商承担的费用：特价支持、损耗补贴、陈列费、促销员、赠品、物料。
- 锁定价格有效期，避免活动前临时涨价或断供。
- 确认活动门店清单、各店预估销量和配送频次。

**2. 活动前5–7天：货源与品质预案**
- 按预估销量备货，主推品备货量建议为日常的2–3倍，并准备备用货源。
- 提前采摘/催熟/分级，确保会员日当天成熟度、糖度、果径、色泽达标。
- 明确分级标准：活动爆品用统一规格，避免大小混装引发投诉。
- 准备次品替换方案，避免以次充好。
- 对易损耗水果（草莓、蓝莓、荔枝、榴莲等）控制单批到货量，增加配送频次。

**3. 活动前3–5天：物流与到店节奏**
- 确认配送时间，建议活动前一天完成首轮铺货，活动当天早间补一轮。
- 按门店销量分级配送，避免小店压货、大店断货。
- 冷链品确认全程温控，到店验收标准提前对齐。
- 准备好周转筐、保鲜膜、冰袋、陈列道具等。
- 明确缺货、迟到、品质不达标的应急联系人和处理时限。

**4. 活动前1–3天：陈列与促销配合**
- 提供堆头/端架陈列方案，包括陈列量、层级、POP卖点。
- 提供试吃品、试吃台、一次性用品，安排试吃人员。
- 配合制作价签、爆炸贴、产地/卖点说明。
- 对榴莲、菠萝蜜等需现场分切的品项，提前安排刀工人员或培训门店员工。
- 安排促销员在重点门店驻场，负责补货、试吃、导购。

**5. 活动当天：补货与品质巡检**
- 供应商业务员巡店，重点看排面丰满度、品质、价签一致性。
- 建立补货响应机制：门店报缺后2–4小时内响应，重点店优先。
- 发现品质问题立即换货，不拖延、不扯皮。
- 记录各店实际销量，为次日补货和下次活动做数据沉淀。

**6. 活动后：复盘与结算**
- 48小时内完成损耗确认、退换货处理、费用对账。
- 复盘活动销量、断货率、损耗率、客诉率、毛利率。
- 对表现好的品项形成下次会员日主推清单。

**最关键的三件事：**
1. **价格和货量提前锁死**，不能活动前变价或断供。
2. **品质标准前置确认**，避免到店后被拒收或引发客诉。
3. **补货响应人明确到姓名和电话**，活动当天能快速处理缺货和品质问题。

建议商超采购给供应商发一张《会员日水果活动供应商准备确认表》，逐项打勾确认，活动前3天完成复核。
