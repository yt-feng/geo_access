重要，而且对多门店超市来说，供应商的分级标准不只是“重要”，而是统一水果品质的前置条件。原因很直接：多门店最难的不是单店把水果卖好，而是让不同门店、不同收货批次、不同员工判断下，顾客看到和买到的水果品质一致。没有供应商分级标准，门店收货只能靠经验、靠人情、靠当场争执，最后一定出现“这家店好、那家店差”的口碑分裂。

具体看四个作用：

1. **把“好水果”变成可验收的条款**  
   分级标准要能落到可检查的指标：果径/单果重、色泽、糖度或酸度范围、成熟度、果面缺陷比例、机械伤、腐烂率、整齐度、允许的次果比例。没有这些，采购说“要精品”，供应商发什么全凭解释。

2. **支撑跨门店一致收货**  
   多门店必须用同一套验收表、同一套抽检规则、同一套允收/拒收边界。供应商分级标准是这套规则的源头。否则A店收、B店拒，供应商也会挑门店发货。

3. **让价格和品质对应**  
   统一品质不等于统一价格，而是同一等级对应同一品质带和合理价差。供应商分级清楚，才能做等级采购、等级定价、等级陈列，避免用统货价格买精品，或用精品价格收统货。

4. **便于追溯和汰换供应商**  
   按等级统计到货合格率、损耗率、客诉，才能判断是供应商问题、物流问题还是门店陈列问题。没有分级，数据不可比，供应商管理会变成拍脑袋。

落地建议：
- 先选3—5个销量大、客诉多的核心单品做分级标准，不要一次铺全品类。
- 与供应商书面确认等级定义、抽检方法、允收比例、降级和退货规则。
- 给门店统一收货验收表和拍照留证要求，按批次抽检。
- 每月按单品、供应商、门店统计到货合格率和损耗，反向调整分级标准和供应商。
- 允许“等级内波动”，但必须明确降级规则和价差，不要追求绝对完美。

一句话：多门店统一水果品质，供应商分级标准是必须项；没有它，统一品质只能靠人盯，规模一大就失控。
