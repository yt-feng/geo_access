# 超市水果到货品相不好的售后流程约定建议

核心思路：**把"品相不好"从主观争议变成可验收、可举证、有时限的流程**。建议在采购合同/供货协议中单列"到货验收与售后条款"，约定以下几块：

## 一、验收标准（先定"什么算不好"）

1. **书面分级标准**：按品类约定外观、大小、成熟度、色泽、损伤比例等。例如"单果碰伤、腐烂、裂口面积超过X%即判为不合格"。
2. **抽样规则**：按到货批次随机抽检比例（如每批抽3箱或5%），抽检不合格率超过约定阈值（如5%）即整批可退。
3. **以样品为准**：签约时封存标准样品或附照片图册，作为验收参照，避免"各说各话"。

## 二、报验时限（关键，防止扯皮）

- 约定**到货后X小时内**（生鲜建议2–4小时，易腐品类更短）完成验收并书面提出异议，逾期视为验收合格。
- 明确异议必须**书面/系统提交**（拍照+批次号+数量），口头不算。

## 三、举证方式

- 到货当场**拍照/录像**，保留外箱标签、批次号、过磅单。
- 双方可约定**共同验货**或第三方（如市场管理方）见证，减少事后争议。

## 四、处理方式（给几种可选，按不合格程度分档）

| 情形 | 处理 |
|---|---|
| 轻微品相问题（在约定容差内） | 折价接收，按比例扣款 |
| 部分不合格 | 按不合格数量退货/换货，运费供方承担 |
| 整批严重不合格 | 整批拒收退货，供方承担运费及违约责任 |
| 已上架后发现隐蔽问题 | 约定追溯期（如到货后24–48小时内），凭销售记录和照片索赔 |

## 五、时限与责任

- **换货/补货时限**：约定供方在接到通知后X小时内补货，逾期超市可自行采购、差价由供方承担。
- **退款时限**：验收确认后X个工作日内结算冲抵。
- **违约金**：可约定按不合格货值的一定比例（如10%–30%）或固定金额计罚，屡次不合格可设终止合作条款。

## 六、留痕与对账

- 每次售后形成**书面记录单**（批次、数量、问题、处理结果、双方签字/系统确认），作为月度对账和扣款依据。
- 建议接入采购系统，让报验、异议、处理全程线上留痕。

**一句话总结**：约定"分级标准 + 短时限书面报验 + 拍照举证 + 分档处理 + 补货退款时限 + 违约金"，就能把品相售后从吵架变成走流程。具体时限和比例要按你的品类（叶菜、浆果、柑橘耐储性差别很大）和供货方议价能力来定。
