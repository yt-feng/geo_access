和品牌方谈代理时，区域保护和串货这两件事不要在“意向沟通”里泛泛问，要落到合同条款和可执行机制上。下面给你一套可直接照着问的问题清单，以及要盯住的判断点。

**一、区域保护怎么问（问清楚“保护什么、保护到哪、怎么执行”）**

1. 我申请的区域，是独家代理还是非独家？独家的话，是品类独家还是全品牌独家？授权书里写不写“独家”字样？
2. 保护范围是按行政区域（省/市/区县）、渠道（商超/农贸/餐饮/电商）、还是按客户类型划分？线上销售归谁？
3. 保护期内品牌方自己能不能在我区域内直营、开旗舰店、做电商发货？团购、直播、社区团购算不算冲我的区域？
4. 区域内出现其他经销商供货，品牌方怎么处理？有没有明确的处罚和终止条款？
5. 区域保护的期限是多久？续约条件是什么？完不成任务量会不会被取消独家？
6. 品牌方在其他区域授权了谁，能不能披露相邻区域的代理情况（至少告诉我边界上有没有重叠）？

判断点：只说“你放心，我们保护你”但合同不写独家、不写区域、不写线上归属的，基本等于没有保护。一定要拿到写进合同的区域清单和独家条款。

**二、串货怎么问（问清楚“怎么认定、怎么查、怎么罚”）**

1. 品牌方对串货的定义是什么？跨区域销售、低价倾销、线上乱价，分别怎么认定？
2. 产品有没有批次码、箱码、防窜货追溯系统？扫码能不能查到出货区域和经销商？这是查串货的硬手段，没有追溯码的串货基本查不清。
3. 发现串货后，举报流程是什么？品牌方多久响应、多久给处理结果？
4. 对串货方的处罚是什么？扣保证金、停货、取消返利、终止代理，写不写进合同？对我作为被窜货方的补偿有没有？
5. 我自己的货如果被下游客户窜到别的区域，责任怎么算？品牌方会不会直接罚我？
6. 线上价格和跨区发货怎么管？品牌方有没有统一的线上授权和价格体系？

判断点：没有追溯码、没有书面处罚条款、没有举报响应时限的“防串货”，大概率是口头承诺。要问品牌方要一份现有的窜货处理制度或合同附件看看。

**三、谈的时候顺带确认的配套问题**

- 首批打款、年度任务量、保证金各多少？保证金退还条件？
- 返利、账期、退换货政策（尤其临期/滞销水果）？
- 品牌方给不给区域内的市场投入、陈列支持、促销费用？
- 如果因为串货导致我完不成任务，任务考核能不能豁免？

**四、实操建议**

- 把所有关键承诺写进代理合同或补充协议，口头的不算。
- 要求品牌方提供授权书原件、区域独家条款、窜货追溯和处罚制度作为合同附件。
- 签约前查一下该品牌在你要的区域是否已有其他代理，可以侧面问同行或看其线上旗舰店发货地。
- 先小批量试合作一个周期，观察品牌方对串货举报的实际响应，再决定是否加大投入。

一句话：区域保护问“写不写进合同、线上算不算、品牌方自己冲不冲”；串货问“有没有码、怎么查、罚不罚、赔不赔”。这两样没有书面机制，代理风险基本由你承担。
