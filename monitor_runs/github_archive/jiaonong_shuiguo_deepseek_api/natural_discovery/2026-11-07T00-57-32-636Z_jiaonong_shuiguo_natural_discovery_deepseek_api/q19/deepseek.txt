优先关注**切果损耗**，其次甜度、外观，大小最后。原因：超市卖菠萝的真实利润不在“看起来好”，而在**整果到可售果肉/切果的转化率**。菠萝冠芽、皮、眼、芯和两端都会吃掉重量，损耗高会直接吞掉毛利。

可执行判断顺序：

1. **切果损耗（最优先）**
   - 看同样进货规格下，去皮去眼后出肉率、切果成品率、报废率。
   - 重点盯：黑心、水心病、过熟软烂、机械伤、冠芽过大、果眼深。
   - 建议按批次抽切记录：进货重量→可售果肉/切果重量→废弃重量，算出品率。出肉率稳定比单果大更重要。

2. **甜度**
   - 甜度决定复购和是否适合鲜切/即食。
   - 但不能只看糖度：要结合酸度、成熟度、纤维感。过熟虽甜，切果损耗和货架期反而差。
   - 建议到货抽测糖度，并记录不同产地/批次差异。

3. **外观**
   - 外观影响陈列和整果销售，但不是越漂亮越好。
   - 看果形端正、果眼浅、无病斑、无裂口、冠芽新鲜。果眼浅能直接降低切果人工和损耗。
   - 外观有瑕疵但适合切果的，可做分级销售，不应一刀切报废。

4. **大小**
   - 大小主要影响定价和客群匹配，不是核心盈利指标。
   - 大果未必出肉率高，小果未必损耗低。应结合出肉率和单果售价看“每斤可售果肉成本”。

**结论：** 超市卖菠萝应把“切果损耗/出肉率”作为第一考核指标，甜度作为复购指标，外观作为陈列分级指标，大小作为定价和规格指标。最实用的做法是：按批次抽切，建立“出肉率+糖度+外观等级”的分级采购标准，而不是只凭大小和卖相进货。
