香蕉怕压、怕冷、怕乙烯，采购时要把“熟度”和“到货节奏”分开管，不要一次全进同一熟度。

**1. 采购熟度怎么要求**
- 主线用“青黄交接”的香蕉：果身大部分青绿、棱角明显、只有轻微转黄，适合放3—5天慢慢卖。
- 少量配“黄熟蕉”：表皮已黄、无黑斑或仅极少量芝麻点，用于1—2天内卖完或做促销。
- 明确拒收标准：到货时不得有大面积黑斑、果指发软、果柄发黑霉、机械压伤、水烂；青蕉可以青，但不能“青硬到不转黄”或有冻伤。
- 最好按“成熟度”而不是只按“青/黄”口头描述，要求供应商分批次、分熟度装筐，并在筐上标注采收/发货日期和熟度。

**2. 到货时间怎么要求**
- 不要一次到齐：按日销量拆成2—3批到货，例如周一、周三、周五各到一批，保证每批有3天左右销售窗口。
- 要求“到店即入周转”的到货时段：尽量安排在开门前或上午早段到货，避免下午高温时段卸货、堆在店外。
- 缩短在途时间：要求供应商说明发货时间，优先选择运输时间短、途中不混装催熟水果的批次；夏天避免中午到货。
- 新批次和旧批次分开：到货后先进先出，旧蕉放前排，新蕉放后排/后仓，不要混筐。

**3. 采购单上建议直接写清**
> 青黄蕉×箱，要求果身青绿微转黄、无黑斑软果，分2批到货：周X、周X上午到店；黄熟蕉×箱，要求黄皮无黑斑，周X到货当天可售。到货发现软烂、黑斑、压伤、冻伤按比例拒收或折价。

**4. 配套动作**
- 香蕉不要冷藏，放阴凉通风处；夏天可适当加快周转，冬天注意防冻。
- 黄熟蕉单独陈列、优先促销，避免乙烯催熟旁边青蕉。
- 记录每批到货熟度、到货日、售完日，连续记2—3周就能定出适合你店销量的“熟度+频次”组合。

核心要求一句话：**青黄蕉为主、黄熟蕉少量，分批到货、上午到店，写清拒收标准，先进先出。**
