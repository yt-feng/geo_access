判断茶饮连锁的菠萝供应商能否稳定按规格送货，不能只看报价和样品，要按“规格定义—产能与季节—分级与品控—履约与追溯”四层做验证。可执行的做法如下：

1. **先把规格写成可验收标准**
   - 明确品种/产地、单果重量区间、果径、成熟度（糖度、酸度、色泽）、外观缺陷允许比例、农残标准、包装方式（箱规、每箱净重、是否带冠芽）、到货温度、压伤/黑心/水心病等拒收项。
   - 茶饮常用菠萝要区分“鲜果现切”和“工厂预处理果块/果酱原料”，两者的验收标准不同，不要用一份标准混用。

2. **验证真实产能和季节性**
   - 要求供应商提供近6—12个月同类客户的供货记录或出货单（可脱敏），核对高峰期日/周供货量。
   - 问清自有基地、合作基地、代采比例；菠萝有明显产季和产区切换，要确认淡季替代产区、跨区调货能力和价格波动处理方式。
   - 至少准备“主供应商+备选供应商”，避免单一产区天气或物流中断导致断供。

3. **现场看分级和品控**
   - 到分选现场看：是否按重量/果径分级，分级后抽检合格率，次果如何处理，是否有预冷和保鲜措施。
   - 连续抽3—5批到货做验收记录，重点看规格达标率、压伤率、成熟度一致性、箱内上下层是否一致。只看样品容易“样品好、大货差”。
   - 要求每批提供农残检测报告或产地证明，并约定第三方抽检和不合格处理。

4. **用小单试履约，再签框架**
   - 先下2—4周小批量订单，按真实门店节奏测试准时率、缺货率、破损率、临时加单响应。
   - 合同里写清：规格公差、允许缺陷比例、到货时限、冷链/运输责任、拒收和补货时限、缺货违约金、价格调整机制、批次追溯（产地/采收日/分选日）。
   - 建立到货评分表，按批次记录“规格合格率、准时率、破损率、异常处理速度”，连续不达标就降量或切换备选。

**快速判断口诀**：规格能验收、产能有记录、分级在现场、小单先跑通、合同有罚则、备选不断供。样品和大货分开看，旺季和淡季分开问，才能判断是不是“稳定按规格送货”。
