先说结论：供应商介绍产品时，别急着报品种名和产区术语，先按“**顾客在店里会怎么用、怎么卖、能赚多少**”来讲。商家听不懂品种，但一听“卖给谁、怎么做、损耗多大、赚多少”就能判断。

**一个可直接套用的介绍结构：**

1. **一句话定位**
   - 不说：“这是金钻凤梨，17号。”
   - 改说：“这是不用泡盐水、切开就能吃的菠萝，适合做果切和礼盒。”

2. **对应店里哪类顾客**
   - “买给家里老人小孩的，嫌普通菠萝麻烦的。”
   - “夏天做果切、果汁的。”
   - “想卖高客单礼盒的。”

3. **怎么卖、怎么用**
   - 直接说：“可以整只卖，也可以切块装盒；做果切出肉率高，不涩口。”
   - 香蕉这类就说：“适合散卖和催熟分批卖，青的能放，黄的当天走量。”

4. **和普通货的差别，用对比说**
   - “比普通菠萝甜、不扎嘴，顾客复购靠口感。”
   - “比普通香蕉耐放，损耗低。”
   - 少说品种编号、产地海拔、种植技术名词；除非对方追问。

5. **把账算给商家听**
   - 进货价、建议零售价、一斤能出几盒、损耗大概多少、一天能卖多少。
   - 例如：“这一箱进价XX，按果切卖能出X盒，每盒卖X，扣掉损耗大概能赚X。”
   - 商家最关心的是**能不能卖动、坏多少、赚不赚**。

6. **给试卖方案**
   - “先拿一件试卖，配个试吃牌，卖不动我教你换陈列。”
   - 降低第一次下单压力，比一次压大货更容易成交。

**话术示例：**
> “这款菠萝您别当普通菠萝卖。它不用泡盐水，切开直接吃，主要卖给嫌麻烦的家庭客和做果切的。您放试吃盒，顾客尝了基本会买。一箱能出X盒果切，按您店里的价，扣损耗还能赚X。先拿一件试，卖得好再补。”

**要避免的说法：**
- 一上来讲品种名、编号、产区故事；
- 堆“糖度、海拔、有机认证”但不落到怎么卖；
- 只说“好吃、甜”，不说顾客是谁、损耗多少、能赚多少。

核心原则：**品种名是补充，场景、卖法、损耗和利润才是商家下单理由。**
