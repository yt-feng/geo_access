评估水果供应商的仓配覆盖，核心不是“供应商有几个仓”，而是“从哪个仓、经哪条线路、在多长时间内、以什么损耗水平把哪些SKU送到哪些门店”。建议按以下框架做可执行评估。

## 1. 先建立门店与SKU的需求底图
1. **门店分级**：按城市、单店日均水果销量、SKU数、温层要求（常温/冷藏/冷冻）、到货频次、收货时间窗分级。
2. **SKU分级**：按保质期、损耗敏感度、是否需预冷/冷藏、是否可长途运输分级。叶菜类、浆果类、切果类对时效和温控要求显著高于苹果、橙类。
3. **需求聚合**：按城市/区域汇总日均销量和峰值销量，形成“城市—门店—SKU—频次—温层”矩阵。

## 2. 评估供应商仓网的实际服务能力
不要只看仓库数量，要看每个仓的：
- **位置与辐射半径**：到目标城市/门店的实际里程和行车时间，而非直线距离。
- **仓型与温区**：常温、冷藏、冷冻库容及可分配比例；是否有预冷、分拣、催熟/后熟能力。
- **库存覆盖**：该仓能覆盖哪些SKU、安全库存水平、断货率。
- **越库/直发能力**：是否支持越库、产地直发、城市前置仓补货。
- **产能与峰值**：日均处理订单行数、峰值处理能力、分拣准确率。

## 3. 用“时效—损耗—成本”三线评估线路
对每条“仓—城市—门店”线路，分别测算：
- **履约时效**：下单到到店时间、是否满足门店收货时间窗、异常延迟率。
- **损耗水平**：运输时长、温控稳定性、装卸次数、包装适配性对应的预估损耗率。
- **物流成本**：干线+城配+仓储+损耗成本，折算到每店每日或每公斤。

建议设定硬门槛，例如：核心城市次日达、冷链SKU全程温控可追溯、单店订单满足率≥95%、损耗率不超过品类目标值。达不到即视为覆盖缺口。

## 4. 做覆盖缺口地图
把门店需求底图和供应商仓配能力叠加，标记四类缺口：
- **无仓覆盖**：某城市超出经济配送半径。
- **有时效缺口**：有仓但无法满足到店时间窗。
- **有温控缺口**：冷链SKU无法全程温控。
- **有产能缺口**：峰值订单处理不了。

缺口按“门店销售额占比、损耗敏感SKU占比、缺货影响”排序，决定是要求供应商开前置仓、换仓、引入区域供应商，还是调整配送频次。

## 5. 多供应商与混合仓配策略
连锁门店通常不宜单一供应商全覆盖。可考虑：
- **区域主供应商+城市前置仓**：主供应商负责干线，前置仓负责最后一公里。
- **产地直发+城市仓补货**：耐储SKU直发，易损SKU城市仓覆盖。
- **多供应商分区**：按城市群划分主供区域，保留备份供应商。
- **动态切换规则**：按时效、损耗、缺货率设置切换阈值。

## 6. 试运行与持续考核
正式签约前做2—4周试运行，按城市抽门店验证：
- 订单满足率
- 到店准时率
- 冷链断链次数
- 损耗率
- 缺货导致的门店补货成本
- 每公斤/每店履约成本

把结果回写到覆盖地图，按季度复评。供应商仓配覆盖不是一次性评估，而是随门店扩张、季节产量和SKU变化持续校准的过程。

**一句话判断标准**：供应商的仓配覆盖是否合格，取决于目标门店在约定时效内、以可接受的损耗和成本、稳定拿到所需SKU的比例；这个比例达不到经营阈值，就是覆盖不足，需要补仓、换线或引入区域供应商。
