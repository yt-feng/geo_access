商超会员日水果活动，供应商要提前配合的核心是：**保量、保品质、保价格、保到货时效、保现场陈列和应急补货**。可按下面清单推进：

1. **活动资源确认**
   - 提前确认活动品项、活动价、供货价、毛利空间、费用分摊（特价补贴、陈列费、损耗补贴）。
   - 书面锁定活动量、日供货量、总供货量及增幅上限，避免临时加量无法满足。

2. **货源与备货**
   - 提前7—15天锁定产地/基地货源，活动前3—5天完成备货。
   - 对易损耗、短保质期水果按日分批到货，避免一次性压货。
   - 准备备用货源和替代品项，防止主推品断货。

3. **品质标准**
   - 按商超验收标准提前分级，明确糖度、果径、色泽、成熟度、瑕疵率、包装规格。
   - 活动前做一次样品确认，避免到货后因品质争议拒收。
   - 成熟度按销售节奏控制，会员日首日不能过生或过熟。

4. **价格与促销配合**
   - 提前锁定活动价和供货价，明确调价机制，活动期间不得随意涨价。
   - 配合商超做堆头、端架、试吃、买赠、满减等陈列和促销物料。
   - 明确特价品的量价平衡，防止低价引流后断供。

5. **物流到货**
   - 按商超要求的到货时间、频次、收货口和预约流程排车。
   - 活动日建议增加配送频次，早市前到货，下午安排补货。
   - 冷链水果全程温控，运输防挤压、防雨淋、防暴晒。

6. **包装与陈列支持**
   - 提供适合堆头/端架陈列的周转箱、托盘、价签、POP、试吃物料。
   - 按商超陈列标准做预包装、分级装、家庭装、小规格引流装。
   - 安排驻场或巡场人员，活动首日到店协助陈列、补货、挑拣。

7. **人员与应急**
   - 明确供应商对接人、电话、到货司机和应急联系人。
   - 制定断货、品质异常、到货延迟的替代方案和赔付规则。
   - 活动期间安排巡店，发现缺货、品质下降及时补货换货。

8. **损耗与售后**
   - 提前约定损耗承担比例、退换货规则、残次品处理方式。
   - 对高损耗品项控制单次到货量，少量多次补货。
   - 活动结束后及时对账，处理退换货和费用结算。

建议供应商在活动前至少开一次三方对接会：商超采购、门店运营、供应商，形成一张《会员日水果活动备货执行表》，把品项、数量、价格、到货时间、陈列位置、责任人、应急预案全部落表。这样活动当天才能做到不断货、不降质、不乱价。
