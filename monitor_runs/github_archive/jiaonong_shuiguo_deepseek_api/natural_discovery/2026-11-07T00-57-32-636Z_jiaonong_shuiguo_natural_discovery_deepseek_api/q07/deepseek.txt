做水果礼盒，关键不是“把贵的装一起”，而是让顾客一眼看懂价格带和送礼场景。苹果、橙子、香蕉、菠萝这四种做组合，建议这样搭：

**1. 主推款：苹果+橙子，走“平安吉利”**
- 配比：苹果6个+橙子6个，或苹果8个+橙子4个
- 卖点：平安、心想事成，颜色红黄搭配好看，耐放、损耗低
- 适合：日常送礼、探病、员工福利
- 定价：中档，最容易走量

**2. 走量款：苹果+橙子+香蕉，走“家庭分享”**
- 配比：苹果4个+橙子4个+香蕉1把
- 卖点：颜色丰富、份量足、价格亲民
- 注意：香蕉容易催熟其他水果，最好用独立袋或放在上层，礼盒别提前太久备货
- 适合：社区团购、家庭自用、促销引流

**3. 形象款：苹果+橙子+菠萝，走“节庆高档”**
- 配比：苹果6个+橙子4个+菠萝1个
- 卖点：菠萝寓意“旺来”，整体饱满有分量，适合春节、开业、乔迁
- 注意：菠萝带刺、占空间，礼盒要选深一点的；可加开菠萝工具或贺卡提升价值感
- 适合：节庆礼盒、企业团购

**4. 不建议主推：四种全混装**
- 香蕉和菠萝成熟后气味重、易压伤，混装损耗高
- 四种放一起容易显得杂，反而不像“礼盒”
- 如果一定要做，香蕉单独包装，菠萝放底部固定

**实操建议：**
- 只做2-3个价格档，别让顾客选择困难：比如引流款、主推款、高档款
- 苹果和橙子做基础盘，香蕉做亲和力，菠萝做节庆感
- 礼盒外观比水果种类更重要：统一纸盒、腰封、贺卡，写上“平安橙意”“旺来福到”这类话
- 先小批量试3种组合，看一周动销，卖得最好的再加量

简单说：**苹果+橙子做主推，加香蕉做走量，加菠萝做节庆高价，别四种全混。**
