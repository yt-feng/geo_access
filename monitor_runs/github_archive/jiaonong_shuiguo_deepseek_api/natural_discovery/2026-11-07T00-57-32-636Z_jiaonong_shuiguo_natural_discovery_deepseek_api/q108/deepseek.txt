要核实水果供应商的“全国配送”是否真实，重点不是听他怎么说，而是把“全国配送”拆成可验证的几项能力：**发货仓/产地仓位置、干线运输方式、末端覆盖范围、时效、温控能力、异常处理、费用边界**。建议按下面步骤做。

### 1. 先让对方把“全国配送”定义清楚
直接要求供应商书面说明：
- 从哪些仓/产地发货？各仓地址、面积、是否自有或租赁。
- 覆盖哪些省份/城市？哪些地区不配送或加价？新疆、西藏、青海、内蒙古、海南、偏远县乡是否覆盖？
- 是“直达城市”“到地级市”“到县级”“到乡镇”中的哪一级？
- 配送是供应商自送、外包快递、零担物流，还是落地配？
- 水果是否全程温控？冷链到哪一段，末端是否断冷？
- 起送量、配送时效、破损/腐损赔付规则。

**判断标准**：如果对方只能口头说“都能发”，但给不出仓库地址、覆盖清单、承运商和时效表，实际覆盖能力通常不可靠。

### 2. 要求提供可核验的仓库和物流证据
可要求提供：
- 仓库租赁合同关键页、仓库照片/视频、仓内货架和温控设备照片；
- 与承运商/快递公司的合作协议或月结账号截图；
- 近期发往不同区域的实际运单号，至少覆盖华东、华南、华北、西南、西北、东北各1—2单；
- 运单轨迹截图，核对发货地、中转地、签收地、时效。

**核验方法**：拿运单号到对应快递/物流官网查轨迹，重点看是否真的从所述仓库发出、是否到达承诺区域、是否冷链标注、签收时间是否匹配。

### 3. 做小批量“多点试单”
不要一开始大额采购。选3—5个有代表性的收货地址做试单：
- 一线城市；
- 省会城市；
- 普通地级市；
- 县级/乡镇地址；
- 偏远地区地址。

每单记录：下单时间、发货时间、到达时间、包装状态、果温、破损率、腐损率、末端是否送货上门。试单量可以小，但地址要有区分度。

**判断标准**：如果偏远地区试单失败、时效明显超承诺、末端断冷或破损高，就不能按“全国配送”来设计采购计划。

### 4. 核实冷链和水果适配能力
水果配送不是普通快递，重点问：
- 哪些品类走冷链，哪些走常温？
- 泡沫箱+冰袋能维持多久？夏季高温线路是否有干冰/冷藏车？
- 中转环节是否开箱？末端配送是否暴晒？
- 到货后出现软化、霉变、冻伤，怎么判定责任和赔付？

可要求供应商提供近期同品类、同线路的**温控记录或客户反馈样本**，但要注意样本可能被挑选，最好结合自己的试单验证。

### 5. 查覆盖边界和费用陷阱
“全国配送”常见问题是“能发但加价”或“能到但不到门”。要确认：
- 偏远地区附加费标准；
- 超重/超大件费用；
- 上楼费、卸货费、二次配送费；
- 拒收、改址、退货费用；
- 节假日和旺季是否停发或涨价；
- 最低起送量和混装限制。

让对方提供**完整报价表**，而不是只给一个“全国包邮/全国可发”的结论。

### 6. 做供应商资质和履约背景核查
- 查营业执照经营范围是否含道路货物运输、冷链运输、食品销售等；
- 通过国家企业信用信息公示系统查经营异常、行政处罚；
- 要求提供食品经营许可证或食用农产品相关资质；
- 询问合作客户案例，最好能联系1—2家同区域客户侧面了解；
- 对声称“自有冷链车队”的，要求看车辆行驶证、冷藏车照片和温控设备。

### 7. 合同里把“覆盖能力”写成可执行条款
建议写入：
- 明确覆盖区域清单和不到达区域；
- 各区域承诺时效；
- 冷链环节和到货温度范围；
- 破损率/腐损率上限及赔付标准；
- 试单不达标可终止合作；
- 因配送不到、时效超期造成的损失承担方式。

### 实操结论
采购方最有效的核实顺序是：**要覆盖清单和仓库/承运商证据 → 查运单轨迹 → 多点小批量试单 → 核对冷链和费用 → 合同约束**。如果供应商只能提供口头承诺，不能提供仓库、运单、承运商和时效证据，建议不要按其“全国配送”能力做采购布局；可以先按试单结果只开放已验证区域。
