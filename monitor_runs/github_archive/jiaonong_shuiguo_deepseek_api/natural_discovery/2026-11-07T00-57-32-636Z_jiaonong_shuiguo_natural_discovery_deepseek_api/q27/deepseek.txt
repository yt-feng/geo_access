判断门店销售规格，核心不是“找最大最好”，而是看**目标客群、陈列方式、损耗、定价带**是否匹配。可按下面步骤快速判断。

## 1. 先定销售场景与规格带
采购前先明确门店类型：

- **社区生鲜店/便利店**：家庭即时消费，偏中等规格，单果不宜过大，价格敏感。
- **商超散称区**：规格可稍宽，但要整齐，便于顾客挑选。
- **精品/礼盒区**：要求大小均匀、外观一致，规格偏中大。
- **餐饮/团购渠道**：更看单果稳定性和出成率，不一定要好看。

然后给苹果、橙子各定一个“主销规格带”和“辅助规格带”，不要所有规格都进。

## 2. 苹果怎么判断
重点看：

- **单果重量/直径**：按门店主销习惯定档，例如小果、中果、大果分档采购；散称主销通常以中等均匀果为主。
- **大小均匀度**：同一批里大小差异不能太大，否则陈列乱、顾客挑剩多。
- **果形与外观**：无明显畸形、日灼、药斑、碰压伤；果梗完整度影响卖相。
- **硬度与成熟度**：过硬可能偏生，过软不耐放；门店销售要兼顾“可即食”和“货架期”。
- **等级一致性**：一级果、二级果不要混装冒充同一价带。

可执行判断：随机抽 20～30 个，称单果重、量横径，看极差和平均值；再看 24 小时常温放置后的失水、软化、碰伤变化。

## 3. 橙子怎么判断
重点看：

- **单果重量/横径**：按主销价格带定中果或大果；过小显廉价，过大不一定好卖。
- **果皮与手感**：皮薄紧实、有弹性、无明显枯水感；避免皮厚、粗皮、浮皮。
- **整齐度与颜色**：同批颜色、大小尽量一致，利于陈列。
- **可食率与汁水**：切开或手压判断是否干瘪、汁少；橙子规格不能只看外观。
- **耐储性**：检查果蒂、有无霉斑、软腐、机械伤，橙类一旦有伤易传染。

可执行判断：抽检称重、量横径，切开 3～5 个看皮厚、汁水、籽和化渣情况；轻压是否有弹性，闻有无异味。

## 4. 用“门店销售四问”做最终判断
每个规格问四个问题：

1. **好不好陈列**：同规格能否整齐堆头、减少挑拣？
2. **好不好定价**：这个规格在门店价格带是否有竞争力，毛利是否覆盖损耗？
3. **好不好卖完**：按日均销量，货架期内能否售罄？
4. **损耗能不能接受**：碰伤、软化、霉变、挑剩的预期损耗是否在毛利内？

如果某个规格“好看但卖不动”或“便宜但损耗高”，就不适合作为主销规格。

## 5. 建议的采购动作
- 先小批量试销 2～3 天，记录：到货规格分布、挑剩比例、损耗率、日均销量、顾客反馈。
- 同一供应商要求**分档清晰**，合同里写明规格区间、允许差异比例、伤残率上限。
- 陈列时按规格分价签，不要把大小果混卖，否则顾客只挑大的，小的全剩。
- 对苹果重点控碰压伤和软化；对橙子重点控霉变、干水和粗皮。

**一句话结论**：适合门店销售的规格，是“大小均匀、成熟度合适、损耗可控、价格带匹配、能在货架期内卖完”的规格，不是单纯越大越好。
