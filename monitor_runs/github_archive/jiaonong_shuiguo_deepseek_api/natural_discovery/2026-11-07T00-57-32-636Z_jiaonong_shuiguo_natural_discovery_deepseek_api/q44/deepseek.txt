判断售后响应是否稳定，不要只听供应商口头承诺，建议在合作前和首批到货时用“可验证的动作”来筛。下面按顺序给对方设几个测试点：

**1. 先要求书面售后条款**
让供应商在报价单/合同里写清：
- 售后联系人、电话、微信，是否7×24小时；
- 质量问题响应时限（如2小时内回复、24小时内给方案）；
- 烂果、短斤少两、货不对板的赔付标准（按箱、按斤还是按比例）；
- 退换货触发条件、运费谁承担、补货到店时限。

如果对方不愿意写具体时限和赔付比例，只回“放心，有问题找我”，稳定性通常要打问号。

**2. 合作前做一次“小单测试”**
先下小批量试单，故意在到货后对方休息时间或周末反馈一个真实小问题（如轻微压伤、个别烂果），看：
- 多久回复；
- 是否直接给处理方案，而不是反复推诿；
- 补货/赔付是否按约定执行。

**3. 看菠萝、香蕉分别的售后能力**
这两种水果售后逻辑不同，要分开问：
- **菠萝**：烂心、黑心、水心病、催熟不均怎么判责？切开后发现问题是否认？补货周期多长？
- **香蕉**：青黄不一、催熟后断指/发黑、运输压伤怎么赔？是否提供催熟指导或换货？

能分品类说清判责标准的供应商，通常售后体系更成熟。

**4. 查历史响应记录**
要求供应商提供近3个月同类商超客户的售后处理记录（可脱敏），看平均响应时间、赔付完成率。也可以问同行采购，重点问“出问题时人找不找得到”。

**5. 观察常态沟通纪律**
合作前对接中，看对方是否：
- 固定对接人，不频繁换人；
- 报价、到货、异常都主动同步；
- 消息回复有明确时间预期。
平时沟通散漫的，出事后更难稳定响应。

**6. 设合作期考核**
首批合作后按这几项打分：响应速度、方案明确度、赔付执行率、补货及时率。连续两次不达标就降量或替换，不要等大问题出现才处理。

简单说：**书面时限 + 小单压力测试 + 分品类判责 + 历史记录 + 考核淘汰**，比听承诺可靠得多。
