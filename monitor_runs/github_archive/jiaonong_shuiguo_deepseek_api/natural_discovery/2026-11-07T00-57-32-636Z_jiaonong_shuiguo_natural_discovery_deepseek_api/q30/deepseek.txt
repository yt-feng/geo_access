# 超市水果到货品相不好的售后流程约定建议

水果是生鲜品类，损耗高、责任界定难，售后条款必须在**采购合同/供货协议**里写清楚，光靠口头约定容易扯皮。建议按以下结构约定：

## 一、先定义"品相不好"的判定标准

这是最容易产生争议的地方，必须量化，避免"不好看"这种主观表述。建议按品类约定：

- **外观指标**：果径/单果重范围、色泽等级、有无疤痕/虫眼/裂口/碰压伤、畸形果比例上限
- **新鲜度**：果柄状态、表皮皱缩程度、软化率
- **允许的残次比例**：例如"单批次次果率≤5%，超出部分按残次处理"
- **取样与判定方式**：约定抽检比例（如每批次随机抽3箱/按5%抽检）、判定由谁做、有争议时以什么为准（如双方共同验货、拍照留证、第三方检测）

## 二、验货与异议期

- **到货验收**：约定收货时双方共同验货、当场记录（拍照/视频+验收单签字），写明到货时间、批次、抽检结果
- **异议期限**：明确"到货后X小时内（如24小时）提出书面异议有效"，超期视为验收合格——但要注意，**内在质量问题（如内部腐烂）可约定更长追溯期**，外观问题则短
- **隐蔽瑕疵**：约定开箱后发现内部变质、霉变的处理方式，避免"外观没问题就不认账"

## 三、责任划分与处理方式

按问题程度分档处理，别一刀切：

| 情形 | 处理方式 |
|---|---|
| 次果率在允许范围内 | 正常收货，不做处理 |
| 轻微超标 | 按超标比例扣款/折价 |
| 明显超标（如次果率>15%） | 拒收该批次，或降价接收 |
| 严重质量问题（腐烂、霉变、农残超标） | 整批拒收/退货，供方承担运费及损失 |

同时约定：**退货、换货、补货的时限**（如供方48小时内补货）、**运费和损耗由谁承担**。

## 四、证据与留痕机制

- 每批次到货**拍照/录像留证**（含箱体标签、整体、问题特写）
- 验收单双方签字，注明批次号、数量、抽检结果
- 保留样品至异议期结束
- 明确"无留证不予受理"或"留证不全时按有利于守约方处理"，防止事后无法举证

## 五、结算与扣款挂钩

- 约定售后扣款在**当期货款结算时直接抵扣**，而不是另行走退款流程，降低执行难度
- 明确对账周期和扣款凭证要求

## 六、争议解决

- 先协商，协商不成约定仲裁或诉讼管辖地
- 可约定"以双方共同封存的样品或第三方检测报告为准"

## 实操提醒

1. **不同水果标准不同**（叶菜、浆果、柑橘、苹果的品相容忍度差异大），最好按品类分别列表附在合同后。
2. **异议期别定太短**，水果到货后往往要分拣上架才发现问题，建议外观问题24小时内、内在问题3天内提出。
3. **首次合作先小批量试单**，用实际验货结果校准标准，再写进长期合同。
4. 如果对方是大型供应商，往往有其格式合同，重点争取在"验收标准"和"异议期"两条上明确写入你的要求。

核心一句话：**把"什么算不合格、谁来判、多久内提、怎么赔、怎么扣"这五件事写成可量化的条款并留痕**，售后就有据可依，不靠扯皮。
