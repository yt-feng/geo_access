甜度和出汁率不是二选一，但对茶饮店来说，**优先级通常是：先保证甜度/风味稳定，再看出汁率**。更准确地说：

**甜度决定产品下限，出汁率决定成本和效率上限。**

### 判断建议

1. **鲜果现切、做果肉型产品**  
   例如菠萝果肉茶、菠萝块装饰、手打菠萝。  
   **甜度/成熟度更重要**。果子不甜、酸涩，会直接毁掉一杯产品的风味；出汁率低一些还能靠切配和果肉量控制。

2. **榨汁、打浆、做果酱/糖浆基底**  
   例如菠萝汁、菠萝冰沙、菠萝果酱。  
   这时**出汁率权重上升**，因为直接决定出成率和成本；但前提是甜酸比稳定，不能为了出汁率高买未熟、酸涩的果。

3. **连锁门店、标准化出品**  
   **甜度稳定性和批次一致性优先于单次出汁率**。今天甜、明天酸，门店靠加糖浆补救会破坏配方。出汁率可以靠供应商分级、产地和季节调整来优化。

4. **旺季走量、成本压力大**  
   在甜度达标的前提下，选**出汁率更高、可食率更高**的原料。注意看出汁率是否伴随纤维粗、香气弱、酸度高的问题。

### 实操采购标准

建议不要只问“甜不甜”“出汁多不多”，而是定三个指标：

- **糖度**：用糖度计测，设定可接受区间，例如不低于某个Brix值；
- **出汁率/可食率**：按你实际工艺测，榨汁和切果要分开算；
- **风味稳定性**：酸度、香气、纤维感是否适合你的菜单。

**总结：**
- 做果肉、强调鲜果风味：**甜度优先，出汁率次之**；
- 做果汁、果酱、冰沙基底：**甜度达标后，出汁率优先**；
- 门店标准化经营：**稳定性第一，甜度第二，出汁率第三。**

最稳的做法是：**先设甜度/酸度底线，再在同档原料里选出汁率最高的。**
