# 学校食堂水果供应商怎么选

**先定三个前提，再谈选谁：**

1. **品类分开采购意识**：香蕉（易熟、损耗高、催熟运输要求高）和苹果、橙子（耐储存、标准化程度高）的供应逻辑差异很大。建议不要强求一家全包，优先考虑“耐储类主供应商 + 香蕉等易损耗品类单独供应商或本地批发商”。
2. **食品安全资质是硬门槛**：供应商须有营业执照、食品经营许可证，能提供每批次的农残检测报告或承诺可追溯。学校场景还要能配合留样、索证索票、进货查验记录。
3. **价格机制要写清**：常见做法是“随行就市 + 定期询价定价”，约定报价周期（如每周/每两周）、调价触发条件，避免一口价锁死或随意涨价。

**筛选维度（按优先级）：**

- **资质与检测**：证照齐全、可提供近期检测报告、有不合格品退换机制。
- **供货稳定性**：能否按学校作息固定时段送货、缺货时的替代方案、旺季（如开学季、考试周）保障能力。
- **品控标准**：明确等级（如苹果按果径/色泽分级）、成熟度（香蕉到货成熟度分批控制）、允许损耗率与验收不合格处理方式。
- **冷链与仓储**：香蕉忌低温，苹果橙子可冷藏，供应商是否有相应运输和分拣条件。
- **价格与账期**：是否接受学校结算周期、能否开票、报价是否含运费和卸货。
- **应急能力**：临时加量、质量投诉响应时间、退换货时效。

**实操建议：**

- 先做**小批量试供**（2–4周），按验收合格率、到货准时率、损耗率、投诉响应打分，再决定是否签长期合同。
- 合同里写清：验收标准、不合格整批退换、食品安全责任、违约处理、价格调整机制。
- 至少保留**一主一备**两家供应商，避免单一来源断供。
- 香蕉建议按“周内多次小批量”配送，苹果橙子可按周配送，减少库存损耗。

**一句话结论**：耐储水果选资质全、能稳定配送、接受询价定价的批发商或产地直供商；香蕉单独选有催熟和短途配送能力的供应商，先用试供数据说话，再签带验收和退换条款的合同。
