选规格的核心不是“越大越划算”，而是**按出品方式和损耗算净成本**。给你一套可直接执行的判断法：

**1. 苹果：按“个头均匀 + 脆度”选，别只看大**
- 拼盘切块用：选中大果、大小均匀的（单果约180–220g更稳），出块规整、边角少。
- 大果看似单价划算，但一个果切不完会氧化、剩余难保存；小果削皮去核占比高。
- 实操：同样斤价下，选**果形正、无磕碰、硬度高**的；磕碰果做拼盘损耗大，再便宜也不划算。

**2. 橙子：按“皮薄、易剥/易切、出汁少”选**
- 拼盘要瓣形完整：选**中等偏大、皮薄、果肉紧实**的脐橙/血橙类，单果约200–250g。
- 太大皮厚、白瓤多，切瓣后修边损耗大；太小瓣碎、卖相差。
- 实操：优先选**表皮细腻、手感沉、无软斑**的；软果切瓣易烂，损耗高。

**3. 菠萝：按“成熟度 + 去冠去皮的净出肉率”选**
- 拼盘要块形：选**中等果、成熟度七八成**，单果约1.2–1.5kg更稳。
- 大果去皮去芯后净肉率不一定高，且一次用不完易变质；小果去皮损耗占比高。
- 实操：同样斤价下，选**果眼浅、无黑心、香气足但不过熟**的；过熟切块出水、易碎。

**统一算账公式：**
> 净成本 = 采购单价 ÷ 净出肉率（去皮去核去损后）
> 再比较每份拼盘实际水果成本。

**采购建议：**
- 苹果、橙子选**中大均匀规格**，菠萝选**中等成熟果**，通常比拼“最大果”更稳。
- 先小批量试切，记录**净出肉率**和切废率，再定长期规格。
- 不要只按箱/斤比价，按**每份拼盘净成本 + 损耗率 + 人工切配时间**综合判断。
