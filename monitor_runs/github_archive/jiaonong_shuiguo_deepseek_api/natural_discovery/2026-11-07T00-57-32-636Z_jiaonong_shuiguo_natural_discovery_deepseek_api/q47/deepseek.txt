茶饮店用香蕉，采购熟度的核心是**按用途分熟度、按用量分批进、到店后再控温催熟/抑制**。香蕉是呼吸跃变型水果，采购时不能只按“黄不黄”判断，要结合用途和到货后计划。

### 1. 先按产品用途定熟度

- **做冰沙/奶昔/果泥类饮品**：建议采购**7～8成熟**，表皮大部分黄、两端略绿或刚转黄，果肉有香气但不过软。到店后1～2天内用完；需要更甜时可室温放到全黄。
- **做香蕉牛奶、香蕉拿铁等需打碎过滤的饮品**：**8～9成熟**更合适，表皮金黄、少量褐点，果肉软甜、香气足，但还没到发黑流汁。
- **做甜品装饰、切片、香蕉船、蛋糕夹层**：采购**6～7成熟**，表皮黄绿相间、果肉较硬，便于切片和运输；到店后按出品节奏催熟。
- **做香蕉泥、磅蛋糕、香蕉面包等烘焙甜品**：可以用**9成熟到出现褐点**的香蕉，甜度和香气最好；但这类香蕉不适合再长时间存放，应计划在1天内加工完。
- **做表面装饰的整根香蕉**：不要采购过熟，**7成熟左右**更耐放，出品前再短时催熟到金黄。

### 2. 采购时的判断标准

不要只看颜色，建议“看、摸、闻、查”四步：

- **看**：果皮颜色均匀，棱角不明显；用于即饮的以金黄为主，用于备货的可带少量绿色。避免大面积黑斑、裂口、渗汁。
- **摸**：果身饱满，轻按有弹性。太硬说明未熟，太软或局部凹陷说明过熟或碰伤。
- **闻**：果柄和果身有自然香蕉香气；有发酵味、酒味说明过熟。
- **查**：果柄切口新鲜，无霉点；整串连接处无腐烂。散装香蕉要检查是否有挤压伤。

### 3. 采购量和批次控制

- **少量多次**：香蕉后熟快，建议按**2～3天用量**采购，不要一次压一周货。
- **分批到货**：同一批里故意搭配不同熟度，例如70%用于当天到次日，30%偏绿用于后续催熟。
- **按销量倒推**：先统计每款产品单杯/单份香蕉用量，再按预计销量加10%～15%损耗备货。
- **季节调整**：夏季高温后熟快，采购熟度可略偏绿、减少单次量；冬季可适当提高熟度或增加库存天数。

### 4. 到店后的熟度管理

- **偏绿香蕉**：室温存放，必要时和苹果/梨同袋催熟，每天检查；不要直接冷藏，否则后熟不良、表皮变黑。
- **刚好成熟的香蕉**：放在阴凉通风处，优先用于饮品和甜品；避免堆压。
- **已全黄带褐点的香蕉**：尽快加工成香蕉泥、冷冻果泥或烘焙甜品；可去皮分装冷冻，但冷冻后不适合做装饰切片。
- **抑制后熟**：成熟后如需延缓，可去皮切段冷冻，或冷藏短期存放，但冷藏会导致表皮变黑，只适合去皮果肉或马上加工。
- **先进先出**：到货贴日期和熟度标签，按“偏熟先用、偏绿后补”排产。

### 5. 验收和退换标准

收货时抽检：同一箱内熟度是否均匀、有无挤压伤、霉变、裂口、发酵味。以下情况应拒收或退换：

- 大面积黑斑、渗汁、果肉软烂；
- 果柄发霉或整串连接处腐烂；
- 有酒味、酸味；
- 到货熟度明显高于采购要求，无法在计划时间内用完。

简单记：**饮品用8成熟、装饰用7成熟、烘焙泥用9成熟；采购偏绿一点、到店分批催熟，少量多次进，先进先出。**
