判断“哪个规格更容易出货”，别只看感觉，建议用下面4步做可判断、可执行的筛选。

**1. 先按用途分规格，不只看大小**
菠萝批发常见规格可按：
- 单果重量：如1斤以下、1–1.5斤、1.5–2斤、2–2.5斤、2.5斤以上
- 果型：圆整度、果眼深浅、有无畸形
- 成熟度：青果、微黄、黄熟
- 品种/产地：如金钻、香水、本地/外地

不同客户要的规格不同：
- **水果店/社区团购**：偏1.5–2.5斤、卖相好、成熟度适中
- **餐饮/果汁店**：偏大果、出肉率高，对卖相要求低
- **路边摊/夜市**：偏中等果、价格带低、耐放
- **电商/礼盒**：偏果型均匀、外观好

**2. 用最近7–14天真实出货数据排序**
每个规格记录：
- 出货箱数/件数
- 出货速度：几天清完
- 退货/损耗率
- 客户复购次数
- 毛利额，不只看单价

判断标准：
- **出货最快**：库存周转天数最短
- **最稳**：连续多天有单、退货少
- **最赚钱**：单件毛利×出货量最高
不是“卖得最多”就一定最好，可能是低价清货。

**3. 做小批量测试**
拿3–5个主推规格，各留固定量，比如每规格20–30件，同一天放给同类客户，记录：
- 当天询价次数
- 成交件数
- 客户指定复购规格
- 剩货情况

如果某规格**询价多、成交快、剩货少、退货少**，就是更容易出货的规格。

**4. 看客户问句和退货车**
最快判断信号：
- 客户反复问“有没有1.8–2斤的？”
- 哪种规格最先被挑完
- 哪种规格剩到最后、被压价
- 退货原因是大果熟过头、小果卖相差，还是中果不耐放

**实操建议：**
先设一个主推规格，比如**1.5–2.5斤、果型圆整、微黄**，作为水果店和社区团购的通用出货款；再保留**大果**供餐饮/果汁客户，**小果**做低价引流。每周按“周转天数+退货率+毛利额”三项重新排一次，连续两周排第一的规格加大备货，排最后且退货高的规格减少或改渠道。

一句话：**更容易出货的规格=目标客户明确、周转天数短、退货率低、毛利额不差的规格；用7–14天数据和一次小批量测试验证，不要只凭大小判断。**
