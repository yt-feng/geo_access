# 社区团购旺季提前锁定水果库存的操作清单

核心逻辑：**用"框架协议+分批锁量+分级定金"替代一次性口头订货**，既锁住产能，又不把现金流和损耗风险全压在自己身上。

## 一、先算清"锁多少"，再谈

- **按历史数据定基线**：取去年同期+近8周周均销量，旺季峰值按基线的1.5–2倍预估，别按最高想象值锁。
- **分ABC三类**：
  - A类爆款（如应季西瓜、砂糖橘）：锁70–80%预估量，优先级最高。
  - B类常规品：锁50–60%。
  - C类引流/试销品：不锁量，按周补。
- **留调剂空间**：锁定量里约定10–15%可免费取消或延期（提前X天告知）。

## 二、协议要写死的条款

| 条款 | 建议写法 |
|---|---|
| 价格 | 锁量不锁价或"锁价+浮动带"，约定随产地价波动±5%内不调价，超出双方按比例分担 |
| 分级 | 按果径/糖度/瑕疵率写验收标准，附样品封存 |
| 交付节奏 | 按周或按批次（如每周二、五各一批），明确最迟到货时间 |
| 违约 | 供应商缺量按缺口金额比例赔付；自己取消按定金比例扣 |
| 损耗兜底 | 约定到货损耗率上限（如生鲜3–5%），超出自担或折价 |

## 三、用定金而不是全款锁货

- **分级预付**：签框架协议付小额诚意金（如预付款10–20%），每批次发货前再付该批40–50%，尾款验收后结。这样锁得住货、压得住账。
- **对头部供应商可谈"产能预留费"**：旺季前付一笔固定费用，换对方把某果园/某品类的产能优先给你，货到再付货款。
- **避免全款压库**：水果损耗高，全款锁量在行情下跌时会很被动。

## 四、多源与产地直连

- **每个A类爆款至少2家供应商**，主供锁60%、备供锁20%，防止单点断供。
- **能直连产地/合作社就直连**，比经过二级批发商更容易锁到真实产能，还能拿到采摘计划。
- **关注产地天气和上市期**：提前和供应商对齐采摘窗口，把"预计上市日"写进协议，错峰排交付。

## 五、沟通与执行节奏

1. 旺季前6–8周启动谈判，先谈A类爆款。
2. 用书面订货单/合同锁定，微信口头约定不算数。
3. 每周滚动更新需求预测给供应商，让对方排产有依据。
4. 每批到货做质检记录，作为后续调量和索赔依据。

**最容易踩的坑**：只口头锁量不签违约条款、按峰值一次性锁死、只依赖一家供应商。把这三条避开，旺季爆单的库存风险就基本可控。
