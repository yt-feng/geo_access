最需要优先关注**食品安全**，其次是**配送准时**，最后才是**价格**。原因很直接：企业食堂是集中供餐，水果一旦出现农残超标、霉变、致病菌污染，影响的是成批员工，后果和处置成本远高于价格差异或偶尔晚到。

可以按这个优先级判断：

1. **食品安全是底线，必须先设门槛**
   - 供应商资质、检测报告、进货查验、批次追溯要能提供。
   - 腐烂霉变、切开久放、冷链断链的水果不能进食堂。
   - 出现问题时要有召回和替换机制。
   - 这一项不达标，价格再低也不应采购。

2. **配送准时是食堂运营保障**
   - 水果通常按餐次或每日计划使用，晚到会影响供餐或造成临时替代。
   - 但准时可以靠合同约定、备选供应商、合理库存来管理，属于可运营解决的问题。

3. **价格重要，但应放在达标之后比较**
   - 在食品安全和配送能力都合格的供应商之间，再比价格、损耗率和结算方式。
   - 只盯单价容易忽略损耗、退换货成本和食品安全风险。

实际采购中建议设置成：**食品安全一票否决，配送准时纳入考核，价格在同资质供应商中竞争**。如果食堂规模大、水果生食比例高，食品安全权重还应进一步加大。
