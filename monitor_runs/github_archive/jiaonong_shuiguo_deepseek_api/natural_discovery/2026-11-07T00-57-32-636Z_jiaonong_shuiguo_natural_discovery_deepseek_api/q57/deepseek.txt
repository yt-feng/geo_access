结论：绝大多数餐饮连锁优先建议**中央厨房/总仓统一收货**，门店只做例外收货。是否例外，用下面4条判断即可。

**一、统一收货更适合的情况（多数连锁）**
1. **水果用于标准化出品**：切果盘、沙拉、饮品配料、甜品装饰等，规格、成熟度、甜度标准能统一，中央厨房可复检、分拣、催熟/预冷后再配送。
2. **供应商集中管理**：总部统采、统签合同、统一对账，价格和账期更可控；发票和食品安全追溯也集中。
3. **食品安全风险高**：农残检测、批次追溯、冷链温度记录集中在中央厨房做，比几十上百家门店各自验收更可靠。
4. **门店面积小、人手紧**：门店只收预包装/定量周转箱，减少称重、挑拣、退货扯皮。
5. **损耗可集中处理**：中央厨房可把外观瑕疵但可加工的水果转做果酱、果汁、烘焙馅料，降低整体损耗。

**二、门店分开收货更适合的情况**
1. **鲜食水果直接售卖或门店现切现摆**，对“到店新鲜度、货架期”要求极高，多一道中转反而缩短货架期。
2. **门店密度低、配送距离远**，中央厨房二次配送成本高、时效难保证。
3. **水果品类多、单店量小且波动大**，统配容易压库存，门店自采更灵活。
4. **当地有强势批发市场/产地直供**，门店就地采购品质和价格明显更优。
5. **中央厨房不具备水果分拣、预冷、催熟能力**，统一收货只是多一道搬运动作。

**三、建议的落地模式：统收为主 + 例外清单**
- **A类统收**：所有标准化、可预包装、用于中央厨房加工或统一配送的水果，100%中央厨房收货。
- **B类门店直收**：叶菜类易损水果、门店现切高周转水果、地方特色小批量水果，列白名单，由总部定供应商和价格，门店按标准验收并上传照片/温度/批次。
- **C类紧急补货**：门店可向指定本地供应商紧急采购，但限金额、限品类、事后补单，月度复盘。

**四、决策时重点算三笔账**
1. **总成本**：采购价差 + 中央厨房分拣人工 + 二次配送冷链成本 + 门店验收人工 + 损耗率。不要只看采购单价。
2. **损耗与货架期**：水果多一道中转通常增加1天左右货架期损失，易损品类要单独测算。
3. **食安与追责**：统一收货的批次追溯、农残检测、温控记录更完整；门店分散收货必须配套“总部定标准、门店执行、系统留痕”的验收制度，否则容易失控。

**可执行建议**：先选3-5个高频水果品类做1个月统收试点，对比损耗率、到店新鲜度、门店投诉率和综合成本；同时建立门店直收白名单和验收拍照制度。试点数据支持后，再决定扩大统收还是保留门店直收。
