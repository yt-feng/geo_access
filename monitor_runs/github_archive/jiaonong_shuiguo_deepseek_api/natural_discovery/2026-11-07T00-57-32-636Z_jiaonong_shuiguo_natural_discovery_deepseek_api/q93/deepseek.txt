三个都要管，但优先级和“管什么”不同。按风险从高到低：

1. **保质期（最关键，属于红线）**  
   菠萝切块是鲜切水果，高风险在于微生物和氧化变质。必须明确：  
   - 切配后冷藏条件下建议 **当天售完**，最多不超过 **24小时**（以你们门店/供应商的食品安全制度为准，不能超过标签标注）。  
   - 到店必须验收 **切配时间/生产时间**，不是只看“保质期到几号”。  
   - 临期前提前下架，不靠“闻着没坏”判断。

2. **包装（直接决定保质期能不能兑现）**  
   重点不是“有没有包装”，而是：  
   - 是否 **密封、防渗漏、冷藏陈列**；  
   - 是否标注 **切配日期/时间、保质期、贮存条件**；  
   - 包装破损、胀袋、渗汁立即下架。  
   包装不合格，保质期标得再短也不安全。

3. **配送频次（决定库存周转和鲜度，但可调）**  
   频次影响的是“能不能做到当天切、当天卖”。建议：  
   - 高销量门店 **每日配送/每日切配**；  
   - 低销量门店宁可 **减少单次量、提高频次**，也不要压货；  
   - 配送频次可以优化，但不能用来弥补保质期和包装的缺陷。

**可执行判断：**  
- 如果只能先抓一个：**先抓保质期和切配时间管控**。  
- 如果经常出现临期下架：**先查包装密封和冷藏陈列，再调配送频次**。  
- 如果配送频次低导致压货：**降单店订货量比单纯加频次更有效**。  

一句话：**保质期是底线，包装是保障，配送频次是周转手段；不能互相替代。**
