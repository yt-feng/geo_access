判断香蕉供应商能不能“按时到车”，核心不是听他口头保证，而是把他的**履约能力、货源状态、运输安排、违约成本**拆开验证。可以按下面几步做，重点看可核验证据。

### 1. 先确认“按时到车”的定义
在订单里写清楚：
- 到车时间：具体到日期和几点前
- 到车地点：市场档口/仓库/指定卸货点
- 车型和载重：几米车、装多少件/吨
- 装车时间：产地几点装车
- 延误处理：超几小时算违约、怎么扣款/补差价
- 香蕉状态：成熟度、梳蕉/把蕉、青蕉还是黄蕉、是否催熟

没有这些，后面容易扯皮。

### 2. 验证供应商的真实货源
不要只问“有没有货”，要问：
- 货在哪个产地/仓库，能否视频看货
- 是自有基地、长期合作代办，还是临时调货
- 当天能装多少车，已订出去几车
- 能否提供装车视频、装车单、过磅单

**判断信号：**
- 能马上发定位、仓库视频、现有包装和蕉条状态，可信度较高
- 只说“放心”“肯定有”，但给不出具体位置和装车计划，要警惕
- 同时接很多单但说不清货源，容易临时拼车或跳票

### 3. 看他的运输资源
重点问：
- 车是自有车、长期合作车队，还是临时找车
- 车牌号、司机电话、车型什么时候能定
- 装车后走哪条线路，大概多久到
- 有没有备用车方案

**可执行判断：**
- 要求装车前给出**车牌号+司机电话+装车定位**
- 到装车时间还没有车号，延误风险高
- 临时找车的供应商，遇到运价上涨容易放鸽子

### 4. 用时间节点倒推
让供应商给出完整时间表：
- 今天几点确认货源
- 明天几点开始装车
- 几点装完发车
- 预计几点到市场

然后你按关键节点跟进：
- 装车开始是否准时
- 装车中途是否发视频
- 发车后是否给车牌和司机联系方式
- 路上是否正常推进

**只要装车节点反复推迟，就不要相信“到车没问题”。**

### 5. 查历史履约
问同行、市场档口、代办：
- 这个供应商以前是否准时
- 有没有临时加价、换货、少斤两、以次充好
- 延误后是否认账

首次合作不要只靠一家，尽量保留备用供应商。

### 6. 用合同和付款控制风险
建议：
- 少量定金，装车视频/过磅单确认后再付大部分
- 写明延误扣款、退定金、补车费责任
- 不接受“先全款再排车”
- 首次合作先小批量试单
- 保留聊天记录、装车单、过磅单、转账记录

### 7. 香蕉品类的额外注意
香蕉成熟度变化快，延误不仅是到车晚，还会导致：
- 青蕉转黄过快
- 催熟节奏被打乱
- 卸货后货架期缩短

所以订单里要约定成熟度，并要求供应商按到车时间反推采摘/催熟节奏。若供应商对成熟度控制说不清，即使车准时，货也可能出问题。

### 简单判断标准
可以合作：能给出具体产地/仓库、装车计划、车牌司机信息、历史履约记录，且接受节点付款和延误责任。

谨慎合作：只说有货、车“马上安排”，但给不出定位、车号、装车视频，要求大额预付。

基本不要合作：装车时间反复改、临时加价、拒绝写延误责任、货源和车辆都模糊。

最稳的做法：**先小单试履约，再逐步放量；每车都按“货源确认—装车视频—过磅单—车牌司机—在途跟踪—到车验收”走流程。**
