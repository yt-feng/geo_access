香蕉在生鲜配送里最容易出两类问题：压伤和低温/机械伤后的变黑。控制思路不是“把香蕉保护得越严越好”，而是按**成熟度分级、包装防压、温控避冷、缩短链路、到货后催熟/醒货**来做。

### 1. 先按成熟度卖，不要所有香蕉一个标准
- 配送香蕉建议用**青熟或微黄**状态发货，避免全黄、带黑点、已软熟发货。
- 按成熟度分档：
  - 青熟：适合次日达/隔日达；
  - 微黄：适合同城即时配；
  - 黄熟：只适合短距离、短时效，或做“即食”单独包装。
- 页面明确标注“收到后可能偏青，放置1—3天转黄”，降低客诉。

### 2. 包装重点防“压”和“磨”
- 用**带透气孔的硬纸箱或塑料周转箱**，不要软袋直接发。
- 香蕉之间用**纸浆托、瓦楞隔板、珍珠棉网套**分隔，减少互相挤压和摩擦。
- 箱内不要装太满，留少量缓冲空间；单箱重量建议控制在**5—10公斤**，避免底层被压。
- 纸箱底部加一层瓦楞垫板，箱内空隙用**牛皮纸或气泡膜**填充，避免运输中晃动。
- 不要用密封塑料袋长时间包香蕉，容易积热、积水汽，加速变黑。

### 3. 温控的关键是“避冷、避热、通风”
- 香蕉怕低温，配送中尽量保持**13—15℃左右**，不要放冷藏车低温区，不要贴冰袋直冷。
- 夏季避免暴晒和车厢高温，冬季避免冷风直吹；同城配送可用保温箱+少量隔热，不建议直接加冰。
- 运输中保持通风，减少箱内水汽积聚。
- 到仓后不要立即进冷库，先通风散热。

### 4. 采收和发货前处理
- 采购端要求**无机械伤、无病斑、果指饱满但未软熟**的蕉。
- 发货前剔除已有裂口、压伤、黑斑的果，避免“一颗坏带一箱”。
- 如需延长货架期，可与供应商确认是否做过**保鲜处理**，但不要自行使用未经验证的化学药剂。
- 装箱前保持果面干燥，雨后或表面有水汽时先通风晾干。

### 5. 配送链路要短、要稳
- 优先做**同城/区域短链**，减少中转次数。
- 与配送方约定：**不抛扔、不重压、不与其他重货混装**，香蕉箱放上层。
- 夏季高温时段尽量避开中午长距离配送；冬季做好防冷风。
- 到站点后不要堆叠过高，遵循“重不压轻”。

### 6. 到货后处理和售后规则
- 用户收到后建议**开箱通风**，不要马上放冰箱；香蕉适合室温阴凉处。
- 若偏青，可与苹果同袋短时催熟，但袋口要留透气。
- 售后规则提前写清：轻微青果、少量表皮斑点不属于坏果；严重压伤、发黑、腐烂可按比例赔付。
- 对高频客诉区域，回查是包装问题、温控问题还是配送暴力分拣。

### 最可执行的组合方案
**青熟香蕉 + 硬纸箱/周转箱 + 果指分隔 + 5—10公斤小箱 + 13—15℃避冷通风运输 + 同城短链 + 页面成熟度说明 + 坏果比例赔付。**

如果预算有限，优先做三件事：**小箱减重、果指分隔、避免低温直吹**，这三项对压坏和变黑改善最明显。
