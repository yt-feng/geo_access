提前向供应商索要“可核验、能对上批次”的资料，不要只收一张泛泛的承诺函。建议按下面清单要，并在采购合同/验收标准里写清楚：

1. **供应商资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按实际业态）
   - 若是产地直采，尽量要种植基地/合作社主体信息和联系方式

2. **批次对应的检测报告**
   - 要**与到货批次号/采收日期/产地一致**的农残检测报告
   - 报告应有CMA资质标识（或CATL等相应资质），检测项目覆盖常见高风险农药，不要只看“合格”两个字
   - 核对：样品名称、受检单位、采样/送样日期、检测方法、检出限、判定依据、检测机构盖章
   - 报告日期不能过久；不同批次不能反复用同一份报告

3. **承诺书/质量保证协议**
   - 明确农残符合GB 2763《食品安全国家标准 食品中农药最大残留限量》
   - 写明批次不合格的处理：退货、销毁、赔偿、复检费用承担
   - 写明供应商配合飞检、追溯和提供真实资料的义务

4. **产地与用药管理资料**
   - 产地证明/供货证明
   - 种植环节农药使用记录（尤其是基地直采）
   - 采收前安全间隔期执行说明
   - 如有绿色食品、有机认证等，要证书及对应批次有效性证明

5. **追溯与运输资料**
   - 批次追溯码/随货同行单
   - 送货单上的产地、批次、采收日期、数量
   - 运输温湿度记录（易腐水果）
   - 包装标签信息

6. **抽检与不合格处理记录**
   - 供应商近期自检/第三方抽检记录
   - 过往不合格整改记录
   - 快检记录（若有）

实操建议：
- **每批到货“三查”**：查报告批次是否对应、查报告资质和日期、查感官和包装标签。
- 对高风险水果（如草莓、葡萄、柑橘、苹果等）提高第三方报告频次，或超市自己做快检/送检。
- 合同里约定**供应商随货提供批次检测报告**，否则拒收或暂收待检。
- 不要接受“报告在总部”“下次补”的口头承诺，至少要有盖章扫描件并约定补原件时限。
- 保留供应商提供的所有资料和验收记录，万一监管抽检不合格，便于追溯和免责举证。

一句话：**要“证照+批次检测报告+质量保证协议+产地用药记录+追溯单据”，核心是报告必须对得上这批货。**
