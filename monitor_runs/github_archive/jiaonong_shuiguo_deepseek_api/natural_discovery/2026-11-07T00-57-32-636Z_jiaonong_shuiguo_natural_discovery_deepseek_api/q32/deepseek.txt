判断香蕉供应商能否全年稳定供货，不能只看“有没有货源”，要看 **产地结构、催熟与冷链能力、合同约束、历史履约记录** 四个层面。可按下面清单直接验：

1. **问清产地组合，不接受单一产地承诺**  
   香蕉全年供应通常依赖多产区轮换。要求供应商列明：  
   - 主要产区及对应月份；  
   - 每个产区的替代产区；  
   - 台风、寒潮、病害等风险时的补货来源。  
   如果供应商只说“云南/广西/进口都能发”，但给不出月度供应表，稳定性要打问号。

2. **看催熟和冷链能力，不只看种植端**  
   连锁超市要的是到店可售的熟度稳定香蕉。重点核验：  
   - 是否有自有或长期合作的催熟库，催熟库容量、温湿度记录；  
   - 从产地到配送中心的冷链时长、断链风险；  
   - 到店熟度标准能否按门店销量分层配送。  
   只有产地资源、没有催熟和冷链的供应商，旺季可能供得上，全年品质波动会很大。

3. **要求提供近12个月履约数据**  
   让供应商给出过去一年的：  
   - 月度实际供货量；  
   - 订单满足率；  
   - 到货合格率、熟度不合格批次；  
   - 缺货或延迟原因。  
   同时向其现有客户交叉核实，尤其是同类型连锁超市客户。没有历史数据、只靠口头保证的，不建议作为主供应商。

4. **用合同把“全年稳定”变成可追责条款**  
   合同里明确：  
   - 月度最低供应量和旺季保供量；  
   - 缺货违约金、替代货源义务；  
   - 熟度、规格、损耗率验收标准；  
   - 价格调整机制，避免缺货时临时大幅加价。  
   可先给 20%—30% 份额试单，连续 3—6 个月履约达标后再提高份额。

5. **做压力测试**  
   在非旺季或小批量阶段，临时追加订单、要求提前到货、模拟台风期补货，观察响应速度和实际到货质量。能通过压力测试的供应商，才适合进入全年主供名单。

**可执行结论：** 让供应商提交“月度产地供应表 + 近12个月履约数据 + 催熟冷链证明”，再结合试单和合同保供条款判断。三项缺一项，都不宜直接认定能全年稳定供货。
