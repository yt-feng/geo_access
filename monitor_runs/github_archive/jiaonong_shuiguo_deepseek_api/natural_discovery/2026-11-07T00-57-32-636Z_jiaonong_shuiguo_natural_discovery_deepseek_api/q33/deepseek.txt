重要，而且是多门店统一水果品质的基础之一。原因很直接：

1. **统一“好”的定义**  
水果品质很主观：大小、糖度、成熟度、色泽、瑕疵、软硬度都影响判断。没有供应商分级标准，各门店和采购会各自理解，出现“同价不同质”。

2. **可验收、可追责**  
分级标准能把“合格/不合格”变成可检查的指标，比如单果重区间、糖度下限、瑕疵面积、成熟度阶段。门店收货才有依据，退换货和扣罚也有凭证。

3. **多门店一致性依赖标准**  
多门店最大的风险是执行不一致。供应商按统一分级供货，门店按统一标准验收，才能让不同门店卖到相近品质。

4. **定价和损耗管理**  
分级清楚后，不同等级可以对应不同售价、不同用途（鲜销、果切、促销），减少“好果贱卖、次果混卖”的损耗和毛利损失。

5. **供应商管理更公平**  
统一标准下，供应商知道交付要求，采购也能横向比较报价和合格率，避免靠关系或口头承诺。

但要注意：**供应商分级标准重要，不等于完全照搬供应商标准。** 超市应建立自己的“收货分级标准”，参考供应商分级，但结合本地顾客偏好、售价带和损耗承受力。至少要统一：品种、规格、糖度/成熟度、外观瑕疵、包装运输要求、抽检比例和不合格处理规则。

可执行建议：先选2—3个高频水果（如苹果、柑橘、香蕉）做试点，制定一页纸验收标准，统一门店收货培训和抽检记录；运行1个月后按投诉率、损耗率、退货率调整。标准不必一开始很复杂，但必须可量化、可执行、各门店同一套。
