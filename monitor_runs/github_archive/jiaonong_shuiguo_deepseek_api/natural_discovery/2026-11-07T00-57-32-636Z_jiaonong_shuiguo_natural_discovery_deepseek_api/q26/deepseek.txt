社区超市卖小包装香蕉，采购时重点抓两件事：**包装要适配“小份、快周转、少压伤”**，**损耗要按香蕉后熟特性做分级和控温**。下面是可以直接落到采购单和收货标准里的建议。

### 一、包装注意点
1. **小包装规格别贪大**  
   社区超市建议做 **2–3 根装、约 400–600g/份**，家庭一次吃完为主。包装过大卖得慢，香蕉后熟快，容易在货架上过熟。

2. **优先选透气包装，不要全密封**  
   香蕉会释放乙烯，密封袋/密封盒会加速后熟和结露。建议：
   - 打孔保鲜袋、网袋、透气托盘+收缩膜打孔；
   - 避免完全密封的透明盒长期陈列；
   - 若用托盘覆膜，膜上至少留透气孔。

3. **包装要防压伤，不是越紧越好**  
   香蕉怕挤压、摩擦、磕碰。小包装内不要硬塞，果指之间留轻微缓冲；可用纸托、瓦楞隔板或轻质网套。不要用硬质大盒混装多根，容易底层压伤。

4. **标签别直接贴在果皮上**  
   价签、条码贴包装上，避免撕标伤果皮。果皮破损会加速褐变和腐烂。

5. **包装材料要防结露**  
   冷柜或空调出风口附近陈列时，薄膜内侧易结露，水滴会引发黑斑和霉变。采购时确认包装有透气孔，陈列避免正对出风口。

6. **考虑“可拆零”包装**  
   采购时优先选可按把/按根分装的到货形式，比如整把到货后门店自行小包装，比工厂预包装更灵活，能按成熟度分流。

### 二、损耗控制注意点
1. **采购成熟度要分档**  
   不要一次全采“黄熟”香蕉。建议：
   - 约 **70%–80% 青黄**用于日常补货；
   - 少量 **黄熟**用于即时销售；
   - 避免采购已出现梅花点、果柄发黑、果身软塌的货。

2. **按成熟度分区陈列**  
   青一点的放常温背阴处，黄熟的放显眼快销位；不要全部堆在同一个暖风口或灯光直射下。香蕉对温度敏感，**13–15℃左右**较适宜，普通社区超市常温阴凉通风即可，不建议长时间放冷柜，低温易冻伤发黑。

3. **收货标准写清楚**  
   采购合同或收货单明确：
   - 果指饱满、无严重机械伤、无裂果、无霉点；
   - 果柄切口干净，无腐烂；
   - 到货成熟度一致，不能一把里青黄差异过大；
   - 箱内无挤压变形、无结露水湿。

4. **少量多次补货**  
   小包装香蕉周转快但后熟也快，建议按日销量拆箱补货，先进先出，不要一次把整箱全拆上架。箱内剩余用透气袋分装，阴凉处存放。

5. **每天挑拣，及时处理**  
   出现轻微斑点但果肉未坏的，可做“熟蕉特价”快速出清；已软烂、渗液、霉变的立即剔除，避免乙烯和病菌传染。挑拣时轻拿轻放，减少二次损伤。

6. **控制堆叠高度**  
   小包装陈列不要堆太高，尤其黄熟蕉，堆压会加快软烂。用浅筐、斜口陈列，减少底层受压。

7. **算清损耗率再定采购量**  
   香蕉小包装常见损耗来自压伤、过熟、脱柄和顾客翻拣。采购前按门店日销量预估，首单少量试销，观察 **2–3 天**的动销和损耗，再定稳定采购量。一般小包装香蕉要把“可售率”而不是“到货重量”作为核算口径。

### 三、采购时可直接问供应商的几句话
- 这批货的成熟度是几成黄？到店后大概几天可售？
- 是整把到货还是预包装？预包装是否打孔透气？
- 箱内有没有纸托/隔板防压？每箱净重和果指数量多少？
- 能否按成熟度分档供货，或者分批到货？
- 破损、过熟、霉变的售后怎么算？

**总结：** 小包装香蕉采购的核心是“**小份透气、防压防结露、成熟度分档、少量多次**”。包装上优先打孔透气+轻缓冲，损耗上按成熟度分流陈列、每日挑拣、先进先出，先用小批量试销校准采购量。
