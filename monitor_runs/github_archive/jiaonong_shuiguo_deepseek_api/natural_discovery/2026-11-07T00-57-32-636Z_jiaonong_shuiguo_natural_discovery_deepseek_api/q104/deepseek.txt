单位采购水果出现品质不一致，建议把“验收”和“售后”分成两条线，并且都留下可追溯证据。

**一、到货验收怎么做**

1. **先定标准再收货**
   - 在采购单/合同里写清：品种、规格（单果重/果径）、成熟度、糖度范围、外观（无腐烂、无裂口、无大面积斑点）、允许损耗率。
   - 明确“合格判定”：例如抽检100箱，不合格超过5箱即整批可拒收或按比例扣款。
   - 约定“品质不一致”的处理方式：分级降价、换货、补发、退货。

2. **到货当场抽检**
   - 按批次随机抽样，不要只查上层；大货可分层、分角落抽。
   - 记录：到货时间、车牌/司机、批次号、数量、抽检数量、不合格数量、问题照片/视频。
   - 对腐烂、压伤、规格不符、成熟度差异大等分类记录，不要只写“质量差”。

3. **验收单双签**
   - 验收单写明合格数、不合格数、处理意见（拒收/降价接收/换货），双方签字。
   - 不合格品单独隔离，避免与合格品混放，防止后续责任不清。

4. **及时反馈**
   - 到货后尽快完成验收，越早反馈越有利于售后；不要等入库几天后才提。
   - 通过书面渠道（邮件/工作群/采购系统）发送验收结果和照片，保留时间戳。

**二、售后怎么处理**

1. **按合同走**
   - 优先依据合同中的质量条款、损耗率、退换货时限处理。
   - 若合同未细写，可参考双方长期交易习惯，但最好补签补充协议。

2. **分级处理**
   - 轻微不一致：按比例降价接收，双方确认折价金额。
   - 影响使用：要求换货或补发，明确到货时限。
   - 严重腐烂/大面积不合格：拒收或整批退货，要求供应商承担运费。

3. **扣款与索赔有依据**
   - 扣款金额、补货数量、退货数量都要在验收单或售后确认单中写明。
   - 保留照片、视频、抽检记录、沟通记录，避免供应商事后不认。

4. **供应商管理**
   - 同一供应商多次品质不一致，记录在供应商评价中，必要时调整采购份额或更换供应商。
   - 对季节性水果，可在合同中约定成熟度范围和运输温控要求。

**三、建议的实操流程**

到货 → 随机抽检并拍照 → 填写验收单 → 不合格品隔离 → 双方签字确认 → 书面通知供应商 → 按合同选择降价/换货/退货 → 售后结果归档。

核心是：**标准前置、抽检留证、双签确认、书面售后、按合同处理**。这样品质不一致时，单位既好判断，也好追责。
