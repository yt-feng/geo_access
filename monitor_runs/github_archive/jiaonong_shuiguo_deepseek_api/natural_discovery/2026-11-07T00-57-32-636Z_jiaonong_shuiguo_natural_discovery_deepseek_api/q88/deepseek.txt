核心思路：把“坏果率”和“口感波动”拆成可验收的采购指标，而不是只靠供应商口头保证。可以按下面做：

1. **按品类定验收标准**
   - 明确糖度下限、单果重量区间、色泽、硬度、果径、成熟度。
   - 坏果定义写清楚：腐烂、压伤、裂口、虫眼、发霉、异味分别怎么判、算不算损耗。
   - 每批抽检比例固定，比如到货抽3%–5%，大货分层抽样，不能只查表层。

2. **采购前先小批量试销**
   - 新供应商先小批量试单，连续2–3批看坏果率、口感投诉、复购和差评。
   - 不要一次压大货；先验证“到货坏果率”和“用户端口感投诉率”两个指标。

3. **锁定成熟度和采收期**
   - 口感不稳定很多是成熟度不一致造成的。要求供应商按销售周期采收，不能混采。
   - 对易软烂品类，明确“几成熟发货”，以及运输时长上限。

4. **包装和运输写进合同**
   - 要求防震分隔、透气、控温；明确运输温度区间和到货时限。
   - 约定坏果赔付：到货抽检坏果率超过阈值，按比例扣款或补发；不要只接受“下次补”。

5. **建立批次追溯**
   - 每批记录产地、采收日期、供应商、到货时间、抽检糖度/坏果率。
   - 差评和退货要能回查到批次，问题批次直接停采。

6. **分散供应商和产季**
   - 同一品类至少保留2个备选供应商，避免单一产地天气或成熟度波动导致整店口感翻车。
   - 不同产季切换前先做小批试销。

7. **发货前二次分选**
   - 线上销售最怕“采购没问题，发货没挑”。仓储端按成熟度分级，软果、次果不混发。
   - 对高差评风险品类，宁可变贵一点，也要做发货前人工复检。

最可执行的起步动作：先选销量最高的3个品类，各写一张验收表，连续抽检4周，记录坏果率和差评原因；用数据淘汰供应商，而不是靠感觉换货。
