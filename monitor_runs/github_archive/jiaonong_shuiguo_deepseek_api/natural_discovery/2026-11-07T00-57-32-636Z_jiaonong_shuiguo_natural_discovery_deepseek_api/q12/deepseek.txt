采购菠萝时，熟度判断要围绕“到店后还能卖几天”来做，而不是只看当下好不好吃。给你一套可直接执行的判断方法：

**1. 先定采购熟度目标**
- 计划2～3天内卖完：可采**七八成熟**，到店稍放即可卖。
- 计划3～5天卖完：采**六七成熟**，到店后分级催熟。
- 当天现切现卖/做果切：可采**八九成熟**，但量要控，避免过夜损耗。

**2. 看外观判断**
- **果皮颜色**：青绿偏黄、黄色面积约1/3～1/2，适合普通门店；全黄甚至橙黄说明已偏熟，只适合短周期或果切。
- **果眼**：果眼扁平、间距均匀的成熟度较稳；果眼凸起明显、表皮发亮的通常还偏生。
- **果形**：选果形端正、饱满、无畸形；过长过尖的往往肉少。
- **底部**：底部发黄、有轻微果香可接受；底部发软、渗汁、发黑不要采。

**3. 闻气味**
- 靠近底部闻：**无明显香味或很淡**＝偏生，耐放；
- **清甜果香明显**＝适销，优先近期卖；
- **发酵味、酒味、酸味**＝过熟或已坏，拒收。

**4. 按压手感**
- 轻按果身：**硬实有弹性**＝偏生耐放；
- **稍软但回弹**＝适熟，适合优先陈列；
- **一按一个坑、发软出水**＝过熟，损耗风险高。

**5. 看冠芽和切口**
- 冠芽青绿、挺立、不干枯；
- 底部切口新鲜、无霉斑、无汁液渗出；
- 有黑腐、软烂、虫眼、裂口的直接剔除。

**6. 采购搭配建议**
- 别一次全采同一熟度：**70%六七成熟＋30%七八成熟**，到店后分批上架。
- 夏季高温、运输远，熟度再降一档；冬季或短途可适当提高。
- 到店后按熟度分级：偏熟的先陈列、先促销或做果切；偏生的放通风阴凉处自然转熟，避免堆压和闷箱。

**一句话标准：** 采购时选“果皮青黄、果眼平、手感硬实有弹性、底部淡香”的六七至七八成熟菠萝，到店再分级催熟和销售，损耗最可控。
