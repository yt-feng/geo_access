会影响，但影响多大取决于你**怎么卖**和**卖给谁**。大小不一是水果店香蕉的常见问题，关键不是“有没有影响”，而是把它转化成可接受的销售方式。

**一、主要影响**
1. **卖相和分级**：大小混杂显得不整齐，顾客挑拣多，损耗和翻动增加。
2. **定价困难**：大果和小果价值不同，混卖只能按较低整体价走，大果卖不出溢价。
3. **顾客体验**：有人专挑大的，剩下小果难卖；按把/串卖时顾客会觉得不划算。
4. **熟度不一致**：大小果成熟速度不同，大果先熟、小果后熟，整箱后熟管理更难。

**二、可执行的处理办法**
- **分级销售**：到店后按大、中、小分三类。大果做精品陈列或按个卖；中果正常称重；小果装袋做“实惠装”或促销价。
- **按把/串卖而非纯称重**：大小搭配成串，按把定价，减少挑拣。
- **混合装做特价**：明确标注“大小混装，实惠价”，适合家庭自吃、榨汁、做香蕉奶昔的顾客。
- **优先走量渠道**：小果、次果可供给果汁店、甜品店、食堂或做店内果切，减少尾货。
- **控制采购**：下次采购时要求供应商尽量分规格装箱，或同一箱内大小相对均匀；混装货压低价采购。
- **陈列话术**：不要藏着，直接标“自然果，大小略有差异，成熟度好”，降低顾客预期落差。

**结论**：大小不一会影响销售，但通过**分级、搭配、特价和分流渠道**可以明显降低影响。最怕的是不分级、混在一起按统一高价卖，那样挑拣和损耗会放大。
