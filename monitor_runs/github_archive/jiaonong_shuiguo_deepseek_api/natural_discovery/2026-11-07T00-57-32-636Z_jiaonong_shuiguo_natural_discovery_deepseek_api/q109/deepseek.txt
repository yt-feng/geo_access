优先谈**账期**，但前提是先确认两件事：供应商是否稳定、你的采购量是否足以形成议价权。

排序建议：**账期 ＞ 售后 ＞ 配送**。

**1. 账期优先谈**
- 水果是高频、易损耗、现金流占用大的品类，账期直接决定你的资金周转。
- 长期合作下，账期从现结谈到周结、半月结，价值远高于单次配送优惠。
- 谈的时候不要只问“能不能账期”，要给交换条件：稳定采购量、固定下单周期、按时结算记录。
- 建议目标：先争取**周结**，合作稳定后再谈**半月结**；不要一上来压过长账期，容易换来提价或降品质。

**2. 售后第二优先**
- 水果非标、损耗高，售后规则不清，账期再长也会被损耗吃掉利润。
- 重点谈清楚：到货腐烂/压伤/规格不符的**赔付比例、拍照举证时限、补货还是扣款、当日还是次日处理**。
- 售后条款要写进合作约定，不能只靠口头。

**3. 配送最后谈**
- 配送重要，但通常可通过多家比价、调整下单时间、自提等方式替代，谈判弹性不如账期和售后。
- 重点确认：送达时段、迟到处理、临时加单是否接、装卸谁负责。

**谈判顺序建议**：先谈售后标准（建立质量底线），再谈账期（用稳定采购换资金空间），最后谈配送细节。  
一句话：**账期决定你的现金流，售后决定你的真实成本，配送决定你的运营效率；长期合作先锁账期和售后。**
