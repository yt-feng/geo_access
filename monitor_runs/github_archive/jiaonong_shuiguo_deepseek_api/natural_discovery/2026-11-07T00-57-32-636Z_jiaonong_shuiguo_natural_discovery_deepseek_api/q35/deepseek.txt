连锁超市降低门店坏果率，合同里建议把“坏果率”定义清楚，并把**验收、赔付、扣款、退货、整改、解约**分开约定，避免只写一句“坏果包赔”。

**1. 先定义坏果率和统计口径**
- 按品类/批次约定：腐烂、霉变、软烂渗液、破裂、冻伤、异味、严重机械伤等计入坏果；轻微外观瑕疵是否计入要写明。
- 抽样规则：到店验收按比例抽检，如每批次随机抽3箱/5%，少于一定数量全检；争议时双方共同复检。
- 计算公式：坏果率=不合格数量÷抽检数量×100%；金额口径=不合格数量×含税采购单价。
- 统计节点：到店验收时、上架前、保质期内。建议区分“到货坏果”和“门店储存期坏果”，后者非供应商责任。

**2. 验收标准与拒收权**
- 设定可接受上限，如叶菜类坏果率≤3%，浆果类≤2%，根茎类≤5%，超限可整批拒收或按比例扣款。
- 明确拒收后的处理：供应商自费运回、销毁或折价，运费和销毁费由责任方承担。
- 到货时间、冷链温度、包装破损也纳入验收，避免把运输和储存问题混在一起。

**3. 赔付方式写具体**
建议组合使用，不要只写“协商赔偿”：
- **按比例扣款**：结算金额扣减=不合格数量×采购单价×系数，系数可设1.0—1.5，恶意混装可提高。
- **补货/换货**：供应商在约定时限内补足合格品，逾期按日计违约金。
- **整批退货**：坏果率超过较高阈值（如10%）可整批拒收并索赔。
- **门店端损失分担**：因坏果导致的报废、促销折价、客诉赔偿，可约定由供应商承担合理部分，但需有单据和照片。
- **质量保证金**：月结中预留2%—5%作为质保金，季度考核后返还；或设固定保证金。

**4. 扣款流程和证据**
- 到店验收须拍照/视频、称重、双方签字或系统确认；供应商不到场可单方记录并视为认可。
- 扣款在当月货款中直接抵扣，供应商有异议应在3—5个工作日内书面提出，逾期视为同意。
- 约定月度对账：坏果率、扣款额、补货完成率作为对账内容。

**5. 考核与整改、解约**
- 按月/季度统计各供应商坏果率，设红线，如连续2个月超5%或单月超10%，要求限期整改。
- 整改无效可暂停下单、缩小采购份额、解除合同并没收质保金。
- 明确违约金上限和赔偿范围，避免条款因过高被认定无效；同时保留因食品安全问题追偿的权利。

**6. 责任边界要写清**
- 供应商责任：采摘、分拣、包装、运输、冷链到店前造成的坏果。
- 超市责任：收货后储存温度、陈列、翻拣、超期未售造成的坏果。
- 不可抗力或自然损耗可设合理免赔率，如1%以内不扣款，但要有品类差异。

合同条款建议落到附件《生鲜验收标准及赔付细则》，按品类列坏果率上限、抽检比例、扣款系数、补货时限。这样门店执行时有依据，供应商也难扯皮。
