# 批发合同中坏果责任的写法要点

核心思路：**先定验收标准，再定责任归属和时限，最后定赔付方式**。坏果责任最容易出纠纷的地方不是“赔不赔”，而是“怎么算坏、什么时候算、算谁的”。

## 一、明确质量标准和“坏果”定义

合同中不能只写“坏果”，要量化：
- 等级标准：果径、糖度、色泽、成熟度，最好附样品或行业标准编号（如按国家标准或双方封样）。
- “坏果”的界定：腐烂、霉变、明显压伤、裂口、虫害等，逐项列明。
- 允许损耗率：约定一个合理比例（如到货验收时坏果率不超过X%视为合格，超出部分由供方承担）。这个比例要按品类和运输距离谈，别照抄。

## 二、验收环节是责任划分的关键

- **验收时限**：货到后多少小时内完成验收（如24小时/48小时），逾期未提出异议视为验收合格。
- **验收方式**：谁在场、怎么抽样（如按批次随机抽N箱，抽检结果代表整批）、是否拍照/录像留证。
- **异议程序**：发现超标坏果，买方应在时限内书面（含微信、邮件等可留痕方式）通知卖方，并保留货物原状或影像证据，否则视为认可。

## 三、责任归属分阶段写清

- **装车前**：卖方对装车前的品质负责，装车时双方可共同确认。
- **运输途中**：明确运输由谁负责。若买方自提或买方指定承运人，途中损耗一般由买方承担；若卖方负责送货，途中非因买方原因造成的损耗由卖方承担。**这一条一定要写，很多纠纷就出在“路上坏的算谁的”。**
- **到货后**：验收合格后风险转移给买方；验收不合格部分按约定处理。

## 四、赔付方式要可执行

- 超出允许损耗率的部分：按该部分货值扣减货款，或补发，或折价处理，三选一写死。
- 约定计算方式：如“坏果率超出X%的，超出部分按当批次单价的Y%扣款”，避免扯皮。
- 设置上限和下限：如单批扣款不超过该批货款的Z%，避免极端情况。
- 争议解决：协商不成时的鉴定机构或仲裁/诉讼管辖。

## 五、实用建议

1. **附封样**：签约时双方封存标准样品，验收时对照，比文字描述管用。
2. **留痕**：装车、卸货、抽检全程拍照录像，合同里写明影像可作为证据。
3. **别把损耗率定成0**：生鲜运输必然有损耗，定得过严供方要么涨价要么拒签，反而不利于履约。
4. **区分“自然损耗”和“质量缺陷”**：前者按比例双方分担，后者由责任方全额承担。

一句话总结条款结构：**质量标准＋允许损耗率＋验收时限与程序＋分阶段风险归属＋超标赔付计算方式＋证据规则**。把这六块写全，坏果纠纷基本能覆盖。
