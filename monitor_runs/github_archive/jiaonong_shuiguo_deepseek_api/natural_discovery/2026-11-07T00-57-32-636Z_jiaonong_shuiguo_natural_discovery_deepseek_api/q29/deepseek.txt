超市和水果供应商的账期没有唯一标准，常见区间可以这样判断：

1. **现结/7天以内**：多见于小超市、夫妻店、批发市场拿货、叶菜/草莓/荔枝等损耗极快品类。
2. **7～15天**：社区超市、区域中小连锁较常见，尤其是刚开始合作、单品周转快的供应商。
3. **15～30天**：连锁超市、商超渠道较常见。水果类因损耗高，通常比包装食品账期短，**30天已算偏长**。
4. **30～45天**：大型连锁、强势渠道可能压到，但对水果供应商资金压力较大，通常伴随返点、促销、损耗承担等条件。
5. **60天以上**：水果生鲜里不算普遍，更多见于强势大卖场或供应商有较强资金实力、长期合作的情况。

实操建议：
- 新供应商先做**7～15天**，稳定后再谈**15～30天**。
- 超市方谈判时可参考：本地小供应商多接受**7～15天**；有规模的水果供应商对**15～30天**接受度较高；超过30天要准备承担更高报价或返利条件。
- 供应商方要重点确认：**对账日、开票日、付款日**是否明确，损耗和退换货怎么扣，逾期是否有违约金。账期“30天”如果是“月结30天”还是“货到30天”，差别很大。

一句话：**水果供应商常见账期是7～30天，15天左右比较中性；30天以上属于偏长，需要看渠道强势程度和合作条件。**
