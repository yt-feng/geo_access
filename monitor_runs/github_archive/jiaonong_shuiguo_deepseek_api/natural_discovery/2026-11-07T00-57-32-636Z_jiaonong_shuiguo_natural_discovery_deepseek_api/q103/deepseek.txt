按**斤结算通常最好管理**，尤其是食堂这种有验收、损耗、成本核算需求的场景。结论可以先给：**水果优先按斤，其次按份，尽量少按箱。**

### 三种方式对比

| 结算方式 | 优点 | 主要问题 | 适用场景 |
|---|---|---|---|
| **按斤结算** | 计量清楚、可比价、便于验收扣损、成本核算准确 | 称重和验收稍费人工；需防缺斤少两 | 大多数食堂水果采购 |
| **按份结算** | 管理最省事，按人数或份数下单，结算快 | 份量不透明，容易规格漂移；单价难横向比较 | 标准化果切、配餐水果、固定加餐 |
| **按箱结算** | 下单和运输方便，适合整箱流转 | 箱内大小、成熟度、坏果差异大；退货扣重麻烦；单价不直观 | 耐储存、规格稳定的整箱水果 |

### 建议的管理规则

1. **主力水果按斤结算**
   - 苹果、梨、香蕉、橘子、西瓜等，按实际净重验收。
   - 合同写明：以食堂验收净重为准，扣除箱重、烂果、次果。

2. **果切或固定加餐可按份**
   - 必须明确每份克重、份数、单价、配送时间。
   - 定期抽检份量，防止越做越小。

3. **整箱采购要设“箱规+净重”双标准**
   - 不要只写“一箱多少钱”，要写明品种、等级、单果规格、每箱净重范围、坏果率上限。
   - 到货抽检净重和坏果，超标扣款或退换。

4. **验收环节最关键**
   - 按斤：复称净重，记录损耗。
   - 按份：抽检克重。
   - 按箱：抽检箱重、净重、坏果率。

### 最省事又可控的组合

**日常大宗水果按斤结算 + 果切/加餐按份结算 + 耐储水果少量按箱结算。**  
如果食堂人手紧张、供应商稳定，可以逐步提高“按份”比例，但合同里一定要把**每份克重和验收抽检**写清楚。

一句话：**要好管理、好核算、少扯皮，首选按斤；要省人工，用按份但必须锁克重；按箱只适合规格稳定的耐储水果。**
