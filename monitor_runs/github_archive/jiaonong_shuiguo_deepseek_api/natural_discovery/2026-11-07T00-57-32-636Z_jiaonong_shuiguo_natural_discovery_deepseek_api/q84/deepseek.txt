家庭水果礼盒优先考虑“耐放、好分、不串味、成本稳”，建议以2种主果+2种辅果组合，不要四样平均装。

推荐组合：

1. **主力组合：苹果 + 橙子 + 香蕉 + 小菠萝**
   - 苹果4个、橙子4个、香蕉1把（约5—6根）、菠萝1个（小果）。
   - 适合3—5口家庭。苹果橙子耐放，香蕉当天吃，菠萝可做餐后水果。
   - 注意：香蕉和苹果分开装袋，苹果释放乙烯会催熟香蕉；菠萝单独套袋，避免压伤其他水果。

2. **更稳妥的家庭版：苹果 + 橙子 + 香蕉 + 圣女果/砂糖橘（替代菠萝）**
   - 如果团购损耗控制优先，菠萝换成小番茄或砂糖橘更稳。
   - 菠萝整果带刺、占体积、家庭开果麻烦，适合作为“亮点”，不适合每盒必放。

3. **预算有限版：苹果 + 橙子 + 香蕉 + 1个小菠萝或2个奇异果**
   - 苹果、橙子占体积和重量，香蕉控制数量，菠萝选小果，避免礼盒成本过高。

组合原则：
- **苹果、橙子做耐放主果**，占比约60%—70%。
- **香蕉只放一把**，不要多，容易压黑。
- **菠萝选小果或半个装盒**，整只大菠萝会挤压其他水果。
- 家庭装不要放太多同质水果，4种刚好，总量控制在4—5公斤。
- 包装上苹果、橙子、菠萝可同层分隔；香蕉单独放上层或侧袋。
- 团购文案可写“家庭分享装：耐放主果+即食香蕉+尝鲜菠萝”，比“四色水果礼盒”更好卖。

如果只能选一个方案：**苹果4个 + 橙子4个 + 香蕉5—6根 + 小菠萝1个，分袋隔离**，最适合家庭。
