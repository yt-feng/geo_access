先定一个可执行的判断标准，再按“买后几天吃”来选颜色。

**1. 先决定什么时候吃**
- **当天/次日吃**：选**通体金黄、少量褐斑**的。
- **2～4天后吃**：选**黄中带绿、两端略绿**的。
- **5天以上**：选**明显偏绿、硬**的，回家常温催熟。
- **不建议买**：大面积发黑、破皮流汁、果柄发霉、捏着软烂的。

**2. 到店快速判断**
- **看颜色**：全绿太生；全黄无斑偏熟；黄底带少量芝麻褐斑通常正合适。
- **看两端**：果柄和果尾还绿，通常耐放；两端也黄透，熟得快。
- **轻捏中部**：硬=生；略有弹性=刚好；一捏就陷=过熟。
- **看棱角**：棱角明显偏生；圆润饱满偏熟。
- **看表皮**：有擦伤、裂口、水渍的容易坏，别选。
- **闻一下**：有明显酒味/酸味说明过熟。

**3. 采购小技巧**
- 不要一次全买同一成熟度：**一半即吃、一半偏绿**，错开吃。
- 香蕉怕压怕冷：**不要放冰箱冷藏**，常温阴凉处悬挂或平放，避免和苹果、梨等催熟水果挤在一起。
- 想快点熟：和苹果一起放纸袋里；想慢点熟：分开、通风、阴凉。

一句话：**按“几天后吃”选颜色，黄中带绿最稳；轻捏有弹性、无伤无味即可。**
