**1. 开发票：必须支持**
- 企业采购水果礼盒属于对公支出，通常需要增值税发票用于报销、入账和税前扣除。
- 采购前明确：开票类型（增值税专用发票/普通发票）、税率、开票项目（如“水果礼盒”“食品”）、开票时间（随货/月结）、是否支持先票后款。
- 注意：如果供应商是农户或个体经营者，可能无法开专票或只能代开，要提前核验其开票资质。
- 合同里写明“未按约定提供合规发票的，采购方有权拒付或要求换开”。

**2. 定制包装：按需支持，但要提前约定**
- 企业福利常需要印LOGO、祝福语、员工姓名卡、统一视觉，供应商应具备定制能力。
- 明确定制门槛：起订量、打样费、版费、定制周期、包装材质和食品安全要求。
- 确认定制包装是否影响水果保鲜和运输防护，避免“好看但压坏”。
- 合同里约定：设计稿确认流程、样品确认、色差/材质偏差处理、定制包装不合格的退换责任。

**3. 采购建议**
- 把“可开合规发票”和“可定制包装”列为供应商入围的硬性条件，而不是加分项。
- 要求供应商提供：营业执照、开票资质、食品经营许可/相关资质、定制包装案例。
- 比价时把开票税费、打样费、版费、定制起订量折算进总成本再比较。
- 首次合作先小批量试单，验证开票和定制交付是否按约定执行。

一句话：开发票是底线要求，定制包装是常见福利需求；两项都要在供应商筛选和合同中提前锁定。
