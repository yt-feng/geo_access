小商家采购水果，现金结算和月结账期的风险可以按“资金压力、货损与质量、供应商关系、对账与凭证、断供风险”分开看。

## 一、现金结算的风险

1. **资金占用和周转压力**
   - 现结能拿到更好价格或优先挑货，但会压住流动资金；水果损耗高、回款有账期时，容易出现“货卖了、钱还没回来，但采购款已付”的缺口。

2. **质量与数量争议难追溯**
   - 现金交易常见口头约定、简单收据甚至无票。事后发现短斤少两、以次充好、坏果率高，追责和退换货谈判空间较小。
   - 建议每笔留：过磅单/称重照片、品种规格、单价、数量、总价、坏果扣款约定、收款人签字或微信确认。

3. **无票/缺票的税务与合规风险**
   - 大量现金采购若无合规凭证，入账、成本扣除、进项抵扣都可能有问题；从农户或个人处采购还要关注自产农产品收购凭证等合规要求。
   - 不要用“白条”长期替代合规凭证；至少保留转账记录、收据、身份信息和交易明细。

4. **人身与现金安全、内部舞弊**
   - 现金携带和保管有安全风险；店员经手现金采购也容易产生截留、虚报价格、虚增重量等内控问题。
   - 建议限额备用金、双人验收、每日对账、采购与付款分离。

5. **议价优势可能是假象**
   - 现结换低价要算总账：若因此减少安全库存、被迫接受差货或占用应急资金，综合成本可能更高。

## 二、月结账期的风险

1. **供应商信用风险与断供**
   - 账期本质是供应商给你授信。一旦你回款慢、对账有争议或供应商自身资金紧张，可能被停供、缩量、优先供给现结客户，水果旺季断供影响很大。

2. **价格与质量隐性成本**
   - 月结供应商可能把资金成本打进单价，或在你急要货时给次货。要比较“现结价”和“月结价”的真实差额，别只看账面单价。

3. **对账争议和坏果扣款扯皮**
   - 水果非标、损耗高，月结最容易在“这批坏果谁承担、扣款多少、退货是否已入账”上扯皮。
   - 建议每车/每批当场验收并双方签字确认，送货单注明品种、等级、件数、重量、单价、坏果扣款；月底对账单先对数量再对金额，争议款项单独挂账。

4. **账期管理与现金流错觉**
   - 月结容易让采购放松，觉得“下月才付”，实际形成应付账款堆积；若销售回款也慢，可能出现集中付款压力。
   - 建议做应付账款台账：供应商、账期起算日、到期日、已验收未对账、争议金额、预计付款日。

5. **依赖单一供应商**
   - 月结往往绑定一家主供，临时换供成本高。应保留至少一个备用供应商，并明确账期不是无限授信。

6. **合同与凭证风险**
   - 仅有口头月结，供应商随时可改规则；若对方是公司，应签简单采购框架：账期天数、对账日、付款日、质量标准、坏果扣款、逾期利息、停供通知期。
   - 避免个人账户代收公司货款、避免无授权人员确认对账单。

## 三、可执行的折中做法

- **小额现结 + 大额月结**：叶菜、易损耗、急需补货用现结；主销稳定品种用月结，但设授信上限。
- **现结换折扣要量化**：比较月结单价上浮、资金占用成本和坏果率，算综合采购成本。
- **每批必验收**：称重、拍照、签字，坏果当场扣款，月底只核对已确认单据。
- **账期写清楚**：起算日按“验收合格且对账确认”起算，避免送货日与对账日争议。
- **留备用供应商**：月结供应商停供时能在1—2天内补货。
- **现金采购留痕**：收据、转账、身份信息、过磅记录齐全，减少税务和追责风险。

一句话：现金结算主要风险是**资金占用、凭证不足和争议难追溯**；月结主要风险是**断供、对账扯皮、隐性涨价和应付堆积**。小商家最稳妥的是“现结保灵活、月结保主供，但每批验收留痕、账期设上限”。
