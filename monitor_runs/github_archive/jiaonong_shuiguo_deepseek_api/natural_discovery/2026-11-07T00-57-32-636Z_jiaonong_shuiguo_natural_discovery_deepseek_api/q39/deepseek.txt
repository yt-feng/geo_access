可以，而且这通常不是“能不能”，是“谈到什么程度、由谁承担成本和风险”。给你一个可判断的框架：

**一、供应商一般能提供的支持**
- **包装**：多数水果供应商可做定制纸箱、彩盒、吸塑盒、网套、标签、手提袋，支持印商超自有品牌LOGO、产地、等级、追溯码。
- **规格**：可按果径、单果重、个数/箱、净重、等级（特级/一级）、成熟度、糖度区间分选。
- **组合装**：多品类拼箱、礼盒装、家庭装、小规格尝鲜装。
- **贴标与追溯**：贴自有品牌标签、批次码、采摘/包装日期。
- **代采代发**：部分供应商可做一件代发或门店直配。

**二、但要分清三种供应商能力**
1. **产地/合作社型**：包装能力弱，规格分选靠人工，适合做基础款，定制包装需你方提供包材或找第三方。
2. **产地服务商/代加工型**：能分选、打包、贴标，定制包装支持较好，是商超自有品牌最常见合作方。
3. **批发市场档口型**：灵活但标准化弱，包装多为通用箱，规格稳定性差，不适合做长期自有品牌。

**三、必须提前谈死的条款**
- **最小起订量**：定制包装通常有MOQ，包材起订量可能远高于单次水果采购量。
- **包材成本归属**：谁设计、谁打样、谁付版费、谁承担库存；常见是商超承担包材或分摊。
- **规格公差**：写清果径/单果重允许偏差、次果率上限、糖度下限。
- **损耗与售后**：到店损耗、烂果率、缺重怎么赔。
- **独家与知识产权**：包装设计归属、供应商不得把同款包装卖给竞品。
- **换供应商时包材怎么办**：版费、模具、剩余包材处理。

**四、给你的可执行建议**
1. 先选1—2个单品试点（如苹果、橙子），不要全品类铺开。
2. 要求供应商提供：现有分选线照片/视频、定制包装打样、近3批规格检测记录。
3. 合同里写“规格公差+次果率+糖度”三项硬指标，比谈价格更重要。
4. 包装先做通用版+贴标，验证动销后再上定制印刷，降低包材库存风险。
5. 如果供应商说“都能做”，重点追问：**分选设备、包材起订量、打样周期、谁承担版费**。

一句话：供应商普遍能提供包装和规格支持，但**标准化分选能力和包材成本分担**才是决定自有品牌能不能做稳的关键。
