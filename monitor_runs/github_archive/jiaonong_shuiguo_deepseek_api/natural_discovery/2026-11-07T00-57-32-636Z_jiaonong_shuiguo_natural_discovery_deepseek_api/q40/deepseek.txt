节假日水果需求暴增，连锁超市要提前锁定货源，核心是**把“临时抢货”变成“提前锁量、锁价、锁品质、锁运力”**。建议按下面几步做，通常提前3—6周启动，春节、中秋等大节提前6—8周更稳。

**1. 先做需求预测，按品类分级锁货**
- 拉取近2—3年同节假日的门店销量、客流、客单价、损耗率，按门店和品类做预测。
- 把水果分成三类：  
  - **爆款刚需**：苹果、橙子、香蕉、梨、砂糖橘等，走量稳定，重点锁量和锁价。  
  - **节庆礼品果**：车厘子、草莓、礼盒装、进口果等，利润高但波动大，锁“框架量+浮动量”。  
  - **易损耗鲜果**：葡萄、桃、荔枝等，锁短期产能和冷链运力，不宜一次性压太多库存。
- 预测时加上安全库存，但鲜果安全库存不宜过高，按“多批次、小批量、高频补货”设计。

**2. 提前与供应商签框架协议**
- 与核心供应商签节假日保供协议，明确：保供品类、最低供货量、价格机制、质量标准、到货时间、违约赔付。
- 价格不要只锁死一口价，可采用“基准价+浮动区间”或“锁量不锁死价、设价格上限”，避免供应商因行情暴涨毁约。
- 对关键单品发展2—3家备选供应商，避免单一产地或单一供应商断供。
- 对礼品果、进口果提前下意向订单，支付少量定金锁产能。

**3. 向上游产地提前锁园、锁仓**
- 对大宗单品，提前到主产区锁定果园或合作社产能，签订采购意向，约定采摘期和分级标准。
- 与供应商协商“产地暂存+分批调运”，节前把部分耐储果存入产地仓或销地仓，按门店节奏分批出货。
- 对易损耗果，优先锁“加工分选能力”和“冷链车次”，而不是单纯锁库存。

**4. 锁定物流与冷链运力**
- 节前运力紧张，提前与物流商确认节假日车次、司机、冷库月台和卸货时段。
- 对跨区域调运的果品，签订运力保障协议，明确延误责任。
- 门店端提前排定收货窗口，避免集中到货造成压车和损耗。

**5. 建立分级储备和动态补货机制**
- 总部设“核心单品总仓储备+区域仓周转+门店日配”三层结构。
- 耐储果适当提高总仓储备；鲜果以区域仓和门店高频补货为主。
- 设置库存预警线：低于安全库存自动触发补货，高于上限则启动促销或调拨。
- 节假日期间每日复盘销量、到货、损耗和价格，动态追加订单。

**6. 用合同和备选方案防风险**
- 合同写明：质量不达标拒收、延迟到货赔付、不可抗力处理、价格异常时的协商机制。
- 准备替代产地和替代品类方案，例如某进口果断供时用国产优质果替代。
- 对供应商做节前产能核查，避免“签了约但没货”。

**7. 门店端配合减少损耗**
- 提前培训门店按节日客流调整陈列和订货量。
- 礼品果提前做预包装和礼盒备货，鲜果按日配送。
- 设置临期果快速处理机制，避免节后集中损耗。

**可执行清单：**
- 节前6—8周：完成销量预测和品类分级。
- 节前4—6周：签核心供应商保供协议，锁量、锁价区间、锁运力。
- 节前3—4周：产地锁园/锁仓，下礼品果和进口果订单。
- 节前2周：确认到货计划、门店收货排期、备用供应商名单。
- 节前1周至节中：每日复盘，动态补货和调拨。

一句话总结：**耐储爆款提前锁量锁价，鲜果锁产能和冷链，礼品果锁订单和定金，所有关键单品保留备选供应商和替代产地。**
