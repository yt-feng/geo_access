酒店采购水果盘原料时，建议把“可验收”的标准写进采购单/合同附件，至少覆盖以下规格与外观要求。

**一、通用到货要求**
1. **品种、产地/品牌、等级明确**：如“一级果”“酒店专供级”，不接受混级、落地果、次级果冒充。
2. **成熟度**：到货时处于“即食或1—2天内可达最佳食用”的状态；香蕉、牛油果、芒果等需按后熟阶段约定。
3. **批次一致**：同一批次大小、色泽、成熟度基本一致，便于摆盘统一。
4. **温度与冷链**：易腐水果全程冷藏/冷链，到货中心温度符合品类要求；不得有断链、暴晒、冻伤。
5. **农残与安全**：提供合格证明/检测报告或承诺符合国家农残限量；不得使用违规保鲜剂、催熟剂、染色剂。
6. **包装**：洁净、无污染、无虫害；内包装不直接接触污染源；标明品名、批次、到货日期。
7. **到货时限**：采摘/分拣后至到货时间可控，叶菜类不适用；浆果、切果类尤其要短。

**二、外观与规格验收标准**
1. **新鲜度**：果面洁净，无腐烂、霉变、异味、发酵味；无严重失水皱缩、干疤。
2. **完整性**：无破裂、明显压伤、磕伤、虫眼、病斑；切口类原料切面新鲜、无褐变、无汁液浑浊。
3. **大小与形状**：按品种约定单果重量/直径/长度范围，同一批次公差尽量控制在±10%—15%以内；畸形果比例设上限。
4. **色泽**：符合品种固有色泽，成熟度一致；无明显日灼、药斑、褪色。
5. **表面**：无泥污、无大面积水渍；允许少量自然果锈/轻微表皮瑕疵，但不得影响摆盘和食用。
6. **缺陷率**：约定允许缺陷比例，例如外观缺陷果不超过5%，腐烂/霉变果为0；超出则拒收或扣款。
7. **异物与虫害**：无活虫、虫卵、蜗牛、枝叶杂物；无玻璃、塑料、金属等异物风险。

**三、按品类补充**
- **浆果类（草莓、蓝莓、树莓）**：果粉完整、无渗液霉变；蓝莓果实紧实，霉果率为0；草莓无软烂、白粉病斑。
- **柑橘类**：果皮无严重机械伤，无腐烂；切开类需皮薄汁多、籽少。
- **瓜类（西瓜、哈密瓜、火龙果）**：外形端正，无裂口渗液；切果类中心温度、切面新鲜度单独约定。
- **热带水果（芒果、木瓜、牛油果）**：按后熟度分级到货，避免“今天不能用、明天全烂”的集中成熟。
- **苹果、梨、葡萄**：果梗新鲜，无严重皱皮；葡萄果粒附着牢固、无落粒霉变。
- **叶/装饰类配叶**：无黄叶、萎蔫、虫斑，长度和颜色一致。

**四、验收与责任建议**
1. **抽样比例**：按到货箱数/件数抽检，如每批抽5%—10%，大货可分层抽样；腐烂、霉变、异味项目全检关键箱。
2. **验收记录**：记录品种、批次、数量、温度、缺陷率、拍照留证；不合格当场标记、隔离。
3. **退换货条款**：腐烂霉变、农残不合格、规格严重不符、冷链断链的，酒店有权拒收、退货或要求补货，费用由供应商承担。
4. **扣款/赔付**：按缺陷率设阶梯扣款；因原料问题导致客诉或食品安全事件的，约定赔偿责任。
5. **持续考核**：按月统计到货合格率、缺陷率、客诉率，纳入供应商评级。

最实用的做法是：**按酒店实际水果盘菜单，为每个品种列一张“品种—等级—单果规格—成熟度—缺陷率上限—冷链温度—验收方法”表**，作为合同附件，双方签字确认后按表验收。
