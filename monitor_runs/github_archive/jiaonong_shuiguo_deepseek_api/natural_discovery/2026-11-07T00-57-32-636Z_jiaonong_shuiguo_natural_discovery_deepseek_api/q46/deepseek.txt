优先买**鲜果**，其次选**冷冻果丁/果肉**，不建议把**果泥**作为果茶主原料。

直接判断如下：

1. **鲜菠萝**
   - 最适合做果茶：香气、纤维感、咀嚼感最好，顾客感知价值高。
   - 适合：现切菠萝果茶、菠萝柠檬茶、菠萝冰茶。
   - 注意：需要去皮、去眼、切丁，人工和损耗较高；要选成熟度稳定、酸甜适合饮用的批次。

2. **冷冻果丁/果肉**
   - 适合门店稳定出品、降低人工和损耗。
   - 优点：批次稳定、出杯快、季节性影响小。
   - 注意：选速冻、无额外糖浆或添加少的；解冻后口感会下降，适合做打碎型或果肉型饮品，不适合强调“现切鲜果”的产品。

3. **果泥**
   - 适合做调味、打底、冰沙或需要稳定酸甜度的产品。
   - 不适合作为主打“鲜果茶”的核心原料，因为缺少果肉感和现切感知，且可能含糖、香精或增稠剂。
   - 如果用于调节酸甜和出杯稳定性，可以作为辅助原料少量搭配。

**建议采购组合：**
- 主推产品用**鲜果**；
- 高峰期或标准化产品用**冷冻果丁**兜底；
- 果泥只做辅助调味，不作为“鲜果茶”卖点。

**采购前重点确认：**
- 是鲜切还是速冻，是否加糖/加糖浆；
- 可溶性固形物、酸甜度是否稳定；
- 解冻后出水情况；
- 每杯出成率和损耗；
- 供应商是否有检测报告和稳定供货能力。

如果门店人手紧、销量大，选**冷冻果丁为主+少量鲜果做展示和顶料**更实际；如果主打现切鲜果和高客单，选**鲜果**。
