# 向品牌方问清区域保护和串货：可直接照着问的清单

核心思路：**别只听承诺，要问清"规则+留痕+违约怎么办+执行证据"**。下面按你谈判时最该问的顺序列。

## 一、区域保护：问到"边界"和"例外"

1. **我的授权区域到底怎么划？** 按省/市/县，还是按渠道（商超、水果店、社区团购、电商）？请写进合同附件。
2. **是独家还是非独家？** 区域内品牌方自己还招不招第二家？我有没有优先续约权和扩区权？
3. **线上算不算我的区域？** 品牌方自营网店、官方旗舰店、直播带货，在我区域内卖不卖？这是水果行业最容易出问题的地方，必须单列一条。
4. **区域内的大客户/连锁商超谁来做？** 是我直供，还是品牌方直营或另授权？团购、批发市场档口算不算我的范围？
5. **区域保护期多长？** 考核指标是什么（年进货量、铺货网点数、回款）？完不成会不会被缩小区域或取消独家？反之完成了能不能锁定独家？
6. **跨区调货的例外**：品牌方自己的大促、临期清货、尾货处理，会不会进我区域低价冲？这些要提前约定。

## 二、串货：问到"认定标准+处罚+执行"

7. **串货怎么认定？** 是按包装批次码、区域专供码、还是举报核实？有没有一物一码追溯？请给我看现行规则。
8. **发现串货，处理流程和时限是什么？** 我举报后几天内响应、几天内给结论？由谁裁定？
9. **处罚对谁、力度多大？** 扣保证金、停货、取消授权、罚款？是罚串货方还是连我一起罚？我被串货冲了市场，品牌方赔不赔、怎么补偿？
10. **保证金和返利怎么挂钩？** 保证金多少、什么情况下扣、什么时候退？返利是否与"无串货"考核绑定？
11. **执行证据**：品牌方过去一年实际处理过几起串货？能不能给案例或处理记录？只讲制度不讲执行，基本等于没有。
12. **我自己的义务边界**：我区域内下游客户把货卖到区外，算不算我串货？我怎么管控下游、品牌方认不认我的管控措施？

## 三、合同里必须落下的条款

- 授权区域、渠道、期限、独家性，写进**合同附件**，口头不算。
- 线上销售归属和品牌方自营/直播的边界，单列条款。
- 串货认定标准、举报流程、响应时限、处罚与补偿，写成可执行条款。
- 保证金金额、扣除条件、退还时间。
- 考核指标与区域调整规则，双向写清（他也考核你，你也要求他保障）。
- 违约救济：协商不成怎么处理（仲裁/诉讼地）。

## 四、谈判时的判断标准

- **肯把规则写进合同、给得出历史处理记录的，相对靠谱**；只谈感情、说"放心不会串"的，风险高。
- **水果品类特殊性**：鲜果保质期短、价格波动大，临期尾货最容易变成低价串货来源。要专门问清"尾货和临期品怎么处理、流向哪里"。
- **线上是重灾区**：品牌方自播、达人带货、平台补贴，往往比线下经销商更能冲垮区域价格。这一条不写清，区域保护基本是纸面的。

建议把以上问题整理成一页纸，谈判时逐条让对方书面回复或直接改合同，**口头承诺一律要求落到合同或补充协议里**。
