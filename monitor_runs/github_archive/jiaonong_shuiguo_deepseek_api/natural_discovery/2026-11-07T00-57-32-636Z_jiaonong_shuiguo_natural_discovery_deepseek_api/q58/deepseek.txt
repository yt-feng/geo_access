通常直接买成品果丁的**显性损耗更低**，但总成本不一定更低；如果只问“损耗率”，多数甜品店选成品果丁更稳。判断关键是：你店里的菠萝周转速度、切配人力、冷藏条件和成品果丁的到货状态。

**建议这样选：**

1. **日均用量小、菜单销量不稳定 → 买成品果丁**
   - 鲜果切配损耗主要来自：去皮去眼、修边、切废、氧化出水、卖不完报废。
   - 成品果丁按需订货，拆袋即用，损耗通常集中在到货质量、保质期和开封后未用完。
   - 适合小店、新品试销、菠萝不是主力水果的店。

2. **日均用量大且稳定、有人手现场切 → 鲜果切配可能更划算**
   - 鲜果损耗率看似高，但可把修边果肉用于果酱、酸奶杯、冰沙、员工餐，实际净损耗可下降。
   - 前提是：每天能卖完、冷藏规范、切配后2—4小时内用完或密封冷藏当日用完。
   - 如果切配后经常剩到第二天，损耗会反超成品果丁。

3. **看“可食用率”而不是只看单价**
   - 鲜菠萝去皮去眼后的可食部分通常明显低于毛重，且成熟度、品种、批次差异大。
   - 成品果丁要看：净含量、糖水/汁液占比、到货破损、保质期剩余天数。
   - 比较公式：  
     **鲜果实际成本 = 毛重单价 ÷ 可食用率 + 切配人工 + 报废成本**  
     **成品成本 = 到货单价 ÷ 实际可用率 + 开封后报废成本**

4. **最稳妥的做法：做7天小对比**
   - 同一菜单、同一用量，分别记录鲜果和成品果丁的：进货毛重/净重、切配后可用重量、报废重量、人工分钟数、顾客投诉。
   - 如果鲜果可食用率低于约60%—65%，且人工紧张，成品果丁通常更优。
   - 如果鲜果可食用率能稳定在70%以上、当天用完，鲜果切配的总损耗和口感通常更好。

**结论：** 只比损耗，**成品果丁一般更低、更可控**；比综合成本，**用量大且周转快的店用鲜果切配更划算**。小店和用量不稳的店，优先成品果丁。
