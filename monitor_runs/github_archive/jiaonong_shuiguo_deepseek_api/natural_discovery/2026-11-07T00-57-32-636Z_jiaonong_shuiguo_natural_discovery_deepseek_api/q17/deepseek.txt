社区超市做水果，核心不是“多进货显得丰富”，而是用少量、多频、快周转把损耗压下来。给你一套可直接落地的做法：

**1. 先定品类结构，别所有水果一个进法**
- 引流款：香蕉、苹果、橙子、梨，走量稳定，可适当备货。
- 利润款：草莓、车厘子、葡萄、蓝莓，少量高频，卖相好但损耗高。
- 试销款：新品类先小批量试2–3天，卖不动立即停。
- 按“易损程度”分三级：高损（草莓/葡萄/桃）、中损（香蕉/柑橘）、低损（苹果/梨/橙）。高损品占总库存比例要低。

**2. 用“以销定进”代替凭感觉进货**
- 每天记录销量、到货量、损耗量，连续记2周就能算出每个单品的日均销量。
- 订货量公式：**明日订货 ≈ 近3天日均销量 × 调整系数 − 当前可售库存**。天气热、周末、节假日上调；雨天、工作日下调。
- 高损品只订1–2天量，低损品可订3–5天量。

**3. 设定库存红线**
- 给每个单品设“最高库存天数”：高损品1–2天，中损2–3天，低损3–5天。
- 超过红线不再进货，先促销清库。
- 每天闭店前盘点一次，重点看高损品剩多少。

**4. 动态定价清库存**
- 上午正常价，下午对临期品做“组合装/折扣装”，比如水果拼盘、买二送一。
- 高损品当天没卖完，闭店前打折清掉，别留到第二天。
- 设“损耗警戒线”：单品损耗率超过5%–8%，就减少下次订货量或暂停。

**5. 陈列和保管直接影响新鲜度**
- 少量多次补货，货架不要堆太满，避免底层压坏。
- 香蕉、苹果等释放乙烯的水果不要和草莓、绿叶菜混放。
- 冷藏水果和常温水果分区，温度按品类控制。
- 每天翻检，先卖旧的，新货放后面。

**6. 用预售和团购消化库存**
- 对高损品做社区群预售、接龙，按订单进货，减少盲进。
- 临期品做“特价接龙”，当天清完。

**7. 每周复盘三个数**
- 销量、损耗率、库存周转天数。
- 连续两周卖得慢的单品，直接砍掉或换品。
- 记住一句话：**水果宁可少卖一点，也不要压在店里烂掉。**
