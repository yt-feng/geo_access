先问**配送**，再问**售后**，最后谈**价格**。原因很直接：

1. **配送优先问**  
水果是生鲜，团购团长最怕的是：迟到、缺货、品相压坏、临时换货。配送不稳，价格再低也会把团长口碑做坏。重点问清：
- 到货时间能否固定、误差多大
- 起送量、配送费、谁卸货
- 缺货/少货怎么补
- 破损率大概多少、怎么认定
- 临时加单/减单截止时间

2. **售后第二问**  
水果售后决定团长会不会自己贴钱。重点问：
- 坏果、烂果、规格不符的赔付标准
- 是补货、退款还是下次抵扣
- 申诉时限和举证方式
- 售后响应时间
- 是否直接对接团长，还是让团员自己找

3. **价格最后谈**  
价格要谈，但应在配送和售后规则清楚后谈，否则低价可能对应“到货慢、坏果不赔、缺货不管”。谈价时确认：
- 是否含配送费
- 是否含损耗
- 不同起订量的阶梯价
- 结算方式、账期和押金

**判断标准：**  
如果供应商配送稳定、售后规则清楚，价格高一点可以接受；如果配送和售后含糊，只强调低价，风险通常由团长承担。最该先问配送，因为它是团长每天要面对、也最容易直接损害团员体验的环节。
