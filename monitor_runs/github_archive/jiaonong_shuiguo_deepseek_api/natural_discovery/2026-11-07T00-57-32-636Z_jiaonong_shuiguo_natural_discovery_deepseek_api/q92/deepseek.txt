小便利店做水果，核心不是“品类全”，而是“少SKU、快周转、可止损”。建议按下面几条落地：

**1. 品类控制：只做“顺手买”水果**
- 控制在 **8—15个SKU**，面积越小越靠下限。
- 结构建议：
  - **引流款2—3个**：香蕉、苹果、橙子这类认知高、周转稳的。
  - **即食款3—5个**：小番茄、葡萄、蓝莓、切好的果切，满足即时消费。
  - **季节款2—3个**：当季单品，少量试销。
  - **利润款1—2个**：精品小包装、礼盒小规格。
- 不要做：低频大单品、需要复杂陈列的、易碰伤且客单高的、同质化严重的（比如同时上5种苹果）。

**2. 采购量：按“日销×覆盖天数”定，不按感觉补**
- 易损耗品（香蕉、葡萄、蓝莓、果切）覆盖 **1—1.5天**。
- 中等耐放品（苹果、橙子、梨）覆盖 **2—3天**。
- 新品类首单只进 **最小陈列量**，卖动再加。
- 设“单品日销基线”：连续3天低于基线就减量或下架，不要等烂了再处理。

**3. 损耗控制：从收货到出清全链路**
- **收货**：只收成熟度适合便利店周转的货，香蕉不要一次进全熟；拒收碰伤、软烂、冷链断过的货。
- **陈列**：小面积用 **少量多补**，不要堆大堆；易压伤的水果分层、分格；香蕉悬挂或单层摆，避免叠压。
- **温控**：蓝莓、葡萄、果切、浆果类必须冷藏；苹果和香蕉尽量分开，香蕉对乙烯敏感。
- **日清**：每天早晚各查一次，挑出软伤果，能果切/打折的及时处理，不能卖的立刻报损，不要留在台面影响购买。
- **出清机制**：设定下午/晚间折扣时段，易损耗品当天出清；果切只做当天量。

**4. 用数据管，而不是用眼睛管**
- 每天记3个数：**进货量、销量、报损量**。
- 每周算单品 **损耗率**，超过 **8%—10%** 的易损耗品要缩量或换品。
- 连续两周动销慢的SKU直接淘汰，腾位置给周转快的。
- 果切单独核算：人工、包装、报损都算进去，不赚钱就不做。

**5. 小面积陈列原则**
- 水果区占门店面积不要过大，优先靠门口/收银动线做即食小包装。
- 用 **小筐、小托盘、分层架** 控制陈列量，视觉丰满但不压货。
- 一个品类只给一个位置，避免同类多SKU互相抢量。

**一句话执行版：**  
**SKU控制在10个左右，易损耗品只备1天量，耐放品备2—3天，少量多补、日清打折、按损耗率淘汰，果切当天做当天清。**
