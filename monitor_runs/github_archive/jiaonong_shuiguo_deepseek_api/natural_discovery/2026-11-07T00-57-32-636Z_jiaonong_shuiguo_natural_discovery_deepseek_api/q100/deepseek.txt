核心思路：**按“成熟度分批采购 + 临近过熟转用途 + 用量预测”管理**，而不是只买“看起来刚好”的香蕉。

可执行做法：

1. **采购时选成熟度偏低的香蕉**
   - 优先买“青黄交接、果柄青、无黑点”的香蕉。
   - 避免整批都买全黄、带芝麻黑点的。
   - 与供应商约定到货成熟度标准，例如“7成黄左右”，并要求分批次配送。

2. **分批到货，少量多次**
   - 不要一次囤太多，按 1—2 天用量配送。
   - 夏季或室温高时，改为每天少量补货。
   - 香蕉对温度敏感，食堂验收后放在阴凉通风处，不要堆压、不要密封闷着。

3. **按成熟度分区使用**
   - 青黄：正常供应。
   - 全黄：优先当天用完或做加餐。
   - 出现少量黑点但果肉正常：用于香蕉牛奶、香蕉粥、烘焙、甜品等。
   - 明显过熟但未变质：及时加工成香蕉泥、香蕉饼、香蕉面包，不要继续摆放零售。

4. **建立简单用量预测**
   - 记录近 1—2 周每天实际消耗量，按“日均消耗 × 安全系数1.1—1.2”订货。
   - 遇周末、假期、考试周、天气变化，提前调整采购量。
   - 设“最小陈列量”，卖完再补，避免长时间暴露。

5. **验收和库存轮换**
   - 收货时抽检成熟度，青黄、全黄分开存放。
   - 先进先出，先熟先用。
   - 每天下班前检查一次，把第二天可能过熟的香蕉挑出，转做加工或次日早餐优先消耗。

6. **和供应商约定退换或调剂**
   - 合同中写明到货成熟度、破损率、退换条件。
   - 对经常到货过熟的供应商减少订单或更换。
   - 可与供应商协商小批量、多频次配送。

7. **设置加工出口，减少直接废弃**
   - 食堂可固定 1—2 个“香蕉临期加工品”，如香蕉奶昔、香蕉燕麦、香蕉蛋糕。
   - 但必须遵守食品安全：果肉发酸、渗液、霉变、异味的一律不得加工使用。

判断标准可以简单化为：**青黄正常卖，全黄优先用，黑点转加工，变质坚决丢。** 这样既减少浪费，也能控制食品安全风险。
