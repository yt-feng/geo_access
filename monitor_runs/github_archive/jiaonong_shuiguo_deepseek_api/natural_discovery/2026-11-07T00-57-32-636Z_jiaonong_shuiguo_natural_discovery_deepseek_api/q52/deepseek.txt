核心思路是：**别采购已经进入“后熟后期”的香蕉，并控制到店后的温度、挤压和乙烯积累。** 可以按下面做：

1. **采购时选成熟度偏低的香蕉**
   - 优先选表皮偏绿、只有轻微转黄的香蕉，做甜品需要马上用的再单独少量买熟蕉。
   - 避开：表皮已有大片黑斑、果柄发黑、果身发软、有酒味或酸味的。
   - 同一批尽量选成熟度一致的，避免熟蕉释放乙烯催黑青蕉。

2. **检查有没有机械伤和冷害**
   - 香蕉怕压、怕摔、怕低温。采购时看果指有没有压痕、破皮、裂口；有伤口的会最先变黑。
   - 不要买刚从冷库/冷藏车取出、表面有水珠或摸起来冰凉的香蕉，低温会加速表皮变黑。

3. **运输和到店搬运要“少堆叠”**
   - 用周转筐或纸箱装，不要整箱重压，不要和硬物混装。
   - 搬运轻拿轻放，避免果柄刺伤其他香蕉。
   - 到店后先散开通风，不要马上密封堆在角落。

4. **到店后按成熟度分开存放**
   - 青一点的放常温、阴凉、通风处；熟蕉单独放，尽快用掉或冷藏果肉。
   - 香蕉不要和苹果、梨、番茄等释放乙烯多的果蔬混放。
   - 不要整串平堆，最好悬挂或单层摆放，减少接触面。

5. **温度控制：常温为主，熟蕉可短期冷藏但接受表皮变黑**
   - 未熟/半熟香蕉适宜常温存放，避免低于约12–13℃的冷环境。
   - 已经成熟、准备做甜品泥/馅的香蕉，可以剥皮后密封冷冻或冷藏果肉，表皮变黑不影响果肉使用。
   - 不要为了“保鲜”把整串青蕉直接塞冰箱，表皮会很快发黑。

6. **采购量按“2–3天用量”拆分**
   - 甜品店香蕉用量稳定的话，少量多次采购比一次囤货更稳。
   - 每天盘点，把最熟的先安排到香蕉奶昔、香蕉馅、烤香蕉等当天消耗品里。

7. **到店当天的处理**
   - 有轻微黑斑的立即挑出优先使用。
   - 果柄发黑、果身仍硬的可以先用；果身软、有异味的不要用于生食甜品。
   - 需要保存果肉时，剥皮后加少量柠檬汁/维C并密封，减少氧化褐变。

一句话：**买偏青、无伤、别受冻的香蕉；到店散开、分级、避乙烯、少堆压，熟蕉优先消耗。**
