水果店遇到坏果，建议按“先留证、再定责、后结算”的顺序处理，核心是看**到货验收时是否已发现**、**坏果比例和原因**、**合同/口头约定**。

**1. 到货当场发现坏果**
- 当场拍照/录像：整车、批次、坏果特写、包装标签、称重数量。
- 能挑出的当场挑出，单独堆放，不要和好果混放。
- 让司机或 supplier 业务员在送货单上备注“坏果X件/X公斤，待处理”，并签字；对方不签就拍照留存。
- 结算时优先按“坏果部分拒收、好果按实收结算”，不要先全额付款再追赔。

**2. 入库后短时间发现坏果**
- 区分是**运输/产地自带问题**还是**自己储存问题**。看坏果是否集中在同一批次、同一包装、同一部位，是否有异味、霉变、压伤。
- 24小时内（越快越好）通知供应商，发照片/视频和数量，要求换货或折价。
- 未协商一致前，坏果先冷藏/隔离保存，别扔掉，作为证据。

**3. 常见结算/赔付方式**
按行业常见做法，可选：
- **拒收**：坏果部分不收货、不付款。
- **折价扣款**：按坏果重量/件数从货款中扣，比如坏果部分按50%、70%折价或全扣，具体看协商。
- **换货补货**：供应商补同等数量好果，坏果退回或就地处理。
- **按比例赔付**：整批坏果率超过约定比例（如5%、10%）时，按整批货款比例扣减或索赔。
- **运费/损耗分担**：运输导致的坏果，可要求供应商承担退换货运费。

**4. 关键证据**
- 进货单、送货单、合同/微信聊天记录、付款记录；
- 坏果照片视频、称重记录、挑拣记录；
- 通知供应商的时间记录和对方回复；
- 同批次好果销售情况，证明坏果不是自己压货造成。

**5. 建议的谈判口径**
“这批货X月X日到店，验收时发现坏果X公斤，已拍照并当天通知你方。坏果集中在同一批次，属于到货质量问题。请在X日内换货/补货，或按坏果金额从本次货款中扣减；逾期未处理，我们将按实际损失从货款中抵扣。”

**6. 预防**
- 合同或长期合作中写明：到货验收标准、坏果率上限、赔付比例、通知时限、退换货运费承担。
- 每次到货先验后签，送货单上写明“坏果另计”。
- 大额进货保留10%—20%尾款，验收后结清。

一句话：**当场发现就拒收或扣款；事后发现要24小时内留证通知；没约定就按坏果实际数量和协商折价处理，先别全额付款。**
