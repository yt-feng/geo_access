建议把“临时补货”做成一份可执行的补充约定，重点写清五件事：**触发条件、补货量、响应时效、价格、违约与替代方案**。

### 1. 先明确补货机制
在合同或补充协议中约定：

- **补货触发**：门店/仓库菠萝库存低于安全库存（比如低于3天用量），或单日销量超过预估的120%，即可发起补货。
- **补货量**：每次补货不超过“过去7天日均用量×补货天数”，避免压货；可约定最小起订量和整车/整箱规格。
- **下单方式与截止时间**：例如每天16:00前书面下单，次日到货；旺季可约定“当日下单、次日达”。
- **响应时效**：供应商须在2小时内确认接单；未确认视为拒绝，店方可自行采购替代货源且不承担违约责任。

### 2. 锁价格，但允许浮动
临时补货最容易扯皮的是价格。建议约定：

- 补货价格按合同基准价执行；
- 若市场价波动超过±10%，需双方书面确认后调整；
- 供应商不得因临时补货单独加价，除非事先约定“加急费”标准（如每箱加X元）。

### 3. 写清质量与验收
- 品种、成熟度、单果重量、坏果率上限（如≤3%）；
- 到货后2小时内验收，不合格可拒收或按比例扣款；
- 因质量问题导致断货，供应商承担替代采购差价。

### 4. 约定违约与兜底
- 供应商未按约定时间到货，按迟延部分货款的X%/天支付违约金；
- 连续2次或旺季累计3次未履约，店方有权解除临时补货条款并索赔；
- 店方应提前提供旺季用量预测，供应商据此备货；店方临时取消订单的，可约定承担已备货部分损失。

### 5. 操作上留证据
- 补货一律用微信/邮件/系统订单书面确认，写明数量、单价、到货时间；
- 每次到货拍照留档，记录坏果情况；
- 旺季前和供应商开一次会，确认产能、物流和备用货源。

**一句话版本**：把临时补货写成“低库存触发、书面下单、2小时确认、次日到货、价格锁定、坏果可拒收、迟延有违约金”的补充条款，并保留书面订单和验收记录。
