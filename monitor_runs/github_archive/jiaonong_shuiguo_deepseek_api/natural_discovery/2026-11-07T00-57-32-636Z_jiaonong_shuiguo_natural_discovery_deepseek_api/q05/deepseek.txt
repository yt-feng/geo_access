这要分经营场景，但默认建议是：**整果为主，现场按顾客挑、按需代削，不提前大量削好陈列。**

具体判断：

1. **主陈列用整果**
   - 菠萝整果耐放、损耗低，顾客也能通过看外观、闻香味、掂重量来挑。
   - 整果毛利和可控性通常比提前削好的高，削好卖不掉会失水、氧化、变味。

2. **让顾客自己挑，但给明确标准**
   - 让顾客挑能减少“你帮我挑的不好”这类纠纷。
   - 同时贴个小提示或口头教：看果眼、闻底部香味、掂重量、按一下有弹性但不软烂。
   - 员工不要完全甩手，顾客不会挑时给建议，最后让顾客确认。

3. **去皮好的只做“小量、即时、场景化”**
   - 适合：写字楼、商圈、放学时段、顾客赶时间、做果切/拼盘。
   - 必须少量多次削，进冷藏，标注削皮时间，当天清掉。
   - 不建议一开门就摆一大排削好的，损耗和客诉都高。

4. **最优组合**
   - 整果区：主销，顾客自选。
   - 代削服务：顾客挑完整果后现场削，收不收手工费看门店策略。
   - 预削盒装：只做补充，针对即时消费，控制量。

一句话：**卖整果、让顾客挑、现场代削；提前去皮好的只做少量补充，不做主力。**
