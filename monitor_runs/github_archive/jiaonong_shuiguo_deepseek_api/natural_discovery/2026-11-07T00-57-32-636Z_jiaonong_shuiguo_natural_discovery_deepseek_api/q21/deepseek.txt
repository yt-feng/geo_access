超市采购水果时，供应商通常需要提供以下几类证明和检测报告。具体以当地市场监管要求、超市自身验收标准和水果品类为准：

**1. 主体资质证明**
- 营业执照
- 食品经营许可证（或食品生产/流通相关许可，视经营模式）
- 供货商为生产企业的，提供生产许可证；为经销商的，提供其经营许可及上游供货证明

**2. 进货凭证与来源证明**
- 进货发票、送货单、购销合同
- 产地证明或供货商出具的来源说明
- 进口水果需提供海关报关单、入境货物检验检疫证明

**3. 质量安全检测报告**
- 农药残留检测报告（最常见，通常要求有资质检测机构出具，如CMA/CNAS）
- 重金属、污染物检测报告（按风险或超市要求）
- 食品添加剂使用情况说明（水果一般较少涉及，但加工水果如蜜饯、果干需关注）

**4. 合格证明文件**
- 产品合格证或出厂检验报告（生产企业提供）
- 批次检验报告，尤其大型超市通常要求“一批一检”或按批次索取
- 食用农产品承诺达标合格证（很多地区推行，供应商可提供）

**5. 其他按品类要求的文件**
- 有机水果：有机产品认证证书
- 绿色食品：绿色食品认证证书
- 地理标志产品：相应认定文件
- 冷链水果：冷链运输温度记录
- 预包装水果：标签标识符合要求

**实操建议：**
- 首次合作时索取全套资质并留存复印件/电子档，建立供应商档案。
- 每批次进货索要对应批次的检测报告或合格证明，做到票、证、货一致。
- 对高风险品类（如叶菜类、草莓、葡萄等农残关注度高的水果）提高抽检频次或要求第三方检测。
- 以当地市场监管部门的最新要求为准，必要时让供应商提供检测机构资质证明。
