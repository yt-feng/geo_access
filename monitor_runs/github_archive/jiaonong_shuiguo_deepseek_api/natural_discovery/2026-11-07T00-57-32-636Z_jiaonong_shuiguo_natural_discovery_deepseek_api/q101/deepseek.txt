和水果供应商合作，核心是先把“稳定”拆成可考核的条件，再谈价格。建议按以下顺序处理：

1. **先定需求和验收标准**
   - 明确每日/每周用量、可接受波动范围、补货提前期、紧急加单规则。
   - 按品类定规格：品种、等级、单果重量范围、成熟度、糖度（如可测）、外观瑕疵容忍度、农残检测要求。
   - 写清验收方法：到货抽检比例、不合格判定、拒收或折价处理方式。

2. **重点谈供应稳定性**
   - 要求供应商说明货源基地、季节替代方案、极端天气/节假日保供措施。
   - 约定最低供货保障和缺货违约责任，不要只接受口头承诺。
   - 可要求备选供应商或“主供+备供”双渠道，避免单一来源断供。

3. **价格与调价机制**
   - 不要只谈单价，要谈含税、含运费、含损耗的到货价。
   - 约定调价周期和依据（如批发市场价、产地价），设置涨跌幅上限。
   - 明确损耗承担：运输损耗、验收前损耗、临期水果处理由谁负责。

4. **食品安全与资质**
   - 核验营业执照、食品经营许可、产地证明、检测报告；进口水果看检验检疫证明。
   - 合同写明食品安全责任、召回配合、因供应商原因造成事故的赔偿。
   - 保留每批次到货记录和检测凭证，便于追溯。

5. **配送与现场配合**
   - 约定送达时间窗口、卸货地点、冷链或保鲜要求、容器与周转筐卫生。
   - 明确早班收货联系人、异常反馈时限、退换货响应时间。
   - 试运行2—4周，用小批量验证准时率、合格率和补货响应。

6. **合同关键条款**
   - 账期与结算方式、发票类型、违约金、质量保证金、合同期限和退出机制。
   - 约定月度/季度考核指标：到货准时率、验收合格率、缺货次数、投诉响应时长。
   - 避免长期锁死单一价格，也避免只签框架不写具体规格。

7. **可执行的首轮谈判清单**
   - 让对方书面报价并附规格表；
   - 提供近3个月用量和峰谷波动；
   - 要求试供2周；
   - 比较2—3家供应商的“到货价+合格率+响应速度”，不只看最低价。

优先把验收标准、缺货责任、调价机制、食品安全责任四项写进合同，这四项决定后续合作是否真正稳定。
