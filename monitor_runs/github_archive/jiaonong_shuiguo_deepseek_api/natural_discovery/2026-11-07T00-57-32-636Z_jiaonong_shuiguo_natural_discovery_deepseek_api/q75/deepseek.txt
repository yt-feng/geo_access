第一次合作建议把“试单”设计成一次**低风险验证**，而不是单纯谈价格。核心是验证四件事：品质稳定性、交付可靠性、结算可控性、售后可追责。具体可以这样设计：

**1. 试单规模**
- 选 **2–3 个单品、每品 3–5 个整件/小批量**，总量控制在你能在 **2–3 天**内消化或转手的范围内。
- 单笔金额建议不超过你单店/单渠道一周进货额的 **10%–20%**，别为了压价一次性拿太多。
- 避开最易损、最难保存的品类做首单；先试常规品，成熟后再试高毛利高风险品。

**2. 品种与规格**
- 每个单品明确：品种、产地、等级、单果规格/净重、包装方式、箱规、允许损耗率。
- 要求供应商提供**同批次实拍图或视频**，并约定到货与样品/描述不符的处理方式。
- 首单不要混太多SKU，否则出问题难判断是品控还是物流。

**3. 价格与结算**
- 首单可接受略高于长期价，但必须写清**含税/不含税、是否含运费、卸货费谁承担、损耗怎么算**。
- 结算优先选**货到验收后付款**，或小额预付+尾款验收后结；避免首次合作大额全款预付。
- 明确报价有效期和调价机制，水果价格波动大，别只口头约定。

**4. 交付与验收**
- 约定发货时间、运输方式、到货时限、温控要求。
- 到货后 **2–4 小时内**完成验收：数量、规格、成熟度、破损、异味、腐烂比例，拍照留存。
- 约定验收标准：比如破损/腐烂超过 **3%–5%** 如何补货、扣款或退货；谁承担退货运费。
- 首单最好安排在你方便盯货的时间到货，别周五下午到货没人处理。

**5. 售后与责任**
- 书面确认：短装、错发、品质不达标、延迟到货的处理时限和赔付方式。
- 保留聊天记录、报价单、发货单、验收照片，作为后续追责依据。
- 明确联系人及响应时间，避免出问题找不到人。

**6. 复盘与放量条件**
- 试单结束后按维度打分：到货准时率、规格符合率、损耗率、售后响应、实际毛利。
- 只有**品质稳定、损耗可接受、售后配合**，再逐步放量；第二次订单可增加到首单的2–3倍，仍分批次验证。
- 如果首单出现规格不符或损耗超标且处理不积极，不建议直接放大合作。

一句话：首单要**小到能承受损失，严到能验证底线**；把验收标准和售后责任写在前头，比压价更重要。
