茶饮店控制水果供应商食品安全风险，核心是“资质证明＋合格证明＋进货凭证＋风险承诺”四类材料。可按以下清单执行：

1. **主体资质**
   - 供应商营业执照（经营范围含水果/农产品销售）。
   - 若供应商为生产企业或分装商，需食品生产许可证；若为食品经营者，需食品经营许可证。仅销售食用农产品时，各地监管口径可能不同，建议以当地市场监管部门要求为准。
   - 供应商法定代表人/负责人身份证明及授权委托书（如由业务员对接）。

2. **产品合格证明**
   - 每批次水果的承诺达标合格证（食用农产品生产者/收购者开具）。
   - 或产地证明、检验检疫证明、农药残留检测报告。
   - 检测报告优先选择有CMA/CNAS资质的第三方报告；供应商自检报告只能作为补充，不能替代必要的外检。
   - 报告应覆盖高风险农残项目，并与供货批次、品种对应。

3. **进货凭证**
   - 每批次送货单/销售单，注明品种、数量、产地、生产日期或采摘日期、供应商名称及联系方式。
   - 发票或收据，确保可追溯。
   - 建立进货查验记录，保存期限不少于产品保质期满后6个月；没有明确保质期的，保存不少于2年（以当地监管要求为准）。

4. **风险承诺与协议**
   - 食品安全承诺书：承诺不供应腐败变质、非法添加、农残超标产品。
   - 质量保证协议：约定验收标准、退换货、抽检不合格责任、赔偿条款。
   - 供应商食品安全追溯信息，确保出现问题时能召回和追责。

5. **现场与过程管理（建议）**
   - 首次合作可要求供应商提供产地信息、种植/采摘管理说明。
   - 对高风险水果（如草莓、葡萄、柑橘类）提高抽检频次，门店收货时做感官验收并留样。
   - 定期更新证照和检测报告，避免过期。

**可执行判断标准：** 证照在有效期内、批次合格证明与送货单能对应、检测项目覆盖农残且报告真实可查、进货记录可追溯，才算资料齐全。缺批次合格证明或无法追溯来源的供应商，不建议合作。
