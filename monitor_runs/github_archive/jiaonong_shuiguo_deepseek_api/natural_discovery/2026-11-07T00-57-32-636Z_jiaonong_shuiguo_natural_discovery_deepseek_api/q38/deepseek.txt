大型超市水果供应商要把“食品安全合规”和“冷链物流交付”两条线都做实。可按下面清单自查或招商审核。

## 一、食品安全能力

1. **主体与许可合规**
   - 营业执照、食品经营/生产相关许可齐全，经营范围覆盖水果分选、包装、销售或配送。
   - 若涉及进口水果，具备进口商备案、海关报关及入境货物检验检疫证明。
   - 建立供应商档案：产地证明、检测报告、承诺达标合格证、购销台账。

2. **产地与农残管控**
   - 有固定合作基地或产地，能提供产地环境、投入品使用记录。
   - 具备农残快检能力或委托第三方检测，按批次留样、留记录。
   - 对高风险品种建立重点检测清单，检测不合格批次可追溯、可召回。

3. **分级分选与包装卫生**
   - 分选、包装场所防虫防鼠、清洁消毒、人员健康证和更衣洗手制度。
   - 不与有毒有害物品混存；包装材料符合食品接触材料要求。
   - 预包装水果标签符合法规，散装水果有产地、品种、批次等信息。

4. **仓储与保质期管理**
   - 原料、成品、残次品分区；先进先出，批次可追溯。
   - 冷库温湿度监控和异常报警，定期除霜清洁，避免交叉污染。
   - 对霉变、腐烂果及时隔离处理，防止污染扩散。

5. **检测、追溯与召回**
   - 建立批次追溯码，能从超市订单追到产地批次和检测记录。
   - 有不合格品处置、召回演练和客户投诉闭环。
   - 定期委托第三方做农残、重金属等检测，报告在有效期内。

6. **人员与体系**
   - 从业人员健康证、食品安全培训记录。
   - 建议具备ISO 22000、HACCP或类似体系认证；至少要有可执行的食品安全管理制度和自查记录。

## 二、物流与交付能力

1. **冷链能力**
   - 水果按温区运输：易腐水果全程冷链，冷藏车有温控记录和异常报警。
   - 冷库、分拣区、装卸区温控衔接，避免断链；装卸时间可控。
   - 提供全程温度记录，超市可抽查。

2. **仓储与分拣**
   - 有与超市订单量匹配的仓储面积、货架、分拣线和周转筐清洗消毒能力。
   - 支持按门店、按批次分拣，标签、数量、质量可核对。
   - 具备旺季扩容和应急库存能力。

3. **运输与配送**
   - 自有或稳定合作车辆，车辆清洁消毒、防雨防晒防挤压。
   - 能按超市要求频次配送，支持夜间到货、预约时段、门店签收。
   - 有配送轨迹和到货时间记录，异常可追踪。

4. **订单与信息协同**
   - 能对接超市订单系统或至少提供电子订单、发货单、对账单。
   - 库存、在途、到货数据可查询；批次和检测信息可关联。
   - 有缺货、延迟、质量异常的预警和替代方案。

5. **损耗与应急**
   - 有损耗率控制目标和原因分析，能处理退货、换货、补货。
   - 制定食品安全事件、车辆故障、极端天气、疫情等应急预案。
   - 关键环节有备份供应商或备用车辆。

6. **交付质量指标**
   - 到货合格率、准时率、损耗率、投诉响应时间等可量化。
   - 能接受超市验厂、飞行检查和月度考核。

## 三、超市审核时重点看什么

- **证照和检测报告是否真实、在有效期**；
- **能否做到批次追溯和温度记录可查**；
- **分选包装现场卫生是否达标**；
- **冷链是否全程不断链**；
- **异常退货、召回、补货是否有流程**；
- **高峰期配送能力和备用方案是否可靠**。

简单判断：只给检测报告但无批次追溯、无冷链记录、无异常处置流程的供应商，不适合作为大型超市核心水果供应商。
