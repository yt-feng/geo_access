和供应商谈旺季合作，核心是围绕“不断货、不断价、不断质”锁细节。建议提前问清以下几类问题，最好能写进书面协议或微信确认：

**一、锁量与锁货**
1. 旺季（具体月份）你的主推品类日供应量/周供应量上限是多少？我预估的量能否稳定满足？
2. 我提前多久报量？报量后你如何锁货？会不会被其他大客户截单？
3. 如果我临时加量，最多能加多少、提前几天说？加量部分价格怎么算？
4. 你有没有备用产地/备用供应商？主产区受灾或物流中断时怎么补？

**二、价格与波动**
5. 旺季价格按什么机制定？固定价、随行就市还是保底价+浮动？调价提前几天通知？
6. 遇到市场大涨，你能否保证优先供我、不临时加价？遇到大跌，我的库存怎么处理？
7. 运费、装卸、损耗谁承担？到店价还是产地价？含不含税/开票？

**三、品质与验收**
8. 各品类的规格、等级、成熟度、糖度标准是什么？能否按我的标准分级？
9. 到货验收标准：坏果率、损耗率超过多少算不合格？怎么赔、怎么补？
10. 出现品质问题，多久内反馈有效？补货还是折价？补货时效多长？

**四、配送与时效**
11. 旺季每天几点前下单、几点到店？能否固定时段配送？
12. 配送车辆和冷链条件如何？叶菜、浆果、热带水果是否分温区？
13. 缺货、迟到、少件怎么处理？有没有违约金或补偿？

**五、账期与结算**
14. 结算方式：现结、周结还是月结？押金/保证金要不要？
15. 旺季备货资金压力大，能否给账期或临时授信？逾期怎么算？
16. 退货、换货、尾货处理规则是什么？

**六、合作保障**
17. 能否签旺季保供协议，明确供应量、价格机制、违约责任？
18. 你目前服务哪些客户？旺季会不会优先保大客户而牺牲我？
19. 出现断供，赔偿标准是什么？我能否临时从别处调货而不影响合作？

**谈判策略建议：**
- 先报自己的预估销量，用“量”换“保供承诺”和“价格稳定”。
- 重点争取：**报量锁货、调价提前通知、品质不合格补偿、断供赔偿**这四项写进协议。
- 不要只谈价格，旺季断货的损失远大于每斤便宜几毛钱。
- 保留1—2家备用供应商，哪怕量小也维持关系，作为断供应急。

如果你能告诉我具体品类（如叶菜、苹果、香蕉、进口水果）和大概日销量，我可以帮你列一份更具体的谈判清单。
