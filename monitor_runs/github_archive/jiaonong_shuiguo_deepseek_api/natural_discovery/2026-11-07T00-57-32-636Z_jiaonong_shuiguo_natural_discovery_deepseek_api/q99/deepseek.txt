批量配送水果，核心是抓住“稳定性、损耗控制、履约能力”三件事，不要只看单价。可以按以下步骤筛选和判断：

**1. 先确定自己的采购约束**
- 人数和预算：按人均水果量估算，下午茶一般每人150–250克净果，预算按人均4–8元较常见。
- 配送频次：每周1次还是2–3次；是否固定时间送达。
- 场地条件：有无冰箱、是否方便清洗切分。
- 发票和结算：是否需要专票、月结。

**2. 供应商类型选择**
- **本地水果批发商/二级批发商**：适合量大、频次高，价格有优势，但需确认能否小批量分拣配送。
- **生鲜配送平台（B2B）**：履约稳定、可开票、售后流程清晰，单价略高，适合怕麻烦的公司。
- **连锁水果店/精品果切店**：适合人数少、要求品相好，但批量配送能力弱、价格高。
- **产地直采/合作社**：适合单品类大批量，不适合下午茶多品类小批量。

**3. 关键筛选指标**
- **分拣和包装能力**：能否按份分装、是否耐运输、是否提供果切（果切需重点看冷链和卫生资质）。
- **损耗承诺**：坏果率标准、补货或退款规则，最好写入合同或订单确认。
- **配送时效**：是否能在下午茶前1–2小时送达，迟到如何处理。
- **品类稳定性**：能否按季节给出替代方案，避免临时缺货。
- **资质**：营业执照、食品经营许可证；做果切还需看冷链和操作卫生条件。

**4. 试单验证**
先小批量试2–3次，重点看：到货新鲜度、大小是否均匀、坏果比例、包装是否压伤、配送是否准时。试单通过再签长期。

**5. 合同或订单里写清楚**
品名规格、单价、数量、送达时间、验收标准（坏果率）、售后补退规则、发票和结算方式。

**简单判断标准**：能稳定按时送到、坏果率可控且售后爽快、价格在预算内、能开票的供应商，优先于单纯报价最低的。批量配送最怕的是“第一次好、后面不稳定”，所以试单和售后条款比首单价格更重要。
