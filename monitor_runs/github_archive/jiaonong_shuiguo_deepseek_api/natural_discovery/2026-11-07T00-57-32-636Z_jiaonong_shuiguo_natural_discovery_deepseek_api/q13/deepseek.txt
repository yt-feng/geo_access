做附近小区团购，水果供应商至少要支持下面这些服务；你可以按“必须具备、最好具备、合作前要写清楚”三层筛选。

**一、必须具备**
1. **稳定供货与固定报价**
   - 每天或隔天能稳定供应当季主推水果。
   - 能提前给团购价、起订量、规格，避免今天报低价、明天断货涨价。
   - 支持小批量多品种拼单，不能只接受大批量单品。

2. **分级与品质稳定**
   - 明确果径、甜度、成熟度、净重/毛重、包装规格。
   - 能按团购做“普通款/精品款”分级，坏果率有承诺。
   - 同批次品质稳定，避免第一批好、第二批差。

3. **坏果、缺斤少两售后**
   - 支持到货后按比例补货、退款或下次抵扣。
   - 坏果理赔有时限，比如收货2—4小时内拍照报损。
   - 明确运输损耗、自然损耗谁承担。

4. **配送与到货时效**
   - 能送到你店里或指定自提点。
   - 支持清晨到货，方便当天分拣、当天自提。
   - 临时加单、改量有截止时间和响应方式。

5. **包装与分拣支持**
   - 能按团购份量预包装，或至少提供统一规格箱装。
   - 包装结实、透气、防压，适合小区自提和短途搬运。
   - 能贴品名、规格、到货日期标签更好。

**二、最好具备**
1. **团购专供价和阶梯价**
   - 按起订量给阶梯价，卖得多成本能降。
   - 有每周爆品、尾货特价、滞销支持。

2. **预售和代发能力**
   - 你上午截单，供应商下午或次日按单配货。
   - 支持“按团购订单分装”，减少你店里二次分拣压力。

3. **售后响应快**
   - 有专门对接人，微信/电话能及时处理。
   - 坏果不扯皮，能快速补损。

4. **退换和临期处理**
   - 未拆封、未售完的耐储水果能否调换。
   - 临期果是否有折价处理方案，避免你全损。

5. **票据与合规**
   - 能提供送货单、对账单、收款凭证。
   - 涉及食品安全，最好有营业执照、产地/检测信息可查。

**三、合作前必须写清楚**
- 报价是否含运费、包装费、卸货费。
- 起订量、混拼规则、截单时间、送达时间。
- 坏果理赔比例、拍照时限、补货还是退款。
- 价格有效期和涨跌通知时间。
- 缺货替代规则：能不能换同价品种，需不需要你确认。
- 结算方式：现结、周结、月结，押金或账期。

**给你的实操建议**
先别签长期大单，用**2—3家供应商小批量试跑2周**，重点看：到货准点率、坏果率、售后响应、分拣是否省事。团购水果最关键不是进货价最低，而是**品质稳定+坏果有人赔+到货准时**。供应商能满足这三点，再谈阶梯价和账期。
