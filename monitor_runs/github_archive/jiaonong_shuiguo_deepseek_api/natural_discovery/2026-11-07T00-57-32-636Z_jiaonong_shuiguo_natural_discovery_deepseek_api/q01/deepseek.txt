判断水果供应商靠不靠谱，核心不是听他说得多好，而是用小批量、可验证的方式试出稳定性。给你一套直接能用的判断方法：

**1. 先看“稳定供货能力”，不是看价格低**
- 问他香蕉主要来自哪里、菠萝主要来自哪里，是否常年有货，换季时怎么替代。
- 让他明确：每周能稳定给你多少箱/件，最少起订量多少，临时加单提前多久说。
- 靠谱的供应商会主动说自己的短板，比如“雨季菠萝品质波动大，我会提前告诉你”；不靠谱的通常只说“都没问题”。

**2. 用三次小批量试单验证**
不要一上来长期合作。分三次进货：
- 第一次：少量试品质和准时率；
- 第二次：故意稍微加量，看是否还能按时按质；
- 第三次：临时改一次订单或问一次售后，看他反应。
重点记录：到货时间误差、缺斤少两、坏果率、大小是否均匀、催熟是否一致。

**3. 香蕉重点看催熟和到货状态**
- 香蕉不能只看外观黄不黄，要看他给你的货是“生蕉”还是“催熟蕉”，催熟程度是否适合你几天内卖完。
- 问清楚：到你店里时大概几成熟、你还能放几天、不同季节催熟时间怎么调。
- 试单时切开看：果肉是否发软、芯是否发黑、有没有“青熟”或“过熟”混装。
- 靠谱供应商会根据你的销量建议进货成熟度，而不是一味推大货。

**4. 菠萝重点看成熟度、损耗和品种一致性**
- 问清楚品种、产地、单果重量范围、成熟度标准。
- 到货后抽查：底部有没有腐烂、果眼是否正常、有没有异味、切开是否黑心。
- 看他一箱里大小是否均匀、成熟度是否一致。混装严重说明分级不认真。
- 菠萝损耗高，靠谱供应商要能明确售后标准，比如坏果怎么赔、拍照后多久处理。

**5. 看售后规则是否清楚**
合作前直接问：
- 坏果率超过多少可以赔？怎么赔？是补货还是扣款？
- 到货后发现质量问题，几小时内反馈有效？
- 缺货、迟到、临时涨价怎么处理？
能把这些说清楚并愿意写进订单/聊天记录的，通常更靠谱。只说“放心，有问题找我”但不给标准的，要谨慎。

**6. 看价格是否“异常低”**
长期进货不要只追求最低价。明显低于市场价的香蕉和菠萝，常见问题是：成熟度不适合你、混级、损耗转嫁、缺斤少两、临时断供。算账时要算“到手可卖成本”，不是只算进货价：
- 进货价 + 损耗 + 坏果 + 人工挑选 = 真实成本。
让供应商报“可卖率”或你试单后自己算，比单纯比价可靠。

**7. 观察几个细节**
- 是否愿意让你去他仓库/档口看货；
- 送货司机是否固定、是否熟悉你的收货要求；
- 是否主动提醒你天气、产地、节假日对价格和品质的影响；
- 结款方式是否合理，是否一上来就要求大额预付。

**建议你的落地做法：**
先选2家供应商，各做2—3次小批量试单，用同一套表格记录：到货时间、数量、坏果率、可卖率、售后响应、价格波动。连续试1—2周后，把70%的常规量给最稳定的一家，30%留给备用供应商。香蕉和菠萝都不适合只靠一家，尤其香蕉催熟和菠萝季节波动大，保留备用渠道比压价更重要。

一句话：**靠谱供应商不是价格最低的，而是品质稳定、规则清楚、出问题能按约定处理、你能提前判断风险的那家。**
