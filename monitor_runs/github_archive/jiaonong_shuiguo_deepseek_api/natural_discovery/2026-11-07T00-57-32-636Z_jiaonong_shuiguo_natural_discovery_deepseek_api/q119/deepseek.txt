水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格”和“有没有货”，而是下面这些会慢慢侵蚀利润和口碑的细节：

1. **同一规格的稳定性，而不是单次样品好坏**
   只看一次样品很容易被“精品货”误导。要看他连续几批同规格果的个头、糖度、成熟度、色泽是否稳定。长期生意最怕这批好、下批差。

2. **成熟度和货架期的匹配**
   供应商说“熟得好”不一定是好事。要问清楚：采摘成熟度、到货后还能放几天、适合当天卖还是可周转几天。不同渠道（商超、水果店、社区团购、电商）对货架期要求完全不同。

3. **损耗责任和售后边界**
   最容易忽视的是：烂果、压伤、规格不符、到货晚导致变质，算谁的？要提前明确赔付比例、补货方式、拍照取证时限、是否含运费。没有书面规则，长期合作一定扯皮。

4. **包装和运输细节**
   箱规是否统一、内衬是否到位、码垛方式、冷链是否连续、卸货是否粗暴。很多损耗不是果子本身差，而是包装和运输把利润吃掉了。

5. **产地和季节切换能力**
   长期稳定不能只靠一个产地或一个单品。要看他有没有多产地 backup、换季时能不能平滑切换规格和价格。只靠单一货源的供应商，旺季还行，淡季容易断供或乱报价。

6. **报价是否含隐性成本**
   问清楚是否含税、含运费、含卸货、含包装、是否有起订量、账期条件。低价往往藏在“不含运费”“不包售后”“现款现货”里。

7. **分级标准和验收口径**
   “大果”“中果”到底按重量、直径还是目测？糖度是否有抽检？次果比例怎么算？最好有可执行的验收表，而不是靠感觉。

8. **供应能力和履约记录**
   不要只听他说“每天能发几车”。要看他高峰期是否优先保你、是否经常临时涨价、是否准时到货。可以要求看近期发货记录或向同行侧面了解。

9. **账期和资金占用**
   长期合作中，账期比单价更影响现金流。要明确结算周期、对账方式、逾期规则。过度依赖赊销的供应商，往往会在质量或价格上找补。

10. **是否愿意做小批量试单和问题复盘**
    靠谱的供应商愿意先小批量试合作，出问题能一起复盘。只会催大单、不愿处理售后的，长期风险高。

实操建议：先做 **2—3 家供应商并行试单**，连续跟踪 3—5 批货，记录到货损耗率、规格合格率、准时率、售后响应速度，再决定主供和备供。长期稳定靠的是“可验证的稳定性”，不是一次低价。
