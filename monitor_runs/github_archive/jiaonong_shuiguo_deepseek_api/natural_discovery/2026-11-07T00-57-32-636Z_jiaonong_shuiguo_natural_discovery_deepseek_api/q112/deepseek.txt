坏果率没有全国统一法定阈值，主要看合同约定和行业惯例。实务建议：

1. **合同里最好明确“允收标准+赔付触发线”**
   - 常见做法：坏果率≤3%视为正常损耗，不赔付；超过3%启动扣款或换货；超过5%可拒收或要求整批折价；超过10%可解除合同并索赔。
   - 易腐水果（草莓、荔枝、杨梅等）可适当放宽到5%允收；耐储水果（苹果、橙子等）可收紧到2%—3%。

2. **赔付计算要写清楚**
   - 建议按“超出允收部分的坏果比例×该批货款”扣减，而不是一旦超标就全批拒付。
   - 示例：允收3%，实际坏果率8%，则扣款比例=（8%-3%）×货款，或按合同约定的固定倍数赔付。

3. **验收时点很关键**
   - 写明到货后多少小时内完成抽检、抽检比例、取样方法、拍照留证和双方签字确认流程。
   - 超过约定验收期未提出异议，通常视为验收合格，后续难索赔。

4. **没有合同约定时**
   - 可参考双方交易习惯或行业标准，但举证难度较大。建议至少保留到货照片、抽检记录、聊天记录和第三方检测报告。

**结论：** 合同里建议把“3%作为允收线、5%作为拒收/折价线、10%作为解约索赔线”写清楚，并按超出部分比例赔付；具体阈值可根据水果品类和运输距离调整。
