结论先说：**默认以整果为主，切果作为补充；如果门店客流以即时消费、单身/小家庭、办公商圈为主，则提高切果占比。** 不要只选一种，关键看门店客群和损耗管理能力。

**一、更适合卖整果的情况**
- 社区店、家庭客群多：整果单价低、可存放，顾客更愿意买回家自己处理。
- 门店没有冷藏展示柜或切果操作间、人手有限：整果损耗和食品安全风险更低。
- 菠萝产季价格低时：整果走量快，适合做堆头促销。
- 采购建议：选成熟度略低、耐存放的果，按大小分级，整果做引流价。

**二、更适合卖切果的情况**
- 商圈店、写字楼店、学校/医院周边：顾客要即时吃、怕麻烦。
- 门店有冷藏陈列和规范切配条件：可做菠萝块、菠萝片、小份装。
- 小家庭、单身客群多：整果吃不完，切果复购更高。
- 关键前提：切果必须冷链陈列、当日清货，毛利要覆盖损耗和人工。

**三、建议的组合方式**
1. **整果做引流**：选1—2个规格，低价堆头，满足家庭采购。
2. **切果做利润和便利**：小盒装、组合水果盒，放在收银台或冷柜端头。
3. **按时间段调整**：上午整果多备，下午和晚间切果占比提高。
4. **看数据再定比例**：连续观察2—4周，记录整果销量、切果销量、损耗率和毛利额，切果损耗率明显高于整果且毛利覆盖不了，就收缩切果。

**四、采购判断标准**
- 整果采购：看耐储性、分级、到货成熟度，适合走量。
- 切果采购：要成熟度适中、果形规整、出肉率高的果，别用快过熟果切配，否则口感差、损耗高。
- 先小批量试销：切果先每天少量上架，卖完再切，避免一次性切太多。

**一句话：社区家庭店以整果为主、切果试水；商圈便利型门店整果引流、切果提毛利；没有冷链和人手就不要大规模上切果。**
