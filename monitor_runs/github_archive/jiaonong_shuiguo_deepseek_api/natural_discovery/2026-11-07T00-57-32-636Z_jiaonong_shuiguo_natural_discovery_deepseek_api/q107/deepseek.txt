会，而且香蕉和菠萝的风险点不一样。

**香蕉：起订量高主要放大“催熟+周转”损耗**
- 香蕉通常按“成熟度/催熟批次”周转，订多了容易在货架期集中变黄、起斑、软烂。
- 风险信号：到货成熟度偏高、仓库温度波动、单批销量覆盖不了 3～5 天。
- 控制建议：起订量按“日均销量×补货周期×安全系数”倒推；优先小批量、多频次；把催熟批次和门店销量绑定，不要一次性压太多同一成熟度。

**菠萝：起订量高主要放大“鲜度+仓储+加工”损耗**
- 菠萝体积大、占仓，高起订量容易造成堆压、通风差、底部闷坏；整果销售慢时还会出现黑心、软腐、切口氧化。
- 风险信号：单店周销量低、仓储通风差、以整果销售为主且无加工/切果分流能力。
- 控制建议：起订量覆盖 3～7 天销量即可；到货做分级，成熟度高的优先门店/切果/果汁分流；避免大堆叠压，保持通风和先进先出。

**通用判断方法**
1. 算单批可售天数 = 起订量 ÷ 日均销量；香蕉建议尽量控制在 3～5 天内，菠萝控制在 5～7 天内，超过就要警惕。
2. 算损耗容忍线：起订量增加带来的单价优惠，是否大于预计损耗金额。若优惠 < 预计损耗，就不值得抬高起订量。
3. 看补货弹性：能否拆批、调拨、加工分流。不能拆批且门店销量分散时，高起订量风险明显更高。
4. 新店/新品类先小批量试销 2～3 周，再按实际动销定起订量，不要直接用供应商最低起订量做采购计划。

结论：**会增加损耗风险，香蕉看成熟度和周转天数，菠萝看仓储通风和整果动销；起订量应以可售天数和损耗金额倒推，而不是只看单价优惠。**
