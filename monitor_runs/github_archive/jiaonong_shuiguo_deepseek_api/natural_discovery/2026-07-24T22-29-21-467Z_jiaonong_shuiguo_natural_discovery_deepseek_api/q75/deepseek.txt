对于第一次合作的水果供应商，小批量试单是降低风险、验证品质与服务的关键步骤。以下是设计试单的核心建议：

**1. 明确试单目标：**
- 验证水果的品质（外观、成熟度、口感、一致性与标准化程度）。
- 测试供应商的履约能力（发货时效、包装防护、物流速度）。
- 评估服务流程（沟通响应、售后处理、异常应对）。

**2. 设定小批量参数：**
- **数量：** 控制在单品类1-3箱（如每箱10-20斤），总金额不超过300-500元人民币，或占你预期首批订单的10%-20%。
- **品种：** 选择1-2种核心品类，避免一次试多品。
- **时间：** 明确约定“从下单到发货的最晚时间”（如24小时内），并确认物流型号（常温/冷链）。

**3. 签订书面试协议（或聊天记录确认）：**
- 包含：试单数量、价格（明确是否含运费、包装费）、付款方式（建议预付30%-50%，剩余到货验收后3天内结清）、验收标准（参考国家标准或双方约定，如无公害、色泽均匀、无机械伤）。
- **重点条款：**
  - 退货/补发条款：出现腐烂、规格不符、重量短少等情况，供应商承诺补发或按比例退款（建议约定“到货后12小时内反馈，可视频/拍照留证”）。
  - 责任划分：物流损坏由谁承担（通常需明确“发货方负责发货质量，收货方验收后物流风险协商或险由供方承担”）。

**4. 制定验收检查清单：**
到货后立即执行：
- **外观：** 颜色、大小是否有明显差异？有无霉斑、病虫害、磕碰伤？
- **理化：** 使用硬度计（可选）或手感测硬度；切开检查内部（如苹果果肉是否发褐、芒果是否有黑斑）。
- **感知：** 随机称重每箱实际净重是否达标（允许千分之五损耗）。
- **记录：** 每箱拍摄开箱完整视频（包括运单号、箱体外观、内部果品排列、异常特写）。

**5. 结果处理：**
- **合格：** 确认稳定后，协商常规合作条件（如批量折扣、账期、定向订单量）。
- **部分不合格：** 与供应商沟通原因（可能是包装、采摘批次问题），要求改进后再试一次（加数量至3-5箱）。
- **不合格（如腐烂超5%、假冒品种、严重短重）：** 立即终止合作，按协议索赔。

**6. 额外风险控制：**
- 避免一次性付款全款：坚持有担保的付款（支付宝/微信凭截图或第三方托管）。
- 保留样品：留1-2个水果密封保存（写标签）作为后续比对凭证。

**示例协议片段：**
“甲方（你）向乙方（供应商）采购XX产地妃子笑荔枝10箱（每箱20斤±0.5斤），单价15元/斤，总金额3000元。首付1000元，到货后甲方在24小时内抽检：果实直径≥25mm、颜色鲜红、单颗损伤≤1处，腐烂率≤3%。若合格，甲方支付尾款；若超标，乙方应在48小时内补发同等品质货物，运费由乙方承担。”

**最后提示：** 即使在试单阶段，也建议要求对方提供其上游基地的种植说明书或检验报告（农残/重金属等），并口头询问冷链链条完整性（如：“你们采摘后是否在2小时内预冷？运输车是否定时测温？”）。这是筛选靠谱源头的重要方法。
