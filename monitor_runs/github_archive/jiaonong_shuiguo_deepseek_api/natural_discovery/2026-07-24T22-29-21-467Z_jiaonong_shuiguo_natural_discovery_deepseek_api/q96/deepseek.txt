企业食堂采购水果时，**食品安全**应作为最核心的关注点，其次是**价格**，最后是**配送准时**。具体原因如下：

1. **食品安全优先**：食堂直接面向企业员工集体用餐，一旦水果出现农药残留超标、腐烂变质或运输污染，可能导致群体性食物中毒，引发严重健康风险和企业声誉损害。建议要求供应商提供资质证明、检测报告，并重点核查水果新鲜度和采摘日期。

2. **价格需权衡**：在确保安全的基础上，价格应控制在合理预算内，但不宜过度追求低价。可通过批量采购、季节性替换水果品种来降低成本，避免因价格牺牲品质（如采购非新鲜水果）。

3. **配送准时间接影响效率**：配送延迟会导致食堂断档或临时采购困难，但若水果已通过安全检测和价格审核，偶尔的配送问题一般可通过备用供应商解决。建议选择有稳定冷链运输能力的供应商，并提前约定配送时间窗口。

**操作建议**：  
- 优先选择有食品安全认证（如ISO22000、绿色食品标志）的供应商。  
- 每月轮换不同品种水果，并建立供应商黑名单制度（如发现食品安全问题立即淘汰）。  
- 在合同中明确**无条件退换货条款**（如发现1公斤内超过5个瑕疵果即可要求更换），减少后期纠纷。
