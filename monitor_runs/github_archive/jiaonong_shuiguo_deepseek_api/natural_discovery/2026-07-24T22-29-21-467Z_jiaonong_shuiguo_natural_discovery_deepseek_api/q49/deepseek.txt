针对茶饮店旺季菠萝用量突增的情况，与供应商临时补货时，建议按以下步骤操作，避免断货或成本过高：

1. **立即沟通确认**：先电话或微信联系供应商，说明“旺季临时补货，需紧急追加XXX斤菠萝（明确数量）”，并确认对方当前库存是否充足、能否在X小时内送达（例如24小时内）。

2. **明确价格条款**：临时补货可能涉及旺季溢价或运费调整。需问清：
   - “这批补货单价是否按原合同执行？还是有临时加价？”
   - “如果加价，加幅是多少？能否控制在5%以内？”
   - 建议约定“若单次补货量超过XX斤，则按原价结算”。

3. **约定交付细节**：
   - 交货时间：具体到“X月X日X点前送达”或“下单后X小时内”。
   - 验收标准：如“果肉橙黄、无黑斑、无机械伤，单果重量不低于XXX克”。
   - 次品处理：约定“不合格品当场拒收或按比例折价（如损坏率超5%则补货）”。

4. **书面确认**：要求供应商提供补充协议或合同文字（微信聊天记录也可作为凭证），包含：临时补货单、数量、单价、总金额、最晚送达时间、验收方式。

5. **风险预案**：如果供应商无法满足，提前联系1-2个备用供应商（如当地水果批发市场、线上生鲜平台），并告知主供应商“如超时未到货，将启用备用渠道，后续合作可能调整优先级”。

**示例沟通话术**（可直接使用）：
> “王总，我店菠萝用量进入旺季，现在需要紧急追加XXX斤，按原合同价X元/斤结算，请在明天下午3点前送到店。如果能做到，我们会在本周内补签一个临时补充单；如果做不到，请立刻告知，我找其他渠道补货，后续旺季订单会优先给能及时供货的合作方。”

**最后提醒**：旺季期间建议提前3天预判用量，与供应商约定“旺季优先供给量”和“每周补货上限”，避免每次临时补货措手不及。
