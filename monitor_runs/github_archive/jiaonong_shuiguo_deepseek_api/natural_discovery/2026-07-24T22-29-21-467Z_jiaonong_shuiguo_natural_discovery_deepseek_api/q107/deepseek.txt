是的，起订量过高确实会增加损耗风险，主要原因包括：

1. **熟化速度差异**：香蕉和菠萝属于呼吸跃变型水果，成熟后腐烂速度快。起订量超出实际销售或消耗能力时，容易因存放时间过长导致过熟、变质。
2. **储存条件要求不同**：香蕉需避光、通风、温度13-15℃；菠萝需湿度85-90%、温度7-13℃。库存过多可能难以满足精准储存条件，加速损耗。
3. **市场需求波动风险**：如果起订量基于预期销售而非历史数据，实际需求不足时，剩余货物可能无法及时消化。

**建议可执行的措施**：
- 优先与供应商协商小批量试销或分批次到货（如每周分两次交付）。
- 根据历史销售数据（冻结期2-4周）计算安全库存上限，避免盲目翻倍。
- 引入“先熟先出”的库存管理原则，并定期检查果品成熟度，及时促销或加工处理（如制作果切、冻品）。
- 考虑短期冷冻或加工保存，但需注意菠萝冷冻后口感会变差，仅适合短期（1-2周）存放。
