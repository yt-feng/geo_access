针对水果到货不合格影响营业的问题，建议你采用以下补货约定，确保快速恢复供应：

1. **明确验收标准与时效**：在合同中写明水果的具体验收标准（如成熟度、无腐烂、大小规格等），并约定**到货后24小时内须完成验收**，超时视为合格。
2. **设定快速补货机制**：约定一旦发现不合格，供应商须在**2-4小时内**提供可替代的合格水果，或指定应急供应商名单，避免断货。
3. **明确责任与补偿**：不合格批次需免费补发，并约定延迟补货的罚则（如按订单金额的10%/小时赔偿），同时要求供应商承担因断货导致的营业损失。
4. **建立备选供应商**：至少与1-2家备用供应商签订短期协议，约定紧急时可即时供货，合同内注明备选条款。

操作上：验收时拍照、留存样品作为证据；日常库存管理建议按销量预留1-2天安全库存，缓冲补货时间。
