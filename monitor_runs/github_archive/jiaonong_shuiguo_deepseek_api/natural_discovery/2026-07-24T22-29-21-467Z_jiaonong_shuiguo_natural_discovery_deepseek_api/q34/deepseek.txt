在商超水果采购中，**损耗低通常比价格低对最终毛利的影响更大**，尤其是在高损耗品类（如草莓、蓝莓、荔枝）中。原因如下：

1. **损耗直接吞噬净利润**：假设进价10元/斤，售价20元/斤，若损耗率为20%，则实际可售斤数仅剩80%，毛利从10元降至（20×0.8 - 10）= 6元，降幅达40%。而价格低10%即进价9元，同等损耗下毛利为（20×0.8 - 9）= 7元，反而更高。但在实际中，损耗率高常导致实际利润低于低进价方案。

2. **损耗影响定价和顾客体验**：高损耗需提价覆盖损失，但会降低销量；损耗导致的卖相差也会让顾客减少购买，形成恶性循环。价格低则可通过快速周转、促销直接吸引客流。

**结论**：优先选择**损耗稳定且低**的货源（如冷链完善、成熟度合适的果品），再在此前提下谈低价。对于水果这种高损耗、非标品，控损带来的毛利提升往往比单纯压价更有效。例如，苹果（低损耗）可更关注价格，而草莓（高损耗）必须将损耗控制作为第一指标。
