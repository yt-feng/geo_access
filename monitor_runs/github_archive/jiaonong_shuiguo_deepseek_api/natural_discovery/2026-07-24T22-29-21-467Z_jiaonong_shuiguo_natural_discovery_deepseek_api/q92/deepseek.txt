针对便利店面积小、水果损耗高的问题，建议从**品类精简、周转加速、管控细节**三个核心方向入手：

1. **品类选择：聚焦高频、耐储存、高毛利**
   - **必选品**：香蕉（走量快、损耗波动可控）、苹果/梨（耐放、四季稳定）、应季水果（如夏季西瓜切块、冬季砂糖橘）。
   - **慎选品**：草莓、蓝莓等易压坏/货架期短的高成本水果，可做**切盒/拼盘**（提毛利、降外观损耗）。
   - **避开品**：榴莲、整箱进口提子（占用面积大、库存周转慢）。

2. **陈列与补货：小批量、多频次**
   - 面积有限时，**减少平铺展示**，用**斜口篮+分层架**竖放水果（如菠萝、哈密瓜），视觉不凌乱且不易挤压。
   - 每类水果单次上架量不超过**2-3层**（按当日预估销量），**上午补货1次、下午高峰前补1次**，避免一次性堆满导致底部腐烂。

3. **损耗控制：动态出清与加工转化**
   - **动态定价工具**：每天固定时段（如晚7点）对成熟度高的水果打折（例：香蕉8折→6折→买一送一），**当日清空易腐品**。
   - **二次加工**：轻微压伤、磕碰的硬质水果（如苹果）切边分装为**果切盒**（价格按原价60%），软质水果（如芒果）可制成果昔或冰沙。

4. **库存与进货：以销定采**
   - 记录连续**3周**的日销量，按**当日分时销量曲线**（如：早6-8点顾客买香蕉带走，午间买切盒，晚高峰买西瓜）调整次日进货量。
   - 首次尝试新品种时，**先拿货5kg试销**（无论原厂装多大），比如如果原箱12kg，就与批发商协商拆零或与同行拼单。

5. **时间轴管理：重点时段巡检**
   - **早8点** 检查前晚存放状态，**中午12点** 翻动易压坏水果（如葡萄），**晚6点** 统计滞销品准备打折。
   - 硬性要求：**每2小时检查一次 “有伤口”的水果**（如碰伤的芒果）立即挑出，避免传染腐烂。

**总结表格：**

| 品类 | 建议操作 | 核心风险 |
|------|----------|----------|
| 香蕉 | 单串反放（减少压痕）；当天到货当天卖完 | 不能冷藏，需每日进货 |
| 苹果/梨 | 维持4-6种常规品牌；整箱存放于通风处 | 小心低温产生的冷害（发糠） |
| 葡萄/草莓 | 只做“杯装现切”；退货时可能被批发商拒绝 | 极短货架期（约1天） |
| 芒果/牛油果 | 只进半熟果，店内自然催熟 | 必须专人每日手捏检查硬度 |

**最后建议**：订购“水果周转箱”（带托盘的塑料筐），可减少搬运过程中的60%物理损伤。每日只进**3-5个水果品类**，比多品类的损耗率低约30%。
