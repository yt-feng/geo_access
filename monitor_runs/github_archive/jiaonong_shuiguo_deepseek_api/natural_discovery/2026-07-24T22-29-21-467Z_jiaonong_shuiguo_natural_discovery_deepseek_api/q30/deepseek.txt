当超市水果到货后发现品相不好时，建议按以下步骤约定售后流程，确保责任清晰、处理高效：

1. **验收与确认**  
   - 收货时立即开箱检查，对品相不佳的水果拍照或录像（细节需清晰，如腐烂、磕碰、变色等）。  
   - 在收货单或电子系统中标注“部分品相不合格”，并保留原始包装及运单。

2. **责任界定**  
   - 明确是运输途中问题（如挤压、温度异常），还是供应商源头质量问题。  
   - 运输问题：立即联系物流方，要求出具《运输异常证明》。  
   - 源头问题：保存证据后通知供应商，要求书面确认或通过系统提交。

3. **约定处理方式（按优先级）**  
   - **退换货**：品相严重影响销售（如腐烂超过10%），要求供应商免费补发或按比例退款。  
   - **折扣索赔**：轻微品相问题（如局部疤痕），协商按原价80%~90%结算。  
   - **抵扣未来订单**：与供应商约定，从下一批货款中扣除损失金额。

4. **时间限制**  
   - 收货后24小时内提交问题清单及证据，逾期视为默认通过验收。  
   - 供应商需在48小时内给出书面答复并提供处理方案。

5. **合同条款补充**  
   - 在采购合同中加入“品相标准附件”，列出具体允许瑕疵范围（如直径<2cm的疤痕不超过单果面积5%）。  
   - 明确售后处理的违约金比例（如未及时处理需按货款10%赔偿）。

6. **沟通与升级**  
   - 先通过微信/邮件与供应商对接人沟通，保留聊天记录。  
   - 若3天内无回应，升级至供应商管理层或启动合同中的仲裁条款。

**执行建议**：立即建立《到货品相检查记录表》，包括日期、品种、不合格比例、照片编号、处理状态，定期分析高风险供应商并调整采购策略。
