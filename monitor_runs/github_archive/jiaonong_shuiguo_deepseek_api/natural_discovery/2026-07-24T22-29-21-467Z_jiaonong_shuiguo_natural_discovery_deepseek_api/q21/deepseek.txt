在超市采购水果时，供应商通常需要提供以下检测报告或进货证明，以确保食品安全和合规性：

1. **农产品质量安全检测报告**：证明水果符合国家或地方规定的农药残留、重金属等安全标准，通常由第三方检测机构出具。
2. **产地证明或产地检疫合格证明**：如来自特定产区（如有机、绿色食品基地），需提供产地证书或检疫证明。
3. **进货发票或购销凭证**：证明水果来源合法、可追溯，包括供应商名称、日期、品种、数量等信息。
4. **无公害、绿色食品或有机认证证书**（如适用）：若水果标称此类认证，需提供有效的认证文件。
5. **进口水果的检验检疫证明**：如为进口水果，需提供海关出具的入境货物检验检疫证明。
6. **其他可能需要的证明**：如水果的保质期、包装标识合规证明（如产地、生产日期、保质期等）。

建议与供应商签订合同时明确要求提供上述文件，并定期核实其有效性。若批量采购，可要求供应商提供最近批次的检测报告。
