水果店遇到坏果时，与供应商结算或赔付的方式通常依据双方的合作协议、采购合同或行业惯例。以下是一般流程和建议：

1. **确认责任归属**：首先要明确坏果是运输过程、储存不当还是自然变质导致。如果是供应商发货前已存在质量问题（如虫蛀、腐烂、过度成熟），通常由供应商负责；如果问题出在店铺存放或运输，则可能需要自己承担。

2. **及时沟通并保留证据**：发现坏果后，立即拍照或录像（清晰显示坏果、包装、批次、数量），并联系供应商说明情况。最好有书面记录（如微信、邮件或聊天记录）。

3. **参考常见结算方式**：
   - **按比例扣除**：如果坏果占比明确（如一箱中10%坏了），通常按售价或成本价从货款中直接扣除，例如一箱水果进价100元，坏了10个（假设一箱20个），则扣除50元。
   - **退换货**：供应商同意后，将坏果退回或由对方补发同等数量好果，运费由责任方承担。
   - **价格折让**：供应商同意按实际好果数量结算，或给予折扣（如坏果部分免单）。
   - **按合同条款**：如果有采购合同，按约定的坏果率、赔付比例或“包退包换”条款处理。例如合同约定“坏果率超过5%才赔付”，则低于5%可能不赔。

4. **常见行业惯例**：
   - 生鲜水果中，常见“30天内坏果包赔”或“到货24小时内反馈”的约定。
   - 如果供应商是长期合作，往往更灵活，可能直接减免坏果金额或下次补货。
   - 对于批发商或大型供应商，可能按坏果重量/数量比例结算。

5. **若无法协商**：可以要求供应商提供发货时的质量证明（如检疫单、发货记录），或向批发市场管理方、行业协会投诉调解。若金额较大，可考虑法律途径（但通常水果纠纷金额小，不经济）。

**建议**：在初次合作时，明确在合同或订单备注中写清“坏果赔付规则”，比如“坏果率5%以内由买方承担，超过5%由卖方按售价（或进价）赔付”。平时保存好采购凭证、沟通记录，便于快速处理。
