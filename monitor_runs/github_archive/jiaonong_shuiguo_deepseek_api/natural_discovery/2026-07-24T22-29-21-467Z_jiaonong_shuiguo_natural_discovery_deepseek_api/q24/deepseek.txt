建议您向供应商索要以下关键资料，以确保水果的农药残留符合安全标准：

1. **第三方检测报告**：要求供应商提供最近批次水果的农残检测合格报告。报告需由国家认可的检测机构（如SGS、华测、中检等）出具，并明确标注检测项目（如有机磷、拟除虫菊酯等常见农残）和未超标结论。

2. **产地证明及批次信息**：包含具体产地（果园/区域）、采摘日期、批次号的文件。这有助于追溯问题源头。

3. **承诺函/保证书**：供应商签字盖章的正式文件，承诺其供应的水果符合国家《食品安全国家标准 食品中农药最大残留限量》（GB 2763）要求，并承担违约赔偿责任。

4. **相关的资质证书**：供应商的营业执照、食品经营许可证（若涉及预包装）、以及《食用农产品合格证》等。

5. **质量体系认证**：如供应商持有GAP（良好农业规范）、有机认证等，可索取复印件，表明其有更严格的农残控制体系。

**建议步骤**：
- 每次新批次到货前，要求供应商提供对应批次的检测报告。
- 可自行快速抽检（如使用农残速测卡），作为验收辅助手段。
- 保留所有资料至少2年，备查。
