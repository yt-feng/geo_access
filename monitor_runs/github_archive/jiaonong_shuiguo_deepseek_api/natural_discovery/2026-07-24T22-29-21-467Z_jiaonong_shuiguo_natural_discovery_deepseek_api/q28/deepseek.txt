建议先从**香蕉**开始。原因如下：

1. **市场接受度高**：香蕉是进口水果中销量最大、消费者最熟悉的品种，几乎不需要教育市场，购买风险低。
2. **供应链稳定**：进口香蕉（如菲律宾、厄瓜多尔产）的冷链运输技术成熟，保质期相对较长，损耗可控。
3. **入门门槛低**：香蕉对仓储温控要求（13-14℃）和销售速度要求比菠萝、苹果更友好，适合新手试水。
4. **延伸性强**：稳定后可以自然过渡到其他热带水果。

**可执行步骤**：
- 联系当地大型批发市场或直接对接进口商，小批量采购（如1-2箱）试销。
- 注意颜色控制：到货时7-8分熟（青绿色），在店内存放至变黄售卖，避免过熟损耗。
- 定价比国产香蕉高20%-30%，突出“进口香蕉口感更甜糯”的卖点。

**补充说明**：如果超市已有国产香蕉销售，可从菠萝（如菲律宾金菠萝）入手，因为菠萝视觉冲击力强、单位利润高，但需要更强的控温和切块服务能力。苹果作为最后选项，因为国产优质苹果已很强，进口苹果（如美国嘎啦、新西兰爱妃）通常需要高客单价和特定消费群支撑。
