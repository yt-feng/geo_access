商超供应商配合会员日水果活动的准备，核心在于**库存、品质、定价、陈列、人员与应急**。以下是具体建议：

1. **预估需求与提前备货**  
   - 根据过往会员日数据、季节、天气及活动周期，提前3-5天与商超确认活动品种（如当季爆款、易损耗品需控量）。  
   - 建议备货量为常规销售的120%-150%，但避免过度压货；对高损耗品类（如草莓、蓝莓）建议按“分批到货”策略。

2. **品质把控与保鲜处理**  
   - 提前1天完成分拣，剔除次果、烂果，确保出货品相统一（例：苹果直径误差≤5mm）。  
   - 采用冷链运输（温度控制在0-4℃），到店后第一时间进行预冷或冷藏，并对易腐水果（如荔枝、芒果）增加冰袋或气调包装。

3. **价格与活动方案确认**  
   - 与商超协商定价策略：是否采用“会员专享价”“满减”“买一送一”等形式，明确供应商承担的成本比例。  
   - 提前准备特价商品库存（如限量秒杀品），并安排促销道具（如价签、跳跳卡、堆头围板）。

4. **陈列与包装方案**  
   - 配合商超设计堆头或端架位置：突出量感（如整箱堆放）、色彩搭配（如红黄绿分层）。  
   - 备足散装、预包装（如切盒、果篮）及试吃装（建议试吃品为活动量的5%）。  
   - 提供展示道具：如价格标签、加热灯（烘托氛围）、装饰文字（如“会员特惠”“鲜到先得”）。

5. **人员与现场执行**  
   - 活动当天安排1-2名导购或理货员驻场：负责补货、整理、称重、解答会员疑问。  
   - 培训话术：如“会员专属价”“营养推荐”（例：猕猴桃催熟方法说明）。

6. **应急与销控计划**  
   - 准备替补品种：若某种水果意外滞销，提前沟通可替换为同价位替代品。  
   - 制定临时调货机制：如备货不足，2小时内可从门店或仓库存调拨。  
   - 规划残次果处理：如打折、员工内购、或销毁（需提前与商超约定损耗承担比例）。

**关键时间节点**：  
- 活动前3天：提交供货明细及到货时间表  
- 活动前1天：到货并完成初次陈列  
- 活动当天：早上7:30前到位并整理完毕  

**特别注意**：提前与商超确认**试吃许可、促销员工牌、地面防滑及果皮箱摆放**等细节，避免现场违规。
