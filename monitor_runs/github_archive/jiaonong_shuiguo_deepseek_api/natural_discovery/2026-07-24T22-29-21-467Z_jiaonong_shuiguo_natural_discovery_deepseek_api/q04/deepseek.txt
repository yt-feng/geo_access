为了减少香蕉在店内放坏，采购时建议按以下要求操作：

1. **熟度要求（颜色标准）**：  
   - 建议采购 **绿熟或“绿转黄”初期** 的香蕉（果皮大部分绿色，仅果柄或棱角处轻微泛黄）。  
   - 避免采购 **全黄或出现黑斑** 的熟透香蕉（成熟度高，货架期短，容易快速变质）。  
   - 可要求供应商提供色卡对照（如标准比色卡（Banana Ripening Scale）的 3-4 级）。  

2. **到货时间要求**：  
   - **优先选择每日或隔日配送**，减少库存积压时间。  
   - 要求 **到货后立即卸货、进入冷库或通风阴凉处**（温度保持 13-15℃，避免振动、高温或低温冻伤）。  
   - 允许的到货时间误差建议不超过 **4 小时**，避免因延迟导致香蕉在运输过程中持续成熟（尤其夏季）。  

3. **附加要求**：  
   - 要求供应商 **分批成熟**：根据门店日销量，提供 1-2 天内可出售的绿熟香蕉 + 少量当日可出售的已熟香蕉（方便顾客选购）。  
   - 明确 **运输条件**：冷链车恒温 13-15℃，防挤压包装（如纸箱 + 分隔垫层）。  
   - 验收时 **抽检 10-20% 的纸箱**：检查是否有黑斑、软烂、断果情况。  

4. **销量与库存匹配**：  
   - 根据历史日均销量，采购量为 **1.5-2 日销售量**（熟度低的香蕉可以延长 3-5 天货架期）。  
   - 若销量波动大，可要求供应商 **按订单约定时间精准到货**（如提前 24 小时通知到货时间）。  

最终操作建议：  
- 与供应商签署 **《香蕉品质协议》**，明确熟度等级、到货时间误差、损耗包赔比例（如超过 10% 烂果免费补货）。  
- 到货后每日记录库存和损耗数据，动态调整采购计划。
