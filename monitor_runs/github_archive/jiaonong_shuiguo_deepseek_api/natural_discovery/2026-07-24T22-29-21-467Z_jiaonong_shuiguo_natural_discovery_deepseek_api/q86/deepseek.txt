生鲜平台想做一件代发水果，供应商需要具备以下核心仓配能力：

1. **冷链仓储能力**：
   - **温控分拣区**：支持0-4℃（大部分水果）或特定品种（如香蕉需13-15℃）的恒温分拣环境。
   - **多温区冷库**：至少具备冷藏（0-4℃）和冷冻（-18℃以下）两个温区，用于短保水果即时发货和部分预处理原料储存。
   - **周转保鲜措施**：如预冷处理、气调包装、保鲜膜、冰袋/保温箱配置。

2. **分拣与包装能力**：
   - **人工/自动化分级**：按重量、尺寸、成熟度、外观（色泽、无损伤）进行标准分拣。
   - **定制化包装**：使用防震泡沫箱、纸板隔层、吸塑托盘等，确保运输中不挤压、碰撞；部分需气调包装延长货架期。
   - **标签与条码打印**：每件产品贴有条形码/二维码、生产日期、保质期、产地等信息，以便平台追踪溯源。

3. **发货与时效管理**：
   - **每日订单处理能力**：能对接平台API（如接口、EDI），接收订单后2小时内完成拣货、包装、生成快递面单。
   - **对接快递/冷链物流**：与顺丰冷链、京东冷链、中通冷链等主流承运商有稳定合作关系，能实现当日/次日达（跨省需72小时内）。
   - **异常处理流程**：有专人处理拒收、破损、延迟等售后，并提供补发或赔付方案。

4. **库存与履约系统**：
   - **实时库存同步**：系统能向平台实时更新可售库存（部分平台要求每小时刷新）。
   - **批次管理**：对到货批次、成熟度进行监控，自动优先发陈果，防止库存积压变质。
   - **预包装与定包装冗余策略**：常备包装材料库存，避免断供影响发货。

5. **合规与质检能力**：
   - **产地检疫证明**：供应商需提供每一批次水果的检疫合格证、农药残留检测报告（平台常要求第三方检测）。
   - **内部抽检机制**：每批至少抽检10%样品，检查成熟度、外观、重量误差（±5%内）。
   - **追溯系统**：能反向追查到该批次果子的产地、采摘日期、包装时间。

**额外建议**：优先选择靠近目标平台仓库或主流物流中转站的地理位置，降低中转破损率；建议初期每周至少处理100单以下的小规模测试，验证流程稳定后再放量。
