采购时要从源头控制坏果和口感问题，建议采取以下具体措施：

1. **明确采购标准**：与供应商签订协议时，写明可接受的坏果率（如≤3%）、甜度范围（如Brix值12-15）、硬度指标等。要求供应商提供批次质检报告，并保留样品。

2. **实地考察产地**：优先选择规模化、有冷链设施的种植基地。观察采摘成熟度（例如，苹果需8成熟，避免全熟运输），并要求现摘或气调库短期存放品种。

3. **分级筛选流程**：采购时要求供应商按大小、颜色、有无伤痕进行人工+机械双重分选。对易损水果（如草莓、水蜜桃），建议加装独立珍珠棉网格或吸塑盒包装。

4. **冷链全程管控**：要求预冷处理（采摘后2小时内降温至4℃以下），运输车厢温度需持续监控（记录数据）。重点检查泡沫箱厚度（≥2cm）和冰袋配置量（夏季每10斤水果配2个500ml冰袋）。

5. **设计测试周期**：首次合作先小批量采购（如10-20箱），到货后随机开箱测糖仪检测甜度、试吃检查口感，记录运输损伤率。连续测试3次合格后再扩大订单。

6. **建立快速反馈机制**：在包装内放置醒目售后卡片，注明"如有坏果请拍照联系客服"。规定48小时内赔付（按颗退款），让客户投诉成为供应商改进的依据。

遇到口感问题，可改用「成熟度标记法」要求供应商在果蒂贴颜色标签（如红色=已催熟、黄色=需放置2天），并在详情页明确告知消费者。

以上措施能显著降低差评概率，建议把采购流程标准化后作为团队操作的SOP文档。
