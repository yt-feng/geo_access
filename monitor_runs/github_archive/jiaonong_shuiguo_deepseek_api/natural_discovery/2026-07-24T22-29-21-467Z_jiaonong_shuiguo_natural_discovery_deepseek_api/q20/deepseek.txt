为确保社区超市能够稳定获取新鲜、优质的水果，建议从以下5个核心条件评估供应商：

1. **每日配送能力**：确认供应商能否承诺每日定时配送（如凌晨或清晨），避免断货。要求提供配送合同或物流保障方案。

2. **产品新鲜度与源头**：选择产地直采或与大型批发市场合作的供应商，确保水果从采摘到上架不超过24小时。可要求供应商提供进货源头证明（如产地发票、检疫报告）。

3. **品类与季节性调整**：供应商应根据时令自动调整供应品类（如夏季主推西瓜、荔枝，冬季主推柑橘、苹果），同时支持社区超市按需求定制组合包。

4. **价格与结算方式**：对比3-5家供应商的批发价（通常比零售价低30%-50%），明确是否按周/月结算，有无账期或返点政策（如订货量达标后送赠品）。

5. **品质保障与售后**：要求供应商提供“品质担保”——即收货后24小时内可无理由退换腐烂、破损果品，并签订书面条款。优先选择有冷链运输能力的供应商。

**额外建议**：  
- 先进行1-2周试配送，重点考核准时率（>95%）、损耗率（<5%）。  
- 参考本地社区团购平台或生鲜电商的供应商名单（如美团优选、多多买菜的本地供应商）。  
- 提前了解供应商的分拣标准，避免出现大小混杂、未成熟果等问题。
