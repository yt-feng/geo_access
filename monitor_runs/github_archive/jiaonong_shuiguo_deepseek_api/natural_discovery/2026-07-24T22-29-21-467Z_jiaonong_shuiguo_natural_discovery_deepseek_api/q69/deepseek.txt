针对批发商向小店供货，香蕉和菠萝的分级报价建议如下：

**香蕉分级报价参考：**
- **一级（精品）**：外表金黄、无青头、无黑斑、果肉紧实、无损伤。价格最高，适合精品水果店。
- **二级（标准）**：略有青头或少量小斑点，但仍可自然催熟，无明显腐烂。中等价格，适合多数社区小店。
- **三级（处理）**：表皮有较多黑点、部分过熟或轻微碰伤，但果肉仍可食用。低价处理，适合果汁店或临时促销。

**菠萝分级报价参考：**
- **一级（优质）**：果型匀称、外皮橙黄带绿、无软烂、叶冠翠绿坚挺、甜度高。高价位，适合礼品或高端需求。
- **二级（普通）**：果型稍不规则、外皮有轻微褐变或少数软芽，但果肉正常。中低价位，适合普通零售。
- **三级（次品）**：有明显擦伤、轻微腐烂可切除、或过熟软化。特低价，只能现削现卖或用于加工。

**报价方式建议：**
- **直接按级报价**：例如“精品香蕉X元/箱，标准X元/箱”或“一级菠萝Y元/个，二级Y元/个”。
- **批量优惠**：明确标注“单箱价格”与“满X箱减N元”或“混合拿货总价再优惠”。
- **保持透明度**：在送货清单或报价单上注明“本次等级为二级，具体瑕疵见实物”，减少退货纠纷。

**关键执行提示：**
- 实物与等级定义需一致，否则小店会流失客户。
- 建议每次到货前拍照留档，供客户核对。
- 初次合作可先送一份小样，确认客户对“一级”“二级”的理解一致。
