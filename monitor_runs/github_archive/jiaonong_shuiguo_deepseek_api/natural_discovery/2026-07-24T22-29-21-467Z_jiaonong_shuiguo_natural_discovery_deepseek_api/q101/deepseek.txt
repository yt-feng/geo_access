与水果供应商洽谈酒店早餐长期合作时，建议重点关注以下5个核心环节：

1. **品质与规格标准**  
   - 明确所需水果的品种（如切片哈密瓜、整颗苹果/香蕉等）、成熟度（如全熟/7成熟）、尺寸范围（如蜜瓜单颗1.5-2kg）和包装方式。  
   - 要求供应商提供每日/每周质检报告（如农药残留检测、冷链温度记录），并约定如连续3次到货不合格可解除合同。

2. **供应稳定性保障**  
   - 要求供应商提供备选基地或产区名单（如：冬季可从云南、夏季可从海南调配），避免单一产地受气候影响断供。  
   - 合同中明确设定应急响应时间（如突发缺货时需在6小时内调货送达），并约定每日最低库存承诺（如：酒店早餐时段需保持15kg切块水果库存）。

3. **价格与结算机制**  
   - 采用“保底价+浮动价”模式：约定基础价（覆盖80%订单量），剩余20%可参考当月批发市场均价浮动（浮动范围不超过±10%）。  
   - 明确汇率风险分摊（如进口水果原币价格变动超5%时双方重新议价）。

4. **物流与损耗管控**  
   - 要求供应商用车内温度≤6℃的冷藏车配送，且每日到货时间准确率≥95%（如迟到超30分钟需承担10%单日货款罚金）。  
   - 明确到货后30分钟内酒店有权开箱验收，发现冻伤、磕碰等非顾客可接受瑕疵品，供应商需2小时内补货或按当日采购价3倍赔付。

5. **合规与风险条款**  
   - 要求供应商提供所有产品的原产地证明、检疫许可证（尤其是进口水果的入境检验单）。  
   - 合同中加入不可抗力免责条款，但需列明可替代方案（如旺季台风导致断供时，供应商需48小时内启动备用基地货源）。

**实操建议**：首次合作可先签订3个月试用期合同，期间安排早餐时段高频次收货抽查（如每日随机抽取3箱称重、测糖度），试用期合格后再转为年度框架协议。
