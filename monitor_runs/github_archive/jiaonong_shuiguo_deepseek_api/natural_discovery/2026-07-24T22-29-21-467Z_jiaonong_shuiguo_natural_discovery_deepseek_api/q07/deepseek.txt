针对水果店搭配水果礼盒，建议按**颜色、口感、价位和用途**组合，优先考虑**耐放、甜度高、外观好**的水果。以下是几种高销量搭配方案：

**1. 经典“红黄绿”搭配（大众畅销款）**
- 内容：苹果（红）+ 橙子（黄）+ 青提或猕猴桃（绿）+ 香蕉
- 特点：颜色鲜艳、甜酸平衡，适合送礼或日常。
- 注意：香蕉易熟，建议放未全熟的；橙子选脐橙或冰糖橙。

**2. “耐放+高性价比”搭配（适合企业团购或快递）**
- 内容：苹果 + 橙子 + 火龙果 + 柚子或哈密瓜（切块密封）
- 特点：耐运输、不易坏，重量感强。
- 排除：菠萝（易氧化、需泡水）、香蕉（易压坏）。

**3. “热带风情”高端款（适合年轻客户、节日送礼）**
- 内容：菠萝（切好密封）+ 芒果 + 火龙果 + 蓝莓或草莓
- 注意：菠萝需提前处理（去皮切片、盐水浸泡），搭配密封盒。

**4. “健康轻食”款（适合健身、控制体重人群）**
- 内容：苹果 + 橙子 + 圣女果 + 菠萝（少量）
- 建议：菠萝切成小盒装，标注“即食”；香蕉可以不放（热量高）。

**关键注意事项：**
- **香蕉**：只能放未全熟的，且放在礼盒最上层（避免被压），很多礼盒会避开香蕉。
- **菠萝**：一定要提前处理（去皮、切块、盐水浸泡），否则客户觉得麻烦。可以做成“半成品”配竹签。
- **打包技巧**：用干净纸或泡沫隔开，避免碰撞；苹果和橙子最百搭，建议各占30%以上。

**试卖建议**：先做“苹果+橙子+随机一种”的基础款，注明“可自选替换”，观察客户反馈再调整。
