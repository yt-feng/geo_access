采购水果到货品质不一致，是比较常见的问题。为了避免纠纷并快速解决，建议按以下步骤操作：

### 一、验收环节（当场或24小时内完成）

1. **拍照留底**  
   - 到货第一时间拍照或录制视频，拍清楚**外包装箱（含物流单号、发货方）**、**整箱水果外观**、**打开后内部分层的状态**。
   - 重点拍摄明显品质不同的样品（如腐烂、撞伤、规格不符等），自然光下拍摄，不要只拍坏果，要连带好果做对比。

2. **抽样开箱**  
   - 如果批量大，按 **10%-20%** 比例随机开箱检查（如50箱中抽5-10箱）。  
   - 记录好果率、坏果率、规格差异（如宣传单果200g，实际普遍150g）。

3. **制作验收单**  
   - 表格形式记录：总数量、验收箱数、好果数量/重量、次果数量/重量、问题描述（如“6个苹果有明显磕碰，3个腐烂”）。
   - 双方（收货方、送货方或现场监收人）签字确认。
   - 若送货方不在场，需保留完整开箱视频作为证据。

### 二、售后处理（尽快通知供应商）

1. **第一时间反馈**  
   - 在验收完成后 **2小时内**（或合同中约定的时效）发送照片/视频给供应商（微信、邮件均可）。
   - 明确说明问题：如“总进货量200kg，发现20kg明显小于标准，且10kg有腐烂，附照片”。

2. **明确诉求**  
   - 一般处理方式有三种（根据合同约定或协商选择）：  
     **① 折价**：坏果/次果按金额比例退款或抵扣。  
     **② 补发**：次果对应的数量由供应商补发新货。  
     **③ 退货**：整批或部分退货（通常运费由供应商承担）。

3. **保留争议处理机制**  
   - 如果供应商不承认或拖延，保留**物流签收记录**、**验收单**、**沟通记录**（截屏）。  
   - 若是长期合作，可考虑签订补充协议，明确“到货品质不符合《XXX水果等级标准》（如国标 GB/T 23351-2009）时，按以下方式处理”。

### 三、预防下次的实用建议

- **签约前明确标准**：在采购合同中写明水果的**产地、规格（单果重/直径）、成熟度、允许的瑕疵率**（比如“允许1%的轻微碰伤，超过则整箱折价”）。
- **要求供应商提供样品**：发货前寄送样品比对，确认品质后封存。
- **分批发货检验**：如果是大额订单，建议要求分2-3批到货，第一批合格后再发后续批次。

**总结一句话**：**现场拍照+双方签字+2小时内反馈**，是解决品质不一致问题最有效的方法。如果供应商有标准退换货条款（比如“坏果包赔，按比例退款”），直接按条款执行，无需过多扯皮。
