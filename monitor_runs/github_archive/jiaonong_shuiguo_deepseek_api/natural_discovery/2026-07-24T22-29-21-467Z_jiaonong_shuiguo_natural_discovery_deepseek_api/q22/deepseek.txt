以下是为超市水果区设计的三种组合促销方案，侧重不同消费心理和提升客单价：

---

### 方案一：“能量早餐组合”（适合早市/家庭客群）
- **商品**：香蕉 + 苹果
- **定价逻辑**：原价合计15元 → 组合价10.9元（约73折）
- **组合理由**：
  - 香蕉（即食性强）和苹果（耐储存）都是高频消费品
  - 搭配可满足“早餐水果+日常水果”需求
- **执行细节**：
  - 在收银台旁设“早市组合区”，用暖色便签贴手写标语：“早晨一根香蕉补钾，一个苹果抗氧化”
  - 搭配袋装酸奶（+3元换购酸奶）进一步提客单价

### 方案二：“果盘DIY套装”（适合办公室/下午茶场景）
- **商品**：3个香蕉 + 1个菠萝（切块）+ 3个苹果
- **定价逻辑**：原价合计38元 → 组合价29.9元（约78折）
- **组合理由**：
  - 菠萝自带“仪式感”（需切），搭配苹果、香蕉可丰富口感
  - 买回家可直接拿小盒分装，适合2-3人分享
- **执行细节**：
  - 在菠萝上方贴“+10元换购香蕉+苹果”的箭头指示
  - 冰柜旁放试吃小杯（菠萝+苹果丁，撒少量盐）

### 方案三：“果切增量套”（适合即食/冲动消费）
- **商品**：整只菠萝（配水果刀）+ 2根香蕉 + 3个苹果
- **定价逻辑**：原价48元 → 组合价39.9元
- **组合理由**：
  - 菠萝作为“视觉锚点”（价格高，需称重），用低价苹果、香蕉拉低平均价
  - 暗示“买了菠萝顺便带香蕉苹果回家”
- **执行细节**：
  - 用绿色托盒将菠萝切半放中间，左右放香蕉、苹果
  - 标语：“刺不刺激？亲自削菠萝，送水果刀和使用指南”

---

### ⚠️ 执行提示
1. **控制损耗**：香蕉单独穿保鲜膜，避免与菠萝挤压；苹果先挑“摔伤”品种做组合
2. **收银话术**：收银员补刀句——“菠萝现在处理最快，10分钟能切好”
3. **数据追踪**：3天后对比组（无组合时）客单价变化，若提升＜20%则调整折扣力度

短期聚焦“组合价低于单买总和”的直观优惠，长期可通过“买组合送水果网兜/可降解盒”绑定复购。
