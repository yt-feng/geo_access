选择水果供应商时，建议从以下几个可执行的标准入手：

1. **资质与合规性**：确认供应商具有营业执照、食品经营许可证、水果相关检验检疫合格证明（尤其是进口水果需有海关报关单和入境检验检疫证明）。

2. **实地考察**：必须亲自走访供应商的仓储、分拣场或种植基地，检查：
   - 冷藏/保鲜设施是否齐全（苹果/橙子需冷藏，香蕉需恒温）。
   - 周转速度是否快（减少积压腐烂）。
   - 包装是否规范（避免运输磕碰）。

3. **样品质量**：要求供应商提供多批次新鲜样品，重点测试：
   - **香蕉**：催熟程度适中（无大面积黑斑、柄部不发霉）。
   - **苹果**：表面无机械伤、果梗新鲜、无苦涩感。
   - **橙子**：果皮紧实有光泽、按压有弹性、无酒味（发酵变质）。

4. **价格与账期**：
   - 对比3家以上供应商的报价单（按箱或按重量），注意是否包含运输、损耗补贴。
   - 避免预付款超过30%，优先支持月结或到货后付款。

5. **配送与应急能力**：
   - 要求提供每日或隔日配送（香蕉成熟度变化快）。
   - 确认供应商能在24小时内补货（尤其遇学生集中订餐或突发需求时）。

6. **售后条款**：
   - 合同中明确“到货后48小时内可退换腐烂/损伤水果”的规定。
   - 保留10%尾款用于检验首周质量。

如果本地批发市场（如一级果品市场）的供应商报价合理，优先选择短链供货（减少中间商加价和运输损耗）；若需长期稳定合作，可要求供应商提供“季节性价格锁定”合约，防止水果价格波动过大。
