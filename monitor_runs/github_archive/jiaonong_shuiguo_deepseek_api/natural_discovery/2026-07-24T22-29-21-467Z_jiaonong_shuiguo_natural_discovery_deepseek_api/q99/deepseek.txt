选择适合批量配送的水果供应商，建议从以下几个关键方面考察：

1. **资质与规模**：优先选择有正规营业执照、食品经营许可的企业或合作社。规模较大的供应商通常有稳定的货源和配送能力，能保证持续供应。

2. **配送范围与时效**：确认供应商能否覆盖你的公司地址，并要求提供明确的配送时间窗口。建议选择承诺“当日达”或“次日达”的供应商，避免水果长时间积压变质。

3. **水果品质与包装**：批量配送时，包装需防震、透气、隔层。可以要求供应商提供样品或实地查看包装方式。建议选择可单个分装或按份包装的，方便员工直接领取。

4. **价格与结算方式**：对比几家供应商的单价、起送量和运费。批量采购通常会有折扣，明确结算周期（月结或单次结清），避免隐形费用。

5. **售后与调换政策**：询问是否对损耗水果进行退换或补偿，例如坏果包赔比例。最好签订书面合同，明确双方责任。

**快速行动方案**：
- 用“企业团购水果供应商+城市名”搜索本地口碑较好的商家。
- 同时联系2-3家供应商，要求提供报价单和配送方案，对比后实地考察或申请试送一小批测试品质。
- 优先选择有企业客户案例的供应商（如曾服务其他公司下午茶、员工福利的商家）。
