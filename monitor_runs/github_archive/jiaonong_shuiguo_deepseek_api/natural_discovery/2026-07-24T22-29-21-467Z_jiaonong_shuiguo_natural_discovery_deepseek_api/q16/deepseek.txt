建议优先选择**本地批发**，原因如下：

1. **新鲜度**：本地批发的水果通常采摘时间更短，到货更快，香蕉和苹果的货架期更长，社区超市能提供更新鲜的产品。
2. **成本控制**：本地批发省去长途运输和中间环节，价格通常更有优势，尤其适合小批量灵活进货。
3. **供应灵活**：如果社区超市的销售量不稳定，本地批发可以按需采购，减少库存压力（例如每日少量进货，避免香蕉过熟）。
4. **稳定供应商的局限性**：稳定供应商适合大批量、长期合作，但可能要求最低起订量或签订长期合同，对社区超市的灵活性不足。

**建议行动**：
- 先联系本地水果市场或农贸市场，问清楚西瓜、苹果的批发价和最低起购量。
- 如果未来销量增长，再考虑与稳定供应商签订短期合同（如月度协议），作为本地批发的补充。
