判断香蕉熟度和坏果风险，可以从以下几个关键方面入手，以下是具体可执行的方法：

### 1. 观察外观颜色（熟度判断）
- **青绿（未熟）**：果皮全绿，果肉硬，需常温催熟，适合长期储存或运输。
- **黄绿相间（半熟）**：部分变黄，果肉开始软化，适合短期销售。
- **通体金黄（成熟）**：皮黄无斑，口感最佳，但储存期短，需尽快销售或冷藏。
- **出现黑点（过熟）**：表皮有少量黑点，果肉软甜，但易腐烂，需优先处理。
- **大面积褐变（腐烂信号）**：果皮有深褐色或黑色软斑，果肉可能已变质。

### 2. 检查果柄和果指（坏果风险）
- **果柄**：新鲜香蕉果柄呈青色，干燥或发黑说明可能已受损或运输不当。
- **果指间距**：果指之间若出现裂缝或分离，容易滋生霉菌。
- **果指末端**：检查是否有发黑、发霉斑点，尤其是“梅花点”（果指末端的小黑点）可能预示早期腐烂。

### 3. 物理触感（软硬度）
- **坚硬**：未熟，适合长期存放。
- **有弹性**：可正常销售。
- **软烂**：内部可能已开始腐败，或者运输中压伤，风险高。注意：软烂不等于全部坏，可以用手指轻按果肉，若按压处有水渍感或发出酸味，则已变质。

### 4. 气味检测
- **正常**：轻微香蕉清香。
- **酸味或酒味**：过度成熟或开始发酵，内部可能已变质。
- **霉味**：出现霉菌感染，例如果皮上有白毛或绿毛。

### 5. 通风与挤压伤（坏果风险）
- **挤压伤**：果皮有凹陷、褐色压痕处，容易快速褐变并扩散，需挑出。
- **包装内水汽**：检查包装袋或纸箱内是否有积水、霉斑，潮湿环境加速腐烂。

### 6. 批量抽样建议
- **抽样比例**：随机抽取整批量的5%-10%（比如100箱抽5-10箱），每箱至少看5根。
- **重点检查**：箱子底部、角落的香蕉容易受压，果柄处最常见坏果。

### 现场速查口诀：
- 一看（颜色、黑斑、果柄）
- 二摸（硬软、挤压伤）
- 三闻（酸酒霉味）
- 四抽样（批次均匀）

如果发现单箱中超过3根有明显软烂、发霉或酸味，建议整箱拒收或降价处理。熟度过高（全黄带斑）的批次，优先安排本地零售或餐饮渠道快速出货。
