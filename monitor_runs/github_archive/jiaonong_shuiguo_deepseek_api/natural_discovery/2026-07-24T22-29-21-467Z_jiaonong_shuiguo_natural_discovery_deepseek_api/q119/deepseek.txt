选择水果供应商时，除了价格和新鲜度，以下几个细节常被忽视，但直接影响长期稳定：

1. **产地直采比例**：供应商是否拥有自有或长期合作的产地，而不是完全依赖批发市场。直采比例高能保证货源稳定、价格波动小，且品质更可控。

2. **分拣与品控标准**：供应商是否严格执行分拣（如大小、成熟度、外观分级）。可以要求查看其品控流程，明确退换货规则（如坏果率超过多少可退）。

3. **物流与冷链条件**：重点确认冷藏车温度控制、运输时长、到货后存放条件。可以要求看仓库冷库温度记录，避免“最后一公里”失效。

4. **单品稳定性和季节性衔接**：核心水果（如苹果、橙子）能否保证全年供应，以及换季时品种过渡是否顺畅。建议要求供应商提供过去两年的供货记录。

5. **价格锁定机制**：是否支持短期锁价协议（如半月内价格不变），或对突发涨价有缓冲方案（如优先供应老客户）。

6. **账期与售后响应速度**：确认账期天数、坏果赔付周期（如48小时内响应），以及退换货的物流成本承担方。

建议：与供应商建立“试合作期”（如1个月），重点考核鲜度保持时间和退货率。同时要求提供第三方检测报告（如农药残留），尤其对进口水果。
