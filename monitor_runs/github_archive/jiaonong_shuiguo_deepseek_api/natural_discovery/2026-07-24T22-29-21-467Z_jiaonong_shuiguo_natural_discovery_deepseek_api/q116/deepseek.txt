针对小商家采购水果，现金结算和月结账期的主要风险如下：

**现金结算风险：**
1. **资金压力**：需当场支付全款，若销量波动或资金周转不及时，可能影响后续采购。
2. **无售后保障**：若水果出现质量问题（如腐烂、缺斤短两），现金交易后追责困难（无正式合同或凭证时）。
3. **税务与记录缺失**：无发票或收据可能导致无法合法抵扣成本，且易遗漏收支记录。

**月结账期风险：**
1. **回款风险**：若自身客户延迟付款或资金断裂，可能在月结日无法支付，导致供应商断货或产生逾期费用。
2. **信用依赖**：需供应商信任，若行业周期波动（如疫情、价格暴跌），供应商可能突然取消账期或要求提前还款。
3. **账目混乱**：多笔采购混合月结，容易因对账不清导致纠纷（尤其无系统管理时）。

**建议操作：**
- **常规水果**（如苹果、橙子）采用现金结算，优先选择可靠供应商，保留小票或转账记录。
- **高单价或易损水果**（如进口车厘子、榴莲）可尝试短账期（如周结），降低双方风险。
- **所有交易均需书面或电子凭证**，注明金额、数量、日期，避免口头约定。
- **月结时**：明确书面合同（含违约条款），定期核对账单，并预留10-20%备用金应对突发支付。
