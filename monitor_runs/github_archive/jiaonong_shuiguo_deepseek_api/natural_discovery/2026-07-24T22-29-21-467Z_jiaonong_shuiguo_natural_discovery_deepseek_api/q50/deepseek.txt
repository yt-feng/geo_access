对于茶饮店选购菠萝原料，**甜度通常比出汁率更重要**，但需结合具体用途综合判断。

**建议优先级：**
1. **甜度高**：直接决定饮品风味，避免额外加糖增加成本或影响口感层次。尤其用于果茶、奶茶等需突出果味的产品，高甜度菠萝能提升整体品质和顾客满意度。
2. **出汁率适中**：若榨汁或制作果泥，出汁率影响产量和成本；但若仅切果肉做装饰或果粒，出汁率影响较小。

**具体场景选择：**
- **主打果茶或冰沙**：高甜度+高出汁率（如金菠萝、香水菠萝）最佳，甜度≥12°Brix，出汁率≥60%。
- **饮品中作为果粒/装饰**：优先甜度，出汁率次之，选择脆肉、汁水少的品种（如杂交菠萝）避免果肉出水影响口感。
- **与糖浆搭配**：若用普通甜度菠萝（10-12°Brix），需控制糖浆比例，避免过甜或成本上升。

**副建议**：要求供应商提供样品试做，并参考当地市场接受度（如顾客喜甜则更侧重甜度）。常用品种：都乐金菠萝（甜度高、出汁率高但价格较高）、巴厘菠萝（甜度中、出汁率中、性价比好）。
