这三个问题都重要，但最应该先问 **配送**，因为它直接影响水果的新鲜度和你的销售效率。具体原因和操作建议如下：

1. **优先问配送**：水果是生鲜，配送时效和冷链条件决定损耗率。建议问：“你们是当天采摘发货吗？用冷藏车还是普通车？不同季节最快几小时到货？” —— 如果配送不稳定，再低的价格也可能因坏果导致售后压力。

2. **其次问售后**：问清“坏果包赔比例是多少？是按斤赔还是整箱赔？需要提供什么凭证？” 这决定你是否能快速处理客户投诉，避免口碑崩盘。

3. **最后谈价格**：在确认配送稳定、售后明确后，再谈价格。比较时要求对方提供“同规格同品种”的报价，并问清包装费、物流费是否包含。

**简单决策建议**：优先选择配送能承诺“24小时内到货+冷链运输”的供应商，哪怕价格高10%-15%，也比低价但经常延误或变质导致的售后风险更划算。
