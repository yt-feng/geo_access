判断茶饮连锁供应商能否稳定按规格送货，建议采取以下可执行步骤：

1. **明确规格标准并书面化**：先内部制定《菠萝采购验收标准》，包含品种（如巴厘、凤梨等）、重量范围（如单果1.2-1.5kg）、成熟度、色泽、甜度（如Brix值≥14%）、无腐烂/病斑等指标。将标准写入采购合同或供应协议。

2. **要求供应商提供历史出货记录**：查看其近3-6个月的出货记录，重点看同一品种、规格菠萝的日均发货量、次品率、重量偏差率。若连续30天内的规格符合率低于95%，风险较高。

3. 开展**小批量试单（300-500kg）**：按正常流程下单，要求分3次送货（间隔2-3天），记录每批到货的规格合格率、重量波动范围、到货准时率。试单合格率≥95%视为初步稳定。

4. 建立**动态评分机制**：每次到货后按以下维度打分（满分100分）：
   - 规格符合率（满分40分）：单批次合格率每低于1%扣1分
   - 重量稳定性（满分30分）：单果重量超出标准范围±10%的比例，每超出1%扣1分
   - 到货准时率（满分30分）：晚到1天扣5分，超3天视为违约
   连续5批得分≥85分，可以纳入稳定供应商名单。

5. 实施**竞品对标监控**：同一批次优先采购2-3家提供相同规格的供应商，对比其实际到货数据，保留表现稳定的供应商。同时要求供应商承诺对不达标的批次承担调换或扣款责任（合同中注明）。

6. 关注**产地和气候因素**：菠萝主产区（如海南、广东、菲律宾等）的产区气候、采收周期会影响规格。可要求供应商提供产地证明、采收日期、采摘时的气候记录，避免因自然条件导致的规格缩水。

7. 建立**应急备选清单**：即使主要供应商稳定，也需准备1-2家备用供应商（如提前签订框架协议），防止因自然灾害或物流问题导致断供。

**快速判断口诀**：
- 先看小单三次送，合格率要过95%（三次试单规格符合率均≥95%）
- 再查合同写标准，扣款条款要明确
- 最后记分看趋势，连续5批达85分即入围

如果试单合格率低于90%，或出现连续2次重量偏差超过15%，建议要求供应商整改或更换。
