为茶饮店采购香蕉时，控制熟度需考虑最终用途和储存时间。以下是具体建议：

1. **明确用途与对应熟度**  
   - **做冰沙、奶昔或烘焙（如香蕉蛋糕）**：选用**熟透**的香蕉（表皮出现大量黑色斑点，整体偏软，闻起来有浓郁甜香）。这类香蕉甜度高、易搅拌，能增强饮品或甜品的天然甜味和稠度。  
   - **做切片装饰、甜品摆盘或直接搭配饮品（如拿铁）**：选用**七八成熟**的香蕉（表皮金黄，略带青色，手感稍硬）。这类香蕉不易氧化变黑，形状较完整，口感紧实不软烂。  
   - **作为配料短期库存**：建议采购**七成熟**的香蕉（表皮基本金黄，末端略有青绿），让其在店内自然成熟，避免一次性全熟导致耗损。

2. **分批次采购与储存策略**  
   - **按用量分批次到货**：如每天消耗量大，可隔天采购一批成熟度不同的香蕉；若消耗量小，建议选七成熟，分批取出催熟（将香蕉放入纸袋，室温放置1-2天，或与苹果/番茄同放加速）。  
   - **储存管理**：未熟的香蕉放在室温、通风处（避免阳光直射）；已熟透的香蕉若未立即使用，应剥皮切块冷冻（密封袋保存），用于制作冰沙或果酱，避免浪费。

3. **现场验收标准**  
   - 检查表皮：避免严重擦伤、黑腐烂或散发酒精味（过熟变质）。  
   - 手感判断：轻轻按压香蕉中部，若太软（一按即凹陷）说明过熟；若硬而无弹性说明太生。可使用“指压法”：按压时能感到弹性但不过度脆弱为佳。

4. **商业参考建议**  
   - **小批量试用**：初期兼顾两种熟度采购（如70%七成熟+30%八分熟），测试顾客对不同口感饮品的接受度。  
   - **与供应商协定**：明确告知供应商每日或每周所需香蕉的成熟度范围（如“七至八分熟，无机械伤”），并要求到货时附成熟度标签。

**总结**：优先根据菜单用途决定熟度，采购量少时以七成熟为基准自然催熟，熟度不可控时用冷冻方式保存损耗品。若不确定，先采购小批量七成熟的香蕉，试验2-3天再调整订货量。
