针对餐饮店每天少量水果的需求，建议选择 **本地生鲜配送平台** 或 **社区团购自提点** 作为供应商，这样的方式最省心。具体推荐如下：

1. **生鲜电商平台（如叮咚买菜、美团优选等）**  
   - 支持每日下单，按需购买，无需囤货。  
   - 配送时间固定，可在闭店前预约第二天送达。  
   - 品控相对稳定，退换货流程标准化。

2. **周边农贸市场或社区果蔬店**  
   - 建立固定合作关系，约定每日送货上门。  
   - 提前沟通需求，由店家按份配好（如切块水果、混合果盒）。  
   - 价格灵活，可月结或周结，减少现金压力。

3. **大型批发市场的“拼单”模式**  
   - 加入周边餐饮店“拼货群”，与同行合买整箱水果（如芒果、西瓜），分摊成本。  
   - 优先选择产地直供的小型批发商，可以要求按日分装送货。

**操作建议**：  
- 首次合作时 **要求试订3-5天**，测试新鲜度和准时率。  
- 明确退换标准：如有变质水果，拍摄证据后当日更换或退款。  
- 避免选择需要起批量大、需预付押金的供应商（如冷库批发行）。  

**省心关键点**：  
- 选择可 **支持每日小量、次日达** 的平台，而非按箱批发的供应商。  
- 优先 **本地化**，减少运输损耗和沟通成本。  
- 建立 **第2备选**（如再找一家社区店），应对突发断供。
