从品控稳定性角度看，建议采取**“固定核心产地 + 多批次溯源”**的组合策略，而非完全固定一个产地或批次。具体建议如下：

### 1. 为什么不能完全固定？
- **自然波动**：同一产地、同一批次的成熟度、甜度、农残残留仍可能有较大差异（如雨水、日照影响）。
- **供应风险**：固定单一产地或供应商可能受气候、物流或政治因素影响断供。

### 2. 推荐做法
- **优选2-3个核心产地**：比如芒果选海南+广西，既分散风险，又能在口味对比中择优。
- **统一品控标准**：要求所有批次到货前提供“糖度、酸度、农药检测”报告（如糖度≥12%），而非单纯看产地名称。
- **批次性试饮**：每批次到货先剥开3-5个样品，对比前期留存的标准风味档案（用感官或仪器记录酸度、香气等数据）。

### 3. 建议执行的动作
- **建立“风味档案库”**：每次新批次到货后，记录糖酸比、香气浓度等数据，与历史批次做对照。
- **动态调整采购**：比如：如果A产地的芒果连续2批次糖度低于日常标准75%，则暂停采购、换B产地补位。

### 4. 可量化操作示例
- **初期（第1-2个月）**：要求供应商每批提供“Brix值（糖度）”+ 感官评级（自家员工盲测）。
- **优化期（第3个月起）**：基于数据统计，固定60%采购量给最高分的产地，留40%灵活调节。

**总结**：不要“固定死”，而是“固定品控标准+动态调配产地方向”。这样既能降低口味波动，又保留应对波动的缓冲空间。
