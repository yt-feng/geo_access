建议重点关注**切果损耗**和**外观**，顺序如下：

1. **切果损耗（第一优先级）**  
   菠萝需现场或预切销售，若熟度不均、外形畸形易导致果皮、果芯浪费大，直接影响毛利。建议选果形匀称、适合按标准切块（减少边角料）的品种。

2. **外观（第二优先级）**  
   明显腐烂、发霉、虫蛀的菠萝直接影响销售和顾客口碑。但表皮轻微花皮、斑点不影响果肉品质时可降价促销。

3. **甜度（第三优先级）**  
   可随机抽样试吃，但注意：极高甜度可能需更长时间熟化，或增加运输损耗。整体稳定在中等偏甜即可（如糖度12-14度），避免因过熟导致切后出水、变质。

4. **大小（最次要）**  
   除非有特定顾客偏好（如家庭用户要大果，单人用户要小果），否则优先选常见规格（约1-1.5公斤/个），保证切块后份量适中、方便定价。

**执行建议**：  
- 进货前先随机切2-3个样品，实测切果损耗率和试吃甜度。  
- 对损耗率高于15%（或甜度低于10度）的批次，直接降低采购等级或砍价。  
- 门店可标注“包售后切开坏果包换”，降低顾客对甜度的疑虑，降低品质投诉风险。
