针对连锁门店分布在不同城市的水果供应商仓配覆盖评估，核心思路是匹配“门店需求”与“供应商仓配能力”。以下是结构化的评估框架：

1. **计算门店与仓库的辐射半径**：明确每家门店对水果送达时效（如24小时/48小时/次日达）和新鲜度（如采摘后冷链时长）的要求。根据供应商的中央仓、区域仓或前置仓位置，用地图工具估算各仓到门店的运输时间距离，看是否在时效容忍范围内。

2. **评估配送频率与批次灵活性**：水果保质期短、波动大，需要让供应商提供每周或每日配送次数选项。如果门店销量波动大（如节假日高峰），要测试供应商能否临时增加批次，或支持门店额外紧急补货。

3. **检验冷链与保鲜能力**：水果新鲜度高度依赖全程冷链。查看供应商仓库是否有分区温控（常温、冷藏、冷冻），以及配送车辆是否配备冷藏设备。要求提供跨城市长距离运输（如跨省配送）的损耗率数据（一般应控制在3%-8%以内）。

4. **验证补货响应与到货准确率**：要求供应商提供历史订单的**准时到货率**（如≥95%）、**缺货率**以及**退换货处理时效**。可以抽取最近1-3个月部分门店的交易数据做交叉核验。

5. **实地模拟与压力测试**：对核心城市（门店数量多或销量大的）进行1-2周试配送。观察实际到货时间、水果外观与包装质量、以及送货单据与实物的一致性。重点测试节假日或促销季的负荷能力。

**执行建议**：
- 制作一张“门店-仓配覆盖矩阵表”，横轴为所有门店，纵轴为供应商的仓库位置，按“配送时长达标（绿）/超标（黄）/不可达（红）”标色。
- 如果发现多个城市无法满足24小时送达，可要求供应商补充区域仓或与本地小型冷链服务商合作（如“统仓共配”）。
- 若供应商无法达到关键指标（如跨省次日达、损耗率），则视为不可满足，需要寻找分区域供应商补充。

最后，务必将评估结论（能/不能覆盖、需要改进点）形成书面报告，并与供应商签订SLA（服务水平协议）约束关键指标。
