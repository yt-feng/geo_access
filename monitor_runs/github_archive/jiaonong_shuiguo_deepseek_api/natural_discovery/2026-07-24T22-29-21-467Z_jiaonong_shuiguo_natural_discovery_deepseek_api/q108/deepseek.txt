核实水果供应商的全国配送覆盖能力，建议采购方按以下步骤操作：

1. **索要配送范围明细**：要求供应商提供明确的配送城市、区域列表，以及是否支持乡镇或偏远地区。可具体到省份、地级市甚至县级市。

2. **测试订单验证**：选择2-3个不同地区的非核心城市（如中西部地级市或县城），下小额试单，观察是否能在承诺时间内送达。注意测试地址要避开一线城市核心区，以检验真实覆盖能力。

3. **核查物流合作伙伴**：询问供应商合作的物流公司（如顺丰、京东、中通等），并联系物流方确认其在该区域的网络。大型物流公司的网点覆盖可通过公开渠道查询。

4. **要求历史配送记录**：请供应商提供近期（如过去3个月）向不同城市发货的物流单号或截图，随机抽查订单是否成功送达。

5. **查看售后记录**：询问供应商是否有因配送范围未覆盖导致的退单、退款或投诉记录。可与供应商协商，规定若因配送问题产生损失需承担违约责任。

6. **实地或远程确认仓储**：若供应商声称有外地分仓（如水果前置仓），可要求提供仓库地址、照片或视频，并利用地图软件核实该地址是否存在及位置合理性。

7. **分阶段合作**：可先签署短期框架协议，约定以“下单前确认配送可行性”为前置条件，逐步扩大合作城市范围。

8. **利用行业资源核查**：查询该供应商在生鲜电商平台（如美团优选、每日优鲜等）或农产品平台的合作记录，或向行业商会咨询其信誉。

注意：水果行业易受季节、交通影响，建议在合同中明确“配送时效”与“范围调整权”，并保留因配送问题导致货损的追索权。
