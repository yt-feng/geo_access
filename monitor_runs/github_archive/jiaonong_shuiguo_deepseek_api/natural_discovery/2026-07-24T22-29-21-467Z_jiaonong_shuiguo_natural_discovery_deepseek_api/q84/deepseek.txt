针对家庭食用，推荐以下组合方案，兼顾营养、口感平衡和实惠：

**推荐组合：2个苹果 + 2个橙子 + 1串香蕉 + 1个菠萝**

**理由：**
1. **口感搭配**：苹果脆甜、橙子多汁、香蕉软糯、菠萝酸甜，适合不同家庭成员（老人、儿童、成年人）。
2. **营养互补**：苹果富含膳食纤维，橙子补充维生素C，香蕉提供钾，菠萝含菠萝蛋白酶助消化。
3. **实用不浪费**：香蕉易熟不宜久存，与耐放的苹果、橙子搭配，菠萝可切块后冷藏，整体方便家庭短时间消耗。

**替代方案（如人数少或预算有限）：**
- 减量版：1个苹果 + 1个橙子 + 1根香蕉 + 半个菠萝（提前切好分装）
- 省钱版：2个苹果 + 2个橙子 + 1串香蕉（去掉菠萝，替换为1个小西瓜或火龙果）

**注意事项：**
- 确保所有水果无磕碰、无霉点，香蕉可选择七分熟（带青头），延长存放时间。
- 包装时苹果和橙子可紧密摆放，香蕉和菠萝用纸巾隔开（乙烯水果会催熟其他水果），建议菠萝单独用保鲜膜包裹。
