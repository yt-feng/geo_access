会的，一箱香蕉大小不一确实会影响销售，主要体现在以下几个方面：

1. **顾客感知**：顾客通常期望同一箱或同一批次的香蕉大小均匀。大小差异明显会让人觉得产品“不专业”或“品质不稳定”，从而降低购买意愿。
2. **定价困难**：大小混装导致无法统一标价。如果按箱卖，顾客会挑拣大个的，剩下小个的难卖；如果按斤卖，大小不一的香蕉容易在称重时引发争议（例如觉得“小的占了斤数”）。
3. **损耗增加**：小香蕉因成熟快或易被压坏，可能更早变质；大香蕉若无人挑选，也容易在箱底被忽视，最终腐烂。
4. **影响销量**：顾客会更倾向选择大小均匀的香蕉（例如超市的精品包装），混合箱可能滞销，或者需要降低价格处理。

**建议做法**：  
- 采购时明确要求供应商按大小分级（如“大果、中果”），或直接采购标准化包装。  
- 如果已收到混合箱，可以将大小分开陈列，分别定价（大果高价，小果低价或作为“特价混装”处理）。  
- 对顾客明确标注“大小混合，按斤销售”，主动说明是性价比选择，避免误解。
