对于食堂水果采购，更推荐的结算方式是**按箱结算**。理由如下：

1. **降低管理复杂度**：按斤结算需要每次都称重、记录、计算单价和总价，过程繁琐且易出错。按份结算则需要提前定义每份的标准重量或数量，如果每次重量不统一，容易产生争议。
2. **便于库存与成本控制**：水果通常以箱为单位批发，按箱进货可直接对应采购订单和实际入库数量，账目清晰，不易漏记或混乱。
3. **减少损耗纠纷**：按箱结算时，买卖双方对一箱的标准重量或个数有共同预期（如“一箱苹果净重10公斤”），运输中如果出现损耗，责任更明确，避免因称重误差产生的摩擦。
4. **兼顾灵活性**：如需按份销售或分餐，可在按箱入库后统一分解为份数，内部核算即可，无需在采购环节增加复杂度。

建议做法：与供应商约定固定规格的包装（如每箱的净重或个数标准），签订采购合同时明确按箱计价。日常验收时只需检查箱体完整性和标注重量，快速高效。
