通常情况下，供应商是愿意提供周末促销支持的，尤其是针对长期合作或采购量较大的水果店。具体支持方式包括：

1. **价格支持**：供应商可能提供短期降价、折扣或“买赠”政策（如买10箱送1箱），但需要你提前沟通，说明促销计划并承诺销量。
2. **物料支持**：供应商可提供宣传海报、试吃样品、促销台或品牌专属包装袋等，部分还会分摊广告费用。
3. **联合推广**：对大品牌供应商，可能参与联合促销，分担部分成本。

**建议**：
- 提前（至少1周）联系供应商，明确促销时间、预期销量和所需支持。
- 以书面或邮件形式确认支持内容和条件，避免误解。
- 若供应商最初拒绝，可协商以“销量达标后补返点”或“长期合作优先”作为条件。

如果供应商规模小或合作刚起步，支持力度可能有限，但主动沟通仍有机会获得部分帮助。
