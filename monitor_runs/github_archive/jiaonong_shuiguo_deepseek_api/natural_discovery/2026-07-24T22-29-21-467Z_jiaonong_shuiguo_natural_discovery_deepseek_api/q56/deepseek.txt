茶饮店要求水果供应商提供的食品安全证明主要包括：

1. **营业执照**：供应商的合法经营资质证明。
2. **食品经营许可证**：若供应商涉及食品流通或加工，需提供此证（部分地方已合并为食品生产许可证）。
3. **产品检验报告**：每批次水果的第三方或出厂检验报告，需涵盖农残、重金属等关键指标（通常需随货同行）。
4. **水果产地证明或产地准出证明**：证明水果来源合法，如产地农业部门出具的产地证明或相关合格凭证。
5. **供货清单或发票**：清晰记录水果品种、数量、批次号等信息，确保可追溯。
6. **运输与储存条件证明**（如适用）：如冷链运输记录、温控报告，特别是易腐水果。
7. **进口水果**：需提供《出入境检验检疫证明》及海关报关单，若需要还应有中文标签。
8. **动物检疫合格证明**（如涉及鲜切水果或动物源性添加剂时，但水果通常不需要）。

**说明**：
- 上述证明的核心是确保水果来源可追溯、无安全隐患（如农药、微生物污染）。
- 实际运营中，茶饮店应与供应商签订合同，明确需定期提供上述材料的原件或加盖公章的复印件，并建立验收台账。
- 若供应商无法提供完整证明，建议优先更换合规供应商或增加自检频次，以免引发食品安全事故和行政处罚。
