消费者对品牌水果的认知程度确实在逐年上升。根据市场调查，约60%的消费者在购买水果时会优先考虑品牌，尤其是中高端水果，比如佳沛奇异果、都乐香蕉等。

建议您可以从以下几点切入：
1. **选择主流口碑品牌**：优先引入知名度较高、有产地或品种特色的水果品牌，如“褚橙”、“阿克苏冰糖心苹果”、“农夫山泉17.5°橙”。
2. **突出品牌故事与品质**：在店内陈列或宣传物料中，强调品牌水果的种植标准、产地优势（如有机认证、地理标志等），让顾客直观感知其差异化。
3. **设置试吃体验**：品牌水果的标准口感往往是核心卖点，可以针对高单价品类提供免费试吃，用味觉说服顾客。
4. **结合价格策略**：品牌水果定价需比普通品种高15%-30%，但同时标注“尝鲜价”或“产地直供”，给冲动消费一个理由。

总结：品牌水果更容易获得年轻消费者、家庭主妇等高消费意愿群体的信任，但需要配合清晰的展示和适度促销才能快速打开市场。
