对于甜品店而言，**直接买成品果丁的损耗通常更低**。以下是具体分析：

1. **鲜果切配损耗**：
   - **去皮、去芯、去眼**：菠萝的不可食用部分（外皮、硬芯、果眼）约占整果重量的**40%-50%**。例如，一个2斤的菠萝，可食用果肉仅1-1.2斤。
   - **切配技巧复杂度**：若员工经验不足，切配过程容易切掉过多果肉或处理不当导致果肉碎裂，额外增加损耗。
   - **时间与存储成本**：切好后的果丁若不立即使用，氧化变色、出水变质的速度更快（通常冷藏仅能保存1-2天），容易导致浪费。

2. **成品果丁损耗**：
   - **基本无初始损耗**：已去皮去芯，直接称重即用，几乎无重量损失。
   - **质量控制稳定**：厂商通过标准化生产，果丁大小、成熟度更统一，避免人工切配的参差不齐。
   - **存储时间略长**：通常使用真空或气调包装（如冷藏保存3-5天），进货后按需使用即可，减少因卖不完导致的报废。

**但需注意**：
- 成品果丁价格通常高于整果，需综合单价和实际得料率对比（例如：整果单价5元/斤，得肉率50%=实际果肉成本10元/斤；成品果丁单价12元/斤，若后者损耗率低且无需人工费，可能更划算）。
- 若店铺用量极大（如日均用50斤以上果丁），且切配技术熟练、能合理利用边角料（如菠萝皮熬糖浆），鲜果切配成本可能更优。

**建议**：
- 先计算“实际可用果肉成本”：整果价格 ÷ 得料率（约0.5-0.6） > 成品果丁单价？若成品更低或接近，优先选成品。
- 若选鲜果切配，务必培训员工标准化切法（如保留约1cm厚的果肉层），避免浪费。
