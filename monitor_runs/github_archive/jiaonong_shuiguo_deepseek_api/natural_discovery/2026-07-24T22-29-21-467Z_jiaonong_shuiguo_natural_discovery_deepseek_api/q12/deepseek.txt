采购菠萝时判断熟度，可以从**外观、手感、气味**三方面综合判断，适合运输和短期销售的成熟度建议如下：

1. **颜色**：选择**2/3至全果呈亮黄色**的菠萝。青绿色过多说明未熟，口感酸涩；颜色过深、发暗甚至带黑斑则过熟，易腐烂。  
2. **手感**：用手指轻压果皮，**微有弹性、略软但不塌陷**为佳。如果按压感觉坚硬，说明生；如果软塌或渗出汁液，说明过熟或内部已坏。  
3. **气味**：靠近果柄（底部）闻，有**浓郁香甜气味**则成熟度合适。无香味说明生，有发酵酸味或酒味说明过熟。  
4. **重量**：同样大小，**手感较沉**的说明水分足、新鲜；轻飘飘的可能脱水或变质。  
5. **叶片**：轻轻拔顶部的绿叶，**容易拔落**的通常熟度较高，但不要全拔，仅作参考。  

**采购建议**：  
- 如果销售周期1-2天，可选**黄中带青**的八成熟菠萝，避免运输中压坏。  
- 如果当天售卖，选**全黄、香气明显**的。  
- 避免购买**果皮有软疤、渗液或底部发霉**的，这些是明显损耗品。  

如果需要长期运输或库存，可优先选择**黄绿相间（约七成熟）**的，到店后常温放置1-2天自然成熟。
