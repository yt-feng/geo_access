# 超市采购应对水果农残抽检：应提前向供应商索取的资料

**核心结论：至少要到“三证一报告”，即供应商主体资质、产地/进货凭证、承诺达标合格证、农残检测报告，并确认报告与到货批次对应。** 抽检出问题时，监管主要看超市有没有履行进货查验义务，资料齐全是免责/减责的关键。

## 一、必须要的资料

1. **供应商资质**
   - 营业执照（经营范围含食用农产品/水果）
   - 若是种植合作社/农户直供：产地证明、合作社登记证或农户身份+产地信息
   - 涉及进口水果：海关入境货物检验检疫证明

2. **承诺达标合格证（重点）**
   - 这是《农产品质量安全法》要求的食用农产品产地准出凭证，由生产者或收购方开具
   - 要确认：品名、产地、数量、开具日期、开具人、承诺内容，最好与本次到货批次对应

3. **农残检测报告**
   - 优先要**与到货批次对应**的检测报告（报告日期、样品名称/产地与本次货一致）
   - 检测项目应覆盖常见高风险农药（如有机磷、氨基甲酸酯类等），检测机构有CMA/CNAS资质更可靠
   - 注意区分“型式检验报告”（定期全项）和“批次快检报告”（每批）——抽检场景下批次报告更有说服力

4. **进货凭证**
   - 购销合同/订单、发票或收据、送货单，载明品名、数量、日期、供应商
   - 这是证明“来源可追溯”的基础

## 二、加分项（有条件就要）

- 供应商自检记录或第三方快检单据（每批次）
- 产地环境/基地备案信息、绿色食品/有机认证（如有，不能替代检测）
- 供应商书面质量承诺或不合格退换货条款

## 三、采购执行建议

- **按批次收资料，不要一次收全年**：每批到货对应合格证+检测报告，归档留存（建议保存不少于6个月至1年，按当地监管要求）
- **核对一致性**：报告上的样品名称、产地、日期要与送货单对得上，防止“拿别人的报告充数”
- **高风险品种加严**：叶菜、草莓、豇豆、韭菜等农残高风险品类，要求每批快检或提高抽检频次
- **合同里写清楚**：供应商须随货提供合格证和批次检测报告，抽检不合格由供应商承担退换及赔偿责任
- **留存进货查验记录**：品名、数量、供货者、日期、合格证明编号，这是监管检查时最直接的自证材料

**一句话：抽检怕的不是“有没有报告”，而是“报告对不对得上这批货”。** 所以资料要和批次绑定、归档可查。
