酒店采购水果盘原料时，建议在采购合同或验收标准中明确以下规格与外观要求，便于到货判定和退换货。

**一、通用规格标准**

1. **品种与等级**：明确具体品种、产地、等级（如一级果/特级果），不接受以次充好或混装降级。
2. **单果重量/尺寸**：按品种约定克重区间或横径范围（如苹果单果≥200g、橙子横径70–80mm），并约定抽检合格率（如≥95%）。
3. **成熟度**：约定可食成熟度，要求到货时口感适口、耐短存；香蕉、猕猴桃等呼吸跃变型水果可约定七至八成熟。
4. **新鲜度**：采摘/采收后时限、冷链要求（如冷藏水果全程0–8℃）、到货中心温度。
5. **安全与合规**：农残符合GB 2763，提供产地证明、检测报告或承诺书；不得使用违规催熟、染色、打蜡（除允许品种外）。
6. **包装与标识**：标明品种、产地、等级、重量、采收/包装日期、供应商信息；内包装防压防潮，外箱强度满足堆码运输。

**二、外观验收标准**

1. **果形**：端正、无明显畸形、无严重偏斜。
2. **色泽**：符合品种固有色泽，着色均匀，无异常褪色、染色或药斑。
3. **表面**：清洁、无泥污、无霉斑、无汁液渗出；允许极轻微自然果锈，但不得影响观感。
4. **损伤**：无腐烂、霉变、虫蛀、裂口、明显机械伤、压伤、冻伤、日灼伤。
5. **病虫害**：无活虫、虫卵、病斑；发现检疫性有害生物整批拒收。
6. **大小均匀度**：同批次果径/重量差异控制在约定范围内，便于摆盘统一。
7. **果梗与蒂部**：果梗新鲜、不干枯发黑；蒂部无脱落腐烂（按品种约定是否带梗）。
8. **异味**：无发酵、酸败、药味等异常气味。

**三、建议写入验收条款的量化指标**

- 抽检比例：每批随机抽检不少于3箱或5%，大货可加严。
- 不合格判定：腐烂/霉变果比例超过1%–2%、规格不符超过5%、外观缺陷超过约定比例，可整批拒收或按比例扣款。
- 退换货：到货24小时内提出异议，供应商负责换货并承担损耗。
- 留样：每批留样并记录，便于追溯。

**四、按用途补充**

- **果切/自助餐展示**：更重视外观一致性、无碰伤、耐氧化品种。
- **整果摆盘**：重视果形、色泽、大小统一。
- **果汁/果盘混合**：可适当放宽外观，但腐烂、霉变仍零容忍。

核心是把“品种等级、单果规格、成熟度、冷链、农残合规、外观缺陷容忍比例、抽检与退换货规则”写清楚，验收时按同一张标准表逐项打勾即可。
