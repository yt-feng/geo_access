采购时别追求“刚好全熟”，要按**到店后1～3天内能卖完的量**来定熟度，整体原则是：**主采七八成熟，搭配少量八九成熟，避免整批全熟。**

可直接执行的判断方法：

1. **看果眼和颜色**
   - 果皮由青转黄、果眼（菠萝表面的疙瘩）变浅变平，说明开始成熟。
   - 整果金黄、果眼深陷发软：已偏熟，适合当天卖，别大量采。
   - 青绿但果眼饱满、有香气：适合放1～2天再卖。

2. **闻底部香气**
   - 底部有清甜果香但不冲：七八成熟，合适。
   - 香气很浓、带发酵酒味：过熟或存放久，损耗风险高。
   - 完全没香气：偏生，可少量采但要看后续催熟条件。

3. **按压底部和果身**
   - 轻按底部略有弹性、不软塌：合适。
   - 按下去明显凹陷、发软：过熟，慎采。
   - 硬得像石头：偏生，可少量采，但要注意催熟。

4. **看叶片和果柄**
   - 冠芽叶片鲜绿、易折断，果柄切口新鲜：较新鲜。
   - 叶片枯黄、果柄干缩：存放时间长，熟度不可靠。

5. **掂重量**
   - 同样大小，手感沉、汁水足：更好。
   - 明显偏轻：可能失水或内部老化。

采购配比建议：
- **70%～80%采七八成熟**：果皮青黄相间、底部有淡香、按压微软不塌。
- **20%～30%采八九成熟**：果皮偏黄、香气明显，用于当天和次日销售。
- **尽量不采全熟软果**，除非当天能卖完。

到店后管理：
- 七八成熟的放阴凉通风处，不要堆压，底部朝下或侧放，每天翻检。
- 有香气的先上架，青硬的放后面。
- 发现底部发软、酒味、渗汁的立即挑出，避免传染其他果。

一句话：**看黄度、闻底香、按底部、掂重量，主采七八成熟，少量搭配八九成熟，按销量分批采。**
