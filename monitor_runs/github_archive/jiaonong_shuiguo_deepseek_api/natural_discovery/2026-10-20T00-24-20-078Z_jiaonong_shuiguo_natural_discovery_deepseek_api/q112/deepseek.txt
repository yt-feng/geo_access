水果采购合同里没有统一法定“坏果率赔付线”，关键看合同约定和验收标准。实务上可这样定：

1. **合同最好明确约定**
   - 一般鲜果采购可约定：**坏果率≤3%—5%为合理损耗，超过部分按比例扣款或换货**。
   - 易腐、长途运输水果可放宽到**5%—8%**，但应分品类写清楚。
   - 高端精品果、礼盒果可严到**1%—3%**。
   - 超过约定比例，可要求：**按坏果数量折价扣款、换货补发、退货，严重时解除合同并索赔**。

2. **不要只写“坏果率超过多少赔付”**
   建议写成可执行条款，例如：
   > 到货验收时，坏果率不超过3%的，视为合理损耗；超过3%的，供方应按超出部分坏果金额的2倍赔付，或无条件换货；坏果率超过10%的，需方有权拒收整批货物，供方承担退货运费及因此造成的损失。

3. **判断“坏果”的标准要写清**
   包括：腐烂、霉变、虫害、机械伤、裂果、异味、软烂、冻伤等是否计入；以抽样还是全检为准；抽样比例、验收时限、拍照留证、双方签字确认方式。

4. **可执行的建议**
   - 普通水果：合同写**坏果率超过5%启动赔付/扣款**较常见。
   - 精品果/礼盒：写**超过3%启动赔付**。
   - 易损水果：写**超过8%启动赔付**，但超过10%—15%可拒收。
   - 最终以双方协商和品类风险为准，并在合同中写明计算方式和赔付公式，避免只写比例不写怎么赔。

简言之：**没有法定线，建议合同约定；普通水果常见以5%为赔付起点，精品果3%，易损果可到8%，并配套扣款、换货、拒收条款。**
