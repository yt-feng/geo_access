# 商超水果采购压价不影响品质的谈法

核心思路：**别把谈判焦点放在“单价降多少”，而是放在“同样的钱买到更高出成率/更稳的品质”上。** 压价伤品质，通常是因为只压单价、不调标准，供应商只能靠降等级、掺次果、减规格来找补。

## 一、谈之前先把手里的牌做足

1. **算清到岸成本，而不是只看报价。** 把损耗率、规格（净重/毛重、单果重区间）、包装费、运费、账期、退换货条款全部折算成“可售每斤成本”。很多供应商报价低但损耗高 3–5 个点，实际更贵。用这个口径去谈，压的是真实成本。
2. **拆开谈，不要打包谈。** 价格、规格标准、账期、返利、损耗承担、促销支持分开谈。打包谈时供应商会用价格换标准，你很难发现。
3. **掌握替代与行情。** 同一单品至少有 2–3 家备选，知道产区行情和季节拐点（集中上市期议价空间最大）。手里有备选，谈判才有底气，但别用“你不降我换人”硬压，容易换来降级货。
4. **分级定价。** 把统货拆成 A/B/C 三级分别定价，明确各级的果径、糖度、外观、碰伤率。压价只压 B/C 级的采购比例和价格，A 级守住标准——这是最不伤品质的压价方式。

## 二、谈判桌上的具体话术与交换条件

- **用“量+稳定”换价，而不是单纯压价。** “我把这个单品全年 60% 的量锁定给你，按月均量下单，价格给我一个阶梯价。”稳定订单对供应商价值很大，愿意让 2–5 个点，且不需要降品质。
- **用账期换价。** 现结/短账期通常能换到更低单价，比硬压价健康得多。
- **用返利替代降价。** 谈“达成月度销量返 X%”，而不是直接砍单价。返利不改变每批货的品质标准，也便于考核。
- **明确品质条款写进合同：** 糖度下限、果径区间、碰伤/腐烂率上限、到货验收抽检比例、不合格整批退换或折价。**价格可以谈，标准不能松**，并把“降级折价”规则写清楚，供应商就不会用次果充数。
- **锁价+浮动机制。** 对价格波动大的单品，谈“基准价+行情联动”，避免行情涨时供应商偷工减料、跌时你不占便宜。
- **要求供应商给出降本方案。** “同样的品质，你能不能从包装、物流、产地直发上帮我省？”往往包装规格优化、减少二次搬运就能省 3–8%，比压果价更不伤品质。

## 三、守住品质的几条红线

- 不接受“降价但规格缩水”（毛重变净重、单果变小、箱内垫材变多）。
- 不接受口头承诺，验收标准和折价规则写进合同/订单。
- 降价后前 2–3 批加密抽检，发现降级立即按条款折价或退货，形成可信的约束。
- 给供应商留合理毛利。压到对方无利可图，短期你看不到问题，长期一定在品质和供货稳定性上找回来。

## 四、一句话总结

**压价压的是“交易条件”（量、账期、返利、包装物流、分级结构），不是“品质标准”。** 把到岸成本算清、把标准写死、用稳定订单和现结换让利，既降成本又不掉品质。
