如果只选一个核心指标，**先看切果损耗**；但真正决定“该不该卖、怎么卖”的，是把四件事分开管：

1. **切果损耗：最该优先关注**
- 它直接决定毛利和报损。
- 重点看：到货成熟度是否过高、黑心/水心比例、去皮去眼损耗率、切开后变色和出水。
- 建议动作：分批次记录“到货量—可售果肉量—报损量”，算出实际出肉率和损耗率；损耗高的供应商或批次要降量或换货。

2. **甜度：决定复购**
- 菠萝不是越甜越好卖，要看目标客群和食用方式。
- 建议用糖酸比或固定抽检：到货抽测、上架前抽测。甜度不稳定时，用试吃、分级定价、搭配促销消化。
- 甜度低但外观好的，不适合做鲜切主推，可转促销或加工。

3. **外观：决定第一眼购买**
- 外观影响陈列和转化，但不是越高越好。过度追求外观会推高采购价，还可能掩盖内在品质问题。
- 重点看：果形端正、色泽均匀、无机械伤、无软腐、冠芽新鲜。外观分级后，一级果正价，二级果鲜切或促销。

4. **大小：决定定价和场景**
- 大小影响客单价、家庭装/单人装匹配和鲜切出成。
- 不是越大越好：太大难一次吃完，太小出肉率低。建议按门店客群设2—3个规格，而不是只追大果。

**可执行的判断顺序：**
- 采购端：先卡损耗和内在品质，再谈外观大小。
- 陈列端：外观做转化，甜度做复购，大小做规格。
- 经营端：用损耗率倒推采购成熟度和供应商；用甜度抽检决定主推；用外观分级决定正价还是促销；用大小决定包装和定价。

一句话：**短期看损耗保命，中期看甜度保复购，外观和大小是定价与陈列工具，不应压过损耗和口感。**
