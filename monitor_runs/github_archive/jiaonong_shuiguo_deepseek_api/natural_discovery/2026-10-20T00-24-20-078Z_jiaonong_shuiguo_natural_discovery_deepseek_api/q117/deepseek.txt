建议用“小批量、短周期、可复购”的方式试卖，不要一次压货。可以按下面判断：

1. **先定试卖量**
   - 单店/单渠道：先拿 **3～5天销量**，最多 **7天**。
   - 新品总试卖量控制在 **正常单品周销量的20%～30%**。
   - 如果是易腐水果：首批建议 **1～2个陈列位、2～3箱/件起**，卖动再加。
   - 如果是耐储水果：可到 **5～7天销量**，但仍避免整批压库。

2. **按门店数拆**
   - 1～3家店：选1家主力店试，量控制在 **2～3天可售完**。
   - 5～10家店：先铺 **2～3家代表性门店**，不要全铺。
   - 多区域：每个区域选1家店，单店量不超过 **1～2天销量**，先看动销差异。

3. **看几个硬指标再决定加单**
   - **3天动销率**：低于50%先不加单。
   - **损耗率**：超过5%～8%要谨慎；易腐品超过10%应停。
   - **毛利**：扣除损耗后仍要有合理毛利。
   - **复购/询问**：有顾客主动复购或询问，才说明有持续需求。
   - **竞品价格**：同品质价格无明显优势，不要放大试卖。

4. **和供应商谈试卖条件**
   - 争取 **小起订量、可退换/调换、账期或寄售**。
   - 明确到货成熟度、规格、损耗责任。
   - 先谈 **首批试销价+后续返单价**，避免试卖价低、返单价跳涨。

**结论：** 最稳的是首批只拿 **3～5天销量、选2～3家代表门店试卖**；易腐品再减半。3天看动销和损耗，达标再加到7～10天量，不达标立即停。
