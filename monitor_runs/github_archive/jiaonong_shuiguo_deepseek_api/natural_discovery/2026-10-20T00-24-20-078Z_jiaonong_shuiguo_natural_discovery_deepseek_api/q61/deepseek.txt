判断香蕉批发商是否“稳定供货”，重点不是看他嘴上说有多少车，而是看**产地控制力、加工催熟能力、合同履约记录、价格波动时的表现**。给你一套可落地的判断清单：

## 1. 先分清对方是哪一类供货商
- **产地代办/种植基地**：有蕉园或长期合作农户，货源强，但未必能稳定供熟蕉。
- **催熟加工档口**：有催熟库、加工线，能稳定出熟蕉，但要看原料来源。
- **二级贩子/信息中介**：转手倒货，价格可能低，但稳定性最差。

**优先找“自己有催熟库+有固定产地合作”的一级供货商**，纯粹中间人风险最高。

## 2. 用6个问题快速试探
1. **“你蕉从哪来？哪个县/基地？能视频看园子或加工厂吗？”**  
   答不出具体产地、只说是“广西/云南那边”的，多半是倒手。
2. **“一天能稳定出几车？淡季怎么保证？”**  
   让他给近3个月的日出货记录，不是口头报数。
3. **“催熟库多大？几间？温湿度怎么控？”**  
   有库、有加工线，才具备稳定供熟蕉能力。
4. **“下雨/台风/寒潮时，货怎么补？”**  
   稳定供货商会有备选产区，比如广西+云南+老挝/越南多渠道。
5. **“价格涨的时候，你按合同走还是临时加价？”**  
   直接问，观察反应；要求写进合同。
6. **“能不能先小批量试供2-3次，再谈长期？”**  
   拒绝试供的，基本不用考虑。

## 3. 必须核验的硬证据
- **营业执照、产地证明/购销合同、检疫证明**；
- **催熟库和加工现场视频**，最好实地看；
- **近期的发货单、物流单、回款记录**（可打码）；
- **至少2个老客户电话**，问：断货频率、品质波动、涨价时是否履约、售后是否认账。

## 4. 用“小单测试”验证稳定性
不要一次压大单。建议：
- 连续**3-5次小批量试供**，间隔一周左右；
- 每次记录：到货时间、熟度、损耗率、单果重量、黑斑/烂果比例；
- 看**是否准时、是否缺斤少两、次品是否按约定赔付**；
- 故意在**价格波动或节假日**前下单，看他是否优先保你。

## 5. 合同里写死这几条
- 规格：每箱净重、果指长度/粗度、熟度（几成熟）、允许损耗率；
- 价格机制：随行就市时，**提前几天报价、涨幅上限、锁价周期**；
- 违约：延迟发货、断供、品质不达标怎么赔；
- 结算：先货后款还是定金，试供期建议**货到验收后付**；
- 备选：要求对方在断供时**48小时内协调替代货源**。

## 6. 红旗信号
出现以下情况，基本可判不稳定：
- 只肯电话/微信聊，拒绝视频看库、看园；
- 报价明显低于市场，催你打全款；
- 说不出固定产地，问多了就不耐烦；
- 没有催熟库却承诺天天有熟蕉；
- 老客户不愿意留电话或支支吾吾；
- 合同不愿写断供赔付和品质标准。

**一句话：稳定供货=产地有根、加工有库、履约有人证、波动时肯认账。先用小单试3次，再谈长期。**
