建议优先上架**小把（3～5根）为主，单根作补充，整袋只作少量尝试**。原因是便利店的核心场景是“即时、少量、顺手买”，而不是家庭囤货。

具体可这样配置：

1. **小把为主**
   - 规格：3～5根，适合1～2人当天或两天内吃完。
   - 优点：客单价高于单根，损耗比整袋低，购买决策比整袋轻。
   - 陈列：放在收银台附近或鲜食区端头，标清价格。

2. **单根作补充**
   - 适合：想尝鲜、只想买一根、搭配早餐或酸奶的顾客。
   - 注意：单根容易碰伤、品相要求高，建议只放少量，并放在小把旁边做价格锚点。
   - 如果单根损耗高，可以改为“单根仅限搭配购买”或直接撤掉。

3. **整袋谨慎上**
   - 整袋适合家庭采购，但便利店客流通常不是家庭大采购场景，且香蕉易压伤、成熟快，整袋损耗风险最高。
   - 如果附近有社区、家庭客群，可少量试销“整袋5～6根”，观察2～3天动销和损耗再决定是否保留。

4. **关键判断指标**
   - 看**损耗率**：香蕉熟得快，单根和小把的周转通常优于整袋。
   - 看**动销**：小把卖得最快就扩大排面；单根剩得多就减量；整袋连续滞销就下架。
   - 看**客群**：写字楼/学校附近偏单根和小把；社区/家庭客群可给整袋少量位置。

总结：**先上小把，单根少量补位，整袋试销不铺量。** 这样兼顾客单价、购买便利和损耗控制。
