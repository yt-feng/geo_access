可以按“引流品不提价、结构品做组合、关联品做加购”来设计，香蕉、菠萝、苹果分别承担不同角色：

**1. 组合原则**
- **香蕉做引流**：单价低、购买频次高，适合做“基础款+加购”。
- **菠萝做结构**：客单提升空间大，适合做“第二件优惠/整果+切果”。
- **苹果做稳定毛利**：耐储、家庭常买，适合做组合装和满额赠。

**2. 可直接落地的促销组合**
- **家庭果篮组合**：香蕉1把 + 菠萝1个 + 苹果4个，打包价略低于单买合计，主推“一次买齐”。
- **满额加购**：买苹果满15元，加3元换购香蕉1把；买菠萝1个，加2元换购苹果2个。用低门槛加购拉客单。
- **第二件半价**：菠萝第二件半价，适合家庭或拼单；香蕉不做直接打折，改“买2把送保鲜袋/香蕉挂架”。
- **切果关联**：整颗菠萝旁设“菠萝切块+香蕉+苹果”小份果盒，价格锚定整果，推动“整果+果盒”双买。
- **时段促销**：晚高峰做“香蕉+苹果”9.9元家庭装，菠萝做“整果特价+免费代削”，减少损耗同时提客单。

**3. 定价与陈列建议**
- 组合价按单买合计的**85%—90%**设置，避免过度折价。
- 陈列上做“三角堆头”：香蕉靠前引流，菠萝居中做主推，苹果靠后做家庭装；组合装放端头，加购品放收银动线。
- 标牌写清“单买价/组合价/省多少”，不要只写折扣。

**4. 判断是否有效的指标**
看三个数：**客单价、组合渗透率、损耗率**。如果客单价升但菠萝损耗明显上升，就减少整果主推，改切果和加购；如果组合渗透率低，优先调低加购门槛，而不是继续降价。
