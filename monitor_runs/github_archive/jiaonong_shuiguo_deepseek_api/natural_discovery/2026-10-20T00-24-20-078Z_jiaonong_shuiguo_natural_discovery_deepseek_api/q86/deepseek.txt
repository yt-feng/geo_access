一件代发水果，供应商的仓配能力不能只看“有没有仓”和“能不能发快递”，要按水果品类、订单波动和售后成本逐项卡。建议重点核验以下几类能力：

1. **产地/销地仓与温控能力**
   - 有稳定的收货、分拣、打包场地，能区分常温、冷藏（0~8℃）、部分品类冷冻需求。
   - 仓内温湿度可监控，冷藏区有备用发电或温控异常预案。
   - 对浆果、荔枝、樱桃等易腐品，能提供预冷、冷藏暂存、冰袋/保温箱方案。
   - 要能说明各温区库存容量和旺季最大日处理单量。

2. **分拣打包与标准化能力**
   - 能按SKU做分级、称重、装盒、贴标、放保鲜剂/冰袋、套防撞网。
   - 有明确的坏果率控制标准、次果剔除流程和打包SOP。
   - 能提供不同规格包装方案，并测算包装成本、破损率和运输适配性。
   - 支持定制箱贴、感谢卡、品牌包装等平台要求。

3. **订单系统与一件代发对接能力**
   - 有WMS/OMS或至少稳定的订单处理系统，能对接平台API或批量导单。
   - 支持实时库存同步、订单拦截、改址、拆合单、赠品/备注处理。
   - 有超卖和缺货处理机制，缺货时能及时反馈而不是静默延迟。
   - 能按平台要求回传发货状态和物流单号，异常订单可追踪。

4. **快递资源与履约时效**
   - 与多家快递/落地配合作，按区域和品类匹配时效产品；生鲜件有专门通道。
   - 能承诺截单时间、日均发货时效、偏远地区覆盖范围和停发区域规则。
   - 旺季有备用运力和爆单限流机制，不能只靠单一快递。
   - 能提供近30~90天准时发货率、揽收及时率、破损率、客诉率数据。

5. **售后与逆向处理能力**
   - 有坏果、压伤、腐烂的判定标准和赔付流程，能按订单快速补发或退款。
   - 能保留打包照片、称重记录、批次溯源信息，方便责任判定。
   - 有退货/拒收/拦截件的处理路径；生鲜逆向通常不宜退回，要有就地销毁或折价处理规则。
   - 售后响应时限、赔付上限、责任划分要写进合同。

6. **品控与批次追溯**
   - 收货有农残/外观/糖度/成熟度抽检，出货有批次记录。
   - 能追溯到产地、采摘日期、入库批次、打包时间和快递单号。
   - 对催熟类水果（香蕉、芒果等）有成熟度管理和催熟/暂存能力。
   - 有异常批次召回或定向拦截能力。

7. **旺季与弹性产能**
   - 明确日常单量、峰值单量、最大承接量和扩产周期。
   - 大促、节日、产地集中上市期能否加班、增人、增包材、增冷库。
   - 有爆单限流、分仓发货或临时外仓方案，避免承诺后大面积延迟。

8. **合规与保险**
   - 食品经营/生产相关资质、产地证明、检测报告齐全。
   - 有货物运输险或生鲜破损险方案，明确保价和理赔责任。
   - 包装材料符合食品接触要求，冷链记录可查。

实操建议：先让供应商提供“仓配能力表”，包括温区容量、日峰值单量、截单时间、覆盖区域、快递合作方、近90天履约与售后数据；再用小批量试单压测，重点看发货时效、坏果率、异常订单响应和赔付执行。合同里把时效、坏果率、赔付标准、缺货违约、旺季保供和数据回传写成可考核条款，不要只停留在口头承诺。
