单位采购水果出现品质不一致，验收和售后要抓三件事：**标准前置、到场可判定、凭证可追溯**。建议按下面执行。

## 一、验收前先把标准写进订单/合同

不要等到货后争执“算不算差”。采购单或合同里至少明确：

1. **品名、品种、产地、规格**：如“红富士苹果，单果直径80–85mm，果形端正”。
2. **等级和成熟度**：如“一级果，八成至九成熟”，明确允许的成熟区间。
3. **外观和口感要求**：色泽、大小均匀度、无明显碰伤、腐烂、裂口、虫眼、异味；甜度/酸度如可测，写抽检方式。
4. **允许差异比例**：建议写明“同批次不合格果比例不超过X%”，超过即整批或按比例退换。
5. **包装和到货温度**：箱规、净重、是否冷链、到货中心温度要求。
6. **验收时限和异议方式**：到货后多少小时内提出，谁到场，怎么拍照留证。
7. **售后条款**：不合格部分补发、换货、折价或退款的选择顺序和时限。

## 二、到货验收怎么做

建议采用“**先看整批、再分层抽样、当场记录**”的方式：

1. **核对单据和数量**：品种、规格、数量、批次、送货单与订单一致。
2. **整批外观检查**：看包装是否破损、有无汁液渗漏、异味、霉变、明显挤压。
3. **分层抽样**：不要只查上层。按箱数抽取，每箱从上、中、下不同位置取样；大批量可按比例抽检，并记录抽样数量。
4. **逐项判定**：
   - 大小、色泽、果形是否均匀；
   - 碰伤、压伤、裂果、腐烂、虫害比例；
   - 成熟度是否一致，是否过生或过熟；
   - 净重是否足称；
   - 冷链品测到货温度。
5. **现场留证**：对不合格果拍全景、特写、称重照片或视频，记录箱号、批次、抽样数、不合格数，双方签字确认。
6. **分类处理**：
   - **轻微不一致**：按不合格比例折价，或挑出不合格部分补发；
   - **明显不一致**：整批拒收或换货；
   - **局部问题**：合格部分先收，不合格部分单独封存，等供应商确认后退换，避免混放导致责任不清。

关键点：**不合格品单独隔离并贴标识**，不要和合格品混放；验收记录要能对应到具体箱号和批次。

## 三、售后怎么处理

1. **限时反馈**：到货验收发现的问题，当天或合同约定时限内书面通知供应商，附照片、抽样记录和数量。
2. **先协商处理方式**：按合同优先级处理，通常为补发合格品、换货、按比例折价、退货退款。腐烂、霉变、异味等食品安全风险项，应直接隔离并退货，不建议折价使用。
3. **补换货再验收**：补发或换货到场后重新抽检，不合格仍按同一标准处理。
4. **保留凭证**：订单、送货单、验收记录、照片视频、沟通记录、退换货单、退款凭证都要归档。
5. **结算挂钩**：未处理完的售后争议，暂缓对应批次结算；折价或扣款金额在结算单中写明依据。
6. **供应商评价**：同一供应商反复出现品质不一致，记录到供应商考核，必要时调整采购份额或更换供应商。

## 四、给单位的落地建议

- 指定**固定验收人+复核人**，避免一个人说了算。
- 制作一张简单《水果验收单》：批次、抽样数、不合格数、不合格比例、处理意见、双方签字。
- 对易腐水果尽量**到货即验**，不要隔夜再验。
- 单位内部领用前再抽看一次，发现储存导致的变质要与到货品质问题区分开。

一句话：**验收靠抽检比例和留证，售后靠合同条款和书面记录。** 标准越具体，现场越好判断，售后越少扯皮。
