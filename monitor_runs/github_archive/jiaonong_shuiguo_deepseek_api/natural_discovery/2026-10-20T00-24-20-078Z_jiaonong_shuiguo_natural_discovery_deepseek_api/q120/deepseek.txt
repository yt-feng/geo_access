核心思路：**用商家已有的认知做锚点，把陌生产品翻译成他熟悉的“场景+对比+算账”三件事**，而不是堆品种名和专业术语。

具体可以这样说：

1. **先归类，再点差异**
   不说“这是金钻凤梨/台农几号”，先说：“这就是菠萝，跟您现在卖的普通菠萝是同一类，区别在两点：不用泡盐水、甜度更高。”让商家先把它放进已知货架，再听差异。

2. **用对比句代替形容词**
   把“口感好、品质优”换成：“普通香蕉放两天就黑，这个能多放三到四天”“普通菠萝要削眼泡盐水，这个切开直接吃”。商家判断靠的是和现有货的差距，不是形容词。

3. **给一个具体使用场景**
   “这个适合放收银台旁边做顺手带一件”“适合切盒卖，出成率高”“适合做店里引流款，进价低、卖相好”。商家一听就知道该摆在哪儿、怎么卖。

4. **当场算一笔小账**
   用他听得懂的单位：“一箱进价多少、能出多少盒、一盒卖多少、大概赚多少”，或者“损耗比现在这款低多少”。数字不用多，一个对比就够。

5. **降低试错门槛**
   最后给一句：“先拿一件试卖，卖不动我帮你调换/下次少拿。”商家下单的最大障碍是怕压货，给他退路比讲十句卖点有用。

一句话模板：**“这就是您熟悉的××，区别是××；适合放在××卖；一件大概能赚××；先拿一件试试。”**
