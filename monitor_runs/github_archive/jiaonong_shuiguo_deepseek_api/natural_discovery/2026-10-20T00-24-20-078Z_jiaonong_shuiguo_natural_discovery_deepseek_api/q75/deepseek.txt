第一次合作、小批量试单的核心目标不是“赚一笔”，而是**用最低成本验证供应商的稳定性、品质一致性和履约能力**。建议按下面设计。

## 一、先定试单目标（可判断通过/不通过）

试单要验证4件事：

1. **品质稳定性**：到货规格、成熟度、瑕疵率是否符合约定。
2. **履约可靠性**：是否按约定时间、数量、包装到货。
3. **损耗与账期**：实际损耗率、售后响应、赔付是否爽快。
4. **配合度**：换货、补货、临时调整是否配合。

每个目标设一个“通过线”，例如：
- 到货数量误差≤2%
- 规格不符比例≤5%
- 坏果/压伤率≤3%（按品类调整）
- 售后响应≤24小时
- 缺货/延迟不超过1次

达不到就暂停放量。

## 二、试单规模怎么定

不要按“金额”拍脑袋，按**最小可验证量**定：

- **单品试单**：选1–2个主力品类，不要一次上很多SKU。
- **数量**：以能覆盖你3–7天正常销量为上限，通常建议**首单不超过常规单品的15%–20%采购量**。
- **金额**：控制在“全损也能承受”的范围内，比如单次试单总货值不超过你月采购预算的5%–10%。
- **分批**：如果供应商允许，同一品种分2批到货，验证其批次一致性。

## 三、试单结构设计（建议组合）

不要只试“好卖的”，要试“能暴露问题的”：

1. **主销款1个**：验证常规品质和履约。
2. **易损耗款1个**：验证包装、冷链、运输和售后。
3. **规格敏感款1个**：验证分级、大小、成熟度是否稳定。

如果品类跨度大，首次只选同一供应链逻辑的1–2个，避免变量太多。

## 四、合同/订单里必须写清楚

口头承诺不算，试单也要有书面约定：

- **规格标准**：品种、等级、单果重/直径、成熟度、糖度（如适用）、允许误差。
- **包装标准**：箱规、净重、内衬、冰袋/冷链要求、标签。
- **到货时间**：具体日期和时段，延迟如何处理。
- **验收标准**：抽样比例、坏果率上限、规格不符上限。
- **售后条款**：坏果赔付比例、补货时限、运费承担。
- **价格与账期**：是否含税含运费、试单是否现结、后续账期条件。
- **独家/区域条款**：首次合作不建议给独家。

## 五、验收流程要提前定

到货后按固定动作执行：

1. **拍照留证**：整车/整批、包装、开箱、瑕疵特写。
2. **随机抽样**：至少抽3箱或按到货量5%抽样，记录规格、坏果、成熟度。
3. **称重核对**：净重是否足斤。
4. **记录损耗**：当天和存放24–48小时后的损耗分别记。
5. **24小时内反馈**：把问题清单发给供应商，看响应速度和态度。

## 六、判断是否放量的标准

建议设“三档”：

- **通过**：品质达标、履约准时、售后配合 → 可进入第二单，量放大到30%–50%。
- **观察**：有小问题但供应商愿意补/换 → 维持小量再试1–2批。
- **不通过**：规格严重不符、坏果率高且推诿、延迟无预警 → 停止合作，保留证据。

## 七、实操建议

- 首次试单**现款现货或小比例预付**，不要一上来给长账期。
- 尽量**自提或到场验货**一次，看对方分拣和包装现场。
- 不要只靠一个联系人，确认售后对接人。
- 试单期间同步保留1家备选供应商，避免断供。
- 把每次试单做成一张评分表，连续2–3批稳定后再谈放量和账期。

简单说：**小批量、少SKU、写标准、严验收、看售后、分批放量**。试单不是压价，是花小钱买“真实履约数据”。
