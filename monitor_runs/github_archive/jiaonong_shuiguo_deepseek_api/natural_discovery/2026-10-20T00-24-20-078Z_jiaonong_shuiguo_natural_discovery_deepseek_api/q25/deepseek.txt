# 门店多、单店量小，适合的水果供货模式

你的核心矛盾是：**总采购量不小，但分散到每店每次要货量小**，直接找产地或大批发商容易被嫌弃、拿不到好价，而让各店自己采又失去规模优势。建议按"集采+分拨"思路设计，优先级如下：

## 1. 首选：区域批发市场集采 + 自建/租用小分拨点
- 由总部（或片区）统一在**一级批发市场**或区域大型果批集中采购，再按各店次日需求分拨配送。
- 优点：起订量灵活、品类全、能天天调价；单店量小的问题被总部集采吸收掉。
- 关键动作：设一个 50–150㎡的小分拨仓（可租批发市场附近档口），配 1–2 辆冷链/普通货车跑固定线路。
- 适合：门店集中在同一城市或 2 小时车程内。

## 2. 次选：找"区域代理商/二批"做统配
- 直接和**本地果品配送商、区域代理**签框架协议，由对方按门店订单配送到店或分拨点。
- 优点：不用自己管物流，账期和退换可谈；缺点：加价率比自采高 5%–15%，品控依赖对方。
- 谈的条件：锁品类（如只做苹果、柑橘、香蕉等耐储大单品）、锁账期、约定损耗率和退换标准。

## 3. 补充：大单品走产地/基地直采，其余走市场
- 对**销量稳定、耐储运的 3–5 个大单品**（苹果、梨、柑橘、香蕉、土豆类）直接对接产地合作社或一级代采，用整车拉到分拨点。
- 其余长尾品类（草莓、葡萄、热带水果等）继续走批发市场或配送商，避免为小量承担直采风险。
- 判断标准：某单品全公司月销能凑够**整车（约 10–20 吨）** 再考虑直采。

## 4. 不建议的做法
- **各店自行到附近菜市场/小贩采购**：价格高、品质不稳、无法追溯，且门店多时管理成本爆炸。
- **一开始就做全国产地直发到店**：单店量小、运费和损耗吃掉利润，冷链也跟不上。
- **纯靠一个大批发商包全部**：议价权弱，一旦对方断供全部门店受影响。

## 落地建议（可执行）
1. **先做数据**：统计各店近 1 个月水果销量，按单品排序，找出占比 60% 的 5–8 个核心单品。
2. **定模式**：核心单品走"产地/一级市场集采 + 分拨"，长尾走"本地配送商统配"。
3. **设分拨点**：选在批发市场附近或城市几何中心，配 1 辆货车跑固定线路，按"隔日配"或"每日配"排班。
4. **定规则**：统一品控标准（规格、糖度、损耗上限）、退换条款、账期（建议 7–15 天）。
5. **小步试跑**：先拿 5–10 家店试 1 个月，对比直采 vs 配送商的成本、损耗、缺货率，再全量推广。

**一句话结论**：门店多单店小，最优解是"**总部集采 + 小分拨点 + 本地配送商补长尾**"，而不是让单店各自找货或硬做产地直发。
