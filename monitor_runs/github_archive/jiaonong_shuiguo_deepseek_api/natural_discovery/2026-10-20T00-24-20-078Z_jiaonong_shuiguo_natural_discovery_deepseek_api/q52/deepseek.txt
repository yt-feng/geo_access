采购香蕉做甜品，关键不是“买最黄的”，而是**买成熟度合适、耐放且到店后能控温控乙烯**。给你一套可执行做法：

1. **按用途选成熟度**
   - 当天/次日用：买**黄中带少量褐斑**的，香气足、可直接用。
   - 2–3天用：买**通体黄、两端略绿**的，到店后逐步熟。
   - 3天以上用：买**绿黄、硬身**的，回店后分批催熟。
   - 不要一次全买全黄，甜品店最怕集中过熟。

2. **采购时避开“暗伤”**
   - 看果柄和果身：有**压伤、裂口、水渍状软斑**的不要，黑斑会从伤口扩散。
   - 摸硬度：整体硬实、无局部软塌。
   - 闻味道：有酒味、酸味说明已过熟。
   - 整把香蕉检查中间层，避免外层好、内层压坏。

3. **运输别闷、别压、别冷藏**
   - 用周转筐平放，最多两层，避免堆压。
   - 不要用塑料袋密封，乙烯和热量会加速变黑。
   - 夏季避免放后备箱闷热，短途也要通风。
   - 香蕉**未切开前不要冷藏**，低温会导致皮黑、果肉僵化。

4. **到店后立即“拆把、分级、控乙烯”**
   - 拆开整把，按成熟度分筐：今天用、明天用、后几天用。
   - 用剪刀剪成小把，保留短果柄，减少伤口。
   - 成熟香蕉和未熟香蕉**分开存放**，成熟香蕉释放乙烯会催熟其他香蕉。
   - 可把成熟香蕉放通风阴凉处，理想温度约**13–15℃**，避免空调直吹和阳光直射。
   - 不要和苹果、梨、番茄等乙烯释放大的果蔬混放。

5. **到店后快速降温但别冻伤**
   - 夏天到店后先摊开通风散热，不要立即密封进冷库。
   - 若必须冷藏延缓，只适合**已成熟且短期使用**的香蕉，温度别低于约12℃，且用纸包/透气袋防冷凝水。
   - 切开后的香蕉立即用柠檬汁/维C水防氧化，并冷藏，当天用完。

6. **采购节奏比保存更重要**
   - 甜品店建议**少量多次**采购，按2–3天用量下单。
   - 建立“到货成熟度—使用日期”标签，先进先出。
   - 对过熟香蕉不要扔，可做香蕉泥、磅蛋糕、奶昔、冷冻果泥，减少损耗。

一句话：**买绿黄硬身、分成熟度拆把、通风避压避乙烯、少量多次采购**，比单纯追求“黄香蕉”更能避免到店后很快变黑。
