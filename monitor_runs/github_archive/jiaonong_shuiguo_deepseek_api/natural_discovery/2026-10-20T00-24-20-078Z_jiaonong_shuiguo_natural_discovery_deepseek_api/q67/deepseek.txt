和品牌方谈代理时，区域保护和串货不要笼统问“有没有保护”，要拆成可写进合同的具体条款来问。建议按下面几组问题逐条确认，并明确要求写进合同而非口头承诺。

**一、区域保护怎么问**

1. 授权区域边界：是市、区县还是具体渠道（商超/水果店/电商）？边界以什么为准？
2. 独家性：这个区域内是否只授权我一家？还是允许开第二家、第三家？什么条件下会增开？
3. 保护期限：区域独家有效期多久？续约条件是什么？完不成任务会不会被取消或缩小区域？
4. 线上归属：品牌自营电商、直播、社区团购是否算进我的区域？它们在本地发货算不算侵入我的区域？
5. 品牌方直供：品牌方是否会给本区域内的大客户、连锁商超直接供货？若直供，价格是否不低于给我的供货价？
6. 跨区来源：其他区域经销商把货卖到我区域，品牌方怎么处理？我举报后多久响应、怎么核实、怎么处罚？
7. 保护的具体形式：是书面独家授权书、区域编码、还是只在合同里写一句？要求写明违约后果（扣返利、罚款、取消授权、终止供货等）。

**二、串货怎么问**

1. 定义：什么算串货？跨区域销售、线上低价倾销、给非授权渠道供货，分别怎么认定？
2. 溯源手段：产品有没有区域码/批次码/一物一码？能否通过码查到出货经销商？这是追责的前提，要问清楚。
3. 举报流程：我提供什么证据（照片、订单、物流单、条码）？品牌方多久给书面回复？处理结果是否告知我？
4. 处罚力度：对串货方是警告、罚款、扣保证金、停货还是取消代理？处罚是否与我方损失挂钩？
5. 我的责任：我被认定串货的判定标准和申诉渠道是什么？误判怎么纠正？
6. 价格体系：各区域供货价、建议零售价是否统一？价差过大本身就是串货诱因，要问品牌方如何控价。

**三、必须落到合同里的点**

- 授权区域、渠道、期限、独家性写明；
- 串货定义、溯源方式、举报与处理时限、处罚标准写明；
- 品牌方直供和线上销售的边界写明；
- 违约救济：我因串货受损时，品牌方承担什么责任（补差、调货、赔偿、解约退款）；
- 争议解决方式和保证金/返利扣减规则。

**四、判断品牌方是否靠谱的几个信号**

- 只说“放心，我们管得很严”但拿不出溯源方案和处罚案例的，风险高；
- 合同里区域写成“以公司通知为准”或“非独家”的，等于没有保护；
- 不愿意写串货处罚条款的，基本说明它没有控盘能力或不想控；
- 可以要求看近一年处理串货的记录或至少说明处理流程，看是否具体。

谈的时候建议带一份问题清单逐项要书面答复，把口头承诺转成合同条款再签。
