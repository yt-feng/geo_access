最省心的是**本地水果批发商/配送商里专做餐饮小B客户的那种**，不是大型批发市场随机摊位，也不是生鲜电商平台。

**优先级建议：**

1. **本地餐饮食材配送商**（主做饭店、食堂、奶茶店的）  
   优点：能按天/隔天送，起送量低，可开票，缺货能临时补。  
   找法：问附近餐馆老板、在本地餐饮群问、搜“城市名+餐饮食材配送/水果配送”。  
   重点问清：起送金额、配送费、临时加单截止时间、坏果怎么赔。

2. **本地水果批发市场的固定档口**  
   选有稳定档口、愿意做小单配送的，谈“每天固定时间送、按当天报价结算”。  
   比配送商便宜，但需要你每天确认品项和价格，省心程度稍低。

3. **产地/一级代理直供**  
   只适合单一水果用量稳定且量稍大的店；每天少量、品类杂的话不划算。

**不建议：** 生鲜电商平台（价格波动大、售后流程长）、路边流动摊贩（不稳定、无票据）、大型商超（成本高）。

**签约/合作前必须确认5件事：**
- 起送量和配送费，少量是否加价；
- 每天几点前下单、几点送达；
- 缺货时是否可换品或次日补；
- 坏果/不新鲜怎么赔（拍照即赔还是下次抵扣）；
- 是否支持月结和开票。

**最省心的组合：** 主供应商1家做日常配送，备用1家应对缺货；每天只报“品类+数量+可接受价位”，让供应商按当天好货配，减少你比价精力。
