做批发生意，收货验货要卡在“当场发现、当场记录、当场签字”这三步上，目的是把责任定在货物离场或离店之前。下面给一套可以直接执行的做法。

**一、收货前先定规则**
- 和供应商/物流方提前约定验货时限：到货后多少小时内提出外观、数量异议有效，超时视为认可。
- 在采购单、送货单或合同里写明验收标准：品名、规格、颜色、数量、包装完整度、次品率上限、退换货条件。
- 明确“隐蔽瑕疵”怎么处理：外观当场验，功能/材质问题允许在约定期限内复检，但需保留原包装和批次证据。

**二、到货先查单据，再动货**
1. 核对送货单与采购单：品名、型号、规格、数量、批次、单价是否一致。
2. 检查外包装：有无破损、水渍、挤压、二次封箱、标签涂改。
3. 发现外包装异常，先拍照/录像再开箱，拍清运单号、箱体、封口。
4. 数量清点：整箱抽点加重点品类全点，别只信送货单上的数字。

**三、开箱验货按“先外后内、先量后质”**
- 外观：颜色、尺寸、做工、污渍、划痕、变形。
- 规格：与样品或订单参数逐项对照，尤其是服装鞋帽的码数、颜色色差，电子配件的型号版本。
- 数量：按箱清点，抽检比例可按品类定，高退货品类建议全检或高比例抽检。
- 功能/材质：需要通电、试穿、试用的，抽检并记录结果。
- 拍照留证：整批全景、问题单品特写、包装标签、批次号同框，最好带时间水印。

**四、验收结果当场签字确认**
- 合格品：在送货单上签“数量相符、外观验收合格”，别签“货已收到，一切无误”这类兜底话。
- 有问题：当场在送货单备注问题项，列明数量、批号、问题描述，要求送货人签字；对方不签就拍照录像并同步通知供应商。
- 建立验货记录表：日期、供应商、单号、批次、抽检数、不良数、问题类型、处理结果、签字人。

**五、把验货结果接入退货管理**
- 按供应商和品类统计退货原因，区分“到货即发现”和“售出后退回”。
- 高退货品类提高抽检比例，问题频发的供应商要求发货前预检或加严验收条款。
- 对下游客户发货时，同样拍照留底、附批次信息，避免客户退货时说不清是哪一批。

**六、几个容易被忽略的点**
- 别在货物已上架、已拆散后再补验，责任很难界定。
- 退货纠纷多数败在“没有当场证据”，照片视频要能对应到具体批次和送货单。
- 口头约定不算数，验货时限和标准要落在单据或聊天记录里。
- 对“先签字后卸货”的物流，签字前先看外包装，有问题在签收单上注明再签。

一句话：验货不是看一眼，而是“单据对得上、数量点得清、问题拍得下、责任签得明”。把这四件事做成固定动作，退货纠纷会明显下降。
