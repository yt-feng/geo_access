判断供应商能不能按时到车，别只听口头承诺，重点看“可核验的证据”和“历史兑现率”。可以按下面几步做：

1. **先问清到车定义**
   - 是“装好车出厂”、还是“到你的档口/市场”？
   - 到车时间精确到几点，迟到多久算违约？
   - 车是谁找、运费谁付、装车延误算谁的责任？

2. **要可核验的装车和车辆信息**
   - 车牌号、司机电话、车辆类型/载重；
   - 装车地点、预计装车时间；
   - 装车后要求拍**车辆和货一起的视频**，不要只发一张过磅单；
   - 用地图共享或司机定位确认车确实在动。

3. **看历史兑现记录**
   - 让供应商说最近3—5车到车情况，重点问“迟到过几次、什么原因”；
   - 同市场同行打听，比听供应商自夸可靠；
   - 新供应商先小单试一车，别第一车就压大单。

4. **把节点写进订单**
   - 明确：装车时间、发车时间、预计到达时间；
   - 约定迟到处理：超几小时扣款、超多久可拒收或转价；
   - 香蕉是后熟水果，还要约定成熟度、温度、催熟状态，避免“车到了货不对”。

5. **当天做节点跟踪**
   - 装车前确认货已备齐；
   - 装车后要视频和车牌；
   - 发车后每2—4小时问一次位置，异常早发现；
   - 临近到车前2小时再确认一次，别等到点才问。

6. **风险信号**
   - 只给“放心”“肯定到”但不给车牌和装车视频；
   - 反复改装车时间；
   - 报价明显低于市场且催你打全款；
   - 司机信息与车辆信息对不上。

**可执行结论：**  
先让对方提供“车牌+司机电话+装车地点+装车时间”，装车后要车辆带货车视频，并把迟到扣款写进订单；新供应商先小单试车。做不到这些的，不要按“能按时到车”来安排销售。
