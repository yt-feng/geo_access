判断供应商售后是否稳定，不要只听口头承诺，建议用“问流程＋要证据＋做小测试＋写进合同”四步核验：

1. **先问清售后流程**
   - 质量问题（烂果、黑心、催熟不均、香蕉青硬或过熟）多久内响应？多久给处理方案？
   - 谁对接：业务员、售后专员还是老板？是否有备用联系人？
   - 处理方式：补货、换货、折价、退货还是下次抵扣？运费谁承担？
   - 异常时段：节假日、凌晨到货、雨天到货是否同样响应？

2. **要可核验的证据**
   - 近3个月售后记录：投诉次数、平均响应时长、处理结果，最好有聊天记录或售后单截图。
   - 合作商超名单及可回访联系人；不愿给可模糊处理，但至少能说明服务过哪些业态。
   - 是否有固定售后电话/微信群、值班表、异常上报模板。
   - 注意：不要轻信“我们售后很好”，要看记录和可回访对象。

3. **做小批量压力测试**
   - 首单不要大，故意在到货后按合同时限内提一次合理质量异议，观察响应速度和方案。
   - 测试非工作时间：比如傍晚或周末发一条售后消息，看是否有人接。
   - 记录：首次回复时间、给出方案时间、实际补换货时间。连续2—3次都稳定，才算可靠。

4. **写进采购合同或订单条款**
   - 明确响应时限：如到货后2小时内响应、24小时内给方案、48小时内补换货。
   - 明确质量标准和赔付：烂果率、黑心率、香蕉成熟度范围、低于标准如何折价。
   - 明确售后联系人、备用联系人、违约处理。
   - 约定“售后响应不达标可暂停后续订单或扣款”。

**可执行判断标准：** 首次回复≤2小时、方案≤24小时、补换货≤48小时，且连续3次小单测试都做到，可认为售后较稳定；若第一次就拖到第二天、只口头答应不落单，基本不可靠。菠萝重点看黑心、烂心、运输磕碰；香蕉重点看成熟度、催熟一致性和到货后损耗，售后条款要分别写清。
