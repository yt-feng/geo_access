这四种水果做礼盒，关键不是“都放一点”，而是**按场景分价位、按耐运输性分组合**。香蕉和菠萝最容易拉低礼盒质感，建议少用或只做低价款。

**推荐组合，直接可上架：**

1. **基础走量款（58—88元）**
   - 苹果6个 + 橙子6个 + 香蕉1把
   - 卖点：日常探病、办公室分享，价格低、出货快
   - 注意：香蕉选青一点，避免当天发黄发黑

2. **主推利润款（98—138元）**
   - 苹果6个 + 橙子6个 + 菠萝1个
   - 卖点：颜色橙红黄搭配，送礼有分量，耐放
   - 菠萝选小果，提前削皮装盒或整只带叶，二选一

3. **高端送礼款（158—198元）**
   - 苹果8个（选大果、贴字或精品果）+ 橙子8个 + 菠萝1个
   - 不放香蕉，避免拉低档次
   - 用硬质礼盒、分层摆放、加贺卡

4. **企业团购/节日款**
   - 苹果+橙子为主，菠萝点缀，香蕉可换成小番茄或提子
   - 统一规格、统一标签，方便批量交付

**搭配原则：**
- **苹果、橙子做主角**：耐放、寓意好、颜色正。
- **菠萝做视觉点**：1个就够，多了占空间且扎手。
- **香蕉只做低价款**：易压伤、易变黑，不适合高端礼盒。
- **比例建议**：苹果和橙子占70%—80%，菠萝10%—20%，香蕉只在低价款出现。

**好卖的关键：**
- 做3个明确价位，不要让顾客自己拼。
- 礼盒上标“送长辈”“送同事”“节日款”，比只写水果名称好卖。
- 香蕉单独用纸托固定，菠萝切口包保鲜膜，苹果橙子套网套。
- 先试销10—20盒，记录哪个价位卖得快，再调整组合。
