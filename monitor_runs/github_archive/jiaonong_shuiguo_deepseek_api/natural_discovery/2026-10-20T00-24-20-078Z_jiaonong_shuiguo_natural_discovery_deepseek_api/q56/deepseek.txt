茶饮店控制水果供应商食品安全风险，核心是“证照合规＋检测合格＋来源可追溯＋现场卫生可控”。可按以下清单索证，并做成供应商档案。

**一、主体资质类**
1. 营业执照（经营范围含水果销售/农产品销售等）。
2. 食品经营许可证或食品生产许可证（若供应商为食品经营者/加工者；仅销售食用农产品的情况各地要求不同，需向当地市场监管确认）。
3. 法定代表人/负责人身份证明及授权委托书、对接人联系方式。

**二、产品合格与检测类**
1. 每批次水果的产地证明或进货凭证、销售凭证。
2. 农药残留检测报告：优先要求每批次或定期（如每周/每月）第三方检测报告；无法每批提供时，至少要求供应商自检记录＋定期第三方报告。
3. 重金属、霉菌毒素等风险项目检测报告（按水果品类和当地监管要求，如苹果汁原料关注展青霉素等）。
4. 若为进口水果：海关入境货物检验检疫证明、报关单等。
5. 若供应商声称“有机/绿色/地理标志”等：对应认证证书。

**三、来源追溯类**
1. 供货清单/送货单：品名、规格、产地、批次、数量、日期、供应商盖章或签字。
2. 上游采购凭证或产地合作社/基地信息，确保可追溯到具体批次。
3. 承诺书：承诺不掺杂使假、不使用禁用农药、不销售变质水果。

**四、储运与卫生类**
1. 运输车辆卫生、温控记录（冷链水果需冷藏运输温度记录）。
2. 包装材料合规证明（食品级包装或符合农产品包装要求）。
3. 供应商食品安全管理制度、从业人员健康证明（接触直接入口水果或分切水果时尤其重要）。

**五、茶饮店内部管理动作**
1. 建立供应商准入审核表，证照过期前提醒更新。
2. 每批到货验收：感官检查（腐烂、霉变、异味）、温度、数量、票据核对，留样或拍照记录。
3. 对高风险水果（如草莓、葡萄、切果）提高抽检频次；分切水果按即食食品要求管理。
4. 保留索证索票和验收记录至少产品保质期满后6个月；无明确保质期的，保存不少于2年（以当地监管要求为准）。

**可执行判断标准**：证照齐全且在有效期内、每批有票据可追溯、农残检测合格、运输卫生可控、到货验收无腐烂霉变，才算风险可控。若供应商只能提供营业执照、无法提供批次检测或来源凭证，应列为高风险供应商，限制采购或更换。
