进货量不大时，一般更建议找**固定供应商**为主，批发市场作为补充。原因：

1. **价格未必差很多**：批发市场看似便宜，但小批量拿货没有议价权，加上交通、时间、退换货成本，未必比固定供应商划算。
2. **供应稳定性更重要**：小店最怕断货。固定供应商可以提前沟通库存、送货上门、缺货调货，批发市场每次都要重新找货、比价。
3. **账期和售后**：固定供应商做熟后可能给小额度账期、允许少量退换；批发市场通常现款现货，售后难。
4. **品质一致性**：小店靠回头客，固定供应商更容易保证批次稳定。

具体可以这样做：

- **先找2-3家固定供应商**，小批量试单，比较价格、送货、售后和响应速度。
- **保留一个批发市场渠道**，用于临时补货、试新品、比价。
- **和固定供应商谈条件**：少量起送、固定送货日、滞销品少量调换、月结或周结。
- **不要只依赖一家**，核心品类至少备一家备用供应商。

例外：如果你卖的是**季节性强、款式变化快、每次进货品类差异大**的商品，批发市场的灵活性更重要，可以以市场拿货为主，但也要逐步沉淀几家熟悉的档口。
