很重要，而且对便利店这种业态尤其关键。核心原因是：水果销量不稳定时，小批量试卖能力直接决定**试错成本**和**现金流压力**。

可以这样判断供应商是否“真支持”小批量试卖：

1. **起订量是否可谈**  
   - 单店单SKU能否低到几箱/几公斤，而不是必须整托盘。
   - 是否允许按周、按店调整起订量。

2. **配送频次与拆零能力**  
   - 能否一周多次配送、拆箱拆筐。
   - 小批量是否加收高额配送费或拆零费，这会抵消试卖价值。

3. **损耗与退换责任**  
   - 试卖品出现品质问题、临期或滞销时，能否换货、调拨或承担部分损耗。
   - 没有退换机制的小批量，本质只是把库存风险转给门店。

4. **账期与结算灵活度**  
   - 小批量试卖若要求现结或押金过高，会削弱试卖意义。

5. **数据反馈配合**  
   - 供应商是否愿意根据门店销量数据调整品类和补货量，而不是只负责送货。

**结论：**  
如果供应商只能大批量供货、不拆零、不换货，水果销量不稳定时门店很容易被库存和损耗拖住；能支持小批量试卖的供应商，价值不只是“少进货”，而是让门店用较低成本验证品类、定价和补货节奏。建议把“小批量试卖”写进合作条件，明确起订量、配送频次、损耗责任和退出机制，再决定是否长期合作。
