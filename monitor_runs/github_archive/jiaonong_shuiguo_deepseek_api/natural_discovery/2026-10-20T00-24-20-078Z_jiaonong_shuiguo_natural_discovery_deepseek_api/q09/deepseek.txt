旺季谈供应商，核心不是“多进点货”，而是把**保供能力、锁价规则、缺货责任、补货时效**提前问清楚。建议按下面问，并尽量落到书面/微信确认。

**1. 先问保供能力**
- 旺季你每天/每周最大能稳定供我多少箱？最低起订量多少？
- 哪些单品旺季最容易断？你一般提前多久备货？
- 如果我临时加单30%—50%，提前几小时/几天说能接住？
- 你有没有备用产地/备用冷库？主产区天气或运输出问题时怎么补？

**2. 问价格和锁价**
- 报价是随行就市还是可以锁价？锁价锁多久、锁哪些规格？
- 涨价提前几天通知？我确认前能不能按原价执行？
- 旺季有没有“保供加价”“优先供货费”？怎么算？
- 运费、装卸、损耗、包装费谁承担？到店价还是产地价？

**3. 问品质标准和验收**
- 每批的等级、规格、成熟度、糖度、大小、瑕疵率标准是什么？
- 到店验收不合格怎么算？当场拒收、换货还是折价？
- 损耗率超过多少由你承担？比如烂果、压伤、冻伤怎么赔？
- 能否每批提供产地/检测/采摘日期信息？

**4. 问缺货和违约**
- 你承诺的供货量没做到，怎么补？多久补？有没有违约金或补偿？
- 我下了订单你临时说没货，我临时从别处高价调货的差价谁承担？
- 连续几次缺货，我能不能终止合作？已付货款怎么退？
- 不可抗力（天气、封路、疫情）怎么界定？提前多久通知？

**5. 问补货和配送**
- 每天几点前下单、几点送到？旺季能不能一日两配？
- 临时补货最晚几点前说？加急配送费怎么算？
- 送货迟到影响我营业，怎么处理？
- 节假日、周末是否正常配送？司机和冷库是否稳定？

**6. 问结算和账期**
- 现结、周结还是月结？旺季能不能给账期或备货金？
- 押金/保证金多少？合作结束多久退？
- 退货、换货、折价的货款怎么冲抵？
- 发票怎么开？税率和开票时间？

**7. 问合作保障**
- 能不能签旺季保供协议，把供货量、价格、缺货责任写进去？
- 能不能给我一个“优先供货”档位？需要预付或包量吗？
- 有没有同区域其他水果店也在供？会不会优先给别人？
- 如果我想做独家单品或区域保护，条件是什么？

**实操建议：**
- 不要只听口头承诺，把**每日保底量、加单提前期、缺货补偿、锁价期限**四项写进微信或合同。
- 旺季前先做**小批量压力测试**：连续一周按旺季量下单，看准时率、损耗率和临时加单响应。
- 至少保留**1家备选供应商**，主力供应商问清“断供时能否介绍备用渠道”反而更实用。
- 谈判时用“我旺季稳定走量、现结/短账期”换“保供优先级和锁价”，比单纯压价更有效。
