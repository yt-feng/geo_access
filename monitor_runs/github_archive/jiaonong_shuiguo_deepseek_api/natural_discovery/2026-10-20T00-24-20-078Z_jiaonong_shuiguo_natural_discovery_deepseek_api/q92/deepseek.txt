小面积便利店做水果，核心不是“品类齐全”，而是“少SKU、快周转、强控损”。下面按可执行层面说。

**一、品类控制：只做“高频刚需+即食场景”**

1. **品类数控制在8～15个SKU**
   - 面积小、客流有限，SKU一多每个都卖不动，损耗必然上升。
   - 可按“3个引流品+5～8个常规品+2～3个季节品”配置。

2. **优先选这四类**
   - **高频刚需**：苹果、香蕉、橙子、梨——耐放、认知高、复购稳。
   - **即食便利**：小番茄、葡萄、蓝莓、切好的果切（如果条件允许）。
   - **单果/小包装**：按个卖、按小盒卖，降低顾客决策成本，也便于控制库存。
   - **季节爆品**：只选1～2个当季强需求品，做短周期试销。

3. **坚决少做或不做**
   - 易损高、客单低的：草莓、水蜜桃、熟透芒果等，除非有稳定高客流。
   - 需要大量陈列面才能出效果的：西瓜整只、大菠萝等。
   - 长尾小众品：火龙果、山竹、进口稀有果等，除非周边客群明确。

4. **用“角色”管理品类**
   - 引流品：1～2个，价格有感知，允许低毛利。
   - 利润品：2～3个，毛利较高、损耗可控。
   - 便利品：果切、小盒装，提升客单。
   - 淘汰机制：连续7天销量排名末位且损耗高的SKU直接下架，不恋战。

**二、采购控制：小批量、多频次、以销定采**

1. **按销量定采购量**
   - 用最近3～7天日均销量×安全系数（1.1～1.3）下单。
   - 新品首单只进1～2天量，试销3天再决定是否保留。

2. **提高采购频次**
   - 叶菜类、浆果类尽量日配或隔日配；苹果、橙子等耐储品可2～3天一次。
   - 小门店宁可采购价略高，也要换低库存和低损耗。

3. **采购标准前置**
   - 明确规格：单果重量、成熟度、包装规格。
   - 要求供应商按小包装、小箱配送，避免“大箱便宜但卖不完”。
   - 到货验收看：烂果率、成熟度、温度、包装破损，不合格当场拒收或折价。

4. **建立简单台账**
   - 每天记录：进货量、销量、损耗量、剩余量。
   - 一周复盘一次，找出“卖得慢+坏得快”的品，直接砍掉。

**三、损耗控制：从陈列、定价、加工三处下手**

1. **陈列少量多次**
   - 小门店不要堆大堆头，采用“少量陈列+后仓补货”，视觉丰满即可。
   - 易损品放冷藏或阴凉处，避免阳光直射和挤压。

2. **分级定价和动态打折**
   - 每天固定时段（如晚间）对临近品相下降的水果打折清货。
   - 品相稍差的做果切或组合装，但必须符合食品安全要求。
   - 不要等到烂了才处理，成熟度到临界点就促销。

3. **控制订货节奏**
   - 周末、节假日可适度增加，但不超过日均销量的1.5倍。
   - 天气炎热、客流下降时主动减量。

4. **果切是双刃剑**
   - 能消化部分临期水果、提升客单，但需要冷藏条件、操作规范和当日清空。
   - 没有冷链和专人操作，不建议做。

**四、给一个小店可直接套用的模型**

- SKU：10个左右。
- 结构：苹果、香蕉、橙子、小番茄、葡萄、梨为基础；加1个当季品；加2个果切/小盒装。
- 采购：香蕉、葡萄、小番茄2天一次；苹果、橙子、梨3天一次；当季品1～2天一次。
- 库存：生鲜区陈列量控制在半天到一天销量，后仓不压超过1天量。
- 复盘：每周砍掉1个末位SKU，补1个试销SKU，保持动态优化。

**一句话原则：小门店水果不是“卖得多”，而是“进得准、转得快、坏得少”。** 先把SKU压到10个左右，用销量台账驱动采购，再配合晚间折扣和少量陈列，损耗通常能明显降下来。
