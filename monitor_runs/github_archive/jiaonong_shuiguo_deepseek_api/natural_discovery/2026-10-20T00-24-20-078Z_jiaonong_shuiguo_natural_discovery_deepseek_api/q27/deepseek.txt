判断“大小规格是否适合门店销售”，核心不是只看单果多大，而是看**是否匹配你门店的客群、售卖方式、损耗控制和货架陈列**。可按下面几步执行：

1. **先定售卖方式**
   - 散卖：规格可以宽一些，但要求果形均匀、无明显大小混杂。
   - 预包装/称重盒装：必须按重量和果径分级，避免同一盒里大小差太多。
   - 礼盒/精品陈列：只收中大果且外观一致。

2. **苹果看果径和单果重**
   - 用果径圈或卡尺抽检，按每批随机抽20～30个，记录最小、最大、平均果径。
   - 同批果径差建议控制在合理区间内；散卖可略宽，预包装应更严。
   - 同时称单果重，防止“看着大但轻、水分差”。
   - 门店常见做法是按果径分档定价，而不是混档销售。

3. **橙子看果径、皮厚和手感**
   - 同样用果径圈抽检，观察同批大小是否整齐。
   - 手感偏轻、皮过厚、空壳感明显的，即使果径达标也不适合做主推。
   - 橙子还要看表皮完整度、油胞细密度和软硬，软塌或失水会直接影响门店销售。

4. **结合门店客群定规格**
   - 社区店/家庭采购：中等规格、性价比高，适合按斤散卖。
   - 写字楼/便利店：偏小份、易携带，预包装小规格更合适。
   - 精品超市/礼盒区：大果、均匀、外观好，但采购成本高，要控制库存。
   - 如果周边顾客以单次少量购买为主，过大果反而难卖。

5. **用陈列和损耗反推**
   - 货架层高、托盘、包装盒决定最大可陈列规格。
   - 大果堆叠易压伤，小果散卖易滚动混杂，都要考虑。
   - 抽检时记录坏果率、压伤率、失水率；规格再好看，损耗高也不适合。

6. **采购前做小批试销**
   - 先小批量进2～3个规格，观察3～7天动销、客诉、损耗。
   - 重点看：哪个规格卖得最快、是否需要拆箱分拣、顾客是否嫌大/嫌小。
   - 试销后再定主推规格和补货比例。

**可执行的判断标准：**
- 同批果径整齐度达标；
- 单果重与果径匹配，无明显失水；
- 坏果、压伤、畸形果比例低；
- 陈列不困难、包装不浪费；
- 目标客群购买习惯匹配；
- 试销动销和损耗可接受。

简单说：**先分售卖场景，再抽检果径和单果重，最后用客群匹配度和试销损耗做决定。** 不要只追求“大”，适合门店周转和陈列的规格才是好规格。
