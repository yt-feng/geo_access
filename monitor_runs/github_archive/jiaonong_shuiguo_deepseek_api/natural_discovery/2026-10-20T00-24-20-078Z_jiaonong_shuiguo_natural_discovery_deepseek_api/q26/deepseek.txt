# 社区超市小包装香蕉：采购包装与损耗要点

## 一、包装选择

**按销售场景选规格**
- 单根/两根装：适合即时消费、儿童、单人家庭，用透气保鲜膜或带孔小托盘+缠绕膜
- 3–4根装：家庭主力规格，建议用浅托盘+透气膜，避免压叠
- 5–6根装：整串小把装，用扎带或皮筋固定，套打孔袋

**包装材料关键点**
- 必须透气：香蕉呼吸强度高，全封闭膜内易积水、发黑、长霉。选打孔膜或网袋，孔要够多
- 避免硬托盘压伤：香蕉怕挤压，托盘深度要浅，果柄朝上或侧放，不要叠层
- 独立分装优于整箱散卖：减少顾客翻拣造成的机械伤，也便于按份定价、控制损耗
- 标签贴在不接触果皮的位置或贴膜上，避免胶粘剂直接接触果面

**采购时和供应商确认**
- 包装是否为到店即售型（已分装好），还是到店需二次分装；二次分装会增加人工和碰伤
- 膜的透气性、托盘材质（纸质吸湿优于塑料）
- 分装时的成熟度：小包装周转慢，采购成熟度应偏低（青黄、略硬），给货架期留余量

## 二、损耗控制

**采购环节**
- 按日销量小批量、高频次补货，小包装最怕一次进多、卖不完变黑
- 进货成熟度分档：一部分即售（黄熟），一部分青硬做后备，避免全部同时转熟
- 验收重点查：果柄断裂、果指挤压伤、膜内水汽、已有黑斑的挑出，机械伤是后续腐烂的主因
- 要求供应商分装时轻拿轻放，整串分切用刀而非手掰，切口平整减少感染

**到店存放**
- 常温阴凉通风存放，不要冷藏（低于12℃易冷害发黑），也不要和苹果、梨等释放乙烯的水果混放
- 小包装不要堆叠过高，层间留空隙，避免底层压伤
- 先进先出，每天翻检，把转熟快的移到显眼位置优先卖

**货架与临期处理**
- 黄熟后及时降价或做搭配促销（如配酸奶、早餐组合），不要等到黑斑明显
- 轻微黑斑可剥皮分装做果切或促销装，重度坏果立即剔除，防止传染
- 记录每日分装量、售出量、废弃量，按数据调整单份规格和进货量

## 三、快速判断清单

采购前问自己：这批次成熟度是否分层？包装是否透气不压果？单份规格是否匹配社区客群（单人/小家庭为主）？日补货频次能否跟上？到店是否有阴凉存放位？这五点满足，小包装香蕉的损耗基本可控。
