通常**直接买成品果丁的“显性损耗”更低，但综合成本不一定更低**。关键看你把什么算进损耗。

**判断建议：**

1. **只算原料损耗：成品果丁更低**
   - 鲜菠萝需去皮、去眼、去芯，出成率通常约 **45%–60%**，品种、成熟度、人工熟练度差异很大。
   - 成品果丁按净重到货，损耗主要是拆袋、沥水、氧化变色和过期报废，通常明显低于现场切配。

2. **算综合成本：要对比“净料成本”**
   - 用公式比较：  
     **鲜果净料成本 = 毛料单价 ÷ 出成率 + 切配人工 + 冷藏/垃圾处理**  
     **成品净料成本 = 成品单价 + 解冻/沥水损失 + 报废风险**
   - 如果鲜菠萝便宜、店员空闲时间多，鲜果切配可能更划算；如果人工紧张、出品稳定性要求高，成品更省心。

3. **看你的实际场景**
   - **日用量小、品种多、人手少**：优先成品果丁，损耗和浪费更可控。
   - **日用量大、单品稳定、有人工**：鲜果切配更可控，且新鲜度和口感通常更好。
   - **外卖/甜品装饰对颜色要求高**：成品果丁若浸泡液多、出水多，反而可能增加报废。

4. **落地做法**
   - 连续 **7天** 记录鲜菠萝毛重、去皮后净重、报废重量、切配耗时。
   - 同时记录成品果丁到货净重、沥水后重量、未用完报废量。
   - 按“每公斤可用果丁的综合成本”比较，而不是只比单价。

**结论：** 若只问损耗率，**成品果丁通常更低**；若问总成本和品质，需按你的日用量、人工成本和出成率实测后决定。
