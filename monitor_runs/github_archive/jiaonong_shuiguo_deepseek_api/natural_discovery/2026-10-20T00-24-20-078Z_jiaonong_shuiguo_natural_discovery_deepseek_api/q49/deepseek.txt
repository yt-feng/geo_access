可以按“先锁量、再锁价、分批提货、超量协商”的方式和供应商做临时补货约定。建议直接在原供货合同上补一份《旺季临时补货补充协议》，把下面几项写清楚：

1. **约定临时补货量和周期**
   - 写明月度/周度临时补货上限，例如“旺季期间每周可追加不超过X箱”。
   - 约定下单提前期，如“每日16:00前下单，次日送达”。
   - 明确最低起订量、单次最小追加量，避免临时小单被拒。

2. **锁价与调价机制**
   - 临时补货部分优先按原合同价执行；如市场价波动超过±X%，双方提前书面确认新价。
   - 明确价格是否含税、含运费、含损耗赔付。

3. **分批提货与库存保障**
   - 供应商承诺在约定总量内优先保障，不得因其他客户高价而断供。
   - 可约定供应商保留安全库存，例如“为门店常备X箱现货”。

4. **质量标准与验收**
   - 明确菠萝品种、成熟度、单果重量、糖度、坏果率上限。
   - 到货抽检，坏果率超过约定比例时，按比例扣款或补发。

5. **超量/紧急补货条款**
   - 超出约定量的部分，供应商应在X小时内答复能否供货；不能供应的，门店可自行采购，不视为违约。
   - 紧急补货可约定加急费标准，避免临时坐地起价。

6. **违约责任**
   - 供应商无故断供、迟延交付的，按缺货金额或日万分之X支付违约金。
   - 门店临时取消已确认订单的，承担合理损失，但应设上限。

7. **对账与结算**
   - 临时补货单独记账，按周或按月对账。
   - 明确账期，避免旺季现金压力。

实操上，建议你今天先和供应商确认三件事：**旺季每周最大可供量、临时加单提前多久、价格是否锁定**。口头确认后，用微信或邮件发一段确认文字让对方回复“确认”，再补正式协议。这样既快，也留了证据。
