家庭场景优先考虑“耐放、吃起来方便、大小适中、不浪费”，建议这样组合更实用：

**推荐组合：苹果 + 橙子为主，香蕉少量，菠萝按需/单独**

1. **苹果 40%**
   - 耐放、老少皆宜，适合家庭常备。
   - 选中等果，别全是大果，礼盒显满且不压预算。

2. **橙子 30%**
   - 家庭接受度高，剥皮方便，适合饭后水果。
   - 和苹果一起撑起礼盒主体，耐运输。

3. **香蕉 15%—20%**
   - 适合早餐、孩子和老人，但**不耐放、易压伤**。
   - 建议放小把装，别和硬果混得太紧，礼盒里做“即吃款”。

4. **菠萝 10%—15%或单独选项**
   - 家庭喜欢但处理麻烦，且有些人嫌酸、易过敏。
   - 建议整个礼盒只放**1个小菠萝**，或做成“可换菠萝”的选项；不要占比太高。

**更稳的家庭礼盒结构：**
- 苹果 4—5个
- 橙子 4—5个
- 香蕉 1小把（3—4根）
- 菠萝 1个（小果）
- 总重控制在 **5—7斤** 更适合普通家庭，太大反而吃不完。

**避坑建议：**
- 香蕉和苹果不要紧贴放，苹果释放乙烯会催熟香蕉。
- 菠萝有刺手感，礼盒内要加隔层，避免扎坏其他水果。
- 家庭装别追求“每种都多”，**品种齐全、量适中**比大份量更好卖。
- 可做两个档：**基础家庭装（苹果+橙子+香蕉）**、**升级家庭装（加1个小菠萝）**，降低菠萝不受欢迎带来的退货风险。
