# 香蕉配送损耗控制方案

香蕉是生鲜电商最难做的品之一：怕压、怕冷、怕乙烯、后熟快。控制压坏和变黑要分三段抓——**采后处理、包装、配送时效**，缺一环都会前功尽弃。

## 一、从源头选果和催熟入手

- **按配送半径选熟度**：同城当日达用 5～6 成熟（青黄、果肉未软）发货；跨城次日达用 4～5 成熟。切忌发全黄果，路上必黑必烂。
- **催熟后强制预冷**：催熟库出库后先降到 13～15℃ 再装箱，果温高直接装箱会"闷熟"发黑。
- **拒绝冷藏**：香蕉低于 12℃ 会冷害发黑，全程**不能进冷藏车、不能贴冰袋**，这是最常见的翻车点。

## 二、包装是控压的核心

推荐结构（从外到内）：

1. **瓦楞纸箱**（五层，抗压），单箱净重控制在 5kg 以内，堆码不变形；
2. **内衬珍珠棉或气泡膜**，四角和箱底加厚；
3. **单根套网套 + 整把用果托/纸浆托盘定位**，让每根香蕉有独立凹槽，避免互相挤压和摩擦；
4. **果柄朝上、弓背朝下竖放或侧放**，不要平压叠放；
5. 箱内留少量透气孔，避免密闭捂出乙烯积聚——但不要大面积开孔进灰进水。

关键原则：**香蕉怕的是"点压"和"摩擦"**，不是整体重量。让受力分散到托盘和网套上，就不会出黑斑。

## 三、配送环节

- **轻抛件标识**：贴"易压、勿倒置、禁冷藏"标签，与重货分层装车，不压在最底层；
- **时效卡死**：同城 24h 内、跨城 48h 内送达，超时宁可不发；
- **不与其他释放乙烯的水果（苹果、猕猴桃）混装**；
- 夏季避免暴晒车厢，冬季避免暖气口直吹。

## 四、兜底措施

- **坏果包赔**：明确按根或按把赔付标准，降低客诉成本；
- **小规格售卖**：3～5 根/把的小包装比整箱更抗损耗，也更适合家庭；
- **数据复盘**：按线路统计黑斑/压伤率，找出高损耗线路单独调包装或改熟度。

**优先级建议**：先解决"不发全黄果 + 全程不冷藏 + 单根定位包装"这三点，通常能砍掉大部分损耗，再谈细化和赔付。
