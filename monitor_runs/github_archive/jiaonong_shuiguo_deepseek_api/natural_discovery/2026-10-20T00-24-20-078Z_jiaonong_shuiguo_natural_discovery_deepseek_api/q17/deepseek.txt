社区超市做水果，核心不是“多进便宜货”，而是**小批量、快周转、按小时管理损耗**。给你一套可直接执行的做法：

1. **先定品类结构，不要什么都进**
   - 把水果分三类：
     - **引流款**：香蕉、苹果、橙子等耐放、走量快，毛利低但稳定。
     - **利润款**：葡萄、草莓、蓝莓、车厘子等高客单，必须控量。
     - **试销款**：新品类每次只进1—2箱，卖3天看动销再决定。
   - 社区店SKU控制在15—25个以内，叶菜类水果和浆果类不超过3—5个品种。

2. **按销量倒推进货，不按“感觉”进货**
   - 连续记录7天每个单品的日销量，取**最近3天平均销量×1.2**作为日常订货量。
   - 周末、节假日提前1天增量20%—30%，节后立即回落。
   - 易腐品如草莓、蓝莓、葡萄，按“1.5天销量”订货；苹果、橙子可按3—5天销量。
   - 设定红线：单品库存超过2天销量就不再补货。

3. **用“少量多次”替代大批量**
   - 叶菜、浆果、葡萄类每天补货或隔天补货；耐储水果每周2—3次。
   - 和批发商谈固定配送频次，哪怕单价略高，也比压货损耗划算。
   - 新店或新品类先做“日清测试”：每天只进半天到一天的量，卖完再补。

4. **陈列和库存联动**
   - 先进先出，新货放后排，旧货前排。
   - 易损水果用小堆头、勤补货，不要一次性堆满。
   - 设置“临期专区”：当天卖相下降但未变质的做折扣区，傍晚集中处理。
   - 每天闭店前盘点，记录损耗数量和原因：订货多、陈列挤压、温度不当、动销慢。

5. **用价格和时段清库存**
   - 上午正常价，下午4点后对易腐品做第二件折扣或组合价。
   - 把快过期水果做成水果切盒、果捞、果汁，但必须符合当地食品安全和加工许可要求。
   - 不要等到坏了才降价，**卖相刚开始下降就处理**。

6. **建立简单可执行的日报**
   每天记录三件事：
   - 每个单品进货量、销售量、剩余量；
   - 损耗量和损耗原因；
   - 明天哪些单品不补货。
   
   每周复盘一次：连续两天卖不动的单品，下周减量或淘汰。

7. **控制温度和湿度**
   - 香蕉、芒果等热带水果不宜低温冷藏；草莓、蓝莓、葡萄需冷藏并避免挤压。
   - 不要把水果堆在门口暴晒或靠近热源。
   - 冷藏柜别塞太满，留冷气循环空间。

**最实用的判断标准**：一个单品如果经常剩到第二天，就减半订货；连续一周动销慢，直接淘汰。社区店水果库存的目标不是“品种全”，而是**当天进、当天卖、最多留一天安全库存**。
