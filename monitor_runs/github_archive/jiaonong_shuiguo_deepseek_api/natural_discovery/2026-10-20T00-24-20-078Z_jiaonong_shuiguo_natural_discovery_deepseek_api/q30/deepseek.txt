# 超市水果到货品相不好：售后流程约定建议

水果属于生鲜易腐品，品相问题（磕碰、腐烂、色差、规格不符）与"到货后发现"的时间点强相关，售后条款必须把**验收时点、责任划分、举证方式、处理时限**写清楚，否则事后极易扯皮。建议按以下结构约定：

## 一、验收环节（最关键）

1. **到货即时验收**：约定收货方须在到货后 X 小时内（建议 2–4 小时，大宗可当天）完成外观、数量、规格、温度抽检，逾期未提出异议视为外观合格。这条是防"到货很久才说品相不好"的底线。
2. **抽检比例与标准**：约定按批次抽检比例（如每批不低于 10% 或每车抽 N 箱），并明确"品相不好"的可量化标准——例如腐烂/压伤比例超过 X%、果径低于约定规格、色泽偏离约定等级、成熟度过高或过低。避免只用"品相好"这类主观词。
3. **验收单据**：验收结果须双方签字（或拍照+系统确认），注明批次、数量、问题比例，作为后续索赔依据。

## 二、责任与处理方式

4. **分级处理**：按问题严重程度分档约定，例如：
   - 轻微（低于约定比例）：折价接收，按比例扣款；
   - 中度：部分退货、换货，运费由责任方承担；
   - 严重（超过约定比例或整批不合格）：整批拒收或退货退款。
5. **责任归属**：区分"到货时即存在"（供货方责任，含运输环节）与"验收后因储存不当产生"（收货方责任）。运输途中的损耗、冷链断链责任要在合同中明确由谁承担。
6. **举证方式**：约定以到货现场照片/视频、验收单、第三方检测（如农残、冷害）为准；争议时以哪方证据优先要有规则。

## 三、时限与流程

7. **提出异议的时限**：外观品相问题须在验收时或到货后 X 小时内提出；隐蔽性问题（内部腐烂等）可约定到货后 24–48 小时内提出，逾期视为接受。
8. **响应与处理时限**：供货方须在收到异议后 X 小时内回复，X 个工作日内完成换货/退款/折价结算。
9. **结算挂钩**：约定问题批次货款暂缓结算，处理完毕后再结，避免先付款后扯皮。

## 四、其他要点

10. **换货补货条款**：换货的到货时限、二次验收标准、因换货导致的断货损失是否赔偿。
11. **累计考核**：约定同一供应商月度/季度不合格批次达到一定比例，可降级或终止合作。
12. **书面留痕**：所有异议、处理结果走书面或系统工单，口头沟通不作为依据。

**一句话原则**：把"品相不好"翻译成可测量的比例和规格标准，把"到货后发现"锚定在明确的验收时限内，责任、举证、时限、结算四件事写死，售后才有可执行性。
