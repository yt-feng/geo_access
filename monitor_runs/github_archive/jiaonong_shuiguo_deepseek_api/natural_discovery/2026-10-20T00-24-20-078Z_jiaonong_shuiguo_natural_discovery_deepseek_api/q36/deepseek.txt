这要看的不是“哪种更好卖”，而是**损耗率、客群、门店时段和供应链能力**。给一个可执行的判断框架：

**先给结论：多数社区商超更适合“整果为主 + 少量切果做增量”；纯切果只适合客流大、年轻客群集中、能高频处理损耗的门店。**

### 判断维度

| 维度 | 整果更优 | 切果更优 |
|---|---|---|
| 客户 | 家庭囤货、中老年、追求性价比 | 上班族、单身、即食、年轻客群 |
| 损耗 | 可观察挑拣，损耗可控 | 去皮后快速氧化、出水、保质期短 |
| 操作 | 无需加工人手 | 需要专人切、包、冷链/冷藏展示 |
| 毛利 | 毛利低但损耗低 | 单价高、毛利高，但报损风险大 |
| 门店条件 | 无加工区、人手紧 | 有果切台、冷藏柜、稳定客流 |
| 销售时段 | 全天可卖 | 午晚高峰、写字楼/商圈效果好 |

### 采购和经营建议

1. **先小批量试切，不要一上来全切。**  
   选1—2天在高峰时段切3—5个，记录：切后售价、售罄时间、报损量、整果同期销量。

2. **切果只做“引流/增量”，不要替代整果。**  
   整果承担走量和价格感知，切果承担即食需求和毛利。

3. **按门店分型定策略：**
   - 社区店、家庭客多：整果为主，切果少量试销。
   - 商圈店、写字楼店、年轻客多：整果+切果并重，晚高峰前切。
   - 无冷藏展示、人手不足：只卖整果，或做“现切现卖”预订。

4. **控制切果报损。**  
   切果当天清，按小时段补切；用透明盒+冷藏陈列；可搭配“买整果送切果试吃”或“切果限时折扣”清尾货。

5. **采购端注意：**  
   整果采购看成熟度和耐储性；切果用果要选成熟度适中、果形规整的，避免用熟透果切后出水。整果和切果最好分批次、分等级采购。

**一句话：先按门店客群和加工条件做7天小测试，用“整果销量+切果售罄率+切果报损率”三项数据决定配比。**
