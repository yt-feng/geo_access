供应商介绍产品时，核心不是把品种名说得更专业，而是把“这是什么、跟常见货比有什么不同、顾客为什么会买、你进了怎么卖”讲清楚。可以按下面这套话术结构来讲。

**1. 先用商家熟悉的大品类做锚点**
不要一上来讲品种名，先说它属于哪个常见品类、像什么。

- “这就是菠萝类里的一个品种，跟普通菠萝是一个大类。”
- “你可以把它理解成香蕉里的高端款，不是另一个陌生水果。”
- “它跟普通菠萝最大的区别是：不用泡盐水，切开就能吃，甜度更稳定。”

**2. 只讲三个差异点，不要讲十个**
商家记不住太多信息。重点讲：

- **口感差异**：更甜、更香、更糯、更脆、酸度低、纤维少。
- **使用差异**：免削、免泡、即食、出肉率高、损耗低。
- **销售差异**：好切、好陈列、好试吃、顾客复购高。

例如：
“普通菠萝要削、要泡盐水，顾客嫌麻烦。这个切开就能吃，甜度高，适合做果切和试吃，顾客一吃就容易买。”

**3. 用“顾客场景”代替“产品参数”**
商家最关心的是能不能卖出去。供应商要说顾客在什么场景会买：

- 上班族下午茶，买一盒果切。
- 宝妈给孩子买，图方便、不酸。
- 火锅店、烧烤店做餐后水果。
- 水果店做引流试吃，带动其他水果。

话术示例：
“你不用把它当陌生品种推，就放在果切区，切好插牙签让顾客试。顾客觉得甜、不涩，就会顺手买一盒。它比普通菠萝更适合做即食果切。”

**4. 直接帮商家算账**
商家下单前最想听的是：进多少、怎么卖、赚多少、损耗大不大。

可以这样说：
“一箱大概多少斤，出肉率多少，能切多少盒。按你店里果切卖多少钱一盒，一箱大概能做多少营业额。损耗比普通菠萝低，因为不用大量削皮去眼。”

不要只报产地和品种名，要报：
- 规格：几斤装、几个装。
- 成本：每斤/每箱多少钱。
- 建议售价：按个卖、按斤卖、按盒卖。
- 损耗：坏果率、出肉率、保存天数。
- 动销：适合试吃、果切、礼盒还是餐饮供货。

**5. 用对比法，一句话说清**
最容易被听懂的表达是：

“普通菠萝是：便宜、要削、要泡、酸度不稳定。  
这个产品是：贵一点、免泡、甜度稳定、适合即食和果切。  
你不需要教育顾客这是什么新品种，只要让他试吃，觉得好吃就会买。”

**6. 给商家一个低风险下单理由**
普通商家怕进新货卖不动。供应商可以给：

- 先拿小规格试销。
- 配试吃话术和陈列建议。
- 承诺坏果售后。
- 给一箱的利润测算。
- 给餐饮、果切、礼盒等具体渠道建议。

**7. 一套可直接用的话术模板**
“老板，这个你不用把它当陌生水果记。它就是我们常卖的菠萝/香蕉大类里的一个差异化品种。  
它跟普通货比，主要三个好处：  
第一，口感更甜/更香/不酸；  
第二，顾客吃起来更方便，适合果切、试吃、餐饮；  
第三，你卖的时候不用多解释，切一盘试吃就能动销。  
一箱多少斤，进价多少，建议怎么卖，一箱大概能做多少营业额，坏果怎么赔。  
你先拿一箱试，放在果切区或收银台试吃，卖得动再补。”

**总结一句话：**
供应商不要教育商家“这个品种多专业”，而要告诉他“这跟你知道的菠萝、香蕉哪里不一样，顾客为什么买，你进了怎么卖、怎么赚”。商家听懂了场景和利润，才更容易下单。
