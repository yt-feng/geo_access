会有影响，但影响大小取决于你卖给谁、怎么卖。

**核心结论：**
一箱里大小差异明显，会直接影响销售，主要表现为：
1. **卖相变差**：顾客挑香蕉时通常偏好整齐、均匀的，大小混杂会让人觉得“品质不稳”。
2. **成熟不一致**：大果和小果往往熟度不同，同一箱里可能出现有的已经黄熟、有的还青硬，增加损耗。
3. **定价困难**：如果按整箱或按把卖，顾客会觉得“花了同样的钱，拿到的不一样”，容易压价或挑剩。
4. **损耗上升**：小的、丑的、熟过头的最后容易剩下来，变成折价处理或报损。

**但也不是绝对不能卖，关键看你怎么处理：**
- **散卖/按斤卖**：影响相对小，顾客更关注单价和新鲜度，大小差异可以接受。
- **分级销售**：把大果、中果、小果分开，按不同价格卖，反而能减少挑拣和损耗。
- **做促销/搭配**：小果、次果可以捆把低价卖，或做香蕉奶昔、果切、烘焙原料渠道。
- **整箱批发**：如果客户是奶茶店、果汁店、食堂，他们更看重成本和出肉率，大小差异影响较小。
- **礼盒/精品路线**：如果做高端礼盒或精品水果店，大小不一会明显拉低溢价，最好别混装。

**采购建议：**
- 如果你走**零售精品**路线：尽量采购分级均匀的货，宁可贵一点。
- 如果你走**平价走量**路线：可以接受大小混装，但要把价格压下来，并提前想好分级或促销方案。
- 如果已经进了混装箱：尽快按大小分拣，大的正常卖，小的捆把或做特价，避免一起放到过熟。

简单说：**大小不一会影响销售，但不是致命问题；致命的是不分级、不定价、不处理，最后全砸手里。**
