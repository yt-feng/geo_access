选批量配送水果供应商，重点看**稳定性、配送能力、结算方式、损耗处理**这四件事，而不是单纯比价格。

**1. 先明确你的采购约束**
- 人数和预算：比如20人/50人/100人，人均5元还是10元。
- 配送频率：每周一次还是每天一次。
- 配送时间：必须下午2点前到，还是上午到就行。
- 发票要求：能否开专票/普票，是否对公付款。
- 场地条件：有没有冰箱、能不能代收、有没有电梯。

这些条件先写清楚，再去找供应商，否则容易被低价诱导。

**2. 适合批量配送的供应商类型**
优先顺序一般是：
1. **本地水果批发商/农批市场档口**：价格低，适合量大、能接受自己分装或简单分装。
2. **企业下午茶/团餐配送商**：省心，能按份配送，但单价高一些。
3. **连锁水果店或区域水果连锁**：品质稳定，配送准时，适合中小批量。
4. **生鲜电商企业购**：流程规范、开票方便，但价格通常不是最低。
5. **产地直发**：只适合单一品种、大批量，不适合混合水果下午茶。

**3. 筛选时要问的问题**
- 起送量是多少？低于起送量怎么算？
- 配送费怎么收？是否按楼层、距离、时段加价？
- 能不能按人数配成独立小份？分装费多少？
- 水果是固定搭配还是可自选？能不能提前一天确认菜单？
- 坏果、压伤、不熟怎么处理？是补送、退款还是下次抵扣？
- 临时加单、改时间、取消订单的规则是什么？
- 能不能提供检测报告或产地证明？至少要有进货凭证。
- 结算周期：现结、月结还是预付？能否对公转账并开票？

**4. 建议的试单流程**
不要一上来就签长期合同。先做三步：
1. **询价3-5家**：同一份需求发给不同供应商，比较报价和配送条件。
2. **小批量试单**：先订一次，重点看准时率、水果新鲜度、分装质量、有没有缺斤少两。
3. **复盘再定**：如果试单合格，再谈月结价格和固定配送时间。

**5. 判断供应商是否靠谱的硬指标**
- 准时率：能不能在约定时间前30分钟送到。
- 损耗率：一箱里坏果超过5%就要警惕。
- 响应速度：出问题后多久回复、多久补送。
- 价格透明度：是否随行就市，涨价提前几天通知。
- 分装卫生：是否戴手套、用食品级包装。

**6. 适合下午茶的水果选择**
批量配送建议选：
- 易分装：圣女果、葡萄、橘子、香蕉、蓝莓杯。
- 耐运输：苹果、橙子、梨、猕猴桃。
- 少选：草莓、荔枝、樱桃、切好的西瓜，除非供应商冷链和分装很强。

**7. 一个实用做法**
如果公司人数在30-100人，最稳的方案是：
- 找1家本地水果连锁或企业下午茶配送商做主供应商；
- 再找1家农批档口做备选，用于大批量或临时补货；
- 固定每周菜单，提前2天确认，按份配送，月结开票。

这样既能控制成本，又不会因为一家出问题导致下午茶断供。核心原则是：**先试单，再签约；先保准时和新鲜，再谈低价。**
