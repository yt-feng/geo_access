和小批量试单的核心目标不是“赚一笔”，而是**用最低成本验证供应商是否值得长期合作**。所以试单设计要围绕三件事：**验品质、验履约、验结算**。

下面给你一套可直接执行的设计框架。

## 一、先明确试单目标

第一次合作，不要一上来就压价压量，重点观察：

1. **品质稳定性**：不是“这一批好不好”，而是“是否和样品一致、损耗多大”。
2. **履约可靠性**：能否按约定时间、数量、规格交货。
3. **结算与售后**：账期、票据、坏果赔付是否按约定执行。
4. **沟通效率**：出问题时响应快不快、是否推诿。

## 二、试单规模怎么定

建议遵循“**小到可承受，大到能暴露问题**”：

- **金额**：控制在你能接受“全损也不影响经营”的范围，通常是单次采购预算的 5%–10%，或首次不超过 1–2 万元（视你规模调整）。
- **品种**：选 **1–2 个单品**，优先选你最有把握卖、周转最快的品类，不要一次试很多品种。
- **数量**：按最小起订量或最小包装单位来，比如 1–2 个托盘、几十箱，够你观察 3–5 天销售和损耗即可。
- **批次**：最好分 **2 次小单**，间隔 1–2 周，看第二批是否还稳定，避免“首批特别好、后面变差”。

## 三、试单必须锁定的关键条款

试单前用文字（微信/合同/订单）确认清楚，别只靠口头：

| 项目 | 要确认的内容 |
|---|---|
| 规格 | 品种、等级、单果重/果径、成熟度、糖度、包装方式 |
| 价格 | 单价、是否含税、含运费、是否随行就市 |
| 数量 | 允许±多少浮动（水果常见 ±5%–10%） |
| 交货 | 时间、地点、运输方式、温控要求、谁承担运费 |
| 验收 | 到货后多久内验收、以谁的标准为准 |
| 损耗/赔付 | 坏果率超过多少赔付、怎么赔（补货/扣款/退货） |
| 结算 | 现结/账期、付款节点、发票 |
| 退换 | 严重不合格能否拒收或退货，费用谁承担 |

**重点**：把“坏果率标准”和“赔付方式”写死。比如：到货坏果率≤5% 正常，超过部分按实扣款或补货。

## 四、试单执行流程（建议照做）

1. **先要样品**：让供应商寄 1–2 箱样品，你自己看外观、试口感、称重、测损耗。
2. **下试单**：明确规格、数量、到货时间、验收标准。
3. **到货验收**：当场拍照、称重、开箱抽检，记录：
   - 实际到货数量 vs 订单数量
   - 坏果/次果比例
   - 规格是否达标
   - 包装和温度是否合格
4. **销售跟踪**：记录 3–5 天内的实际损耗、客户反馈、动销速度。
5. **复盘打分**：按品质、履约、售后、价格四项打分，决定是否继续。

## 五、验收抽检怎么做

- **抽检比例**：小单至少抽 10%–20% 的箱数，每箱随机抽若干果。
- **记录方式**：拍照+视频，保留原始包装和标签。
- **判定标准**：提前约定，比如：
  - 单果重低于约定下限的比例
  - 腐烂、压伤、裂果比例
  - 成熟度是否适合你的销售周期

## 六、试单后怎么判断要不要继续

可以用一个简单打分表：

| 维度 | 权重 | 判断标准 |
|---|---|---|
| 品质 | 40% | 与样品一致，损耗在约定范围内 |
| 履约 | 25% | 按时、按量、按规格到货 |
| 售后 | 20% | 出问题响应快、赔付爽快 |
| 价格 | 15% | 有竞争力且稳定 |

- **80 分以上**：可逐步放量，第二次试单增加 30%–50%。
- **60–80 分**：再试一次，重点盯问题项。
- **60 分以下**：直接换供应商，不要因为“便宜”硬撑。

## 七、几个容易踩的坑

1. **只看单价低**：便宜但损耗高、规格不稳，实际成本更高。
2. **没约定赔付**：出问题后扯皮，损失全自己扛。
3. **一次下大单**：首次合作就压重注，风险太大。
4. **只试一个批次**：水果季节性和批次差异大，一次好不代表次次好。
5. **口头承诺不落字**：后面维权没有依据。

## 八、一句话总结

**试单要小、要分两次、要锁规格和赔付、要到货抽检记录、要按品质/履约/售后/价格打分再决定放量。** 先验证供应商靠不靠谱，再谈长期合作和压价。
