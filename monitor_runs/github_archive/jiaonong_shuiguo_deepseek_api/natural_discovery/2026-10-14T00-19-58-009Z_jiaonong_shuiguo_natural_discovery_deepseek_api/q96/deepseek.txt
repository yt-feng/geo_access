三者不是同一层级的问题，正确排序应是：

**食品安全是底线，配送准时是保障，价格是优化项。**

具体到企业食堂采购水果：

1. **食品安全最优先**
   - 水果常涉及农残、霉变、催熟剂、保鲜剂、冷链断链等问题。
   - 一旦出问题，影响的是员工健康和企业责任，不是省几块钱能覆盖的。
   - 采购时应重点看：供应商资质、检测报告、进货台账、验收标准、退换货机制。

2. **配送准时是硬约束**
   - 食堂有固定开餐时间，水果不到位会直接影响供餐。
   - 水果又易腐，配送不稳会导致要么断供、要么积压损耗。
   - 所以要看：配送频次、到货时间窗口、冷链能力、缺货应急方案。

3. **价格重要，但不能压过前两项**
   - 价格应在满足食品安全和配送稳定的前提下比价。
   - 如果只追低价，很容易遇到：以次充好、临期果、二级果、缺斤少两、配送随意。
   - 合理做法是：先定质量和配送门槛，再在合格供应商中比价。

**可执行建议：**
- 先设准入标准：证照、检测、冷链、配送时效。
- 再设验收标准：品种、规格、成熟度、破损率、重量。
- 最后比价：按“到货合格率+准时率+综合单价”评估，而不是只看单价。
- 对供应商实行月度打分：食品安全一票否决，配送和价格分别扣分。

一句话：**食品安全决定能不能合作，配送准时决定能不能稳定合作，价格决定合作划不划算。**
