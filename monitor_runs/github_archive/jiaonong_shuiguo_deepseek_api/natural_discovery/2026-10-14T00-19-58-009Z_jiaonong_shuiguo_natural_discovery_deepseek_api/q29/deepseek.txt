超市和水果供应商的账期没有统一标准，主要取决于**水果品类、供应商规模、超市话语权**。常见情况如下：

**1. 最常见的账期区间：30～60天**
- 大型连锁超市对中小水果供应商：通常是 **30天、45天、60天**。
- 其中 **45～60天最普遍**，尤其是全国性商超、区域龙头超市。

**2. 品类差异很明显**
- **耐储水果**（苹果、梨、橙子、进口水果等）：账期可以谈到 **45～60天**，甚至 **90天**。
- **短保易腐水果**（草莓、荔枝、杨梅、樱桃、葡萄等）：账期通常更短，常见 **7～30天**，有些要求 **现结或周结**，因为损耗和资金周转压力大。
- **叶菜、浆果类**：如果和水果一起谈，账期往往被单独缩短。

**3. 供应商规模影响账期**
- 大型果业公司、品牌供应商：议价能力强，账期常见 **30～45天**。
- 中小果农、合作社、批发商：往往被迫接受 **60～90天**，甚至更长。
- 新供应商进场：超市常要求 **首单现结或短账期**，稳定后再延长。

**4. 超市类型差异**
- 全国性大卖场/会员店：**45～90天** 都常见，部分强势渠道更长。
- 区域连锁超市：**30～60天** 较常见。
- 社区生鲜店、水果专营店：账期更短，**7～30天** 或周结较多。
- 电商平台自营：通常 **30～60天**，按结算周期执行。

**5. 实际谈判中常见的折中方案**
- **30天账期 + 到期电汇**：对供应商较友好。
- **45天账期 + 月结**：超市和供应商都容易接受。
- **60天账期 + 首单现结**：超市常见让步方式。
- **阶梯账期**：合作前3个月30天，稳定后60天。
- **按品类分账期**：耐储60天，短保15天。

**给供应商的判断建议：**
- 如果对方是强势大型超市，**45～60天**是现实区间，低于30天很难谈。
- 如果水果损耗高、保质期短，尽量争取 **30天以内**，否则资金压力很大。
- 账期超过 **90天** 要谨慎，除非毛利足够高或有其他资源支持。
- 谈判时不要只盯账期，还要看 **结算方式、起算时间、对账周期、退货扣款条款**。有些超市写“60天”，但加上对账和开票流程，实际回款可能到 **75～90天**。

简单说：**水果供应商和超市合作，30～60天最常见，短保水果尽量压到30天内，耐储水果45～60天较普遍。**
