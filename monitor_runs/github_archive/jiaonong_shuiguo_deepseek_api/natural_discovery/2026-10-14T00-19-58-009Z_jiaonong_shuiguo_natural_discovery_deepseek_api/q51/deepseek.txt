要固定，但不要只固定“产地”，更要固定“品种 + 成熟度 + 加工批次 + 验收标准”。  
对茶饮店来说，水果风味波动是直接影响复购的，尤其鲜果茶、果酱茶。

更可执行的做法：

1. **固定品种和规格，不必迷信固定产地**
   - 同一产地也可能因雨水、季节、树龄、采摘期不同而波动。
   - 优先固定：品种、单果克重/糖度范围、成熟度、去皮去核规格、冷冻/冷藏状态。

2. **能固定供应批次就固定批次**
   - 对连锁或用量大的店，锁定供应商的特定果园/加工厂/产季批次更稳。
   - 要求供应商提供：采摘期、加工日期、糖度、酸度、出汁率、是否冷冻、保质期。

3. **建立验收指标**
   - 鲜果：糖度、酸度、香气、软硬度、颜色、坏果率。
   - 果酱/冷冻果泥：可溶性固形物、pH、颜色、黏度、风味描述。
   - 每批留样，做盲测对比，不合格就退。

4. **保留备选供应方案**
   - 不要只押一个产地或一个供应商。极端天气、运输延误、涨价都会断供。
   - 至少准备 1 个同品种替代批次或替代配方，比如用冷冻果泥补鲜果风味。

5. **用配方和操作抵消波动**
   - 设定糖浆/茶底/酸度微调规则。
   - 对员工做“今天这批偏酸/偏淡怎么调”的标准卡。
   - 新品测试时记录批次差异，别只测一次就上架。

6. **采购策略建议**
   - 核心爆品：固定品种 + 固定加工批次 + 双供应商备份。
   - 季节限定：按产季切换，但提前做风味测试和配方备案。
   - 小用量水果：不必强求固定产地，优先稳定加工规格。

一句话：**固定标准比固定产地更重要，固定批次比固定供应商更实际。**  
最稳的是“品种规格 + 验收标准 + 批次留样 + 备选方案”一起做。
