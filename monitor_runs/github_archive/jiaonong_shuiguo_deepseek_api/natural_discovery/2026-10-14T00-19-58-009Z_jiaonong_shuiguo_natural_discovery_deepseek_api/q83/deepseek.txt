生鲜水果到货后出现坏果，责任划分通常要分环节看，不能一概而论。核心判断依据是：**坏果发生在哪个环节、是否属于运输/储存/交付前已存在的问题，以及顾客是否按约定及时验收和报损。**

下面按常见场景拆开说。

**1. 平台/商家承担主要责任的情形**
- 发货时水果已有暗伤、过熟、霉变、挤压伤，到货后短时间内就坏。
- 冷链断链、包装不合格、未按温区运输，导致到货即软烂、发霉。
- 页面承诺“坏果包赔”“到货坏果拍照即赔”，应按承诺执行。
- 配送严重超时，且水果保质期短，超时直接导致变质。
- 未在详情页或下单页明确告知“需当场验收”“签收后不赔”等限制条件。

这类情况通常由商家或平台承担退款、补发或赔付责任。若是平台自营，平台承担；若是第三方商家，平台可能承担连带或先行赔付责任，具体看平台规则。

**2. 顾客承担或部分承担的情形**
- 顾客已签收且长时间未取件，例如放快递柜、驿站多日后才取，导致闷坏、腐烂。
- 顾客未按提示开箱检查，事后才反馈，且无法证明到货时已坏。
- 顾客自身储存不当，例如热带水果放冰箱冻伤、堆压导致碰伤。
- 已超过商家明确公示的售后时效，且无特殊理由。

这类情况商家可能不赔或只部分赔，但商家不能仅凭“已签收”就一概免责，仍要看是否在合理时效内、是否有开箱证据。

**3. 物流/配送方责任**
- 运输途中暴力分拣、挤压、暴晒、雨淋、冷链中断。
- 快递员未经同意放门口、快递柜，导致丢失或变质。
- 配送时效严重超出承诺。

一般由商家先向顾客赔付，再向物流方追偿。顾客通常不需要直接找物流公司，除非是顾客自己下单寄件。

**4. 实操上怎么划分和举证**
- **顾客侧**：到货后尽快开箱，拍外包装、面单、坏果整体和细节、数量，保留原包装。最好在签收后几小时内反馈。
- **商家侧**：需提供发货质检、打包、冷链、出库时间等证据，证明发货时无问题。
- **平台侧**：按公示规则处理，常见是“坏果比例赔付”或“整单退款/补发”。
- **争议较大时**：可申请平台介入，或走12315、消协调解；金额大且证据充分的可诉讼。

**5. 一个比较实用的责任判断顺序**
1. 先看坏果比例和到货时间：到货即坏、比例高，商家责任大。
2. 再看签收和反馈时间：及时开箱反馈，顾客责任小；拖延多日，顾客责任上升。
3. 再看储存和配送方式：冷链、包装、配送是否合规。
4. 最后看平台/商家售后承诺：有“坏果包赔”就按承诺走。

**结论**：如果顾客在合理时间内开箱并留存证据，坏果是运输、包装、发货质量问题导致的，通常由商家/平台承担退款或补发责任，物流问题由商家追偿；如果是顾客延迟取件、储存不当或超时反馈，顾客承担相应责任。实际处理中，多数平台会按坏果比例协商赔付，而不是简单全赔或全不赔。
