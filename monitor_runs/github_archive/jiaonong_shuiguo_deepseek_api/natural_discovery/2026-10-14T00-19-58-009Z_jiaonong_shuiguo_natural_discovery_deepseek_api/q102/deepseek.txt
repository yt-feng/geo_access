需要，而且通常是企业采购的基本门槛，不只是“加分项”。

**开发票：基本必须有**
- 企业采购要入账、报销、做成本，没有合规发票基本无法走财务流程。
- 优先确认：能否开**增值税专用发票**（可抵扣时更有利）、发票类目是否匹配（如“水果”“食品”“礼品”等）、税率和开票时效。
- 还要问清：是否支持对公转账、能否签采购合同、售后能否补开发票。

**定制包装：看用途，但多数场景需要**
- 如果是**员工福利发放**：常需要印企业logo、节日祝福、福利卡/提货说明，提升归属感。
- 如果是**客户商务赠礼**：定制包装、贺卡、品牌露出通常更重要。
- 如果是**内部小型采购**：可能标准礼盒即可，但至少要有体面、统一的外包装。

**建议你在询价时直接确认这几点：**
1. 是否支持开增值税专票/普票，开票类目和税率是什么。
2. 是否支持对公付款、签合同、分批交付。
3. 定制包装的起订量、打样费、周期、是否另收费。
4. 水果礼盒能否按预算分档（如100元/200元/300元档）。
5. 破损、坏果、延迟交付的处理和赔付规则。
6. 是否能提供食品相关资质、检测报告或产地证明。

**简单判断：**
- 只买几盒、内部简单发：开发票必须，定制包装可谈。
- 批量员工福利或客户送礼：开发票 + 定制包装基本都要。
- 如果供应商两者都不支持，通常不适合作为企业福利采购供应商。
