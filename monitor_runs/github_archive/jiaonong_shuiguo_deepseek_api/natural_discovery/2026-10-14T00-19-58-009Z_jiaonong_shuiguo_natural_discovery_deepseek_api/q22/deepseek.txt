可以按“高频带低频、低价带高价、即时吃+带回家”来组合。香蕉通常是引流品，苹果是稳定销量品，菠萝客单和加工价值更高，适合做搭配升级。

**1. 香蕉+菠萝：做“即食果盒/拼盘”**
- 组合：香蕉1根+菠萝块1盒，定价比单买合计略低，但高于单买香蕉。
- 话术：**“即买即吃，酸甜搭配”**
- 目的：把只想买香蕉的人，升级成带一份菠萝果盒。

**2. 苹果+菠萝：做“家庭装/炖煮装”**
- 组合：苹果3个+菠萝1个，主打**“煮水果茶、做咕噜肉、做沙拉”**。
- 可附小食谱卡，降低菠萝处理门槛。
- 定价：按单品合计的8.5—9折，但设置整组价，提升客单。

**3. 香蕉+苹果：做“早餐/儿童装”**
- 组合：香蕉3根+苹果2个，主打**“一周早餐水果”**。
- 用透明袋或小篮预包，放在收银动线附近，方便顺手拿。
- 适合做成9.9元、12.9元这类心理价位。

**4. 三品组合：做“9.9/19.9元水果篮”**
- 小份：香蕉2根+苹果1个+菠萝块1盒，定价9.9元，适合单人/办公室。
- 家庭份：香蕉1把+苹果4个+菠萝1个，定价19.9—29.9元，按实际成本调整。
- 关键不是单纯降价，而是**把散买变成整组买**。

**5. 促销机制建议**
- **满赠**：买菠萝+任意苹果/香蕉，送削皮或切块服务。
- **加价购**：买苹果满10元，加3元换购菠萝块1盒。
- **第二件半价**：适合香蕉、苹果这类高频品，但菠萝更适合做“加价购”。
- **时段促销**：晚7点后推即食果盒，减少损耗。

**6. 陈列执行**
- 香蕉放端头引流，苹果放主通道，菠萝和果盒放一起。
- 组合装统一用同一个价格牌：**“组合价XX元，单买约XX元”**。
- 菠萝必须解决“不会削、不会切”的障碍，现场切块或代削皮会明显提升转化。

**最推荐先试的一套：**
- 引流：香蕉正常价，甚至略低。
- 利润：菠萝切块盒+苹果做加价购。
- 主推：**“买苹果满10元，加3元换购菠萝块”**，同时放9.9元香蕉苹果早餐袋。
- 目标：让顾客从“只买一串香蕉”变成“香蕉+苹果+菠萝块”一起买。
