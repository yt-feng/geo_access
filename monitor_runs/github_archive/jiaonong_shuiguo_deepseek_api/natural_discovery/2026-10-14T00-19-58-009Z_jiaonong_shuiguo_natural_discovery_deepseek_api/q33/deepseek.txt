重要，而且对多门店超市来说，供应商的分级标准不只是“重要”，而是统一水果品质的基础设施。没有它，门店越多，品质越容易失控。

**为什么重要**

1. **统一验收依据**
   多门店最难的是“同一批货，不同门店验收结果不一样”。如果供应商有明确分级标准，比如按果径、糖度、色泽、瑕疵率、成熟度分级，门店就能按同一套标准收货，减少扯皮。

2. **减少门店间体验差异**
   顾客在A店买到的苹果和B店买到的同款苹果，如果大小、甜度、熟度差很多，会直接损害品牌信任。分级标准是让不同门店“卖同一个东西”的前提。

3. **采购定价和结算更清晰**
   一级果、二级果、统货价格不同。没有分级，采购容易花一级果的钱买到统货，或者门店把二级果当一级果卖，造成价格和品质错配。

4. **降低损耗和客诉**
   水果损耗很大程度来自成熟度不统一、大小不一、隐性瑕疵。分级标准能提前筛掉不适合长途配送或不适合当日销售的部分，减少门店端烂果和退货。

5. **便于供应商管理和淘汰**
   有了分级标准，才能量化考核供应商：到货合格率、分级准确率、批次稳定性。否则只能凭感觉说“这家还行”，无法做多门店统一管理。

**但要注意**

- 分级标准不能只写在合同里，必须可操作，比如用糖度计、卡尺、色卡、样品对照。
- 要区分“采购分级”和“门店销售分级”，两者可以对应，但不能混为一谈。
- 最好保留每批次留样和验收记录，否则出现争议时很难追溯。
- 如果供应商分级标准很粗，超市可以要求其按你的销售场景重新定级，而不是被动接受。

**结论**
多门店超市要统一水果品质，供应商分级标准是必须的。它决定了你能不能把“好水果”变成可复制、可验收、可追责的标准，而不是靠每个店长个人经验。建议至少做到：统一分级维度、统一验收工具、统一留样追溯、统一供应商考核。
