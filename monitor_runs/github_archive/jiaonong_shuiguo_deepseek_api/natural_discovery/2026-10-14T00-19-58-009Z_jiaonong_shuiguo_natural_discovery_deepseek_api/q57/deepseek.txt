对于餐饮连锁采购水果，**大多数情况下，“中央厨房统一收货 + 再配送/统采统配”更好**；但前提是你的门店密度、冷链能力、水果损耗特性和结算体系能支撑。若门店少、区域分散、水果以门店现场加工/鲜食展示为主，则“门店分开收货”可能更灵活。

下面给你一个可判断的框架。

## 一、两种模式的核心区别

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 采购权 | 总部/中央集中 | 分散到门店或区域 |
| 品控标准 | 容易统一 | 容易执行不一 |
| 成本 | 量大议价强，但增加仓储配送成本 | 采购灵活，但单价通常更高 |
| 损耗 | 集中分拣可控，但多一次搬运 | 少一次中转，但门店储存能力差 |
| 食品安全 | 可集中检测、留样、追溯 | 追溯链条更长、更难 |
| 门店操作 | 门店省事 | 门店要收货、验货、记账 |
| 适合场景 | 门店多、标准化高、有冷链 | 门店少、区域散、水果品类多变 |

## 二、建议优先选中央厨房统一收货的情况

满足以下 3 条以上，优先中央统收：

1. **门店数量多**，比如 20 家以上，且集中在可配送半径内。
2. **水果用途标准化**，如果切果盘、果汁、甜品装饰、沙拉，规格和成熟度要求统一。
3. **有冷藏/冷链和分拣能力**，能控制温度、湿度、成熟度。
4. **总部要强控食品安全和毛利**，需要统一检测、留样、追溯。
5. **供应商愿意配合统采统配**，能按中央厨房标准分级、包装、贴标。
6. **门店后厨面积小**，没有条件做二次分拣、催熟、冷藏。

优点：
- 议价能力强，采购成本更低。
- 品质标准统一，减少“这家店甜、那家店酸”。
- 食品安全和追溯更可控。
- 门店操作简化，降低店长腐败和随意采购。
- 便于做净果率、出成率、损耗率考核。

风险：
- 多一次装卸和配送，机械伤可能增加。
- 中央厨房如果压货，损耗会集中爆发。
- 配送频次不够时，门店会出现断货或水果不新鲜。
- 对信息系统和冷链要求高。

## 三、建议选门店分开收货的情况

满足以下 3 条以上，可以考虑门店直收：

1. **门店数量少**，比如 10 家以内，或城市间跨度大。
2. **水果品类变化快**，比如时令鲜果、门店现场陈列、按当天客流灵活补货。
3. **没有中央厨房或冷链配送能力**，统配反而增加成本。
4. **门店有独立加工和储存能力**，能自己验货、催熟、分切。
5. **区域供应商本地化强**，本地直送更快、更便宜。
6. **总部只做品牌和菜单，不强制统一采购**。

优点：
- 到店链路短，新鲜度可能更好。
- 门店可快速调整品类和数量。
- 不需要中央仓配投入。
- 本地小供应商响应快。

风险：
- 采购价不统一，毛利波动大。
- 品控标准难统一，食品安全风险高。
- 门店容易虚报、拿回扣、串货。
- 总部难做统一核算和追溯。
- 门店人力负担增加。

## 四、更现实的推荐：混合模式

多数连锁餐饮最后会走到“混合模式”，而不是二选一。

### 推荐做法

1. **核心大单品统采统配**
   - 如苹果、橙子、柠檬、西瓜、冷冻果浆、果切原料。
   - 由中央厨房统一收货、分拣、定价、配送。

2. **时令/易损/区域特色水果门店直采**
   - 如草莓、蓝莓、荔枝、杨梅、桃子等。
   - 允许区域采购或门店直收，但必须进供应商白名单。

3. **总部定标准，不一定要总部收货**
   - 统一规格书：品种、单果重、糖度、成熟度、瑕疵率、农残检测。
   - 统一验收流程：拍照、称重、测温、留样、异常上报。
   - 统一结算：总部对账，或门店按标准上传单据。

4. **按配送半径分区**
   - 300 公里内：中央厨房统配。
   - 300 公里外或门店分散：区域分仓/区域供应商直送。
   - 单店偏远：门店直收，但总部审批供应商和价格。

## 五、决策时最该算的 5 笔账

1. **采购成本差**：统采能降几个点？是否覆盖仓配成本？
2. **损耗率差**：统配多一次搬运，损耗增加多少？门店直收是否因储存差反而更高？
3. **人力成本**：中央分拣人工 vs 门店收货验货人工。
4. **食品安全风险**：一次事故的损失，通常远大于采购省下的钱。
5. **管理成本**：门店分散采购带来的腐败、串货、标准不统一，是否能承受。

## 六、直接结论

- **门店多、标准化强、有冷链：选中央厨房统一收货。**
- **门店少、区域散、水果时令性强：选门店分开收货。**
- **最推荐：核心品类中央统收，易损时令品类区域/门店直采，总部统一标准和供应商准入。**
