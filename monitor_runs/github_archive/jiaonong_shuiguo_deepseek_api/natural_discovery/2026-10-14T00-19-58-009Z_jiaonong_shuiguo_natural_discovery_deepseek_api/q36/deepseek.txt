建议优先卖**整果为主，切果为辅**，具体取决于门店客群和损耗控制能力。

**更适合卖整果的情况：**
- 社区店、家庭客群为主，顾客买回家自己削；
- 门店没有稳定的人手做现场加工；
- 菠萝进货价低、周转快，想靠低价走量；
- 损耗管控弱，切果卖不掉容易报废。

整果优点是：**损耗低、操作简单、毛利稳定、适合堆头促销**。缺点是客单价低，年轻客群嫌麻烦。

**更适合卖切果的情况：**
- 商圈店、年轻客群、上班族、即买即吃需求强；
- 门店有冷柜、加工台和稳定人手；
- 能控制切果损耗，比如按份卖、定时打折；
- 可以搭配其他果切做组合销售。

切果优点是：**客单价高、购买便利、视觉吸引力强**。缺点是：**损耗高、食品安全要求高、人工成本高**。

**实操建议：**
1. **主推整果**：做低价引流，比如“9.9元/个”，适合家庭客。
2. **搭配切果**：只做小份、少量、勤补，放在冷柜显眼位置。
3. **切果要控量**：先按预估销量的70%切，卖完再补，避免晚上大量报废。
4. **分时段定价**：切果上午原价，下午打折，闭店前特价清仓。
5. **看数据决定比例**：连续一周记录整果和切果销量、损耗、毛利，再调整。

**简单判断：**
- 社区家庭多、人手少 → **整果为主**；
- 商圈年轻人多、有冷柜人手 → **整果+切果并行**；
- 损耗控制差 → **先别大规模做切果**。

核心不是二选一，而是：**整果保销量和低损耗，切果提客单和便利性，切果比例控制在能当天清完的范围内。**
