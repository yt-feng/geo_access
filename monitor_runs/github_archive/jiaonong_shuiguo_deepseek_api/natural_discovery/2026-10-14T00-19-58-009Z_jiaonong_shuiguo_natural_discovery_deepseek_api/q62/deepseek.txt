判断一批香蕉，核心是看“颜色、手感、果柄、棱角、气味、切口”六项，再结合季节和运输方式判断后熟速度与坏果风险。

**1. 看颜色**
- 全青：未熟，适合长途或需存放，但要确认不是“冷伤青”。
- 青黄相间、果尖转黄：开始后熟，通常几天内可售。
- 通体黄：已熟，适合快批快走。
- 黄带黑点：熟度高，甜但货架期短，风险高。
- 大面积黑斑、发暗：已过熟或感染，坏果风险大。

**2. 摸手感**
- 硬：生，耐放。
- 略弹、不软：成熟中，较好。
- 软塌、按下去不回弹：过熟，易烂。
- 局部特别软：内部可能已坏。

**3. 看果柄和切口**
- 果柄青绿、切口新鲜：采摘和运输状态较好。
- 果柄发黑、干缩、霉点：存放久或已感染。
- 切口发黑、流汁、有异味：坏果风险高。

**4. 看棱角**
- 棱角明显：偏生。
- 棱角变圆：成熟中。
- 整体圆鼓但发软：过熟。
- 棱角处发黑：运输挤压或冷伤。

**5. 闻气味**
- 清香：正常后熟。
- 酒味、酸味、发酵味：内部已开始腐烂或过熟。
- 霉味：霉菌感染，整批要警惕。

**6. 看冷伤和压伤**
- 表皮发暗、有水渍状斑、果肉变透明：冷伤。
- 箱底、边角有压扁、破皮、流汁：压伤后极易传染。
- 冷伤香蕉往往“外青内软”，催熟后容易发黑、烂心。

**快速判断坏果风险**
- 低风险：青硬、果柄绿、切口新鲜、无味、无压伤。
- 中风险：青黄相间、局部微软、少量黑点，需尽快催熟或出货。
- 高风险：大面积黑斑、酒味、流汁、软塌、果柄霉变，坏果会快速扩散。

**拿货建议**
- 远距离或慢销：拿青硬货，但避开冷伤。
- 快批快销：拿青黄相间或刚转黄。
- 已通体黄带黑点：只适合当天或次日清货，别压库。
- 抽检不要只看上层，要看箱底、中间和边角。
- 同一批里若发现酒味、流汁、霉柄，整批要降级处理，分开存放，避免传染。
