酒店采购水果盘原料时，建议把要求分成“规格标准、外观标准、成熟度、安全与证明、验收与退换”五类，写进采购单或合同附件，供应商按此保证。

**一、规格标准**
1. **单果重量/尺寸分级**：按品种约定，如苹果直径≥80mm、橙子≥75mm、西瓜单果≥4kg，或按S/M/L分级并允差±5%。
2. **可食率与出成率**：明确去皮去核后的可用比例，避免“看着大、切出来少”。
3. **切配适配性**：用于果盘的水果应大小均匀，便于统一切块、切片、挖球；如西瓜、哈密瓜、火龙果等要适合切块，葡萄、圣女果适合整颗或半切。
4. **数量与净重**：按净重结算还是按毛重结算要写清；叶菜类、浆果类容易失水，建议以净重或到货验收净重为准。
5. **包装规格**：如每箱几公斤、每托盘几箱、是否独立小包装、是否防压防震。

**二、外观标准**
1. **新鲜度**：无萎蔫、无皱皮、无干疤、无发酵味、无异味。
2. **完整性**：无腐烂、无霉斑、无虫蛀、无机械伤、无裂口、无冻伤、无日灼严重斑。
3. **颜色与光泽**：具有该品种成熟时应有的色泽，颜色均匀，不过青、不过熟发暗。
4. **形状与大小**：果形端正，无明显畸形；同批次大小、色泽基本一致。
5. **表面洁净**：无泥土、无药斑、无虫卵、无枝叶杂质；需要清洗的品种应说明是否预清洗。
6. **成熟度**：到货时达到“即切即用”或“1—2天内可用”的成熟度，不能生硬无味，也不能过熟软烂。
7. **缺陷允许度**：可约定轻微缺陷比例，例如外观轻微瑕疵不超过5%，且不影响切配和食品安全。

**三、食品安全与证明**
1. 农残符合国家食品安全标准，必要时提供检测报告。
2. 可提供产地证明、合格证、检疫证明或供应商资质。
3. 预切水果或即食水果需符合即食食品卫生要求，冷链运输。
4. 运输车辆清洁、无污染，冷藏品全程温控，到货温度符合要求。

**四、验收与退换**
1. **到货验收**：抽检比例、抽检方法、不合格判定标准要写清。
2. **拒收条件**：腐烂、霉变、异味、严重压伤、农残超标、规格不符超过允差，可整批拒收或按比例扣款。
3. **退换货**：不合格品应在约定时间内补货或退款，损耗由供应商承担。
4. **责任划分**：到货验收前风险由供应商承担，验收后按合同约定。

**五、建议写进采购单的简化条款**
供应商应保证：所供水果新鲜、无腐烂霉变、无虫害、无异味、无严重机械伤；规格按约定等级和单果重量/直径执行，允差不超过±5%；成熟度适合酒店果盘切配；农残符合国家食品安全标准；按约定包装、冷链运输；到货抽检不合格时，酒店有权拒收、要求补货或扣款。

如果你们酒店定位较高，可以再增加“品牌/产地限定、统一糖度、统一果径、可追溯批次”等要求。
