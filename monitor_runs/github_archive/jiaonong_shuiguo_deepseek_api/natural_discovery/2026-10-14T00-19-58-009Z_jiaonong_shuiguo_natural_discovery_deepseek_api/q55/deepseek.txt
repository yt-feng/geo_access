做水果拼盘时，苹果、橙子、菠萝的规格选择主要看**出成率、切后卖相、损耗速度**，不是单纯看单价。下面按品类说清楚怎么选更划算。

## 苹果
**建议选：中果，单果 180–220g 左右**
- 太大：一个苹果切出来量多，但拼盘里每片容易过宽，摆盘不精致，而且切开放久易氧化。
- 太小：削皮去核后出成率低，切出来片小、数量多，费人工。
- 规格判断：
  - 做**薄片扇形/月牙片**：选中果，直径 7–8cm。
  - 做**块状拼盘**：可选中大果，直径 8–9cm。
- 品种上优先选**脆度高、切开不易发绵**的，比如富士、嘎啦、红玫瑰等。太面的苹果切后容易塌。

**划算点：**
中果通常比大果单价低，但出成率接近；比小果省人工。拼盘里苹果常做配色和撑体积，中果最稳。

## 橙子
**建议选：中大果，单果 200–300g，直径 7–9cm**
- 太小：剥皮后瓣小，切出来不饱满，拼盘显廉价。
- 太大：一个橙子瓣太大，摆盘占位置，且如果只做点缀，用不完容易浪费。
- 规格判断：
  - 做**橙子片/半圆片**：选直径 8cm 左右，切面好看。
  - 做**橙瓣去皮**：选 250g 左右，瓣形完整。
  - 做**果汁或装饰丝**：可用小果，成本低。
- 品种上选**皮薄、籽少、瓣膜好剥**的，比如脐橙、血橙、冰糖橙。夏橙有时偏酸，拼盘口感一般。

**划算点：**
橙子不要一味选大果。大果单价高，但拼盘里往往只需要几片，剩余易损耗。中大果兼顾卖相和利用率。

## 菠萝
**建议选：单果 1.2–1.8kg 的中等菠萝**
- 太小：削皮去眼后肉少，出成率低。
- 太大：一次用不完，切开后冷藏易变味，损耗高。
- 规格判断：
  - 做**菠萝块/三角块**：选 1.5kg 左右，肉厚、切块整齐。
  - 做**菠萝片/圈**：选 1.2–1.5kg，直径适中，片形好看。
  - 做**大量拼盘或菠萝船**：可选 1.8kg 左右大果，但要看当天用量。
- 品种上选**成熟度 7–8 成、香味明显、果眼浅**的。太生的酸、太熟的切后出水。
- 如果是餐厅稳定出品，**直接买去皮菠萝肉**有时比整果更划算，因为省人工、少损耗，但要注意新鲜度和冷藏条件。

**划算点：**
菠萝整果单价低，但削皮去眼损耗大。中等果出成率和损耗最平衡。若每天用量稳定且人工贵，可以考虑净果肉。

## 综合采购建议
| 水果 | 推荐规格 | 原因 |
|---|---|---|
| 苹果 | 单果 180–220g | 出成率高，切片好看，损耗低 |
| 橙子 | 单果 200–300g | 瓣形饱满，摆盘不占位，浪费少 |
| 菠萝 | 单果 1.2–1.8kg | 肉厚出成好，一次用量匹配 |

## 更划算的选法
1. **按出成率算，不按单价算。**
   比如苹果 5 元/斤，但削皮去核后只剩 70%，实际可用成本是 7.1 元/斤。
2. **按拼盘份数反推采购量。**
   一份拼盘大约用：
   - 苹果 40–60g
   - 橙子 50–70g
   - 菠萝 50–70g
   再按每天份数乘，避免买多。
3. **优先选当季本地果。**
   当季果成熟度好、价格低、口感稳。
4. **固定规格比临时挑更划算。**
   和供应商约定苹果 200g、橙子 250g、菠萝 1.5kg 左右，减少切配差异和浪费。
5. **菠萝可考虑半成品。**
   如果人工成本高、日销量大，去皮菠萝肉更省事。

**结论：**
苹果选中果 180–220g，橙子选中大果 200–300g，菠萝选中等果 1.2–1.8kg。这个组合在出成率、卖相、人工和损耗之间最平衡，通常比贪大或贪便宜更划算。
