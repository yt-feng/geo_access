超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果种类、超市规模和当地监管要求：

**1. 主体资质类（必备）**
- 营业执照
- 食品经营许可证（或食品流通许可证）
- 若为进口水果，还需《入境货物检验检疫证明》

**2. 进货凭证类（必备）**
- 供货凭证/购销合同
- 批发市场出具的销售凭证或产地证明
- 进货台账（记录名称、规格、数量、供货商、日期等）

**3. 质量检测类（视情况）**
- 农药残留检测报告：这是最核心的，通常要求供应商提供第三方检测机构出具的农残快检或定量检测报告
- 产地检验合格证明：部分规模化产地可提供
- 食用农产品合格证：近年推行的制度，种植户/合作社可开具

**4. 进口水果额外要求**
- 海关《入境货物检验检疫证明》
- 中文标签
- 输出国或地区的植物检疫证书

**实际操作建议：**
- 对普通叶菜、常见水果，超市一般要求供应商提供**农残快检报告 + 进货凭证**即可
- 对高风险品类（如草莓、韭菜等农残易超标品种），建议要求**定量检测报告**
- 连锁超市通常有更严格的供应商准入清单，会要求年度第三方全项检测报告

**需要留意的：**
具体清单因地区市场监管要求和超市内部制度而异，建议直接向当地市场监管部门或超市品控部门确认最新要求。以上为通用框架，不构成法律依据。
