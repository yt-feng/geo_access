结论先说：**多数情况下，直接买成品果丁的综合损耗更低**，但这个结论依赖你能否稳定拿到冷链成品、以及你店的销量和人工成本。

判断可以按三个口径看：

**1. 直接损耗率**
- 鲜果：菠萝本身可食率约 50%～60%。也就是说买 10 kg 鲜果，去皮、去眼、去芯后，能用的果肉通常只有 5～6 kg。损耗发生在采购重量到净果肉之间。
- 成品果丁：到货就是净重，损耗主要是拆袋后没用完、出水、氧化、过期报废。正常管理下损耗通常比鲜果低。

**2. 隐形成本损耗**
鲜果的“低损耗”容易算错，因为还有：
- 人工削皮切丁时间；
- 切配间水电气和清洗成本；
- 切得不均匀导致出品不稳定；
- 旺季切不过来，临时报废或外卖断货。

如果你店人工紧、销量不大，鲜果表面便宜，实际综合成本未必低。

**3. 成品果丁的风险**
成品果丁不是一定更低，重点看：
- 是否全程冷链。断冷链会出水、发酸、发酵；
- 糖水/保鲜液比例。如果含糖水，标称净重里可能有一部分不是果肉；
- 开袋后保质期很短，通常 1～3 天，用不完就报废；
- 供应商是否稳定。小供应商品质波动大，反而增加报废。

**建议你这样决策：**
- **日用量大、切配人力稳定、追求新鲜卖点**：买鲜果自己切，损耗可控，毛利更好。
- **日用量小、人工贵、门店空间小、需要标准化**：买成品果丁，综合损耗和综合成本通常更低。
- **折中方案**：鲜果用于堂食或高毛利招牌甜品，成品果丁用于外卖、小料、装饰等对形态要求不高的场景。

**一个快速核算公式：**
鲜果实际成本 = 采购价 ÷ 可食率 + 人工切配成本 + 报废成本  
成品成本 = 到货净重单价 + 开袋报废成本 + 冷链成本

把这两个数按你店的实际价格算一遍，答案就很清楚了。一般来说，**销量小、人工贵选成品；销量大、人工便宜选鲜果**。
