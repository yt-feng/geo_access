最应该先问**售后**，其次问**配送**，最后再压**价格**。

原因很直接：团购团长赚的是信任和复购，不是单次差价。水果又是非标、易损、损耗高的品类，一旦售后和配送不稳，价格再低也会把团长做死。

可以按这个顺序判断：

1. **售后优先问**
   - 坏果、烂果、缺斤少两怎么赔？
   - 是按比例赔、按个数赔，还是全额补发？
   - 拍照后多久处理？谁承担运费？
   - 是赔给团长，还是直接赔给团员？
   - 如果一批货大面积翻车，能不能整批退换？

   水果团购最怕的是团员收到烂果后找团长，团长却找不到上游负责。售后不清晰，团长就是最后兜底的人。

2. **配送第二问**
   - 到货时间是否稳定？
   - 是送到团长自提点，还是送到每个团员？
   - 冷链、泡沫箱、冰袋是否包含？
   - 破损率大概多少？
   - 旺季、节假日能不能保证时效？
   - 临时加单、少单怎么处理？

   配送决定体验下限。水果晚到一天、暴晒半天，品质就可能明显下降。

3. **价格最后谈**
   - 价格当然重要，但要在售后和配送都能兜底的前提下比价。
   - 不要只看进货价，要算“综合成本”：进货价 + 损耗 + 赔付 + 配送 + 团长时间成本。
   - 低价但售后扯皮的供应商，实际成本往往更高。

一句话判断标准：

**售后敢不敢兜底，决定你能不能做；配送稳不稳定，决定团员会不会复购；价格有没有优势，决定你赚多赚少。**

所以选水果供应商，先问售后，再问配送，最后谈价格。价格是最后一道筛选，不是第一道。
