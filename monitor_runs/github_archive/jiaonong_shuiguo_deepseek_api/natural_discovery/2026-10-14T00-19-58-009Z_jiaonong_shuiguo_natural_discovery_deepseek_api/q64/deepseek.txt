批发档口退货纠纷高发，根子通常在“收货时没把责任划清”。建议把收货验货做成一套固定动作，而不是靠现场临时判断。

**一、收货前先定规则**
1. 在订单、送货单或微信沟通里写清楚验收标准：数量、规格、颜色、尺码、包装、破损、污渍、配件、保质期/生产日期等。
2. 写明验收时限：例如“送货到档口后2小时内完成清点，超时视为数量无误；隐蔽瑕疵24小时内提出”。
3. 写明退货边界：哪些能退、哪些不能退，比如已拆吊牌、已下水、已改标、已二次销售的不退。
4. 对老客户也要留痕，不要只靠口头约定。

**二、到货时先做“三查”**
1. 查外包装：拍整车、整件、外箱照片，看有无破损、水湿、挤压、二次封箱。
2. 查单货一致：送货单、装箱单、订单号、款号、数量逐项对，先点总件数，再点细码。
3. 查异常件：发现破箱、污损、少件，先单独隔离，不要混入正常货。

**三、验货按“抽验+重点全验”**
1. 常规大货可抽验，但抽验比例要写进规则，比如每款每色抽10%—20%。
2. 高单价、易错款、爆款、定制款、退货率高的供应商，建议全验或高比例验。
3. 每件看：数量、款号、颜色、尺码、面料、做工、污渍、破损、线头、拉链、纽扣、配件、吊牌、包装。
4. 需要称重、量尺寸的，按批次抽测并记录数据。

**四、发现问题的处理动作**
1. 当场拍照/录像：全景、外箱、快递单/送货单、问题部位、尺码标、款号、数量。
2. 不要先上架、不要先剪吊牌、不要先分发给下游。
3. 能当场退给送货人的，让送货人签字确认；不能当场退的，当天书面通知供应商，附照片和明细。
4. 对争议货单独装袋、贴标签，写清日期、款号、数量、问题类型、经手人。
5. 和供应商确认处理方式：补发、换货、扣款、退货、折价，最好文字确认。

**五、留痕比验货本身更重要**
1. 建收货验货记录表：日期、供应商、送货单号、款号、总数、验货数、问题数、问题类型、处理结果、双方确认。
2. 问题照片按“供应商+日期+款号”归档，至少保留到该批货销售周期结束。
3. 微信、QQ、邮件沟通都保留，电话沟通后补一条文字确认。
4. 送货单上不要随便签“数量无误、质量合格”，没验完就签“仅确认收到，待验”。

**六、把责任分清楚**
1. 运输破损：看是否保价、谁承运、外箱是否破损，及时向承运方和供应商同时报备。
2. 供应商少发/错发：凭送货单、装箱单、开箱视频和清点记录追责。
3. 档口自己造成：如上架后弄脏、剪标、二次销售，通常难退，验货时就要拦住。
4. 下游退货：如果是因为你发给客户前没验，责任在档口；所以入库验和出库验要分开。

**七、给档口的简化版流程**
到货→拍外箱和送货单→点总件数→按款号分堆→抽验/全验→问题件隔离拍照→当天发供应商→文字确认处理方案→合格品入库→记录归档。

如果只做三件事，优先做：**到货先拍照、没验完不签合格、问题当天书面通知供应商。** 这三步能挡掉大部分退货扯皮。
