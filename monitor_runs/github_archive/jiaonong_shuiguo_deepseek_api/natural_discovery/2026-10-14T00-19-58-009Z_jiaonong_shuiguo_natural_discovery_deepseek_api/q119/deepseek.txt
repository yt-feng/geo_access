做水果生意，供应商选择最容易忽视的不是价格、产地这些显性项，而是一些“隐性但决定长期稳定性”的细节。以下按重要程度列出，并给出可执行的判断方法。

**1. 供应稳定性与替代能力**
很多人只看“现在能不能供货”，忽视“旺季/淡季/突发情况下能不能持续供”。
- 要问：同一单品有几个合作基地/果园？遇到台风、霜冻、疫情封控时，能否从其他产区调货？
- 判断方法：让对方说出近两年断供或延迟的案例，以及当时怎么解决的。答不上来或全是“没发生过”，反而要警惕。

**2. 分级标准的执行一致性**
水果是非标品，同一供应商不同批次的大小、糖度、成熟度可能差异很大。
- 要确认：是否有书面分级标准（单果重、果径、糖度、着色度、瑕疵率）？谁来判定？
- 判断方法：连续要3批货的到货验收记录，对比抽检合格率。如果波动超过约定范围，说明分级是“看人下菜”。

**3. 采后处理与冷链细节**
这是损耗和货架期的核心，却常被跳过。
- 要问：采摘后多久预冷？冷链车温度记录是否随货提供？包装是否按运输距离设计？
- 判断方法：索要最近一次冷链温度曲线，看是否有断链；到货后测中心温度，高于约定值直接扣款或拒收。

**4. 账期与资金占用背后的风险**
低价格往往伴随短账期或现结，这会吃掉你的现金流。
- 要算：不是看单价，而是看“综合到岸成本 + 资金占用成本 + 损耗率”。
- 判断方法：同一单品找2-3家报价，把账期、运费、损耗、退换货政策折算成每斤实际成本再比。

**5. 售后与索赔机制**
水果到货后烂损、规格不符是常态，关键看对方认不认、多久认。
- 要明确：验收时限、拍照留证要求、赔付比例、补货还是退款。
- 判断方法：在合同里写清“到货24小时内反馈有效”，并保留每批留样。口头承诺“有问题找我”基本等于没有。

**6. 供应商的客户结构**
如果对方主要供大型商超或批发市场，你的小单可能永远排在后面。
- 要问：你的订单占他出货量多少？旺季会不会优先保大客户？
- 判断方法：观察旺季时他给你的到货准时率和品质，是否明显低于淡季。

**7. 信息透明度**
愿意让你看果园、看分拣线、看冷库的供应商，长期合作风险更低。
- 判断方法：至少实地看一次，重点看分拣区是否按标准分流、冷库温度是否达标、工人操作是否规范。

**8. 合同里的“软条款”**
比如“以实际到货为准”“品质问题协商解决”，这些会让售后扯皮。
- 要改成可量化条款：糖度不低于X、单果重X-X克、瑕疵率不超过X%、到货温度不高于X℃。

**总结一句**：选水果供应商，短期看价格和货源，长期看的是“标准能不能执行、断供有没有预案、损耗谁来承担、账期是否可持续”。把这四条写进合同并持续记录数据，比单纯比价更能保证长期稳定。
