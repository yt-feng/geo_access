单位采购水果，核心是：**验收标准前置 + 到货当场留证 + 书面售后时限**。水果属于生鲜，坏果、大小不一、成熟度差异很常见，如果只看“总量对不对”，后面很容易扯皮。

下面按可执行流程说。

## 一、采购前先把标准写进合同/订单

不要等到货再争论“算不算合格”。下单前就要明确：

1. **品种、产地、等级**
   - 例如：红富士苹果，80mm 以上，一级果。
   - 如果是“统货”“一级”“特级”，要写清具体含义。

2. **规格**
   - 单果重量/直径范围，如 70–80mm。
   - 每箱净重、毛重、个数。
   - 允许的规格偏差，如 ±5%。

3. **成熟度**
   - 即食、催熟后食用、耐储存，要求不同。
   - 例如：香蕉到货成熟度 3–4 成，不能全黄。

4. **外观和瑕疵容忍度**
   - 允许轻微机械伤、日灼、果锈的比例。
   - 明确哪些算严重不合格：腐烂、霉变、虫蛀、裂口、异味、冻伤。

5. **验收方式**
   - 全检还是抽检。
   - 抽检比例，如每批抽 10%，或每箱抽 5 个。
   - 不合格判定规则：如抽检不合格率超过 5%，整批可退换。

6. **售后条款**
   - 到货当场验收，还是 24 小时内复检。
   - 坏果包赔比例。
   - 补发、换货、退款、扣款方式。
   - 响应时限：如 2 小时内响应，24 小时内补发。

7. **留证要求**
   - 到货照片、视频、称重记录、开箱视频。
   - 双方签字确认的验收单。

## 二、到货验收怎么做

建议按这个顺序：

### 1. 先核对单据和数量
- 送货单、订单、合同是否一致。
- 品种、箱数、件数、总重量是否对。
- 冷链水果要看运输温度记录。

### 2. 再抽检品质
按批次分层抽样，不要只开最上面一箱。

检查项：
- **大小**：用卡尺或称重，看是否符合规格。
- **颜色**：是否过青、过熟、发黑。
- **硬度**：是否过软、腐烂、冻伤。
- **气味**：是否有发酵味、霉味。
- **瑕疵**：烂果、虫眼、裂口、压伤、发霉。
- **成熟度**：是否适合单位食堂/发放/储存。

### 3. 现场记录
建议做一张简单验收单：

| 项目 | 记录 |
|---|---|
| 到货时间 | |
| 供应商 | |
| 品种/规格 | |
| 订单数量 | |
| 实收数量 | |
| 抽检数量 | |
| 不合格数量 | |
| 不合格率 | |
| 问题描述 | |
| 处理意见 | |
| 双方签字 | |

同时拍：
- 整车/整批外观
- 开箱过程
- 不合格果特写
- 称重照片
- 送货单和签字单

### 4. 判定处理
可以分三档：

- **轻微不一致**：如少量大小偏差、轻微外观差异  
  → 可接收，但按比例扣款或要求下次补足。

- **部分不合格**：如坏果率 5%–15%  
  → 要求现场分拣，按实际合格数量结算，或补发。

- **严重不合格**：如腐烂、霉变、异味、规格严重不符、合格率低于约定  
  → 拒收、整批退回、要求换货，并保留追责权利。

## 三、售后怎么处理

### 1. 当场提出，不要拖
生鲜最容易争议的就是“是不是你放坏的”。所以：
- 到货当场发现问题，当场拍照、当场通知供应商。
- 最好让送货员签字确认。
- 如果当场无法全检，合同里要写“到货后 X 小时内可复检”。

### 2. 书面通知
用微信、邮件、钉钉都行，但内容要清楚：
- 批次、到货时间、订单号
- 问题描述
- 照片/视频
- 不合格数量或比例
- 要求：补发/换货/退款/扣款
- 回复时限

示例：
> 今日到货红富士苹果 20 箱，抽检 200 个，其中 18 个腐烂、23 个规格低于 70mm，不合格率约 20.5%。附件为照片和称重记录。请于今日 17:00 前确认补发 4 箱合格果或按比例退款。

### 3. 处理方式
常见有：
- **补发**：适合还能用，但数量不足。
- **换货**：适合整批品质不达标。
- **退款/扣款**：适合部分坏果，按合格数量结算。
- **整批拒收**：适合严重不合格。
- **折价接收**：适合不影响使用，但品质低于约定。

### 4. 留好证据
- 验收单
- 照片视频
- 聊天记录
- 邮件
- 称重记录
- 退货/补发记录
- 付款和扣款凭证

## 四、建议写进采购要求的条款

可以直接用这几条：

1. 到货后由采购方按不低于 10% 比例抽检。
2. 抽检不合格率超过 5%，供应商需补发或换货。
3. 腐烂、霉变、虫蛀、异味果按 1:1 补足。
4. 规格不符超过 10%，采购方有权拒收或按比例扣款。
5. 供应商需在接到通知后 2 小时内响应，24 小时内提出处理方案。
6. 因质量问题产生的退换货运输费用由供应商承担。
7. 验收以双方签字确认的验收单和现场影像为准。

## 五、最简单的执行版

如果你们没有很复杂的合同，就抓这 4 件事：

1. **下单前**：写清品种、规格、坏果率上限、售后时限。
2. **到货时**：抽检、拍照、称重、填验收单、让送货人签字。
3. **有问题**：当场书面通知，要求补发/换货/扣款。
4. **结算时**：按合格数量结算，不合格部分不付款或扣款。

这样基本能避免“到货品质不一致，后面说不清”的问题。
