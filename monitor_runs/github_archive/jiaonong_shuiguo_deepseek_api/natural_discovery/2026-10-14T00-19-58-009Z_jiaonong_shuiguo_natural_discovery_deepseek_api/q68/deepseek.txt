判断供应商能不能按时到车，核心不是听承诺，而是看“可验证的履约能力”。建议按下面顺序做。

**一、合作前先查底子**
1. **看有没有稳定货源基地**：是自有基地、长期合作基地，还是临时调货。临时调货的，旺季最容易掉链子。
2. **看车辆和司机情况**：问清是自有车、长期合作车队，还是临时找车。临时找车的，节假日、雨天、查超时最容易延误。
3. **看历史履约记录**：让他提供近1个月的发车记录、到货记录，重点看有没有迟到、放空、换车、换货。
4. **看是否只做你一家**：同时接很多单的供应商，旺季容易先保大客户，小单被往后排。

**二、下单时把条件锁死**
1. **明确到车时间**：不要只写“明天到”，要写“几月几日几点前到市场/仓库”。
2. **写明车型、载重、车牌**：防止临时换小车、拼车、转车。
3. **约定迟到处理**：比如超过几小时扣多少钱、超过多久可拒收、损失谁承担。
4. **约定放空和换货责任**：车没来、货不对板、以次充好，怎么赔。
5. **定金和尾款挂钩到车**：不要全款先打，最好到车验货后付尾款。

**三、发车前做三次确认**
1. **装车前确认**：问是否已经装车，装了多少件、什么规格。
2. **发车后确认**：要司机电话、车牌、定位，最好让司机发装车视频和出车视频。
3. **途中确认**：预计到达前几小时再确认一次位置和路况，别等到时间到了才问。

**四、用细节判断靠不靠谱**
1. **回复是否具体**：靠谱的会说车牌、司机电话、装车时间、预计到达时间；不靠谱的只会说“放心”“没问题”。
2. **是否主动同步异常**：堵车、装车慢、车坏了，靠谱的会提前说；不靠谱的会一直拖到你去问。
3. **是否愿意写进合同或微信确认**：不愿意留文字凭证的，要警惕。
4. **是否接受视频验货**：装车视频、车厢视频、磅单，能提供这些的通常更稳。

**五、实操建议**
- 新供应商第一单不要下大单，先小批量试一车。
- 旺季提前2—3天锁车，不要当天临时找。
- 同一线路最好备2—3个供应商，别只靠一家。
- 关键节点全部用微信留痕：到车时间、车牌、司机电话、迟到责任。
- 到车后先验货再卸车，发现规格、成熟度、数量不对，立即拍照留证。

**一句话判断标准**：能给出具体车牌、司机电话、装车视频、明确到车时间，并且愿意把迟到责任写清楚的，才基本可信；只靠口头保证、催款很急、信息含糊的，按时到车风险就高。
