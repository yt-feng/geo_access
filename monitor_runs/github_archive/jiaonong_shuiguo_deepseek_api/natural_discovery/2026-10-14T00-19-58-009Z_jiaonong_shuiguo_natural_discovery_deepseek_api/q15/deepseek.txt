水果店遇到坏果，处理方式主要取决于**采购模式**和**事前约定**。以下是常见的结算和赔付做法：

## 一、先分清采购模式

**1. 批发市场/产地直采（现结、看货买断）**
- 一般当场验货，离场后坏果风险多由自己承担。
- 能做的是：当场挑出坏果，让供应商补货或按比例扣款；离场后发现的，协商解决，没有强制依据。

**2. 长期合作供应商（有账期、有协议）**
- 按合同或口头约定处理，通常有明确的赔付标准。

## 二、常见赔付/结算方式

| 方式 | 说明 |
|------|------|
| 按坏果比例扣款 | 如到货100斤，坏10斤，按10%扣款或补货 |
| 补货 | 供应商下次送货时补同等数量 |
| 换货 | 整批退回，重新发货 |
| 折价结算 | 坏果部分按折扣价或成本价结算 |
| 全额退货 | 坏果比例过高（如超20%~30%），整批退回不结算 |

## 三、操作建议

**收到货当场做：**
1. **拍照/录像**：开箱、称重、坏果特写、整体堆头，留证据。
2. **分类称重**：好果、坏果分别过秤，记录比例。
3. **及时反馈**：最好当天或约定时限内通知供应商，别拖到几天后。

**和供应商谈：**
- 先看有没有事前约定（合同、微信聊天记录、口头承诺）。
- 没约定的，按行业惯例谈，常见是“坏果照价扣款”或“补货”。
- 长期合作以协商为主，别为一批货闹僵，但也要守住底线。

## 四、容易踩的坑

- **口头约定没留痕**：微信确认一下赔付方式，比事后扯皮强。
- **拖太久才反馈**：供应商会说是你自己存放坏的。
- **没当场验货**：离场后基本只能协商，没有强制力。
- **坏果比例认定分歧**：最好双方一起开箱、一起称重。

## 五、写进合作条件更省心

如果长期合作，建议在采购时明确：
- 坏果率超过多少算不合格（如5%）
- 超出部分怎么赔（扣款/补货/换货）
- 反馈时限（如24小时内）
- 生鲜损耗的正常范围谁承担

---

**一句话总结**：当场验货、留证据、按约定或协商比例扣款/补货；长期合作最好事前把坏果率标准和赔付方式谈清楚，写进聊天记录或合同。
