要避免香蕉到店后很快变黑，核心是控制**成熟度、温度、机械损伤和乙烯暴露**。采购时按下面几条做，通常能明显延长货架期：

1. **买“青一点”的香蕉，不要买已经全黄甚至带黑点的**
   - 最佳到店状态：**微黄带绿、果柄青绿、没有黑斑**。
   - 如果当天就要用，可以买黄熟的；如果要放1–3天，买青黄交接的。
   - 已经出现芝麻黑点、果柄发黑、整串发软的，到店后基本很快变质。

2. **要求供应商冷链运输，但不要冻伤**
   - 香蕉适宜储运温度大致在 **13–15℃**。
   - 低于约12℃容易冷害，表皮变黑、果肉发硬或发暗。
   - 夏天采购时，尽量用冷藏车或空调车，避免后备箱高温闷放。

3. **到店后不要马上堆在常温潮湿处**
   - 先拆外箱通风，检查有没有压伤、裂果、发霉。
   - 暂存放在 **阴凉、通风、13–15℃** 的地方。
   - 如果没有恒温库，放在空调房阴凉处，避免靠近烤箱、蒸箱、热水槽、阳光直射处。

4. **减少机械损伤**
   - 香蕉被挤压、磕碰后，伤处会快速褐变并传染周围。
   - 搬运时不要整箱摔放，不要用尖物划伤。
   - 到店后把压伤、裂口的香蕉先挑出来优先使用，不要和好果混放。

5. **控制乙烯，别和苹果、梨、番茄等混放**
   - 苹果、梨、番茄、牛油果等会释放乙烯，催熟香蕉。
   - 香蕉本身也会释放乙烯，所以成熟度高的香蕉要单独放，别闷在纸箱里。
   - 需要延缓成熟时，可适当通风，降低周围乙烯浓度。

6. **不要整串闷在塑料袋里**
   - 塑料袋不通风，容易积水汽，加速发黑和霉变。
   - 可用透气的纸箱、网筐或保鲜袋稍微开口存放。
   - 如果已经切开，切口用保鲜膜包好冷藏，并尽快使用。

7. **按用量分批采购**
   - 甜品店最好“少量多次”采购，不要一次囤太多。
   - 根据销量预估：当天用多少、第二天用多少，分别买不同成熟度。
   - 需要当天做香蕉泥、香蕉蛋糕的，可以用熟蕉；需要陈列或后续使用的，买生一点。

8. **到店后做简单分级**
   - 青黄：常温阴凉催熟，后续用。
   - 微黄：优先用于当天或次日产品。
   - 全黄：尽快用，可冷藏短期延缓，但冷藏后表皮仍可能变黑。
   - 有黑点但果肉正常：适合做香蕉泥、烘焙，不适合装饰。

9. **冷藏只适合“已成熟且马上要用”的香蕉**
   - 未熟香蕉冷藏容易冷害，之后更难正常成熟。
   - 已熟香蕉如果必须多放1–2天，可冷藏，但表皮会变黑，果肉短期内仍可用。
   - 用于装饰的香蕉，尽量当天买当天用。

10. **和供应商约定到货标准**
   - 明确要求：果柄青绿、无黑斑、无压伤、无冷害、到货温度约13–15℃。
   - 如果经常到店就发黑，优先换供应商或调整配送时间，比如改成每天早配，而不是隔天大量配。

简单判断标准：
- **想放2–3天**：买青黄交接、硬挺、无斑。
- **想当天用**：买黄熟、无伤、无黑点。
- **已经全黄带黑点**：别再等，尽快做香蕉泥或烘焙。

最关键的一句：**香蕉到店后快黑，通常不是“放坏了”，而是采购时已经太熟、运输温度不对、被压伤或和催熟水果闷在一起。** 把这四点控制住，基本就能明显改善。
