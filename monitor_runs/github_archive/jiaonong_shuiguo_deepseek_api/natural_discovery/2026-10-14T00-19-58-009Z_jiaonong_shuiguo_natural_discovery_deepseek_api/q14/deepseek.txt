可以，但“给不给、给多少”取决于你的采购量、合作稳定性和谈判方式。周末促销常见能争取到的支持有这几类：

1. **价格支持**
   - **周末特价供货**：对1-2个引流单品，供应商按低于日常批发价供货。
   - **满额返点/达量返利**：比如周末两天进货满多少件，返几个点或下批抵扣。
   - **临时补贴**：针对你选的爆款，供应商承担一部分降价差额。
   - **账期支持**：先货后款、延长账期，缓解周末备货现金流。

2. **物料支持**
   - 海报、爆炸贴、价格牌、吊旗、围挡。
   - 试吃盒、牙签、一次性手套、打包袋。
   - 供应商品牌周边：遮阳棚、推车、工服、购物袋。
   - 线上素材：朋友圈海报、短视频素材、产品图。

3. **人员/活动支持**
   - 周末派促销员或理货员驻店。
   - 试吃推广、叫卖支持。
   - 帮你做堆头、端架陈列。

**供应商一般愿意支持的情况：**
- 你是稳定客户，月采购量还可以。
- 你主推的是他的品牌或他急着走量的单品。
- 促销能帮他清库存、冲销量、打竞品。
- 你愿意把陈列位、海报位、朋友圈曝光给到他。
- 你提前谈，不是周五晚上才临时要。

**谈判时可以直接这样问：**
- “这周末我准备主推你家XX，预计拿XX件，能不能给个周末特供价？”
- “价格降不了的话，能不能支持点海报、试吃盒、价格牌？”
- “我这边给你做堆头+朋友圈推广，你能否给一箱搭赠或返点？”
- “如果周末两天进货满XX件，能不能返XX个点/下批抵扣？”

**注意：**
- 生鲜水果价格波动大，供应商通常更愿意给**搭赠、返点、物料**，而不是直接长期降价。
- 口头承诺要落到订单、微信记录或简单协议里，写清品种、规格、数量、价格、支持内容、结算方式。
- 不要只压价，最好给对方“销量+曝光+稳定采购”的交换条件。

简单说：**能要，而且应该要。先谈特价和搭赠，再谈物料和人员，最后用陈列和推广资源去换。**
