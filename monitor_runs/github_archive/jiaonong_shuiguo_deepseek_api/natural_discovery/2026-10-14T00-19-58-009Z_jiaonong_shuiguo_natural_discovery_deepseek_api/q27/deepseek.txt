判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看**目标客群、陈列方式、价格带和损耗率**。可以按下面这套标准直接判断。

## 一、先定门店销售场景

不同门店适合的规格不同：

| 门店类型 | 更适合的规格方向 | 原因 |
|---|---|---|
| 社区生鲜店 | 中等规格、家庭装 | 家庭一次买几个，太大单价高，太小显廉价 |
| 精品水果店 | 中大果、礼盒果 | 卖相和送礼需求强 |
| 商超散称区 | 中等偏小、均匀 | 按斤称重，顾客挑拣多，均匀度重要 |
| 便利店/小业态 | 小规格、即食装 | 客群单人/双人，购买量小 |
| 团购/批发 | 大规格、耐运输 | 看重斤价和货架期 |

所以先问：**卖给谁、怎么卖、按个卖还是按斤卖。**

## 二、苹果规格判断

苹果常见按果径分，例如 70、75、80、85、90 等，单位通常是毫米。

### 适合门店销售的判断点

1. **果径是否均匀**
   - 同一批货果径差最好控制在 5mm 以内。
   - 如果 70 和 90 混在一起，顾客会挑大的，小的剩货，损耗高。

2. **单果重量是否稳定**
   - 苹果常见单果重：
     - 小果：150–180g
     - 中果：180–220g
     - 大果：220–280g
     - 特大果：280g 以上
   - 社区店散卖更适合 180–220g，拿起来有分量但不压手。

3. **外观等级**
   - 门店销售至少要看：果形端正、无明显畸形、无严重锈斑、无碰伤、无虫眼。
   - 精品店要求更高：着色均匀、果面干净、大小一致。

4. **硬度与新鲜度**
   - 轻按果肩，明显发软的不适合门店长陈列。
   - 苹果若已发绵，做特价可以，但不能作为正常规格品。

5. **包装箱标称规格是否可信**
   - 看箱标：果径、个数、净重。
   - 抽检 10–20 个，量果径和称重。
   - 如果标 80，实际大量 75 以下，说明规格不达标。

### 简单结论
- 社区店/散称：**果径 75–85，单果 180–220g，均匀度好**，通常比较稳。
- 精品/礼盒：**果径 85 以上，单果 220g 以上，外观整齐**。
- 便利店/小家庭：**果径 70–80，单果 150–200g**，单价更容易接受。

## 三、橙子规格判断

橙子常见也按果径分，如 60、65、70、75、80 等，单位毫米。不同品种差异大，比如脐橙、血橙、冰糖橙、沃柑不能一刀切。

### 适合门店销售的判断点

1. **果径均匀度**
   - 同一陈列批次，果径差最好不超过 5–8mm。
   - 橙子如果大小混装，顾客会翻拣，造成碰伤。

2. **单果重量**
   - 常见门店适中规格：
     - 小果：120–160g
     - 中果：160–200g
     - 大果：200–260g
     - 特大果：260g 以上
   - 散称社区店通常 160–220g 比较好卖。
   - 礼盒或精品店可选 220g 以上。

3. **皮厚与可食率**
   - 同样大小，皮太厚的不划算，顾客复购差。
   - 判断方法：抽几个切开或剥开，看果肉占比。
   - 若果径大但皮厚、空壳感明显，不适合作为高毛利主推。

4. **新鲜度**
   - 果蒂青绿或新鲜，果皮紧实有弹性。
   - 果皮明显失水、发皱、发软，不适合正常货架。
   - 油胞下陷、霉变、烂点，直接淘汰。

5. **品种与销售定位**
   - 冰糖橙：小果也受欢迎，但必须甜。
   - 脐橙：中等偏大更符合送礼和家庭消费。
   - 沃柑：中等规格、皮薄易剥更关键。
   - 血橙：规格不是第一，颜色和口感更重要。

### 简单结论
- 社区散称：**果径 65–75，单果 160–220g，大小均匀**，通常适合。
- 精品/礼盒：**果径 75 以上，单果 220g 以上，外观漂亮**。
- 便利店/即食：**果径 60–70，单果 120–180g**，单价低、方便买。

## 四、门店采购时直接执行的验收方法

到货后不要只看箱标，按这几步做：

1. **抽检比例**
   - 小批量：抽 10–20 个。
   - 大批量：每箱抽 5–10 个，至少抽 3–5 箱。

2. **量果径**
   - 用水果卡尺或分级板。
   - 记录最大、最小、平均果径。
   - 看是否符合采购约定。

3. **称单果重**
   - 随机称 10 个，算平均单果重。
   - 同时看最重和最轻差多少。
   - 差距过大说明分级差。

4. **看均匀度**
   - 把抽检果按大小排一排。
   - 如果肉眼一看就大小分明，不适合做统一规格陈列。

5. **看损伤率**
   - 碰伤、压伤、烂果、霉果比例。
   - 超过 3%–5% 就要扣重、换货或降价处理，否则门店损耗会很高。

6. **试口感**
   - 苹果：脆度、甜度、是否发绵。
   - 橙子：甜酸比、水分、皮厚、是否干渣。
   - 规格再好，口感不行也不适合主推。

7. **算毛利和损耗**
   - 进货价按净重算，不要按毛重算。
   - 加上预计损耗 5%–15%。
   - 如果售价减进货价减损耗后毛利太薄，规格再漂亮也不适合。

## 五、最常见的误判

1. **只看大果**
   - 大果单价高，社区店可能卖不动，最后损耗大。

2. **只看箱标**
   - 箱标写 80，实际可能混 70。必须抽检。

3. **忽略均匀度**
   - 大小混装会导致顾客挑拣，剩小果，损耗增加。

4. **忽略口感**
   - 水果规格是卖相，口感才是复购。

5. **忽略陈列方式**
   - 礼盒要整齐，散称要均匀，堆头可以略宽松但也不能差太多。

## 六、直接可用的采购标准模板

你可以这样写采购要求：

**苹果**
- 品种：______
- 果径：75–85mm，允许 ±5mm
- 单果重：180–220g
- 均匀度：同批次果径差 ≤5mm
- 外观：无严重碰伤、虫眼、畸形，着色良好
- 口感：脆甜，无明显发绵
- 损耗率：到店 ≤5%

**橙子**
- 品种：______
- 果径：65–75mm，允许 ±5mm
- 单果重：160–220g
- 均匀度：同批次果径差 ≤8mm
- 外观：果皮新鲜紧实，无霉烂、无严重皱皮
- 口感：甜酸适口，水分足，皮不过厚
- 损耗率：到店 ≤5%
