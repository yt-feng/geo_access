最省心的方向，优先选**本地水果批发市场里做“餐饮配送”的档口/二批**，其次才是生鲜B2B平台。原因很简单：你每天量少、品类可能变、又要稳定，纯批发商不一定接，平台又容易起送价/品质波动。

可以按这个顺序找：

1. **本地水果批发市场的二批/配送档口**
   - 直接问：接不接餐饮店每天少量配送、起送金额多少、能不能按你要的品种和熟度配。
   - 优点：价格通常比平台低，能换货、能临时加单，沟通直接。
   - 适合：每天几十到一两百元、3～5个单品以内。

2. **生鲜B2B平台**
   - 比如美团快驴、美菜、饿了么有菜这类，具体以你当地开通为准。
   - 优点：下单省事、有票、售后流程清楚。
   - 缺点：起送价、配送时间、品质稳定性要看区域，小量可能不划算。

3. **本地果蔬配送商/净菜配送商**
   - 他们本来给餐馆送菜，顺带送水果最顺。
   - 优点：一个供应商解决蔬菜+水果，对账、收货都省心。
   - 适合：你本来就有蔬菜配送商，优先问能不能加水果。

4. **附近大型水果店/连锁店**
   - 有些店愿意给周边餐饮做每日配送。
   - 优点：离得近，补货快。
   - 缺点：价格未必低，品类偏零售。

选供应商时重点看这几点：

- **起送门槛**：每天少量能不能送，别今天送明天不送。
- **配送时间**：能不能在你营业前送到，比如早上7～9点。
- **退换规则**：坏果、熟度不对、规格不符能不能当场退换。
- **报价方式**：是固定价还是每天随行就市，能不能提前发报价单。
- **结算周期**：日结、周结、月结，能不能开票。
- **稳定性**：同一品种每天规格是否一致，别今天大果明天小果。

最省心的组合建议：

- 如果每天用量很小：找**市场档口+微信下单**，提前一天报单。
- 如果店里本来有蔬菜配送：直接让**蔬菜配送商加水果**。
- 如果连锁/要票据：用**B2B平台**，但先试一周看品质。

实操上，先找2～3家同时试：

- 每家试3～5天；
- 固定几个常用水果：苹果、橙子、香蕉、柠檬、西瓜这类；
- 记录到货时间、坏果率、价格、临时加单响应；
- 一周后留1家主供、1家备选。

一句话：**优先找本地做餐饮配送的水果二批或你现有的蔬菜配送商，让他们每天按单送，比你自己去市场或纯零售店买省心得多。**
