遇到水果到货不合格，核心不是“事后怎么吵”，而是**把补货写成可执行条款，并让门店当天就能先恢复营业**。建议按下面做：

**1. 合同/订货单里先写清验收标准**
- 按品类写：品种、规格、单果重量、成熟度、糖度、色泽、允许损伤比例。
- 写清“不合格判定”：腐烂、发霉、压伤、冻伤、异味、以次充好，分别怎么算。
- 约定验收时限：到货后30-60分钟内完成抽检，拍照留证，超时未提异议视为合格。
- 约定抽检比例：比如每批次抽10%，高风险水果抽20%。

**2. 补货条款要写“先补货、后追责”**
- 供应商应在接到通知后**X小时内**补发合格同品项同数量货物。
- 补货运输费用、装卸费用由供应商承担。
- 因补货不及时导致门店缺货、下架、停售的，供应商按缺货货值或营业额损失赔偿。
- 供应商不得以“先退回旧货再补新货”为条件拖延；可约定“先补新货，旧货同车退回或另行处理”。

**3. 给门店留“应急替代”权利**
- 若供应商不能在约定时间内补货，门店有权就近采购同品质水果，差价和额外运费由供应商承担。
- 门店有权临时调整菜单、下架相关产品，不视为违约。
- 对已到货但部分合格的水果，可约定“合格部分先收，不合格部分拒收并补货”，避免整批卡死影响营业。

**4. 结算和扣款要挂钩**
- 不合格批次货款可暂扣，补货合格并验收后再结。
- 设置质量保证金或月结扣款机制：比如每批次不合格扣当批货款10%-30%。
- 连续2次或月度累计3次不合格，门店有权暂停下单、更换供应商或解除合同。

**5. 当天实操流程**
- 到货先拍照、称重、开箱抽检。
- 不合格立刻发书面通知：微信/邮件/系统订单备注都算，写清批次、数量、问题、要求补货时间。
- 让供应商确认回复，未回复也保留记录。
- 同时启动备用采购或临时菜单调整，先保营业。
- 补货到店后二次验收，合格再入库、再结算。

**6. 条款示例**
> 供应商交付水果经门店验收不合格的，应在接到通知后4小时内补发同等规格、同等数量合格货物，费用由供应商承担。门店有权先接收合格部分，不合格部分拒收并要求补货。供应商逾期未补货的，门店有权自行采购替代品，差价及运费由供应商承担，并按缺货货值20%支付违约金。连续两次不合格，门店有权解除本批次及后续订单。

**关键点：**
补货条款要同时满足三个条件：**时间明确、责任明确、门店有替代权**。只要供应商不能按时补，门店就能自己买、先营业，再让供应商承担差价和损失。这样才不会因为一批烂水果把当天生意卡住。
