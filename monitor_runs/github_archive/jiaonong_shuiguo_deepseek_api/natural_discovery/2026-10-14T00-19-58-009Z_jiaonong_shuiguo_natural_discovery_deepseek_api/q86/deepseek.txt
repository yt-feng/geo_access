做生鲜水果一件代发，供应商仓配能力不能只看“有没有仓库和快递”，要重点看**能否稳定承接小单、多SKU、按单发货，且损耗和时效可控**。建议至少从以下 7 个方面核验：

1. **产地或销地仓能力**
   - 有稳定仓库，最好靠近产区或核心销地。
   - 能支持多温区：常温、冷藏，部分水果需 0~8℃ 或 10~15℃。
   - 有预冷、分级、打包、贴单、暂存区，不是普通电商仓简单代发。
   - 仓库需具备日处理单量能力，例如日常 3000~10000 单、峰值可扩容。

2. **水果分级与品控能力**
   - 能按平台标准做大小、重量、糖度、成熟度、外观分级。
   - 有抽检、坏果率控制、次果剔除流程。
   - 能提供批次质检记录，支持售后举证。
   - 对易损水果如草莓、樱桃、荔枝、水蜜桃，要有专门包装方案。

3. **按单打包与耗材能力**
   - 支持一件代发，不是只发整箱批发。
   - 有适配不同水果的包装：泡沫箱、冰袋、吸水纸、网套、气柱袋、保温袋等。
   - 能按订单放入卡片、赠品、发票等。
   - 打包效率稳定，避免大促爆单后延迟发货。

4. **快递与时效能力**
   - 有稳定合作的快递或专线，能发全国或指定区域。
   - 能明确时效：同省、江浙沪、京津冀、偏远地区分别多久。
   - 支持顺丰、京东、中通、圆通、极兔等不同价格带方案。
   - 能提供物流轨迹回传、异常件拦截、改址、拒收处理。
   - 对高客单或易损水果，最好能走航空、冷链或高铁快运。

5. **库存与订单系统对接能力**
   - 能实时同步库存，避免超卖。
   - 支持 API/ERP/WMS 对接平台订单。
   - 能回传发货状态、快递单号、批次信息。
   - 支持多平台订单：抖音、快手、拼多多、淘宝、私域小程序等。
   - 能处理退换货、补发、仅退款等售后流程。

6. **损耗与售后兜底能力**
   - 明确坏果率标准，例如 5% 以内、10% 以内，按品类不同。
   - 有售后赔付规则：坏果拍照、按比例赔、补发或退款。
   - 能区分责任：物流延误、冻伤、压伤、熟过头、缺斤少两。
   - 能提供售后数据，帮助平台判断供应商是否稳定。
   - 最好有坏果包赔或售后基金机制。

7. **峰值与应急能力**
   - 大促、节日、爆款期间能临时增加人手和包材。
   - 有天气、疫情、交通管制等异常预案。
   - 能切换快递或临时仓，避免单一节点瘫痪。
   - 对爆单有明确日产能上限，不接超出能力的单。

**判断供应商是否合格，可以重点问这 8 个问题：**
1. 日发单量多少？峰值多少？  
2. 哪些水果能做一件代发？哪些只能整箱？  
3. 坏果率承诺多少？售后怎么赔？  
4. 发什么快递？偏远地区发不发？  
5. 能否 API 对接？库存多久同步一次？  
6. 打包是否含冰袋、泡沫箱、气柱？是否另收费？  
7. 发货时效是 24 小时还是 48 小时？  
8. 出现大面积坏果，能否补发、退款或承担平台罚款？

**简单结论：**
合格的水果一件代发供应商，至少要具备：**产地/销地仓 + 分级品控 + 专业打包 + 稳定快递 + 系统对接 + 售后赔付 + 峰值扩容**。如果只有仓库和快递，没有品控与售后兜底，生鲜平台合作后很容易被坏果率和物流时效拖垮。
