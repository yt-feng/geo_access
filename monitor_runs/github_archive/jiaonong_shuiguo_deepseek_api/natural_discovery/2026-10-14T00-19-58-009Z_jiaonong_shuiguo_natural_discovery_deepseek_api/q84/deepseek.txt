如果是家庭自己吃，组合原则不是“每样都放”，而是**耐放、好分食、甜酸搭配、不互相催熟压坏**。可以按下面选：

**最推荐：苹果 + 橙子 + 香蕉**
- 适合家庭日常吃，接受度高，老人小孩都能吃。
- 苹果、橙子耐放；香蕉负责软甜和香气。
- 建议比例：苹果 40%、橙子 40%、香蕉 20%。
- 注意：香蕉会释放乙烯，最好单独套袋或放最上层，别压着苹果橙子。

**想要体面礼盒感：苹果 + 橙子 + 菠萝**
- 更耐运输、耐存放，适合送家庭或团购统一发货。
- 菠萝有“分量感”，礼盒看起来更值。
- 建议比例：苹果 35%、橙子 35%、菠萝 30%。
- 注意：菠萝带皮占空间、处理麻烦，家庭如果嫌削皮烦，可换成果切菠萝或小菠萝。

**不建议四样全混成一个大礼盒**
- 香蕉和菠萝都容易压伤、催熟其他水果。
- 四样混装看似丰富，实际容易“先坏一颗，坏一箱”。
- 如果一定要四样，建议做**分格/独立袋装**，并减少香蕉数量。

**家庭团购最优组合建议**
1. 走量实惠款：苹果 + 橙子 + 香蕉，比例 4:4:2。
2. 送礼耐放款：苹果 + 橙子 + 菠萝，比例 3.5:3.5:3。
3. 想四样都有：苹果 + 橙子 + 香蕉 + 菠萝，但做分格，比例 3:3:2:2，香蕉最少。

**挑选要点**
- 苹果选脆甜耐放的，如富士、嘎啦。
- 橙子选好剥皮的，如脐橙、冰糖橙。
- 香蕉别选全黄熟透的，选微黄带绿，到家刚好能吃。
- 菠萝选小菠萝或金钻凤梨，家庭更好处理。

**结论：家庭团购优先“苹果 + 橙子 + 香蕉”；要耐放、有礼盒感就“苹果 + 橙子 + 菠萝”。四样混装可以做，但必须分格，香蕉比例要低。**
