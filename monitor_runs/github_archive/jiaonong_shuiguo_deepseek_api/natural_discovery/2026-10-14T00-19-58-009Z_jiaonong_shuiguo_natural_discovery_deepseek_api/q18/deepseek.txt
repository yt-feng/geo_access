核心看**颜色 + 手感 + 用途**，按下面判断，基本不会买错。

**1. 先定用途**
- **当天吃**：买黄皮带少量褐斑、手感微软的。
- **2～3天内吃**：买通体黄、无斑或极少斑、捏着略硬的。
- **4～6天后吃**：买黄绿相间、果柄偏绿的。
- **更久或做奶昔/烘焙**：可买青一点的，回家常温放；做香蕉面包可专门买带黑斑的熟蕉。

**2. 到店看这几点**
- **颜色**：越青越耐放；全黄带黑斑最熟，通常只能放1～2天。
- **果柄**：柄绿、粗硬，说明刚转熟；柄发黑、干瘪，通常偏熟或放久了。
- **棱角**：香蕉有明显的五条棱，棱角越分明越生；越圆润越熟。
- **斑点**：少量褐斑是甜度高、适合马上吃；大量黑斑且面积大，可能过熟。
- **手感**：轻捏中部，硬=生，微软=刚好，软塌=太熟。不要买表皮破损、渗汁、发霉的。

**3. 避免“到店太生或太熟”的实操**
- 想要**当天或第二天吃**：直接挑全黄、微软、带1～2个褐斑的。
- 想要**放几天**：挑黄绿相间、手感硬、果柄绿的。
- 不要只拿一整串：同一串熟度通常接近，可以买两串不同熟度，回家分批吃。
- 如果超市只有太青的：回家和苹果/梨放同一个纸袋里，能加速催熟。
- 如果已经太熟：立刻冷藏，能多撑1～2天；但冷藏后表皮会变黑，内部仍可吃。

**4. 回家后怎么放**
- 未熟：常温、阴凉通风，别冷藏。
- 刚熟：常温尽快吃。
- 很熟：剥皮冷冻，做奶昔；或冷藏1～2天。
- 别把香蕉和苹果/梨长期混放，除非你想让它更快熟。

简单记：**当天吃选黄带斑微软；想放几天选黄绿相间偏硬；做烘焙选黑斑熟蕉。**
