核心就一句话：**把所有承诺落到合同条款和可核验的文件上，口头承诺一律不算。** 下面按"先摸底、再谈判、后落合同"三步给你具体该问什么。

## 一、先摸底（判断这个品牌值不值得代理）

- 这个品牌是**品牌方直营招商**，还是**大区/省级代理再往下放**？如果是二级、三级转授权，区域保护的含金量会打折，要问清楚上一级和品牌的合同里到底写了什么。
- 品牌方目前在你所在区域**有没有已经在合作的代理、经销商或直营客户**？让他们书面列出名单。
- 全国/全省目前有多少家代理？**近两年有没有因为串货被处罚、解约的案例**？（对方越含糊越要警惕）

## 二、区域保护——要问的问题

1. 我拿到的授权是**独家、排他，还是仅"授权范围"**？独家要写明"区域内不再授权第三方、品牌方自己也不直营"。
2. 保护范围是**按行政区、按渠道（商超/批发/电商/餐饮），还是按客户类型**？很多"区域保护"其实只保护某个渠道，别的渠道照样放货。
3. 线上怎么算？品牌方自己开不开旗舰店、直播、社群团购？**这些线上销量算不算进入我的区域？** 这是现在串货纠纷最大的来源。
4. 保护期限多久？**续约条件**是什么？达标销量是按进货额还是按出货额算？
5. 有没有**最低进货量/最低任务**？完不成会不会被取消独家、被降级？

## 三、串货——要问的问题

1. 串货（跨区销售）的**官方定义**是什么？哪些算违规（低价倾销、跨区批发、电商低价、经销商之间倒货）？
2. 举报和认定流程：我怀疑别人串货到我区域，**向谁报、多久处理、需要什么证据**（批号、物流单、发票）？
3. 处罚机制：对串货方的**罚款、扣返利、断货、解约**具体怎么执行？关键是——**处罚后我的损失怎么补**？（价格补偿、返点、还是仅口头安抚）
4. 品牌方有没有**产品追溯体系**（一物一码、批号管理）？没有追溯手段，串货根本查不清、也管不住。
5. 谁负责稽查？是品牌方专门团队，还是让我自己举证？**举证责任在我、处理又慢的，基本等于没有保护。**

## 四、必须写进合同的条款

- 授权性质（独家/非独家）、**区域与渠道的精确界定**（最好附地图或客户名单）
- 品牌方在本区域的**直营/线上销售限制**
- 串货的**定义、认定流程、处理时限、处罚措施**
- 因串货造成的**价格体系破坏如何补偿**
- 违约责任、**解约与退出机制**（库存怎么回收、保证金怎么退）
- 续约、调价、任务调整的规则

## 五、给你的实操提醒

- 谈判全程**留书面记录**（微信、邮件、会议纪要），关键承诺让对方盖章确认。
- 重点查两样东西：**上一级/品牌的授权文件**和**现有代理名单**，能核实对方说的区域保护是不是真的。
- 如果对方对"线上算不算串货""损失怎么补"含糊其辞，基本可以判断保护力度有限。
- 合同签署前，涉及独家范围、违约补偿这类核心条款，建议找熟悉经销/代理纠纷的律师过一遍。

简单说：**问得越具体，对方越难含糊；写进合同的才是保护，说在嘴上的都不算。**
