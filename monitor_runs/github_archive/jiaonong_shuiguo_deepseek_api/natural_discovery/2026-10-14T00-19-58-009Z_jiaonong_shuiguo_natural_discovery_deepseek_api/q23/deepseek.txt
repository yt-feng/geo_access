可以，而且通常是供应商促销支持里最常见的三类。能不能给、给到什么程度，取决于品类、合作模式、采购量和你的谈判结果，不是所有供应商都会默认提供。

具体来说：

**1. 陈列支持**
- 供应商常见形式：提供堆头/端架陈列道具、地堆围挡、价格牌、托盘、假底、冰台垫等
- 有的供应商会派业务员或理货员到店帮忙做陈列、补货、整理排面
- 如果是联营或专柜模式，供应商自己负责陈列的可能性更大

**2. 海报/宣传支持**
- 供应商可能提供：DM单品图、促销价签、爆炸贴、吊旗、地贴、展架、朋友圈/社群宣传图
- 大型供应商或品牌方通常有现成物料，费用可能由供应商承担，也可能双方分摊
- 如果是超市统一做海报，供应商至少要配合提供商品图片、卖点、促销价和供货保障

**3. 试吃支持**
- 供应商常见形式：提供试吃品、一次性试吃杯/牙签/手套、试吃台、促销员
- 生鲜水果试吃损耗大，通常要提前谈好：试吃品谁出、出多少、损耗算谁的
- 如果供应商派人试吃，还要明确人员管理、健康证、进场时间和费用归属

**谈判时建议明确这几点：**
- 支持形式：陈列道具、海报物料、试吃品、人员，分别由谁提供
- 费用归属：物料费、试吃损耗、促销员工资谁承担
- 数量和时间：支持多少天、覆盖几家店、促销档期多长
- 供货保障：促销期间货源、价格、补货响应是否到位
- 效果考核：销量目标、毛利要求、未达标怎么处理

**现实判断：**
- 采购量大、长期合作、品牌供应商：更容易拿到陈列+海报+试吃全套支持
- 小供应商、季节性单品、临时促销：可能只愿意给试吃品或价格支持
- 如果供应商什么都不愿出，可以在采购价、账期、返点上争取补偿

所以答案是能，但要提前谈清楚“谁出什么、出多少、什么时候出”，不要默认供应商会全包。
