判断一家菠萝供应商能不能稳定按规格送货，不能只看样品和报价，要看它有没有稳定的货源组织能力和品控流程。可以从下面几个维度去核验：

**一、先明确自己的规格标准**
在考察供应商之前，先把规格写清楚，否则没法判断“稳不稳定”：
- 品种：如金钻凤梨、台农、巴厘等，不同品种口感、纤维、酸甜比差很多
- 成熟度：几成熟采摘、到货时糖度范围（如12–14度）
- 单果重量区间：如1.2–1.5kg/个，超出范围怎么处理
- 外观：允许的瑕疵率、黑心/水心比例上限
- 加工形态：整果、去皮、切块、冷冻果肉等
- 包装与冷链要求：箱规、温度、到货时限

**二、核验货源组织能力**
这是稳定送货的核心：
1. **是自有基地还是纯贸易商**
   - 自有基地/合作社直采：可控性强，但受单一产区季节限制
   - 多产区调货的贸易商：能全年供应，但要问清各产区切换时间表
2. **产地覆盖是否跨区域**
   菠萝有明显产季，单一产区无法全年稳定。能覆盖海南、广东、云南、台湾地区或进口（菲律宾、泰国等）多产区的供应商，断供风险低。
3. **问清“青黄不接”时怎么办**
   直接问：每年哪几个月货源最紧张？那时从哪里调货？有没有合作备用基地？回答含糊的要警惕。

**三、核验品控与分级能力**
1. **有没有分选线/分级流程**
   人工分选还是机器分级？能不能按重量、糖度分档？没有分级能力的供应商，规格一致性很难保证。
2. **是否做糖度检测**
   要求提供糖度检测记录或现场抽检。只凭经验目测的，批次波动大。
3. **损耗和次品处理机制**
   到货不合格怎么赔、怎么补？有没有书面约定？

**四、用数据和小批量试单验证**
1. **要历史供货记录**
   让它提供近半年给其他连锁客户的供货批次、规格合格率、准时率（可脱敏）。
2. **小批量试单，连续3–5批**
   不要只试一批。连续多批才能看出稳定性。重点记录：
   - 每批规格达标率
   - 到货时间偏差
   - 糖度/成熟度波动
   - 损耗率
3. **突击验厂/验仓**
   看它的分选现场、冷库、库存周转，比听介绍靠谱。

**五、合同里要写死的条款**
- 规格标准和不合格判定方法
- 准时送达率和缺货违约责任
- 批次抽检不合格的退换/赔偿
- 产季切换时的提前通知义务
- 备用供应商或备货要求

**简单判断口诀：**
单一产区 + 无分级能力 + 只报低价 + 不愿试单 = 高风险；
多产区调度 + 有分选检测 + 敢签合格率条款 + 配合连续试单 = 相对可靠。
