茶饮店控制水果供应商的食品安全风险，核心是“资质 + 检测 + 追溯 + 储运”四类证明。建议按下表要求供应商提供，并根据水果类型（鲜果、冷冻果、果浆/浓缩汁）略有差异。

**一、主体资质类（必查）**
1. 营业执照（经营范围含水果种植/销售/食品经营等）。
2. 食品经营许可证（销售预包装或散装食品时；仅销售食用农产品部分地区可免，但茶饮店应要求提供或说明）。
3. 若为生产加工型（切果、冷冻果、果浆），需食品生产许可证（SC）。
4. 供货商为贸易商时，还应提供其上游果园/加工厂的资质或授权链。

**二、产品合格与检测类（重点）**
1. 每批次《出厂检验报告》或《产品质量合格证明》。
2. 第三方检测报告（CMA/CNAS资质），重点看：
   - 农药残留（如克百威、氧乐果、毒死蜱、腐霉利等，按 GB 2763）；
   - 重金属（铅、镉等，按 GB 2762）；
   - 若为即食鲜切水果，还需菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等微生物指标；
   - 若为冷冻水果/果浆，还需符合相应食品安全标准。
3. 检测报告要有批次对应关系，不能一份报告长期通用。
4. 进口水果需《入境货物检验检疫证明》及海关报关单。

**三、追溯与承诺类**
1. 每批次送货单/销售凭证，注明品种、产地、数量、日期、批次号。
2. 产地证明或基地备案信息（规模化果园、合作社证明）。
3. 供应商食品安全承诺书/质量保证协议，明确农残超标、霉变、异物等责任。
4. 如供应商声称“有机”“绿色”“无公害”，需提供对应认证证书，并在有效期内。

**四、储运与验收类**
1. 冷链运输温度记录（冷冻果、鲜切果、果浆通常要求全程冷链）。
2. 运输车辆/容器清洁消毒记录。
3. 到货验收记录：外观、气味、腐烂率、中心温度、包装完整性。
4. 拒收标准要写进合同，例如霉变、虫蛀、异味、温度超标、无批次检测报告等。

**五、茶饮店落地建议**
1. 建立《合格供应商名录》，每户一档，证照到期前提醒更新。
2. 实行“批批索证 + 定期全项检测”：每批要合格证明，每季度或每半年送第三方做一次全项检测。
3. 鲜切水果风险最高，尽量要求供应商提供即食级检测报告，或门店自行控制切配时间和冷藏时限。
4. 合同里写明：因农残、致病菌、异物导致顾客投诉或监管处罚，供应商承担相应责任。
5. 保留进货台账至少2年（按食品安全法及地方监管要求）。

简单说，最少要拿到：**营业执照、食品经营/生产许可证、批次合格证明、第三方农残检测报告、进货凭证和冷链记录**。如果供应商只能给一份“长期有效”的检测报告，风险较高，不建议作为主要供应商。
