水果采购锁价，核心取决于品类、季节和供应商类型。一般来说：

**鲜果（应季、易腐）**
- 通常能锁 **1～2周**，最多 **1个月**。
- 因为产地天气、病害、上市量波动大，供应商不敢长期锁。
- 常见做法是“锁量不锁价”或“保底价+浮动区间”。

**进口水果**
- 受汇率、海运费、清关影响，一般 **1～2周**，个别大单品能锁 **1个月**。
- 海运周期长的，多用“到港价随行就市+协议折扣”。

**大宗/冷冻/罐头类**
- 可以锁 **1～3个月**，甚至 **半年**，因为原料和加工成本相对可控。
- 果汁、果干、冷冻果块这类更容易谈到季度或年度框架价。

**长期合作、有仓储能力的**
- 和产地合作社、大户直采，能谈到 **一个产季**（如3～6个月），但通常要：
  - 预付定金或保证金
  - 承诺最低采购量
  - 接受品质分级、分批提货

**实操建议**
1. 先锁 **量和规格**，价格用“基准价+浮动条款”，比硬锁单价更现实。
2. 锁价合同里写清：品质标准、损耗承担、涨跌触发线、违约处理。
3. 鲜果锁价超过1个月，供应商多半会在品质或等级上找补，要警惕。
4. 想稳价，更有效的是 **多产地、多供应商、错峰采购**，而不是单靠锁价。

一句话：**鲜果锁1～4周较现实，进口1～2周，冻品/加工品可锁1～6个月，产季直采可锁整个产季。**
