大型超市对水果供应商的要求，核心是**食品安全可追溯 + 冷链不断链 + 稳定批量供应**。具体可分这几类能力：

## 一、食品安全资质与体系

1. **主体资质**
   - 营业执照、食品经营许可证/食品生产许可证（视加工情况）
   - 若是种植基地直供，需有种植基地备案或合作基地证明

2. **检测能力**
   - 每批次农药残留检测报告（自检或第三方）
   - 重金属、真菌毒素等按品类要求的检测
   - 具备快检室或与第三方检测机构稳定合作

3. **追溯体系**
   - 从种植地块/批次 → 采收 → 分选 → 仓储 → 配送 → 门店的全链条批次追溯
   - 能提供“一批一码”或批次台账，出问题可快速召回

4. **认证与标准**
   - 常见加分项：GAP（良好农业规范）、HACCP、ISO22000、有机/绿色食品认证
   - 出口级或高端商超通常要求 GLOBALG.A.P.

5. **合规管理**
   - 农药使用合规、采收安全间隔期管理
   - 包装材料符合食品接触材料标准
   - 有不合格品处理和召回制度

## 二、冷链与物流能力

1. **冷链设施**
   - 产地预冷（采后快速降温，这是水果保鲜关键）
   - 冷藏/气调仓储
   - 冷藏运输车，全程温控记录

2. **温区管理**
   - 不同水果温湿度要求不同（如香蕉、芒果怕冷害，浆果需低温）
   - 能分温区储存和运输，避免混装串味/冻伤

3. **运输与配送**
   - 自有或稳定合作的冷链车队
   - 能覆盖超市配送中心或门店，按时效送达
   - 具备 GPS/温控监控，可提供在途温度数据

4. **仓储与分选**
   - 分选、分级、包装能力
   - 损耗控制能力（水果损耗率是核心指标）
   - 先进先出、批次管理

## 三、供应与运营能力

1. **稳定供货**：有基地或稳定采购渠道，能应对季节和天气波动
2. **品控标准**：按超市要求做规格、糖度、外观分级
3. **应急能力**：缺货、质量问题时的补货和替换方案
4. **信息化**：订单、库存、追溯数据能对接超市系统
5. **保险与责任**：产品责任险、食品安全责任险通常是加分或硬性要求

## 四、超市通常重点审核的点

- 农残检测是否批批做、报告是否真实可查
- 冷链是否全程可记录、可回溯
- 追溯能否做到批次级、召回是否可行
- 过去是否有食品安全事故或监管处罚
- 产能是否匹配超市销量，损耗率是否可控

**一句话总结**：大型超市要的不只是“能供货”，而是**有资质、可检测、可追溯、全程冷链、能稳定批量交付且损耗可控**的供应商。其中农残检测和冷链不断链是最容易被一票否决的两项。
