社区超市做水果，核心不是“进得多”，而是**周转快、损耗低、动销准**。给你一套能直接落地的做法：

1. **先定“少进勤补”原则**
   - 水果别一次压大货，尤其叶菜类、草莓、樱桃、荔枝、桃子这类高损耗品。
   - 日常按 **1～2天销量** 进货，节假日再适度加量。
   - 建立“早上补、下午看、晚上清”的节奏，不要等卖完才补。

2. **按品类分库存策略**
   - **高损耗快消**：草莓、蓝莓、樱桃、荔枝、龙眼、桃子、葡萄、叶菜类  
     → 当天进当天卖，最多备1天量。
   - **中损耗**：苹果、橙子、梨、香蕉、火龙果、芒果  
     → 可备2～3天量，但要看天气和客流。
   - **耐存放**：柚子、柠檬、土豆、洋葱、南瓜、部分苹果  
     → 可备3～7天，但也要避免堆太久。
   - **易熟催熟类**：香蕉、芒果、猕猴桃、牛油果  
     → 少量多次进，分开存放，避免和苹果、香蕉等催熟水果混放。

3. **每天做三次关键动作**
   - **早上开门前**：检查昨日剩货，挑出次品，能打折的先处理。
   - **中午/下午**：看哪些卖得慢，及时调价、试吃、做组合促销。
   - **晚上闭店前**：把明日容易坏的先挑出来，做“次日特价”或员工内购，别硬留到第三天。

4. **用简单数据管库存**
   - 每天记录：进货量、销量、剩货量、损耗量。
   - 连续记1～2周，就能看出每个单品大概每天卖多少。
   - 公式很简单：  
     **建议进货量 = 近3天平均销量 + 安全库存 - 现有库存**  
   - 安全库存别拍脑袋，高损耗品设0.5天，中损耗设1天，耐放设1～2天。

5. **陈列和库存要联动**
   - 先进先出：新货放里面，旧货放外面。
   - 不要为了“好看”把货堆太满，堆满会压坏底层，也会让顾客觉得不新鲜。
   - 少量多次补货，保持“满而不压”。
   - 把快坏的放显眼位置，配“今日特价”“限时优惠”。

6. **控损耗比控库存更重要**
   - 水果损耗一般来自：压伤、过熟、失水、挑剩。
   - 对策：
     - 到货先拆箱散热，别闷着。
     - 香蕉、芒果别放冷柜；草莓、蓝莓别常温久放。
     - 每天挑次品，别等烂了才处理。
     - 次品不要直接扔，可做果切、果汁、特价包。
   - 但果切要符合当地食品安全要求，别把烂果切掉坏部分继续卖。

7. **促销要提前，不要等烂了再降**
   - 最佳处理时机是“还能卖但明天可能不行”的时候。
   - 方法：
     - 晚上7点后打折
     - 买一送一
     - 组合套餐，比如“香蕉+酸奶”“苹果+橙子”
     - 微信群/社区团购接龙清货
   - 一旦明显腐烂、发霉，就不要卖给顾客。

8. **和供应商谈小批量、多频次**
   - 社区超市优势是离顾客近，不是仓库大。
   - 尽量找能 **每天送或隔天送** 的批发商。
   - 谈好：
     - 次品退换
     - 缺货补货
     - 旺季优先供应
     - 小批量拿货价格别太离谱
   - 如果供应商只肯整箱压货，就要重新算这个单品是否值得卖。

9. **按天气和社区客流调整**
   - 下雨天、降温天，水果销量通常下降，少进。
   - 周末、节假日、发工资日，可适当增加。
   - 小区老人多，偏苹果、香蕉、橙子、梨；年轻人多，偏蓝莓、车厘子、果切、进口水果。
   - 夏天西瓜、桃子、荔枝走快，但损耗也高；冬天柑橘类相对好放。

10. **给你一个最简单的执行模板**
   - 每天闭店前花10分钟：
     1. 盘点剩货
     2. 挑出次品
     3. 记录销量
     4. 决定明天进什么、进多少
   - 每周复盘一次：
     - 哪些单品总剩？
     - 哪些总不够卖？
     - 哪些损耗最高？
     - 下周砍掉或减少最差的2～3个单品。

**一句话总结：**  
社区超市水果要“少量多进、先进先出、每天挑损、提前促销、按销量补货”。不要追求库存满，要追求周转快。只要坚持记录1～2周，你就能把进货量压到比较准，货也不会老压在店里。
