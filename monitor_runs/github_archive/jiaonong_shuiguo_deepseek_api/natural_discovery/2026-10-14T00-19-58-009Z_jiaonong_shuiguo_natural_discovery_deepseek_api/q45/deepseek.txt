连锁超市和水果供应商签年度合同，最容易踩的坑集中在“价格机制、损耗归属、验收标准、账期与返利、独家与替代、不可抗力”六块。下面按风险点和可执行写法给你拆开。

**1. 价格机制：只锁年价，必踩坑**
水果价格波动大，固定年价要么供应商亏到断供，要么超市被高价套牢。  
建议写：  
- 基准价+浮动机制，挂钩批发市场指数或产区收购价，约定调价周期（如月度/季度）。  
- 设置调价触发阈值，比如波动超5%才启动。  
- 明确调价需双方书面确认，避免供应商单方涨价。  
- 促销价、特价品单独列，不纳入年度框架价。

**2. 损耗与验收：不写清，扯皮无底洞**
水果非标，验收争议最多。  
必须写：  
- 验收标准按品类细化：糖度、单果重、色泽、成熟度、机械伤比例、腐烂率上限。  
- 验收地点和时间：到仓验收还是产地验收，到仓后多少小时内提出异议有效。  
- 损耗归属：运输途损谁承担，到仓后自然失水/腐烂谁承担，超过约定比例如何扣款或补货。  
- 抽检规则：抽检比例、不合格判定、整批退货还是按比例扣款。  
- 留样和影像记录，避免事后不认。

**3. 账期与返利：现金流和利润暗坑**
常见坑是账期模糊、返利条件不清、费用乱扣。  
建议：  
- 账期写死：货到验收合格后X天付款，起算点明确。  
- 返利分档写清：年度采购额、季度达标、新品推广等，避免“综合返利”一笔糊涂账。  
- 各项费用列明：进场费、陈列费、促销费、损耗补贴，是否含税、能否抵扣。  
- 扣款需提前书面通知并附依据，禁止无依据直接扣货款。

**4. 独家与替代：锁死供应，反被拿捏**
年度合同常写“独家供应”，但水果季节性、产区集中，独家容易导致断供或坐地起价。  
建议：  
- 不轻易签全品类独家，最多按单品或产区做有限独家。  
- 约定替代品机制：某单品缺货时，供应商需提前X天通知，超市可临时从其他渠道补货且不违约。  
- 约定最低供货量和断供应急责任，避免旺季断货。

**5. 不可抗力与政策风险：别写成万能免责**
天气、疫情、封路、关税都可能影响。  
建议：  
- 不可抗力需定义清楚，并约定通知时限和证明文件。  
- 不可抗力持续超过X天，双方可协商调价或解除部分订单。  
- 供应商因自身管理问题导致的缺货，不算不可抗力。

**6. 合同期限与退出：年度合同也要能刹车**
- 约定试用期或首季度考核，不达标可调整或终止。  
- 明确终止后的库存处理、未结货款、返利结算。  
- 争议解决选超市所在地法院或仲裁，降低维权成本。

**一句话总结**：年度合同别只谈量 and 价，重点把“价格怎么调、损耗怎么分、验收怎么判、钱怎么结、断供怎么办”写死。谁把这些写细，谁少踩坑。
