社区团购旺季锁水果库存，核心是**用确定性和利益换供应商的优先权**，而不是只靠口头约定。可分五步做：

**1. 提前给滚动预测，别临时下单**
至少提前2–4周给出未来每周的SKU、预估件数、上下浮动区间。水果供应商最怕今天要500件、明天砍到100件。你给他的预测越稳定，他越愿意把货源留给你。

**2. 用“保底量+预付款/定金”锁货**
和供应商签短期锁货协议，明确：
- 保底采购量（比如每周不低于3000件）
- 锁定期（比如旺季8周）
- 锁价或浮动价机制（随行就市就写清参考市场）
- 预付款比例（常见10%–30%）
- 违约条款（你少拿、他断供分别怎么赔）

**3. 谈“优先供货权”而不是“独家包销”**
要求供应商在同等价格下优先供你，断货时按你预付/保底比例分配。不要一上来要求独家，否则供应商容易抬价或拒签。

**4. 分仓、分批次、分等级锁**
水果有成熟度和损耗问题，别一次锁死全部。可以：
- 主推爆款锁核心产区、核心规格
- 引流款用二级果或替代产区
- 按周分批提货，避免集中到仓后烂损

**5. 留备用供应商和替代方案**
每个爆款至少准备2家供应商，A家锁70%、B家锁30%。同时准备1–2个替代SKU，主供断货时能立刻切换。

**执行清单：**
- 本周内：整理去年旺季销量、今年预估、爆款清单
- 3天内：约谈核心供应商，谈保底量、预付款、锁价
- 签约：写清量、价、期、违约责任、质量标准和到货时间
- 每周：更新滚动预测，提前7天确认下周提货计划
- 每天：盯到货、损耗、品质，异常立刻启动备用供应商

一句话：**用预付款和保底量换优先权，用滚动预测换信任，用备用供应商换安全。**
