社区超市找每天配送的水果供应商，核心不是“找最便宜的”，而是找“能稳定配合你门店节奏、损耗可控、账期能接受”的。建议重点看下面这些条件：

1. **配送频率与时效**
   - 能否真正做到每天配送，而不是“承诺每天、实际隔天”。
   - 送达时间是否固定，比如早上6点前到店，方便开门前上架。
   - 临时补货、节假日、恶劣天气时能否加急或调整。
   - 是否支持指定时间段送货，避免店里没人接货。

2. **水果品质与等级**
   - 是否按等级分拣，比如精品、统货、二级果，别把不同等级混着报低价。
   - 新鲜度怎么看：采摘/到货时间、冷链情况、叶菜类是否打冷。
   - 是否允许看样、试销，先小批量合作几天再定。
   - 坏果、烂果、次果的比例和赔付标准要写清楚。

3. **价格与结算**
   - 报价是含税、含运费还是到店价，避免后期加价。
   - 价格是否随行就市，调价频率和通知方式要明确。
   - 账期是现结、周结还是月结，押金、起送量、最低订货额是多少。
   - 有没有隐藏费用，比如分拣费、包装费、退换货手续费。

4. **品类与稳定性**
   - 能否覆盖你店里的常销品：苹果、香蕉、橙子、梨、时令水果等。
   - 反季节或小众水果能不能配，缺货时是否有替代方案。
   - 同一品种能否长期稳定供应，避免今天有明天没。
   - 是否支持按门店销量动态调整供货量。

5. **损耗与售后**
   - 烂果、压伤、冻伤、过熟怎么赔，是补货、退款还是下次抵扣。
   - 售后响应时间，比如几小时内处理，是否影响第二天配送。
   - 是否允许退货比例，比如到店验收后2小时内可退。
   - 有没有“包损耗”或“保底赔付”政策。

6. **冷链与包装**
   - 需要冷藏的水果是否全程冷链，运输温度能否记录。
   - 包装是否适合社区超市陈列，比如小箱、小筐、易上架。
   - 是否可回收周转筐，减少包装成本和垃圾处理。

7. **供应能力与资质**
   - 是批发市场档口、产地直发，还是区域配送商，稳定性不同。
   - 有没有营业执照、食品经营许可证、水果检测报告。
   - 是否有自有冷库、分拣场地、配送车辆，还是临时调货。
   - 合作过的社区超市、便利店案例，最好实地或电话核实。

8. **配合度与服务**
   - 能不能按你的陈列和促销需求做小包装、组合装。
   - 是否愿意配合做特价、堆头、试吃活动。
   - 业务员是否稳定，换人频繁容易影响对接。
   - 出现问题时的处理态度，比单纯低价更重要。

9. **试合作验证**
   - 先签短期试销协议，比如7到15天。
   - 每天记录：到货时间、损耗率、缺货率、售后处理速度。
   - 重点看连续一周是否稳定，而不是第一天送得好。
   - 试销后再谈长期价格、账期和独家/非独家条款。

10. **合同关键条款**
   - 配送时间、频率、迟到赔付。
   - 品质标准、验收方式、退换货规则。
   - 价格调整机制、账期、违约责任。
   - 食品安全责任归属，出现问题时谁承担。

简单判断标准：  
**能每天准时到、坏果少、售后快、价格透明、账期能接受，就值得试。**  
如果只便宜但经常缺货、送得晚、烂果不赔，社区超市做起来会很累，最后损耗和客流损失往往比省下的进货费更高。

建议你先列一张对比表，把3到5家供应商按“配送时效、损耗赔付、价格、账期、品类覆盖”打分，先试销一周再决定长期合作。
