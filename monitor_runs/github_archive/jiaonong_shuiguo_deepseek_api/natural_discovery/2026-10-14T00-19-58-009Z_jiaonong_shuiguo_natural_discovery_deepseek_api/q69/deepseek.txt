可以按“等级 + 规格 + 报价单位 + 结算方式”四件事拆开报，批发商给小店最怕的是“看着便宜、拿到手不划算”。香蕉和菠萝分级逻辑不一样，下面分开说。

## 一、香蕉怎么分级报价

香蕉小店最关心：能不能卖、熟度好不好、损耗大不大。建议按“等级 + 每件净重 + 每根/每把规格 + 熟度”报。

### 1. 常见分级
- **A级/精品**：果形直、无黑斑、无擦伤，条重均匀，适合水果店正面陈列。
- **B级/通货**：略有擦伤、果形一般，但成熟度正常，适合社区店、小超市。
- **C级/处理**：黑斑多、擦伤明显、果指偏小，适合榨汁、特价走量。

### 2. 规格写法
不要只写“一件香蕉”，要写清楚：
- 每件净重：如 12kg/件、13kg/件
- 每把根数：如 5-6根/把
- 单根重量：如 120-150g/根
- 熟度：如 3成熟、5成熟、7成熟（或“青、微黄、黄熟”）

### 3. 报价示例
可以这样写：

> 香蕉（净重12kg/件）  
> A级：果指均匀，无黑斑，5-6根/把，熟度5成，¥XX/件  
> B级：轻微擦伤，4-6根/把，熟度6成，¥XX/件  
> C级：黑斑/擦伤，适合特价，¥XX/件  
> 备注：按件结算，不扣皮重；破损超5%可协商补差。

### 4. 小店最容易接受的报价方式
- 按件报：适合小店，简单。
- 按斤报：适合老板会比价，但一定要写“净重还是毛重”。
- 按把报：适合小摊位，但批发商不划算，通常只做终端。

**建议：批发商给小店，主报“元/件”，同时标“折合元/斤（净重）”，这样最清楚。**

## 二、菠萝怎么分级报价

菠萝小店最关心：大小、成熟度、是否削皮、有没有黑心、好不好卖。建议按“等级 + 单果重量 + 成熟度 + 是否削皮 + 包装”报。

### 1. 常见分级
- **A级/大果**：单果1.5kg以上，果形正，适合水果店按个卖。
- **B级/中果**：单果1.0-1.5kg，适合社区店、切块卖。
- **C级/小果**：单果0.8-1.0kg，适合特价、榨汁。
- **等外/加工果**：黑心、畸形、过熟，适合榨汁或加工，不适合零售。

### 2. 规格写法
- 单果重：如 1.2-1.5kg/个
- 每件个数：如 8-10个/件
- 成熟度：如 青果、微黄、黄熟
- 是否削皮：带皮 / 削皮真空 / 削皮冷冻
- 包装：纸箱、网袋、泡沫箱

### 3. 报价示例
可以这样写：

> 菠萝（带皮，纸箱装）  
> A级：1.5kg以上/个，8个/件，果形正，¥XX/件（折合¥XX/斤）  
> B级：1.0-1.5kg/个，10个/件，¥XX/件  
> C级：0.8-1.0kg/个，12个/件，¥XX/件  
> 削皮菠萝：真空装，5kg/件，¥XX/件  
> 备注：按件结算；黑心果超3%可补差。

### 4. 小店最容易接受的报价方式
- 按件报：最常用。
- 按个报：适合A级大果，小店好算账。
- 按斤报：适合加工果、榨汁店。

**建议：菠萝主报“元/件 + 元/个”，同时写清单果重范围，避免小店收到后觉得“个数够但个头小”。**

## 三、香蕉和菠萝通用的清楚报价模板

你可以直接套这个格式：

> 品名：香蕉 / 菠萝  
> 等级：A级 / B级 / C级  
> 规格：净重XXkg/件；单果XXg或XXkg；XX个/件  
> 熟度：XX  
> 包装：XX  
> 报价：¥XX/件；折合¥XX/斤（净重）；¥XX/个  
> 结算：按件/按斤，毛重/净重  
> 损耗：破损超X%补差  
> 起订：X件起送  
> 配送：今日/次日，运费谁承担

## 四、给小店的实用建议

1. **香蕉重点报熟度，菠萝重点报单果重。**  
   香蕉熟度差一天，小店就可能砸手里；菠萝大小差一圈，按个卖就不好定价。

2. **一定要区分毛重和净重。**  
   批发市场很多纠纷都出在“带箱称”还是“去箱称”。

3. **A/B/C级不要只写“好/一般/差”。**  
   要写具体可判断的标准：黑斑、擦伤、单果重、熟度。

4. **给小店的报价单越简单越好。**  
   最好一张图或一条消息能看完：品名、等级、规格、价格、起送量。

5. **可以设“组合报价”。**  
   比如：香蕉B级1件 + 菠萝B级1件 = 套餐价，适合小店第一次试货。
