**结论：建议以“卖整果为主，提供去皮服务为增值项”，让顾客自己挑不带皮果则尽量避免。**

具体分析如下：

1. **优先卖整果**  
   - 整果损耗低，保存时间长，顾客可自由挑选熟度，客单价更高（整果利润空间大）。  
   - 菠萝相比西瓜更需要挑熟度，很多顾客信任自己选，容易产生“负责感”和复购。

2. **升级服务：提供“现切去皮”增值服务**  
   - 对赶时间、怕麻烦的顾客，提供现场去皮切片服务，收取合理加工费（如每斤加收1-2元）。  
   - 好处：不占库存、损耗可控（去皮后再卖坏果风险高）、差异化竞争。

3. **不建议长期主推“店主预先去皮好”**  
   - 去皮后的菠萝暴露在空气中易氧化变色、滋生细菌，保存期极短（常温半天内口感下降）。  
   - 若当天卖不完损耗极高，利润会被吃掉，且顾客无法判断新鲜度。

---

**实操建议（供你参考执行）：**
- 店内主推整果，在堆头旁边放一个“去皮服务价”的提示牌。
- 如果已经积压了一批不太熟的货，可以提前去皮切片打包，用低价快销（但这是清库存手段，不是长期模式）。
- 定价策略：
  - 整果价：正常市场价；
  - 去皮价：整果价 + 加工费；
  - 打折处理价：仅用于尾货处理。

**一句话总结：** 卖整果让顾客自己挑，把“去皮”做成收费服务，两头都赚。
