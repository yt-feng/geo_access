针对**家庭**场景做水果礼盒，**核心需求**不是“贵”或“稀罕”，而是**耐放、口感好、大人小孩都能吃、且寓意吉祥**。

下面给您几套组合方案，直接按预算和季节来选就行：

---

### 方案一：性价比之王（最推荐家庭自购或走量款）
**组合：苹果（4个） + 橙子（4个） + 香蕉（1大把） + 菠萝（1个）**

- **理由**：这个组合最能体现“水果篮子”的实惠感。
    - **苹果**是硬通货，放得住，孩子饿了随手拿一个。
    - **橙子**富含维C，是家庭日常刚需。
    - **香蕉**是**最容易消耗**的水果，放进去会显得篮子很满，且家庭中有老人小孩都爱吃。
    - **菠萝**则起到“提香+增加体积”的作用，让这个礼盒看起来分量十足。
- **注意**：香蕉和菠萝都熟得快，建议选7-8成熟的，并**用纸或网袋单独包一下**，防止碰坏苹果和橙子。

---

### 方案二：颜值担当 / 送礼款（用于送亲戚或家庭聚餐）
**组合：红富士苹果（4个） + 新奇士/脐橙（4个） + 都乐菠萝/香水菠萝（1个） + 少量软籽石榴（2个，可替换香蕉）**

- **理由**：主打**色彩鲜艳**——红的、黄的、橙的、绿的，视觉冲击力强。
    - 把**香蕉**去掉，换成**石榴**或**青提**，显得更上档次，且避免了香蕉发黑影响卖相的尴尬。
    - **菠萝**选叶片翠绿、果型圆润的，插上装饰签，放在礼盒C位，拍照好看。
- **注意**：石榴皮硬，适合直接摆放在礼盒底部或边角，提升品质感。

---

### 方案三：健康养生款（适合送给有长辈的家庭）
**组合：丑苹果/阿克苏苹果（4个） + 血橙/冰糖橙（4个） + 香蕉（去掉）+ 菠萝（换成凤梨）**

- **理由**：家庭里如果有血糖高或怕甜的**中老年人**：
    - 把**香蕉**拿掉（糖分高、升糖快）。
    - **菠萝**有酸味，如果老人牙口不好建议换成**凤梨**（口感更软糯、纤维少），或者直接换成**火龙果**（红心，通便，且过季时在礼盒中显得新奇）。
- **注意**：切开的火龙果会渗水，**一定不要切开卖**，必须是整果装盒。

---

### 关键操作小贴士（团购做礼盒必看）

1.  **控熟度**：所有水果**绝对不要全熟**。香蕉容易受催熟，要选择**皮青、硬邦邦**的七成熟香蕉。菠萝选底部发黄但叶子新鲜的那种，切勿选全黄软塌的。
2.  **做防护**：因为里面有菠萝和苹果（都是比较硬的），建议在礼盒**底部铺碎纸条或珍珠棉**，防止运输中磕碰出汁污染其他水果。
3.  **话术设计**：在团购介绍里，强烈建议写**“专为家庭组合，无一个多余的水果”**。同时，提供**同价换购**选项（如：不要香蕉可换成2个苹果，或者不要菠萝可换成6个猕猴桃），这样能最大程度贴合每一户需求，复购率高。

**结论：如果是家庭日常吃，最保险的就选【方案一：苹果+橙子+香蕉+菠萝】这个黄金四件套，成本低、不容易腻，且能满足大多数中国家庭一周的水果需求。**

如果您需要针对**特定节日（如中秋、春节）**或**特定人群（如1-3岁幼儿）**做调整，请再告诉我具体场景。
