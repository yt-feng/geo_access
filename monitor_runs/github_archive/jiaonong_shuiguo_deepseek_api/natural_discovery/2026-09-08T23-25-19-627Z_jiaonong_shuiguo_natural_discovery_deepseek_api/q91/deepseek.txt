针对便利店上架香蕉，我的建议如下（结合实际经营角度）：

**结论：优先选择“小把（2-3根）”，其次“单根”，**不建议**整袋包装作为主推。**

**具体分析和执行建议：**

1. **核心原因：损耗控制**
   - **整袋包装（如5根以上）**：这是最不可取的。便利店客单价低、购买即时性强，顾客通常只买1-2根当餐后水果。整袋装极易造成一次性卖不掉，香蕉在后熟期几天内就会发黑、软烂，产生大量损耗。
   - **单根**：损耗最低，但毛利和客单价太低，且需要单独逐个贴价签，操作繁琐。
   - **小把（2-3根）**：是“黄金平衡点”。既满足一人食（2根刚好），又适合家庭补货（3根一周内吃完），毛利适中，且自然成束减少称重或贴标动作。

2. **执行细节（重点）**：
   - **拒绝“整袋”作为主销款**，如果供应商只给整袋，请务必在到店后**立刻拆袋，按2-3根重新整理成小把**，用保鲜膜或橡皮筋固定，并按单价称重后贴一次性条码。
   - **销售包装建议**：在冷柜外的常温水果架（避免放冷藏，会冻伤发黑）陈列。**把最熟的一根单独切开用果盒装**，作为“即食香蕉”放在收银台附近试吃或促销，吸引冲动购买。
   - **定价策略**：可参考“单根1-1.5元，小把3根约4-5元”。用小把作为主力，单根作为加1元换购的引流品。

3. **供应链选择**：进货时明确要求供应商配送“2-3根的小把装”，不要贪图整袋的单价便宜。如果所在区域供应商只有整袋，请自己买可降解的香蕉专用薄膜袋，在店里拆装后售卖，**包装袋上标清“请于2天内食用”**，减少客服纠纷。

4. **替代方案（进阶）**：如果店面有冷藏展示柜且有员工定时维护，可以考虑“预切香蕉杯（半根+酸奶/麦片）”，但这属于加价增值品，不是上架基础品。
