关于茶饮店水果采购的问题，我的建议是：**不要完全固定产地或供应批次，而要建立“双轨制”采购策略**。

具体原因和实操建议如下：

**1. 为什么不能“完全固定单一产地/批次”？**
- **季节性风险**：固定产地意味着品种和成熟期固定，但农产品受气候、病虫害影响大，一旦该产地减产或质量下滑，你无法快速切换，会导致断货或口味不稳定。
- **口味同质化风险**：如果长期依赖同一个产地，水果风味会趋于单一，缺乏新鲜感；而不同产地的同类水果（如广东和广西的柠檬、福建和越南的百香果）香气、酸度差异很大，稳定的配方需要“动态最优”而非“静态锁定”。

**2. 推荐做法：核心参数固定，供应源灵活**
- **固定的是“风味标准”而非“产地”**：比如你要做柠檬茶，就规定柠檬的“酸度范围（如总酸含量≥6%）、香气强度、果皮厚度、出汁率”这些理化指标。采购时用这些标准去筛选不同产地的批次，符合标准就入库。
- **建立“备选供应商库”**：至少签约2-3个不同产地的供应商（如云南和四川的橙子），并让他们在到货时附带当批次的质检报告（糖度、酸度值）。如果主产地波动大，能立即启用备选。
- **设置“小批试产”机制**：对于新批次的原料，先购入小批量（比如够试做30-50杯的量），让研发或店长测评，对比旧批次的风味差异，确认可替代后再批量下单。

**3. 如何应对“批次波动”本身？**
- **配方留出“缓冲”**：在茶饮配方中，水果的用量不要卡得太死。例如水果茶里的果肉占比在30%-40%之间可调，糖浆或柠檬酸（调酸用）用来中和批次差异。
- **做“风味封存”**：对于应季风险大的水果（如杨梅、荔枝），在当季采购时，部分做成果泥或冷冻果肉（-18℃以下），延长稳定供应期，减少对鲜果的依赖。
- **数据记录**：为每次采购的水果记录产地、到货糖酸比、实际制作后的出杯反馈。累计3-6个月数据后，你就能看出哪些产地/批次最稳定，作为优先选择。

**4. 具体执行清单（供店长操作）**
- **采购单上必须写明**：品种、糖度下限（如Brix≥12%）、酸度范围、允许的成熟度（如7-8成熟）、到货温度（0-4℃冷链）。
- **收货检验**：到货后随机取3个果实测糖度，出汁后试喝，不合格直接拒收，不与供应商口头妥协。
- **供应商合同里加上**：“批次波动时，供应商需提前7天通知，并允许你方小批试购”条款。

**总结**：不要“锁死”产地，而要“锁定标准”。固定产地会把你和风险绑在一起，而固定标准+灵活采购，才能让口味在可接受范围内波动，同时降低断货风险。
