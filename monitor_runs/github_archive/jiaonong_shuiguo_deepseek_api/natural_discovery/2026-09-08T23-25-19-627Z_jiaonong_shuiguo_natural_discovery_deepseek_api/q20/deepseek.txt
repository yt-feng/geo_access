选择社区超市的每日水果供应商，建议**优先考察以下几个核心维度**，兼顾稳定性和利润空间：

**1. 供应稳定性与时效**
- 是否承诺**每日凌晨/清晨**送达（社区超市通常需赶在早市前上架）。
- 是否有**备用供货渠道**（如遇极端天气或产地断货，能否当天调货补足）。

**2. 损耗率与售后责任**
- 明确现场验收标准：**每箱净重、表皮碰伤率、软烂比例**是否写入合同。
- 关键询问：**当日未售完的临期水果**（如香蕉、草莓）是否支持**退换或按比例折扣补差**。

**3. 价格与账期灵活性**
- 对比批发市场价：要求提供**每日实时报价单**（而非固定价），并询问**阶梯调价机制**（如采购量超xx斤，次日单价下调）。
- 账期建议优先选择**周结或半月结**，避免压款；若月结，需谈好10%-20%的采购返点。

**4. 品类与产地匹配度**
- 对社区消费群体画像：周边是年轻白领（需高端蓝莓、牛油果）还是家庭主妇（需大宗苹果、梨）？
- 要求供应商提供**应季主推清单+非应季稳定货源表**，避免空有“车厘子”噱头但日常缺货。

**5. 质量可追溯性**
- 要求提供**进货票据或产地证明**（哪怕是批发市场进货，也要有每日小票），规避安全风险。
- 可实地抽查一次：提前一天预约供应商的**分拣仓库**，观察其卫生条件和周转速度。

---

**落地执行建议：**
- 前两周采取“**代销模式**”（每日结算卖多少算多少，剩余退给供应商），跑通销量后谈买断价。
- 签订合同时务必包含“**不可抗力下的补货时限**”（如24小时内必须响应）。
- 直接开启**3天试供期**，比任何口头承诺都有效。

如果您的超市周边有农贸市场，还可以关注是否有“产地直发+小货车每日配送”的农户个体，这类通常价格低15%-20%，但需自行承担品控风险。
