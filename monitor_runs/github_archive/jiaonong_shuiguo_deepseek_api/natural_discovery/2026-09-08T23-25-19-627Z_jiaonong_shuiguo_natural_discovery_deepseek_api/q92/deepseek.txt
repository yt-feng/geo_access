便利店受限于面积和存储条件，水果经营的核心逻辑是**“小批量、多批次、高周转”**，而不是像大卖场那样追求品类齐全或一次性囤货。

直接给你一套可执行的控制策略：

**一、品类控制：只做“精选”和“爆款”**

1. **放弃“全”的概念**。小门店通常只保留 **15-25个SKU**（单品）即可。
   - **黄金单品**：香蕉、苹果（红富士）、梨（秋月/丰水）、应季西瓜（夏季）。
   - **引流差异品**：圣女果（小番茄）、蓝莓、草莓（冬春）、阳光玫瑰葡萄（夏秋）。
   - **本地特色**：门店周边居民爱吃且好保存的品种（如杨梅、枇杷只做本地快进快出）。

2. **按“头尾”分档**：
   - **头部（必做）**：香蕉、苹果、梨、柑橘类。这些走量稳，损耗低。
   - **尾部（慎做）**：榴莲、山竹、大樱桃（冬季进口）等高单价易损耗的，**要么不卖，要么只接受预售或顾客预定**，坚决不大量现货陈列。

**二、损耗控制：抓住“进货、陈列、处理”三关**

1. **进货关（最关键）**：**少进勤补**。
   - 便利店水果的进货周期，春夏至少**一天一进**，冬天可以两天一进。
   - 进货时**必须亲自验货**，只看箱子表面是没用的，要抽检中间层和底层，发霉或碰伤的坚决拒收。宁可进价贵5%，也不要赌运气赔20%损耗。

2. **陈列关（保护视觉损耗）**：
   - **轻拿轻放**，陈列深度不要超过2层，避免顾客翻找压坏底层。
   - **借助冷风柜**：苹果、梨、葡萄、蓝莓**必须放冷藏柜**，温度控制在2-8℃。香蕉和未熟的猕猴桃**绝不能进冷柜**（会黑心），放常温货架。
   - **正向摆放**：带叶的草莓、樱桃，要叶子朝上，果柄朝上，不要堆叠。

3. **处理关（建立“三级损耗”）**：
   - **一级（轻微瑕疵）**：表皮划伤、微软但不烂的，**当场盒装打折**，定价为原价70%或买一送一，放到收银台旁边“每日特价”框，快闪快清。
   - **二级（明显变软）**：直接切成果切拼盘（去皮去坏），用保鲜膜包好，标注“当日鲜切”，售价按克价卖。**果切是消化损耗的救命稻草**。
   - **三级（已烂/出水）**：**立即丢弃，不要心软**。因为烂水果散发的乙烯会加速旁边水果成熟腐烂，这叫**病毒式损耗**，会毁掉整筐库存。

**三、数据化管理（精算到日）**

每天必须清楚记录三组数字并进行复盘：

- **进货金额** vs **售出金额** vs **报损金额**。
- 如果单日损耗率（报损金额÷进货金额）超过 **5%**，说明进货量过大或陈列不合格；如果低于 **1%**，往往说明缺货了（表面卖得好，实际少赚了钱）。

**四、其他实用技巧**

- **包装标准化**：非动销快的单品，可以用小塑料盒分装，一份约半斤或1斤，按份卖。这能**强制控制顾客不当挑选**，减少触摸。
- **“今日到”标签**：贴上日期，让顾客知道新鲜，同时倒逼你**不压货**。
- **借势试吃**：当某个水果临近损耗（但没坏），切小块给顾客试吃，用口感换销量，比直接扔掉好。

**总结给你的一个硬性标准：**
在便利店，水果的采购预算单次不要超过门店全天营业额的5%-8%（视水果为辅助品类时），并且坚持**“先进先出、每日查验、日清日结”**。只要今天没卖完的水果，明天必须降价或处理掉，**永远不要留到后天**。
