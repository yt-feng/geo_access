在处理生鲜电商水果到货后的坏果投诉时，责任划分主要取决于**问题发生的时间点**和**商品状态**，通常分为以下几种情况：

### 1. 责任划分的核心判断标准
- **运输途中的损坏**：一般情况下，生鲜电商承诺“坏果包赔”或“48小时无理由退换”，只要顾客在收货后规定时间内（通常为24-48小时）拍照并提供订单号，**责任由商家承担**。因为水果在打包后交给物流，运输中的磕碰、高温、挤压属于商家不可控但应赔付的履约风险。
- **收货后存放不当**：如果顾客收货后未及时放入冰箱、放置时间过长导致腐烂，且未在规定时效内反馈，**责任由顾客承担**。
- **商品本身质量问题（如内部腐烂、虫害等）**：即使外观完好，但切开后内部明显变质，**责任在商家**，商家应承担退换或部分退款。

### 2. 实操中的责任认定建议
- **商家与物流的责任边界**：如果商家使用快递发货，且明确在页面注明“生鲜不支持7天无理由”，但承诺“坏果包赔”，那么运输损坏的赔偿责任在商家，商家可再向物流追偿（需提供照片、称重等证据）。
- **顾客投诉时间节点**：顾客收货后**应立即开箱检查**。若在签收后24小时内反馈，商家基本无异议；若超过48小时（或商家承诺的售后时效），商家可拒绝赔付，责任归顾客。

### 3. 给顾客的维权建议（如果商家推诿）
- **保留证据**：拍摄坏果特写照片、整箱水果全景照片、快递面单或订单截图，清晰显示坏果数量和整体比例。
- **查看售后规则**：多数平台（如盒马、京东到家、美团闪购）有“缺重/坏果按比例退款”机制，直接按果品克重比例申请退款。
- **协商方案**：优先要求“坏果按比例退款”或“补发”，如果商家拒绝，可联系平台客服介入，说明“生鲜属易腐烂商品，非买家过错”。

### 4. 特殊情况
- **“次日达”或“小时达”服务**：如果商家承诺配送时效，但实际超时导致水果高温变质，**责任在商家（或平台配送环节）**，顾客可主张全额退款。
- **不可抗力（如极端高温）**：若在夏季高温期，且商家未采用冰袋/保温箱，导致到货全坏，**责任在商家**（因未履行冷链约定）；若商家正常冷链且已尽提示，但快递运输途中异常延迟，则涉及三方协商。

### 总结建议
**默认处理方式**：顾客按“坏果包赔”规定提交照片后，商家应主动承担。若商家不履行，顾客可直接申请平台仲裁，**无需与客服反复沟通**——平台规则通常更偏向消费者保护（生鲜类除定制款外，坏果基本都会支持退款）。
