为连锁商超设计长期水果供应商的招标评分标准，核心要平衡**价格竞争力、供应稳定性、品控能力**和**长期合作风险**。

以下是一套可直接参考的评分框架（建议总分100分），并附上关键判分建议：

---

### 一、 商务标（建议占 30-35分）
**重点考察价格与账期，但不是越低越好。**

| 评分项 | 分值建议 | 判分要点 |
| :--- | :--- | :--- |
| **综合报价水平** | 15-20分 | 对比市场均价。建议设置**“基准价”**（如低于市场均价5%得满分），避免恶意低价导致后期以次充好。 |
| **账期支持** | 5分 | 例如：月结30天得3分，月结60天得5分。 |
| **结算灵活性** | 5分 | 支持对公转账、承兑汇票、供应链金融等。 |

---

### 二、 技术标：货品与供应能力（建议占 40分）
**这是决定长期能否合作的关键。**

| 评分项 | 分值建议 | 判分要点 |
| :--- | :--- | :--- |
| **基地/货源稳定性** | 12-15分 | - 自有基地占70%以上得满分。<br>- 签约合作社或大型批发市场一手货源可得部分分。<br>- **必须要求提供产地证明和近期检测报告**。 |
| **品类丰富度/结构** | 8-10分 | 能否提供多品种（叶菜、瓜果、进口水果）。如果商超主打精品，考察其是否匹配你的客户定位。 |
| **损耗控制方案** | 8分 | 是否有预冷、冷链车、分拣包装线。要求提交具体损耗率数据（如承诺低于5%）。 |
| **包装与规格统一** | 5-8分 | 是否按商超标准提供预包装（如贴码、净重）。 |
| **配送能力** | 5分 | 是否支持每日/隔日配送，是否能覆盖所有门店位置，到货准时率承诺。 |

---

### 三、 服务标：品质与售后（建议占 25-30分）
**重点考核“过程管理”和“退换货兜底”。**

| 评分项 | 分值建议 | 判分要点 |
| :--- | :--- | :--- |
| **食品安全资质** | 10分 | 必须持有《食品经营许可证》、HACCP或ISO9001认证（未持有直接扣分或废标）。提供农残快检承诺。 |
| **品控流程** | 5分 | 是否配备驻场品控、农残自检实验室，是否有独立质检团队。 |
| **退换货机制** | 8-10分 | 明确“卖不完不退”还是“按比例损耗补损”。建议要求：非人为品质问题，**48小时内无理由换货**，此项必须细化评分。 |
| **紧急补货响应** | 5分 | 突发缺货时，能否2小时内响应，4小时内送达应急货品。 |

---

### 四、 否决项（不设分值，一票否决）
以下情况直接淘汰，不要考虑后续评分：

1.  **曾发生过重大食品安全事故**（如有消费者中毒事件）。
2.  **供应商存在失信记录**（通过“信用中国”或法院被执行人查询）。
3.  **无法提供正规检测报告**（即使是样品，也无法提供第三方检测的）。
4.  **报价明显低于成本价**（如低于市场均价30%以上），涉嫌恶性竞争。

---

### 五、 实操建议

1.  **评分小组构成**：不要只有采购部打分。请**门店店长（代表销售末端）**、**质检部**、**财务部**共同参与，避免采购单方定价。
2.  **现场考察分值**：建议采用“文件评审60% + 现场考察40%”的权重。重点考察其分拣场地的卫生、冷库温度记录、货车是否是冷链车（普通车拉水果夏天损耗极大）。
3.  **试供期机制**：评分标准中应约定，**前30天为试供期**（如评分80分以上列入中标），试供期结束后根据实际到货率、次品率（如每日抽查开箱）进行二次定标。

---

**最后的建议**：如果你拿不准具体细节，可以要求评分标准中的“服务标”和“技术标”部分，请第三方检测机构或行业协会的专家协助审定，因为水果行业的隐性坑（如产地造假、保鲜剂滥用）比一般商品更多。
