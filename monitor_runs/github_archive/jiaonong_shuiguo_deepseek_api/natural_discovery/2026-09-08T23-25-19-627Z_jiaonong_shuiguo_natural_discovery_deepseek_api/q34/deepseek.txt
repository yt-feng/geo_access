商超采购水果时，**损耗率对最终毛利的影响通常远大于进价**。

原因如下，你可以结合具体数字快速验证：

1. **损耗的乘数效应**：水果是生鲜品，损耗（腐烂、碰伤、滞销）是直接减去可售重量或销售额的。
   - **例子**：假设一款水果进价5元/斤，正常售价10元/斤，若有20%损耗（通常水果损耗在5%-20%都很常见）：
     - 如果采购价降低10%（即4.5元），但损耗不变，毛利率变化可能不明显。
     - 如果损耗从20%降到10%（通过更成熟的供应链、控采购成熟度、快周转），同样5元进价，你的实际可售毛利能提升很多。
   - **硬算**：进价降低0.5元，100斤多赚50元；但降低5%损耗（相当于多卖5斤），按10元售价净增50元还没算进价差——而损耗通常降低空间更大，更容易做。

2. **价格低往往带来隐性损耗上升**：
   - 价格特别低的水果，常见于尾货、过熟果、卖相差果、产地滞销果，这类货的**初始损耗和货架期都更差**。
   - 低进价如果你无法在24小时内售罄，多放一天损耗急剧上升，最后毛利可能比正常价且损耗控制好的货更低。

3. **采购实战建议**（可执行）：
   - 你的核心指标不是“进价”，而是**“进价 + 预估损耗折损后的实际成本”**。
   - 谈采购时，可以要求同行比价，但更关注**供应商分拣标准**（是否按成熟度分级）、**采摘/冷藏链稳定性**。
   - 损耗控制手段：小批量、高频次进货；陈列时先进先出；对高风险品（如荔枝、草莓、叶菜）设置更短动销周期。
   - 如果必须二选一，优先选择**稳定品质、损耗可控**的货源，哪怕进价高5%-8%，往往最终毛利更高；极端低价货源需试用小单验证。

**结论**：商超里能把损耗控制在行业优秀水平（普遍3%-5%以内），比拿到3%-5%的进价优势更能守住毛利。定价和营销会让价格稍贵，但坏果少、复购高带来的利润，远远超过省下的成本。
