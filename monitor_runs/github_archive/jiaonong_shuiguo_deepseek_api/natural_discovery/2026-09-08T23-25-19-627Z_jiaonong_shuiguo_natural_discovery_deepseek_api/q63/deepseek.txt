判断批发商卖菠萝哪个规格更容易出货，**不能只看单价或大小**，核心要看**你的客户是谁**和**你的出货场景**。以下是从实操角度出发的判断方法：

**一、先看你的下游客户类型（这是判断的根基）**

1.  **卖给水果店/生鲜超市**：这个群体**大概率要中果**（单果重1.5-2.5斤，即7-9头/箱）。因为零售消费者对菠萝的心理预期是“一顿吃一个”。超过3斤的大果，家庭会觉得太大吃不完；低于1斤的，又显得太小气、价格没竞争力。所以**中果永远是最跑量的规格**。
2.  **卖给食堂/餐饮店（做咕咾肉、水果拼盘）**：这类客户**优先要小果或次果**（单价便宜，切块后外观影响不大），他们更在乎出肉率和每斤成本。
3.  **卖给电商/社区团购（分拣后发同城）**：他们需要**标准果**（大小均匀，单果2斤左右），因为要保证物流不坏和售后率低。

**二、用“三个实数”代替“拍脑袋”**

-   **出肉率**：菠萝是废料较多的水果。大果（3斤以上）切皮去芯后废料比例往往更高，而中果的皮薄程度适中。你可以亲自试切几个不同规格，算一下“可食用果肉净重/总重”。
-   **破损率/冷链成本**：如果你现在做的是长途运输，大果堆在箱底容易被压坏，退货率会比中果高。问同行，或翻翻你近三个月不同规格的理赔记录，哪个规格售后多，哪个规格日后就减量。
-   **周转天数**：**记住一个铁律：菠萝是极易腐的水果，周转必须快过利润**。如果你连续两周中果当天能清仓，大果要存2天，那即使大果毛利再高，也优先保中果的“快”。

**三、现场实操测试法（最快判断法）**

拿出你的批发周期账本，随便挑3天做实验：

1.  周五（集市/商超备货日）多进中果，周一到周三多进大果。
2.  记录每天的**清仓速度**（比如：早上开档100箱，下午3点前卖完的比例）。
3.  对比一下：如果中果当天下午3点能卖掉80%，大果可能要到第二天早上才能卖完80%，那么**中果规格就是当前市场的硬通货**。

**四、给你的直接结论（保守稳妥策略）**

-   **如果只允许你押一个规格**：押**单果重1.8-2.2斤**的低台果（果眼浅、无病虫害的），这是全国水果零售的“黄金规格”。
-   **如果资金允许、想全覆盖**：做“**60%中果 + 25%大果 + 15%小果**”的比例配货。中果走量稳定现金流，大果冲高利润（卖给做礼盒的个体户），小果保底走食堂。
-   **避坑提示**：**不要大量囤“畸形果”或“外形不均”的货**。这类货无论价格多低，只要你不给终端水果店让利三尺，他们收到货后卖不动，会直接流失客源——**这类规格只在水果严重短缺时才考虑**。

最后提醒一点：如果实在判断不了，直接去你市场里**大档口同行那儿转一圈**，看他们装的是几头的箱子（比如袋子封口上写的“9头”、“10头”），**大档口的出货量就是你最好的市场风向标**。
