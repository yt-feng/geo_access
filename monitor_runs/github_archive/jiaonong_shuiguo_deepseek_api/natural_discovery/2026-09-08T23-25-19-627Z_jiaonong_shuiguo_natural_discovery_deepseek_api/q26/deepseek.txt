针对社区超市销售小包装香蕉，采购时需要注意以下几点，尤其是包装与损耗控制方面：

**一、包装环节的核心注意点**

1. **尺寸与规格匹配**  
   - 建议采用**1-2根/包**的小包装，或者**200-300克/包**的重量规格，方便单人购买。
   - 包装尺寸需预留缓冲空间（建议留出5%-10%），避免香蕉在箱内因挤压变形。

2. **透气性与防压设计**  
   - **不要使用全密封保鲜膜**，香蕉需要呼吸，建议选用带透气孔（孔径1-2mm）的薄膜或网袋。
   - 底部需加吸潮海绵或防震纸板，防止果柄刺破包装或果肉碰伤。

3. **成熟度分级包装**  
   - 采购时要明确区分**硬绿果（未熟）**和**黄熟果（即食）**。
   - 包装上必须标注成熟度等级，方便按用途分开陈列，避免混装后催熟过快导致损耗。

4. **防碰撞内衬**  
   - 包装盒建议用瓦楞纸或可降解泡沫，内部加**隔离隔板**，防止果与果直接接触产生机械伤。
   - 每包内建议附一张干燥剂（食品级硅胶），但需确保不与果肉直接接触。

**二、损耗控制的关键操作**

1. **采购数量与周转速度匹配**  
   - 小包装香蕉保质期仅**2-4天**（冷藏条件下），按社区店日均销量估算，建议首批进货不超过**3-5天销量**，避免库存积压。
   - 尽量选择**每周2次小批量进货**，而不是一次性大批量，以降低熟化期内的自然损耗。

2. **冷链与到货验收标准**  
   - 到货时立即检查果柄是否干裂、果皮是否有深褐色斑点（炭疽病早期），**剔除任何有流汁、发黑迹象的果实**。
   - 保持运输温度在**13-15℃**，避免低于12℃引发冷害（果皮变灰褐）。

3. **陈列与补货规则**  
   - 上架时遵循**“先进先出”**原则，小包装外侧贴日期标签。
   - 早晨放熟果，下午补硬果；每**2小时**巡视一次，将过快成熟或软化的包装撤下做折扣处理（如水果切盘或员工内部消化）。

4. **包装破损的应急处理**  
   - 采购合同中需约定：因包装破损导致的坏果，供应商需**按比例提供无偿补发**（通常要求破损率不超过2%-3%）。
   - 收货时拍照留存，签收后48小时内反馈有效。

**三、采购清单建议（可附在合同附件）**

- 包装材质：食品级PP托盘 + 带孔PE膜（透气孔总直径不少于5mm/包）。
- 每包净重误差：不超过±10克。
- 单包允许碰伤面积：不超过果皮总面积的3%（肉眼可见一处浅褐色面积≤1cm²）。
- 供应商需提供成熟度检测报告（如硬度计读数或色卡比对）。

**最后提醒**：如果本社区超市无冷柜陈列，建议将小包装香蕉放在**通风阴凉处**，并缩短上架周期至1-2天，否则损耗率会显著上升。
