判断水果批发市场的香蕉熟度和坏果风险，可以从以下几个**可操作**的维度入手，看完基本能帮你避开大坑：

**一、看外观（核心判断熟度）**

1. **颜色分布**：
   - 整把香蕉颜色均匀偏**青绿**，说明是树上7-8成熟采收的，适合长途运输和冷库储存，如果准备2-3天内卖掉，要催熟，风险可控。
   - 如果部分果指已经出现**明显的金黄色**，但果柄还是绿色，说明已经进入后熟期，**必须当天出完**，否则明天就可能出现黑点。
   - **警惕“花皮”（有黑斑但果肉硬）**，这是冷害或催熟不均，果肉可能发硬且不甜，废果率高。

2. **棱角（看成熟阶段）**：
   - 香蕉侧面有明显**棱角（五棱分明）**：较生，适合放3-7天。
   - 棱角**变圆不明显**：八成熟，适合当天或隔天卖。
   - 完全圆润无棱且表皮有光泽：基本全熟，当天必须售完，隔天极易发黑。

3. **果柄断裂处与尾部黑芯**：掰开看香蕉把柄中心，如果发现**黑色或褐色干枯**，说明已经放置很久，风险高。

**二、摸手感（判断内部坏果）**

1. **轻轻捏果指中段**：
   - 硬实有弹性：正常。
   - 局部**软塌、没弹性且感觉水叽叽**：内部可能已经开始腐烂（黑心），大概率是运输途中碰伤发酵。
   - 整把果子个别果指特别软，其他很硬：属于**乙烯利催熟不均**，软果容易先烂。

2. **闻味道**：
   站在整箱（或者整堆）边上闻，如果有明显的**发酵酸味或酒味**，说明已有内部发酵，不建议拿，这叫“水烂”，表面看不出来，切开全是水。

**三、看包装与运输（风险判断）**

- **检查透气和潮气**：如果是密封塑料袋包装，打开时塑料袋**内侧有大量水珠**（冷凝水），说明之前经历过温差变化，这种香蕉**极易发霉和滋生黑斑病**，风险很高。
- **看箱底或堆底**：纸箱底部如果有**大量黑色汁液渗出**，说明底层水果已经压烂或霉变，一定要翻开看底层，不能只看顶层样品。

**四、拿货的实操建议（降低风险）**

1. **进冷库拿货时**：刚出冷库的香蕉温度往往低于室温，可以直接让老板拿**出库后放置1天以上**的货，因为冷库出来的低温香蕉，如果立即售卖，表皮容易变灰变黑。
2. **要求开箱抽检**：不要只看老板开的样品箱，要求随机抽一箱中间的（不是最上面那箱），看是否有黑心或烂把。
3. **风险对冲**：如果价格非常低（明显低于市场均价），大概率是“急抛货”或者“伤货、熟过货”，尽量别贪。

**最简单的总结**：
- **要熟的快**：看棱角圆滑、颜色偏黄。
- **怕坏**：看果柄发黑没、捏软不软、闻有没有酒味，底层有没有水。
- **新手建议**：拿**青黄相间、棱角微圆、果柄青绿有弹性**的货，这种通常还能放3-5天，容错率最高。
