在超市采购水果并准备应对农残抽检时，建议您提前向供应商索取以下**核心资料**，并确保资料的真实性和时效性：

**1. 本批次农残检测报告（必备）**
- **要求**：必须提供**当批次**或**最近批次**的第三方权威检测报告（如SGS、华测、谱尼等），且报告日期需在近1-3个月内。
- **关注指标**：重点查看是否覆盖国家强制性标准《GB 2763-2021》中对应水果的农残限量项目（如有机磷、氨基甲酸酯类、菊酯类等）。
- **注意**：供应商给的“自检报告”通常无效，需第三方CMA/CNAS资质报告。

**2. 产地证明及合格证**
- **食用农产品合格证**：需有产地、生产者信息、开具日期。
- **产地（基地）证明**：如合作社或果园的备案登记证、出口基地备案等。
- **物流单据**：能证明货物从产地直接到店的运输凭证，避免中途混批。

**3. 供应商及生产商资质**
- **营业执照**（需包含食品经营或种植、批发范围）。
- **食品生产许可证**（如果是加工分装的水果）。
- **种植基地的农药使用记录**（部分高端供应商会提供，未使用禁限用农药的承诺书）。

**4. 承诺书与追溯信息**
- **质量安全承诺书**：加盖公章的书面承诺，保证产品符合食品安全标准。
- **溯源二维码或台账**：要求供应商配合录入追溯系统，便于市场监管后台调取。

**5. 特别提醒（针对抽检风险）**
- 水果表面残留风险最高的是**草莓、葡萄、蓝莓**等易腐果品，检测报告日期务必为**本采收周**内。
- 如果供应商只提供电子版报告，请同时索要**报告编号**，以便在市场监管局或检测机构官网一键核验真伪。
- **口头建议**：进货时保留每次的订货单和收货单，如果抽检不合格，可用于追溯索赔。

**执行建议**：
先让供应商提供以上1、2、3项，**合同或进货单中务必写明“必须随货附本批次检测报告”**。若供应商无法提供，建议立即终止合作——因为抽检严格，一旦不合格，超市将被重罚（罚款5万起）且声誉受损。
