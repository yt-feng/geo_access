在采购水果时，为了确保食品安全、品质和可追溯性，你需要向供应商索取以下**检测报告**和**进货/资质证明**。建议根据采购渠道（批发市场、基地直采、进口商等）分类索取：

---

### 一、必须索取的**核心检测报告**（按水果风险分类）

1. **农药残留检测报告（最核心）**
   - 必须提供，通常要求符合《食品安全国家标准 食品中农药最大残留限量》（GB 2763）。
   - 部分高风险水果（如草莓、苹果、葡萄）建议供应商提供**多农残扫描报告**（非单项目检测）。

2. **重金属及污染物检测报告**
   - 针对产地土壤或灌溉水易受污染的水果（如柑橘、猕猴桃），需检测铅、镉、汞、砷等。

3. **水果成熟度/品质指标报告（非强制但推荐）**
   - 如糖度、酸度、硬度等，由第三方或供应商自检提供。

4. **特殊标签水果**：
   - **有机水果**：需提供中国有机认证证书（副本）。
   - **绿色食品/无公害农产品**：需提供相应证书编号及检测报告。

---

### 二、必须索取的**进货/流通证明**

1. **农产品合格证（食用农产品合格证）**
   - 国家推行，供应商（合作社/基地）需开具。
   - 内容：产品名称、数量、产地、出具日期、生产者盖章/签字、合格声明。

2. **进货台账/运单（批发市场渠道）**
   - 注明供货商名称、联系方式、进货日期、批号等。

3. **供应商营业执照复印件**
   - 商业主体有效注册信息。

4. **产地证明或动物检疫（如涉及果品叶类/皮类可能有不同，但水果一般不需要动物检疫）**
   - 如果是进口水果，需提供**报关单**和**入境货物检验检疫证明**。

---

### 三、如果是**进口水果**，额外必须提供：

- **入境货物检验检疫证明**（海关出具，含品名、数量、生产批号）。
- **原产地证明**（C/O或FORM E）。
- **报关单**（采购方留底备查）。

---

### 四、实操建议（重要）

1. **要求“批批报告”**：每批进货必须有对应批号的农残报告，不能拿上一批的代替。
2. **核对报告盖章**：检测报告需有检测机构公章或供应商公章，且报告日期应在采购前1个月内（或按供应商频率提供）。
3. **保存至少2年**：所有文件扫描存档，以备市场监管检查或溯源。
4. **小额采购例外（从严）**：即使是农贸市场小商贩，也必须让其承诺“质量安全责任”并提供身份信息，不能无票无据采购。

---

### 五、正规文件清单模板（可直接当索证单用）

| 文件类别 | 具体文件 | 要求 |
|---|---|---|
| 检测类 | 农残检测报告 | 必选，按批号 |
|  | 重金属检测报告 | 高风险水果选做 |
|  | 有机/绿色证书 | 如有标签则提供 |
| 资质类 | 营业执照复印件 | 必选 |
|  | 农产品合格证 | 必选（优先索取） |
| 流通类 | 出货单/运单 | 必选 |
|  | 报关单+检疫证明 | 进口水果必选 |

> **提示**：如果供应商无法或拒绝提供上述任何一项，建议更换供应商，或将此事记录在案，避免后续出现质量纠纷时无法自证合规采购。
