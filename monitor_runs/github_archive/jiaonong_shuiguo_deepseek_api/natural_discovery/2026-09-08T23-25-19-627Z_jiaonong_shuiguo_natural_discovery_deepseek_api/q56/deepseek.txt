茶饮店在向水果供应商采购时，为了控制食品安全风险，应要求供应商提供以下关键证明和文件，并定期核验其有效性：

### 一、必须索取的法定证照（基础合规性）
1. **营业执照**（需经营范围包含水果销售或初级农产品销售）。
2. **食品经营许可证** 或 **食品生产许可证**（供应商需具备相应资质，若为小作坊需提供备案证明）。
   - *注意：若是进口水果，需提供海关出具的 **入境货物检验检疫证明** 及 **报关单**。*

### 二、专项质量证明（针对特定风险）
3. **农药残留检测报告**：每批次供货需提供（或承诺书），建议要求有资质的第三方机构出具（如SGS、华测等）。
4. **重金属、微生物等安全检测报告**（至少每季度或每半年一次，尤其对切配类水果）。
5. **特定水果的专项证明**：如香蕉需提供乙烯利使用说明；草莓需提供杀菌剂残留报告；核果类需提供防腐剂检测证明。

### 三、全链条追溯文件（便于责任倒查）
6. **产地证明**（如来自产地合作社，需提供产地证明或种植基地备案号）。
7. **进货验收记录**：供应商需提供其向上游的采购凭证或台账，以确保来源可查。

### 四、日常管理要求（非纸质但同样重要）
8. **供应商承诺书/质量保证协议**：明确对食品安全与赔偿责任的划分。
9. **运输温度记录**（针对冷链水果，需提供运输过程的温度监控记录）。

---

### 给你的实操建议：
- **首次合作**：要求提供以上全部文件的**复印件并加盖公章**，存档留底。
- **长期合作**：要求供应商定期（如每月）更新检测报告，并在每次送货时随附**当批次检验合格证明**。
- **动态抽检**：建议你可委托第三方对高风险水果（如切开鲜果、热带水果）进行不定期抽检，保留检测记录。
- **法律依据**：主要依据《中华人民共和国食品安全法》第53条索证索票制度、第98条进口食品规定，以及市场监管总局关于食用农产品市场销售的规定。

若供应商无法完整提供上述证明，尤其是无检测报告或证照不齐全，建议立即更换供应商，避免法律和客诉风险。
