针对小水果店进香蕉，**最优先看熟度**，其次是坏果率，然后是价格，最后才是送货速度。具体原因和操作建议如下：

**1. 熟度（最核心，决定生死）**
- 香蕉是典型后熟水果，进店后还会继续熟。如果进时太生（全绿），顾客看到不会买，且催熟需要时间和设备，小店难操作；进得太熟（已出现黑斑、表皮发软），可能1-2天内卖不完就烂掉。
- **建议**：进“微黄偏绿、果柄新鲜硬挺”的货，即七至八成熟。摸起来略硬但按着有轻微弹性，表皮黄色但两端略带绿。这样在常温下可放3-5天，有足够销售窗口。

**2. 坏果率（控制损耗）**
- 香蕉怕压、怕碰伤。坏果包括压坏、黑点病斑、发霉等。如果整箱中散见软烂、流水、发酸的，说明运输或储存不当，哪怕便宜也不能要。
- **建议**：开箱时检查上下层，挑出受伤果；争取“坏果包换”或按比例扣款（例如整箱坏超5%要求补或退差价）。

**3. 价格（利润空间）**
- 小店进货量小，议价能力弱，但过于追求低价往往意味着拿的是次品（老果、过熟或碰伤多），最终损耗吃掉利润。
- **建议**：拿市场中等偏上品质，价格比最高档便宜个3-5毛/斤即可，不要贪图明显低于行情的货。

**4. 送货速度（弹性要求）**
- 香蕉不像叶菜那样必须当天送。如果供应稳定，提前1天订货，次日到货完全够用。真正需要送货快的情况是：生意突然火爆断货、或节假日补货。
- **建议**：和供应商谈好“固定配送日+临时加急补货”的机制，确保旺季有保障即可，正常运营不必强行追求当日达。

---

**综合操作顺序（决策优先级）**：
> **先看熟度和坏果率 → 再看价格 → 最后比送货速度**

**给小店的实操小贴士**：
1. 亲自去批发市场挑货，现场捏香蕉硬度、看果柄是否新鲜。
2. 进货量控制在“预计2-3天能卖完的量”，宁愿勤进货，也不要囤货。
3. 夏天运输和存放易加速成熟，进货时要求供应商减少混装成熟果。
4. 多找1-2家供应商对比，固定一家作为主力，另一家作为应急。
