第一次做水果生意，核心原则是**“少量多批次、看货再补货”**，千万别急着压货。

针对你提到的香蕉、苹果、橙子，试单逻辑完全不同，因为它们损耗和走量周期差别很大。给你一套可执行的“实战清单”：

**一、 先定“进货铁律”（对每个供货商都适用）**

1. **只拿一箱/一筐**：无论对方怎么鼓吹量大优惠，第一次绝对只拿一个最小单位（比如一件苹果，大概20-30斤）。
2. **当场开箱验货**：重点看**中层和底层**（很多供应商在表面放好果，下面以次充好）。随机拿底层几个摸一摸、捏一捏。
3. **要尾货/代卖渠道**：如果本地批发市场有那种“包赔代卖”的档口，第一次可以试走代卖，卖不掉退回去，只付手续费。这能让你零风险摸清行情。
4. **问清“损耗包不包”**：口头问一句“回去如果烂了几个，你们认不认？” 好的供应商会认账，差劲的会推脱。

**二、 三种水果的差异化试单策略**

| 水果 | 试单核心 | 具体操作 |
| :--- | :--- | :--- |
| **香蕉** | **看“催熟房”，别拿全生货** | 香蕉是后熟水果，批发市场很多是生蕉。第一次不要拿青皮蕉，**直接拿“已经黄了但带一点绿”的**，当天就能卖。如果供货商没有催熟条件，你拿全生的回去只能烂在店里。试单量控制在**5斤以内**，因为它的损耗是这三种里最高的。 |
| **苹果** | **看“口感+分级”，别被漂亮果骗** | 苹果容易存储，但同行都在打价格战。第一次拿货，**拿中档偏下的价位**（比如70#-80#规格），别追高端。**最重要是试吃**：削皮咬一口，看是否脆甜、有无酸涩味。同一批苹果，上下层甜度可能不一样，要尝中间那层的。 |
| **橙子** | **看“皮厚薄+汁水”** | 橙子最坑人的是“看着大，皮厚肉干”。试单时，**用手掂重量**（同样大小，越沉越好），**用手指按压果皮**（有弹性的是鲜的，硬邦邦的可能是冷库陈货）。第一次拿量控制在**10斤左右**，因为橙子如果口感好，回头客最多，但一旦踩雷，砸口碑也最快。 |

**三、 试单当天的“临门一脚”（判断要不要长期合作）**

1. **当场加微信/要名片**：但先别谈账期，第一次**全部现金结清**，为自己留足主动权。
2. **故意问一句“明天还拿不拿”**：看对方是急着甩货（对你说“再拿优惠点”）还是正常报价。后者更靠谱。
3. **实战验货法**：试单拿回去后，**卖两天记录损耗**。如果苹果卖了2天烂了1个，橙子皮干了2个，这说明供货商货品本身新鲜度差。**最多试单两次**，损耗超过5%（即20斤损耗1斤），直接换下一家，别恋战。

**最后提醒一个常见坑**：很多供货商会主动帮你“挑好”放箱子里。第一次一定要**自己亲自选或者盯紧他挑**，防止他把你当大客户宰，给你塞隔夜货。

**试单预算建议**：三种水果各拿20斤左右，总成本控制在150元以内。这笔钱就当是“探路费”，只要能换来一个靠谱的长期供货商，绝对物超所值。
