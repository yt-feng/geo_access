水果店采购香蕉时，**一箱内大小不一样，确实会影响销售，但影响程度取决于“大小差异的程度”和“你的经营模式”**。

**1. 直接影响（主要在视觉和定价上）**

- **外观不整齐，影响货架观感**：顾客在挑选时，如果看到箱内香蕉粗细、长短混杂，会觉得“这箱货不新鲜、不整齐”，降低购买欲望，尤其是对品质敏感的中高端顾客。
- **称重计价矛盾**：如果按斤卖，大小差异不明显；但如果按“根”卖（如论把卖），大小不一容易让顾客产生“花同样的钱买小果”的不满，或直接挑走最大的一把，剩下小果滞销。
- **催熟不均匀**：香蕉是呼吸跃变型水果，大小差异会导致成熟时间不同。大果可能先软先熟，小果还偏生，同一批进货后容易“大果熟过头、小果还是硬的”，增加损耗。

**2. 间接影响（库存与损耗）**

- **分拣成本上升**：如果箱内差异非常大，你需要在售卖前重新筛选分级，否则很难统一定价或统一促销。
- **特价处理麻烦**：小果或畸形果如果一直卖不掉，只能降价促销，这会拉低整体毛利。

**3. 什么情况下影响较小？**

- **你是做低价走量、社区团购或菜市场散卖**：顾客更在意价格，只要便宜、够新鲜，大小不一可以接受。
- **箱内差异属于“正常自然差”**（比如上下层果肉厚度略有区别），不影响整体卖相，那么影响微乎其微。
- **你打算拆散后按“小果/中果/大果”分三堆放**：这属于主动分级，反而能利用差异，小果打成特价吸引客流，大果卖高利润。

**4. 实际采购建议**

- **如果是一级批发市场进货**：优先要求“同一级别”（如统货里要求果指长度接近，或直接买“一级/二级”分级的货），哪怕价格每斤贵两三毛，也远比损耗浪费划算。
- **如果是产地直发整箱**：收货时当场开箱检查，如果差异属于“中大宗”混入“特小宗”（例如多数40cm长、个别20cm短），建议当场挑出小果，降价捆绑出售或做果盘。
- **如果差异只是“一根两根稍短”**：不影响，按整箱正常销售即可，但摆放时将有斑痕、短小果放在底层或靠内侧，大果、匀果朝外。

**一句话总结**：**小到中等的差异不会毁掉销售，但差异过大（超过20%~30%）会明显拖累卖相和利润。** 最好的做法是：进货前问清“统货”还是“分级货”，如果只能买到大小不一的统货，就主动拆箱分级，给不同大小定不同价，利用差异化赚钱，而不是被迫混卖。
