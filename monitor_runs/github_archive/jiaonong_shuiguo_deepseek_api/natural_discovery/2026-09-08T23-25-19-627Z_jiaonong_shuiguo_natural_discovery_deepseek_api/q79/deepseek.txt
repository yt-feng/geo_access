面对这个问题，我的建议是：**优先问配送和售后，价格放在第三位，但不要忽略。**

具体理由和实操建议如下：

**1. 配送是生命线（决定你能赚多少）**
- **为什么最重要**：水果是生鲜易损品，配送时效决定了损耗率。如果运输迟了、冷链断了，烂果率可能高达10%-20%，你的利润会被直接吃掉。
- **必问问题**：
  - 从果园/仓库到你的小区，最快多久送达？（是否有固定配送日？）
  - 是冷链车还是普通货车？（夏季尤其关键）
  - 如果遇暴雨、封路等突发情况，最迟能推迟多久？有没有备用应急方案？

**2. 售后是信誉墙（决定你还能不能做）**
- **为什么重要**：团购的核心是邻居信任。你无法保证每批水果100%完美，但供应商怎么处理“坏果”直接决定你是赚口碑还是赔名声。
- **必问问题**：
  - 如果到货后10%以内坏果，是补发、退款还是按比例赔付？（要白纸黑字写清楚标准）
  - 签收后多少小时内可以反馈？（常见是24-48小时）
  - 理赔流程是拍照+说明，还是要寄回坏果？（如果要求寄回，可以直接PASS，因为很麻烦）

**3. 价格是利润空间（但不能单独比）**
- **为什么不排第一**：即使给你全网最低价，如果配送延误+售后推诿，你赔掉的口碑和精力远超省下的几毛钱差价。
- **如何比较**：要求供应商**报“落地价”**（包含包装、运费的总价），而不是单纯问“多少钱一斤”。同时问清**是否含破损补贴/售后基金**（有些供应商报价含“补损额度”）。

**给团长的“黄金提问组合”（按顺序当面问）：**
> 1. “你们送到我们小区，从采摘到派送到团长手上，最快多少小时？用什么车？”
> 2. “如果我这批货有5%的坏果，具体怎么赔？是您直接补发还是退款？我需要做哪些动作？”
> 3. “这个价格是含运费和损耗补贴的最终价吗？如果我要加到50份，价格能不能再低一点？但前提是售后标准不变。”

**最后提醒**：如果时间允许，**建议先小额试单（比如订10箱苹果）**，亲自验证一次配送时效、包装质量、售后响应速度，再决定长期合作。**下单前口头承诺再美好，都不如一次实际交易靠谱。**
