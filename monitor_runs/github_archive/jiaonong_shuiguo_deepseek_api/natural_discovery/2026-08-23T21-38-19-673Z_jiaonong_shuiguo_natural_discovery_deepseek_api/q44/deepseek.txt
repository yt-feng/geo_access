判断商超供应商售后稳定性，不能只听口头承诺，要看**制度、流程和可验证的既有记录**。以下是可执行的具体排查步骤和判断标准：

**一、直接要求提供书面文件（最硬性）**
1. **售后协议条款**：要求供应商在合同中明确写清：
   - 响应时效（例如：质量问题反馈后**2小时内**回复，24小时内给出处理方案）。
   - 处理方式（换货、补货、折价或退款的具体触发条件）。
   - 节假日、台风季（菠萝和香蕉易在运输中腐损）的特殊预案。
2. **退货/赔付流程图**：要求对方提供带责任人和时间节点的售后流程图，而不是“口头说没问题”。

**二、测试响应速度（最有效）**
- **工作日白天测试**：以“疑似到货香蕉黑心，需紧急报损”为由，在工作日上午发送书面邮件+微信，记录**首次回复时间**。稳定供应商通常**1-2小时**内有回复。
- **晚间/周末测试**：故意在周六晚上发一个“菠萝到货有一箱出水”的询问，观察是否有值班人员或自动回复机制。如果是个人供应商，若第二天中午才回，说明售后依赖个体习惯，不稳定。

**三、查历史记录与第三方反馈（最客观）**
1. **索要上季度退货记录**：让供应商提供过去3-6个月的销售单中，因质量原因退货或换货的**明细张数及处理天数**。如果对方支吾或拿不出，基本等于没有稳定售后。
2. **同行业口碑求证**：打电话给该供应商在附近另一个城市的商超采购（可从其包装箱/物流单上找线索，或直接请供应商提供2-3家合作商超的名称，然后以“巡检员”身份电话询问）。
3. **直接看物流对接口径**：询问运损处理时，供应商是否要求“先拍照、后留货”，还是“口头报损即可”。**稳定售后一定要求留痕**，这反而是好事。

**四、小额试单赔付测试（最直接）**
- 首次合作不要下大单，下一次**300-500公斤**小批量混合单（含少量易损的香蕉），故意记录是否有零星腐损。
- 提出退货要求时，观察对方是否：
  - 直接同意补货/退款，而不找理由推诿。
  - 明确告知“已收到凭证，X日内处理”。
- 如果小额单的售后都拖延超过3天，大单时只会更差。

**五、特别提醒菠萝和香蕉的特殊判断点**
- **香蕉属“后熟型”**，售后问题常出现在货架期变短而非腐烂。稳定的供应商应主动提供“催熟程度批次说明”并承诺对过度催熟货品无条件换货。
- **菠萝的售后常是切口发酸、冠芽失水**。稳定供应商应接受对“外观完好但切开内部褐变”的批次按比例核销，而不是只赔表面破损。

**最终判断口诀**：  
**敢写时限、敢留书面、敢接紧急电话、敢给小单试错**的供应商，售后必稳定；  
反之，**只说“没问题、老客户都知道”**，且拒绝提供数据和流程的，慎选。

如果以上测试中，对方有2项及以上不达标，建议直接替换供应商，因为超市生鲜的售后崩溃往往发生在大批到货当天，而那时已来不及补救。
