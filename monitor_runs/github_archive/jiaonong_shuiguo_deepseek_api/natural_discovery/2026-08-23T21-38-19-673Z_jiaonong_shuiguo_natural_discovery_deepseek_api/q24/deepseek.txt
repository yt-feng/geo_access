在超市采购水果时，为了应对农残抽检，同时确保商品合规和追溯性，建议你在采购合同签订前或首批进货时，向供应商索要以下**核心资料**：

**一、 资质与合规证明（必备）**
1.  **营业执照**：确认供应商是合法经营主体，且经营范围包含水果销售或种植。
2.  **食品经营许可证**：如果是生鲜配送或批发商，需提供。
3.  **本批次农残检测报告**：必须是**该批次**（或同产地同一采收期）的检测报告，报告需加盖公章或CMA（中国计量认证）/CNAS（中国合格评定国家认可委员会）章。报告中应明确标明检测项目（如有机磷、氨基甲酸酯类等）及“未检出”或低于国标限量值的数据。

**二、 追溯与产地证明（用于应对抽检溯源）**
4.  **产地证明**：由产地村委会、农业合作社或政府出具，证明水果来源区域。
5.  **进货凭证**：供应商的送货单、销售清单，上面需注明品种、数量、产地、到货日期。
6.  **种植基地信息**：如果是直采，应要求提供基地备案号、农药使用记录（可溯源至具体工人和用药时间）。

**三、 风险提示与应对材料（针对抽检不合格）**
7.  **供应商质量承诺书**：书面承诺如因农残超标导致超市被查处或下架，供应商需承担全部经济损失及法律责任。
8.  **自检报告（如有）**：部分大型供应商会有内部快检室出具的快检结果，可作为进货验收的第一道防线。

---

**额外建议（提高抽检合格率的关键操作）：**

-   **验收时再次索证**：每次到货，**必须**随货附有该批次的纸质或电子版检测报告，不要只存一份通用报告。
-   **留样**：按超市规定对高风险水果（如草莓、冬枣、葡萄）进行留样冷冻，以备复检。
-   **快检自查**：建议超市配备农残快速检测卡，随机抽查，发现异常立即拒收，不要依赖供应商承诺。

**总结清单（最简版）**：索要 **营业执照副本** + **当批次农药残留检测报告** + **进货台账凭证**即可满足常规抽检的台账要求。如果抽检不合格，凭**质量承诺书**进行追偿。
