选择适合批量配送的水果供应商，重点要兼顾**品质稳定性、配送时效、价格账期和售后响应**。以下是可执行的筛选步骤与判断标准：

---

**一、明确需求（先做内部确认）**
1. **采购周期**：是每日配送、隔日配送，还是每周2-3次？频率影响供应商的配送成本和新鲜度保障能力。
2. **水果清单**：常备哪些品类（如苹果、香蕉、橙子、西瓜、圣女果等）？是否需要切盒果盘？
3. **单次采购量**：预估公司人数和人均消耗量（一般一人一天150g-250g），报给供应商以便其报价和备货。

---

**二、供应商来源渠道**
- **本地水果批发市场商户**：价格最低，但需自己或派员去提货，批量配送需谈额外配送费。
- **生鲜电商企业客户部**（如美菜、快驴、叮咚买菜企业版、美团优选企业购）：配送稳定、有APP下单记录，可对账，适合中小公司。
- **本地连锁水果店/果切品牌**：品质、包装较好，但单价偏高，适合对颜值和体验要求高的场合。
- **产地直供合作社/供应链公司**：量大（如月采购额5000元以上）时可谈，价格最优，但需验厂验质。

---

**三、关键筛选指标（用打分制评估，5分制）**
| 指标 | 判断标准 | 打分 |
|------|---------|------|
| **配送准时率** | 是否承诺到货时间点（如上午10点前），迟到是否有补偿 | 1-5 |
| **品质新鲜度** | 是否有质检报告，是否提供“坏果包赔”承诺，赔付流程是否简单 | 1-5 |
| **退换货机制** | 到货后2小时内发现坏果能否免费补送？补送时效多久？ | 1-5 |
| **价格透明度** | 是否提供含税含运费报价？是否每周有市场价联动调整？ | 1-5 |
| **最低起送量** | 是否能满足你公司“少量多次”或“一次多量”的需求 | 1-5 |
| **账期灵活性** | 月结、周结是否可谈，开票是否及时 | 1-5 |

---

**四、实操建议**
1. **先试单再转正**：每家供应商先下2-3次小额订单，实测配送速度、水果品相、客服响应。
2. **签订合同明确条款**：把“坏果率超过5%全赔”“迟到超30分钟扣款”等写进合同，避免口头承诺。
3. **备选两家**：同一时间段保持两家合格供应商，一家主供，一家应急，防止断供。
4. **定期复盘**：每月统计投诉率、损耗率、实际单价涨幅，作为续约或淘汰的依据。

---

**五、常见避坑提示**
- 低价陷阱：报价低于市场均价20%以上的，往往在次品果或短斤缺两上找补。
- 不要只看首单价格，要看**含配送费、含税、含损耗**的综合单价。
- 要求供应商提供**当批次水果的产地证明或进货单据**，防止来源不明。
