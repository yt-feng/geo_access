采购方在试卖新品时，建议遵循**小批量、多频次、低风险**的原则。具体数量没有固定标准，但可以根据以下三个核心变量来推算：

**1. 基础参考量（按日均销量比例计算）**
- **重点推荐：** 试卖量 = 该店日均销量的 **10% ~ 20%**。
- **举例：** 如果这家店平时每天卖500斤水果，那么新品试卖量建议控制在 **50~100斤** 之间。
- 这个量级既能测出市场反应，又不会因为积压导致损耗过大。

**2. 关键变量修正（根据水果属性调整）**
- **易腐烂、季节性强的（如荔枝、樱桃、杨梅）：** 建议降至 **5%~10%**，且优先选择短保的成熟果。
- **耐储存、大众接受度高的（如苹果、柑橘、香蕉）：** 可放宽至 **20%**，方便做陈列和促销测试。

**3. 决策门槛：设定“止损线”与“加码线”**
- **止损线：** 如果试卖期（建议3~5天）内，损耗率超过 **15%** 且动销率低于 **30%**，立即停止补货。
- **加码线：** 如果试卖期结束，首批货已售出 **80%**，且复购客户占比超过 **20%**，再考虑追加订单（追加量可为试卖量的2~3倍）。

**4. 实操建议（比数量更重要的动作）**
- **不要只看总量，要看品相：** 要求供应商提供 **分级定价**，试卖时挑出中上品做促销引流，差果做特价处理，避免混卖影响判断。
- **明确结算周期：** 试卖期尽量争取 **“先货后款”或“售完结款”**，如果供应商要求全款，则只采购最低起送量。

**最终结论：** 单店首次试卖，**50~100斤**（或按日均销量的10%量级）是最稳妥的起步点。如果供应商给的起订量远高于此，你可以要求拆单或分拨到多家门店试卖，以此倒逼供应商调整供货方案。
