针对社区超市增加香蕉和苹果，**建议采用“本地批发+稳定供应商”双轨制组合**，具体比例根据超市定位调整。

以下是决策框架和理由：

### 1. 首选策略：双轨并行（最稳妥）
- **本地批发市场（占采购量的60%-70%）**：用于日常补货和新鲜度优先。香蕉和苹果是走量快的水果，社区超市的核心竞争力是“新鲜”。本地批发市场可以当天凌晨进货，上午上架，损耗率低，且能用现金交易换取更低价格。
- **稳定供应商（占采购量的30%-40%）**：用于保底和特殊时段。签订月度或季度协议，锁定基础价格和供应量，防止台风、疫情或节假日批发价格暴涨时断货。同时，稳定供应商能提供更稳定的品控（比如苹果的糖度、香蕉的催熟度）。

### 2. 如果必须二选一，看以下三个条件
- **看超市日客流**：如果日均客流<150人，香蕉苹果走量慢，**选本地批发**，按需少量多批，避免库存积压。
- **看周边竞争**：旁边如果有大型超市或水果专营店，**选稳定供应商**，用固定品质（如“阿克苏苹果”“进口蕉”）做差异化，不打价格战。
- **看你的仓储能力**：有冷库或保鲜柜且能控制温度，选本地批发（大胆囤货）；如果店面小、无冷库，选稳定供应商（小批量高频次送货）。

### 3. 具体执行建议（避免踩坑）
- **香蕉**：一定选本地批发。香蕉是呼吸跃变型水果，到货后还要自己催熟，稳定供应商的“到店即卖”通常催熟过度，损耗极高。建议每天清晨去批发市场挑“青头蕉”，回店后放乙烯催熟袋。
- **苹果**：选稳定供应商更优。苹果耐储存，但社区店如果进太多分拣不均，容易卖相变差。供应商可按规格分装（如75#-80#果），减少人工分拣损耗。

### 4. 数据参考（非精确，供预算）
- 本地批发：香蕉批发价通常比市场零售价低40%-50%，但需承担0.5-1天的存放损耗。
- 稳定供应商：苹果供货价高5%-8%，但提供包退换（坏果包赔）或者账期支持。

**最终判断**：如果只能选一个，**首选本地批发**。理由是香蕉苹果作为民生水果，社区超市的核心是“勤进快销”，本地批发灵活性更高。但建议在第一个月试运行期间，同步联系1家供应商作为紧急备用，降低风险。
