茶饮店在控制食品安全风险时，对水果供应商的管理是核心环节。供应商需要提供以下证明和文件，以确保合规、可追溯，并降低食安风险：

### 1. 基础资质证明（必须）
- **营业执照**：确认供应商为合法经营主体。
- **食品经营许可证**：或**食品生产许可证**（如涉及分装、加工）。
- **开户许可证/对公账户信息**（用于财务合规，非食安直接相关，但便于追溯）。

### 2. 产品合格证明（每批次）
- **出厂检验报告**（或合格证）：由供应商出具，包含农残、重金属、微生物等常规检测项目。
- **第三方检测报告**：建议每次进货时索要，或要求供应商每季度提供一次（需由具有CMA/CNAS资质的机构出具），重点检测农药残留（如毒死蜱、克百威）、重金属（铅、镉）、防腐剂（如苯甲酸）等。

### 3. 溯源与物流证明
- **进货凭证/送货单**：载明品名、规格、数量、产地、批号、到货日期，做到批次可追溯。
- **冷链运输温度记录**：如果是易腐水果，需提供全程冷链温度监控记录（一般要求0-4℃或按品种要求）。
- **产地证明**：如产品来自特定地理标志区域或进口水果，需提供原产地证、报关单、入境货物检验检疫证明（进口水果必须）。

### 4. 特定品类额外要求
- **有机/绿色食品认证证书**（如有标注销售）。
- **无公害农产品证书**（如适用）。
- **转基因检测报告**（如属于木瓜等少数有转基因品种的水果，需明确标注并检测）。

### 5. 内部管理文件（建议备查）
- **供应商的HACCP或ISO22000体系认证**（非强制，但加分）。
- **供应商的食品安全管理制度/作业指导书**（证明其内部有控制措施）。

---

### 关键提醒（操作建议）：
1. **不要只看纸质证明**：建议你方在收货时，按比例抽查水果，并与批次证明核对（如农残报告编号、日期是否匹配）。
2. **动态管理**：每季度更新供应商证件，过期证件立即停用；建立供应商黑名单制度。
3. **留痕保存**：所有证明复印件或电子版需存档至少2年（建议保存至保质期后6个月）。

如果你需要某个具体检测项目的标准限值，或需要撰写供应商审核清单模板，可以进一步告知。
