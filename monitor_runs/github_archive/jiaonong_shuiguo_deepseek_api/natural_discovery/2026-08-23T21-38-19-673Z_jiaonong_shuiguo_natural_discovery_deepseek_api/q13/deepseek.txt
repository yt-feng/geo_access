针对小水果店做附近小区团购，供应商的支持能力直接决定你的利润和复购率。建议你在选供应商时，重点确认以下7个核心服务，并据此筛选：

**1. 极速分拣与配送（尤其关键）**
- **要求**：订单截单后（比如当天下午4点截单），第二天上午能否分拣并配送至你的门店或社区提货点。
- **注意**：避免选只能按箱发货的供应商，需支持**按份/按斤拆零分拣**，防止损耗。

**2. 损耗包赔与售后倒扣**
- **要求**：明确“坏果/烂果怎么赔”？是直接退款、下次补货还是按比例扣除货款？
- **关键点**：团购销售的是熟人社群的信任，一旦有顾客投诉，供应商必须能**快速响应（最好24小时内）**，且赔付不扯皮。

**3. 打包耗材支持**
- **要求**：供应商是否提供定制的塑料袋、带店招的包装盒或贴纸？
- **作用**：统一包装能强化你店铺品牌，降低顾客混淆；若供应商能提供免费或低价印刷，能省下不少成本。

**4. 预售型产品支持（重点考察）**
- **需求**：小区团购适合预售（比如车厘子、海鲜等高价品），供应商是否接受**隔夜预售**？
- **要求**：能按实际预订量向产地/上级市场加工订货，而不是让你囤货。

**5. 价格阶梯与灵活调价**
- **要求**：单量达到多少有批发价折扣？
- **核心**：避免“死价”，要求供应商针对**爆款单品**（如鸡蛋、香蕉）给出团购专属价格，并允许你**在截单前1小时调整定价**应对竞争。

**6. 供应稳定性与应急备货**
- **要求**：遇到恶劣天气、节假日或某款水果突然缺货时，供应商能否提供**替代方案**（如用相似品类替换并给出成本价）？
- **建议**：尽量签2-3家供应商，避免单一依赖，但需确保各家的配送时间和包赔标准一致。

**7. 周末/节假日特殊服务**
- **重要原因**：小区团购通常在周五和周六达到高峰（因为顾客周末吃水果、做饭）。
- **要求**：确认周末是否正常发货？是否需要提前加购安全库存？**提前确认**供应商周末的配送时效是否与工作日一致。

---

**落地实操建议：**
签订合作前，先让供应商提供**一箱样品测试**，测试三个动作：
1. 下单后测算**实际到货时间**；
2. 拆箱检查**损耗率**（超过5%直接淘汰）；
3. 模拟一次售后（故意报损一个坏果），看对方处理速度和态度。

如果供应商无法满足以上任何一项，优先考虑更换。因为团购的核心是“效率+容错”，供应商出错一次，你的邻里口碑就丢了。
