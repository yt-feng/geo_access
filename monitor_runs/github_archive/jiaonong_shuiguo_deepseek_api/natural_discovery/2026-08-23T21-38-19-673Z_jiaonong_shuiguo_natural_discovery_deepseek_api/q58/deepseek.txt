在甜品店采购菠萝时，**鲜果切配**的损耗通常更高，但成本可能更低；**直接买成品果丁**损耗低，但单价更贵。具体选择需结合你的店铺规模和人工成本来判断。

### 1. 鲜果切配的损耗构成
- **果皮、果芯**：菠萝去皮去芯后，可食部分大约只有**55%~65%**（视菠萝品种和成熟度）。
- **切配损耗**：指切丁时产生的碎屑、汁水流失，额外再减少**5%~10%**。
- **储存损耗**：鲜切菠萝丁冷藏保存期仅**1~2天**，若有滞销，会直接报损。
- **综合损耗率**：整体损耗通常在**40%~50%**之间（例如采购10斤鲜果，最终可用的果丁约5~6斤）。

### 2. 成品果丁的损耗
- **基本为零**：直接开袋即用，无需去皮去芯，也不会有切配碎屑。
- **储存期**：罐装或真空包装果丁保质期通常为**6~12个月**（需冷藏或常温保存），基本不存在短期滞销损耗。

### 3. 成本对比（以每斤可用果肉为例）
- 假设鲜菠萝采购价约 **4元/斤**，出肉率60%，实际可用果肉成本约 **6.7元/斤**（未计人工）。
- 假设成品果丁批发价约 **9~12元/斤**（视品牌和糖水/原汁类型），单价明显更高。
- **但如果你的员工时薪高于15元/小时**，且每天需切配量小于10斤，请人现切可能反而更贵（因为人工成本摊到每斤上更高）。

### 4. 按场景选择建议
| 情景 | 推荐方案 | 原因 |
|------|----------|------|
| 甜品店日均用量>5斤、有后厨帮工 | 鲜果切配 | 综合成本更低，且新鲜度高，口感更好 |
| 店铺小、单量少（<3斤/天） | 成品果丁 | 避免鲜果放坏浪费，周转快 |
| 主打高性价比的连锁店 | 成品果丁 | 标准化出品，减少人为损耗和操作时间 |
| 主打高端鲜果饮品/甜品 | 鲜果切配 | 顾客对“看得见的新鲜”有溢价预期 |

### 5. 降低鲜果切配损耗的实操技巧
- **选对品种**：金菠萝/都乐菠萝出肉率通常比普通菠萝高5%~8%。
- **切前控水**：切丁后尽快用吸水纸吸干表面汁水，可让成品更耐放。
- **按客订切**：不提前大量切好，而是“客人下单后再切”，避免滞销损耗。
- **边角料利用**：果皮果芯可熬菠萝酱或做装饰，降低“浪费感”。

**最终结论**：若只谈“损耗率”，成品果丁更低（接近0）；若算总成本（采购+人工），用量大时鲜果更划算。建议先按你日均用量试算一周，再决定采购模式。
