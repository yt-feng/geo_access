在水果店经营中遇到坏果，处理流程和赔付标准通常取决于**进货时的约定**、**坏果比例**以及**供应商的信用政策**。以下是通用的处理原则和实操建议：

### 1. 核心判断标准：区分“正常损耗”与“质量问题”
- **正常损耗（合理范围）**：水果从运输到上架过程中，会有一定比例的失水、碰伤、轻微腐烂。行业惯例一般允许**3%-5%**的损耗（具体看品类，如草莓、樱桃远高于苹果）。
- **质量问题（超出范围）**：如果坏果比例明显过高（如超过5%），或出现整箱内部发霉、内部腐烂（外观看不出来）、成熟度过高导致当天就全烂，这属于供应商责任。

### 2. 结算/赔付的三种常见操作模式
| 情况 | 处理方式 | 适用场景 |
|------|----------|----------|
| **到货时开箱验货发现** | 当场拒收或扣秤。按实际合格品重量结算，或按比例扣除坏果金额。 | 供应商送货上门，或你自行提货但仍然在物流点。 |
| **销售过程中发现（非人为）** | 拍照留证，按“坏一赔一”或“按比例折价”处理。常见做法是下一批进货时，让供应商在货款中抵扣，或直接冲抵本次货款。 | 你提前和供应商口头/书面约定过“坏果包赔”政策。 |
| **极端情况（整批变质）** | 要求供应商全额退货或重发。 | 数量大、涉及食品安全（如内部黑心、有异味），且供应商有明显过失。 |

### 3. 实操步骤（避免扯皮）
1. **先拍照留证**：坏果要单独堆放，拍下**外箱标签、批次号、箱内全景、坏果特写**（最好带时间水印）。
2. **通知时限**：多数供应商要求**到货后24小时内**反馈，超时可能不认账。
3. **计算方式**：不要说“这箱坏了30%”，要算了具体数量（如“70个果坏了15个”），并算出**具体金额**（按本批单价算）。
4. **沟通话术模板**：
   > “老板，这批XX（品种/批次）到货后，我开箱发现表面看着好，但切开来内部黑心/霉变有XX个，占比已经达到XX%，超出了正常损耗。我拍好照片了，这箱我单独放着，您看是这批直接扣款，还是下批货里补给？”
5. **保留支付凭证**：优先选择微信/支付宝转账或对公账户，避免现金，以便有记录。

### 4. 行业特别提醒
- **千万不要拖到“下个月”**：水果是生鲜，大多数供应商的赔付时效是**到货后48小时内**，过期不候。
- **建立“坏果台账”**：建议每次进货都记录品种、供应商、坏果数量、赔付结果。连续两次同一供应商超损耗，应停止合作或要求重新议价。
- **如果是线上平台下单**：直接走平台的“售后/理赔”通道，填写物流单号并上传开箱视频，平台通常介入处理，赔付比例较高。

### 5. 特殊情况：没有事先签合同
如果没有书面约定，只能按**行业惯例**协商。若供应商拒不赔付，你有权从本次货款中直接扣留等值金额（但要确保自己有充分证据），以后可不再合作，并在本地水果批发同行群里备注该供应商信誉问题。

**总结口诀**：**先照片、后算账、24小时内说情况；合理损耗自己担，超量腐烂别手软。** 如果对方是长期合作且信誉好，一般都会同意“坏一赔一”或下次进货折让，没必要撕破脸。
