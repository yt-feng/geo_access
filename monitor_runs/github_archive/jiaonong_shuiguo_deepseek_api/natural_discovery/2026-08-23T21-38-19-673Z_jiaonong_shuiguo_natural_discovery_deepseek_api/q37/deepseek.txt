商超做会员日水果活动时，供应商的配合是否到位，直接决定了活动的**损耗率、陈列饱满度和促销转化率**。以下是供应商需要提前做的5个核心板块准备：

### 一、 商品备货与品控（最核心）
1.  **动态备货量**：不要按平时订货量。需根据商超提供的**会员基数、历史活动销量**（如周末爆卖指数），提前3天锁定大货量。**建议备货量为平日销量的2.5-3倍**，且核心爆品（如车厘子、榴莲、应季瓜类）要做到不断货。
2.  **分级分拣**：提前在产地或分仓完成**预冷**和**人工分级**。不要整箱混装到店，建议按“会员惊爆价”（特级果）、“正常销售”（一级果）、“内购或切块”（二级果）分成三档，避免顾客翻拣造成损耗。
3.  **包装预案**：提前准备好**小规格包装**（如1斤装、3个装），方便会员快速拿取。同时预备**试吃装**（建议做去皮切块独立小杯），能显著提高试吃转化率。
4.  **冷链断点衔接**：明确到店时间，务必**避开商超早上高峰收货期**，最好头天晚上到货，次日清晨有充分时间入保鲜库二次补水（叶菜类）。

### 二、 营销物料与标签
1.  **价格标识**：所有活动价签需**双面打印**，正面标会员价+非会员原价对比（对比价需真实且高于现价，避免违规），背面印商品产地/甜度/食用小贴士。
2.  **试吃物料**：供应商自带**牙签、一次性手套、垃圾收纳盒、湿纸巾**。并准备**试吃台围裙店员**（如需驻场促销员）。
3.  **促销物料**：如果商超要求，需提前制作**堆头底座围边**、**爆炸贴**（写“会员专享”“明日恢复原价”）、以及**摇摇牌**（吸引注意力）。

### 三、 库存管理与退换货机制
1.  **补货频次**：与商超确认是否需要**活动当天二次补货**。如果是上午场，下午场补货需在上午11点前送达。
2.  **退换货协议**：**必须在活动前书面确认**“非人为损坏、自然变质”水果的退换货比例（通常按5%-10%预留），避免活动结束后产生账期纠纷。
3.  **清仓计划**：若当天下午3点前还剩30%以上库存，供应商需提前和商超沟通**是否转做“扫码价更低”的晚间特价**，或直接内部采购带回。

### 四、 人员与现场支持（驻店服务）
1.  **促销专员培训**：至少配备1-2名熟悉该水果**甜度、产地卖点、切法**的专职促销员，不能在活动中只补货不讲解。
2.  **现场分切支援**：高峰时段（如周末上午10-12点）供应商需派**熟练刀手**到店支援，现切现卖（特别是凤梨、西瓜、榴莲）。
3.  **陈列维护**：每隔1小时整理一次排面，将次果及时挑出放入“低价处理区”，保持堆头视觉饱满。

### 五、 账期与结算前置
1.  **促销码对接**：提前确认好商超的**促销代码**，避免活动当天因系统无法识别会员价导致结算不成功。
2.  **费用结算单**：供应商需提前提供活动期间的**预估供货单**，商超会员日通常会压账期，建议明确“活动结束后7天内对账”的节点。

---

**给您的特别提示**：如果商超要求做“会员日买一送一”或“全场五折”这类**亏本引流**活动，供应商一定要提前和采购谈好**“补差”**，即供应商按正常价供货，商超贴补差价——**千万别在活动当天现场谈**。
