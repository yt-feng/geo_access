在茶饮店经营中，水果到货不合格是常见但棘手的供应链问题。要确保**不影响营业**，核心在于**“事前约定”**和**“快速响应机制”**。以下是具体的操作建议，你可以直接用于和供应商谈判或修订采购合同：

### 1. 明确“不合格”的判定标准（避免扯皮）
在合同或采购单中，**不要只写“新鲜”或“合格”**，要量化标准：
- **外观标准**：注明允许的瑕疵比例（如：表皮破损面积不超过X%，斑点不超过X处），并明确“不能使用”的情形（如：软烂、发霉、果肉褐变）。
- **成熟度**：约定“到达门店时”的成熟度等级（例如：牛油果到达时达7-8成熟，可存放2-3天）。
- **重量/规格**：明确单果克重范围（例如：青柠单果不低于50g），避免收到小果。

### 2. 约定“补货”的**硬性时效**（保证营业）
这是最关键的一点，建议在协议中写清楚：
- **超时免费补货**：如果到货不合格（如：整箱腐烂超过10%），供应商需在**接到通知后2-4小时内**免费补发同规格水果。若无法在当日内补到，需**全额退款或冲抵下次货款**。
- **运费承担**：因质量问题产生的补货，**运费由供应商承担**，且不能因补货数量少而加收配送费。

### 3. 建立“先补后检”的快速通道（避免停售）
- **拍照留证，即时电话沟通**：签收时不纠结于拒收，而是**立即签收但保留原包装**拍照，同时电话通知供应商“缺货补货”。
- **在合同中约定“应急采购权”**：如果供应商不能在约定时间内补货，门店有权**自行在本地市场采购**，差价由原供应商承担。这是倒逼供应商快速响应的最有效条款。

### 4. 针对不同水果的“补货阶梯”（应对不同情况）
你可以和供应商约定分级处理方式：
- **整箱不可用**（如腐败）：免费补足**同规格**新货。
- **部分不良**（如10%挤压）：只补不良部分的**1.5倍重量**（补偿挑拣损耗及切配废料）。
- **轻微瑕疵**（可做果切但不影响饮品风味）：按比例**折价结算**（如打8折），不要求补货，减少物流时间。

### 5. 应对“断档期”的备用方案（兜底策略）
即使有补货约定，脱销期间也可能影响营业额。建议**同时**和1-2家备选供应商建立“应急供货协议”，并约定备选供应商的送货时效。在与主供应商的合同中，可以加入“若因供货中断导致门店营业额损失，按预估日均销售额的X%进行赔偿”的条款，这能极大提升供应商的补货优先级。

**给您的建议话术（可直接使用）：**
> “王老板，咱们合同里这次的补货条款得改一下，为了保证我店里不断货，咱们约定：**如果这批货有烂果率超过10%或者规格不符，您这边**最晚在3小时内**给我安排同城补货，运费您出。如果当天补不上，我从隔壁市场现采的差价您得报销。这样咱俩合作省心，我也能放心主推您的果子。”

**补充提醒**：在合同中务必加上**“质量保证金”**条款（比如扣押10%货款作为质保金），一旦出现拖延补货影响营业，直接从质保金中扣除延误赔偿。这比口头承诺更有约束力。
