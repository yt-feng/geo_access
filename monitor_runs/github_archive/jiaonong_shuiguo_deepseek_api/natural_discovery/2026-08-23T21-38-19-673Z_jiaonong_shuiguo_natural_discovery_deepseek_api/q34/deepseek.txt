商超采购水果时，**损耗率通常比采购价格对最终毛利的影响更大**，尤其是在生鲜品类中。

具体原因和逻辑如下：

**1. 损耗是“乘数效应”，价格是“基数效应”**
*   **采购价**：只影响进货成本（基数）。
*   **损耗**：直接影响可售数量（销量），进而影响销售额和毛利额。
*   公式：**毛利额 = （售价 - 进价） × 可售数量**。损耗直接减少“可售数量”。

**2. 数学逻辑对比（用数字说明）**
假设：
*   采购价10元/斤，售价15元/斤。
*   进货100斤。

**场景A：采购价低2元（即8元/斤），但损耗高（损耗20%）**
*   进价成本 = 8元 × 100斤 = 800元。
*   可售重量 = 100斤 × (1-20%) = 80斤。
*   销售额 = 15元 × 80斤 = 1200元。
*   毛利额 = 1200 - 800 = 400元。

**场景B：采购价高2元（即12元/斤），但损耗低（损耗5%）**
*   进价成本 = 12元 × 100斤 = 1200元。
*   可售重量 = 100斤 × (1-5%) = 95斤。
*   销售额 = 15元 × 95斤 = 1425元。
*   毛利额 = 1425 - 1200 = 225元。

在这个例子中，**场景A（低进价+高损耗）的毛利反而更高**。这说明了“损耗”在毛利中的权重。

**3. 但现实更复杂：损耗是“可控”的，价格是“波动”的**
*   **损耗的可控性**：损耗可以通过精细化运营（如冷链、分拣、上架时机、促销策略）来降低，是**管理能力**的体现。
*   **价格的波动性**：采购价受市场行情影响大，有时不得不高价进。

**结论：**

*   **如果必须二选一，优先控制损耗**，因为它直接影响可售数量和销售额，且能通过管理弥补。
*   **但最优策略是“综合成本核算”**：不能只看单价，要看**“每斤可售果实的综合成本”** = （采购价 × 进货量） ÷ （进货量 × 预估可售率）。选这个值最低的采购方案。

**实操建议：**
1.  **建立损耗率台账**：对不同品种水果记录实际损耗，数据说话。
2.  **采购时评估品质**：价格低但成熟度过高、表皮损伤多的水果，损耗往往巨大。
3.  **动态定价**：对高损耗高风险水果，设定较高的加价率；对耐储存水果，可以基于价格优势竞争。

**一句话总结：** 采购时，**先看损耗风险，再看价格**。如果一款水果的损耗率预估超过10%，而另一款价格高5%但损耗率能压在3%以内，后者往往更赚钱。
