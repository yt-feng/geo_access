针对家庭团购水果礼盒，**建议以“耐放+百搭+老少皆宜”为原则**，结合四种水果的特性做组合：

**推荐组合（6-8斤装，约4-6人家庭）：**

- **苹果（2-3个）**：首选红富士，脆甜、耐储存，家庭常备。
- **橙子（3-4个）**：首选脐橙或赣南橙，维C高，酸甜适口，小朋友接受度高。
- **香蕉（1把，约5-6根）**：注意选**稍微带青**的，不要全熟，否则到家2天就烂。香蕉是家庭消耗最快的，适合混搭。
- **菠萝（半个或1个，视大小）**：菠萝偏酸且需处理，**建议作为“调剂品”**，放半个即可，或者换成“凤梨”（更甜无刺）。

**搭配逻辑：**
- 苹果、橙子耐放，撑得起礼盒“颜值”和重量。
- 香蕉软糯，适合老人小孩，但极易坏，少量配。
- 菠萝是“季节限定”，有新鲜感，但酸，不适合作为主力，放少量或标注“温馨提示：菠萝偏酸，喜甜可蘸盐水”。

**团购注意事项（建议发给团友）：**
1. 菠萝建议**削皮或切块密封**，避免家庭处理麻烦。
2. 香蕉和菠萝**不要放同一层**，香蕉会加速熟化（乙烯催熟）。
3. 定价建议：比超市散买便宜10%-15%，否则团购没吸引力。
4. 若预算有限，可将菠萝换成“雪梨”或“火龙果”，更稳妥。

**备选方案（若需要更高端或更耐放）：**
- 苹果+橙子+奇异果（耐放）+香蕉（少量）
- 苹果+橙子+葡萄（当季）+香蕉

**一句话结论：** 家庭团购礼盒选 **“苹果2+橙子3+香蕉1把+菠萝半个”**，最平衡，成本可控。如果菠萝不便宜，就直接换掉。
