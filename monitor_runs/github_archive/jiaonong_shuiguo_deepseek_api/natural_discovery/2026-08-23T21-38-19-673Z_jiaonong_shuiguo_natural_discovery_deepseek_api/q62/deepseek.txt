判断一批香蕉的熟度和坏果风险，是水果批发商控制损耗的关键。以下是基于实操经验的建议，分为**现场看**、**上手摸**和**后续管理**三个层面：

### 一、 现场判断熟度（核心指标）

香蕉的熟度直接决定销售窗口期。

1.  **看颜色（最直观）**：
    *   **全青（绿皮）**：熟度约1-2成。适合长途运输或冷库储存，但上市销售需等3-5天（自然催熟），不宜直接上架零售。
    *   **绿中带黄（黄绿相间，但黄少）**：熟度约3-4成。适合今天到货、明后天销售的商户。
    *   **大面积黄、果柄仍带绿**：熟度约5-6成。**这是最适合批发零售的黄金熟度**，今天拿货，明天即可全熟销售，货架期约2-3天。
    *   **全黄、果柄干枯**：熟度约7-8成。必须当天卖完，否则隔天必烂，风险极高。
    *   **出现黑点（芝麻点）**：熟度9成以上。除非已谈好低价特卖，否则不建议批发商在此阶段整批吃进。

2.  **看硬度（用手轻握）**：
    *   捏果实中部，**手感紧实、有弹性**，是标准熟度。
    *   如果捏起来**发软、没有回弹**，说明内部已经过熟，果肉可能已经开始发酵，风险大。
    *   如果捏起来**像石头一样硬**，虽然耐放，但催熟周期长，资金占用大。

3.  **看果柄切面**：
    *   新鲜的果柄切口呈**湿润、乳白色**。
    *   如果切面**发黑、干瘪、出水**，说明这串蕉在树上或运输中已受损，极易感染炭疽病（表现为长黑斑）。

### 二、 坏果风险排查（重点看“暗伤”）

香蕉最怕**机械伤**和**低温伤**，这两种伤表面看不出，但会迅速传染。

1.  **翻堆抽查（必做动作）**：
    *   不能只看表面那一层。一定要随机抽2-3箱，**从底层和中间翻出来看**。
    *   重点看**果指与果指之间、果指与果柄接触处**。这些地方是挤压伤的重灾区，如果发现发黑、流水或发霉，那整箱的传染风险极高。

2.  **检查“碰伤”与“冻伤”**：
    *   **碰伤**：表皮凹陷、按压发软，但颜色还是黄的。这种伤口会迅速氧化变黑。
    *   **冻伤**：表皮颜色**青灰发暗（无光泽）**，或者手指揉搓表皮能轻易搓掉皮（说明细胞已坏死）。冻伤的香蕉放几天会直接变黑水烂，必须拒收或压价。

3.  **闻气味（关键但常被忽略）**：
    *   凑近箱内的一串香蕉，若闻到**强烈的酒精味（发酵味）**，说明内部已经有大量碰伤或过熟，正在发酵，这批货今天必须清仓。
    *   若有**酸腐味**，说明箱内已有烂果，正在污染整箱。

### 三、 降低风险的实操策略

1.  **不要贪图“全绿”低价货**：除非你自有催熟库，否则全绿蕉在夏季（高温）风险极大，夏季温差小，全绿蕉在零售端很难自然转黄，容易闷坏。
2.  **根据销售速度定熟度**：
    *   如果你走量快（一天能卖完一挂），拿7-8成熟。
    *   如果你卖货慢，只拿5成左右的，给自己留出3天缓冲期。
3.  **抽检比例建议**：300箱以内的货，至少抽5箱；大批量必须抽10箱以上。
4.  **判断“黄”是否人为**：有些商户会用药水催熟（乙烯利），这种香蕉颜色均匀、成熟快，但果肉软糯无香气。判断方法：闻果皮，自然熟的清香，药水催的有化学味；且药水蕉的果柄常呈现不自然的鲜绿色。

**最终建议**：在批发市场，如果整批货的**颜色超过80%为全黄**，直接放弃；如果抽检时发现**箱内有2根以上流水烂果**，要么巨大折扣，要么直接拒绝，千万不要赌“漏网之鱼”，烂果传染极快（一烂烂一串）。
