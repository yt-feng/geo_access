选水果供应商时，**配送、售后、价格三个都要问，但优先级和问法有讲究**。

如果只能排出先后顺序，我建议：**先问配送（时效和损耗）→ 再问售后（标准和流程）→ 最后谈价格（付款和账期）**。

具体原因和关键问题拆解如下：

---

### 第一优先：配送（决定你的货能不能卖、损耗多大）
水果是生鲜，损耗是利润最大的杀手。配送环节直接决定你拿到手的是“能卖的好果”还是“一堆烂果”。

**必问的问题：**
1. **时效**：“今天下单，最晚什么时候能送到？如果是爆单日，能否承诺不超过24小时？”
2. **冷链标准**：“全程冷链还是普通常温车？夏季高温天和雨天分别怎么处理？”
3. **到货损耗**：“如果到货时烂果超过5%（或10%）怎么算？是当场剔除还是补重？”
4. **分拣标准**：“大小、甜度、外观有分级吗？我要求的分级标准，你能否保证？”

**判断点：** 如果供应商支支吾吾或者只说“没问题”却给不出书面保证，那他的配送体系可能很脆弱。好的供应商会主动告诉你他们的分拣合格率和到货损耗率。

---

### 第二优先：售后（决定你的纠纷成本）
售后差，一单亏五单。问售后，本质上是在问对方“出了问题愿不愿意认账”。

**必问的问题：**
1. **售后标准**：“坏果、小果、不甜（如适用）的赔付标准是什么？是按个数赔还是按重量折价？”
2. **赔付时效**：“拍照反馈后，多久能出处理结果？是直接退款还是下次抵扣？”
3. **责任界定**：“运输中压扁的、到货后才熟过头的、客户放几天才反馈的，这些情况你分别认不认？”
4. **对接人**：“售后找谁？是专人专员还是我直接找业务员？电话/微信是否随时能通？”

**判断点：** 敢直接把售后标准写进合同或微信白纸黑字发给你的，才靠谱。口头说“放心，有问题找我”的，大概率售后扯皮。

---

### 第三优先：价格（但要问“聪明”的价格）
价格不是不能问，而是不能只问“多少钱一斤”。你要问的是**综合成本**。

**必问的问题：**
1. **价格构成**：“这个价是含税含运费价吗？有没有最低起送量？配送费单独收吗？”
2. **价格波动**：“如果产地收购价波动，你们的调价机制是什么？一周内调几次？会不会突然涨价不给通知？”
3. **账期**：“支持先货后款还是现结？有账期支持吗？账期多长？”
4. **对比韧性**：“如果我要的量很大（或很小），你们的价格弹性有多大？比如一次性拿50箱和拿20箱，差多少？”

**判断点：** 报价特别低的供应商，一定要警惕——水果行业“低价”往往意味着“以次充好”或者“售后不认”。你真正要谈的是“到手总成本/可出售果重”，而不是“批发单价”。

---

### 总结建议（供你实际操作）
1. **哪怕供应商再熟，也要把配送时效、售后赔付标准、价格含税含运费**这三条用文字确认下来，截图存档。
2. **第一次合作时先小批量试单**，故意挑到货高峰或雨天测一次配送和售后，比签大合同再试错划算十倍。
3. 谈判时，如果对方三个条件里愿意主动给足两个（比如配送稳、售后爽快），价格高一点也完全值得——你省下的坏果和扯皮时间，远大于那点差价。

**一句话结论：** 先谈配送保品质，再谈售后担责任，最后谈价格控成本，三者缺一不可，但别被单一价格牵着走。
