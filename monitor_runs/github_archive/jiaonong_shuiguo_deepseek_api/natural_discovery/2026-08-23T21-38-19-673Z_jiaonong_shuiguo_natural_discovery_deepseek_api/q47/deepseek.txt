针对茶饮店/甜品店采购香蕉的需求，这里提供一个**可落地的采购标准与验收清单**，重点解决“熟度控制”问题。

---

### 一、核心原则：熟度 = 用途 + 到店时间

茶饮店香蕉通常有三种用途，熟度要求完全不同：

| 用途 | 最佳熟度（外皮） | 果肉状态 |
|------|----------------|----------|
| **打奶昔/冰沙/烘焙馅** | 全熟/熟透（大面积黑斑但果肉不烂） | 软糯，甜度高，易压泥 |
| **做装饰/果切/搭配酸奶杯** | 半熟偏黄（皮黄但光滑无斑） | 硬挺，不易氧化变黑 |
| **储备/短期周转（1-3天）** | 7分熟（皮微黄带绿） | 较硬，能自然成熟 |

---

### 二、采购时的“5步验收法”

**1. 看颜色（最直观）**
- 全绿 = 生，需5-7天催熟，**不适合日常采购**（除非有冷库）。
- 黄中带绿 = 7分熟，适合采购后存2-3天再用。
- 全黄无斑 = 9分熟，立即可用，但只能放1天。
- 全黄带黑斑 = 熟透，只能当天用，**不建议预存**。

**2. 摸手感（判断内部）**
- 轻捏果柄与果顶，**软塌但有弹性** → 熟度合适。
- 捏起来硬如石头 → 太生，果肉发涩。
- 捏起来软烂且渗汁 → 过熟，易发酸发酵。

**3. 闻气味**
- 有浓郁香蕉香 → 恰熟。
- 无香 → 未熟。
- 有酒精味/酸味 → 已发酵，**直接拒收**。

**4. 掐蒂头（判断新鲜度）**
- 果柄断裂处颜色鲜绿、湿润 → 新鲜。
- 果柄干枯发黑 → 已存放多日，寿命短。

**5. 试重量**
- 同样大小，**越轻越熟**（水分流失多）。拿两只对比，重量差异大的可能熟度不均。

---

### 三、采购策略建议（防止损耗）

**1. 错峰采购（强烈推荐）**
- 例：周日采购一批黄绿的（3天后用），周二补一批全黄的（当天/隔天用），形成“梯次熟度”。
- 避免一次买全部熟透的，用不完全烂。

**2. 分拣上架**
- 到货后立即分两筐：
  - A筐：偏生的（放常温，不能进冰箱）。
  - B筐：偏熟的（放**冷藏区**，但不要低于12℃，否则果皮变黑但果肉不熟）。

**3. 急用时可“烤催熟”**
- 若急需熟透用于打泥，可将黄绿香蕉带皮放入烤箱 150℃ / 5分钟，果肉立刻软糯甜度提高（注意别烤爆皮）。

**4. 进货量公式（行业参考）**
- 日常消耗量 × 采购周期天数 + 20%安全余量。
- 比如日消耗5把（约5根/把），3天采购一次 → (5×3) + 3 = 18把。

---

### 四、特别注意（易被忽略的坑）

- **别买“催熟剂”香蕉**：部分批发市场会用乙烯利催熟，外皮很黄但果肉白硬、不甜。验收时**切开一根试吃**，果肉发白、无香味的果断退货。
- **冷藏禁忌**：香蕉不能放0℃以下，表皮会立刻变黑，严重影响甜品颜值。
- **成熟度不一致的处理**：草莓香蕉挞等颜值要求高的，**装饰果切必须用半熟**；奶昔/冰淇淋则可用全熟，两者分开采购更划算。
