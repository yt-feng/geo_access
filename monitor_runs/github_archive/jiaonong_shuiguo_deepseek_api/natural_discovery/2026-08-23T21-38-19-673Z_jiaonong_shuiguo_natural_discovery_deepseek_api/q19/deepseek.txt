选购超市菠萝时，**没有单一答案**，需要根据你的定位（是超市采购、档口零售，还是社区团购）综合权衡。以下是分场景的优先级排序和实操建议：

---

### 1. **核心矛盾：甜度 vs 大小**
- **甜度（可溶性固形物）**：这是复购率和口碑的**生命线**。菠萝如果偏酸，顾客大概率不会再买。  
  **判断方法**：肉眼难测，但可扒开底部叶子闻香气（越浓越甜），或用糖度计抽检（目标≥12%）。  
  **建议**：进货时可要求供应商提供糖度检测报告，或现场切开试吃。

- **大小**：影响客单价和损耗率。  
  **注意**：  
  - 大果（1.2kg以上）适合家庭/多人份，但容易因切果损耗高而拉高成本；  
  - 小果（0.8kg以下）适合单人/即食，但单价低，毛利空间小。  
  **建议**：如果是社区超市（高复购），**中果（900g-1100g）最稳妥**；如果是高端商超，可选大果做精品陈列。

---

### 2. **外观 vs 切果损耗（关键决策点）**
- **外观**：决定“能否卖得掉”。  
  - 要求：果眼平整、无黑斑、无裂口、颜色金黄均匀（偏绿未熟，偏褐过熟）。  
  - 注意：外观完美但可能内部成熟不均匀，**需批量抽检切开验证**。

- **切果损耗**：决定“赚不赚钱”。  
  菠萝带皮卖损耗约10%-15%；切果卖损耗可达25%-35%（去冠、去皮、去眼、切块）。  
  **建议**：  
  - **如果你有剥皮机或人工技术好**，可主推切果（售价高，损耗可控），重点选果形端正、果眼浅的品种（如“金钻”眼浅，“香水”眼深）。  
  - **如果人工成本高**，建议整果售卖，但需在促销时主动提供免费削皮服务，用服务带动销量，摊薄损耗。

---

### 3. **实操采购清单（按优先级排序）**
| 优先级 | 检查项 | 操作细节 |
|--------|--------|----------|
| **第一** | 成熟度 | 底部叶子掰一下——能轻松掰掉且带香气 = 熟度合适；轻轻捏果身，微软有弹性 = 最佳；发硬偏生，发软偏熟。 |
| **第二** | 糖度抽检 | 随机切1-2个，试吃中心果肉（甜度>12%才可验收）。 |
| **第三** | 外观瑕疵 | 拒绝黑心、裂果、发霉（尤其果眼处）。 |
| **第四** | 大小分布 | 要求供应商提供**均匀中果**，避免大小差异过大（影响定价和陈列）。 |
| **第五** | 损耗预估 | 要求供应商担责：到货时若有5%以上严重损伤，需补偿或换货。 |

---

### 4. **风险提示（很重要）**
- **切勿只看外观**：外表好看的菠萝可能内部白芯、酸涩（特别是早期果）。  
- **催熟陷阱**：供应商用乙烯催熟的菠萝，表面黄但无香气、糖度低，尽量选“树上熟”或自然熟的产地（如海南、广西）。  
- **季节因素**：3-5月是菠萝季，此时甜度普遍高；反季节进货需谨慎。

---

**最终结论**：  
若你追求**稳定复购** → 优先**甜度**（通过试吃报数据），其次**中果大小**，外观和损耗靠进货时的抽检和合同约定来控制。  
若你追求**高毛利** → 优先**切果损耗管理**（选浅眼品种+技术好的工人），此时外观重要，但甜度仍不能低于及格线。  

建议第一周先小批量进两三个品种（如金钻+普通台农），对比试吃和损耗，用数据决定后续主力。
