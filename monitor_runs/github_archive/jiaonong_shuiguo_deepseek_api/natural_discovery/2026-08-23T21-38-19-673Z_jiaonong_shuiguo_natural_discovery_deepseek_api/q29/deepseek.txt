在超市与水果供应商的谈判中，**账期（付款周期）通常在15天到60天之间，最常见的是30天或45天**。具体情况会受以下因素影响：

**最常见的区间参考：**
- **中小型超市/生鲜店**：通常15~30天，因为生鲜损耗大、资金回笼快，供应商为了走量会接受较短账期。
- **大型连锁超市/商超系统**：一般30~60天，部分巨头（如大型全国性连锁）可能谈到60~90天，但对供应商的供货稳定性和规模要求极高。
- **特色精品水果或进口水果供应商**：账期通常较短（7~15天），因为单价高、保质期短，供应商更看重现金周转。

**影响账期的关键变量：**
1. **水果品类**：易腐水果（草莓、荔枝、叶菜类）账期普遍短；耐储水果（苹果、橙子、梨）账期可适度拉长。
2. **超市规模和采购量**：采购量越大，账期议价空间越高。
3. **供应商实力**：源头基地直供或大经销商往往能接受较长账期；二三级经销贩子通常要求现结或短账期。
4. **合作模式**：代销（卖完结算）账期较短；买断经销（进库后付款）账期可更长。

**给你的建议：**
- 如果你是**中型超市**，从30天谈起比较稳妥，若想拉长到45天，最好承诺提高采购量或预付部分定金。
- 如果是**新开的小型门店**，建议先谈15~20天，否则供应商很可能要求现金现结或提高价格。
- 务必在合同中写明**到货验收、退货条件和逾期付款的违约金**，避免因损耗纠纷拖累账期执行。
