节假日水果需求暴增时，连锁超市要提前锁定货源，不能只靠“临时打电话”，需要系统化操作。以下是具体、可执行的分层建议：

---

**一、提前2-3个月：签订“保量保价”框架协议**
- **锁定核心单品**：根据往年节假日销量数据，筛选出前20%的爆款水果（如车厘子、草莓、砂糖橘、西瓜等）。
- **签订阶梯价格协议**：与长期合作的基地或一级批发商约定“保底采购量+浮动价格上限”，明确若市场涨价，供货价允许上浮但不超过合同价的10%-15%；若跌价，则按市场价执行，确保对方有供应动力。
- **支付定金/预付款**：对独家或有稀缺性的货源（如进口车厘子），支付10%-20%的定金换取优先供货权，并注明“违约三倍赔偿”条款。

**二、提前1个月：建立多级备选供应商库**
- **核心供应商（占70%货源）**：当地最大一级批发市场或直采基地。
- **次级供应商（占20%）**：周边省份农场、合作社，用于补缺。
- **应急供应商（占10%）**：全国性电商平台（如拼多多、美团优选批发端）或冷链物流公司代采，确保偏远地区也能发货。
- **关键动作**：每周与核心供应商沟通一次库存和天气影响，判断是否需要调整采购量。

**三、提前1-2周：锁定物流与仓储能力**
- **预订冷链车**：节假日物流紧张，提前锁定至少3家冷链运输公司的固定车辆排期，签订“日配送保底趟次”合同。
- **提前租赁周转仓库**：若门店冷库容积不足，提前租赁附近冷库，并按“多频次、小批量”原则配送，避免积压损耗。
- **明确到货时间节点**：要求供应商在节前第3天、节前第1天、节日当天分别安排到货，避免集中到货造成拥堵。

**四、预售与锁客联动（内部应战）**
- **推行“预售订单”**：在节假日启动前10天，通过超市APP/小程序开启爆款水果预售，用户付定金享优惠。根据预售量倒推采购量（预售量×1.2保底系数），并同步把订单数据发给供应商，锁定对应货量。
- **设置“不可退定金”承诺**：对供应商发出“已预售数量”作为约束，要求其必须满足该数字。

**五、防风险：建立“毁约应对预案”**
- **与至少2家替代供应商保持随时可联系**：一旦核心供应商临时缺货，立即启动“同类产品替代”（例如用赣南脐橙替代进口橙子）。
- **提前准备“临时换品”名单**：假设某水果断供，主推同价位、同品类的替代品，并提前做好海报/货架陈列方案，避免现场慌乱。

---

**最终执行清单（建议做成表格）**：

| 时间节点 | 动作 | 输出物 |
|---------|------|-------|
| T-60天 | 签框架协议、付定金 | 供应合同 |
| T-30天 | 建三级供应商库、每周会商 | 供应商名录 |
| T-15天 | 预订冷链车、租赁周转仓 | 物流排期表 |
| T-10天 | 启动预售、锁定预售量 | 预售订单汇总 |
| T-5天 | 与供应商核对最终下单量 | 采购确认单 |

**一句话提醒**：节假日锁货的核心不是“买得多”，而是“契约早、渠道广、物流稳、预售通”，四者缺一不可。
