批发商与水果供应商的**首次合作试单**，是整个供应链关系中最关键的一步。试单的核心目的不是**赚钱**，而是**验货、验人、验流程**。

建议你按照以下**四步闭环**来设计试单方案，既能控制风险，又能测试供应商的真实水平。

### 第一步：明确试单目标与SKU（选品策略）
首次试单不要贪多，也不要只选最贵的或最便宜的。

1.  **2-3个SKU为宜**：选择1个**走量款**（大众水果，如苹果、橙子），1个**利润款**（中高端，如阳光玫瑰、车厘子或进口牛油果），1个**易损耗款**（如草莓、水蜜桃）来测试对方的包装和冷链能力。
2.  **明确规格标准**：在合同/订单中写死**克重范围**（如单果重200-250g）、**甜度下限**、**瑕疵率**（如允许≤5%的轻微擦伤）以及**包装标准**（如5层瓦楞纸箱，带防震棉）。

### 第二步：试单量设定与风险控制
作为批发商，你的承担能力是首位的。

-   **数量设定**：建议**不超过你正常日销量的1.5倍**，或者控制在**最保守货件的15-20%**。比如你平时一天走500箱，试单就订80-100箱，控制在1-2天内销完的量，避免滞留。
-   **定金与尾款**：**坚决不做100%预付**。建议采用 **30%定金 + 70%验货后付** 的模式。如果供应商要求全款，**直接淘汰**，这大概率是处理库存或者没有实力的中间商。
-   **明确补损条款**：合同里必须写明**缺斤短两怎么赔（通常按3倍货值补偿）、到货伤果率超过X%怎么处理（拒收或折算）**。

### 第三步：物流与验收测试（重点） 
水果的关键在于**新鲜度**，试单的重点必须放在物流环节。

-   **指定物流与时效**：要求对方使用**固定班次冷链车**（比如顺丰冷运或特定冷链专线），并明确约定**发货至到货的时效（如48小时内）**。到货时间必须在**凌晨**（水果批发市场多在凌晨交易），这能测试对方能否配合你的营业时间。
-   **开箱质检（3方见证）**：到货时，**务必在卸货现场**与司机、供应商代表（或视频连线）共同开箱。
    -   **测中心温度**：用手探温度计测果心温度，应低于X度（不同水果不同）。
    -   **随机拆箱**：随机抽3-5箱，查看箱内是否有“外好内差”的情况（俗称“盖面”）。
    -   **称重复秤**：测试净重是否含水含箱（减去包装箱的重量才是水果实际重量）。

### 第四步：小步快跑与复盘评价
试单结束后，建立一份**《供应商试单评估表》**，打分决定是否转正。

| 评估维度 | 核心指标 | 得分（1-5分） |
| :--- | :--- | :--- |
| **品质稳定性** | 大小均匀度、糖度报告、瑕疵率是否符合合同要求 | |
| **履约能力** | 发货时效是否准时？断货风险期是否如实告知？ | |
| **服务态度** | 出现损耗后，赔付流程是否痛快？是否推诿扯皮？ | |
| **毛利空间** | 结算价格+损耗后，你的毛利是否能覆盖人工和摊位费？ | |

**特别提醒（避坑指南）：**

-   **看“货”不看“价”**：第一次对方报价低，往往意味着货差。试单时如果发现价格明显低于市场价3天前的行情，要警惕是**尾货清仓**。
-   **要求提供产地证明**：必须要求对方提供**农药残留检测报告**（最好是一县一检的合格证），现在终端商场查得很严，没证被查到会直接罚死你。

---

**执行建议**：你可以在下周联系2-3家候选供应商，发去一份**《试单采购询价函》**，注明“首单小批量试销，请报最惠价格及补损细则”，看谁回复最快、条款最清晰，谁就值得合作。试单金额建议控制在**总流动资金的10%以内**。
