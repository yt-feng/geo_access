社区超市卖小包装香蕉，是个好思路，能提升客单价、减少顾客挑拣损耗。但采购时如果只看价格，容易踩坑。以下是几个核心注意点，分为**包装端**和**损耗端**，供你参考：

---

### 一、包装端：直接影响购买欲和保鲜

1. **包装规格要“小”而“准”**
   - 建议每包 **2-3根**（约400-600克），适合一人食或小家庭。4根以上容易让顾客觉得“吃不完”。
   - 不要混装大小差异过大的香蕉，否则顾客会觉得是在“卖处理品”。

2. **包装材质要透气**
   - **绝对不能全封闭塑料袋**，香蕉是呼吸跃变型水果，密封会加速自熟和腐烂。
   - 推荐：
     - **打孔塑料袋**（孔距均匀，通风）。适合短期（1-2天）销售。
     - **保鲜膜+托盘**（托盘底部垫吸水纸）。适合高端定位，但成本略高。
     - **网套包装**（单独套网套再装袋）。防碰伤，但成本增加。

3. **包装外观要“透明”**
   - 包装需透明可见，让顾客能看清香蕉的成熟度和病斑。
   - **封口不要封死**，留个活口或用易撕贴，方便顾客取出检查（但提醒顾客“选好勿换”）。

4. **标签信息要完整**
   - 贴价签时，注明**规格（2根/包）**和**保质期（建议24小时内食用）**，降低顾客对“时间长了不新鲜”的顾虑。

---

### 二、损耗端：采购时就要避开的坑

1. **成熟度控制（最关键）**
   - 采购时别买全熟的，也别买全青的。
   - 理想采购标准：**果皮黄中带青（黄绿各半）**，捏起来稍硬但能回弹。这样到货后1-2天正好转黄，给足销售时间。
   - **拒绝采购**：果柄发黑、有酒精味、果皮出现黑斑点且软化（过熟）、果皮发灰（受冻或病害）。

2. **货损谈判与到货验收**
   - 和供应商明确：**到货损耗率**（通常允许多退少补3%-5%）。
   - 到货后立即拆箱检查：
     - **挤压伤**（黑褐压痕，易滋生霉菌）。
     - **断柄/裂果**（破损果要立即隔离，不能进包装堆）。
     - **腐烂果**（只要出现一根烂的，整箱都要检查，霉菌会传染）。

3. **分装时机与手法**
   - **不要一到货就分装**。刚到的香蕉通常是青的，分装后封在袋子里催熟不均，容易“外熟内生”。
   - 建议：让香蕉在**常温通风**的地方放1天，等颜色转为“黄多绿少”时再分装。
   - 分装时**轻拿轻放**，捏住果柄，千万别摘断果柄（断柄处1天就会发黑）。

4. **销售中的损耗控制（采购后也要管）**
   - **少进勤补**：每天分装量控制在预计销量的1.2倍以内。
   - **分层陈列**：货架上层放“刚熟、硬挺”的，下层放“全熟、偏软”的，用价签区分（如“今日特惠熟”，甚至打折），避免熟透的全部报废。

---

### 三、采购清单（给你一个快速核对表）

| 检查项 | 标准 |
|--------|------|
| 颜色 | 黄中带绿，绿不超过1/3 |
| 硬度 | 指压有弹性，不软塌 |
| 果柄 | 完整无断裂，不渗液 |
| 果皮 | 无黑斑、无软烂、无霉点 |
| 气味 | 无酒精味、无异味 |
| 包装袋 | 打孔透气，透明可视 |
| 标签 | 明确规格、建议食用期 |

---

### 一个额外提醒
社区超市卖小包装香蕉，**“熟度分档”** 比“统一包装”更赚钱。建议你采购时直接跟供应商说：“给我一箱青一点的（放2天再卖），一箱黄一点的（当天卖）。”这样每天都有新鲜货，损耗能再降20%以上。
