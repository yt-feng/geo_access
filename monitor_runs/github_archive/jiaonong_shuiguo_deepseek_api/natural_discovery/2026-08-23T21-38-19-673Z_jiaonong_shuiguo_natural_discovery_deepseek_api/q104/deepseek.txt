单位采购水果时，如果发现到货品质不一致（如大小不均、新鲜度不一、部分腐烂或磕碰等），建议按以下流程进行**验收**和**售后**，确保流程合规、责任清晰：

---

### 一、验收阶段（到货后立即进行）

1. **当场清点与开箱抽检**  
   - 不要直接签字收货。先核对外包装数量、重量与采购单是否一致。  
   - 按箱/筐进行随机开箱，建议抽查比例不低于10%～20%（数量大时可酌情降低，但至少开箱5箱以上）。  
   - 检查水果的品种、规格、成熟度、新鲜度、有无机械损伤、病虫害、腐烂变质。

2. **记录问题并拍照留证**  
   - 对发现的不一致、损坏、不新鲜的水果，**单独分拣并摆放**，避免混淆。  
   - 对问题部位、整体箱况、外箱标签、送货单号等进行**清晰拍照**（含近距离和整体照片）。  
   - 记录：到货时间、供应商名称、送货人员、车辆信息、问题箱数/个数/重量。

3. **现场反馈并拒收问题货物**  
   - 如果明确不合格（如大面积腐烂、严重变质），**可现场拒收该部分货物**，并在送货单上备注“已拒收XX箱，原因：XXX”。  
   - 如果只是轻微差异（如大小不均、个别软果），也不要直接签“完全合格”，需在收货单上注明“有部分品质不一致，待处理”。

4. **划分责任时间节点**  
   - **如果现场发现即不合格** → 属供应商责任，拒绝接收该部分或协商更换。  
   - **如果签收后数小时内发现** → 需在当天内立即通知供应商（保留好物流签收时间证据），部分水果（如草莓、荔枝）保质期短，必须当天处理。

---

### 二、售后处理（签收后或问题确认后）

1. **正式提出书面售后申请**  
   - 将拍照证据、清点清单、异常数量（重量）整理成一份**书面售后单**（含单位名称、订单号、到货时间、问题描述、期望处理方式）。  
   - 通过电话、微信、邮件等多渠道发送给供应商，并要求其书面回复处理方案。

2. **明确处理方式（按合同或协商）**  
   - **换货**（优先）：要求供应商在次日或约定时间内补发并承担运费。  
   - **折价赔偿**（可接受时）：对细微差异，可协商按比例折扣（如总价的5%–15%），需在付款前书面确认。  
   - **扣款退款**：对无法使用的部分，按采购单价折算金额进行扣减或退款。

3. **保留“先处理、后付款”权利**  
   - 在问题处理完之前，**不要支付全部货款**（可先支付无争议部分）。  
   - 付款时在付款凭证备注“已扣除售后扣款X元”或“待售后完成后支付”。

4. **若无法达成一致**  
   - 可向单位采购部门、法务/合规部门或上级汇报。  
   - 如合同中有明确违约条款，按约定执行；必要时向市场监督管理部门投诉或申请仲裁/诉讼（金额较大时）。

---

### 三、日常防范建议（供后续参考）

- **在采购合同中明确品质标准**（如品种、大小规格、成熟度、允许的损伤率≤5%等），并注明“到货验收单需双方签字确认”。  
- **选择有稳定供应链和售后能力的供应商**（多打听口碑，可先小额试单）。  
- **建立水果分批次到货记录**，方便追溯每批来源和问题发生概率。  
- **对易损水果（如樱桃、草莓、芒果）要求更严格的包装与运输约定**，并在合同中约定“运输途中损耗由供应商承担”。
