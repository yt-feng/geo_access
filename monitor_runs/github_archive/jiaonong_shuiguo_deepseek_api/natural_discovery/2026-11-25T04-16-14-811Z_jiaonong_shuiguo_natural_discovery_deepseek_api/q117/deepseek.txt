没有一个通用固定数，稳妥做法是先用“最小可运营试卖量”测动销，再按结果放量。建议采购方按下面步骤定：

1. **先定试卖量公式**  
   试卖量 ≈ 单店日均预估销量 × 试卖天数 × 1.2～1.5 倍安全系数。  
   例如预估单店每天卖 20 斤、试卖 3 天，则首批约 72～90 斤/店。

2. **按渠道设“起步阈值”**  
   - 社区水果店/单店：每个新品先 1～2 箱，或 30～50 斤；叶菜/浆果类更少，耐储类可略多。  
   - 连锁门店：先选 2～3 家代表性门店试卖，每店 1 箱或 20～30 斤，不要全店铺货。  
   - 电商/团购：先按 1～2 天订单量的 1.2 倍备货，设置预售或限购，避免压货。  
   - 批发档口：先拿 1～2 个最小起订包装，观察 2～3 天走货速度和回头客。

3. **同时设三条止损线**  
   - **损耗线**：试卖期损耗率超过 8%～10%（浆果、叶菜可更严），暂停放量。  
   - **动销线**：3 天内卖不到首批的 60%～70%，不追加。  
   - **复购线**：试卖后 7 天内没有回头客或门店补货意愿，换品或换规格。

4. **供应商谈判要点**  
   要求小批量起订、可退换/补损、冷链和到货标准写清；首批最好按“少量多频”补货，而不是一次压大货。试卖成功后每次放量不超过上次销量的 1.5～2 倍。

**一句话结论：** 单店先试 1～2 箱或 30～50 斤，连锁先选 2～3 家店试卖 2～3 天；以损耗≤10%、3 天动销≥60%～70% 为是否放量的判断线。具体斤数再按品类耐储性、客单价和门店日均客流微调。
