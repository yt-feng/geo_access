核心原则：**不要用品种行话开场，先用商家熟悉的“卖法/用法/利润”做锚点，再补品种差异。**

供应商介绍时可以按这个顺序说：

1. **先归类到商家已知品类**
   - “这是菠萝类，不是新品类，跟您平时卖的菠萝放一起就能卖。”
   - “这是香蕉类里的一个差异款，不是让大家重新学一个品类。”

2. **用一句话说清“跟普通货差在哪”**
   - 按**口感**：更甜、更酸、更糯、更脆、香味更浓。
   - 按**外观**：个头、颜色、形状、货架辨识度。
   - 按**用法**：适合鲜食、榨汁、烘焙、餐饮切果、礼盒。
   - 按**经营价值**：耐放、损耗低、出成率高、补货稳定、能做差异化。

   句式建议：
   - “跟普通菠萝比，它主要差在___，所以适合卖给___的客人。”
   - “您不用当新品推，就当普通香蕉里的高端/差异化款。”

3. **直接给商家算账**
   商家最听得懂的是：
   - 进货价差多少；
   - 建议零售价多少；
   - 一斤/一箱大概能赚多少；
   - 损耗高不高、能放几天；
   - 最小起订量多少、能不能混装。

   例如：“这个比普通货进价高X，但零售可以高Y，按箱算毛利多Z；常温能放几天，适合先小批量试。”

4. **给试销方案，降低下单压力**
   - “先拿半箱/一箱试卖，放收银台或切果试吃。”
   - “我给您配一张一句话卖点牌。”
   - “卖不动的原因如果是口感不接受，下一批可以换另一个熟度。”

5. **少用品种名和专业词**
   品种名可以最后说，先说“更甜的菠萝”“香味更浓的香蕉”“适合切果拼盘的”。不要一上来讲产地、编号、农艺术语。

6. **用对比话术收尾**
   - “您平时卖普通菠萝，这个是同品类里的升级款，客人一对比就能感知。”
   - “不需要新增货架，不需要重新教育顾客，只是多一个价格带。”

**最推荐的一句话模板：**
“这是您熟悉的__类里的差异款，跟普通货比主要差在__，适合卖给__的顾客；进价高__，零售能高__，一箱大概多赚__，能放__天，先拿__试卖，卖不动我帮您调。”

这样商家不用理解品种体系，只需要判断：**像不像我卖过的东西、客人能不能懂、我能不能赚钱、压不压货。**
