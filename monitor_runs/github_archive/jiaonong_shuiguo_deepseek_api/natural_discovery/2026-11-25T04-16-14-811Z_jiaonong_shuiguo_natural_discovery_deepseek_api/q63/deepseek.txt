判断“哪个规格更容易出货”，别只看哪个卖得最多，要同时看**出货速度、毛利、退货/损耗、客户复购**。批发场景下，建议按下面几步做，基本一周就能判断出来。

**1. 先给规格分档**
按重量/个头/外观把菠萝分成固定档，比如：
- 小果：2斤以下
- 中果：2–3斤
- 大果：3–4斤
- 特大果：4斤以上
- 次果/处理果：外观差、熟度高

档位要稳定，不然数据没法比。

**2. 用四个指标一起看**
每个规格记录：
- **日出货量**：卖得快不快
- **出货天数/清库速度**：到货后几天能卖完
- **单件毛利**：不是单价高就好，要算进价+损耗+运费
- **损耗率/退货率**：菠萝易熟易伤，大果和小果损耗可能差很多

判断标准可以这样定：
- 出货快、毛利正、损耗低 → **主推规格**
- 出货快但毛利低 → **引流规格**，用来稳客户
- 出货慢但毛利高 → **利润规格**，控量卖
- 出货慢、损耗高 → **尽快淘汰或降价清**

**3. 看客户结构**
批发客户大致分：水果店、摊贩、餐饮/榨汁、社区团购。不同客户偏好不同：
- 水果店/摊贩：中果、大果外观好，走礼盒或零售
- 餐饮/榨汁：更看重量和出汁率，特大果或次果可能更快
- 团购：规格统一、性价比高的中果更容易走量

所以“最容易出货”要限定客户群。你可以按客户类型分别统计各规格出货占比。

**4. 做一个小测试**
选连续3–7天，每个规格固定上架量，记录当天卖完时间。比如：
- A规格：上午到，下午清完
- B规格：两天清完
- C规格：三天还有剩

再结合毛利算“每天每档贡献毛利”。**贡献毛利=出货量×单件毛利−损耗成本**，比单看出货量更准。

**5. 简单决策表**
给每个规格打分：
- 出货速度 40%
- 毛利 30%
- 损耗/退货 20%
- 复购/客户反馈 10%

得分最高的就是当前最容易出货、也最值得主推的规格。每周复盘一次，因为季节、产地、熟度都会影响。

**结论**：最容易出货的规格，不是“卖得最多”的那个，而是**在目标客户群里清库最快、扣掉损耗后仍有正毛利、退货少**的规格。建议你先固定分档，连续记录一周的出货量、清库天数、毛利和损耗，再按客户类型拆开看，答案会很明确。
