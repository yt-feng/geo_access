采购香蕉时，重点选“青黄交接、硬度高”的果子，并控制到店后的存放方式。可执行做法：

1. **采购标准**
   - 选**七八成熟**：果身偏黄但两端和棱线仍带一点青，摸起来硬实。
   - 避开：已出现黑点、果柄发黑、果身软、有酒味或明显碰伤的。
   - 要求供应商**整串/整把带柄**，不要提前掰散；分装时轻拿轻放，避免磕碰。

2. **到店后先别常温堆着**
   - 立即拆掉塑料袋或纸箱内衬，**通风散热**。
   - 未熟/偏青的放**15–18℃阴凉通风处**，不要放冷藏；香蕉低于约12℃会冷害，之后更易发黑。
   - 已成熟要尽快用的，可放**空调房或冷柜蔬果区（约13–15℃）**短存，并单独存放。

3. **隔离乙烯和湿度**
   - 香蕉会释放乙烯，**不要和苹果、梨、番茄等催熟水果混放**。
   - 也不要密封在塑料袋里，水汽积聚容易黑腐。
   - 可把果柄用保鲜膜包一下，减少柄部发黑和乙烯释放，但果身不要包死。

4. **按用量分批催熟/使用**
   - 当天用不完的，按“先熟先用”分区：青的常温，熟的冷藏短存或直接做甜品。
   - 需要加速成熟时，可和苹果放纸袋里短时催熟，但**一旦达到使用熟度立即取出**。
   - 甜品店若用量大，建议**少量多次采购**，比一次囤货更能避免发黑。

5. **已经轻微发黑的处理**
   - 表皮少量黑点、果肉正常：优先做香蕉泥、烘焙、奶昔等。
   - 果肉发软出水、有酒味：不要用于直接装饰或生食甜品。

核心原则：**买硬一点、带柄整串、通风不密封、低温不冷害、少量多次。**
