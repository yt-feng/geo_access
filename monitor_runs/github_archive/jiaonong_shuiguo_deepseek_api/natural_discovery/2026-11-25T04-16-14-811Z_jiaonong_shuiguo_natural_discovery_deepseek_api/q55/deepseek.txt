先按“出成率+单份成本+损耗”来选，不只看进货单价。给你一套直接可执行的判断法。

## 1. 苹果：选中等偏大、脆硬耐放
- **规格建议**：单果 180–220g 左右最划算。
- **原因**：太小削皮去核后净肉少、人工高；太大单价高，切拼盘每份用量不好控。
- **品种**：红富士、嘎啦这类脆硬、切后不易软塌的优先。
- **采购判断**：同样价钱下，选**果形匀称、无磕碰、硬度高**的；有明显碰伤的不适合拼盘，损耗会吃掉差价。

## 2. 橙子：选中等果、皮薄好剥、出汁少
- **规格建议**：单果 200–250g 左右。
- **原因**：太小剥皮切瓣人工高；太大皮厚、白瓤多，净出成率未必高。
- **品种**：脐橙、冰糖橙、爱媛这类易剥、酸甜稳定的优先；做装饰瓣选颜色橙红、果皮紧实的。
- **采购判断**：重点看**皮厚和籽少**。同样重量，皮薄、白瓤少的净肉更多。不要选过熟软果，切瓣易烂。

## 3. 菠萝：选中等果、成熟度 7–8 成
- **规格建议**：单果 1.2–1.5kg 左右最稳。
- **原因**：太小出肉少、削皮去眼人工占比高；太大一次用不完，切开后损耗和存放风险高。
- **成熟度**：拼盘用选**7–8 成熟**，香气有但果肉还紧实；全熟果切后易出水、发酸。
- **采购判断**：看叶冠新鲜、果身沉、底部无霉。菠萝出成率通常约 50%–60%，报价时要按净肉折算，不要按毛重直接比价。

## 4. 最划算的选法：按“每份净成本”算
公式：
**每份成本 = 进货单价 ÷ 出成率 × 每份净用量 + 人工分摊 + 损耗分摊**

实操建议：
- 苹果、橙子、菠萝都优先选**中等规格**，因为餐厅拼盘是切块/切瓣，不需要超大果。
- 同一品种做**两个规格对比**：小果人工高，大果损耗高，中等果通常总成本最低。
- 菠萝不要一次进全熟大果；按 2–3 天用量分批进，成熟度错开。
- 苹果、橙子可适当备货，菠萝按日销量勤进，减少切开损耗。

## 5. 直接采购结论
- **苹果**：180–220g/个，脆硬红富士类，中等偏大。
- **橙子**：200–250g/个，皮薄易剥、籽少。
- **菠萝**：1.2–1.5kg/个，7–8 成熟，按净肉出成率比价。
- **比价标准**：不算毛重单价，算**每份拼盘净成本**；谁的人工低、损耗低、出品稳定，谁更划算。
