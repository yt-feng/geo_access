优先看**切果损耗（出成率）**，其次甜度，再看外观，大小最后。原因是超市卖菠萝的利润主要被“削皮去眼、去头尾、坏果、试吃、临期折价”吃掉，大小只影响陈列和定价，不直接决定赚不赚钱。

可执行判断顺序：

1. **切果损耗优先**
   - 看削皮去眼后净重/毛重，出成率低的品种或批次直接拉低毛利。
   - 关注黑心、水心病、过熟软烂、机械伤，这些会让切果报废。
   - 超市若做鲜切，损耗权重最高；整果销售则看坏果率和周转。

2. **甜度第二**
   - 甜度决定复购和试吃转化，但要用“可售甜度”判断：太生酸、太熟不耐放都不行。
   - 整果销售要兼顾货架期，不能只追最高糖度。

3. **外观第三**
   - 外观影响第一眼购买，但不是核心利润项。
   - 重点看果形端正、色泽正常、无霉斑裂口；轻微外观瑕疵可转鲜切或折价。

4. **大小最后**
   - 大小主要影响定价带和陈列，不是决定盈亏的关键。
   - 同价位下大小均匀比单纯“大”更好卖。

**结论：** 超市卖菠萝，第一关注切果损耗/出成率，第二甜度，第三外观，大小放最后。若只做整果不做鲜切，可把“坏果率+周转”提到第一，但本质仍是损耗优先。
