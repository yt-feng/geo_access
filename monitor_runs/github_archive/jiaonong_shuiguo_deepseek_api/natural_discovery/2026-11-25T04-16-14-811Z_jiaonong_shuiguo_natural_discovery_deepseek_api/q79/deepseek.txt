最应该先问**售后**，其次问**配送稳定性**，最后再谈价格。

原因是团购团长卖水果，真正决定你能不能长期做下去的是：

1. **售后兜底**
   水果是非标品，坏果、烂果、缺斤少两、口感不符几乎必然发生。你要先问清楚：
   - 坏果怎么赔：按比例赔、拍照即赔，还是必须整箱退？
   - 理赔时效：收货后几小时内反馈有效？
   - 损耗谁承担：运输损耗、到货损耗、用户放坏分别怎么算？
   - 是否影响你给团员补发或退款。

   售后不清楚，价格再低也可能把利润和口碑赔进去。

2. **配送稳定性**
   水果团购最怕“今天到、明天不到”“说好冷链变常温”“到货时间飘”。要问：
   - 固定几点前下单、几点到团点？
   - 缺货、延迟怎么提前通知？
   - 到货是整箱还是分拣好？破损率大概多少？
   - 旺季爆单时能不能保量保时？

3. **价格**
   价格当然要谈，但应放在售后和配送之后。因为低价往往对应高损耗、弱售后、配送不稳。团长真正要算的是**综合到岸成本 = 进货价 + 损耗 + 理赔成本 + 售后沟通成本 + 口碑损失**，不是单看报价。

建议你问供应商的顺序就是：**先问售后规则，再问配送履约，最后压价格和账期**。如果对方售后含糊、配送承诺不敢落纸面，价格再低也慎选。
