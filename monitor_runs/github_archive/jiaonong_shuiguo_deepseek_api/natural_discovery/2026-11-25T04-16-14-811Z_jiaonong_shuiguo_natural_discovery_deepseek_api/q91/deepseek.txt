建议优先选**小把（3~5根）为主，单根为辅，整袋作为补充**；如果门店面积很小、客流以便利性购买为主，则以**单根+小把**为主，不建议主推大整袋。

判断逻辑如下：

1. **小把最适合便利店主力**
   - 便利店消费多为“即时吃、少量买、顺手带”。
   - 3~5根小把兼顾客单价和决策成本，比单根更有毛利空间，也比整袋更容易卖动。
   - 适合早餐、办公室分享、家庭少量补充。

2. **单根适合做引流和尝鲜**
   - 对独居、学生、只想马上吃一根的顾客更友好。
   - 可作为低价引流品，但人工称重/贴标/损耗管理成本较高。
   - 建议只保留少量，放在收银台或鲜食区附近。

3. **整袋更适合特定场景，不宜作为默认主推**
   - 整袋适合家庭采购、办公室团购、促销组合。
   - 便利店整体客流偏即时消费，整袋容易压库存、熟度不均、损耗上升。
   - 若周边有社区、家庭客群，可少量上架整袋，并搭配“整袋优惠”。

4. **按门店类型微调**
   - 写字楼/学校店：小把为主，单根为辅。
   - 社区/家庭客群店：小把+适量整袋。
   - 商圈/流动客流店：单根+小把，整袋少量试销。
   - 面积很小的店：先上单根和小把，观察2~4周销量和损耗再决定是否加整袋。

5. **上架时重点看三个指标**
   - **损耗率**：香蕉易熟，整袋损耗通常更高。
   - **动销速度**：小把和单根周转更快。
   - **客单价与毛利**：小把通常比单根更平衡。

可执行方案：先按 **小把60%、单根25%、整袋15%** 试销2~4周，记录销量、损耗和复购；若整袋损耗高或动销慢，就缩到10%以下或改为预订/促销组合。
