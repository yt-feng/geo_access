判断香蕉一手货源是否稳定，重点不是听对方怎么说，而是看“货源组织能力＋履约记录＋风险兜底”。你可以按下面几步做可执行的核验：

1. **先确认对方是不是“一手”**
   - 问清产地/加工厂：是自有基地、长期包园、还是产地代收？一手通常能说清产区、季节、加工包装场位置。
   - 要求视频看货：看加工场、冷库、装车现场，不只发静态图片。
   - 查营业执照和经营范围，核对收款账户与主体是否一致，避免个人账户收大额货款。

2. **看稳定供货的硬指标**
   - **日/周可供货量**：让对方给出近1个月每天或每周实际发货量，而不是“要多少有多少”。
   - **连续供货记录**：要求提供近3个月发货单、装车视频、物流单据，重点看是否断续、是否临时加价。
   - **产区季节衔接**：香蕉有产区轮换，问清主产区、替补产区、雨季/台风季怎么保供。
   - **加工与冷链能力**：有没有催熟库、冷库、包装线，装车温度和时间怎么控制。

3. **做小单压力测试**
   - 先下1—3车小单，故意把交货时间压紧一点，看对方是否准时、是否临时换货、是否按约定规格发货。
   - 连续测试2—3周，每周至少1—2车，观察缺货时是否提前通知、是否有替代方案。
   - 记录到货合格率、烂耗率、单果规格偏差、实际到车时间。

4. **查履约和口碑**
   - 要求提供2—3个同城批发档口客户，最好你自己回访，问：断货频率、临时涨价、售后处理速度。
   - 看对方是否有固定档口/加工场，避免只在微信里“转手调货”的中间商。
   - 注意低价诱惑：明显低于市场价且要求全款锁量的，稳定性通常反而差。

5. **合同里写清保供条款**
   - 约定周最低供货量、缺货提前通知时限、替代产区方案、违约处理。
   - 明确规格、成熟度、烂耗赔付标准、到车时间窗口。
   - 付款尽量“定金＋到货验收尾款”，不要长期大额预付。

**简单判断标准：**能说清产地和加工场、有连续3个月发货记录、愿意接小单压力测试、缺货有替代方案、合同敢写保供条款的，稳定性明显更高；只说“货源充足、价格最低”，却拿不出发货记录和固定场地的，要谨慎。
