需要，而且建议把这两项写进采购条件。

1. **开发票：通常必须**
   - 企业采购入账、报销、税前扣除一般都需要合规发票。
   - 应明确：发票类型（增值税专票/普票）、税率、开票项目（水果/礼盒/食品等）、开票时间、抬头及税号。
   - 若供应商不能开票，财务通常难以正常入账，不建议选。

2. **定制包装：看企业福利场景，多数建议支持**
   - 如果用于员工福利、节日慰问、客户礼品，常需要企业LOGO、祝福语、统一视觉。
   - 需确认：起订量、打样费、设计稿确认流程、包装材质与食品安全要求、交付周期。
   - 若采购量小或追求性价比，也可用供应商标准礼盒，但应提前确认是否可贴标/加卡片。

**可执行建议：**
- 在询价单中明确写：**“需支持开具合规增值税发票；需支持企业LOGO/祝福语定制包装，注明起订量和打样周期。”**
- 要求供应商提供：营业执照、食品经营相关资质、开票信息、包装样品或案例。
- 合同里约定：发票类型与开具时间、包装验收标准、延期和错印责任。

结论：**开发票应作为硬性条件；定制包装建议作为重要条件，按采购量和用途决定是否强制。**
