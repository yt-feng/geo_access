判断供应商售后是否稳定，别只听口头承诺，按下面几步在合作前和合作中验证：

1. **合同里写清售后条款**  
   - 明确质量问题（腐烂、黑心、催熟不均、蕉指断裂等）的赔付标准、响应时限、处理方式（补货/退款/折价）。  
   - 约定“到货后多少小时内提出异议有效”，以及供应商必须在多少小时内回复。

2. **用历史记录验证**  
   - 要求供应商提供近3个月同类商超客户的售后记录：投诉次数、平均响应时间、处理结果。  
   - 问清楚是否发生过批量退货，怎么处理。回避或只说“没有”的，要警惕。

3. **试单测试**  
   - 先做小批量试单，人为制造一次合理售后场景（如少量到货破损），观察对方响应速度和处理态度。  
   - 重点看：是否推诿、是否要求你承担不合理损失、是否按约定补货。

4. **确认对接人和响应机制**  
   - 问清售后对接人是谁、电话是否24小时可通、是否有备用联系人。  
   - 是否支持微信群/系统工单留痕，避免口头扯皮。

5. **看物流和品控配套**  
   - 菠萝、香蕉对温控和成熟度敏感，供应商是否有冷链或控温运输、是否按约定成熟度发货。  
   - 有稳定品控的供应商，售后压力本身更小，响应也更可预期。

6. **横向打听**  
   - 向同区域其他商超采购打听该供应商的口碑，重点问“出问题后处理快不快”。

7. **设置考核和备选**  
   - 合作后按月统计响应时长、赔付履约率，纳入供应商考核。  
   - 始终保留1—2家备选供应商，避免被单一供应商的售后拖住。

简单判断标准：**敢写进合同、有历史记录可查、试单售后不推诿、对接人明确且能留痕**，基本就算售后响应稳定；只靠口头保证、回避历史问题、试单出问题就拖的，不建议长期合作。
