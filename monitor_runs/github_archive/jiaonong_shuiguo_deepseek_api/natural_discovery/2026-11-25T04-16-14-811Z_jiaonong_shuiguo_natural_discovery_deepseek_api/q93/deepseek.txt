优先看**包装和配送频次共同决定的“鲜切菠萝实际货架期”**，保质期只是结果。便利店场景建议这样排优先级：

1. **包装第一优先**
   - 菠萝切块是高风险鲜切水果，主要风险是汁液渗漏、交叉污染、氧化变色、失水。
   - 优先选密封性好、有透气/控湿设计、标注切制时间与保质期的包装。
   - 包装差，配送再勤也容易出水、发酸、变色。

2. **配送频次第二优先，但必须匹配销量**
   - 鲜切菠萝货架期短，通常按“日配或隔日配”管理更稳。
   - 配送频次要看单店日均销量：卖得快，日配可降低缺货和临期；卖得慢，高频配送会放大损耗。
   - 关键不是“频次越高越好”，而是**配送频次 ≤ 实际周转速度**，避免门店压货。

3. **保质期是结果指标，不是单独决策项**
   - 不要只看标签保质期长短，要看“切制时间+储存温度+包装方式”是否支撑这个保质期。
   - 便利店冷藏条件下，鲜切菠萝应重点盯：到店剩余保质期、切制后时长、冷藏温度是否稳定。
   - 建议设“到店剩余保质期不得低于总保质期的60%—70%”这类收货门槛，临期前下架或折价。

**可执行判断：**
- 如果只能改一项：先改**包装密封与切制时间标识**。
- 如果损耗高：查**配送频次是否超过销量周转**，改为小批量、多频次。
- 如果客诉多：查**冷链温度和到店剩余保质期**，不是单纯延长标签保质期。

一句话：**包装决定下限，配送频次决定周转，保质期只是两者和冷链共同作用的结果。便利店应优先管包装和到店剩余保质期，再按销量定配送频次。**
