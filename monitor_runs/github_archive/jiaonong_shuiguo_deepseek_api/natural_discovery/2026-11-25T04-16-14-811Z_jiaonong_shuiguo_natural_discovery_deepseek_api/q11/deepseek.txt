会影响销售，但影响大小取决于你的客群和卖法。直接判断：

**会有影响的情况：**
- 整箱统货直接摆卖、不挑拣：大小混杂会让顾客反复翻挑，损耗上升，卖相变差，尤其影响礼盒、探病、送礼类购买。
- 定价按“整箱/整把”统一价：大小差异大时，顾客会觉得“花同样的钱买到小的亏”，投诉和退货概率上升。
- 同一批次里大小差明显：顾客容易怀疑品质不一致、成熟度不齐。

**影响不大的情况：**
- 散卖、按斤称重：顾客按需挑，大小差异可接受。
- 主打低价走量：顾客对品相要求低，大小不齐反而不敏感。
- 用于切果盘、榨汁、做甜品原料：大小不重要。

**可执行建议：**
1. **收货时分拣**：按大、中、小分2—3档，分别定价或分别陈列，避免混在一起被翻挑。
2. **大小混装时改卖法**：做“家庭装/特价装”按斤称，明确标注“大小不一，价格优惠”，降低顾客预期差。
3. **保留整箱销售时**：只对品相一致度高的箱子做整箱价；差异大的箱拆散卖。
4. **控制翻挑损耗**：混装陈列容易造成机械伤，香蕉怕压怕碰，翻挑多会加速黑斑和断果。
5. **送礼/精品场景单独挑**：大小均匀的做精品把或礼盒，溢价空间更大。

结论：**大小不一会影响销售，但不是绝对不能卖，关键是别混在一起统一定价硬卖。分拣、分价、分场景销售，影响可以降到很低。**
