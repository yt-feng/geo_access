要避免买到太生或太熟，核心是**先定“什么时候吃”，再按表皮和手感选**。

**1. 先按食用时间选成熟度**
- **当天/明天吃**：选**通体金黄、少量芝麻黑点**的，手感微软。  
- **2～3天后吃**：选**黄中带一点青**、两端仍偏绿、手感较硬的。  
- **4～5天后吃**：选**整体偏青、棱角明显**的，回家常温放熟。  
- **不要买**：表皮大面积黑褐、发软流水、柄部发黑霉变、有明显酸味的。

**2. 到店快速判断**
- **看颜色**：金黄均匀适合马上吃；青黄相间适合放几天；黑点少量正常，大片黑斑偏熟。  
- **摸手感**：轻捏微软最好；硬邦邦偏生；一捏一个坑或发黏偏熟。  
- **看两头**：果柄和果顶尖端发黑、发霉的不要。  
- **看棱角**：棱角越明显越生，越圆润越熟。  
- **闻气味**：有清香正常；有酒味、酸味说明过熟。

**3. 采购策略**
- 别一次只买同一成熟度：**买一把金黄当天吃 + 一把青黄过几天吃**最稳。  
- 如果超市冷藏区拿出来的香蕉，回家可能表皮变黑但里面没熟，优先选常温货架、无冷害斑的。  
- 回家后：青的常温避光放，别放冰箱；熟的想延后一两天可冷藏，但表皮会变黑，不影响果肉。  
- 想催熟：和苹果/梨一起放纸袋，常温1～2天。

**一句话判断**：**当天吃选金黄微软，过几天吃选黄中带青、手感硬，黑斑多、发软、有酒味的不要。**
