旺季菠萝用量突然变大，和供应商做临时补货，核心是**提前把“临时增量”的规则写清楚**，而不是临时打电话求货。建议按下面四步做：

**1. 先算清楚缺口和节奏**
- 根据近7天菠萝实际消耗、未来7天预估销量，算出日均用量和峰值用量。
- 明确你要的是“一次性补一批”还是“连续几天每天补”，以及可接受的最晚到货时间。
- 把菠萝规格写死：品种、单果重量区间、成熟度、去皮/带皮、是否要求冷链。茶饮店对成熟度和出成率很敏感，临时补货最容易在这上面扯皮。

**2. 和供应商签一份“临时补货补充条款”**
不要只口头约定，至少用微信文字或补充协议确认以下内容：
- **触发条件**：比如日用量超过日常订单量20%时启动临时补货。
- **提前通知时间**：比如提前24小时或48小时下单，给供应商备货时间。
- **临时补货上限**：约定单次最多补多少、每周最多补几次，避免供应商无限兜底或你被临时加价。
- **价格机制**：临时补货按当日市场价、按原合同价上浮固定比例，还是阶梯价。必须写清楚，防止旺季坐地起价。
- **到货时间和违约责任**：比如约定次日几点前到店，迟到几小时怎么扣款或赔偿。
- **质量标准和退换**：到货验收标准、坏果率上限、不合格怎么退换。

**3. 给供应商留出利益，换稳定供应**
旺季临时补货，供应商也怕你量不稳定。可以主动给：
- 临时补货量计入年度采购量或返利考核；
- 承诺临时补货的货款结算周期更短，比如货到即付；
- 提前给一个周度滚动预估量，哪怕不精确，也比临时突然要货强。
这样供应商更愿意优先保你。

**4. 同时准备备用供应商**
临时补货条款再细，也不要把宝押在一家。旺季至少备一家同城或周边二级供应商，哪怕价格略高，用于应急。主供应商临时补货条款里也可以约定“不可抗力或产能不足时提前通知”，给你切换时间。

**可直接发给供应商的确认话术：**
“旺季期间我司菠萝用量可能临时增加，现确认临时补货规则：我方提前24小时书面下单；单次补货不超过X箱，每周不超过X次；价格按原合同价上浮X%或当日市场价；次日上午10点前到店；坏果率超过X%可退换；临时补货货款货到3天内结清。请确认是否可执行。”

一句话总结：**把临时补货变成有触发条件、有上限、有价格、有时限、有验收标准的书面规则，同时给供应商稳定预期并保留备选供应商。**
