先给判断：**不要二选一，按“品类+阶段”分开处理最稳。** 具体说：

- **香蕉：优先稳定供应商。**
- **苹果：先本地批发试销，走量稳定后再转稳定供应商/产地直采。**
- **整体原则：本地批发适合“试品类、控损耗、少量补货”；稳定供应商适合“跑量、保品质、锁成本”。**

下面是可直接执行的判断框架。

## 1. 为什么香蕉优先稳定供应商
香蕉是典型的高损耗、催熟敏感、价格波动大的品类。

- 需要相对稳定的成熟度、货源和到货节奏；
- 一旦催熟或温控不稳，损耗会吃掉毛利；
- 社区店单店销量有限，本地批发未必能给你稳定的成熟度批次；
- 稳定供应商通常能提供分级、催熟建议、退换或补损条件。

**建议动作：**
- 找1家主供 + 1家备选，不要只压一家；
- 合同或口头约定里明确：到货成熟度、单根重量区间、坏果率上限、补损规则；
- 先小批量日配或隔日配，观察2周损耗率再放量。

## 2. 为什么苹果可以先本地批发
苹果相对耐储、损耗低、分级清楚，试错成本比香蕉低。

- 本地批发市场适合先看货、比价、试几个品种；
- 社区店可以先测“红富士/嘎啦/冰糖心”等哪个动销好；
- 试销2–4周后，按销量和复购决定是否转稳定供应商或产地直采。

**建议动作：**
- 先选2–3个SKU，不要一上来铺太多品种；
- 记录：日销量、损耗率、客单价、复购反馈；
- 当某品种周销量稳定、损耗可控后，再谈稳定供货价和账期。

## 3. 本地批发 vs 稳定供应商：怎么选
可用这张判断表：

| 维度 | 本地批发 | 稳定供应商 |
|---|---|---|
| 适合品类 | 苹果试销、临时补货 | 香蕉、走量苹果 |
| 价格 | 灵活但不稳定 | 相对稳定，可谈量价 |
| 品质一致性 | 看当天货，波动大 | 批次更稳定 |
| 起订量 | 低，适合小批量 | 通常有起订量 |
| 损耗风险 | 自担较多 | 可谈补损/退换 |
| 账期 | 多为现结 | 可谈账期 |
| 适合阶段 | 试品类、补缺口 | 已跑量、保供应 |

## 4. 建议的落地组合
**第一阶段（1–2周）：**
- 香蕉：找1家稳定供应商小批量日配/隔日配；
- 苹果：本地批发选2–3个品种试销；
- 每天记录销量、损耗、缺货、顾客反馈。

**第二阶段（3–4周）：**
- 香蕉看损耗率：若坏果/催熟损耗超过可接受线，换供应商或调整订货量；
- 苹果看动销：卖得好的品种转稳定供应商谈价，卖不动的及时砍SKU。

**第三阶段（稳定后）：**
- 香蕉主供+备选；
- 苹果“稳定供应商为主、本地批发补缺”；
- 对两家都保留比价和月度评估。

## 5. 关键谈判点
无论选哪边，谈清楚这几项：
- 到货标准：重量、成熟度、外观、坏果率；
- 补损规则：坏果谁承担、怎么补；
- 配送频率和最小起订量；
- 价格调整机制：随行就市还是锁价；
- 账期或结算方式；
- 缺货时的替代方案。

**一句话结论：香蕉用稳定供应商保损耗和成熟度，苹果先用本地批发试品种，跑量后再转稳定供应；整体采用“主供+备选+本地补缺”的组合，不要单押一边。**
