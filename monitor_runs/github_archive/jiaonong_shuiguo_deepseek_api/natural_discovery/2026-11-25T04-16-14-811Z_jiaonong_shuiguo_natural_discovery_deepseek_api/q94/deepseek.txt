很重要，尤其对便利店这种“高损耗、低客单、周转快”的业态。

判断供应商能否支持小批量试卖，关键看它是否直接影响三件事：

1. **降低试错成本**  
水果销量不稳定时，一次进多了卖不掉就是损耗。小批量试卖能先用少量货测门店真实动销，避免把不成熟品种一次性压成库存。

2. **提高上新和换品速度**  
便利店水果通常靠季节、周边客流和促销变化。供应商能小批量供货，你才能快速试新品、换规格、调陈列，而不是被起订量绑住。

3. **判断供应商是否适合长期合作**  
愿意小批量试卖的供应商，通常更愿意配合门店做动销测试、补货频率和损耗分担。反过来，只接受大起订量的供应商，往往不适合销量不稳定的小店。

实操上建议你重点问供应商四个条件：

- **最小起订量**：按箱、按件还是可按品种拼箱；
- **试卖周期**：能否先合作2—4周，按周补货；
- **损耗与退换**：坏果、滞销品是否有换货或折价机制；
- **补货响应**：小批量补货的频率、配送门槛和运费。

如果供应商完全不能小批量试卖，也不是绝对不能合作，但更适合销量已经稳定、单品动销数据清楚的品类。对“销量不稳定”的水果，小批量试卖能力基本是筛选供应商的硬指标之一。
