水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格”和“有没有货”，而是下面这些会影响长期损耗、现金流的细节：

1. **只看大货样，不看日常货**
   供应商给你看的样品通常最好。要重点看：非样品日、雨天/高温天、节前节后、下午到货时的一致性。建议至少连续看3—5批货，别用一次样品定合作。

2. **不核对产地和季节替换**
   很多供应商会说“同一个产地”，实际可能换园、换批次、混装。长期合作要问清：主产区、替代产区、换季时间、换季时品质波动。水果季节性很强，供应稳定性比单次低价重要。

3. **忽视分级标准和验收口径**
   最容易扯皮的是“什么算次果”。合作前要明确：大小、糖度、着色、软硬、机械伤、裂口、霉变、冻伤、允许损耗比例。最好写进采购单，并按批次留样或拍照留存。

4. **不算综合到货成本**
   便宜货可能包装差、损耗高、到货晚。要把采购价、运费、包装费、卸货费、损耗率、退货成本、账期资金成本合在一起算。长期看，“到货可用成本”比“报价”更真实。

5. **忽略供应商的冷库和运输能力**
   水果不是只看产地，采后预冷、冷库温湿度、装车方式、运输时长都影响货架期。尤其叶菜、浆果、荔枝、水蜜桃等，冷链断一次，零售端损耗会明显上升。

6. **不查供应集中度**
   如果某个单品只靠一个供应商，遇到天气、封路、抽检、工人短缺就会断货。长期稳定要至少有“主供+备供”，但备供也要实际走过单，不能只留电话。

7. **账期和结算方式没提前试**
   账期长不一定好，可能价格里已经加了资金成本；现结也不一定差，可能拿到更好货。要观察供应商对账是否及时、扣款是否随意、退货是否爽快。长期合作最怕结算规则模糊。

8. **忽视售后和异常处理机制**
   要提前问清：坏果怎么赔、到货不合格怎么退、补货多久到、谁承担运费、节假日怎么响应。没有明确售后规则的供应商，平时便宜，出问题时最贵。

9. **不看供应商的客户结构和经营稳定性**
   供应商如果主要客户是商超、团购还是批发市场，会影响它给你的优先級和规格。还要留意它是否频繁换品、换产地、换负责人。长期稳定合作，最好是对方也有稳定下游，而不是临时倒货。

10. **不做小批量试单和月度复盘**
    不要一上来签长期大单。先小批量试单，连续跑一段时间，记录到货合格率、损耗率、缺货次数、售后响应、实际毛利。用数据决定是否加深合作，而不是靠感觉。

**最实用的判断方法：**  
选供应商时，不要只问“你家水果甜不甜、便宜不便宜”，而要问：  
“这个单品你全年哪几个月最稳？换季时品质怎么波动？验收标准怎么写？坏果怎么赔？我临时加单你多久能到？你最大的三个客户是什么类型？”  

能把这些问题答清楚、并且连续几批货稳定的供应商，才更适合长期合作。
