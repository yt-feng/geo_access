餐饮店每天少量水果，想省心，建议优先选“本地批发市场固定档口+按需配送”的组合，而不是找大型水果供应链平台或产地直采。原因和判断标准如下：

**优先找这三类供应商：**

1. **本地农贸批发市场固定档口**
   - 最适合每天少量、品类杂、要灵活调量的店。
   - 选有固定摊位、做了几年以上、愿意早上送货的档口。
   - 优点是当天要货当天到，缺货能换品，少量也接；缺点是品质稳定性靠你和档口老板的关系维护。

2. **本地小型水果配送商/生鲜配送公司**
   - 适合你不想每天早起采购、希望微信下单次日达的店。
   - 重点问清：起送金额、配送费、缺货替代规则、坏果赔付、是否支持每天改量。
   - 少量订单容易被排在后面，所以要选专门做餐饮小B客户的，而不是主打家庭团购的。

3. **附近水果店/社区生鲜店长期合作**
   - 适合每天只要几斤到十几斤、品类不多的店。
   - 谈固定供货价和每天固定时间送，比临时买省心。
   - 缺点是品类和价格随门店进货波动，旺季可能满足不了。

**不建议优先选：**
- 大型水果B2B平台：起送量、账期、售后流程对小店未必友好。
- 产地直采：量小不现实，物流和损耗都难控制。
- 流动摊贩：价格可能低，但稳定性和食品安全追溯差。

**签约/合作前必须确认的5件事：**
- 每天几点前下单、几点送到；
- 最小起订量和配送费；
- 坏果、缺货怎么补或赔；
- 价格是固定价还是随行就市，多久调一次；
- 能否提供进货凭证或产地信息，方便食品安全查验。

**最省心的落地做法：**
先同时试2家：一家批发市场档口做主力，一家本地配送商做备份。连续试1—2周，记录到货时间、坏果率、缺货次数和实际单价，留下响应最快、赔付爽快的那家做长期合作。每天用量少，关键不是压到最低价，而是“不断货、坏果有人赔、改量方便”。
