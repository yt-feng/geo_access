判断香蕉供应商能否全年稳定供货，不要只听“我们有基地、全年不断货”，要按以下顺序核验：

1. **先看供应来源是否多元且可替换**
   - 问清香蕉来自哪些产区、各产区占比、是否跨省/跨国采购。
   - 单一产区供应商风险高，因为香蕉主产区会受台风、寒害、病害和季节性上市影响。
   - 要求提供近12个月逐月到货记录：每月到货量、产地、到货批次、缺货次数。

2. **核验基地或合作果园的真实性**
   - 要求提供果园/基地清单、面积、预计月产量、合作年限。
   - 最好实地看或视频验看，重点看是否有稳定挂果、采后处理场、催熟/仓储能力。
   - 注意“基地证明”容易造假，要交叉核对产地证明、采收记录、运输单据和发票流。

3. **看采后处理和冷链能力**
   - 香蕉全年稳定供货，关键不只是种得出，还要能采后处理、分级、预冷、运输。
   - 问清：有没有催熟库、冷库、加工线；运输是常温还是冷链；台风季/寒潮季如何保供。
   - 要求提供旺季和淡季各一个月的实际发货记录。

4. **看合同里的保供条款**
   - 不要只签年度框架，要写清月度最低供货量、缺货违约责任、替代产地条款、价格调整机制。
   - 设置安全库存和备选供应商：主供应商占60%—70%，备选1—2家，避免单点依赖。
   - 约定提前订货周期、到货合格率、缺货赔偿和紧急补货时限。

5. **做小规模压力测试**
   - 先给供应商一个淡季月份或节假日高峰的试单，观察准时率、缺货率、品质波动。
   - 连续跟踪3—6个月，重点看台风季、寒潮季、春节前后的到货稳定性。
   - 用数据判断：月均到货完成率、缺货次数、品质合格率、价格波动幅度。

6. **看财务和经营稳定性**
   - 查营业执照、经营年限、涉诉情况、是否有频繁变更。
   - 问清上游果园结算方式，若供应商长期拖欠上游，断供风险高。
   - 大额采购可要求提供近半年银行流水或主要客户供货证明，但注意合法合规获取。

**最简判断标准：**  
能提供近12个月逐月到货数据、2个以上产区来源、采后冷链能力证明，并接受“月度最低供货量+缺货赔偿+备选产地”合同条款的供应商，才基本具备全年稳定供货能力。只口头承诺、拿不出逐月记录、单一产地、无冷链的，不建议作为主供应商。
