控制水果新鲜度和库存，核心是“少进、快转、早处理”，而不是靠多进货压价。给你一套可直接执行的做法：

## 1. 进货：按销量定采购，不按感觉
- **建单品台账**：连续记录2-4周每个水果的日均销量、周末销量、损耗量。
- **采购量公式**：  
  叶菜类/草莓/葡萄等易损品：`日采购量 ≈ 前7天日均销量 × 0.8～1.0`  
  苹果/橙子/梨等耐储品：`× 1.2～1.5`，但也要设上限。
- **小批量高频补货**：易损品每天或隔天补，耐储品每周2-3次，避免一次性压货。
- **只选2-3个主推品种**：社区店客流有限，单品太多会摊薄周转。

## 2. 库存：设“安全库存+红线”
- 每个单品设**最低陈列量**和**最高库存天数**：
  - 叶菜、草莓、荔枝：库存不超过1天
  - 葡萄、桃子、香蕉：不超过2天
  - 苹果、橙、梨：不超过5-7天
- 每天闭店前盘点，超过红线的单品第二天**停止进货**，先消化。
- 先进先出：新货放里面，旧货摆前面，标到货日期。

## 3. 陈列与保鲜：减少人为损耗
- 易损水果**少量多次上架**，不要一次堆满。
- 香蕉、苹果等释放乙烯的不要和叶菜、草莓混放。
- 冷藏柜温度按品类分开：草莓/葡萄/切果2-8℃，香蕉常温避风。
- 每天早晚挑出软伤果，**及时降价或做果切**，不要等到烂了才处理。

## 4. 销售端：加快周转
- 每天固定时段做“当日鲜”特价，比如傍晚6点后易损品打折。
- 推**小份装、组合装**，降低顾客购买门槛。
- 建社区群，每天发到货和特价，接受预订，按订单补货。
- 对临近保质期的水果做果切、果汁或搭配酸奶销售，但果切必须冷藏且当天售完。

## 5. 止损机制：设损耗率目标
- 水果店合理损耗率一般控制在**3%-8%**，叶菜和浆果可略高。
- 每周复盘：哪个单品损耗高，就减少采购量或换供应商。
- 连续两周损耗超10%的单品，直接下架或改为预订制。

## 6. 供应商配合
- 和供应商谈**小批量、多频次配送**，哪怕单价略高，也比压货烂掉划算。
- 要求到货时抽检，坏果当场退换，避免把损耗转嫁到店里。

**一句话执行清单**：每天盘点→超红线停进→易损品当天清→每周看损耗砍单品→小批量高频补货。先坚持一个月记录销量，采购就有依据了。
