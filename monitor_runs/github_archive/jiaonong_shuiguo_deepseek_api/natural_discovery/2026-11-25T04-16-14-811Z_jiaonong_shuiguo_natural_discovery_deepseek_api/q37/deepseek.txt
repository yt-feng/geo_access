商超会员日水果活动，供应商的配合重点不是“多送货”，而是把**货量、品质、价格、陈列、补货、损耗**六件事提前锁定。可执行准备如下：

**1. 提前锁定活动货量与到货节奏**
- 按门店/区域拆分预估销量，明确活动前1—2天预铺货、活动当天分时段补货的频次。
- 主推单品备足安全库存，设置缺货替代品；避免只报总量、不报分店。
- 与商超确认收货时间窗、卸货能力、冷链车位，防止集中到货压车。

**2. 品质与规格提前分级**
- 按活动价对应的规格明确果径、糖度、成熟度、净重、包装标准，活动前封样。
- 主推单品提前做农残检测、产地证明、合格证等资料准备。
- 成熟度按销售节奏控制：首日可略生，活动高峰要适熟，避免集中过熟。

**3. 价格与费用提前确认**
- 确认供货价、活动零售价、毛利空间、促销折让、损耗补贴、返利和结算方式。
- 明确特价品是否限购、是否参加满减/券、价保规则，避免收银端价格不一致。
- 对爆款设置价格保护期，活动前不得随意调高供货价。

**4. 包装与陈列物料配合**
- 提前提供统一规格的周转箱、预包装、称重标签、产地/卖点插牌、试吃物料。
- 按商超陈列位提供堆头箱、端架箱、绑赠物料，保证“到店即陈列”。
- 预包装单品条码、称重码提前录入并试扫。

**5. 人员与现场支持**
- 安排活动期驻店或巡店人员，负责开箱分拣、补货、挑拣残次、试吃推广。
- 明确供应商与商超员工的补货责任边界和响应时限，如缺货/品质异常2小时内响应。
- 活动首日安排人员在高峰前到场，不要等商超电话催。

**6. 冷链与损耗预案**
- 确认冷链车、保温箱、冰袋、门店冷柜位；易损水果减少多次搬运。
- 约定残次品挑拣标准、打折处理权限、报损拍照和补货换货规则。
- 对高温、雨天、客流不及预期准备减量补货和转场促销方案。

**7. 数据与复盘准备**
- 活动前与采购确认每日销量、库存、缺货、损耗、客诉的数据回传方式。
- 活动结束当天完成剩货处理、对账差异、损耗归属确认，避免事后扯皮。

**建议供应商在活动前至少开一次三方确认会：供应商、商超采购、门店运营**，形成一张《会员日水果活动准备清单》，逐项确认货量、到货时间、价格、陈列位、驻店人和应急联系人。这样比单纯“提前备货”更能保证活动效果。
