结论先说：**食堂采购水果优先按斤结算；次选按份（固定规格）；尽量少用按箱结算。**

三种方式的管理优劣如下：

1. **按斤结算：管理最细，适合大多数食堂**
   - 优点：数量透明，便于核算成本、控制损耗、对比供应商报价，也方便按实际到货验收。
   - 缺点：称重、验收、对账工作量稍大；水分、包装、筐重容易产生争议。
   - 适用：叶果类、时令水果、每日或每周多次采购、需要控制成本的食堂。
   - 管理要点：统一以**净重**验收，明确去皮、去筐、去包装；固定称重工具；到货当场记录；约定合理损耗范围。

2. **按份结算：最适合标准化配送和窗口售卖**
   - 优点：验收快、对账简单，适合固定规格（如每份5斤、每袋10斤）、小份配送、直接分发到窗口。
   - 缺点：单价通常略高；份内品质差异不容易追责；容易出现“缺斤少两但按份算”的模糊地带。
   - 适用：水果品种稳定、规格统一、配送频次高、人手少的食堂。
   - 管理要点：合同里写清每份**净重下限、品种等级、允许次果率**；抽检称重；不合格整份退换。

3. **按箱结算：最省事但最不透明，建议限制使用**
   - 优点：交易快、适合大宗耐储水果（如苹果、橙子）和临时应急采购。
   - 缺点：箱内大小、成熟度、坏果率差异大；箱重和包装成本容易转嫁；一旦拆箱发现质量问题，责任难界定。
   - 适用：耐储水果、长期合作供应商、整箱直接入库且能抽检的情况。
   - 管理要点：必须约定**箱内净重、规格、次果率上限、坏果赔付**；到货抽检并拍照留证；不要只按“箱”比价，要折算成每斤单价。

**实操建议：**
- **主粮式、日常大量水果**：按斤结算，净重验收。
- **窗口小份配送、规格稳定的水果**：按份结算，但合同写明每份净重和品质标准。
- **耐储大宗水果**：可以按箱，但必须抽检、折算单价、约定赔付。
- 最稳妥的是**混合模式**：主采购按斤，辅以按份配送；按箱只作为补充，并且每次抽检。

一句话：**想管得细、控成本，按斤；想省人力、标准化，按份；按箱可以省事，但必须用合同和抽检把风险补上。**
