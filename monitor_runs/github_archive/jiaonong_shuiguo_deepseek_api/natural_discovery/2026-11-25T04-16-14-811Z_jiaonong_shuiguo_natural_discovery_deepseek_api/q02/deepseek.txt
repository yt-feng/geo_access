优先看**熟度**，其次看**坏果率和送货速度**，最后看**价格**。

更可执行的判断顺序：

1. **熟度第一**
   - 小水果店周转慢，香蕉进得太生或太熟都容易砸手里。
   - 理想是进“能卖2～3天”的熟度：当天能卖一部分，第二天仍好看，第三天还能处理。
   - 太青：占货架、顾客不买；太黄：一两天就发黑。
   - 如果店里没有催熟条件，别贪便宜进生蕉。

2. **坏果率第二**
   - 香蕉损耗快，坏果率高直接吃掉利润。
   - 进货时看整箱/整把的压伤、黑斑、断柄、发霉。
   - 可以约定“开箱坏果超过一定比例补货或扣款”，小店里这比单价便宜几毛更重要。

3. **送货速度第三**
   - 香蕉不耐放，送货慢会打乱熟度控制。
   - 优先选能稳定次日达、按你要求熟度送货的供应商。
   - 如果送货不稳，再便宜也不敢多进。

4. **价格最后看，但不是不看**
   - 价格要在“熟度合适、坏果可控、送货稳定”的前提下比较。
   - 单纯便宜但熟度差、损耗高，实际成本更高。
   - 小水果店适合少量多次进，别为了低价一次压太多货。

**简单决策规则：**
- 熟度不合适：直接不选。
- 坏果率明显高：换供应商。
- 送货经常拖：不能作为主供应商。
- 以上都过关，再比价格，选综合毛利和损耗最低的。

如果只能记一句话：**小水果店进香蕉，先买“卖得动、损耗低”，再买“便宜”。**
