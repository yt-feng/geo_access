要支持，但要有边界和规则，不能无条件支持。对即时零售平台卖水果，小批量高频补货通常是提升竞争力所必需的，但供应商应把它做成“有门槛、有价差、有考核”的运营机制。

**判断结论**

1. **应该支持小批量高频补货**，尤其是叶菜、浆果、切果、鲜切水果、高周转爆品和前置仓/门店型即时零售。
2. **不应全品类、全客户、无条件支持**。根茎类、耐储果、整箱大规格、低毛利引流品，不必高频小批量。
3. 支持方式应是**分层补货**：高频品小批量、耐储品中批量、长尾品按需补，而不是把所有SKU都切成小单。

**为什么供应商要支持**

- 水果损耗高、保鲜期短，即时零售靠“少补勤补”降低平台和门店库存风险。
- 即时零售订单波动大，小批量高频能减少缺货和次日报废。
- 平台通常考核履约率、缺货率、鲜度，供应商不支持小批量高频，容易被替换。
- 对供应商而言，高频补货能锁定平台份额、提高复购品渗透，但必须把物流和拣配成本转成规则。

**供应商必须设的边界**

- **起订门槛**：按客户设最低单次金额或最低件数，例如单店/前置仓单次不低于一定金额，低于门槛加收配送费。
- **频次分层**：爆品每日1—2配，常规品隔日配，长尾品每周2—3配；不是所有SKU每日配。
- **价格机制**：小批量高频补货的单价比大批量低频率补货适当上浮，或设“高频补货服务费”，覆盖拣货、分拨、短驳成本。
- **品类限制**：鲜度敏感、高周转品支持小批量高频；耐储品建议中批量；低毛利品不单独高频配。
- **时效与责任**：明确截单时间、到仓/到店时间、验收标准、短装和品质不达标的责任。
- **数据协同**：要求平台或门店提供销量、库存、缺货、报废数据，按数据补货，避免“拍脑袋高频”。
- **考核与退出**：对频繁极小单、临时加单、拒收造成损耗的客户，设置加价或降低服务等级。

**可执行建议**

- 先选**20%高周转、高损耗、高缺货SKU**做小批量高频补货试点，跑2—4周看缺货率、损耗率、单均履约成本。
- 对客户分A/B/C级：A级高频小批量支持，B级隔日配，C级标准起订量。
- 把“小批量高频”做成**报价选项**，而不是默认免费服务：基础价对应标准补货，高频小批量对应服务价。
- 用**动态安全库存+自动补货建议**替代人工频繁下单，降低供应商拣配压力。

一句话：**要支持，但只对对的品类、对的客户、对的频次支持；用起订量、价差、时效和数据协同把成本管住。**
