采购菠萝时，建议把“熟度判断”分成**到店可售窗口**和**当天必须清掉**两档，而不是只追求“最甜”。水果店控损耗，核心是**分批采、按成熟度分级卖**。

可直接执行的做法：

1. **按销售节奏定采购熟度**
   - 预计 1～2 天内卖完的：可采**七八成熟到九成熟**，香气明显、果肉开始软化。
   - 预计 3～5 天卖的：采**六七成熟**，外观转黄但手感还偏硬，入店后自然后熟。
   - 不要一次全采九成熟以上，除非当天有促销或加工（切果盒、果汁）。

2. **现场看外观**
   - 果皮：从青绿转黄、黄色面积逐步扩大为后熟标志；全青通常偏生，全黄偏熟。
   - 果眼：果眼饱满、间距均匀，说明发育较好；果眼发黑、渗液、凹陷要警惕过熟或腐烂。
   - 冠芽：叶片青绿、挺立较好；冠芽干枯、易拔脱可能放置过久。
   - 底部：重点看果底，发黑、发软、有酒味或酸味说明过熟或已坏。

3. **闻香气**
   - 靠近果底闻：有清淡果香说明开始适熟；香气浓烈、带酒味说明过熟，损耗风险高。
   - 完全无香且很硬，偏生，适合放几天再卖。

4. **手感判断**
   - 轻压果身：硬挺偏生；略有弹性、不塌陷为适熟；一按就软、回弹差为过熟。
   - 同样大小下手感越重通常水分更足，但不要只看重量。

5. **分等级采购和陈列**
   - 把货分成：**青硬（可放）、转黄（主推）、香软（当天清）**。
   - 转黄果放显眼位置优先卖；青硬果放后区或阴凉处后熟；香软果及时切盒、做果汁或打折。
   - 采购单上按“预计销量 × 成熟度比例”下单，例如 60% 六七成熟、30% 八成熟、10% 九成熟，随天气和客流调整。

6. **到店后减少损耗的操作**
   - 不要堆压，菠萝怕压伤；避免闷在塑料袋里，保持通风。
   - 不要整批水洗后存放，切口果冷藏并尽快售完。
   - 每天翻检一次，把开始发软、有香气的挑出来优先处理。

简单判断口诀：**青硬能放，转黄好卖，香软快清；底部发黑、有酒味的不进。** 采购时宁可略生一点分批后熟，也不要整批偏熟压库存。
