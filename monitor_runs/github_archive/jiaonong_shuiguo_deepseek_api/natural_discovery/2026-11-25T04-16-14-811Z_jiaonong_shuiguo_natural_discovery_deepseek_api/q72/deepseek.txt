先把方向说清楚：批发商想“稳定大客户”，核心不是把账期和额度一次谈得很大，而是把**回款风险、供货稳定、客户粘性**三者绑在一起谈。水果是高损耗、强季节、价格波动大的品类，账期和额度必须跟“品类、周转、结算方式、担保”挂钩，不能只谈一个数字。

下面给你一套可执行的谈法。

### 1. 先定原则：账期换量，额度换保障
- **账期**：不要一上来给30天、45天，先给“短账期+高频结算”，比如7天、10天、15天，稳定后再阶梯延长。
- **额度**：不要给固定大额度，用“动态额度”或“滚动额度”，跟历史回款、采购量、担保方式挂钩。
- **水果品类特殊处理**：叶菜、浆果、熟度高的水果损耗快，账期要短；耐储品类如苹果、梨、柑橘可适当长一点。
- **价格波动条款**：行情大跌时，供应商最怕客户压价又拖账，合同里要写清“账期不因行情波动自动延长”。

### 2. 账期怎么谈：用阶梯和条件换稳定
建议这样设计：
- **首期合作**：现款现货或3天账期，最多7天，先跑1—2个月。
- **稳定期**：连续按时回款后，给10—15天账期。
- **大客户期**：月采购额稳定、回款记录良好，再给20—30天，但必须满足条件：
  - 每月最低采购量或最低采购额；
  - 超期付款有违约金或暂停供货条款；
  - 大额订单单独审批，不占用常规额度；
  - 节假日、旺季前缩短账期或要求预付款。

谈判话术可以这样：
“账期我可以给，但咱们按阶梯来。前两个月7天，回款稳定后调到15天，月采购额达到X万再谈30天。这样你资金压力小，我供货也稳。”

### 3. 额度怎么谈：动态额度比固定额度更安全
不要直接给“月赊销50万”这种固定额度，建议用：
- **初始额度**：按客户月采购额的30%—50%设定，或按首月试单金额的2—3倍设定。
- **动态调整**：连续3个月按时回款，额度上调20%—30%；出现一次逾期，额度下调或暂停。
- **额度分层**：
  - 常规额度：日常补货；
  - 临时额度：节假日、大促单独申请，需预付款或担保；
  - 超额部分：现款或部分现款。
- **额度与账期挂钩**：账期越长，额度越谨慎；额度越大，账期越短。

### 4. 必须谈进去的保护条款
水果供应商最怕“货给了、账拖了、损耗算我的”，合同里要写清：
- **对账周期**：每周或每半月对账，避免月底扯皮。
- **验收与损耗责任**：到货验收标准、损耗率上限、超过部分谁承担，必须提前写。
- **逾期处理**：逾期几天暂停供货、违约金比例、是否取消账期。
- **价格调整机制**：行情大幅波动时，未结算订单按什么价格执行。
- **担保方式**：大额度可要求保证金、法人担保、房产或第三方担保，至少要有书面还款承诺。
- **停止供货权**：逾期未回款，供应商有权暂停供货且不承担断供责任。

### 5. 谈判节奏：先小后大，先短后长
建议分三步：
1. **试单期**：小批量、短账期，观察回款和验收配合度。
2. **稳定期**：签框架协议，明确阶梯账期和动态额度，按月复盘。
3. **大客户期**：给更长账期和更高额度，但换取最低采购量、独家品类或优先供货权。

### 6. 判断标准：什么条件可以给
- 可以给较长账期：客户连续6个月按时回款、采购量稳定、有担保、损耗争议少。
- 不能给长账期：新客户、单笔金额突然放大、回款靠口头承诺、验收标准模糊、只压价不保量。
- 额度上限参考：常规赊销额度不超过客户月均采购额的50%，且不超过供应商可承受的坏账上限。

一句话总结：**账期用阶梯换稳定，额度用动态换安全；先短后长、先小后大，所有长账期和大额度都必须绑定最低采购量、回款记录和担保条款。**
