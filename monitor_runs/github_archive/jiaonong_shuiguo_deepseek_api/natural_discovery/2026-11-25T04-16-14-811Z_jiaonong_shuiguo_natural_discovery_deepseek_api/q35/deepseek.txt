连锁超市降低门店坏果率，赔付条款不能只写“按损失赔”，而应把**验收标准、责任分界、赔付计算、扣款/补货机制、举证与时效**写清楚。建议合同按以下结构约定：

**1. 先定义“坏果”和验收标准**
- 明确品类标准：腐烂、霉变、软烂、裂口、虫害、异味、冻伤、机械伤等分别是否计入坏果。
- 约定允许损耗率/坏果率上限，例如“到店验收坏果率≤X%”“门店上架前坏果率≤Y%”，超限即触发赔付。
- 抽样方法写清楚：按批次随机抽检、抽检比例、以门店收货记录和照片/视频为准。
- 等级标准最好附《质量验收标准表》，避免只写“新鲜”“无坏果”。

**2. 划分责任节点**
按“产地装车—运输—配送中心—门店收货—上架销售”分节点：
- 到店验收前发现坏果，原则上由供应商承担；
- 验收签字后发现且能证明是运输/储存不当造成的，按责任方承担；
- 门店自身陈列、温控、挤压、超期销售造成的，供应商不承担。
建议写明“收货验收不免除供应商对隐蔽性腐烂、内部霉变的责任”，但设置合理期限，如到店后24/48小时内提出。

**3. 赔付计算要可执行**
不要只写“赔偿实际损失”，建议采用“**扣款+补货+违约金**”组合：
- 坏果部分：按该批次不合格数量×含税采购单价全额扣减；
- 超过约定坏果率：按“超出部分货值×1—3倍”扣款，倍数按品类和严重程度分档；
- 整批严重不合格：超市有权拒收、退货，供应商承担退货运费及因此产生的缺货损失；
- 造成客诉、监管处罚、下架销毁的，约定供应商承担直接损失及合理处理费用。
注意：违约金和损失赔偿的关系要写清，避免重复计算或无法主张。

**4. 设置补货和保证金机制**
- 不合格批次可要求限期补货，补货不到位的按缺货货值扣款；
- 月度坏果率连续超限的，触发整改、暂停供货或解除合同；
- 可设质量保证金，从货款中预留一定比例，按季度结算，质量达标返还；
- 明确扣款直接从当月货款中扣除，供应商有异议应在约定期限内书面提出并提供证据。

**5. 举证、时效和争议处理**
- 门店收货时拍照、视频、留存抽样记录；双方可约定以超市系统记录为初步证据，供应商可申请复检。
- 明确异议期，例如收货后24小时内提出质量异议，逾期视为验收合格，但隐蔽质量问题除外。
- 约定复检机构、费用承担和最终依据。
- 生鲜易腐品可约定“先处置后争议”，避免扩大损失，但处置过程需留证。

**6. 建议的核心条款表述示例**
“供应商交付商品坏果率超过本合同约定标准的，超市有权按不合格数量对应货值全额扣减货款；超出约定坏果率部分，另按超出货值的2倍支付质量违约金。因坏果导致退货、销毁、客诉处理或监管处罚的，供应商还应赔偿超市直接损失。质量保证金按月度货款的5%预留，季度结算。供应商对质量扣款有异议的，应在收到通知后2个工作日内书面提出并申请复检，逾期视为认可。”

**关键提醒：**赔付条款必须和验收标准、抽检方法、责任节点绑定，否则容易变成“有条款难执行”。另外，生鲜损耗有自然属性，建议设置合理的基础损耗率，只对“超限部分”追责，避免供应商报价中隐性加价。
