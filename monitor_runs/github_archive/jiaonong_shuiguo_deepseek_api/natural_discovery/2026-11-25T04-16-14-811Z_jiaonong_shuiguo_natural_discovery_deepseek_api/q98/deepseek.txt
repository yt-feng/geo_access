判断养老院或医院食堂的水果供应商，核心抓两条线：**合规资质（能不能合法供、出了问题能不能追责）** 和 **稳定性（能不能持续按质按量供）**。以下按可执行的核查动作列出。

## 一、合规性核查（先过门槛，再谈价格）

**1. 主体资质（必须查原件/官方渠道）**
- 营业执照：经营范围含食用农产品销售/食品销售；核对名称、地址与合同主体一致，避免“个人挂靠公司”。
- 食品经营许可证：若供应商涉及分装、切配、预包装或配送冷链食品，需相应许可；仅销售初级食用农产品一般不强制，但**养老院/医院属高风险供餐场景，建议优先选有食品经营许可的配送商**。
- 若供应商是农户/合作社直供：查合作社营业执照、产地证明、承诺达标合格证。

**2. 产品合规凭证（按批次索要，不能只给一次）**
- 食用农产品承诺达标合格证（现行主推的产地准出凭证）。
- 农药残留检测报告：优先要**第三方检测报告**（CMA/CNAS资质机构），并核对报告上的样品名称、日期、批次与到货是否对得上。
- 肉类、进口水果另需检疫证明、报关单等（水果主要看农残和产地）。

**3. 追溯与责任链条**
- 要求提供进货台账、上游产地/批发市场来源，能做到“这批货从哪来”。
- 合同里写清：质量不达标、检出农残超标的退换货与赔偿责任；约定抽检不合格的违约金。
- 查企业信用：国家企业信用信息公示系统看经营异常、行政处罚；有食品安全处罚记录的慎用。

**4. 现场核查（首次合作必做）**
- 看仓储：是否分区分架、有无防鼠防虫、冷藏条件；水果是否与有毒有害物混放。
- 看分拣/切配环节（如有）：人员健康证、操作卫生、清洗消毒。
- 看配送车辆：是否专用、有无温控、是否与生鲜/化学品混装。

## 二、稳定性判断（看能力和履约记录）

**1. 供应能力**
- 是否有稳定上游：产地直采、批发市场档口、合作社协议；问清旺季/淡季、极端天气下的替代货源。
- 日供货能力是否匹配食堂用量，是否有备用供应商机制。
- 配送频次、到货时间窗口能否固定（医院/养老院对开餐时间敏感）。

**2. 履约记录**
- 要求提供近半年同类客户（ preferably 医院、养老院、学校食堂）供货案例，可电话回访。
- 试供期：先小批量试供 2–4 周，记录到货准时率、损耗率、规格达标率、投诉响应时间。

**3. 质量波动管理**
- 约定验收标准：品种、规格（单果重/等级）、成熟度、外观、农残合格；明确不合格判定和扣款规则。
- 约定抽检机制：食堂方定期送检或快检，费用与责任归属写进合同。
- 看其对投诉的响应：是否 24 小时内换货、是否有质量追溯和整改记录。

**4. 经营稳健性**
- 公司成立年限、注册资本与实际经营是否匹配；避免刚注册、无实体仓的“皮包”供应商。
- 是否过度依赖单一客户或单一产地；价格是否明显低于市场（低价往往伴随质量或合规风险）。

## 三、落地建议（可直接照做）

1. **建立供应商准入表**：营业执照、食品经营许可、合格证、检测报告、信用查询截图、现场核查记录，缺一不可。
2. **合同必备条款**：批次合格证随货、农残超标退换与赔偿、准时率与损耗率考核、备用货源义务、食品安全责任险（如有）。
3. **验收双人签字**：数量、规格、外观、温度、凭证齐全才入库；不合格当场记录并拍照。
4. **季度复评**：准时率、合格率、投诉次数、检测结果打分，末位淘汰并启动备选供应商。
5. **保留票据与台账**：应对监管检查，也便于出问题时追责。

一句话原则：**合规看“证、检、溯、现场”，稳定看“上游、履约、波动、财务”**；养老院和医院属重点供餐单位，宁可供应商少而稳，不要低价多而杂。
