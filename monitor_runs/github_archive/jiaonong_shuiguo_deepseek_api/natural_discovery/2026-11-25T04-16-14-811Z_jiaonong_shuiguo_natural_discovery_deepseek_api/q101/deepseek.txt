和水果供应商谈酒店早餐合作，重点是把“稳定”落到可执行的条款和验收标准上。建议按下面几项准备和谈判：

1. **先定需求和标准**
   - 列明早餐常用水果品类、规格（如单果重量、等级）、成熟度、去皮/切配要求。
   - 明确每日/每周用量、最低起送量、临时加量提前多久通知。
   - 约定验收标准：新鲜度、无腐烂、无虫害、农残检测报告、包装和温度要求。

2. **考察供应能力**
   - 问清产地、季节替代方案、冷链能力、仓储和配送车辆。
   - 要求提供营业执照、食品经营许可证、检测报告或合格证明。
   - 了解其其他酒店客户、旺季/节假日保供方案、缺货时的替代方案。

3. **价格与结算**
   - 不要只比单价，要算损耗率、切配人工、配送费、退换货成本。
   - 明确价格调整机制：随行就市时提前通知，锁定周期和涨跌幅上限。
   - 约定账期、发票类型、对账周期和付款方式。

4. **配送与验收流程**
   - 固定配送时间窗口，避免影响早餐备餐。
   - 约定到货温度、抽检比例、验收不合格的处理：拒收、补货时限、扣款或赔偿。
   - 建立每日验收单和异常记录，双方签字确认。

5. **稳定性保障条款**
   - 缺货提前通知时限和违约金/补偿方式。
   - 要求备选货源或替代品类方案，避免单一供应商断供。
   - 旺季、节假日、恶劣天气的保供预案。
   - 食品安全事故的责任划分和召回机制。

6. **合同关键条款**
   - 质量规格、价格、配送、验收、退换货、违约责任、食品安全责任、保密和终止条件。
   - 先小批量试供1—2周，再签长期协议；保留更换供应商的权利。
   - 避免口头承诺，所有标准写进合同附件。

7. **内部管理配合**
   - 指定验收人和异常上报流程。
   - 记录每日到货质量、损耗和缺货情况，作为月度评估依据。
   - 定期复盘用量和浪费，调整订货量。

最需要盯住的三件事：**验收标准可量化、缺货有替代和赔偿、食品安全责任写清楚**。
