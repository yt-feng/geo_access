# 坏果责任条款怎么写：给批发商的合同要点

核心思路：**不能只写"损耗由卖方承担"这种一句话，而要拆成"验收标准 + 责任分段 + 举证方式 + 救济手段"四个部分**，否则出了事很难执行。

## 一、先把"坏果"定义清楚（最关键）

模糊的"损耗"是扯皮根源。建议在合同里写清：

1. **分级标准**：按国家/行业标准（如鲜果等级标准）或双方封样确定，明确"腐烂、霉变、压伤、裂口、软烂"各自算不算坏果，单果坏到什么程度（如腐烂面积超过1/3）计为坏果。
2. **计数口径**：按重量计还是按件/箱计；坏果是"整果计入"还是"按坏损部分折算重量"。
3. **封样**：签约时双方共同封存标准样品（可拍照+视频+签字），作为到货比对依据。

## 二、责任分段：按环节划分，不要笼统

| 环节 | 建议约定 |
|---|---|
| 装车前 | 卖方对起运时的果实质量负责，装车时双方（或卖方委托的第三方）验货并留影像记录 |
| 运输中 | 明确运输方式、温控要求（如冷链温度区间）、承运人责任；若买方自提或自派车，途中风险由买方承担 |
| 到货验收 | 约定验收时限（如到货后X小时内完成）、验收地点、双方到场或第三方检验 |
| 验收后 | 验收合格或超期未提异议，视为认可，后续损耗由买方承担 |

## 三、容忍度与责任比例（可谈判的核心）

鲜果不可能零损耗，建议设"合理损耗率"：

- 例如：到货坏果率 **≤3%** 由买方自担（行业惯例区间，需双方议定）；**超过部分**由卖方按坏果重量/件数折价补偿、补发或退货。
- 也可设阶梯：3%–5% 按X折补偿，超过5% 买方有权拒收整批或要求退货退款。
- 注意：若因买方未及时卸货、未按要求冷藏导致的损耗，应排除在卖方责任外。

## 四、举证与验收程序（决定条款能否落地）

1. **到货即验**：约定买方须在到货后约定时限内开箱抽检，抽检比例（如每车随机抽X箱）和抽检方法写清。
2. **影像+书面记录**：拍照/录像需含时间、整车、开箱过程、坏果特写；异议须在时限内书面（含微信/邮件）通知卖方，逾期视为无异议。
3. **第三方检验**：争议大时约定由双方认可的检测机构或行业协会出具意见，费用由责任方承担。
4. **保全货物**：约定异议期间坏果不得随意处置，需保留至双方确认或第三方查验，避免"货没了说不清"。

## 五、救济方式写具体

- 折价补偿：按坏果重量×单价×折扣系数，X日内支付或从下批货款抵扣；
- 补发：约定补发时限和运费承担；
- 退货退款：达到约定坏果率上限时买方有权拒收，卖方承担退货运费及买方已付费用返还；
- 违约金/赔偿上限：可约定卖方赔偿责任以该批货款为限（卖方角度），买方则争取包含合理损失。

## 六、两个容易被忽略的点

- **不可抗力和自然损耗**：明确高温、长途运输等"自然减量"是否计入坏果率，避免卖方以此免责、买方以此索赔。
- **多批次交易**：约定连续多批出现超标坏果时的处理（如买方有权解除后续订单）。

## 给批发商的实操建议

1. 签约前先做**封样**，并在合同附件里放标准照片和分级表；
2. 把"验收时限+书面异议+影像留证"作为买方内部流程固定下来，否则条款形同虚设；
3. 首次合作可先小批量试单，用实际损耗数据校准合同里的损耗率阈值；
4. 金额大的订单，考虑约定第三方检验机构，减少事后扯皮。
