**一般情况：**

1. **图片：多数供应商能给，但质量参差**
   - 产地/果园实拍、装箱图、果径对比图：常见，可用性较高。
   - 白底精修图、场景图、切开展示图：头部供应商/品牌方常有；中小批发商往往只有手机随手拍。
   - 需注意：供应商图常有水印、其他平台logo、过度滤镜、非当季旧图，直接商用有风险。

2. **卖点：能给，但多为“原料级”信息**
   - 供应商通常能提供：品种、产区、果径/规格、糖度范围、采摘时间、储存方式、箱规、损耗率。
   - 不一定能提供：面向消费者的文案、食用场景、口感描述、对比竞品的差异化卖点。这些通常要采购/运营自己提炼。

**可执行建议：**

- **采购合同或沟通里明确素材要求**：每批次提供果园/包装实拍≥3张、规格对比图1张、当季采摘证明或糖度检测记录（如有）。
- **建立供应商素材评分**：图片清晰度、是否白底/场景、是否可商用、卖点完整度、更新频率。优先选能稳定供图的供应商。
- **不要全靠供应商**：核心详情页首图、切开图、口感文案建议自拍/自写，供应商图做补充和背书。
- **商用授权要问清**：是否允许二次剪辑、去水印、用于电商平台；避免拿到别家品牌图。
- **到货抽检反哺素材**：用实际到货拍开箱、切果、糖度测试，比供应商图更可信，也能降低“图文不符”售后。

**判断标准：** 如果供应商只能给模糊装箱图和一句“很甜”，就别指望它支撑详情页；如果它能给当季实拍、规格对比、检测数据且授权清晰，就可以作为素材主来源之一。
