建议优先从**香蕉**开始，但前提是你要把它当成“引流+稳定周转品”，而不是高毛利品。三个品类的排序和判断如下：

1. **香蕉：最适合先做稳定进口水果**
   - 需求稳定、消费频次高、顾客接受度高，适合做日常引流。
   - 进口香蕉供应链成熟，标准化程度较高，全年可操作。
   - 风险点：损耗和成熟度管理要求高，催熟、温湿度、周转速度决定成败；毛利通常不高。
   - 适合条件：你有冷藏/催熟或至少稳定的温控陈列能力，能按日管理库存。

2. **菠萝：可以第二步做差异化**
   - 进口菠萝有差异化卖点，客单价和毛利通常比香蕉好一些。
   - 但消费频次低于香蕉，且顾客对酸度、成熟度、削皮服务敏感，损耗也不低。
   - 适合在香蕉跑通冷链和周转后，再小批量引入，做主推试吃和现场服务。

3. **苹果：不建议作为“第一步进口稳定品”**
   - 苹果需求大，但国产苹果供应强、价格竞争激烈，进口苹果很容易变成高成本低差异。
   - 除非你做高端进口品种、礼盒或特定客群，否则稳定性和毛利都容易被国产替代。
   - 更适合在已有进口水果客群后，作为结构补充，而不是首发稳定品。

**执行建议：**
- 先小批量试销进口香蕉，连续观察2—4周的日销量、损耗率、毛利率、缺货率。
- 关键指标：损耗率控制在5%—8%以内，周转天数尽量不超过3—5天；若做不到，先不要扩大进口品类。
- 香蕉跑通后，再引入菠萝做第二品类，采用“小批量、勤补货、试吃带动”的方式。
- 苹果放到第三阶段，只做有明确差异的进口品种，避免和国产苹果正面拼价。

一句话：**先香蕉跑通供应链和损耗管理，再菠萝做差异化，苹果最后做结构补充。**
