坏果率没有统一法定阈值，关键看合同怎么约定。实务建议：

1. **合同里最好明确分档赔付**
   - 坏果率≤3%：通常视为合理损耗，不赔付或仅扣重。
   - 3%＜坏果率≤5%：按坏果重量扣款，或按货值比例折价。
   - 5%＜坏果率≤10%：除扣重外，可要求按坏果对应货值的1～2倍赔付。
   - 坏果率＞10%：可要求整批退货、换货，或拒收并索赔。
   具体比例可随品类调整：叶菜、浆果等易腐品可放宽到5%～8%；苹果、柑橘等耐储水果可收紧到3%～5%。

2. **没有约定时怎么主张**
   可依据《民法典》质量瑕疵担保和违约责任主张：先看是否符合约定质量标准或行业通常标准；不符合的，可要求扣减价款、换货、退货或赔偿实际损失。坏果率明显偏高时，建议保留到货照片、视频、过磅单、抽样记录和书面通知，及时固定证据。

3. **合同条款建议写成可执行**
   写清“抽样方法、检验时限、坏果定义、扣款公式、赔付上限、退货触发条件、异议期”。例如：“到货24小时内按随机抽样3箱/车检验，坏果率超过5%的，按超出部分重量×采购单价×2扣款；超过10%的，买方有权拒收并要求卖方承担运费。”

所以，**建议把赔付触发线设在5%左右，10%左右设退货/拒收线**；最终以你合同约定和水果品类为准。
