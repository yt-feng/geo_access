和供应商谈旺季合作，核心是“把断货风险拆开问清楚”。建议按下面几组问题提前确认，最好让对方给书面承诺或写进合同/订货单：

**1. 供应能力与旺季保障**
- 旺季你们每天/每周最多能给我供多少货？分品类说。
- 我平时日均销量是X，旺季预计增长Y%，你们能否锁定这个量？
- 你们上游产地/批发市场在旺季是否稳定？有没有备选货源？
- 如果我临时加单，提前多久通知能保证？加单上限是多少？
- 旺季你们同时供多少家店？会不会优先保大客户而挤占我的量？

**2. 缺货与替代方案**
- 某品类缺货时，提前多久通知我？
- 有没有同品质替代品？价格怎么算？
- 缺货导致我断货，有没有补偿或违约责任？
- 能不能约定“保底供应量”和“缺货提前预警时间”？

**3. 价格与结算**
- 旺季价格是锁价还是随行就市？锁价锁多久？
- 涨价提前几天通知？幅度有没有上限？
- 结算方式是现结、周结还是月结？旺季会不会要求预付？
- 运费、装卸、损耗谁承担？到店价还是批发价？

**4. 品质与损耗**
- 旺季品质标准会不会下降？验收标准是什么？
- 坏果、短斤少两怎么赔？当场退换还是下次抵扣？
- 损耗率大概多少？超过部分谁承担？
- 能不能先少量试供几天，再定旺季量？

**5. 配送与时效**
- 每天几点前下单、几点送到？旺季会不会延迟？
- 配送频率能不能从隔天加到每天？
- 临时补货最快几小时到？
- 节假日、极端天气怎么保障配送？

**6. 合作约束与备胎**
- 能不能签旺季保供协议？关键条款写清楚：品类、日供量、价格机制、缺货预警、违约责任。
- 我能不能同时保留第二供应商？会不会要求独家？
- 如果你们断供超过X天，我可以解除合作并索赔吗？

**谈判时最该拿到手的几项：**
1. 分品类旺季日供量/周供量；
2. 缺货提前预警时间；
3. 临时加单的最晚通知时间和上限；
4. 价格调整机制与通知期；
5. 品质验收和损耗赔付标准；
6. 违约责任或补偿方式。

另外，水果店旺季别只谈一家，至少备一个二批或周边产地直供作为“备胎”，哪怕量不大，也能在主力断货时顶住。
