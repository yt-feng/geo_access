建议先向供应商要**可核验的抽检/检测资料和批次追溯资料**，且要按“批次”对应，不要只看一张长期有效的报告。

可提前索要：
1. **本批次农产品农药残留检测报告**
   - 看报告是否有 CMA/CNAS 标识、检测机构、报告编号、样品名称、生产/供货单位、抽样或送样日期、检测项目、结果和判定依据。
   - 重点确认报告对应的是**本次到货批次/产地/品种**，不是其他批次或过期报告。

2. **产地证明或供货证明**
   - 如产地证明、采购凭证、供货单、基地/合作社供货证明，用于确认来源和批次对应关系。

3. **承诺达标合格证/质量安全承诺书**
   - 食用农产品可要求供应商提供承诺达标合格证或类似质量安全承诺文件，并核对品种、数量、产地、开具日期。

4. **批次追溯信息**
   - 要求供货单上写明：品种、产地、供应商、采收/包装日期、批号、数量、运输信息。
   - 超市入库时把检测报告编号与进货批次绑定留存。

5. **供应商资质和检测安排**
   - 营业执照、食品经营/生产相关许可（按其经营模式）、近期的第三方检测报告。
   - 询问其农残自检/送检频次、抽检项目和异常处理流程。

6. **进货查验记录所需资料**
   - 发票或供货凭证、送货单、验收记录，确保能追溯。

操作上建议：
- **不要接受“一份报告长期通用”**，要求按品种、产地、批次提供或至少覆盖近期供货批次。
- 对高风险品种、新供应商、产地不明的水果，可要求**批批带检测报告或承诺达标合格证**；到货后超市再做快检抽检。
- 资料不全或批次对不上时，先**暂缓收货/单独存放**，待补齐或快检合格后入库。
- 留存期限按当地监管和超市制度执行，通常进货查验记录应妥善保存备查。

一句话：重点是**本批次检测报告 + 承诺达标合格证/产地供货证明 + 可追溯送货单**，三者能互相对应。
