香蕉是生鲜电商里最难做的品类之一，因为它既怕压，又怕冷，还怕乙烯催熟。要控制配送途中的压坏和变黑，建议从**采购成熟度、分级包装、控温、减震、时效**五个环节一起抓，单靠包装解决不了。

## 1. 采购端：控制成熟度和采收标准

- **不要发全熟蕉**：七至八成熟（果指饱满、棱角尚存、果皮青绿转浅绿）最适合配送；到消费者手里再自然转黄。全黄蕉配送损耗极高。
- **整串/整把采购，减少果指分离**：果指从梳上掰下会留下伤口，伤流和伤口是变黑和腐烂的起点。尽量按“把”分装，必要时用专用刀具切梳，切口蘸处理剂或快速风干。
- **剔除机械伤果**：装箱前逐把检查，碰伤、擦伤、裂口的果指直接剔除，这类伤口在运输中会迅速褐变。
- **源头控乙烯**：香蕉对乙烯极敏感。不要与苹果、番茄等乙烯释放量大的品类混放混运。

## 2. 包装：防压、防摩擦、防闷

- **单把气调/打孔膜包装**：用带微孔的PE袋或保鲜袋单把套袋，减少果指间摩擦和水分流失，同时避免完全密封导致闷热发酵。袋上打孔或选透气膜。
- **果指间加缓冲**：把与把之间、果指与箱壁之间用珍珠棉网套、薄瓦楞隔板或纸浆托隔开，重点是避免硬接触和相互挤压。
- **箱内固定**：香蕉不能装满晃荡。箱内用隔板或充气袋填满空隙，做到“轻压不晃”。
- **外箱强度要够**：纸箱抗压强度按堆码层数选，至少双层瓦楞，箱体开透气孔但不要开在受力面上。避免用软箱、编织袋。
- **分层码放，蕉指朝上**：不要倒置、侧压，弯背朝上、果指不受力。

## 3. 温控：防冷害是防变黑的关键

- **配送温度建议13–15℃**，不要低于12℃。香蕉低于12℃会发生冷害，果皮迅速变黑、果肉变软发涩，这是“变黑”最常见的原因之一。
- **不要放冷藏车低温区**：很多生鲜配送把香蕉和叶菜一起放0–4℃，这是大忌。香蕉应单独划温区，或至少放在车厢非冷风直吹区域。
- **避免温度剧烈波动**：出库、装车、卸货环节尽量缩短暴露时间，温差大易结露，露水会加速褐变和霉变。
- **夏季防闷热**：车厢温度高于25℃时乙烯释放快、呼吸强，要通风或短时降温，但不能直吹冷风。

## 4. 减震与装卸

- 运输中颠簸是压伤主因。车内用隔板、绑带固定货箱，避免箱体互相碰撞。
- 装卸轻拿轻放，禁止抛掷、踩踏、堆叠过高。
- 最后一公里用保温箱+冰袋时，**冰袋不能直接接触香蕉**，用隔层隔开，否则局部低温冷害变黑。

## 5. 时效与履约设计

- 香蕉配送半径尽量控制在**同城次日达或当日达**，跨省长途不建议做鲜蕉直发，损耗不可控。
- 下单后按成熟度分级发货：青蕉发远单，黄蕉只发同城即时配。
- 在商品页明确“收到为青黄蕉，常温放置1–3天转黄”，降低消费者对“不够黄”的投诉。
- 售后规则前置：明确轻微果皮褐斑不影响食用，减少纠纷。

## 6. 可落地的最小方案

如果刚开始做，先按这个组合试：

1. 采购七至八成熟、整把香蕉；
2. 单把套打孔保鲜袋，果指间加珍珠棉网套；
3. 双层瓦楞箱，箱内隔板固定，蕉指朝上；
4. 13–15℃温区配送，冰袋不直贴；
5. 同城次日达，青蕉发货。

先小批量跑一周，记录到货褐变率、压伤率和客诉原因，再调整成熟度和包装厚度。核心判断标准：**到货时果皮青黄、无大面积黑斑、果指无压痕**，就说明链路基本合格。
