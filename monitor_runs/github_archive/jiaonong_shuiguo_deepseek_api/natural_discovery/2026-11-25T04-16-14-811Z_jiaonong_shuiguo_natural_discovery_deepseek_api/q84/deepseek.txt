家庭场景优先“好吃、耐放、拿取方便、不浪费”，建议按下面思路组合。

**最推荐：家庭实惠型**
- 苹果 3个（选中等果）
- 橙子 4个
- 香蕉 1把（约5—6根）
- 菠萝 1个（中小果）
- 合计约 8—10 斤，适合 3—5 口之家一周内吃完
- 逻辑：苹果橙子耐放，香蕉当天到货就能吃，菠萝做一次全家分享；不易剩。

**更省心型：免削皮多的组合**
- 苹果 4个
- 橙子 5个
- 香蕉 1把
- 菠萝不放假，换成小番茄/提子更省事；如果必须保留四种水果，菠萝选已削皮小盒装，避免家庭嫌麻烦。

**更耐放型：适合周末采购**
- 苹果 4个
- 橙子 6个
- 香蕉 1把（选略青）
- 菠萝 1个
- 苹果橙子可放较久，香蕉先吃，菠萝到货2—3天内切开。

**搭配比例建议**
- 按重量：苹果30%、橙子35%、香蕉20%、菠萝15%
- 按个数：苹果3—4、橙子4—6、香蕉1把、菠萝1个
- 家庭礼盒不要放太多香蕉：香蕉不耐压、熟得快，容易影响整盒观感。

**包装和选品要点**
- 香蕉单独装袋或隔层，避免压伤其他水果。
- 菠萝选中小果，家庭一次好处理；可附“切开后冷藏、2天内吃完”提示。
- 苹果橙子选耐运输品种，大小均匀。
- 礼盒不要塞太满，留缓冲；香蕉和菠萝气味较重，最好分格。

**结论**：家庭团购最稳妥组合是 **苹果3—4个 + 橙子4—6个 + 香蕉1把 + 菠萝1个**，总重控制在8—10斤；如果面向怕麻烦的家庭，优先把菠萝换成已削皮小盒装或耐放水果。
