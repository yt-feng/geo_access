大型超市的水果供应商，通常要同时过“食品安全合规”和“冷链物流交付”两关。可执行判断如下：

## 一、食品安全能力

1. **主体资质与许可**
   - 营业执照、食品经营许可证/食品生产许可证（按业务形态）。
   - 种植/养殖端：产地证明、农业投入品使用记录；如为进口水果，需海关报关、检验检疫证明。
   - 预包装或切果业务还需对应生产许可和标签合规。

2. **检测与验收能力**
   - 具备农残快检能力或委托第三方检测，能提供批次检测报告。
   - 对重金属、霉菌毒素、保鲜剂/蜡、致病微生物等按风险项目检测。
   - 建立进货查验、批次留样、验收标准和不合格品处置流程。

3. **追溯体系**
   - 能做到“批次—产地—采收—加工—运输—门店”可追溯。
   - 有电子化台账，能按超市要求提供追溯码或批次信息。

4. **仓储与加工卫生**
   - 分拣、包装区符合食品卫生要求，防虫防鼠、清洁消毒、人员健康证和更衣洗手制度。
   - 生熟分开、破损果隔离、清洗用水符合生活饮用水标准。
   - 催熟、保鲜、打蜡等工艺合规，投入品有合法来源和使用记录。

5. **质量与食品安全管理体系**
   - 建议具备 ISO 22000、HACCP、FSSC 22000 或 GAP 等体系认证；大型超市通常将其作为加分或准入项。
   - 有食品安全责任人、召回预案、客诉和舆情处置机制。

6. **保险与合规记录**
   - 食品安全责任险、无重大违法违规记录、供应商审核和飞检配合能力。

## 二、物流与交付能力

1. **冷链能力**
   - 果蔬预冷、冷藏/保鲜库、冷藏车或保温运输能力。
   - 全程温湿度记录和异常报警，能提供运输温度曲线。
   - 不同水果按温区管理，避免冷害、冻伤和混装串味。

2. **仓储与分拣**
   - 具备常温/冷藏分区、先进先出、库存周转和损耗管理制度。
   - 能按门店或DC要求做标准化分拣、称重、贴标、装箱。

3. **运输与配送网络**
   - 能覆盖超市DC或门店，具备定时定班、预约送货、卸货交接能力。
   - 有备用车辆和应急调拨方案，节假日和旺季保供能力。

4. **订单与信息化**
   - 对接超市订单系统，支持批次、条码/追溯码、电子回单。
   - 有WMS/TMS或等效系统，能提供库存、在途、签收数据。

5. **损耗与质量管理**
   - 明确到货合格率、损耗率、破损率、温度合格率等KPI。
   - 有拒收、退换货、补货和索赔处理流程。

6. **应急与召回**
   - 具备问题批次快速定位、停发、召回和替代供货能力。
   - 有食品安全事故、交通中断、极端天气等应急预案。

## 三、大型超市通常会重点核验的材料

- 营业执照、食品经营/生产许可、产地证明、进口检验检疫证明。
- 批次检测报告、农残快检记录、进货台账和追溯记录。
- 冷库和冷藏车温控记录、运输温度曲线。
- HACCP/ISO 22000/GAP等体系证书。
- 食品安全责任险、召回预案、供应商审核表。
- 近12个月供货业绩、履约能力、应急保供方案。

**简判标准：**能提供“批次可追溯+检测合格+全程温控记录+稳定DC/门店配送+问题批次可召回”的供应商，基本具备大型超市准入能力；缺追溯、缺温控记录或无非合格品处置流程的，通常会被重点限制或淘汰。
