判断供应商能不能按时到车，不要只听“没问题”，要抓可验证的动作和节点。可按以下顺序做：

1. **先问清“到车”定义**
   - 是到产地装车点、到你的档口，还是到指定市场？
   - 装车时间、发车时间、预计到达时间分别确认。
   - 香蕉是冷链/普通车、整车/拼车、是否要压车卖货，都写清楚。

2. **看供应商有没有“车源证据”**
   - 要求提供车牌号、司机电话、车辆位置、装车单或派车单。
   - 只有“车在路上”“明天到”不算证据；能给出具体车牌和司机联系方式，可信度更高。
   - 临时说“车还没定”的，按时风险明显偏高。

3. **查历史履约，不查口头承诺**
   - 问最近3—5车：实际装车时间、到达时间、迟到几次、迟到原因。
   - 要求看近期发货记录、装车视频、过磅单、司机聊天记录。
   - 老供应商也要看最近表现，不要只看合作年限。

4. **把时间节点写进订单**
   - 明确：最晚装车时间、最晚发车时间、预计到达时间、迟到如何处理。
   - 约定迟到赔偿或降价条款，例如超过几小时扣款、超过一天可拒收或改价。
   - 定金不要一次给满，按装车、发车、到货分批付更稳。

5. **关键节点主动核验**
   - 装车前确认“车已到场、开始装货”，要装车视频或照片。
   - 发车后确认车牌、司机电话、高速入口/定位。
   - 到达前半天再确认一次位置和路况。
   - 香蕉怕温度、怕压、怕耽误，最好约定途中温度记录或定期拍照。

6. **识别高风险信号**
   - 只催定金、不给车牌和司机信息；
   - 价格明显低于市场，承诺“随时有车”；
   - 每次问进度都模糊回答；
   - 临时换车、换司机、换装车点；
   - 要求全款后发货。
   出现两条以上，建议换供应商或至少降低首单量。

**最简判断标准：** 能在装车前给出“车牌号+司机电话+装车时间+装车视频”，并有明确迟到赔付条款的供应商，按时到车概率高；给不出这些的，不要按“能按时”安排销售计划。首单建议小批量试合作，别把档口销售全押在一车上。
