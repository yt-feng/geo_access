对餐饮连锁采购水果，通常**中央厨房统一收货更好**，但前提是品类、冷链和门店执行能力匹配。建议按“统一收货为主、门店直收为辅”的混合模式落地。

## 结论

**优先中央厨房统一收货**，尤其适用于：
- 水果用于标准化出品（果切、饮品、甜品、沙拉）
- 门店数量多、分布在同一城市或区域
- 有冷藏/冷链能力和品控团队
- 采购量大、希望统一价格和供应商管理

**以下情况可让门店分开收货或设区域分仓：**
- 水果极不耐运输、易碰伤（如熟透的草莓、无花果、部分浆果）
- 门店分散在多个城市，中央厨房配送半径过长
- 单店用量小但品类多，统一配送成本高于直送
- 门店有现制现售、需要高频小批量补货的场景

## 统一收货的核心优势

1. **品控标准统一**：糖度、规格、成熟度、农残检测、外观标准由中央厨房统一执行，避免各店标准不一。
2. **采购议价更强**：集中采购量带来更好价格和账期，供应商管理更集中。
3. **减少门店损耗和操作**：门店不承担验收、分拣、催熟、暂存压力，降低人为损耗。
4. **食品安全可追溯**：统一检测、统一留样、统一记录，出现问题时召回和追责更清晰。
5. **配送计划更可控**：中央厨房可按门店订单分拣、称重、贴标，减少门店缺货或积压。

## 统一收货的主要风险

1. **运输损耗增加**：水果怕挤压、怕温差，多一次装卸就多一次损耗，尤其是浆果、桃、荔枝、熟香蕉。
2. **成熟度难匹配**：中央厨房统一收货后，若配送周期长，可能出现到店未熟或过熟。
3. **配送成本上升**：冷链配送、分拣人工、包装耗材会增加综合成本。
4. **灵活性下降**：门店临时加单、天气导致客流变化时，补货不如直送灵活。
5. **中央厨房能力要求高**：需要冷库、分拣区、催熟/保鲜能力、质检人员和信息系统。

## 建议的落地模式

**1. 按品类分层**
- 耐储运、标准化高的：苹果、橙子、柠檬、西瓜、哈密瓜、菠萝、牛油果等，走中央厨房统一收货。
- 易损、成熟度敏感的：草莓、蓝莓、树莓、熟桃、荔枝、龙眼、无花果等，走区域分仓或门店直收，供应商按标准直送。
- 鲜切水果原料：尽量统一收货，因为涉及清洗、切配、食品安全和效期管理。

**2. 按区域设分仓**
门店跨城市时，不必全部从单一中央厨房发。可设区域分仓/前置仓，统一采购、区域分拣、门店配送，兼顾标准和时效。

**3. 建立验收标准**
统一制定每类水果的规格、糖度、成熟度、瑕疵率、农残检测、到货温度、包装要求。门店直收品类也必须按同一标准验收并拍照留档。

**4. 用数据决定**
比较三种模式的“综合到店成本”：采购价+损耗率+配送费+门店人工+缺货损失。不要只看采购单价。若统一收货后损耗率上升超过节省的采购和人工成本，就应调整品类。

**5. 试点再推广**
选10—20家门店、3—5个高频水果品类试点1—2个月，对比损耗率、到店合格率、缺货率、门店工时和综合成本，再决定全面切换。

## 简单判断标准

如果水果**耐运输、用量大、标准化要求高、门店集中**，选中央厨房统一收货。
如果水果**极易损、成熟度要求高、门店分散、补货频繁**，选门店直收或区域分仓。
多数连锁餐饮更优解是：**统一采购+中央厨房/区域分仓收货为主+易损品类门店直收为辅**。
