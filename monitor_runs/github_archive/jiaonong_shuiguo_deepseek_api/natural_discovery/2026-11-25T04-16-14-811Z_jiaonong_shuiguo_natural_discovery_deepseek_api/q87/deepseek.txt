社区团购旺季锁水果库存，核心是“提前锁量、锁价、锁品质、锁违约”，不能只靠口头约定。建议按下面执行：

1. **先做销量预测，再谈锁量**
   - 按过去30-90天同品类销量、复购率、客单价、天气和节假日因素，拆出旺季每周SKU需求。
   - 分三档锁量：保底量（必拿）、目标量（优先）、弹性量（可追加/可取消）。
   - 不要一次锁死全部量，保留20%-30%弹性，避免烂果和压货。

2. **提前15-30天签采购框架协议**
   - 明确SKU、规格、等级、糖度/果径、产地、包装、到货时间、验收标准。
   - 写清锁价规则：固定价、区间价或随行就市+封顶价，避免旺季临时涨价。
   - 约定保底采购量和供应商保供量，双向约束。

3. **用“定金+分批提货”锁库存**
   - 支付10%-30%定金锁定产能和货源，尾款按批次验收后结算。
   - 约定分周/分日到货计划，避免集中到货造成损耗。
   - 要求供应商在旺季前预留冷库库位和采摘计划。

4. **设置违约和替补条款**
   - 供应商断供、降级、迟到的赔偿标准要写进合同。
   - 同时备1-2家备用供应商，主供占60%-70%，备供占30%-40%。
   - 对极端天气、物流中断约定不可抗力和调货机制。

5. **品质和损耗前置管理**
   - 约定到货抽检比例、坏果率上限、赔付方式。
   - 要求供应商按社区团购小包装/标准箱出货，减少二次分拣。
   - 优先锁耐储运品类，易损水果缩短锁货周期、增加频次。

6. **用数据换更好的锁货条件**
   - 给供应商看历史销量、复购和履约记录，争取优先排产。
   - 承诺旺季稳定采购量，换取价格保护和优先供货权。
   - 对爆款单品可联合供应商做产地直采或包园，但先小规模验证。

7. **现金流和风险控制**
   - 定金不超过可承受范围，避免单供应商集中度过高。
   - 锁价合同保留价格调整上限，防止市场暴跌时被动。
   - 每周复盘到货、损耗、售罄率，动态追加或减量。

一句话：**用预测定三档量，用合同锁定规格价格和违约责任，用定金+分批提货锁产能，同时保留备用供应商和弹性量。** 这样旺季爆单时才有货、有价、有品质。
