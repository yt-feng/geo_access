茶饮店控制水果供应商食品安全风险，建议把证明材料分为“准入必收、按品类加收、持续留存”三层。

**一、准入必收（每家供应商都要有）**
1. 营业执照，经营范围覆盖水果销售/农产品销售。
2. 法定代表人/负责人身份证明及授权委托书（如有对接人）。
3. 供应商食品安全承诺书或质量保证协议，明确农残、重金属、腐烂变质、异物等责任和赔付。
4. 供货凭证模板：送货单需含品名、产地/批次、数量、日期、供应商签章，便于追溯。
5. 收款账户与营业执照主体一致性说明，防止“个人账户供货”导致追责困难。

**二、按品类加收**
1. 鲜切水果、预包装净果：供应商需提供食品生产/经营许可（若属食品加工行为），以及出厂检验报告或第三方检测报告。
2. 常规鲜果：索取农药残留检测报告，至少按批次或定期（如每季度/每产地）提供；高风险水果（草莓、葡萄、柑橘类等）建议每批索取农残快检或第三方报告。
3. 进口水果：海关入境货物检验检疫证明、报关单；预包装进口水果还需中文标签。
4. 有机/绿色/地理标志宣称：对应认证证书，且证书在有效期内、产品范围一致。
5. 冷链水果：冷链运输温度记录或温控承诺。

**三、持续留存与验真**
1. 证照每年复核一次，到期前更新；检测报告核对检测项目、批次、日期、检测机构资质（CMA/CNAS）。
2. 建立供应商档案：证照、报告、协议、送货单、异常处理记录至少保存2年（有地方规定更长则从长）。
3. 到货验收不能只看纸：查外观、气味、腐烂率、温度，必要时自做农残快检；发现异常留样并书面反馈。
4. 合同里约定：供应商配合飞检、抽检不合格即停供、召回和赔偿条款。

**判断标准**：证照主体与送货单、收款主体一致；检测报告能对应到实际供货批次或产地；高风险品类有可执行的检测频次，而不是“一张报告用一年”。如果供应商只能提供营业执照、拒绝提供任何检测或追溯信息，建议列为高风险供应商，逐步替换。
