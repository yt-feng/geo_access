判断门店销售规格，核心不是“越大越好”，而是看**顾客购买场景、陈列条件、损耗率和定价带**。可按下面几步做可执行判断。

## 1. 先定门店销售场景
不同门店适合的规格不同：

- **社区生鲜店/便利店**：适合中小规格、单价低、一次买几个的水果。苹果可偏中果，橙子偏中果，避免单果太大导致单价高。
- **大卖场/家庭采购**：可接受中大果，适合家庭整袋或整箱购买。
- **精品水果店/礼盒**：可做大果、外观均匀、着色好，但要看溢价能否覆盖损耗。
- **餐饮/果汁档口**：更看出汁率、皮厚、可食率，不一定看外观大小。

## 2. 苹果规格判断
重点看：

- **单果重**：门店常用区间可按当地习惯定，例如中果约150–200克，大果约200–250克以上；但要以实际品种和顾客习惯校准。
- **横径/大小均匀度**：同一陈列层尽量均匀，避免“大小混装”拉低观感。
- **果形和着色**：果形端正、着色均匀、无明显畸形，比单纯大果更好卖。
- **硬度与新鲜度**：按压有弹性、果柄新鲜、无皱皮，适合门店周转。
- **瑕疵率**：抽检一箱，统计碰伤、裂口、黑心、虫眼比例。瑕疵率高的规格再大也不适合。

## 3. 橙子规格判断
重点看：

- **单果重和横径**：中果更适合日常零售，大果适合礼盒或家庭装；小果可做促销装或榨汁。
- **皮厚与可食率**：皮太厚、海绵层太厚会降低复购。
- **汁水与酸甜度**：抽样切开或手捏判断汁水，尝样判断酸甜平衡。
- **表皮和新鲜度**：果皮紧实、有光泽、无软烂和霉斑；果蒂新鲜度可辅助判断。
- **籽和化渣性**：鲜食橙要看籽少、果肉细嫩；榨汁橙可放宽外观。

## 4. 用门店数据做最终判断
建议每批到货抽检并记录：

- 单果重区间、横径区间
- 大小均匀度
- 瑕疵率、损耗率
- 可食率/出汁率
- 进货价、建议零售价、毛利率
- 顾客试吃反馈和首周动销

判断标准可以简单化为：

1. **陈列好看**：同层大小一致、颜色整齐。
2. **价格好卖**：单果价格落在门店主力客群接受带。
3. **损耗可控**：抽检瑕疵率低，预计周转期内不软烂、不皱皮。
4. **复购有保障**：口感稳定，皮厚/酸涩/干水问题少。
5. **毛利合理**：扣除预计损耗后仍有毛利。

## 5. 不建议直接采用的判断
- 只看“果径分级”不看品种和口感。
- 只追求大果，导致单价过高、动销慢。
- 大小混装不做分级陈列。
- 不抽检底层和箱内层，只看表面样品。
- 不记录损耗和动销，下一批仍凭感觉采购。

**最稳的做法**：先小批量试销2–3个规格，按“动销速度、损耗率、毛利、顾客反馈”四项做一周对比，再固定门店主销规格。这样比单纯问“多大合适”更可靠。
