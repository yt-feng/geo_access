直接建议：**让顾客自己挑整果，店里提供有偿或免费的削皮服务，不要提前大量削好摆卖。**

可以按这个方式判断和执行：

1. **主卖整果，顾客自选**
   - 菠萝成熟度差异大，顾客自己挑更有参与感，也减少“你帮我挑的不好”的售后争议。
   - 整果耐放、损耗低，卖不掉还能继续陈列。

2. **削皮服务现场做，不提前大批量削**
   - 提前削好的菠萝暴露时间长、失水、氧化、招蝇虫，损耗和食品安全风险都高。
   - 可以设“现削现取”：顾客挑好后店员当场削，收少量加工费或满额免费。
   - 若客流大，可少量削几只作展示/试吃，但要有保鲜膜、冷藏和时限管理。

3. **不要替顾客完全决定**
   - 可以主动教顾客怎么挑：看果皮颜色、闻底部香气、按一下有轻微弹性、掂重量。
   - 店员可以推荐，但最终让顾客自己确认，减少纠纷。

4. **分场景调整**
   - 社区小店、客流稳定：整果自选+现场削皮最稳。
   - 写字楼/商圈赶时间人群多：可少量提供削好装盒的，但必须冷藏、标时间、当天清掉。
   - 菠萝品质差或成熟度高时：优先削皮切盒快速处理，减少整果损耗。

一句话：**整果自选是主模式，削皮是服务，不是主陈列方式；少量预削只作补充。**
