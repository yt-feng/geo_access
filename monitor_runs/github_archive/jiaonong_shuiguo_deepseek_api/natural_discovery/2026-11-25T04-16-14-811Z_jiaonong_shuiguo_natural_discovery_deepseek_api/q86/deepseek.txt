做生鲜水果一件代发，供应商不能只会“发货”，核心要能支撑 **小单、多SKU、高频、时效、低损耗、可追溯**。建议按下面几项仓配能力逐项核验供应商。

## 1. 仓储能力
- **生鲜专用仓/温控仓**：至少具备常温、冷藏分区；浆果、荔枝、樱桃等需冷藏或冷链。要确认是否有温度监控和异常报警。
- **多SKU分区分储**：按品类、温层、周转速度分区，避免混放串味、压伤。
- **库存准确率**：要求库存准确率≥99%，支持实时库存同步，避免超卖。
- **先进先出/批次管理**：水果保质期短，必须按批次、采摘/入库日期管理，支持临期预警。
- **质检与分级能力**：入库验货、糖度/果径/外观分级、次果剔除；一件代发最怕“以次充好”导致售后。
- **打包能力**：防撞、防压、透气、冰袋/保温箱配置，能按品类输出标准包装方案。

## 2. 订单与系统能力
- **支持一件代发作业**：能接单、打单、拣货、复核、贴单、出库全流程，不是传统整箱批发模式。
- **系统对接**：能对接平台ERP/OMS/WMS，至少支持API或表格批量导入；订单、库存、物流单号回传及时。
- **多平台面单兼容**：支持主流快递电子面单，能处理平台订单标识、隐私面单。
- **异常订单处理**：缺货、地址异常、改单、拦截、退款回传有明确流程。
- **日单量弹性**：确认日常单量、峰值单量、爆单扩容能力，以及大促/节日排产计划。

## 3. 配送与时效能力
- **快递资源稳定**：有合作快递及备选快递，能按区域选择时效；生鲜需优先空运/冷链线路。
- **发货时效承诺**：例如16点前订单当日发、次日发比例、48小时揽收率，要有可考核指标。
- **冷链/保温方案**：按品类和季节配置冰袋、保温箱、泡沫箱；高温季和远距离线路要有验证。
- **区域覆盖与时效表**：明确哪些省份可发、哪些偏远地区不发或加价，避免下单后才发现超区。
- **物流异常处理**：破损、延误、丢件、温度失控的理赔和补发机制。

## 4. 品控与售后能力
- **到货损耗率承诺**：按品类约定可接受损耗率和赔付标准。
- **售后响应时效**：坏果、少件、压伤等问题的举证、判责、补发/退款时限。
- **溯源能力**：批次可追溯到产地、入库时间、质检记录，便于处理客诉。
- **召回/拦截能力**：发现批次质量问题能快速锁定库存、拦截在途订单。

## 5. 仓配运营指标
建议在合作前要求供应商提供或承诺：
- 库存准确率 ≥99%
- 订单按时出库率 ≥98%
- 发货错误率 ≤0.5%
- 48小时揽收率 ≥95%（按区域约定）
- 生鲜售后率/损耗率按品类设上限
- 客诉响应 ≤2小时，补发/赔付 ≤24-48小时

## 6. 合作前必须实地或视频核验
- 看仓库温区、打包区、待发区是否分区清晰；
- 抽测打包：模拟一单易损水果，看包装和冰袋配置；
- 查系统：库存是否实时、订单能否自动回传；
- 试发：先小批量试单，覆盖近/中/远区域和高温天气；
- 看资质：营业执照、食品经营/生产相关资质、产地证明、检测报告。

**一句话判断标准**：供应商能稳定做到“小单可发、库存准、打包稳、时效可控、坏果有赔付、系统能对接”，才适合做水果一件代发；只有产地货源和快递折扣、没有生鲜仓配作业能力的，不建议直接合作。
