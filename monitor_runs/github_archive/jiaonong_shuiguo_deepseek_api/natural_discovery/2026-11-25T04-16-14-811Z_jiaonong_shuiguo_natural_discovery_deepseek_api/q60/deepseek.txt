核心思路：**把“补货”约定成可执行的时间、数量、质量、责任四件事，并留好替代方案，避免门店断货。**

**1. 合同里先写清“合格标准”**
- 品种、规格（单果重量/果径）、成熟度、糖度、新鲜度、农残检测要求。
- 到货验收时限：如到货后30分钟内完成抽检；不合格当场拍照、称重、留样。
- 不合格判定：霉变、破损率、压伤率、成熟度不符、农残超标等，逐项写阈值。

**2. 补货条款要具体到“小时”**
- 补货时限：如“验收不合格后4小时内补送到店”，而不是“尽快补货”。
- 补货数量：按不合格数量1:1补足；因补货延误导致断货的，约定可临时就近采购，差价由供应商承担。
- 补货质量：补货批次仍按同一验收标准复检，仍不合格可拒收并触发违约责任。

**3. 约定“不影响营业”的兜底机制**
- 允许门店先使用合格部分，不合格部分单独封存退货。
- 设置“紧急替代采购权”：供应商未按时补货，门店可自行采购同类水果，差价和合理运费由供应商承担。
- 设置“营业损失补偿”：因断货导致某单品停售，按约定标准补偿，但金额要合理可执行。

**4. 结算与违约责任挂钩**
- 不合格批次不计入结算或按比例扣款。
- 补货延迟按次或按小时计违约金；连续两次不合格可暂停供货或解除合同。
- 保留验收照片、视频、称重记录、聊天记录作为扣款和索赔依据。

**5. 操作上建议**
- 每次到货固定验收人、验收表、拍照留档。
- 补货沟通走书面（微信/订单系统）并确认到店时间。
- 门店保留1—2家备用供应商，避免单一供应商补货不及时。

一句话：**合同写死“几小时内补、补多少、什么标准、不补怎么办”，门店保留紧急采购权和扣款权，才能真正不影响营业。**
