超市采购水果时，建议按“供应商资质 + 批次合格证明 + 进货票据 + 重点风险项报告”四类索取，具体如下：

1. 供应商主体资质
- 营业执照
- 食品经营许可证（或食品生产/流通相关许可，视供应商性质）
- 若为进口水果，还需海关报关单、入境货物检验检疫证明

2. 批次合格证明
- 该批次水果的出厂检验报告或供货商自检报告
- 农产品承诺达标合格证（适用于食用农产品，很多地区已推行）
- 若供应商为批发市场商户，可要求提供市场快检合格凭证或产地证明

3. 进货票据与追溯材料
- 供货合同/订单
- 发票或送货单（注明品名、批次、数量、日期、供应商）
- 产地证明、种植基地信息或采购来源说明，便于追溯

4. 重点风险项检测报告（按需、按风险索取）
- 农药残留检测报告：叶菜、草莓、葡萄、柑橘等高风险品类重点要求
- 重金属检测报告：产地受污染风险较高时索取
- 真菌毒素检测：如苹果汁原料、干果类另论；鲜果一般不作为常规项
- 保鲜剂/防腐剂违规使用相关检测：如蜡处理、二氧化硫等，视品类和加工方式
- 进口水果的检疫处理证明

5. 超市自身应做的验收动作
- 查验并留存上述材料，建立供应商和批次台账
- 每批查验感官、新鲜度、腐烂率、包装标识
- 对高风险品类定期抽检或快检，保留记录
- 发现无合格证、来源不明、检测异常时拒收并记录

简要判断标准：国产鲜果至少应有“营业执照/许可证 + 承诺达标合格证或批次检测报告 + 送货票据”；进口水果必须有“报关单 + 入境货物检验检疫证明”；高风险品类再增加农残检测报告。各地监管要求略有差异，具体以当地市场监管部门规定为准。
