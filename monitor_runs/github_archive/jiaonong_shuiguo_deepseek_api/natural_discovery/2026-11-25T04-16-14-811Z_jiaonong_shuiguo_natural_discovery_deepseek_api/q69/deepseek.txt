香蕉和菠萝分级报价，关键是让小店老板“一眼看懂、按级拿货、按级算钱”。建议用“外观等级 + 规格区间 + 报价单位 + 售后口径”四件事固定下来。

**一、香蕉分级建议**
- **A级**：果指饱满、条直或微弯，无明显黑斑、无机械伤，梳形整齐；适合水果店陈列、礼盒。
- **B级**：轻微斑点或轻微擦伤，成熟度稍不均，不影响食用；适合小店日常零售、切果。
- **C级**：斑点较多、表皮瑕疵明显、大小不匀；适合特价、榨汁、加工。
- 报价单位：按**箱/件**报，同时标明**净重、每箱把数或根数、果指长度区间、成熟度**。例如“A级香蕉，净重12kg/箱，果指18-20cm，7成熟，XX元/箱”。

**二、菠萝分级建议**
- **A级**：果形端正、单果重达标、无裂口、无软烂、冠芽完整、色泽均匀；适合陈列和整果零售。
- **B级**：果形略偏、轻微日灼或小瑕疵、单果重稍小；适合切块、特价。
- **C级**：明显畸形、裂口、熟度不均或小果；适合加工、榨汁。
- 报价单位：按**箱/件**报，标明**净重、果数、单果重区间、成熟度、是否带冠**。例如“A级菠萝，净重10kg/箱，8-10个/箱，单果1.0-1.2kg，XX元/箱”。

**三、报价单写法**
每级写一行：**等级 | 规格（净重/个数/单果重或果指长） | 成熟度 | 单价（元/箱） | 最低起订 | 售后口径**。售后口径要写清：坏果率超过多少补/换、签收后几小时内反馈、是否包退箱损。

**四、避免扯皮的做法**
- 样品封箱：每级留一箱样品，双方确认后贴标。
- 报价有效期写清，比如“本周有效”。
- 同一等级不要混装不同规格，否则小店会按最差果压价。
- 用“等级+规格+价格”三列并排，不要只写“好/中/差”，否则解释空间太大。

这样分级报价，小店老板能按自己的客群选级，你也能减少因“等级理解不同”产生的退换货争议。
