线上卖水果，差评主要来自两类问题：坏果（磕碰、腐烂、过熟）和口感不稳定（酸涩、寡淡、忽甜忽酸）。采购端能做的，核心是把“不可控的产地差异”变成“可筛选、可验证、可追责”的流程。下面按可执行程度给建议。

**一、先定标准，再谈采购**

不要只说“要好的”，要把验收标准写成可量化的条款，写进采购合同或供应商协议：

- **成熟度**：按品种定采摘成熟度区间（如糖度下限、硬度区间、果皮颜色），要求产地按“发货地到客户手中”的运输时长倒推采摘成熟度，而不是统一摘八成熟。
- **糖酸比**：对口感敏感品种（柑橘、葡萄、草莓、桃）设糖度下限和酸度上限，用便携糖度计抽检，写进验收。
- **规格与缺陷率**：明确单果重量区间、允许的机械伤/日灼/裂口比例（如抽检坏果率≤2%），超出即拒收或扣款。
- **批次一致性**：要求同一批次来自同一园区、同一采收期，避免混装导致口感忽好忽坏。

**二、选供应商看“稳定性”而非“最低价”**

- 优先选有分级分选能力的供应商（有分选线、冷库、预冷设备），而不是纯农户直发。
- 考察其**预冷和冷链**：浆果、樱桃、荔枝等采后是否及时预冷，运输是否全程冷链。坏果很多不是产地问题，是采后温度断链。
- 要求供应商提供**历史批次数据**（糖度、坏果率、客诉率），没有数据的先小批量试单。
- 同一品种至少备2家供应商，避免单一产地天气波动导致整批口感崩盘。

**三、采购时的抽检与留样**

- **到货抽检**：按批次随机抽样，测糖度、看硬度、查机械伤和霉变，记录数据。抽检不合格按约定拒收或降级。
- **留样对比**：每批留样，和上一批做口感对比，发现偏差及时反馈供应商，形成“批次档案”。
- **产地直采时**：到园看树势、看采收操作（是否带果柄、是否轻拿轻放）、看分级环节，避免“好果掺次果”。

**四、用包装和物流兜住采购的短板**

采购再好，包装物流不行照样坏果。采购时要同步确认：

- 耐压品种用强度足够的箱体，浆果用吸塑盒+缓冲，避免堆压。
- 按运输距离和季节选择冰袋/保温箱，夏季高温线路要缩短在途时间。
- 和供应商约定**到货时效**，超时批次重点抽检。

**五、口感不稳定的针对性做法**

- 对口感波动大的品种，**不要全年只靠一个产地**，按产区季节轮换，提前锁定下一产区货源。
- 上架前做**小批量试吃**，糖度不达标的不做主推，或调整宣传口径（不承诺“纯甜”）。
- 建立**客诉回流机制**：把差评按“坏果/不甜/酸/大小不符”分类，反推到具体批次和供应商，作为下一轮采购的筛选依据。

**一句话总结**：采购端减少差评，靠的是“量化验收标准 + 有冷链能力的稳定供应商 + 批次抽检留样 + 包装物流配套 + 客诉反推采购”。先把糖度和坏果率两个指标管住，差评会明显下降。
