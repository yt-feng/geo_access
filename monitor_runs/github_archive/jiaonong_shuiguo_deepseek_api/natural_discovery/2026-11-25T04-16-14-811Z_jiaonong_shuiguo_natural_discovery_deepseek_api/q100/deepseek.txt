# 学校食堂采购香蕉：避免熟过头浪费的实操建议

核心思路：**控制采购节奏 + 按成熟度分级使用 + 用物理手段放慢后熟**。香蕉是呼吸跃变型水果，采后仍会集中释放乙烯、快速后熟，靠"少买、分批、分开、快用"四招最有效。

## 一、采购环节：少量多次，按用量算

- **改大批量为小批量高频**：按食堂实际日均消耗量下单，每次采购量控制在 **2–3 天用量**，避免一次囤一周。
- **按颜色分级下单**：要求供应商按成熟度分档供货，大部分要 **青黄（7–8成熟，绿尖黄身）**，只少量要即食黄熟果。
- **错峰到货**：一周内分 2–3 次到货，而不是一次到齐，让后熟的"波峰"分散。
- **与供应商约定**：明确到货成熟度标准，过熟果可拒收或换货。

## 二、储存环节：抑制后熟

- **不要整串挂着放**：把香蕉**拆开单根存放**，能显著减慢后熟（乙烯在果柄处集中释放）。
- **包裹果柄**：用保鲜膜包住香蕉根部/果柄，减少乙烯扩散。
- **远离其他果蔬**：香蕉释放乙烯会催熟苹果、蔬菜等，同时其他果蔬的乙烯也会催熟香蕉，**单独分区存放**。
- **温度控制**：存放于 **12–15℃ 阴凉通风处**，不要放冰箱冷藏（低温会冻伤发黑），也不要暴晒、靠近热源或灶台。
- **青果与熟果分开**：把已黄的挑出来单独放、优先用，避免"一颗黄带黄一串"。

## 三、使用环节：按成熟度分级消耗（关键）

建立"**先熟先用**"的调度规则，把不同成熟度的香蕉分配到不同用途：

| 成熟度 | 状态 | 优先用途 |
|---|---|---|
| 青黄 | 硬、微绿 | 储备，继续后熟 |
| 黄熟 | 软硬适中 | 直接发放/果盘 |
| 过熟（表皮有黑点、发软） | 甜度高但易烂 | **当天做香蕉奶昔、香蕉面包/蛋糕、香蕉粥、烘焙** |

- 设"**临期香蕉专用加工位**"：每天检查，把将过熟的挑出，转做香蕉牛奶、香蕉饼、拔丝香蕉等，变废为用。
- **每日盘点一次**：早间检查成熟度，定当天"必须消耗"的清单。
- 就餐高峰（如早餐、加餐）优先摆出熟度高的，减少积压。

## 四、管理机制

- **建立消耗台账**：记录每日进货量、领用量、剩余量，据此动态调整下次采购量。
- **按人数估算**：一般每人每次约 1 根（100–150g），按实际就餐人数×供应频次下单。
- **设置安全库存**：保留 1 天用量的缓冲即可，不追求"仓库满"。
- **责任到人**：指定专人负责香蕉的验收、分拣、催用，避免"没人管、烂了才扔"。

## 一句话总结

**少量多次采购、拆串包柄阴凉存、按成熟度分级用、过熟当天转加工**——把"等它坏"变成"赶在坏之前用掉"。
