判断“合理波动”不能只看涨跌幅度，要建立一套可核查的对照和规则。给你一套可直接落地的方法：

## 1. 先区分“波动类型”
每天变价通常来自四类原因，判断标准不同：

| 类型 | 典型表现 | 合理性判断 |
|---|---|---|
| 季节性/产地周期 | 某品类整体缓慢涨跌，持续数周 | 对比往年同期和主产区行情，缓涨缓跌合理 |
| 天气/灾害 | 短期急涨，集中在某产区或某品类 | 核实产区天气、交通、灾情，急涨后往往回落 |
| 节日/集中采购 | 节前普涨、节后回落 | 看是否全品类同步、是否可预期 |
| 供应商自身调价 | 只有该供应商涨，或涨跌无规律 | 重点核查，要求书面说明成本依据 |

**关键判断：** 同一品类如果市场上多数供应商同向变动，属行业波动；只有一家逆势大幅调价，属个体行为，要质疑。

## 2. 建立“三方比价”机制
每天或每周固定采集：
- **至少3家供应商**同品类、同等级、同规格报价；
- **一个公开行情基准**（如当地批发市场均价、农业农村部/商务部门发布的农产品价格信息、主产区收购价）；
- **自己的历史采购价**（近30天、去年同期）。

计算偏离度：  
`偏离度 = (供应商报价 - 三方均价) / 三方均价`  
建议设阈值：**±5%以内视为正常，5%–10%要求说明，超过10%暂停下单并复核**。阈值按品类调整，叶菜波动大，根茎类、苹果等耐储品应更稳定。

## 3. 要求供应商提供“调价依据”
在合同或框架协议中约定：
- 涨价需提前书面通知，并附产地收购价、物流成本、包装成本等依据；
- 同一规格、同一等级才可比价，防止用“等级变化”掩盖涨价；
- 设置价格联动公式，例如：`结算价 = 基准价 × (1 + 产地指数变动率)`，把随意报价变成可计算规则。

## 4. 用“异常信号”快速识别不合理
出现以下情况要警惕：
- 连续多日单向上涨，但公开行情平稳；
- 涨价比产地收购价涨幅明显更大，且无物流/人工成本说明；
- 同一供应商对不同客户报价差异大；
- 报价频繁但实际供货等级下降（变相涨价）；
- 只口头报价、拒绝书面确认。

## 5. 实操建议
- **短周期品类**（叶菜、草莓等）：每日比价，设±10%预警；
- **耐储品类**（苹果、土豆、洋葱）：周度比价，设±5%预警；
- **大宗采购**：签价格联动条款，锁定基准和调整机制；
- **保留记录**：每天报价截图、比价表、调价说明存档，出现争议时有据可查。

一句话：**合理波动 = 可解释的原因 + 与市场同向 + 幅度在阈值内 + 有书面依据**。四条同时满足才接受，缺一条就要求供应商说明或切换备选供应商。
