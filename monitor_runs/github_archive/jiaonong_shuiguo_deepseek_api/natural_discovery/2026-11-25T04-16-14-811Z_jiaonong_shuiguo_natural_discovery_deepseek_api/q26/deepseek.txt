小包装香蕉最容易死在两个环节：包装选错导致压伤/闷熟，以及订货规格和动销不匹配导致批量发黑。采购时建议按下面逐项卡。

**一、先定小包装形态**
- 优先做 **2–3根装、约400–600g**，适合单人/小家庭；不要一开始上1根装，人工和包材摊不下来。
- 香蕉要按**成熟度分开卖**：青黄果做“可放2–3天”，黄熟果做“即食特价”，不要混装，否则顾客买回去要么太生要么已过熟。

**二、包装材料注意**
- 用**带透气孔的食品级PE袋或微孔保鲜袋**，不要完全密封。香蕉呼吸强度高，密封易闷出水汽，表皮发黑、果柄长霉。
- 袋上开孔要均匀，别只开一两个大孔；采购前让供应商提供包装样品，做24小时回温观察。
- 托盘建议用**浅底PET/PP托**，香蕉不要被托盘边卡住；托盘深度过深会压伤果指。
- 标签贴在袋面或托盘侧面，**不要直接贴在香蕉表皮**，撕标会伤果皮。
- 若做礼盒/组合装，香蕉不要和苹果、梨等释放乙烯的水果混放，否则催熟过快。

**三、采购规格要写进订单**
- 明确**果指长度、每把根数、单把重量范围**，例如“每把2–3根，单把450–600g，果指长度14–18cm”。
- 明确**成熟度**：到店时果皮颜色、果柄状态、有无机械伤。建议采购**7–8成熟**，到店后自然转黄，不要进全黄果做小包装。
- 要求供应商**按把分切、切口平整**，切口不整齐易褐变和感染。
- 约定**到货温度**和运输方式，香蕉忌低温，运输不要低于13℃左右，避免冷害后发黑。

**四、损耗控制要点**
- **少量高频订货**：小包装香蕉动销慢，首单按3–5天销量试水，宁可补货不要压库。
- **先进先出+按成熟度分区陈列**：黄熟果放前台快销区，青黄果放后排；每天挑出黑点果做折扣或加工。
- **不要提前全部分装**：到店先整把存放，按预估当日销量分装，减少袋内水汽和压伤。
- **陈列不要堆叠超过2层**，小包装之间留缝隙；避免放在冷柜出风口或阳光直射处。
- **控制袋内水汽**：发现袋内有明显水珠，及时换袋或开孔，否则果柄和接触面易霉。
- **设置损耗台账**：按“到货把数—分装袋数—售出袋数—报损袋数”记录，连续一周就能判断包装规格和订货量是否合理。

**五、采购谈判时可加的条件**
- 要求供应商**提供小包装样品和透气袋规格**，先小批量试销。
- 约定**机械伤、果柄霉变、过熟果的退换比例**，到货当场抽检。
- 问清**分切后保质期**和推荐存放条件，别只听“能放几天”，要落到温度和包装上。

一句话：小包装香蕉采购的核心是**透气包装、按成熟度分装、小批量高频补货、陈列不压不闷**。先试2–3根装，用一周损耗数据再定是否扩品。
