第一次找水果供货商，建议按“少量、多批次、可退换、先验后放量”的方式试单，别一上来压大货。

**试单前先定规则**
- 每个供货商先试 2～3 次，不要只试一次就定长期。
- 首单每样控制在半天到一天销量：香蕉 1～2 箱、苹果 1～2 箱、橙子 1～2 箱，按你店实际客流调整。
- 提前说清：坏果率怎么算、能不能换、损耗谁承担、送货时间、结款方式。
- 要求供货商当面过秤、开单，注明品种、规格、产地、单价、件重。

**三类货的试单重点**
- 香蕉：最看成熟度和催熟稳定性。试单要问“到店是几成熟、几天能卖完、青蕉能不能换”。首单别拿太熟的，拿一箱偏青、一箱可售的对比。
- 苹果：看大小是否均匀、硬度、碰伤和果面。试单时随机翻箱底，别只看上面一层；问清规格是 80/85 还是混装。
- 橙子：看皮厚、干水、酸度、大小和坏果。试单切开几个尝，问清是当季鲜果还是库存货，运输有没有冻伤。

**到货验收怎么做**
- 当场抽检：每箱随机翻 3～5 层，记录坏果、碰伤、软果数量。
- 拍照留证：箱体、标签、过秤重量、坏果特写。
- 超过约定坏果率当场拒收或要求补换，别先签字后扯皮。
- 首单不要现金全结，尽量“验货后结”或留少量尾款。

**试单后怎么判断**
- 连续 2～3 次：到货时间稳、损耗在约定内、换货痛快、价格不是最低但算上损耗更划算，就可以逐步加量。
- 如果第一次就出现压货、混级、坏果不认、临时涨价，直接换下一家。
- 常见货至少留 2 个备选供货商，香蕉和橙子最好各留一个备用，避免断货。

**一句话原则**：首单小、验货严、票据清、换货快；先比“综合损耗成本”，别只比报价。
