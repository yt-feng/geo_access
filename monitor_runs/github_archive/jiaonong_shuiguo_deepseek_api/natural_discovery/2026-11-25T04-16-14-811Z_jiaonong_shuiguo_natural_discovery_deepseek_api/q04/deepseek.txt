直接按“熟度分级+到货窗口+验收动作”去要求供应商，别只说“要生一点”或“要熟一点”。

**1. 采购时明确熟度**
香蕉建议按色卡/催熟阶段订货，要求供应商写明：

- **默认主力货：3.5～4.5成熟**  
  适合水果店2～4天内陆续销售，表皮偏绿、棱角明显、无黑斑。
- **马上要卖/促销堆头：5成熟左右**  
  表皮黄绿、少量转黄，适合1～2天内卖完。
- **不要默认发6熟以上**  
  除非当天做促销、切果盘或已知销量很好，否则高温天很容易次日就出黑斑。
- **要求“同批次熟度一致”**  
  避免一箱里有的青、有的黄，导致后熟不齐、坏的先坏。

采购单上最好写清楚：**“香蕉到货熟度3.5～4.5成，色卡验收；批次内熟度差不超过半成；无机械伤、无黑斑、无烂指。”**

**2. 明确到货时间**
要求供应商按你门店的销售节奏到货：

- **优先要求上午开门前1～2小时到货**，当天能上架、能分拣。
- **避开下午高温时段到货**，尤其夏季，减少运输闷热催熟。
- **每周分2～3次小批量到货**，比一次大批量更稳，特别是销量一般的店。
- **节假日/高温天提前锁量**：要求“按日分批到，不一次性压货”。
- **到货前确认发车熟度**：让供应商发货当天拍照或报熟度，发现偏熟可要求换批次或减量。

**3. 验收和合同要求**
到货现场按这几点验：

- 抽箱看色卡，偏熟超过约定就**拒收或折价**。
- 摸温度：运输车厢闷热、果体发热的要谨慎。
- 看有没有**水烂、压伤、黑斑、断指**。
- 要求供应商承诺：**到货后24小时内出现非门店原因的大面积快速转黄/黑斑，可换货或补差**。

**4. 门店配合动作**
- 到货后立刻**开箱通风、散堆、分级**，不要整箱闷着。
- 按熟度分“今天卖/明天卖/促销用”，先进先出。
- 香蕉不要放冷柜，放阴凉通风处；夏天可适当缩短订货周期。

一句话采购要求可以这样发给供应商：  
**“香蕉要3.5～4.5成熟，色卡验收，批次熟度一致，无黑斑无压伤；上午开门前到货，高温天分2～3次小批量送；到货偏熟或24小时内异常快熟，按约定换货/折价。”**
