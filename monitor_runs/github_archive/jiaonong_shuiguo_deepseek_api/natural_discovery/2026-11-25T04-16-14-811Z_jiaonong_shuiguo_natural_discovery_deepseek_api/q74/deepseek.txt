做餐饮客户，核心不是“多上几个规格”，而是按餐饮用途分层备货，让档口能稳定供、客户能少损耗。菠萝和香蕉建议这样准备：

## 菠萝：按“加工方式+成熟度”分规格

餐饮客户主要分三类用途：鲜切果盘/甜品、烘焙/饮品、后厨烹饪。

**1. 鲜切果盘、甜品店、奶茶店**
- **大果、果形端正、单果1.2–1.5kg左右**：出肉率高，适合切块、切片。
- **成熟度7–8成**：到店后1–2天可用，适合有冷库或稳定周转的客户。
- **成熟度8–9成**：适合当天或次日就要用的客户，但损耗风险高，不建议大量压货。
- **去皮小果/二级果**：可做低价引流规格，适合榨汁、果酱、员工餐，不建议作为主推。

**2. 烘焙、果酱、餐饮后厨**
- **统货中大果**：对果形要求低，重点看出肉率和价格。
- **偏生果7成熟**：适合需要去皮切丁后加工、对酸甜度有要求的客户。
- **熟果8–9成熟**：适合即用型果酱、烘焙馅料，但要控制到货节奏。

**3. 饮品客户**
- **单果1.0–1.3kg、酸度稳定、纤维少**的规格更稳。
- 可额外准备**去皮菠萝块/半成品**，但要看档口是否有加工条件。

**建议档口常备：**
- 主推：中大果7–8成熟，走量。
- 辅助：大果8–9成熟，供鲜切急用。
- 引流：二级果/小果，供榨汁和后厨。

## 香蕉：按“成熟度+果指大小+串型”分

餐饮用香蕉主要是：早餐店、甜品店、奶茶店、烘焙、果盘、员工餐。

**1. 甜品、奶茶、果盘**
- **果指中大、串型整齐、无机械伤**：卖相好，适合直接出品。
- **成熟度5–6成**：适合档口周转和配送，到店后自然催熟。
- **成熟度6–7成**：适合次日或当天用，餐饮客户更愿意接。
- **熟蕉7–8成**：适合即用型客户，但货架期短，要控制量。

**2. 烘焙、香蕉泥、饮品**
- **中果/统货**：对串型要求低，重点看出肉率和成熟度。
- **7–8成熟**：适合打泥、做馅、做奶昔，香气足。
- **过熟蕉**：可做低价加工规格，但必须明确到货时间和使用场景，避免客户拿去当鲜果卖。

**3. 早餐、食堂、员工餐**
- **中果统货、成熟度6–7成**：价格稳、耐周转。
- 不建议给这类客户推太熟的蕉，损耗和投诉都高。

**建议档口常备：**
- 主推：中果6–7成熟，串型整齐，走餐饮配送。
- 辅助：中大果7–8成熟，供甜品饮品即用。
- 加工：统货/过熟蕉，供烘焙打泥，低价但明确用途。

## 档口落地建议

1. **不要只按“大中小”分，要按“用途+成熟度”分。** 餐饮客户最怕今天到的能用、明天到的不能用。
2. **菠萝重点看出肉率和成熟度，香蕉重点看成熟度和串型。**
3. **给餐饮客户报价时，最好绑定使用场景**：鲜切、榨汁、烘焙、后厨，不同场景接受度不同。
4. **先小批量试供**：每个规格先备1–2个周转量，观察客户复购和损耗，再放量。
5. **明确售后边界**：熟度、到货时间、储存条件提前说清，避免熟果损耗扯皮。

简单说：菠萝备“中大果7–8成熟主推、大果8–9成熟急用、二级果加工”；香蕉备“中果6–7成熟主推、中大果7–8成熟即用、统货过熟做加工”。这样比单纯报规格更容易打进餐饮客户。
