先给判断口径：**坏果责任原则上按“交付时风险转移”划，但生鲜水果有特殊性，不能一刀切。核心看三点：坏果是“交付前已存在/运输温控不当造成”，还是“交付后顾客储存不当造成”；顾客是否及时验货并留证；平台/商家是否对易腐商品做了充分提示和售后承诺。**

可直接执行的划分建议如下：

1. **签收前/当面验货发现坏果**
   - 责任在商家或配送方。
   - 处理：拒收、换货、退款或按坏果比例赔付。
   - 配送方野蛮装卸、超时配送、冷链断链导致变质的，商家先对顾客负责，再向配送/仓储方追偿。

2. **签收后短时间内发现坏果**
   - 生鲜通常不支持“七天无理由”，但不等于商家免责。
   - 若顾客在合理时间内开箱、拍照/录像，能证明坏果与到货状态相关，商家应承担售后。
   - 合理时间可由平台规则或商家承诺确定；没有明确约定时，按水果品类和季节判断，越易腐要求越及时。
   - 商家不能仅以“生鲜不支持退换”拒绝质量问题。

3. **顾客延迟验货或储存不当**
   - 如签收后长时间未开箱、未冷藏、暴晒、挤压、自行分装导致变质，责任在顾客。
   - 商家已明确提示储存方式和验货时限的，顾客举证责任更重。

4. **部分坏果**
   - 不建议简单“全赔或全不赔”，按坏果数量/重量比例退款或补发更合理。
   - 少量个体差异、轻微磕碰不等于质量问题；腐烂、霉变、异味、明显压烂应认定为坏果。

5. **平台责任**
   - 平台自营的，平台承担销售者责任。
   - 第三方商家的，平台一般承担审核、规则和协助维权责任；商家失联或平台承诺“坏果包赔”的，平台应按承诺先行处理。

6. **举证与操作建议**
   - 顾客：开箱即拍全景、坏果特写、快递面单和称重照片，保留原包装，及时申请售后。
   - 商家：留存出库质检、冷链温控、包装和配送记录；售后规则写清验货时限、赔付比例和例外情形。
   - 争议大时：按坏果比例协商；协商不成走平台介入或消费者投诉。

一句话总结：**交付前和运输温控问题商家担责，交付后顾客储存不当顾客担责；短时开箱有证据的坏果，商家应售后；部分坏果按比例赔，不搞全有全无。**
