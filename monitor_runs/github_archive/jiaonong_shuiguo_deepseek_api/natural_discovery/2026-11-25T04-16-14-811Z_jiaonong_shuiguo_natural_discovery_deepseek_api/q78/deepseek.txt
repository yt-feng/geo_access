做高损耗水果团，核心思路是**把控损前置到选品、到货和交付话术里**，而不是靠售后补救。香蕉和菠萝的损耗机理不同，要分开处理。

## 香蕉：控制成熟度和交付节奏

**选品与到货**
- 不要团全熟香蕉，选**七八成熟、青转黄阶段**的货，到货后还有2-3天货架期。
- 到货当天抽检：看有没有黑斑、软塌、断把。断把和黑斑多的批次直接降级，不要按正常品发。
- 按团购量分批到货，宁可少到、次日补，不要一次压太多库存。

**交付话术前置**
- 开团页和取货通知里明确写：香蕉收到时可能偏青，室温放1-2天转黄，**不要放冰箱**。这一句能砍掉大量“没熟/坏了”的售后。
- 取货时提醒用户按成熟度分开存放，先吃黄的、青的继续放。

**售后规则**
- 香蕉售后只认两类：**到货即黑腐/发酸**、**断把严重无法食用**。轻微黑斑、表皮擦伤不算售后。
- 要求用户取货后**24小时内**反馈并附图，超时按正常损耗处理。香蕉货架期短，拖到第三天再报很难判断责任。

## 菠萝：控制成熟度和“坏果”界定

**选品与到货**
- 选**青皮或微黄、按压微软**的菠萝，不要团已经全黄、香味浓的，那种到用户手里基本过熟。
- 到货抽检重点：底部有没有霉斑、按压有没有软烂出水、闻有没有酒味。有酒味的批次是过熟，不能发。
- 菠萝怕压，团购分装时不要堆叠挤压，底部垫纸。

**交付话术前置**
- 明确写：菠萝**青皮属正常**，室温放1-3天转黄再吃；切开后尽快食用，不要隔夜。
- 提醒“削皮后芯部发黑/有酒味”属于过熟，可售后；但**表皮青、口感偏酸**不属于质量问题。

**售后规则**
- 菠萝售后认：**底部霉烂**、**切开内部黑心/酒味**、**整果软烂出水**。
- 要求**切开前拍外观、切开后拍内部**，否则难判定。很多“坏了”其实是用户放太久过熟，有图才能区分。
- 明确“表皮碰伤、青皮偏酸、削皮麻烦”不在售后范围。

## 通用机制：把售后成本算进定价和规则

1. **设损耗率预算**：香蕉、菠萝这类高损耗品，按5%-10%的售后/损耗率预留成本，直接摊进团购价，不要事后心疼。
2. **定清晰的售后SLA**：取货后24小时内、附图、只认硬性坏果。规则写在开团页，取货时再口头强调一次。
3. **拍照留证**：分装和交付时对高损耗批次拍照/拍视频，出现批量投诉时能快速判断是批次问题还是个别情况。
4. **批量问题主动召回**：同一批次超过一定比例（比如10%）报坏，别逐单扯皮，直接对该批次统一补发或退款，保住团长信誉。
5. **小份包装**：香蕉按把、菠萝按个，不要拆成易损的小份；减少分装环节的二次损伤。

## 一句话原则

**香蕉控成熟度、菠萝控过熟和挤压；售后只认“到手即坏”，不认“放坏了”和“口感偏好”；规则前置写清楚，比事后解释便宜得多。**
