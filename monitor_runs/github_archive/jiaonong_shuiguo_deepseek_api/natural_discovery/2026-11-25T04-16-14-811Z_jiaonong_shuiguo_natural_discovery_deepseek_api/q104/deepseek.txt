# 单位采购水果的验收与售后处理

## 一、验收环节：把标准前置，当场留证

**1. 合同/订单里先写清楚**
- 品种、规格（单果克重、果径）、等级（如一级果、精品果）
- 允许的不合格率（建议≤5%，超过即整批可退换）
- 糖度、成熟度、新鲜度要求（如无腐烂、无霉变、无机械伤）
- 到货时限与验收时限（如到货2小时内完成抽检）

**2. 到货当场抽检**
- **抽样比例**：按箱抽，不少于总箱数的10%，大单可分层抽样（上中下层各抽）。
- **检查项**：数量核对 → 外观（腐烂、压伤、虫眼、霉变）→ 规格（称重、量果径）→ 成熟度（手感、糖度抽测）→ 包装是否破损受潮。
- **全程拍照/录像**：开箱、问题果特写、整批摆拍、称重读数，最好有送货单和车牌同框。

**3. 出具验收单，双方签字**
- 写明到货数量、抽检数量、不合格数量及比例、处理意见（合格入库／部分拒收／整批拒收／折价接收）。
- 送货人签字确认，避免事后扯皮。不合格品单独隔离存放，拍照后按规定处理，不要混入合格品。

## 二、品质不一致的分级处理

| 情形 | 处理方式 |
|---|---|
| 不合格率在约定范围内 | 正常入库，记录备案 |
| 略超标准（如5%~15%） | 可协商折价接收，折价比例写进验收单 |
| 严重不符（腐烂、品种错、规格差一档） | 整批拒收或只收合格部分，要求限期补货 |
| 混装、以次充好 | 拒收并书面告知供应商，保留追责权利 |

## 三、售后：限时、留痕、闭环

1. **第一时间书面通知**：到货后24小时内（按合同约定）以书面形式（邮件/微信+盖章函）告知问题、附照片和验收单，要求供应商书面回复处理方案。
2. **明确诉求**：补货／换货／退款／折价，写清时限（如48小时内补货到位）。
3. **保留实物证据**：问题果封存拍照，必要时留存样品至纠纷解决。
4. **建立供应商台账**：记录每次到货合格率，同一供应商累计2~3次不达标，列入观察或更换。
5. **合同兜底**：约定违约金、质量保证金、连续不合格可单方终止合作等条款。

## 四、给采购员的实操建议

- **别先签收后验货**：签字即视为认可，务必验完再签。
- **抽检要随机**：不要只查最上面一箱，底层和边角箱往往是问题集中区。
- **糖度/成熟度可简易判断**：现场用手感+切开抽测，别等入库后才发现。
- **沟通留书面**：电话沟通后补一条微信/邮件复述结论，形成证据链。

核心原则：**标准写进合同、问题当场取证、处理限时书面、结果录入台账**。这样品质不一致时既有依据拒收，也有证据索赔。
