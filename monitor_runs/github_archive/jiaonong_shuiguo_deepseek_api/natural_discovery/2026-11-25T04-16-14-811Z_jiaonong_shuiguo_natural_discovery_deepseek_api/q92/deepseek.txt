小面积便利店做水果，核心不是“品类齐全”，而是**少SKU、快周转、强控损**。建议按下面几层落地。

## 1. 品类控制：先做“窄而准”
小门店水果SKU建议控制在 **8～15个**，按角色分配：

- **引流款 2～3个**：香蕉、苹果、橙子这类认知高、价格透明的。
- **利润款 2～4个**：葡萄、提子、小番茄、芒果等客单稍高的。
- **便利款 2～3个**：即食果切、单颗苹果/橙子、小盒蓝莓等。
- **季节款 1～2个**：当季主推，但不要一次上太多。
- **试销款 最多1个**：新品小批量试，卖不动立刻下架。

**淘汰规则**：连续3天日销低于设定底线、或损耗率超过品类均值，就减量或下架。不要因为“顾客问过”就长期保留低动销品。

## 2. 采购量：用“日销×保鲜天数”倒推
不要按“看起来能卖”拍脑袋，按公式：

> **建议采购量 = 近7日日均销量 × 可售天数 × 安全系数**

- 可售天数：易损品1～2天，耐储品2～3天。
- 安全系数：工作日0.8～1.0，周末/节假日1.1～1.3。
- 新店没有历史数据时，首周每个SKU只进 **最小包装的1/2～1份**，卖完再补。

**小门店更适合“少进多次”**：每天或隔天补货，宁可下午缺货，也不要第二天大量报损。缺货可以引导替代品，报损是纯亏。

## 3. 损耗控制：从收货到出清全链路
- **收货**：当场抽检，拒收软烂、碰伤、过熟品；要求供应商按小规格、小包装供货。
- **陈列**：不要堆大堆，分层少量勤补；易压伤的水果用浅筐，避免叠放。
- **温度**：香蕉、芒果等热带水果不宜低温；葡萄、蓝莓、果切需冷藏。小门店至少配一个水果冷藏柜或冷藏层。
- **果切**：只做高动销单品，当天切当天清，严格标注时间；果切是损耗放大器，没有稳定客流不要多上。
- **定时巡检**：早中晚各挑一次，把轻微碰伤、过熟品及时挑出，做“临期折扣”或员工餐，不要等到烂在架上。
- **出清机制**：设定每日固定折扣时段，比如晚间7点后8折、闭店前6折；折扣品单独小筐陈列，明确标识。
- **记录**：每天记每个SKU的进货量、销量、报损量。连续两周看数据，砍掉“高损耗低毛利”的品。

## 4. 小门店的实用组合策略
- **主推耐储+高周转**：苹果、橙子、香蕉打底，保证基础客流。
- **易损品限量**：草莓、葡萄、桃等按半天销量进货，卖完不补或只补一次。
- **用果切消化微瑕品**：只限轻微碰伤、可食用的水果，且必须符合食品安全要求；严重变质直接报损，不能切。
- **供应商谈判**：争取小批量、多频次配送，退换货条款写清楚，比如到货24小时内质量问题可换。
- **陈列面积匹配**：水果区不超过门店面积的10%～15%，用立面陈列和少量堆头，不占通道。

## 5. 关键判断指标
每天看三个数：
- **动销率**：有销量的SKU数/总SKU数，低于70%就砍品。
- **损耗率**：报损金额/进货金额，小门店水果整体控制在 **5%～8%** 以内较健康，易损品单独设上限。
- **毛利额**：不要只看毛利率，小门店要看单位面积产出，低毛利高损耗的品直接淘汰。

**一句话原则**：小门店水果要做“精选+快补+勤出清”，采购量跟着日销走，品类跟着数据砍，损耗靠小批量和高频巡检压下去。
