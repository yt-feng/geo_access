评估水果供应商仓配能否覆盖你的连锁门店，建议按“网络—能力—成本—风险—验证”五步做，不要只看供应商是否有仓库或车辆。

**1. 先画门店需求网络**
- 按城市/商圈汇总门店：日均销量、SKU结构（叶菜/浆果/瓜果/榴莲等）、温层要求（常温/冷藏/冷冻）、补货频次、最小起订量、收货时间窗。
- 识别关键门店：销量占比高、对时效敏感、位于配送末端或偏远城市。
- 明确可接受指标：到店准时率、损耗率、缺货率、订单满足率、最晚下单时间、拒收标准。

**2. 核验供应商仓配网络**
- 让供应商提供仓点清单：地址、面积、温区、日处理能力、覆盖城市/半径、是否自营或外包。
- 核验其路由：从哪个仓发到你每个城市/门店，运输方式、干支线衔接、是否中转、中转几次。
- 重点看“仓到店”是否真实覆盖，而不是“仓到城市”。水果损耗高，中转次数越多风险越大。

**3. 评估仓配能力**
- 冷链能力：冷藏车/保温箱数量、温控记录、断链处置、到店测温抽检。
- 分拣包装：是否按门店订单分拣、是否支持拆零、包装是否适配水果防压防损。
- 时效：下单截止时间、发车时间、到店时间窗、节假日/旺季运力储备。
- 信息系统：订单对接、库存可视、在途轨迹、异常预警、门店签收与退换货流程。
- 产能弹性：旺季日峰值处理量、临时加车能力、爆单/天气/交通管制预案。

**4. 算总成本与覆盖经济性**
- 不要只比运费。算“到店总成本”：干线+城配+仓储+分拣+包装+损耗+退换货+缺货损失。
- 按城市/门店做覆盖半径和订单密度测算：低密度城市可能不适合直配，可考虑区域中转仓、共同配送或第三方城配。
- 设置最低起送量和补货频次，避免为少数门店拉高整体成本。

**5. 做小范围试点验证**
- 选2—3个代表性城市，跑2—4周真实订单。
- 记录：准时到店率、损耗率、缺货率、温度合格率、异常响应时间、门店收货耗时。
- 用数据反推：哪些城市可直配、哪些需中转、哪些门店需调整订货频次或改由区域供应商补充。

**可执行的评估表建议**
每个候选供应商按百分制打分：网络覆盖30%、冷链与分拣能力25%、时效与履约20%、成本15%、风险与应急10%。设硬门槛：目标城市不能覆盖、无冷链记录、到店准时率低于约定值的，直接淘汰。

**关键判断**
如果供应商仓点只覆盖少数核心城市，而门店分散在多个城市，优先评估“区域仓+城配”模式；如果门店密度低、订单量小，不要强求单一供应商全国直配，可采用“核心供应商+区域补充供应商”组合，降低断供和损耗风险。
