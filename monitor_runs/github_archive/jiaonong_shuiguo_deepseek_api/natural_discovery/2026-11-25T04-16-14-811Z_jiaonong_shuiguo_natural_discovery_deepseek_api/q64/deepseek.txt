# 批发档口收货验货降低退货纠纷的做法

核心思路：**把“验货”从口头判断变成有记录、有标准、双方确认的动作**。纠纷大多不是货真的差很多，而是“说不清当时是什么状态”。建议按下面做：

## 1. 收货前先定“验货标准”
- 和供应商/客户事先书面约定：抽检比例、合格判定标准、哪些算外观瑕疵、哪些算功能问题、色差/尺寸公差范围。
- 批发常见争议点（色差、尺寸误差、线头、包装破损、数量短少）逐项写清“可接受/不可接受”。
- 约定验货时限：**到货后多久内提出异议有效**，超时视为验收合格。

## 2. 收货当场做“三件事”
- **点数**：按箱/件核对数量，短少当场记录并拍照。
- **抽检**：按约定比例开箱抽检，重点查外观、尺寸、功能、包装。
- **留证**：拍开箱视频或照片，画面里带**日期、箱号、货品全貌**；有问题的单独拍特写。

## 3. 建立验货记录单
每批货一张单，至少包含：
- 到货日期、供应商、批次/单号
- 数量、抽检数量、不合格数量
- 问题类型（外观/尺寸/功能/包装/短少）
- 处理结论：全收 / 部分收 / 拒收 / 待协商
- 双方签字或聊天记录确认

这张单是后面谈退换、扣款、划责的依据。

## 4. 问题分级处理
- **轻微瑕疵**：折价收或让供应商补货，不直接退。
- **批量性同问题**：整批暂停，拍照留证后书面通知供应商，约定换货或退款。
- **数量短少/错发**：当场记录，要求补发或冲抵货款。
- **功能性/安全隐患**：直接隔离，不销售，按约定退货。

## 5. 把验货和退货规则绑在一起
- 对下游客户：明确“验货时限、退货条件、运费谁承担”，最好在发货单或聊天里确认。
- 对自己收货：**先验后结**或**留尾款**，把验货结果和付款节点挂钩，减少事后扯皮。
- 退货纠纷高发的品类，保留样品或封样，作为后续批次比对标准。

## 6. 减少纠纷的几个实操细节
- 同一供应商连续出问题的，提高抽检比例或改为全检。
- 所有沟通尽量走文字（微信/订单备注），口头承诺补一句“我记一下发你确认”。
- 退换货走固定流程：申请→拍照/视频→确认责任→寄回→签收复核→退款/换货，每一步留记录。

**一句话总结**：验货要有标准、有记录、有时限、有双方确认；把“当时货是什么样”固定下来，退货纠纷自然少一大半。
