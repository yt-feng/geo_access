# 水果店遇到坏果，怎么和供应商结算/赔付

核心原则：**先看合同/口头约定，再按批次留证，按"扣款、补货、退货、折价"四种方式之一处理**，不要拖到卖完再算账。

## 一、先确认约定基础

1. **有书面合同/供货协议**：看质量条款、验收期限、损耗率约定、赔付方式。有约定按约定。
2. **无书面约定（批发市场常见）**：按行业惯例——**到货当场验货，当场提出**；事后提出的，供应商通常只认有证据的部分。
3. **关键时间点**：多数纠纷败在"验货太晚"。建议约定或习惯为**到货4小时内（易腐品最好当场）完成抽检并拍照**。

## 二、发现坏果后的标准动作（可执行）

1. **分批次隔离**：坏果单独堆放，不要混入正常货，也不要急着扔。
2. **留证**：整箱/整车照片、坏果特写、称重记录、进货单/送货单、聊天记录。有条件的拍视频开箱。
3. **定量**：按箱数或斤数统计坏果比例（如"10箱中3箱、约15斤腐烂"），比笼统说"坏了很多"好谈得多。
4. **限时书面通知**：当天通过微信/电话+文字告知供应商，写明批次、数量、比例、诉求。

## 三、四种结算/赔付方式（按优先级）

| 方式 | 适用情形 | 操作要点 |
|---|---|---|
| **扣款** | 坏果比例明确、货已收 | 从本批货款中按坏果斤数×进货单价扣减；比例高时可要求额外补偿（如扣款额上浮10%–30%覆盖人工/客流损失，需事先谈） |
| **补货** | 供应商愿意、店里有销售窗口 | 约定补货时间；坏果退回或就地销毁并拍照；补货到店再验收一次 |
| **退货退款** | 整批质量不达标 | 整批退回，运费由责任方承担；已拆箱部分按比例折价 |
| **折价销售** | 轻微瑕疵、可降价卖 | 供应商按折价差额补偿，或双方各担一部分 |

**通用算法**：赔付额 = 坏果数量 × 进货单价 ×（1 + 协商补偿系数）。补偿系数用于覆盖运费、人工、误售风险，通常0–30%，事先约定最稳。

## 四、谈不拢时的处理顺序

1. 出示照片、称重、送货单，要求按批次对账；
2. 提出明确方案（如"本批扣款XXX元，或明天补X箱"），给对方选择；
3. 仍不认的，暂停该供应商后续订货，把该批货款争议单独挂账，其余批次正常结算，避免全面僵持；
4. 金额较大且有合同的，可按合同争议条款处理（书面催告→协商→必要时走法律途径），保留全部证据。

## 五、长期建议（减少下次扯皮）

- 在供货单上固定写：**验收时限、允许损耗率（如3%）、超标处理方式（扣款/补货）、坏果退回还是就地处理**。
- 每批到货固定抽检比例（如每10箱抽1箱），拍照存档。
- 对高频出问题的供应商，改为"货到验收合格后付款"或缩短账期。

一句话：**当场验、当场拍、当天说、按批次算，四种方式里选一个写清楚**。
