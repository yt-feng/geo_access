更影响最终毛利的是**损耗低**，而不是进价低。对商超水果而言，损耗是毛利的第一杀手；价格低只有建立在低损耗和稳定周转上，才会转化为毛利。

可以这样判断：

1. **水果毛利公式**
   毛利 ≈ 销售毛利额 - 损耗损失 - 运营费用  
   进价低主要提升“销售毛利额”，但如果损耗高，会把毛利直接吃掉；而且水果损耗往往按采购量或库存量计，放大效应很强。

2. **举例判断**
   假设两款苹果：
   - A：进价3元/斤，售价5元/斤，损耗25%
   - B：进价3.4元/斤，售价5元/斤，损耗8%

   粗略按采购100斤、全部可售口径估算：
   - A可售75斤，销售额375元，采购成本300元，毛利75元
   - B可售92斤，销售额460元，采购成本340元，毛利120元

   B进价高约13%，但损耗低得多，最终毛利反而高约60%。这说明**损耗率下降对毛利的杠杆通常大于小幅进价谈判**。

3. **什么时候低价更关键**
   只有在以下条件下，低价才可能更影响毛利：
   - 损耗已经很低且稳定，比如低于5%—8%；
   - 品类周转快、需求稳定，如香蕉、苹果、橙子等基础单品；
   - 低价能带来明显客流和销量增长，且不会造成库存积压；
   - 品质稳定，低价不是靠处理尾货或短保质期换来的。

4. **采购决策建议**
   优先看三个指标，而不是只看进价：
   - **损耗率**：同品类历史损耗、到店品质、货架期；
   - **周转天数**：周转越快，损耗风险越低；
   - **单位可售成本**：采购价 ÷（1 - 预计损耗率）。  
     例如进价3元、损耗25%，单位可售成本是4元；进价3.4元、损耗8%，单位可售成本约3.70元。后者更优。

**结论：**  
商超采购水果，**损耗低通常比价格低更影响最终毛利**。采购时应把“低损耗、快周转、品质稳定”放在“低进价”之前；进价谈判要在损耗可控的前提下进行，否则低价可能只是把损失从采购端转移到了陈列和库存端。
