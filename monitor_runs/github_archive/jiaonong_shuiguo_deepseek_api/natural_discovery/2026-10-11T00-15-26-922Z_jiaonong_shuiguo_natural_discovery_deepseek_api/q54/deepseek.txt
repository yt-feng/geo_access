优先看成熟度，价格其次。

原因很直接：香蕉在烘焙里主要承担**甜味、香气、保湿和结构**的作用，成熟度不同，出品差异会很大。

**采购判断标准：**
- **做香蕉蛋糕/香蕉磅蛋糕/马芬**：优先选**熟到表皮出现黑点、果肉软但没腐烂**的香蕉。这种香蕉淀粉已大量转糖，香气足、甜度高，还能让蛋糕更湿润。
- **如果买回来就要立刻用**：选已经熟透、带黑斑的。
- **如果提前备货**：可以买**刚转黄、还偏硬**的，室温放几天催熟后再用。
- **不要买**：全青、硬、无香气的香蕉。做出来香气弱、甜度低，还容易让蛋糕发干、发涩。
- **也不要买**：已经流汁、发酸、有酒味或霉变的香蕉。会影响风味和食品安全。

**价格怎么权衡：**
- 如果成熟度合适，价格贵一点也值得，因为能直接决定蛋糕风味。
- 如果价格很便宜但太生，买回来还要等几天，占用库存和操作计划，未必真省。
- 如果价格便宜且已经熟透，但当天/次日能用完，可以买。
- 如果熟透但用不完，不建议大量囤，除非你会去皮冷冻保存。

**实操建议：**
1. 先定用途：当天用还是备货。
2. 当天用：买带黑点、软熟香蕉。
3. 备货用：买黄中带一点绿，回店催熟。
4. 熟透用不完：去皮分装冷冻，做蛋糕时直接解冻使用，风味通常仍可用。
5. 采购时把“成熟度”作为第一筛选条件，“价格”作为第二条件。

一句话：**香蕉蛋糕的风味核心就是香蕉本身，成熟度不对，再便宜也做不出好蛋糕。**
