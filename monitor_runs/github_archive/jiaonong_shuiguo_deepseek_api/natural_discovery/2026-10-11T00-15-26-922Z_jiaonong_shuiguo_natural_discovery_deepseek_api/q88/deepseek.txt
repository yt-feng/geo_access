线上水果销售，坏果和口感不稳定本质上要分成两个环节解决：**采购端控制货源稳定性**，**履约端控制损耗和批次波动**。核心不是“买到最好的果”，而是“让每批货的可预期性变高”。

**采购时重点抓这几件事：**

1. **按成熟度而不是按外观采购**
   线上发货有运输时间，采购时要明确“发货时成熟度”和“到货时成熟度”。比如芒果、猕猴桃、牛油果这类后熟水果，不能采太生，也不能采太熟。要求供应商按“硬熟度/糖度/干物质”分级，而不是只说“大果、精品”。

2. **固定产区、固定果园、固定采摘批次**
   口感不稳定往往来自混收。今天收A园，明天收B园，甚至同一批里混不同成熟度，评价一定波动。尽量锁定几个核心供应商，要求同一链接同一规格尽量来自同一产区、同一采摘期。

3. **用可量化指标代替口头承诺**
   能测的就测：糖度、酸度、单果重、果径、硬度、干物质、瑕疵率。比如橙子要求糖度≥11、酸度≤0.8，猕猴桃要求干物质≥15%。不能全测也要抽检，并把标准写进采购合同。

4. **明确瑕疵率和赔付规则**
   采购时约定：坏果率、软果率、裂果率、机械伤率的上限，以及超出后怎么赔。不要等售后再扯皮。比如“到仓抽检坏果率≤3%，超过部分按比例扣款或补发”。

5. **先小批量试发，再放量**
   新供应商、新产区、新批次先发50-100单，看真实评价：坏果、口感、成熟度、物流后状态。数据稳定再放量。不要一次囤很多，水果批次差异很大。

6. **采购时就要考虑包装和物流**
   有些果不是质量差，是包装和运输不适合线上。采购时要问：这个品种耐不耐压、怕不怕闷、适不适合加冰袋/保温袋、能不能用气调包装。比如草莓、蓝莓、荔枝，采购标准必须和冷链方案一起定。

7. **建立批次档案和留样**
   每批货记录：供应商、产区、采摘日期、到仓日期、糖度抽检、坏果率、发货日期、评价关键词。出问题能快速定位是产地、仓储还是物流。留样也能对比口感变化。

**履约端减少坏果和口感波动的关键：**

- **到仓快检**：坏果、软果、成熟度不合格的直接拦截，不发给客户。
- **分级发货**：按成熟度分开发，近的发熟一点，远的发生一点。
- **控制库存周转**：水果不是标品，压库越久口感越不稳定。先进先出，临期批次及时处理。
- **包装按品类定制**：防震、防压、透气、控温，不同水果不能用同一套包装。
- **售后前置**：详情页写清成熟度、食用建议、催熟方法，能减少“没熟/太熟”的差评。

**最实用的判断标准：**
采购时不要只问“甜不甜”，要问：**这批货糖度多少、硬度多少、坏果率多少、能放几天、适合发多远、上次同批次线上差评率多少。** 能回答这些的供应商，才值得长期合作。
