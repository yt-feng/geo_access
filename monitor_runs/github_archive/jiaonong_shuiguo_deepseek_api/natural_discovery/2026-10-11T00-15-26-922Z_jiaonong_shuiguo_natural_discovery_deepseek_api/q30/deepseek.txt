超市水果到货后发现品相不好，售后流程建议在采购合同或供货协议里提前约定，重点写清“验收标准、时限、证据、处理方式、责任归属、结算扣款”六件事。可以按下面框架约定：

**1. 明确验收标准**
不要只写“品相好”，要量化：
- 规格：单果重量、直径、等级。
- 外观：颜色、成熟度、允许的磕碰、压伤、腐烂、裂口比例。
- 新鲜度：叶片、果柄、表皮皱缩、异味、出水等。
- 允许差异：例如“抽检中不合格率≤5%为合格，超过5%可拒收或扣款”。

**2. 约定验收时限和方式**
- 到货后多久验收：如“卸货后2小时内完成抽检”。
- 谁验收：收货员、品控、店长或第三方。
- 怎么抽检：按比例抽检，如每批次随机抽3箱/10%。
- 逾期未验收的后果：可约定“未在时限内提出异议视为验收合格”，但生鲜可保留隐蔽瑕疵追责期，如“腐烂、内伤可在24小时内追溯”。

**3. 证据要求**
- 到货照片、视频：整车、批次、包装、标签、问题果特写。
- 称重记录、抽检记录、验收单。
- 聊天记录、邮件、电话录音等沟通凭证。
- 最好双方现场签字确认，避免事后扯皮。

**4. 分级处理方式**
按问题严重程度约定：
- 轻微：降价接收，按比例扣款。
- 中度：部分退货，供应商补货或换货。
- 严重：整批拒收，供应商承担运费和损耗。
- 已上架后发现：可要求补偿、退货或下次货款抵扣。

**5. 责任和费用**
- 运输途损由谁承担：装车后、卸货前、卸货后分别约定。
- 退换货费用：运费、装卸费、垃圾处理费由责任方承担。
- 因品相问题导致顾客投诉、罚款、损耗，是否由供应商承担。
- 扣款方式：当场扣、月结扣、保证金扣。

**6. 结算与争议**
- 不合格批次是否影响账期。
- 扣款金额计算方式：按件、按斤、按批次比例。
- 争议解决：先协商，再按合同约定仲裁或诉讼。
- 保留保证金或质保金，便于快速处理售后。

**一个可落地的条款示例：**
“乙方送货到甲方指定地点后，甲方应在2小时内按每批次不低于10%比例抽检。抽检不合格率≤5%，甲方按合格品接收，不合格部分按每斤X元扣款；不合格率5%-15%，甲方有权对不合格部分退货，乙方应在24小时内补货；不合格率超过15%，甲方有权整批拒收，乙方承担运费及因此产生的损耗。甲方需提供照片、视频及验收记录。隐蔽性腐烂可在到货后24小时内追溯。争议先协商，协商不成提交甲方所在地法院。”

**实操建议：**
- 新供应商先小批量试单，别一上来大额采购。
- 每次到货都留验收单和照片，形成习惯。
- 扣款规则要写具体，避免“视情况协商”。
- 对长期供应商可设月度质量评分，连续不达标调整采购量或终止合作。
