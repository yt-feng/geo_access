结论先说：**多数甜品店直接买成品果丁的总损耗更低，但如果你的销量大、出品稳定、能控温控时，鲜果现切在成本上可能更划算。** 关键不是只看“丢了多少”，而是看**可售出部分占比 + 人工 + 报废风险**。

### 1. 鲜果切配的损耗点
- **去皮、去眼、去芯**：菠萝可食率通常约 50%～65%，取决于品种、成熟度和刀工。
- **修边、氧化出水**：切好后放久会出水、发暗、变味。
- **批次波动**：生熟不一，太生酸、太熟易烂，报废率高。
- **人工损耗**：切配时间、清洗、消毒、冷藏占用。
- **库存损耗**：整果放久会过熟、黑心、腐烂。

所以鲜果的“损耗”不只是果皮果芯，还包括**时间损耗和报废损耗**。

### 2. 成品果丁的损耗点
- **开袋后保质期短**：一旦开封，用不完就容易酸败、出水、污染。
- **冷链依赖**：运输或冷藏断链会直接报废。
- **规格不匹配**：丁太大/太小，影响出品，可能还要二次处理。
- **单价通常更高**：但你买的是“已筛选、已切好、可直接用”的部分。

成品果丁的损耗主要是**开封后报废和冷链风险**，不是切配损耗。

### 3. 怎么判断你店该选哪个
可以用这个简单算法：

**鲜果实际成本 = 采购单价 ÷ 可食率 + 人工成本 + 报废成本**

**成品实际成本 = 采购单价 ÷ 可用率 + 开封报废成本**

举例：
- 鲜菠萝 8 元/个，可食率 55%，那可食部分成本约 **14.5 元/斤**，还没算人工。
- 成品果丁 15 元/斤，开封后能用 90%，实际约 **16.7 元/斤**。
- 如果鲜果人工和报废一加，很可能超过成品。

### 4. 实操建议
- **销量小、菜单杂、人手紧**：直接买成品果丁，损耗和稳定性更好。
- **销量大、每天固定用很多、有专人不忙时切**：鲜果切配更省，但必须当天切当天用。
- **折中方案**：核心爆品用鲜果现切提升口感；低频或装饰用成品果丁。
- **无论选哪个**：都要记录 7 天实际报废量，不要凭感觉。损耗高低最终由你的销量、排班和冷藏条件决定。

一句话：**小店和用量不稳定时，成品果丁总损耗通常更低；大店和高频稳定出品时，鲜果切配更可能降本。**
