建议以**小把（3–5根）为主，搭配少量单根，整袋只做补充**。理由如下：

1. **便利店的核心场景是“即时消费”**
   顾客多为临时想买一点、马上吃，单根或小把小把最符合“少量、低决策成本”的需求。整袋更适合家庭采购，而家庭通常更倾向去超市或水果店。

2. **损耗控制比客单价更重要**
   香蕉易熟、易压伤，整袋一旦其中几根过熟或碰伤，整袋都难卖。小把和单根能降低单次报损金额，也方便按成熟度分级处理。

3. **单根适合做“顺手带”**
   单根可以放在收银台附近，作为冲动消费商品，适合已经买了别的东西、想顺手加一根的顾客。但单根毛利低、称重/计价麻烦，不建议作为唯一形式。

4. **小把最适合作为主力**
   3–5根的小把既有一定客单价，又不会让顾客觉得“买太多吃不完”。定价上可以直接按把标价，减少称重环节，提高收银效率。

5. **整袋只适合特定情况**
   如果门店附近有家庭客群、且能保证较快周转，可以少量上整袋；否则容易变成高损耗库存。整袋更适合做促销或预订，而不是日常主力陈列。

**具体建议：**
- 主力：**小把 3–5 根**，按把定价。
- 辅助：**单根**，放收银台或端头，方便顺手买。
- 补充：**整袋**，仅少量试销，观察周转和损耗。
- 陈列时按成熟度分开：偏青的放常规区，偏熟的尽快促销或做单根特价。
- 每天检查，出现黑斑、压伤、过熟就及时下架或打折，不要等整批坏掉。

一句话：**便利店卖香蕉，优先小把，单根做顺手购，整袋谨慎做。**
