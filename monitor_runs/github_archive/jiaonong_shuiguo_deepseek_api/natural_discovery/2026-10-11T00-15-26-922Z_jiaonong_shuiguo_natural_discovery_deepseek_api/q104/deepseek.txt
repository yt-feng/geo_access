单位采购水果遇到品质不一致，核心是**把验收标准前置到合同里**，到货按标准逐项验，不合格当场留证、分级处理，售后按合同条款走。具体操作如下。

## 一、验收前：先定标准（最关键）

如果合同/订单里没写清楚，验收时就会扯皮。采购时应约定：

1. **规格标准**：品种、单果重量/直径、等级（如一级果）、成熟度、糖度（可抽检）。
2. **品质标准**：色泽、新鲜度、无腐烂、无虫眼、无机械伤、无催熟异味。
3. **允许误差**：明确"不合格率上限"，比如抽检不合格率≤5%视为合格，超过即整批可退或按比例扣款。
4. **包装与重量**：净重还是毛重、装箱规格、损耗率约定。
5. **验收方式**：抽检比例（如每批抽10%）、验收时限（如到货2小时内）。
6. **售后条款**：不合格如何退换、补货时限、扣款比例、运费谁承担。

## 二、到货验收：分层抽检 + 全程留证

**1. 先核对单据**
- 送货单、品种、数量、批次、产地与订单是否一致。

**2. 分层抽样，不要只看表面**
- 按箱/筐随机抽取，**上中下、里外层都要抽到**（品质不一致往往是表层好、里层差）。
- 建议抽检比例：大批量按5%~10%，小批量适当提高。

**3. 逐项判定并记录**
- 对每箱记录：合格数、不合格数、不合格类型（腐烂、压伤、生青、过熟等）。
- 现场拍照/录像，**照片要能体现批次、箱号、整体和局部**，最好有称重或对比参照。

**4. 称重复核**
- 若约定净重，去包装后称重，核算实际到货量与损耗。

**5. 当场确认**
- 不合格部分当场与送货人确认签字，避免事后不认账。

## 三、按不合格程度处理（分档）

| 情况 | 处理方式 |
|------|----------|
| 轻微、零散不合格 | 按比例扣款或折价接收 |
| 不合格率超约定上限 | 整批拒收或要求补换货 |
| 部分批次不合格 | 只退不合格部分，合格部分照收 |
| 严重（腐烂、变质、货不对板） | 整批拒收，要求重新发货并追责 |

原则：**能扣款的不轻易全退，能换货的不轻易终止合作**，但底线（食品安全、变质）必须零容忍。

## 四、售后跟进

1. **书面反馈**：把验收记录、照片、不合格率、诉求（退/换/扣款）以书面或微信/邮件形式发给供应商，留痕。
2. **约定时限**：要求供应商在约定时间内补货或退款。
3. **复核补货**：补发的水果要重新验收，不能免检。
4. **记录归档**：建立供应商质量台账，多次不合格的降低份额或更换。
5. **合同兜底**：若供应商拒赔，按合同违约条款处理（扣款、索赔、终止合作）。

## 五、几个实操建议

- **别让"验收"变成一个人的事**：采购、使用部门（如食堂/工会）共同验收，减少争议。
- **保留样品**：纠纷时封存样品作为证据。
- **提前告知供应商验收标准**：让供货方知道你会怎么验，能大幅减少到货品质偏差。
- **小额高频采购**：单位用水果若量大，可分批到货，降低单批品质波动风险。

一句话总结：**标准写进合同 → 分层抽检留证 → 按不合格率分档处理 → 书面售后并归档供应商表现。** 验收标准越前置，售后扯皮越少。
