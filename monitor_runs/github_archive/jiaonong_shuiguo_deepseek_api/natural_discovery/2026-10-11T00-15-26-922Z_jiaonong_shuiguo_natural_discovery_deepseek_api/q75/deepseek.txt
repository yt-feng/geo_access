和小批量试单的核心目的不是“赚一笔”，而是**用最低成本验证这个供应商能不能长期合作**。所以试单设计要围绕三件事：**验证品质稳定性、验证履约可靠性、算清真实成本**。

下面给一套可以直接落地的方案。

## 一、先定试单目标（别只想着拿货）

试单要回答 4 个问题：

1. **品质**：到货规格、成熟度、损耗率是否和样品/承诺一致？
2. **履约**：能不能按时发货、按量发货、包装是否经得起运输？
3. **价格**：加上运费、损耗、账期后，真实成本是多少？有没有利润空间？
4. **配合度**：出问题时对方是积极解决还是推诿？

只要有一项明显不合格，就不要急着放量。

## 二、试单规模怎么定

原则：**小到亏得起，大到能暴露问题。**

- **数量**：选 1~2 个单品，每个单品 1~3 个批次，每批控制在你能承受损失的范围内。比如单批货值控制在你月采购预算的 5%~10%，或总试单金额不超过你愿意交“学费”的上限。
- **不要只试一批**：一批可能是运气好或运气差。至少 2~3 批，才能看出稳定性。
- **不要一次试太多品类**：品类越多，变量越多，出了问题都归因不清。

## 三、试单要重点验证的指标

| 维度 | 具体看什么 | 合格标准（示例） |
|---|---|---|
| 规格 | 大小、等级、糖度、颜色、成熟度 | 与约定标准一致，偏差在可接受范围 |
| 损耗 | 运输损耗、腐烂、压伤 | 明显低于你现有供应商或行业常见水平 |
| 包装 | 是否抗压、是否适合你的销售场景 | 到货后无需大量返工 |
| 时效 | 下单到发货、在途时间 | 符合约定，不随意拖延 |
| 数量 | 是否短装、多装 | 短装要提前沟通并补/退 |
| 单据 | 产地、检测、发票 | 能提供你下游需要的凭证 |
| 售后 | 出问题响应速度、赔付态度 | 24~48 小时内给方案 |

## 四、试单流程设计（建议照做）

1. **先要样品 + 报价单**：样品免费或低价，确认基本品质和价格结构。
2. **签简易试单协议**：写清品名、规格、数量、单价、包装、发货时间、验收标准、损耗责任、付款方式。哪怕微信确认也要留文字记录。
3. **小批量下单**：首批可以选最稳妥的品类和规格，不要挑最难的。
4. **到货立即验收**：拍视频、称重、开箱抽检，记录损耗和规格偏差。
5. **跑一遍你的销售端**：看这个货在你的渠道好不好卖、客户反馈如何。
6. **复盘再决定是否放量**：连续 2~3 批合格，再逐步加量。

## 五、付款和风险控制

- **首次合作尽量不全款预付**：能货到验收后付款最好；至少留一部分尾款，验收合格再付。
- **如果必须预付**：金额控制小，走可追溯的付款方式，保留聊天和转账记录。
- **明确损耗责任**：比如运输损耗超过 X% 由谁承担，写清楚。
- **不要只看低价**：低价但损耗高、规格乱，真实成本可能更高。

## 六、怎么判断能不能继续合作

连续试单后，用这个标准判断：

- **可以放量**：品质稳定、按时按量、售后配合、算下来有利润。
- **再观察**：品质还行但偶有小问题，愿意整改，可以再试 1~2 批。
- **直接放弃**：短装、拖延、以次充好、出问题推责、单据不全。

## 七、一个简单的试单模板

> 品名：XXX  
> 规格：XXX（大小/等级/糖度/成熟度）  
> 数量：首批 XX 箱/斤  
> 单价：XX 元（含/不含运费）  
> 包装：XX  
> 发货时间：X 月 X 日前  
> 验收标准：损耗≤X%，规格偏差≤X%  
> 付款：验收合格后 X 天内付 X%，尾款 X 天内付清  
> 售后：到货 X 小时内反馈，供应商 X 小时内给方案

**一句话总结**：第一次试单，宁小勿大、宁慢勿快，重点不是压价，而是用 2~3 批小货把品质、履约、成本和配合度摸清楚，再决定要不要放量。
