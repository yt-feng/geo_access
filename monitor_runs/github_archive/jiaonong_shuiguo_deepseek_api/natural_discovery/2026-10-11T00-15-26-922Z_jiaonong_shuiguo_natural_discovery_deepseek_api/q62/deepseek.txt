判断一批香蕉，核心是分“当前熟度”和“后续坏果风险”两条线看。批发场景下，不能只看黄不黄，要结合颜色、硬度、棱角、柄部、果指状态和箱内气味综合判断。

**一、判断当前熟度**

香蕉熟度一般看几个关键信号：

1. **颜色**
   - 全绿：未熟，适合长途运输或需要催熟后再卖。
   - 绿中带黄、棱角明显：开始转熟，适合计划几天内出货。
   - 黄中带绿：中等熟度，通常适合较快批发。
   - 全黄、无绿：已熟，适合短期销售。
   - 黄带黑点：接近最佳食用期，但货架期短。
   - 大面积褐斑、发黑：过熟，坏果风险高。

2. **棱角**
   - 果指棱角分明、截面偏方：偏生。
   - 棱角变圆、果身饱满：偏熟。
   - 果指明显鼓胀、软塌：过熟。

3. **硬度**
   - 手捏果身中部，硬实：生。
   - 略有弹性：适中。
   - 明显软、按下去不回弹：熟过头或已开始坏。

4. **果柄和果轴**
   - 果柄青绿、切口新鲜：货较新。
   - 果柄发黄、发褐、干缩：存放时间偏长。
   - 果轴发黑、发霉、渗液：风险高。

5. **气味**
   - 清香正常。
   - 有明显酒味、酸味、发酵味：内部已开始变质，坏果风险高。

**二、判断坏果风险**

重点看这些高风险信号：

1. **果指表皮**
   - 水渍状斑块、透明感：可能已软腐。
   - 凹陷斑、褐色腐烂斑：已感染。
   - 黑点密集且扩大：货架期很短。
   - 裂口、破皮：容易二次感染。

2. **柄部和果轴**
   - 发黑、发霉、长白毛或绿毛：霉菌感染，整箱风险上升。
   - 切口渗液、发黏：细菌性软腐风险高。
   - 果柄与果指连接处发黑：容易从连接处烂。

3. **箱内情况**
   - 箱底有汁液、发黏、异味：已有坏果污染整批。
   - 箱壁有水珠且温度高：容易加速腐烂。
   - 打开后有闷热感、酒味：储存条件可能已出问题。

4. **温度历史**
   - 香蕉怕冷，也怕高温。
   - 低温冻伤：表皮发暗、发灰，果肉变硬或水化，后熟不正常。
   - 高温堆压：快速转熟，容易软腐。
   - 如果运输或仓储温度波动大，表面看着还行，内部坏果风险也会升高。

5. **压伤和机械伤**
   - 被压过的果指，局部会先变黑、变软、出水。
   - 批发箱中下层、靠边位置要重点翻看。

**三、现场快速判断方法**

可以按这个顺序做：

1. 看整箱颜色是否均匀，有没有明显“青黄混杂”或局部发黑。
2. 随机抽3到5把，翻看底层和中间层。
3. 捏果身中部，判断软硬是否一致。
4. 看果柄、果轴、连接处有没有发黑发霉。
5. 闻箱内气味，有酒味、酸味直接警惕。
6. 看箱底有没有汁液、黏腻、腐烂残留。
7. 问清楚采摘时间、运输温度、是否催熟、催熟程度。

**四、按用途判断能不能拿**

- **要长途运输或囤几天**：拿绿中带黄、硬实、棱角明显、无黑斑、柄青的货。
- **要马上批给零售终端**：拿黄中带绿、微软、无大面积黑点、箱内干爽的货。
- **要当天或次日卖完**：可接受少量黑点，但不能有酒味、渗液、霉斑。
- **发现箱底有汁液、酒味、果轴发霉**：整批风险高，除非能大幅压价并快速处理，否则不建议拿。

**五、简单结论**

好货标准：颜色均匀、果身饱满但不过软、柄青轴干、无黑斑霉斑、箱内干爽无异味。  
高风险货：青黄不均且局部发黑、果身软塌、柄轴发霉、箱底渗液、有酒味酸味。  
最实用的判断是：**看颜色定熟度，捏硬度定货架期，查柄轴和箱底定坏果风险。**
