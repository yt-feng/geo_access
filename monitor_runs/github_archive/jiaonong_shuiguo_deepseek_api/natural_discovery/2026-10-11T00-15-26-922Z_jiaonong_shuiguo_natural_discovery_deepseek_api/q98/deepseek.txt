判断养老院或医院食堂的水果供应商，核心是看**资质合规**和**供应稳定性**两条线。下面给你可执行的核查清单和判断标准。

## 一、合规性核查（缺一项都要警惕）

**1. 主体资质**
- 营业执照：经营范围含“食品销售/食用农产品销售”，且在有效期内。
- 食品经营许可证：这是关键。水果若仅销售初级农产品（未加工、未分切），部分情况可豁免；但**一旦涉及分切、拼盘、鲜切果盒**，必须持有食品经营许可证（含“预包装/散装食品销售”或相应项目）。
- 要求提供证件原件核对，留存加盖公章的复印件，并定期核验有效期。

**2. 产品合规凭证**
- **食用农产品合格证**：正规基地/合作社应能提供，是农产品“产地准出”证明。
- **农残检测报告**：可要求每批次或定期提供；大型供应商应有自检或第三方检测。
- **进货票据/检疫证明**：涉及进口水果需有入境货物检验检疫证明。

**3. 追溯能力**
- 问清楚：这批水果**产地、批次、采摘/到货日期**能否追溯。
- 好供应商能说清从哪来、什么时候到。说不清来源的，直接排除。

**4. 合规红线**
- 无法提供任何检测/合格凭证；
- 证件过期或经营范围不符；
- 拒绝签订含食品安全责任条款的合同。

出现以上任一情况，不建议合作。

## 二、稳定性判断

**1. 供应能力**
- 是否有**固定合作基地或稳定货源渠道**，而非临时从批发市场倒手。
- 旺季/淡季、节假日能否保证供货，问其应对方案。

**2. 履约记录**
- 要求提供**同类客户案例**（其他养老院、医院、学校食堂），可侧面核实。
- 询问合作时长，长期合作且客户稳定的通常更可靠。

**3. 物流与保鲜**
- 是否有**冷链或专用配送车辆**，配送频次是否匹配你的用量。
- 到货新鲜度、损耗率如何处理，有无退换货机制。

**4. 价格与结算稳定性**
- 报价是否随行情剧烈波动，有无调价机制约定。
- 能否接受月结等账期，反映其资金和经营稳定性。

**5. 应急能力**
- 突发断供、质量问题时的替补方案和响应时间。

## 三、落地操作建议

1. **先资质、后试用**：证件齐全才进入试用，先小批量试供1–2个月。
2. **签合同写清**：食品安全责任、检测要求、退换货、违约赔偿、调价机制。
3. **建立验收台账**：每批记录品名、数量、产地、到货时间、验收人、检测情况。
4. **定期复评**：每季度或每半年复核证件有效性、供货及时率、质量合格率，不合格就换。
5. **保留备选供应商**：至少储备1家替补，避免单一依赖。

**一句话判断法**：证件齐全可追溯 + 有稳定货源和同类客户 + 愿意签责任合同并接受验收，三条都满足才算合规且稳定。
