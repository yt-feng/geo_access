超市和水果供应商的账期没有统一标准，主要取决于**供应商类型、品类特性、超市规模、合作阶段**。常见区间大致是：

| 场景 | 常见账期 |
|---|---|
| 本地小供应商 / 农户 / 批发市场 | 现结、周结、7–15 天 |
| 常规生鲜水果供应商 | 15–30 天 |
| 大型连锁超市对中小供应商 | 30–60 天 |
| 强势零售商对弱势供应商 | 60–90 天，甚至更长 |
| 进口水果、品牌水果、独家货源 | 15–30 天，甚至预付款 |

更具体地说：

1. **水果属于高损耗、短保质期商品**  
   供应商资金周转压力大，所以账期通常比日化、百货短。超过 45 天，很多水果供应商会要求加价或减少供货。

2. **本地应季水果**  
   常见 7–15 天，甚至现结。因为货值波动大、损耗快，供应商不愿压太久。

3. **长期稳定合作的水果供应商**  
   30 天比较常见，双方都能接受。大型超市可能谈到 45–60 天。

4. **大型商超 / 连锁超市**  
   对中小水果供应商常给 30–60 天；如果是强势渠道，可能 60–90 天，但通常会搭配返点、促销费、损耗补贴等条件。

5. **新供应商或首次合作**  
   一般先现结或 7–15 天，合作稳定后再逐步延长到 30 天左右。

**谈判建议：**
- 如果你代表超市：先从 30 天切入，目标 45–60 天，但要对高损耗、强季节性水果留出现结或短账期空间。
- 如果你代表供应商：30 天是相对合理底线，超过 45 天要计算资金占用成本，通常相当于变相降价 1%–3% 甚至更多。
- 无论哪方，账期都要和**损耗承担、退换货、价格调整、促销费用**一起谈，单独看账期容易吃亏。

一句话：**水果供应商常见账期是 15–30 天，大型超市常见 30–60 天，超过 60 天对水果供应商压力较大。**
