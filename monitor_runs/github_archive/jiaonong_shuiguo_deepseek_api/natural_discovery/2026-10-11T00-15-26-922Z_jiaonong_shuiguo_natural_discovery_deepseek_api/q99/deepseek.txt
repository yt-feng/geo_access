下午茶水果批量配送，核心是“稳定、省事、不踩坑”。可以从下面几个维度筛供应商。

## 一、先明确自己的需求

采购前先算清楚，否则容易被销售带偏：

- **人数 / 份量**：人均200g左右比较合适，30人约6kg，50人约10kg
- **预算**：普通下午茶人均3–8元，想体面些可到10元以上
- **配送频次**：一次性还是每周固定几次
- **配送时间**：必须卡在下午茶前1–2小时到，太早不新鲜、太晚耽误事
- **场地条件**：有没有冰箱、能不能切果、需不需要摆盘

## 二、选供应商的5个关键指标

**1. 配送稳定性**
固定时段送达、有冷链车或保温箱、能开发票。这是批量配送最容易出问题的地方。问清楚：节假日/雨天是否照常送、临时加单多久能响应。

**2. 品类与规格匹配**
适合下午茶的水果通常是：切好的果切拼盘、圣女果/蓝莓/葡萄这类免切即食、西瓜/哈密瓜等易分食的。整颗需要削皮切块的其实很麻烦，除非公司有人处理。

**3. 品控与损耗处理**
问清楚坏果怎么赔、能否当天换货。批量配送难免有压伤，售后政策比单价更重要。

**4. 价格与结算**
单价、起送量、配送费、包装费是否另算。长期合作尽量谈月结和固定价，避免每次询价扯皮。

**5. 资质**
食品经营许可证、营业执照齐全，尤其涉及果切现制的，卫生资质必须查。

## 三、常见渠道对比

| 渠道 | 适合场景 | 注意点 |
|---|---|---|
| 本地水果连锁/批发市场商户 | 量大、想压低成本 | 配送能力参差，需自己盯品控 |
| 生鲜电商B端（如美菜、快驴等） | 中小批量、要发票 | 品类标准化，但个性化摆盘弱 |
| 专业果切/下午茶配送商 | 要颜值、要省心 | 单价高，适合正式场合 |
| 附近精品水果店 | 小公司、临时单 | 灵活但批量能力有限 |

## 四、落地建议

1. **先小单试**：别一上来就签长期，先用1–2次真实下午茶验证配送准时率、新鲜度、包装。
2. **定标准清单**：固定2–3种水果搭配，减少每次沟通成本。
3. **建验收流程**：到货当场清点数量、拍照留证，坏果当天反馈。
4. **签简单协议**：把配送时间、坏果赔付、结算方式写清楚，哪怕一页纸。
5. **备一个替补供应商**：主供应商临时掉链子时能顶上。
