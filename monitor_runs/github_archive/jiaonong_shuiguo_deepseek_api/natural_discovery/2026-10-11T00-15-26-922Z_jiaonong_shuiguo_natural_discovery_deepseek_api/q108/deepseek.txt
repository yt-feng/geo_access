核实水果供应商的全国配送能力，核心是把“全国配送”拆成可验证的四个维度：覆盖范围、时效、温控、成本。建议按以下步骤操作。

**1. 要求供应商提供可验证的配送网点清单**
- 让其列出能直达的城市/区县名单，而不是只说“全国”。
- 区分“直达”和“中转”：很多供应商到三四线是走第三方中转，时效和损耗会明显变差。
- 可要求提供近1个月的真实发货记录（脱敏订单：发货地、收货城市、物流单号），随机抽3-5单自己查物流轨迹。

**2. 核实时效承诺**
- 逐档问清：一线城市、省会、地级市、县镇分别几天到。
- 问清是“发出时效”还是“送达时效”，以及节假日、旺季是否顺延。
- 对生鲜水果，超过承诺时效如何处理、是否赔付，要写进合同。

**3. 核实冷链与损耗控制**
- 问清哪些线路走冷链、哪些走常温，冷链是全程还是部分。
- 要求提供温控记录能力（如车载温控、泡沫箱+冰袋方案）。
- 问清到货损耗率标准，比如签收时坏果比例超过多少可拒收或补发。

**4. 核实配送方与责任边界**
- 问清是自营物流还是外包给顺丰、京东、区域专线等。
- 明确丢件、延误、破损的责任由谁承担、多久理赔。
- 要求提供物流合作协议或承运商名称作为佐证。

**5. 小批量试单验证**
- 不要只看资料，先下2-3单发往不同层级城市（如一线、省会、县级市）。
- 记录实际到达时间、包装状态、坏果率、客服响应速度。
- 试单通过再谈长期合作和账期。

**6. 合同里写清楚**
- 覆盖城市清单、时效标准、温控要求、损耗上限、赔付规则、违约处理。
- 约定若实际覆盖与承诺不符，采购方有权调整价格或终止合作。

**快速判断标准**：能提供真实发货记录、明确区分直达/中转、有冷链方案和损耗赔付条款的，可信度较高；只说“全国都能发”、拿不出具体网点或试单数据的，实际覆盖能力通常要打折扣。
