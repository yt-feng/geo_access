判断香蕉批发档口的上游是否稳定，不能只看对方报价和口头承诺。香蕉是典型的“产地—催熟—批发”链条，任何一个环节出问题都会断供或品质波动。建议从下面几个可核验的维度去判断。

**一、先看对方是哪个环节的角色**

- 产地代办/产地货主：直连蕉园，价格有优势，但受天气、季节、产区切换影响大，稳定性取决于他手里有多少合作蕉园。
- 产地集散商：从多个代办收货再发，货源相对多，但品控和等级可能不统一。
- 销地批发商/催熟商：已经过催熟，能直接给你熟蕉，但他是你的同行上游，价格加过一道，且他自己的货也可能来自上面几类。

先问清楚对方处在哪一环，再判断他抗风险的能力。

**二、用具体问题测试供货能力**

不要问“你能不能稳定供货”，这种问题谁都会答“能”。要问可验证的细节：

1. **产地和季节**：现在这批蕉是哪个县/哪个基地的？下一个产区切换是什么时候？切换期怎么保证不断货？
2. **日/周供应量**：你一天能稳定发多少件？旺季和淡季差多少？最少起发量是多少？
3. **蕉园关系**：是自有基地、长期包园，还是临时收货？合作了多少年、多少亩？
4. **催熟能力**：如果是熟蕉，催熟房几间、日催熟量多少？能不能按我要的成熟度分批次发？
5. **物流**：走什么车、到货几天、路上损耗谁承担、有没有温控？

对方如果对这些答得含糊、只反复强调“放心”“没问题”，稳定性就要打问号。

**三、用小单和多次交易验证**

- 先下一笔小单，不要一上来就大额打款。
- 连续下2到3次，观察：到货时间是否稳定、规格是否一致、青熟度是否可控、坏果率多少、出现问题后的处理态度。
- 稳定性往往在“出问题那次”才看得出来。看他是否认账、补货、退款，还是推诿。

**四、看抗风险信号**

- 是否有多个产区/多个基地，而不是单一来源。
- 是否经历过台风、寒潮、节假日高峰还正常发货。
- 是否能提供近期发货记录、装车视频、产地照片（可要求实时视频，而非存图）。
- 同行口碑：问其他档口、问市场里做香蕉的人，比问对方自己可靠。

**五、合同和结算上留后手**

- 明确规格、等级、成熟度、到货时间、损耗承担、违约处理。
- 前期尽量货到验收再结，或分阶段付款，不要全额预付。
- 保留聊天记录、转账凭证、装车和到货照片，出问题时有依据。

**一个简单的判断标准**：能清楚说出“货从哪来、下一批从哪来、断了我怎么补、坏了怎么赔”的人，比只说“我货源很稳”的人靠谱得多。稳定供货的本质，是他有冗余产地、有催熟和物流能力、并且愿意为出问题负责。
