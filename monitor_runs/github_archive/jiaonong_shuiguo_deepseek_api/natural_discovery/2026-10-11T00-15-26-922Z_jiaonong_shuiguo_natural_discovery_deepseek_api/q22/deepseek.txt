可以先按“引流品 + 利润品 + 搭配品”来组合，别只做简单打折。香蕉适合引流，苹果适合走量和提客单，菠萝适合做关联搭配和提升毛利。

**1. 组合方案**
- **香蕉 + 苹果：高频刚需组合**
  - 做法：香蕉按正常价或略低价引流，苹果做“第二件/加购价”。
  - 例：买1串香蕉，加9.9元换购3个苹果；或香蕉+苹果组合装定价低于单买合计约10%—15%。
  - 目的：香蕉把人拉过来，苹果把客单拉高。

- **菠萝 + 苹果：果切/拼盘组合**
  - 做法：菠萝和苹果做即食果切盒，或“菠萝+苹果”家庭装。
  - 例：一盒菠萝+一盒苹果切块，组合价15.9元；单买合计19.8元。
  - 目的：提高便利性和毛利，尤其适合下班客流。

- **香蕉 + 菠萝 + 苹果：家庭果篮/一周水果包**
  - 做法：按家庭人数做小份、中份。
  - 例：小份39.9元：香蕉1把+菠萝1个+苹果6个；中份59.9元：香蕉2把+菠萝1个+苹果10个。
  - 目的：直接拉高客单，适合周末和家庭采购。

**2. 陈列和话术**
- 三个品放一起，做成“今日组合专区”，不要分散。
- 标价要写清：单买合计多少、组合省多少。
- 用一句话话术：  
  “香蕉今天便宜，搭苹果和菠萝做果盘最划算，一篮够吃一周。”
- 试吃优先推菠萝和苹果，因为香蕉大家熟悉，不需要试吃。

**3. 定价建议**
- 香蕉：可微利甚至平进平出，负责引流。
- 苹果：正常毛利，做加购主角。
- 菠萝：毛利略高，做组合里的利润补充。
- 组合价一般比单买合计低10%—20%即可，太低会伤毛利。

**4. 避免的问题**
- 不要三个都打折，否则只是降客单，不是提客单。
- 不要组合里放太多易损香蕉，避免损耗。
- 菠萝要提供削皮服务，否则很多人不买。
- 苹果按大小分级，组合装用中果即可，不要用最好的果。

**5. 最简单可执行版**
明天就能做：
- 香蕉正常卖，挂“加9.9元换购苹果3个”。
- 菠萝削好切盒，和苹果切盒做“双拼果切15.9元”。
- 周末推“39.9元家庭水果包：香蕉1把+菠萝1个+苹果6个”。

这样核心逻辑是：**香蕉引流，苹果加购，菠萝提毛利，组合装拉客单。**
