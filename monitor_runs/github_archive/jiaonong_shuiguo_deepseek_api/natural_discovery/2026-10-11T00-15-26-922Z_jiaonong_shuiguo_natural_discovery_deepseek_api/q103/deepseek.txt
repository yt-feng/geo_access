结论：**如果目标是“好管理”，优先选按份结算，其次按箱，最不建议按斤。**  
但具体要看水果品类、采购规模和食堂管理能力。

### 1. 按份结算：最好管理
适合：切好分装的水果、酸奶水果杯、固定规格果盘、每人一份的餐后水果。

优点：
- 验收简单：数份数即可，不用称重。
- 成本固定：每份多少钱清楚，方便核算餐标。
- 发放快：窗口直接发，减少排队和人为挑拣。
- 损耗易控：提前定份量，避免“多拿多占”。

缺点：
- 供应商可能把份量做小，需要规定每份克重或果品数量。
- 不适合整果采购，比如整箱苹果、整筐橘子。

**建议：**  
如果是食堂直接提供给就餐者，优先按份。合同里写清楚：每份净重、水果种类、每份价格、允许误差。

### 2. 按箱结算：次好管理
适合：苹果、橙子、梨、香蕉、橘子等耐储存、规格相对统一的水果。

优点：
- 收货快：点箱数、看外观、抽检重量。
- 价格谈判简单：一箱多少钱，方便比价。
- 适合批量入库和领用。

缺点：
- 箱内可能有大小果、坏果，实际净重和品质不稳定。
- 如果只按箱不抽检，容易吃亏。
- 不同批次箱重可能不一致。

**建议：**  
按箱结算必须加三个条件：
1. 固定箱规，比如每箱净重10斤，不是毛重。
2. 验收抽检，随机开箱称重、查坏果率。
3. 约定坏果扣款或换货规则。

### 3. 按斤结算：最灵活，但最难管理
适合：品类杂、每天用量不固定、需要精确控制成本的场景。

优点：
- 按实际用量付费，理论上最公平。
- 适合苹果、香蕉、葡萄等散装采购。

缺点：
- 验收麻烦：每批都要称重、记录、复称。
- 容易产生争议：毛重还是净重、筐子算不算、水分损耗算谁的。
- 人工成本高：称重、记账、核对都费时间。
- 损耗和价格波动更难控制。

**建议：**  
如果必须按斤，最好做到：
- 统一去皮称重。
- 固定验收人和复核人。
- 每次记录品种、毛重、皮重、净重、单价、金额。
- 用电子秤并定期校准。

### 直接建议
- **给就餐者直接发放：按份结算。**
- **整果批量入库、耐储存水果：按箱结算。**
- **用量小、品类杂、价格波动大：按斤结算，但要配称重和验收流程。**
- **混合模式最实用：**  
  对就餐者按份管理，对供应商按箱或按斤采购。比如苹果按箱进货，食堂再按份发放。

一句话：**对外采购可以按箱或按斤，对内发放最好按份。** 这样既控制成本，又方便管理。
