大型超市对水果供应商的要求，核心是**食品安全合规能力 + 冷链物流能力 + 稳定供货能力**。通常可以分为以下几类：

## 一、食品安全能力

### 1. 资质与合规
- 营业执照、食品经营许可证/食品生产许可证（视业务形态）
- 种植基地需有土地/合作基地证明、农药使用记录
- 出口或特定品类可能需要GAP、有机认证、绿色食品认证等
- 每批次可提供产地证明、检测报告、合格证

### 2. 农残与污染物控制
- 具备农残检测能力或与第三方检测机构合作
- 能按国家标准（如GB 2763）控制农药残留
- 对重金属、霉菌毒素等有监控
- 能提供批次检测报告，并支持超市抽检复核

### 3. 追溯体系
- 从种植、采收、加工、包装到配送可追溯
- 批次号管理清晰，出问题能快速召回
- 记录保存完整，通常要求2年以上

### 4. 加工与包装卫生
- 分拣、清洗、打蜡、包装环节符合卫生规范
- 人员健康证、车间消毒、防虫防鼠
- 包装材料符合食品接触材料标准

### 5. 质量分级与验收标准
- 能按超市要求做大小、色泽、糖度、成熟度分级
- 有坏果率、磕碰率、新鲜度控制标准
- 能接受超市的验收标准和退货机制

## 二、物流与供应链能力

### 1. 冷链能力
- 采后预冷：快速去除田间热
- 冷藏运输：不同水果温区不同，如：
  - 浆果类：0~4℃
  - 热带水果：10~15℃
  - 柑橘类：4~8℃
- 冷库储存、冷链车、温控记录
- 能提供全程温度监控数据

### 2. 仓储与分拣
- 有符合要求的仓库，分区、防潮、防鼠、防虫
- 能按超市订单做拆零、分拣、贴标、组托
- 支持多SKU、多门店配送

### 3. 配送时效
- 能保证日配、隔日配或按超市要求频次配送
- 到店准时率、订单满足率高
- 有应急补货能力，避免断货

### 4. 损耗控制
- 采后处理得当，降低腐烂和磕碰
- 包装设计合理，适合运输和门店陈列
- 有明确的损耗率承诺和赔付机制

### 5. 信息化能力
- 订单、库存、物流信息可对接超市系统
- 能提供电子回单、温控记录、批次追溯信息
- 异常情况能及时预警和反馈

## 三、超市通常还会重点考察

- **供货稳定性**：产地资源、季节切换能力、自然灾害应对
- **价格与账期**：能否接受超市账期、返利、促销配合
- **售后响应**：质量问题处理速度、退换货机制
- **社会责任**：用工合规、环保、可持续种植
- **保险**：产品责任险、货物运输险

## 四、简单判断标准

如果一家水果供应商要进大型超市，至少要能回答：

1. 这批水果从哪来，谁种的，用了什么药？
2. 有没有检测报告，能不能追溯到这个批次？
3. 从采收到到店，温度是否全程可控？
4. 能不能稳定按超市要求的时间和标准送货？
5. 出了质量问题，能不能快速召回和赔付？

满足这些，才具备进入大型超市供应链的基础条件。
