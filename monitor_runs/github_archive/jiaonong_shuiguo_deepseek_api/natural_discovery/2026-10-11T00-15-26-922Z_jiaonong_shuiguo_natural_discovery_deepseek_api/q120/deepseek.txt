供应商想让普通商家“听懂并下单”，核心不是讲品种、产地、参数，而是把产品翻译成**商家能直接判断的卖点、利润和风险**。对菠萝、香蕉这类大品类，商家通常只关心：

1. **卖给谁**  
2. **怎么卖**  
3. **赚多少**  
4. **坏货怎么办**  
5. **多久能到、能不能稳定供**

所以介绍产品时，建议按这个顺序说：

**1. 先说“适合谁卖”**
不要一上来讲“这是金钻凤梨、红皮香蕉”。  
直接说：

- “这个适合水果店做引流，因为香味浓、颜色亮，顾客容易试买。”
- “这个适合社区团购，因为耐放，第二天送也不容易坏。”
- “这个适合餐饮店，因为出肉率高，切果盘损耗低。”
- “这个适合夜市摊，因为成本低，能按份卖，走量大。”

商家一听就知道自己能不能卖。

**2. 再说“顾客为什么买”**
把品种特点变成顾客语言：

- 不是“糖度18度”，而是“比普通香蕉甜一档，顾客试吃后容易复购。”
- 不是“果形端正”，而是“摆出来好看，拍照能当主推图。”
- 不是“耐运输”，而是“发到北方也不容易黑皮，减少售后。”
- 不是“小果”，而是“适合做儿童果切、办公室下午茶，一份刚好。”

**3. 直接算利润，不要只报单价**
商家最怕听不懂“净重、毛重、箱规、损耗”。  
最好直接说：

- “一箱20斤，进价80元，按每斤6元卖，毛利大概40元。”
- “损耗按10%算，每斤成本大概4.4元，你卖5.5元以上就有钱赚。”
- “这个适合做9.9元三斤引流，搭配高毛利果切一起卖。”

只要商家能算明白，下单概率就会高很多。

**4. 说清楚“怎么卖”**
给具体卖法，不要只说“品质好”：

- “门店可以整箱拆开，按斤卖，也可以做试吃。”
- “团购可以按5斤装、9.9元包邮做爆款。”
- “餐饮可以切片做果盘，或者打果汁，出汁率高。”
- “直播可以主打‘现摘现发、坏果包赔’，容易逼单。”

**5. 把风险讲明白**
普通商家最怕压货和售后。  
供应商要主动说：

- “常温能放几天，冷藏能放几天。”
- “熟度是几分熟，收到后几天最好卖。”
- “坏果怎么赔，拍几张照片，多久到账。”
- “第一次建议少拿，卖得好再补，不让你压货。”

**6. 给一个低门槛下单方案**
不要一开始就让商家拿大货。  
可以说：

- “先拿一箱试卖，卖不动我教你做试吃和组合。”
- “首单少拿，第二次补货再给你锁价。”
- “这周先发样品，你门店试卖三天，觉得行再走整柜。”

**一句话模板：**
“这个货不是让你记品种，是让你好卖。它适合水果店/团购/餐饮做引流，顾客买它的原因是甜、香、好看、耐放。一箱成本X元，按Y元卖，毛利大概Z元，损耗低，坏果包赔。你先拿一箱试卖，卖得好我再给你稳定供。”

**关键原则：**
少讲“我有什么”，多讲“你能怎么卖、赚多少、风险谁担”。  
普通商家下单，不是因为懂产品，而是因为**听得懂、算得清、觉得不亏**。
