判断商超水果供应商的售后响应是否稳定，不能只看口头承诺或合同条款，要在合作前和合作中用可验证的方式去测。以下是可以直接执行的方法：

**一、合作前：用真实场景测试**

1. **提一个具体的售后场景让对方给方案**
   - 例如：“到货后香蕉有20%发黑、菠萝有10%黑心，你们怎么处理？多久给答复？补货还是退款？”
   - 看对方能否给出**明确时限、明确责任划分、明确赔付方式**，而不是“放心，肯定负责”这种模糊话。

2. **测试非工作时间响应**
   - 在晚上或周末发一条售后咨询，记录对方多久回复。
   - 生鲜售后往往发生在凌晨到货或早市时段，如果对方只在工作日9点到17点在线，实际响应能力就要打问号。

3. **要求提供近期售后记录**
   - 让对方给出过去1-3个月的售后处理台账，包含：问题类型、提出时间、响应时间、解决时间、结果。
   - 如果对方拿不出来，或者只有口头说“都处理得很好”，稳定性就缺乏证据。

4. **问清售后对接人机制**
   - 是固定专人对接，还是每次找不同的人？
   - 有没有备用联系人？对接人请假或离职时谁接手？
   - 只有一个微信、一个人负责的供应商，响应稳定性通常较差。

**二、合作中：用小批量试单验证**

1. **首单刻意设置一次售后**
   - 收到货后，按真实标准提出一次质量异议，观察：
     - 多久回复；
     - 是否推诿；
     - 是否按约定补货或退款；
     - 补货速度和质量。
   - 这一步比任何承诺都有效。

2. **记录响应数据**
   - 每次售后记录：提出时间、首次回复时间、解决完成时间、是否一次解决。
   - 连续3-5次后，就能看出是偶然快还是稳定快。

3. **看补货/退款是否及时**
   - 生鲜售后关键不是“认不认”，而是“多快补上”。
   - 如果每次都要拖3-5天，即使态度好，也会影响门店销售和损耗。

**三、合同里要写死的可执行条款**

1. **响应时限**
   - 例如：收到售后申请后2小时内首次回复，24小时内给出处理方案。

2. **解决时限**
   - 例如：确认质量问题后，24-48小时内完成补货或退款。

3. **责任标准**
   - 明确香蕉、菠萝的验收标准，比如黑心、发黑、成熟度超标等比例达到多少即触发售后。

4. **违约处理**
   - 超过时限未响应或未解决，约定扣款、赔偿或终止合作。

5. **对接人和备用机制**
   - 写明主对接人、备用对接人及联系方式。

**四、简单判断标准**

- **稳定**：非工作时间也能回复，有固定对接人，有售后台账，试单售后24小时内响应并解决。
- **一般**：工作时间回复快，但非工作时间慢，售后能处理但需要反复催。
- **不稳定**：经常找不到人，售后靠拖，补货慢，没有记录，对接人频繁更换。

实际采购中，建议先用小批量试单加一次真实售后测试，再决定是否放大采购量。对商超来说，生鲜供应商的售后稳定性，最终看的是“出问题时能不能快速补上或赔上”，而不是平时说得多好。
