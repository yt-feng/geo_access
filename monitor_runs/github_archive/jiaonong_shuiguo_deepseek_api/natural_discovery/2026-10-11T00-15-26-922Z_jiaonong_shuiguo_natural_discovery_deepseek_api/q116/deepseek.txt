对做水果生意的小商家来说，现金结算和月结账期各有风险，核心差别在于**风险落在谁身上、什么时候暴露**。

## 现金结算的风险

1. **资金占用压力大**
   每批货都要当场掏钱，现金流容易被压死。水果周转快、损耗高，一旦某批货卖不动，现金就卡在库存里。

2. **采购规模受限**
   现金不够就只能少进，拿不到批量优惠，议价能力弱。

3. **假钞、找零、对账麻烦**
   大额现金交易有收假钞风险，现场清点容易出错，事后对账也缺凭证。

4. **安全与合规风险**
   携带大量现金有被盗抢风险；大额现金往来若没有规范票据，税务和账目上也不好处理。

5. **关系依赖强、维权难**
   现金交易往往凭口头或简单收据，货有问题时退换、追责缺乏书面依据。

**好处**：不欠钱、不怕被催款、供应商关系简单，价格上有时还能拿到现金折扣。

## 月结账期的风险

1. **坏账和拖欠风险**
   账期到了对方不付、拖付，甚至跑路，小商家很难扛。

2. **现金流被反向占用**
   你先拿货后付款，看似轻松，但如果下游回款慢，到了付款日你仍要垫钱，容易资金链断裂。

3. **隐性成本**
   账期往往对应更高的进货价，或者供应商把资金成本算进报价里，实际不比现金便宜。

4. **对账纠纷**
   月结涉及多批次、退换货、损耗扣款，月底对账容易扯皮，尤其是没有规范单据时。

5. **被动依赖**
   长期月结会让你依赖某个供应商，一旦对方提价、断供或收紧账期，你临时换供应商很被动。

6. **信用风险外溢**
   如果你自己也对下游月结，上游又对你月结，一旦中间某个环节断掉，风险会连锁传导。

**好处**：缓解短期资金压力，便于扩大采购和周转，也能用账期测试供应商是否稳定。

## 给小商家的实操建议

- **现金结算**：适合小额、高频、关系熟的采购；一定留好转账记录或收据，尽量用银行/移动支付代替纯现金。
- **月结账期**：适合稳定大供应商，但要**书面约定账期、对账方式、逾期责任**，并控制单家供应商的欠款上限。
- **混合策略**：核心走量品类用现金拿低价，辅料或季节性品类用短账期；不要把所有采购押在一种结算方式上。
- **留足安全垫**：无论哪种方式，手里至少留能覆盖 1–2 周进货和损耗的流动资金。
- **关键看两点**：你的**下游回款周期**和**水果损耗速度**。水果损耗越快，越不适合长账期压货。

一句话总结：**现金结算的风险是“现在没钱”，月结的风险是“以后可能收不回或还不上”；小商家更适合短账期+部分现金的组合，而不是走极端。**
