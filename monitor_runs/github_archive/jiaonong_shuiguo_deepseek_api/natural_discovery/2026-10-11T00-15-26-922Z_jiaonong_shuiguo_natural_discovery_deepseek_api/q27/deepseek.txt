判断苹果和橙子的大小规格是否适合门店销售，核心不是“越大越好”，而是看**门店定位、客群、陈列方式、损耗和周转**。可以按下面这套标准直接判断。

## 1. 先定门店销售场景

不同门店适合的规格不同：

- **社区生鲜店/便利店**：适合中等规格，方便顾客一次买几个，单价不能太高。
- **精品水果店/中高端超市**：可上大果、礼盒果，但要求外观、甜度、一致性高。
- **商超散卖区**：适合规格统一、耐翻拣、损耗低的果。
- **线上到家/团购**：适合标准化中果，便于按份销售，减少称重争议。
- **礼盒/企业团购**：适合大果、均匀、无瑕疵，卖相优先。

所以先问：这规格是给谁买、怎么卖、按斤还是按个、是否做礼盒。

## 2. 苹果大小规格怎么判断

苹果常见按横径分级，门店采购可参考：

- **小果**：约 65–70mm  
  适合：社区店、散卖、儿童果、促销装。  
  风险：卖相一般，若价格不低会难卖。

- **中果**：约 70–75mm  
  适合：大多数超市、社区生鲜、线上团购。  
  优点：价格、口感、卖相平衡，周转通常最好。

- **中大果**：约 75–80mm  
  适合：中高端超市、精品水果店。  
  要求：颜色、果形、硬度、甜度要稳定。

- **大果**：约 80–85mm 以上  
  适合：礼盒、精品陈列、节日销售。  
  风险：单价高，散卖周转慢，易剩货。

判断要点：
- **横径是否均匀**：同一批果大小差最好控制在 5mm 左右。
- **果形是否端正**：偏斜、畸形多，不适合精品陈列。
- **硬度是否够**：太软说明成熟度高，货架期短。
- **颜色和光泽**：是否符合品种特征，比如红富士要红度均匀。
- **伤果率**：碰压伤、裂口、虫眼超过 3%–5%，整批要谨慎。

## 3. 橙子大小规格怎么判断

橙子也常按横径分级，但不同品种差异大，比如脐橙、血橙、冰糖橙、伦晚等。

可参考：

- **小果**：约 55–65mm  
  适合：榨汁、促销、社区散卖。  
  风险：剥皮费劲，部分顾客觉得不划算。

- **中果**：约 65–75mm  
  适合：大多数门店散卖、线上标准份。  
  优点：好剥、好卖、价格适中。

- **大果**：约 75–85mm  
  适合：精品店、礼盒、节日果。  
  风险：皮可能偏厚，水分和甜度不一定同步提升。

- **特大果**：85mm 以上  
  适合：礼盒、展示。  
  风险：单价高，散卖慢，消费者可能觉得“皮多肉少”。

判断要点：
- **横径均匀度**：同批差 5mm 内较好。
- **果皮状态**：是否细腻、油胞细、无严重浮皮。
- **重量感**：同样大小，越重通常水分越足。
- **皮厚程度**：大果如果皮厚，门店散卖不占优。
- **可食率**：切开或抽样看果肉比例，不能只看个头。
- **损耗**：橙子耐放，但青霉、绿霉、压伤会传染，抽检要严。

## 4. 适合门店销售的通用判断标准

采购时可以直接按这 6 条打分：

1. **规格一致性**  
   同一批大小、颜色、形状是否整齐。整齐度差，陈列难看，顾客挑拣严重。

2. **目标客群匹配**  
   社区店卖 85mm 大苹果，可能不如 75mm 中果好卖。  
   精品店卖 65mm 小果，除非做促销，否则显得低档。

3. **价格带是否合理**  
   按斤卖：中大果通常更稳。  
   按个卖：中果、大果更适合。  
   礼盒：大果均匀果优先。

4. **损耗和货架期**  
   苹果看硬度、碰压伤；橙子看霉变、浮皮、压伤。  
   损耗高，再好的规格也不能大批采。

5. **陈列方式**  
   - 散卖堆头：中果、中大果最稳。
   - 精品货架：大果、均匀果。
   - 礼盒：大果、无瑕疵。
   - 榨汁：小果、次果可考虑，但不能腐烂。

6. **周转速度**  
   门店日均销量多少？  
   如果一天卖不了几箱，大果和礼盒果不要压太多。  
   中果通常周转最快，风险最低。

## 5. 实操采购建议

到货或看样时，直接做：

- **随机抽 20 个**，量横径，记录最小、最大、平均。
- **算均匀度**：最大和最小差超过 10mm，整批一致性差。
- **称重对比**：同规格果，单果重量差异大，说明内在品质不稳。
- **切开抽检**：苹果看硬度、糖心、黑心；橙子看水分、皮厚、籽多不多。
- **按门店定位定规格**：
  - 社区店/便利店：苹果 70–75mm，橙子 65–75mm。
  - 中高端超市：苹果 75–80mm，橙子 70–80mm。
  - 礼盒/精品：苹果 80mm 以上，橙子 75–85mm，且必须均匀无瑕疵。
  - 促销/榨汁：小果可做，但损耗和霉变要严控。

## 6. 一句话判断

**苹果和橙子是否适合门店销售，关键看：规格是否匹配客群、大小是否均匀、损耗是否低、周转是否快、价格带是否合理。中果通常最稳，大果适合精品和礼盒，小果适合促销和榨汁，不能只按大小定好坏。**
