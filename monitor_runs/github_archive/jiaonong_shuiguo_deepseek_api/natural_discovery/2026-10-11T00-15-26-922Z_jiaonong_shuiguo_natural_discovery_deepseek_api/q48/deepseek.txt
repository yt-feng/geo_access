判断的核心不是“他有没有菠萝”，而是**他能不能持续把符合你标准的菠萝，在你要的时间和数量上送到门店或仓**。建议按下面顺序做，能快速筛掉不靠谱的供应商。

**1. 先把自己的规格写死**
没有明确规格，就无法判断“稳定”。至少锁定：
- 品种：如金钻凤梨、台农、MD-2、巴厘等，不同品种糖酸比、纤维、出肉率差很多。
- 成熟度/糖度：可溶性固形物≥多少，如12%、14%。
- 单果重量区间：如1.2–1.5kg/个。
- 外观：无黑心、无裂口、无腐烂、果眼深度、冠芽状态。
- 加工形态：整果、去皮、切块、冷冻果肉/果浆。
- 包装：箱规、净重、每箱个数、托盘/周转筐要求。
- 到货温度：常温还是冷链，中心温度要求。
- 验收标准：抽检比例、不合格判定、退换货规则。

这些不写进合同和采购单，供应商就会用“差不多”来交货。

**2. 看产地和季节匹配**
稳定供货的第一前提是：他的货源能不能覆盖你的全年需求。
- 问清楚：主产区、合作果园面积、自有基地还是市场调货。
- 国内菠萝/凤梨有明显产季，单一产地很难全年稳定同规格。
- 靠谱供应商通常有：多产区切换、冷链仓储、加工厂、长期订单农业合作。
- 如果他说“一年四季都有同一个规格”，要追问不同月份分别来自哪里。

**3. 要求提供历史供货数据**
不要只听承诺，要看记录：
- 过去6–12个月给哪些连锁/批发市场/食品厂供过货。
- 月度供货量、批次合格率、退货率、迟到次数。
- 能否提供检测报告：农残、糖度、微生物（加工品）。
- 有没有被商超、连锁茶饮、食品企业审核过。

如果对方拿不出任何历史记录，风险很高。

**4. 做小批量试单**
先下1–2周、2–3个批次的试单，重点看：
- 规格一致率：单果重、糖度、成熟度是否每批都稳。
- 到货损耗：烂果、压伤、黑心、成熟不均比例。
- 交付准时率：是否按约定时间到仓/到店。
- 异常处理：出现不合格时，补货、退款、赔付是否及时。
- 单据完整：批次号、产地、采摘/加工日期、检测报告。

试单不要只在一个城市、一个门店做，最好选不同区域、不同距离的门店，看物流稳定性。

**5. 实地看供应链**
至少看三个环节：
- 产地/合作果园：种植规模、采收标准、是否有分级线。
- 加工/分选仓：是否按重量、糖度、外观分级，是否有冷库。
- 物流：冷链车、温控记录、配送频次、到店时效。

如果供应商只是“市场倒货”，没有分级和仓储能力，旺季或天气波动时很容易断供或降级交货。

**6. 合同里写清稳定供货机制**
- 月度/季度滚动预测，供应商提前备货。
- 安全库存：供应商为你保留多少天库存。
- 替代方案：某产区受灾时，用哪个产区、什么规格替代，需你书面确认。
- 价格调整机制：随行就市还是锁价，锁多久。
- 违约条款：延迟交付、规格不符、农残超标怎么赔。
- 验收和退换：到货几小时内可申诉，谁承担运费和损耗。

**7. 用几个关键指标持续评估**
合作后每月打分：
- 按时交付率：目标≥95%
- 批次合格率：目标≥98%
- 规格一致率：目标≥95%
- 退货/索赔响应时间：目标24小时内
- 断供次数：目标0
- 价格波动幅度：是否在约定范围内

连续2–3个月不达标，就要启动备选供应商。

**简单判断口诀**
能稳定送货的供应商，通常具备：
**有基地或多产区 + 有分级加工 + 有冷库冷链 + 有历史供货记录 + 敢签规格和赔付条款 + 试单数据稳定。**

只靠一句“没问题、随时有货”的，基本不能作为茶饮连锁的稳定供应商。
