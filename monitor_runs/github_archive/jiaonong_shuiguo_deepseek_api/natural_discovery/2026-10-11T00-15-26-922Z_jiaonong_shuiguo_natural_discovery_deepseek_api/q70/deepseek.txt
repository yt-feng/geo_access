# 坏果责任条款的核心思路

批发交易中坏果责任的关键，不是"谁负责"一句话，而是**把风险按环节切开、用可验证的标准定责、用时间节点锁定举证**。建议从以下五个层面写：


## 一、先明确"坏果"的定义和计量方式

模糊的"坏果"最容易扯皮。建议在合同里直接量化：

- **分级定义**：轻微压伤/表皮瑕疵（不影响销售）算不算坏果？腐烂、霉变、汁液渗出才算？建议约定"以腐烂、霉变、严重软烂渗液为坏果，表皮轻微擦伤不计"。
- **计量口径**：按重量计还是按件数计？抽样还是全检？
- **抽样规则**：约定抽检比例（如每批次随机抽10%），以及抽样不合格时如何推定整批（如抽样坏果率超X%，整批按同比例计损）。

> 示例表述：*"坏果指果实出现腐烂、霉变、汁液渗出或严重软烂无法销售的情形。以卸货时随机抽取不低于10%的货物检验，坏果率=抽样坏果重量÷抽样总重量。"*


## 二、按运输环节切分责任节点

损耗发生在哪一段，责任就归哪一段。常见节点：

| 环节 | 风险归属建议 |
|------|------------|
| 装车前（产地） | 卖方负责，装车前检验合格 |
| 运输途中 | 谁安排运输谁负责；买方自提则买方担，卖方送货则卖方担 |
| 卸货时 | 当场验收，超时未验收视为合格 |
| 卸货后 | 买方负责（除非能证明是隐蔽瑕疵） |

关键动作：**把验收时点和责任转移点写死在合同里**，比如"货物运抵指定地点、买方当场验收签字后，风险转移至买方"。


## 三、给责任方设"免赔额"和"赔付上限"

批发损耗很难做到零，全部由一方承担不现实。行业常见做法：

- **约定合理损耗率**（如3%以内双方各担或买方自担），超出部分才追责；
- **超出部分按比例赔付**：如"坏果率超过3%的，超出部分由卖方按当批次货款的X%赔付，或按坏果重量退款/补货"；
- **设赔付上限**，避免无限责任。

> 示例：*"合理损耗率为3%。卸货验收坏果率≤3%的，买方自担；超过3%的，超出部分由卖方按对应货款金额退款，或补发同等数量货物，二者由买方选择。"*


## 四、锁定检验和异议的时间窗口

这是最容易被忽略、也最容易翻车的地方：

- **当场验收**：约定卸货时必须检验并出具书面记录（拍照/视频+签字），
- **异议期**：隐蔽瑕疵（如内部腐烂）可约定"卸货后X小时内提出，逾期视为合格"，
- **举证责任**：谁主张谁举证，要求提供带时间戳的照片、视频、第三方检测或公证记录。

> 示例：*"买方应在卸货现场完成验收并签署验收单。对表面可见坏果，当场提出；对隐蔽瑕疵，应在卸货后24小时内书面通知卖方并提供影像证据，逾期视为验收合格。"*


## 五、写清赔付方式和争议解决

- **赔付方式**：退款、补货、折价、还是抵扣下批货款？二选一或由买方选，避免"既要退款又要补货"。
- **争议解决**：约定检验机构（如当地质检/第三方检测），约定管辖法院或仲裁。
- **不可抗力/自然损耗**：明确极端天气、长途运输自然失水等是否免责。


## 实操建议（一句话版）

**"定义清楚坏果 + 验收当场做 + 合理损耗自担 + 超损按比例赔 + 异议限时提"**——这五点写进合同，基本能覆盖80%的坏果纠纷。

如果金额较大，建议把验收流程（谁验、怎么拍照、验收单模板）作为合同附件，比只在正文写一句"坏果由卖方负责"有效得多。
