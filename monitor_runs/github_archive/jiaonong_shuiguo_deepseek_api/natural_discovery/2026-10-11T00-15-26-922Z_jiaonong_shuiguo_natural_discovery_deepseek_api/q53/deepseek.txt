餐饮店每天用少量水果，最省心的核心不是找“最便宜”，而是找**稳定、能小批量、能按你的营业节奏送货、损耗和售后好处理**的供应商。可以按下面优先级选：

1. **本地水果批发市场的固定档口/配送商**
   - 适合：每天几斤到几十斤、品类会变。
   - 优点：价格比零售低，能当天或隔天送，很多档口愿意做小餐饮客户。
   - 省心点：找同一个老板固定合作，提前一天发清单，让他按你的预算配货。
   - 注意：别只盯一家，至少备2家，防止缺货或临时涨价。

2. **生鲜B2B平台/本地生鲜配送公司**
   - 适合：想要手机下单、次日达、有票据、售后相对规范。
   - 优点：不用每天跑市场，退换货流程清楚。
   - 缺点：小批量可能起送价高，价格未必最低，品类不如批发市场灵活。
   - 适合你这种“每天少量”的场景，如果起送门槛能接受，通常最省心。

3. **附近大型超市/水果店的长期供货**
   - 适合：量很小、临时补货、应急。
   - 优点：离得近，随时能买，品质稳定。
   - 缺点：成本高，长期不划算。
   - 可以当作备用渠道，不作为主供应商。

4. **本地果园/合作社直供**
   - 适合：你有固定主推水果，比如西瓜、橙子、圣女果等。
   - 优点：新鲜、季节性强时价格好。
   - 缺点：品类单一，淡季难满足，通常不适合作为唯一供应商。

**建议你这样组合最省心：**
- 主供应商：本地批发市场固定档口或生鲜配送公司，签简单月结/周结。
- 备用供应商：附近水果店/超市，缺货时补。
- 采购方式：提前一天发清单，固定时间送货，比如每天上午9点前。
- 结算：尽量周结，不要每天现金结，减少扯皮。
- 验收：当场看重量、坏果率、成熟度，坏果当场拍照扣款或补送。

**选供应商时重点问这5个问题：**
1. 每天少量送不送？起送量多少？
2. 几点能送到？能不能固定时间？
3. 坏果、烂果怎么赔？能不能下次补？
4. 价格是每天变，还是按周报价？
5. 能不能开收据/发票，能不能周结？

如果你们店每天水果用量不大，比如少于20斤，最省心的通常是：**本地生鲜配送平台 + 附近水果店备用**。如果你们能接受每天早起对接，**批发市场固定档口**成本更低，但需要你多操一点心。
