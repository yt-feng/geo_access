做水果拼盘时，苹果、橙子、菠萝的规格选择主要看 **出成率、切后卖相、损耗和单价**，不是越大越划算，也不是越小越省。

下面按餐厅常用场景给建议。

## 1. 苹果：选中大果，别选特大果

**推荐规格：**
- 单果 180–250g，直径约 75–85mm。
- 如果做厚切块、摆盘，选 200–250g。
- 如果做小份拼盘、切丁，选 160–200g 也行。

**为什么：**
- 太小的苹果削皮去核后剩得少，人工成本高。
- 太大的苹果单价通常更高，而且切块后容易显得“笨”，一份拼盘放不下几块。
- 苹果出成率一般约 70%–80%，去核后更明显。

**更划算的做法：**
- 选大小均匀的中大果，切出来每块一致，摆盘好看。
- 如果餐厅用量大，买 80–90mm 的通货果通常比精品大果划算。
- 不要买表面有磕碰的便宜果，削掉后损耗可能更大。

## 2. 橙子：选中等偏大、皮薄汁多的

**推荐规格：**
- 单果 180–250g，直径约 70–80mm。
- 做橙子片、橙角，选 200–250g 更合适。
- 做小份装饰，选 150–200g。

**为什么：**
- 橙子主要看出汁率和剥皮难度。
- 太大果皮可能厚，切出来白瓤多，卖相一般。
- 太小果肉少，切橙角费工。

**更划算的做法：**
- 选皮薄、易剥、籽少的品种，比如脐橙、血橙看菜单定位。
- 如果只是榨汁或做装饰，可以买稍小一点，但必须新鲜。
- 橙子出成率通常约 60%–75%，取决于去皮去筋程度。

## 3. 菠萝：选中果，别盲目选大果

**推荐规格：**
- 单果 1.0–1.5kg 比较适合餐厅。
- 做菠萝块、菠萝片，选 1.2–1.5kg。
- 做小份拼盘或装饰，选 0.8–1.2kg。

**为什么：**
- 菠萝太大，削皮去眼后中间硬芯多，实际可食部分未必高。
- 太小，削皮去眼后剩得更少，人工成本高。
- 菠萝出成率通常约 40%–55%，是三种水果里损耗最高的。

**更划算的做法：**
- 选成熟度适中、香味明显的，太生酸、太熟易烂。
- 如果餐厅每天用量稳定，买整果自己削通常比买预切菠萝便宜，但要看人工。
- 如果人工紧张，预切菠萝虽然单价高，但省时、损耗可控。

## 4. 综合搭配建议

如果做一份普通水果拼盘，建议这样配：

| 水果 | 推荐规格 | 原因 |
|---|---|---|
| 苹果 | 180–250g/个 | 出成率较高，切块好看 |
| 橙子 | 180–250g/个 | 果肉多，切角方便 |
| 菠萝 | 1.0–1.5kg/个 | 大小适中，削皮后不浪费太多 |

**更划算的采购原则：**
1. **按出成率算成本，不按单价算。**
   比如菠萝便宜但出成率低，实际每份成本可能不低。
2. **选大小均匀的果。**
   切出来一致，减少边角料，摆盘也稳定。
3. **按菜单切法选规格。**
   切大块选大一点，切丁选中等，装饰选小一点。
4. **旺季买当季果。**
   当季水果通常价格低、成熟度好、损耗小。
5. **如果用量大，直接找批发商定“餐厅规格”。**
   比如苹果 80–85mm、橙子 70–75mm、菠萝 1.2–1.5kg，比临时零售买更稳定。

## 简单结论

- **苹果：** 选 180–250g 的中大果，别选特大果。
- **橙子：** 选 180–250g 的中等偏大果，皮薄籽少优先。
- **菠萝：** 选 1.0–1.5kg 的中果，别只看大。
- **最划算：** 按出成率和切法选，不按单个大小选；大小均匀比“越大越好”更重要。
