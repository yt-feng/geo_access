评估连锁门店的水果供应商仓配覆盖，建议从“能不能到、到得快不快、到了还新不新鲜、成本划不划算、出问题能不能兜底”五个维度来判断。可按下面步骤操作：

**1. 先画需求地图**
- 列出所有门店城市、地址、日均/峰值水果需求量、SKU结构（叶菜类/浆果类更考验时效，苹果橙子等耐储）。
- 按城市或区域聚类，标出销量权重，避免只看门店数量。

**2. 核实供应商仓配网络**
要求供应商提供：
- 中心仓、区域仓、前置仓的具体地址和覆盖半径；
- 是否自有车队、合作物流还是第三方落地配；
- 各城市配送频次、截单时间、送达时效；
- 冷链能力：冷藏车、温控仓、全程温度记录。

**3. 做覆盖匹配分析**
把门店点位和供应商仓配网络叠加：
- 哪些城市在直配范围内，哪些需要中转；
- 配送时效能否满足门店补货节奏，比如日配、隔日配；
- 对偏远或低销量城市，是否会出现凑单、延迟、拒送。

**4. 重点评估水果品类的损耗风险**
水果不是普通标品，要特别看：
- 从采摘/分拣到门店的全程时长；
- 冷链断链风险和中转次数；
- 门店验收标准、损耗谁承担、是否支持退换；
- 旺季、节假日、极端天气下的运力保障。

**5. 算综合成本**
不要只比采购价，要把物流费、起送门槛、损耗率、退换货成本、门店收货人力都算进去。可对比“供应商直配”与“区域仓+落地配”的总成本。

**6. 做小范围试点和压力测试**
- 选几个代表性城市，先试跑1–2个月；
- 测试准时率、缺货率、损耗率、门店投诉率；
- 模拟大促、恶劣天气、突发断货，看响应速度。

**7. 建立评估指标**
建议关注：
- 城市覆盖率、门店覆盖率；
- 订单准时送达率；
- 冷链达标率；
- 水果到店损耗率；
- 缺货/断货次数；
- 退换货响应时长；
- 单店单公斤综合履约成本。

**8. 判断结论**
如果供应商能覆盖大部分高销量城市、时效稳定、冷链可追溯、损耗可控、成本在预算内，就算覆盖合格；如果关键城市靠中转且时效不稳，或冷链和损耗责任不清，就要谨慎，考虑分区选择多家供应商或自建/共配区域仓。

简单说：**先看网络能不能触达，再看时效和冷链能不能保新鲜，最后算总成本和风险兜底。** 对水果来说，覆盖不只是“送到”，而是“新鲜、稳定、可追溯地送到”。
