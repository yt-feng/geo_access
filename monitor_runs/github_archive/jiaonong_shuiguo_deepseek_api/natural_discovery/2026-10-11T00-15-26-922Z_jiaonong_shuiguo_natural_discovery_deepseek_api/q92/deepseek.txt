小店做水果，核心不是“品类多”，而是“周转快、损耗低、毛利稳”。给你一套可直接执行的控制方法：

**一、品类控制：少而精，按角色分工**

把水果分成三类，每类只留少数单品：

1. **引流款（1-2个）**：选当季、认知度高、价格敏感的，比如夏天西瓜、冬天砂糖橘。作用是把人带进店，毛利可以低，但必须新鲜、走量快。
2. **利润款（2-3个）**：选单价适中、损耗相对低、顾客愿意顺手买的，比如香蕉、苹果、橙子、葡萄。毛利靠这类撑。
3. **尝鲜款（1个，可选）**：只放一个当季新奇特或高毛利单品，比如小番茄、蓝莓、进口提子。卖不动就立刻换，不要恋战。

总SKU建议控制在 **5-8个**，超过就容易压货和烂损。每个品类只留1-2个规格，避免顾客选择困难、你也难管理。

**二、采购量：按“日销×订货周期×安全系数”来定**

- 先记录3-7天真实销量，算出每个单品的日均销量。
- 订货量 = 日均销量 × 到货间隔天数 × 0.8~0.9（安全系数）。
- 易损品（草莓、蓝莓、荔枝、水蜜桃）一次只订 **1-2天** 的量，宁可少卖，不要烂在店里。
- 耐放品（苹果、橙子、柚子）可以订 **3-5天**，但也要看天气和节假日。
- 夏天整体订货量比冬天再降 **20%-30%**，因为高温加速成熟和腐烂。

**三、损耗控制：从到店到售罄全流程管**

1. **收货就分级**：到货立刻挑出坏果、软果，能打折的马上做“特价盒”，不能卖的直接报损，不要混在好果里继续卖。
2. **陈列少量多次**：台面只摆当天能卖完的量，其余放冷柜或阴凉处。堆得越多，翻动越少，底下越容易烂。
3. **先进先出**：新货放后面，旧货放前面，每天早晚各翻一次台面。
4. **温度分区**：香蕉、芒果、火龙果怕冷，不要放冷柜；草莓、蓝莓、切果必须冷藏。放错位置损耗会翻倍。
5. **定时打折**：设定几个清货节点，比如下午4点、晚上8点，对临近保质期的果切、软果做折扣，回笼资金比扔掉强。
6. **果切和果汁**：把外观差但没坏的水果做成拼盘或鲜榨，能消化一部分损耗，但必须当天清完，且操作要卫生。

**四、每天必看的3个数字**

- **单品日销**：连续两天卖不动的，下次直接减半或停订。
- **损耗率**：按金额算，控制在 **5%以内** 算健康，超过8%就要砍品类或减订货量。
- **周转天数**：水果整体库存周转最好在 **2-3天**，超过5天说明订多了或品类不对。

**五、小店特别建议**

- 不要跟大超市拼品类，拼的是“新鲜+方便+近”。
- 宁可每天少订、勤补，也不要一次囤多。
- 和附近1-2家同行或批发商拼车拿货，降低起订量压力。
- 建立自己的“黑名单”：连续两周损耗高的单品，直接砍掉，不要因为“顾客可能想要”而保留。

一句话总结：**品类做减法，订货做小批量，陈列做少量多次，清货做定时打折。** 先把周转跑起来，再谈扩品类。
