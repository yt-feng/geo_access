香蕉和菠萝是社区团购里最容易亏的两类水果，核心问题是：**它们不是"坏了才赔"，而是"还没到手就开始坏"**。控制售后不能只靠售后规则，得从选品→到货→分拣→履约→售后五个环节一起卡。

## 一、先承认一个前提：这两类不适合"零售后"

香蕉和菠萝的售后率天然比苹果橙子高。你要做的不是消灭售后，而是把它压到可承受范围，并且让售后规则清晰、不扯皮。

建议给这两类设一个**单独的损耗预算**（比如销售额的3%～6%），而不是和耐储水果混在一起考核。

## 二、香蕉：核心是"熟度控制"，不是"新鲜度"

香蕉的问题几乎都出在**到货时已经过熟**。

**采购端**
- 明确要"青香蕉"或"微黄"，不要"金黄熟透"的货。
- 和供应商约定：到仓时香蕉必须是硬的、可催熟的，不能是已经出糖点的。

**到货端**
- 到货当天必须抽检：捏硬度、看有没有黑斑、闻有没有酒味。
- 一旦发现有催熟过度或已出糖点，当批不能按正常价开团，要么降价做"即食特价"，要么直接走内部处理，别硬卖。

**履约端**
- 香蕉怕压、怕闷、怕高温。团长点要"平铺、不堆叠、通风"。
- 尽量做到**当天下单、次日到、当天取**，不要让它在你手里过夜太久。
- 夏天要缩短链路，必要时走冷链或减少单次团量。

**售后规则**
- 香蕉售后只认"到手即坏/大面积黑斑/发软出水"，轻微磕碰不赔。
- 关键在于：**开团文案里就写清"青蕉到货，需自行放熟"**，把预期管理前置，能砍掉一大半售后。

## 三、菠萝：核心是"切果时机"和"果眼/黑心"

菠萝的售后集中在两类：**黑心（内部坏）**和**切开后口感差 / 果眼发黑**。

**采购端**
- 尽量选成熟度一致的整果，别混收不同批次的。
- 要求供应商做**抽切开检验**，尤其看有没有黑心。

**到货端**
- 菠萝的坏是"隐藏的"，外表看不出来。所以必须**抽切**：随机开几个，看果肉颜色和味道。
- 如果抽切发现黑心率偏高，整批不能按正常开团。

**履约端**
- 菠萝相对耐放，但怕冻、怕挤压。常温通风存放，别和香蕉堆一起（乙烯会互相催熟）。
- 如果做"代削皮/代切块"，要**现切现取**，切好放置超过几小时就容易出水变质，这本身就是售后来源。

**售后规则**
- 整果：切开发现黑心/烂心的，凭照片赔。
- 切块：明确"现切需当天取，隔夜不赔"。
- 最关键的一条：**"切开后才发现问题"的售后，必须有清晰的举证标准和时效**（比如取货后24小时内、需带包装照片）。

## 四、通用规则：把售后成本压下去的四件事

1. **开团前做小批到货测试**：新供应商、新品种先小量试，别直接大团。
2. **到货验收写进合同**：把香蕉熟度、菠萝黑心率写成可抽检的标准，不合格整批退或折价。
3. **售后规则前置到开团页**：把"轻微磕碰不赔""需当天取""青蕉需自熟"写清楚，比事后解释有用得多。
4. **区分"品质售后"和"服务售后"**：品质问题该赔就赔，别抠；但因为顾客放太久、没及时取导致的，要有明确不赔条款，否则会被薅。

## 五、一句话总结

香蕉控**熟度**，菠萝控**黑心**；两者都靠**缩短链路 + 到货抽检 + 售后规则前置**来压售后。真正省钱的不是售后话术，而是**在开团之前就把不合格的货挡在门外**。
