超市采购水果时，供应商通常需要提供的资料，取决于**水果品类、是否进口、超市自身风控要求、当地市场监管要求**。实操上一般分为“基础资质证明”和“批次检测/合格证明”两类。

**一、基础资质证明**
1. **营业执照**
   - 供应商合法经营主体证明。
2. **食品经营许可证/食品生产许可证**
   - 若供应商是销售方，通常需食品经营许可证；若为生产加工或分装方，可能涉及食品生产许可证。
3. **供货合同或采购协议**
   - 明确质量责任、退换货、农残超标责任等。
4. **品牌授权/经销证明**
   - 若是品牌水果、进口水果或特定渠道产品，可能需要授权书或经销证明。

**二、批次进货证明**
1. **进货凭证/销售单/送货单**
   - 应包含品名、规格、数量、批次、日期、供应商信息等。
2. **产地证明或采购来源证明**
   - 尤其对国产水果、基地直采、合作社供货时较常见。
3. **合格证/自检报告**
   - 供应商或产地对批次水果出具的合格证明。
4. **承诺达标合格证**
   - 食用农产品常见，尤其规模化生产主体、合作社等可能提供。

**三、检测报告**
1. **农药残留检测报告**
   - 最常见、最核心。通常是批次检测或定期检测报告。
   - 重点看：检测项目、检测方法、检测结果、报告编号、检测日期、批次是否对应。
2. **重金属、污染物检测报告**
   - 视品类和风险而定，如某些根茎类、叶菜类、环境风险较高产区。
3. **食品添加剂/保鲜剂检测**
   - 如打蜡、防腐保鲜处理的水果，可能涉及相关项目。
4. **进口水果检测及入境证明**
   - 进口水果通常需要：
     - 海关入境货物检验检疫证明；
     - 报关单；
     - 核酸检测证明（如政策要求时期）；
     - 标签、产地、果园/包装厂注册信息等。
5. **第三方检测报告**
   - 大型超市常要求具 CMA/CNAS 资质的第三方检测报告。
   - 但要注意：检测报告一般只对送检批次负责，不能简单等同于所有批次合格。

**四、超市实操中通常怎么要求**
- **普通国产水果**：营业执照、食品经营许可证、送货单、批次合格证或农残检测报告。
- **高风险水果**：如叶菜类、草莓、葡萄、豇豆等，通常要求更严格的农残检测报告。
- **进口水果**：入境货物检验检疫证明、报关单、标签审核资料等。
- **长期供应商**：可能要求年度资质+每批次合格证明+定期第三方检测。
- **农贸市场/个体供应商**：若无法提供齐全资料，超市通常会自行快检或要求补交。

**五、验收时重点核对**
1. 报告上的**品名、批次、日期**是否与到货一致。
2. 检测报告是否在有效期内，是否覆盖本批次。
3. 检测机构是否具备 CMA/CNAS 资质。
4. 农残检测结果是否低于国家标准限值。
5. 进口水果的检验检疫证明是否与货物一致。
6. 证照是否在有效期内，经营范围是否覆盖。

**六、建议**
如果你是超市采购方，最好在合同里明确：
- 供应商必须随货提供批次合格证明；
- 定期提供第三方农残检测报告；
- 农残超标时承担退货、赔偿和监管责任；
- 进口水果必须提供入境检验检疫证明和报关单。

如果你是供应商，建议按“基础证照+批次合格证+农残检测报告+进口证明”准备，具体清单再向超市品控或当地市场监管部门确认，因为不同超市和地区要求会有差异。
