从商超经营角度，**大多数门店更适合“整果为主 + 切果为辅/引流”**，而不是单纯只卖切好的。原因如下：

1. **毛利与损耗**
   - 整果：损耗相对可控，主要风险是磕碰、过熟、滞销。
   - 切果：需要人工、包材、冷链陈列，且切开后保质期短，损耗和食品安全风险更高。
   - 如果门店客流不够大、周转不够快，切果很容易变成报损。

2. **客群需求不同**
   - 整果适合：家庭采购、价格敏感型顾客、送礼/囤货型顾客。
   - 切果适合：单身、上班族、即食需求、小家庭、怕麻烦的顾客。
   - 所以不是二选一，而是**按客群分层**。

3. **更适合的门店类型**
   - 社区超市、生鲜超市：整果为主，切果做小份试吃/即食杯。
   - 商圈店、写字楼店、便利店型商超：切果比例可以更高。
   - 高端精品超市：可做精品整果 + 高颜值切果盒。
   - 低客流门店：不建议大量切果，优先整果。

4. **建议的组合策略**
   - **整果做主力**：按大小、成熟度分级，散卖 + 促销装。
   - **切果做补充**：只做小份、高周转、即食场景，比如菠萝杯、拼盘。
   - **用切果带动整果**：试吃引流，顾客觉得甜再买整果。
   - **动态调整比例**：按门店时段、客流、天气、节假日调整。
     - 夏季、午后、写字楼店：切果可多些。
     - 冬季、社区店、晚间：整果更稳。

5. **关键判断指标**
   - 切果日周转能不能做到当天基本售完？
   - 切果毛利能不能覆盖人工、包材、损耗？
   - 整果有没有稳定客流和促销消化能力？
   - 门店有没有冷藏陈列和防尘防蝇条件？

**结论：**
如果只能选一个，**优先卖整果**。  
如果条件允许，**最佳是“整果为主、切果为辅”**：整果保销量和毛利，切果抓即食客群和提升客单价。切果不要盲目上量，先小份测试周转，再决定是否扩大。
