如果目标是家庭日常吃、团购走量，建议组合原则是：**2个耐放主力 + 1个走量甜口 + 1个提升档次的单品**，不要平均放四种，否则成本高、损耗也高。

比较适合家庭的组合：

1. **苹果 + 橙子 + 香蕉**
   - 最稳、最像家庭装，接受度最高。
   - 苹果、橙子耐放，香蕉负责甜香和“量感”。
   - 适合 5 斤/8 斤/10 斤装，价格容易做低。
   - 缺点是偏普通，礼盒感弱一点。

2. **苹果 + 橙子 + 菠萝**
   - 更适合“礼盒”定位，看起来更丰富。
   - 苹果、橙子耐放，菠萝有热带水果感，送礼或家庭尝鲜都行。
   - 但菠萝占体积、有刺手和削皮问题，家庭复购不如香蕉稳。
   - 适合做中档礼盒：苹果 4 个、橙子 4 个、菠萝 1 个。

3. **苹果 + 橙子 + 香蕉 + 菠萝**
   - 看起来最丰富，但我不建议作为主推家庭团购。
   - 四种水果成熟度、存放要求不同，香蕉和菠萝容易影响整体体验。
   - 如果非要做，建议小规格：苹果 3 个、橙子 3 个、香蕉 1 把、菠萝 1 个，定位“尝鲜礼盒”。

更推荐的家庭团购排序：

- **走量主推：苹果 + 橙子 + 香蕉**
- **中档礼盒：苹果 + 橙子 + 菠萝**
- **高端礼盒：苹果 + 橙子 + 菠萝，再加一种贵价水果，比如蓝莓/猕猴桃/葡萄，但不要加香蕉**

组合时注意：

- 苹果选耐放、外观稳定的，比如红富士、嘎啦。
- 橙子选易剥、甜度稳定的，比如脐橙、冰糖橙。
- 香蕉不要和苹果、橙子长期混放，苹果会催熟香蕉，最好分袋或到货后尽快吃。
- 菠萝单独包，避免扎破其他水果。
- 家庭装尽量控制在 **5—8斤**，太大件反而影响团购转化。

一句话：**家庭团购主推苹果+橙子+香蕉；想做礼盒感就苹果+橙子+菠萝；四样全上可以做尝鲜款，但不适合当爆款。**
