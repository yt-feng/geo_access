判断哪个规格更容易出货，核心看“下游是谁、怎么用、什么价带最好卖”，而不是单看大小。给你一套可直接执行的判断方法：

## 1. 先按用途分规格，不要只按重量分

菠萝常见出货逻辑：

- **小果（约0.8–1.2斤/个）**：适合水果店散卖、切果盒、果汁店、餐饮店。走量快，但单价低。
- **中果（约1.2–1.8斤/个）**：最通用，家庭购买、水果店、社区团购都容易接受，通常最好出货。
- **大果（约1.8–2.5斤以上）**：适合礼盒、商超堆头、餐饮切片、加工厂，但家庭客群会嫌大、一次吃不完。
- **特大果/精品果**：适合礼盒、电商直播、高端商超，量不一定大，但利润可能高。

所以先问自己：你手里这批货，主要能供给哪类客户？

## 2. 看四个硬指标，快速判断

### ① 下游客户结构
- 如果客户是**水果店、社区团购、路边摊**：中果通常最好出。
- 如果客户是**果汁店、餐饮、切果摊**：小果、中果出得快。
- 如果客户是**商超、礼盒、电商**：大果、精品果更有溢价，但要求外观高。

### ② 价格带
同一批货，把不同规格按“每斤价”和“每个价”都算出来：
- 中果如果每个价格落在消费者习惯区间，比如“10元2个/3个”，通常动销最快。
- 大果如果单果价格明显跳档，比如一个要15–20元，家庭客群会犹豫。
- 小果如果按斤卖便宜，但剥皮麻烦，切果店反而更喜欢。

**结论：不是越大越好卖，而是“单价看起来不贵、用起来方便”的规格最好卖。**

### ③ 外观和成熟度
- 中果、大果如果果形正、芽眼浅、无黑心、无裂口，适合商超和礼盒。
- 小果如果外观一般，但成熟度好，适合走加工、果汁、切果。
- 如果成熟度偏高，必须走快消渠道：路边摊、果汁店、社区团购，不能压商超。

### ④ 季节和区域
- 夏季：切果、果汁、散卖需求大，中小果走得快。
- 节假日：礼盒需求上升，大果、精品果更好卖。
- 北方市场：偏大果、耐储运规格。
- 南方产区附近：中果、小果散卖更快，因为消费者买鲜食多。

## 3. 最实用的测试方法

不要凭感觉压一个规格，直接做小批量测试：

1. **同一市场、同一时间，分3个规格报价**
   - 小果、中果、大果各放一部分。
2. **记录3天数据**
   - 每个规格：问价人数、成交人数、成交斤数、退货/投诉。
3. **算两个指标**
   - 动销率 = 卖出量 ÷ 到货量
   - 毛利额 = 卖出斤数 × 每斤毛利
4. **优先追“毛利额高且动销快”的规格**
   - 如果中果动销最快、毛利也不差，就主推中果。
   - 如果大果动销慢但毛利高，只适合做利润补充，不适合当主力。

## 4. 一般经验结论

大多数批发场景下：

- **中果最容易出货**，因为家庭、水果店、团购都能接受。
- **小果走加工和切果渠道快**，但价格低，适合跑量。
- **大果适合礼盒、商超、餐饮**，不是普货里最快出的，但利润可能高。
- **特大果风险最大**，客户群窄，压货后损耗高。

所以如果你问“哪个规格更容易出货”，通常答案是：**中果最稳，小果看加工渠道，大果看礼盒和商超。真正要选，得看你下游客户是谁。**

## 5. 直接可用的判断口诀

**中果走量，小果走加工，大果走礼盒；**
**先看客户，再看价格，最后看外观；**
**动销快不快，三天小测试；**
**赚钱不赚钱，算斤毛利，不算单个大小。**
