超市卖菠萝，最该关注什么，取决于你的角色：**采购/选品、门店运营，还是现场售卖**。如果只能选一个优先级，我的建议是：

**先看切果损耗，再看甜度，然后大小，最后外观。**

原因很简单：超市卖菠萝不是“摆着好看”，而是**要赚钱、要复购、要少扔货**。

### 1. 切果损耗：最该先管
菠萝和很多水果不一样，顾客往往需要削皮、去眼、切块。损耗直接吃掉毛利。

重点关注：
- 到货后坏果率、黑心率、烂心率
- 削皮去眼后的出肉率
- 切块后当天卖不掉的比例
- 是整果卖得多，还是切果卖得多

如果损耗高，哪怕甜度好、外观漂亮，也可能不赚钱。  
**判断标准：出肉率低、坏果多、切后变色快，就不适合主推。**

### 2. 甜度：决定复购
菠萝如果酸、涩、麻嘴，顾客买一次就不会再买。甜度是复购的核心。

但要注意：
- 不能只靠“闻起来香”
- 要看品种、产地、成熟度
- 现场最好有试吃或糖度抽检

**判断标准：同一批货里，甜度稳定比个别特别甜更重要。**  
如果一批货甜度忽高忽低，顾客体验会很差。

### 3. 大小：影响定价和场景
大小不是越小越好，也不是越大越好，要看超市客群。

- 社区超市：中等个头更好卖，家庭一次能吃完
- 商圈/写字楼：切果盒、小份装更好卖
- 促销堆头：大果显得实惠，但削皮后可能吃不完

**判断标准：大小要匹配你的主要客群和售卖形式。**  
如果主推切果，大小均匀比单个超大更重要。

### 4. 外观：重要，但排最后
外观影响第一眼购买，但菠萝有厚皮，外观好不代表里面好。

- 果形端正、颜色金黄、冠芽新鲜，能促进冲动购买
- 但外观好、里面黑心的菠萝，反而造成投诉和损耗

**判断标准：外观用于陈列和引流，但不能替代切开验货。**

---

### 直接可执行的建议
如果你是超市经营者，按这个顺序做：

1. **先测损耗**：连续记录3天到货、削皮、切块、报损数据  
2. **再测甜度**：抽检糖度，做试吃，记录顾客反馈  
3. **再定规格**：根据客群决定主推整果还是切果  
4. **最后做外观分级**：好果陈列，次果切盒或促销  
5. **动态调整**：哪批货损耗低、甜度高、复购好，就加大采购

一句话总结：  
**超市卖菠萝，先保不亏，再保好吃，然后看好卖，最后才是好看。**  
所以优先级是：**切果损耗 ＞ 甜度 ＞ 大小 ＞ 外观。**
