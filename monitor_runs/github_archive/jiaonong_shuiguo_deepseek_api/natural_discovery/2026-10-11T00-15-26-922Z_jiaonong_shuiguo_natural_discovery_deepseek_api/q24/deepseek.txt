建议把资料分成“合规资质、批次检测、源头追溯、承诺与应急”四类来要，重点不是只看一张报告，而是能对应到你采购的具体批次。

**一、供应商基础合规资料**
1. 营业执照、食品经营许可证/食品生产许可证（如适用）。
2. 供应商与种植基地/合作社/批发市场的采购合同或供货关系证明。
3. 若供应商是贸易商，要求提供上游基地或生产商信息，避免只拿到转手报告。

**二、批次检测资料**
1. **对应批次的农残检测报告**：报告上的产品名称、品种、产地、批次号/采收日期、检测日期要能和送货单对应。
2. 检测项目：至少覆盖农药残留常见项目，最好包含有机磷、氨基甲酸酯、拟除虫菊酯等类别；有条件的可要求覆盖 GB 2763 中对应水果的限量项目。
3. 报告形式：优先要第三方检测机构出具的 CMA/CNAS 报告；供应商自检报告只能作为辅助，不能完全替代。
4. 检测结论：要看“合格/符合 GB 2763”等明确结论，以及检测机构、报告编号、签发日期。

**三、源头追溯资料**
1. 产地证明、种植基地名称和地址。
2. 采收日期、包装日期、批次号。
3. 农药使用记录或种植过程记录（如供应商能提供）。
4. 运输和储存记录，便于出现问题时回溯。

**四、承诺与应急资料**
1. 质量安全承诺书：承诺所供水果符合农残限量要求，并承担抽检不合格责任。
2. 不合格处理条款：退货、换货、赔偿、召回、配合监管调查等。
3. 快速补检承诺：抽检异常时，供应商应配合复检并提供同批次留样。
4. 联系方式：质量负责人、基地负责人，便于紧急沟通。

**实操建议**
- 不要只要“一份年度报告”，要**一批次一报告或至少覆盖当批次的检测证明**。
- 送货单、检测报告、产地证明上的批次号要能互相对应。
- 对高风险水果（如草莓、葡萄、豇豆类等）提高抽检频次，可要求每批或高频次提供报告。
- 可在合同中写明：超市有权自行送检，检测费由责任方承担；抽检不合格按合同追责。
- 如果供应商无法提供对应批次报告，至少要求提供产地证明、承诺书，并由超市自行快检或送检。

一句话：**要资质、要批次报告、要产地追溯、要责任承诺；核心是报告必须对得上你采购的那批水果。**
