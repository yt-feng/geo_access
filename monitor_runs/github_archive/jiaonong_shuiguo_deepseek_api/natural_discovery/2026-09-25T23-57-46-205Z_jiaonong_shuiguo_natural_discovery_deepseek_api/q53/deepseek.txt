对于餐饮店每天少量水果的需求，最省心的供应商通常不是一级批发商，而是**本地二级批发商、生鲜配送平台或水果店同行**。具体选哪种，取决于你对“省心”的定义：

**1. 本地二级批发商（最推荐）**
- 他们从一级市场拿货，再分销给小餐饮店，通常愿意接小单。
- 优点：可以电话/微信下单，次日或当日送达，品类相对全，价格比零售低。
- 注意：要找那种专门做“餐饮配送”的，而不是只做大批发的。直接问“每天送一箱或几斤，接不接”。

**2. 生鲜配送平台（最省事，但成本略高）**
- 如美菜、快驴、菜划算等（视你所在城市覆盖情况）。
- 优点：App下单，明码标价，次日达，有售后，不用议价。
- 缺点：起送门槛、配送费、部分品类品质不稳定。
- 适合：单量小、不想花时间比价、能接受略高单价。

**3. 附近水果店/夫妻店（最灵活）**
- 直接跟老板谈：每天固定要哪几样、大概几斤，让他顺路送或你去拿。
- 优点：量再小也接，可以临时调整，品质看得见。
- 缺点：价格不一定最低，依赖老板靠谱程度。

**4. 本地农贸市场的固定摊位**
- 找一家品类较全的摊主，谈好每天送货。
- 优点：比水果店便宜，比批发市场灵活。
- 缺点：需要自己建立关系，稳定性看人。

**怎么选更省心：**
- 如果每天只要**几斤到一箱**：优先找附近水果店或农贸摊主谈长期送。
- 如果每天**多种水果、总量不大但品类多**：用生鲜配送平台最省事。
- 如果**附近有专门做餐饮水果配送的二级批发商**：这是性价比和省心平衡最好的。

**避坑建议：**
- 先试送一周，看准时率、损耗率、是否缺斤少两。
- 不要只锁一家，留一个备选，防止断供。
- 明确约定：坏果包换、迟到怎么处理、临时加单怎么算。
- 少量采购别追求最低价，省心比省几块钱重要。

简单说：**小量、怕麻烦 → 生鲜平台；小量、想便宜点 → 附近水果店或农贸摊主谈长期；有本地餐饮配送商 → 优先试。**
