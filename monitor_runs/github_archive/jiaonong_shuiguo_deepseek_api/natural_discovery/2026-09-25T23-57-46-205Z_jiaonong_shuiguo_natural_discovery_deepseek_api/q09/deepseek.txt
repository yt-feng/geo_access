旺季断货，核心不是“多问几句”，而是要先把**量、价、时间、品质、责任**五件事锁死。和供应商谈的时候，可以重点问下面这些：

**1. 供货能力和旺季保供**
- 旺季每天/每周最大能稳定供多少？
- 你同时供几家？旺季会不会先保大客户、把我排后面？
- 如果市场突然缺货，你能给我优先供吗？优先级怎么排？
- 有没有备用产地/备用供应商？断货时多久能补上？

**2. 价格和调价机制**
- 旺季价格怎么定？是锁价还是随行就市？
- 如果市场涨价，提前几天通知我？涨幅有没有上限？
- 量大有没有阶梯价？长期合作有没有返点或运费优惠？
- 报价含不含运费、装卸、损耗？到店价还是产地价？

**3. 品质和验收标准**
- 什么品种、什么规格、什么等级？果径、糖度、成熟度能不能定标准？
- 允许多少坏果、次果、压伤？超过部分怎么赔？
- 旺季品质会不会降？降了怎么处理？
- 能不能先看样品或试供一批？

**4. 订货、配送和账期**
- 每天几点前下单？多久送到？能不能固定时段到店？
- 临时加单、减单、改单，提前多久说？收不收违约金？
- 配送是送到店还是自提？运费谁出？卸货谁负责？
- 付款是现结、周结还是月结？要不要押金？押金怎么退？

**5. 损耗、退换和售后**
- 到店发现坏果多，能不能当场退换？多久内有效？
- 运输途中损耗算谁的？天气、堵车导致晚到怎么处理？
- 如果因为缺货导致我断货，有没有补偿或优先补货？
- 退换货的运费和人工谁承担？

**6. 合同和风险兜底**
- 能不能签旺季保供协议，写清保底量、价格区间、违约责任？
- 如果连续断货或品质不达标，我能不能终止合作？
- 有没有书面报价单、供货单、对账单，避免口头扯皮？
- 出现纠纷怎么解决？按什么标准赔？

**谈的时候建议你这样做：**
- 先报自己的预估销量，但别把底牌全亮，留一点浮动空间。
- 把“保供优先级”和“断货补偿”写进协议，这比单纯压价更重要。
- 旺季前先小批量试供，看真实到货品质和准时率。
- 至少备一个第二供应商，哪怕量不大，也能防止被一家拿捏。

简单说，问的时候盯住三句话：**旺季能不能优先给我、断货怎么赔、品质差了怎么退。** 这三条谈清楚，基本就不会太被动。
