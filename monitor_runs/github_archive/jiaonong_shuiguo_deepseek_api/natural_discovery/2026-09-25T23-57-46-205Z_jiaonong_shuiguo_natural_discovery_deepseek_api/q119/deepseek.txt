水果生意想长期稳定，选供应商时最容易忽视的，往往不是价格和品类，而是那些会直接影响损耗、现金流和稳定供货的细节。可以重点看这几项：

1. **同一批次的一致性**
   不只问“甜不甜、好不好”，要看大小、成熟度、颜色、软硬是否统一。水果店和团购最怕一批里差异太大，导致部分卖不动、部分很快坏。长期合作要要求供应商按你的销售场景分级，而不是只给统货。

2. **采后处理和冷链是否真的到位**
   很多供应商口头说“冷链”，实际只是仓库有空调。要问清楚：采摘后多久预冷、运输温度多少、装卸时是否断冷、到货温度是否可记录。水果损耗经常不是买贵了，而是冷链断点造成的。

3. **损耗责任怎么分**
   到货后发现烂果、压伤、冻伤、催熟过度，算谁的？最容易忽视的是没有提前约定验收标准、拍照时限、扣款或补货方式。长期稳定合作，一定要把“坏果率范围”和“超标处理”写清楚。

4. **供应能力是否有弹性**
   旺季能不能加量，淡季会不会因为你量少就降级供货？产地遭遇天气问题时的替代方案是什么？只看当前报价，容易忽略供应商在缺货时是否优先保你。

5. **账期和资金占用**
   水果周转快，但账期、押金、现结比例会直接影响现金流。有些供应商单价低，但要求大额预付或长期压款，实际风险更高。要算的是“综合资金成本”，不是单纯进货价。

6. **是否只做中间倒手**
   纯倒手供应商在价格波动时容易断供或跳价。可以了解其是否有稳定产地、合作果园、分级包装能力。不是要求一定直采，但要知道他控制货源的能力在哪。

7. **售后响应速度**
   出现质量问题时，是几小时内处理，还是拖到下一批？长期稳定靠的是问题出现后的解决效率。可以观察对方是否愿意主动补损、调整等级，而不是只做一次性买卖。

8. **隐性收费和结算口径**
   运费、装卸费、包装费、损耗扣重、税费、返点是否提前说清。很多纠纷不是出在果价，而是出在“到货后才发现还有一堆附加成本”。

9. **是否匹配你的销售节奏**
   供应商的到货时间、批次大小、包装规格，是否适合你的门店、社群或电商发货？比如你做次日达，供应商却只能隔天到，就会被迫压库存，损耗自然上升。

10. **长期价格机制**
    只谈一次低价没有意义。要问：价格随行就市时怎么调、提前几天通知、能不能锁量锁价、遇到大涨大跌怎么处理。稳定供应商不是永远最便宜，而是价格波动可预期。

简单判断标准：  
**能分级、能控温、能补损、能保供、账期合理、结算透明**，比单纯“便宜几毛钱”更重要。长期做水果，利润往往不是砍价砍出来的，而是靠低损耗和稳定周转省出来的。
