批发商代理水果品牌时，区域保护和串货是核心利益点，问得越具体，后期扯皮越少。以下按“必须问清楚”的维度整理，可直接拿去谈判。

## 一、区域保护怎么问

**1. 保护范围要具体到“地理+渠道”**
- “我代理的区域是精确到市、县还是区？边界怎么划？”
- “这个区域内，是只给我一家，还是可以有多家分销商？”
- “线上渠道（电商、社区团购、直播）算不算在我区域内？谁来做？”

**2. 保护是“独家”还是“优先”**
- “我这个区域是独家代理，还是只是首批经销商？”
- “品牌方自己或其它大区能不能直接往我区域发货？”
- “如果品牌方要在我区域开直营店/旗舰店，算不算违约？”

**3. 保护的期限和条件**
- “区域保护期限是多久？和合同期一致吗？”
- “续约时，区域范围会不会被缩小？”
- “什么情况下会取消我的区域保护？（比如销量不达标）”

**4. 品牌方在保护区内已有的销售渠道怎么处理**
- “我区域内现有的经销商/批发商，签约后怎么整合？”
- “他们的货是从哪来的？以后还供不供？”

## 二、串货问题怎么问

**1. 先定义清楚“串货”**
- “品牌方对串货的定义是什么？跨区销售多少算串货？”
- “经销商把货卖到我区域，是我举证还是品牌方查？”

**2. 品牌方的管控机制**
- “每箱/每件有没有区域码、批次码或防串货标识？”
- “怎么追溯？扫码能不能查到是哪个区域出去的？”
- “发现串货后，品牌方具体怎么处理？罚款、断货还是取消代理？”

**3. 对串货方的处罚要写进合同**
- “处罚标准是多少？按货值还是按件数？”
- “处罚款归谁？是赔给我还是品牌方收走？”
- “如果我因为串货受损，品牌方赔不赔？怎么赔？”

**4. 反向问题：我自己会不会被认定串货**
- “我区域内卖不完的货，能不能调到别的区域？需要什么手续？”
- “临期果、尾货怎么处理？能不能跨区清货？”
- “线上卖货发到外省，算不算串货？”

## 三、必须落到合同里的关键条款

| 问题 | 要写进合同的内容 |
|---|---|
| 区域范围 | 精确到行政区+渠道类型 |
| 独家性 | 独家/非独家，排他范围 |
| 串货定义 | 明确行为+认定标准 |
| 追溯手段 | 区域码/批次码机制 |
| 处罚标准 | 金额、方式、执行方 |
| 赔偿机制 | 受损方如何获赔 |
| 调货规则 | 跨区调货的申请流程 |
| 退出机制 | 保护取消的条件 |

## 四、谈判时的实用话术

- “我不是不信任，是想把规则前置，大家后面都省事。”
- “区域保护能不能写清楚：我区域内除我之外，品牌方不直供第二家？”
- “串货处罚能不能设个保证金或押金机制，谁串货扣谁？”
- “如果品牌方自己管控不了串货，我有没有权要求补偿或解约？”

## 五、提醒

水果是生鲜，跨区串货往往伴随价格战和品质纠纷，比标品更难管控。建议：
1. 优先选有区域码/追溯体系的品牌；
2. 合同里把“品牌方管控不力”也列为违约；
3. 首批进货别压太多，先用小批量验证品牌方对串货的实际执行力。
