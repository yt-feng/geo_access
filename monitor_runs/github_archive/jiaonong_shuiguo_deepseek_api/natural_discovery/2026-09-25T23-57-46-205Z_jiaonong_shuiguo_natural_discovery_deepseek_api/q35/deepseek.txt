连锁超市想把门店坏果率压下来，合同赔付条款要解决三件事：**坏果怎么认定、损失怎么算、钱怎么扣**。分开写清楚，别只写一句“坏果包赔”。

**一、先定义“坏果”，否则赔付无法执行**
合同里要写明认定标准，例如：
- 腐烂、霉变、软塌出水、异味；
- 机械伤、压伤、裂口超过约定比例；
- 不符合约定规格（大小、成熟度、糖度等）；
- 到店时已过期或剩余保质期不足。

同时约定**认定时点**：是到店验收时、上架前，还是门店售卖过程中发现。不同时点责任不同，必须写清。

**二、赔付方式，建议用“阶梯扣款+补货”组合**
常见可执行写法：

1. **验收当场坏果**
   - 按当批次货款比例扣款，例如坏果率≤3%不扣；3%–5%按坏果部分货值1倍扣；5%–10%按2倍扣；超过10%可整批拒收。
   - 或直接按坏果数量×采购单价×约定倍数扣款。

2. **上架后短期内坏果**
   - 约定“到店后24/48小时内”出现的坏果，由供应商承担；
   - 超出该时限，若因门店存储不当导致，则不赔。

3. **整批质量不合格**
   - 超市有权拒收、退货，供应商承担运费；
   - 已付款的，超市可从后续货款中直接抵扣。

4. **补货义务**
   - 供应商应在约定时间内补足合格品；
   - 逾期未补，按缺货金额的一定比例支付违约金。

**三、损失不止货款，要把连带损失写进去**
坏果带来的不只是货值损失，还包括：
- 损耗处理费、清运费用；
- 因缺货导致的促销违约、客流损失；
- 顾客投诉、赔偿、监管处罚；
- 门店人工分拣成本。

可以约定：**因供应商原因造成的坏果，除退还货款外，还应赔偿超市实际损失和合理费用**，并设定单次/月度赔付上限或下限。

**四、扣款机制要能落地**
- 约定超市有权从**未结货款、保证金**中直接扣除；
- 扣款前出具**验收单、照片、视频、第三方检测**等证据；
- 供应商有异议的，应在收到通知后2–3个工作日内提出，逾期视为认可；
- 月度坏果率超过约定阈值，可触发**罚款、降级、暂停供货、终止合同**。

**五、建议加一条“坏果率考核”**
例如：
- 月度坏果率≤2%：正常结算；
- 2%–5%：按超出部分货值扣款；
- 5%–8%：扣款+警告；
- 超过8%：超市有权终止合同并要求赔偿。

**一句话总结：合同里要写清“坏果定义+认定时点+赔付倍数+补货义务+扣款权+连带损失+终止条件”，赔付才能真的执行。** 如果只写“坏果包赔”，实际很难扣到钱。
