连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是围绕“价格怎么变、货怎么收、损耗谁承担、账怎么结、违约怎么算”这几类条款。下面按风险从高到低说，并给出可执行的写法建议。

**1. 价格与调价机制**

这是水果年度合同最大的坑。水果价格波动大，如果合同只写“按市场价”“随行就市”，年底一定扯皮。

- 坑：只约定年度框架价，没有调价触发条件、频率、依据。
- 建议写清：
  - 基准价 + 调价公式，比如以某批发市场均价/产地收购价为参照；
  - 调价周期（如每两周一次）和生效时间；
  - 谁有权发起调价、需要什么书面确认；
  - 价格上限或涨幅封顶，避免供应商单方暴涨。

**2. 质量标准与验收**

水果是非标品，最容易在“合格不合格”上吵。

- 坑：只写“符合国家标准”，但没写具体品种的规格、糖度、大小、成熟度、外观。
- 建议：
  - 按品类列明验收标准：单果重、直径、糖度、色泽、允许瑕疵比例；
  - 明确验收地点（到仓验收还是产地验收）、验收时限、抽检比例；
  - 约定不合格的处理：拒收、降价接收、换货、扣款，选哪种提前写死；
  - 保留双方认可的样品或封样，作为争议依据。

**3. 损耗与短溢装**

水果运输和上架损耗高，这块责任不清会直接吃掉利润。

- 坑：只写“按实际到货数量结算”，但运输途中烂果、水分流失算谁的没写。
- 建议：
  - 明确途损率上限，超过部分由供应商承担；
  - 约定按到仓实收数量还是发货数量结算；
  - 短装、溢装的处理规则和补货时限；
  - 季节性损耗是否单独约定。

**4. 订货、供货与缺货责任**

- 坑：只写“供应商保证供货”，但没有最低供货量、提前期、缺货赔偿。
- 建议：
  - 约定下单提前期、最低起订量、单次最大供货量；
  - 旺季保供条款，供应商需承诺优先供货；
  - 缺货、延迟到货的违约金或替代采购差价由供应商承担；
  - 不可抗力范围要具体，不能把普通天气、运输问题都算不可抗力。

**5. 账期、结算与返利**

- 坑：账期含糊、对账周期长、返利条件写得像“看情况”。
- 建议：
  - 明确对账日、开票要求、付款日、逾期付款利息；
  - 返利/返点写清计算基数（含税还是不含税、是否扣除退货）；
  - 返利支付时间和方式；
  - 扣款项目（质量扣款、缺货扣款、促销费用）要列明，避免供应商事后不认。

**6. 退换货与滞销处理**

- 坑：只写“可退换”，但没写时限、费用、比例。
- 建议：
  - 明确可退换的情形：质量问题、临期、滞销；
  - 退换货的运费、损耗由谁承担；
  - 滞销退货比例上限和结算方式；
  - 生鲜类通常要约定“质量问题无条件退换”的时限。

**7. 违约责任与赔偿上限**

- 坑：违约金写得太低没约束力，或写得太高被认定无效；赔偿范围不清。
- 建议：
  - 分场景设违约金：缺货、质量不合格、延迟交货、单方涨价；
  - 约定赔偿是否包括超市的下游损失、商誉损失；
  - 设置合理的赔偿上限，但质量安全和食品安全责任不应封顶；
  - 明确争议解决方式和管辖地，优先约定在超市所在地。

**8. 排他性与供货限制**

- 坑：供应商同时给竞争对手更低价或更好货，合同没约束。
- 建议：
  - 是否要求区域/渠道排他，写清范围和期限；
  - 最惠客户条款：供应商给第三方的价格不得低于给本超市的价格；
  - 注意排他条款可能涉及反垄断合规，范围别过宽。

**9. 食品安全与资质**

- 坑：只收营业执照，没约定农残、检疫、追溯责任。
- 建议：
  - 供应商需提供检测报告、检疫证明、产地证明；
  - 出现食品安全问题的召回、赔偿、解约责任；
  - 要求供应商购买产品责任险，并约定保额。

**10. 合同期限与退出机制**

- 坑：年度合同到期自动续约，或中途想换供应商却解不掉。
- 建议：
  - 明确起止日期、续约条件；
  - 约定提前解约情形和通知期；
  - 季节性品类可设单独考核期，连续不达标可终止。

**实操上最该盯的三件事：**

1. **价格调整机制**必须可计算、可执行，不能靠“协商”。
2. **验收标准和损耗归属**必须写到具体数字和比例。
3. **缺货、质量、账期的违约责任**必须能落地扣款，否则合同只是形式。
