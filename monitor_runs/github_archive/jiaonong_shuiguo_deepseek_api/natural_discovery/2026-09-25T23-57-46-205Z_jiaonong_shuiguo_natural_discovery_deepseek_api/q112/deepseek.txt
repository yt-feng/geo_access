水果采购合同里并没有统一法定的“坏果率赔付线”，关键看双方合同约定、验收标准和货物用途。实务上可以这样定：

1. **合同有约定，按约定**
   - 如果合同写了“坏果率≤3%”“超过5%可索赔”等，就按合同执行。
   - 注意区分：坏果率、腐烂率、机械伤率、次果率，标准不同，赔付也不同。

2. **合同没约定时，常见商业惯例**
   - **鲜食、精品果、礼盒果**：通常要求较严，坏果率超过 **3%～5%** 就可以提出扣款、补货或索赔。
   - **普通批发、市场销售**：常见容忍范围是 **5%～10%**，超过部分可要求按比例扣款或赔偿。
   - **加工用果**：如果用于榨汁、罐头、果干等，标准可放宽到 **10%～15%** 甚至更高，但腐烂、霉变果通常仍应单独剔除。
   - **严重腐烂、霉变、异味**：不管比例多少，通常都应拒收或要求整批处理，因为这可能影响食品安全和其余货物。

3. **更建议写进合同的方式**
   - 明确验收时间：到货后几小时内验收。
   - 明确抽样方法：如随机抽几箱、每箱抽多少。
   - 明确计算方式：坏果率 = 坏果重量 ÷ 总重量，或坏果个数 ÷ 总个数。
   - 明确赔付方式：
     - 超过约定比例的部分，按重量扣款；
     - 超过一定比例，整批退货或换货；
     - 造成逾期、损耗的，另赔违约金。
   - 示例写法：  
     “坏果率≤5%，超过5%的部分按实际坏果重量双倍扣款；坏果率超过10%，买方有权拒收或要求整车退货，运费及损失由卖方承担。”

4. **简单判断**
   - 精品/鲜食：超过 **3%～5%** 就应主张赔付。
   - 普通批发：超过 **5%～10%** 可主张赔付。
   - 加工果：超过 **10%～15%** 可主张赔付，但霉烂果应更严格。
   - 如果合同没写，仍可依据实际损失、验收记录、照片、物流凭证等协商或诉讼索赔。

所以，最稳妥的不是记一个固定数字，而是在合同里写清楚：**允许坏果率、超标后的扣款/退货/赔偿规则**。如果没有约定，一般从 **5%左右** 开始就具备比较强的索赔理由，精品果则可低到 **3%**。
