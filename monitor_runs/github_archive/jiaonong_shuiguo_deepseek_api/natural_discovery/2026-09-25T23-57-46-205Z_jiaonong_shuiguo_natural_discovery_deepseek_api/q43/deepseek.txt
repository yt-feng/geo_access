评估跨城市连锁门店的水果供应商仓配覆盖，核心不是看“有没有仓”，而是看**从仓到门店的链路是否稳定、成本是否可控、损耗是否可接受**。建议按以下维度逐项评估：

**1. 仓网布局与门店匹配度**
- 供应商在你门店所在城市或周边是否有**前置仓/DC（配送中心）**，还是从单一中心仓长距离发运。
- 计算每个仓到每个门店的**实际配送半径和时效**，不是直线距离，而是实际可走路线。
- 重点看：门店密集的城市是否单独设仓，还是靠周边城市仓覆盖。跨城覆盖半径过大，水果损耗和时效风险会明显上升。

**2. 配送时效与频次**
- 水果是高频、短保品类，核心看**每日/隔日配送能力**。
- 评估：下单到到店需要多久，是否支持门店按需补货，还是固定周期配送。
- 冷链或控温能力：不同水果对温度要求不同，要区分常温、冷藏、冷链车型。
- 高峰期（节假日、大促）是否还能保证频次和准时率。

**3. 冷链与损耗控制**
- 仓内是否有**冷藏/保鲜分区**，运输是否全程控温。
- 要求供应商提供**历史损耗率数据**，按品类看，而不是只看整体。
- 到店验收标准是否清晰：品相、成熟度、温度、包装。
- 损耗责任怎么划分：运输途中、到店验收前、验收后分别由谁承担。

**4. 成本结构**
- 报价是否含**配送费、装卸费、冷链附加费、远距离附加费**。
- 跨城配送往往有最低起送量，门店单店量小会导致成本摊高。
- 对比：供应商直送门店 vs 供应商送到区域仓再由第三方城配分发，哪种总成本更低。
- 隐性成本：损耗、缺货导致的门店销售损失、临时补货的加急运费。

**5. 供应稳定性与弹性**
- 供应商在覆盖城市是否有**备用仓或合作仓**，单仓故障时能否切换。
- 产地直发能力：是否能在产地端做分级、预冷、包装，减少中转损耗。
- 应对天气、交通、节假日的能力，是否有应急预案。
- 多供应商备份：关键城市是否只依赖一家，风险是否集中。

**6. 信息系统与协同**
- 是否支持门店在线下单、库存可视、配送轨迹查询。
- 能否按门店维度提供**到货准时率、缺货率、损耗率**报表。
- 数据能否对接你的采购或门店系统，减少人工对账。

**7. 实际验证方法**
- 先选**2-3个典型城市**做小范围试跑，覆盖近仓城市和远仓城市各一个。
- 试跑周期建议至少**2-4周**，覆盖正常日、周末、一次促销或节假日。
- 记录：准时率、缺货率、损耗率、单店单次配送成本、门店投诉。
- 再决定是否扩大合作范围，或要求供应商补仓。

**快速判断标准：**
如果供应商在门店所在城市没有仓，且配送时效超过24小时、无全程冷链、损耗率不透明，基本不适合做水果主供，最多只能做补充或低价引流品。水果仓配覆盖的核心结论是：**近仓、高频、冷链、损耗可量化、成本可算清**，缺一项都要谨慎。
