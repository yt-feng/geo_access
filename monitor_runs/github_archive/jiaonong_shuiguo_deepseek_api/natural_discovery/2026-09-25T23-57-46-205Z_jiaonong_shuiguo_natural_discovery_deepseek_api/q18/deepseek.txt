买香蕉前先想好你打算**什么时候吃**，再按这个时间挑，基本就不会出错。

**按食用时间选颜色：**
- **当天或第二天吃**：选**通体黄色、带少量褐色斑点**的，最甜最软。
- **2～3天内吃**：选**黄色为主、两端略微带绿**的。
- **3～5天后吃**：选**黄绿相间**的。
- **5天以上**：选**整体偏绿、硬实**的，回家常温放。

**避坑要点：**
- 别只看一面的颜色，**翻面看有没有压伤、发黑**，有黑斑软塌的说明已经熟过或碰伤，会很快烂。
- 摸一下：过硬=很生，过软或有凹陷=过熟。
- 如果**已经熟透但暂时不吃**，直接放冰箱冷藏，能多撑几天；不过皮会变黑，里面还是好的，冷藏后别再指望它继续变甜。

**加速或延缓：**
- 想快点熟：和苹果或熟香蕉放一个纸袋里，常温一天左右就明显催熟。
- 想慢点熟：单独放、阴凉通风处，别和苹果、西红柿放一起。

**一句话判断**：按“几天后吃”选黄绿程度，再翻面看有没有伤，就不会买到太生或太熟。
