能，但**取决于你的采购规模、合作稳定性、供应商类型和谈判方式**。水果供应商周末给支持是常见做法，但通常不是“白给”，而是有条件的。

**一、价格支持：一般能谈，但分情况**

- **批发市场档口/一级批发商**：周末促销走量大，可以谈“周末特价”“整箱价”“爆品补贴”。常见形式是某几个单品降价几毛到一两块/斤，或满多少箱返点。
- **产地直供/基地**：更可能给价格支持，但通常要求你提前报量、集中采购、自提或承担运费。
- **二级批发/本地配送商**：价格空间小，更可能给“搭赠”而不是直接降价，比如进10箱送1箱。
- **品牌水果/进口水果经销商**：可能有厂家促销补贴，但一般要求陈列、拍照、按指导价卖。

**二、物料支持：比价格更容易拿到**

供应商常能给：
- 纸箱、周转筐、保鲜袋
- 促销海报、价签、爆炸贴
- 试吃果、切果
- 遮阳棚、堆头围挡（看供应商规模）

但物料一般要求你：
- 把他们的货放在显眼位置
- 允许拍照回传
- 达到一定进货量

**三、怎么谈更有效**

1. **提前3-7天谈**，别周五下午才说。
2. **给明确量**：比如“周末两天我要进200箱砂糖橘，你能不能给周末价，或者送20箱试吃果？”
3. **绑定陈列**：承诺堆头、主推、发朋友圈/社群。
4. **要组合支持**：价格降一点 + 送物料 + 送试吃，比只压价更容易成。
5. **长期合作换支持**：说明你每周周末都做，稳定采购，供应商更愿意让利。

**四、现实判断**

- 小水果店第一次合作：大概率只能拿到**少量搭赠或物料**，直接降价较难。
- 有一定采购量、固定合作：**价格+物料都能谈**。
- 供应商自己库存压力大时：**周末支持最好谈**，尤其是应季水果、易腐水果。

一句话：**能要，但要拿“量、陈列、长期合作”去换，别只开口要降价。**
