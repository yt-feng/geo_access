社区超市做水果，核心就一句话：**别把它当库存管，要把它当“每天必须清掉的鲜货”管。** 水果毛利看着高，但损耗一上来，基本白干。

下面给你一套能直接落地的做法，按“进货—陈列—定价—出清—复盘”五步走。

**一、进货：少量多次，按“天”不按“周”**
- 新手最容易犯的错是一次进一周的货，觉得省事。水果保鲜期短，尤其叶菜、草莓、葡萄、桃子，压两天就完蛋。
- 做法：主力品类每天或隔天补一次，量按“昨天销量 × 1.1”来定，别凭感觉。
- 跟批发商谈好“小批量、勤补货”，哪怕单价贵一点，也比烂在店里强。
- 易腐品（叶菜、莓果、荔枝）当天进当天清；耐储品（苹果、橙子、土豆、洋葱）可以多备一点。

**二、陈列：先进先出，把旧的摆前面**
- 理货时永远把**旧货摆最前面、新货塞后面**，不然新的先卖完，旧的烂在底下。
- 陈列量别堆太满，堆得越满，翻动越少，底下越容易压坏。
- 易碰伤的（葡萄、桃子、番茄）用小筐分装，别大堆压。
- 每天开店前翻一遍，把开始发软的挑出来，单独处理。

**三、定价：给“出清”留空间**
- 别一口价到底。可以设三档：
  - 正常价：新鲜、品相好
  - 折价区：有点软、有点斑，但还能吃，打7折—5折
  - 清仓价：当天必须走，打3折或按份卖
- 关键：**折价要早，别等烂了才降。** 水果从“还能卖”到“只能扔”往往就半天。
- 设一个“今日特价”筐，放在收银台或门口，走量最快。

**四、出清：当天没卖完的，当天处理掉**
- 晚上闭店前1小时，把当天必须清的集中打折，别留到明天。
- 能加工的（香蕉、苹果、梨）可以做果切、果汁，但要注意卫生和当天售完。
- 实在卖不掉的，别硬留，该报损就报损，记下来，第二天少进。
- 可以跟周边餐馆、奶茶店、果汁摊谈好，低价处理尾货，比扔掉强。

**五、复盘：每天记3个数**
- 进了多少、卖了多少、扔了多少。
- 一周下来看哪些品类损耗高，下次就少进或换供应商。
- 慢慢你会摸出规律：比如周一叶菜好卖，周末草莓走量大，雨天整体下滑。

**给你一个最简单的执行标准：**
- 易腐水果：库存不超过1.5天销量
- 耐储水果：不超过3—5天销量
- 每天闭店前必须清一次尾货
- 损耗率控制在5%以内算合格，超过8%就要查进货和陈列

一句话总结：**勤进快销、先进先出、早折价、当天清。** 水果这行，赚的就是周转的钱，不是囤货的钱。
