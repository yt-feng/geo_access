结论先说：**大多数餐饮连锁，水果应优先“中央厨房/总仓统一收货”，再统一分拣、分级、配送门店；只有少数例外（极短保、高损耗、门店现场加工强、区域分散且冷链弱）才适合门店分开收货。**

下面是判断逻辑和可执行建议。

## 一、为什么通常统一收货更好

### 1. 品控更稳定
水果最大的问题是：
- 成熟度不一致
- 大小、糖度、外观波动大
- 不同批次差异明显

统一收货后，可以在中央厨房/总仓做：
- 到货验收
- 抽检糖度、硬度、成熟度
- 分级分选
- 不合格批次整批拒收或降级使用

如果门店各自收货，验收标准容易不统一，店长、厨师长、库管执行尺度不同，最后同一品牌不同门店口感差异会很大。

### 2. 采购议价能力更强
统一收货意味着：
- 订单集中
- 供应商更愿意给量价
- 可以签年度框架、锁价、保供
- 更容易要求产地直发、品牌果、定制规格

门店分开收货通常会导致：
- 单店采购量小
- 价格高
- 供应商分散
- 品质和账期难统一

### 3. 食品安全和追溯更可控
水果涉及农残、霉变、冷链断链等问题。统一收货可以：
- 统一索取检测报告、产地证明
- 统一做农残快检
- 统一定义拒收标准
- 一旦出事，快速追溯批次和流向

门店分开收货时，票据、检测报告、批次记录很容易缺失。

### 4. 损耗管理更专业
水果损耗高，但统一收货后可以：
- 按门店销量做主动配送
- 对熟度做分级：今天用、明天用、后厨加工用
- 把外观不合格但可加工的水果转到果汁、甜品、沙拉等
- 减少门店因不会存、不会催熟造成的报废

### 5. 配送和库存更可计划
中央厨房/总仓可以根据门店销售预测：
- 隔日配
- 日配
- 按门店等级配不同规格
- 减少门店安全库存

门店分开收货往往变成“各店自己囤”，库存不透明，调拨困难。

## 二、什么时候门店分开收货更合适

以下情况可以门店直收，或“总部谈价 + 门店收货”：

1. **极短保、易损水果**
   如熟透的草莓、杨梅、荔枝、枇杷、部分浆果。多一道中转就多一次损耗。

2. **门店密度低、区域分散**
   中央厨房覆盖半径太大，配送成本高于损耗成本。

3. **门店现场加工属性强**
   如高端果切、鲜榨果汁店，门店需要按当天客流频繁补货，且对成熟度要求每天变化。

4. **当地有强势批发市场**
   门店就在大型农批市场旁边，直采新鲜度和成本明显更优。

5. **冷链和仓储能力不足**
   中央厨房没有合适的水果冷藏、催熟、分拣条件，统一收货反而压坏货。

## 三、更优的混合模式

实际连锁餐饮里，最推荐的是：

**总部统一供应商和价格 + 中央厨房统一收货分拣 + 门店按需下单配送 + 少数极短保水果门店直收**

具体可分三类管理：

| 水果类型 | 建议模式 |
|---|---|
| 苹果、橙子、柠檬、香蕉、西瓜等耐储水果 | 中央厨房统一收货、统一配送 |
| 草莓、蓝莓、荔枝、杨梅等短保易损水果 | 总部定供应商和标准，门店直收或区域仓直配 |
| 果切、果汁用水果 | 中央厨房统一分级，加工果和鲜食果分开 |

## 四、落地建议

1. **先定标准**
   按品类定：品种、产地、规格、糖度、成熟度、允许瑕疵率、拒收条件。

2. **再定收货权**
   耐储水果：中央厨房收货。
   短保水果：可门店收货，但必须总部指定供应商和验收标准。

3. **做分级使用**
   A级鲜食，B级加工，C级拒收。不要一刀切报废。

4. **门店只做少量安全库存**
   水果尽量日配或隔日配，门店不承担主要库存。

5. **用数据决策**
   比较两种模式的：
   - 采购单价
   - 到货损耗率
   - 门店报废率
   - 客诉率
   - 配送成本
   - 人工验收成本

   如果统一收货后，综合成本低于门店直收，就继续集中；如果短保品类损耗明显上升，就对该品类放开门店直收。

## 五、一句话判断

**耐储、标准品、食品安全要求高的水果：中央厨房统一收货更好。**
**极短保、易损、区域分散、门店现场加工强的水果：门店分开收货或区域直配更好。**
**成熟连锁更适合“总部控标准、中央厨房控品控、门店按需配送”的混合模式。**
