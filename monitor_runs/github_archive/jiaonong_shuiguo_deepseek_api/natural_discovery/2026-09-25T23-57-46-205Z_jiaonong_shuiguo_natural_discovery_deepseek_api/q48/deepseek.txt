判断的核心不是“他现在能不能送”，而是“换季、爆单、涨价时他还能不能按你的规格稳定送”。可以从以下几个层面做验证，不用等到合作后才发现问题。

**1. 先把自己的规格量化到可验收**
把“菠萝”拆成硬指标，否则没法判断对方是否稳定：
- 品种/产地（如金钻、都乐、台农等，是否允许混装）
- 单果重量区间（如1.2–1.5kg）、果径
- 成熟度/糖度（如糖度≥14，或七成熟）
- 外观（青皮/黄皮、有无黑心、裂口、机械伤）
- 加工形态：整果、去皮、切块、丁/片尺寸
- 包装：箱规、每箱净重、冷链还是常温
- 到货温度、农残检测要求、到货时效

只有规格可验收，才有“稳定不稳定”的判断基础。

**2. 重点考察货源结构，而不是看他嘴上承诺**
- 是自有种植基地、长期合作果园，还是市场档口调货？调货型供应商最容易在旺季掉链子。
- 产区是否单一？单一产区遇台风、雨季、病害就断供。最好有主产区+备用产区。
- 有没有冷库、加工线、分选线？有分选线才能保证规格统一。
- 要求看近3个月给其他连锁客户的发货记录、退货率、客诉记录。

**3. 用小批量试单做压力测试**
不要一上来签大单，按这个节奏：
- 首单小批量：验证规格、成熟度、包装、到货温度。
- 连续3–4周每周下单：看波动，不看单次表现。
- 故意在周末、节假日、雨天各下一次：看履约和物流。
- 临时加单20%–30%：看弹性。
- 要求换规格（如小果换大果、整果换切块）：看响应。

**4. 用数据指标判断，而不是靠感觉**
建议约定并每月复盘：
- 准时到货率（≥98%）
- 规格合格率（≥95%–98%）
- 损耗/退货率（设定上限，如≤3%）
- 缺货提前通知时间（如至少48小时）
- 价格波动通知机制

连续两个月不达标，就说明不稳定。

**5. 合同里把“稳定”变成责任**
- 保供条款：旺季、节假日优先供货。
- 备用货源条款：主产区受灾时的替代方案。
- 价格联动机制：随行就市但设涨跌幅上限。
- 违约与赔付：断供、规格不符、延迟到货的赔付标准。
- 检测与追溯：每批提供农残检测、产地证明。

**6. 一个简单的判断口径**
如果供应商能满足：
- 有稳定基地或长期锁定货源
- 有分选/冷链能力
- 试单连续4周规格合格率≥95%、准时率≥98%
- 旺季愿意签保供和赔付条款

基本可以判断“能稳定按规格送货”。反之，如果只能给口头承诺、靠市场调货、不愿试单、不敢签赔付，基本不可靠。
