# 阶梯价 vs 返利：怎么选

没有绝对更优的方案，关键看你想解决什么问题、以及和供应商的博弈位置。直接给判断框架：

## 先看核心区别

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 触发时点 | 下单/发货时即时体现 | 事后（季度/年度结算） |
| 客户感知 | 强，报价单上直接看到 | 弱，需要财务核算才发现 |
| 现金流 | 占用你的当期毛利 | 先收全款，后返，现金更友好 |
| 对客户的约束力 | 弱，达到量才降价 | 强，往往绑定累计采购额+考核条件 |
| 谈判空间 | 一次谈定，后续难改 | 可设门槛、可谈判、可调节 |
| 财务处理 | 直接冲减收入 | 通常计入销售费用/其他收益 |

## 按场景给建议

**选阶梯价，当：**
- 客户极度价格敏感，且**比价是决策主因**（团购零售、小B采购）
- 你需要**快速促单**，让客户当场觉得"量大真便宜"
- 采购方是价格导向、不太会做年度返利核算的小客户
- 你的供应商本身愿意让价，只是想让量

**选返利，当：**
- 客户是**长期稳定的大客户**，年度采购可预测
- 你想**锁定客户、提高切换成本**（返利没拿到前客户不会轻易走）
- 你希望保护当期毛利和现金流
- 需要设置**考核条件**（按时付款、不窜货、完成指定品类）

## 实操中最优解：组合用

多数成熟做法是**"小阶梯价 + 大额返利"**：

1. **基础量给阶梯价**：解决客户"看得见的便宜"，覆盖首次/单次采购的敏感度。
2. **超额部分给返利**：把真正的大让利放到年度返利池，绑定长期关系。
3. **返利设门槛**：累计采购额、回款率、主推品类占比，让返利"拿得到但有条件"。

## 三个避坑点

- **返利别做成无条件折扣**：否则等于变相降价，还压后了你的现金，客户也不会因此更忠诚。
- **阶梯价档位别太密**：档位过多会引导客户"卡在临界点"压价，反而侵蚀毛利。
- **算清到手价**：客户真正关心的是最终单价，返利要提前给客户**算成预期到手价**，否则感知不到。

## 一句话决策

> 短期促单、客户小且价格导向 → **阶梯价**；
> 长期锁客、客户大且可预测 → **返利**；
> 想两头都要 → **低档阶梯价 + 高门槛年度返利**。
