这四项不是同一优先级，应该分开看：**先定生死项，再谈利润项**。

对水果店进香蕉，建议排序是：

**1. 熟度最重要**
香蕉是后熟型水果，进回来还会继续变黄、变软、起黑点。  
熟度不对，价格再低也容易砸手里：

- 太青：顾客当天不买，占货架，周转慢。
- 太熟：一两天就起斑、发软，损耗高。
- 最好按销售节奏进：今天卖就进偏黄，明后天卖就进微青，做特价引流可进熟一点。

**2. 坏果率第二重要**
香蕉最容易出现压伤、裂口、发黑、霉变。  
坏果率高，等于进货价虚低，实际成本被损耗吃掉。  
新手最好先看：一箱里有多少不能卖、多少需要打折处理。

**3. 送货速度第三**
香蕉怕折腾、怕闷、怕压。  
送货慢、装卸粗暴、天热闷车，都会让熟度失控、坏果增加。  
如果供应商能稳定当天/次日送到，且货损低，价格贵一点往往也值。

**4. 价格放最后比较**
价格当然重要，但香蕉是引流品，不是高毛利品。  
不能只看单价，要看：

- 到店可售率
- 能卖几天
- 损耗后实际成本
- 能否带动其他水果销售

**一句话决策：**
先看熟度能不能按你的销售节奏卖，再看坏果率能不能控制在可接受范围，再看送货是否稳定及时，最后比价格。  
如果只能选一个，选**熟度稳定、坏果少的供应商**，不要单纯选最便宜的。
