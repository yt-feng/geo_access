判断供应商能不能按时到车，核心不是听他怎么说，而是看他有没有“被约束”和“有兑现记录”。可以从下面几个层面快速判断。

**1. 先看合同和定金约束**
- 有没有明确写清：到车日期、具体时间段、车型/吨位、产地、成熟度、验收标准。
- 有没有约定逾期违约金，比如每延迟一天扣多少钱、超过多久可以拒收。
- 定金/订金付了多少。供应商如果愿意接受“逾期扣款”，可信度会高一些；如果只催你打款、不愿写违约条款，风险大。
- 注意区分“订金”和“定金”，以及对方是不是实际货主。很多中间商自己也没车，层层转手，最容易延迟。

**2. 看他的货源和车辆是不是自己能控制**
问清楚几个关键问题：
- 香蕉是自有基地、长期合作基地，还是临时在市场调货？
- 装车车队是长期合作，还是临时找车？
- 现在货在哪，是在产地、口岸，还是已经在路上？
- 如果产地突然涨价或掉价，他会不会优先把货卖给出价更高的人？

如果他说“货还在找”“车还没定”“明天再看”，基本不要指望准时。真正有把握的供应商，通常能说出具体产地、装车点、车牌或司机联系方式。

**3. 要求提供可核验的进度证据**
不要只听口头承诺，要让他给：
- 装车视频或照片，能看到货、车牌、装车时间。
- 司机电话或车牌号，你可以直接联系确认位置。
- 运输轨迹，比如货运平台定位、司机微信实时位置。
- 发车单、过磅单、检疫/质检相关单据。

如果对方总是“不方便发”“司机不让给电话”“到了再说”，要警惕。

**4. 查他的历史兑现记录**
- 之前合作过几次，是否准时？
- 问同行、市场档口、其他批发商对他的评价。
- 看他是否经常换电话、换微信、换公司名。
- 新供应商第一次合作，不要下大单，先小批量试一车。

**5. 用付款方式降低风险**
- 不要全款预付。常见做法是定金+到车验收后付尾款。
- 如果必须预付，尽量走对公账户或有凭证的转账，别转私人微信、支付宝后没有任何合同。
- 可以要求“车到市场/指定地点验收合格再付剩余款”。
- 对第一次合作且坚持全款的供应商，直接降低优先级。

**6. 自己留出缓冲**
- 香蕉是生鲜，到车晚一天，可能成熟度、卖相、损耗都变。
- 如果市场档口已经定了销售计划，最好同时备一个备用供应商。
- 旺季、节假日、天气异常、口岸拥堵时，准时率本来就会下降，不能只靠供应商承诺。

**简单判断标准：**
- 敢签违约条款、敢给定金约束、敢给车牌和司机电话、有历史准时记录：相对可信。
- 只催款、不给合同、不给车牌、不让联系司机、货在哪说不清：大概率不能按时到车。
- 第一次合作，先小单试，不要把所有档口销量押在一个新供应商身上。
