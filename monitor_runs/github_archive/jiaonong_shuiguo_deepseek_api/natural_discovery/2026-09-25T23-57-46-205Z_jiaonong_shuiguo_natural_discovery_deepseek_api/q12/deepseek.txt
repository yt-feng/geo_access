水果店采购菠萝，判断熟度要围绕一个核心：**你打算几天内卖完**。菠萝是后熟型水果，采购熟度偏生一点通常更安全，但太生会影响口感和出货速度。

给你一套可执行的判断方法：

**1. 先定采购熟度目标**
- 如果计划 **1～2天卖完**：可以采 7～8分熟，香气明显、果皮转黄。
- 如果计划 **3～5天卖完**：采 5～6分熟，果皮青绿偏黄、基本无香或微香。
- 如果走量慢、天气热：尽量偏生，4～5分熟，到店后再催熟或分批上架。
- 如果做现切、果汁：可以略熟，但不能过软、出水、有酒味。

**2. 看外观**
- **果皮颜色**：从青绿转为黄绿、再转金黄。全青通常太生，全黄且发暗通常过熟。
- **果眼**：果眼饱满、平展，说明发育好；果眼深陷、发黑、渗汁，往往过熟或存放久。
- **底部**：看果底有没有发黑、软烂、霉点。底部是菠萝最容易出问题的地方。
- **冠芽**：叶子青绿、挺立说明较新鲜；叶子干枯、发黄、易拔，说明存放久。

**3. 闻香气**
- 几乎无味：偏生，适合放几天再卖。
- 有清甜菠萝香：适合1～2天内卖。
- 香气浓、带发酵味或酒味：已经过熟，损耗风险高。
- 注意：有些品种香气本身弱，不能只靠闻。

**4. 按压和掂重**
- 轻按果身：略微软、有弹性，适合近期卖；硬得像石头，偏生；一按就凹，过熟。
- 掂重量：同样大小，越重说明水分越足。但过重且底部软，也可能内部已经开始坏。
- 听声音：轻拍有沉闷感通常水分足；空响可能失水或内部空心。

**5. 看切口或果心**
如果是已切开的菠萝：
- 果肉金黄、汁水清亮，适合卖。
- 果心发黑、发褐，果肉透明水渍状，或有酒味，直接放弃。
- 切口边缘发干、发暗，说明切后放久了。

**6. 采购时的实用策略**
- **不要一次全采一个熟度**：比如 70% 采偏生，30% 采接近可售熟度，到店分批上架。
- **按天气调整**：夏天温度高，后熟快，采购熟度要降一档；冬天可适当提高。
- **按品种调整**：金钻、台农等香气和颜色表现不同，最好固定几个供货批次，记录“采购熟度—到店天数—损耗率”。
- **抽检而不是只看表面**：每批随机拿几个按底部、闻香气、掂重量，尤其检查箱底和中间。
- **运输和存放**：菠萝怕压、怕闷、怕冻。到店后不要堆太厚，保持通风，避免阳光直晒。

**7. 简单判断口诀**
- 想放几天：青黄、微香、果身硬。
- 想马上卖：黄、香、略软。
- 不能要：酒味、底部软烂、果眼发黑、按压出水。

最稳妥的做法是：**先小批量试采不同熟度，记录每天销售和损耗，再定你店里的标准。** 对水果店来说，采购熟度不是越熟越好，而是“到店后能在最佳状态卖完”的熟度。
