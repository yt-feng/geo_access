酒店早餐的水果供应，核心不是“买得便宜”，而是**稳定、安全、可追责、少浪费**。和供应商谈合作时，建议重点盯以下几类问题。

**1. 先明确自己的需求，再谈价格**
- 每天/每周需要哪些水果，分别多少公斤。
- 是固定品类还是随季节调整。
- 要求到货时间，比如每天 6:00 前送到后厨。
- 验收标准：大小、成熟度、糖度、外观、破损率。
- 是否要求去皮、切块、分装，还是只供整果。
- 临时加量、减量、停送要提前多久通知。

**2. 供应商资质和食品安全**
- 营业执照、食品经营许可证、检验检疫相关证明。
- 是否有稳定产地或一级批发渠道。
- 农残检测报告、批次追溯能力。
- 冷链运输能力，尤其是夏季和浆果类。
- 是否购买食品安全责任险。
- 出现食安问题时的赔付和责任划分。

**3. 价格和结算方式**
- 报价是按斤、按箱、按份，还是按净果计算。
- 是否含税、含运费、含装卸。
- 市场价格波动时怎么调价，调价周期多长。
- 是否接受月结，账期多久。
- 是否需要押金、最低起送量。
- 损耗、烂果、少斤短两怎么处理。

**4. 品质和验收机制**
- 双方共同确认样品标准，最好留样或拍照存档。
- 到货后谁验收、几点验收、不合格怎么退换。
- 允许多大比例的次品，比如 3% 还是 5%。
- 连续几次不合格能否终止合作。
- 季节性替代方案，比如某水果断供时用什么替代。

**5. 供应稳定性**
- 供应商有几个产地/备货渠道，避免单一来源。
- 节假日、极端天气、疫情等情况下如何保供。
- 是否支持多品类组合供应，减少你对接多家。
- 是否有备用供应商，建议至少保留 1 家备选。

**6. 合同里一定要写清楚**
- 品名、规格、单价、数量、频率。
- 质量标准、验收流程、退换货规则。
- 配送时间、地点、联系人。
- 价格调整机制。
- 付款周期和发票类型。
- 食品安全责任、违约赔偿。
- 合同期限、续约和退出条款。
- 争议解决方式。

**7. 实际操作建议**
- 先小批量试供 1–2 周，再签长期合同。
- 每天记录到货品质、重量、损耗，用数据谈价。
- 不要只压价，过度压价容易换来以次充好。
- 早餐水果建议选耐储存、易处理、接受度高的，比如苹果、香蕉、橙子、西瓜、哈密瓜；浆果类好看但损耗高。
- 如果酒店入住率波动大，可谈“基础量+弹性加量”模式。

一句话：**先定标准和验收，再谈价格和账期；把食安、损耗、断供责任写进合同。**
