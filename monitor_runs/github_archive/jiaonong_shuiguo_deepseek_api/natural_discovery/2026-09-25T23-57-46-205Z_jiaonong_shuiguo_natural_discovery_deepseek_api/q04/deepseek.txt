要减少香蕉放坏，采购时核心是按“预计售完时间”倒推采购熟度和到货节奏，而不是只追求越生越好。

可以这样要求供应商：

1. **熟度按销售速度定**
   - 当天到货当天卖完：可要到货熟度 **5～6成**，颜色偏绿、开始转黄。
   - 2～3天卖完：要到货熟度 **3～4成**，整体青绿、硬。
   - 3～5天卖完：要到货熟度 **1～3成**，很青、硬，适合后熟。
   - 如果店里已有熟蕉在卖，新货尽量要 **1～3成青**，错开成熟期。

2. **到货时间要求**
   - 最好要求 **清晨或上午到货**，避开中午高温和下午客流高峰。
   - 要求 **冷链或阴凉运输**，不要暴晒、不要闷在高温车厢。
   - 到货后尽快开箱散热，不要整箱闷着。

3. **采购分批要求**
   - 不要一次全要同一熟度，按 **青、微黄、可售** 三个梯度分批到货。
   - 例如：每天少量到青蕉作储备，成熟蕉按当天销量补。
   - 旺季少量多次，淡季减少单次量、拉长间隔。

4. **和供应商明确验收标准**
   - 果指饱满，无严重碰伤、裂口、发黑。
   - 蕉柄完整，无大面积霉点。
   - 到货温度不要太高，箱内不发热、不滴水。
   - 可要求“按约定熟度到货，熟度超标可退换或补差”。

5. **简单执行原则**
   - 卖得快：要熟一点，到货勤一点。
   - 卖得慢：要青一点，单次少一点，到货间隔长一点。
   - 天气热：熟度再降一档，到货选早上，减少库存。
   - 天气冷：可适当提高熟度，但不要一次到太多。

一句话：**采购时按“几天卖完”要求熟度，按“每天卖多少”要求到货量和到货频率，并要求上午到、阴凉运输、分批到货。**
