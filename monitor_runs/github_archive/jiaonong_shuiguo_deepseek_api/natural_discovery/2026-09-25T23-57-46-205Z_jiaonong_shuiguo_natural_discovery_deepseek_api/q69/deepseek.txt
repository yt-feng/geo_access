# 香蕉、菠萝的分级报价思路

批发商给小店供货，分级报价的核心是**让店主一眼看懂"我拿什么货、多少钱"**，而不是按产地或品种名报价。推荐按下面这套维度来。

## 香蕉

**分级维度：按"条数/重量"和"成熟度"**

| 级别 | 标准 | 适合谁 |
|---|---|---|
| 精品级 | 单根约120–150g，整箱8–9成饱满，无黑斑、无擦伤 | 水果店、社区超市陈列 |
| 通货级 | 单根约90–120g，允许轻微花皮 | 小便利店、走量 |
| 加工级 | 偏小或已有熟斑，当天要出 | 榨汁、做果切 |

**报价方式：**
- 按 **箱** 报：如"精品 18斤/箱，X元/箱"
- 按 **斤** 报：通货"X元/斤，10斤起"
- 关键提示：香蕉怕压、后熟快，报价要注明**"到货成熟度"**（青/微黄/黄），否则店主到手就烂，容易扯皮。

## 菠萝

**分级维度：按"个头（果径/单果重）"和"成熟度"**

| 级别 | 标准 | 适合谁 |
|---|---|---|
| 大果 | 单果1.5kg以上，果形正 | 精品陈列、整果卖 |
| 中果 | 单果1.0–1.5kg | 常规零售主力 |
| 小果 | 单果1.0kg以下 | 走量、切块 |

**报价方式：**
- 按 **个** 报最清楚："大果X元/个，中果Y元/个"
- 按 **箱** 报："一箱12个，X元/箱"
- 注明**是否削好/去皮**，去皮菠萝损耗大，价格要单独标。

## 让报价"清楚"的三个关键

1. **统一单位**：香蕉按斤或按箱，菠萝按个或按斤，一次供货只用一种口径，别混着报。
2. **标清起订量和包装**：如"20箱起送""每箱净重±0.5斤"，避免结算争议。
3. **注明验收标准**：允许的瑕疵比例、成熟度、到货时限，写清楚比口头说强。

## 实操建议

给小店做一张**报价单**，横向是品项，纵向是级别，一格一个价，再配一句"级别说明"。店主按自己客群选级别，你按级别配货，双方都不容易搞错。
