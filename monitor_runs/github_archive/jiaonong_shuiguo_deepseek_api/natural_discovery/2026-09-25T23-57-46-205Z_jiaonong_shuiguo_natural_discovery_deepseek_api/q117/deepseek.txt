先别按“拍脑袋定个数量”试卖，更稳的做法是先定一个**可承受亏损的试卖预算**，再反推试卖量。

可以按这个顺序判断：

1. **先定试卖目的**
   - 只是测顾客接受度：量可以更小。
   - 要测损耗、复购、陈列效果：量要够覆盖一个销售周期。
   - 要决定是否长期上架：至少测 1-2 个完整补货周期。

2. **用“试错预算”反推量**
   公式：
   **试卖量 = 可接受最大试错金额 ÷ 单件可能亏损**
   
   单件可能亏损 = 进货价 - 预估处理价（打折、清货、损耗后的回收价）
   
   举例：
   - 你最多能接受亏 500 元试这个新品。
   - 预估卖不掉时每件亏 3 元。
   - 那试卖量约 160 件左右，而不是一上来进 1000 件。

3. **按销售周期定最小量**
   水果看保质期：
   - 不耐放：1-3 天为一个测试周期。
   - 中等耐放：3-7 天。
   - 耐放：7-14 天。
   
   试卖量至少覆盖一个周期，否则看不出真实动销。
   
   公式：
   **试卖量 ≥ 日均预估销量 × 测试天数**
   
   日均预估销量可以先用同类水果历史销量打 5-7 折，因为新品没有认知。

4. **参考陈列和最小起订**
   - 如果供应商有最小起订量，先看这个量是否在试错预算内。
   - 如果超出预算，宁可换小规格、拼柜、少品类试，不要为了拿低价压大货。
   - 试卖量最好能摆满一个正常陈列面，但不要堆到必须靠特价才能清。

5. **实操建议区间**
   如果没有历史数据，可以这样起步：
   - 社区水果店：先试 1-3 箱，或 20-50 斤。
   - 中小超市/生鲜店：先试 3-5 箱，或 50-100 斤。
   - 连锁采购：先选 1-2 家门店试销，单店 1-2 个陈列位，量控制在 3 天内能卖完。
   - 高损耗、高单价新品：再减半。
   - 低损耗、低单价、大众品类：可适当加 30%-50%。

6. **判断是否加量的标准**
   试卖后看：
   - 动销率：3 天内卖掉 60% 以上，可以考虑加量。
   - 损耗率：超过 10%-15%，先别加。
   - 复购：有顾客回头问或买第二次，比单纯第一天卖爆更重要。
   - 毛利：扣掉损耗、折扣后仍为正，才值得扩大。

7. **最稳的执行方式**
   先小批量试卖，同时记录：
   - 进货量
   - 售价
   - 日销量
   - 损耗量
   - 打折清货量
   - 顾客反馈
   
   然后按“小步快跑”补货：第一次试卖，第二次加 30%-50%，第三次再决定是否正常采购。不要第一次就压到供应商给的优惠门槛。

一句话：**先算你能亏多少，再定试卖多少；试卖量控制在 1 个销售周期内能卖完，且亏损可承受。**
