小店做水果，核心原则是：**先保周转，再谈品类；宁可少卖，不要烂在店里。** 下面按可执行的思路给你捋一遍。

## 一、品类控制：做“窄而准”，不做“大而全”

**1. 砍到 6~10 个单品就够**
小店面积有限，货架和冷柜都紧张。每个品类（浆果、柑橘、瓜类、热带、苹果梨）留 1~2 个即可，同类里只留最好卖的那一支，避免“苹果卖 5 种、每种都压货”。

**2. 按角色选品，而不是按喜好**
- **引流款**：香蕉、苹果、橘子——价格透明、复购高、走量。
- **利润款**：车厘子、阳光玫瑰、进口提子等——单价高、毛利高，但**必须小批量、勤补**。
- **应急款**：整颗西瓜、切块果盒——上班族/路过客随手买。

**3. 优先选耐放、周转快的**
小店最怕损耗，优先选：
- 苹果、梨、橙、柚子、香蕉（催熟可控）
- 少碰或严格限量：草莓、蓝莓、桃、葡萄、切好的果盒（保质期以天甚至小时计）

**4. 按门店定位定主打**
写字楼店：切块果盒、单人份、香蕉苹果；社区店：整颗瓜、家庭装、耐放水果。

## 二、损耗控制：核心是“量”和“动销”

**1. 采购量按“天”算，不按“批”囤**
- 用**近 7 天日均销量 × 1.2**做当日采购量，宁可缺货，不压隔夜货。
- 高价易损品（车厘子、草莓）当天进货当天清，卖不完就降价促销。

**2. 少量多次补货**
小店没有仓储优势，靠“勤补”而不是“多囤”。可以和供应商谈**小批量、高频次**配送，哪怕单价略高，也比烂掉划算。

**3. 设置动态降价机制**
- 到货第 2 天开始：正常价
- 第 3 天：8 折
- 第 4 天：5 折或做果切
- 再卖不掉：直接报损，别再占位置
把损耗当“计划内成本”，而不是每次都想“再等等看”。

**4. 先进先出 + 陈列分区**
- 新货放里面，旧货摆前面。
- 把“临界品”单独放促销筐，别和好货混着卖，否则好的也显得不新鲜。

**5. 监控两个数**
- **损耗率**：水果行业小店控制在 5%~8% 算正常，超过 10% 就要砍品类或减量。
- **动销率**：每个单品每周是否都能卖掉，卖不动的直接淘汰，别舍不得。

## 三、给你的具体建议

1. **首批只上 6~8 个单品**，跑两周数据，留下卖得最快的 4~5 个，其余淘汰。
2. **高价水果限量进**：比如车厘子一次只进 1~2 盒，卖完再补。
3. **每天下午 5 点做一次“临期处理”**：打折、做果切或员工内购。
4. **和供应商约定退换/调货政策**，能退的尽量退，不能退的就少进。
5. **面积小就做“单品爆款”**，比如只主推一款切块果盒，比铺一堆品类更赚钱。

一句话总结：**品类做减法，采购做小量，库存做快转，滞销做快清。** 小店水果赚的是周转的钱，不是囤货的钱。
