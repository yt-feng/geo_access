要提高水果区客单价，核心不是单纯打折，而是用高频刚需品带低频高毛利品，并让顾客觉得“买一组更划算”。香蕉、菠萝、苹果这三样适合做组合促销，建议按下面思路操作。

## 1. 组合逻辑

- **香蕉**：高频、低价、引流强，适合做“钩子”。
- **苹果**：中高频、客单稳定、家庭常买，适合做“基本盘”。
- **菠萝**：季节感强、单价相对高、处理麻烦，适合做“利润点和冲动点”。

所以组合时不要三样平均降价，而是：
**用香蕉吸引进店，用苹果稳住购买量，用菠萝拉高客单。**

## 2. 可直接落地的组合方案

### 方案A：家庭果篮组合
**香蕉1把 + 苹果4个 + 菠萝1个**
定价建议：比单买总价便宜 **10%—15%**，但整体客单高于只买香蕉或苹果。

适合场景：
- 周末家庭采购
- 晚间下班顺路购买
- 社区超市、生鲜店

话术：
“一袋配齐，早餐、饭后水果都有了。”

### 方案B：早餐水果组合
**香蕉1把 + 苹果3个**
加购价：**+9.9元换购小菠萝1个**，或菠萝切盒半价换购。

目的：
- 先用低门槛组合成交
- 再用菠萝做加购，提高客单
- 避免直接降菠萝价格伤毛利

话术：
“买早餐水果，加9.9元换购菠萝，今明两天吃刚好。”

### 方案C：菠萝引流，苹果香蕉做利润
**菠萝切盒/整果特价**
条件是：
- 买菠萝后，苹果和香蕉可享“第二件8折”
- 或满39元送香蕉1把

目的：
- 用菠萝做视觉焦点和促销爆点
- 带动苹果、香蕉连带购买
- 适合菠萝上市季

### 方案D：阶梯满赠
- 满19元：送香蕉1根
- 满29元：香蕉1把 + 苹果2个
- 满39元：加1个菠萝或菠萝切盒

目的：
- 让顾客为了凑档位多买
- 比直接全场打折更保毛利
- 档位要卡在顾客原本客单价上方5—10元

## 3. 陈列怎么配合

组合促销能不能成，陈列占一半。

- **香蕉放入口或主通道**：吸引客流，但不要堵住动线。
- **苹果放中间层**：颜色整齐，家庭顾客容易拿。
- **菠萝放端头或堆头**：整果和切盒一起放，现场切一个，气味和视觉都能刺激购买。
- **组合包提前打包**：用透明袋或网兜，标“家庭装”“早餐装”，减少顾客决策时间。
- **价格牌写清单买价和组合价**：例如“单买18.7元，组合价15.9元”，让优惠一眼可见。

## 4. 定价和毛利控制

建议不要三样都降价。可以用这个原则：

- 香蕉：微利或平进平出，负责引流。
- 苹果：正常毛利，负责稳住利润。
- 菠萝：组合中让利一部分，但通过加购、切盒、满赠拉回毛利。

组合价计算方式：
**组合价 = 单买总价 × 0.85—0.9**
但组合价必须高于顾客只买香蕉或只买苹果的常见客单。

如果香蕉成本2元/斤，苹果5元/斤，菠萝6元/斤：
- 香蕉2斤：4元
- 苹果3斤：15元
- 菠萝1个约3斤：18元
- 单买总价：37元
- 组合价可定：32.9元或33.9元

这样客单从原来可能十几元，拉到30元以上。

## 5. 最有用的执行建议

如果只能选一个方案，优先做：

**“香蕉+苹果基础组合，加9.9元换购菠萝。”**

原因：
- 香蕉和苹果接受度高，成交容易。
- 菠萝作为加购，不强行捆绑，减少反感。
- 客单提升明显，且不破坏整体价格体系。
- 操作简单，员工也好执行。

## 6. 避免踩坑

- 不要做“香蕉+菠萝+苹果”全部大降价，容易只走量不赚钱。
- 不要组合里放太多易压伤的水果，香蕉和菠萝都怕压。
- 不要只在价签上写“优惠”，要写清便宜多少。
- 不要长期固定一个组合，建议每2周换一次主题，比如“早餐装”“周末家庭装”“下午茶装”。

简单说：**香蕉引流，苹果稳客单，菠萝做加购和利润；组合价让利10%—15%，再用满赠和换购把客单往上推。**
