判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要重点核查其“产地布局、冷链能力、历史履约、风险预案”四条线。可按下面清单逐项验证。

**1. 先看产地是否跨区域**
香蕉怕寒、怕台风、怕集中上市断档。单一产地很难全年稳定。
- 要求供应商说明：自有基地/合作基地分别在哪些省份或国家，各产地上市月份怎么衔接。
- 重点问：国产蕉淡季（一般冬春）靠哪里补？进口蕉来源是否稳定？
- 可判断标准：至少有2个以上不同气候带产区，且能画出全年12个月供货来源表。

**2. 看加工与冷链能力**
香蕉需要催熟、分级、冷链，不是地里摘了就能直送超市。
- 是否有催熟库、冷藏库、分拣线？日处理能力多少？
- 从产地到门店的运输温度、时间怎么控制？
- 旺季日供能力能否覆盖你所有门店，而不是只供几家样板店。
- 可判断标准：能提供冷库/催熟库照片、地址、容量，且愿意接受突访。

**3. 查历史履约数据**
不要只听“我们一直供某某超市”，要要证据。
- 过去12个月，每月实际供货量、缺货次数、到货合格率。
- 是否服务过同规模连锁超市？能否提供合同关键页或验收单。
- 可判断标准：过去一年月均供货量达到你需求的1.5倍以上，且缺货率低于约定阈值。

**4. 看风险预案**
真正稳定的供应商，会提前准备断供方案。
- 遇到台风、寒潮、运输中断、疫情封控，备用产地和备用物流是什么？
- 是否购买农业保险或价格波动对冲？
- 质量问题如何退换、补货时效多长？
- 可判断标准：有书面应急预案，且备用产地能在3—7天内切换。

**5. 做小规模压力测试**
签约前先试供。
- 选择淡季或天气异常月份，让供应商连续供2—4周。
- 同时下“加急单”“增量单”，看响应速度和到货品质。
- 记录到货时间、损耗率、催熟一致性、门店投诉。
- 可判断标准：试供期缺货不超过1次，损耗率在行业可接受范围内，且能按约定补货。

**6. 合同里写死稳定供货条款**
- 约定全年最低月供量、旺季增量响应时间、缺货违约金。
- 要求提供备用货源，并写入合同。
- 约定质量标准和退换货机制。
- 约定价格调整机制，避免行情波动时对方优先供高价客户。

**简单判断口诀：**
一看产地能不能接上，二看冷库催熟够不够，三看历史缺货多不多，四看断供应急有没有，五看淡季试供稳不稳。

如果这五项都过关，基本可判断能全年稳定供货；如果只靠一个产地、没有冷库、拿不出历史数据，风险就很高。
