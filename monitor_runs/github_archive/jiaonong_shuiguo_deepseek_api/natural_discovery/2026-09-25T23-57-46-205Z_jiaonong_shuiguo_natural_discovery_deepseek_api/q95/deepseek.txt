选学校食堂水果供应商，关键不是找“最便宜的”，而是找**能稳定供货、质量可控、票据齐全、出问题能追责**的。香蕉、苹果、橙子这类常见水果，建议按下面几个维度来筛。

## 1. 先明确准入硬门槛

学校采购通常比普通餐饮更严，供应商至少要满足：

- **营业执照、食品经营许可证**齐全，经营范围含食用农产品/食品销售。
- 能提供**每批次检测报告或产地证明**，至少能提供农残快检或承诺达标合格证。
- 能开**正规发票**，对公账户收款。
- 有固定经营场所、仓储或分拣能力，不是临时倒手。
- 能签**供货合同和食品安全责任书**，明确退换货、赔偿、终止合作条款。
- 配送人员有健康证，车辆清洁、有防雨防晒措施。

如果供应商连票据和检测报告都拿不出来，价格再低也不建议进。

## 2. 按水果品类看供应商类型

不同水果适合的供应商不一样：

- **苹果、橙子**：耐储存，适合找产地合作社、批发市场一级批发商、大型果蔬配送公司。重点看分级是否稳定、有无打蜡和保鲜处理合规。
- **香蕉**：催熟和储存要求高，最好找有催熟库或稳定配送能力的供应商，不要找只能当天从市场临时拿货的。
- **综合配送**：如果食堂每天要多种水果，优先选能一站式配送的果蔬公司，减少多家对接和验收压力。

## 3. 重点考察这 6 项

### ① 供货稳定性
问清楚：  
- 是否常年有货，还是季节性断供？  
- 遇到台风、寒潮、节假日能不能保供？  
- 每天最晚几点前送到？临时加单多久能响应？

学校食堂最怕今天有、明天没，或者临时换品种。

### ② 质量标准和验收方式
合同里要写清楚：
- 香蕉：成熟度、无黑斑烂果、单根重量范围。
- 苹果：大小均匀、无腐烂、无严重碰伤、口感正常。
- 橙子：无干瘪、无霉变、酸甜度可接受、大小相对一致。

验收建议：
- 每批抽检，坏果率超过约定比例整批退换。
- 现场称重，避免“带箱称重”或掺水。
- 拍照留档，记录批次、时间、数量、质量。

### ③ 价格机制
不要只比单次报价，建议：
- 每周或每两周询价一次，参考当地批发市场均价。
- 合同约定“随行就市但设上限”，或者直接约定阶段性固定价。
- 明确是否含运费、税费、损耗。
- 对比时按**可食用部分单价**算，不只看毛重价格。

### ④ 冷链和配送
- 香蕉怕冻，苹果橙子相对耐放，但夏季高温都容易坏。
- 配送车应干净、无异味、有遮盖，夏天最好有温控或通风。
- 到货时间尽量安排在加工使用前，避免长时间堆放。

### ⑤ 食品安全追溯
要求供应商做到：
- 每批可追溯到产地或批发来源。
- 出现农残、霉变、投诉时能立刻召回并换供。
- 保留进货台账，学校可随时抽查。

### ⑥ 应急和赔付
合同里写清楚：
- 质量问题多久内退换？
- 因水果问题导致师生不适，责任和赔偿怎么承担？
- 连续几次不合格可终止合同？
- 是否有备用供应商？

## 4. 建议的筛选流程

1. **收集 3—5 家供应商**：本地果蔬配送公司、批发市场大户、产地合作社。
2. **资质初审**：证照、检测、发票、配送能力。
3. **小批量试供 1—2 周**：每天记录到货时间、坏果率、重量、口感。
4. **综合评分**：质量 40%、价格 25%、稳定性 20%、服务 10%、票据合规 5%。
5. **签订合同**：明确品种、规格、价格机制、验收标准、退换货、违约责任。
6. **保留 2 家备选**：主供应商出问题时能马上切换。

## 5. 简单判断口诀

**证照全、票据齐、能追溯、送得稳、坏果少、退换快、价格透明、有备选。**

如果只能选一家，优先选**本地有仓储和配送能力、能给学校供货经验、愿意签质量责任条款**的果蔬配送商，而不是单纯报价最低的批发摊贩。
