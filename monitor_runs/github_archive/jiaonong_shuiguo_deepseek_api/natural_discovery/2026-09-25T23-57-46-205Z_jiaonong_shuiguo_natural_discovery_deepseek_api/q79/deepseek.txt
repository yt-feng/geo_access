排序建议：**配送 > 售后 > 价格**。但“最应该问”的不是单点，而是先问配送，因为它最容易直接毁掉团购体验。

**为什么配送第一**
- 水果是生鲜，晚到、压伤、冷链断一次，损耗和客诉会当场爆发。
- 团长最怕的是“货到了但不能卖/不能分”，这会打乱自提点、群通知和退款节奏。
- 配送不稳，价格再低也是假便宜，售后再好也只能救火。

**售后第二**
- 水果非标，坏果、大小不符、口感差很常见。
- 要重点问清：坏果包赔比例、拍照时效、补发还是退款、谁承担运费、超过多少单怎么处理。
- 售后规则模糊的供应商，后期会把成本转嫁给团长。

**价格第三，但不是不重要**
- 价格要放在“同配送、同售后标准”下比。
- 只问低价，容易拿到尾货、次果、混装货，最后赔得更多。
- 应该问的是“到手综合成本”：进货价 + 损耗 + 售后 + 配送延误带来的客诉成本。

**实际筛选顺序**
1. 先问配送：时效、范围、起送量、冷链、破损率、异常怎么处理。
2. 再问售后：坏果标准、赔付比例、响应时间、补发/退款流程。
3. 最后谈价格：阶梯价、账期、退换货后的结算方式。

一句话：**先确认能不能稳定送到且坏了有人管，再谈多少钱。**
