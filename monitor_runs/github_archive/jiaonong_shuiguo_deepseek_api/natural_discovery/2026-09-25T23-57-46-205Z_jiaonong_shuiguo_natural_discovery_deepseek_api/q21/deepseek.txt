超市采购水果时，供应商通常需要根据**水果类型、是否预包装、超市自身风控要求、当地监管要求**提供以下材料。最稳妥的判断是：

- **初级农产品/散装水果**：重点看**产地证明/进货凭证 + 农残检测合格证明**。
- **预包装或进口水果**：还要看**标签合规、入境货物检验检疫证明、中文标签**等。
- **大型超市/连锁商超**：通常还会要求供应商提供**营业执照、食品经营许可证、批次检测报告、承诺达标合格证**等，并按批次留存。

具体可分为以下几类：

### 1. 供应商主体资质证明
适用于企业、合作社、批发商等供应商：

- 营业执照
- 食品经营许可证（如涉及食品销售；部分食用农产品销售可能按当地规定执行）
- 若为生产商/合作社：相关生产资质、合作社登记证明等
- 供货合同、授权书、开票信息等

### 2. 水果作为食用农产品的证明
国产初级水果常见要求：

- **承诺达标合格证**：很多地区对食用农产品推行，供应商或生产者出具。
- **产地证明**：如产地村委会、乡镇政府、合作社或基地出具。
- **进货凭证/购销凭证**：证明来源合法、可追溯。
- **农药残留检测合格证明**：可以是供应商自检、第三方检测或产地快速检测报告。

### 3. 检测报告
超市一般会要求，尤其是高风险水果或长期合作供应商：

- **农药残留检测报告**：常见必查项，如有机磷、氨基甲酸酯类等。
- **重金属检测报告**：视品种和产地风险而定。
- **致病微生物检测**：通常更多针对即食鲜切水果，不是所有整果都强制。
- **第三方检测报告**：如 CMA/CNAS 资质机构出具，超市更认可。
- **批次检测报告或快检单**：与送货批次对应，不能只用一份旧报告长期通用。

### 4. 进口水果额外材料
进口水果通常需要：

- **入境货物检验检疫证明**
- **海关报关单/通关证明**
- **中文标签**
- **进口商资质**
- **核酸检测/消杀证明**：特定时期或特定地区可能要求，现已视政策而定
- **原产地证明**

### 5. 预包装或鲜切水果额外材料
如果是预包装、鲜切、果切：

- 食品生产许可证或食品经营许可证
- 产品标签：品名、产地、生产日期、保质期、贮存条件、生产者/经营者信息
- 出厂检验报告或批次检验报告
- 符合预包装食品相关标准

### 6. 超市实际验收时通常会查
- 证照是否在有效期内
- 检测报告是否对应**本批次**
- 报告项目是否覆盖超市要求
- 水果感官是否正常：新鲜度、腐烂、病虫害、异味
- 包装、标签、温控是否符合要求
- 能否追溯到产地或上游供应商

### 简单判断标准
你可以这样要求供应商：

1. **国产散装水果**：营业执照/经营许可 + 承诺达标合格证或产地证明 + 进货凭证 + 农残检测合格证明。
2. **国产预包装/果切**：再加生产许可、标签、出厂检验报告。
3. **进口水果**：再加入境货物检验检疫证明、报关单、中文标签。
4. **大型超市合作**：通常还要第三方检测报告、批次报告、供货合同、质量保证协议。

如果只是小型超市或临时采购，最低限度应保留：**供应商身份证明、进货凭证、农残检测合格证明或承诺达标合格证**，确保来源可追溯。
