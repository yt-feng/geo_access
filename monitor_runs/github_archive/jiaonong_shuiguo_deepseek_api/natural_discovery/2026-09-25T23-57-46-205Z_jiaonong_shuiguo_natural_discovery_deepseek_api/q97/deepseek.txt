酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准，避免只写“新鲜、优质”这种无法验收的描述。可按下面维度要求供应商。

## 一、通用规格标准

1. **品种与产地**
   - 明确具体品种，如红富士苹果、皇冠梨、台农芒果、夏黑葡萄等。
   - 需要时约定产地或品牌，避免同品种不同口感、大小差异过大。

2. **单果重量/直径**
   - 按品种约定克重或直径范围，例如苹果单果 180–220g、橙子直径 70–80mm。
   - 同一批次大小尽量均匀，便于摆盘统一。

3. **成熟度**
   - 到货时达到“即食成熟度”或“1–2 天可熟化”的标准。
   - 香蕉、芒果、牛油果等后熟水果要明确到货成熟阶段，避免当天不能用或第二天过熟。

4. **糖度/口感**
   - 对重点水果可约定可溶性固形物，如西瓜中心糖度≥11%、橙子≥10%。
   - 口感要求：甜酸适口、无异味、无发酵味、无酒精味。

5. **新鲜度**
   - 采摘/采收后到到货时间尽量短，叶菜类、浆果类尤其要控制。
   - 不得为库存尾货、冷库长期积压果或临期处理果。

6. **安全与合规**
   - 符合国家食品安全标准，农残不超标。
   - 可要求提供批次检测报告、承诺达标合格证或产地证明。
   - 包装材料符合食品接触要求，不得使用回收污染材料直接接触果肉。

7. **包装与运输**
   - 按酒店用量分箱、分筐或分袋，避免二次污染。
   - 运输温度按品类控制：浆果、切果类冷藏；热带水果防冷害。
   - 到货外箱干净、无破损、无受潮、无虫害痕迹。

## 二、外观标准

1. **颜色**
   - 具有该品种成熟后应有的色泽，色泽自然均匀。
   - 不得青白、发暗、褐变、黑斑明显或催熟不均。

2. **果形**
   - 果形端正，无明显畸形、偏斜、双果、裂果。
   - 摆盘用果更应大小一致、形状规整。

3. **表面**
   - 果皮光滑或符合品种特征，无大面积疤痕、锈斑、日灼、药斑、霉斑。
   - 允许极轻微自然瑕疵，但不能影响削切、摆盘和食用。

4. **损伤**
   - 无腐烂、发霉、软烂、渗液、虫蛀、虫眼、鸟啄。
   - 无明显压伤、磕碰伤、冻伤、裂口。
   - 蒂部不霉、不黑、不脱落严重。

5. **洁净度**
   - 无泥土、粉尘、明显污渍、枝叶残渣。
   - 不要求供应商过度清洗导致易腐，但应达到入厨前可直接清洗处理的状态。

6. **气味**
   - 有品种自然果香，无酸败、发酵、霉味、化学药味。

## 三、建议写入验收条款的量化示例

- 苹果：单果 180–220g，横径≥75mm，着色≥70%，无碰压伤、无腐烂，糖度≥11%。
- 橙子：横径 70–80mm，果面洁净，无霉蒂、无软果，糖度≥10%。
- 葡萄：整串完好，落粒率≤3%，无霉粒、无裂果，果粉自然。
- 西瓜：单果 4–6kg，中心糖度≥11%，无空心、无倒瓤、无裂瓜。
- 草莓：单果 15–25g，果形完整，无霉烂、无压伤，到货温度 0–4℃。
- 芒果：单果 250–350g，到货成熟度 7–8 成，无黑斑、无炭疽病斑、无软腐。

## 四、验收与退换要求

1. **抽检比例**
   - 每批次按 5%–10% 抽检，重点查腐烂、碰伤、成熟度、大小均匀度。

2. **不合格判定**
   - 腐烂、霉变、虫蛀、异味：直接拒收或整批退换。
   - 大小、颜色、成熟度不符：可要求换货、降价或按比例扣款。

3. **到货时间**
   - 明确下单后到货时限，如 24/48 小时内送达。
   - 明确每日或每周配送频次，保证酒店高峰用量。

4. **责任归属**
   - 到货验收前风险由供应商承担。
   - 因原料不合格导致酒店出菜延误、客诉或食品安全问题，供应商应承担相应责任。

## 五、最简采购标准模板

可要求供应商承诺：

> 所供水果盘原料品种纯正、新鲜成熟、大小均匀、色泽正常、无腐烂霉变、无虫蛀异味、无严重碰压伤；符合国家食品安全及农残标准；按约定克重/直径、成熟度、温度配送；到货验收不合格可拒收、退换或扣款。
