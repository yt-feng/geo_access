采购香蕉想减少熟过头浪费，关键不是“买得更少”这么简单，而是把**采购、验收、催熟/保鲜、使用顺序**一起管起来。可按下面执行。

**1. 采购时按成熟度分批买，不要一次全买同一种熟度**
- 香蕉一般分：青硬、微黄、黄熟、带斑点。
- 食堂不要全买“已经黄熟”的，建议：
  - 当天或次日用的：买黄熟、少量带斑点。
  - 2–3天用的：买微黄。
  - 3–5天用的：买青硬或刚转黄。
- 如果供应商能分级，直接要求“按成熟度分箱”，不要混装。

**2. 验收时把“熟度”写进标准**
验收不要只看大小和外观，要看：
- 果皮颜色：青、微黄、黄、斑点。
- 手感：硬、稍软、软。
- 是否有压伤、裂口、酒味。
建议规定：
- 直接发放水果：允许微黄到黄熟，不接受大面积黑斑、软烂。
- 加工用：可接受稍熟，但不能有发酵味。
- 青硬香蕉单独存放，不要和已熟香蕉混放。

**3. 储存时隔离乙烯，别让熟香蕉催熟青香蕉**
香蕉自身会释放乙烯，互相催熟。
- 青香蕉和黄熟香蕉分开放。
- 已熟香蕉不要密封在高温处。
- 条件允许时，青香蕉放在阴凉通风处；已熟香蕉可冷藏延缓继续成熟，但表皮会变黑，适合尽快加工。
- 不要放在暖气旁、灶台旁、阳光直射处。

**4. 使用时按“先熟先出”**
- 建立简单标识：到货日期、成熟度、先用哪一箱。
- 每天检查一次，把最熟的挑出来优先用。
- 最熟但不烂的香蕉，不要等到发水果，直接转给后厨做香蕉粥、香蕉饼、奶昔、烘焙、水果捞等。
- 已经软但无酒味、无霉变的，可加工；有酒味、流汁、霉变的必须废弃。

**5. 采购量按“消耗速度”倒推**
可以用一个简单公式：
- 每日香蕉消耗量 ≈ 发水果份数 + 加工用量。
- 采购周期内总量 = 每日消耗量 × 到货间隔天数。
- 再根据熟度分批：当天用 40%，中间用 40%，后面用 20%。
如果食堂周末消耗少，周五就不要按工作日量采购。

**6. 和供应商约定退换或调整**
- 要求供应商按成熟度分批配送，而不是一次送全熟。
- 约定到货后 24 小时内出现大面积过熟、压伤、腐烂的，可退换或补货。
- 如果供应商做不到分级，就缩短配送周期，改为少量多次。

**7. 最简单可执行的制度**
可以定为：
- 每周一、三、五送香蕉，每次分青、微黄、黄熟三档。
- 到货当天贴标签，按“先熟先出”摆放。
- 每天上午检查，带斑点的优先发或转加工。
- 出现酒味、霉变立即报废。
- 连续两周有浪费，就减少 10%–20% 采购量，并调整熟度比例。

核心原则一句话：**少量多次、按熟度分批采购、青熟分开、先熟先出、过熟转加工。**
