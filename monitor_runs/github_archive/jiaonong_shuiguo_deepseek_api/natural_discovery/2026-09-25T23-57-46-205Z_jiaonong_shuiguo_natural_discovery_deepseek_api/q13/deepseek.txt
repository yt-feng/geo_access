小水果店做附近小区团购，水果供应商最好能支持这些服务，按优先级给你列清楚：

**一、基础供货服务**
1. **稳定货源与品质分级**：能按团购价提供稳定批次，明确规格（斤两、果径、甜度、成熟度），避免“图片大果、到手小果”。
2. **小批量起订**：社区团购初期单量不稳定，供应商要能接受低起订量，甚至多品种拼车发货。
3. **次日达/定时配送**：能配合你的截单时间，第二天早上或前一晚送到店里/自提点。
4. **售后包赔**：坏果、烂果、缺斤少两、成熟度不够，能按比例赔付或补发。这点最重要。

**二、团购适配服务**
5. **提供团购专供规格**：比如5斤装、10斤装、家庭套餐、爆品组合，而不是只给批发大筐。
6. **支持代发/分拣**：如果单量上来，供应商能按小区订单分拣、贴标签、打包，减少你店里人工。
7. **允许预售锁价**：你前一天晚上截单，供应商能按约定价格锁定，不临时涨价。
8. **配合爆品节奏**：能提前告诉你哪些品适合做引流、哪些品利润高、哪些品容易售后。

**三、营销与运营支持**
9. **提供素材**：实拍图、短视频、规格文案、卖点、售后说明，方便你发群。
10. **试吃/样品支持**：新品先给样品或低价试吃装，你好在小区做试吃转化。
11. **区域保护**：同一个小区或附近几公里内，不把同款团购价放给多个团长，避免价格打架。
12. **活动支持**：节假日、开业、冲单量时，能给特价、赠品、满减补贴。

**四、结算与风险支持**
13. **账期灵活**：初期最好支持现结、周结，或少量押金，不压太多资金。
14. **退换货机制清晰**：什么情况赔、怎么赔、多久到账，提前写进合作约定。
15. **冷链能力**：夏天浆果、荔枝、樱桃等易坏品，要有冷链或泡沫箱冰袋支持。

**你选供应商时，重点问这5个问题：**
- 起订量多少？能不能多品拼车？
- 坏果怎么赔？比例多少？多久补？
- 能不能按我的团购规格打包？
- 截单后多久送到？迟到怎么办？
- 同一个小区，会不会再放给别的团长？

**建议你先做“小范围测试”：**
选3-5个高频水果，找1-2个供应商，先在一个小区试团一周。重点看：到货品质、损耗率、售后响应、配送准时。跑通后再扩品、扩小区。
