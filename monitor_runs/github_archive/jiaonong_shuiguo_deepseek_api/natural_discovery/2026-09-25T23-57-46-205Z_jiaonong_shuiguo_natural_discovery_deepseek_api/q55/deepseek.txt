餐厅水果拼盘想更划算，核心不是单看“哪个水果便宜”，而是看**可食率、损耗、出片/出块数量、人工、季节价差**。苹果、橙子、菠萝要按不同用途选规格。

下面按餐厅实际采购给你一套判断标准：

## 1. 苹果：优先选中大果，不要盲目贪大或特小

**推荐规格：**
- 做拼盘切块、切瓣：选 **80–85mm 或 85–90mm** 的中大果。
- 做雕花、薄片、摆造型：选 **85–90mm** 以上，果形端正的。
- 控制成本、混合拼盘：选 **75–80mm** 中小果。

**为什么：**
- 太小的苹果出肉少、削皮去核后损耗大，人工也高。
- 太大的苹果单价高，但切块数量不一定同比增加，容易“买贵不划算”。
- 餐厅最稳的是 **80–85mm**：大小均匀、出块稳定、摆盘好看、损耗可控。

**划算建议：**
- 选 **红富士、嘎啦、阿克苏** 这类脆度高、切后不易发面的。
- 按“每个苹果能出多少块”算，而不是按斤算。
- 如果拼盘以配色为主，苹果不用买最大，买颜色好、大小均匀的更划算。

## 2. 橙子：按“榨汁/切瓣/切片”分开选

**推荐规格：**
- 切瓣摆盘：选 **70–80mm** 中果，皮薄、籽少、易剥。
- 切片装饰：选 **75–85mm**，果形圆、横切面好看。
- 榨汁：选 **60–70mm** 小果或次果，出汁率优先，外观不重要。

**为什么：**
- 橙子太大，皮厚、白瓤多，切瓣后卖相不一定好。
- 小果榨汁更划算，因为采购价低，出汁率差距没有价格差距大。
- 切瓣用的橙子要选 **皮薄、无籽、易剥** 的品种，比如脐橙、血橙、沃柑要看季节。

**划算建议：**
- 拼盘用橙子，优先选 **中果**，不要选超大果。
- 如果餐厅同时做果汁，把外观差的橙子拿去榨汁，减少损耗。
- 橙子按“可剥出几瓣”算成本，比按斤算更准。

## 3. 菠萝：按“整果现切”还是“预切/罐头”选

**推荐规格：**
- 整果现切：选 **1.2–1.5kg/个** 的中等果。
- 做菠萝船、厚切：选 **1.5–2kg** 大果，果眼浅、肉厚。
- 控制人工、稳定出品：可用 **预切菠萝块/菠萝丁**，但成本通常高于整果。

**为什么：**
- 菠萝太大，削皮去眼损耗也大，而且一次用不完容易氧化。
- 中等果出肉率和人工平衡最好。
- 如果餐厅单量不稳定，整果切开后卖不完，损耗会吃掉利润。

**划算建议：**
- 选 **果眼浅、香味足、成熟度均匀** 的品种，比如金钻、台农、都乐等。
- 整果采购时，按“去皮去眼后剩多少克”算净成本。
- 如果拼盘用量不大，预切菠萝反而更划算，因为不浪费、不压人工。

## 4. 餐厅最实用的选规格原则

可以按这个顺序判断：

1. **先定用途**：切块、切瓣、切片、雕花、榨汁，规格完全不同。
2. **算净成本**：采购价 ÷ 可食重量，不是单看毛重价格。
3. **算人工**：削皮、去核、去眼、切配的时间也是成本。
4. **算损耗**：切后氧化、卖不完、边角料能不能二次利用。
5. **看季节**：当季水果通常比反季更划算，品质也更稳。

## 5. 直接给你的采购建议

如果餐厅做常规水果拼盘：

- **苹果**：选 **80–85mm 中大型果**，脆甜、颜色好、大小均匀。
- **橙子**：选 **70–80mm 中果**，皮薄无籽，适合切瓣。
- **菠萝**：选 **1.2–1.5kg 中等果**，出肉和人工平衡最好。

如果拼盘走高端路线：

- 苹果选 **85–90mm 精品果**。
- 橙子选 **75–85mm 外观完整的精品果**。
- 菠萝选 **1.5kg 左右、果眼浅的精品果**。

如果拼盘走低价走量：

- 苹果选 **75–80mm**。
- 橙子选 **60–70mm** 或榨汁级。
- 菠萝用 **预切块** 或当季小果，减少人工和损耗。

一句话总结：**苹果选中大果最稳，橙子切瓣选中果、榨汁选小果，菠萝选1.2–1.5kg中等果最划算。真正要比的是“净可食成本”，不是毛重单价。**
