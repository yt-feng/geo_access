判断供应商售后响应稳不稳定，不能只看口头承诺，要在**合作前、试单期、正式合作**三个阶段用具体动作去验证。给你一套可执行的判断方法：

## 一、合作前：先看“有没有机制”

**1. 问清楚售后对接方式**
- 有没有固定对接人？是业务员兼售后，还是专门客服？
- 响应渠道是什么：电话、微信、系统工单？
- 承诺多久响应？多久给处理方案？多久补货/退款？

**关键判断**：如果对方说“有问题找我”，但说不出流程和时限，基本不稳。

**2. 要书面的售后条款**
- 到货腐烂、黑心、催熟不均、短斤少两、香蕉青黄不接怎么赔？
- 是补货、扣款还是退货？比例标准写没写？
- 生鲜损耗一般有“到货验收期”，比如24小时内报损有效，超时怎么算？

**关键判断**：愿意把赔付标准写进合同或订单确认单的，通常比只口头答应的靠谱。

**3. 看它有没有“生鲜售后”经验**
- 菠萝怕黑心、水烂、催熟过头；香蕉怕青、怕冻、怕转黄太快。
- 问它：香蕉到店后几天转黄？菠萝到货糖度/成熟度怎么控？出问题怎么补？
- 如果供应商答不上来具体品控节点，售后大概率也是糊弄。

## 二、试单期：用小单测响应

**1. 故意留一次可追溯的问题**
比如到货后拍清楚：
- 时间、车牌/单号、批次
- 腐烂比例、黑心切开图、香蕉青硬或过熟图
- 过磅单、验收单

然后按合同渠道报修，记录：
- 多久回复？
- 多久给方案？
- 方案是否可执行（补货/退款/扣款）？
- 有没有推诿给物流、产地、天气？

**判断标准**：
- 2小时内回复、24小时内给方案、3天内落地赔付/补货，算合格。
- 超过24小时不回复，或每次都要你反复催，基本不稳。

**2. 连测2—3次，看一致性**
一次响应好可能是偶然。连续几次不同问题（数量、质量、时间）都能按同一标准处理，才叫稳定。

**3. 看它主动不主动**
稳定售后的供应商通常会：
- 主动问销售情况、损耗情况
- 提前提醒香蕉催熟节奏、菠萝存放条件
- 出问题先给临时方案，再谈责任

只会说“这不是我的问题”的，售后稳定性差。

## 三、正式合作：用数据持续盯

建议建一个简单台账，按供应商记录：

| 指标 | 合格线参考 |
|---|---|
| 首次响应时间 | ≤2小时 |
| 处理方案时间 | ≤24小时 |
| 赔付/补货落地 | ≤3天 |
| 报损争议率 | 低且稳定 |
| 同一问题重复发生 | 不反复 |
| 主动沟通频率 | 每周/每批有 |

连续2—3个月看：
- 响应时间是否波动大
- 赔付是否打折扣
- 是否换对接人就失联

## 四、几个直接可用的“试探问题”

采购时可以当面问：
1. “香蕉到店第3天大面积转黄、卖相变差，你们怎么处理？”
2. “菠萝切开黑心超过10%，是补货还是扣款？多久到账？”
3. “晚上或周末出问题，找谁？多久回？”
4. “上个月有没有客户因为售后终止合作？为什么？”
5. “能不能把赔付标准写进本次采购合同附件？”

**如果对方回避、含糊、只谈感情不谈条款，售后稳定性就要打问号。**

## 五、最稳的做法

- **小单试、连续试**：先试2—3批，不一次性压大单。
- **合同写死**：响应时限、赔付标准、对接人、备用联系人。
- **留证据**：每批拍照、过磅、验收单齐全。
- **设退出线**：比如连续2次超24小时不处理，就降级或换供应商。

一句话：**稳定售后 = 有固定人 + 有书面标准 + 有响应时限 + 连续几次真能兑现。** 只靠嘴说的，不要当稳定供应商。
