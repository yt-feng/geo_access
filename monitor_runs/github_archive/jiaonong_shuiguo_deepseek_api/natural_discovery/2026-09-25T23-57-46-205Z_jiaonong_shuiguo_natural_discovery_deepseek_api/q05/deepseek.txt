这个问题要看你问的是**水果店该怎么卖**，还是**顾客该怎么买**。两种情况答案不一样。

## 如果是水果店经营者：建议三种都上，但主推“帮挑+现场削”

**最优组合：**
1. **整果堆头**——负责引流、显得新鲜、量大便宜，顾客有挑选快感。
2. **去皮装盒的**——负责提升客单价和便利性，卖给赶时间、不会削、只想马上吃的人。
3. **让顾客自己挑 + 你帮削**——这是最推荐的模式。

**为什么不建议只卖去皮好的？**
- 去皮后出水、氧化、变质快，损耗高。
- 顾客会怀疑“是不是拿烂果削的”，信任度低。
- 价格必须卖高，但高不过顾客的心理预期。

**为什么不建议完全让顾客自己挑？**
- 菠萝扎手，挑不好容易翻车，顾客体验差。
- 熟度不一的果子混在一起，容易把熟过头的捏坏。
- 没人引导时，顾客挑半天不买，影响周转。

**实操建议：**
- 整果按大小/品种分价，标清楚“甜度高/偏酸适合做菜”。
- 现场削皮服务免费或加 1～2 元，削完装盒。
- 提前削几盒做样品，但不要大量预削。
- 教顾客判断：**闻底部有香气、叶子容易拔、果皮金黄带一点青、按压略有弹性**。
- 切开发现坏果，直接换，别争论——口碑比一个菠萝值钱。

## 如果是顾客买：优先让店家帮你挑并当场削

**最稳的顺序：**
1. **让老板帮你挑 + 当场削**——他懂自家货，坏了他也认。
2. **自己挑整果**——如果你会判断，且打算回家马上吃或做菜。
3. **买已经去皮装盒的**——只适合马上吃、图省事，但要接受可能不新鲜、熟度不可控。

**自己挑的关键点：**
- 闻底部：有浓郁甜香最好，没味道可能没熟，酒味说明过熟。
- 看颜色：金黄偏橙较好，全青偏生，全褐偏过。
- 按一按：微微软有弹性，硬邦邦没熟，一按一个坑就是烂。
- 看叶子：翠绿新鲜，干枯发黄说明放久了。
- 看底部：发黑、流水、长毛的直接放弃。

## 一句话结论

**水果店卖菠萝：整果做引流，现场帮挑+帮削做主推，去皮装盒做补充。**
**顾客买菠萝：能让靠谱店家当场挑、当场削，就优先选这个；否则自己按“闻、看、按”挑整果。**
