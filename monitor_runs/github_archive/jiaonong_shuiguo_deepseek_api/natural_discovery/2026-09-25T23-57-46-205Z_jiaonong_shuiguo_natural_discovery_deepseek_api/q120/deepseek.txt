供应商介绍产品时，核心不是把品种讲得多专业，而是帮商家快速回答三个问题：**卖给谁、怎么卖、能赚多少**。可以按下面这套话术逻辑来讲。

**1. 先绑定消费场景，不先讲品种名**
不要说“这是金钻凤梨，台农17号”，商家听不懂也不关心。改成：
- “这是**不用泡盐水、切开就能吃**的菠萝，适合写字楼果切和下午茶拼盘。”
- “这是**小个头、一次吃一个**的香蕉，适合便利店单根卖和学生党。”

场景一出来，商家立刻知道卖给谁。

**2. 用“对比老品类”的方式定位**
商家熟悉菠萝、香蕉，就用它们当参照物：
- “比普通菠萝**甜度高、酸度低**，不用挑，客人复购高。”
- “比普通香蕉**个头小、熟得慢**，货架期多2天，损耗低。”

一句话说清“和现在卖的有啥不一样”。

**3. 直接算利润账**
商家下单最关心赚不赚钱。给三个数：
- 进货价 vs 建议零售价
- 单箱毛利
- 损耗率或保质期

例如：“一箱12个，进价XX，建议卖X块一个，毛利大概XX%，放5天没问题。”这比说“品质很好”有用得多。

**4. 给最小起订和试销方案**
新品类商家怕压货。可以说：
- “先拿一箱试卖，卖不动我教你做果切引流。”
- “这个品和香蕉摆一起，顺手就带走了。”

降低决策门槛。

**5. 用一句话总结卖点**
模板：
> “这是给【谁】吃的【什么场景】用的【品类】，比【老品类】好在【具体差异】，一箱能赚【多少钱】，保质期【几天】，可以先拿【最小量】试。”

**避坑**
- 少讲产地故事、品种编号、糖度值，除非商家追问。
- 不要只说“好吃、新鲜、爆款”，这些无法判断。
- 不要一次推太多SKU，先推1-2个最容易懂的。

简单说：**把新品种翻译成“老品类的升级版 + 明确场景 + 利润数字 + 低风险试单”**，商家就更容易听懂并下单。
