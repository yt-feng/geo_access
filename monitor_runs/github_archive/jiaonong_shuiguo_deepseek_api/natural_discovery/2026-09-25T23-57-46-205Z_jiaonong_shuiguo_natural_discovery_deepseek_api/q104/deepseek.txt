单位采购水果遇到品质不一致，核心是**把“验收标准”前置到合同/订单里，到货时按标准验、留证据，再按约定走售后**。下面给你一套可直接执行的流程。

## 一、采购前先把标准写清楚

验收扯皮大多是因为下单时只写了“苹果200斤”，没写规格。建议订单/合同里明确：

1. **品种、产地、等级**：如红富士一级果，不是统货。
2. **单果规格**：按重量或直径，如“单果200–250g”“直径80mm以上”。
3. **成熟度**：如七八成熟，避免过生或过熟。
4. **外观要求**：无腐烂、无虫眼、无大面积碰伤、无药斑，色泽正常。
5. **新鲜度**：果柄新鲜、无萎蔫、无异味。
6. **允许偏差**：如“不合格率不超过5%，超出部分可退换”。
7. **包装和运输**：防挤压、防冻防热，到货温度要求。
8. **验收时限**：到货后多久内完成验收，如2小时内。
9. **售后条款**：不合格怎么退、换、补、扣款，响应时限。

## 二、到货验收怎么做

### 1. 验收准备
- 指定验收人，最好两人以上。
- 准备好电子秤、卷尺/卡尺、相机、验收单。
- 对照订单和送货单，核对品种、数量、规格。

### 2. 抽样验收
大批量不要全部拆，按批次抽：
- 每批随机抽 **5%–10%**，或至少抽20–30个/箱。
- 重点看：大小是否均匀、成熟度、腐烂率、碰伤率、虫害。
- 称重核对净重，注意是否带箱皮、垫纸增重。

### 3. 分档记录
把抽检结果分成：
- 合格
- 轻微瑕疵（可折价接受）
- 严重不合格（腐烂、虫蛀、规格严重不符）

算出**不合格率**，对照合同允许偏差。

### 4. 留证据
- 拍整体到货照、开箱照、问题果特写。
- 拍称重照片/视频。
- 送货单上注明问题，让送货人签字确认。
- 保留样品，必要时封存。

### 5. 现场处理
- **不合格率在允许范围内**：正常收货，瑕疵部分可协商折价。
- **超出允许范围**：
  - 能当场退换的，直接退换；
  - 不能当场处理的，先**拒收问题批次**或**暂收待处理**，在送货单上写明“品质待确认，保留追责权利”；
  - 不要先签字确认“数量质量无误”再事后追责，会很难。

## 三、售后怎么走

### 1. 第一时间书面通知
到货验收后尽快（最好当天）通过微信、邮件或函件通知供应商：
- 批次、数量、问题描述
- 抽检比例和不合格率
- 照片/视频
- 诉求：退货、换货、补货、折价或扣款

### 2. 按合同约定处理
常见方式：
- **退货**：严重不合格批次全退，运费由供应商承担。
- **换货**：限时补送合格品。
- **补货**：数量短缺部分补齐。
- **折价**：轻微瑕疵但可用的，按比例降价。
- **扣款**：从货款中直接扣除相应金额。

### 3. 设定响应时限
如“24小时内回复，48小时内完成退换”，避免拖到水果进一步腐烂，责任说不清。

### 4. 谈不拢时
- 保留合同、订单、送货单、验收记录、照片、聊天记录。
- 找第三方或双方共同复检。
- 仍无法解决，可按合同走投诉、12315或法律途径。

## 四、几个关键提醒

1. **别先签“验收合格”再验货**，签字前先看货。
2. **腐烂、虫害、异味类问题要当场提**，事后容易扯皮。
3. **水果是生鲜，时效很重要**，发现问题当天处理，别拖。
4. **长期供应商也要每次留记录**，方便累计考核和索赔。
5. **最好在合同里写清“不合格率超标按整批退换”**，比逐个挑拣更省事。
