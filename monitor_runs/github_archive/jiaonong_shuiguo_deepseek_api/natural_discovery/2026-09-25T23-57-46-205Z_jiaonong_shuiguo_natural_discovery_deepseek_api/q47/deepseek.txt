采购香蕉时，核心不是“买香蕉”，而是按**使用场景**控制熟度。茶饮店常用的香蕉大致分三种用途：

**1. 做香蕉果泥/奶昔/冰沙/奶茶底**
需要**熟度高但不过熟**的香蕉。

- 最佳采购状态：表皮**黄中带少量小黑点**，果肉软甜、香气足。
- 到店后通常还能放 **1～2天** 达到最佳使用点。
- 判断标准：捏起来有明显软感，但剥开后不能发黑、出水、发酒味。
- 如果买全青香蕉，后熟时间太长；买全黑香蕉，损耗高，容易出现发酵味。

**2. 做香蕉块、装饰、切片、烤香蕉甜品**
需要**外形完整、硬度较高**的香蕉。

- 最佳采购状态：表皮**基本全黄，但两端没有明显黑斑**，捏起来有弹性、不软塌。
- 适合当天到货后 **1～3天** 内使用。
- 太熟会切不成型，太生会涩口、香气不足。
- 如果要做焦糖香蕉、烤香蕉，可以略生一点，因为加热后会变软变甜。

**3. 做香蕉果酱、香蕉泥馅料、熬煮类甜品**
可以用**熟度偏高**的香蕉。

- 最佳采购状态：表皮**黄带较多黑点**，果肉很软、甜度高、香气浓。
- 这种香蕉不适合直接卖，但适合熬酱、做馅、混入面糊。
- 到店后应尽快使用或冷藏/冷冻处理。

**采购控制建议：**

- **按销量分批采购**：不要一次全买同一熟度。比如 60% 买黄中带点黑点，30% 买全黄偏硬，10% 买略青用于周转。
- **按使用节奏下单**：如果每天用 10 斤，可以每天到货，而不是每周一次大批量。
- **收货时抽检**：看表皮颜色、黑斑比例、果柄状态；捏几根判断软硬；有酒味、酸味、渗水的拒收或尽快处理。
- **储存分开放**：熟香蕉不要和青香蕉混放，乙烯会催熟。青香蕉可常温催熟，熟香蕉可冷藏延缓过熟；果肉可去皮分装冷冻。
- **建立熟度标准**：给员工一张对照表，比如：
  - 1级：全青，不能用
  - 2级：黄绿，适合催熟
  - 3级：全黄偏硬，适合切片/装饰
  - 4级：黄带黑点，适合奶昔/果泥
  - 5级：大量黑斑、软塌，只适合熬酱或报废
- **控制损耗**：香蕉是后熟水果，采购量建议按 **2～3天用量** 为上限；夏天缩短到 **1～2天**。

简单说：**做饮品果泥买“黄带黑点”的，做装饰切片买“全黄偏硬”的，做果酱买“黑点较多”的；下单要分批、少量、多频次。**
