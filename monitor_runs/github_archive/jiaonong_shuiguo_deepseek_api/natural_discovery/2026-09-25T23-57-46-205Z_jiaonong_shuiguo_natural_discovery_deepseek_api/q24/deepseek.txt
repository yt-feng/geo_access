提前向供应商索取资料，核心是把“合规证明”和“可追溯凭证”一起拿到。建议至少要求以下几类：

**一、主体与准入类**
1. 营业执照
2. 食品经营许可证（或食品生产许可证，视供应商类型）
3. 若供应商是贸易商而非种植基地，还要其上游基地/合作社的资质及授权链

**二、批次合规证明类（最关键）**
4. 该批次水果的**农药残留检测报告**
   - 最好由 CMA/CNAS 资质机构出具
   - 报告要能对应到具体品种、批次/采收日期、产地
   - 注意报告有效期，不能拿几个月前甚至去年的报告反复用
5. 供应商自检报告或基地快检记录（可作为辅助，不能替代第三方报告）
6. 若做有机、绿色、GAP 等认证，索取对应有效证书

**三、追溯与过程类**
7. 产地证明或基地信息：具体到县/乡镇/基地名称
8. 批次追溯信息：采收日期、加工/分拣日期、包装日期、批次号
9. 用药记录或种植过程记录（能提供更好，用于风险判断）
10. 运输和仓储记录，尤其是冷链品种

**四、合同与责任类**
11. 供货合同里明确农残标准、抽检不合格的退换货和赔偿责任
12. 质量保证书/承诺书
13. 每批次随货的“合格证”或“质量安全承诺达标合格证”

**实操建议：**
- 不要只收一次资料就长期沿用，**按批次索要检测报告和追溯信息**。
- 报告重点看：检测项目是否覆盖常见高风险农药，结论是否合格，样品名称和批次是否与到货一致。
- 对高风险品种（如豇豆、韭菜、芹菜、草莓、葡萄等）提高抽检频次，或要求供应商提供更全的农残扫描报告。
- 自己超市也可保留快检能力，作为入场抽查，不完全依赖供应商材料。
- 若供应商只能提供“合格证”但无检测报告，建议在合同中约定超市有权送检，不合格费用和损失由供应商承担。

简单说：**资质 + 批次检测报告 + 追溯信息 + 合同责任**，这四样齐了，农残抽检风险会小很多。
