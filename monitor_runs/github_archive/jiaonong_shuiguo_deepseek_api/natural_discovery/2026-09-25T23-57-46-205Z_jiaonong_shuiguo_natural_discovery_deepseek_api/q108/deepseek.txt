# 核实水果供应商“全国配送”真实覆盖能力的操作清单

“全国配送”是个模糊话术，实际含义往往差别很大：是自营冷链直达、还是只是发快递、还是只覆盖部分城市再中转？采购方按下面几步核实即可。

## 一、先问清“配送”的定义

供应商口中的配送通常分几类，要先锁定是哪一种：

- **产地直发快递**：顺丰/京东/普通快递，非冷链，水果损耗高，适合耐运品类（苹果、橙子）。
- **第三方冷链物流**：外包给顺丰冷运、京东冷链、中通冷链等。
- **自营或合作干线+落地配**：真正意义上的“送到指定城市/门店”。
- **只到区域分拨中心**：货到某地后需采购方自提或自行安排末端。

**判断口径**：让供应商书面说明起运地、运输方式、是否冷链、末端由谁负责。

## 二、用具体地址做测试，而不是听概括

拿你要覆盖的**实际收货地址**（尤其是偏远、县级、需要冷链的）逐一向供应商确认：

1. 能否送达这个具体地址（不是“这个省”）？
2. 送达时效几天？
3. 到货温度、包装标准？
4. 破损/损耗怎么赔付？

**重点测试**：新疆、西藏、青海、内蒙古偏远旗县、云贵山区、海岛等，这些是“全国”最容易露馅的地方。

## 三、索要可验证的证据

- **历史运单号**：让供应商提供近期发往你目标区域的真实运单，自己上快递/物流官网查轨迹，看是否真到末端。
- **冷链温控记录**：如有冷链，索要运输温度记录。
- **合作物流合同/协议**：看是否有稳定的承运方，而非临时找车。
- **损耗与售后数据**：让其提供近3个月各区域的赔付率。

## 四、小批量实测

洽谈阶段先下**小批量订单**，选1-2个最难覆盖的区域做真实配送测试，重点看：

- 是否按时到达
- 到货新鲜度/温度
- 末端是否真送到、还是让你自提
- 出问题后响应速度

这是最直接、最难造假的一步。

## 五、合同里把“覆盖能力”写实

- 明确列出**可送达区域清单**（细分到区县或邮编）。
- 约定**时效标准**和**损耗赔付比例**。
- 约定**超区/无法配送的处理方式**（提前告知、改址、退款）。
- 约定**违约条款**：承诺能到却到不了怎么赔。

## 快速判断建议

- 只要对方只说“全国配送”却给不出**具体区域清单+真实运单**，基本可判定覆盖能力存疑。
- 生鲜尤其是需要冷链的品类，能真正全国稳定覆盖的供应商很少，多为区域龙头+干线合作。
- **先小单实测、再签大合同**，是成本最低的验证方式。
