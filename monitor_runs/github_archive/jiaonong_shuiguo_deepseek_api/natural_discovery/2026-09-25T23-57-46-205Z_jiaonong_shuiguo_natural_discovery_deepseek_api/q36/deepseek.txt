从商超经营角度看，**没有绝对“哪个更好”，关键看门店客群、损耗控制能力和动销目标**。但总体结论可以很明确：

**多数社区商超：整果为主，切果为辅更稳。**
**写字楼/商圈/年轻客群强的门店：切果可以做成重点，但必须严格控损。**

下面给你一套可判断的逻辑。

## 1. 先看两种模式的核心差异

| 维度 | 卖整果 | 卖切果 |
|---|---|---|
| 毛利 | 通常较低 | 通常更高，有加工溢价 |
| 损耗 | 相对低，但压货会烂 | 很高，切后保质期短 |
| 客单价 | 低 | 高，容易连带销售 |
| 购买便利性 | 差，要自己削 | 强，即买即吃 |
| 适合人群 | 家庭、中老年、价格敏感 | 年轻人、上班族、游客、单身 |
| 运营要求 | 低 | 高，要冷链、刀工、排面管理 |
| 风险 | 库存积压 | 切了卖不掉直接报损 |

## 2. 判断你门店该主推哪种，看这4个指标

### ① 客群是谁
- **社区家庭客多**：整果为主。家庭更愿意买整颗回去削，价格敏感。
- **写字楼、地铁口、医院、学校、景区**：切果更好卖，尤其是小盒装。
- **年轻人和单身客多**：切果、小份装明显更有优势。

### ② 门店有没有冷链和现场加工条件
切果不是切完摆着就行，要求：
- 冷藏柜
- 干净操作台
- 定时 discarded
- 当日切当日清

如果这些做不到，**切果损耗会吃掉利润**，不如卖整果。

### ③ 菠萝本身的价格和季节
- 旺季、产地价低：整果好卖，切果也有利润空间。
- 淡季、进价高：整果更容易被嫌贵，切果小份反而好接受。

### ④ 门店定位
- **走量型**：整果。
- **便利型/精品型**：切果。
- **全客群型**：整果 + 切果组合。

## 3. 更推荐的实操方案：组合卖，不要二选一

比较稳的做法是：

### 整果区
- 卖完整菠萝
- 做堆头、促销价
- 满足家庭客和价格敏感客

### 切果区
- 卖两种规格：
  - **小盒装**：单人一次吃完，走便利
  - **大盒/半个**：家庭或两人份
- 可以搭配：
  - 菠萝块
  - 菠萝+其他水果拼盒
  - 冰镇菠萝

这样做的原因：
- 整果保底走量
- 切果拉高毛利和客单
- 不同客群都能覆盖

## 4. 切果能不能赚钱，关键看3件事

1. **当日切、当日清**
   卖不完的切果，第二天口感差、风险高，直接报损比继续卖更安全。

2. **控制切果比例**
   建议初期切果只占菠萝总进货量的 **20%—30%**，测试动销后再调整。
   如果当天切果卖不完，第二天就减量。

3. **定价要覆盖损耗**
   切果毛利必须明显高于整果，否则不值得做。
   一般切果毛利率要能覆盖：
   - 人工
   - 包装
   - 冷藏
   - 报损

## 5. 直接给你结论

- **社区店、家庭客为主**：整果为主，切果少量试水。
- **商圈店、年轻客多**：整果+切果并行，切果可占30%—50%。
- **没有冷链、没有专人管理**：只卖整果。
- **想提高毛利和客单**：做切果，但必须小份、冷藏、当日清。
- **想稳销量降损耗**：整果更安全。

一句话：
**整果是基本盘，切果是利润盘。**
**多数门店最优解不是选一个，而是整果保量、切果增量，但切果比例必须按动销和损耗动态调。**
