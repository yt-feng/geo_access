超市水果到货后发现品相不好，售后约定建议按“验收时限—判定标准—处理方式—责任费用—证据留痕”写清楚，避免扯皮。

**1. 验收时限**
- 到货当场验收：外观、品种、规格、数量、成熟度。
- 隐蔽问题：如内部腐烂、夹层坏果，约定到货后 **2-4 小时**内提出，最晚不超过 **当日营业结束前**。
- 逾期未提，视为外观验收合格，但不免除供方对食品安全、严重质量问题的责任。

**2. 品相不好怎么判定**
建议量化，不要只写“品相好”。
- 坏果率：如单批次腐烂、发霉、压伤、裂口超过 **3%** 可要求退换。
- 规格不符：果径、单果重、等级低于约定标准。
- 成熟度：过生、过熟、软化、出水、异味。
- 新鲜度：萎蔫、失水、褐变、虫眼、药斑、泥污严重。
- 包装：挤压、受潮、破损导致品相受损。

**3. 售后处理方式**
可按比例选择：
- 轻微不符：折价接收，按不合格比例扣款。
- 部分不合格：合格部分收货，不合格部分退货或换货。
- 严重不合格：整批拒收或整车退货。
- 已上架后发现：供方补货、退款、承担下架损耗。
- 食品安全问题：立即下架封存，按食安流程处理，供方承担相应责任。

**4. 费用和责任**
- 因供方质量导致的退换货，运费、装卸费、损耗由供方承担。
- 因超市储存不当导致的，由超市承担。
- 换货后仍不合格，超市有权解除该批次订单并要求赔偿。
- 可约定违约金或扣款比例，例如不合格部分货款的 **10%-30%**，但不宜过高以免被认定不合理。

**5. 证据留痕**
- 到货照片、视频，含车牌、批次、时间。
- 验收单、称重单、质检记录。
- 不合格样品保留，必要时封样。
- 沟通记录：微信、邮件、书面通知。
- 退货换货单据双方签字。

**6. 推荐条款写法**
“供方交付的水果应符合约定品种、规格、等级和新鲜度。超市应在到货后4小时内完成验收；发现坏果、压伤、腐烂、规格不符等，按实际不合格数量退货、换货或折价结算。因供方原因产生的退换货费用及损耗由供方承担。坏果率超过3%的，超市有权拒收该批次或要求供方补货；超过10%的，超市有权解除该批次订单并要求供方赔偿损失。”
