判断一批香蕉，核心看“到货状态 + 你计划卖几天”。香蕉是后熟型水果，现场熟度不等于到手熟度，坏果风险主要来自冷害、压伤、病害和催熟不均。

下面按可执行流程说。

## 一、先问清/确认基础信息

1. **品种和产地**：巴西蕉、菲律宾蕉、云南蕉、老挝蕉等，耐储性不同。
2. **是否催熟过**：已催熟的货，青皮也可能内部开始软。
3. **运输温度**：低于12℃容易冷害，表皮看着还行，里面发黑发软。
4. **采摘时间/到货天数**：越接近销售期，越要拿熟度刚好的货。

## 二、现场判断熟度：看、摸、闻、切

### 1. 看颜色
- **全青、硬**：未熟，适合自己催熟或放几天卖。
- **青中带黄、棱角明显**：开始转熟，通常2~4天可售。
- **黄多青少、棱角变圆**：接近可售，适合1~2天内走货。
- **全黄、出现糖斑**：即食熟度，必须快卖。
- **黄中带褐、柄发黑**：过熟或存放偏久，坏果风险高。

注意：**颜色只能看表皮，不能单独判断内部**。冷害蕉可能皮绿但芯软发黑。

### 2. 摸硬度
轻捏蕉身中段：
- **硬挺、无弹性**：生。
- **稍有弹性、不软塌**：适合短期存放。
- **一捏就陷、皮肉分离感**：过熟或压伤。
- **局部特别软**：大概率内部压伤或腐烂起点。

### 3. 看蕉柄和蕉轴
- 蕉柄**青绿、干爽**：较新鲜。
- 蕉柄**发黑、发软、渗液**：存放久或病害风险。
- 蕉轴切口**发黑腐烂**：整串风险上升，容易从轴心烂进去。

### 4. 闻气味
- 淡淡清香：正常转熟。
- **酒味、酸味、发酵味**：内部已经开始烂或过熟。
- 霉味：有真菌感染风险。

### 5. 切开抽查
不要只切一根。按不同位置抽：
- 每箱抽1~2根；
- 每批抽上、中、下层；
- 切开看芯部是否发黑、发软、空心、褐变。

**芯部发黑/发软**是坏果高风险信号，尤其冷害或浸水后。

## 三、判断坏果风险：重点查这几类

### 1. 冷害风险
表现：
- 表皮灰暗、发哑；
- 皮下维管束发黑；
- 芯部发黑、发硬或发软；
- 催熟后颜色不均、不上色。

如果运输温度低、到货后表皮异常发暗，风险高。

### 2. 压伤/机械伤
表现：
- 箱边、底层、串间接触处发黑软陷；
- 局部果皮破裂、渗汁；
- 切开后伤处褐变。

压伤果会先烂，并传染旁边果实。

### 3. 病害风险
常见：
- **炭疽病**：黑斑凹陷，逐渐扩大。
- **冠腐病/轴腐病**：蕉轴切口发黑腐烂。
- **霉病**：白色/灰色霉层。

只要蕉轴腐烂、黑斑连片，整箱风险都高。

### 4. 催熟不均
表现：
- 同一串有的黄有的青；
- 黄果已软，青果还硬；
- 表皮黄但果肉生硬，或表皮青但内部已软。

这种货卖相和损耗都难控。

### 5. 浸水/雨淋
表现：
- 箱内有水汽、纸箱发软；
- 果柄发黑；
- 有酸腐味。

这种货短期就可能大面积烂。

## 四、给批发商的实操决策标准

可以按“计划销售天数”倒推：

| 你计划卖几天 | 适合拿的熟度 | 风险判断 |
|---|---|---|
| 1~2天 | 黄多青少、稍有弹性 | 不能有酒味、轴腐、黑斑连片 |
| 3~5天 | 青黄各半、硬中带弹 | 可少量催熟，冷害和压伤要低 |
| 5天以上 | 偏青、硬、棱角明显 | 必须未催熟、无冷害、无浸水 |
| 当天特价 | 全黄、糖斑 | 只适合快走，坏果率会高 |

## 五、现场快速验收口诀

**一看色，二摸身，三闻味，四看轴，五切开。**
- 色不均：催熟或冷害风险。
- 身太软：过熟或压伤。
- 有酒酸味：内部烂。
- 轴发黑：整串风险。
- 芯发黑：直接降级或拒收。

## 六、建议的抽检方法

1. 每批至少抽 **3~5箱**，不是只开一箱。
2. 每箱抽 **上、中、下** 不同位置。
3. 每箱切 **1~2根**，重点切看起来最差的。
4. 记录：
   - 青黄比例；
   - 软果比例；
   - 黑斑/轴腐比例；
   - 异味情况；
   - 切开芯部异常比例。
5. 如果坏果/异常果超过 **5%~10%**，就要压价、减量或拒收；超过 **10%** 且继续发展，通常不适合正常批发。

## 七、拿货后的处理建议

- **青蕉**：保持13~15℃，通风，别闷箱。
- **开始转黄**：降到适温，尽快分流销售。
- **已黄熟**：优先出货，别堆压。
- **有压伤/黑斑**：单独挑出，避免传染。
- **冷害蕉**：不要高温猛催，容易外表黄、内部烂。

一句话：**拿香蕉不要只看黄不黄，要看“颜色是否均匀、手感是否正常、蕉轴是否干净、切开芯部是否健康”。** 如果颜色不均、轴发黑、有酒味、切开芯黑，这批货坏果风险就高。
