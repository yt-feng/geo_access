水果店遇到坏果，和供应商结算或赔付，关键看**坏果是在到货验收时就发现，还是上架销售后才陆续发现**，以及你们事先有没有约定。正常可以按下面处理。

## 1. 到货验收时发现坏果
这是最好处理的阶段。

- **当场拍照、拍视频留证**：整批货、坏果特写、快递单/送货单、时间地点都拍进去。
- **当场清点数量**：比如一箱苹果 40 个，坏了 8 个，就明确记录“坏果 8 个”。
- **优先按比例扣款**：  
  最常见的是：
  - 坏果部分不结算；
  - 或者按坏果数量 × 进货单价扣减货款。
- **如果坏果比例很高**：  
  比如超过 10%～20%，可以要求：
  - 整批退货；
  - 换货；
  - 补发；
  - 或整批按折扣价结算。

**举例**：  
进货 100 斤橙子，单价 3 元/斤，到货发现 12 斤坏果。  
正常可结算：  
(100 - 12) × 3 = 264 元。  
如果约定“坏果超过 10% 整批拒收”，那就可以要求退货或换货。

## 2. 上架后才陆续发现坏果
这种情况要看责任和约定。

- 如果是**供应商发货时就带了内伤、熟度不对、冷链不到位**，通常仍可要求供应商承担。
- 如果是你这边**存放不当、挤压、温度不对、放太久**，一般由水果店自己承担。
- 实际操作中，很多供应商会接受：
  - 下次进货时补货；
  - 按坏果金额抵扣下批货款；
  - 小额现金赔付；
  - 达到一定比例才赔。

建议当天发现当天反馈，不要拖太久，否则责任容易扯不清。

## 3. 常见结算/赔付方式
按优先级排：

1. **坏果直接扣款**：最直接，坏多少扣多少。
2. **补货/换货**：适合坏果比例较高、还能继续合作的情况。
3. **下批货款抵扣**：供应商常见做法，水果店也能接受。
4. **整批退货**：坏果比例很高或品质严重不符时用。
5. **现金赔付**：一般用于已经付款、又不方便退货的情况。
6. **按比例折价结算**：比如整批按 8 折、7 折结算。

## 4. 和供应商谈的时候怎么说
可以直接按这个逻辑讲：

> “这批货到货后发现坏果 X 斤/件，我已经拍照留证。按进货价算，坏果金额是 X 元。你看是直接扣这批货款，还是下批补货/抵扣？”

这样比只说“你的水果坏了”更容易推进。

## 5. 最好提前在合作里约定清楚
为了避免每次扯皮，建议和供应商约定：

- 到货验收时限：比如 2 小时内、当天内；
- 坏果赔付标准：按个数、重量还是比例；
- 坏果率容忍范围：比如 3% 以内不赔，超过部分赔；
- 赔付方式：扣款、补货、下批抵扣；
- 生鲜损耗责任：运输中、到店后分别谁承担；
- 留证要求：照片、视频、送货单。

## 6. 一句话总结
**到货发现坏果，正常就是坏果不结算或按坏果金额扣款；坏得多就退货、换货或补发；上架后才发现，要看是不是供应商责任，通常用补货或下批抵扣解决。核心是：当场留证、及时反馈、按约定扣赔。**
