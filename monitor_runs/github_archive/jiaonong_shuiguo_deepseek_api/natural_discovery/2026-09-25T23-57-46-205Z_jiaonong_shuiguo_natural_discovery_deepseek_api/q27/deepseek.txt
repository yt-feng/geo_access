判断苹果和橙子的规格是否适合门店销售，核心是看**目标客群、陈列方式、损耗控制和定价带**，而不是单纯看“大不大”。可以按下面几个维度直接判断。

**一、先定门店销售场景**
1. **社区生鲜店/便利店**  
   - 苹果：单果 **180–250g** 比较稳，约直径 75–85mm。  
   - 橙子：单果 **180–280g** 比较稳，约直径 70–85mm。  
   - 特点：家庭一次买 3–6 个，太大单价高，太小显得品质弱。

2. **精品水果店/中高端超市**  
   - 苹果：**220–300g**，直径 80–90mm。  
   - 橙子：**250–350g**，直径 80–95mm。  
   - 特点：礼盒、家庭装、按个卖都合适，外观和均匀度要求更高。

3. **平价走量店/社区团购自提点**  
   - 苹果：**150–220g**，直径 70–80mm。  
   - 橙子：**150–250g**，直径 65–80mm。  
   - 特点：价格敏感，适合按斤卖，但太小会影响复购。

4. **礼盒/企业团购**  
   - 苹果：**250–350g**，直径 85–95mm，果形端正。  
   - 橙子：**300–400g**，直径 85–100mm，表皮干净。  
   - 特点：规格要高度一致，大小不齐会直接拉低礼盒价值。

**二、现场快速判断方法**
1. **称重抽样**  
   随机抽 20–30 个，算平均单果重和最大最小差。  
   - 苹果：同一批最大最小差最好不超过 **40–50g**。  
   - 橙子：同一批最大最小差最好不超过 **50–60g**。  
   差距太大，陈列会显得杂乱，顾客容易挑拣，损耗上升。

2. **量直径**  
   用卡尺或分级圈测横径。  
   - 苹果常见销售级：70、75、80、85、90mm。  
   - 橙子常见销售级：65、70、75、80、85mm。  
   如果门店按“个”卖，直径均匀比单果大更重要。

3. **看果形和表皮**  
   - 苹果：果形端正、无明显偏斜、无严重锈斑、无碰压伤。  
   - 橙子：圆整、表皮细、无严重浮皮、无油胞下陷、无软果。  
   规格再大，如果畸形、软塌、机械伤多，也不适合正常货架销售。

4. **算陈列层数和托盘适配**
   - 苹果直径 80mm 左右，普通货架一层大约能放 8–10 个/米。  
   - 橙子直径 75mm 左右，一层大约能放 9–12 个/米。  
   如果果子太大，堆头容易滚落、陈列量少、补货频繁；太小则堆头显得空。

**三、关键经营指标**
1. **毛利与定价带**  
   先看周边同类门店卖多少钱。  
   - 苹果按斤卖：常见 5.98–12.98 元/斤。  
   - 橙子按斤卖：常见 4.98–9.98 元/斤。  
   如果规格导致采购价明显高于这个带，就不适合该门店主推。

2. **损耗率**  
   苹果正常损耗约 **3%–8%**，橙子约 **5%–10%**。  
   如果小果、软果、碰伤果多，损耗会快速上升，规格再便宜也不划算。

3. **周转速度**  
   社区店日销苹果/橙子通常几十斤到一两百斤。  
   如果单果太大，顾客一次买 2–3 个就接近 1 斤，可能抑制购买量；如果太小，顾客觉得不划算。

**四、最适合门店的通用结论**
- **社区超市/生鲜店主推：**  
  苹果 **75–85mm，180–250g**；橙子 **70–85mm，180–280g**。  
- **精品店主推：**  
  苹果 **80–90mm，220–300g**；橙子 **80–95mm，250–350g**。  
- **礼盒/团购：**  
  苹果 **85mm 以上，250g 以上**；橙子 **85mm 以上，300g 以上**，且必须大小一致。  
- **不建议正常货架销售：**  
  苹果低于 **65mm / 120g**，橙子低于 **60mm / 120g**，除非明确做特价引流。  
  苹果高于 **95mm**、橙子高于 **100mm**，除非做礼盒或高端按个卖，否则动销和毛利容易出问题。

**五、采购时直接问供应商的 5 个问题**
1. 这批货的横径范围是多少？比如 75–80mm 还是 80–85mm？  
2. 单果重范围是多少？平均多少克？  
3. 大小均匀度如何？最大最小差多少？  
4. 可食率、糖度、酸度大概多少？  
5. 到店损耗预估多少？有没有软果、碰伤、浮皮？

最终判断标准可以概括为：**目标客群买得起、陈列放得下、损耗控得住、毛利算得过来、顾客复购不觉得坑。** 满足这五点，规格就适合门店销售。
