判断养老院/医院食堂的水果供应商，核心不是"价格低不低"，而是**能不能持续、合规、可追溯地供货**。可以从下面几个层面逐一核验。

## 一、合规资质（准入底线，缺一不可）

| 项目 | 要看什么 | 红线 |
|---|---|---|
| 营业执照 | 经营范围含"食品销售/农产品销售" | 无照或超范围直接排除 |
| 食品经营许可证 | 主体业态、经营项目覆盖水果销售 | 过期、借用他证不行 |
| 检测报告 | 农残检测（如GB 2763对应项目）、第三方或自检报告 | 无检测能力又拒不提供，风险高 |
| 进货凭证 | 上游产地/批发市场的票据、承诺达标合格证 | 无法溯源的一律不收 |
| 人员健康证 | 接触食品的配送、分拣人员 | 过期证件要限期整改 |

> 注意：只做"食用农产品"销售的，很多地区按《食品安全法》可豁免食品经营许可，但仍需**可追溯**。所以别只看有没有证，要看**能不能追到货**。

## 二、稳定性判断（比资质更隐蔽，也更容易踩坑）

1. **供货来源是否单一**
   问清楚：自营基地？固定合作果园？还是每天去批发市场现采？
   - 有稳定基地/长期协议 → 稳
   - 纯"市场现采、看天吃饭" → 价格波动大、断供风险高

2. **季节性应对能力**
   问：冬季、雨季、节假日前怎么保供？有没有替代产地？
   - 回答含糊 → 大概率会断货

3. **冷链与配送能力**
   - 有没有冷藏车/保温箱？
   - 配送频次、到货时间是否固定？
   - 覆盖半径内能否当天补货？

4. **经营年限与客户结构**
   - 成立时间、是否长期给同类机构（学校、医院、养老院）供货
   - 能否提供**可核实的**合作案例（能打电话回访的）

5. **财务与规模**
   - 注册资本、是否有被列为失信被执行人（可查"中国执行信息公开网"）
   - 突然低价抢单、规模明显不匹配的，警惕转包或跑路

## 三、可执行的核验动作（建议照做）

1. **查**：国家企业信用信息公示系统、中国执行信息公开网、当地市场监管局抽检公告（看有没有被通报过）
2. **验**：要求提供近3个月检测报告 + 进货台账样本
3. **访**：实地看分拣场地、仓储、车辆（不要只去办公室）
4. **试**：先签**1–3个月小批量试用**，考核到货准时率、损耗率、投诉响应
5. **留痕**：每批到货索证索票，建立验收记录（这也是你们自己的合规要求）

## 四、合同里必须写死的条款

- 质量标准：明确农残、外观、规格、损耗率上限
- 索证索票义务：每批随货提供合格证/检测凭证
- 断供与违约：延迟、缺货、质量不合格的赔偿与替换机制
- 价格机制：随行就市还是锁价，调价需提前书面通知
- 追溯与召回：出现食品安全问题时供应商的配合与责任
- 退出机制：连续N次不达标可单方解除

## 五、给养老院/医院的额外提醒

- 老人、病人对农残、新鲜度、软硬度更敏感，**验收标准要比普通食堂更严**
- 送养老院的水果要考虑**易咀嚼、易消化**，这属于采购规格问题，提前和供应商约定品种
- 建议**至少两家备选供应商**，主供+应急，避免单一依赖

---

**一句话判断标准**：资质齐全只是入场券，真正决定稳定性的是"**有没有稳定货源 + 能不能持续供 + 出问题能不能追责**"。用"小批量试用+每批索证+定期复查"这三招，基本能把大部分不靠谱的供应商筛掉。
