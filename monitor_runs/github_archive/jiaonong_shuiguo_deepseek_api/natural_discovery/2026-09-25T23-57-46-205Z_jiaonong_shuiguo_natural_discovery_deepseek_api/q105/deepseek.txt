水果采购锁价能锁多久，没有统一标准，主要看品类、季节、供应商类型和你们的采购量。按经验大致可以这样判断：

**常见锁价周期**
- **鲜果、时令水果（如荔枝、樱桃、西瓜）**：一般很难锁长，常见 **3～7天**，最多 **15天**。因为产地价格波动大，供应商通常只愿意给很短窗口。
- **常规大宗水果（如苹果、橙子、香蕉、梨）**：相对容易谈，通常能锁 **15～30天**，采购量大的可以到 **1～3个月**。
- **进口水果**：受汇率、海运、关税影响，一般 **7～15天**，很少超过1个月。
- **冷冻果、果浆、罐头原料**：这类标准化程度高，通常能锁 **1～3个月**，甚至 **半年到一年**（配合年度框架协议）。
- **全年稳定品类 + 长期合作供应商**：可以谈 **季度价、半年价**，但通常会附带调价机制。

**影响锁价时长的关键因素**
1. **品类波动性**：越容易受天气、季节影响，越难锁长。
2. **采购量**：月采购量越大、越稳定，供应商越愿意让利锁价。
3. **付款条件**：预付、现结、账期短，锁价能力更强。
4. **是否接受保底量**：承诺最低采购量，是锁价的核心筹码。
5. **是否有调价条款**：完全固定价难，带触发条件的浮动价更容易谈成。

**实操建议**
- 短期锁价：先锁 **7～15天**，到期滚动续签，适合时令果。
- 中期锁价：谈 **1个月固定价 + 超量/减量调价**，适合常规果。
- 长期锁价：签 **季度/年度框架协议**，约定基准价 + 波动阈值（比如产地价涨跌超5%再调）。
- 合同里写清：**锁价周期、保底量、调价触发条件、质量标准、违约处理**。
- 不要只盯价格，同时锁 **规格、等级、包装、损耗承担、到货时间**，否则价格锁了，品质和履约可能缩水。

一句话总结：**时令鲜果一般锁几天到两周，常规大宗果能锁半个月到一个月，冷冻/加工原料可锁几个月到一年。** 想锁更久，靠的是采购量、稳定性和长期合作关系，而不是单纯压价。
