超市和水果供应商的账期没有统一标准，常见范围大致如下：

- **生鲜水果类：7～30天较常见**，其中 **15～30天** 是许多超市和供应商都能接受的区间。
- **大型商超/连锁超市**：对中小供应商常见 **30～60天**，部分强势渠道可能到 **60～90天**，但水果因损耗高、周转快，通常会比普通食品短。
- **中小超市、社区店、水果店**：更常见 **现结、周结、7～15天**。
- **批发市场或产地直采**：常见 **现款现货、3～7天、10～15天**。

影响账期的关键因素：

1. **谁更强势**：大型连锁超市通常压账期，供应商议价弱。
2. **水果品类**：叶菜、浆果、荔枝等易损耗品类账期更短；苹果、橙子、土豆等耐储品类可稍长。
3. **供应规模**：独家、稳定、大批量供应，供应商可能接受更长账期。
4. **结算风险**：新合作通常先短账期或现结，合作稳定后再延长。
5. **是否含退换货、损耗承担**：如果超市承担损耗少，供应商会要求更短账期。

实操建议：

- 新供应商合作：先谈 **7～15天**，最多 **30天**。
- 稳定合作后：可逐步到 **30天**，大型超市可谈 **45～60天**。
- 如果超市要求 **60天以上**，供应商应把资金成本算进报价，或要求部分现结、缩短对账周期。
- 合同里要写清：对账日、开票日、付款日、逾期违约金。比如“每月5日前对账，10日前开票，开票后30天内付款”。

一句话：**水果供应商账期常见是7～30天；大型超市可能30～60天；中小超市和水果店多为现结到15天。**
