做低价香蕉，投诉高发点通常集中在：青硬催不熟、到手已经发黑、大小/重量不符、断把掉根、局部烂心。低价不等于低质，核心是把“低价”建立在**可控的品种、成熟度、履约速度和售后规则**上，而不是靠压货甩卖。

**1. 选对品种和产区**
- 优先选催熟后风味稳定的品种，如巴西蕉、桂蕉系列等，别用来路不明的高山蕉或尾货蕉。
- 低价可以来自产地集中采购、二级果分级，但不要收“已经转黄再回青”的蕉，这种后期必出黑斑和烂心。

**2. 控制到货成熟度**
- 社区团购到消费者手里通常还要1-2天，所以团购走货的蕉应该是**青蕉或微黄**，不是已经全黄。
- 青蕉需要自然催熟或随箱放苹果/香蕉催熟，但要在页面写清楚“青蕉发货，2-4天自然转黄”，避免用户收到青蕉直接投诉“没熟”。
- 如果做“即食黄蕉”，必须走冷链或次日达，且成熟度控制在7-8成，不能全熟。

**3. 分级和重量透明**
- 按“净重”而非“毛重”标价，例如“净重4.5斤±0.2斤”，不要写“5斤装”结果含箱5斤。
- 大小可以分“小果/中果/大果”，低价款明确写“小果/二级果”，把预期前置，投诉会少很多。
- 同一批货尽量统一成熟度，避免一箱里有的青有的黄。

**4. 包装和运输防压防冻**
- 用带透气孔的纸箱或网套，不要用密封塑料袋闷着，否则容易发霉、烂心。
- 冬季防冻、夏季防高温，运输中避免挤压。香蕉怕压、怕冻、怕闷，这三样都会直接导致黑斑和烂心。
- 到团长点后不要堆在暖气旁或太阳下，阴凉通风存放。

**5. 售后规则前置**
- 页面明确写：青蕉需自然催熟，催熟后食用；如出现烂心、发黑、断把超过一定比例，可拍照售后。
- 设定简单可执行的赔付标准，例如“坏果超过20%按比例赔，超过50%全赔”，不要设“必须当天反馈”这种做不到的门槛。
- 团长端提前培训：收到投诉先看照片判断是“未熟”还是“已坏”，未熟引导催熟，已坏直接走赔付，避免扯皮。

**6. 用“低价+确定性”替代“低价+清仓”**
- 低价款可以固定为“青蕉催熟款”，走稳定产地和稳定规格，长期卖，而不是今天一批明天一批。
- 把低价做成引流款，但用页面说明和售后兜底把品质预期管住。
- 如果某批货成熟度不齐或已有软化，宁可不上团购，转做门店特价或加工，不要硬发。

**7. 关键动作清单**
- 到货抽检：随机开3-5箱，看青度、硬度、有无黑斑烂心。
- 分拣：青黄分开、大小分开，坏果挑出。
- 页面写清：品种、净重、成熟度、催熟方法、售后标准。
- 团长点：阴凉通风，不堆压，不暴晒。
- 售后：坏果拍照按比例赔，未熟给催熟指引。

一句话：低价香蕉的投诉，大多不是“便宜”造成的，而是**成熟度预期错位 + 运输闷压 + 售后规则模糊**造成的。把这三件事管住，低价也能做到低投诉。
