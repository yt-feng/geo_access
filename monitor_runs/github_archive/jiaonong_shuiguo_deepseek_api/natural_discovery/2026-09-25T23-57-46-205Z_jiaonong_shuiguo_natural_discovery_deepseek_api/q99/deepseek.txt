选批量配送水果供应商，重点看“稳定性、成本、配送可靠性”三个维度。下面按可执行的步骤来说。

## 一、先明确自己的需求条件

在找供应商前先定清楚：

- **人数和用量**：多少人、每周几次、每次预算多少
- **配送时间**：固定时间（如下午2点前送到）还是提前一天预约
- **形式**：整果还是切好的果盘（切果对冷链、卫生要求高很多）
- **预算区间**：比如人均5元、8元、15元，直接决定能选什么档次

这一步不清楚，后面比价没有意义。

## 二、供应商类型及适用场景

| 类型 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| 本地水果批发商/农批市场 | 价格低、品类全 | 配送和售后不稳定 | 量大、有专人对接 |
| 生鲜B2B平台（如美菜等） | 可开票、配送规范 | 品类受限、价格中等 | 中小公司常规采购 |
| 本地水果店/连锁 | 灵活、可小批量 | 单价偏高 | 人数少、频次低 |
| 专业企业下午茶服务商 | 省心、含果切 | 单价最高 | 预算充足、要省事 |

## 三、比价和筛选要点

1. **要报价单**：按品类单价+配送费，别只看总价
2. **问清损耗处理**：坏果、烂果是否包赔、怎么补
3. **试单**：先小批量订一次，看准时率、新鲜度、包装
4. **确认资质**：食品经营许可证、果切需冷链和卫生资质
5. **结算方式**：能否月结、开发票，这决定财务是否好处理

## 四、签约前必问的问题

- 临时加量/减量怎么处理？
- 节假日、恶劣天气能否保证配送？
- 出现品质问题多久内响应、如何补偿？
- 能否固定配送时段？

## 五、实用建议

- **不要只找一家**，备1家主供应商+1家备选
- **整果比果切更划算也更易配送**，除非有硬性需求
- **按周或按月签框架**，比单次采购更易拿到低价
- 首次合作**先试1-2周**再长期合作
