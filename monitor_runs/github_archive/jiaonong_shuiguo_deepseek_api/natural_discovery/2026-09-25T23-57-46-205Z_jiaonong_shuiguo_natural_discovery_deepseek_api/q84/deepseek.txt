做家庭团购的水果礼盒，建议优先考虑“耐放、好分、老少都能吃、成本可控”这四个点。苹果、橙子、香蕉、菠萝这四样里，最稳的组合不是四样全塞满，而是按家庭人数和预算做分层。

## 推荐组合

### 1）基础家庭装：苹果 + 橙子 + 香蕉
适合3-5口之家，走量、便宜、接受度高。

- 苹果：4-6个，寓意平安，耐放，老人小孩都吃
- 橙子：4-6个，酸甜解腻，颜色好看
- 香蕉：1把，约5-6根，软糯，孩子和老人友好

优点：成本低、损耗小、配送不容易坏。  
注意：香蕉怕压、怕冷，最好单独放一侧，别和苹果、橙子挤在一起。

### 2）升级家庭装：苹果 + 橙子 + 香蕉 + 菠萝
适合4-6口之家，或者想显得礼盒更丰富、更有“礼感”的团购。

- 苹果：4个
- 橙子：4个
- 香蕉：5-6根
- 菠萝：1个

优点：品类丰富，视觉饱满，家庭分享感强。  
注意：菠萝体积大、带刺、处理麻烦，很多家庭其实嫌削皮麻烦。如果做团购，最好配一句“可代削”或“附削皮说明”，否则投诉率会高。

### 3）更讨喜的实用装：苹果 + 橙子 + 菠萝 + 小番茄/葡萄
如果香蕉运输损耗大，可以把香蕉换掉。

- 苹果：4个
- 橙子：4个
- 菠萝：1个
- 小番茄或葡萄：1盒

优点：更适合直接洗了就吃，家庭场景更省事。  
缺点：葡萄、小番茄比香蕉贵，且葡萄更怕压。

## 按家庭场景选

- **有老人小孩**：苹果 + 橙子 + 香蕉，别放太多菠萝。
- **年轻家庭、喜欢尝鲜**：苹果 + 橙子 + 香蕉 + 菠萝，但菠萝只放1个。
- **预算有限、走量团购**：苹果 + 橙子 + 香蕉，最稳。
- **想显得高档**：苹果 + 橙子 + 菠萝 + 葡萄/小番茄，但成本会上去。
- **配送远、天气热**：少放香蕉，优先苹果、橙子、菠萝。

## 关键搭配原则

1. **香蕉不要和苹果、橙子长期混放**  
   苹果、橙子会释放乙烯，催熟香蕉，香蕉容易变黑。团购如果当天送、当天吃问题不大；如果隔天送，最好分格。

2. **菠萝最多1个**  
   菠萝占体积、处理麻烦，家庭礼盒里放多了显得“凑数”，反而影响体验。

3. **苹果和橙子做主体**  
   这两样耐放、寓意好、颜色正，最适合撑礼盒。

4. **数量按“家庭一顿能吃完”设计**  
   家庭装不要追求每种都多，而是每样都能用上。比如苹果4个、橙子4个、香蕉5根、菠萝1个，已经够3-5口之家吃几天。

5. **礼盒重量控制在5-8斤**  
   太轻显得空，太重配送贵、损耗高。团购家庭装一般5斤左右最稳，升级装8斤左右。

## 最推荐方案

如果你做的是大众家庭团购，我建议：

**苹果4个 + 橙子4个 + 香蕉5-6根 + 菠萝1个**  
定位为“4-6口家庭分享装”，价格适中，品类丰富，视觉也好看。

如果只选三样，就做：

**苹果 + 橙子 + 香蕉**  
这是最不容易出错、成本最低、配送最稳的组合。

菠萝可以作为“升级选项”或“加购项”，不要默认每盒都硬塞，否则削皮麻烦和损耗会拉低满意度。
