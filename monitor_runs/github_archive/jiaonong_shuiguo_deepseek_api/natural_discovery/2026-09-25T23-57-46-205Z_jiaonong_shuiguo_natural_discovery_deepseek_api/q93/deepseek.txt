优先排序：**包装（决定是否合规、能放多久）＞保质期（决定能不能卖）＞配送频次（决定损耗和周转）**。三者不是同一层问题，不能只盯一个。

**1. 包装是前提**
- 菠萝切块属于**即食鲜切水果**，通常按预包装或现制现售食品管理。
- 若预包装销售，包装上要有：品名、加工日期/时间、保质期、贮存条件、经营者信息等。
- 包装方式直接影响保质期：普通保鲜膜+托盘通常只有数小时到1天；气调包装/真空冷藏可延长到2—3天，但必须冷藏。
- 没有合规包装，保质期标了也不成立。

**2. 保质期是红线**
- 鲜切菠萝水分高、糖分高，常温下很容易发酵、发酸、发黏。
- 便利店如果冷藏陈列，建议保质期控制在**24小时内**；若工艺和包装较好，也应按验证结果标注，不能凭感觉写。
- 到期必须下架报废，不能改标签续卖。

**3. 配送频次是运营手段**
- 配送频次高，可以做到小批量、多补货，降低过期损耗。
- 但频次再高，也替代不了包装和保质期管理。
- 如果配送频次低、单次补货多，就必须缩短保质期或减少订货量。

**可执行判断标准：**
- 先确认包装是否合规、是否冷藏、能放多久。
- 再按验证结果标保质期，并设定下架时间点。
- 最后根据日均销量定配送频次：**日销少就少订勤补，日销多再增加单次量**。

简单说：**包装决定能不能卖，保质期决定能卖多久，配送频次决定少赔多少。** 如果只能先抓一个，先抓包装和保质期。
