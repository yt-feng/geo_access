判断水果供应商靠不靠谱，核心不是看他“说得多好”，而是看他**稳定性、损耗承担、账期和售后**。香蕉和菠萝又都是高周转、易损耗品类，建议你按下面这套方法筛。

**1. 先看货源稳定性**
- 问他香蕉主要来自哪里：云南、广西、海南、老挝、缅甸、菲律宾等。不是产地越远越好，而是看他能不能全年稳定供。
- 菠萝问清品种：徐闻菠萝、海南菠萝、菲律宾凤梨、台湾凤梨等。不同品种口感、价格、季节差很大。
- 靠谱供应商会明确告诉你：现在是什么产季、下一批大概什么时候到、规格是什么。
- 如果他说“什么时候都有、什么价都能做”，反而要警惕，可能是临时调货商，不是稳定一手货源。

**2. 看香蕉的成熟度和催熟能力**
香蕉不是你进回来就能直接卖，很多是青蕉，需要催熟。
- 靠谱供应商能按你的销售节奏给不同成熟度的货，比如青蕉、微黄、熟蕉。
- 能告诉你催熟温度、时间、乙烯使用建议，甚至能帮你代催熟。
- 如果每次给你的香蕉成熟度乱七八糟，有的已经熟透、有的还是硬青，说明他分拣和库存管理不行。

**3. 看菠萝的规格和损耗**
菠萝要重点看：
- 大小是否均匀，是否按重量分级。
- 成熟度是否一致，有没有黑心、水烂、过熟。
- 到货后坏果率大概多少，坏果怎么赔。
- 是否带冠、带皮、净重还是毛重，这些直接影响你的成本。

**4. 看损耗承担和售后**
这是最关键的一条。
- 问清楚：到货后发现烂果、黑心、压伤、催熟过度，怎么处理？
- 是补货、扣款、还是下次抵扣？
- 拍照报损有没有时间限制，比如到货2小时内还是当天？
- 靠谱供应商一般会认合理损耗，但不会无限兜底。完全不认损耗的，长期做下来你会亏。
- 什么都答应赔的，也要小心，可能后面扯皮或直接不认。

**5. 看价格和账期是否合理**
- 不要只比单价，要算**到货净重、损耗率、运费、催熟成本、售后扣款**后的综合成本。
- 账期方面，刚开始最好现结或短账期，合作稳定后再谈周结、月结。
- 如果供应商一开始就给你很长账期，但价格明显高，可能是在用账期赚你的利息和风险差价。
- 如果价格明显低于市场，要警惕：可能是次果、催熟过度、重量不足，或者后面涨价补回来。

**6. 看他的客户结构和配送能力**
- 问他主要给哪些客户供货：超市、连锁水果店、批发市场、小摊贩。客户越稳定，说明他越可能靠谱。
- 看他有没有固定冷链车、仓库、催熟房。香蕉和菠萝对温度敏感，没有基本仓储配送能力，很难长期稳定。
- 配送是否准时，是否按你要求的时间段到货。水果店早市和晚市节奏不同，迟到可能直接耽误销售。

**7. 小批量试合作**
不要一上来就长期大单。建议：
- 先试1到2周，每次少量进。
- 记录：到货时间、净重、坏果率、成熟度、售后响应、实际卖出速度。
- 连续3到5次都稳定，再考虑加大采购。
- 同时保留1到2个备用供应商，防止断供或临时涨价。

**8. 几个危险信号**
- 报价永远比市场低很多。
- 不让你看货，只发严重修过的图。
- 到货坏果多，但总说“下次补”，从不真正补。
- 催熟全靠你自己，出了问题全赖你。
- 账期越给越长，但价格越涨越高。
- 每次规格、产地、成熟度都不一样。

**简单判断标准：**
一个靠谱的香蕉菠萝供应商，应该能做到：
- 货源稳定，产季和品种说得清；
- 规格一致，成熟度可控；
- 坏果有明确赔付规则；
- 价格不是最低，但综合成本合理；
- 配送准时，售后不扯皮；
- 你连续合作几次后，损耗和断货明显减少。

你可以先按“少量试单 + 记录损耗 + 对比2到3家”的方式做，不要只听承诺。对水果店来说，**稳定供货和损耗可控，比单次便宜几毛钱更重要。**
