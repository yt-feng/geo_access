针对长期合作的水果供应商，我的核心建议是：**优先谈“售后”，其次谈“账期”，最后谈“配送”**。

原因很简单：水果是生鲜，损耗大、品质波动快。售后条款直接决定你能否“止损”，账期决定你的现金流，而配送在长期合作中差异最小（因为可以标准化）。具体分析如下：

**1. 售后（最优先，决定生死）**
水果生意最大的风险不是卖不动，而是“坏在手里”。你需要重点明确三个条款：
- **到货损耗率**：比如规定“到货后48小时内，非人为损坏的损耗率超过5%的部分，由供应商全额赔偿”或“按比例补货”。
- **品质标准**：写清楚“果径大小、甜度、外观瑕疵”的具体标准（如“A级果，单果重XX克”），避免口头约定。
- **坏果处理方式**：是“拍照秒赔”、“下次抵扣”还是“立即补发”？明确时限（如24小时内响应）。

**2. 账期（次优先，决定活下去）**
账期直接影响你的资金压力，但谈判空间相对灵活：
- **目标**：争取“月结30天”或“首批货到付款，后续月结45天”。
- **策略**：如果对方要求现结，可以用“提高订货量”或“签订年度框架合同”换取账期延长。**注意**：账期越长，价格通常越高（相当于利息），所以账期谈判的核心是寻找“资金成本”和“价格”的平衡点。

**3. 配送（最后谈，因为可替代性最强）**
配送频率、准时率当然重要，但它是**最容易标准化**的环节：
- **要求**：明确“下单后24小时内送达”、“冷链车运输”、“到货时间误差不超过2小时”。
- **为什么放最后**：因为如果你售后条款谈得好（损耗归供应商），供应商为了减少自己的赔偿，自然会主动优化配送速度，否则赔钱的是他们自己。所以配送可以作为“配合项”而非“核心筹码”。

---

**实战谈判顺序建议：**
1. **先谈售后**（用“我们会长期稳定订货”作为筹码，要求高品质赔付标准）。
2. **再谈账期**（用“售后保障”敲定后，再谈付款周期）。
3. **最后确认配送**（作为附带条款写进合同，强调“因配送延误导致的损耗由对方承担”）。

**一句话总结：** 把风险（损耗）和资金（账期）的控制权握在手里，配送交给供应商内卷。
