是的，**起订量太高会增加损耗风险**，而且这种风险在水果（尤其是香蕉和菠萝）采购中尤为突出。  

具体来说，风险主要体现在以下几个方面：  

1. **库存积压**：起订量高意味着一次性购入量大，如果需求预测不准或销售速度慢，库存积压会导致商品存放时间过长。  
2. **保鲜期短**：香蕉和菠萝都是呼吸跃变型水果，采摘后仍会继续成熟，存放时间有限。香蕉一般在成熟后3-7天内品质下降，菠萝虽稍耐放，但切开后极易变质。  
3. **物理损伤**：大量采购往往涉及运输、搬运，箱内挤压、碰撞可能造成表皮破损，破损处易滋生细菌，加速腐败。  
4. **冷库依赖**：若无法在短期内售出，必须依赖冷链存储，但即使冷藏，长时间存放也会影响口感和风味（如香蕉皮变黑、菠萝酸度失衡）。  
5. **资金占用**：高起订量意味着前期资金投入大，若损耗高，利润率被吞噬，甚至可能亏损。  

**建议的应对策略**：  
- 优先选择起订量灵活、可分批配送的供应商（如按日/按周小批量补货）。  
- 与供应商协商“阶梯起订量”或“试用期小批量”，实测销售周转率后再扩大采购。  
- 建立可靠的销量预测机制（最好基于历史数据或当前促销计划），避免盲目压货。  
- 如果必须大批量采购，可考虑与隔壁店铺或有需求的客户拼单，分摊库存压力。  

总结：**起订量应基于实际周转能力，而非“便宜”或“供应商要求”**，否则损耗风险会显著上升。建议你在谈判时优先确保灵活性。
