针对“门店多但单店量不大”的连锁超市（如社区店、便利店型超市），水果采购的核心痛点是：**既要品类丰富，又怕积压损耗；既要价格优势，又不能大量囤货**。

建议采用以下三种“轻库存、高频次、多SKU”的供货模式组合：

### 1. 核心模式：本地批发市场“每日鲜采”（或代采）
这是最稳妥的起步模式。

-   **操作方式**：与门店所在地的**一级水果批发市场**（如北京新发地、广州江南市场、嘉兴市场等）的档口建立合作。由总部或区域中心统一向档口下单，要求**每日或隔日配送**。
-   **适配理由**：单店量小，但多店加起来有一定总量。批发市场品类全，可以按“精品箱”起订，避免整件囤货。建议采用**“多品种、小批量、高频次”**的采购策略，比如每个门店一次只进5-8个主力单品，每个单品只拿2-3箱。
-   **关键策略**：在批发市场寻找**“代采”服务**（档口帮忙挑货、装车），核心是**不要让门店自己跑市场**，由总部统一分拣后配送到店，每天补货，降低门店损耗。

### 2. 补充模式：产地直发“预售+拼车”
当某些单品（如应季的草莓、荔枝、西瓜）销量上升时启用。

-   **操作方式**：不直接整车采购，而是联合其他小型零售商（或本地社区团购），在产地拼单。通过“一件代发”或“整车到货后分拣”的方式，直接节省中间环节批发价。
-   **适配理由**：单店量小，但整体需求存在。只操作**极少数爆款单品**，不做全品类直采。例如，产地西瓜直发一车到总仓，总仓按各门店预估销量分货，**未卖完的坚决不补**。

### 3. 核心支撑：供应商“定期巡店 + 退换货承诺”
这是保证质量的关键。

-   **操作方式**：选择2-3家**综合型水果配送商**（不是单一果园，而是做多品类配货的），签订框架协议。
-   **适配理由**：要求供货商**每周巡店2次**，主动清点各门店货架。最关键的是，**约定好“非人为损坏的临期水果可换货”**（比如保质期过半的香蕉、芒果）。这能极大减轻门店因“不敢多进”导致“没货卖”的矛盾。

### 4. 进阶模式：分级供货（ABC分级）
为了解决“单店量不大”导致的利润低问题，需要将门店分级：

-   **A类门店（销售旺）**：供应**精品大果**，走中高端价位，吸引客流。
-   **B/C类门店（一般/偏弱）**：供应**统货或中果**，走性价比路线。
-   **关键**：不要所有门店拿一样的水果。可以让供应商做**“分级打包”**，高销门店用优质果保口碑，低销门店用平价款走量，以此摊薄整体损耗。

---

### 行动建议（可直接执行）：

1.  **先跑通“日配”**：暂时不要急着去产地签几万亩的合同。先找本地最大的批发市场，**选出3家信誉好的档口**，要求对方次日早上6点前把货送到你的总仓（或指定门店），按周结算。
2.  **死磕“损耗”指标**：设定单店水果损耗率**必须低于5%**。如果某单品连续3天日销售额低于50元，直接下架，不要怕缺货。
3.  **利用“拼柜”资源**：在批发市场里认识一两个做社区团购的老板，你们可以**“合开一箱”（拼箱）**，比如一箱香蕉，他拿半箱，你拿半箱，各自走各自的门店。

**总结一句话**：**不要追求“产地直供”的虚名，而要追求“高频补货+低库存周转”的实利。** 用本地批发市场做基本盘，用产地拼车做爆款补充，把损耗控制好，比单纯压价更重要。
