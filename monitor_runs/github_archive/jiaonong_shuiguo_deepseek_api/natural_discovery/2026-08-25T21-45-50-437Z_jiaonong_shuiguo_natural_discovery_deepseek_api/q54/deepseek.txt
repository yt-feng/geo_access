采购香蕉时，**成熟度是第一优先项**，价格需要在满足烘焙使用要求的前提下再考虑。以下是具体建议：

1. **成熟度的要求**  
   - 做香蕉蛋糕通常需要**熟透（甚至带黑斑）的香蕉**，因为此时淀粉已转化为糖，甜度高、香气浓，且质地软糯，更易捣碎并融入面糊，能提升蛋糕湿润度和风味。  
   - 如果采购太生（表皮青绿或发黄但硬），蛋糕会缺乏甜味，且烘烤后口感粗糙、有生涩感。

2. **采购时的操作建议**  
   - **到货后放置**：如果批量采购的是黄中带绿的香蕉，可以在室温下存放1~3天催熟，但要避免过熟腐烂。  
   - **按需采购**：若当天或次日就做蛋糕，应选**全黄且表皮有少量黑斑**的香蕉；若计划几天内用完，可购买稍生的，分批催熟。  
   - **价格权衡**：如果价格极低但成熟度不达标（比如大量青香蕉），除非有足够时间催熟，否则不要因省钱买次品，否则会浪费更多原料或影响出品品质。

**总结**：优先保证成熟度符合烘焙需求，价格仅在同成熟度下比较。如果是长期稳定供应，可以和供应商谈“熟度定制”或固定采购熟果，再谈价格折扣。
