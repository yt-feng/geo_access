在挑选和经营超市菠萝时，**应该以“切果损耗”为首要核心关注点**，同时兼顾甜度和外观，大小作为参考。

以下是具体分析和优先级建议：

**1. 首要关注：切果损耗（直接影响利润）**
- **为什么最重要**：菠萝的销售很大一部分是现场切果（或预切盒装）。损耗率直接决定毛利率。如果菠萝皮厚、果眼深、内部腐烂率高（黑心/水心），即使甜度高、外观好，切出来可售果肉少，利润也会被吞掉。
- **怎么判断**：
  - 轻敲听声音（沉闷厚实为佳，空洞声可能空心或过熟）。
  - 按压果身（微软有弹性为宜，过硬可能未熟，过软易烂）。
  - 检查底部切口（新鲜湿润无霉变，有霉斑黑点的损耗大）。
  - 试切样品，计算“切出果肉重量/原果重量”，正常可售率约在55%-65%。

**2. 其次关注：甜度（决定复购率）**
- 甜度不够，顾客尝过不买，会积压成损耗。甜度可以通过**果香**（浓郁清甜香）和**底部糖度计抽查**（可选）来判断。
- 优先选“金钻”（台农17号）等甜度高的品种，尤其应季时（3-5月更甜）。

**3. 再次关注：外观（影响第一印象）**
- 外观**不是**越漂亮越好。要选**果形圆润、芽眼少而浅**的（切起来损耗小），颜色橙黄均匀（带少量青绿可后熟，全青太生）。
- 避免：表皮发黑、有软烂斑、长霉的（内部大概率坏）。

**4. 最后参考：大小**
- 大小不是绝对标准，但**中等偏大（1-1.5kg）**的通常果肉密度更好，且切盒分量更容易定价（比过小的划算，比过大的好卖）。
- 过小的菠萝可能皮厚肉少，过大的可能空心，所以要结合敲打判断。

---

**经营建议总结（可执行）**：
- **做一次“损耗测试”**：进一批不同产区或批次的菠萝，各切5个，记录可售果肉比例、甜度Brix值、次品率，用数据选品。
- **销售策略**：对损耗高的批次，建议**按整个出售**而非切果；损耗低的批次，主推切果盒装，单价更高。
- **到货后处理**：先放常温后熟12-24小时再切，可降低生切损耗。

如果只选一个指标做为进货决策，请务必选**切果损耗**，因为这是能否赚钱的关键。
