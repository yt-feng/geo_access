和酒店供应商谈水果长期合作时，关键要围绕 **“品质稳定性、价格合理性、供应弹性、风险兜底”** 四个维度来谈。以下是一份可直接使用的谈判要点清单：

### 一、核心合同条款（最优先谈）
1. **品质标准白纸黑字**
   - 要求供应商提供 **“供应标准规格书”**（如芒果≥M级、蓝莓果径≥12mm），并附图片对比。
   - 明确**残次率**：比如到货破损率≤3%，超出部分无条件补货或按当日批发价退款。
2. **价格锁定机制**
   - 不要只谈“批发价”，要谈**“周期定价”**：淡/旺季价格波动区间（比如±10%），并约定**价格复议周期**（如每两周一次，以市场调研价为准）。
   - 明确**报价含税、含运费、含损耗**，防止隐形费用。

### 二、供应稳定与弹性（最容易踩坑）
3. **异常天气/节庆预案**
   - 要求供应商提供**“缺货替代方案”**（如西瓜缺货时换哈密瓜，且价格按当期价）。
   - 明确**最低供货量**和**最大应急量**（比如日常100kg，节假日高峰可提供160kg，需提前48小时通知）。
4. **到货时效与违约赔付**
   - 写明“每日/每周到货时间”（如早上6:30前），供应商迟到1小时赔偿当日订单金额的20%。
   - **现场验收权**：酒店可开箱抽检，不合格全批退回，且供应商需承担因此造成的早餐停摆损失（此为谈判底线）。

### 三、品控与冷链（专业度区分度）
5. **冷链溯源要求**
   - 要求提供**车辆温度记录**，并允许你方不定期跟车抽检。
   - 问清“采摘到送货时长”，一般水果D+1到货（不超过24小时）最佳，超时需备注。
6. **农药残留检测**
   - 要求每批次提供**第三方检测报告**（重点查农残、重金属），费用可双方分摊，但必须有文件。

### 四、账期与付款（保护现金流）
7. **账期谈判**
   - 首次合作可先提**月结（30天）**，若对方要求现结，可要求折让（现金价降低2%）。
   - 约定**对账日**（如每月25日），超过对账期未对账，以你方数据为准。
8. **连带责任**
   - 若供应商因资质造假（如产地伪造）导致酒店被投诉，供应商需承担60%以上赔偿。

### 五、谈判中的实际话术示例
- **压价时**：“我们酒店早餐出品质，需要的是长期稳定，你报市场波动价我很难向总厨交代。不如我们锁定一个中位价，我给你保住每周固定订单量（如500kg），你看行吗？”
- **谈品质时**：“你送来的货我可以免检，但如果被我发现两次以次充好，我们立刻终止合作，并且我还会在酒店圈子里如实反馈，你想清楚。”

### 六、必避开的坑
- ❌ **不谈“不可抗力条款”**：必须写明“若因台风等不可抗力缺货，需提前24小时通知并提供可替代果品，否则视同违约”。
- ❌ **只看价格不看净出肉率**：比如菠萝、榴莲，要看果肉厚度，最好按“净果肉克数”计价，而不是按“颗数”。
- ❌ **不限定产地**：写明“指定产区”（如海南三亚芒果），防止供应商用次产区以次充好。

### 七、后续管理提醒
签合同前**先试供2周**（小批量），实际测试配送、品质、服务响应速度，再签长期合同。并在合同中写明“试用期合同可随时终止，无需违约金”。
