针对餐饮连锁采购水果，**建议采用“中央厨房统一收货 + 门店二次分拣配送”的模式，但需根据水果品类做差异化调整**。以下是具体分析和执行建议：

### 一、为什么优先推荐中央厨房统一收货？
1. **品质把控更严格**  
   - 水果损耗率高，中央厨房可安排专人按标准（甜度、大小、外观、农残检测）逐批验收，不合格直接退换货，避免门店直接收劣果。
   - 可建立溯源台账，统一处理售后，减少门店与供应商扯皮。

2. **采购成本优势**  
   - 批量采购议价能力强，减少多次运输的物流费和门店零星采购的管理成本。

3. **库存和损耗可控**  
   - 中央厨房按需分拣打包（如切配盒装果切），标准化后门店拆包即用，避免门店各自囤积造成积压腐烂。

4. **食品安全责任集中**  
   - 农药残留检测、冷链温度记录等集中在中央厨房完成，一旦出问题责任清晰，降低连锁品牌风险。

---

### 二、必须注意的“反例”与调整方案
**不要“一刀切”，以下情况建议门店直接收货或部分直送：**

| 情况 | 建议 | 原因 |
|------|------|------|
| **距离中央厨房过远（>2小时车程）** | 门店直收短保水果（如草莓、蓝莓） | 避免二次运输损耗，缩短到店时间 |
| **水果保鲜期极短（<24小时）** | 供应商直送门店 | 如鲜荔枝、山竹，中央厨房停留会增加损耗 |
| **门店销量大且具备储存条件** | 部分干果、柑橘类可门店自收 | 减轻中央厨房分拣压力，但需门店严格验收 |

---

### 三、落地执行要点（关键）
1. **制定中央厨房验收标准**：  
   - 明确不同水果的糖度（如西瓜≥11°）、硬度、破损率（≤3%）等硬指标，拍照留档。

2. **建立“店退”机制**：  
   - 中央厨房发货前做好分拣，但允许门店在收货后2小时内报告未拆封的不良品，由总部承担损耗，避免门店隐瞒或浪费。

3. **小批量快周转**：  
   - 中央厨房不要加工过多果切，按当日门店预估订单分装，每日上午和下午分两批配送（冷链车），确保新鲜。

4. **数字化订单系统**：  
   - 门店提前一天在系统报需求量，中央厨房按量采购，避免盲目囤货。

---

### 四、最终建议
**结论**：  
- **标准水果（苹果、橙、梨等）** → 中央厨房统收统配。  
- **高损耗短保水果（叶菜、浆果、热带水果）** → 供应商直送门店，但需总部审核供应商资质。

**执行优先级**：先统一收货试运行1个月，对比损耗率和客诉数据；若损耗率超过8%，再对特定品类改为直送。这样既能控制成本，又兼顾新鲜度。
