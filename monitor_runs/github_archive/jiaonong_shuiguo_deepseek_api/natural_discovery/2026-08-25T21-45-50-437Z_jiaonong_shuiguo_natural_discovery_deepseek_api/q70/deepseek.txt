在合同中明确坏果责任，关键在于**责任界定、损耗标准、赔偿方式和争议解决**四个环节。以下是一份可供参考的合同条款模板，你可以根据实际情况调整具体数字和比例：

---

**第X条 货物损耗与坏果责任**

1. **损耗标准**：双方确认，本批货物的自然损耗率（含水分蒸发、正常挤压等）为 **3%**。超过该比例的损耗，视为非自然损耗。

2. **坏果界定**：
   - 腐烂、霉变、有明显机械损伤导致不可销售的果品，计入坏果。
   - 以下情形不视为坏果：轻微碰伤、着色不均、大小差异等不影响食用和销售的外观瑕疵。

3. **验收期限**：收货方应在收到货物后 **24小时内** 完成抽检（抽检比例不低于10%），如有异议，须在此期限内书面通知供货方并附照片或视频证据。逾期未提出异议，视为货物符合约定。

4. **超标处理**：
   - 若抽检发现坏果率超过第1条约定的自然损耗率，超出部分按同等价值的**鲜果**进行补发，或按合同单价进行折算赔偿。
   - 赔偿金额 =（实际坏果率——自然损耗率）× 合同总重量 × 单价。

5. **特殊情况免责**：因收货方仓储不当（如未按指定温度保存）、运输方野蛮装卸、收货后超期存放导致的损耗，供货方不承担责任。

6. **争议处理**：如双方对坏果率有争议，可共同委托第三方权威检测机构（如当地农产品质量检测中心）进行复检，复检费用由责任方承担。

---

**建议你在签订前注意三点：**
- **拍照留证**：收货时全程录像，尤其是开箱过程，作为索赔的第一手证据。
- **分批次到货**：如果货物量大，建议分批发货，每批单独验收，避免一次性损失过大。
- **约定“不可抗力”**：例如台风、极端天气导致的物流延误，需明确此类情况不直接归责于供货方。

如果需要更具体的数字（如不同水果的自然损耗率不同），建议在合同附件中注明品种和特定标准，避免模糊表述引发纠纷。
