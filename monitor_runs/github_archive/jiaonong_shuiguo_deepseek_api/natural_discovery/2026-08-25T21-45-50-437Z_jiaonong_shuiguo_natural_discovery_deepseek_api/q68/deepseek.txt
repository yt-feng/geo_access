判断水果批发商（尤其是香蕉）供应商能否按时到车，**核心不能只看口头发票，要看“可验证的物流动作”和“库存/装货安排”**。香蕉是熟度敏感品，到货时间直接影响损耗。

以下是可直接执行的6个判断标准，按紧急程度排序：

**1. 直接索要“装车照片/视频”（最快捷）**
- **问法**：“兄弟，现在冷柜在哪个冷库装？拍个装车到一半的视频给我，我看下把头和码数。”
- **判断点**：
  - 如果**已经开始装货**，视频里应能看到**叉车、正在堆叠的香蕉箱、车厢里的预冷状态**——证明有实际行动。
  - 如果对方拖延或只发“正在联系”“马上就好”，大概率车还没装。
  - **注意**：要求视频看**车头车牌号**，防止拿别人的视频充数。

**2. 核实“车牌号 + 司机电话 + 发车定位”三件套**
- **必须拿到**：车牌号、司机手机号、司机当前**GPS定位截图**（微信发实时位置）。
- **判断点**：
  - 如果到约定时间（比如下午5点发车），直接**打司机电话**，问“你现在到哪了？从哪个市场发的？”——司机通常比老板更实在。
  - 让司机发**实时共享位置**，如果位置在产区冷库附近且持续向你的城市移动，基本靠谱。
  - 若司机电话不通或含糊其辞，说明车还没动。

**3. 核查“冷库装货单/磅单”**
- **买香蕉必看**：要供应商发**冷库装车磅单**（带有仓库名称、日期、件数、皮重）。
- **判断点**：
  - 如果磅单日期是当天的，且重量接近约定吨位（比如订10吨，磅单显示9.8吨），说明货已装好。
  - 如果磅单是昨天或前天的，说明他可能在“拼车”或“找货”拖延，到你市场的时间必然延后。

**4. 问清“报备情况”**
- **问法**：“你这车货今天报备市场了吗？报备编号是多少？”
- **判断点**：
  - 大部分水果批发市场需要供应商提前报备（尤其是香蕉需要冷柜检疫）。能报出编号的，说明已走完手续；报不出说明还在流程中，大概率会晚。

**5. 对比“历史准时率”**
- **最简单**：回忆或记录他过去3次送货时间。
  - 如果过去2次都准时，这次只要物流信息对得上，可放心。
  - 如果过去就常迟到，这次哪怕说“马上到”，也要做好延迟预案（比如提前联系其他备选供应商）。

**6. 设置“最后确认时间”**
- **给供应商定节点**：“下午3点前，把装好车的视频和司机定位发我，过了3点我就当你不来了，另找别家。”
- **判断点**：真正有货的供应商，为了留住订单，会在半小时内发来；没货的会各种借口。

---

**特别提醒（香蕉行业特性）**：
- **熟度不可逆**：如果供应商说“车在路上堵了”，但连续3小时没有移动定位，大概率是**货还没从树上采**，临时装是来不及的。
- **装车时间参考**：一车9.6米冷柜装香蕉，正常需要**2.5-3小时**，如果他说“马上装好”但视频里货还是散的，基本是骗你。

**最终建议**：做香蕉批发，**“到货准时”比“价格便宜”更重要**。如果连续两次不准时，宁可多花2毛/斤找稳定的供应商，别被低价套牢。出发前1天（比如晚上）再确认一次司机定位，比当天早上等更稳妥。
