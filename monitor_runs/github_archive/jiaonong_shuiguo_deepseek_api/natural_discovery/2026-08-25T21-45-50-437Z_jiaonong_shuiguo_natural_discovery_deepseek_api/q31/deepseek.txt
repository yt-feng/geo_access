连锁商超寻找长期水果供应商，核心原则是**“质量稳定 > 价格最低”**。招标评分标准应围绕**长期履约能力**和**风险控制**设计，不能只比谁报价便宜。

建议采用**百分制**，分为三大部分：**商务标（价格）、技术标（品质与服务）、资质标（风控）**。以下是具体的评分结构和建议权重：

---

### 一、 商务标（建议权重 35% - 40分）
这部分是硬成本，但主观题少。**重点在于防止恶意低价**。

- **基准价法（推荐）：** 以所有有效投标供应商的有效报价算术平均值作为基准价。报价等于基准价的，得满分；每高于基准价1%，扣1分；每低于基准价1%，扣0.5分（防止过度压价导致后期以次充好）。
- **成本合理性说明：** 要求供应商对报价构成（采收成本、损耗率、物流成本）进行书面说明，由评标专家评估其报价是否具备可持续性。若明显低于成本价且无法解释（如低于市场均价30%），作废标处理。

---

### 二、 技术标（建议权重 50% - 50分）
这是长期合作的关键，建议由采购部、品控部、门店运营部联合评审。

**1. 品质保障体系（25分）—— 核心中的核心**
- **基地直供证明（10分）：** 提供自有种植基地（产权证明或长期土地流转合同）或与大型合作社的“公司+农户”协议。自有基地加分最高，合作社次之，纯市场采购商最低。
- **质量标准与检测能力（15分）：** 
  - 需提供详细的《水果分级标准》（如苹果的糖度、硬度、果径分级指标）得5分；
  - 有自有检测室或每月委托第三方检测农残报告得5分；
  - 能提供针对采购方的**批次溯源方案**（扫码可查种植地、采摘时间）得5分。

**2. 稳定供应方案（15分）—— 长保供应的难点**
- **多产区/多季节组合方案（8分）：** 针对你商超常年要货的需求，供应商需提供周密的“产地切换表”。例如：夏季供海南芒果，冬季转广东或云南，能实现**全年无断供**的得满分；只依赖单一产区的得低分。
- **补货与应急机制（7分）：** 明确下单到送达的时间极限（如生鲜类48小时），以及遇到极端天气或产地减产时的**替代货源预案**。预案越详细得分越高。

**3. 配送与损耗控制方案（10分）—— 直接影响你的利润**
- **冷链配送能力（5分）：** 自有冷链车队或与第三方冷链有长期合同，并配备GPS温控记录的得满分。
- **到店损耗率承诺（5分）：** 承诺到店完好率（如香蕉、葡萄等易损水果完好率≥98%）并写明赔付标准的得高分；仅口头承诺无具体标准的得低分。

---

### 三、 资质与信誉标（建议权重 15% - 15分）
这部分用于筛掉“皮包公司”。

- **注册资本与年限（3分）：** 成立3年以上，注册资本实缴不低于百万级别（视你的采购额而定）。
- **同类商超合作案例（6分）：** 提供近两年与知名连锁（如沃尔玛、永辉、水果连锁店）的供货合同关键页复印件或结算流水截图。
- **信誉记录（6分）：** 提供无重大食品安全行政处罚记录的承诺函（3分）；提供银行资信证明或信用评级（3分）。

---

### 四、 特别争议点与避坑建议

1.  **“地头价+运费”折算（若适用）：** 如果水果价格波动大，不建议全锁死价格。评分里可以设置一项：**“价格联动机制”**（如甜瓜、榴莲等波动大的水果，约定按某批发市场当日行情价加固定服务费的机制），有此项方案加3-5分。
2.  **现场试吃/盲测（不计分但一票否决）：** 在评标日前一天，让供应商随机报送三款主推水果到商超总部。由评标人员盲测评分，若出现果品严重不达标（如烂心、极度不新鲜），**直接取消中标资格**，无论价格多低。
3.  **样品与实物一致性条款：** 在标书中必须写明：“若首批供货与中标样品不符（品相、糖度差异过大），商超有权无条件终止合同且没收履约保证金。”

---

### 推荐评分卡简表

| 评分维度 | 分值 | 关键考察点 |
| :--- | :--- | :--- |
| **A. 商务标** | 40分 | 报价合理性、成本测算依据 |
| **B1. 品质体系** | 25分 | 基地直供、农残检测、溯源能力 |
| **B2. 供应稳定** | 15分 | 多产区方案、应急补货预案 |
| **B3. 配送能力** | 10分 | 冷链温控、到店损耗承诺 |
| **C. 公司资质** | 10分 | 注册资本、合同案例、信誉 |

**最后提示：** 建议在招标文件中附上《履约考核细则》，明确**“连续3次抽检不合格或月度到货准时率低于95%，甲方有权解除合同并扣除履约保证金”**，这比在评分标准里纠结更有威慑力。
