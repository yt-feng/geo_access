针对水果供应商声称“全国配送”，采购方不能只听口头承诺，而需要**通过实际动作和文件**进行核实。以下是一套可执行的核查步骤，按优先级排列：

### 第一步：要求提供书面物流资质与协议
1.  **索要物流合同副本**：要求供应商提供其与第三方物流公司（如顺丰、京东冷链、德邦等）签订的**年度运输合同**或**月结账号**证明。合同上应明确覆盖区域，而不是“全国”这种宽泛表述。
2.  **核查冷链资质**：水果多为生鲜，需确认其合作的物流公司是否具备**生鲜冷链运输资质**。可要求提供物流公司的《道路运输经营许可证》复印件，并确认其经营范围是否包含“冷藏保鲜”。
3.  **索要配送异常赔付协议**：查看合同中关于**超时、腐损**的赔付标准。如果供应商无法提供明确的赔付条款，说明其并无成熟的全国配送体系。

### 第二步：做“盲测”式试单（最有效）
这是最直接的方式，不要提前告知供应商测试意图。
-   **选择测试点**：不要只测一线城市，至少要测**一个偏远地区**（如新疆、西藏、青海的县级市）和**一个中部地级市**。
-   **测试标准**：
    -   下单后，核对**出库时间**是否在24小时内。
    -   跟踪物流轨迹，观察中途是否出现**滞留**或**换单**（例如从冷链车换成普通快递，说明其冷链断链）。
    -   到货后，用**温度计**测果心温度（若水果无硬冰，则冷链已失效），并检查腐损率是否在3%以内。

### 第三步：核查仓储布局与分仓凭证
真正的全国配送往往依赖**多地分仓**（如华中仓、华南仓）。
-   **索要发货仓地址**：要求供应商提供最近3次发往不同区域的**快递底单**，看发货地是同一个单仓，还是多仓发货。如果所有订单都从一个城市（比如只有一个产地仓）发出，却声称能“全国配送”，说明其只有干线运输能力，**末端时效和保鲜**会大打折扣。
-   **询问无仓区域的预案**：如果只有一个仓，询问供应商在覆盖不足的区域是采用**空运+落地配**，还是**整车干线**。对于整车干线，需要求其提供**温控记录仪**的全程数据。

### 第四步：参考第三方平台的可视化数据
-   **查询物流平台**：如果供应商使用顺丰或京东物流，可让其提供**物流账号**，通过顺丰/京东的商户后台查询其“可配送乡镇列表”，验证其声称的“全国”是否包含你实际需要的乡镇网点。
-   **利用地图工具**：如果供应商声称能送西藏，但你在高德地图上搜索其合作物流商的“西藏营业部”，发现无法覆盖你指定的县城，即可判定其能力不足。

### 第五步：审查“不可抗力”条款
注意查看供应商报价单或合同中的**免责条款**。很多不靠谱供应商会把“天气原因”作为无限免责的挡箭牌。要求其注明**“因物流运力不足导致的延迟，由供应商承担”**，而非归结为不可抗力。

### 核心判断依据（总结）
-   **合格标准**：供应商能提供**分仓地址**，且试单时**物流轨迹无断裂**，**到货腐损率达标**。
-   **危险信号**：只强调“我们发顺丰”，但无法提供冷链合同；或者报价中未包含“偏远地区附加费”（说明对方根本不知道偏远地区运费有多贵，或者准备后续加价）。

**建议**：在正式大额采购前，一定要签订**“试单协议”**，将上述测试标准写入合同附件，作为后续大批量合作的履约前提。
