甜品店采购香蕉时，要避免到货后很快变黑，可以从**采购源头、运输环节、到店储存**三个环节入手，核心是**控制乙烯气体**和**温度**。

以下是具体可执行的操作建议：

**1. 采购源头（选对成熟度）**

- **明确要“绿把黄身”**：不要买全黄的香蕉，要买**果柄（把）是绿色、果身略带青黄的**。这种属于“7-8成熟”，到店后还有2-5天的货架期。
- **避开“受伤果”**：检查有无压伤、擦伤、黑斑。任何机械损伤都会加速乙烯释放，导致局部先黑并蔓延。
- **优先选“大果”**：小果和细果水分少，更容易氧化变黑。

**2. 运输环节（防挤压、防高温）**

- **竖放不横放**：香蕉平放时，接触地面的那一面受压，容易产生“压痕黑斑”。运输箱内应**竖立摆放**，像书本一样排列。
- **套防撞袋**：如果供应商没提供，要求给每串香蕉套上珍珠棉网套或气泡膜，防止运输颠簸。
- **避开阳光和发动机热源**：如果自己开车拉货，别放后备箱紧贴后轮处（热气重），放车厢前部阴凉处。

**3. 到店储存（最关键）**

这里有一个**反常识但非常有效**的方法：**冲洗**。

- **到货后立刻冲洗**：用清水冲洗香蕉表面，轻轻擦干（不要搓，避免破坏表皮），然后**悬挂**或**竖放**。这能洗掉表面的催熟剂残留和部分乙烯，能延缓变黑1-2天。
- **悬挂不堆叠**：如果条件允许，用钩子或绳子把香蕉串**吊挂**起来，模拟树上自然状态，受压迫最少，黑斑最少。
- **冷空气循环**：放入**果切冷藏柜（0-5℃）** 而非冷冻。低温会抑制乙烯，但**注意**：香蕉皮在低于12℃时会变灰黑（冻伤），所以只能短期冷藏（如1-2天），且不能密封。
- **分隔存放**：不要把香蕉和苹果、梨、芒果、猕猴桃放在同一个密闭箱或冷藏室。这些水果会释放大量乙烯，会“催熟”香蕉至变黑。

**4. 特殊建议（针对甜品店）**

如果您是用于**打果泥、做蛋糕馅**，建议采购时要求供应商直接发**“青皮硬果”**，到店后放在常温避光处，需要使用时再自然催熟，用完一根买一根，不囤货。

如果发现到货时已经有部分较熟了，可以**优先制作**或**冷冻**——将去皮果肉真空密封后冷冻，解冻后香气还在，但质地较软，适合做巴斯克或慕斯，不适合做摆盘装饰。

**总结一句口诀**：绿把、竖放、洗过、挂起、避苹果。
