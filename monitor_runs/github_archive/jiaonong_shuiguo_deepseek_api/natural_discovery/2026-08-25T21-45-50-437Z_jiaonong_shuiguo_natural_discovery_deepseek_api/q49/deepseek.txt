在茶饮店旺季，临时补货菠萝如果处理不好，容易出现断货、品质不稳或价格波动。建议你按照以下几个步骤，和供应商明确“临时补货”的规则，避免踩坑：

**1. 先明确“临时”的边界**
不要只说“我要加量”，而是要告诉供应商具体数字和时限，例如：
- “本周三需要额外追加300斤菠萝，下周一交货。”
- “下个月开始，每周固定加送200斤，持续到旺季结束（具体到几月几号）。”

**2. 锁定品质标准（最重要）**
菠萝是易损耗水果，旺季供应商容易掺杂次果。补货时，必须再次明确：
- **成熟度**：是卡在“八成熟”（适合现切/加工）还是“全熟”（直接售卖）？
- **规格**：要求“单果重量≥1.5斤”或“果径≥14cm”，避免混入小果。
- **瑕疵率**：约定“腐烂、黑心、机械伤比例不得超过3%”，超出部分当场扣除或退款。

**3. 约定价格与结算方式**
临时补货往往涉及溢价，一定要先讲清楚：
- **加价幅度**：明确“临时加单按原价上浮5%”还是“按市场当日批发价结算”（建议写个上限，防止涨价离谱）。
- **付款方式**：如果是临时加急订单，是否可以“货到验收后24小时内转账”或“继续沿用原月结周期”。切勿模糊处理。

**4. 明确交货时间与违约责任**
- 约定**最迟到货时间**（例如“每日下午4点前送抵门店”）。
- 如果供应商因产能不够导致缺货，需赔偿你因断货造成的损失（例如按缺货吨数×当日售价的20%赔偿）。这个条款能倒逼对方优先供你的货。

**5. 建立“备胎”预案**
即使约定好了，也要和供应商口头确认一句：“如果你们这次临时调配不了，提前48小时告诉我，我好安排备选渠道。”这可以倒逼供应商更重视你的追加订单。

---

**实操建议（马上能用的模板话术给供应商）：**
> “王老板，旺季到了，我这边菠萝用量上涨，想跟你把临时补货规矩定一下：从这周起，我如果临时追加，会在下单前**提前48小时**给你具体斤数，品质还是按咱们之前定的（八成熟、单果1.5斤以上、坏果率3%以内）。价格方面，如果加急，我接受在原价基础上**每斤加0.2元**作为你的运费补贴，但送货时间必须卡在**下午4点前**到店。如果你们实在调不出货，至少提前24小时告知我，我好另想办法，后面长期合作咱们再聊。你看这样可以吗？”

**最后提醒：** 补货量突然变大时，记得同时**留出5%-10%的损耗冗余**（因为追加批次通常更难保证新鲜度），避免到货后次品多导致又得紧急二次补货。如果短期（1-2周）用量是平日的2倍以上，建议直接考虑**与供应商签订旺季专供协议**，锁定优先供货权和保护价。
