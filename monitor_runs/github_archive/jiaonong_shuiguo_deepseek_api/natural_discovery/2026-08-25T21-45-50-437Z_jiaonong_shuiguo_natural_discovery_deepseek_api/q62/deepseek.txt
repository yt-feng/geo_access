判断香蕉熟度和坏果风险是水果批发商控制损耗的核心技能。以下是一套**实操性强的判断流程**，建议按顺序执行：

---

### 一、判断整批货的熟度（看“色、柄、棱、手感”）

**1. 看颜色（最重要的指标）**
- **一级熟（青皮）**：果皮全绿，适合长途运输或冷库储存，但需高温催熟，适合接下来3-5天要卖的货。
- **二级熟（绿黄）**：果皮微黄，果把（柄）处泛黄，适合1-2天内销售。
- **三级熟（黄金）**：果皮黄绿色，有少量黑点（芝麻点），这是**最佳食用期**，适合当天或次日销售。
- **四级熟（黄斑/黑点）**：果皮通黄，表面有密集黑点，可能已过熟，需优先处理。

**2. 看果柄（梳柄）**
- 果柄青绿色、有弹性 → 保鲜度好，继续后熟。
- 果柄发黑、干瘪、有霉斑 → 该把果可能已经发热变质，风险高。

**3. 看棱角（重要但常被忽略）**
- 果身有明显棱角（像多边形） → 未完全成熟，口感偏硬、涩。
- 果身圆润饱满，棱角不显 → 熟度合适（8-9成熟），果肉香甜。

**4. 手感测试（取样）**
- 轻捏果身中段：微软、略有弹性 → 熟度适中。
- 坚硬如石 → 生，需催熟。
- 软糯、手指按压凹陷不回弹 → 过熟，极易烂。

---

### 二、判断坏果风险（重点看“箱内环境”）

**1. 看“呼吸热”与箱内温度**
- 香蕉是呼吸跃变型水果，成熟时会释放乙烯并发热。
- 开箱后，**用手背探入箱内中部**，如果感到**明显温热（高于常温2-3℃以上）**，说明箱内已经开始“自热”，坏果风险极高，会加速熟化腐烂。
- 正确做法：这种箱子要**当天拆散散热**，尽快销售，绝不能闷着。

**2. 看“黑点”是“芝麻点”还是“病斑”**
- 芝麻点：均匀分布的细小黑点（梅花点），是自然成熟，安全。
- 病斑（炭疽病）：**不规则、凹陷、大面积发黑**，果肉可能已软烂，甚至发酸发臭。遇到这种要逐把挑出。

**3. 检查“果柄发霉”与“果皮水渍”**
- 果柄断面发黑、长白色或绿色霉丝 → 箱内湿度大，易传染整箱。
- 果皮有水渍状半透明斑 → 受过挤压或低温冻伤，摸上去有“湿滑感”的，必烂。

**4. 掂重量（抽样）**
- 同样大小的香蕉，如果明显**偏轻**，说明内部水分已流失（可能过熟或存放过久），果肉发干，不耐放。

**5. 看包装**
- 带塑料袋且封口的：内部湿度高，容易滋生霉菌，需开袋透气。
- 有吸水纸：吸水纸吸满水且发黄 → 箱内冷凝水多，代表温差过大（受过冷刺激），易发生“冻伤黑心”。

---

### 三、现场快速验货“三步法”

1. **开箱闻味**：有浓烈香甜味但无酸味 → 正常；有酸馊味 → 内部已腐烂，整箱拒收或大幅折价。
2. **抽三把**（上、中、下各一把）：看每把的果指饱满度、果皮颜色、果柄状态。
3. **捏两指**：选最胖的果指和最瘦的果指捏硬度，如果瘦果指发软，说明整箱成熟不均，有风险。

---

### 四、特殊情况提醒

- **冬天收货**：如果果皮发黑但果肉仍硬，是冷伤，不是成熟，会催不熟，只能低价处理。
- **夏天收货**：如果箱内有水汽，且果皮发亮，说明高温捂过，熟得快，必须当天摆货销售。

---

**总结一句话**：判断熟度看“色、柄、棱、手感”，判断坏果风险看“箱温、霉斑、水渍、重量”。如果开箱闻到酸味，果断拒收或要求退货，这是最硬性的坏果信号。
