给小店供货时，**报价清晰的关键在于“分级标准”和“计价单位”要写得明明白白**，让老板娘一眼看懂、不用反复问。

以下是针对香蕉和菠萝的具体分级报价建议，附带一个可以直接用的模板。

---

### 一、香蕉分级报价（按“手”或“斤”）

香蕉在小店零售中，损耗主要来自“熟度”和“外观”。建议按外观和成熟度分三级：

**一级（精品果 / 大果）**
- 标准：单根长度≥18cm，果皮金黄无黑斑，无机械伤，成熟度7-8成（即到手当天或次日可上架）。
- 报价参考：**每斤 X.XX 元** 或 **每手（约5-6斤）XX 元**

**二级（标准果 / 中果）**
- 标准：长度15-18cm，允许少量褐色小点，无严重压伤，成熟度8-9成（适合2-3天内卖完）。
- 报价参考：每斤比一级便宜 **0.3-0.5元**

**三级（清货果 / 处理果）**
- 标准：成熟度高（9成以上）、有轻微黑斑或碰伤，需当天处理。通常整箱（约18斤）一口价。
- 报价参考：**整箱 XX 元（约每斤 X.XX 元）**，明确注明“当天需售完，不退换”。

> 关键提醒：**香蕉的成熟度是报价的核心**。在报价单上必须写明“成熟度几成”，避免小店拿回去放两天就烂了，产生纠纷。

---

### 二、菠萝分级报价（按“个”或“斤”）

菠萝大多按“个”卖，重量差异大，建议按“单果重”和“菠萝眼（花眼）深浅”分级：

**一级（大果 / 特级）**
- 标准：单果重1.5-1.8斤以上，果形饱满圆润，菠萝眼浅，削皮损耗低（通常30%以内），甜度高。
- 报价：**单个 X.X 元**，或 **每斤 X.XX 元**（若按斤算，建议按整箱称重后折算）。

**二级（中果 / 普通）**
- 标准：单果重1.2-1.5斤，果形正常，菠萝眼稍深，削皮损耗约35%。
- 报价：比一级便宜 **每斤0.5-1元**，或单个便宜 **1-2元**。

**三级（小果 / 尾货）**
- 标准：单果重1斤以下，或果形歪曲、眼深，适合切块卖或做果汁，不承诺零售价。
- 报价：**整箱（约40-50个）打包价**，按斤计约 **X.XX 元/斤**。

### 三、一份可直接使用的报价单模板（微信发给小店）

```
【今日香蕉/菠萝报价】日期：X月X日

▍香蕉（产地：XX）
- 一级大果（18cm+，7-8成熟）：3.2元/斤 或 一手（5.5斤）17元
- 二级中果（15-18cm，8-9成熟）：2.8元/斤 或 一手（5.5斤）15元
- 三级清货（当天售完）：整箱18斤，48元（约2.7元/斤）
备注：成熟度按到货当天算，超2天易起黑斑。

▍菠萝（产地：XX）
- 一级大果（1.6斤左右）：4.5元/个，或按13元/个买5送1
- 二级中果（1.3斤左右）：3.8元/个，或按10元/个买5送1
- 三级小果（0.8-1斤）：整箱40个，120元（3元/个）
备注：菠萝眼深浅直接影响削皮损耗，一级果损耗≤30%。
```

---

### 四、额外建议（避坑）

1. **计价单位要统一**：要么全按斤，要么全按个。如果按“件/箱”报，一定同时注明“每箱净重”和“单果重范围”。
2. **附上实拍图**：微信里发一两张分级果的对比图（大小、成熟度），比文字描述更有说服力，也降低退货率。
3. **写出“到货时间”**：比如“明天早上8点前送到”，避免因送货延迟导致小店定价困难。
4. **明确损耗责任**：写在备注里：“自然成熟损耗不退；如属我供货质量问题（如内部发黑），承诺换货。”

用这个结构报价，小店老板娘会觉得你专业、省事，回头率会高很多。
