在茶饮店采购菠萝原料时，**出汁率通常比甜度更重要**，但两者并非单选，而是需要根据你的产品定位和成本结构来权衡。

以下是从**商业实操角度**的详细拆解，你可以直接对照决策：

**1. 为什么出汁率优先（成本与毛利）**
- **直接成本**：出汁率直接决定每杯饮品的原料成本。例如，A品种出汁率60%，B品种出汁率45%。做一杯500ml的菠萝茶需要150ml果汁：
  - A品种需鲜果250g，B品种需333g。
  - 如果采购价相同（比如5元/kg），则B品种每杯成本多0.42元。按一天卖200杯算，每月多出2520元成本，这是纯利润流失。
- **出品稳定性**：出汁率低的果肉纤维多，压榨时容易堵塞设备，且果汁浓度不稳定，导致每杯口感有差异，这在连锁店是致命的。

**2. 甜度的重要性（但可用“补糖”解决）**
- 甜度可人工干预：茶饮行业有标准解法——**果糖、蔗糖浆、风味糖浆**。
- 如果你的菠萝偏酸但香气足，可通过加糖浆（成本每杯约0.1~0.3元）精准调至你想要的甜度。
- 但**出汁率无法通过加任何东西来弥补**，只能用更多水果替代，成本不可逆。

**3. 关键补充：香气与酸度比例（比甜度更关键）**
- 茶饮用的菠萝，**香气浓度 > 甜度**。因为茶汤和冰块会稀释甜味，但香气能穿透饮品。
- 建议实际测试：将不同菠萝榨汁后，按“1份果汁+3份茶汤+糖浆”来盲测，重点看**香气持久度和酸感是否平衡**。酸度高的菠萝反而能做出更开胃的果茶，但酸涩感过强则不适合做纯果汁款，更适合做“菠萝气泡水”或“菠萝乳酸菌”类。

**4. 实操建议（按你的经营场景）**

| 场景 | 优先选择 | 理由 |
|------|---------|------|
| **做鲜果茶、菠萝茶底** | 出汁率>甜度 | 用量大，成本敏感；酸甜统一靠糖浆调节 |
| **做菠萝果肉小料（加在奶茶/冰淇淋里）** | 甜度>出汁率 | 果肉口感更重要，甜度直接影响咀嚼体验，出汁率低反而果肉更紧实 |
| **小门店、走量低价款** | 出汁率优先 | 薄利多销，1%的出品率差异就是利润 |
| **主打高端、鲜果现切展示** | 两者都要高 | 要买“都乐金菠萝”或“香水菠萝”这类高溢价品种，但注意出汁率别低于55% |

**5. 采购时的硬性检测方法（30秒判断）**
- 切开一个菠萝，**用力挤一下果肉**：
  - 如果流出的果汁多且澄清，说明出汁率好。
  - 如果挤出来的是浑浊的碎末多、水少，说明纤维多，出汁率差。
- **测可溶性固形物（糖度计）**：Brix值在12~14之间是标准，但如果你要加糖，**10~11的低甜高香版本反而性价比更高**（采购价更低）。

**最终结论**：
- **做单杯成本控制在5元以内的饮品：无脑选高出汁率，甜度用糖浆补。**
- **做精品手作、顾客能喝出风味的：可以接受出汁率低5个百分点，但必须买香气浓、酸度平衡的品种（如都乐金菠萝、台湾凤梨17号）。**

不要被“天然甜”绑架——茶饮行业的核心利润逻辑是：**用最低的水果成本，做出口感统一的产品**。出汁率就是那个“最低成本”的硬指标。
