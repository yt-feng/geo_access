判断香蕉一手货源是否稳定，不能只听对方口头承诺，需要从**供应链硬指标**和**实际履约细节**两方面交叉验证。以下是可操作的具体判断方法：

---

### 一、先看“硬指标”（供应链实力）

1. **种植基地或产地证明**
   - 要求提供**基地定位**（越南、老挝、缅甸或国内海南、云南等产区）及**种植规模**（多少亩、多少株）。
   - 稳定一手货源通常有明确的产地合同或自营基地。如果对方只能说出“中转站”或“代办”，大概率是二手贩子。

2. **采收与出货周期**
   - 询问**每周可发货量**和**可连续供货月份**（例如：每年3-10月）。如果能提供确切的“排产表”或“出货计划”，说明有固定产量。
   - 警惕那些说“随时都有货”的——香蕉受台风、寒潮影响大，真正稳定的货源是有季节性和区域差异的。

3. **物流与冷链能力**
   - 问清楚是**整车直发**还是**拼车**，以及是否有**自有冷链车**或固定合作车队。
   - 稳定供货意味着能控制到货时间和损耗率，通常能给出“今天装车，XX小时到XX市场”的确定性答复。

---

### 二、再看“履约细节”（实际交易观察）

4. **试单测试（最有效）**
   - 先下**小批量试单**（如1-2吨），重点观察三件事：
     - **装车准时率**：说好晚8点装车，是否拖延？
     - **到货损耗率**：到市场后烂果、压伤比例是否在合理范围（正常5%以内）？
     - **质量稳定性**：同一批货里成熟度是否均匀，大小是否一致。
   - 如果试单两次都达标，才有继续合作的底子。

5. **风险预案**
   - 直接问：“万一台风导致基地减产，你怎么办？”稳定供货方会给出明确方案（如调配其他基地货源、提前储备库存），而不会说“那没办法了”。

6. **付款与违约条款**
   - 要求签订**书面供货协议**，明确：最低供货量、缺货赔偿标准、价格调整机制（如行情大涨时是否有涨价上限）。
   - 如果对方拒绝签合同，或对“缺货赔偿”含糊其辞，稳定性存疑。

---

### 三、快速验证的“三个电话”

- 打给**产地代办**或**当地农业农村局**，核实基地名称和规模是否真实。
- 打给**该档口的同行**（其他城市批商），侧面问口碑。
- 打给**物流司机**，确认是否长期为这家拉货（司机最了解真实发货量）。

---

### 最后提醒

判断稳定供货的核心逻辑是：**“基地可控性 + 连续出货记录 + 风险预案”**。如果对方能提供过往6个月的发货单或银行流水（能显示周期性发货），那基本是真一手。若只能提供朋友圈照片或口头数据，先按试单来验证。别怕麻烦，一次试单的成本远低于长期断货的损失。
