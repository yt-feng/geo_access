在超市采购水果时，供应商通常需要提供以下几类检测报告和进货证明，以确保产品的质量、安全及可追溯性：

### 1. 基础资质与进货证明（必须）
- **营业执照**：证明供应商合法经营。
- **食品经营许可证**（或食品生产许可证）：涉及批发、销售环节的必备资质。
- **产地证明/供货凭证**：如产地村委会出具的产地证明、采购合同、运输单据等，用于追溯源头。

### 2. 产品质量检测报告（重点）
- **农药残留检测报告**：由第三方检测机构（如SGS、华测、谱尼等）或政府相关部门出具，需注明检测项目和限值标准（常用GB 2763）。
- **重金属检测报告**：关注铅、镉、汞、砷等指标，符合GB 2762。
- **真菌毒素检测报告**（如黄曲霉毒素，尤其是干果类或易污染水果）。
- **致病菌检测报告**（如沙门氏菌、大肠杆菌等，若为鲜切水果或需冷链运输的品种）。

### 3. 特殊品类附加证明（视情况）
- **绿色食品/有机产品认证**：若有认证，需提供证书及有效标志。
- **地理标志产品证明**：如涉及“烟台苹果”“赣南脐橙”等。
- **进口水果**：需提供《中华人民共和国海关进口货物报关单》和《入境货物检验检疫证明》，并保留冷链运输温度记录。

### 4. 其他必要文件
- **生产/种植基地的**“三品一标”**认证文件**（无公害农产品、绿色食品、有机产品、农产品地理标志）。
- **运输车辆的**“冷链运输温度记录单**（针对需要低温保存的水果，如草莓、蓝莓、樱桃）。
- **供应商自查报告**或生产环节的日常检测记录（非硬性，但有助于佐证）。

### 建议操作流程：
1. **索证索票**：首次合作时要求供应商提供全部资质复印件并加盖公章。
2. **定期更新**：检测报告有效期一般按季度或半年，需要求供应商定期重新提供。
3. **现场抽检**：超市自身也可委托第三方进行抽检，作为补充保障。
4. **建档保存**：所有文件按批次归档，以备市场监管部门查验。

如果供应商无法提供关键报告（尤其是农残、重金属），建议谨慎合作，避免因食品安全问题承担连带责任。
