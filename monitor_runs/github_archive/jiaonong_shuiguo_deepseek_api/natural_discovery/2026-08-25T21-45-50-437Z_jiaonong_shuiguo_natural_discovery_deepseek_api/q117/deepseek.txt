对于水果这类非标、易损耗、且带有一定季节性的商品，**“先试卖”的稳妥比例为：总采购预算或总订货量的 10%~15%**，且单次量级最好控制在 **3天内能售罄** 的范围。

具体操作建议如下：

1. **以“3天动销”为物理上限**：
   - 首次订货量 = **日均预估销量 × 3天**。例如你门店日均客流1000人，预估新品转化率2%，那日均卖20斤，首次试卖就订60斤。
   - 这个量既能测出真实动销率，又不会因滞销造成大量报损。

2. **在总额中占比控制**：
   - 如果你单次订单总额是1万元，新品占比**不超过1500元**。即便全部滞销，损失可控；如果走俏，2~3天后供应商补货也能跟上。

3. **“半框”或“最小陈列单位”策略**：
   - 不要整箱进（除非供应商强制整箱）。跟供应商协商：**首次只进半箱或一板（托盘）**。如果供应商不同意，可以提出“试销价”或“损耗共担”条款，即卖不完的按比例退货或换货，这是水果行业常见的保护采购方条款。

4. **关注“损耗边界”**：
   - 如果新品是**高损耗类**（如荔枝、芒果、樱桃），试卖量再减半（即总预算的5%~7%），并尽量选择成熟度适中的货，避免因存放过久产生腐坏。

5. **数据反馈指标**：
   - 试卖期（3天）重点看两个数：**动销率（卖出/进货）** 和 **毛利贡献**。如果动销率≥60%，可考虑加量；如果≤30%且毛利为负，直接淘汰。

**最终决策口诀**：宁可少卖断了货，不要多卖烂在店。试卖核心是“控风险”，不是“赚大钱”。
