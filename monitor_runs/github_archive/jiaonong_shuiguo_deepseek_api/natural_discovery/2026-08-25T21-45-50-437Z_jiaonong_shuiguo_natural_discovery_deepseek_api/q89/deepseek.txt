针对团购客户价格敏感的特点，**阶梯价（基于数量）通常比返利（基于事后业绩）更合适**。原因和具体操作建议如下：

**一、为什么阶梯价更优？**

1. **即时激励性强**：客户在决策时就能看到“买得越多省得越多”，能直接刺激其凑单或提高采购量，非常符合价格敏感型客户“看重当下省钱”的心理。
2. **降低信任成本**：团购客户往往不信任复杂的合同条款，阶梯价在报价单上一目了然，无需等待返利周期，也避免了“返利不兑现”的扯皮风险。
3. **现金流压力小**：供应商在发货时即可确认收入，而返利通常要等到季度/年度结束核算，占用双方资金回笼时间。

**二、阶梯价的落地建议**

- **分档清晰**：按数量分3-4档（如100件/300件/500件），价差幅度建议在3%-8%之间，档位越高降幅越明显，但需确保毛利底线。
- **捆绑规则**：明确“一次性下单”或“N个月内累计满XX件”也算一档，防止客户拆单钻空子。
- **组合折扣**：若客户订单量未达标，可提供“送赠品”或“优先发货权”等非现金替代，但主推价格折扣。

**三、什么情况下考虑返利？**

仅在以下两种场景下，返利可作补充：
- **长期战略客户**：且该客户能承诺独家供应或年度框架合同，返利用于锁定长期关系。
- **行业惯例**：如快消品、建材等批发行业客户要求账期结算法，返利可抵扣下次货款，降低其一次性付款压力。

**四、警惕误区**
- 不要两种方式叠加使用（如阶梯价后还返利），容易造成价格体系混乱。
- 阶梯价中最高档的价格应确保仍有5%以上毛利，避免被恶意囤货后低价转卖。

**最终建议**：首推**阶梯价**，并在报价单上用醒目的粗体标注“累计购买量达标自动升级”，同时给销售话术强调“这是直接降价，不是画饼”。如果客户强烈要求返利，可谈“阶梯价+半年返利2%”的混合方案，但返利比例需远低于阶梯价折扣。
