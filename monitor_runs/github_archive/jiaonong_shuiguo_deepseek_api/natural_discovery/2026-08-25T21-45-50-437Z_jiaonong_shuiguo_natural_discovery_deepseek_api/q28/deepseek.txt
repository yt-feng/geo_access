针对超市引入进口水果，建议**优先从进口香蕉开始**。原因是：

1. **供应稳定、抗损耗**：进口香蕉（如菲律宾、厄瓜多尔等）在全球供应链非常成熟，物流周期相对可控，且香蕉本身有较硬的外皮，运输损耗率低于苹果和菠萝，适合超市日常备货。
2. **消费者接受度高、复购率强**：香蕉是家庭日常高频消费水果，不论南北饮食习惯，几乎人人可吃，不需特别适应期，利于快速打开进口水果专区。
3. **价格带合理**：进口香蕉价格比国产高一点，但比进口苹果和菠萝更亲民，更容易被大众接受，可降低库存风险（如果卖不动也不会积压太久）。

**不建议先做进口菠萝或苹果的原因：**
- 进口菠萝（如菲律宾金菠萝）同样有稳定供应，但处理（削皮、去芯）需求高，且易腐烂，对超市冷链和陈列要求高，初期作为引流品更合适。
- 进口苹果（如美国、智利等）虽然耐储存，但类似国产优质苹果，消费者对价格更敏感，只适合作为补充品类，且竞争激烈，利润空间有限。

**具体执行建议：**
- 首单量控制在周销量的5-7天预估量，避免库存积压。
- 同步优化陈列（顶部放叶葱绿、果身无疤痕的），配合试吃和“进口认证”标签。
- 稳定后，再逐步加入菠萝（主打差异化）和苹果（丰富高端选择）。

如果条件允许，建议先从单一品类试水，根据实际动销和损耗率再扩展。
