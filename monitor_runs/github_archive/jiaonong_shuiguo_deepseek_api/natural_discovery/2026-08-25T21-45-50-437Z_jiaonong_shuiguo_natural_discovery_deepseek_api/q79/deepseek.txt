选水果供应商时，**最应该先问配送，其次是售后，最后才是价格**。这个排序是基于水果生鲜品类的特殊性——损耗快、季节性强、运输时效要求高。

给你拆解一下为什么是这个顺序，以及每个环节具体要问什么：

### 1. 配送（优先级最高，决定“货能不能到”）
水果的利润往往就藏在损耗里。如果配送不及时、包装不到位，哪怕价格再低，拿到手烂一半，你的团购口碑就崩了。

- **问时效**：今天下单，明天最晚几点能送到？能不能承诺“昨晚截单，今早到货”？（社区团购最好隔日达，当天到会更优）
- **问包装**：运输用泡沫箱还是纸箱？有没有放冰袋？分装是按5斤/箱还是按份数？包装是否防挤压？（尤其草莓、葡萄、水蜜桃这类娇贵水果）
- **问起送量**：单次最少要订多少？如果起送量太高，而你的社群规模小，会导致库存压力。
- **问补货/换货机制**：如果到货后因运输磕碰，是直接补发还是按比例赔偿？补发时效多久？（这其实已经涉及售后，但和配送强绑定）

### 2. 售后（决定“赔不赔得起”）
生鲜不可能100%无瑕疵，关键是“出问题后谁买单”。

- **问坏果标准**：坏果率超过多少%可以包赔？是按个赔还是按斤赔？（比如“坏果超3%按比例赔付”）
- **问理赔流程**：是拍照发群里就赔，还是需要寄回坏果？理赔到账是微信红包、支付宝还是直接抵扣下次货款？
- **问售后责任边界**：如果是团长自己分拣时弄坏的，供应商管不管？如果是客户保存不当（比如放常温过夜），怎么界定？

### 3. 价格（最后问，但要问“综合成本”）
价格不是问“一斤多少钱”，而是问“包含了哪些隐形成本”。

- **问含包装和运费吗**？很多低价是裸果价，加包装、加冷链运费后可能比别家还贵。
- **问分拣损耗谁承担**？是送到你手上你自行分拣，还是供应商按净重/份数包装好？如果供应商能帮你打包成固定份量（比如每份5斤、10斤），能省你大量人工。
- **问淡旺季波动**：现在是应季水果还是反季？如果应季，价格下浮空间有多大？

---

**给你的实操建议（假设你是新手团长）：**

1. **先试单**：别第一次就大批量采购，先订一小批（比如5-10箱），重点测试配送速度和售后响应速度，比供应商说的天花乱坠有用。
2. **合同/聊天记录留证据**：所有“包赔”“配送时效”的承诺，尽量让供应商在微信里用文字确认，不然口头承诺后期扯皮。
3. **备选供应商**：同品类至少备2家，A家主供，B家应急（比如A家缺货或爆单时）。

**一句话总结**：配送决定“货能不能跑赢时间”，售后决定“出了问题谁兜底”，价格是最后权衡的“甜头”。先把前两者谈妥，再谈价格，否则省下的钱都会变成烂果和投诉。
