针对节假日水果需求暴增的情况，连锁超市要提前锁定货源，可以从**数据预测、供应商锁量、物流预案、紧急替补**四个维度入手。以下是具体可执行方案：

**1. 提前1-2个月做需求预测和锁定**
-   **数据复盘**：调出过去2-3年同期（如春节、中秋）各门店的销量数据，结合今年消费趋势（如车厘子、草莓热度）估算增幅。
-   **签锁量合同**：与核心供应商（产地直采或一级批发商）签订《节假日保供协议》，明确**预付款锁价**（防止涨价）和**保底采购量**（未销完按约定折扣处理），锁定总货源的60%-70%。

**2. 产地直采 + 基地前置仓**
-   如果销量大，直接派采购团队驻扎主产区（如海南、云南、山东），包树或包棚（如整果园采购），锁定未采摘的水果。
-   在产地设立**分拣前置仓**，节假日期间直接从产地发车到区域DC（配送中心），跳过批发市场中间环节，既锁价又锁量。

**3. 分波次锁定 + 动态补货**
-   不要一次性全部锁死。第一波（节前3天）锁定60%-70%，第二波（节前1天）根据预售进度补30%，这30%用“实时竞价”或“优先合作伙伴”方式锁定，防止积压。
-   建立**替代货源库**（例如A产区不足，B产区随时可调货），与2-3家非主流产地的供应商保持联系，作为应急预案。

**4. 物流与冷库资源锁定**
-   节假日物流运力紧张，需要提前7天锁定冷链车（签订用车协议），确保“货到了拉不走”的情况不发生。
-   提前租好或协调好本地冷库容量，确保到货后能储存，避免堆在门店烂掉。

**5. 实战钩子：提前预售锁定消费端**
-   提前15天开启**线上预售**（如“春节车厘子礼盒”），收取定金或全款。以预售数据作为采购谈判的筹码，增加对供应商的议价权。

---

**特别注意（防坑指南）：**
-   **不要全额付款**：只付定金，尾款到货验收合格后支付，防止供应商以次充好。
-   **明确质量规格**：合同里必须写清品种、规格（如车厘子J级别）、糖度、成熟度，避免节假日拿品相差的充数。
-   **考虑损耗率**：放大10%-15%的损耗预算，锁量时买多5%左右，宁可在节后做促销，也不要出现断货。

**总结优先级**：数据定基数 > 签锁量合同 > 产地包园 > 锁冷链车 > 线上预售托底。这些动作最好在节前40-60天启动。
