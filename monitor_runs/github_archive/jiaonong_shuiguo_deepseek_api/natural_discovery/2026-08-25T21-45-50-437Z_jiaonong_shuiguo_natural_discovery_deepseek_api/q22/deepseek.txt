针对超市水果区，提高客单价的核心在于**“组合购买”与“场景化消费”**。

给您三个可落地的组合方案，按不同目的划分，您可以直接复制执行：

---

### 方案一：早餐/健身场景——**“能量唤醒组合”**
**组合逻辑：** 高碳水（香蕉）+ 高纤维（苹果）+ 解腻（菠萝），主打“快速补充能量”。

**具体操作：**
- **主推品：** 香蕉（引流品，价格做低）
- **捆绑品：** 苹果 + 菠萝（利润品，价格正常）
- **展示方式：** 在香蕉堆头旁放置一个小展板，写上：“早餐组合：香蕉1根 + 苹果1个 + 菠萝1/4个 = 今日活力”。
- **促销形式：** 同价换购。买**任意1斤香蕉**，+2元可换购1个苹果（原价3元），+3元可换购1/4个菠萝（原价5元）。这样顾客原本只买3元的香蕉，最终可能消费到8-10元。

### 方案二：家庭分享场景——**“果盘组合”**
**组合逻辑：** 应对家庭聚餐或下午茶，将三种水果直接组成“免切果盘”的原料包。

**具体操作：**
- **主推品：** 菠萝（切半展示，视觉冲击）
- **捆绑品：** 苹果、香蕉（作为填充体积的水果）
- **促销形式：** **“家庭果盘包”**。将1个菠萝、2个苹果、3根香蕉用保鲜膜+托盘打包成一盒，定价为**单买总价的8折**（例如单买合计20元，组合价16.8元）。
- **话术技巧：** 在价签上标注：“回家只需切一刀，省15分钟”。同时免费赠送一次性果叉和餐巾纸，提升价值感。

### 方案三：冲动消费场景——**“甜蜜特价组合”**
**组合逻辑：** 利用菠萝高糖分和苹果的耐储存性，做“满减”计算。

**具体操作：**
- **主推品：** 菠萝（现削皮，带香气）
- **捆绑品：** 香蕉（易损耗）、苹果（耐放）
- **促销形式：** **“满10元减2元”**。设置一个专区，顾客如果**同时购买菠萝和香蕉**（不计重量），合计金额满10元立减2元；如果再加1个苹果，满15元立减4元。
- **关键细节：** 该区域一定要提供**试吃**（切好的菠萝块和香蕉块），试吃后购买率会提升30%以上。

---

### 执行时的3个关键细节（非常重要）：

1.  **位置设置：** 不要平铺三个货架。应设置一个**“L型”陈列**。香蕉在入口处（价格惊爆），苹果在中间（视觉饱满），菠萝在出口处（香气扑鼻）。顾客必须走完这条动线才能结账。
2.  **视觉刺激：** 货架上方挂一张大图，画着一盘切好的**“菠萝炒饭”**或**“热带水果沙拉”**，刺激非理性购买。
3.  **员工话术：** 称重台员工在给香蕉称重时，主动问一句：“苹果今天做活动，跟香蕉一个价（或特别优惠），带两个吧？”这种口头推销的成功率极高。

### 建议优先尝试：
**立即执行方案一（换购）**，成本最低，见效最快。因为香蕉损耗最快，用它来带动其他两种水果的动销率是最高效的。建议活动周期为**3-5天**，制造稀缺感。
