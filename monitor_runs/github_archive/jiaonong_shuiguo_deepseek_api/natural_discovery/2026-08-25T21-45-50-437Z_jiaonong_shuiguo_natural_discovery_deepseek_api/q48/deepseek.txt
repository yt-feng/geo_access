判断茶饮连锁的菠萝供应商能否**稳定按规格送货**，不能只看口头承诺，必须建立一套可验证的评估和试单机制。以下是可执行的操作步骤：

**一、先看“硬指标”：供应商的产能与排产逻辑**
1. **要求提供“产能证明”**：让其提供近3个月的菠萝采购/加工量台账，或者主要合作果园的承包面积。如果供应量超过其日常产能的70%，大概率会断供。
2. **考察其“冻品库存”能力**：茶饮用的菠萝多为去皮切块冷冻果，需确认其是否有**冷库容积**和**速冻线**。没有深冷产能的供应商，无法保证夏季高峰的连续供货。

**二、关键试单测试（7天连续到货测试）**
这是最核心的验证方法：
- 签一份**小单试运合同**，要求其连续7天、每天固定时间送固定规格的货（例如每天500kg，块型2cm±0.3，糖度14±1）。
- **重点观察**：
  - 到货**准点率**（延误超2小时计一次违规）。
  - **重量负偏差**（不能超过合同约定的±3%）。
  - **颗粒度均匀度**（随机抽3箱，目测不合格比例）。
  - **温度检测**（到货中心温度需低于-18℃，温度波动是断链隐患）。

**三、合同里的“硬约束条款”**
如果试单通过，正式合同必须写明以下三点，否则供应商容易钻空子：
- **超时赔付条款**：晚到1小时，按该批货值2%扣款，迟延超6小时，甲方有权拒收并索赔空运费用。
- **规格波动容忍度**：写明“连续三次超过±5%偏差，甲方有权解除合同并要求赔偿门店停售损失”。
- **备选产能背书**：要求供应商提供其上游2-3家合作果园的“保供协议”或“意向书”复印件，确保其能调配货源。

**四、第三方抽检机制**
- 指定一家**第三方检测公司**（如SGS、华测），每周二、周五到你仓库随机抽1箱菠萝，送检**农残、糖度一致性、块型尺寸**。费用可以约定由双方各承担50%，这能有效逼退投机供应商。

**五、实地突击检查（未经预约）**
- 合同的执行期前2个月内，至少安排1次**无预警到访**其加工车间。
- 重点看两条线：一是**原料分拣线**是否有人工或色选机剔除次果；二是**切块机刀头**是否每日更换（刀钝会导致碎屑多、规格不准）。

---

**重要判断底线**：
如果供应商在试单期出现**超过2次规格偏差**，或者**有1次为了赶货而提前24小时解冻再复冻**（口感会发绵），直接淘汰。茶饮店高峰期（夏季）损失不可逆。

**最后提醒**：不要相信“我们做出口的，肯定没问题”这类话术。市场规律是**出口订单优先级永远高于内贸**，务必在合同中明确“**内贸订单不得低于出口订单排产优先级**”，否则旺季必被插单。
