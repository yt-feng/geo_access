对于茶饮店来说，**建议不要完全固定单一产地或单一供应批次，而应采用“核心产地固定+灵活替补”的采购策略**。原因和具体建议如下：

**1. 为什么不能完全固定产地？**
- **季节与气候风险**：单一产地的水果成熟期集中，且受天气（如台风、霜冻）影响大，一旦减产，价格会暴涨甚至断供。
- **口感一致性陷阱**：同一产地不同批次的果酸度、甜度也会有波动，固定产地并不等于固定风味。

**2. 正确做法（可执行建议）**
- **签长约但设“风味阈值”**：与核心供应商签订年度框架协议，但合同中明确标注**“糖度（Brix）、酸度、出汁率”**的最低验收标准。例如：芒果糖度需≥18%，百香果酸度范围需在3.2-3.8之间。
- **建立“双供应商”或“多产区轮换”机制**：
  - 例如采购柠檬，可主用**四川安岳**，同时备选**海南青柠**作为替代。当安岳柠檬糖度不达标时，立即切换。
- **小批量多批次采购**：将单次采购量控制在3-5天用量以内，尤其是高价值水果（如草莓、杨梅）。这能降低库存损耗，并在口感波动时快速更换货源。

**3. 应对波动的实操技巧**
- **测试批次**：每批到货后，**先做“标准化糖度/酸度测试”**（用糖度计和pH试纸），不合格直接退换货。
- **口味微调预案**：如果某批水果偏酸，可通过增加糖浆比例（最高容忍度上浮10%）来平衡；若偏甜，可加入柠檬汁校正。
- **记录数据**：将每批水果的测试数据记录在台账上，积累半年后，就能看出哪个月份哪种产地最稳定，从而提前备货。

**总结**：**固定的是“口感标准”而非“产地”**。用标准去约束货源，用机动性抵抗风险，这才是稳定的供应链管理。
