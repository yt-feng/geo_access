香蕉和菠萝分级报价，最清楚的做法是“按级定规格、按规格定单价、按件/斤报净重”，并把验收标准写在同一张报价单上。

**一、先定分级口径**
- 香蕉：按“每把/每根长度+粗度+成熟度+外观”分。常用：
  - A级：长度均匀、无黑斑、无机械伤，成熟度7成左右，适合直接上架；
  - B级：轻微擦伤/色差/大小略不匀，适合促销或熟食加工；
  - C级：明显斑点、压伤、断把，明确为处理货。
- 菠萝：按“单果重量+果形+成熟度+有无黑心/裂口”分。常用：
  - A级：单果重达标、果形正、无裂口无黑心，成熟度适合3-5天销售；
  - B级：单果略小或果形偏，允许轻微日灼/擦伤；
  - C级：小果、裂口、熟度高，限当日或加工用。

**二、报价单固定字段**
品名、等级、规格（香蕉写长度/每把根数/成熟度；菠萝写单果重区间/成熟度）、包装（箱/件/把）、净重、单价（元/斤或元/件）、起批量、当日可供量、验收扣重规则、退换规则、报价有效期。

**三、报价表达方式**
建议统一报“净重单价+件价”两个数，例如：
- 香蕉A级：净重XX斤/件，X元/斤，折合X元/件；成熟度7成，允许≤3%机械伤。
- 菠萝A级：单果X-X斤，X元/斤，按件净重结算；黑心裂口包退换。

**四、避免扯皮的关键**
1. 等级差用“可量化指标”写清，不用“好/一般”这种词。
2. 报价注明“按净重结算，箱皮/垫纸不计重”。
3. 明确扣重和退换：例如机械伤超3%部分扣重，黑心裂口当场拍照退换。
4. 每天或每批次更新报价，写有效期，避免行情波动争议。
5. 同一等级固定包装规格，不要今天按把、明天按根混报。

这样小店一眼能判断“什么级、什么规格、多少钱、坏了怎么算”，报价就清楚了。
