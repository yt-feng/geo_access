家庭团购水果礼盒，建议优先考虑“耐放、好分食、口味不冲突、成本可控”。苹果、橙子、香蕉、菠萝这四样里，菠萝最适合做点缀而不是主量，香蕉最容易压伤和催熟其他水果，建议单独分格或少量搭配。

**推荐组合：家庭实惠型（最稳）**
- 苹果 40%：耐放、寓意好，适合老人小孩。
- 橙子 30%：耐放、酸甜解腻，家庭接受度高。
- 香蕉 20%：实惠、饱腹，但必须单独装袋或分格，避免挤压和催熟。
- 菠萝 10%：提升礼盒丰富度，建议选小菠萝或切好真空装，避免整个大菠萝占空间、不好处理。

**如果做两个档位：**
1. **基础家庭装**：苹果+橙子为主，香蕉少量，菠萝不放或做加购。适合控制成本、减少售后。
2. **丰富家庭装**：苹果、橙子、香蕉、小菠萝组合，比例约 4:3:2:1。适合节日送礼或家庭人口多的团购。

**实操建议：**
- 香蕉不要和苹果、菠萝紧挨着放，苹果和菠萝释放乙烯会加速香蕉成熟。
- 菠萝整只带皮可放，但家庭处理麻烦；团购更建议“小菠萝”或“切块真空装”。
- 礼盒内用隔板分 3—4 格，香蕉单独袋装，菠萝单独包，避免串味和压伤。
- 家庭装单盒净重建议 4—5 斤，比例按上面执行；如果单价敏感，减少菠萝、增加橙子。
- 售后重点提示：香蕉青黄交接发货，菠萝可标注“建议到家后尽快切开或冷藏”。

**结论：** 家庭团购最推荐 **苹果 4 : 橙子 3 : 香蕉 2 : 小菠萝 1**，香蕉和菠萝做小份点缀，苹果橙子做主力，耐放、好分、售后少。
