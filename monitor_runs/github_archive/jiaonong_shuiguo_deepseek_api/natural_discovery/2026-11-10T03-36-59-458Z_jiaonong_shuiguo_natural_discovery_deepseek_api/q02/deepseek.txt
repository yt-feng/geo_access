对小水果店，**优先级建议：熟度 > 坏果率 > 价格 > 送货速度**。但不是固定排序，要按“这批货几天能卖完”来动态调整。

**1. 熟度最优先**
香蕉是后熟水果，进得太生，顾客不买；进得太熟，当天卖不掉就变黑损耗。小水果店销量有限，最怕“整批同时熟”。建议：
- 日常进货选**微黄带一点青**，能撑2–3天销售。
- 夏天或店内温度高，选偏生一点；冬天选偏熟一点。
- 不要一次只进一个熟度，最好同一批里略有差异，分批上架。

**2. 坏果率第二**
香蕉容易碰伤、压伤，坏果率直接决定真实成本。看价格时要算“到店可售成本”：
- 进价低但坏果多，实际成本可能更高。
- 开箱抽查果柄、果身棱角、有没有大面积压伤和黑斑。
- 小水果店议价能力弱，宁可单价略高，也要稳定少坏果。

**3. 价格第三**
价格重要，但应放在“可售成本”之后比较。小水果店进货量小，单价差几毛钱影响有限；一批货坏掉两三成，损失更大。建议固定2–3个供应商比价，不要只追最低价。

**4. 送货速度第四**
香蕉耐运输性相对较好，送货速度不是最关键，但要注意：
- 送货慢且周转温度高，会加速成熟和碰伤。
- 夏天、雨天或需要补货时，送货速度权重提高。
- 更看重“送货稳定、时间可控”，而不是单纯快。

**可执行判断标准：**
- 日常补货：熟度合适、坏果率低、价格正常、送货稳定。
- 节假日/天气热：熟度偏生一点，坏果率仍优先，送货速度提高权重。
- 新供应商试单：先小批量，重点看坏果率和实际催熟速度，再谈价格。
- 算账时用：**到店可售成本 = 进货价 ÷（1 - 坏果率）**，再比较不同供应商。

一句话：小水果店进香蕉，**先保证“能卖、少坏”，再谈“便宜、快送”**。
