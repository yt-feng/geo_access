做餐饮客户，菠萝和香蕉的规格要按“用途”分，不要只按“大小”分。批发档口建议准备以下组合，并用稳定等级+可追溯批次管理：

## 菠萝：建议准备4类规格
1. **鲜切/果盘用大果**
   - 单果 **1.5–2.0 kg**，果形端正、冠芽完整、无黑心。
   - 适合中高端餐饮做鲜切、果盘；要求熟度可控，到货以 **7–8成熟** 为主，便于门店后熟。

2. **餐饮后厨/热菜用中果**
   - 单果 **1.0–1.5 kg**，出肉率稳定。
   - 适合炒饭、咕噜肉、菠萝包馅等，对糖酸比宽容度更高。

3. **饮品/甜品店用小果或二级果**
   - 单果 **0.8–1.2 kg** 或统货分级，成本低。
   - 用于榨汁、果酱、糖水，重点控酸度和损耗率。

4. **预切/真空鲜切菠萝**
   - 按 **袋装 1 kg/2 kg/5 kg** 或 **盒装 200–500 g** 供。
   - 餐饮客户最看重省人工和稳定出品，适合茶饮、沙拉、快餐。

菠萝选品关键：**品种统一、熟度分级、无黑心、冠芽不扎手、到店后熟时间可控**。不同品种如金钻、巴厘、MD2 不要混批报同一个价。

## 香蕉：建议准备3类规格
1. **餐饮果盘/ directly食用**
   - 单根 **120–150 g**，整把整齐，果指长度均匀。
   - 到货熟度 **3–4号色**，门店可自行催熟到5–6号色。

2. **烘焙/甜品/饮品用**
   - 单根 **100–130 g** 或二级果，要求果肉细腻、香气足。
   - 适合香蕉面包、奶昔、甜品；可接受外观略差但内部完好。

3. **后厨加工/低成本客户**
   - 统货或 **小果/弯果/二级果**，按箱或按公斤报价。
   - 用于炸香蕉、果泥、员工餐，重点控制到货熟度和黑斑速度。

香蕉选品关键：**按色号分级报价**，不要只说“熟香蕉”。餐饮客户最怕今天3号色、明天6号色。建议固定催熟供应商，按 **3–4号色到店、5–6号色即用** 分两档供货。

## 档口备货建议
- 菠萝：**大果、中果、小果/二级果、鲜切** 四档，先各备少量试单。
- 香蕉：**果盘级、加工级、二级统货** 三档，按色号分箱。
- 报价单上写清楚：**单果/单根重量区间、熟度、等级、装箱规格、损耗责任、起订量、配送频次**。
- 先找3–5家餐饮客户做小批量试供，记录他们实际用于果盘、热菜、饮品还是烘焙，再决定主推规格。餐饮客户复购的关键不是最低价，而是**规格稳定、熟度可控、少损耗**。
