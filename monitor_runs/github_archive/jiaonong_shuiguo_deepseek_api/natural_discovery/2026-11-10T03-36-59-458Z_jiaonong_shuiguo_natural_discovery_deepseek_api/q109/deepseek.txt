优先谈 **账期**，但要先明确一个前提：你谈的不是“越长越好”，而是把账期、配送、售后绑成一揽子条件来谈。如果只能先谈一项，顺序建议是：

1. **账期优先**
2. **配送次之**
3. **售后最后**

理由如下：

**1. 账期最值得优先谈**
- 水果是高频、易损耗、价格波动大的品类，现金流占用明显。
- 账期直接决定你的资金周转和议价空间，长期合作中影响最大。
- 但不要只谈“延长账期”，要同时谈清楚：结算周期、对账日、付款方式、逾期处理、是否影响单价。
- 如果供应商要求现款或短账期，可以用“稳定采购量、长期合作、缩短对账流程”换取更合理账期。

**2. 配送第二优先**
- 水果配送涉及时效、损耗、缺货补货，直接影响门店/业务运转。
- 重点谈：配送频率、截单时间、到货时间窗口、缺货替代规则、临时加单是否支持、配送费用和起送量。
- 配送条件谈不好，账期再长也会被损耗和断货吃掉利润。

**3. 售后最后谈，但不能不写进合同**
- 售后通常是在出问题后才有感知，优先级低于账期和配送。
- 重点明确：坏果/短斤少两/品质不达标的判定标准、赔付方式、补货时效、责任归属、照片或视频凭证要求。
- 售后条款要具体，避免“协商处理”这种模糊表述。

**建议的谈判策略：**
- 先谈**总量和合作稳定性**，再谈账期。
- 用“账期 + 配送 + 售后”打包交换，而不是单项硬压。
- 优先争取：**合理账期 + 稳定配送时效 + 明确坏果赔付标准**。
- 如果供应商账期很硬，就退一步争取：**缩短对账周期、部分品类账期、配送免费或优先补货**。

一句话结论：**优先谈账期，但把配送时效和售后赔付标准一起写进合作条件，单项谈账期容易留下后续扯皮空间。**
