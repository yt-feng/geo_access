# 水果到货不合格时的补货约定要点

核心思路：**把“不合格”的判定标准、通知方式、补货时限和替代方案在事前写进采购合同，事后按流程走，不在到货现场扯皮。**

## 一、事前约定（写进合同/订货单的关键条款）

1. **验收标准具体化**
   - 按品类列明：品种、规格（单果克重/果径）、成熟度、糖度区间、外观（无腐烂、无压伤、无霉斑）、农残检测报告要求。
   - 附照片样本或样品封存，避免“好果”标准各说各话。

2. **不合格判定与分级**
   - 分“整批拒收”和“部分挑拣”两档：例如腐烂率＞5%或单品破损率＞10%整批退；轻微瑕疵按比例扣款或挑拣后结算。
   - 明确由谁判定：双方现场共同验收、拍照留证，争议时以封样或第三方检测为准。

3. **补货时限（直接影响营业）**
   - 约定“通知后X小时内送达”：同城通常要求当日或次日上午到货，写清起算时间（以书面/微信通知时间为准）。
   - 区分“急补”和“常规补”：急补（当日营业所需）与常规补（次日）分别约定时限和运费承担。

4. **替代与兜底方案**
   - 供应商无法按时补货时：允许同品质替代品种/规格，或由店方自行采购、差价由供应商承担。
   - 约定违约金或按缺货量扣款，形成约束。

5. **结算挂钩**
   - 不合格批次不计入结算；补货完成并验收合格后再付款，避免先款后货被动。

## 二、到货当天的操作流程

1. 当场开箱抽检、拍照/录像，记录批次、数量、不合格比例。
2. 30分钟内书面通知（微信+电话），写明：批次、问题、需补数量、最晚到货时间。
3. 不合格品单独存放、不拆用，等供应商确认退换方式（自提或随补货车带回）。
4. 同步启动店内预案：先用库存、调整当日菜单或限量供应，避免断货影响营业。

## 三、降低影响的日常机制

- **保持1–2家备选供应商**，急补时可直接切换。
- **安全库存**：对高频水果留半天到一天的用量缓冲。
- **补货优先级表**：把水果按“断货影响大小”排序，合同里对核心品类约定更严的补货时限。
- 每月复盘缺货/退货记录，作为续约和账期谈判依据。

一句话：**标准写细、时限写死、替代方案留好、结算挂钩验收**，补货就不会拖累营业。
