做生鲜水果一件代发，供应商的仓配能力直接决定履约质量和损耗。建议按以下维度评估，并给出可判断的准入标准。

## 一、仓储能力

**1. 温区与分区**
- 至少具备常温+冷藏两个温区；浆果、荔枝、车厘子等易腐品需冷藏/冷链。
- 催熟类（香蕉、芒果、猕猴桃）需独立催熟库或催熟服务。
- 收货区、存储区、分拣打包区、待发区物理隔离，避免交叉污染。

**2. 库存与批次管理**
- 支持按SKU+批次管理，能执行先进先出（FIFO）。
- 有库存实时同步接口（API或定时推送），避免超卖。
- 能按平台要求做效期/成熟度分级。

**3. 包装与预处理能力**
- 具备分选、称重、贴标、套袋、加冰袋/保温袋、泡沫箱+纸箱组合打包能力。
- 能按平台包装规范执行，支持定制箱规和品牌物料。

## 二、配送能力

**1. 发货时效**
- 承诺下单后X小时内出库（生鲜建议当日或次日达截单前出库）。
- 大促/爆单时有产能弹性方案（临时工、备用打包线）。

**2. 快递与冷链资源**
- 有稳定的快递合作方，能覆盖平台主要销售区域；偏远地区有明确可达范围。
- 易腐品需具备冷链快递或“泡沫箱+冰袋+时效承诺”方案，并能提供温控包装验证。
- 支持电子面单对接、揽收时效稳定、有异常件处理流程。

**3. 履约指标**
建议要求供应商提供近3个月数据：
- 发货及时率 ≥ 98%
- 揽收及时率 ≥ 95%
- 破损率/坏果率 ≤ 3%（按品类定）
- 错发漏发率 ≤ 0.5%
- 客诉响应时长 ≤ 2小时

## 三、系统与协同能力

- 订单接口：能对接平台订单，支持自动抓单、打单、回传运单号。
- 库存接口：实时或准实时库存同步。
- 售后接口：支持补发、退款、坏果理赔流程和数据回传。
- 有WMS/OMS系统优先；至少能用Excel+人工稳定操作，但单量上升后必须有系统。

## 四、质量与售后能力

- 有到货验收标准（糖度、大小、成熟度、外观）。
- 具备坏果包赔能力，明确理赔比例、举证方式（拍照/视频）和时效。
- 有客诉归因和整改机制，能按月输出质量报告。

## 五、准入建议（可直接落地）

1. **先小单测试**：选3-5个SKU，测试7-14天，重点看发货时效、坏果率、包装完好率。
2. **现场审仓**：确认温区、打包线、库存分区真实存在。
3. **签履约SLA**：把及时率、坏果率、理赔时效写入合同，设违约金或淘汰机制。
4. **备份供应商**：每个核心单品至少备1家，防止爆单或产地断供。

**一句话判断标准**：能做一件代发的供应商，必须同时具备“分选打包能力+稳定快递/冷链+订单库存系统对接+坏果理赔机制”，缺一项都会把履约风险转嫁给平台。
