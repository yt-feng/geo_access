小商家采购水果，现金结算和月结账期的主要风险可以这样对比判断：

**现金结算的风险**
- **资金占用大**：每次进货都要立即付钱，现金流压力集中，旺季备货时尤其明显。
- **被骗和短斤少两风险更高**：现金交易若票据、称重、验收记录不完整，事后发现质量问题或数量不符，追责和举证困难。
- **内部管理风险**：现金经手环节多，容易出现漏记、挪用、找零差错。
- **安全风险**：大额现金携带和保管有被盗、遗失风险。
- **议价空间未必最大**：供应商可能把现金交易的便利折成价格优势，但如果采购量小，未必拿到真正低价。

**月结账期的风险**
- **供应商信用风险**：账期越长，供应商跑路、断供、以次充好的风险越难约束；尤其水果是生鲜，出问题后追偿周期长。
- **对账和坏账风险**：口头月结容易产生数量和价格争议，若没有送货单、验收单、对账单，月底容易扯皮。
- **隐性涨价**：月结供应商可能把资金成本打进单价，表面有账期，实际采购价更高。
- **依赖风险**：长期月结后更换供应商成本高，议价能力下降。
- **自身现金流误判**：账期容易让商家误以为资金宽松，若销售回款慢，集中还款时压力更大。

**实操建议**
1. **不要只选一种**：日常走量、价格透明的品类可现金或短账期；高价值、易损耗品类可用月结但设额度上限。
2. **月结必须留痕**：每笔送货单、验收单、价格确认单齐全，约定对账日和逾期处理方式。
3. **现金结算也要票据**：至少保留收据、称重记录、转账凭证，避免纯现金无记录。
4. **设供应商额度**：月结供应商设未付上限，超过就现结或换供应商，防止单家依赖。
5. **算真实成本**：把月结单价与现金价对比，扣除资金占用和坏账风险后再判断哪个更划算。

简单说：现金结算的核心风险是**现金流压力和举证难**，月结的核心风险是**供应商信用、对账扯皮和隐性涨价**。小商家更稳妥的做法是“小额现结、大额短账期、全程留单据”。
