可以，但先提醒：水果促销别只做“打包一口价”硬塞组合。香蕉、菠萝、苹果的客单价提升，重点不是让顾客多买一个不常买的水果，而是让顾客**一次买更多、买更顺、搭配到具体场景**。

建议按三个层次做，直接可执行：

**1. 场景组合：按“吃法/用途”卖，不按水果品类堆**
- **早餐组合**：香蕉 + 苹果，主打“一周早餐水果”。建议 2 斤香蕉 + 3 个苹果，组合价比单买低 10%—15%。香蕉熟得快，顾客容易一次买多，正好拉高件数。
- **家庭果盘组合**：苹果 + 菠萝，主打“周末果盘/待客”。菠萝切好或附切菠萝服务，苹果选 3—4 个装。组合价略低于单买，但提升客单靠“件数+加工服务”。
- **清爽饮品组合**：菠萝 + 苹果，配“榨汁/煮水果茶”小标签，可加 1 根香蕉做奶昔场景。适合年轻顾客，组合价不必最低，靠场景说明提升购买意愿。

**2. 阶梯促销：让顾客自然从单品转向组合**
- 单买：原价。
- 任选 2 样组合：9.5 折。
- 三样全带组合：8.8 折或送小份试吃/切片盒。
- 满 39 元加 3 元换购一根香蕉或小盒菠萝。
注意折扣别全打在香蕉上：香蕉单价低、毛利薄，适合做引流，不适合做主力折扣。菠萝和苹果承担客单和毛利。

**3. 陈列与话术比折扣更重要**
- 把香蕉、菠萝、苹果放在同一端头，做“早餐一周”“周末果盘”“办公室下午茶”三个小场景牌。
- 组合装用透明盒/网袋，标清“适合几人吃、几天吃完”，减少顾客怕买多吃不完的顾虑。
- 菠萝提供免费切块或去皮服务，苹果做大小分级，香蕉做“青/黄/熟”分档，让组合看起来是“省事”，不是“清库存”。
- 收银台再做加购：买组合装后加 2 元换购香蕉一根或苹果一个，提升二次加购率。

**不建议的做法**：三样等量硬打包、组合价明显高于顾客心理预期、把快熟香蕉大量塞进组合。这样短期能清货，但复购和客单都会掉。

**判断标准**：促销后看三个数——组合装占比、客单价、香蕉损耗率。如果客单价涨了但香蕉损耗也明显涨，说明组合里香蕉放多了，应改为“香蕉引流、苹果菠萝做利润”。
