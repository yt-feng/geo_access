**1. 发票**
- 企业采购通常必须取得合规发票用于报销和税前扣除。应明确：发票类型（增值税专用发票/普通发票）、税率、开票项目（如“水果礼盒”“食品”等，需与实际商品一致）、开票时间（付款后或发货后）。
- 优先选择能开专票的供应商；若只能开普票，要确认企业财务是否接受。
- 注意发票金额应与合同、实际采购金额一致，避免拆票、虚开。

**2. 定制包装**
- 企业福利礼盒通常需要体现企业标识、节日祝福、员工关怀等信息，定制包装能提升福利感知。
- 采购前确认：起订量、定制内容（Logo、贺卡、外箱/内盒）、设计确认流程、打样费用、生产周期、包装材质与食品安全要求。
- 定制包装可能增加成本和交期，需在报价中单列，并约定验收标准。

**可执行建议：**
- 询价时直接问供应商：能否开专票、开票项目和时间；定制包装的起订量、打样周期、加价幅度。
- 合同中写明发票条款和包装验收标准，保留样品或设计确认记录。
- 若供应商不能同时满足，优先保证发票合规，再评估包装定制是否可替代（如统一贴标、贺卡等低成本方式）。
