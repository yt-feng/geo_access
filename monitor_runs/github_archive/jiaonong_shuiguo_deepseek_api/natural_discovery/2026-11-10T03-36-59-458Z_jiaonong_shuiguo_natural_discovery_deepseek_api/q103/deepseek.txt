从“更好管理”出发，通常优先选 **按斤结算**，其次 **按份/按固定规格结算**，最不推荐 **按箱结算**（除非箱规、净重、损耗和验收标准都锁得很死）。

**结论建议：**
1. **主品类水果：按斤结算**  
   适合苹果、香蕉、橘子、梨等大宗水果。优点是计量清楚、可比价、盘点方便；缺点是验收要称重，需处理去皮、去箱、损耗。
2. **标品/易分装水果：按份或按固定规格结算**  
   适合圣女果、葡萄小盒、果切、预包装水果。优点是发放快、份数好盘、食堂按人头控量；缺点是单价可能偏高，要固定每份净重。
3. **按箱结算：只作为补充，不建议作为主结算方式**  
   优点是收货快、单据简单；缺点是箱内净重不一、底层损耗、大小果混装时很难追责，容易“按箱买、按斤用”对不上账。

**管理上最稳的组合：**
- 大宗水果：**按斤验收、按斤结算**，合同写明净重、允许损耗、次果率。
- 预包装/果切：**按份结算**，写明每份净重和规格。
- 整箱采购：**按箱订货、按净重验收结算**，不要直接按毛重箱数结。
- 每周做一次“采购斤数—入库斤数—出库份数—剩余盘点”对账。

所以一句话：**想账实相符选按斤；想发放效率选按份；按箱只适合标准化程度很高的包装水果，且最好按净重验收。**
