优先关注**成熟度**，价格排第二。原因很直接：香蕉成熟度会同时决定蛋糕的**风味、甜度、含水量、组织结构稳定性和出品一致性**，而价格只影响成本。

### 采购判断建议
1. **做香蕉蛋糕/香蕉磅蛋糕**：优先选**表皮黄、带少量褐斑、果肉软但有弹性**的香蕉。  
   - 太青：香气弱、淀粉多、甜度低，蛋糕风味不足，还可能有涩味。
   - 过熟发黑、果肉流汁：甜度和香气强，但含水量高、易发酵，配方需调整，且品控不稳定。
2. **需要稳定出品**：不要只看“便宜”，要按成熟度分档采购，并固定使用同一成熟阶段的香蕉。  
   - 建议采购标准写成：**黄色为主、褐斑少量、无破损、无霉变、果肉软糯不流汁**。
3. **价格低但成熟度不合适的香蕉**：  
   - 太青的可以后熟，但要预留时间，且批次差异大。  
   - 过熟或破损的只适合当天处理，不适合作为常规原料，除非你有能力调整配方和损耗。
4. **成本控制方式**：不是牺牲成熟度买低价，而是通过**按需分批采购、与供应商约定成熟度、利用后熟管理**来降本。

**结论：先定成熟度标准，再在合格批次里比价格。** 成熟度不合格的低价香蕉，最终会以风味差、损耗高、批次不稳定和配方难调的形式把成本还回来。
