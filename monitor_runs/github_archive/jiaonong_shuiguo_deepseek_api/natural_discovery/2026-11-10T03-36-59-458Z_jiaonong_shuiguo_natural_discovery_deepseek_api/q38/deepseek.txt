大型超市的水果供应商，必须同时具备“食品安全合规能力”和“冷链物流交付能力”。下面按超市通常会验厂、验资质、看实际运营的维度列出可执行清单。

## 一、食品安全能力

### 1. 主体与许可资质
- 营业执照、食品经营许可证/食品生产许可证（按实际业态）
- 食用农产品销售者应建立进货查验记录；供应商需能提供产地证明、购货凭证、合格证明文件
- 若涉及进口水果：海关报关单、入境货物检验检疫证明、中文标签
- 若涉及分装、切果、预包装：相应生产许可或经营许可，包装标签合规

### 2. 源头与基地管理
- 种植基地备案或合作协议，农药、化肥使用记录
- 农药残留自检或委托检测报告，按品种和季节有检测频次
- 重金属、保鲜剂、催熟剂等风险项目按超市要求检测
- 可追溯体系：批次号能关联到产地、采收日期、加工日期、检测报告

### 3. 验收与检测
- 每批次随货提供合格证明或检测报告
- 具备农残快检能力或固定第三方检测合作
- 不合格品隔离、召回、销毁记录
- 配合超市抽检、飞行检查和不合格处理机制

### 4. 仓储与加工卫生
- 仓库防鼠、防虫、防潮、防交叉污染
- 冷藏库温湿度监控和记录
- 分拣、包装区域清洁消毒记录
- 人员健康证、更衣洗手、手套口罩等卫生管理
- 周转筐、托盘、刀具、包装材料清洁和食品安全合规

### 5. 体系与记录
- 食品安全管理制度、岗位责任、培训记录
- 进货查验、销售记录、不合格品处置、投诉处理记录
- 有ISO22000、HACCP、GAP、BRC等认证会加分，但不是唯一门槛
- 食品安全责任险视超市要求

## 二、物流与交付能力

### 1. 冷链能力
- 冷藏车/保温车数量与温控记录，车厢预冷和清洗消毒
- 运输温度按品类控制，如多数鲜果2–8℃或按品类要求，热带水果防冷害
- 全程温度记录可导出、可追溯
- 冷链断链应急预案

### 2. 仓储与配送
- 产地仓/销地仓/中转仓布局，距门店配送半径合理
- 按SKU分区分温储存，先进先出
- 订单履约能力：日配、隔日配、节假日保供
- 门店收货预约、卸货、周转筐回收流程

### 3. 时效与损耗控制
- 采收、预冷、分拣、装车时效
- 损耗率指标和原因分析
- 缺货率、准时率、破损率、温度合格率等KPI
- 异常天气、交通、旺季爆单的保供预案

### 4. 信息化与追溯
- 订单、库存、批次、温度、检测报告可系统关联
- 支持超市系统对接或至少提供电子化单据
- 批次追溯能在约定时间内完成正反向追踪

### 5. 门店服务与售后
- 门店陈列建议、催熟/保鲜指导
- 质量问题快速响应、退换货、补偿机制
- 临期、滞销、破损处理方案
- 配合超市促销、堆头、节日备货

## 三、超市验厂时重点看什么
1. 证照和检测报告是否齐全、批次可对应
2. 仓库和冷链现场是否与记录一致
3. 农残快检或第三方检测是否真实执行
4. 批次追溯能否现场演示
5. 冷藏车温度记录能否导出
6. 不合格品和投诉处理是否有闭环
7. 旺季保供和断链应急预案是否可执行

## 四、最低可执行门槛
如果概括成“必须项”，至少包括：
- 合法主体和食品经营/生产资质
- 进货查验、产地证明、合格证明、批次追溯
- 农残检测能力和不合格处置
- 符合品类要求的冷链运输与仓储
- 温度记录、清洗消毒、人员健康管理
- 准时配送、损耗控制、质量售后响应

不同超市、不同水果品类要求会有差异，例如进口水果、切果、有机水果、地理标志产品会额外增加证照和检测要求。实际合作前应以超市供应商准入标准和合同附件为准。
