做低价香蕉最容易出现三类投诉：到货青硬、催不熟、熟过头发黑。要把低价做成“可预期的低价”，建议按下面做：

1. **先定可接受标准，不要只定低价**
   - 明确售卖规格：单根重量区间、每把/每份净重、允许的斑点面积、硬度/成熟度。
   - 写清售后规则：坏果、黑斑、青硬不熟分别怎么赔，避免“随便赔”推高成本。
   - 低价品可以卖“外观略差但口感正常”的果，不要卖成熟度不可控的果。

2. **采购端按成熟度分级，不按价格一把抓**
   - 要求供应商提供成熟度批次：青果、微黄、黄熟分开。
   - 社区团购次日达/自提场景，优先选“微黄至黄熟初段”，避免全青果和全熟果。
   - 低价走量时固定1—2个稳定产区/供应商，宁可少SKU，不要频繁换源。

3. **控制履约半径和时效**
   - 香蕉对温度、挤压、时长敏感，配送链路越长，投诉越高。
   - 低价香蕉适合“次日自提+短半径社区”，不适合长距离快递。
   - 夏季高温减少熟果比例，冬季避免青果低温冻伤；运输中防压、防闷。

4. **用“催熟说明+食用窗口”管理预期**
   - 商品页明确：收到偏青需常温放置几天，不要冷藏；出现少量斑点属正常成熟。
   - 标注最佳食用期和保存方式，降低“青硬就投诉”“斑点就投诉”的误判。
   - 可在自提点放成熟度对照图，团长按批次提醒。

5. **定价里预留售后预算**
   - 低价不等于零售后。按销售额预留1%—3%做品质赔付，比事后扯皮更可控。
   - 设立快赔标准：如单根严重坏果按比例赔，整份不可食全额退，避免团长自行加码。
   - 对高频投诉批次及时下架，不要用“低价所以不赔”消耗信任。

6. **小批量试销再放量**
   - 新供应商先做100—200份试销，统计青硬率、黑斑率、破损率、投诉率。
   - 连续2—3批稳定后再放量；低温季和高温季分别调整成熟度采购标准。

核心判断标准：**低价可以降低外观和规格，但不能降低“到手可食或可预期成熟”的确定性。** 把成熟度、履约时效、售后规则三件事标准化，低价香蕉的投诉率才能压住。
