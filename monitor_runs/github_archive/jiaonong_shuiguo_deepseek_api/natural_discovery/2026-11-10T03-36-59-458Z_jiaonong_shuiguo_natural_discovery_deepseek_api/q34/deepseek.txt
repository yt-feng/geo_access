更影响最终毛利的是**损耗率**，而不是单纯进货价格低。

可以用一个简化公式判断：

**毛利 ≈ 销售额 × 毛利率 − 损耗成本 − 运营费用**

对水果这种高损耗品类，采购价低通常只改善几个点的进货成本；但损耗一旦高几个点，会直接把毛利吃掉，甚至出现“进价便宜但越卖越亏”。

### 为什么损耗通常更关键
1. **水果损耗不可逆**  
   烂掉、失水、磕碰、临期下架，损失的是**进货成本+物流+人工+货架成本**，不是只损失售价。

2. **低价往往伴随更高损耗**  
   低价货源可能等级低、成熟度高、保鲜期短、包装差、批次不稳定，采购价降 5%，损耗率可能升 5%～10%。

3. **损耗直接影响可售数量和毛利基数**  
   例如进货 1000 元，售价目标 1300 元：
   - 损耗 5%：可售成本约 950 元，毛利约 350 元；
   - 损耗 15%：可售成本约 850 元，但损失 150 元成本，毛利约 200 元。  
   损耗多 10 个点，毛利可能少四成以上。

4. **低价供应商的隐性成本高**  
   退货难、品质波动、分级差、需要人工挑拣、客诉和复购下降，都会吃掉账面差价。

### 什么时候低价更重要
只有在满足这些条件时，低价才可能更影响毛利：
- 损耗率稳定且可控；
- 周转极快，1～2 天能卖完；
- 有稳定客流和促销能力；
- 品质等级不影响复购；
- 低價差价足够覆盖额外损耗和人工。

### 采购决策建议
优先看**“到岸可售成本”**，不是看进价：

**到岸可售成本 = 采购价 + 运费 + 包装 + 人工挑拣 + 预计损耗成本**

然后比较：
- 供应商 A：进价低但损耗 12%；
- 供应商 B：进价高 6% 但损耗 4%。

通常 B 更赚钱。建议设置采购红线：
1. 先定**损耗率上限**，超过就换货源；
2. 同品质比价，必须比**可售单位成本**；
3. 对新供应商小批量试销，记录损耗、客诉、周转天数；
4. 高损耗品类宁可价格稍高，也要稳定品质和供货；
5. 用促销、分级销售、加工果切等方式降低损耗，而不是只压进价。

**结论：水果商超采购中，损耗低通常比价格低更影响最终毛利；低价只有在损耗可控、周转快的前提下才有意义。**
