优先结论：**大多数生鲜电商先做“整果”为主线，切配做差异化增量，冷冻原料只适合特定场景/特定客群，不建议作为主推。**

按线上售卖适配度排序与判断要点：

1. **整果：最适合作为主销**
   - 优势：损耗相对可控、加工成本低、客诉点少、适合按重量/规格标准化；用户对“新鲜”感知强。
   - 关键风险：成熟度不一致、到货后过熟/黑心、重量争议。
   - 可执行建议：
     - 按规格分级卖（如单果重量段），明确“成熟度/食用建议”。
     - 预售+按成熟度分批发货，减少库存熟度风险。
     - 详情页写清品种、产地、甜度范围、催熟/保存方式、坏果赔付规则。

2. **切配：适合做高客单和差异化，但不要一开始铺太大**
   - 优势：即食便利、适合家庭/办公场景、可与果切组合提高客单；线上图片展示效果好。
   - 关键风险：保鲜期短、冷链要求高、微生物与氧化变色、破损渗漏客诉、损耗和退货成本高。
   - 可执行建议：
     - 只做“预订制/次日达/半日达”覆盖范围内，不做全国长链路。
     - 明确净含量、食用期限、冷藏条件；采用气调/真空或防氧化处理。
     - 先小范围测试复购和客诉，再扩SKU。

3. **冷冻原料：不建议作为生鲜电商主推，只适合B端或特定C端场景**
   - 优势：保质期长、损耗低、适合烘焙/饮品/餐饮供应链；B端复购稳定。
   - 关键风险：C端“生鲜心智”弱，解冻品质和口感争议；冷链干线成本高；小包装零售溢价难。
   - 可执行建议：
     - 若做C端，定位为“饮品/烘焙原料”而非鲜食水果，主打冷冻菠萝块/果泥。
     - 更优先走B端餐饮、茶饮、烘焙客户，或作为组合装里的补充品。

**决策建议：**
- 如果你是新店/中小生鲜电商：**70%资源做整果标准化，20%做切配预售测试，10%试冷冻原料B端**。
- 如果你有强冷链和即时配送能力：可提高切配占比，但仍以整果引流。
- 如果你有餐饮/茶饮渠道：冷冻原料可作为稳定利润品单独运营，不要混在C端鲜果主链路里。

一句话：**线上卖菠萝，整果负责规模与信任，切配负责便利与溢价，冷冻原料负责B端/长保质期补充；主推整果最稳。**
