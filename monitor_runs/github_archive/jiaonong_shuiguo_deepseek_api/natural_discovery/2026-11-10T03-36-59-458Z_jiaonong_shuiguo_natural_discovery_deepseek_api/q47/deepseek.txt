茶饮店用香蕉，采购熟度要按“到货熟度 + 使用节奏”分段控制，不能只按一个标准买。

**1. 采购熟度分档**
- **做奶昔、冰沙、果泥、香蕉牛奶**：优先采购**7～8成熟**，即果皮基本黄色、两头略带一点绿、捏起来有弹性但不软塌。到店后可放1～2天转熟，适合批量备货。
- **做香蕉甜品装饰、厚切果肉、芭菲顶料**：采购**8成熟**，果皮全黄、无黑斑、果肉成型，切片不易碎。
- **做香蕉泥、焦糖香蕉、香蕉酱**：可用**8～9成熟**，表皮有少量芝麻黑点，甜度高、香气足，但不适合再久放。
- **避免采购**：明显青绿、硬如石头的香蕉，催熟不均；大面积黑斑、果柄发黑、捏着出水或软烂的香蕉，损耗和异味风险高。

**2. 到货验收标准**
- 看：果皮颜色均匀，无大面积机械伤、裂口、霉点；果柄不发黑腐烂。
- 摸：整串软硬基本一致，轻捏有弹性；局部过软说明已过熟。
- 闻：有正常香蕉香气，无酸味、酒味、霉味。
- 抽检：每箱抽几个切开看，果肉无褐变、无异味。

**3. 控制采购量和节奏**
- 香蕉后熟快，建议**少量多次采购**，不要一次压太多库存。
- 按“今天用、明天用、后天转熟”分三批：**即用批、转熟批、备用批**。
- 夏季或高温天气缩短备货周期，香蕉转熟明显加快；冬季可适当多备一点。
- 门店日均用量波动大时，按**2～3天用量**采购较稳，避免熟度集中爆发。

**4. 到店后熟度管理**
- 未熟香蕉：常温、通风、避光存放，不要冷藏；需要加快转熟可与苹果同放密闭环境，但要每天检查。
- 已达使用熟度：优先使用，减少翻动和挤压。
- 过熟但未变质：尽快去皮、切段、冷冻，用于奶昔或果泥，避免继续恶化。
- 已软烂、有酒味或霉点：直接报废，不要用于饮品。

**5. 简单可执行规则**
- **采购标准：7～8成熟为主，8成熟少量搭配。**
- **验收标准：黄皮、有弹性、无黑斑腐烂。**
- **库存标准：2～3天用量，分批次到货。**
- **使用顺序：先熟先用，过熟转冷冻，变质报废。**

如果门店只做一款香蕉饮品，建议固定用**8成熟**香蕉，采购时要求供应商按“黄皮、微弹性、无黑斑”供货，到店后每天按软硬分拣，先软后硬使用。
