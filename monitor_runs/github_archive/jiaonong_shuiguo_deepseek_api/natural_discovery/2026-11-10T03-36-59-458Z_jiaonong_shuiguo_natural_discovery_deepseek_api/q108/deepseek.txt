建议按“资质文件→网络证据→小单实测→合同约束”四层核实，别只听口头承诺：

1. **要覆盖清单和证明文件**
   - 让供应商提供可配送省份/城市清单，注明是自营网点、合作仓还是第三方快递/冷链。
   - 索取冷链资质、仓储地址、合作物流合同或授权书（可遮挡敏感信息）。
   - 对“全国配送”追问：偏远地区、乡镇、县级市是否覆盖，时效和温控如何保证。

2. **用第三方信息交叉验证**
   - 查企业工商信息、经营异常、食品经营许可/冷链相关资质。
   - 要求提供近期发往不同区域的实际物流单号，抽查轨迹是否真实、是否冷链。
   - 地图搜索其声称的仓库/网点，核对地址是否真实存在。
   - 参考同行或客户案例，但要求可联系的脱敏案例，不轻信截图。

3. **小单实测，不要一次大单**
   - 选3—5个目标区域（含一个偏远或县级地址）下小批量试单。
   - 记录下单到签收时长、包装温控、果品损耗、异常处理速度。
   - 故意设置一次地址变更或售后问题，观察响应能力。

4. **合同写清可执行条款**
   - 明确覆盖区域、时效承诺、温控标准、破损/腐损赔付比例。
   - 约定“未覆盖区域须提前书面告知”，虚假覆盖的违约责任。
   - 保留试单记录作为验收依据，分批放量，设置考核期。

核心判断标准：**能提供可核验的物流轨迹和真实仓配地址，且小单在目标区域稳定履约，才算实际覆盖；只有口头“全国配送”不算。**
