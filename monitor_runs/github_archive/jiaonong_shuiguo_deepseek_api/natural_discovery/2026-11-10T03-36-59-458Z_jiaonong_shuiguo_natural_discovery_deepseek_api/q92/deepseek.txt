小店卖水果，关键不是“品类越全越好”，而是把水果当成高频引流品来控：**少SKU、快周转、按销量定采购、用分级定价吃掉损耗**。

可执行建议如下：

**1. 品类控制：先做“6+4”结构**
- 常驻6个左右高频刚需品：香蕉、苹果、橙/橘、葡萄、圣女果、梨。选耐放、认知高、无需教育的水果。
- 季节尝鲜4个以内：夏天西瓜/桃，冬天砂糖橘/草莓少量。每周最多换1—2个新品，不一次上太多。
- 单店水果SKU建议控制在8—12个，面积更小可压到6—8个。每个品类只留1—2个价格带，不做同质化堆叠。
- 明确“引流品+利润品+清货品”：香蕉/苹果做价格感知，葡萄/圣女果做毛利，临期品做特价清货。

**2. 采购量：按“日销×保质期”倒推**
- 易损耗品（草莓、葡萄、桃、切果）按1—1.5天销量采购；中等耐放（香蕉、柑橘、圣女果）按2—3天；耐放品（苹果、梨）按3—5天。
- 首单小批量试销：新品先拿最小包装/半箱，连续3天日销稳定再放大。
- 建立简单台账：每天记录进货量、销量、报废量、剩货量，按单品算“日销”和“损耗率”。连续3天卖不动的品直接停采或减半。
- 采购频率优先“少拿多次”，宁可补货也不压库存。供应商能拆箱、小批量配送的优先合作。

**3. 陈列与库存：小面积做“少量满排”**
- 陈列量控制在当日销量的1—1.5倍，排面满但不堆高，避免底层压伤。
- 香蕉、苹果、柑橘常温通风；葡萄、草莓、切果冷藏；易压伤水果不要叠放超过2层。
- 每天早晚两次挑拣，把轻微瑕疵品立即转到特价筐，不要等烂了再处理。
- 先进先出，新货放后排，旧货前置。

**4. 损耗处理：分级定价，当天清**
- 设“正价区+特价区”：外观瑕疵但可食用的，当天打折清，别拖到第二天。
- 香蕉、苹果等可做切果盒/果切，但果切必须冷藏、当天售完，且要符合当地食品经营要求。
- 晚上固定时段做“临期特价”，用小份装降低顾客决策成本。
- 设定损耗红线：水果整体损耗率控制在5%—8%较合理，易损耗单品单独盯；超过红线就减采购量或换品。

**5. 供应商与补货机制**
- 固定1—2家能小批量、频率高、退换货配合的供应商，谈好“次品可换/可退”。
- 每天下午根据剩余库存和次日天气、周末/工作日调整次日订单：雨天、工作日减量，周末和节假日前适度加量。
- 不做长期囤货，不因“便宜”大量压易损品。

**一句话原则：小店水果赚的是周转钱，不是差价钱。品类少而稳，采购少而勤，瑕疵早分级，当天尽量清。**
