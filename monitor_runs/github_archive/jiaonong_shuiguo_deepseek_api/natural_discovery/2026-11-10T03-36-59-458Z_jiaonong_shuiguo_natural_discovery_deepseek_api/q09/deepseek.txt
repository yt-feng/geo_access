旺季谈供应，核心是把“能不能稳定供、断货怎么办、价格怎么锁”三件事提前说清楚。建议按下面几组问题问，边问边记进合作条款。

**一、供应能力**
1. 旺季每天/每周能稳定给我供多少量？最低保供量能不能写进合同？
2. 你们主要从哪些产地/基地拿货？遇到产地减产、天气灾害，备选货源是什么？
3. 我的品类里，哪些是你们强项、哪些需要外调？外调货的品质和时效怎么保证？
4. 旺季你们的其他客户也在抢货，我的订单优先级怎么排？

**二、断货与应急**
5. 如果我下的量超过你的保供量，提前几天通知你能备到？
6. 出现断货时，提前多久通知我？有没有替代品种或替代规格？
7. 断货、迟到的违约责任怎么定？是按缺货金额赔偿，还是补货、返点？
8. 临时加单、改单的截止时间是几点？当天加单能不能次日到？

**三、价格与结算**
9. 旺季价格怎么定？是随行就市、锁价，还是设价格上限/浮动区间？
10. 涨价提前几天通知？能不能约定“涨幅不超过X%”或“超出部分双方分担”？
11. 账期怎么算？现结、周结还是月结？有没有旺季临时调账期的空间？
12. 运费、损耗、装卸费谁承担？到店价还是产地价？

**四、品质与验收**
13. 规格、等级、成熟度、瑕疵率的标准是什么？能不能样品封存？
14. 到货验收不合格怎么处理？拒收、换货还是折价？损耗率超过多少算供应商责任？
15. 冷链/保鲜条件怎么保证？运输途中坏果谁赔？

**五、合作保障**
16. 能不能签旺季保供协议，明确保供量、价格机制、违约条款？
17. 要不要交履约保证金？我不交、你不交，靠什么约束？
18. 结算周期内如果我销量波动大，能不能设阶梯返利或超额奖励？
19. 出现质量或断货纠纷，多久内响应、多久内解决？

**谈的时候注意三点：**
- 所有口头承诺落到书面：保供量、价格上限、通知时限、违约责任，写进合同或补充协议。
- 别只谈一家：旺季至少备一个第二供应商，哪怕量小，关键时能顶。
- 先小单试供：旺季前用2—3周小批量跑一遍，看准时率、损耗率、售后响应，再放量。

一句话总结：问清“保供量、断货预案、价格机制、验收责任”四件事，并把它们写进合同，比单纯压价更重要。
