如果是社区团购，水果供应商不只要“供货”，更关键的是要能配合你控制损耗、履约稳定、售后清晰。建议重点看这些服务和支持，签合作前逐项确认：

1. **稳定供货与分级**
   - 能否按你的团购量稳定供货，旺季、节假日不随意断货。
   - 水果能否按规格分级，比如大小、甜度、成熟度、瑕疵率，避免“图片好看、到货参差”。
   - 是否支持小批量、多频次补货，社区团购通常怕一次压太多货。

2. **预售与按单配货**
   - 支持你晚上截单、第二天早上配货的模式。
   - 能按订单分拣、贴团购标签、按小区或团长分袋。
   - 是否支持临时加减单，以及截单后调整的截止时间。

3. **配送时效与到货方式**
   - 能否送到你店里、小区自提点或团长指定点。
   - 配送时间是否稳定，最好能在居民取货前到货。
   - 是否支持冷链或保温运输，尤其是浆果、荔枝、葡萄、切果类。
   - 破损、压伤、漏汁的包装责任怎么算。

4. **损耗与售后政策**
   - 到货坏果率标准是多少，超过部分怎么赔。
   - 是补货、退款还是按比例扣款，处理时限多长。
   - 居民拿回家后才发现坏果，供应商认不认，需要什么凭证。
   - 建议明确：坏果包赔范围、拍照要求、当日或次日处理。

5. **价格与账期**
   - 团购价是否含配送、分拣、包装费用。
   - 价格有效期多长，是否随行就市，涨价提前多久通知。
   - 是否支持按批次结算、周结或月结，押金和起订量多少。
   - 促销款、引流款能否给专属供货价。

6. **包装与物料支持**
   - 是否提供统一果袋、标签、箱筐、冰袋、吸水纸等。
   - 能否印团长信息、售后二维码、团购说明。
   - 包装是否适合小区自提，避免散装难分发。

7. **选品与上新支持**
   - 能否按季节给选品建议，提供爆款、引流款、利润款组合。
   - 是否提供产地、口感、保存方法、催熟提示等素材。
   - 能否小量试销新品，不好卖可否退换。

8. **质量与安全**
   - 能否提供农残检测或进货凭证，至少能追溯到批次。
   - 对进口水果、切果、预包装水果，资质和标签要齐全。
   - 出现食品安全问题时，责任和赔付机制要写清。

9. **退换货与临期处理**
   - 未售完或品质下降的水果能否调换。
   - 临期果、尾货是否有折价处理或回收机制。
   - 不建议接受“只换不退”“坏果超过比例才赔”这类模糊条款。

10. **系统与对账支持**
   - 能否按你的订单表配货，支持Excel/微信群/小程序订单导入。
   - 每批提供送货单、品名、规格、数量、单价、金额。
   - 对账是否清晰，差异能否当天核对。

**签合作前最该确认的5件事：**
- 坏果赔付标准和时限；
- 截单后能否改单；
- 配送迟到怎么处理；
- 起订量、配送费、包装费是否另收；
- 价格调整提前通知时间。

**建议做法：**先小批量试合作2—3周，重点试叶菜类不适用，水果里选草莓/葡萄/荔枝等高损耗品和苹果/橙子等耐储品各一款，观察到货品质、坏果率、配送准时率和售后响应。合作稳定后再谈账期和专属价。
