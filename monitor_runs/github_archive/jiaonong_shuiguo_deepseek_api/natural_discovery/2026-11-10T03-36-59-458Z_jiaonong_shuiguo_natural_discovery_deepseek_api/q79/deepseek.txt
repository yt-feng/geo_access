最应该先问**售后**。配送和价格都重要，但售后规则决定你亏不亏、会不会被团员追着赔。

按优先级和要问的关键点：

1. **售后（先问，写清楚）**
   - 坏果、烂果、压伤、少重、错发怎么赔：按颗赔、按斤赔、还是整单补发？
   - 报损时限：收货后几小时内报？要不要拍照/视频？超过时限还认不认？
   - 赔付形式：现金退、下次抵扣、还是补发？补发运费谁出？
   - 损耗率承诺：比如“坏果率超过5%整批处理”能不能写进合作约定。
   - 生鲜波动大，售后不清楚，价格再低也可能被理赔吃掉利润。

2. **配送（第二问，决定体验和复购）**
   - 到团时间是否固定，误差多大；迟到怎么处理。
   - 是否送到自提点/团长指定点，卸货谁负责，是否分拣打包。
   - 破损、挤压谁承担；临时改量、加单截止时间。
   - 冷链水果是否有保温/冰袋，夏天怎么保证。

3. **价格（第三问，但要会算）**
   - 不要只问单价，问**到团价**：含不含运费、分拣费、包装费、损耗补贴。
   - 起订量、阶梯价、结算方式（现结/账期）、调价规则。
   - 用“到手成本+预估售后损失”比较，而不是只看报价低。

**实操建议：**先让供应商给出书面售后规则和配送时效承诺，再拿2—3家同品类报价做对比。首次合作先小批量试团，重点看坏果率和报损响应速度，别一上来压大单。
