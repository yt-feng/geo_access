判断供应商能不能按时到车，重点不是听口头保证，而是看“可验证的证据 + 历史履约 + 违约成本”。可以按下面几步做：

1. **先看历史履约记录**
   - 问对方最近30天同类线路发车记录：发车时间、到车时间、延误次数、延误原因。
   - 优先选合作过2—3次都准时的供应商；新供应商只给小单试。
   - 让供应商提供近期车牌号和司机电话，侧面核实是否真实发车。

2. **确认“车”是否已经落实**
   - 问清楚：是自有车、合同车队还是临时调车。
   - 临时调车最容易放鸽子。要求提供车牌号、司机姓名电话、装车地点、预计装车时间。
   - 发车前2—4小时再确认一次：车到没到装货点、装了多少、几点能上高速。

3. **把时间节点写进订单**
   - 不要只写“明天到”，要写：装车时间、发车时间、预计到车时间、最晚到车时间。
   - 约定延误处理：超几小时扣款/补差价/承担压车费/取消订单。
   - 香蕉是易熟品，必须约定成熟度、温度、通风和到车后验收标准。

4. **看供应商的履约能力**
   - 旺季、节假日、天气异常时，问备用车方案。
   - 问清楚装货点是否固定、是否要排队、是否受产地降雨影响。
   - 供应商同时接很多单却车少，风险高。

5. **用付款方式控风险**
   - 新供应商尽量少定金、货到验收后付尾款，或走可追踪的担保交易。
   - 不要因为“便宜几毛钱”放松到车时间约束，香蕉晚到一天损耗可能远大于差价。

6. **到车前做预警**
   - 到车前一天确认一次，发车前确认一次，上高速后要定位/司机电话确认一次。
   - 若供应商反复改口、不给车牌、不让联系司机、只说“放心”，基本可判定风险较高。

**简单判断标准：**
- 能给车牌、司机电话、装车视频/照片、历史准时记录，且愿意写延误责任的，可信度较高。
- 只给低价、催定金、不给车信息、时间含糊的，不要下大单。

**建议动作：** 第一单控制在半天到一天销量，要求“装车后付部分、到车验收后付尾款”，并保留聊天记录和订单约定。这样即使延误，损失也可控。
