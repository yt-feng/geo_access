核心是**按“计划吃的日期”选熟度**，别只看香蕉外表。

1. **先定吃的时间**  
   - 当天/明天吃：选**通体偏黄、少量芝麻黑点**的。  
   - 2～3天后吃：选**黄中带一点青肩**（两头或棱线略青）的。  
   - 3～5天后吃：选**整体偏青、但已开始转黄**的。  
   - 想放更久：选**青绿、硬实、无黑点**的，回家常温分开放。

2. **到店快速判断**  
   - **太生**：整体青绿、棱角明显、手感很硬，通常还要很多天。  
   - **刚好**：黄色均匀、略有弹性、闻起来有香蕉香。  
   - **太熟**：大面积黑斑、手感软塌、果柄发黑或渗汁，适合当天吃或做奶昔。  
   - **避开**：表皮破损、发霉、局部凹陷流水、整串有酒精味。

3. **采购小技巧**  
   - 买**整串偏青一点**的，回家室温放，别马上冷藏；熟到理想状态再吃，吃不完再冷藏延缓。  
   - 如果超市允许，**挑整串里熟度最均匀的**，不要选一串里一半黑一半青的。  
   - 不要买已经碰伤、压软的，即使看起来黄，也容易提前烂。  
   - 一次别买太多：香蕉释放乙烯，整串会一起熟，按家里2～3天消耗量买最稳。
