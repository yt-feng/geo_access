连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是“价格机制、质量标准、损耗归属、账期返利、断供赔偿”五类条款。建议重点盯以下几处：

1. **价格与调价机制**
   - 坑：只写“随行就市”或“参考市场价”，没有定价基准、调价周期、审批流程。
   - 建议：明确基准价来源（如某批发市场均价/双方确认价）、调价频率（周/月）、触发幅度（涨跌超5%才调）、书面确认方式。年度合同最好设价格上限或封顶涨幅。

2. **质量标准与验收**
   - 坑：只写“符合国家标准”，水果实际按等级、糖度、大小、新鲜度验收，标准模糊必扯皮。
   - 建议：附《质量验收标准表》，按品类写清等级、规格、糖度、农残检测、到货温度、外观缺陷率；明确抽检比例、验收时限、不合格处理（拒收/折价/换货）和检测费用承担。

3. **损耗与退换货归属**
   - 坑：到店后损耗谁承担没写清，供应商把“离柜概不负责”写进合同。
   - 建议：分环节约定：运输途中损耗归供应商；验收合格前归供应商；验收后超市承担。临期、变质、农残不合格必须无条件退换，并约定响应时限和运费承担。

4. **账期、返利与费用**
   - 坑：口头承诺返利、进场费、促销费，合同只写账期；返利计算基数不清（含税/不含税、退货后是否扣减）。
   - 建议：所有费用写进合同附件，明确返利基数、结算周期、支付方式；账期与逾期付款违约金对等；退货金额从返利基数中扣除要写清。

5. **供货保障与违约赔偿**
   - 坑：只写“保证供应”，没有断供违约金；旺季涨价断供，超市无救济。
   - 建议：约定最低供货量/备货比例、断供提前通知期、违约金计算方式（如按缺口金额比例），并保留替代采购差价索赔权。同时给供应商合理免责情形（不可抗力、重大自然灾害）。

6. **年度合同与单次订单的关系**
   - 坑：年度合同写总量，实际按单订货，供应商以“未达采购量”要求补偿，或超市以“未足量供货”罚款，双方口径不一。
   - 建议：明确年度合同是框架协议，具体以订单为准；写清预估量不构成最低采购承诺，或设定最低采购量与未达量补偿机制，二者选一，别混写。

7. **食品安全与责任追溯**
   - 坑：农残、食安事故责任笼统写“由供应商负责”，但检测、追溯、召回流程缺失。
   - 建议：要求供应商提供每批次检测报告，约定食安事故的召回配合、赔偿范围（含消费者赔偿、行政处罚、商誉损失），并设质量保证金。

8. **合同期限与退出机制**
   - 坑：一年期合同没有中途解约条款，供应商质量下滑也换不掉。
   - 建议：设季度/半年考核指标（到货合格率、断供次数、投诉率），连续不达标可单方解约；明确解约后的库存处理、未结货款结算。

**实操建议**：把质量验收标准、费用清单、返利计算表、供货量预估表作为合同附件，正文只写机制和违约责任；所有口头承诺书面化；价格和损耗条款让采购、财务、门店运营三方会签后再定。
