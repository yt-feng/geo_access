判断“合理波动”不要只盯涨幅，建议用一套可核验的规则：

1. **先分品类定波动阈值**
   - 叶菜、浆果等易腐品：日波动5%—10%可视为正常，超过15%要问原因。
   - 苹果、柑橘、根茎类等耐储品：日波动3%—5%正常，超过10%要复核。
   - 进口或单一产地水果：受汇率、船期、产季影响，阈值可放宽，但要有对应证据。
   阈值应按自己历史采购数据校准，不要照搬。

2. **看“是否只对你涨”**
   同一天向2—3家供应商询同规格、同等级、同产地的货。若市场普遍涨，属系统性波动；只有一家涨，先怀疑报价策略。

3. **看成本驱动是否可验证**
   要求供应商说明涨价归因：产地收购价、天气、运输、燃油、包装、人工、汇率。能用产地日报、批发市场行情、物流报价佐证的，可信度更高；只给“最近贵了”这种口头解释，不算证据。

4. **看历史价格区间和频率**
   建立自己的价格台账：品名、规格、等级、产地、日期、单价、供应商。判断当前价处于近30/90天什么分位。偶发跳涨可接受，连续多日单边上涨或频繁“今天涨明天跌”要警惕。

5. **看合同和报价机制**
   优先约定：报价有效期、调价触发条件、提前通知期、同规格比价权、异常波动复核权。日报价可以接受，但应约定“单日超过X%需书面说明并双方确认后执行”。

6. **做小批量验证**
   对可疑报价先减量下单或拆分订单，观察实际到货质量、等级是否缩水。有时价格没涨，但规格、净重、损耗、账期变相涨价，要折算成“到岸可用的单位成本”比较。

7. **设置异常处理动作**
   - 波动在阈值内：按约执行，记录台账。
   - 超阈值但证据充分：接受，同步调整售价或菜单。
   - 超阈值且无证据：要求二次报价、启动备选供应商、暂缓大单。
   - 连续异常：重谈价格公式或更换供应商。

核心原则：**合理波动=可解释+可验证+可比较+可承受**。采购方要把“每天变”变成“按规则变”，而不是靠感觉判断。
