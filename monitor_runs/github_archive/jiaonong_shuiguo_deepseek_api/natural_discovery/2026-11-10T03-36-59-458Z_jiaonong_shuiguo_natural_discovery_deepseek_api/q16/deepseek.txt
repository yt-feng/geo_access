优先用稳定供应商做主供，本地批发做补货和试价，不要二选一。

**建议这样定：**
1. **香蕉：以稳定供应商为主。** 香蕉周转快、损耗高、成熟度难控，稳定供应商更能保证到货品质、规格和固定配送频次；本地批发适合临时补货、节假日加量或对比价格。
2. **苹果：可先本地批发试销，再逐步签稳定供应商。** 苹果相对耐储，适合先小批量看本地货源的价格、口感和客群接受度；销量稳定后，用稳定供应商锁品质和账期。
3. **社区超市的评判标准：** 看总成本，不只看进货价。把损耗率、到货合格率、缺货次数、账期、退换货、配送频次一起算。
4. **可执行做法：**
   - 前2周：香蕉稳定供应商主供，本地批发每周比价1次；苹果本地批发小批量试2—3个品种。
   - 设验收线：香蕉到货合格率低于95%或损耗明显偏高，换供应商；苹果本地批发若价格优势覆盖不了品质波动，转稳定供应商。
   - 保留一个本地批发备用渠道，防止主供断货。
5. **合同/口头约定要明确：** 固定配送日、最低起送量、坏果赔付、账期、临时加单响应时间。

一句话：**香蕉先稳供，苹果先试批；主供保稳定，本地批发保灵活和比价。**
