社区超市找“每天配送”的水果供应商，核心不是只看价格，而是看**日配稳定性、损耗可控、账期和退换机制**。建议按下面条件逐项筛：

1. **日配能力**
   - 是否每天固定时段送达，能否接受早市前到货；
   - 自有/固定冷链车数量，是否拼车配送；
   - 节假日、雨雪天、爆单时是否保供；
   - 最小起订量和临时加单截止时间。

2. **货源与品类稳定性**
   - 是否有稳定产地/一级批发市场档口，还是临时调货；
   - 常销品（苹果、香蕉、柑橘、梨、应季叶菜类水果）能否长期稳定供应；
   - 是否支持小批量多品类混配，适合社区店低库存高频补货；
   - 换季时能否提前给到替代品建议。

3. **品控与验收标准**
   - 明确等级、规格、成熟度、糖度、单果重、箱装净重；
   - 是否允许到货抽检、开箱验货、当场拒收；
   - 坏果率、短斤少两的处理标准；
   - 是否提供农残检测或产地证明（能提供更好，不能提供要明确）。

4. **损耗与退换**
   - 坏果、压伤、过熟是否包退换，时限是当天还是24小时内；
   - 退换是补货、折价还是冲抵货款；
   - 是否接受“卖不完/临期”少量调换，这一点对社区店很关键；
   - 退换响应速度，是否影响第二天配送。

5. **价格与账期**
   - 报价是否含运费、装卸费、箱皮/托盘费；
   - 是否随行就市每天报价，调价是否有提前通知；
   - 账期是现结、周结还是月结，押金和违约条款；
   - 对比时按“到店净重单价+损耗率”算，不要只比毛价。

6. **配送与交接**
   - 到货时间是否匹配开店/补货节奏；
   - 冷链温度、包装是否防压防潮；
   - 是否有固定对接人，缺货/迟到如何通知；
   - 卸货、上架是否协助，社区店人手少要问清。

7. **合规与风险**
   - 营业执照、食品经营/流通相关资质是否齐全；
   - 是否能开票；
   - 是否有食品安全责任约定；
   - 合作前先试配1—2周，重点看迟到率、坏果率、缺货率。

实操建议：先找2—3家试配，用一张表记录**到货准时率、验收合格率、缺货次数、退换响应、实际损耗**，两周后按数据定主供应商，再留一家备用。社区超市最怕单一供应商断供，主供+备供更稳。
