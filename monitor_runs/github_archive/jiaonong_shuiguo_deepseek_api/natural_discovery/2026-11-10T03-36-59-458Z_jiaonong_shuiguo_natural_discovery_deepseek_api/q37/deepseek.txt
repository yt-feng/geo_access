商超会员日水果活动，供应商要提前配合的重点是把“货、价、品质、陈列、履约、应急”六件事在活动前锁死。建议按以下清单准备：

## 1. 活动前确认与备货
- **确认活动方案**：品项、规格、会员价/促销价、限量规则、活动时段、门店范围、预计销量。
- **锁量锁价**：提前确认供货量、供货价、返利/费用承担、价格保护期，避免活动前涨价或断供。
- **备货计划**：按门店分货量、安全库存、日配送频次准备；重点单品备足1.2–1.5倍预估量，并预留补货仓。
- **产地/批次锁定**：提前锁定货源和采摘批次，避免临时换产地导致品质波动。

## 2. 品质与验收标准
- **明确验收标准**：糖度、果径、色泽、成熟度、新鲜度、瑕疵率、农残检测报告。
- **到货成熟度控制**：会员日集中销售，到货不宜过生或过熟；需按销售节奏分批到货。
- **预冷与包装**：冷链品提前预冷，包装规格与门店陈列、称重方式匹配，减少损耗。
- **质检文件**：合格证、检测报告、产地证明等随货或提前提交。

## 3. 价格与费用配合
- **促销价执行**：确认供货价与零售价联动，避免门店执行价与供应商结算价不一致。
- **费用分摊**：促销折扣、损耗、物料、临促人员等费用提前书面确认。
- **价格保护**：活动期间及前后价格稳定，防止周边门店或线上比价冲击。

## 4. 物流履约
- **配送排期**：按门店开门前、补货高峰前到货；明确到货时间窗和卸货要求。
- **分店分拣**：按门店订单分拣、贴标，减少门店二次分拣。
- **冷链保障**：运输温度记录、到货温度检测；易损品加防护包装。
- **补货机制**：活动日安排应急补货车辆和联系人，明确补货响应时限。

## 5. 陈列与物料
- **陈列支持**：提供陈列建议、堆头/端架方案、试吃样品。
- **促销物料**：价签、POP、试吃台、围裙、手套、包装袋等提前到位。
- **人员支持**：重点门店安排临促或供应商理货员，负责补货、挑拣、试吃。

## 6. 应急与售后
- **质量异常处理**：明确退换货、补货、折价处理时限和责任人。
- **断货预案**：替代品项、替代规格提前报备。
- **损耗承担**：活动后损耗、滞销库存的处理方式提前约定。
- **活动复盘**：销售、损耗、客诉数据活动后及时对账复盘。

**最关键的三个提前动作**：活动前7天锁量锁价并确认分店订单；活动前3天完成质检和物料到店；活动前1天完成首批到货和陈列试摆。
