连锁商超选长期水果供应商，评分标准要围绕“长期稳定供货”设计，不能只比价格。建议采用“资格门槛+综合评分”的结构，综合评分可参考以下框架（按100分制，可按企业实际调整权重）：

**一、先设资格门槛（不达标直接淘汰）**
- 营业执照、食品经营许可、种植/养殖基地证明或稳定采购渠道证明
- 近2年无重大食品安全事故、无严重失信记录
- 具备冷链运输与仓储能力（或稳定合作方）
- 能接受商超的账期、退换货、质量追溯和违约条款

**二、综合评分维度建议**

1. **产品质量与安全（25–30分）**
   - 农残/重金属检测报告、批次抽检合格率
   - 分级标准是否清晰（果径、糖度、外观、成熟度）
   - 追溯体系：能否追溯到批次、产地、采摘时间
   - 食品安全管理体系认证（如ISO22000、HACCP等，有则加分）

2. **供货稳定性与产能（20–25分）**
   - 自有基地或长期合作基地面积、年供应量
   - 对商超年度需求量的覆盖比例（建议要求可覆盖70%以上）
   - 淡旺季供应方案、极端天气/病虫害时的备货预案
   - 多产地布局或替代货源能力

3. **冷链与物流配送（15分）**
   - 冷链车辆数量、温控记录能力
   - 到店/到仓配送时效、覆盖门店范围
   - 破损率、损耗率承诺及历史数据
   - 应急补货响应时间

4. **价格与成本（15–20分）**
   - 报价合理性，不宜唯低价；可设“报价偏离基准价过高/过低均扣分”
   - 价格调整机制是否透明（如随产地行情联动，设涨跌幅上限）
   - 长期合作的价格优惠或返利方案
   - 包装、损耗、退换货等隐性成本是否清晰

5. **服务与履约能力（10–15分）**
   - 退换货响应时限与责任划分
   - 专职对接团队、问题处理时效
   - 配合商超促销、临时加单的能力
   - 历史合作客户评价或履约记录

6. **企业实力与可持续性（10分）**
   - 财务状况、抗风险能力
   - 种植/采购的可持续性（如环保、用工合规）
   - 长期合作意愿与合同履约保障（保证金、违约赔偿）

**三、几个关键设置建议**
- **价格分不宜过高**，建议不超过20分，避免低价中标后断供或降质。
- **设置“样品盲测+实地考察”环节**，把主观质量评价量化，如糖度、外观、口感打分。
- **设置履约保证金和阶梯违约条款**，尤其对断供、质量不达标、追溯造假。
- **要求投标方提供“年度供应保障方案”**，作为技术标核心内容评分。
- **评分表公开、评委独立打分、保留复核记录**，减少围标和人情分。

整体原则：**质量安全是底线，稳定供应是核心，价格是调节项**。长期供应商更应看“能不能持续稳定地供好货”，而不是“这一单谁最便宜”。
