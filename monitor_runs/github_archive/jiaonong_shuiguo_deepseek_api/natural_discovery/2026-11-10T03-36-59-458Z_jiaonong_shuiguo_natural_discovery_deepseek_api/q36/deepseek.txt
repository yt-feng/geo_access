结论：多数商超更适合“整果为主、鲜切为辅”，而不是主卖切好的。要不要上鲜切，取决于你门店客流结构、损耗管控和现场操作条件。

**为什么整果更适合做主销**
- 单价低、损耗可控：整果按个/斤卖，坏果可挑拣、降级处理，不像鲜切一旦氧化、出水、变质就直接报损。
- 毛利结构简单：整果毛利靠进销差，鲜切还要叠加人工、包装、冷链和损耗。
- 适合家庭采购：菠萝整果是家庭常规购买单位，尤其节庆、周末囤货场景。
- 操作门槛低：不需要专门切配间、消毒条件、专人现场操作。

**什么情况下鲜切值得做**
- 门店在写字楼、商圈、社区年轻客群集中，即时消费、单人份需求强。
- 已有成熟鲜切水果业务：有切配间、冷藏展示柜、稳定操作人员，能共用包装和冷链。
- 客流高峰能现场切配、快速周转，能做到“当天切当天清”。
- 鲜切只做小份试销，不压库存，按小时补货。

**建议的品类组合**
- 整果：主陈列，选1—2个主推品种，按个和按斤两种价签，方便不同客群。
- 鲜切：只做小盒装，放在冷藏柜靠近收银或水果区端头，限量试销。
- 不要大量预切：鲜切菠萝氧化快、出水多，预切多了报损率会明显上升。

**关键判断指标**
连续试销2—4周，看三个数：
1. 鲜切菠萝的日周转率：当天卖不完的比例超过20%，就不适合主推。
2. 鲜切报损率：高于整果报损率2倍以上，说明需求或操作跟不上。
3. 整果与鲜切的客单价、连带购买：鲜切是否带来额外客流，而不是抢整果销量。

**执行建议**
先按“整果主销+鲜切小份试销”跑一个月；鲜切只保留一个规格、一个价格带，放在冷藏柜显眼位置，标注切配时间。若鲜切日清率稳定在80%以上、报损可控，再逐步增加规格；否则回到整果为主。
