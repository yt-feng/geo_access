第一次试单，核心就三句话：**少量多批、先验稳定、再谈价格**。别一上来就压价或大批量拿货，夫妻店现金流和损耗都扛不住。

### 试单前的准备
1. **定好试单量**：每个单品先拿1—2箱（香蕉按件/把，苹果橙子按箱），够卖3—5天就行，不要一次进一周的量。
2. **明确验收标准**：跟供货商提前说清楚——香蕉要几成熟（比如7成熟，到店2—3天转黄）、苹果要什么规格（80/85果、果径均匀）、橙子要什么品种和酸度甜度预期，坏果率超过多少算不合格。
3. **问清结算和退换**：是否可退换坏果、退换时限（当天还是次日）、是否送货上门、起送量、账期还是现结。
4. **准备记录表**：记录每个单品的进货价、到货重量/数量、坏果数、售价、售罄天数。

### 试单时怎么操作
- **同一品类找2家供货商对比**，各拿少量，不要只试一家。比如香蕉A家、苹果B家，或者同品两家各拿半箱对比。
- **到货当场验**：开箱看底层、看果柄、摸硬度，香蕉看有没有黑斑和断指，橙子掂重量看是否干水，苹果看有没有碰伤和冷害。
- **当天上架试卖**：观察顾客反馈——香蕉转色速度、苹果脆度、橙子甜度，这些比进货价更能决定复购。
- **卖完再补**：第一次不要囤货，卖完一批再下第二批，连续试2—3轮再判断是否长期合作。

### 判断供货商是否靠谱
重点看四个指标：
1. **到货一致性**：两次货规格、成熟度是否稳定，忽好忽坏的不行。
2. **坏果率**：常见水果试单阶段控制在5%以内可接受，超过10%要谈或换。
3. **售后响应**：坏果是否痛快补换，推诿的别长期合作。
4. **送货准时**：水果店早市很关键，迟到影响当天销售。

### 价格怎么谈
第一次别急着要最低价，先问清楚**报价含不含配送、是否含税/开票、退换是否扣款**。试单稳定后再谈量价，比如"我每周稳定拿X件，能不能给个固定价或账期"。夫妻店的优势是现结、不拖账，可以拿这个换好货和优先配送。

### 避坑提醒
- 不押大额预付款，第一次尽量现结或少量定金。
- 不接受"整件不拆、坏果不包"的口头承诺，最好微信留文字记录。
- 香蕉别一次进太多，它是试单里损耗最快的品，先小量测转色和客流匹配度。
- 苹果橙子耐放，可以稍微多拿一点做主力，但也要看店内客流。

一句话总结：**每个单品小量试2—3轮，看坏果率、到货稳定性和售后，稳定后再放量和谈价。**
