生鲜水果坏果投诉的责任划分，核心看**坏果发生在哪个环节、是否可归责于商家、以及顾客是否及时举证**。可以按下面判断和操作：

**1. 先定责任的基本原则**
- **签收前/开箱即坏**：通常由商家或发货方承担。水果在运输中腐烂、压伤、冻伤、闷坏，属于商家履约质量问题。
- **顾客签收后因存放不当变坏**：一般由顾客承担。比如高温放置、未冷藏、堆放挤压、超过合理食用期。
- **运输破损但外包装完好、内部压伤**：商家先对顾客负责，再按合同向物流/供应商追偿，不能直接让顾客找快递。
- **顾客无及时验收或长期不取货**：责任可能转移或部分由顾客承担，尤其是生鲜自提柜/驿站超时存放。

**2. 商家通常应赔的情况**
- 到货开箱即有霉变、腐烂、异味、明显压伤；
- 坏果比例明显超出合理损耗；
- 商品与描述不符，如品种、规格、成熟度严重不符；
- 冷链断链、包装不当导致闷坏；
- 顾客在合理时间内拍照/视频举证。

**3. 顾客可能自担或部分自担的情况**
- 签收后数小时甚至隔天才反馈，且无开箱证据；
- 未按提示冷藏/避晒；
- 自行长时间存放导致过熟腐烂；
- 已切开、食用部分后才发现问题，难以判断原始状态；
- 特价临期果已明确告知瑕疵且顾客接受。

**4. 平台/商家处理建议**
- 建立**开箱验货时效**：如签收后24小时内反馈，附坏果和包装照片；
- 按**坏果比例赔付**，不要一律全赔或一律不赔；
- 对小额投诉优先**退款/补发**，降低举证和客服成本；
- 保留发货质检、冷链记录、物流签收记录，便于向供应商或物流追偿；
- 明确规则：生鲜不适用无理由退货，但质量问题仍应赔。

**5. 顾客维权建议**
- 到货立即开箱拍照/录视频，保留外包装和面单；
- 在平台规定时效内申请售后，说明坏果数量和比例；
- 先找商家/平台，不必自行找快递定责；
- 协商不成可向平台投诉或12315反映。

一句话：**签收时已坏或运输冷链导致坏的，商家担责；签收后因顾客存放不当坏的，顾客担责；责任不清时，商家先对顾客兜底，再向物流或供应商追偿。**
