批发档口要降低退货纠纷，验货环节的核心不是“看得仔细”，而是**把验收标准前移、把证据固定、把责任时点写清楚**。建议按下面做：

## 1. 收货前先定规则
- 在供货合同/订单里写明：质量验收标准、允许瑕疵范围、色差/尺寸误差、包装要求、到货后几小时内提异议、哪些情况不退换。
- 明确“签收≠验收”还是“签收即验收”，以及谁负责拆包验货。
- 对易争议品类（服装、鞋、生鲜、五金、电子）单独列验收清单。

## 2. 到货先做“外包装验收”
- 看外箱有无破损、水渍、挤压、二次封箱、封条异常。
- 有异常先拍照/录像，再决定是否签收；能拒收破损严重的直接拒收并留证。
- 不要先签“外包装完好”再拆出问题，否则责任容易扯皮。

## 3. 拆包验货固定证据
- 全程录像或至少关键节点拍照：外箱面单、封箱状态、拆包过程、货品整体、瑕疵特写、数量清点。
- 照片要能看出批次、货号、尺码/规格和问题位置，别只拍局部特写。
- 大批量抽检要有抽检记录：抽多少、合格多少、不合格项。

## 4. 按清单验，不凭感觉
建议每个档口做一张《到货验收单》，至少包含：
- 数量：总数、短装、多装
- 外观：破损、污渍、线头、划痕、变形
- 规格：尺码、颜色、型号、材质
- 功能：可试用的做基本功能测试
- 包装：吊牌、标签、配件、说明书是否齐全
- 批次一致性：是否与样品/上批货有明显差异

## 5. 发现问题当场分级处理
- **拒收**：外包装严重破损、货不对板、批量性质量问题。
- **当场记录并限期答复**：少量瑕疵、色差、短装，拍照后书面通知供货方，约定补发/折价/退货时限。
- **先收后验的品类**：约定“隐藏瑕疵”发现后多少小时内可提异议，避免拖太久。

## 6. 签字和台账要留痕
- 验收人、日期、批次、结论、异常处理方式都签字记录。
- 建立退货纠纷台账：问题类型、供货商、处理结果、复发次数。反复出问题的供货商要调整合作条件。
- 对下游客户也一样：发货前抽检、打包拍照，明确收货异议时限，减少“客户说有问题”时无据可查。

## 7. 最关键的三句话
- **标准写进订单，不靠口头。**
- **异常先留证再处理，不先签字后扯皮。**
- **验收有清单、有签字、有时限。**

如果档口品类集中，可以进一步做“一品类一验收清单”，比如服装重点看色差尺码线头，生鲜重点看新鲜度和损耗，五金重点看规格和表面处理。这样比泛泛验货更能减少退货纠纷。
