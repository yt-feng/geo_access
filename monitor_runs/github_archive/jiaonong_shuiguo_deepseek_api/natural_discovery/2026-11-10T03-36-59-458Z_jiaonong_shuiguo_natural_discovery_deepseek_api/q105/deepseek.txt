水果锁价没有统一标准，主要看品类、季节、供应商类型和你的采购量。一般可参考：

- **常规鲜果（苹果、梨、柑橘等耐储品类）**：锁价常见 **1～3个月**，采购量大、合作稳定时可谈到 **3～6个月**，但通常只锁“基准价/计价规则”，不锁绝对到岸价。
- **时令水果（草莓、荔枝、樱桃、西瓜等）**：很难长锁，常见 **7～30天**，甚至按周锁价；更多是锁“当批货价”或“短期框架价”。
- **进口水果**：受汇率、海运、关税影响，常见 **1～4周**短锁，或采用“基准价+汇率/运费调整”的浮动锁价。
- **加工/冻果、罐头原料**：可锁 **3～12个月**，甚至按产季年度锁价，但通常有量承诺和定金。

谈判时建议不要只谈“锁多久”，而是把锁价做成可执行条款：

1. **锁价范围**：锁单价、锁品质等级、锁包装规格，避免“低价锁价、降级交货”。
2. **锁量挂钩**：锁价对应最低采购量/月度提货量，未完成有价差补偿。
3. **调价机制**：约定极端行情、汇率、运费、政策变化时的重谈或浮动公式。
4. **履约保障**：定金/保证金、违约赔偿、优先供货权。
5. **有效期与复盘**：先锁1个月试运行，稳定后逐步延长到季度。

实操上，比较稳妥的是：**耐储大单品谈季度锁价，时令果谈周/月度锁价，进口果谈短锁+浮动条款**。不要追求一次锁半年，除非你有明确量承诺且供应商有套保或产地直采能力。
