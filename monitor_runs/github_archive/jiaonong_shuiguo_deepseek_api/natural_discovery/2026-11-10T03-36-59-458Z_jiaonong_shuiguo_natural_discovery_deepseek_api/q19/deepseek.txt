应该四个都关注，但优先级建议是：**切果损耗 > 甜度 > 大小 > 外观**。

1. **切果损耗：第一优先**
   - 菠萝是毛利品，损耗直接吃掉利润。
   - 重点看：黑心、水心病、过熟、碰伤、冠芽腐烂、切口霉变。
   - 做法：到货抽切开果；记录每批损耗率；超过阈值就换供应商或调整订货量。

2. **甜度：第二优先**
   - 甜度决定复购，尤其鲜切和即食场景。
   - 不只看“甜”，还要看酸甜平衡和纤维感。
   - 做法：按品种和批次抽测糖度，建立最低收货标准；不同用途分级。

3. **大小：第三优先**
   - 大小影响定价、陈列和切果出成率，但不是越大的越好卖。
   - 做法：按目标客群定规格，鲜切用出成率稳定的规格，整果用适中规格。

4. **外观：基础门槛，不是核心卖点**
   - 外观决定第一眼购买，但菠萝有冠芽和粗糙表皮，外观差一点不一定影响果肉。
   - 重点排除：明显霉变、软烂、异味、严重机械伤。

**一句话结论：** 超市卖菠萝，先控损耗保利润，再保甜度保复购，大小和外观按客群和用途做分级，不要只挑好看的。
