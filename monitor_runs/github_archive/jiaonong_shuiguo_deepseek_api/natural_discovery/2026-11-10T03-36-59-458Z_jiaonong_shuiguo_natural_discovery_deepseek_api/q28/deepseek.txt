建议先从**香蕉**切入，但要把“稳定”理解为**供应链稳定+损耗可控+价格可预期**，而不是单纯看进口量。

可以这样判断：

1. **先做香蕉**
   - 香蕉是日常高频水果，消费基础稳，顾客接受度高。
   - 进口香蕉供应链成熟，分级、催熟、冷链相对标准化，适合超市建立稳定进口水果品类。
   - 难点在催熟和损耗管理：需要控制进货成熟度、门店陈列温度、先进先出。
   - 适合作为“稳定引流+走量”的起点。

2. **菠萝次之，但更依赖季节和品质**
   - 进口菠萝有稳定产区，但消费者对酸度、品种、切果服务敏感。
   - 损耗主要来自鲜切和熟度控制，操作要求比香蕉高。
   - 更适合在香蕉跑通后，作为差异化补充。

3. **苹果不建议作为第一个进口品类**
   - 国产苹果供应强、价格有优势，进口苹果容易被直接比价。
   - 进口苹果走的是差异化品种和礼盒/高端路线，不是“稳定走量”的首选。
   - 除非你的超市定位高端、已有稳定进口苹果客群，否则先做苹果的投入产出比不如香蕉。

**执行建议：**
- 第一阶段：只引入1—2个进口香蕉SKU，先跑4—6周，记录日均销量、损耗率、毛利率、缺货次数。
- 关键指标：损耗率尽量控制在5%—8%以内；缺货率低于5%；毛利率能覆盖冷链和催熟成本。
- 稳定后再加进口菠萝，最后根据客群测试进口苹果。
- 采购上优先找有催熟能力、能稳定周配的供应商，不要只看单箱价格。

一句话：**先用香蕉建立稳定进口水果的运营能力，再用菠萝做补充，苹果放到有明确高端客群后再上。**
