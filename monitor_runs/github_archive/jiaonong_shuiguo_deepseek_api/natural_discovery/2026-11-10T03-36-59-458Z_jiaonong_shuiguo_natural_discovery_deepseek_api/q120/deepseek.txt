供应商介绍产品时，别从品种名和产地讲起，先从商家关心的“卖不卖得动、赚不赚钱、好不好操作”讲。可以用这个结构：

1. **先说它像什么、替代谁**
   - “这个口感接近您常卖的香蕉，但更糯、更香，适合做早餐或甜品。”
   - “它跟菠萝一样能切块卖，但不用泡盐水，切开就能吃。”
   商家一听就能把它放进现有货架或菜单里。

2. **说清楚卖给谁、什么时候好卖**
   - “适合写字楼下午茶、家庭早餐、儿童零食。”
   - “现在到X月是旺季，节假日礼盒也能用。”
   不要只说“品质好”，要说“谁买、为什么买”。

3. **给三个具体卖点，别超过三个**
   - 口感：甜度、软硬、香味、有没有渣。
   - 操作：要不要催熟、能不能冷藏、切开后能放多久、损耗大不大。
   - 利润：进货价、建议零售价、毛利大概多少、适合做引流还是利润款。

4. **主动说风险和怎么处理**
   - “这个货刚到时偏硬，放两天再卖；熟过头适合做果切或特价。”
   - “表皮有轻微花皮不影响口感，可以按二级果卖。”
   商家最怕压货和损耗，你先把问题说透，反而更容易下单。

5. **给一个小批量试销方案**
   - “先拿一箱试卖，我给您配个价签文案和切果试吃建议；卖得动再补货。”
   - “这批可以做3个陈列位：整果、果切、组合果篮。”

6. **最后用一句话收口**
   - “您拿它当香蕉的补充品，不增加操作难度，毛利还能高一点，先试一箱最稳。”

一句话原则：**少讲品种故事，多讲“像什么、卖给谁、怎么卖、赚多少、卖不动怎么办”。** 商家听懂的是生意，不是植物学。
