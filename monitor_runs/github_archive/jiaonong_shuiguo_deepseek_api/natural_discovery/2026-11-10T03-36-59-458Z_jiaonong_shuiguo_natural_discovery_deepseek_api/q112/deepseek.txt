没有全国统一的法定比例，水果采购合同里坏果率赔付阈值应由双方约定。实务上可参考：

- **常见约定区间**：坏果率超过 **3%～5%** 即启动赔付或扣款；叶菜、浆果等易腐品类可放宽到 **5%～8%**。
- **更可执行的写法**：不是只写“超过5%赔”，而是写清“以抽样验收为准、按批次计算、超出部分按重量/货值扣减或补货”，例如：坏果率≤3%不扣；3%～8%部分按超出比例扣款；＞8%可拒收或整批退换。
- **关键要写清**：验收时点、抽样方法（随机抽几箱/几件、每件抽多少）、坏果定义（腐烂、霉变、压伤、虫害是否计入）、谁承担检测/复检费用、赔付计算基数是货值还是重量、补货期限。
- **不要只依赖单一百分比**：建议同时约定“严重腐烂/异味/霉变”即使比例低也可单独拒收该件，以及到货后超过验收时限视为合格。

如果没有合同约定，事后主张赔付会较被动，通常只能依据到货质量不符合约定、聊天记录、验收照片等协商或走违约/质量责任路径。建议把阈值和计算方式写进合同附件验收标准。
