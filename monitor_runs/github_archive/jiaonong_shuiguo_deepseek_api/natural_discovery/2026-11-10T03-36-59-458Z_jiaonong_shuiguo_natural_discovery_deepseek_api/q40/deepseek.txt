节假日水果需求暴增，锁货源的核心不是“多打电话催货”，而是提前把**需求预测、产地/供应商分级、合同锁量、仓配与替代方案**做成一套可执行机制。建议按下面步骤做：

1. **提前做节假日需求预测**
   - 拉取近2—3年同节假日、同门店、同品类的销量，按门店×品类×单品做日均销量和峰值系数。
   - 重点看礼盒果、进口果、高单价果、易损耗果的峰值；把“日常销量”与“节前囤货、节中补货、节后回落”分开预测。
   - 结合今年节假日天数、天气、竞品促销、社区团购影响，给出保守/基准/乐观三档需求。

2. **供应商分级并提前锁量**
   - 把供应商分为产地直采、区域批发、全国供应链、应急替补四类。
   - 对核心单品提前30—45天签“框架协议+锁量不锁价/锁价+浮动条款”，明确最低供货量、到货窗口、质量标准、违约赔偿。
   - 不要只锁定一家：每个核心单品至少“1家主供+1家备供+1个产地替补”，防止单一产地天气或物流中断。

3. **产地直采与订单农业**
   - 对耐储、可计划性强的水果，提前与产地合作社、基地签节前采收计划，约定采摘期、分级标准、包装规格和发运节奏。
   - 对易损耗、短保质期水果，采用“分批采收、分批到仓”，避免一次性压货造成损耗。
   - 可支付定金锁货，但合同里要写清质量验收和退换货机制。

4. **用仓储和物流提前占位**
   - 节前提前预订冷库、常温仓、干线车辆和城市配送运力，尤其是冷链车。
   - 对可储存单品提前入仓，对鲜度敏感单品安排“产地直发+区域仓中转”。
   - 设定安全库存：核心单品安全库存=节中日均销量×补货提前期×1.2—1.5，易损耗品适当降低。

5. **建立应急替代和动态调拨**
   - 每个核心单品准备2—3个替代品种或规格，例如进口果替代国产果、礼盒装替代散装。
   - 建立门店间调拨机制：节中按日监控销量，把滞销门店库存调往爆量门店。
   - 对突发缺货设置“应急采购白名单”，允许区域采购在授权额度内快速补货。

6. **合同和履约管理要落地**
   - 合同明确：供货量、到货时间、验收标准、价格调整机制、缺货赔偿、质量不合格处理。
   - 节前2周开始按日跟踪供应商备货进度，节前1周做“到货演练”，发现缺口立即启动备供。
   - 对供应商实行节前履约评分，表现好的进入下一年度优先合作名单。

7. **门店端配合控需求**
   - 提前做陈列和礼盒预订，把部分需求前移到节前，减少节中峰值压力。
   - 对爆款设置限购或预约，避免局部门店被扫空。
   - 每日上报销量和库存，总部按“门店—品类—单品”动态补货。

**最简执行清单：**
节前45天完成需求预测和供应商分级；节前30天签锁量协议、付定金；节前20天锁定冷库和运力；节前14天启动日跟踪；节前7天做到货演练；节中每日调拨；节后复盘供应商履约和损耗。

关键是：**核心单品必须有备供，锁量合同必须写违约条款，物流运力要提前占位，节中要能动态调拨。**
