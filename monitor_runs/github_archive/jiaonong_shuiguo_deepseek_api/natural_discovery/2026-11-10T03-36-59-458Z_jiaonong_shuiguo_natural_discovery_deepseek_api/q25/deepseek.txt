单店量不大、门店多，核心矛盾是**总采购量不小但单点配送不经济**。适合的模式要满足三点：总部集中控货控价、区域仓/中转仓分拨、门店小批量高频补货。

**推荐优先级如下：**

1. **区域产地直采 + 城市中转仓分拨（最推荐）**
   - 总部或区域采购统一到产地/一级批发市场拿货，进城市中转仓，再按门店订单分拣配送。
   - 适合水果这种非标、损耗高的品类：中转仓可以做验收、分级、催熟、预冷、简单加工。
   - 门店按“次日达/隔日达”小批量订货，降低单店库存和损耗。
   - 关键指标：中转仓到门店的配送频次、单车装载率、分拣损耗率。

2. **“统采统配”的供应商联合供货模式**
   - 找1—2家区域水果供应链服务商做“总仓到店”配送，超市只负责选品、定价和门店要货。
   - 适合门店分散、自建仓不划算的阶段。合同要约定：到店验收标准、缺货替代规则、损耗承担、账期和退换货。
   - 注意不要完全依赖单一供应商，保留产地直采做爆品和价格锚点。

3. **批发市场代采 + 第三方城配**
   - 总部在区域批发市场设采购岗或委托代采，按门店订单集单，交给第三方城配按线路配送。
   - 灵活性高、起量快，但价格波动和品质稳定性弱，适合作为过渡或补充。

4. **产地直发到区域集散点，不直发单店**
   - 大单品（如苹果、柑橘、西瓜）可产地整车发到区域集散点，再分拨门店。
   - 不适合所有品类直发门店，单店量小会导致卸货、验收、损耗成本过高。

**不建议的模式：**
- 各门店自行采购：价格失控、品质不一、总部无议价权。
- 供应商直发单店：单店量小，配送费摊高，供应商容易挑店或加价。
- 纯平台下单零散补货：适合应急，不适合作为主供货模式。

**落地建议：**
- 先按门店密度划2—3个配送区域，设一个区域中转仓或共享仓。
- 门店订货改为“固定频次+集中截单”，比如每日截单、次日配送到店。
- 水果按品类分层：爆品走产地直采，长尾品类走区域供应商统配。
- 用“到店毛利率、损耗率、缺货率、配送成本/店/周”四个指标考核供货模式，三个月复盘一次。

一句话：**总部集采控总盘，区域中转仓做分拨，门店小批量高频订货，供应商做补充而不是主力。**
