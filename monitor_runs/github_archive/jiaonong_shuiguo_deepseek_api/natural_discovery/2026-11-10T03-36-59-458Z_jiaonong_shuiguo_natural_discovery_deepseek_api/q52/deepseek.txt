采购时按“青一点、硬一点、少磕碰、分开放”来做，基本能明显延缓到店后变黑。

**采购判断**
- 选**七成熟左右**：表皮整体偏黄但两端还带一点青，手感硬实；不要买已经全黄、有黑点、软塌的。
- 看**果柄和棱线**：果柄青绿、棱线不明显更耐放；果柄发黑、果身有压痕的容易先坏。
- 避开**冷害果**：表皮灰暗、有细密凹陷斑的不要，可能是冷链受过低温，回温后很快发黑。
- 少量多次进货，甜品店用量稳定的话，按2—3天用量分批买，比一次囤货稳。

**运输和到店处理**
- 用**带孔周转箱**装，不要用密封塑料袋闷着；香蕉会释放乙烯，闷着会加速成熟。
- 轻拿轻放，避免堆压，压伤处会先黑。
- 到店后**不要放冰箱冷藏**，香蕉怕低温，冷藏后表皮会快速变黑。
- 放在**阴凉通风处，15—18℃左右**较合适，避开阳光、烤箱、热饮机等热源。
- **整串悬挂或单层平放**，减少接触面；已经分离的单根可包住果柄，减少乙烯从切口释放。
- 和苹果、梨、熟芒果等**高乙烯水果分开**，不要同箱混放。

**使用顺序**
- 每天分拣一次，**先熟先用**：有黑点、发软的优先做香蕉泥、烘焙、奶昔类。
- 需要延缓整批成熟时，可把香蕉**分开摆放并通风**；不要为了保鲜把青香蕉和熟香蕉密封在一起。
- 表皮刚出现少量黑点但果肉正常，不影响甜品使用；若果肉发软发酸、渗液，就不要用。

**最有效的三条**：买偏青硬实的、别冷藏、别闷袋堆压。
