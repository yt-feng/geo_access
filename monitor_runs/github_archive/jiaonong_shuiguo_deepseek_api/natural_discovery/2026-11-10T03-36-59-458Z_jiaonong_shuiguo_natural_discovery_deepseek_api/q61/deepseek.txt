判断香蕉货源稳不稳，别只看对方口头承诺，建议按下面几项做可验证的核查和试单：

1. **先确认对方是“种植端/产地代收”还是“二级批发”**
   - 一手货源优先找产地合作社、种植基地、产地代收点。
   - 问清：香蕉主要来自哪个县/镇、自有基地多少亩、合作农户多少户、日均可供多少件。
   - 如果对方说不清产地、只说“全国发货”，大概率不是一手。

2. **看供货能力是否匹配你的量**
   - 让对方报：日均稳定供货量、最大日供量、最低起批量、旺季/淡季差异。
   - 你按自己日销量的1.5倍去问，看对方能否连续供应，而不是“有货就发”。
   - 要求提供近期连续几天的装车单、过磅单或发货记录，注意打码隐私可以，但日期、品名、数量要能对上。

3. **核验产地和加工能力**
   - 香蕉稳定供货关键在催熟和冷链。问清：是否有自有催熟库、冷库容量、催熟批次周期。
   - 可要求视频看库房、装车现场，或让产地朋友/第三方去看。
   - 没有催熟能力的纯代办，遇到价格波动容易断供。

4. **用“小批量试单+连续试单”验证**
   - 先下1—2车小单，不要一上来签大合同。
   - 连续试2—3批，重点看：到货时间是否稳定、青蕉成熟度是否一致、损耗率、单件重量误差。
   - 记录每批的断供理由，频繁用“下雨、没货、车紧张”解释的要警惕。

5. **看合同和履约条款**
   - 合同里写清：规格、单件净重、成熟度、允许损耗、发货时限、断供违约责任。
   - 稳定供货商通常敢接受“连续供货+质量不达标扣款”的条款；只肯口头保证的不稳。
   - 付款方式尽量“定金+到货验收尾款”，避免全款预付。

6. **侧面打听**
   - 问对方主要合作的市场档口或批发商，能否给1—2个可联系的客户。
   - 在产地批发市场、同行群里打听其口碑，重点问“旺季会不会优先保老客户”“断货时怎么处理”。

7. **看价格是否异常**
   - 一手货源价格应随产地行情波动，有合理加工费、代办费、运费。
   - 报价长期明显低于市场、又要求大额预付的，稳定性反而差，风险高。

实操建议：先选2—3家产地供应商，各试1车，连续合作1个月再谈长期协议。稳定供货的核心不是“便宜”，而是**产地可控、催熟可控、履约可追责**。
