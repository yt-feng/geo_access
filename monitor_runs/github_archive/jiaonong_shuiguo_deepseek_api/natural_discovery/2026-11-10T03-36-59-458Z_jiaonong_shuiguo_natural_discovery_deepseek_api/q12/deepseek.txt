采购菠萝时，判断熟度要围绕“到店后能卖几天、损耗发生在哪”来定，不要只挑最熟或最生的。

**可执行判断：**

1. **按销售节奏定采购熟度**
   - 当天或次日能卖完的：可采**七八成熟**，果皮由青转黄约1/3—1/2，果肉已甜但不过软。
   - 常规2—3天周转：采**六七成熟**，果皮大部分青绿、底部略转黄，回家后可自然后熟。
   - 不建议大批量采全黄、香味浓的果，除非当天促销走量。

2. **看外观**
   - 果形端正、饱满，没有明显偏斜或干瘪。
   - 果皮颜色：青绿带局部转黄较耐放；大面积金黄、果眼发褐说明偏熟。
   - 果眼要平展、不凹陷；有汁液渗出、发黑、霉点直接排除。

3. **闻香味**
   - 底部轻闻有淡淡果香：适合2—3天销售。
   - 香味浓烈、带酒味：已偏熟或过熟，只适合当天特价。
   - 完全无香味：偏生，可放，但甜度可能不足。

4. **按手感**
   - 轻按果身有弹性、不软塌：适中。
   - 按下去明显软、回弹慢：过熟，损耗风险高。
   - 硬得像石头：偏生，需后熟，占货架和资金。

5. **看底部和果心**
   - 底部切口新鲜、无黑腐、无酸味。
   - 底部闻着发酸、发酒味，说明内部可能已坏。

6. **采购比例建议**
   - 一批货里以**六七成熟为主**，搭配少量七八成熟用于当天现切或促销。
   - 夏季高温、店内无冷库时，熟度再降一档；冬季或冷藏条件好可略高。
   - 先小批量试销，记录“到店后第几天开始出现软化/黑心”，再调整采购熟度。

**简单记：** 要放2—3天，选青绿转黄、淡香、按着稍弹的；当天卖，选金黄、香浓、微软的；全黄浓香、按着软、底部发酸酒味的不要大批量进。
