社区团购旺季锁水果库存，核心不是“提前打个招呼”，而是把**需求预估、锁量协议、分阶段提货、违约与损耗责任**四件事写清楚，并用少量定金/保证金把口头承诺变成可执行约束。建议按下面做：

**1. 先做可承诺的需求预测，不要拍脑袋**
- 按品类拆分：爆品（如砂糖橘、苹果、车厘子）、常规品、引流品分别预测。
- 用近4周日均销量、去年同期、已开团预售量、团长历史履约率做基准，给出“保守/基准/乐观”三档。
- 对供应商只锁定“保守量+部分基准量”，避免过度承诺后卖不掉。

**2. 和供应商签“锁量不锁死”的框架协议**
关键条款建议包括：
- **锁量方式**：约定旺季期间每周/每批次最低提货量和最高供应量，供应商优先保障。
- **价格机制**：锁基础价+浮动区间，或按产地行情周度调价，避免单方毁约。
- **定金/保证金**：支付可承受的定金锁定货源；明确供应商缺货、延迟、品质不达标的赔付。
- **分阶段提货**：不要一次性全提，按开团节奏分3—5批提货，降低损耗和资金压力。
- **质量标准**：规格、糖度、成熟度、瑕疵率、农残检测、包装方式写进验收标准。
- **损耗与退换**：到货验收不合格的退换货时限、运费承担、坏果率上限。
- **违约条款**：供应商旺季临时涨价、转卖他人的违约责任；我方不提货的定金处理。

**3. 用“多供应商+主次份额”分散风险**
- 每个爆品至少2家供应商：主供应商锁60%—70%，备用供应商锁20%—30%。
- 对备用供应商也给小批量订单保持合作，旺季才能临时补货。
- 产地直采和一批商结合，避免单一产地天气、交通中断。

**4. 提前锁定物流和仓储**
水果爆单往往不是没货，是到货后分拣、冷链、配送跟不上。提前预约冷链车、临时分拣场地和打包人手，和供应商约定到货时间窗，避免集中到货压库。

**5. 用预售和团长数据反向锁货**
- 提前3—7天开预售，用真实订单指导提货。
- 给团长设置下单截止时间和履约率要求，减少虚假需求。
- 对预售爆品收小额定金，降低弃单率。

**6. 盯住三个预警指标**
- 供应商日供货达成率低于90%立即启动备用；
- 到货坏果率超过约定上限，暂停该批次并索赔；
- 库存周转超过2—3天，减少后续提货，转促销或调拨。

实操上，最稳的做法是：**先付小额定金锁“保守量”，签分周提货协议，主备供应商并行，预售订单再追加基准量。** 不要只靠微信口头约定，也不要一次性把全季库存锁死。
