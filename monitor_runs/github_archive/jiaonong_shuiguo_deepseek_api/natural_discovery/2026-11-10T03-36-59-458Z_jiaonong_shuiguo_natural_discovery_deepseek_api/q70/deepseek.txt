# 合同中坏果责任的写法建议

核心原则：**把“谁的环节出问题、按什么标准判、怎么赔、多久内提异议”四件事写死**，避免只写一句“坏果由卖方负责”。

## 一、先定“坏果”的判定标准（最关键）

不要用“坏果”这种模糊词，建议在合同里量化：

- **定义**：霉变、腐烂、软烂出水、严重压伤/裂口、异味、虫蛀等，逐项列明。
- **比例计算**：坏果率 =（不合格果重量 ÷ 该批次总重量）× 100%。
- **抽样方法**：约定按到货批次随机抽若干箱/件，抽检比例（如每批抽 5% 或不少于 X 箱），抽检结果代表整批。
- **参考标准**：可引用国家标准或行业分级标准（如鲜果等级、农残标准），但要在合同里写明具体标准名称和版本，不要只写“符合国标”。

## 二、按环节划分责任

| 环节 | 风险承担方 | 写法要点 |
|---|---|---|
| 装车/发货前 | 批发商（卖方） | 约定发货前坏果率上限（如 ≤2%），随车附自检记录或照片 |
| 运输途中 | 看谁安排运输 | 若卖方负责运输/承运，途中损耗由卖方承担或由其向承运人追偿；若买方自提或指定承运人，需明确风险转移点 |
| 到货验收 | 买方 | 约定验收时限（如到货后 24/48 小时内），逾期未提异议视为合格 |
| 卸货后存储 | 买方 | 因买方存储不当（温度、堆压、未及时入库）造成的坏果，卖方不担责 |

**风险转移节点**要写清楚：是“装车即转移”“到货签收转移”还是“验收合格后转移”。这直接决定坏果算谁的。

## 三、赔偿方式（给几种可选写法）

1. **扣款/折价**：坏果率超过约定阈值（如 5%）的部分，按当批单价 × 超出部分重量扣减货款。
2. **换货/补发**：约定卖方在收到异议后 X 日内补发同等数量合格果，运费由责任方承担。
3. **整批退货**：坏果率超过较高阈值（如 15%–20%）时，买方有权整批拒收或退货，卖方承担往返运费及因此产生的损失。
4. **封顶条款**：卖方可能要求赔偿以该批货款为上限，买方应争取把“因此造成的直接损失”（如已向下游违约的赔偿）单独约定。

## 四、程序性条款（防止扯皮）

- **异议通知**：买方须在验收时限内以书面/微信/邮件等可留痕方式通知，附照片、视频、抽样记录。
- **共同复检**：双方对抽检结果有争议时，约定送第三方检测机构，费用由责任方承担或先各付一半。
- **证据留存**：到货开箱、抽样、称重全程拍照录像，作为理赔依据。
- **时效**：明确索赔提出的最长期限，过期视为放弃。

## 五、示范条款（可直接改写使用）

> 1. 坏果指霉变、腐烂、软烂出水、严重压伤裂口、异味、虫蛀的果实。到货后 48 小时内，买方按每批随机抽取不少于 5% 的件数进行验收，抽检坏果率代表整批。
> 2. 抽检坏果率 ≤5% 的，买方不得拒收；超过 5% 的部分，按该批单价×超出重量从货款中扣除；超过 15% 的，买方有权整批退货，往返运费由卖方承担。
> 3. 因买方未在约定时限内提出书面异议，或卸货后因存储、堆压、温度不当造成的坏果，卖方不承担责任。
> 4. 双方对抽检结果有争议的，送双方认可的第三方机构复检，复检结果为最终依据，检测费用由责任方承担。

## 提醒

- 各地对生鲜买卖的举证责任和“合理损耗”认定可能有差异，条款最好结合当地交易习惯；金额大的合同建议请律师过一遍。
- 如果对方是强势批发商，重点争取**明确抽样方法和验收时限**，这两条比赔偿比例更能决定实际能不能赔到。
