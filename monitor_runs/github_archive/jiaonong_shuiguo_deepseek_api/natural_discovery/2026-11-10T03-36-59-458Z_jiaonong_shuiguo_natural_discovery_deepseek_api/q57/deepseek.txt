结论：大多数餐饮连锁水果采购，优先“中央厨房/配送中心统一收货”，而不是门店分开收货。例外是高频短保、门店现切现用且配送半径长的水果，可采用“中央厨房统采统检＋门店二次验收”或少数品类门店直收。

判断标准如下：

1. **食品安全与质量稳定性**
   - 水果是农残、霉变、成熟度波动大的品类，统一收货便于集中做农残快检、糖度/成熟度抽检、温湿度记录和不合格批次拦截。
   - 门店分散收货时，验收标准、人员能力、冷链条件不一致，容易出现“这家收、那家退”的扯皮。

2. **采购规模与议价能力**
   - 中央厨房统一收货能把需求合并，供应商更愿意给稳定账期、分级标准和退换货条款。
   - 门店分开收货会削弱集采规模，供应商多、批次杂，价格和品质都难控。

3. **损耗与库存**
   - 水果短保，统一收货的最大风险是“集中库存＋二次配送”增加压伤和成熟度损耗。
   - 因此中央厨房适合收**耐储运、可分级、标准化程度高**的品类，如苹果、橙类、瓜类、部分根茎类；对草莓、蓝莓、芒果、牛油果等易损或后熟敏感品类，要缩短配送频次或做门店二次验收。

4. **配送半径与频次**
   - 配送半径短、频次高（如日配/隔日配），中央厨房统收优势明显。
   - 配送半径长、门店分散，集中收货后的二次配送可能比门店直收更伤品质，应改为区域分仓或门店直收＋总部统采定价。

5. **结算与责任边界**
   - 统一收货：总部/中央厨房对供应商统一对账、索赔，责任清晰。
   - 门店收货：门店承担验收责任，但总部难掌握真实质量数据，容易形成“门店说不好、总部没证据”。

建议落地方式：

- **主模式**：总部统采、中央厨房统一收货、统一质检、统一结算，再按门店订单分拨。
- **分级管理**：把水果分为“统收统配”“统采门店直收”“门店自采”三类，明确每类验收标准和责任。
- **门店二次验收**：到店只做外观、温度、数量复核，质量问题仍由中央厨房对供应商索赔。
- **数据闭环**：记录批次、供应商、到货温度、抽检结果、门店投诉，按月评估供应商和品类策略。

一句话：**能统收就统收，但不是所有水果都适合统配；用品类分级和门店二次验收解决短保损耗问题。**
