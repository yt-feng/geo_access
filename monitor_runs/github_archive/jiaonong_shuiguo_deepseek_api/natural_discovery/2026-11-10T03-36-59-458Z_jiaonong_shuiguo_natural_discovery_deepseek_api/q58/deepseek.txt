先说结论：**多数甜品店场景下，直接买成品果丁的总损耗通常更低、更好控制；鲜果切配只有在你能稳定拿到好菠萝、人工不紧张、且能把边角料再利用时，才可能更划算。** 但“损耗低”要分三层看：原料损耗、人工损耗、隐性损耗。

**1）原料损耗对比**

- **鲜果切配**：菠萝去皮、去眼、去芯后，出成率一般约 **50%–65%**，取决于品种、成熟度、去皮厚度和是否留芯。也就是说买10斤鲜果，实际可用果肉可能只有5–6.5斤。成熟度高、削皮厚、去眼多时更低。
- **成品果丁**：供应商已承担去皮去芯损耗，你按“净果丁”重量采购，**账面出成率接近100%**。但要验货：糖水/汁水多、规格碎、解冻出水、临期变色都会变成你的损耗。

**2）人工与操作损耗**

- 鲜果切配要占用人工，切配不均、放置氧化、冷藏风干、交叉污染、切多了用不完，都会增加损耗。忙时切配还容易影响出品一致性。
- 成品果丁开袋即用，**人工损耗和备货误差小**，适合中小店和标准化要求高的店。但开袋后氧化、出水、用不完变质仍是损耗点。

**3）隐性损耗**

- 鲜果：采购批次不稳定、成熟度不可控、季节性价格波动、退货难。
- 成品：供应商质量波动、最小起订量、保质期短、解冻/冷藏条件要求高、临期报废。

**可执行的判断方法**：连续两周记录两种方案的同口径数据——  
**实际可用果肉克数 ÷ 采购总克数 = 出成率**；  
**报废克数 ÷ 采购总克数 = 报废率**；  
**总损耗成本 = 采购金额 + 人工分摊 − 边角料再利用收益**。  
比较“每公斤可用果丁的综合成本”，不要只比单价。

**建议**：

- 日用量小、SKU多、人工紧、要求出品稳定：**优先成品果丁**，但选净含量足、汁水少、规格一致的供应商，少量高频订货。
- 日用量大、有稳定好货源、能把菠萝芯/边角做果酱、果汁、装饰：**鲜果切配可能更划算**，但必须定标准出成率和切配SOP。
- 折中方案：**鲜果做装饰和高端出品，成品果丁做内馅/批量配料**，通常总损耗最可控。

一句话：**看“每公斤可用果丁的综合成本”，不看单斤采购价；没有稳定货源和切配管理能力时，成品果丁损耗更可控。**
