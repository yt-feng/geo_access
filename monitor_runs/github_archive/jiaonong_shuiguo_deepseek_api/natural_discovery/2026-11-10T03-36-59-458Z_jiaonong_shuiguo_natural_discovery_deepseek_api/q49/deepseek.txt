旺季菠萝突然放量，补货约定要抓三件事：**锁量不锁死、锁价有上限、验收和违约写清楚**。建议按下面操作。

**1. 先内部算清补货需求**
- 按最近7天实际用量、未来14天预估销量，算出周需求量和峰值日用量。
- 给供应商一个“周基础量+可追加比例”，例如每周基础200箱，旺季可提前3天追加不超过50%。
- 明确规格：品种、单果重量区间、成熟度、去皮/带皮、每箱净重、农残检测要求。

**2. 和供应商签临时补充协议，不要只口头约定**
核心条款建议写：
- **补货触发**：提前3天书面/微信下单，供应商24小时内确认；紧急单提前24小时，能供多少确认多少。
- **数量弹性**：基础量+浮动上限，超出部分双方另行确认，避免供应商以“没货”断供。
- **价格机制**：约定基准价，随行就市但设涨幅上限，例如单周涨幅不超过10%；或按批发市场均价下浮固定比例结算，并保留当日报价截图。
- **到货时限**：确认订单后48小时内到店，旺季峰值可约定24小时急送，急送费用谁承担写清。
- **质量验收**：到货抽检比例、坏果率上限（如超过5%可拒收或按比例扣款）、成熟度不符合怎么退换。
- **违约与替代**：供应商缺货需提前48小时告知，并协助联系备选货源；无故断供按缺货金额一定比例赔付或扣减后续货款。
- **付款**：临时补货可货到验收后3—7天结算，避免旺季现金流压力。

**3. 同时准备备选供应商**
- 主供应商承担70%—80%，备选1—2家承担20%—30%，旺季前先小批量试单。
- 让备选供应商知道你有临时补货需求，保持报价和库存沟通。
- 店内安全库存至少覆盖2—3天峰值用量，避免等货断档。

**可直接发给供应商的简短话术：**
“旺季我们菠萝用量会上升，想签个临时补货约定：每周基础量X箱，提前3天可追加不超过50%；价格按基准价，单周涨幅不超过10%；确认后48小时到货，坏果率超5%可拒收；缺货需提前48小时告知并协助调货。先按这个框架合作一个月，跑顺了再续。”

一句话：**用书面临时协议锁住弹性数量、价格上限、到货时限和验收标准，同时保留备选供应商，避免旺季被单一供应商卡住。**
