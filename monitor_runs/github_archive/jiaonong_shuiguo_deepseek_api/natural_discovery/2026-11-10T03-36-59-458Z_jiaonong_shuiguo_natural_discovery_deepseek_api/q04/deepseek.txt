香蕉损耗大，核心是“按卖相分批采购、按销售节奏到货”，而不是一味要求更青或更熟。建议把采购要求写进订货单：

**1. 熟度分档要求**
- **主销批次：微黄至半黄**，果身硬、棱角尚明显、无黑斑，适合当天到店后2–3天销售。
- **备用/促销批次：青黄**，果身硬、无软化，用于衔接后段销售或做活动。
- **少量即售批次：黄熟**，仅限客流稳定、当天能卖完的时段，要求无软烂、无酒味、无大面积黑斑。
- 明确拒收：果柄发黑霉变、果身软塌、表皮大面积黑斑、有酒味/酸味、受冻发暗。

**2. 到货时间要求**
- 要求**早上营业前到货**，给理货、分拣、上架留时间；避开午后高温时段到货。
- 按销量拆成**每周2–3次小批量到货**，不要一次压大货。
- 节假日/周末前可提前一天到“微黄”货，工作日到“青黄偏硬”货。
- 到货后立即开箱散热、分拣，不要闷在箱里。

**3. 采购沟通话术**
“请按微黄偏硬为主、青黄为辅供货，单批不超过X箱；每周X、X早上X点前到货；软熟、黑斑、霉柄、酒味果拒收；连续两次熟度超标则减量或换供应商。”

**4. 配套控制**
- 订货量按“近3天日均销量×1.2–1.5”控制，天气热再下调。
- 门店按熟度分区摆放，微黄在前、青黄在后；黄熟果及时促销或做果切。
- 香蕉不要冷藏，放阴凉通风处，避免和苹果、梨等催熟水果混放。

一句话：**采购时要求“微黄偏硬为主、青黄搭配、早到小批量、熟度超标拒收”，比单纯要求“青一点”更可执行。**
