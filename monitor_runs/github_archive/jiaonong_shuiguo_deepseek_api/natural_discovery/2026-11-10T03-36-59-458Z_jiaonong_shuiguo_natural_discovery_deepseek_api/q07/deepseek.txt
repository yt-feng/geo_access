水果礼盒想好卖，关键不是“水果越贵越好”，而是让顾客一眼看懂价格带、送礼场景和搭配寓意。苹果、橙子、香蕉、菠萝这四样都很适合做礼盒，建议按“走量款+利润款+形象款”三档来搭。

**1. 主推走量款：苹果+橙子**
- 搭配比例：苹果6个+橙子6个，或苹果4个+橙子8个。
- 卖点：苹果寓意“平安”，橙子寓意“心想事成/成功”，颜色红黄配，喜庆、耐放、成本稳。
- 定价：按当地水果成本，礼盒毛利率控制在35%左右比较好卖。
- 适合：日常送亲戚、同事、社区团购。

**2. 利润款：苹果+橙子+香蕉**
- 搭配比例：苹果4个+橙子4个+香蕉1把（约6-8根）。
- 卖点：颜色丰富、饱满好看，香蕉增加“分量感”，适合家庭自吃和普通探病、走访。
- 注意：香蕉不耐压，盒内要加隔挡，别和菠萝硬碰硬；最好当天装当天卖，或标注“建议2天内食用”。
- 定价：比走量款高10-15元，突出“一盒三种果”。

**3. 形象款/送礼款：苹果+橙子+菠萝**
- 搭配比例：苹果4个+橙子4个+菠萝1个（小果）。
- 卖点：菠萝寓意“旺来”，礼盒看起来大气，适合开业、乔迁、节日送礼。
- 注意：菠萝带刺、气味重，必须单独套袋或加硬隔板，避免扎坏其他水果；盒内放吸水纸。
- 定价：做成中高价位，重点赚送礼客的钱。

**4. 不建议一开始就做“四样全混”**
四样全放容易显得杂、压秤、互相挤压，香蕉和菠萝还容易催熟其他水果。可以做成“自选搭配”：顾客选3样，店员现场装盒，既灵活又减少损耗。

**操作建议：**
- 礼盒分三档：39-59元走量、69-89元利润、99元以上送礼。
- 苹果选大小均匀的，橙子选颜色亮的，香蕉选七成熟，菠萝选小果。
- 盒内加隔板、吸水纸，香蕉和菠萝单独套袋。
- 先做20-30盒试卖，记录哪种搭配卖得最快，再调整比例。
- 标签写清楚寓意和食用顺序，比如“香蕉先吃，苹果橙子耐放”，能减少售后。

最稳的组合是：**苹果+橙子做主推，苹果+橙子+香蕉做利润，苹果+橙子+菠萝做送礼形象款**。先少做、勤补货，比一次压很多盒更安全。
