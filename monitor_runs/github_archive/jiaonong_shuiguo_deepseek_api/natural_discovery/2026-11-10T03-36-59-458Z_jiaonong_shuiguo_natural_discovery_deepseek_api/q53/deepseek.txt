餐饮店每天少量水果，想省心，优先找**本地中小型水果配送商/批发商做固定日配**，而不是超市、生鲜平台或产地直采。判断标准就四条：能固定时间送、能小批量起送、能按你的菜单配品项、坏果能当场换补。

具体选哪类：

1. **本地水果批发市场里做“配送档口”的商户**——最适合少量日配。你每天报单，他们按箱/按斤配好送来，价格比平台低，坏果可换。找的时候问清：起送金额、配送时间、是否可拆箱、坏果怎么赔。
2. **专门做餐饮/茶饮的水果配送商**——比普通档口更省心，能按你的用量做小包装、固定品项、定期报价。适合每天品项稳定、量少但要求准时的店。
3. **周边水果店/社区生鲜店合作**——适合每天只要几斤、临时补货。优点是灵活、能少量拿；缺点是价格略高、品项不稳定，适合作为备用渠道。
4. **生鲜平台/外卖平台**——不建议做主渠道，适合应急。起送、包装费、品质波动会让“省心”打折扣。

签约/合作前重点确认这几件事：
- **起送量和拆箱规则**：能不能按斤/按小箱拿，避免压货。
- **配送时间和迟到处理**：餐饮最怕到货晚，约定固定送达时段和迟到补救。
- **品质标准和退换**：坏果、熟度不合适当天换补还是扣款，写清楚。
- **报价方式**：按周/按日报价，避免临时涨价；至少找两家备选。
- **结算方式**：少量日配建议月结或周结，先小单试一周再固定。

省心的组合一般是：**一家本地配送商做主力日配 + 一家周边水果店做应急补货**。先试送3—5天，看准时率、坏果率和换补态度，再决定是否长期合作。
