# 超市水果到货品相不好：售后流程约定建议

水果属于生鲜易腐品类，售后不能照搬标品（如“七天无理由”），核心思路是：**把“品相”变成可判定的标准 + 到货即验的时限 + 分级处理方式**，并在合同/采购单/收货单里写死。建议按以下结构约定：

## 一、先定义“品相不好”，避免扯皮

在合同附件中写明验收标准，至少包括：

- **外观**：果形大小、色泽、无明显机械伤/压伤、无裂果、畸形果比例上限。
- **新鲜度**：无萎蔫、无软化、无异味、无霉变。
- **成熟度**：约定到货成熟度区间（如七八成熟），避免“太生/太熟”各说各话。
- **等级比例**：明确允许的不合格率。例如“单批次不合格果比例≤5%，超过部分按退货或折价处理”。
- **取样方法**：按箱/按批次随机抽检比例（如10%或每批不少于X箱），抽检不合格即判定整批。

关键：**用比例和等级说话，不用“品相不好”这种主观词**。

## 二、约定到货验收时限与动作

- **验货时限**：到货后X小时内（生鲜建议2–4小时内）完成验收，逾期视为验收合格——但要在合同中写明，且给收货方合理时间。
- **验货流程**：收货方拍照/录像留证（整箱、抽样、问题果特写、称重记录），形成《到货验收单》，双方签字或系统确认。
- **异议提出**：发现问题须在验货时限内书面/系统内提出，附照片和数量，否则视为接受。

## 三、分级售后处理方式（写进条款）

按不合格程度分档处理，比“一律退货”更可执行：

1. **轻微瑕疵（在约定比例内）**：正常收货，不追责；或按约定折价。
2. **超标但不影响销售**：折价接收（如按不合格比例扣款），或换货補发。
3. **严重问题（霉变、腐烂、异味、大面积压伤）**：整批拒收/退货，供应商承担运费及损耗。
4. **已上架后发现**：约定发现时限（如到货后24小时内）和举证方式，超时一般不再受理，避免责任无限扩大。

## 四、责任与费用划分

- 运输途中损耗、冷链断链导致的问题由供应商承担；
- 收货方存储不当（如未按要求冷藏）导致的问题由超市承担；
- 明确退换货的**运费、装卸费、损耗补偿**由谁承担；
- 约定**补货/换货时限**（如48小时内补发），以及缺货时的替代方案（退款或下次抵扣）。

## 五、结算与违约挂钩

- 约定**质保金/账期扣款**机制：验收不合格可在当期货款中直接扣减，减少扯皮。
- 约定**累计不合格率**的后果：如月度不合格率超过X%，可要求整改、降低采购量或终止合作。
- 保留**索赔权**：因品相问题导致的顾客投诉、下架损失，可约定由供应商承担（需有举证）。

## 六、流程落地建议

把上述内容固化成三份文件，缺一不可：

1. **采购合同附件《生鲜验收标准》**：标准、比例、取样方法；
2. **《到货验收单》**：时限、拍照留证、签字确认；
3. **《售后处理单》**：问题描述、处理方式（折价/换货/退货）、扣款金额、双方确认。

**一句话总结**：先定量定义品相标准和不合格率，再约定“到货几小时内验、怎么取证、超比例怎么分级处理、费用谁担、怎么扣款”，全部落到书面单据上，售后才有可执行依据。
