判断水果供应商靠不靠谱，重点看“稳定性、透明度、赔付意愿、账期与售后”四件事，而不是只看第一次报价。给你一套可执行的方法：

**1. 先看是否专做水果、是否有稳定货源**
- 问清香蕉主要来自哪里（如云南、广西、海南、进口菲律宾/厄瓜多尔等），菠萝主要产区（广东徐闻、海南、广西等），不同季节换产区是否顺畅。
- 靠谱供应商能说清“现在这批是哪里的、什么品种、几成熟、预计放几天”，而不是只会说“好货”。
- 看是否有冷库/催熟库/分拣场地；香蕉尤其依赖催熟和温控，没有催熟能力的供应商后期损耗会转嫁给你。

**2. 用三次小批量试单验证，不要一次压大货**
- 第一次：小批量试单，记录到货成熟度、青果比例、机械伤、烂果率、单箱重量误差。
- 第二次：故意在价格波动或节假日前提货，看是否临时加价、换货、缺斤少两。
- 第三次：要求按约定时间到货，测试准时率。
- 每次到货当面抽检：香蕉看梳把整齐度、青硬比例、催熟均匀度；菠萝看果眼深浅、黑心/水心病、冠芽新鲜度、单果重区间。

**3. 把“坏果赔付”写进合作规则**
- 明确验收标准：烂果率、青果率、单箱净重允许误差、成熟度区间。
- 明确赔付方式：到场发现问题的，拍照留证后按比例扣款或补货；事后24～48小时内出现的内部腐坏是否认赔。
- 观察对方态度：一谈赔付就推诿的，价格再低也别长期做。水果生意的利润常被售后吃掉。

**4. 看价格是否透明、是否乱承诺**
- 要求报价包含：产地/品种/规格/净重/成熟度/是否含箱/运费/卸货费。
- 警惕明显低于市场价的报价，通常会在箱重、等级、成熟度或售后上找回来。
- 靠谱供应商会主动说风险，比如“这批熟度高，适合近距离快销”“这两天产地涨价，明天报价会变”。

**5. 看账期与资金安全**
- 新供应商建议现结或短账期，先建立信任再谈账期。
- 长期合作可约定固定对账日、赔付抵扣方式，避免口头账。
- 不轻易大额预付；需要预付时，要求合同/单据写明品名、规格、数量、到货时间和违约处理。

**6. 看响应速度和异常处理**
- 临时补货、到货异常、天气影响时，看对方是否及时回复、能否给替代方案。
- 长期靠谱的供应商不一定最便宜，但通常“说几成熟就几成熟、说几点到就几点到、出问题认赔快”。

**实操建议：**  
同时保留2家供应商，一家主供、一家备供；连续合作前3个月每月做一次到货统计（烂果率、准时率、净重误差、赔付兑现率），用数据决定是否长期合作。香蕉和菠萝都是后熟/易损品，**供应商的催熟能力、冷链能力和赔付意愿**比单纯报价更重要。
