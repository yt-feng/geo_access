判断“能不能全年稳定供货”，不能只听供应商口头承诺，要把它拆成可核验的能力。建议按下面顺序做：

## 1. 先问清供应模式，而不是只问产量
重点确认供应商是哪种模式：

- **自有基地**：有多少亩、分布在几个产区、香蕉品种、可采收面积、历史月均出货量。
- **合作基地/合作社**：合作多少户、是否签长期协议、能否直接调度。
- **市场代采/调货型**：自己没基地，靠批发市场或同行调货，全年稳定性最弱。
- **进口+国产组合**：要看进口来源国、港口、清关和国内补货能力。

**判断标准**：能全年稳定供货的供应商，通常不是单一基地，而是“多产区+多基地+可调度合作户”的组合。单一产区几乎无法覆盖全年，因为香蕉有季节性和台风、寒害风险。

## 2. 要求提供12个月的真实供货记录
不要只看“年产能”，要看：

- 过去12个月每月实际发货量；
- 每月主要发货产区；
- 最大单月供货量和最小单月供货量；
- 是否有断供月份、断供原因；
- 主要客户类型和合作年限。

**可执行判断**：让对方提供近12个月的出货台账或对账单脱敏件。若最小月供货量仍能覆盖你们超市的月度需求量，并留出20%—30%安全库存，才算基本稳定。

## 3. 核查产区分散度
香蕉怕台风、寒潮、病害和集中上市。要问：

- 基地分布在哪些县市/省份/国家；
- 各产区上市时间是否错开；
- 台风季、冬季寒害时从哪个产区补货；
- 是否有备用产区或备用供应商。

**判断标准**：至少有两个以上可错峰上市的产区；主产区受灾时，能在7—15天内切换到备用产区。只有一个产区或一个县的，全年稳定性要打问号。

## 4. 看采后处理和冷链能力
香蕉全年供应不仅是“有货”，还要“能按超市标准到货”。要核查：

- 是否有催熟库、分拣线、冷库；
- 催熟能力每天多少托盘/多少吨；
- 冷链车数量、是否自有或长期合作；
- 从产地到门店的运输时效；
- 青蕉、黄蕉的收货标准和质量追溯。

**判断标准**：能按你们门店的催熟节奏、到货成熟度、包装规格稳定交货的，才算真能供。只会发青蕉、没有催熟和分拣能力的，不适合连锁超市长期合作。

## 5. 用“压力测试”验证，而不是只看材料
可以要求供应商做三次测试：

1. **旺季增量测试**：在节日或促销前，要求比平时增加30%—50%供货，看响应速度。
2. **突发减量测试**：模拟主产区受灾，问对方从哪个产区补、几天能到、成本增加多少。
3. **月度错峰测试**：连续3个月按不同成熟度、不同包装规格下单，看合格率和到货准时率。

**判断标准**：增量能接、灾后能补、连续3个月准时足量且质量合格，才进入正式年度合同。

## 6. 合同里写清楚“稳定供货”的责任
不要只写年度总量，要写：

- 月度最低供货量和月度上限；
- 缺货违约金或补货责任；
- 主产区受灾时的替代方案；
- 质量不合格的退换货和扣款；
- 价格调整机制；
- 安全库存由谁承担。

**可执行建议**：先签3—6个月试供合同，按月考核“准时足量率、合格率、断供次数”，连续达标再签全年框架协议。同时保留1—2家备用供应商，避免被单一供应商卡住。

## 简单判断口诀
**看基地是否多产区、看出货是否有12个月记录、看灾后能否切换、看催熟冷链是否配套、看合同是否写月度保供。** 五项都过关，才基本能判断为全年稳定供货；缺两项以上，建议只做阶段性或备用供应商。
