先给结论：**给团购客户做价格管理，通常“阶梯价为主、返利为辅”更合适；但若客户价格极度敏感、采购量波动大，返利应作为主机制。** 不要二选一，关键是把“即时低价感”和“全年利润保护”分开设计。

**判断框架**

1. **看客户决策方式**
   - 客户每次下单都要求最低价、比价频繁、采购分散 → **阶梯价**更有效，因为即时可见、易比较、能促成单次成交。
   - 客户看重年度合作、能接受季度/年度结算、采购量有承诺 → **返利**更合适，能绑定全年采购，避免单次压价击穿底价。

2. **看采购量波动**
   - 量稳定、可预测 → 阶梯价简单，执行成本低。
   - 量波动大、季节性明显 → 返利更好，避免小单也拿到低价，也防止大单压价后量没兑现。

3. **看利润保护**
   - 阶梯价一旦给出去，所有达到档位的订单都低价，容易“价格倒挂”和被其他客户攀比。
   - 返利是“先按正常价成交、后按达成情况返还”，对现金流和底价保护更好，但需要合同、对账和兑现管理。

4. **看渠道冲突**
   - 如果团购客户会转售或影响其他渠道价格，**返利更安全**，因为不直接破坏公开报价体系。
   - 如果只是终端团购、不转售，阶梯价更直观。

**推荐组合方案**

- **基础价 + 阶梯价**：设定2—3档，按单次订单量或季度累计量给即时折扣，解决“价格敏感、要马上看到便宜”。
- **年度返利**：对全年采购额、回款、品类结构设返利，返利比例控制在可承受利润内，解决“绑定大客户、奖励增量”。
- **返利设计要点**：
  - 返利只返“增量部分”或“达成目标后的全额”，避免自然销量也返。
  - 返利以货款抵扣、下一期订单折扣或服务资源兑现，不轻易返现金。
  - 设置回款条件，逾期回款扣减返利。
  - 合同写清计算口径、统计周期、兑现时间、退货扣回。
- **阶梯价设计要点**：
  - 档位不要过多，2—3档即可，避免客户拆单凑档。
  - 最低档价格必须高于底价，并预留返利空间。
  - 明确是否含税、含运费、是否可与其他优惠叠加。

**简单决策规则**

- 客户只做一次性或短周期团购 → **阶梯价**。
- 客户有年度合作意愿、采购量可承诺 → **返利为主**。
- 客户价格极敏感但又想长期合作 → **低阶梯价 + 小比例年度返利**。
- 客户会转售、影响渠道价格 → **少用阶梯价，多用返利和专属政策**。

一句话：**阶梯价解决“这次买贵不贵”，返利解决“全年合作值不值”。团购客户价格敏感，先用阶梯价给成交理由，再用返利锁全年和护底价。**
