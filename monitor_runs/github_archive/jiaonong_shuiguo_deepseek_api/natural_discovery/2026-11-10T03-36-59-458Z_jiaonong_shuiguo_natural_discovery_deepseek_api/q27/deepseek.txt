判断“适合门店销售”的核心不是单纯看大小，而是看**规格一致性、陈列适配、顾客购买习惯和损耗可控**。可按下面流程做：

## 1. 先定门店目标：卖给谁、怎么卖
- **散卖为主**：规格可略宽，但同一堆头内大小要接近，避免“挑大剩小”。
- **预包装/称重包装**：要求更高，单包重量和果径要稳定。
- **高端/精品区**：偏大、外观好、整齐度高。
- **社区日常消费**：中等规格、性价比高，过大反而难卖。

## 2. 苹果判断要点
- **果径分级**：用果径圈或卡尺抽检，记录每批的横径分布，不要只看“大果/中果”标签。
- **单果重量**：同规格单果重量波动要小，便于定价和包装。
- **一致性**：颜色、形状、果面瑕疵、成熟度要接近；混级严重会拉低陈列效果。
- **陈列适配**：货架层高、堆头深度、包装袋容量能否匹配。
- **顾客接受度**：社区店通常中等个头更好卖；过大果在散卖区容易剩，需搭配礼盒或分级定价。

## 3. 橙子判断要点
- **果径+单果重量**：橙子大小差异对剥皮体验和单次食用影响明显，规格要更稳定。
- **皮厚与手感**：同样大小下，皮过厚、手感轻的果出汁率低，不适合主推。
- **整齐度**：同批颜色、形状、表皮粗细要接近；青黄混杂要分开陈列或说明。
- **包装适配**：网袋、礼盒、称重袋的容量要和果径匹配，避免装不满或挤压。
- **试销判断**：同规格连续卖几天，看动销、挑剩率和损耗，再决定是否保留。

## 4. 到货验收的简单可执行方法
1. **随机抽样**：每批至少抽3个位置、每位置抽若干果，不能只查上层。
2. **量果径和单果重**：记录最小值、最大值、平均值和波动范围。
3. **看混级率**：明显小于或大于主规格的比例超过可接受范围，就要求分拣或降级处理。
4. **做陈列试验**：按拟定规格上堆头/货架，观察顾客挑选行为和挑剩情况。
5. **算损耗**：对比同规格3—5天的销量、挑剩、碰伤、腐烂，规格不合适会体现在损耗和动销上。

## 5. 判断标准
适合门店销售的规格通常满足：
- **同批大小差异可控**，顾客一眼看不出明显混级；
- **陈列整齐**，不因过大压伤、过小显得空；
- **定价有对应客群**，中等规格动销稳定，大规格有明确溢价场景；
- **损耗可接受**，挑剩和碰伤不明显高于同类品；
- **包装和称重方便**，员工操作不额外增加太多时间。

建议做法：先小批量试销2—3天，按“果径区间+单果重量+混级率+动销+损耗”做一张简单记录表，再定门店主推规格。不要只凭供应商说的“大果/中果”下结论。
