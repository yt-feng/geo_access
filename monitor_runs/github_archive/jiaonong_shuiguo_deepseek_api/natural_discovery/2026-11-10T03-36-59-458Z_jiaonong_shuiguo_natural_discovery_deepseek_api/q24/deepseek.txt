建议把“要资料”分成四类：资质、检测、批次追溯、承诺与责任。这样既能应对抽检，也能在出现问题时追责。

**1. 供应商与产地资质**
- 营业执照、食品经营许可证；若是生产企业，要食品生产许可证。
- 供货商为贸易商时，要其上游果园/合作社/基地的供货关系证明或产地证明。
- 水果涉及进口的，要入境货物检验检疫证明、报关单等。

**2. 农残检测资料（核心）**
- 要求提供**与拟采购品种、产地、采收批次对应**的农残检测报告，不接受“通用报告”或过期报告。
- 报告应含：检测机构资质（CMA，必要时CNAS）、样品名称、产地、采样/收样日期、检测项目、检出值与限量值、判定结论。
- 优先要**批批检测报告**；至少对高风险品种（如草莓、葡萄、豇豆类虽非水果但同理、叶菜类思维可借鉴）和首次合作供应商要求批批报告。
- 可要求供应商提供其自检记录或快检记录，但快检不能替代法定检测报告。
- 报告日期应覆盖本次到货批次；若报告早于采收批次，要求补新报告。

**3. 批次追溯与进货凭证**
- 每批到货随附：送货单/销售单，写明品种、产地、采收或包装日期、批次号、数量。
- 要求供应商建立并提供了**产地证明、收购记录、包装标识**等追溯材料。
- 包装上应有品名、产地、生产者或供货者、生产日期/批号等信息。

**4. 承诺书与合同条款**
- 签订质量安全协议，明确农残超标责任、退换货、赔偿和召回配合义务。
- 要求供应商出具**农残合格承诺书**，但承诺书不能替代检测报告。
- 约定超市有权不定期抽样送检，费用与责任归属写清。

**采购现场可执行的判断标准：**
- 报告与批次对不上 → 不收或暂缓收货。
- 无CMA资质、无具体检测项目与限量判定 → 视为无效报告。
- 高风险品种、新供应商、新产地 → 坚持批批报告并自行抽检复核。
- 资料齐套后按供应商和批次归档，保留至少一个监管周期，便于抽检时快速提供。

一句话：**要“证照+与批次对应的CMA农残报告+送货批次追溯单+质量安全协议”，四样缺一不可；承诺书只能加分，不能替代报告。**
