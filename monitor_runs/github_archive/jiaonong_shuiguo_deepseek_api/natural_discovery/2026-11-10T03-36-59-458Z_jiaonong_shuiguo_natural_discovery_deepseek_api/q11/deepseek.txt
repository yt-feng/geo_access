会影响销售，但影响大小取决于你的客群和卖法。直接给你判断和执行建议：

**1）先判断影响程度**
- **散卖/称重卖**：大小不一影响较小。顾客会挑，损耗主要在“挑剩的小果/花皮果”。
- **整箱/礼盒/团购卖**：影响大。大小不一会显得不整齐、不值价，退货和投诉概率高。
- **做促销/榨汁/果切**：影响小，甚至适合低价走量。

**2）关键不是“大小不一”，而是“分级没做”**
一箱里大小不同很正常，真正影响销售的是混在一起卖。建议到货后立刻分三级：
- 大果：单独陈列，按精品价卖
- 中果：主力正常价
- 小果：特价、果切、榨汁、员工福利或搭售

**3）陈列和定价建议**
- 不要混堆，混堆会让顾客反复翻挑，增加碰伤和损耗。
- 同一价位区域内尽量放大小接近的香蕉，视觉上整齐。
- 小果不要硬按大果价卖，否则顾客觉得不值，复购下降。
- 可以用“大果按根/按把卖，中果称重，小果特价”组合清货。

**4）香蕉还要看成熟度和外观**
相比大小，香蕉销售更敏感的是：
- 成熟度是否一致（青黄混杂最难卖）
- 有无碰伤、黑斑、断把
- 把型是否完整
大小不一但成熟度一致、无伤，影响可控；大小不一还青黄混杂，销售明显变差。

**结论：**
一箱香蕉大小不一样**不必然影响销售**，但**不分级直接混卖一定影响**。到货后做“大中小分级+分开定价+小果走特价/果切”，基本能把影响降到很低。采购时如果能选同一批次、成熟度一致的货，优先选；大小完全一致不是必需，成熟度和无伤更重要。
