判断一批香蕉，核心是“看颜色、摸硬度、查果指和切口、闻气味、抽样切开”，再结合你预计几天卖完来决定能不能拿。

**1. 先定用途：你几天能卖完**
- 2～3天内卖完：可拿颜色偏黄、已开始软熟的货，价格通常更好，但风险高。
- 4～7天卖完：拿“黄中带绿、果指硬、棱角还明显”的货，后熟空间够。
- 超过7天：拿青硬货，但必须确认冷库/催熟条件和途中温度，否则易僵果或后期集中爆熟。

**2. 看颜色和成熟阶段**
- 全青硬：耐放，但要看是否有“僵青”、寒害斑。
- 青中带黄、果指饱满但棱角明显：适合批发周转。
- 黄多绿少、果柄开始转黄：已进入可食期，适合快销。
- 全黄、虎皮斑多、果柄发黑：熟度高，坏果风险大，只适合当天/次日清货。
- 注意：颜色均匀不代表安全，箱内中层和底层要翻看。

**3. 摸硬度和果指状态**
- 好货：果指饱满、手感结实有弹性，果指之间不粘手。
- 偏熟：整体发软、按压回弹慢。
- 高风险：局部软塌、果指发黏、果皮起皱、果柄一碰就脱。
- 同一箱里若上层硬、下层软，说明受热或压伤，坏果风险高。

**4. 查果柄、切口和果指连接处**
- 果柄切口新鲜、无霉、无黑腐，说明采后处理较好。
- 果柄发黑、发霉、流水，整把容易从柄部开始烂。
- 果指连接处有黑线、裂口、霉点，装箱后易传染。
- 香蕉“梳”与“梳”之间若有压痕、汁液，说明挤压伤，后面会黑烂。

**5. 闻气味**
- 正常：清淡青草味或轻微果香。
- 发酵味、酒味、酸味：内部已过熟或开始腐烂，别拿。
- 霉味：箱体或果柄已带霉菌，整批风险高。

**6. 抽样翻箱，别只看表层**
- 至少抽上、中、下三层和箱角。
- 看箱底有无汁液、黑斑、霉粉。
- 随机拿几根轻捏果指中部，感受是否有“软心”。
- 切开1～2根可疑果：果肉中心发暗、发褐、水化、有酒味，说明内部已坏。
- 看果皮黑斑：少量芝麻斑可接受；大片黑斑、凹陷黑斑、边缘水渍状，是坏果风险信号。

**7. 快速风险分级**
- 低风险：青硬或黄中带绿、果柄新鲜、无霉无汁、箱内硬度一致、无酒味。
- 中风险：黄多绿少、局部微软、少量芝麻斑、箱底轻微水汽；适合快进快出，压价拿。
- 高风险：全黄发软、果柄黑腐、箱底有汁、酒味/霉味、局部软塌；不建议拿，除非当天能低价清完且能挑出坏果。

**8. 拿货时的实操建议**
- 先问产地、采摘时间、运输温度、是否催熟过。
- 要求开箱翻底层，不接受只开上层。
- 同批货随机抽3～5箱，看成熟度是否一致；不一致就压价或分批拿。
- 合同/单据写明“到货坏果率超过X%怎么处理”，X按你渠道定，通常批发环节要提前约定。
- 夏季高温、长途运输、箱内积水是坏果高发条件，宁拿青硬不拿软黄。

一句话：**要周转快就拿黄中带绿、果柄新鲜、硬度一致的；看到全黄发软、柄黑、箱底有汁、有酒味，直接判高风险。**
