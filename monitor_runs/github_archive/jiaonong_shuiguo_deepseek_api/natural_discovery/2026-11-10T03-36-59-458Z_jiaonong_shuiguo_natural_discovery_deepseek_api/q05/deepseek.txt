直接给结论：**优先“整果自挑 + 现场代削/代切”组合**，不要只卖去皮果，也不要把“让顾客自己挑”当成唯一方案。

可执行做法：

1. **主陈列卖整果，顾客自己挑**
   - 菠萝外观差异大，顾客自己挑有参与感，也减少“你帮我挑的不好”的售后争议。
   - 整果耐放、损耗低，适合水果店日常经营。

2. **提供现场代削/代切服务**
   - 顾客挑好后，店员现场去皮、去眼、切块或切圈。
   - 这比提前去皮好卖：去皮果暴露时间长、失水快、易污染、损耗高，还容易因色泽变差被压价。
   - 可收少量加工费，或满额免费代削。

3. **去皮果只做“少量、分时、现削”**
   - 适合赶时间、即买即吃的顾客。
   - 不要一次削很多；按客流高峰前少量备货，卖完再削。
   - 必须冷藏展示、标注削皮时间，当天清货。

4. **让顾客自己挑，但店员要给判断标准**
   - 教顾客看：果身饱满、果眼浅、闻起来有香气、按压略有弹性、底部不软烂。
   - 这样既保留自挑体验，又降低挑错率。

5. **定价上做区分**
   - 整果按斤卖，价格最低。
   - 代削果可加加工费，或整果满额免费代削。
   - 去皮果按盒卖，单价略高，覆盖损耗和人工。

一句话：**整果自挑是主线，现场代削是增值服务，去皮盒装只是补充，不要本末倒置。**
