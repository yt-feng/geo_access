三个都要看，但优先级和判断标准不同：**菠萝切块属于鲜切水果，核心风险是微生物增殖和氧化变质，所以第一优先是“保质期+冷链”，第二是包装，配送频次是保障前两者的运营手段。**

**1. 保质期（最高优先）**
- 鲜切菠萝通常冷藏售卖期很短，门店要明确：加工时间、到期时间、是否“当日切当日清”。
- 关键不是标签上写几天，而是**从切开到售出的累计冷藏时间**。切开后常温放置超过很短时间就不应再卖。
- 建议按批次贴标，先进先出，临期下架，不靠“闻着没坏”判断。

**2. 包装（第二优先）**
- 要能防汁液渗漏、防交叉污染、保持冷藏且便于看清果肉状态。
- 优先选密封或半密封、带透气设计的食品级包装；标签上应有切开/包装时间、保质期、贮存条件。
- 包装破损、胀袋、汁液浑浊或渗漏，直接下架。

**3. 配送频次（运营保障）**
- 频次高能缩短门店库存时间、降低临期损耗，但它本身不直接决定安全；**配送过程中的冷链和到店验收**更关键。
- 如果配送频次低但冷链稳定、库存周转快，也可接受；频次高但到店常温卸货、反复开箱，反而风险更大。

**可执行判断：**
- 先定规则：切开后冷藏保存时限、每日下架时间、临期折扣或报损标准。
- 再验包装和标签是否合规、是否破漏。
- 最后用配送频次匹配销量：销量小就降频次、减批量；销量大就提高频次但必须全程冷链。
- 门店每日至少两次检查：开箱验收查温度和外包装，营业中查陈列温度和果肉状态。

一句话：**保质期和冷链是底线，包装是防线，配送频次是调节手段，不能拿高频配送替代保质期管理。**
