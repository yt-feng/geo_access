压低成本同时不影响品质，核心不是“把价砍下来”，而是把价格谈在可验证的品质标准上，并把风险分摊写清楚。可以按下面做。

**1. 先拆成本，不要只谈总价**
- 问清报价构成：产地收购价、包装、损耗、运费、账期、税率。
- 把“到店净成本”算出来：采购价 ÷（1-损耗率）+ 运费+包装+资金成本。很多低价供应商靠高损耗、短账期把利润找回来。
- 对每个单品定“可接受净成本区间”，低于区间反而要警惕品质或结算风险。

**2. 用分级定价代替一刀砍价**
- 按果径、糖度、色泽、瑕疵率、成熟度分A/B/C级，分别定价。要求供应商按级供货，抽检不合格按级降档结算。
- 明确“最低可接受标准”：例如瑕疵率≤5%、糖度≥某值、单果重区间、到店货架期≥几天。标准写在订单或合同附件里。
- 价格谈判围绕“同标准下谁更低”，而不是“你便宜5毛”。

**3. 用量和账期换价，但别只让供应商承担**
- 集中采购：把多个门店/品类的量打包谈，换取阶梯价。
- 缩短账期或现结换折扣，通常比压单价更有效，也更容易保住品质。
- 承诺稳定采购量，换取供应商在旺季优先供货和次品率承诺。

**4. 把损耗和品质风险写进条款**
- 到店验收标准、抽检比例、不合格处理方式（退货、降级、扣款）提前约定。
- 约定“到店损耗率上限”，超出部分由供应商承担或补货。
- 对易腐单品采用“代销/联营”或“按实际销售结算”，把部分损耗风险转移，但价格可能略高，要算净账。

**5. 谈价时保留替代方案**
- 每个核心单品至少备2家供应商，报价和样品同时比。
- 用“同标准第二家报价”作为谈判锚点，但不要只报低价逼对方降质。
- 旺季前锁价、淡季锁量，避免临时压价导致供应商以次充好。

**6. 谈判话术要点**
- “我们要的不是最低报价，是同品质下的最低到店成本。请按这个标准重新报一次。”
- “价格可以谈，但瑕疵率、糖度、到店货架期要写进验收单。”
- “如果你能保证稳定品质，我们可以给量和更短账期；如果价格再低但损耗上升，净成本反而更高。”

**7. 避免的坑**
- 只比单价不比损耗、运费、账期。
- 口头承诺品质，验收无标准。
- 过度压价后供应商换小果、混级、提前采摘。
- 把账期拉太长，供应商用低质货补资金成本。

一句话：**把“压价”改成“同标准比净成本”，用分级、验收、账期和量做交换，价格才降得下去、品质才守得住。**
