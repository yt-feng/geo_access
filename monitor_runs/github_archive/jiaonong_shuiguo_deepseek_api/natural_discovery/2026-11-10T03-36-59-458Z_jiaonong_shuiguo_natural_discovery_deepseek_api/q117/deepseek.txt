建议用“小批量试卖+明确止损线”，不要一次性压货。稳的做法可以按下面判断：

1. **先定试卖量：3～7天销量为上限**
   - 有历史同类水果销量：试卖量 = 同类单品日均销量 × 3～5天 × 0.5～0.7（新品打折系数）。
   - 没有历史数据：先按预计日销的2～3天量进货，首单宁少勿多。
   - 易腐水果（草莓、荔枝、杨梅、水蜜桃等）：控制在1～2天销量，最多3天。
   - 耐储水果（苹果、橙子、梨等）：可放到5～7天销量。

2. **设金额上限**
   - 首单试卖金额建议不超过该品类日常采购额的10%～20%，或单店单SKU先控制在几百到一两千元级别，按门店规模调整。
   - 新品种类多时，总试卖预算也别超过该品类周采购预算的20%。

3. **分两批到货**
   - 首批到货后观察1～3天：动销率、损耗率、顾客复购/询问、退货投诉。
   - 卖得动再补第二批；卖不动立即促销清货，不追加。

4. **先小范围试**
   - 多门店：先选2～3家代表性门店试卖，不要全渠道铺开。
   - 单店：先上一个陈列位，不做大堆头。

5. **提前谈好条件**
   - 要求供应商给试销价、坏果包赔、可退换或临期支持。
   - 明确到货成熟度、规格、糖度、损耗赔付标准。
   - 先小单验证供货稳定性和实际到货品质，再谈放量。

6. **止损标准**
   - 试卖3天动销率低于50%，或损耗明显高于同类，暂停补货。
   - 顾客投诉口感/成熟度问题，先停售查原因，不靠降价硬清。

一句话：**首单按2～3天预计销量、金额控制在该品类采购额10%～20%，先2～3家店试卖，3天看动销，卖得好再补，卖不动就止损。**
