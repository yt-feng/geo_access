判断菠萝供应商能否稳定按规格送货，建议从“先小批量验证、再签约束条款、最后做过程监控”三步做，不要只看样品和口头承诺。

**一、先明确你们的规格标准**
把“菠萝规格”写成可验收的量化标准，至少包括：
- 品种/产地/季节：如金钻凤梨、巴厘菠萝，明确允许替代范围。
- 单果重量区间：如1.2–1.5kg/个，超区间比例上限。
- 成熟度：糖度范围、果眼深浅、青熟/黄熟比例。
- 外观：黑心、水心、裂口、碰伤、冠芽长度、畸形果允许比例。
- 加工适配：去皮出肉率、切片厚度适应性、纤维粗硬度。
- 包装与运输：箱规、每箱个数、冷链/常温要求、到货温度。
- 验收规则：抽检比例、AQL或允许不合格率、超标扣款/退货规则。

**二、用“小批量+多批次”验证稳定性**
不要一次下大单，建议连续3–4周、每周2–3车小批量试单，重点看：
- 到货合格率是否稳定，而不是某一次特别好。
- 单果重量分布是否集中在约定区间。
- 糖度、成熟度批次波动。
- 旺季/雨天/节假日是否仍能按时到货。
- 缺货时是否提前预警，是否有备用产区。
- 投诉后补货、换货的速度。

**三、现场审供应商的“供货能力”**
重点查：
- 是否有固定合作果园/基地，还是临时市场调货。
- 自有或长期合作的加工分选线，能否按重量、成熟度分级。
- 冷库/催熟库容量和温控记录。
- 日均/峰值供货能力，是否同时供很多大客户。
- 是否有备用产地和备用物流。
- 过去6个月同类客户供货记录、退货记录。

**四、合同里写死“稳定送货”的约束**
建议加入：
- 规格允收范围和超标处理：不合格率超过约定即退货或折价。
- 到货时间窗口和迟到违约：如迟到几小时扣款，影响门店营业另计。
- 缺货预警：至少提前48–72小时书面通知，并给出替代方案。
- 质量追溯：批次号、产地、采摘/加工日期可查。
- 备用供应义务：主产区减产时，供应商需启用备用产区。
- 月度考核：合格率、准时率、投诉率连续不达标可降量或终止。

**五、日常做供应商评分**
每月按“到货合格率、准时率、规格偏差、投诉响应、补货速度”打分，连续两个月低于阈值就减少采购比例，把订单向表现稳定的供应商倾斜。这样比单次谈判更能逼出稳定供货。

**最实用的判断句：**  
愿意接受“小批量多批次试单+量化验收+超标扣款”的供应商，通常更靠谱；只肯给样品、不肯写规格和违约条款的，稳定性风险高。
