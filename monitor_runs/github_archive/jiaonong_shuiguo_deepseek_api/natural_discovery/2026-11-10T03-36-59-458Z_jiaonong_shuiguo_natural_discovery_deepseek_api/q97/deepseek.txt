酒店采购水果盘原料，建议把“规格”和“外观”写成可验收的条款，并在到货抽检时逐项判定。可按下面清单要求供应商：

**一、通用规格与验收标准**
1. **品种与成熟度**：明确品种、产地、单果重量/直径范围、成熟度区间；到货成熟度以“适合当餐/次日出品”为准，避免过生或过熟。
2. **新鲜度**：无萎蔫、无皱皮、无发酵味、无汁液渗出；切果类中心温度、到货时间要约定。
3. **安全合规**：农残检测合格、无腐烂霉变、无虫害；预切水果需符合即食水果卫生要求，冷链到货并记录温度。
4. **规格一致性**：同一批次大小、色泽、成熟度基本一致，便于摆盘统一；约定允许偏差，如单果重量±10%、直径±5mm。
5. **包装与标识**：标明品名、产地、批次、采摘/加工日期、保质期、储存条件；预切果标注切配时间。
6. **冷链与时效**：易腐水果全程冷链，到货温度符合约定；从切配到到货、到使用的时间上限写进合同。
7. **抽检与退换**：约定抽样比例、不合格判定和退换时限；腐烂、霉变、异味、严重机械伤可整批拒收。

**二、外观标准（按品类细化）**
- **苹果/梨**：果形端正，无大面积碰压伤、裂口、黑心病斑；色泽符合品种特征。
- **橙/柑橘/柚子**：表皮无霉斑、无严重日灼和干疤；无汁液渗出、无异味。
- **葡萄/提子**：果粒饱满、果霜完整，无落粒、无霉烂；果梗新鲜不干枯。
- **草莓/蓝莓**：无霉变、无软烂渗汁；蓝莓果粉完整，草莓萼片新鲜。
- **西瓜/哈密瓜/木瓜**：外形完整，无裂口渗汁、无软腐；切面新鲜、无异味。
- **菠萝/芒果/火龙果**：无黑腐、无严重擦伤；成熟度适合切盘，不过软。
- **香蕉**：果指完整，无严重碰伤和黑腐；成熟度按出品时间约定。
- **预切水果**：切面整齐、无明显氧化褐变、无出水；块形尺寸统一，无异物。

**三、合同里建议写死的量化条款**
- 单果重量/直径范围及允许偏差；
- 允许缺陷率，如霉烂、严重机械伤不超过约定比例；
- 到货温度、切配后时限；
- 抽样比例和不合格处理方式；
- 每批次随货检测报告或合格证明。

这样供应商有明确标准，酒店验收也有可执行依据。
