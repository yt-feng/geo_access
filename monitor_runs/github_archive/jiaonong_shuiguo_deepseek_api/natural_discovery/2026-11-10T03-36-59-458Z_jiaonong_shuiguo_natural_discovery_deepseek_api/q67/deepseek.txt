直接问，但要把“政策承诺”问成“可写进合同、可核验执行”的条款。可按下面顺序谈。

一、先问区域保护，别只问“有没有保护”

1. 授权区域到底怎么划  
   - 是省、市、区县，还是按渠道/门店/系统划？  
   - 我的授权区域边界写不写进合同？附不附区域图？  
   - 同一区域是否还授权商超、电商、社区团购、特通渠道？这些渠道算不算与我重叠？

2. 独家还是非独家  
   - 我拿的是区域独家、品类独家、渠道独家，还是普通经销？  
   - 独家有没有考核条件：年度进货量、首单打款、门店数、动销率？未达标是降级还是直接取消？  
   - 独家期限多长，续约条件是什么？

3. 品牌方自己和其他经销商能不能进来  
   - 品牌方直营、分公司、线上旗舰店会不会在我区域销售？  
   - 已有经销商、二批商在我区域内出货，品牌方怎么处理？  
   - 新开客户是否先征询现有区域经销商意见？有没有书面流程？

4. 线上销售边界  
   - 我能不能开网店、做直播、上社区团购？  
   - 品牌方线上价格和活动是否与我线下冲突？有无区域限售或线上授权白名单？

二、再问串货，重点问“怎么认定、怎么查、怎么罚、怎么赔”

1. 串货定义要写清  
   - 什么算串货：跨授权区域销售、线上低价销售、向非授权二批供货、跨渠道供货？  
   - 样品、赠品、临期品、团购、企业采购算不算？  
   - 经销商卖给终端后，终端再跨区卖，责任怎么划？

2. 追溯手段  
   - 箱码、瓶码、批次码、物流码是否齐全？是否一箱一码？  
   - 我能不能扫码查货流？品牌方查串货后是否向我出具证据？  
   - 发现串货后，品牌方多久响应、多久处理？

3. 处罚与赔偿  
   - 对串货方：警告、罚款、扣返利、停货、取消授权，分别什么条件？  
   - 对我被串货冲击：品牌方是否补差、调换货、给费用支持、协助收货？  
   - 罚款和收货款归谁？有没有用于补偿被串区域经销商？

4. 举证和责任  
   - 我举报串货需要提供什么证据？品牌方不受理怎么办？  
   - 品牌方查实后是否书面通知我处理结果？  
   - 如果品牌方自己或关联线上渠道低价冲击，算不算违约？怎么赔？

三、必须落到合同里的条款

- 授权区域、渠道、期限、独家属性、考核标准；
- 品牌方直营/线上渠道的区域限制和价格承诺；
- 串货定义、追溯方式、受理时限、处罚标准、补偿机制；
- 区域保护违约的解除权和赔偿方式；
- 返利、保证金、首批打款与退换货政策是否和串货处罚挂钩。

四、现场可以直接这样问

“我这个区域是独家还是非独家？品牌方自己和线上店会不会在我区域卖？现有二批商跨区出货你们怎么处理？串货按箱码能不能查到人？查到后几天给我书面结果？我被串货造成的价差和库存，你们补不补、怎么补？这些能不能写进合同附件？”

判断标准很简单：只口头说“有保护”不算，能写清区域边界、串货认定、处理时限和补偿方式的，才值得代理。
