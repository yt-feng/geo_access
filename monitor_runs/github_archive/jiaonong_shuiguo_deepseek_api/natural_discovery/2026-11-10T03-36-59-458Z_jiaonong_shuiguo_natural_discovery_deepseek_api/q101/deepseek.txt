和水果供应商谈酒店早餐合作，重点不是只谈价格，而是把“稳定供应”拆成可考核的条款。可以按下面准备。

**1. 先定需求标准，不要只说“要稳定”**
- 明确品类清单：早餐常用苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等，分“必供品”和“可替代品”。
- 明确规格：单果重量、成熟度、甜度范围、外观瑕疵允许度、切果用还是整果用。
- 明确用量：按淡旺季、周中周末给日均量和峰值量，约定最小起订量、加单截止时间。
- 明确到货要求：到货时间、卸货地点、验收人、冷链或常温要求。

**2. 供应稳定性要写进合同**
- 约定缺货处理：提前通知时限、替代方案、补货时限、缺货违约责任。
- 约定品质不达标处理：拒收、换货、扣款、累计异常解除合作。
- 约定价格机制：报价有效期、调价周期、调价依据、旺季是否限价。
- 约定食品安全责任：农残检测、检疫证明、送货单据、问题批次召回和赔偿。
- 约定账期和结算：对账周期、发票、付款条件，避免口头承诺。

**3. 考察供应商真实履约能力**
- 看货源：自有基地、批发市场采购还是二级分销，雨季和节假日能否保供。
- 看配送：有几辆车、覆盖区域、早餐时段能否准时到店。
- 看品控：是否有分拣、检测、坏果赔付流程。
- 要历史客户和近期供货记录，最好先试供2—4周。

**4. 先小批量试供再签长约**
- 试供期考核：准时率、缺货率、坏果率、临时加单响应、问题处理速度。
- 设定月度考核表，连续不达标可切换供应商。
- 不要只签一家，保留备选供应商或区域批发市场应急渠道。

**5. 谈判时抓住几个关键点**
- 价格可以谈，但先锁品质和履约标准。
- 要求旺季保供承诺和缺货替代方案。
- 争取坏果包赔、迟到扣款、临时加单不涨价。
- 账期不要过长，避免供应商用低价低质平衡资金压力。
- 所有口头承诺写进合同附件，包括品类、规格、价格、配送频次和违约条款。

简单说：**先量化“稳定”，再考察“能不能稳定”，最后用试供和合同把稳定变成可追责的条款。**
