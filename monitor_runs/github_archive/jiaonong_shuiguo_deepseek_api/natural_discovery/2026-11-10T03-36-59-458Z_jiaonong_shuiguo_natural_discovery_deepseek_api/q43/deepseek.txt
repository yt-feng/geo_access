评估水果供应商仓配覆盖，核心不是看“有没有仓”，而是看“从哪个仓、走哪条线、多久能到门店、水果在这种时效下还能不能卖”。建议按下面几步做成可判断的评估体系。

## 1. 先画门店与供应商仓配网络
把连锁门店按城市、商圈、门店类型、日均销量、温层需求（常温/冷藏/冷冻）列成清单；把供应商的仓、分仓、合作仓、干线线路、配送商列出来。形成一张“门店—仓—线路—时效”的矩阵，逐店标注：

- 最近可用仓是哪个
- 配送距离/预计在途时间
- 是否直配、越库、还是经城市分拨
- 是否具备冷藏/冷冻/多温区共配能力
- 每周可配送频次和截单时间

## 2. 按时效和水果品类分级评估
水果对时效和温控敏感度差异大，不能一刀切。建议按品类分级：

- **高敏感**：浆果、叶菜类水果、切果、熟度高的香蕉/芒果等，要求短在途、强冷链、少中转。
- **中敏感**：苹果、梨、柑橘、葡萄等，可接受一定在途，但怕挤压和温度波动。
- **低敏感**：耐储水果、根茎类，可适当放宽时效。

评估每个门店每个品类是否满足“**截单—发运—到店—上架**”的最长允许时长。超过即视为覆盖不足，而不是简单看距离。

## 3. 用四个硬指标打分
建议每个门店/城市按以下维度打分，形成覆盖评分：

1. **时效覆盖率**：能在要求时效内到店的门店占比；高敏感品类单独算。
2. **频次满足率**：供应商实际可配送频次 ÷ 门店需要的补货频次。
3. **温控达标率**：全程冷链/多温区能力覆盖的门店占比，重点看中转环节是否断链。
4. **履约稳定性**：近3—6个月准时到店率、破损率、缺货率、温度异常率。

这四项比“仓库数量”更能判断真实覆盖能力。

## 4. 做压力测试和成本测算
不要只看日常覆盖，要模拟：

- 节假日/大促峰值运力是否够
- 单一仓故障或线路中断时有无替代仓/替代线路
- 新开门店能否在开业前纳入配送
- 跨城调拨的响应时间
- 每店每品类到店履约成本，包括干线、城配、冷链、损耗

## 5. 输出可执行结论
最终形成一张“门店覆盖红黄绿灯表”：

- **绿灯**：时效、频次、温控、稳定性均达标，可直接纳入主供。
- **黄灯**：日常可覆盖但峰值或高敏感品类有风险，需备选仓/备选供应商。
- **红灯**：关键品类无法满足时效或温控，需设前置仓、城市分拨、改用本地供应商或调整配送频次。

## 6. 合同和运营上要落地的条款
评估后要把结论写进合作机制：

- 分城市/分品类约定到店时效和温控标准
- 约定截单时间、配送频次、异常响应时限
- 设置准时率、损耗率、温度异常率的考核与赔付
- 要求供应商提供仓配网络变更的提前通知
- 对红灯区域设置备选供应商或城市前置仓方案

简单判断标准：**如果某城市高敏感水果无法在门店要求时效内、全程温控不断链、且频次满足补货，就不能算有效覆盖。** 评估时以“门店—品类—时效—温控—频次”五个维度逐店打分，比只看供应商仓库数量可靠得多。
