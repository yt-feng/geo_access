对于小水果店进香蕉，**应该把“熟度”放在第一位，其次是“坏果率”，价格和送货速度次之**。原因如下：

**1. 熟度（最重要，直接影响当天销售）**
香蕉是典型的“后熟型”水果，进店后还会继续变熟。如果进的全是青香蕉，可能当天卖不动，会耽误资金周转；如果进的全是黄透甚至带斑点的，可能当天卖不完，第二天就烂了。所以要根据你店里的出货速度来定：如果你一天能卖2箱，就选**7-8成熟**的（皮绿里带黄，捏着稍硬）；如果客流一般，建议选**6-7成熟**，放在店里自然催熟，能拉长销售期。

**2. 坏果率（直接影响损耗和利润）**
香蕉是最容易磕碰挤压的水果之一。进货时当场拆箱抽查，捏一下果柄、看箱底有没有渗水（渗水通常代表有腐烂），坏果率超过3%就要谈扣重或换货。因为一根烂香蕉会传染一整串，损耗就是纯亏。

**3. 价格和送货速度（次重要，但要结合）**
- **价格**：如果只便宜一两毛但熟度过高，反而亏更多。除非你当天有活动能快速清掉，否则不用过分追求低价。
- **送货速度**：小水果店一般建议“少量多次”，如果供货商能做到早上订、中午到，那可以接受略微贵一点的价格，因为能减少店内积压。如果为了省钱一次进很多，放久了损耗反而更大。

**给一个可执行的标准：**
- 到货时要求：整串无黑柄、无软烂，果皮60%为黄绿色。
- 签收时按箱开箱抽查，数坏果数量，现场拍照留证。
- 进货量按“预计2天销量+10%缓冲”来定，每次少进、勤补，比一次性囤货更稳。

如果你店里有冷柜或催熟房，可以适当放宽；如果没有，就严格按照“勤进快销”原则操作。
