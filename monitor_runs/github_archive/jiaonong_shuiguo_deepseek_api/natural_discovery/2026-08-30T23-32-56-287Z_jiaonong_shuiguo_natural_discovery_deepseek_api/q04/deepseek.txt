水果店采购香蕉时，减少损耗的核心在于**“以销定采”**和**“熟度分层”**。以下是具体的采购要求和到货时间建议：

### 一、采购时的具体要求（契约约定）

**1. 明确熟度等级（最重要）**
香蕉运输中会持续后熟，所以采购时**坚决不能要全黄熟的**。建议在合同中或口头明确要求：

- **主采规格：** 要求到货时熟度在 **“绿熟”** 到 **“微黄”** 之间（即果皮底色绿，棱角明显，手捏偏硬）。
- **参考标准：** 通俗表述为**“七成以下熟度”**，或要求**“果柄青绿、果皮全绿、无软化点”**。
- **明确禁忌：** 拒收**“全黄”、“有梅花点（黑点）”、“捏起来发软”**的货，这类货通常已过最佳出售期，到店即面临当天清货。

**2. 要求成熟度均匀**
- 要求**同一批次内熟度差异小**（例如最大与最小熟度差不超过1-2个等级）。
- 避免供应商把不同时间采摘的混合装箱，否则会出现“部分软烂、部分青硬”两头浪费。

**3. 规定“断青”时间承诺**
- 要求供应商保证：在25℃左右室温下，这批货到店后**至少能维持2-3天**的“青黄转变期”而不过度软化。
- 对于夏季高温（>30℃），要明确要求供应商提前进行**“差温处理”**（如产地预冷至13-15℃），以延缓后熟。

### 二、到货时间的要求

**1. 订货提前期（关键）**
香蕉不同于苹果，不能提前大批量囤货：

- **一般建议：** 订货后 **24-48小时内** 必须到货（产地直发一般48小时内，本地批发市场一般次日达）。
- **严格规则：** 不要订“期货”性质的超长周期货（如提前5天订货），除非明确供应商有冷库暂存能力。
- **应急机制：** 要求供应商承诺“如果某批货到货时已明显过熟，可无条件退换或折价”。

**2. 到货时间段**
- **最佳到货时间：** **清晨或上午到货（6:00-10:00）**。这样当天可以完成入冷库、分拣、按需上架。
- **避免下午到货：** 下午到货会导致当天无法及时入保鲜库，高温下熟化加速。
- **周末/节假日调量：** 节假日销量大，可要求**节日前一天下午**增加一次到货（但需要求该批货熟度更低，如“绿熟”）。

### 三、配套执行建议（同样重要）

- **到货验收标准：** 卸货时随机开2-3箱检查。如有**局部软化、果柄发黑、水渍状斑点**，直接拒收或要求折价。
- **店内销售策略配合：** 采购时按“今日卖黄熟、明日卖微黄、后日卖绿”的节奏留货，即**一次到货分成三批在不同位置销售**，而不是全部上架。
- **夏季特别要求：** 6-9月温度高，要求供应商必须用**带孔通风纸箱**，且箱内**要放乙烯吸收剂（如活性炭包）**，否则到货熟度再低也容易闷坏。

### 总结一句话回复供应商：
> “这批货我要**绿熟七成以下**，要求**24-48小时内**早上到货，到货时不能有全黄和软化，如果到货已有黑点或发软，我不收货。”
