引入稳定的进口水果，建议**先从香蕉开始**，其次是菠萝，苹果可以作为后续扩展选项。

理由如下，便于你直接判断和执行：

**1. 香蕉（首选）**
- **供应链最成熟**：全球香蕉（尤其是菲律宾、厄瓜多尔产）海运和冷链物流体系非常稳定，价格波动小，损耗率低。
- **销售门槛低**：香蕉是大众接受度最高的水果，无需特殊营销，适合作为试水品类。
- **操作简单**：保质期相对可控，不需要复杂的催熟设备（商用催熟房可后期加装）。如果初期想完全稳定，可直接采购“即食香蕉”（已催熟），但成本略高。
  
**操作建议**：初期选择1-2个固定供应商，签订月度供应合同。到货后按“绿熟-黄熟”分批上架，避免一次性铺货。

**2. 菠萝（次选）**
- **供应链稳定**：泰国、菲律宾、哥斯达黎加产菠萝保鲜期较长（冷藏可达20天以上），适合海运。
- **风味差异化**：能吸引尝鲜顾客，但需注意削皮服务和口感一致性（建议提供免费切割服务）。
- **风险点**：进口菠萝价格季节波动略大，且消费者对“酸度”敏感，需提前做试吃活动。

**3. 苹果（不建议首批引入）**
- **竞争激烈**：国产红富士、花牛等苹果价格更低，进口苹果（如美国蛇果、新西兰爱妃）价格溢价高，若没有高端客群支撑，容易滞销。
- **仓储复杂**：需专业的控温控湿设备（0-4℃、相对湿度90%以上），初创期容易造成“虎皮病”等损耗。

---

**最终执行建议**：
- **首批**：只做香蕉（按周订货，先小批量试3周）。
- **第二个月**：加入菠萝作为互补品类（均价较高，客单价提升）。
- **如果前三个月月均损耗率低于8%，且周复购率超15%**，再考虑引入进口苹果，并同步做会员预定或礼盒装。

另外，务必在合同中明确“到货包装破损包赔”“到货后72小时内可退换”等条款，第一次订货量建议控制在日均销量的5倍以内。
