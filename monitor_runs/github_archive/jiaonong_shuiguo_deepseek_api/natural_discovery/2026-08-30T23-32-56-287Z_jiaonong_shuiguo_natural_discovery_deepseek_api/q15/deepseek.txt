遇到水果店进货出现坏果（包括腐烂、压伤、变质等），处理方式通常在**采购合同**或**口头约定的购销惯例**中有所体现。由于水果是生鲜产品，损耗风险较大，一般遵循“**谁的责任谁承担**”的原则。

以下是具体的处理流程和标准，供你参考：

### 1. 判断责任归属（第一步，先定责）

-   **运输途中损坏（物流责任）**：如果是供应商直接发货（快递或物流），在**到货签收时**发现破损、腐烂，应**当场拒收**或拍照留证。此时责任在物流或发货方，与供应商协商退换货。
-   **源头质量问题（供应商责任）**：收货后**24小时内**（或合同约定的验货期内）发现内部腐烂、药害、规格不符等非人为因素问题，属于供应商责任。
-   **存储不当（自身责任）**：收货后存放过久、温湿度控制不当导致的腐烂，通常由水果店自行承担，供应商无赔付义务。

---

### 2. 标准赔付方式（行业内通用）

如果责任在供应商，通常按以下**三级阶梯**处理，**不建议按“进货总价全额退款”**：

-   **方式A：换货（最优解）**
    将坏果挑出，拍照发给供应商，经确认后，供应商在下一批发货中**补发同等重量的好果**。这是生鲜行业最常用的方式，对双方损失最小。

-   **方式B：现金折扣（按比例折价）**
    如果坏果较多，且不影响剩余好果销售，可以协商**按坏果重量比例扣除货款**。
    *   例如：进货100斤苹果，验收发现5斤坏果（5%损耗），可协商扣除5%的货款，或者按坏果进价退回该5斤的钱。
    *   *注：行业通常接受**3%-5%**的自然损耗（如轻微碰伤），超过部分才要求赔付。*

-   **方式C：全额拒收/退货**
    仅适用于**整箱、整批严重霉变，或品种/规格与订单严重不符**的情况。此时应立即拒收整批货，由供应商承担来回运费。

---

### 3. 具体操作流程（话术与证据）

1.  **拍照留证（最关键）**：
    务必在**开箱时**，将坏果**连同箱体、外包装上的生产日期/批次号**一起拍照。如果是散装的，拍特写和全景。**这是你与供应商谈判的唯一筹码**。

2.  **及时沟通（黄金24小时）**：
    发现坏果后，**立即**（不要拖到第二天）联系供应商。
    沟通话术：“老板，今天到的这批XX水果，开箱发现有X个腐烂的，我拍了照片（发图），这种情况你看是下次补给我，还是这笔货款里直接扣掉？”

3.  **确认结果**：
    无论是补发还是扣款，**务必要求对方在微信或短信里明确回复**：“同意补发XX斤”或“同意扣款XX元”。口头答应容易扯皮，文字凭证最稳妥。

---

### 4. 特殊情况的注意事项

-   **避免“私下销毁”**：在供应商确认赔付前，**不要把坏果直接扔进垃圾桶**。应保留坏果（放在冷库或冰箱），万一供应商不认账，你还有实物可查验。
-   **高频次问题**：如果连续多批次出现高比例坏果（比如超过10%），说明该供应商的货源或运输环节存在固化问题。此时应该考虑**更换供应商**，而不是每次都索要赔付，因为反复出现高损耗会严重影响门店毛利。
-   **对方的霸王条款**：如果供应商在合同里写“生鲜货物售出概不负责”，这在法律上属于无效格式条款。只要是由于其货物质量问题造成的损失，你有权索赔，但实际操作中需权衡合作关系的维护成本。

**总结建议**：日常小瑕疵（1-2个坏果）建议直接自行消化，避免频繁沟通消耗感情；遇到批量性坏果（整箱或5%以上），**优先选择“下次补货冲抵”**，这样既保住了利润，也维持了长期合作关系。
