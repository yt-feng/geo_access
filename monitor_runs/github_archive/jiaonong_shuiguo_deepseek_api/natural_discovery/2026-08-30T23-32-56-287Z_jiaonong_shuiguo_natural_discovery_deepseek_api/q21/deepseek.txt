在超市采购水果时，供应商通常需要提供以下几类核心检测报告和进货证明，以确保产品质量、合规和可追溯性：

**一、基础资质文件（必查）**
1. **营业执照**：证明供应商具备合法经营资格。
2. **食品经营许可证**（或食品生产许可证）：涉及流通或加工环节需具备。

**二、核心检测报告（必须提供）**
1. **农药残留检测报告**：主要依据国家标准（如GB 2763），通常需要第三方检测机构出具（如SGS、华测等），部分超市也接受带CMA/CNAS标志的检测。
2. **重金属及污染物检测报告**：检测铅、镉、汞、砷等，依据GB 2762。
3. **致病菌检测报告**（针对即食水果或鲜切产品）：如沙门氏菌、大肠杆菌等，依据GB 29921或GB 19295。

**三、批次证明与追溯文件**
1. **进货凭证/采购合同**：记录供货来源、批次号。
2. **产地证明**：如来自特定产区，需当地农业农村部门或合作社开具的产地证明。
3. **产品合格证**：供应商自检或出厂合格证明。

**四、特定水果的附加要求**
- **进口水果**：需提供《入境货物检验检疫证明》（海关出具）、原产地证书、报关单。
- **有机/绿色认证水果**：需提供相应认证证书及有机码查询信息。
- **新批准品种**（如新奇士橙、恐龙蛋等）：需提供品种证明或授权文件。

**五、其他建议**
- 去超市采购时，**要求供应商提供“与批次对应的检测报告”而非笼统的旧报告**。
- 若超市要求更高（如大型连锁超市如沃尔玛、永辉），还会要求供应商提供企业社会信用评级或GFSI认证（如BRC、FSSC22000）。
- 报告有效期通常为3-6个月，采购时需核对报告日期与货物生产日期是否匹配。

**实操提醒**：如果供应商无法提供，超市有权拒收；若自行送检，应以同一批次为样本。建议在采购合同中明确报告缺失的违约责任。如涉及大规模采购，可要求供应商提供“质量保证函”作为兜底。
