在便利店上架香蕉时，**推荐优先选择“单根”和“小把（2-3根）混合销售”的组合，不建议只卖整袋包装。**

原因如下，你可以根据店铺位置和客流情况调整配比：

**1. 单根包装（最适合商圈、写字楼、地铁口）**
- **核心优势：** 解决“买多吃不完”的痛点。适合单人、白领早餐或加餐。
- **销售逻辑：** 方便即拿即走，即使价格略高，消费者也愿意为便利性买单。
- **风险：** 损耗相对较高，因为剥皮试吃或挑拣频繁。

**2. 小把包装（2-3根，最佳推荐）**
- **核心优势：** 兼顾“新鲜”和“适量”。比单根显得划算，又比整把更容易在24小时内吃完。
- **销售逻辑：** 适合小家庭或年轻情侣，是便利店最主流的形态，复购率稳定。

**3. 整袋包装（不建议作为主力）**
- **问题：** 整袋通常指5斤以上。除非你的店是社区型生鲜便利店，且顾客有明确的囤货需求，否则**非常容易积压损耗**。香蕉熟得快，整袋卖不动时，第二天就会发黑，只能当止损品处理。

---

**具体执行建议（实操层面）：**

- **陈列方式：** 建议**70%小把 + 30%单根**。小把放在黄金视线区，单根放收银台旁或冷柜边上的小挂篮里。
- **定价策略：** 单根定**3-4元**（按个卖），小把定**7-9元**（按把卖）。避免按斤称重算钱，便利店按份卖效率更高。
- **关键动作：** 一定要配置**电子标签机**，打印“特价/新鲜到店”标签，并标注“今日鲜”或“8点后半价”，有效控制损耗。

**特别注意：** 香蕉怕压、怕闷，陈列时不要多层摞放，保持表皮干燥，避免被其他硬物（如可乐、牛奶瓶）挤压。如果店铺有冷藏柜，别放冷藏柜，放常温反而熟度更均匀。
