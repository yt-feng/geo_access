小商家采购水果，现金结算和月结账期各有明显风险，具体如下：

### 一、现金结算（一手交钱一手交货）
**风险点：**
1. **价格波动风险**：水果价格受季节、天气、运输影响大，现金买断后，如果次日行情下跌，货砸手里，亏的是自己。
2. **品质风险**：现金交易往往“出门不认账”。如果当场没仔细验货（比如外表光鲜但内部烂、重量短斤少两），后续发现坏果、次果，供应商大概率不负责。
3. **资金占用风险**：现金采购意味着钱立即流出，小商家现金流紧张，一旦水果滞销，资金链容易断裂。
4. **腐败风险（人为）**：个别采购人员可能吃回扣（报价虚高、以次充好），现金交易难以审计。

**适合场景**：采购量小、临时补货、供应商信誉差、价格极低且可现场质检。

---

### 二、月结账期（先拿货，月底/次月结款）
**风险点：**
1. **供应商跑路/断供风险**：如果供应商规模小、资金链紧张，可能收不到款后不再供货，甚至卷款消失，你的货款变成坏账。
2. **账期纠纷风险**：水果易腐，如果货到有坏果，供应商拖延不赔，月底结算时容易扯皮（如“这款已扣了，但你没记录”）。
3. **供应商抬高风险**：月结通常意味着单价略高于现金价（供应商转嫁资金成本），如果长期算下来，成本可能高出3%-8%。
4. **财务漏洞风险**：小商家如果不开正规发票、不做台账，月底对账可能糊涂账，甚至出现“供应商报多，你少付了”导致断货。
5. **依赖风险**：一旦养成月结习惯，供应商可能用“账期”绑架你，逼你继续从他家进货，否则不结清旧账不供货。

**适合场景**：供应商规模大、信誉好、货源稳定；你长期需要稳定供货，且有能力做账和管理现金流。

---

### 三、实用建议（可执行）
1. **不要极端化**：现金和月结可以结合。比如：订货量＜500元用现金（减风险），订货量＞2000元且供应商合作超3个月用月结。
2. **现金采购时**：一定要当场开箱抽样（上下、中间都查），称重复秤，并保留进货单（日期、品种、数量、单价）。
3. **月结时**：务必让供应商开正规收据/发票，每次收货后24小时内拍照留档，月底对账以留档为准。
4. **风险对冲**：现金采购时，可要求供应商“保价3天”（若3天内跌价，补差价或下次抵扣）。
5. **测试供应商**：第一次合作只现金，连续3次无质量问题，再谈月结。月结首单金额控制在1万元以内试水。

**核心原则**：先控制品质，再谈账期。如果水果新鲜度和损耗率控制不了，账期再长也没意义。小商家抗风险能力弱，宁可少赚，不要欠账烂账。
