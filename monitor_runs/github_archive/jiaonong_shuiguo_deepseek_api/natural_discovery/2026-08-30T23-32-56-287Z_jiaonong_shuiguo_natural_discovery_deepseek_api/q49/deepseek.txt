茶饮店旺季菠萝用量突然变大，和供应商谈临时补货的核心是 **“锁定价格+保障到货时间+明确品质标准”** ，同时要留好退路（防止供应商趁机抬价或卖次品）。

以下是具体的操作步骤和话术建议：

**第一步：提前沟通，明确“紧急但长期”的定位**
不要只说“我要加单”，要强调这是旺季常态需求，而不是一次性危机。这样供应商才愿意配合。

- **话术**：“王总，我们菠萝用量这几天翻了不止一倍，店里天天断货。这个趋势至少会持续到9月底，我们想跟你锁定接下来X周的稳定供应量，价格上您千万得给我们旺季优惠价，长期合作嘛。”

**第二步：约定三个核心条款（必须白纸黑字或文字确认）**

1. **到货时效（最优先）** ：
   - 明确要求：**每日（或每2日）固定到货**，并设置“缺货应急响应时间”（如：今日下午3点前下单，次日上午10点前必须到店）。
   - 如果对方表示运力紧张，可以主动支付合理的加急运费，但要求对方承诺“优先排产”。

2. **价格锁定机制**：
   - 旺季水果价格波动大，建议约定**“阶梯价”**或**“周结价”**，避免供应商按当天市场行情临时涨价。
   - 可以提出：“本周我按每斤X元跟你签，但如果下周市场价降了，你要同步给我降；如果涨了，我最多接受涨幅不超过X%。”这样双方都有保障。

3. **品质标准（防止以次充好）**：
   - 明确验收标准：**糖度不低于XX度，无霉斑、无软烂，单果重量不低于XX克**。
   - 约定“到货即检，抽检不合格整批退换”。

**第三步：用“合同或微信文字”锁定，并设置违约条款**
- 即使合作很久，也要在微信或邮件里明确：“好的，那就按您刚才说的，明天开始每天X箱，单价比上周高X毛，保证次日上午10点前送到，抽检不合格我拒收。如果连续两次延误，我就要临时找备选供应商了。”
- 这样即使对方口头答应，事后如果出问题，你有依据。

**第四步：准备“B计划”（应急预案）**
- 旺季供应商容易“店大欺客”，建议**同时联系1-2家备选供应商**（批发市场档口或本地水果商），并提前问好：“如果今天下午我加急要200斤，您明天早上能送到吗？”一旦主供应商掉链子，你能立刻切换。

**第五步：补救性措施（如果供应商实在供不上）**
- 考虑**混合采购**：先让供应商供60%的量，剩余部分从批发市场“零售采购”应急。
- 如果菠萝是核心原料，可以考虑改用**冷冻菠萝丁或菠萝罐头**作为短期替代，虽然口感略差，但能保证不断货（前提是顾客不挑剔）。

---

**特别提醒：**
- **不要一次性囤太多**，菠萝保质期短，旺季天气热更容易坏，宁可每日少量多次补货，也别囤货积压。
- **签合同前先付定金**（比如总价的20%），让供应商有动力优先供你货，但定金条款要写明“若供不上货双倍返还”。

最后，直接给供应商发一条明确的消息即可，比如：
> “老板，菠萝量我们这几天涨得凶，明天起每天需增至500斤，价格按今天批发价上浮5%以内我们接受，但必须保证**次日早9点前到店**，品质不能掉（发霉软烂不收）。如果连续两次迟到，我就要急调别家，您看这样行不行？”

这段话既给了对方利润空间，又划清了底线，对方通常愿意配合。
