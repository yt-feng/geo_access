针对单位采购水果，如果到货品质不一致，这是一个非常常见的采购风险点。为了保障单位权益，建议从**验收规范**和**售后处理**两个维度严格把控，具体操作如下：

### 一、验收规范（到货时立即执行）

1.  **全员到场、拍照留证**
    -   务必由采购经办人、使用部门代表（或仓库管理员）共同在场验收，**不要单独一人签收**。
    -   每个批次、每个品种都要拍摄**开箱前**（外包装完整）和**开箱后**（内部水果情况）的对比照片及视频，最好包含时间水印。

2.  **按“样品标准”比对**
    -   合同或报价单中一般会约定规格（如：单果重量、直径、成熟度、糖度）。验收时，随机抽取**5%-10%**的箱子，拆箱检查。
    -   关注重点：**糖度/成熟度**（是否过生或过熟）、**物理损伤**（压伤、碰伤、腐烂）、**规格大小**（是否以次充好，比如约定中大果，实际混入小果）。

3.  **分拣定级**
    -   如果有明显不一致，立刻进行现场分拣：合格品、轻微瑕疵品（可降价处理）、严重次品（拒收）。
    -   记录各等级的**具体数量（公斤数）**，这是后续谈判的原始凭证。

4.  **拒收与暂收**
    -   **坚决拒收**：大面积腐烂、发霉、有明显变质特征的水果。
    -   **暂收处理**：对于成熟度不足（未熟）或轻微瑕疵的，可以暂收，但必须在签收单上注明“暂收待定，需售后处理”，不要让供应商日后推诿。

---

### 二、售后处理（签收后24小时内）

1.  **提交书面凭证**
    -   在验收后**24小时内**（水果易腐，时间窗口越快越好），向供应商出具《水果验收异常报告》，附上照片、视频和称重记录。
    -   报告中需明确列举问题点：例如“约定单果200克，实际抽查100个中，35个低于150克”。

2.  **协商解决方案（按优先级）**
    -   **方案A：补货（首选）**。对于品质不符的部分，要求供应商在指定时间内（如次日）补齐同等品质的新鲜水果。
    -   **方案B：折价（次选）**。如果补货来不及（比如活动当天），按降级后的市场价格重新核价，直接扣除差价部分。
    -   **方案C：退货退款**。若问题严重（如80%以上不合格），全批次拒收退货，并要求供应商承担运输及相关误工费用。

3.  **设定售后期限**
    -   水果有后熟期（如香蕉、猕猴桃）。建议约定**3-5天的“最佳食用期”**。若在签收后第2-3天出现内部腐烂（非外部损伤），供应商也需承担一定比例的“隐性问题”赔付。

---

### 三、特别提醒（法律与合同层面）

-   **合同留痕**：如果这项采购是长期合作，建议在采购合同中明确写入：“单批次合格率需达到95%以上，若不合格率超过5%，供应商需无条件补货或按1:1.5的比例折价赔偿。”
-   **防“好果掺次果”**：很多供应商表面样品是好的，但底部或中间会夹杂次果。验收时务必**翻箱检查底部**，或要求供应商提前装箱后贴封条。
-   **处理速度**：水果售后黄金期就是**24-48小时**。拖得越久，供应商越容易以“储存不当”为由拒绝赔付。

**总结一句话**：到货先拍照分拣，问题不解决不签“合格”单；售后列出表格，只谈“数量”和“证据”，不吵“态度”。这样可以最大程度保障单位的采购利益。
