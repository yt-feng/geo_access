茶饮店在选择水果供应商时，为了控制食品安全风险，核心是核验供应商的**资质合规性**和**产品追溯能力**。以下是你需要向水果供应商索要的关键证明文件，建议按类别整理并定期更新（通常每年核验一次，批次性产品每批次索要）：

### 一、 供应商主体资质（证明其合法经营）
1. **营业执照**：经营范围须包含“水果销售”或“食用农产品销售”。
2. **食品经营许可证**（或仅销售预包装食品备案证明）：如果供应商涉及水果分装、切配或初加工，必须有此证。
3. **种植基地备案证明**（如果源头直采）：如果是大型农场直供，需要提供**食用农产品合格证**或产地准出证明。

### 二、 产品批次证明（证明该批水果安全）
1. **食用农产品合格证**（俗称“一票通”）：这是最核心的证明，需包含产品名称、数量、产地、生产者信息、开具日期及质量承诺。
2. **农药残留检测报告**：
   - 必须由**具有CMA或CNAS资质**的第三方检测机构出具。
   - 检测项目须覆盖茶饮店常用的高风险农药（如：毒死蜱、克百威、氧乐果、甲胺磷等）。
   - **注意**：报告日期须与供货批次接近，一般要求**每批次**提供（尤其对于草莓、葡萄、柑橘类等易残留水果），至少每月或每两周更新一次。
3. **重金属检测报告**（针对长期合作的固定品种，如苹果、梨等）：重点检测铅、镉、总砷、总汞。

### 三、 运输与储存证明（证明冷链不断链）
1. **运输车辆温度记录**：如果水果需要冷链运输，供应商需提供运输过程中的温度监控记录截图或数据，确保在2-8℃（或按水果品种要求）环境下运输。
2. **仓库温湿度记录**：要求供应商提供其存储仓库的温湿度日常记录表（近一周内）。

### 四、 追踪与应急文件
1. **进货查验记录**：你方需自行建立台账，但供应商需配合提供**产品流向记录**（即该批水果从产地到你的仓库的完整链路）。
2. **召回与赔付承诺函**：要求供应商书面承诺，如因水果导致食品安全问题，需无条件召回并承担连带责任。

### 五、 实操建议（避免踩坑）
- **非“一刀切”**：对于小规模农户直供，可要求其提供**村级或乡镇开具的产地证明** + **快速检测卡（胶体金）检测结果**，并保留身份证复印件。
- **动态核查**：建议每季度通过“国家企业信用信息公示系统”核查供应商是否有行政处罚记录（如检测不合格、经营异常）。
- **特殊水果要求**：
  - **鲜切水果（如西瓜切块、芒果切块）**：必须要求供应商提供**食品生产许可证（SC证）**，并按即食食品标准提供**菌落总数/大肠菌群**检测报告。
  - **进口水果**：需提供**进境动植物检疫许可证**和**海关报关单**，以及供应商的**入境货物检验检疫证明**。

### 六、 风险提示
- 如果供应商无法提供**食用农产品合格证**且**无检测报告**，属于高风险情况，**建议直接更换供应商**。
- 务必保存好所有文件的**电子扫描件**，并在茶饮店显眼位置留存《供应商资质公示栏》备查，以满足当地市场监管局的日常检查要求。
