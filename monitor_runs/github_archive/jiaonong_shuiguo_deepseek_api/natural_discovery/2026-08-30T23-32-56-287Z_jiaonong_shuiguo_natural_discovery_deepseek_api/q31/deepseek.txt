在为连锁商超招标长期水果供应商时，评分标准的设计需要平衡**长期稳定性**、**品质安全**和**成本效率**。如果标准设置过松，容易导致履约困难；过严则可能流标或只剩个别高价供应商。

以下是6个核心评分维度的建议及权重分配（满分100分），供招标文件参考：

**1. 供应保障能力（权重：25分）**
*注意：长期合作的核心是“不断供”，而非单纯价格便宜。*
- **基地资源证明（10分）**：自有种植基地面积、合作基地数量及产权证明（是否具备跨区域供货能力）。
- **应急调配方案（10分）**：针对台风、节假日爆单、产地受灾时的替代货源预案（需有具体供应商名录或备用仓地址）。
- **冷库及物流设施（5分）**：自有冷链车辆数、仓储面积、最后一公里配送时效承诺（如：下单后24小时内送达门店）。

**2. 品质与安全标准（权重：30分）**
*注意：生鲜类安全事故对品牌影响极大，此项应是最高权重。*
- **检测报告（10分）**：农残检测报告（必须）、重金属检测、针对当季高风险品种（如草莓、豇豆）的专项检测。
- **分级标准清晰度（10分）**：是否按大小、色泽、糖度进行明确分级（如A/B/C级），并承诺混级率低于3%。
- **退换货机制（10分）**：生鲜损耗率超标时（如≥5%），供应商承担的赔付比例及快速补货响应时间。

**3. 价格竞争力（权重：20分）**
- **综合报价单（10分）**：按品类报出基地价/批发价，需包含**含税价**与**不含税价**。
- **价格联动机制（10分）**：若未来6个月产地价格波动超过±10%，如何调整订单价（建议参考当地农业农村厅发布的“周报价格指数”，而非单纯看CPI）。

**4. 供货稳定性与历史业绩（权重：15分）**
- **既往案例（10分）**：近2年内服务商超或团餐企业的年平均履约率（可用甲方签收单或对账单证明）。
- **单品持续性（5分）**：对于应季水果（如国产车厘子、阳光玫瑰），可从几月供应到几月，空窗期是否可补库存水果。

**5. 服务与信息化水平（权重：10分）**
- **订货系统对接能力（5分）**：能否使用ERP系统或APP接单，实现电子化对账。
- **驻场/巡店服务（5分）**：每周巡店次数、是否提供季节性新品的试吃培训和营销方案支持。

**6. 否决项（一票否决）**
- 发现提供虚假产地证明或检测报告。
- 近3年有工商行政处罚记录或食品安全事故记录。

---

**给招标方的特别建议：**

1. **不要只看最低价**：建议在评分表中设置“剔除异常低价”条款（如低于平均价15%以上需提供成本构成说明），以防低价中标后中途以次充好。
2. **增加“试供期”评分**：可以设15-30天的试供期，期间的分货质量、损耗率按**30%权重**折算进入总评分。
3. **明确履约保证金**：建议在合同条款中规定，评分高的供应商可降低保证金比例，作为优质供应商的激励。

**如果贵司实际采购量较小，可以简化标准：** 重点收紧“品质检测报告”和“账期”两项，其余维度可适当降低权重。
