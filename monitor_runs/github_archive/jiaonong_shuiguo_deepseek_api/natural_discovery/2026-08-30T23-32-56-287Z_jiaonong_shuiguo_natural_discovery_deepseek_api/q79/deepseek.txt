选水果供应商时，**最核心的顺序是：先问售后政策，再问配送细节，最后谈价格**。理由如下：

**1. 先问售后（决定你能不能长期做）**  
水果是生鲜，损耗和品质波动不可避免。如果供应商没有明确、可执行的售后标准（比如烂果、坏果、重量不足怎么赔，赔付比例是多少，多久内受理），一旦出了问题，你的佣金和口碑都会受损。  
**建议必问**：  
- “如果到货有10%以上坏果/烂果，是全额退款、按比例补货还是只退坏果钱？”  
- “售后申报的流程是什么？需要拍视频还是称重？”  
- “遇极端天气导致延迟，你们是否会主动担责？”

**2. 再问配送（决定履约体验和成本）**  
配送决定了水果的新鲜度、破损率和你自己的组装时间。  
**建议必问**：  
- “你们从采摘/产地到我这，全程冷链还是普通快递？大概几天到？”  
- “能指定送货日吗？能预约上午/下午时段吗？”  
- “一箱多少件起送？运费怎么算？如果补货，运费谁承担？”

**3. 最后谈价格（因为价格是结果）**  
价格高低取决于品质和供应量，但若前面两项没保障，便宜的价格反而是陷阱。  
**建议必问**：  
- “这个价格含税、含运费吗？是统货价还是分拣后的一级果价？”  
- “如果长期合作、量多，最低能压到什么点位？”  
- “季节性涨价时是否提前通知？能锁定稳定价格多久？”

---

**给你的实操建议**：  
- 先挑2-3家供应商，每家**只发一箱样品**，用“坏果率+到货时间+实际口感”验证，再综合比价。  
- 谈判时把售后条款写进**书面协议或聊天记录**，避免口头承诺。  
- 初期少量试跑3次，再决定是否长期合作，不要一次性压太多货。  

**简单记：售后保命，配送保鲜，价格保利。** 顺序别反过来。
