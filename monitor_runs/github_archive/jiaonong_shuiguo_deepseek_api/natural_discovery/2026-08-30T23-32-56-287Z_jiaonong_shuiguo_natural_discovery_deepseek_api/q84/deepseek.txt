针对家庭水果礼盒，建议以“口味均衡、颜色丰富、耐储存”为原则，并兼顾不同年龄段的食用习惯。以下是比较稳妥的组合方案，供你参考：

**核心推荐组合（性价比高、适口性强）**

- **苹果（2个）**：选红富士或冰糖心，脆甜，耐放，家庭接受度最高。
- **橙子（2-3个）**：选赣南脐橙或冰糖橙，补充维C，酸甜解腻。
- **香蕉（1把，约4-5根）**：选熟度适中（表皮微黄带青），老人小孩都方便吃，且能缓解便秘。
- **菠萝（半个或1个小个）**：选金钻菠萝（无眼刺少），切块后装盒，口感酸甜多汁，能增加热带风情感。

**搭配逻辑：**
- 苹果+橙子属于“基础硬货”，价格波动小，送礼不易出错。
- 香蕉是“软糯担当”，给老人和小孩吃最合适。
- 菠萝提供清新果香和色彩亮点，但注意提醒客户“切开后建议当天食用，或冷藏保存2天内吃完”。

**额外建议（避免踩坑）：**
- 如果家庭中有3岁以下幼儿，**菠萝建议替换成圣女果或火龙果**，因为菠萝酸度可能刺激孩子肠胃。
- 如果客单价允许，可将苹果改为“嘎啦果”或“阿克苏”，将橙子改为“新奇士”，提升礼盒质感。
- 包装时注意：菠萝最好用独立保鲜袋或隔层垫垫好，避免汁水浸湿其他水果；香蕉根部用保鲜膜包好，防氧化变黑。

**你可以这样向客户推荐：**
“这个组合是‘硬脆+软糯+多汁’搭配，切开后颜色有红、黄、橙，摆盘都好看。苹果橙子常温放，香蕉别压，菠萝切好的放冰箱冷藏，一家三口两三天就能吃完，不浪费。”

如果需要更高端版本，可将苹果换成“红蛇果”，橙子换成“褚橙”，菠萝换成“都乐金菠萝”，并根据季节替换时令水果（如秋天加石榴/冬枣）。
