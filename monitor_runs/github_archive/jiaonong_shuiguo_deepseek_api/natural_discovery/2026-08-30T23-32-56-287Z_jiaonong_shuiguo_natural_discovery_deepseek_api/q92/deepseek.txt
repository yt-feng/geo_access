针对便利店面积小、水果品类和损耗的控制，核心逻辑是 **“少而精、快周转、高毛利、鲜陈列”** 。以下是具体的执行建议：

**一、 品类控制原则（少而精）**

1.  **SKU数量极简**：建议控制在 **10-15个** SKU以内。不要追求“全”，要追求“精”。
2.  **主打“即食型”与“小包装”**：
    -   避开大西瓜、整箱苹果等大果（不好陈列、损耗大）。
    -   优选**香蕉、苹果、梨、橘子/橙子、圣女果、黄瓜**等高频刚需品。
    -   增加**切块果盘/果切**（如西瓜切块、菠萝蜜、哈密瓜杯），毛利高且消化库存。
3.  **按季节和天气调整**：
    -   夏天主推西瓜（切块）、荔枝、水蜜桃。
    -   冬天主推柑橘类、草莓、甘蔗（切段）。
    -   **雨天或寒流天**，水果需求下降，当日采购量需下调30%-50%，主推耐储存的苹果、梨。

**二、 损耗控制核心策略**

1.  **采购端（防源头损耗）**：
    -   **只买“当天熟”**：进货时认准八成熟，不要买全熟（当天卖不完必烂）。
    -   **少量多次进货**：如果条件允许，一天进2次（早上一批，下午补一批），不要一次性囤3天量。
    -   **去批发市场盯货**：亲自挑选，不要电话订货，防止供应商塞次品。
2.  **门店端（防陈列损耗）**：
    -   **“先进先出”强制原则**：新水果必须放在旧水果**下面或后面**，表面层放刚上架的。
    -   **分级销售**：将轻微碰伤、品相不佳的水果挑出来，**立即制作成果切或“特价盲盒”**，10分钟内结账，避免烂在货架上。
    -   **控制陈列面积**：货架只摆**一层**（不要堆高），宁可空位也不多摆，缺货反而显得新鲜。
3.  **数据端（防预测损耗）**：
    -   每天晚上盘点是核心理念：**先卖成熟货，再卖新货**。
    -   建立“前日销量记录表”，记录每个SKU的当日销量，以**3天平均销量作为次日订货基准**，不要凭感觉订货。

**三、 高损耗单品避坑指南**

-   **谨慎上架**：**榴莲、菠萝蜜、山竹**等（热带果熟度难控，且需冷藏）。
-   **坚决不上架**：**杨梅、桑葚**等（极易破皮出水）。
-   **替代方案**：如果非卖不可，只卖**预包装**（盒装）或**冷冻果肉**。

**四、 特殊情况处理（应急方案）**

-   **暴雨/极端天气**：提前一天将采购量减半，主推苹果、梨、香蕉（耐放）。
-   **节假日（如春节）**：水果需求暴增，可提前一天备好**整箱礼盒装**（保质期长），散货适当增量。
-   **损耗已发生**：当品质下降但未变质时，**优先降价抛售（下班前30分钟7折）**，超过保质期的**立即报损丢弃**，绝不允许以次充好，防止砸招牌。

**执行清单（可直接打印贴仓库）：**
> 1. 每日订货 = 昨日销量 × 0.8（留出安全边际）。
> 2. 所有水果上架前用湿毛巾擦净，禁用水洗（易烂）。
> 3. 香蕉悬挂式陈列（不接触桌面，减少压伤）。
> 4. 果切区必须配备冰袋或冷藏展示柜，温度控制在5°C以下。
> 5. 每周日进行一次库存全面盘点，超3天的单品强制促销。
