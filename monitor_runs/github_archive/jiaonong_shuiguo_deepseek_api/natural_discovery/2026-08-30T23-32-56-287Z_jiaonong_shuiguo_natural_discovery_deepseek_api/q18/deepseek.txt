在超市采购香蕉时，要避免买到太生或太熟，可以参考以下几个实用技巧：

**1. 看颜色，选“黄中带绿”**
- **最佳状态**：表皮金黄，但果柄（连接香蕉的那根短把）仍带一点绿色。这种香蕉通常能放2-3天，刚刚好。
- **太生**：整根香蕉包括果柄都是青绿色，捏起来硬邦邦，买回去放很久才熟，且可能涩口。
- **太熟**：表皮出现大面积黑斑（麻点），或者果柄发黑发软，捏起来非常软，这种通常当天必须吃完，否则会烂。

**2. 用手感判断成熟度**
- **轻捏香蕉中部**（不要捏两端）：
  - 摸起来**有弹性**，但**不凹陷** → 最佳。
  - **硬邦邦** → 偏生。
  - **一按就软榻、有汁液渗出** → 过熟，不要买。
- **注意**：不要买表皮有压痕、破皮的，即使里面没坏，也极易变质。

**3. 看果柄和棱角**
- **果柄粗壮、带点绿** → 新鲜。
- **果柄发黑、干枯** → 放置时间较长。
- **棱角分明**（香蕉侧面有明显的五条棱线）→ 比较生。
- **棱角圆润**（侧面几乎看不到棱线，看起来圆滚滚）→ 成熟度刚好。

**4. 按需购买，不要贪多**
- 如果你打算**当天吃** → 选表皮有极少量小黑点（甜度最高）。
- 如果你打算**放2-3天** → 选黄中带绿。
- 如果你买得多，建议**混搭**：拿一两根全黄的，再拿几根偏绿的，每天吃不同成熟度的，避免全部同时熟。

**5. 特殊情况提示**
- 超市里**已经成串包装**的香蕉，如果其中一根已出现大片黑斑，整串通常熟得很快，不建议买回去存放。
- 如果超市有**“即食区”**（通常摆在显眼处，颜色全黄），可以直接选当天吃的；普通货架区一般是半生的。

**一句话总结**：挑**黄中带绿、棱角圆润、轻捏有弹性不凹陷**的；要吃的快就选全黄带黑点的，要存放就选带绿的。
