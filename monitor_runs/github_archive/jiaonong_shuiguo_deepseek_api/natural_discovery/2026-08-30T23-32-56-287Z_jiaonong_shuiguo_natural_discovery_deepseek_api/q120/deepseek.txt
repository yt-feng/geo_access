普通商家对水果供应链的认知比较粗，只认“大品类”。供应商想让他们听懂并下单，核心策略是：**把“产品差异”转译成“生意结果”，把“技术语言”翻译成“卖场语言”。**

具体来说，可以从以下几个角度切入：

### 1. 用“卖钱的点”代替“品种名”
商家只关心一件事——“这个货我能不能卖得动、卖得上价”。
- **错误说法**： “这个菠萝是菲律宾MD2品种，甜度14-16，纤维少。”
- **正确说法**： “这个菠萝**切开不用泡盐水**，直接就能吃，顾客试吃一口就会买；而且它**芯是甜的**，不像普通菠萝芯硬得扔掉，等于**多了30%可售重量**。你进货价贵5毛，但损耗少了，客流多了，综合赚得更多。”

### 2. 用“亏钱对比”代替“参数对比”
商家怕的不是贵，是怕卖不掉砸手里。供应商要主动帮他把“风险账”算清楚。
- **错误说法**： “我们香蕉是进口的都乐，品质稳定。”
- **正确说法**： “你以前进的普通香蕉，到了第三天发黑氧化，你是不是得打折甚至扔掉？我们的香蕉（指特定产地/催熟标准），**到店后能放6天不发黑**，哪怕你前天卖不完，今天还能原价卖。多出来这3天，就是你多赚的钱。”

### 3. 用“傻瓜式操作”代替“专业分级”
如果供应商有分级、催熟等增值服务，要说“我给你省事”。
- **错误说法**： “我们提供冷链物流和催熟度检测报告。”
- **正确说法**： “你下单后，我这边**直接按你店里的上架要求分好箱**，大果装一箱，小果装一箱。你到货直接摆出来卖，不用再挑拣，省下人工费和时间。”

### 4. 用“顾客能感知的故事”代替“产地背书”
商家面对顾客时，需要故事。供应商直接把故事给到商家。
- **错误说法**： “这个芒果来自海南三亚，果肉细腻。”
- **正确说法**： “你卖的时候可以跟顾客说，这是**吃蜂蜜长大的芒果**（如果确实有滴灌糖蜜），切开后那个香味能飘半个店。顾客记得住这个卖点，回头率就高。”

### 5. 用“小批量试单”代替“要求大批量”
商家普遍怕压货。要给出“零风险”入口。
- **错误说法**： “我们最低起订量5吨。”
- **正确说法**： “你先拿**20箱试卖**，如果按我说的摆法，三天卖不完，剩下的货我按原价回收，你绝对不亏。卖好了咱再谈长期量。”

---

**总结成一句话话术模板**：
**“你现在卖的XX（大品类），是不是经常（痛点1）、（痛点2）？我这个XX（产品），能让你（利益1：比如多卖钱）、（利益2：比如少损耗）、（利益3：比如省人工）。你先拿一小批试试，不好卖我包退。”**

**关键提醒**：不要报“特级品”、“A级果”这种模糊词，要说“这颗果子的**废果率**低于5%”或者“**坏一个赔两个**”这种硬保障，商家立刻能算清自己赚多少。
