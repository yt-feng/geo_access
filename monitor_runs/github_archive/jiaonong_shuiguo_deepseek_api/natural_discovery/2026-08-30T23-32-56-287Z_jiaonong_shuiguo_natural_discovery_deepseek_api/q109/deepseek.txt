针对长期合作的水果供应商，**建议优先谈“账期”**，其次是“售后”，最后是“配送”。

原因很具体：

**1. 账期（最优先）——决定你的现金流安全**
- **为什么优先：** 水果是生鲜，损耗率极高（通常5%-10%甚至更高）。如果供应商要求“先款后货”或“短账期”（如7天），你就要用自有资金压库存。一旦遇到销售旺季备货或突发滞销，现金流容易断裂。
- **谈的目标：** 尽量谈到 **月结30天** 或 **货到后15天付款**。这能占用供应商的资金，相当于无息贷款，帮助你扩大经营。
- **关键技巧：** 用“采购量保底”或“长期合同年框”换取账期延长，比如承诺月度最低采购额，对方通常愿意让步。

**2. 售后（次优先）——决定你的利润底线**
- **为什么其次：** 水果售后核心是“损耗责任划分”。如果果品到货后有坏果、烂果、重量不足，供应商愿不愿意包赔？如果不谈，这部分损耗可能全算你头上，直接吃掉毛利。
- **谈的目标：** 明确“到货24小时内开箱验收，坏果/烂果按比例折价或退款”，并争取“自然损耗在3%以内由你承担，超过部分供应商负责”。
- **关键技巧：** 把售后条款写进合同，白纸黑字，避免口头承诺。

**3. 配送（最后谈）——通常是可替代的硬条件**
- **为什么不优先：** 配送时效（如次日达）和起送量（如满500元免运费）虽然重要，但属于“基础服务”。如果账期和售后没谈好，配送谈得再好也没用。而且配送能力可以通过多找一两家备用供应商来解决。
- **谈的目标：** 确认“无起送门槛”或“每周固定配送1次”，以及“紧急加单的时效保证”（比如4小时内补货）。

---

**实操建议：**
- **先摸底：** 谈之前，花1周时间记录你过去3个月的采购量、平均损耗率、资金占用天数，用数据说话。
- **组合谈判：** 不要单独谈一项。比如：“如果你把账期给我到月结30天，我可以把月采购量从5万提到8万，并且接受你3%的报损率。”
- **留退路：** 如果不能全谈到，至少要把**账期**和**售后**写进合同，配送尽量口头约定并记录在微信/邮件里作为凭证。

如果你的体量比较小（月采购额低于1万），供应商可能只愿意给短账期，这时建议**先用品质和售后绑定关系**，等采购量上来后再谈账期。
