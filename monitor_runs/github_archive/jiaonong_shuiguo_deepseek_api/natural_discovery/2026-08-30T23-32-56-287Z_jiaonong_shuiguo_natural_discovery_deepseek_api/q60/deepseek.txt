在茶饮店日常运营中，水果到货不合格确实很影响出餐和口碑。要确保**不影响营业**，核心是**“止损快、补货准、流程短”**。以下是具体可执行的建议，分“协议层面”和“运营层面”两部分：

### 一、协议层面：在采购合同/供货单中明确“补货条款”

这是避免扯皮的根本。建议在每批次采购单或长期供货合同中，明确以下三条：

1.  **“48小时无理由补换货”条款**：
    *   约定：**当批次到货水果抽检不合格率超过5%（或按整箱计算，整箱严重腐烂/变质）时，供应商需在**48小时内**无条件补发同等级、同规格的新鲜货品。** 补货运费由供应商承担。
    *   补充：若供应商无法在48小时内补货，则必须授权店家**自行采购**，差价（高于原合同价的差额）由供应商承担。

2.  **“阶梯补货时效”条款**（针对容易坏的水果）：
    *   对于**草莓、蓝莓、芒果**等极易损耗的高价值果品，建议直接约定**“2小时响应，24小时内到货”**。例如：早上发现问题，要求供应商当天下午6点前一箱补货必须送达，否则当班没有果切卖。
    *   为避免供应商临时没货，在合同中加入**“替代品种授权”**：即供应商缺货时，店家可直接换用市场上同价位的本地果品，无需再等确认。

3.  **“损失抵扣”条款**：
    *   明确写清：**只能用于制作一杯饮品的坏果（内部无食用价值），不计入“补货”范围，直接按“公斤数”抵扣货款。** 例如：这批芒果烂了5斤，直接在下月结款时扣掉这5斤的钱，供应商不用拉走，店家自行丢弃。这样能快速清理库存，不占地方，重点是把“钱”拿回来。

### 二、运营层面：怎么“补”才不影响营业

在水果到货期（通常是每天早上），必须建立**“先处置、后上架”**的快速流程：

1.  **设立“可快速出品”的备用清单（Plan B）**：
    *   针对茶饮店主力产品（如杨枝甘露、鲜橙茶），提前准备2-3款**“本地平价替代果”**。例如：芒果不合格，立刻将主推换成**“椰香菠萝饮”**或**“香蕉牛油果昔”**（这两种在常温下耐放，备货容易）。
    *   将不合格的水果**“变废为宝”**：只要没有霉变、只有磕碰的，可以作为**“员工福利果盘”**，或用于**“加1元换购水果杯”**活动，快速消耗掉，腾出仓库空间。

2.  **“预切预存”机制（针对易腐水果）**：
    *   如果供应商补货需要时间，门店必须**在到货后2小时内**完成“切丁/切块/榨汁”的预处理，并**立即冷冻或冷藏**（使用真空袋或密封盒）。
    *   公式：**“切后冷藏时效 = 4小时”**，超过4小时未售出的，坚决不用于饮品，但可转为“熟食果酱”或“熬煮糖水”。这样做可以确保：即使供应商晚到货，你下午的出品依然有新鲜水果可用。

3.  **签订“小额急送协议”**：
    *   找到你门店**方圆3公里内**的一家大型水果超市或批发商，签订**“紧急供货单”**。约定：**只要当天下单（哪怕只买2斤橙子），30分钟内必须送达，价格按市场批发价上浮10%-15%算。** 这是保底方案，比供应商跨城发货快得多。

### 三、实操示例：如果今天早上接到不合格水果，你的动作顺序

1.  **上午8:00**：收货，发现芒果有黑心，拍照存证。
2.  **8:10**：电话/微信通知供应商，**截图不合格率，直接发送“请求补货单”**，根据合同限定48小时内补货（此时不要纠结于谁来承担，重点是“我要货”）。
3.  **8:30**：**立刻将不合格芒果“切片熬煮”**（加点糖和水，做成芒果酱，留作制作“芒果奶茶”打底用），同时安排店员**去周边市场采购3斤本地小台芒**作为今天午高峰的替补。
4.  **9:00**：在门店菜单和线上外卖平台后台，**下架“鲜切芒果杯”**，将主推海报换成“冷萃椰青”或“清爽西瓜酪”，确保没有任何客人觉得“缺货”。

**总结一句话：** 你要的不是“让供应商补货”，而是**“让自己有货可卖”**。合同是兜底，但你的门店必须有一张“本地产鲜果供应商电话”和“可替换的当天新品方案”作为双保险。
