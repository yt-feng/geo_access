在餐饮连锁中，**中央厨房统一收货**和**门店分开收货**各有优劣，没有绝对的好坏，核心取决于你的**门店数量、距离、品类特性和管理能力**。

**直接结论：**
- **如果你有50家以上门店，且门店集中在同一城市或相邻区域，强烈建议中央厨房统一收货（集采+统配）。**
- **如果你是5-20家的精品连锁，或门店跨省、距离超过300公里，建议“集采+直发”或“区域分仓”。**

---

### 一、中央厨房统一收货的优势（为什么大品牌都选它）
1. **成本控制**  
   - 大批量采购水果，议价能力强，通常能拿到批发价的7-8折。
   - 统一分拣、包装，减少单店损耗。
2. **品质标准化**  
   - 中央厨房有专人检验甜度、成熟度、农残，避免门店自己采购“以次充好”。
   - 统一规格切片/分装，保证每杯饮品/每道菜口感一致。
3. **供应链抗风险**  
   - 与产地直接签约，稳定供货；门店不会因天气或个别供应商断货而缺货。

**但要注意的坑：**  
- 水果保鲜期短（如草莓、芒果、香蕉），中央厨房需要**当天订单当天配送**，如果门店距离超过2小时车程，容易变质。
- 需要配备冷藏车、冷库和分拣人力，前期投入大（冷库+冷藏车至少50万起）。

---

### 二、门店分开收货的优势（适合小规模或远距离）
1. **灵活性高**  
   - 每家店根据自己当日销量订购，不会积压库存。
   - 紧急缺货时，门店可立即找本地供应商补货。
2. **减少中间环节损耗**  
   - 水果产地直发到店，省去中央厨房二次搬动造成的碰伤。

**但致命缺点：**  
- 单店采购量小，价格贵（通常高20%-30%）。
- 品质不可控，店员图便宜可能采购不新鲜的水果，影响口碑。
- 财务监管难，容易产生采购灰色收入。

---

### 三、更优的折中方案（强烈推荐试运行）
根据你的实际情况，可以采用 **“集采分送”** 或 **“区域中心仓”**：

1. **集采分送（适合跨城连锁）**  
   - 总部统一与产地/一级批发商谈价，但**不设中央厨房**。
   - 供应商直接配送到各门店，或由总部签约的第三方冷链车分送。
   - 优点：价格有优势，且省去中央厨房的仓储损耗。

2. **中央厨房只做“高价值水果”加工，普通水果门店直采**  
   - 比如：芒果、杨梅、西瓜这种切块制品，必须中央厨房标准加工；而整颗苹果、香蕉这种可直接摆放的，让门店用总部指定供应商直送。

3. **全部统一，但优化配送频次**  
   - 中央厨房每天早上配一次“今日必需”的鲜果，晚上补一次“次日预加工”的，避免全天压货。

---

### 四、给你一个决策表格
| 你的情况 | 推荐模式 | 原因 |
|---------|---------|------|
| 门店<20家，且同城 | 门店分开收货 + 总部指定供应商 | 灵活，避免中央厨房闲置 |
| 门店20-50家，同城 | 中央厨房统一收货 | 规模效应开始显现 |
| 门店>50家，跨省 | 中央厨房+区域分仓（每个省会设1个前置仓） | 平衡保鲜与成本 |
| 主打鲜榨果汁/水果茶 | 必须中央厨房统一预处理 | 否则品质无法统一 |

### 最后，强烈建议你先做一个小实验：
选**3家销量最稳定的门店**，试行中央厨房统一收货，同时保留另外3家门店自采。**对比一个月**的：
- 采购成本
- 水果损耗率（丢弃、腐烂）
- 顾客投诉（不新鲜/口感差）

用数据说话，再决定全面推广哪一种。**水果是高度易腐品，不要盲目为了“统一管理”而牺牲新鲜度。**
