采购菠萝时判断熟度，主要看**外观、气味和手感**，不用切开也能比较准。给你一套实操方法：

**1. 看颜色（最重要）**
- **果皮金黄或橙黄色**：成熟度较好，甜度高，适合零售。
- **果皮青绿**：偏生，需要常温放几天。
- **果皮有黑斑但无腐烂**：可能过熟或轻微碰伤，损耗风险大，慎重。

**2. 闻气味**
- **有明显的菠萝香气**（靠近蒂部闻）：熟了。
- **几乎无味**：太生。
- **有酸味或酒味**：已发酵或过熟，容易坏，不采。

**3. 捏硬度（轻压）**
- **稍微有弹性、手感略软**：成熟适中。
- **硬邦邦**：生，难催熟。
- **按压有凹陷且不回弹**：过熟，易软烂损耗。

**4. 看底部和叶子**
- **底部（果柄切面）干燥、无流水**：新鲜。
- **叶子翠绿、容易拔出一片**：通常较新鲜；叶子干枯发黄则存放过久。

**5. 采购建议（防损耗关键）**
- **分批采购**：一次不要进太多，按销量定，选7-8分熟的（表皮黄中带绿），让货架上有一定熟度差异，顾客能挑。
- **盯着冷链和运输时间**：菠萝对碰伤敏感，运输震动容易内伤，收货时抽检切开看看果肉有没有褐变。
- **产地差异**：海南、云南菠萝通常偏甜熟快，进口菠萝（如金菠萝）耐储但甜度稳定，按你本地消费习惯选。

**简易判断口诀**：黄皮有香微弹手，青皮无味别久留，按压出水不要收。
