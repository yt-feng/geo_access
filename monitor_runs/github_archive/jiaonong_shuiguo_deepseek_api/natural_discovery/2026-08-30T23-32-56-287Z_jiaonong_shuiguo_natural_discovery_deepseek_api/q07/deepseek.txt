针对水果店的水果礼盒，搭配的核心逻辑是：**颜色好看、口感互补、寓意吉利、近期不易损坏**。根据你的四种水果，我给出三种不同定位的实用搭配方案，你直接照做即可。

---

### 方案一：经典家庭实惠装（走量款，主打性价比）

**搭配内容**：苹果 4个 + 橙子 4个 + 香蕉 1把（约4-5根） + 菠萝 1个（去皮切块或整只）

**逻辑分析**：
- **苹果**：象征平安，价格便宜，能垫底增重，显得盒子满。
- **橙子**：寓意心想事成，颜色鲜艳，是硬果，耐放。
- **香蕉**：禁忌最少，老人小孩都爱，但**注意要选稍微带点绿的**，熟度正好，不会在路上压坏。
- **菠萝**：比较少见，“旺来”寓意好，但个头大。建议**去头去尾、削皮切块装盒**，单价高一点，但显得礼盒高级。

**定价建议**：成本控制在45-60元之间，零售卖88-108元。适合送亲戚、朋友，走量最快。

---

### 方案二：高端精品礼盒（送礼撑面子，利润高）

**搭配内容**：苹果 2个 + 橙子 2个 + 香蕉 半把（3-4根） + 菠萝 1个（切块精致装盒）

**视觉升级**：
- **摆法**：苹果和橙子放在底层四角（红色+橙色），香蕉铺在中间当隔层，菠萝切好的果肉块放在最上层中央，形成**红、黄、金、绿**的渐变感。
- **包装**：一定要用带海绵垫的透明PET盖盒，或者红丝绒底衬。中间撒一点**薄荷叶或圣女果**做点缀，成本几毛钱，但显得非常贵。

**定价建议**：成本60-80元，零售卖128-168元。适合送领导、客户、丈母娘。

---

### 方案三：时令混搭款（清库存、快周转）

如果你的**菠萝进多了**或者**苹果快不新鲜了**，按这个方案做：

**搭配内容**：苹果 2个 + 橙子 2个 + 香蕉 2根 + **菠萝蜜（代替菠萝）** 或者 菠萝切大块。

**关键点**：
- 如果菠萝带皮卖，一定要在盒子上贴**“需冷藏，2天内食用”** 的标签。
- 把香蕉和苹果放在一起，**用保鲜膜单独包住香蕉头**，因为苹果释放的乙烯会催熟香蕉，不包会很快变黑。

---

### 特别提醒（决定好不好卖的三条铁律）：

1.  **颜色不撞色**：四样水果颜色很冲突（苹果红、橙子橙、香蕉黄、菠萝黄绿）。**一定不要平铺乱放**，建议采用**“下层深色（苹果橙子），上层浅色（菠萝香蕉）”** 的塔式结构。
2.  **“香蕉”是双刃剑**：香蕉皮薄容易撞烂，**礼盒必须平放**，不能竖着捆扎。
3.  **应季调整**：如果当地菠萝很酸，建议**腌渍成酸甜口**再装盒，或者换成哈密瓜（同样黄绿色，但更甜）。

**最直接的实战建议**：
去隔壁大超市看看他们今天主推的“果篮”长什么样。如果发现大家都在卖苹果+橙子的基础款，你就直接推出 **“菠萝切盒”** 作为主角，差异化竞争，利润会高很多。
