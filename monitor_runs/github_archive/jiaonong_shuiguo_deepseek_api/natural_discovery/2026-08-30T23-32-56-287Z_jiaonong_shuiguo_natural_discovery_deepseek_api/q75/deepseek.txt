第一次与水果供应商合作时，**小批量试单的目的不是“买到最便宜货”，而是“验证供应商的稳定性、履约能力和售后态度”**。

试单设计主要分为以下四个核心模块，供你参考：

---

### 第一模块：选品与数量设计（核心是“一主一辅”）

| 维度 | 具体建议 |
|------|----------|
| **选品** | 选 **1-2个** 你店铺/渠道最走量的核心单品（如苹果、橙子），再加1个当季高风险易损品（如草莓、葡萄）用来测试供货商的保鲜能力。 |
| **数量** | **不要低于起订量，但也不要超过日常3天销量**。例如：日常卖500斤/天，试单就订1000-1500斤。 |
| **规格** | 要求必须和正式合作时完全一致（如：一级果、单果重200g-250g），**不要因为量小就同意随意混装**。 |

---

### 第二模块：合同/单据设计（关键条款）

- **明确验收标准**：白纸黑字写明——产地、规格（分级标准）、糖度（如有条件）、破损率（一般≤3%-5%）、成熟度（几成熟发货）。
- **损耗责任**：写明“运输途中自然损耗≤5%由买方承担，超过部分或货到验收不合格由供应商承担”。
- **结算方式**：**坚决拒绝“全款预付”**。建议：定金30%（或干脆全款到货后结），货到验收合格后48小时内结清尾款。
- **违约条款**：哪怕量小，也要写明“未按时到货、质量不达标，按合同金额10%赔付”或“无条件退货退款”。

---

### 第三模块：收货与验收流程（重点抓“48小时”）

1. **拍视频开箱**：到货后，不要拆包前先录整体外观视频（车况、箱体），再逐一拆箱。
2. **去皮称重**：注意扣除纸箱、保鲜袋、冰瓶等包装重量，确认“净果重”是否达标。
3. **抽样检测**：从不同位置的箱子各抽2-3斤，检查破损率、大小均匀度、内部有无烂心。
4. **48小时复检**：存放48小时后再次观察，主要看“后熟软化速度”和“腐烂蔓延率”，这是判断对方是否使用了催熟剂或冷库处理的关键。

---

### 第四模块：试单后的复盘与决策

试单结束后，不要只看“这次赚没赚”，建议做一个**供应商评分表**：

| 评分项 | 权重 | 评分（1-5分） |
|--------|------|---------------|
| 货品质量（外观/口感/规格符合度） | 40% | |
| 到货时效与物流包装 | 20% | |
| 售后响应速度与处理态度 | 20% | |
| 价格合理性 | 10% | |
| 后续沟通的顺畅度 | 10% | |

**最终的决策标准**：
- 总分≥4分 → 可以进入正式合作，但第一次大批量仍建议分批下。
- 总分3-4分 → 复盘问题出在哪个环节，再给一次“小量补单”机会，期限1周内。
- 总分<3分 → 果断放弃，及时止损。水果行业最忌“将就”和“怕麻烦”。

---

### 额外的三个“避坑”提醒

- **警惕“低价清仓”话术**：如果对方第一次就给你报出远低于市场均价的价格，通常意味着货品有隐性瑕疵（如积压库存、成熟度失控）。
- **保留沟通证据**：所有口头承诺（如“包甜”“包无损”）要求对方微信文字确认，便于售后维权。
- **试单频率**：建议同一地区只试2-3家供应商，不要一次性试太多，否则容易分散管理精力且难以对比真实水平。
