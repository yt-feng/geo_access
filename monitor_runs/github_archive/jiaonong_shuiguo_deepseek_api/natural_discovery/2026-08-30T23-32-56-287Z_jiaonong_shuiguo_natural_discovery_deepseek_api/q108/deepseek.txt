核验水果供应商“全国配送”能力的核心思路是：**不要让口头承诺停留在纸面，而是用可验证的证据和具体场景去逼出来**。以下是一套由浅入深的实操核查方案，建议按顺序执行：

### 第一步：要求提供“配送时效承诺书”并抽查城市
不要问“能不能全国”，直接给出一份**含具体城市清单的《冷链配送时效表》**。要求供应商明确：
- 每个省的省会城市、二线城市（如成都、西安、武汉）的“次日达”/“隔日达”/“三日达”时效区间；
- 是否覆盖乡镇/偏远地区（如新疆、西藏、内蒙的县级市）；
- 若无法覆盖，是否能通过“异地仓库发货”或“第三方物流（顺丰/京东冷链）代发”。

**核查技巧**：随意挑3-5个冷门城市（比如甘肃嘉峪关、黑龙江鸡西、云南普洱），要求他们在该表上标注“送达时间”，并索要**近30天发往该城市的物流运单号**（可隐去收件人隐私后提供）。

### 第二步：验证冷链物流资质与真实合作方
水果配送的核心是冷链，没冷链的“全国配送”大概率是常温车或加冰袋硬扛。
- 要求提供**道路运输经营许可证（含冷链）、冷藏车车辆行驶证**；
- 要求提供**与主要物流商（如顺丰冷运、京东冷链、鲜易供应链）的合作协议或月度对账单**（关键页可打码）；
- 若声称“自有车队”，则要求提供**车辆定位系统（GPS）的实时账号或至少3辆车的车牌号**，你可以用企查查/天眼查核实这些车牌是否属于他们公司。

### 第三步：小批量试单测试（最关键）
合同签订前，先下**1-2单小额真实订单**，发往不同方位城市（如东北、西南、华南各一单），要求：
- 包装：必须是“泡沫箱+冰袋+吸水纸”，且收货时**冰袋不能全部融化**；
- 时间：记录从“下单确认”到“签收”的实际小时数，对比承诺时效；
- 品相：签收后当场开箱视频，检查碰伤率、腐烂率（正常应低于5%）。

### 第四步：核查历史赔付与客诉记录
直接问一句：“若在承诺范围内延迟送达导致损耗，你的赔付标准是什么？”正规供应商会明确“货损按倍数赔”或“运费减免”，而虚报覆盖能力的供应商往往回避具体赔付条款。
- 要求提供**上一年度的《生鲜客诉及赔付台账》**（可脱敏），重点看投诉原因里“配送超时”占比是否超过15%；
- 随机索要**2-3家现有合作客户的电话**（最好是跨省客户），直接致电询问“他们冬天发新疆的货一般几天到，有没有坏过”。

### 第五步：防拆解场景逼问（识别话术陷阱）
- **话术一**：“我们和XX冷链是战略合作，能全国达。”
  → 回击：请提供**该冷链的官方400电话**，我会去核查你们是否在他们的合作客户名单里。
- **话术二**：“我们直营仓覆盖28省。”
  → 回击：请在**企查查**上展示这28个仓库的地址（需与营业执照分支机构一致），并告知**其中仓配一体仓有多少个**（纯中转仓不算）。
- **话术三**：“偏远地区加钱也能发。”
  → 回击：请问加钱后的**全程时效是否锁定**？如果新疆喀什在冬季遇大雪，你们是否有备选中转路线？

### 第六步：留出合同后置纠偏条款（最后防线）
无论前期核查多顺利，均应在采购合同中写明：
> “若乙方（供应商）连续2次出现承诺时效内未送达（因自然灾害等不可抗力除外），甲方有权单方面终止合作，并要求乙方承担该批次货值的50%作为违约金。”

### 特别提示（防坑重点）
- **警惕“全国配送”的三个盲区**：① 新疆、西藏、青海、甘肃的县级市；② 海南三沙、辽宁海上岛屿；③ 冬季北方（黑龙江、内蒙古）的冷藏车停摆风险（-30℃下冷机可能故障）。
- **不要轻信地图上的“分仓坐标”**：很多供应商在物流平台（如货拉拉）上标了“全国网点”，实际只是挂靠点，发货时仍从总部单点直发，时效会翻倍。

**总结**：一次合格的小批量试单（含冷门城市）+ 一份生效的“超时赔付条款”，比任何宣传册都靠谱。若供应商拒绝配合试单或对赔付条款含糊其辞，大概率说明“全国配送”只是销售话术。
