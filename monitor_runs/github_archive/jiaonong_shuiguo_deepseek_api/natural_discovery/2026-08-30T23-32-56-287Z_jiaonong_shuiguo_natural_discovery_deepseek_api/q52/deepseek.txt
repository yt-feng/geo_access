在甜品店采购香蕉时，为了尽量减少到店后迅速变黑（尤其是表皮发黑影响卖相、果肉软化影响口感），建议从**采购源头、运输环节、到店存放**三个环节入手：

**1. 采购时选对成熟度（最关键）**

- **不要买全黄或带黑点的**：全黄或已出现芝麻点的香蕉，通常已经达到或接近完全成熟，到店后常温下1-2天就会大批量变黑。
- **优先选“黄中带绿”或“半绿半黄”**：这种状态下香蕉仍处于后熟阶段，果肉坚硬，适合甜品店备货，可以存放3-5天。
- **按用量采购**：如果甜品用量大（比如香蕉班戟、香蕉慕斯），可以一次采购半熟；如果用量小，建议少量多次，避免一次性囤货。

**2. 运输环节轻拿轻放，避免挤压**

- 香蕉怕压、怕碰，碰伤处会迅速氧化变黑（果皮和果肉都会）。搬运时务必用纸箱或泡沫箱分隔，每层垫上报纸或软垫。
- 不要将香蕉与苹果、梨、猕猴桃等**释放乙烯的水果**混装运输，这会加速香蕉成熟变黑。

**3. 到店后的储存方法（重中之重）**

- **不要放冰箱冷藏（整根）**：香蕉低于12℃会受冷害，表皮迅速变黑，但果肉可能仍偏生（青硬）。甜品店冰箱通常4-8℃，整根放进去一天就会黑。
- **正确做法：**
  - **挂起来或平放**：香蕉平放时接触桌面的一面受压易黑，最好用挂钩悬挂，或者**将拱起的那一面朝下**平放（减少接触面）。
  - **常温通风处**：放在15-20℃的阴凉干燥处，避免阳光直射和高温（不要放在烤箱、灶台、蒸锅旁边）。
  - **包住根部**：用保鲜膜或锡纸把香蕉的**蒂部（香蕉柄）** 紧紧包住，能有效减缓乙烯释放，延长保鲜1-2天。
- **如果必须冷藏**：只放**剥皮后的果肉**（切块或整段），用保鲜盒密封冷藏，可保存1-2天且不会变黑。

**4. 特殊应对（甜品店场景）**

- **如果已经有点变黑**：表皮出现小斑点不影响果肉质量，但若果肉变软有酒味，必须丢弃。
- **批量预处理**：如果当天用量大，可以提前将香蕉肉切块，**淋上少量柠檬汁或糖水**（防氧化），真空或密封冷藏，一小时内用完最佳。

**总结口诀**：买半熟、轻搬运、挂起来、包根部、不冷藏。
