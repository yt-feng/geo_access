第一次和水果供货商合作，**核心原则是“小批量、多频次、先测品质、再谈账期”**。不要一上来就订几十箱，试单主要看三个东西：**货品新鲜度、损耗率、以及对方的售后态度**。

具体步骤和建议如下：

**1. 试单量怎么定？**
不要按“件”算，要按“天”算。
- 每种水果先订 **1-2 箱**（如果是香蕉，建议只订1把或半箱，因为香蕉熟得快，损耗大）。
- 数量够卖1-2天即可。这样即使品质不好，损失也控制在几十块钱内。

**2. 香蕉怎么试？**
香蕉是损耗最大的，也是最容易踩坑的。
- **看成熟度**：试单时明确要求要“7-8分熟”的，表皮青黄相间，捏起来稍硬。如果供货商给你发全黄的，你当天卖不完第二天就会全黑。
- **看重量**：把香蕉拿在手里掂量，一箱香蕉，如果比正常重量明显偏轻，可能是放久了水分流失。
- **动作**：进价谈好，但要求对方**带箱称重**（连包装箱一起算重量），或者要求扣除筐重、纸箱重。

**3. 苹果怎么试？**
苹果是标准品，主要看“眼色”和“手感”。
- **看果柄**：果柄翠绿、湿润，说明是新鲜的；果柄干枯发黑，说明是冷库陈货。
- **看规格**：明确要求“80#”或“75#”的果径（苹果指头粗细），如果到货后大小参差不齐，说明走统货，下次要指定“标准果”。
- **动作**：当场开箱检查底层，有些供货商会把大果放上面，小果压箱底。试单时务必拆开看中下层。

**4. 橙子怎么试？**
橙子主要看“皮”和“水”。
- **看表皮**：要求表皮光滑、油胞细密（毛孔小），颜色要自然橙黄。如果颜色特别鲜艳发亮，可能是打了蜡或抛光。
- **掂重量**：同样大小的橙子，拿手里越沉的越新鲜（水分足）。
- **动作**：现场切开一个尝味道。如果酸度太高或干水（无汁水），坚决退货或压价。

**5. 试单的关键话术和动作（最重要）**
- **先付现，不要赊账**：第一次合作，主动提出“这次试单我直接现金结，但你给我保证品质”。现金结账时，你有绝对的话语权，对方也愿意做你的回头客生意。
- **拍照留证**：开箱时，如果发现烂果、发霉、压伤，**当场拍照**，直接发微信给供货商，要求要么退钱，要么补货。**不要口头说，一定留图文证据。**
- **明确退换标准**：试单时问一句：“如果这批有些瑕疵，烂果损耗超过多少比例你们认账？”如果对方说“这个说不准”，那这家的品控大概率不行，换下一家。

**6. 试单后的决策**
- **如果试单品质好，但价格贵一点**：留着作为备选，不要立刻深度绑定。
- **如果品质一般，但价格便宜**：坚决不选。水果店最怕的就是砸口碑，一个坏香蕉毁掉整盘生意不值得。
- **如果品质好、价格合理**：第二次订货时再谈“周结账期”或“月结”，同时要求他们以后优先给你挑好货。

**一句话总结**：第一次试单，你就当自己是来“验货”的，给供应商标明底线：“我是长期开店的，第一次如果你坑我，你就少了一个长期客户。” 态度硬气，先小人后君子。
