和酒店早餐水果供应商谈合作，需要兼顾**稳定性**、**品质**、**成本**和**应急能力**。以下是几个关键注意事项：

**1. 明确品质标准与验收细节**
- 不要只谈“新鲜”，要写清楚具体标准：比如苹果的果径、香蕉的成熟度（几成黄）、叶菜的水分和瑕疵率。
- **约定验收盲区**：早晨6-7点是到货高发期，要明确收货时间、退货流程（如按箱开箱比例抽检，发现坏果如何折算扣款）。

**2. 锁定供应频率与波动保障**
- 早餐是刚需，建议**签订框架协议**（比如月供量），明确：日常按订单配送，但**必须备有一定比例的“安全库存”**给酒店。
- 问清供应商：如果遇到极端天气（台风、暴雨）或节假日水果价格上涨，是否有**临时调货渠道**？价格联动机制怎么算？

**3. 价格机制要“活”**
- 不建议固定死价。谈成**“随行就市+每周定价”**模式：每周五供应商报下周批发价，酒店用同日报价对比其他市场，若高于市场价5%以上，有权要求调整。
- **警惕最低价陷阱**：过于便宜的水果可能混淆产地或催熟过度，直接影响早餐品质。

**4. 账期与结算方式**
- 酒店通常有账期（如月结30天）。务必在合同中书面明确：**账期天数**、**对账周期**（每月几号），以及**逾期付款的滞纳金比例**。
- 可要求供应商提供**正规发票**（注意发票品目是否包含“水果”），避免后期财务合规风险。

**5. 应急与售后响应**
- 一定额内置“突发应急条款”：如果早晨到货严重不足（比如缺40%），供应商必须在**2小时内**调货运抵，否则按当日订单价的X倍赔偿。
- 要对方提供**冷链运输GPS轨迹**（可选），确保运输途中温度可控。

**6. 合同附件要细化**
- 建议附一份《品类清单表》，写明：每种水果的规格、产地（如：江西赣南脐橙，直径85mm以上）、包装（如：10kg/箱）。

**最后提醒**：先进行**为期2周的试供期**，试供期间每日记录损耗率、到货准时率，再签正式年度合同，能大幅降低后期扯皮风险。
