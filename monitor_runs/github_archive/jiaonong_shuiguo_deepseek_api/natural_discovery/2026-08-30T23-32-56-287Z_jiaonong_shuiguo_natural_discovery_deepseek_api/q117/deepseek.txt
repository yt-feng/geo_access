对于水果采购方来说，新品试卖的核心原则是：**小批量、多频次、控损耗**，切忌一上来就大批量压货。

以下是具体的实操建议：

**1. 起订量建议（按经营规模划分）**

- **中小型门店/摊贩**：建议首次试卖量控制在 **10-20公斤**（或按收货件数，如1-2箱）。
- **中大型超市/连锁**：建议首次试卖量控制在 **2-3个标准箱**（约30-50公斤），且只覆盖1-2家核心门店，不做全城铺货。

**2. 关键判断标准（决定是否追加）**

不要看总利润，要看**动销速度**和**损耗率**。

- **72小时法则**：试卖前3天如果销量呈上升趋势，且日销量达到预计日均量，说明有潜力，可考虑补货。
- **损耗红线**：如果三天内损耗超过10%（如腐烂、皱皮、顾客因外观不买），应立即止损，即使销量尚可，也要考虑更换单品或调整陈列方式。

**3. 附带条件**

在试卖前，请务必和供应商谈好**售后政策**，这是最稳的保险：

- **坏果包赔**：需明确“按比例补偿”或“无条件退换”，避免新品因品质波动造成全损。
- **补货阶梯价**：约定若试卖成功，后续追加订单量在X件以上，享受更低的进货价，以此对冲试卖期的高毛利压力。

**总结建议**：前期宁可少赚，也要保证**资金灵活**。如果供应商强烈要求你一次性拿大量货（如100公斤以上），且拒绝任何售后承诺，这本身就是一个风险信号，建议谨慎合作或换一家供应商。
