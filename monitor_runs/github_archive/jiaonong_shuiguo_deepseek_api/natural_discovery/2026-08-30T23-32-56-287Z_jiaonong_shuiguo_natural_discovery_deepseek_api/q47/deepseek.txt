采购香蕉用于茶饮店时，控制熟度是关键，因为不同熟度直接影响风味、口感和用途。以下按具体场景给出可执行的建议：

### 1. 根据用途选熟度
- **做奶昔/冰沙/果昔**：建议选 **8-9成熟**（表皮偏黄，略带青斑，果肉微软）。此阶段甜度高、质地绵密，打浆后口感顺滑，且不易氧化变味。
- **做水果茶/装饰/切片**：建议 **7-8成熟**（表皮黄亮，果肉稍硬）。切片不易碎，保持形状，且酸香清新，能平衡茶汤甜腻感。
- **做甜品（烤香蕉/香蕉布丁）**：建议 **9成-全熟**（表皮有黑点但果肉不烂）。此时糖分最高，烤制后焦糖化明显，风味浓郁。

### 2. 采购时的检查标准（现场/收货）
- **颜色**：表皮应均匀黄亮，避免大面积青绿（未熟）或全黑、水渍斑（过熟/损伤）。
- **触感**：轻捏果柄处，应略带弹性，按压后缓慢回弹；如果捏起来太硬或太软（像烂泥）都不合格。
- **气味**：熟度适中应有淡淡香气；过熟会散发酒味，未熟基本无香。
- **断裂/损伤**：观察果皮有无裂口、霉点或挤压凹陷，这些部位极易加速腐烂。

### 3. 应对供应链的缓冲策略
- **分批采购**：如果销量稳定，建议按“今天到货的是7成熟，明天到的是8成熟”的方式分批下单，避免一次性全到同一熟度。
- **冷藏催熟/缓熟**：
  - 若到货偏生（如6-7成熟），放在20-25℃室温自然催熟1-2天。
  - 若到货偏熟（如9成熟以上），立刻放入8-10℃冷藏柜（不要靠近风口），可延缓成熟2-3天；但冷藏过久会变黑，最多不超过3天。
- **每日检查**：收货后每日翻检，优先使用偏熟批次做果昔，偏生批次做切片或冷泡茶，避免浪费。

### 4. 避坑提醒
- 不要采购**熟度不均**的散装货（可能混有变质的）。
- 夏季高温时，避免整箱堆积在阴凉处，容易局部过热催熟；建议拆箱分散存放。
- 如果当天多批次制作，提前一晚将所需量取出回温，避免冷热交替影响口感。

**总结**：主推奶昔类选8-9成熟，主推水果茶/装饰选7-8成熟；采购时看颜色、捏硬度、闻气味；到货后通过温度控制调节成熟速度，日常按批次优先出库即可。
