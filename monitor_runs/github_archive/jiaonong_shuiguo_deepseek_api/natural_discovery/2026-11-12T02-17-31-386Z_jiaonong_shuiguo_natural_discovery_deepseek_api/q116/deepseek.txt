小商家采购水果，现金结算和月结账期各有不同风险，关键不在“哪个更安全”，而在你的现金流、验货能力和供应商稳定性。

**现金结算的主要风险**
1. **质量与数量风险前置**：钱先付或当场付，事后发现烂果、短斤少两、规格不符，追偿和换货被动。
2. **资金占用与假币/找零风险**：大量现金占压流动资金，零钱、假币、收据不规范都会增加管理成本。
3. **无账期杠杆**：对供应商约束力弱，价格谈判空间小；供应商临时缺货时你也没有账期作为缓冲。
4. **安全与合规风险**：现金保管、被盗、员工挪用，以及无票采购导致成本无法规范入账。
5. **价格波动风险**：水果价格日变，现金现结通常按当日价，遇到涨价只能接受。

**月结账期的主要风险**
1. **信用与坏账反向风险**：账期是供应商给你信用，但若你经营不善或对方突然收紧账期，会集中还款压力。
2. **质量纠纷拖成账款纠纷**：坏果、损耗责任没在收货时书面确认，月底对账容易扯皮，甚至被停供。
3. **隐性成本**：月结价通常高于现结价，或要求最低采购量、押金、担保，实际资金成本可能不低。
4. **供应商集中风险**：依赖一家月结供应商，一旦对方断供或转产，短期替换困难。
5. **对账与内控风险**：赊销记录、收货单、退货单不齐，容易出现多付、漏付、员工与供应商串通。
6. **账期被随时缩短**：水果损耗高、供应商资金也紧，月结可能变成“半月结”甚至现结，打乱现金流。

**可执行建议**
- 新供应商先**小批量现金试单**，验质量、验称重、验票据，再谈账期。
- 无论现结还是月结，收货时**当场抽检并书面记录**：品种、规格、重量、坏果率、退货数量，双方签字或微信留痕。
- 月结合同写清：对账日、付款日、质量异议期、退货扣款方式、逾期停供条件，避免口头账期。
- 现金结算保留**正规收据或发票**，大额尽量转账留痕；月结控制单一供应商采购占比，保留备选货源。
- 算清真实成本：月结价与现结价的差价，折算成年化资金成本，再判断账期是否划算。

简单判断：**日销稳定、验货能力强、供应商可靠，可适度用月结换现金流；新供应商、高损耗品类、对账能力弱，优先现金或短账期。**
