判断供应商售后是否稳定，不要只听口头承诺，建议用「可验证动作」来筛：

1. **先问清售后范围和响应时效**
   - 明确：到货腐烂/压伤/成熟度不符/重量短缺/农残检测不合格，分别怎么赔、怎么换、多久处理。
   - 要求写进合同或订单确认单，不接受“到时候再说”。
   - 关键指标：**响应时间（如2小时内回复）、处理时限（如24小时内给方案）、补货/退款到账时限**。

2. **用一次小批量试单做压力测试**
   - 首单不要大，故意在到货后24小时内反馈一个真实小问题（如少量压伤、成熟度不均），看对方：
     - 多久回复；
     - 是否推诿给物流/天气；
     - 是否愿意先补货或折价；
     - 处理是否闭环。
   - 这比看资质更有效。

3. **要求提供近期同类客户售后记录**
   - 可让对方给**脱敏的售后处理单/客诉台账**，看近3个月同类问题数量、平均处理时长、赔付方式。
   - 注意：只给“合作客户名单”不给处理记录的，参考价值低。

4. **确认对接人和升级通道**
   - 是否固定业务对接人+售后负责人双通道；
   - 非工作时间、节假日能否联系；
   - 出现批量质量问题，谁有权限当场决定补货/退款。
   - 只有单个销售、没有备份联系人的，风险较高。

5. **合同里写清售后条款和违约后果**
   - 菠萝、香蕉都是易腐品，要特别约定：**到货验收标准、损耗率上限、异常反馈时限、补货优先级、退款周期、连续质量不达标可终止合作**。
   - 售后响应不达标是否有违约金或扣款，写进去才有约束力。

6. **看其冷链和产地/档口稳定性**
   - 售后稳不稳，往往取决于上游稳不稳。问清：货源是自有基地、长期合作档口还是临时调货；冷链是否全程；旺季断货时怎么保供。
   - 临时拼货型供应商，售后通常更不稳定。

7. **做一次“批量异常”情景提问**
   - 直接问：“如果一批香蕉到店后催熟不均、三天内大面积发黑，你们怎么处理？多久补货？费用谁承担？”
   - 看对方能否给出具体流程、时限和责任人，而不是只答“放心，我们负责”。

**实操建议：** 先小单试合作，保留每次沟通记录和验收照片；连续2—3次售后都能在约定时限内闭环，再放量。对生鲜商超来说，**售后响应速度和处理闭环能力，比单纯低价更重要**。
