压低成本又不伤品质，核心不是“把价砍到最低”，而是用**可验证的品质标准 + 采购量/账期/稳定性的交换**去换价格。谈价前先做三件事：明确规格、掌握行情、准备替代方案。

**1. 先定“品质底线”，再谈价格**
把品质写成可验收的条款，避免供应商靠降规格降价：
- 品种/产地/等级：如“一级果、单果重200–250g、着色≥80%”
- 糖度、硬度、农残检测标准
- 允许瑕疵率（如外观瑕疵≤3%）
- 到货温度、包装规格、损耗赔付
- 拒收和扣款规则：不合格批次拒收或按比例扣款

谈价时只谈“在底线之上的价格”，不接“降等级换低价”。

**2. 用采购结构换价，而不是压单价**
供应商愿意让价的通常是确定性，不是被砍价。可交换的筹码：
- **集中采购量**：把分散SKU合并给一家，换阶梯价
- **稳定计划**：提前给周/月采购计划，换3%–8%的价格空间
- **账期缩短**：现结或周结，通常能换2%–5%
- **长期合同**：季度/年度框架，锁量不锁死价
- **自提/减少配送频次**：降低对方物流成本
- **淡季锁价、旺季保量**：帮供应商平滑库存

**3. 用行情和替代方案压价**
- 每周记录批发市场、产地、竞品商超同规格价格，形成行情表
- 询价至少3家，保留1–2家备选供应商
- 对同品质报价，直接说“同规格A家报X，你能做到多少”，但不要虚构价格
- 对季节性强的水果，抓上市高峰和尾期议价，错峰采购

**4. 谈价话术参考**
“我们要的是一级果，规格和验收标准按这个表来。如果你们能保证每周稳定供X吨、破损率控制在3%以内，我们可以把账期从30天缩到7天，采购量集中给你。价格上你给一个阶梯报价，达到量我们按阶梯走。”

**5. 守住品质的机制**
- 首批小批量试单，合格再放量
- 每批抽检糖度、重量、瑕疵率，记录供应商评分
- 价格与品质评分挂钩：连续合格给更多量，降质立即减量或淘汰
- 合同里写清“降价不得降规格”，否则拒收并索赔

**判断标准**：如果对方降价但要求放宽等级、混装、降低糖度或减少赔付，这不是真降价，是降品质。真正可接受的降价，应来自采购量、账期、物流和计划性带来的成本下降。

一句话：**先锁品质标准，再用确定性和规模换价格；不拿规格换低价。**
