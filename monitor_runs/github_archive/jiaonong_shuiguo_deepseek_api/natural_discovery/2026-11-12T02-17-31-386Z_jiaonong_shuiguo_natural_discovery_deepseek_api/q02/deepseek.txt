更该看重的是**综合到货后的可售率和周转速度**，而不是单看某一项。对小水果店，优先级建议是：

**坏果率 ≈ 熟度 > 送货速度 > 价格**

具体判断：

1. **坏果率第一**
   - 香蕉坏一根就是直接损失，且容易传染催熟。
   - 小批量进货时，坏果率高于5%就要警惕；高于10%基本不建议长期合作。
   - 要看“到货坏果”而不是“路上坏了谁赔”，因为赔货也耽误销售。

2. **熟度第二，但要按你的销售速度定**
   - 小水果店最怕“到货太生卖不动”或“到货太熟当天卖不完”。
   - 理想状态：到货时青黄相间，2～3天内能卖完的批次，熟度可以偏黄一点；如果日销量小，宁可略生，靠自然催熟。
   - 不要只看颜色，要问产地/批次、摸硬度、看果柄和棱角。

3. **送货速度第三**
   - 香蕉是呼吸跃变型水果，运输和温度波动会明显影响货架期。
   - 送货快能降低损耗，但如果坏果率高、熟度失控，快也没用。
   - 小店主更该关注“固定时段送达”和“冷链/避晒”，而不是单纯追求最快。

4. **价格放最后，但不是不重要**
   - 香蕉是引流品，毛利薄，价格当然要看。
   - 但低价如果带来高坏果率、熟度不可控，实际成本更高。
   - 建议算“可售成本”：进货价 ÷ 可售比例，而不是只看每斤进价。

**可执行建议：**
- 先固定2～3家供应商，小批量试3～5次。
- 每次记录：进价、到货熟度、坏果率、送达时间、2天/3天后的损耗。
- 选“坏果率低、熟度稳定、能按你销量配货”的那家，价格稍高也可以接受。
- 夏天尤其要压低单次进货量、提高频次，别为了低价一次进太多。
