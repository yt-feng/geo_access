要支持，但要“有条件地支持”，不是无差别满足所有小批量高频补货。

**核心判断**
即时零售卖水果，订单碎片化、履约时效短、损耗敏感，供应商如果不支持小批量高频补货，平台端很容易缺货、断品、履约差，最终销量和复购都会受损。但供应商如果无条件支持，会面临拣货、配送、损耗和账期成本上升。所以正确做法是：**对高周转、高毛利、强时效的单品支持；对低周转、长保质期、低毛利单品不鼓励。**

**建议的落地规则**
1. **按品类分层**
   - 支持：叶菜、浆果、切果、鲜切水果、应季爆品、高频刚需单品，例如草莓、蓝莓、香蕉、苹果、西瓜小规格。
   - 限制：耐储水果、低周转进口果、礼盒果、大规格整箱果。
2. **设置起订门槛**
   - 单次补货金额或件数设最低线，低于门槛加收补货服务费，或并入次日补货。
   - 对紧急补货设“加急费”，避免平台把高频补货当免费库存缓冲。
3. **按销量数据给补货频次**
   - 日销稳定、动销率高的门店或前置仓，给每日1—2次补货。
   - 新店或低动销点，先隔日补货，跑出数据再提频。
4. **用“小批量+高频”换确定性**
   - 平台承诺滚动预测或固定补货窗口，供应商承诺缺货率、到货时效和鲜度标准。
   - 双方共担损耗，比如到货验收标准、临期处理规则、退货比例上限写清楚。
5. **成本要显性化**
   - 小批量高频补货的拣货、包装、短驳、冷链成本，必须通过补货费、阶梯价或返利机制覆盖，不能只让供应商承担。
   - 否则供应商会用降品质、减规格、拖时效来消化成本，最后反噬平台体验。

**一句话结论**
供应商应该支持小批量高频补货，但必须按品类、动销和成本设置门槛与阶梯规则；无条件支持不可持续，有条件支持才能同时保住履约体验和供应商毛利。
