茶饮店用香蕉，采购熟度控制的关键是：**不要按“已经很甜很好吃”的熟度买，而要按“到店后还能撑1—3天、并在使用日达到目标熟度”来买。** 香蕉是后熟水果，采购熟度要跟你的使用场景、到货频率、储存条件一起定。

### 1. 先按用途定目标熟度
- **做香蕉牛奶、奶昔、冰沙、果泥**：用**7—8成熟**，果肉软但没有明显酒味，甜度足、香气好，打碎后质地顺。
- **做香蕉甜品、捣泥铺底、蛋糕夹层**：用**6—7成熟**，偏硬一点，便于运输和操作，到店后放1—2天再用。
- **做装饰切片、表面摆盘**：用**5—6成熟**，果肉硬挺、切片不烂，但口感偏生，不能直接大量入口，需搭配甜品整体成熟度。
- **做香蕉果酱、熬煮馅料**：可用**8—9成熟**，甚至表皮有少量黑点，但必须无破损、无酸败酒味。

### 2. 采购时看“表皮+手感+果柄”
不要只看颜色，建议按这三项判断：
- **表皮**：青黄均匀、无大面积黑斑、无裂口、无渗液。做饮品建议买“黄中带一点青肩”的，回店后熟1—2天正好。
- **手感**：轻捏有弹性但不软塌。整串中若个别已经软烂，说明整批可能过熟。
- **果柄和切口**：果柄新鲜、切口不黑不霉；有霉点、酸味、酒味的直接拒收。

### 3. 采购量按“3天用量”控制
香蕉后熟快，建议：
- 高频到货的店：每次采**1—2天用量**，另备少量偏青香蕉做缓冲。
- 低频到货的店：采**3天用量**，按**5—6成熟、6—7成熟、7—8成熟**分批买，不要一批全同熟度。
- 夏季或室温高：采购熟度整体下调半级，到货后尽快分拣。
- 冬季或冷藏条件好：可略高半级，但香蕉不宜长期低温冷藏，易冻伤发黑。

### 4. 到店后必须分拣
到货当天把香蕉按熟度分成三档：
- **偏青**：常温阴凉处催熟，远离热源和阳光。
- **正好用**：当天优先使用。
- **偏熟**：立即去皮分装冷冻或做果泥，不要继续常温堆放。

香蕉会释放乙烯，**不要和已成熟水果、叶菜混放**；也不要整串闷在塑料袋里，容易过快软烂和发霉。

### 5. 到货验收标准建议写成一句话
**“表皮黄中带青、无黑斑裂口、轻捏有弹性、果柄新鲜无霉、无酒味酸味；到货熟度以6—7成熟为主，搭配少量5—6成熟和7—8成熟。”**

这样采购的核心不是追求“越熟越香”，而是**让香蕉在你需要的那一天刚好达到可用熟度**，同时把损耗控制在可接受范围内。
