普通水果和品牌水果在毛利与复购上的差别，核心不在“品牌”本身，而在**定价权、损耗率、购买决策成本和顾客信任**。下面按可判断、可执行的维度拆开说。

## 1. 毛利差别

**普通水果：毛利率通常更高，但毛利额不稳定。**
- 普通水果（如散装苹果、香蕉、应季柑橘）采购价低、加价空间看起来大，但同质化严重，顾客对价格敏感，售价容易被周边同行压住。
- 真正吃掉毛利的是**损耗**：普通水果品控不稳定、分级粗、卖相参差，腐烂、碰伤、尾货打折会显著拉低实际毛利。
- 所以普通水果常见情况是：**账面毛利率高，净毛利不一定高**，尤其叶菜类、浆果类、熟度高的水果。

**品牌水果：毛利率通常偏低，但毛利额和稳定性更好。**
- 品牌水果有包装、分级、产地背书，采购成本高，终端售价透明，单斤加价空间往往被压缩。
- 但它的优势是**损耗低、客单价高、动销可预期**：规格统一、耐储运、顾客认牌子后价格敏感度下降，尾货处理压力小。
- 因此品牌水果常见情况是：**毛利率低一些，但实际毛利额更稳，促销和临期损失更可控。**

**判断口诀：**
- 看**毛利率**：普通水果通常占优。
- 看**实际毛利额/损耗后毛利**：品牌水果往往更稳。
- 看**现金流和库存风险**：普通水果压货风险更高，品牌水果周转更可预测。

## 2. 复购差别

**普通水果：复购靠“便宜、新鲜、方便”，忠诚度低。**
- 顾客决策快，谁家便宜新鲜就去谁家，迁移成本低。
- 复购频率可以很高，尤其日常刚需品类，但**复购质量低**：价格一波动、品质一不稳，顾客就走。
- 普通水果的复购更依赖门店位置、陈列、当日新鲜度和促销，而不是商品本身。

**品牌水果：复购靠“信任和确定性”，复购率更稳但频次未必更高。**
- 顾客买品牌水果，买的是“不会踩雷”：甜度、规格、外观、送礼体面。
- 一旦建立信任，复购更稳定，客单价更高，退货和投诉更少。
- 但品牌水果的复购频次通常低于日常普通水果，因为价格带更高、消费场景更偏改善型或送礼型。

**判断口诀：**
- 要高**频次**：普通水果更强。
- 要高**复购质量/客单/信任**：品牌水果更强。
- 要**低投诉、低损耗、可预测**：品牌水果更强。

## 3. 组合建议（可直接执行）

1. **普通水果做流量和频次**：选 3–5 个高频刚需品，严控新鲜度和价格形象，用来拉客流。
2. **品牌水果做利润稳定器和客单**：选 2–3 个有认知、耐储运、复购稳定的品牌单品，用来托毛利额和信任。
3. **分开考核**：普通水果看“损耗后毛利额 + 动销天数”，品牌水果看“毛利率 + 复购率 + 客单价”，不要用同一毛利率标准要求两类商品。
4. **普通水果重点管损耗**：订货量、分级、尾货处理规则比追求加价率更重要。
5. **品牌水果重点管价格形象**：品牌水果价格透明，乱加价会伤复购；应靠稳定供应和组合销售赚钱。

**一句话总结：** 普通水果更容易做出毛利率和频次，但复购忠诚度和毛利稳定性差；品牌水果毛利率偏低，但损耗低、信任强、复购质量和毛利额更稳。实际经营中，普通水果负责拉新和频次，品牌水果负责稳毛利和稳复购。
