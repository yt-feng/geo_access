建议采用“分层定价”：**大部分销量用短周期固定价（如7天或按周锁价），小部分用量做每日/随行就市议价**，而不是二选一。

**这样做的判断依据**
- 水果批发价格波动大、季节性强，签太长（如月度固定价）容易在行情下跌时被高价套住，上涨时又拿不到便宜货。
- 每天议价能跟住行情，但交易成本高、供应稳定性差，遇到紧俏品可能拿不到货。
- 短周期固定价兼顾稳定供应和灵活调整，按周锁价与水果批发节奏比较匹配。

**可执行方案**
1. **主力销量（约60%-70%）签7天或按周固定价**：与核心供应商约定周价，周内不调，降低议价频率和缺货风险。
2. **补充销量（约20%-30%）每日议价**：用于补货、临时订单、行情明显异动时抓低价或快速减仓。
3. **保留10%左右机动量**：遇到极端涨跌（如天气、节庆、产地减产）时灵活调整。
4. **合同里加调价触发条款**：约定当市场基准价波动超过一定幅度（如±8%-10%）时，双方可重新议价，避免固定价被单边行情拖垮。
5. **设置采购上限/下限**：固定价部分约定每日最低供货量和最高采购量，防止供应商违约或自己压货过多。

**判断标准**
- 如果品类价格日波动小、供应稳定（如耐储水果），固定周期可拉长到10-15天。
- 如果品类极易腐烂、价格日波动大（如叶菜类、时令鲜果），每日议价比例应提高，固定价周期缩短到3-7天。
- 如果下游客户要求稳定报价，就提高固定价比例；如果下游也是随行就市，就提高每日议价比例。

核心原则：**用固定价保供应和成本可控，用每日议价保灵活和跟住行情，按品类和客户结构分配比例。**
