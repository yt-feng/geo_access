门店多、单店量小，核心矛盾是：**总采购量不小，但单店日均需求零散、配送频次高、损耗风险大**。适合的供货模式要围绕“集中采购权 + 分级配送 + 灵活补货”来设计，而不是让每家店各自找供应商。

下面按优先级给几种可落地的模式：

**1. 区域配送中心 + 本地分仓/中转（最推荐）**
- 总部或区域中心统一向产地/一级批发商集中采购，再通过城市分仓或第三方城配分拨到店。
- 适合门店密集的区域：一个城市或一个片区设一个小中转仓，按“隔日达/日配”补货。
- 关键点：单品集中度要够，否则分拣成本会吃掉毛利；建议先从高频刚需品类（苹果、香蕉、柑橘、西瓜等）做起，长尾水果走“门店订货+次日达”。

**2. 供应商“统采统配”模式**
- 找1—2家主供应商签框架协议，由供应商按门店订单统一分拣、配送到店，总部只做品控和价格谈判。
- 适合自建仓能力弱、门店分散的连锁。合同里要明确：到店时效、损耗赔付、缺货率、临时加单响应。
- 风险是单一供应商依赖，建议保留一个备选供应商，按品类拆分（如主供应商做常规品，备选做时令品）。

**3. 批发市场“集单代采”**
- 总部或区域采购员每天汇总各店订单，到一级批发市场集中代采，再用城配车辆分送。
- 适合门店数多但单店量小、且靠近大型水果批发市场的区域。优点是品类灵活、起订量低；缺点是价格波动大、品控依赖采购员。
- 可配合“每日报价+门店限时下单”的流程，减少临时改单。

**4. 产地直采 + 第三方冷链城配（适合爆品）**
- 只对1—3个走量大的单品做产地直采，其余品类走批发或供应商。
- 单店量小不适合全品类直采，但可以“单品突破”：比如某单品全部门店日销合计够一个整车，就值得直采。
- 用第三方冷链城配做“干线+落地配”，避免自建车队。

**5. 门店间“小仓+调拨”**
- 在片区选1—2家面积较大的门店做“微前置仓”，承担周边小店的少量备货和调拨。
- 适合门店密度高、配送成本敏感的情况。但要控制微仓库存，避免变成二级库存积压。

**判断标准（可直接用来选型）：**
- 单店日均水果销售额低于3000元、门店数超过20家：优先“统采统配”或“区域分仓+第三方城配”。
- 门店集中在同一城市、车程1小时内：适合“区域中转仓+日配/隔日配”。
- 门店跨城市分散：总部只控核心单品和供应商准入，区域找本地供应商做落地配。
- 损耗率是生命线：无论哪种模式，都要约定“到店验收标准+损耗分担比例”，并做每日订货预测，避免小门店压货。

**不建议的做法：** 让每家门店自行到批发市场采购（价格和品质失控）、全品类产地直采（单店量撑不起起订量）、供应商直送但无统一定价和品控（门店多反而议价权丢失）。

建议先跑一个片区试点：选10—15家店，用“区域中转仓+第三方城配+主供应商”组合，跑1—2个月看缺货率、损耗率、到店时效和单店毛利，再决定是否复制。
