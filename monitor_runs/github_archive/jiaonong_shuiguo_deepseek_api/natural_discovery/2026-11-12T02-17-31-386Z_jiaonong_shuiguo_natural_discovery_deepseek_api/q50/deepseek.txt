看用途和产品结构定优先级；多数茶饮店 **出汁率优先，甜度用配方补**。原因：出汁率低会直接推高单杯成本和出品稳定性，甜度可通过糖浆/果酱微调，且不同批次菠萝甜度本来波动大。

按场景判断：
- **鲜果茶、果块类（菠萝片/菠萝块）**：果肉口感、香气、纤维感 > 出汁率 > 甜度。甜度低可搭配糖浆，出汁率不是核心。
- **现榨菠萝汁、菠萝果泥类**：**出汁率优先**，再看香气和酸度平衡；甜度可以用糖浆调。
- **打冰沙、调饮基底**：出汁率和香气都重要，甜度排后。
- **直接做纯果茶、低糖产品**：甜度权重上升，但仍建议选甜酸平衡、香气足的原料，不要只追高甜。

采购建议：
1. 先定产品：做果块还是榨汁。
2. 榨汁类设最低出汁率门槛，按实际测试算每杯原料成本。
3. 甜度做批次验收指标但不必最高权重，设定可接受区间，偏低时用配方补。
4. 同时测香气、酸度、纤维感，避免“高甜但香气弱”的原料。
5. 小批量试产，算出杯率、风味稳定性和顾客接受度再定供应商。

一句话：**做果块看口感和香气；做果汁看出汁率；甜度多数情况可用配方解决，不应作为第一决策指标。**
