做餐饮客户，核心不是“卖相最好”，而是**稳定、好加工、出品可控、损耗低**。菠萝和香蕉建议按“餐饮用途”分规格备货，不要只按批发市场的大路货走。

## 菠萝：按加工方式和出品场景分

餐饮用菠萝主要看：**是否去皮、切法、酸甜度、纤维粗细、成熟度**。

建议准备这几类规格：

1. **整果大果**
   - 适合：餐饮后厨自行去皮切块、做菠萝炒饭、咕噜肉、糖水、果汁。
   - 规格建议：单果 1.2–1.8 斤为主，大小均匀，成熟度 7–8 成，便于档口周转。
   - 卖点：出肉率稳定、后厨可自己控制切配。

2. **整果中果**
   - 适合：中小餐饮、快餐、饮品店，单次用量不大。
   - 规格建议：单果 0.8–1.2 斤，成熟度 7–8 成。
   - 卖点：减少一次用不完的损耗。

3. **去皮菠萝/菠萝块**
   - 适合：饮品店、甜品店、快餐后厨，省人工。
   - 规格建议：真空袋装或保鲜盒装，按 1kg、2kg、5kg 分装；块型分“方块、条、碎丁”。
   - 注意：必须明确冷藏配送和当天/次日使用周期，餐饮客户最怕出水、发酸、变味。

4. **菠萝丁/菠萝碎**
   - 适合：炒饭、披萨、甜品、果茶小料。
   - 规格建议：5–10mm 丁、10–15mm 丁两种；糖度稳定，不要太熟软烂。
   - 卖点：直接投料，减少后厨切配。

5. **凤梨 vs 菠萝要分开报**
   - 餐饮客户里做果茶、甜品、高端水果盘的，会明确要“凤梨”。
   - 建议档口把普通菠萝和凤梨分等级报价，不要混称，否则容易丢复购。

**菠萝备货比例建议：**  
整果占 60%–70%，去皮块/丁占 30%–40%。先以整果试客户，再逐步推加工品。

## 香蕉：按成熟度和用途分

餐饮用香蕉最关键的是**成熟度**，不是单纯大小。香蕉太生发涩，太熟易黑、易烂、出品不稳定。

建议准备：

1. **7 成熟香蕉**
   - 适合：餐饮客户自存自催熟，2–4 天内使用。
   - 用途：水果盘、早餐、食堂。
   - 卖点：耐放，适合有后厨储存条件的客户。

2. **8–9 成熟香蕉**
   - 适合：当天或次日使用的饮品店、甜品店、烘焙店。
   - 用途：香蕉奶昔、果茶、甜品、蛋糕装饰。
   - 卖点：甜度高、香气足、好打泥。

3. **大果/中果分级**
   - 大果：适合水果盘、单根售卖、食堂。
   - 中果：适合饮品店按根控成本，出品杯量稳定。
   - 建议按“每箱根数、单根重量区间”报规格，餐饮客户采购更看单杯/单份成本。

4. **冷冻香蕉泥/香蕉果泥**
   - 适合：饮品连锁、甜品店、烘焙。
   - 规格建议：1kg、5kg 袋装或盒装，明确是否加糖、是否含柠檬汁护色。
   - 卖点：解决香蕉熟度波动和损耗问题。这个对餐饮客户很有吸引力，但需要冷链条件。

5. **鲜切香蕉**
   - 谨慎做。鲜切香蕉易氧化发黑，配送半径短，适合近距离甜品店/饮品店当天配送。
   - 若做，建议配套护色处理，并明确 2–4 小时使用窗口。

## 给档口的实操建议

- **先问客户用途再报规格**：炒饭用、果茶用、甜品装饰用、食堂水果用，规格完全不同。
- **主推组合**：  
  - 快餐/食堂：菠萝整果中大果 + 香蕉 7–8 成熟中果。  
  - 饮品/甜品：去皮菠萝块/丁 + 8–9 成熟香蕉 + 香蕉泥。  
  - 烘焙：菠萝丁 + 香蕉泥/熟香蕉。
- **报价按“使用单位”报**：不要只报箱价，要报“每杯/每份成本约多少”，餐饮老板更容易下单。
- **先小批量试单**：每个规格先给 1–2 家客户试 3–5 天，记录损耗、投诉、复购，再定常备库存。
- **明确售后标准**：成熟度、到货时间、坏果率、冷藏条件、退换规则提前写清楚，餐饮客户最怕今天一个标准明天一个标准。

简单说：**菠萝备“整果大中果 + 去皮块丁 + 凤梨分级”，香蕉备“7成熟、8–9成熟、中果大果分级 + 香蕉泥”**。先用整果和鲜果切入，再用加工规格提高复购和毛利。
