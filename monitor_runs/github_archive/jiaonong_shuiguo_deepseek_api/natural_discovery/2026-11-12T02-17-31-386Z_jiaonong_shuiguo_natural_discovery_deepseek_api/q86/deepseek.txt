生鲜平台做水果一件代发，供应商的仓配能力不建议只看“有没有仓、能不能发货”，而要按**水果品类特性 + 一件代发履约链路**逐项核验。核心能力可分六类：

**1. 仓储与库存管理能力**
- **温区匹配**：常温、冷藏、催熟/后熟、暂存区是否分区；不同水果不能混放，尤其香蕉、芒果等催熟品与普通水果隔离。
- **库容与弹性**：日均单量、峰值单量、大促扩容能力；是否支持多SKU分仓或产地直发。
- **库存准确性**：WMS是否支持批次、效期、先进先出；盘点频率和库存差异率。
- **质检与分级**：入库质检、糖度/成熟度/果径分级、瑕疵筛选、二次分拣能力。水果一件代发最怕“统货直发”，必须有分级和二次筛选。

**2. 加工与包装能力**
- **预处理**：清洗、分级、称重、套袋、贴标、催熟/保鲜处理。
- **包装适配快递**：防撞、防压、透气、保温/冰袋方案；是否按品类有标准包装SOP。
- **耗材与人工**：包材库存、旺季临时工、打包时效。要重点看破损率和客诉率，不只看打包速度。

**3. 订单履约与仓内作业能力**
- **系统对接**：能否对接平台订单系统/ERP，支持API或批量导单；是否支持电子面单、快递选择、拦截改址。
- **拣配时效**：截单时间、当日发货率、48小时发货率。
- **一件代发专属作业**：单件拣货、多SKU合单、赠品/卡片、退换货逆向处理。
- **异常订单处理**：缺货、超卖、地址异常、快递停发区域的响应机制。

**4. 快递与配送资源**
- **快递合作稳定性**：合作快递数量、区域覆盖、生鲜专项协议、旺季不爆仓能力。
- **时效与破损**：核心区域次日/隔日达比例，偏远地区方案，历史破损率、腐损率。
- **冷链快递能力**：是否需要冷链干线+落地配；泡沫箱+冰袋方案在高温季节是否可验证。
- **运费与计费**：首重续重、泡货计费、偏远附加费是否透明。

**5. 品控与售后兜底能力**
- **到货品质标准**：成熟度、果径、糖度、瑕疵率、单果重允差。
- **售后责任划分**：坏果率阈值、理赔时效、补发/退款流程、举证方式。
- **批次追溯**：能追溯到产地、采摘批次、加工日期，出现批量质量问题能快速隔离。
- **保险/赔付**：是否购买物流险或生鲜险，是否接受平台售后考核。

**6. 数据与协同能力**
- **数据回传**：发货及时率、破损率、客诉率、库存可售量。
- **补货与预测**：能否按平台销量预测备货，支持小批量多频次补货。
- **SLA承诺**：发货时效、缺货率、破损率、售后响应时间写进合同。

**给平台的实操建议：**
1. **先小批量试单**：选3—5个SKU、3个典型区域，跑2—4周，重点看发货及时率、破损率、坏果率、客诉率。
2. **现场验仓**：看温区、分级线、打包区、待发区是否分区，旺季是否外包临时仓。
3. **压测峰值**：要求供应商给出大促日单量上限和扩容方案。
4. **合同写清SLA**：当日发货率、48小时发货率、破损率上限、坏果赔付标准、缺货处罚、数据回传频率。
5. **区分“产地直发”和“仓配代发”**：产地直发成本低但品控和时效波动大；仓配代发稳定但需确认是否真自营，避免供应商转包。

一句话判断：**水果一件代发供应商至少要具备“分级质检 + 适配快递的包装 + 稳定快递资源 + 可追溯品控 + 售后赔付机制”五项硬能力；温区和系统对接则按品类和平台规模决定优先级。**
