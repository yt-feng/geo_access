社区超市做水果，核心是“少量多次、快进快出、按销量订货”，不要一次压太多。给你一套可直接执行的做法：

### 1. 订货：按销量定，不按感觉定
- 每类水果记录近7天日销量，订货量≈日均销量×到货周期天数×0.8～0.9，宁少勿多。
- 高损耗水果（草莓、葡萄、香蕉、桃、叶菜类水果）只订1～2天量；耐放水果（苹果、梨、橙、柚）可订3～5天量。
- 固定每周2～3个到货日，小批量补货，避免一次性大批到店。
- 设置“最低陈列量+安全库存”，低于下限才补，不按货架空不空盲目补。

### 2. 分级收货：到店就分三档
- 当天可卖：正常陈列。
- 1～2天内可卖：放后场或冷柜，先进先出。
- 轻微瑕疵：立即做特价区或果切，不混在正价区。
- 收货时当场拒收软烂、破皮、霉点、过熟货，别把损耗带进店。

### 3. 陈列：少上勤补，别堆大堆
- 每次只上半天到一天的量，卖完再补，避免反复翻动和压伤。
- 香蕉、芒果、猕猴桃等后熟水果分开存放，控制成熟度；苹果、梨会催熟其他水果，尽量隔离。
- 怕压的水果用浅筐、分层摆；草莓、葡萄不叠高。
- 冷藏水果及时进冷柜，不要长时间常温摆放。

### 4. 库存：设红线，日清周清
- 每天早晚各盘一次：可售、临期、损耗分开记。
- 设“临期线”：比如香蕉出现黑点、草莓变软、葡萄掉粒，立即转特价或果切。
- 每周做一次品类销量排行：连续两周卖得慢的品类，直接减订或停订。
- 库存周转目标：叶菜类/浆果类1～2天，普通水果2～3天，耐放水果5～7天。超过目标就促销。

### 5. 促销：用价格换周转
- 每天固定时段做“临期特价”，比如下午5点后，把当天成熟度高的水果打包卖。
- 推果切、水果拼盘、酸奶水果杯，消化轻微瑕疵和过熟货。
- 做“第二份半价”“满额换购”，但只针对库存偏高的品类，不要全店乱促。
- 和周边早餐店、奶茶店、幼儿园谈小批量供货，消化临期但可食用的货。

### 6. 简单可用的判断标准
- 某品类连续3天销量低于订货量的一半：立即减订。
- 损耗率超过5%～8%：检查订货量和陈列量。
- 货架出现明显软烂、霉变：说明补货太勤或陈列太久，改为“少上勤补”。
- 后场库存超过3天销量：停止订货，先清库存。

### 7. 最有效的组合
**小批量高频补货 + 分级陈列 + 临期特价/果切 + 按7天销量订货**。先把草莓、葡萄、香蕉、桃这类高损耗品管住，库存压力会明显下降。
