采购菠萝时，建议把“到店即卖”和“放两三天再卖”分开判断熟度，别只按一个标准进。

**判断方法（按顺序看）**

1. **看外观**  
   - 适合放2～3天再卖的：果皮底色偏青绿、鳞目紧密、果眼浅，整体硬挺。  
   - 适合当天/次日卖的：底色由青转黄、鳞目略鼓，但果皮还没有大面积软塌。  
   - 谨慎进：整果金黄、果眼深陷、底部发软或有酒味，损耗会很快。

2. **闻底部**  
   把菠萝翻过来闻果底：清香淡、偏青味 = 偏生，可放；香味明显但不冲 = 适销；有发酵味、酒味 = 过熟，少进或不进。

3. **按果身和底部**  
   轻按果身有弹性但不塌，底部干爽、不软、不渗汁为佳。底部一按就软、湿，说明后熟快、易坏。

4. **看冠芽和切口**  
   冠芽青绿有精神、切口新鲜无褐变、无霉点更好。冠芽枯黄、切口发黑，耐放性差。

5. **掂重量**  
   同样大小，手感沉、汁水足更好；过轻可能失水或过熟空心。

**采购比例建议**

- 当天卖：进底色转黄、香味初显、按着略有弹性的，约占 **30%～40%**。  
- 放2～3天卖：进偏青、硬挺、香味淡的，约占 **60%～70%**。  
- 气温高、门店周转慢时，偏青比例再提高；夏天少进全黄果。

**简单执行标准**

> 青底硬身、底干香淡的为主；黄底微弹、香而不酒的为辅；软底、酒味、渗汁的一律少进或不进。

另外，菠萝是后熟水果，进货后不要堆压、不要闷在高温处，底部朝下通风摆放，先卖黄的、后卖青的，能明显减少损耗。
