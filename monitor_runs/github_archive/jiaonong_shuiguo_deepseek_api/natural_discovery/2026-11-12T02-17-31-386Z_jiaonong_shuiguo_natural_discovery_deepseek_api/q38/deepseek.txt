大型超市对水果供应商的要求，核心是“食品安全能追溯、冷链不断链、批次能隔离召回、到店损耗可控”。可按下面清单判断供应商是否合格。

## 1. 食品安全资质与体系
供应商至少应具备并可持续维持：

- **合法主体资质**：营业执照、食品经营/生产相关许可（按业务形态）、种植/养殖基地证明或合作基地协议。
- **食品安全管理体系**：ISO 22000、HACCP 或同等体系；有完整食品安全管理制度、组织架构和责任人。
- **产品检测能力或委托检测机制**：农残快检 + 第三方定量检测；能按超市要求提供批次检测报告。
- **投入品管理**：农药、化肥、保鲜剂、催熟剂、清洗剂、蜡等的采购、领用、休药期/安全间隔期记录。
- **人员与场所卫生**：加工分选场所卫生、人员健康证、虫害控制、清洗消毒记录。
- **包装与标签合规**：食品接触材料合规，标签含品名、产地、批次、日期、供应商信息等。
- **召回与投诉处理**：有不合格品隔离、召回演练、客诉追溯和纠正措施记录。

判断要点：不要只看证书，要看**最近一次内审/外审不符合项闭环、近12个月检测报告、召回演练记录**。

## 2. 追溯与批次管理
大型超市通常要求“从门店到基地”可追溯：

- 每批货有**唯一批次号**，能关联基地/地块、采收日期、分选包装日期、检测报告、发货单、收货门店。
- 有**进货查验和出厂检验记录**，票据、检测报告、物流温控记录能按批次调取。
- 能支持超市抽检、飞行检查、监管抽查时**2小时内提供批次链路**（具体时限按合同）。
- 不合格批次能快速锁定库存、在途和在店数量，配合下架召回。

## 3. 冷链与物流能力
水果品类差异大，但供应商应具备：

- **预冷能力**：采收后尽快预冷，尤其是浆果、叶菜类水果、桃李等呼吸跃变型水果。
- **冷链运输**：冷藏车/保温车，车厢清洁消毒记录，温度实时记录并可导出；不同水果分温区管理。
- **装卸与中转**：月台封闭或防雨防虫，装卸时间控制，避免断链；中转仓有温湿度监控。
- **包装与堆码**：透气/防压包装，防挤压、防日晒雨淋，托盘化与周转筐清洁。
- **配送时效与频次**：能按超市DC或门店要求定时达，支持多温层、多门店配送。
- **异常处理**：断链、温度超标、延误、破损的应急预案和赔付机制。
- **物流信息系统**：TMS/WMS或等效系统，能提供在途温度、到货时间、签收和异常记录。

判断要点：重点看**预冷到装车的时间、运输温度曲线、到店中心温度、断链次数和赔付记录**。

## 4. 品控与收货标准
- 能执行超市的**水果验收标准**：糖度、硬度、色泽、规格、成熟度、缺陷率、农残合格。
- 有**分选分级、抽检留样、不合格品隔离**流程。
- 对易腐水果有**成熟度与货架期管理**，能按门店销售节奏调整发货成熟度。
- 有**损耗率承诺和赔付机制**，能处理到店后短保质期商品的退换。

## 5. 产能、应急与合规
- **基地/货源稳定性**：自有基地或长期合作基地，能提供产地证明和面积/产量匹配说明。
- **季节性替代方案**：主产区受灾时的替代产区或储备货源。
- **食品安全事件应急**：不合格品封存、召回、媒体与监管应对、客户通知机制。
- **保险与责任**：产品责任险、货物运输险等（按超市要求）。
- **可持续与合规**：农残超标历史、监管处罚记录、环保和用工合规审查。

## 快速判断清单
让供应商提供以下材料，基本能判断是否达标：

1. 营业执照、食品相关许可、体系证书及最近审核报告；
2. 近6—12个月批次农残检测报告和快检记录；
3. 基地清单、地块图、投入品记录样本；
4. 批次追溯演示：任选一箱货追溯到基地和检测报告；
5. 冷链温度记录样本和断链应急流程；
6. 召回演练记录、客诉与不合格品处理记录；
7. 物流车辆清单、温控设备校准记录、保险单；
8. 超市验收标准执行方案和损耗赔付承诺。

**结论**：大型超市水果供应商的门槛不是“有证有车”，而是**批次可追溯、冷链可验证、异常可召回、损耗可赔付**。采购审核时应以现场审核 + 批次追溯演练 + 温度记录抽检为主，证书只作入门条件。
