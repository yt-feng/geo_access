做小包装香蕉，采购和包装要重点盯“成熟度、分装方式、损耗边界”三件事。可以按下面执行判断：

1. **采购成熟度要偏生**
   - 小包装周转慢，建议采购3～4成熟、到店后能自然转色的香蕉，避免买5～6成熟黄香蕉直接分装。
   - 看果柄：青绿色、无霉斑；果身：无大面积黑点、无压伤、无裂口。
   - 夏季或门店温度高时，成熟度再降半档；冬季可略高半档。

2. **包装规格别贪小**
   - 社区超市建议单包3～5根，净重约500～800克，太小单包损耗占比高、人工也高。
   - 优先选带透气孔的薄塑料袋或开窗纸盒，不要完全密封：香蕉呼吸产热，密封易出汗、发黑、长霉。
   - 袋口不要扎死，留透气口；盒装底部垫吸水纸，减少冷凝水。

3. **分装时减少机械伤**
   - 整把分切时用锋利刀从果梳连接处切，不要硬掰，避免撕伤果柄。
   - 分装前挑出已有黑斑、软伤、裂口的果子，不要混进小包装“赌卖相”。
   - 操作台保持干燥，手和工具少沾水，香蕉表皮沾水后易发黑。

4. **陈列和库存控制**
   - 小包装适合放收银台或常温端架，避免冷柜直吹和阳光直射；香蕉低于10～12℃易冷害发黑。
   - 每天按“先进先出”翻检，黄熟快的包优先做促销或移到显眼位。
   - 采购量按1～2天销量定，小包装香蕉不适合压库存；夏季日损耗控制在3%～5%以内较合理，超过要缩量或改规格。

5. **和供应商约定**
   - 采购时明确到货成熟度、单根长度和允许黑斑比例，比如“果柄青绿、果身无大面积黑点、压伤率低于5%”。
   - 要求整箱内加垫纸、分层摆放，减少运输压伤；到货当场抽检底层和箱边果。
   - 若做固定小包装，可让供应商按规格预分装，但要把透气孔、净重和成熟度写进验收标准。

简单记：**买偏生、包透气、分3～5根、不扎死、不进冷柜、日清日翻。**
