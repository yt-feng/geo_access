单位采购水果到货品质不一致，验收和售后要抓住三个环节：**到货前定标准、到货时留证据、到货后按合同处理**。

**一、到货前先明确标准**
- 合同或订单里写清品种、规格（果径/单果重）、成熟度、糖度范围、外观要求（无腐烂、无机械伤、无病虫害）、允许的不合格比例。
- 明确“品质不一致”的处理规则，例如：不合格率≤5%正常收货；5%–15%按比例扣款或换货；>15%拒收或整批退货。
- 约定到货时限、验收时限（如到货后2小时内完成抽检）、售后响应时限（如24小时内答复、48小时内补换）。

**二、到货验收怎么做**
1. **随机抽样，不只看表面**：按批次分层抽样，箱装水果抽上中下三层，散装按不同位置取样，避免只验最上面一层。
2. **现场记录**：开箱拍照/录像，拍清包装标签、批次、整箱状态和问题果特写；称重记录实际到货重量。
3. **分级判定**：按合同标准把样品分为合格、可让步接收、不合格三类，统计不合格比例。
4. **当场确认**：验收单上写清到货数量、抽检数量、不合格数量及比例、处理意见（收货/扣款/换货/拒收），双方签字。供应商不到场的，拍照录像并书面通知，保留送达记录。
5. **留样**：有争议的批次留样封存，标注日期和批次，便于后续复检。

**三、售后怎么处理**
- **按合同执行**：不合格部分优先要求补换货；无法补换的按比例扣款或退货。不要先自行处理问题果再找供应商，容易扯皮。
- **书面留痕**：用邮件或工作群发验收结果和整改要求，写明批次、数量、问题、期望处理方式和时限。
- **区分责任**：运输损耗、冷链断链、成熟度不符、以次充好，处理方式不同。若供应商多次出现同类问题，可依据合同条款暂停合作或索赔。
- **内部同步**：把验收结果同步给使用部门，避免问题水果流入食堂或发放环节。

**可执行建议**：先做一张《水果验收单》，包含批次、品种、规格、到货数量、抽检数量、不合格比例、问题描述、处理意见、双方签字；再在合同里补一条品质不一致的分级处理条款。这样验收有依据，售后有抓手。
