核实“全国配送”不能只听口头承诺，建议按以下顺序做，能较快判断真实覆盖能力：

1. **要配送范围清单，不要只听“全国”**
   - 让对方提供可配送的省份/城市/区县清单，最好到区县或至少到地级市。
   - 明确哪些地区是“直达”、哪些是“中转/自提/加价配送”。
   - 重点问：偏远地区、县级市、乡镇、山区、岛屿是否覆盖。

2. **要时效和温控承诺**
   - 水果关键看时效和冷链。要求写明：下单到发货、干线运输、末端配送各多久。
   - 问清是否全程冷链、用哪类冷藏车/保温箱/冰袋，夏季和冬季方案是否不同。
   - 到货温度、破损率、腐损率如何约定。

3. **用真实地址做试单**
   - 选几个代表性地址：一线城市、普通地级市、县级市/乡镇、偏远地区，分别让对方报价并确认能否送达。
   - 试单不要只发一个近处地址，最好同时测“远、偏、小”的地址。
   - 小批量试单后检查：实际到达时间、包装、温控、损耗、末端是否转快递或自提。

4. **核验物流合作方和单号轨迹**
   - 问清合作物流/快递公司名称、是否自有冷链、哪些线路外包。
   - 要求提供真实运单号，看轨迹是否从产地仓直达目的地，是否中途多次转手。
   - 注意“全国配送”可能只是发普通快递，水果品质风险高。

5. **要资质和案例，但交叉验证**
   - 营业执照、食品经营/生产相关资质、冷链运输资质（如有）。
   - 让其提供近3个月发往不同省份的配送记录或客户案例，最好能联系1—2个采购方核实。
   - 不要只看宣传页和截图，要求可核验的运单或合同案例。

6. **在合同里写清覆盖和违约责任**
   - 列明可配送区域、时效、温控标准、破损/腐损赔付、无法送达的处理方式。
   - 约定“超出覆盖范围需提前告知”，避免下单后转普通快递或加价。
   - 设置试运行期和考核指标：准时率、腐损率、投诉响应时间。

7. **看售后和异常处理能力**
   - 问清偏远地区出现延误、破损、拒收时谁负责、多久响应、如何补发或赔付。
   - 要求提供末端配送联系人，而不是只有销售对接。

**最有效的组合：先要区县清单 + 选3—5个代表性地址试单 + 查运单轨迹 + 合同写清时效温控赔付。** 如果对方只能给“全国都能发”但给不出区县清单、运单案例和温控方案，实际覆盖能力大概率有限。
