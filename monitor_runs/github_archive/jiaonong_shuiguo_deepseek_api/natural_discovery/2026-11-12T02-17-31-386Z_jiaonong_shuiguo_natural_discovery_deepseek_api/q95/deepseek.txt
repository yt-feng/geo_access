选水果供应商，核心不是“找最便宜的”，而是先定验收标准，再让供应商按标准报价和送货。建议按下面做。

**1. 先定采购和验收标准**
- 香蕉：按成熟度分级，青蕉、微黄、黄熟分开；到货以微黄为主，拒绝黑斑过多、断指、水烂。
- 苹果：定品种、果径、糖度范围、色泽、碰伤率；常见如红富士按70/75/80果径分档。
- 橙子：定品种和产地范围，如脐橙、冰糖橙；看果径、皮厚、汁水、腐烂率。
- 统一写进采购单：品种、规格、等级、产地范围、成熟度、单果重量或果径、允许损耗率、农残检测要求、送货频次、退货规则。

**2. 供应商来源**
优先找三类：
- 本地一级批发商：响应快、可小批量、适合日常补货。
- 产地合作社或水果基地：价格和稳定性好，但要有冷链和分拣能力。
- 合规配送商：能提供检测报告、发票、冷链记录，适合学校审计要求。

不要只看一家，至少找3家比价，并实地看分拣场、冷库和货源。

**3. 重点核验资质**
- 营业执照、食品经营许可证或食用农产品销售相关资质。
- 水果农残检测报告或承诺达标合格证。
- 冷链运输能力，尤其夏季。
- 食品安全责任险、开票能力、应急补货能力。
- 近一年给学校、机关、企事业单位供货的案例。

**4. 用试供和验收筛供应商**
先签短期试供合同，比如2周到1个月，按同一标准送3到5次。每次验收记录：
- 到货重量与净重
- 品种规格符合率
- 腐烂、碰伤、畸形率
- 成熟度是否适合当天或次日食用
- 送货准时率
- 缺货补货响应时间
- 价格是否随行就市且有报价依据

建议设定明确门槛，例如：到货合格率低于95%扣款或退货；连续两次不达标终止试供。

**5. 合同和价格机制**
- 价格不要一次锁死太久，常见水果价格波动大，可用“每周/每两周报价+市场询价对比”机制。
- 约定质量标准、退货换货时限、损耗承担方、违约责任、食品安全责任。
- 约定不得以次充好、不得混装、不得临时换产地品种。
- 结算附验收单、检测报告、发票。

**6. 日常管理**
- 至少保留两家合格供应商，主供加备供，防止断供。
- 每周看一次市场价格，和供应商报价对比。
- 每月统计各供应商合格率、准时率、投诉次数，末位淘汰。
- 食堂收货、库管、采购分开，验收时随机抽检，不能供应商说合格就合格。

简单说：**先写标准，再找3家试供，用验收数据选主供，合同里写清质量、价格、退货和食品安全责任。** 对学校食堂来说，稳定、可追溯、能退换，比单纯低价更重要。
