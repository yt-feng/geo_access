商超会员日水果活动，供应商要提前配合的核心是**把“货、价、品质、陈列、履约、应急”六件事在活动前锁定**，而不是等活动当天再补。可按以下清单准备：

**1. 活动前7—15天：确认活动方案**
- 确认会员日档期、主推单品、活动价/会员价、限购规则、预估销量。
- 与商超采购确认毛利空间、费用承担方式（特价补贴、陈列费、损耗承担）。
- 确认门店覆盖范围、配送频次、到货时间窗口。
- 对主推品做供应能力评估：产地是否稳定、能否分批次到货、是否有替代品。

**2. 活动前5—7天：锁货与锁价**
- 按预估销量的1.2—1.5倍备货，主推爆品单独锁货源。
- 与上游产地/批发商锁定价格和采摘/发货计划，避免活动前涨价断供。
- 确认包装规格、箱重、标签、条码、会员价签信息，避免门店二次改价出错。
- 提前送样或提供到货质量标准，和商超品控对齐验收口径。

**3. 活动前3—5天：品质与加工准备**
- 按活动日销量做分级、预包装、贴标，减少门店现场加工压力。
- 明确成熟度标准：活动首日到货不能过熟，后续批次按日销节奏分批到。
- 准备损耗预案：易损品如草莓、葡萄、桃类，控制单批到货量，增加补货频次。
- 冷库/冷链车辆预冷，确认温控记录和到店交接流程。

**4. 活动前2—3天：物流与到店安排**
- 提交分店分日配送计划，明确每店到货时间，避开门店高峰。
- 确认卸货人员、周转筐、托盘、冷链车资源。
- 对重点门店可安排供应商驻店或巡店人员，负责补货、挑拣、陈列协助。
- 与门店确认陈列位置、堆头/端架、POP物料由谁提供。

**5. 活动前1天：最终确认**
- 再次确认库存、在途、到店数量，和商超对接人做一次电话/群确认。
- 确认应急联系人、备用车辆、备用货源。
- 检查价签、活动标识、试吃物料（如需要）是否到位。
- 对可能缺货单品准备替代方案，避免门店空陈列。

**6. 活动当天及活动后**
- 首日早高峰前到货，安排人员巡店补货、挑出次果。
- 按销售数据动态补货，避免一次性压货造成损耗。
- 活动结束后48小时内完成对账、损耗确认、退换货处理。
- 复盘销量、缺货率、损耗率、客诉，作为下次会员日备货依据。

**最关键的三个判断点：**
- 爆品有没有**锁量锁价**；
- 到货成熟度能不能**撑住首日高峰**；
- 有没有**备用货源和补货车辆**。

这三项没落实，会员日水果活动很容易出现“低价引流但断货、品质差、损耗高”的问题。
