采购香蕉时，熟度不要统一要求成黄色，按销售周期分批要货才实用。建议这样定：

**1. 按熟度分批要货**
- **主力批次要“青黄之间”**：果身基本转黄、两头还带一点绿，适合到店后卖 2–4 天。不要大面积黄、带黑点的。
- **少量要“偏青”**：青果肩、绿色明显，适合作为后段库存，在店里自然转熟。
- **熟果只少量补**：已经全黄、略有香气的，只按当天或次日销量要，不能作为主要采购熟度。

**2. 到货时间要求**
- 优先要求**清晨到货或开门前到货**，避开午后再到一批、当天卖不完又过夜。
- 和供应商约定**分 2–3 批到货**，比如周初一批偏青、周中一批青黄、周末前少量补熟果，而不是一次到一大堆同熟度。
- 到货后按熟度分区、先进先出，偏青的放常温后熟，熟果优先陈列和促销。

**3. 采购验收口径**
- 明确拒收：大面积黄斑、黑点、果柄发黑、软塌、明显机械伤、整箱成熟度过于一致的。
- 明确要求：同一箱或同一批里允许有熟度差，便于门店分批销售。
- 观察果指粗细和棱角：过细、棱角明显发青的一般后熟差，不建议作为主库存。

**4. 和供应商约定**
可以直接说：“香蕉不要统货全黄，按青黄分批；主力批次要能卖 3 天左右，熟果只补当天量；到货分清晨和开门前，不要下午集中到货；整批过熟或黑点多的拒收。”

核心原则：**不要把采购熟度定成一个标准，而要按到货后几天卖完来倒推熟度，并让供应商分批送。**
