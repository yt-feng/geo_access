水果生意要长期稳定，选供应商时最容易忽视的不是“价格”和“有没有货”，而是下面这些会慢慢放大的细节：

1. **只看样品，不看大货一致性**
   样品很好不代表每批稳定。要关注同一供应商连续多批的规格、糖度、成熟度、大小、色泽是否一致。长期生意最怕“这批好、下批差”。

2. **不核验产地与分级标准**
   问清楚是产地直发、批发市场调货还是代采；分级是按大小、糖度、外观还是混级。分级标准模糊，后期损耗和客诉会很高。

3. **忽视采摘成熟度和运输半径**
   为了耐运输采得太生，口感不稳定；太熟又损耗大。要确认采摘成熟度、预冷方式、运输时长和到货成熟度，而不是只问“几天到”。

4. **没有明确损耗责任和赔付规则**
   到货烂果、压伤、冻伤、失水谁承担？按件赔、按斤赔还是下批补？最好有照片/视频验收、时限和赔付标准。否则每次扯皮都会侵蚀利润。

5. **不看出货高峰期的履约能力**
   旺季、节假日、恶劣天气时能不能稳定供货，比平时报价更重要。要了解对方日发货量、备货来源、替代方案和临时涨价规则。

6. **忽视包装和预冷细节**
   箱规、内衬、冰袋、透气孔、码垛方式、预冷是否到位，直接影响损耗。很多问题不是水果本身，而是包装和冷链不匹配。

7. **不关注供应商的客户结构**
   如果对方主要供商超，分级和稳定性通常更强；如果主要做尾货，价格低但波动大。要看他把你放在什么客户层级，旺季会不会优先保你。

8. **账期和结算方式模糊**
   长期合作要明确现结、周结、月结、保证金、涨价通知期。账期越长越要评估对方资金压力，避免突然断供或以次充好。

9. **没有备选供应商**
   单一供应商风险很高。至少保持“一主一备”，并定期小批量测试备选，不要等主供出问题才找。

10. **只谈价格，不谈售后和沟通效率**
    出问题时响应速度、能否快速补货、是否愿意共同承担损耗，比每斤便宜几分钱更重要。长期稳定靠的是可预期的合作规则。

**可执行建议：** 先做一张供应商评估表，固定记录：到货损耗率、规格一致率、糖度/口感、准时率、赔付执行、旺季保供、账期条件。连续合作3—5批后再决定是否放量，不要凭一次样品和一次低价就长期绑定。
