建议优先选 **小把（3～5根）为主，单根作补充，整袋谨慎少量试销**。便利店场景下，“小把”通常是销量和损耗之间最平衡的包装。

判断依据和可执行方案如下：

1. **主推小把（3～5根）**
   - 适合便利店“即时消费、小家庭、单人”场景。
   - 客单价高于单根，又比整袋更容易冲动购买。
   - 建议按根数或重量统一定价，标清“约3～5根/把”，避免每把差异太大引起比价。

2. **保留单根**
   - 适合学生、上班族、只想买一根的人群。
   - 可作为引流和降低尝试门槛的规格。
   - 但单根毛利低、人工分拣和称重成本高，不建议作为唯一规格。

3. **整袋只做小规格试销**
   - 整袋适合家庭采购，但便利店客流多为即时消费，整袋容易滞销、压货和产生黑斑损耗。
   - 如果要做，选 **小袋装、固定根数、固定价格**，先少量上架观察1～2周。

4. **陈列和损耗控制**
   - 香蕉按成熟度分开陈列：偏青的放后排，黄色即食的放前排。
   - 小把和单根放在收银台附近或鲜食区，整袋放果蔬冷藏柜旁端架。
   - 每天检查黑斑、断裂和过熟品，及时降价处理或做搭配促销。

5. **简单试销判断标准**
   - 连续1～2周统计：小把销量占比、单根销量、整袋动销率和报损率。
   - 若小把动销最快、报损可控，就扩大小把排面；整袋若周动销低或报损高，就下架或改为预订。

结论：**起步组合建议为“小把为主 + 单根补充 + 小袋少量试销”**，不要一开始大量上整袋。
