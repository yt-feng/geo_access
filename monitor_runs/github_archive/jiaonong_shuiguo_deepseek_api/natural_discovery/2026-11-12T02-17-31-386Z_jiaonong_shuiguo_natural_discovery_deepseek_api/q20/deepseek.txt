社区超市做每日水果配送，筛选供应商时重点看“能否稳定日配 + 损耗可控 + 结算清晰”。建议按下面条件逐项核验：

1. **日配能力**
   - 是否固定每天配送，几点到店，能否按你营业时间送。
   - 节假日、雨天、爆单时是否照常配送。
   - 有无冷藏车/保温箱，水果是否全程冷链或避晒避冻。
   - 临时加单、减单的最晚截止时间。

2. **货源与品类结构**
   - 常供品类是否覆盖你的主力：苹果梨橙等耐储、香蕉、时令浆果、瓜类。
   - 是产地直采、一级批发还是二级分销，价格波动时谁承担。
   - 能否小批量多品类混配，避免一次压太多货。
   - 是否有稳定替代品，某品类断货时能否及时补位。

3. **质量与损耗条款**
   - 验收标准要写清：大小、成熟度、伤果率、烂果率、农残检测或承诺。
   - 坏果、短斤少两怎么赔：当场退换、下次补货、折价还是扣款。
   - 损耗率大概多少，是否接受“到店验收后责任转移”。
   - 先小批量试配1—2周，记录每天到货合格率和损耗。

4. **价格与结算**
   - 报价是否含配送费、装箱费、卸货费。
   - 价格随行就市时，提前多久通知调价。
   - 账期是现结、周结还是月结，有无押金。
   - 对账方式：送货单、微信群确认还是系统下单，避免扯皮。

5. **资质与食品安全**
   - 营业执照、食品经营许可/食用农产品相关资质。
   - 农残检测报告或承诺书，是否能提供批次来源。
   - 配送人员健康证、车辆卫生情况。

6. **履约与售后**
   - 迟到、漏送、缺货的补偿规则。
   - 售后响应时间，是否专人对接。
   - 合作稳定性：服务多少家社区店、有无同类客户案例，但别只听对方说，最好实地看仓库和分拣。

7. **试合作建议**
   - 先签短期试配协议，选10—15个高频单品，连续试2周。
   - 每天记录：到货时间、合格率、损耗、缺货次数、售后处理速度。
   - 同时保留1家备选供应商，避免单一依赖。

实操上，最关键是三件事：**能不能每天准点到、坏果谁承担、价格和账期是否写清**。把这三点落到书面或聊天记录里，再谈长期合作。
