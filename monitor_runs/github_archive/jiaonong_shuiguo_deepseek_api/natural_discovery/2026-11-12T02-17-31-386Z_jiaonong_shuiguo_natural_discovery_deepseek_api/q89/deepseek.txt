对价格敏感的团购客户，通常**阶梯价更合适做“前台主机制”，返利作为补充**。判断标准不是二选一，而是看三件事：客户是否愿意提前承诺量、你是否能核验实际销量、以及价格透明度和窜货风险。

**1. 阶梯价更适合的情况**
- 客户决策逻辑是“现在单价能降多少”，对即时折扣最敏感。
- 单次团购、项目制、季节促销，销量集中在短周期。
- 产品标准化、SKU少，阶梯档位容易设计。
- 你希望用明确价目表快速成交，减少谈判成本。
- 优点：感知强、易比较、成交快；缺点：可能压低首单价格、量未达标难追回、不同客户间比价压力大。

**2. 返利更适合的情况**
- 客户是长期团购渠道，销量分散在全年，单次订单不稳定。
- 你无法在成交时确认最终销量，或需要防止客户虚报团购量。
- 希望绑定客户持续采购、控制终端零售价、减少直接降价对价格体系的冲击。
- 优点：保护标价、事后按实际销量兑现、便于绑定长期合作；缺点：客户感知弱、兑现周期长、对现金流敏感的客户吸引力不足。

**3. 对价格敏感客户，推荐组合**
- **前台给小额阶梯价**：设置2—3档，首档容易达到，让客户立即感到优惠。
- **后台给销量返利**：按季度/年度累计销量返利，返利以货款抵扣、下一单折扣或市场费用形式兑现，不直接返现金。
- **设保底量与封顶**：返利门槛要高于阶梯价最高档，避免双重让利过度。
- **价格透明规则**：阶梯价按单次订单量，返利按累计核销销量，明确不含退货、跨区窜货不计入。
- **算清毛利底线**：先测算阶梯价最低档和返利最高档叠加后的综合毛利率，确保不低于底线；返利比例建议从低起点测试，再按客户实际动销调整。

**简单判断**：如果客户要“这次就便宜”，用阶梯价；如果客户要“长期合作越买越便宜”，用返利；大多数价格敏感团购客户，用“低门槛阶梯价 + 累计销量返利”最稳。
