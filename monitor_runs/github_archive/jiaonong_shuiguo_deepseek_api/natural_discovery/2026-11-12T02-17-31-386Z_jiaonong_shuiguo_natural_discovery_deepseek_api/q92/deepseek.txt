门店面积小，水果采购的核心不是“多进几个品种”，而是**把水果当引流+高周转品类做，而不是当全品类生鲜做**。建议从下面几个层面控制品类和损耗。

## 一、先定品类：少而准，控制在“3+2+1”

小店水果区建议总SKU控制在 **8～12个**，结构如下：

1. **3个高频刚需品**：苹果、香蕉、橙子/柑橘。  
   - 作用：稳定客流、价格敏感、顾客认知强。
   - 采购：香蕉少量多次；苹果耐放可稍多；橙子按季节选1种主推。

2. **2个季节引流品**：当季最好卖、能做出价格感的，如夏季西瓜/葡萄，冬季砂糖橘/草莓。  
   - 作用：制造“这家店水果新鲜便宜”的印象。
   - 采购：只做1～2个爆品，不做全季节矩阵。

3. **1个差异化/高毛利品**：如小番茄、蓝莓、切果盒、精品提子等。  
   - 作用：拉毛利，但量要小。
   - 采购：按预订/小份装走，不压货。

**明确不做或少做**：榴莲、菠萝蜜、整箱高端进口果、易碰伤浆果类大量铺货、需要现场加工且动销慢的品类。小店经不起“品类齐全”的库存压力。

## 二、采购量：用“日销倒推”，不要凭感觉

1. **按天订货，按半周调整**  
   - 叶菜类、草莓、葡萄、香蕉等易损品：**1～2天量**。
   - 苹果、橙子、梨等耐放品：**3～5天量**，但也不要超过一周。
   - 新品种首次只进 **最小陈列量的1～2倍**，卖动再补。

2. **设置单品日销上限**  
   例如某店日均卖香蕉20斤，就按20～25斤订货；节假日上浮20%～30%，不要翻倍。小店缺货可以补，压货只能扔。

3. **用“最小陈列+后台少量库存”**  
   台面只摆看起来满的量，实际库存放后台。避免台面堆太多导致翻拣、碰伤、成熟过快。

## 三、损耗控制：从收货到出清做闭环

1. **收货标准要硬**  
   - 香蕉不要进太熟的；草莓、葡萄看底层；西瓜抽检。  
   - 一次到货不合格率高的供应商，直接减量或换。

2. **分级陈列和定价**  
   - 好果正价，轻微瑕疵果及时做“特价盒/切果盒”。  
   - 不要等烂了再处理，**外观下降就降价**，比报废强。

3. **小份化销售**  
   - 西瓜切半/四分之一，葡萄小盒，苹果按个卖。  
   - 小店顾客即时消费多，小份装能显著降低整颗/整串卖不掉的风险。

4. **固定出清时段**  
   - 每天晚高峰后设“水果出清价”，把当天成熟度高、次日难卖的品处理掉。  
   - 建立规则：香蕉表皮出现黑点、草莓变软、切果盒超时，立即下架或折价，不隔夜硬撑。

5. **记录三个数**  
   每天记：**进货量、销售量、报损量**。连续一周看哪些单品报损高，直接砍掉或减半订货。小店不需要复杂系统，一个表格就够。

## 四、供应商和补货策略

- **少量多次补货**：和供应商谈每日或隔日配送，哪怕单价略高，也比损耗低。
- **主推品集中采购**：3个刚需品固定供应商，保证稳定；季节品快进快出。
- **避免“凑单进货”**：为了运费或返点多进不动的品，是小店水果损耗的最大来源之一。

## 五、直接可执行的采购原则

可以给门店定一条简单规则：

> **水果SKU不超过12个；易损品只备1～2天量；耐放品不超过5天量；新品首单只进最小陈列量；每天晚间出清；连续3天报损高的单品立即下架或减半订货。**

这样小店水果区能做到：品类看起来有重点、库存不重、损耗可控，同时还能承担引流作用。
