茶饮店控制水果供应商食品安全风险，建议按“资质证明＋检测报告＋过程证明＋批次凭证”四类收集，并根据水果用途（鲜食、榨汁、加热）和风险等级分级管理。

**一、供应商主体资质**
1. 营业执照（经营范围含水果种植、销售或农产品批发）。
2. 食品经营许可证或食品生产许可证：若供应商仅销售食用农产品，通常可免于食品经营许可；若涉及切果、鲜榨、预包装加工，应核查相应许可。
3. 仅销售预包装食品的，核查仅销售预包装食品备案信息。
4. 供应商食品安全管理员或质量负责人信息及联系方式。

**二、产品合格证明**
1. 食用农产品承诺达标合格证，优先要求每批次随货提供。
2. 产地证明或购货凭证，用于追溯来源。
3. 农药残留检测报告：优先索取近批次或近半年的第三方检测报告；高风险水果如草莓、葡萄、柑橘类、杨梅等可提高频次。
4. 若供应商自行检测，要求提供快检记录和检测项目、方法、结果。
5. 进口水果需提供海关入境货物检验检疫证明及中文标签。

**三、过程与储运证明**
1. 冷链运输温度记录，适用于需冷藏的水果。
2. 仓储和运输卫生控制说明，包括防虫害、防污染、防交叉污染措施。
3. 供应商食品安全管理制度或质量协议，明确农残超标、腐烂变质、异物混入等问题的退换货和赔偿责任。
4. 虫害控制记录、清洗消毒记录等，视供应商规模索取。

**四、批次验收凭证**
1. 每批次送货单，注明品名、产地、数量、采摘或包装日期、供应商名称。
2. 到货验收记录：感官检查（腐烂、霉变、虫害、异味）、温度、包装完整性。
3. 不合格品处理记录和退货记录。

**可执行建议**
- 建立供应商档案，一供应商一档，证照到期前提醒更新。
- 签订质量保证协议，明确检测报告提供频次、农残超标处理、追溯配合义务。
- 对高风险水果实行“合格证＋检测报告＋到货快检”组合控制；对低风险水果至少保留合格证和购货凭证。
- 保留所有凭证不少于产品保质期满后6个月；无明确保质期的，不少于2年，具体以当地监管要求为准。
- 不要仅收一次报告长期沿用，应按批次或按季度更新，并核对报告中的样品名称、日期、检测机构资质。
