# 水果到货不合格的补货约定要点

核心思路：**把“不合格后的补货”写成有时限、有标准、有替代方案的硬条款，而不是事后临时协商。** 建议在采购合同/供货协议中明确以下内容：

## 一、验收标准前置
- 按品类逐项写明验收标准：品种、规格（单果克重/直径）、成熟度、糖度（如适用）、色泽、无腐烂/虫害/机械伤、允许的瑕疵比例（例如同批次不合格率超过5%即整批可拒收）。
- 附样品或照片作为标准参照物，避免“算不算合格”扯皮。

## 二、补货时限（关键条款）
- 明确补货到达时限，例如：**验收不合格并书面/微信通知后，4小时内（或当日营业结束前）补到位**；急用品类要求2小时内。
- 写明起算点：以门店发出的通知时间为准，并保留通知记录（微信群、短信截图均有效）。

## 三、补货责任与费用
- 因质量问题补货，**运费、损耗由供应商承担**，且不得因此加价。
- 补货仍不合格的，门店有权**拒收并要求退款**，或按约扣减货款。

## 四、不断货的兜底机制
- **替代方案条款**：约定供应商无法按时补货时，门店可自行就近采购同品质水果，**差价由供应商承担**（或从货款中扣除），并保留凭证。
- **安全库存约定**：对高频核心品类（如柠檬、芒果、百香果），要求供应商保持一定备货量或允许多送10%-20%作为缓冲。

## 五、结算挂钩
- 货款按月结的，设置**质量保证金/扣款条款**：不合格批次不计入结算，或按批次金额的X%扣减。
- 连续两次补货不合格，门店有权**暂停下单或终止合作**。

## 六、操作落地
- 每次到货当场验收、拍照留证，不合格品单独存放并**当场通知供应商**，避免事后争议。
- 建立简单的到货验收记录表（日期、品类、数量、问题、通知时间、补货到达时间）。

**一句话总结**：验收标准写细 + 补货时限写死 + 自采差价由供应商兜底 + 扣款与解约权挂钩，才能真正做到“不断货、不扯皮”。
