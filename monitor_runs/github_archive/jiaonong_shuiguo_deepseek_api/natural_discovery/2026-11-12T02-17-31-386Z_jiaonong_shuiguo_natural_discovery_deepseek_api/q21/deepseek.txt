超市采购水果时，供应商通常需要提供以下证明和检测报告，具体以超市验收制度、属地监管要求和水果品类风险为准：

1. **营业执照及供货资质**
   - 供应商营业执照复印件
   - 食品经营许可证或食用农产品销售相关资质（按属地要求）
   - 若为生产企业，提供食品生产许可证；若为进口商，提供进口相关资质

2. **进货凭证和溯源材料**
   - 供货单、发票或购销合同
   - 产地证明、种植基地信息或合作社证明
   - 批次信息、采收日期、包装日期
   - 运输和贮存记录，冷链水果需冷链温度记录

3. **合格证明文件**
   - 食用农产品承诺达标合格证（很多地区对产地直销、合作社、种植户有要求）
   - 出厂检验报告或供货商自检报告
   - 批发市场销售凭证或市场快检合格记录

4. **检测报告**
   - 农药残留检测报告：通常要求有资质检测机构出具，按批次或定期提供；超市也可要求供应商提供快检记录
   - 重金属、真菌毒素等风险项目：按品类和监管要求提供，如某些浆果、柑橘等
   - 进口水果：出入境检验检疫证明、海关报关单、入境货物检验检疫证明
   - 有机、绿色、地理标志等认证水果：对应认证证书和年度检测材料

5. **包装与标签材料**
   - 预包装水果需符合标签标识要求
   - 散装水果需标明品名、产地、生产者或供货者信息、采收或包装日期等，按当地要求执行

6. **其他按风险补充**
   - 新品种、高风险品类或抽检不合格后的整改批次，可要求第三方全项检测
   - 供应商食品安全承诺书、质量保证协议
   - 不合格产品召回和处置记录

实操建议：超市应在采购合同中明确“每批随货提供供货凭证和合格证明；农残检测报告按批次或每月提供；进口水果逐批提供检验检疫证明；高风险品类增加第三方检测频次”，并在收货时核验批次、证照和报告是否对应，避免“报告与货物不一致”。
