判断香蕉批发对方是否“稳定供货”，核心看**产地控制力、蕉品分级能力、催熟与冷链、履约记录**四件事，别只看报价和朋友圈视频。给你一套可执行的判断方法：

**1. 先问清货源结构**
- 是自有/包园基地，还是常年合作代办、批发市场转手？
- 主产区能否说清：广西、云南、海南、老挝、越南、缅甸、菲律宾等，不同季节主供哪里？
- 全年哪些月份会断供、换产区？稳定供货商通常有明确“产区轮换表”，而不是只说“常年有货”。

**2. 看分级和催熟能力**
香蕉稳定供货不只是“有香蕉”，而是能持续给**同一规格、同一成熟度**的货。
- 问：每箱净重、条数/把数、单根粗度长度、青蕉成熟度、是否去蕾去轴、切口处理。
- 是否自有催熟库？催熟工艺能否按你的销售节奏分批出熟？
- 是否有腐烂率、机械伤率、黄叶率、掉把率的常规控制标准。

**3. 冷链和运输要落到细节**
- 青蕉运输温度、装车方式、通风/保温措施、到货温度谁记录。
- 到货后多久能入催熟库？夏季和冬季方案是否不同？
- 远距离发货是否有备用车、压车和延误处理方案。

**4. 用“小单连续试供”验证，而不是一次大单**
建议连续试供3—4周，每周固定规格和数量：
- 记录到货准时率、净重差异、青蕉成熟度一致性、坏果率、催熟后成品率。
- 看对方遇到天气、堵车、产地涨价时是否提前沟通，是否随意换产区、换规格、掺货。
- 稳定供应商的关键表现是：**出问题有预案，不靠临时找货救场。**

**5. 查履约和结算边界**
- 让他提供近几个月的发货记录、装车视频、合作档口或市场客户（能核实的）。
- 明确订金、账期、损耗赔付、到货验收标准、争议处理。
- 警惕：报价明显低于同产区行情、什么规格都能马上大量供、只发精修剪辑视频、不愿视频看库/装车、催你大额打款。

**最实用的判断句：**
让对方按你的包装规格和成熟度，连续给你供3周；同时要求每批可追溯产区、装车时间、催熟批次。能稳定做到，再谈长期价；做不到，报价再低也不是一手稳定货源。
