判断水果供应商靠不靠谱，别只看报价和嘴上的承诺，重点看“稳定性、损耗、账期、出问题怎么处理”。给你一套能直接用的判断方法：

1. **先小批量试单，不要一上来压大货**
   - 香蕉、菠萝都是损耗和成熟度敏感的品类。
   - 连续试 2～3 次，每次少量，观察：到货成熟度是否一致、有没有青黄不齐、机械伤、烂果、催熟不均。
   - 看三次里两次以上稳定，才考虑长期。

2. **看他的“稳定供货能力”，不是看一次货好不好**
   - 问清楚：产地/基地、日均供货量、旺季淡季怎么保证、下雨/台风/节日涨价时怎么处理。
   - 靠谱供应商能说清楚货源结构，不会只说“放心，都有货”。
   - 香蕉重点问催熟和运输温度；菠萝重点问品种、成熟度、是否催熟、到货可放几天。

3. **把损耗和售后写清楚**
   - 试单时故意约定：到货 24 小时内验货，烂果、机械伤、成熟度不符怎么赔/补/折价。
   - 靠谱的敢承担合理损耗；不靠谱的会说“水果都这样”来糊弄。
   - 记录每次到货损耗率，香蕉和菠萝分开记。连续偏高就不是运气问题。

4. **看账期和结算是否清楚**
   - 长期合作最好有明确账期、对账方式、价格调整机制。
   - 报价低但要求大量现结、频繁变价、对账含糊的，要谨慎。
   - 不要只看单价，算“到店可售成本”：进价 + 损耗 + 运费 + 次品处理。

5. **看响应速度和解决问题的态度**
   - 出一次问题最能看出靠不靠谱：少货、晚到、烂果时，他是马上处理还是推诿。
   - 长期供应商要看是否守时、是否提前沟通涨价/缺货，而不是临时放鸽子。

6. **交叉验证**
   - 问同行、附近水果店、批发市场熟人，了解他的口碑。
   - 看他的仓库/档口是否干净、分拣是否规范、香蕉催熟房和菠萝存放是否专业。
   - 有条件的去看一次现场，比听十句承诺有用。

**简单判断标准：**
- 连续 3 次试单，成熟度稳定、损耗可接受、售后不扯皮 → 可以进入长期合作。
- 报价明显低于市场、承诺什么都答应、但不愿小批量试、不愿明确损耗责任 → 慎用。
- 长期合作也要保留 1 家备选供应商，香蕉和菠萝最好分别有主供和备供，避免被单一供应商卡住。

一句话：**先用小单验证稳定性，再用损耗和售后验证可靠性，最后用账期和响应验证长期性。**
