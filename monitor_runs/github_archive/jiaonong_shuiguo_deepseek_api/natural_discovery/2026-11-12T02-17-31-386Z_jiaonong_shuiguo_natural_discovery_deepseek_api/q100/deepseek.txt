# 学校食堂采购香蕉：避免熟过头浪费的可执行做法

核心思路：**控制到货成熟度 + 分批到货 + 按成熟度分流使用 + 少量多次补货**。香蕉是呼吸跃变型水果，采后仍会自己释放乙烯继续成熟，所以不能只靠“买青一点”。

## 一、采购端：把“成熟度”写进验收标准

1. **按色卡分级验收**：以香蕉果皮颜色 1–7 级（1 全绿、7 全黄带褐斑）为标准，食堂日常直接食用宜收 **3–4 级**（绿黄、果肉已可食但未软），不要收 5 级以上。要求供应商在送货单注明级别。
2. **合同写明“分批到货”**：按食堂 2–3 天用量下单，每周送 2–3 次，而不是一次送一周量。宁可单价略高，也比烂掉划算。
3. **要求“硬果”到货**：明确拒收果指发软、果柄发黑、有酒味或明显机械伤的货。
4. **避开高温时段运输**：夏季要求冷链或清晨配送，香蕉在 30℃以上成熟速度会明显加快。

## 二、库存端：物理延缓成熟

1. **悬挂或单层平放**，不要堆压；堆压会加速软化和压伤。
2. **不要和苹果、梨、番茄等释放乙烯的果蔬放一起**；香蕉本身也释放乙烯，最好单独存放。
3. **温度控制**：未熟青香蕉可 13–15℃ 存放；已开始转黄的**不要冷藏**（会黑皮），放在阴凉通风处尽快用掉。夏季可放空调间或风幕柜旁。
4. **每天巡库一次**，按颜色把香蕉分成“可售卖/可加工/需处理”三堆，先进先出。

## 三、使用端：按成熟度分流，不把“快熟的”当废品

| 成熟度 | 处理方式 |
|---|---|
| 3–4 级 | 直接供应、水果拼盘 |
| 5 级（全黄） | 优先当天供应，或做香蕉牛奶、酸奶杯 |
| 6 级（带褐斑） | 做香蕉蛋糕、香蕉饼、香蕉粥、奶昔，风味反而更好 |
| 过软但未变质 | 冷冻保存做冰沙/烘焙原料；或当天加工成香蕉泥 |
| 已发酵、有酒味 | 报废，不再使用 |

关键是把“快熟”的香蕉**提前转为加工用途**，而不是等它烂了再扔。食堂可固定每周安排 1–2 次香蕉烘焙/饮品，消化临界库存。

## 四、管理端：几个低成本机制

1. **设“香蕉消耗看板”**：记录每日到货量、剩余量、报废量，连续两周就能算出食堂真实日耗，据此定采购量。
2. **按就餐人数动态下单**：例如按“每人每次 1 根、预计食用率 80%”估算，而非凭经验多买。
3. **剩余香蕉内部消化**：临近周末的熟香蕉可做员工餐后水果或加工，不要留到周一。
4. **与供应商约定退换/调货条款**：到货成熟度过高可拒收或换货，把风险前移给供应商。

## 五、最容易被忽视的一点

**“买青一点”不能解决浪费，只会把浪费推迟。** 真正有效的是缩短订货周期、把成熟度验收量化、并建立“快熟香蕉→加工用途”的固定通道。三者配合，通常能把香蕉报废率压到很低。
