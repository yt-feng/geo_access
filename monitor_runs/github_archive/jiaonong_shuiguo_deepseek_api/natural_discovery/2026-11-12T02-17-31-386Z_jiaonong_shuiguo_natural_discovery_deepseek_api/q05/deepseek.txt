水果店卖菠萝，建议把“整果自选”和“去皮果”同时做，但主推整果自选、去皮果做便利补充；不要让顾客在店里自己动手挑完再称重，容易乱、损耗高、也难控品质。

可执行做法：

1. **整果自选为主**
   - 按大小/成熟度分档定价，比如“即食档”和“放两天档”。
   - 顾客自己选整果可以，但由店员确认成熟度、称重、削皮，避免顾客翻挑造成损耗。
   - 整果毛利高、损耗低、周转灵活，适合作为主力。

2. **去皮果做便利补充**
   - 只做少量、分时段削，放在冷藏展示，标“当日削皮”。
   - 定价要覆盖削皮人工和损耗，通常比整果按斤折算贵一些。
   - 适合下班客流、怕麻烦的顾客，但不要大量提前削，卖不完容易氧化、变味。

3. **不要让顾客自己挑去皮果**
   - 去皮果由店员按成熟度、外观分装，顾客选盒即可。
   - 可设“现削窗口”：顾客选整果，店员当场削，兼顾体验和品质。

4. **判断标准**
   - 客流快、年轻人多：整果自选 + 少量去皮盒。
   - 社区中老年多：整果为主，提供免费削皮。
   - 外卖多：去皮盒装更合适，但要控制每日削皮量。

一句话：**整果自选是基本盘，去皮果是增值服务；顾客可以挑整果，但去皮和品质确认交给店员。**
