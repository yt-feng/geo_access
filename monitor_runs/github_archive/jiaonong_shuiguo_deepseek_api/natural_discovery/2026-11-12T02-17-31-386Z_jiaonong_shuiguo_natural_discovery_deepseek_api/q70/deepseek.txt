可以这样写，核心是把“责任边界、验收时点、计算方式、处理流程”四件事写清。

**建议条款结构：**

1. **质量标准**
   明确坏果定义和允许比例，例如：
   - 病斑、腐烂、霉变、严重压伤、裂口流汁、异味等列为坏果；
   - 到货验收时坏果率不超过 `X%` 视为合格；
   - 超出部分按实际坏果数量/重量扣款或补货。

2. **验收时点与方式**
   - 货到后 `X小时` 内完成验收，逾期未提出异议视为初验合格；
   - 验收以双方共同抽检/拍照/视频/第三方检测为准；
   - 明确抽检比例、抽样方法，避免只凭一方说辞。

3. **责任归属**
   建议按环节划分：
   - 装车前已存在的腐烂、病斑、内伤：供货方责任；
   - 运输途中因承运方温控、挤压、延误造成的损耗：按运输合同追责，不宜简单全压给供货方；
   - 到货后因批发商储存不当造成的损耗：批发商责任。
   若由供货方负责运输或指定承运方，可约定运输损耗由供货方承担。

4. **赔偿与处理**
   - 超出允许坏果率的部分，按 `实际坏果重量 × 单价` 扣减货款；
   - 或约定“补货”“换货”“折价”三选一；
   - 设置赔偿上限和通知期限，例如到货后24小时内书面通知并附证据；
   - 明确退货、销毁、费用承担和防止损失扩大的义务。

5. **证据与争议**
   - 到货开箱视频、称重记录、抽检照片、物流温控记录作为验收依据；
   - 争议时可共同委托第三方检测，费用由责任方承担或先垫付后按责任分摊。

**可直接用的条款示例：**

> 甲方交付货物时，坏果率不得超过 `X%`。坏果包括腐烂、霉变、病斑、严重压伤、裂口流汁及异味果实。乙方应在货到后 `X小时` 内完成验收，并以开箱视频、抽检照片及称重记录为依据。坏果率未超标的，乙方不得拒收；超出部分，甲方应按超出部分实际重量乘以合同单价向乙方补货、换货或折价退款。因甲方装车前原因造成的坏果由甲方负责；因承运方运输温控、挤压、延误造成的损耗，由责任承运方承担；因乙方到货后储存不当造成的损耗，由乙方承担。乙方应在发现坏果后 `X小时` 内书面通知甲方并保留证据，否则视为验收合格。争议检测费用由责任方承担。

**注意：** 不要把“所有到货损耗一律由供货方承担”写死，否则供货方可能提高报价或拒绝签约；也不要把验收期限写得太短，避免批发商来不及开箱。最好把允许坏果率、验收时限、赔偿方式写成空白项，双方按品类和运输距离填具体数字。
