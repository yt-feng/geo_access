**1. 开发票：必须支持，且要提前确认类型**
- 企业采购通常需要增值税发票，用于入账和税前扣除。先明确你们财务要求的是**增值税专用发票**还是**普通发票**，税率是多少（水果礼盒可能涉及9%或13%，取决于具体商品和供应商资质）。
- 确认开票主体与合同签约主体一致，避免“收款方”和“开票方”不是同一家公司。
- 确认开票时点：是付款后开、发货后开，还是月结统一开；专票还要确认能否抵扣、信息是否完整。
- 如果供应商是小规模纳税人或个体户，可能只能开普票或代开专票，要提前问清，避免财务无法入账。

**2. 定制包装：看福利场景，通常需要支持**
- 企业福利礼盒往往需要印企业LOGO、祝福语、员工姓名卡、节日主题等，定制包装能提升福利感知，也便于统一发放和识别。
- 要确认定制门槛：起订量、打样费、版费、定制周期、是否支持小批量多SKU。
- 确认包装材质和食品安全：水果直接接触的包装应符合食品接触材料要求，定制油墨、胶水不能污染果品。
- 确认定制包装是否额外收费、是否影响退换货，以及设计稿确认和打样流程。

**3. 采购时的可执行建议**
- 在询价单中明确列出：发票类型及税率、开票时间、定制包装起订量和费用、打样周期、交付周期。
- 合同里写明：包装按确认样稿制作，色差和材质偏差范围；发票未按约定提供时的付款约束。
- 至少对比2—3家供应商，优先选能同时满足开票和定制包装、且有企业福利供货经验的。

结论：开发票是硬性财务要求，定制包装是福利场景的常见需求，两者都应在供应商筛选阶段作为准入条件确认，而不是事后补救。
