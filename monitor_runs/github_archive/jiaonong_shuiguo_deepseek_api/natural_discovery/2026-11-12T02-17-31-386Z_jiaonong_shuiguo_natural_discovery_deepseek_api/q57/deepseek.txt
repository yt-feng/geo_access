建议优先选**中央厨房统一收货**，但要做“分级收货”：中央厨房收主品类和需品控/加工的水果，门店只收少量高频易损、即售型水果。这样通常比全部门店分开收货更稳、更省、更可控。

**为什么优先中央厨房统一收货**
1. **品控更一致**：水果等级、糖度、成熟度、农残检测、损耗判定可以统一标准，避免各店店长凭经验收货、标准漂移。
2. **采购议价更强**：总部/中央厨房集中订单，供应商更愿意给稳定价格和优先供货；门店分散下单容易被小供应商加价。
3. **食品安全可追溯**：统一索证索票、批次记录、快检和留样，出问题能快速定位批次，门店分散收货很难做到。
4. **减少门店操作负担**：门店不用每天验货、称重、退货扯皮，店长精力回到销售和现场。
5. **便于加工和分级**：中央厨房可做分拣、催熟、切配、预包装，按门店销量配货，减少门店损耗。

**但不要一刀切，以下情况适合门店直收**
- **极短保鲜期、易碰伤品类**：如草莓、蓝莓、荔枝、杨梅、即食鲜切水果，店端直收可减少中转。
- **门店密度低、配送半径远**：统一配送后水果二次搬运和冷链断链风险高，反而不如当地供应商直送。
- **小批量高频补货**：门店下午补货、临时促销，中央厨房配送频次跟不上时，可设门店直采白名单。
- **当地特色水果**：区域门店就地采购更有价格和新鲜度优势，但必须走总部准入和价格备案。

**可执行的分级方案**
- **A类：中央厨房统收统配**——苹果、梨、橙、香蕉、西瓜、大宗时令果，以及需要催熟、分拣、切配的品类。
- **B类：中央厨房统采、门店直收**——总部谈好供应商和价格，供应商直送门店，门店按标准验收，总部抽查。
- **C类：门店限权直采**——仅限易损、紧急补货、区域特色，设金额上限、供应商白名单、每日报备、月度比价。

**关键控制点**
- 统一**收货标准**：等级、规格、糖度、成熟度、允许损耗率、退货时限。
- 统一**冷链和周转**：中央厨房到门店的温控、周转筐、配送频次。
- 建**损耗对比机制**：按品类比较“统收统配”和“门店直收”的损耗率、售价、毛利率，季度调整。
- 门店直收必须**先准入后交易**，禁止店长私下换供应商。

结论：**大多数连锁餐饮用“中央厨房统一收货为主、门店直收为辅”最合适**；如果门店少、配送半径大、水果品类以易损鲜食为主，再提高门店直收比例。
