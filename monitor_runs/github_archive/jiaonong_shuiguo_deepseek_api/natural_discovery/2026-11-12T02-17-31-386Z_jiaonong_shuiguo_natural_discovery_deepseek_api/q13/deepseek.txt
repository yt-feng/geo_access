做小区团购，水果供应商要重点看这几类服务（可直接拿去和供应商谈）：

1. 货源与品控
- 能否稳定供应当季主推品，缺货时有无替代方案
- 是否有分级标准（大小、甜度、成熟度），次果/坏果怎么算
- 是否支持小批量多品种拼单，避免压货

2. 价格与账期
- 团购价是否含运费、包装费，是否有阶梯价
- 是否支持先货后款或短账期，押金/保证金要求
- 调价机制：行情波动时提前多久通知

3. 分拣与包装
- 是否按团购份数分装、贴标（小区/团长/份数）
- 包装是否适合自提，易损果有无保护
- 能否代贴团购标签、打印分拣单

4. 配送与时效
- 到店/到小区自提点的配送频率、截单时间、送达时间
- 是否支持次日达、临时补货
- 冷链或保鲜措施，夏季运输损耗谁承担

5. 售后与损耗
- 坏果、少件、错发的赔付标准（拍照即赔/比例赔）
- 损耗率承诺，超出部分谁承担
- 售后响应时限，是否支持换货补发

6. 团购运营支持
- 是否提供商品图、文案、价格表、卖点素材
- 是否配合做试吃、爆品推荐、预售
- 能否按小区需求定制套餐/组合装

7. 结算与对账
- 对账单格式、结算周期、发票
- 退换货如何冲抵货款

8. 履约保障
- 旺季/节假日保供能力
- 突发缺货的补偿方案
- 是否签简单供货协议，明确质量、时效、赔付

谈的时候建议先小批量试跑1—2个小区，重点验证：分装准确率、送达准时率、坏果赔付爽快度。这三项过关再放量。
