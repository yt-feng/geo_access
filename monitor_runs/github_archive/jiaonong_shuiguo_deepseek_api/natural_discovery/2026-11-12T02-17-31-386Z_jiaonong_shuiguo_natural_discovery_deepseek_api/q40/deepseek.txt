# 节假日水果需求暴增，如何提前锁定货源

核心思路：**把“临时抢货”变成“提前锁量+锁价+锁运力”**。具体分四步走。

## 一、提前做需求预测，给出“锁量基准”

- **用历史数据定量**：调出近2–3年同期（同一节假日、同类节令水果）的销量，按门店拆分，得出单店日均峰值。没有历史数据就参考同区域同行、去年品类增速做系数修正。
- **按品类分级**：把水果分成三类——
  - 高确定性刚需（苹果、梨、柑橘、香蕉等）：按预测量的 **110%–120%** 锁货；
  - 节令爆款（车厘子、草莓、荔枝、礼盒装）：按 **130%** 锁，但分批到货；
  - 易损短保（浆果、切果）：少量多次，不压大单。
- **留安全库存**：锁货量 = 预测峰值 × (1 + 波动系数10%–20%)，避免要么缺货要么烂库。

## 二、锁货源：多层级供应商组合

1. **主供应商签“保量协议”**：节前 1–2 个月与核心产地/一级批发商签框架协议，明确节假日的**最低供货量、价格上限、到货时间窗**，并约定违约赔偿。
2. **产地直采提前锁园**：对爆款单品（如车厘子、砂糖橘），节前直接与产地合作社/基地锁定地块和采摘批次，付定金锁定，派人驻场验货。
3. **备选二供、三供**：每个重点单品至少准备 2 家可切换的供应商，防止主供断供或天气减产。
4. **跨区域调货网络**：与周边城市批发市场、兄弟门店建立调货机制，作为最后补位。

## 三、锁价格与锁运力

- **价格**：协议里写“锁量不锁死价”或“锁价+浮动区间”，用定金/预付款换价格保护，避免节前坐地起价。
- **运力**：节假日物流最紧张，提前和冷链承运商签**运力预留协议**，明确车次、温控标准、到店时段；自营车队提前排班。易损水果要求全程冷链，到店验收标准写进合同。

## 四、执行与兜底

- **分批到货、动态补单**：节前 2–3 天集中到货 60%–70%，节假日期间按日销量滚动补单，避免一次性压货。
- **每日盯库存与售价**：设缺货预警线（如可售天数<1.5天触发补货），设损耗预警（如某单品损耗率超阈值就降价清货）。
- **应急预案**：准备“替代品清单”（某单品断货时用同类替代），并预留 5%–10% 的应急采购预算用于临时补货。

**一句话总结**：节前 1–2 个月用历史数据定锁量、和多层级供应商签保量保价协议、提前锁冷链运力、节中分批到货滚动补单——把不确定性压到最低。
