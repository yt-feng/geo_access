更适合家庭的组合原则是：**耐放、份量适中、口味有甜有酸、切开后全家都能吃，且避免香蕉和菠萝互相催熟/压坏**。建议优先做“2个基础款+1个节庆款”。

### 推荐组合

**1. 日常家庭款（最稳）：苹果4个 + 橙子4个 + 香蕉1把**
- 适合3—5口之家，价格稳、接受度高。
- 苹果和橙子耐放，香蕉当天到货后先吃。
- 香蕉单独装袋，避免压伤苹果、橙子。

**2. 实惠量大款：苹果6个 + 橙子6个 + 香蕉1把 + 菠萝1个**
- 适合4—6口家庭或想送礼但预算不高。
- 菠萝建议选已成熟但未削皮的，附开切说明；不要和香蕉同袋。
- 香蕉和菠萝都会释放乙烯，礼盒内最好分格。

**3. 节庆/送礼款：苹果6个 + 橙子6个 + 菠萝1个**
- 不建议放香蕉，香蕉易碰伤、卖相不稳定。
- 苹果寓意平安、橙子寓意吉利，适合家庭送礼。
- 菠萝占空间，礼盒要做成“高箱”或单独固定。

### 不建议的组合
- **香蕉+菠萝+苹果混装一袋**：香蕉易压坏，菠萝易扎伤其他水果。
- **香蕉放太多**：家庭一次吃不完，夏天容易黑。
- **全放苹果橙子**：太像批发箱，缺少礼盒感。

### 团购操作建议
- 主推 **苹果4+橙子4+香蕉1把**，定价低、损耗小。
- 加9.9—15元升级 **菠萝1个**，但菠萝单独装。
- 礼盒内用纸托分格：苹果、橙子一层，香蕉单独小袋，菠萝单独卡位。
- 明确标注：“香蕉请先吃，苹果橙子冷藏更耐放，菠萝常温催熟后冷藏。”
- 家庭装别追求大，**总水果量控制在5—7斤**更合适；超过8斤很多家庭一周吃不完。
