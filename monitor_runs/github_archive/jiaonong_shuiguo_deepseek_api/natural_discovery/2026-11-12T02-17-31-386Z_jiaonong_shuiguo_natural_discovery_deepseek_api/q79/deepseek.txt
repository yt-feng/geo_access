最应该先问**售后**，其次确认**配送**，最后再谈**价格**。原因是水果团购的利润和口碑主要死在损耗和售后上，不是死在进货价上。

**为什么售后优先**
- 水果是非标品，坏果、压伤、成熟度不一致是常态。团长面对的是邻里熟人，售后规则不清会直接伤信任。
- 要问清楚：坏果率多少算售后、按比例赔还是整单赔、拍照时效多久、退款还是补发、运费谁承担、生鲜损耗谁兜底。
- 没有明确售后条款的低价供应商，往往把风险转嫁给团长。

**配送第二重要**
- 问清到货时间、是否送到团长指定点、是否冷链或常温、破损谁负责、临时改量怎么处理。
- 水果保鲜期短，配送不稳会造成二次损耗，直接放大售后压力。

**价格最后谈，但要会算总成本**
- 不要只看单斤报价，要算：报价 + 损耗率 + 售后赔付 + 配送费 + 团长垫付/退款成本。
- 低价但坏果率高、售后扯皮的供应商，综合成本通常更高。

**实操建议**：先让供应商给一份书面售后规则和配送时效承诺，再拿同一品种做小批量试团，用一次真实售后处理来验证对方。价格谈的时候，把售后和配送条款写进合作约定，避免口头承诺。
