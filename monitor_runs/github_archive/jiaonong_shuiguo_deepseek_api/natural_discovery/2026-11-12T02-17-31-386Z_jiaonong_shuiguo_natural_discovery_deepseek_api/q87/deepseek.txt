社区团购旺季锁水果库存，核心不是“提前打招呼”，而是把**预测、合约、订金、分批次提货、违约条款和替代方案**绑在一起。可以按下面做：

1. **先做可承诺的销量预测**
   - 按单品、到货日、仓/团点拆分未来2—4周需求，不要只给供应商一个总量。
   - 用近2—4周销量、去年同期、活动排期、复购率做基准，再设“保底量/目标量/冲刺量”三档。
   - 水果损耗高，预测宁可按“保底量”锁，不要一次性把冲刺量全压给供应商。

2. **提前签短周期锁量协议**
   - 明确：品名、规格、等级、产地、糖度/果径等验收标准、单价或计价公式、锁量数量、到货窗口、分批次提货计划。
   - 约定价格调整机制：如遇产地大幅涨跌，按约定区间协商，避免供应商旺季毁约。
   - 锁量不等于锁价时，要写清楚“量优先、价随行”还是“价量同锁”。

3. **用订金/预付款换优先级**
   - 对核心单品支付10%—30%订金，换取供应商“优先供货权”和“缺货时优先保供”。
   - 订金绑定违约条款：供应商未按量供货的赔偿、平台未按量提货的订金处理，都要写清。
   - 大额预付款要控制比例，最好分批支付、与到货验收挂钩。

4. **分批次锁货，不要一次锁死**
   - 第1批锁未来7—10天，第2批锁15—20天，第3批用框架协议锁“产能优先级”。
   - 每周根据实际销量滚动补锁，降低预测偏差和损耗风险。
   - 对易损水果，优先锁“采摘/分拣产能”和“冷链车位”，而不只是锁货量。

5. **要求供应商给“保供+替代”方案**
   - 核心单品至少准备1—2个备选产地或备选供应商。
   - 协议里约定等级替代规则：如一级果不足，二级果按什么价补，避免临时断供。
   - 旺季前确认供应商的冷库、分拣线、包装材料和物流车辆是否已预留。

6. **把验收和损耗责任前置**
   - 到货前抽检、到货后按标准验收；明确坏果率、短斤少两、延迟到货的扣款或补货规则。
   - 水果非标品，建议约定“到货合格率”和“损耗上限”，否则锁了库存也可能锁到低质量货。

7. **用“保底+激励”稳住供应商**
   - 承诺旺季保底采购量，完成后再给阶梯返利或优先结算。
   - 对配合度高的供应商缩短账期、提高预付款比例，换取旺季优先排产。
   - 不要只压价，旺季供应商更愿意把货留给结算稳、履约确定的客户。

8. **内部留安全库存和应急预算**
   - 对爆款水果留3—5天安全库存，对易腐品留1—2天。
   - 准备应急采购预算和临时调拨方案，避免单一供应商失约导致团点缺货。

一句话：**用“保底量+订金+分批提货+违约条款+备选供应商”锁库存，而不是只靠口头约定。** 优先锁核心爆品和易缺货产地，非核心品用框架协议保留弹性。
