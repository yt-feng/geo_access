# 超市水果到货品相不好的售后流程约定

建议在采购合同或供货协议中把"到货验收—报损—退换—扣款"四段写清楚，核心是把"品相不好"变成可判断的标准，避免事后扯皮。

## 一、先约定验收标准和时限

1. **明确品相标准**：按品类写清可接受范围，例如：
   - 外观：无明显腐烂、霉变、机械伤、裂口；单果瑕疵面积不超过X%；
   - 规格：单果重量/直径区间、成熟度（如七成熟以上）；
   - 新鲜度：无异味、无萎蔫、无冻伤。
   建议附**图片或样品封样**作为参照，比文字更少争议。
2. **验收时限**：到货后当场或X小时内（如4小时）完成抽检；抽检比例（如每批次抽检10%或按箱抽检）。逾期未提异议视为验收合格——这条对超市有利，但要给供应商合理验货时间。
3. **验收方式**：开箱抽检、拍照留证（含批次、箱号、时间），双方签字确认验收单。

## 二、约定不合格的处理方式

按问题程度分档，别只写"可退换"：

| 情形 | 处理方式 |
|---|---|
| 整批严重不合格（腐烂、霉变超比例） | 整批拒收或退货，运费由供应商承担 |
| 部分不合格（瑕疵率在约定区间内） | 按比例折价、换货，或超市挑拣后按实际合格数量结算 |
| 轻微品相问题不影响销售 | 协商降价处理，写明折价比例 |

同时约定**换货时限**（如24小时内补货）和**退货退款时限**（如验收后3个工作日内）。

## 三、约定责任与费用

- 退换货运费、装卸费由责任方承担（供应商原因则供应商承担）；
- 因品相问题导致的损耗、降价销售差额，可从货款中直接扣减，写明扣款依据（验收单+照片）；
- 设置**质量保证金或账期扣款机制**，便于执行扣款，避免供应商拖着不认。

## 四、约定争议解决和证据

- 争议以**验收单、抽检照片/视频、封样样品**为准；
- 生鲜易腐，约定"先处理货物、后结算争议"，避免水果烂在库里扩大损失；
- 明确对接人和响应时限（如供应商2小时内回复）。

## 五、落地建议

1. 把上述内容做成**一页纸的《到货验收与售后细则》**作为合同附件，按品类填参数；
2. 验收单模板固定字段：批次、到货时间、抽检数量、不合格数量、瑕疵类型、照片编号、双方签字；
3. 首次合作先小批量试单，跑一遍流程再放量。

一句话原则：**标准可量化、时限可执行、扣款有依据、证据留得住。**
