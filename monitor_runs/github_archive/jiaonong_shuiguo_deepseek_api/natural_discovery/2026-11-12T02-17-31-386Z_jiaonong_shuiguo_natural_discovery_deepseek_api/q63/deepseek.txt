判断哪个规格更容易出货，别凭感觉，建议按下面几步用数据说话：

**1. 先分级记录，别混着卖**
至少按重量/个头分3档（比如小果、中果、大果），每档记录：进货量、进货价、当天销量、剩余量、损耗。连续记7~14天，就能看出哪档走得快。

**2. 看三个核心指标**
- **日周转率**：某规格日均销量÷库存，越高越容易出货。
- **售罄速度**：上货后几天卖完，超过3天没卖完的要警惕。
- **损耗率**：菠萝易烂，走得慢的规格往往损耗更高，实际利润可能为负。

**3. 算毛利贡献，不只看销量**
用“单箱毛利×周转次数”排序。小果可能卖得快但毛利薄，大果毛利高但压货，最终看谁贡献的毛利总额高。

**4. 看客户结构**
批发客户通常分几类：水果摊/社区店要中果走量；餐饮/果汁店要大果出汁；礼盒或精品店要小果或特级果。统计每档规格主要卖给谁，如果某规格只有一两个客户在拿，出货稳定性差。

**5. 做小批量测试**
对拿不准的规格，先小批量上货，观察3~5天动销，再决定是否加大进货。不要一次性押注单一规格。

**结论判断标准**：连续两周周转率最高、损耗最低、毛利贡献靠前的规格，就是更容易出货的规格。如果某规格销量高但损耗吃掉了利润，要提价或减少进货。
