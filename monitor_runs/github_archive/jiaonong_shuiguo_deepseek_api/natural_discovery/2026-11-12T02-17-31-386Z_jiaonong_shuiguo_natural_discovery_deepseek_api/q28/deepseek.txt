建议先从**香蕉**试，其次菠萝；苹果不建议作为“进口水果”切入点。

理由很直接：

1. **香蕉：最适合先跑通进口供应链**
   - 需求稳定、周转快，消费者对进口香蕉接受度高。
   - 标准化程度高，分级、催熟、损耗管理相对成熟。
   - 适合先验证：报关/口岸、冷链、催熟库、门店周转、损耗控制。
   - 风险点：催熟和温控要求高，必须确认供应商能提供稳定催熟方案和到店成熟度标准。

2. **菠萝：可作为第二梯队**
   - 进口菠萝有差异化卖点，客单价和毛利通常比香蕉好。
   - 但损耗、成熟度、品种接受度、季节波动更明显，需要更强的门店陈列和试吃推广。
   - 适合在香蕉跑通冷链和订货节奏后引入，先小批量、多频次。

3. **苹果：不建议先做进口**
   - 国产苹果供应充足、价格有优势、消费者认知强，进口苹果差异化不足。
   - 进口苹果周转慢、库存压力大，容易变成高损耗或低动销品。
   - 除非有明确高端客群和稳定礼盒渠道，否则不建议作为进口水果首品。

**可执行建议：**
- 第一步：选1—2家能稳定供货的进口香蕉供应商，先做4周小规模试销。
- 关键指标：到店成熟度合格率、周损耗率、日均销量、缺货率、毛利。
- 试销通过后再引入菠萝，按“小批量、高频补货”做2周测试。
- 苹果暂缓，等进口水果客群和动销数据稳定后再评估。

一句话：**先香蕉跑供应链，再菠萝做差异化，苹果最后看客群。**
