先给结论：坏果责任不能一概而论，通常按“坏果发生在哪个环节、哪一方控制风险、是否有约定”来划分。实操上建议先赔付顾客、再按证据向责任方追偿，避免把消费者拖进平台、商家、物流之间的扯皮。

**一、按环节划分**

1. **采摘/分拣/包装环节（供应商或商家责任）**
   - 到货即有腐烂、霉变、明显压伤、成熟度过高、未做防撞/防潮包装。
   - 责任方：供货商、产地采购方或商家自营分拣团队。
   - 判断点：同批次是否普遍坏果、包装是否符合水果品类要求、发货前有无质检记录。

2. **仓储环节（商家/仓库责任）**
   - 入库后未按温湿度要求储存、先进先出执行不到位、积压导致过期变质。
   - 责任方：商家或仓配服务商。
   - 判断点：入库时间、库温记录、库存周转记录。

3. **干线/末端配送环节（物流或平台配送责任）**
   - 运输超时、冷链断链、暴力分拣、高温暴晒、未按约定时效送达。
   - 责任方：承运物流、平台配送方；商家若自行选择物流且未保价/未约定，也可能先对顾客承担。
   - 判断点：物流轨迹、温控记录、签收时间、外包装破损照片。

4. **顾客签收后环节（顾客责任或协商分担）**
   - 签收后长时间未取、未冷藏、自行磕碰导致坏果。
   - 责任方：顾客；但商家需证明“签收时完好”或“坏果由签收后保管不当造成”，否则仍可能承担售后。

5. **不可归责或约定不明**
   - 生鲜自然损耗、轻微外观差异、未约定验收标准。
   - 处理：按平台规则、行业惯例和公平原则协商；商家不能简单以“生鲜不退不换”免责，尤其存在明显质量问题或误导宣传时。

**二、对顾客的责任先看合同和平台规则**

- 顾客在平台下单，通常先由**销售者/平台内商家**对顾客承担质量责任；平台自营则由平台承担。
- 商家赔付后，再依据供货合同、物流合同向供应商或物流追偿。
- 若平台规则承诺“坏果包赔”“签收后24小时内拍照理赔”，按规则执行；规则不能排除消费者法定权利。
- 消费者需保留：坏果照片/视频、外包装、快递面单、签收时间、与客服沟通记录。

**三、商家内部追责建议**

- 建立到货验收标准：品类、成熟度、磕碰率、腐烂率阈值。
- 每批留样并记录：供货商、批次、采摘/发货时间、包装方式、温控记录。
- 物流合同明确：时效、温控、破损赔付、举证责任。
- 售后按“先赔顾客、后定责”处理，设置小额快速赔付阈值，避免争议升级。
- 对重复出现坏果的供应商或物流商，按批次扣款、减少采购或更换承运商。

**四、一句话判断**

**坏果在签收前已发生且非顾客原因，商家/平台先对顾客负责；内部再按“供货、仓储、配送”环节证据追责。顾客签收后因保管不当造成的，顾客承担；双方都有过错的，按过错程度分担。**
