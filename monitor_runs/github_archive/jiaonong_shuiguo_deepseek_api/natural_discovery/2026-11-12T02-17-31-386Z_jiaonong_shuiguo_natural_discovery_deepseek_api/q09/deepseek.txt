旺季水果店最怕的不是“没货”，而是**临时没对路的货、价格被抬、品质掉档、送货迟到**。和供应商谈合作，重点把下面几类问题提前问清并落到书面/微信确认。

**1. 供货能力与优先级**
- 旺季每天/每周能稳定给我多少量？最小起订量多少？
- 我这类店在你客户里排什么优先级？断货时先保谁？
- 有没有备用产地/备用仓库？主产区受灾或涨价时怎么补？
- 哪些单品旺季容易缺，提前多久锁量？

**2. 价格与调价机制**
- 报价是到场价还是产地价？含不含运费、装卸、损耗？
- 旺季价格怎么调？提前几天通知？我锁价能锁多久、锁量多少？
- 同一单品不同等级怎么分价？次果、小果怎么算？
- 有没有返点、满额优惠、淡季支持？账期还是现结？

**3. 品质标准与验收**
- 按什么等级标准发货？糖度、个头、成熟度、外观有无明确标准？
- 允许的损耗率/次果率是多少？超出怎么赔、怎么补？
- 到店验收发现坏果、压伤、规格不符，多久内可退换？运费谁承担？
- 能不能先寄样品或小批量试发？试发不合格怎么处理？

**4. 配送与时效**
- 每天几点前下单、几点到店？旺季能不能加急/加频次？
- 送货迟到导致断档，有没有补偿或应急补货？
- 运输方式、冷链条件、包装规格是什么？破损谁负责？
- 节假日和极端天气怎么安排？

**5. 结算与风险**
- 结算周期、押金、账期、发票怎么定？
- 质量问题、缺货、临时涨价的责任怎么划分？
- 合作期限多久？旺季中途能不能单方面停供或涨价？
- 有没有书面合同或至少微信文字确认关键条款？

**6. 退换与售后**
- 滞销品能不能调换？临期果怎么处理？
- 售后响应时间多长？对接人是谁、电话是否24小时可通？

**谈判建议：** 先小批量试供1—2周，重点看**到货准时率、损耗率、规格稳定性和临时补货能力**；再把旺季保供量、锁价周期、损耗赔付、迟到补偿写进合作确认。不要只谈单价，旺季真正决定利润的是**稳定供货+品质一致+售后兜底**。
