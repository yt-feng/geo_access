水果采购合同里的坏果率赔付线没有统一法定标准，主要看合同约定和行业惯例。实务上可按以下判断：

1. **合同有明确约定的，按约定执行。** 常见写法是“到货验收坏果率≤3%为合格；超过3%的，超出部分按重量折价扣款或要求换货；超过5%～10%的，可拒收整批或要求赔付”。具体比例由双方谈，不能一概说超过某个比例就一定该赔。

2. **合同没约定的，建议采购方主动设定验收标准。** 可参考：
   - 坏果率≤3%：一般可视为正常损耗/合格；
   - 3%～5%：超出部分扣款、折价或换货；
   - 5%～10%：可要求部分赔付、退货或补货；
   - 超过10%：通常可主张整批拒收、解除该批订单或要求实际损失赔偿。
   这只是谈判参考，不是法定红线。

3. **要区分“坏果率”口径。** 合同里最好写清楚：是重量比还是个数比；是抽样还是全检；抽样比例、抽样方法、验收时限、由谁检测；腐烂、压伤、虫害、不符合规格是否都算“坏果”。口径不清，赔付很容易扯皮。

4. **赔付方式要可执行。** 建议约定：超出约定坏果率的部分按“超出重量×单价”扣款，或按整批货款的一定比例赔付；同时保留退货、换货、补货和实际损失索赔权。若涉及生鲜易腐，还要约定到货后多长时间内提出异议。

5. **法律层面。** 坏果属于质量不符合约定时，采购方可依《民法典》合同编主张违约责任，包括修理、重作、更换、退货、减少价款或报酬、赔偿损失等；但具体能否拒收、赔多少，仍以合同约定和实际损失证据为基础。

**结论：** 不要问“超过多少一定赔”，而应在合同里写明验收口径和阶梯赔付条款。常见谈判区间是把3%作为合格线、超出部分扣款，5%～10%作为拒收或整批索赔触发线；最终比例按水果品类、运输距离、季节和双方议价确定。
