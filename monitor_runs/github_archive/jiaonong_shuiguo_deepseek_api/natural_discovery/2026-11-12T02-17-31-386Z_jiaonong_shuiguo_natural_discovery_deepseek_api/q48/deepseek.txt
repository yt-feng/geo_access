判断菠萝供应商能不能稳定按规格送货，重点不是看一次样品，而是看“规格定义 + 到货波动 + 供应能力 + 违约约束”。可按下面做。

**1. 先把规格写成可验收标准**
不要只写“新鲜菠萝”“中果”。至少明确：
- 品种/产地：如金钻凤梨、巴厘菠萝等，产地是否可固定。
- 单果重量区间：如1.2–1.5kg，允许±5%或明确上下限。
- 成熟度/糖度：如糖度≥14°Brix，到货成熟度几成，是否允许后熟。
- 外观：无腐烂、黑心、裂口、机械伤、药斑，冠芽保留长度。
- 加工适配：出肉率、果眼深度、纤维感、是否适合切丁/榨汁。
- 包装与温控：箱规、每箱个数、托盘/冷链要求、到货温度。
- 验收抽样：每批抽几箱、每箱抽几个，不合格判定和扣款/退货规则。

**2. 用连续到货数据判断稳定性**
不要只看首批。要求供应商连续供3–5批小批量试单，记录：
- 单果重量合格率；
- 糖度合格率；
- 腐烂/黑心/机械伤比例；
- 实际到货时间与承诺时间偏差；
- 每批数量短缺率；
- 出肉率波动。
建议设定门槛，例如：重量合格率≥95%、腐烂率≤2%、到货准时率≥95%，连续3批达标再放量。

**3. 考察供应能力而不是口头承诺**
- 问清自有基地、合作基地、代办/批发市场采购占比。纯市场调货的供应商，规格和价格波动更大。
- 问产季：主产季、尾季、雨季的供应方案，是否有多产地替补。
- 看日/周供货上限，以及同时服务多少家客户，节假日高峰能否保供。
- 要求提供过去1–2个月同规格客户的发货记录或批次检测记录，能提供再谈。
- 最好实地看分选线、冷库、包装场地和原料库存。

**4. 用小批量压力测试**
- 连续下3–5个小单，故意覆盖不同到货日，观察是否每批都按规格。
- 下一单“增量单”，看其能否在短时间内补货。
- 抽查不同箱内、箱与箱之间的差异，防止“上层好果、下层次果”。
- 记录异常后供应商的补货、换货、赔付响应速度。

**5. 合同里写清稳定供货约束**
- 规格、抽样方法、合格率、退货/扣款标准。
- 准时率与短溢装比例。
- 质量异常时的补货时限和费用承担。
- 价格调整机制：按产季/市场波动设区间，避免随意涨价。
- 最低供货承诺与旺季优先供货条款。
- 连续不合格的淘汰/降量条款。

**6. 做供应商评分卡**
每批按“规格合格率、腐烂率、准时率、数量准确率、异常响应”打分，月度排名。稳定供应商不是一次验厂决定的，而是连续批次数据筛出来的。建议先小批量试供，达标后再签季度框架、逐步放量，并保留第二供应商做备份。

一句话：**规格可验收、连续批次可量化、产季保供有方案、合同有违约成本**，四项都过，才能判断其能稳定按规格送货。
