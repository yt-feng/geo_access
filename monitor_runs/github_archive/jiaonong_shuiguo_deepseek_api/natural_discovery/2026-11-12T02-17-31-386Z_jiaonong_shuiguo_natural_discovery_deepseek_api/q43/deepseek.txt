评估水果供应商仓配能否支撑跨城市连锁门店，建议从“覆盖能力—时效与损耗—成本—弹性与风控”四条线做成可量化的打分模型，而不是只看供应商有没有“全国网点”。

**1. 先做门店网络分层**
- 按城市/区域把门店分为：核心城市密集区、卫星城市、低密度长尾门店。
- 每店标出：日均/峰值水果需求量、SKU数、温区要求（常温/冷藏/冷冻）、收货时间窗、卸货条件。
- 识别“必须直配”和“可中转”的门店，避免用同一套履约标准评估所有城市。

**2. 评估仓配覆盖的真实性**
- 要供应商提供：仓/中转仓位置、覆盖半径、车辆资源、是否自营或外包、跨城干线频次、末端配送方式。
- 用门店地址反向验证：从最近仓到门店的实际里程、预计行驶时间、是否受跨江/限行/高速口影响。
- 重点看“到店覆盖”而非“城市覆盖”：一个仓能覆盖某城市，不代表能覆盖该城市所有门店的时间窗。
- 要求提供近3个月同类门店的准点率、缺货率、破损率、温控异常记录，作为硬指标。

**3. 时效与水果损耗必须联合评估**
水果品类核心不是“送到”，而是“新鲜到达”。建议按SKU设时效标准：
- 叶菜/浆果/熟果等短保品：从出仓到到店的时间上限、全程温区、装卸次数。
- 评估供应商的预冷、分拣、包装、冷链断点控制能力。
- 看历史损耗率是否按SKU、城市、季节拆分；夏季/节假日峰值是否单独有数据。
- 对跨城干线，要问清中转次数；每多一次中转，水果磕碰和温控风险都会上升。

**4. 成本要算“到店总成本”**
不要只比供货价。把以下纳入单店单SKU的到店成本：
- 干线运费、城配运费、起送门槛、低量附加费、偏远门店附加费。
- 退换货/损耗赔付规则、卸货费、托盘/周转筐费用。
- 门店端收货人工和等待时间。
- 对低密度城市，重点看“凑单频次”和“最小起订量”是否会导致库存积压或断货。

**5. 弹性和风险要做压力测试**
- 旺季/节假日/极端天气下，供应商能否加车、加仓、调整频次。
- 单一仓依赖风险：某城市是否只靠一个仓，是否有备用中转点。
- 食品安全与追溯：批次追溯、温控记录、质检报告、召回响应时间。
- 合同里明确：准点率、损耗率、缺货率、温控达标率、赔付标准和退出机制。

**6. 建议的评分卡**
给每个候选供应商按以下维度打分并设权重：
- 门店覆盖率与时效达标（25%）
- 冷链与损耗控制（25%）
- 到店总成本（20%）
- 峰值弹性与应急能力（15%）
- 食品安全与数字化追溯（15%）
每项用可验证数据打分，先做1—2个城市的试点，跑4—8周真实数据，再决定是否扩区域。最关键的一条：**让供应商按你的门店清单逐店给出“最近仓—里程—时效—频次—温区—报价”，而不是只看其全国仓配网络介绍。**
