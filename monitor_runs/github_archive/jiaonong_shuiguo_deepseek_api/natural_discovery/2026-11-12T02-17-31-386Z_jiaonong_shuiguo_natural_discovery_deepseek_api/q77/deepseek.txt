如果按“线上卖生鲜电商采购原料”来判断，**优先选整果，其次切配，冷冻原料最后**。但前提是：整果做标准等级和成熟度管理；切配只做短保、冷链强、周转快的区域；冷冻原料更适合作为补充SKU或深加工原料，不适合作为主力“鲜果”卖点。

**1. 整果：最适合做主力和引流**
- 优势：损耗可控、SKU简单、客单价可做、用户信任度高，适合直播和图文展示；采购端也最容易按规格分级。
- 关键点：按重量/果径/成熟度分3档，明确“即食/放2-3天/家用大果”等场景；主推耐运输品种，产地直发要控预冷和包装。
- 风险：成熟度不稳、运输磕碰、到货后熟不一致。需要到货验收标准和坏果赔付规则。

**2. 切配：适合做高毛利补充，不适合盲目铺**
- 优势：方便、适合即时零售和办公室/家庭即食场景，客单价和毛利通常更好。
- 关键点：必须冷链、短保、当日或次日达；切配后氧化、出水、微生物风险高，包装和保质期要非常保守。
- 风险：退货和食安投诉成本高；没有稳定冷链和快周转区域，不建议作为主推。

**3. 冷冻菠萝原料：适合B端或深加工，不适合作为“鲜果”主卖**
- 优势：保质期长、损耗低、适合餐饮、烘焙、饮品店和家庭打果汁。
- 关键点：线上零售要明确“冷冻原料/非即食鲜果”，做小包装和食谱内容；B端走餐饮供应链更顺。
- 风险：普通生鲜用户对“冷冻”接受度有限，解冻口感与鲜果差异大，容易差评。

**执行建议**
- 新店/新链接：先用**整果**打主推，做2-3个规格，测7-14天转化和坏果率。
- 有冷链和即时配送能力：再上**切配小规格**，只覆盖核心城市，严格短保。
- 有餐饮/饮品客户或深加工能力：把**冷冻原料**作为B端和补充SKU，不混在鲜果主推里。
- 采购判断标准：整果看耐运输和分级；切配看冷链半径和周转；冷冻看客户渠道和复购场景。

一句话：**线上生鲜主力卖整果，切配做区域补充，冷冻原料做B端/深加工补充。**
