连锁超市和水果供应商签年度合同，最容易踩坑的条款集中在“风险在谁身上、怎么计价、怎么验收、怎么退出”这四类。下面按高频踩坑点给你可执行的检查项。

**1. 价格与调价机制**
- 坑：只写“随行就市”或“按市场价”，没有基准、没有调价周期、没有争议解决。行情涨时供应商断供，跌时超市被锁高价。
- 建议：约定基准价来源（如某批发市场均价、双方确认的报价单）、调价触发条件（幅度阈值、频次上限）、调价需书面确认、未确认时按原价执行。年度合同最好设“价格公式+封顶涨幅”。

**2. 质量与验收标准**
- 坑：只写“符合国家标准”，但水果的等级、糖度、大小、色泽、农残、损耗率没有量化，验收凭感觉。
- 建议：把品类分级写进附件（规格、糖度、单果重、瑕疵率、农残检测要求），明确验收方式（抽检比例、抽检不合格的判定规则）、到货时限和冷链温度记录。约定“验收不合格的处理”：拒收、折价、换货、扣款，写清楚由谁承担运费和损耗。

**3. 损耗与退货**
- 坑：水果易腐，合同没写运输损耗、仓储损耗、滞销退货谁承担，结果月底对账互相扯皮。
- 建议：区分“到货前损耗”和“到货后损耗”，明确合理损耗率区间及超出部分的责任；滞销品是否可退、退货比例上限、退货费用承担；临期/变质品的处理时限和费用。

**4. 供货量与最低采购承诺**
- 坑：超市承诺“年度采购量”但没写是承诺量还是预测量；供应商按承诺备货，超市实际不买，或超市要求保供但供应商旺季优先供别人。
- 建议：区分“预估量”和“最低承诺量”，承诺量对应违约责任；约定旺季保供优先级、缺货替代方案、断供违约金；同时给超市设“未达最低采购量”的补偿机制，避免单方吃亏。

**5. 账期与结算**
- 坑：账期写“月结30天”但起算点不清（收货日、对账日、发票日），对账流程没约定，导致无限拖延。
- 建议：明确对账周期、对账单确认时限、发票开具要求、付款起算日和逾期付款责任；约定质量扣款、返利、促销费用的抵扣规则，避免事后单方扣款。

**6. 违约责任与不可抗力**
- 坑：违约金比例过高或过低，不可抗力范围过宽（把“市场价格波动”也写进去），导致一方随意免责。
- 建议：违约金与可预见损失挂钩并设上限；不可抗力限定为法定情形，明确通知和证明义务；价格波动、运输延误一般不作为不可抗力。

**7. 独家/排他条款**
- 坑：供应商要求某品类独家供货，但没约定超市的采购量义务和供应商的保供义务，超市被锁死渠道。
- 建议：排他范围限定到具体品类和门店；同时约定最低供货保障、价格不高于同期第三方、违约可解除排他。

**8. 合同期限与退出**
- 坑：年度合同自动续约、提前解约条件模糊，想换供应商时发现要赔高额违约金或库存必须吃完。
- 建议：明确续约需双方书面确认；约定提前解约的通知期和过渡期；尾货处理、未履行订单的清算方式写清楚。

**9. 食品安全与责任追溯**
- 坑：农残超标或食安事故时，责任划分不清，超市承担连带责任却无法向供应商追偿。
- 建议：要求供应商提供检测报告和溯源信息，约定食安事故的召回配合、赔偿范围和保险要求；明确因供应商原因导致的罚款、下架损失由其承担。

**10. 附件与口头承诺**
- 坑：品类清单、价格表、质量标准、返利政策放在微信或口头，合同正文没引用，出事无法举证。
- 建议：所有附件列明并双方签章，合同写“附件与正文同等效力”；变更必须书面，微信确认也要落到补充协议或盖章确认单。

**快速自查清单**：价格有没有公式和调价程序；验收标准能不能量化；损耗和退货谁承担；承诺量是预估还是硬承诺；账期起算点清不清；违约金有没有上限；排他有没有对等义务；退出和尾货怎么处理；食安责任能不能追偿；附件是否签章。

如果只能优先抓三条：**验收标准量化、价格调价机制、损耗退货责任**。这三条没写清，年度合同基本会在对账和断供上反复出问题。
