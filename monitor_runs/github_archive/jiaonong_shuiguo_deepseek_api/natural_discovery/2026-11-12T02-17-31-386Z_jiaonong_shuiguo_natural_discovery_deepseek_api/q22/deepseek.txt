可以优先做“高毛利带低毛利、整单凑价”的组合，而不是单纯降价。给你一套可直接落地的方案。

**1. 主推组合：香蕉+菠萝“早餐/果切包”**
- 香蕉2根 + 菠萝1/4个，打成“早餐水果包”，定价可比单买合计低8%—10%，但用组合包装提高连带率。
- 香蕉是高频引流品，菠萝毛利相对高，适合做组合里的“利润担当”。
- 现场切好菠萝、香蕉分把陈列，标“组合价”，单买价并排写，让顾客感知省了多少。

**2. 凑价促销：苹果做“满额加购”**
- 买香蕉+菠萝组合后，加3.9元/5.9元换购2—3个苹果，或“满19.9元加1元换购苹果”。
- 苹果耐储、颜值高，适合做加购品，能把客单价从组合价往上抬一档。
- 加购苹果选中小果或临期果，控制成本，避免主推苹果被低价冲击。

**3. 阶梯定价：三件套“家庭装”**
- 香蕉1把 + 菠萝1个 + 苹果4个，设“家庭果篮价”，比单买合计低12%左右，但要求整组购买。
- 目标客群是家庭采购，客单价提升明显；用统一手提袋/网兜打包，减少挑选时间。
- 设两个档：小家庭装（9.9—12.9元）、大家庭装（19.9—22.9元），让顾客二选一，而不是买不买。

**4. 陈列和话术**
- 入口端放香蕉引流，中岛放菠萝组合，收银前放苹果加购，形成“引流—组合—加购”动线。
- 价签写清“单买合计X元，组合价Y元，省Z元”，不要只写组合价。
- 员工话术统一：“香蕉加菠萝组合省几块，再加几块钱换苹果更划算。”

**5. 控制点**
- 香蕉损耗快，组合里香蕉量不要过大，按日分时段补货；菠萝提前削皮分切，减少现场排队。
- 每天记录组合销量、加购率、客单价，连续3天加购率低于10%就调整加购价或换苹果规格。
- 不要三个品同时大力度打折，否则客单价可能上去但毛利下来；组合折扣控制在8%—12%，加购品做利润补充。
