水果店遇到坏果，结算或赔付一般按“先分清责任和环节，再按合同/惯例处理”的原则来。可执行做法如下：

1. **到货当场验货**
   - 卸货时抽检/全检，拍照或录像：坏果比例、批次、筐号、车牌、时间。
   - 让司机或供应商在场人员签字确认“坏果数量/比例”，或在送货单上注明异常。
   - 未当场发现的隐蔽坏果（如内部腐烂），保留原包装、批次标签和照片，尽快反馈。

2. **按合同或约定结算**
   - 有采购合同/供货协议的，按合同中的质量标准和赔付条款执行。
   - 没有书面合同的，按行业惯例协商，常见方式：
     - **扣减货款**：按坏果数量或比例从当批货款中扣除；
     - **补货**：供应商补发同等数量合格果；
     - **折价**：坏果降级折价销售，差额由供应商承担；
     - **退货**：严重质量问题整批退回，运费和损耗由责任方承担。
   - 结算时保留书面记录：扣款金额、补货数量、退货数量，双方确认。

3. **分清责任环节**
   - 产地采摘/包装问题：供应商承担；
   - 运输途中磕碰、温度失控：看运输责任方，供应商先对水果店负责，再向承运方追偿；
   - 水果店储存不当导致扩大损失：扩大部分一般由水果店承担；
   - 自然损耗在约定比例内的，按合同或惯例不赔。

4. **赔付标准建议**
   - 按“坏果数量×进货单价”扣款最直接；
   - 也可按“坏果比例×当批货款”扣减；
   - 若坏果导致整批无法销售，按整批退货或全额扣款处理；
   - 协商时可要求供应商承担合理运费、分拣人工等直接损失，但需提前有约定或双方认可。

5. **留证和流程**
   - 建立验收单：批次、数量、坏果数、照片、处理方式、双方签字。
   - 坏果单独存放，避免与好果混放，防止争议。
   - 大额或反复出现的问题，书面发函要求整改，并在后续合同中明确质量标准、验收时限、赔付比例和争议处理方式。

简单说：**当场验货留证，按合同扣款/补货/退货，责任不清的先协商书面确认，别只口头说。**
