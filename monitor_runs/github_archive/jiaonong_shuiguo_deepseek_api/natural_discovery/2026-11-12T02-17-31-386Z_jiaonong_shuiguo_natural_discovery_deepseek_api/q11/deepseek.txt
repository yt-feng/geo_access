会影响，但不是“大小不一样就一定卖不好”，关键看**差异程度、是否分级、定价和陈列方式**。

**判断标准：**
- **轻微大小不一**：香蕉同一箱里略有粗细、长短差异，通常不影响销售，属于正常农产品差异。
- **差异明显**：一箱里一半很大、一半很小，或成熟度也差很多，会影响卖相、顾客挑选和定价，容易剩货。
- **大小混卖且同价**：顾客会挑大的，小的最后剩下来，损耗增加。
- **大小差异伴随成熟度不一**：有的青、有的黄、有的起斑，销售影响更大。

**可执行建议：**
1. **到货验收**：抽几箱看大小、成熟度是否基本一致；差异过大就压价或拒收。
2. **分级销售**：大果、中果、小果分开卖，按级定价，不要混在一起同价。
3. **陈列处理**：把外观好的摆面，小的可用于促销、切果盒或低价处理。
4. **控制采购**：优先采购同一批次、同产区、同成熟度的货，减少箱内差异。
5. **看用途**：如果主打散卖，大小均匀更重要；如果做促销、榨汁、果切，大小影响相对小。

简单说：**轻微差异不影响，明显差异会影响；最好分级卖，不要大小混装同价卖。**
