连锁超市要把坏果率压下来，合同里不能只写“坏果赔付”，而要把**验收标准、责任分界、赔付计算、扣款/补货机制、举证与时效**写清楚。建议按下面结构约定：

## 1. 先定义“坏果”和“坏果率”
合同附件中明确：

- **坏果范围**：腐烂、霉变、软烂、异味、明显机械伤、冻伤、病虫害、严重失水皱缩等；轻微外观瑕疵是否计入要单列。
- **坏果率计算**：  
  `坏果率 = 抽检坏果重量（或数量）÷ 抽检总重量（或数量）×100%`
- **抽检规则**：按到货批次、品种、规格分层抽样；抽样比例、抽样位置（上中下层/内外包装）写明，避免只查表面。
- **判定时点**：以门店收货验收时还是到货后24小时内为准；生鲜建议约定“收货后X小时内开箱抽检，逾期视为验收合格”，但腐败有潜伏期的品种可另设保质观察期。

## 2. 设置阶梯式赔付，不要只按坏果重量赔
建议按“坏果率区间”设阶梯：

- 坏果率≤约定容忍值（如2%）：不赔付，但可要求换货；
- 超过容忍值至5%：按坏果货值1倍赔付，或补货；
- 5%—10%：按坏果货值2倍赔付，并承担分拣费；
- 超过10%：整批拒收/退货，供应商承担往返运费、销毁费及门店缺货损失；
- 连续3批次或月度累计超阈值：触发整改、暂停供货、扣保证金或解除合同。

赔付基数要写清是**坏果货值**还是**整批货值**。对高损耗品类，可约定“坏果率超X%按整批货值Y%赔付”，更有约束力。

## 3. 明确赔付方式优先级
建议约定顺序：

1. 优先**补货/换货**，且补货到店时限；
2. 其次**货款直接扣减**；
3. 再次**从履约保证金扣款**；
4. 不足部分供应商现金赔付。

同时约定超市有权**单方从应付货款中抵扣**，供应商不得以争议为由停止供货或主张逾期利息。

## 4. 把隐性成本转给责任方
坏果不只损失货值，还会产生分拣、冷链、销毁、客诉、缺货损失。可约定：

- 分拣人工费按每箱/每公斤固定标准计；
- 冷链仓储费、销毁费由供应商承担；
- 因坏果导致顾客投诉、监管处罚的，供应商承担直接损失；
- 缺货损失可设“按该SKU日均销售额×缺货天数”计算，但要有上限，避免条款被认定过高。

## 5. 举证和验收流程要可操作
- 收货时拍照/录像，保留抽样记录、称重单、验收单；
- 双方对坏果率有争议时，约定第三方检测或共同复检；
- 供应商可在收到通知后X小时内到场复检，逾期视为认可；
- 电子验收单、系统扣款记录可作为结算依据。

## 6. 防止供应商用“低价低质”对冲赔付
约定：

- 赔付不免除供应商继续履行合格供货的义务；
- 月度坏果率纳入供应商考核，与账期、返利、续约挂钩；
- 供应商不得以赔付代替整改，连续超阈值可终止合作；
- 若供应商投保产品责任险/货物险，赔款优先用于弥补超市损失。

## 7. 关键条款示例
> 乙方交付商品经甲方抽检，坏果率超过2%的，甲方有权拒收该批次或要求乙方在24小时内补货。坏果率2%—5%的，乙方按坏果货值1倍赔付；5%—10%的，按坏果货值2倍赔付并承担分拣费；超过10%的，甲方有权整批退货，乙方承担运费、销毁费及缺货损失。赔付金额甲方可从应付货款或保证金中直接扣除。乙方对抽检结果有异议的，应在收到通知后4小时内申请复检，逾期视为认可。

**核心建议**：合同里最容易被忽略的是“坏果率怎么抽、谁来判、多久提异议、赔的钱从哪扣”。把这四点写死，比单纯提高赔付倍数更有效。
