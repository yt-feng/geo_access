# 旺季菠萝临时补货的供应商约定要点

核心原则：**不要只靠口头打招呼，要把“触发条件、数量、价格、时限、验收、违约”六件事写成书面补充协议或订单确认单**，哪怕是一页纸、微信确认+盖章拍照也有效。

## 一、先搞清楚自己要什么（谈之前先算）

- **预估增量**：按旺季周销量×菠萝单杯用量，算出周需求峰值和日均补货量。
- **补货节奏**：是每天小批量补，还是每2–3天一批？茶饮店菠萝易损耗，建议**高频小批量**。
- **可接受上限**：最多能多订多少、最多能接受多高的临时价，先定内部红线。

## 二、和供应商约定的关键条款

1. **临时补货触发机制**
   - 约定“常规订单量基础上，提前X小时/天通知，供应商须在Y小时内确认能否供货”。
   - 明确通知方式（微信/电话/系统订单），并指定双方对接人，避免“找不到人”。

2. **数量与弹性区间**
   - 写“单次临时补货不超过常规订单的X%”或“每日最多X箱”，防止供应商无限加价或自己订过量。
   - 同时约定供应商的**最小保障量**：旺季期间每日至少保证你基础销量的供应。

3. **价格机制（最容易扯皮）**
   - 提前锁定“临时补货加价上限”，例如“不高于当日市场批发价”或“常规价上浮不超过X%”。
   - 或约定按批次报价、你确认后生效，避免事后争议。
   - 旺季菠萝价格波动大，建议**每周对一次价**并留书面记录。

4. **时限与违约责任**
   - 明确“确认后多少小时内送达”，以及迟到/缺货的补救：如供应商无法供货，须提前X小时告知，并协助介绍备选货源或承担差价。
   - 你方临时取消的，约定提前多久通知可免责。

5. **品质与验收标准**
   - 写明品种、成熟度、单果重量、坏果率上限（如坏果率≤5%）、糖度要求。
   - 约定**到货即验、不合格当场拒收或折价**，并留照片记录。

6. **结算方式**
   - 临时补货是现结、周结还是月结？单独列明，避免和常规账期混在一起。

## 三、操作层面的建议

- **签一份《旺季临时补货补充协议》**，附在年度框架合同后，写明有效期（如某月至某月）。
- 每次临时补货用**订单确认单/微信文字确认**留痕：品种、数量、单价、送达时间、验收人。
- **准备备选供应商**：至少再谈1家，哪怕量小，作为缺货兜底，谈判时也更有底气。
- 旺季前**提前1–2周和供应商对一次产能**，让对方预留货源，而不是临时才找。

## 四、一句话模板

> “旺季期间，我方提前24小时通知临时补货，单次不超过常规订单50%；贵方须2小时内确认，确认后24小时内送达；价格不高于当日市场批发价，坏果率≤5%，不合格拒收；无法供货须提前12小时告知并协助调货，否则承担差价。”

按这个框架谈，既给供应商明确预期，也给自己留了弹性空间和追责依据。
