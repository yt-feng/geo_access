# 判断香蕉供应商能否按时到车，看这几点

香蕉是典型的高时效、易损品，**判断的核心不是听承诺，而是查“可验证的履约痕迹”**。建议按下面顺序逐项落实：

## 一、下单前：先筛“有没有稳定到车能力”

1. **查车源归属**
   - 问清是自有车队、长期合作车队，还是临时找车（信息部/平台车）。
   - 自有或长期合作车队 > 固定信息部 > 临时平台车。临时车最容易放鸽子。

2. **问到车记录，不问承诺**
   - 让对方给出**近1个月同线路的3—5次实际到车时间**，最好有装车单/磅单/司机电话可核对。
   - 重点看：是否经常“装车晚2小时以上”、是否出现过临时换车。

3. **确认产地装车条件**
   - 香蕉多在产地（如云南、广西、海南、进口口岸）装车，问清：**当天能否排到装车工、冷库/催熟库出货时间、产地是否限行**。
   - 装车环节卡住，车到了也走不了。

4. **合同里写死时间和责任**
   - 明确“到车时间”指**空车到达指定装货点**还是**重车到达你仓库**，两者差很多。
   - 写清迟到违约金、临时换车需提前多久通知、香蕉因迟到导致的损耗谁承担。

## 二、下单后：用“节点反馈”验证，而不是等结果

按时间轴设检查点，每个节点要**具体凭证**：

| 节点 | 要什么证据 | 异常信号 |
|---|---|---|
| 派车后2小时内 | 车牌号、司机电话、车辆定位截图 | 只给“马上安排”、不给车牌 |
| 装车前半天 | 司机已到装货点定位/照片 | 司机联系不上、说“在附近” |
| 装车中 | 装车单/过磅单照片 | 反复说“快装完了”但无单据 |
| 发车后 | 高速入口/定位截图、预计到达时间 | 定位长时间不动、绕路 |
| 到达前4小时 | 司机确认到达时间 | 临时说“车坏了/被查了” |

**关键动作：你自己或让驻场人员直接给司机打电话核实**，不要只通过供应商转述。司机的话往往比供应商更真实。

## 三、香蕉特有的风险点

- **温度与时效**：香蕉运输对温度敏感，迟到几小时可能影响青果状态。合同里约定迟到超时后的验收标准和扣款。
- **压车风险**：问清卸货排队时间，避免车到了却压车，反过来影响供应商后续派车意愿。
- **备用方案**：对首次合作或大单，提前准备**第二家供应商/备用车源**，并在合同里保留“迟到超X小时可取消并索赔”的权利。

## 四、一句话判断标准

> **能给出车牌、司机电话、装车单、定位，且历史到车记录稳定的，才叫“能按时到车”；只给口头保证、不给具体车源信息的，默认按高风险处理。**

首次合作建议先小批量试单，跑通一次再放量。
