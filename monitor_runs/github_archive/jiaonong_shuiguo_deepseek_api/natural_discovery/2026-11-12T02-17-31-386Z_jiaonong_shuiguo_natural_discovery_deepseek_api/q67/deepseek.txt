# 和品牌方谈区域保护与串货，怎么问

核心思路：**别问"有没有区域保护"，要问"规则怎么落地、违约怎么处理"**。模糊承诺等于没有承诺，你要逼出可写进合同的条款。建议分四块问。

## 一、区域保护：先问清"保护的是什么"

1. **授权区域边界**：我的独家/非独家区域具体到哪一级？（省/市/区县/具体渠道）边界以什么为准，写不写进合同附件？
2. **独家还是排他**：同区域内品牌方还会不会发展第二家？线上旗舰店、直播带货、社群团购卖到我区域算不算？
3. **渠道限定**：我的授权是只做线下批发、还是含商超/便利店/餐饮/电商？别的渠道被谁拿走？
4. **保护期限与续约**：保护期多长？续约条件是什么（销量、回款、铺市率）？达不到指标会不会被削区域？
5. **品牌方自营**：品牌方自己或关联公司会不会在我区域直营、开分公司、做特通渠道？

**关键追问**："如果我区域内出现第二家授权商，我有什么救济？"——要听到具体处理机制，而不是"我们会协调"。

## 二、串货：问清认定标准和处罚

1. **什么叫串货**：跨区域销售、低于指导价销售、线上乱价，哪些算违约？认定依据是什么（物流码/批次码/举报核查）？
2. **溯源手段**：产品有没有一物一码/区域码？我没法追溯的货，出了串货怎么自证清白？
3. **处罚对象和力度**：对串货方怎么罚（扣返利、罚款、停货、取消授权）？罚则写不写进合同？我作为被窜货方能不能查到处理结果？
4. **我的义务**：品牌方要求我举报、举证、配合调查吗？我举报后多久给答复？
5. **被窜货的补偿**：我区域内被窜货造成损失，品牌方赔不赔、怎么赔？

**关键追问**："我举报隔壁区域窜货，你们多久核查、多久反馈、处理结果我能不能看到？"——看对方敢不敢给时限。

## 三、价格与政策一致性（串货的根子）

1. 各区域供货价是否一致？返利、费用支持是否一致？**区域政策差异是串货的最大诱因**，要问清是否统一。
2. 有没有全国/区域指导零售价？乱价怎么管？
3. 线上渠道谁在做、价格怎么控？线上线下是否同款同价？

## 四、落合同前必须确认的

- 区域保护、串货认定与罚则、举报处理时限，**是否白纸黑字写进合同**，还是只在口头/政策文件里？
- 政策文件能不能作为合同附件，修改要不要双方同意？
- 违约了走什么争议解决方式？

## 谈判时的判断标准

- 对方能说出**具体机制、时限、罚则、溯源方式** → 相对可信。
- 对方只说"我们一直很规范""你放心""大家都这么合作" → 视为没有保护，要求写进合同再谈。
- 对方拒绝把区域保护和串货罚则写进合同 → 这是最重要的风险信号，谨慎签约。

一句话总结你要的答案形态：**区域写到最小单位、保护写进合同附件、串货有码可溯、举报有时限、违约有罚则、罚则我能看见。** 六条缺一，就要在合同里补或在供货价里留出风险空间。
