超市和水果供应商的账期没有全国统一标准，常见区间大致如下：

- **现结/周结**：7天、15天，多见于高损耗、短保水果、叶菜类、进口精品水果，或供应商议价能力强、首次合作。
- **月结30天**：最常见的一档，尤其是本地批发商、区域供应商给中小超市、社区店。
- **月结45～60天**：大型连锁超市、商超对常规水果供应商较常见；账期越长，通常采购量或合作稳定性要求越高。
- **90天及以上**：多见于强势大型商超、全国性连锁，或供应商承担较高进场费/促销费时；对水果这种高损耗品类不太普遍，供应商往往会把资金成本折进报价。

实操上可这样判断：

1. **看品类**：叶菜、浆果、鲜切水果等损耗高、周转快的，账期宜短，7～15天或周结更合理；苹果、梨、橙等耐储水果可谈到30天左右。
2. **看规模**：社区超市/单店常见15～30天；区域连锁常见30～45天；大型商超常见45～60天，部分强势渠道到90天。
3. **看新供应商**：首次合作建议先做15～30天，或“前两单现结、稳定后月结30天”，降低双方风险。
4. **看报价联动**：账期每延长15～30天，供应商通常会加价或要求保底采购量，谈判时要把账期和价格、损耗承担、退换货一起谈。

如果是你作为超市方去谈，比较稳妥的目标是：**常规水果月结30天，高损耗品类15天或周结，新供应商首月15天**。如果对方要求60天以上，建议同步谈价格折让、损耗分担或缩短部分品类账期。
