重点看“到货时熟度 + 还能放几天 + 隐性坏果比例”。建议按下面顺序判断：

**1. 先看整体熟度**
- **1-2成黄、棱角明显、手捏硬**：青蕉/生蕉，适合放熟或远途分销，但要注意冷害和催熟是否均匀。
- **3-4成黄、果身稍软**：适合批发周转，通常还有几天货架期。
- **5-6成黄、果指饱满、微香**：适合快批快走，再放容易过熟。
- **7成黄以上、果柄发黑、香味重**：当天必须出手，坏果风险高。
- **果身出现梅花点/黑斑初期**：不是立刻坏，但货架期明显缩短；黑斑连片、渗液则不要拿。

**2. 看棱角和饱满度**
- 香蕉棱角尖锐、果身瘦：偏生。
- 果身圆润、棱角变钝：在转熟，接近可售。
- 果指过软、压痕不回弹：过熟或运输压伤。

**3. 查隐性坏果，不能只看表面**
随机抽几把，重点翻看：
- 底层、箱角、靠箱壁的果指；
- 果柄连接处是否发黑、发霉、渗液；
- 果指中间是否有暗软斑、指压凹陷；
- 箱内是否有汁液、霉味、酸味；
- 果梳切口是否褐变、腐烂。

**坏果风险信号：**
- 一箱里抽到2-3根局部软烂或霉柄，整批要降级估价；
- 有酸味、酒味、霉味，说明内部已开始变质；
- 果柄发黑且连到果身，容易整把坏；
- 箱底潮湿、纸箱软塌，通常有压伤和渗液；
- 同一批熟度差异大，说明催熟不均或混批，损耗会高。

**4. 判断“熟得匀不匀”**
看同一箱、同一托盘上下层颜色差异。上下层差一两个色阶可接受；如果上层已黄、下层还硬青，或箱内一半黄一半青，说明催熟不均，批发后客诉和损耗都高。

**5. 快速抽检方法**
- 每托盘随机抽3-5箱，每箱抽上、中、下三层；
- 每箱抽2-3把，轻捏果指中段，不要只捏果柄；
- 记录：黄度比例、软果数、霉柄数、异味、渗液；
- 按“好果/软果/烂果”估算比例，软果超过5%就要谨慎，烂果超过1%-2%建议压价或拒收。

**6. 结合季节和运输**
- 夏季高温、闷箱运输：熟得快，隐性软果多，宁可拿偏生一点；
- 冬季低温运输：警惕冷害，果皮灰暗、果心硬、后熟不均；
- 到货后立即开箱散热，不要闷在车里或库房角落。

**拿货决策简表：**
- 偏生、均匀、无霉柄、无异味：可拿，按计划放熟。
- 熟度合适、少量梅花点、软果少：快进快出。
- 熟度不匀、箱底潮湿、有霉柄：压价或只拿好箱。
- 有酒味/酸味、软烂连片、果柄发黑腐烂：拒收。

最后记住：香蕉批发最怕“表面好、箱底烂”和“催熟不匀”。抽样必须翻底层和箱角，不能只看最上面一层。
