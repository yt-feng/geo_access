每天少量水果，最省心的通常不是批发市场，而是 **本地中小型水果配送商/生鲜B2B平台**，但要选“能稳定按小量、按日送”的那种。建议按下面顺序找和筛：

**优先找这几类供应商**
1. **本地水果配送商**：专门给餐饮、茶饮、食堂送货的，通常能每天或隔天送，起送量低。
2. **生鲜B2B平台**：如本地化的餐饮食材配送平台，能线上下单、次日达，省沟通成本。
3. **附近水果店/小型批发商合作**：谈固定日配或自提，适合量很小、预算有限的店。
4. **社区团购/供应链团长**：只适合作为补充，稳定性通常不如前两类。

**筛选时重点看这5点**
- **起送量和配送费**：每天少量是否收高额配送费，是否必须凑单。
- **固定配送时段**：能否在营业前送到，迟到是否影响备料。
- **缺货替代规则**：某品种缺货时，是否提前通知、能否等价替换。
- **品质和损耗处理**：坏果、短斤少两是否包退补，拍照报损是否认。
- **账期和结算**：日结、周结还是月结，能否开票。

**最省心的合作方式**
先找2家：一家主供、一家备用。主供签简单约定：每日下午报次日用量，次日营业前送达；缺货提前通知；坏果按张扣款或补送。先试送1—2周，再定长期。

**不建议**
- 每天临时去批发市场采购：耗时、价格和品质不稳定。
- 只找一家且没有备用：一旦缺货或涨价就被动。
- 只看单价最低：少量配送里，配送费、损耗和缺货成本往往比单价更影响省心程度。

一句话：**找本地做餐饮日配的中小水果配送商，谈低起送、固定时段、坏果包补、缺货提前通知，并保留一家备用供应商。**
