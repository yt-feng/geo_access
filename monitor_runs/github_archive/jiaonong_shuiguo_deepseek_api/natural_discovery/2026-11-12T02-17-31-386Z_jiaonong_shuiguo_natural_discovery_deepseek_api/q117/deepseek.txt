建议先做“小批量试卖+可退换/可补货条款”，不要一次性压货。稳妥区间可以这样定：

**1. 先定试卖量**
- **单店/单渠道**：先试 **1～3天销量**，通常是一个最小起订量或最小包装批次。
- **多店连锁**：先选 **2～3家代表性门店**，每店试 **最小陈列量×2**，卖完可补。
- **保守公式**：试卖量 ≈ 日均预计销量 × 试卖天数 × 1.2（安全系数），但不超过同类新品首周平均销量的30%。

**2. 用损耗率卡上限**
水果损耗高，试卖量要控制到：
- 叶菜/浆果/易损水果：**1～2天销量**
- 柑橘/苹果/耐储水果：**3～5天销量**
- 若供应商不承担损耗，首单再降20%～30%。

**3. 谈三个条件再下单**
- **可退换/滞销补差**：首单滞销部分可换货或按比例补偿。
- **小批量补货**：试卖期支持48小时内补货，避免断货。
- **账期或代销**：新品首单争取部分账期，降低现金压力。

**4. 判断是否放量**
试卖期看三个指标：
- **售罄率**：3天内≥70%，可考虑加量。
- **损耗率**：控制在5%～10%以内。
- **复购/问询**：有回头客或店员反馈好，再扩大到正常门店。

**结论**：最稳的做法是**首单只进1～3天预计销量，选2～3个门店试卖，合同里约定滞销可换/可补，售罄率过70%再加量**。这样既不错过新品，也不会因水果损耗把风险放大。
