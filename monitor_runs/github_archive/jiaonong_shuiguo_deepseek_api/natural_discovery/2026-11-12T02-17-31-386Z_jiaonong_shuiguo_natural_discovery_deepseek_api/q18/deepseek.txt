先定用途，再按“当天吃/放几天”选颜色，到店用手和果柄复核，比只看颜色可靠。

**按用途选颜色**
- **当天或第二天吃**：选**黄底、少量褐斑**的；褐斑多、发黑、果柄发黑或有酒味的不要。
- **2～3天后吃**：选**整体偏黄、两端略绿**的。
- **4～5天后吃**：选**黄绿相间、棱角还明显**的，回家常温放。
- **不要买**：大面积青绿且很硬（可能放很久仍不熟）、已发黑软塌、有酸酒味、果柄霉变的。

**到店快速判断**
1. **看果柄**：果柄青绿通常较生；果柄发黑、干枯多半偏熟或放久了。
2. **看棱角**：香蕉棱角分明=偏生；棱角圆润饱满=偏熟。
3. **轻捏中部**：硬=生；略有弹性=正好；一捏就软=偏熟。别捏两端，容易伤果。
4. **看表皮**：均匀黄最好；零星小褐斑可当天吃；成片黑斑、渗水、破皮不要。
5. **闻一下**：有清甜香正常；有酒味、酸味说明过熟或已坏。

**采购小技巧**
- 想错开成熟时间：**同一把里挑颜色略有差异的**，或买两把不同成熟度。
- 不要买已经装袋密封、水汽重的，容易闷坏。
- 回家后**未熟常温放**，别急着冷藏；**已熟**可冷藏延缓继续变软，但表皮会变黑，不影响果肉。
- 香蕉别和苹果、梨长期密封放一起，会加速成熟。
