**香蕉：高风险**
- 香蕉是呼吸跃变型水果，后熟快，青蕉会集中转黄，销售窗口短。
- 起订量高会迫使门店/仓库在未完全消化前就进入成熟期，容易出现压伤、黑斑、过熟。
- 若冷链或催熟控制不精细，整批集中成熟，损耗会明显上升。
- 建议：按“日销量×在途+安全库存”倒推起订量；优先小批量高频补货；青蕉和黄蕉分开控温；设置催熟批次上限。

**菠萝：中等风险**
- 菠萝相对耐储，但起订量高仍会带来叶冠萎蔫、果皮褐变、内部黑心、霉变等风险。
- 堆码过高压伤、通风不良、温度波动会加速腐烂。
- 整箱起订容易造成“先进未先出”，底部或后排果先坏。
- 建议：控制堆码高度和通风；按周转天数定起订量；到货即做品质抽检；严格执行先进先出。

**判断标准**
- 若起订量对应的库存周转天数超过：香蕉约2–3天、菠萝约5–7天，就应警惕损耗上升；具体还要看温湿度、包装、销售速度。
- 起订量谈判优先争取：小批量多频次、混装拼柜、可拆分SKU、滞销可调换。
- 采购合同里最好约定到货成熟度、规格、损耗赔付和退换条件。

结论：起订量太高会增加损耗风险，香蕉尤其明显；采购时应以周转天数而不是单价折扣作为起订量决策核心。
