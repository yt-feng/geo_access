可以按“同一套分级维度、两套价格表、按箱报价并注明折算”的方式做，小店最容易看懂，也方便你现场议价。

**一、先统一分级维度**
香蕉和菠萝都用“外观+单果规格+成熟度+损耗”来分，但指标不同：
- 香蕉：按每把/每根长度、粗细、条数、青熟度、机械伤、掉把率分。建议分：A级（果指匀称、无黑斑、青熟可催）、B级（轻微擦伤/大小不匀）、C级（熟度高或外观差，适合即卖或加工）。
- 菠萝：按单果重量、果形端正度、冠芽完整度、成熟度、黑心病/水心病抽检情况分。建议分：A级（单果重达标、果形正、冠芽好）、B级（大小略不匀、冠芽短）、C级（偏小/偏熟/外观瑕疵，即售型）。

**二、报价表做成“三列一备注”**
每级一行，列：
1. 等级与规格（例：香蕉A级 每把5-7根/单根18-22cm；菠萝A级 单果1.2-1.5kg）
2. 箱规与净重（例：香蕉A级 12kg/箱；菠萝A级 9-10头/箱，净重约12kg）
3. 批发价（元/箱）+ 折算价（元/kg或元/根）
备注：成熟度、是否含箱、运费/卸货、当日可退换比例、最小起订量。

**三、报价表达要“清楚到可结算”**
- 香蕉：报“元/箱”为主，同时写“约X元/kg、约X元/把”，避免小店按根算产生歧义。
- 菠萝：报“元/箱、X头/箱”，再写“约X元/个、X元/kg”，并注明“按头计价还是按重量计价”。
- 同一等级内若规格跨度大，再拆“大果/中果”两档，不要只写A/B/C。
- 明确损耗归属：到店后坏果率在多少以内不补、超过怎么补，写进报价单。

**四、给小店看的简版模板**
香蕉：
- A级 12kg/箱，约5-7根/把，青熟可催：XX元/箱（约XX元/kg）
- B级 12kg/箱，大小略不匀：XX元/箱
- C级 12kg/箱，熟度高/外观瑕疵：XX元/箱
菠萝：
- A级 9-10头/箱，单果1.2-1.5kg：XX元/箱（约XX元/个）
- B级 10-12头/箱，单果0.9-1.2kg：XX元/箱
- C级 按实际头数/重量：XX元/箱

**五、执行建议**
先让小店按“箱”下单，折算价只作参考；每天或每批更新一次等级和价格，报价单上写清日期、产地、成熟度、箱规、退换规则。这样分级清楚、报价可核对，后面少扯皮。
