建议不是二选一，而是“整果为主、切果为辅”，并按门店客流和损耗能力定比例。判断顺序如下：

1. **先看门店客群**
   - 社区店、家庭采购多：整果为主，切果少量。家庭更在意单价和耐放。
   - 商圈店、写字楼店、年轻客群多：切果比例提高。即买即吃、单人份需求强。
   - 学校、医院、交通枢纽附近：切果更适合，整果只保留少量。

2. **看损耗和操作能力**
   - 没有冷藏陈列、切果操作间、当天能卖完的把握：不要多做切果，损耗和食品安全风险高。
   - 有冷藏柜、专人操作、能日清：切果可做引流和提客单。
   - 菠萝整果耐放，切果保质期短，切果本质是“用损耗换便利溢价”。

3. **看价格带和毛利**
   - 整果适合做低价引流、家庭装、堆头陈列。
   - 切果适合做便利性溢价，但要把去皮、切块、包装、损耗算进成本。切果毛利率应明显高于整果，否则不值得做。

4. **建议的实操配置**
   - 中小社区店：整果70%—80%，切果20%—30%，切果只做当天小批量。
   - 商圈/年轻客群店：整果50%—60%，切果40%—50%，高峰前分批切。
   - 新店或客流不稳：先整果试销，切果每天少量试水，观察3—7天动销再调比例。
   - 切果必须标注加工时间、冷藏销售、当日清货；卖不完的不要隔夜继续当鲜切卖。

5. **采购端配合**
   - 整果选耐储、外观好的规格，适合堆头和家庭购买。
   - 切果用成熟度略高、出成率稳定的果，避免用快坏果切盘，否则口碑和食安风险大。
   - 整果和切果最好分开等级采购，不要用同一批货硬切。

**结论：多数商超应以整果为基本盘，切果做增量。** 如果门店年轻客群集中、冷藏和日清能力强，切果比例可以提高到四到五成；如果是以家庭采购为主、操作能力一般，整果占七到八成更稳。
