优先谈**账期**，其次售后，最后配送。原因是长期合作里，账期直接决定你的现金流和议价空间，售后是风险兜底，配送在水果品类虽重要但通常可通过备选供应商和验收标准部分对冲。

具体判断：

1. **账期最优先**
   - 水果损耗高、价格波动大，账期每延长15天，对现金流改善明显。
   - 谈判时不要只谈“月结30/60天”，要明确：起算日、对账日、付款日、节假日顺延规则、逾期是否停供。
   - 优先争取“货到验收后30天”而非“自然月月结”，后者实际账期可能被拉长到45天以上。

2. **售后第二**
   - 水果核心售后是：到货腐烂/压伤/规格不符/重量短缺怎么赔。
   - 要谈成可执行标准：验收时限（如到货2小时内反馈）、举证方式（照片/视频）、赔付方式（补货/扣款/折价）、损耗率上限。
   - 售后条款谈不清，账期再长也会被质量纠纷拖成坏账。

3. **配送第三**
   - 配送频次、到货时间窗、临时加单响应、缺货替代方案要谈，但通常供应商可替换性比账期和售后强。
   - 重点不是“送得快”，而是“送得稳”：固定配送日、迟到处理、冷链/保鲜责任。

谈判顺序建议：先谈**验收和售后标准**作为合作底线，再谈**账期**作为核心利益，最后用**配送频次和独家/优先供货**做交换筹码。不要一上来只压账期，否则供应商可能在品质和配送上找补。
