商超采购菠萝，具体是卖整果还是切好的，**并没有绝对的好与坏，核心取决于门店的选址、客群画像、以及供应链能力**。

从实际操作和利润角度看，建议采取**“整果主推、切果补充”**的组合策略，而非单选其一。以下是可以直接落地的判断建议：

**1. 看门店位置与客流（决定损耗风险）**

-   **核心商圈店/写字楼店：** 客群以年轻白领、单身或双人家庭为主，他们追求“即买即食”和便捷，通常没有时间和工具处理菠萝。**适合主推切好的果切或带皮切片**，每盒按200g-300g小份装，溢价空间高（毛利可达50%以上）。
-   **社区店/家庭店：** 客群以中老年和家庭主妇为主，他们更看重性价比和新鲜度，习惯买回家自己削（削好的怕不新鲜）。**适合主推整果**，价格透明，竞争少。

**2. 看采购与加工能力（决定成本结构）**

-   **如果门店没有专门削皮区或熟练刀工：** 强行卖切好的，一旦销量跟不上，菠萝氧化变黑、出水严重，损耗率会超过整果。此时**应主卖整果**，把削皮服务作为增值项（比如免费代削，但只卖整果）。
-   **如果有加工间或档口：** 可以每天定时（如上午10点、下午3点）分批次削好，只切新鲜的那几个。卖不完的**必须当天报损**，绝不过夜，这对口碑影响极大。

**3. 关键动作：用“双轨定价”对冲风险**

-   **整果标价**：按斤卖，定价略低于市场均价，引流用。
-   **切果标价**：按盒卖，定价为整果的1.5-2倍（含加工费）。例如整果卖5元/斤，切好的卖8-10元/半斤。
-   **止损机制**：临近打烊（如晚上7点后），切好的果盒如果没卖完，可以**买一送一**或**降至半价**清掉，宁可少赚也不能留到第二天。同时，当天最不新鲜的整果，直接打折促销（如“今日特价”），优先消化滞销品。

**4. 特别注意（避免踩坑）**

-   **不要贩卖“泡盐水”的菠萝**：很多超市为了保鲜，切好后泡盐水，但这会导致风味流失且容易滋生细菌。建议切好后直接去皮去眼，用保鲜膜干包，附赠一小包盐（成本只需几毛钱）。
-   **标注产地与甜度**：海南菠萝和徐闻菠萝甜度差异大，整果和切果都要用价签注明“现切/去皮/当天加工”，增加信任感。
