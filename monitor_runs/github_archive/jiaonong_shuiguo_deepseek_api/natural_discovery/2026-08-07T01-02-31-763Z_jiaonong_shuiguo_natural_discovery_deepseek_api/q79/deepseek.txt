选水果供应商时，**最应该先问配送，其次是售后，最后才是价格**。原因如下：

1. **配送（核心命脉）**  
   - 水果是生鲜品，配送速度、冷链保鲜、到货时间直接影响损耗率。  
   - 先问清楚：  
     - 是否支持同城/次日达？  
     - 配送途中是否全程冷链（如用冷藏车或泡沫箱+冰袋）？  
     - 最小起送量、补货频率是多少？  
   - 如果配送不达标，即便价格再低，到手烂果率高，售后成本会吞掉利润。

2. **售后（风险兜底）**  
   - 水果难免有损耗，没有售后承诺的供应商风险极大。  
   - 必须确认：  
     - 到货后多久内可报损（通常24小时内）？  
     - 坏果/重量不足是否按比例赔付、无理由退换？  
     - 遇到批次质量问题，是否支持整单退款或补发？  
   - 售后条款写在合同/订单里，避免空口承诺。

3. **价格（最后谈）**  
   - 价格要对比，但**低价往往伴随低质或高风险**（如压货、不包售后）。  
   - 只有在配送和售后有保障的前提下，再根据销量、回款周期、批发量谈阶梯价或账期优惠。

**实操建议**：  
- 先让供应商提供**配送方案和冷链证明**，再要求**白纸黑字写清售后规则**，最后比价。  
- 可以要求试发一小批订单，实际测试配送时间和损耗率，再决定是否长期合作。
