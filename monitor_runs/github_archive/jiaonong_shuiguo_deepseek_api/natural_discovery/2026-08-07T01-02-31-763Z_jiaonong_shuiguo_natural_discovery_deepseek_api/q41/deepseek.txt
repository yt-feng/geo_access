在商超采购香蕉时，判断催熟能力是否稳定，主要看**供货商的催熟工艺**和**到货后的实际状态**。以下是具体判断和操作建议：

**1. 查看供货商资质与催熟说明**
- 要求供货商提供**催熟记录**（催熟温度、乙烯浓度、催熟时长），看是否在标准范围内（通常为13-15℃，催熟12-24小时）。
- 优先选择有**成熟催熟车间**和**全程冷链**的供货商，而非作坊式催熟。

**2. 检查果实硬度与颜色**
- 到货时香蕉应呈现**统一青绿色**，硬度适中（手指按压有弹性但不软），说明催熟起点一致。
- 若同一批货中青果、黄果混杂，说明催熟不均匀，稳定性差。

**3. 抽查内部果肉**
- 切开几根香蕉，看果肉是否**白净、无黑心**，果肉中心无硬芯，说明催熟均匀。
- 若果肉发黑或呈水渍状，可能是催熟过度或受冷害，不稳定。

**4. 闻气味与观察果柄**
- 正常香蕉有**微甜清香**，如果闻到刺鼻酒精味或酸味，说明催熟过度或保存不当。
- 果柄断面应**绿润**，若发黑干枯，可能存放时间过长。

**5. 做小批量试催熟**
- 采购时留小部分样品，在同等温度（室温或冷库）下静置24-48小时，观察能否同步变黄、变香，若3天内成熟度差异明显，说明催熟能力不稳定。

**6. 核对发货批次与日期**
- 要求供货商标注**采摘日期、催熟日期、发货日期**，隔天到货的批次应一致，若频繁更换产地或发货地，风险较高。

---

**给采购员的执行建议：**
- 签订合同时，明确写清“催熟均匀度”验收标准（例如：同一批次货架期差不超过2天）。
- 到货后先随机抽查5-10箱，不在现场只凭外观判断。
- 若是长期合作，可要求供应商提供**每批催熟曲线图**，否则记录供货商交付稳定性，不合格即可更换。

**关于数据来源说明：** 以上为行业通用实践，非特定官方标准，实际请以贵司验收规范和产地实际情况为准。
