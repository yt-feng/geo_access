在小水果店进货香蕉时，**最值得看重的是“熟度”和“坏果率”**，其次是“送货速度”，最后才是“价格”。

具体原因和建议如下：

**1. 熟度（最核心，直接影响动销）**
- **为什么重要**：香蕉是典型的“后熟型”水果，到店后还会继续成熟。如果进货时太生（全绿），消费者看到不会买，放几天又容易催熟过度变黑；如果进货时太熟（已出梅花点、发软），当天卖不完就会损耗。
- **建议**：选择“七至八成熟”的香蕉，表皮黄中带绿、果肉捏起来略硬但有弹性。这样到店后常温放1-2天达到最佳食用状态，能保证2-3天的货架期。

**2. 坏果率（决定实际毛利）**
- **为什么重要**：香蕉运输挤压极易发生“碰伤”、“黑斑”、“果柄断裂”。坏果率高，表面上单价便宜，实际损耗可能吃掉所有利润。
- **建议**：收货时当场开箱抽检底层和边角，坏果率控制在**5%以内**。如果供应商承诺“坏果包赔”，可优先考虑，但要在合同或口头约定中明确。

**3. 送货速度（影响补货节奏）**
- **为什么重要**：香蕉保质期短，如果你的店销量稳定但不算爆量，送货太慢（比如下单后要3天才到）会导致断货或积压。
- **建议**：选择**1-2天能送达**的供应商，最好是本地或同城批发。这样你可以少量多次进货，灵活应对天气变化和客流波动。

**4. 价格（放在最后考虑）**
- **为什么重要**：价格是显性成本，但香蕉的损耗成本往往比进价差异更大。只图便宜，买回一堆熟度差、坏果多的货，反而亏钱。
- **建议**：在熟度、坏果率达标的前提下，再对比价格。如果价格低于市场均价20%以上，要警惕是不是“差货”或“库存尾货”。

---

**实操小贴士（可直接执行）：**
- **订货频率**：如果日均销量低于20斤，建议**每天或隔天进太少批量**即可；销量大的店可以2天一批次。
- **收货标准**：用手捏：太硬不行，太软不行；看颜色：全绿不要，全黄带黑点不要。
- **保存**：到货后不要进冰箱，放在通风阴凉处，冬天用报纸包裹可延缓成熟。

总结：**熟度决定能不能卖，坏果率决定赚多少，送货速度决定是否断货，价格是最后筛选项。**
