在旺季备货，最重要的就是“稳”字当头。和供应商谈合作时，建议提前把**供货稳定性、价格波动、质量责任**这三大核心问题问透。为了帮您更有条理地谈判，我按合作周期给您梳理了一套可以直接照着问的问题清单：

### 第一阶段：合作前（摸清对方“底牌”）

1. **供货能力与周期：**
   - “旺季高峰期，您每天/每周能稳定供应多少斤？如果我要加急补货，最快要多久能到货？”
   - “如果有大客户和水果店同时抢货，您的供货优先级怎么安排？”
   *（核心目的：确认对方产能上限，防止中途断供。）*

2. **价格与结算机制：**
   - “价格是随行就市，还是可以签订保底价？如果市场行情大涨，涨价的触发条件是什么？”
   - “结算是现结、周结还是月结？旺季资金压力大，能否申请部分账期？”
   *（核心目的：避免旺季突然大幅涨价，导致你被动亏损。）*

3. **品质与损耗标准：**
   - “旺季高峰期，您的残次果比例标准是多少？（例如：水分流失、磕碰率≤5%？）”
   - “如果送来货我验货发现质量不达标，是当场退货，还是可以按比例折价？”

### 第二阶段：合作中（旺季应急“保命”问题）

4. **缺货与应急预案：**
   - “如果产区出现极端天气（如台风压减产），您那边大概会缺货几天？有没有备选产区或者替身品种？”
   - “如果遇到突发爆单，您能否提供‘保量优先’的特别通道？”

5. **物流与损耗责任：**
   - “物流是自提还是送货上门？如果是冷链车，到了发现冻伤或压烂，这个损耗算谁的？”
   *（核心目的：明确**在途损耗**的责任划分，旺季物流压力大，这条特别容易扯皮。）*

### 第三阶段：旺季末期（收尾与长期合作）

6. **尾货处理：**
   - “旺季末尾剩的尾货，能否支持退货或调换成其他好卖的品种？”
   *（核心目的：防止你压了一堆过季水果卖不掉。）*

7. **长期绑定优势：**
   - “如果我们全年都在你这拿货，旺季你能给我优先排产权和更低的结算价吗？”

---

**💡 给您的额外提醒：**
在正式合作前，**不要只看报价单**。建议您先小额试单，或者在谈判时要求对方在合同里写明：“**若因供方原因导致断货，需按日赔偿门店预估损失**”。同时，建议您**同时维护2-3家备选供应商**（哪怕价格贵一点），旺季断货一天损失的客流，远比省下的那点差价多得多。

您如果是第一次合作，追问时还可以补充问一句：“您工厂的质检报告和最近批次的进货单能给我看一下吗？”——这条能帮你快速筛掉二道贩子和皮包公司。祝您旺季生意火爆！如果还有其他具体合同条款需要帮您把关，随时告诉我。
