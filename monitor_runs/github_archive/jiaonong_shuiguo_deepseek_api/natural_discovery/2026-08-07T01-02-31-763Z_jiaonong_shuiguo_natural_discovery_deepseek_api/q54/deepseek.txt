在采购香蕉用于烘焙蛋糕时，**成熟度应优先于价格**，价格是次要因素。原因如下：

1. **风味与质地**：烘焙蛋糕需要香蕉的天然甜味和香气，过生的香蕉（青绿色）水分少、淀粉多，烤出来的蛋糕口感发涩、不香甜；过熟的香蕉（表皮全黑、果肉发软）虽然香气浓郁，但水分过多，可能导致蛋糕糊过稀、内部湿黏。最佳状态是**表皮出现棕色斑点（即“香蕉点”），果肉软糯但不流汁**，此时糖分和风味最集中。

2. **成本与损耗**：如果只看价格采购过生或过熟的香蕉，烘焙后的成品品质不稳定，可能导致返工或客户差评，反而增加隐性成本。成熟度合适的香蕉虽然单价可能稍高，但出品率和一次成功率更高。

**具体执行建议**：
- 采购时，选择**表皮黄中带少量黑斑、捏起来微软但不塌陷**的香蕉（成熟度约80%）。
- 如果当天必须用，可以采购全熟（表皮黑斑较多）的香蕉，但需减少配方中的液体量（如牛奶或水）。
- 如果提前1-2天采购，可选稍生一点的香蕉，放在室温下自然成熟，避免冷藏（冷藏会破坏风味）。

**价格谈判技巧**：可以告诉供应商，你不需要品相完美的香蕉（表皮有斑或轻微碰撞不影响），通常这类香蕉会有折扣，但你要确保其内部成熟度达标。这样能在价格上适当争取优惠，但底线是**不因价格牺牲成熟度**。
