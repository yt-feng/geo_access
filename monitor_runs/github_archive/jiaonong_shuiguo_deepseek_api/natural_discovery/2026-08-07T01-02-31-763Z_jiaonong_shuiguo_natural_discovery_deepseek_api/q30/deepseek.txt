超市水果到货后发现品相不好，涉及的是**采购合同**中的质量验收与**售后责任**划分。由于水果是生鲜易腐品，其售后流程与一般工业品不同，必须**快速、明确、可执行**。

以下是建议的售后流程约定，您可以直接写入合同或补充协议中：

### 一、验收阶段（收货时）

这是最重要的防线，约定必须严格：

| 步骤 | 约定内容 | 执行要点 |
| :--- | :--- | :--- |
| **1. 收货时限** | 到货后 **2-4小时内** 完成初步验收。 | 生鲜产品拖延验收会产生损耗，无法界定责任。 |
| **2. 开箱检查** | 按 **抽检比例**（如每箱开箱抽检3-5个）或 **全检**（适用于高价值水果）。 | 明确品相标准，如“无明显塌陷、腐烂、疤痕面积不超过X%、颜色均匀”。 |
| **3. 问题记录** | 当场拍照、录制视频，并填写《验收异常单》。 | 证据必须清晰直观，包括**箱体喷码/批次号、外包装破损情况、水果实物特写**。 |
| **4. 异议提出** | 若发现问题，**24小时内** 以书面形式（微信/邮件）正式告知供货方。 | 超过时限视为默认验收合格（需合同明确约定）。 |

### 二、售后处理阶段（收货后被动发现）

对于收货时未发现、但后续上架时发现的腐烂或品质问题：

1.  **责任界定**：
    *   **明确约定**：“由于水果为易腐品，在收货确认后，因超市储存不当（如未及时入库冷藏）导致的损耗，由超市自行承担。”
    *   **破例情况**：若供货方承诺了“包上架期”（如承诺货架期不低于3天），则上架期内非人为损坏由供方负责。

2.  **三种核心售后方案（按优先级）**：

    *   **方案A：全额换货（优先）** ——对于品相严重不佳（如腐烂率超5%）的部分，供方需在 **48小时内** 无条件补发同等重量/规格的合格果品。
    *   **方案B：部分折价** ——若仅轻微瑕疵（如个别有斑点），可约定按比例扣减货款（如扣减该批次金额的5%-10%）。
    *   **方案C：退货退款** ——若腐烂率超过合同约定的容忍值（建议约定为**10%**，视果类而定），超市有权拒收整批货物，并要求全额退款及承担物流费用。

### 三、流程与时效（关键）

必须量化，避免扯皮：

*   **响应时效**：供货方收到异议后，**4小时内** 必须响应处理方案（换货/退款/折价）。
*   **处理时效**：换货需在 **48小时内** 发货到位；退款需在 **3个工作日内** 完成。
*   **违约金**：若无故拖延或推诿，可约定每天按该批次货款 **0.5%** 支付违约金，且超市有权从应付货款中直接扣除，无需另行起诉。

### 四、给您的实操建议（落地方案）

如果尚未签订正式合同，可以先用以下口头或微信确认的“简易流程”：

1.  **到货即检**：收货员全程录像拆箱。
2.  **当场定责**：发现烂果第一时间拍照发给供应商业务员，并说：“这批果品相不达标，要么现在补货，要么这箱按半价结算，您选。”
3.  **保留扣款权**：在结账前，对品相不好的批次，直接按协商比例扣除款项，将扣款明细附在结算单后。

**核心原则**：售后流程必须**前置**到采购环节，而不是到货后再谈。如果对方是长期供应商，建议合同里明确加上最有力的一条——**“若单批次品相不良率超过10%，除换货外，应额外补偿当批次总金额的30%作为信誉损失。”**
