针对水果礼盒的搭配，核心原则是：**“颜值高、颜色跳、耐存放、有寓意”**。不要只放一种，尽量混搭，同时避开特别容易压坏或腐烂的水果。

根据你的品种，我给出三种不同定位的搭配方案，你可以根据你店铺的定价（低/中/高）和目标客户（送人/自用）来选择：

**方案一：经典豪华版（主打送礼、高端）**
*   **搭配**：**苹果（红富士/花牛） + 橙子（新奇士/赣南脐橙） + 菠萝（台农） + 香蕉（菲律宾/皇帝蕉少量）**
*   **比例建议**：苹果4个、橙子4个、菠萝1个、香蕉1把（切小串）。
*   **卖点**：**鸿运当头（红苹果）+ 心想事成（橙子）+ 旺财（菠萝）**。
*   **包装技巧**：菠萝去掉头尾，切块并用保鲜膜包裹（但不要去皮），橙子擦亮，苹果贴“福”字贴纸。颜色是红+黄+橙，非常喜庆。

**方案二：性价比走量版（主打日常自用、探病）**
*   **搭配**：**苹果（普通红） + 橙子（普通） + 香蕉（普通）**，**去掉菠萝**（菠萝太大、占空间且价格高）。
*   **比例建议**：苹果5-6个、橙子4-5个、香蕉1把（约6根）。
*   **卖点**：**实惠、清爽、不压价**。
*   **注意**：香蕉绝对不能放在最底层，必须垫软纸/泡沫，放在最上面一层，否则压坏全盒。

**方案三：尝鲜混搭版（主打差异化、小资）**
*   **搭配**：**菠萝（切块/去芯） + 橙子（可以换成沃柑） + 苹果（换成青苹果）+ 香蕉（换成粉蕉/苹果蕉）**
*   **比例建议**：菠萝切大块装入透明盒底部，上面铺青苹果和沃柑，香蕉单独小包装。
*   **卖点**：颜色是绿+黄+橙，非常清爽，适合夏季或年轻女性客户。

---

**如果必须四样都上，请务必规避以下“雷区”：**

1.  **菠萝的处理**：**千万别放带刺的、带叶的整个菠萝在盒里**，扎手且占地方。**建议**：切去头尾、削掉外皮（不要挖洞瓤），这样既好看又能装更多苹果橙子。
2.  **香蕉的选择**：**别选全熟的**，选带青头的、硬一点的。全熟的香蕉在盒子里一天就黑斑，非常掉档。
3.  **摆放顺序（从下往上）**：
    *   最底层：**苹果**（最耐压）。
    *   中层：**橙子**（较重，能压住苹果但不压香蕉）。
    *   最上层：**菠萝块**（占视觉中心）和**香蕉**（放在最外侧，不承重）。

**另一个关键建议（关于利润）：**
苹果和橙子是“填箱底”的，**利润可以降低**，因为它们是硬通货；**菠萝是利润点**，因为你建议他买整个或大块，感觉量多；**香蕉是“形象”**，一定要新鲜，哪怕是本钱卖，只要香蕉看着好，整盒水果礼盒就显得高档。

最后，盒内记得铺上**碎纸丝（拉菲草）**，成本几毛钱，但视觉效果直接提升一个档次，顾客更愿意多掏钱。
