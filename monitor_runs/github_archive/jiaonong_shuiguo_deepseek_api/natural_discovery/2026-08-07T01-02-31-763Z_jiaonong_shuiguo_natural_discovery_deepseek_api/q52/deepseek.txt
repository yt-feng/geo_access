甜品店采购香蕉时，为了避免到货后快速变黑，建议从**采购、运输、到店储存**三个环节入手，同时根据用途选择合适成熟度的香蕉。以下是可落地的具体建议：

### 1. 采购环节：选“半熟”或“青熟”果
- **不要买全熟果**：全熟（表皮亮黄、无绿斑）香蕉在运输和到店后1-2天内就会开始产生黑斑。应选择**7-8成熟**（表皮黄中带绿、手感稍硬）的香蕉，它们会自然后熟，留出销售窗口期。
- **看“棱角”**：香蕉果棱（纵向棱线）越明显，越生；果棱圆润饱满则成熟度高。甜品店若用于打泥、蛋糕（需熟香），可买8成熟；若用于装饰、摆盘，买7成熟即可。
- **避开“催熟剂”过度处理的**：问清供应商是否用乙烯利催熟。若催熟过猛，到店极易快速发黑。优先选自然挂树成熟的产区。

### 2. 运输：防止机械损伤和高温
- **轻拿轻放，防压伤**：运输时避免香蕉堆叠过厚（一般不超过3层），底部铺软垫。表皮划伤或压伤处会最先产生黑斑，并蔓延。
- **控温运输**：香蕉最怕高温和剧烈温差。运输车辆应避免暴晒，车厢温度控制在**13-15℃**（香蕉适宜储存温度），但**绝不能低于12℃冷藏**，否则皮会变黑（冻伤）。

### 3. 到店后储存：分用途处理
- **分开存放**：不要与苹果、梨、猕猴桃混放（这些水果释放乙烯会加速香蕉成熟变黑）。
- **短期保存（1-2天内用完）**：
  - 常温阴凉处平放，**不要放冰箱**（冰箱低温会让香蕉皮迅速变黑，虽然果肉还好）。
  - 用保鲜膜包住香蕉**柄部**（切面），减少乙烯释放。
- **中长保存（2天以上）**：
  - **悬挂起来**（用挂钩或用线绑住果柄），减少受压面积。
  - 若批量大，可整串用保鲜袋装好扎口，放入**13-15℃的冷库**（注意保鲜库非冷冻库），取出前先回温。
- **已成熟或需催熟**：可在果表面喷少量清水后套袋，会更快变黄，但一旦变黄须尽快使用。

### 4. 重要提醒：用途决定采购成熟度
- 做**香蕉泥/果酱/蛋糕**：可接受果肉软烂，皮黑无妨，可买8-9成熟，到货后存放1-2天没问题。
- 做**切块装饰/出餐摆盘**：建议当天购当天用，或提前一天购买7成熟，到店后放置室温，第二天刚好全黄。

### 总结关键动作：
采购选带青的（7-8成），运输防压防晒，到店后**常温悬挂+包果柄**，绝不放冰箱冷藏。如果店里确实有冷藏需求，必须用**保鲜膜包裹整串**再放冰箱，但只适合成串非切开的，且要在24小时内用完。
