针对茶饮店水果口味波动的问题，**建议在核心品类（如柠檬、橙、芒果等）上固定长期合作产地，并锁定供应批次；对非核心水果（如季节性莓果）则允许灵活更换，但要设置统一的验收标准和品控流程。**

以下是具体操作建议，可根据你的门店规模和成本结构来调整：

**1. 核心水果：固定产地 + 锁定批次（推荐优先执行）**
- **为什么**：不同产地的同种水果（如香水柠檬）在酸度、香气、甜度上差异巨大，直接决定饮品口味。固定产地能最大程度保证风味稳定性。
- **怎么做**：
  - 与源头农场或一级批发商签订**年度框架协议**，明确产地、品种（如“云南高山柠檬”而非笼统的“柠檬”）。
  - 要求供应商**分批次供货**，每批附上产地证明和采摘日期。到货后，品控人员要对每批样品进行**糖度测试（用折射仪）和酸度试纸检测**，达标才收货。
  - 如果担心批次间有细微差异，可要求供应商**提供连续批次的混合拼配**（例如将同产区一周内的多批果混匀），减少单一批次波动的影响。

**2. 非核心水果：固定验收标准 + 稳定配方兜底**
- 对于季节性水果（如杨梅、草莓），产地和批次变动不可避免。此时不要追求“一个口味的绝对稳定”，而是**规定“可接受的风味区间”**。
- **怎么做**：
  - 制定**采购SOP**：比如“草莓要求可溶性固形物≥10%，酸度≤1.2%，无烂果比例≤2%”，无论哪个供应商，不达标就拒收。
  - 在配方上预留**调整空间**：例如糖浆比例、果酱用量可依据酸度在±5%范围内微调（门店操作手册中注明换算公式）。
  - 不要频繁更换供应商，至少为每种水果保留**2个备选供应商**，并且每次更换前强制进行小批量试制（如做3杯招牌饮品），由店长和研发共同确认口味偏差可接受后才批量订货。

**3. 供应链管理技巧（重实操）**
- **批次追溯**：每批到货贴标签记录“供应商-产地-到货日”，便于口味异常时快速定位问题批次。
- **“以存定采”**：根据每日销量预估，要求供应商提供**最小订货量**（如每批200kg起订），避免因频繁跨批次采购导致口味混乱。
- **备选方案**：如果某批次到货后发现酸度过高，可立即启用“备用果源”（如提前约定好同城另一家批发商可紧急调货），同时将这批水果转入“制果酱”用途（加热可抑制过酸），不直接用于鲜果茶。

**4. 例外情况处理**
- 若门店客流量大且追求极致稳定，建议**在季节转换期（如冬果转夏果）提前1个月**要求供应商提供新品种测试，并同步储备上一季节的冷冻果（部分水果冷冻可保留风味7-14天），作为过渡期“防御库存”。
- 对于无法立即检测的指标（如香气），建议**建立“盲测打分卡”**：到货时店长和1名员工盲闻/盲尝，按1-5分评分，连续两个批次低于3分则触发供应商更换流程。

**总结**：固定产地+批次不是目的，而是手段。真正要建立的是“**品控标准+预警机制+纠偏流程**”。如果成本允许，核心水果固定产地；如果成本压力大，至少固定“风味阈值”和“供应商黑名单制度”，用可量化的检验数据替代“感觉差不多”的经验判断。
