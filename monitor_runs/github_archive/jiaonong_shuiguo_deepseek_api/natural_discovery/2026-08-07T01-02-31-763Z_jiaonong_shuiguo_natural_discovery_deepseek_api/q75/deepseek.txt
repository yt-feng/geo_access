批发商第一次与水果供应商合作，风险主要集中在**品质不稳定、缺斤短两、售后难**三个方面。试单的核心目标不是省钱，而是**用最低的试错成本，摸清对方的履约底线**。

以下是具体的设计方案，按流程拆解：

### 1. 品类与数量：单品类、小规模
- **选1-2个主销单品**，不要一次性上几十个品。比如只定苹果或只定柑橘。
- **数量控制**：建议为日常订货量的**10%-20%**，或者一个**托盘/整车**（如果是冷链车），大约几百斤到一两千斤。如果是高端果或进口果，可以只批2-5箱。
- **目的**：确认该品类在对方基地或市场的**稳定货源能力**，以及分选包装水平。

### 2. 规格标准：白纸黑字写清楚
- **克重/果径**：明确一级果、二级果的标准（例如：果径80-85mm，重200g±10g）。
- **甜度/成熟度**：如果是可测的，要求提供测糖仪数据；如果不能测，约定“硬熟”（便于运输）或“即食”状态。
- **瑕疵率**：约定“次果率不超过X%”（一般批发标准是5%以内）。
- **包装**：确定是纸箱、塑料筐还是冷链包装，注明**净重**还是毛重结算（必须要求净重）。

### 3. 结算方式：先款后货？还是预付+尾款？
- **第一次合作**：建议**预付30%-50%定金**锁定货源，尾款在**货到验收合格后24小时内结清**。
- **坚决避免**：全额预付（风险太高）或纯赊账（对方不一定会当真）。
- **付款凭证**：对公转账，注明“XX水果试单定金”，保留聊天记录。

### 4. 物流与验收：到货即验，三小时内反馈
- **物流**：明确是对方发货（运费谁承担），还是自己找车。如果是整车，要求**封签**，并拍照发货。
- **验收节点**：
  - 货到后，**先查冷链温度**（如果有冷链）。
  - 开箱前**全程录像**，开箱后**称毛重、净重**（抽查几个箱）。
  - **拍照记录**：外箱破损、内部果实坏果、规格不符。
- **超时条款**：到货后**2-4小时内**未反馈问题，视为验收合格（防止对方做手脚）。

### 5. 售后与赔付条款（试单的核心）
- **坏果/次果**：约定“次果超过5%的部分，按重量折价或补货”。
- **缺重**：若实际净重低于标称净重2%以上，直接扣款。
- **品质不符**：例如果径严重偏小，整批按**降级价**结算或拒收（需提前约定）。
- **赔付时效**：书面确认问题后，最长**72小时内**给到赔偿方案（补差价或下次订单抵扣）。

### 6. 额外测试项（可选）
- **抽检第三方检测**：如果不放心农残，花几十块钱送检一个样品。
- **时间测试**：看货架期，常温下放2-3天，观察腐烂速度，评估其采摘成熟度控制。

### 7. 小贴士（避坑指南）
- **视频见证发货**：要求发车时拍一段装车视频。
- **不要怕麻烦**：把上述条款简化成一张**《试单采购确认单》**，拍照发微信给对方确认，这比口头承诺靠谱得多。
- **留意“尾货”**：如果对方报价明显低于市场价（比如低20%），大概率是尾货或次果，不要贪便宜。

---

**总结一句**：试单就是“用小钱买大信息”，如果这次合作出现了小问题且解决速度快，那就是好供应商；如果故意拖延或者隐瞒，果断止损换人。
