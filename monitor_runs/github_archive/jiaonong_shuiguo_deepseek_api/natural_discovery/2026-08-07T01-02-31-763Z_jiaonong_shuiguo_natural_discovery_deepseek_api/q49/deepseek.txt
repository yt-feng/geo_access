针对茶饮店旺季菠萝用量突然暴增的情况，临时补货的核心在于**锁定价格、明确交付时效、规避品质风险**。建议按以下步骤和话术与供应商沟通：

### 1. 先明确内部需求再谈判
- 核算日均新增用量：估算旺季持续多久（如2周），每日新增多少公斤。
- 明确品质要求：是要鲜切菠萝（去皮去芯）、整果，还是冷冻菠萝丁？不同形态价格和补货周期差异大。

### 2. 谈判要点（逐条确认）
- **价格保护**：旺季原料通常涨价，提前约定“按上月基础价上浮不超过X%”或“一口价锁死本周”。
- **交付时效**：要求明确“下单后X小时内送达”或“固定每日X点前送到门店”。
- **损耗兜底**：菠萝易腐，务必约定“到货验收不合格（发黑、过熟、腐烂）当场拒收或24小时内退换”。
- **安全库存**：建议每天保持1.5天的安全库存，避免断货。

### 3. 可用的沟通话术模板
> “王老板，这两天菠萝销量涨得特别快，预计接下来两周每天需要多加XX公斤。您那边库存够吗？能不能按这个量每天稳定送？价格方面，如果按长期合作价，我们可以签个短期补充协议，另外到货如果有烂的，我这边直接拍照给您，当天补新的，您看行不行？”

### 4. 实操防坑提醒
- **先小批量试单**：如果换新供应商或新产地，先订2-3天的量，验证品质和物流。
- **签书面/微信确认**：即使是口头约定，也请对方在微信或合同中回复确认“数量、单价、送货时间、退换条款”，避免旺季扯皮。
- **备选方案**：如果原供应商产能不足，可同步联系1-2家本地批发市场档口或同城农产品配送公司，作为应急替补。

### 5. 常见陷阱
- 对方说“有货但贵”但迟迟不锁价 → 旺季后期可能翻倍。
- 承诺“早上送”结果下午到 → 必须约定违约金或折扣。

**简单总结**：先算量，再锁定“价格上限+当天送达+坏果包赔”，并留好书面凭证。如果旺季持续超过1个月，建议直接增加第二个供应商分摊风险。
