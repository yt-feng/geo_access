水果店采购香蕉时，如果一箱里面大小不一样，**会影响销售，但这种影响是可控的，具体取决于你的销售定位和经营策略**。以下是具体分析和建议：

**1. 影响主要有这几方面：**
- **视觉观感**：顾客购买时通常喜欢整齐划一、大小均匀的香蕉，大小混装容易显得“卖相”杂乱，可能降低购买欲望。
- **定价和称重**：不同大小香蕉口感、成熟度往往有差异。小香蕉偏甜软，大香蕉偏脆硬。若混装，顾客可能觉得“挑不到满意的”，而且按统一价格卖，心理上可能觉得“大的划算，小的吃亏”。
- **损耗风险**：大小差异常伴随成熟度不一致（如一箱里有的快熟烂了，有的还生），这会导致售出时部分香蕉过熟或未熟，容易造成烂果损耗，影响利润。

**2. 如果你做零售（散卖）**：
- 建议分开销售。按大小分成“大果”和“小果”两个价位或两个框。大果可以稍微贵一点，小果便宜一点，反而能满足不同顾客的需求（例如爱做香蕉奶昔的客人喜欢小果）。
- 如果不分开，最好在进货时就要求供应商提供“级果”（分拣过、大小较一致的箱装），虽然单价略高，但损耗低、卖相好、回头客多，长期更划算。

**3. 如果你做批发或承包单位供应**：
- 影响相对小，因为买家（食堂、水果捞店）通常按斤购买且不挑剔外观。但如果你面向超市或社区生鲜店，他们通常也要求分拣过。

**4. 实际操作建议**：
- **进货时沟通**：主动问供应商“这箱是混装还是分拣过的？”要求对方尽量提供大小均匀的，哪怕贵一点。
- **到店分拣**：即便进了混装箱，拆箱后花10分钟把明显过大或过小的挑出来，按批次卖，或者把零星小果做成“特价促销”或“试吃装”。
- **成熟度管理**：大小混杂时，注意把已经八成黄的挑出来先卖，以免大果未熟小果先烂。

**总结**：大小不一确实会影响零售销量和顾客满意度，但通过分拣、分级定价、按需促销，完全可以转化为价格层次优势。核心原则是**不让顾客觉得“脏乱差”或“吃亏”**，让大小差异变成“多一个选择”而不是“品质问题”。
