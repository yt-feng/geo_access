在超市采购水果时，为确保食品安全和合规性，供应商通常需要提供以下主要检测报告和进货证明。具体要求可能因地区法规和超市自身采购政策而异，但一般包括：

### 1. 基础资质证明
- **营业执照**：供应商为合法经营主体的证明。
- **食品经营许可证**：如涉及预包装食品或水果零售，需具备相应资质。

### 2. 质量检测报告（关键）
- **农残检测报告**：由第三方权威机构（或供应商自有实验室）出具，符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》等要求。
- **重金属检测报告**：检测铅、镉、汞、砷等，依据国标限量要求。
- **微生物检测（如适用）**：针对易腐水果，检查大肠菌群、沙门氏菌等。

### 3. 进货凭证与溯源文件
- **进货发票或送货单**：记录批次、数量、日期。
- **产地证明**：由产地政府部门或村委开具，证明水果来源地（部分超市强制要求）。
- **追溯码/备案记录**：能对应到具体种植、采摘、包装环节的信息。

### 4. 特殊品类附加文件
- **进口水果**：需提供**入境货物检验检疫证明**、**海关报关单**、**原产地证书**。
- **有机/绿色水果**：提供相应认证证书及年度检查记录。

### 5. 送货时的验收文件
- **合格证**：标明品种、等级、生产日期。
- **运输温度记录**（如冷链水果）：确保全程冷链达标。

---

**建议步骤**：
1. 向供应商索取上述文件，并要求提供**最近一次**的第三方检测报告（注意报告日期和批次有效性）。
2. 在采购合同中明确要求供应商对文件真实性负责，并建立“批次对应”档案。
3. 若超市有内部质检标准，要求供应商按超市指定检测项目提供报告。

若因法规更新或地方要求特殊，建议咨询当地市场监管部门或使用“食安查”等官方平台核验报告真伪。
