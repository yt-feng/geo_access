判断批发档口的香蕉货源是否稳定，可以从以下几个维度进行实操性验证，避免“首单低价、后续断供”的坑：

**1. 看货源基地资质与规模（最核心）**
- **产地证明**：要求对方提供**香蕉种植基地的备案号**（如广西、云南、老挝、缅甸等主产区的出境/内销检验检疫证明），或海关/农业部门的产地注册编号。正规基地会主动出示。
- **基地面积**：问清“基地实际种植面积是多少亩？分几块区域？”。若对方只说是“基地”，但面积含糊、说不出具体坐标，多为二手贩子。
- **采收批次**：稳定的基地通常有**排产计划**，可问“本月预计能出多少柜（货柜）？每周几车？”。有计划的才敢承诺“随时有货”。

**2. 渠道层级测试（试单法）**
- **小批量试单**：先订1-2吨（或少量箱），要求**次日或48小时内必须到货**。若试单时能准时、足量、质量稳定，才考虑长期合作。
- **断供压力测试**：故意提出“下周需要追加50%的量”，看对方反应。真一手货源会说“可以，但需要提前3天锁单”，假货源则会找借口推脱或说“等下个月”。

**3. 价格与结算方式合理性**
- **价格对比**：当日产区收购价（如广西香蕉约2.5-3.5元/斤，视品级）+运费+合理利润（约10%-15%）。若对方报价远低于市场价且量还很大，大概率是“先用低价吸引，再以涨运费、涨包装费”补回来。
- **结算方式**：优质一手货源通常**支持“货到付款”或“尾款3天内结清”**，不会强制“全款预付”。若坚持“先全款再发货”，警惕卷款风险。

**4. 硬性凭证核查**
- **运输合同**：要求对方提供与物流公司的**运输合同或承运单**（上面有发货地、收货地、车牌号）。
- **产地收购记录**：正规货源能提供基地的**过磅单、冷库出入库单据**（显示连续批次的重量、时间）。
- **营业执照经营范围**：查看营业执照上的经营范围是否含“水果种植、批发”，若只有“销售”，说明是中间商。

**5. 实地或视频核验（强烈建议）**
- 若对方说基地在云南，可要求**视频连线拍一下冷库**，看有没有“正在装柜”的实景，或者要几张**与你聊天时间吻合的基地照片**（发图时间戳可验证）。
- 若量大，可派专人**到产地冷库蹲点1-2天**，看是否连续有车进出。真一手货源的基地每天都有装卸作业。

**6. 行业口碑与替代方案**
- 向当地批发市场同行打听：“这个档口在行业里做了几年？有没有断供记录？”一般老档主不会为蝇头小利砸招牌。
- 反向验证：联系2-3家其他批发商，问他们能否提供同品质、同价格的货。若其他人都说“这个价做不了”，那此报价很可能有水分。

**关键提醒：**
- **宁签短期合同**：首个合作周期签15天/30天，约定“甲方无法供货需提前5天告知，否则赔付违约金”，用合同约束稳定性。
- **警惕“今天打款明天发”**：真一手货源通常需要提前1-3天下单排产，当天要大量现货的多为存货商。

如果对方在以上5个环节中，有3个以上回答模糊或避开核心问题（尤其产地备案号、可否视频看货），基本可判断为不稳定供货商，建议换人。
