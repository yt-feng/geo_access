针对水果店减少香蕉损耗的问题，采购时的核心原则是：**到货时香蕉应是“半熟或微黄带绿”状态，而不是全黄或软熟状态**。具体可以从以下几个可执行的维度向供货商提出要求：

### 1. 明确熟度等级（最重要的要求）
香蕉成熟度通常分为1-7级（国际通用），采购时要有明确的书面约定：
- **理想到货熟度**：要求 **3-4级熟度**（果皮整体绿色，但果体饱满，棱角分明，果皮开始转黄但绿底明显，约10%-20%面积泛黄）。
- **明确拒绝的熟度**：拒绝到货时 **5-7级**（即果皮全黄、果肉软化、甚至出现黑斑或裂果）。这种熟度在店里只能卖1-2天。
- **补充条款**：要求“果柄切口新鲜，无水渍发霉”，并注明“到货时若有20%以上果实已达到5级熟度，可拒收或折价”。

### 2. 到货时间（与门店周转周期匹配）
- **按日周转量定到货频率**：如果门店香蕉日销量为整箱的1/3，建议 **两天一送**，每次送2天的量。不建议一次性进一周货。
- **要求“今日订货，隔日早晨到”**：即要求供货商在**下单后24-48小时内送达**，而不是让香蕉在供货商冷库或运输途中多呆几天。这样能保证你拿到的是“刚出库的硬香蕉”。
- **避开节假日提前囤货**：明确告知供货商，平日按正常节奏送，遇到周末或节日如需加量，提前告知送达时间应比平时早半天（因为节日物流慢）。

### 3. 运输过程要求（减少催熟损耗）
- **冷链或恒温车**：要求使用 **10-15℃** 的恒温车运输，避免高温（>25℃）导致途中快速成熟，也避免低温（<8℃）造成皮黑肉硬。
- **封箱要求**：要求成箱香蕉内不放催熟剂（如乙烯利），如果供货商通常会在运输前催熟，必须要求**运输中不催熟，只做防腐处理**。
- **货损责任**：注明“运输超过24小时未送达导致的黄熟、软损，由供货商承担”。

### 4. 验收与拒收标准（现场执行）
- **验收时做抽样检查**：开箱后随机抽取3-5根，看果皮颜色和硬度，若已有“黄底大面积、手指按下去发软”的情况，当场退货。
- **留一个“缓货”条款**：要求供货商允许你 **退货或换货的比例为总货量的10%以内**（因为运输不可控），防止到货全熟时你吃哑巴亏。
- **固定熟度等级标签**：要求供货商在外箱上标注“熟度等级”和“采摘日期”，方便你核对批次。

### 5. 给店内的后续建议（配合采购）
- **到货后先做“催熟隔离”**：如果偏绿（3级），放在常温库（20-22℃）自然熟，不要放冰柜；如果已经有些黄（4级），直接摆货架。
- **排序销售**：买回后按“先到先卖”原则，把本来熟的（4级）放上层，偏生的（3级）放下层，避免软熟的压坏生香蕉。

**总结一句话要求给供货商**：“我要的是到货时7成绿、3成黄的硬香蕉，你只要在我下单后36小时内送到，送到时超过20%已经软熟，这箱我不收。”
