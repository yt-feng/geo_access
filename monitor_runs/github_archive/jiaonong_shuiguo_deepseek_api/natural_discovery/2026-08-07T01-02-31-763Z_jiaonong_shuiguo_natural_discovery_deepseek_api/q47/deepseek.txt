在茶饮店采购香蕉时，控制熟度是保证饮品/甜品风味、质感和成本的关键。以下是具体建议：

### 1. 明确用途决定熟度偏好
| 用途 | 推荐熟度 | 表现特征 |
|------|----------|----------|
| 奶昔/冰沙/芭菲 | **8-9成熟** | 表皮有少量黑点，果肉软糯，甜度高，能自然增加顺滑口感和甜味，无需额外加糖 |
| 香蕉拿铁/茶饮顶料 | **7-8成熟** | 表皮基本黄色，果肉微软但不变黑，切片不塌陷，能保持形状但易搅打 |
| 香蕉蛋糕/烤布蕾 | **9-10成熟** | 表皮全黑斑，果肉非常软烂，甜味最浓，烤后香气突出（需当天用完） |
| 装饰切片/拼盘 | **6-7成熟** | 表皮全黄无斑，果肉紧实，切面不易氧化发黑，摆放时间长 |

### 2. 采购时的“看、摸、闻”三法
- **看皮色**：全绿=未熟，全黄有光泽=7成熟，出现稀疏黑点=8-9成熟，大量黑斑=过熟。
- **摸手感**：轻轻捏两端，整体微软且回弹快=恰到好处；捏下去有深印=过熟；硬邦邦=生。
- **闻气味**：有浓郁果香=成熟；无味=未熟；有发酵酒味=过熟。

### 3. 最稳妥的采购策略：**分批采购 + 梯度熟度**
不要一次性全部买同熟度。建议：
- **60% 买7成熟**：到店后常温（20-25℃）放置1天可达8.5成，第2-3天可用完。
- **30% 买8成熟**：当天或次日即可用。
- **10% 买6成熟**：作为储备，万一前两批卖完可应急，低温催熟。

### 4. 到店后的熟度管理（重点）
- **成熟速度**：香蕉成熟速度约每天0.5-1成（常温）。夏季快，冬季慢。
- **控制方法**：
  - 想**延缓成熟**：放入冰箱冷藏（但表皮会变黑，果肉仍可食用），或与其他水果分开存放（乙烯气体催熟）。
  - 想**加速成熟**：与苹果或梨同袋密封放置12-24小时。
- **每天晨检**：开档前把熟度超过9成的香蕉挑出，单独放冷藏区或当天优先用完（做奶昔/烤品）。

### 5. 门店实操细节
- 每次到货记录到货日期和熟度，贴标签（如“周三9成”）。
- 规定**切配时限**：切好的香蕉片在常温下超过15分钟会氧化发黑，需泡柠檬水或盐水（但会改变风味，不建议长期用），尽量现切现用。
- 每天打烊前，将即将过熟的香蕉做成**香蕉泥**冷冻（密封袋压平冷藏，可存3天），用于奶昔或甜品基底，减少损耗。
- 与供应商沟通：明确要求“到货7成熟”，并要求每箱抽检，若出现大量全绿或全黑可退换。

### 6. 供应商管理建议
- 选择能提供**分档熟度**的供应商（如专门做烘焙供应链的），而非只卖统货。
- 签订合同时写明“到货熟度7±1成熟”，到货抽检比例至少20%。

**总结**：不要赌运气，按用途分批买、梯度熟度管理、每天检查并动态调整使用顺序，就能把损耗控制在5%以内，同时保证饮品口感稳定。
