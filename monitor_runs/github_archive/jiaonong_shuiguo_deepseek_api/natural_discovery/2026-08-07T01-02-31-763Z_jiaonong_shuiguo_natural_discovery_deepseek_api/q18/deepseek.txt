在超市选购香蕉时，想避开“太生”或“太熟”，可以用几个可操作的方法：

**1. 看颜色，但不只看表面**
- **太生**：整把香蕉呈纯绿色、质地硬实、表皮无光泽。如果你计划当天或次日吃，这个状态通常还太生。
- **理想状态**：果皮呈鲜黄色，略带少量绿色斑点或轻微褐色雀斑（不是大面积黑斑），摸起来有弹性能轻微回弹。
- **太熟**：大面积黑色斑块、表皮发软变形、甚至渗出水分，或捏起来非常软塌（可能已接近发酵）。

**2. 捏两端，不看中间**
香蕉最有参考价值的部位是两端（果柄和果尖）。
- 如果两端摸起来硬且发绿 → 偏生。
- 如果两端发软、颜色发褐 → 偏熟。
- 判断标准是：**整体黄，两端略带一点弹性，但不要软到能轻易压扁**。

**3. 看果柄粗细和新鲜度**
- 果柄粗壮、颜色浅绿或带褐色是正常的；如果果柄断裂、发黑渗水，说明存放过久。
- 如果果皮上有大量霉点或绿色霉斑，不要买（内部可能已烂）。

**4. 针对当天吃的紧急性**
- 如果你今天就要吃 → 选全黄、无青绿、表皮有少量褐点的（此时甜度最高）。
- 如果你打算放2-3天再吃 → 选黄色为主、略带一点青绿或果柄微绿的（不要选全黄的，否则放几天会过熟）。

**小技巧**：即使买到稍生的香蕉，不要放冰箱（会变黑且僵化），常温存放1-2天即可熟化。如果买到太熟的，可以立刻剥皮切段冷冻，用来做奶昔或烘焙。

最后，如果超市允许，可以选散装而不是整把捆扎的，更容易挑出均匀成熟度的。
