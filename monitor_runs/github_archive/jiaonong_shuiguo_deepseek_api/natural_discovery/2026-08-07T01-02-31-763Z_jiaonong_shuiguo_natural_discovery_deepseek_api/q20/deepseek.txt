为社区超市寻找每日配送的水果供应商，需要综合考察以下关键条件，建议按以下维度筛选：

**1. 供应稳定与灵活性**
- **每日供货能力**：能否保证每天固定供货（含周末），且能根据你的销量波动（如促销日、节日）灵活加量。
- **品类丰富度**：常备国产、进口、应季和反季水果，避免单一品种断货。
- **替代方案**：遇到主产地天气或运输问题，是否有备选供货渠道。

**2. 品质与新鲜度**
- **损耗率**：要求供应商承诺到货损耗率（如≤3%），超出门店端自行承担部分要明确。
- **分拣标准**：是否按大小、成熟度分级，拒收烂果、裂果、过熟果。
- **冷鲜链路**：从采摘到送达的时间窗口（建议≤48小时），是否有全程冷链车运输。

**3. 价格与账期**
- **报价结构**：要求提供每日/每周报价单，明确含税价、到店价，是否随行情浮动（需约定调价规则）。
- **账期周期**：常见的日结、周结或月结，选择现金流压力更小的方案。
- **退换货条款**：对当日残次品是否能无条件换货或冲抵货款。

**4. 物流与配送**
- **送达时间**：最好在早晨开门前到货（如5:00-7:00），不耽误上架。
- **配送车型**：冷藏车（4.2米或依维柯）能否卸到店门口，是否需要你额外承担搬运费。
- **紧急响应**：是否支持临时补货（如周末突发客流），响应时长建议≤4小时。

**5. 资质与合规**
- **证照齐全**：要求提供营业执照、食品经营许可证、产地证明或质检报告（每批有追溯码更佳）。
- **源头可溯**：直采基地或一二级批发商，避免中间转手过多。

**6. 市场口碑与抽检**
- **同行推荐**：向附近餐饮或生鲜同行打听该供应商的准时率、服务态度。
- **试用期**：先签1-2周试供合同，重点观察损耗、缺斤短两和沟通顺畅度。

**7. 附加服务**
- **促销支持**：是否提供陈列建议、海报或试吃品。
- **结算简便性**：能否电子对账，减少单据往来。

**实操建议**：
- 同时对比3-5家供应商，让每家提供连续一周的报价和样本（如各送10kg试销）。
- 签订合同时明确违约金（如延迟到货扣款）、临时取消条款。
- 考虑与周边2-3家社区超市联合采购，提升议价权。

**风险提示**：警惕报价远低于市场价的供应商（可能以次充好），以及只强调“便宜”不提供质检报告的商家。首次合作尽量小额多频，再逐步加大供货量。
