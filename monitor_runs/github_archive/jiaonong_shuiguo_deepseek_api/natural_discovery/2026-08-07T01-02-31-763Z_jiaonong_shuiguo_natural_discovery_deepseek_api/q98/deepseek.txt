采购水果这类生鲜食材，无论是养老院还是医院，合规性和稳定性是核心。因为服务对象是老人或病患，食品安全和责任风险极高。以下是具体的判断维度和实操方法，按优先级排序：

**一、判断合规性（法律与资质硬门槛）**

1.  **查验营业执照与经营范围**：必须要求供应商提供有效期内的《营业执照》，且经营范围明确包含“新鲜水果批发/零售”或“食用农产品销售”。
2.  **食品经营许可证（关键）**：**绝对不能省略**。供应商必须持有有效的《食品经营许可证》。重点看许可项目是否包含“预包装食品销售”或“散装食品销售”。如果对方是大型批发商，还需查验其是否具备“冷藏冷冻食品”的贮存条件许可。
3.  **食用农产品合格证明（快检报告）**：每批次水果应能提供《食用农产品合格证》，或者每日/每周的农药残留快速检测报告（需有检测机构盖章或供应商单位章）。
4.  **索证索票制度**：要求供应商提供每一批次水果的进货凭证（来源产地证明）、检疫检验证明（进口水果需报关单及入境检验检疫证明）。
5.  **运输资质**：如果涉及冷链运输，需查验其车辆是否有《道路运输经营许可证》及冷冻冷藏运输条件。

**二、判断稳定性（供应链与履约能力）**

1.  **供应商规模与实体考察（核心）**：
    - 实地走访其分拣仓库或配送中心，看是否有恒温保鲜库、储存环境是否整洁、是否有虫鼠害防护设施。
    - 查看其上游采购渠道是否直接对接产地/基地，还是多层批发。直接对接的稳定性更强，价格也更有优势。
2.  **历史合作记录与拒单率**：直接索要其近3-6个月为其他医院/养老院/机关食堂供货的合同或送货单（可抹去敏感商业信息）。重点看**按时到货率**和**因缺货发起的换货通知频率**。
3.  **应急响应能力**：要求供应商明确承诺“当日下单、次日达”，并建立缺货时的**应急预案**（如同一城内的备选供应商名单）。在谈判中明确写进合同：若出现流行性水果断供，需在2小时内提供同品质的替代方案。
4.  **财务稳定性**：如果是长期合同，可要求查看其近一年的纳税证明或银行流水（部分敏感，可协商），降低因供应商倒闭影响供应的风险。

**三、实操建议（可执行的筛选流程）**

- **试运行期**：不要直接签一年长约。可以签1个月试用期合同，每天下单，重点观察**准时率、新鲜度（果皮无伤疤、无催熟迹象）、缺货率**。
- **建立双供应机制**：同一品类（如苹果）至少考察2家供应商，轮流下单，避免单一依赖。
- **明确验收标准写入合同**：合同内附“验收标准附件”，例如：
  - 外观：无腐烂、无压伤、无病斑；
  - 成熟度：需达到采摘后7-8成熟（可食率95%以上）；
  - 重量误差：单箱净重误差≤2%。
- **留样备查**：每批次送货，库管应留取少量样品并拍照留存，以备食用后出现疑似中毒等事件时溯源。

**四、警惕“低价陷阱”**

如果报价明显低于市场批发价（如低于当地批发市场指导价15%以上），大概率涉嫌以次充好（如用落地果、催熟果冒充）或虚报重量。医院和养老院的食品安全责任不允许用最低价中标的风险去赌。

**总结判断公式**：
**合规 = 证照齐全 + 合格证可追溯**
**稳定 = 实体可考察 + 有应急方案 + 有历史记录**

建议贵单位在招标或询价时，将以上条款作为《供应商准入评分表》的打分项。如果对方无法提供《食品经营许可证》或明确拒绝实地考察，**直接淘汰**。
