社区团购旺季爆单，提前锁定水果供应商库存的核心在于**“用合同买确定性”**，同时做好**“弹性补货”**准备。以下是可落地的操作步骤：

### 一、锁定库存的4个核心动作

1.  **签订保量框架协议（最重要）**
    -   不要口头约定，签署**《旺季保量采购协议》**，明确：旺季期间（如12月-2月），每周保底采购量（如5000件/周），以及爆单时供应商需优先保障的**最大产能**（如1万件/周）。
    -   **关键条款**：写明“若供应商无法履约，需按缺货金额的X%赔偿”，否则旺季供应商会优先给利润高的渠道。

2.  **支付定金或预付款（建立强绑定）**
    -   预付总货款的20%-30%作为**锁库定金**。明确注明这是“库存锁定预付款”，非“订货款”。
    -   如果担心资金占用，可以分批支付（例如首付15%，旺季前一周再付15%）。

3.  **锁定“次日达”的现货仓**
    -   要求供应商在本地或临近城市（车程5小时内）提前备好**基础安全库存**（比如锁定3000件），这些货属于你，放在他的冷库，你随时提货。
    -   同时明确**提货周期**：例如下单后24小时内必须装车，超时有滞纳金。

4.  **明确分级锁价机制**
    -   水果价格波动大，签合同时固定**“封顶价+浮动价”**：例如锁定量内按合同价结算，超量部分按“锁定价+当日市场价差额的20%”结算，避免供应商旺季涨价毁约。

### 二、应对爆单的弹性策略（防超卖）

1.  **设置“二供”备选**
    -   每个爆款水果，锁定主供应商（70%量），再找一个备选供应商（30%量）。旺季前测试备选供应商的打包和品质，避免主供应商缺货时手忙脚乱。

2.  **提前锁定“果切/加工”能力**
    -   如果爆单，时间来不及分拣，提前和供应商谈好**代分拣、代包装**服务（例如按件加收1-2元服务费），把人工风险转移给供应链端。

3.  **约定“缺货自动补位”机制**
    -   在合同中写明：若主供应商无法满足当日订单，**必须**在4小时内从周边基地调货补上，或者允许你直接从其合作的上游果园直发。

### 三、日常执行清单（务必提前2-3周启动）

| 时间 | 动作 | 关键指标 |
|---|---|---|
| 旺季前3周 | 下发锁定意向书，供应商确认库容 | 锁定量≥预估爆单量80% |
| 旺季前2周 | 打定金，签合同，开始备货 | 供应商仓库入仓量≥锁定量50% |
| 旺季前1周 | 全链路压测（下单、分拣、装车） | 单日发货能力≥预估峰值1.5倍 |
| 旺季每日 | **早上10点前**确认当日供需缺口 | 缺口>20%立即启动备选方案 |

### 四、避坑提醒
-   **不要全款锁死**：旺季行情变化快，全款锁死会导致你资金吃紧，且供应商品质下滑你无法制约。
-   **品质验收前置**：不是锁库存就不验收，旺季抽检比例要提高至20%以上，发现坏果率超标有权扣减货款并让供应商当日补货。
-   **动态数据跟踪**：每天统计各SKU的**售罄率**，售罄率>95%的品项，当天直接向供应商追加“临时加单”（加单不受合同保底量限制）。

**行动建议**：今天就把你的旺季预估销量（分SKU）发给出核心供应商，书面要求他们3天内回复“可锁定量和单价”，不要等到抢货时才去求人。
