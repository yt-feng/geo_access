与水果供应商签订年度合同时，以下几个条款最容易出现“踩坑”风险，建议您重点关注并逐条推敲：

**一、价格与调价机制（最容易扯皮）**
1. **“随行就市”的模糊定义**：若只写“按市场批发价结算”，后续供应商可能报高价。建议明确**基准价格**（如以某批发市场均价或某固定成本价为基准），并约定**调价触发条件**（如批发价涨幅超5%才可调价，且需提供凭证）。
2. **最低采购量**：年度合同若承诺“全年最低采购量”，需评估自身销售预测。一旦签了保底量，淡季可能积压库存，旺季又可能缺货。建议将最低采购量改为“分季度/月度可协商调整”。

**二、品质标准与验收（最常见纠纷）**
1. **等级标准要具体**：避免写“优质水果”，需列明**果径、糖度、成熟度、伤疤面积、农药残留标准**等可测量指标，并附上实物照片或样品。
2. **到货验收时限**：若未约定“到货后多少小时内必须验货并书面反馈”，供应商可能推诿。建议写**24小时内验收，超时视为默认合格**，但需允许抽样检测。
3. **腐烂/坏果赔付**：明确“途中损耗率”（如≤3%），超出部分由供应商承担，并规定赔付方式是补货、退款还是抵扣货款。

**三、交货与物流责任**
1. **延迟到货的责任**：写清“逾期每日按货值X%扣款”，并设置**合同解除线**（如累计迟到5次或单次迟到超2天）。
2. **运输风险**：若约定“货到验收”，运输途中损失是供应商的责任；若约定“装车即交接”，则超市担责。建议写明**货物风险转移点**（如装车、到达仓库验收、卸货完成）。

**四、付款与结算周期**
1. **付款期限**：明确“收货后X天内付款”，防止供应商要求“先付30%订金再发货”。若资金紧张，可协商“月结30天”，但需在合同中写清逾期付款的罚息（如每日万分之五）。
2. **以票付款**：规定“供应商须先提供增值税普通发票，超市再付款”，避免后续税务纠纷。

**五、独家供应与违约责任**
1. **独家条款**：若供应商承诺“只供你一家”，需约定**违约赔偿标准**（如赔偿全年采购额的20%）。若你发现自己拿到的货比同行贵，可据此索赔。
2. **单方解约权**：给超市留一个“无理由解约窗口”（如提前15天书面通知），否则一旦供应商质量异常，你被迫履约将非常被动。

**六、免责条款与不可抗力**
1. **天气、洪涝等**：水果受自然灾害影响大，建议约定“供应不足时，双方可协商调货，而非供应商直接违约”。但要写明“供应商需提供气象局证明或受灾照片”。
2. **极端市场**：若发生价格暴涨暴跌（如疫情封控），应允许**提前3天启动价格重新谈判**，否则僵局很难破解。
