判断供应商售后是否稳定，不能只听承诺，最好在合作前和试单阶段用可验证的动作去测。可以按下面几步做：

1. **先问清售后条款**
   - 坏果、短斤少两、成熟度不符、到货延迟分别怎么赔？
   - 响应时限是几小时？处理时限是几天？
   - 谁承担退换货运费？是否支持补发、扣款或下次抵扣？
   - 菠萝和香蕉的售后标准要分开写：菠萝看黑心、烂心、果眼霉变；香蕉看青熟度、压伤、催熟后不合格比例。

2. **合作前做一次小单测试**
   - 故意下一个小批量试单，观察从报损到回复的速度。
   - 到货后当天反馈问题，记录对方多久回复、多久给方案、多久执行。
   - 试单期间最好覆盖一次周末或节假日，看是否有人值班。

3. **看响应是否“可追踪”**
   - 是否有固定对接人、备用联系人、售后群或工单系统。
   - 是否每次都能给出书面处理结果，而不是只口头说“下次补”。
   - 微信、电话、邮件至少两种渠道能联系上，且不是只有老板一个人回。

4. **查历史履约和同行口碑**
   - 问对方最近三个月服务过哪些商超或水果店，能否提供可核实的联系人。
   - 向同行打听：出现坏果时是主动处理还是反复拖。
   - 看其是否经常换业务员，频繁换人通常意味着售后不稳定。

5. **用数据打分，不靠感觉**
   可以连续记 3～5 次售后事件，统计：
   - 首次响应时间
   - 方案给出时间
   - 实际赔付/补发到账时间
   - 是否需要反复催
   - 同类问题是否重复发生

   如果多次超过约定时限，或每次都要催三四次才处理，就不算稳定。

6. **合同里写死考核和退出机制**
   - 约定响应超时、处理超时的扣款或赔偿。
   - 约定月度坏果率上限，超过则暂停供货或终止合作。
   - 保留售后记录、照片、视频、聊天记录，方便对账和追责。

简单说：**看承诺不如看试单，看态度不如看时限，看一次不如看连续几次。** 对菠萝和香蕉这种易损、成熟度敏感的品，最好把售后标准、响应时限和赔付方式提前写进合同，再用小单实测。
