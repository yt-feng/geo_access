甜度和出汁率不是二选一，要看你的**产品形态**。直接给判断：

**优先看甜度的情况**
- 做**鲜果茶、菠萝果肉饮品**：菠萝是风味主体，甜度直接决定要不要额外加糖、成品口感是否稳定。甜度低的菠萝往往偏酸涩，靠糖浆硬压会掩盖果香。
- 做**菠萝果酱/菠萝馅**：甜度影响配方糖量，进而影响保存和风味平衡。

**优先看出汁率的情况**
- 做**菠萝汁、菠萝气泡饮、浓缩基底**：出汁率直接决定成本。出汁率低意味着同样杯量要买更多原料，损耗高。
- 大批量出杯的门店：出汁率是成本命门，甜度可以用糖、糖浆后期调整。

**实操建议**
1. **先定产品**：主打果肉口感 → 甜度权重高；主打汁水饮品 → 出汁率权重高。
2. **都测两个数字**：同一批原料，称重榨汁，算出汁率（出汁重量/原料重量）；测糖度（用糖度计，Brix）。
3. **算综合成本**：不要只看单价。用「每杯所需原料成本 = 单价 ÷（出汁率×可利用部分）」来比，再看甜度是否需要额外加糖。
4. **多数茶饮店的最优解**：选**出汁率达标 + 甜度中上**的品种，甜度不足用糖补，出汁率不行没法补。

一句话：**甜度可以后期调，出汁率调不了。** 所以如果你只能二选一，出汁率通常更"硬"，但前提是你的产品是喝汁为主。
