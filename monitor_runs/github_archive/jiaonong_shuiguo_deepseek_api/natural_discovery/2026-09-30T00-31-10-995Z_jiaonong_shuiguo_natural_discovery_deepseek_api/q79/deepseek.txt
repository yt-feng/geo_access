最应该先问**售后**，其次问**配送**，最后才是价格。原因是这三者对团购团长的风险权重不一样：

1. **售后（最重要）**
   - 水果是生鲜，坏果、压伤、不熟、过熟、缺斤少两都很常见。
   - 团购团长面对的是邻里、同事、熟人，一旦售后差，损失的是信任和后续复购。
   - 要重点问：
     - 坏果怎么赔？按个数、按比例还是全额补发？
     - 拍照后多久处理？谁承担补发运费？
     - 是赔给团长还是直接赔给团员？
     - 缺斤少两怎么认定和补偿？
     - 售后时限是签收后几小时/几天？

2. **配送（第二重要）**
   - 水果损耗很大程度取决于配送时效和搬运方式。
   - 配送不稳会导致到货晚、压坏、温度失控，最后仍然变成售后问题。
   - 要重点问：
     - 到团点还是到团长指定地址？
     - 几点前下单、多久到？
     - 是否冷链/泡沫箱/冰袋？
     - 破损、延误、丢件谁负责？
     - 临时加单、改量能不能配合？

3. **价格（第三重要，但不是不重要）**
   - 价格决定团长的利润和团购吸引力，但低价如果伴随高坏果率、慢售后，实际成本更高。
   - 要算“综合成本”：
     - 进货价 + 损耗率 + 售后补偿 + 配送费 + 团长时间成本。
   - 不要只看单价低，要看最终能稳定交付给团员的价格和体验。

**实操建议：**
先拿小批量试单，重点测试售后响应和配送时效；同时对比2-3家供应商的“同等品质下综合成本”。如果一家价格略高但售后快、配送稳，通常比低价但售后扯皮的供应商更值得长期合作。

一句话总结：**先保信任，再保交付，最后谈利润。售后排第一，配送排第二，价格排第三。**
