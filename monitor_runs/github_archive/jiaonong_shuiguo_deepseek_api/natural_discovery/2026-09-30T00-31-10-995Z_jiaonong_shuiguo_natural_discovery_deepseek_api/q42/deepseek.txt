压低成本又不牺牲品质，核心不是“把价格砍下来”，而是**改变采购结构、谈判筹码和验收标准**。单靠压价，供应商通常会在等级、成熟度、产地、包装上做手脚。下面按可执行程度给你一套谈法。

**一、先明确：哪些能压，哪些不能压**

能压的部分：
- 采购批量与频次（集中下单、拼车、锁量）
- 结算方式（现结、短账期）
- 包装规格（大箱、简装、周转筐）
- 等级外的“统货”或二级果
- 产地直发、减少中间商
- 非高峰时段、尾货时段拿货

不能压的部分：
- 品种纯度、糖度、单果重
- 成熟度与货架期
- 冷链和损耗率
- 农残与合规检测

谈价格时把“不能压”的写成硬指标，把“能压”的作为交换条件，供应商才知道你不是乱砍价。

**二、谈判前先做三件事**

1. **建立可比价体系**  
   同一单品至少问3家，统一规格：品种、等级、单果重、箱重、成熟度、到店时间、含税/不含税、账期。否则价格没有可比性。

2. **算清到店成本，不只看采购价**  
   采购价 + 运费 + 损耗 + 账期资金成本 + 退货率 = 真实成本。  
   有些供应商报价低5%，但损耗高10%，实际更贵。

3. **掌握自己的量**  
   月采购量、单次起订量、稳定门店数、旺季淡季波动。量是你的筹码，但要说“可锁定”，不能虚报。

**三、谈价格的具体话术和条件交换**

不要直接说“再便宜点”，而是给选择题：

- “这个价如果能做到，我月采购量从X提到Y，账期从30天改15天。”
- “你按现在价格给，但包装改成10kg大箱，我承担分装。”
- “这批我要统货价，但等级标准写进合同：单果重不低于X，糖度不低于X，到店损耗超过X你补。”
- “我接受非高峰到货，你价格让3个点，但到店时间必须卡在早上6点前。”
- “同样品质，隔壁报低8%，你能匹配我就把下季度订单给你；匹配不了，你告诉我哪部分能调。”

关键点：**每次压价都要对应一个你给出的利益**，否则供应商只能从品质里找利润。

**四、用合同和验收锁住品质**

价格谈完后，必须落到可验收条款：

- 等级标准：品种、产地、单果重范围、糖度、色泽、成熟度
- 到店标准：到店时间、温度、箱重、破损率上限
- 损耗责任：到店24小时内损耗超过约定比例，按比例补货或扣款
- 抽检机制：每批抽检，不合格整批退或降价
- 价格调整机制：随行就市，但只调价格，不调等级

没有验收条款的压价，基本等于默认供应商降级。

**五、更有效的降本方式，往往不是砍价**

1. **产地直采**：跳过一批中间商，通常能降10%—20%，但要自己承担物流和损耗。
2. **集中采购**：把多个门店、多个单品的量打包谈，换年度框架价。
3. **错峰采购**：避开节日和早市高峰，尾货时段拿货，价格低但要做动销计划。
4. **分级销售**：一级果卖高价，二级果做果切、促销、员工餐，整体毛利反而更高。
5. **缩短账期换价格**：现结通常比30天账期便宜2%—5%，看你资金成本是否划算。
6. **联合采购**：和周边非竞争商超拼单，凑量拿产地价。

**六、一句话判断标准**

如果供应商答应降价，但不愿把等级、损耗、到店时间写进合同，这个低价大概率会从品质里扣回来。  
真正安全的压价是：**价格降了，验收标准反而更细了。**
