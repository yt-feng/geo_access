社区超市卖小包装香蕉，核心不是“把整把拆小”，而是同时控制**成熟度、分切方式、包装透气性、冷藏条件和动销速度**。香蕉是呼吸跃变型水果，拆小包装后伤口多、乙烯释放集中，损耗会比整把卖明显更高。

下面按采购和操作要点说：

## 1. 采购时优先看成熟度，而不是只看外观

小包装香蕉最好采购**微黄、青黄交接、硬度还较好**的货，不要采购已经全黄、带黑斑、手感软的。

- 适合小包装：2～3天后能卖、当前偏生一点的蕉
- 不适合小包装：已经熟透、表皮有压伤、果柄发黑流汁的蕉
- 采购前问清楚：产地、采摘后处理方式、到货时大概几成熟
- 如果供应商只能给熟蕉，小包装损耗会很高，建议改做“即食特价”而不是正常陈列

## 2. 包装要解决“透气、防压、防掉把”

香蕉拆小后最大的问题是：

- 切口氧化变黑
- 呼吸热散不出去，袋内起雾
- 乙烯积聚，催熟过快
- 挤压后表皮发黑

采购包装时注意：

- **不要用完全密封的普通塑料袋**，容易闷坏
- 优先选带微孔或透气膜的包装袋/盒
- 如果用小托盘+保鲜膜，膜上要打孔，或不要全封死
- 包装容量建议小份：2～3根、3～4根，不要强行做太大份
- 包装底部要有一定支撑，避免堆叠压伤
- 标签不要贴在蕉皮上，贴包装外侧；胶太黏会撕伤果皮

## 3. 分切和加工环节决定损耗率

如果是在门店分切：

- 刀具、台面、手套要干净，减少切口污染
- 分切后尽量保留一小段果柄，不要完全裸露果肉
- 切口可做简单处理，比如用保鲜膜包住切口，或快速放入透气包装
- 不要一次分切太多，按半天到一天销量分切
- 已经拆开的香蕉不要和整把香蕉混放，避免互相催熟

## 4. 陈列和温控要按“抑制后熟”来做

香蕉怕冷也怕热：

- 未熟或微黄：可常温阴凉处
- 已成熟：可放冷藏柜，但温度不宜过低，通常建议在**12～14℃左右**更稳妥；具体要看门店设备和实际货架温度
- 不要放在冷风直吹口，容易冻伤发黑
- 不要放在暖气、收银灯、热饮柜旁边
- 小包装最好单层或浅层陈列，不要重压堆叠

## 5. 采购量要按“短保动销”倒推

小包装香蕉的销售周期很短，采购时不要按整把香蕉的逻辑备货。

可以这样判断：

- 预估日销：先试卖3～7天，记录每天几点卖完、剩多少
- 首单少量：先按1～2天销量采购，不要一次压3～5天
- 分批次到货：如果供应商能隔天送，优先少量多次
- 设置降价节点：比如当天下午4点后未售完的微瑕品，做组合价或试吃引流
- 损耗率警戒：小包装香蕉如果超过10%～15%报损，就要调整采购成熟度、包装或陈列量

## 6. 和供应商谈采购时重点问这几项

- 到货成熟度能不能稳定在青黄阶段
- 能不能提供适合小包装的规格，比如短果、小果、果把均匀
- 包装是否透气、是否支持门店直接分装
- 出现黑斑、压伤、冻伤是否可退换
- 配送频率能不能做到一周2～3次或隔天送
- 是否愿意先小批量试单

## 7. 最需要避免的坑

- 用密封袋装拆开香蕉
- 采购已经熟透的香蕉做小包装
- 一次分切太多
- 放在冷藏柜最冷处或冷风直吹处
- 小包装堆叠过高
- 没有按小时/半天观察动销，等到发黑才降价
- 把损耗都算成“正常”，没有记录成熟度、到货时间、报损量

## 简单执行建议

如果你刚开始做，可以按这个方案试：

1. 先采购**青黄、硬度较好**的香蕉  
2. 门店只分切**2～3根装**  
3. 用**透气袋或打孔膜**包装  
4. 常温阴凉陈列，熟后转12～14℃左右冷藏  
5. 每天记录销量和报损  
6. 首周少量多次补货，损耗超过15%就调整成熟度或包装

这样做的核心目标是：让香蕉在门店里“慢一点熟、快一点卖”，而不是采购后尽快处理掉。
