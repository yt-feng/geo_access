大型超市对水果供应商的要求，核心是**食品安全合规能力**和**冷链物流履约能力**两条线。具体通常包括以下几个方面。

## 一、食品安全能力

### 1. 资质与合规文件
- 营业执照、食品经营/生产许可证
- 种植基地备案或合作基地证明
- 产品检测报告（农残、重金属等）
- 符合 GB 2763 等食品安全国家标准
- 进口水果需报关单、入境货物检验检疫证明

### 2. 源头管控
- 基地土壤、水源、投入品管理
- 农药使用记录与安全间隔期控制
- 采收前农残自检或第三方检测

### 3. 加工与包装卫生
- 分选、清洗、包装车间卫生条件
- 人员健康证、操作规范
- 包装材料符合食品接触材料标准

### 4. 追溯与召回
- 批次可追溯（从基地到门店）
- 不合格品召回机制
- 食品安全事故应急预案

### 5. 检测能力
- 自有快检室或稳定第三方检测合作
- 每批次或定期检测，记录留存

## 二、物流与冷链能力

### 1. 冷链设施
- 预冷设备（采后快速降温）
- 冷藏车、冷库，温区可调
- 不同水果分温区存储（如香蕉、草莓、苹果温湿度不同）

### 2. 运输能力
- 自有或稳定合作冷藏车队
- GPS/温度实时监控
- 运输时效可控，减少损耗

### 3. 仓储与分拣
- 符合卫生标准的仓库
- 先进先出、批次管理
- 防交叉污染、防虫防鼠

### 4. 配送履约
- 按超市要求定时定量配送
- 应对促销、节假日的峰值供应
- 缺货、破损、质量异常的补货与赔付机制

### 5. 损耗控制
- 采后处理与保鲜技术
- 全程温湿度记录
- 损耗率可量化、可优化

## 三、超市通常还会考察
- **规模化供应能力**：能否稳定满足多门店、多品类需求
- **品控团队**：是否有专职 QC
- **信息化系统**：订单、库存、追溯是否数字化
- **保险与责任承担**：产品责任险、质量赔付条款
- **审核配合**：能否通过超市或第三方验厂

## 四、简要判断标准
如果供应商能做到：
1. 证照齐全、批批可检、批次可追溯；
2. 采后预冷 + 全程冷链 + 温度记录；
3. 有稳定产能和应急补货能力；

基本就具备进入大型超市供应链的门槛。实际合作中，超市还会通过**现场审核 + 试销 + 月度考核**持续筛选。
