会有影响，但影响大小取决于你的销售方式和客户类型。关键不是“大小不一样”本身，而是**大小差异会不会让顾客觉得不值、难挑、卖相差**。

分几种情况看：

1. **整箱批发/走量卖给同行或单位**
   影响较小。对方更看重量、成熟度、价格。大小不齐但总重够、品质稳定，通常能接受。

2. **拆开散卖、按根/按斤零售**
   影响较明显。顾客会挑大的，剩下小的难卖，损耗增加；如果大小混在一起还卖同价，顾客容易觉得吃亏。

3. **做果切、榨汁、甜品店供货**
   影响很小。大小不齐不影响出成率，反而适合低价采购。

4. **礼盒、精品陈列**
   影响很大。大小不一会显得不整齐，直接拉低档次和溢价。

**可执行建议：**
- 采购时先问清楚：同箱大小差异范围多大，是“自然果差异”还是“混级”。
- 如果零售为主，尽量选大小相对均匀的，哪怕单价高一点，通常比后面挑剩损耗更划算。
- 已经进了大小不一的货，可以分级卖：
  - 大果：正常价或略高价，做陈列面；
  - 中果：正常价，主力卖；
  - 小果：降价、捆售、做果切/奶昔/香蕉饼，别和大果混在同一堆同价卖。
- 陈列时不要全部倒在一起，按大小分成两三个区域，顾客挑拣少，损耗也低。
- 如果差异太大且成熟度还不一致，建议尽快处理，不要等熟透后一起烂。

简单判断：**走量、加工、低价场景影响小；零售、精品、礼盒场景影响大。** 你如果是社区水果店日常散卖，建议优先采购大小相对均匀的货，或者进回来后立刻分级销售。
