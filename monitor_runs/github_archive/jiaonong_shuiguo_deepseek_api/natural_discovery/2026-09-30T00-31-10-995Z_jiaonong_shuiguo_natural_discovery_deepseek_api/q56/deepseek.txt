茶饮店控制水果供应商的食品安全风险，核心是拿到**能证明“来源合法、质量合格、可追溯”**的文件。建议按下面几类索证索票，并保留原件或加盖公章的复印件：

1. **主体资质证明**
   - 供应商的营业执照
   - 食品经营许可证或食品生产许可证（根据其实际业态）
   - 若供应商是经销商，最好同时提供上游生产商/种植基地的资质

2. **产品合格证明**
   - 每批次的出厂检验报告或合格证明
   - 有资质的第三方检测报告，重点看：
     - 农药残留
     - 重金属（铅、镉等）
     - 致病菌（沙门氏菌、金黄色葡萄球菌等，视水果种类和即食要求）
     - 霉菌毒素（如苹果、梨等需关注展青霉素）
   - 检测报告应有 CMA/CNAS 标识，且在有效期内

3. **追溯与来源证明**
   - 供货单/送货单，注明品名、规格、数量、批次、日期
   - 产地证明或种植基地信息
   - 若为进口水果，需提供入境货物检验检疫证明、报关单

4. **质量安全承诺或协议**
   - 食品安全承诺书
   - 采购合同中的质量条款，明确农药残留、新鲜度、冷链、违约责任
   - 对即食水果，最好约定“可即食”或“适合生食”标准

5. **储运与验收记录**
   - 冷链运输温度记录（如需要）
   - 到货验收记录：外观、气味、温度、批次、检测报告核对
   - 不合格品退货/销毁记录

6. **人员与操作证明（视情况）**
   - 配送人员健康证（若直接接触即食水果）
   - 供应商的消毒、分切、包装操作规范文件（若提供预切水果）

**实操建议：**
- 首次合作：索要全套资质 + 近期检测报告，实地或视频审核供应商。
- 长期合作：每批索要合格证明/送货单，定期（如每季度或每半年）更新第三方检测报告。
- 重点高风险水果：草莓、葡萄、切片水果、即食水果，检测和验收要更严。
- 保留期限：至少保存到产品保质期满后6个月；没有明确保质期的，保存不少于2年。

如果供应商只能提供营业执照、无法提供检测报告或产地证明，建议不要采购，或要求其补全后再合作。
