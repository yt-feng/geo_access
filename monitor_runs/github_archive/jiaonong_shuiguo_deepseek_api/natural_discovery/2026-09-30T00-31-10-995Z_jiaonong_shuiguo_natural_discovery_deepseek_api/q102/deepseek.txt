需要，而且通常是企业采购的基本门槛。

**发票：基本必需**
- 企业采购要入账、报销、税前扣除，必须取得合规发票。
- 一般纳税人企业通常要**增值税专用发票**用于抵扣；小规模或福利费场景可能接受**增值税普通发票**。
- 下单前要确认：能否开专票、税率多少、开票项目是"水果"还是"食品/礼盒"、是否随货或事后补开。

**定制包装：视需求而定，但福利场景很常见**
- 如果只是内部发放，标准礼盒往往够用。
- 如果要做**企业形象展示**（印LOGO、节日祝福、企业名称），就需要供应商支持定制。
- 定制通常涉及：起订量、打样费、加价、交期延长。

**采购前建议确认的清单**
1. 是否支持开专票，税率和开票项目
2. 定制包装的起订量、单价、打样周期
3. 水果品类、规格、产地、损耗和售后标准
4. 配送范围、时效、能否分地址发货
5. 合同里的质量验收和退换条款

**结论**：发票是硬性要求，定制包装看你的福利定位。两者都支持的供应商更省事，但价格和交期通常也会相应提高。建议至少对比2-3家，把发票和定制需求写进合同再下单。
