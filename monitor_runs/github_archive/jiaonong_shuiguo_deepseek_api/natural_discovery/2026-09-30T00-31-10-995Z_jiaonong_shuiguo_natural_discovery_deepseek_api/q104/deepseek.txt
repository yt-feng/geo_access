单位采购水果，验收和售后的核心是：**把“合格标准”提前写进合同/订单，到货按标准抽检、留证，不合格部分按约定退换或扣款，而不是靠事后扯皮。**

下面按可执行流程说明。

## 一、采购前先定标准

到货品质不一致，很多是因为下单时只写了“苹果多少斤”，没写等级、规格、成熟度、产地、包装。建议在订单或合同里写清：

1. **品种、产地、等级**：如一级果、统货、单果重范围。
2. **规格**：果径、单果重量、每箱个数、净重。
3. **成熟度**：如七成熟、九成熟，是否允许青果、软果。
4. **外观标准**：允许的碰伤、虫眼、裂口、畸形比例。
5. **新鲜度**：采摘/发货时间、冷链要求、到货温度。
6. **包装**：箱规、防压、防潮、标签。
7. **验收方式**：抽检比例、判定规则、谁验收。
8. **售后条款**：不合格如何退换、补发、扣款、时效。
9. **结算方式**：验收合格后付款，还是留质保金。

关键一句最好写进合同：
> 到货后按双方确认的样品或标准验收，不符合约定标准的，采购方有权拒收、要求换货、补货或按不合格数量扣款。

## 二、到货验收怎么做

### 1. 到货前准备
- 确认验收人、验收时间、卸货地点。
- 准备好秤、卷尺、温度计、拍照设备、验收单。
- 如有封样，拿出封样对比。

### 2. 先查外包装和运输状态
- 数量：总箱数、总重量是否一致。
- 包装：有无破损、受潮、挤压、异味。
- 冷链：如要求冷链，查温度记录或到货温度。
- 批次：不同批次分开验收，避免混批。

### 3. 抽检，不要只翻表面
建议按批次随机抽检，不能只查上层。
- 小批量：抽 10%—20%。
- 大批量：按箱抽，每箱抽上中下不同位置。
- 重点查：底层、边角、中间箱。

### 4. 记录不合格类型
把问题分开记，方便售后：
- **数量短缺**：净重不足、箱数少。
- **规格不符**：果径小、单果轻、个数少。
- **品质不符**：腐烂、虫害、碰伤、裂口、异味。
- **成熟度不符**：太生、太熟、软烂。
- **批次不一致**：同一批里好坏混装、产地混装。

### 5. 判定方式
建议用“不合格率”判定：
- 不合格率 ≤ 约定比例：接收，但可要求按比例扣款。
- 不合格率 > 约定比例：整批拒收或要求换货。
- 局部不合格：合格部分接收，不合格部分退货/补发。

### 6. 留证
必须留：
- 到货时间、车牌、送货单。
- 开箱前、开箱中、开箱后照片/视频。
- 抽检数量、不合格数量、称重照片。
- 验收单双方签字；对方不签，也要备注并拍照。
- 聊天记录、电话录音、邮件确认。

## 三、售后怎么处理

### 1. 当场提出，不要拖
到货验收发现问题，最好**当场**在送货单上注明，并让送货人签字确认。常见写法：
> 经抽检，第X批苹果共X箱，抽检X箱，发现腐烂/碰伤/规格不符X箱，不合格率约X%，暂拒收/要求换货。

如果对方不签字：
- 拍照录像；
- 发微信/邮件给对方负责人；
- 在送货单上写“送货人拒绝签字，已拍照留证”。

### 2. 按合同走售后
优先顺序：
1. **补发/换货**：适合生鲜、易腐品。
2. **退货退款**：整批严重不符。
3. **按比例扣款**：局部不合格，仍可使用。
4. **折价接收**：双方协商，但要有书面确认。

### 3. 设定时效
水果易坏，售后时效要短：
- 到货 2 小时内初验；
- 24 小时内提出书面异议；
- 腐烂类最好当天处理。
超过时效，供应商可能不认。

### 4. 保留样品
有争议时，保留不合格样品、照片、称重记录，必要时冷冻或冷藏保存，作为证据。

## 五、最实用的几条原则

1. **先定标准，再采购**，不要到货才争论“什么叫好”。
2. **抽检要随机、要查底层**，不能只看表面。
3. **当场留证、当场注明**，比事后解释有用。
4. **不合格部分单独称重、单独拍照**。
5. **售后按合同走**：能补发就补发，不能补发就扣款或退货。
6. **付款留尾款**，验收合格后再付，能大幅降低扯皮成本。

如果你们是长期采购，最好固定“封样+验收标准+不合格率+扣款规则”，每次到货按同一套流程执行。
