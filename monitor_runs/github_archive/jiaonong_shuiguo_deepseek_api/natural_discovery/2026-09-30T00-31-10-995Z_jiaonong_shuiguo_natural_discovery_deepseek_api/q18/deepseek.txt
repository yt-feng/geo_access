核心思路是：**先按你打算什么时候吃来选成熟度，再按家里温度决定买几根、怎么放。**

可以这样判断：

1. **看颜色定用途**
   - **青绿/棱角明显**：太生，通常要放 3～5 天甚至更久。除非你打算一周后吃，否则少买。
   - **黄中带一点绿、果柄还偏绿**：适合 1～3 天后吃，最稳。
   - **通体金黄、无明显绿**：适合当天到 1～2 天内吃。
   - **有黑斑但果肉不塌**：已经很熟，适合当天吃或做奶昔、烘焙。
   - **大面积发黑、渗液、果柄霉点**：别买。

2. **摸手感比只看颜色更准**
   - 硬：生。
   - 轻按有弹性、不软塌：刚好。
   - 一按就凹：偏熟，尽快吃。
   - 表皮裂、发黏：不要。

3. **看果柄和棱角**
   - 果柄青绿、切口新鲜：通常更新。
   - 棱角很分明：偏生。
   - 棱角变圆润：偏熟。

4. **按计划买**
   - 今天吃：买金黄、微弹的。
   - 2～3 天吃：买黄中带绿、轻按稍硬的。
   - 一周后吃：可买青黄相间、较硬的，但别买全青。
   - 想分批吃：**一半刚好熟，一半稍生**，别全买同一成熟度。

5. **回家后这样控熟**
   - 想催熟：和苹果或熟香蕉一起放纸袋，室温 1～2 天。
   - 想慢熟：分开单放，别和苹果、熟香蕉同袋；室温阴凉处。
   - 已经熟了：进冰箱冷藏可延缓 2～4 天，但表皮会变黑，果肉通常还能吃。
   - 别把生香蕉直接冷藏，会停熟、口感差。

6. **到店快速判断口诀**
   **青硬等几天，黄绿一两天，金黄当天吃，黑斑马上吃，发黏不要买。**
