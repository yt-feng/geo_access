对小水果店，**不能只看一个指标**，但如果非要排优先级，建议是：

**熟度 > 坏果率 > 送货速度 > 价格**。

原因很简单：香蕉是典型“买回来还要继续熟”的水果，利润和损耗主要卡在熟度和坏果上。

### 1. 熟度最重要
香蕉进回来太生，不能马上卖；太熟，当天卖不掉就黑、软、烂。  
小水果店没有大商超的控温催熟和快速周转能力，所以要看：

- 适合你销售速度的熟度：一般选**微黄、带一点青**，别选全青或全黄。
- 能不能分批次卖：如果一天卖得慢，就宁可偏生一点。
- 季节影响：夏天熟得快，要更生；冬天可稍熟。

### 2. 坏果率其次
坏果率高，表面进价便宜也没用。  
要重点看：

- 有没有黑斑、裂口、压伤、发霉。
- 箱底、中间有没有烂果。
- 是不是“上面好看、下面烂”。
- 能不能挑货、包售后。

小水果店损耗承受力低，坏果率高的货很容易把利润吃光。

### 3. 送货速度第三
香蕉周转快，送货慢会带来两个问题：

- 到货时熟度已经变了，不好控。
- 补货不及时，断货或被迫进高价货。

但送货速度一般可以通过换供应商、约定固定配送时间解决，不如熟度和坏果率那么致命。

### 4. 价格放最后
不是价格不重要，而是**不能优先看价格**。  
香蕉是引流品，毛利通常不高，靠的是周转和损耗控制。  
进价便宜但熟度差、坏果多，最后往往更贵。

### 实操建议
你可以按这个标准选供应商：

1. **先试熟度**：同一批货，拿回来放1—2天，看变色和口感。
2. **再算坏果**：开箱抽检，坏果超过5%就要谨慎，超过10%基本不划算。
3. **看配送稳定性**：能不能按你需要的熟度、时间送到。
4. **最后谈价格**：在满足前三项的前提下，再比价。

一句话：  
**小水果店进香蕉，优先选“熟度合适、坏果少、送得稳”的货，价格只在同等质量下比较。**
