要减少香蕉放坏，采购时核心是：**不要一次全拿同一熟度，按“销售节奏”分批次要货，并明确到货时蕉体状态。**

可以直接这样要求供应商：

1. **按熟度分等级采购**
   - **青硬蕉**：适合2–4天后卖，要求果皮全绿、无黄斑、手感硬。
   - **微熟蕉**：适合1–2天内卖，要求果皮绿中带黄、无黑点、轻按微软。
   - **即食蕉**：当天或次日卖，要求果皮黄、少量糖斑，但不能软塌、渗汁、发黑。
   - 建议比例按你门店销量定，通常：
     - 走量快：青硬40%、微熟40%、即食20%
     - 走量慢：青硬60%、微熟30%、即食10%

2. **要求到货时间**
   - 最好要求**早上到货**，方便当天分拣、上架、挑出伤果。
   - 避免**下午晚到或隔夜到**，尤其夏天，闷在车里和仓库会明显加快后熟。
   - 如果只能一天一配，要求供应商**按当天可售量+1–2天缓冲量**发，不要为了凑重量硬塞即食蕉。

3. **明确运输和包装要求**
   - 要求**冷链或通风阴凉运输**，不要暴晒、不要闷箱。
   - 要求**带通风孔纸箱或周转筐**，不要用密封塑料袋久装。
   - 要求**不压伤、不摔伤**，因为机械伤会先黑先烂。
   - 到货蕉把如果已经大量发黄、有酒味、果柄发黑，应拒收或折价。

4. **采购订单里写清楚验收标准**
   - 品种、规格、数量。
   - 熟度等级和比例。
   - 到货时间段。
   - 温度/包装要求。
   - 验收标准：无严重压伤、无裂果、无酒味、无大面积黑斑。
   - 不合格处理：拒收、换货或扣款。

5. **门店配合做法**
   - 到货后立刻拆箱通风，按熟度分开摆放。
   - 青蕉放阴凉通风处，不要和苹果、梨、番茄等催熟水果放一起。
   - 即食蕉少量上架，其余放冷柜或阴凉处延缓后熟。
   - 每天挑出软蕉、黑斑蕉，做折扣、果切或促销，避免传染整箱。

简单说，采购时你就一句话要求：  
**“请按青硬、微熟、即食三档分开发货，早上到，通风筐装，不能压伤；即食蕉只发当天能卖完的量，青蕉做后续库存。”**
