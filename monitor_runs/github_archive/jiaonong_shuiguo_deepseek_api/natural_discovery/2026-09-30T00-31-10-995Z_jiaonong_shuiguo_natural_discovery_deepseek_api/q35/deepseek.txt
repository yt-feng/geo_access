连锁超市降低门店坏果率，核心是把「坏果率」变成一个可测量、可归责、可赔付的合同指标，而不是只写一句“质量不合格退货”。建议从以下六个方面约定：

**一、先定义“坏果”和“坏果率”**

合同里不能只写“坏果”，要明确标准，否则赔付时容易扯皮：

- 坏果范围：腐烂、霉变、软烂、破损渗汁、异味、冻伤、虫蛀等，最好附照片或验收标准作为附件。
- 计量口径：按件数、重量还是金额计算；分子是坏果数量/重量，分母是当批到货数量/重量。
- 统计时点：到店验收时、上架前、还是门店销售过程中发现。不同时点责任不同，建议分段约定。
- 抽检规则：全检还是抽检，抽检比例、抽样方法、双方是否共同确认。

**二、约定验收标准和拒收权**

- 到货验收坏果率超过约定阈值（如3%或5%，按品类定），超市有权拒收整批或部分拒收。
- 低于阈值但存在坏果的，可要求按坏果数量扣减货款，或要求供应商补货。
- 明确验收期限，例如到货后X小时内完成验收，逾期视为合格，避免责任无限期延伸。

**三、约定赔付方式**

赔付要可执行，建议分层：

1. **直接扣款**：按坏果数量×进货单价扣减货款，这是最直接的方式。
2. **补货/换货**：供应商在约定时间内补足合格品，逾期未补的转为扣款或违约金。
3. **违约金**：坏果率超过阈值时，除扣款外再按当批货值的一定比例支付违约金，例如超标部分货值的20%—50%。
4. **门店损失赔偿**：因坏果导致的门店损耗、人工分拣、客诉赔偿等，可约定由供应商承担或按固定标准补偿。
5. **阶梯赔付**：坏果率越高，赔付比例越高，形成约束。例如3%以内扣款，3%—8%加收违约金，超过8%拒收并可追责。

**四、区分责任环节**

坏果可能发生在产地、运输、仓储、门店陈列等环节，合同要写清：

- 到货验收前：供应商责任。
- 验收合格后因门店储存、陈列不当导致的：超市自担。
- 运输环节：谁负责运输、谁承担途中损耗，要明确。
- 若由第三方物流承运，可约定供应商先向超市赔付，再向物流追偿。

**五、设置质量保证金或账期扣款机制**

- 约定质量保证金，出现坏果赔付时优先从中扣除，不足部分从货款中补扣。
- 或约定超市有权在每月结算时直接扣除坏果赔付款，供应商有异议需在X日内提出并提供证据。
- 这样避免“先赔付再追讨”的被动局面。

**六、配套条款**

- **数据确认**：验收记录、照片、视频、称重单作为赔付依据，双方签字或系统确认。
- **争议处理**：对坏果认定有争议时，约定第三方检测或双方共同复检机制。
- **累计考核**：月度/季度坏果率连续超标，超市有权调整供货比例、暂停下单或解除合同。
- **追溯期限**：约定坏果发现后的通知期限和索赔期限，避免过久后无法举证。

**实操建议：**

- 按品类设置不同阈值，叶菜、浆果类损耗天然高，不能和根茎类用同一标准。
- 把“坏果率”写进月度考核，和返利、续约、供货资格挂钩，比单纯赔款更有约束力。
- 所有赔付条款都要配上可操作的验收流程和单据，否则条款再细也难执行。

一句话：合同里要写清“什么是坏果、谁来认定、怎么计算、怎么扣钱、多久内提出”，赔付才落得了地。
