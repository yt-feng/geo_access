香蕉在配送中最容易出两类问题：**压伤**和**低温变黑**。控制思路要同时抓“选品—包装—温控—履约”四段，任何一段单独做都很难彻底解决。

**1. 选成熟度，不要发全黄蕉**
- 配送香蕉最好发**七到八成熟、微黄带绿**的蕉，到用户手里正好黄熟。
- 全黄、起糖斑的蕉只适合即时零售/短距离，不适合快递或次日达。
- 采购时要求产地做**催熟后分级**，避免生青蕉和过熟蕉混装。

**2. 包装的核心是“防压+缓冲+透气”**
- 单根或小把用**珍珠棉网套/气柱袋**包住，重点保护蕉指和蕉柄。
- 箱内不要堆太高，建议**不超过2层**，层间加瓦楞纸隔板。
- 箱体选**五层瓦楞纸箱**，比三层抗压明显好。
- 不要用完全密封的塑料袋闷住，香蕉会呼吸产热、产生水汽，容易发黑发霉；需要**透气孔**。
- 箱内留一定空隙但不要晃动，空隙用牛皮纸或气泡膜填实。

**3. 温控：怕冷也怕热**
- 香蕉最适配送温度大致在**13–15℃**，低于约12℃容易冷害，表皮变黑、果肉发硬。
- 夏天要避免暴晒和车厢高温，可用**冷链车但温度设在13–15℃**，不要直接放0–4℃冷库或冰袋贴身。
- 冬天北方要防冻，用保温箱+少量蓄热袋，但别让香蕉直接贴热源。
- 如果做常温配送，尽量选择**夜间/清晨配送**，缩短在途时间。

**4. 履约环节比包装更关键**
- 缩短从催熟到签收的时间，理想是**24–48小时内**。
- 分拣时轻拿轻放，禁止抛件；香蕉箱上贴**“易压、勿倒置、防冻防热”**标识。
- 快递面单不要直接贴在香蕉包装的透气孔上。
- 优先用**同城即时配、次日达**，少用多日中转快递。

**5. 到用户端的提示**
- 随箱放卡片：收到后**先取出、通风、常温放置**，不要马上放冰箱。
- 如果已经微青，放在室温1–2天再吃；如果已黄熟，尽快食用或冷藏果肉。
- 告诉用户：表皮轻微黑点不等于坏，但大面积发黑、流水、异味就是冷害或腐烂。

**6. 售后和损耗兜底**
- 按“根”或“把”做小规格，减少整箱压坏风险。
- 对压伤、冷害设置明确赔付标准，比如**单根严重压伤/发黑超过1/3即赔**。
- 记录每批到货破损率，反向调整包装和成熟度，通常能把损耗压到可接受范围。

一句话：**发微黄蕉、单根缓冲、五层箱、13–15℃、短时效、别闷袋**。这几条做到，压坏和变黑会明显下降。
