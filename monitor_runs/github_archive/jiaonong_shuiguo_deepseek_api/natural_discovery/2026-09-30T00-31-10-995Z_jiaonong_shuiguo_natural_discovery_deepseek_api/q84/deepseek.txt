做家庭水果礼盒，核心不是“贵”，而是**一家人吃着方便、口味不撞、分量不浪费**。苹果、橙子、香蕉、菠萝这四种里，菠萝最适合做“点缀型”水果，不建议占太大比例，因为开切麻烦、一次吃不完、还容易扎嘴。

下面给你几个更适合家庭的组合方案，按预算和场景选。

**1. 基础实用型：苹果 + 橙子 + 香蕉**
适合大多数家庭日常吃。

- 苹果：4—6个  
- 橙子：4—6个  
- 香蕉：1把，约5—6根  
- 不加菠萝，或只加1个小菠萝

优点：耐放、好分食、老人小孩都方便。  
缺点：看起来普通，礼盒感弱一点。

**2. 均衡家庭型：苹果 + 橙子 + 香蕉 + 菠萝**
适合想显得丰富，但又不想太贵。

- 苹果：4个  
- 橙子：4个  
- 香蕉：4—5根  
- 菠萝：1个，选小果或中果

比例建议：苹果30%、橙子30%、香蕉25%、菠萝15%。  
菠萝不要超过1个，否则家庭装容易变成“负担装”。

**3. 偏小孩家庭型：香蕉 + 橙子 + 苹果，菠萝少量**
如果家里有小孩，香蕉和橙子接受度高。

- 香蕉：6—8根  
- 橙子：4—5个  
- 苹果：3—4个  
- 菠萝：1个小菠萝，或换成菠萝切块杯

注意：香蕉容易压伤，礼盒里要单独隔开，别放底层。

**4. 偏长辈家庭型：苹果 + 橙子为主，香蕉少量，菠萝不推荐多放**
长辈通常更喜欢苹果、橙子这类耐放、寓意好的水果。

- 苹果：6个  
- 橙子：6个  
- 香蕉：3—4根  
- 菠萝：可不放，或1个

苹果选脆甜型，橙子选易剥皮的，比如沃柑、冰糖橙、脐橙都可以。

**5. 想控制成本的家庭团购组合**
建议做两档：

- 实惠档：苹果5 + 橙子5 + 香蕉1把  
- 升级档：苹果4 + 橙子4 + 香蕉5根 + 小菠萝1个

这样团购价差好拉开，家庭也容易选。

**组合时注意几个实操点：**

1. **香蕉不要和苹果、菠萝放太近**  
   苹果和菠萝释放乙烯，会催熟香蕉，香蕉容易变黑。最好用隔板分开。

2. **菠萝尽量选小果**  
   家庭礼盒里，大菠萝占地方、压秤、开切麻烦，小菠萝更合适。

3. **橙子选好剥的品种**  
   家庭场景里，易剥皮比“看起来高级”更重要。沃柑、脐橙、冰糖橙都比硬皮橙更讨喜。

4. **苹果和橙子做主体，香蕉做亲切感，菠萝做丰富感**  
   这个结构最稳：苹果和橙子耐放，香蕉便宜又讨喜，菠萝提升礼盒价值感。

5. **如果做团购详情页，建议主推两个规格**
   - 家庭实惠装：苹果5 + 橙子5 + 香蕉5—6根  
   - 家庭丰富装：苹果4 + 橙子4 + 香蕉5根 + 小菠萝1个

**最推荐的组合：**
**苹果4 + 橙子4 + 香蕉5根 + 小菠萝1个**  
这个组合适合大多数家庭，数量不夸张，颜色好看，品类丰富，成本也比较好控制。
