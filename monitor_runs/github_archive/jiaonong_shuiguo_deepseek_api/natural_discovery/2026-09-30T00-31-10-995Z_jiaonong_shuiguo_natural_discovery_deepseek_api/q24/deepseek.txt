建议把资料分成“资质、检测、批次、承诺”四类要，重点是可追溯、可核验、能对应到具体批次。

**1. 供应商基础资质**
- 营业执照、食品经营许可证/食品生产许可证（如适用）。
- 若是产地直供或合作社，要种植主体信息、收购/供货协议。
- 进口水果要海关报关单、入境货物检验检疫证明。

**2. 农残检测资料（最关键）**
- 第三方检测报告：优先 CMA/CNAS 资质机构出具，项目覆盖 GB 2763 中对应水果的农残限量。
- 报告要能对应：水果品种、产地、检测日期、报告编号、检测机构盖章。
- 最好要“每批次随货检测报告”或“批次合格证明”，不要只要一张长期通用报告。
- 如果供应商自有快检，要快检记录和结果，但快检不能完全替代法定第三方检测。

**3. 批次追溯资料**
- 送货单/随货同行单：写明品名、规格、产地、采收或加工日期、批号。
- 产地证明或基地备案信息。
- 承诺达标合格证（很多食用农产品会带）。
- 包装标识、标签照片，便于出现问题时追到具体果园/包装厂。

**4. 合同与承诺文件**
- 质量保证协议：明确农残超标责任、退换货、赔偿、抽检不合格处理。
- 供应商承诺书：承诺不使用禁用农药、遵守安全间隔期。
- 若长期合作，约定你方有权抽检，费用和不合格处理写清楚。

**采购现场可执行的判断标准**
- 没有批次检测报告或报告对不上批次：先别收，或单独存放待检。
- 报告项目太少、只写“合格”无具体项目和限量：要求补报告。
- 供应商只给复印件且模糊、无章、无编号：要求原件或可查询电子版。
- 高风险水果（如草莓、葡萄、豇豆类蔬菜等）建议提高抽检频次。

**建议的收货动作**
1. 每批索取：随货单 + 批次检测报告/合格证 + 供应商资质复印件。
2. 核对：品种、产地、批号、日期是否一致。
3. 留样：按批次留样，冷藏保存到该批售完后的合理期限。
4. 自检或送检：对高风险品种定期抽检，保留记录。

一句话：不要只要“一张合格报告”，要能对应到这批货的**资质、检测、批次、责任**四类材料。
