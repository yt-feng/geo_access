判断供应商能不能按时到车，不能只听口头承诺，要抓“可验证的履约能力”。给你一套批发商常用的判断框架，按优先级排：

## 1. 先看历史交付记录
- 问同行、问市场里其他批发商：这个供应商最近有没有迟到、断供、临时加价的记录。
- 优先选有过 3 次以上按时到车记录的供应商，而不是只看报价最低的。
- 新供应商第一次合作，建议先小批量试单，不要直接把档口销量押上去。

## 2. 看“车”是不是他自己的
- 自有车队/长期固定司机：按时率通常比临时调车高。
- 临时找车、靠信息部配货：旺季、雨天、节假日容易掉链子。
- 直接问：车牌号、司机电话、车辆当前位置、预计装车时间、预计到达时间。能当场给出来的，可信度更高。

## 3. 看装车节点，而不是只看“发车时间”
关键节点要逐个确认：
1. 产地是否已经摘/收；
2. 是否已经进冷库或装车点；
3. 是否已装车；
4. 是否已上高速；
5. 当前到了哪个服务区/城市。

如果供应商只说“明天到”，但说不清现在货在哪儿，风险就高。

## 4. 合同或聊天里写死时间和违约
- 明确到车日期、时间段、市场卸货点。
- 写明迟到怎么赔：比如超过几小时扣多少钱/吨，超过一天怎么处理。
- 定金和尾款挂钩到车验收，不要提前全款。
- 保留微信、转账、合同记录，方便追责。

## 5. 看天气、路线和旺季
- 台风、暴雨、大雪、高速管控、节假日堵车，都会影响时效。
- 同一供应商在旺季是否还能保证车辆，要提前问“有没有备用车”。
- 跨省长途至少预留半天到一天缓冲，别按理论最短时间排销售。

## 6. 用“压力测试”问几个问题
可以直接问：
- “如果这车临时坏了，你多久能调第二台？”
- “司机现在电话多少？我直接跟车。”
- “装车视频/照片什么时候发我？”
- “最晚几点能到市场？超过怎么办？”

回答含糊、回避车牌和司机信息的，按时到车概率通常偏低。

## 7. 到车前的最后确认
- 发车前确认一次；
- 上高速后确认一次；
- 预计到达前 3—4 小时再确认一次；
- 让司机直接发定位，不要只转述。

## 简单判断标准
| 信号 | 可信 | 风险高 |
|---|---|---|
| 车牌/司机信息 | 能马上给 | 推脱不给 |
| 货物位置 | 说得清 | 说不清 |
| 历史记录 | 有多次按时 | 没记录/差评多 |
| 备用方案 | 有备用车 | 没有 |
| 违约条款 | 愿意写 | 不愿写 |

**最稳的做法：** 新供应商先小单试，老供应商也要每次确认车牌、司机、装车视频和实时位置；合同里写清迟到赔偿。不要因为价格低就放松到车时间要求，香蕉压一天，损耗和档口排期都会出问题。
