优先看**成熟度**，但真正决策要分用途和损耗：

- **做香蕉磅蛋糕、香蕉马芬、香蕉面包**：优先选**熟透的**，表皮出现黑斑、果肉软甜、香气浓的香蕉，成品质地和风味明显更好。
- **做装饰、夹馅、需要成型**：反而要选**刚熟、无黑斑**的，太熟会出水、塌软、不好操作。
- **做香蕉泥、冷冻保存、批量生产**：可以买**快熟或已经熟透的折价香蕉**，只要没有霉变、酸败、酒味，回来立刻去皮分装冷冻。

**价格什么时候优先？**
当你能当天处理、能去皮冷冻、或产品对香蕉形态要求低时，价格可以优先。否则买太生或太熟的香蕉都会带来额外成本：太生风味不足，太熟损耗高、出品不稳定。

**采购判断标准：**
1. 表皮：做泥/烘焙选黄皮带黑斑；做装饰选黄皮无斑。
2. 手感：微软有弹性，不是硬芯，也不是一按就烂。
3. 气味：香甜浓郁，无酒味、酸味。
4. 果肉：无发黑、霉变、流水。
5. 到货时间：如果当天不用，按未来 1–3 天的成熟进度倒推采购。

**实操建议：**
- 固定产品：按成熟度分等级采购，别只看单价。
- 临时促销：可低价收熟香蕉，但必须当天去皮冷冻或立即生产。
- 算总成本：`采购价 + 损耗 + 人工处理 + 出品稳定性`，而不只是每斤价格。

一句话：**成熟度决定能不能用、好不好吃；价格决定划不划算。先卡成熟度底线，再在可用范围内比价。**
