生鲜水果到货后出现坏果，责任划分通常不能简单归为某一方，关键看**坏果产生的时间点、原因和各方是否尽到义务**。可以按下面几个环节判断。

## 一、先看责任可能落在哪几方

1. **供应商/产地/批发商**：采摘、分拣、包装、预冷、发货时水果本身已有伤、熟过度、带病。
2. **平台/商家**：采购验收不严、仓储温湿度不当、分拣打包不规范、配送时效安排不合理。
3. **物流/配送方**：运输挤压、冷链断链、延迟配送、暴力分拣、末端配送放置过久。
4. **顾客**：收货后未及时取货、未按要求冷藏、放置过久、自身保存不当。

所以责任划分的核心是：**坏果是“到货前就已经坏/必然坏”，还是“到货后因顾客保存不当才坏”。**

## 二、常见情形与责任判断

### 1. 到货即坏，且外包装有挤压、渗漏、异味
一般偏向**商家/平台或物流责任**。  
顾客签收后发现明显腐烂、压伤、汁液渗出，通常可要求补发、退款或赔偿。商家不能仅以“生鲜不支持退换”一概拒绝。

### 2. 外观正常，但切开后内部变质
要区分：
- 若同一批次大量出现，可能是**采购或仓储责任**；
- 若只是个别，可能是水果本身特性或运输隐损，通常仍由商家承担售后，但可向供应链追责。

### 3. 到货时完好，顾客放置几天后坏
若顾客未按提示冷藏、未及时食用，责任多在**顾客**。  
但如果是商家承诺“可放X天”却提前变质，商家仍可能担责。

### 4. 物流延迟导致坏果
若商家已按时发货，但物流严重延误且未冷链，责任可能在**物流方**；  
但顾客通常先找商家售后，商家再向物流追偿。

### 5. 顾客填错地址、电话不通、拒绝签收导致延误
责任通常偏向**顾客**，商家可拒绝全额赔付或仅协商部分补偿。

## 三、实务中较合理的划分原则

- **谁控制风险，谁承担相应责任**：采摘、包装、仓储、运输、末端保存各管一段。
- **举证责任向经营者倾斜**：生鲜易腐，顾客很难证明“收到时就坏”。商家若主张是顾客保存不当，应提供发货记录、冷链记录、签收时间等证据。
- **平台/商家先对外赔付，再对内追偿**：顾客一般只需找销售者，不必直接找物流或产地。
- **按坏果比例赔付**：全坏可全赔；部分坏可按数量、重量、金额比例退赔，而不是一律全赔或一律不赔。

## 四、给商家的处理建议

1. 售后规则写清楚：签收后多久内可申请、需提供哪些照片/视频。
2. 要求顾客提供：坏果照片、快递面单、开箱视频、坏果数量。
3. 建立批次追溯：采购、分拣、打包、发货、物流温控记录。
4. 对高频坏果品类，优化包装和冷链，不要只靠售后兜底。
5. 对物流延误、暴力分拣保留追偿依据。

## 五、给顾客的维权建议

1. 收货后尽快开箱，拍完整开箱视频和坏果特写。
2. 保留快递面单、聊天记录、订单截图。
3. 先找商家/平台售后，要求退款、补发或按比例赔偿。
4. 商家拒绝时，可申请平台介入；仍无法解决可向12315投诉。
5. 不要拖太久，生鲜售后通常有较强时效要求。

## 六、一句话结论

**如果坏果在签收时或合理开箱时间内已经存在，通常由商家/平台承担售后责任，商家再根据运输、仓储、采购环节向物流或供应商追偿；如果到货完好、因顾客保存不当导致，则顾客承担。部分损坏的，一般按比例退赔。**
