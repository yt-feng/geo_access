判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要按“产地结构—硬件能力—历史记录—合同约束”逐层验证。下面给你一套可直接执行的判断框架。

## 一、先看产地结构：单一产地基本不可靠

香蕉是热带作物，不同产区季节和风险不同。要问供应商：

1. **有几个产地/合作农场？**
   - 只报一个产地：风险高，台风、寒害、病害、政局都可能断供。
   - 至少应有2—3个跨区域产地，且上市期能衔接。
   - 国内主产区如海南、广西、云南、福建，以及进口来源如菲律宾、越南、厄瓜多尔、柬埔寨等，要能说清各产地全年供应月份。

2. **各产地的气候风险如何分散？**
   - 台风区、寒害区是否集中在同一时间段？
   - 如果两个产地同时受灾，有没有第三备份？

3. **是自有基地、长期合作农场，还是临时市场收购？**
   - 自有基地/长期订单农业：稳定性较强。
   - 临时批发市场调货：价格波动大，旺季可能抢不到货。

## 二、看硬件和加工能力

全年供货不只是地里有香蕉，还要能采后处理、催熟、冷链、仓储。

要核实：

1. **有没有催熟库？容量多大？**
   - 连锁超市通常需要稳定供应熟度一致的香蕉。
   - 没有催熟能力，只能靠第三方，旺季容易被卡脖子。

2. **有没有冷藏/冷链运输能力？**
   - 香蕉对温度敏感，运输和仓储温度失控会导致货损。
   - 问清是自有冷链还是外包，外包是否有长期协议。

3. **日加工/出货能力是多少？**
   - 让供应商给出：每天最多能出多少箱、多少吨。
   - 对比你门店日均销量和旺季峰值，看是否有余量。

4. **包装厂、分拣线是否规范？**
   - 能否按你要求的规格、等级、箱重稳定供货。

## 三、看历史供货记录

这是最硬的证据。

1. **要求提供过去12个月的供货记录**
   - 每个月供了多少、供给了哪些客户。
   - 重点看是否在春节、台风季、雨季等关键时期断供或大幅减量。

2. **找同行或现有客户交叉验证**
   - 问其他超市、水果连锁、批发市场客户：这家是否全年稳定、是否经常临时涨价、是否断供。
   - 最好直接联系2—3个现有大客户。

3. **看合作年限**
   - 和现有大客户合作3年以上，通常比新供应商更可靠。
   - 但也要注意：大客户优先，你可能在紧张时被排后面。

## 四、看资金和抗风险能力

全年供货需要资金周转和风险承受能力。

1. **是否有足够流动资金？**
   - 香蕉采购、催熟、冷链、运输都需要垫资。
   - 资金链紧张的供应商，遇到价格波动容易违约。

2. **是否有农业保险或风险对冲？**
   - 台风、寒害、病害是否有保险或备用资金。
   - 没有保险的供应商，一次灾害就可能断供。

3. **是否依赖单一资金来源或单一客户？**
   - 过度依赖一个客户，可能因对方压款而影响你的供货。

## 五、用合同和试单来验证

口头承诺不算，必须落到合同和实际测试。

1. **合同里写清：**
   - 全年最低供货量、月度供货计划。
   - 断供、减量、质量不达标的违约责任。
   - 价格调整机制：不能随意涨价，要有公式或协商周期。
   - 替代产地条款：一个产地受灾，供应商有义务从其他产地补货。

2. **设置试单期**
   - 先合作3—6个月，覆盖一个淡旺季转换。
   - 试单期重点观察：准时到货率、缺货次数、质量波动、临时涨价频率。

3. **做压力测试**
   - 故意在旺季或天气异常时下稍大订单，看对方能否按时按量交付。
   - 问对方：如果主产地受灾，几天内能从备用产地补货？补货量多少？

## 六、快速判断清单

你可以直接拿这张表去问供应商：

| 项目 | 关键问题 | 合格标准 |
|---|---|---|
| 产地 | 有几个产地？上市月份？ | 至少2—3个跨区域产地，能覆盖全年 |
| 基地 | 自有还是临时收购？ | 自有或长期订单农业 |
| 催熟 | 有无催熟库？容量？ | 有，且能满足你的旺季需求 |
| 冷链 | 自有还是外包？ | 有稳定冷链，温度可控 |
| 历史 | 过去12个月供货记录？ | 无明显断供，旺季有增量 |
| 客户 | 现有大客户是谁？ | 可交叉验证，合作3年以上 |
| 资金 | 抗风险能力？ | 有流动资金、保险或备用金 |
| 合同 | 是否接受断供罚则？ | 接受最低供货量和违约条款 |
| 试单 | 是否愿意试单3—6个月？ | 愿意，且能覆盖淡旺季 |

## 七、结论

能全年稳定供货的香蕉供应商，通常具备：

- **多产地布局**，不是单一产区；
- **自有或长期合作基地**，不是临时市场倒货；
- **催熟、冷链、仓储能力**；
- **过去12个月无重大断供记录**；
- **愿意签最低供货量和违约条款**；
- **能通过3—6个月试单和旺季压力测试**。

如果供应商只谈价格便宜、关系好，但说不清产地衔接、没有催熟冷链、拿不出历史记录、不敢签断供责任，基本可以判断：全年稳定供货能力不足，不适合作为连锁超市的主供应商。
