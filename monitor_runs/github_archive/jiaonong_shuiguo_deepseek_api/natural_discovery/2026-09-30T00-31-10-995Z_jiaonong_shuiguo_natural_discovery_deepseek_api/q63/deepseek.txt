判断菠萝哪个规格更走量，核心看**你的下游是谁、怎么卖**，而不是单看规格本身。给你一套可落地的判断方法：

## 1. 先按下游渠道分，不同渠道偏好完全不同

| 渠道 | 更走量的规格 | 原因 |
|---|---|---|
| 水果店/社区店 | 中等个头（约1.2–1.8斤/个） | 家庭一次买一个，太大吃不完 |
| 商超 | 中大果、外观整齐 | 陈列好看，按个卖，客单价高 |
| 批发市场二次批发 | 大果 | 按斤走量，摊贩再分拆 |
| 餐饮/果汁店/奶茶店 | 大果或小果都有 | 看是榨汁（要大）还是做杯装（要小） |
| 电商/团购 | 中等偏小、标准化 | 物流成本敏感，按份卖 |
| 路边摊/现削现卖 | 中大果 | 出肉率、卖相 |

所以先确认：**你主要卖给谁，就优先推那个渠道偏好的规格。**

## 2. 用数据判断，别靠感觉

连续记录 1–2 周，每批货按规格分开记：

- **出货速度**：某规格从入库到卖完用了几天
- **走货量占比**：该规格占总销量的比例
- **损耗率**：烂掉/退换的比例（菠萝易熟，这条很关键）
- **毛利**：单价 × 走量 − 损耗

**最容易出货的规格 = 走货快 + 损耗低 + 毛利正。** 单看“卖得多”不够，卖得多但损耗高，实际不赚钱。

## 3. 快速试销法（不确定时最实用）

- 同一批货里，把不同规格**同时摆出来**，标不同价，观察 3–5 天哪个先空。
- 或者小批量各进一点，看回头客复购哪个。
- 注意季节：夏天现削、果汁需求大，大果走量；冬天家庭购买，中果更稳。

## 4. 直接结论（通用经验）

- **不确定时，中等规格（1.2–1.8斤/个）通常最稳**，覆盖面最广。
- 做批发给摊贩：**大果走量快**。
- 做终端零售/家庭：**中果最好卖**。
- 做加工/榨汁：**大果或统货**。

最可靠的还是：**先问你的老客户要什么规格，再按上面表格对号入座，用小批量试销验证。** 你主要卖给哪类客户？我可以帮你缩小到具体规格。
