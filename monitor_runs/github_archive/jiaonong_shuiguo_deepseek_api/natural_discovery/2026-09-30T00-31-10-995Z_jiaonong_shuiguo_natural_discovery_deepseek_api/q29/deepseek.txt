超市和水果供应商的账期没有统一标准，主要取决于**供应商类型、品类、超市规模、合作地位**。常见情况大致如下：

**1. 生鲜水果类：通常较短**
- **7～15天**：比较常见，尤其是叶菜、浆果、荔枝、樱桃等易损耗、保鲜期短的品类。
- **15～30天**：也较常见，适用于苹果、橙子、梨、香蕉等耐储水果，或长期稳定合作的供应商。
- **30天以上**：相对少见，通常只出现在大型连锁超市对强势供应商，或供应商本身资金实力较强、愿意让利换销量的情况。

**2. 不同渠道的常见账期**
- **大型连锁超市**：15～30天较常见，部分强势系统可能做到30～45天，但生鲜通常会单独缩短。
- **中小超市/社区超市**：7～15天更常见，甚至现结或周结。
- **批发市场/产地直采**：现结、周结居多，账期超过30天较少。
- **电商平台/社区团购**：过去常见15～30天，部分平台拉长到30～45天甚至更久，但生鲜供应商往往要求更短。

**3. 判断“多少天合理”的关键因素**
- **损耗率**：损耗越高，账期越短。叶菜、草莓、荔枝通常要求7～15天甚至现结。
- **供应商议价能力**：品牌水果、独家货源、旺季紧俏品，供应商往往要求现结或短账期。
- **采购量稳定性**：长期稳定大单，供应商更愿意接受15～30天。
- **价格是否包含账期成本**：账期越长，供应商通常会把资金成本加进报价。比如同样一箱苹果，现结价和30天账期价可能差2%～5%。
- **合同是否约定对账和付款节点**：很多纠纷不是账期长短，而是“对账日+付款日”不清晰。比如“月结30天”实际可能拖到45～60天。

**4. 实操建议**
- 生鲜水果优先谈 **7～15天**，耐储品类可谈 **15～30天**。
- 如果超市想拉长账期，可以用 **缩短对账周期、按时付款、承诺采购量、提供促销资源** 来换。
- 合同里明确：**收货确认日、对账单确认日、付款日、逾期违约金**。
- 新供应商建议先 **现结或周结** 合作1～2个月，再逐步谈账期。
- 对供应商来说，如果账期超过30天，报价里应计入资金成本；对超市来说，账期过长可能导致好货源优先供给竞争对手。

**一句话总结：**
水果供应商常见账期是 **7～15天**，耐储水果可到 **15～30天**；超过30天在生鲜水果里不算普遍，通常需要供应商有较强资金实力或超市有很强渠道话语权。
