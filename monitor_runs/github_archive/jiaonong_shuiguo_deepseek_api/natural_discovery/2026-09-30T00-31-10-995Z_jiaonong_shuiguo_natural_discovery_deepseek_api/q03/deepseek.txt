第一次找供货商，别一上来就大单。常见货（香蕉、苹果、橙子）的重点根本不是“能不能进到货”，而是**试出他的稳定性、损耗承担和价格水分**。建议按下面这套流程走。

## 一、先明确：你要试的是供货商，不是水果

第一次合作，核心看四件事：

1. **到货质量稳不稳**（不是第一次好，是每次都差不多）
2. **损耗怎么算**（坏果、烂果、压伤谁承担）
3. **价格是不是真批发价**（对比周边批发市场/同行）
4. **配送及不及时、缺货怎么补**

所以试单要小额、多批次，而不是一次进一堆。

## 二、试单节奏：分3次，别一次定生死

### 第1次：少量试水（1~2天量）
- 香蕉：1~2箱（或1把数少一点）
- 苹果：1~2箱
- 橙子：1~2箱
- 目的：看到货品相、成熟度、包装、有没有以次充好

**重点看：**
- 香蕉：青度是否统一？有没有催熟过度、发黑、断把？
- 苹果：大小是否均匀？有没有碰伤、发面、打蜡过重？
- 橙子：皮是否新鲜？有没有干水、烂底、大小混杂？

### 第2次：加量但压账期（3~5天量）
- 数量翻到第一次的2~3倍
- 要求明确：坏果怎么赔、少货怎么补、临期/过熟能不能换
- 目的：看他忙的时候会不会降质量

### 第3次：模拟正常补货（按你店真实销量）
- 连续合作1~2周
- 记录每天到货质量、损耗率、缺货次数
- 再决定是否长期合作

## 三、三类货分别怎么试

### 香蕉
- **最怕催熟不一致**：一箱里有的能卖、有的当天就黑
- 试单时问清楚：是生蕉还是熟蕉？能不能按你销量分批催熟？
- 第一次别拿太熟的，宁可青一点自己控
- 看损耗：断把、黑斑、压伤比例超过多少他赔

### 苹果
- **最怕大小混、底层烂**
- 试单时要求开箱看底层，不能只看上面一层
- 问清楚：是统货还是分级？80/85/90果怎么算？
- 第一次少拿，观察放3~5天后有没有发面、失水

### 橙子
- **最怕干水、烂底、大小不均**
- 试单时切开几个看汁水
- 问清楚：产地、品种、是否打蜡、保质期大概多久
- 第一次拿小果和中果对比，看你店客群接受哪个

## 四、必须提前谈死的条件

第一次合作前，把这些写清楚（微信文字也算）：

1. **坏果赔付**：到货坏果超过X%怎么赔？是补货还是扣款？
2. **少货补货**：数量不够，下次补还是当场退？
3. **价格有效期**：报价保几天？过节会不会临时涨？
4. **配送时间**：几点送到？晚了影响你开门怎么办？
5. **退换条件**：卖不动的、过熟的能不能换？
6. **结算方式**：现结、周结、还是压一批？第一次建议现结或少量压款

## 五、判断要不要继续合作的标准

试单1~2周后，用这几个指标判断：

- **损耗率**：香蕉>8%、苹果>5%、橙子>5%，就要警惕
- **到货准时率**：经常迟到、缺货，直接换
- **价格**：比周边批发市场高5%以上，除非省了运费和人工，否则不划算
- **售后**：出问题推诿、不补不赔，直接淘汰

## 六、最实用的做法

1. **同时试2~3家**，不要只找一家
2. 每家先拿少量，同一品类对比
3. 每天记录：到货时间、数量、坏果数、卖完时间
4. 一周后算总账：谁的综合成本低、谁最省心，就留谁
5. 长期合作也别只留一家，留一个备用供货商

一句话：**第一次试单，宁可少拿多试，也别贪便宜压大货。你要试的是“长期稳不稳”，不是“这次便不便宜”。**
