茶饮店用香蕉，核心是**按用途定熟度，而不是只按“香蕉熟没熟”采购**。建议把香蕉分成三档管理：

**1. 做香蕉牛奶、奶昔、冰沙、香蕉椰奶**
- **最佳熟度：7～8成熟**
- 表现：果肉已软，甜度上来，但还没有明显酒味、黑斑大面积出现。
- 原因：太生会涩、粉、香气弱；太熟容易发黑、发酸，和奶制品混合后风味容易闷。
- 采购建议：买**微黄、带少量青肩**的，到店后常温放1～2天再用。

**2. 做香蕉泥、果酱、夹心、烘焙内馅**
- **最佳熟度：8～9成熟**
- 表现：表皮大面积黄，带少量褐斑，果肉软甜，香气浓。
- 原因：这个阶段糖分高、香气足，压泥和熬酱效果最好。
- 采购建议：可采购**黄皮带少量斑点**的，但到店后要尽快处理，不适合久放。

**3. 做装饰切片、水果茶顶料、甜品摆盘**
- **最佳熟度：6～7成熟**
- 表现：表皮黄但较硬挺，切片不烂，外形完整。
- 原因：太熟切片会塌、发黑，影响出品颜值。
- 采购建议：买**形体硬挺、颜色均匀偏黄**的，冷藏短存，但不要久放。

**采购控制方法：**
1. **按菜单用量分档下单**  
   不要只订一种熟度。比如：
   - 奶昔类：7～8成熟，占大头；
   - 装饰类：6～7成熟，少量；
   - 果酱/烘焙：8～9成熟，按加工计划订。

2. **看表皮，也看用途**
   - 青肩明显：适合放几天再用；
   - 全黄无斑：适合切片、短期使用；
   - 黄底褐斑：适合打泥、熬酱，当天用；
   - 大面积黑斑、渗液、酒味：报废，不要用于饮品。

3. **控制到货节奏**
   - 夏季高温：香蕉熟得快，采购熟度要**比冬季低一档**；
   - 冬季低温：可适当买熟一点，但避免冻伤；
   - 门店若没有催熟条件，就少量多次采购，不要一次囤太多。

4. **到店后分开放**
   - 未熟香蕉：常温、通风、避免挤压；
   - 快熟香蕉：单独放，减少乙烯影响其他水果；
   - 已熟香蕉：冷藏可延缓1～2天，但表皮会变黑，果肉仍可用；
   - 要打泥的熟蕉：可去皮分装冷冻，按杯取用。

5. **设定验收标准**
   - 合格：无腐烂、无裂口渗液、无严重压伤、无异味；
   - 可收货但需优先用：黄皮带少量褐斑、局部轻微压伤；
   - 拒收：大面积黑斑、发酸酒味、果肉透明水化、表皮渗液。

**简单记：**
- **要切片：买偏硬、6～7成熟；**
- **要打奶昔：买7～8成熟；**
- **要压泥熬酱：买8～9成熟；**
- **门店备货：少量多次，按用途分熟度，不要统一买“全熟”。**
