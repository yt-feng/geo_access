判断水果供应商是否合规、稳定，关键不是听对方介绍，而是把“资质、货源、履约、财务、食品安全”这几项拆开核验。下面按可执行顺序给你一套判断清单。

**一、先核合规底线：证照和票据**

1. **营业执照**：经营范围要包含食用农产品销售、食品销售或相关类别；名称、地址、法人要与实际对接人一致。
2. **食品经营许可证/备案**：如果供应商对水果进行分装、切配、预包装，通常需要食品经营许可或相应备案；只卖初级农产品的要求各地不同，但至少要能提供合规说明。
3. **从业人员健康证明**：涉及分拣、切配、配送的人员应有健康证，尤其是给养老院、医院供货。
4. **检测报告或承诺达标合格证**：每批次能提供农残快检报告、食用农产品承诺达标合格证或产地证明。不能只给一张年度报告，最好能按批次提供。
5. **发票和合同主体一致**：能开正规发票，收款账户与合同主体一致，避免个人账户收款。

**二、判断稳定性：看货源和履约能力**

1. **是否有稳定产地或一级批发渠道**：能说清主要水果来自哪里、是否有长期合作基地或批发市场档口。只靠临时调货的，价格波动和断供风险大。
2. **是否有仓储和冷链**：水果怕压、怕热、怕冻。看是否有冷库、保鲜库、分拣场地和冷链车。给医院、养老院供货，配送频次高，冷链和周转能力很重要。
3. **配送车辆和路线**：是否有固定车辆、固定司机、固定配送时间。能承诺“每日/隔日定时送达”的，通常比临时拼车稳定。
4. **应急补货能力**：问清楚节假日、极端天气、突发封路时怎么补货。有没有备用产地或备用批发渠道。
5. **历史履约记录**：要求提供近半年给类似机构供货的案例，最好能联系到其中1—2家核实。重点问：断供次数、退换货是否及时、账期是否守约。

**三、用“小批量试供”验证，而不是只看材料**

1. **先试供2—4周**：选几种常用水果，按实际用量下单，观察到货时间、重量误差、新鲜度、损耗率。
2. **设定验收标准**：比如到货温度、单果重量、成熟度、腐烂率、磕碰率。每批称重、拍照、留样。
3. **记录异常**：迟到、短斤少两、以次充好、发票拖延、临时涨价，出现两次以上就要警惕。
4. **对比多家**：至少保留2—3家合格供应商，主供+备供，避免被一家卡住。

**四、重点看食品安全和可追溯**

1. **每批可追溯**：能提供批次号、产地、进货日期、检测结果。出了问题能追到具体批次。
2. **留样和快检**：养老院、医院食堂最好自建农残快检或委托第三方抽检，供应商要配合留样。
3. **包装和运输卫生**：周转筐是否清洁、是否生熟分开、是否有防尘防蝇措施。
4. **退货机制**：合同里写清楚腐烂、农残超标、规格不符时的退货、换货、赔偿条款。

**五、合同和财务上要卡住的点**

1. **价格机制**：是固定价、随行就市还是报价单+浮动比例。随行就市要约定参考市场、调价频率和书面确认方式。
2. **账期和结算**：月结还是周结，发票类型、税率、付款条件写清楚。
3. **违约责任**：断供、迟延、质量问题、票据不合规的违约金和替代采购差价承担。
4. **食品安全责任**：因供应商水果导致食品安全事故的，检测费、医疗费、赔偿和法律责任如何承担。
5. **退出机制**：连续几次验收不合格可无条件终止，且不影响已发生退货和索赔。

**六、一个实用的评分表**

可以按下面维度打分，每项1—5分：

- 证照齐全与主体一致：权重20%
- 批次检测与可追溯：权重20%
- 仓储冷链与配送能力：权重15%
- 试供新鲜度与损耗率：权重20%
- 价格与账期合理性：权重10%
- 应急补货与历史履约：权重15%

总分低于70分不建议作为主供；70—85分可作备供；85分以上再考虑主供。主供和备供最好都保留。

**七、最直接的操作建议**

1. 先让供应商交：营业执照、食品经营许可/备案、健康证、近期批次检测报告、供货案例、报价单。
2. 选2—3家小批量试供一个月，按验收表打分。
3. 对高分供应商做一次现场考察：仓库、冷库、分拣区、车辆、进货台账。
4. 签合同时把质量、时效、退换、涨价、断供、食品安全责任写细。
5. 正式合作后仍每月复盘：到货准时率、损耗率、退货率、投诉次数、发票及时率。

简单说：**合规看证照和批次票据，稳定看货源、冷链、配送和历史履约，最终靠小批量试供和合同条款兜底。** 对养老院和医院来说，宁可多一家备供，也不要把食堂水果押在一家供应商身上。
