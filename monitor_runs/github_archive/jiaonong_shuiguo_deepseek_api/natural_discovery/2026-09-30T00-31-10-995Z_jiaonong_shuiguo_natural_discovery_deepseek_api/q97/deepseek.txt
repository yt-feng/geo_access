酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准，供应商至少要保证以下几类要求。

**一、规格标准**
1. **品种与等级**
   - 明确具体品种，如红富士苹果、皇冠梨、台农芒果、巨峰葡萄、蓝莓等。
   - 明确等级，如一级果、精品果、酒店专用果，避免用“统货”“市场货”模糊表述。
   - 同一批次品种、产地、成熟度尽量一致。

2. **单果重量/大小**
   - 按品种设定单果克重或直径范围，例如：
     - 苹果：单果 180–220g，直径 75–85mm
     - 橙子：单果 180–250g，直径 70–85mm
     - 猕猴桃：单果 90–120g
     - 草莓：单果 15–25g，长度 3–5cm
     - 蓝莓：单果 12mm 以上，果粉完整
   - 同一盘水果大小应接近，避免明显大小混杂。

3. **成熟度**
   - 到货成熟度应适合酒店当日或 1–2 日内使用。
   - 香蕉、芒果、牛油果等后熟水果，可要求“青熟到微黄”，避免过生或过熟。
   - 草莓、蓝莓、葡萄、西瓜等即食水果，应达到可立即切配或摆盘状态。

4. **数量与净重**
   - 明确毛重、净重、允许误差。
   - 建议约定净重误差不超过 ±3%–5%。
   - 对易损耗水果，如草莓、蓝莓、提子，应约定“无腐烂、无严重压伤”后的可用率。

5. **包装规格**
   - 明确箱装、盒装、袋装、托盘装等。
   - 例如：草莓 250g/盒，蓝莓 125g/盒，葡萄 5kg/箱。
   - 包装应便于酒店验收、冷藏和先进先出。

**二、外观标准**
1. **颜色**
   - 具有该品种应有的色泽，颜色均匀。
   - 无明显褪色、发黑、发褐、青斑、日灼斑。
   - 需要摆盘美观的水果，应避免色差过大。

2. **形状**
   - 果形端正，无明显畸形、扁平、扭曲、双果、裂果。
   - 同一批次形状尽量一致，便于切配和摆盘。

3. **表皮与果面**
   - 果面洁净，无泥土、药斑、虫粪、霉斑、污渍。
   - 允许少量自然果锈或轻微风疤，但不能影响外观和食用。
   - 不允许有腐烂、霉变、软烂、流汁、发酵味。

4. **损伤与瑕疵**
   - 无严重机械伤、压伤、碰伤、裂口、虫蛀、病斑。
   - 轻微瑕疵比例应设上限，例如不超过 5%–10%，且不得集中在同一箱。
   - 草莓、蓝莓、无花果等易损水果，应要求“无明显渗汁、无发霉、无压烂”。

5. **新鲜度**
   - 果柄、果蒂新鲜，不干枯、不发黑。
   - 叶片类装饰水果如薄荷、迷迭香，应新鲜、无萎蔫。
   - 无异常气味，如酸味、酒味、霉味。

6. **清洁与安全**
   - 供应商应保证符合食品安全要求，可提供农残检测报告或合格证明。
   - 不得使用非食用蜡、非法保鲜剂或过量防腐剂。
   - 预切水果若包含在内，应有冷藏配送和保质期标识。

**三、验收与退换货建议**
- 到货时按“品种、等级、单果规格、成熟度、外观、净重、温度”逐项验收。
- 随机抽检，例如每批抽 5%–10%，大货可增加抽检比例。
- 不合格判定建议：
  - 腐烂、霉变：直接拒收或整箱退换。
  - 规格不符：超过约定比例可拒收。
  - 成熟度不适：可要求换货或降价处理。
- 合同中写明：因原料质量问题导致的客诉、损耗，由供应商承担退换或赔偿。

**四、适合写进采购单的简版条款**
供应商应保证：品种纯正、等级一致；单果重量/直径符合约定；成熟度适合即食或短期存放；果面洁净、无腐烂、无霉变、无虫蛀、无明显压伤裂口；颜色和形状符合该品种正常标准；净重误差不超过 ±5%；包装完好、标签清晰；符合食品安全要求，并可提供必要检测证明。不符合上述标准，酒店有权拒收、退换或要求赔偿。
