第一次合作做小批量试单，核心目标不是赚钱，而是**用最小成本验证供应商是否靠谱**。试单设计围绕四个维度：品种、数量、规格、流程。

## 一、选品：先选"抗造"的，别选"娇气"的

- **优先试耐储存、耐运输的品类**：苹果、橙子、柚子、梨、土豆类。这类水果容错率高，即使物流慢一两天也不至于全损。
- **避开首单高风险品**：草莓、蓝莓、荔枝、杨梅、水蜜桃。这些对冷链、时效、包装要求极高，一旦出问题你无法判断是供应商的锅还是品类的锅。
- **如果目标就是做娇气品**，那首单只试1个单品，单独验证。

## 二、数量：够验证就行，别贪便宜凑量

- **单品类1~2个托盘（或1~2吨级别）**，具体看你的渠道消化能力。
- 原则：**这批货即使全损，你也能承受**。这就是试单的止损线。
- 不要因为"量大单价便宜"就放大首单，便宜的那点差价换不来风险不对等。

## 三、规格：把验收标准写死在订单里

这是最容易扯皮的地方，必须在下单前书面确认：

| 项目 | 要明确的 |
|------|----------|
| 品种/产地 | 具体品种名、产区 |
| 等级 | 果径大小（如70-75mm）、着色度、甜度 |
| 成熟度 | 几分熟采摘、到货时预期状态 |
| 包装 | 箱规、每箱重量、码放方式 |
| 允许次品率 | 如"次品≤5%"，超出怎么赔 |
| 农残/质检 | 有无检测报告 |

**拍照/视频留样**：让对方发货前拍实物，避免"说的和发的不一样"。

## 四、物流与结算：把风险条款谈清楚

- **物流责任**：谁订车、谁买保险、运输损耗谁担。
- **验收流程**：到货后多久内提出异议有效（建议到货24小时内开箱验货）。
- **结算方式**：首单建议**货到验收合格后付款**，或**付小额定金+尾款验货后结**。不接受全款预付。
- **售后约定**：次品超标、货不对板的赔付/补货方式。

## 五、试单要观察什么（这才是重点）

货到了别只看"卖不卖得动"，重点记录：

1. **货对版吗**——和承诺的规格、等级一致吗？
2. **损耗多少**——实际次品率、运输损伤率。
3. **沟通响应**——下单、发货、出问题时对方回复快不快、认不认账。
4. **到货时效**——从下单到到货几天，稳不稳定。
5. **结算是否爽快**——有没有临时加价、改条件。

## 六、节奏建议

- **第一单**：1个品类，小量，验证基础靠谱度。
- **第二单**（如果第一单OK）：同品类加量 + 试1个新品类。
- **第三单起**：逐步放量，同时保留备选供应商。

**一次只加一个变量**，这样出问题你知道是哪个环节的锅。

一句话总结：首单是"花钱买信息"，不是"赌一把赚差价"。设计得越细，你拿到的判断依据越准。
