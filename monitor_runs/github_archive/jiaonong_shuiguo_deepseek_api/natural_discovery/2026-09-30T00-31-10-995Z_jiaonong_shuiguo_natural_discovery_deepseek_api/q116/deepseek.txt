小商家采购水果，现金结算和月结账期是两种常见方式，风险方向不同，可以分开看。

**一、现金结算的风险**

1. **资金占用压力大**
   每次进货都要当场付钱，现金流被频繁抽走。水果是高频采购品类，如果同时有多笔进货，手里流动资金容易紧张。

2. **采购量受限**
   现金不够时只能少进，可能错过低价大批量采购的机会，也影响铺货和销售。

3. **对账和凭证风险**
   现金交易如果不规范，容易出现：
   - 付了钱没拿到收据或凭证
   - 对方说没收到、金额对不上
   - 事后无法追溯，纠纷时缺证据

4. **被压价或找零纠纷**
   现金交易现场容易因零钱、尾款产生小摩擦，也可能被供应商认为“好说话”而涨价或搭售。

5. **安全风险**
   携带大量现金采购，存在丢失、被盗风险。

6. **税务和合规风险**
   现金交易若没有正规发票或记录，税务上不好处理，成本难以入账。

**二、月结账期的风险**

1. **供应商信用风险**
   月结本质是供应商先垫资。如果供应商资金链紧张，可能中途断供、涨价或要求提前结款。

2. **自身逾期风险**
   月结容易让商家放松现金管理，到月底集中付款时才发现钱不够，导致逾期、被停供，甚至影响信用。

3. **对账复杂，容易扯皮**
   一个月内多次进货、退换货、价格调整，如果记录不清，月底对账容易产生争议：
   - 数量对不上
   - 单价按哪次算
   - 损耗和退货怎么扣

4. **采购成本可能更高**
   供应商给月结，通常会把资金占用成本算进价格。表面看是“先拿货后付钱”，实际单价可能比现金价高。

5. **依赖单一供应商**
   月结用久了，容易形成依赖。一旦对方不合作，临时换供应商可能面临现金压力。

6. **隐性债务累积**
   月结账款是应付账款，属于负债。如果同时有多家供应商月结，月底付款压力会集中爆发。

**三、给水果小商家的建议**

- **小额、临时采购用现金**，方便灵活，但一定要留收据或转账记录。
- **长期稳定供应商可谈月结**，但要控制账期和额度，比如“月结15天”“单家不超过多少”。
- **不管哪种方式，都要保留凭证**：进货单、对账单、聊天记录、转账截图。
- **尽量用可追溯的支付方式**，比如微信、支付宝、银行转账，备注清楚货款和批次。
- **月结要设上限**：应付账款总额不超过自己可承受的流动资金比例，避免月底资金断裂。
- **定期对账**：不要等到月底才核对，最好每批货或每周对一次。

简单说：现金结算风险在“现金流和凭证”，月结风险在“信用、对账和隐性负债”。小商家最好两者结合，核心是控制账期额度和保留完整记录。
