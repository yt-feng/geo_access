优先看你的门店客群和损耗承受能力，一般建议：

**1. 主推“小把装”（2–4根）**
- 最适合便利店：客单价适中，顾客拿起来就能买。
- 比单根更像“商品”，比整袋更容易冲动购买。
- 适合上班族、学生、单人/双人家庭。

**2. 单根适合做补充**
- 适合门店客流快、顾客只想马上吃、或客单价敏感的场景。
- 但单根毛利低、称重/贴标麻烦，也容易被人挑来挑去。
- 如果做，建议定价简单直接，比如“1根2元/3元”，不要按复杂称重。

**3. 整袋适合特定情况**
- 适合社区店、家庭客多、下班买菜型客流。
- 能提高客单价、减少分拣，但风险是：
  - 卖不完熟得快，损耗高；
  - 顾客会嫌“太多吃不完”；
  - 价格敏感时不如小把好卖。

**实操建议：**
- **新上架先试组合：小把装为主 + 少量单根 + 少量整袋。**
- 观察 1–2 周：
  - 如果单根卖得快、小把也快：保留单根和小把，减少整袋。
  - 如果整袋卖得快：说明家庭客多，可增加整袋。
  - 如果香蕉熟得快、损耗大：减少整袋，改小把，并控制订货量。
- 香蕉最好按成熟度分开：
  - 偏青的做小把/整袋；
  - 偏黄的做单根或即食区，快速清货。

**结论：**
大多数便利店首选 **小把装**，单根做补充，整袋只在社区家庭客明显时做主推。
