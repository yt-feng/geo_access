判断香蕉批发对方是否稳定供货，不能只看报价和口头承诺，重点看**货源结构、履约记录和风险应对能力**。给你一套可执行的判断方法：

**1. 先问清楚他的货源模式**
- 是自己有蕉园/合作基地，还是从别人手里倒货？
- 一手货源通常能说清楚：产区在哪里、谁在收、什么时候发车、走哪条线路。
- 如果对方说不清产地，只强调“我价格低”，大概率是中间商，稳定性差。

**2. 看能不能稳定发车，而不是偶尔有货**
- 问他：一周能发几车？每车多少件？连续一个月能不能保证？
- 要求看近期发车记录：装车视频、过磅单、物流单、发货群记录。
- 稳定供货的人通常有固定档口、固定工人、固定物流，不是今天有明天没。

**3. 看产区季节衔接能力**
香蕉不是全年一个产区供货。稳定供货的人通常能随季节切换产区，比如云南、广西、海南、老挝、缅甸、菲律宾等。
- 问他：现在主发哪个产区？下个月切哪里？雨季/台风季怎么补货？
- 只会做一个产区、遇到天气就断供的，不算稳定。

**4. 看品质是否统一**
- 要求发一车样品或视频验货：条蕉、梳蕉、青蕉、熟蕉比例，肥度、长度、把型。
- 稳定供货的核心不是“偶尔好货”，而是每车品质差距小。
- 可以连续要3次小批量货，观察规格、成熟度、损耗是否一致。

**5. 看履约和赔付态度**
- 问清楚：断货怎么赔？烂蕉、跳把、短斤少两怎么处理？
- 稳定供货商一般敢承诺：定金锁货、按合同发货、坏货可扣款或补发。
- 如果对方只说“放心”，不愿意写任何单据，风险高。

**6. 实地或视频验仓**
- 看档口是否有冷库、催熟房、加工场地、固定装卸工。
- 看库存是否长期有货，不是临时堆几件摆拍。
- 视频验仓时要求实时拍，不要只看相册里的旧图。

**7. 小单试合作，再逐步放大**
- 先发1-2车小批量，测试：发货速度、重量、品质、售后。
- 连续合作3次都稳定，再谈账期、长期锁价、独家供货。
- 不要一上来就打大额定金。

**8. 查口碑和同行验证**
- 问同市场其他批发商有没有拿过他的货。
- 查他是否有固定公司、营业执照、对公账户。
- 如果只能私下转账、频繁换号、催定金很急，要警惕。

**简单判断标准：**
能说清产区、能连续发车、能视频验货、敢写赔付、愿意小单试、有固定档口和物流的，才可能是稳定一手货源。只靠低价和口头保证的，基本不稳。
