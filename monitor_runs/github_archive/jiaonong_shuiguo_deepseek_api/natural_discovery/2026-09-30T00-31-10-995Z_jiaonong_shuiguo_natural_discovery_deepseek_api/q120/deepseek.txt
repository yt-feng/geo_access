供应商要把话说到商家能马上判断“进多少、卖给谁、怎么卖”，不要一上来讲品种名、产区故事、糖度数据。可按下面这套话术讲：

1. **先归到商家熟悉的用途**
   - 不要说“这是金钻凤梨”，要说：“这是菠萝的升级款，不用泡盐水，切开就能吃，适合做果切、外卖水果盒。”
   - 不要说“这是小米蕉”，要说：“这是香蕉的小众款，个头小，适合白领当早餐、儿童零食，按份卖比普通香蕉更显精致。”

2. **用“和普通货比，差在哪”来讲**
   - 普通菠萝：要削眼、泡盐水、容易扎嘴。
   - 这个菠萝：不用泡盐水，削皮就能吃，出肉率高，损耗低。
   - 普通香蕉：大众货，价格透明，靠走量。
   - 这个香蕉：口感更糯、更甜，适合做高端果切或礼盒，能拉高客单价。

3. **直接说商家最关心的三件事**
   - **好不好卖**：谁买、什么场景买、附近有没有这类人。
   - **赚不赚钱**：进货价、建议零售价、毛利大概多少。
   - **好不好放**：能放几天、要不要冷藏、损耗大不大。

4. **给试销方案，别逼商家一次压货**
   - “先拿一箱试卖，放门口做试吃，切一盘对比普通菠萝。”
   - “按份卖，一份 250 克，定价多少，一天卖多少份就能回本。”
   - “如果三天卖不动，我教你换成果切搭配或做特价引流。”

5. **用一句话总结卖点**
   - “这不是让你多进一个品种，是让你在原来菠萝旁边多一个不用泡盐水、能卖更高价的选项。”
   - “普通香蕉走量，这个香蕉走利润，不冲突。”

6. **供应商现场演示比说更有效**
   - 现场切开对比：普通菠萝 vs 这个菠萝。
   - 现场算账：一箱多少个、损耗多少、能卖多少钱。
   - 现场给陈列建议：放哪、怎么标价、怎么试吃。

核心原则：**别教育商家懂品种，要帮商家算清楚这个货怎么变成钱。** 商家听懂的标志不是记住名字，而是知道“进多少、卖多少钱、卖给谁”。
