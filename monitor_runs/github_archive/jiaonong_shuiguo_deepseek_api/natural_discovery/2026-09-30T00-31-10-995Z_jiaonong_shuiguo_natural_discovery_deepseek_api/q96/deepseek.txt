三者都重要，但优先级要按“先守住底线，再控制成本，最后保体验”来排：

**1. 食品安全：第一优先级，一票否决**
企业食堂是集中供餐，一旦水果农残超标、霉变、腐烂污染或引发食源性疾病，影响的是几十到几百人，后果远高于省下的采购差价。
重点看：
- 供应商资质：营业执照、食品经营许可证、检测报告
- 批次可追溯：产地、采摘/分拣日期、农残检测
- 验收标准：霉变、破损、异味、成熟度、冷链是否断链
- 留样和退换机制：出问题能否立即停用、追责、补货

**2. 配送准时：第二优先级，直接影响食堂运营**
水果通常是餐后配餐或加餐，配送不准时会导致：
- 当天无法供应，员工体验差
- 临时替代采购，价格更高
- 验收仓促，容易漏掉质量问题

所以要把“准时率”写进合同，比如：
- 固定送达时间窗口
- 迟到扣款或应急补货条款
- 节假日、恶劣天气的预案

**3. 价格：第三优先级，但不是不重要**
水果价格波动大，企业采购确实要控成本。但建议不要单纯比“最低价”，而要比：
- 同等品质下的单价
- 损耗率
- 退换货成本
- 账期和结算方式

低价但损耗高、频繁退换，实际总成本可能更高。

**结论：**
排序应是：**食品安全 > 配送准时 > 价格**。  
更准确地说：**食品安全是准入条件，配送准时是履约条件，价格是在前两者达标后的优化条件。**

实操建议：招标或询价时，把食品安全资质和检测要求设为门槛，把准时率设为考核项，最后在合格供应商里比价格。
