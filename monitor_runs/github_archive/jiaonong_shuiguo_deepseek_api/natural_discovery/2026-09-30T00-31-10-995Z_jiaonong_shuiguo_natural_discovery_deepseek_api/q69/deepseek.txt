给香蕉、菠萝分级报价，核心是**先定级，再定价，最后把价差说清楚**。对批发商和小店最实用的做法是：

## 一、先统一“分级维度”

### 1）香蕉分级
建议按 **外观 + 成熟度 + 单根规格** 分：

- **A级**
  - 果形直、饱满，无明显黑斑、擦伤、裂口
  - 成熟度一致，适合直接上架或1–2天内卖
  - 每把整齐，单根长度/粗度较均匀

- **B级**
  - 有轻微擦伤、少量黑点，但果肉正常
  - 成熟度略不齐，适合做促销或尽快卖
  - 规格稍小或不齐

- **C级**
  - 黑斑多、压伤明显、掉把、裂口
  - 适合低价走量，或加工用途
  - 不建议按正常零售价给小店

香蕉报价最好再标一句：
- **青蕉**：耐放，适合小店慢慢卖
- **黄蕉/熟蕉**：上架即卖，但损耗快
- **催熟蕉**：到店后1–3天集中卖

因为香蕉价格受成熟度影响很大，不写成熟度，后面容易扯皮。

### 2）菠萝分级
建议按 **单果重量 + 外观 + 熟度** 分：

- **A级**
  - 单果重达标，果形端正，冠芽完整
  - 无明显裂口、软烂、黑心风险低
  - 适合正常零售、切果、礼盒

- **B级**
  - 单果略小或果形稍歪
  - 有轻微擦伤、日灼斑，但不影响食用
  - 适合促销、切块、做果汁

- **C级**
  - 小果、畸形、明显伤口、熟度不齐
  - 适合加工或特价处理

菠萝最好按重量直接分档，例如：
- 大果：1.5kg以上
- 中果：1.0–1.5kg
- 小果：0.8–1.0kg
- 等外：0.8kg以下或有伤

## 二、报价方式要统一单位

小店最容易糊涂的地方，就是单位不统一。建议固定：

- 香蕉：**按箱 / 按把 / 按公斤** 三者只选一种主报价
- 菠萝：**按个 / 按箱 / 按公斤** 只选一种主报价

推荐写法：

**香蕉**
- A级：XX元/箱（约XX斤，XX–XX根/把）
- B级：XX元/箱
- C级：XX元/箱
- 备注：今日熟度、是否催熟、可放几天

**菠萝**
- A级大果：XX元/个
- A级中果：XX元/个
- B级：XX元/个
- C级：XX元/个
- 备注：单果重范围、熟度、是否可切果

## 三、价差怎么定比较清楚

可以用“同级同价、级差明确”的方法：

### 香蕉
- A级：基准价
- B级：A级的 **80%–90%**
- C级：A级的 **50%–70%**

如果熟度很高、当天必须走：
- 直接在报价单写“今日熟蕉特价”，不要混在A级里。

### 菠萝
- A级大果：基准价
- A级中果：大果的 **80%–90%**
- B级：A级的 **60%–80%**
- C级：A级的 **40%–60%**

这样小店一看就知道：  
不是随口压价，而是按等级对应折扣。

## 四、最清楚的报价单模板

可以这样发给小店：

**今日香蕉报价**
- A级青蕉：XX元/箱，约XX斤，适合存放3–5天
- A级熟蕉：XX元/箱，适合1–2天卖完
- B级：XX元/箱，轻微花皮，建议促销
- C级：XX元/箱，压伤/黑斑较多，特价走量

**今日菠萝报价**
- A级大果：XX元/个，1.5kg以上
- A级中果：XX元/个，1.0–1.5kg
- B级：XX元/个，轻微擦伤/果形稍歪
- C级：XX元/个，小果/伤果，适合切果

**统一说明**
- 报价含/不含运费
- 是否包售后
- 几件起送
- 当天几点前下单
- 坏果怎么赔

## 五、避免扯皮的关键

1. **样品定级**：第一次合作先给小店看A/B/C实物，确认标准。
2. **照片留档**：每次发货前拍该批次等级照片。
3. **售后规则写清**：
   - 运输压伤、自然熟烂、存放过久，责任不同
   - 例如：到货24小时内拍照，按比例赔；超过时间不赔
4. **不要只报一个价**：  
   只报“香蕉3块、菠萝5块”，小店一定会拿C级要求A级。
5. **按等级给不同建议用途**：
   - A级：正常上架
   - B级：促销/切果
   - C级：特价/加工

## 六、最简执行版

你可以直接这样定：

**香蕉**
- A级：外形好、熟度整齐 → 正常价
- B级：轻微花皮、大小不齐 → 正常价8–9折
- C级：黑斑压伤多 → 正常价5–7折

**菠萝**
- A级：果形正、重量达标 → 正常价
- B级：略小/轻伤 → 正常价6–8折
- C级：小果/伤果 → 正常价4–6折

关键不是分得多复杂，而是：**等级标准固定、报价单位固定、售后规则固定**。这样小店能判断值不值，你也能减少还价和扯皮。
