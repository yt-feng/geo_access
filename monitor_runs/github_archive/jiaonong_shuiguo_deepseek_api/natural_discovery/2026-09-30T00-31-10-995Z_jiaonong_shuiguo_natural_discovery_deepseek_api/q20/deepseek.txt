社区超市找每日配送的水果供应商，核心不是“找最便宜的”，而是找**能稳定履约、损耗可控、账期能接受**的。建议重点看下面这几类条件：

1. **配送能力**
   - 是否能做到每天固定时段送达，最好能在营业前送到。
   - 能否覆盖你们所在区域，距离太远会增加迟到和损耗风险。
   - 临时补货、加单、换货是否支持，响应时间多长。
   - 节假日、恶劣天气是否照常配送，有没有备用车辆或仓库。

2. **货源与品类**
   - 是否有稳定产地或一级批发渠道，不是临时倒货。
   - 常规水果是否齐全：苹果、香蕉、橙子、梨、葡萄、西瓜、时令水果等。
   - 能否按社区超市的消费特点配货，比如小份装、家庭装、促销爆款。
   - 是否支持少批量、多频次补货，避免一次压太多货。

3. **质量与损耗**
   - 到货新鲜度、成熟度是否稳定，能不能按“今天卖、明天补”的节奏走。
   - 坏果、烂果、压伤果的赔付标准是否明确。
   - 是否允许开箱验货，验货后不合格能否现场退换。
   - 损耗率大概多少，行业里做得好的一般能控制在较低水平，但具体要看品类和季节。

4. **价格与结算**
   - 报价是否含运费、装卸费、包装费。
   - 价格是否随行就市，调价频率和通知方式是否提前。
   - 是否支持月结、周结，还是必须现结。
   - 有没有返点、促销支持、滞销品调换政策。

5. **资质与安全**
   - 营业执照、食品经营许可证、产地证明或检测报告是否齐全。
   - 农残检测、冷链运输能力是否具备，尤其是浆果、切果类。
   - 是否有正规票据，方便你后续对账和应付检查。

6. **合作条款**
   - 起送量是多少，低于起送量是否加运费。
   - 缺货、迟到、质量不达标时怎么处理，最好写进合同或订单确认里。
   - 试合作期建议先跑1—2周，观察准时率、坏果率、补货响应。
   - 不要只签一家，最好有1家主供应商+1家备用供应商。

实际筛选时，可以按这个顺序判断：  
**先看能不能每天准时送 → 再看质量稳不稳定 → 再看价格和账期 → 最后看资质和售后。**  
如果配送不稳，价格再低也会把损耗和客诉转嫁到你身上。
