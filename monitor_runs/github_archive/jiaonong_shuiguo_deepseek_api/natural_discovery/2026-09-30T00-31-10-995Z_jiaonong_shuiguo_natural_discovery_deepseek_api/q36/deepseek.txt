建议：**以“整果为主、切果为辅”，不要二选一。** 具体做哪种，取决于你门店的客流结构和损耗控制能力。

## 直接判断

| 情况 | 更适合 |
|---|---|
| 社区店、家庭客群多、有冰箱 | 整果为主，切果少量 |
| 商圈店、写字楼、年轻人多、即买即吃 | 切果占比提高 |
| 高端超市、客单价高 | 整果做品质，切果做便利 |
| 低毛利、损耗管控弱 | 尽量卖整果，少切 |
| 有冷链、日清机制 | 可以放大切果 |

## 为什么整果更稳
- **损耗低**：不切就不容易坏，卖不掉还能继续陈列。
- **毛利可控**：整果按个/按斤卖，定价简单。
- **适合家庭**：一个菠萝一家人吃，客群匹配。
- **采购简单**：不用额外人工、刀具、包装、冷藏。

但整果的问题是：**购买门槛高**。很多人嫌削皮麻烦、不会挑、一次吃不完，所以会流失即食型顾客。

## 为什么切果更好卖
- **即买即吃**：写字楼、学校、商圈、地铁店效果明显。
- **降低决策门槛**：不用削、不用挑，拿了就走。
- **可做组合**：菠萝块+其他水果拼盘，提高客单价。
- **减少“不会开”的流失**：把不想动手的人变成顾客。

但切果的核心风险是：**损耗和食品安全**。切后保质期短，卖不掉就是报损。

## 实操建议

1. **整果做主力，切果做补充**
   - 整果占菠萝销量 **60%—80%**
   - 切果占 **20%—40%**，按门店客流调整

2. **切果只做小份、日清**
   - 小盒装，当天切当天清
   - 不要一次切太多，宁可少切多次

3. **整果做两种规格**
   - 普通整果：走量
   - 精品/去皮整果：提高客单

4. **切果重点投放在这些位置**
   - 收银台附近
   - 水果区入口
   - 冷藏柜即食区
   - 写字楼店、商圈店可加大

5. **用数据决定比例**
   - 连续观察 **2—3周**
   - 看整果和切果的**销量、毛利、报损率**
   - 切果报损超过 **10%—15%**，就减少切果量

## 一句话结论
**社区家庭店：整果为主，切果少量试销。商圈/写字楼/年轻客群店：整果+切果并行，切果比例提高。**  
最终标准不是“哪个更好卖”，而是：**哪个在控制损耗后，综合毛利更高。**
