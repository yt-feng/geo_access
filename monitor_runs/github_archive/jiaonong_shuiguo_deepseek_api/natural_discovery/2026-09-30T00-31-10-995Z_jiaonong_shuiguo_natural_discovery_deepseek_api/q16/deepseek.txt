建议把“本地批发”和“稳定供应商”分开用途，不要二选一。

**香蕉：优先本地批发或本地一级商**
香蕉是后熟型水果，损耗高、周转快。社区超市每天销量有限，最怕一次进太多、催熟不均、压货发黑。
建议：
- 找本地批发市场里专做香蕉的档口，按 1–2 天销量小批量补货。
- 如果本地有催熟库或一级香蕉商，可以让他们按你需要的成熟度供货。
- 初期每天少量试销，观察 3–7 天销量，再决定稳定进货量。

**苹果：优先稳定供应商**
苹果相对耐储，品质和规格更重要，比如红富士、嘎啦、冰糖心等，顾客会看大小、颜色、脆度、甜度。
建议：
- 找能长期稳定供货的产地供应商、区域经销商或批发市场固定档口。
- 先谈小批量试供，确认规格、糖度、硬度、坏果率。
- 要求分级明确，比如 75#、80#、85#，避免大小混装。
- 谈好售后：坏果率超过多少补货或扣款。

**更稳的组合做法**
1. 香蕉：本地批发 + 高频补货，控制在 1–2 天库存。
2. 苹果：稳定供应商 + 每周 1–2 次补货，保持 3–5 天安全库存。
3. 两家都先试供 1–2 周，记录：进价、损耗率、顾客反馈、退货率。
4. 不要只比进价，要算“到手可卖成本”：
   - 进价 + 运费 + 损耗 + 坏果 + 人工分拣。
5. 香蕉可以本地拿，苹果可以稳定拿；如果本地苹果质量稳定且便宜，也可以本地为主，但必须固定档口。

**简单判断标准**
- 损耗高、成熟快、需要天天补：本地批发。
- 耐储存、看规格、要长期稳定：稳定供应商。
- 初期量小：本地批发试销。
- 销量稳定后：苹果转稳定供应商，香蕉保留本地灵活补货。

如果只选一个：**香蕉选本地批发，苹果选稳定供应商**，这样最适合社区超市的小批量、低损耗经营。
