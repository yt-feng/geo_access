水果店采购菠萝，核心不是“挑最熟的”，而是**按预计销售速度分层采购**：马上卖的可以偏熟，放几天卖的必须偏生。菠萝是后熟型水果，采后还会继续变黄、变香、变甜，但过熟后很快黑心、出水、发酒味。

判断熟度可以按下面几个可执行标准：

1. **看果皮颜色**
   - **全青、果眼紧闭**：很生，适合放3—5天以上再卖，但甜度低、酸度高。
   - **青黄相间、底部开始转黄**：最适合采购，通常可放2—4天，成熟后品质稳定。
   - **大面积金黄、底部橙黄**：1—2天内必须卖完，适合确定能走量的门店。
   - **果皮橙红、发暗、局部褐斑**：过熟风险高，损耗大，除非当天促销，否则少采。

2. **看底部和果眼**
   - 底部开始变黄、有香味，说明成熟启动。
   - 果眼变平、变浅，通常比果眼深陷的更熟。
   - 底部发软、渗汁、有黑点，说明过熟或开始腐烂。

3. **闻气味**
   - 几乎无味：偏生，可存放。
   - 底部有清甜菠萝香：成熟度合适，适合近1—2天销售。
   - 整体香味浓、带酒味：过熟，必须当天处理。

4. **按压测试**
   - 轻按底部和中部，硬实：偏生。
   - 稍有弹性、不塌陷：合适。
   - 一按就软、出水：过熟或内部已坏。

5. **看叶片和果柄**
   - 叶片青绿、挺立：较新鲜。
   - 叶片枯黄、易拔：存放较久，熟度可能偏高。
   - 果柄切口新鲜、无霉斑：更好。
   - 注意：叶片容易拔不代表一定熟，更多反映存放时间和品种特性。

6. **掂重量**
   - 同样大小，越重通常水分越足。
   - 但过熟菠萝可能因内部出水、空心而重量异常，要结合气味和按压判断。

采购建议：

- **当天卖的量**：采青黄相间、底部微黄、有淡香、轻按稍软的。
- **2—3天卖的量**：采青黄相间、底部刚转黄、基本无香或淡香的。
- **3天以上卖的量**：采偏青、果眼紧、无香、硬实的，但不要全青，否则后期甜度差。
- **高温季节**：后熟快，采购熟度要降一档，青黄相间即可。
- **低温季节**：后熟慢，可以适当采黄一点。
- **整箱采购**：不要全采同一熟度，按“偏生、适中、偏熟”搭配，避免集中成熟。

简单记：
**青黄相间、底部微黄、淡香、轻按稍软，是最稳的采购熟度。**
**全黄浓香、底部软、有酒味，只适合当天促销，不适合常规采购。**
