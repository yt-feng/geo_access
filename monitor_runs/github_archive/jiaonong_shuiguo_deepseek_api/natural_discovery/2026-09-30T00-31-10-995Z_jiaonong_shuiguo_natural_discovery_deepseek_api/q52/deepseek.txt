采购时优先选“青黄相接”的香蕉，不要选已经全黄、带黑点或柄部发黑的。到店后按下面做，能明显延缓变黑：

1. **买成熟度偏生的**
   - 最佳状态：果皮大部分黄、两头带一点青，捏起来硬实但不生硬。
   - 避免：全黄、有梅花点、果柄发黑、局部软塌的。

2. **到店先拆袋、通风**
   - 香蕉在袋里会积聚乙烯，催熟很快。
   - 到店后立刻取出，放在阴凉通风处摊开，不要堆压。

3. **不要冷藏整串香蕉**
   - 香蕉怕冷，冷藏容易表皮变黑。
   - 如果已经熟透、当天要用，可以冷藏，但表皮会变黑，果肉短期还行。

4. **分开挂放或单层平放**
   - 最好用挂钩悬挂，减少受压。
   - 不能挂就单层平放，果柄朝上，避免叠压。

5. **把果柄包一下**
   - 用保鲜膜包住香蕉柄部，能减少乙烯释放。
   - 注意是包柄，不是整根包死。

6. **和苹果、梨、番茄分开**
   - 这些水果释放乙烯多，会催熟香蕉。
   - 甜品店后厨如果同时有这些，务必分区放。

7. **按用量分批催熟**
   - 不要一次全买熟香蕉。
   - 一部分放阴凉处慢慢熟，一部分需要当天用的再单独催熟。
   - 催熟可放苹果一起，但要及时分开。

8. **已经熟了的处理**
   - 当天用不完的熟香蕉，可去皮后冷冻，做奶昔、香蕉泥、蛋糕。
   - 不要继续常温堆着，否则很快发黑发软。

简单判断：
- **想放 2～3 天**：买偏青、硬实的，拆袋、通风、挂起来。
- **想放 4～5 天**：买更青的，柄部包膜，远离苹果梨。
- **当天就用**：可以买熟一点的，但到店后尽快处理，别闷在袋里。

最关键一句：**别买全熟、别闷袋、别堆压、别和苹果梨放一起。**
