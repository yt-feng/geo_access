对绝大多数餐饮连锁来说，**中央厨房统一收货更好**；但前提是你的中央厨房具备冷藏、分拣、品控和配送能力。门店分散收货通常只适合水果品类极多、门店密度低、供应链不成熟或单店采购灵活度要求极高的场景。

可以按下面判断：

**一、中央厨房统一收货的优势**
1. **品控统一**  
   水果的成熟度、糖酸度、大小、外观标准可以统一验收，避免各门店标准不一致，影响出品稳定性。

2. **采购议价更强**  
   总部或央厨集中采购，量大，更容易拿到低价、稳定货源和账期。

3. **食品安全可追溯**  
   批次、供应商、检测报告、农残快检记录集中在央厨，追溯和留样更规范。

4. **减少门店操作和腐败空间**  
   门店只负责收货确认或直接使用，减少店长/厨师长私下采购、虚报损耗、收受回扣的问题。

5. **配送效率更高**  
   可以按门店订单统一分拣、称重、贴标，再按线路配送，尤其适合门店集中、频次固定的连锁。

6. **库存和损耗更可控**  
   央厨可以统筹调拨，把A店用不完的转到B店，减少单店报损。

**二、门店分开收货的优势**
1. **水果新鲜度可能更高**  
   对草莓、杨梅、荔枝、樱桃等极短保水果，门店直配减少中转，可能更快到店。

2. **本地化灵活**  
   不同城市、商圈门店可以买当地当季水果，价格和品质更灵活。

3. **初期投入低**  
   不需要央厨分拣区、冷藏库、配送车辆和品控人员。

4. **适合小店模型**  
   如果门店少、水果用量小、没有央厨，硬做统配反而成本高。

**三、关键判断标准**
建议用这5个问题判断：

1. **水果是否影响核心产品？**  
   如果水果是招牌菜、饮品、甜品的关键原料，必须统收统配。

2. **门店数量是否超过10—20家？**  
   超过后，分散收货的品控和采购漏洞会明显放大。

3. **水果是否短保易损？**  
   叶菜型、浆果型水果可考虑“央厨统采+供应商直配门店”，但标准和价格仍由总部锁定。

4. **央厨是否有冷链和分拣能力？**  
   没有冷链，统配反而会增加损耗。

5. **配送半径和频次是否合理？**  
   同城或300公里内、每日/隔日配，适合统配；跨区域太远，可分仓。

**四、推荐模式**
多数连锁更适合：

**总部统一供应商、统一价格、统一标准 + 中央厨房统一收货、分拣、配送 + 门店只验收数量和质量。**

如果水果特别短保，可以用折中方案：

**总部锁供应商和标准，供应商直配门店，门店按总部标准验收，数据回传总部，央厨或总部做抽检和结算。**

**结论：**
- 有央厨、门店多、水果是核心原料：**中央厨房统一收货更好。**
- 门店少、无央厨、水果短保且本地化强：**门店分开收货更现实。**
- 最推荐的是：**总部统管标准与采购，央厨统收统配；短保品类可供应商直配，但必须纳入总部品控体系。**
