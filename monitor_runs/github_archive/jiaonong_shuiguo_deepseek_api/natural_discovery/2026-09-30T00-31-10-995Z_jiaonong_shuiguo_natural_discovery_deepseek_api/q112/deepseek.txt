坏果率的赔付触发点没有统一法定标准，主要看合同约定和行业惯例。可以按下面几个档来把握：

**常见约定区间**
- **5% 以内**：通常视为合理损耗，一般不单独赔付，按正常扣重处理。
- **5%～10%**：不少批发/商超采购合同会约定开始按比例扣款或折价结算。
- **超过 10%**：多数采购方会要求整批退货、换货或按实际坏果比例赔付。
- **超过 20%～30%**：通常可认定为严重不合格，支持拒收、全额退款并索赔。

**实操建议**
1. **合同里写清“验收标准”**：明确抽样方法（如随机抽几箱、每箱抽多少）、判定时间（到货后几小时内）、由谁判定。
2. **写清赔付计算方式**：例如“坏果率超过 8% 的部分，按坏果重量对应货款的 2 倍扣减”或“整车退货，运费由供方承担”。
3. **区分“坏果”定义**：腐烂、压伤、发霉、未熟/过熟，标准不同，最好逐项列明。
4. **保留证据**：到货照片/视频、开箱记录、第三方检测或双方签字确认单，否则索赔容易扯皮。

**一句话结论**：如果合同没约定，一般以 **超过 5% 开始协商扣重、超过 10% 要求赔付或退换** 作为谈判底线；最终以你合同里写明的数字为准。
