通常 **直接买成品果丁的总损耗更低**，尤其是你店里菠萝用量不算特别大、后厨人手紧、切配标准不稳定时。

但要分两种“损耗”看：

1. **可看见的原料损耗**
- 鲜果：要削皮、去眼、去芯，实际出肉率大概只有 **40%~60%**，品种、成熟度、人工熟练度影响很大。
- 成品果丁：到货基本就是可用的果肉，开封后主要损耗是汁水流失、压碎、过期变质。

2. **隐藏损耗**
- 鲜果：人工时间、冷藏空间、切配失败、品相不稳定、当天用不完氧化出水。
- 成品果丁：采购价通常更高，但省人工、省时间、出品稳定；如果订货量不准，也会因开封后变质造成损耗。

**判断建议：**
- 如果你每天菠萝用量大、后厨有人能稳定切配、能按计划当天用完：鲜果更划算，损耗也能压低。
- 如果你用量中等偏小、人工贵、切配容易浪费、需要稳定出品：直接买成品果丁，综合损耗通常更低。
- 如果只比较“果肉浪费率”，鲜果损耗更高；如果比较“门店总成本+总浪费”，成品果丁往往更低。

**最实用的做法：**
先做 3 天测试：
- A 方案：买鲜果，记录进货重量、削完后净重、报废重量、人工耗时。
- B 方案：买成品果丁，记录到货重量、实际可用重量、报废重量、采购差价。

然后算：
**每公斤可用果丁成本 =（采购成本 + 人工成本 + 报废成本）÷ 实际可用重量**

哪个低，就选哪个。多数小型甜品店，成品果丁的综合损耗更低；用量大的店，鲜果切配更省钱。
