通常情况下，水果店遇到坏果的结算或赔付方式取决于双方合同约定。以下是常见的处理标准和建议：

1. **明确合同条款**：首先查看与供应商签订的采购合同或协议，其中通常会有关于坏果比例（如“损耗率”）和赔付方式的具体规定（如按比例扣款、换货或免费补货）。

2. **常见赔付标准**：
   - **按比例赔付**：若坏果率超过约定的损耗率（如5%），超出部分由供应商按进货价赔偿。
   - **全额退换**：对于明显腐烂、变质、严重机械伤等影响销售的坏果，供应商常同意退换或冲抵货款。
   - **折扣结算**：部分供应商会同意将坏果部分折价结算（如按50%价格结算）。

3. **操作流程**：
   - **及时取证**：收货时发现坏果，立即拍照或录像留存证据（包括外包装、坏果数量、批次号、到货时间）。
   - **按流程沟通**：第一时间联系供应商客服或业务员，说明情况并发送证据。
   - **确认处理方式**：与供应商商定具体方案（换货、补货、扣款等），并书面确认（如微信聊天记录、邮件或平台记录）。
   - **保留凭证**：保留所有沟通记录和单据，作为后续结算依据。

4. **无明确约定时的合理做法**：
   - 如果合同未写明，行业惯例通常是：轻微坏果（如局部软烂）按20%-50%折扣赔付；严重坏果（如全烂、发霉）按100%退换或扣款。
   - 如供应商不配合，可考虑协商以“下次进货抵扣”或“赠送等值货物”方式处理。

5. **注意事项**：
   - 尽量在**收货后24小时内**反馈问题，避免因时间推移导致责任不清。
   - 长期合作关系下，很多供应商会适当让步以维护关系。
   - 若涉及大额损失或经常出现坏果，建议重新评估供应商或签订更详细的合约。

如果无法协商一致，可依据合同条款或相关法律（如《民法典》中关于买卖合同的规定）提出正式索赔要求。
