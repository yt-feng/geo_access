连锁超市与水果供应商签年度合同时，以下条款最容易踩坑，需特别注意：

1. **价格调整机制**  
   - **问题**：未明确市场价格波动（如季节性涨价、异常天气导致减产）时的调价规则。  
   - **建议**：约定价格浮动范围（如±10%）或绑定参考指数（如批发市场均价），并明确调价触发条件和执行时间。

2. **品质验收标准**  
   - **问题**：使用“新鲜”“成熟”等模糊描述，导致退货争议。  
   - **建议**：量化指标（如糖度≥12%、无机械伤率≥95%），并约定第三方检测机构（如SGS）作为仲裁标准。

3. **保证金与违约责任**  
   - **问题**：供应商违约（如断供、质量不达标）时，保证金扣除比例不明确。  
   - **建议**：明确每类违约行为的罚款金额或比例（如延迟交货每日扣0.5%货款），并约定保证金退还条件。

4. **最低供货量与灵活性**  
   - **问题**：超市要求“保底量”但未考虑实际需求波动，导致库存积压或短缺。  
   - **建议**：设定浮动区间（如±20%），并加入“重大事件”（如疫情、天气灾害）免责条款。

5. **货款结算周期**  
   - **问题**：账期过长（如60天）导致供应商资金链压力，引发断供风险。  
   - **建议**：分阶段结算（如每月按实际到货量结款），或约定逾期付款利息（如日万分之三）。

6. **退货与短重处理**  
   - **问题**：超市以“顾客投诉”为由退货，但未规定退货比例上限。  
   - **建议**：约定退货占总订单比例≤3%，且需提供拍照/视频证据；短重按同价差补偿而非退货。

7. **专属权与排他性**  
   - **问题**：供应商同时给竞品供货，导致超市货源或价格劣势。  
   - **建议**：明确是否独家供货、区域限制（如仅限本市），并约定违约赔偿（如销售额30%）。

8. **不可抗力条款**  
   - **问题**：仅列自然灾害，未覆盖“运输中断”“政策限行”等实际风险。  
   - **建议**：列举具体情形（如港口罢工、突发检疫），且注明免责需提供官方证明。

9. **证件与合规性**  
   - **问题**：供应商无农药残留检测报告或产地证明，超市被连带处罚。  
   - **建议**：要求每批次提供检验报告，并约定“证件缺失视为违约”。

10. **合同终止条件**  
    - **问题**：仅规定“协商终止”，未考虑持续质量问题或长期缺货。  
    - **建议**：写入“单方解约权”（如连续3次品质不达标），并设置30天过渡期。

**实操建议**：  
- **逐条列清**：所有量化标准（如甜度、账期天数）需精确到数字；  
- **保留证据**：验收、调价协商过程需邮件或系统留痕；  
- **小型供应商**：简化条款，避免因过度约束导致合作破裂。
