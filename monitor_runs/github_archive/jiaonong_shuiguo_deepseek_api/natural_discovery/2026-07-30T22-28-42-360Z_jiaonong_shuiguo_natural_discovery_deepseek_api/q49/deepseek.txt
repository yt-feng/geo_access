临时补货的关键在于**快速、明确地沟通，并提前锁定价格与质量**。建议按以下步骤操作：

1. **立即电话/微信联系现有供应商**  
   明确说明：旺季需求激增，需紧急补货**X公斤/箱**，询问其库存、单价及最快到货时间。

2. **约定核心条款（优先口头确认，随后书面确认）**  
   - **价格**：确认是否沿用原合同价，或按市场临时价（旺季可能涨价，建议要求折扣或量价挂钩）。  
   - **数量**：写明本次需求**X公斤**，并预留弹性（如±10%浮动）。  
   - **到货时间**：精确到**X月X日X时前送达**，并约定逾期赔偿比例（如每日0.5%货款）。  
   - **质量**：要求符合原标准（如新鲜度、无腐烂），允许抽查，不合格可拒收或扣款。  
   - **支付方式**：可协商先付定金（如30%），尾款验货后付清。

3. **要求供应商出具补充协议或签收单**  
   即使时间紧迫，也要留痕（微信聊天记录或邮件），写明：补货数量、价格、最晚到货时间、违约责任。

4. **备用方案**  
   若原供应商无法满足，同步联系1-2家备用供应商（可考虑批发市场或周边同行调货），但需提前确认菠萝品种和规格是否一致。

5. **后续管理**  
   旺季期间，建议提前一周报备采购计划，与供应商约定“临时优先补货权”（例如可加价10%但保证供应）。  

**一句话总结**：电话沟通锁定价格、数量、到货时间，微信文字确认关键条款，验收时严格对照标准。
