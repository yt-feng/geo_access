和供应商合作时，为了避免旺季断货，建议提前明确以下关键问题，优先确保供应稳定：

1. **日/周最大产能与补货周期**  
   “你目前每天最多能供应多少斤（或箱）？从下单到到货，最快需要几天？紧急加单需要多久？”

2. **旺季历史供应量与波动预案**  
   “过去两年，你的果园/批发库在5月、10月（选对应旺季月）分别发了多少货？如果今年需求突然翻倍，能协调多少额外库存？”

3. **品质分级与次品处理**  
   “如果到货后开箱发现烂果、压伤或规格不符，怎么处理？是现场直赔、换货，还是按比例退款？次品率有没有承诺标准（如≤3%）？”

4. **价格锁定与调价机制**  
   “旺季前能否签保量锁价协议？如果市场价格突然暴涨，你多久会调价？涨价的触发条件和上限是多少？”

5. **包装与运输责任**  
   “泡沬箱+纸箱还是散装？夏季高温天会用冷链车吗？运输途中损耗算谁的？破损包赔是100%还是按比例？”

6. **付款与账期**  
   “第一次合作需要全款预付吗？长期合作能否月结30天？旺季加单能否先货后款？”

7. **应急违约条款**  
   “如果旺季你突然断供/涨价，合同里有什么赔偿？能否提前1周通知？有没有备用供应商推荐？”

**额外建议**：  
- 索取近期3家长期客户的联系方式，匿名问该供应商的旺季履约情况。  
- 首次合作时，旺季前1个月先小批量试单，并压一周库存应对突发断供。
