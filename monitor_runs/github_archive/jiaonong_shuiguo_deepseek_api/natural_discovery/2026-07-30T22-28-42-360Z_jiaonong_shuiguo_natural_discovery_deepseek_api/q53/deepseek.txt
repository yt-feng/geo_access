对于每天需要少量水果的餐饮店（如奶茶店、小餐馆、简餐店），省心为主的供应商选择建议如下：

1. **首选本地大型生鲜电商/社区团购平台**  
   - 例如美团优选、叮咚买菜、朴朴超市等，它们通常有稳定的小份包装水果，下单后次日达，补货灵活，无需起订量，有售后保障（坏果包赔）。  
   - 优点：配送准时、品种齐全、可随时调整数量，适合少量高频需求。

2. **对接附近的农贸市场小批发商**  
   - 直接去当地农贸市场的固定摊位，说明是长期小批量采购，部分商家愿意按“零售价+小折扣”甚至“按斤称重”供货。  
   - 优点：价格可能比线上更低，可现场挑选新鲜度，每周或隔天固定时间自提即可，一般能接受少量欠款或周结。

3. **合作附近的社区水果店或连锁超市**  
   - 与门口的水果店谈长期合作，每天按需提供已分装好的小份水果（如切好的菠萝、盒装草莓），他们可能更愿意为了稳定客源提供优惠或送货上门。  
   - 注意：需明确每日交接时间（如早上6点前送到）和变质退换规则。

4. **使用专业餐饮食材采购APP**  
   - 如美菜网、快驴进货等（主要面向餐饮商家），虽然主打大份，但部分城市支持按“零售单位”下单，且有售后服务，适合有固定餐单的店铺。  
   - 注意：查看是否支持“小份加购”或“每日补货”，避免起订量过高。

**省心核心操作：**  
- **签长期试配合同**：与1-2个供应商试合作1-2周，看配送准时率、水果新鲜度、售后响应速度。  
- **统一标准**：要求供应商每次提供相同品种（如固定苹果是某个品种、香蕉的成熟度），减少挑选精力。  
- **设定每日下限**：比如每天最低采购金额30元，若某天不需要，提前一天通知即可，避免浪费。

**避坑建议：**  
- 不要选只做“团购”或“批发大单”的供应商，他们会因订单量小而不愿调整。  
- 提前问清：如果当天水果不达标（如磕碰、熟烂），是否可以无条件无理由退货，由谁承担运费。
