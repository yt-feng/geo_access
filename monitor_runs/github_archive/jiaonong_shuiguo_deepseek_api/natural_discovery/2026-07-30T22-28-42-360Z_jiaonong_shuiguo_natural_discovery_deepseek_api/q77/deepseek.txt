针对生鲜电商采购菠萝，建议优先考虑**切配菠萝**和**冷冻菠萝**，**整果**相对更适合线下场景。具体分析如下：

### 1. 整果菠萝：**不太推荐线上主推**
- **问题：** 用户自行削皮、去眼、切块操作门槛高，耗时长（约5-10分钟），且易切伤手。线上无现场指导，差评风险高（如“太硬”“不甜”）。
- **适用场景：** 仅适合“产地直发”或“整箱团购”等价格敏感型、且用户有处理意愿的场景。若做C端零售，转化率普遍较低。

### 2. 切配菠萝（即切即食）：**强烈推荐**
- **优点：**
  - **高转化率：** 90%以上用户愿意为“省去处理时间”付费，复购率比整果高40%-50%。
  - **标准化：** 切配后按克重或份数包装，便于定价（如9.9元/盒200g）、配送和库存管理。
  - **降低损耗：** 可提前处理掉有瑕疵的菠萝（如局部碰伤），整体损耗率可从整果的15%-20%降至5%-8%。
- **注意：**
  - 处理需在低温洁净环境完成，当天采摘后4小时内加工，真空或气调包装，全程冷链运输（2-6℃）。
  - 包装不宜过厚（避免出水），建议配冰袋和泡棉箱。

### 3. 冷冻菠萝：**推荐作为长尾补充**
- **优点：**
  - **极低损耗：** 可存放6-12个月，适合作为酸奶/果汁/烘焙原料，解决夏季过季后供应问题。
  - **客单价高：** 可按家庭规格（如500g袋装）或果粒/碎果形式售卖，毛利率可达50%以上。
- **劣势：**
  - 解冻后口感变软、酸甜度下降，不适合直接生食，需明确标注“适合制作饮品或烹饪”。
  - 需要用户具备料理习惯，购买频次低（通常月复购1次）。

### 综合建议：
- **首选方案：** 主做**切配菠萝**，占SKU的70%，按日销售周期滚动采购。
- **辅助方案：** 在切配之外，上架**冷冻菠萝**（占20%），面向制作冰沙、菠萝饭等场景用户。
- **整果策略：** 仅作为“产地直发”活动款或拼团款（占10%），强调“自己削才新鲜”，同时附赠削皮刀教程卡片。

**最终结论：** 切配菠萝>冷冻菠萝>整果菠萝。重点控制切配损耗和冷链成本，使用防出水包装。
