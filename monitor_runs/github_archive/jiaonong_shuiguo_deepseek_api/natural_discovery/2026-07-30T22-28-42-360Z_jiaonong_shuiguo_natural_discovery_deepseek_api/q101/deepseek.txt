和供应商谈酒店早餐水果供应合作时，建议关注以下几点，以确保供应稳定、质量可靠且成本可控：

1. **供应稳定性与季节性**：明确要求供应商具备全年不间断供货能力，尤其要确认反季节水果的来源（如进口或冷库储备）。要求对方提供备选方案，以防主产区因天气、疫情等突发问题断供。

2. **质量标准与分拣规范**：明确水果规格（如大小、成熟度、无损伤）、包装要求（防挤压包装）以及验收标准。可要求供应商提供样品或实地查看其分拣流程，确保早餐水果外观、口感统一。

3. **配送时效与条件**：约定每日最晚到货时间（比如早上6点前），并要求使用冷链运输（尤其是夏季或易腐水果）。明确验货流程：到货后有权拒收不达标产品，并需供应商立即补货。

4. **价格与付款条款**：建议提前锁定3-6个月的基准价格，同时约定价格浮动机制（如因季节或市场涨幅超过10%时重新协商）。避免一次性全款，可约定月结或根据送货单分期付款，并明确延期罚款。

5. **合同细节与应急条款**：合同中写明最低起订量、违约赔偿（如配送延迟1小时扣款X%）、单方面解约条件。要求供应商提供食品安全检测报告（如农残、重金属检测），并购买产品责任险。

6. **长期合作与监控**：建议先签订3个月试合作合同，根据其表现再续约。要求供应商每月提供供应总结报告（含批次、合格率、反馈），并可定期进行突击库存抽查。

最后，建议多联系1-2家备选供应商，避免完全依赖单一货源。如果酒店规模较大，可考虑与几家供应商联合谈判，以量换价。
