针对批发档口拓展餐饮客户（如奶茶店、甜品店、水果捞、餐厅等），建议准备以下规格，兼顾性价比与使用便利性：

**菠萝：**

-   **规格1：去皮去芯菠萝肉块（3kg/袋或5kg/袋）**  
    - 适合：果茶店、水果捞、沙拉店，直接切块或打汁，节省人工。
    - 注意：需真空包装或冷冻，标明确切糖度（如12-14度）。
-   **规格2：整颗去皮菠萝（约1.2-1.5kg/颗）**  
    - 适合：西餐厅或精品饮品店，需现场切配展示。
    - 注意：提供防氧化处理（如浸泡淡盐水或维生素C溶液），可延长货架期24小时。
-   **规格3：冷冻菠萝块（2.5kg/袋，切成立方体2-3cm）**  
    - 适合：做冷饮、冰沙、蛋糕装饰，不缩水。
    - 提示：标注“速冻锁鲜”，包装上说明“无需解冻可直接使用”。

**香蕉：**

-   **规格1：特级大果（单根>200g，约4-5根/斤）**  
    - 适合：切盘、制作奶昔、装饰甜点，果肉饱满，出杯率高。
    - 供应：成熟度7-8成（黄皮硬果），到店后1-2天可使用。
-   **规格2：小果或次果（单根120-180g，约5-6根/斤）**  
    - 适合：做果酱、烘焙或打浆，成本更低。
    - 提示：批发档口可主推“熟透果”特价打包（如当天口感最佳，适合快消品）。
-   **规格3：冷冻香蕉泥（1L/袋或500g/真空袋）**  
    - 适合：奶茶店、连锁饮品店标准化出品，省去剥皮、打泥步骤。
    - 要求：零添加纯果泥，保质期6个月以上，冷链配送。

**对餐饮客户的关键沟通要点：**
- 明确标注“去芯”“熟度”“是否真空”“冷链配送等级”“最低起订量”。
- 提供“整箱包装+独立小包装”双选项（大店整箱，小单店用小包）。
- 给客户试吃样品，并展示规格对比（如大果vs小果的切片大小差异）。
