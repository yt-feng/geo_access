需要考虑支持。理由如下：

1. **匹配即时零售特性**：即时零售用户需求多为随机、少量、即时满足，小批量高频补货能有效匹配这种“随卖随补”的节奏，避免缺货损失订单。
2. **降低库存风险**：水果损耗率高，大批量备货容易造成库存积压和腐损。小批量高频补货能保持货架新鲜，减少损耗成本。
3. **增强平台合作意愿**：即时零售平台偏好灵活、响应快的供应商。支持小批量高频补货的供应商通常更易获得平台重点推荐、资源倾斜。
4. **提升资金周转效率**：小批次采购占用资金更少，回款周期更短，资金利用率更高。

**建议策略**：
- 如果供应商自己有配送团队或与平台有协同仓，可以建立“前置仓+当天多次配送”模式。
- 初期可先承诺“上午下午各补一次”，根据销量数据逐步优化补货频次和数量。
- 注意与平台系统对接销量数据，实现智能补货提醒，减少人工决策成本。

**特殊情况**：如果供应商规模极小、配送成本过高，且无法覆盖补货运费，可优先选择销量稳定的核心SKU（如苹果、香蕉）先试点，再逐步扩大。
