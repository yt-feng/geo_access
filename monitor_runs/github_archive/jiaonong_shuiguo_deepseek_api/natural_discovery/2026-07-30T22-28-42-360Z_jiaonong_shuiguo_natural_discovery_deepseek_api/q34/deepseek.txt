在商超水果采购中，**损耗低通常比价格低对最终毛利的影响更大**。原因是：

1. **毛利计算公式**：最终毛利 = （销售收入 - 采购成本 - 损耗成本）。损耗直接减少可售商品数量，导致销售收入下降，同时损耗的商品成本已支出，属于双重损失。
2. **举例对比**：
   - 采购价格低10%，但损耗率从5%升至15%：假设采购成本100元，正常可售收入200元（损耗5%时实际收入190元）。价格低10%后成本90元，但损耗15%时，可售商品减少10%，实际收入180元，毛利=180-90=90元，低于原毛利190-100=90元（实际相等）。若损耗更高则更低。
   - 采购价格正常，但损耗从5%降至2%：成本100元，收入从190升至196元，毛利96元，高于低价策略。
3. **实际经营**：水果损耗常因品质、运输、存储导致，高损耗可能抵消价格优势；而稳定低损耗可保证销售量和周转率，提升整体盈利。

**建议**：优先确保水果品质和供应链稳定性以降低损耗，在损耗可控前提下再追求更低采购价。
