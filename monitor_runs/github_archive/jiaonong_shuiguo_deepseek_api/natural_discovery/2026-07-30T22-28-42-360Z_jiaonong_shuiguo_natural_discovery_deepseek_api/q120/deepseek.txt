好的，针对普通商家（比如水果店、小型批发商、社区团购团长）的特点，他们最关心的是：“好不好卖、耐不耐放、赚不赚钱”。供应商介绍产品时，应该把专业术语翻译成“大白话”，切中这三个痛点。

**核心原则：** 不说“品种名”，说“卖点”；不说“技术指标”，说“对比优势”。

以下是具体的“翻译”话术模板和场景举例：

#### 1. 介绍新奇特/小众品种时
**错误示范：** “这是马来西亚的MD2金菠萝。” （商家听了一脸懵）
**正确话术：** “这个菠萝是**不用挖眼、不用泡盐水**的，切开就能吃，**芯也是甜的**。你在小区团购群里一说‘不用处理’就能直接啃，宝妈们肯定抢着买，**复购率很高**。”

-   **翻译逻辑：** 把品种名（MD2）翻译成“不用挖眼、芯甜”（卖点），把“马来西亚产地”翻译成“复购率高好卖”（利益）。

#### 2. 介绍高甜度/口感时
**错误示范：** “这个甜度达到18度以上，果肉紧实。”
**正确话术：** “这个香蕉**越放越甜、不软烂**。你昨天进的货，今天卖不完，明天放熟了，口感反而像奶油一样滑。不像那种便宜的香蕉，放一天就发黑、发软烂了，损耗少很多。”

-   **翻译逻辑：** 把“甜度18度”翻译成“越放越甜”（耐卖），把“果肉紧实”翻译成“不放坏、损耗少”（利润保护）。

#### 3. 介绍外观/卖相时
**错误示范：** “这个是优级果，单果重XX克，果面干净。”
**正确话术：** “你看这个菠萝，**个头大、头小屁股大**（单果重），摆摊时**眼睛一看**就觉得比旁边摊位的货‘靓’。客户拍照发朋友圈，都不用滤镜，光指着‘绿色顶花’和‘金黄身子’就愿意掏钱。”

-   **翻译逻辑：** 把“单果重”翻译成“个头大、视觉冲击强”，把“果面干净”翻译成“拍照好看、客户自发传播”。

#### 4. 介绍特殊品种（如红皮香蕉、树熟芒果）时
**错误示范：** “这是红皮香蕉，花青素高。”
**正确话术：** “这种香蕉**外观像火龙果一样稀有**，你摆在门口最显眼的位置，老人小孩经过都会多看一眼。它**皮薄肉厚、香甜软糯**，你拍条短视频发抖音，**自带流量**。虽然不是走量的主力，但绝对是**引流、拉高客单价**的好东西。”

-   **翻译逻辑：** 把“花青素高”翻译成“有噱头、适合引流”，把“稀有品种”翻译成“制造话题、增加利润”。

### 总结：让“供应商”变“翻译官”

| 客户关心的点 | 供应商应该说的“人话” |
| :--- | :--- |
| **好不好卖？** | “这个卖相/颜色特别吸引路过的人” / “适合发朋友圈、短视频引流” |
| **耐不耐放？** | “放三天不软不烂” / “越放越甜、不影响口感” |
| **赚不赚钱？** | “损耗低，卖不完明天还能卖” / “比普通品种单价高，但好卖，利润空间大” |

**一句话口诀：** **“别谈品种名，就说好看好吃好卖；别谈数据，就说耐放损耗少；别谈产地，就说客户抢着要。”**
