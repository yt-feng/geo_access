作为水果供应商的客户经理响应慢，对门店经营会直接产生以下几类负面影响：

1. **缺货与销售机会损失**  
   门店需要根据销售情况快速补货，尤其是时令水果保质期短。如果客户经理迟迟不处理补货订单或确认到货时间，门店可能出现断货，错失高峰销售时段，直接减少营收。

2. **损耗成本增加**  
   水果易腐坏，若遇到质量问题（如压伤、霉变）需要退货或换货时，响应延迟会导致问题水果继续存放，形成更大损耗。门店需自行承担废弃成本或低价甩卖损失。

3. **价格波动风险失控**  
   水果市场价格变化快，客户经理若未及时传递调整后的供货价、促销政策或库存预警信息，门店可能以高价进货后遭遇市场低价，造成利润压缩甚至亏损。

4. **客户信任与口碑下降**  
   门店无法及时满足顾客对新鲜水果的需求，或反复出现断货、品质问题，会导致老顾客流失。尤其生鲜零售中口碑传播快，负面体验可能影响周边社区的长远客源。

5. **内部运营效率低下**  
   门店员工需要反复催促、等待答复，浪费大量时间在沟通协调上，影响正常的货架整理、陈列和销售服务。同时，缺乏及时的商品信息（如到货品种、产地变更），促销或陈列计划也无法有效执行。

6. **错失竞争机会**  
   其他供应商能提供更及时响应时，门店有动力切换合作对象。长期响应慢会削弱该供应商的议价能力和合作稳定性，最终使门店在供应链竞争中处于劣势。

**总结建议**：如果问题持续，可尝试与供应商管理层沟通，明确期望的响应时限（如订单2小时内确认、质量问题4小时内处理），并将响应速度作为供应商考核指标之一。同时，考虑储备备选供应商，降低单一依赖风险。
