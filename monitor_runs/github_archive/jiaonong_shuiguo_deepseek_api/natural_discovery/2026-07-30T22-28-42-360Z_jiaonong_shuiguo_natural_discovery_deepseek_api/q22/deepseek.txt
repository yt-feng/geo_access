针对超市水果区提高客单价，香蕉、菠萝和苹果是比较常见的基础水果，组合促销的关键是让顾客感觉“多买更划算”。建议如下：

**1. 主推“家庭装”或“拼盘装”组合**
- 将3根香蕉、1个菠萝、3个苹果组合成一袋或一盒，定价为单买总价的**85%-90%**。
- 例如：单买香蕉4元、菠萝12元、苹果6元（总价22元），组合装定价**18.8-19.8元**。

**2. 突出“果汁/沙拉套餐”场景**
- 制作指示牌：“鲜榨果汁推荐（香蕉+菠萝+苹果）”，或“水果沙拉拼盘”。
- 捆绑销售：买2个菠萝+3个香蕉+4个苹果，赠送一个小号沙拉碗或一次性手套。

**3. 利用香蕉易损耗特点做引流**
- 将香蕉作为“低价引路品”：单买香蕉不降价，但**组合购买时香蕉算作赠品**。例如：买菠萝和苹果各1个，送2根香蕉。

**4. 明确阶梯价格**
- 方案一：单买苹果5元/斤，菠萝8元/个；**三样合买苹果4元/斤+菠萝6元/个+香蕉限时半价**。
- 方案二： **满20元（含菠萝+苹果）送3根香蕉**。这能让目标客单价从可能12-15元提升到20元以上。

**5. 视觉与陈列**
- 在菠萝旁放一张“食谱卡”：菠萝炒饭、菠萝苹果沙拉、香蕉菠萝奶昔，强调组合的多样性。
- 设置一个独立“组合促销堆头”，用醒目的爆炸贴标出“省XX元”或“多买多省”。

 **建议优先尝试第1个“家庭组合装”+第5个“情景陈列”**，这是直接提高每单金额且容易试行的办法。注意控制菠萝和香蕉的损耗率，组合装最好当日或半日内组装完毕。
