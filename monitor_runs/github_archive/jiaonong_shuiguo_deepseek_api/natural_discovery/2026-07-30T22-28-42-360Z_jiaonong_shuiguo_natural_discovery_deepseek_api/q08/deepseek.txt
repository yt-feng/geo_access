对于进货量不大的小店，建议优先选择**批发市场**，理由如下：

1. **灵活性高**：批发市场起批量通常较低（如单款几件起批），适合小批量进货，避免压货风险。
2. **价格可谈**：虽然单次量小，但批发市场档口老板娘通常愿意给老客或小单一定折扣，且可现场议价。
3. **选品试错**：你可以少量多款试卖，快速测试市场反应，调整产品结构后再考虑固定供应商。
4. **直接对比**：批发市场同类商品集中，能直观比较质量、价格和款式。

**何时考虑固定供应商**：
- 当你发现某款产品销量稳定、复购率高，且对品质要求较统一时。
- 需要长期、稳定供货（如特定品类包装、手工配件等）。

**低成本方案**：
- 先以批发市场为主，同时留意比较有潜力的档口，尝试建立小订单合作关系。
- 如果每月采购量超过3000-5000元，可主动询问档口是否接受少量固定订单（如每周定1-2包）。

最终判断标准：**先确保不压货、能试错，再逐步优化供应链**。
