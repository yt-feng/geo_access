三者都非常重要，但**食品安全是前提和底线**，失去食品安全，价格再低、配送再准时也毫无意义。具体建议如下：

1. **食品安全（最高优先级）**  
   - 必须确保供应商有正规资质（如食品经营许可证）、水果检疫证明。  
   - 定期抽检农残、霉菌，并记录留样（应对溯源和纠纷）。  
   - 避免采购已出现变质、腐烂的产品（如霉变、挤压破损）。

2. **价格（次优先级）**  
   - 在保证安全的前提下，通过集中采购、签约供应商、季节性囤货降低成本。  
   - 可参考当地批发市场日均价，要求供应商提供报价单并接受定期比价。  

3. **配送准时（执行优先级）**  
   - 提前约定每日配送时间（如早7:00前送达），并约定迟到扣款或补送机制。  
   - 选择有冷链能力的供应商，防止高温下水果腐坏（若配送路程长）。  

**操作建议**：  
- 与供应商签订合同，明确“食品安全一票否决权（如发现变质可无条件召回并赔偿）”。  
- 建立“先验货、后付款”制度，签收时随机开箱检查质量和数量。  
- 如果预算允许，可考虑组合策略：与2-3家供应商签约，做“主供+备份”，既保安全又控价格和时效。
