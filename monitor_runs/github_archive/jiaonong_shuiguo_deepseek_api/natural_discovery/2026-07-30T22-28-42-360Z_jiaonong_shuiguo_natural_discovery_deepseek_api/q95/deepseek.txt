选择学校食堂的水果供应商时，建议从以下几个方面入手，确保品质、安全与稳定供应：

1. **资质与合规性**  
   - 要求供应商提供营业执照、食品经营许可证、水果产地证明及农残检测报告（需符合国家食品安全标准）。  
   - 优先选择有学校或大型单位供货经验、信誉良好的供应商。

2. **品质与新鲜度**  
   - 实地考察或要求供应商提供样品，检查水果外观（无腐烂、病斑）、成熟度（香蕉、苹果、橙子需达到可食用标准）及包装。  
   - 了解供应商的冷链物流能力，确保运输中保持低温（如香蕉需防止低温冻伤）。

3. **价格与稳定性**  
   - 与多家供应商询价，对比同一品种、规格（如苹果的等级：红富士 vs 其他品种）的批发价及季节性波动。  
   - 明确是否包含送货费用、退换货条款（如水果变质如何处理）及账期。

4. **合同条款**  
   - 在合同中写明：供应品种、规格（如苹果直径80mm以上）、无损伤率（如≤5%）、交付时间、违约赔偿（如到货延误、品质不达标）。  
   - 要求定期更换品种以保持新鲜度（如每周提供不同产地的橙子）。

5. **风险控制**  
   - 选择至少2家备选供应商，避免单一依赖。  
   - 关注季节性因素：香蕉易熟，需缩短采购周期（如3天一次）；苹果、橙子可耐储存，适当增加单次采购量。

建议：先小批量试单（如每周采购50kg），验证品质与配送效率后再签订长期合同。
