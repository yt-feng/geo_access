第一次试单最关键的是**小批量、多对比、控制风险**，不要一次性订太多。以下是根据常见水果特点的具体建议：

### 1. 香蕉：最易损耗，先试熟度把控
- **试单量**：建议只进 **1-2箱**（约13-17公斤/箱）。
- **找供货商要点**：重点问清楚“到货是几成熟？”（通常建议7-8成熟，青皮带黄）。要求供应商承诺**到货后2-3天内不会大批量变黑**。
- **验证方法**：开箱后立即检查有无大量“水烂”或“裂柄”。测试自己店内常温存放能否撑3天。
- **试单目标**：找到能给你**稳定发“7成半熟”**的供应商，且能容忍你每次只拿一两箱。

### 2. 苹果：耐储存，但重包装和规格
- **试单量**：可拿 **1-2箱**（不同品种各一箱，如红富士、嘎啦）。
- **关键问题**：确认是**70#、75#还是80#果**（数字越大果越大，价格越高）。问清是“纸袋果还是膜袋果”（纸袋果口感更脆甜，膜袋果易发酸）。
- **验证方法**：切开尝心（是否发黑、发绵）。拿回家放一周，看表皮是否起皱。用秤称量整箱**净重**是否符合（常有缺斤短两）。
- **试单目标**：找到**个头均匀、口感脆、价格适中的一手批发商**。

### 3. 橙子：看季看酸度
- **试单量**：拿 **1箱**（约30斤起，或按件拿）。
- **夏季（夏橙/伦晚）**：重点尝酸度是否过高，皮是否太厚、汁水少。**试单时当场要求切开1-2个**。
- **冬季（脐橙/沃柑）**：看果皮是否油亮、蒂部是否干枯（代表新鲜度）。称重时注意整箱重量。
- **验证方法**：拿回家放一周，看是否变干或发霉。观察果柄切口是否新鲜（发黑说明库存久）。
- **试单目标**：找到**皮薄、汁多、酸甜比合适**（不要纯酸或纯甜无风味）的产地直发或一级批发商。

### 4. 通用的防坑操作（必做）
- **当面验货**：约定到货后 **30分钟内开箱验货**，发现有烂果、压伤、规格不符要立即拍照拒收或索赔。
- **分批对比**：同一种水果，找 **2-3家**各自拿一箱，标注好来源，对比品质和价格，只留1家长期合作。
- **结算方式**：首次尽量现结/日结，不要压账。表明“如果货好，以后稳定拿货”。
- **避免唯价格论**：低于市场均价很多的，通常混入次品或短秤。品质稳定的中小供应商比大型批发商更适合夫妻店。

**简单总结**：第一次试单，香蕉和橙子各**1箱**，苹果按品种各**1箱**。总投入控制在500元以内。卖完再决定是否加量，不要为了“打折”或“量大价优”冲动压货。
