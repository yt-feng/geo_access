评估水果供应商的仓配覆盖能力，需要结合门店分布、水果特性（保鲜期短、易损耗）和供应链效率。以下是具体评估维度与方法：

### 1. 基础覆盖数据评估
- **仓配网络匹配度**：列出供应商所有仓库（含冷链）位置，与你的门店城市分布进行**距离/时效匹配**。例如：供应商在上海有仓，能覆盖江浙沪；但你的门店在新疆，则需评估是否有中转仓或直发能力。
- **服务半径**：要求供应商提供每个仓库的服务范围（通常冷链车200公里内日配，300-500公里需次日达）。标注出你的门店是否在其核心辐射圈。

### 2. 配送时效与稳定性
- **到店时间要求**：根据门店销量（如日配、隔日配），询问供应商能否保证**指定时间段内到货**（如早6点前到店）。
- **应急机制**：若某仓缺货或运输受阻，是否有备选仓或紧急调拨方案（如跨区域调车、启用第三方冷链）？

### 3. 冷链与损耗控制
- **冷链设备**：供应商是否有专用冷藏车、保温箱，以及运输过程中的温度监控（如GPS实时回传温度数据）。
- **水果特性管理**：不同水果（如草莓、榴莲）对温湿度、振动敏感，需评估其分拣、预冷、包装是否匹配。例如：硬质水果（苹果）可混放，但软质水果（芒果）需单独防压。

### 4. 历史数据与参考验证
- **现有客户案例**：要求供应商提供与服务相似门店规模（如便利店、社区生鲜）的合作案例，重点看覆盖城市和配送准时率（≥98%为优）。
- **试用测试**：选取2-3个不同城市门店（如一线、二线、偏远城市），试运行1-2周，统计**到货完好率**（≥95%）、**破损率**（<3%）和**履约率**（订单按时到店占比）。

### 5. 成本与灵活性
- **配送阶梯价**：不同距离、订单量的运费差异。例如：同城每箱3元，跨省每箱8元，需对比自建物流或第三方冷链的成本。
- **最小起订量**：偏远门店若销量低，供应商是否接受小单（如每次50箱以下）且不额外加价？

### 6. 数字化追踪能力
- **系统对接**：供应商能否提供订单追踪API或小程序，实时查看车辆位置、到店预计时间、温度曲线。这直接决定你对门店的补货响应速度。

### 操作建议：
1. **绘制热力图**：将门店按城市/区域分组，加上供应商仓点，直观看到覆盖空白区。
2. **做压力测试**：模拟节日促销（订单量翻倍），看供应商仓配能否临时扩容。
3. **合同明确KPI**：将“配送时效、完好率、应急响应时间”写入合同，并设置违约扣款条款（如延误扣运费20%）。

如果某区域始终无法满足要求，可考虑 **“主供应商+区域应急供应商”** 组合模式。
