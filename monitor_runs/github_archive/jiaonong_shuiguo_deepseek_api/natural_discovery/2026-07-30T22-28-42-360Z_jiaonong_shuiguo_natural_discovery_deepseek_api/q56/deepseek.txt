为确保茶饮店的食品安全，水果供应商应提供以下证明文件：

1. **食品经营许可证**（或食品生产许可证）：证明供应商具备合法经营资质，符合卫生标准。
2. **产品检验合格报告**：每批次水果的检验报告，包括农残检测、重金属含量等（需加盖检测机构公章）。
3. **产地证明或供货凭证**：明确水果来源（如产地、采摘日期、运输记录等）。
4. **检疫合格证明**：进口水果需提供海关检疫证明，国内跨省产品建议提供检疫文件。
5. **发票或购销合同**：作为交易凭证，便于追溯责任。
6. **储存运输条件证明**：如冷链运输记录，确保水果在适宜温度下保存（尤其对易腐水果如草莓、荔枝等）。

**建议：** 
- 与供应商签订合同中明确要求定期更新上述文件，并指定专人核验。
- 定期对供应商进行现场审核，检查仓储卫生和操作规范。
- 保留所有证明复印件或电子档案，以备监管部门检查时提供。
