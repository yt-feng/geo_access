水果采购锁价的时间通常取决于多种因素，包括水果品种、市场波动性、双方合作关系以及合同条款等。一般情况下，锁价期限可以从以下范围参考：

- **短期锁价**：常见于价格波动大的水果（如应季水果、进口水果），通常锁价1-2周，部分可能按周或按月锁定。
- **中期锁价**：对于价格相对稳定的水果（如苹果、梨等大宗品种），或与长期合作的供应商，可能锁价1-3个月。
- **特殊情况**：若市场极不稳定或供应商有库存压力，锁价可能仅几天；反之，通过预付款或长期合同，部分可锁价半年甚至一年。

实际谈判时，建议先评估水果的市场周期（如产新季前后价格变化明显），并结合自身采购频率、供应商供应能力及行业惯例来协商。最好在合同中明确锁价期限、数量、质量及价格调整机制，以降低风险。
