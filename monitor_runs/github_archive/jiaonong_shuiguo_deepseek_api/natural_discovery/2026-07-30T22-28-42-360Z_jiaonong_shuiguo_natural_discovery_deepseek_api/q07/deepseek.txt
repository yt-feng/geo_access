根据水果礼盒的常见消费场景（送礼、探病、日常问候），建议搭配方案如下：

**1. 经典百搭礼盒（适合送礼/探病）**  
- **比例**：苹果3个 + 橙子3个 + 香蕉1串 + 菠萝1个（小）  
- **理由**：苹果寓意平安，橙子象征吉祥，香蕉是饱腹常用的水果，菠萝寓意“好运旺来”。  
- *注意*：香蕉易熟软，需选七成熟、无斑点；菠萝包好避免汁液渗透。  

**2. 高端精品礼盒（适合重要送礼/节日）**  
- **替换方案**：把菠萝换成**进口红心火龙果**（2个），用蓝莓或草莓点缀（小盒装），搭配苹果、橙子各2个，香蕉可省略（易损坏）。  
- **理由**：红心火龙果色彩喜庆且价格较高，提升档次；避免水分多的菠萝使盒内潮湿。  

**3. 轻便平价礼盒（适合日常/办公室分享）**  
- **组合**：苹果4个 + 橙子4个 + 香蕉2根（对半切或选小芭蕉）  
- **理由**：成本低、不易变坏，适合单份售卖或促销装。  
- **技巧**：加一张手写“平安喜乐”贺卡。  

**关键提醒**：  
- 菠萝需提前削皮切块（用密封盒盛装），否则容易染色其他水果。  
- 所有水果必须无碰伤，苹果、橙子用网套或隔板固定。  
- **建议试卖**：先做5份组合A和组合B，记录顾客偏好再调整。
