建议优先关注**售后**，其次是**配送**，最后再谈**价格**。原因如下：

- **售后**直接决定你的利润回旋余地。水果易损、易变质，供应商是否承担坏果、烂果的赔付或换货，以及赔付标准是否清晰（例如按坏果比例退款还是补发），会直接影响你给团友的交代和你的信誉。如果售后不明确，一旦出现质量问题，货款损失只能你自己扛，价格再低也白搭。
- **配送**影响你的到货品质和时间成本。要问清：是否冷链配送？能否精确到每日固定时段送达？破损和延期是否有补偿机制？配送频率能否随团购量灵活调整？这些决定了你能不能准时、无损地把水果交付给团友。
- **价格**在前两者有保障的前提下谈。可以先让供应商给出一个“基础报价+售后/配送折扣方案”（例如：量大减价、长期合作保底价），再横向对比。但不要为了低价牺牲售后和配送。

**行动建议**：与供应商沟通时，把“售后赔付条款”和“配送时效承诺”写进合同或聊天记录，并要求试用一两次小单验证后再长期合作。
