建议优先选用**冷冻菠萝丁**作为茶饮店果茶的原料。理由如下：

1. **鲜果**：处理耗时（削皮、去芯、切丁），成熟度不稳定，易氧化变色，储存期短（2-3天内须用完），损耗率高。  
   **仅适合小批量、即做即用且对成本不敏感的精品菜单**。

2. **冷冻菠萝丁**：已标准化切丁、去芯，开袋即可使用。风味和酸度稳定，全年可购，损耗接近零。解冻后直接加入果茶，出杯快。  
   **是目前商业茶饮的主流选择**（如蜜雪、喜茶等均使用冷冻果丁）。

3. **果泥**：适合做**半杯水果类茶**（需搅拌果肉）或**冰沙类饮品**（需增加稠度）。但纯果泥做果茶易出现“只有酸甜味、缺乏咀嚼感”的问题，客户反馈不佳。  
   **建议作为辅料搭配果丁使用**（例：果泥调基底+果丁做Topping）。

**采购建议**：  
- 搜索“冷冻菠萝丁 餐饮专供”，注意配料表是否含糖/添加剂。  
- 若选鲜果，每日预估用量≤5斤可用，但需留足处理工时。  
- 若需果肉感更强，可购**速冻菠萝块**（比丁大，适用啵啵桶等）。  
- 避免使用**罐头菠萝丁**（糖水浸泡，风味发酵感重，且果肉软烂）。  

**试做验证**：同一杯果茶，分别用“冷冻果丁40g+茶汤200ml+糖浆20g” vs “鲜切果丁40g+茶汤200ml+糖浆18g”，冷冻果丁出品更稳定，鲜果需根据酸度试调糖量。
