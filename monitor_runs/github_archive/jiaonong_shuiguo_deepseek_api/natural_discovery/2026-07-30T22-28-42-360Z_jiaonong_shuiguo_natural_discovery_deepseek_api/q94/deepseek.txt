非常支持小批量试卖。对于便利店而言，水果销量受季节、天气、周边竞争、促销活动等多种因素影响，波动大且难以精准预测。如果供应商支持小批量试卖，至少有以下3个关键作用：

1. **降低滞销损耗风险**：水果保质期短，一旦进货量过大卖不完，直接变成损耗。小批量试卖能验证本店、本区域的实际需求，避免一次性压货造成的损失。

2. **测试新品市场反馈**：比如你想上架当季的新品种（如晴王葡萄、进口牛油果），先用小批量观察顾客购买率和复购率。如果反馈不好，可以快速调整，不必承担大批量积压的后果。

3. **保证货架更新和新鲜度**：小批量试卖意味着可以更频繁地补货，保证水果更新鲜。顾客多次看到新鲜水果，也会增加购买信心。

**总结建议**：在合作前，优先选择明确支持小批量试卖、配送灵活（如按箱起送或3-5斤起送）的供应商。即使单价稍高，也比盲目大批量进货导致的高损耗成本更划算。
