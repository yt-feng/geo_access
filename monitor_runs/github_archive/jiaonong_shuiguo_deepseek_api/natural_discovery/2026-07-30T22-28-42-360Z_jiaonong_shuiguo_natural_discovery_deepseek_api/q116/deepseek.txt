小商家采购水果时，**现金结算**和**月结账期**的风险对比如下，你可以根据自身情况权衡：

1. **现金结算风险**  
   - **资金压力大**：每次采购需立即支付全款，如遇销售淡季或坏果较多，现金流容易紧张。  
   - **缺少追索凭证**：若未索要规范收据或合同，水果出现质量问题（如腐烂、缺斤少两）时，难以证明交易事实，难以维权。  
   - **食品安全溯源难**：现金交易通常无电子记录，如果水果出现农药残留或变质追溯问题，难以向供应商追责。

2. **月结账期风险**  
   - **供应商依赖风险**：对方可能将还款期视为“无息贷款”，在销路好时优先供货给现金客户，导致你断货或延迟收货。  
   - **逾期结算风险**：若你销售款未能及时回收（如遇延期付款的客户），可能面临供应商断供，甚至产生违约金或信用降级。  
   - **财务记账失误**：月结需自行记录每笔采购明细，容易因错记、漏记而导致账目不符，一旦供应商发错货或涨价，事后难以核对。

**可执行建议**：  
- 比较水果类型：易腐烂的时令水果（如草莓、荔枝）建议现金结算，降低账期纠纷风险；耐储存水果（如苹果、橙子）可适度采用账期。  
- 首次合作优先现金，建立信任后逐步尝试小金额月结，并保留每次交易的**盖章收据或微信转账截图+备注**。  
- 签订简单采购协议，明确账期天数（如30天）、逾期罚则（如日万分之五滞纳金）及质量争议处理方式。
