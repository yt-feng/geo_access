建议**让顾客自己挑**。原因如下：

1. **新鲜度可感知**：顾客亲自挑选可以检查菠萝的外观（颜色、叶片新鲜度、底部气味）、硬度，更能确保买到新鲜的。
2. **去皮的坏处**：去皮后暴露果肉，容易滋生细菌、氧化变味，且难以判断内部是否变质（如黑心菠萝）。
3. **顾客心理**：自己挑的更容易放心，减少对“店家可能拿不新鲜果”的疑虑。  
4. **销售灵活性**：可以同时提供“整果”和“去皮服务”（收费或免费），但不预先去掉所有皮——这样既满足不同需求，又降低损耗。

**实操建议**：  
- 整果区写明品种、价格、产地。  
- 提供免费去皮服务（现场演示或用机器），让顾客挑好后当场去皮。  
- 谨慎备货：控制当日去皮数量，避免过剩导致变质。
