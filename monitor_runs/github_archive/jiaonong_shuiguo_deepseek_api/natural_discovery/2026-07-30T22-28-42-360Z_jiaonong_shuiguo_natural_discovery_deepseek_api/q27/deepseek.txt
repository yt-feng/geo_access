判断苹果和橙子大小是否适合门店销售，需结合**品级标准**、**顾客需求**和**陈列效果**。以下是具体步骤：

1. **参考行业通用标准**：
   - **苹果**：通常按直径（厘米）分级，门店常见优选级为70-80mm（中果），大果80-90mm更吸引高端顾客。小于65mm或畸形果建议淘汰。
   - **橙子**：橙子常见规格为65-75mm（中果），75-85mm（大果）。过于小(如60mm以下)可能影响利润，极大果(90mm以上)可能口感偏差或价格过高。

2. **评估门店定位与顾客**：
   - 若定位**家庭日常消费**，中果(苹果75-80mm，橙子70-75mm)销量最快，价格适中。
   - 若定位**礼品或高端**，选大果(苹果85mm+，橙子80mm+)并统一包装。

3. **观察整体一致性与外观**：
   - 同一批次中的大小差异不应超过10-15%，否则陈列杂乱，影响购买欲。
   - 检查有无**机械损伤、软斑、病斑**——即使大小合适，外观不合格也应排除。

4. **执行简单测量**：
   - 使用**卡尺或手抓法**：抓在掌心中，苹果应几乎填满手掌(不露太多空隙)；橙子以食指与拇指能轻松环绕为佳。
   - 若全批次中超过20%大小低于标准底线，建议退回或降价处理。

**可执行建议**：进货前与供应商确认规格参数（如“苹果直径70-80mm”），到货按上述标准抽检10-15个样品，记录不合格率。若不合格率>5%，协商换货或调整订单。
