要判断批发商卖的菠萝哪个规格更容易出货，可以从以下几个关键点分析：

1. **了解客户群体**：
   - **零售摊贩/水果店**：通常偏好个头中等（约1.5-2斤）、外形匀称的菠萝，因为便于搬运、存放和按个销售。
   - **餐饮/果汁店**：可能偏好个头较大（2.5斤以上）的菠萝，因为出肉率高，切块或榨汁更划算。
   - **超市/社区团购**：更倾向标准化、无瑕疵的规格，大小适中，包装整齐。

2. **观察市场热销趋势**：
   - 到本地批发市场或周边零售点实地考察，看哪种规格的菠萝摊位前人流多、补货快。
   - 询问同行或老客户近期哪种规格好卖（例如：“最近小菠萝好走还是大果走得快？”）。

3. **分析价格与利润**：
   - 计算不同规格的进货价、损耗率和售价。例如：小规格单价低但周转快（薄利多销），大规格单价高但销量可能不集中（利润空间大但压货风险高）。
   - 注意：如果批发商能提供分级服务（如精品果、统货果），优先推精品果。

4. **考虑季节性因素**：
   - 菠萝旺季（如春季）市场需求大，中等规格和统货果容易走量。
   - 淡季或节日前（如春节）可推大规格礼盒装，溢价空间更高。

5. **试销验证**：
   - 少量进货不同规格，观察成交速度。比如每规格进100个，看哪种规格3天内卖完。

**总结建议**：
- 如果没有明确客户群体，**中等规格（约1.8-2.2斤）** 和 **统货果** 通常最容易出货，因为覆盖了零售和餐饮两类常见需求。
- 如果周边餐饮店多，优先备 **大果**；如果以零售摊为主，则选 **中等果**。

**可执行的操作**：先向客户调查：“您通常进什么大小的菠萝最好卖？是否需要帮您挑特定规格？”根据反馈调整库存。
