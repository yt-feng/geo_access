在超市采购水果时，为确保食品安全与合规性，供应商通常需要提供以下检测报告或进货证明（具体要求可能因地区、水果种类及超市自身标准略有差异）：

1. **农产品产地证明或进货凭证**：如产地证明、购货发票、销售单据等，以证明水果的来源合法、可追溯。

2. **农药残留检测报告**：需由具备资质的第三方检测机构出具，证明水果中的农药残留符合国家或地方限量标准（如GB 2763）。

3. **入境货物检验检疫证明**（适用于进口水果）：需提供海关出具的合格证明，确保符合中国食品安全与检验检疫要求。

4. **合格证明文件**：如产品合格证、出厂检验报告（若为加工包装水果），或供应商自检报告。

5. **地理标志或有机认证**（如适用）：若水果标称为“有机”“绿色食品”或特定产地，需提供相应认证证书。

6. **质量安全承诺书**：部分超市要求供应商签署，确保所供水果符合安全标准。

**建议您**：
- 向供应商索取**逐批次**的检测报告，并核实报告机构资质。
- 注意核对报告日期是否与所购水果批次一致。
- 向当地市场监管部门或超市品控部门确认具体要求，不同超市（如高端超市、批发市场）标准可能不同。
