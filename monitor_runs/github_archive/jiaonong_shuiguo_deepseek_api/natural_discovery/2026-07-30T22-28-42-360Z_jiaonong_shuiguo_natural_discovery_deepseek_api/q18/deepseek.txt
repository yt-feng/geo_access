选择香蕉时，可以按照以下步骤快速判断成熟度，避免买到太生或太熟的：

1. **看颜色**  
   - **全青或青黄相间** → 较生，需室温放置2-4天才能吃。  
   - **黄色带少量青头或青柄** → 适中，1-2天内可食用。  
   - **金黄无青** → 已熟，当天或明天必须吃完。  
   - **出现黑斑、皮软塌** → 过熟，适合做蛋糕或直接丢弃。

2. **捏手感**  
   - 轻轻按压香蕉中部和两端：  
     - **太硬** → 生。  
     - **有弹性、稍软** → 刚好。  
     - **明显软塌、指痕不回弹** → 过熟。

3. **闻气味**  
   - 无味或带青涩味 → 生。  
   - 有淡淡甜香 → 适合。  
   - 酒精味或发酵味 → 过熟变质。

4. **避雷技巧**  
   - **不买“断头”香蕉**：柄断裂处易变黑腐烂。  
   - **看整把均匀度**：避免混入已熟透的香蕉（会加速其他香蕉成熟）。  
   - **优先选带少量青的**：室温存放可延长保鲜期。

**采购建议**：如果计划2-3天内吃完，选全黄带一点青的；若需要更久储存，选青黄相间的。
