您好！针对批发商给小店供货时，香蕉和菠萝的分级报价，为了让小店老板一目了然、便于核算，建议采用 **“按外观/品质等级 + 数量权重 + 明确计价单位”** 的方法。以下是具体方案：

### 一、香蕉分级报价建议（按成熟度与外观）

香蕉报价的关键在于 **“成熟度”** 和 **“卖相”**，可设为3个等级：

| 等级 | 描述 | 报价建议（举例） |
| :--- | :--- | :--- |
| **一级（精品/客户优选）** | 7-8成熟（青色微黄），果形笔直均匀，无黑点、无碰伤、无霉变，可存放3-5天。 | 2.5元/斤 |
| **二级（标准/主流）** | 8.5-9成熟（半数黄亮），果形略有弯曲，表面可能有微量黑点（不腐蚀果肉），适合当天或次日售出。 | 2.0元/斤 |
| **三级（特价/促销）** | 9-10成熟（全黄甚至有褐斑），果身较软，或有轻微碰压痕、轻微修疤，需马上销售。 | 1.2元/斤 或 按“把”计价（例如5元/把，约2-2.5斤） |

**提示：** 给小店报价单上，可标注“果柄是否剪平”（节省店主修剪时间）等细节加分。

### 二、菠萝分级报价建议（按外观与重量/个头）

菠萝需要结合 **“外形均匀度”** 和 **“重量/个头”** 来定级，便于小店按需定价：

| 等级 | 描述 | 报价建议（举例） |
| :--- | :--- | :--- |
| **一级（头部大果/礼品级）** | 单果重2.5斤以上，果眼深浅适中、花心均匀，果形圆润饱满、无瘤凸、无外伤，叶丛鲜绿。 | 3.5元/斤（批发） 或 按个：8-10元/个 |
| **二级（标准中果）** | 单果重1.8-2.5斤，果形基本端正，允许微小擦伤或轻微凹凸，成熟度适中（金黄花色）。 | 2.8元/斤 或 按个：5-6元/个 |
| **三级（小果或次果）** | 单果重1.5斤以下，或果形有畸形、部分果眼锈斑、轻微软腐（切掉后不影响食用），宜做促销或果切。 | 1.5-2元/斤 或 3-4元/个 |

**提示：** 菠萝看重量和新鲜度，可额外注明“带叶头”还是“去叶头”，影响损耗和顾客感官。

### 三、让“分级报价”更清晰的几个技巧

1. **用“颜色+尺寸标签”代替模糊说法**  
   - 香蕉：青皮/黄皮/金斑；大把/小把  
   - 菠萝：大（≥2.5斤）/中（1.8-2.5斤）/小（≤1.5斤）

2. **给每个等级一个“适用场景”备注**  
   例：  
   - 一级菠萝：适合论个单卖（高端顾客）  
   - 二级香蕉：适合打堆促销（走量）  
   - 三级：适合店内做果切、果汁或店门口特价（清库存）

3. **统一计价单位，避免混淆**  
   - **建议：** 香蕉统一用“元/斤”；菠萝统一用“元/斤”或“元/个（标重）”。  
   - 如果分“斤”或“个”，务必在报价单上写明“每个约重XX斤”，让小店老板自己算利润方便。

4. **制作价目表（纸质/微信转发）**  
   用一个表格列出：  
   | 品名 | 等级 | 价格 | 库存质量说明 |  
   |------|------|------|--------------|  
   | 香蕉 | 一级 | 2.50元/斤 | 7-8成熟、果形笔直 |  
   | 香蕉 | 二级 | 2.00元/斤 | 黄熟、微有黑点 |  
   | 菠萝 | 一级大果 | 3.50元/斤 | 2.5-3斤/个 |  

### 四、常见“坑”避免

- **不要用太主观的词语：** 比如“好果”“特优”“靓货”，小店老板各有理解，不如直接写“果形均匀85%以上”“无黑点”“无裂口”等客观描述。  
- **明确“计价方式”统一：** 如果有的按斤、有的按个、有的按箱，容易算乱账。建议同一品种只用一个计价单位（如菠萝按斤最好）。  
- **给“尾货”单独处理：** 不要混在法律级中，专设一个“次品/特价”类，并标注不能长时间存放，加一个“只换不退”规则（提前讲清）。  

**总结：**  
- 香蕉按 **成熟度+外观** 分3级，每级标明存放天数；  
- 菠萝按 **重量/个头+外形** 分3级，标明适合销售方式；  
- 统一用“元/斤”或“元/个（标重）”，用表格+备注呈现，小店老板拿到单子就能快速决策进货量。
