是的，起订量太高确实可能增加损耗风险，尤其是对于香蕉和菠萝这类易腐水果。原因如下：

1. **保质期短**：香蕉成熟快，通常3-7天内易变质；菠萝虽耐放，但切开后或存放不当也易腐烂。大订单若无法快速销售或消耗，损耗概率显著上升。
2. **储存条件苛刻**：香蕉需避冷、通风，菠萝需避湿润，超量采购可能超出冷藏或常温储存能力，加速腐败。
3. **需求波动**：若客户或市场需求不稳定，高起订量易导致库存积压，尤其小规模商家或家庭用户风险更高。

**建议**：
- 优先选择起订量较低的供应商，或协商分批交付。
- 根据实际周转率（如日均销量或消费量）设定安全库存量，避免超量采购。
- 如需批量采购，可计划加工（如香蕉冷冻、菠萝制罐头或分装）以减少损耗。
