针对团购客户价格敏感的特点，**阶梯价通常比返利更合适**，具体分析如下：

1. **直接满足价格敏感心理**：阶梯价（如买10件打9折、50件打8折）能立刻让客户看到“买越多省越多”，降低决策门槛，避免客户因返利需要后期核算或等待而犹豫。
2. **简化交易流程**：返利通常需要设定返利周期（如季度返利）、核对销量、等待结算，增加双方管理成本；而阶梯价在订单结算时直接扣除，客户即感即得，减少摩擦。
3. **激励一次性大单**：团购客户常希望“一次囤够”，阶梯价能清晰引导客户提高单次订单量，降低供应商的拆单、配送成本。
4. **避免返利争议**：返利可能有“累计销量未达标而不返”的说明，容易导致客户不满；阶梯价规则透明（按当前订单数量计算），信任成本更低。

**适用建议**：
- 如果客户**单次采购量大且频繁复购**：阶梯价为主，再搭配小额返利（如满一定量级额外返1%-2%）。
- 如果客户**希望通过长期合作绑定**：阶梯价+年度返利（如全年累计达100万元返2%），但需在合同中明确返利周期和兑付方式。

总之，优先用阶梯价锁定当次订单，返利作为补充激励，并避免复杂的返利规则增加沟通成本。
