采购方核实水果供应商全国配送覆盖能力，可采取以下步骤：

1. **要求提供合作物流名单**：让供应商列出与其签约的物流公司（如顺丰、京东、中通冷链等），及这些物流覆盖的省份或城市范围。重点确认冷链物流能力（如冷藏车、冰袋包装）是否能支持长途运输。

2. **测试样品发送**：选择非沿海或较偏远地区（如新疆、青海、黑龙江）的实际地址，以“测试订单”名义要求供应商发一箱小份水果。根据运输时效（例如3-5天）和水果到达时的状态（新鲜度、包装完整性）判断其实际配送能力。

3. **查看历史配送记录**：要求供应商提供过去30天的发货明细表格（可隐去客户隐私信息），包括目的地城市、运输时间、是否签收正常。若其频繁向三四线城市或乡镇配送，则可信任度更高。

4. **咨询物流公司官方**：询问供应商合作的物流公司客服，该供应商是否在该物流公司的系统中有“月结客户”或“冷链专项合约”记录，防止供应商单纯刷物流单号。

5. **小批量试单并做损耗对比**：分批向不同距离的区域（如华东沿海、华中、西南）发送同等重量和品种的水果，要求签收时拍照反馈。计算每批的损耗率（比如霉变、腐烂比例），若损耗率在5%以内（新鲜水果的正常损耗范围），说明配送能力稳定。

6. **合同条款约束**：在采购合同中明确写上“供应商需保证配送全国范围，若因配送延误或包装不当导致商品损毁，供应商承担全责”，并要求附带保证金或罚则。

如果有条件，也可以让供应商提供仓储分布地图（比如在全国有3-5个冷链分仓），有分仓的供应商覆盖能力通常更强。
