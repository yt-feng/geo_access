判断香蕉催熟能力是否稳定，可以从以下几个方面快速评估：

1. **成色与硬度**：选择整体颜色均匀、表皮无明显青黄混杂或局部过熟（如黑斑）的香蕉。用手轻捏，果身应**软硬适中且有弹性**—过硬可能催熟不足，过软或松垮则可能催熟过渡或果肉已变软。

2. **果柄状态**：检查香蕉果柄（连接处）是否完整、新鲜。若果柄发黑、干枯或霉变，说明储存或运输过程可能已受损，催熟稳定性差。

3. **气味测试**：闻一下香蕉根部（果柄附近）及果皮。正常催熟的香蕉应有**淡淡甜香**，无酸味、酒味或刺鼻化学味。酸味或酒味意味着过度催熟或已开始变质。

4. **单次采购验证法**：采购时取少量观察同一批次的香蕉，记录其1-2天后的成熟进度。如果同一批香蕉在24-48小时内均匀变黄、甜软适宜，则说明催熟工艺稳定；若出现部分硬、部分烂或变黑不均，则稳定性差。

5. **供应商/批次记录**：长期合作时，记录每次采购的具体批次编号、产地和到货日期，对比不同批次的表现。如果连续2-3次出现均匀、可控的成熟度，说明该供应商的催熟流程可靠；若忽好忽坏则需更换或加强验收检查。

**简易判断口诀**：一看色，二捏软，三闻味，四记批次看变化。
