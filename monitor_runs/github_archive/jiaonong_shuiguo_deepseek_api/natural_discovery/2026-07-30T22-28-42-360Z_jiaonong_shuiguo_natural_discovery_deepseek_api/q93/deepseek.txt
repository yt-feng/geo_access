主要需要关注以下三点，按重要性排序：

1. **保质期（核心）**  
   - 菠萝切开后氧化快，建议保质期标定为**24-48小时**（冷藏条件下）。  
   - 严格执行“生产时间+到期时间”标签，超时立即下架报废，避免食品安全风险。

2. **包装（防护关键）**  
   - 使用**食品级保鲜膜/密封盒**，隔绝空气减缓氧化。  
   - 结合**气调包装**（如充氮气）可延长至3-5天，但需测算成本。  
   - 包装上标注“开封后尽快食用”，并提醒冷藏保存。

3. **配送频次（保证新鲜度）**  
   - 建议**每日配送**，避免一次到货积压库存。  
   - 根据历史销量动态调整：如周一到周四客流量较低，可减少单次配送量，改为隔日配送（配合冷柜库存管理）。

**建议顺序**：先优化保质期管理流程，改进包装设计，再根据实际损耗数据调整配送频次。
