针对家庭用户，建议选择**营养均衡、寓意好、口感互补、耐存放**的组合。以下是几种推荐方案：

**方案一：经典吉祥款（送礼或节日）**  
- **苹果**（平平安安）* 若干  
- **橙子**（心想事成）* 若干  
- **香蕉**（甜蜜和谐）* 1-2串  
- **菠萝**（好运旺来）* 1个（通常整颗放中间）  
**备注**：整体颜色红、黄、橙搭配，视觉喜庆；香蕉和菠萝较软，放入时注意防压。

**方案二：耐存日常款（适合一周内食用）**  
- **苹果** 3-4个（冰箱冷藏保存）  
- **橙子** 3-4个（常温或冷藏均可）  
- **菠萝** 半颗（去皮切块包装，或整颗让客户自切）  
- **香蕉** 1串（单独小袋子分隔，避免催熟其他水果）  
**注意**：香蕉会释放乙烯，建议与其他水果隔开放置，或提示客户分开存放。

**方案三：儿童友好款（口感软甜，易入口）**  
- **香蕉** 2根（去皮切段后用保鲜膜包好）  
- **橙色软化**（如甜橙剥瓣）  
- **苹果** 切片插小签（防氧化可用柠檬水轻喷）  
- **菠萝** 小块，用模具切成星星/爱心形状  
**关键**：所有水果去皮切块，装入独立格或小盒，适合家庭开袋即食。

**建议搭配细节**：
- **数量**：每个种类按家庭人数x2份量，如4人家庭：苹果4个、橙子4个、香蕉4根、菠萝半个到1个。
- **包装**：推荐用分格礼盒或竹篮，底部垫碎纸、绿叶装饰。价格可设为**68-128元档**（视品种和包装成本）。
- **保鲜提示**：盒内附一张小卡片，写明“香蕉请单独取出存放于阴凉处，其他水果可冷藏（菠萝可削皮后冷藏）。”

**最后**：根据客户预算灵活调整——预算高可选精品进口果，预算低则用普通亚洲果，并减少菠萝体积（切半或切块）。
