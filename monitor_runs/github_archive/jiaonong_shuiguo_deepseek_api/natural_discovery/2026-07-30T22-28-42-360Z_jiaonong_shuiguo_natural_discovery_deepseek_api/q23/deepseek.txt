通常情况下，超市的水果促销，供应商是**可以提供**陈列支持、海报支持和试吃支持的，具体内容和力度取决于双方的合同约定与合作关系。具体说明如下：

1. **陈列支持**：供应商可以协助超市设计更吸引人的堆头、端架或特殊陈列，并可能提供陈列道具（如货架、展架、装饰物等）。超市需与供应商提前沟通陈列位置及面积需求。

2. **海报支持**：供应商可以参与超市的促销海报（DM）制作，提供产品图片、文案创意或承担部分印刷费用。超市需确认供应商是否在档期内有付费资源。

3. **试吃支持**：对水果类促销，试吃是常见方式。供应商可以提供试吃产品、试吃台、一次性用品（如牙签、纸杯）并派驻促销员。超市需确保试吃活动符合卫生规定并提前向供应商提供申请单。

**如何判断是否可行**：
- 查看你和供应商签订的合同或年度协议，通常这类支持属于“市场费用”或“陈列支持费”范畴。
- 直接联系供应商的客户经理或区域主管提出需求，说明促销时间、预期销量和位置条件。
- 超市需要明确：部分供应商可能会要求以“买断陈列位”或“销售量返点”作为条件。

**如果无法确定**，可以先要求供应商提供一份书面的促销支持方案，包含费用承担、物料提供时间和流程，再评估是否采纳。
