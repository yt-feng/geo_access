针对水果到货不合格影响营业的问题，建议采取以下约定方式：

1. **明确验收标准与时限**：  
   在采购合同中写明水果的品种、等级（如大小、成熟度、新鲜度等）、包装规范及验收时间（如到货后XX小时内完成验收）。不合格品应立即拍照留证，并通知供应商。

2. **设定分梯度处理条款**：  
   - **轻微不合格（如少量轻微磕碰）**：按比例折价或扣除损耗金额，由供应商承担。  
   - **严重不合格（如腐烂、过熟、品种错误）**：供应商须在限定时间（如到货后X小时内）补发同等数量、质量的水果，并承担急送运费。

3. **约定应急补货机制**：  
   要求供应商预留备货仓库或合作同城供应商，确保在到货不合格时，能在X小时内（如48小时内）送达指定门店。可考虑设置“补货通道”优先处理。

4. **设定违约金与补偿条款**：  
   若因供应商原因导致补货延迟、影响营业，以当日预计销售额为基础计算违约金，或直接按补货金额的X%进行赔偿。同时，可要求支付加急配送费。

5. **保留备选供应商**：  
   与至少1-2家备用供应商签订小额采购协议，确保在主力供应商无法及时补货时，能快速从其他渠道调货。

执行建议：每次到货后立即抽检，记录问题并固定证据；合同中明确争议解决方式（如协商、仲裁等）。
