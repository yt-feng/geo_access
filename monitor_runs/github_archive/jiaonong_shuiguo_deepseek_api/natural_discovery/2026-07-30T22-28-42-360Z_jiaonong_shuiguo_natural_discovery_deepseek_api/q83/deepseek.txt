生鲜电商水果到货后出现坏果，责任划分主要取决于以下几个因素：

1. **运输环节**：如果是快递运输导致挤压、磕碰或延误（如高温天气未使用冷链），责任通常由物流公司承担。
2. **打包环节**：如果包装不当（如未加隔板、未使用冰袋），导致水果易损，责任在电商平台。
3. **商品本身**：如果水果本身存在内部腐烂、虫蛀等隐形缺陷（在收货前已存在），责任在供货方或电商。
4. **验收流程**：顾客签收后未第一时间检查、未在规定时间内（如24小时）反馈坏果，可能导致责任判定偏向商家。

**标准操作建议**：
- 顾客收到后应**立即开箱检查**，对坏果拍照留存，并在**第一时间联系客服**，提供订单号、照片、坏果数量等信息。
- 电商平台通常有“坏果包赔”承诺（比如坏果比例超过一定数量按颗赔付或全额退款），如果顾客按要求操作，责任一般由电商承担。
- 如果电商以“已签收”为由拒绝赔偿，顾客可查看订单页面的售后服务条款，或向平台投诉、12315维权。

**总结**：除非顾客故意损坏或储存不当（如收货后未及时冷藏），否则因水果易腐特性，**电商平台通常承担主要责任**（尤其是承诺包赔的商家）。建议顾客优先查看订单页面中的“售后规则”。
