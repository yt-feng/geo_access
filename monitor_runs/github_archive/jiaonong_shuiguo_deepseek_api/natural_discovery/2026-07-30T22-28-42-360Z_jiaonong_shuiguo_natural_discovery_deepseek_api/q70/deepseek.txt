为防范批发商因货到后坏果损耗承担过高责任，建议在采购合同中明确以下条款（可根据实际情况调整）：

1. **明确质量标准**  
   “商品应达到【行业/地方/双方约定】质量标准，完好率不低于【例如：95%】。若货到后完好率低于此标准，视为卖方交付不合格品。”

2. **指定验收期限与程序**  
   “买方在收货后【例如：24小时/48小时】内对商品进行验收。若发现坏果，应在验收期内通过【拍照/视频/第三方检测】方式固定证据，并书面通知卖方。”

3. **明确损耗责任归属**  
   “运输途中产生的自然损耗（如因水分蒸发、轻微挤压等导致的重量减少）由买方承担；因商品自身质量缺陷（如发货时已存在病菌、内部变质、虫害等）或包装不当导致的坏果，由卖方承担全部损失。”

4. **约定赔偿与退换货**  
   “若坏果率超过【例如：5%】，卖方应按【坏果价值×【1.5或2】倍】赔偿买方，或按坏果比例【例如：1:1.5】补发合格品。退货、换货产生的运费及二次检验费由卖方承担。”

5. **设置免责例外**  
   “买方储存不当（如未按要求的温度/湿度保存）、超过验收期未检验或不可抗力导致的坏果，不适用上述责任条款。”

**操作建议**：  
- 保留好发货地/到达地的第三方检测报告或视频证据。  
- 明确约定“消耗/干耗率”（建议不超过3%）与“坏果率”分开计算。  
- 在合同末尾加一句：**“本合同项下‘坏果’指腐烂、霉变、虫蛀或失去商品基本食用价值的水果/蔬菜，以双方共同确认或第三方机构检测为准。”**
