要判断茶饮连锁的菠萝供应商能否稳定按规格送货，建议从以下几个可操作环节入手：

1. **明确规格标准并写入合同**  
   提前拟定书面《采购规格书》，明确菠萝的成熟度、单果重量（如每颗1.2-1.5斤）、果径（如17-20cm）、色泽、甜度（如Brix 13-15%）、无黑心/褐斑等要求。合同中加入“连续2次到货不符的，有权解除合同或按比例扣款”条款。

2. **试单期验证**  
   先下3-5次小批量试单（如每次200斤），间隔7-10天。统计每次到货的规格合格率（≥95%算稳定），并特别关注雨天/台风季等时段菠萝品质是否波动。

3. **实地考察与供应链透明度**  
   到一级批发市场或产地查看供应商的分拣流水线（应有分选机或人工按重量/大小分级），确认其每日备货量和仓储条件（如菠萝到货后能否在12-24小时内周转出货）。要求供应商提供近30天同类客户的出货记录。

4. **设定应急补货机制**  
   要求供应商提供稳定的备选同规格货源（如产季不同时切换海南/云南/广东产区），并在合同中约定：若无法按规格供货，需在6小时内调配替代货品补足，否则赔偿门店营业额损失（例如按缺货单量的预估销售额赔偿10%）。

5. **分阶段绩效考核**  
   签约后，实行“前3次免检→后5次抽检10%→长期合作后每周抽检一次”的阶梯式检查。若连续4周合格率低于95%，则自动触发降级预警（减少采购份额或下调信用等级）。

6. **反向验证合作案例**  
   要求供应商列举3家以上类似茶饮连锁（如蜜雪冰城、喜茶等供应商级别）的合作案例，并至少提供其中1家的联系方式或可查验的合同复印件（去除非敏感信息后），进行电话回访。

最后，最直接的方法是：**安排一次盲测**——让供应商将所有等级的菠萝（如特级、一级、通货）分别送货，然后由你的研发部盲测果肉风味和固形物含量，确认其分级是否真实。如果对方无法做到固定分级，则替换为有产地分选能力的供应商。
