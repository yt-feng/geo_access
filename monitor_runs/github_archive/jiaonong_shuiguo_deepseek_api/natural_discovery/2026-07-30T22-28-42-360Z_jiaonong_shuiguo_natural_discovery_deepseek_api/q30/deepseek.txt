针对超市水果到货后品相不佳的情况，建议在采购合同或供应商协议中明确以下售后流程约定，以保障双方权益并减少纠纷：

1. **验收标准与时效**  
   - 明确约定“品相”的具体标准（如颜色、大小、有无破损/霉变等），可附图片作为参照。  
   - 规定到货后 **24小时内** 完成验收，验收期内发现问题可拒收或要求换货；超时视为默认接受。

2. **问题商品处理**  
   - 品相不合格的货物，供应商须在 **48小时内** 完成补发或更换，补运费由供应商承担。  
   - 若无法补发，应按问题商品数量 **原价1.2-2倍** 进行现金赔偿（具体倍数需双方协商）。

3. **责任划分与举证**  
   - 要求到货时双方共同拍照或截图留证（拍摄外包装、开箱后品相、快递面单等）。  
   - 因运输造成的品相损坏，由供应商负责向物流公司追责；供应商须提供完整物流包装完好证明。

4. **争议解决**  
   - 若双方对品相判定存在分歧，可约定 **第三方质检机构**（如当地农检中心）介入，费用由判断有误方承担。  
   - 超过3次品相不合格，超市有权单方面终止合作并扣除当月货款。

5. **付款调整机制**  
   - 设立“结算前质检期”：每月采购的品相合格率低于 **85%**，供应商需接受 **10-20%货款延迟支付** 或折扣。

**操作建议**：  
- 在合同中增加“附件：品相验收标准图解”，细化不同水果的合格/不合格示例。  
- 建立微信群或管理后台，要求供应商在发货前发送“备货照片”预审，降低到货问题率。  
- 保留所有沟通记录（聊天、邮件、签收单），作为日后证据。
