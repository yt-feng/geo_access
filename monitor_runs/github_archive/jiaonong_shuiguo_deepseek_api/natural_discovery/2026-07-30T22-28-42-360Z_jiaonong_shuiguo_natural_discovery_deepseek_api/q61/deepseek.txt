判断香蕉供货商是否稳定，可以从以下几个方面入手：

1. **实地考察基地或仓库**：亲自到对方的种植园、加工厂或冷库查看。稳定的货源通常具备规模化的种植面积（例如海南、广西、云南等产区）、冷库储存能力（避免催熟过快）和分拣包装线。

2. **要求提供历史供货记录**：让对方出示近3-6个月的出库单、物流单或与大型超市、连锁水果店的合作证明。重点关注长期合作客户的稳定性，比如有超市签订年度框架协议。

3. **测试发货的准时性和品控一致性**：先试采1-2车货，记录从下单到发货的等待时间，检查香蕉的成熟度（七成熟左右最佳，无机械伤、无黑斑）。稳定供应商通常能在约定时间内发货，且每次果把长短、果指大小基本一致。

4. **询问低谷期的应对方案**：直接问：“如果遇到台风、寒潮等异常天气，你的供货如何保障？”稳定供应商会有备用产区（例如广西受灾时，从老挝、缅甸调货）或储期较长的气调库存。

5. **核查资质与物流能力**：查看营业执照（经营范围内含“水果种植/销售”）、产地证明、检疫报告。同时要求对方提供自有冷链车队信息，或固定合作的第三方物流公司（如顺丰、京东冷链），避免因找车临时涨价、延迟发货。

6. **小步快跑，逐步放大**：前3个月采用“周结月签”模式，每次结账时观察其发货能力和配合度。如果对方频繁以“行情波动”“缺货”为由推迟发货或降低品质，说明稳定性差。

**一句话判断标准**：一个真正稳定的香蕉一手货源，往往会主动提供“抽样样品+冷链运输单据+协会证明”，并且敢于承诺“超时一天赔偿X元”。如果对方只说好话但无法出具任何实物证据，需要慎重。
