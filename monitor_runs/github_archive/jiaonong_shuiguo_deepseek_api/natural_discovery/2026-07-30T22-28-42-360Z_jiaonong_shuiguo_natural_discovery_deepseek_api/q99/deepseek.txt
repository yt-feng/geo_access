为批量配送选择水果供应商时，建议按以下步骤操作：

1. **明确需求**  
   - 预判水果种类（优先选耐储存、不易压坏的，如苹果、橙子、梨、香蕉、提子）
   - 估算每周或每次所需重量/箱数
   - 明确配送时间（如固定周几下午）、地点和卸货条件（有无冷库、电梯）

2. **筛选供应商渠道**  
   - 本地大型水果批发市场：自行实地考察，对比价格和新鲜度。
   - 社区团购/生鲜平台（如美菜、快驴、每日优鲜）：可线上比价，部分提供企业采购通道。
   - 当地水果种植基地或合作社：直接对接，减少中间环节，适合长期稳定合作。
   - 企业级配送公司（如蜀海供应链、望家欢）：适合大规模企业，可定制组合、配送准时。

3. **关键考察因素**  
   - **质量稳定**：要求供应商提供当季水果样品，检查表皮、硬度、甜度；长期合作可要求“退换货”条款。
   - **配送能力**：确认司机有冷链车或保温箱（夏季尤其重要）；是否能分栋、包装（比如用纸箱+珍珠棉防撞）。
   - **价格透明**：询问批发价、含包装费否、是否含税、起订量。
   - **应急能力**：遇发霉或破损，补货或更换的速度。

4. **操作建议**  
   - 先从小批量订单试合作（如试购3-5箱），评估品控和时效。
   - 签订短期合同（如月结），注明：品种规格、最低起送金额、退换货标准、配送频率。
   - 定期收集员工反馈，每季度调整采购清单。

**直接可执行行动**：搜索“城市名+水果批发市场”，下周一二上午去实地看；或直接联系当地提供“企业下午茶配送”的供应商索取报价单。
