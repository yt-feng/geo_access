社区团购对小水果店来说，本质是把“到店客流”变成“预售+自提”。供应商能不能配合这套模式，直接决定你赚不赚钱。下面按优先级列供应商需要支持的服务，并给出判断标准。

**一、必须支持（没有就别做）**

1. **一件代发/按团分量分拣**
   - 你按团统计数量下单，供应商按“每份”分装好，而不是给你整箱让你自己拆。
   - 判断标准：能否按你给的团购份数（如50份）分装、贴标签，误差率控制在2%以内。

2. **次日达或定时配送**
   - 团购一般是今天下单、明天到店自提。供应商要能在你截单后当晚或次日凌晨送到。
   - 判断标准：截单时间（如晚8点）之后还能接单，次日早8点前到货。

3. **售后包损**
   - 水果损耗是团购最大风险。供应商要承诺坏果、烂果、重量不足的赔付方式。
   - 判断标准：明确包损比例（如3%以内全赔）、拍照理赔流程、赔付是补货还是退款。

4. **稳定供货和价格保护**
   - 团购靠低价走量，供应商临时涨价或断货会直接毁掉你的团。
   - 判断标准：能否提前锁定一周价格、缺货时有无替代品方案。

**二、强烈建议支持（决定你能不能做大）**

5. **小批量起订**
   - 新团初期量小，供应商起订量太高会压货。
   - 判断标准：单品类起订量能否低到10—20份，或支持多品类拼单凑起送量。

6. **提供团购素材**
   - 你需要图片、规格、产地、卖点文案发群里。
   - 判断标准：能否提供现成的商品图、短视频、文案，最好有“今日团品”打包素材。

7. **支持预售锁货**
   - 你先开团收单，再向供应商下单，避免压货。
   - 判断标准：能否接受“晚上报单、次日凌晨配货”的节奏，而不是要求你提前一天备货。

8. **退换货灵活**
   - 团购中临时取消、客户拒收的情况要有处理机制。
   - 判断标准：未拆封商品能否退换、退换周期多长。

**三、加分项（有则更好）**

9. **冷链或保鲜配送**：夏季叶菜、浆果类必须有，否则损耗吃不消。
10. **支持代贴团购标签/分团包装**：你省人工，出错少。
11. **提供试吃装或首团支持**：帮你降低启动风险。
12. **账期支持**：先货后款，缓解你现金流压力，但小供应商一般难做到。

**给你的实操建议**

- 先找2—3家供应商，每家只谈“分装+次日达+包损”这三条硬指标，能同时满足再谈价格。
- 首团选耐储品类（苹果、橙子、香蕉），别一上来做草莓、荔枝这类高损耗品。
- 和供应商书面确认：截单时间、到货时间、包损比例、缺货处理方式，微信文字也算数。
- 起订量谈不下来时，可以联合附近1—2家小店拼单，提高议价能力。

一句话判断：**能按份分装、能次日到、坏果能赔，这三条齐了才值得合作；起订量低、给素材、能锁价，决定你能不能长期做下去。**
