建议先从**香蕉**开始，其次菠萝，苹果放后。

理由：

1. **香蕉最适合做“稳定进口水果”的起步单品**
   - 消费频次高、认知强，不教育市场。
   - 全年需求稳定，周转快。
   - 进口香蕉（如菲律宾、厄瓜多尔等）供应链成熟，规格和熟度分级较标准。
   - 缺点是损耗和催熟管理要求高，但这正好能逼你把冷链、催熟、陈列和日清流程建起来。

2. **菠萝可以第二做**
   - 进口菠萝有差异化卖点，单价和毛利通常比香蕉好。
   - 但消费频次低于香蕉，且消费者对品种、酸甜度、削切服务敏感，动销更依赖试吃和现场服务。
   - 适合在香蕉跑通冷链和周转后，作为补充品类。

3. **苹果不建议先做进口**
   - 国产苹果供应充足、价格带覆盖广，进口苹果差异化弱。
   - 消费者对进口苹果的价格敏感度较高，容易变成“有货但动销慢”。
   - 除非你有明确的高端客群和稳定冷链，否则不建议作为首个稳定进口单品。

**可执行起步方案：**
- 先选1—2个进口香蕉规格试销4周，记录日均销量、损耗率、毛利率、缺货次数。
- 目标先看：损耗率能否控制在可接受范围、日均销量是否稳定、复购是否出现。
- 香蕉跑通后再引入1个进口菠萝单品，做试吃和削切服务。
- 进口苹果作为第三阶段，先小批量测试高端客群，不压库存。

一句话：**先用香蕉建立进口水果的冷链和周转能力，再用菠萝做毛利补充，苹果最后做差异化。**
