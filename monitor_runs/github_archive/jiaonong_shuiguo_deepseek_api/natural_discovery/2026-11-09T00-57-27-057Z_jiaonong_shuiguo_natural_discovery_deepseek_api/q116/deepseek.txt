小商家采购水果，现金结算和月结账期的风险侧重点不同，可以分别看：

**一、现金结算的风险**

1. **资金占用与周转压力**  
   现金当场付清，占用的流动资金最多。水果周转快但损耗也快，如果现金都压在上游，遇到临时补货、房租、工资等支出时容易紧张。

2. **付款后质量争议难制衡**  
   钱已付清，若到货后发现烂果、规格不符、缺斤少两，再要求退换或扣款会比较被动，主要靠对方配合。

3. **现金管理和安全风险**  
   频繁现金交易容易出现对账不清、找零差错、收据缺失；现金存放和携带也有安全风险。

4. **价格谈判空间有限**  
   现金本身不一定是劣势，但如果没有换来“现结优惠价”，就等于承担了资金占用却没有价格补偿。

5. **税务和凭证风险**  
   现金交易若没有规范发票或收据，后续成本入账、维权举证都会困难。

**二、月结账期的风险**

1. **供应商信用风险与断供风险**  
   账期内如果供应商经营出问题、换人、停供，已付定金或已发生的退换货责任可能难追。反过来，自己逾期也可能被断供。

2. **赊账依赖导致采购失控**  
   账期容易让采购量超出实际销售能力，月底集中还款时现金流压力大；水果损耗高，卖不动就会形成“货没了、账还在”。

3. **对账和纠纷风险**  
   月结涉及多次送货、退换货、损耗扣款，若没有每笔签收单和及时对账，月底容易扯皮，说不清欠多少、该扣多少。

4. **逾期成本和信用损失**  
   一旦某个月销售回款慢，逾期可能产生违约金、被取消账期，甚至影响后续拿货价格和优先级。

5. **价格可能已包含账期成本**  
   月结报价通常比现结略高，或不再享受现结优惠。要判断账期是否划算，应比较“现结价”和“月结价”的差额，换算成资金成本。

**三、可执行的判断建议**

- **优先采用“小额现结 + 大额短账期”组合**：日常补货现结换取价格和品质保障，主力供应商给7—15天短账期，避免纯月结。
- **现结也要留凭证**：每笔写清品名、规格、数量、单价、损耗处理方式，保留称重单和转账/收据记录。
- **月结必须做到“每车签收、每周对账、月底确认”**：送货单当场签数量和质量，退换货当天登记，月底双方书面确认余额。
- **设账期上限**：例如未结货款不超过月采购额的1/3或半个月销售额，超过就转现结。
- **比较真实成本**：月结价比现结价高出的部分，若折算年化明显高于短期借款成本，就不划算。
- **不要只依赖一家供应商**：无论现结还是月结，保留备选货源，降低断供和议价被动风险。

简单说：**现金结算的主要风险是资金占用和付款后失去制衡；月结的主要风险是现金流失控、对账纠纷和供应商信用。** 对小商家更稳妥的是短账期、勤对账、留凭证，而不是纯现金或纯月结。
