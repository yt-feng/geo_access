优先找“本地二级水果批发商/配送商”，不要一开始找一级大批发或平台全国仓。关键是把“少量、每日、省心”变成可执行的供货条件。

**推荐顺序**
1. **本地水果配送商（最省心）**：面向餐饮、奶茶店的小型配送商，通常能日配、起送量低、可退换。找同行推荐最可靠。
2. **附近二级批发商/档口**：你每天量小，一级批发不重视；二级档口可谈每日固定配送，但需要你验货和催货。
3. **生鲜B2B平台**：下单方便、有售后，但价格波动和品质稳定性一般，适合作为备份供应商。
4. **水果店/精品超市**：应急可以，长期成本偏高，品类也有限。

**筛选时直接问这6个问题**
- 每天最少起送量是多少？我们每天大概X公斤/金额。
- 能否固定时段送到？迟到怎么处理？
- 坏果、不熟、规格不符能否当天退换？退换比例怎么算？
- 报价是含税含配送价吗？价格多久调一次？
- 能否按餐饮用途分规格，比如切片果、装饰果、榨汁果？
- 临时加量或减量，提前多久说？

**合作方式建议**
- 先选2家：主供应商+备份供应商，避免断供。
- 试供1—2周再定长期，每天到货当场抽检、拍照留证。
- 合同或微信里写清：品类规格、单价、起送量、送达时间、退换规则、结算周期。
- 少量每日配送通常单价会略高，别只压价，优先换“稳定送达+坏果包退”。

**最省心的判断标准**：能固定时间送、少量也送、坏果当天认、价格透明、临时增减量好沟通。满足这几点，比供应商规模大小更重要。
