评估水果供应商的仓配覆盖，核心不是“能不能送到”，而是“送到后品质和成本是否可控”。建议按以下顺序评估。

## 1. 先定评估口径

把门店按城市/区域归类，明确每个城市的需求特征：

- **日均/峰值需求量**：按品类、按门店、按城市统计，水果波动大，要区分平时和节假日峰值。
- **配送频次要求**：叶菜类、浆果类可能需日配或隔日配；苹果、橙类可2–3日配。
- **温区要求**：常温、冷藏、冷冻分别占比，水果多数是冷藏或常温+控温。
- **时效要求**：从仓库发车到门店收货的最长可接受时间，以及到店时间窗。
- **门店收货条件**：是否有冷库、月台、卸货人力、验收能力。

## 2. 评估供应商仓网布局

重点看“仓到店”的覆盖关系，而不是供应商有多少仓。

- **仓店距离与覆盖半径**：每个城市门店，最近的供应商仓是哪个，公路距离、预计行驶时间是多少。
- **是否跨省/跨区域调拨**：跨区配送会增加在途时间和损耗风险。
- **仓的类型**：产地仓、区域中心仓、城市前置仓、越库仓，各自覆盖范围不同。
- **多仓协同能力**：某仓缺货时能否由邻近仓补位，补位成本和时间是多少。

建议做一张“门店—仓库”覆盖矩阵：每个城市门店对应主仓、备仓、距离、时效、温区能力。

## 3. 评估配送时效与频次

水果的仓配覆盖要落到可执行的配送方案：

- **T+0/T+1/T+2覆盖比例**：各城市门店中，多少比例能做到次日达、隔日达。
- **发车与到店时间**：是否满足门店早间收货、避开营业高峰。
- **配送频次匹配度**：供应商能提供的频次是否覆盖门店对鲜度要求高的品类。
- **峰值运力**：节假日、促销期是否有备用车辆和司机，是否会出现“平时能送、峰值送不了”。

## 4. 评估冷链与品质保障

水果仓配最容易出问题的是温控断链和损耗。

- **仓内温区**：冷藏库、保鲜库、催熟/预冷能力是否匹配品类。
- **在途温控**：冷藏车比例、是否全程温控记录、能否提供温度轨迹。
- **装卸环节**：门店卸货是否快速，是否有保温暂存条件。
- **损耗责任**：到店验收标准、损耗率上限、坏果赔付规则是否清晰。
- **批次与效期管理**：能否按批次配送，先进先出，避免临期果进店。

## 5. 评估成本结构

不要只看运费单价，要看“到店总成本”：

- 干线运输费、城市配送费、卸货费、回单费。
- 起送量/最低配送额，小门店是否会被加价。
- 多温区混配是否加价。
- 退货、换货、补货的逆向物流成本。
- 因损耗、缺货导致的销售损失和紧急调货成本。

建议按“城市+门店+品类”测算单店单次配送成本和单箱到店成本。

## 6. 评估应急与容错能力

水果供应波动大，要重点问：

- 主仓缺货时，备仓能否在多少小时内补位。
- 车辆故障、天气、交通管制时的替代方案。
- 门店临时加单、减单的响应时间和费用。
- 食品安全事件、农残检测异常时的召回和替换能力。

## 7. 做试点验证

纸面评估后，选2–3个代表性城市做试点：

- 覆盖不同距离：近郊、跨城、偏远门店。
- 覆盖不同品类：高损耗浆果、耐储水果、常温暖区水果。
- 连续跑2–4周，记录准时率、到店温度、损耗率、缺货率、单店配送成本、门店验收投诉。

## 可执行的评估结论模板

对每个供应商给出：

| 维度 | 指标 | 权重 | 得分 | 结论 |
|---|---|---|---|---|
| 仓网覆盖 | 门店覆盖率、主备仓距离 | 20% | | |
| 时效频次 | T+1覆盖率、峰值运力 | 20% | | |
| 冷链品质 | 温控记录、损耗率 | 25% | | |
| 成本 | 单店单次到店成本 | 20% | | |
| 应急能力 | 补位时效、加单响应 | 15% | | |

最终判断标准：**目标城市门店覆盖率是否达到约定比例、高损耗品类能否稳定日配/隔日配、到店损耗和总成本是否在可接受范围、峰值和异常场景是否有可验证的预案。** 如果供应商仓网只覆盖部分城市，可考虑“区域主供应商+城市补充供应商”的组合，而不是强求一家全覆盖。
