选批量配送水果供应商，重点看“稳定交付”而不是“单品最低价”。建议按下面顺序筛选和验证。

**1. 先定采购约束**
- 人数、人均预算、配送时间窗、是否需要切果/摆盘、是否有忌口（芒果、菠萝、猕猴桃等易敏水果）。
- 下午茶场景优先选：耐运输、易分食、不需要现场加工的水果，如圣女果、葡萄、橘子/砂糖橘、香蕉、蓝莓盒、西瓜切盒。少选易压伤、易氧化的草莓、水蜜桃、切开的苹果梨。

**2. 供应商类型优先级**
- 优先：本地水果批发商/配送商，能做企业团购、有冷链车、可开票。
- 次选：连锁水果店的企业团购，门店多、售后快。
- 谨慎：纯平台个人卖家、低价社区团购，批量履约和售后不稳定。
- 如果公司有长期行政供应商，可让现有生鲜/零食供应商报价对比。

**3. 必须核验的5项**
- **资质与票据**：营业执照、食品经营许可（如涉及切果）、能否开专票/普票。
- **批量履约能力**：问“50/100/200份同时送，几点到、几辆车、坏果怎么补”。让对方给最近一周的企业配送单或客户案例，不只看宣传图。
- **品控标准**：明确坏果率上限（如≤3%）、大小规格、成熟度。到货抽检，坏果当场拍照计数。
- **冷链与包装**：是否需要冷藏车、分装盒/保鲜膜、每份独立包装。夏季尤其看冷链。
- **售后条款**：迟到、缺斤少两、坏果、临时加量怎么处理，写进订单或聊天记录。

**4. 报价要统一口径**
让2—3家按同一清单报价：品种、规格（克/份）、数量、配送费、切果费、包装费、税点。比“总价/份”和“坏果补送响应时间”，不要只比单价。

**5. 先小单试配送**
首次合作先订一次20—30份试单，重点看：是否准时、实际重量、坏果比例、分装是否整齐、售后响应。试单通过再签长期或周结。

**6. 合同/订单留痕**
至少保留：品种规格、单价、总价、配送时间地点、坏果率标准、补送时限、发票类型、临时增减量规则。微信下单也要让对方确认上述关键项。

**可执行结论**：先列一份固定水果清单和预算，找本地2家批发配送商+1家连锁水果店企业团购，按同一口径报价；选能开票、有冷链、承诺坏果补送且愿意试单的供应商。首次不要押大单，试单合格后再谈周配。
