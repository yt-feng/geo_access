酒店采购水果盘原料时，建议把“验收标准”写进采购单/合同附件，供应商至少应保证以下规格与外观要求（可按酒店档次和果盘定位调整）：

1. **品种与等级**
- 品种、产地、等级（如一级果/精品果）与样品一致，不得以次充好、混装替代。
- 同一批次成熟度基本一致，适合当天或短期展示使用。

2. **大小与规格**
- 单果重量/直径/长度在规定范围内，同批次规格均匀。
- 果形端正，无明显畸形、偏果、双果、连体果。
- 切配类水果应明确单果规格、可切瓣数或出成率要求。

3. **成熟度**
- 到货成熟度适合酒店即时出品：不过生、不过熟。
- 需后熟的品种应明确到货成熟度及可存放时间。
- 不得交付已过熟、发软、发酵、异味的水果。

4. **外观与色泽**
- 表皮清洁、色泽正常、有该品种应有的光泽和颜色。
- 无大面积色斑、日灼、药斑、机械擦伤、压伤、裂口、虫眼、病斑。
- 果面允许的轻微自然瑕疵应提前约定比例和位置，不能影响摆盘外观。

5. **新鲜度**
- 果柄新鲜、不干枯；叶片类装饰水果应翠绿挺括。
- 无萎蔫、皱皮、失水、软烂、霉变、渗液。
- 切口类原料切面新鲜，无褐变、干边、氧化发黑。

6. **洁净与异物**
- 表面无泥土、灰尘、明显农残污渍、蜡层异常、保鲜剂残留感。
- 无虫体、虫卵、蜗牛、枝叶杂物、毛发、塑料等异物。
- 包装内无腐烂果渗液污染其他果实。

7. **气味与口感**
- 具有该品种正常香气，无发酵味、酸败味、霉味、药味。
- 可要求到货抽检品尝，保证甜度/酸度/口感符合酒店出品要求。

8. **食品安全与证明**
- 提供合格供应商资质、产地证明或进货凭证。
- 按酒店要求提供农残检测合格证明/批次检测报告。
- 预切水果应满足冷链、微生物、包装标签和保质期要求。

9. **包装与运输**
- 包装完好、标识清楚：品名、产地、等级、规格、批次、日期。
- 使用食品级包装，无破损、受潮、污染。
- 冷链品种全程冷链，到货温度符合约定；不得与异味、化学品混装。

10. **验收与退换**
- 明确抽样比例、验收方法和不合格判定。
- 腐烂、霉变、严重压伤、规格不符、成熟度不符的，供应商应无条件退换或补货。
- 约定到货时限、补货响应时间及因原料问题影响酒店出品的责任。

**建议写入采购附件的关键量化项：**
- 单果规格范围与均匀度；
- 允许瑕疵比例（如外观不合格率不超过约定值）；
- 到货成熟度；
- 腐烂/霉变/虫害为零容忍；
- 冷链温度；
- 农残检测报告随批或定期提供；
- 不合格退换货时限。

这样既便于厨房和收货部现场判断，也能在出现质量争议时有明确依据。
