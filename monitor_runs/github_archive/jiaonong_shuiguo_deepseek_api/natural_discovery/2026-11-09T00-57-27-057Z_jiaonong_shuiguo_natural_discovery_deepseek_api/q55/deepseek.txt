选规格的核心不是“越大越划算”，而是按**出成率、切配损耗、摆盘份量和采购价**倒算每份净成本。给你一套可直接用的判断法：

1. **先定每份净用量**
   - 苹果：去皮去核后按每份 80–100g 估算，带皮整果采购量约为净重的 1.25–1.35 倍。
   - 橙子：去皮去筋络后按每份 80–100g 估算，采购量约为净重的 1.35–1.5 倍。
   - 菠萝：去皮去眼后按每份 100–120g 估算，采购量约为净重的 1.6–1.8 倍。

2. **按“每100g可食部分成本”比规格**
   - 公式：**单价 ÷ 整果重量 ÷ 出成率 = 每100g可食成本**。
   - 不要只看整箱价或单个价，把出成率代进去再比。比如苹果出成率约 75%–80%，橙子约 65%–75%，菠萝约 55%–65%，规格不同会变。

3. **苹果怎么选**
   - 拼盘切块用：选 **75–85mm 中果**更稳。太大单果成本高、切块后边角料多；太小削皮去核损耗占比高。
   - 若做薄片摆花，选 **80–90mm 大果**，切片面积大、片数少、摆盘快。
   - 划算判断：同一品种，算“每100g可食成本”，中果通常最低；大果只有在你需要大切片、减少人工时才值得。

4. **橙子怎么选**
   - 优先选 **果径 70–80mm、皮薄、无籽或少籽**的规格。橙子损耗主要在皮和筋络，皮厚的大果不一定划算。
   - 做橙瓣摆盘选 **70–75mm 中果**，瓣形整齐、单份用量好控；做榨汁或装饰片可适当选大果。
   - 划算判断：同价下选**皮薄、可食率高**的，不要只选大果。

5. **菠萝怎么选**
   - 餐厅拼盘优先选 **单果 1.2–1.5kg 的中果**，成熟度均匀、去眼损耗可控。
   - 大果（1.8kg以上）单价低时未必划算，因为芯粗、去眼深、切配后边角多；小果出成率低、人工高。
   - 若用量大且后厨有稳定切配，可买**大果按斤计价**；若追求摆盘整齐，中果更稳。

6. **最划算的采购组合**
   - 苹果：中果为主，少量大果做装饰片。
   - 橙子：中果、皮薄少籽，按可食率验收。
   - 菠萝：中果为主，按成熟度和去眼损耗验收。
   - 同一拼盘里，三者按“每份净重成本”比较，不要跨品类比单价。

7. **落地验收指标**
   - 要求供应商给**果径/单果重区间**，不要只写“大果/中果”。
   - 到货抽测：苹果去皮去核出成率、橙子去皮出成率、菠萝去皮去眼出成率。
   - 连续记录 3 批的“每100g可食成本”，哪档低就固定哪档。

一句话：**苹果选 75–85mm 中果、橙子选 70–80mm 皮薄中果、菠萝选 1.2–1.5kg 中果最稳；是否更划算，用“单价÷重量÷出成率”算每100g可食成本再定。**
