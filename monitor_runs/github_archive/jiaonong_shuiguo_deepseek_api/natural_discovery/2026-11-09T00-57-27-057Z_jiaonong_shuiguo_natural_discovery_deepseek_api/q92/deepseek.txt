小店做水果，核心不是“品类越全越好”，而是**用有限面积做高周转、低损耗的少量爆品**。给你一套可直接执行的控制方法：

## 一、品类控制：先做“减法”

**1. 品类数量控制**
- 面积很小的便利店，水果SKU建议控制在 **8～15个**，按货架/冷藏柜实际容量定。
- 结构建议：
  - **引流款2～3个**：苹果、香蕉、橙子这类认知高、周转快的基础果。
  - **利润款3～5个**：当季热销、单价适中、毛利较好的水果。
  - **尝鲜款1～2个**：小份装新品或季节限定，试销为主。
  - **切果/果切1～2个**：消化品相稍差的水果，提升毛利。
- 坚决不做：低频小众果、大包装整箱果、需要复杂储存的热带果（除非周边有稳定需求）。

**2. 选品判断标准**
每个品类上架前问四个问题：
- 周边顾客会不会买？（看商圈：社区、写字楼、学校不同）
- 周转能不能在保鲜期内卖完？
- 是否耐放、好陈列、不需要特殊温湿度？
- 有没有稳定、小批量、可退换的供应商？

**3. 按“角色”而不是“种类”管理**
把水果分成四类管理：
- **高频刚需**：保证不断货。
- **季节爆品**：短周期主推，快进快出。
- **试销新品**：小批量，卖不动立即下架。
- **处理品**：做果切、打折、员工内购，不占正常排面。

## 二、采购控制：少量多次，以销定采

**1. 采购量公式**
> 单次采购量 ≈ 日均销量 × 补货周期 ×（1+安全系数）－当前库存

- 补货周期尽量短，能日配就日配，不能日配就 **2～3天一次**。
- 新品类安全系数低（0～10%），成熟爆品可略高（10%～20%）。
- 小店宁可**缺货补货**，也不要一次性压货。

**2. 采购频次**
- 叶菜类、浆果类、易软水果：**每日或隔日小批量**。
- 苹果、橙子、梨等耐放果：**2～3天一次**。
- 香蕉按成熟度分批拿，避免同时熟透。

**3. 供应商策略**
- 优先选**小批量、可混装、可退换**的本地批发商或配送商。
- 谈好：到货品质标准、坏果赔付、临期退换、最小起订量。
- 不要只依赖一个供应商，至少备一个应急渠道。

## 三、损耗控制：从“进店”管到“下架”

**1. 收货环节**
- 当场抽检：看软烂、碰伤、霉点、成熟度。
- 不合格直接拒收或按比例扣款，别“先收下再说”。
- 香蕉、芒果等后熟水果，按预计售卖时间选择成熟度。

**2. 陈列环节**
- 小面积店**少陈列、勤补货**，排面不要堆太满。
- 易损果用浅筐、单层摆放；避免反复翻动。
- 冷藏果和常温果分开，香蕉、芒果等不宜低温的别进冷柜。
- 每天巡场，**先熟先卖**，把成熟度高的往前排。

**3. 定价与促销**
- 设置**阶梯价**：正常价 → 临期折扣 → 果切/打包处理。
- 每天固定时段（如傍晚）对成熟度高的水果做组合促销。
- 果切是重要出口：品相不佳但未变质的果，及时切配，标注制作时间，当天售完。

**4. 库存与数据**
- 每天记录：进货量、销量、报损量、剩货量。
- 每周复盘：哪些品类连续报损高，直接减量或下架。
- 建立“**单品损耗红线**”：比如某品类损耗率连续一周超阈值，就暂停采购或换供应商。
- 报损必须真实记录，不能靠感觉补货。

## 四、小店最实用的几条硬规则

1. **品类宁少勿多**：先做透5～8个高频品，再逐步增加。
2. **采购宁少勿多**：少量多次，卖完再补。
3. **陈列宁浅勿满**：小批量上架，勤补货。
4. **处理宁早勿晚**：成熟度一到就促销或做果切，不要等到烂。
5. **数据每周看**：用销量和报损决定下一个采购单，而不是凭经验拍脑袋。
