供应商介绍时，核心不是讲“品种知识”，而是把陌生品种翻译成商家熟悉的“卖法、口感、损耗、利润”。可以按这个顺序说：

1. **先对标大品类**  
   “这个口感和菠萝接近，但更甜、不扎嘴，适合直接切盒。”  
   “香蕉是刚需引流，这个更像高毛利补充品，不是替代香蕉。”

2. **只说商家听得懂的三件事**  
   - **怎么卖**：整果、切盒、果切拼盘、饮品原料、礼盒。  
   - **卖给谁**：家庭日常、办公室下午茶、儿童、餐饮客户。  
   - **怎么赚钱**：进货价、建议零售价、毛利空间、适合做引流还是利润款。

3. **主动讲损耗和操作**  
   商家最怕“不会卖、卖不掉、坏得快”。要说清：  
   “常温能放几天、冷藏几天、切开后多久变色、熟度怎么判断、坏果率大概多少、要不要催熟。”  
   不要只报一个模糊的“耐储存”。

4. **用对比句，不用品种术语**  
   少说：糖度、产区、品系名。  
   多说：  
   “比菠萝甜、比香蕉脆、比苹果香。”  
   “不用泡盐水，切开就能卖。”  
   “一斤能出几盒，切盒损耗比菠萝低。”

5. **给最小试单方案**  
   不要一上来压大货。直接说：  
   “先拿一箱试卖，我配试吃和话术卡；卖得动再补，卖不动我教你换场景。”  
   商家更容易下单。

6. **现场给一句话卖点**  
   供应商最好直接帮商家想好招牌话术，例如：  
   “比菠萝甜、不用泡盐水，切盒直接卖。”  
   商家能立刻用，才觉得这个产品“能卖”。

一句话总结：**别介绍“这是什么水果”，要介绍“这个水果在店里怎么变成钱”。** 先对标菠萝香蕉，再讲卖法、损耗、利润和试单，商家就容易听懂并下单。
