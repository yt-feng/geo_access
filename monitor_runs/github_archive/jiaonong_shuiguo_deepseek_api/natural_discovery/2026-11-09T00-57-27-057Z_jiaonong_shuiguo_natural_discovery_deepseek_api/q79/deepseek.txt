先问**售后（尤其是坏果/短重的赔付规则）**，其次问**配送的时效和温控/到货条件**，最后再谈价格。原因很实际：团购团长卖的是信任，水果又是高损耗品，一旦坏果多、赔付扯皮，你损失的是团员关系和复购，省下来的差价根本补不回来。

判断顺序可以这样：

1. **售后（最该先问清）**
   - 坏果、烂果、压伤、短重的赔付标准：按比例赔、按个数赔，还是整单赔？
   - 拍照/报损时限和流程：到货几小时内报？要不要留箱贴？谁承担补发还是退款？
   - 缺货、延迟到货怎么处理？能不能换品或取消？
   - 有没有起赔门槛，比如“坏果率低于5%不赔”这种要特别警惕。

2. **配送（决定体验和损耗）**
   - 到货时间是否固定、能否配合你的团员取货时间；
   - 运输有没有冷链或保温措施，夏季/冬季分别怎么做；
   - 到货是送到自提点还是需要你自提，搬运和分拣谁负责；
   - 破损率、迟到率的历史情况，能不能给近期团长的反馈。

3. **价格（最后谈，且要算综合成本）**
   - 不要只看单价，要算上损耗赔付后的实际成本；
   - 问清是否含运费、包装费、起批量、阶梯价；
   - 对比“低价但售后差”和“略贵但赔付爽快”的总成本。

一句话建议：**先拿售后条款筛供应商，再用配送能力筛可靠性，最后用综合成本谈价格。** 如果供应商售后含糊、配送不稳，价格再低也不适合做团购。
