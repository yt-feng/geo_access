水果生意想长期稳定，选供应商时最容易忽视的不是“价格”和“品种”，而是下面这些**会影响持续性、损耗率和客户信任**的细节：

1. **只看样品，不看大货稳定性**
   样品好不代表批量稳定。要重点看：同一品种连续几批的规格、甜度、成熟度、色泽、果径是否一致。长期生意最怕“这一批好、下一批差”。

2. **忽视到货损耗责任**
   要提前明确：运输损耗、压伤、烂果、短斤少两由谁承担，怎么赔。很多合作前面谈得顺，出问题才发现没有书面规则。

3. **不看过往供货记录**
   不要只问“能不能供”，要问“最近三个月给哪些客户供过、供了多少、退换货多不多”。能提供稳定客户和复购记录的供应商更可靠。

4. **忽视采摘和催熟节奏**
   水果不是越熟越好卖。要确认供应商是否能按你的销售节奏控制采摘成熟度、是否做过量催熟、货架期大概几天。否则到店后很快软烂，损耗会吃掉利润。

5. **没有分级标准**
   长期合作必须把等级说清楚：果径、重量、糖度、外观瑕疵、包装规格。只靠“大果、中果、精品”这种口头描述，后面很容易扯皮。

6. **忽视包装和运输细节**
   同样是水果，泡沫箱、纸箱、冰袋、透气孔、码放方式不同，损耗差很多。要看到货包装是否适合你的销售场景，比如门店陈列、外卖配送、社区团购。

7. **不考察产地和季节切换能力**
   只依赖一个产地，遇到天气、病虫害、集中上市尾期就容易断供。稳定供应商应能说明不同季节的替代产区、切换标准和价格变化逻辑。

8. **忽视账期和资金压力**
   低价现结和稍高价月结，对现金流影响很大。要明确账期、结算方式、涨价提前通知时间，避免旺季临时压货或突然提价。

9. **不测试售后响应**
   合作前故意问一次售后处理流程：坏果怎么拍照、多久反馈、几天补货或退款。响应慢的供应商，在旺季会把小问题放大成大损失。

10. **忽视对方的客户结构**
    如果供应商主要做大超市、大批发，可能看不上你的小单；如果主要做零售散客，又不一定稳供。要找与你采购量匹配、愿意长期配合的供应商。

实操建议：先小批量试供2—3批，固定验收标准，记录每批损耗率、退货率、到货时间和客户反馈；连续稳定后再谈账期和独家规格。长期稳定靠的是**可复制的验收规则**，不是单次低价。
