香蕉放坏的核心是“到货时已经太熟、或到货后没有足够货架期”。采购要求要把“熟度标准”和“到货节奏”同时写清楚。

**1. 熟度要求：按颜色和手感分级，不笼统说“熟一点/生一点”**

建议按香蕉果皮颜色（行业常用1–7号色卡）约定：

- **常规门店销售**：到货以 **3–4号色** 为主（绿中带黄到黄多绿少），手感硬挺、果指饱满、无软塌。
  - 3号色适合放2–4天再进入最佳销售期；
  - 4号色适合1–2天内卖完。
- **夏季或周转慢的门店**：主采 **2.5–3号色**，减少到货即熟透。
- **促销/快周转档口**：可少量要 **4–5号色**，但必须当天或次日基本售完。
- **明确拒收线**：到货超过 **5号色**（大面积黄、果柄发黄软）、果指有软斑、棱角消失、果柄发黑、有酒味/酸味，应拒收或折价。

同时要求：
- **无机械伤、无压伤、无冷害**：香蕉怕冷，运输温度一般不低于 **13–14℃**，不得与低温冷藏混装。
- **整批色号一致**：同一批次色差不超过1个色号，避免“青黄混装”导致催熟不均。
- **果指饱满度**：要求七成以上饱满，不采太瘦果；太生的香蕉到店后难均匀转黄。

**2. 到货时间：按销售节奏分批到，不一次压货**

- **频率**：旺季或高温天 **每日到货或隔日到货**；淡季可2–3天一批，但单批量控制在 **2–3天销量**。
- **到货时段**：要求 **早晨开店前到货**，便于当天分拣、上架、挑出过熟果；避免傍晚到货后整夜闷在库房。
- **在途时间**：从产地/催熟库到门店尽量控制在 **24小时内**；夏季要求 **冷链或通风运输**，车厢温度 **13–15℃**，不得暴晒、不得与乙烯释放大的水果混装。
- **分批催熟**：如果供应商有催熟能力，要求按门店销量分 **3–4号色** 和 **4–5号色** 两档分批送，而不是一整批同熟度。

**3. 采购合同/订单里建议直接写这几句**

> “香蕉到货色号以3–4号为主，同批色差不超过1号；5号色以上、软斑、机械伤、冷害、异味果拒收。夏季主采2.5–3号色。到货时间为每日开店前，单批量为2–3天销量。运输温度13–15℃，在途不超过24小时。”

**4. 配套动作**

- 到货当天做 **色号抽检**，按10%抽样；
- 门店存放 **通风、13–14℃、避免叠压**，不要放冷藏柜；
- 每天挑出 **5号色以上** 的香蕉，转促销或加工，别等整串坏；
- 记录“到货色号—售完天数”，连续两周就能反推出适合自己门店的采购色号和批量。

一句话：**采购时要求“3–4号色为主、同批色差小、每日/隔日小批量早晨到货、运输不低于13℃”，并把5号色以上和软伤果写进拒收标准。**
