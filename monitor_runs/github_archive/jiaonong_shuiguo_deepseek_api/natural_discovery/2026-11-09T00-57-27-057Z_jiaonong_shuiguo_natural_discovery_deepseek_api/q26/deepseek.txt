做小包装香蕉，采购和包装环节要重点抓这几件事：

1. **按“根”定规格，别按整串估**
   - 小包装建议 2～3 根/袋，单袋净重控制在 300～500g，适合单人/小家庭。
   - 采购时明确要求“可拆分小串”或“单根分级”，避免拿到大串后强行拆袋，造成断口、掉把。
   - 优先选果指均匀、果把完整、无机械伤的货；果把是损耗关键，断把后极易从伤口腐烂。

2. **控制成熟度，分批次采购**
   - 社区店周转慢，小包装最怕“卖一半熟过头”。采购成熟度建议偏青一点，留 1～2 天催熟窗口。
   - 一次采购量按 1～1.5 天销量订，少量多次；不要为了拿低价一次压太多货。
   - 到货后按成熟度分两批：偏青的放后面，已黄有香气的先上架。

3. **包装要“透气+防压+防掉把”**
   - 袋装选打孔保鲜袋或网袋，不要完全密封；密封袋易积水汽，加速黑斑和腐烂。
   - 袋内不要套太紧，避免挤压果指；2～3 根一袋比多根混装更稳。
   - 可用托盘+收缩膜或带孔袋，减少顾客翻拣造成的掉把。
   - 标签贴袋面，不要直接贴在香蕉皮上，撕标会伤果皮。

4. **陈列和周转要配合包装**
   - 小包装适合平铺或浅筐陈列，不要堆高，堆压会压伤下层。
   - 每天至少挑拣 2 次，把出现黑斑、软烂、断把的袋拆开处理或降价，不要留在原袋里传染。
   - 黄熟小包装可做“当日特价”，青一点的正常价，形成梯次销售。

5. **损耗要算进采购价**
   - 香蕉小包装损耗通常来自：断把、压伤、过熟、顾客翻拣。采购时要把 5%～10% 的预期损耗计入毛利，不要按零损耗定价。
   - 和供应商约定：断把、严重机械伤、到货过熟可退换或折价；到货当场抽检，别等上架后才发现。
   - 记录每天拆袋损耗，连续几天某规格损耗高，就调整单袋根数或采购成熟度。

6. **季节和门店条件**
   - 夏季高温，小包装更容易闷坏，袋孔要更多，采购量再压缩；冬季可适当放宽。
   - 如果店里有空调直吹或阳光直射的位置，不要放小包装香蕉，容易表皮发黑、成熟不均。

简单执行标准：**2～3 根/袋、偏青采购、打孔袋、少量多次、每天挑拣、损耗按 5%～10% 预留。** 先试销一周，按实际拆袋损耗再调单袋规格和采购量。
