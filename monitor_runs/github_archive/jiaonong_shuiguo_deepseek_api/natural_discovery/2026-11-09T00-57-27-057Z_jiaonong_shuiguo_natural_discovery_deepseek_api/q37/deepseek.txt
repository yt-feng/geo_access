商超会员日水果活动，供应商要提前配合的重点可以按“货、价、质、场、人、数”六类准备：

1. **货：锁量锁档期**
   - 提前确认会员日销量预估、锁货量和备货比例，主推单品备足，另留10%–20%安全库存。
   - 明确到货时间、到货批次和补货频次，会员日当天最好有二次补货或应急补货方案。
   - 包装规格、箱规、码盘方式与门店陈列/后仓容量匹配，避免大箱到店拆不动。

2. **价：提前锁价并明确费用承担**
   - 会员价/促销价提前锁定，明确供应商承担、商超承担或双方分摊的比例。
   - 确认是否含税、含运费、含损耗，避免活动前临时变价。
   - 对主推爆品准备价格保护或限量规则，防止被囤货、倒卖。

3. **质：到货标准和验收前置**
   - 提前约定等级、规格、糖度/成熟度、果径、色泽、破损率等验收标准。
   - 会员日货量集中，供应商要提前做分选、预冷、分级，避免到店后集中挑拣。
   - 明确坏果、烂果、短斤少两的处理和赔付规则，最好活动前书面确认。

4. **场：配合陈列和物料**
   - 按商超堆头、端架、冷柜尺寸准备统一箱规、陈列道具、试吃样品和价签信息。
   - 主推单品提前给门店做陈列建议：堆头量、补货动线、试吃位置、关联陈列。
   - 需要冷链的提前确认冷库/冷柜容量和到店温度要求。

5. **人：驻场与响应**
   - 会员日高峰安排驻场或巡店人员，负责补货、挑拣、试吃、客诉处理。
   - 明确供应商对接人、商超对接人、异常响应时限，最好建活动群。
   - 提前培训试吃和推介话术，统一口径，避免夸大宣传。

6. **数：数据与复盘**
   - 活动前确认销量目标、毛利目标、损耗率上限和库存周转要求。
   - 约定每日销售/库存/损耗数据回传时间，便于中途加单或调价。
   - 活动后48小时内做复盘：动销、缺货、损耗、客诉、费用分摊，形成下次备货系数。

可执行清单：活动前7天锁量和锁价，前3天确认到货批次与陈列方案，前1天完成分选预冷和驻场排班，当天按2–4小时补货节奏响应，活动后48小时复盘。最关键的是把**锁量、锁价、验收标准、损耗赔付、补货责任**五项提前书面确认，否则会员日最容易在缺货、品质和费用上扯皮。
