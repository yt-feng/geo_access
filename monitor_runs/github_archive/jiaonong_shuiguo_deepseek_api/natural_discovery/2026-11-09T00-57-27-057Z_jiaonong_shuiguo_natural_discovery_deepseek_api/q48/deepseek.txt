判断茶饮连锁的菠萝供应商能否稳定按规格送货，不能只看样品和报价，建议把“能不能稳定”拆成可验证的四件事：**规格可量化、产能有证据、品控有记录、履约可兜底**。按下面顺序做，基本能筛掉大部分不稳定供应商。

**1. 先把“规格”写成可验收的合同语言**
不要只写“中大果、成熟度适中”。至少明确：
- 品种/产地：如金钻凤梨/巴厘种，允许替代是否需书面同意；
- 单果重量区间：如1.2–1.5kg，超出比例上限；
- 成熟度：糖度范围、果眼/果皮转色比例、是否允许催熟；
- 外观：黑心、水心、裂果、机械伤、冠芽长度等次品率上限；
- 加工适配：去皮出肉率、纤维粗硬度、酸甜比，茶饮店更应关注出肉率和切丁后出水情况；
- 包装与冷链：箱规、每箱净重、预冷温度、运输温度记录；
- 到货验收：抽检比例、不合格判定、扣款/退换货时限。

**2. 用“连续批次”验证，而不是一次样品**
要求供应商提供最近3–6个月、至少3–5个批次的供货记录，重点看：
- 每批到货重量区间是否稳定，最大最小差多少；
- 次品率、糖度波动、出肉率波动；
- 是否有同一批次前后不一致的情况；
- 能否提供分拣照片、抽检记录、冷链温度记录。
如果对方只有“好果”样品，没有历史批次数据，稳定性要打问号。

**3. 查产能和季节替代方案**
菠萝有明显产季和产区切换。要问清：
- 自有基地/合作基地面积、日加工能力、冷库容量；
- 当前产区下市后从哪个产区补，切换期规格是否变化；
- 旺季日供量上限，连锁门店峰值需求能否覆盖；
- 是否有备用供应商或备用产区，断供时多久能补货。
能稳定送货的供应商，通常能说清“产季切换表”，而不是只承诺“全年都有”。

**4. 做小批量试单和压力测试**
建议先下2–4周、覆盖不同门店的试单，故意设置一次加急补货和一次规格抽检：
- 看准时交付率、短装率、破损率；
- 看异常响应时间，是否24小时内给处理方案；
- 看退换货是否爽快，是否把损耗转嫁给门店；
- 看同一规格连续到货是否漂移。

**5. 合同里加履约约束**
至少写进：
- 准时交付率和短装罚则；
- 规格不符的退换货、扣款和补货时限；
- 连续不合格批次的终止条款；
- 产季切换提前通知义务；
- 备用货源报备；
- 到货抽检争议的第三方检测或复检机制。

**实操判断标准**：如果供应商能提供连续批次质检记录、明确产季切换方案、接受小批量试单和履约罚则，稳定性通常可验证；如果只会带你看样品、口头保证“没问题”、不愿写规格和罚则，建议不要作为主力供应商。茶饮连锁最好采用“1家主供+1家备供”，主供占比70%–80%，备供保持小单激活，避免单一产区断供。
