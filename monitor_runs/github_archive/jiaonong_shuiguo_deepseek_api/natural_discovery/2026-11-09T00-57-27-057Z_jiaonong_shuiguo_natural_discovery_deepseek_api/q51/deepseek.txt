要固定，但建议“固定标准 + 多产地/多批次备案”，而不是死守单一产地或单一批次。

**判断原则**
- **必须固定的是质量标准**：品种、成熟度、糖度/酸度范围、香气、出汁率、农残检测、冷链时效。
- **不必固定到唯一产地**：单一产地遇雨季、减产、病虫害、断货时，口味和供应都会被动。
- **批次要可追溯，但不要只认一个批次**：同产地不同批次也会有波动，关键是每批检测和留样。

**可执行做法**
1. 建“水果风味卡”：每类水果定糖酸比、香气、颜色、纤维感等可验收指标。
2. 主供 + 备供：同一品种固定 1 家主供、1–2 家备供，产地可不同但标准一致。
3. 每批到货快检：糖度、酸度、外观、口感盲测；不合格退货或降级使用。
4. 配方设容错：糖浆、酸度、冰量、茶底浓度留微调空间，但不靠员工随意改。
5. 留样与记录：每批留样，记录产地、批次、检测结果，出现波动可追溯。
6. 季节性切换提前做盲测：换产地前先小批量试饮，通过再切换。

**结论**：采购合同固定“验收标准、追溯要求、备供机制”，产地和批次保持“主固定、备可切换”。这样既控口味波动，又不断供。
