# 水果到货不合格：补货约定要点

核心思路：**把「不合格怎么认定、谁来补、多久补到、补不到怎么办」写进采购合同或供货协议**，而不是每次到货临时扯皮。

## 一、先约定「不合格」的判定标准

模糊的“质量不好”没法执行，要写成可当场判断的条款：

- **品类分级标准**：按品种写明规格（如柠檬单果直径、糖度范围、表皮无腐烂/无压伤/无虫眼、成熟度区间）。
- **抽检比例与判定**：如每批随机抽 10%，不合格率超过 X% 即整批拒收或折价接收。
- **到货验收时限**：收货时当场验收，超过约定时限（如 2 小时）未提出异议视为合格——这条对双方都公平，也避免事后扯皮。
- **留证方式**：拍照/视频留存、验收单双方签字，作为补货依据。

## 二、补货条款要写清的四件事

1. **补货时限**：按影响程度分级。例如：
   - 影响招牌产品的核心水果：**当日或次日营业前补到**；
   - 非核心品类：24–48 小时内补到。
2. **补货方式**：由供货方免费补发同规格合格品，运费由供货方承担；原不合格品由供货方取回或就地处理（写明谁承担损耗）。
3. **补货不到位的兜底**：约定供货方逾期未补的违约责任，如按缺货金额比例扣款、我方有权自行就近采购且差价由供货方承担。这一条是保证营业不受影响的关键。
4. **结算挂钩**：不合格批次不计入结算，或先扣款后补货，避免“货没补、钱已付”。

## 三、降低对营业影响的运营配套

- **安全库存**：核心水果保持 1–2 天用量，给补货留缓冲。
- **备用供应商**：至少一家备选，合同里写明紧急调货权。
- **替代配方预案**：提前准备缺货时的临时替代饮品/下架话术，避免顾客体验受损。
- **到货时间前置**：要求供货方在营业前（如开门前 2 小时）送达，留出验收和应急调货时间。

## 四、合同里建议加的一句话模板

> 供货方交付的水果经我方按附件《验收标准》验收不合格的，我方有权拒收或折价接收；供货方应在接到通知后 ___ 小时内免费补发合格品并承担运费，逾期未补的，我方有权自行采购，差价及因此产生的损失由供货方承担。

**一句话总结**：标准可判定、时限可执行、补不到有兜底、结算能挂钩——四条写进协议，补货就不会拖累营业。

（以上为通用合同条款建议，具体表述建议结合当地法规和实际供货关系由专业人士审核。）
