**供应商通常能提供的支持**

1. **包装形式**：预包装袋、贴体托盘、礼盒、网袋、散装大箱等；可做商超自有品牌标签（需确认是否代贴、谁承担标签合规责任）。
2. **规格分级**：按单果重、果径、糖度、外观瑕疵做分级，按你的货架和客单价做不同规格组合。
3. **包装定制**：印刷自有品牌logo、条码、产地信息、追溯码；起订量通常按包装材料和单品量谈。
4. **产地直发或分装**：部分供应商可在产地按你的规格分选包装后直发门店或配送中心。

**你必须提前确认的关键点**

- **起订量与加价**：定制包装一般有MOQ，小批量定制会摊高单件成本，先问清“定制包装比通用包装贵多少、MOQ多少”。
- **标签合规责任**：自有品牌标签上的品名、产地、等级、农残检测、保质期、贮存条件由谁提供和担责，写进合同。
- **分级标准可执行**：不要只写“大果”，要写清单果重区间、果径、允许瑕疵比例、糖度下限，并约定抽检和拒收规则。
- **损耗与售后**：运输损耗、到店烂果率、短重怎么赔，是否支持退换。
- **产能稳定性**：旺季能否保证你的规格优先供应，是否同时供竞品同款。

**建议动作**

先选1—2个单品做小批量试单：让供应商按你定的规格和包装打样，走一遍到店验收，测算实际损耗和毛利，再决定是否扩品。合同里把规格、抽检比例、损耗赔付、标签责任写死。

一句话：供应商普遍能做包装和规格支持，但你的核心工作是把“规格标准、成本增量、责任归属”三件事量化写进合作条款。
