三个都要管，但如果必须排优先级：**食品安全 > 配送准时 > 价格**。理由和可执行判断如下：

1. **食品安全是底线，不能妥协**
   - 水果风险主要在：农残超标、霉变腐烂、冷链断链、来源不明。
   - 企业食堂一旦出问题，影响面大、追责重，省下的采购差价远不够覆盖风险。
   - 至少要能做到：供应商资质可查、每批可追溯、到货验收有记录、异常可退换并留证。

2. **配送准时是食堂运营刚需**
   - 水果通常按餐次或每日配送，晚到会直接影响供餐和菜单执行。
   - 准时不是“大概送到”，要明确配送时段、迟到处理、缺货替代方案。
   - 建议合同里写清：到货时间窗口、迟到扣罚或应急补货责任。

3. **价格重要，但应放在“满足前两项后的比价”**
   - 水果价格波动大，单纯低价容易换来等级下降、以次充好、缺斤少两。
   - 合理做法是：固定品质标准后比价，按周/月调价，保留市场询价机制。

**可执行建议：**
- 准入阶段：先审供应商资质和食品安全记录，不合格直接淘汰。
- 日常验收：每批查外观、新鲜度、温度、数量，留验收单和照片；高风险品类定期抽检农残。
- 合同约束：把食品安全责任、配送时效、缺货赔付、价格调整机制写清楚。
- 考核权重可参考：食品安全40%、配送准时30%、价格20%、服务售后10%，再按企业实际调整。

一句话：**食品安全是一票否决，配送准时是运营保障，价格是在前两者达标后的优化项。**
