结论先给：**大多数商超应以“整果为主、鲜切为辅”的双轨结构来卖，而不是二选一。** 如果必须只选一个，优先整果；切好的适合作为补充品类，用来承接即时消费和提升客单价。

判断依据和可执行建议如下：

**1. 整果更适合商超主力销售**
- 菠萝整果耐存放、损耗可控，采购和陈列简单，适合走量。
- 顾客对整果的新鲜度、完整性更放心，价格敏感度也更高，适合做促销引流。
- 整果毛利通常更稳定，不需要额外的人工削切和包装成本。
- 适合家庭采购，尤其是节假日和周末。

**2. 鲜切菠萝适合做补充和增量**
- 适合即时消费场景：上班族、学生、逛街顾客，买完就能吃。
- 能提升客单价和陈列丰富度，尤其适合放在收银台附近、水果区端头或冷柜。
- 但鲜切对操作卫生、冷链、当日售罄要求高，损耗和人工成本明显高于整果。
- 如果门店客流不足或鲜切销量不稳定，容易变成损耗来源。

**3. 建议的落地结构**
- **整果占菠萝陈列面积约70%—80%**，做主推和促销。
- **鲜切占20%—30%**，放在冷柜或试吃台附近，按小份定价，突出“即食”。
- 鲜切采用“当日切、当日清”原则，下午时段可做折扣清货，避免隔夜。
- 整果可搭配“免费代削”服务，既保留整果优势，又满足即食需求，比直接大量上鲜切更稳。

**4. 什么情况下可以加大鲜切比例**
- 门店位于商圈、写字楼、学校附近，即时消费客流强。
- 水果区已有成熟冷柜和专职削切人员。
- 鲜切试销两周后，日售罄率稳定在80%以上。
- 反之，如果鲜切经常剩货、客流以家庭为主，就应压缩鲜切，回到整果为主。

**简单判断标准：** 看门店客群。家庭采购型门店，整果为主；商圈即时型门店，可提高鲜切比例，但仍建议整果打底。鲜切不要盲目铺量，先用小份试销，看售罄率和损耗再调整。
