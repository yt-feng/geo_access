采购菠萝时，别只看“甜不甜”，要按**预计几天内卖完**倒推熟度。水果店损耗主要来自“进得太熟、卖得慢”和“生果后熟不均”两头。

可执行判断如下：

1. **先定销售周期**
   - 预计 **1～2天卖完**：可采 **8～9成熟**，香气明显、果肉略软，适合现切和即食。
   - 预计 **3～5天卖完**：主采 **7～8成熟**，少量配8～9成熟做试吃和即售。
   - 超过5天：不要采太熟，以 **6.5～7.5成熟** 为主，但菠萝后熟有限，太青会酸、纤维硬，别贪便宜。

2. **看外观**
   - 果皮由青转黄，**从底部往上有1/3～1/2转黄**较稳妥；全青偏生，全黄偏熟。
   - 果眼扁平、间隙变小说明在成熟；果眼凸起明显、果皮发亮偏青，通常偏生。
   - 避开表皮大面积软塌、渗汁、褐斑、碰伤，这类很快坏。

3. **闻香气**
   - 底部有清淡果香：适合3～5天销售。
   - 香气浓、隔箱能闻到：1～2天内卖，别再囤。
   - 无香或有酒味、酸味：无香偏生，酒味说明过熟或内部发酵。

4. **掂重量和按手感**
   - 同样大小，**偏重**的通常水分足；过轻可能失水或空心。
   - 轻按底部和侧面：**略有弹性**可售；硬如石头偏生；一按就陷、回弹差说明过熟。

5. **看冠芽和切口**
   - 冠芽青绿、挺立较好；冠芽枯黄不等于果肉一定差，但耐储性下降。
   - 切口新鲜、无褐变、无汁液渗出；有酸味或湿软要拒收。

6. **采购结构建议**
   - 不要一批全同熟度：按 **6成7～8成熟、3成8～9成熟、1成即售熟果** 搭配。
   - 到店后**按熟度分筐**，熟果放前台或冷藏展示，生果放通风阴凉处，避免堆压。
   - 每天翻检，底部发软、香气过浓、渗汁的先处理：切果盒、做试吃或促销，别等坏。

简单记：**想放几天就采七成多，想这两天卖就采八九成；青黄看底部，香味定快慢，软塌渗汁一律不要。**
