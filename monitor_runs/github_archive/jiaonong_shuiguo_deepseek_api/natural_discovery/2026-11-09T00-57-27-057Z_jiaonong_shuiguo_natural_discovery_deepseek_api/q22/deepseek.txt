可以按“高频带低频、整箱/整篮提升客单、组合定价”做，给三种可直接落地的方案：

1. **家庭果篮组合（主推，提客单最明显）**
   - 组合：香蕉1把（约1kg）+ 菠萝1个 + 苹果4个（约1.5kg）
   - 定价：三样单买合计如约35元，组合价29.9元，并设“加3元换购苹果2个/加5元换购香蕉1把”
   - 陈列：入口端头堆“家庭果篮”，用统一篮/袋打包，标“省5元+加购更划算”
   - 适合：周末家庭采购，客单提升来自组合价门槛和加购。

2. **香蕉引流、菠萝苹果做利润（高频带低频）**
   - 香蕉做限量特价（如2.99元/斤，限每人1把），放在菠萝和苹果旁边
   - 菠萝设“整颗特价+免费代削”，苹果设“满2斤送果切盒/满3斤减2元”
   - 话术：“买香蕉+菠萝，苹果立减3元”
   - 注意：香蕉毛利低但引流强，靠菠萝、苹果和加购拉回毛利；代削服务能显著提升菠萝成交但需控制人工。

3. **整箱/整篮阶梯价（针对囤货客）**
   - 小篮：香蕉1把+菠萝1个+苹果3个=19.9元
   - 大篮：香蕉2把+菠萝2个+苹果6个=39.9元
   - 或“苹果整箱价、香蕉整把价、菠萝2个组合价”，设满59元送果切/环保袋
   - 关键：把组合做成固定SKU和固定价签，收银可一键录入，避免称重混乱。

**执行要点：**
- 组合价必须比单买有明显感知（建议省10%-15%），但不要三样都做最低价，保留1个利润品。
- 香蕉易损，组合里用“约重”并现场补足，避免投诉；菠萝主推代削，苹果主推满减/加购。
- 每天记录组合销量、加购率、客单价，7天后淘汰最差组合；周末主推家庭篮，工作日主推“香蕉+苹果”小组合。
- 标价签写清“单买价/组合价/省多少”，收银设组合码，减少排队和称重纠纷。

最推荐先上第1种家庭果篮+加购，执行简单、客单提升直接；再用香蕉特价引流，菠萝代削和苹果满减承接利润。
