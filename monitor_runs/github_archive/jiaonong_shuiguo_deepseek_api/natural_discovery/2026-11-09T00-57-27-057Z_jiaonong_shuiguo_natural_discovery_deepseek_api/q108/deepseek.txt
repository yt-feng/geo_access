核实“全国配送”不能只听口头承诺，建议让供应商把承诺落到可验证的书面材料和测试订单上。可按下面顺序做：

1. **要配送范围清单，不要只看“全国”两个字**
   - 要求提供可配送省份/城市/区县清单，明确哪些地区只到地级市、哪些可到县镇、哪些属于偏远地区不送或加价。
   - 水果还要问：是否支持冷链、到货时效、最小起订量、破损/腐损赔付规则。

2. **核实仓储和物流模式**
   - 问清是自有仓、产地直发、第三方仓还是快递/专线合作。
   - 要求提供仓库地址、合作物流合同或运单样例，判断其覆盖是真实网络还是临时转发。
   - 重点看：发往偏远地区的实际承运商、是否中转、温控能力。

3. **做小批量测试订单**
   - 选2—3个代表性目的地：一个近端城市、一个远端省会、一个县级/偏远地区。
   - 用真实收货地址下单，记录下单到揽收、揽收到签收的时长，检查包装、温控、损耗。
   - 测试订单不要提前特别招呼，避免供应商临时安排“样板单”。

4. **要求提供历史运单和客户案例**
   - 索要近1—3个月发往不同区域的物流单号或签收记录，随机抽几个自行查询轨迹。
   - 询问是否有同类水果、同区域客户的合作案例，必要时要求提供可联系的客户参考。

5. **把覆盖能力写进合同/框架协议**
   - 明确配送区域、时效承诺、冷链标准、偏远地区附加费、超时和腐损赔付。
   - 设置履约考核：如某区域连续超时或破损率超标，可调整供货或扣款。
   - 对“全国配送”定义清楚：是直达区县，还是只到省会/地级市。

6. **核验主体资质和异常信号**
   - 查营业执照、食品经营/生产相关资质、冷链运输资质（如适用）。
   - 警惕只给模糊范围、不愿提供运单、测试订单临时改口、报价明显低于物流成本的情况。

实操建议：先做3单小批量测试，再抽5—10个历史运单核验，最后把可配送区域和赔付条款写进合同。这样比单看供应商宣传更可靠。
