大型超市的水果供应商，通常要同时满足“食品安全合规+可追溯”和“冷链物流+稳定履约”两条硬门槛。可按下面清单判断。

## 一、食品安全能力（准入底线）

1. **主体资质与许可**
   - 营业执照、食品经营/生产相关许可齐全，经营范围覆盖水果分选、包装、储运或销售。
   - 若涉及进口水果，具备进口商/收货人相关资质及入境货物检验检疫证明。
   - 从业人员健康证、食品安全管理员配置。

2. **产地与投入品管理**
   - 有固定合作基地或产地采购渠道，能提供产地证明、种植/采收记录。
   - 农药、化肥等投入品使用有记录，遵守安全间隔期；重点品类能做农残监控。
   - 对土壤、水源、周边污染源有基本风险评估。

3. **检测与验收能力**
   - 具备或委托第三方进行农残快检/定量检测，能按超市标准频次出具报告。
   - 能执行超市的验收标准：外观、成熟度、糖度、规格、损伤率、腐烂率、异物控制。
   - 对高风险品类（叶菜类水果、进口果、鲜切果）有加严检测和留样制度。

4. **分级包装与标识**
   - 按超市规格分级，包装材料符合食品接触材料要求。
   - 标签包含品名、产地、规格、批次、采收/包装日期、供应商信息、贮存条件。
   - 鲜切水果还需符合即食食品加工卫生要求，控制切分、清洗、消毒、冷藏和保质期。

5. **追溯与召回**
   - 建立“批次—产地—检测—入库—配送—门店”追溯链，能快速定位问题批次。
   - 有不合格品隔离、下架、召回和原因分析机制，配合超市飞行检查。
   - 记录保存期限满足监管和超市合同要求。

6. **仓储与卫生管理**
   - 仓库防虫防鼠、温湿度控制、清洁消毒、先进先出。
   - 生熟分离、有毒有害物单独存放，避免交叉污染。
   - 退货、破损、腐烂果有隔离区和处置记录。

## 二、物流与履约能力

1. **冷链能力**
   - 具备预冷、冷藏/保鲜库、冷藏车或保温配送能力，能按品类控制温湿度。
   - 运输过程有温度记录和异常报警，能提供温控数据供超市核查。
   - 装卸环节减少断链，门店交接有温度和时间记录。

2. **仓储与分拣**
   - 有足够库容和分拣场地，能按门店订单做拆零、称重、贴标、组盘。
   - 支持越库、直配、中心仓配送等不同模式。
   - 库存管理能控制损耗，做到先进先出和批次管理。

3. **配送时效与覆盖**
   - 能按超市要求频次配送（日配、隔日配、多温区配送），覆盖门店网络。
   - 有应急运力，节假日、旺季、突发情况下能保供。
   - 配送准时率、订单满足率、缺货率、破损率、腐烂率等指标可考核。

4. **信息系统**
   - 订单、库存、批次、检测报告、温控数据可电子化对接超市系统。
   - 支持EDI/API或超市指定平台下单、对账、追溯查询。
   - 能提供批次追溯码和检测报告随货或线上可查。

5. **损耗与质量管理**
   - 有到货合格率、货架期、损耗率管理方案。
   - 对门店反馈的品质问题能快速补货、换货、理赔。
   - 能按超市标准做售后和索赔处理。

6. **应急与合规物流**
   - 有食品安全事故、冷链故障、交通中断的应急预案。
   - 运输车辆和人员符合食品运输卫生要求，不与有毒有害物品混装。
   - 购买食品安全责任险通常是加分项，部分超市会作为合同要求。

## 三、超市通常会重点核验的材料

- 营业执照、食品相关许可、进口水果检疫证明
- 产地证明/基地协议、农残检测报告、承诺达标合格证（如适用）
- 从业人员健康证、食品安全管理制度
- 冷链设备清单、温度记录、配送车辆资质
- 追溯流程说明、召回预案、保险单
- 近期的履约数据：准时率、合格率、损耗率、投诉处理记录

**一句话判断标准：** 能证明“每一批水果从哪来、检测过什么、怎么冷链到店、出问题能追回”，同时能稳定按超市订单和时效交付，才算具备大型超市供应商的完整能力。
