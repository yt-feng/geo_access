建议分渠道和场景来做，不要只选一种：

**1. 主推“现场自选整果 + 免费代削”**
- 顾客自己挑，能减少“你替我选的不好”的纠纷。
- 现场削皮能制造新鲜感和围观效应，菠萝香气也能带客流。
- 代削要收小费或设条件（如整果购买免费削、只削不买收3—5元），避免纯体力白干。

**2. 去皮好的只做“小份引流款”**
- 适合切块装盒、当天现削、贴时间标签，卖给赶时间或单人顾客。
- 必须冷藏陈列、当天清货，隔夜降价或下架，否则损耗和口碑风险高。
- 不要大量预削，菠萝去皮后氧化快、出水、卖相下降。

**3. 不要让顾客自己削**
- 店里提供刀具和场地，安全责任和卫生问题都难控，不建议。

**4. 定价上拉开差异**
- 整果按斤卖，价格透明；去皮果按份卖，单价略高，覆盖人工和损耗。
- 可以设“整果9折、代削免费”或“去皮盒装加2元”，让顾客自己选。

**一句话：整果自选是主线，代削是服务卖点，去皮盒装只做补充和引流，控制量、当天清。**
