社区超市找每日配送的水果供应商，重点看“稳定性、损耗可控、结算清楚”这三类条件。可以按下面清单筛选：

1. **配送能力**
   - 是否能固定每天配送，几点前到店，临时补货多久能到。
   - 配送车辆、冷库/保温箱是否具备，夏季和雨季是否会影响品质。
   - 配送范围是否覆盖你所在社区，起送量、配送费、退换货怎么算。

2. **货源与品类稳定性**
   - 是否有稳定产地或一级批发渠道，不是临时拼货。
   - 常见刚需水果能否常年稳定供应：苹果、香蕉、橙子、梨、西瓜、葡萄等。
   - 是否支持小批量多品类混配，适合社区超市低库存、高频补货。

3. **品质与验收标准**
   - 是否明确等级、规格、成熟度、净重/毛重、包装方式。
   - 是否允许到店验收，坏果、压伤、缺斤少两如何处理。
   - 是否承诺当日或次日退换，损耗责任怎么划分。

4. **价格与结算**
   - 报价是否含税、含运费、含包装，是否每日随行就市。
   - 是否有价格保护或长期协议价，调价是否提前通知。
   - 账期、押金、起订额、结算方式是否清楚，避免隐性费用。

5. **食品安全与资质**
   - 营业执照、食品经营/食用农产品相关资质是否齐全。
   - 是否有农残检测或产地证明，能否提供批次信息。
   - 包装、运输卫生和冷链管理是否到位。

6. **试配与淘汰机制**
   - 先试配7—14天，固定验收标准，记录到货时间、损耗率、缺货率、退换响应。
   - 建议同时保留1家主供应商+1家备选供应商，避免断供。
   - 关键指标可看：准时到货率、坏果率、缺货率、退换响应时间、综合毛利。

简单说，优先选“能每天送、品类稳、坏果可退、价格透明、资质齐全”的供应商，不要只看单价最低。
