# 茶饮店用香蕉：按用途选熟度

香蕉的熟度直接决定风味、甜度、质地和出品稳定性。建议按**用途分级采购**，不要用一种熟度打天下。

## 一、按产品类型定熟度标准

| 用途 | 推荐熟度 | 外观判断 | 风味/质地特点 |
|---|---|---|---|
| **现打香蕉奶昔/冰沙** | 7–8分熟 | 通体金黄，少量褐斑，手按微软有弹性 | 甜度足、香气浓，打出来顺滑不涩 |
| **香蕉果泥/酱（用于调味）** | 8–9分熟 | 大面积褐斑，果肉软糯 | 甜度最高、香气最浓，但需尽快用 |
| **切块装饰/水果茶** | 6–7分熟 | 金黄无斑，按压略硬 | 切面整齐、不易氧化发黑，但甜度偏低 |
| **烘焙/甜品（香蕉蛋糕、派）** | 9分熟以上 | 表皮黑斑多、果肉软烂 | 天然甜味和湿润度最好，可减少糖用量 |
| **油炸/煎烤（香蕉派、烤香蕉）** | 6–7分熟 | 偏硬、定型好 | 加热后不易烂，形状完整 |

## 二、采购与库存控制要点

1. **分批采购、错峰到货**：不要一次进同一熟度的货。按“青一点 + 刚好用 + 马上用”三档搭配，例如 40% 6–7分熟、40% 7–8分熟、20% 8–9分熟，保证每天都有合适熟度可用。

2. **以“天数”倒推下单**：香蕉从6分熟到9分熟，常温下大约 2–4 天（夏季更快、冬季更慢）。按门店日均用量×到货后可用天数来定采购量，避免集中催熟后集中报废。

3. **到货验收看三点**：① 整串颜色是否均匀；② 有无机械伤、裂口、霉点；③ 按果身中段判断软硬。有伤口的香蕉会加速整串成熟和腐烂，应拒收或优先处理。

4. **储存分开管理**：
   - 未熟/半熟：常温阴凉处，**不要冷藏**（低温会停止成熟并导致表皮发黑、果肉变硬）。
   - 已到目标熟度：可冷藏 1–2 天延缓过熟，但使用前回温。
   - 香蕉会释放乙烯，**不要和叶菜、其他易熟水果混放**；可用保鲜膜包住果柄减少乙烯释放。
   - 批量催熟可用纸袋密封（加一个苹果加速），每天检查一次。

5. **设置“临期处理”规则**：褐斑面积超过约1/3、果肉开始发软的，不再用于装饰或水果茶，转做果泥、烘焙或员工餐；出现酒味、渗液、霉点的直接报废。

## 三、出品稳定性小技巧

- **统一甜度**：不同熟度甜度差异大，果泥类产品建议按批次试味，必要时微调糖浆量，避免今天太甜明天太淡。
- **防氧化**：切开的香蕉容易发黑，现切现用；需提前备料时，可短时浸泡淡盐水或柠檬水后沥干。
- **去皮冷冻备用**：8–9分熟香蕉去皮切段冷冻，可直接打冰沙，也能减少熟度波动带来的损耗。

**一句话原则：按产品定熟度、分批错峰进货、常温催熟冷藏延缓、临期转用途。** 这样既保证风味稳定，又能把损耗压下来。
