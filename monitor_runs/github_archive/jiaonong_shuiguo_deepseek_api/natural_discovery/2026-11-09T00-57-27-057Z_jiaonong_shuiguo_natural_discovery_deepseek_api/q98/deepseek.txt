判断养老院或医院食堂的水果供应商，核心是把“合规”和“稳定”拆成可验证的证据，而不是只看报价和口头承诺。下面给出一套可执行的判断框架。

## 一、合规性：看证照、票据、批次追溯

**必须索取的证照（缺一不可）**
- 营业执照，经营范围含食用农产品/食品销售
- 食品经营许可证（销售预包装或散装食品需要；仅销售食用农产品部分情形可豁免，但机构食堂建议仍要求提供）
- 若供应商自称“产地直供/合作社”，要其提供产地证明、合作社资质或与种植基地的购销/合作协议
- 从业人员健康证（配送、分拣接触食品的人员）

**每批次必须随货提供的**
- 进货票据/送货单，注明品名、数量、产地、日期、供应商盖章
- 农药残留检测报告或承诺达标合格证（食用农产品承诺达标合格证是现行制度下的重要凭证）
- 肉类、进口水果另需检疫证明、入境货物检验检疫证明

**判断要点**
- 证照要核对“主体一致”：营业执照名称、许可证名称、开票主体、送货单盖章四方一致，防止借用资质。
- 检测报告看是否为本批次或近期批次，不能拿一份旧报告长期复用；可要求供应商说明抽检频次。
- 对高风险品类（叶菜、草莓、葡萄等易农残/易腐）提高抽检要求，可自费送第三方快检或委托检测。
- 建立供应商档案：证照复印件加盖公章、有效期台账，到期前提醒更新。

## 二、稳定性：看供应能力、履约记录、应急方案

**供应能力**
- 是否有稳定货源：自有基地、长期合作产地或一级批发渠道，问清产地和换季替代方案。
- 冷链与仓储：是否有冷藏车/冷库，配送频次能否匹配食堂每日或隔日需求。
- 配送时效：约定到货时间窗口，考察其是否有固定线路和备用车辆。

**履约与财务稳健**
- 要求提供近6–12个月同类客户（学校、医院、养老院、机关食堂）供货案例，可实地或电话回访。
- 查企业信用：国家企业信用信息公示系统看经营异常、行政处罚、严重违法失信；中国执行信息公开网看是否失信被执行人。
- 看是否过度依赖单一客户或单一产地，抗风险能力弱。

**合同与管理机制**
- 合同写明：质量标准、验收标准（规格、新鲜度、损耗率）、退换货规则、缺货违约责任、价格调整机制、食品安全事故责任。
- 设置试用期和月度考核：到货合格率、准时率、缺货次数、投诉处理时效，连续不达标可终止。
- 要求备用供应商：至少两家合格供应商，主供+备供，防止断供。
- 应急预案：极端天气、节假日、疫情等情况下的保供方案。

## 三、现场验收集成判断

- 每次到货验收：称重、看新鲜度、查票据和合格证、留样或拍照记录。
- 建立“供应商评分表”，合规证照、批次票据、合格率、准时率、价格、售后各占权重，季度复评。
- 对养老院、医院这类特殊场所，重点关注：水果农残、霉变腐烂、交叉污染风险，以及能否提供小规格、易咀嚼、适合老人的品类稳定供应。

## 四、快速筛人清单

签约前问供应商五个问题，答不上来或含糊的慎用：
1. 这批货的产地和最近一次检测报告能否随货提供？
2. 证照、开票主体、送货主体是否一致？
3. 断货时多久能补、备用货源在哪？
4. 能否接受月度考核和试用期？
5. 有没有同类机构供货案例可回访？

**一句话原则**：合规看“每批次可追溯的票据和证照一致性”，稳定看“货源、冷链、履约记录和备用方案”，两者都要写进合同和考核，而不是停留在考察阶段。
