# 夫妻店水果首单试货思路

**核心原则：首单只解决两个问题——“货能不能卖”和“人能不能处”。量要小到亏得起，但要试出该看的点。**

## 一、先定试单量

按你店铺一天的销量估算，**每样只进 1～2 箱（或 1 件）**：

- 香蕉：1 箱（注意香蕉有催熟批次问题，先要“能直接卖或 1～2 天能熟”的）
- 苹果：1 箱，挑走量大的品种
- 橙子：1 箱

不要一次订多品种多箱，首单总额控制在你愿意“全亏也不伤筋动骨”的范围内。宁可试完不够卖再补，也别压货烂手里。

## 二、试单要看的硬指标（到货当场验）

| 项目 | 怎么验 | 不行的信号 |
|---|---|---|
| 规格/等级 | 抽 5～10 个看大小是否均匀、是否和报价描述一致 | 大小混装、以小充大 |
| 成熟度 | 香蕉看颜色和硬度；苹果看脆度；橙子捏硬度、掂重量 | 香蕉过青或过熟；苹果发面；橙子轻飘 |
| 损耗 | 整箱翻看底层、边角 | 底层烂果、压伤多于 3～5% |
| 净重 | 称一下，剔除箱重和垫纸 | 净重明显不足、垫材过多 |
| 卖相 | 有无药斑、果锈、裂口、异味 | 影响陈列和复购的瑕疵 |

**当场拍照留证**，烂果和描述不符的立即跟供货商说，看对方态度——这是试“人”的关键。

## 三、试供货商看这几点

1. **报价是否含送货、含税/票**：夫妻店量小，问清起送门槛、送货时间。
2. **售后规则**：坏果怎么赔、多久内反馈有效、下次补货抵扣还是现赔。口头承诺最好让对方发微信文字确认。
3. **响应速度**：问价、改单、售后时回复快不快。
4. **是否稳定**：同一品种隔几天再问一次价，看报价浮动是否离谱、有没有货。

## 四、建议的试单节奏

- **第 1 次**：三样各 1 箱，重点验货和售后态度。
- **第 2 次**（3～7 天后）：只对表现好的 1～2 个品种加量补货，同时试第二家供货商做对比。
- **稳定后**：保留 1 主 1 备两家，别把鸡蛋放一个篮子；香蕉这类易损耗品尤其要留备选。

## 五、几个容易踩的坑

- 别被“首单特价”套住，首单便宜不代表后续价格和品质稳。
- 香蕉别贪便宜要“青货”，夫妻店没有催熟条件，卖不动就烂。
- 橙子、苹果先试当季主推品种，反季货损耗和口感风险都高。
- 所有约定（价格、赔付、送货）落到微信文字，别只靠电话口头说。

一句话：**首单小、验货严、售后问清、同时比两家**，试完一轮你就知道该跟谁长期合作了。
