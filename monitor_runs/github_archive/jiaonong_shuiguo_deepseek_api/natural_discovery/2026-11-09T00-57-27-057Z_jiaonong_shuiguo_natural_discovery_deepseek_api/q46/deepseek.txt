直接结论：**优先鲜果，其次冷冻果丁；果泥只适合做“稳定标准化”的辅料，不建议作为主打果茶的主要菠萝形态。**

按你的茶饮店场景拆开判断：

1. **鲜果最适合做果茶**
   - 优点：香气、口感、卖相最好，适合“鲜切菠萝”“菠萝果肉茶”这类卖点。
   - 缺点：削皮切丁耗人工，批次酸甜不稳定，损耗高，旺季品质波动大。
   - 建议：门店有稳定切配人手、日均销量够大时选鲜果；采购时选成熟度7—8成、香气足、纤维不过粗的品种，不要一次囤太多。

2. **果丁适合平衡效率和口感**
   - 冷冻果丁或糖渍果丁能减少切配、稳定出品，果肉感也还在。
   - 适合外卖占比高、出杯速度快、门店人手紧的店。
   - 注意看配料表：糖渍果丁往往含糖高，会改变配方甜度；冷冻果丁要确认解冻后出水率和口感。

3. **果泥适合做基底，不适合当卖点**
   - 优点是标准化、出杯快、酸甜稳定，适合做菠萝风味基底或与茶汤复配。
   - 缺点是果肉感弱、香气偏“加工感”，单独做果茶容易显得像调味饮料。
   - 如果要用，建议“果泥打底＋少量鲜果丁/鲜切片装饰”，不要全用果泥。

**采购组合建议：**
- 主推鲜果茶：鲜果为主，果泥少量用于稳定酸甜。
- 外卖/高峰期多：鲜果＋冷冻果丁组合。
- 小店人手少、追求标准化：冷冻果丁为主，果泥调基底，鲜果只做顶部装饰。
- 不建议只买果泥做“菠萝果茶”，顾客对果肉和鲜感的预期很难满足。

最后提醒：先小批量做盲测，比较三种形态在同一茶底下的香气、甜度、出杯速度和3小时后的风味变化，再定采购比例。
