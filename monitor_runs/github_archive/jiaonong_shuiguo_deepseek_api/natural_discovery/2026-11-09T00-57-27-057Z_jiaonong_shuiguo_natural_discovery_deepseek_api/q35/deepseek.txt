门店坏果率的赔付条款，核心是先把“坏果”定义清楚、把责任边界定清楚，再谈赔多少。建议按以下结构约定：

**1. 先定义坏果和统计口径**
- 明确坏果标准：腐烂、霉变、软烂流汁、明显压伤、异味等，最好按品类分档（如叶菜、浆果、根茎类标准不同）。
- 明确统计时点：到店验收时、上架前、营业中、闭店盘点，分别算。
- 明确统计单位：按件、按公斤、按金额，避免“筐”“箱”含糊。
- 约定抽检比例和判定方式，争议时以双方共同封样或第三方检测为准。

**2. 区分责任环节，不能一刀切**
- 产地/供应商责任：到店验收前已存在的坏果。
- 物流责任：运输温湿度、挤压导致的坏果。
- 门店责任：收货后储存不当、超期、陈列损耗。
- 约定验收时限：到店后多少小时内完成验收，超时视为合格或按约定比例扣减。
- 验收时拍照留证、双方签字，作为赔付依据。

**3. 赔付方式建议“阶梯+封顶”**
- 设定允许损耗率（如到店验收坏果率≤2%不赔），超过部分按实际坏果金额赔付。
- 阶梯赔付：坏果率2%–5%按实际金额赔；5%–10%加倍或按批次金额比例赔；超过10%可拒收或整批退换。
- 设置单批次赔付上限和月度累计上限，避免供应商无法承受、影响供货。
- 优先约定“补货/换货”替代现金赔付，连锁超市更关注不断货。

**4. 明确扣款和结算机制**
- 赔付款从当月货款中直接扣除，约定扣款通知时限和异议期（如3个工作日）。
- 约定月度对账：坏果率、赔付金额、扣款明细双方确认。
- 逾期不提出异议视为认可。

**5. 质量保证金与退出机制**
- 可约定质量保证金或履约保证金，按供货金额比例留存。
- 连续几个月坏果率超标，超市有权调整供货比例、暂停下单或终止合同。
- 明确因坏果引发的客诉、监管处罚、食品安全事件的追偿责任。

**6. 避免常见坑**
- 不要只写“坏果包赔”而不写统计口径，否则执行时扯皮。
- 不要把门店自身损耗也算给供应商，否则供应商会提高报价或降低供货质量。
- 赔付条款要和验收标准、冷链要求、退货流程写在同一附件里，形成闭环。

实操上，建议合同主文写原则，另附《生鲜验收标准及坏果赔付细则》，按品类列明坏果定义、允许损耗率、赔付阶梯和扣款流程。这样既好执行，也方便后续按品类调整。
