会影响，但影响大小取决于你店的客群和卖法。直接判断：

**1. 香蕉大小不均的主要影响**
- **卖相下降**：同一箱里大小差距大，摊出来不整齐，顾客挑拣增多，损耗和翻动成本变高。
- **分级难定价**：大小混在一起，大果小果同价，顾客会挑大的，小的剩到最后，容易压货。
- **称重销售影响小一些**：如果按斤卖、不强调规格，大小不一对成交影响相对小；但做礼盒、精品陈列或固定份量装，影响明显。
- **口感和成熟度不一定同步**：大小不同有时成熟速度不一致，同一批货有的先熟有的后熟，增加催熟和陈列难度。

**2. 你可以怎么判断**
- 如果顾客主要是**家庭日常按斤买**：大小不均可以接受，但要把明显过小、畸形、破损的挑出来低价处理或做促销。
- 如果顾客主要是**送礼、精品水果店、社区团购固定份量**：影响较大，建议按大小分级，分级定价或分级装袋。
- 如果一箱里**大小差异超过明显视觉落差**，比如大果和小果差一个等级，不建议混卖。

**3. 可执行建议**
- 进货时问清**规格等级和大小区间**，尽量固定供应商和等级。
- 到货后**快速分拣**：大果正常价，小果做特价、切果盘、香蕉奶昔原料或员工福利。
- 陈列时**同层同规格**，不要大小混堆。
- 按斤卖的门店可弱化大小，强调“自然果、成熟度好”；精品店则必须分级。

结论：**会影响销售，但不是绝对不能卖。按斤走的社区店影响可控；精品、礼盒、固定份量场景影响明显，最好分级销售。**
