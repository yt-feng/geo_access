超市采购水果时，供应商通常需要提供以下材料，具体以超市验收制度、属地监管要求和合同约定为准：

1. **供货资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视供应环节而定）
- 若为进口水果，需提供海关报关单、入境货物检验检疫证明

2. **进货凭证类**
- 进货发票、送货单、销售单或采购合同
- 产地证明、种植基地证明或合作社供货证明（部分超市要求）
- 食用农产品承诺达标合格证（很多地区已推行，适合果蔬类）

3. **检测报告类**
- 农药残留检测报告：供应商自检报告或第三方检测报告
- 批次检测报告：应与送货批次对应，注意报告日期、样品名称、检测项目、检测结论
- 若超市有快检要求，供应商需配合提供样品或快检合格记录
- 对高风险品种或进口水果，可能需要重点检测项目报告

4. **标签与包装信息**
- 品名、产地、生产日期/采摘日期、供应商名称及联系方式
- 预包装水果还需符合预包装食品标签要求

**实务建议：**
- 采购前在合同中明确“随货提供材料清单”，避免到货后补件。
- 每批货查验“合格证/检测报告+进货票据+感官验收”，留存复印件或电子档案。
- 检测报告要核对批次和日期，不能用一份报告长期覆盖所有批次。
- 各地对食用农产品合格证、快检要求不同，建议向当地市场监管部门或超市品控确认。

核心是：**资质证明、进货票据、批次合格证明/检测报告、产地或承诺达标合格证**，进口水果再加**报关和检验检疫证明**。
