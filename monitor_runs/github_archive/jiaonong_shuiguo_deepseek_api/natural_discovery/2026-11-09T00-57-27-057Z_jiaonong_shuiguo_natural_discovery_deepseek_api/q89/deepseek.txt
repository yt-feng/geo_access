更合适的是：**阶梯价为主，返利为辅**，而不是二选一。

原因很直接：团购客户价格敏感，核心诉求是“先看到便宜”，而不是“以后可能拿回来”。所以：

## 什么时候用阶梯价
阶梯价适合作为主机制，尤其满足以下情况：

- 客户采购频次高、单次量大、需求相对稳定
- 客户希望下单时就看到明确单价
- 产品标准化程度高，SKU不复杂
- 你需要快速成交、降低比价阻力
- 客户群体多，规则要简单透明

**做法建议：**
- 按累计采购量或单次采购量设3档即可，不要设太多
- 档差要有感知，但保留底价空间
- 明确阶梯周期，比如月度、季度或单次订单
- 标清“含税/不含税、运费、账期是否影响阶梯价”

## 什么时候用返利
返利更适合作为补充机制，适合以下情况：

- 客户承诺年度/季度总量，但单次下单不稳定
- 你不希望一开始把底价打穿
- 需要绑定客户持续采购，而不是一次性压价
- 客户有账期、售后、退换货等风险，需要留利润缓冲
- 你想奖励回款、复购、品类拓展，而不只是销量

**做法建议：**
- 返利比例不要过高，作为阶梯价后的二次激励
- 返利条件写清楚：按实际回款、扣除退货后计算
- 返利兑现方式可选：抵扣下批货款、返现、货品赠送
- 设置封顶和结算周期，避免年底集中挤兑利润

## 更稳妥的组合
可以采用：

1. **首单/单次大单：阶梯价**，让客户立刻感受到价格优势
2. **季度/年度累计：返利**，绑定持续采购
3. **返利只按回款计算**，防止只压货不付款
4. **底价不公开**，阶梯价留2%—5%的返利空间

## 判断标准
如果客户主要比较“这一单单价”，优先阶梯价；  
如果客户愿意承诺“全年采购量”，用“阶梯价+年度返利”；  
如果客户只追求最低价、采购不稳定，不建议给高返利，直接用严格阶梯价或一单一议。

一句话：**价格敏感型团购客户，先用阶梯价降低成交门槛；返利用来锁量、锁回款，不要拿来代替明面报价。**
