对便利店卖菠萝切块来说，这三项不是“选一个”，而是优先级不同：

**1. 保质期最关键**
菠萝切块属于鲜切水果，高风险点是微生物滋生和氧化变质。便利店要重点管控：
- 切配后冷藏保存，明确标注制作时间和丢弃时间；
- 到店后剩余售卖时间要短，通常按小时管理，不宜跨天；
- 出现出水、发酸、发黏、颜色暗沉就下架。

**2. 包装是保质期的保障手段**
包装不是越复杂越好，但要能起到作用：
- 用食品级密封盒/保鲜膜，减少氧化和交叉污染；
- 冷藏陈列，避免常温长时间摆放；
- 包装上要有制作日期时间、保质截止时间，便于店员判断。

**3. 配送频次影响新鲜度，但优先级低于前两项**
如果门店自己切配，配送频次主要影响原料菠萝的新鲜度；如果是中央厨房配送切块，配送频次直接决定货架期余量。建议：
- 高频少量配送，避免门店积压；
- 到店验收看温度、包装完整性和制作时间；
- 配送频次应服从“到店后还能卖多久”，而不是单纯追求多送。

**可执行判断：**
- 先定死**保质期和丢弃规则**（最重要）；
- 再确保**冷藏包装和标签**到位；
- 最后用**配送频次**去匹配销量，做到少量多次、先进先出。

一句话：**保质期是底线，包装是保障，配送频次是优化；便利店最该先管的是保质期和冷藏标签。**
