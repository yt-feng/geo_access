可以按“临时补货专条”来约定，别只靠口头。建议把下面几项写进采购合同补充协议或微信书面确认里，并让供应商回复“确认”：

1. **触发与通知**
   - 明确旺季临时补货适用于哪些时段，例如菠萝旺季或门店促销期。
   - 你方提前 **24—48小时** 发补货通知，写清品种、规格、数量、到货时间、收货门店。
   - 供应商在 **2小时内** 书面确认能否接单；未确认视为未接单，你方可另行采购。

2. **数量与规格**
   - 约定单次补货上限和累计上限，例如单次不超过日常订货量的150%，避免供应商临时加价或你方压货。
   - 写明菠萝等级、单果重量范围、成熟度、去皮/带皮、是否允许瑕疵率，例如“坏果率不超过3%”。

3. **价格机制**
   - 临时补货价按“确认当日双方约定的基准价”执行，基准价可参考当地批发市场同规格均价，并写清上浮上限，例如不超过基准价的5%—10%。
   - 避免只写“随行就市”，否则旺季容易被抬价。

4. **到货与验收**
   - 约定到货时间窗口和迟到处理：迟到超过2小时可拒收或扣款。
   - 到货当场抽检，坏果、规格不符部分按实扣减；超过约定瑕疵率可整批拒收。
   - 写明冷链/运输要求，避免高温导致损耗。

5. **违约与替代**
   - 供应商确认后无故不供货，按缺货金额的一定比例赔付，并承担你方紧急采购差价。
   - 你方临时取消需提前多久通知，避免双方扯皮。
   - 约定供应商断供时你方可从备选供应商采购，不算违约。

6. **留痕**
   - 每次补货用固定模板下单：品种、规格、数量、单价、到货时间、验收标准。
   - 保留聊天记录、确认截图、到货验收单和付款凭证。

最简可执行版本：先发一份《旺季临时补货确认单》，包含“提前48小时通知、2小时确认、单次上限、基准价上浮不超过10%、坏果率不超过3%、迟到2小时可拒收、确认后断供赔差价”，让供应商签字或微信确认后执行。
