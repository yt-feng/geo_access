多数情况下，**中央厨房统一收货更好**，但要看品类、门店密度和配送能力。可以按下面的决策逻辑判断。

## 优先中央厨房统一收货的情况
适合：门店多、采购量大、水果用于标准化产品（果切、饮品、甜品装饰等）、有冷链和分拨能力。

优点：
1. **采购议价更强**：总部集中下单，供应商更愿意给稳定价格和账期。
2. **品控标准统一**：到中央厨房做验收、分级、催熟、清洗、切配，门店只接收半成品或标准果，减少门店验收能力参差。
3. **食品安全可追溯**：批次、农残检测、温控记录集中在中央厨房，责任链更清楚。
4. **减少门店损耗和操作**：门店不承担挑果、催熟、切配，降低人为损耗。
5. **供应商管理简单**：一对多变成一对少，对账和索赔更集中。

代价：
- 需要中央厨房有水果验收、冷藏、催熟、分拣能力；
- 多一段分拨配送，增加物流成本和机械伤风险；
- 门店临时补货不灵活。

## 更适合门店分开收货的情况
适合：门店少且分散、水果以整果现售为主、门店有较强验收能力、配送半径大且冷链弱。

优点：
- 到店新鲜度可能更好，减少中转；
- 门店可按当天客流灵活补货；
- 初期不建中央厨房水果分拨能力，投入低。

风险：
- 各店验收标准不一致，容易“好店收好货、差店收差货”；
- 供应商多、对账和索赔分散；
- 门店随意收货可能带来食品安全和损耗漏洞；
- 采购量分散，议价能力弱。

## 建议的折中方案
不必二选一，按品类分层：

- **标准化程度高、用量大的水果**：中央厨房统一收货、统一验收、分拣后配送门店。例如饮品基果、果切原料、甜品装饰水果。
- **易损、短保、门店现售型水果**：可由供应商直送门店，但必须执行总部统一验收标准和抽检。
- **紧急补货**：允许门店在总部授权供应商清单内小量补货，设置金额和频次上限。

## 判断标准
用四个问题快速判断：
1. 单店日均水果采购额是否足够大？太小则集中收货物流不经济。
2. 水果是否要进入切配、催熟、清洗等加工环节？要则中央厨房更合适。
3. 门店是否有稳定冷链和会验收的人？没有则集中收货更稳。
4. 配送半径和频次能否支撑？如果中央厨房到店超过合理冷链半径，可考虑区域分仓而不是门店直收。

**结论：** 连锁餐饮只要门店达到一定规模、水果用于标准化出品，优先“中央厨房统一收货+统一品控+分拨配送”；门店分散或水果以整果现售为主时，采用“总部定标准和供应商，门店直收+强抽检”的混合模式。
