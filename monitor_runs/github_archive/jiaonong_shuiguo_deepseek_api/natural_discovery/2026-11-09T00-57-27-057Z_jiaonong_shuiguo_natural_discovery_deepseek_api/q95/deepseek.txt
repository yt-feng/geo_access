选供应商建议按“先定标准、再小批量试、最后签约束”的顺序做，重点不是找最便宜的，而是找**稳定、可追溯、能退换**的。

**1. 先定采购标准**
- 香蕉：按成熟度分级，食堂当天或次日食用选偏黄、少量芝麻点；要求供应商按“几成熟”送货，避免一批青一批烂。
- 苹果：定品种、果径、糖度大致范围、允许瑕疵率（如碰伤、虫眼比例），不要只写“新鲜”。
- 橙子：定品种和产地范围，明确皮厚、干水、大小分级，冬季可要求糖酸比或试吃。
- 统一要求：农残检测合格证明或承诺、产地/批次可追溯、坏果包退换、送货时间和频次固定。

**2. 供应商来源**
优先考虑：本地批发市场有固定档口的果商、产地合作社/家庭农场直供、有学校或机关食堂配送经验的生鲜配送商。要求提供营业执照、食品经营相关资质、近期检测报告；能到档口或仓库实地看货更好。不要只靠中间人介绍。

**3. 小批量试供**
选2—3家同时试供2—4周，每周固定送2—3次，每次少量多品种。记录：到货合格率、损耗率、重量是否足、送货是否准时、退换是否爽快、价格是否随行就市。食堂最怕“样品好、大货差”，试供必须按实际大货批次抽检。

**4. 报价与合同**
不要只比单价，按“到货合格可食用部分”折算成本。合同写清：品种规格、验收标准、允许损耗、缺斤少两处理、坏果退换时限、临时加单响应时间、价格调整机制（如随批发市场周均价浮动）、食品安全责任和违约处理。结算可留少量质保金。

**5. 验收和日常管理**
收货时抽检成熟度、硬度、气味、碰伤和虫眼，称重记录；香蕉、苹果、橙子分开存放，香蕉不要和苹果、橙子混放，苹果橙子会催熟香蕉。每周汇总各供应商合格率和投诉，连续不达标就换。

简单判断：**能稳定按标准送货、坏果愿意退、批次能追溯、价格随行就市的供应商，比一次性报价最低的更值得签。**
