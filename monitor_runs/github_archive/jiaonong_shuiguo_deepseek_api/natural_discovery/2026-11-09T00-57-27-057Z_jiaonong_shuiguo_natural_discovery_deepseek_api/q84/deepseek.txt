家庭团购水果礼盒，建议优先考虑“耐放、好吃、分量不浪费、老人小孩都能吃”。组合上可以这样定：

**推荐组合：苹果 + 橙子 + 香蕉为主，菠萝少量点缀**

1. **比例建议**
   - 苹果 40%：耐放、百搭，家庭接受度高
   - 橙子 30%：耐放、酸甜适中，颜色也好看
   - 香蕉 20%：软糯适合老人小孩，但不耐放，别放太多
   - 菠萝 10%：有新鲜感，但处理麻烦、占体积，适合少量搭配

2. **按家庭人数配**
   - 3口之家：苹果6个、橙子6个、香蕉1把、菠萝1个
   - 4—5口之家：苹果8个、橙子8个、香蕉1把、菠萝1个
   - 6口以上：苹果10个、橙子10个、香蕉2把、菠萝1—2个

3. **团购礼盒更稳妥的做法**
   - 主推“苹果+橙子+香蕉”基础款，成本低、损耗小、家庭接受度高
   - 做“加菠萝升级款”，但菠萝单独放，避免压坏其他水果
   - 香蕉选偏生一点的，家庭收到后能放几天
   - 苹果、橙子选耐运输的规格，礼盒不要装太满，留透气空间

4. **不建议的组合方式**
   - 香蕉和菠萝放太多：香蕉易压伤、菠萝占空间且处理麻烦
   - 四种水果平均分配：看起来丰富，但家庭实际吃不完，尤其小家庭
   - 礼盒塞太满：水果互相挤压，团购运输后容易坏

**结论：**
家庭团购最稳妥的是 **苹果+橙子+香蕉为主，菠萝少量升级**。如果只做一个爆款，建议做 **苹果6—8个、橙子6—8个、香蕉1把** 的基础家庭盒；想提升礼盒感，再加1个菠萝，但不要四种都平均放。
