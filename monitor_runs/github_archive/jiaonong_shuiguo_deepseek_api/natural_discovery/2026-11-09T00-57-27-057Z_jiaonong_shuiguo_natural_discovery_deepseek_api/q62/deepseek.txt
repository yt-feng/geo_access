# 判断香蕉熟度与坏果风险的实操方法

## 一、先看“色卡”：按表皮颜色定熟度

香蕉行业通行用**颜色编号1–7**（1全绿、7全黄带褐斑甚至发黑）：

| 编号 | 外观 | 状态 | 适合 |
|---|---|---|---|
| 1–2 | 全绿/绿带微黄 | 生，硬 | 长途运输、催熟后批发 |
| 3 | 绿黄各半 | 七分熟，硬 | 入库待催熟 |
| 4 | 黄多于绿、两端仍绿 | 八分熟 | 短途批发、2–4天内出货 |
| 5 | 全黄、无绿 | 正好 | 零售高峰，1–2天内卖完 |
| 6 | 全黄带少量褐点 | 完熟 | 当天出货，做促销/加工 |
| 7 | 大面积褐斑、发黑 | 过熟 | 只能低价处理，坏果率高 |

**批发拿货关键**：你要的是“到店后还能卖几天”的货，一般拿 **3–4号** 最稳；天气热、运输远就偏低号（2–3），近途快销可拿4–5。

## 二、判断坏果风险的6个检查点

1. **摸果指（单根香蕉）硬度**：整把均匀偏硬=好；局部软塌、有“水感”=内部已烂。
2. **看果柄和切口**：果柄青绿、切口新鲜=刚采/刚分梳；果柄发黑干枯=放久了。
3. **看棱角**：香蕉有5–6条棱，棱角分明=生；棱角圆润、果身饱满=熟；果身出现凹陷软斑=开始坏。
4. **查褐斑形态**：零星小褐点（芝麻斑）是正常完熟；**成片、边缘发暗、按下去软**的是炭疽病/腐烂前兆，会传染整把。
5. **看梳口和轴心**：整梳连接处发黑、渗汁、有酒味/酸味=已开始腐坏，且容易串烂。
6. **抽检内部**：随机掰开几根看果心，中心发褐、发黑或有异味，说明这批货“外好内坏”，风险高。

## 三、快速风险分级（拿货时用）

- **低风险**：颜色3–4、整体硬、果柄青、无软斑、无异味 → 可正常拿。
- **中风险**：颜色5、有零星褐点但果身仍硬、个别果柄发黑 → 压价拿，要求当天/次日出。
- **高风险（建议拒收或大幅压价）**：成片软斑、渗汁、酒味酸味、整梳轴心发黑、掰开果心变色 → 坏果会快速扩散，别贪便宜。

## 四、两个容易忽略的点

- **温度决定腐坏速度**：香蕉13–15℃最耐放，低于10℃会冻伤发黑，高于25℃熟得飞快。问清运输和仓储温度，比只看外观更准。
- **整批抽检要“分层”**：别只看箱口，翻到箱底和中层抽几把——底层受压、湿度大，往往先坏；箱内如果有催熟药剂残留或水汽凝结，风险更高。

**一句话结论**：拿货优先选 **3–4号色、整体硬、果柄青、无成片软斑无异味** 的货；看到成片褐斑、渗汁、酒味、果心变色，直接判高风险，压价或拒收。
