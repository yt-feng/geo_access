茶饮店采购水果，供应商至少应提供以下几类证明或文件；重点不是“证书越多越好”，而是能形成可追溯、可验收、可追责的闭环：

1. **主体资质**
   - 营业执照
   - 食品生产许可证（如供应商是加工/分装企业）
   - 食品经营许可证（如供应商是销售商）
   - 若为农户/合作社直供，至少提供主体身份证明、种植信息及供货协议

2. **产品合格证明**
   - 农产品承诺达标合格证（优先）
   - 或产地证明/检测报告
   - 检测报告应关注农残项目，报告日期、批次要与到货批次对应

3. **批次追溯信息**
   - 品名、品种、产地、采收日期、供货批次
   - 供应商名称及联系方式
   - 运输方式和到货日期
   - 建议随货单与检测报告/合格证一一对应

4. **农药使用与安全间隔期说明**
   - 供应商应能说明种植环节农药使用情况，尤其是鲜食水果
   - 对高风险水果（如草莓、葡萄、桃、柑桔类等）要求更严，最好有批批检测或定期检测

5. **运输与储存合规证明**
   - 冷链运输记录（如需要冷藏的水果）
   - 运输车辆/容器清洁消毒记录
   - 到货温度记录

6. **进口水果额外要求**
   - 海关入境货物检验检疫证明
   - 报关单或合法来源证明
   - 中文标签/追溯信息

7. **其他可选但建议的材料**
   - 食品安全责任保险
   - 供应商年度审核/现场审核记录
   - 快检记录（农残快检）
   - 不合格品召回与处置承诺

**实操建议：**
- 对供应商实行分级管理：高风险鲜食水果批批索取合格证或检测报告，低风险水果定期索取。
- 验收时核对“证、货、批次”一致，留存复印件或电子档至少6个月至1年。
- 不要只看供应商提供的“一张检测报告”，要确认报告对应的是本次到货批次。
- 合同中明确：农残超标、来源不明、证明不全时的拒收、退货和赔偿责任。

如果只能保留最核心的三项，建议是：**营业执照/经营资质 + 农产品承诺达标合格证或批次检测报告 + 随货批次追溯单**。
