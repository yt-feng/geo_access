先定一个关键原则：**按“你打算什么时候吃”来选香蕉的成熟度，而不是只看外观。** 香蕉从青到熟变化很快，尤其夏天。

**到店挑选时看这几点：**

1. **看颜色**
   - 当天或第二天吃：选**整体黄、带少量小褐点**的。
   - 2～3天内吃：选**黄中带一点青肩**（两端略青）的。
   - 4～5天后吃：选**整体偏青、只有轻微转黄**的。
   - 不要选大面积青绿且硬邦邦的，除非你愿意等一周左右。

2. **摸硬度**
   - 轻捏有弹性但不软塌：适合近期吃。
   - 捏起来很硬：偏生。
   - 表皮发软、有凹陷：过熟或已碰伤。

3. **看果柄和棱角**
   - 果柄青绿、切口新鲜：较新。
   - 香蕉棱角明显：偏生；棱角不明显、圆润：偏熟。

4. **避开损伤**
   - 有裂口、明显黑斑连片、渗汁、局部软烂的不要。
   - 少量芝麻大小的褐点是正常成熟标志，不是坏。

**按采购量选：**
- 只买几根、两三天吃完：直接买**黄带小褐点**的。
- 买一整把吃一周：**混着买**，一部分黄、一部分黄中带青，或把青的放阴凉处、黄的先吃。
- 想放久一点：买**青肩明显**的，回家后不要放冰箱冷藏，在室温阴凉处催熟；想加速可和苹果装一个纸袋。

**一句话判断：** 当天吃选“黄+小褐点”，两三天吃选“黄带青肩”，一周吃选“偏青硬实”。到店别只看一把，**翻到底部看有没有压伤和软烂**。
