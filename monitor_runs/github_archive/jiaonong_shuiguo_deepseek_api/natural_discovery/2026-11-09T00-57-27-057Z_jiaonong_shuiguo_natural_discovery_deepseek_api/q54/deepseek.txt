优先看成熟度，价格排后面。原因很直接：香蕉成熟度决定蛋糕的香气、甜度、含水量和成品稳定性，采购失误很难靠配方补救。

**采购判断标准：**
- **做香蕉蛋糕/磅蛋糕/马芬**：选**表皮金黄、带少量褐斑、果肉软但未流汁**的香蕉，香气足、甜度高、易压泥。  
- **需要整形或切块装饰**：选**七到八成熟、表皮偏黄、果肉稍硬**的，避免太软塌。  
- **不建议**：全青香蕉香气弱、涩味重；大面积发黑、渗汁、有酒味或霉点的，风味和出品风险高。

**价格怎么处理：**
- 成熟度达标时，再比价和看批次稳定性。
- 如果价格明显低于市场价，先确认是不是过熟、碰伤、冷链断过或临期处理货。
- 可以和供应商约定“到货成熟度”，比如“黄皮带少量斑点、无流汁”，而不是只写“香蕉”。

**可执行建议：**
1. 按用途分两档采购：**熟香蕉做泥**、**稍硬香蕉做装饰/切片**。
2. 每次到货抽检：看斑点比例、按压软硬、闻有无酒味。
3. 熟香蕉到店后尽快去皮压泥或冷冻保存，避免继续过熟。
4. 如果长期用量大，固定供应商并锁定成熟度标准，比单纯追低价更稳。

结论：**先按成熟度筛合格批次，再在合格批次里比价格。** 价格是第二道筛选，不是第一道。
