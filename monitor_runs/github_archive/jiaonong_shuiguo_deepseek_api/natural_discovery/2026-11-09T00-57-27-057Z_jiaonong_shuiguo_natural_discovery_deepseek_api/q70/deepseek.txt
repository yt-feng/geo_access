合同里建议把“坏果责任”写成可验收、可计价、可追偿的条款，核心是四件事：**验收标准、验收时点、责任归属、赔付方式**。可以按下面结构写：

**1. 明确“坏果”的客观标准**
不要只写“坏果”“损耗”，要定义清楚，例如：
- 腐烂、霉变、流汁、异味；
- 严重压伤、裂果、冻伤、日灼；
- 单果缺陷面积超过X%；
- 不符合约定等级、规格、成熟度的比例。

建议约定：**坏果率=不合格果重量÷该批到货总重量×100%**，并区分“自然损耗”和“质量不合格”。

**2. 约定验收时点和验收方式**
- 货到后**X小时内**在双方指定地点共同验收；
- 以**到场开箱、抽样、称重、拍照/视频**为准；
- 抽样比例、抽样方法写清楚，例如每车随机抽X箱，发现异常加倍抽检；
- 双方签字确认验收单；一方不到场，可约定由另一方委托第三方检验，结果对双方有约束力。

**3. 分档约定责任**
建议按坏果率分档：
- 坏果率≤X%：视为合理损耗，买方承担；
- X%＜坏果率≤Y%：超出部分按重量扣款，或按该批单价×超出重量扣减；
- 坏果率＞Y%：买方有权拒收整批，或要求换货、退货，运费和装卸费由卖方承担；
- 因卖方包装、采摘、预冷、运输安排不当造成的集中腐烂，不受合理损耗档限制，由卖方全责。

**4. 明确赔付计算和时限**
写清楚：
- 扣款金额=不合格果重量×约定单价×系数；
- 或“按不合格果数量1:1补货”；
- 卖方应在验收后X日内补货、退款或支付赔款；
- 逾期按日万分之X支付违约金；
- 因坏果导致的二次分拣费、冷藏费、退运费由责任方承担。

**5. 保留追偿和证据条款**
- 验收单、照片、视频、第三方检测报告作为索赔依据；
- 买方应在发现坏果后X小时内通知卖方，逾期视为验收合格，但隐蔽瑕疵除外；
- 卖方对运输途中因包装、预冷不足导致的损耗承担责任；承运人责任可另约定，但不影响买方向卖方索赔。

**6. 写清除外情形**
避免扯皮，可约定以下不由卖方承担：买方收货后储存不当、擅自转售延误、不可抗力、双方确认的合理自然损耗。

**最简可落地写法：**
> 货到后24小时内双方共同验收，按每车随机抽取10箱开箱检验。坏果率≤3%为合理损耗，由买方承担；超过3%的部分，按不合格果重量×该批单价扣减货款；坏果率超过10%的，买方有权拒收或要求卖方48小时内换货，退运费及装卸费由卖方承担。验收照片、视频及双方签字的验收单作为赔付依据。

这样写的好处是：坏果有定义、验收有时限、责任有分档、赔款有公式，批发商不会只拿到一句“质量问题协商解决”。
