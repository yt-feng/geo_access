建议按“先要合规底稿、再要批次证据、最后约定责任”的顺序向供应商索取资料，这样既能应对抽检，也便于后续追责。

**一、先要供应商主体与合规底稿（一次性建档）**
1. 营业执照（经营范围含水果种植/销售/批发）。
2. 若供应商是生产企业/合作社：食品生产许可证或食用农产品相关备案信息；合作社可要其登记证明。
3. 供货商与上游产地/基地的采购合同或授权供货证明，确认货源可追溯。
4. 供应商的质量承诺书/食品安全承诺书，明确农残符合GB 2763。

**二、每个批次要“批次证据”**
1. 该批次水果的**产地证明或进货凭证**（产地、品种、采收/发货日期、数量）。
2. **农残检测报告**：优先要带CMA/CNAS标识的第三方检测报告；至少要有供应商自检报告，并核对报告中的样品名称、批次、检测项目是否覆盖该品种常见农残，报告日期是否对应本批次。
3. 若供应商无法提供批次检测报告，可要求其提供**承诺书+抽检记录**，并约定超市有权自行送检、费用及责任承担。
4. 随货单据（送货单/销售单）上注明品种、产地、批次号、数量、日期，便于与检测报告对应。

**三、合同/协议里约定**
1. 农残超标时的退换货、召回、赔偿及检测费用承担。
2. 供应商须在抽检或监管检查时配合提供资料。
3. 明确“批次”定义和留样要求，避免报告与货物对不上。

**四、超市自己可做的动作**
1. 收货时按批次留样并记录，必要时自费快检或送检。
2. 建立供应商档案和批次台账，抽检时能快速调取“来源+检测+去向”。
3. 对高风险品种（如叶菜类、草莓、豇豆等）提高抽检频次。

核心判断标准：**能证明“这批货从哪来、检测过什么、出了问题谁负责”**。如果供应商只能给一张模糊的复印件或报告与批次对不上，应视为资料不完整。
