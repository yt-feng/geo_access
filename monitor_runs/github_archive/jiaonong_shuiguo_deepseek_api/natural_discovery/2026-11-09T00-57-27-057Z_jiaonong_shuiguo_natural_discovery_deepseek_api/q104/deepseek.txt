到货品质不一致时，验收和售后的核心是：**先按标准抽样验、现场分级记录、能拒收的当场拒收/降级，不能当场解决的留证并在合同/订单约定时限内发起售后**。下面给你一套可直接执行的流程。

## 一、验收前先准备“可判断的标准”
1. **明确验收标准**：在采购订单/合同里写清品种、规格（单果重/果径）、等级、成熟度、色泽、允许缺陷比例、糖度（如需要）、包装方式、到货时限。
2. **约定抽样规则**：例如每批次按到货件数抽 5%–10%，不足 10 件全检；每件上中下三层抽样，避免只抽表层。
3. **约定“品质不一致”的处理规则**：如不合格比例≤5%按合格；5%–15%扣款/降级；＞15%可拒收或退货；腐烂、异味、严重压伤单独计。
4. **准备工具**：电子秤、糖度计（如需要）、卷尺/卡尺、拍照设备、验收单、封样样品。

## 二、到货现场验收怎么做
### 1. 先验外包装和冷链
- 检查包装是否破损、受潮、挤压、异味。
- 冷藏/冷链水果测到货温度并记录；温度异常先拍照留证。

### 2. 分层随机抽样
- 不要只验最上面一层。
- 每件抽上、中、下，记录抽样件数、抽样数量。

### 3. 按“可量化指标”分级记录
现场把货分成三类并分别称重/计数：
- **合格品**：符合约定规格和等级。
- **可降级品**：轻微缺陷但不影响食用，如小果、轻微碰伤、色泽差。
- **不合格品**：腐烂、霉变、异味、严重压伤、规格严重不符。

记录每类数量和比例，不要只写“品质差”。

### 4. 当场拍照/视频留证
至少拍：
- 整批到货全景、包装标签、批次号；
- 抽样过程；
- 不合格品特写；
- 称重/计数画面；
- 到货温度（如适用）。

### 5. 现场给出验收结论
根据合同规则直接判断：
- **合格收货**；
- **让步接收/降级扣款**；
- **部分拒收**；
- **整批拒收/退货**。

验收单上写清：到货数量、抽样数量、合格/降级/不合格数量及比例、处理意见、双方签字。**不要让送货人员只签字不写处理意见。**

## 三、品质不一致时的处理顺序
1. **能当场分级的当场分级**：合格部分收，不合格部分拒收或降级，避免整批扯皮。
2. **不能当场判断的**：封存争议样品，双方拍照签字，约定 24–48 小时内复检。
3. **腐烂/变质风险高的**：优先隔离，避免污染合格品；必要时冷藏保存并尽快处理。
4. **补货/换货**：要求供应商在约定时限内补足合格品，补货到货仍按同一标准验收。
5. **扣款/退货**：按合同约定的不合格比例对应扣款、降级价或退货退款。

## 四、售后怎么发起才有依据
售后不要只说“品质不好”，要提交一套证据包：
- 采购订单/合同中的品质条款；
- 验收单（含抽样比例、分级数量）；
- 照片/视频；
- 称重记录；
- 到货温度记录（如适用）；
- 双方签字或聊天记录确认。

售后诉求写清楚：**补货、换货、降级扣款、退货退款、运费/损耗承担**中的哪一种，以及时限。

## 五、建议写进合同/订单的关键条款
- 验收标准、抽样比例、合格判定规则；
- 不合格比例对应的扣款/降级/拒收规则；
- 售后响应时限（如 24 小时内响应、48 小时内补换货）；
- 腐烂变质和冷链异常的責任归属；
- 补货仍不合格的处理方式；
- 验收单和照片作为结算依据。

## 六、简单可执行的验收口诀
**先看包装和温度，分层随机抽；合格降级不合格，分别计数称重；拍照签字写结论，超比例就拒收/扣款；售后带证据，补换退扣写清楚。**
