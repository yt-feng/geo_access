# 水果店遇到坏果，和供应商怎么结算或赔付

先看合同/口头约定，再看行业惯例。核心原则：**按约定办事，没约定就按"到货验收+证据+协商"的流程走**，不要自己先扣款再通知，容易激化矛盾。

## 一、先确认责任发生在哪个环节

| 环节 | 通常谁担责 |
|---|---|
| 装车前就烂（产地问题） | 供应商 |
| 运输途中闷坏/压坏 | 看谁安排物流：供应商包送到店，一般供应商担；你自提或指定物流，一般你担 |
| 到店后存放/销售期自然损耗 | 你自己担（水果有合理损耗率） |
| 货不对板（等级、品种、产地不符） | 供应商 |

## 二、正常操作流程（可执行）

1. **到货当场验收**：开箱抽查，拍照/录像（含箱号、批次、日期），当场记录坏果比例，让司机或送货人签字确认。这一步最关键，事后扯皮多半是因为没当场留证。
2. **及时书面通知**：发现问题当天（最好几小时内）微信/电话+文字通知供应商，说明批次、数量、坏果比例、照片，提出诉求。
3. **协商方案**，常见几种：
   - **补货**：供应商下次送货补同等数量（最常用）。
   - **折价结算**：按坏果比例扣减本批货款，比如坏 10% 就按 90% 结算。
   - **退货退款**：整批严重损坏，退回并退货款，运费谁承担按约定。
   - **换货+少量补偿**：影响销售档期时，可要求补货外加一点补偿。
4. **形成书面确认**：微信文字确认"本批扣 XX 元/补 XX 斤"，双方回复"确认"即可，不必正式合同。

## 三、金额怎么算才合理

- **按比例扣款**：坏果斤数 × 进货单价，或整批按坏果率打折。
- **合理损耗要自己承担**：水果行业普遍有 2%–5% 的自然损耗，这部分通常不算供应商责任，别把正常损耗也算进去，否则供应商不认。
- **别把销售损失全转嫁**：一般只赔货值，除非合同明确约定档期损失，否则要求"坏一箱赔十箱"很难成立。

## 四、几个避坑提醒

- **别先斩后奏**：直接扣款不通知，供应商可能断供或起诉，得不偿失。
- **长期合作看总量**：小额坏果可以攒着月底一起谈，比每批都吵更省事。
- **写进采购约定**：下次合作前把"坏果率超过 X% 怎么处理、验收签字、通知时限"写清楚，哪怕微信里说定，后面省很多事。
- **保留证据链**：照片、视频、聊天记录、送货单签字，协商不成时可作为依据。

**一句话总结**：当场验货留证 → 当天书面通知 → 按坏果比例协商补货或折价 → 微信文字确认，合理损耗自己认。
