社区超市水果损耗高，核心矛盾是“进货量拍脑袋 + 卖不动才发现”。要控制新鲜度和库存，建议按“少进、快转、早处理、用数据”四件事做。

**1. 进货：少批量、多频次，按销量定**
- 每天固定时段补货，不要一次进一周量。叶菜类、草莓、蓝莓、香蕉这类高损耗品，按1-2天销量进；苹果、橙子、梨可3-5天。
- 用近7天同品类日均销量做基准：首单进“日均销量×1.5天”左右，卖得好第二天追加。
- 设安全库存上限：库存超过“3天预估销量”就不再进，宁可当天缺一点，也别压货。
- 新品先小量试销，连续3天卖不动就停进。

**2. 陈列与鲜度管理：先进先出 + 勤挑拣**
- 到货立刻分级：好果上主陈列，轻微瑕疵放“特价区”，烂果当天清出，避免传染。
- 严格执行先进先出，旧货放前面，新货放后面。
- 高损耗品小份陈列、勤补货，别一次堆满；叶菜可喷雾保鲜，香蕉、苹果等注意乙烯影响，分开摆放。
- 每天早、中、晚三次挑拣，发现软伤、出水、霉点立即下架处理。

**3. 库存预警：设“天数”而不是“件数”**
- 给每个品类算“可售天数 = 当前库存 ÷ 近3天日均销量”。
- 超过3天：停止进货、安排促销；超过5天：当天必须出清。
- 每天闭店前看一次，第二天进货单据此调整。社区店品类不多，用表格或进销存软件就能做。

**4. 早处理：把损耗变成销售**
- 临期/品相下降的水果设固定“折扣时段”，比如下午5点后8折、闭店前6折，明示“当日鲜果”。
- 切果盒、果切、果汁是消化轻微瑕疵果的好办法，但要注意操作卫生和当天售完。
- 做预订/团购：社区群提前一天收单，按单进货，减少盲进。
- 和周边餐饮、果汁店谈尾货处理，但必须保证食品安全。

**5. 简单可执行的日流程**
- 早上：查库存可售天数，定当天进货量；到货分级上架。
- 中午：挑拣一次，瑕疵果转特价区。
- 下午5点后：启动折扣出清。
- 闭店：记录销量、损耗、剩余库存，调整次日进货。

**关键判断标准：** 如果某品类连续一周损耗率超过10%，说明进货量偏大或陈列期太长，先把日进货量降20%-30%，再观察销量。社区店不要追求“货卖堆山”，新鲜、周转快比陈列满更重要。
