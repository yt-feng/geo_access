会。起订量越高，通常损耗风险越大，尤其是香蕉和菠萝都属于呼吸跃变型、成熟变化快的商品，对到货成熟度、销售周期、仓储条件和周转速度都很敏感。

判断风险主要看这几个点：

1. **销售周期 vs 起订量**
   - 起订量对应的货量，如果能在**1-2个销售周期内卖完**，风险可控。
   - 如果起订量超过你正常**3-5天销量**，香蕉容易出现集中转黄、催熟不均、压伤；菠萝容易出现黑心、腐烂、果眼发黑，损耗会明显上升。

2. **香蕉的典型风险**
   - 到货成熟度高时，起订量一大就容易“来不及卖就黄熟”。
   - 堆压、温度波动、乙烯积聚会导致批量催熟。
   - 建议：按**预计销量×1.2-1.5倍**订货；高起订量时要求分批到货或分仓催熟。

3. **菠萝的典型风险**
   - 菠萝耐储性比香蕉略好，但起订量高会带来**堆压伤、冷链断链后黑心、尾部腐烂**。
   - 如果走常温销售，起订量超过**5-7天销量**风险偏高；走冷链可适当放宽，但也要看周转。
   - 建议：控制单批到货量，优先“小批量、多频次”，检查果心温度和到货成熟度。

4. **起订量高时怎么降风险**
   - 和供应商谈**分批交货、分规格交货**，不要一次压满。
   - 要求按**销售节奏分成熟度到货**：先到偏生、后到适熟。
   - 设置**到货验收标准**：香蕉看色卡和硬度，菠萝看果心温度、黑心率和尾部状态。
   - 建立**安全库存线**：超过安全库存的起订量，宁可换供应商或拼单，也不要硬吃。
   - 做**促销/加工预案**：香蕉可转烘焙、果切；菠萝可转果切、果汁，降低临期损耗。

结论：**起订量太高会显著增加损耗风险，尤其是香蕉；菠萝相对耐放，但高起订量叠加常温周转也会有黑心和腐烂风险。** 建议把起订量控制在正常销量的1.2-1.5倍以内，并优先谈分批到货和成熟度分级。
