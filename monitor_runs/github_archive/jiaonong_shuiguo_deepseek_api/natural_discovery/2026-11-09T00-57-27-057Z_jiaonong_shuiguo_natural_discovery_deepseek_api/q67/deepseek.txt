可以按“先问规则，再问证据，最后问违约处理”的顺序谈，重点别只听口头承诺。

**一、区域保护要问清**
1. 代理区域是省、市、区县还是按渠道划分？边界以行政区还是门店清单为准？
2. 区域内独家还是非独家？有没有例外渠道，如电商、商超总部、团购、直播、特通渠道？
3. 品牌方直营、其他大客户、线上订单落到我区域，算不算冲区域？业绩归谁？
4. 区域保护期限多长？续约条件是什么？完不成任务是否自动取消独家？
5. 保护是只保护“签约主体”，还是保护区域内所有下游客户？跨区客户主动找我采购怎么处理？

**二、串货要问清定义和证据**
1. 什么行为算串货？跨区销售、线上低价销售、下游客户外流、异地发货，分别怎么认定？
2. 用箱码、批次码、物流码还是经销商系统追踪？我能否查到货物流向证据？
3. 发现串货后，谁举证？品牌方处理时限多久？我能否要求书面调查结论？
4. 线上平台销售是否允许？若允许，价格、区域、店铺授权怎么管？若不允许，品牌方如何管控其他店铺？
5. 下游客户自己跨区拿货，责任算经销商还是客户？我如何避免被连带处罚？

**三、违约和处罚要写成条款**
1. 品牌方违反区域保护，怎么赔？是补偿差价、扣减任务、返还保证金，还是解除代理？
2. 我被认定串货，处罚标准是什么？首次警告、二次罚款、三次解约？罚款上限多少？
3. 罚款是否从返利、保证金里扣？扣款前是否给申辩和复核机会？
4. 解约后库存怎么处理？按什么价格退货？临期、破损谁承担？
5. 争议解决地在哪里？能否约定先协商、再仲裁或诉讼？

**四、签约前要拿到的书面材料**
- 代理合同及附件中的区域图、渠道清单、价格表、任务量、返利政策；
- 串货认定标准和处罚细则；
- 品牌方现有线上店铺清单及授权经销商名单；
- 箱码/追溯系统说明和查询权限；
- 近一年该区域已有代理商的授权情况，避免“一区多代”。

**五、建议的提问话术**
“请把区域保护范围、例外渠道、串货认定标准、举证方式、处罚上限、品牌方违约补偿写进合同附件。若品牌方直营或线上订单进入我区域，请明确业绩归属和补偿方式。涉及串货处罚，请给书面证据和申辩期。”

最关键一句：**不要只问“保不保护”，要问“保护范围、例外、证据、违约赔偿”四件事，并全部落到合同附件。**
