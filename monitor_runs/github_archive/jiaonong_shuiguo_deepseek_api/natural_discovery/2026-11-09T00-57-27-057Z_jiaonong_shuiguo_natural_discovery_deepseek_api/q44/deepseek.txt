先明确：售后响应能力不能只看对方口头承诺，要拆成可验证的机制和历史记录来判断。对商超采购菠萝、香蕉这类生鲜，重点看“到货质量问题多久能处理、损耗怎么赔、缺货怎么补”。

**一、签合同前要对方提供的硬证据**
1. **售后响应条款写进合同**：明确响应时限（如电话/微信30分钟内回复、2小时内给处理方案）、处理时限（如质量问题24小时内换货或折价）、责任划分（到货验收标准、运输损耗归属）。
2. **书面售后流程**：谁对接、什么时段在线、升级路径（业务员→主管→负责人），不能只有一个销售微信。
3. **历史服务记录**：近3—6个月同类商超客户的售后工单数量、平均处理时长、退换货/折价记录。可要求提供脱敏的售后台账或客户证明。
4. **赔付和补货机制**：菠萝黑心、香蕉催熟不均或压伤，按什么标准折价/退换；旺季缺货多久内补到，是否有替代方案。

**二、实地和试单验证**
1. **试单2—3周**：故意安排一次小批量到货验收，记录报损后对方首次回复时间、给出方案时间、实际补货/赔付到账时间。
2. **非工作时间测试**：在晚间或周末发一次售后问题，看是否有人响应，生鲜商超经常需要这种时段支持。
3. **看仓库和冷链**：菠萝、香蕉对温控和催熟要求高，有稳定冷链和催熟能力的供应商，售后问题本身会更少。
4. **问现有客户**：找同区域商超同行了解该供应商处理退换货是否爽快、是否推诿。

**三、判断标准（可直接用）**
- 合格：合同有明确响应时限和赔付标准；试单期间售后首次响应≤30分钟、方案≤2小时、实际处理≤24小时；有可查的售后台账。
- 警惕：只承诺“有问题找我”但不给时限；售后只靠一个销售个人；历史记录拿不出；赔付要反复扯皮；旺季缺货无补货计划。

**四、采购操作建议**
把“售后响应”设为供应商准入评分项，权重不低于价格和账期；首批合作保留一定质保金或账期约束；每次售后记录时间节点，作为后续续约依据。菠萝和香蕉损耗率高，建议合同里单独约定到货验收标准和损耗赔付比例，避免事后争议。
