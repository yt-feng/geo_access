社区团购旺季锁库存，核心不是“提前打个招呼”，而是用**可执行的采购承诺+分阶段锁量+违约条款**把供应商的货真正占住。建议按下面几步做：

1. **先做销量预测，别凭感觉报量**
   - 拉过去2周同品类日销、近3个旺季同期数据、当前预售/接龙数据。
   - 按“保守/基准/乐观”三档预测，锁库存只锁**基准量的70%-80%**，剩余用短周期补货，避免压货。
   - 水果按SKU分开：易损耗、短保的少锁；耐储、爆款多锁。

2. **和供应商签“框架+分阶段锁量”协议**
   - 框架约定旺季总意向量和价格区间。
   - 分周/分日下确认单，比如提前7天确认下周每日量，提前3天微调±10%-15%。
   - 明确锁量部分供应商不得转卖、不得随意涨价；你方按约定提货。

3. **用定金/预付款换优先权**
   - 对核心爆款付10%-30%定金锁货，尾款按提货结算。
   - 定金对应具体批次、具体到货日，不要只写“意向金”。
   - 要求供应商提供备货凭证或产地/冷库库存照片，定期核验。

4. **写清违约和替代方案**
   - 供应商缺货：按缺口金额比例赔付，或约定优先补发、价格补偿。
   - 你方不提货：定金不退或按比例扣减，给供应商确定性。
   - 约定质量标准和拒收规则：糖度、规格、损耗率、到货温度，避免旺季以次充好。

5. **多供应商备份，别把鸡蛋放一个篮子**
   - 每个爆款至少2家供应商：主供锁70%，备供锁30%或保留优先补货权。
   - 主供出问题，备供能在24-48小时内补位。

6. **用“以销定采+预售”降低自身风险**
   - 旺季提前开预售/接龙，用真实订单驱动锁量。
   - 对锁量大的SKU设置起送/成团门槛，减少无效库存。
   - 到货前1-2天再确认最终量，减少损耗。

7. **物流和验收提前锁**
   - 旺季车紧张，提前锁定冷链车和到货时段。
   - 约定到货窗口、卸货责任、温控要求，避免“有货没车”或“到了没人收”。

一句话执行清单：**做三档预测→锁基准量70%-80%→付定金签分周确认单→写缺货赔付→每爆款配第二供应商→预售对冲库存风险。** 这样既能把货占住，又不会因为过度锁量把自己压死。
