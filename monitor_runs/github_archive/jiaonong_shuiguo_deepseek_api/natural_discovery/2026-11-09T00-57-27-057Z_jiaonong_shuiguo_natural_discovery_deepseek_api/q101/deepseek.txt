和水果供应商谈酒店早餐合作，重点不是只谈价格，而是把“稳定供应”拆成可验收的条款。建议按下面几块准备和谈判：

**1. 先明确自己的需求数据**
谈之前先整理：每天/每周大概用量、早餐时段、需要的品类（如苹果、香蕉、橙子、西瓜、圣女果等）、规格要求（大小、成熟度、甜度、是否切果）、送货时间、验收标准、临时加量提前多久通知。没有这些数据，供应商报价和承诺都会虚。

**2. 供应稳定性要写进合同**
- 要求供应商说明货源基地/批发市场、替代方案和缺货时的处理流程。
- 约定缺货提前通知时间，以及替代品类、补货时限。
- 对旺季、节假日、极端天气要有预案，不能只靠口头“没问题”。
- 可要求备选供应商或第二供货渠道，避免单一来源风险。

**3. 品质和验收标准要可执行**
- 按品类写清等级、单果重量/大小、成熟度、外观（无腐烂、无虫害、无明显碰伤）、农残检测要求。
- 明确验收方式：到货抽检比例、不合格怎么退换、损耗谁承担。
- 切果类要额外约定加工环境、包装、冷链和微生物指标。
- 早餐水果通常要求到货即可用或短时间可熟化，成熟度标准要提前试单确认。

**4. 价格与结算机制**
- 不要只谈一个固定单价，水果价格波动大，可约定报价周期（如每周/每半月）、调价依据和提前通知期。
- 明确是否含税、含运费、含卸货、含损耗。
- 结算周期、对账方式、发票类型提前谈清。
- 警惕明显低于市场价的报价，往往会在品质、重量或后续调价上找回来。

**5. 配送与食品安全**
- 送货时间要匹配早餐备餐，约定迟到、漏送的处理和违约责任。
- 运输车辆、周转筐、冷链要求写清楚，避免交叉污染。
- 要求提供营业执照、食品经营/生产相关资质、检测报告，并约定定期更新。
- 明确食安事故责任和赔偿机制。

**6. 试供和考核**
- 先做2—4周试供，按品类记录到货合格率、缺货次数、迟到次数、损耗率。
- 约定月度/季度考核，连续不达标可调整份额或终止合作。
- 保留一定比例的第二供应商，不要把所有品类压给一家。

**7. 合同关键条款**
建议重点看：供货品类和规格、价格及调价机制、送货时限、验收与退换、缺货违约责任、食品安全责任、结算方式、合同期限、终止条件、保密与廉洁条款。所有口头承诺都落到书面或订单确认中。

简单说：**用数据定需求，用试供验能力，用合同管波动，用备选保稳定。** 谈判时把“稳定”拆成缺货率、到货准时率、合格率、替代方案和违约责任，比单纯压价更有用。
