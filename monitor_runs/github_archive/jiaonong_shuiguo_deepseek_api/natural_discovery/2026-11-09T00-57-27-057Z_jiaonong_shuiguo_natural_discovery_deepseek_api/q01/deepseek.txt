判断水果供应商靠不靠谱，别只看报价和嘴上的承诺，建议用下面这套“可验证”的方法，长期合作尤其要看稳定性。

**1. 先小批量试供，至少跑3次**
- 每次订少量香蕉和菠萝，重点看：到货时间是否稳定、缺斤少两、损耗率、成熟度是否一致。
- 香蕉看青度是否统一、有没有催熟过度；菠萝看大小分级、黑心病/烂心、叶冠新鲜度。
- 连续3次都稳定，才谈长期价和账期。一次好不算数。

**2. 到货验收要量化，别凭感觉**
- 每批抽检称重，记录实际净重和标称差。
- 记录坏果率、压伤率、成熟度不合格比例。
- 香蕉和菠萝分开定验收标准，比如香蕉青度、菠萝糖度/黑心比例。标准写进供货单，不合格怎么赔提前说清。

**3. 看他的货源和周转能力**
- 问清楚香蕉、菠萝分别从哪一级市场或产地拿货，是否有稳定档口。
- 观察他给你的货是不是“拼货”：同一批里等级混杂、大小不一，说明分拣能力弱。
- 旺季缺货时能不能补上，比平时报价更能说明实力。可以故意在节前问一次紧急补货。

**4. 查账期和售后态度**
- 靠谱供应商敢接受“少量试供+明确赔付”，不靠谱的往往只谈低价、催你大批量打款。
- 出现坏果时看处理速度：是痛快补货/扣款，还是推给运输、天气。
- 长期合作建议月结或分批结，不要一次性大额预付。

**5. 侧面验证**
- 问同行或周边水果店他的口碑，重点问“缺货时靠不靠得住”“售后扯不扯皮”。
- 看他是否有固定仓库/档口、能否随时去看货。只能电话联系、不让看货的要多留心。

**6. 长期合作的硬指标**
- 连续供货稳定、损耗在你能接受的范围内、售后不扯皮、旺季能优先给你货。
- 价格不是唯一标准：香蕉菠萝都是易损耗品，到货质量差1成，可能把低价优势全吃掉。

简单说：**先小单试3次，验收量化，售后看态度，旺季看补货，账期别冒进。** 这几条都过了，再谈长期。
