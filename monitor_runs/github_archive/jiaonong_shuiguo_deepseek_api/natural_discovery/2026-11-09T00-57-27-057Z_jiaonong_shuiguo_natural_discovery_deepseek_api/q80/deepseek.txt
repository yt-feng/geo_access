# 能提供，但要分层看，别默认“全都有”

**结论：大多数正规水果供应商能提供基础图片和卖点，但质量参差，且很难直接拿来当详情页成品用。**

## 供应商通常能给什么

| 素材类型 | 常见程度 | 说明 |
|---|---|---|
| 产地实拍图 | 高 | 果园、采摘、装箱场景，多为手机随手拍 |
| 产品图 | 中高 | 有摆拍但光线、背景、规格不统一 |
| 卖点文案 | 中 | 多为“甜、脆、多汁、产地直发”等通用词 |
| 规格/糖度/品种参数 | 高 | 这是供应商最愿意也最能给准的 |
| 检测报告/资质 | 中 | 大供应商有，小档口常缺 |
| 精修/白底/视频 | 低 | 基本要自己补 |

## 实操建议

1. **询价时就列素材清单**：把“白底图、切开图、果园视频、糖度检测、包装图、规格表”逐项写进沟通，让对方勾选能提供哪些，比笼统问“有没有图”有效得多。
2. **优先要“不可替代”的素材**：产地实拍、采摘视频、检测报告、品种规格——这些你拍不出来，最有价值。通用产品图反而可以自己补拍。
3. **卖点别直接抄**：供应商文案同质化严重且常夸大（“爆甜”“入口即化”），要结合自己的品控数据改写，避免售后纠纷。
4. **大供应商 vs 产地档口**：一级批发商/品牌供应商素材更规范但套路化；产地合作社实拍更真实但质量差，适合做“溯源感”内容。
5. **合同里约定**：图片授权范围（能否商用、能否二次修改）要写清楚，避免盗图风险。

## 一句话判断

**基础图和参数大概率有，精修成品和差异化卖点基本得自己做。** 把供应商当“原料提供方”而非“素材外包方”，预期就对了。
