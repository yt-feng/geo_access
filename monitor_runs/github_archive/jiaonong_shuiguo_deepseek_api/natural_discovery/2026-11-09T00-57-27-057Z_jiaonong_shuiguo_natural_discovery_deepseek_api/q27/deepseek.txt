判断苹果、橙子到店规格是否适合，核心是：**按门店客群和售卖方式定规格带，再用抽样测量+目测分级验收**，不要只看供应商报的“75果/80果”。

**1. 先定门店适配规格**
- 苹果：社区店/水果店常卖 **70–85mm** 中果，商超礼盒可要 **80–90mm** 大果；散卖不建议大量低于65mm，易被认为小气。
- 橙子：脐橙/冰糖橙常用 **65–80mm**，太大皮厚、太小剥皮麻烦；榨汁店可偏大，礼盒可偏大且均匀。
- 关键不是“越大越好”，而是**同一批大小均匀、无畸形、可整齐陈列**。

**2. 到货抽样测量**
- 每批随机抽 **3–5箱**，每箱上中下抽 **10–20个**，用卡尺或分级板量横径。
- 记录：最大、最小、平均值、超范围比例。建议**80%以上落在目标规格带**才适合主推；超范围超20%要求降级或调价。
- 看**大小极差**：苹果同批横径差尽量≤10mm，橙子≤8–10mm；极差大不适合堆头统一陈列。

**3. 目测和手感判断**
- 苹果：看果形端正、无明显大小混装；同箱果径差一眼能看出就不合格。
- 橙子：看圆整度、皮厚感、大小一致；过小易酸、过大可能皮厚汁少，需试吃验证。
- 称重核对：随机称10个算平均单果重，与箱标规格、净重是否一致，防“大小混装压秤”。

**4. 结合门店销售方式判断**
- **散卖堆头**：要大小均匀、颜色一致，规格带窄，方便顾客抓取。
- **预包装/称重盒**：可接受略小但必须同盒一致，单盒个数固定。
- **礼盒**：优先大果且均匀，瑕疵容忍度低。
- **促销引流**：可收偏小果，但需明确标价和用途，避免拉低门店形象。

**5. 验收动作**
- 到货即抽检，拍照留样，记录规格分布。
- 不达标就**分级销售**：达标果正价，偏小果做特价/榨汁，偏大果做礼盒或单卖。
- 连续2–3批规格不稳的供应商，要求整改或换源。

一句话：**先定门店目标规格带，再抽检验“均匀度+达标率+净重”，最后按售卖场景分级处理。**
