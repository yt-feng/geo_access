批发档口退货纠纷，八成不是货本身坏了，而是**收货当场没把责任划清**。建议把验货做成固定动作，别靠记忆和口头。

**1. 收货前先定规则**
- 在订单、送货单或微信里提前写清：验货时限（如当场验或到货2小时内）、哪些情况可退换、哪些属人为/二次销售不退。
- 让下游客户也知道你的验货规则，别等出事才解释。

**2. 到货先验外包装再签收**
- 看外箱有无破损、水渍、挤压、封条二次粘贴。
- 外箱明显破损的，**先拍照再开箱**，能当场拒收就拒收，或让物流写异常签收。
- 别先签“完好”再开箱，签收后责任很难倒推。

**3. 开箱全程录像**
- 手机固定拍：外箱六面、面单、封口、开箱过程、箱内填充、货品整体。
- 录像要连续，别只拍结果。这是纠纷时最硬的证据。

**4. 按品类做抽检/全检**
- 服装鞋帽：对款号、颜色、尺码、数量；查污渍、破洞、线头、色差、异味、吊牌。
- 箱包配饰：查五金、拉链、走线、划痕、配件数量。
- 易碎/小商品：按比例抽检，重点看破损和混款。
- 每批至少抽到能覆盖不同款/不同箱，别只翻最上面一层。

**5. 异常当场留证并标注**
- 发现少件、错款、破损、脏污，立即拍照/录像，保留原包装和填充物。
- 在送货单上写明异常数量、款号、问题，让送货人签字确认；对方不签就录像记录。
- 当天在微信/系统里发给上游，别拖到卖完才说。

**6. 入库前分级**
- 把货分成“可正常销售 / 待处理异常 / 退回上游”三类，异常货单独放、贴标签，避免混入正常库存后说不清。
- 退货回来的货也要当场验，防止二次销售纠纷。

**7. 留好对账闭环**
- 每批货保留：订单截图、送货单、验货录像/照片、异常沟通记录、处理结果。
- 月底和上游对一次异常清单，能换的换、能扣的扣，别累积。

核心就一句：**先验后签、全程留证、异常当场写清、退货再验一次。** 做到这几步，大部分“说不清是谁的责任”的退货纠纷就能压下去。
