香蕉配送的核心矛盾是：**它还在呼吸、还在后熟，而且怕压、怕冷、怕乙烯积聚**。控制压坏和变黑要同时做“物理防护＋温湿度与气体管理＋成熟度分级＋配送时效约束”，单靠加厚包装解决不了变黑。

**1. 先按成熟度分级，不要一种香蕉发全国**
- 配送用蕉建议在 **7～8 成熟** 采收或入库，到消费者手中正好可食；全熟蕉只做同城即时配。
- 入库按成熟度分色卡/硬度分拣，同一箱内成熟度一致，避免“一箱里有的已熟、有的还青”，后熟不齐导致局部过熟发黑。
- 对配送蕉做乙烯处理要谨慎：需要集中催熟的走催熟房，催熟后尽快配送，不要在常温仓库久放。

**2. 温控：避开冷害，不是越冷越好**
- 香蕉对低温敏感，**低于约 12～13℃容易冷害**，果皮变黑、果肉发硬。普通冷藏车 0～4℃ 不适合直接拉香蕉。
- 配送环节建议 **13～15℃** 短途运输；同城即时配可用保温箱＋冰袋间接降温，冰袋不要直接贴果，避免局部冻伤。
- 远程干线尽量用可控温车辆，装车前预冷车厢，避免暴晒和发动机热源。

**3. 包装：防压＋防摩擦＋透气**
- 用**带透气孔的硬质纸箱或塑料周转箱**，不要用密封袋长时间闷装；密封会导致乙烯和水分积聚，加速变黑。
- 箱内单果套**薄珍珠棉网套或纸套**，重点保护果指弯曲处和果柄；果柄是机械伤和病菌入口。
- 层间加瓦楞纸隔板，箱内留少量缓冲但不要塞太满，避免运输中互相挤压。
- 整箱堆码限高，重物不压香蕉箱；装车时香蕉箱放上层，避免被其他货压。
- 如果做“一串蕉”直发，用**悬挂式或果梳固定托**减少果指间摩擦，比散装更稳。

**4. 气体与湿度管理**
- 香蕉对乙烯敏感，配送箱内可放**乙烯吸附包**，但不要和保鲜剂混用导致异味。
- 湿度控制在 **85%～90%** 左右，过干失水皱皮，过湿易霉；纸箱受潮会塌，注意防雨防冷凝水。
- 长途运输可考虑气调，但生鲜电商小批量配送更现实的是：**缩短在途时间＋透气包装＋乙烯吸附**。

**5. 配送时效和路由**
- 同城/近场：**当日达或次日达**，高温季节尽量避开中午装车，选择早晚配送。
- 跨城：优先走可控温干线，到前置仓后再短驳；不要反复装卸，装卸次数越多压伤越多。
- 订单端设置**配送范围和时间承诺**，超过 48 小时的区域不建议卖全熟香蕉。

**6. 到货验收和售后兜底**
- 出库前抽检：果皮无大面积机械伤、果柄无霉、硬度一致。
- 给用户明确“香蕉到货偏青可放 1～2 天再吃”的提示，降低“看起来不黄”的投诉。
- 建立按成熟度定价和售后标准：轻微表皮黑点不赔，果肉软烂/大面积压伤赔，避免把正常后熟当质量问题。

**最优先做的三件事**：按成熟度分开发货、把运输温度控制在 13～15℃、用透气硬箱＋单果护套＋限高堆码。这三项做到，压坏和变黑会明显下降。
