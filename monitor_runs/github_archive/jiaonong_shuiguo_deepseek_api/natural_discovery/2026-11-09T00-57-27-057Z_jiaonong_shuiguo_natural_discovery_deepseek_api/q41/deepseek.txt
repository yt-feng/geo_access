判断香蕉催熟能力是否稳定，采购端别只看“黄不黄”，要抓“到货状态一致性 + 催熟响应可预测性 + 批次波动”。可执行判断如下：

1. **固定催熟窗口做小批试催**
   - 每批抽同一梳/同一箱的香蕉，记录到货硬度、颜色（用色卡7级或1–7号色阶）、果指粗细、棱角明显度。
   - 在相同温度、湿度、乙烯浓度/催熟剂用量下催熟，记录“开始转黄时间、到达销售黄（如4–5号色）时间、均匀度、青果比例、软烂比例”。
   - 连续3–5批波动小，才算稳定；只看单批成功不算。

2. **看到货成熟度是否整齐**
   - 同一箱内色差超过1个色阶、硬度差异明显，说明采收/分级不稳，催熟后容易花皮、青黄不匀。
   - 重点看果指中段和果柄端成熟度是否接近；果柄端长期偏青，催熟响应常不稳定。

3. **看“青硬果比例”和“伤果比例”**
   - 每箱随机抽20–30根，记录青硬果占比。青硬果比例批次间忽高忽低，催熟窗口就难控。
   - 机械伤、擦伤、断柄、水烂多的批次，催熟中易局部早熟或腐烂，不能作为稳定供应批次。

4. **要求供应商提供采收/处理信息**
   - 问清采收成熟度、是否做过去手处理、运输温度、到货前储存时间。
   - 长期稳定的一般有固定产地/基地、固定采收标准、冷链记录；只说“保证能催熟”但给不出批次信息的，稳定性风险高。

5. **建立批次档案和验收阈值**
   - 每批记录：产地、到货日期、色阶分布、青硬果比例、试催结果、货架期。
   - 设定可接受阈值，例如试催后青果比例≤5%、色差≤1级、软烂≤2%；连续两批超阈值就降级或换批次。

6. **用“货架期”反向验证**
   - 催熟到销售色后，观察2–3天是否出现集中黑斑、果肉软化过快、掉把。
   - 催熟快但货架期短的批次，不算稳定催熟能力，只算“催得动”。

7. **避免单一指标误判**
   - 不要用“催熟剂用量越大越快”判断能力；稳定是相同条件下响应一致。
   - 不要只看外观黄；要结合硬度、青果率、均匀度和货架期。

实操建议：先对新供应商做**3批小试**，每批固定抽样、固定催熟条件、固定记录表；3批数据波动在阈值内再放量采购。采购合同里可加入“到货青硬果比例、试催均匀度、货架期”验收条款。
