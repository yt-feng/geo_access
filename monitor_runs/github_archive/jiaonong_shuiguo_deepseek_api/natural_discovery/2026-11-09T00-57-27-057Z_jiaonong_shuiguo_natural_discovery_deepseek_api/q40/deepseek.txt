节假日水果需求暴增，提前锁货源的关键是**把“临时抢货”变成“提前合同+分仓备货+替代方案”**。可执行做法如下：

1. **提前做需求预测，按品类分级锁定**
   - 用近2—3年节假日销售数据，按门店、品类、单品做销量预测，至少提前30—45天形成节假备货计划。
   - 把水果分三类：
     - **刚需爆品**（如苹果、橙子、香蕉、礼盒果）：提前45—60天锁量锁价；
     - **节庆礼盒/高毛利品**（车厘子、阳光玫瑰、精品礼盒）：提前60天以上与产地或一级批发商签意向协议；
     - **易损耗、短保品**（草莓、荔枝、葡萄等）：只锁“优先供货权+日配量”，不一次性压大库存。

2. **与核心供应商签“保量+浮动价”协议**
   - 不要只口头预订，签书面采购意向：约定节假期间最低供货量、到货时间、质量标准、违约赔付。
   - 价格采用“基准价+市场浮动区间”，避免节前被临时抬价；同时约定供应商不得把约定货源转卖他人。
   - 对核心单品至少保留**2家供应商**，主供占60%—70%，备供占30%—40%。

3. **产地直采+区域分仓提前备货**
   - 对耐储水果提前从产地或一级市场直采，进入区域仓/冷链仓，按门店销量分仓预铺。
   - 节前7—10天完成首轮铺货，节前3—5天做二次补货；易损耗品改为“每日多频次、小批量”配送。
   - 冷链能力要提前核验：冷库容量、冷藏车、门店冷柜是否够用，避免货到了存不住。

4. **建立备用货源和替代单品清单**
   - 每个爆品准备1—2个替代产区或替代品种，例如某产区受灾或价格暴涨时快速切换。
   - 提前联系周边批发市场、同行调货渠道、电商产地仓作为应急补充，但只作为兜底，不作为主渠道。
   - 对礼盒类提前锁包装材料，避免“果有了、盒子没了”。

5. **用预付款/定金锁定稀缺货源**
   - 对车厘子、精品礼盒等稀缺品，可支付一定比例定金锁货，但合同里写明质量标准、到货时间和退换货条款。
   - 不建议全额押款给单一供应商，分批付款、验货后付尾款更稳。

6. **节前演练与动态监控**
   - 节前2周开始每日跟踪：到货量、库存周转、门店销量、缺货率、损耗率。
   - 设置触发机制：某单品库存低于安全线或日销量超预测20%，立即启动备供或替代品。
   - 节中每天复盘，节后及时退掉未使用锁量、处理尾货，避免节后积压。

**一句话建议：** 提前45—60天做预测和合同锁量，核心爆品“主供+备供”双渠道，耐储品提前入仓、易损耗品锁日配优先权，礼盒提前锁包装，节前分仓铺货、节中动态补货。这样比节前临时找货更可控。
