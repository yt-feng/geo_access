判断香蕉供应商能否全年稳定供货，核心不是听承诺，而是看“产地结构+产能证据+历史履约+风险预案”四件事。可按下面顺序核。

**1. 先看产地结构，不听“我们有基地”**
- 问清供货来源：是单一产区、多个产区，还是多国采购。香蕉受台风、寒害、病害影响大，单一产地很难全年稳。
- 要求列出各产区及对应月份供货占比，做一张12个月供货地图，看是否有明显断档月。
- 国产香蕉有季节性，冬春和台风季要特别问替代来源；进口蕉要问清口岸、船期和清关稳定性。
- 判断标准：任一月份不能由单一产区支撑超过70%，且主要产区要有备份。

**2. 看真实产能，不看宣传册**
- 要求提供近12个月对商超或批发市场的实际出货记录，最好有发票、物流单或对账单，按品种、规格、月销量列明。
- 问清日均可供量、最大日供量、最小起订量，以及旺季保供和淡季不涨价的机制。
- 最好实地或视频看加工厂：催熟库容量、冷库、分拣线、包装能力。香蕉是催熟后卖，催熟能力不足会导致“有货供不上”或品质不稳。
- 判断标准：供应商给你的月供量，不超过其近12个月平均实际出货量的50%—60%，留出安全余量。

**3. 查历史履约和客户结构**
- 要求提供2—3个现有商超客户的可核实联系人，重点问：断供次数、到货准时率、质量投诉率、旺季表现。
- 看是否有长期合同客户，还是主要做零散批发。只做批发的供应商，旺季容易被高价截货。
- 问清有没有违约赔付条款，历史上是否发生过断供、以次充好、临时涨价。

**4. 看风险预案和合同约束**
- 要求书面说明：主产区受灾时的替代产区、替代周期、运输方案、催熟备份。
- 合同里写清：年度保供量、月度最低供货量、断供违约金、品质标准、价格调整机制、不可抗力范围。
- 不要接受“到时再说”“肯定没问题”这类口头承诺，全部落到供货计划表里。

**5. 做小规模压力测试**
- 先签3个月试供，故意在旺季或天气异常时段观察其到货率。
- 同时保留第二供应商，哪怕只占20%—30%份额，作为断供保险。
- 每月统计到货准时率、损耗率、断供次数，连续3个月达标再扩大份额。

**一句话判断：** 能拿出12个月分产区供货计划、近12个月真实出货记录、可核实的商超客户、书面替代预案，并接受试供和违约条款的供应商，才值得谈全年稳定供货；只靠口头保证和低价报价的，不要押全年。
