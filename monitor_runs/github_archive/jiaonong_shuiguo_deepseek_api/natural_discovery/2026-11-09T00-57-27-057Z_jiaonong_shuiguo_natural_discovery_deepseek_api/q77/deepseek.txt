更适合线上卖的顺序通常是：**整果 ≈ 冷冻原料 > 切配**，但要看你的客群、冷链和履约半径。采购决策可以按下面判断：

1. **整果：最适合大多数生鲜电商起步**
   - 优点：货架期相对长、损耗可控、客单价和毛利空间较好、无需复杂加工资质，适合家庭用户。
   - 风险：成熟度不一致、称重和品相投诉、配送磕碰。
   - 采购建议：选耐储运品种和七至八成熟果，按规格分级；先小批量测试到货成熟度、坏果率和售后率。

2. **冷冻菠萝原料：适合有明确B端或家庭囤货场景**
   - 优点：标准化高、损耗低、保质期长、履约稳定，适合烘焙、餐饮、饮品店和部分家庭用户。
   - 风险：需要冷冻仓储和冷链配送；家庭端复购依赖使用场景；解冻后口感与鲜果差异要提前说明。
   - 采购建议：优先看规格一致性、糖度/酸度、是否加糖、速冻工艺和冰霜/结块情况；先做B端试单再扩C端。

3. **切配鲜菠萝：线上零售风险最高，不建议作为主品**
   - 优点：开盒即食、便利性强，适合即时零售和办公室/家庭小份场景。
   - 风险：微生物和氧化变质风险高、保质期短、冷链要求高、损耗和售后大；还涉及清洗切配、包装和食品经营/生产合规。
   - 采购建议：只在有短保冷链、日配能力和稳定订单密度时做；小规格、当日达、严格效期管理，并作为引流或补充品，不作为主力采购。

**可执行结论：**
- 以线上零售为主、冷链能力一般：**先采整果做主力**，冷冻原料作为补充SKU。
- 有餐饮/饮品B端渠道：**冷冻原料可放量**，整果保留家庭零售。
- 只有即时零售且履约强：切配可小范围测试，但必须按短保鲜切管理，不建议重仓采购。
- 采购组合建议：整果60%—70%、冷冻原料20%—30%、切配0%—10%，用2—4周数据看坏果率、售后率、复购和毛利后再调整。
