避免香蕉到店后很快变黑，核心是**控制成熟度、减少机械伤、隔离乙烯、控制温湿度**。采购时按这几条执行：

1. **采购成熟度偏青一点的香蕉**
   - 选果皮青绿、棱角明显、没有大面积黄斑的。
   - 不要买已经通体金黄、带黑点、果柄发黑的，那种到店后很快过熟。
   - 甜品店如果当天/次日用，可以选“黄中带绿”；如果要放2–3天，选更青一点。

2. **整串买，保留果柄和连接处**
   - 香蕉受伤后黑得快，尽量买整串、少分切。
   - 搬运时避免挤压、磕碰、堆压，不要和硬物混装。

3. **到店后立即拆袋通风**
   - 不要闷在塑料袋里，袋内水汽和乙烯会加速变黑。
   - 用纸箱或透气筐存放，避免密封。

4. **悬挂或拱面朝上存放**
   - 能悬挂最好，减少受压面积。
   - 不能悬挂就单层摆放，拱面朝上，避免压到果身。

5. **远离苹果、梨、番茄等乙烯释放量大的果蔬**
   - 香蕉对乙烯敏感，混放会明显加快成熟和变黑。

6. **温度控制：不要冷藏，放阴凉通风处**
   - 未熟或半熟香蕉放12–15℃左右较合适；普通门店放阴凉通风处即可。
   - 不要放冰箱冷藏，低温会导致表皮变黑、风味变差。
   - 夏天避免靠近烤箱、热饮机、阳光直射处。

7. **按使用量分批采购**
   - 甜品店最好“少量多次”，每天或隔天补货。
   - 把青一点的放后面，熟一点的先用，先进先出。

8. **已经偏熟的隔离处理**
   - 出现少量黑点的香蕉单独挑出，优先做香蕉泥、烘焙、奶昔等。
   - 不要和青香蕉放在一起，否则会催熟整批。

简单判断：**采购时选青绿、整串、无伤；到店后拆袋、通风、悬挂、避压、别冷藏、远离乙烯水果。** 这样能明显延缓到店后变黑。
