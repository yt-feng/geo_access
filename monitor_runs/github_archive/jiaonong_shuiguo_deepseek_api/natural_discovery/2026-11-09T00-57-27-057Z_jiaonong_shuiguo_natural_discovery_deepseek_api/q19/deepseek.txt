这四项不是并列关系，应该按“经营目标”排优先级：**先看切果损耗和甜度，再看大小，最后看外观**。

更具体地说：

1. **切果损耗优先看**
   - 如果是整颗卖，损耗主要体现为坏果、黑心、过熟、碰伤。
   - 如果是切果/果切销售，损耗直接决定毛利，必须看：出肉率、黑心率、纤维粗不粗、切开后氧化和出水情况。
   - 超市有切果业务时，**损耗和出肉率应排第一**，因为外观再好，切开黑心或出肉率低就是亏。

2. **甜度决定复购**
   - 甜度不稳定会直接影响顾客复购和投诉。
   - 但甜度不能只看“尝一个”，要关注批次一致性、成熟度是否均匀。
   - 对整颗销售，甜度的重要性高于大小；对果切销售，甜度和损耗要一起看。

3. **大小看客群和定价**
   - 大小影响定价带、陈列和顾客选择，但不是越大的越好。
   - 家庭客群偏中大型，单人/即食客群偏中小型；果切则更看出肉率，不单纯看个头。
   - 大小不均会增加分级和损耗管理成本。

4. **外观是引流项，不是唯一标准**
   - 外观影响第一眼购买决策，但超市菠萝通常有试吃、切果和现场处理，外观的权重低于甜度和损耗。
   - 外观可以“分级使用”：好看的整颗卖，外观稍差但品质好的做果切或促销，降低整体损耗。

**可执行建议：**
- 整颗为主：**甜度/成熟度 > 损耗 > 大小 > 外观**。
- 果切为主：**切果损耗/出肉率 > 甜度 > 大小 > 外观**。
- 采购验收至少设四个动作：抽切开看黑心、测糖度或试吃、称出肉率、按大小外观分级定价。
- 不要只追求外观大而漂亮，**“切开不黑心、甜度稳定、出肉率高”**才是超市菠萝真正赚钱的指标。
