可以从“采购—验收—储存—加工—处置”五个环节控熟度，核心是把香蕉按成熟度分批管理，而不是一次性全买全熟。

**1. 采购：控制成熟度和批量**
- 优先采购七成熟左右的香蕉：果皮偏绿黄、无黑斑、果肉尚硬，到校后还有2–4天缓冲期。
- 不要一次买全熟香蕉；按食堂2–3天用量分批下单，热天缩短到1–2天。
- 和供应商约定到货成熟度标准，例如“允许少量青黄，拒收大面积黑斑、软烂渗汁”。
- 可要求供应商分两批到货：一批即用偏熟，一批稍青后熟。

**2. 验收：按成熟度分级**
- 到货立即分拣：青黄、黄熟、偏熟三档。
- 偏熟香蕉单独放，贴“优先使用”标签，当天用于加餐或加工。
- 拒收已经软烂、破皮、有酒味或霉点的香蕉。

**3. 储存：减慢后熟**
- 香蕉不宜冷藏，低温会变黑；放在阴凉通风处，避免阳光和热源。
- 不要和苹果、梨等释放乙烯的水果混放，会加速成熟。
- 悬挂或单层摆放，减少压伤；偏熟香蕉可拆开分散放置。
- 当天不用的稍青香蕉可保持整串，减少乙烯接触。

**4. 使用：按成熟度排优先级**
- 先熟先用：偏熟香蕉当天供应；黄熟香蕉次日用；青黄香蕉后置。
- 食堂窗口可设“成熟度提示”，优先推销偏熟香蕉。
- 偏熟香蕉适合做香蕉牛奶、香蕉燕麦、香蕉面包、蒸糕等加工品，减少直接售卖压力。
- 每天闭餐前盘点，把次日可能过熟的香蕉提前转为加工用途。

**5. 处置：建立报损和反馈**
- 每天记录到货量、成熟度、使用量、报损量，找到采购量与实际消耗的偏差。
- 连续几天报损偏高，就下调单次采购量或要求供应商发更青的货。
- 与供应商约定少量退换或调剂机制，但不要依赖退货解决日常浪费。

**最可执行的一条**：把“一次采购全熟”改成“按2–3天用量、分成熟度批次采购”，并在验收时立刻分成“今天用/明天用/后天用”三堆，偏熟香蕉当天转加工。这样通常能显著降低熟过头浪费。
