新品试卖的“稳”不在于一个固定箱数，而在于**先用最小可测批量跑一轮真实动销，再根据售罄率、损耗和复购决定是否放大**。可以按下面执行：

**1. 先定试卖量：按2～3天销量、至少20～30个购买决策样本**
- 小门店/社区店：先试 **1～2箱**，或单SKU **20～30份**。
- 中型超市/水果店：试 **3～5箱**，控制在日常同类单品2～3天销量的 **50%～70%**。
- 多门店：先选 **1～2家代表性门店**试卖，不要全门店铺开。
- 单价高、易损、小众品种：取更低值；大众苹果梨柑橘类可略高。

**2. 设置试卖判断线**
试卖3天左右看：
- **售罄率≥80%、损耗≤5%～8%、有复购询问**：可补货放大到1～2周销量。
- **售罄率50%～80%、损耗可控**：维持小批量，调整陈列和价格再试3天。
- **售罄率<50%或损耗>10%**：暂停放量，要求供应商给促销支持或换品。
- 若出现明显口感投诉、到货成熟度不均，直接停止放大。

**3. 和供应商谈试卖条件**
要求：小批量起订、可退换/损耗补偿、到货成熟度标准、试卖期价格保护、后续放量价阶梯。试卖期不要一次性压货，也不要只看“卖完没”，要记录**进货量、售价、损耗、日销量、顾客反馈**。

**4. 陈列和测试方法**
新品单独做小堆头/试吃，标价签写清品种和口感卖点；同时保留一个对照同类老品，观察新品是否抢了老品销量而非带来增量。试卖期避免大促掩盖真实需求。

**结论：**最稳的做法是**单店1～2箱、2～3天、20～30个购买样本**起步；售罄率和损耗达标再逐步放大，不达标就停。这样损失可控，也能判断新品是否值得长期采购。
