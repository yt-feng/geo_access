超市和水果供应商的账期没有统一标准，常见区间大致是 **7～45天**，具体取决于品类、渠道和供应商规模：

- **水果（生鲜）**：**7～15天**较常见，部分强势超市会压到 **15～30天**；叶菜、浆果等损耗高的品类往往更短，甚至现结或周结。
- **大型商超/连锁超市**：对中小供应商常见 **30～45天**，有时按“到货后30天”或“月结30/45天”执行。
- **区域超市/社区生鲜店**：多为 **7～15天**，或“周结”“半月结”。
- **产地直采/大批量稳定供货**：可能谈到 **15～30天**；新供应商通常先短账期，稳定后再延长。
- **批发市场/现金采购**：基本现结或 **3～7天**。

谈判时可参考：新供应商先争取 **7～15天**；合作稳定后逐步到 **30天**；超过 **45天**对水果供应商资金压力较大，通常需要更高供货价或更严的退货条款来补偿。账期之外还要明确**对账日、付款日、起算点（到货/验收/开票）、质量扣款和逾期利息**，否则“30天”实际可能拖成45天以上。
