判断香蕉批发商是否稳定，别只看报价和口头承诺，重点核这几项，能当场验证的优先验证：

1. **看产地和季节供应能力**
   - 问清主营产区：云南、广西、海南、老挝、越南、菲律宾等。稳定供货商通常能说清“现在主发哪里、下个月切到哪里、雨季/台风季怎么补”。
   - 如果只靠单一产区、单一果园，旺季没问题，淡季或灾情时容易断供。
   - 要求对方说明近3个月每天/每周大概能供多少件、多少吨，和你需求匹配不匹配。

2. **要求看近期连续发货记录**
   - 不要只看朋友圈一张装车图。让他提供近7—15天的发货单、装车视频、车牌、冷库/档口实拍。
   - 重点看是否“连续每天/隔天有货”，而不是偶尔一车。
   - 可要求视频通话看档口现场、冷库、正在装的货，确认不是借图。

3. **核验档口/公司主体**
   - 要营业执照、档口名称、市场档口号、负责人电话，最好实地或让本地朋友去看。
   - 对公收款优先；长期合作再谈账期。个人微信收款且催着全款的要谨慎。
   - 查一下是否有固定冷库、加工线、催熟库。香蕉供货稳定很依赖冷库和催熟能力。

4. **问异常情况处理方案**
   - 直接问：台风/寒潮/口岸堵车时怎么保供？断货提前几天通知？质量不达标怎么赔？运费谁承担？
   - 稳定供货商通常有备用产区、备用车队、明确赔付标准；含糊其辞的说“放心没问题”的反而要小心。

5. **小单试供，连续试3—5次**
   - 先小批量走2—3车或几批，不要一上来大额预付。
   - 每次记录：到货时间、数量误差、青黄比例、坏果率、催熟效果、售后响应。
   - 连续几次都稳定，再谈长期价和账期。试供期可要求“到货验收后付尾款”或部分押金。

6. **看价格是否异常低于市场**
   - 香蕉一手货源价格透明，明显低于市场价往往有猫腻：可能是二级倒手、以次充好、扣称、临时加价。
   - 稳定供货商报价不一定最低，但会说明规格、等级、包装、运费、损耗承担。

7. **合同/订单写清楚**
   - 写明品种、规格、单件重量、成熟度、包装、发货时间、数量浮动范围、验收标准、坏果赔付、断供责任。
   - 先款后货的，保留聊天记录、转账凭证、车牌和装车视频。

简单说：**能带你看现场、能给出连续发货记录、能说清备用产区和赔付方案、愿意小单试供的，稳定性才可信。** 只靠低价和口头保证的，不建议直接大额合作。
