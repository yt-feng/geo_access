判断供应商能不能“按时到车”（按约定时间把货送到市场/档口），核心不是听口头保证，而是看他有没有稳定的产地组织能力和履约记录。你可以按下面几步做，起订前就能筛掉大部分不靠谱的：

1. **先问清“车”从哪来、谁控制**
   - 是供应商自有/长期合作的车队，还是临时在平台叫车？
   - 装车地点是产地冷库、代收点，还是他自己档口？
   - 香蕉催熟、装车、打冷、运输是否由他一条链控制。环节越分散，延误概率越高。

2. **看历史履约记录，不看承诺**
   - 直接要他最近10—20车同线路的发车记录：发车时间、到车时间、延误原因。
   - 问固定客户能不能给一个可回访的电话；老客户复购率比任何保证都硬。
   - 新供应商先小批量试一车，别一上来压大单。

3. **查产地和装车能力**
   - 问清产地县/镇、代收点每天能装几车、装车时段。
   - 香蕉怕高温和挤压，要确认是否有预冷/打冷条件、装车工人是否固定。
   - 如果他说“随时有车”，反而要警惕；正常供应商会告诉你装车窗口和排车计划。

4. **把“按时”写进订单，不靠嘴**
   - 合同或微信订单里写明：约定到车时间、允许延误分钟数、延误后怎么赔（比如每超1小时扣款、超X小时可拒收）。
   - 约定发车后必须发：车牌号、司机电话、装车照片、定位共享。
   - 付款方式留尾款，到车验货后结清，别提前全款。

5. **发车后做动态跟踪**
   - 要求装车完成即报车牌和定位；中途在关键节点（上高速、过省界、下高速）各报一次。
   - 到车前一晚确认司机是否在正常行驶；如果定位停超过2小时且无合理解释，立即启动备选供应商。

6. **永远留备选**
   - 同一线路至少维护2—3个供应商，主供占70%，备供占30%。
   - 旺季前提前锁车，别等到缺货才找车。

**快速判断口诀：** 能说清产地、装车点、车牌、司机、历史到车时间的，可信度较高；只拍胸脯说“没问题”、不肯给记录、不肯写延误条款的，基本不要指望按时。新合作先试一车，尾款到车再结，是最低成本的验证方式。
