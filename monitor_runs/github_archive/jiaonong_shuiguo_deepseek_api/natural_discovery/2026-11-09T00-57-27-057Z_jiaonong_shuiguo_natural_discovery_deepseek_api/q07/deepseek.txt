做水果礼盒，想“好卖”关键不是把四种水果都塞进去，而是**按场景定价、按耐放程度搭配、按视觉层次装箱**。苹果、橙子、香蕉、菠萝这四种里，香蕉最不耐放也最怕压，菠萝体积大、带刺冠，适合做“体面款”但不好做小盒。建议你这样组合：

**1. 主推款：日常送礼/探病款（最好卖）**
- 苹果 4 个 + 橙子 4 个 + 香蕉 1 把（约 5-6 根）
- 定位：39-59 元档，走量
- 理由：苹果橙子耐放、寓意好（平安、吉利），香蕉增加“满”的感觉，成本低、周转快。
- 注意：香蕉放最上层，用隔板或气柱垫住，别压。

**2. 体面款：节日/商务/看望长辈**
- 苹果 4 个 + 橙子 4 个 + 菠萝 1 个（小果）
- 定位：69-99 元档
- 理由：菠萝立起来有“旺来”寓意，礼盒高度和视觉冲击强，适合拍照和送人。
- 注意：菠萝冠芽朝上固定，底部垫吸水纸，避免扎破其他水果。

**3. 小份尝鲜款：办公室/情侣/随手礼**
- 苹果 2 个 + 橙子 2 个 + 香蕉 3-4 根
- 定位：19.9-29.9 元档
- 理由：低门槛试单，适合放在收银台旁边冲动购买。
- 注意：香蕉选偏青一点的，延长货架期。

**4. 不建议主推的组合**
- 四种全放一大盒：菠萝占空间、香蕉易催熟其他水果，损耗高，顾客也觉得“杂”。
- 香蕉和菠萝大量混装：香蕉对乙烯敏感，菠萝又占体积，容易压伤、熟烂。

**实操建议：**
- 礼盒内用**牛皮纸丝/拉菲草+隔板**分区，苹果橙子放底层，香蕉放上层凹槽，菠萝单独卡位。
- 定价按“水果成本×2.2-2.8”起步，节日可到3倍，但要留出损耗。
- 先做3个价位段：19.9/39.9/69.9，观察一周动销，哪个卖得快就加量。
- 香蕉每天检查，熟透的拆出来做果切或特价，别等礼盒里发黑。
- 苹果选红富士、橙子选脐橙/沃柑，颜色对比强，礼盒显档次。

总结：**日常走量靠“苹果+橙子+香蕉”，节日体面靠“苹果+橙子+菠萝”，四种全上反而不好卖。**
