甜度和出汁率不是同一个维度，不能简单二选一；对茶饮店来说，**先看出汁率/可用果肉率，再看甜度是否稳定可控**。更准确地说：

**优先级：出汁率与风味稳定 > 甜度绝对值。**

原因：

1. **出汁率决定成本和出品稳定性**
   - 菠萝在茶饮里通常要的是果汁、果肉、果酱感。出汁率低，同样一杯用量下原料成本更高，操作也更费工。
   - 出汁率低、纤维粗、芯硬的菠萝，做果肉茶口感差，还容易堵吸管、出品不稳定。
   - 对门店来说，出汁率和可食用比例是更硬的经营指标。

2. **甜度可以用配方调节，出汁率不好救**
   - 甜度偏低可以通过糖浆、果酱、复配水果调整；甜度偏高可以稀释或减少糖。
   - 但出汁率低、果肉少、纤维粗，靠配方很难补出自然果感，还会增加原料用量。

3. **甜度更重要的情况**
   - 如果你做的是**纯果茶、鲜果茶，强调“自然甜感”且不想用太多糖浆**，那甜度稳定性会变得很重要。
   - 这时不是追求“越甜越好”，而是要求**批次甜度稳定、酸甜比合适**。菠萝太酸或甜度波动大，会导致门店配方反复调整。

建议的采购判断顺序：

1. **先测出汁率/可食率**：同样重量榨汁或切果肉，看出汁量、果肉完整度、纤维粗细。
2. **再看酸甜比和香气**：不是单看糖度，要看糖酸比和菠萝风味是否足。
3. **看批次稳定性**：不同批次甜度波动大，比“平均很甜”更麻烦。
4. **结合产品定位**：
   - 冰茶、果肉茶、性价比款：出汁率和果肉率优先。
   - 高端鲜果茶、无糖/低糖概念款：甜度稳定性和香气优先，但仍不能牺牲出汁率。

一句话结论：**茶饮店买菠萝，出汁率和可用果肉率是底线，甜度是调节项；先保证出汁率和风味稳定，再选甜度合适且批次稳定的原料。**
