旺季谈供应商，核心不是“能不能供货”，而是把**供货能力、锁价方式、缺货责任、补货时效**提前写清楚。建议你带着下面这些问题去谈，能问出对方真实底牌。

**一、先问供货能力，别只听“没问题”**
1. 旺季你每天能稳定给我多少箱/斤？分品种报最大可供量。
2. 你现在的货源是自有基地、产地直采还是市场调货？旺季会不会优先保老客户？
3. 去年旺季你最紧张的时候，断过哪些品种？断货一般持续几天？
4. 有没有备用产地或备用供应商？遇到天气、交通、节日集中采购时怎么保供？
5. 你服务的水果店里，和我同规模的有几家？旺季你如何分配货源？

**二、把价格和锁价方式问透**
6. 旺季价格是随行就市，还是可以提前锁价？锁价锁多久、锁哪些品种？
7. 如果市场价下跌，我的拿货价能不能跟着降？如果上涨，涨幅有没有上限？
8. 报价含不含运费、装卸、损耗？到店价还是出库价？
9. 起订量多少？达不到起订量怎么算？临时加单加不加价？
10. 结算方式是现结、周结还是月结？旺季能不能给账期或备用额度？

**三、缺货和品质责任必须落到纸面**
11. 我下单后你多久确认？确认后缺货怎么赔？是补货、退款还是承担我临时采购差价？
12. 到货品质不达标怎么处理？坏果率超过多少可以拒收或索赔？
13. 损耗算谁的？运输途中烂果、压伤怎么界定？
14. 临时缺货提前多久通知我？有没有应急补货方案？
15. 旺季能不能给我留安全库存？留多少、怎么收费？

**四、配送和售后要问细**
16. 每天几点前下单、几点送到？旺季配送会不会延迟？
17. 能不能按我门店销售节奏分次送，避免一次压太多货？
18. 出现质量问题，多久内响应？换货还是退款？
19. 有没有专门对接人？旺季电话打不通时找谁？
20. 合作要不要签旺季保供协议？能不能把可供量、价格上限、缺货赔偿写进去？

**谈判时的实用建议：**
- 不要只谈一家，旺季至少备**两家供应商**，主供占70%、备供占30%，避免被单一货源卡住。
- 先小批量试单，看**到货准时率、坏果率、缺货通知速度**，再决定旺季主推哪家。
- 把关键承诺写成简单书面确认，哪怕是微信文字确认：**品种、日供量、价格区间、送达时间、缺货赔偿**。
- 你自己也要提前做**3—7天安全库存**，易腐水果别压太多，用周转筐和冷柜控制损耗。

最该盯住的一句话是：**“旺季断货时，你具体怎么赔、多久补上？”** 对方如果只拍胸脯不给方案，就不能作为主供。
