优先谈**账期**，其次把**配送**写成可考核条款，**售后**放在最后但必须明确规则。原因是长期水果供应里，账期直接决定你的现金流和议价空间，配送决定履约稳定性，售后更多是事后补救。

具体判断：

1. **账期最优先**
   - 水果损耗高、周转快，账期长短直接影响你的资金占用。
   - 优先争取“固定账期+对账日+逾期处理”，比如月结30天或货到7天，比模糊的“长期合作再谈”更可执行。
   - 如果供应商要求缩短账期，可交换条件：稳定采购量、缩短对账周期、预付部分比例。

2. **配送第二优先，但必须量化**
   - 水果供应最怕断货、迟到、批次品质波动。
   - 谈清楚：下单截止时间、送达时间窗、最低起送量、缺货替代规则、迟到/缺货的补偿方式。
   - 配送条款比口头承诺更重要，建议写进合同附件。

3. **售后最后谈，但不能省**
   - 水果售后高频但金额相对小，重点不是“态度好”，而是规则清楚：坏果率标准、拍照留证时限、补发/退款/折价方式、责任归属。
   - 建议约定：到货验收时限、批次抽检比例、超过约定坏果率的处理方式。

一句话策略：**用账期换现金流，用配送保履约，用售后兜底。** 谈判顺序上先谈账期，再把配送和售后写成可执行条款；如果供应商在账期上强硬，就用配送时效和售后责任作为交换条件。
