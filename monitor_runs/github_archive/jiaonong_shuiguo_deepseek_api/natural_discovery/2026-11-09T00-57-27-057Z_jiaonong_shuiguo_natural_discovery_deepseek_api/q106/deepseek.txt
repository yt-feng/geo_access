判断“合理波动”不要盯着单日价格，而要看**波动是否有可解释的原因、是否落在历史区间、是否和同类市场同向**。可执行做法如下：

1. **建立历史价格基线**
   - 按品类、规格、等级、产地、包装分别记录，不要混在一起。
   - 至少保留30–90天日价，算7日均价、30日均价、波动率和历史高低区间。
   - 单日涨跌超过过去30天波动率的2倍，或超过7日均价10%–15%（按品类设阈值），才进入重点核查。

2. **要求报价附带波动原因**
   让供应商每次报价说明：产地天气、采收量、等级变化、包装/运输成本、燃油/冷链、节假日备货、批次质量差异等。**不能解释原因的涨价，先不认。**

3. **做横向比价**
   - 同一天向2–3家同类供应商询价，看是否全市场同向变动。
   - 对照当地批发市场、农业农村部门价格监测、主要产销地行情。只有一家涨、市场没涨，通常不是合理波动。
   - 注意比较口径：同一品种、同一等级、同一规格、含税/含运费是否一致。

4. **区分“价格波动”和“报价条件变化”**
   很多涨价其实是规格变小、等级降级、包装费/运费/损耗另算。要求报价单固定口径：毛重/净重、等级、产地、包装、交货地、账期、损耗承担。口径变了，先按可比价折算再判断。

5. **设置合同机制**
   - 约定价格调整公式：挂钩公开市场均价或双方认可的指数，设定调整频率（如每周一次）和涨跌幅上限。
   - 约定异常波动复核：超过阈值需提前书面通知并附证明，采购方有权暂停下单或重新询价。
   - 对短期暴涨可约定“锁价期”或“保底+浮动”条款。

6. **看趋势不看单点**
   连续3–5天同向变化、且伴随产地天气/季节因素，更可能是合理波动；单日跳涨、无原因、只此一家，优先视为异常报价。

**简单判断规则：** 有公开原因、多家同向、落在历史区间内、口径一致 → 合理；无原因、只有一家涨、口径悄悄变化、频繁朝同一方向调 → 不合理，要求复核或换供应商。
