需要，而且建议把这两项作为准入条件写进采购要求。

1. **开发票：必须支持**
   - 企业采购水果礼盒通常涉及报销、入账和税务合规，供应商应能开具**增值税普通发票或专用发票**。
   - 采购前确认：开票主体与合同主体一致、发票品名能开“水果礼盒/食品”等合规类目、税率和开票时间。
   - 若供应商只能开收据或第三方代开，风险较高，不建议选。

2. **定制包装：建议支持，按需求定**
   - 企业福利通常有统一形象需求，如印LOGO、贺卡、企业祝福语、统一外箱等，定制包装能提升福利感知。
   - 但并非所有场景都必须：若预算紧、数量少、节日临近，可接受标准包装+贴纸/贺卡的低成本定制。
   - 采购前确认：起订量、打样费、打样周期、包装食品安全合规（油墨不直接接触水果）、定制后是否影响退换货。

**可执行建议：**
- 询价时直接问供应商三件事：能否开专票/普票、能否定制包装及起订量、定制周期和打样费用。
- 合同里写明：开票类型与时间、包装定制标准与验收样、因包装或发票问题导致无法结算的责任。
- 若供应商不能开票，直接排除；定制包装可作为加分项，但食品安全和交付时效优先。
