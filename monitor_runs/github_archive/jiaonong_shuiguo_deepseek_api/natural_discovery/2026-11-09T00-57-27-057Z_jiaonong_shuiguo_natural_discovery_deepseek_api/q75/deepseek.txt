第一次合作水果供应商，小批量试单不要只当“买点货卖卖看”，而要把它设计成一次**低风险的质量、履约和结算验证**。建议按下面方式做。

## 1. 先定试单目标

试单要回答四个问题：

1. **品质是否稳定**：到货成熟度、大小、糖度、外观、损耗是否可接受。
2. **履约是否可靠**：能否按约定时间、数量、规格交货。
3. **结算是否清爽**：价格、费用、损耗、退换、账期是否按约定执行。
4. **是否适合你的下游**：你的客户是否愿意复购。

## 2. 试单规模怎么定

原则：**够验证一个完整销售周期，但不至于压货。**

- 单品首次试单：建议按 **1—3 天销量** 备货，不要按一周以上销量压。
- 多品测试：选 **2—3 个主销单品**，每品少量，便于横向比较。
- 金额控制：建议首次试单总金额不超过你单周水果采购额的 **10%—20%**，或设一个你能承受全损的上限。
- 易腐程度高的先更小：浆果、荔枝、水蜜桃等按 **1 天销量** 试；苹果、梨、柑橘可适当放大。

## 3. 试单设计的关键动作

### 试单前
- 明确 **品名、品种、产地、等级、规格、单果重/果径、成熟度、包装方式、净重**。
- 约定 **交货时间、交货地点、验收时限、运输温度**。
- 约定 **价格是否含税含运、装卸费谁承担、损耗率上限、次果怎么算**。
- 约定 **退换货规则**：坏果率超标怎么补、怎么退、运费谁出。
- 先要 **样品或近期实拍视频**，但样品不能替代到货验收。
- 最好签简单书面试单协议或微信书面确认，避免口头约定。

### 到货验收
建议当场按固定流程验：

1. **点数称重**：核对件数、净重，抽检是否短斤少两。
2. **分层抽检**：不要只看上层，按上中下、内外层抽样。
3. **记录指标**：坏果率、压伤率、成熟度、大小均匀度、包装破损。
4. **拍照留证**：开箱、称重、坏果、包装、运单一起拍。
5. **当天反馈**：问题当天书面反馈供应商，约定处理时限。

可设一个简单验收标准，例如：
- 坏果/腐烂率超过 **3%—5%** 启动扣款或补货；
- 规格不符超过 **10%** 要求换货或折价；
- 到货成熟度过高、无法销售则拒收或协商退货。

具体比例按品类和你下游要求调整，但一定要提前写进试单约定。

### 试销验证
- 记录 **到货损耗、上架损耗、售罄时间、顾客投诉、复购意愿**。
- 不要只看进货价便宜，要算 **综合到货成本**：采购价 + 运费 + 损耗 + 退换成本 + 人工分拣。
- 同一单品可小量对比第二家供应商，但不要一次铺太多家导致管理混乱。

## 4. 付款和风险控制

- 首次合作建议 **小比例定金 + 到货验收后付尾款**，或货到付款。
- 不建议首次就大额预付、长账期或无条件包销。
- 明确质量保证金或首批扣留款：如尾款的 **10%—20%** 作为质量观察金，下一单验收无问题后结清。
- 所有变更走书面确认，尤其是价格、数量、规格、交货时间。

## 5. 试单后判断是否扩大合作

满足以下条件再放量：
- 连续 **2—3 次** 到货品质稳定；
- 损耗和退换处理及时；
- 交货准时率可接受；
- 综合成本有优势；
- 下游动销正常、投诉可控。

只要出现 **品质波动大、验收扯皮、短斤少两、退换不认账** 中任一严重问题，就先不扩大，换供应商或继续小单观察。

一句话：**试单要小到亏得起，但要验得全；重点不是“进一批卖卖”，而是把品质、履约、结算三条线一次跑通。**
