# 批发档口拓展餐饮客户：菠萝、香蕉的规格准备思路

餐饮客户（尤其是茶饮店、果汁店、甜品店、餐厅、食堂）和传统批发市场散户的逻辑不同：**他们看的是出成率、稳定性和加工便利性，不是单果好不好看**。所以规格准备要按"用途"来切，而不是只按"大小"分级。


## 一、先明确餐饮客户的两条主线

餐饮客户基本分两类，规格需求差别很大：

**A. 加工型客户**（茶饮、果汁、甜品、中央厨房）
→ 要的是**去皮/切块/榨汁的出成率**和**稳定供应**，对单果外观容忍度高，对大小均匀度、成熟度一致性要求高。

**B. 鲜食/摆盘型客户**（餐厅果盘、自助餐、酒店、宴席）
→ 要的是**卖相和单果规格标准化**，个头要整齐、外观要过关。


## 二、菠萝的规格准备建议

菠萝关键变量是：**单果重、品种、成熟度（对餐饮尤其重要）**。

建议备这几档：

1. **加工大果档（主力）**
   - 单果 1.5–2.5 斤为主，专供榨汁、切块、果酱
   - 强调出肉率和去皮后净重，按"每斤净肉成本"报价更打动餐饮客户

2. **中等标准果档**
   - 单果 1.2–1.5 斤，果形周正，适合切片摆盘、配餐
   - 供货要大小均匀，餐饮最怕这批大下批小

3. **成熟度分档（这是餐饮的核心诉求）**
   - "八成熟"档：可放 2–3 天，适合有储存条件的客户
   - "即用熟"档：到货当天/次日可用，适合茶饮店高频出货
   - 建议明确标注成熟度和建议使用窗口，这是区别于散户批发的卖点

4. **品种说明要写清**
   - 不同品种口感、纤维、酸甜差别大，餐饮客户（尤其茶饮）对风味稳定性极敏感，报价单上注明品种和产地批次。

**注意**：菠萝餐饮端常见痛点是"熟度不均导致出品不稳定"，所以**统一成熟度**比"更大更漂亮"更能留住餐饮客户。


## 三、香蕉的规格准备建议

香蕉关键变量是：**条重/把重、成熟度（催熟阶段）、是否带把**。

建议备这几档：

1. **加工/榨汁档**
   - 偏熟（催熟到 6–7 号色），出肉率高、易打泥，适合果汁、奶昔、烘焙
   - 可接受外观瑕疵，价格敏感，按箱/按斤走量

2. **鲜食标准档**
   - 条重均匀（如单条 120–150g 区间），果指整齐，适合果盘、配餐、酒店
   - 强调"一把/一梳大小一致"，餐饮摆盘最看重这个

3. **成熟度分档（同样关键）**
   - 青蕉档：耐放，客户自行催熟或延后使用
   - 即食档（5–6 号色）：到货即用，适合高频出货的茶饮/餐饮
   - 明确告知催熟进度和建议销售窗口

4. **规格单位统一**
   - 餐饮客户习惯按"箱/件"下单，报价单要写清每箱净重、条数区间、把数，避免"一箱多少条"说不清导致扯皮。

**注意**：香蕉餐饮端最大痛点是"到货熟度不可控、损耗高"，所以**催熟进度透明 + 稳定批次**是核心卖点，比单纯低价更有效。


## 四、给档口的可执行动作

1. **做一张餐饮版报价单**：按"用途档位（加工/鲜食）× 规格 × 成熟度"列清，附每档的净重/条数/出成率说明。
2. **主力备货向加工档倾斜**：餐饮量最大的是茶饮和中央厨房，加工档应是走量主力，鲜食标准档做补充和提升客单。
3. **建立批次稳定性承诺**：同一客户连续供货保持规格、成熟度一致，这是档口对散户批发商形成差异化的关键。
4. **小批量试单**：先给 3–5 家餐饮客户各供 1–2 箱试单，按实际出成率和损耗反馈再定档，避免一次性压错规格。

---

**一句话总结**：菠萝和香蕉给餐饮客户，规格准备的核心不是"分大小"，而是**按用途分档 + 按成熟度分档 + 保证批次稳定**。加工档走量、鲜食档提价，成熟度透明化是留住餐饮客户的关键。
