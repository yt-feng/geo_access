给批发商做香蕉和菠萝的分级报价，核心逻辑是**按规格（大小/重量）和成熟度（催熟状态）来定档**，让小店老板一眼知道自己拿到的货值多少钱。

以下是实操性很强的分级和报价模板，你可以直接套用：

### 一、香蕉分级报价（重点看“熟度”和“净重”）

小店容易卖熟果，但要屯货要生一点。所以分级主要分**货源等级**和**熟度**。

| 等级 | 标准（外观/重量） | 参考报价话术（举例） | 适用小店 |
| :--- | :--- | :--- | :--- |
| **A级 特级果** | 单根长度≥20cm，无斑点、无擦伤，全绿或头绿尾黄 | 按箱算：**XX元/箱（净重18-20斤）** <br>（俗称“大条货”） | 商圈、人流量大的水果店，卖相好，定价高 |
| **B级 一级果** | 长度16-20cm，允许少量黑点（梅花点），果形整齐 | 按箱算：**XX元/箱（净重18斤）** <br>（俗称“中条货”） | 社区店、菜场摊，走量为主 |
| **C级 二级果** | 长度<16cm，或弯曲度大、有轻微疤痕（不影响食用） | 按斤卖：**XX元/斤**（或者按**整把**报价） | 榨汁店、甜品店、路边摊 |

**报价关键提醒：**
- **必须注明“熟度”**：建议报两个价格——`绿熟价`（耐放）和`催熟价`（黄熟，价格略高1-2毛，当天能卖）。不要只说“香蕉价”，因为小店老板最怕拿回去一夜全黄。
- **单位要统一**：要么都按**箱**（固定净重），要么都按**斤**（过磅）。强烈建议按**箱**报，带皮损耗大，按斤算容易扯皮。

---

### 二、菠萝分级报价（重点看“单果重”和“冠芽”）

菠萝分级主要看**个头**，因为个头决定了零售价。同时要分**带叶/削皮**。

| 等级 | 标准（单果重） | 参考报价话术（举例） | 适用小店 |
| :--- | :--- | :--- | :--- |
| **大果（一级）** | 单果重≥2.5斤（或≥1.2kg），果型椭圆、饱满 | **XX元/个**（必须注明是**带叶价**）<br>（折算约X.X元/斤） | 精品水果店，卖整果、好看 |
| **中果（二级）** | 单果重1.8-2.5斤（800g-1.2kg），果眼浅 | **按个卖：XX元/个** <br>（最好按**件**走，一件xx个） | 社区店（最走量，不压货） |
| **小果（统级/特价）** | 单果重<1.8斤，或有轻微擦伤 | **按桶/按件（统货价）**：XX元/件（约XX斤） | 街边流动摊、削皮卖 |

**报价关键提醒：**
- **必须区分“带叶”和“削皮”**：菠萝按个卖时，**带叶**和**去叶（光果）** 价格差别很大（通常相差1-1.5元/个）。请在报价单上直接写明：`A级带叶菠萝 X元/个`，`A级去叶菠萝 X元/个`。
- **注明“出肉率”**：对于经常要削皮的客户，可以补充一句“本批出肉率约65%”，这能解释为什么贵一点，也能避免客户觉得皮厚。

### 三、最终报价单模板（给客户看，一页纸搞定）

你可以做成下面这样，直接复制到微信或打印出来：

```
【今日香蕉报价】—— 建议拍图发群里
A级大条（净重20斤/箱）：XX元/箱（绿熟） / XX元/箱（黄熟）
B级中条（净重18斤/箱）：XX元/箱（绿熟） / XX元/箱（黄熟）
C级散装统货（整把）：XX元/斤（需要提前说）

【今日菠萝报价】
带叶大果（5-6个/件，约14-15斤）：XX元/件（约 X.X元/个）
去叶中果（整箱装）：XX元/件（约 X.X元/个）
削皮果（仅限老客户，提前预定）：XX元/斤（每天17点前截单）
```

### 老板实操建议（避坑指南）：
1. **报价别报“浮动区间”**：比如报“5-6元/斤”，小店会永远按最低价跟你算。直接报死价，`5.5元/斤`。
2. **损耗提前说清**：菠萝在运输中容易碰伤，建议报价时备注“**本批货约2%运输损耗不保**”，或者直接把损耗折进价格里。
3. **同一批货要分堆**：到货后，在仓库把大小分好。**明确告诉客户“挑大果要加价”**，不要让他自己翻，否则他会把所有大的挑走，给你剩小的，最后扯皮。
