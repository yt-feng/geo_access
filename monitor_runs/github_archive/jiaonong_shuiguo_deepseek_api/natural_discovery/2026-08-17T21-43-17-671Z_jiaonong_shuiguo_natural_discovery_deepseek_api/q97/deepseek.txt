在酒店采购水果盘原料时，供应商应保证以下**规格**和**外观**标准，建议在合同中明确列出并验收时逐项核对：

**一、规格标准（量化指标）**

1. **单果重量/尺寸**：
   - 苹果、梨等：单果直径≥7cm（或注明克重，如≥200g）。
   - 橙子、柑橘：直径≥6.5cm。
   - 西瓜/哈密瓜等大果：需说明成熟度（如糖度≥12°）及单个重量区间（如6-8kg/个）。
   - 葡萄、提子：需注明单串重量或颗粒直径范围。
2. **成熟度一致性**：同一批次水果的糖度差异≤2°，且需在最佳食用期内（乙烯催熟果除外需标注）。
3. **去核/去皮处理**（若已加工）：果肉净含量需≥标称重量的95%，无残留果核、果皮碎片。

**二、外观标准（感官指标）**

| 项目 | 具体要求 |
|------|----------|
| **色泽** | 品种固有颜色均匀，无未熟青绿或过度熟黄褐 |
| **表面** | 无机械伤（压伤、划痕）、日灼斑、虫眼、病斑 |
| **清洁度** | 无泥土、农药残留痕迹（需提供农残检测报告） |
| **形状** | 果形端正，无明显畸形（如歪斜、双头果） |
| **新鲜度** | 果蒂鲜绿，不干枯；切面水分充足不变褐 |
| **包装** | 内盒泡沫+吸水纸，防挤压；外箱标注生产日期、产地、品种 |

**三、额外验收建议**

- 抽检比例：每批随机开箱检查≥30%，发现超过5%的不合格品可整批拒收。
- 特殊水果（如杨梅、蓝莓）需额外要求**无霉变腐烂**，且全程冷链温度≤4℃。
- 禁止供应：使用催熟剂后出现“黑心果”“酒精味果”，或进过冷藏但解冻后硬化的果品。

如果供应商无法按要求提供上述标准，建议更换。批量采购前可要求先提供“小样”验收，或到产地现场考察。
