选择茶饮店的菠萝原料时，**出汁率通常比甜度更重要**，但两者需要结合具体产品定位来权衡。

**核心逻辑：**
1. **出汁率直接决定成本和口感厚度**。茶饮（尤其是果茶、冰沙）需要大量果汁作为基底，出汁率低的菠萝（如某些品种或过熟果）会导致单杯成本飙升，且饮品风味稀薄、容易寡淡。
2. **甜度可以通过糖浆、果糖等商业化手段调节**。门店完全可以依据产品配方额外加糖，但**无法弥补出汁不足带来的“水感”**——即使加糖后甜度够了，口感依然会显得单薄，缺乏菠萝的浓郁果汁感。

**具体建议：**
- **做鲜榨类/大桶水果茶**：优先选**出汁率≥60%**的品种（如金钻菠萝、台农17号），同时要求成熟度适中（表皮微黄、按压稍软），此时甜度自然8-10度即可，减少额外加糖成本。
- **做点缀/装饰或果肉小料**（如菠萝丁、菠萝碎）：此时甜度和果肉质地更重要，选甜度高（糖度≥11）且纤维少的品种，出汁率次要。
- **供应链角度**：需要对方提供**SBR（固形物）或出汁率检测数据**，不要只听“很甜”的描述。签订合同时约定最低出汁率标准（如≥55%），防止供应商用次果充数。

**一句话结论：** 如果只能选一个，**出汁率优先**——因为糖可以后加，汁水无法人造。但若你的产品主打“低糖天然”，则甜度权重需提高到与出汁率同等程度，此时应直接采购糖度≥12的高熟度菠萝，并接受出汁率略低的可能。
