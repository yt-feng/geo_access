在便利店卖菠萝切块，这三方面**都很关键，且相互关联**，但优先级和具体做法可以这样拆解：

**1. 保质期（核心红线）**
- **明确规定**：菠萝切块属于高酸性、高水分、易氧化的鲜切水果，**从切配到报废**通常建议不超过**24小时**（冷藏0-4℃）。具体需参考你的供应商标准或自制SOP。
- **标签管理**：必须贴有**制作时间/日期**和 **“请于X日前食用”** 的标签，并写清“需冷藏”。
- **责任划分**：如果是供应商供货，明确**收货时的验收标准**（如表面无褐变、无汁水渗出、盒内无积水）；如果是店内现切，需记录切割时间。

**2. 包装（直接影响寿命与卖相）**
- **防氧化**：建议使用**气调包装（MAP）** 或**贴体膜包装**（密封性好、氧含量低），能显著延长2-4小时有效期。
- **防压伤**：选用**硬质透明塑料盒**（PET材质），底部带**吸水垫**或**沥水盘**，防止汁水浸泡果肉发软变质。
- **购买提示**：包装必须完好，若有胀包、漏液、破膜，一律下架。

**3. 配送频次（决定库存新鲜度）**
- **建议频次**：如果门店日销量一般，**建议每日配送1次**（或每日早晨一次+午后机动补货），确保货架期不超过12小时。
- **最优做法**：**按需配货，少量多次**，例如上午8点、下午2点各送一批，避免一早送过多导致下午氧化。
- **现场反馈**：每次收货时抽检两盒，摸盒底有无积液、闻有无发酵酸味，一旦异常立即拒收并反馈，调整次日订货量。

**优先级建议**：
1. **先定保质期标准**（半天/一天），
2. **再选密封+沥水的包装**，
3. **最后根据销售曲线定配送**（高峰前到货，低峰控量）。

如果预算有限，可以**优先确保“当日切、当日清”**，因为损耗风险远高于包装成本。若需进一步核算每日订货量，可以告诉我门店日均客流或历史销量。
