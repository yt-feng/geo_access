大型超市（如沃尔玛、永辉、盒马等）对水果供应商的准入和考核非常严格，主要围绕**食品安全合规**与**冷链物流履约**两大核心。具体必备能力如下：

### 一、食品安全能力（基础门槛）
1. **资质与认证合规**
   - 必须持有有效的《食品经营许可证》或《食品生产许可证》。
   - 拥有**ISO 22000**（食品安全管理体系）或**HACCP**（危害分析与关键控制点）认证。
   - 最好通过GLOBALG.A.P.（全球良好农业操作规范）认证，证明种植源头合规。

2. **源头追溯与农残控制**
   - 自有或签约种植基地需具备**二维码/批次溯源系统**，能实时追踪至具体果园和采收日期。
   - 提供每批次产品的**第三方农残检测报告**（如SGS、华测等），且符合国家GB 2763标准。超市常要求*抽检合格率100%*。
   - 明确提供采摘前**安全间隔期**记录，杜绝提前采摘导致农残超标。

3. **加工与分拣卫生标准**
   - 分拣车间需具备**恒温/低温环境**，防止交叉污染。
   - 包装材质必须满足**食品级标准**（PP/PE材质，有QS标识），并标注产地、保质期、储存条件。
   - 具备**金属检测/异物剔除设备**，并保留操作记录。

4. **质量分级与标准**
   - 必须严格执行超市指定的水果分级标准（如尺寸、糖度、硬度、外观瑕疵比例），提供**糖度检测仪**出库前自检数据。
   - 需配备**快速检测实验室**（针对二氧化硫、催熟剂等），因大型超市对水果保鲜剂残留要求高于国标。

---

### 二、物流与供应链能力（关键生存力）
1. **全程冷链能力（0-4℃/常温分季控制）**
   - 拥有或可控的**冷藏车**（车况需符合GSP标准），且具备**温度实时监控装置**（车载记录仪，数据可导出）。
   - **“最后一公里”保温措施**：配送至超市收货区时，车厢温度和果温需与收货标准一致（通常要求≤8℃），否则会被拒收。
   - 冷库需具备**温度分区控制**（如香蕉催熟库、苹果气调库），并有温度报警系统。

2. **精准配送时效**
   - 承诺严格的**摘-送时效**，例如生鲜类24小时内完成从果园到门店的上架。
   - 具备**多温层混载能力**（如冷冻、冷藏、常温同车分区），以减少转运损耗。
   - 提供**订单-库存可视化系统**，超市可实时查询在途车辆位置与温控曲线。

3. **损耗控制与应急机制**
   - 需证明水果**损耗率**控制在行业最低水平（如桃李类损耗率<5%），并具备成熟的分级销售策略（如次果转加工渠道）。
   - 建立**断货/掉链应急预案**（如备用冷库、替代运输商），承诺在超市促销档期内不可断供。

4. **物流追溯与交接规范**
   - 每车货须附**发货单+检测报告+温度记录**，超市收货时通过扫码联查。
   - 针对高价值水果（如车厘子、晴王葡萄），供应商需提供**海运/空运报关单**及原产地证明，确保无走私风险。

---

### 三、对大型超市的特别附加要求
- **周报/月报制度**：提供定期的质量投诉统计、退换货数据分析。
- **保险条款**：要求供应商投保**产品责任险**，保额通常不低于500万。
- **战略合作库存**：能接受“寄售”或“账期结算”模式，且能承担收货后7天内15%以内的自然损耗风险。

---

### 总结建议：
如果作为供应商，**先拿到HACCP认证并建立可追溯溯源系统**，这是硬门槛；**其次便是投入冷库和GPS温控车辆**，因为大超市往往通过“收货温度异常”直接判定不合格，而非仅看产品质量。若暂时不具备冷链车，可优先与大型第三方冷链物流商（如顺丰冷运、中外运冷链）签订长协，以证明此能力。
