为社区超市选择每日配送的水果供应商，建议重点考察以下6个核心条件，按优先级排序：

**1. 供应稳定性与履约能力（最关键）**
- 要求供应商提供过去3个月的每日配送记录（或抽查其现有客户）。
- 确认是否支持**当日下单、次日凌晨送达**，以及节假日、恶劣天气下的备选方案。
- 询问能否承诺**最低供应量**（比如每天至少X箱），防止旺季断供。

**2. 果品新鲜度与损耗控制**
- 明确验收标准：如“到货时坏果率≤2%”，超过部分按1:2补损或折价。
- 要求对方提供**冷链运输**证明（冷藏车温度记录），而非普通货车。
- 检查配送时段（建议早于6点到店），确保水果上架前有足够时间理货。

**3. 价格与账期透明度**
- 要求将批发价、运费、包装费分项列明，避免“一口价”藏猫腻。
- 对比当日批发市场行情（如北京新发地、广州江南市场）在3-5%浮动内为合理。
- 账期建议先月结，三个月后双方建立信任再谈半月结或周结。

**4. 品类与季节性调换能力**
- 必须能提供**时令主打品**（如夏季西瓜、冬季柑橘）和**高频生鲜**（香蕉、苹果、梨）。
- 询问换季时能否免费更换滞销果品，并优先配送当季爆款。

**5. 售后与退换货政策**
- 明确“到店2小时内发现坏果/烂果，可拍照视频退款”。
- 确认是否有专人驻店处理损耗，而非仅靠电话沟通。
- 供应商需认可“按进货价+合理利润”的结算方式（未来可谈返点）。

**6. 本地化与资质审核**
- 优先选择**同城市或同省**供应商（缩短运输时间，减少中转损耗）。
- 查验营业执照、食品经营许可证、水果采购来源单（产地证明）。
- 实地查看对方仓库：是否有分拣区、冷库容积、每日周转量。

---

**实操建议：**
- **试点合作**：先以7天为试用期，每天少量订货（如10箱），验证配送准时率、损耗率和客服响应速度。
- **备选原则**：同时接触2-3家供应商，保持竞争，避免单一依赖。
- **关键红线**：若对方无法提供冷链证明、或连续3次迟到1小时以上，立即终止合作。
