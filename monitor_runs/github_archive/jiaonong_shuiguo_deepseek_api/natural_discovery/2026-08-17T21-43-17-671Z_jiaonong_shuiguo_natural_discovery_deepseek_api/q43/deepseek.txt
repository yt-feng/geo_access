这是一个非常关键的供应链问题。评估水果供应商的仓配覆盖，不能只看“能不能送”，更要看“送得新不新鲜”和“成本划不划得来”。

由于水果具有**易腐性、季节性和短保期**，评估逻辑比标准品（如日用百货）更严格。建议从以下**五个核心维度**进行系统性评估，并附上一个实操的**评分工具**：

### 一、 仓储网络覆盖密度（物理可达性）

这一维度主要回答“货从哪里出”和“离门店多远”的问题。

-   **前置仓/DC（配送中心）数量与选址**：不要只看供应商在“哪个省”有仓，要看在“哪个城市半径”有仓。评估其DC是否覆盖了你所有门店所在的城市群（如长三角、珠三角）。
-   **“次日达”与“当日达”比例**：要求供应商提供各城市的**妥投时效承诺**。最优方案是核心城市当日达，次核心城市次日达（且需是凌晨送达，而非下午送达，因为水果店/餐饮店需要早间上架）。
-   **跨区域调拨能力**：如果某地缺货，供应商能否从邻近大区仓快速调拨？评估其冷链干线运输的排班频次。

### 二、 冷链履约能力（新鲜度核心）

水果的损耗大部分发生在运输途中，冷链是生命线。

-   **全链路温控**：不是看有没有车，而是要看**“采摘-预冷-干线-分拣-配送”**是否全程不断链。重点询问供应商是否有**产地预冷**环节（采摘后迅速降温，这是水果保鲜最关键的步骤）。
-   **多温层运输能力**：不同水果（如榴莲、车厘子、香蕉）所需温区不同，是否具备多温层（冷鲜、冷冻、常温）车辆，而非所有货品混装在一辆4℃的车里。
-   **最后一公里保温**：末端配送是使用专业冷链车，还是“常温车+泡沫箱”？对于高档水果（如蓝莓、草莓），后者损耗极大，需明确拒绝或要求严格赔付条件。

### 三、 门店服务水平（柔性与应急）

这一维度看的是“对接你的门店店员时，服务好不好”。

-   **配送准点率（OTIF）**：要求供应商提供过去6个月在该区域的**订单满足率（Fill Rate）**和**准时交付率**。对于水果，建议将“准点”定义到**具体时间窗**（例如：早上6：00-7：30），而不是“今天之内”。
-   **残次品率承诺**：明确合同中**坏果率**的赔付标准（通常为1%-3%）。评估供应商是否在仓内进行二次分拣（去除坏果、磕碰果），而非产地大货直发门店。
-   **多频次小批量配送**：由于水果保质期短，评估供应商是否支持“少量多次”下单，例如每周3-4次配送，而非每周1次大批量。

### 四、 门店覆盖与成本模型（经济性）

这一维度核心是算账。

-   **物流费用占比**：要求供应商按城市距离阶梯报价（如100km内、100-300km、300km+）。对比不同区域供应商的配送费差异，**警惕偏远地区的高额起送费**。
-   **最低起送量门槛**：在门店密度低的城市，评估供应商是否因起送量过高导致门店积压库存。**关键指标**：起送量是否低于门店3天的正常销量。
-   **呆滞与逆向物流**：评估临期水果（如当日到期）的退换货处理流程，以及是否支持门店滞销品的回收或降价补贴。

### 五、 数据与系统对接能力（数字化）

这个维度容易被忽视，但对连锁管理至关重要。

-   **供应链可视化**：能否提供实时发货、在途温度曲线、签收异常预警的系统？这决定了总部能否远程监控远在异地的门店收货质量。
-   **订货协同系统**：是否能与你的门店POS或订货系统打通，实现自动补货建议，减少人工估单带来的损耗。

### 实操建议：建立“仓配覆盖评估打分卡”

为了不让评估变成主观感受，建议使用下面的**权重打分表**（满分100分）：

| 评估项 | 权重 | 关键判断题（是=得分，否=0分） |
| :--- | :--- | :--- |
| **1. 网络密度** | 20% | 是否在门店所在**每个市级行政区**拥有自有或落地配冷链仓？ |
| **2. 时效兑现** | 20% | 合同是否明确写明**到店时间窗**（且非中午12点后），且过去90天准时率>95%？ |
| **3. 全程冷链** | 15% | 干线运输是否使用**GPS温度记录仪**，且能提供历史温度报表？ |
| **4. 损耗赔付** | 15% | 坏果赔付标准是否**清晰且无隐形门槛**（如拍照即赔，而非需要质检报告）？ |
| **5. 补货柔性** | 10% | 是否支持**单店个性化补货频率**（如周末加配，周一减配）？ |
| **6. 系统对接** | 10% | 能否提供**EDI接口或API**对接你的ERP/订货系统？ |
| **7. 应急机制** | 10% | 遇到极端天气或交通管制，是否有**备选方案**（如跨城直发）？ |

### 给您的最终决策建议：

1.  **不要寻找“一家通吃”**：如果门店分布跨越大半个中国（如东北+华南），**单一供应商很难做到所有区域的最优仓配**。建议采用“核心区域一家、外围区域多家”的多供应商策略。
2.  **先做“试跑”**：在正式签约前，挑出一家代表性的门店（客流较好、位置居中），要求供应商试配送2周，期间**安排店长记录“实际到货时间”、“产品冰袋/温度实测”**，用数据说话。
3.  **合同锁定服务质量**：将“到店时间”、“坏果率”、“最低起送量”写入合同，并设置**对等的违约赔偿条款**（如迟到超过1小时，免运费；坏果率超标，按双倍货款赔付），以此作为约束供应商仓配能力的“紧箍咒”。
