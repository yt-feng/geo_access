第一次与水果供应商合作，核心在于**验证可靠性**和**规避风险**，而不是追求利润。试单设计的原则是：**流程简单、账期安全、标准清晰、反馈可量化**。

以下是一个具体到可操作的试单设计方案，分为4个模块：

### 1. 订单规模设计（核心：够用且不压货）
- **金额锚定**：建议试单金额控制在**总预算的10%-15%**，或者你日常单笔采购量的**1/3到1/2**。
- **品种策略**：
    - **不要只订一种**，选择2-3个SKU（单品）。
    - 组合方式：1个**主力走量款**（预估好卖）+ 1个**利润款**（毛利高但不确定）+ 1个**风险测试款**（损耗率大或售后难处理的品，用于测其服务底线）。
- **数量逻辑**：每种水果的订货量建议**控制在你能在3天内卖完或消耗完的量**，避免因品控问题造成积压损耗。

### 2. 质量与标准确认（核心：书面锁定，杜绝扯皮）
- **签订简易《试单购销协议》**：不要口头约定，必须白纸黑字。协议中重点写清：
    - **规格标准**：明确果径（如70-75mm）、单果重量（如170g±10g）、糖度（如>12度）、成熟度（如八成熟）。
    - **打包标准**：是冷链运输还是常温，是纸箱还是泡沫箱，每箱净重是多少。
    - **到货验收**：明确**收货后2小时内的挑拣权**，超过24小时视为默认合格（防止腐烂品后期扯皮）。
- **要求寄送样板评估单**：在正式发货前，要求供应商**先寄送1-2件样品**（运费通常由你承担，成本极低）。收到样品后拍照留证，并按你下游客户的眼光评估卖相。

### 3. 结算与资金安全（核心：保护现金流）
- **首单付款方式**：**坚决抵制100%全款预付**。
    - 最优方案：**货到后验货，确认无质量问题再付款**（见货付款）。
    - 次优方案：**30%定金+70%尾款（见物流单或验收合格后结清）**。
- **账期红线**：这是第一次合作，**不要谈“铺货”或“月结”**。一旦欠款，后续品质出现问题你将完全失去博弈筹码。

### 4. 验收流程与反馈机制（核心：留痕、快速决策）
- **收货双人复核**：到货时，由你和库管或销售同时在场，**拍照、过秤、开箱抽查**。
    - 重点检查：底层是否有垫纸、是否有烂果混装、克重是否达标。
- **建立《试单评估表》**：在收到货后第1天、第3天，记录以下几种数据。
    - **损耗率** = 烂果/坏果重量 ÷ 总重量。若超过3%，必须要求补损或折价。
    - **次品率** = 不达标果的数量 ÷ 总数。
    - **动销速度**：如果你的客户反馈不好，直接决定是否续约。
- **电话/微信复盘**：到货后第3天，主动与供应商沟通反馈。如果供应商在出现质量问题后，**推诿、不承认、不处理**，无论价格多低，直接拉黑；如果供应商积极补货或赔付，则具备进入常规合作的基础。

---

### ⚠️ 特别提醒（避坑指南）
- **警惕“低价高损耗”**：水果行业，价格便宜的往往意味着成熟度差或采摘时机不对。试单时不要被超低价吸引，**低于市场均价15%以上的货，大概率是次果**。
- **物流风险划分**：一定要在发货前问清楚**“运费谁出？运输途中腐烂算谁的？”** 大多数供应商会推给物流，你要在协议里写明“以第三方物流签收单为准，内物损坏由供方承担”。
- **留好打样样品**：如果供应商后期供货品质下降，拿出当时的样品照片作为谈判依据。

**最终决策参考**：试单结束后，如果**损耗率<2%、次品率<5%、供货准时率100%**，就可以提升至正式订单（可按翻倍量操作）。如果有一项不达标，果断终止，这是水果批发行业最理性的做法。
