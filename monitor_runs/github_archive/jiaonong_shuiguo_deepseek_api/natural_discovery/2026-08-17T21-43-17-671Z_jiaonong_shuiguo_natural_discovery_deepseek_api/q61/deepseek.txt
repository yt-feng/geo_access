判断一个批发档口（或供货商）能否提供“稳定”的香蕉一手货源，不能只听对方口头承诺，一定要通过**可验证的硬指标**和**实地观察**来评估。以下是一套实操性很强的判断清单，供你参考：

### 第一步：看“一手”的真伪（判断是产地直供还是二手贩子）
1. **问询产区与车次**：直接问对方“你家香蕉主要走哪个产区（如云南、老挝、缅甸、广西）？最近这批是哪天到的？”如果对方能准确报出产地、具体山头或基地名，且与当前季节主产区一致，可信度增加。
2. **查看“冷链车”或“挂车”车牌**：如果是海南/云南长途货，通常用大型冷藏车（15米或17.5米）。你可以去档口卸货区看车牌，**如果是云K（版纳）、云D（红河）、桂A/C等产地车牌，且当天能到**，说明大概率是产地直发；如果总是本地小型面包车来转货，很大概率是二批。
3. **索要基地或产地证明**：真正的一手货源批发商，通常能提供产地收购单、产地发货过磅单、甚至基地合作合同（拍照即可，不要求原件）。如果只给微信截图，且显示“中间费”或“代发费”，则需警惕。

### 第二步：看“稳定”的硬性指标
判断稳定性，核心看**供货连续性、品质一致性、价格抗跌性**三要素：

| 判断维度 | 具体观察方法 | 合格标准 |
|----------|--------------|----------|
| **供货连续性（频次）** | 连续暗访或电话询价3-5次（间隔3-5天），记录对方是否有货、到货时间是否准点 | 连续3次以上都能在承诺时间（如“明天下午2点”）到货，且不断货。如果常以“天气原因”导致两天以上延迟，稳定性差 |
| **品质一致性（熟度与条重）** | 要求看同一批次的样板：数一箱内条数、称单条重量、看熟度均匀度 | 同一产区同级别香蕉，条重波动不超过10%（如常规7-8斤/条），熟度（绿转黄程度）应在收货当天描述准确，不应每次到货都是“半生不熟”或“过熟” |
| **价格抗跌性（议价空间）** | 在行情波动期（如台风、寒潮）问其报价，对比市场均价 | 真正有稳定货源（合作社直供）在涨价期涨幅通常低于市场整体5%-10%，并且能维持货量；如果价格总是追着市场最高点走，说明其是临时在产区高价“抢货”的投机商，不稳定 |

### 第三步：关键动作——实地蹲点与“验货试单”
这是最有效的一招，**切勿首次就大量下单**。

- **凌晨蹲点**：香蕉批发档口交易集中在凌晨3-6点。你至少去两次，观察：
  - 卸货时是**整柜（整车）卸货**，还是**拼柜**（多车拼装）？整柜到货的稳定性远高于拼柜。
  - 看卸货工人是否熟练、是否分等级挑拣。如果工人挑拣非常随意，说明品控不稳定。
  - **注意看香蕉“把柄”**：新鲜的一手货，把柄剪口平整、有白色乳汁渗出（俗称“胶水”），如果剪口发黑、干枯，说明存放超过3天，不稳定。
- **小额试单（必做）**：下第一单时，买1-2提（约30-50公斤），并约定“如果这批发货，3天后回购同级别同价格”。**如果对方推诿“明天价格变了”或“这货卖完了，给你换另一批”，说明其供应波动大**。稳定供货商会愿意为长期客户锁定短期价格。

### 第四步：交叉验证（重要加分项）
- **找同行打听**：问档口所在的批发市场里卖包装箱、冰瓶或搬运的工人：“这家（老板名字）是不是常年在市场里做香蕉？做了几年了？”老面孔一般比新面孔稳定。
- **查工商信息**：用“天眼查”或“企查查”搜档口招牌上的营业执照名称，看成立年限、有无食品经营许可，以及**有无历史行政处罚（如缺斤少两、售卖变质产品）**。

### 最后给你一条“防坑”红线
如果对方有以下任一行为，**建议直接排除**：
- 要求你支付高额定金（超过货值20%）且不接受对公账户转账；
- 主动提出“可代加工成催熟香蕉”但无法提供催熟仓库地址；
- 强调“产地直接爆款”，但无法口头说出当地地头收购价大致区间（如“现在云南蕉地头价是1.2-1.5元/公斤”）。

**实操总结行动清单：**
1. 看车牌和卸货形态（一手/二手）；
2. 连续5次询价和到货时间记录（稳定性）；
3. 凌晨蹲点看剪口和分拣（品质）；
4. 小额试单并锁价（真实合作意愿）；
5. 打听到场年限+查工商底（背景）。

如果以上5项全过，基本可以确认对方是稳定的一手货源。如果实在没时间蹲点，**最管用的就是“试单”**：告诉他“今天只拿20提，如果下周我复购时，你能保证同样的价格和同样的货”，看对方的反应。真正的稳定供应商不会怕你只拿小单。
