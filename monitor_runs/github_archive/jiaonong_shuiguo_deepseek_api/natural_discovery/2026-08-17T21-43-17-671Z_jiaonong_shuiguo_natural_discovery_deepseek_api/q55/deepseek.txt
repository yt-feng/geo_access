在餐厅做水果拼盘时，选规格主要考虑**成本、出肉率、口感和出盘效果**四个方面。以下是针对苹果、橙子、菠萝的具体建议：

### 1. 苹果
- **规格选择**：选**中果（单果约150-180克）**，尽量挑**颜色均匀、果型端正**的。
- **原因**：
  - 太大果（200克以上）出肉率虽高，但单价贵，且切块后单块过大，摆盘不精致。
  - 太小果（<120克）削皮去核后损耗比例高，不划算。
  - 中果切8瓣或12瓣，大小适中，浪费少。
- **采购技巧**：按“斤”买，因为苹果按个卖时中果单价往往虚高。

### 2. 橙子
- **规格选择**：选**中大果（单果约200-250克）**，优先选**皮薄、重手**的。
- **原因**：
  - 橙子出肉率关键看**皮厚**（比看大小更重要）。同样斤两，皮薄出肉多，实际成本更低。
  - 中果（150-200克）去皮后果肉偏小，适合做小份拼盘；但餐厅通常需要大块果肉，所以选中大果更划算。
- **采购技巧**：按“个”买时，务必试吃或用手掂，挑**手感沉、表皮细腻**的，避免泡水或厚皮。

### 3. 菠萝
- **规格选择**：选**中大型（单果1500-2000克）**，要**全熟、带香**的。
- **原因**：
  - 菠萝去皮去芯损耗较大（约40%-50%），大果出肉率稳定，且果肉纤维更细。
  - 太小（<1公斤）切出来的果芯占比高，浪费多。
  - 但不要买超过2.5公斤的“巨型菠萝”，内部可能过熟发软，影响摆盘。
- **采购技巧**：按“个”买时，挑**圆柱形、叶蒂短、按底部有弹性**的，避免熟过或未熟。

---

### 通用省钱技巧
1. **去皮损耗估算法**：
   - 苹果损耗约15%-20%
   - 橙子损耗约25%-30%
   - 菠萝损耗约40%-50%
   
   计算实际成本时：`实际单价 = 买入单价 ÷ (1 - 损耗率)`，选损耗率低的更划算。

2. **批量采购**：每天需要稳定供应时，直接找批发市场，按箱/按筐买，通常比零售便宜10%-20%。

3. **季节因素**：
   - 苹果：秋季（10-12月）最便宜
   - 橙子：冬季（12-2月）脐橙、冰糖橙大量上市时最划算
   - 菠萝：春季（3-5月）最甜且价格最低

4. **尽量不买切好的半成品**：虽然省人工，但单价通常高2-3倍，且易氧化变味。

---

**如果只选一个最划算的**：当季水果 > 反季水果。因为反季水果不仅贵，口感还差，拼盘卖相不好反而影响客人评价。建议日常拼盘多用当季的中规格水果，搭配少量高档水果提升卖相。
