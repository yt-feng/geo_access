这个问题很实际，直接关系到出品稳定和成本控制。我的建议是：**不要绝对固定，而应建立“分级+框架”的供应策略。**

具体执行建议如下：

**1. 核心策略：固定“供应链框架”，而非固定“单一产地”**

- **固定供应商层级**：与2-3家大型、有稳定货源的一级供应商建立长期合作，而不是只找一家。
- **固定“风味基线”**：明确你所需水果的核心指标，例如：**糖度、酸度、水分含量、香气浓度**。比如芒果，你要的是“甜度18-20度、有浓郁果香”，而不是必须“海南金煌芒”。这让你在产地间切换时有客观依据。

**2. 实战操作：分季节、分品类管理**

- **季节性明显的品类（如杨梅、荔枝）**：必须固定到**特定产季+特定产区**（例如：福建浮宫杨梅初期、广州增城荔枝中期）。因为风味窗口期短，不同批次的差异可能巨大。
- **全年供应品类（如柠檬、橙子、西瓜）**：固定**供应批次**，即要求供应商提供**“同一果园、同一采收周”**的批次。若换批，必须提前48小时通知，并允许你进行小样测试。

**3. 规避风险的关键动作**

- **建立“盲测”制度**：每次新批次到货，让店长和主厨盲测对比，不是看产地，而是看“这杯茶饮做出来风味是否达标”。
- **设置“缓冲库”**：常用水果保持3-5天的安全库存，用以抵消切换批次时的风味波动期。
- **合同中写明“批次波动赔偿条款”**：如果因批次问题导致出品风味不达标，供应商需承担部分损耗或调换货，这会倒逼对方保障质量。

**结论**：**固定“风味标准”和“供应商考核机制”，灵活选择“产地和批次”**。这样既能利用不同产地的优势，又能防止被单一产地或批次“绑架”，导致口味被动起伏。

如果在实际操作中，你发现某款水果（比如百香果）在淡旺季差异过大，可以考虑**调整配方比例**（淡季多用一点或搭配其他水果调香），而不是死磕一个产地。
