社区团购旺季“爆单”前，和水果供应商锁定库存，核心是**用确定性换取优先权**。不要只靠“多打电话”，要用合同+数据+资金三个抓手来提前锁定。

以下是可直接落地的五个步骤，以及话术建议：

**第一步：提前2-3周，做“阶梯式”锁库，而非一刀切**
旺季前，不要一次性锁死全部需求，容易压货。建议分三批：
- **第一批（提前3周）：** 锁核心爆品（如阳光玫瑰、秋月梨等）总量的**50%**，确保底线不断货。
- **第二批（提前2周）：** 根据预售/接龙数据锁**30%**。
- **第三批（提前3-5天）：** 锁剩余20%，根据实时销量加单。
这样供应商能提前规划采摘，你也规避了空库风险。

**第二步：签“保量保价”协议，明确毁约赔偿**
光口头说“我要10000斤”没用，旺季供应商会把货卖给高价渠道。你需要和供应商签**书面协议**，关键条款只需写清三点：
1. **保价：** 锁定当前批发价，**约定遇市价涨幅超过10%时，可协商调价，但涨幅上限不超15%**（防止供应商见利忘义）。
2. **优先权：** 注明“**同价位下，我方拥有供货优先权**”，且到货时效需明确（如“下单后24小时内送达”）。
3. **违约责任：** 供应商延迟或缺斤短两，需赔付**30%定金作为违约金**。

**第三步：支付“诚意定金”，锁定冷库与分拣产能**
水果旺季，供应商最怕的是“你吹牛要货，结果他没地方存”。你需要：
- 随协议支付**20%~30%的定金**（无定金不锁库）。
- 如果条件允许，**额外加付10%“冷库占用费”**，明确要求供应商为你的货预留专属冷库库位。
这样即使有人出更高价，供应商考虑到冷库空置风险，也会优先给你供货。

**第四步：用“预售数据”反向给供应商吃定心丸**
供应商担心你卖不掉。你可以提前在社群做“爆品预售”：
- 提交一份**《预售统计表》**给供应商，上面写清楚“已收用户定金XX单，预计首日消化XX斤”。
- 告诉供应商：“我们预计首日就能消耗首批货的50%，剩余会在48小时内售罄，绝不砸在库里。”
这会让供应商认为你的履约能力可靠，愿意多给你留优质果。

**第五步：关键话术与沟通节奏**

- **开场话术（避免被敷衍）：**
  “张总，今年旺季我们社区渠道预计日销3000单，我这边提前**付全额定金**（这里指协议约定的定金），**只要你在我的截单时间前保证不掉链子，价格咱们好谈。** 但我需要你给我一个明确的书面答复：**我的量能不能在冷库最前排？**”

- **沟通频率：** 锁库协议签订后，**每周一、周四固定两次进度同步**，让供应商帮你拍照确认冷库库存状态，建立“神秘顾客”式的监督。

**⚠️ 重要注意事项：**
如果供应商是中小型农户，**不要签过于复杂的法律合同**，他们看不懂也不敢签。只需要用**定金微信转账+备注姓名+打款截图留存**，并附上一句“**此定金用于锁定X日X品种X斤库存，若贵方违约需双倍返还**”，在微信上留痕即可，同样具备法律效力。

最后提醒：锁定库存时，**别把所有鸡蛋放在一个篮子里**。保留一个“替补供应商”关系，平时给其少量订单维持热度，旺季关键时刻作为应急备用。
