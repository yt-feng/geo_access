商超做会员日水果活动时，供应商的配合程度直接影响活动的销量和口碑。建议供应商从以下五个关键维度提前准备，避免出现断货、损耗或服务跟不上等问题：

**一、货源与品项准备（核心）**
1. **爆品锁量**：提前锁定3-5款引流爆品（如应季西瓜、榴莲、车厘子等），签订锁价协议，确保会员日价格优势。
2. **备货系数**：建议备货量为平日同品类销量的2-3倍，特别是临期前48小时必须到仓，避免活动当天断货。
3. **品项分级**：区分引流款（低毛利走量）、利润款（中高档礼盒）和补充款（异形果/小众果），满足不同客群。

**二、物流与到货计划**
1. **分批到货**：活动前1天到60%货品，活动当天清晨补40%新鲜货，保证早晨开门时货架新鲜度最高。
2. **应急补货机制**：提前沟通好当天下午补货的响应时间（建议不超过4小时），防止热门单品晚间空架。
3. **冷链衔接**：确认冷藏车温度记录、到店卸货时间，确保水果中心温度始终处于保鲜区间（如叶菜0-4℃，热带水果10-15℃）。

**三、品质与损耗控制**
1. **三级验货**：供应商发货前自检+商超收货抽检+上架前理货，剔除磕碰、过熟果。
2. **损耗承诺**：提前和商超确认**损耗补偿比例**（一般损耗率控制在5%-8%以内），超出的部分由供应商承担或补充新品。
3. **定制化包装**：针对会员日特殊要求（如切片试吃装、小份家庭装），提前准备预包装物料。

**四、陈列与营销配合**
1. **堆头规划**：提前给商超提供堆头搭建效果图和陈列道具（如异形堆头、灯光装饰），并明确主打品在C位。
2. **试吃与促销员**：活动当天需安排至少1-2名熟悉水果卖点的促销员，现场提供去皮、切块、榨汁服务，并引导试吃转化。
3. **价签与话术**：配合商超更换醒目的爆炸贴、会员价签，并准备3-5句产品核心卖点话术（如“这颗凤梨甜度14度，现切现吃”）。

**五、售后与数据复盘**
1. **快速售后响应**：设立活动专属客服，会员日当天退换货响应需在1小时内解决，避免差评发酵。
2. **实时销售数据共享**：活动当天每2小时同步一次品类销量和库存数据，方便供应商调整下午补货结构。
3. **次日复盘**：活动结束第二天提交损耗表、周转率、会员转化数据，为下月会员日制定更精准的供货计划。

**特别提醒：**
- 提前一周**书面**确认活动协议，明确双方责任边界（如自然损耗率、最低供货量、价格保护期）。
- 提前准备好**检测报告**（农残、糖度），会员日也是商超应对市场监管抽查的高风险时段。
- 如遇暴雨、台风等突发天气，提前准备替代货源方案，确保活动不空场。
