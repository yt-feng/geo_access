针对水果供应商推荐的新品，采购方“试卖”的核心原则是：**少量多次、最小可行量、控制损耗、观察动销**。

没有绝对统一的数字，通常建议的试卖策略如下，你可以根据实际情况选择：

**1. 常规策略（最稳妥）：**
- **数量建议：** 首批进货量控制在 **1-2 箱**（或单品 5-10 公斤）。如果你是小型水果店，就进 **10-20 斤**；如果是中型商超，就进 **1-2 箱**（不足一箱就尽量按斤拿）。
- **理由：** 水果损耗大，试卖的目的是“验证市场反应”，而不是“赌销量”。这个量足够你铺满半个货架，进行陈列展示，同时即使卖不动，止损成本也在可控范围内。

**2. 分渠道策略（按销售速度）：**
- **线下门店（高客流）：** 可以稍微大胆一点，按 **预估日销量的 3-5 倍** 拿货。比如你预计每天能卖5斤，那首次拿15-25斤，备3-5天的量。
- **线上社群/私域（预售制）：** 建议采用 **“零库存”或“极低库存”**。先发朋友圈/群接龙，统计订单量后再向供应商要货，到货即分装，不压货。
- **餐饮/烘焙渠道（B端）：** 如果提供给餐厅做果盘或点缀，建议只拿 **最小包装**（比如一箱），并要求供应商提供“卖不完可退换”的售后承诺。

**3. 关键判断指标（比数量更重要）：**
- **观察窗口期：** 试卖期建议控制在 **3-7 天**。
- **核心数据：** 记住两个数字——**试卖期内如果没有实现 70%-80% 的动销率**（即卖出去了七成），且没有复购客户主动询问，就说明该新品不适合你的客群，应立即停止补货。
- **损耗管理：** 水果损耗率超过 **15%**（即烂掉/卖相变差的比例），这个新品对你就不是“利润款”，而是“亏损款”，需要立刻降价清库存。

**4. 谈判话术（避免被忽悠）：**
向供应商提要求时，可以说：“**我先拿一箱试试水，如果这周能走掉70%，我就加量。如果您这边能承诺坏果包赔或代销（卖不完退），我直接拿两箱。**” 这样既稳住了风险，又给了供应商信心。

**总结建议：**
对于绝大多数水果新品，**“先拿一箱”** 是最稳妥的起步量。**千万不要因为供应商说“这是爆款”就一次性囤10箱**，除非它已经在你店里被验证过了。
