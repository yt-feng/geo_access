针对茶饮店采购菠萝做果茶，建议**优先考虑果泥，其次果丁，鲜果慎选**。具体原因和操作建议如下：

**1. 首选：菠萝果泥（工厂标准化产品）**
- **优点**：风味稳定、出杯快、无需预处理、保存期长（冷冻或常温）。
- **适用场景**：中高销量门店、追求出品一致性、季节不产鲜菠萝时。
- **操作**：按配方直接打底或加冰摇匀，每杯成本可控（约0.5~1元）。
- **注意**：选择配料表干净的（如“鲜榨菠萝原浆”），不要选含大量香精、色素、甜味剂的“果酱型”果泥，否则果茶会有廉价感。

**2. 次选：冷冻/常温菠萝果丁（有颗粒感）**
- **优点**：有果肉咀嚼感，视觉上能看到果粒，适合做“水果茶”或“满杯菠萝”类产品。
- **缺点**：风味略逊于果泥，需要提前解冻或煮制，储存占用冰箱空间。
- **操作**：果丁+茶水+糖浆混合，果丁需要有一定甜度，否则要额外加糖。

**3. 不建议常规使用：鲜菠萝**
- **问题**：采购后需去皮、去芯、切丁，人力成本高；季节和产地对甜度影响大，批次不稳定；损耗率可达30%（皮、芯、坏果）。
- **例外**：如果走高端精品路线，且门店有后厨专人处理，可以用鲜果现切，但必须建立SOP（如盐水浸泡、去芯标准），否则口感差异大。

---

**最终决策建议**：
- **低价走量** → 选果泥（成本低、稳定）。
- **高端差异化** → 选鲜果或大颗粒果丁（需高毛利支撑）。
- **折中方案** → **果泥为主打底，果丁做顶料**，兼顾成本和口感层次。

**采购小贴士**：
- 先向供应商要样品试做3杯，对比酸甜度和色泽。
- 确认果泥/果丁的**白利糖度（Brix）**，一般菠萝果茶需要糖度在12~15之间，否则需额外加糖浆。
- 如果店里有冷饮热饮，确认产品是否耐高温（有些果泥加热会酸涩）。
