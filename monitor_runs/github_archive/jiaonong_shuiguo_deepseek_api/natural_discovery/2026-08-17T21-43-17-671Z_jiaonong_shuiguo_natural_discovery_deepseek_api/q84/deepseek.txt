针对家庭水果礼盒，我的建议是**“一个主（大果）、一个解腻（酸/甜）、两个软硬搭配”**的组合逻辑。

**推荐组合方案：**

**方案A：均衡型（最推荐，适合多数家庭）**
- **苹果 4-5个**（脆甜，耐储存，老人小孩都能吃）
- **橙子 3-4个**（补充维C，橙香浓郁，切开香气足）
- **香蕉 2-3根**（软糯，即食，适合早餐或孩子加餐）
- **菠萝 1个**（无眼菠萝，去皮后直接切块，增加节日/特殊口感）

> **理由**：苹果和橙子是硬果，香蕉是软果，菠萝是风味果。甜度有层次（苹果蜜甜、橙子酸甜、香蕉糯甜、菠萝清香），且保存时间从短到长（香蕉先吃、菠萝次之、苹果橙子最后），避免一起坏掉。

**方案B：轻奢尝鲜型（预算稍高，追求少见）**
- **苹果（红富士/阿克苏）3个 + 橙子（赣南/纽荷尔）3个 + 香蕉1把 + 菠萝肉（预切盒装）**
> 菠萝预切好，省去家庭处理麻烦，且个头不用太大，主打新鲜感。

**方案C：性价比型（家庭量大，追求实惠）**
- **苹果6个 + 橙子5个 + 香蕉4根 + 小菠萝2个（或凤梨1个）**
> 小菠萝甜美多汁（建议选海南小菠萝），比大菠萝更适合家庭分食，不浪费。

---

**重要提示（直接影响体验）：**
1. **香蕉别放多**：香蕉熟得快，放多了容易压坏或放烂。建议放2-3根，且放在礼盒最上层，不要被苹果压伤。
2. **菠萝选“无眼”或“凤梨”**：普通菠萝要挖眼，很多家庭嫌麻烦。如果没法保证是凤梨，建议切好装盒。
3. **不要放同质果**：比如不要用梨替代苹果（水分不同），也不要把葡萄放进去（易掉粒）。
