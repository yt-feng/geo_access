水果店旺季想避免断货，和供应商谈判时，重点要问的不是“能不能供货”，而是**“万一断了怎么办”以及“怎么保证优先供我”**。以下5类核心问题，建议分步问清：

---

**一、产能与备货能力（判断旺季是否有货）**

- “旺季（特别是节假日）你们的最大日供货量是多少？能持续几天？”
- “你现在还有哪些水果库存紧张？估计何时能补上？”
- “如果临时加单（比如突然爆单），从下单到送达最快需要多久？加急费怎么算？”

**二、供货稳定性与优先级（判断谁先断货）**

- “旺季时，你同时供几家客户？如果有多个订单冲突，怎么分配货源？”
- “有没有书面承诺或保供条款，保证我的店在旺季优先满足？如果断供，赔偿或扣款怎么算？”
- “有没有备用产区或替代供应商？如果本地下大雨/台风，你能从哪调货？”

**三、价格与波动机制（避免旺季被宰）**

- “你的价格是随行就市还是锁价？如果涨，通常提前几天通知？”
- “旺季价格上浮的区间大概是多少？有没有保底价或阶梯价？”
- “付款账期能延长吗？旺季我现金流紧张，能否压一批结一批？”

**四、品控与损耗责任（避免拿坏果）**

- “旺季到货的次果率标准是多少？如果到手有熟烂果，怎么赔付或补货？”
- “如果运输延迟导致水果不新鲜，算谁的？能退换吗？”
- “你能不能提供定期到店抽检服务，或者售后快速响应？”

**五、送货与售后细节（避免掉链子）**

- “旺季你们送货时间怎么安排？能保证每天固定时间到吗？能不能加急早班？”
- “如果当天卖断了，紧急补货能不能当天送达？最晚几点下单？”
- “有没有建立微信群或专用联系方式，断货时能第一时间更新库存信息？”

---

**额外建议：**
- 谈之前先算清楚自己旺季的日均销量和峰值销量，带着数据去谈，对方会更重视。
- 最好同时谈2家供应商（一家主供，一家备选），但别全押一家。
- 最重要的一条：**所有承诺，哪怕口头讲的，尽量在工作群里用文字再确认一遍**，保留记录。旺季靠情面不如靠合同。
