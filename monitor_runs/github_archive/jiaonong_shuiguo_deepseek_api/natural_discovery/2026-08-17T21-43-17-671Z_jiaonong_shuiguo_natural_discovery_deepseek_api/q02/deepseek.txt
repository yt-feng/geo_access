对于小水果店进香蕉，**应该最看重“坏果率”和“熟度”**（两者并重），价格和送货速度为次。原因如下：

**1. 熟度最关键：控制损耗和销售窗口**
- 香蕉是典型的“后熟型”水果，到货太生（全绿）顾客不会买，太熟（黑斑多、果肉发软）当天卖不完就会烂。
- **建议**：要求供应商发货时熟度控制在“八成熟左右”（果身微黄，果柄仍青绿），这样到店后常温放置1-2天正好达到最佳食用状态，可以卖2-3天，损耗最低。

**2. 坏果率直接决定利润**
- 香蕉在运输中极易挤压、撞伤，如果整箱坏果率超过3%-5%，损失往往超过价格优惠带来的差价。
- **操作建议**：进货时当场抽检一箱底部和整箱重量（香蕉很重时可能注水或带枝过多），签订“坏果按比例赔付”条款，底线是坏果率超过5%要求退货或补货。

**3. 价格要让位于“综合毛利”**
- 香蕉是走量引流品，毛利本身不高。如果价格低但坏果率高，算下来单斤成本反而更高。
- 建议：不要只看单价，计算“实际可售重量成本”。例如：50元/件（30斤），坏果5斤，实际可售25斤，折合2元/斤；如果55元/件但坏果1斤，可售29斤，折合1.9元/斤。后者更划算。

**4. 送货速度可协商，不追求“最快”**
- 香蕉不能存冰箱，到货后要尽快卖，但一般一天内送达即可。真正要关注的是“冷链是否全程不断链”（夏天尤其重要，否则到货会熟过头）。
- 如果供应商能保证“下单后次日中午前到货”，且能提供保温包装，就足够了。追求半日达反而可能增加物流碰撞风险。

**总结建议（优先级从高到低）**：
1. 熟度：明确要求“八成熟，果柄青绿”
2. 坏果率：约定坏果补偿，现场抽检
3. 价格：按“可售净重”核算单价
4. 送货速度：保证次日达+保温即可

最后，小水果店建议每次少量、分批进货（比如一次进2-3天的量），即使单次价格稍高，也远好于一次性大批量导致熟过头报废。
