在超市采购水果时，为应对市场监管部门的农残抽检，建议提前向供应商索取并核验以下核心资料，并注意分类留存：

**一、必备的法定资质与批检报告（必不可少）**
1. **供应商营业执照**（经营范围内需包含水果销售）。
2. **食品经营许可证**（或备案证明）。
3. **本批次水果的《食用农产品合格证》**（即“一证”，部分产地为承诺达标合格证，必须与到货批次一致）。
4. **本批次的《农药残留快速检测报告》**（需由供应商自检或委托第三方出具，检测项目应至少包含有机磷和氨基甲酸酯类）。

**二、针对高风险水果的特定佐证（提高抽检合格率）**
5. **产地证明**（如产地村委会/合作社出具的产地证明，或运输单据、发货单，能追溯到具体种植基地）。
6. **种植环节用药记录**（若为基地直采，要求提供最近一次施药日期及农药名称，便于评估安全间隔期）。
7. **绿色食品/有机认证证书**（如果采购的是认证产品，需索证并在包装上核对认证标志）。

**三、可追溯性关键单据（应对抽检溯源）**
8. **购货凭证**（发票、收据、转账记录，必须写明品名、数量、供货方名称）。
9. **入货查验记录**（超市内部填写的到货验收台账，记录感官检查、索证情况）。
10. **运输温度及车辆信息**（虽与农残关系不大，但属于冷链抽检环节的佐证材料）。

**四、操作建议（提高应对效率）**
- 上述资料中，**第1、2、3、4项**是抽检时必查的“硬指标”，缺一不可。
- 在采购合同中**明确约定**：若因农残超标导致抽检不合格，供应商须承担全部退货及市场监管处罚责任，并赔偿损失。
- 每次进货前**要求提供当批快检报告**（短信或邮件发送），不要用上一批次的替代。

**五、特别提示（快速核验技巧）**
- 查看快检报告上的**样品名称、生产日期/批次号**是否与实物包装标签完全一致，防止“张冠李戴”。
- 对于**草莓、叶菜类（如菠菜、芹菜）、豇豆**等风险较高品种，建议额外要求供应商提供**定量检测报告**（即实验室GB 2763标准全项或重点项），而不仅仅是10分钟快检的定性报告。

如供应商拒绝提供第1、2、3项资料，该批货应**坚决拒收**，并将其列为风险供应商进行淘汰。
