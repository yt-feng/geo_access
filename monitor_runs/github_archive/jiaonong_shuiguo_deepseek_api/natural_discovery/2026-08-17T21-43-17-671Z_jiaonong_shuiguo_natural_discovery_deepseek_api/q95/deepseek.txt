为学校食堂采购香蕉、苹果、橙子这类常见水果，选择供应商的核心是**安全、稳定、性价比**。以下是可执行的分步建议：

**第一步：明确基础硬性条件（排除法）**
1. **资质合规**：必须要求供应商提供营业执照、食品经营许可证（或流通许可证）。如果是批发商，还需提供水果产地证明和农残检测报告（每批次）。
2. **配送能力**：确认供应商能否保证**每日或隔日送达**，且具备冷链车（夏天尤其重要，防止水果高温变质）。
3. **退换货机制**：明确损耗率标准（例如单次损耗超过5%可免费补货），并约定变质水果的赔付流程。

**第二步：实地考察与试单（关键动作）**
1. **看仓库与冷链**：实地查看其仓库是否干燥通风，是否有冷库。如果仓库杂乱、有苍蝇或酸腐味，直接淘汰。
2. **索要样品试吃**：分别要求提供当季的香蕉（注意成熟度，不能过生或过熟）、苹果（脆度）、橙子（甜度和水分）。
3. **小批量试单**：连续试订3次（例如每次订50-100斤），观察**到货完整度**和**质量稳定性**。如果第一次好、第二次差，说明管理不稳定，不建议长期合作。

**第三步：比价与报价单（谈合同）**
1. **要求报价单细化**：必须包含**品种、规格（如一级果/二级果）、产地、单价（元/斤）、配送费、发票税率**。不要只给总价。
2. **对比市场均价**：去当地果品批发市场（如新发地、本地农批市场）询价，了解当日行情。低于市场价20%以上的报价要警惕（可能是库存次果或短斤少两）。
3. **合同锁定价格周期**：水果价格波动大，建议每2-4周根据批发市场行情调整一次价格，而不是固定整学期价格。

**第四步：建立复检与淘汰机制（长期监督）**
1. **到货验收标准**：每次收货由食堂管理员和厨师共同验收。香蕉要求**无黑斑、无压伤**；苹果**无碰伤、无虫眼**；橙子**皮紧实、色泽均匀**。
2. **设置“红黄牌”制度**：如果供应商出现3次质量问题（例如混入烂果、缺斤短两），黄牌警告；累计5次直接中止合作，启用备选供应商。
3. **定期抽检农残**：即使供应商提供了检测报告，建议每学期花几百元送第三方机构抽检1次（如当地疾控或检测公司），留存报告备查。

**特别提示（本地化建议）**
- 优先选择**本地或邻近产区的果园直供商**，运输时间短，损耗小，价格也更优。
- 如果学校规模较大（每餐超过500人就餐），可以**同时选择2家供应商**（一主一备），防止单一供应商断供或抬价。
- 不要只看“最便宜”，学校食品安全责任重大，一旦出问题，罚款和声誉损失远超省下的采购成本。
