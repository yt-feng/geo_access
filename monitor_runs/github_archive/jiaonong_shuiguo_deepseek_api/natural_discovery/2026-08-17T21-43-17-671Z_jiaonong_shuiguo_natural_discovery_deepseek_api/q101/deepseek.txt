针对酒店早餐水果供应这一细分业务，以下是与供应商谈判和合作时的核心注意事项，按“供应链稳定性”、“品质与成本”、“风险与合规”三个维度展开：

**一、供应链稳定性（核心诉求）**

1. **明确最低供货量与浮动机制**
   - 约定每日/每周的**保底采购量**（例如每天50公斤），低于此量供应商必须保证供应。
   - 设定周末、节假日、大型会议（如婚宴、团队入住）的**突发增量预案**（例如提前48小时通知，供应商需在4小时内补货）。

2. **固定采购时间与配送窗口**
   - 明确早餐备餐时间（如每天凌晨5:00前送达），避免因晚点打乱后厨节奏。
   - 规定卸货后需由供应商负责**搬运至后厨指定区域**，并清理废弃包装。

3. **应急预案**
   - 要求供应商提供**备用货源渠道**（如第二产地或同城调货商），并在合同中写明“断货时至少提前12小时通知，且提供同等规格替代品”。

**二、品质与验收标准（决定早餐体验）**

1. **水果规格书面化**
   - 明确单果重量范围（如苹果200-250克）、成熟度（八成熟）、糖度（Brix≥12）、农残检测标准（符合GB 2763）。
   - **特别注意：** 早餐常用水果（如香蕉、猕猴桃）需避免催熟剂，要求供应商提供“未使用乙烯利催熟”的书面承诺。

2. **损耗率与退换货规则**
   - 规定到货时的**容损率**（通常≤5%），超过部分由供应商承担。
   - 签订“24小时无条件退换”条款，对切开后发现内部黑心、烂芯的水果，供应商须免费换货。

3. **批次检验留样**
   - 每批水果随机抽检5-10个，双方签字确认后拍照留档。若有争议，可委托第三方检测机构仲裁。

**三、成本与账期（谈判重点）**

1. **价格锁定机制**
   - 建议采用“**季度固定价+月度微调**”模式，避免因季节波动导致成本失控。
   - 若市场价短期暴涨（如台风后香蕉价格上涨），约定涨幅超过**10%**时需提前3天书面通知，并允许酒店临时减少订单量。

2. **账期与付款条件**
   - 常见账期为30天（月结）。可以争取“**周结月清**”（每周结算一次，月底付清），降低供应商资金压力，换取更优价格。
   - 明确发票类型（专票或普票），避免后期财务纠纷。

3. **增值服务捆绑**
   - 要求供应商免费提供**月度水果消耗分析报告**（如哪种水果损耗高、性价比差），或提供换季新品种试吃，计入谈判筹码。

**四、合同关键条款（务必白纸黑字）**

| 风险点 | 合同条款建议 |
|--------|-------------|
| 断供风险 | 约定“单次断货赔偿当日采购金额的30%，连续断货2次，酒店有权终止合同并追偿损失” |
| 食品安全 | 要求提供每批次**进货检验报告**（含农残、重金属），并承担因水果引发食安事故的全部责任 |
| 价格变动 | 明确调价触发条件（如市场价波动±15%），并设置**调价通知期限（7天）** |
| 竞业限制 | 若供应商同时服务多家酒店，要求其在同等条件下优先保障本酒店货源 |

**五、试运行期（重要门槛）**

建议先签订**1个月试运行合作**：
- 前2周每天记录供货准时率、品质合格率、售后响应速度。
- 若三项指标均≥98%，再签正式年度合同，并在合同中加入**年度折扣**（如年采购额超50万，享受3%返利）。

**六、谈判技巧（实操建议）**

- **不要只谈单价：** 把“损耗率、退换货便利度、应急响应时间”与单价捆绑谈判，综合成本可能更低。
- **提前摸底**：走访供应商现有客户（如其他酒店），观察其配送车辆是否冷链、仓库是否整洁，这比合同条款更真实。
- **留有余地**：不要一次性承诺全部采购量，按60%锁量、40%浮动，给双方调整空间。

---

最后提醒：水果供应最怕“只比价格不看细节”，建议在合同生效后每月做一次**供应商评分表**（准时率40%、品质30%、服务20%、价格10%），未达标则启动3个月整改，仍不改进则替换。这样能最大程度保证早餐水果稳定，同时避免后厨因频繁换供应商而手忙脚乱。
