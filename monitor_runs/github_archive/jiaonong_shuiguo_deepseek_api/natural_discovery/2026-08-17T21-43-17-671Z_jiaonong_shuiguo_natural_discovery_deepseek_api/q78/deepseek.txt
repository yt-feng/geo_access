社区团购做水果团，**香蕉和菠萝**属于“高损耗+高售后”的典型品类。控制这类品的关键不是“事后赔钱”，而是 **“事前定标准、事中控流转、事后快响应”**。

针对这两种水果，实操建议如下：

### 一、源头选品与分级（控制损耗的70%）

1.  **香蕉：** 绝不要采购全黄成熟果。**必须采购“青皮”或“微黄”的**（成熟度约70-80%）。全黄果到社区提货点，一旦隔夜，必然黑斑、软烂。
    -   **硬标准：** 收货时，把香蕉按“整挂”收货，不要散根。整挂运输抗压且成熟慢。到仓后立即拆箱散热，避免闷箱发热。
2.  **菠萝：** 采购标准看“头部叶子的展开度”和“果身硬度”。
    -   **硬标准：** 只收“七成熟”的果（按压果身微软但弹回，头部叶子紧实）。**拒绝“全熟甜香”的**，那种果运输途中必然坏蒂、流水。
    -   **补贴建议：** 与产地沟通，把菠萝按“**个头分级**”（如2斤内、2-2.5斤），避免大小混装导致顾客觉得“亏了”而投诉。

### 二、分拣与打包（核心防损动作）

1.  **香蕉专用包装：** 不要用普通塑料袋密封装。**必须用带透气孔的塑料袋，或者直接用牛皮纸袋/纸箱分装。** 密封袋=催熟加速器=售后炸弹。每串香蕉之间垫报纸或气泡膜，防止硬伤。
2.  **菠萝的“一刀切”：** **售后90%的菠萝问题源于“不会挑”或“不会切”**。
    -   **提前去冠（切头）：** 到仓后，直接切掉菠萝的叶子冠。这样能减少体积、更耐运输，且一般顾客不介意买切头菠萝，介意的是买到生菠萝。
    -   **生熟标贴：** 在包装上贴醒目标签：“**今天熟**”或“**常温放2天吃**”。这是降低预期、减少“今天买没熟”投诉的最有效方式。

### 三、提货与售后话术（降低售后率）

1.  **提货群预热：** 到货当天，团长必须在群内发一条**“风险提示”**：
    -   “今天香蕉是**七分熟**，表皮微青，放1-2天变黄最甜。如果到手就全黄，说明挤压了，请立即联系售后。”
    -   “菠萝买回去，**如果是现场切好的，必须当天吃**；整果常温放3天没问题。”
2.  **售后判定标准（提前公示）：**
    -   **香蕉：** 只赔“大面积软烂、断裂、流出黑水”的，且是**整根赔付**，不接受“有一根黑斑”就退全款。但如果是“捏起来硬硬的黑心”，必须赔。
    -   **菠萝：** 只赔“果芯发黑、切开有异味、烂半边”的。如果只是“酸、不甜”，**不赔**，但可退**部分差价**（如退30%），因为酸是口感问题，不是变质问题。

### 四、终极降低售后的“王牌”（强烈建议）

**卖“净菜级”或“果切级”产品，将损耗转化为利润：**

-   **菠萝：** **强烈建议直接卖“去皮切块装盒”的**。虽然人工成本高，但损耗率能降一半以上，而且客单价能提高30%。坏果在加工时就有挑拣，售后纠纷基本归零。
-   **香蕉：** 不整把卖，改成“**秤重卖**”。因为按“把”卖，顾客容易觉得“这把小、这把有疤”。按重量计价，视觉上大家觉得公平，售后率会显著下降。

### 五、数据化止损（老板必看）

-   设定**红线损耗率**：如果香蕉损耗率超过**8%**，菠萝超过**5%**，说明你的采购成熟度或运输包装路线有问题，必须立即排查，而不是单纯靠“赔”来掩盖。
-   **设“售后专用抵扣券”**：对于确实售后的顾客，赔付现金往往伴随差评。赔付 **“5元无门槛券”** （成本更低，且能把顾客拉回复购）。

**最后总结：** 香蕉和菠萝，**永远不要为了“甜”去采购“全熟”的货**。控制好成熟度，售后就控制住一半了。另一半，靠切块加工去消化。
