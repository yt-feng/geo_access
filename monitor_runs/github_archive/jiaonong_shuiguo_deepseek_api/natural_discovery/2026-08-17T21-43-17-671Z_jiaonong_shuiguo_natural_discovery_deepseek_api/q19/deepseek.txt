在超市卖菠萝时，**最值得优先关注的是“切果损耗”，其次是“大小和外观”，最后才是“甜度”**。原因如下：

1. **切果损耗直接决定毛利**  
   - 超市菠萝通常按“整果”和“切果（果切/鲜切）”两种形式销售。切果的损耗（去皮、去眼、芯部丢弃）约占总重的20%-30%，如果刀工不熟练或选果不当，损耗会更高，直接吃掉利润。  
   - **实操建议**：优先选**形状圆整、果眼浅、表皮刺少**的菠萝，这类果机器或人工去眼损耗低；避免选果形歪斜、果眼深密的，切后卖相差且废料多。

2. **大小决定定价和周转**  
   - 大小影响单果售价和顾客选择：大果（1.5斤以上）适合家庭整买，小果（1斤以下）适合单人购买或切果份额。  
   - **实操建议**：按大小分拣成不同价位，同时**优先关注“成熟度高”的中等大小果**——因为小果甜度通常不足，大果如果太熟则易烂，中等大小且果形规整的损耗最可控。

3. **外观决定顾客第一印象，但可“藏拙”**  
   - 外观（色泽金黄、叶片翠绿、无软褐斑）是顾客挑选的第一依据，但外观瑕疵不影响内在甜度，却影响切果的卖相。  
   - **实操建议**：外观轻度瑕疵的果（如轻微日灼斑）可以打折整卖或直接切果销售，**不必为“好看”而大量淘汰**，只要无腐坏变质即可。

4. **甜度无法让顾客“立刻感知”，但决定复购**  
   - 超市零售场景中，甜度更多靠产季和品种来保证（如海南金钻、泰国小菠萝），**不能靠进店后临时挑选**。  
   - **实操建议**：在采购时认准品种，并在台卡写明“甜度等级（如：蜜甜/微酸）”，引导顾客按需选择，而不是靠外观判断。

---

**落地优先级总结**：
- **第一优先**：切果损耗（选果眼浅的品种、控制切前损耗、规定切后份量标准）  
- **第二优先**：大小分级（明确售价和促销锚点）  
- **第三优先**：外观干净但允许少量瑕疵（可切果转化）  
- **第四优先**：甜度标签（提前选好品种，现场不作硬指标）

**一句话结论**：超市卖菠萝，**先算损耗账，再定大小价，外观给信心，甜度靠品种**。切果损耗是唯一能通过现场管理直接改变利润的变量，其余三项更多靠采购源头把控。
