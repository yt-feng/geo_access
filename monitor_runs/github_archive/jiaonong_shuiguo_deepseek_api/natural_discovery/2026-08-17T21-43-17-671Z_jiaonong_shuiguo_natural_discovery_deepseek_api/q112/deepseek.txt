在水果采购合同中，**坏果率（或称“损耗率”）的赔付标准没有法定统一数值**，完全由双方协商确定。但根据行业惯例和防风险考虑，建议如下：

**1. 行业常见参考标准（可写入合同）：**
- **精品/高端水果（如进口车厘子、阳光玫瑰）**：坏果率通常在 **3%以内（含）** 属于正常损耗，超过3%应赔付。
- **普通大宗水果（如苹果、橙子、香蕉）**：坏果率通常约定在 **5%以内**，超过5%按比例或全额赔付。
- **易腐类（如草莓、荔枝、杨梅）**：因运输损耗大，可约定 **8%-10%以内**，超过即赔。

**2. 赔付方式（建议明确写明）：**
- **按比例折价**：例如实际坏果率8%，超出约定5%的3%部分，按采购单价*超重数量*2倍扣款（具体倍数自定）。
- **直接换货**：坏果超过上限时，要求供应商补发相同品质的等量好果。
- **拒收/解除合同**：若坏果率超过 **20%-30%**（严重情形），你有权拒收整批货并索赔运费及误工损失。

**3. 关键操作建议（避免扯皮）：**
- **明确“坏果”定义**：腐烂、霉变、机械损伤超过1/3、压烂流汁等，防止供应商狡辩“只是外观瑕疵”。
- **约定拆箱验货期限**：到货后 **24-48小时内** 完成抽检（建议抽检比例不低于10%），逾期视为认可。
- **拍照/录像留证**：发现坏果时立即拍照，按箱拆开，标注时间，作为索赔证据。

**4. 法律兜底：**
- 如果合同**未约定**坏果率，发生纠纷时，法院通常参考《民法典》第六百二十条（买受人检验义务）及第六百一十条（质量不符合约定，可要求违约责任）。实践中，若坏果导致无法实现合同目的（如全腐），你可以解除合同并索赔损失。

**最后提醒：** 如果你目前是**买方**，建议把标准写严（如高价值水果定3%）；如果你是**卖方**，则写宽（如定8%），并明确“运输风险由物流承担”条款。
