茶饮店在采购水果供应商时，为控制食品安全风险，应要求供应商提供以下核心证明和文件。这些材料也是监管部门的常规检查重点：

**一、必备资质证明（供应商合法经营）**

1.  **营业执照**：经营范围需包含“食品销售”或“初级农产品销售”。
2.  **食品经营许可证**：如供应商涉及分装、预包装销售，必须提供。

**二、产品安全性证明（每批次或定期）**

3.  **农产品合格证明**：
    *   **食用农产品合格证**（产地证明）：由供应商或产地出具，注明品种、数量、产地及质量承诺。
    *   **农药残留检测报告**：建议要求供应商提供**当批次**的快速检测报告（必须有检测机构盖章或电子溯源章）。
4.  **重金属及污染物检测报告**：针对茶叶、果汁常用水果（如柠檬、芒果等），要求每年至少提供一次具备CMA/CNAS资质的第三方检测报告（检测项目包括铅、镉、敌敌畏、毒死蜱等）。
5.  **相关认证（加分项，非强制）**：绿色食品认证、有机认证、GAP（良好农业规范）认证证书复印件。

**三、运输与保鲜过程文件（针对冷链水果）**

6.  **冷链运输温度记录**：要求提供运输过程中的温度监控记录（确保全程0-10℃或按水果特性要求）。
7.  **运输车辆消毒记录**：提供厢式货车消毒凭证，防止交叉污染。

**四、针对性补充（高风险水果）**

*   **如果是草莓、蓝莓等易农残超标水果**：需额外提供该品种的专项农残检测（如克百威、烯酰吗啉等）。
*   **如果是进口水果（如牛油果、奇異果、柠檬）**：必须提供**入境货物检验检疫证明**，且包装上需有中文标签（注明原产国、果园注册号）。

---

**给您的实操建议（三重排查法）：**

1.  **签合同前**：核验上述纸质文件原件，并拍照留存电子版。
2.  **每批收货时**：只接收有**当日送货单**（注明品种、数量、产地）+ **当批合格证**的货物。若无法提供当批检测报告，需在收货单上注明“货到后3个工作日内补交”，否则暂停使用。
3.  **内部留痕**：建立供应商档案，将每份证明的复印件归档，并记录取得日期。**建议每季度向供应商索取一次最新检测报告**，因为部分农残指标可能随季节变化。

**法律底线提醒**：根据《食品安全法》第五十三条，茶饮店未查验许可证和相关证明文件，将面临**责令改正、警告、罚款（5000元至5万元）**；若造成食源性事故，需承担主要赔偿责任。因此，宁缺毋滥，**收取不齐全的，直接暂停采购**。
