针对“门店多、单店量小”的超市特点，水果供应链的核心矛盾是**“既要品种全、损耗低，又要配送稳、成本可控”**。直接套用大卖场的“产地大批发”模式会压死库存，完全依赖本地批发市场则价格没有优势。

以下四种模式最适合这种业态，按**优先级**排序，你可以根据自身资金和团队情况选择：

**1. 本地/区域一级批发市场“代采+拼车”模式（最稳妥，起步首选）**
这是最符合“店多量小”的底层模式。

-   **具体做法**：不要直接对接产地，而是每天在周边的城市一级批发市场（如广州江南、北京新发地、杭州勾庄等）找2-3个固定的“代采手”或“档口合伙人”。你每天上午把各门店的需求（合计）报给代采，他负责在市场内帮你拼柜、配货。
-   **适合理由**：单店量小，但多店加起来一天有个几百斤，就有了跟档口谈“批发价、次天价”的筹码。**最关键的是损耗极低**，因为可以直接看到实物，不压货，今天拿明天卖。
-   **执行关键**：锁死“运输费”和“代采佣金”，要求代采每天发水印照片（含价格牌）进行比价。

**2. “基地直发+前置仓/司机配送”的统采统配模式（中期进阶，拼效率）**
当你的门店数量达到8-10家以上，且集中在同一城市时，适合建一个300平米左右的**城市前置总仓**。

-   **具体做法**：选3-5个核心大单品（如香蕉、苹果、橙子、西瓜）直接对接产地（如广西、云南、海南），整车发到总仓。到仓后按门店需求分拣，由一台冷藏车或专线司机按线路配送。
-   **适合理由**：多店集合的采购量足以支撑整车发货，能拿到产地最低价，毛利率比去批发市场高5-8个百分点。同时，总仓可以分担库存，门店卖完了随时补货，不用门店自己堆库存。
-   **执行关键**：总仓一定要做“分拣加工”，把大包装拆成小包装（如5斤装），避免门店因卖不完而产生大量损耗。

**3. 区域连锁社区生鲜供应链平台（轻资产借用，省人力）**
现在很多城市有专业服务“钱大妈”、“百果园”周边散户的**第三方生鲜配送公司**。

-   **具体做法**：寻找当地专门给社区超市、小水果店供货的配送商。跟他们谈“统采协议”，直接让他们把所有门店的水果按“日配”送到店。
-   **适合理由**：你不需要养采购员和司机，完全借力。他们通常能提供较小规格的包装（如2-3斤小箱），正好匹配单店量小、动销快的需求。
-   **执行关键**：一定要要求**“退换货条款”**——当天卖不完的、不新鲜的，次日无条件退回，这是降低损耗的关键。

**4. “爆款集采+例行批发”混合模式（控制损耗的终极解法）**
不要所有品类都用一种模式，要“抓大放小”。

-   **具体做法**：对于**引流爆款**（如当季的车厘子、榴莲、阳光玫瑰），集中全部门店订单，直接跟产地或大商行包山订货，专门促销；对于**常规品类**（如圣女果、黄瓜、芒果等），继续用模式1（批发市场代采）。
-   **适合理由**：爆款利润高但风险大，单店不敢多拿，全部门店集合起来就能对冲风险；常规品用批发市场随拿随走，把损耗降到最低。

---

**给你的三点核心建议（避免踩坑）：**

-   **别碰“全品类产地直发”**：单店量小，产地直发不仅运费贵，而且发来一箱如果是次果，整个门店就砸手里了。只对耐储存的品类（苹果、梨）做直发。
-   **损耗率是生命线**：多店量小最怕的是“门店积压”。宁可批发价高3毛钱，也要保证当天到货、当天清货。**毛利率要做到30%以上，否则覆盖不了损耗**。
-   **先跑通“1个市场”再扩张**：先找一家最旺的门店或者最近的批发市场，把“代采-分拣-配送-退货”全流程跑顺2周，摸着石头过河，再复制到所有门店。

**最推荐起步方案**：直接找当地一级批发市场里的**“果品配送商”**（专门给高档超市送货的那种），跟他们谈“多店拼箱”方案，这是投入最小、见效最快、风险最低的路径。
