在超市与水果供应商的账期谈判中，常见账期通常在 **30天至60天** 之间，具体取决于双方的合作模式、供应商规模、水果品类（如易腐败程度）以及超市的采购政策。

以下是不同情况下的常见账期参考：

1. **大型连锁超市（如永辉、华润万家等）**：
   - 账期普遍较长，通常在 **45天至60天**。
   - 如果供应商是长期合作的大供应商，可能协商至 **75天**，但需要供应商具备较强的资金垫付能力。
   - 大型超市往往要求“月结30天”起谈，即本月货款下月末支付。

2. **中型超市或区域连锁**：
   - 账期一般在 **30天至45天**。
   - 此类超市对资金周转要求较高，账期过短会压缩其利润空间，但也需平衡供应商接受度。

3. **小型超市、便利店或生鲜专营店**：
   - 账期较短，常见 **15天至30天**。
   - 甚至有些会采用“现结现采”，尤其是对进口水果或高价果品。

4. **特殊情况**：
   - **一级代理/基地直供**：若供应商是产地直供，可能争取到 **7-15天** 的短账期，因为其损耗控制能力较强，且大客户能保证稳定采购量。
   - **季节性水果**：如荔枝、草莓等易损耗品种，超市通常要求 **7天内结算**，否则供应商会加价转嫁给超市风险。

**实操建议**：
- 如果你是供应商，可以争取“ **月结30天** ”作为谈判起点，并强调水果的保鲜周期短，将账期与损耗风险挂钩。
- 如果你是采购方，先以“45天”为试探值，观察供应商反馈；若对方强烈抵抗，再降至30天并附加“延迟付款需支付滞纳金”条款。
- 无论双方达成何种账期，合同中务必明确 **对账日、付款日、逾期利率（如每日0.5‰）**，避免口头约定。

**注意**：超市行业惯例中，除去账期天数，实际到账可能因对账流程延长3-7天，建议在合同中约定“到账时间以实际收款为准，但对账需在3个工作日内完成”。
