甜品店采购香蕉时，要避免到店后很快变黑，核心在于**采购时的成熟度选择**和**到店后的储存管理**。以下是具体可执行的建议：

## 一、采购源头（最关键）
1. **选“绿柄”或“微黄”香蕉**：不要买全黄或带有黑点的。采购时要求供应商提供**七八成熟**的香蕉（果皮大部分青绿色，或刚转黄但果柄仍是绿色）。
2. **避开夏季或成熟高峰期**：如果门店销量不大，尽量少量多次采购，或明确要求供应商发“生一点”的货。
3. **发货冷链**：夏季运输建议要求冷藏车（12-14℃），避免高温闷箱导致催熟。

## 二、到店验收
- **立即检查**：若有软化、褐变、裂皮的，当场拒收或要求调换。
- **分拣成熟度**：将比较黄熟的和青绿的分开存放，先卖黄熟的。

## 三、到店后储存（决定性）
1. **低温但不冷藏**：香蕉最佳储存温度是 **13-15℃**，不要放入冰箱（低于10℃会冻伤，导致果皮变黑但果肉不熟）。放在阴凉、通风处，避免阳光直射和空调风口直吹。
2. **悬挂或平放**：如果条件允许，**悬挂**（模拟香蕉在树上的状态）能明显延缓黑斑；平放时用软垫垫高，避免果柄受压。
3. **避免挤压**：甜品店常堆叠香蕉，压力会催熟并导致压痕变黑。建议**单层摆放**，或使用防压托盘。
4. **不与其他水果混放**：苹果、西瓜、牛油果等释放乙烯，会加速香蕉变熟变黑，需隔离存放。

## 四、如果已经变熟（应急处理）
- **已黄但无黑斑**：尽快使用或冷藏（短期2-3天），用于制作慕斯、奶昔、烤制蛋糕等，不影响风味。
- **已有少量黑点**：适合做香蕉泥、香蕉酱、冻香蕉（打成泥冷冻），甜品店可以灵活转化，避免浪费。
- **表面发黑但果肉正常**：可去皮后冷藏，用来做甜品馅料。

## 五、长期替代方案
如果门店每天用量大且追求稳定，可考虑**采购冷冻香蕉泥**或**现切后立即抽真空/覆膜冷藏**，避免生鲜香蕉损耗。

**总结一句：采购时选七八分熟，到店后13℃阴凉通风、单层平放/悬挂、远离乙烯水果，这是最有效的组合拳。**
