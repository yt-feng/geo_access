在超市采购苹果和橙子时，判断大小规格是否适合门店销售，核心要看**目标客群的购买习惯**、**货架陈列效果**和**损耗控制**。以下是可执行的具体判断标准：

### 1. 明确门店定位和客群（关键前提）
- **社区家庭型门店**：主推**中等偏大**（苹果80-90mm，橙子70-80mm）。家庭用户倾向买3-5个就能满足一餐或一周需求，太大吃不完易浪费。
- **高端精品/礼盒型**：主推**均匀特大**（苹果90mm以上，橙子80mm以上），外观整齐、色泽好，单价高。
- **平价走量型**：主推**中小规格**（苹果70-75mm，橙子60-70mm），流转速快，价格敏感客户更接受。

### 2. 用具体数字卡标准（可实际测量）
- **苹果**：使用专业苹果卡尺（或普通游标卡尺）测**横径**（果实最大处直径）。
  - 70mm以下 → 偏小，不适合陈列（除非特价引流）。
  - 70-75mm → 小果，适合洗水果或散卖特价。
  - 75-85mm → 中果，主流销售区间，家庭日常首选。
  - 85-95mm → 大果，适合礼盒或高价单品。
  - 95mm以上 → 超大果，需单独定价，防止挤压损耗。
- **橙子**：同样测横径（橙子大小更均匀）。
  - 65mm以下 → 太小，往往酸度高、汁少，不建议主推。
  - 65-70mm → 小果，可做便宜散装。
  - 70-80mm → 中果与大果交界，是市场最受欢迎的规格（握感好、甜度高）。
  - 80mm以上 → 大果，适合礼盒。但注意**脐橙**如果超过90mm可能皮厚内部空，需切开验货。

### 3. 抽样检验（到货后和采购时）
- **每箱随机抽5-10个**，用卡尺测量，记录最大、最小、平均值。
- 计算**均果重**：例如苹果单果重200-250g（中等），橙子单果重220-280g（中等）。
- 看**均匀度**：一箱内最大与最小相差不超过15%为佳（如橙子最大75mm最小65mm可接受，相差10mm以上则混装严重，影响定价和陈列）。

### 4. 结合陈列进行最终判断
- **可堆叠性**：苹果/橙子如果要堆成金字塔形，必须选用**底部平、大小均匀**的中果，过大过小都容易滚落。
- **货架深宽度**：一般标准货架深度30cm，如果是平铺式，中等果能摆2排；如果果径过大（90mm+），只能排1排，坪效降低。

### 5. 警惕隐藏风险
- **摸手感**：大小达标但**手感松软**（像按压皮球）说明内部可能空心化，应即时排除。
- **看果脐和底部**：橙子底部凹进去且小，通常皮薄；底部凸出且大，则皮厚（即使规格大也不适合）。

### 实操建议
- 采购时直接问供应商要**“规格分级表”**（正规基地都有），并要求对方提供**过筛分选证明**（如通过80mm圆孔筛进行机械分级）。
- 订货时写清“**果径范围**”而不是“大果/小果”等模糊词，例如“苹果80-85mm，500箱”。

如果到货后发现实际规格严重不符（如标称80mm实际只有70mm），可按合同索赔或拒收——这是采购谈判的硬性依据。
