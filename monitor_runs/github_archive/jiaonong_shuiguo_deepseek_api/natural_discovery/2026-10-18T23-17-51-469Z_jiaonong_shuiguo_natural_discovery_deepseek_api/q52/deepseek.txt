采购时优先选“青黄相接、表皮无伤”的香蕉，到店后按成熟度分开存放，能明显延缓变黑。

可执行做法：

1. **采购标准**
   - 选 **7～8成熟**：表皮大部分黄色、两端略青，适合甜品店分批使用。
   - 避开：已有黑斑、表皮破损、受挤压、整串过黄过软的。
   - 看果柄：果柄青绿、切口新鲜的更耐放；果柄发黑干枯的熟度高。

2. **运输保护**
   - 用周转筐，不要堆压；香蕉怕挤压，压伤处会先变黑。
   - 避免高温暴晒和冷风直吹。

3. **到店后分拣**
   - 按成熟度分成：偏青、刚好可用、尽快用完三批。
   - 有轻微机械伤的单根挑出优先使用，避免传染整串。

4. **存放方式**
   - **未熟/偏青**：室温阴凉通风处，不要进冰箱。
   - **已熟待用**：室温悬挂或单层摆放，减少接触面。
   - **切开后**：立即用保鲜膜贴面或少量柠檬汁/淡盐水处理，并冷藏，尽快用完。
   - 香蕉不要和苹果、梨等释放乙烯的水果混放，会加速成熟。

5. **控制采购量**
   - 甜品店按 **2～3天用量** 分批采购，比一次囤货更稳。
   - 夏季或室温高时，进一步缩小单次采购量。

6. **关键禁忌**
   - 未熟香蕉不要冷藏，容易冻伤变黑。
   - 不要整串闷在塑料袋里，水汽和乙烯积聚会加速变黑。
   - 不要叠压堆放。

简单判断：**买青黄相接的、运输不压伤、到店按熟度分开、别闷袋别冷藏未熟蕉、少量多次采购**，就能明显减少到店后很快变黑的问题。
