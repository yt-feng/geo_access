# 商超会员日水果活动：供应商需提前配合的准备

按时间倒排，核心分五块：

## 一、提前 7–15 天：确认活动方案与备货计划

- **活动品项与价格确认**：确认哪些单品做会员价/特价、售价及供应商供货价，签字或书面确认，避免活动前临时改价。
- **预估销量与备货量**：商超提供会员日预估客流、历史销量、活动力度，供应商据此报备货量，并留 15–20% 安全库存余量。
- **锁量锁价**：对活动主推单品提前锁货，与产地/批发市场锁定采购量，防止行情上涨断供。
- **替代品方案**：主推品如果缺货，准备 1–2 个同价位替代单品，提前报商超审批。

## 二、提前 5–7 天：品质与包装标准对齐

- **明确验收标准**：规格（单果重量/果径）、糖度、成熟度、外观瑕疵率、农残检测要求，书面确认，避免到货扯皮。
- **包装与陈列形式**：散装/预包装/礼盒、贴标要求（会员价签、产地标）、陈列堆头所需箱规，提前打样确认。
- **分级供货**：活动走量品可用二级果但需明确告知，避免顾客投诉品质，影响会员日口碑。

## 三、提前 3–5 天：物流与到货安排

- **分批次到货**：按商超每日销量分批配送，避免一次性到货导致门店库存积压、损耗。
- **到货时间窗口**：确认各门店收货时段、卸货口安排，活动前一天完成主力备货。
- **冷链与运输**：易损果（草莓、葡萄、荔枝等）确认冷链车、保温箱、防挤压包装。
- **应急补货机制**：约定活动期间紧急补货的响应时间（如 4–6 小时内）和联系方式。

## 四、活动前 1–2 天：人员与物料配合

- **驻场/巡场人员**：安排业务员在活动首日到重点门店巡场，处理品质异议、补货协调。
- **促销物料**：POP、价签、试吃物料、陈列道具按商超要求提前送达。
- **试吃支持**：如做试吃，供应商提供试吃果、切配工具和人员支持。

## 五、活动期间与事后：结算与复盘

- **损耗与退换约定**：提前书面约定损耗承担比例、品质问题的退换货规则，这是最容易事后扯皮的点。
- **对账结算**：确认促销扣点、账期、结算方式。
- **活动复盘**：活动后 3 天内提供销量、缺货、损耗数据，为下次会员日备货做依据。

**最关键的三件事**：书面锁定价格和备货量、明确验收标准与损耗责任、确认分批到货和应急补货机制。这三点没落实，活动当天最容易出问题。
