# 超市水果到货品相不好：售后流程约定建议

水果属于生鲜，品相争议高频且难举证，售后条款要围绕**验收时点、分级标准、举证方式、处理时限、责任归属**五个要素写清楚。建议按以下框架约定：

## 一、验收环节（最关键）

1. **验收方式**：约定"到货后X小时内（建议2–4小时）由双方共同开箱抽检"，超时未提出视为验收合格。生鲜易腐，必须设时限，否则事后无法界定责任。
2. **抽检比例**：按箱数的5%–10%随机抽检，或按品类约定固定箱数；写明抽检结果适用于整批还是仅限抽检箱。
3. **验收记录**：双方签字确认的验收单+现场照片/视频（含包装、批次号、时间水印），作为后续争议依据。

## 二、品相标准（避免"不好"这种主观表述）

- 按品类写**可量化标准**：如腐烂、霉变、机械伤、畸形、着色度、单果重量区间、软硬度等。
- 建议分三级：
  - **合格**：正常签收；
  - **轻微瑕疵**（如少量表皮擦伤、规格偏小）：折价或按比例扣款；
  - **严重不合格**（腐烂、霉变、大面积损伤）：整批拒收或退换。
- 明确"品相不好"的判定以**书面标准+抽检结果**为准，不以主观感受为准。

## 三、处理方式与时限

| 情形 | 处理方式 | 时限 |
|---|---|---|
| 轻微瑕疵 | 按瑕疵比例折价，货款中直接扣减 | 验收后24小时内确认 |
| 严重不合格 | 拒收、退货或换货，运费由供货方承担 | 验收当场或2小时内提出 |
| 部分批次问题 | 仅退问题批次，不影响其余批次结算 | 同上 |

约定**响应时限**：供货方收到异议后X小时内（建议4–8小时）答复，逾期视为认可采购方处理意见。

## 四、举证与责任

- 明确**举证责任**：采购方在验收时限内提供照片/视频/验收单即完成初步举证；供货方对"非其责任"承担举证责任。
- 区分**到货即有问题**与**到货后储存不当**：约定签收后因采购方储存、陈列不当导致的损耗由其自行承担。
- 退换货的**损耗与费用**（运费、销毁费）由责任方承担。

## 五、结算挂钩

- 建议预留**质量保证金**（如货款的5%–10%），或约定"瑕疵扣款在当期货款中直接冲抵"，避免事后追讨困难。
- 累计质量问题达到约定次数（如月度3次），可约定暂停供货或终止合作。

## 六、兜底条款

- 生鲜不适用"七天无理由"类规则，明确以**验收结果**为最终依据。
- 争议解决方式（协商→书面异议→仲裁/诉讼）写清。

**一句话原则**：把"品相不好"拆成可量化的验收标准，把争议压缩到"到货后几小时内、双方在场、有照片记录"这个窗口内解决，事后扯皮的空间就基本没有了。
