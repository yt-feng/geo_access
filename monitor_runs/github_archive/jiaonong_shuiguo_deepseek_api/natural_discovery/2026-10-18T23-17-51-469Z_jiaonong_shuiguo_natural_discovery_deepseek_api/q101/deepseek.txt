和水果供应商谈酒店早餐合作，重点是把“稳定”落到可执行的条款上，而不是只谈价格。建议按下面几个方面准备和谈判：

1. **先定需求和验收标准**
   - 明确每日/每周用量、早餐时段、补货时间、最低起订量。
   - 列出常供品类、规格（大小、成熟度、甜度）、包装方式、允许损耗率。
   - 约定验收标准：外观、新鲜度、农残检测报告、冷链温度记录；不合格如何退换、扣款。

2. **供应稳定性与应急机制**
   - 要求供应商说明产地/季节替代方案，避免单一品种断供。
   - 约定缺货提前通知时限、替代品方案、紧急补货响应时间。
   - 考察其仓储、冷链车辆、分拣能力，以及旺季/节假日保供记录。
   - 可考虑主供应商+备选供应商，避免独家依赖。

3. **价格与结算**
   - 不要只看单价，比较含税、配送、损耗、退换货后的综合成本。
   - 约定价格调整机制：调价周期、参考市场依据、提前通知期。
   - 明确账期、发票类型、对账周期、逾期付款/质量扣款规则。

4. **食品安全与合规**
   - 核验营业执照、食品经营许可证、检测报告、从业人员健康证等。
   - 明确冷链要求、运输卫生、包装标签、追溯体系。
   - 合同里写清食品安全责任、召回配合、事故赔偿。

5. **合同关键条款**
   - 供货范围、价格、数量、质量标准、交付时间地点。
   - 验收与退换、缺货违约、质量违约、赔偿上限。
   - 账期与结算、保密、终止与过渡期安排。
   - 建议先小批量试供1—2周，再签长期协议。

6. **现场考察与试供**
   - 实地看分拣场、冷库、车辆卫生。
   - 试供期间记录到货准时率、损耗率、投诉次数，作为正式合作依据。

7. **沟通与对接机制**
   - 指定双方对接人、下单截止时间、异常反馈渠道。
   - 建立每日/每周对账和月度复盘，及时调整品类和用量。

简单说：**先量化需求，再验资质和保供能力，最后用合同把质量、缺货、价格调整和退换责任写死。** 不要只口头承诺“保证供应”，要写成可考核的条款。
