# 单位采购水果的验收与售后处理

## 一、验收前先定标准（关键）

到货品质不一致往往是因为合同没写清。采购前应在订单或合同里明确：

- **规格等级**：品种、果径/单果重量范围、成熟度、糖度（如有要求）、外观（无明显碰伤、腐烂、畸形）。
- **允收比例**：例如“单个批次允许≤5%的轻微瑕疵（表皮轻微擦伤、果形略偏），腐烂/霉变/严重碰伤一律不计入可收数量”。
- **验收方式**：抽检比例（如每批随机抽3箱或按10%抽检）、称重方式（毛重/净重、是否扣除包装）。
- **到货时限与温控**：冷链水果要求到货温度、运输时长。
- **售后条款**：不合格部分如何退换、补货时限、扣款或折价规则。

## 二、到货验收怎么做

1. **先拍照留证**：整批外观、开箱抽检、问题果特写、称重读数、运单和到货时间，全部拍照/录像。
2. **按比例抽检**：随机开箱，逐箱记录问题果数量，算出不合格率，不要只凭“感觉差”。
3. **当场分拣**：把腐烂、霉变、严重碰伤、规格不符的挑出单独堆放，避免污染好果，也方便清点。
4. **填写验收单**：记录到货数量、抽检数量、不合格数量与比例、问题描述，由供货方送货人签字确认（或拍照发对方确认）。
5. **按标准判定**：
   - 不合格率在允收范围内 → 收货，问题果按约定折价或下次补。
   - 超出允收范围 → 拒收该部分或整批，当场书面/微信告知供货方并留痕。
6. **入库前再筛一遍**：水果有后熟和隐性损伤，入库当天复检一次，坏果及时挑出，减少后续损耗争议。

## 三、售后怎么处理

- **及时反馈**：到货当天（最好几小时内）把照片、验收单、不合格比例发给供货方，明确诉求：换货、补货、折价或退款。
- **约定时限**：要求供货方在24–48小时内答复并给出补换货时间，写进验收单或沟通记录。
- **不合格品处理**：腐烂变质的不退回（避免二次流通），当场销毁或按规定处理并拍照，按数量折价扣款；可退换的规格不符品单独封存待换。
- **扣款依据**：按合同约定的单价×不合格数量扣减，或按整批折价比例结算，保留计算明细。
- **累计考核**：同一供应商多次到货不合格，记录在案，作为后续是否续约、调整采购量的依据。

## 四、实用建议

- 验收最好由**采购经办人+使用部门（如食堂/工会）两人以上**共同进行，避免单人说了算。
- 所有沟通走**书面或微信留痕**，口头承诺事后补确认。
- 小额零星采购也至少保留“到货照片+验收记录+对方确认”三样，售后才有依据。
- 首次合作的供应商可先小批量试单，稳定后再放量。

核心一句话：**标准写在前、抽检验收留证据、问题当天反馈、按约定折价或补换。**
