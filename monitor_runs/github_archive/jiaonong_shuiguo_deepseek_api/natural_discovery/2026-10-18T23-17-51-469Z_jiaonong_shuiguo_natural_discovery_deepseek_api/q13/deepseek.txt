做小区团购，水果供应商至少要能支持下面这些服务，建议你按“必选 / 加分 / 合同要写清”来筛选。

**一、必选服务**

1. **小批量、多频次配送**
   - 能接受你初期单量小，比如每次几十斤、几百元起送。
   - 能按团购节奏配送，最好支持次日达或固定频次到店。
   - 能送到你店里，而不是只到批发市场自提。

2. **稳定供货和缺货处理**
   - 有稳定货源，能提前给你报次日可供应品类。
   - 缺货时能及时通知并给替代方案，不能团购开出去后大量断货。
   - 对爆品能预留库存，避免今天有、明天没。

3. **分级分拣和品控**
   - 能按团购标准分拣，比如按份、按箱、按斤装好。
   - 坏果率、次果率有明确标准，不能把尾货混进团购。
   - 支持你抽检，出现品质问题能补货、换货或退款。

4. **售后和损耗兜底**
   - 坏果、烂果、短斤少两能赔补。
   - 明确售后时限，比如到货后几小时内反馈有效。
   - 最好有损耗分担机制，而不是全部由你承担。

5. **价格稳定和报价透明**
   - 能提前给团购价，不临时大幅涨价。
   - 报价含不含运费、包装费、装卸费要写清。
   - 对长期合作有阶梯价或爆品支持价更好。

**二、团购场景很需要的服务**

6. **包装和规格支持**
   - 能按“家庭份”“5斤装”“整箱装”分装。
   - 包装要适合小区自提，不容易压坏、漏汁。
   - 能贴团购标签或按你的要求简单标识。

7. **配送时间可控**
   - 能配合你傍晚到货、次日自提的节奏。
   - 临时加单、改单能有一定弹性。
   - 节假日、周末能提前确认配送安排。

8. **退换货和补发响应快**
   - 小区团购口碑很敏感，一次坏果处理慢就会掉客。
   - 供应商最好能做到当天反馈、次日补或直接赔。

9. **试销和小单支持**
   - 新店初期最怕压货，供应商能支持小单试销很关键。
   - 能接受你先拿少量样品测试小区接受度。

10. **结算灵活**
   - 初期最好支持现结、周结或少量账期。
   - 押金、起订量、违约条款要提前谈清。

**三、合同或合作前必须写清**

- 起送量、配送费、配送频次、到货时间；
- 品名、规格、等级、允许坏果率；
- 缺货怎么处理、售后怎么赔、多久内反馈；
- 价格有效期、调价是否提前通知；
- 包装费谁承担、损耗谁承担；
- 退换货条件和结算方式。

**四、筛选供应商的实操建议**

先找 **2—3 家备选**，每家先试供 1—2 周，重点看：
- 到货准时率；
- 坏果率和售后速度；
- 小单是否愿意配合；
- 爆品缺货时是否提前说；
- 价格是否稳定。

对你这种小水果店，最核心不是找最便宜的，而是找 **能小批量送、品控稳定、售后不扯皮、缺货提前说** 的供应商。团购做的是复购和口碑，供应不稳比价格高一点更伤店。
