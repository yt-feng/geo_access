# 生鲜平台做水果一件代发：供应商需具备的仓配能力

一件代发的水果供应商，本质上是替平台承担了“仓储+打包+发货+售后”的全链路履约。平台不碰货，所以供应商的仓配能力直接决定消费者体验。建议从以下几方面考察：

## 一、仓储能力

1. **产地仓/销地仓布局**
   - 水果易腐，最好有靠近产区的产地仓（缩短采后时间）或靠近核心消费区的销地仓（缩短配送时效）。
   - 需明确仓库位置、面积、温区配置，能否支撑平台日均单量峰值。

2. **温湿度控制**
   - 按品类区分：常温、冷藏（0–4℃）、气调/保鲜库。浆果、荔枝、车厘子等对冷链要求高，普通门店式存放会大幅提升损耗。
   - 仓库是否有温湿度监控和记录，异常能否预警。

3. **库内作业能力**
   - 收货质检、分级、预冷、分拣、打包动线是否顺畅。
   - 日处理单量上限、旺季（如节日、大促）扩容能力。

4. **库存管理**
   - 是否有WMS系统，能否对接平台的订单/库存接口，做到库存实时同步、超卖控制。
   - 批次管理和先进先出（FIFO），避免陈货发出。

## 二、加工与包装能力

1. **分选分级**：按果径、糖度、外观分级，保证发出去的商品与平台描述一致。
2. **预冷与保鲜处理**：采后预冷、保鲜剂/气调包装等，直接关系货架期。
3. **包装适配快递**：防震、防压、透气/保温（冰袋、泡沫箱、保温袋）方案是否成熟，能否通过快递跌落测试。
4. **打包效率与标准化**：单人打包时效、错发漏发率、包装一致性。

## 三、配送与履约能力

1. **快递资源**
   - 是否与顺丰、京东、中通等有稳定合作及协议价，能否按平台要求选择时效产品（次日达/隔日达）。
   - 生鲜件是否有优先中转、温控运输资源。

2. **发货时效**
   - 下单后多久出库、截单时间、当日/次日发货承诺能否稳定达成。
   - 大促和节假日是否限单、爆仓风险如何管控。

3. **覆盖范围与时效**
   - 能发哪些区域、偏远地区是否支持、时效承诺（如48小时/72小时达）。
   - 是否支持多仓发货以缩短链路。

4. **物流异常处理**
   - 破损、延误、丢件的响应机制和赔付标准。

## 四、品控与售后能力

1. **到货质检标准**：收货验收标准、抽检比例、不合格处理。
2. **损耗率数据**：历史履约损耗率、坏果率、客诉率，最好有近3–6个月数据。
3. **售后响应**：坏果包赔的判定标准、补发/退款时效、对接平台的客服响应时间（如2小时内响应）。
4. **溯源能力**：批次可追溯，出问题能定位到货源和发货批次。

## 五、系统与协同能力

1. 是否能对接平台的订单系统（API/ERP对接），实现自动接单、打单、回传物流单号。
2. 库存、发货、售后数据能否实时同步，支持平台监控履约指标。
3. 是否有异常订单预警和对账能力。

## 六、资质与合规

- 营业执照、食品经营许可（如涉及分装加工需相应资质）。
- 产地证明/检测报告，农残检测合格证明。
- 包装标识合规（品名、产地、等级、保质期等）。

## 平台侧建议的准入评估清单

| 维度 | 关键问题 |
|---|---|
| 仓 | 仓在哪、温区是否匹配品类、峰值日单量 |
| 加工 | 分级标准、包装方案、打包时效与差错率 |
| 配 | 快递合作、发货截单时间、覆盖区域与时效 |
| 品控 | 损耗率/坏果率/客诉率历史数据、质检标准 |
| 售后 | 赔付规则、响应时效 |
| 系统 | 能否API对接、库存实时同步 |

**一句话判断标准**：优先选“有匹配温区仓储 + 稳定快递资源 + 可量化损耗/客诉数据 + 能系统对接”的供应商；只靠临时租仓、无冷链、无对接能力的作坊式供应商，不适合一件代发模式。
