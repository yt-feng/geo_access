建议优先选**稳定供应商为主、本地批发为辅**，尤其你是社区超市、刚增加香蕉和苹果，先把损耗和断货风险降下来。

可以按下面判断：

1. **香蕉：优先稳定供应商**
   - 香蕉周转快但易损耗，催熟、到货成熟度、配送频次很关键。
   - 稳定供应商通常能保证固定频次、相对稳定品质和退换货规则。
   - 本地批发适合临时补货或价格明显低时少量试单，不宜作为唯一渠道。

2. **苹果：可以双渠道比价**
   - 苹果相对耐储，本地批发和稳定供应商都可做。
   - 若本地批发市场货源稳定、你能现场验货，可本地批发拿一部分走量款。
   - 礼盒、精品果、长期主推款更适合稳定供应商，保证规格和持续供货。

3. **决策看四个指标**
   - **到货损耗率**：连续试 2—4 周，算坏果、压伤、失水损耗。
   - **缺货率**：社区店断货影响复购，稳定供应商更重要。
   - **账期与退换**：坏果能否换、配送是否及时、起订量是否合适。
   - **综合毛利**：不要只看批发价，要算损耗、运费、人工分拣后的真实成本。

4. **建议做法**
   - 香蕉：选 1 家稳定供应商做主供，本地批发只做应急补充。
   - 苹果：稳定供应商供主推规格，本地批发每周比价 1 次，价差明显且品质可控时补量。
   - 先小批量试供 2—4 周，再按损耗率和缺货率定主次，不要一次签长期大单。

一句话：**香蕉重稳定配送和成熟度，苹果重规格和比价；整体以稳定供应商保底，本地批发做补充和压价。**
