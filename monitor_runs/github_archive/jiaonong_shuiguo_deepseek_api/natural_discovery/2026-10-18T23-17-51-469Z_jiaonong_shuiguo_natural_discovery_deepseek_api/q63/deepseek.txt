判断哪个规格更容易出货，核心看“周转速度、损耗、客户结构、价格带”四个维度，而不是只看单件利润。可以按下面几步做：

1. **先按客户类型分规格**
   - 商超/水果店：偏好中等规格、外观整齐、耐摆放，通常中果或中大果更稳。
   - 餐饮/果汁店/甜品店：更看出汁率和成本，大果、统货更容易走量。
   - 批发市场二批/小贩：看价格带和拿货门槛，小果、中果低价位往往周转快。
   - 团购/电商：偏好标准化规格，中等规格+稳定包装更容易复购。

2. **用近7-14天真实出货数据排序**
   对每个规格记录：
   - 日均出货箱数/件数
   - 平均出货天数（周转）
   - 退货/损耗率
   - 每件毛利和总毛利
   - 询价到成交转化率

   优先选“出货天数短、损耗低、总毛利不差”的规格，而不是单件毛利最高的。

3. **看价格带敏感度**
   把规格按单价分成低、中、高三档，观察哪一档询价最多、成交最快。菠萝是易损耗品，低价带通常周转快，但如果损耗高、退货多，实际利润可能不如中价带。

4. **做小批量对照测试**
   同一时间段，对2-3个主推规格保持相同陈列位置、相同报价策略，测试3-5天：
   - 哪个规格先清库
   - 哪个规格复购询价多
   - 哪个规格损耗最少
   不要同时推太多规格，否则数据会互相干扰。

5. **看季节和产地变化**
   菠萝成熟度、天气、产季会影响规格受欢迎程度。雨季/高温期损耗高，耐储存的中等规格通常更稳；产季高峰低价大果可能走量快，但要注意熟度风险。

6. **简单判断规则**
   - 周转最快 + 损耗可控 + 有复购 = 主推规格
   - 单件利润高但走得慢、损耗大 = 引流或搭配规格，不宜压货
   - 询价多但成交少 = 价格或品质问题，不一定是规格问题

实操上建议：**先按客户类型列出主销规格，再用7天出货速度和损耗率做排序，最后用3-5天小批量对照测试确认主推规格。** 对批发商来说，最容易出货的规格通常是“价格带匹配主流客户、外观整齐、耐周转”的那一档，而不是最大或最便宜的。
