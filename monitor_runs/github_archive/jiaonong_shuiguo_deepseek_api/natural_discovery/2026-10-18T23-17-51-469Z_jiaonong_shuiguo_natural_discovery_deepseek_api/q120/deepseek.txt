核心思路：**不要用“品种名”开头，先用商家熟悉的场景和用途做锚点，再讲差异，最后给一个能直接下单的小规格。**

具体可以按这个结构说：

1. **先挂钩熟悉的东西**  
   比如：“这个跟您常卖的菠萝是一类用法，但口感更甜、纤维更少，适合做鲜切果盒。”  
   不要说“这是MD2/金钻/台农几号”，商家听不懂。

2. **用一句话说清“卖给谁、怎么卖”**  
   例如：“这个适合放水果店散卖，也适合奶茶店做果切，不用削眼，出成率高。”  
   商家最关心的是：谁买、好不好卖、损耗大不大。

3. **只讲三个可感知的差异**  
   建议固定讲：  
   - **口感/熟度**：甜不甜、酸不酸、软硬  
   - **卖相/操作**：好不好看、好不好削、耐不耐放  
   - **价格带/利润**：比普通货贵多少、能卖什么价  
   不要一次讲十个优点。

4. **拿熟悉品类做对比，但不贬低**  
   例如：“跟普通香蕉比，这个更小串、上架好看，适合做精品区；普通香蕉走量，这个走利润。”  
   对比要具体到“摆在哪、卖给谁”。

5. **给试单方案，降低决策压力**  
   例如：“先拿一箱试卖，按您店里一天卖多少来配，卖不动我给您换常规货。”  
   商家听不懂时，最怕压货；小规格试单比讲参数有用。

6. **现场演示比嘴说有效**  
   能切就切、能剥就剥、能摆盘就摆盘；让商家看到出成率和卖相。  
   对菠萝这类，直接说“不用泡盐水/削眼省人工”比讲品种名更有效。

一句话总结：**用“跟什么像、卖给谁、怎么卖、先拿多少试”四句话介绍，少讲品种名，多讲用途和试单。**
