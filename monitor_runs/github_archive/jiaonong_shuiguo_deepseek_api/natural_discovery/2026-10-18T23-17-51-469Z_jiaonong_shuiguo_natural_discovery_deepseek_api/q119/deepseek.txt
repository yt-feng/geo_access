水果生意要做长期稳定，选供应商时最容易忽视的不是“价格”和“有没有货”，而是那些**会随时间放大成损耗、断供和客诉的细节**。可以重点盯这几类：

1. **产地/批次稳定性，而不只是“今天这车好不好”**
   - 同一供应商不同批次品质波动大，会导致售价和口碑不稳。
   - 要问：货源是固定基地、固定产区，还是每天市场调货？
   - 最好连续跟踪几批的规格、糖度、硬度、色泽、成熟度是否一致。

2. **采后处理与冷链细节**
   - 是否预冷、分级、清洗、打蜡、催熟？冷链是否全程不断链？
   - 很多问题不是产地差，而是采摘成熟度、运输温度、堆压方式造成的。
   - 重点看：到货温度、箱内温差、是否有冷凝水、压伤、闷坏。

3. **分级标准和“以次充好”的边界**
   - 口头说“大果/精品”不算，要看明确规格：单果重区间、个数/箱、瑕疵率上限。
   - 是否把二级果混进一级果、底层和表层不一致。
   - 长期合作要约定抽检方式和不合格处理，不要只靠熟人关系。

4. **损耗责任怎么算**
   - 到货损耗、运输损耗、仓储后熟损耗、门店自然损耗，责任边界要提前说清。
   - 容易忽视的是“隐性损耗”：到货当天好看，两三天后集中软烂、发霉。
   - 建议约定到货验收时限、拍照留证、补货/折价/退货规则。

5. **供应弹性与断供预案**
   - 节假日、雨季、产地减产时能不能保量？涨价提前多久通知？
   - 只有一个供应商风险很高，至少要有备选产区或备选供应商。
   - 看对方是否有冷库、分拣能力、稳定物流，而不是纯倒手。

6. **账期、结算和售后响应**
   - 账期越长不一定越好，可能隐含价格上浮或品质下降。
   - 出问题时响应速度比承诺更重要：能否当天补货、是否推诿。
   - 合同/订单里写清价格调整机制、退换货时限、质量争议处理。

7. **合规与食品安全细节**
   - 农药残留检测、产地证明、包装标识、冷链记录是否齐全。
   - 做长期生意，一次食品安全问题可能比几次损耗更致命。
   - 不要只看对方口头保证，要求可追溯的批次信息。

8. **供应商的客户结构**
   - 如果对方主要供商超/大客户，你的紧俏货优先级可能很低。
   - 了解他给谁供货、旺季保谁，能判断你在其体系里的位置。

实操建议：先用**小批量、多批次**试供 3—5 批，固定验收表（规格、糖度、瑕疵率、到货温度、2—3 天后损耗率），再谈长期价。长期稳定的核心不是找到“最便宜的最好的”，而是找到**波动可预期、责任可界定、出问题能兜底**的供应商。
