# 首次合作水果供应商的小批量试单设计

水果是生鲜里损耗敏感、品质波动大的品类，首次试单的核心目标不是"多拿货压低成本"，而是**用最小风险验证供应商的三件事：品质稳定性、履约可靠性、结算诚信**。建议按以下框架设计。

## 一、先定试单目标（决定后面所有参数）

一次试单同时验证四个维度：

1. **品质**：到货与该供应商提供的样品/承诺的偏差有多大
2. **履约**：交货时间、数量准确度、包装规格是否一致
3. **损耗**：运输和到货后的自然损耗率、腐烂率
4. **配合度**：出问题时的响应速度和处理态度（这是长期合作最关键信号）

## 二、选品：挑"能暴露问题"的品

- **选1–3个品类**，不要一上来铺全品类。优先选你**主销、周转快、你熟悉**的品种，这样你能一眼看出好坏。
- **避坑**：不要只拿耐储品种（如苹果、橙子）试单——耐储品掩盖问题；也不要只拿最娇贵的（如草莓、荔枝）——容易误判供应商真实水平。建议"1个中等难度的常规品 + 1个易损品"组合，看不同品类的处理能力。
- **试单量**：单一品类控制在**1–3天销量**或**1个整件/托盘为单位**，总量以"即使全损也能接受"为上限。生鲜行业常见做法是首单金额不超过单日采购预算的1–2倍。

## 三、品质标准必须书面化（最容易踩的坑）

试单前去谈口头的"品质好"没有约束力，要把标准写进订单或往来记录：

- **规格**：单果重量区间、大小分级（如70–80mm）、装箱颗数
- **外观**：成熟度（几成熟）、颜色、允许的瑕疵比例
- **包装**：箱型、单箱净重、内衬、是否有产地/批次标识
- **验收标准**：允许的腐烂率/次果率（例如到货抽检次果率≤5%）、超标如何扣款或退货
- **交付**：交货时间窗口、交货地点、运费谁承担、数量短溢的允许范围

建议做成一张**简单的验收单**，到货即抽检记录。

## 四、试单执行的关键动作

1. **小单分次**：如果预算允许，把试单拆成2次（间隔一周），看品质是否稳定，还是一次性碰运气。
2. **到货即验**：当场开箱抽检（按比例抽查，如每批抽3–5箱），拍照留证，记录重量、瑕疵、成熟度。
3. **跟踪一周**：水果问题常在存放2–3天后暴露（如内部腐烂、催熟不均），记录货架期表现。
4. **测试异常响应**：故意如实反馈一个小问题（如个别箱短重），看对方是推诿还是积极补货/补偿——这是判断能否长期合作的最有效信号。
5. **结算方式**：首单尽量**货到验收后付款**或小额预付，不要一次性大额预付；明确账期和发票。

## 五、怎么判断"通过/不通过"

建议事先定好阈值，例如：

- 到货次果率/腐烂率在约定范围内、连续两批稳定 → 可进入加量阶段
- 交货准时、数量误差在允许范围 → 履约合格
- 出问题时24–48小时内给出补救方案 → 配合度合格
- 若出现**以次充好、短重不认、拖延处理**任一情况 → 直接淘汰，不因价格便宜妥协

## 六、常见误区

- ❌ 试单只看价格最低的供应商——低价往往对应品质波动大
- ❌ 试单量按"整批便宜"拿太多——失去试单意义
- ❌ 只验到货不跟踪货架期——水果的坑多在存放后暴露
- ❌ 不写标准只凭口头——出纠纷时无据可依
- ❌ 一次试单就签长期框架——应"试单→小批量稳定单→加量/签框架"三步走

**一句话总结**：用"1–3个品类、1–3天销量、书面验收标准、分2次到货、跟踪一周货架期、测一次异常响应"这套组合，用最低成本把供应商的真实水平摸清楚，再决定是否加量。
