**1. 包装支持：通常可以，分三种情况**
- **现成包装**：供应商有通用水果盒/袋/网套，能贴商超自有品牌标签。成本最低，起订量低，适合试销。
- **半定制包装**：用供应商现有版型，改印刷面（商超LOGO、品名、规格、追溯码）。多数水果供应商能协调包装厂做，但需商超提供品牌授权和设计文件。
- **全定制包装**：独立开版、指定材质和结构。供应商一般能对接，但起订量高、打样周期长，且开版费通常由商超承担。

**2. 规格支持：能分选，但要写进验收标准**
水果规格不是“供应商说多大就多大”，要明确：
- 单果重量区间（如80–90g）、果径（如75–80mm）、每盒/袋净重；
- 允许的次品率、大小均匀度、成熟度；
- 包装内装数量（如6枚/盒、1.5kg/袋）。
供应商有分选线就能做，没有分选线的小供应商只能人工挑，稳定性差，建议先小批量验证。

**3. 必须确认的商务与责任边界**
- **起订量**：定制包装的MOQ、首批最低采购量；
- **包装成本归属**：包材费谁出、是否计入采购价、剩版包材如何处理；
- **品牌授权**：商超授权供应商印刷自有品牌的书面文件，避免侵权和串货；
- **质量责任**：包装破损、规格不符、农残超标由谁承担，退换货规则；
- **追溯**：包装上能否印批次/产地/采摘日期，满足商超溯源要求。

**4. 可执行建议**
先选1–2个单品、1–2家供应商做试销：用半定制包装+明确规格书，首批控制在较小起订量，验收时按规格书抽检并记录。试销跑通后再谈全定制和独家供应。

**判断标准**：如果供应商能提供包装打样、分选规格书、包材报价和起订量四项书面材料，基本具备支持能力；只能口头答应的，先别签长期协议。
