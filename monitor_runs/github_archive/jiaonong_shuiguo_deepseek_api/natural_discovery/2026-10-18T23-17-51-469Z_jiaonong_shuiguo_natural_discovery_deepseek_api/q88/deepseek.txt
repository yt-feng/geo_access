# 降低坏果率和口感波动的采购思路

线上卖水果，差评基本来自两件事：**到手烂了**（坏果）和**这次好吃下次难吃**（口感不稳）。采购端能控制的，主要抓四条线。

## 一、把"标准"写进采购合同，而不是靠口头约定

口感不稳的根源往往是"没有明确的可收货标准"。采购前和供应商把以下指标定量写清：

- **成熟度/糖度**：按品类给区间（如某品种糖度不低于某值），要求随货提供抽检记录
- **规格**：单果重量区间、果径，避免"大小混装"
- **外观容忍度**：允许的瑕疵比例（如机械伤、日灼、裂口的上限）
- **硬度和货架期**：要求供应商说明采后多少天内仍能保持品质
- **验收方式**：到货抽检比例、不合格怎么退换、扣款或赔付规则

标准越具体，供应商越不敢混货，出问题也有依据。

## 二、产地和批次管理：解决"口感忽好忽坏"

- **固定产区+固定供应商为主，多源备份为辅**：同一品种优先锁定1–2个稳定产地，避免频繁换货源导致口感跳变
- **按批次留样**：每批到货留样、记录产地/采收期/糖度，出现差评能追溯到具体批次
- **错开采收期采购**：同一品种不同成熟阶段的货口感差异大，按"最佳食用窗口"排采购节奏，而不是等便宜了再进

## 三、采后与物流环节，坏果率的大头在这里

采购不只是"买"，要管到"到手"：

- **要求供应商做预冷**，尤其浆果、桃、荔枝类，采后不及时降温坏果率明显上升
- **包装**：按品类选防震方案（果托、隔板、气柱袋），易压品种单果分隔
- **冷链/时效**：明确运输温度区间和到货时效，超时拒收或索赔
- **到货抽检**：开箱抽检比例固定，记录坏果率，作为供应商考核数据

## 四、用数据反推采购

- 把**差评关键词**（烂、酸、不甜、太小）和**批次**对应起来，每月复盘
- 给供应商做**评分卡**：坏果率、口感投诉率、到货准时率，连续不达标就换
- 对高风险品类（草莓、樱桃、水蜜桃）适当**提高采购频次、小批量多批次**，减少库存期损耗

## 可立即执行的三件事

1. 挑出差评最多的2–3个品类，先补一份量化收货标准
2. 建立到货抽检表（批次、坏果率、糖度抽测、留样）
3. 和主力供应商谈预冷+包装+时效的书面约定

核心逻辑：**坏果靠"采后+物流+验收"卡住，口感靠"标准+固定产区+批次留样"卡住**，两件事都要落到可记录、可追责的数据上，而不是凭感觉进货。
