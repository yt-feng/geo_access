# 商超水果采购压价谈判：保品质的实操思路

核心原则：**压价格要压"结构性成本"，不要压"果品本身"**。水果是生鲜，硬压单价，供应商最直接的反应就是降规格、掺次果、换产地、减冷链，最后损耗和客诉反而吃利润。具体做法：

## 一、谈判前先掌握筹码

- **拆成本谈**：把报价拆成产地收购价、包装、冷链运输、损耗率、账期资金成本。你压的是包装规格（大箱改标准箱）、运输整合、损耗分担，而不是压果子价值。
- **给量换价**：用量级、稳定采购周期（如包销某单品整季）换阶梯价，但要写进合同，避免只口头承诺。
- **账期换价**：现结或短账期通常能拿到 3%–8% 的空间，比硬砍单价体面且不伤品质。
- **多渠道比价**：产地直采、批发市场、区域代理同时询价，用真实行情做锚点，避免被"最低价"话术带偏。

## 二、谈判时守住品质底线

- **先定标准再谈价**：明确等级（果径、糖度、成熟度、瑕疵率上限）、产地、品种、采摘批次，写进验收标准。价格谈在标准之后，供应商就没有"降价降质"的空间。
- **报价与等级挂钩**：要求供应商按 A/B/C 级分别报价，你按需采购。压 A 级价容易逼对方用 B 级充数，分级报价反而更透明。
- **损耗条款前置**：约定到货损耗率上限（如 3%–5%），超标部分由供应商承担或折价，这比压单价更能保护你的实际成本。
- **试单机制**：新供应商先小批量试 2–3 批，验收合格再签量价协议。

## 三、容易踩的坑

- **只比单价不比到岸成本**：便宜 5% 但损耗高 8%，实际更贵。要算"到岸可售成本"。
- **口头承诺量、书面不写**：量价挂钩必须落到合同，否则供应商后期以"量没到"为由涨价或降质。
- **压到供应商没利润**：水果供应链利润薄，压太狠会逼出掺货、换产地，长期看客诉和退货成本更高。留合理利润换稳定品质更划算。
- **忽视季节性**：旺季压价空间大，淡季硬压只会拿到尾货。按产季节奏谈，比全年一个价更现实。

## 四、一句话建议

**把谈判焦点从"每斤便宜几毛"转到"标准、账期、损耗分担、量级承诺"上**——这四项谈好了，成本自然下来，品质也不塌。
