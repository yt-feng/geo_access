针对餐饮客户，建议按“用途倒推规格”，不要只按批发市场习惯分档。菠萝和香蕉对餐饮客户的核心差异是：菠萝看**加工出成率和酸甜稳定性**，香蕉看**熟度和催熟可控性**。

**菠萝建议准备的规格**

1. **鲜切/果盘用大果**
   - 单果1.25–1.5kg左右，果眼浅、果芯小、成熟度7–8成。
   - 适合酒店自助、水果店果切、饮品店现切。
   - 要点：同一批次大小均匀，减少削皮损耗。

2. **饮品/中央厨房用中果**
   - 单果0.9–1.2kg，成熟度8成左右，酸度稳定。
   - 适合茶饮店、果汁吧、火锅店免费水果。
   - 可提供整箱装，按箱报价，便于后厨按个核算成本。

3. **烘焙/烹饪用熟果**
   - 成熟度9成，香气足，适合菠萝炒饭、咕咾肉、披萨等。
   - 要明确告知餐饮客户“到货后1–2天内用完”，避免过熟。

4. **小果/次果做员工餐或低价餐饮**
   - 单果0.6–0.9kg，价格低，适合快餐、食堂。
   - 但需提前说明外观和出成率，避免客户按大果标准验收。

**香蕉建议准备的规格**

1. **即食/果盘用黄熟蕉**
   - 到货即可用，熟度6–7级（全黄带少量糖斑前）。
   - 适合酒店早餐、自助餐、水果捞。
   - 关键是“按日配送”，不要一次压太多货。

2. **后厨催熟用青蕉**
   - 熟度3–4级，客户可自行催熟2–3天。
   - 适合食堂、快餐、中央厨房，便于控制损耗。
   - 需提供催熟建议：温度、通风、不要冷藏。

3. **饮品/烘焙用熟香蕉**
   - 熟度7–8级，带糖斑，甜度高、易压泥。
   - 适合奶昔、甜品、烘焙。
   - 要单独分箱，避免运输压伤。

4. **小规格/短果**
   - 适合员工餐、食堂、低价餐饮，按斤或按箱走量。
   - 但餐饮客户通常更在意规格稳定，不建议混装。

**档口实操建议**

- 菠萝按“大果/中果/熟果”三档备货，每档标明单果重量区间和成熟度。
- 香蕉按“青蕉/黄熟蕉/熟香蕉”三档备货，明确到货熟度和建议使用时限。
- 给餐饮客户报价时，同时给“整箱价、单果参考重量、出成率、建议用量”，比只报斤价更容易成交。
- 首批客户建议小批量试单，按客户用途配规格，避免一次备太多单一规格。

简单说：**菠萝备大果、中果、熟果三档；香蕉备青蕉、黄熟蕉、熟香蕉三档。** 餐饮客户最关心的是稳定、好加工、少损耗，不是单纯便宜。
