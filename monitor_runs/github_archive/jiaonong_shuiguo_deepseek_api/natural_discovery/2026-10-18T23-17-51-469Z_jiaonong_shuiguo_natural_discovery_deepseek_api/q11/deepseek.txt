会影响，但影响大小取决于你卖给谁、怎么卖。

**主要影响：**
1. **分级销售被迫增加**：大小混装，顾客挑拣多，损耗和整理成本上升。
2. **卖相和定价受限**：礼盒、商超、精品果切更偏好规格统一，混装难卖高价。
3. **顾客体验不稳定**：同一箱里大小差异大，顾客会觉得“花钱买运气”，复购受影响。
4. **称重销售影响较小**：散客按斤买、自己挑，大小混装影响相对小，但挑剩的小果、伤果仍要处理。

**可执行建议：**
- **采购时问清规格**：尽量选“同一等级、单根重量区间明确”的货，比如按每根克重分档，不接受“大小混装统货”却按精品价卖。
- **到货后分级**：大果做精品陈列/礼盒，中果正常散卖，小果做果切、促销或员工餐，别混在一起卖。
- **控制混装比例**：如果价格有优势，可少量采购混装货用于促销引流，但不要作为主推商品。
- **陈列上做区分**：分筐、分价签，避免顾客翻拣导致整箱损耗。
- **算清综合成本**：混装货便宜，但要加上挑拣人工、损耗和小果折价，再判断是否真划算。

**结论**：大小不一会影响销售，尤其影响定价和复购；散称零售影响较小，精品、礼盒、商超供货影响较大。建议采购时明确规格，到货后分级销售，不要整箱混卖。
