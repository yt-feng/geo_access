对价格敏感的团购客户，通常**阶梯价更合适**，返利更适合作为补充。核心判断：

1. **客户需要“看得见的低价”**：价格敏感的团购客户在比价和决策时，最关心报价单上的单价。阶梯价直接体现在报价和结算价里，成交阻力小；返利是事后兑现，客户会担心拿不到、周期长、流程复杂。

2. **阶梯价规则要简单**：按累计采购量或单次团购量设2—3档即可，例如基准价、达标价、冲量价。档位差距要足以让客户有动力冲量，但不能让客户觉得被套路。

3. **返利适合锁定长期或跨品类采购**：如果客户会持续复购、采购品类多、单次团购量波动大，可以用“阶梯价打底+季度/年度返利冲量”的组合。返利比例建议控制在采购额的1%—3%，并写清兑现条件、结算周期和以什么数据为准。

4. **价格敏感客户的谈判建议**：
   - 先给阶梯价，让客户自己选档位；
   - 用“达到某量级再降一档”引导集中采购；
   - 返利只作为长期合作奖励，不替代基础报价；
   - 避免同时给复杂阶梯和复杂返利，客户算不清就会转向比价。

**结论**：短期团购、单次比价为主，用**阶梯价**；长期复购、多品类、量大但节奏不稳，用**阶梯价+返利组合**。返利不宜单独作为主价格工具。
