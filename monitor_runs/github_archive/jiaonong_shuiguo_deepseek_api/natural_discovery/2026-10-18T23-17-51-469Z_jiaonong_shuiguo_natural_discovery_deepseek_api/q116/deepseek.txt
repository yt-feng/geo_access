小商家采购水果，现金结算和月结账期各有风险，核心要看你自己的现金流、供应商稳定性和货品损耗速度。

**现金结算的风险：**
1. **资金占用与断档**：一次性付现会压占流动资金，遇到压货、滞销或突发支出时容易周转紧张。
2. **采购冲动**：现金在手容易多拿货，水果损耗快，多拿未必多赚。
3. **价格未必最优**：部分供应商对现结给低价，但也有可能借“现结优惠”抬高原价，需要对比净价。
4. **安全与对账风险**：现金当面点清、保留收据，否则出现短少、假币、口头改价时难追溯。
5. **供应商依赖**：现结通常换供应商灵活，但也可能拿不到紧俏货或稳定货源。

**月结账期的风险：**
1. **账期违约与坏账**：水果行业账期常见但风险高，供应商跑路、质量争议、对账不清都可能变成纠纷。
2. **隐性成本**：月结报价通常比现结高，等于把资金成本转进采购价，要算清“账期价差”是否划算。
3. **过度采购**：账期容易让人感觉“没花钱”，导致订货量失控，水果损耗直接吃掉利润。
4. **对账与证据风险**：必须保留送货单、验收单、质量异议记录，否则月底对账容易扯皮。
5. **关系绑定与断供风险**：长期月结可能形成依赖，一旦供应商提价、缩账期或断供，旺季会很被动。
6. **现金流错配**：你的销售回款若慢于月结付款，容易出现“账面有利润、手里没现金”。

**可执行建议：**
- 小额、高频、易损耗品优先现结或短账期，争取现结净价。
- 月结只给稳定、可追溯、能签简单供货单的供应商，账期控制在7—15天更稳。
- 每笔采购记录：品名、等级、单价、数量、损耗验收、付款方式，月底对账。
- 比较“现结价”和“月结价”的实际差额，若月结加价超过你资金成本，选现结。
- 保留2—3家备用供应商，避免被单一账期绑定。
