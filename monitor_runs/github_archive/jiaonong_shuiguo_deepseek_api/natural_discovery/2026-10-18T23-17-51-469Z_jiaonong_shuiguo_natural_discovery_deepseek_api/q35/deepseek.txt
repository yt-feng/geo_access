# 连锁超市降低门店坏果率的合同赔付约定建议

坏果率的责任通常跨多个环节（产地/供应商—物流—配送中心—门店），合同里最关键的是**把"坏果率"定义清楚、把责任环节切开、把赔付标准和流程写成可执行的动作**。建议按以下结构约定：

## 一、先定义，再谈赔付

没有统一定义，赔付条款必然扯皮。合同中应明确：

- **坏果口径**：腐烂、霉变、软烂渗汁、机械压伤、冻伤/冷害、裂口等分别是否计入；轻微外观瑕疵（如表皮擦伤不影响食用）是否剔除。
- **计量方式**：按件数、重量（kg）还是货值金额计算；抽样还是全检。
- **统计时点与主体**：到货验收时、门店上架前、还是货架期内第 N 天；由谁统计、双方是否共同签字确认、是否拍照留证。
- **基准值**：约定"允许自然损耗率"（如叶菜 3%–5%、浆果类可更高），超出部分才算供应商责任，避免把正常损耗转嫁。

## 二、按环节切分责任

- **到货验收环节**：验收时坏果率超过约定阈值的，可拒收、部分拒收或折价接收，费用由供应商承担。
- **配送中心到门店环节**：因运输、装卸、冷链断链造成的坏果，由承运方/配送方按货值赔付；合同应约定承运方对温控记录（温度曲线）的举证义务。
- **门店货架期环节**：区分"到店即坏"与"存放期内坏"。后者要看是否属于供应商质量问题（如未成熟采收、带病入库），还是门店陈列/温控不当。建议约定：到店后 X 小时内报损可归责供应商，超时需门店举证温控合规。

## 三、赔付标准写成可计算公式

避免"按实际损失赔偿"这种模糊表述，建议：

- **阶梯赔付**：坏果率在阈值至 A% 之间，按超出部分货值 1 倍扣款；A% 至 B% 按 1.5–2 倍；超过 B% 可整批退货并计违约。
- **扣款方式**：优先从当期货款中直接扣减，不足部分供应商补足；或设质量保证金，按批次扣罚。
- **连带损失**：明确是否包含门店报损、促销折价损失、客诉赔偿；建议设上限（如不超过该批次货值的 3 倍），避免无限责任争议。
- **重复问题加重**：同一供应商月度坏果率超标 N 次，触发整改、降级或终止合作。

## 四、流程与举证

- 约定**报损时限**（如到货 24 小时内、货架期内发现 48 小时内）和**证据要求**（照片、视频、称重记录、温控数据）。
- 约定**异议期**：供应商在收到赔付通知后 X 个工作日内可提出复核，逾期视为认可。
- 明确**争议解决方式**：共同委托第三方检测，费用由责任方承担。

## 五、几个容易漏的点

- **不可抗力与免责**：自然灾害导致产地质量下降是否免责、如何举证。
- **包装与冷链义务**：供应商对包装规格、预冷、运输温度的责任，写入验收标准附件。
- **数据留痕**：要求供应商随货提供采收日期、批次、产地，便于追溯定责。
- **与返利/账期联动**：坏果扣款是否影响年度返利计算基数，提前写清。

**一句话建议**：把"坏果率"拆成到货、运输、货架三段，每段设阈值、设公式、设举证责任和时限，赔付优先走货款扣减，并配质量保证金兜底。这样条款才既公平又能落地执行。
