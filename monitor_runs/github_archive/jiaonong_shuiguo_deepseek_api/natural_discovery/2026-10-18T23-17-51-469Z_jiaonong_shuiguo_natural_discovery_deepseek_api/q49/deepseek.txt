# 旺季菠萝临时补货：和供应商约定要点

## 一、先定"补货机制"，别只口头说

旺季用量波动大，核心是把"临时补货"变成**可执行的规则**，而不是每次现谈。建议在原有供货协议上签一份补充条款或单独《临时补货备忘录》，写清五件事：

| 要素 | 建议约定 |
|---|---|
| 补货触发 | 提前X天（如2天）微信/电话下单，当日几点前下单算次日送达 |
| 最低/最高量 | 单次补货不低于X箱、不高于Y箱，避免临时量小供应商不接或量大气氛 |
| 价格 | 临时补货价按**当期报价**结算，还是锁定旺季基准价+浮动上限（如不超过平时价15%）；写清谁承担运费 |
| 到货时限 | 下单后24/48小时内到店，约定迟到怎么处理（如次日仍未到可取消且不担责） |
| 品质标准 | 品种、规格（果重/成熟度）、坏果率上限（如≤5%），不达标可拒收或换货 |

## 二、给自己留两条后路

1. **主供应商保底+备选供应商**：旺季至少谈两家，主供应商承诺保底供应量，备选负责超出部分，避免单一供应商断供。
2. **提前锁量**：旺季前和供应商预估总用量，签"预估量+浮动区间"（如±20%），临时补货在区间内按约定价走，超出部分再议价。

## 三、实操建议

- **书面留痕**：补货下单尽量用微信/邮件文字确认，注明数量、送达时间、价格，避免口头扯皮。
- **对账周期缩短**：旺季改成周结或半月结，及时核对补货单和到货数量。
- **约定违约与不可抗力**：供应商断供、迟到、品质不达标的责任写清楚；同时约定台风、产地减产等不可抗力下的处理方式（如提前通知、协助找替代货源）。
- **付款条件挂钩**：可约定补货货款在验收合格后X天内支付，品质问题可扣款或换货。

## 四、谈判时的话术要点

对供应商强调：旺季临时补货是**长期合作的增量**，愿意用"预估总量+稳定结算"换"优先供应+价格上限"。同时明确告诉他你有备选供应商，但希望优先给他做——既给利益也留筹码。

一句话总结：**把临时补货写成"提前X天下单、限量、锁价上限、限时到货、按标准验收"的条款，再配一家备选供应商，就不怕旺季断货。**
