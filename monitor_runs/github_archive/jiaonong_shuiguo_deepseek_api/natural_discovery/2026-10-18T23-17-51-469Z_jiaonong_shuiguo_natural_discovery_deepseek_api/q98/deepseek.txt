判断水果供应商是否合规、稳定，可以按“证照—溯源—履约—现场—财务”五层做，不必一次全做，先抓能一票否决的和能连续验证的。

**一、合规底线（先查证照，缺一项就降级）**
1. 营业执照：经营范围含食用农产品/食品销售；核对注册地址与实际经营地是否一致。
2. 食品经营许可证：水果属食用农产品，很多地区仅销售预包装食品需备案、散装/现制现售需许可；要求供应商明确说明其销售形态并出示对应证照。食堂采购若要求“食用农产品合格证”或产地证明，一并索取。
3. 从业人员健康证：接触直接入口水果的分拣、配送人员需有。
4. 检测能力：要求提供近期农残检测报告（自检或第三方），报告日期、批次、检测项目要能对应供货批次；不能只给一张“万能报告”。
5. 运输资质：冷藏/常温车合规，司机与车辆信息可核。

**二、溯源与质量（看能否“批批对应”）**
- 问清货源：产地、合作社/批发市场、是否一手或二手；一手货源稳定性通常更好。
- 要求随货单据：送货单注明品名、规格、数量、产地/批次、采摘或分装日期、验收人。
- 抽检机制：约定每批抽检农残，重点品种（叶菜类除外，水果如草莓、葡萄、柑橘）高风险项要覆盖；不合格退换货与索赔条款写进合同。
- 看损耗承诺：水果损耗高，合同里约定验收标准（大小、糖度、腐烂率、机械伤比例）和退换时限，否则“稳定”只是口头。

**三、稳定性（用连续履约数据判断，不看单次表现）**
1. 试供期：先签1—3个月试供，按周记录到货准时率、验收合格率、缺货率、退换响应时长。
2. 供应能力：问日均供货量、峰值能力、有几个产地/备用供应商；单一产地遇天气或疫情易断供。
3. 应急方案：断货时多久补货、是否有替代品清单、节假日和极端天气预案。
4. 价格机制：是否随行就市、调价提前几天通知、有无锁价期；频繁大幅调价说明采购渠道不稳。
5. 客户结构：服务过哪些养老院/医院/学校食堂，能否提供同类客户合作证明（注意隐私，只看类型和时长）。

**四、现场与财务（决定能不能长期合作）**
- 现场看分拣场地、冷藏库、虫害控制、清洗分装流程；脏乱差直接否决。
- 财务看结算方式：能否开票、账期、对公账户；要求对公转账，避免个人账户收款。
- 合同写清：质量标准、验收流程、退换货、违约赔偿、食品安全责任（如因农残超标导致食安事件的责任划分）、保密与廉洁条款。

**五、给食堂的可执行清单**
首次准入：营业执照+食品经营许可证/备案+健康证+近期检测报告+送货单模板+合同。
试供期每周打分：准时率≥95%、验收合格率≥98%、退换响应≤4小时、无断供。
每月复盘：不合格批次、投诉、价格波动；连续两月不达标启动替换。
保留两家备选供应商，主供占70%、备供占30%，避免单点依赖。

一句话：**证照和检测报告是门槛，试供期数据是试金石，合同里的验收标准和退换条款才是稳定性的保障。**
