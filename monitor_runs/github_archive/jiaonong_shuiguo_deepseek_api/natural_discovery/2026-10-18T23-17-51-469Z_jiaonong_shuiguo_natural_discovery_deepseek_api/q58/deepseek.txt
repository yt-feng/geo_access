通常**直接买成品果丁的损耗更低**，但要看你的门店销量、配送频次和验收能力。

可以按下面判断：

1. **损耗口径先分清**
   - 鲜果损耗：去皮、去眼、切边、氧化变色、过熟报废、冷藏失水。
   - 成品果丁损耗：到货短重、化水出水、过期报废、配送频次不足导致的临期损耗、品质不稳定退货。

2. **一般结论**
   - 日用量不大、切配人手紧、菠萝成熟度不好控：**成品果丁通常更低**，因为免去削皮切丁和鲜果熟度波动。
   - 日用量大、周转快、有稳定切配人员：**鲜果可能更划算**，但损耗管理要求高，尤其是成熟度、冷藏和当日用完。
   - 如果成品果丁配送频次低、包装大、开封后必须当天用完，那成品损耗也可能高。

3. **建议做7天对比测试**
   - 同一甜品用量下，分别记录：采购重量、可售重量、报废重量、工时、冷藏占位、到货不合格重量。
   - 计算：**损耗率 = 报废重量 ÷ 采购重量**，同时算**每公斤可售果丁综合成本**，把人工和报废都算进去。
   - 如果成品果丁综合成本不高于鲜果切配的90%，优先成品；如果接近或更高，再考虑鲜果。

4. **采购成品果丁要盯验收**
   - 到货温度、出水情况、色泽、异味、净重、保质期剩余天数。
   - 要求小包装、高频配送，避免大包装开封后用不完。

**简单决策：销量小或人手不稳选成品果丁；销量大且能当日周转、切配稳定再选鲜果。** 最终以7天实测损耗率和综合成本为准。
