茶饮店用香蕉，核心不是“买最熟的”，而是按用途分批控制熟度，并且把“到货熟度”和“使用窗口”分开管理。

**1. 先按用途定熟度标准**
- **做冰沙/奶昔/香蕉牛奶类饮品**：用**7～8成熟**，果肉偏硬、香气足、切块不易烂，打出来不容易发黑发黏。
- **做果泥、厚乳、甜品夹层**：用**8～9成熟**，软糯、甜度高、易压泥。
- **做表面装饰、现切果片**：用**6～7成熟**，形状完整、不易氧化变软。
- **做香蕉蛋糕/布丁/烤香蕉类甜品**：可用**9成熟到全熟**，香气和甜度最好。

建议门店把香蕉分成**A果（装饰/饮品）**、**B果（果泥/甜品）**两档采购，不要一批全买同一熟度。

**2. 采购时看“可操作熟度”，不要只看颜色**
香蕉熟度建议用“颜色+手感”双指标：
- **6成熟**：青黄，硬度高，适合存放。
- **7成熟**：黄底带少量绿，按下去略硬，适合饮品切块。
- **8成熟**：全黄，微软，适合果泥和甜品。
- **9成熟**：出现少量糖斑，软，香气强，适合当天做泥/烤制。
- **过熟**：大面积黑斑、果肉发透明、有酒味，不建议再用于饮品。

采购单上可直接写：**“黄底微绿、硬度适中、无大面积黑斑”**，比只写“熟香蕉”更可执行。

**3. 按使用量分批到货**
茶饮店香蕉损耗主要来自“一次到太熟”。建议：
- 每天用量稳定的店：按**2～3天用量**订货。
- 香蕉饮品占比高的店：每周到货**2～3次**，每次混合到货：**70% 7成熟 + 30% 8成熟**。
- 不要一次全部买9成熟，除非当天做果泥或甜品。

**4. 到货验收标准**
拒收或降级使用的情况：
- 果柄发黑腐烂、果皮大面积破损；
- 有酒味、酸味；
- 果肉已透明化；
- 整批过软，按压后不回弹。
到货后按熟度分筐，贴上“到货日期+建议使用日”，先进先出。

**5. 门店存放控制**
- **7成熟**：常温阴凉处存放，避免冷藏，香蕉冷藏易表皮变黑。
- **8～9成熟**：尽快使用；夏天可放空调房或冷藏短时延缓，但冷藏后表皮会黑，不影响果肉时也要尽快处理。
- **已切开的香蕉**：不建议久放，果泥当天用完。
- 需要延缓成熟时，把香蕉**分开、通风、避免堆压**；需要催熟时可与苹果同放，但茶饮店不建议大批量催熟，容易失控。

**6. 设定“使用窗口”**
建议门店直接规定：
- 7成熟：到货后**1～2天**用于饮品；
- 8成熟：**当天到次日**做果泥/甜品；
- 9成熟：**当天**处理完，做果泥、烤制或甜品，不再做装饰。

**简单执行方案：**
采购时要求供应商按“**黄底微绿、硬度适中**”发货；门店到货后分A/B两筐，A筐7成熟做饮品，B筐8～9成熟做果泥甜品；每天按2～3天用量补货，出现糖斑的香蕉当天转做果泥或甜品，不进入装饰和鲜切环节。这样比单纯追求“全熟”更稳，损耗也更好控。
