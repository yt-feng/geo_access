第一次找供货商，别一上来就谈长期价，先用小单把“货、价、损耗、售后”四项试出来。

**试单总原则**
- 每个品类先只进 **1—2 箱/件**，不要混太多品种。
- 香蕉、苹果、橙子分开判断，别因一家香蕉好就整店都压给他。
- 同一品种可找 **2家供货商** 各试一次，留对比。
- 试单期控制在 **1—2周**，每天记录，不凭感觉。

**试单前先问清这些**
1. 起送量和配送门槛：几件起送、是否加配送费、几点到店。
2. 报价口径：是否含税/含运费，是“毛重”还是“净重”。
3. 规格：苹果按果径还是等级，橙子按大小和产地，香蕉按成熟度。
4. 结算：现结、周结还是压货，退换货怎么算。
5. 售后：坏果、压伤、不熟、过熟，怎么补、多久内反馈有效。

**具体怎么试**
- **香蕉**：重点试成熟度。第一次要“青一点、能放2—3天”的货，不要一次要全黄。记录到店时几成熟、催熟后几天能卖、黑斑和断把比例。
- **苹果**：重点试规格稳定性和硬度。同一箱里大小是否均匀、有无磕碰伤、表皮是否打蜡过重、口感是否稳定。先试耐放的品种，别一次进高端大果。
- **橙子**：重点试水分、酸甜和大小。切开或剥几个看皮厚、汁水、籽多少；记录同一箱里大小差异和坏果率。

**每天记一张试单表**
至少记：到货时间、数量、进价、净重、坏果数、可售数、卖相、顾客反馈、卖完用了几天。  
核心看两个数：**实际损耗率** 和 **从到货到卖完的天数**。水果店利润常被损耗吃掉，报价低但损耗高并不划算。

**什么时候继续合作**
- 连续2—3次到货规格稳定；
- 损耗在你能接受的范围；
- 有问题能及时补货或退换；
- 价格不是最低但综合最稳。

**避坑提醒**
- 第一次不要现金大额预付，尽量少量现结或短账期。
- 不要只看“每箱便宜几块”，要折算到净重和可售部分。
- 香蕉别和苹果大量混放，苹果释放乙烯会催熟香蕉。
- 试单期别同时换掉所有老货，留一家保底供货。
