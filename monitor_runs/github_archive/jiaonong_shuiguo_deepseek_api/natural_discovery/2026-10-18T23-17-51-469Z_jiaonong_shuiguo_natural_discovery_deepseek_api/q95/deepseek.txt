选水果供应商，核心不是“找最便宜的”，而是先把风险控制住，再比价格。学校食堂有食品安全和稳定供应的硬约束，建议按下面顺序做。

**一、先定采购标准，再找供应商**
- 明确品类规格：香蕉按每根大小/每箱净重、成熟度（青转黄比例）定；苹果按果径、品种、糖度、外观瑕疵率定；橙子按果径、酸甜度、可食率定。
- 明确验收标准：到货新鲜度、破损率上限（如单箱破损不超过3%—5%）、农残检测报告随货、冷链或常温运输要求。
- 明确结算与退换：账期、缺货补货时限、质量问题退换货责任、临期或过熟处理方式。

**二、供应商来源优先顺序**
1. 学校所在地的大型农产品批发市场有固定档口的经销商，便于现场看货、退换货快。
2. 本地果蔬配送公司，能提供检测报告、固定车辆和配送时效。
3. 产地合作社或基地直供，适合用量大、品类单一时压成本，但要核实资质和分拣能力。
4. 大型商超或生鲜平台的企业配送，价格偏高但票据和质检相对规范。

不建议只找一家，至少保持“主供应商+备选供应商”，防止断供和坐地起价。

**三、资质和现场核查**
要求提供营业执照、食品经营许可证或食用农产品相关资质、近期农残检测报告、配送车辆和仓储照片。条件允许实地看分拣场地、冷库和货源。重点问清楚：货源是产地直采还是市场调货、当天到货时间、缺货时怎么补。

**四、比价方式**
不要只比单价，按“到货净重+损耗率+配送费+退换货成本”折算实际成本。比如香蕉损耗高，报价低但破损多，实际成本可能更高。可以按月或按周询价，设定价格调整机制，避免长期锁价导致供应商偷工减料。

**五、试供和小批量验证**
新供应商先试供2—4周，记录到货准时率、破损率、口感稳定性、补货响应速度。试供合格再签正式合同。合同里写清验收标准、违约处理、食品安全责任和退出机制。

**六、日常管理**
每批到货留样和验收记录，定期轮换或评估供应商，避免单一供应商依赖。对香蕉这类后熟水果，要求按学校用量分批次配送，不要一次送太多导致催熟过剩。

简单说：**先定验收标准，再找本地有档口或配送能力的供应商，资质和检测报告齐全，试供后按“净重+损耗+服务”综合比价，保持主备两家。**
