建议按“能证明合规 + 能追溯到批次 + 能支持你抽检应对”的思路要资料，不要只要一张合格证。可向供应商提前索取以下材料：

1. **主体与资质资料**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按供应商性质）
   - 供货商与上游基地/合作社的采购合同或授权供货证明

2. **批次合格证明**
   - 该批次水果的**出厂检验报告/自检报告**
   - 或供应商委托第三方检测的**农残检测报告**
   - 报告要能对应：品种、产地、生产/采收日期、批次号、检测项目、检测依据、检测机构资质（CMA/CNAS）、报告日期

3. **产地与种植信息**
   - 产地证明/基地证明
   - 种植基地名称、地址、联系人
   - 若为“三品一标”或绿色/有机认证，可要认证证书及有效期

4. **承诺与追溯文件**
   - 质量安全承诺书
   - 农残合格承诺及违约责任条款
   - 批次追溯码/随货同行单，做到“一批一码/一单一报告”
   - 农药使用记录或基地投入品记录（能提供更好，至少对高风险品种要求）

5. **抽检应对资料**
   - 供应商联系人及应急响应流程
   - 不合格批次召回/换货承诺
   - 近半年同品种检测报告汇总
   - 运输、贮存环节温湿度记录（易腐水果）

**关键判断标准：**
- 检测报告必须是**对应批次**，不能拿“同品种长期报告”代替；
- 报告检测项目要覆盖常见有机磷、氨基甲酸酯、拟除虫菊酯等农残，并注明检测限；
- 优先选择能提供**基地直供+批批检测+追溯码**的供应商；
- 对高风险品种（如草莓、葡萄、豇豆类虽非水果但同理、叶菜）提高抽检频次，并在合同中约定抽检不合格的退货、赔偿和检测费承担。

实操上可做一张《供应商资料清单》，每批到货要求“随货三件套”：**送货单+批次检测报告+产地/追溯信息**，缺一项先收货待检或拒收。
