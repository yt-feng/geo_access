应该优先关注**切果损耗**，其次看**甜度和外观**，大小放在最后。

更具体地说：

1. **切果损耗优先**
   - 超市卖菠萝，真正影响利润的是：去皮、去眼、去头尾后的**出果率**。
   - 同样进货价，出果率差 5%～10%，毛利差别很明显。
   - 重点看：果眼深浅、皮厚不厚、果芯大不大、坏心/黑心比例、成熟度是否导致切后易烂。

2. **甜度要看，但要和损耗平衡**
   - 甜度影响复购和试吃转化，但超市不是水果专卖店，太熟虽甜却损耗高、货架期短。
   - 建议关注**稳定可接受的甜度**，不要一味追求最高甜。

3. **外观决定卖相和动销**
   - 外观影响陈列和顾客第一眼购买，但超市菠萝很多是切果或去皮销售，外观权重低于损耗。
   - 重点看：果形端正、无霉斑、无软烂、无裂口。

4. **大小最后看**
   - 大小影响客单价和陈列，但不是核心。
   - 中大果未必比中果赚钱，关键还是出果率和损耗。

**可执行建议：**
- 进货前做小批量切果测试，算**出果率 = 可售果肉重量 ÷ 毛重**。
- 优先选果眼浅、皮薄、果芯小、坏心率低的批次。
- 甜度用糖度计抽检，设一个最低可接受值，不必追求最高。
- 外观作为淘汰标准，大小作为陈列搭配，不作为首要采购标准。

一句话：**超市卖菠萝，先算损耗账，再谈甜度和卖相；大小不是核心。**
