判断供应商售后响应是否稳定，不能只靠口头承诺，建议在询价、打样、试单三个阶段用可验证的动作来测。下面按可执行程度排列：

**一、询价阶段：先做“响应压力测试”**
1. 用文字+电话双渠道提一个具体问题（如“菠萝到店后发现黑心病比例超标，多久内响应、谁到场、怎么赔付”），记录对方首次回复时间和答复是否具体。
2. 故意在工作时间外（如晚上或周末）发一次非紧急咨询，看是否有值班机制。生鲜售后往往发生在到货当天清晨，夜间无人响应是硬伤。
3. 要求对方书面给出售后时限：报损申请多久内受理、多久内补货或退款、争议由谁裁定。只给“放心，有问题找我”这类口头话术的，直接降级。

**二、合同与条款：把响应写成可考核指标**
1. 明确到货验收标准（菠萝黑心/水烂比例、香蕉青熟度与机械伤比例），以及超标后的处理方式：扣款、补货、退货三选一，写清触发比例。
2. 写入响应时限，例如“到货后2小时内受理报损，24小时内给出处理方案，48小时内完成补货或退款”，并约定超时违约金。
3. 约定对接人和备用联系人，避免只靠一个业务员，人一走售后就断。

**三、试单阶段：用小批量真实检验**
1. 先下1–2批小单，重点不是看货好不好，而是**故意走一次售后流程**：比如对轻微超标批次提出报损，观察对方是否按承诺时限处理、是否推诿、是否要求你承担不合理举证。
2. 记录三次售后的响应时长和处理结果，稳定性看的是“每次都差不多”，而不是“某次特别快”。
3. 问同行或现有客户要1–2个可联系的参考客户，重点问“出问题时对方拖不拖”。

**四、日常运营信号**
1. 看对方是否有固定的品控/售后岗位，而不是业务员兼管。
2. 看其是否主动提供到货抽检记录、产地证明、农残检测报告；愿意留痕的供应商，售后通常更规范。
3. 观察补货能力：香蕉、菠萝都是易损耗品类，售后稳定的前提是对方有稳定货源和冷链，否则承诺补货也补不上。

**判断结论可以很简单：** 书面条款齐全 + 试单中至少一次售后按承诺时限闭环 + 有可核实的参考客户，三者同时满足，才算“售后响应稳定”；缺一项就只算“有售后意愿”，采购时应保留备选供应商。另外建议同类品类至少保留两家合格供应商，避免单一依赖。
