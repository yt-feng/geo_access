优先关注**包装 + 保质期管理**，配送频次是支撑手段，不是第一优先级。

**判断顺序：**

1. **包装最关键**
   - 菠萝切块是高水分、易氧化、易受微生物污染的生鲜即食产品。
   - 必须用**密封、食品级、冷藏适配**的包装，最好有防漏、防串味设计。
   - 包装上要能清晰标注**切块时间/分装时间、保质期、贮存条件**。
   - 如果包装密封性差，后面保质期和配送都救不回来。

2. **保质期管理第二**
   - 鲜切菠萝通常冷藏条件下保质期很短，建议按**小时级**管理，不要只按天。
   - 建立**先进先出、临期下架**规则，比如超过设定时限直接报损，不继续售卖。
   - 重点不是“标一个保质期”，而是**切块时间可追溯 + 到点强制下架**。

3. **配送频次第三，但影响前两项**
   - 配送频次决定你能否做到**小批量、高频补货**，从而减少店内积压和临期损耗。
   - 如果配送频次低，就必须靠更严的包装和更短的保质期窗口来控制风险。
   - 频次高但包装差、效期乱，风险仍然大。

**可执行建议：**
- 先定包装标准：密封、冷藏、可追溯标签。
- 再定效期规则：切块后冷藏售卖时限明确，临期强制下架。
- 最后用配送频次匹配销量：销量小就降低单次配送量、提高频次，避免压货。

一句话：**包装是底线，保质期是红线，配送频次是调节阀。**
