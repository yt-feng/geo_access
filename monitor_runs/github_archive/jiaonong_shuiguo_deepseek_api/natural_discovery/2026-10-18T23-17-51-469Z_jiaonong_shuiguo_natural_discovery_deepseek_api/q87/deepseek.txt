旺季锁库存，核心不是“提前打招呼”，而是把**不确定的销量变成可执行的分批锁量合同**。建议按下面五步做：

## 1. 先做“可锁量”预测，不要拿拍脑袋销量去谈
- 用过去2—4周同品类销量、当前预售/接龙数据、去年同期旺季数据，算出三个量：
  - **保底量**：按近7天日均×旺季系数（保守）  
  - **目标量**：按预售+历史增幅  
  - **上限量**：爆单极限，仅作为调货参考
- 只拿**保底量+目标量**去和供应商锁，上限量用“优先补货权”解决，避免压死库存。

## 2. 合同里锁“量价+分批+违约”，而不是锁一句口头承诺
和供应商明确写清：
- **分批锁量**：例如每周一确认下周提货量，保底量必须保留，超出部分提前3天报量。
- **锁价周期**：约定7—15天价格保护，超期随行就市但涨幅封顶。
- **分级定金**：保底量付10%—20%定金锁货；目标量付少量诚意金锁优先权，不全额压款。
- **违约条款**：供应商缺货按差额赔偿或下一批折价；你方不提保底量则定金不退。
- **质量标准与验收**：规格、糖度、损耗率、坏果率、到货时限写进合同，避免旺季“以次充好”。

## 3. 用“组合锁仓”降低单一供应商风险
- 主供应商锁**60%—70%**保底量，副供应商锁**20%—30%**，留**10%**机动现货采购。
- 对易爆单品（如西瓜、荔枝、车厘子）至少备2个产区/2个供应商，防止天气或物流断供。
- 要求主供应商给**每日可发量上限**，避免爆单后他优先供大客户。

## 4. 把“锁库存”延伸到产地和仓储
- 能产地直发的，提前锁**果园/合作社的采摘档期**，比锁贸易商库存更稳。
- 与供应商谈**代储**：货放供应商冷库，你按日提货，降低自仓损耗和资金占用。
- 自仓提前预留**爆单缓冲区**，旺季前一周把保底量的30%—40%提前入库。

## 5. 建立每日滚动机制
- 每天下午更新次日销量预测，**下午4点前向供应商报次日提货量**。
- 设置库存红线：当某单品可售库存低于1.5天销量，立即触发补货和替代品预案。
- 爆单时优先保**高复购、高毛利**单品，低毛利引流品限量或改预售。

**一句话执行建议**：本周内用历史数据算出每个爆品的保底量/目标量，找主副供应商各签一份“分批锁量+锁价7天+缺货赔偿”的简单协议，先锁保底量，目标量用定金锁优先权，不要一次性全款压货。
