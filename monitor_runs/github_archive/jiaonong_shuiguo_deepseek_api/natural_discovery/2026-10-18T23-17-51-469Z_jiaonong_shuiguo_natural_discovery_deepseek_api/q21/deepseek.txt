超市采购水果时，建议按“供应商资质 + 批次合格证明 + 进货票据 + 必要时专项检测”四类材料索取和留存。具体可分两层看：

**一、常规必须留存的材料**
1. **供应商资质**
   - 营业执照
   - 食品经营许可证（或食品生产许可证，视供应商性质）
   - 若是农产品生产者/合作社，可提供社会信用代码证、种植主体证明等
2. **进货凭证**
   - 供货合同或采购订单
   - 送货单、销售单、发票或收据
   - 进货台账：品名、规格、数量、生产日期/采收日期、供货者名称地址联系方式、进货日期
3. **批次合格证明**
   - 食用农产品合格证/承诺达标合格证（很多产地已推行）
   - 供应商自检报告或委托检测报告
   - 批发市场出具的产地证明、质量安全检测合格凭证等

**二、按风险和要求补充的检测报告**
- **农残检测报告**：重点品种、高风险季节、首次合作供应商建议每批次或定期索取；报告应覆盖该批次或近期生产周期，含检测项目、结果、检测机构、日期。
- **重金属/污染物检测**：针对产地环境风险较高的品类，可定期索取。
- **承诺达标合格证**：对蔬菜水果类食用农产品，这是较常见的产地准出凭证。
- **进口水果**：需海关入境货物检验检疫证明、报关单等；预包装进口水果还应有中文标签。
- **绿色食品/有机/地理标志等认证**：如超市以认证产品售卖，需索取有效认证证书及对应检测报告。

**实操建议**
- 不要只收一张“检测报告”就完事，要核对**报告是否覆盖该供应商、该品种、该批次/近期批次**，避免张冠李戴。
- 对叶菜、草莓、豇豆、韭菜、芹菜等农残高风险品类，提高抽检和索证频次。
- 保留供应商提供的承诺达标合格证、快检单据和进货票据，至少保存至产品保质期满后6个月；无明确保质期的，保存不少于2年（以当地市场监管要求为准）。
- 超市自身也应建立进货查验记录和快速检测制度，不能把责任完全转给供应商。

一句话：**常规采购至少要“证照+合格证/检测报告+进货票据+台账”；高风险品类和进口水果再追加对应专项检测或检疫证明。**
