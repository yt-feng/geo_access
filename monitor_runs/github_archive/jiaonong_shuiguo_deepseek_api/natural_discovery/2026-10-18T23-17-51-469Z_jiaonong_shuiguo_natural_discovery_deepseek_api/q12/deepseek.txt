采购菠萝时，判断“合适熟度”的核心不是挑最熟的，而是按**预计售完时间**分批配货。水果店的损耗多来自“买得太熟、卖得太慢”。

### 1. 先定采购熟度：按销售速度分档

- **当天或次日能卖完**：可采购**七八成熟到全熟**，香气明显、果身略软，适合现切和即食。
- **2～3天卖完**：主采**六七成熟**，果皮由绿转黄、按压微弹，货架期更稳。
- **3～5天卖完**：采**五六成熟**，青黄相间、果身硬，放在店内常温后熟，少量上架催熟果。

不要一次全进同一熟度，建议按 **20%即食熟果 + 60%中期果 + 20%后熟青果** 搭配。

### 2. 现场判断菠萝熟度的可操作方法

**看：**
- 果皮从基部向顶部由绿转黄，**基部先黄**通常成熟度更可靠。
- 果眼扁平、间距均匀，不要选果眼深陷、表皮皱缩的。
- 冠芽青绿有活力；冠芽枯黄、易拔说明放久了。

**闻：**
- 果底有**清淡菠萝香**为合适；香气浓烈甚至发酸，说明过熟。
- 无香气通常偏生，可后熟。

**按：**
- 轻按果身有**轻微弹性**，不是硬如石头，也不能一按一个坑。
- 果底软塌、渗汁、有酒味，直接拒收。

**看切口/果心（如可抽检）：**
- 果肉金黄、果心不空心为成熟适中；果心发褐、水渍状是过熟或冷害。

### 3. 采购时的验收动作

- **分批试压**：每箱抽3～5个，按果底和中部，记录软硬度。
- **查底部**：翻看果底有无霉斑、渗液、压伤，菠萝损耗常从底部开始。
- **控温运输**：菠萝怕冷害，长途运输别低于7～10℃；到店后青果常温后熟，熟果尽快冷藏或切售。
- **先进先出**：青果放后排，熟果前排；每天翻检一次，把香气过浓、底部发软的挑出做现切或促销。

### 4. 简单判断口诀

**“基部转黄、底部清香、轻按微弹、冠芽青绿”** 为可上架熟度；**“香气浓、底部软、有酒味”** 说明已过熟，采购时要减量或拒收。

最实用的做法是：**按你店每天能卖掉的量，倒推采购熟度，宁可少量多次补货，不要一次压太多熟果。**
