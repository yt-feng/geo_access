直接给结论：**大多数茶饮店做菠萝果茶，优先用“冷冻菠萝果丁/果肉”，鲜果作为门店现切补充，果泥只用于特定口感或调味型产品。**

按场景判断：

1. **鲜果**
   - 适合：主打“现切鲜果”、客单价较高、销量稳定、门店有切配人手的店。
   - 优点：卖点好、香气自然、顾客感知强。
   - 缺点：菠萝批次差异大、削切耗人工、损耗高、酸甜不稳定，旺季和淡季品质波动明显。
   - 建议：鲜果只备当天用量，选成熟度稳定的品种，门店统一糖酸调整标准。

2. **冷冻菠萝果丁/果肉**
   - 适合：大多数连锁茶饮店、外卖占比高、出杯量稳定的店。
   - 优点：规格统一、出杯稳定、损耗低、操作快，能做“果肉感”；冷冻菠萝通常比长期冷藏鲜果更稳定。
   - 缺点：解冻后口感略软，香气不如现切鲜果突出。
   - 建议：优先选**速冻、无糖或轻糖、果丁大小适合吸管**的产品；解冻后当班用完，不要反复冻融。

3. **菠萝果泥/果浆**
   - 适合：做冰沙、奶昔、调味茶、需要稳定酸甜和颜色的产品；不适合作为唯一“果肉卖点”。
   - 优点：标准化最高、出杯快、酸甜稳定、成本可控。
   - 缺点：果肉感弱，顾客容易感知为“酱”而不是鲜果；用量不当会盖茶香。
   - 建议：选**果汁/果肉含量高、少香精、糖度明确**的产品，和果丁搭配使用。

**采购组合建议：**
- 小店/外卖为主：**冷冻果丁为主 + 少量鲜果做展示和顶料 + 果泥做冰沙类**。
- 鲜果主打店：**鲜果为主 + 冷冻果丁兜底**，避免断货和损耗。
- 连锁标准化店：**冷冻果丁 + 果泥复配**，鲜果只做季节营销。

**关键判断标准：**
- 产品定位是否强调“鲜切果肉”；
- 门店是否有稳定切配能力；
- 日出杯量和损耗承受能力；
- 供应商能否稳定供货、规格统一；
- 每杯成本按“可出杯量”算，不只看每公斤单价。

一句话：**要果肉感和稳定，选冷冻果丁；要鲜果卖点，鲜果少量现切；要冰沙和标准化，果泥辅助。不要只买果泥做“菠萝果茶”，顾客感知会偏弱。**
