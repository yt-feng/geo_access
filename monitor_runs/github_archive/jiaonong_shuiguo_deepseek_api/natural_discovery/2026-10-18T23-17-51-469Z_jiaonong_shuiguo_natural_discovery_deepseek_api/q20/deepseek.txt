社区超市找日配水果供应商，建议重点看下面这些条件，按优先级排：

1. **日配能力是否真实**
   - 是否每天固定时段送货，能否接受清晨到店，避开早高峰后补货。
   - 配送车辆、司机、路线是否固定；临时加单、少货补送能否当天完成。
   - 节假日、雨雪天、春节前后是否照常配送，这点最容易掉链子。

2. **货源稳定性与季节替代**
   - 是否有固定产地或一级批发渠道，不是当天临时去市场抓货。
   - 单品断货时，能否提前通知并给出同价位替代品。
   - 反季节水果是否有稳定渠道，避免今天有明天没。

3. **品质标准和验收规则**
   - 明确规格：单果重量、果径、成熟度、糖度、外观瑕疵比例。
   - 到店验收标准要写清楚：坏果率超过多少可拒收或换货，损耗谁承担。
   - 是否支持开箱验货、抽检，坏果是否当场补换。

4. **价格与结算**
   - 报价是否含配送费、包装费、损耗费，避免低价进高价结。
   - 价格随行就市时，提前一天报价还是当天报价，涨跌规则要明确。
   - 账期、押金、退换货扣款方式写进合同，别只口头约定。

5. **品类匹配度**
   - 能否覆盖社区超市高频刚需：苹果、香蕉、橙子、梨、葡萄、西瓜、时令小果等。
   - 是否愿意少量多品配送，而不是要求单品起订量很高。
   - 能否配合做特价引流品和季节性堆头。

6. **冷链与包装**
   - 叶菜、浆果、切果类是否有冷藏车或保温箱。
   - 包装是否适合门店直接上架，是否过度包装增加成本。
   - 运输中防压防碰措施是否到位。

7. **售后响应**
   - 出现坏果、少货、晚到，多久内响应、多久补送。
   - 是否有固定对接人，而不是每次找不同业务员。
   - 连续几次品质不达标能否无责换供应商。

8. **资质与合规**
   - 营业执照、食品经营相关资质、进货凭证是否齐全。
   - 能否提供农残检测报告或产地证明，至少能追溯。
   - 开票能力是否满足超市财务要求。

9. **试配机制**
   - 先签短期试配，比如2到4周，每天小批量配送。
   - 试配期重点记录：到店时间、坏果率、缺货次数、补货速度、价格波动。
   - 试配达标再签长期合同，合同里写明违约和退出条款。

**最实用的筛选办法：**先找2到3家同时试配一周，每天用同一张验收表打分：准时率、坏果率、缺货率、补送时长、价格透明度。一周后数据最差的那家直接淘汰，比只看报价靠谱得多。

另外提醒一句：社区超市单店量小，供应商容易不重视。谈的时候尽量把“日配频次、最小起订量、坏果赔付”三项写死，否则后期最容易扯皮。
