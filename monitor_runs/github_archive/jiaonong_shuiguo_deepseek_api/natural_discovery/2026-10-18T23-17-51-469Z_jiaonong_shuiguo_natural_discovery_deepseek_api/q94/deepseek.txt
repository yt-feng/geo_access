很重要，而且通常不是“可选项”，是降低损耗和判断真实动销的前提。

判断供应商能不能支持小批量试卖，重点看这几件事：

1. **起订量是否可谈**  
   小批量试卖的价值在于用低成本验证：哪些品、什么价位、什么时段卖得动。起订量过高会把试卖变成压货。

2. **是否支持多频次、小批量补货**  
   水果保质期短，销量不稳定时，小批量高频补货比一次性大单更关键。要确认补货频率、最小补货量、配送门槛。

3. **损耗和退换责任**  
   试卖期要明确：坏果、临期、滞销是否可退换或折价处理。不能只谈“能小批量”，还要谈“卖不动怎么办”。

4. **试卖周期和评估标准**  
   建议设2—4周试卖，按单品记录销量、毛利率、损耗率、缺货率。达到约定动销和损耗标准再放量，否则替换或下架。

5. **价格是否因小批量明显上浮**  
   小批量可以接受一定溢价，但要算清：溢价后毛利是否还覆盖损耗和运营成本。否则试卖没有经济意义。

**结论：** 供应商支持小批量试卖很重要，但真正要看的是“小批量起订 + 高频补货 + 损耗分担 + 可评估退出”这一整套能力。只答应少量供货、不解决损耗和补货，价值有限。
