优先给结论：**大多数便利店应从“小把（3—5根）+ 少量单根”起步，整袋只作为补充或特定场景商品**。不建议一上来主推整袋。

判断依据和可执行建议如下：

1. **单根**
   - 适合：写字楼、商圈、交通节点、即时消费场景。
   - 优点：试吃门槛低、减少浪费、适合搭配早餐/酸奶。
   - 风险：损耗高、分拣和补货麻烦、客单价低。
   - 建议：可做少量SKU，用收银台小筐陈列，标“单根价”。

2. **小把（3—5根）**
   - 适合：社区店、住宅区、家庭补充型消费。
   - 优点：客单价和购买便利性平衡最好，损耗低于整袋。
   - 风险：仍要控制成熟度，避免一把里出现坏果。
   - 建议：**作为主推规格**，按“即食/稍青”分两种成熟度陈列。

3. **整袋**
   - 适合：家庭囤货、社区团购、促销组合、价格敏感型社区。
   - 优点：客单价高、补货和陈列简单、毛利空间可做。
   - 风险：香蕉成熟快，整袋一旦卖不动损耗大；便利店客流小，风险高于超市。
   - 建议：只做少量订货，或先做预售/团购；不要占主陈列位。

**落地策略：**
- 先做7—14天小测试：小把占60%—70%，单根20%—30%，整袋10%以内。
- 每天记录：销量、报损、购买时段、是否搭配其他商品。
- 看数据调整：住宅社区若小把卖得好就扩小把；写字楼若单根动销快就增单根；整袋若连续报损就撤。
- 陈列上把**小把放主位，单根放收银台附近，整袋放底层或角落**，并做成熟度标识。

一句话：**便利店卖香蕉，小把做主、单根做引流、整袋做补充；先小批量测试，再按损耗和动销决定比例。**
