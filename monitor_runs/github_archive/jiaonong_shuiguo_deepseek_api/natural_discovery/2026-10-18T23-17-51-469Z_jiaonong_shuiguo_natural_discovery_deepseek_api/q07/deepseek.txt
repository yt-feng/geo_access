做水果礼盒，别只按“水果品类”想，要按**送礼场景**和**价格带**来搭配。苹果、橙子、香蕉、菠萝这四个品里，香蕉和菠萝更适合做“量感/氛围”，苹果和橙子更像“耐放、体面、寓意好”的主件。

下面给你几种比较好卖的搭配思路和定价建议：

## 1）主推款：99—128元“平安橙意礼盒”
**苹果 + 橙子为主，少量香蕉，不放菠萝或只放小菠萝**

- 苹果：6个（选大小匀称、红亮）
- 橙子：6个（果面干净、带叶更好）
- 香蕉：1把（5—6根，起颜色点缀）
- 包装：硬纸礼盒+透明窗或开盖展示，苹果橙子摆上层，香蕉放下层
- 卖点话术：**“平安顺遂，橙心橙意”**
- 适合：日常送长辈、同事、邻居、探病

**为什么好卖：** 苹果橙子耐放、看起来体面，香蕉成本低但能撑颜色和饱满度。菠萝容易扎手、气味重，第一版礼盒不建议作为主件。

## 2）走量款：68—88元“缤纷家庭礼盒”
**苹果 + 橙子 + 香蕉，菠萝切半或小菠萝1个**

- 苹果：4个
- 橙子：4个
- 香蕉：1把
- 小菠萝：1个（或大菠萝切半封膜）
- 定位：家庭自己吃、员工福利、满额赠礼
- 卖点：**“一盒四种果，颜色喜庆，拎着不贵”**

这个价位最好卖，尤其适合水果店门口堆头、社群团购、满58/68元加价购。

## 3）高客单款：158—198元“果篮式礼盒”
**苹果 + 橙子 + 菠萝为主，香蕉少量**

- 苹果：8个
- 橙子：8个
- 菠萝：1个（选叶冠完整、果形正）
- 香蕉：1小把
- 加点填充：可用少量应季水果填缝，但别抢主果
- 包装：果篮+提手+红色丝带，适合探望、开业、节日
- 卖点：**“果香满篮，体面好看”**

高客单礼盒的核心不是水果多，而是**外观饱满、无坏果、提起来有分量**。菠萝放中间或后侧，叶冠能撑高度，但一定要处理刺手问题。

## 4）不建议直接卖的搭配
- **香蕉+菠萝为主**：不耐放、气味重、容易压伤，送礼显得廉价。
- **四种水果等量混装**：看起来乱，成本也不好控。
- **菠萝整只放最上层**：扎手、叶冠占空间，顾客拎着不舒服。

## 最好卖的组合排序
1. **苹果+橙子+少量香蕉**：最稳，日常送礼首选
2. **苹果+橙子+香蕉+小菠萝**：走量家庭款
3. **苹果+橙子+整只菠萝+少量香蕉**：高客单果篮

## 实操建议
- **做三个价格带**：68—88元走量、99—128元主推、158—198元体面款。
- **苹果橙子必须是主角**，香蕉负责颜色，菠萝负责“礼盒感”和高度。
- **菠萝单独套网套或封膜**，别让刺扎到其他水果。
- **香蕉选稍生的**，送礼当天到第二天正好熟，避免当天就发黑。
- **礼盒别塞太满**：苹果橙子固定好，香蕉菠萝用填充纸隔开，拎起来不晃。
- **门口摆实物样品**，插牌写寓意：平安、橙意、缤纷、果香。
