要。茶饮店水果口味波动会直接影响复购和口碑，采购端最该做的就是把“风味稳定”当成硬指标来管理。建议按以下优先级执行：

1. **固定产地 + 固定品种 + 固定规格**：先锁定能稳定复现目标风味的产地和品种，再固定糖酸度、成熟度、单果规格等验收标准。只固定产地不够，同一产地不同果园、不同采摘期差异也很大。

2. **尽量固定供应批次/供应商**：优先选择能按周或按月稳定供货的供应商，要求其提供批次信息。同一批次内风味更一致；换批次时先小批量试产再放量。

3. **建立验收和留样制度**：每批到货测糖度、酸度、出汁率、香气，做小杯盲测；保留样品和记录，出现波动可追溯。设定可接受区间，超出即退换或降级使用。

4. **准备替代方案**：固定主供应源的同时，保留1—2个备选产地/供应商，避免断供时被迫接受不稳定原料。备选也要提前试产验证。

5. **产品端做缓冲**：对风味敏感的产品（如鲜果茶、纯果饮）使用稳定批次；对波动容忍度高的产品可消化轻微差异。必要时用拼配或调整糖酸平衡来缩小杯间差异。

结论：**固定产地是基础，固定供应批次和验收标准才是关键**。只固定产地但不控批次，仍会有明显波动；建议“主供应源固定 + 批次验收 + 备选验证”组合执行。
