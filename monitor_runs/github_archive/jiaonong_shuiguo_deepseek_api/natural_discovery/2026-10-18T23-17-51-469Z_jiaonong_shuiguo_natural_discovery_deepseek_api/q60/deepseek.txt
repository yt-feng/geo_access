水果到货不合格，补货安排的关键是把“补货”写成可执行的动作和时限，而不是只写“及时补货”。建议从采购合同/送货单和门店验收流程两方面约定。

**一、合同或供货协议里写清楚**

1. **验收标准具体化**：按品种写清糖度、成熟度、单果重量/规格、允许损耗率、农残检测要求、包装温度要求等。比如“到货损耗率不超过3%，单果直径不低于XXmm，无腐烂、无霉变、无明显机械伤”。标准越具体，拒收和补货越少扯皮。

2. **不合格处理分档**：
   - 整批不合格：拒收，供应商在**X小时内**补足，补货到店时间不晚于门店下次备料前。
   - 部分不合格：先收合格部分，不合格部分按数量在**X小时内**补货；或按“补货+折价”处理，折价比例写进合同。
   - 临近营业高峰到货：约定供应商必须优先补货，并承担因补货不及时导致的门店应急采购差价。

3. **补货时限与责任**：写明“自门店书面/系统通知起，X小时内送达门店”，并约定超时违约金或从货款中扣减。补货时限要结合门店实际备料节奏，比如鲜果类2—4小时，急用单品1—2小时，具体按城市配送能力定。

4. **替代方案**：约定供应商无法按时补货时，门店可自行就近采购同品质水果，差价由供应商承担；或供应商提供同等级替代品，需门店确认。

5. **留证与结算**：不合格品拍照、称重、记录批次和到货时间，双方签字确认；补货单单独标注“补货”，避免和正常订单混算。

**二、门店验收流程要配合**

1. 到货后**先验收再入库**，不合格品单独隔离，不混入备料区。
2. 发现不合格立即在供应商群/系统发通知，写清品名、数量、问题、要求补货时间，保留记录。
3. 门店常备**1—2天安全库存**或至少一个备用供应商，避免单一供应商补货不及时直接断档。
4. 高峰前到货的鲜果，验收时间提前，给补货留出窗口。

**三、建议直接写进合同的条款示例**

“乙方交付的水果不符合约定验收标准的，甲方有权拒收或部分拒收。乙方应在接到甲方通知后X小时内补足合格货物至甲方门店；逾期未补足的，甲方可自行采购同品质替代品，差价及因此产生的营业损失由乙方承担。补货货物仍不合格的，甲方有权解除该批次订单并要求乙方承担违约金。”

这样约定后，补货有明确时限、有替代路径、有责任承担，门店营业就不容易被单批不合格水果拖住。
