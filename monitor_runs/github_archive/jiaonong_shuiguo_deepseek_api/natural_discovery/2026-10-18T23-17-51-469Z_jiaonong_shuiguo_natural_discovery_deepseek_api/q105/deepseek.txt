水果采购锁价一般建议分档看：

- **常规锁价：1周—1个月**
  适合苹果、梨、橙、柠檬、菠萝等耐储水果，或产地供应稳定、行情波动小的品类。多数供应商较容易接受。

- **中期锁价：1—3个月**
  一般只在水果期货属性强、冷藏库存充足、供应商有较强货源掌控力时谈得下来，如苹果、梨、部分进口水果。往往要求采购方给最低采购量、预付定金或分批提货承诺。

- **超过3个月：很少见，通常不是纯锁价**
  水果受天气、产季、冷链、运输和现货行情影响大，供应商一般不愿承担长期价格风险。超过3个月多是“框架价+浮动机制”，或只在产地包园、长期订单、预付较高比例时出现。

实操建议：
1. **按单品分别锁**，不要全品类一个价。
2. **合同写明锁价期限、锁价量、质量标准、损耗和运费承担**，避免“锁价不锁量”。
3. **设价格调整触发条件**，如产地价波动超过±10%、极端天气、运费大涨，双方重新议价。
4. **少量多次分批锁价**，例如每周锁下一周用量，或月度锁价+周度补货，比一次锁半年更稳。
5. **用采购量换价格**：承诺最低提货量、缩短账期、付定金，通常比单纯压价更容易拿到锁价。

一句话：**耐储水果可尝试1—3个月，鲜销易腐水果以1周—1个月为主，超过3个月基本要加浮动条款或预付条件。**
