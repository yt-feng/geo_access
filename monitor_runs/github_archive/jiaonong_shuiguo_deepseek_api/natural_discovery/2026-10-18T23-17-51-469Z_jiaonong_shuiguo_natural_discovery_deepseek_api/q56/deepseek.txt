茶饮店控制水果供应商食品安全风险，建议索取并按“资质、检测、过程、追溯、协议”五类归档。不同水果和加工方式要求不同，以下为可执行清单。

一、供应商主体资质
1. 营业执照（经营范围含水果/农产品销售或种植）。
2. 食品经营许可证或食品生产许可证（如供应商做鲜切水果、果汁、果浆等加工；仅销售初级农产品通常不需要食品经营许可，但需核实当地规定）。
3. 仅种植户/合作社直供时：提供身份证或合作社营业执照、产地证明/村委会或合作社出具的自产证明。
4. 进口水果：海关进口货物报关单、入境货物检验检疫证明；预包装进口水果还需中文标签。

二、产品合格与检测证明
1. 每批次或定期提供农产品承诺达标合格证（优先）。
2. 第三方检测报告：农残（如敌敌畏、毒死蜱、克百威等按GB 2763）、重金属（铅、镉等）；鲜切水果另加微生物指标（菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等）。
3. 检测报告要求：有CMA/CNAS标识、项目覆盖对应水果、日期在合理周期内（建议每半年至一年更新，高风险品种每批次或每月抽检）。
4. 供应商自检报告可作为补充，不能替代第三方报告。

三、过程控制证明
1. 鲜切水果供应商：生产场所卫生证明、从业人员健康证、清洗消毒记录、冷链运输温度记录。
2. 普通水果供应商：仓储和运输卫生条件说明；冷藏水果提供冷链温度记录。
3. 农药使用记录或种植管理记录（直采基地时索取）。
4. 如供应商声称“绿色食品/有机”等认证，索取有效认证证书并核对认证范围。

四、追溯与验收材料
1. 供货清单/送货单：品名、产地、批次、数量、采摘或包装日期。
2. 批次追溯码或产地信息，确保出现问题可召回。
3. 门店验收记录：感官检查（霉烂、虫害、异味）、温度、农残快检结果（如有快检设备）。

五、合同与责任约定
1. 食品安全协议：明确农残、重金属等标准，不合格退货/赔偿/召回责任。
2. 供应商食品安全承诺书。
3. 定期供应商审核记录（现场或文件审核）。

优先级建议：先确保营业执照+承诺达标合格证/检测报告+送货批次信息三件套齐全；鲜切水果供应商额外要求健康证、冷链记录和微生物检测；进口水果必须核验报关单和检验检疫证明。对无法提供检测报告的供应商，可要求每批提供快检合格证明或由门店抽检，并在合同中约定责任。
