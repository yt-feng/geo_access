可以优先做“高频带低频、整单凑价”的组合，而不是简单打折。

**推荐组合**
1. **香蕉+苹果“日常果篮”**  
   - 香蕉按每斤原价，苹果做第二件优惠；或“买2斤香蕉+2斤苹果立减3元”。  
   - 目的：香蕉是高频引流品，苹果客单稳定，组合后提升单次购买量。

2. **菠萝+苹果“清甜组合”**  
   - 半个/一个菠萝+3个苹果打包价，标“组合价比单买省X元”。  
   - 菠萝单价感知高，适合做组合里的“价值感担当”。

3. **三品“家庭水果包”**  
   - 1把香蕉+1个菠萝+4个苹果，设两档：小份29.9、家庭份39.9。  
   - 用固定价格包降低顾客比价，直接拉高客单。

**执行要点**
- 组合价折扣控制在10%—15%，不要伤单品毛利。
- 香蕉易损耗，组合包当天分切/熟度分级，避免压货。
- 菠萝提供免费去皮或现场切块，提升组合吸引力。
- 收银台和称重台放“加3元换购苹果/香蕉”提示，做二次加购。
- 每天记录组合包销量、单品销量和毛利，7天后淘汰动销最差的组合。

**更稳的替代方案**：先做“满39元送香蕉一把”或“买菠萝加9.9元换购苹果”，比直接捆绑更不容易引起单品价格冲突。
