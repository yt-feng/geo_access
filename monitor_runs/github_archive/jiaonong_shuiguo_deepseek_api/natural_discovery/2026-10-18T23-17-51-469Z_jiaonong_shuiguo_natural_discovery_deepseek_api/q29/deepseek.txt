超市和水果供应商的账期没有统一标准，关键看**品类、损耗风险、供应商层级和你所在渠道**。常见区间可以这样判断：

- **水果类普遍比标准超市快**：生鲜周转快、损耗高，账期通常短于包装食品。  
  - 产地直采/一级供应商：常见 **15～30天**，强势超市可能 **30～45天**，但会给产地一些预付或短账期。  
  - 批发市场/二级供应商：常见 **7～15天**，部分现结或周结。  
  - 进口水果、品牌水果：常见 **30～60天**，视品牌方和超市议价能力而定。

- **按渠道看**：  
  - 大型连锁商超：对供应商常见 **30～60天**，生鲜可能压到 **15～30天**。  
  - 社区超市/生鲜店：常见 **7～15天**，或 **周结/半月结**。  
  - 电商/即时零售：常见 **7～30天**，部分平台有固定结算周期。

- **谈判时别只谈天数**：水果损耗高，建议把**账期、结算方式、损耗承担、退换货、促销费用**一起谈。比如账期30天但损耗由供应商承担，实际成本可能高于账期15天。  
- **可执行建议**：首次合作可先谈 **15天或周结**，稳定后逐步延长到 **30天**；若超市要求 **45天以上**，要评估资金占用和坏账风险，并要求明确对账和付款节点。

总结：**水果供应商最常见的是7～30天，15～30天是较常见的谈判区间；30天以上多见于大型商超或强势渠道。**
