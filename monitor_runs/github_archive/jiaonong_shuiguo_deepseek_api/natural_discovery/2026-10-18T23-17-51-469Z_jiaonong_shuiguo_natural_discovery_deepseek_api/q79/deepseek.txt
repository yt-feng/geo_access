排序是：**配送 > 售后 > 价格**。团购团长真正容易翻车的是配送不稳和售后扯皮，价格反而最不该先问。

具体判断：

1. **配送最优先问**
   水果是生鲜，团长最怕的是：到货晚、破损、缺斤少两、临时换货。要问清楚：
   - 截单时间、到货时间窗口，是否固定；
   - 起送量、配送费、谁卸货；
   - 破损/烂果怎么算，现场拒收还是拍照报损；
   - 旺季或节假日是否保证履约。
   配送不稳，价格再低也会把团长口碑做坏。

2. **售后第二问**
   重点不是“有没有售后”，而是**规则是否可执行**：
   - 坏果赔付比例和时限；
   - 是补发、退款还是下次抵扣；
   - 需要什么凭证，谁承担举证；
   - 整批质量问题怎么处理。
   售后模糊的供应商，低价往往是把风险转给团长。

3. **价格最后问，且要问“到手综合成本”**
   不要只比单价，要算：配送费、损耗率、售后赔付、起订量、账期。低价但损耗高、售后差，实际成本更高。

一句话建议：**先确认配送能稳定履约、售后规则清楚，再谈价格；价格只在同等履约和售后条件下比较。**
