这取决于你说的“卖”是**零售陈列方式**还是**卖给顾客时的交付方式**。更实际的做法通常是：**整果为主、现场代削为辅，不建议提前大量削好裸卖。**

**1. 整果：作为主销形态**
- 顾客能自己挑，感知新鲜、可判断成熟度，损耗也低。
- 适合做堆头/陈列，按个或按斤卖都行。
- 缺点是部分顾客嫌处理麻烦。

**2. 去皮好的：只做少量、预订或试吃**
- 优点是方便、即买即吃，能提升客单价和冲动购买。
- 但提前去皮裸卖有几个问题：失水快、氧化变色、卫生和保鲜要求高、卖不掉就损耗；顾客也看不到原果状态。
- 如果做，建议**冷藏展示、当天少量、明确标注削皮时间**，最好用保鲜膜/盒装，不要敞开放一整天。

**3. 让顾客自己挑：建议保留，但加服务**
- 整果区让顾客自己挑，旁边提供**免费或少量收费代削**，这是水果店比较稳的组合。
- 代削可以现场做，顾客看得见，信任度高；也可以设“买整果免费削、削好盒装加一点服务费”的规则。

**可执行建议：**
- **主陈列用整果**，按成熟度分两堆：即食熟果、放两天的果。
- **每天只削少量**做方便装，放在冷藏柜，卖完不补或按预订削。
- **提供现场代削服务**，顾客挑完再削，既满足方便需求又降低损耗。
- 如果客流大、复购高，可以试“整果自选 + 削好盒装”双陈列，观察一周哪类卖得快、损耗多少，再调比例。

一句话：**整果让顾客挑是基本盘，去皮好的做补充和便利服务，不要反过来让削好的成为主要库存。**
