酒店采购水果盘原料时，供应商应保证的规格和外观标准可按以下维度写入采购合同或验收标准：

**一、规格标准**

1. **品种与等级**
   - 明确品种（如红富士苹果、夏黑葡萄、金煌芒等），不接受以次充好或品种替换。
   - 明确等级（特级/一级），并约定等级不符时的处理方式。

2. **单果规格**
   - 按品种约定单果重量区间或横径/纵径范围（如苹果单果200–250g、橙子横径75–85mm），允许±5%偏差，超差比例不超过约定批次量的5%–10%。

3. **成熟度**
   - 约定采收成熟度或可食成熟度：到货即可直接摆盘食用，或约定催熟后XX小时内达到可食状态。
   - 果盘用水果一般要求“即食成熟度”，避免过硬或过软。

4. **包装规格**
   - 明确每箱/每盒净重、单层摆放数量、隔层材料（如珍珠棉、纸托），防止运输挤压。
   - 约定箱内允许的机械损伤果比例（一般不超过3%–5%）。

**二、外观标准**

1. **色泽**：符合品种固有色泽，着色均匀，无明显褪色、发白或异常变色。
2. **果形**：端正、无明显畸形，同一批次果形一致性要好（摆盘美观要求）。
3. **表面**：果面光洁，无病斑、虫眼、药斑、日灼、裂口、机械伤、压伤、冻伤。
4. **新鲜度**：果柄新鲜（如适用）、无萎蔫皱缩、无发酵异味、无霉变。
5. **洁净度**：无泥土、无残留枝叶、无外来异物；如约定“免洗即食”，需明确清洗消毒工艺和微生物指标。
6. **大小均匀度**：同一摆盘批次内单果大小差异控制在约定范围内（如横径差≤5mm），保证摆盘视觉统一。

**三、验收与责任条款建议**

- 约定抽样比例（如每批次随机抽检5%–10%）和合格判定规则（如外观不合格率≤5%为合格）。
- 明确不合格处理：退货、换货、折价或扣款，并约定响应时限（如24小时内补货）。
- 对即食类水果，可要求供应商提供农残检测报告或承诺符合国家农残限量标准，并约定抽检不合格的责任。
- 约定冷链或常温运输条件、到货温度（如冷藏水果到货中心温度≤10℃）及到货时限。

**四、需注意**

具体数值（单果重量、偏差比例、损伤率）应结合酒店定位、菜单要求和当地市场供应情况确定，不宜照搬；涉及食品安全指标（农残、微生物）应以现行国家标准和供应商检测报告为准，合同中写明验收依据即可。
