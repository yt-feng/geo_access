重点是把“采购熟度”和“到货节奏”分开管理，香蕉不要一次全进同一熟度。

**采购时这样要求：**

1. **按销售速度分配熟度**
   - 当天/次日卖：要**5～6成熟偏黄**，表皮开始转黄但两端还带绿，适合2～3天内走量。
   - 2～4天卖：要**4～5成熟**，整体偏绿、少量转黄，耐放。
   - 做促销或当天高峰：可少量要**7成熟**，黄皮带少量绿，当天必须卖动。
   - 原则：**同一批不要全是同一熟度**，按“今天能卖、明后天能卖、备货”分成三档。

2. **明确拒绝过熟和催熟过度**
   - 要求果柄完整、无黑斑、无软塌、无裂口。
   - 不要“黄透带黑点”的到货，除非当天特价清货。
   - 问清是否催熟、催熟程度，避免供应商把快熟的货压给你。

3. **到货时间要求**
   - 优先要求**早晨开门前到货**，当天上架、当天判断熟度。
   - 避开高温时段到货，夏季要求**冷链或阴凉运输**，不要暴晒。
   - 不要一次到齐一周量，改成**每周2～3次小批量到货**，每次按2～3天销量订。
   - 节假日高峰可提前1天到货，但熟度要降一档，留出转熟时间。

4. **写进采购单的硬要求**
   - “本批以4～5成熟为主，搭配少量6成熟，不得混入7成熟以上。”
   - “到货时间不晚于上午X点，夏季全程避免高温暴晒。”
   - “到货抽检：青绿均匀、果柄完整、无黑斑软果；不合格可拒收或折价。”
   - “分2～3次到货，每次按2～3天销量配送。”

**可执行判断标准：** 到货后摸果身应硬实、表皮无大面积黄斑；如果一箱里超过两成已经黄软，就说明熟度偏高，下一批要求降一档并缩短到货间隔。
