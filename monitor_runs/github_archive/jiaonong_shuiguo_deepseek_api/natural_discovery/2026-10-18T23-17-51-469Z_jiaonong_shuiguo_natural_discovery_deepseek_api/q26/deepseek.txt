社区超市卖小包装香蕉，采购和运营重点不是“把大把拆小”这么简单，核心是**按成熟度分批、控制单包重量、减少机械伤和催熟失控**。下面按可执行项说。

**1. 采购规格**
- 优先采购**已分级、已梳蕉/小把蕉**，要求供应商按“每把 2～4 根、单把 300～500 克”预分装，减少门店二次分切。
- 如果只能进整把，选**条蕉均匀、果指短粗、无棱角**的货，分切后小包卖相更稳。
- 不要一次全进同一成熟度。建议按销量拆成：
  - 青一点：1～2 天后再上架；
  - 黄熟：当天上架；
  - 少量即食熟蕉：做特价或搭配促销。
- 采购单上明确：到货成熟度、单把重量范围、允许的机械伤比例、断指/脱把比例。

**2. 包装方式**
- 小包装优先用**透气打孔袋或网套+托盘**，不要完全密封。香蕉呼吸量大，密封袋内易积水、发黑、长霉。
- 袋上打孔要够，一般每袋至少几个小孔；若用保鲜膜，选透气膜且不要裹太紧。
- 单包标签不要贴在蕉指弯折处，贴袋面或托盘边，避免撕标伤果。
- 包装内不要混放已熟和青蕉，成熟度差异会导致一包先坏。
- 若做“即食小包”，可 2～3 根一包；若做“家庭补货包”，4～5 根一包。社区超市通常 300～500 克/包更好周转。

**3. 分切与操作**
- 分切用**锋利弧形刀**，一刀断开，不要反复锯；切口尽量整齐。
- 分切后切口易氧化发黑，可尽快上架，不建议长时间裸露存放。
- 操作时戴手套，避免手汗和挤压；不要拎蕉指，托住蕉梳底部。
- 分切台保持干燥，蕉类怕水，水滴会加速黑斑和腐烂。

**4. 损耗控制**
- 香蕉损耗主要来自：**挤压伤、脱把、过熟、冷害、密封积水**。
- 门店存放温度建议**13～15℃**，不要放冷柜、不要低于 12℃，否则冷害发黑。
- 上架遵循“先进先出”，但熟度高的先摆前排；每天早晚挑出黑斑严重、脱把的做特价或加工。
- 小包装不要堆叠过高，建议单层或最多两层，避免压伤。
- 控制订货量：小包装香蕉周转快，建议首单少量试销，按日销量 1～1.5 倍订货，观察 3～5 天再放量。

**5. 采购合同/验收要点**
- 验收看：成熟度是否一致、有无水烂、有无压伤、脱把率、单把重量是否达标。
- 要求供应商**预冷到位但不过冷**，运输避免暴晒和挤压。
- 明确损耗责任：到货 24 小时内出现的严重机械伤、水烂可退换；门店二次分切造成的损耗自行承担。
- 小包装若由供应商预包装，验包装透气性、封口强度、标签位置和净重。

**建议你先做一个小测试：** 进 2～3 种成熟度、每包 300～500 克，分“打孔袋”和“网套托盘”两种包装，连续 5 天记录黑斑、脱把、报废量。哪组日损耗低、动销快，就固定那组采购和包装规格。
