应该**优先关注成熟度，价格放在其次**。香蕉对烘焙蛋糕的影响，成熟度几乎直接决定成品风味、甜度、颜色和含水率，价格只影响成本。

### 判断建议
- **做香蕉蛋糕/香蕉磅蛋糕/香蕉马芬**：选**表皮大面积出现黑点、果肉软但不流汁**的香蕉，香气和甜度最好，糖分高、酸涩感低。
- **不要用**：全青或刚转黄的香蕉，香气不足、涩味重、淀粉多，烤出来香蕉味弱。
- **慎用**：已经发黑软烂、有酒味或渗汁的香蕉，可能过熟发酵，影响风味和稳定性。
- **价格策略**：可以低价采购“熟度偏高但仍可食用”的香蕉，但不要为了便宜买青蕉或已经变质蕉。若一次买多，按熟度分批使用，过熟的可冷冻保存做果泥。

### 简单采购标准
**看皮色和手感**：黄皮带黑点、捏起来有弹性偏软、闻起来有明显香蕉香，是蛋糕用最合适的成熟度。价格在同一成熟度档位里再比较，不要用价格倒推成熟度。
