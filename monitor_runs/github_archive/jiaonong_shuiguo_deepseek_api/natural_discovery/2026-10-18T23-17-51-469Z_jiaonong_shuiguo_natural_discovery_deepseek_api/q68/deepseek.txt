判断供应商能不能按时到车，不要只听口头承诺，重点看以下几项，可执行地核验：

1. **看装车计划是否具体**
   - 要求供应商明确：装车日期、装车时间段、车牌号、司机电话、装车地、预计到达市场时间。
   - 只有“明天发”“这两天装”这类模糊说法的，风险较高。
   - 最好让供应商发装车现场视频或照片，包含车牌、香蕉包装、装车进度。

2. **核实车辆和司机**
   - 要真实车牌号和司机电话，直接联系司机确认：是否已接单、到哪里装、预计几点能装完。
   - 车牌与司机对不上、司机说还没接到安排、电话打不通，都要警惕。
   - 可以要求提供行驶证或运输单据照片，至少核实车辆归属和路线。

3. **看供应商近期履约记录**
   - 问清楚最近几天发过哪些车、到货市场、商户反馈。
   - 老供应商看历史迟到率；新供应商要求提供近期装车单、过磅单、市场收货记录。
   - 对“低价但要求全款”的新供应商尤其谨慎。

4. **合同或聊天记录写清违约条款**
   - 写明最晚装车时间、最晚到达时间，以及迟到后的处理方式：扣款、补差价、退定金、承担市场空档损失等。
   - 定金不要一次性全付，按装车进度付款；尾款到货验货后结。
   - 微信聊天也要把关键承诺写清楚，保留记录。

5. **装车当天做节点确认**
   - 装车前确认一次：货是否备齐、工人是否到位、车是否到场。
   - 装车中要求拍视频：车牌、装车数量、封车情况。
   - 发车后要定位或高速通行信息，按预计到达时间前再确认一次。

6. **设置备选方案**
   - 同时联系1—2家备选供应商，不要把所有档期压在一家。
   - 对急档期，优先选有固定车队、能当天装车的供应商，而不是报价最低的。

**简单判断标准：**能给出车牌、司机电话、明确装车时间，并接受节点视频确认和迟到扣款的，按时到车概率较高；只催定金、不给车牌、装车时间模糊、拒绝写迟到责任的，建议不要押重注。
