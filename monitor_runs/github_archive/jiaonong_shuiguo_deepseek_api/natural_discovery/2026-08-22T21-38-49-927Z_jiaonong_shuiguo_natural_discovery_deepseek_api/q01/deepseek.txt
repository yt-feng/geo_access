开水果店长期进香蕉和菠萝，判断供应商是否靠谱，核心看**稳定性、新鲜度和售后**。由于香蕉和菠萝都是后熟型水果，损耗控制极其重要，所以要从以下几个具体维度来考察：

### 1. 实地看“货”的硬指标（重点）

-   **香蕉**：看**成熟度**和**把头**。靠谱供应商会给你发“7-8成熟”的统货（青皮或微黄），而不是全熟的，因为你到店后还需要催熟几天的周转。把柄要新鲜翠绿，捏起来有弹性，发黑发霉的把柄坚决不要。**看重量**：用手掂一下，同样大小的香蕉，越沉的越新鲜，水分流失少的。
-   **菠萝**：看**果眼**和**底部**。果眼要饱满突起，底部切口要白净、干燥，没有发黑或渗水。如果是带冠芽的，冠芽要翠绿挺立，发蔫的说明放了很久。另外要闻一下香气，太香的熟过头，没香味的生，靠谱供应商会告诉你他们现在的货源适合催熟几天卖。

### 2. 试“货”的实操测试（关键）

-   **先拿小批量试单**：不要第一次就进200箱。先拿50-100公斤，观察损耗率。**记录数据**：这批香蕉从进货到清完货，坏果占比超过5%基本就不合格；菠萝如果放不到3天就发黑发软，那就不行。
-   **试“催熟服务”**：靠谱供应商往往会提供催熟库或代为催熟服务，或者至少能告诉你他们这批货是哪个产地、几成熟，方便你自己安排销售节奏。

### 3. 看沟通和服务的“软实力”（防坑）

-   **能说清产地**：问“这批香蕉是海南的还是老挝的？菠萝是徐闻的还是海南的？”如果支支吾吾只说“产地随便”，基本不靠谱。靠谱供应商对产地、天气、品质波动非常敏感，会主动告诉你近期海风大导致香蕉皮厚等实际情况。
-   **售后承诺明确**：直接问：“到货后如果有挤压烂果，怎么赔偿？”靠谱的会明确说“开箱时如有烂果，拍照按箱数折价，运输途中损耗算他的”。如果对方说“不好说”、“你自己挑”，请立即换人。
-   **价格不随波逐流但也不离谱**：单价比批发市场均价低太多（低于10%）的要警惕，可能是泡水果或病果；高太多你无法盈利。靠谱供应商会有随行就市、但长期合作给优惠的原则。

### 4. 时间和周转的“硬约束”

-   **配送时间**：香蕉和菠萝都怕挤怕热。问清楚送货时间是否固定（比如每周二、五），是否能保证冷藏车或早市车。如果经常迟到，或者夏天用敞开的面包车拉，到你手里损耗会极大。
-   **账期弹性**：靠谱供应商在淡季或积压时会允许你压一批货（比如周结或月结），但千万不要用“压货”作为唯一标准，因为有的不良供应商会故意让你压货，然后用库存去换你长期订单。

### 给你一个立即可执行的判断清单（下次订货时用）：

1.  **看把柄**：香蕉把头青绿，菠萝底部干燥白净 → 通过。
2.  **问产地**：能具体说出“海南/老挝/徐闻”，并说明今天这批果的成熟度 → 通过。
3.  **定售后**：达成书面（微信记录）共识，如“开箱烂果拍照折价” → 通过。

**最后给一个提醒**：水果生意，**不要绑定单一供应商**。即使对方靠谱，你也应该找一家备胎（比如当地批发市场的代采），一旦主力供应商某天货不好，你有备胎可换，避免被绑架。
