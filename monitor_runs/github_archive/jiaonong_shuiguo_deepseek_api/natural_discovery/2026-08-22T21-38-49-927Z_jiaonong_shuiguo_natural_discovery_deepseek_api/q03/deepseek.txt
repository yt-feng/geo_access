第一次做水果生意，**试单的核心不是“进大量货”，而是“测货损、测销量、测周期”**。直接压货很容易亏在损耗上。

针对夫妻小店，给你一套**零风险试单法**（按单品操作）：

**第一步：先定“试单天花板”（总量控制）**
- 每种水果**只进正常销量的 1/3**（比如你预计一天能卖30斤苹果，试单只进10斤）。
- 总进货金额控制在预算的20%以内，留出周转金。

**第二步：按水果特性，用不同策略试**

1. **香蕉（损耗最高，试“周转速度”）**
   - 只拿 **1-2把**（约10-15斤），且**必须要求带青头的半熟蕉**（不要全黄的，全黄转天就烂）。
   - 试单合同期**只谈2天**：如果2天内卖不完，果断放弃这家（因为香蕉是冲量货，卖不动就是纯亏）。
   - 记住：跟供货商要求“断货可补，但绝对不接全熟货”。

2. **苹果（首选试单品，试“品质稳定性”）**
   - 拿**3箱不同产地的**（比如山东栖霞、陕西洛川、新疆阿克苏各1箱，每箱约30斤）。
   - 签合同**只谈“按箱结账，不按斤拆”**，防止供货商混装次果。
   - 试单周期拉长到**5-7天**，因为苹果耐放，值得测一周的口碑。
   - 关键动作：开箱后**当场剪开果核**看心部有无褐变（若有，直接退货，这家不合作）。

3. **橙子（试“糖度与皮厚”）**
   - 拿**2筐**（约40斤），但要问清是“整筐含筐重”还是“净果重”（很多新手被筐重坑）。
   - 试单时**现场切开2个试吃**：皮厚>5mm或酸度明显的整筐退。
   - 橙子是复购型水果，试单重点看**3天内回头客有没有**（如果3天没回头客，说明品质不达标，换供应商）。

**第三步：签“试单保护条款”（口头+微信记录均可）**
- 必须先说清楚：**“我是试单，只拿少量，如果品质好，后面长期按周结算；如果今天这批烂果超过5%，我整批退回。”**
- 要求供货商送货车到店时**拍照留存开箱验货视频**（这是万一扯皮时的证据）。

**第四步：试单定量参考表（必须白纸黑字）**

| 单品 | 首次进量 | 试单期 | 淘汰标准 |
|------|---------|--------|---------|
| 香蕉 | 1-2把 | 2天 | 卖不完 |
| 苹果 | 3箱（分产地）| 5-7天 | 开箱有烂心 |
| 橙子 | 2筐 | 3天 | 无回头客 |

**特别提醒：**
- 千万别一次性进10箱苹果试“便宜”，小超市损耗率超过8%就是亏本，宁愿进贵一点的精品果试销。
- 供货商如果说“必须整板拿”或“不足多少斤不发货”，直接扭头就走——这类不配跟小店主合作。

最后，试单成功后，**不要贪大**，第二周只翻一倍量（比如2把变4把），再稳定两周，才敢正常进货。
