在水果店旺季来临之前，和供应商谈判是决定生死的一环。谈得不好，旺季天天断货，看着客人来了又走；谈得好，你不仅能拿到货，还能在价格上占据优势。

以下是针对“旺季不断货”这个核心目标，你需要提前问清楚的关键问题，分为**货源保障、价格机制、品质售后、物流损耗**四个维度：

**一、 货源保障（最核心，决定你是否有货卖）**

1. **保供量承诺：** “如果我从你这里下大单（比如单日1000斤），你能保证给我留多少货？万一遇到产地断货，你的调配方案是什么？”（问清“保底供应量”，而不是听对方说“货多得很”）
2. **缺货违约责任：** “如果到了旺季你突然没货给我，合同里怎么约定赔付？是退定金、补差价，还是按缺货数量的百分比赔偿？”
3. **提货方式：** “是你们送货上门，还是我自己去批发市场提？如果是批发市场拿货，你能否保证档口优先给我们留货？”

**二、 价格机制（防止旺季被坐地起价）**

4. **价格锁定周期：** “旺季价格波动大，我们的订单能锁价几天？（比如提前3天下单锁价，哪怕市场涨了也按锁定价走）” 注意：旺季不要锁太长时间（超过7天），否则供应商亏本会毁约。
5. **溢价规则：** “如果因特殊天气（如台风、暴雨）导致产地暴涨，涨价超过20%时，我们是按新价结算还是可以无条件取消订单？”
6. **账期与付款方式：** “旺季是日结、周结还是月结？如果可以月结，有没有账期额度上限？”（旺季供应商资金压力大，常规会给“预付50%”的条件，但你要问清尾款节点的违约金比例。）

**三、 品质与售后（避免旺季收到烂货砸招牌）**

7. **到货验收标准：** “按什么标准验货？（如：表皮无大面积软斑、重量误差范围不超过±3%）如果到货有20%以上的损耗，是免费补货还是按比例折价？”
8. **售后响应时限：** “到货发现烂果，几个小时内反馈有效？赔付方式是下次进货抵扣，还是直接退现金？”
9. **产地信息透明：** “这批货是哪个基地的？能提供产地证明或发货单吗？”（旺季有人会拿次果冒充好果，必须问清源头）。

**四、 物流与损耗（旺季最容易被物流坑）**

10. **冷链运输标准：** “是全程冷链车还是常温车？夏季高温，冷链车途中温度控制在几度以内？”（旺季高温，冷链断链会让水果损耗率飙升到30%以上）。
11. **破损承担方：** “运输途中的挤压、腐烂损耗算谁的？是装车后你们负责，还是到店后我自行承担？”（**关键话术**：建议问“如果整车损耗超过8%，你们怎么处理？”）。
12. **淡季转旺季的额度条款：** “如果我在淡季也持续从你这进货，旺季你是否保证我的优先配货权？”（很多供应商愿意用淡季合作换旺季优先，这是你的谈判筹码）。

---

**谈判时的“潜规则”提点：**

- **永远别问“有没有货”**，而是问“**最高能给我留多少**”。货源永远紧俏，问“有没有”就是送客上门，问“留多少”才是锁定资源。
- **签订书面“保量协议”**：电话、微信里的口头承诺在旺季基本无效。旺季市场缺货时，供应商一定会先保大客户和签了违约条款的客户。
- **反向压价技巧**：如果对方报价高，你可以说：“旺季我主推你这几款爆品，但如果你能承诺**周一到周五保证供货**，我可以把单品采购量提到翻倍，但单价要再降5分钱。”——用“稳定订单量”换“降价”，供应商通常愿意。

最后，如果对方在旺季前愿意答应“缺货降价赔付”或“免费补货”这些条款，说明他家实力较强；如果顾左右而言他，只说“放心，肯定安排得妥妥的”，那你就要多备1-2家备用供应商，别把鸡蛋放一个篮子里。
