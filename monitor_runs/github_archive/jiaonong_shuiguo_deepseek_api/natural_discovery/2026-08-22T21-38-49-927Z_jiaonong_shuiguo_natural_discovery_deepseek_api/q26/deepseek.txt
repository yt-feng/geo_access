社区超市卖小包装香蕉，采购时最核心的平衡点是：**既要满足“按串/按份买”的便利性，又要最大化减少因包装引起的人为损耗和货架期缩短。**

以下是针对**包装**和**损耗**两大板块的具体注意事项：

### 一、包装问题（直接影响卖相与二次损伤）

1.  **尺寸与克重标准**
    -   **单份克重**：建议控制在 **500g-1000g**（约4-6根）。太小（<400g）单价低、利润薄，且容易散；太大（>1500g）不适合单人社区消费。
    -   **包装规格**：必须统一每份的根数和重量，方便称重计价。如果无法做到精确，建议贴“按份销售”的标签，而不是让顾客挑个没完。

2.  **包装材质（避免“闷坏”）**
    -   **首选透气孔托盘 + 保鲜膜**：底部用泡沫或纸托固定，保鲜膜必须扎孔或使用透气膜。**最忌讳全密封塑料袋**，香蕉释放的乙烯气体在密闭空间内会加速自身成熟，且袋内凝水易引发霉变。
    -   **避免硬壳包装**：香蕉弯月形，硬质塑料盒如果尺寸不匹配，运输和摆放时尖角会扎伤果肉，形成黑点。

3.  **包装时机（决定命运）**
    -   **必须现切现包**：不要提前一天打包。香蕉一旦切开或分串，切口处暴露在空气中会迅速氧化发黑。建议当天到货、当天分装、当天上柜。
    -   **颜色分级**：散装时香蕉颜色杂，但小包装必须**按成熟度分拣**。一盒内不能有全绿和全黄混装，否则顾客吃了绿的感觉生，黄的又放久变黑，导致整盒差评。

### 二、损耗问题（主要分“物理损耗”和“生理损耗”）

1.  **采购环节的源头损耗**
    -   **拒收短斤缺两**：香蕉水分大，运输中失重明显。到货时按**连柄整串**抽查毛重与净重差，避免按“毛重”付款。
    -   **弯直度**：采购时优先要**直梳**（果指朝上弯曲小的），直梳塑形好包装，且摆放时不易压断果柄。弯度过大的香蕉包装后容易挤压断裂。
    -   **切口新鲜度**：检查整串香蕉的根部切口——如果切口发黑出水，说明存放过久；需选择切口白净、干燥的，这样分切后的小切口不易快速腐烂。

2.  **陈列与翻包的隐形损耗**
    -   **“倒金字塔”翻包损耗**：小包装香蕉往往靠近收银台，顾客挑选时会将上层包装盒翻来翻去。**显著损耗是“翻包造成的黑点”**。对策：摆放深度不超过一盒，且将最熟的一盒放最上面，标“今日特价”加速出清。
    -   **防止“蒂头”磕碰**：香蕉最脆弱的是每根果柄与果肉连接处的“肩部”。包在盒里时，要让香蕉**拱形朝上放置**（果柄朝下贴托盘），避免果柄顶破保鲜膜或戳伤旁边其他香蕉。

3.  **库存周转损耗（最关键）**
    -   **销售周期预估**：小包装香蕉的货架期极短。采购量应以**当天销量 + 次日早市销量的80%**为准。宁可卖断货二次补货，不要囤货过夜。
    -   **“催熟-控熟”清单**：采购时要向供应商明确要求**七成熟度发货**（果皮绿中带黄）。因为小包装分装过程约耗时1小时，期间温度变化会加速成熟，等上架后刚好呈亮黄色最佳。

### 三、实操紧急建议

-   **包装线后置**：在冷风柜或阴凉区划线，建议包装台设在卖场内的**阴凉背光处**，不要正对射灯或热风口。
-   **防“指压伤”**：分装人员必须戴**干净棉手套**，裸手捏香蕉极易留下褐色指印，非常影响小包装的卖相。
-   **标签作价策略**：0.5KG以下的小包装，建议直接**贴死价格**（如3.9元），避免顾客拿去称重台反复撕标称重，这种动作会加剧果皮擦伤损耗。

**一句话总结**：小包装卖的是**精致**，采购时核心是控制**成熟度**（七成熟）和**分装速度**（当日现包），包装上坚决拒绝全密封塑料袋，陈列上只允许顾客平拿，竖翻必损。
