在超市采购苹果和橙子时，判断大小规格是否适合门店销售，核心基于**目标客群、陈列方式、损耗控制**和**定价逻辑**。以下是从实操角度给出的具体判断标准和方法：

### 一、明确“适合”的基准线（先定规格区间）
1. **苹果**：
   - **常规零售装**（散称/袋装）：单果直径约 **70~85mm**，重量约 **150~250克**（即3~5两/个）。这个区间最容易走量，适合三口之家。
   - **高端礼盒装**：单果直径 **85~95mm**，重量 **250~350克**。果径超过95mm通常价格过高，销售速度慢，除非是节日档期。
   - **不适合门店的主力规格**：单果小于65mm（偏小，卖相差，但可做特价引流）；超过100mm（过大，多数家庭一次吃不完，容易产生损耗）。
2. **橙子**：
   - **主流大果**：单果直径 **75~85mm**，重量约 **200~300克**。目前市场偏好偏大果，尤其果皮厚的新奇士橙。
   - **中果**：直径 **65~75mm**，适合做“家庭装”或特价促销，但甜度差异需实测。
   - **不适合**：小于60mm（籽多皮厚，口感差）；大于90mm（果肉水分可能变柴，且单价过高）。

### 二、用“试销售”或“对比法”快速验证
如果你不确定，可以用**货架同品类对比法**：
- 进店观察你周边3家同业态超市（社区店、精品店），记录其苹果、橙子的**主推果径**和**价格带**。
- 如果对方主推90mm大苹果，你进80mm的，除非价格低20%，否则很难卖；如果对方卖75mm小果，你进85mm大果，则需在陈列首位突出“大果上新”。

### 三、实操判断的4个硬指标（不用仪器，肉眼分辨）
1. **抓握感**：单手拿起苹果，掌心自然包住，手指无法完全合拢（指尖碰不到掌心）→ 大约是70-80mm，适合大部分家庭。
2. **对比参照物**：用**一元硬币**（直径25mm）叠放：
   - 苹果直径 ≈ 3个硬币直径（75mm）为佳；
   - 橙子直径 ≥ 3个硬币略多（80mm以上）为佳。
3. **同批均匀度**：整箱中最大果与最小果的直径差≤10%，否则顾客会挑挑拣拣，产生大量翻拣损耗。
4. **单果重量抽查**：用电子秤抽5个，若平均重量低于该规格下限（如苹果低于150g），则可能产地施肥不足或采摘过早，即使个头达标也不建议进货。

### 四、基于“损耗与动销”倒推
- **苹果**：如果门店日均销售≤10斤，建议采购90mm规格（毛利高，卖得少但单笔利润大）；如果日均≥30斤，主采75-80mm（走量快）。
- **橙子**：橙子耐储运（室温可放7-10天），可以适当进大果（80mm+），因为消费者买橙子更看重“果大皮薄”，但要注意**糖度实测**，用糖度计抽查5个，可溶性固形物≥11%才值得进货。

### 五、特殊提醒（容易踩坑）
- **避免“规格陷阱”**：部分产地用“70#、80#”标号，这是**果径mm**，不是重量。采购单上必须写清“果径范围（mm）”。
- **试卖原则**：首次采购任何新规格，只进一箱（约20kg），在货架最醒目的位置陈列2天，记录**动销率**和顾客询问率。若日均销量＜3个，下次务必调小或调大规格。

**总结一句话**：苹果抓“70-85mm、均匀度好、单果重150-250g”，橙子抓“75-85mm、皮薄甜度高”，并拿周边竞品做标尺，小批量试错后再补货。
