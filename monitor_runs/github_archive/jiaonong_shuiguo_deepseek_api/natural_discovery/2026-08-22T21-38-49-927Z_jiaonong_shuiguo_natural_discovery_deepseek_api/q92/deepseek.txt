针对便利店面积小、水果损耗高的问题，核心思路是：**少进、勤补、卖相优先、严禁囤货**。以下是具体的可执行建议：

### 一、 品类控制：做“减法”，只卖高频流量款

便利店不是水果店，**不要追求“全”**，只需要满足“顺手买、立即吃”的即时需求。

1. **品类锁定在“老三样+2个爆款”**：
   - **必需常备**：香蕉（走量之王）、苹果（耐放）、应季柑橘类（好剥皮、气味香）。
   - **动态爆款**：每周只推1-2种当下最便宜、品质最稳定的时令水果（如夏季西瓜、冬季草莓）。
   - **坚决不碰**：榴莲（占地方且贵）、山竹（损耗极高）、各种高端进口水果（走不动）。

2. **包装规格“三口之家”化**：
   - 尽量拆散卖或小份装（如2-3个苹果一盒），单价控制在10-15元以内。小包装能大幅降低顾客“买多了吃不完”的心理负担，减少店内损耗。

### 二、 损耗控制：从“源头”和“陈列”两头堵

1. **进货策略（最关键）**：**“少拿多次”**。
   - 宁可每天多跑一趟批发市场或让供应商分次配送，也不要一次性进3天的货。
   - 原则：**只进当天能卖完的量**。如果预估卖不完，第二天清晨的损耗就会集中爆发。

2. **陈列与保鲜**：
   - **抬头不见低头见**：把**香蕉**挂起来或斜放，因为香蕉压放极易压坏且发黑。
   - **“轻伤”下架**：发现表皮有轻微碰伤、发软的果子，**立刻挑出来**，不要放在货架影响整堆销量。
   - **“临期”处理**：每天下午5点后，将不太新鲜的水果打包成“特价盲盒”（例如5元一袋），快速清库存，比直接扔掉强。

3. **选址摆放**：
   - 水果区必须靠近**收银台**或**进门处**，且**必须喷洒颜色鲜艳的射灯**。灯光鲜亮能掩盖轻微瑕疵，刺激冲动消费。

### 三、 每日标准化动作（附时间轴）

- **7:30 收货**：核对数量，当场把所有碰压伤、发霉的果子挑出并退货或记账。
- **8:00-10:00 理货**：按“好看在上、新鲜在后”摆放，把前一天的剩货放在最上层优先卖。
- **14:00 检查**：这是损耗高发期，下午气温升高，迅速清理软果和烂果。
- **20:00 收摊**：将果篮清空，把剩下的水果移入冷柜（若无冷柜则直接打折清掉），**绝不过夜**。

### 四、 止损红线（重要）

- **超过2天**卖不完的苹果/梨，即使外观还凑合，也请直接做成“特价果切”卖出或报损。在便利店，存放超过2天，**水分流失导致的隐形成本**高于售价。
- **不要为水果配备专职店员**，最好由收银员顺带理货，人工成本会吃掉水果微薄的毛利。

**总结**：便利店卖水果是赚“快钱”，不是赚“规模钱”。**每天进多少卖多少，卖不完就主动降价，绝不让水果在店里过第三个晚上。**
