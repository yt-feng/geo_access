做附近小区团购，水果供应商的配合能力至关重要。一个合适的供应商，远不止是“送货”这么简单，它应该是一个能帮你降低损耗、提升复购率的**后端引擎**。

以下是供应商需要支持的**核心服务清单**，你可以按照这个标准去筛选和谈判：

**1. 极速分拣与配货（最基础但最关键）**
团购的特点是“单品少量多批次”，供应商需要支持：
- **小批量拿货：** 不要整箱强制拿，能支持按个数、按斤分装（比如一盒2斤装）。
- **预分拣服务：** 供应商直接帮你把坏果挑出，按标准克重/个数打包好。这样你拿到手直接提走，节省了大量人力。
- **准时送达：** 团购的截单时间通常是晚上9点-12点，次日中午前必须到货。供应商必须有**上午11点前**完成配送到分拣站/小区的物流体系。

**2. 损耗包赔（利润的护城河）**
水果生鲜最怕售后。供应商必须提供**“货损包赔”**政策，需要明确以下条款：
- **一定比例的免赔额：** 比如允许1%以内的自然损耗，超出部分供应商无条件补货或退款。
- **售后即时响应：** 团购群里有个别顾客投诉“烂了”，你拍个照片给供应商，他必须**先赔后查**，不能推诿。
- **标准定价：** 明确“个头大小”标准（比如70MM以上），如果收到的货明显偏小，供应商需按比例折价。

**3. 档期与爆品储备（帮你制造话题）**
小区团购需要持续的新鲜感：
- **新品首发权：** 供应商有应季爆款（如春见耙耙柑、丹东草莓）时，需要优先给你预留**特价试吃装**，让你在群里做秒杀引流。
- **预售能力：** 支持“产地直发”模式，如果团购量超过一定数量（如50箱），供应商能直接对接基地，省去中间仓储费。

**4. 赋能支持（供应商做后盾）**
优秀的供应商不仅卖货，还会帮你卖货：
- **图文素材包：** 提供高清产地实拍图、糖度测试小视频、去核对比图等。你直接发到群里就能激活购买欲，无需自己拍照修图。
- **标准化话术：** 告诉你怎么介绍这批果子的口感（比如“皮薄肉厚，纯甜无酸”），避免你描述失实引发售后。

**5. 账期与结算（现金流安全）**
- **货到付款/当日账期：** 支持收货后**24小时内**凭签收单打款，不要找那种必须“月结”的供应商，否则你的现金流会断。
- **阶梯返点：** 这个月累计采购满5万或10万，供应商给予2%-5%的货补或现金返利。

---

**特别提示（甄别供应商的“试金石”）：**
你可以**故意测试**一下：在签约前，特意跟供应商说：“我这周要做一个榴莲团购，但是预估会剩下5个，如果卖不完我能退给你吗？”
- 如果对方说“不行，水果不退货”，说明他是**批发商思维**，比较难合作。
- 如果对方说“可以按报废价处理给我”，或者“我给你换同等价位的其他水果”，说明他是**社区团购思维**，这才是你需要的合作伙伴。

**下一步建议：**
先找2-3家供应商，每家下一个小单（比如拿5箱苹果），重点观察**实际送货重量（是否存在短斤缺两）、包装是否稳固（防止挤坏）、售后到账速度**。只有实测通过，才能签长期合同。
