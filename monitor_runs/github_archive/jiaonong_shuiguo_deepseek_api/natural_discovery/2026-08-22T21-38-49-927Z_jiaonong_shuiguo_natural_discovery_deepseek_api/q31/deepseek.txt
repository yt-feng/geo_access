在连锁商超的水果供应商招标中，评分标准的设置核心在于**平衡“当下性价比”与“长期稳定性”**。水果是高频、易损耗、非标品，单纯拼价格很容易导致后期断货或品质崩盘。

建议将评分体系分为**客观分（价格+资质）**和**主观分（服务+品控）**，具体可按以下框架设置（总分100分）：

### 一、价格竞争力（权重建议：35-40分）
**设定门槛：** 不设“最低价中标”，设置“基准价”机制。
- **评分公式：** 以所有有效投标人报价的算术平均值或中位数为基准价，报价等于基准价得满分（如40分），每高于基准价1%扣1分，每低于基准价1%扣0.5分（防止恶意低价扰乱市场）。
- **附加项（额外加分）：** 承诺在同类市场价波动超过±10%时，执行价格联动机制（即锁价期后按市场行情浮动，但有上限）的，加2-3分。

### 二、品质与品控能力（权重建议：30分）
水果招标最怕“货不对板”，这部分需用硬指标约束：
- **基地直供比例（10分）：** 提供自有或合作种植基地证明，直供比例≥60%得满分，低于30%不得分。
- **质检标准（15分）：** 提供第三方农残检测报告、糖度/成熟度标准承诺书（如“到货糖度不低于XX度”），有可量化的分级标准（如按国标或商超自有分级）的加分。
- **溯源系统（5分）：** 全链条可扫码溯源的加分。

### 三、供应稳定性与抗风险能力（权重建议：20分）
- **应急响应（10分）：** 承诺节假日或促销日（如春节）的备货能力，能提供“最低供应保障吨数”承诺的加分。
- **基地分布（5分）：** 跨区域或南北多基地布局，能对冲极端天气风险的加分。
- **历史合作记录（5分）：** 提供过去2年为同类商超供应的合同或履约证明（可脱敏），无断供记录。

### 四、物流与损耗控制（权重建议：10-15分）
- **冷链物流（10分）：** 自有冷链车队或与头部冷链平台签约证明。承诺“到货损耗率低于X%（如叶菜≤5%）”的加分。
- **配送时效（5分）：** 承诺下单后次日达，或提供“早市前置仓”服务的加分。

### 五、服务与结算（权重建议：5-10分）
- **售后处理（5分）：** 承诺质量问题“48小时内无条件换货/退款”，且明确占比（如当日到货不合格品全额退）。
- **结算账期（5分）：** 接受月结或更长账期的加分（视商超资金压力而定）。

---

### 关键避坑提示（招标执行层面）：
1. **必须设“样品盲测”环节**：在评分前，组织采购部、门店店长、顾客代表对供应商送样进行盲测打分（外观、口感、新鲜度），此分数占比建议不低于总分的20%，且**必须**淘汰盲测排名末尾的20%供应商（防止“以次充好”只靠文件得分）。
2. **违约条款前置**：若发生“断供”或“以货充好”，扣罚履约保证金的比例要在招标文件中明确（如首次违约扣10%，累计三次取消资格）。
3. **不设“终身制”**：中标合同建议签1+1年，第二年视全年月均到货合格率（≥95%）续签，避免温水煮青蛙。
