在长期合作的水果供应商谈判中，**账期**通常最值得优先谈，其次是**配送**，**售后**可以放在第三位（但需明确底线）。

原因如下：

1.  **账期（资金安全与现金流）**：这是最核心的。
    -   水果是**易耗、易腐**商品，且价格波动大。如果账期过长（比如超过45天），一旦水果集中出现质量问题或价格暴跌，供应商可能因资金链紧张而无法退款或换货，你的损失会直接变成坏账。
    -   优先谈成**“账期短（如7-15天）+ 现结优惠”**的组合，能显著降低你的经营风险。账期谈得好，即使采购价略高，你的资金周转压力也小于账期长但单价低的情况。

2.  **配送（损耗与效率）**：这一项直接决定你的利润损耗。
    -   水果按重量/箱进货，配送准时率、冷链完整度直接影响损耗。建议谈判时明确**“延时到达的扣款标准”**和**“到货破损率≤2%”**的硬性条款。
    -   如果不谈配送，供应商可能会用普通物流拼车，到货时果品烂损严重，此时售后条款往往无法完全覆盖这部分损失。

3.  **售后（止损底线）**：这一项可以作为“保险”来谈。
    -   水果的售后通常是“部分坏果按比例赔付”。你需要谈的是**“开箱坏果率超过5%整箱拒收”**的硬性规则，以及**“48小时内响应赔付”**。
    -   但注意：售后条款再完善，也解决不了“水果已经坏在仓库里”的损失。售后只能减少纠纷，不能创造价值。

**实操建议（谈判优先级策略）：**

-   **第一步**：先谈**账期**（争取30天以内，或“月结15天”），并以此为条件换取**采购价格**下浮。
-   **第二步**：在账期基本确定后，再谈**配送**（要求指定冷链物流、T+1送达，迟到按100元/单扣款）。
-   **第三步**：最后确认**售后**（重点谈“坏果率免赔门槛”），这通常是最容易谈下来的，供应商为了留客一般不会卡太死。

**一句话总结**：先保命（账期），再省钱（配送降损），最后兜底（售后）。如果你目前资金充裕但对水果损耗很敏感，可以调整为“配送优先”，但长期合作中，账期仍是最具战略价值的一环。
