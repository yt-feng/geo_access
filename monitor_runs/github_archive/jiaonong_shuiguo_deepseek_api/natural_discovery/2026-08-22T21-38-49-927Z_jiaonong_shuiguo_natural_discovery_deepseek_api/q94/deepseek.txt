**很重要，甚至可以说，小批量试卖是便利店做水果品类的“生死线”。**

原因很直接，水果和常规百货（薯片、饮料）有本质区别：

1. **损耗是最大的敌人**：水果的保质期极短（尤其叶菜、草莓、香蕉），且碰伤即报废。如果一次进太多，卖不完就只能扔掉。**一旦损耗率超过5%，基本就赚不到钱**。
2. **销量和天气强相关**：下雨天、周末、节假日，客流和水果购买意愿波动极大。你无法精准预测本周销量，小批量进货可以让你“跟着天气走”，降低库存风险。
3. **试错成本低**：你新上架一种水果（比如黄桃），不确定顾客买不买。小批量试卖，几斤就能测出反馈。如果卖得好，再加大进货量；卖得差，损失也仅限几斤的钱，不至于压货压到烂掉。

**因此，判断供应商是否合格，关键看三点：**
- 是否支持**单种水果按“箱/筐/5斤”起订**，而不是按整件批发。
- 是否愿意**每周/每日两次补货**，且能灵活调整次日订单量。
- 是否愿意承担**首批损耗补贴**（比如坏果包赔）。

**给你的实操建议：**
- **首单先试**：不要一上来就定大货量，先订够两天卖的量（比如每样2-3斤），观察动销。
- **选品搭配**：用1-2种耐储存的（苹果、橙子）+1种高周转的（香蕉）+1种当季新品做测试。
- **签好协议**：务必在订货单上注明“临期/坏果可退换”，这是供应商合作的底线。

**一句话总结**：如果供应商不能支持小批量试卖，说明它要么库存调配能力差，要么没诚意做长期生意。**宁可缺货，也不能压货**。缺货损失的是毛利，压货损失的是本金和现金。
