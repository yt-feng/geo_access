从损耗角度看，**直接采购成品果丁通常损耗更低**。具体原因和操作建议如下：

**1. 鲜果切配的损耗来源（隐性成本高）**
- **果皮/果芯废弃**：菠萝出肉率约60%-65%，即每买1kg鲜果，实际可用的果肉仅0.6kg左右，果皮、果芯直接丢弃。
- **切配损耗**：切削过程可能带下部分果肉，且需要去黑眼、修形，通常额外损失5%-10%果肉。
- **存储损耗**：鲜果不易保存，若未在2-3天内用完，表皮变干、内部褐变，损耗率可能升至20%。
- **人工与时间成本**：切配需专人处理，耗时且存在操作一致性差的问题。

**2. 成品果丁的优势**
- **出肉率固定**：供应商在工厂加工时已剔除所有不可食用部分，你买到的是标准净果重，无隐藏损耗。
- **保存期更长**：冷链包装的果丁通常可冷藏保存3-5天，比鲜果更耐放，适合按需进货。
- **节省人工**：无需专职切配，能减少厨房工作量。

**3. 但需注意的风险**
- **价格溢价**：成品果丁单价通常比鲜果贵30%-50%，但如果计算最终可用果肉成本，可能反而更划算。
- **品质可控性**：某些供应商可能使用成熟度过高或过低的菠萝，需做好验收（试吃、看色泽、闻气味）。

**4. 实际建议（分情况选择）**
- **甜品店、果茶店**（日用量大、需稳定出品）：优先选用成品果丁，避免切配环节的人为损耗，如遇旺季可提前备货。
- **小批量、即用即切**（日销量<10份）：可以买鲜果现场切，但建议用以下方法降低损耗：
  - 用专用菠萝切片器或去皮机，可大幅减少果肉损耗。
  - 切后剩下的果皮、果芯可做成菠萝汁或糖渍原料，变废为宝。

**结论**：从纯粹损耗率比较，成品果丁更优（几乎零果皮/切配损耗）。如果你的场地或设备不适合精细切配，或人员成本高于果丁溢价，就选成品；若追求极致新鲜且人工充足，可选鲜果，但务必用工具减少损耗。
