针对社区超市水果保鲜和库存控制，核心思路是**“以销定采、快进快出”**。以下给你一套可落地的实操方案：

**一、进货前：精准测算，少进勤补**
1. **看历史数据**：统计店铺最近1-2周每天各类水果的销量（按周一至周日分，周末和雨天差异很大）。
2. **定安全系数**：首次进货量 = 预估日销量 × 保质天数 × 0.8（留20%机动）。比如苹果能放5天，日销10斤，最多进40斤，而不是一次进一整箱。
3. **分类管理**：
   - **耐储类**（苹果、梨、柑橘、哈密瓜）：可进3-5天量，放阴凉通风处。
   - **中熟类**（香蕉、猕猴桃、芒果）：进2-3天量，需催熟或冷藏。
   - **易损类**（草莓、葡萄、樱桃、叶类水果）：只进1天量，甚至半日量，宁缺毋滥。

**二、收货时：严格验货，把住第一关**
1. **看外观**：表皮无机械伤、无霉斑、无腐烂点；香蕉不能有黑斑，草莓不能发软出水。
2. **捏硬度**：按品种标准验收，如桃、杏不能过软；苹果、梨要硬实。
3. **查成熟度**：要求供应商提供八分熟左右（刚好能摆1-2天卖完），避免进全熟或青涩货。
4. **当场扣秤**：切开抽查，发现内部腐烂的部位超过5%可直接拒收或要求折扣。

**三、库存控制：先进先出 + 视觉刺激**
1. **货架分三层**：最上层放最新的货，中间放昨天没卖完的（降价处理），底层放临期品（特价清仓），员工拿货必须从最上层拿。
2. **定期翻堆**：每天早晚各翻一次果筐，把底部的坏果挑出，防止霉变传染（尤其葡萄、草莓一坏烂一片）。
3. **动态降价梯度**：
   - 剩余保质期 > 2天：正常售价
   - 剩余保质期 = 1天：打8折，并贴“今日特价”标签
   - 剩余保质期 = 0.5天：打5折，或做成水果拼盘、鲜榨果汁引流
   - **关键原则：宁可少赚，不留过夜易损果**，每晚闭店前必须清掉当天易损类。

**四、日常保鲜技巧（低成本）**
1. **温度分区**：香蕉、芒果、木瓜不能进冰箱（会发黑）；草莓、葡萄、蓝莓必须冷藏（4-8℃）；苹果、梨常温即可。
2. **隔离催熟**：把苹果、香蕉（释放乙烯）与绿叶蔬菜、不耐放的水果（如草莓）分筐存放，避免加速成熟。
3. **加湿防干**：用喷壶每天早中晚对叶类水果（如荔枝、龙眼）轻喷水雾，保持湿润。

**五、极端情况处理**
- **滞销预警**：如果连续2天某个品种日销量低于预期的60%，立即停止补货，将该品种转为“今日特价”或搭配其他热销品组合销售（如“买西瓜送一小把葡萄”）。
- **进货渠道灵活**：尽量找能**次日送货**的供应商，签订“少量多次”供货协议（比如每天送20斤，而不是每周送140斤），把库存风险转移给供应商。

**执行清单（每天固定动作）**：
- 早9点：盘点昨日各水果剩余量，记录损耗，调整今日进货单。
- 中午12点：检查易损果状态，完成一次翻堆挑坏。
- 晚7点：对当天没售完的易损果启动降价或加工处理，检查冷柜温度。

坚持这套流程1-2周，你会自然算出店铺的**保本周转天数**（比如草莓必须是1天，苹果是4天），从而真正实现“卖多少进多少”。如果某类水果连续3天降不出去，果断停掉该品种，集中精力做爆款。
