做水果礼盒，针对**家庭**场景，核心是**营养均衡、方便现吃、耐储存、份量适中**。推荐三种侧重不同的组合方案，你可以根据预算和时节选择。

---

**方案一：经典均衡型（最推荐，适合多数家庭）**
- **组合**：苹果 3个 + 橙子 3个 + 香蕉 1把（约4-5根） + 菠萝 1个（切好的或整果）
- **理由**：苹果耐放、橙子补充维C、香蕉是即食能量、菠萝增加热带风味。所有水果都容易切开，老人小孩都能吃。
- **盒装建议**：香蕉单独用纸包住放最上层，防止压坏；菠萝如果是整果，建议放底层，纸盒内用泡沫网兜隔开。

---

**方案二：低糖健康型（适合有控糖或健身需求的家庭）**
- **组合**：苹果 4个（选脆甜型，如阿克苏） + 橙子 4个（选酸甜适中的） + 香蕉 1小把（选熟度偏低一点，升糖指数相对低） + 菠萝 半个（切块，减少一次摄入量）
- **理由**：把香蕉换成小把（减少单次碳水摄入），菠萝给半个并切块，方便分两顿吃，不容易浪费。

---

**方案三：便利即食型（适合双职工家庭或孩子小）**
- **组合**：苹果 2个 + 橙子 2个 + 香蕉 2根 + **菠萝切块（装独立小盒）** + 附赠一次性水果叉
- **理由**：把菠萝提前切块（放冰袋或冷藏处理后放入盒内），香蕉选对半切，所有东西开盒即食，省去处理菠萝的麻烦（菠萝处理费时且易扎手）。

---

**关键操作建议（重要）：**

1. **香蕉放最上层**：香蕉怕压，且会释放乙烯催熟其他水果，所以**必须**与其他水果用纸或泡沫隔开，且不要封死在盒子里。
2. **菠萝要看人处理**：如果对方家里没人会削菠萝，建议让商家削好并去皮、切块（用食用盐水泡过），否则买整颗菠萝回家可能“吃不了”几天。如果是整颗，选青皮多一点的，更耐放。
3. **份量控制**：家庭份量建议总净重**5-6斤**左右，刚好够一家3-4口人吃2-3天，避免一次买太多放坏。
4. **包装颜色**：苹果选红色、橙子选橙色、香蕉选黄绿色、菠萝有绿叶，组合起来颜色跳跃，符合节日或送礼氛围。

---

如果必须四选一优先保证，**苹果和橙子**是必留的（耐放、好处理），香蕉和菠萝可以二选一替换（香蕉更易吃，菠萝更有仪式感）。若预算有限，建议方案一，性价比最高。
