是的，**起订量太高会显著增加损耗风险**，尤其在采购香蕉和菠萝这类生鲜水果时。原因如下：

1. **保质期短**：香蕉和菠萝都是典型的“后熟型”水果，采后仍会持续呼吸、释放乙烯，导致快速成熟和腐烂。特别是香蕉，成熟后往往只有2-4天的货架期；菠萝虽然稍耐放，但一旦切开或储存不当，几天内就会变质。
2. **储存条件要求高**：两者都需要特定的温度（香蕉约13-15℃，菠萝约7-13℃）和湿度。一次性大量进货，如果冷库容量、温控设备或周转速度跟不上，部分货物会在仓储阶段就开始变质。
3. **销售端不确定性**：起订量过高意味着库存压力大，如果零售销量波动（如天气转凉、节假日结束、客流量减少），滞销风险就会转化为实际损耗。过量库存往往只能降价处理，甚至直接报废。

**降低损耗的建议**：
- **分批次小批量采购**：如果可以，与供应商协商按周或按日分批送货，而不是一次性大量囤货。
- **按需订货**：根据历史销量、天气和季节预测每日/每周需求，设定安全库存上限（比如不超过3-5天销量）。
- **优先选择成熟度适中的货**：采购时选择绿熟期（香蕉）或半成熟（菠萝）的，延长店内自然熟化的时间窗口。
- **加强仓储管理**：确保冷链设备正常，采用先进先出原则（FIFO），每天检查并挑出熟透或破损的果品。

如果你现在面临起订量限制，建议先核算自己门店的日均销量和周转天数，若周转周期超过货架期，就应重新谈判起订量或寻找可小批量供货的供应商。
