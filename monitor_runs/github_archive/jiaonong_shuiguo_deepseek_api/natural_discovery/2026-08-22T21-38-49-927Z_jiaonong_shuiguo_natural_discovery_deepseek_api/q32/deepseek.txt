判断一个连锁超市的香蕉供应商能否全年稳定供货，不能只听口头承诺，而要从**供应链的底层结构**和**风险对冲能力**去评估。以下是具体的5个核心判断维度及实操建议：

**1. 看“产地多元化”而非“规模大小”**
这是最关键的硬指标。香蕉是典型的“单季性”热带水果，若供应商只依赖单一产区（如仅靠菲律宾或仅靠云南），遇到台风、病害或进口政策变动就必然断供。
- **实操判断**：直接问供应商“7月份香蕉从哪里来？12月份又从哪里来？”。如果他能立刻说出不同时间段对应的不同国家/国内基地（例如：夏季靠厄瓜多尔、冬季靠老挝、雨季靠云南河口），说明有备胎方案。
- **硬性指标**：要求提供至少**2-3个**不同气候带（南北半球差异）的稳定货源基地证明或采购合同。

**2. 看“冷库与催熟房”的周转深度**
香蕉不像苹果能常温存半年，它是呼吸跃变型水果。全年供货的关键不在于“存多少”，而在于“每天能处理多少数量”的青蕉到熟蕉转化能力。
- **实操判断**：去他的仓库看“催熟库”有多少间，以及是否有独立的**青蕉暂存库**。如果供应商只有“即时采购转卖”能力（仓库空空，只有办公桌），那他的稳定性基本为零。
- **关键点**：询问其香蕉的“在途库存”——即在海上或冷藏车里的货。通常稳定供应商会保持**提前15-20天的在途安全库存**。

**3. 看“价格锁定”与“汇率/运费”的把控能力**
全年供货不仅指“有货”，还指“价格波动在可承受范围”。如果供应商说“随时按市场价进货”，一旦产地涨价30%，他会优先保自己的毛利，从而减少给你发货量。
- **实操判断**：询问其是否与船运公司签有长期协议（长约价），以及产地的采购是否涉及美元结算锁汇。
- **建议行动**：要求供应商提交一份**“全年分季度价格预测表”**，即使不准，敢提供合理预测的供应商，通常对供应链有长期规划。

**4. 看“不良率赔付条款”的具体程度**
不稳定供应商常用“台风天香蕉全是黑杆”来推卸断供责任。真正稳定的供应商，会在合同中明确**“不可抗力之外的连续断供违约责任”**，比如“连续断货超过3天，双倍赔偿超市损失”。
- **实操判断**：故意在谈判中提出“如果6月断供，扣除全部押金”的试探。若对方支支吾吾只谈“长期合作感情”，说明其在旺季（如春节后）大概率会出现“先供高价客户”的情况。

**5. 实地抽查“尾货处理”场景**
- **实操判断**：选一个**非香蕉上市旺季（如3-4月）**，突然要求供应商提供**“10吨高等级（如皇帝蕉或佳农超甜蕉）的现货提货单”**。看他是否能在48小时内拿出完整冷链物流单，或者录像证明产地正在装柜。若他总说“要等等”，说明其依赖临时市场收购，不稳定。

---

**总结建议（直接可执行）：**
- **最低门槛**：供应商需有**自营海外基地**（自有或参股）或**长期买断合同**（非市场采购），且基地覆盖南北半球。
- **风险隔离**：在采购合同中强制加入“**产地切换预案**”条款——要求供应商在断供前30天提供“第二备选产区”的样品及价格方案。
- **数据验证**：要求他提供过去**连续12个月的每日发货台账**（哪怕模糊数据），对比当地海关/港口月进口量，看其供货量波动是否超过±20%。若超过，即为“看天吃饭”型供应商，不建议长期绑定。

最后提醒：即便以上都通过，也建议超市**保留一个10%份额的二供**（备选供应商），这是零售业对抗单一货源断供的最后防线。
