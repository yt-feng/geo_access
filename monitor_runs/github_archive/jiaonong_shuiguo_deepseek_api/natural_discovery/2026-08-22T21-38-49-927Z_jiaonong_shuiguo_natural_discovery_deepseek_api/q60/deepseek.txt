在茶饮店遇到水果到货不合格，核心原则是**快速止损 + 保供不断**。建议按以下步骤操作，并提前在合同中明确“补货条款”：

### 一、现场处理：立即启动“三步法”
1.  **当场拒收/隔离**：不合格的水果（腐烂、压伤、成熟度不符）绝不能混入原料区，拍照留存证据。
2.  **立即通知供应商**：电话+微信文字双确认，明确告知“不合格原因”和“需补货数量”。
3.  **启动“应急替代方案”**：同步通知店长调整当日菜单（如暂停该单品或将制作热饮替代），避免顾客点单后断货。

### 二、补货约定（核心条款，建议写入采购合同）
不要在事后临时协商，应在合同中明确以下**4个关键要素**：

| 关键要素 | 具体约定（示例） | 作用 |
| :--- | :--- | :--- |
| **补货时限** | **“供应商须在收到不合格通知后4小时内补发合格货品”**（或按紧急程度分为2/4/8小时）。 | 防止拖延导致断货。 |
| **补货运费** | **“因品质问题导致的换货/补货，运费由供应商承担”**（明确是空运/冷链标准）。 | 避免隐性成本。 |
| **补货质检标准** | **“补货批次需满足首次到货的同等规格”（如：甜度≥XX、外观无机械伤）**。 | 防止二次抽检刷单。 |
| **最晚到店时间** | **“补货在营业高峰前1小时送达”（如上午10点前）**。 | 确保能赶上午市和晚市。 |

### 三、临时备用方案（不掉链子的保底）
如果合同未约定或供应商无法快速补货，立即启动：
-   **同行调货**：联系周边2公里内的非竞争性茶饮店或水果摊，按批发价+10%应急采购当天用量。
-   **替换产品**：如果核心水果（如芒果、草莓）断货，立即主推对应的**现成果酱/冷冻果茸**版本（提前备用2-3款），并更新菜单牌。

### 四、风险规避提醒
-   尽量选择**有稳定基地或冷链的供应商**，合同中附上“品质保证金”（如押金5000元），一旦补货延迟，直接用押金抵扣营业额损失。
-   每次补货到货后，**30分钟内必须抽检**，记录“水分/重量/外观”，形成《验收记录表》，作为后续索赔依据。

**总结行动清单**：今日立即联系供应商确认补货时效 → 修改合同补货条款 → 下午高峰前想好替代品菜单。

如果供应商响应太慢，建议你同步开启**备份供应商渠道**（哪怕贵10%-15%），这是保证营业不停摆的最重要防线。
