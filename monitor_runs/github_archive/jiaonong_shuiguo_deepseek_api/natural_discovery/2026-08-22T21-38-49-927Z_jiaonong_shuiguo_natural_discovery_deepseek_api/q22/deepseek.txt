针对超市水果区提高客单价，**核心策略不是单纯打折，而是“用高毛利单品带动低毛利引流品”，并引导顾客从“买一个”变成“买一餐/一组”**。

以下是针对香蕉、菠萝、苹果的具体组合促销方案，分为三个层级，你可根据门店定位选择或叠加使用：

### 一、 基础组合：制造“必买理由”（提升连带率）
**1. “热带风情早餐组合”**（建议放置在收银台旁或水果区主通道）
- **组合内容**：1根香蕉 + 1杯菠萝（切块） + 1个苹果（小果）。
- **定价策略**：单买合计约12元，组合价**9.9元**（让利约18%）。
- **话术/陈列**：用透明PET盒装好，贴上“每日维C+膳食纤维，元气早餐首选”的标签。菠萝建议提前去皮切块，用保鲜膜包好，减少顾客处理时间。
- **利润逻辑**：香蕉和苹果通常毛利较低（15%-20%），但菠萝（特别是国产菠萝）毛利可达40%以上，组合后整体毛利率反而提升。

**2. “果切能量碗”**（针对白领/健身人群）
- **组合内容**：菠萝块 + 苹果片 + 香蕉段，混合装盒（约350g）。
- **定价策略**：定价**15.8元/盒**，同时标明“单点三种果切约需18元”。
- **关键动作**：在盒子侧面外贴“低卡轻食”标识，并在旁边放一个小立牌：“搭配酸奶/燕麦更美味”。

---

### 二、 进阶促销：借“势”提单价（提升客单价金额）
**3. “买2送1”的临界点设计**
- **适用商品**：香蕉（按根卖）、菠萝（按个卖）、苹果（按个卖）。
- **玩法**：不直接打折，而是设计**“三件套”**：
  - 购买任意2个水果（例如1个菠萝+1个苹果），加0.9元换购1根香蕉。
  - **心理学要点**：顾客原本只想买1个苹果，看到“加0.9元可得香蕉”会觉得超值，从而把预算从3元提升到10元以上。

**4. “满额立减/赠品”捆绑**
- **设置门槛**：水果区单笔消费满**25元**，立减3元，或赠送1个香蕉（成本约0.8元）。
- **意义**：香蕉、苹果单价低，顾客很难凑到25元。这会促使他们主动加购一个**菠萝**（通常8-10元）来凑单。这利用菠萝的高单价拉高整体客单。

---

### 三、 高阶玩法：制造“关联需求”（提升转化率）
**5. “周末榨汁组合”主题堆头**
- **灵感**：苹果+香蕉+菠萝是经典的“排毒果蔬汁”配方。
- **具体执行**：
  - 在水果区的一端设一个**专题堆头**，把三种水果放在同一货架。
  - 旁边放一块**立牌**，写明配方：**“苹果1个 + 香蕉半根 + 菠萝1/4个 + 凉白开500ml = 清甜顺滑排毒饮”**。
- **定价**：为这个“榨汁三件套”单独打包，售**19.9元/套**（保证每种水果的量足够榨一壶）。这个方法能直接提升整体客单价，因为顾客买的不再是单一水果，而是一份“解决方案”。

---

### ⚠️ 重点执行细节（直接决定成败）

- **菠萝处理**：促销时必须提供**去皮**选项。直接卖带皮菠萝，很多顾客会嫌麻烦而放弃购买。**现场切块装盒的菠萝，转化率是带皮菠萝的3倍以上。**
- **苹果选品**：不要用最贵的品种（如新疆阿克苏），选**中等价位、口感脆甜**的普通红富士即可，控制成本。
- **香蕉成熟度**：促销的香蕉可以稍微带一点青色（稍生一点），因为顾客买回去不会立刻吃完，能减少损耗；但**陈列盒内**的果切香蕉必须全熟（表皮有黑点也问题不大）。

### 最终建议方案（可直接执行）：
> **“一日鲜饮组合”：** 即可直接采用方案5的“榨汁三件套”19.9元，并附赠1个小号购物袋。同时，在收银台放置方案2的“果切能量碗”15.8元作为冲动消费品。

**执行话术**（员工推荐语）：“今天是菠萝最好的批次，您搭配香蕉和这个苹果榨汁，一杯成本只要6块多，比奶茶健康还便宜。”
