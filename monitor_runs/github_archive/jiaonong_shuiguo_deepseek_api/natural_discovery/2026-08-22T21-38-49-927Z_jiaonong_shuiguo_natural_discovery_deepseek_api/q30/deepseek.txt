针对超市水果到货品相不佳的问题，售后流程的约定应当**清晰、快速、可执行**，同时兼顾供应商和超市双方的利益。以下是建议的约定框架：

### 1. 核心原则
- **时效优先**：水果腐烂变质快，售后处理必须在24-48小时内启动。
- **证据链**：以到货照片/视频为准，避免口头扯皮。
- **责任前置**：明确“供货前”与“到货后”的品控标准。

### 2. 标准约定条款（按顺序执行）

**第一步：到货验收（24小时内）**
- 超市收货员须在到货后**2小时内**完成抽查（建议开箱率≥10%，重点看底箱）。
- 若发现品相差（如软烂、发霉、黑斑、挤压变形），需**立即拍照留证**（含外箱码、内貌、整体托盘图）。
- 供应商须认同：品相不确定时，以超市抽检结果为初步依据，供应商可调取物流监控。

**第二步：争议分级处理（48小时内）**
- **轻度瑕疵**（单一水果软损、表皮划痕，占比<5%）：超市自行降级销售（搞特价/加工切盒），不退货，仅扣减损耗补贴（约定按次扣供应商货款金额）。
- **中度瑕疵**（占比5%~15% 或 袋装内有霉变）：超市提供照片清单，允许供应商在**48小时内**补货或折价，否则按破损数量等额退款。
- **重度瑕疵**（整箱翻白、发黑、虫蛀，占比>15%）：超市有权**整箱拒收**，需在到货后6小时内书面通知供应商拒收并保留证据，供应商承担运费、包装费。

**第三步：售后判定时限**
- 双方须在**到货后48小时内**达成退货/补偿/抵扣意见。
- 若23小时内未反馈，默认同意超市处理方案（该条款需供应商签字确认）。

### 3. 特别条款（防止扯皮）
- **签收不等于认可**：包装上需写明“外表完整不代表内部无质量问题”，允许开箱后24小时反馈。
- **常绿水果（香蕉、葡萄）**：需约定“成熟度”等级，若到货过生或过熟，按外观比例扣款。
- **赔付上限**：单批水果投诉赔付总金额不超过该批货款的30%（防止恶意索赔）。

### 4. 实操建议（落地处）
- 在采购合同“验收单”下方加一行：**“收货方有权在到货后24小时内对品相提出异议，并保留现场照片证据”**。
- 供应商沟通群内，提前发布《品相标准图例》（比如：草莓红度需≥80%，葡萄不掉粒，叶菜无黄叶等）。

### 5. 风险提示
- 不要约定“外观好但不甜” = 退货，因为甜度无法证明且难追溯。
- 若供应商频繁出现中度以上瑕疵，每季度可通过售后记录下调其供货等级或加收品控押金。
