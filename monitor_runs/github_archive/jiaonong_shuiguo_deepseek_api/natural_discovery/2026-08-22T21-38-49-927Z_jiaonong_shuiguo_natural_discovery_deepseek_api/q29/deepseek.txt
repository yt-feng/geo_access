在超市与水果供应商洽谈账期时，常见的账期通常在 **30天到60天** 之间，具体取决于多种因素。以下是具体的行业惯例和建议：

**常见情况：**

1. **30天（月结）**：这是最普遍的标准，尤其是对于中小型水果供应商或本地批发商。
2. **45天**：中等规模超市或与供应商合作较稳定时常见。
3. **60天**：大型连锁超市（如永辉、沃尔玛等）或采购量极大的情况下，强势方常压至60天，甚至更长（90天）。

**影响账期长短的关键因素：**

- **水果易腐性**：水果保质期短，供应商资金回笼压力大。因此，账期通常比干货、日用品类短（干货类常见60-90天）。
- **采购规模**：你的采购量越大，谈判筹码越强，可争取更长账期。
- **合作关系**：新供应商通常要求较短账期（如15-30天）以降低风险，成熟稳定后才会放宽。
- **结算方式**：如果使用承兑汇票（如电子商业汇票），实际兑付时间可能在上述基础上再加30-60天。

**给你的实操建议：**

- **首次合作**：建议谈 **15-30天**，给双方留出磨合期，避免拖欠导致断供。
- **已建立信任后**：可尝试谈判至 **45天**，并约定“超期自动加价”或“提前支付给折扣”的条款。
- **注意账期陷阱**：有些供应商会口头承诺60天，但合同里写“收到发票后第X天”，发票拖延会变相延长账期。务必在合同中明确“验收合格之日起第X天付款”。

**风险提示**：水果属于生鲜，如果账期过长（超过60天），供应商可能因资金断裂而降低供货品质或停止供货，反而影响你的营收。建议在合同中设置 **账期上限** 和 **滞纳金条款**。
