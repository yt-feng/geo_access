酒店在采购水果盘原料时，供应商应保证的规格和外观标准，通常需要根据酒店的**星级标准、出品档次（自助餐/客房送餐/宴会）以及成本预算**来确定。但无论何种档次，以下**核心规格和外观标准**是通用底线：

**一、核心规格标准（尺寸、成熟度、数量）**

1.  **成熟度（最重要）：**
    *   必须达到**食用成熟度**，即口感、甜度、香气最佳阶段。
    *   不能过于生硬（无味难咬），也不能过熟软烂（易出水、压伤）。
    *   通常要求糖度达标（如西瓜中心糖度≥10度，哈密瓜≥12度，草莓需全红香甜）。
2.  **大小均匀度：**
    *   同一批次、同一品种的水果，单果克重或直径差异不得超过**±10%**（例如：草莓要求单果≥15g，蓝莓单果直径≥12mm，橙子直径≥7cm）。
    *   切片水果（如哈密瓜、火龙果）切块大小需一致，厚度均匀（通常为3cm见方）。
3.  **新鲜度与重量：**
    *   发货时需保证当日或前一日采摘，总净重需满足订单要求，并预留合理的失水率（通常允许±2%损耗）。

**二、外观标准（色泽、损伤、瑕疵）**

1.  **色泽与光泽：**
    *   果皮颜色必须达到该品种的典型成熟色，且整体色泽均匀。
    *   表面需有自然光泽，无暗淡、无过度脱水皱皮现象。
2.  **无机械损伤与病虫害：**
    *   **绝对禁止**：果实表面有压痕、软化凹陷、开裂、冻伤、病菌斑（如霉变、褐变）、虫眼或虫卵。
    *   **允许范围**：极轻微的果锈或不超过果面2%的微小擦伤（不影响口味和外观），但客房果盘或宴会摆台必须要求**零瑕疵**。
3.  **形状规整：**
    *   外形需符合该品种的典型形状（如苹果要圆润，芒果要饱满），不认可畸形果、裂果、歪果（除非是主要用于打汁但外观要求高的果盘，也需剔除）。
4.  **表面干净度：**
    *   无残留农药渍、无泥土、无保鲜剂挂水痕迹，需经过清洗并自然晾干（供鲜切使用）。

**三、供应商应附带的“隐形标准”（合规与冷链）**

*   **农残检测报告**：每批次必须提供有效的农残快检合格报告（符合GB 2763国家标准）。
*   **冷链温度**：交货时果心温度需达到**2℃-8℃**（冷链运输，防止高温催熟或细菌滋生）。
*   **标识清晰**：外包装需注明品名、产地、采收日期、保质期，以便酒店收货验收。

---

**给您的采购验收建议（可直接执行）：**

*   **制定《验收标准卡》**：在合同中明确以上量化指标（如：草莓单颗≥15g，西瓜中心糖度≥10%），并附上优质果实的图片作为对照样本。
*   **按“批次抽检”**：到货后随机抽取整箱中的5-10个果实进行切开检查，重点看内部是否有褐变、空心、白籽（表示催熟）或籽变黑（过熟）。
*   **特别提示**：如果要给**VIP客户或宴会**使用，建议要求供应商提供**“特级果”**（颜色一致、无任何疤痕），并提前一天到货，由酒店后厨自行二次清洗和精修果皮。
