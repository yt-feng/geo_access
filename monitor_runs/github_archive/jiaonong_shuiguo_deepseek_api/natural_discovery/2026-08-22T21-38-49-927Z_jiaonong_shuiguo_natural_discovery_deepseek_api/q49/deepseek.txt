茶饮店旺季临时补货，核心是**“快”**和**“稳”**。建议按以下步骤与供应商沟通，并明确书面约定：

**第一步：立即电话沟通（先别发微信）**
直接打电话给供应商采购负责人，说明情况，话术参考：
> “X总，我们最近菠萝销量暴增，现在库存只能撑X天，急需加急补X件（约XX公斤）。能不能帮忙协调一下？”

**重点：** 明确告知**“紧急程度”**和**“具体数量”**，不要模糊说“多来点”。

**第二步：约定“临时加单”的关键条款（务必落实到微信/合同）**
1.  **价格与调价机制：** 明确本次临时补货按**原合同价**执行，还是因旺季上涨（若涨价，要求给出市场依据）。同时约定：**若后续价格下调，本次订单应自动按新价格结算**。
2.  **到货时限（最重要）：** 白纸黑字写清楚“**X月X日X点前送达**”，并约定**逾期赔付**（如每延迟1小时扣总货款的2%）。
3.  **品质标准：** 注明“**到货菠萝需无黑心、无腐烂、成熟度一致**”，并约定**到货抽检比例**，一旦发现品质问题有权拒收或扣除相应货款。
4.  **数量弹性：** 约定“**允许±5%的浮动偏差**”，防止供应商多送或少送。
5.  **结算账期：** 明确本次临时补货是**现款现结**（一般临时加急单需要现结优先排产），还是拉长账期（如果是老供应商，可以争取月结额度内优先）。

**第三步：现场验收（收货时操作）**
- 到货后**立即开箱抽查**，重点看底部是否混有烂果（旺季为了防止断货，供应商可能掺次品）。
- 若发现品质问题，**当场拍照留证**，并拒收问题部分，同时向供应商确认“**是否重新补货，还是直接扣款**”。

**第四步：长期防缺货（未雨绸缪）**
- 告知供应商“**本次只是阶段性急单，后续如果能保证稳定供应，我们月采购量可提升至X吨**”，以此换取他优先排产。
- 同时**双供应商备选**：分出一小部分量给第二家供应商，防止单一来源旺季坐地起价。

**最后提醒：** 所有临时承诺（价格、数量、到货时间）**必须截图保存微信聊天记录**，或让供应商发一封确认邮件，作为后续对账和违约追责的依据。口头说的都不算数。如果供应商要求立刻打款，务必核对到货后再付款，或预付不超30%定金。
