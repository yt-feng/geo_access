在水果采购合同中，**坏果率（包括腐烂、霉变、严重机械损伤等）的赔付标准没有全国统一的法律规定**，主要取决于合同双方的约定、行业惯例以及水果的品类特性。

为了保障你的权益，以下是一些**可操作的建议和参考标准**：

**1. 合同约定的核心条款（强烈建议）**

- **明确“坏果”定义**：合同中必须写清楚哪些情况算坏果。通常包括：腐烂、发霉、变质、严重压伤（导致不能食用）、冻伤等。**不要只写“坏果”两个字**，应附上照片作为标准例证。
- **约定赔付阈值**：建议在合同中明确写出“**当单批到货坏果率超过 X% 时，买方有权要求赔付**”。具体阈值可根据水果品类调整：
    - **易腐类（如草莓、樱桃、荔枝）**：建议约定 **3% - 5%**。超过此标准即触发赔付。
    - **较耐储存类（如苹果、梨、柑橘、西瓜）**：建议约定 **5% - 8%**。
    - **特殊加工类（如用于榨汁的次果）**：双方可自行约定更高的容忍度。
- **赔付方式**：应写明是**按比例扣除货款**（例如：坏果率10%，则扣减总货款的10%），还是**按实际坏果重量补偿**，或是**无条件补发同品质新货**。

**2. 法律/行业惯例参考（无合同约定时）**

- **《中华人民共和国民法典》**：如果合同未约定，买方可以根据《民法典》第610条主张“**标的物不符合质量要求**”，要求卖方承担修理、重作、更换、退货、减少价款等违约责任。
- **行业惯例**：多数正规水果批发市场及电商供应链，通常将**3% - 5%** 作为“合理损耗”的默认上限。**如果坏果率超过 3% - 5%**，通常可以认为属于“数量不符”或“质量违约”，有权索赔。

**3. 特殊情况说明**

- **运输风险**：如果合同约定送货上门，那么在到货时（卸货前）发现的问题由卖方负责；如果约定自提，那么在装车后的风险通常由买方承担。**合同中应明确“验收地点”**。
- **“自然损耗”除外**：某些水果（如香蕉在运输中成熟的斑点、苹果的水分蒸发）属于自然现象，不属于坏果，应事先约定排除在外。

**结论与建议**

- **最稳妥方案**：**直接约定“坏果率 ≤ 3%”**（对于大多数水果）。一旦超过3%，即触发赔付条款。
- **最优先操作**：**先看合同**。如果合同里写了具体比例，按合同执行。
- **如果合同未写**：**不要等收货后在现场争吵**，应在到货 **24小时内**（短保水果）或 **48小时内**（普通水果），**拍照、录像留证**，并书面（微信/邮件）通知供应商，援引“违约”条款要求赔付或退货。

建议你在签订合同前，将上述“3%-5%”的阈值作为谈判底线写入条款，并附上“验收标准照片”作为附件。这比事后补救更有保障。
