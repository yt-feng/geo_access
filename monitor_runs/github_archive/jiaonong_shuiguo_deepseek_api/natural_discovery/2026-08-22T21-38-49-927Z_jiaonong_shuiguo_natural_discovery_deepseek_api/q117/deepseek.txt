对于水果供应商推荐的新品，采购方试卖的核心原则是**“少量多频、快进快出”**，避免库存积压和损耗。

建议的试卖数量参考如下：

**1. 基础安全量（普遍适用）**
- **单店试卖**：建议首批进货控制在 **20~50斤**（或3~5箱，视水果包装而定）。
- **多店测试**：如果是连锁，建议只在 **1~2家** 核心门店测试，总量控制在 **100斤以内**。

**2. 按品类调整**
- **高损耗、难储存**（如草莓、山竹、杨梅）：首批 **10-20斤** 即可，当天必须售罄，考验周转速度。
- **易储存、大众化**（如苹果、橙子、梨）：首批可稍多 **50斤** 左右，试销周期可拉长至3-5天。
- **进口高价果品**（如晴王葡萄、进口车厘子）：按 **5-10公斤** 或 **1-2箱** 起步，先看客流反应。

**3. 控制试卖周期**
- **黄金测试窗口**：建议试卖 **3~7天**。
- 如果3天内回头客或大单出现，说明有市场，可正常订货。
- 如果7天内动销缓慢，果断停止补货，降价清尾货**，不要恋战。

**4. 关键判断指标**
试卖不是看“卖没卖完”，而是看**复购率**和**毛利空间**：
- 试卖期间，**复购占比**应达到 **20%~30%** 以上（即老客户回头买新品）。
- 如果同行竞品价格低于你，但品质相近，则谨慎主推。

**5. 额外提醒**
- **留样对比**：试卖时让供应商提供小样，与现有同类果品做盲测对比（甜度、脆度、外观）。
- **损耗计提**：试卖期间损耗率超过 **10%**，建议立即叫停，说明品质或保鲜不适合你的渠道。

如果供应商坚持要求大量进货，可以要求“**阶梯式拿货**”（首批小、后续逐次加大），并约定**尾货回收或调换**条款，这是最稳妥的谈判方案。
