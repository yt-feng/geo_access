社区团购旺季爆单时，水果供应商库存紧张是常态。要提前锁定库存，建议从**契约、资金、计划**三个维度入手，并配合实际执行动作，具体如下：

**一、签订“保量保价”协议（契约锁库）**
1. **签框架合同**：旺季前1-2个月，与供应商签订旺季采购协议。明确**锁定期（例如9月1日-10月15日）、锁定品种（如阳光玫瑰、秋月梨）、锁定吨数**。
2. **明确“死约”与“活约”比例**：例如约定总需求量的70%为不可撤销预订单（死约），剩余30%为弹性采购（活约），避免预估错误造成压货损失。

**二、支付诚意定金（资金锁库）**
1. **预付定金**：向供应商支付订单总金额的**10%-30%**作为定金，并在合同中注明“该定金为包销定金，若供应商违约需双倍返还”。
2. **账期换优先权**：如果现金流充裕，可以承诺“现款现货”或缩短账期（如原本30天缩短至7天），换取供应商优先发货权。

**三、共享销售预测（计划锁库）**
1. **提供历史爆单数据**：将你过往旺季的销售数据、各小区团长下单趋势给供应商看，证明你的需求量真实可靠。
2. **滚动下单**：不要一次性下满，而是采取“**14天滚动预测**”。比如今天锁定下周的量，后天再锁定下下周的量，让供应商每天都清楚你的确定需求，减少其种植/备货风险。

**四、执行层面的“防掉链子”动作**
1. **产地驻场员**：旺季前派1名员工或雇佣当地代办驻守在供应商的冷库/分拣中心，每天核对库存和采摘进度，确保货被半夜抢走“最早发货”。
2. **替代供应商备胎**：在30-50公里外或同产区，提前谈好1-2家备选供应商，并垫付少量合作诚意金，以防主要供应商因天气等原因缺货。
3. **损耗风险条款**：在协议中约定“验收标准”，比如糖度、果径下限，防止旺季供应商以次充好，用次货顶替优质库存。

**五、话术参考（如何跟供应商谈）**
> “王老板，今年旺季我们预估每天的销量是X吨，我计划在你这边锁定其中60%的量。为了保证你优先给我留货，我先把这一周的定金打给你，并且我承诺每天下午4点前给你下第二天的具体数字。如果最后因为我预估少了导致我少拿货，定金按合同比例你留一部分当补偿，但如果到了日子我交了钱你没货，你得赔付我的损失。”

**关键提醒：** 供应商也是靠天吃饭，遇到持续阴雨导致减产，定金无法完全规避缺货风险。因此锁库的核心是**“让利给供应商”**——要么把采购价提高0.2-0.5元/斤，要么承诺“卖不完的自己兜底”，这样对方才愿意冒风险为你留库存。
