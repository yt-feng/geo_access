针对连锁门店分布在不同城市的水果供应商仓配覆盖评估，核心是**用数据验证“门店缺货成本”和“损耗成本”之间的平衡**。水果是高频、高损耗、短保商品，评估不能只看配送半径，要分四个维度打分。

以下是可执行的评估框架：

### 第一步：画出“门店-仓”物理距离矩阵
不要只看直线距离，要计算**实际车程**。用地图API（高德/百度）拉取所有门店到供应商各仓的驾车时长。

| 维度 | 评估标准 |
| :--- | :--- |
| **T+0（当日达）** | 车程≤3小时，可当日凌晨采摘、上午送达。 |
| **T+1（次日达） | 车程3-8小时，需夜间运输或次日早晨到达。 |
| **T+2以上** | 车程>8小时，水果品类基本不适合常规配送，除非做冻品或极耐储品种。 |

**关键动作**：计算每个仓覆盖的门店比例。如果核心商圈门店（占销售额60%以上）处于T+1边缘，建议强烈要求供应商加设前置仓或改配。

### 第二步：评估“多温层”与“分拣”能力（比距离更重要）
水果的损耗率在5%-15%，评估仓配最关键的不是送得快，而是**处理快**。

- **分拣能力**：供应商仓库是否有**催熟库**和**预冷库**？到货后能否在2小时内完成分拣装车（避免堆叠压伤）。
- **温度断链检查**：要求供应商提供**冷链GPS温控记录**，核对从产地到门店的全程温度曲线。
- **破损率KPI**：设定硬指标：**到货损耗率≤3%**（常规水果），**≤5%**（浆果/叶菜）。在合同中必须写明退换货条款。

### 第三步：用“每周3次”的高频测试代替一次性考核
水果采购不是一锤子买卖，建议进行**4周连续测试**：

1. **第1-2周**：选3个不同城市的门店，要求供应商按正常节奏配送（不提醒）。
2. **记录数据**：到货时间准确率、腐败果比例、客服响应时效。
3. **第3-4周**：模拟大促（临时增加30%订单量），看供应商是否掉链子（优先保障你的货还是别人的）。

**合格线建议**：4周内**准时率≥95%，大促期间≤1天延迟**。

### 第四步：核算“隐形物流成本”
评估不能只看报价单上的运费，要算综合账：

- **远仓近送**：如果某城市只有1家门店，供应商从300公里外送货，单店履约成本极高。此时应考核**拼车/并单能力**（与其他连锁店共享车次）。
- **逆向物流**：水果退换货率较高，是否有空车返程带回？返程空驶成本是否计入报价？
- **最低起送量**：供应商是否要求“单城市日订单≥500斤”才配送？如果凑不够，会强制压货，导致门店损耗增加。要**明确每个城市的起订门槛**。

### 第五步：给出可执行的“一票否决”项
以下情况，无论价格多便宜，直接判负：

1. **核心城市（TOP3销售城市）无法做到T+1**。
2. **无恒温分拣车间**（只有常温库，夏天到货极易腐）。
3. **拒绝提供冷链温度记录**。
4. **合同里只写“产地直发”，不设“到店前置仓”**。
5. **对损耗率0赔付**（只换不退）。

---

**最终输出形式建议**：
给供应商发一张评估表，要求他们填写并附证据，按以下权重打分：

| 评估项 | 权重 | 数据来源 |
| :--- | :--- | :--- |
| 配送时效（T+0/T+1覆盖率） | 30% | 高德API计算 |
| 仓内设备达标率（预冷/催熟/分拣） | 20% | 实地拍照+设备清单 |
| 近3个月历史准时率 | 20% | 要求提供系统截图 |
| 损耗率数据 | 20% | 提供过往客户（非你司）出库单与验收单对比 |
| 应急响应（加单/改单） | 10% | 模拟测试结果 |

**特别提醒**：如果门店在**县级市**或**地级市非主城区**，务必要求供应商明确“最后一公里”的承接方（是供应商直送还是第三方城配）。很多大供应商只覆盖省会，地级市由当地合作商配送，品质会大打折扣，这必须在评估表里单列。
