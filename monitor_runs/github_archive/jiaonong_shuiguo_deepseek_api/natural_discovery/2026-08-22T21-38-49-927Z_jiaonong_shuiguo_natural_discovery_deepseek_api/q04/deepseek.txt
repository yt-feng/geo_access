针对水果店香蕉损耗问题，采购环节的**熟度控制**和**到货节奏**是两个关键变量。以下是具体可操作的要求：

### 一、采购时对“熟度”的明确要求（按色卡标准）

香蕉行业常用 **“色号”** 来定义成熟度（1号全绿，7号全黄带黑斑）。根据你的销售周期，建议在采购单上直接注明：

| 销售场景 | 建议采购熟度 | 原因与要求 |
| :--- | :--- | :--- |
| **主打“当日熟”**（高流量店/果切店） | **3.5号 - 4号** | 果体微黄带绿，果柄仍绿。到店后常温放置1-2天即可全黄可售，损耗最低。 |
| **主打“次日卖”**（普通社区店） | **3号** | 整体偏绿，仅个别转黄。到店后需催熟2-3天，适合囤货，抗压能力强。 |
| **不允许** | **5号及以上** | 到货即全黄甚至带斑，当天卖不完，第二天必然发黑报废。**采购单上必须写死“拒收5号以上”。** |

**具体要求话术（直接发给供应商）：**
> “本次到货香蕉要求熟度**3.5号**，色卡标准，**指捏果柄有弹性但果身硬挺**。到货后若出现超过10%果身发软或已有黑点，将按损耗比例扣除货款。”

### 二、到货时间与排期要求

**核心原则：宁可“少量多次”，不要“一次囤足”。**

| 维度 | 具体要求 |
| :--- | :--- |
| **到货频率** | 如果日销量低于1箱（约13公斤），**要求每2天到货一次**，每次只进1-2箱。每周到货不超过3次。 |
| **到货时间段** | 必须**避开中午和傍晚客人高峰期**。最好要求在**早上6:00-8:00**之间到货，充分留出理货、挑选、催熟的时间。 |
| **到货缓冲期** | 合同中写明**“到货后72小时内免责”**——即到货后头3天内出现的非严重磕碰损伤（如果皮划伤），供应商应承担换货责任（损耗补偿）。 |
| **极端天气预案** | 夏季（超过30℃）或冬季（低于5℃）到货，必须要求供应商提供**冷藏运输车**，且到货后你方立即开箱散热10分钟再入库，防止“热捂”或“冻伤”。 |

### 三、最实际的损耗控制技巧（到货后你做）

采购要求只是第一道防线，到货后的操作决定损耗率：

1.  **立即开箱分拣**：到货后不要原箱堆放。把**全绿、微黄、全黄**分三个筐。全黄的直接上货架卖，微黄的放冷藏区（13℃左右）延缓成熟，全绿的放在通风处催熟。
2.  **悬挂存放**：香蕉不要平躺堆放，最好**挂起来**或竖放（果柄朝上），受压面积减少黑斑概率。
3.  **到货“翻包”检查**：每一箱香蕉拆开检查**上中下三层**，底层最容易闷坏。若发现底层已有出水软烂，应立即拍照索赔。

### 四、供应商合同中的“硬指标”条款

如果供应商经常违约，采购合同中应写明：
> - “到货香蕉成熟度超出合同范围（低于3号或高于5号），**整批货物可按原价60%结算**，供应商不得拒收。”
> - “连续2次出现熟度超标，终止合作关系。”

**最终建议一句话总结：** 给供应商最清晰的指令是“**4号以下，每两天一送，早上六点到货，黑点超10%拒收**”。用这个标准筛掉不配合的供应商，能直接减少三分之一的烂果损耗。
