生鲜电商水果到货后出现坏果，责任的划分通常取决于**发货责任**、**运输责任**和**签收责任**三个环节。一般遵循“**谁投诉谁举证，但平台通常先行赔付**”的规则。

以下是具体的责任划分框架，你可以根据实际情况对号入座：

**1. 发货方（商家/供应商）责任**
- **情形**：发货时水果本身带有暗伤、过度成熟、包装不防震（如直接裸露、纸箱过软导致挤压）。
- **责任**：**商家全责**。这是最常见的纠纷原因，因为水果在出库时已经存在瑕疵。
- **处理**：提供坏果照片，商家应按照平台规则进行**部分退款**（按坏果比例）或**全额退款**。

**2. 承运方（快递/同城配送）责任**
- **情形**：发货时完好，但运输途中因**暴力分拣、长时间滞留、高温/低温受损**（如冻伤、腐烂）导致到货坏果。
- **责任**：属于商家与物流之间的合同纠纷。**对顾客而言，商家需要先行赔付**，然后商家再向物流追偿，顾客无需直接联系快递索赔。
- **例外**：如果是顾客指定了特殊时效（如“隔天达”），且商家已按时发货，因快递延误导致的坏果，快递方需承担责任。

**3. 顾客（签收后）责任**
- **情形**：
  - **未及时签收**：快递放驿站/快递柜超过24小时未取，导致水果闷坏。
  - **未及时联络**：已收到货但未开箱检查，放置数天后才投诉。
  - **存放不当**：如将需冷藏的水果放在高温环境。
- **责任**：**顾客自担**。但若商家在详情页未明确标注“需冷藏”或“签收后24小时内反馈”，商家需承担部分责任。

**4. 平台/商家的特殊承诺责任**
- **特别提示**：很多生鲜平台或店铺有“**坏果包赔**”的承诺（如“坏一赔一”、“按比例赔付”）。只要在**承诺时效内**（通常为签收后6-24小时内）提交证据，**即使原因不明，平台也会直接赔付**，以换取售后快速关闭，此时不划分具体责任。

---

**如果你遇到此问题，建议按以下步骤行动（通用处理流程）：**

1.  **立即拍照取证**：将坏果与**快递单号/外包装**放在一起拍清晰照片（要能看清坏果数量）。
2.  **查看时效**：确认是否在商家承诺的售后时效内（通常在“我的订单”-“售后/申请退款”页面能看到）。
3.  **发起售后**：
    - 在平台点击“申请退款/仅退款”。
    - 理由选择“水果腐烂/变质”。
    - 上传照片，勾选快递签收日期。
4.  **若商家拒绝**：申请平台客服介入。平台通常会依据照片和物流信息直接判决退款，**无需费力自证属于哪方责任**。

---

**总结判定口诀：**
- **发货前坏** → 商家责任（全额/部分退款）。
- **路上坏** → 商家先行赔付，商家再找快递。
- **签收后放坏了** → 顾客责任（除非商家承诺“超时包赔”）。

**关键点**：只要不存在“顾客故意延迟领取”这一明显过错，**大多数平台会偏向支持顾客的赔款申请**，因为生鲜品类售后率极高，平台为保口碑通常会快速退款。
