大型超市水果供应商需要具备以下食品安全和物流能力，才能满足超市的合规要求、品质控制及供应链效率需求：

---

### 一、食品安全能力（核心合规要求）

1. **资质与体系认证**
   - 具备食品经营许可证、营业执照，并符合出口/进口检验检疫要求。
   - 通过 ISO 22000（食品安全管理体系）、HACCP（危害分析与关键控制点）或 GAP（良好农业规范）等认证。

2. **源头控制**
   - 有明确的水果种植基地或采购渠道，可追溯产地信息。
   - 定期对土壤、水源、农药残留、重金属进行检测，确保符合国家标准。

3. **仓储环境**
   - 配备温湿度可控的冷库或保鲜库，根据不同水果（如香蕉、苹果、草莓）设定适宜温度（0-15℃不等）。
   - 有防虫、防鼠、防霉变设施，并记录每日温湿度数据。

4. **包装与标识**
   - 使用食品级包装材料，避免二次污染。
   - 标签注明品名、产地、采摘日期、保质期、储存方式等信息。

5. **检验与留样**
   - 每批次提供农残检测报告（如GB/T 5009系列标准），并保留样品以备追溯。
   - 对分拣、打包环节制定卫生操作规范。

---

### 二、物流能力（保障鲜度和时效）

1. **冷链全链条**
   - 具备“采后预冷—冷藏运输—门店验收”全程温控能力，运输车辆需带实时温度记录仪。
   - 不同水果需分区运输（如热带水果与温带水果分开），避免乙烯催熟效应。

2. **分拣与配送效率**
   - 支持超市的“当日达”或“次日达”订单，配送准时率需≥95%。
   - 能灵活匹配超市的补货节奏（如早市、晚市），并应对促销活动的突发需求。

3. **库存周转与损耗控制**
   - 建立“先进先出”原则，对易腐烂水果（如荔枝、杨梅）采用小批量高频配送。
   - 库存周转天数控制在1-3天内，损耗率需低于行业平均水平（通常低于5%）。

4. **应急与追溯系统**
   - 在出现质量问题时，能72小时内完成问题批次产品的召回。
   - 拥有数字化系统（如WMS仓储管理系统、TMS运输管理系统）实时监测物流状态。

---

### 三、对超市合作的补充要求

- **数据对接**：与超市共享库存和销售数据，实现智能补货。
- **退货处理**：明确变质、挤压、破伤水果的退换货流程。
- **验货标准**：提供与超市一致的分级标准（如果径大小、甜度、瑕疵率）。

---

**总结**：供应商必须同时满足“可追溯、可控制、可追溯”的食品安全闭环，以及“快、准、稳”的冷链物流能力。若无法核验某项证书或数据，建议以超市的实际验收标准为准。
