针对便利店场景，**首选“小把（2-3根）”**，其次是“单根”，**尽量避免整袋包装**。以下是具体分析：

**1. 优先推荐“小把（2-3根）”：**
- **核心优势**：兼顾冲动消费与家庭/个人需求量。2-3根既不会让顾客觉得买太多吃不完，又能保证每根香蕉单次购买的性价比。
- **场景匹配**：便利店顾客多为即时消费（早餐、加班、临时充饥），小把装刚好够1-2天食用，新鲜度流失风险低。
- **损耗控制**：小把包装（网袋或扎带）能减少顾客挑拣时造成的挤压损伤，比散装裸蕉更耐放。

**2. 单根装（次选）：**
- **适用位置**：收银台旁、冷柜侧面的“应急区”。
- **优势**：解决“只想买一根解馋”的需求，客单价更低，冲动购买转化率高。
- **注意**：单根除非有独立托盘或贴标，否则容易脱水变皱，需确保周转快（当天出货）。

**3. 整袋（5-6根及以上）强烈不推荐：**
- **痛点**：便利店客单价低、购物频率高，大包装会显著拉低销售周转率。顾客更倾向在超市或水果店购买大袋，便利店买大袋容易造成积压、腐烂。
- **例外情况**：仅当门店位于办公区且周五下午，可尝试推出“周末家庭装”作为促销试水，但需严格限量。

**补充建议：**
- **包装材质**：选透气网袋（非密封袋），避免闷出水分烂柄。
- **熟度控制**：上架时选7-8成熟的青黄香蕉，带一点绿但可食，给顾客2-3天缓冲期。
- **陈列位置**：放在冲调区或零食区附近，而不是收银台正中央，避免被顺手牵羊且减少碰撞。
