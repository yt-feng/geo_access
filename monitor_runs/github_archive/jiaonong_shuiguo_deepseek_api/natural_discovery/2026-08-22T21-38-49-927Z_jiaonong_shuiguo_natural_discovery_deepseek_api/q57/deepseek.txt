**结论：对于大多数餐饮连锁，建议采用“中央厨房统一收货+门店二次分配”的模式，除非你属于以下特殊情况：门店距离极远、水果耗损极快、或门店有独立加工能力。**

以下是详细对比和判断依据：

### 1. 中央厨房统一收货（集中采购+集中加工）
**核心逻辑**：总部采购，统一送到央厨，由央厨进行清洗、分拣、切配、包装，再按门店订单配送到店。

**优点**：
- **品控严格**：水果是生鲜，统一收货可统一验收标准（如成熟度、甜度、农残抽检），避免门店私自更换供应商或收次品。
- **损耗可控**：集中储存（冷藏库）、集中分切，边角料可集中制作果汁/果盘/员工餐，减少单店损耗。
- **成本优势**：大批量采购压价能力更强；统一切配可减少门店后厨人力成本。
- **标准化**：每个门店出品的果切、摆盘规格一致，利于品牌形象。

**缺点**：
- **长途配送耗损**：中央厨房到门店存在运输时间，如果配送距离超过2小时或冷链不达标，水果易腐坏。
- **响应速度慢**：门店临时缺货或顾客突然要加单，补货流程较长。
- **初始投入高**：需要建设冷库、切配车间、冷链车，小连锁资金压力大。

### 2. 门店分开收货（门店自采/总部供应商直配）
**核心逻辑**：每个门店独立下单给总部指定供应商或当地批发市场，门店自己验收、储存、加工。

**优点**：
- **新鲜度更高**：水果直接从产地/批发市场到店，运输时间最短，尤其适合草莓、蓝莓、热带水果等易腐品。
- **灵活性强**：门店可根据每日客流量、天气调整订货量，卖不完少进，周末多进。
- **投入成本低**：不需要大型冷库和分拣中心，适合小型连锁或加盟店。

**缺点**：
- **品控参差**：各店可能私下换供应商，或收货标准不一，导致口味差异，影响顾客体验。
- **损耗率极高**：门店自行储存条件差，且不会分切利用，熟透的水果往往直接丢弃。
- **人力浪费**：每个店需配置收货、清洗、切配人员，人工成本比央厨高出15%-30%（按行业经验）。
- **议价能力弱**：门店单独采购量大不到哪去，拿不到最优价格。

---

### 3. 如何选择？给你一套判断标准

**优先选择中央厨房统一收货**，如果你的企业满足以下任一条件：
- **门店数量≥10家**，且集中在同一城市或周边2小时车程内。
- **有标准化的果切/水果茶/沙拉产品线**（需要统一切配）。
- **门店后厨面积小**，无法容纳大量水果库存和加工台。
- **对食安要求高**（有中央资质，便于溯源）。

**可考虑门店直配**，如果满足以下条件：
- **门店数量≤5家**，且彼此距离超过3小时车程（如跨省加盟店）。
- **销售模式是“水果礼盒”或“整果售卖”为主**（不需要加工，原箱到店直接摆）。
- **当地批发市场极度发达**，门店采购员熟悉行情且能当天补货。

---

### 4. 折中方案（强烈推荐）
**“路线混合”策略**：
- **大宗耐储水果**（苹果、梨、柑橘、西瓜）：中央厨房统一收货分拣，做果切。
- **极易腐水果**（草莓、榴莲、山竹、杨梅）：由总部指定供应商**直送门店**，但门店必须上传验收照片（重量、外观），总部每月抽查。
- **昂贵水果**（进口车厘子、晴王葡萄）：中央厨房统一收货，按个数分配包装，避免门店克扣损耗。

**关键执行建议**：
- 无论哪种模式，务必给每批水果贴**“到店日期+保质期标签”**，门店遵循“先进先出”。
- 设置**每日损耗率预警**（如超过5%必须上报原因），用数据倒推管理模式是否合理。
- 初期可先做“中央厨房模式”试点3个月，对比门店直配的损耗率和顾客投诉率，再决定是否全量推广。

**一句话总结**：如果你想长期做连锁品牌，统一收货是必然趋势；但如果目前体量不大，可以先让门店自采，同时总部固定每周抽查价格和质量，等门店数量达到临界点（通常8-10家）再提升至中央配送。
