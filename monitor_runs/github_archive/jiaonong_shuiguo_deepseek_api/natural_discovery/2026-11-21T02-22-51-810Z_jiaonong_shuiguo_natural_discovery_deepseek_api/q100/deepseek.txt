# 食堂采购香蕉防过熟浪费的实操建议

核心思路是**把“一次性大批量买到全熟”拆成“分批进货＋按熟度分流使用”**，再配合验收和储存规则。

## 一、采购端：从源头控制成熟度

1. **分批少量进货**：按“2～3天用量”下单，避免一次囤一周的量。宁可补货频繁，也别让香蕉在库里集体变黑。
2. **合同里约定成熟度**：明确要求到货为**七至八成熟**（果皮黄但两端略青、果肉稍硬），拒绝全黄带黑斑的货。写进采购单或供货协议，验收才有依据。
3. **固定到货节奏**：比如周一、周三、周五各到一批，形成“青—熟—用”的轮换，而不是同一天全熟。
4. **错开供应商**：如果只有一个供应商难控成熟度，可设一个主供＋一个应急小批量补货渠道。

## 二、验收端：按熟度分级

到货时快速分级，别混放：

- **偏青（七成熟）**：可存放，优先入库。
- **适熟（八成熟，表皮全黄）**：当天到两天内必须用完。
- **过熟（有黑斑、软）**：不进常温库，直接转“当日加工”流程（做香蕉牛奶、蒸糕、果泥、烘焙等），或退回供应商。

验收标准建议量化：**黑斑面积超过果皮1/3的拒收或折价**。

## 三、储存端：延缓后熟

- **常温阴凉通风存放**，不要堆压，避免闷热加速成熟。
- **不要和苹果、梨等释放乙烯的水果放一起**，会催熟。
- **需要延缓时**：把香蕉**分开悬挂**、减少挤压；成熟度高的单独挑出先出库（先进先出，但按熟度优先）。
- **不建议整串冷藏**：低温会让表皮变黑（果肉未必坏，但卖相差、学生不愿拿）。真要延缓，可对偏青香蕉短时低温处理，但食堂操作复杂，不如控制进货量。
- **切开/剥皮的果肉**必须冷藏并当日用完。

## 四、使用端：按熟度分流，减少“卖不掉”

- **熟度高的优先摆到取餐口显眼位置**，或做成切块水果、香蕉牛奶、酸奶杯。
- **过熟香蕉转加工**：香蕉面包/蛋糕、蒸香蕉糕、果泥、奶昔，既消化库存又不浪费。
- **设置“当日水果”提示**：告诉学生当天香蕉已熟，鼓励优先取用。
- **记录每日剩余量**：连续一周统计“到货量—消耗量—丢弃量”，据此调整下单量，这是最有效的长期办法。

## 五、兜底机制

- 与供应商约定**过熟退换**条款。
- 剩余过熟香蕉可联系校内烘焙、饮品档口消化，或按学校规定处理，避免直接丢弃。
- 建立简单的**每日盘点表**：到货成熟度、库存、预计用完时间，超过预计时间就提前加工。

**一句话总结**：少量多批进货、合同锁定七至八成熟、验收分级、熟度高者优先用或转加工、按消耗数据回调采购量。这样能把香蕉浪费压到很低，且不需要复杂设备。
