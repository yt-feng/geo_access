家庭场景优先考虑“好吃、耐放、分量不浪费、拿得出手”。建议组合按 **1个主果+2个辅果+1个点缀**，不要四种平均装。

**推荐组合（按家庭人数）**

1. **3—4口之家，日常家庭礼盒**
   - 苹果 4个 + 橙子 4个 + 香蕉 1把（约5—6根）+ 菠萝 1个
   - 适合：预算适中、颜色丰富、有仪式感。
   - 注意：香蕉容易催熟，和苹果分开装或加隔层，避免苹果乙烯让香蕉过快变软。

2. **2—3口之家，小家庭轻量盒**
   - 苹果 3个 + 橙子 4个 + 香蕉 1小把（4—5根）+ 菠萝 1个
   - 适合：不想剩太多，水果种类齐。

3. **5—6口之家或三代同堂**
   - 苹果 6个 + 橙子 6个 + 香蕉 1大把（8—10根）+ 菠萝 1个
   - 适合：消耗快、分享多。

**更建议的搭配比例**
- 苹果、橙子占体积约60%—70%，耐放且送礼稳妥；
- 香蕉占15%—20%，但别多，容易黑；
- 菠萝1个即可，起“礼盒感”和香气作用，多了占空间且处理麻烦。

**不太建议**
- 四种水果数量完全一样：香蕉和菠萝不耐放，家庭容易吃不完。
- 香蕉放太多：家庭礼盒最容易坏的就是香蕉。
- 菠萝选太大：礼盒显满但实际可食比例低，还压其他水果。

**装箱细节**
- 苹果、橙子放底层和四周，菠萝单独固定，香蕉放上层或侧袋；
- 苹果和香蕉最好物理隔开；
- 橙子选中等果，苹果选脆甜耐储品种；
- 礼盒里可放一张“食用顺序”小卡：先吃香蕉、菠萝，再吃橙子、苹果。

**结论**：家庭团购最稳妥的是 **苹果+橙子为主，香蕉少量，菠萝1个点缀**。按人数选“4+4+1把+1个”或“6+6+1把+1个”最不容易出错。
