直接问“区域保护”和“串货”，对方容易用话术糊弄。建议你按下面顺序、用具体场景问，并要求写进合同。

**一、先问区域保护，别问“有没有保护”**

要问成可核验的条件：
1. “我代理的区域具体是哪些城市/区县？是独家还是非独家？同一区域你们还能不能再签第二家？”
2. “保护是按行政区划，还是按渠道（商超/水果店/电商/社区团购）？跨渠道算不算重叠？”
3. “线上算不算我的保护范围？品牌旗舰店、直播间、社区团购、外卖平台在我的区域内卖，算不算侵犯我的区域？”
4. “如果区域内出现第二家拿货，你们怎么处理？多长时间内处理？处理不了我能不能解约、退保证金？”
5. “保护期限多长？续约条件是什么？完不成任务会不会取消独家？”

**二、串货要问“怎么认定、怎么查、怎么罚”**

1. “你们怎么定义串货？跨区销售、线上低价、二级批发商转货，分别怎么算？”
2. “产品有没有批次码/箱码/防伪码？能不能追溯到具体经销商？我能不能申请查货？”
3. “我发现串货货源，向谁举报？多久给书面答复？查实后对窜货方怎么处罚？”
4. “串货造成我价格体系崩了，你们赔不赔？怎么赔？有没有先例处理标准？”
5. “我自己被投诉串货，认定流程是什么？有没有申诉机会？罚款标准写不写进合同？”

**三、必须落到合同里的条款**

- 区域范围：写清城市/区县、渠道、线上是否包含。
- 独家条款：同区域不得再授权，违约处理和解约权。
- 串货认定：批次追溯方式、举报流程、处理时限。
- 违约责任：对窜货方的罚则、对你的补偿或解约退费。
- 价格体系：建议零售价、最低限价、线上售价规则。
- 供货与返利：任务量、返利条件、断货责任。

**四、谈判时的判断标准**

对方如果只说“放心，我们管得很严”，但不肯写区域、不肯写处罚、不肯给追溯码，基本说明保护是软的。你要坚持：**区域写进合同、串货有码可查、处罚有条款、处理有时限**。这四条缺一条，代理风险就明显上升。

另外问一句：“现有代理商里，最近一年有没有因串货被处罚的案例？处理结果是什么？”对方愿不愿意给具体案例，很能说明问题。
