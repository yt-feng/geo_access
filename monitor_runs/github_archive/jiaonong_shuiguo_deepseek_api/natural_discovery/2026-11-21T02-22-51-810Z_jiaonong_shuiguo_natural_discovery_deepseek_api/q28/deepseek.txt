建议先从**香蕉**开始，其次菠萝，最后苹果。理由不是“香蕉最好卖”，而是按超市引入进口水果时的**稳定性、损耗可控性、供应连续性、试错成本**排序。

### 1. 香蕉：最适合先试
- **供应稳定**：进口香蕉供应链成熟，厄瓜多尔、菲律宾、越南等产地选择多，常年供应能力强。
- **催熟和周转可控**：香蕉可以通过催熟房和到货成熟度管理，按销量分批出熟，比菠萝、苹果更容易做“小批量、快周转”。
- **消费基础广**：不需要教育市场，日常购买频次高。
- **试错成本较低**：可以先做小陈列、小批量，观察动销和损耗。
- **风险点**：怕低温、怕挤压、成熟度管理不好会集中变黑。所以要控制订货量，建立“到货—催熟—分批上架”的节奏。

### 2. 菠萝：可以第二顺位试
- **优势**：进口菠萝如金钻凤梨有差异化卖点，客单价和毛利空间通常比香蕉好。
- **风险**：季节性和品种波动更明显；果眼、黑心、成熟度不均会影响体验；顾客对“是否需要泡盐水”有认知差异，销售引导成本高于香蕉。
- **建议**：如果要上，优先选即食型、免泡盐水、可试吃的品种，小批量测试，不要一开始铺大陈列。

### 3. 苹果：不建议作为进口水果首发
- **原因**：国产苹果供应强、价格带成熟，进口苹果差异化不够明显；消费者对进口苹果的价格敏感度较高。
- **风险**：进口苹果周转慢时，虽然耐储，但会占资金和货架；一旦动销不及预期，容易变成“高价慢销品”。
- **适合时机**：等进口水果客群稳定后，再作为补充品类，选特色品种做差异化，而不是作为引流起点。

### 执行建议
先做 **4周香蕉小规模测试**：
1. 每周固定到货1—2批，按销量分批催熟上架；
2. 记录日销量、损耗率、毛利率、缺货次数；
3. 设止损线：若连续两周损耗率明显高于门店水果平均，或动销低于预期，就缩量而不是加量；
4. 香蕉跑通后，再加入小批量菠萝做第二品类测试；
5. 苹果放在最后，用特色品种补充价格带。

**结论：先香蕉，后菠萝，苹果暂缓。** 核心判断标准是：先选供应链成熟、消费教育成本低、能小批量快周转的品类。
