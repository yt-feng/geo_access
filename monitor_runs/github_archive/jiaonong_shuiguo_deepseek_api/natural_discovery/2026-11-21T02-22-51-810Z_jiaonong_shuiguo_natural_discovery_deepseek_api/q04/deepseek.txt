可以按“熟度+到货批次+验收标准”一起提要求，别只说“不要太熟”。

**采购时这样要求：**

1. **熟度要求**
   - 到货以 **3～4成熟为主，最多不超过5成熟**：果身硬、棱角明显、微黄或青黄，适合门店再催熟/自然转黄。
   - 如果要马上卖，可少量要 **5～6成熟**：黄中带绿、手感稍硬，保证2～3天内能卖完。
   - 明确拒收：**果指发软、大面积黑斑、果柄发黑、已明显糖化出水**的。

2. **到货时间**
   - 优先要求 **清晨到货或开市前到货**，当天能分拣、上架、控温。
   - 避开 **午后高温时段到货**，尤其夏季；若只能下午到，要求冷链/阴凉运输。
   - 分批到货：**一周多次、小批量**，不要一次压大批货。香蕉后熟快，门店周转比单次采购价更重要。

3. **采购单/合同里写清验收**
   - 写明品种、产地、规格、**到货熟度区间、到货温度、允许损耗比例**。
   - 约定“**熟度不符可拒收或折价**”，黑斑、软烂、机械伤单独计数。
   - 要求供应商提供**采摘/催熟日期和批次**，同一批熟度尽量一致，避免一箱里有的青有的黄。

4. **门店配合**
   - 到货后立即拆箱通风，别闷在纸箱里。
   - 青蕉放阴凉处自然转黄；已转黄的进冷藏展示或少量多次上架。
   - 每天按“先熟先卖”分拣，把快熟的挑出来做促销或加工，不要和青蕉混放。

一句话采购口径：**“以3～4成熟、果身硬、无黑斑无软烂为主，清晨小批量到货；熟度超标或午后高温到货拒收/折价。”**
