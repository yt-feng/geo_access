优先看成熟度，价格排第二。原因和可执行判断如下：

**1. 先明确用途再定成熟度**
- **做香蕉蛋糕/香蕉磅蛋糕/马芬**：最适合的是**表皮大面积出现黑斑、果肉软但没流汁**的香蕉。这时淀粉转糖充分，香气足、甜度高，配方里糖可以略减，成品风味明显更好。
- **完全发黑、果肉水化、有酒味或酸味**：不要用于烘焙，容易带异味、发酵过头。
- **全青或刚转黄、手感硬**：香气弱、甜度低，烤出来香蕉味淡，还可能发涩，不适合直接做蛋糕。

**2. 价格只在“同成熟度档位”里比较**
- 同一成熟度下，当然选单价低、损耗小的。
- 不要因为便宜买青蕉再等熟：催熟需要时间、空间和损耗管理；烘焙店每天要出品，青蕉占用后熟周期，反而增加库存和报废风险。若确实要囤，必须能控温催熟并排产。

**3. 采购时的可判断标准**
- **看**：表皮黑斑面积约30%–60%、无霉点、无破损流汁。
- **摸**：整根略软、有弹性，不是一捏就烂。
- **闻**：有明显香蕉甜香，无酒味、酸味。
- **切**：果肉乳白到微黄、无黑心、无过多水化。
- **算**：按“可食果肉出成率”比价，而不是只比带皮单价；黑斑蕉去皮损耗可能更高，要折算到每公斤果肉成本。

**结论**：**成熟度优先，价格其次。** 正确做法是按产品需求锁定成熟度档位，再在该档位内比价和比出成率；青蕉便宜但会拖慢出品、增加损耗，不适合作为常规蛋糕用蕉的首选。
