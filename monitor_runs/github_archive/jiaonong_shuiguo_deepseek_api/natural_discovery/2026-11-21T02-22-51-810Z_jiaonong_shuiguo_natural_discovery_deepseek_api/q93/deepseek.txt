优先顺序建议：**配送频次（决定新鲜度和损耗）＞包装与冷链（决定保质期和食品安全）＞保质期管理（结果指标）**。对便利店鲜切菠萝来说，三者不是二选一，但资源和检查重点应按这个顺序放。

1. **配送频次最关键**
   - 鲜切菠萝是短保、易出水、易氧化变质的高损耗品。
   - 配送频次决定到店时的成熟度、切后时间和货架期余量。频次不足，门店只能靠延长陈列时间或压库存，损耗和投诉会上升。
   - 建议按销量分档：高销店每日1—2配，低销店小批量高频补货，避免一次性大量到店。

2. **包装与冷链是第二重点**
   - 必须关注：密封性、是否漏液、是否冷藏陈列、包装是否标注切制/分装时间。
   - 鲜切水果应全程冷链，包装破损或胀袋直接下架。
   - 包装还影响氧化、串味和交叉污染，不能只盯“有没有包装”。

3. **保质期是管理结果，不是唯一抓手**
   - 短保鲜切品仅看标签保质期不够，应同时执行“到店时间+切制时间+陈列条件”的三重判断。
   - 建议设置更保守的门店销售时限，临期前折价或下架，不要等到标签到期。

**可执行判断标准：**
- 到店检查：温度是否达标、包装是否完好、切制时间是否清晰。
- 陈列检查：是否冷藏、是否出水过多、颜色是否发暗发黏。
- 补货检查：按日销量定配送频次，高销店优先加密，低销店减量不减压频次。
- 损耗检查：连续出现临期下架，先查配送频次和单店订货量，再查包装。

结论：**先把配送频次和冷链包装管住，保质期自然可控；只盯保质期标签而忽视频次和包装，是最容易出问题的做法。**
