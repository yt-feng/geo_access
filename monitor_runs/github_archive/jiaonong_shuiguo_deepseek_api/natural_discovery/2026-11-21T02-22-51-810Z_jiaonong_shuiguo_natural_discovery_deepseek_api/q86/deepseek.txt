生鲜平台做水果一件代发，供应商至少要具备以下仓配能力。判断时建议按“能不能稳定履约”而不是只看报价。

## 一、仓储能力
1. **水果专用仓储条件**
   - 常温、冷藏、冷冻分区；苹果梨等常温，蓝莓草莓樱桃等冷藏，冻果独立冷冻。
   - 具备温湿度监控和记录，能按SKU设定存储温度。
   - 有防虫防鼠、通风、防潮、防挤压措施。

2. **库存管理与批次追溯**
   - WMS系统能对接平台订单，支持批次号/采摘日期/入库日期管理。
   - 先进先出，临期和损耗预警。
   - 能提供每日可售库存，避免超卖。

3. **分拣打包能力**
   - 按单拣货、称重、贴单、装袋/装箱。
   - 具备水果防护包装：网套、气泡膜、吸水纸、冰袋、保温箱等，按品类配置。
   - 能处理多SKU合并订单和赠品。

4. **预冷与分级能力（重要）**
   - 产地或仓内预冷能力，尤其是浆果、樱桃、荔枝等易腐水果。
   - 按果径、糖度、外观分级，能稳定输出商品规格。

## 二、配送履约能力
1. **快递合作与时效**
   - 有稳定合作的快递/冷链快递，能覆盖平台主要销售区域。
   - 能承诺发货时效：如16点前订单当日发，次日达/隔日达范围明确。
   - 具备异常件处理：破损、延误、拒收、退换货拦截。

2. **冷链能力**
   - 冷藏水果能用泡沫箱+冰袋/冷链车，夏季有温控方案。
   - 能说明不同季节、不同线路的温控方案和破损率。

3. **面单与系统对接**
   - 支持电子面单、平台ERP/OMS对接，订单自动下发。
   - 支持物流轨迹回传、发货回传、库存同步。
   - 有API或至少批量导入导出能力。

## 三、售后与逆向能力
- 能按平台规则处理坏果、少件、破损的补发/退款。
- 有售后响应时效，比如24小时内响应。
- 能提供坏果照片审核、理赔标准和月度对账。
- 支持退货拦截和二次销售判断。

## 四、建议平台重点核验的指标
- **发货及时率**：承诺时效内发货比例。
- **破损率/坏果率**：按品类看历史数据。
- **库存准确率**：系统库存与实物差异。
- **冷链覆盖范围**：哪些区域能发、时效多久。
- **日峰值处理能力**：大促时一天能发多少单。
- **系统对接方式**：API还是手工，是否支持自动回传。
- **售后赔付标准**：坏果怎么赔、谁承担。

## 五、合同里建议写清楚
- 发货时效和截单时间；
- 温控与包装标准；
- 坏果率上限及赔付；
- 库存同步频率；
- 大促备货和产能保障；
- 系统对接责任；
- 逆向物流和退货处理。

简单说：**水果一件代发供应商的核心不是“有仓库”，而是“有温控仓储+预冷分级+按单打包+稳定快递+系统对接+售后赔付”这一整条链。** 平台筛选时优先看浆果/易腐品类的历史履约数据，再谈价格。
