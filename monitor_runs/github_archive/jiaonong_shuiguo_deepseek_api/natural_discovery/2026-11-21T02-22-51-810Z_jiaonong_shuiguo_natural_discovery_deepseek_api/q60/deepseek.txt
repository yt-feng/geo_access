核心思路：**把“补货”从口头承诺变成有触发条件、有时限、有替代方案的合同条款**，让门店在水果不合格时能快速拿到可用货，而不用停售或临时高价采购。

### 一、约定“不合格”的判定标准（先解决扯皮）
- 按品种写清验收标准：单果重量/规格、成熟度、糖度（如可测）、色泽、软硬度、破损率、腐烂率、异味。
- 量化拒收线：例如“同批次腐烂/压伤比例超过5%可整批拒收；单项不合格超过10%可要求换货”。
- 验收时限：到货后30–60分钟内完成验收并拍照留证，超时视为合格（避免事后争议）。
- 留样与照片：每批留样24小时，不合格品拍照/视频，作为补货依据。

### 二、补货条款要写“时限+方式+费用”
1. **补货时限**：明确“验收不合格通知发出后，供应商须在X小时内补送到店”。鲜果建议：本地供应商4–6小时；跨城供应商次日营业前到店。写清起算点（以微信/邮件/系统通知时间为准）。
2. **补货方式**：优先“同品同规格补送”；无法补送时，允许“等价替代品种”或“按合格比例补差”，由门店选择。
3. **费用承担**：不合格品的退换运费、补货运输费由供应商承担；因补货不及时导致门店临时采购的差价，约定由供应商承担或从货款中扣减。
4. **不影响营业的兜底**：约定“若供应商未在时限内补货，门店有权自行就近采购，差价及合理费用由供应商承担/从当月货款扣除”。这是最关键的一条。

### 三、结算与违约挂钩
- 不合格批次不计入当月采购量，不参与返点。
- 设置补货及时率考核：如月度补货及时率低于95%，扣减货款或降低供货比例。
- 连续两次或月度三次补货超时，门店有权单方减少订单量或终止合作。
- 质量保证金/账期扣款：从当月货款中预留一定比例作为质量保证金，验收合格后释放。

### 四、操作流程固化（避免执行走样）
- 下单时注明“到货时间窗口”和“验收联系人”。
- 不合格时统一走“拍照→填验收单→微信/系统通知→供应商确认→补货→二次验收”流程。
- 补货到店后重新验收，仍不合格则触发兜底采购条款。
- 每周对账时核对补货记录，避免口头承诺无法追溯。

### 五、给门店的谈判话术
“我们不是要压价，是要保证营业不断货。补货时限和自行采购兜底写进去，对双方都清楚：你按时补，我们不乱扣；你补不了，我们有权自救，费用按实际算。”

**建议落成一张《水果验收与补货补充协议》**，附在采购合同后，写清：验收标准表、补货时限表（按品种）、通知方式、费用承担、兜底采购权、扣款规则。这样遇到不合格时，店长按条款执行即可，不需要临时请示，也不影响正常营业。
