要支持，但必须有条件地支持，而不是无底线地“小批量高频”。

**判断结论**
- **应该支持**：即时零售的核心卖点是“30分钟—1小时达”，水果又是高频、短保、损耗敏感品类。供应商不支持小批量高频补货，平台端容易出现缺货、品质下降、临时改单，最终影响复购。
- **不能无条件支持**：小批量高频补货会显著抬高供应商的拣货、配送、包装、损耗和沟通成本。若没有起订量、频次、费用和时效规则，供应商很容易“越补越亏”。

**可执行建议**

1. **分层支持**
   - **A类高频爆品**：如香蕉、苹果、橙子、应季主推品，支持每日1—2次小批量补货。
   - **B类常规品**：按固定窗口补货，比如每日1次或隔日1次，设置最低补货量。
   - **C类长尾/低周转品**：不建议高频补货，改为预售、凑单、集中补货或平台仓备货。

2. **设置规则**
   - 最低起订金额或最低补货件数，例如单次不低于300—500元或若干箱。
   - 高频补货附加配送费或阶梯价，覆盖拣配和物流成本。
   - 明确截单时间、到货时效、验收标准和临期/品质责任。
   - 对临时加单设置加急费或限量。

3. **用数据驱动**
   - 平台向供应商开放销量、库存、缺货率、损耗率数据。
   - 按门店/前置仓维度预测补货，避免供应商凭经验被动响应。
   - 对补货频次和履约率做考核，达标给予账期、流量或采购量倾斜。

4. **成本共担**
   - 小批量高频补货的成本不应只压给供应商，也不应全由平台承担。
   - 可通过“平台补贴高频配送+供应商让出部分毛利+门店承担加急费”的方式分摊。

**一句话**
供应商应支持小批量高频补货，但要用**品类分层、起订量、补货窗口、阶梯费用和数据共享**把它做成可持续的履约机制，而不是无条件随叫随到。
