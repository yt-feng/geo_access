给公司下午茶批量买水果，选供应商时重点不是“水果最好”，而是**稳定、准时、能处理售后、适合分食**。可以按下面标准筛：

**1. 先定采购规则**
- **人数和预算**：按人均 300–500g 估算，另加 10%–15% 余量。
- **配送时间**：明确到“下午 2:30 前送到前台”，不要只写“下午送达”。
- **分食方式**：优先选易分装、不脏手、不需现场切的水果，如圣女果、葡萄、橘子、香蕉、冬枣、蓝莓、切盒西瓜；少选榴莲、菠萝蜜、完整菠萝、大量需要削皮的。
- **结算方式**：优先支持对公转账、开票、月结或到货验收后付款。

**2. 供应商类型怎么选**
- **本地水果批发商/配送商**：适合 50 人以上、每周固定采购。价格和品类有优势，但要确认是否配送到楼层、是否免费分装。
- **生鲜电商企业购**：适合 20–50 人、频次低。流程规范、发票方便，缺点是价格略高、高峰期配送不稳。
- **附近水果店/连锁店**：适合小批量、临时补货。响应快，但大批量分装和准时性较弱。
- **中央厨房/团餐供应商**：适合同时有下午茶餐食需求的。能一站式配送，但水果品类可能不精。

**3. 必须核验的 6 项**
- **准时率**：问“近一个月企业订单迟到率”，要求写进订单备注；首次合作先小单试配。
- **分装能力**：能否按部门/人数分袋或分盒，是否加收分装费。
- **品质标准**：明确坏果率上限，比如到货坏果超过 5% 补送或退款；拍照即可售后。
- **食品安全**：切盒水果要有冷藏配送和当天制作承诺；整果要看新鲜度、无霉变。
- **报价口径**：确认是否含配送费、分装费、上楼费、税点，避免低价引流后加价。
- **应急能力**：临时加 10–20 份能否 2 小时内补送。

**4. 建议的筛选流程**
1. 找 3 家：1 家本地批发配送、1 家生鲜企业购、1 家附近水果店。
2. 同一份清单询价：例如圣女果、香蕉、橘子、葡萄、蓝莓，写明人数、送达时间、分装要求。
3. 首次各下小单试配，重点看：是否准时、坏果多少、分装是否干净、售后是否爽快。
4. 选 1 家主供 + 1 家备供，签简单月度框架：价格随行就市但提前报价，坏果率超标扣款或补送。

**5. 避坑**
- 不要只看单价低，问清配送、分装、税点后的总价。
- 不要首次就下大单，先试配。
- 不要选需要现场加工的水果，下午茶场景容易乱。
- 不要接受“坏果少量正常”这种模糊说法，提前定坏果率。

一句话：**优先选本地能准时送到楼层、支持分装、售后爽快、能开票的供应商；用“小单试配 + 主备供应商”控制风险。**
