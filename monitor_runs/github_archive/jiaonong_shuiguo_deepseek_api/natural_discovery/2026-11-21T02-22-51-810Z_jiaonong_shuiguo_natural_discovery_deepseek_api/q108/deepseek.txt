核实“全国配送”不能只听口头承诺，建议采购方按“证据—测试—合同”三层验证，重点看实际可达范围和时效，而不是只看能否发货。

**1. 先要可核验的配送能力证据**
- 要求供应商提供近1—3个月的真实配送记录：目的地城市/区县、订单量、签收时效、破损/拒收率。可抽样回访收货方或看物流面单，不接受只给截图汇总。
- 要其合作物流商清单及账号类型（快递、冷链零担、专线、落地配），说明哪些区域走快递、哪些走冷链、哪些需中转。
- 问清“全国”具体定义：是覆盖全部地级市，还是仅市县主城区；偏远地区、乡镇、海岛、高原是否加价或不到。
- 水果属生鲜，重点核验冷链能力：冷库位置、预冷设备、冷链车/保温箱、温控记录、中转仓分布。

**2. 用真实订单做小批量测试**
- 选3—5个有代表性的目的地：近端、远端、乡镇、偏远省份，各下小批量真实订单。
- 记录下单到签收时长、到货温度、损耗率、包装完整度、物流轨迹是否可查。
- 测试“异常场景”：改地址、拒收、延迟、破损理赔，看响应速度和赔付态度。
- 不要只测一线城市，那最容易覆盖；问题通常出在二三线城市和乡镇。

**3. 查主体与履约资质**
- 核对营业执照经营范围、食品经营/生产许可（如涉及分装）、冷链运输相关资质。
- 查企业信用信息、涉诉记录、经营异常；若是中间商，追问实际发货仓和承运方。
- 要求提供至少2—3个可联系的长期采购客户作为参考，并独立回访。

**4. 把“覆盖能力”写进合同**
- 明确配送范围清单：哪些省市区县可达、哪些不到、哪些加价；附目的地时效表。
- 约定时效和损耗标准：如签收超时、腐烂率超阈值如何扣款/补发/赔偿。
- 约定物流轨迹可查、温控记录随货或可调取、异常响应时限。
- 设置试运行期和小批量履约保证金，达标后再放量。

**判断标准**：能提供可抽样回访的真实记录、愿意接受多区域小单测试、合同里敢写清不到达区域和赔付标准，才算实际覆盖能力可信；只强调“都能发”、拿不出分区域时效和冷链证据的，通常只是转包物流，风险较高。
