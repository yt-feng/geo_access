线上水果最怕“开箱坏果”和“口感忽好忽坏”。核心不是采购时“挑得更仔细”，而是把**验收标准、供应商分级、批次留样、到货抽检和售后归因**做成固定动作。可按下面执行：

**1. 先定可验收的采购标准，不写“新鲜”“甜”**
- 按品类写清：品种/产地/规格（单果克重或直径）、成熟度（几成熟采摘）、糖度下限或区间、酸度、软硬、果面缺陷允许比例、箱内坏果率上限。
- 例：坏果率≤2%、碰伤/裂口≤3%、糖度抽检均值≥某值且单果不低于某值；达不到就拒收或降级。
- 不同季节、不同产地分别设标准，不能全年一套。

**2. 供应商分级，别只比价**
- 新供应商先小批量试单，连续3-5批看坏果率、口感投诉率、到货温差和包装破损。
- 供应商档案记录：批次号、采摘/发货日期、运输方式、到货抽检结果、售后原因。
- 设A/B/C级：A级稳定供货，B级限品类/限季节，C级只做促销或淘汰。采购价不是唯一指标，要算“坏果+退款+差评”的综合成本。

**3. 到货抽检按批次做，别凭手感**
- 每批随机抽检，覆盖箱体上中下层，记录坏果、软果、裂果、异味、大小不均、糖度（有条件的用糖度计）。
- 拍照留证，异常批次立即隔离，不混入好货发货。
- 抽检结果当天反馈供应商，形成批次质量分。

**4. 控制成熟度和运输，减少“到货坏”**
- 线上销售按配送时长倒推采摘成熟度：远距离发七八成熟，同城可稍熟；高呼吸跃变型水果要预冷、控温、透气包装。
- 要求供应商采摘后快速预冷，运输避免暴晒和挤压；箱内加缓冲、分层，不超装。
- 夏季/雨季缩短在库时间，先进先出，不做长库存。

**5. 用“留样+售后归因”找出真正问题**
- 每批留样，记录到货、发货、签收时间。
- 售后按原因分类：运输碰伤、成熟度不足、过熟腐烂、口感酸淡、大小不符、包装挤压。
- 连续看数据：某供应商某品类坏果率高，就换供应商或改成熟度；某线路破损高，就改包装/物流；某季节口感差，就调整产地或下架。

**6. 采购合同里写清责任**
- 明确验收标准、抽检比例、坏果率超标处理（补货/扣款/退货）、口感投诉的判定和赔付。
- 要求供应商提供采摘日期、批次、农残检测等必要信息；不虚构检测，但要把可提供的凭证写进流程。

**最优先做的三件事：**  
① 给销量前5的水果各写一张“可验收标准卡”；② 每批到货抽检并拍照留档；③ 把售后原因按批次归因，连续两周就能看出该换供应商、改成熟度还是改包装。这样比单纯“采购时挑好货”更能稳定坏果率和口感。
