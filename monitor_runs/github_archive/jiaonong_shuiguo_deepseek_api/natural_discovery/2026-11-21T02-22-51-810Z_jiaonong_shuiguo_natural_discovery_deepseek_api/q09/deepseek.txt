旺季谈水果供应，核心不是“多进点货”，而是把**断货风险、品质波动、价格波动、赔付责任**提前锁进约定。和供应商谈时，建议按下面几组问题逐项问清，并尽量落到书面或微信可留痕的确认里。

**一、先问保供能力**
1. 旺季你每天/每周能稳定给我供多少量？最低保供量是多少？
2. 你自有货源还是靠调货？主要产地/批发市场是哪里？
3. 遇到产地减产、天气、节假日爆单，你的优先保供顺序怎么排？我在什么级别？
4. 有没有备用货源？备用货源品质和价格差多少？
5. 旺季最长提前多久下单？临时加单最晚几点前确认、能加多少？

**二、问品质和验收标准**
6. 每个品类按什么等级、规格、糖度、单果重、成熟度供货？
7. 允许的坏果率/损耗率是多少？超出怎么赔、怎么补？
8. 到货后发现烂果、压伤、熟度不够，多长时间内可反馈？谁承担退换货运费？
9. 是否支持我抽检、拍照留证、按实际合格数量结算？
10. 旺季品质会不会降级？如果降级，价格是否同步调整？

**三、问价格和锁价机制**
11. 报价是含税含运费到店价，还是市场价随行就市？
12. 旺季能不能锁价？锁多久？锁价对应保供量是多少？
13. 如果市场价下跌，我的拿货价能不能跟着下调？如果上涨，涨幅上限怎么定？
14. 起订量、阶梯价、运费、装卸费、包装费分别怎么算？
15. 促销爆款能不能单独申请特价和优先供货？

**四、问配送和时效**
16. 每天几点前下单、几点到店？能否固定配送时段？
17. 临时补货最快多久到？加急配送加不加钱？
18. 配送途中损耗谁承担？缺斤少两怎么核？
19. 节假日和雨天是否照常配送？不能送时提前多久通知？

**五、问结算和违约**
20. 账期怎么定？现结、周结还是月结？旺季是否要预付？
21. 断货、迟送、品质不达标，具体怎么赔？是按缺货金额赔，还是补货+补偿？
22. 我临时取消订单有没有违约金？比例多少？
23. 合作期限怎么定？旺季结束后价格和账期怎么恢复？

**六、谈的时候要拿到的落地材料**
- 让对方发一份**可供货品类、规格、日保供量、价格、账期**清单；
- 把口头承诺改成微信文字确认，至少写明：保供量、锁价期、坏果赔付、断货赔付、配送时效；
- 先小批量试单3—7天，重点看**到货准时率、坏果率、临时加单响应**；
- 不要只压一家，旺季至少备一家主供、一家备用，备用哪怕量小也要保持合作。

最该盯死的三条是：**最低保供量、断货赔付、坏果赔付**。这三条没写清，价格谈得再低，旺季也可能白忙。
