节假日水果需求暴增，锁货源的关键不是“临时加单”，而是提前把**量、价、品质、到货时间**四件事用合同和预案固定下来。可按下面执行：

1. **提前做需求预测，按品类分层锁货**
   - 用过去2—3年同期销售数据，叠加今年节假日天数、促销计划、天气和社区团购/线上订单增量，做日销量预测。
   - 把水果分三类：  
     - **必保爆品**（礼盒果、进口果、节令果）：提前30—60天锁量锁价；  
     - **高频走量品**（苹果、橙子、香蕉、梨）：提前15—30天签框架协议，约定最低供货量和浮动价格机制；  
     - **易损短保品**（草莓、葡萄、车厘子等）：提前7—15天锁定产地或一级批发商，按日分批到货，避免一次性压货。

2. **多源锁货，不把鸡蛋放一个篮子**
   - 每个核心单品至少准备**2—3个供应商**：主供应商保量、备选供应商补缺口。
   - 产地直采+区域批发市场+连锁供应商组合使用，避免单一产地因天气、交通、节日用工短缺断供。
   - 对进口果提前确认船期、报关和冷链仓库存，预留7—10天缓冲。

3. **用合同把关键条款写死**
   - 明确：供货量及上浮比例、锁价期限、质量标准、到货时间窗、冷链温度、破损率、违约赔偿和缺货替代方案。
   - 价格不要只签死价，可采用“基础价+节日浮动上限”，防止供应商节前毁约转卖高价。
   - 约定“优先供货权”和“缺口补货响应时间”，例如缺货24小时内补足。

4. **提前打款和备库存，换优先权**
   - 对核心供应商提前支付部分定金或预付款，换取节日期间优先发货权。
   - 自建或租用冷链仓，节前7—10天对耐储水果建立安全库存；易损水果采用“少量多次”到货。
   - 与物流方提前锁车辆和司机，节假日运力紧张往往比货源更先出问题。

5. **建立日监控和应急机制**
   - 节前两周起每日监控：到货量、库存周转、售价、损耗、供应商履约率。
   - 设置库存红线：核心单品安全库存=日均销量×节假日天数×1.2—1.5。
   - 准备替代清单：某单品缺货时，用同价位、同用途水果替代，并同步调整陈列和促销。

6. **门店端配合控需求**
   - 对爆品做限量预售、团购预订和礼盒预定，用订单反推采购量。
   - 节假日中后期减少易损品订货，避免“前面抢货、后面损耗”。

一句话执行顺序：**先用历史数据算出节日销量，再按品类提前30—60天签锁量锁价合同，核心单品备2—3个供应商，提前打款锁运力，节前建安全库存，节中每日盯履约和损耗。**
