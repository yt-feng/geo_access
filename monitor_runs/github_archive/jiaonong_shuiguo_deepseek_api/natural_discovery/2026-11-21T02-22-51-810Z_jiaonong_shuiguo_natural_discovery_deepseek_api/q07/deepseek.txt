做水果礼盒，关键不是“把四种水果都塞进去”，而是按价位和送礼场景做2—3个清晰档次。苹果、橙子、香蕉、菠萝这四样成本透明、辨识度高，适合走“看得懂、拿得出手、不压货”的路线。

**建议主推这3款：**

1. **日常走量款（39—59元）**
   - 苹果4个 + 橙子4个 + 香蕉1把（约1斤）
   - 定位：自己吃、探病、顺手带。
   - 卖点：苹果橙子耐放，香蕉当天吃，搭配自然。
   - 不建议放菠萝：日常款加菠萝会抬高成本，且菠萝外观占空间、成熟度难控。

2. **中档送礼款（69—99元，主推）**
   - 苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个
   - 定位：走亲访友、节日小礼。
   - 卖点：四色齐全，礼盒看起来满；菠萝做视觉中心。
   - 注意：菠萝选小果或中果，别选大果，否则盒子显空或成本失控；苹果选红富士等颜色正的，橙子选表皮亮的，香蕉选七成熟，避免到家就黑。

3. **高档组合款（109—139元）**
   - 苹果6个 + 橙子6个 + 香蕉1把 + 菠萝1个，盒子加大，加丝带/贺卡
   - 定位：节日、商务小礼、看望长辈。
   - 卖点：数量足、颜色喜庆，苹果橙子寓意好。
   - 不建议做过高价位：这四样水果撑不起太高端，超过150元顾客会对比车厘子、阳光玫瑰等，反而不好卖。

**搭配原则：**
- **苹果、橙子做主体**：耐放、颜色正、寓意好，占礼盒60%—70%。
- **香蕉做补充**：便宜、显量，但成熟度难控，别放太多，1把即可；夏天减少香蕉比例，或用独立小袋装。
- **菠萝做视觉点**：一盒一个就够，选小果，提前问顾客是否要削皮；不削皮更耐放、更好看。
- **颜色搭配**：红苹果+橙橙子+黄香蕉+绿/黄菠萝，盒内垫纸隔开，避免香蕉被压。

**好卖的细节：**
- 明码标价，分“自吃款/送礼款”，别让顾客自己猜。
- 礼盒上贴标签：品种、数量、建议食用顺序（先香蕉后菠萝再苹果橙子）。
- 提供“可替换”：香蕉可换同价橙子，菠萝可换2个苹果，减少售后。
- 节日做预售，按订单进货，香蕉和菠萝少备货，苹果橙子可多备。
- 拍照时盒子要满，空隙用拉菲草或纸丝填，不要用泡沫显廉价。

**避坑：**
- 香蕉和苹果不要紧挨着放，苹果释放乙烯会催熟香蕉。
- 菠萝不削皮更耐运输，但要在标签上写清楚。
- 别做“四样各一个”的小盒，显得空且不划算，不如做两样加量。
- 先小批量试3天，看哪款动销快，再调整水果数量和盒型。
