三者不是同一优先级，建议排序为：**食品安全 > 配送准时 > 价格**。原因是企业食堂属于集中供餐，水果一旦出现农残、霉变、来源不明或交叉污染，影响面大、追责成本高；配送不准时会打乱食堂备餐和库存周转；价格重要，但应在满足前两项底线后优化。

可执行判断标准：

1. **食品安全（一票否决）**
   - 供应商资质、检验报告、进货票据可追溯。
   - 到货抽检：霉变、破损、异味、农残快速检测或批次报告。
   - 冷链/常温运输条件、分拣卫生、是否与生鲜肉禽混装。
   - 合同写明不合格退换、批次追溯和赔偿责任。

2. **配送准时（硬约束）**
   - 明确到货时间窗，如早餐/午餐前固定时段。
   - 约定迟到处理：临时补货、扣款、连续迟到淘汰。
   - 评估供应商仓储距离、旺季运力和异常天气预案。

3. **价格（优化项）**
   - 不比单次最低价，比“合格品质下的稳定单价”。
   - 用周/月报价、季节性水果替代、阶梯采购量控成本。
   - 警惕明显低价，可能对应尾货、品质波动或短斤少两。

**结论：** 先设食品安全准入线，再设配送准时考核线，最后在合格供应商中比价。若必须只选一个最需要关注的，选**食品安全**。
