判断哪个规格更容易出货，建议批发商按“地域消费习惯+渠道用途+价格带+损耗表现”交叉看，不要只看单个规格的进货价或历史销量。

具体可按下面几步执行：

1. **先分渠道看规格偏好**
   - **农贸/水果摊**：更偏好中等规格、果形匀称、熟度可调的货，便于按个卖或按斤卖。
   - **商超**：偏好规格稳定、外观整齐的货，强调大小一致、货架期。
   - **餐饮/果汁/果切/甜品店**：更看重出肉率、酸甜度、稳定供应，大果或加工型果往往更受欢迎。
   - **社区团购/电商**：常看单果重量是否适合家庭一次消费，特大果反而可能难动销。

2. **做“同周期小批量试销”**
   - 每次只上2—3个规格，同一天、同渠道、同价格策略下试销3—7天。
   - 记录：到货量、日均出货量、售罄天数、退货/损耗率、客户复购询问。
   - 最容易出货的规格，应该是“售罄天数短 + 损耗低 + 价格不需要明显让利”的那个，而不是单看卖得最多。

3. **算“实际出货效率”**
   用两个指标判断：
   - **日均出货率 = 某规格日均出货量 ÷ 该规格到货量**
   - **损耗后毛利 = 销售额 − 进货成本 − 损耗报废金额 − 人工/运费分摊**
   
   有的规格卖得快但损耗高、要降价，实际不如中等规格稳定赚钱。

4. **看价格带和替代关系**
   - 如果大果和中等果价差过大，客户会转向更容易接受的规格。
   - 如果小果单价低但出肉少，餐饮客户可能不选；家庭客户则可能因为一次吃不完而不选特大果。
   - 观察客户问价后实际拿货的规格，比听口头偏好更准。

5. **关注季节和熟度**
   - 气温高时，大果、熟果动销快但损耗风险高；气温低时中等果更稳。
   - 同一规格不同熟度出货速度也不同，应把“规格+熟度”一起测试，不要只按重量分级。

6. **快速判断规则**
   - 连续3天某规格**出货率最高、损耗最低、不需要额外特价**，就优先加大该规格。
   - 某规格**问得多、拿得少**，通常说明价格或单果大小不匹配，可调包装、拆箱或换渠道。
   - 某规格**只有特价才动**，说明不是自然好出货，应控制进货量。

最实用的做法是：选2—3个主推规格做一周小批量对比，按渠道分别记录出货率和损耗，再决定主推规格和备货比例。不要凭“大果好卖”或“小果便宜”一概而论。
