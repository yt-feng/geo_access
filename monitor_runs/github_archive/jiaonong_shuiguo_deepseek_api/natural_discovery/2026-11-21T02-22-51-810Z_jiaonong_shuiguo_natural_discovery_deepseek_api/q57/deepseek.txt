多数餐饮连锁更适合“中央厨房统一收货（或至少统一下单+区域集货仓收货），门店只做少量应急直采”。但要看品类和规模，不能一刀切。

**判断原则**
- 水果标准化程度高、可冷藏、用量稳定、供应商可集中配送：优先中央厨房/区域仓统一收货。
- 水果易损、成熟度要求高、门店现场验收要求强、配送半径大：可“统一下单、区域分仓收货、门店验收”，而不是每店各自找供应商。
- 门店分散且单店量小：分散收货会导致价格、品质、账期、食安追溯都失控，不建议长期采用。

**统一收货的优势**
1. **采购议价强**：集中量换价格和账期，减少门店各自加价。
2. **品质标准统一**：可设糖度、规格、成熟度、损耗率标准，中央厨房统一验收。
3. **食安可追溯**：供应商资质、检测报告、批次记录集中管理。
4. **减少门店作弊和损耗争议**：避免门店私采、虚报损耗。
5. **配送计划可控**：按门店订单分拣配送，减少门店库存和压货。

**统一收货的风险**
1. **二次搬运增加损耗**：水果怕压怕碰，中央厨房分拣再配送会多一次损伤。
2. **成熟度难统一**：香蕉、牛油果、草莓等后熟/易损品，中央厨房收得太生或太熟都影响门店。
3. **配送时效要求高**：冷链断链或延迟会放大损耗。
4. **中央厨房能力不足时反而添乱**：没有冷藏分拣区、品控人员、WMS/订货系统，统一收货会变成“集中压货”。

**门店分开收货的优势**
- 门店现场看货，成熟度、外观、损耗当场判断。
- 短半径配送，减少二次搬运。
- 应急补货灵活。

**门店分开收货的劣势**
- 价格不统一、供应商难管理、品质波动大。
- 食安追溯弱，门店私采难控。
- 财务对账、损耗核算复杂。
- 单店采购量小，议价能力弱。

**推荐落地模式**
1. **统一下单、统一供应商、统一价格**：门店在系统报量，总部集中下单。
2. **区域集货仓/中央厨房收货为主**：适合苹果、橙子、西瓜、哈密瓜等耐储水果。
3. **易损后熟水果设“区域分仓+门店验收”**：如草莓、蓝莓、香蕉、牛油果，由区域仓按成熟度分拨，门店只做到货验收。
4. **门店保留少量应急直采权限**：设金额/品类上限，必须报备、留凭证、纳入供应商名录。
5. **建立验收标准**：规格、糖度、成熟度、破损率、到货温度、批次检测报告。
6. **算总成本**：比较“采购价+损耗+配送+人工+食安风险”，不要只看进货价。

**结论**
- 5家以内小店：可门店收货为主，总部统一下单和比价。
- 10家以上或有中央厨房：优先中央厨房/区域仓统一收货。
- 水果易损品类：用“区域分仓收货+门店验收”折中，不建议纯门店分散采购。
