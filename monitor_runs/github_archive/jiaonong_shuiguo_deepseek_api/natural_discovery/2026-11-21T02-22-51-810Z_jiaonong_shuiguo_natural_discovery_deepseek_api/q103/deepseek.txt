结论：**按斤结算最容易管住成本和数量，最适合作为主结算方式；按箱结算适合高周转、标准包装的单品作补充；按份结算只适合终端售卖或固定套餐，不适合食堂采购主流程。**

理由和判断标准：

1. **按斤结算：最推荐作为主方式**
   - 优点：验收可复秤，数量、单价、金额可核对；损耗和短斤少两容易发现；便于比价和成本核算。
   - 风险：称重、登记工作量大；水果规格不一时需要定验收标准。
   - 管理要点：
     - 每次到货必须双人验收、当场复秤并签字；
     - 采购单写清品种、等级、单价、估重/实重；
     - 月度用“入库斤数—出库斤数—损耗斤数”对账。

2. **按箱结算：适合标准箱、周转快的单品作补充**
   - 优点：收货快、单据简单，适合苹果、橙子等规格稳定的箱装水果。
   - 风险：箱内大小、净重、坏果率不透明时容易吃亏；只写“箱”不写净重最难管理。
   - 管理要点：
     - 合同必须写明“箱规+净重下限+坏果率上限”；
     - 首次合作抽箱复秤，后续定期抽查；
     - 按“箱价折合每斤价”与按斤报价比较。

3. **按份结算：不建议用于采购入库**
   - 优点：分发简单，适合按人配餐、果切或固定标准份。
   - 风险：份量标准模糊，采购端难比价，容易把管理成本转成隐性成本。
   - 适用场景：只用于最终发放/售卖环节，或明确每份克重、品种、包装后的果切配送。

**建议的组合方案：**
- 主采购：**按斤结算**；
- 规格稳定的箱装单品：**按箱结算，但合同折算净重和单价**；
- 食堂窗口或套餐发放：内部**按份管理**，不改变采购按斤/按箱结算。

一句话：**采购端按斤为主、按箱为辅并折算净重；发放端才按份。**
