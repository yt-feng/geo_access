判断“大小规格是否适合门店销售”，核心不是只看单个大小，而是看**顾客接受度、陈列稳定性、损耗和价格带是否匹配**。可按下面执行。

## 1. 先定门店定位对应的规格带
不要问“苹果多大算好”，要问“我的顾客买苹果/橙子偏向哪种消费场景”。

- **社区生鲜/便利店**：偏中小规格、单价低、家庭随手买。苹果单果约 **160–220g**，橙子约 **150–220g** 较常见。
- **标准超市/大卖场**：规格可覆盖中到大果，苹果 **180–260g**，橙子 **180–260g**，但必须分档陈列。
- **精品/水果专营**：更看外观、糖度、整齐度，大果可做礼盒，散卖仍要中等果为主。
- **团购/食堂/餐饮渠道**：更看单果稳定、出成率，规格可以偏大，但必须大小一致。

**判断原则：同一陈列区内，单果重量差异尽量控制在 ±15% 以内**。超过这个范围，顾客会挑大弃小，造成小果剩货和损耗。

## 2. 现场抽样测量，不凭目测
到货或采购前做抽样：

1. 随机抽 **30–50 个**，不要只拿上层。
2. 逐个称单果重，记录最小、最大、平均、中位数。
3. 量横径：苹果看最大横径，橙子看赤道直径。
4. 同时看**整齐度**：一箱里最大和最小差多少，是否有明显大小混装。

可执行标准：
- 苹果：散卖主力果横径约 **70–80mm**，单果 **180–220g** 较稳；低于 160g 适合做特价/小家庭装，高于 260g 要单独定价或礼盒。
- 橙子：散卖主力果横径约 **65–75mm**，单果 **180–230g** 较稳；低于 150g 做促销装，高于 260g 单独分档。
- 以上是常见零售参考，最终以门店历史销售数据为准。

## 3. 看陈列和拿取体验
规格适不适合，要到货架上判断：

- **能否稳定堆叠**：苹果太圆太大易滚落，橙子大小不一会塌堆。
- **顾客单手能否拿取**：过大不适合社区日常购买，过小显得廉价。
- **包装是否匹配**：网袋装、托盘装、礼盒装的格位是否放得下。
- **称重是否方便**：散卖时单果重量差异大，顾客会反复挑拣，增加损耗和称重排队。

**建议：散卖区只放一个主力规格，另设“小果特价”和“大果精品”两个独立价格带。** 不要把大小果混在一个堆头里。

## 4. 用损耗和毛利反推是否适合
采购规格要算账，不只看进价：

- 小果进价低但顾客接受度差，容易剩货；
- 大果卖相好但单价高，社区店动销可能慢；
- 大小混装看似便宜，实际挑拣损耗高。

可执行判断：
- 若某规格到店后 **挑拣损耗超过 8%–10%**，说明整齐度不够或规格与客群不匹配。
- 若同一价格带下，顾客频繁翻拣、留下小果，说明主力规格偏小或混装严重。
- 若大果需要降价才能清货，说明该规格超出本店价格接受带。

## 5. 采购前的快速决策表
| 判断项 | 适合门店销售 | 不适合或需调整 |
|---|---|---|
| 单果重量差异 | 同档 ±15% 内 | 大小混装明显 |
| 横径整齐度 | 目测基本一致 | 一箱内差 2–3 个等级 |
| 陈列 | 堆叠稳定、单手可取 | 易滚落、塌堆 |
| 价格带 | 与门店主力客群匹配 | 大果单价明显超出客流消费 |
| 损耗 | 挑拣损耗低 | 顾客挑大留小严重 |
| 包装 | 与网袋/托盘/礼盒匹配 | 装不进或空隙大 |

## 6. 最稳妥的做法
先小批量试销 **3–7 天**，记录：
- 日均销量；
- 挑拣损耗；
- 顾客询问/投诉；
- 同价格带竞品规格；
- 清货折扣幅度。

**试销后保留“动销最快、损耗最低、毛利可接受”的 1–2 个规格作为主力**，其余规格做特价或礼盒，不要长期混卖。
