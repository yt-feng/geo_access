判断水果供应商靠不靠谱，核心看“稳定性、损耗、账期、售后”四件事。你可以按下面这套可执行清单去筛：

1. **先小单试供，不直接签长期**
   - 连续试供2—4周，每次少量进货。
   - 重点记录：到货时间是否准时、香蕉成熟度是否一致、菠萝烂果/黑心比例、单箱重量是否足。
   - 香蕉看：同批青度是否均匀、催熟后是否掉把、是否容易发黑。
   - 菠萝看：果形是否正、叶冠新鲜度、底部有无霉斑、切开黑心比例。

2. **看货源和季节应对能力**
   - 问清楚香蕉主要来自哪里、菠萝主要来自哪里，是否固定产区还是到处调货。
   - 靠谱供应商会主动说明产季波动、天气影响、替代货源。
   - 不靠谱的常见表现：什么都能保证、价格永远最低、缺货才临时通知。

3. **看分级和损耗承诺**
   - 让供应商明确：香蕉按什么规格分级、菠萝按几头/斤重分级。
   - 问清楚坏果怎么赔：是拍照报损、下次补货，还是按比例扣款。
   - 最好写进长期供货约定：到货24小时内验货，烂果/黑心果按比例赔付。

4. **看价格是否透明**
   - 不要只比单价，要比“到店可售成本”：单价+运费+损耗+催熟费用。
   - 要求报价含等级、产地、包装重量、是否含税运。
   - 长期合作可以谈阶梯价，但别一开始只压价，压到最低往往会在等级和损耗上找回来。

5. **看账期和资金压力**
   - 新供应商建议先现结或短账期，稳定后再谈账期。
   - 账期不是越长越好，关键看对方是否接受“质量问题扣款”。
   - 如果对方要求大额预付、长期压货，要谨慎。

6. **看售后响应**
   - 故意在试供期反馈一次质量问题，看对方多久回复、是否推诿。
   - 靠谱的会给出补货、换货或扣款方案；不靠谱的会说“水果都这样”。

7. **看履约稳定性**
   - 连续问几次临时加单、改单，看对方能否协调。
   - 节假日、雨天、产季末是否还能稳定供货，这是长期合作的关键。

**建议你做一个简单评分表**：准时率、等级合格率、损耗率、售后响应、价格透明度、账期配合，每项1—5分。试供一个月后，低于4分的不要签长期。

最后提醒：香蕉和菠萝都是损耗敏感品，长期供应商最重要的不是“最便宜”，而是“每次到货都差不多、出了问题有人认”。先小单验证，再逐步放量，比听任何承诺都可靠。
