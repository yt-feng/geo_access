结论：**多数甜品店用“鲜果切配”总损耗不一定更低，关键看销量和周转；如果菠萝用量不大、切配后不能当天/次日用完，直接买成品果丁通常损耗更低。** 如果菠萝用量大且稳定、能当天切当天用完，鲜果切配更容易把损耗压低。

可以按这几项判断：

1. **鲜果切配的隐性损耗更高**
   - 菠萝鲜果有去皮、去眼、去芯损耗，通常可食率大概六到七成，具体看品种和成熟度。
   - 成熟度不好控制：太生酸、太熟易出水变质。
   - 切配后氧化、出水、串味，冷藏保质期短。
   - 人工切配时间和卫生管理成本也要算进去。

2. **成品果丁的损耗低在“可控”**
   - 按需进货、开袋即用，减少切配废料和人工。
   - 但要注意：包装规格是否匹配单日用量；开袋后没用完同样会坏；供货批次质量不稳定也会造成报废。
   - 成品果丁单价通常更高，损耗低不等于成本低。

3. **决策标准**
   - **日用量大且稳定、能当天切完**：选鲜果切配，损耗和成本通常更优。
   - **日用量小、品类多、切配后常剩**：选成品果丁，损耗更可控。
   - **处于中间**：可鲜果切配为主，成品果丁作为应急补货；或按“每周用量÷包装规格”算开袋报废率再定。

4. **实际核算方法**
   用同一周记录两组数据：
   - 鲜果：采购重量、去皮去芯后净重、报废重量、人工分钟数。
   - 成品：到货重量、开袋未用完报废重量、退货/质量问题重量。
   比较“**每公斤可用果丁的综合成本 =（采购金额+人工分摊+报废金额）÷实际可用重量**”。这个指标比单纯看损耗率更可靠。

所以，**不要只问哪个损耗低，要问“以你店里的日用量和周转速度，哪个综合损耗和综合成本更低”。** 用量小选成品果丁更稳；用量大且周转快选鲜果切配更划算。
