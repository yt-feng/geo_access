先给判断：**香蕉优先稳定供应商，苹果优先本地批发；如果只能二选一，香蕉走稳定供应商，苹果走本地批发并保留一个备选供应商。** 社区超市客群固定、单店销量不大，关键不是“哪边绝对便宜”，而是**损耗、稳定性和补货频率**。

### 为什么这样选

**香蕉：更适合稳定供应商**
- 香蕉后熟快、损耗高，最怕批次不一致和断货。
- 社区店通常每天或隔天补货，稳定供应商能保证成熟度、送货频次和售后。
- 香蕉毛利薄，价格波动大，但稳定性比单次低价更重要。
- 适合找能按“青果/微熟/可售”分级供货、可调换次品的供应商。

**苹果：更适合本地批发**
- 苹果相对耐储，损耗低于香蕉，可以一次多进几个品种。
- 本地批发市场适合看货、比价、挑等级和试销新品种。
- 社区店苹果销量取决于品相和价格，本地批发更容易灵活调整。
- 但不要只靠临时批发，建议固定1个本地档口，避免旺季拿不到好货。

### 可执行方案

1. **香蕉：签稳定供应商**
   - 要求每周至少2到3次送货，支持次品调换。
   - 先小批量试2周，记录到货成熟度、损耗率、断货次数。
   - 合同或口头约定：到货过青或过熟可退换，送货时间固定。

2. **苹果：本地批发为主，稳定供应商兜底**
   - 先在本地批发市场选2到3个档口比价，固定1个主档口。
   - 试销2到3个品种，按“销量、损耗、毛利”每周淘汰。
   - 同时保留1个稳定供应商作为缺货时的备选，不必签长期量。

3. **用数据决定是否调整**
   - 连续2周记录：到货损耗率、缺货次数、售罄天数、毛利率。
   - 香蕉损耗率超过8%到10%，或一周断货2次，就换供应商。
   - 苹果本地批发价比稳定供应商低10%以上且损耗可控，就继续本地批发。

### 不建议的做法
- 香蕉和苹果都只找最低价临时批发，社区店经不起断货和品质波动。
- 香蕉一次性大量进货，后熟期短，容易集中损耗。
- 苹果只签稳定供应商但从不比价，社区店对价格敏感，容易失去竞争力。

**结论：香蕉以稳定供应商为主，苹果以本地批发为主并保留稳定供应商备选；试销2周后按损耗率和缺货次数做取舍。**
