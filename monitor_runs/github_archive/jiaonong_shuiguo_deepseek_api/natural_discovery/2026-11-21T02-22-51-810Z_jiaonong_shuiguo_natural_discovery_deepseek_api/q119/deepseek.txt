水果生意想长期稳定，选供应商时最容易忽视的往往不是价格和品类，而是下面这些“平时不出事、一出事就断货或烂货”的细节：

1. **产地与货源稳定性**
   别只看供应商说有货，要问清楚：是自有基地、长期合作基地，还是临时调货？主供品类在淡季、雨季、节假日前后的替代货源在哪。只靠一个市场档口调货的供应商，价格一波动就容易掉链子。

2. **分级标准是否统一**
   同样叫“一级果”，不同供应商的果径、糖度、瑕疵率、成熟度可能差很多。长期合作前要明确：按什么标准分级、允许的次果率是多少、大小是否均匀。最好留样品或书面标准，避免每次靠口头“差不多”。

3. **采后处理与冷链能力**
   水果损耗大头在采后。要关注供应商是否有预冷、分级包装、冷藏运输能力，还是采摘后直接装车。尤其浆果、叶菜类、热带水果，冷链断链一次就可能整批货软烂。

4. **到货损耗的责任边界**
   很多合作初期不谈清楚：运输损耗谁承担、到货后几小时内反馈有效、烂果是按比例扣款还是补货。建议明确验收时限、抽检方式、理赔标准，别等出问题再扯皮。

5. **供货弹性与应急能力**
   节假日、天气异常、产地减产时，供应商能不能临时加量或换规格？有没有备用产地或合作档口？长期稳定不是永远不出问题，而是出问题时对方有预案。

6. **账期与资金压力**
   低价往往伴随紧账期或押金要求。要评估供应商是否依赖你的预付款周转；过度压账期可能换来短期低价，但供应商资金一紧，优先供货的就不是你。

7. **食品安全与农残检测**
   长期做生意要留检测报告或批次记录，尤其是直接面向消费者、商超或团购渠道。不要只看“看起来新鲜”，要问是否有产地证明、农残检测、追溯批次。

8. **包装与物流适配**
   包装是否适合你的销售场景：散卖、礼盒、电商快递还是门店陈列。包装不当会增加磕碰损耗，也会影响卖相和人工分拣成本。

9. **沟通响应与决策链条**
   对接人能不能拍板？出现问题多久响应？是老板直接管还是业务员层层转达？长期合作中，响应速度比单次报价更重要。

10. **历史合作口碑与违约记录**
    不要只看对方规模。可以问同行、看其合作客户类型，关注是否有临时涨价、以次充好、拖延补损的记录。

**可执行建议：** 先小批量试单 2—3 次，覆盖不同季节或不同品类；每次记录到货损耗率、分级达标率、响应时间；把分级标准、验收时限、损耗赔付写进简单合作条款。长期稳定供应商的核心不是“最便宜”，而是**标准稳定、损耗可控、出问题能兜底**。
