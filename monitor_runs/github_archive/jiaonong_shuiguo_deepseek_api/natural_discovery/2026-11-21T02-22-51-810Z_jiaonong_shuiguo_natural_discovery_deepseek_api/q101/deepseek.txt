和水果供应商谈酒店早餐合作，重点是把“稳定”落到可执行的条款上，而不只是口头承诺。建议围绕下面几项谈：

1. **先定品类和规格**
   - 明确早餐常用水果清单：如苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等，分“常备”和“轮换”两类。
   - 写清规格：单果重量范围、成熟度、甜度、外观瑕疵允许比例、是否预切/去皮、包装规格。
   - 早餐场景优先选耐放、易分切、损耗低的品种，少用易软烂、成熟窗口窄的水果。

2. **供应稳定性要写进合同**
   - 约定每日/每周送货频次、最晚下单时间、送达时间窗。
   - 要求供应商给出替代方案：某品种缺货时，提前多久通知、用什么同价位品种替代。
   - 设置最低供货保障和缺货违约责任，避免早餐断档。
   - 对节假日、雨季、产地换季等提前确认保供安排。

3. **质量验收标准要可操作**
   - 到货验收：数量、重量、外观、成熟度、异味、腐烂率。
   - 约定拒收和换货规则：如腐烂/破损超过约定比例，整批拒收或按比例扣款。
   - 预切水果要重点约定冷链温度、切配时间、保质期和微生物指标。

4. **价格和调价机制**
   - 不要只谈单价，要谈含税、含运费、含损耗后的综合成本。
   - 水果价格波动大，可约定每周或每半月按市场价联动，但设涨跌幅上限和提前通知期。
   - 明确临时加单、紧急补货是否加价。

5. **食品安全资质**
   - 核验营业执照、食品经营许可、检测报告、产地证明。
   - 预切水果供应商需有冷链配送能力，明确运输温度记录。
   - 合同里写清食品安全责任和出问题后的召回、赔偿机制。

6. **结算和账期**
   - 明确对账周期、发票类型、账期天数。
   - 设置质量保证金或首月观察期，稳定后再放宽账期。

7. **试供和退出机制**
   - 先试供2—4周，按到货准时率、合格率、缺货次数评估。
   - 合同里约定连续几次不合格可终止合作，且不影响酒店紧急找替代供应商。

谈判时建议带一张表：品类、规格、日需求量、送货时间、验收标准、缺货处理、价格机制，逐项确认。这样谈出来的合作才可执行、可考核。
