超市采购水果时，通常要把“供应商资质、进货凭证、质量合格证明、检疫证明”分开看。你要向供应商索要的材料一般包括：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按经营性质）
   - 若是农产品生产者或合作社，提供相关登记或产地证明

2. **进货证明**
   - 进货发票、送货单、购销合同或订单
   - 供货清单：品名、产地、数量、批次、日期
   - 供应商盖章的供货证明或承诺书

3. **质量合格证明**
   - 农产品质量安全承诺达标合格证（常见于蔬菜水果）
   - 产地证明或检测合格报告
   - 供应商自检报告或委托第三方检测报告
   - 检测项目通常关注：农药残留、重金属等；可按批次或定期提供

4. **检疫证明**
   - 一般国产新鲜水果通常不需要动物检疫证明
   - 若涉及进口水果，需要海关/出入境检验检疫相关证明、报关单等
   - 若地方监管有特定要求，按当地规定执行

5. **批次追溯材料**
   - 每批水果的产地、采摘/包装日期、批次号
   - 冷链运输记录（如适用）
   - 不合格品召回和处置记录

实操建议：让供应商首次合作时提供资质证照和近期检测报告；每批进货随货提供送货单、合格证或承诺达标合格证；对高风险品种或新供应商，要求批批检测或定期第三方检测。具体清单以当地市场监管部门要求和超市自身进货查验制度为准。
