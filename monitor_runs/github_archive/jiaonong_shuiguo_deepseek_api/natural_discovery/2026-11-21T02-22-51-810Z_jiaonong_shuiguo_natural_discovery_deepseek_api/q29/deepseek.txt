超市和水果供应商常见的账期要分两种情况看，因为“水果”内部差异很大：

**1. 普通水果（苹果、橙子、梨、西瓜等耐储水果）**
- 常见账期：**30～60天**
- 连锁商超、区域超市较常见 **45～60天**；小型超市或现金压力大的门店多为 **15～30天**
- 生鲜品类中，水果通常比叶菜、肉类略长，但比包装食品短

**2. 鲜切水果、浆果、荔枝、樱桃等易损耗/短保水果**
- 常见账期：**7～15天**，部分为 **现结或周结**
- 因为损耗高、货架期短，供应商通常不愿给长账期

**行业实操参考：**
- 大型连锁商超对水果供应商常见 **月结30天、月结45天、月结60天**
- 中小超市、社区生鲜店更常见 **半月结、月结30天**
- 新供应商首单常见 **现结或7～15天**，合作稳定后再延长

**谈判建议：**
- 首次合作优先争取 **15～30天**，给双方留缓冲
- 稳定供货后可谈 **30～45天**，超过60天对水果供应商资金压力较大
- 账期要和**损耗承担、退换货规则、结算起算日（收货日还是对账日）**一起谈，否则名义账期短、实际回款可能更长

一句话总结：**耐储水果30～60天较常见，短保水果7～15天较常见；中小超市偏短，大型连锁偏长。**
