优先看**切果损耗**，其次外观，再是大小，甜度最后看。

理由很简单：超市卖菠萝不是自己吃，核心是**毛利和周转**。

1. **切果损耗最该关注**
   - 菠萝有冠芽、果皮、果眼，损耗天然高。
   - 同样进价，出肉率高、切后卖相好的货，实际毛利差很多。
   - 建议按批次记录：去皮后净重/毛重、坏果率、当天切果报废量。这个指标最能决定赚不赚钱。

2. **外观第二**
   - 外观直接影响顾客拿取率和切果卖相。
   - 看果形端正、果眼浅、无裂口、无软烂黑斑、冠芽新鲜。
   - 但外观不能压过损耗：特别大特别漂亮的菠萝，如果果眼深、出肉率低，也未必划算。

3. **大小第三**
   - 大小影响定价和场景：整果促销走量、切果盒装走便利。
   - 不要一味追大果，过大可能果眼深、纤维粗、切盒份数不经济；中小果有时周转更快。

4. **甜度最后看**
   - 甜度重要，但超市现场很难稳定无损检测，顾客也更依赖外观和试吃。
   - 甜度可以作为选品批次标准，但不建议作为第一决策指标；除非你做高端切果或试吃转化。

**可执行建议：**
- 进货先定标准：果形端正、无软烂、果眼浅、冠芽绿。
- 每批抽3-5个做切果测试，记录出肉率和报废率。
- 损耗高的批次改整果促销，损耗低的批次做切果盒。
- 甜度用试吃台和批次抽检辅助，不作为唯一采购依据。

一句话：**超市卖菠萝，先算切果损耗，再看外观，大小服务场景，甜度辅助选品。**
