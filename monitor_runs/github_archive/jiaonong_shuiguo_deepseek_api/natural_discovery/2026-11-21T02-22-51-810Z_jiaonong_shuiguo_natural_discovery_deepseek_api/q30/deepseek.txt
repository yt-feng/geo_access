超市水果到货发现品相不好，售后流程建议在采购合同或供货协议里提前约定成“可执行的动作”，而不是只写“保证质量”。可以按下面几个环节约定：

1. **验收标准和时限**
   - 明确“品相不好”的具体判定：腐烂、碰伤、裂果、畸形、色泽不符、大小不均、成熟度不符、包装破损等。
   - 约定到货后验收时限，例如收货后2小时内完成外观抽检，24小时内完成开箱/内部品质抽检。
   - 明确抽检比例和判定规则，例如按批次随机抽检5%—10%，不合格率超过约定比例即整批可退换。

2. **取证要求**
   - 收货方应在发现问题的第一时间拍照/录像，保留到货时间、批次、包装标签、开箱过程、问题部位。
   - 双方可约定通过微信群、邮件或系统上传证据，作为售后依据。
   - 易腐水果应约定“先保全证据，再协商处理”，避免因等待导致腐坏扩大、责任不清。

3. **通知与响应时限**
   - 收货方在验收时限内发出书面异议通知，说明批次、数量、问题类型和诉求。
   - 供货方应在约定时间内响应，例如2小时内确认，24小时内给出处理方案。
   - 逾期未响应可视为认可收货方提出的售后诉求。

4. **售后处理方式**
   - 优先约定分级处理：轻微品相问题折价接收；严重问题换货；无法换货或影响销售的打折、退货、补货。
   - 明确退换货的运输、装卸、冷藏费用由谁承担；通常质量问题由供货方承担。
   - 约定退款或补货完成时限，例如确认后48小时内补货、3个工作日内退款。

5. **责任边界和例外**
   - 区分“到货即有问题”和“收货后因储存不当造成的问题”。约定收货后的储存条件、温度要求及责任转移节点。
   - 明确自然损耗率，例如叶菜、浆果类允许一定比例的自然损耗，超出部分按售后处理。
   - 对特价果、处理果、尾货可单独约定“不退不换”或“仅限折价”，但必须醒目确认。

6. **违约与结算挂钩**
   - 约定售后未处理完毕前，对应批次货款可暂缓结算。
   - 对多次出现品相问题的供货方设置扣款、降级、暂停供货或终止合作条款。
   - 保留书面记录，按月汇总售后率，作为供应商考核依据。

建议把上述内容做成一张《水果到货验收与售后确认单》，每次到货签字确认，避免口头扯皮。核心是：**标准写清楚、时限卡住、证据留全、处理方式分级、费用和责任落到文字上。**
