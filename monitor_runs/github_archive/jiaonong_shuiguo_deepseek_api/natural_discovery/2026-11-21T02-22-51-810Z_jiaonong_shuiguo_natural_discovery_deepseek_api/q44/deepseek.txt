判断商超水果供应商的售后响应，不要只听口头承诺，建议用“可验证动作 + 合同条款 + 试单数据”三层来筛。

**1. 先做可验证的响应测试**

- 在正式合作前，用真实问题测试：发一条售后需求（如“到货有压伤/催熟不均”），记录对方首次回复时间、给出处理方案时间、实际补货或赔付时间。
- 至少测试2次，且选不同时段（工作日白天、晚间或周末），看是否稳定。
- 要求对方提供最近3个月的售后记录样例：报损率、补货时效、赔付方式、异常原因分类。不能提供或只给“口头保证”的，直接降级。

**2. 看其售后机制是否具体**

重点问清并写进合同/订单附件：

- 响应时限：如到货异常2小时内响应、24小时内给方案。
- 补货/换货时限：如48小时内补到，缺货时如何替代。
- 赔付标准：按重量、按金额、按批次，坏果率超过多少触发赔付。
- 责任边界：运输损耗、催熟损耗、门店存储损耗分别谁承担。
- 对接人机制：是否有固定售后对接人、备用联系人、升级路径。
- 香蕉和菠萝分开约定：香蕉催熟和运输易损，菠萝看黑心、烂心、机械伤，验收标准和赔付触发条件要分品类写。

**3. 用试单和旁证验证稳定性**

- 先小批量试单2—4周，记录每次异常从反馈到闭环的天数，要求稳定在约定时限内。
- 向同行或同区域商超采购打听其售后口碑，重点问“出问题时是否拖、是否推责”。
- 看其是否有冷链/催熟能力、固定车队或稳定第三方物流；售后响应往往依赖其履约体系，不只是客服态度。
- 观察业务员流动率：对接人频繁更换的供应商，售后连续性通常差。

**4. 合同里加“可执行罚则”**

- 约定响应超时、补货超时、赔付拖延的违约金或扣款比例。
- 约定连续两次售后不达标可暂停供货或终止合作。
- 保留售后沟通记录（微信、邮件、工单），作为月度考核依据。

**简单判断标准：** 敢让你做真实售后测试、能提供历史售后数据、合同里愿意写时限和赔付、试单期间闭环稳定的供应商，售后响应才相对可靠。只承诺“有问题随时找我”但不愿写条款、不愿试单的，不建议作为主供应商。
