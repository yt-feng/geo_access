核心思路：**把“压价”改成“压可核算的成本项”，用分级、账期、量和损耗分担换价格，而不是单纯砍单价。** 直接砍单价最容易逼供应商降规格、混级、以次充好。

可执行做法：

1. **先拆成本再谈价**
   - 要求供应商报：产地收购价、包装费、损耗率、运费、账期资金成本。
   - 你重点谈的是“损耗率”和“包装/物流”，不是只盯果价。比如同样单价，损耗从8%降到4%，实际成本就降了约4%。

2. **用分级采购代替一味压价**
   - 明确分级标准：大小、糖度、外观、允许瑕疵比例。
   - 畅销品要A级，促销/果切/员工餐可用B级，但合同写清等级和验收标准。这样价格降了，品质不被偷换。

3. **以量换价，但设阶梯和保底**
   - 给阶梯价：月采购量达标返点或下调单价；未达标恢复原价。
   - 不要轻易承诺“包销”，否则品质议价权会下降。

4. **谈账期换价格**
   - 现结/短账期通常能换2%—5%的价格空间；若你现金流允许，可先谈“现结折扣”，比硬压单价有效且不伤品质。

5. **损耗共担写进合同**
   - 到货验收标准、坏果率上限、超标扣款或补货。
   - 例如：坏果率≤3%按原价结算，3%—5%按比例扣款，>5%拒收或补货。这样供应商不敢用次果充好。

6. **用竞标/比价保持压力**
   - 同一品类找2—3家供应商，按周或按月比价，但不要频繁换，避免供应商不愿投入好货。
   - 报价要求“同规格同等级”对比，防止低价低质。

7. **谈返利和费用分担，而不是只砍单价**
   - 年度返点、促销支持、陈列费、配送费分担、包装箱回收。
   - 这些不直接降低果品规格，但能降低综合成本。

8. **关键话术**
   - “单价可以按你的来，但损耗率和账期我们要重新算。”
   - “同样的钱，我要的是稳定到货等级，不是最低报价。”
   - “你报三个等级的价格，我按销量分配，不用一个价混着供。”

**判断标准：** 谈完价格后，连续2—3周到货的糖度、大小、坏果率是否稳定；若单价降了但损耗率上升、退货率上升，实际成本没降，反而影响口碑。优先谈“综合到货成本”，不要只谈“采购单价”。
