选规格的核心不是“越大越划算”，而是按**出成率、损耗、切盘颜值和进货价差**算可食用部分成本。水果拼盘里苹果、橙子、菠萝的实用选法如下：

**苹果**
- 优先选**中果/中大果（单果约180–250g）**，不要盲目选特大果。
- 拼盘用苹果主要看出成率和切面氧化。中果削皮去核损耗约25%–35%，特大果看起来单价高但核、碰伤、削皮损耗未必更低。
- 选**脆度高、果形周正、无明显碰伤**的规格，切花瓣或月牙片更整齐。
- 如果做小份拼盘，选中果更灵活；做大份/自助餐，可选中大果，减少削皮次数。
- 不建议买散装小果做拼盘，切出来规格不统一、边角料多。

**橙子**
- 优先选**单果约200–280g的脐橙/甜橙类中果**，皮薄、易剥、果肉饱满。
- 橙子拼盘常用橙瓣，不是整果称重。要重点看**皮厚和籽**：皮厚品种出成率低，有籽品种切瓣费工。
- 规格过大的橙子不一定划算：皮厚、白瓤多、单瓣过大，摆盘反而不好看；过小则切瓣费工、卖相差。
- 做橙瓣拼盘选中果；做鲜榨或装饰片可用稍大果，但要看皮厚。

**菠萝**
- 优先选**单果约1–1.5kg的中等果**，不要一味选超大果。
- 菠萝看**去皮去眼损耗**：大果肉多，但芯粗、去眼损耗也可能高；中等果通常芯相对细、切块规整。
- 做拼盘块选中等果，出成率和切块整齐度更稳；做菠萝圈/装饰片可略大。
- 选**熟度一致、果眼浅、无黑心**的规格，比单纯比大小更重要。

**实操判断公式**
按“可食用成本”比较：
> 可食用成本 = 进货单价 ÷ 出成率

例如同样品种，A规格进价低20%，但出成率低30%，就不如B规格。餐厅应连续称3–5个样品，记录：
- 单果重
- 削皮去核/去皮去眼后净重
- 出成率
- 切出的标准份数
- 边角料能否用于果汁/装饰

**采购建议**
- 苹果、橙子：以**中果/中大果**为主，稳定切盘规格。
- 菠萝：以**1–1.5kg中等果**为主，兼顾出成率和切块整齐。
- 不要只看箱价或单果价，按**净果成本/标准份成本**比价。
- 拼盘销量大时，固定2–3个规格供应商，要求同一批次熟度、果径接近，减少切配浪费。

简单结论：**苹果选中大果、橙子选中果、菠萝选中等果最稳；特大果通常只适合装饰或鲜榨场景，不一定更划算。**
