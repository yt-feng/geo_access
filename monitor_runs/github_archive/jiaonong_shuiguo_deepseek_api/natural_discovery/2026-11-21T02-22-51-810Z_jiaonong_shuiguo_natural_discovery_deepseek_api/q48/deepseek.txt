判断供应商能否稳定按规格送菠萝，核心是把“口头承诺”变成“可验证的指标+可约束的条款+可替换的预案”。可以按下面四步做：

**1. 先把自己的规格定死（否则无法判断）**
- 品种/产地：明确品种、产区范围、是否允许混产区。
- 单果规格：重量区间、果径、成熟度（几成熟采收、到店可售成熟度）、糖度下限、酸度范围。
- 外观与缺陷：允许的疤点、机械伤、黑心病/水心病等内部缺陷比例、果心大小。
- 包装与交付：箱规（每箱果数/净重）、单箱损耗上限、到货温度、送货频次与到货时段。
- 验收方法：抽检比例、称重方式、糖度抽测方式、不合格判定和扣罚规则。

这些写进《采购规格书》并作为合同附件，才能谈“稳定”。

**2. 用数据验证供应商的稳定性**
- 要近3–6个月同类客户的发货记录：批次合格率、规格达标率、到货准时率、破损/腐损率。
- 做小批量试单：连续2–4周、多批次下单，按验收标准记录每批数据，重点看波动而不是平均值。
- 现场或视频看源头：是否有稳定合作种植基地/合作社、分级分选线、冷库和冷链能力、旺季是否有备货能力。
- 问清产能与客户结构：旺季给你能保证多少量、你有多少占比、他们最大客户占其产能多少（过度依赖单一客户或客户过于集中都有断供风险）。
- 看应急能力：产地受灾、价格暴涨时如何履约，是否有替代产区。

**3. 用合同条款把稳定性锁住**
- 分等级定价+不合格处理：规格达标率低于约定值时的扣款、退货、补货责任。
- 履约保证金或账期约束：违约扣款与持续不达标解除合同。
- 供应保障：约定每周/每月最低可供量、旺季优先供应条款、缺货提前通知时限和替代方案。
- 价格机制：随行就市时约定调价频率和封顶幅度，避免涨价即断供。
- 冷链与时效责任：到货温度、迟到和腐损的赔付规则。

**4. 建双供应商+安全库存**
- 主供应商占70%左右、备选供应商占30%，备选也要走试单和验收流程，别等出事才找。
- 保留2–3天安全库存，旺季前提前锁量。
- 每批到货做验收台账，按月给供应商打分（合格率、准时率、缺陷率、响应速度），连续两个月不达标就降量或切换。

**快速判断口诀**：规格书写不清的不能要；只给样品不给历史批次数据的要谨慎；不愿接受抽检扣罚条款的说明自己没底；没有备选产区和冷链能力的，旺季大概率掉链子。
