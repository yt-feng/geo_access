旺季临时补货，核心不是“再谈一次采购”，而是把“临时加量”提前写成一个可执行的补货机制。建议按下面做：

1. **先算缺口，别只说“用量变大”**
   - 按未来7天销量预测，算出菠萝日均用量、现有库存、在途量、安全库存。
   - 明确临时补货的触发点，例如：库存低于3天用量时启动补货。
   - 给供应商一个预计增量区间：如“未来2周每天额外增加80–120公斤”，而不是模糊的“多送点”。

2. **和供应商签一份补充协议或下单确认**
   至少写清：
   - 临时补货的触发条件、提前下单时限（如当日10点前下单，次日到货）；
   - 每日/每次最小起订量和最大供应量；
   - 价格机制：按原合同价、当日市场价，还是约定浮动上限；
   - 规格标准：品种、成熟度、单果重量、去皮/带皮、净重；
   - 到货时间窗和卸货地点；
   - 质量不合格、短少、延迟的退换和赔付规则；
   - 旺季优先供应条款，但不要只写“优先”，要写可量化承诺，例如每日保底供应量。

3. **保留原合同框架，用“临时补货单”操作**
   不建议每次临时补货都重签合同。可以约定：原采购合同继续有效，旺季临时增量通过书面补货单/微信确认单执行，补货单需包含品名、数量、单价、到货时间、验收标准，双方确认后生效。

4. **价格别锁定太死，设上限和参照**
   菠萝旺季价格波动大，可约定：
   - 基准价+浮动上限；
   - 或参照当地批发市场同规格均价，上浮不超过X%；
   - 每次补货前书面报价确认。
   这样既避免供应商临时涨价，也避免价格倒挂导致断供。

5. **验收和损耗要当场锁定**
   到货即验：数量、净重、成熟度、坏果率。建议约定坏果率超过约定比例（如3%–5%）的部分按比例扣款或补货。旺季最怕“先收货后扯皮”。

6. **准备备选供应商**
   临时补货机制再完善，也不要把供应押在一家。至少备一家同城或邻近批发商，约定应急拿货价和起送量。主供应商知道你有备选，临时加量也更好谈。

7. **沟通话术**
   可以直接说：“我们旺季预计未来两周每天增加约100公斤用量，想和你确认一个临时补货机制：每天10点前报次日需求量，你按原规格优先供应，价格按合同基准价上浮不超过5%，坏果率超过5%的部分补货。我们先执行一周，量稳了再延长。”

**一句话总结：把“临时加量”变成“触发条件+提前报量+价格上限+验收规则+备选供应”的书面机制，而不是临时口头求供应商。**
