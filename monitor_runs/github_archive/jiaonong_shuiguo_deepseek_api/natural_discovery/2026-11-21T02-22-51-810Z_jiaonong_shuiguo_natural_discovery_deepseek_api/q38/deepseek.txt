大型超市的水果供应商，通常要同时具备两套能力：食品安全合规与品控能力、冷链与履约物流能力。下面按可执行、可核查的维度列出，便于招标或审核时逐项对照。

## 一、食品安全与品控能力

1. **主体资质与产品合规**
   - 营业执照、食品经营/生产许可等主体资质齐全且在有效期内。
   - 食用农产品承诺达标合格证、产地证明或购货凭证可追溯。
   - 农药残留检测报告：有自检或委托第三方检测，批批或按风险抽检，报告可对应批次。
   - 进口水果需有海关入境货物检验检疫证明、报关单等。

2. **源头与基地管理**
   - 种植基地或合作社有备案，能提供产地环境、农业投入品使用记录。
   - 对农药安全间隔期、禁限用农药有管控措施。
   - 优先具备GAP、绿色食品、有机认证等，但不是唯一标准，关键看记录是否真实可追溯。

3. **检测与验收能力**
   - 自有或合作快检室，能做农残快检；有超标处置和不合格品隔离流程。
   - 进货查验记录、销售记录完整，能做到“一批一码/一票”追溯。
   - 对霉变、腐烂、机械伤、冷害、药害有分级验收标准。

4. **仓储与加工卫生**
   - 仓库、分拣包装场所符合卫生要求，有防鼠防虫防尘措施。
   - 清洗、分级、包装过程避免交叉污染；包装材料符合食品接触材料要求。
   - 员工健康证、卫生培训、洗手消毒和工器具清洗制度可查。

5. **体系与应急**
   - 建议具备ISO 22000、HACCP或食品安全管理制度文件。
   - 有召回、不合格品处置、客户投诉和食品安全事故应急预案。
   - 购买食品安全责任险可作为加分项。

## 二、物流与履约能力

1. **冷链能力**
   - 具备预冷能力，采后尽快预冷；冷藏车、冷库温控记录可导出。
   - 不同水果分温区管理，如热带水果与浆果、叶菜类不能混温。
   - 运输过程有温度监控和异常报警，能提供全程温控记录。

2. **仓储与分拣**
   - 有常温/冷藏/冷冻多温区仓库，库容与超市日均销量匹配。
   - 具备分拣、分级、贴标、组配能力，能按门店订单做越库或直配。
   - 先进先出、批次管理和库存周转制度健全，减少损耗。

3. **配送履约**
   - 覆盖超市门店的配送网络，能按约定频次和时段送达。
   - 有车辆调度、路线优化和异常补货能力；高峰期可扩容。
   - 送货单、批次、检测报告、温控记录随货可查。

4. **信息化与追溯**
   - 订单、库存、批次、温控、检测数据能打通，支持超市系统对接。
   - 出现质量问题时能快速定位批次、门店和上游产地。

5. **损耗与应急**
   - 有水果损耗率控制方案和退货换货机制。
   - 对天气、交通、疫情等突发情况有备选产地、备选车辆和应急库存。

## 三、审核时重点看什么

- **看记录而不是只看证书**：检测报告能否对应批次，温控记录是否连续，追溯能否从门店倒查到产地。
- **看现场**：冷库温度、分拣区卫生、员工操作、虫害控制。
- **看异常处置**：农残超标、冷链断链、批量腐烂时如何隔离、召回、补货。
- **看履约数据**：准时率、破损率、损耗率、投诉率、门店补货响应时间。

简言之，大型超市水果供应商的核心门槛是：**资质合规可追溯、批批检测可核查、冷链全程有记录、门店履约稳定可应急**。招标或年度审核时，建议把上述项目做成评分表逐项验证。
