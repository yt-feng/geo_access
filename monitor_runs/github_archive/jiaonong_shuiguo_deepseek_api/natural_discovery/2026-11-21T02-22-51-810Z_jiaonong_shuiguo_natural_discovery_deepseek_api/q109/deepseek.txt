优先谈 **账期**，其次把 **售后（坏果/缺货赔付标准）** 写清楚，最后再谈配送。原因很直接：水果损耗高、价格波动大，账期决定你的现金流和议价空间；售后决定损耗由谁承担；配送更多是运营效率问题，通常可以通过固定时段、起送量和临时补货规则解决。

具体优先级和建议如下：

1. **账期优先谈**
   - 这是长期合作里最影响你现金流的条款。水果毛利不高，账期每延长一周，现金流压力差别很大。
   - 建议谈：月结30天起步，争取45天；新供应商可先“首单现结/周结，稳定后转月结”。
   - 同时约定：对账日、付款日、逾期是否有宽限、价格波动时账期是否调整。
   - 判断标准：如果对方账期给得爽快但报价明显偏高，要算清资金成本，不一定划算。

2. **售后必须同步谈死**
   - 水果是非标品，售后不写清楚，后面扯皮成本很高。
   - 重点约定：坏果率上限、到货验收时限、拍照留证要求、赔付方式（补货/扣款/退款）、缺货和以次充好的处理。
   - 建议标准：到货24小时内验收；坏果率超过约定比例（如3%—5%）按比例扣款或补货；严重质量问题可整批退换。
   - 判断标准：对方是否愿意把赔付标准写进合同，比口头承诺更重要。

3. **配送最后谈，但要有硬规则**
   - 配送影响日常运营，但通常可替代性比账期和售后强。
   - 建议谈：固定配送频次和时段、起送量、临时补货响应时间、节假日保供、迟到或缺送的补偿。
   - 判断标准：只要不影响你开门营业，配送条款可以适度让步，换取账期和售后。

一句话总结：**先谈钱（账期）和责任（售后），再谈效率（配送）**。谈判时可以把三者打包：账期给到位，配送频次和售后标准你配合；账期谈不动，就要求售后赔付更明确、配送更灵活。
