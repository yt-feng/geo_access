# 判断香蕉供应商能否“按时到车”的可操作方法

“按时到车”核心是两件事：**人靠谱** + **货已备好、车已落实**。批发商可以按下面顺序排查，越往后越能验证真实履约能力。

## 一、先看“履约记录”，不只看口头承诺

1. **要最近3—5车的实际发车记录**：车牌、装车时间、到达时间、货主电话。没有记录或支支吾吾的，直接降级。
2. **向同行交叉打听**：问2—3个用过该供应商的批发商，重点问“最近一个月有没有拖车、临时加价、以次充好”。
3. **看是否长期做香蕉**：香蕉催熟、温控、装车都有门道，临时拼货的“倒爷”按时到车概率低。优先选有稳定产地或固定档口的供应商。

## 二、订车前把“到车条件”写死

口头说“没问题”不算数，订金前至少确认：

- **装车时间精确到半天**，并约定“最晚发车时间”；
- **车牌号和司机电话**在发车前24小时提供；
- **装车后拍视频/照片**：车号、香蕉箱数、装车现场、封车；
- **违约条款**：晚到几小时怎么扣款、临时换车怎么处理、烂货怎么赔；
- **付款节奏**：尽量“装车付一部分、到车验货付尾款”，不要全款前置。

## 三、发车前24小时做“三确认”

1. **确认货**：问“今天装还是明天装？装了多少件？在哪个库/场地装？”要求现场视频。
2. **确认车**：要车牌、司机电话，直接给司机打个电话，问“几点到装车点、装完走哪条线、预计几天到”。司机说法和供应商不一致，就是风险信号。
3. **确认天气和路线**：香蕉怕冻怕热，问清运输温控方式；查沿途是否有极端天气、堵车、限行。供应商如果对路线一问三不知，说明车可能是临时找的。

## 四、装车当天看“动作”

- 是否**按约定时间开始装车**；
- 是否**主动发装车视频**，而不是你催几次才发；
- 封车后是否**立即给出发车时间**；
- 有没有**临时换车、换司机、加价、说“货不够要拼车”**——这些都是拖车前兆。

## 五、到车节点留缓冲

- 合同里把“到车时间”写成**区间**，比如“发车后48—60小时到”，并约定超出后的扣款标准；
- 自己**提前备1—2个备选供应商**，不要把所有档期押在一家；
- 首次合作**小批量试单**，跑顺2—3车再放量。

## 快速判断口诀

**有记录、有车牌、有装车视频、有违约条款、有备选**——五样齐了再打订金；缺两样以上，就按“可能拖车”处理。
