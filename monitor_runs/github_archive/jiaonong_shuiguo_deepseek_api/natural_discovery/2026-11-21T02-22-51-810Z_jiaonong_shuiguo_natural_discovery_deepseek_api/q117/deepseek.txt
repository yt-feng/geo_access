先给一个可执行的判断框架：**新品首单不要按“推荐量”定，而按“能在一周内卖完且不影响现金流的量”定。** 水果供应商推荐新品时，最稳的试卖量通常不是固定箱数，而是用下面三个数取最小值。

**1. 先算“一周可消化量”**
用你门店/渠道同类水果最近7天的日均销量，乘以下面系数：

- 完全新品类、顾客没认知：**日均同类销量 × 3～5天**
- 同品类换品种/换产地：**× 5～7天**
- 有促销位、能试吃、员工会推：可到 **× 7天**，但不要再高
- 只有货架自然销售、没推广：**× 3天** 更稳

例：你店同类水果一天卖20斤，新品没认知、无试吃，首单就 **60～100斤**；有试吃和陈列位，可 **100～140斤**。

**2. 再看“损耗承受量”**
水果新品最大的风险是损耗。首单金额建议控制在：

- 单店/单渠道：**不超过该品类周营业额的10%～15%**
- 新供应商第一次合作：**不超过500～1000元**，或**不超过1～2个托盘/少量多品种拼车**
- 高客单精品果：**先1～2箱/件**，宁可断货补货，不要压货

**3. 最后看“补货周期”**
首单量 = **日均预估销量 × 补货到货天数 + 安全库存**。
如果供应商次日能补，首单就压到 **2～3天销量**；如果一周补一次，才放到 **5～7天销量**。**能快速补货的，首单越少越稳。**

**比较稳的起步建议：**

- **社区水果店/单店**：先拿 **1～3箱** 或 **30～50公斤**，最多不超过 **一周同类销量的一半**。
- **连锁小批量试销**：选 **2～3家代表性门店**，每店 **1箱/20～30公斤**，跑 **7天**。
- **电商/社群团购**：先开 **1～2个团**，每团 **20～50单**，按预售制，不压库存。
- **餐饮/果汁店采购**：先要 **1～2天用量**，同时做杯测/出汁率测试，稳定后再签周量。

**判断是否加单的硬指标：**
试卖7天后看三个数：**售罄率≥80%、损耗率≤5%～8%、复购/回头询问明显**，再按1.5～2倍加单；如果售罄率低于60%或损耗超过10%，先不要加量，换陈列或换门店再试。

一句话：**首单按3～5天销量起，金额控制在500～1000元或品类周流水10%以内，能补货就少压货，用7天数据决定加不加单。**
