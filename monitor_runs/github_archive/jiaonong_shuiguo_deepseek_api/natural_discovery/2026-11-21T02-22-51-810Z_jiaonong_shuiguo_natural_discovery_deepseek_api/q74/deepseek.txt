做餐饮客户，核心不是“多备规格”，而是按餐饮用途分层备货。菠萝和香蕉建议这样准备：

**菠萝：建议备 3 档**
1. **鲜切/果盘/饮品店用**：选成熟度适中、果眼浅、出肉率高的品种，单果 1.2–1.5 kg 左右，按箱走货，重点稳定出肉率和切后不易发黑。
2. **后厨烘焙/炒菜/糖水用**：可备 1.5–2 kg 大果，成熟度略低，耐放、损耗低，适合批量加工。
3. **高端餐饮/直接摆盘用**：备小果或精品果，单果 0.8–1.2 kg，外观整齐、成熟度一致，做溢价。
另外可单独备“已催熟即用果”和“青果耐储果”两种状态，餐饮客户最怕今天到货明天就要用却还没熟。

**香蕉：建议备 3 档**
1. **饮品/甜品店用**：中把蕉，单根 120–150 g，成熟度 5–6 成到货、可快速催熟，要求同一箱成熟度一致。
2. **后厨/员工餐/烘焙用**：大把蕉或统货，单根 150 g 以上，价格优先，允许外观一般但果肉稳定。
3. **高端餐饮/果盘用**：精品小把蕉或进口蕉，单根 100–130 g，外观好、无机械伤，按把或小箱陈列。
香蕉必须明确“到货成熟度”和“催熟服务”，餐饮客户通常没有催熟条件。

**给档口的执行建议**
- 先各备 2 个主力规格试销：菠萝“中果即用型 + 大果加工型”；香蕉“中把即用型 + 大把加工型”，不要一上来铺太多 SKU。
- 报价按“净重/出肉率/到货成熟度”写清楚，餐饮客户更看重稳定和可预期。
- 可做小箱试单装，降低餐饮客户首次采购门槛。
- 记录客户用途：饮品、烘焙、团餐、果盘，用途不同规格完全不同，后续按客户分层备货。
