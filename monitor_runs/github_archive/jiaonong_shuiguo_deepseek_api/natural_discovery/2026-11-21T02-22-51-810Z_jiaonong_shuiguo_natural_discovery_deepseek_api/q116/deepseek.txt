小商家采购水果，现金结算和月结账期各有明确风险，核心区别在于**资金占用与信用暴露的方向不同**。

## 现金结算的风险
现金结算通常是“现款现货”或“先款后货”，风险主要在买方：

1. **资金占用压力大**：水果周转快但毛利薄，现金付款会压缩现金流，旺季集中备货时尤其明显。
2. **质量纠纷时被动**：钱已付清，若到货发现烂果、规格不符、缺斤少两，追偿和换货的谈判筹码弱，容易变成“扯皮”。
3. **供应商履约风险**：先付款后发货时，遇到不靠谱供应商可能延迟发货、以次充好，甚至收款后失联。
4. **现金管理风险**：大量现金交易存在收付差错、假币、内部挪用和账目不清的问题，不利于留痕和对账。
5. **无账期杠杆**：无法利用账期筛选供应商，也拿不到月结通常对应的价格让利或稳定供货优先权。

## 月结账期的风险
月结是“先货后款”，风险主要转向信用和账务：

1. **供应商信用风险**：账期内供应商可能提价、断供、降低品质，或把好货优先给现结客户；小商家议价能力弱时更明显。
2. **账期被单方缩短或取消**：供应商可能因自身资金紧张突然要求现结，打乱你的现金流安排。
3. **对账与纠纷复杂**：水果损耗、退货、调价频繁，月结容易出现“你说退了、他说没收到”的争议，月底对账成本高。
4. **隐性成本**：月结价格通常高于现结，若没有明确价格条款，账期带来的“便利”可能被加价抵消。
5. **依赖风险**：长期月结容易形成单一供应商依赖，一旦对方停供，短期替代成本高。
6. **违约与法律风险**：若你方逾期付款，可能承担违约金、被停供，甚至影响后续采购信用。

## 可执行建议
- **小额高频、品质不稳定品类**：优先现结或短账期，但保留验收单、过磅单、照片留证，约定“不合格可退换”再付款。
- **大额稳定品类**：可谈月结，但合同写清价格、账期起算日、对账方式、退货扣款规则和逾期责任。
- **混合策略**：部分现结换价格优惠，部分月结保留现金流，避免单一结算方式。
- **无论哪种方式**：坚持每笔留单据、定期对账，现金支付要求收据并注明用途，月结保留书面确认记录。

简单判断：**现金结算怕“钱付了货不对”，月结怕“货用了账说不清、供应被卡脖子”**。小商家更适合“短账期+强验收+书面对账”，而不是无条件现结或长期月结。
