最应该先问**售后**，其次问**配送**，最后才是价格。理由很直接：水果是非标生鲜，团长真正的风险不是进货贵一点，而是**坏果、缺斤少两、压货和赔付扯皮**把团购口碑毁掉。

判断顺序可以这样：

1. **售后先问死**
   - 坏果怎么赔：按个数、按比例，还是整单补发？
   - 拍照时限、报损时限是多少？
   - 是补货还是退款？补货谁承担运费？
   - 缺斤少两怎么处理？有没有称重留证？
   - 当天卖不完/品质下降能不能退换？
   这一项谈不清，价格再低也别轻易合作。

2. **配送再问细**
   - 到团点的时间窗口是否固定？
   - 冷链还是常温？夏天怎么控温？
   - 破损、延迟、少送怎么算？
   - 起送量、配送费、临时加单怎么处理？
   配送不稳会直接导致团长在群里失信。

3. **价格最后谈，但要谈总成本**
   不要只比单价，要算：损耗率 + 赔付成本 + 配送费 + 压货风险 + 售后扯皮时间。便宜但坏果率高的供应商，综合成本往往更高。

**可执行建议：**先让供应商书面回复售后规则和配送时效，再用小批量试团1–2次，重点看坏果率、到货准时率和赔付爽快度。三项都过关，再谈量价。价格是最后一道筛选，不是第一道。
