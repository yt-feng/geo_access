要避免香蕉到店后很快变黑，核心是**控制成熟度、减少机械伤、避开乙烯和低温伤害**。可执行建议如下：

1. **采购时选成熟度偏低的香蕉**
   - 选表皮偏绿、微软但无黑点的香蕉，不要买已经全黄、带梅花点或果柄发黑的。
   - 甜品店如果2-3天内用完，可买“黄绿相间、略硬”的；当天现用才买全黄。

2. **整串采购，保留果柄**
   - 尽量买整把/整串，不要提前拆散。果柄和连接处损伤会加速变黑。
   - 到店后再按需分切，分切后尽快使用。

3. **避免挤压和磕碰**
   - 运输时平放，不要堆压，不要和硬物混装。
   - 香蕉怕擦伤，表皮一破损，黑斑会很快扩散。

4. **存放温度要合适**
   - 未熟或半熟香蕉放**12-15℃左右阴凉通风处**，不要放冰箱冷藏。
   - 香蕉低于约10℃容易冷害，表皮会变黑。
   - 已成熟的香蕉可短时间放空调房阴凉处，但仍不建议冷藏整串。

5. **隔离乙烯，控制催熟**
   - 香蕉自身释放乙烯，会催熟自己和周围水果。不要和苹果、梨、芒果等一起闷放。
   - 需要延缓成熟时，放在通风处，别套不透气的塑料袋。
   - 如果已经较黄，可把果柄用保鲜膜包一下，减少乙烯从切口释放，但不要整根密封。

6. **到店后先进先出**
   - 按成熟度分开放：偏绿的放里面，偏黄的放外面先用。
   - 每天挑出有黑点、软伤的香蕉优先做香蕉泥、奶昔、烘焙，避免继续传染。

7. **不要清洗后存放**
   - 香蕉表面有保护作用，到店后不要水洗。用的时候再处理。

**最实用组合：买偏绿整串 + 12-15℃通风平放 + 不冷藏不挤压 + 按成熟度分批用。** 这样通常能明显延缓到店后变黑。
