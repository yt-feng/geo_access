小水果店进香蕉，优先级建议按这个顺序看：

1. **熟度**
2. **坏果率**
3. **价格**
4. **送货速度**

更准确地说，要分“刚开店/日常补货”和“临时救急”两种情况。

**日常进货：熟度 > 坏果率 > 价格 > 送货速度**
- **熟度最重要**：香蕉是后熟水果，进得太生，卖相和口感起不来；进得太熟，当天卖不掉就容易黑、软、压伤。小水果店销量有限，最好按未来 **1～3天能卖完**的量进，选能当天卖一部分、隔天继续转黄的货。
- **坏果率第二**：香蕉怕压、怕闷、怕冷。坏果率高会直接吃掉毛利，还会影响顾客观感。进货时要看箱内压伤、断把、黑斑、发霉情况。
- **价格第三**：香蕉价格透明、毛利薄，低价但熟度差或坏果多，往往更亏。不要只贪低价。
- **送货速度最后**：除非你断货或临时补货，否则送货速度不是核心；但如果送货慢导致高温闷箱、挤压严重，也会变相提高坏果率。

**临时救急：送货速度可以提到第二**
如果你当天缺货、周末或节假日要补货，顺序可调整为：**熟度 > 送货速度 > 坏果率 > 价格**，避免断货影响客流，但仍不能收明显过熟或压坏的货。

**可执行判断标准：**
- 进货熟度：选 **7～8成熟**、果指饱满、棱角稍圆但不软塌的货。
- 坏果率：开箱抽检，压伤、断把、黑腐明显的不收；按箱算，明显坏果超过 **3%～5%** 就要压价或换货。
- 价格：跟当地批发市场同日比价，低于市场价太多要警惕熟度或品质问题。
- 送货：日常固定供应商要稳定；临时补货再选最快能到的。

一句话：**小水果店进香蕉，先保熟度和坏果率，再谈价格；送货速度只在断货救急时优先级上升。**
