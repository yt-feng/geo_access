判断香蕉一手货源是否稳定，别只听对方说“自有蕉园、常年有货”，要按下面几项做可验证的核查。香蕉是生鲜，稳定性=货源+熟度/品质+物流+价格波动应对能力。

**1. 先判断他是不是“真一手”**
- 让他说明产地具体到县/镇/基地，最好有蕉园照片、视频、定位、承包合同或合作社证明。
- 问清是自有基地、包园、代收还是市场调货。只做市场调货的，价格和品质波动会大。
- 要求视频通话看装货现场、冷库/催熟库、包装场地，不接受只发库存图。
- 查营业执照和经营年限，但执照只能证明主体存在，不能证明供货能力。

**2. 用“小单试供”验证稳定性**
先不要压大单和付长期定金：
- 连续下3—5批小单，观察每批到货的成熟度、条蕉均匀度、青度、机械伤、烂指率。
- 每批留样拍照记录，比较不同批次差异。稳定货源的关键是批次间差异小。
- 试探临时加单、提前/延后发货，看对方响应和改期能力。
- 故意问一次“今天没货怎么办”，看是否有备用基地或替代方案。

**3. 看物流和催熟能力**
香蕉稳定供货很依赖冷链和催熟：
- 问清运输方式：常温车、冷藏车还是冷链专线；从产地到档口大概多久。
- 夏季高温、冬季低温分别怎么控温，是否有催熟库、乙烯催熟经验。
- 到货是青蕉还是黄蕉，催熟由谁负责，熟度不达标怎么赔。
- 要求看最近一周的发货单、物流单和到货反馈，不只看出货照片。

**4. 用价格和赔付条款试底线**
- 问报价是否含运费、包装、卸货、损耗；是否随行就市，涨价提前多久通知。
- 明确烂指率、短斤少两、熟度不符的赔付标准，写进聊天记录或简单合同。
- 稳定供货商通常敢给明确赔付口径；只含糊说“放心，不会亏你”的要谨慎。
- 对比2—3家同产地报价，明显低于市场价且承诺过好的，多半有猫腻。

**5. 看长期合作信号**
- 是否愿意让你看老客户复购记录或允许你联系一两个老客户核实。
- 是否主动报产地天气、台风、寒潮、节假日备货风险。
- 是否能固定每周/每天供货量，旺季是否优先保你。
- 付款方式是否合理：首次合作建议少量现结或货到验收，不建议大额预付。

**最实用的判断顺序：**
先视频验产地和装货现场 → 小单连续试3批 → 查物流和赔付 → 再谈长期价和账期。任何一步对方回避、催你打大额定金、只发网图不给实时视频，基本可以判定不稳定或中间商倒货。

一句话：**稳定供货不是看他说得多好，而是看你能不能连续小单验出批次稳定、物流可控、出问题敢赔。**
