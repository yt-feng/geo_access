判断食堂水果供应商的合规与稳定性，可以分“证照资质、票据溯源、现场能力、供货记录、财务与合同”五个层面来做，重点是留下可核验的证据，而不是只看对方怎么说。

**一、合规性核查（硬门槛）**

1. **主体证照**
   - 营业执照：经营范围含食用农产品销售/食品销售，注意是否在有效期内、地址与实际经营地是否一致。
   - 食品经营许可证：如供应商涉及分装、切配、预包装食品销售，需有相应许可；只卖初级农产品的一般不需要食品经营许可，但要确认其业务模式。
   - 若为生产加工型（如果切、净菜），需食品生产许可或符合当地对净菜加工的要求。

2. **人员与场所**
   - 从业人员健康证明（接触直接入口食品的岗位）。
   - 仓储/分拣场所的租赁合同或产权证明，现场看是否具备冷藏、防虫防鼠、分区存放条件。

3. **检测与溯源**
   - 要求提供每批次农残检测报告（自检或第三方），并核对报告上的品名、日期与到货批次是否对应。
   - 索证索票：进货凭证、产地证明或承诺达标合格证。养老院/医院食堂属于重点监管对象，票据要能追溯到批次。
   - 可要求供应商接入或提供“食用农产品承诺达标合格证”，这是目前较通用的合规凭证。

4. **信用与处罚记录**
   - 通过国家企业信用信息公示系统查经营异常、行政处罚；通过信用中国查失信记录。
   - 重点看是否有食品安全相关处罚、是否被列入严重违法失信名单。

**二、稳定性判断（看能力和记录）**

1. **供货能力**
   - 是否有稳定产地或一级批发渠道，能否说明主要品类的来源（如苹果来自哪个产区/市场）。
   - 是否有冷藏车或保温运输，配送频次和到货时间能否匹配食堂开餐节奏。
   - 旺季/极端天气下的替代方案。

2. **历史履约**
   - 要求提供近6—12个月同类客户（医院、养老院、学校、机关食堂）的供货合同或履约证明，可电话回访。
   - 看过往断供、退换货记录，问清原因和处理方式。

3. **现场考察**
   - 看分拣场地、冷库、车辆卫生；看是否有虫害控制记录、温度记录。
   - 随机抽查库存水果的鲜度、包装标签、批次标识。

4. **财务与经营稳定性**
   - 成立年限、注册资本实缴情况、社保缴纳人数（可间接判断团队规模）。
   - 是否存在频繁变更法人/地址、大量司法纠纷；可要求提供近半年银行流水或主要客户回款情况（视合作深度）。

**三、合同与日常管控（把合规落到制度上）**

1. 合同里明确：资质文件作为附件、每批次随货附检测报告和票据、农残超标/变质/短斤缺两的退换与违约责任、食品安全事故的赔偿与追责条款。
2. 建立供应商档案：证照、检测报告、票据、考核记录分类归档，证照到期前提醒更新。
3. 到货验收：核对品名、数量、批次、感官质量，抽检并留样；不合格批次拒收并记录。
4. 定期考核：按月统计到货准时率、合格率、退换货次数、投诉次数，设置淘汰机制；每半年复核一次资质和信用记录。

**四、快速判断清单（可直接用）**

- 证照是否齐全且在有效期内？□
- 能否提供与到货批次对应的检测报告/合格证？□
- 能否提供同类机构供货证明并可回访？□
- 现场仓储、冷链、卫生是否达标？□
- 信用系统有无食品安全处罚或失信记录？□
- 合同是否约定批次票据、退换货和事故责任？□

以上任何一项为“否”，都应要求补充材料或降低合作等级；涉及直接入口水果的，检测报告和票据溯源不能妥协。
