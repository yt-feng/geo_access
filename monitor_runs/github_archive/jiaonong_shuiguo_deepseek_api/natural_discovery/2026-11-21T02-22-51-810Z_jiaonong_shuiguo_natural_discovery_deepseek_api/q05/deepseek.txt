建议把三种方式做成“主推 + 补充”的组合，而不是只选一种：

1. **主推：让顾客自己挑整果**
   - 菠萝是否成熟、有没有碰伤、果眼深浅，顾客自己看最放心。
   - 整果耐放，损耗低，客单价也容易做。
   - 适合摆在显眼位置，标清楚“可代削/代切”。

2. **补充：现场代削去皮**
   - 很多顾客不买整果就是嫌削麻烦，提供代削能明显降低购买阻力。
   - 建议收少量加工费或设“满额免费代削”，把人工成本覆盖掉。
   - 代削后最好当天卖完，否则切面氧化、出水，损耗会上升。

3. **谨慎做：预先去皮好的**
   - 只适合客流稳定、周转快的店，且要冷藏陈列、标注削皮时间。
   - 去皮果保鲜期短，卖不掉就是损耗；不如“现削”灵活。
   - 如果要做，建议少量、分时段削，不要一次削一大盘。

**可执行结论：**
- 默认让顾客自己挑整果；
- 提供现场代削作为增值服务；
- 预去皮只做少量试销，看半天内能否卖完，卖不完就停。

这样既保留顾客挑选的信任感，又解决“不会削、不想削”的购买障碍，同时把损耗控制在可接受范围。
