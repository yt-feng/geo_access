酒店采购水果盘原料时，建议把“可验收的规格”和“可判定的外观标准”写进采购单/验收单，避免只写“新鲜、优质”。可按以下维度要求供应商：

**1. 通用规格与安全标准**
- 品种、产地、等级明确：如“红富士苹果，一级果，山东产”，不接受混级、混品种充数。
- 单果重量/直径分级：按品种约定，如苹果≥200g/个或直径≥75mm；橙子≥180g；草莓单果≥15g等，允许±5%偏差。
- 成熟度：到货时8–9成熟，适合当日或次日切配；不得过生或过熟。
- 农残与合规：提供批次农残检测合格证明或承诺符合GB 2763；进口水果提供入境货物检验检疫证明。
- 新鲜度：采摘/到货时间可控，叶菜类、浆果类到货不超过约定时限。
- 温度与包装：冷链品种全程0–4℃（浆果、切果类尤其），到货中心温度符合约定；包装无破损、无渗漏、无污染。
- 批次一致性：同批次颜色、大小、成熟度基本一致，便于摆盘标准化。
- 可追溯：批次号、供应商名称、采收/包装日期可查。

**2. 外观标准（按品类写细）**
- **果形**：具有品种典型形状，无严重畸形、偏果、裂果。
- **色泽**：着色均匀，符合品种成熟色泽；无大面积青斑、日灼斑、药斑。
- **表面**：洁净，无泥土、污渍、汁液残留；无病虫害斑、霉点、腐烂、软烂、渗液。
- **损伤**：无明显机械伤、压伤、磕碰伤、划伤；果柄剪口平整，不刺伤其他果。
- **新鲜度**：果皮饱满有光泽，无皱缩、失水、干瘪；叶菜类无黄叶、萎蔫。
- **异味**：无发酵味、霉味、化学药剂味。
- **规格偏差**：单果大小、颜色差异控制在约定比例内（如大小偏差≤5%，色泽差异≤10%）。

**3. 验收与退换条款**
- 抽样比例：如每批次随机抽检5%–10%，不少于约定数量。
- 不合格判定：腐烂、霉变、虫害、异味、严重压伤为直接拒收；规格偏差超限、外观瑕疵超比例可要求换货或折价。
- 损耗率：约定到货可接受损耗上限（如≤2%–3%），超出部分由供应商补货或扣款。
- 退换时限：到货验收发现问题的，供应商应在约定时间内补换合格品。
- 留样与记录：验收拍照、留样，异常批次书面确认。

**4. 写进合同的建议表述**
“供应商保证所供水果符合约定品种、等级、单果规格及成熟度；外观无腐烂、霉变、虫害、异味、明显机械伤和失水皱缩；农残符合GB 2763；冷链品种到货温度0–4℃；每批次提供检测/追溯信息。验收按抽样比例执行，不合格品无条件退换，损耗超约定上限由供应商补足。”

这样既便于酒店验收人员判断，也能在出现争议时有明确依据。
