会影响，但通常不是“致命影响”，关键在于**大小差异是否明显、是否影响卖相和定价**，以及你用什么方式卖。

可直接判断：

1. **整箱统货卖**：大小差异大，顾客会挑大留小，最后小的难卖，损耗和投诉会增加。
2. **分拣分级卖**：大果、中果、小果分开定价，影响会小很多；小果可做促销、切果盘、香蕉奶昔原料。
3. **差异轻微**：同一品种同一成熟度下，大小略不均通常不影响销售，反而更像自然果。
4. **差异明显或混品种**：会明显影响销售，尤其礼盒、团购、精品店场景，顾客会觉得“货不匀”。

采购建议：

- 先看**大小差异比例**：一箱里最大和最小差多少，小果占比多少。
- 看**成熟度是否一致**：大小不匀还能接受，成熟不匀更麻烦。
- 问清是**同一品种自然差异**还是**混级货**。
- 如果做水果店零售，优先采购**分级清楚**的货；统货可以拿，但价格要低，并准备分拣。
- 礼盒、企业团购、线上按份卖，尽量选**大小均匀**的。

一句话：**大小不一会影响销售，但可通过分级、定价和用途消化；差异大且不给你分拣空间时，压价或换货。**
