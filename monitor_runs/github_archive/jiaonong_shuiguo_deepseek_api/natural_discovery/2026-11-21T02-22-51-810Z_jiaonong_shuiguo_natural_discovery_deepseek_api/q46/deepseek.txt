建议按“菜单定位 + 出杯量 + 人工”来选，不要只看单价。结论先说：

- **主打“新鲜现切、果肉感”的中小茶饮店：优先鲜果**，但要用“鲜果+少量果泥/果丁兜底”组合。
- **出杯量大、追求稳定和效率：以果丁/果泥为主**，鲜果只做展示或顶部装饰。
- **只做单一爆款、配方固定：果泥最稳**；**要咀嚼感和颜值：果丁更合适**。

具体判断：

1. **鲜果**
   - 适合：强调新鲜、现切，有后厨人手，菠萝周转快。
   - 优点：香气自然、可做装饰、顾客感知好。
   - 风险：成熟度不稳定、酸甜波动大、去皮切丁耗人工、损耗高；菠萝还有酶导致的“扎嘴/苦味”问题，需要盐水或热处理控制。
   - 适合日销量能消化整箱、且有切配人手的店。

2. **果丁（冷冻/糖渍/罐头类）**
   - 适合：要果肉咀嚼感、出杯较稳定、人工紧张的店。
   - 优点：规格统一、开袋即用、损耗低、出杯速度快。
   - 风险：香气和鲜感弱于鲜果；糖渍果丁要调配方，避免整体过甜；冷冻果丁解冻后口感会变软。
   - 最适合做“果肉型菠萝茶”的主力原料。

3. **果泥（冷冻果泥/浓缩果浆）**
   - 适合：标准化程度高、出杯量大、连锁或外卖占比高的店。
   - 优点：酸甜稳定、易定量、出杯快、损耗低。
   - 风险：果肉感弱，香气可能偏“加工感”；要看清是果泥、果浆还是浓缩汁，糖度和添加物不同，配方不能直接套用。
   - 最适合做基底风味，不一定适合单独撑“鲜果”卖点。

**实操建议：**
- 如果你的店**日出杯菠萝产品少于30杯**：不建议大量买鲜果，损耗和人工不划算，可用**冷冻果丁+果泥**。
- **30～80杯**：鲜果做装饰和部分果肉，果丁/果泥做基底，平衡新鲜感和稳定性。
- **80杯以上或外卖多**：以果丁/果泥为主，鲜果只做顶部装饰或限量款。
- 先做**小批量盲测**：同一配方分别用鲜果、果丁、果泥出杯，比较香气、酸甜、果肉感、出杯速度、3天损耗，再定主力。
- 采购时重点问：**是否加糖/加酸、固形物含量、解冻后状态、保质期、每杯建议用量**。不要只比较每公斤价格，要算“每杯成本”。

一句话：**想卖“鲜”就用鲜果但控制损耗；想卖“稳”就用果丁/果泥；多数茶饮店最稳的是“果丁做果肉、果泥调基底、鲜果做点缀”的组合。**
