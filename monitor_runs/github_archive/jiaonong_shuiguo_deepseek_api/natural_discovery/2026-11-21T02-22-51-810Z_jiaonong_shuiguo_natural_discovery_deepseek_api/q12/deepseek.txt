采购菠萝时，关键不是“挑最熟的”，而是按**到店后预计几天卖完**来倒推熟度。菠萝是后熟水果，采购熟度偏生一点更稳；但太生会酸、纤维硬、顾客复购差。

可执行判断标准：

1. **优先选 7～8 成熟，不要全熟**
   - 适合预计 2～4 天卖完的店。
   - 外观：果皮底色由青转黄，但仍有约 1/3～1/2 青绿；不是全青，也不是通体深黄。
   - 闻：靠近果底有淡淡菠萝香，不能无味，也不能香气冲鼻、发酒味。
   - 按：轻按果身略有弹性，不能硬如石头，也不能一按一个坑。

2. **按销售速度分档采购**
   - 当天/次日能卖完：可选 8～9 成熟，果皮大部分转黄、香气明显。
   - 2～4 天卖完：选 7～8 成熟，黄绿相间、微香、轻按微弹。
   - 超过 4 天或天气热：选 6～7 成熟，青黄为主、香气很淡，到店后自然催熟。
   - 夏季高温、店内无冷柜：整体再降半成熟，少量多次采购。

3. **看果底和果眼，比看果皮更可靠**
   - 果底：干燥、无霉点、无软烂、无汁液渗出。果底发黑发软的直接不要。
   - 果眼：饱满、平整，不凹陷流水；果眼深处发黑说明内部可能已坏。
   - 冠芽：青绿、挺立较好；枯黄严重通常放久了。
   - 果形：端正、饱满，不要明显偏斜或局部发软。

4. **现场抽检方法**
   - 同一批货随机拿 2～3 个，闻果底、轻按果身、看果底。
   - 切开一个代表性样品看：果肉由白转黄、中心不硬、汁水适中。若果心发黑、果肉水渍状、有酒味，说明过熟或储存不当。
   - 不要只按最上面一层判断，底层和箱内温度高的位置更容易过熟。

5. **采购谈判和到货管理**
   - 要求供应商按“黄绿比例、果底状态、到货天数”分级，不要只报“大果/中果”。
   - 到店后立即倒箱、通风、分级：熟的分出来优先促销或现切，生的放阴凉通风处。
   - 菠萝不宜长期低温冷藏，未切的可放阴凉通风处；已切必须冷藏并尽快售完。
   - 建简单损耗记录：每次采购熟度、到货数量、2～3 天后的损耗率。连续记 2～3 周，就能定出适合你店销量的固定采购熟度。

简单记：**看底色黄绿相间、闻果底淡香、按果身微弹、查果底干燥无软烂；卖得快拿偏熟，卖得慢拿偏生，热天再降半档。**
