判断一批香蕉，核心看“颜色阶段 + 硬度 + 棱角 + 果柄/切口 + 气味 + 抽检切开”，不要只看表面黄不黄。

**1. 先定颜色阶段**
- 全绿：未熟，适合长途/压货，但催熟风险高，怕冷害。
- 绿带黄、果尖转黄：开始熟，适合短途批发。
- 黄带绿肩：成熟中，适合1–3天内出货。
- 全黄、果尖略褐：适销，但货架期短。
- 大面积褐斑、果柄发黑：过熟或损伤，坏果风险高。

**2. 看棱角和饱满度**
- 棱角明显、果身瘦：偏生。
- 果身饱满、棱角变圆：熟度上来。
- 局部异常鼓包、软塌：可能内部已坏或挤压伤。

**3. 摸硬度和弹性**
- 整把轻按果身：硬实偏生，微软适熟，一按就陷偏熟。
- 注意“外硬内软”：表面看着好，果指中段发软，切开常已烂心。
- 摸果柄：果柄发软、发黑、发霉，整把风险高。

**4. 看果柄、切口和梳面**
- 切口新鲜、无黑腐、无霉毛：较好。
- 切口发黑、渗液、有酸味：运输或存放过久。
- 梳面连接处发黑、断指多：掉果和坏果风险高。

**5. 闻气味**
- 清香正常。
- 酒味、酸味、发酵味：已过熟或内部开始腐坏，批发风险大。

**6. 抽检必须切开**
别只捏外皮。随机抽几根，重点看：
- 果肉是否均匀乳白/淡黄；
- 中心是否发黑、发褐、水化；
- 是否有硬心不熟；
- 靠近果柄处是否霉变。

**7. 快速判断坏果风险的动作**
- 随机翻箱看底层和中间，不只看面上。
- 看箱内是否有水汽、渗液、霉点。
- 同批抽3–5把，按“颜色、硬度、切口、气味、切开”各查一遍。
- 坏果率明显高、酒味重、切口黑腐、局部软塌的，压价或拒收。

**简单结论：**
适合拿的货：颜色阶段整齐、果身饱满但不过软、果柄切口新鲜、无酒酸味、抽切果肉正常。
谨慎或拒收：颜色不齐、外硬内软、切口黑腐、有酒味酸味、底层渗液霉变、掉指多。
