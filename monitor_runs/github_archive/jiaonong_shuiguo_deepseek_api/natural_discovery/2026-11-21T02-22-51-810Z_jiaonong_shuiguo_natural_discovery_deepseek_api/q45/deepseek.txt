水果年度合同最容易踩坑的条款，集中在“价格随行就市”“损耗谁承担”“到货标准”“账期与返利”“独家与违约”这几块。签之前建议逐条落到可量化、可追责的写法上。

1. **价格与调价机制**
   - 坑：只写“随行就市”“参考市场价”，旺季涨价供应商单方通知，淡季又不降。
   - 建议：约定基准价+调价触发条件（如产地批发价连续7天波动超X%）、调价频率（每月/每旬一次）、书面确认流程，未确认不得执行；明确促销、特价、临期处理价谁承担。

2. **质量标准与验收**
   - 坑：只写“符合国家标准”，到货大小、成熟度、糖度、农残、包装规格没量化，收货时扯皮。
   - 建议：附《验收标准表》，按品类写清规格（单果重、直径、等级）、成熟度、允许瑕疵比例、农残检测要求、包装和标签；明确抽检比例、不合格整批退回还是扣重扣款、二次复检费用谁出。

3. **损耗与退货**
   - 坑：门店损耗、运输损耗、仓储损耗混在一起，最后全算超市或全算供应商。
   - 建议：分段约定——装车前的产地损耗归供应商，运输途中按承运责任，到店验收合格后的门店自然损耗归超市；明确“允许损耗率”和超损扣款公式；临期/变质商品的退货时限、运费和销毁责任写清楚。

4. **交付与缺货**
   - 坑：只写“按时供货”，没写缺货罚则和补货时限，节假日前断货最伤。
   - 建议：按周/日给供货计划，约定最低供货量、缺货违约金或扣减返利；旺季保供条款单独写；不可抗力范围收窄，避免“产地减产”被滥用。

5. **账期、返利与费用**
   - 坑：账期起算点模糊（收货日/对账日/发票日），返利条件口头承诺，进场费、陈列费、促销费层层加码。
   - 建议：写明账期起算日和付款日、对账周期；返利按“实际结算销售额”还是“进货额”算清楚，达成条件、结算时间、未达标处理都写；所有费用列清单并约定上限，合同外新增费用需书面同意。

6. **独家/最低供货与违约**
   - 坑：给了独家却无销量承诺；违约金过高或过低，实际无法执行。
   - 建议：独家条款绑定年度采购量或增长率，未达标自动解除；违约金按可预见损失设定，同时约定质量事故、食品安全事件的赔偿和解除权。

7. **食品安全与追责**
   - 坑：出事后只罚供应商，但超市仍承担连带责任，合同里没约定召回配合和检测报告义务。
   - 建议：要求每批次提供检测报告/合格证，约定召回通知时限、配合义务、消费者赔偿的内部追偿比例；保留供应商资质和产地证明。

8. **合同期限与退出**
   - 坑：一年期但没写提前解约条件，淡季想换供应商换不掉。
   - 建议：约定试用期/季度考核（质量合格率、缺货率、投诉率），连续不达标可提前解约；解约后的库存处理、未结货款、返利清算写清楚。

实操上，建议把验收标准、价格表、返利规则做成合同附件，和主合同同等效力；所有口头承诺写进补充协议。最容易出事的不是大条款，而是“标准没量化、责任没分段、调价没流程”这三件事。
