买香蕉想“到店就能吃、放几天也不坏”，关键不是只看颜色，而是**按你打算吃的时间选成熟度**，再结合手感、果柄和季节判断。

### 1. 先定你什么时候吃
- **当天/第二天吃**：选**全黄、带少量小黑点**的，最稳。
- **2～3天内吃**：选**黄底、两头略绿**的，放到家刚好。
- **3～5天后吃**：选**绿黄相间、果柄偏绿**的，别选全绿，全绿可能催不熟或口感涩。
- **想囤一周**：买**整把偏绿、无碰伤**的，回家分开挂放，别装塑料袋闷着。

### 2. 到店快速判断
- **看颜色**：通体金黄=熟；黄中带绿=将熟；青绿=生。**果柄发黑、果身大面积褐斑**=过熟或磕碰。
- **摸手感**：轻捏有**轻微弹性**最好；硬邦邦=生；一捏就软=熟过头。
- **看棱角**：棱角明显=偏生；棱角变圆润=成熟。
- **看果柄和切口**：果柄青绿较耐放；切口发黑、发霉别买。
- **看表皮**：少量芝麻黑点正常且甜；**大片黑斑、流水、裂口**不要。
- **闻一下**：有清香可以；有酒味/酸味说明过熟。

### 3. 超市里容易踩的坑
- **别买整把最底下被压软的**：上面看着好，下面可能已压伤。
- **别选冷柜边或空调直吹的**：香蕉怕冷，表皮会变黑、里面发硬。
- **别买已经套紧塑料袋的**：水汽闷着容易烂。
- **别一次买太多熟蕉**：熟蕉回家后熟得快，2～3天吃不完就冷冻或做奶昔。

### 4. 回家处理
- 偏生：**常温**放，和苹果/梨装纸袋可加速成熟，每天看一下。
- 刚好熟：**常温阴凉**，别放冰箱冷藏，表皮会黑。
- 太熟吃不完：**剥皮切段冷冻**，做奶昔；或冷藏后尽快吃。

**最稳买法**：当天吃选“全黄+少量黑点+轻捏微弹”；想放几天选“黄底带绿+果柄青+手感偏硬但不青涩”。
