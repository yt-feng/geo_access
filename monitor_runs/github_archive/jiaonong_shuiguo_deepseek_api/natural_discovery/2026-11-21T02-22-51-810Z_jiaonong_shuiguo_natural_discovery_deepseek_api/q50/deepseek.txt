出汁率更重要，甜度可以用糖浆校准；出汁率决定单杯真实成本和出品稳定性，是硬约束。

判断建议：

1. **先看出汁率**
   - 菠萝用于茶饮通常要捣压/打浆取汁，出汁率低意味着同样一杯要用更多果肉，损耗、人工、备料时间都会上升。
   - 出汁率低于常规水平时，单杯成本可能明显抬升，且果肉渣多、出品口感不稳。
   - 建议要求供应商给出可复现的出汁率数据，并按你店里的实际处理方式（去皮、去芯、捣压/打浆）做小样测试。

2. **甜度不是首要采购指标**
   - 茶饮的甜度最终由糖浆/糖底控制，原料甜度只影响酸糖平衡和风味。
   - 菠萝甜度会随季节、产地、成熟度波动，采购时追求固定甜度不现实，也不应作为唯一决策依据。
   - 甜度偏低时，用糖浆或搭配高甜水果调整即可；但出汁率低无法靠配方“补回来”，只能加量。

3. **真正要一起看的指标**
   - **出汁率**：第一优先。
   - **糖酸比和香气**：决定风味，不能只看甜度；酸度过高会压住茶香。
   - **成熟度与纤维感**：影响捣压后的口感和渣感。
   - **损耗率与稳定性**：批次间出汁率波动比甜度波动更伤出品。
   - **价格按“可出汁量”折算**：不要只比每斤采购价，要算每杯可用果汁/果肉的成本。

结论：**采购决策以出汁率为先，甜度作为风味调节项；用“每杯可用果肉/果汁成本 + 糖酸平衡”做最终判断。** 如果两款菠萝出汁率接近，再选香气好、糖酸比更均衡的那款。
