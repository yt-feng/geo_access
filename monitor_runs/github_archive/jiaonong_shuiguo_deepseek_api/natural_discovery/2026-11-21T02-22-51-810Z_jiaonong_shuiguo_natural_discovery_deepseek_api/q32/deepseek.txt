判断能否**全年稳定供货**，不能只听供应商口头承诺，要按“产能—产地—合同—履约记录—风险预案”五层核验。

**1. 先问清供货结构，不只问总产量**
- 要求供应商列出：自有基地/合作基地比例、各产地面积、品种、上市月份、年可供量、月可供量。
- 重点看**淡季月份**的货源从哪来。香蕉主产区有季节性，单一产区很难全年稳定；能全年供的通常有跨产区布局或长期合作基地。
- 让供应商提供近12个月实际发货记录，按品名、规格、月份列量，和你需求做缺口比对。

**2. 核验产地与产能真实性**
- 要基地清单：地址、面积、种植年限、年产量、是否通过认证。
- 抽查视频或实地看基地，核对包装厂、冷库、催熟库能力。
- 问清是自有、订单农业还是市场临时收购。临时收购比例高的，旺季可能供得上，淡季和行情波动时容易断供。

**3. 看冷链与催熟能力**
香蕉全年稳定还取决于采后处理：
- 是否有稳定冷库和催熟库，库容能否覆盖你的日销量和周转天数；
- 运输是常温还是冷链，跨省运输时长和损耗率；
- 旺季爆单时，包装和催熟产能是否跟得上。

**4. 用合同锁定量和价**
- 合同写明：年度框架量、月度最低供货量、淡季保供条款、缺货违约责任。
- 价格机制建议“基准价+浮动”，避免行情大涨时供应商优先供高价客户。
- 约定质量标准、验收扣重、损耗分担和替代品种/产地条款。

5. 查履约记录和财务稳定性
- 要近1—2年同类超市客户合作证明或供货合同脱敏页；
- 查企业工商、涉诉、被执行信息；
- 问如果连续阴雨、台风、寒潮、病害导致减产，备用产地和替代方案是什么。

**6. 小步验证再放量**
先给2—4周试单，覆盖一个淡季月份更好；同时保留第二供应商，按70/30或80/20分配采购量。连续3—6个月月度达成率低于约定阈值，就降级或替换。

**快速判断信号：**
- 能拿出按月供货计划和近12个月发货数据；
- 有2个以上产区或基地，淡季有明确来源；
- 愿意签最低月供量和违约条款；
- 有冷库、催熟库和稳定物流；
- 经得起实地或视频抽查。
反之，只谈“货源充足”、拒绝提供月度数据、无淡季方案、不愿签保供条款的，不建议作为全年主供应商。
