水果供应商客户经理响应慢，会从“缺货、损耗、价格、客诉”四条线同时传导到门店经营：

1. **缺货与断货**
   - 补货、调货、临采申请审批慢，热销品断档，直接丢销售。
   - 突发缺货时不能快速协调替代品，门店只能空排面或临时高价采购，毛利被侵蚀。

2. **损耗上升**
   - 水果保质期短，到货异常（品质差、规格不符、少发）若不能及时反馈处理，错过最佳销售窗口，只能折价或报损。
   - 退换货、补损响应慢，损耗责任难以及时确认，门店被动承担。

3. **价格与促销被动**
   - 行情波动时报价慢，门店错过低价锁货或高价避损窗口。
   - 促销备货、活动支持确认慢，档期商品不到位，活动效果打折，还影响客流和复购。

4. **客诉与口碑受损**
   - 品质问题处理慢，顾客退换、补偿延迟，门店前台承压，差评和流失增加。
   - 长期缺货或品质不稳定，顾客形成“这家店水果不新鲜/不全”的印象，复购下降。

5. **内部管理成本增加**
   - 店长和采购反复催单、对账、追售后，挤占抓销售和现场管理的时间。
   - 到货、退损、结算信息不同步，容易造成账实不符和员工扯皮。

6. **现金流与结算风险**
   - 对账、发票、返利核销慢，影响结算周期和资金周转。
   - 争议处理拖延，可能形成隐性占款或坏账风险。

**可执行判断：** 如果响应慢已导致热销品周断货≥1次、报损率明显上升、或客诉处理超过24小时未闭环，就应按供应商履约问题处理：明确响应时限（如询价/补货/售后分别几小时内回复）、设置缺货替代预案、把响应时效纳入供应商考核，并准备备选供应商。
