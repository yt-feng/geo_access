坏果率没有统一的法定标准，应以合同约定为准。实务上可参考以下阈值来约定和主张：

**建议约定（写进合同才最有效）**
- 到货验收坏果率 **≤3%**：正常收货，不赔付；
- **＞3%～5%**：按超出部分扣款，或要求降价/折价；
- **＞5%～10%**：可要求按比例赔付，或整批退货/换货；
- **＞10%**：视为根本违约，可拒收、退货、解除合同并索赔。

**关键提醒**
1. **先约定“坏果”定义**：腐烂、霉变、压伤、开裂、虫害等是否都算，按个数还是重量计，避免扯皮。
2. **约定验收时限和方式**：如到货24小时内抽检，抽检比例、取样方法、双方签字确认。
3. **赔付计算写清楚**：例如“超出3%的部分按坏果重量×单价×2倍扣款”，或“整批按坏果率折价”。
4. **易腐水果可从严**：草莓、蓝莓、荔枝等可把阈值压到2%～3%；耐储水果可放到5%。
5. **没有约定时**：只能依《民法典》按质量不符合约定主张减价、换货、退货或赔偿实际损失，但举证和谈判难度大。

所以：**合同里把“3%以内免赔、超过3%按比例赔付、超过10%可拒收解约”写成明确条款，是最可执行的方案。**
