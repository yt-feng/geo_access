社区超市找每日配送的水果供应商，重点看这些条件，按优先级判断：

1. **配送稳定性**
   - 能否承诺每天固定时段送达，迟到或漏送如何处理。
   - 是否有备用车辆、备用仓库或应急补货方案。
   - 节假日、雨天、凌晨采购高峰是否照常配送。

2. **货源与季节供应能力**
   - 是否有稳定产地或一级批发市场渠道，不靠临时倒货。
   - 常见水果全年能否稳定供，季节性水果能否提前报备。
   - 是否支持小批量多品种，适合社区店“少进快销”。

3. **品质与损耗控制**
   - 看实际到货样品：成熟度、大小、外观、坏果率。
   - 是否按标准分级，能否约定坏果率上限和赔付。
   - 是否支持开箱验货、当场退换。

4. **价格与结算**
   - 报价是否含运费、装卸费，是否随行就市且有调价通知。
   - 起订量、单品最低量是否适合社区店。
   - 账期、押金、退换货结算方式是否清楚。

5. **冷链与仓储能力**
   - 易腐水果是否有冷藏车或保温配送。
   - 仓库是否分区存放，避免串味、压伤。
   - 夏季高温和冬季防冻是否有措施。

6. **售后响应**
   - 出现质量问题多久响应、多久补货。
   - 是否有专人对接，微信/电话能否及时处理。
   - 退换货是否顺畅，是否推诿。

7. **资质与合规**
   - 营业执照、食品经营相关资质是否齐全。
   - 能否提供进货凭证、检测报告或产地证明。
   - 索证索票是否规范，便于应对检查。

8. **试配与合同**
   - 先试配1—2周，看准时率、坏果率、缺货率。
   - 合同写清配送时间、品质标准、赔付规则、调价机制、退出条款。
   - 不要只看最低报价，算上损耗和售后成本再比较。

实操建议：同时找2—3家试配，用“准时率、坏果率、缺货率、售后响应时间”四个指标打分，留一家主供、一家备供。
