结论先给：**线上生鲜电商优先做“整果为主 + 切配为辅”，冷冻菠萝作为补充SKU，不建议作为主推。** 判断依据是损耗、履约半径、客单价和复购结构。

**1. 整果：最适合做线上主品**
- 优点：标准化程度相对高、加工成本低、保质期比切配长、可做预售和产地直发；用户对“整果”信任度高，适合拼团、秒杀、家庭装。
- 关键风险：成熟度不一致、磕碰压伤、重量差异、售后纠纷。
- 可执行建议：
  - 按规格分级卖：小果/中果/家庭装，明确单果重区间和糖度范围。
  - 做“坏果包赔”规则，但设定拍照时效和赔付比例，控制售后成本。
  - 产地直发用泡沫网套+纸箱，短保同城用周转箱，避免和重物混装。
  - 主推应季单品，用预售锁定销量，降低库存损耗。

**2. 切配：适合做同城/次日达的利润补充**
- 优点：客单价高、即食便利、适合办公室和年轻家庭；能消化外观瑕疵果。
- 关键风险：微生物和氧化变质风险高，保质期短，冷链要求高，售后成本高。
- 可执行建议：
  - 只在有稳定冷链和短履约半径的城市做，配送时效控制在当日或次日。
  - 明确“开袋即食/需冷藏/建议24小时内食用”，标注切配日期。
  - 小规格试销，先看复购和损耗率，再扩SKU。
  - 切配原料必须和整果分级分开，不能用已过熟或破损果降级处理，否则客诉会反噬主品。

**3. 冷冻原料：适合做补充，不适合做生鲜主推**
- 优点：保质期长、损耗低、适合烘焙/饮品/餐饮场景，履约压力小。
- 关键风险：家庭零售复购弱、客单价低、冷链仓储成本高；和“生鲜”心智不完全匹配。
- 可执行建议：
  - 定位为B端原料或家庭囤货补充，不做首页主推。
  - 优先做餐饮、饮品店、烘焙店的小B渠道，按箱/按袋卖。
  - 家庭端只做搭配销售，比如“冷冻菠萝+酸奶/燕麦”组合，提高客单。

**组合策略**
- 主品：整果，占销量大头，做产地直发和同城次日达。
- 利润品：切配，限城市、限时效，做即食场景。
- 补充品：冷冻原料，走B端或组合装，消化库存和次果。
- 运营上先用整果拉新和复购，再用切配提客单，冷冻做长尾，不要反过来。

**判断标准**
- 如果你冷链弱、履约半径大：只做整果。
- 如果你同城冷链强、用户偏年轻：整果+切配。
- 如果你有B端餐饮客户：整果+冷冻原料，切配谨慎做。
