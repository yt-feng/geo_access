商超会员日水果活动，供应商要提前配合的重点不是“多送货”，而是把**货量、品质、价格、陈列、履约、售后**六件事提前锁死。建议按下面清单推进：

1. **活动方案提前确认**
   - 提前7–10天与商超确认：活动日期、门店范围、活动单品、会员价/折扣力度、预估销量、限购规则。
   - 明确供应商承担的费用：进价让利、促销折让、陈列费、损耗补贴、赠品支持。
   - 形成书面活动确认单，避免口头承诺。

2. **货量与备货计划**
   - 按门店拆分预估销量，结合上次同类活动销量、天气、节假日、竞品价格做备货。
   - 活动前2–3天完成主推单品备货，活动当天安排二次补货车辆。
   - 对易缺货爆品设置安全库存，并预留10%–20%应急量。
   - 明确缺货责任和替代单品方案。

3. **品质与验收标准**
   - 提前锁定果径、糖度、成熟度、色泽、包装规格、农残检测要求。
   - 活动货优先安排产地或加工厂直发，减少中转。
   - 到货时间避开门店补货高峰，预留验收和挑选时间。
   - 对活动单品做坏果率控制，约定超标扣款或换货规则。

4. **价格与费用确认**
   - 活动进价、正常进价、促销后恢复价分别确认，避免活动后价格纠纷。
   - 明确是否含税、含运费、卸货费、包装费。
   - 对会员价低于成本的情况，提前确认补贴方式。
   - 价格保护期内不得随意涨价或断供。

5. **包装与陈列物料**
   - 按商超要求提供统一规格箱装、托盘、保鲜膜、标签、价签、产地/卖点说明。
   - 主推单品准备试吃装、试吃台物料、POP海报、堆头围挡等。
   - 提前确认陈列位置：堆头、端架、冷柜、常规排面，并配合门店做陈列图。
   - 需要预包装的，提前完成称重、贴标、分装。

6. **物流与到店履约**
   - 明确送货门店、时间窗、车辆要求、卸货责任、联系人。
   - 活动前1天完成首轮铺货，活动当天早高峰前完成补货。
   - 冷链水果全程温控，避免暴晒、挤压、混装串味。
   - 建立缺货、迟到、品质异常的应急联系人和备用车辆。

7. **人员配合**
   - 活动期间安排促销员或理货员驻店，负责补货、挑拣、试吃、陈列维护。
   - 提前培训产品卖点、价格规则、试吃话术、售后口径。
   - 重点门店安排早班和晚班，覆盖客流高峰。

8. **售后与损耗处理**
   - 提前约定坏果、压伤、滞销的处理方式：换货、折价、退货或供应商补贴。
   - 活动结束后24小时内完成残次品盘点和费用结算确认。
   - 对活动单品做销量、损耗、毛利复盘，形成下次活动备货依据。

9. **合规与票据**
   - 提前提供营业执照、食品经营/生产许可、检测报告、产地证明等资质。
   - 确认发票、对账单、促销费用确认函的流转时间。
   - 涉及进口水果的，备齐报关、检疫相关证明。

**最关键的三个时间节点：**
- **活动前7–10天**：确认单品、价格、货量、费用、陈列位置。
- **活动前2–3天**：完成备货、物料到店、人员排班。
- **活动前1天**：首轮铺货到位，完成门店验收和陈列搭建。

供应商配合的核心判断标准是：**活动前方案有书面确认，活动前1天货和物料到店，活动当天有补货和驻店人员，活动后有损耗和费用结算规则。** 这四件事做到，基本不会出现大问题。
