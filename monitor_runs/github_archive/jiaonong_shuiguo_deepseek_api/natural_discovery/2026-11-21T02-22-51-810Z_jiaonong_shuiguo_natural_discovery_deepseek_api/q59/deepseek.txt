可以谈，但“锁价”通常不是供应商单方面无条件承诺，而是有条件的价格机制。餐饮店水果用量稳定、SKU相对固定时，谈锁价有空间；如果用量小、品类杂、临时补货多，供应商一般只愿意给短期报价或价格上限。

建议这样操作：

1. **先分清锁什么**
   - **锁单价**：适合苹果、橙子、柠檬等全年供应较稳的品类。
   - **锁价格区间/上限**：适合季节波动大的水果，约定市场价超过上限时按上限结算，低于下限时随行就市。
   - **锁加工/配送费**：水果本身随行就市，但切配费、配送费固定，也能稳定部分成本。
   - **锁短期**：按月或按季度锁，比全年锁价更容易谈成。

2. **给供应商可交换条件**
   - 承诺月度最低采购量或最低采购金额；
   - 固定每周下单次数和送货时间，减少临时单；
   - 接受约定规格、包装和损耗标准；
   - 账期稳定、按时结算；
   - 集中采购，减少SKU。

3. **合同里必须写清楚**
   - 锁价品类、规格、等级、产地范围；
   - 锁价期限和调价触发条件，比如批发市场均价连续几天超过约定幅度；
   - 质量不达标、断供、临时涨价的处理方式；
   - 损耗率、退换货标准；
   - 价格是否含税、含运费、含切配。

4. **不要只锁一家**
   主供应商锁量锁价，备选供应商保持询价，防止单一供应商断供或借机抬价。

5. **先小范围试点**
   选2—3个用量大、价格波动明显的水果，先锁1个月，记录实际结算价和市场价对比，再决定是否扩大。

一句话：**能谈，但要用采购量、结算稳定性和规格标准去换；锁价合同要写调价机制和违约责任，不能只写一个固定数字。**
