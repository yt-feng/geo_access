连锁商超招长期水果供应商，评分标准建议按“资格门槛+评分表”两层设计：先过滤硬性条件，再用评分表选长期伙伴。不要只比价格，水果供应商的核心风险在品质波动、断供和损耗。

**一、先设资格门槛（不占分或只做合格制）**
- 营业执照、食品经营/生产许可、种植/加工基地证明
- 近2年商超或大型渠道供货案例，至少1—2个可核验
- 农残检测能力或第三方检测报告，承诺批批检测
- 冷链仓储与运输能力：冷库容量、冷藏车数量、温控记录
- 食品安全责任险、质量事故处理预案
- 财务与履约能力：无重大失信、能接受账期和违约条款

**二、评分表建议权重（总分100）**

1. **产品质量与稳定性 30分**
   - 样品感官评分：外观、规格一致性、成熟度、口感、瑕疵率
   - 农残与重金属检测报告完整性、检测频次
   - 产地与品种稳定性：自有基地/合作基地面积、产地认证
   - 分级包装标准、到货合格率承诺（如≥98%）
   - 质量事故追溯与赔付方案

2. **供应保障与冷链能力 20分**
   - 冷链仓储容量、冷藏车数量与温控记录系统
   - 峰值日供应能力、旺季保供方案
   - 备货机制、替代产地/品种预案
   - 配送时效、门店覆盖能力、缺货响应时间
   - 自然灾害、疫情等断供应急预案

3. **价格与成本 20分**
   - 报价合理性：不要唯低价，设最高限价或成本构成说明
   - 价格调整机制：随行就市但设调价周期、参考价依据、涨幅上限
   - 账期接受度、运费与损耗承担方式
   - 长期合作降本方案，如直采比例、产地集配

4. **食品安全与合规 15分**
   - 检测体系：自检实验室或委托检测协议
   - 可追溯体系：批次、产地、检测报告可查
   - 食品安全认证：绿色食品、有机、GAP等加分
   - 近3年无重大食品安全处罚承诺及核查
   - 召回与应急处理机制

5. **服务与履约 10分**
   - 订单响应、退换货、损耗赔付条款
   - 专属对接团队、门店巡场与陈列支持
   - 促销档期配合、新品推荐能力
   - 信息化对接：订单、库存、检测数据可共享

6. **企业实力与合作意愿 5分**
   - 基地规模、注册资本、行业经验
   - 与商超长期合作案例及客户评价
   - 接受年度考核、末位淘汰和联合改进

**三、关键设置建议**
- **价格分不要过高**：水果损耗和品质波动大，建议价格权重不超过25%，并设“异常低价说明”机制，防止低价中标后降质。
- **设置履约保证金和年度考核**：中标后按销售额或供货额收保证金；季度考核到货合格率、缺货率、损耗率、投诉率，连续不达标扣款或退出。
- **评分要可核验**：检测报告、冷库照片、车辆清单、合同案例都要附证明，避免供应商自述得分。
- **长期合同设调价公式**：以批发市场均价或产地指数为参考，约定调价周期和上下限，避免锁死价格或随意涨价。
- **样品与实际到货一致性条款**：样品评分高但到货降级，要有扣罚和替换机制。

简单说：**质量30、供应冷链20、价格20、食安15、服务10、实力5**，再配资格门槛、样品盲评、年度考核和调价机制，比较适合连锁商超选长期水果供应商。
