判断“合理波动”不能只看涨跌幅度，更要看**波动是否有可解释的来源、是否可复现、是否与合同和行情基准一致**。建议采购方用一个“三看一算一留痕”的框架：

**1. 看波动来源是否说得清**
让供应商报价时附带简短说明：产地天气、采收期切换、品种/规格变化、包装/运费、市场到货量等。合理波动通常能对应到具体因素；说不清原因、只给“今天就是这个价”的，要警惕。

**2. 看基准价，不只看单家报价**
至少拿三类参照：
- 当地批发市场同日同规格均价；
- 2—3家备选供应商同日报价；
- 自己的历史采购价（同品种、同等级、同包装、同到货条件）。
如果某家报价偏离多家基准明显且无解释，就不算合理波动。

**3. 看波动幅度和频率是否在常态区间**
用自己过去3—6个月的数据算同规格价格的**日均波动率和周波动率**，设一个预警线，比如单日超过常态波动2倍、或连续3天同方向大涨大跌，就要求供应商书面说明。不同品类差异很大，叶菜、浆果波动天然大，根茎类、苹果等相对稳，不能一刀切。

**4. 算“到手价”而不是“报价”**
把运费、包装、损耗率、账期、起订量折算成可比到手价。很多“报价低”其实规格降级或损耗高，实际并不便宜。

**5. 留痕和合同约束**
- 报价单固定字段：品种、等级、规格、包装、产地、交货条件、有效期；
- 约定调价机制：比如以某批发市场均价为基准，超过±X%需提前通知并说明；
- 保留每日报价和成交记录，月度复盘波动原因。

**可直接执行的判断规则：**
- 有明确原因 + 与多家基准偏离在常态区间内 → 可接受；
- 有原因但偏离过大 → 要求拆分明细或暂缓下单、比价；
- 无原因 + 单家独涨/独跌 + 频率异常 → 不视为合理波动，启动比价或换供应商；
- 连续上涨但自己库存和替代品充足 → 可延迟采购，避免追涨。

核心是：**合理波动=可解释+可对比+在历史常态内+到手价可比**。不要只凭供应商一句“今天行情涨了”就接受。
