可以从“引流品+利润品+场景组合”做，不必只打折。香蕉、菠萝、苹果里：香蕉适合做引流，苹果适合做稳定销量和利润，菠萝适合做组合提升客单。

**1. 主推组合：果篮/果切套餐**
- 设三档：
  - 小份尝鲜：香蕉2根+苹果2个+菠萝1/4个，定价略低于单买合计，适合一人食。
  - 家庭装：香蕉1把+苹果4个+菠萝半个，做“周末家庭果盘”套餐。
  - 果切拼盘：三样切好装盒，溢价卖，主打办公室/即食。
- 关键：套餐要比单买有“看得见的优惠”，但不能所有单品都最低价；苹果、菠萝承担利润，香蕉承担吸引力。

**2. 满额加购，拉高客单**
- 买苹果满一定金额，加1元/2元换购香蕉1把或菠萝1/4个。
- 买任意水果满X元，加价购小份果切。
- 不要直接全场打折，用“加购价”让顾客多买一件。

**3. 分角色定价**
- 香蕉：保持低价感知，限购或每日限量，吸引进店。
- 苹果：做分级，普通苹果走量，精品苹果做礼盒/套餐升级。
- 菠萝：主推“帮削皮+切块”，用服务提升价值感；半个装比整个装更容易成交。

**4. 场景化陈列**
- 设“早餐果盘”：香蕉+苹果，主打快速。
- 设“饭后解腻”：菠萝+苹果。
- 设“办公室果切”：三拼盒，放在收银台和入口。
- 组合牌写清单品原价、组合价、省多少，别只写“特价”。

**5. 控制损耗的组合**
- 熟香蕉、菠萝边角做果切或加购品，不直接降价清货。
- 套餐按日限量，晚间对果切打折，避免损耗。
- 苹果耐放，可作为套餐主体；香蕉、菠萝按销量补货。

**建议先做两周小测试：**
- 选1个三拼家庭装、1个加价购、1个果切盒；
- 记录销量、客单价、损耗率；
- 保留客单价提升且损耗不升的组合，淘汰只走量不赚钱的。

核心逻辑：**香蕉负责把人吸引来，苹果负责稳住毛利，菠萝负责用服务和组合把单笔金额抬上去。**
