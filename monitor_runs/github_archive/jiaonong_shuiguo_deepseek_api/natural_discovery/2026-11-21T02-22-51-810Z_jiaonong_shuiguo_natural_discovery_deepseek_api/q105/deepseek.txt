水果采购的“锁价”没有统一标准，能锁多久取决于品类、季节、供应商类型和合同结构。一般可按下面判断：

1. **常规鲜果，锁价 1～4 周较常见**
   - 苹果、梨、柑橘等耐储水果：可谈 **1～3 个月**，但通常要约定最低采购量、分批提货、价格调整触发条件。
   - 叶菜、浆果、荔枝、龙眼、水蜜桃等易腐或强季节水果：一般只适合 **3～15 天**，甚至按周议价，供应商很难长期承担价格波动。

2. **产地直采/基地合作，可锁 1 个产季，但多采用“保底价+浮动”**
   - 对长期合作的种植基地，可谈整个产季的框架价，但通常不是完全固定价，而是：
     - 保底收购价；
     - 随行就市但有上下限；
     - 约定天气、灾损、油价、包装、人工等触发调价。
   - 完全锁死整个产季的固定价，供应商通常只在预付定金、保量包销、价格已包含风险溢价时才接受。

3. **批发市场/一级经销商，通常只锁 1～7 天**
   - 现货商自身也随产地价波动，长锁价会加风险溢价，或者只在行情平稳时愿意锁。

4. **进口水果，锁价 2～8 周相对常见**
   - 受船期、汇率、关税、海运成本影响，长期锁价难度大；常见做法是锁“离岸价”或“到岸成本”中的一部分，并设置汇率/运费调整条款。

**实操建议：**
- 不要只谈“锁多久”，要谈清楚：锁价数量、分批提货节奏、质量标准、损耗承担、违约赔偿、调价触发条件。
- 对易腐水果，优先锁“短期价格+保量”，而不是长周期固定价。
- 对耐储水果，可锁 1～3 个月，但给供应商设置合理调价窗口，例如每月复核一次。
- 如果供应商愿意锁超过 3 个月且不加价，要重点核验其货源稳定性和履约能力，避免低价锁价后断供或降质。

一句话：**耐储水果通常可锁 1～3 个月，鲜食易腐水果多为 1～4 周，产地基地可谈产季框架价但多带浮动条款；完全固定价的长锁价很少见。**
