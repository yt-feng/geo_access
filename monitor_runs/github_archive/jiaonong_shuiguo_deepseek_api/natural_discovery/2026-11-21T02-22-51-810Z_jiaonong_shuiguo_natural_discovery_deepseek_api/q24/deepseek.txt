建议先要“能对上批次和检测项”的书面材料，而不是只要一张合格证。可按下面清单向供应商索取，并在采购合同/验收标准里写明：

1. **批次对应资料**
   - 供货批次号、采摘/包装日期、产地、供应商名称。
   - 要求检测报告上的样品名称、批次/生产日期、供应商与到货批次能对应；只给“某水果合格”的通用报告参考价值低。

2. **农残检测报告**
   - 优先要**第三方检测机构出具**的检测报告，查看：
     - 检测机构资质（CMA；有CNAS更好但不是必须）；
     - 检测项目是否覆盖常见高风险农药及你关注的重点；
     - 检测依据标准（如GB 2763）；
     - 报告编号、签发日期、样品批次；
     - 结论是否为“合格”。
   - 若供应商只有自检，要求提供自检记录和委托第三方抽检计划；自检不能替代第三方报告。

3. **产地与种植管理资料**
   - 产地证明/供货证明、种植基地或合作社信息。
   - 农药采购和使用记录（尤其近期用药记录）、安全间隔期执行记录。
   - 有条件的要**承诺书/质量保证书**：承诺按安全间隔期采收、不采购禁用农药。

4. **供应商资质与追溯材料**
   - 营业执照、食品经营/生产相关许可（按业态）。
   - 进货查验记录、上游供货商和产地信息，确保可追溯。
   - 包装标签、承诺达标合格证（如适用）。

5. **验收与抽检约定**
   - 合同中写明：到货随批提供检测报告或合格证明；超市有权按批次抽检；不合格的退货、复检、赔付和责任承担。
   - 对高风险品种或新供应商，要求**到货前预检/到货批批检**，并约定抽检频率。

实操上：先要“**该批次第三方农残检测报告 + 批次追溯信息 + 质量承诺**”；资料对不上批次就要求补检或换货。不要只看供应商口头保证或一张无批次信息的复印件。
