要固定，但“固定”的重点不是死守一个产地，而是固定一套可复现的品质标准，并尽量固定供应渠道和批次管理。

具体建议：

1. **优先固定供应渠道，而不是单押一个产地**
   - 和1–2家稳定供应商签合作，要求其按你的水果用途分级供货。
   - 单一产地遇到减产、雨季、价格波动时容易断供，建议“主供应商+备用供应商”。

2. **对关键水果固定品种、等级和成熟度**
   - 口味波动更常来自品种、成熟度、采摘期，而不只是产地。
   - 采购规格写清楚：品种、单果重量/糖度范围、成熟度、瑕疵率、冷链要求。

3. **按批次验收，建立批次记录**
   - 每批记录产地、供应商、采摘/到货日期、糖度、酸度、外观、试饮结果。
   - 设定可接受范围，例如糖度、酸度、出汁率、香气；超出范围就降级使用或拒收。

4. **配方端做“弹性标准化”**
   - 设定基准确口味，再根据每批水果糖酸度微调糖浆、酸度或水果用量。
   - 对波动大的水果，开发2–3个替代品种或拼配方案，避免门店口味大起大落。

5. **不要过度固定到“单一批次”**
   - 同一产地不同批次也可能差异大；固定批次不现实，除非是季节性短供。
   - 更可行的是：固定供应商+固定规格+批次验收+配方微调。

结论：**要固定供应渠道和品质规格，批次要管但不必死守；主供+备用、验收标准、试饮微调三者配合，才能稳住水果口味。**
