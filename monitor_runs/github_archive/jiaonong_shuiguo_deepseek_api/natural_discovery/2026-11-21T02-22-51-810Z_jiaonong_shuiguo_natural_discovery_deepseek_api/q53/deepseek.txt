优先找**本地水果批发商/配送商做“日配”**，比你自己每天去批发市场或找大平台更省心。按优先级给你一个可执行选择：

1. **本地水果批发市场的固定档口/配送商（最推荐）**
   - 适合每天少量、品类杂的餐饮店。
   - 选有“餐饮客户日配”经验的档口，谈好：每天几点前送到、最低起送量、缺货替代规则、坏果包赔、月结/周结。
   - 省心点：固定一家主供 + 一家备用，避免单一供应商断货。

2. **本地生鲜配送平台/餐饮供应链公司**
   - 如当地做餐饮B2B的生鲜配送商，通常可日配、可开票、售后相对规范。
   - 缺点是少量配送可能有起送门槛，价格略高。
   - 适合你不想每天沟通、要稳定票据和售后的店。

3. **大型商超/水果连锁的团购或固定采购**
   - 只适合应急或补充，不适合作为主供：少量可以，但日配稳定性和价格通常不如批发商。

4. **产地/果园直供**
   - 不建议作为“每天少量水果”的主渠道。量小、品类少、物流和售后麻烦，除非你有稳定大单品需求。

**选供应商时重点问清 6 件事：**
- 是否支持每天少量配送，起送量多少；
- 固定送达时间，迟到怎么处理；
- 坏果/烂果包赔比例和拍照报损流程；
- 缺货时是否自动替换，替换前是否确认；
- 价格是随行就市还是按周报价；
- 结算方式：现结、周结还是月结。

**最省心的组合：**
一家本地批发档口做主供，负责每天少量日配；一家本地生鲜配送平台做备用；自己只保留 1 个对接人，每天前一天下午发次日清单，早上收货拍照验收。
