会增加，而且香蕉和菠萝的损耗风险对起订量尤其敏感，原因不同：

**香蕉**
- 后熟快、货架期短，批量到货后集中转熟，销售端消化不掉就会集中发黑、软烂。
- 起订量高通常意味着单次到货多、批次少，催熟进度难拆分，容易出现“前一批还没卖完，后一批已经过熟”。
- 机械伤和温度波动在大批量堆码时更明显，会加速损耗。

**菠萝**
- 整果耐储性比香蕉好，但起订量高会带来集中成熟、集中切口/去皮加工压力；切开后货架期很短。
- 大批量堆码易发生压伤、碰伤，伤果很快腐烂并传染。
- 若以整果销售为主，损耗相对可控；若涉及鲜切，起订量高会显著放大加工端损耗。

**判断建议**
1. 用“日均销量 × 补货周期 + 安全库存”反推合理起订量，而不是按供应商最小起订量硬吃。
2. 香蕉重点看：到货成熟度、可分批次催熟/上架的能力、单批可售天数。若单批可售天数接近或超过货架期，起订量就偏高。
3. 菠萝重点看：整果与鲜切比例、堆码和搬运条件。鲜切占比越高，越应压低单次到货量。
4. 起订量降不下来时，优先谈“分批到货”“多频次小批量”“成熟度分级”，比单纯压库存更有效。
5. 设一个简单阈值：若预计损耗率上升带来的损失 > 起订量带来的单价优惠，就应降低起订量或改分批。

结论：**会，香蕉比菠萝更敏感；起订量高会通过集中到货、集中成熟、堆码压伤和加工压力放大损耗。** 建议按销量反推起订量，并优先争取分批到货和成熟度分级。
