# 连锁超市降低门店坏果率：合同赔付条款设计

坏果率问题本质上是**损耗责任在供应链各环节的分配问题**。合同约定要解决三件事：**谁承担、按什么标准算、怎么兑现**。以下按可落地的条款结构给出建议。

## 一、先明确"坏果"的判定标准（最容易被忽略、最易引发纠纷）

赔付条款能否执行，取决于验收标准是否可量化、可当场判定：

- **分级定义**：明确"坏果"的边界（腐烂、霉变、机械伤、软化、异味等），并约定是否包含"瑕疵果"（外观缺陷但可食用）。建议把"可接受瑕疵率"和"不可接受腐烂率"分开设阈值。
- **抽检规则**：约定抽检比例（如每批次按箱数或重量随机抽 5%–10%）、抽检时点（到店验收时/卸货时）、判定主体（门店收货员+供应商代表共同确认，或第三方）。
- **拍照留证与时限**：约定验收异议须在到货后 X 小时内提出并附影像，超时视为验收合格。这既保护超市，也避免供应商被"事后追责"。
- **标准依据**：尽量引用国家标准或行业标准（如鲜果类相关质量等级标准），没有适用标准的，在合同附件中自建分级表并附参考图片。

## 二、赔付方式：三种机制组合使用

单一"按坏果重量扣款"往往不够，建议组合：

1. **质量扣款（按批次结算）**
   - 设定阶梯：坏果率 ≤ 阈值A（如3%）正常结算；阈值A–B（如3%–8%）按超出部分重量×单价扣款；>B（如8%）整批拒收或按折价率结算。
   - 注意：扣款基数要写清是"该批次货款"还是"坏果对应货值"，避免歧义。

2. **补货/换货义务**
   - 约定坏果率超标时供应商须在 X 小时内补足合格货品，补货产生的物流费用由供应商承担。
   - 明确"补货不免除已发生的门店损失赔偿责任"。

3. **门店端损失赔偿（这是降坏果率的关键）**
   - 坏果导致的**门店端二次损失**（如陈列损耗、客诉赔偿、下架处理费、冷链电费分摊）应约定由供应商按比例承担，可设"每批次赔偿上限"控制争议。
   - 对高频超标供应商设**违约金/保证金扣减**条款（如月度坏果率累计超标扣履约保证金）。

## 三、把"激励"写进合同，而不只是罚

只罚不奖容易导致供应商把好货优先给别家、或验收环节扯皮。建议：

- **阶梯返利/价格联动**：月度坏果率低于目标值的供应商，给予返点或下月优先采购量。
- **考核周期与退出机制**：按周/月统计坏果率，连续 N 期超标触发警告、降级、暂停供货直至解约，标准写进合同附件。
- **数据口径统一**：约定坏果率以超市系统（WMS/收货系统）记录为准，或双方签字的验收单为准，避免"各算各的"。

## 四、几个容易埋雷的细节

- **运输与储存责任划分**：明确"到店前"损耗归供应商，"到店验收合格后"因超市储存不当产生的损耗归超市。冷链断链责任要有温度记录佐证。
- **不可抗力与自然损耗**：鲜果天然有呼吸损耗，建议约定一个"自然损耗率"不计入坏果考核，否则供应商会通过抬价转嫁。
- **争议解决与举证**：约定抽检留样保存期限（如48小时）、争议时以留样复检为准。
- **与采购价联动**：坏果率目标应与采购价挂钩——低价采购往往对应高损耗，合同应写明"目标坏果率对应的价格档位"，避免用低价货要求高标准。

## 实操建议

条款落地前，建议先用 1–2 个月历史数据测算各品类的**实际坏果率分布**，据此设定阈值和阶梯，避免标准定得过严导致供应商拒签或暗中抬价。同时把赔付条款与**供应商分级管理**打通，让坏果率成为供应商准入、份额分配的核心指标，而不只是财务扣款工具。
