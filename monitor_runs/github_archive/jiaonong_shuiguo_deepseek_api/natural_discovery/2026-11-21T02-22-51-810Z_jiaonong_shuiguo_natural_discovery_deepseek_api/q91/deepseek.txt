建议把三种包装都纳入试销，但**主推小把装**，单根和整袋作为补充。判断依据可以按便利店的核心约束来定：

### 1. 小把装（3–5根）作为主推
- **最匹配便利店购买场景**：即时消费、1–2人份、当天吃完，决策成本低。
- **客单价和损耗平衡较好**：比单根有更高客单，又不像整袋那样容易吃不完。
- **陈列效率高**：一把一目了然，方便快速拿取。
- **适合做价格锚点**：可设“单根价”和“小把优惠价”，引导买小把。

### 2. 单根作为补充，不建议做主力
- 优点是**试吃门槛低、适合搭配早餐/酸奶/临时加餐**。
- 缺点是**损耗和人工管理成本高**：反复挑拣、断柄、称重或贴标都麻烦；客单价也低。
- 如果门店在写字楼、交通枢纽、学校附近，单根可以保留少量，放在收银台或早餐组合里。

### 3. 整袋谨慎上，适合特定门店
- 整袋适合**家庭客群、社区店、下班顺路采购**，客单价高。
- 但便利店主流是即时消费，整袋容易造成**库存压力和熟度损耗**。
- 若上整袋，建议选小规格（如5–6根），并明确“家庭装/分享装”，不要和大卖场比价。

### 可执行的试销方案
- **第一轮（2–3周）**：三种都上，但陈列比例为小把70%、单根20%、整袋10%。
- **观察指标**：日均销量、损耗率、毛利率、缺货率、顾客拿取后放回率。
- **动态调整**：小把卖得动就扩到80%；单根只在早高峰或收银台做加购；整袋若周损耗超过10%就下架或改为预订。
- **定价**：单根价略高，小把体现“多买一点更划算”，整袋按家庭装定价但不要低于小把折算价太多，避免自我竞争。
- **鲜度管理**：香蕉按成熟度分两批陈列，青一点做后备库存，黄熟的主陈列，过熟及时做折扣或加工成果切/奶昔原料。

**结论：以3–5根小把装为主，单根做场景补充，整袋小规格试销；用2–3周数据决定最终结构。**
