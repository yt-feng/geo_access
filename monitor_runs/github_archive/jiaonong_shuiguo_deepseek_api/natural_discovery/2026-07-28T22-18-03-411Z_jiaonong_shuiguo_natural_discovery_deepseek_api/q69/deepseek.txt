为了帮助批发商和水果店之间清楚沟通报价，建议采用以下分级标准来定义香蕉和菠萝的“等级”，并建立对应的报价规则。

### 一、香蕉分级报价参考

香蕉分级主要依据：**成熟度、果指大小、果皮外观、是否有机械伤或病害**。

| 等级 | 核心特征 | 报价建议（举例） |
| :--- | :--- | :--- |
| **精品/特级** | 果指长度≥18cm，果形均匀，表皮金黄无瑕，无斑、无擦伤，成熟度7-8成（适合立即零售或3天内卖完） | 基准价 + 0.3~0.5元/斤 |
| **一级** | 果指长度15-18cm，允许少量轻微黑点（如梅花点），无严重压伤，成熟度7-8成或5-6成（按需标注） | 基准价 |
| **二级** | 果指长度12-15cm，有少量表皮轻微划伤或灰霉斑，不影响果肉，成熟度可混搭（需标注“熟得快”或“青皮”） | 基准价 - 0.2~0.4元/斤 |
| **处理级/特价** | 果指小于12cm，有较多黑斑、裂口或轻微水烂，需当天或隔天销售，或用于加工（如甜品店）。**批发商议价，通常按箱/袋出** | 按箱统货价（如：50元/箱） |

**报价话术示例：** “这批香蕉是**一级**，长度16-20cm，7成熟，适合本周卖，按**2.5元/斤**走，整箱不称，3箱起送。”

---

### 二、菠萝分级报价参考

菠萝分级主要依据：**大小（重量）、果形、成熟度（颜色）、糖度预估、产季（春季/夏季价格差异大）**。

| 等级 | 核心特征 | 报价建议（举例） |
| :--- | :--- | :--- |
| **特级/大果** | 重量≥2斤/个，果形端正（圆柱形或短筒形），果眼浅，果皮金黄或浅黄（八成黄以上），无软弱、无霉点，切面呈蜜黄色，**糖度≥12%**（可标注） | 单个价或按斤价上浮10~15%（如：4.8元/斤） |
| **一级/中果** | 重量1.5-2斤/个，果形基本端正，果眼稍深但均匀，果皮黄绿相间（五六成黄），允许轻微果斑（如日灼斑长<2cm），**糖度10-12%** | 基准价（如：4.2元/斤） |
| **二级/小果** | 重量1-1.5斤/个，果形有轻微畸形或偏椭圆形，果眼较深（去眼后损失率稍高），果皮偏青，可按“熟度-颜色”再细分（如：青果 / 微黄果），**糖度8-10%** | 基准价下浮15~20%（如：3.5元/斤） |
| **次品/特价** | 裂果、软烂、严重畸形、黑心病风险高（如：冷藏过久），**仅按个或论袋、论堆卖**，不按斤称。需明确标注“需当天售完”或“加工用” | 定价极低（如：10元/5个） |

**报价话术示例：** “这批菠萝是**一级中果**，单果约1.7-2斤，七八成黄，果眼浅，果味足，按**4.2元/斤**，一箱约20斤，整箱拿价同。”

### 三、更清晰的报价方式建议（让小店老板一眼看懂）

1. **制作分级清单（或微信发图）**：直接标注“【今日报价】香蕉：特级2.8，一级2.5，二级2.2；菠萝：特级4.8，一级4.2，二级3.5”。 同时标注“品控标准”链接或图片参考。

2. **尽量使用“可观察、可测量”的标准**：
   - 🍌香蕉：强调“**果指长度**”和“**成熟度颜色**”（如：果指长17cm以上，皮色黄亮无黑斑）。
   - 🍍菠萝：强调“**单果重量区间**”和“**果皮着色面积**”（如：1.8-2.2斤，金黄占70%以上）。

3. **提供“等级转换”弹性规则**： 如果小店老板觉得某一等级价格偏高但想压价，可说明：“您要的批量如果超过x箱，可以给二级价调一级货”；或者“这批一级果如果放两天卖不动，可以按二级价补给您甜度降低的下一批货”。

4. **重点用“可售天数”辅助分级**： 批发商可以主动告知：“特级货适合马上上架，一级货可以冷藏多放2天，二级货要快进快出。” 这对水果店规划库存极有帮助。

---

### 四、最后一句总结

**香蕉看长短、熟度皮色；菠萝看大小、果眼深浅和着色面积。** 报价时写“级别+重量/长度范围+成熟度颜色+建议零售时长”，比单纯报“一级”或“好/中/差”清晰百倍。
