选择超市香蕉时，避免过生或过熟的关键是观察颜色、硬度和细节。以下是可执行的具体方法：

1. **看颜色**：选择**黄色为主、带少量浅绿色**的香蕉。全青的偏生，可能需放几天；出现大面积褐色斑点的已过熟，适合即食或做甜点，不耐存储。
2. **摸硬度**：轻轻捏香蕉中部，**微软且有弹性**代表刚好成熟。太硬则生，太软或一按凹陷则过熟。
3. **检查果柄和尾部**：果柄仍呈绿色说明新鲜，发黑或干枯则存放过久。尾部果肉若变软或发黑，内部可能已变质。
4. **观察果皮**：没有明显擦伤、霉斑或裂口。轻微褐斑是成熟标志，但大块黑色或软塌处说明内部受损。
5. **按需求选择**：如果计划2天内吃，选全黄无斑点的；若想放更久，可挑带微青的；如需当天食用，选带少量褐点或香味浓郁(而非发酵味)的。

**实用建议**：在超市货架前，优先选中间一层的香蕉（通常周转快，更新鲜）。如果遇到成串香蕉，留意最里面或底部的几根，它们可能更绿或更软，更能代表整串的成熟度差异。
