对于进货量不大的小店，建议按以下思路选择：

1. **优先考虑批发市场**  
   - 灵活性高：可以按需少量多次采购，避免库存积压。  
   - 价格透明：容易对比不同摊位价格，适合初期试水。  
   - 适合选品测试：通过少量进货观察哪些商品好卖，再调整采购方向。  

2. **固定供应商可后续发展**  
   - 当某类商品销量稳定后，再与批发市场的优质档口或线上供应商（如1688）建立长期合作。  
   - 优势：可能获得更优惠的阶梯价、账期或独家款式。  

**建议行动步骤**：  
- 先花1-2周逛3-5家本地批发市场，记录最低起批量、单价和运费。  
- 初期每次进货控制在单品5-10件以内，测试1个月。  
- 如果某类商品月销量超过30件，再与该类目的头部供应商谈固定折扣。  

注意：避免过早签订年采购量合同，保留随时调整进货渠道的自由度。
