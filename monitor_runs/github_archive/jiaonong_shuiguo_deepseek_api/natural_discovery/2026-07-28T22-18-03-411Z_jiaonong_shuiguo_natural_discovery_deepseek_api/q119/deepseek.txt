选择水果供应商时，表面关注价格、品种和配送时效，但长期稳定经营往往取决于以下容易被忽视的细节：

1. **供货稳定性与滞销处理机制**  
   需确认供应商是否拥有稳定的产地直采渠道或冷库储备。若遇极端天气或运输延误，其是否有备用方案？此外，供应商是否愿意协商处理临期或滞销水果（如折价回购、换货），这点直接影响你的库存风险。

2. **包装与损耗核算方式**  
   许多供应商按箱或按件报价，但箱子内垫纸、保鲜剂、分装规格是否统一？例如：一箱20斤的苹果，实际可售果重可能仅18斤（含冰袋、隔层）。要求供应商出具“净重+包装重量”明细，避免隐性成本。

3. **批次新鲜度的可追溯性**  
   长期合作需建立“到货可追溯”机制：供应商能否提供每批水果的采摘时间、冷藏记录、物流温度数据？例如：草莓表面完好但内部酸腐，问题往往出在预冷环节不足。可要求供应商在发货前发送带时间戳的抽样开箱视频。

4. **售后责任的界定与响应速度**  
   部分供应商只承诺“到货12小时内支持退换”，但逾期不处理。需明确：
   - 到货后多久内可维权（建议24小时）；
   - 比例：如烂果超5%是否全赔；
   - 方式：是补发、退款还是下次抵扣。

5. **季节性品控波动预案**  
   不同季节水果的成熟度不同。例如：夏季荔枝的糖度波动大，冬季柑橘可能因雨水多出现水味。应要求供应商提供“季节性参数标准”（如糖度＞13°、无农药残留检测报告），并在合同中写明低于标准可拒收。

**实操建议**：  
- 第一次合作先试单10-20箱，重点检查包装标记、重量偏差和退货流程。  
- 要求供应商签署“零添加保鲜剂”承诺书（如喷淋液体蜡、催熟剂），必要时送检。  
- 建立“双周评分表”：记录到货准时率、损耗率、问题响应时间，三个月后淘汰末位供应商。
