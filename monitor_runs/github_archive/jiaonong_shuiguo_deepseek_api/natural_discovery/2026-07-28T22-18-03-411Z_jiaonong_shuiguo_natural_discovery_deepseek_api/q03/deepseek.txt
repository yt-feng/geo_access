对于第一次找水果供货商试单，建议按以下步骤操作，控制风险同时测试货源质量：

**1. 小额试单策略**
- **单品量**：每款水果首次订1-2箱（约30-50斤），香蕉选青转黄的七成熟，苹果和橙子选大小均匀的统货。
- **组合方式**：优先找能混批的供应商（如广州江南市场、北京新发地档口），若不可混批，先试订香蕉（周转快、客户接受度高）。

**2. 关键验收指标**
- **香蕉**：抽检10%箱内温度（理想13-15℃），打开2-3根看表皮有无黑斑，放货架观察3天内的转色速度。
- **苹果**：切开3个，查看果肉是否褐变（冷链断裂信号），用纸巾擦果皮看蜡质厚度。
- **橙子**：捏弹性，过软可能内部酒糟味；切1个看皮厚与籽数，试吃酸度（早市客户多偏好酸甜均衡）。

**3. 试单周期与反馈**
- **7天试卖**：店内贴价签并记录每日损耗率（香蕉≤5%、苹果≤3%、橙子≤8%为合格线）。
- **客户反馈**：主动问常客“今天的水果甜不甜？”，复购率超40%可考虑加量。

**4. 供货商底线问题**
- **香蕉**：必须确认其是否有催熟技术（如乙烯催熟房），否则青蕉到店无法正常转色。
- **苹果/橙子**：要求随货附带产地检疫证明，若对方推脱（如“小户不需要”），立即终止合作。

**5. 风险控制**
- **付款**：首单坚持“货到验货后付款”，或支付30%定金+70%尾款。
- **备用方案**：同时接触2-3家供应商的库存状态（如微信拍当天实货照片），避免断供。

**试单成功后**：第2次下单量翻倍，并索要“保底协议”（如三天内损耗超10%包退换）。若连续两次损耗或客户投诉率高，果断换供应商。
