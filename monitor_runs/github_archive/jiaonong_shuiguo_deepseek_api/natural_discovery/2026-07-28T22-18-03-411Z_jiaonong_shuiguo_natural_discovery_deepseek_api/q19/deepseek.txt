建议优先关注**切果损耗**，其次是**甜度**，外观和大小可作为辅助参考。具体原因如下：

1. **切果损耗**（核心）：超市销售菠萝通常需现场削皮切块，损耗直接影响利润。皮厚、眼深、形状不规则的菠萝可食用部分少，若按重量销售会拉高实际成本。应选择果形圆整、眼浅、表皮光滑的品种（如都乐金菠萝、台农17号等），减少浪费。
   
2. **甜度**（关键卖点）：顾客购买决策常取决于口感。可通过以下方式评估：
   - 按产区（如菲律宾金菠萝甜度稳定）；
   - 按压果肩（弹性好表示成熟度高）；
   - 闻底部香气（浓郁有甜味信号）。
   建议小批量试切试吃，验证后大批进货。

3. **外观**（次要）：正常偏黄、略带青斑可接受，但避免深褐色、发软或霉斑点——这会影响货架期和顾客信任。

4. **大小**（最末位）：除非针对特定客群（如家庭装需要大果），否则中等个头（1~1.5kg）更易分割，且价格敏感度较低。

操作建议：
- 进货前先试切1~2个菠萝，测量可食用比例（果肉重量/原果重量），确保损耗低于35%；
- 在明显位置标注“当天现切”“可试吃”，提升甜度吸引力；
- 外观略青的菠萝可降价促销，搭配“买后放置2天更甜”提示。
