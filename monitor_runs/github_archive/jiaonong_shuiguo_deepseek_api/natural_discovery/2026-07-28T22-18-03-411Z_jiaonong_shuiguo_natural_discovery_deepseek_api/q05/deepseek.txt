建议根据目标顾客和利润模型灵活选择，但最优策略是 **“准备好去皮果肉作为主推，同时保留整果满足DIY需求”**。以下是具体分析和操作建议：

### 1. 核心判断标准：场景与顾客
- **整果（带皮）**：适合**注重新鲜感、家庭食用、有处理经验**的顾客。优点：顾客亲手挑，视觉新鲜度高；缺点：购买后需自行削皮，耗时且可能削坏。  
  **适用场景**：菜市场、社区店、追求“所见即所得”的顾客。
- **去皮果肉（保鲜盒/袋装）**：适合**即食性需求强、年轻上班族、怕麻烦**的顾客。优点：开袋即食，消耗快，单价更高；缺点：保质期短，需控制损耗。  
  **适用场景**：商场、便利店、外卖渠道、面向白领和学生的区域。

### 2. 利润与损耗分析  
- **整果**：单位价格较低（因含皮/芯），但损耗风险小（可延售）。  
- **去皮果肉**：高毛利（通常每斤去皮后的菠萝售价=整果价格的1.5-2倍）。但**剥皮损耗率达30%-40%**，且需快速售出（常温下2-4小时变味）。  
  **计算示例**：整果进价5元/斤，剥皮后出肉率60%，则去壳成本约8.3元/斤。若售价12元/斤，毛利润约44%，整果售价8元/斤则毛利仅37.5%（且顾客需自行付出削皮成本）。

### 3. 实操建议（优先执行项）  
- **混合模式**：  
  - **主推去皮果肉**（占陈列70%），用透明盒+插签展示，标价清晰（如“即食菠萝肉15元/盒”），搭配水果切或酸奶杯增值。  
  - **整果作为补充**（占20%），贴“自己削更甜”的引导标签，**注意：必须预留10%的整果用于表皮损坏时当场削价处理**。  
- **陈列细节**：  
  - 去皮果肉放在冰台或冷藏柜（4-8℃），插“现切1小时”标签强化新鲜感。  
  - 整果标价低于去皮后的每斤单价约15-20%（例如：整果8元/斤，去皮果肉15元/盒（净重约0.8斤））。  
- **应变策略**：  
  - **高峰时段**（午休、下班）：多做去皮准备，勤补货。  
  - **低峰时段**（晚间）：减少去皮量，促销整果（如“买一送一”或“满减”）。

### 4. 风险提示  
- 避免**全做去皮**：一旦剩货，次日无法整果出售。每天按当日预估销量的40%准备去皮，剩余保留整果。  
- 保证去皮流程卫生（戴手套、使用消毒刀），避免引发食安投诉。

### 总结  
> **优先推去皮果肉**，单价高、符合便捷趋势，再搭配整果吸引传统客群和减少库存。  
> 如果面向家庭客群多（尤其菜市场），可以**整果为主（70%）+去皮为辅（30%）**。  
> **核心法则**：通过去皮增加客单价，通过整果控制损耗。
