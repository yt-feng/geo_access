根据超市水果区的常见消费心理和产品特性，以下是针对香蕉、菠萝、苹果三款水果的具体组合促销方案，可直接执行：

**核心策略：** 利用 "高频刚需品（香蕉）+ 高价值感/尝鲜品（菠萝）+ 高耐储/搭配品（苹果）" 的组合逻辑，引导顾客从 "买一种" 升级为 "买一组"，提升客单价。

### 方案一：家庭健康套装（主推家庭囤货场景）
- **组合内容：** 香蕉1斤（约3-5根） + 菠萝半个（或1个小台农） + 苹果3-4个
- **定价建议：** 直接设一个打包价。例如，单买原价约25元，组合价19.9元（或直接标“买三样立省5元”）。
- **落地执行：**
  - 在堆头或端架处，用礼盒或专用网兜将三样水果固定成一份，贴上统一价签。
  - 在货架旁放置试吃台，切好菠萝和苹果，旁边放香蕉方便顾客触摸成熟度。
  - 搭配促销语：“每天两水果，医生远离我。全家健康一套搞定！”
- **效果逻辑：** 香蕉解决“买水果不知道买什么”的决策成本（刚需），菠萝提供“尝鲜/榨汁”的附加值（提升感知价值），苹果弥补“香蕉易熟坏、菠萝需处理”的短板（耐储、顶饿），让顾客觉得“买一套更划算、更全面”。

### 方案二：夏日能量补给（主推下午茶/学生/运动群体）
- **组合内容：** 2根香蕉 + 1个菠萝（切块盒装） + 1个苹果
- **定价建议：** 固定一个总价（如15.8元），比单买便宜3-5元。如果菠萝是整果，单价会高，建议切盒装把菠萝单价拉低。
- **落地执行：**
  - 放在冷柜或靠近收银台的促销区，已经切好菠萝和苹果，香蕉单独用袋子装。
  - 制作“3秒能量包”标签：香蕉（快速糖分） + 菠萝（维生素C+酶促消化） + 苹果（膳食纤维）。
  - 关联促销：旁边放酸奶或坚果，满三件减1元。
- **效果逻辑：** 降低顾客加工麻烦（菠萝切好、苹果免洗），组合后单价看着“一顿饭钱”，很容易顺带带走。

### 方案三：互动拆单法（适用时令/半盲盒玩法）
- **形式：** 在菠萝上贴“1元换购券”，只要购买香蕉+苹果满10元，凭小票可以1元换购1个菠萝（限前50份）。
- **或：** 香蕉+苹果组合价10元，加5元可得熟透菠萝（用于当天清库存）。
- **落地执行：** 菠萝单独放在收银台旁或出口处，由店员主动告知：“买香蕉和苹果的顾客，加1块钱就能拿这个大菠萝哦！”
- **效果逻辑：** 用菠萝的高单价（原价可能5-8元）做钩子，刺激顾客为了“赚优惠”主动购买香蕉+苹果。**核心是：菠萝的毛利空间足够支撑折扣，香蕉和苹果的毛利兜底。**

### 核心风险与执行要点：
1.  **菠萝必须处理！** 菠萝是这三者中最麻烦的，不切皮卖不动。建议提前去皮切块装盒，或提供免费削皮服务（放在促销台附近）。
2.  **香蕉的成熟度控制：** 香蕉要选偏生一点的（带点绿头），这样组合后顾客不会两天内全熟烂掉；苹果必须新鲜无伤口。
3.  **陈列位置：** 组合装必须放在**流量最大**的促销堆头（如入口处、收银台前），旁边贴大价签。**不要拆开陈列**，否则顾客只会选走单样。
4.  **利润测算：** 假设香蕉毛利15%，苹果毛利30%，菠萝毛利35%。组合定价建议控制在总毛利的15-20%左右（即比单买总价低5-8元，但比成本高8-12元），保持超市有利润，顾客觉得便宜。

**建议先做方案一（家庭健康套装）试跑三天**，观察动销率。如果菠萝动销快、苹果动销慢，可调整为方案三的“1元换购”策略。

**额外提醒：** 如果是社区生鲜店，可加强话术：“给孩子做水果沙拉/学校带去，这三样刚好够一周的维生素量。” 如果是大商超，可以在装袋区放菠萝刀，或提供免费切块服务。
