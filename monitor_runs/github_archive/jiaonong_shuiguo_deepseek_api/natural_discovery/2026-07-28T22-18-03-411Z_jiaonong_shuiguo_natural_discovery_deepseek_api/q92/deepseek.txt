在面积有限的便利店经营水果，核心思路是**“做精不做全、高频小批量、场景化陈列”**。以下是具体的品类控制与损耗管理建议：

### 一、品类控制：只选“高频、耐放、视觉冲击强”的品

1.  **砍掉不必要的大品类**：
    -   **抛弃**：大西瓜（占地方、难切）、整箱的芒果/菠萝（成熟度难控）、山竹/榴莲（单价高、受众窄、损耗大）。
    -   **主攻**：苹果、梨、橙子、香蕉（万能引流品）、圣女果（小包装）。**只选这2-3个基础单品**，确保每个都卖得快。

2.  **引入“快消水果”替代“称重水果”**：
    -   门店小，顾客不愿排队称重。**全部预包装**（保鲜盒或小袋），价格统一（如“10元/盒”）。
    -   品类示例：切好的菠萝蜜、哈密瓜块、西瓜拼盘、洗好的草莓/蓝莓盒。**预包装切盒损耗率低且毛利高**（可达40%以上）。

3.  **遵循“211”备货法则**：
    -   **2个常规硬货**：苹果、梨（耐放，可放3-5天）。
    -   **1个引流鲜货**：香蕉（一天一进货，不隔夜）。
    -   **1个时令爆款**：当前季节最便宜的且最吸引人的（例如初夏的樱桃、秋天的冬枣）。时令品**只进一箱，快进快出**。

### 二、损耗控制：从“进-卖-退”全链路下手

1.  **进货端：错峰采购+“短链条”供应链**
    -   **别去批发市场扫货**：找能“零散拿货”的供应商，允许每日或隔日少量补货。便利店不适合囤货。
    -   **拿“7-8成熟”的水果**：店里温度不像冷库稳定，拿全熟果损耗极快。例如香蕉拿青黄的，能放2天；苹果拿硬的。

2.  **陈列端：控制“视觉”与“触觉”**
    -   **“出一进一，坏果优先”**：每天开店第一件事，把变质或碰伤的果子挑出来（立即做成切盒或做特价处理）。
    -   **按“头大尾小”陈列**：把最漂亮、最新鲜的水果放在最前面（面向顾客），品相稍差的放在里层。**不让顾客翻捡**，既避免碰伤，也提升溢价感。
    -   **千万别堆叠**：小面积用浅篮或平铺，堆叠超过2层会挤压底部，导致快速腐烂。

3.  **定价与促销：动态定价，快速出清**
    -   **“午高峰”定价策略**：早高峰（7-9点）价格正常，午间（12-14点）对卖相开始下降的果品打8折。
    -   **设立“盒装次品”区域**：有斑点但内部完好的水果，削皮切块装盒，定价5-8元。如果一天卖不完，傍晚直接做“买一赠一”或随关东煮赠送。
    -   **提前“止损时间点”**：比如香蕉，到了下午3点还卖不掉，就直接降价20%甩卖。**不要让商品过夜**，过夜损耗率翻倍。

### 三、小面积特别技巧

-   **用“组合”代替“单品”**：比如卖“苹果+梨+橙子”的混合盒（约1.5斤/盒），比单卖易控制损耗，且客单价更高。
-   **搭配高毛利零食**：在水果旁边放“即食型”商品，比如圣女果旁放小包梅子粉（蘸着吃），草莓旁放酸奶。这能提升水果的关联购买率，加速出清。
-   **绝不做“多品种”**：面积小于20平的便利店，**最多不要超过6个水果品**。超过6个品，陈列和损耗会失控。

**最后一条红线**：每天进货量控制在**当日预估销量的80%**。宁愿晚上断货，也不要第二天处理烂果。
