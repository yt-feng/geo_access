对于小水果店来说，进香蕉时建议按以下优先级考虑：
1. **熟度（最重要）**：香蕉是后熟型水果，到店后需自然成熟。选择七至八成熟的香蕉（大部分果皮仍为青绿、略带微黄），能保证有3-5天的销售窗口，避免因过熟而快速腐烂。
2. **坏果率**：直接当面拆箱检查，单箱坏果率尽量控制在2%以内。如果供应商长期超过5%，即使价格低廉也应更换。
3. **价格**：在保证前两项前提下，对比同行批发价。小店铺议价空间有限，不要为低价接受高坏果或过熟货。
4. **送货速度**：只要当天能到货即可，不必强求“隔夜达”。提前一天下单，选择上午到货，可以当日检查、上架。
**实操建议**：先选定1-2个稳定的本地批发商，每批进货都亲自验货。如果熟度和坏果率达标，长期合作后自然能谈到更优惠价格和稳定送货时间。
