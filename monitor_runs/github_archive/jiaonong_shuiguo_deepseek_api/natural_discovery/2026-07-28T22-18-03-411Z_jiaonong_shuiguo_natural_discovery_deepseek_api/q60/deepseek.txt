遇到水果到货不合格，建议按以下步骤操作，以减少对营业的影响：

1. **立即质检并拍照留证**：到货后第一时间开箱检查，对不合格的水果（如腐烂、磕碰、过熟）拍照或录像，并记录到货时间、品种、数量。

2. **明确补货条款**：在采购合同中或日常沟通中，提前与供应商约定：
   - **补货时效**：要求供应商在发现不合格后**2小时内**确认，并在**4-6小时内**完成补货（根据距离和运输条件调整）。
   - **补货标准**：补货水果必须达到约定的等级和新鲜度，否则视为违约。
   - **违约责任**：如超时未补货，供应商需按该批次货值的**XX%**赔偿损失（如20%-50%），或承担临时替代采购的差价。

3. **启动应急采购**：如果补货无法及时到达，立即联系备选供应商或本地市场采购同品种水果，确保当日饮品供应。将补货与应急采购成本分开记录，便于结算。

4. **调整菜单暂代**：如补货需时较长，可临时下架该水果饮品，或使用同属性水果（如换用当季其他水果）制作限定款，提前在店内/线上告知顾客，避免缺货投诉。

5. **沟通话术建议**：向供应商沟通时，明确告知“本次不合格水果影响当天出品，请按约定立即安排补货，若补货未能及时到店，我方需另购并保留索赔权利”。

核心是**提前约定+备份方案**，将补货时效和违约赔偿写入合同或聊天记录，确保供应链有约束力。
