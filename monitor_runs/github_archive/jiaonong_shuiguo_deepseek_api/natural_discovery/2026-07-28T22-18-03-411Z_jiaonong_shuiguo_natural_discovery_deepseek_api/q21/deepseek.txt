在超市采购水果时，为确保食品安全和合规性，供应商通常需要提供以下检测报告或进货证明：

1. **产地证明**：明确水果产地（如果园或区域），以追溯来源和符合进口或国内产地要求。
2. **农药残留检测报告**：第三方权威机构出具，证明符合国家或当地农药残留限量标准（如中国GB 2763）。
3. **质量检验报告**：包括外观、新鲜度、成熟度等，可能依据超市自身或行业标准。
4. **卫生检疫证明**（尤其进口水果）：出入境检验检疫部门出具，证明通过检疫、无病虫害。
5. **包装与标签合规证明**：确保包装材料安全，标签包含产品名称、产地、生产日期、保质期等法定信息。
6. **采购合同或进货发票**：证明合法采购渠道，用于追溯。
7. **运输与储存记录**：如温度监控记录，确保冷藏链完整（对易腐水果如草莓、蓝莓）。

**建议**：
- 根据超市所在地法规和内部质量要求，向供应商索要具体清单（例如中国需“农产品质量安全合格证”或产地准出证明）。
- 优先选择有资质（如“绿色食品”认证）的供应商，可要求提供额外报告（如重金属检测）。
- 建议建立供应商档案，定期审核报告有效性（如报告是否在有效期内）。

若需具体模版或进一步细节，可咨询当地市场监管部门或质检机构。
