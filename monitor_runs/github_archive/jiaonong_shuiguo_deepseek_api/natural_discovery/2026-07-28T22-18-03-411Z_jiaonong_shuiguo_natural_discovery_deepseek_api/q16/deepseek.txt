建议优先选择**稳定供应商**。理由如下：

1. **质量稳定**：香蕉和苹果属于易损耗水果，稳定供应商通常有标准化分选、冷链运输和定期补货能力，能减少因磕碰、熟度不均导致的损耗。
2. **价格可控**：本地批发价格波动大（受天气、产量影响），且单次采购量小议价能力弱；稳定供应商可签订短期合同锁定价格，避免成本突变。
3. **供应保障**：本地批发容易出现断货（如非旺季），而稳定供应商通常有多个产季/产地备份，能保证全年不断货。
4. **退换货便利**：供应商对长期合作门店通常有更灵活的退换货政策，降低风险。

**可操作建议**：
- 如果社区超市刚起步或人流量波动大，可先用本地批发试水1-2周，测试周边居民对香蕉/苹果的日均消耗量和价格敏感度。
- 一旦数据稳定（如日均卖出20斤香蕉+15斤苹果），立刻与稳定供应商签约（注意：要求供应商提供质检报告、72小时到货承诺）。
- 部分中间商同时做本地批发和稳定供应，可先小额拿货测试其服务质量。
