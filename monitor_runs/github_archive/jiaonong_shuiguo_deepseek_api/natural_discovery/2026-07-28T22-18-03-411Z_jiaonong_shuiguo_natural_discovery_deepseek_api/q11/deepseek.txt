会的。大小不一可能产生以下影响：

1. **顾客体验差异**：顾客购买整箱时，若大小混杂，心理上可能觉得“吃亏”（例如期望大果实际出现小果），或担心小果口感不佳，导致复购率下降。
2. **价格定位矛盾**：大果通常单价高，小果需打折处理。混卖箱难以统一定价，若按均价卖，大客户觉得不合算；若按高价卖，小果难卖出。
3. **损耗风险增加**：小果可能更快熟透、易伤，混装时顾客挑选会翻动，加速全箱损耗。
4. **渠道限制**：若供应给食堂、奶茶店等，对方通常要求规格一致（如每根重150-200克），大小不一可能导致退货。

**建议**：
- 如果进货已经大小不一，可以**分拣销售**：大果单独装袋（高价），小果作为特价品或赠品。
- 采购时与供应商约定**分拣标准**（如“整箱90%为150g以上”），或直接采购“统货”时压低进价，预留分拣人工成本。
- 若坚持整箱销售，明确标注“大小随机”，并设置比单买稍低的折扣，同时提供现场拆箱让顾客自行挑选的权利。
