判断水果批发商手中的香蕉熟度和坏果风险，可以按以下步骤操作：

1. **外观颜色检查**：
   - **全青**：未熟，适宜长距离运输或存放。
   - **绿中带微黄**：七成熟，室温下1-2天可自行催熟。
   - **全黄无斑点**：九成熟，适合立即零售。
   - **出现黑色斑点/梅花点**：过熟，容易变质，应优先销售。

2. **触摸硬度**：
   - **硬实有弹性**：熟度适中，坏果风险低。
   - **手捏时局部发软或塌陷**：内部可能已经水烂或炭疽病，风险高。

3. **闻气味**：
   - **清新香蕉味**：正常。
   - **有酒精味或酸味**：内部已经发酵或变质，极大概率坏果。

4. **检查果柄（香蕉把）**：
   - **果柄青绿且紧实**：新鲜。
   - **果柄发黑、发霉或渗水**：源自冷库或运输时冻伤，后续易整串腐烂。

5. **果皮暗伤与湿度**：
   - **果皮有水渍状半透明斑**：挤压或冻伤，短时间会发黑腐烂。
   - **果皮有褐色划痕、凹痕**：运输碰撞，容易从伤口开始霉变。

6. **抽样核查（每批取3-5串）**：
   - 掰开检查内部的果肉颜色：**应呈乳白或嫩黄色**；发褐、发黑、水烂则判断为坏果。
   - 看根部截面是否有发红或黏稠液体：有则多为细菌性软腐病，无法长期保存。

7. **批次温度**：
   - 温感：香蕉最佳储存温度在13-16℃。手摸果体如果冰凉（低于8℃），大概率已有冷害，后续会变灰或不能正常成熟。

**核心判断建议：**
- 全青坚硬的香蕉，若果柄无霉变，坏果风险低于5%；但需催熟后才可销售。
- 颜色转黄但果皮光滑无斑的，通常当天到3天内风险极低（<10%）。
- 出现酒精味、软烂、果柄发霉或果皮水渍的，坏果风险极高（>40%），不建议整批进货。
