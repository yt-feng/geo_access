小商家采购水果时，现金结算和月结账期各有以下风险：

**现金结算风险：**
- **资金压力大**：需要一次性支付全款，可能占用大量流动资金，影响日常运营或其他采购。
- **无账期缓冲**：无法利用账期进行资金周转，若遇到水果滞销或损耗，直接面临亏损。
- **缺少保障**：若水果质量有问题（如腐烂、缺斤短两），现金交易后追责困难，缺乏书面合同或凭证时更易产生纠纷。
- **机会成本**：提前付款可能错失其他更优采购机会或资金投资。

**月结账期风险：**
- **信用风险**：依赖商家信誉，若供应商出现资金问题或跑路，已提供的水果可能无法获得付款连带损失（如对方反悔不发货）。
- **现金周转压力**：需在账期内垫付资金，若销售回款慢，可能导致自身资金链紧张甚至无法按期付款。
- **财务混乱**：长期账期易导致记账错误或遗漏，增加对账成本，甚至因未及时确认导致纠纷。
- **依赖关系**：可能被迫接受较低质量水果或提价风险，供应商可能利用账期优势要求其他条件（如捆绑采购）。

**建议：**
- 根据自身资金情况选择：资金充裕且对水果质量要求高时可选现金结算（需签简易合同并保留凭证）；资金有限需周转时优先考虑月结，但审核供应商信誉并明确合同条款（如质量等级、付款时间）。
- 混合使用：小额或高损耗水果现金结算，大额或稳定供应商月结。
- 无论哪种方式，均需书面记录采购详情（品种、数量、单价、约定标准），并保留沟通证据（微信/短信）。
