判断连锁超市的香蕉供应商能否全年稳定供货，建议从以下几个核心维度进行考察和评估：

1.  **产地与季节跨度**
    -   **要求**：供应商需要拥有或稳定合作多个不同纬度的种植基地（如国内海南、广西、云南，以及厄瓜多尔、菲律宾等进口源）。
    -   **验证**：查看其合作产地的时间表，确认是否能覆盖你的销售计划。例如，国内产区通常有淡旺季，如果供应商只依赖单一产区，夏季台风季或冬季低温时很可能断供。

2.  **货源结构（自产 vs 采购）**
    -   **要求**：最好有自有基地（30%-50%）+ 长期稳定合作基地的混合模式。
    -   **验证**：询问其自产比例，以及采购合同的期限（是否能锁定1年以上）。纯靠市场临时采购的供应商抗风险能力较差。

3.  **气候与物流风险预案**
    -   **要求**：针对台风、极寒、产区政府管控等不可抗力事件，供应商是否有明确的备用产地或中转仓储计划。
    -   **验证**：询问过去3年中最极端的一次缺货情况，以及他们当时如何应对。没有明确预案的供应商风险较高。

4.  **历史供货记录与合同条款**
    -   **要求**：过去2年对同类连锁超市的供货完成率（比如90%以上）。
    -   **验证**：要求提供历史供货记录或客户推荐信，并在合同中加入**保供条款**：规定缺货时的惩罚（如按缺货金额的10%罚款）或紧急加价机制。

5.  **冷链与保鲜能力**
    -   **要求**：香蕉是呼吸跃变型水果，需要精准的控温控气运输。供应商是否有标准的催熟库或稳定的冷藏运输车队。
    -   **验证**：实地考察其冷库容量和周转效率。如果供应商只有小冷库，旺季或突发需求时无法压货缓冲。

6.  **资金与规模**
    -   **要求**：香蕉批发是资金密集型行业，供应商需要有足够的资金垫付能力（比如能承担30-45天账期的超市回款节奏）。
    -   **验证**：查看其注册资本和近两年财务报表（或通过第三方征信平台核查），避免因资金链断裂导致断供。

**建议执行步骤**：
1.  **现场考察**：至少去其主仓库和1-2个合作基地看一遍，直观感受库存周转和保鲜条件。
2.  **小批量试单**：先下1-2个月的常规订单，考察其按时到货率、品质稳定性（如大小、成熟度、果形一致性）。
3.  **签合同明确违约责任**：重点写明“不可抗力下的补偿方案”和“连续缺货的超期违约金”。

**简单判断标准**：如果一个供应商只能提供“随时有货”的承诺，但无法拿出超过2个不同产区的合作证明、过去3年的极端天气应对记录，或者没有明确的冬季/夏季货源切换方案，建议谨慎合作。
