最应该优先问**售后**。原因如下：

1. **售后决定了团长的容错率**：水果是易损、易变质商品，即使再好的供应商也可能出现坏果、未熟、运输损伤等问题。如果供应商售后无保障（例如不赔付、理赔流程繁琐），这些成本会全部转嫁给你，甚至导致团员退款、团长信誉受损。
2. **价格依赖于售后的底线**：很便宜但售后差的价格，往往意味着只卖“没售后”的货，水果品质和发货量都可能不可控；而一个稳定的售后政策（比如坏果包赔、按比例退款）才是长期经营的基础。
3. **配送排在最后**：配送时效、包装是否防震、能否支持分拣和团点分发等，往往与供应商的实力直接挂钩，在售后问题无法解决时，配送再好也没用。

**建议询问顺序：**
- **第1问**：坏果、未熟、个头不达标怎么处理？邮费谁承担？理赔是24小时内回复还是下单赔付？
- **第2问**：价格是否含税、包邮、分拣费？斤数是否足称？是否支持混发或团点自提？
- **第3问**：配送能否按你的时间安排？破损件如何补发？

如果售后回答含糊、标准高（比如只赔不换、要求视频开箱），除非报价极低且有长期合作方案，否则不建议选。
