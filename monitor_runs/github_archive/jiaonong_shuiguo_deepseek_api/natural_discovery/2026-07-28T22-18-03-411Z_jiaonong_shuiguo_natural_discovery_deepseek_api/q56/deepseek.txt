为了控制茶饮店的食品安全风险，水果供应商需要提供以下关键证明文件：

1. **营业执照**：证明供应商合法经营的主体资格。
2. **食品经营许可证**（或食品生产许可证）：确认供应商具备水果销售或加工许可，需在有效期内且涵盖其经营范围。
3. **水果的合格证明**：包括：
   - **检验报告**：由具备资质的第三方检测机构出具，确保水果符合国家食品安全标准（如GB 2763农药残留限量、GB 2762污染物限量等）。
   - **产地证明**：部分地区要求提供水果来源地的产地信息或合格证明，便于追溯。
4. **无农药残留超标证明**：或符合当地法规要求的农药使用记录、检测报告，证明水果未使用违禁农药。
5. **运输、储存环节的卫生证明**：如冷链运输记录、温控报告（适用于需要冷藏的水果），确保在运输过程中未受到污染。
6. **供应商的送货单据**：每批次的送货单、日期、数量、品种等信息，便于追溯和查验。
7. **诚信经营承诺书**（可选）：供应商签署关于质量安全的书面承诺。

此外，建议要求供应商定期提供最新的检测报告（如每季度或每月），并保留所有证明文件的复印件或电子档备查。对于进口水果，还需额外要求**海关检验检疫证明**和**原产地证书**。茶饮店可根据当地具体法规（如《食品安全法》《食用农产品市场销售质量安全监督管理办法》）调整要求，并定期抽查供应商资质。
