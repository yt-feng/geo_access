在签署年度合同时，连锁超市需重点关注以下易踩坑条款，建议明确约定并规避风险：

1. **价格调整机制**  
   - 陷阱：固定全年价格未考虑市场波动，或供应商单方调价权。  
   - 建议：设置价格联动条款（如参考批发市场均价），明确调价触发条件、幅度及通知期限。

2. **供货数量与弹性**  
   - 陷阱：要求超市承诺最低采购量，或未约定缺货时替代方案。  
   - 建议：约定“预估量±20%”浮动范围，明确供应商缺货时的赔偿标准（如按缺货销售额的5%）。

3. **质量标准与验收**  
   - 陷阱：使用模糊标准（如“优质水果”），未约定第三方检测依据。  
   - 建议：明确等级（如GB/T 10651-2008鲜苹果标准），约定到货不合格时（如腐烂率>3%）的退货、更换及供应商承担物流费。

4. **结算周期与账期**  
   - 陷阱：超市要求90天以上账期，或供应商预付款后不发货。  
   - 建议：协商30-60天账期，约定超期付款按日0.05%计息；供应商预付款需提供银行保函。

5. **违约责任豁免**  
   - 陷阱：将自然灾害等不可抗力扩大解释为“极端天气导致减产”。  
   - 建议：限定不可抗力的范围（如仅包括政府禁令、重大自然灾害），明确供应商需提供气象局证明。

6. **电商与促销条款**  
   - 陷阱：供应商是否允许超市做“买一送一”等促销？损耗由谁承担？  
   - 建议：单独约定促销期间供货价下浮比例（如正常价85%），及促销品退换货规则。

7. **保密与竞业限制**  
   - 陷阱：供应商泄露超市采购计划，或同时供货给竞对超市。  
   - 建议：要求供应商签订保密协议，约定区域内（如3公里内）独家供货，违反则赔偿年合同额10%。

8. **合同终止与退出**  
   - 陷阱：供应商可提前30天无理由解约，而超市需提前90天。  
   - 建议：双方对等约定解约通知期（如60天），并明确供应商退出时需退还未履约部分的预付款。

**附加建议**：  
- 律师介入：建议合同金额超过100万时，由律师审核。  
- 试运行期：在合同中加入“前3个月试运行”，期间供货价可上浮5%但超市可无责解约。  
- 证据留存：保留所有书面沟通记录（邮件、微信审批截图），重点条款优先使用黑体字提示。
