对于商超水果采购而言，**“损耗低”通常比“价格低”更直接影响最终毛利**。原因如下：

1. **毛利公式**：最终毛利 = 销售收入 - 采购成本 - 损耗成本。  
   - **价格低**：能直接降低采购成本，但如果品质差、易腐烂，损耗率会显著上升。  
   - **损耗低**：意味着可销售数量多，减少了因变质、磕碰、称重误差等导致的无效成本。

2. **实际影响差异**：假设采购价低10%，但损耗率从5%升至15%，由于水果利润空间有限（通常毛利率20-30%），高损耗很容易吞噬价格优势甚至导致亏损。例如：  
   - 低价高损耗：进货10元/斤，损耗20%，实际可售成本12.5元/斤。  
   - 高价低损耗：进货12元/斤，损耗5%，实际可售成本12.63元/斤。两者相差不大，但低价策略往往伴随更多退货、补货和残损处理成本。

3. **商超运营特点**：水果作为生鲜品类，消费者对新鲜度和外观敏感，高损耗会导致：  
   - 陈列不美观 → 销售量下降 → 进一步拉低毛利。  
   - 损耗后的折价处理（如做成切盒）虽能减轻损失，但会拉低平均售价。

**建议优先选择损耗低（即品质稳定、耐运输和储存）的供应商**，在保证合理品质的前提下，再争取价格优势。可采取以下措施：  
- 实地考察供应商的分级标准、包装和冷链能力。  
- 进行小批量试采，对比不同货源的实际损耗率。  
- 对损耗率设定警戒线（如≥8%则更换供应商或调整定价）。  

如果价格低10%但损耗率高出5个百分点以上，应放弃低价采购。
