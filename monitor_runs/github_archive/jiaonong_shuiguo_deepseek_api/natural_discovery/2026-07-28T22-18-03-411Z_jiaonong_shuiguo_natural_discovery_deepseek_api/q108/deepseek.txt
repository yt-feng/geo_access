核实水果供应商的全国配送覆盖能力，建议从以下步骤入手：

1. **明确配送范围**：要求供应商提供具体的配送城市列表（精确到地级市或区县），而非笼统的“全国”。同时询问是否支持偏远地区（如西藏、青海部分区域）以及这些地区的配送时效和费用。

2. **要求物流合作方信息**：询问供应商合作的物流公司（如顺丰、京东物流、中通冷链等），直接联系物流公司核实该供应商在相关区域的发货记录或合作资质。

3. **获取历史发货凭证**：索要过去3-6个月的发货记录（隐去客户隐私信息），查看发往不同城市的快递单号或物流追踪截图。重点检查偏远地区（如新疆、内蒙古）是否有实际发货例。

4. **测试小额订单**：在供应商承诺覆盖但较远的城市（如县级市、乡镇）下一个小额试单（如1箱水果），实际体验配送时间、货物状态和是否需额外中转。

5. **关注保鲜与季节限制**：询问供应商在夏季高温或冬季极寒地区（如东北、海南）的包装和冷链方案。如果对方无法提供保温箱、冰袋等，说明实际覆盖能力有限。

6. **合同明确要求**：在采购合同中加入条款，如“若因配送问题导致损坏或延误，供应商承担全部责任；实际配送范围以合同附件城市列表为准”。若未来无法配送某城市，应提前约定退款或赔偿机制。

7. **查询第三方评价**：在行业B2B平台（如惠农网、一亩田）或物流查询网站（如快递100）搜索该供应商，查看其他采购方对配送地区的评价或投诉。

执行以上步骤后，如果供应商能提供具体城市清单、物流合作证明、历史记录并通过试单验证，说明覆盖能力较可靠；若仅口头承诺“全国”，则需警惕。
