主要需要关注以下三点，按优先级排序建议如下：

1. **保质期与食用安全（最高优先）**  
   - 菠萝切块后水分流失快、易氧化变味，且微生物繁殖风险高。建议：  
     - **标注短保质期**（如24-48小时），并明确“切好后立即冷藏（0-4℃）”。  
     - **每日检查**，过期或变色（发黑、变软）立即下架报废。  
     - 使用密封盒/保鲜膜覆盖防污染。

2. **包装（次要但直接影响销售）**  
   - 需平衡防氧化、防漏液与成本：  
     - **最佳选择**：带排水槽的PET透明盒 + 保鲜膜密封（阻止空气接触，延长保质期至2天）。  
     - **替代方案**：普通保鲜袋封口+吸水纸垫（避免果汁流出污染货架）。  
     - 避免用散装或敞口托盘（易导致菠萝风干、被顾客翻动污染）。

3. **配送频次（与库存周转挂钩）**  
   - 如果店铺客流波动大，建议：  
     - **高客流店**：每日配送2次（早高峰+午高峰），每次只供2-4小时销量。  
     - **低客流社区店**：每日1次配送，但需配合现场补货（如每日11点前完成上架，15点后不再补货）。  
     - 原则：**宁可少供断货，也不堆积库存**（切块菠萝隔夜后口感与安全风险显著下降）。

**行动清单**：  
- 先确认本地食药监对“即食鲜切水果”的报废时间或折扣规则（如满6小时需半价促销）。  
- 若配送无法频繁，建议改用**冷冻菠萝块**（保质期3个月，解冻后口感仍可接受）。  

提示：便利店鲜切水果损耗率通常为30%-50%，建议首周用最小包装试销，再根据收银数据调整配送频次。
