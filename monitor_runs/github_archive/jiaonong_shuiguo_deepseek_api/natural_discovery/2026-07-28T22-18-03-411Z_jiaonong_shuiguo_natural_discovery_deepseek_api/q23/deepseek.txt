一般情况下，供应商是可以提供这些支持的，尤其是针对大型超市或重点促销活动。具体能提供哪类支持，取决于供应商的规模、产品利润、合作关系以及超市的谈判地位。

**常见的支持形式包括：**

1.  **陈列支持**：供应商通常会提供额外的陈列架、陈列盒、端架堆头专用底座等物料，或者承担特殊陈列位置的费用（如堆头费）。
2.  **海报支持**：可以协商供应商支付DM单（促销海报）的广告位费用，或由供应商提供水果产品的宣传图片、设计素材资料。
3.  **试吃支持**：供应商提供试吃品（比如将部分水果作为免费品尝的损耗）、试吃台、一次性纸盘、牙签等耗材，甚至派促销人员进行现场切分和推销。

**建议操作步骤：**

-   **首先明确需求**：您需要确定是单品促销（如只推一款芒果）还是品类促销（如夏季水果节），不同形式支持力度不同。
-   **核对合同与费用**：请检查您与供应商的年度合同或单次促销协议，通常这部分支持已经列明费用标准和分摊方式（例如“供应商承担50%海报费用”）。
-   **提前书面沟通**：最好在促销开始前至少1-2周，以书面形式（邮件或正式通知）向供应商提出具体需求（如“需要50个试吃品、A4海报200张”），并明确哪些由供应商免费提供，哪些需收费。
-   **协商损耗处理**：试吃水果的损耗是常见争议点，建议双方提前约定试吃品的费用由谁承担（通常是供应商承担，或者分摊计入促销成本）。

**如果供应商拒绝提供：**
可能是该供应商利润薄或合作力度小。您可以尝试：
-   将多个供应商的同类产品打包，承诺集中推广，争取更多支持。
-   或者超市自己承担部分基础物料费用，只要求供应商提供试吃品或工作人员。

总结：**超市可以要求，供应商有权协商。提前沟通、明确合同和分摊条款是最佳做法。**
