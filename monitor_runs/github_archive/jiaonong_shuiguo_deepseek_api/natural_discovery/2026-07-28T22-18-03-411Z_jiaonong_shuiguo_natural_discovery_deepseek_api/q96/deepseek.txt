在企业食堂采购水果时，**食品安全**是**最需要优先关注**的核心。虽然价格和配送准时也很重要，但食品安全直接关系到员工健康和企业的法律责任。

以下是具体排序和建议：

1. **食品安全（最优先）**  
   - **风险最高**：水果可能农药残留、微生物污染或运输中变质。  
   - **措施**：要求供应商提供产品检测报告、产地证明，建立验收制度（检查外观、气味、存储条件）。  
   - **合规要求**：符合《食品安全法》及地方监管要求。

2. **价格（次重要）**  
   - **控制成本**：通过比价、批量采购或季节性采购降低成本。  
   - **注意陷阱**：不能单纯追求低价，可能导致质量下降或安全隐患。

3. **配送准时（第三重要）**  
   - **影响运营**：延迟配送可能影响食堂备餐安排，但可通过合同条款约束（如履约保证金、补偿机制）。  
   - **柔性处理**：与供应商协商备用方案（如紧急补货渠道）。

**建议实践**：  
- 优先选择**有资质、口碑好的供应商**（如通过HACCP或ISO22000认证）。  
- 签订合同时明确食品安全责任、验收标准和惩罚条款。  
- 建立**随机抽检+定期评估**机制，平衡安全、价格和配送效率。
