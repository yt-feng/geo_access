生鲜电商建议优先选择**切配菠萝**（即预切好的菠萝块/果切），其次为**整果**，**冷冻原料**最不推荐。以下是具体分析：

1. **切配菠萝（推荐首选）**  
   - **优势**：省去用户削皮、去眼、泡盐水等繁琐步骤，即开即吃，符合线上消费的便利性需求；可直接作为水果切、沙拉原料或烘焙辅料销售，客单价和复购率高；冷链配送损耗可控。  
   - **注意**：需标注切配时间、保质期，包装内附叉子或纸袋，并注明“建议当天食用”。  
   - **适用场景**：中高端生鲜平台、社区团购。

2. **整果（次选）**  
   - **优势**：用户能直观看到果实外观，适合海南金钻等品种溢价销售；生鲜电商可规避中途熟度变化导致的腐坏风险（由用户自行判断）；可通过视频教程降低处理门槛。  
   - **劣势**：部分用户因怕麻烦拒绝下单；如果运输不当磕碰导致果皮烂斑，用户易退货差评。  
   - **适用场景**：有“现摘现发”卖点的原产地直发、大号家庭装。

3. **冷冻菠萝（谨慎考虑）**  
   - **劣势**：口感大幅下降（纤维感重），糖分流失后酸度突出；国内用户对冷冻水果接受度仍偏低；冷链成本高且需大容量冷柜储存，若单量不足易积压损耗。  
   - **适用场景**：仅适合批量供应B端烘焙店铺（如冷冻菠萝丁用于披萨或罐头），或面向减脂人群的“冷冻即食水果”专区（需明确标注解冻方法）。

**落地建议**：  
- 可尝试**试销模式**：首月主推切配菠萝（如300±50g小包装，定价12-18元），搭配整果（标注专业刀具推荐）作为高客单选项，冷冻原料暂不上架或仅做B端团购链接。  
- 售后策略：切配菠萝承诺“变色/变味包赔”，整果提供免费削皮教程（扫码看视频），降低用户决策顾虑。  
- 季节节奏：夏季主推切配（配冰块防腐），冬季可增加整果促销（用户有围炉煮茶氛围需求）。
