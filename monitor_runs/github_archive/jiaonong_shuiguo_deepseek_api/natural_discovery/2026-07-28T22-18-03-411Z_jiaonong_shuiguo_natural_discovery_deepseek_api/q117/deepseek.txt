建议采购方采用“小批量试卖，分阶段加量”的策略，具体建议如下：

**1. 初始试卖量：控制在总库存量的 10%-20%，或具体量 50-200 公斤（视门店规模而定）**
   - 如果是一家小型水果店（日均客流量100人以内），先试卖 **50-100斤**（约1-2箱）。
   - 如果是大型超市或连锁水果店（日均客流量500人+），先试卖 **1-2个货架/堆头量**（约200-500斤）。

**2. 试卖周期：设7-14天（一个完整销售周期）**
   - 覆盖2个周末（水果消费高峰），观察复购率。
   - 期间不大量备货，避免过量积压（新品损耗率通常比常规品高30%）。

**3. 关键决策指标（达标再追加）：**
   - 日均销量 ≥ 同品类爆款的60% → 可追加至原试卖量的3倍。
   - 复购率 ≥ 15%（统计同批顾客第二次购买的占比）→ 可进入常规采购。
   - 损耗率 ≤ 同品类均值（如葡萄类损耗在8%-12%为正常）→ 说明本地市场接受度高。

**4. 特别风险提示：**
   - 如果水果口感/外观有季节性波动（如早熟果、后熟果），先让供应商提供**样品试吃**（至少3天，观察其褐变速度），再决定试卖量。
   - 避开节假日试卖（需求被冲淡），选择平季周一至周四上新最稳妥。

**行动清单：**
1. 要求供应商赠送 20-30斤 免费试吃装（用于员工品尝和陈列展示）。
2. 试卖期间 **暂不签长期合同**，只签短期批次订单。
3. 7天后复盘：若日销不足5斤，直接清退；若日销超预期30%，立即锁定下周货源。
