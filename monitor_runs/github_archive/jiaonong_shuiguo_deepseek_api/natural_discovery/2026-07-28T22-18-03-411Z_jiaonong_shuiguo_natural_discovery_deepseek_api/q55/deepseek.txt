挑选苹果、橙子、菠萝做水果拼盘时，划算的规格选择需要综合**出肉率、损耗率、单价和加工难度**。以下是具体建议：

1. **苹果**  
   - **规格**：中等大小（单果约150-200克），表皮光滑、无伤痕。  
   - **原因**：小苹果削皮去核后出肉率低，大苹果单价通常更贵，且太大可能果肉松软；中等果出肉率约70%-80%，损耗（皮+核）可控，单价最实惠。

2. **橙子**  
   - **规格**：**脐橙**选择单果250-350克，**血橙/蜜橘**选单果150-200克。  
   - **原因**：大橙子皮厚、瓣肉分离可能松散，出肉率反而低（尤其带白膜）；中等个头的橙子皮薄肉多，出肉率可达65%-75%，且易切块。避免选超级小果，出肉率仅50%左右。

3. **菠萝**  
   - **规格**：**整只菠萝**比切块装划算。选择单果1.2-1.5公斤，外形圆润、叶芽短、底部无干枯。  
   - **原因**：小菠萝去皮后损耗极大（外皮+硬芯占40%-50%），大菠萝出肉率更高（约60%）。整只买通常比切块单价低30%-50%。如果只论果肉，**菠萝罐头**（无糖盐水浸泡）比新鲜菠萝更省时，且出肉率100%，但口感略逊于新鲜菠萝。

**综合购买策略**（按性价比排序）：
- **最优**：整只菠萝（1.5kg左右）+ 中等苹果（150-200g）+ 中等橙子（250-350g）。  
- **次优**：苹果选普通红富士（比进口更便宜），橙子选本地当季品种（如湖南脐橙），菠萝在夏季或促销时买。  
- **注意**：避开预切水果拼盘，单价至少贵2-3倍，且新鲜度难保证。

**实操技巧**：
- 苹果可以提前切块泡淡盐水防氧化，橙子可用香橙去白膜技法，菠萝切块用盐水浸泡去涩，这样减少浪费，进一步降低单次成本。
