判断菠萝熟度主要看以下几点，按实用程度排序：

1. **闻气味**  
   选择有浓郁菠萝香气的（尤其是底部），无味或带发酵酸味、酒味的不要选——后者过熟易烂，运输损耗大。

2. **看颜色**  
   青绿色多则生硬（难削且酸涩），整体转黄或底部呈金黄色代表成熟度较高。**建议买青黄相间（约7-8分熟）的**，到店后摊开通风1-2天即可售卖，比全黄更耐放。

3. **按压硬度**  
   轻轻按压果身，**微有弹性而不软塌**为佳。如果按下去发硬像石头，说明没熟；一按就凹陷则过熟，次日可能损耗。

4. **看叶子**  
   顶叶翠绿易折断的较新鲜；叶片干枯发黄说明采收时间久或保存不当。

5. **看底部切面**  
   果柄切面呈**白色或淡黄色**为新鲜。如果发黑、发黏，说明内部可能已变质。

**采购建议**：优先选择**青黄各半、香气清淡、按着硬但带弹性**的菠萝。运送时避免叠压，到店后优先卖颜色更黄的。大规模采购可向供应商要求成熟度分级样品，避免批次差别。
