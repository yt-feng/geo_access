评估连锁门店水果供应商的仓配覆盖能力，核心在于**匹配门店需求与供应商仓配网络的可达性、时效和成本**。建议按以下步骤进行系统评估：

### 1. 明确门店端关键约束
先整理出你所有门店的**位置坐标、日均销量、配送频次（如每日/隔日）、收货时间窗口（如早上8-10点）**。特别是水果易损耗，要关注**保鲜要求**（如冷藏车、温度区间）。

### 2. 供应商仓配网络可视化与距离/时效测算
- **获取供应商所有仓库/分拨中心位置**（需明确是自建仓、还是产地直发、或第三方仓）。
- **计算运距**：对每家门店，找出距离最近或时效最优的供应商仓库，测算**陆运/冷链车**的**实际行驶距离**（非直线距离）及**预计到达时间**。
- **重点判断**：是否能满足门店的收货时间窗口。例如，供应商A在南京有仓，但杭州门店要求早上7点前到货，而南京到杭州冷链车需4小时且半夜无配送，则覆盖失效。

### 3. 叠加门店销量与仓库辐射能力（单仓产能瓶颈）
- **计算单仓服务半径**：通常水果供应商单仓有效冷链配送半径约150-300公里（次日达）；若需当日达，通常≤100公里。
- **评估仓库饱和度**：即使距离可行，也要看该仓库的**日均处理能力（吨/天）** 与**现合作客户占用量**。如果该仓已超负荷，实际履约会不稳定。

### 4. 评估损耗控制能力（关键差异化指标）
- **仓间调拨频次**：如果供应商一个城市只有一个仓，但门店分布广，需要确认其是否支持“多点分拨”或“前置仓+干线”。否则欠发达区域货物周转慢，损耗高。
- **到货品质标准**：要求供应商提供**近3个月的历史到货损耗率**（按门店、按品类）。如果某个城市门店的投诉率高且损耗超标，说明该仓配送或存储条件有问题。

### 5. 模拟极端场景（压力测试）
- **集中到货峰值**：如节假日、促销日，供应商的临时加车能力、分拣效率能否支撑。
- **跨区域紧急补货**：如果门店突发缺货，供应商能否启用邻近省际仓24小时内调拨。

### 6. 成本与覆盖率的权衡
- 设定**基础覆盖率目标**（如：所有门店中90%以上可实现次日凌晨6点前到货）。
- 测算不同供应商方案的**综合配送成本**（含冷链、配送费、货损折让）。
- 注意：覆盖面广但全是边远地区的小单量高成本配送，可能不如“区域仓+本地采购”的组合。

### 简易操作建议：
- 使用**地图API**（如高德/百度地图开放平台）批量计算门店到各仓库的驾车时间。
- 要求供应商提供**历史配送数据**：包含每一单的发货时间、到货时间、签收损耗。
- **实地抽样**：对最远/最偏僻的2-3家门店进行实际派送跟单，看流程是否符合承诺。

**最终判断：**  
| 维度 | 合格标准 |
|------|----------|
| 门店覆盖率 | ≥90%的门店可在规定收货时间前送达 |
| 单仓最长运距 | ≤冷链有效覆盖半径（通常300公里内） |
| 历史到货损耗率 | 各门店平均≤3%（水果品类常见底线） |
| 紧急响应 | 有书面应急调拨预案，且24小时内可执行跨区域补货 |

如果评估后供应商仓配覆盖不达标，可考虑**“核心城市自建仓+周边门店供应商直送”**的混合模式。
