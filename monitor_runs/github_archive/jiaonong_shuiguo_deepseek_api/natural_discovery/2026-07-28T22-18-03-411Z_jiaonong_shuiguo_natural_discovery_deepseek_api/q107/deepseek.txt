是的，起订量太高确实会增加损耗风险。原因和具体建议如下：

1. **库存积压与保质期冲突**：香蕉和菠萝都属于易腐水果，成熟速度快（尤其香蕉）。起订量过高会导致库存周转时间延长，在未售出前就可能过熟、变质，直接增加损耗占比。

2. **需求波动难匹配**：如果实际销售量低于起订量，剩余部分难以在短期内消化。特别对于季节性较强的菠萝，或对储存条件敏感的香蕉，长时间存放会加速品质下降。

3. **管理成本隐性增长**：大批量进货需要更多冷库空间、更频繁的翻检和筛除坏果，人工与能源成本随之上升，但最终损耗仍难以完全避免。

**可执行建议**：
- **分阶段采购**：与供应商协商“分批发货、统一结算”模式，用较小批次降低单次库存压力。
- **灵活起订量设置**：基于过往销售数据（如日均销量×到货周期×1.2安全系数）计算，避免盲目追求单价优惠。
- **预包装与促销联动**：对接近成熟的水果提前打折、组合销售，或与保质期相近的食品搭配促销，加快清货速度。
- **强化损耗监测**：制定批次编号制度，记录到货时间、损耗率，每月分析损耗与实际起订量的相关性，动态调整订购策略。

总之，若起订量超过3-5天销售量，且无成熟的分销渠道或加工用途（如制作果酱），损耗风险会显著提高，建议谨慎评估。
