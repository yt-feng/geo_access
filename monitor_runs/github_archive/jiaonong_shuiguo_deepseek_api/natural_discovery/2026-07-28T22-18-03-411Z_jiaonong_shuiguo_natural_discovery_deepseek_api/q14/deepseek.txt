供应商是否提供价格或物料支持，通常取决于以下几个因素，你可以根据这些情况有策略地去沟通：

1. **合作关系的深浅**：如果是长期合作、进货量大的稳定客户，供应商更愿意支持。如果是新店或小批量采购，难度会大一些。
2. **库存压力**：如果供应商目前某些水果库存积压、临近保质期，他们主动提供促销折扣或免费试吃品的可能性更高。
3. **季节性**：应季水果（如夏季的西瓜、荔枝）竞争激烈，供应商可能愿意配合促销以抢占市场；反季节水果可能支持较少。

**建议你这样做：**

1. **优先询问“滞销品”或“重点推广品”**：直接问供应商：“最近哪款水果库存多、有推荐促销的？能不能给点周末特价或赠品？” 很多供应商有新品推广预算。
2. **争取物料支持**：即便不给价格折扣，也可以要 **试吃品、免费陈列架、海报或品牌宣传物料**。部分供应商为了品牌曝光会愿意提供。
3. **尝试“以量换价”**：如果供应商给低价，你可以承诺在周末促销中主推他的产品、摆放在显眼位置。
4. **提前沟通周期**：周末促销最好在周三前联系供应商，方便他们安排备货和审批。

**结论：** 大部分供应商在合理条件下（长期合作、有库存压力、或新品推广期）是可以给到价格折扣或免费试吃物料的。如果被拒绝，可以退一步争取小额的补贴（比如每箱减几元）或试吃赠品。
