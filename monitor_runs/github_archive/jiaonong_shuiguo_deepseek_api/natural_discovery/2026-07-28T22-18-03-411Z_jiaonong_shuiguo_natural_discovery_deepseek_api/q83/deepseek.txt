生鲜电商水果到货后出现坏果的责任划分，通常需要结合以下因素综合判断：

1. **责任方界定**：
   - **发货前**：若在采摘、分拣、包装环节已存在坏果（如挤压、腐烂），责任在卖家或供应链。
   - **运输中**：由快递公司运输不当（如暴力装卸、温控不当）导致的损坏，责任在物流方，但消费者通常可向卖家索赔，由卖家向物流追偿。
   - **收货后**：若顾客签收后未及时开箱检查、储存不当或超时未反馈，责任一般在消费者。

2. **关键判断依据**：
   - **客诉时效**：通常行业标准为收货后24-48小时内反馈（具体看平台规则），超过时限可能影响责任认定。
   - **证据有效性**：需提供清晰照片或视频，能直观看到坏果、包装破损、物流面单等信息。
   - **损坏程度**：少量坏果（如1-2个）多按比例退款；大面积腐烂或整箱损坏，通常需全额赔付。

3. **实操建议**：
   - **立即拍照取证**：保留带时间戳的坏果特写、包装箱整体照片、快递面单。
   - **联系卖家**：在平台内按“售后/货损”通道提交证据，要求按比例或全额退款。若卖家推诿，可申请平台介入。
   - **跟踪物流**：若包装完好但内部损坏，可能是运输问题，要求卖家向物流索赔；若包装破损漏液，可同时向快递公司投诉。
   - **自建标准参考**：保存平台条款截图，或参考《生鲜电商售后标准》（如坏果率超5%可申请全赔）。

4. **特别提示**：
   - 若商品标注“坏果包赔”，即使责任模糊，卖家也需按承诺处理（需在有效期内申请）。
   - 遇重大争议（如恶意欺诈、大量坏果），可向12315投诉，需提供订单号、沟通记录、证据链。
   - 勿自行丢弃坏果或包装，否则可能失去维权凭证。

**总结**：除非是顾客明显过失（如延迟验货、恶意举报），否则优先由卖家承担赔付责任，再由卖家向供应链上游或物流追偿。建议保留证据、尽快反馈、善用平台规则。
