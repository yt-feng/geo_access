为拓展餐饮客户，建议准备以下规格的菠萝和香蕉：

**菠萝：**
- **规格1：整果（带皮）**，每个约1.2-1.5公斤（适合餐厅自行切配或制作果汁）
- **规格2：净肉切块**，真空包装，约500克/袋（适合直接用于沙拉、炒菜或甜品）
- **规格3：菠萝圈或菠萝片**，罐头或鲜切冷冻，约1公斤/包（适合汉堡、披萨或装饰）
- **备注：** 建议提供去芯处理的选项，并标注甜度（如13-15%糖度）。

**香蕉：**
- **规格1：整把**，每把约1.5-2公斤，成熟度在7-8成（适合现食或烘焙）
- **规格2：单根精包装**，每根约100-120克（适合酒店早餐或自助餐）
- **规格3：切片冷冻香蕉**，约500克/袋（适合奶昔、冰淇淋或甜品）
- **备注：** 标注成熟度（如绿皮未熟、黄皮可食、斑点全熟）以匹配不同烹饪需求。

**附加建议：**
- 提供定制包装，如餐厅品牌标签或小份试吃装。
- 明确产地、保质期和储存方式（如常温或冷藏）。
- 赠送少量样品供客户测试菜单可行性。
