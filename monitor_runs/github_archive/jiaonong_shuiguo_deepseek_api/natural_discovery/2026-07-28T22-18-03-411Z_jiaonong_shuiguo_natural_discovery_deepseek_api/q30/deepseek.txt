当超市水果到货品相不符合预期时，建议按以下步骤约定售后流程，确保责任清晰、处理高效：

### 1. 验收与判定标准
- **明确验收时间**：到货后**2小时内**完成外观检查（如颜色、大小、有无腐烂、压伤等）。
- **量化品相标准**：提前约定“品相不好”的具体指标，例如：
  - 腐烂率超过**3%**；
  - 表皮破损面积超过**10%**；
  - 色泽与合同样品差距明显（如青涩、过熟发黑）。
- **证据保留**：要求拍照或录像，并保存**到货签收单**和**运输温度记录**（如冷链运输）。

### 2. 问题提交与处理时限
- **通知期限**：发现问题后**24小时内**以书面形式（如邮件、系统工单）通知供应商，附上图片/视频证据。
- **供应商响应**：收到通知后**48小时内**确认是否接受退货或赔偿，超时视为默认责任方。

### 3. 责任划分与赔偿方案
- **供应商责任**：若品相问题源于发货方（如未按标准分拣、包装不当），则：
  - 全额退款或换货（运费由供应商承担）；
  - 按问题水果货值的**30%-50%**赔偿人工及销量损失（可协商）。
- **运输方责任**：若因运输过程（如摔压、温度失控）导致，由物流公司按保险合同赔付，供应商协助追责。
- **不可抗力**：如突发天气、交通管制等，双方按合同“不可抗力条款”分担损失（通常各承担50%）。

### 4. 争议解决与记录
- **第三方检测**：双方对腐烂率等数据存疑时，可由**具备资质的检测机构**（如SGS）介入，费用由责任方承担。
- **记录留存**：所有沟通、图片、检测报告、赔偿凭证需编号存档，保留至少6个月，便于后续对账。

### 操作示例（快速决策模板）
```
客户：发现10箱苹果中3箱有机械损伤，损伤率约15%。
行动：立即拍照并通知供应商 → 24小时内供应商确认负责 → 2天内换货或按货值35%赔偿。
若不接受：启动第三方检测（72小时内出具报告），按结果执行赔偿。
```

### 注意事项
- 避免口头约定，所有流程写入**采购合同**或**补充协议**。
- 若为长期合作，可设置**季度品相合格率**（如≥95%），低于则减少订单量或提高抽检频率。

如需具体合同条款模板或特殊品类（如易损水果）的细化标准，可进一步说明。
