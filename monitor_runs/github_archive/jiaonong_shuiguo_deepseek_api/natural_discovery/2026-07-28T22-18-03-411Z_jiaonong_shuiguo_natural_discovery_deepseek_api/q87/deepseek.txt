针对社区团购旺季爆单锁定库存，建议按以下步骤提前操作，确保供应链稳定：

1. **提前沟通并签协议**：提前至少2-4周与供应商沟通，明确旺季预计订单量。签书面协议或补充条款，约定锁定库存数量、价格、提货时间、违约赔偿（如供应商缺货赔付比例）。

2. **支付定金或保证金**：支付一定比例定金（如10%-30%）作为锁定诚意金，或提供保证金，让供应商优先保障你的库存。协议中注明定金可抵扣货款但不可退还（若供应商违约需双倍返还）。

3. **设置分阶段提货计划**：按销量预测分批次锁定库存，例如初期锁定总需求60%，旺季中根据销量再追加20%，避免一次性锁死但滞销。协议中加入“阶梯提货”条款。

4. **建立价格保护机制**：约定若供应商旺季内对外售价上涨，锁定部分价格不变；若下跌，按较低价结算。避免供应商因行情波动毁约或抬价。

5. **每日库存确认与预警**：建立每日或隔日上报机制，要求供应商提供实时库存数据（如剩余锁定库存量、已发货量）。设置警戒线（例如剩余量低于30%时启动追加采购）。

6. **备选供应商方案**：锁定时同步与2-3家供应商合作，每家锁定部分库存（如分60%、30%、10%），并提前告知主供应商有备选，增加其履约压力。

7. **垫资或账期优惠**：若供应商资金紧张，可提前支付部分货款（如预付50%），换取其优先排产权。同时要求对方提供库存质押或监管协议。

8. **合同关键条款示例**：
   - “乙方（供应商）确保在[日期]前为甲方保留[数量]吨[水果品种]，若未能按时足量交付，每缺斤1吨赔偿甲方[金额]元。”
   - “甲方支付定金后，乙方不得向其他渠道销售锁定库存，否则双倍返还定金。”

9. **行动检查清单**：
   - [ ] 锁定价格与库存量的书面协议已签署。
   - [ ] 定金或保证金已支付并留凭证。
   - [ ] 建立了每日库存报告渠道（微信/邮箱）。
   - [ ] 已联系至少2家备选供应商。
   - [ ] 已确认水果保鲜期与提货时间匹配。

若供应商是散户或小型果园，可改为“预订金+保底收购”模式，承诺如果未提货，定金不退，但供应量按实际产能锁定。
