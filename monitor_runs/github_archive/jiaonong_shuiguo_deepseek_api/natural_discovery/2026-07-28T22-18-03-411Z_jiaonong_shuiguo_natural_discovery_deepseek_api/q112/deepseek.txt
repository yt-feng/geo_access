在水果采购合同中，坏果率的赔付标准通常没有统一的法律规定，而是由双方协商确定。不过，行业内常见的做法是：

**建议设定以下赔付标准：**

1. **坏果率 ≤ 5%**：属于正常损耗，一般不要求赔付（除非合同另有约定）。
2. **坏果率 5%-10%**：可以协商按比例折价或赔付，例如超出5%的部分按货值的一定比例赔偿（如1:1抵扣）。
3. **坏果率 > 10%**：通常视为严重质量问题，应明确要求全额退换货或按货值100%赔偿，并可要求卖方承担运输、检测等额外费用。

**关键操作建议：**

- **合同明确约定**：务必在合同中写明“坏果率”的定义（如腐烂、霉变、严重机械损伤等），并设置具体的赔付条款，例如：“单批次坏果率超过10%，买方有权拒收或要求卖方按该批次总货款的150%赔偿”。
- **抽样验收**：到货后立即抽样检验（建议按GB/T 8855标准执行），保留影像证据和第三方检测报告，作为赔付依据。
- **特殊水果调整**：易腐水果（如草莓、荔枝）可适当放宽至7%-8%的免赔线，而耐储水果（如苹果、柑橘）建议控制在5%以内。

**如果怀疑已采购批次超额**：立即拍照、封存样品，并书面通知供应商要求处理。根据《民法典》第610条，交货质量不符合约定导致合同目的无法实现的，可以解除合同。
