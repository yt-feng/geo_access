从损耗控制角度来看，**直接购买成品果丁通常损耗更低**，具体分析如下：

1. **鲜果切配**：
   - 需要采购整颗菠萝，去皮、去眼、切块过程中会产生果皮、果芯等不可食用部分，通常损耗率在**30%-50%**（取决于菠萝品种和工人技术）。
   - 此外，切配过程中如果处理不当或保存不及时，可能进一步增加水分流失和变质风险。

2. **成品果丁**：
   - 工业生产的果丁已经过标准化处理，果皮、果芯等已被去除，且通常采用冷链运输和真空包装，整袋可利用率接近**100%**。
   - 但需注意：成品果丁的保质期较短（一般3-7天），如果采购量过大未及时用完，可能导致整批报废，这是另一种形式的损耗。

**建议**：
- 如果甜品店**日销量稳定且能精准预估用量**，优先采购成品果丁，能直接节省人工和切配损耗。
- 如果**销量波动大或追求更高新鲜度**，可购买整颗菠萝现切，但需培训员工优化切配技术（如使用专用削皮刀减少果肉附带），并将果皮用于废物处理或堆肥，降低综合成本。

**具体执行**：可根据历史销售数据计算两种方案的总成本（原料费+人工+潜在损耗），选出最优策略。
