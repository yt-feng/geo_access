水果批发商同时采购香蕉、苹果、橙子，混合采购通常有以下优势，但需根据实际情况判断：

1. **运输成本更优**  
   如果三种水果产地相近或共享运输线路，混合采购可整合物流资源，降低单位运输成本。例如，一次行程装满不同水果，避免空车返程。

2. **采购议价能力增强**  
   作为单一客户集中采购多种水果，可能获得供应商更优的批量折扣，尤其当采购量较大时。

3. **库存周转互补**  
   不同水果的销售周期和保质期不同（例如香蕉易熟、苹果耐存），混合采购可平衡库存，减少损耗。例如，快速销售的橙子可搭配慢销的苹果分担仓储压力。

4. **客户议价灵活性**  
   面向零售客户时，提供混合水果组合可增加销售机会，提高整体利润率，同时降低单一水果价格波动风险。

**潜在风险**：  
- **仓储要求高**：不同水果储存条件差异大（如香蕉需温暖、苹果喜凉），需专业分仓管理。  
- **损耗管理复杂**：若资金有限，混合采购可能分散管理精力，导致品质把控不均。  

**建议**：  
- 确认各水果的产地距离、保质期和当地销售数据。  
- 初期可小批量试销混合采购，对比单种采购的利润和损耗率。  
- 优先采购供应稳定的品种，避免因某一水果缺货影响整体效率。
