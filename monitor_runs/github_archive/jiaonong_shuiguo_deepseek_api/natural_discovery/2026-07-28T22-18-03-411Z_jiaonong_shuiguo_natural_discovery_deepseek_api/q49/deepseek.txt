针对茶饮店旺季菠萝用量激增的临时补货需求，建议按以下步骤与供应商沟通并约定条款，确保供应稳定且风险可控：

### 1. 立即沟通，明确需求
- **电话/即时沟通**：直接联系供应商负责人，说明旺季突发需求，并明确：
  - **需求量**：例如“下周需额外增加500公斤菠萝”。
  - **时间节点**：最晚到货时间（如“周三前需到货200公斤，周五前到齐”）。
  - **品质要求**：统一规格（如“单果重300-400克，成熟度7-8成”）。

### 2. 协商临时价格与条款
- **价格浮动机制**：因临时加单可能涉及成本，可协商：
  - **固定价格**：若供应商有库存，争取原价或小幅上调（如+5%）。
  - **浮动价格**：若需紧急调货，约定“以市场价为基础，双方确认后执行”。
- **附加条款**：明确是否含运费、是否接受分批到货、坏果处理比例（如“到货后2小时内发现坏果，按零售价1.5倍赔付”）。

### 3. 签订短期补充协议或备忘
- **书面确认**：通过微信、邮件或简易签单，包含：
  - 补货数量、规格、价格、到货时间、付款方式。
  - 违约责任：如“延迟到货每天按货款0.5%赔偿”。

### 4. 设定应急预案
- **备用供应商**：若对方无法满足，立即联系第二供货商，说明“若3天内能到货，可长期合作”。
- **替代方案**：如菠萝供应紧张，可提前准备“菠萝汁浓缩液”“冷冻菠萝丁”等替代原料，并通知后厨调整配方比例。

### 5. 跟进与长期优化
- **定期更新需求**：每天向供应商通报未来3天用量预测，便于对方备货。
- **旺季后复盘**：与供应商协商：“可否在淡季签优先供货协议，旺季月度下订量基础上，额外预留10%浮动库存？”

### 关键提醒：
- **优先签署书面记录**，避免口头承诺。
- **分批到货**：若量太大，分2-3次到货，降低一次性压货风险。
- **现场验收**：到货时必须核对数量、品质，并拍照留存（作为后续争议证据）。

通过以上步骤，既能快速满足临时需求，又能将价格、质量、风险控制在可接受范围内。
