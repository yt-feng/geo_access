采购香蕉时，**优先关注成熟度**，其次再考虑价格。原因如下：

1. **成熟度直接影响烘焙效果**：
   - **蛋糕用香蕉**：需要**完全成熟**的香蕉（表皮出现黑斑、果肉软糯、香气浓郁）。这样的香蕉糖分高、易压泥，能给蛋糕带来天然甜味和湿润口感，减少额外加糖或油脂。
   - **太生或半熟**：香蕉未充分转化淀粉，甜度不足、质地硬，做出来蛋糕会发干、缺乏风味。
   - **过熟（烂糊）**：可少量使用，但易导致蛋糕过湿或产生异味。

2. **价格与成本的平衡**：
   - 成熟度达标的前提下，再比较不同供应商的单价、批量折扣或损耗率。如果采购了便宜但未熟的香蕉，需要额外催熟（耗时、可能受环境限制），或者到使用时仍未达标，反而导致浪费和返工成本更高。

**操作建议**：
- **采购标准**：指定采购时香蕉需达到“熟透期”（表皮棕斑面积≥30%，按压微软）。可要求供应商分批次提供不同熟度，以便轮流使用。
- **价格谈判**：以“允许轻微过熟”作为筹码（例如购买即将过季的香蕉），通常能拿到更低价格，但需当天或次日用完，并控制采购量避免积压。
- **避免误区**：不要因价格低而囤积未熟香蕉，除非你有恒温催熟空间且能精准控制时间。

**总结**：用成熟度确定品质底线，在满足底线的供应商里选价格最优的。
