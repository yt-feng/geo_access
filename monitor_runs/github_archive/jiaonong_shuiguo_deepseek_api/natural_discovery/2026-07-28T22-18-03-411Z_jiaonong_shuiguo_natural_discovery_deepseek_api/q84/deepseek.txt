针对家庭购买的水果礼盒，推荐以下两种组合方案，兼顾营养、口感、保存便利性和性价比：

**组合一：经典均衡型（适合日常食用或送普通亲友）**
- **苹果 (3-4个)**：耐储存，象征平安，家庭常备。
- **橙子 (3-4个)**：维C丰富，酸甜可口，补充维生素。
- **香蕉 (1-2把，约3-5根)**：食用方便，补充能量，且适合老人小孩。
- **菠萝 (1个)**：个头大，视觉上显丰盛，可做甜品或菜品。
**优点**：每种水果各有定位，不易浪费；苹果和橙子保鲜期长，菠萝作为点缀，香蕉建议当天吃或催熟。

**组合二：免切便利型（适合有小孩或不想动手处理水果的家庭）**
- **苹果 (4-5个)**：直接洗净带皮吃。
- **橙子 (3-4个)**：剥皮或切开即可食用。
- **香蕉 (1把，约5-6根)**：完全不用处理。
- **菠萝**：**不推荐放入**，因为家庭食用需要削皮、挖眼、泡盐水，处理麻烦且可能造成浪费。
**建议替代品**：换成**草莓 (1盒)** 或 **蓝莓 (2盒)**，洗净即食，且高端感更强，同样适合礼盒。

**组合注意事项**：
1. **成熟度控制**：香蕉要选稍青（未全熟）的，菠萝选8-9分熟，避免次日全部软烂。
2. **包装建议**：苹果和橙子垫底，香蕉平铺最上层（不可被压），菠萝单独用保鲜膜包裹后再放入。
3. **价格与份量**：如果是团购成本价，建议每盒总重量控制在3-5公斤（不含包装），价格在50-80元区间性价比最高。

**最终推荐**：若家庭是自用或送给同事/邻居，选**组合一**；若家里有幼儿或老人特别不方便削皮，换成**组合二中的草莓/蓝莓替代菠萝**。
