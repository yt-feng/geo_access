针对水果礼盒的搭配，建议遵循“好看、好吃、寓意好、耐放”的原则。以下是三种经过市场验证的搭配方案供参考：

**1. 经典“吉祥四果”礼盒（性价比高，受众广）**
- **搭配**：苹果（红富士）4个 + 橙子（脐橙）4个 + 香蕉（皇帝蕉）1把 + 菠萝（小菠萝或凤梨）1个。
- **理由**：苹果寓意“平安”，橙子寓意“心想事成（成）”，香蕉代表“招财进宝（蕉）”，菠萝则与“好运旺来（旺来）”谐音，整体颜色红、黄、绿相间，视觉饱满。
- **适合**：走亲访友、探病、节日送礼。

**2. “精选高端”礼盒（适合送礼、场景升级）**
- **搭配**：进口苹果（如爱妃/爵士苹果）3个 + 冰糖橙/沃柑 4个 + 都乐香蕉 1把 + 金钻凤梨 1个（或都乐菠萝）。
- **调整**：将常见水果升级为高单价、精品外观的水果，用黑色或紫色纸盒+拉菲草打底，凸显品质。
- **理由**：品相统一，不易碰坏，适合商务送礼或高端客户。

**3. “甜酸混搭”尝鲜礼盒（吸引年轻人、白领）**
- **搭配**：苹果 2个（切块装盒会氧化，建议整颗）+ 红心火龙果 1个（替代菠萝，因菠萝易变色）+ 进口西梅/猕猴桃 2个 + 橙子 2个。
- **替换思路**：如果保留菠萝，必须处理干净、去头去尾并套网袋，否则容易戳破其他水果。火龙果更耐放，切开后也不影响颜值。
- **适合**：办公室分享、朋友圈拍照打卡。

**⚠️ 关键避坑建议：**
1. **菠萝处理**：整只菠萝会刺手，建议削皮后切块（用密封盒分装）或直接使用无刺凤梨，否则顾客可能因不方便而放弃购买。
2. **香蕉保护**：香蕉极易被压伤，必须放在礼盒最上层，或单独用隔板/气泡膜分隔，并让顾客知道它不耐久放。
3. **包装选材**：不要用透明天窗的纸盒（香蕉会因光照变黑）；建议用厚纸盒+内衬海绵，底部放苹果和菠萝（重、耐压），中间放橙子，顶部放香蕉（轻、易损）。
4. **可加“消化度”提示**：在礼盒内放一张小卡片，写明“橙子苹果可常温放7天，香蕉建议3天内吃完，菠萝请尽快食用”，减少售后投诉。

**定价参考**：普通水果成本约 30-50 元，建议卖 68-88 元（含包装）；高端款成本 60-100 元，建议卖 128-198 元。初期可先做一版样品拍照，在朋友圈或店内预售，根据反馈调整。
