向超市供应商要求提供以下资料可以降低水果农残风险：

1. **产地证明**：明确水果产地、采摘日期，确保来源可追溯。
2. **农药使用记录**：包括农药名称、使用时间、稀释倍数、安全间隔期等，确认是否按标准操作。
3. **第三方检测报告**：由官方或权威机构出具的农残检测合格报告（如GB 2763标准），建议包含常见高风险农药项目（如毒死蜱、克百威等）。
4. **供应商资质**：营业执照、食品经营许可证、种植基地备案证明等。
5. **承诺书**：供应商签署的书面承诺，保证产品符合农残限量标准，并承担抽检不合格责任。
6. **批次合格证明**：每批次进货时，要求供应商提供对应的出厂检验报告或抽样检验证明。

建议建立“索证索票+自行抽检”双重机制，日常记录存档备查。
