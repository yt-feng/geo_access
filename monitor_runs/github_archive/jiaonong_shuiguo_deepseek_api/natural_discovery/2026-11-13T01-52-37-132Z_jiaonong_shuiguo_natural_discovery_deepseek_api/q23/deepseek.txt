能，而且通常是常规操作。超市做水果促销时，供应商一般能提供以下几类支持，但具体取决于品类、合作模式和门店政策：

1. **陈列支持**
   - 提供陈列方案、堆头/端架设计、POP物料
   - 派促销员或理货员到店协助陈列、补货、整理
   - 提供陈列道具（果篮、层架、价签卡座等）

2. **海报/宣传物料**
   - 提供单品海报、吊旗、爆炸贴、价签、展架
   - 提供产品图片、卖点文案、短视频素材
   - 部分供应商可承担海报印刷费用或与超市联合投放

3. **试吃支持**
   - 提供试吃果品、试吃台、一次性餐具、手套
   - 派试吃员到店执行（需符合门店食品安全和试吃管理要求）
   - 承担试吃损耗或按约定分摊

**实操建议：**
- 促销前在采购合同或促销协议里明确：支持项目、数量、到店时间、费用承担方、损耗归属。
- 试吃涉及食品安全，提前确认门店是否允许、是否需要健康证、试吃时段和位置。
- 陈列和海报支持最好要求供应商提供“到店执行确认单”，避免只给物料不落地。
- 如果供应商不支持，可谈“费用折让”或“进货折扣”替代。

一句话：能要，而且应该提前写进促销方案里，明确谁出物料、谁出人、谁承担损耗。
