建议按 **“菜单定位 + 出杯量 + 人工条件”** 来选，直接结论：

- **主打“鲜切菠萝果茶”、有后厨人力、日销量稳定**：买**鲜果**最合适。
- **追求出杯稳定、节省人工、门店空间小**：买**果丁（冷冻/糖渍/罐头果丁）**更稳。
- **做冰沙、奶昔、调味茶、需要标准化拼配**：用**果泥**更合适。

具体判断：

1. **鲜果**
   - 优点：卖点强、香气自然、可做“现切”展示，适合中高端果茶。
   - 缺点：损耗高、去皮去眼费人工、甜酸波动大，旺季品质不稳定。
   - 适合：有切配人员、日销量大、菜单强调“鲜果现切”的门店。
   - 注意：菠萝需盐水/糖水短泡处理，控制氧化和涩感；采购按日均用量少量多次。

2. **果丁（冷冻果丁/糖渍果丁/罐头果丁）**
   - 优点：出杯快、规格稳定、损耗低，适合连锁和外卖占比高的店。
   - 缺点：鲜感弱于现切，糖渍款要调整糖度，冷冻款解冻后口感会变软。
   - 适合：大多数中小茶饮店做常规菠萝果茶，尤其是人工紧张的门店。
   - 注意：优先选**冷冻原果丁**或低糖糖渍款；看配料表，避免糖水占比过高。

3. **果泥**
   - 优点：标准化最好、风味浓、适合冰沙和复配，出杯速度快。
   - 缺点：缺少果肉咀嚼感，不适合做“果肉感”强的果茶；开袋后保存期短。
   - 适合：做菠萝冰沙、菠萝乳酸菌、复合果茶底，或作为果丁的补充。
   - 注意：选**原浆/果泥**而非“果味酱”，看果汁含量和添加糖。

**最推荐的采购组合：**
- 单店/中小店：**冷冻菠萝果丁为主 + 少量鲜果做顶饰或卖点**。
- 高销量鲜果茶店：**鲜果为主 + 果泥调底**，兼顾鲜感和稳定。
- 外卖/连锁：**果丁 + 果泥**，标准化优先。

采购前先做小批量测试：同一配方分别用鲜果、果丁、果泥出杯，比较**香气、果肉感、酸甜稳定度、单杯成本、人工耗时和损耗**，再定主采购形态。
