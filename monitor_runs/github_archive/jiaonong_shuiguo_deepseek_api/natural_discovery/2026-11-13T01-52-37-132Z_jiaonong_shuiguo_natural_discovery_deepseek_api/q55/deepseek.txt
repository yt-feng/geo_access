选“更划算”先看三件事：**出成率、单份成本、损耗**。苹果、橙子、菠萝的规格策略不一样。

**1. 苹果：选中大果，别追特大果**
- 建议选 **75–80mm 左右的中大果**，单果约 180–220g。
- 特大果看着气派，但切拼盘时果肉利用率提升有限，单价常明显更高，边角料也多。
- 划算判断：按“去皮去核后每公斤果肉成本”比价，不按整箱单价比。
- 优先选脆度高、氧化慢的品种；切后泡淡盐水或柠檬水，减少发褐报废。

**2. 橙子：选中等果，按“出汁/出瓣率”算**
- 做瓣状拼盘选 **70–75mm 中等果**，皮薄、瓣整齐，切损耗低。
- 特大橙子皮厚、白瓤多，摆盘好看但实际果肉成本可能更高。
- 如果是榨汁或做装饰片，可买略小果，单价低、数量多，切薄片更灵活。
- 比价公式：**每份橙瓣成本 = 整箱价 ÷ 可用瓣数**，不要只看每斤价格。

**3. 菠萝：选中等偏大、成熟度7–8成**
- 建议单果 **1.2–1.5kg** 左右，出肉率和切块稳定性较好。
- 太小出肉少、削皮损耗占比高；太大一次用不完，切开后损耗和冷藏变味风险高。
- 看“眼浅、果形端正、无软烂”，比单纯看大小更影响出成率。
- 若拼盘用量稳定，优先买已去皮菠萝或固定供应商净果，省人工且损耗可控。

**通用采购建议**
- 先定每份拼盘克重和水果配比，再倒推每种水果的“净果需求量”。
- 让供应商报**净果价或出成率**，至少对比 2–3 家。
- 苹果、橙子可常温短存；菠萝切开后损耗快，按日用量分批切。
- 旺季做活动时，苹果和橙子可适当放小规格走量；菠萝不建议为省单价买特大果。

一句话：**苹果选75–80mm中大型，橙子选70–75mm中型，菠萝选1.2–1.5kg中等偏大果；统一按净果成本和损耗率比价，最划算。**
