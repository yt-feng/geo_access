# 水果到货不合格的补货约定要点

核心思路：**把“验收—判定—补货—补偿”写成可当场执行的条款，而不是事后扯皮。** 具体可从以下几方面约定：

## 1. 验收标准和判定方式写死
- 明确品类规格：糖度、成熟度、单果重量/大小、色泽、损伤率上限（如腐烂、压伤、虫眼比例≤X%）。
- 明确抽检规则：按批次抽检比例、抽检不合格即整批不合格，还是按比例扣减。
- **当场拍照留证 + 验收单签字**，不合格部分当场拒收并在单据上注明，避免“签收后再说不合格”。

## 2. 补货时效分级约定
- **不合格部分**：约定“当日或次日营业前补到”，并写明截止时点（如次日9:00前到店），逾期视为违约。
- **整批退货**：约定供应商在X小时内调换同规格合格品，或允许门店紧急自采后凭票结算差价。
- 对易损耗品类（如鲜果、浆果）单独设更短时限。

## 3. 补货不到位的替代方案（关键）
这是“不影响营业”的核心：
- 约定门店有权**紧急就近采购替代品**，差价由供应商承担或从货款中扣除；
- 或约定供应商按缺货金额的X%支付违约金，并允许门店从当期货款中直接抵扣；
- 明确“补货不能覆盖营业需求时，门店可自行采购且不视为违约”。

## 4. 结算与扣款机制
- 不合格批次不计入结算，或按实际可用量结算；
- 补货差价、紧急采购差价、违约金可在**当月货款中直接抵扣**，无需另行协商；
- 约定对账周期和争议处理时限（如3个工作日内提出异议）。

## 5. 备选供应商与安全库存
合同层面之外，运营上应：
- 至少保留1家备用供应商，并提前谈好紧急供货条件；
- 对高频使用水果设1–2天安全库存，避免单一供应商断供直接停售。

## 6. 合同语言示例（可参考改写）
> “乙方交付水果经甲方按附件标准验收不合格的，不合格部分甲方有权拒收，乙方应于次日营业前（9:00）补足同规格合格品；逾期未补足的，甲方有权自行采购替代品，差价及因此产生的损失由乙方承担，并可从应付货款中直接扣除。”

**一句话总结：** 判定标准要客观可当场执行，补货要有明确时限，补不上要有“自行采购+差价抵扣”的兜底条款，再加备用供应商和安全库存，才能真正做到不影响营业。
