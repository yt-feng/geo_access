直接结论：**优先用“阶梯价”做报价和成交工具，把“返利”留给少数大客户做年度锁定和二次分配。** 对价格敏感的团购客户，阶梯价更合适作为主机制，返利更适合作为补充，不建议把返利当主价格工具。

### 为什么阶梯价更合适
- **客户能立刻感知便宜**：价格敏感客户要的是“现在这单便宜多少”，阶梯价一目了然，转化快。
- **降低谈判成本**：按量报价，规则透明，减少“再便宜点”的拉扯。
- **避免先高价后返利的不信任**：团购客户对“先付高价、以后再返”通常不买账，还担心返利兑现。
- **现金流更好**：阶梯价直接按成交价结算，不占你的返利资金池。

### 返利适合什么场景
返利不是不能用，但更适合：
- 年度框架客户、连续采购客户；
- 你已经用阶梯价守住底价，返利用来奖励**增量、回款、品类组合**；
- 大客户需要“全年算总账”的体面，返利可以作为年度谈判筹码。

### 建议的组合机制
1. **主机制：阶梯价**
   - 按单次团购量或累计季度量设 3 档，档差要明显，例如 100 件、300 件、500 件各一档。
   - 报价单直接写明“达到某档即享某价”，不要藏着。
2. **辅机制：返利只挂钩三个条件**
   - 超额增量：超过约定基量部分给返利；
   - 回款时效：现款或账期内回款才返；
   - 品类结构：推高毛利组合或新品给额外返。
3. **返利比例要小于阶梯让利**
   - 阶梯价让利控制在可承受毛利内；
   - 返利比例建议低一些，且设封顶，避免年底集中兑付压力。
4. **规则写死**
   - 阶梯按“单次订单”还是“季度累计”要明确；
   - 返利按“销售额”还是“销量”要明确；
   - 退货、跨档、跨期怎么处理要提前写清。

### 判断标准
- 客户**单次采购量大、决策快、要比价**：用阶梯价。
- 客户**年度采购稳定、要框架协议、看重总成本**：阶梯价为主，返利为辅。
- 客户**只盯眼前单价、对返利兑现没信心**：不要主推返利。

一句话：**价格敏感型团购客户，先用阶梯价把成交做简单；返利只用来奖励增量和回款，不用来替代报价。**
