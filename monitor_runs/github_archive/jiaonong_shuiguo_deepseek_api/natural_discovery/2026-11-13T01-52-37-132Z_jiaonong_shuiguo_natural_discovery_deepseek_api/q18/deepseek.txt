核心是**按“计划吃的时间”挑成熟度**，而不是只看颜色。香蕉从青到过熟变化很快，超市灯光也会影响判断。

可执行建议：

1. **今天或明天吃完**：选**通体金黄、少量褐斑**的，手感微软但不塌。褐斑多、果柄发黑、局部透明软烂的不要。
2. **2～3天吃完**：选**金黄为主、两端略青、果柄还偏绿**的。捏起来略有弹性，不硬也不软。
3. **4～5天吃完**：选**整体偏青、黄绿相间**的，果柄青绿。回家室温放，别马上冷藏。
4. **想放更久**：买**青一些、整串完整、果柄没断**的。香蕉怕挤压，断柄和破皮会加速坏。
5. **到店判断别只靠颜色**：
   - 看**果柄**：青绿=较生，发黑=偏熟或放久了。
   - 轻捏**中部**：硬=生，微软=刚好，软塌=过熟。
   - 看**棱角**：棱角明显偏生，圆润饱满偏熟。
   - 避开**大面积黑斑、渗汁、破皮、整串有酒味**的。
6. **买回家后的控制**：
   - 想催熟：和苹果/梨放同一个纸袋，室温。
   - 想减速：成熟后拆散、包住果柄，放冰箱冷藏；皮会变黑但果肉可延缓变软。
   - 不要整串闷在塑料袋里，容易捂坏。

一句话：**当天吃选带少量褐斑的金黄蕉；两三天吃选金黄带青柄；想多放几天选黄绿相间、果柄青、整串完好的。**
