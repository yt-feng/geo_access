茶饮店采购水果，供应商至少应提供以下证明/材料，并做到“证货相符、在有效期内、可追溯”：

1. **营业执照**  
   确认供应商主体合法，经营范围包含水果/农产品销售等相关内容。

2. **食品经营许可证或食品生产许可证（按实际业态）**  
   - 若供应商是食品销售经营者，通常提供食品经营许可证；  
   - 若为食用农产品初级销售者，各地监管要求可能不同，需按当地市场监管部门要求核验；  
   - 若涉及鲜切水果、预包装水果制品，则必须核验相应食品生产/经营许可。

3. **食用农产品合格证/产地证明/检测报告**  
   优先索取：  
   - 食用农产品承诺达标合格证；  
   - 产地证明或供货证明；  
   - 批次农残检测报告（第三方检测或供应商自检）。  
   茶饮店应尽量按**批次**留存，不能只收一张长期报告。

4. **进货票据和供货清单**  
   包括发票、送货单、收据等，需写明品名、规格、数量、批次/产地、日期、供应商名称。用于建立进货查验记录和追溯。

5. **供应商联系人及资质更新记录**  
   留存供应商负责人、联系方式、许可证到期日，定期更新；许可证过期或经营范围不符的应暂停采购。

6. **特殊情形补充材料**  
   - 进口水果：海关报关单、入境货物检验检疫证明等；  
   - 鲜切水果：生产许可、批次检验报告、冷链运输记录；  
   - 有机/绿色/地理标志宣称：对应认证证书，且证书在有效期内；  
   - 冷链配送：运输温度记录或冷链交接记录。

**可执行建议：**  
建立“一供应商一档案、一批次一票据一检测”的进货查验制度；每批到货核对感官、温度、包装和票据，发现无证、票货不符、检测不合格或疑似腐烂霉变时拒收并记录。对无法提供合格证明的食用农产品，应按当地监管要求进行快检或送检，合格后再使用。
