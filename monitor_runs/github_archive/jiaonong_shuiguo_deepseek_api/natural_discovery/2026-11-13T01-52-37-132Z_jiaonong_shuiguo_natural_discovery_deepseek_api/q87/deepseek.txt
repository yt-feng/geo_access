旺季锁库存的核心不是“提前打招呼”，而是把**需求量、锁货规则、违约成本、履约节奏**四件事提前写清楚。可以按下面执行：

**1. 先做需求预测，再谈锁货**
- 按历史同期销量、当前预售/社群接龙、复购率，拆到**品类、SKU、单日/单周**需求量。
- 给供应商一个“保底量+弹性量”：例如保底70%，旺季前一周可追加30%。
- 不要只报总量，要报**到货节奏**：哪天到多少、分几批、最早/最晚到货时间。

**2. 用“框架协议+预付款/保证金”锁货**
和供应商签旺季供货框架，至少写清：
- 锁定的SKU、规格、等级、产地、包装标准；
- 锁价期限和调价机制（如仅因产地极端天气可协商，需提前书面通知）；
- 保底采购量和弹性追加量；
- 预付款比例或保证金，换取优先排产/优先发货权；
- 违约条款：供应商缺货、迟到的赔付；你方取消保底量的赔付；
- 质量验收和退换货规则。

**3. 要求供应商给“库存可视+优先发货”**
- 让供应商按周反馈备货进度、在库量、采摘/分拣计划；
- 约定你方订单在同期客户中的**优先级**；
- 关键SKU要求“专库/专批”预留，避免被临时高价截单。

**4. 用“多供应商+主次分配”防单点断供**
- 每个核心水果品类至少2家供应商：主供70%-80%，备供20%-30%；
- 备供也要提前给预测和少量订单，保持合作活跃，否则旺季调不动货。

**5. 分批到货+动态补单**
- 旺季不要一次压满库存，按“日销+安全库存”分批到货；
- 设置补单触发线：当某SKU库存低于2-3天销量时自动追加；
- 对易腐水果控制单批到货量，优先保履约而不是囤货。

**6. 提前锁定物流和分拣能力**
- 锁货同时确认供应商的装车时间、冷链/常温条件、到仓窗口；
- 爆单期物流比货更紧张，要求供应商书面确认承运方式和延误责任。

**7. 合同外留好沟通记录**
- 微信/邮件确认的锁货数量、价格、到货时间也要留存；
- 每周开一次旺季供需碰头会，形成书面纪要。

一句话：**用保底量换优先权，用预付款换锁定，用多供应商防断供，用分批到货控损耗。** 先谈核心3-5个爆款SKU，不要一次性把所有品类都锁死。
