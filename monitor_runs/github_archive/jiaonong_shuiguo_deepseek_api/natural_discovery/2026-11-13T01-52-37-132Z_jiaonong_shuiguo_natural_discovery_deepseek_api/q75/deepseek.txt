第一次合作水果供应商，小批量试单的核心目标不是“赚钱”，而是**低风险验证供应商是否可靠、货是否对路、售后是否担责**。建议按下面设计。

## 1. 先定试单原则

- **单品种、小批量**：不要一次上5个品类，选你最有把握卖掉的1～2个单品。
- **金额可控**：试单金额控制在你能承受“全亏也不影响现金流”的范围，通常占你日销/周销预估的10%～20%。
- **不压仓**：宁可卖断货，不要剩一仓。水果损耗高，试单以“当天/隔天周转”为目标。
- **先验货再放量**：第一单就不要求最低价，要求稳定和可追责。

## 2. 选品设计

优先选：
- 你已有稳定下游客户、价格透明、周转快的单品；
- 耐储运、规格标准、损耗可判断的品类，如苹果、梨、橙、部分瓜类；
- 避开极难保鲜、成熟度难控、售后争议大的品类，如高熟度浆果、易软熟桃、叶菜等。

试单品种建议：
- 第1单：1个主推单品，量控制在1～3天能卖完；
- 第2单：再加1个邻近品类，验证供应商多品供应和分拣能力。

## 3. 数量与批次设计

不要只下一单，建议设计**2～3次小批次**：

- **第1批：最小验证单**  
  每个单品少量，重点看：到货成熟度、规格、损耗率、包装、到货时间。
- **第2批：重复单**  
  同一单品再下一次，验证第1批问题是否复现，以及供应商处理售后的态度。
- **第3批：小幅放量单**  
  前两批稳定后，数量提高到第1批的1.5～2倍，仍不压仓。

每批之间留出销售观察期，不要连续压货。

## 4. 合同/订单里必须明确的条款

即使是小单，也要在订单或聊天记录中写清：

- **品名、品种、规格**：果径、重量、等级、成熟度、产地；
- **数量与包装**：箱规、净重、毛重、每箱个数；
- **价格与费用**：单价、运费、卸货费、是否含税/含票；
- **到货时间与地点**：几点前到、迟到如何处理；
- **验收标准**：允许损耗率、次果率、软烂/冻伤/霉变判定；
- **售后规则**：坏果比例超过多少可赔、补货还是退款、拍照留证时限；
- **结算方式**：首批建议货到验收后付款，或少量定金+验收尾款，避免全款预付。

## 5. 验收流程要标准化

到货后当场做：

1. **抽箱检查**：随机抽3～5箱，不要只看最上面一层；
2. **称重核对**：净重是否足；
3. **分级计数**：好果、次果、坏果分别计数；
4. **测成熟度**：切开或手感判断，是否能按计划天数卖完；
5. **拍照留证**：外包装、标签、开箱、坏果、称重照片；
6. **记录损耗率**：按箱/按斤计算，形成供应商评分。

建议设定试单红线，例如：
- 坏果/软烂率超过约定标准，要求补货或扣款；
- 规格明显不符，整批可退或折价；
- 到货延迟影响销售，记录并作为后续是否放量依据。

## 6. 试单评估表

每批货后给供应商打分：

- 到货准时率；
- 规格符合度；
- 净重足量率；
- 坏果/损耗率；
- 口感与成熟度；
- 包装是否适合你的运输和存放；
- 售后响应速度与是否兑现；
- 价格是否有竞争力。

**连续2～3批稳定，再谈放量和账期；有一批出现严重问题且售后不担责，就不要因为价格便宜继续加大合作。**

## 7. 和供应商沟通的话术要点

可以直说：

> “我们先小批量试两到三批，主要看规格、成熟度、损耗和售后。第一批按最小起订量走，验收后结算；如果稳定，第二个月逐步放量。希望把等级、损耗赔付和到货时间写清楚。”

这样既表明长期合作意愿，又把风险控制在试单阶段。

**一句话总结：试单要“小金额、少品类、多批次、严验收、写售后、看复购”**。第一批不求低价，求可验证；第二批看稳定性；第三批才小幅放量。
