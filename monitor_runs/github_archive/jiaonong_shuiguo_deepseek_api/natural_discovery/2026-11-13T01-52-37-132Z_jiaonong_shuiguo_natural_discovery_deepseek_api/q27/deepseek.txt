判断苹果、橙子大小规格是否适合门店销售，核心不是“越大越好”，而是看**目标客群、陈列方式、定价方式和损耗**。可以按下面几步直接判断。

### 1. 先定门店销售场景
不同场景适合的规格不同：

- **社区生鲜店/便利店**：更适合中等规格，单果重量适中，顾客一次买几个，价格敏感。
- **精品水果店/高端超市**：可接受大果、礼盒果，但要求外观整齐、果径均匀、卖相好。
- **食堂/团购/批发档口**：更看重量和出成率，规格可偏大，但价格要低。
- **线上到家/社区团购**：中等偏小、按份售卖更合适，避免单果过大导致一份总价过高。

### 2. 苹果怎么判断规格
苹果门店销售重点看**果径、单果重、均匀度、外观**。

常用判断标准：
- **果径**：用分级板或卡尺抽测。门店零售常见中等果径更稳妥；礼盒或精品陈列可选大果，但必须大小一致。
- **单果重**：抽称一箱，看平均单果重和最大最小差。门店零售更适合单果重适中、差异小的货。
- **均匀度**：同一箱内大小差太大，陈列难看，也容易顾客挑拣，增加损耗。
- **外观**：果形端正、无明显畸形、无严重锈斑、无碰伤。大小合格但碰伤多，也不适合门店。
- **硬度与新鲜度**：苹果规格合适但发绵、失水，不适合正常货架销售。

可执行动作：
- 每批抽 20～30 个，测果径和单果重；
- 计算平均单果重、最大最小差；
- 看一箱内大小是否基本一致；
- 结合售价算单果毛利和顾客接受度。

### 3. 橙子怎么判断规格
橙子除了大小，还要看**果径、皮厚、汁水、酸甜度、损耗**。

常用判断标准：
- **果径**：用分级圈或卡尺抽测。门店零售一般中等果径更好卖，太大单价高，太小显得不实惠。
- **单果重与均匀度**：同批次大小要整齐，方便按个卖或按斤卖。
- **皮厚与出汁率**：皮太厚、空壳感强，顾客复购差；可切开或手掂判断。
- **外观**：表皮干净、无明显病斑、无严重机械伤。轻微花皮可做特价，严重伤果不适合正价陈列。
- **成熟度**：太青酸度高，太熟易软烂。门店销售要选成熟度适中、耐摆放的批次。

可执行动作：
- 抽测果径和单果重；
- 随机切 3～5 个看皮厚、汁水、籽和酸甜；
- 看一箱内坏果、软果比例；
- 按目标售价倒推：顾客按个买是否觉得贵，按斤买是否显得小。

### 4. 用“陈列和定价”反推规格
最实用的判断方法：

- **按个卖**：单果不能太大，否则单价高；也不能太小，否则顾客觉得不值。
- **按斤卖**：中等均匀规格最好，大小混杂会被挑拣。
- **礼盒卖**：必须大且均匀，外观优先。
- **特价引流**：可接受偏小或轻微花皮，但坏果率要低。

### 5. 到货验收时直接看这几个指标
建议每批做抽检记录：

| 品类 | 必看指标 | 不适合门店的信号 |
|---|---|---|
| 苹果 | 果径、单果重、均匀度、碰伤、硬度 | 大小差异大、碰伤多、发绵失水 |
| 橙子 | 果径、单果重、皮厚、汁水、病斑、软果 | 皮厚空壳、软烂多、酸度过高、病斑明显 |

### 6. 简单决策规则
可以这样判断：

- **大小均匀、无明显伤、单果重量适合目标售价**：适合门店正价销售。
- **大小偏大但均匀、外观好**：适合精品陈列或礼盒，不适合社区店大量散卖。
- **大小偏小但均匀、口感好**：适合特价、按份卖或社区团购。
- **大小混杂、伤果多、软烂多**：不适合门店正价销售，除非能快速折价处理。

**一句话：门店销售看“均匀度 + 外观 + 单果价格接受度 + 损耗率”，不是单纯看大小。** 每批抽测果径、单果重、坏果率，再结合按个/按斤售价倒推，就能判断是否适合。
