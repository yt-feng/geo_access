建议先从**香蕉**试起，但前提是把它当作“引流+稳定周转”的品类，而不是高毛利品类。更稳妥的排序是：

**香蕉 > 菠萝 > 苹果**（作为“先引入、先跑通”的顺序）

判断依据如下：

1. **香蕉：最适合先跑通供应链**
   - 消费频次高、认知强、价格敏感，动销通常最稳。
   - 进口蕉（如菲律宾、厄瓜多尔等产地）供应链成熟，规格和包装标准化程度较高。
   - 风险点：损耗和催熟管理要求高，必须控制进货量和成熟度。超市若无催熟/温控能力，容易因过熟产生损耗。
   - 适合先做：小批量、固定周配、明确成熟度标准，先验证周转和损耗。

2. **菠萝：适合作为第二品类**
   - 进口菠萝（如哥斯达黎加、菲律宾等）有差异化卖点，客单价和毛利空间通常比香蕉好。
   - 但消费频次低于香蕉，且存在去皮、成熟度、口感不稳定等体验问题。
   - 适合在香蕉跑通冷链/周转后引入，先做小规格、可即食或试吃推广。

3. **苹果：不建议作为“第一个进口水果”**
   - 国产苹果供应充足、价格竞争强，进口苹果差异化有限。
   - 进口苹果对冷链和库存周转要求高，一旦动销不及预期，损耗和资金占用更明显。
   - 更适合在已有稳定进口水果客流后，作为补充品类引入。

**可执行建议：**
- 第一步：选1—2个进口香蕉SKU，小批量试销4—6周，重点看：周销量、损耗率、毛利率、缺货率。
- 设置止损线：若损耗率明显高于门店水果平均、或周周转低于预期，先缩量而不是扩品。
- 香蕉跑通后，再加入1个进口菠萝SKU做试吃和即食场景。
- 苹果最后引入，优先做差异化品种，而不是普通红富士类同质化产品。

一句话：**先用香蕉验证进口水果的冷链、周转和损耗管理能力，再扩菠萝，苹果放后面。**
