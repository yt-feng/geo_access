# 香蕉批发验货判断方法

## 一、看颜色（最直接）
- **青绿**：未熟，适合长途运输或需要催熟后再卖，但要看有没有“青硬”过头的僵果。
- **青转黄（尖端/棱线先黄）**：正常走熟，2～4天可售，适合批发中转。
- **黄中带绿棱**：成熟度适中，货架期约3～5天。
- **全黄、少量黑点（芝麻点）**：已熟，1～2天内必须出手，适合直接供水果店零售。
- **大面积黑斑、发黑发软**：过熟或已开始腐坏，压价也要谨慎，坏果率会快速上升。

**关键**：颜色要均匀，同一箱里颜色差异大说明成熟不齐，分拣和损耗都会增加。

## 二、摸果身判断
- **硬**：未熟，适合催熟或远途。
- **微软有弹性**：正好，可正常销售。
- **局部软塌、按下去不回弹**：内部可能已烂，重点检查软处对应的果柄和果身。
- **果身发黏**：已开始腐败，整箱风险高。

抽查时从箱底、中间、四角各拿几根，不要只看表层。

## 三、看果柄和切口
- 果柄 **青绿、切口新鲜**：采摘和运输状态好。
- 果柄 **发黑、干枯、霉点**：存放久或受潮，坏果风险高。
- 果柄与果身连接处 **发黑渗液**：通常从这里开始烂，要重点翻查。

## 四、查棱线和果指形态
- 棱线明显、果指饱满：正常。
- 棱线特别突出、果指瘦小：可能是未充分发育或僵果，催熟后口感差。
- 果指之间挤压变形、有压痕：运输挤压伤，后续容易从压伤处发黑腐烂。

## 五、闻气味
- 正常：清淡果香。
- **酸味、酒味、霉味**：已发酵或霉变，整批要警惕，尤其箱底和中间。

## 六、开箱抽查比例
- 大批量至少抽 **5%～10% 的箱子**，每箱抽上中下三层。
- 重点看 **箱底和中间**，这两处最易积热、压伤、闷坏。
- 记录：软果数、黑斑果数、果柄霉变数、异味箱数。

## 七、判断坏果风险的几个信号（出现越多风险越高）
1. 箱内有冷凝水、纸箱潮湿发软。
2. 果柄普遍发黑或有霉。
3. 同一箱颜色差异大、软硬不一。
4. 有酒味/酸味。
5. 箱底有压烂果、渗液。
6. 到货时已全黄且带大量黑点（说明路上走熟过度）。

## 八、给批发商的实操建议
- **要远途/囤货**：选青转黄、果身硬、果柄青绿、无冷凝水的货。
- **要快销**：选黄中带绿棱、微软、芝麻点少的货，当天到当天走。
- **压价收货**：全黄带黑点的货只能按“当天清”算，且要扣掉预估坏果率（通常按 5%～15% 扣重或折价，视黑斑和软果比例）。
- **合同/单据**：写清成熟度、坏果扣重标准，到货后先抽检再卸完，发现问题当场拍照留证。

**一句话总结**：颜色看均匀度、果身看软硬是否一致、果柄看新鲜度、气味看有没有发酵，再重点翻箱底和中间——这四项过关，坏果风险基本可控。
