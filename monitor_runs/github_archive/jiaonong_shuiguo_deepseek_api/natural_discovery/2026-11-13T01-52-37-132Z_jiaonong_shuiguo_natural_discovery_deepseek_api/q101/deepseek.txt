和水果供应商谈酒店早餐合作，重点是把“稳定”落到可执行的条款和日常管理上。建议从以下几方面谈：

**1. 先明确自己的需求**
- 列出早餐常用水果品类、每天/每周用量、可接受的价格区间。
- 明确供货频率、送货时间（最好在早餐开始前1–2小时到货）、验收地点。
- 区分固定品类和季节替换品类，避免只依赖单一品种。

**2. 供应稳定性要写进合同**
- 约定缺货时的替代方案：提前多久通知、用什么品类替代、价格如何调整。
- 约定最低供货保障和旺季/节假日的保供安排。
- 要求供应商有备用货源或二级供应渠道，不能一句“尽量保证”了事。

**3. 品质标准和验收规则要具体**
- 按品类写明成熟度、大小、外观、新鲜度要求，比如有无碰伤、腐烂、异味。
- 约定验收不合格的处理：拒收、换货时限、扣款或索赔。
- 最好每次到货当场验收并签字，留照片或记录，避免事后扯皮。

**4. 价格与结算方式**
- 问清报价是否含税、含运费、含装卸。
- 价格随行就市时，约定调价机制：提前通知、参考市场价、设置涨跌幅上限。
- 结算周期、发票类型、对账方式提前谈清楚。

**5. 食品安全与资质**
- 要求提供营业执照、食品经营许可、产品检测报告或产地证明。
- 明确农残、霉变、异物等问题的责任和赔偿。
- 送货车辆、周转箱、人员卫生也要有基本要求。

**6. 配送与售后**
- 迟到、少送、错送的处理规则要写清楚。
- 设置对接人和应急电话，早餐时段出问题能马上联系到人。
- 约定定期复盘，比如每月看一次缺货率、退货率、投诉情况。

**7. 先试合作再长约**
- 可以先签1–3个月试供，考察稳定性、品质和响应速度。
- 试供合格后再谈长期价格和账期，避免一上来被长约锁死。

**8. 别把鸡蛋放一个篮子**
- 主力供应商之外，保留一个备选供应商或本地应急采购渠道。
- 对特别依赖的品类，提前谈好备用方案。

一句话总结：合同里写清“供什么、什么时候供、什么标准、缺货怎么办、不合格怎么赔”，日常做好验收和记录，比单纯压价更重要。
