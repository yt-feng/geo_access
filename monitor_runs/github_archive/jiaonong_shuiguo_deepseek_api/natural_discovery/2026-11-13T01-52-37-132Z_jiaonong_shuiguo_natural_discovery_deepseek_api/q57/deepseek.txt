绝大多数餐饮连锁采购水果，**优先建议中央厨房/区域配送中心统一收货**，但要做“分级收货”：耐储水果统一收，易损、短保、门店即用水果可门店直收或前置仓配送。不要一刀切。

**统一收货更适合的情况：**
- 门店数量多、跨区域，需要统一品质标准和供应商管理。
- 水果用于中央厨房加工、切配、统一配方出品。
- 采购量大，能集中议价、集中质检、集中结算。
- 需要追溯批次、控制损耗责任、防止门店私采。
- 有冷链仓储和配送能力，能做到“收货—分拣—配送”时效闭环。

**门店分开收货更适合的情况：**
- 草莓、蓝莓、熟成牛油果、鲜切果盘用果等极短保、易压伤品类。
- 门店距中央厨房远，二次配送时间长、损耗高。
- 门店有成熟验收能力和本地优质供应商，且总部能统一价格、标准和审计。
- 单店用量小、品种多，集中配送反而增加拆零和物流成本。

**推荐落地模式：**
1. **A类耐储水果**：苹果、橙子、柠檬、西瓜等，中央厨房统一收货、统一质检、按门店订单配送。
2. **B类短保易损水果**：莓果、葡萄、芒果、牛油果等，区域配送中心收货后短链配送，或供应商直送门店但总部统采统价。
3. **C类门店即用鲜切/装饰水果**：允许门店直收，但必须接入总部供应商池、统一验收标准、拍照留档、批次追溯。

**关键判断指标：**
- 二次配送后损耗率是否高于门店直收；
- 中央厨房质检能力是否强于门店；
- 配送频次能否覆盖水果保鲜周期；
- 门店私采和串货风险是否可控；
- 总成本是否包含物流、损耗、人工验收和资金占用。

**结论：**  
有中央厨房和冷链配送能力的连锁，**以中央厨房统一收货为主、门店直收为辅**最稳；没有配送能力或水果极短保的门店，盲目统一收货会增加损耗和成本。先按水果品类分级，再定收货主体。
