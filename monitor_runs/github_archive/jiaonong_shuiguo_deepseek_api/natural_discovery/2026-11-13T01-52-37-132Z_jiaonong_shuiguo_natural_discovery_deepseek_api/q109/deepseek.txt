优先谈 **账期**，其次 **配送**，最后 **售后**。原因不是售后不重要，而是长期合作里三者的“谈判价值”和“失控成本”不同。

**1. 账期优先谈：直接影响现金流和合作稳定性**
水果是高频、易损耗、价格波动大的品类，账期会放大你的资金占用和坏账风险。长期合作最怕“量越做越大，现金越压越死”。
建议谈清楚：
- 账期天数：如货到7天/15天/30天，不要只说“月结”。
- 结算起点：以验收合格、对账确认还是签收为准。
- 对账周期和付款日：固定某日对账、某日付款。
- 逾期与缺货抵扣规则：质量问题、短少如何冲抵货款。
- 超额供货/临时调价是否仍按原账期。
判断标准：如果供应商要求长账期但价格明显更低，要算资金成本；如果对方账期很紧但配送售后强，可先用短账期换稳定供应，再逐步拉长。

**2. 配送第二谈：决定损耗率和门店/仓库执行成本**
水果配送的核心不是“送到”，而是**准时、温控、验收、异常补送**。配送不稳会直接造成缺货、损耗和客诉。
建议谈清楚：
- 配送频次、截单时间、到货时间窗。
- 冷链/常温要求，装车温度和到货温度谁记录。
- 验收标准：规格、成熟度、破损率、短少怎么判。
- 异常补送时限：缺货、晚到、品质不达标几小时内补。
- 临时加单/减单规则和费用。
判断标准：配送条款要能落到“迟到怎么办、坏了怎么办、少了怎么办”，否则只是口头承诺。

**3. 售后最后谈：重要，但通常可在账期和配送框架下解决**
售后包括品质异议、退换货、损耗赔付、客诉处理。它很关键，但长期合作中，售后问题多数源于配送和验收标准不清。先把账期和配送验收谈细，售后争议会少很多。
建议谈清楚：
- 售后申请时限：到货后几小时内提异议。
- 举证方式：照片、视频、留样、批次号。
- 退换/补发/折价的选择顺序和响应时限。
- 月度损耗率上限及超额处理。
- 责任边界：到货验收后风险转移，还是保留一定追溯期。

**谈判顺序建议：**
先谈账期框架，再谈配送和验收标准，最后把售后作为兜底条款写进合同。不要一上来只压价，长期合作中账期、配送稳定性、售后响应往往比单价更能决定总成本。

一句话：**账期先保现金流，配送再保履约，售后做兜底；三者在合同里都要量化，不能只靠关系。**
