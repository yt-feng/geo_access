先看一个核心原则：**坏果责任划分看“坏果发生在谁控制商品的环节”，以及顾客是否在合理时间内按规则反馈。** 不能一概而论让顾客承担，也不能所有坏果都由平台兜底。

可按以下场景判断：

1. **到货即发现明显腐烂、霉变、压烂、异味**
   - 通常由商家/平台承担主要责任，属于采摘、包装、分拣、仓储或配送环节的品控/保鲜问题。
   - 顾客拍照/视频留证后，应支持退款、补发或按坏果比例赔付。
   - 若快递外箱严重破损、挤压变形，商家赔付后可向承运方追偿，但不建议让顾客自己去和快递扯皮。

2. **外观完好，顾客签收后放置较久才坏**
   - 要区分“到货时已潜在变质”与“顾客储存不当”。
   - 若在商家承诺的保鲜期内、按说明储存仍快速变质，商家应承担相应责任。
   - 若顾客未按储存要求（如该冷藏未冷藏、闷在高温车内多日）导致，顾客承担主要责任。

3. **个别坏果 vs 大面积坏果**
   - 个别坏果：按比例赔付或补发，属于正常生鲜损耗范围，商家应承担售后。
   - 大面积坏果：优先整单退款/补发，并排查批次、包装、冷链和配送时效问题。

4. **顾客未及时反馈或无法提供证据**
   - 商家可要求合理时限内提供坏果照片、开箱视频、订单信息。
   - 超过合理售后时限且无证据，责任难以归到商家，可协商处理，但不宜直接认定商家全责。
   - “合理时限”应在购买页面或售后规则中提前写明，不能事后随意加码。

5. **配送环节问题**
   - 快递延误、暴力分拣、未按冷链要求配送导致坏果，商家对顾客先承担责任，再依据承运合同向物流方追偿。
   - 顾客当面签收时发现外箱严重破损、液体渗漏，可拒收或当场拍照反馈。

6. **平台/商家规则层面**
   - 建议明确：坏果赔付标准（按个数、重量或订单比例）、举证要求、反馈时限、补发/退款优先级。
   - 对反复恶意索赔可建立风控，但正常坏果投诉不应设置过高举证门槛。

**可执行结论：**
- 到货即坏、开箱有证据：商家/平台主责，退款或补发。
- 签收后因顾客储存不当坏：顾客主责。
- 无法判断原因：按保鲜期、储存说明、开箱证据和反馈时效综合协商，商家可承担部分责任。
- 物流导致：商家先赔顾客，再向物流追偿。

一句话：**谁控制环节出问题谁担责；商家对顾客承担首要售后责任，顾客需在合理时限内举证反馈。**
