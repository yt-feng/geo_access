判断批发档口“一手货源”是否稳定，不要只听对方说，建议按下面几层做可核查的验证：

1. **先确认真实货源身份**
   - 让对方说明是产地合作社、种植基地、代办、还是外地调货商。真正一手货源通常能说清产区、园口/基地、装货点、包装厂。
   - 要求提供近期装车视频、果园或包装厂照片、装车单、产地证明/购销合同样本。注意视频要能对应当天或近期，不要接受网图。
   - 问清是“自有基地”还是“合作基地”。自有基地看面积、品种、采收周期；合作基地看合作年限和每天可调货量。

2. **用小额试单验证履约**
   - 先做1—2车小批量试单，不要一上来大额预付。试单重点看：承诺装车时间是否准时、果品规格是否一致、催熟状态是否适合你的销售节奏、损耗和次果比例。
   - 试单时故意把要求写细：品种、果指长度、每把条数、青度/熟度、单箱净重、装箱方式、到货时间、次果率上限。能按书面标准履约的，才谈稳定。

3. **核查持续供货能力**
   - 问三个数字：当前每天可稳定供多少车/件、连续供多少天、断档时怎么补。让对方给出近一个月实际发货记录，如装车单、物流单、过磅单，至少能交叉验证。
   - 香蕉有产区和季节差，稳定供货不等于全年同一产区。靠谱的供货商会明确告诉你：几月主供哪里、换产区时价格和品质会怎么变、断货提前几天通知。
   - 看对方是否有备用产区或合作代办。只有一个园口、一个产区的“一手”，遇到天气或集中采收就容易断。

4. **看资金和结算方式是否合理**
   - 对方坚持大额全款预付、拒绝小单试货、不愿写违约责任的，风险高。
   - 稳定货源通常接受“定金+装车尾款”或“货到验收后结部分”，具体看行业习惯，但合同里要写清：装车标准、到货验收、次果扣款、延迟发货责任、断货赔偿。
   - 警惕明显低于市场价的报价，香蕉损耗和运输成本透明，过低价格往往用次果、催熟过度或短斤少两找补。

5. **做同行和现场背调**
   - 问对方合作过哪些市场档口，最好要到2—3个同行联系方式回访：是否准时、果品是否稳定、售后是否扯皮。
   - 有条件就去产地装货点看一次，重点看：当天实际装车量、包装工人是否忙碌、冷库/催熟库是否正常、是否有固定物流车。现场比电话可靠。
   - 查营业执照和经营者身份，确认收款账户与经营主体一致，避免个人账户频繁变更。

6. **建立自己的验收指标**
   - 每批记录：到货时间、净重、次果率、青度、催熟后货架期、损耗金额。连续3—5批数据稳定，再逐步放大采购量。
   - 把“稳定”定义为可量化：比如连续4周每周能按约定供2车、准时率≥90%、次果率不超过约定值、断货提前48小时通知。达不到就换备选。

一句话：**先验证身份和装货现场，再小额试单，用书面标准和连续几批数据判断，不要用大额预付换口头承诺。** 同时始终保留一个备用供货商，香蕉这种生鲜品类，单一“一手货源”本身就不等于稳定。
