先说结论：**大多数社区水果店，最好采用“整果陈列、顾客自己挑、现削代削收费或免费”的组合方式；不建议大量提前削好去皮果作为主力销售。**

具体可以这样判断和操作：

1. **整果陈列 + 顾客自选是主模式**
   - 菠萝外观差异大，顾客通常愿意自己挑。
   - 整果耐放、损耗低，卖不掉还能调整陈列或促销。
   - 让顾客参与挑选，成交感和信任度更高。
   - 标价要清楚：按个、按斤还是按份，避免纠纷。

2. **提前去皮果只适合少量补充**
   - 适合赶时间、不会削、现场冲动购买的顾客。
   - 但去皮后失水快、易氧化、保质期短，损耗明显更高。
   - 如果提前削，建议只做少量试销，放在冷藏柜，明确标注削皮时间和价格。
   - 不建议把去皮果作为主陈列，否则容易造成“挑剩的整果没人要、削好的又卖不完”。

3. **现场代削是很好的增值服务**
   - 顾客挑整果，店里提供现场削皮、切块、装盒。
   - 可以免费代削引流，也可以收少量加工费；看周边竞争和人工成本决定。
   - 代削能同时保留“自己挑”的体验和“去皮方便”的价值。
   - 要注意卫生：刀具、案板、手套、包装分开，削皮区尽量透明可见。

4. **按客群调整比例**
   - 社区店、中老年顾客多：整果为主，代削为辅。
   - 写字楼、商场、年轻人多：可增加小份去皮果盒，但控制数量。
   - 景区、车站、即时消费场景：去皮果盒比例可以高一些，但要快进快出。

5. **实操建议**
   - 整果区：按成熟度分开陈列，标“即食/放两天再吃”。
   - 代削区：明码标价，先问顾客要不要切块、去眼。
   - 去皮果盒：每天少量制作，标注时间和价格，当天未售完及时处理。
   - 观察一周数据：整果销量、代削比例、去皮果损耗，再调整备货。

一句话：**主力卖整果让顾客自己挑，现场代削做服务，去皮果盒只做少量补充。** 这样损耗最低、顾客选择最多，也最不容易压货。
