第一次试单，核心不是“找最低价”，而是用最小成本验证供货商的**稳定性、损耗率、结算规则和补货能力**。夫妻店建议按下面做。

## 1. 先定试单原则
- **少量多频**：第一次每家只拿 1～2 箱，不要一次压满。
- **先试周转快的**：香蕉周转快但损耗高，苹果耐放，橙子居中。三类一起试，能看出不同品类的供货水平。
- **至少找 2～3 家**：一家批发市场档口、一家本地配送商、一家产地/二级批发，平行对比。
- **不签长约、不押大额预付款**：先现结或小额定金，跑 2～3 次再谈账期。

## 2. 三类货怎么试
**香蕉**
- 试单量：先拿 1 箱，要求“青转黄”程度适合你店 2～3 天卖完。
- 看：到货成熟度是否一致、有没有催熟不均、断把多不多、箱底压伤。
- 关键问清：是生蕉还是熟蕉、催熟方式、当天卖不完怎么处理、次日补货能不能到。

**苹果**
- 试单量：1 箱中等规格，别只拿样品箱。
- 看：大小是否均匀、有没有暗伤/碰伤、箱内上下层是否一致、净重是否足。
- 关键问清：产地和品种是否固定、规格分级、坏果包换比例。

**橙子**
- 试单量：1 箱，重点看皮厚、干水、酸度、大小混装。
- 看：切开 2～3 个试口感，检查箱底有没有霉变和压伤。
- 关键问清：当季产地、甜度档位、是否打蜡、坏果怎么算。

## 3. 试单时必问的 8 个问题
1. 起送量多少？配送费怎么算？
2. 今天下单，明天几点到？临时补货能不能当天送？
3. 报价是毛重还是净重？箱皮、托盘算不算钱？
4. 坏果、烂果、压伤怎么赔？拍照后补货还是扣款？
5. 价格多久变一次？节假日前会不会临时涨？
6. 结算方式：现结、周结还是月结？有没有押金？
7. 能不能固定规格和成熟度？换货找谁？
8. 退货规则：卖不动或质量问题，多久内可退？

## 4. 试单验收动作
- 到货**当场开箱**，上下层都查，拍照留证。
- 记录：到货时间、净重、坏果数、成熟度、口感、实际售价和当天销量。
- 香蕉单独记“到店后第 1/2/3 天”的销售和损耗；苹果、橙子记 3～5 天损耗。
- 每类货算一个简单账：**进货价 + 运费 + 损耗 = 真实成本**，不要只看报价。

## 5. 判断是否继续合作
连续试 2～3 次后，满足以下再考虑长期：
- 到货时间稳定，临时补货能响应；
- 坏果率可接受，赔付不扯皮；
- 净重足、规格稳定，不是“样品好、大货差”；
- 真实成本算下来有合理毛利；
- 结算规则清楚，不临时加价或压款。

**避坑提醒**：第一次不要被“低价整箱包圆”吸引；不要只看最上面一层；不要口头约定赔付；香蕉不要一次进太多熟度高的货。先小单跑三轮，比一次拿低价大货更稳。
