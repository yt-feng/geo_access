三者都重要，但优先级不是并列的：**食品安全是底线，配送准时是保障，价格是优化项**。企业食堂采购水果，建议按这个顺序决策：

1. **食品安全优先**
   - 水果一旦农残超标、腐烂霉变或储存污染，可能造成群体性食安事件，食堂责任远大于省下的采购差价。
   - 重点看：供应商资质、批次检测/农残报告、到货验收标准、冷链或储存条件、退换货与追溯机制。
   - 这是“一票否决项”，不能因价格低而放宽。

2. **配送准时其次**
   - 企业食堂用餐时间固定，水果到货晚会影响备餐、验收和菜单执行；到货过早又可能增加储存损耗。
   - 重点看：固定配送窗口、缺货/延误的替代方案、节假日和旺季保供能力。
   - 准时不是“越快越好”，而是“按食堂验收和备餐节奏稳定到货”。

3. **价格最后优化**
   - 在满足食安和配送稳定的前提下再比价，避免低价中标后出现以次充好、缺斤少两或临时加价。
   - 建议用“同等品质、同等验收标准下的综合成本”比较，而不是只看单价。

**可执行判断标准：**
- 供应商准入：食安资质和检测能力不合格 → 直接淘汰。
- 日常考核：延误率、缺货率、验收合格率设阈值；食安问题零容忍。
- 商务决策：先锁定2—3家合格供应商，再在合格池内比价和分配份额。

所以结论是：**食品安全最需要关注，配送准时排第二，价格排第三但必须持续优化。**
