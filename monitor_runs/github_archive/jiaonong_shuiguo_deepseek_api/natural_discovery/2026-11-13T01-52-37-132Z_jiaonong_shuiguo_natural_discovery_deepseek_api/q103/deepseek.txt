结论：**食堂水果优先按“斤（称重）”结算，次选按“份”；按箱只适合少数耐储、规格稳定的品类，且要折算到斤/份验收。** 核心原因是水果非标、损耗大、价格波动快，管理重点不是“结算单位”本身，而是**验收标准、损耗归属和价格可比性**。

### 三种方式的管理优劣

**1. 按斤结算——最适合食堂主采购**
- 优点：价格可比、可核价；验收可复称；损耗和实际用量对得上；适合多品种、小批量、日常配送。
- 缺点：称重和验收工作量大；水分、包装、筐重、损耗容易扯皮。
- 适用：苹果、梨、香蕉、柑橘、西瓜等大宗水果，以及绝大多数日常采购。
- 管理要点：**净重验收**（去箱/筐/袋重）、固定秤、双人验收、每周核价；合同约定破损率/烂果率上限和退换规则。

**2. 按份结算——适合窗口售卖和标准化配餐**
- 优点：结算简单、出餐可控、便于成本卡和售价管理；减少称重争议。
- 缺点：份量标准难统一；供应商容易在单份净含量上做文章；不适合作为原料采购主方式。
- 适用：切配果盘、酸奶水果杯、配餐水果、固定克重的净果。
- 管理要点：合同写死**每份净含量（克）**、允许误差、抽检频次；按份采购时必须定期抽检复称。

**3. 按箱结算——最不推荐作为主方式**
- 优点：交易快、适合耐储品类和整箱配送。
- 缺点：箱内大小、净重、烂果率不透明；价格不可比；损耗和短斤少两难追责；不同批次差异大。
- 适用：西瓜、苹果、橙子等规格相对稳定的整箱采购，且必须是**固定规格箱**。
- 管理要点：合同明确**箱规、净重下限、烂果率上限**；到货抽箱复称并折算单价；不合格整箱退换。

### 建议的食堂组合方案
- **主采购按斤**：日常大宗水果全部按净重结算，建立每周询价/核价机制。
- **净果/果盘按份**：切配、配餐、窗口售卖用固定克重份装，便于成本核算。
- **整箱仅作补充**：只对规格稳定的品类按箱采购，但验收时折算净重和可食率，避免“按箱糊里糊涂”。
- **统一验收口径**：去皮净重、烂果率、规格（大小/成熟度）、退换时限写进采购单；称重和抽检留记录。
- **损耗归属清晰**：运输和到货前损耗归供应商，入库后归食堂；设定合理损耗率，超损扣款或退换。

一句话：**能用斤就不用箱，能定克重就按份；按箱可以买，但必须按斤验收。**
