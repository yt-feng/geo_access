可以直接把采购要求写成“熟度分级 + 到货节奏 + 验收拒收”三条，别只口头说“不要太熟”。

**1. 采购时怎么要求熟度**
按香蕉表皮颜色和手感分等级采购，最实用的是用“色号”约定：

- **主推零售用：3～4号色**
  - 3号：绿中带黄，适合放2～4天卖；
  - 4号：黄多绿少，适合1～3天内卖完。
- **当天/次日要卖：5号色**
  - 全黄、少量糖点，适合立即促销或做果切。
- **不要整批进6号以上**
  - 大面积糖点、表皮发软、果柄发黑，货架期很短。
- **手感要求**
  - 果身硬挺、有弹性，不软塌；
  - 果柄不霉、不黑腐；
  - 无大面积机械伤、裂果、水烂。

采购单可写：**“香蕉以3～4号色为主，5号色不超过当批20%；果身硬挺，无软熟、无霉柄、无裂果。”**

**2. 到货时间怎么要求**
按销售节奏分批到，不要一次压太多：

- **日常门店：每周2～3次小批量到货**，比一次大批量更稳。
- **要求到货后上架可售期**
  - 3号色到店后至少还能卖3～4天；
  - 4号色至少还能卖2～3天。
- **避开高温时段到货**，夏季尽量早晨或傍晚收货，减少闷热催熟。
- **明确“到货即入库/上架”**，不要在月台、车内久放。

**3. 验收和拒收标准**
到货当场抽检，写进采购约定：

- 抽检比例：每批至少抽3～5箱/件，看底层和中间。
- 拒收情形：
  - 整批超过约定色号，如要求3～4号却大量5～6号；
  - 软熟比例超过5%～10%；
  - 果柄霉变、明显水烂、裂果多；
  - 到货温度高、闷箱有酒味。
- 可约定：**超熟部分按折价或退货处理，连续两批不达标更换供应商。**

**4. 配套卖法**
采购要求之外，门店也要配合：香蕉不要堆太厚，避免压伤；先进先出；4～5号色及时做“熟蕉特价”或果切，别等全黑再处理。

一句话采购话术：**“我要3～4号色为主，5号色少量，果身硬挺无霉柄；每周分2～3次小批量到，到店后3号色至少还能卖3天，超熟和软烂比例超标我这边拒收或折价。”**
