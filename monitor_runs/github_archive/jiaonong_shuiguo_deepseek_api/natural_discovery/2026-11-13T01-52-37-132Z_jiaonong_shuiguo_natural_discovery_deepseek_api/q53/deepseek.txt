优先找“本地二级水果批发商 + 固定档口”，比找果农、平台、商超都省心。理由是：量小、要天天送、要能临时补货、要能退换次品，果农不接小单，平台售后慢，商超价高。

具体这样选：

1. **首选：本地水果批发市场里做餐饮配送的档口**
   - 找有固定摊位、能开票/开收据、有面包车配送的。
   - 谈“每天固定时间送、按当日市场价结算、坏果包换、可临时加单”。
   - 先试送3—5天，看准时率、损耗率、补货响应。

2. **次选：本地生鲜配送商/餐饮供应链小公司**
   - 适合你店附近有网点、能覆盖每日配送的。
   - 要求签简单月度协议：品项、规格、验收标准、缺货替代规则、坏果赔付。

3. **不建议作为主供**
   - 果农/果园：起送量高、品项单一、配送不稳定。
   - 电商大平台：小单履约不稳、售后周期长。
   - 超市：价格高，不适合每天少量。
   - 社区团购：品质波动大，不适合餐饮出品稳定。

谈判时盯住5条：
- **固定送达时间**：比如每天9点前到店。
- **按市场价浮动**：约定参考哪个市场、哪天报价。
- **验收标准**：大小、成熟度、坏果率，比如坏果超5%整批退换。
- **缺货替代**：提前1小时告知，允许换同等价位品项。
- **结算方式**：先周结或半月结，试稳后再月结。

最省心的组合是：**1家主供档口 + 1家备选档口**，主供每天送，备选应急补货。先小批量试一周，别一上来签长约。
