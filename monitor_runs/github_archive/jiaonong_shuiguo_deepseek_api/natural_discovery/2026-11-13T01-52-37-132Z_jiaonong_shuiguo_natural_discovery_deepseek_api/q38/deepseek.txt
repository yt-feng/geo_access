大型超市对水果供应商的要求，本质上是“食品安全合规 + 冷链物流稳定 + 可追溯与召回 + 规模化履约”四条线同时达标。可按下面清单判断供应商是否合格。

## 一、食品安全能力（硬门槛）

1. **合法资质**
   - 营业执照、食品经营/生产相关许可（按业态）
   - 食用农产品承诺达标合格证或产地证明
   - 若为进口水果：海关入境货物检验检疫证明、报关单等

2. **农残与污染物控制**
   - 有产地准出检测或第三方检测报告（农残、重金属等按标准）
   - 能按超市要求提供批次检测报告，接受抽检
   - 对禁限用农药有产地管理和供应商审核机制

3. **可追溯体系**
   - 做到“批次—产地—采收/加工—运输—交付”可追溯
   - 有批次编码、台账、出入库记录
   - 能配合超市追溯系统对接或提供追溯凭证

4. **召回与不合格处置**
   - 有召回程序：通知、下架、封存、原因分析、整改
   - 有不合格品隔离区和处置记录
   - 能配合超市和监管部门的应急处置

5. **现场卫生与加工管理**
   - 分选、包装场所卫生、防虫防鼠、人员健康证
   - 清洗、分级、包装过程避免交叉污染
   - 包装材料符合食品接触要求

6. **体系与审核**
   - 常见要求：ISO22000/HACCP、GAP、BRCGS等（不同超市要求不同）
   - 能接受超市验厂、飞行检查、整改闭环

## 二、物流与冷链能力

1. **冷链设施**
   - 预冷能力（采后快速预冷）
   - 冷藏/保鲜库、温湿度监控与记录
   - 冷藏车/保温车，按品类控温（如叶菜、浆果、热带水果温区不同）

2. **运输管理**
   - 车辆清洁消毒、防交叉污染
   - 温度全程记录可查，异常报警与处置
   - 装载规范：防挤压、防日晒、防雨淋，分区装载

3. **时效与履约**
   - 能按超市到货窗口配送，准时率稳定
   - 有波次拣配、订单履约和异常补货能力
   - 高峰期（节假日、促销）有运力储备

4. **仓储与库存管理**
   - 先进先出/批次管理，避免过期和品质衰减
   - 库存温湿度、损耗率可控
   - 有退货、换货和临期处理机制

5. **信息化**
   - 订单、库存、物流、追溯数据可对接
   - 能提供到货温度记录、批次信息和异常报告

## 三、规模化与品控运营能力

- **稳定货源**：产地基地或长期合作产区，能应对季节和气候波动
- **分级包装**：按超市标准分级、规格化包装、标签合规
- **损耗控制**：采后处理、预冷、包装、运输全链条降损
- **应急能力**：缺货替代、质量异常快速换货、舆情和召回响应

## 四、快速判断供应商是否达标

让对方提供并核验：
1. 资质证照与批次检测报告
2. 追溯台账样例和召回预案
3. 冷库、冷藏车、温控记录
4. 近3个月准时交付率和质量退货率
5. 验厂报告或体系证书
6. 高峰期运力与应急方案

**结论**：大型超市水果供应商至少要同时具备“合规资质+批次检测+可追溯+召回处置”的食品安全闭环，以及“预冷+冷链仓储+控温运输+准时履约+信息化”的物流闭环；缺一项都可能在上架审核或日常考核中被淘汰。
