选择适合批量配送的水果供应商，建议按下面顺序判断，重点看“稳定性、配送能力、售后”而不是只看单价。

**1. 先明确采购约束**
- 人数、人均预算、配送时间窗口（下午茶通常要求当天下午前送达）
- 是否需要洗净/切果/分装/摆盘
- 配送地址是否可停车卸货、有无电梯、收货人是否固定
- 是否需要发票、对公付款、食品经营资质

**2. 供应商类型优先级**
- **本地水果批发商/配送商**：适合批量、价格稳，但要确认是否做小B配送、能否按份分装。
- **生鲜B2B平台**：履约稳定、售后流程清楚，适合公司采购，但价格略高。
- **连锁水果店/社区团购供应商**：适合中小批量、临时补货，大批量配送能力要核实。
- **产地直供/农场**：价格可能好，但配送时效和售后风险高，不适合对时效要求强的下午茶。

**3. 必须核实的硬指标**
- **配送能力**：当天几点前下单、几点送达、是否冷链/常温车、能否送到楼层、迟到怎么赔付
- **批量分装**：能否按部门/人数分袋、贴标签、配一次性叉子/纸巾
- **品控标准**：坏果率上限、大小规格、成熟度、能否先送样品
- **售后**：坏果/少件/迟到如何处理，是否当场补送或退款，响应时间
- **资质与结算**：营业执照、食品经营许可证、能否开票、账期

**4. 小范围试单再定**
先选2–3家，各下一个小批量试单，重点看：
- 实际到货时间与承诺是否一致
- 坏果率、成熟度、分装质量
- 出问题后的响应速度
试单通过后再签长期或批量协议。

**5. 合同/订单里写清楚**
品种规格、数量、单价、送达时间、验收标准、坏果赔付、迟到处理、发票类型、联系人。避免只口头约定。

**简单判断标准：** 能接受“先试单”、能明确承诺送达时间和坏果赔付、能按份分装并送到楼层的供应商，优先考虑；只报低价但不承诺时效和售后的，不建议用于公司下午茶。
