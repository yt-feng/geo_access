建议优先做**单根 + 小把（3–5根）两种，整袋先少量试销**。判断依据如下：

1. **主推单根**  
   - 适合便利店“即时消费、低决策成本”场景，顺手买、配早餐、下班路上吃。
   - 单价低、损耗可控，卖相不好的可以及时下架，不至于整把报废。
   - 对客流不稳定的小店最稳。

2. **搭配小把（3–5根）**  
   - 适合家庭临时补货、办公室分享。
   - 比整袋更灵活，客单价略高，损耗比大袋低。
   - 建议用透明或半透明包装，标清根数和价格。

3. **整袋谨慎上**  
   - 整袋适合家庭囤货，但便利店客流以即时需求为主，整袋动销通常慢于单根和小把。
   - 香蕉易压伤、易过熟，整袋一旦有坏果，整袋报废，损耗高。
   - 如果要做，先小批量试销，选6–8根左右、透气包装，并放在显眼位置做特价。

**执行建议：**
- 先按 **单根60%、小把30%、整袋10%** 的陈列比例试2–3周。
- 每天检查成熟度：单根和小把可分级定价，熟度高的做“即食特价”。
- 记录三类包装的日销量、损耗率和毛利，保留动销最好的两类，整袋若连续两周损耗高就撤掉。
- 香蕉不要和苹果、梨等释放乙烯的水果大量混放，避免催熟过快。

结论：**便利店最稳的是“单根为主、小把补充、整袋试销”**，不要一开始就主推整袋。
