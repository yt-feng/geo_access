水果店遇到坏果，关键是**先留证据、按合同/约定分责、再谈赔付方式**。可按下面流程处理：

## 1. 先别急着卖或扔，固定证据
- 到货当场或发现后第一时间拍照/录像：坏果整体、局部特写、箱码/批次、数量、称重记录。
- 保留送货单、进货单、聊天记录、合同/报价单。
- 最好让供应商到场确认，或发视频/照片给对方并让其回复确认。
- 记录坏果率：坏果重量÷该批次总重量。

## 2. 看双方约定
优先按合同、订单、微信约定、行业惯例处理。常见分责：
- **运输前已坏/产地问题**：供应商承担。
- **运输途中损坏**：看谁安排物流、谁承担运费和风险。
- **到货后因存放不当、挤压、超时销售造成**：一般门店自担。
- **自然损耗/轻微瑕疵**：按约定折价或门店承担。

## 3. 常见结算/赔付方式
可单选或组合：
1. **补货**：供应商补同等数量好果，坏果退回或就地处理。
2. **扣款/折价**：按坏果重量×进货单价扣减货款；严重时按合同约定加扣违约金。
3. **换货**：整批或部分换货，运费由责任方承担。
4. **退货退款**：坏果率高、无法销售时整批退回。
5. **下次进货抵扣**：金额小、长期合作时常见，但要书面确认金额和期限。
6. **分级降价**：轻微瑕疵可降价后门店自行处理，但需明确“处理后不再追责”。

## 4. 建议的谈判口径
- “这批共进X公斤，确认坏果Y公斤，坏果率Z%，按进货单价A元/公斤，应扣款Y×A=元；请在本次货款中扣除/补货。”
- 若合同有质量条款，直接引用条款；没有合同就引用双方历史习惯和聊天记录。
- 不要只口头说“下次少算点”，要留下文字确认：数量、单价、金额、处理方式、完成时间。

## 5. 注意风险
- 不要先把坏果处理掉再通知供应商，容易举证困难。
- 不要擅自把坏果混入好果销售，涉及食品安全和消费者权益。
- 扣款前最好取得供应商确认；对方不确认时，保留证据并按合同争议条款处理。
- 长期合作可约定：到货验收时限、坏果率阈值、赔付标准、运费承担、超期视为认可。

**一句话：先取证，再按约定定责，能补货优先补货，不能补货按坏果重量×单价扣款或退货；所有结果文字确认。**
