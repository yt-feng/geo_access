香蕉和菠萝做社区团购，售后控制的重点不在“出了坏果怎么赔”，而在**把损耗拦在用户看到之前**。按品类分开管：

## 香蕉：控催熟和交付节点

香蕉的主要售后是“到手太生/已发黑/一碰就烂”。

1. **按团期倒推成熟度采购**：今天团、明天自提，就进七成熟偏青的货；当天团当天提，可进八成熟。不要一次进全熟货。
2. **拆箱散热，别闷袋**：到货后立即拆原箱，分开放，避风阴凉，温度高时开风扇对流。香蕉不能冷藏，也别和苹果、梨混放（乙烯催熟）。
3. **分把售卖+分级**：好果做正价团，轻微碰伤、过熟的单独做“秒杀/熟蕉特价”，明示“适合当天吃/做奶昔”，比混装后被投诉划算。
4. **自提点只放当天量**：多出来的留在分拣点，按自提时段分批补货，避免在团长处放一晚变黑。
5. **售后规则前置**：明确“表皮少量黑点不影响食用”“断裂一根不理赔”等边界，减少无效售后。

## 菠萝：控切口和分切时效

菠萝的主要售后是“黑心、酸涩、切开后发现坏”。

1. **整果优先，少做预切**：预切菠萝损耗和客诉都高。要做分切，只在自提前2小时内切，切后冷藏并当天售完。
2. **到货抽检黑心**：菠萝黑心从外表看不出来，按批次抽切2–3个验货，有黑心比例高的批次整批退回或转特价处理，不进正价团。
3. **按成熟度分流**：青一点的整果卖，让用户放两天；熟果做“即食/分切”团，标注“建议当天食用”。
4. **削皮服务标准化**：提供削皮就当场削、装盒冷藏，不提前大量削好堆着。
5. **售后凭证**：要求用户切开后拍照/视频，黑心、烂心直接补或退；口味偏酸不算质量问题，提前在文案里说明品种口感。

## 通用机制（两类都适用）

- **损耗预算**：高损耗品按销售额预留3%–8%做售后准备金，超过就调整采购量或停团。
- **少量多批**：宁可团两次、每次少进，也不要一次压货。香蕉菠萝都不适合压库存。
- **坏果包赔但限时**：自提后24小时内凭图申请，超时不受理，避免“放坏了再来赔”。
- **团长培训**：给团长一张“验收+存放+售后话术”卡片，明确哪些赔、哪些不赔、怎么拍照。
- **供应商责任前置**：和供货商约定黑心率、烂果率的退换标准，到货当场验，别等售后爆发再扯皮。

核心一句话：**香蕉管成熟度和存放，菠萝管黑心抽检和分切时效；用少量多批+分级销售+限时凭证售后，把损耗变成可控成本。**
