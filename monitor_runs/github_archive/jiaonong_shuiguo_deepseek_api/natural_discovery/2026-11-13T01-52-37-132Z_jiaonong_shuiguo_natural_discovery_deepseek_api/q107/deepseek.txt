会，而且香蕉和菠萝的损耗风险对起订量特别敏感，但原因不完全一样。

**香蕉：起订量高最主要的损耗风险是“集中催熟/集中变黄”**
- 香蕉通常是青蕉采购、催熟后销售，起订量高意味着同一批次、同一催熟周期的货集中到店/到仓。
- 如果销量跟不上，货架期很短，容易出现整批同时过熟、发黑、被拒收。
- 香蕉对温度、乙烯、机械伤敏感，高起订量会放大“卖不完只能降价/报损”的概率。
- 判断点：看你的日均销量、催熟批次安排、是否有分级销售和加工渠道（果切、烘焙、奶昔）。

**菠萝：起订量高主要增加“仓储占用 + 成熟度不一致 + 切口/腐烂”风险**
- 菠萝耐储性比香蕉好一些，但高起订量会拉长库存周转，后期容易出现底部腐烂、黑心、果眼霉变。
- 整箱/大起订量下，成熟度批次不齐，先熟的先坏，后熟的又占库位。
- 如果做鲜切，起订量高还会增加切开后氧化、冷藏损耗和报废。
- 判断点：看周转天数、仓储通风条件、是否按成熟度分档销售、是否有鲜切/果汁消化能力。

**可执行判断建议**
1. 用“起订量 ÷ 日均销量”算周转天数：香蕉建议尽量控制在2–3天内周转，菠萝可略长但也不宜堆太久；超过这个数，损耗风险明显上升。
2. 对比“采购单价优惠”与“预计报损成本”：高起订量省下的单价差，如果小于预计损耗金额，就不划算。
3. 要求供应商分批到货、分批催熟，或把大起订量拆成多频次小批量。
4. 对香蕉重点管催熟批次和先进先出；对菠萝重点管成熟度分档、通风和底部检查。
5. 如果没有稳定的加工/促销消化渠道，起订量越高，越应该谨慎。

结论：**会。香蕉主要是集中成熟和短货架期风险，菠萝主要是库存周转和成熟度/腐烂风险。起订量是否安全，关键看“周转天数 + 分批能力 + 消化渠道”，不是只看单价。**
