先给结论：**不要一上来谈“账期多久、额度多少”，而是把“大客户稳定供货”拆成可验证的合作条件，用“账期换量、额度换保障、阶梯换稳定”来谈。** 水果生鲜损耗高、价格波动大，账期和额度必须和采购量、结算表现、风险控制绑定，否则很容易变成你单方面垫资。

下面给你一套可直接照着谈的框架。

## 1. 先明确你要的是什么

批发商谈大客户，核心不是“给账期”，而是换三样东西：

1. **采购量的确定性**：月度最低采购量、品类结构、下单频次。
2. **回款的可预期性**：固定对账日、固定付款日、逾期处理。
3. **风险的兜底**：预付款、保证金、担保或缩短账期条款。

谈判时先把“我能给你稳定货源、优先分级、锁价窗口、损耗赔付”摆出来，再谈账期。否则对方只会觉得你在求订单。

## 2. 账期怎么谈：从短到长，阶梯给

建议不要直接给30天或60天，而是设计**阶梯账期**：

- **首月：现款现结或3—7天短账期**，先跑通对账、验收、退换货流程。
- **连续合作2—3个月、无逾期、退货率低于约定值**：账期延长到15天。
- **季度采购达标、回款稳定**：账期给到30天。
- **半年以上稳定大客户**：可谈30—45天，但必须绑定最低采购额和担保措施。

关键话术：
> “账期不是固定福利，是合作信用。我们先按7天跑两个月，您采购量稳定、对账无争议，我再给您申请30天。这样您拿到的账期是稳的，我这边也能持续供货不涨价。”

**注意**：水果行业账期起算点要写清楚——是“到货验收合格日”还是“对账单确认日”，否则容易扯皮。建议用“对账单确认后X天付款”，并约定每月固定对账日。

## 3. 额度怎么谈：额度=月采购额×账期系数×风险折扣

不要拍脑袋给额度，用公式算：

**信用额度 ≈ 月均采购额 × 账期天数/30 × 风险系数**

风险系数建议：
- 新客户、无担保：0.3—0.5
- 合作3个月以上、回款正常：0.6—0.8
- 有保证金或担保：0.8—1.0

举例：对方月采购10万，你给15天账期，风险系数0.5，额度约2.5万。这样即使逾期，敞口也可控。

额度也要**动态调整**：
- 连续2个月超额度且按时回款，可申请上调；
- 出现逾期，额度立即冻结或下调；
- 额度不等于承诺放货，超过额度部分现款或预付。

## 4. 必须写进协议的保障条款

谈账期和额度时，配套条款比数字更重要：

1. **预付款/保证金**：首单可要求20%—30%预付，或收1—2周货值的保证金，合作稳定后抵扣或退还。
2. **最低采购承诺**：给了账期和额度，对方要承诺月度最低采购量，未达标则账期回退。
3. **逾期条款**：逾期几天暂停供货、逾期利息或违约金、超过约定天数转为现款。
4. **价格与损耗规则**：明确锁价周期、涨跌价通知机制、到货验收标准和损耗赔付上限，避免“账期给了、损耗扯皮把利润吃光”。
5. **对账机制**：固定对账日、对账单确认时限，逾期未提异议视为确认。
6. **停止供货权**：额度用尽或逾期时，你有权暂停发货且不承担断供责任。

## 5. 谈判顺序建议

1. 先谈**供货标准**：品类、等级、频次、损耗处理。
2. 再谈**采购承诺**：月度最低量、季度增量。
3. 然后谈**结算方式**：先短账期，再阶梯延长。
4. 最后谈**额度和担保**：额度按公式给，担保按风险配。
5. 所有口头承诺落到书面，尤其是账期起算日、逾期处理、额度调整条件。

## 6. 一句话判断标准

如果对方只要求“账期长、额度高”，却不给最低采购量、不接受对账规则、不愿给任何担保，**这不是稳定大客户，是拿你的资金做无风险周转**。这种客户宁可先做现款，也不要为了“大客户”三个字把现金流搭进去。

你可以先按“首月7天账期、额度按月采购额30%—50%、连续3个月达标再延到30天”去谈，这是水果批发里比较稳的起步方案。
