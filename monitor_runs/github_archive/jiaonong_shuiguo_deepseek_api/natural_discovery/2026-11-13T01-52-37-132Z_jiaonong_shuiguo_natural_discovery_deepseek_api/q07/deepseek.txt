### 推荐主推3个价位

**1）走量款：39—59元“平安如意盒”**
- 苹果 4个（选大小均匀、红亮）
- 橙子 4个
- 香蕉 1小把（5—6根，选偏青一点）
- 菠萝 不放整只，放1个小菠萝或不做
- 定位：日常探亲、员工小福利、社区团购
- 卖点话术：**平安（苹果）如意（橙子）、顺顺利利（香蕉）**
- 注意：这个价位不建议放整只菠萝，成本和体积都容易把盒子撑爆。

**2）主推利润款：69—99元“四色果礼盒”**
- 苹果 4—6个
- 橙子 4—6个
- 香蕉 1把（5—6根，青熟适中）
- 菠萝 1个中小果
- 搭配：用拉菲草/彩纸隔开，菠萝放底层或侧位，香蕉不要压
- 定位：走亲访友、生日、小节日
- 卖点：**四样水果、颜色全、盒子显大**，这是最好卖的中档礼盒。

**3）高客单款：129—169元“果篮/精装礼盒”**
- 苹果 6个
- 橙子 6个
- 香蕉 1把
- 菠萝 1个
- 可加少量填充叶材或固定卡纸
- 定位：送长辈、送客户、节日礼
- 注意：高价款不能只靠这四样堆量，否则会显得“廉价量大”。要靠包装、分级和陈列提升档次。

### 搭配比例建议
- **苹果、橙子做主体**：耐放、寓意好、颜色稳，占成本和体积的60%—70%。
- **香蕉做点缀**：提升“丰富感”，但选偏青的，避免第二天发黑。
- **菠萝做视觉焦点**：一盒最多1个，中小果优先；整只菠萝要固定好，避免刺破其他水果。
- **不要四样等量堆满**：容易显得杂乱，也压高成本。

### 更好卖的几个细节
1. **按价格带陈列**：39/69/99三档并排，让顾客一眼选。
2. **苹果和橙子要分级**：礼盒里不能有大小不一、有斑点的果子。
3. **香蕉单独包护**：用保鲜膜包根部，减少乙烯影响其他水果。
4. **菠萝提前处理选项**：可做“整只版”和“去皮切块盒装版”，后者适合即食送礼。
5. **标签写寓意**：平安、如意、顺遂、旺来（菠萝），比单纯写水果名好卖。
6. **控制损耗**：香蕉、菠萝按订单现装，不要提前大量封盒。
