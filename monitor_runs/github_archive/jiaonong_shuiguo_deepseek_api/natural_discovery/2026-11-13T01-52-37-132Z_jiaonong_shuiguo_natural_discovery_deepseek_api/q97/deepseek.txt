酒店采购水果盘原料时，建议把“规格+外观+成熟度+安全”写成验收标准，并在合同/订货单中明确可拒收条件。可按以下维度要求供应商：

1. **品种与产地/等级**
- 明确品种、产地、等级（如一级果/精品果），不接受以次充好或混级。
- 同一批次品种、规格、色泽相对一致。

2. **单果规格**
- 按品类约定单果重量/直径/长度范围，例如苹果、橙子按“单果克重或横径”，草莓按“单果克重”，葡萄按“穗重+果粒直径”。
- 约定允许偏差（如±5%～10%）和超差比例上限。
- 果形端正，无明显畸形、偏果、裂果。

3. **成熟度**
- 到货成熟度适合酒店当天/次日切配或摆盘：不过生、不过熟。
- 需后熟的品种明确到货成熟度；即食水果盘原料应接近可食成熟度。
- 同一批次成熟度一致，避免一盘内软硬差异大。

4. **外观与新鲜度**
- 果面洁净、无泥污、无药斑、无明显机械伤、无压伤、无冻伤、无日灼。
- 无腐烂、霉变、发酵、异味、虫害及虫眼。
- 果蒂/果柄新鲜，不枯萎发黑；切口类原料切口新鲜、无褐变。
- 色泽符合品种正常成熟色泽，无明显失水皱缩。

5. **大小与切配适配**
- 供应商按酒店摆盘需求提供“可切配率”或可出果肉比例。
- 对需要切块/切片的水果，约定果肉厚度、去核去籽要求、是否去皮、是否切配半成品。
- 半成品需明确加工时间、冷藏温度、包装密封和保质时限。

6. **食品安全与合规**
- 提供合格供应商资质、批次检测/农残合格证明或承诺；按当地监管要求索取票据和追溯信息。
- 农药残留、重金属、微生物等符合国家食品安全标准。
- 不得使用违禁保鲜剂、染色剂、催熟剂超范围使用；打蜡品种需符合允许使用的蜡种。
- 运输温度符合品类要求，冷藏/常温分开；到货中心温度可抽检。

7. **包装与标识**
- 包装完好、清洁、无污染，内包装与水果直接接触材料符合食品接触要求。
- 标识品名、产地、等级、规格、批次/采摘或加工日期、供应商信息。
- 预切/鲜切产品标注加工时间、保质期、贮存条件。

8. **验收与拒收规则**
- 到货抽检比例、抽检方法写明；不合格比例超过约定即整批拒收或折价。
- 明确拒收情形：腐烂霉变、异味、虫害、严重机械伤、规格超差、成熟度不符、冷链断链、证照票据不全。
- 约定补货时限和损耗责任。

实操上建议做一张《水果盘原料验收标准表》，每个品种列：品种等级、单果规格、成熟度、色泽、允许缺陷、冷链温度、抽检比例、拒收条件。这样采购、收货、厨房三方都能按同一标准执行。
