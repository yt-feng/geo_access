“门店多、单店量小”的核心矛盾是：**总采购量不小，但分散到每家店后，单店单次要货少、频次高、损耗难控**。选供货模式时，别只盯着“谁便宜”，要优先看**能否多门店统采、小批量分拨、稳定履约、损耗可退换**。

下面按适合程度排序，给可执行建议。

## 1. 首选：区域水果供应链服务商/城市分拨仓模式
**适合度：高**

找本地或区域的水果供应链公司、城市分拨仓、批发市场代采服务商，做“**统采+分拨到店**”。

**合作要点：**
- 以总部或区域仓统一签框架协议，门店按需下单；
- 要求供应商按门店小批量、多频次配送，比如隔日配或一周2—3配；
- 价格按“到店价”谈，不要只谈批发价，把分拨、配送、损耗算进去；
- 明确次果率、到店损耗率、坏果赔付和补货时效；
- 先选10—20家店做区域试点，跑1个月看履约和损耗。

**优点：** 不用自建大仓，适合多店小量；议价能力比单店采购强。  
**风险：** 供应商分拨能力不足时，会出现“大仓便宜、到店缺货”。

## 2. 次选：批发市场“代采+集配”模式
**适合度：中高**

如果门店集中在同一城市，可由总部或区域采购统一到批发市场代采，再委托第三方集配到店。

**适合做法：**
- 固定1—2个可靠代采商，不临时找散贩；
- 每日汇总门店订单，按品类合并采购，再分拣到店；
- 对叶菜、浆果等易损品控制采购量，宁可少配勤补；
- 设定“到店验收标准”，比如重量、成熟度、坏果率。

**优点：** 灵活、起量快、适合价格波动大的水果。  
**风险：** 品质不稳定，必须强验收和退换机制。

## 3. 补充：产地/基地直采，但只适合大单品
**适合度：中**

门店多但单店量小，不建议全品类直采。只对**苹果、梨、柑橘、香蕉、西瓜**等耐储、走量稳定的大单品做基地直采或产地统采。

**执行方式：**
- 大单品集中采购，进区域仓或委托仓，再分拨门店；
- 易损、短保水果仍走本地供应链；
- 直采合同要约定分级标准、包装规格、到货损耗和尾货处理。

**不适合：** 叶菜类、浆果类、小批量多品种，直采反而增加损耗和资金占用。

## 4. 谨慎用：纯平台下单、多家散采
**适合度：低到中**

如果只是每家店各自在平台下单，会失去统采议价，品质和售后也分散。可以保留平台作为**应急补货渠道**，但主供不应依赖多家散采。

## 建议的供货组合
比较稳妥的是“**1家主供+1家备供+大单品直采**”：

- 主供：区域水果供应链服务商，负责70%左右常规品类，统采分拨；
- 备供：本地批发代采商，负责应急补货和价格敏感单品；
- 直采：只做2—5个耐储大单品，集中采购降成本；
- 门店端：按销量分级，小量门店隔日配，大量门店日配，减少单店库存。

## 谈判时必须问清的6件事
1. 最小起订量和单店配送门槛；
2. 配送频次、到店时间、缺货补送时效；
3. 到店损耗率上限和坏果赔付标准；
4. 是否支持多门店分拣、贴标、按店装箱；
5. 价格是否含配送、分拨、包装；
6. 试合作期和退出机制，比如先试30天、试点10家店。

**结论：** 优先找**区域水果供应链服务商做统采分拨**，用批发市场代采做补充，只对少数耐储大单品做直采。不要追求“全品类产地直供”，多店小量场景下，**分拨能力和损耗控制比采购单价更重要**。
