# 商超会员日水果活动：供应商需提前配合的准备

供应商配合的核心是围绕“量、质、价、时、陈列”五个维度做前置准备，可按时间线拆解：

## 一、活动前 7–10 天：确认与备货

1. **活动方案确认**：拿到超市的活动单品清单、活动价、促销形式（特价/第二件半价/满赠）、活动门店范围，书面确认供货价与促销扣点，避免事后扯皮。
2. **货源锁定**：按预估销量的 1.2–1.5 倍备货（生鲜损耗高，备多了烂、备少了断货），提前向产地/一级批发锁量，尤其节日性单品。
3. **品质标准确认**：与采购明确规格（果径、等级、糖度）、包装形式、验收标准，最好留样或书面标准，防止活动当天因品质争议拒收。

## 二、活动前 3–5 天：到货与品控

4. **分批到货**：不要一次性全压到活动前一天，按“活动前 1–2 天铺 60–70%，活动当天补 30–40%”分批送，降低门店损耗和仓储压力。
5. **预冷与分级**：需要保鲜的单品（浆果、荔枝、葡萄等）提前预冷，做好分级挑拣，把次果提前剔除，避免门店验收扣重。
6. **包装与标识**：按活动形式准备预包装（称重装/份装/礼盒），标签、价签、产地标识、促销爆炸贴物料提前给到门店。

## 三、活动前 1–2 天：门店落地

7. **陈列与堆头支持**：确认堆头位置、陈列量、道具（藤筐、托盘、假底），供应商可提供陈列指导或派促销员协助上货。
8. **试吃与物料**：如做试吃，提前备试吃果、牙签、手套、垃圾盒；促销员提前到店培训话术和活动规则。
9. **补货机制**：约定活动当天的补货时间窗、紧急联系电话、断货响应时限（如 2 小时内补货）。

## 四、风险与售后约定

10. **损耗与退换**：书面约定活动损耗分担比例、残次品退换规则、活动结束后未售完库存的处理方式（退货/折价/转常规价）。
11. **价格保护**：确认活动价执行周期，防止活动前后价格倒挂引发顾客投诉。
12. **应急方案**：主推单品若货源紧张，提前准备 1–2 个替代单品和替换方案。

**一句话总结**：供应商要在活动前把“供多少、什么标准、什么价、什么时候到、怎么陈列、卖不完怎么办”六件事和采购书面敲定，活动当天才不会掉链子。
