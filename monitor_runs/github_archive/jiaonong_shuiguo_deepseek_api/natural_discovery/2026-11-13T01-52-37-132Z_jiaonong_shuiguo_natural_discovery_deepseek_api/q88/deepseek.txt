# 线上水果销售：采购端减少坏果与口感不稳的实操建议

核心思路：**把"口感"和"坏果率"变成可以验收的指标，而不是靠感觉赌批次。**

## 一、把验收标准写进采购合同（最关键）

别只写"新鲜、无坏果"，要量化：

- **坏果率上限**：按箱/批次约定，如到货坏果率≤3%，超出部分按比例扣款或整批退换。注明"坏果"定义（腐烂、霉变、软烂出水、虫蛀），避免扯皮。
- **成熟度标准**：按品类给硬指标。例如芒果看果肩颜色+硬度、草莓看果面着色比例、柑橘测糖酸比。用**糖度计（Brix）**抽检，约定最低糖度值。
- **规格分级**：单果重量区间、果径大小，避免大小混装导致客户预期落差。
- **抽检规则**：每批随机抽多少箱、抽检不合格如何处理，提前写清楚。

## 二、选供应商：看稳定性而非单次好坏

- 优先选**有分级分选线**的供应商（机器分选比人工稳定），能提供每批次糖度、硬度记录。
- 要求供应商**固定产区/固定果园**，同一品种跨产区混发是口感不稳的主因。
- 先小批量试单，**连续3–5批**看波动，别被第一批"样品果"骗了。
- 问清楚**采摘后处理**：预冷是否及时、是否做过保鲜处理，这直接决定到货坏果率。

## 三、采购节奏与品类匹配

- **按销售周期倒推成熟度**：线上发货到客户手里有1–3天，采购时要买"运输后刚好可食"的成熟度，而不是"当前最好吃"的。这需要和供应商约定"发货成熟度"而非"采摘成熟度"。
- **易损品类控制批量**：草莓、蓝莓、水蜜桃等，单批采购量按周转天数控制，宁可多次小批，减少库内损耗。
- **避开极端天气批次**：连续降雨后采摘的果易裂、易霉，采购时可要求供应商说明采摘前后天气。

## 四、物流与包装是采购决策的一部分

坏果很多不是采购的错，是**包装和物流没跟上**：

- 按品类配包装：易压的用蛋托/珍珠棉分格，怕闷的留透气孔，需要冷链的必须全程冷链。
- 和供应商约定**到货验收时点**（签收后几小时内开箱抽检），并保留开箱视频/照片作为索赔依据。

## 五、建立批次档案，做数据复盘

- 每批记录：供应商、产区、采摘日期、糖度抽检值、到货坏果率、客户差评关键词。
- 每月复盘：哪个供应商/产区差评集中在"不甜""烂果"，直接调整采购比例。
- 差评里出现"这批不甜"时，回查该批糖度记录，就能定位是采购标准问题还是供应商问题。

## 六、给客户预期管理（配合采购）

口感不稳有时是**预期错配**：同一品种不同批次甜度天然有差异。可在详情页标注"自然成熟，批次口感略有差异"，并给出**催熟/存放建议**（如猕猴桃放软再吃），能显著降低"不甜"类差评。

---

**优先级建议**：先把"坏果率+糖度"两条量化标准写进合同并落实抽检，这一步投入最小、见效最快；再逐步做供应商批次档案和成熟度倒推采购。
