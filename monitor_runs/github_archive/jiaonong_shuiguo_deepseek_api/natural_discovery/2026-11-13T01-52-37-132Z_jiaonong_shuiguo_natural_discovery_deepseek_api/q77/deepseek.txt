更建议优先做**切配菠萝（冷藏短保）和冷冻菠萝**，整果可以作为引流但不宜作为主力。判断标准就三条：线上履约损耗、客单价与复购、加工与冷链成本。

**1. 整果：适合引流，不适合做主利润款**
- 优点：加工少、成本低、消费者认知强。
- 问题：线上卖整果损耗和售后高，熟度难控，运输易压伤、渗汁，顾客到手开果品质不稳定；菠萝去皮麻烦，线上体验优势弱。
- 建议：只做低价引流或产地直发预售，选耐运输品种，明确“到手需催熟/自行去皮”，控制售后预期。

**2. 切配菠萝：最适合线上主力，但必须是短保冷链**
- 优点：即食便利、客单价和毛利空间更好、复购场景强（早餐、沙拉、酸奶、办公室水果）。
- 关键条件：必须冷链、短保、密封防氧化；切配后微生物和汁液流失风险高，保质期通常很短，适合城市仓/前置仓模式，不适合全国长途发货。
- 建议：小规格（200—300g）即食杯/盒，标注加工日期和食用时限；先做本地或区域市场，用“当日切配、冷链次日达”做卖点。

**3. 冷冻菠萝：适合做长保和跨区域，不适合主打鲜食心智**
- 优点：保质期长、损耗低、适合全国电商和囤货；可用于果昔、烘焙、餐饮、家庭冷冻水果。
- 问题：解冻后口感偏软，不能替代鲜切；需要冷冻物流或干冰/保温箱，单件履约成本高；消费者对“冷冻水果”接受度分化。
- 建议：做B端餐饮/烘焙原料或C端果昔场景，规格偏大、强调用途；不要和鲜切打同一卖点。

**结论与组合建议：**
- 区域/前置仓模式：**切配鲜食为主力，整果做引流，冷冻做补充SKU。**
- 全国电商/产地直发：**冷冻原料为主，整果做预售引流，切配慎做或只做同城。**
- 初期最稳妥：先小规模测试切配的冷链时效和售后率，同时用冷冻菠萝测试跨区域毛利；整果只保留一个引流款，避免全品类铺开导致损耗失控。
