核心思路：别只信口头“全国配送”，要用**可验证的证据链**把“覆盖能力”拆成能核实的问题。建议按以下顺序做：

1. **先要配送范围清单，不只要一句“全国”**
   - 要求供应商提供：可配送省份/城市清单、偏远地区（新疆、西藏、内蒙古、海南、青海等）是否覆盖、是否到县级/乡镇。
   - 明确是“干线到城市”还是“末端到门店/仓库”，两者差别很大。

2. **做小批量实测，优先于看资料**
   - 选3—5个有代表性的收货地址：主销城市、二三级城市、偏远地区各一个。
   - 让供应商报出实际时效、起送量、运费、是否中转、破损和温控责任。
   - 小额试单，记录下单到签收全流程，比任何承诺都可靠。

3. **核验冷链与水果适配能力**
   - 问清楚：常温车、冷藏车、泡沫箱+冰袋分别适用哪些品类和距离。
   - 要求提供温控记录方式、途中异常处理、到货验收标准。
   - 水果损耗高，重点核实“到货新鲜度”和“坏果赔付规则”，不是只看能不能送到。

4. **查承运资源和落地网点**
   - 问供应商自有车辆/仓库/分拣中心在哪里，合作承运商是谁。
   - 要求提供最近的实际发运记录或配送单据（可脱敏），核对发货地、目的地、时效。
   - 对“全国配送”说法，重点问：哪些地区需要中转、中转几次、中转期间谁负责温控和损耗。

5. **用第三方信息交叉验证**
   - 查企业工商信息、经营异常、涉诉记录。
   - 向供应商索取2—3个同类客户案例，最好能联系确认其实际覆盖区域和服务水平。
   - 若供应商声称有平台或物流合作，可要求其提供合作凭证，而不是只看宣传页。

6. **把覆盖能力写进合同或试单协议**
   - 明确配送区域、时效承诺、起送量、运费承担、破损/腐损赔付、超时处理。
   - 对未覆盖区域约定替代方案或违约责任。
   - 先签短期试合作，按实际履约结果决定是否扩大采购。

**判断标准**：能提供区域清单、愿意小额试单、能说清中转和温控责任、有可核对的发运记录的供应商，覆盖能力才可信；只反复强调“全国都能发”但说不清末端和时效的，应按覆盖不足处理。
