直接给你一套可落地的做法，核心是：**按销量订货、按成熟度分级卖、用价格和陈列主动消化临期货**。

**1. 订货：别按“感觉”，按数据**
- 每个单品记录最近 7 天销量，订货量控制在预计销量 + 10% 左右。
- 易腐水果（草莓、葡萄、桃、香蕉）少量多次进，宁可下午补货，不要一次压三天。
- 设“最低陈列量”：货架低于某个量才补，避免为了好看堆满。
- 和供应商谈小批量、多频次配送，哪怕单价略高，也优于损耗。

**2. 收货：当场分级**
- 到货就分三类：**正价货、次价货、处理货**。
- 成熟度高的放前台快速卖，成熟度低的放后场或阴凉处后熟。
- 收货时直接拒收明显软烂、破皮、霉点的货，别心软。

**3. 陈列和库存：先进先出 + 少量勤补**
- 严格“先进先出”，新货放里面，旧货放外面。
- 陈列量不要超过一天半销量，堆得越多，压伤和损耗越大。
- 香蕉、苹果、梨等释放乙烯的水果，别和绿叶菜、草莓混放。
- 每天早晚各巡一次，把轻微磕碰的挑出来做果切、特价包或搭配销售。

**4. 临期处理：提前降价，不要等烂了再降**
- 设定时间节点：比如叶菜当天下午 5 点后打折，草莓第二天早上做特价。
- 用“组合销售”：水果拼盘、果切杯、买赠、满额换购。
- 建立社区群，每天固定时间发“今日特价水果”，快速清临期库存。
- 临期但没坏的可以做果切，但必须当天售完，并明确标注制作时间。

**5. 损耗管理：每天记，按单品复盘**
- 每天记录进货量、销量、损耗量，算出单品损耗率。
- 连续几天损耗高的单品，直接减订或暂停进货。
- 每周复盘一次：哪些单品周转慢、哪些供应商到货成熟度不稳定，及时换品或换供应商。

**6. 简单库存红线**
- 易腐水果：库存不超过 1.5 天销量。
- 耐储水果：不超过 3～5 天销量。
- 超过红线就启动促销，不再补货。

一句话原则：**水果不是“囤出来的利润”，是“周转出来的利润”。** 宁可少陈列、勤补货，也不要让货在店里等烂。
