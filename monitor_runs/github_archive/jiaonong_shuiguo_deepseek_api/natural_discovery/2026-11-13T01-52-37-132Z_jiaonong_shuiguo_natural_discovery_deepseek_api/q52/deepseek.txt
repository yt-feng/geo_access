采购香蕉做甜品，关键是控制成熟度和后熟速度。可执行做法：

1. **采购时选“青黄交接”的香蕉**
   - 优先选表皮黄中带绿、没有黑斑的。
   - 不要买已经全黄、有梅花点或果柄发黑的，到店后很快就会过熟变黑。
   - 按到店后1–3天内用完的量分批采购，别一次囤太多。

2. **要求供应商给“未催熟/轻度催熟”的货**
   - 问清到货时的成熟度，尽量要色泽偏青的。
   - 到货后先挑出有碰伤、裂口、黑斑的，单独先用，避免传染式烂得快。

3. **运输和存放避免挤压、闷热**
   - 用透气筐或纸箱装，别用密封塑料袋闷着。
   - 香蕉怕压，堆叠不要过高；避免放在暖气、烤箱、阳光直射附近。
   - 到店后放在阴凉通风处，理想约13–15℃，不要低于10℃冷藏，否则会冻伤变黑。

4. **悬挂或架空存放，减少接触面**
   - 有条件的用香蕉挂钩挂起来，或单层摆放。
   - 不要和苹果、梨、番茄等释放乙烯的水果放一起，会加速成熟。

5. **分开成熟度存放**
   - 青一点的放一起，熟一点的先用。
   - 已开始变黄的可以移到更凉通风处，但不要直接进冰箱。

6. **需要延缓时用物理隔离**
   - 果柄用保鲜膜包一下可减少乙烯释放，但果身不要密封。
   - 不要水洗后存放，表面水分会加速腐烂。

7. **按用途分级**
   - 当天做甜品优先用最熟的。
   - 偏青的留后1–2天用。
   - 出现轻微黑斑但果肉未软烂的，可优先做香蕉泥、烘焙类，不适合做装饰。

核心判断标准：**采购青黄果、少量多次、通风不挤压、不冷藏、远离催熟水果**。这样到店后通常能明显延缓变黑。
