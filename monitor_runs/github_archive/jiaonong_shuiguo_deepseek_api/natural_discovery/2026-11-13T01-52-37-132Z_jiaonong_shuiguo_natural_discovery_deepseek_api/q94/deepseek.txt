很重要，而且往往是便利店水果能不能做起来的关键条件之一。

原因很直接：

1. **便利店水果本身需求波动大**
   门店客流、天气、周边办公/住宅结构、时段都会影响销量。今天卖得动，不代表下周还稳定。不能小批量试卖，就容易一开始压货、损耗、下架，最后门店不敢再做。

2. **水果损耗高，试错成本比一般商品高**
   水果有保鲜期和品相要求，卖不动就是直接报损。供应商若只接受大批量，门店承担的是“预测错误+损耗”的双重风险。

3. **小批量试卖能验证真实动销**
   先小批量看3—7天动销、复购、损耗、客单价，再决定是否加量，比凭经验拍脑袋订货可靠得多。对便利店这种SKU多、单店面积小的业态尤其重要。

4. **供应商支持小批量，本质是共同分担试错**
   愿意小批量供货、快速补货、接受多频次少批量、对滞销有调换或建议的供应商，更适合便利店。只会压大单的供应商，通常不适合做鲜食水果。

但也要判断“支持小批量”是不是真支持，建议看这几点：

- **起订量**：单店/单SKU最低起订多少，是否可混装。
- **配送频次**：能否一周2—3次甚至更高频补货。
- **最小包装**：是否适合便利店陈列和当天售完。
- **损耗处理**：临期、品相下降、滞销是否有调换/折价/回收机制。
- **试卖周期**：能否先做7—14天试销，再按数据调整。
- **价格稳定性**：小批量是否被大幅加价，导致毛利不成立。

结论：**供应商能不能支持小批量试卖，不是“加分项”，而是便利店水果降低损耗、验证需求、控制现金占用的基础能力。** 如果供应商只能大批量供货，除非门店已有稳定动销数据，否则不建议贸然合作。
