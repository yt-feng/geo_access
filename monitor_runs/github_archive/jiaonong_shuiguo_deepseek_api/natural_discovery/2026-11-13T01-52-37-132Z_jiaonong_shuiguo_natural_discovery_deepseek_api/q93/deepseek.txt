三个都要管，但优先级不是并列的：**先定保质期和包装，再定配送频次**。因为配送频次是前两者确定后的结果，不是起点。

**1. 保质期优先（决定能不能卖）**
菠萝切块属于鲜切水果，高风险点是微生物和汁液流失。先明确：
- 冷藏条件下可售时限（建议按企业内部标准定，通常鲜切水果以“当日制作、当日售完”或极短冷藏保质期管理更稳妥；不要凭感觉拉长）
- 到店后剩余可售时间是否够覆盖一个销售周期
- 过期废弃规则和临期折扣规则要写死

如果保质期覆盖不了一个配送周期，说明这个品就不适合当前配送频次下卖。

**2. 包装第二（决定保质期能否成立）**
包装直接影响氧化、汁液渗漏、串味和微生物。重点看：
- 是否密封、是否冷藏陈列
- 是否有明确制作/分装时间标签
- 是否防漏、防压、便于消费者即食
- 是否标注保存条件和食用建议

包装不达标，保质期定得再短也容易出客诉。

**3. 配送频次第三（由前两者倒推）**
配送频次不是越勤越好，而是保证“到店—售完—废弃”在保质期内闭环：
- 日配：适合销量稳定、要求新鲜度高的门店
- 一日两配：适合销量大、保质期极短的门店
- 隔日配：只适合保质期和包装能支撑的情况，否则不建议

**可执行判断顺序：**
先定“冷藏可售时限”→ 选能支撑此时限的包装和冷链 → 按门店销量倒推配送频次 → 设置临期下架和废弃记录。

一句话：**保质期是红线，包装是保障，配送频次是配套。三者按这个顺序决策，不能反过来。**
