判断供应商售后是否稳定，不要只听口头承诺，建议按“可验证、可追责、可试单”三层来做：

1. **先看合同和响应机制是否写清楚**
   - 明确售后响应时限：如质量问题几小时内回复、多久给处理方案。
   - 明确责任范围：到货腐烂、成熟度不符、重量短缺、运输损伤、批次不合格怎么赔、怎么换、谁承担运费。
   - 明确联系人：不能只留一个业务员，要有售后专线/微信群/负责人，并写进合同。
   - 明确赔付方式：补货、折价、退款、扣款，避免只承诺“下次补”。

2. **用小批量试单验证，而不是直接大单**
   - 先下2—3次小批量，故意包含不同成熟度、不同到货时段。
   - 记录每次报损率、回复时间、处理结果。
   - 测试一次“非工作时间”反馈，比如晚上或清晨到货发现香蕉压伤，看对方多久响应。
   - 测试一次索赔：按合同提出折价或补货，看是否推诿、拖延、要求反复拍照。

3. **看它有没有稳定的品控和物流能力**
   - 问清楚菠萝、香蕉分别来自哪些产区/基地，是否有固定加工厂或分选线。
   - 香蕉要看催熟和冷链能力，菠萝要看成熟度分级和黑心病控制。
   - 要求提供近期的发货记录、报损处理记录、客户投诉闭环记录。
   - 如果供应商自己没冷链、没品控，只靠临时调货，售后通常不稳定。

4. **做供应商评分表，连续跟踪**
   建议每月按以下维度打分：
   - 售后首次响应时间
   - 问题解决时长
   - 赔付/补货兑现率
   - 同一问题重复发生率
   - 到货合格率
   - 沟通配合度
   
   连续2—3个月响应慢、赔付不兑现的，直接降级或淘汰。

5. **警惕几个信号**
   - 只给低价，不愿写售后条款。
   - 业务员口头很热情，但合同里没有响应时限。
   - 出问题就要求“先卖卖看”，不愿当场定责。
   - 每次换对接人，售后记录无法追溯。
   - 只愿意做大批量，不愿小单试错。

**可执行建议：**先选2—3家供应商各做3次小批量试单，每次到货后48小时内记录报损和响应情况；同时把售后响应时限、赔付标准、对接人写进采购合同。试单稳定后再放量，比单纯比价更能判断售后是否可靠。
