会有影响，但关键不在“大小不一样”本身，而在**差得有多明显、能不能分级卖**。

### 判断标准
- **轻微大小差异**：通常不影响销售，甚至更像自然果。只要成熟度、色泽、无破损一致，顾客接受度较高。
- **大小差异明显**：会影响。顾客会挑大果、剩小果，导致小果损耗；整箱统货卖时也容易被压价。
- **混装且成熟度不一致**：影响最大。大小不一还能接受，软硬/成熟度不一很容易造成客诉和损耗。

### 可执行建议
1. **到货先分级**：大果、中果、小果分开，按不同价格或不同场景卖。不要一箱混着统卖。
2. **小果不要硬搭大果**：小果可做促销装、切片/果切、员工福利或低价引流，避免拖累大果售价。
3. **控制采购规格**：后续采购时明确“单箱大小均匀度”，优先同一产地、同一批次、同一成熟度。
4. **看销售场景**：
   - 散卖水果店：大小差异影响中等，靠分级能消化。
   - 礼盒/精品陈列：影响大，必须均匀。
   - 果切/榨汁：影响小，大小不是核心。
5. **算损耗再决定**：如果小果占比超过约20%—30%，且没有低价渠道消化，这箱货的实际毛利会被明显拉低，应谨慎采购或压价。

**结论：大小不一会影响销售，但不是绝对不能卖；核心是分级销售和控制小果占比。采购时应把“均匀度”写进验收标准。**
