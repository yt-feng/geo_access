# 区域保护与串货：批发商谈代理时必须问清的问题

这两块是水果代理最容易扯皮的地方，问得越具体越好。建议按下面顺序问，最好让对方**书面确认**（写进代理合同或补充协议，口头承诺基本没用）。

## 一、区域保护怎么问

1. **授权区域范围**：是划到“省/市/区县”，还是以具体门店、渠道为单位？景区、商超、批发市场算不算在区域内？
2. **独家还是非独家**：区域内是否只放你一个代理？如果是“排他”，有没有销量考核？完不成会不会被收回或降级？
3. **线上渠道归谁**：本区域内的电商、社区团购、直播带货由谁做？品牌方自营旗舰店算不算跟你抢？这点水果行业特别重要，很多串货其实是线上低价货流下来的。
4. **跨区销售的界定**：货从你区域流出算串货，那“客户自己跨区来提货”“发货地址在外地”怎么认定？
5. **品牌方直供客户**：区域内的大型连锁、商超、餐饮客户，品牌方是否保留直供权？如果有，提前列名单，避免你开发完被截胡。
6. **考核与调整机制**：区域多久评估一次？销量不达标是缩区域还是直接取消？调整前给多久预警期？

## 二、串货怎么问

1. **串货的定义和识别标准**：靠什么判断？批次码、箱码、溯源码？有没有扫码稽查系统？你进货时是否能拿到可追溯的编码？
2. **处罚规则**：发现串货，罚谁、罚多少、怎么执行？是扣保证金、取消返利还是终止代理？处罚前是否给你申辩和举证的机会？
3. **对你区域被冲货的保护**：别人往你区域串货，品牌方怎么处理？多久响应？有没有补偿机制（比如补差价、补销量）？这是最关键的一条，很多合同只写“禁止串货”，却不写“被串货了怎么办”。
4. **保证金与返利挂钩**：保证金多少、什么条件下扣、什么时候退？返利是否和“无串货记录”绑定？
5. **自己出货的边界**：你能否给区域外客户发货？如果客户自己找上门、或者你只是代发，算不算违规？把灰色地带提前说清。
6. **退换货与临期处理**：水果损耗大，卖不动的货能不能退、能不能跨区调货？调货算不算串货？这条不写清，后面很容易被扣帽子。

## 三、谈判时的实操建议

- **先要合同再谈**：让对方把区域图、客户名单、串货处罚条款写进合同附件，别只听招商人员口头说。
- **留证据**：所有沟通（微信、邮件）保留，关键承诺让对方回消息确认“以上内容以合同为准”。
- **设定试销期**：先签3–6个月试销，明确试销期内的区域和考核标准，跑通了再签长约。
- **重点盯“被串货”条款**：行业里常见的是品牌方罚串货很积极，保护被串货的代理很消极，合同里必须写清响应时限和补偿方式。
- **问清货源稳定性**：区域保护的前提是品牌方能稳定供货，否则你守区域、别人拿低价货，保护就是空话。

一句话总结：**区域保护问“边界和例外”，串货问“怎么认定、罚谁、我被冲了怎么办”**，三条都落到纸面上再签。
