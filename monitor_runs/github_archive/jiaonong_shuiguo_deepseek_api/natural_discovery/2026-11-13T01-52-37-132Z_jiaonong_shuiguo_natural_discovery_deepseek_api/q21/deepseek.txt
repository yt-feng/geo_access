超市采购水果时，通常要区分**供应商随货证明**和**检测报告**两类。可执行做法如下：

1. **基础进货证明**
   - 供应商营业执照复印件
   - 食品经营许可证或仅销售预包装食品备案信息（按当地要求）
   - 供货合同/订单、送货单、发票或收据
   - 每批次随货的**产地证明或购货凭证**；从批发市场进货的，保留批发市场出具的**销售凭证**
   - 若为进口水果：海关**入境货物检验检疫证明**、报关单等

2. **检测报告**
   - **农药残留检测报告**：优先索取与到货批次对应的报告；报告应有检测机构、样品名称、检测项目、结果、日期和判定依据
   - 供应商自检报告可作为辅助，但不能替代有资质机构报告（若超市制度或监管要求第三方报告）
   - 重点品种、高风险品种或超市自有标准要求时，按批次索取第三方检测报告
   - 进口水果按海关监管要求提供相关检验检疫证明

3. **其他证明**
   - 承诺达标合格证（如适用）
   - 产地准出证明、绿色食品/有机认证等，仅在有相应宣称时索取
   - 运输、贮存环节温控记录（冷链水果更需要）

**判断标准**：证照在有效期内；检测报告能对应品种和批次；报告项目覆盖农残等关键指标；进货凭证能实现来源可追溯。建议超市在采购制度中明确“每批随货凭证+定期/高风险品种检测报告”的要求，并留存台账。
