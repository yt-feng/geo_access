水果采购合同里，**法律上没有统一规定“坏果率超过多少必须赔付”**，关键是看合同约定和验收标准。实务上可这样定：

1. **常见合同阈值**
   - **坏果率 ≤ 3%**：一般视为合理损耗，不赔付或仅扣重。
   - **坏果率 3%～5%**：可约定按超出部分扣款、折价或换货。
   - **坏果率 > 5%**：通常可要求按比例赔付、退货或拒收。
   - 对易腐、远距离运输水果，阈值可适当放宽到 **5%～8%**；对精品果、冷链短途，可收紧到 **2%～3%**。

2. **合同里最好写清楚**
   - 验收时间：到货后几小时内开箱抽检；
   - 抽检比例和方法：如随机抽 10 箱，每箱抽 5%；
   - 坏果定义：腐烂、霉变、压伤、裂果、异味等分别列明；
   - 赔付公式：如“坏果率超过 5% 的部分，按当批次货款的 1.5 倍扣减”或“按坏果重量占比退款”；
   - 处理方式：扣款、换货、退货、拒收及运费承担；
   - 争议检验：双方共同取样或送第三方检测。

3. **可执行的建议**
   - 如果你是**采购方**：把赔付起点写低一些，建议 **超过 3% 即启动扣款，超过 5% 可拒收**。
   - 如果你是**供货方**：建议约定 **5% 以内为合理损耗，超过部分按实际坏果重量赔付**，避免整批退货。
   - 无论哪方，**不要只写“坏果率过高赔付”**，必须写清阈值、计算方式、验收时限和赔付公式，否则很难执行。

简单说：**合同有约定按约定；没约定时，3%～5% 是常见谈判区间，超过 5% 要求赔付较有依据，但最终取决于坏果定义、抽检方式和证据。**
