判断“能不能稳定按规格送货”，核心不是看供应商样品多好，而是看它有没有**可验证的供货能力 + 规格控制体系 + 异常兜底**。建议按下面几层做尽调，并把结论写进合同和验收标准。

**1. 先明确你的“规格”是什么，越具体越好**
不要只写“菠萝”，至少拆成：
- 品种/产地/季节窗口
- 单果重量区间、果径
- 成熟度（几成熟采收、到店可食用状态）
- 糖度范围、酸度、纤维/黑心/水心病容忍度
- 去皮/去眼/切块/冷冻等加工形态
- 包装规格、每箱净重、冷链温度
- 到货允收比例、次品处理方式
把这些做成《验收标准表》，让供应商逐项书面确认。

**2. 验证供应商的真实产能和货源结构**
重点问清：
- 自有基地、合作基地、产地经纪人各占多少？单一产地占比过高，旺季断供风险大。
- 日/周可稳定供多少箱？峰值产能多少？
- 有几个替代产区/替代加工厂？台风、雨季、病害时怎么切换？
- 是否只做贸易转手？转手层级越多，规格越难控。
要求提供近3—6个月同类客户供货记录、出库单或对账单（可脱敏），并做**现场或视频验厂/验基地**。

**3. 用“小批量试单”验证稳定性，而不是只看样品**
建议做2—4周试单，分三批：
- 首批正常量
- 第二批略加量
- 第三批临时追加或改到货时间
记录每批：到货准时率、规格合格率、重量差异、糖度抽检、坏果率、包装破损率、异常响应时间。
连续3批都达标，才谈稳定供应；只靠一批好货不能说明问题。

**4. 建到货验收和抽检规则**
- 每车/每批随机抽检，不固定抽同一位置。
- 按箱称重、按果测重、切开看内部品质。
- 设定AQL或明确允收比例，例如规格合格率≥95%、坏果率≤2%，超出即扣款/退货/补货。
- 拍照留证，异常批次48小时内书面确认处理方案。
- 要求供应商随货提供产地、采收日期、加工日期、批次号。

**5. 看它的异常处理能力**
稳定送货不等于永不出问题，而是出问题时能不能兜底。问清：
- 缺货提前多久通知？
- 有无安全库存或备用供应商？
- 质量问题补货时效？
- 冷链断链、延误、规格不符的赔付标准？
把这些写进合同：最低供货量、提前下单周期、价格调整机制、违约赔付、替代货源义务。

**6. 合同里锁住“稳定”**
至少写清：
- 规格附件和验收方法
- 月度最低供货量及峰值保障
- 提前下单和确认机制
- 质量不合格的退换补、扣款规则
- 断供应急条款和备用供应商备案
- 价格随行就市的上限/调整周期

**可执行判断标准：**
如果供应商能提供明确产地和产能数据、接受小批量多批次试单、连续3批规格合格率≥95%、准时率≥98%、异常有书面兜底方案，基本可判断具备稳定按规格送货能力；如果只强调“关系好、货源足”，但说不清产地结构、不愿试单、不接受验收扣款，建议不要作为主供应商。
