供应商介绍时，核心不是讲“品种知识”，而是把陌生品种翻译成商家熟悉的**口感、用法、客群、损耗和利润**。可以按这个顺序说：

1. **一句话对标熟悉品类**
   - “这个吃起来像菠萝和芒果之间，酸甜，纤维少。”
   - “口感接近香蕉的软糯，但更清香，适合做果切。”
   先让商家有味觉参照，别一上来讲学名、产地故事。

2. **直接说怎么卖**
   - 适合鲜食、果切、奶茶店、烘焙、礼盒、餐饮配餐中的哪一类。
   - 给具体场景：“切块做果切不氧化太快”“适合奶茶店做酸甜型饮品”“适合高端礼盒凑色”。
   商家关心的是能不能上架、怎么用，不是品种百科。

3. **说清客群和卖点**
   - “年轻女性喜欢，颜值高，适合拍照”“家庭客群适合小规格”“餐饮客户看重出成率”。
   用一句话说明谁会买、为什么买。

4. **用数字讲损耗和利润**
   - 给可判断的数据：单果重量、每箱规格、出成率、常温/冷藏保存天数、损耗点。
   - 例如：“一箱10斤，单果1.2斤左右，去皮出成率约65%，冷藏可放5天，适合先小批量试销。”
   不要只说“很好吃、很好卖”，要给商家能算账的信息。

5. **主动降低试错门槛**
   - 建议先拿小规格试卖，或给试吃装、搭配成熟品类做组合。
   - “先拿一箱混搭菠萝香蕉卖，观察一周动销，再决定是否主推。”
   商家最怕压货，供应商主动给试销方案更容易下单。

6. **对比成熟品类说差异**
   - “和菠萝比，不用泡盐水，切开即食；和香蕉比，货架期短一点，建议冷藏。”
   既讲优势，也讲注意事项，反而更可信。

一句话模板可以这样说：

> “这个产品您可以理解成‘菠萝的酸甜+芒果的香’，纤维少，切开即食，适合果切和奶茶店。一箱10斤，单果1斤左右，出成率约65%，冷藏放5天。建议您先拿一箱和菠萝香蕉一起试卖，卖得动再加量。”

关键是：**少讲品种，多讲对标口感、使用场景、损耗数据和试销方案。** 商家听得懂、算得清、试错小，才更容易下单。
