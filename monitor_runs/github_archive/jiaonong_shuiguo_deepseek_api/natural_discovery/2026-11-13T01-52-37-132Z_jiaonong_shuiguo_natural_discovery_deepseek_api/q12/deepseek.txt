采购时不要一味追求“全熟”，菠萝是后熟水果，但货架期短，水果店要按“预计几天卖完”来定熟度。可执行判断如下：

**1. 先定采购熟度**
- **当天/次日卖完**：可收8～9成熟，香气明显、果眼浅、轻按有弹性。
- **2～3天卖完**：主力收7.5～8成熟，香气淡到中等，果身硬中带弹。
- **3天以上或周转慢**：收7成熟左右，青黄相接、基本无香，放店里后熟，别一次压太多。

**2. 现场看**
- 果形端正、饱满，冠芽新鲜不过分干枯。
- 底色由青转黄，**黄色从底部往上走**；底部已黄、上面还青的适合短周转。
- 果眼浅而平、不凹陷发黑；表皮无软烂、无渗汁、无霉点。
- 同批货颜色差异大的分开卖，别混装催熟。

**3. 现场闻**
- 底部闻：**清香=可收；明显甜香=快熟，适合快卖；酒味/酸味=过熟或坏果，拒收。**
- 无香但果身硬，可作后熟货，但要控制量。

**4. 现场按**
- 轻按果身有弹性、不塌陷：适收。
- 按下去软、回弹慢：已熟，只能快销。
- 硬如石头：生，需后熟，别当即食卖。

**5. 看切口/底部（若可查）**
- 底部干爽、无汁液渗出；切开果肉淡黄、纤维细为佳。
- 底部发黑、发软、有汁，整批谨慎。

**6. 采购比例建议**
按销量拆分：**即食熟货20%～30%，2～3天周转货50%～60%，后熟青货10%～20%**。夏季高温、店内无冷柜时，熟货比例再降；冬季或冷柜条件好可略增。

**7. 到店后管理**
- 青货常温通风后熟，别堆压、别套塑料袋闷。
- 熟货尽快冷藏或切卖，先进先出。
- 每天翻检，底部发软、有酒味的立即挑出，避免传染损耗。

一句话：**采购按“卖几天”定熟度，主力收7.5～8成熟，底部清香、果身硬中带弹最稳；明显甜香只适合快销，酒味酸味直接拒收。**
