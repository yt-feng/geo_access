# 单位采购水果的验收与售后处理建议

## 一、到货验收（当场做、留证据）

1. **先定标准再收货**
   - 采购合同/订单里写明：品种、规格（单果重量或直径）、成熟度、允许损耗率（如≤5%）、外观瑕疵上限。
   - 约定"批次验收"：同一批次内品质不一致，按最差比例判定，避免逐箱扯皮。

2. **抽样验收**
   - 按到货箱数抽检（如10箱抽2–3箱，大货按5%–10%抽），开箱看**底层和中间层**，不能只看表层。
   - 逐项记录：个头是否均匀、颜色/成熟度是否一致、有无烂果/压伤/冻伤/异味、包装是否破损受潮。

3. **现场称重与计数**
   - 去皮称净重，核对与订单重量差；烂果、次果单独挑出称重，计算不合格比例。

4. **当场留证**
   - 拍照/录像：整批、开箱、问题果特写、称重读数、车牌和送货单。
   - 双方在**验收单**上签字，写明合格数量、不合格数量、处理意见（拒收/折价/换货）。送货人不在场或拒签的，记录时间和情况并拍照。

5. **分级处理**
   - 轻微不一致（如大小略不均）：折价接收，书面确认折扣。
   - 明显不一致或腐烂超标：**整批拒收或部分拒收**，在送货单上注明"拒收原因+数量"，让送货人签收退回。

## 二、售后处理

1. **按合同条款走**
   - 优先依据合同中的质量条款、损耗率、退换货时限（建议约定到货后24–48小时内提出异议）。
   - 无明确条款时，按"不符合约定质量"要求换货、补货、折价或退款。

2. **书面提出、限时回复**
   - 当天或次日发书面通知（微信/邮件/函件均可，保留记录），附照片、验收单、称重记录，写明诉求和回复期限（如24小时）。

3. **换货/补货要复验**
   - 补换货到货后重新抽样验收，避免二次问题；换货产生的运费、损耗由供方承担（合同约定）。

4. **扣款与结算挂钩**
   - 不合格部分在结算时直接扣减，或按合同约定违约金处理；保留尾款作为质量保证金更稳妥。

5. **升级处理**
   - 供方不配合：发正式函件、暂停后续订单、按合同争议条款处理；金额大的保留全部证据备查。

## 三、事前防范（最省事）

- 合同写明**验收标准、抽检方法、异议期限、退换货责任和费用承担**。
- 固定1–2家供应商并建立**到货质量记录**，连续不合格的降级或更换。
- 大宗采购可分**小批多次到货**，降低单批风险。

**一句话原则：当场抽检、当场留证、当场签字定性；售后按合同限时书面主张，不与结算脱钩。**
