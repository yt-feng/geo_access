优先看**成熟度**，价格应在满足成熟度之后比较。

可执行判断：

1. **先定用途再定成熟度**
   - 做香蕉蛋糕/香蕉磅蛋糕：选**7～8成熟偏熟**，表皮黄中带少量褐斑，果肉软但未流汁，香蕉香气明显。
   - 如果表皮大面积发黑、果肉水化或有酒味：不适合直接做蛋糕主体，可能影响风味和出品稳定。
   - 太青的香蕉：香气弱、甜度低、口感硬，做蛋糕风味不足。

2. **价格只作第二筛选**
   - 同成熟度下比价：按**可食部分单价**比较，不要只看整箱价。
   - 临期/过熟香蕉可以低价采购，但只适合当天或短期加工，且要评估去皮损耗、风味不稳定和报废风险。

3. **采购时要看的关键指标**
   - 表皮颜色和褐斑比例
   - 手感软硬是否均匀
   - 是否有破损、霉点、渗汁、异味
   - 到货后可用时间：偏熟香蕉通常要尽快用完
   - 出肉率和去皮损耗

**结论：成熟度是质量门槛，价格是门槛内的成本优化。** 不建议为了低价买过生或过熟的香蕉；应优先采购适合蛋糕风味和当天加工节奏的成熟度，再在同成熟度里选价格更优的。
