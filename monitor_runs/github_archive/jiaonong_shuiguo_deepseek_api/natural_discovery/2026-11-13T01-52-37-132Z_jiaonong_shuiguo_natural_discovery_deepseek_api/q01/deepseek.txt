判断水果供应商靠不靠谱，别听他说得多好，用下面这套“先小单验证、再逐步放量”的办法最稳：

**1. 先看他能不能稳定供这两个品**
- 香蕉看：能不能按你要的成熟度（青蕉/微黄/熟蕉）分批到货，催熟方式是否稳定，断货时有没有替代方案。
- 菠萝看：品种是否固定（如金钻/巴厘），规格是否整齐，季节性切换时会不会临时换货不打招呼。
- 问清楚：产地、分级标准、包装规格、每箱净重、损耗怎么算。

**2. 用三次小单验货，不要一上来大单**
- 第一次：小批量试单，重点看准时率、到货成熟度、破损率、净重是否足。
- 第二次：故意改一次到货时间或加一次临时补货，看他响应和履约。
- 第三次：在价格波动时再下一单，看他是否临时毁约、以次充好。
三次都稳，再谈长期价和账期。

**3. 到货验收要量化**
- 香蕉：抽箱看把型、条数、青黄比例、机械伤、催熟均匀度；记录到货成熟度和可售期。
- 菠萝：看果形、大小均匀度、冠芽新鲜度、黑心/水烂比例、糖度抽测。
- 每批记录：到货时间、数量、净重、坏果率、可售率、客户投诉。连续几批坏果率明显高于约定，就不能长期合作。

**4. 看他的“后端”而不是嘴**
- 有没有固定档口/仓库/冷库，香蕉催熟库是否规范。
- 断货时能不能从其他产地调货，还是只会说“明天一定有”。
- 愿不愿意明确写损耗赔付、退换货规则、账期和违约责任。

**5. 价格和账期要警惕两种人**
- 报价长期明显低于市场，通常会在成熟度、净重、坏果率上找回来。
- 一上来就给很长账期、很大授信，反而要小心；靠谱供应商通常先款后货或短账期，稳定后再谈。

**6. 长期合作前做三件事**
- 签简单供货协议：品种、规格、净重、验收标准、损耗赔付、到货时间、价格调整机制。
- 保留备用供应商：香蕉、菠萝各至少两家，避免被一家卡住。
- 每月复盘：准时率、坏果率、可售率、投诉率、价格稳定性，连续两个月不达标就降量或换人。

一句话：**先小单、再改单、再看波动单；三次都稳、验收数据能对上、赔付规则敢写清楚，才值得长期进。**
