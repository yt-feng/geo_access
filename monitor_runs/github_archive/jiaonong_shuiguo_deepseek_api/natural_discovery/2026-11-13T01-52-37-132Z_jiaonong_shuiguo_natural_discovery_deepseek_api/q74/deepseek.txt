先说明：我无法核验具体市场价格和某地某档口的真实出货数据，以下按“餐饮客户常见用途→可验收规格”给可执行建议，不引用外部来源。

**一、菠萝（餐饮客户按用途分规格）**

1. **鲜切果盘/饮品店/自助餐**
   - 规格：单果1.2–1.8斤，成熟度7–8成，果眼浅、无黑心。
   - 包装：按箱10–12个，或按“净果斤数”报价。
   - 验收点：切开无褐变、无酒味、糖度稳定（可用糖度计抽测）。

2. **热菜/咕噜肉/菠萝炒饭（后厨切块）**
   - 规格：单果1.8–2.5斤，成熟度6–7成，耐存放、切块后不易出水。
   - 包装：大箱统货，按斤报价；可另设“去皮去眼净果”规格。
   - 验收点：果肉硬挺、酸度够、出成率稳定。

3. **果汁/中央厨房**
   - 规格：统货大果2斤以上或次果，重点看出汁率和糖酸比。
   - 包装：按筐/按斤，注明“当日或次日到货”。
   - 验收点：无腐烂、无发酵味，出汁率可抽测。

4. **高端餐饮/酒店果盘**
   - 规格：单果1.5–2斤、外观端正、大小均匀，可做“礼盒级”分级。
   - 验收点：外观商品性好，切开颜色一致。

**二、香蕉（餐饮客户按用途分规格）**

1. **自助餐/果盘/饮品装饰**
   - 规格：单根120–150g，梳蕉整齐，成熟度3–4号（到货后2–3天可用）。
   - 包装：按箱/按梳，注明“到货成熟度”和“可售窗口”。

2. **后厨甜品/炸香蕉/香蕉派**
   - 规格：单根150–200g，成熟度5–6号，果肉软糯但不变黑。
   - 验收点：无机械伤、无炭疽黑斑扩散。

3. **果汁/奶昔店**
   - 规格：成熟度6–7号，单根150g以上，优先“熟蕉”稳定供应。
   - 验收点：剥皮后无硬心、无异味。

4. **连锁餐饮稳定供货**
   - 建议做“催熟计划”：按客户日用量，分3–4号、5–6号两档分批到货，避免一次全熟。
   - 包装：按箱标注到货日期、成熟度、建议使用顺序。

**三、给档口的落地做法**

- 设两档报价：**统货价**和**分级/净果价**，餐饮客户更看重稳定和出成率。
- 每个SKU写清：单果重量区间、成熟度、包装数量、到货可售天数、验收标准。
- 先小批量试供：菠萝按“鲜切级”和“后厨级”各送一箱；香蕉按“3–4号”和“5–6号”各送一箱，让客户实测出成率和损耗。
- 不要只报“菠萝/香蕉”，要报“用途+规格+成熟度+包装”，餐饮采购才好下单。
