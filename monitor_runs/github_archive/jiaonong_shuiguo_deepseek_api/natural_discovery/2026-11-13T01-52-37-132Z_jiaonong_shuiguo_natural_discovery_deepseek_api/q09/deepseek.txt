和供应商谈合作时，核心是把“旺季不断货”落到可执行条款上。建议按下面几类问题提前问清楚，能判断对方是否靠谱，也能避免旺季临时掉链子。

**一、供货能力与稳定性**
1. 旺季你每天/每周能稳定给我供多少货？最小起订量和最大供应量分别是多少？
2. 你货源是自有基地、合作社还是批发市场调货？断货时有没有备用货源？
3. 旺季你同时供多少家店？给我分配的供应额度大概占你总出货量多少？
4. 遇到天气、节假日、物流管制，你通常怎么保供？有没有应急预案？

**二、价格与结算**
5. 旺季价格怎么定？是锁价、随行就市还是按周报价？锁价能锁多久？
6. 价格波动超过多少需要提前通知？提前几天？
7. 结算方式是现结、周结还是月结？要不要押金/保证金？
8. 运费、装卸费、损耗谁承担？送到店还是自提？

**三、品质与验收**
9. 规格、等级、成熟度怎么约定？有没有样品或标准照片？
10. 到货验收标准是什么？坏果率、损耗率超过多少算不合格？
11. 不合格怎么处理：退货、换货、折价还是补发？响应时限多久？
12. 旺季能不能保证优先给我好货？分级标准会不会临时变？

**四、下单与配送**
13. 每天几点前下单？多久能送到？旺季配送频次能不能增加？
14. 临时加单最晚什么时候提？加单有没有附加费？
15. 配送车辆、冷链条件如何？夏天高温怎么保证新鲜度？
16. 缺货或延迟送达怎么通知？有没有违约补偿？

**五、合作条款与风险**
17. 能不能签旺季保供协议？把供应量、价格机制、违约責任写清楚。
18. 如果我销量超预期，能不能优先追加？追加部分价格怎么算？
19. 合作期限怎么定？旺季结束后价格和合作方式怎么调整？
20. 有没有账期、退换货、质量索赔的具体书面约定？

**谈判时重点抓三条：**
- **保供量写进合同**：别只听“没问题”，要写明每日/每周最低供应量和追加机制。
- **价格机制写清楚**：锁价还是浮动、通知周期、上限。
- **违约和损耗责任写明白**：延迟、缺货、坏果怎么赔、怎么补。

另外建议旺季前先小批量试供1—2周，验证对方的实际到货率、品质稳定性和响应速度，再决定是否签长期或交保证金。
