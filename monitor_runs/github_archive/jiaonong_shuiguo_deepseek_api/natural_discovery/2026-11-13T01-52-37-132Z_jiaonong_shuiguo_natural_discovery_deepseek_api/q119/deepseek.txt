水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格”，而是会影响损耗、复购和现金流的细节。重点看这几类：

1. **同一批次内的稳定性，而不只看样品**
   - 样品好不代表大货稳。要连续看3—5批货的规格、成熟度、糖度、大小、颜色是否一致。
   - 容易忽视：供应商是否把不同产地、不同采摘期的货混装；箱内上下层是否一致。

2. **采后处理和冷链是否真实执行**
   - 问清楚采摘时间、预冷时间、运输温度、到货温度。
   - 容易忽视：只问“有没有冷链”，没问到货时果心温度、断链时长、装卸是否露天暴晒。
   - 对草莓、蓝莓、荔枝、樱桃等高损耗品，这一项比单价更关键。

3. **成熟度与销售节奏是否匹配**
   - 供应商按几成熟发货？到你手里还能放几天？适合当天卖、次日卖还是做特价？
   - 容易忽视：只追求“看起来熟”，结果到店即软、上架期极短，损耗吞掉毛利。

4. **包装和运输损耗责任**
   - 明确箱规、净重/毛重、垫材、透气孔、防压方式。
   - 容易忽视：皮重虚高、底层果压伤、冰袋/保鲜剂是否足量，以及破损、腐烂、短重的赔付标准。
   - 合同或订单里要写清：到货几小时内验货、拍照要求、赔付比例、补货还是退款。

5. **供应能力与替代方案**
   - 不是问“有没有货”，而是问旺季/雨季/节假日能否稳定供、断货时有无同标准替代产地。
   - 容易忽视：供应商自己也是倒手商，上游一断就换货，导致你的门店品质忽高忽低。

6. **账期、结算和隐性费用**
   - 是否含运费、卸货费、包装费、损耗补贴；起订量多少；价格随行就市还是锁价。
   - 容易忽视：低价背后是短重、强制搭售尾货、账期缩短，现金流压力反而更大。

7. **食品安全与合规凭证**
   - 农残检测、产地证明、进货票据是否可追溯。
   - 容易忽视：长期合作后不再索证，一旦抽检或顾客投诉，无法追溯。

8. **供应商的客户结构和你的优先级**
   - 他主要供商超、批发市场还是餐饮？你在他的客户里排第几？
   - 容易忽视：好货先给大客户，你拿到的是“剩下能卖的”，长期品质不稳。

9. **售后响应速度**
   - 出问题后多久能回复、多久补货、是否愿意共同承担损耗。
   - 容易忽视：只看合作前热情，不看凌晨到货出问题时能否及时处理。

实操建议：  
先小批量试3—5批，每批记录“到货温度、净重、坏果率、可售期、售后处理”；同时保留2家备选供应商，主供占70%左右、备供占30%左右。长期稳定靠的是**可验证的批次稳定性+明确损耗责任+备选供应**，不是最低报价。
