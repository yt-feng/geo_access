超市采购担心水果农残抽检，建议提前向供应商索要并核验以下资料，重点是“可追溯+可验证”，不要只收一张合格证照片。

**一、基础资质与主体资料**
1. 供应商营业执照、食品经营许可证/生产许可证（按实际业态）。
2. 供货商与种植基地/合作社/批发市场的关系证明：合同、授权书、产地证明或采购凭证。
3. 联系人、产地地址、批次信息，确保出问题能追到具体果园/地块/批次。

**二、批次检测资料（最核心）**
1. **该批次**的农药残留检测报告，优先 CMA/CNAS 资质机构出具；至少要有检测项目、方法、限值、结论、样品批次、采样日期、报告编号。
2. 报告要与到货批次对应：品种、产地、采收/包装日期、批号能对上。
3. 若供应商只有“委托检验”或“型式检验”报告，要确认不是过期通用报告；抽检风险高时要求每批或定期批批检测。
4. 供应商自检的，要有自检记录和快检设备/方法说明；自检不能替代法定检测，但可作为日常筛查。

**三、产地与种植管理资料**
1. 产地证明/食用农产品合格证（承诺达标合格证），注意看开具主体、品种、数量、日期。
2. 种植基地的农药使用记录：用药品种、时间、剂量、安全间隔期、采收日期。
3. 若为“绿色食品/有机/地理标志”等认证，索要有效证书及对应产品范围，不要只看包装标识。

**四、进货查验与追溯资料**
1. 每批到货的送货单/发票/购销凭证，注明品种、产地、数量、批次、日期。
2. 供应商的进货查验记录和上游采购凭证，确认其货源稳定可追溯。
3. 包装标签、承诺达标合格证、产地编码/追溯码等。

**五、合同与风险约束**
1. 采购合同里写明农残标准、检测频次、不合格退换货和赔偿责任。
2. 要求供应商提供“批次检测报告随货同行”的承诺。
3. 约定超市有权抽样送检，费用和不合格处理方式写清楚。

**实操建议：**
- 对新供应商：先要资质+近期批次报告+产地证明，首批到货可自行送检或快检。
- 对长期供应商：建立批次档案，要求每批附承诺达标合格证/检测报告，定期复核报告真实性（机构官网/二维码验真）。
- 对高风险品种（叶菜、草莓、豇豆等）：提高抽检频次，重点看禁限用农药项目。
- 不要接受“报告复印件模糊、批次对不上、检测日期早于采收期、项目不全”的资料。

一句话：**要“该批次可对应的检测报告+产地追溯资料+合同责任条款”，并保留自行抽检权。**
