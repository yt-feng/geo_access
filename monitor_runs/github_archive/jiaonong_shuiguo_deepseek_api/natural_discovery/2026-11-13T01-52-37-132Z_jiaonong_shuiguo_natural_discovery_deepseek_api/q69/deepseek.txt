香蕉和菠萝分级报价，关键是让小店一眼看懂“按什么级、什么规格、什么价、什么损耗算谁的”。建议用“等级+规格+单价+起批量+结算/损耗规则”五列报价，不要只报一个统货价。

**一、先定分级口径**

香蕉建议按“外观+条数/把重+成熟度”分：
- A级：果指饱满、无黑斑或极少、色泽均匀，条重较整齐；适合直接上架。
- B级：有轻微擦伤、色差、个别断指，适合快销或做促销。
- C级/处理级：黑斑多、断指多、成熟度不齐，适合特价或加工。
- 报价规格写清楚：每箱净重、每把约几根、条重区间、成熟度（青/微黄/黄熟）、到货后建议销售天数。

菠萝建议按“单果重+外观+成熟度”分：
- A级：单果重区间整齐，果形正、无裂口、无烂眼，冠芽完整；适合陈列。
- B级：单果重略不齐，有轻微日灼/擦伤，不影响食用；适合促销。
- C级/处理级：小果、畸形、裂口或熟度偏高，适合切果/特价。
- 报价规格写清楚：每箱几个、单果重区间、成熟度（青/半熟/熟）、是否带冠、是否催熟。

**二、报价表这样列最清楚**

品名 | 等级 | 规格/净重 | 单果或单把标准 | 单价 | 起批量 | 损耗/售后规则

示例写法：
- 香蕉 A级：净重18斤/箱，每把5-7根，条重约120-150g，微黄，单价X元/箱，5箱起批；到货24小时内坏果按比例补，断指不补。
- 香蕉 B级：净重18斤/箱，允许轻微擦伤和少量断指，单价X元/箱；特价不退换。
- 菠萝 A级：净重20斤/箱，约6-8个，单果2.5-3.5斤，半熟带冠，单价X元/箱；坏果超5%补。
- 菠萝 B级：净重20斤/箱，单果2-3斤，允许轻微外观瑕疵，单价X元/箱；特价不退换。

**三、报价时必须说清的四件事**
1. 单价按箱还是按斤，净重还是毛重。
2. 起批量、混装是否同价、是否包运费。
3. 成熟度与到店可售时间，避免小店按A级价买到“明天就熟过头”的货。
4. 损耗归属：坏果补、断指不补、特价不退换，最好写成一句话贴在报价单上。

**四、最实用的做法**
给每家小店一张“一页报价单”：左边香蕉、右边菠萝，每品只列A/B/C三档，每档写“规格、单价、适合怎么卖”。同时用固定编号，比如“香蕉A-18斤-微黄”“菠萝A-20斤-半熟”，以后微信下单只报编号，减少扯皮。
