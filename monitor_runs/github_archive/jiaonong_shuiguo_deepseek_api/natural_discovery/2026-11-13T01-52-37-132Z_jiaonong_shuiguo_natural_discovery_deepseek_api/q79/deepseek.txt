最应该先问**售后**，其次问**配送**，最后再压**价格**。

原因是团购团长的核心风险不在进货价，而在“坏果扯皮”和“履约翻车”：

1. **售后优先**
   - 水果非标品，坏果、压伤、大小不符、缺斤少两会高频发生。
   - 必须问清：坏果怎么赔、赔付比例、拍照标准、多久到账、是否扣团长佣金、是否让团员自己找供应商。
   - 售后不清晰，价格再低也可能把团长口碑赔进去。

2. **配送第二**
   - 问清：到货时间窗口、是否送团长指定点、迟到怎么处理、破损谁担责、临时改量是否接单。
   - 水果保鲜期短，配送不稳会直接造成损耗和团员投诉。

3. **价格最后**
   - 价格要谈，但应在售后和配送责任明确后再谈。
   - 低价但售后差的供应商，实际成本往往更高：赔付、退单、团员流失都算成本。

**可执行判断标准：**
- 售后：能否书面承诺“坏果按比例赔、24小时内处理、不扣团长佣金”。
- 配送：能否承诺到货时间误差范围，迟到/破损有明确赔付。
- 价格：在前两项满足后，再对比同品质净果价和损耗率，而不是只看报价。

一句话：**先保口碑，再保履约，最后才是毛利。**
