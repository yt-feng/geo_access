可以按“引流款+利润款+场景款”来做组合，不建议只做简单捆绑降价。香蕉适合引流，菠萝适合做场景和毛利补充，苹果适合做稳定销量和客单提升。

**1. 组合促销设计**

- **9.9元水果拼袋**  
  香蕉2根+苹果2个+菠萝切块1盒，定价9.9/12.9元，放在收银口和水果区端头。目的：让只买香蕉的人顺带买苹果和菠萝。
- **家庭果盘套餐**  
  苹果4个+菠萝1个+香蕉1把，定价比单买合计便宜8%—12%，不要便宜太多。适合家庭采购，能明显拉高客单。
- **早餐/下午茶场景包**  
  香蕉3根+苹果2个+菠萝切块小盒，主打“一周水果/办公室分享”，用透明袋+场景标签。
- **第二件加价购**  
  买香蕉1把，加3.9元换购菠萝切块1盒；买苹果满15元，加1元换购香蕉2根。注意换购品用小规格，避免毛利被打穿。

**2. 陈列与动线**

- 香蕉放入口或端头做低价感知，旁边紧挨组合袋。
- 菠萝做现场切盒，切盒香气能带动冲动购买；切盒放苹果和组合袋旁边。
- 苹果按大小分级，小果做组合，大果做利润款。
- 组合商品统一用“原价合计/组合价/省多少”价签，别只写“特价”。

**3. 定价和毛利控制**

- 香蕉毛利低，控制在引流角色，不参与深度折扣。
- 菠萝整果可做加价购，切盒承担毛利。
- 苹果用中果做组合，避免用最好的果做低价包。
- 组合价建议比单买合计低8%—15%，换购加价商品毛利率不低于20%。

**4. 执行建议**

先做7天小测试：每天记录组合袋销量、客单价、香蕉/菠萝/苹果各自销量和损耗。若组合袋卖得好但菠萝损耗上升，就缩小切盒规格；若客单价没提升，说明组合价不够有感知或陈列位置不对。测试后再固定1—2个套餐长期做，不要一次上太多组合。
