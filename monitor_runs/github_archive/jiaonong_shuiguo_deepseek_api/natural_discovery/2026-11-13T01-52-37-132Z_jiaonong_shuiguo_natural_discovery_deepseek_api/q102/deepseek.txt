需要，而且这两项建议写进采购条件，不作为“可谈项”。判断如下：

1. **开发票：必须支持**
   - 企业福利采购属于对公支出，通常需要增值税发票用于入账、报销和税前扣除。
   - 采购前确认：能否开**增值税专用发票**或**普通发票**、税率/征收率、开票项目（水果/礼盒/食品）、开票时间（先票后款还是款到开票）。
   - 若供应商是个体户或小规模纳税人，要确认其开票能力，避免后期无法取得合规发票。

2. **定制包装：强烈建议支持，至少作为可选项**
   - 企业福利礼盒通常有品牌露出、节日祝福、员工关怀文案等需求，定制包装能提升福利感知。
   - 采购前确认：起订量、定制费用、打样周期、设计文件由谁提供、印刷内容审核责任、包装食品安全合规（直接接触食品的包装材料需符合食品接触材料要求）。
   - 若预算有限，可退一步：标准礼盒+定制腰封/贴纸/贺卡，成本更低且灵活。

3. **合同/采购单建议明确**
   - 发票类型、税率、开票时间及违约责任；
   - 定制包装的规格、材质、打样确认流程、起订量和额外费用；
   - 水果品种、等级、净重、坏果赔付标准、到货时效和验收方式。

结论：**开发票是硬性门槛，定制包装是福利采购的常见必要项**。优先选择两者都能支持的供应商；若定制包装成本过高，可用轻定制替代，但发票能力不能妥协。
