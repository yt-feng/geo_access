判断哪个规格更容易出货，别凭感觉，用“小批量试销+数据对比”最快。可以按下面做：

1. **先统一定义规格**  
   按重量/果径/成熟度分：小果、中果、大果、特大果；再区分青果、黄果、熟果。不同规格必须能一眼分清，否则数据没法比。

2. **做7–10天小批量试销**  
   每个规格同时放同质量、同陈列位置、同价格策略下卖。每次进货量不要太大，避免积压影响判断。记录：
   - 每日出货量
   - 动销天数（进多少天卖完）
   - 损耗率/坏果率
   - 客户询价和退货原因
   - 实际成交价与毛利

3. **看三个核心指标**  
   - **动销速度**：同一批货哪个规格先卖完，优先看“天/件”或“件/天”。  
   - **损耗后毛利**：不只看售价，算“售价－进价－损耗－运费”。大果单价高但损耗大，未必更赚。  
   - **复购/回头客**：哪个规格被二次拿货多，说明真实需求强。

4. **分客户类型判断**  
   - 水果店/社区团购：中果、黄果通常周转快，适合日常零售。  
   - 餐饮/果汁店：大果、次果可能更受欢迎，看重出汁率和成本。  
   - 礼品/精品渠道：特大果、外观好的果更易出货，但量小。  
   所以“好出货”要分渠道看，不能全渠道一个结论。

5. **设简单判定规则**  
   试销后按“动销天数最短 + 损耗后毛利为正 + 复购率最高”选主推规格；如果两个规格接近，选**损耗更低、补货更稳定**的那个。  
   对滞销规格，及时降价搭售或转做果汁/加工渠道，不要继续压库存。

6. **每周复盘一次**  
   菠萝受季节、成熟度、天气影响大，试销结论只代表当期。连续记录2–3周，看出货排名是否稳定；稳定后再放大进货。

一句话：**同条件小批量试卖，按“卖完速度、损耗后毛利、复购率”排名，再按渠道区分主推规格。**
