小商家采购水果，现金结算和月结账期各有风险，核心区别是：**现金结算主要承担“钱货两清后的质量/短斤少两风险”，月结主要承担“赊账信用和账期失控风险”。**

### 一、现金结算的风险

1. **质量与数量事后难追责**
   - 现场付款后，水果短斤少两、以次充好、内部腐烂，回头找供应商容易扯皮。
   - 建议：当场抽样开箱、称重、拍照留证，并在单据上写明品种、等级、数量、单价。

2. **价格波动风险全由自己承担**
   - 水果价格波动大，现金采购通常即时定价，买在高点没有缓冲。
   - 建议：对大宗单品设采购价上限，分批次小量补货，避免一次压太多现金。

3. **现金管理和安全风险**
   - 现金交易容易无票、无流水，后续记账、报税、对账困难。
   - 大量现金随身有丢失、被盗风险。
   - 建议：尽量转账并保留记录；现金交易也要开收据或写清采购单。

4. **供应商稳定性弱**
   - 现金结算对供应商吸引力有限，紧俏时好货可能优先给长期月结客户。
   - 建议：核心供应商保留少量稳定合作，不要只靠临时现金采购。

5. **采购人员舞弊风险**
   - 现金采购容易出现虚报价格、吃回扣、虚增数量。
   - 建议：采购与付款分离，定期询价对比。

### 二、月结账期的风险

1. **供应商信用风险**
   - 月结本质是供应商给你赊账。若供应商经营不稳、突然断供或换人，已付定金或未结货款容易纠纷。
   - 建议：月结供应商要签简单供货协议，明确账期、对账日、付款日、质量异议期。

2. **账期失控、现金流压力**
   - 水果周转快但损耗高，月结容易让商家误以为“资金宽松”，月底集中付款时现金流紧张。
   - 建议：设应付账款台账，按周预排月底付款额，月结采购额不超过可承受的月均现金流的固定比例。

3. **对账纠纷**
   - 水果每天价格、等级、损耗不同，月结若只记总数，月底容易因单价、退货、损耗扯皮。
   - 建议：每车/每批货当场签送货单，写明品名、等级、件数、重量、单价、金额；退货和损耗当日确认。

4. **质量异议期被压缩**
   - 月结时供应商可能认为“货已用了一个月才说不好”，拒认质量问题。
   - 建议：合同或送货单上约定“收货后24小时内提出明显质量问题，内部腐烂按约定比例赔付”。

5. **过度赊购导致依赖和议价能力下降**
   - 月结额度越滚越大，可能被供应商绑定，价格谈判空间变小。
   - 建议：至少保留两家备选供应商，月结额度设上限。

6. **法律与凭证风险**
   - 没有书面账期约定时，供应商可随时要求付款；口头月结容易变成“随时催款”。
   - 建议：微信文字确认账期也算证据，最好有盖章或签字的对账单。

### 三、给小商家的实操建议

- **现金采购**：适合新供应商、小批量、价格波动大的单品；坚持当场验货、留单据、尽量转账。
- **月结采购**：适合质量稳定、长期合作的核心供应商；必须签简单协议、每批签单、定期对账、设额度上限。
- **混合策略**：核心供应商月结但控制额度，临时补货现金结算；不要把所有采购压在一个账期上。
- **最关键的三件事**：每批货有单据、质量问题有时间约定、应付账款有台账。
