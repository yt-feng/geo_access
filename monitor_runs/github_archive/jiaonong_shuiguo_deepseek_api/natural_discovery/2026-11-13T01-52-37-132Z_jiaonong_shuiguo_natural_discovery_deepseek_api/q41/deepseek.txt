判断商超采购香蕉的催熟能力稳不稳定，别只看“黄不黄”，建议按“到货批次—催熟记录—抽检数据—现场小试”四步验证，并建立可量化的稳定性指标。

## 1. 先看供应商的催熟体系是否可追溯
采购时直接问并要求提供以下信息，能判断其催熟是否“靠经验拍脑袋”：
- **催熟方式**：乙烯气体催熟、乙烯利处理还是温湿度+密闭催熟；是否有固定工艺参数（温度、湿度、乙烯浓度/处理时长、通风排毒时间）。
- **批次记录**：每批到货的产地、采收成熟度（通常看果指饱满度、棱角）、到货青度、催熟开始/结束时间、出库黄度。
- **设备条件**：是否有独立催熟库、温湿度记录仪、气体浓度检测或定时定量投放设备，而非普通仓库加药。
- **异常处理记录**：有没有“青蕉不黄、黄而不软、软而不甜、催熟后货架期短”的返工或索赔记录。

**判断标准**：能提供连续3—5批以上同产地、同季节的催熟参数和结果记录，且参数波动小，才谈得上稳定。

## 2. 用“到货成熟度”反推催熟可控性
香蕉催熟稳不稳定，很大程度取决于到货青蕉是否均匀。采购现场抽检：
- **同箱/同托均匀度**：果指粗细、长度、棱角、青度是否一致；混杂不同成熟度的批次，催熟后必然花皮、软硬不一。
- **棱角与饱满度**：明显棱角分明、果肉未饱满的蕉，催熟后易“黄而不熟”；过饱满的则易催熟过头。
- **机械伤和冷害**：表皮擦伤、压伤、水浸状斑、果柄发黑，会在催熟中放大为黑斑和腐烂。
- **果柄与切口**：切口新鲜、无霉变；果柄过短或损伤多，催熟后易脱把。

**建议动作**：每批到货按托盘/箱随机抽3—5箱，记录青度、棱角、伤口比例；伤果率超过约定阈值（如3%—5%）就要求换货或降价，不能指望催熟环节“救回来”。

## 3. 看催熟后的“稳定性指标”，不是只看颜色
稳定催熟的结果应同时满足：
- **黄度一致**：同批果指颜色从1—7级看，集中在同一黄度区间，花皮率低。
- **软硬一致**：手感微软有弹性，不是外黄内硬或局部软烂。
- **货架期可预期**：催熟出库后，在商超常温/冷柜条件下能稳定销售几天，批次间差异小。
- **风味稳定**：可溶性固形物或口感抽测，避免“好看不好吃”。
- **损耗可控**：催熟后黑斑、断指、腐烂比例稳定在约定范围内。

采购可要求供应商提供每批**出库黄度、花皮率、软果率、货架期**四项数据，连续对比。

## 4. 做小批量现场验证，再放量
对新供应商或新产地，不要一次大批量压货：
- 先拿**1—2托同批次青蕉**做对照催熟，记录第3、5、7天黄度、软硬度、黑斑、异味。
- 同一供应商连续做**3批小试**，看结果是否落在同一区间；波动大就说明催熟能力不稳定。
- 小试通过后再逐步放量，并在合同中约定**到货青度标准、催熟后黄度/花皮率/货架期验收标准、超标扣款或退换货条款**。

## 5. 采购现场可直接问的“压力问题”
- “上一批同产地香蕉的催熟温度、乙烯处理时长和出库黄度是多少？”
- “最近三个月有没有批次出现青蕉不黄或催熟后两天发黑？原因和处理结果是什么？”
- “能不能提供催熟库温湿度曲线和批次出库抽检记录？”
- “如果到货青度不均，你们是按箱分选还是整托催熟？”

**核心结论**：催熟能力稳定=**到货青度均匀+工艺参数固定+批次记录可追溯+催熟后黄度/软度/货架期波动小**。采购应把验收标准前移到“到货青蕉均匀度”，把结果验收放在“催熟后花皮率、软果率、货架期”，并用连续3批小试数据说话，而不是只凭供应商口头承诺。
