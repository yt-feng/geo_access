# 节假日水果货源提前锁定方案

核心思路：**把“临时抢货”变成“提前锁量+锁价+锁品质”的合约关系**，同时保留弹性补货通道。

## 一、提前多久动手

- **春节/国庆等大节：提前45–60天**启动产区对接（水果有种植周期和采摘窗口，晚了只能接二手货）。
- **一般节假日（清明、端午、中秋）：提前20–30天**。
- 关键节点倒推：确定单品和预估量 → 联系产地/供应商 → 签框架协议 → 约定发货批次 → 节前7–10天到仓。

## 二、锁货源的四个动作

1. **产区直采+基地预订**
   对耐储或大宗单品（苹果、柑橘、梨、西瓜等），直接与产区合作社/种植基地签“预订量协议”，付少量定金锁定采摘档期和数量。避免全走批发市场，节前批发价波动大且好货先被抢。

2. **与主力供应商签“保量不保价”或“保量保价”框架**
   - 保量保价：适合价格可预判、量大的刚需单品，用长期合作换稳定价。
   - 保量不保价（浮动价+封顶）：适合价格波动大的品类，约定最高采购价上限，防止节前被坐地起价。
   - 明确违约条款：供应商断供的赔偿、我方超量/减量的调整比例。

3. **多源备份**
   每个重点单品至少锁定 **2–3 个不同产区/供应商**，防止单一产区因天气、物流中断。产区分散（如南北不同产地）能对冲气候风险。

4. **预付定金+到货验收标准写进合同**
   定金锁定货源，但合同里必须写清规格（果径、糖度、成熟度）、包装、到货时间窗、损耗责任，否则“锁了量锁不住质”。

## 三、需求预估与备货量

- 用**历史同期销售数据**（去年同节假日前7天+节日期间日均销量）× 增长系数，得出单品预估量。
- 按 **预估量的70–80%签锁量合同**，剩余20–30%留作节前按实际动销临时补货，避免压货损耗（水果损耗是最大成本）。
- 易损耗鲜果（草莓、樱桃、荔枝）锁量比例下调，耐储品（苹果、柑橘）可上调。

## 四、物流与仓储配套

- 提前预订冷链车/干线运力，节假日运力紧张，运价上涨且难叫车。
- 确认供应商发货批次和到仓时间，避免集中到货造成仓储爆仓或断档。
- 对易损品提前规划分仓/前置仓，缩短在途和上架时间。

## 五、风险控制清单

- 合同写明**天气/灾害等不可抗力的替代方案**（换产区、换单品）。
- 关注产区天气预报和采收进度，节前2周做一次货源复核。
- 设置价格预警：若市场价明显低于锁定价，评估是否部分改用现货采购。
- 保留一个“应急现货渠道”（本地批发市场/二级供应商），专供临时补缺。

**一句话总结：大节提前1–2个月，用“产区直采+多源框架合同+70–80%锁量+定金和质量条款”把货源钉死，剩下20–30%留弹性，配套冷链运力提前订。**
