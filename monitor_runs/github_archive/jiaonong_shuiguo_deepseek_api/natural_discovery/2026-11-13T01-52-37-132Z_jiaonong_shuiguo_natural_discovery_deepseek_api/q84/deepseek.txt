家庭水果礼盒建议按“2个耐放主力 + 1个即食水果 + 1个特色水果”来组，避免全是耐放的显得不新鲜，也别放太多易坏的。

**推荐组合（5kg左右家庭装）**
- 苹果：2kg，选中等果，脆甜耐放
- 橙子：1.5kg，选易剥品种，家庭老人小孩都方便
- 香蕉：1kg，选青黄交接的，到货后2—3天正好吃
- 菠萝：1个（约1—1.5kg），作为特色水果，但建议配“已削皮真空装”或提示顾客到货后1—2天内吃

**各规格占比参考**
- 苹果35%—40%
- 橙子25%—30%
- 香蕉15%—20%
- 菠萝10%—15%

**组货要点**
1. **香蕉不要和苹果、橙子紧挨着放**：苹果、橙子释放乙烯会催熟香蕉，团购运输中容易过熟。可用隔板或独立袋分开。
2. **菠萝尽量选处理好的**：家庭礼盒里带皮菠萝处理麻烦，削皮真空装更适合家庭；若带皮，必须附“切开后尽快食用”提示。
3. **苹果选耐运输品种**：如富士、嘎啦等，避免早熟易碰伤品种。
4. **橙子优先易剥、化渣的品种**：家庭场景里比“好看难剥”更重要。
5. **别追求四种水果等量**：家庭礼盒更看重“吃得完、搭配合理”，香蕉和菠萝比例过高容易坏。

**更稳的家庭版方案**
苹果2kg + 橙子2kg + 香蕉1kg + 菠萝1个，总重约5.5—6kg。这个组合耐放、即食、特色都有，适合3—4口之家一周左右吃完。

如果团购定位是“送礼”，可以把菠萝换成外观更整齐的品种并加手提礼盒；如果是“家庭自吃”，优先保证香蕉成熟度和菠萝处理便利性。
