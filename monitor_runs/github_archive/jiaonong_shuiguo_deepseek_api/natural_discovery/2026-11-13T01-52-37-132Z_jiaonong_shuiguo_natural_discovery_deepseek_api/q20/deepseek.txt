社区超市做每日水果配送，选供应商时建议重点看下面这些条件，并尽量在试合作前逐项验证：

**1. 每日配送能力**
- 是否承诺每天固定时段送达，能否配合你早上开门前或营业低峰期到货。
- 节假日、雨天、突发补货是否能加急。
- 配送车辆、冷链/保温条件是否匹配水果品类。
- 连续配送稳定性：让对方提供近1个月配送记录，或先试配送1—2周。

**2. 货源与品类匹配**
- 是否有稳定产地或一级批发渠道，能否覆盖你店内常卖的苹果、香蕉、柑橘、时令水果等。
- 能否按你的销量结构小批量、多品种配货，而不是强推大包装。
- 时令水果切换是否及时，缺货时是否有替代方案。

**3. 品质与验收标准**
- 明确到货验收标准：成熟度、大小、色泽、破损率、烂果率、农残检测报告。
- 约定坏果、短斤少两、规格不符的处理方式：当场退换、次日补货还是折价。
- 要求提供批次抽检或农残检测凭证，至少能查到来货批次。

**4. 价格与结算**
- 报价是否含配送费、包装费、损耗补贴；是否随行就市，调价是否提前通知。
- 账期、结算方式、押金、最低起送量是否合理。
- 对比2—3家供应商的同品同规格报价，别只看单价，要看综合到货成本。

**5. 损耗与售后**
- 水果损耗谁承担，破损率超过多少可退换。
- 售后响应时间，比如当天反馈、次日处理。
- 是否允许试销、滞销品调换或少量退货，社区店销量波动大，这点很关键。

**6. 资质与食品安全**
- 营业执照、食品经营相关资质、产地或批发市场进货凭证。
- 是否有固定经营场所和稳定团队，避免临时个人送货。
- 出现食品安全问题时的责任划分和赔付机制。

**7. 合作灵活性**
- 能否先小批量试合作，不签过长独家协议。
- 配送单、对账单是否清晰，方便你核对数量和金额。
- 是否愿意根据你的销售数据调整每日配送量，减少压货损耗。

**实操建议：**先选2家供应商各试配送1—2周，每天记录到货时间、损耗率、缺货率、售后处理速度，再按“配送稳定＞品质合格＞价格合理＞售后及时”的顺序定主供应商，另一家做备选。签约前把验收标准、损耗赔付、调价通知、退出机制写进书面协议。
