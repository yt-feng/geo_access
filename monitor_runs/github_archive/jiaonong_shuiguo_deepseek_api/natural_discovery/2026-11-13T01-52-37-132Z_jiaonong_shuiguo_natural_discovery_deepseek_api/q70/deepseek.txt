合同里写坏果责任，核心是把“谁承担、怎么认定、怎么赔、怎么防扯皮”四件事固定下来。可以按下面条款思路写，具体比例你们按品类和运输距离谈。

**1. 明确风险转移节点**
不要只写“货到后损耗由谁负责”，要写清楚：
- 装车前的坏果由供货方承担；
- 运输途中因供货方包装、装载不当造成的坏果由供货方承担；
- 到货后双方在约定时限内共同验收，验收确认的坏果按约定处理；
- 因批发商收货后储存、搬运不当造成的扩大损失，由批发商承担。

**2. 约定坏果认定标准**
建议写可操作标准，例如：
- 以到货开箱抽检/全检为准，双方共同拍照、录像并签字确认；
- 明确“坏果”定义：腐烂、霉变、严重压伤、开裂、异味、不符合约定规格等；
- 约定抽检比例和推算规则，如按每车/每批随机抽检若干箱，坏果率超过约定阈值即启动赔付；
- 对争议批次可约定送第三方检测或由双方认可的共同验货人判定。

**3. 约定免赔率和赔付方式**
常见写法：
- 坏果率在X%以内为合理损耗，供货方不赔；
- 超过X%的部分，按实际坏果数量对应货款的Y倍赔付，或直接补发同等数量合格货品；
- 赔付方式二选一：补货、折价扣款、退款；
- 明确赔付时限，如验收确认后几个工作日内完成补货或从下批货款中抵扣。

**4. 写清验收时限和逾期后果**
例如：货到后24小时内完成验收；批发商应在发现坏果后及时书面/微信通知供货方并保留影像证据；逾期未提出异议视为验收合格。这样既保护批发商，也避免无限期追责。

**5. 包装和运输责任**
可要求供货方按约定包装标准供货，因包装不符导致运输损耗的，由供货方承担；承运人由谁指定也要写清，若由供货方代办运输，供货方应对运输环节造成的坏果先行负责。

**6. 证据和争议解决**
约定验收单、照片、视频、聊天记录可作为责任认定依据；争议协商不成时向哪地法院起诉或仲裁。

**可直接套用的简版条款：**
“双方于到货后24小时内共同验收。坏果指腐烂、霉变、严重压伤、开裂、异味及不符合约定规格的果实。坏果率在__%以内为合理损耗，供方不承担责任；超过__%的，供方应在验收确认后__日内按超出部分对应货款予以补货/折价/退款。因供方包装、装载或运输安排不当造成的坏果由供方承担；因需方收货后储存、搬运不当造成的扩大损失由需方承担。验收以双方签字确认的验收单及影像资料为准。”

关键是把阈值、时限、赔付方式和证据形式写具体，不要只写“坏果由供货方负责”，否则到货后容易扯皮。
