水果锁价能锁多久，没有统一标准，主要看品类、季节、供应商类型和你们的采购量。一般可以这样判断：

1. **常规水果（苹果、梨、橙子、香蕉等）**
   - 短期锁价：**1周—1个月**最常见。
   - 中等锁价：**1—3个月**，通常要有一定采购量、预付定金或框架协议。
   - 超过3个月：较少见，除非是冷库果、进口果或供应商有较强套保/库存能力。

2. **应季鲜果（荔枝、樱桃、水蜜桃、西瓜等）**
   - 一般只能锁 **3—7天**，甚至按批次当天定价。
   - 因为产地价格、天气、成熟期波动大，供应商通常不愿长锁。

3. **进口水果**
   - 可锁 **2周—1个月**较常见。
   - 受汇率、海运、关税、产地行情影响，长锁价通常要加风险溢价。

4. **大宗长期采购**
   - 如果月采购量稳定、单品集中，可谈 **1—3个月框架锁价**，但常附带：
     - 锁价不锁量，或锁量上下浮动10%—20%；
     - 超出约定量部分随行就市；
     - 遇到极端天气/产地暴涨可重新议价；
     - 预付款或保证金；
     - 质量标准、损耗赔付写清楚。

**实操建议：**
- 先按 **“1个月锁价 + 月度复盘”** 去谈，最容易落地。
- 对波动大的单品，谈 **“保底价+浮动上限”** 或“周度定价”，比硬锁半年更现实。
- 合同里一定写明：锁价期限、锁价量、超出量计价、质量等级、损耗承担、违约和调价触发条件。

一句话：**常规果1—3个月可谈，应季鲜果多为几天到2周，进口果2周—1个月；超过3个月一般要加条件。**
