**会，而且影响不小。**  
香蕉是水果店里的“快消品”，顾客购买时对颜值和规格的容忍度其实很低。一箱里大小不一会直接影响销售，具体体现在几个方面：

**1. 顾客感知“不新鲜、不正规”**
- 顾客挑货时，看到同一箱里有的粗大、有的细短，第一反应往往是“这箱是别人挑剩下的”或“进货渠道不稳定”。
- 心理上会觉得“连大小都不统一，成熟度估计也不均匀”，从而降低购买意愿。

**2. 定价与称重矛盾**
- 如果你按**斤**卖，大果和小果混装，顾客买走时可能专挑大的，剩下的小的更难卖（沉淀为损耗）。
- 如果你按**份/把**卖，大小不一会让部分顾客觉得“同价不同量”，引发争议或差评。

**3. 成熟度问题（最致命）**
- 香蕉大小不一通常意味着**采收批次或成熟度不同**。一箱里可能有些已经出现黑斑、有些还发青。
- 顾客买回去一两天，大的可能已熟透软化，小的还硬邦邦，这会导致**复购率下降**，甚至投诉。

**4. 陈列效果差**
- 整齐划一的香蕉视觉上更显“高货感”，能让顾客觉得果品档次高。
- 大小混杂的货架，看起来像“处理品”，很难卖出合理的利润价。

---

**给你的实操建议（按优先级）：**

| 方案 | 操作 | 效果 |
|------|------|------|
| **分拣销售** | 到货后花5分钟把大果、小果分开，分两个价签（大果+0.5~1元/斤，小果低价走量） | 避免“以大带小”心理，小果反而能快速清掉 |
| **直接按份卖** | 按“**每份4-5根**”打包，每份里大小尽量接近（不必完全一样，视感统一即可） | 减少挑选纠结，提高客单价 |
| **特价处理** | 如果混装严重，直接整箱打**特价**（如“清货价”）并标注“家庭装自食”，靠低价走量 | 不占损耗，快速清库存 |
| **源头换货** | 长期遇到混合装箱，要求供应商下次发“**单规格整箱**”（如都按7-8根/手），哪怕进价稍高0.2~0.3元/斤也值得 | 从源头规避问题 |

**一句话结论**：大小不一**不一定会让你亏钱**，但如果直接原箱上架，**大概率会拉低客单价、增加损耗**。建议上架前先分拣，或者直接透明化低价处理，别给它“混着卖”的机会。
