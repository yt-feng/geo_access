是的，采购香蕉和菠萝时，起订量过高确实会显著增加损耗风险。主要原因包括：

1. **易腐性**：香蕉和菠萝都是典型的高呼吸率水果，采摘后会持续成熟，尤其香蕉释放乙烯快，常温下几天内就会过熟变质；菠萝虽然稍耐放，但切开后极易腐烂。
2. **保质期短**：香蕉在25℃下保鲜期通常只有3-5天，菠萝带皮冷藏约1周，去皮后仅1-2天。起订量高意味着库存周转慢，一旦销售不及预期，就会面临大量报废。
3. **储存条件要求高**：两者都需要冷库（12-14℃）和湿度控制，且容易受挤压、磕碰导致淤伤，起订量大时仓储空间和分拣环节的损耗比例也会上升。
4. **需求波动**：如果起订量是按照预估峰值设定的，而实际销量低于预期，剩余库存只能降价处理或直接报废，损耗率可能从正常的5-8%飙升到20%以上。

**建议**：
- 优先与供应商协商**分批次送货**（如每周2-3次），而不是一次囤积全部起订量。
- 若起订量无法降低，考虑**联采拼单**（与其他门店/摊主分货），或选择**更耐储存的品种**（如菲律宾菠萝比本地菠萝更耐放）。
- 建立**动态采购机制**：根据近3天实际销量和库存周转天数，动态调整下单量，而不是机械执行固定起订量。
- 在合同中明确**损耗补偿条款**，如因送货延迟导致的过熟损耗由供应商承担。

如果起订量实在过高，建议先试运行一个小批量测试，再判断是否值得扩大。数字上，一般建议将单次采购量控制在不超过3天预期销量的范围内。
