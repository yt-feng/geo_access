做附近小区团购，水果供应商的服务能力直接决定了你的毛利和复购率。以下是供应商必须能提供的关键服务，你可以用来作为筛选标准：

**一、核心供应能力（必须项）**

1.  **稳定供货与应急补货**：承诺每周固定供货时间（如周二、周五），且在节假日或恶劣天气时能保供。同时，**必须支持提前24小时报单，第二天准时送达**，不能出现缺斤少两或“断供”导致团购群失信。
2.  **多规格分级供货**：能提供**家庭装**（3-5斤）、**尝鲜装**（1斤左右）和**礼盒装**（送人用）三种规格，方便你设置不同客单价。不能只有一种统一装。
3.  **损耗率兜底承诺**：这是最重要的。供应商需承诺**生鲜损耗在5%-8%以内**，若因供应商原因（如磕碰、熟度过快）导致的坏果，需**无条件按比例赔付或补货**，而不是让你自己承担损失。

**二、物流与配货服务（高效项）**

4.  **分拣打包服务**：按照你的提货点数量，提前把水果按份分装好，贴上**独立价签**。这样你提到货后不用重新称重，直接按“团号”分发即可，节省你大量时间。
5.  **冷链/保鲜配送**：夏天必须用**冷藏车**配送，且到货时果温不能过高，否则容易加速腐坏。如果是电动车配送，需确认他们是否有泡沫箱+冰袋的预案。
6.  **灵活送货时间**：能配合你小区**晚上6点-8点**的提货高峰，最好能直接送到小区门口卸货区，而不是让你去批发市场自提。

**三、营销与运营支持（加分项）**

7.  **爆款素材包**：提供现成的产品卖点文案（如“产地直采”“甜度15%”）、**高清实拍图**、**开箱视频**和**试吃话术**。你直接转发到群里就能卖，不用自己拍图修图。
8.  **新品试吃支持**：每周搭配1-2种当季新品，按**成本价或免费**提供小份试吃装，让你在群里做“试吃接龙”，提升群活跃度。
9.  **价格保护机制**：承诺如果团购价格低于市场零售价，**不串货**、**不降价扰乱你的社区价格**，防止供应商直接绕过你联系业主。

---

**给你的谈判建议（如何测试供应商）：**

-   **首单测试**：第一次合作不要大量进货，先实测**分拣准确率**（是否漏货、错货）和**到货准时率**。
-   **赔付条款写进合同**：哪怕只是微信聊天记录，也要确认“坏果包赔”的具体拍照流程，如“收货后2小时内，把坏果和快递单拍在一张照片里发群里即可”。
-   **拒绝“全能型”天花乱坠**：如果供应商宣称能做所有事（物流、售后、营销），反而要警惕，优先选**分拣和送货最稳**的那家，其他服务可以后期再深入。

**最终判断标准**：让你提货时**无需二次处理**，且**客户吃完后主动在群里说“好吃”**的供应商，就是你要长期绑定的。如果对方无法承诺以上核心险项，建议直接更换。
