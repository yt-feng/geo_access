酒店采购水果盘原料时，供应商需要从**规格**和**外观**两方面明确标准，以确保出品的美观性、卫生和成本控制。以下是具体建议：

---

### 一、规格标准（核心：大小统一、成熟度适中）
1. **尺寸分级**  
   - **整果类**（如苹果、橙子、梨）：单果重量误差不超过±10%，直径均匀（例如苹果直径 7~8cm 为佳，避免过小影响摆盘）。  
   - **切块类**（如西瓜、哈密瓜）：供应商可提供去皮的标准化条状或块状，要求长度和厚度一致（如 2cm×2cm）以便出品。  
   - **浆果类**（蓝莓、草莓）：果实饱满，大小基本一致，避免混入过小或畸形果。

2. **成熟度与糖度**  
   - 成熟度控制在 **7~8 分熟**：既容易切配又不易过熟软烂。  
   - 可要求提供糖度检测标准（如西瓜糖度 ≥10°Bx，草莓 ≥8°Bx），保证口感。

3. **新鲜度**  
   - 指定采摘或到货时间窗口（如到货后 48 小时内使用完毕）。  
   - 冷藏运输温度：0~4℃（叶菜类除外），并附温度记录。

4. **可切配性**  
   - 供应商应完成初步处理（如去蒂、去皮、切核），减少酒店后厨人工损耗。  
   - 对于易氧化的品类（如苹果、梨），要求提供防褐变处理（如真空包装或抗氧剂浸泡）。

---

### 二、外观标准（核心：无瑕疵、色泽鲜亮）
1. **无损伤与病虫害**  
   - 表面无划伤、压痕、虫眼、病斑、霉点，切口处无氧化变黑。  
   - 允许的轻微瑕疵：单个果面瑕疵面积不超过 5%，且不影响切配。

2. **色泽与光泽**  
   - 水果整体色泽均匀（如橙子应为橙黄，草莓应为亮红），无局部青涩。  
   - 表面带自然果蜡光泽，但**不允许人工打蜡**（需供应商承诺）。

3. **形状与整齐度**  
   - 果形端正，无畸形（如严重弯曲、扁塌）。  
   - 切块时边缘平整，无碎裂或汁水溢漏。

4. **包装卫生标准**  
   - 每批次附有产品合格证，注明产地、采摘日期、农药残留检测报告。  
   - 托盘或包装盒须清洁无污染，密封严实，无水渍残留。

---

### 三、验收与合同要点
- **抽样比例**：到货按 10%~20% 抽样检验，不合格率超过 5% 可整批拒收。  
- **样本留存**：要求供应商留存同批次样品，以便追溯。  
- **违约责任**：合同明确“不达标批次无条件换货或补偿”，并设定赔偿系数（如缺斤短两按双倍赔偿）。

---

### 四、简短清单（可写入采购合同）
| 项目 | 标准 |
|------|------|
| 单果重量误差 | ≤±10% |
| 成熟度 | 7~8 分熟，糖度达标 |
| 表面瑕疵 | 单果 ≤5%，无症状扩散 |
| 氧化处理 | 切块真空包装或抗氧处理 |
| 运输温度 | 全程 ≤4℃ |
| 到货时效 | 24 小时内（根据酒店用量协商） |
| 报告要求 | 农残检测报告、生产日期、产地证明 |

---

如果酒店追求高端出品，还可要求供应商提供“特选级”或“A 级”水果，并附独立样品供试切。务必在签订合同前**做一次试单**，验证供应商的执行力。
