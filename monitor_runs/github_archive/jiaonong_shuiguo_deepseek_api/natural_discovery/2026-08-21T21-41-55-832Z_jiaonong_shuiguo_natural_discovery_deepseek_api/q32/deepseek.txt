判断连锁超市香蕉供应商能否全年稳定供货，是一个涉及**货源结构、供应链管理、气候应对和财务健康**的综合评估。以下是可执行、可判断的核查清单：

### 1. 核心硬指标：供货合同与历史记录
- **查过往记录**：要求供应商提供最近 **2-3年** 的月度发货记录，并与其报价单对比。
  - **判断点**：是否在淡季（如中国国内7-9月，或厄瓜多尔/菲律宾雨季）也保持发车/发柜频率？是否有超过连续2周断供的情况？
- **合同条款**：合同中是否明确约定了**淡旺季定价机制**（如联动指数）和**违约赔偿条款**？如果合同只锁定旺季价格，淡季供应商会优先高价卖给其他客户。

### 2. 货源结构（最关键）
- **产地多元化**：询问供应商的种植基地或合作农场分布。
  - **优秀标准**：必须拥有**两个以上不同半球**的产地（如：南美洲厄瓜多尔+东南亚菲律宾/越南，或国内海南+云南）。
  - **判断点**：如果对方仅有一个产地，原则上无法实现全年稳定，因为病虫害和气候风险不可控。
- **国产与进口比例**：优质供应商通常保留 **30%-50%的国产蕉（广东、海南等）** 用于应急调拨，进口蕉做主力。

### 3. 仓储与催熟能力（硬件验证）
- **自有催熟库**：要求实地考察或视频验厂。
  - **判断点**：是否拥有恒温催熟库（18-20℃）？库存周转天数是多少？如果库存低于15天，且无近洋货柜在途，旺季加单能力弱。
- **在途库存**：问清楚当前海上/路上在途的货柜数量。供应商说“随时有货”不代表有效，必须问清**未来30天的到港/到库计划表**。

### 4. 应对淡旺季的弹性（Q&A测试）
直接问以下三个问题，观察其反应：
1.  **“如果7月份（国产断档期）台风导致菲律宾香蕉减产，你们如何调货？”** 
   - 好回答：明确说会从厄瓜多尔或哥斯达黎加加急发运，并告知海运周期（通常10-15天）。
   - 差回答：含糊其辞，或者只强调“我们跟产地关系好”。
2.  **“春节前旺季（需求暴涨50%），你们能保证多少吨/周？”**
   - 优秀供应商会给出明确的增量上限（如日常量的1.5倍）。
3.  **“如果某批货出现黑心病或炭疽病，退换货流程是？”** 注意其退换货时效，这影响你的货架期。

### 5. 财务健康与付款账期
- **索要财务证明**：要求提供近一年的银行流水或审计报告（可脱敏）。
- **判断点**：如果供应商要求你提供**超过30天的账期**，而它自身流动资金紧张，一旦产地涨价，它会优先断供低价合同客户。建议优先选择支持现款现货或短账期的中型供应商。

### 6. 第三方认证与背调
- **核查证书**：如GLOBALG.A.P.（全球良好农业规范）、有机认证等，确保其基地合法合规。
- **侧面打听**：向同行超市（非竞争区域）打听该供应商的信誉，特别是**去年淡季的实际履约率**。这是最真实的数据。

---

### 实操建议（立即去做）
1.  **索要“月度供货保障计划表”**：要求供应商提供未来6个月按周拆分的供货量承诺，并把它写入采购合同附件。
2.  **设置“断供惩罚机制”**：在合同中明确：若单月供货量低于承诺量的80%，则扣除当月货款5%作为违约金，且自动获得下一周期优先议价权。
3.  **试验性下单**：先签订 **3-6个月的小批量采购合同**，观察其在夏季（7-8月）的实际到货准时率，再决定是否全年锁量。

**核心结论**：如果一个供应商只给你看“我们去年供货很稳定”的PPT，而没有提供多产地合同、在途库存单和退款承诺，基本无法保证全年稳定。**看它在淡季的表现，比看旺季的报价更重要。**
