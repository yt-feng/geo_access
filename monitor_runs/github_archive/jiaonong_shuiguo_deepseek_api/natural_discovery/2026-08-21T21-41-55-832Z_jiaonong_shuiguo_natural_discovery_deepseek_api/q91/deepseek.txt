针对便利店上架香蕉，我的建议是**以“小把（2-3根）”为主力，搭配“单根”做补充**，**不建议优先选择整袋包装**。

具体原因和操作建议如下：

1. **消费场景匹配**：
   - **便利店的顾客**通常购买即时性商品，如上班族早餐、学生课间零食、临时补充能量。他们买香蕉往往**只想买1-2根**，而不是买一袋回家囤。
   - 整袋包装（如5-8根）通常适合家庭或超市场景，在便利店动销会很慢，容易造成积压和损耗。

2. **损耗控制是关键**：
   - 香蕉属于**呼吸跃变型水果**，成熟后极易腐烂。整袋包装一旦有一根坏了，会影响整袋，损耗极高。
   - **小把包装（2-3根）**是最佳平衡点：既能满足“买一点”的需求，又能通过独立包装减少顾客反复翻捡造成的机械损伤（碰伤后容易发黑）。

3. **单根的适用场景**：
   - 如果店铺位于写字楼、地铁口等**白领聚集地**，可以**预留少量单根装**，因为很多人只想花2-3元解决燃眉之急（比如配咖啡）。
   - 单根装建议用保鲜膜或透明胶袋单独包好，定价略高于小把的平均单价，用高毛利对冲损耗。

4. **陈列与定价建议**：
   - **小把装**：建议用**托盘+保鲜膜**包装，标价如“6.9元/把（约3根）”，放在收银台附近的环形水果架上。
   - **单根装**：放在冷柜旁的小型挂钩或小篮里，标价如“2.9元/根”，方便快速拿取。
   - **避免**将裸装整串香蕉直接散放在货架上，容易被人摸伤。

**执行清单（可落地）**：
- 进货时优先订购**催熟度在70%左右的香蕉**，到店后常温放置1天即可上市。
- 每日高峰时段（上午8-10点，下午2-5点）及时补货，非高峰时段将未售完的香蕉放入冷柜（温度13-15℃）减缓成熟。
- 如果店铺面积小、客流少，**只做小把装即可**，单根装仅在节假日或促销时临时增加。

**最终结论**：**首选小把（2-3根），其次单根，放弃整袋**。这符合便利店“即买即走、控制损耗”的生意逻辑。
