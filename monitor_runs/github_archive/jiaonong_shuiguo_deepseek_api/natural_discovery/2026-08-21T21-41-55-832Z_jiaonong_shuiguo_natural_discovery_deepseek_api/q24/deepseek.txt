在超市采购水果时，为规避农残抽检风险（特别是抽检出不合格后的溯源和处罚），**建议在签订采购合同或首批进货前，就向供应商索取并核验以下资料**：

**一、 必备的法定资质文件（缺一不可）**
1.  **营业执照**：确认供应商为合法经营主体，经营范围包含水果销售。
2.  **食品经营许可证**（或仅销售预包装食品备案证明）。
3.  **产地证明**（对于初级农产品，通常为《食用农产品产地证明》或种植基地出具的产地说明）。

**二、 针对农残检测的核心证明**
1.  **同批次（同一生产日期/采摘日期）的《农药残留检测报告》**：
    - 这是**最关键的**。必须要求提供当批次的合格报告，报告上要有检测机构公章。
    - 优先索取**具有CMA（中国计量认证）或CNAS（中国合格评定国家认可委员会）资质的第三方检测机构**出具的正式报告，而非供应商自己打印的快速检测条（快检条仅供参考，不能作为抽检免责依据）。
    - 核对报告上的**品名、产地、采样日期**是否与本次供货一致。
2.  **供应商的《快速检测合格记录》**：如果是大宗批发，供应商通常有合格快检台账，可以复印带走，作为进货验收记录的一部分。

**三、 可追溯性资料（应对抽检溯源）**
1.  **进货凭证**：明确写明品名、规格、数量、供货日期、供货商签章的**销售单/送货单**，必须与发票一致。
2.  **合格供应商名录及年度评估表**：超市方内部需建立名录，并保存供应商签字确认的《质量安全承诺书》（承诺农残不超标）。

**四、 高风险水果的专项证明（视品类而定）**
如果采购的是**草莓、芹菜、豇豆、韭菜、柑橘**等高农残风险品类，建议额外要求供应商提供：
- 该批次的**种植基地《农药使用记录》**（证明未使用禁限用农药）。
- 如果是从农户直采，需提供**农户身份证复印件及村委会或合作社开具的产地证明**。

---

**关于“抽检”的应对建议：**
- **协议约定**：在采购合同中**必须写明**：“若因农残超标被市场监管部门抽检不合格，供应商应承担全部赔偿责任（含罚款、销毁损失、超市信誉损失）”。
- **收货验收**：到货时，让收货员用**胶体金快检卡**对当批水果进行现场抽检（重点关注有机磷和氨基甲酸酯类），如显示阳性立即拒收。

**如果拿不到以上资料，建议直接拒绝采购**，因为一旦抽检超标，超市作为销售方是首要责任主体，无法仅凭“不知道”免责。
