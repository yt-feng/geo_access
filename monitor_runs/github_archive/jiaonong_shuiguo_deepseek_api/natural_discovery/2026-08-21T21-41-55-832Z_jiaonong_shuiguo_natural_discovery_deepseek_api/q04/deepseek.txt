水果店在采购香蕉时，要减少损耗，核心就两条：**“控熟度、定到货时间”**。香蕉是呼吸跃变型水果，在店里自然催熟，所以采购策略必须“以销定采”。

以下是可以直接拿去跟供货商/批发商谈的具体要求：

### 1. 熟度要求（硬性指标）
不要买“全青”或“全黄”的。全青的催熟时间长、占地方且容易在冷库冻伤；全黄的到店后1-2天就过熟发黑。

- **采购标准**：选择**“6-7成熟”**的香蕉（果皮大部分青绿，仅果棱处微黄，果肉微软）。
- **沟通话术**：“到货时硬度要高，果面允许有5%-10%的局部黄，但果柄要青，不能有熟斑或黑点。捏起来要硬挺，不能发软。”
- **注意**：千万要避免“催熟后回冷”的香蕉。如果供货商是南方长途调的，必须问清是否做了“乙烯利催熟+冷链运输”，这种货到店已经是硬熟（外黄内硬），容易假熟且放不住。

### 2. 到货时间要求（与损耗强相关）
目的是避开周末高峰的“死货期”和夏季高温。

- **首选时间**：**周一至周五的上午10点前**到货。周末客流大，但周一到周三反而是香蕉出货慢的时候，上午到货可以当天开箱散热，第二天刚好进入最佳售卖期。
- **避免时段**：**严禁下午4点后到货**。下午到货，傍晚没人买，夜里常温堆放，第二天早上香蕉大概率发黑变软。
- **夏季特殊要求**：6-9月高温，尽量要求**“当天头批货”**，并告知供货商：“运输车必须通风，不能用全封闭闷罐，到货后温度不能高于35℃”。

### 3. 到货后的验收标准（退货依据）
跟供货商明确，到货后**2小时内验货**，如出现以下情况，有权拒收或按比例折价：

- 果柄断裂超过10%。
- 单把出现3根以上全黑或水浸状软烂（这是“过水货”）。
- 表皮有大量二氧化硫或石灰残留（摸起来发涩）。

### 4. 采购时的“损耗兜底”策略
- **阶梯订货**：要求供货商允许**“分次小批量”**甚至**“周结算”**，不要一次性压一周的量。香蕉是按天熟的，周四的销量和周四的订货要单独算。
- **明确“以旧换新”**：跟供货商谈：“如果某批货到店后3天内还没卖完就发黑，供方要免费补我下一批的2把，作为损耗补偿。”大供货商通常愿意补，因为返程运费比货值高。

### 5. 店内操作配合（减少采购风险的附加项）
即使采购对了，也要跟店员讲：**到货后立刻拆箱、平铺散热（不要堆叠）**，并切成单把或两三把装袋（防顾客翻捏）。如果采购的是6成熟，可以在店里放3-5天；如果是7成熟，就只能放2天。

**最终一句话总结给采购员**：
> “只要7成熟，早上十点前到，拒绝全青货，验收发现水烂就当场退，订货永远按‘昨天卖的’减一成来订。”

这样操作，香蕉损耗率一般可以从20%以上降到5%以内。
