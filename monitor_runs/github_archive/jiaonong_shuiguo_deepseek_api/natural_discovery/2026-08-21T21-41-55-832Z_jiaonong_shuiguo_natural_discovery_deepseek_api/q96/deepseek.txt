企业食堂采购水果时，**食品安全**应该是首要关注点，其次是**价格**和**配送准时**。以下是具体原因和建议：

1. **食品安全是底线**  
   - 食堂直接面向员工，一旦出现农药残留超标、腐烂变质或致病菌污染，可能导致集体食物中毒，造成严重后果（法律责任、声誉损失）。  
   - 应优先选择有资质、能提供检测报告（如农残检测）的供应商，并要求签订质量协议。

2. **价格影响成本，但可协商**  
   - 食堂采购量大，价格敏感度较高，但低价可能伴随品质风险。建议通过**长期合作、集中采购**或**季节性水果替换**来控制成本，而不是单纯压价。

3. **配送准时影响运营效率**  
   - 水果新鲜度随时间下降，配送延误会导致损耗增加。可通过**合同约定到货时间**（如每日固定时段）、**设置应急供应商**来降低风险。

**执行建议**：  
- **排序**：食品安全 > 价格合理 > 配送稳定。  
- **操作**：建立供应商准入清单（查资质、验报告），每月抽检；根据历史数据计算合理采购价；对配送延误设置罚款条款（如按次扣款）。  
- **备用方案**：提前1天确认订单，并保留1家备用供应商，以防突发断供。

如果条件允许，可优先选择有**冷链运输**和**本地溯源**的供应商，这通常能同时满足安全性和新鲜度要求。
