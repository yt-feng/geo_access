甜品店采购香蕉时，要避免到店后很快变黑，核心是**控制成熟度和采购时机**。以下是可执行的操作建议：

1. **按用途分批次采购**
   - 短期使用（1-2天内）：选**黄中带绿**的香蕉，全黄且有黑点的只适合当天用。
   - 长期储备（甜品馅料、果泥）：直接采购**青香蕉**，在室温存放1-3天自然黄熟后再用。

2. **采购源头把关**
   - 优先选**箱装且整箱重量感足**的，轻飘的可能是过熟脱水。
   - 现场闻一闻：有浓郁甜味说明已完全成熟，到店后保鲜期极短；有轻微酒精味则是开始发酵的迹象，坚决不要。
   - 拒绝购买表皮有**明显水渍或软塌**的，运输途中破损的部位会加速整串变黑。

3. **冷链运输关键点**
   - 用保温袋或泡沫箱运输，内部放**冰袋但不要贴皮**，用毛巾隔开，防止冻伤（冻伤后表皮会迅速褐变）。
   - 避免把香蕉和苹果、猕猴桃等**乙烯释放源**混装运输。

4. **到店后立刻处理**
   - 到店后**马上拆箱通风**，不要闷在纸箱里。
   - 悬挂放置（用挂钩挂果柄），比平放减少压伤面，可延长20%以上货架期。
   - 如果到店时已接近全黄，**当天必须处理**：切片后立即用保鲜膜包裹冷藏，或打成泥加柠檬汁封存。

5. **急用时的补救法**
   - 如果到店发现已经发黑但未软烂，可剥皮冷冻，用于果昔或烘焙，不影响风味。
   - 黑点极少且刚出现时，剥皮后切块泡入**1%柠檬酸水**（水：柠檬汁=20：1）10秒，能显著延缓切口褐变。

**重要提醒**：香蕉皮变黑是自身激素催熟过程，无法完全阻止。甜品店建议与供货商约定“提前一天送黄绿熟度香蕉”，比任何保鲜手段都更有效。如果连续两次到货偏熟，直接更换供应商。
