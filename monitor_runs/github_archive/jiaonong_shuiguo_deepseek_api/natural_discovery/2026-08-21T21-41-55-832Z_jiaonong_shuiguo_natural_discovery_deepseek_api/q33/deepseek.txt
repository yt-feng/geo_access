**非常重要。** 对于多门店超市来说，供应商的分级标准不仅仅是“重要”，而是**核心命脉**，直接决定了你的品牌口碑、损耗率和利润率。

如果不统一分级标准，会出现以下**致命问题**：

1.  **门店差异大**：A店卖的是“一级果”，B店卖的是“二级果”，但顾客都叫“XX超市的苹果”。一旦B店品质差，顾客会直接拉黑**整个品牌**。
2.  **损耗不可控**：标准模糊导致供应商“掺着卖”，坏果率飙升，门店理货员天天挑烂果，损耗成本惊人。
3.  **定价无依据**：没有统一等级，采购和门店店长都在“凭感觉”定价，导致毛利忽高忽低。
4.  **供应商管理失控**：没有明确等级，供应商会想尽办法钻空子，用低级果冲高级果，后期扯皮不断。

---

### 如何利用供应商分级标准实现统一品质？

建议从以下**三个层面**落地，缺一不可：

#### 1. 制定“超市专属”分级标准（不能直接用产地标准）
- **参考国标但高于国标**：比如砂糖橘，国标按大小分，但超市应增加**“糖度”**（手持测糖仪）和**“表皮瑕疵率”**标准。
- **细化到具体指标**：不要只说“大”，要说“单果重200g-250g”、“横径85mm-90mm”、“无机械伤”、“着色度≥90%”。
- **制定“收货标准”而非“发货标准”**：标准要以**到店验收**为准，采购合同里要写清“到店损耗率≤3%”。

#### 2. 实行“分级定价”与“分级采购”
- **强制分A/B/C级**：A级供核心门店或做高价区，B级供社区店做促销，C级（瑕疵果）统一入加工中心做果切或榨汁。
- **倒逼供应商**：在合同中约定，如果检出混级（比如B级果掺入A级），**该批次整车降价20%**或直接拒收。

#### 3. 建立“数字化的验收闭环”
- **拍照留档**：门店收货时，必须对抽检的每箱水果拍照上传ERP系统。
- **数据反馈机制**：每月统计各家供应商的“到店合格率”，连续三个月低于95%的，直接降级为备选供应商。
