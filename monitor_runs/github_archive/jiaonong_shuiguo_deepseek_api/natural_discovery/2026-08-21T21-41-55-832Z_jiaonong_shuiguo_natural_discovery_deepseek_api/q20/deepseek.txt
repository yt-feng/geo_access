为社区超市选择每日配送的水果供应商，核心要解决**稳定、新鲜、损耗低、价格有竞争力**这四个问题。建议您重点考察以下五个维度：

**1. 供应稳定性和应急能力（最关键）**
- **日配履约率**：能否承诺每日固定时间（如早7点前）送达，并确认是否有备用货源（如多家种植基地或一级批发市场档口）。
- **缺货替代方案**：如果某天主打水果（如西瓜）断货，能否当天提供等价替代品（如哈密瓜），而不是直接取消订单。
- **合同约束**：合同中应明确延迟配送的赔付条款（如按货值10%/天扣款）。

**2. 新鲜度和损耗率控制**
- **采收与配送间隔**：必须询问水果从采摘到送达门店的时间。超过24小时的水果（尤其是叶菜、草莓、葡萄）新鲜度会断崖式下跌。
- **冷链配套**：需确认供应商是否有冷藏车（非普通厢式货车），温度记录是否可追溯。夏季高温时这一项直接决定货架期。
- **残次率标准**：要求书面承诺单次送货的坏果率（建议≤3%），超出部分按1赔2补货或折扣。

**3. 定价与账期灵活性**
- **日结价机制**：社区超市议价能力弱，可要求供应商提供**当日报价单**（对比当地批发市场均价），并约定好每日价格波动的上限（如±15%内按当日价，超出需沟通）。
- **账期**：能接受“先货后款”且周结或双周结的供应商更合适（避免占用现金流）。若要求现结，需压低3-5%的价格作为补偿。

**4. 品类结构和本地化程度**
- **应季主推能力**：供应商应能提供“本周主推水果清单”（如6月主推荔枝、杨梅），并协助滞销库存出清。
- **本地直采比例**：优先选择有本地果园或周边100公里内合作基地的供应商，运输时间短、价格低，且采摘后处理更及时。

**5. 实际试配与售后响应**
- **先试订一周**：不要急于签长期合同，先试订3-5次，观察实际到货时间（是否在约定时间前后半小时内）、果型均匀度、退换货速度。
- **售后响应时效**：当天反馈坏果问题，供应商是否能在4小时内补发或退款，这是判断其管理水平的试金石。

**给您的执行建议（可直接落地）：**
- 到当地**一级批发市场**找至少2家规模中等（非最大，避免店大欺客）的档口，要求他们提供“社区超市日配方案”并向其他小区超市索要供应商联系方式交叉验证。
- 签订合同时，重点写明：**每日截单时间（如前日20点）、缺货通知最晚时间（前日22点）、迟到扣款标准、坏果赔付方式**。
- 如果供应商承诺“全程冷链”，现场检查车上有无温度记录仪，并随机抽查一次卸货时的果温（莲雾、榴莲等高价果除外）。

**风险提示**：不要被“产地直发”的噱头迷惑，绝大多数社区超市的量贩价低于批发市场直采价，直发品控不稳定。建议您同时备**1家主供给+1家备案备用**，避免单一供应商拿价后控制您。
