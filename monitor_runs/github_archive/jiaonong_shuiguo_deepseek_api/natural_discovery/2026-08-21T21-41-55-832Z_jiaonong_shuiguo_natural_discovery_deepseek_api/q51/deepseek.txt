对于茶饮店来说，**采购水果时固定产地和供应批次非常有必要**，这几乎是从业者绕不开的**核心品控动作**。原因和具体操作建议如下：

**1. 为什么必须固定？——口味稳定是生命线**
- **风味统一**：同一种水果（如芒果、草莓），不同产地（海南 vs 越南，山东 vs 智利）的糖度、酸度、香气物质完全不同。消费者记住的是你**招牌饮品的固定味道**，如果某天芒果突然变酸或香气淡了，复购率会直接暴跌。
- **可追溯性**：一旦出现食安问题（农残超标、霉变），固定产地和批次能让你在1小时内定位问题原料，迅速下架召回，而不是面对一仓库来路不明的货无从下手。

**2. 实际操作中如何“固定”？**
- **锁定1-2个核心产地（主+备）**：不要只押一个产地，因为天气、自然灾害可能导致主产地断货。建议选**主产地占70%销量**，再签一个**备选产地**（口感和主产地接近）作为应急。
- **按成熟度分批次采购**：不要一次性买完。水果是鲜活品，**建议按“到店后7天销量”为一批**。比如A批次当天到、B批次3天后到，避免所有水果同时过熟或积压。
- **与供应商签“规格协议”**：在采购合同里写清楚**糖度下限（Brix值）、单果克重区间、成熟度（如7-8成熟）**。比如采购青柠，要写明“产地为广东湛江，酸度≥6%，果径≥40mm”。供应商做不到就拒收或扣款。

**3. 即使固定了，还需要“动态验证”**
固定不等于三个月不换。**每批货到店后，必须做“到货盲测”**：
- 让店长和2名员工，分别用该批水果做一杯招牌饮品，与上一批做的对比。
- 如果发现酸度、甜度差异超过5%，立刻通知采购调整配方（比如多加点糖浆）或者退换货。

**4. 如果成本有限，给一个折中方案**
如果小店资金紧张，无法签多个产地，**建议固定“供应商”而非“产地”**。找一家自有冷链、能做稳定供应的供应商，要求他们在产季切换时（比如海南芒果下市、转广西芒果），**提前2周通知你**，并寄送样品让你试做调整。**永远不要等到断货再换源头。**

**总结一句**：**固定产地和批次不是束缚，而是你控制成本和口碑的护城河。** 除非你卖的是“当季限定”产品（那也要写明“风味随季节变化”），否则招牌果茶必须保持“一成不变”的味道。
