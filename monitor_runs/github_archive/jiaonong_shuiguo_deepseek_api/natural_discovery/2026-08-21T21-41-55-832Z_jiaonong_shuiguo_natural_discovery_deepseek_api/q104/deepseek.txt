单位采购水果时，如果到货品质不一致，验收和售后处理需要**严谨、留痕、分级处理**。以下是具体操作建议：

---

### 一、验收环节（重点：留证据、划等级）

1. **现场拍照/录像**  
   到货后立即对**整批货**和**随机抽检的几箱/几袋**进行拍照或录像，尤其对品质差异明显的部分（如坏果、过熟、生涩、品相差异）单独特写。这是后续售后的唯一凭证。

2. **分类清点**  
   将水果按品质分为三类：
   - **合格品**（可正常发放/食用）
   - **次品**（可食用但不达标，如大小不均、轻微碰伤）
   - **废品**（腐烂、变质、严重破损，无法食用）

3. **明确比例并记录**  
   在验收单上写明：
   - 总到货数量（公斤/箱）
   - 废品占比（如10%）
   - 次品占比（如5%）
   - 合格品占比（85%）

4. **与合同/订单标准比对**  
   如果采购合同中有明确规格（如“单果直径≥5cm”“无机械伤”），直接对照；若无明确标准，则按“是否影响正常食用”判断。

---

### 二、售后处理（按合同约定或双方协商）

| 情况 | 处理方式 |
|------|----------|
| **废品率≤5%且不影响整体使用** | 可要求供应商按废品重量**折价补偿**（如按采购单价扣除），或要求补发等价水果。 |
| **废品率超过10%** | 属于**严重品质不符**，可要求**全部退换货**，或按合同条款拒收并追责。 |
| **次品率高但可食用** | 与供应商协商按折扣结算（如按次品数量×50%价格补差），或要求供应商承担运费补发一批合格货。 |
| **供应商拒绝处理** | 保留物流签收单、照片、聊天记录，向采购平台/上级部门投诉，必要时走合同违约责任条款。 |

---

### 三、预防性建议

1. **采购前明确标准**  
   合同中写清：  
   - 产地、采摘时间、成熟度范围（如7-8成熟）  
   - 单果重量/大小范围  
   - 允许的（废品+次品）总损耗率（行业一般5%-10%）

2. **分批抽样验收**  
   不要只看表面，随机抽取中下层（防“上下层混装”），翻找箱底是否垫坏果。

3. **售后时效**  
   水果易损耗，从收货到提出售后建议**不超过24小时**，避免因存放导致品质进一步下降，分不清责任。

---

### 四、常见话术（对供应商）

> “本次到货共X公斤，经抽检，废品率约Y%，次品率约Z%。已附现场照片/视频。按合同约定的损耗率上限（如5%），废品超出部分请按采购单价折算退款，或补发等量合格果。请于X日内回复处理方案，否则我们将按合同保留追偿权利。”

---

**核心原则**：**先取证、后沟通、再结算**，不要先付款后发现问题。如果单位有法务或采购制度，优先按既有流程执行。
