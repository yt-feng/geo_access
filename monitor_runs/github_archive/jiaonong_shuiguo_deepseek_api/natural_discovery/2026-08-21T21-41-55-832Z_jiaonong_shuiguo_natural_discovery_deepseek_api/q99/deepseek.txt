选择适合批量配送的水果供应商，建议按以下步骤筛选，重点考察**品控、配送时效和售后**：

**一、核心筛选标准（必看）**

1. **配送能力与时效**
   - 确认是否能覆盖你司具体地址，且**每日/隔日送达**；特别是下午茶场景，**上午订、下午到**或**提前一天到**要明确。
   - 问清是否提供**冷链车配送**（水果保鲜期短，常温车易坏）。
2. **分拣与包装**
   - 批量配送常见问题：磕碰、挤压、烂果。要求供应商提供**独立网套+防压隔层**包装。
   - 要求对方按“整箱”还是“按份”分装（如每份2-3种水果切好或整颗），明确规格。
3. **品控与损耗责任**
   - 约定：**开箱发现坏果/重量不足，当场拍照，按颗/按斤赔付**（行业通用是坏果包赔，比例多为5%-10%）。
   - 不要只信口头承诺，把赔付条款写进采购协议或微信确认记录。
4. **价格与账期**
   - 批量采购一般可谈**阶梯价**（如单次满50份打9折），或**月结（30天）**。
   - 对比**净重报价**，不要被“低价水果价”吸引，要问是否是到司净重价（含包装、配送费）。

**二、供应商类型选择（按你司情况）**

| 类型 | 适合场景 | 优点 | 注意点 |
|------|----------|------|--------|
| 本地水果批发市场档口 | 单次量小、急需 | 现场看货、价格低 | 配送不稳定、售后可能差 |
| 区域型社区团购供应商 | 固定周期大批量 | 有冷链、售后较规范 | 最低起送量可能高 |
| 生鲜电商（如美菜/快驴等） | 中小批量 | APP下单方便、可对账 | 品质波动，需测单 |
| 连锁果切品牌 | 少量高要求 | 切配标准化 | 单价明显偏高 |

**三、实操建议（执行步骤）**

1. **先小批量试单**：选2-3家，各送30份，看送达时间、损耗率（坏果比例）、口感。
2. **建立固定清单**：提前确认当季高性价比水果（如夏天西瓜+提子，冬天橙子+苹果），同时避免过分单一（如全买西瓜）。
3. **固定对接人**：要求对方指定一名销售支持，负责补货、临时加量、突发售后。
4. **记录数据**：每次送货后记录“报损率、迟到次数、口味评分”，3次后淘汰不达标者。

**四、常见高风险坑（避雷）**

- 报价只含水果价，不含纸箱、泡沫箱、配送费（这部分可能占10%-15%）。
- 盲目选“进口水果”，实际运输时间长，损耗高，性价比未必优。
- 不要选无固定地址的“个人微商”，售后无保障。

**最后提醒**：若公司预算允许，优先选**本地或有自有仓库的区域供应商**（配送半径短，水果更新鲜）；建议首月**每单验货拍照留证**，养成习惯后再放宽。
