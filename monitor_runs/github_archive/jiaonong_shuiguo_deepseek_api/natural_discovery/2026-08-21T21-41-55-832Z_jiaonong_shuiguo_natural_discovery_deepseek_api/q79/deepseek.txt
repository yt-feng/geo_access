选水果供应商时，**最应该优先问的是“售后保障机制”**，其次是“配送能力”，最后才是“价格”。

原因如下，这属于**“成本结构”**问题，而不仅是“报价”问题：

1.  **售后是“防亏损”的核心**：水果是生鲜，损耗率极高。如果供应商没有明确的“坏果包赔”、“售后赔付比例”或“缺斤短两补差”机制，一旦这批货出了质量问题，团长需要自掏腰包补贴顾客，**这可能直接吃掉你全部利润，甚至倒亏**。所以必须先确认：**“如果到货发现10%的坏果，你们怎么赔？是按个赔还是按斤赔？赔是折现还是补货？”**
2.  **配送是“防客诉”的关键**：配送决定了水果的“新鲜度”。如果配送时效不稳定（比如隔天到且无冷链），水果到手就可能发软、出水，导致顾客大量退货。要明确：**“你们是次日达还是隔日达？是冷链车还是普通车？坏了谁承担物流责任？”**
3.  **价格是“可谈判”的变量**：水果价格受季节、产量波动大，今天报价低明天可能高。价格只要贵得不是太离谱（比如超过市场价15%以上），通常可以通过**谈账期、谈阶梯价（如满100箱降1元）**来平衡。

---

**如果你时间紧，建议把这3个问题合并成1个“组合拳”来问，最能看出供应商实力：**

> “**按今天这个报价，如果我要订100箱，物流大概要几天到？我想先拿10箱试卖，如果在路上坏了一部分，赔偿是补货还是退款？咱们一般怎么结算账期？**”

**判断标准：**
- **靠谱供应商**：会明确回答“**坏果包赔（按个赔）、次日达（有冷链）、账期可谈（周结/月结）**”。
- **风险供应商**：含糊其辞说“这个到时候再商量”，或者只强调“我们价格最低”，但回避售后细节。

**最后给你的决策建议：**
如果三家都能满足售后和配送要求，**再选价格最低的**。
如果A家便宜但售后模糊，B家贵一点但售后清晰（比如“签收后12小时内凭视频赔付”），**请选B家**。因为一次批量售后纠纷的损失，可能远超你省下的那几百块货款。
