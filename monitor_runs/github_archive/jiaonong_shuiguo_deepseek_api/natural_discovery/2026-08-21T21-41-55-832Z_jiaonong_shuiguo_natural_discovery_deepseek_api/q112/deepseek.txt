在水果采购合同中，关于坏果率的赔付标准**没有统一法定比例**，完全取决于双方约定。但实践中，通常可以参考以下行业惯例和操作建议：

### 1. 合理坏果率的行业参考
大多数批发或零售场景下，合同中常用这几个档位作为“红线”：

- **3%以内（含）**：通常视为**合理损耗**，买方不得要求赔偿或退货。这是最常见的安全线。
- **3% - 8%**：属于**可协商范围**。一般约定按超出部分比例，由卖方折价赔偿（例如：超出部分按货款金额加倍扣减）。
- **8% - 10%以上**：多数采购方会视为**严重违约**，有权要求卖方补足好果数量、拒绝接收该批次、或要求按比例退款。

### 2. 关键约定事项（务必写进合同）
建议你在合同条款中明确以下三项，缺一不可：

- **定义“坏果”**：必须写明包含哪些（如：腐烂、霉变、软化出水、内部褐变），并约定抽样方式（如每箱随机抽取，开箱当面核验）。
- **赔付计算方式**：建议写为“超出5%的部分，每超出1%，按该批次总货款的1%扣除赔偿金”或类似具体公式。**不要只写“协商解决”，否则后续维权困难。**
- **检验时间**：必须约定收货后**48小时内**或**当场**完成验收。水果易腐，超时不提异议，法律上可能视为默认合格。

### 3. 如果合同未约定，如何主张？
若合同没有明确数字，你可以依据《民法典》公平原则，主张以下赔偿逻辑：

- **若坏果率≤3%**：通常无赔偿。
- **若坏果率>10%**：可主张该批次货物**不符合质量要求**，直接拒收或要求解除合同，并要求赔偿运输、保管等实际损失。
- **中间区间**：建议先发书面通知（微信/邮件均可，保留证据），要求按“超出合理损耗部分按比例扣款”处理。若对方拒绝，可申请质量鉴定后起诉。

### 4. 最终建议
强烈建议你在合同签署前谈判时，直接采用以下模板：

> “乙方保证该批次水果坏果率（按个数计算）不超过3%。超出部分，甲方有权按每超出1个百分点扣除总货款2%的标准要求退款；坏果率超过8%的，甲方有权拒收整批货物并退货，乙方承担全部运输费用及甲方仓储损失。”

这样既能保护自己，又避免因标准过高导致无法成交。如果当前合同未做约定，建议尽快补签书面补充协议。
