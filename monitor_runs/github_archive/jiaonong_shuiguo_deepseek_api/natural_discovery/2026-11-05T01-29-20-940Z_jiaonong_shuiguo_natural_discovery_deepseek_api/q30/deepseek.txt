# 超市水果到货品相不好的售后流程约定

## 一、验收标准要写清楚（最关键）

品相问题90%争议来自"标准模糊"。合同里至少要约定：

1. **分级标准**：按品种约定果径、着色度、糖度、瑕疵率（如允许≤5%轻微擦伤，不允许腐烂、软化、开裂）。
2. **验收时点**：到货后几小时内完成验收（如2小时内），超时视为合格，避免供应商扯皮。
3. **验收方式**：抽样比例（如每批抽3箱）、谁在场（收货员+品控）、拍照留证。
4. **允许误差**：约定"不合格率≤X%按合格收货、折价；>X%整批退换"。

## 二、分级处理，不要一刀切

- **轻微品相问题**（外观差但不影响食用）：折价接收，约定折价比例（如按7折结算），可转为特价区销售。
- **明显质量问题**（腐烂、变质、严重压伤）：拒收或整批退货，运费由供应商承担。
- **部分不合格**：挑拣后按实际合格数量结算，挑拣人工费可约定由供应商承担。

## 三、时效与举证

- **报损时效**：到货验收发现的问题当场提出；销售过程中发现隐蔽问题（如内部腐烂），约定"到货后X小时内可追溯"（生鲜一般24小时内）。
- **举证材料**：要求拍照/录像、保留原包装和批次标签、填写验收单双方签字。没有凭证的索赔一律不认。
- **冷链问题**：如涉及冷藏水果，约定到货温度记录（如≤8℃），温度超标可直接拒收。

## 四、责任与赔付条款

- **退换货**：明确"退货、换货、折价"三种方式及触发条件。
- **违约金/赔偿**：因品相问题导致无法销售的部分，可约定供应商按货值赔偿，或从货款中直接扣减。
- **累计考核**：约定"月度不合格率超过X%，可终止合作或调整供货比例"，形成约束。

## 五、流程落地建议

1. 把上述内容写进**采购合同附件《生鲜验收标准与售后细则》**，双方签字。
2. 收货现场执行"**先验后签**"，验收单上注明批次、数量、问题描述、处理意见。
3. 建立**供应商质量台账**，每月复盘不合格率，作为续约依据。
4. 对高频出问题的供应商，改为**到货前预检**或**缩短账期/提高质保金**。

**核心原则**：标准量化、时点明确、凭证留痕、处理方式分级、责任可扣款。把这五点写进合同，售后争议会大幅减少。
