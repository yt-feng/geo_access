社区超市选每日配送的水果供应商，建议按“能不能稳定供、送到能不能卖、出问题能不能兜底”三层筛选。

**一、先看硬性供应能力**
1. **本地或近距产地/一级批发**：每日配送对时效要求高，优先选本地批发市场一级档口、周边产区合作社或区域配送商，减少中转损耗。
2. **配送频次与到店时间**：确认能否每天固定时段送达，比如早6点前到店，是否支持临时补单，节假日是否照常。
3. **品类覆盖与季节切换**：常销果如苹果、香蕉、橙、梨、西瓜能否稳定供；应季果能否提前报品和报价。
4. **货源稳定性**：问清主要单品来自哪些产区、是否自有或合作基地、缺货时如何替代。

**二、再看商品与价格条件**
1. **等级标准**：按斤还是按箱、果径/糖度/成熟度/瑕疵率有无书面标准，避免“图片好、到货差”。
2. **报价方式**：每日报价还是周期定价，是否含运费、装卸费，价格随行就市时提前多久通知。
3. **损耗与退换**：到货坏果、压伤、成熟度过高或不足如何处理，是否支持当场拍照登记、下次补货或折价。
4. **账期与结算**：日结、周结还是月结，是否收押金，能否开票。

**三、必须核验的资质与履约**
1. **营业执照、食品经营相关许可**：水果属食用农产品，仍需确认主体合法、配送车辆和分拣场所卫生条件。
2. **配送车辆与冷链**：普通水果可常温配送，但夏季高温、浆果类、切果类需冷藏或保温措施。
3. **试配期**：先签2—4周试配，约定每日到货验收标准，记录缺货率、损耗率、迟到次数。
4. **应急能力**：临时加单、节日备货、极端天气配送是否有预案。

**四、建议的筛选动作**
- 同时找2—3家报价，拿同一单品同规格比价；
- 要求提供近一周配送客户名单或现场看分拣；
- 首月按“到货合格率、损耗率、准时率、补货响应”四项打分，合格再签长期协议。

核心判断标准：**能每天准时送到、到货可分级销售、坏果有明确兜底、价格随行就市但透明**。先小批量试配，比只看报价更可靠。
