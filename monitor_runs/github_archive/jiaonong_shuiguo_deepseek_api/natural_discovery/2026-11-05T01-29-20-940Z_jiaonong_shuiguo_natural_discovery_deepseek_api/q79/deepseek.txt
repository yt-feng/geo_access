最应该先问**配送**，其次问**售后**，最后再谈**价格**。

原因很直接：团购团长卖水果，真正容易出问题、也最容易伤团长信誉的，是“到货时坏没坏、晚了没晚、坏了谁赔”。价格再低，配送不稳或售后不清，最后都会变成团长自己在群里被投诉、垫钱、掉复购。

建议按这个顺序问供应商：

1. **配送先问清**
   - 能不能按你团的到货时间送？迟到怎么处理？
   - 送到团长点还是分拣到小区？卸货谁负责？
   - 水果有没有冷链或防压措施？
   - 破损、压伤、漏发怎么认定？

2. **售后必须问死**
   - 坏果率超过多少算供应商责任？
   - 拍照报损的时限和标准是什么？
   - 是补发、退款还是下次抵扣？
   - 售后响应多久？谁承担团长对团员的赔付？

3. **价格最后谈**
   - 价格要建立在配送和售后条款清楚之后。
   - 不要只看单价，要算“到货可售成本”：损耗、赔付、垫资、时间成本都算进去。

一句话：**先保交付和赔付，再谈价格。价格低但配送售后不清的供应商，不建议做主力供应商。**
