试单的核心目标不是“赚钱”，而是**用最低成本验证三件事：品质稳定性、履约可靠性、账期/售后可控性**。建议按下面设计。

## 一、先定试单原则

1. **单次金额控制在可承受损失范围内**：建议不超过你单店/单线路周流水的10%—20%，或固定一个“亏了也不影响周转”的金额上限。
2. **不押单一供应商**：同一品类至少找2家同时小试，避免被一家卡住。
3. **先验货再放量**：首单不做账期，现款或货到付款，验证后再谈月结。
4. **合同/订单写清楚**：品名、规格、等级、产地、净重、包装、单价、交货时间地点、验收标准、损耗处理、退货规则。

## 二、试单规模怎么定

- **单品试单量**：按你3—5天能卖完的量下，不要按“便宜多拿”下。比如某单品日销50箱，首单下150—250箱。
- **品类数量**：首单选2—3个你销量最大、最熟悉的品种，不要一次上十几个品。
- **批次设计**：同一供应商分2—3次小批量下单，间隔3—7天，看第二批、第三批是否还能保持品质，而不是只看第一批“样品货”。

## 三、试单要验证的指标（提前做成表格）

| 维度 | 具体验证点 | 判断标准 |
|---|---|---|
| 品质 | 到货等级、大小、色泽、成熟度、腐烂率 | 与样品/约定标准偏差在可接受范围，腐烂率当场记录 |
| 重量 | 净重是否足称、包装是否压秤 | 抽检3—5箱复称，偏差超约定即扣款或退货 |
| 履约 | 是否按时到货、缺货是否提前通知 | 迟到/缺货一次记录，连续两次即降级 |
| 包装 | 是否适合批发周转、有无挤压破损 | 破损率、箱体强度、是否便于分拣 |
| 价格 | 报价是否随行就市、有无临时加价 | 对比当日市场价，临时加价需提前书面确认 |
| 售后 | 烂果/短斤少两是否认账、处理速度 | 明确“到货24小时内拍照反馈”机制 |

## 四、试单流程设计

1. **先要样品/看货**：让供应商发样品或到你当地市场看同批次货，确认等级标准。
2. **首单小批量、现款**：金额小、品种少、到货当场验。
3. **到货验收**：抽检比例建议不低于10%，记录重量、腐烂率、规格偏差，拍照留证。
4. **第二批加量20%—30%**：首单合格再适度加量，仍不签长期大单。
5. **第三批看稳定性**：三批都稳定，再谈账期、返点、独家或包销。
6. **不合格处理**：首单出现明显质量问题，直接按约定退货/扣款，不因“第一次合作”妥协，否则后面更难约束。

## 五、付款与账期

- 首单：**现款现货或货到付款**，不做预付全款。
- 第二、三单：可谈“货到验收后24—48小时付款”。
- 稳定合作3—5次后再谈周结/月结，且账期额度先小后大。
- 预付款只在你已实地看货、对方有稳定档口/基地时考虑，且比例不超过30%。

## 六、合同/订单里必须写清的条款

- 规格等级和验收标准（最好附样品照片或文字标准）。
- 净重与包装扣重方式。
- 到货时限和缺货违约责任。
- 腐烂率/破损率超过多少由供应商承担。
- 价格调整机制（是否随行就市、提前多久通知）。
- 退货、换货、扣款流程和时限。

## 七、给你的直接建议

**首单这样下**：选2个主力品种，每个品种下3—5天销量，金额控制在你可承受范围内，现款现货，到货抽检10%以上并拍照记录；同时找第二家供应商同步小试。连续3批品质和履约都稳定，再逐步放量、谈账期。第一次合作不要追求低价，优先验证“说到的能不能做到”。
