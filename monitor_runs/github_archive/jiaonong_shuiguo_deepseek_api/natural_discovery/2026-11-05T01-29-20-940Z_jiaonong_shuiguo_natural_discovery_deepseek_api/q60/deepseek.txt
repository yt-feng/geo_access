# 水果到货不合格的补货约定方案

核心思路：**把“补货”从口头协商变成合同条款+现场动作**，做到“当场判定、限时补到、缺料有备选”，营业就不会断。

## 一、合同里要写清的4个条款

1. **验收标准前置**
   - 按品类写清合格标准：如芒果糖度≥X、无明显黑斑软烂、单果重量区间、农残检测报告随货。
   - 写明“到货即验、不合格当场拒收”，避免货已入库再扯皮。

2. **补货时限（关键）**
   - 分档约定：**当日补**（上午到货不合格，当日营业前或次日开店前补到）、**24小时补**、**48小时补**，按品类易损程度定。
   - 写明起算点：以“验收不合格并书面通知供应商”之时起算，不是以到货时起算。

3. **补货不到位的替代责任**
   - 供应商逾期未补：要么按缺货金额扣款，要么允许你自行采购、差价由供应商承担（写清凭证要求）。
   - 连续N次不合格或逾期，可单方终止合作。

4. **结算挂钩**
   - 不合格批次不计入结算；补货批次单独验收、单独结算，防止“用次货冲账”。

## 二、现场操作流程（决定补货快不快）

- **收货即验**：固定验收人、固定时段收货，验收单当场签字，不合格拍照留存。
- **书面通知**：微信/钉钉群发“不合格明细+照片+要求补到时间”，留存记录——这是后续扣款和追责的依据。
- **分级判定**：轻微瑕疵（可折价使用）vs 严重不合格（整批拒收），两类处理方式分开写，避免一刀切导致补货量过大。

## 三、营业不中断的兜底设计

- **安全库存**：易损水果保持1~1.5天用量，补货窗口内不断料。
- **备用供应商**：每类主水果至少备1家备选，合同里给自己留“紧急自行采购权”。
- **菜单弹性**：对依赖单一水果的产品准备替代配方或临时下架预案，避免停售影响整体营业。

## 四、谈判落点

优先争取：**当日补+逾期自采差价由供方承担+连续2次不合格可解约**。这三条拿到，补货基本不会拖累营业；供应商若只肯承诺“48小时补”，就把安全库存和备用供应商做厚，用采购端兜住风险。
