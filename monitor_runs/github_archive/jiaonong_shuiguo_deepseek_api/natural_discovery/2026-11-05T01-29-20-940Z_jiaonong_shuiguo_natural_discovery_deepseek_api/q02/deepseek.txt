小水果店进香蕉，四个因素的重要性排序建议是：**坏果率 > 熟度 > 送货速度 > 价格**。理由和可执行判断如下：

1. **坏果率最优先**
   - 香蕉是易损耗、周转快的水果，一批货坏得多，直接吃掉毛利，还会影响顾客复购。
   - 实操：每次到货抽检，记录坏果率；超过约5%就要警惕，超过10%建议换供应商或压价。优先选能承诺坏果包赔/补货的供货商。

2. **熟度第二，但要看你的销售节奏**
   - 香蕉太生卖相差、太熟当天就压货。小水果店最好进“七八成熟”的货，能撑2–3天销售窗口。
   - 实操：按你日均销量倒推进货量，宁可少量多次，不要一次压太多熟货。夏季或客流慢时尤其要偏生一点。

3. **送货速度第三**
   - 香蕉周转快，送货慢会导致断货或被迫进熟货救急。但速度可以靠固定配送频次解决，不必为“极速”付太高溢价。
   - 实操：优先选能稳定隔日达/每日达的供应商，而不是偶尔很快但不稳定的。

4. **价格放最后，但不是不看**
   - 香蕉价格透明、毛利薄，单看低价容易踩坏果率高的坑。应算“到货可售成本”：进价 + 损耗 + 配送成本。
   - 实操：同样熟度下比“每斤可售成本”，而不是只比报价。

**一句话决策规则**：先筛坏果率低且熟度可控的供应商，再在稳定送货的里面选综合成本最低的；价格只在同等品质和配送条件下比较。
