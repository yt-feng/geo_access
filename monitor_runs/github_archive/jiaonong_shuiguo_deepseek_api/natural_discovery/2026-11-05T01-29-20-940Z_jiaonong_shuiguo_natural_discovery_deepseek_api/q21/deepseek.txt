超市采购水果时，供应商通常需要提供以下资料。具体项目取决于水果品类、是否进口、超市自身风控要求和当地监管要求：

**1. 主体与交易资质**
- 营业执照
- 食品经营许可证（或仅销售预包装食品备案凭证；散装水果按当地要求）
- 供货合同/订单、发票或销售凭证
- 送货单，注明品名、数量、产地、批次、日期

**2. 进货证明与溯源**
- 食用农产品进货凭证：产地证明、购货凭证、合格证明文件之一
- 承诺达标合格证（很多地区对食用农产品有要求）
- 批次追溯信息：产地、种植/采摘日期、包装日期、批次号
- 若为进口水果：海关入境货物检验检疫证明、报关单，以及中文标签信息

**3. 检测报告**
- 农药残留检测报告：通常要求有资质的检测机构出具，报告应与批次或产地对应
- 重金属等污染物检测：按超市风控或地方要求
- 若供应商自称“绿色食品”“有机”“地理标志”等，需对应认证证书及有效检测报告
- 超市自检或第三方快检记录也可作为补充，但不能完全替代供应商合格证明

**4. 包装与标签**
- 预包装水果：标签符合食品安全国家标准，含品名、产地、生产者/经营者、生产日期、保质期等
- 散装水果：至少可提供产地、品种、进货日期等溯源信息

**实操建议**
- 采购前让供应商按“一品一证、一批一报告”提供资料，检测报告要能对应到具体批次或产地。
- 对高风险品类（如叶菜类水果、直接入口的浆果等）提高抽检频次。
- 保留进货台账至少满足当地监管保存期限要求。
- 各地对食用农产品合格证、快检报告的要求不同，签约前向当地市场监管部门或超市品控确认清单最稳妥。
