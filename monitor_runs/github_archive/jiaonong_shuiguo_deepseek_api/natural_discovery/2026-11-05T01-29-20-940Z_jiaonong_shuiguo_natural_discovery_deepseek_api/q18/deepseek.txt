采购香蕉避免太生或太熟，核心是**按“预计吃完的时间”倒推成熟度**，并在现场用几个部位判断。可执行建议：

1. **先定用途和时间**
   - 当天/明早吃：选**通体偏黄、少量褐斑**的。
   - 2～3天内吃完：选**黄中带一点绿尖**的。
   - 4～5天吃完：选**绿黄相间、两端略绿**的。
   - 想放一周：选**整体偏绿、无褐斑**的，回家常温分开放。

2. **现场看4个部位**
   - **颜色**：想马上吃选黄色为主；想放几天选带绿。
   - **果柄（连接处）**：发黑、发软说明熟过头或存放久。
   - **棱角**：棱线明显、手感硬＝偏生；棱线圆润＝成熟。
   - **两端**：尖端发黑、渗汁、有酒味＝过熟，别买。

3. **轻捏但别掐**
   - 轻捏中部：**硬**＝生；**略有弹性**＝正好；**一按就软**＝太熟。
   - 不要买表皮破损、裂口、大面积黑斑的。

4. **按把选，不按根选**
   - 同一把香蕉成熟度通常接近；如果一把里有一根已发黑，整把回家会很快过熟。
   - 需要错开吃，可买**两把成熟度不同**的，而不是一把里挑。

5. **回家后的控制**
   - 偏生：常温放，和苹果/梨装同一纸袋可加速成熟。
   - 正好：常温阴凉处，别放冰箱冷藏（表皮会变黑）。
   - 偏熟：拆开单根放，熟透的剥皮冷冻做奶昔；想延后一天可冷藏，但表皮会变黑、口感变软。

一句话：**当天吃选黄带斑，几天吃选黄带绿，一周吃选绿黄相间；果柄发黑、棱线圆润、一捏就软的就别买。**
