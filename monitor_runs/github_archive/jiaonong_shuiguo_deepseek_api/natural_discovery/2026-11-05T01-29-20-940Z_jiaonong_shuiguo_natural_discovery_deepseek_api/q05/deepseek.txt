水果店卖菠萝，核心不是“三选一”，而是**按场景分开卖，主推整果，去皮果做便利补充，顾客自选作为默认动作**。可执行建议如下：

1. **主推整果，但让顾客自己挑**
   - 整果损耗低、毛利更可控，顾客也习惯“挑外观”。
   - 把整果按成熟度分区：即食区、放2—3天区、特价临期区，减少顾客翻找造成的损伤。
   - 明确标价：按个卖或按斤卖要统一，避免挑大挑小引发争议。

2. **去皮果要做，但限量、定时、明码标价**
   - 去皮果适合赶时间、现场吃、办公室场景，是加价便利品，不是主力。
   - 只在高峰前处理少量，卖完再补，避免氧化、出水、损耗。
   - 必须冷藏陈列、标注处理时间，最好当天处理当天清。
   - 定价要覆盖人工和损耗，通常应高于同重量整果折算价。

3. **不要让顾客自己削皮**
   - 现场提供削皮服务比让顾客自己挑完自己处理更好：既保留自选体验，又降低操作风险和卫生问题。
   - 可设“免费削皮/代切”服务，但高峰期收少量服务费或限购。

4. **判断标准**
   - 客流大、上班族多：整果自选 + 少量去皮果。
   - 社区店、家庭客多：整果为主，提供免费削皮。
   - 水果摊/低人工：整果自选为主，不做或极少做去皮果。
   - 去皮果当天卖不完：第二天降价做果切或榨汁，不要继续当鲜切卖。

**结论：整果是基本盘，顾客自选是默认体验，去皮果是限量的便利增值品。** 不要把去皮果当主力，也不要让顾客自己处理整果。
