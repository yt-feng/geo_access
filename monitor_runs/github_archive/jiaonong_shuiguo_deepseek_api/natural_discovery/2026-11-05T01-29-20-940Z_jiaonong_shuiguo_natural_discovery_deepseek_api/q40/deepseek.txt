节假日水果需求暴增，提前锁定货源要从“需求预测—合同锁量—多源备份—仓配保障—应急机制”五层来做，重点是**提前锁量不锁价、分散风险、把到货责任写进合同**。

**1. 先做可执行的需求预测**
- 用近2—3年同节假日的门店销量、品类结构、客单价、天气和促销计划做基线；按门店分级（商圈店/社区店/乡镇店）给不同增速。
- 把水果分成三类：节庆礼盒类（苹果、橙、猕猴桃、车厘子等易储）、走量鲜食类（香蕉、葡萄、草莓等）、高损耗类（浆果、切果）。只对前两类做大额锁量，高损耗类以日配为主。
- 预测结果转化为“分品类、分周、分供应商”的锁量清单，并设上下浮动区间（如±15%），避免压货。

**2. 合同锁量：提前2—4周签框架协议**
- 与核心供应商签节假日保供协议，明确：锁量区间、到货时间窗、质量标准、缺货违约金、价格调整机制（如随行就市但设上限）。
- 采用“保底量+弹性量”：保底量保证基本盘，弹性量在节前7—10天根据销售再确认，降低误判风险。
- 对易储品类可提前备货入库；对鲜食品类要求供应商承诺“节日期间优先供货”。

**3. 多源备份，避免单一产地/供应商断供**
- 每个核心品类至少2—3个供应商，且产地分散（不同产区、不同批发市场），防止天气或物流单点中断。
- 与本地批发市场、周边合作社保持临时采购通道；节前确认备用供应商的可用量和报价。
- 对进口或远距离水果，提前锁定冷链车和仓位，避免“有货无车”。

**4. 仓配与门店保障**
- 节前检查冷库容量、分拣人力、配送频次；对高周转门店增加配送班次。
- 设置安全库存：易储品类备足节日期间70%—80%的量，鲜食品类保持1—2天周转。
- 门店端提前排班，避免到货后无人收货、上架慢导致损耗。

**5. 建立应急机制**
- 节前一周每日跟踪到货率、库存和销售速度，触发阈值（如某品类库存低于3天销量）立即启动备用供应商。
- 准备替代品类方案：某水果短缺时，用相近价位/口感品类做促销替代，减少缺货影响。
- 明确内部责任人：采购、物流、门店各有一名节假日保供负责人，问题当天闭环。

**判断标准**：如果核心品类锁量覆盖预测销量的80%以上、每个品类有至少2个可用供应商、易储品类安全库存达到70%以上，基本可认为货源风险可控。
