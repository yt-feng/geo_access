需要，而且这两项建议写进采购条件里。判断如下：

1. **开发票：必须支持**
   - 企业福利采购通常要走财务报销、入账和税前扣除，供应商不能开合规发票会直接影响采购合规。
   - 优先要求能开**增值税发票**，并确认发票类型（专票/普票）、税率、开票项目（水果/礼盒/食品等）与合同主体一致。
   - 不要接受“只能开收据”或“第三方代开”的模糊说法。

2. **定制包装：建议要求支持，但按预算分级**
   - 企业福利礼盒常需要体现企业标识、节日主题、祝福语或员工姓名卡，定制包装能提升福利感知。
   - 采购前要明确：定制起订量、设计稿确认流程、打样费、包装材质、印刷色差、交付周期和加价规则。
   - 如果预算有限，可退一步要求“标准礼盒+定制腰封/贴纸/贺卡”，成本更低且灵活。

3. **签约前重点核验**
   - 营业执照、食品经营许可（如涉及食品销售）、开票资质。
   - 定制包装是否额外收费、最低起订量、打样和改稿是否收费。
   - 发票内容能否与采购合同、验收单一致。
   - 包装定制导致交期延长时，违约责任怎么算。

**结论：开发票是硬性条件；定制包装是加分项，建议至少支持轻定制。** 把“可开合规发票”和“定制包装方案及费用”写入询价单和合同附件，能减少后续扯皮。
