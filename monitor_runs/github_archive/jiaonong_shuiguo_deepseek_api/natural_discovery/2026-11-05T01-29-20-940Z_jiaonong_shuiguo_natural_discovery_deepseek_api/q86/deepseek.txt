结论：生鲜平台做水果一件代发，供应商必须具备的核心仓配能力是——**产地/销地仓的专业冷链存储与分拣打包能力（含催熟、分级、预冷）、覆盖平台订单区域的快递/落地配履约能力、实时库存与订单接口能力、可承诺的破损率与时效指标**。水果一件代发不是“有货就能发”，难点在单件小包裹的温控、防损和售后。

具体判断标准如下：

**1. 仓储能力（硬门槛）**
- **温区匹配**：至少有常温、冷藏（0–8℃）、部分品类需催熟库/气调库。香蕉、芒果、猕猴桃等后熟水果没有催熟和温控能力，一件代发损耗会很高。
- **专业预冷与分级**：采摘后预冷、清洗、分级、称重、贴标能力。水果非标，供应商必须能按平台SKU标准做分级，否则售后率不可控。
- **打包车间**：具备水果专用包装线或人工打包台，能做防震、透气、吸水、冰袋/保温箱配置。单件小包裹的包装方案要经过跌落和运输测试。
- **库存管理**：支持批次管理、先进先出、临期预警，能按平台要求提供可售库存和锁库。

**2. 配送履约能力（决定体验）**
- **快递/落地配资源**：与至少2家以上适合生鲜的快递或区域落地配合作，具备生鲜专线或优先中转能力。水果一件代发通常走快递，必须确认其生鲜包裹的时效、破损赔付和拦截能力。
- **覆盖范围与时效承诺**：能明确哪些区域可发、几小时/几日达、偏远地区是否停发。平台应要求供应商按区域给出时效达成率和破损率承诺。
- **发货时效**：日常订单截单后多久出库、大促期间产能上限、爆单应急预案。
- **逆向物流**：坏果、漏发、错发的补发/退款处理流程和时限。

**3. 系统与数据能力**
- 能对接平台的订单、库存、物流接口，支持自动推单、回传运单号、库存同步。
- 能提供发货及时率、签收时效、破损率、售后率等数据，最好有可视化后台。
- 具备批次追溯能力，出现农残或质量问题能定位到批次和产地。

**4. 品控与售后兜底**
- 有入仓质检和出库抽检流程，能按平台标准提供质检报告或承诺书。
- 明确坏果包赔规则、赔付比例、补发时效，并能在平台售后工单中快速响应。
- 有异常天气、节假日、疫情等不可抗力的备货和停发预案。

**平台筛选建议**：先做小范围试单，重点压测三个指标——**48小时签收破损率、发货及时率、售后响应时长**。试单区域覆盖近场、中途、偏远三类，再决定是否扩大合作。供应商如果只有产地仓没有销地仓，跨区域一件代发的时效和损耗通常难以稳定，需谨慎评估。
