建议按“整果为主、切果为辅”做组合，而不是二选一。判断依据主要是客流结构、损耗能力、加工条件和价格带。

**更适合卖整果的情况**
- 社区店、家庭客群为主：整果单价低、耐放，顾客更愿意买回家自己处理。
- 门店没有干净加工间、冷藏陈列或专人切果：切果损耗和食品安全风险高。
- 菠萝到货成熟度偏低：先整果陈列，成熟后再转切果或做促销。
- 走量优先：整果毛利低但损耗可控，适合做引流和堆头。

**更适合卖切果的情况**
- 商圈店、年轻客群、即食需求强：切果客单价高，购买决策快。
- 有冷藏展示柜和规范加工条件：能控制切后 4℃ 冷藏、当日售罄。
- 整果出现成熟度高、外观瑕疵但品质没问题的货：切果能减少整果折价损失。
- 能按小份装、透明盒、标注切果时间售卖：降低顾客对卫生和新鲜的顾虑。

**采购和运营建议**
1. 采购时分开下单：70%—80% 整果，20%—30% 切果原料，按门店历史销量调整。
2. 整果选耐储运、成熟度适中的货；切果原料选成熟度高、当天能消化的货。
3. 切果必须“当日切、当日清”，冷藏陈列，避免隔夜再卖。
4. 用整果做低价引流，用切果做毛利补充；切果盒可搭配小叉子、保鲜膜和清晰日期标签。
5. 先在一两家门店试 2—3 周，记录整果损耗率、切果售罄率、客单价和毛利，再决定比例。

简单判断：**社区家庭客群强、加工条件弱，就整果为主；商圈即食客群强、冷藏加工条件好，就提高切果占比。** 大多数商超更适合整果走量、切果补毛利。
