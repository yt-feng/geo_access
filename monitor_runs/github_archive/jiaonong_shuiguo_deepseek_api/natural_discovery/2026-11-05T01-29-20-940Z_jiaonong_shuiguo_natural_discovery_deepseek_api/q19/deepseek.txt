优先排序：**切果损耗 > 甜度 > 外观 > 大小**。如果只能抓一个指标，先抓**切果损耗**。

理由和可执行判断如下：

1. **切果损耗最关键**
   - 菠萝是毛利容易被“削掉”的品类：去皮、去眼、去头尾、坏心、过熟发酵都会变成损耗。
   - 同样进货价，损耗高5个百分点，可能直接把毛利吃没。
   - 关注：到货成熟度、黑心/水心比例、去皮后出成率、当日切果报损率、切开后变色和出水情况。
   - 建议动作：小批量高频次进货；按成熟度分级；过熟果优先做试吃/现切促销，不要压库。

2. **甜度第二重要**
   - 菠萝复购靠口感，酸涩会直接伤客。
   - 但甜度不能只看“闻着香”，要结合品种、产地、季节和成熟度。
   - 建议动作：到货抽切测糖或试吃；建立“可售甜度底线”；不达标的不做主推，转促销或加工用途。

3. **外观第三**
   - 外观影响购买决策，但不是利润核心。
   - 重点看：果眼深浅、表皮新鲜度、有无软烂/霉斑/裂口、冠芽状态。
   - 外观差但内部好的，适合切果或促销；外观好但过熟的，反而损耗风险高。

4. **大小最后**
   - 大小主要影响客群和定价，不是品质核心。
   - 大果不一定出成率高，小果不一定差；关键看品种和成熟度。
   - 建议按客群分档：家庭装、小果便利装、切果杯原料分开管理。

**一句话结论：**  
超市卖菠萝，先管住切果损耗，再用甜度保复购，外观做陈列，大小做分层。若四项冲突，优先牺牲“大小”，守住“损耗”和“甜度”。
