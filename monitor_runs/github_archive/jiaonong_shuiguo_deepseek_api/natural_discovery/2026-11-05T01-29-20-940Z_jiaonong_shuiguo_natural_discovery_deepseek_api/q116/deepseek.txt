小商家采购水果，现金结算和月结账期的核心风险不同：**现金结算主要风险在资金占用、假币/找零差错和现金保管安全；月结主要风险在供应商信用、账期失控、对账争议和坏账/断供**。水果又易腐、价格波动大、品质争议多，账期风险会被放大。

**一、现金结算的风险**
1. **资金占用与周转压力**：现款现货会占用流动资金，旺季备货时尤其明显。
2. **现金保管与安全风险**：门店现金多，存在被盗、遗失、员工挪用风险。
3. **假币与找零差错**：小额高频交易中容易出现假币、短款、找零错误。
4. **无凭证或凭证弱**：若只给收据、不开发票或不留转账记录，后续质量争议、退货、税务入账都难举证。
5. **采购员舞弊空间**：现金交易若没有称重单、验收单、付款记录三方核对，容易出现虚报价格、吃回扣。
6. **大额现金不便**：超过一定金额的现金支付不符合监管和银行结算习惯，也不利于财务留痕。

**二、月结账期的风险**
1. **供应商信用风险**：账期本质是供应商给你授信。若供应商资金链紧张，可能突然要求现结、减少供货甚至断供；你临时换供应商，水果品质和价格都不稳定。
2. **账期失控与现金流误判**：月结容易让采购觉得“不是花自己的钱”，进货量放大，月底集中付款时现金流紧张。
3. **对账争议**：水果有损耗、退换货、等级差异、价格随行就市，若没有每日验收单、退货单、价格确认单，月底容易扯皮。
4. **品质与账期绑定风险**：供应商可能把账期成本计入单价，或对月结客户给较差批次；你因欠款不好严格拒收。
5. **坏账与法律风险**：若你是采购方，月结主要是应付账款管理风险；若你同时给小客户赊销，则要防应收账款坏账。合同不清晰时，容易产生违约金、停供纠纷。
6. **依赖单一供应商**：长期月结容易形成依赖，议价能力下降，断供时替代成本高。

**三、给水果小商家的可执行建议**
- **现金采购**：尽量改用“微信/支付宝/银行转账+备注”，保留称重单、验收单、付款截图；现金只留少量备用金，每日盘点。
- **月结采购**：签简单书面协议，写明账期天数、对账日、付款日、价格确认方式、退换货规则、逾期责任；每天或每批验收签字，月底对账单双方确认。
- **混合策略**：畅销、易腐、品质波动大的品类可现结换低价和好货；稳定大宗品类可谈短账期（如7—15天），不要一上来就月结。
- **设信用上限**：月结供应商控制在2—3家，单家应付账款设上限，避免集中到期。
- **留替代供应商**：至少保持一家可现结的备选货源，防止月结供应商断供。

一句话：**现金结算防“钱和凭证”，月结防“账和供应”**；水果生意最好用“短账期+每日验收+转账留痕”折中，而不是纯现金或纯月结。
