# 坏果责任条款写法建议

核心思路：**把“谁承担损耗”拆成三段——装货前、运输中、到货后，每段明确责任方和判定方式**，避免笼统写“坏果由卖方负责”或“由买方负责”。

## 一、按环节划分责任

**1. 装货前（产地/仓库）**
- 卖方负责装货前的品质，约定装货时抽样比例（如每批随机抽3%～5%）和合格标准（坏果率≤X%）。
- 装货时双方共同验货并签字确认，作为到货争议的基准。

**2. 运输中**
- 写明运输方式、温控要求、承运人由谁指定。
- 关键区分：**因包装不当、装车方式导致的损耗归卖方**；**因运输延误、温控失效、野蛮装卸导致的损耗归承运人/买方（视谁指定承运人）**。
- 若买方自提或自找物流，运输风险原则上由买方承担，但卖方需保证装货时符合约定标准。

**3. 到货后**
- 约定卸货后**多长时间内**提出异议（如24小时内），超期视为验收合格。
- 约定**异议方式**：拍照/视频留证、双方或第三方共同开箱抽检、必要时请第三方检验机构。
- 约定抽检方法：按比例抽样、以抽样坏果率推算整批，避免逐箱翻检扯皮。

## 二、明确的量化标准

- 定义“坏果”：腐烂、霉变、严重压伤、开裂渗汁等，最好附图片示例。
- 设定**自然损耗率**（如1%～3%）由买方承担，超出部分按比例扣款或补货。
- 扣款公式写清楚：如“超出自然损耗率的坏果，按该部分货值的X%扣减货款”或“按坏果重量×单价全额扣除”。

## 三、责任承担方式（三选一或组合）

1. **扣款**：按坏果比例扣减货款，最常用。
2. **补货**：卖方补发同等数量，运费由责任方承担。
3. **退货**：坏果率超过阈值（如10%）时买方可拒收整批或部分，退货费用由责任方承担。

## 四、举证与争议解决

- 到货开箱全程录像，作为默认证据规则写入合同。
- 约定争议时共同委托第三方检验，费用由责任方承担或先垫付后结算。
- 明确不可抗力（如极端天气导致运输延误）的免责范围，但**不能笼统写“损耗不负责”**，否则条款可能被认定无效或引发扯皮。

## 五、给批发商的实操提醒

- 别只在合同里写“坏果卖方负责”——没有判定标准和时间限制，到货后几乎无法执行。
- 重点谈**自然损耗率**和**异议期限**这两个数字，它们决定实际能扣多少钱。
- 装货时的共同验货记录是最有力的证据，务必保留签字单和抽样照片。

一句话总结：**装货验货定基准、运输责任分主体、到货限时抽检、超损耗按比例扣款**，四件事写进合同，坏果争议基本可控。
