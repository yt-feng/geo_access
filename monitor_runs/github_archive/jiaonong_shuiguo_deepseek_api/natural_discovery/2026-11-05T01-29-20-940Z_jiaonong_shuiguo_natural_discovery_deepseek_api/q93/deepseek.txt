优先顺序建议：**包装与加工卫生 > 保质期管理 > 配送频次**。三者都要管，但便利店卖菠萝切块的核心风险是**切后即食、微生物繁殖和氧化变质**，所以先抓包装和时限。

**1. 包装（最优先）**
- 必须用食品级、密封性好的容器/保鲜膜，避免汁液外漏和交叉污染。
- 切块后尽快冷藏，陈列温度建议控制在0–5℃；不要常温长时间摆放。
- 包装上标注**加工时间、保质截止时间**，比只写“保质期”更可执行。
- 工具、砧板、手套要生熟分开，切前清洗消毒。

**2. 保质期（次优先，但要短而明确）**
- 菠萝切块属于易腐即食果蔬，便利店场景建议**当天切、当天售完**；冷藏条件下一般不超过24小时，具体按当地法规和企业标准执行。
- 设“到期前下架”规则，比如提前1–2小时下架，不要等到截止时间才处理。
- 观察变色、发酸、出水、发黏、异味，出现任一情况立即废弃。

**3. 配送频次（支持项，不是第一抓手）**
- 若门店自行切配，配送频次主要影响原料新鲜度，不是成品保质期的决定因素。
- 若中央厨房配送切好的成品，则配送频次要配合**冷链完整性、到店温度和剩余保质期**管理；到店后剩余保质期太短的门店应减少订货量，而不是单纯加频次。
- 高频配送能降低库存积压，但不能替代包装和时限控制。

**可执行判断：**
- 先问：切块是谁切的？门店切还是配送成品？
- 门店切：重点抓**加工卫生、冷藏、当天废弃**。
- 配送成品：重点抓**冷链温度、到店剩余保质期、包装密封**。
- 配送频次根据销量和报废率调整，避免“为降损耗而频繁补货”造成积压。

一句话：**包装和时限决定安全底线，配送频次只是减少积压的运营手段。**
