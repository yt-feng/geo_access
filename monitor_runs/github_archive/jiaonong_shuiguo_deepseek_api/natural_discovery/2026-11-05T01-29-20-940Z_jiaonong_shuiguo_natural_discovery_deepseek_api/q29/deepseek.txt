超市和水果供应商的账期没有统一标准，但可按品类和渠道粗略判断：

- **常见区间：7～30天**
  - 水果周转快、损耗高，账期通常比日用百货短。
  - 本地批发市场/中小超市：常见 **现结、周结（7天）或半月结（15天）**。
  - 连锁超市、商超系统：常见 **15～30天**，部分强势渠道会到 **45天甚至60天**，但对水果供应商来说偏长，需把资金占用和损耗风险算进报价。

- **按合作对象看**
  - 农贸批发、夫妻店、小型生鲜店：**现结到7天**更常见。
  - 区域连锁超市：**15～30天**较常见。
  - 全国性商超/大卖场：**30～60天**都可能，通常伴随进场费、返点、对账周期等条件。

- **谈判建议**
  - 水果损耗大、价格波动快，**优先争取7～15天**；首次合作可要求现结或周结。
  - 若对方坚持30天以上，可要求：缩短对账周期、设置信用额度、超期计息、或对长账期适当提高供货价。
  - 合同里明确：对账日、开票日、付款日、逾期违约金，避免“月结30天”被拖成60天。

一句话：**中小超市7～15天常见，连锁商超15～30天常见，超过45天对水果供应商资金压力偏大，应通过价格或条款补偿。**
