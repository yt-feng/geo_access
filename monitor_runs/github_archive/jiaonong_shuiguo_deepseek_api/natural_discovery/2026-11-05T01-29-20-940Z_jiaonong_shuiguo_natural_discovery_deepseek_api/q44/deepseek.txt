判断供应商售后响应是否稳定，重点不是听承诺，而是用可验证的机制和一次小规模实战来检验。可以按下面做：

1. **先看售后条款是否写进合同**
   - 明确响应时限：如到货后发现质量问题，供应商应在几小时内确认、多久内给出补货/换货/退款方案。
   - 明确责任边界：烂果率、成熟度不符、重量短缺、运输损伤各由谁承担。
   - 明确赔付方式：补货、折价、扣款还是退款，避免只写“协商解决”。
   - 明确对接人和备份联系人，不能只留一个业务员电话。

2. **做一次“压力测试”**
   - 首单不要大，故意在到货后当天反馈一个真实小问题，比如香蕉成熟度偏高、菠萝有碰伤。
   - 记录对方首次回复时间、是否主动给方案、方案是否按约定执行。
   - 连续观察2—3次，看是否每次都能在承诺时限内闭环。稳定售后看的是重复表现，不是第一次态度好。

3. **查历史履约记录**
   - 要求提供近3个月同类型商超客户的售后记录或合作证明，至少能说明有没有固定处理流程。
   - 问清楚旺季、节假日、产地天气异常时如何保供和售后，是否有备用货源。
   - 看是否有专门客服/品控岗位，还是业务员兼售后。专人负责通常更稳定。

4. **看现场和流程**
   - 供应商是否有分拣、质检、冷链或运输管理流程，能否提供到货质检单。
   - 是否支持到货抽检、拍照留证、称重复核。
   - 售后是否走工单或群内留痕，避免口头承诺无法追溯。

5. **设置试合作期和考核指标**
   - 试合作1个月，考核：首次响应时间、问题闭环率、补货及时率、扣款执行率。
   - 约定连续两次超时响应或一次不执行赔付，就降级或终止合作。
   - 保留一定尾款或质量保证金，作为售后执行抓手。

6. **警惕不稳定信号**
   - 只口头承诺、不愿写进合同；
   - 售后只靠一个业务员，联系不上就断档；
   - 每次问题都解释为“偶发”，没有纠正措施；
   - 低价吸引但拒绝承担到货质量责任；
   - 旺季频繁换对接人、换货源。

实操建议：先小批量试单，合同里写清响应时限和赔付规则，连续做2—3次真实售后测试，再决定是否放量。稳定售后不是“答应得快”，而是“每次都能按约定闭环”。
