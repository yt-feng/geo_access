大型超市对水果供应商的要求，通常会分成“食品安全合规能力”和“物流交付能力”两条线，且很多指标是准入门槛，不是加分项。下面按可核查、可执行的维度列。

## 一、食品安全能力

1. **主体资质与许可**
   - 营业执照、食品经营许可证/食品生产许可证（按实际业态）。
   - 种植/加工环节涉及食品生产的，需相应许可；仅销售初级农产品的按当地监管要求执行。
   - 进口水果需有海关报关、检验检疫相关凭证。

2. **质量安全管理体系**
   - 建议具备ISO 22000、HACCP或等效体系；大型商超通常要求提供体系证书或审核报告。
   - 有食品安全管理制度、岗位责任、培训记录、投诉与召回流程。

3. **农残与污染物控制**
   - 有农残检测能力或委托第三方检测协议，能按批次提供检测报告。
   - 能执行超市要求的农残限量标准，并保留检测记录。
   - 对重金属、霉菌毒素等按品类风险进行监控。

4. **溯源能力**
   - 能做到批次级追溯：产地/基地、采收日期、加工包装日期、检测记录、发货记录可关联。
   - 出现问题时能快速定位同批次并召回。

5. **供应商与基地管理**
   - 对种植基地、合作社、加工厂有准入审核和年度评估。
   - 有农业投入品（农药、化肥）使用管理，避免禁限用农药。

6. **加工与仓储卫生**
   - 分选、包装场所符合卫生要求，有防虫防鼠、清洁消毒、人员卫生管理。
   - 冷链仓储温湿度监控和记录。

7. **合规文件与审核配合**
   - 能提供检测报告、合格证明、产地证明、包装标签合规文件。
   - 能接受超市或第三方现场审核，并对不符合项整改。

## 二、物流与交付能力

1. **冷链能力**
   - 具备预冷、冷藏/保鲜仓储和冷链运输能力，能按品类控制温湿度。
   - 运输车辆有温控设备和温度记录，能提供在途温度数据。

2. **仓储与分拣**
   - 有与超市供货量匹配的仓储、分选、包装能力。
   - 能按超市标准做分级、称重、贴标、装箱，减少门店损耗。

3. **配送时效与网络**
   - 能覆盖超市门店或DC的配送半径，按约定频次（日配/隔日配）送达。
   - 有应急补货和旺季保供方案。

4. **订单与信息协同**
   - 能对接超市订单系统，处理订单、发货、对账。
   - 有库存和批次数据，能配合超市做追溯和缺货预警。

5. **损耗与质量管理**
   - 有到货合格率、损耗率控制指标和异常处理机制。
   - 对破损、变质、短少能按合同退换货。

6. **包装与搬运**
   - 包装符合超市陈列和运输要求，标识清楚。
   - 装卸过程有防挤压、防日晒雨淋措施。

7. **应急与召回物流**
   - 出现食品安全预警时，能配合下架、召回和逆向物流。
   - 有异常批次隔离和处置记录。

## 三、超市通常会重点核验的材料

- 营业执照、相关许可证
- 体系证书或审核报告
- 批次检测报告/第三方检测协议
- 产地证明、进口报关检疫文件（如适用）
- 冷链设备清单、温度记录样表
- 追溯流程说明和召回预案
- 配送车辆清单、仓储照片/审核记录
- 供货能力说明和应急保供方案

## 四、可判断的准入建议

供应商若想进入大型超市，至少要同时满足：
1. **资质齐全且可追溯**；
2. **按批次能出检测报告**；
3. **有冷链仓储和运输，并能提供温度记录**；
4. **能按超市标准分级包装并稳定配送**；
5. **有召回和异常处理机制**。

如果其中“批次检测”“冷链温度记录”“批次追溯”三项缺失，通常很难通过大型超市的供应商审核。具体阈值（如检测频次、温控区间、到货合格率）应以目标超市的供应商准入标准和采购合同为准。
