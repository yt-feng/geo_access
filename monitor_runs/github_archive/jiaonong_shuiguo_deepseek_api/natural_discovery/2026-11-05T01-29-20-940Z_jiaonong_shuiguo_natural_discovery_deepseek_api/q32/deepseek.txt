判断香蕉供应商能否全年稳定供货，不能只听“我们全年都有货”，要分三层核验：**货源基础、供应计划、履约与风险控制**。建议按下面做。

## 1. 先核“货源基础”：有没有全年货源能力
香蕉是跨产区作物，单一产区很难全年稳定。重点问清：

- **产区布局**：是否同时有国产主产区（如云南、广西、海南、广东、福建等）和进口来源（如菲律宾、越南、厄瓜多尔、柬埔寨等）？不同产区上市期能否衔接？
- **自有/合作基地**：是自有基地、长期合作基地，还是市场临时调货？临时调货型供应商旺季可以，淡季和极端天气时容易断。
- **加工与仓储**：是否有催熟库、冷库、分拣包装能力？催熟库容量和日处理能力能否覆盖你的日常销量和促销峰值？
- **进口资质与渠道**：做进口香蕉的，是否有稳定报关、检验检疫、港口冷链合作方？进口周期和到港波动如何应对？

**可判断信号**：能拿出分产区、分月份的供应计划表，而不是只给一张总报价单。

## 2. 再核“供应计划”：全年每月能不能对上你的需求
要求供应商提供**12个月供应计划**，至少包含：

- 每月可供品种、规格、预估可供量；
- 各产区/进口来源的切换月份；
- 淡旺季和节假日（春节、中秋、国庆等）保供方案；
- 你的门店日常销量、促销峰值、安全库存对应的供货安排。

然后做交叉验证：

- 把它的月度可供量与你的**月度需求+安全库存**对比，看是否有缺口月份；
- 问清缺口月份从哪里补、补货成本谁承担；
- 要求提供过去12个月的实际供货记录或合作客户案例，重点看**断供次数、缺货时长、质量投诉**。

## 3. 看“履约与风险控制”：能不能持续做到
全年稳定供货的核心是抗风险能力。重点核：

- **天气与病害预案**：寒潮、台风、干旱、香蕉枯萎病等发生时，如何切换产区、提前备货？
- **物流冷链**：运输方式、在途时间、温控记录、到货损耗率承诺；旺季运力是否有备用车队或港口合作方？
- **质量稳定性**：不同产区切换时，成熟度、果指规格、色泽、口感能否保持一致？有无验收标准和退换货机制？
- **库存与补货机制**：是否为你设安全库存？补货响应时间多长？紧急订单最小起订量和加价规则？
- **合同约束**：建议在合同中约定月度最低供货量、断供违约责任、价格调整机制、质量不达标处理方式，避免“口头全年保供”。

## 4. 最有效的验证方式：小步试单+压力测试
不要一次签全年大单，建议：

1. **先试单2—3个月**，覆盖一个淡季或产区切换期；
2. **做压力测试**：临时增加20%—30%订单，看响应速度和到货质量；
3. **查历史履约**：要求提供近12个月供货台账，或向其现有超市客户侧面了解断供情况；
4. **现场看库**：实地看催熟库、冷库、分拣线，确认产能不是临时租用；
5. **合同锁定**：把月度保供量、断供赔偿、替代产区方案写进合同。

## 简单判断标准
如果供应商能做到：**多产区/进口来源衔接 + 12个月供应计划 + 自有或长期合作基地 + 催熟冷链能力 + 可核验的历史履约记录 + 合同保供条款**，基本可判断具备全年稳定供货能力。  
如果只有报价低、口头承诺全年有货、靠批发市场临时调货、无催熟库或冷库、不愿提供月度计划和履约记录，则全年稳定供货风险较高，不建议作为主供应商。
