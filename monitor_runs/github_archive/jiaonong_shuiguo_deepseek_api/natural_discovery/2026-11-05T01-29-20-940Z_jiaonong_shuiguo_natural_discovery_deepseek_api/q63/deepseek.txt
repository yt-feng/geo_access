判断哪个规格更容易出货，不能只看“哪个便宜”或“哪个大”，关键看**下游客户结构 + 走货速度 + 损耗 + 毛利**。给你一套可直接落地的判断方法：

## 1. 先按下游渠道分规格需求
菠萝常见分档（按单果重）：小果（约0.8–1.2斤）、中果（1.2–1.8斤）、大果（1.8–2.5斤以上）。不同渠道偏好不同：

- **水果店/社区团购**：偏好中果，大小均匀、卖相好、单价适中，最容易走量。
- **商超**：偏好中大果，要求外观整齐、成熟度可控。
- **餐饮/果汁店/加工**：偏好大果或统货，看重出肉率和单价，不太看卖相。
- **路边摊/集市**：小中果好卖，单价低、周转快。
- **电商/直播**：中果最稳，大果易破损、小果易被嫌小。

**结论：如果你的客户主要是水果店和社区团购，中果通常最容易出货；如果做餐饮加工，大果/统货更快。**

## 2. 用四个指标做“出货难易”打分
对每个规格记录一周数据，算四个数：

1. **日均出货量**：卖得最多不代表最好卖，要看出货速度。
2. **库存周转天数** = 当前库存 ÷ 日均出货量。周转天数越短越容易出货。
3. **损耗率** = 坏果/次果重量 ÷ 进货重量。菠萝易烂、易碰伤，大果损耗往往更高。
4. **单件毛利** = 售价 − 进价 − 损耗分摊 − 运费/人工。

**判断规则：**
- 周转天数短 + 损耗低 + 毛利为正 → 优先主推。
- 出货量大但损耗高、毛利薄 → 是“流量规格”，可搭配销售，不宜压太多库存。
- 出货慢但毛利高 → 小批量留给特定客户，不要大面积铺货。

## 3. 做一次小规模对比测试
不要凭感觉压货。选3–5个核心客户，每个规格各放少量，连续7天记录：
- 哪个规格最先卖完；
- 客户复购哪个规格；
- 哪个规格退货/投诉最多；
- 哪个规格剩货最多。

**最容易出货的规格 = 最先卖完 + 复购最多 + 投诉最少 + 剩货最少。**

## 4. 看季节和成熟度
- 气温高时菠萝熟得快，**中大果损耗上升**，中果和小果周转更安全。
- 节假日礼盒需求上升，**中大果、均匀果**更好卖。
- 夏季果汁/餐饮需求上升，**大果和统货**出货更快。

## 5. 实操建议
- **主推规格不要超过2个**，否则库存分散、周转变慢。
- 中果作为“基本盘”保周转，大果做餐饮/商超定向供货，小果做低价引流。
- 每周复盘一次周转天数和损耗率，连续两周周转慢的规格立即减量。
- 对批发商来说，**“容易出货”不等于“最赚钱”**，最终看“周转 × 毛利 − 损耗”。

**一句话判断：在你现有客户群里，周转天数最短、损耗最低、复购最稳的那个规格，就是最容易出货的规格。** 先用7天小批量测试验证，再决定主推和备货比例。
