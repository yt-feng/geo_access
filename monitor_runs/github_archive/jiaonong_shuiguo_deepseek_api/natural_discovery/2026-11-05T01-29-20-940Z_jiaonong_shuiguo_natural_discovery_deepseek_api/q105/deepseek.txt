水果锁价一般分三层来看，能锁多久取决于品类、产地、季节和供应商类型：

1. **常规鲜果（苹果、梨、柑橘、香蕉等耐储品类）**
   - 和一级批发商/产地合作社锁价，常见 **7～15天**；量大、长期合作的可以谈到 **1个月**。
   - 超过1个月通常要配合预付款或保证金，且供应商会要求“随行就市、超出区间重议”。

2. **时令/易腐水果（草莓、荔枝、樱桃、水蜜桃等）**
   - 基本只能锁 **3～7天**，甚至按批次单批锁价。
   - 这类品类价格波动大、损耗高，供应商很少愿意承担长周期风险。

3. **进口水果**
   - 受汇率、海运费、到港价影响，通常 **按柜/按批锁价**，周期约 **1～2周**；长期协议多是“公式定价+浮动条款”，而不是固定死价。

**实操建议：**
- 锁价合同里务必写清：锁价品类、规格等级、数量、交货期、**价格调整触发条件**（如产地价涨跌超5%～10%可重议）、违约金和品质不达标处理。
- 想要更稳，可用“**部分锁价+部分随行**”：比如60%数量锁1个月，40%按周议价，降低供应商拒签概率。
- 锁价的同时锁**质量标准**，否则供应商可能用降级货保利润。

一句话：**耐储果常见锁2周～1个月，时令果3～7天，进口果按批1～2周；超过1个月基本要靠预付款或浮动条款。**
