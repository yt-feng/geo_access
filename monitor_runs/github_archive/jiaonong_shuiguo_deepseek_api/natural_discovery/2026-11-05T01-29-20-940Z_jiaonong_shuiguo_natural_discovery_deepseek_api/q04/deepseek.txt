核心思路：香蕉是呼吸跃变型水果，采购要按“到货后几天能卖完”倒推熟度和到货节奏，而不是统一要最熟的。

**一、采购时按销售节奏要求熟度**

建议把香蕉分档采购，不要只进一个熟度：

- **当天/次日主推货：** 要求到货时“青黄转色、果指饱满、棱角略圆但未软”，即约7成熟偏下，能撑2—3天货架期。不要要“全黄带糖斑”的，除非当天就能走量。
- **2—3天后卖：** 要求5—6成熟，青黄、果身硬，可自然转熟。
- **促销/快消档：** 可少量要8成熟黄蕉，但必须当天消化，不参与常规陈列。

采购合同或订单里最好写清楚可验收的熟度标准，例如：
- 果皮绿色占比、转黄程度；
- 果指硬度（轻按不塌）；
- 有无黑斑、裂口、水烂；
- 果柄是否新鲜、有无霉变。

**二、到货时间要“少量多次”**

- 要求**每周2—3次小批量到货**，而不是一次大批量，尤其夏季和潮湿季节。
- 到货尽量安排在**销售高峰前半天到一天**，给分拣和催熟/控熟留出时间。
- 明确到货时段，避免下午晚到、整批压库过夜。
- 要求供应商按你给的“分档熟度”分箱到货，箱外标注熟度档和到货日期，方便先进先出。

**三、和供应商约定可执行的条件**

采购时可直接提这些要求：
1. 按销售计划分档供货：5—6成熟、7成熟各占比例，黄蕉少量。
2. 每次到货附熟度说明和采摘/发货时间。
3. 到货验收：青蕉硬挺、无大面积黑斑、无裂果、果柄不发黑霉变；不符合的拒收或折价。
4. 夏季缩短到货间隔，冬季可适当放宽；雨天、高温天要求更青一点。
5. 不要用“越熟越好”作为统一标准，熟度必须跟你的销量和陈列周期匹配。

**四、店里配合的简单做法**

- 香蕉到货后**不要整箱闷着**，开箱通风，青蕉和熟蕉分开放。
- 熟蕉放阴凉通风处，避免冷柜低温冻伤。
- 每天按“先熟先卖”翻检，轻微糖斑的及时做促销或加工。
- 记录每次到货熟度、到货日和损耗，下一轮采购再调档。

一句话：采购时要求“**分批熟度、少量多次、到货前半天、验收有标准**”，比单纯要求“晚点到、青一点”更能减少放坏。
