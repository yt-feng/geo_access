做小区团购，水果供应商至少要能支持以下几类服务，选供应商时可按清单逐项确认：

1. **小批量、多频次配送**
   - 能否每天或隔天送，一次几十斤到几百斤也送。
   - 能否送到店/自提点，而不是只到批发市场。
   - 配送时间是否固定，临时补货能否当天响应。

2. **分级与品控**
   - 能否按团购价提供稳定等级，比如“家庭装/普通果/精品果”分开报价。
   - 是否支持到货验收、坏果拍照赔付。
   - 次果率、损耗率能否写入合作约定。

3. **售后与损耗兜底**
   - 坏果、烂果、重量不足怎么赔：按比例赔、补发还是退款。
   - 售后响应时限，比如24小时内处理。
   - 生鲜损耗谁承担，是否有首单或固定比例兜底。

4. **灵活结算与账期**
   - 支持现结、周结还是月结；小水果店通常更适合短期账期或押金制。
   - 能否提供每日/每批报价，价格随行就市但提前通知。
   - 是否支持退换货冲抵货款。

5. **包装与分装支持**
   - 能否按团购套餐分装，比如5斤装、家庭箱。
   - 是否提供统一包装箱/袋、标签、产地或品种标识。
   - 分装费、包装费是否另收。

6. **选品与上新支持**
   - 能否按小区消费水平推荐爆品、引流品和利润品。
   - 是否提供当季主推、特价清仓、试吃样品。
   - 能否小批量试销，卖得好再补货。

7. **价格保护与区域保护**
   - 同一小区附近是否还供货给其他团购点，避免恶性比价。
   - 团购价是否低于周边零售价，能否给阶段性特价。
   - 价格调整是否提前通知。

8. **配送与自提配套**
   - 能否配合定时送到小区自提点。
   - 是否支持冷链或保温配送，尤其夏季和易损水果。
   - 缺货、延迟到货时能否提前沟通并替换品种。

9. **资质与票据**
   - 营业执照、食品经营/流通相关资质是否齐全。
   - 能否提供进货凭证、检测报告或产地证明。
   - 能否开票，至少能提供收据和批次信息。

10. **试合作机制**
   - 先小批量试单1—2周，看损耗、准时率、售后。
   - 明确首单最小起订量、退换规则、违约处理。
   - 最好有两家备选供应商，避免单一依赖。

**最需要写进合作约定的4项：** 配送频次与时效、坏果赔付标准、价格调整通知、区域/价格保护。小水果店做团购，供应商的“稳定供货+售后兜底”比单纯低价更重要。
