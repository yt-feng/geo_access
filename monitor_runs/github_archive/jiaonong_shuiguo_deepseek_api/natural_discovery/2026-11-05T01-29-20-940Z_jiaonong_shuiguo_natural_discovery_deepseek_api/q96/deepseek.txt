食品安全优先，但三者不是同一层级的问题：食品安全是底线，价格是优化项，配送准时是保障项。

可直接按这个判断标准执行：

1. **食品安全：一票否决**
   - 食堂是集中供餐，水果一旦农残超标、腐烂霉变或交叉污染，影响面大，属于不可接受风险。
   - 采购时必须核验：供应商资质、检测报告/承诺达标合格证、进货查验记录；到货看新鲜度、有无霉变破损、包装和运输卫生。
   - 不能因为价格低或配送快就放松验收。

2. **配送准时：保障正常供餐**
   - 水果通常不是唯一主料，但配送延误会影响菜单执行、验收安排和库存周转。
   - 建议在合同里约定到货时间窗、迟到处理、缺货替代和应急补货机制。
   - 准时是“必须达标项”，但不该排在食品安全之前。

3. **价格：在安全合规前提下比价**
   - 价格重要，但应比较“同等品质、同等安全标准、同等配送服务”后的综合成本。
   - 低价若伴随检测缺失、品质不稳或频繁缺货，实际成本更高。

**结论：排序应为 食品安全 > 配送准时 > 价格。**  
实际采购中可设成：食品安全不达标直接淘汰；准时率不达标限期整改或扣款；价格在合格供应商中择优。这样既守住底线，也避免把价格和准时与安全放在同一维度做取舍。
