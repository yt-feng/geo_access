判断“合理波动”的核心不是猜行情，而是把**价格变化拆成可验证的几个来源**，再设规则。给你一套采购方可直接落地的判断框架：

## 1. 先看波动是否“有归因”
每天报价变化，采购方至少要供应商给出一个明确归因，常见合理来源：
- **产地收购价变化**（天气、霜冻、降雨、上市量）
- **等级/规格变化**（果径、糖度、净重、包装、损耗率）
- **运费与油价/冷链成本**
- **季节性换茬**（尾季→新季，价格跳变正常）
- **汇率/进口到港节奏**（进口果）

**判断方法**：要求报价附带“与昨日相比的变化原因+幅度”。如果供应商说不出原因、或原因每天都在变且无法对应到货品，就是可疑波动。

## 2. 用“多源交叉”代替单点信任
不要只听一家：
- 同日向 **2–3 家同等级供应商** 询价，看离散度；
- 参考**批发市场当日均价**（如当地大型农批市场公示价）；
- 参考**同类替代品**价格走势（如不同品种柑橘之间的替代关系）。

**经验规则**：同一规格、同一产地、同一天，多家报价的**中位数±5%~10%** 通常可视为正常市场区间；单家报价长期偏离中位数 15% 以上，要么规格不同，要么报价不实。

## 3. 建立“波动阈值”规则
按品类设定日波动容忍度，而不是一律接受：
- 叶菜、浆果等易腐品：日波动 **±10%~15%** 可接受；
- 苹果、柑橘、根茎类等耐储品：日波动 **±3%~5%** 才合理；
- 超过阈值的，要求供应商**书面说明+次日复核**，连续 3 天异常波动则启动比价或换供应商。

## 4. 看“趋势”而非“单日”
单日跳价可能是噪音。采购方应记录**7 日/30 日移动均价**：
- 价格围绕趋势线小幅波动 → 正常；
- 单日大幅跳涨后不回落、且多家同步 → 可能是真实行情；
- 只有一家跳、且次日又回落 → 多为报价试探或凑整。

## 5. 用合同把“波动”变成可管理项
- 约定**报价有效期**（如当日有效、次日重报）；
- 约定**调价需提前通知**及归因材料；
- 对大宗品类采用**周均价/月均价结算**，减少日频博弈；
- 设置**价格复核条款**：偏离市场均价超过约定比例时，采购方有权要求重新议价。

## 6. 一个简单的实操判断表
| 信号 | 合理波动 | 需警惕 |
|---|---|---|
| 归因 | 能对应天气/产地/规格 | 无原因或原因含糊 |
| 多源 | 多家报价接近 | 仅一家异常 |
| 趋势 | 围绕周均价波动 | 单日跳涨不回落或反复试探 |
| 规格 | 等级净重一致 | 借“规格变了”变相涨价 |
| 频率 | 随行情变化 | 每天固定小幅上调 |

**一句话结论**：合理波动 = **可归因 + 多源可验证 + 在品类阈值内 + 与趋势一致**。采购方不必预测行情，但必须要求供应商把“为什么变”说清楚，并用多源比价和阈值规则把异常波动筛出来。
