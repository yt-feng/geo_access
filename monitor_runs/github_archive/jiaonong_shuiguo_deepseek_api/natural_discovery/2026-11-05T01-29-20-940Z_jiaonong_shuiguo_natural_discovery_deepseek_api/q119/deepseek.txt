做水果长期生意，选供应商时最容易忽视的，往往不是“价格高不高”，而是那些**会反复造成损耗、断供和售后扯皮**的细节。重点看这几类：

1. **只看大货样，不看连续到货稳定性**
   一次样品好不代表长期稳定。要连续看3—5批货的规格、熟度、糖酸度、大小均匀度。水果是生物产品，批次波动比工业品大得多。

2. **忽视“产地—分级—包装”是否真控在自己手里**
   很多供应商其实是倒手商，货不是自己分级包装。要问清：谁分级、谁打冷、谁包装、异常谁承担。否则出了问题容易层层推责。

3. **不核验冷库和冷链过程**
   不只是问“有没有冷库”，要看预冷是否及时、库温记录、装车温度、运输时长。尤其浆果、荔枝、樱桃、叶菜类，断链一两次就会明显缩短货架期。

4. **不明确“验收标准”和“责任边界”**
   最容易扯皮的是：到货损耗算谁的、几小时内反馈有效、照片视频怎么留证、次果怎么扣重、严重不合格是否拒收或补发。合作前要写成简单可执行的验收规则。

5. **忽视包装耗材和装箱规范**
   箱规是否统一、内衬是否合适、是否过度挤压、标签是否清楚、托盘是否规范，都会影响终端售卖和损耗。包装差会把你自己的毛利吃掉。

6. **只看报价，不算“到店可售成本”**
   要把运费、损耗率、次果率、退货率、账期资金成本一起算。便宜但损耗高的货，实际成本可能更贵。

7. **不查供应商的“高峰供货能力”**
   平时能供不等于节假日、雨季、产区受灾时还能供。要问清备货来源、替代产区、旺季保供方案和临时涨价规则。

8. **忽视财务和合同细节**
   账期、结算方式、涨价通知期、质量保证金、违约处理、发票资质都要提前明确。长期合作最怕口头承诺多、书面规则少。

9. **不做过往客户回访**
   不要只听供应商自述。找2—3个同类客户问：断货频率、质量问题处理速度、是否临时改价、售后是否痛快。

10. **忽视供应商的“问题处理态度”**
    长期稳定合作，关键不是永远不出问题，而是出问题时是否快速认责、补货、扣款或共同承担。推责型供应商再便宜也不适合长期做。

实操建议：先小批量连续合作3—4周，记录每批到货合格率、损耗率、断供次数、售后响应时间；同时保留至少一个备用供应商。选供应商时，把“稳定性、可追溯、责任清晰、异常处理快”放在价格前面。
