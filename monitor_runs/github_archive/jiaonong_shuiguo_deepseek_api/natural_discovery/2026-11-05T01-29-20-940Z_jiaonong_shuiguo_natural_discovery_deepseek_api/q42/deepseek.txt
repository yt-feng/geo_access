商超水果采购压价又不影响品质，关键不是“把价砍下去”，而是“把价格谈在合理区间内，同时把品质风险写进合同、落到验收”。可执行做法如下：

**一、先算清成本结构，别空口砍价**
- 把供应商报价拆成：产地收购价、包装、损耗、冷链运输、进场费、账期资金成本。
- 用“到货净成本”比较，而不是只看单价：单价低但损耗高、规格缩水，实际更贵。
- 明确你的目标：是降单价、降损耗、延长账期，还是让供应商承担部分促销费用。分开谈，比一揽子压价更容易保住品质。

**二、用“分级定价+品质对赌”替代一刀切压价**
- 按等级谈价：一级果、二级果分开报价，商超主推一级果走量，二级果做促销或加工，避免用统货压价导致好果混差果。
- 设品质对赌条款：约定糖度、单果重、着色度、腐烂率、机械伤率等可量化指标；达标按约定价，不达标按比例扣款或退货。
- 价格与验收挂钩：到货抽检不合格，供应商承担退换货和损耗，采购不因压价而放松验收。

**三、用量和稳定性换价格，而不是用品质换价格**
- 给供应商可预期的采购量或年度框架，换阶梯价；但阶梯价对应明确的品质标准。
- 承诺“稳定走量+按时结算”，换账期或运费让步；比单纯压单价更可持续。
- 集中品类、减少供应商数量，用单品规模换议价空间，同时保留备选供应商防止被拿捏。

**四、谈价时把品质风险转成供应商责任**
- 合同写明：规格、等级、产地、采收期、包装标准、冷链要求、验收标准、不合格处理方式。
- 约定“到货损耗率上限”，超出部分由供应商承担；促销临时增量也要提前锁价锁质。
- 账期、返利、促销费用单独谈，不要用“降价”解决所有成本问题。

**五、采购执行上的止损线**
- 设定品质底线价：低于该价格且供应商无法说明成本来源的，直接放弃，防止以次充好。
- 新供应商先小批量试单，再谈大合同；老供应商压价后加密抽检频次。
- 比价时至少两家同规格报价，避免被“低价钓鱼”后换货。

一句话：**谈价谈的是“标准内的价格”，不是“价格决定标准”。** 先定品质验收标准，再谈阶梯价、账期和损耗责任，压价才不会变成降质。
