# 核实水果供应商“全国配送”实际覆盖能力的建议

“全国配送”这个说法弹性很大，关键要拆成**能否发货、能否保鲜、时效多久、成本多少、异常谁负责**五个维度来核实。建议按以下步骤做：

## 一、先要书面覆盖清单，不要只听口头承诺
要求供应商提供：
- **可配送省份/城市明细**，明确哪些是“直达”、哪些是“中转”、哪些“不发货”；
- **各区域对应的物流方式**（自有冷链、第三方冷链、普通快递、落地配）；
- **时效承诺**（如省会城市24–48小时，偏远地区3–5天）；
- **起送量和运费规则**（按重量、按件、按区域）。

注意区分“能发快递”和“能做冷链配送”——水果尤其鲜果，普通快递能到不等于品质能保证。

## 二、用真实订单做小批量测试
最有效的核实方式是**下几笔真实测试单**，覆盖不同区域：
- 选**华东/华南/华北/西南/西北/东北**各1–2个代表城市，其中至少包含1个偏远或低线城市的收货地址；
- 测试单用**实际采购品类和包装规格**，不要用样品特批；
- 记录：下单到发货时间、物流轨迹是否真实、到货时效、**到货温度/冰袋状态、损耗率、包装完好度**；
- 同一地址下2–3单，看稳定性，避免单次偶然。

## 三、核验物流合作方和冷链能力
- 问清**具体承运商名称**（顺丰冷运、京东冷链、中通冷链、区域冷链专线等），可要求提供近期真实运单号（脱敏）抽查轨迹；
- 确认**冷链是全程温控还是“冰袋+泡沫箱”**，后者在夏季长途和偏远地区风险高；
- 问**中转环节**：是否需要二次分拨，中转城市在哪里，中转是否开箱、是否加冰。

## 四、问清异常处理机制
这是很多供应商回避的部分，要具体到：
- 到货损耗/变质**赔付标准**（按比例赔、按单赔、还是只补发）；
- **售后响应时限**和对接人；
- 偏远地区**拒收/退回**的运费谁承担；
- 旺季（节假日、产季高峰）**运力是否有保障**，是否会临时停发某些区域。

## 五、做背景交叉验证
- 要求提供**近3个月发往目标区域的运单样本**，抽查轨迹是否与承诺一致；
- 询问其**主要客户类型和区域分布**，看是否真有跨区域发货经验；
- 有条件可**实地或视频看仓库/分拣现场**，确认是否有冷链仓储和打包能力；
- 对关键区域，可让其提供**当地落地配合作方**信息。

## 六、合同里写清楚
把核实结果落进合同：**覆盖区域清单、时效标准、冷链方式、损耗赔付比例、旺季保障条款、违约处理**。口头“全国都能发”不写进合同，等于没有约束。

**一句话判断标准**：愿意提供分区域明细、接受小批量真实测试、敢把时效和赔付写进合同的供应商，覆盖能力才可信；只反复强调“全国都能发”但给不出清单和测试的，建议谨慎。
