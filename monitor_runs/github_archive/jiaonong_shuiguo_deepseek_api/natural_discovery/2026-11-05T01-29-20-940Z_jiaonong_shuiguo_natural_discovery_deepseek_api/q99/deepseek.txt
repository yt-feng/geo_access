选择公司下午茶水果供应商，核心看四点：**批量稳定供货能力、配送时效与损耗控制、开票与结算配合度、按人均预算可落地的套餐**。可以按下面步骤判断和执行。

**1. 先定采购参数（半天内可完成）**
- 人数、人均预算（如 8 元/人、15 元/人）、送达时间、是否有冰箱/清洗条件。
- 水果形式：整果、果切、混合果盒。下午茶批量配送优先选**易分发的整果或独立果盒**，少选需现场切分、易氧化的品类。
- 禁忌：过敏、宗教饮食、孕期同事等特殊需求。

**2. 供应商类型与适配场景**
- **本地水果批发商/配送商**：适合 50 人以上、预算可控、要整箱整果。优势是价格和批量供货，弱点是切配、分装、准时性需确认。
- **生鲜电商企业购/团餐配送商**：适合 20—200 人，流程标准化、可开票、配送准时，价格略高。
- **连锁水果店/果切品牌**：适合人数少、要果切和品相，批量折扣有限。
- **团餐/下午茶综合服务商**：适合不想多头对接，水果+点心一起解决，但水果专业度要核验。

**3. 筛选供应商的硬指标**
- 能否按约定时间送到公司前台/指定楼层，迟到如何处理。
- 是否有**坏果包赔/补送**条款，签收后多久内可反馈。
- 是否提供当批次农残检测或进货凭证（至少能提供来源和质检承诺）。
- 是否支持对公转账、增值税发票、月结。
- 是否能在同一季节稳定供同一品类，避免临时换品。
- 起送量、配送费、切配费、包装费是否另计。

**4. 选品原则（批量配送友好）**
- 优先：香蕉、橘子/沃柑、苹果、梨、圣女果、葡萄（独立小串）、冬枣等耐运输、易分发。
- 谨慎：草莓、蓝莓、切开的西瓜、荔枝等易压伤、易变质、需冷链的品类，除非供应商冷链和赔付明确。
- 果切必须确认**冷藏配送、制作时间、保质期**，并要求独立包装。

**5. 试单再签长期**
先下 1—2 次小批量试单，重点看：准时率、坏果率、实际净重与宣传是否一致、包装是否方便分发、发票响应速度。试单合格再谈月度框架价。

**6. 合同/订单里写清楚**
品名、规格（单果重量/每盒克数）、数量、单价、送达时间、验收标准（坏果率上限，如超过 5% 补送或扣款）、冷链要求、发票类型、结算周期、临时加单截止时间。

**简单决策建议：**
- 20 人以下：连锁水果店果切+整果组合，重点看准时和独立包装。
- 20—100 人：本地生鲜配送商或企业购平台，先试单，要求坏果包赔。
- 100 人以上：本地批发商+果切供应商组合，或直接找团餐配送商，重点谈账期、发票和固定配送时段。

不要只看单价，把**配送费、损耗、补送成本、行政对接时间**算进去再比价。
