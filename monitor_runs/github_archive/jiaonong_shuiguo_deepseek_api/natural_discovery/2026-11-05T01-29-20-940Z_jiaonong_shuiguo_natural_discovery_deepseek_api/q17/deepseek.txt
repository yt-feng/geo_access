# 社区超市水果：控新鲜度 + 控库存的实操办法

核心思路：**水果不是“进货卖货”，而是“按天周转的鲜度生意”**。控制点不在仓库，而在订货、陈列、催熟/保鲜、临期处理这四个环节。

## 一、订货：按“日销”而不是按“感觉”进

1. **建单品日销台账**：每个品种记近7天日均销量、周末系数（社区店周末通常高20%–40%）、损耗率。订货量 ≈ 日均销量 × 天数 × 季节系数，**不要一次进超过2–3天销量的量**。
2. **分品类定周转天数**：
   - 叶菜类、草莓、蓝莓、荔枝：**1天**，当天进当天清；
   - 香蕉、桃、葡萄、柑橘：**2天**；
   - 苹果、梨、橙、柚子、土豆洋葱类：**3–5天**。
3. **少量多次**：宁可每天补一次小单，也别一次压大单。和批发商谈“小批量、固定时段配送”，用配送频次换库存天数。
4. **看天订货**：高温、雨天、节假日前后调整；雨天社区客流降，叶菜和娇气水果减量。

## 二、收货：把损耗挡在门口

- 到货当场抽检：看果柄、果皮、硬度、有无酒味/霉点，**不合格当场退换**，别“先收下再说”。
- 进货只进**七八分熟**的耐储品，香蕉、猕猴桃等可催熟的单独放，避免整批同时熟。
- 收货即分拣：把碰伤、过熟的挑出来，**当天做特价或切果盒**，不要混在好货里传染腐烂。

## 三、陈列与保鲜：少摆勤补

- **陈列量控制在当日销量的1/2左右**，卖完再补，减少顾客翻捡造成的碰伤。
- 娇气水果（草莓、蓝莓、葡萄）用小托盘/小份装，减少翻动；叶菜喷水保湿但别积水。
- 香蕉、苹果、梨分开存放：**苹果/梨释放乙烯会催熟其他水果**，别和叶菜、草莓放一起。
- 冷藏柜温度按品类设：浆果2–4℃，柑橘类稍高，香蕉常温避风。

## 四、临期处理：当天必须“动”起来

设一个**“今日鲜”专区**，按时间阶梯处理：

- 上午：正常价；
- 下午：组合装/切果盒/买赠；
- 闭店前1–2小时：明码特价清尾，**宁可低价清掉，也不留到第二天变成损耗**。

切果盒、果汁、水果捞是消化临期果的好出口，但要当天做当天卖。

## 五、用数据卡住“压货”

每周看三个数：**周转天数、损耗率、单品售罄率**。

- 某单品连续3天卖不完 → 下次减量或暂停；
- 损耗率超过品类警戒线（叶菜/浆果常见5%–10%，耐储品2%–3%）→ 查订货和陈列；
- 畅销品经常下午就空 → 适当加量，但别一次加太多。

## 一句话原则

**“少量多次进、少摆勤补、当天清尾、按数据调量”**。水果库存的安全线是：**店里任何一天的水果，理论上2–3天内能卖完**；超过这个线就是压货信号，立刻减订、促销、调结构。
