旺季怕断货，和供应商谈的时候别只听“有货、没问题”，要问能落到纸面和动作上的问题。建议按下面几组提前问清：

**1. 供应能力与优先级**
- 旺季你每天/每周能稳定给我多少货？按品种、规格分别说。
- 你同时供几家店？旺季我和其他客户冲突时，我的优先级怎么保证？
- 你有没有备用产地/备用供应商？主产地遇雨、降温、运输受阻时怎么补？
- 哪些品种旺季最容易断？提前多久告诉我风险？

**2. 价格与调价机制**
- 旺季价格怎么定？是锁价、随行就市，还是保底+浮动？
- 调价提前几天通知？以什么市场报价或标准为依据？
- 如果我提前锁量，能不能锁价或给阶梯价？
- 次果、损耗、规格不达标怎么计价和退换？

**3. 订货与到货时效**
- 每天几点前下单？几点到货？临时加单最晚几点、加多少能接？
- 旺季配送频次能不能增加？运费谁承担？
- 缺货、晚到、少送时提前多久通知？怎么补货？
- 恶劣天气或节假日，配送安排怎么变？

**4. 品质与验收**
- 规格标准怎么写清楚：单果重量、糖度、成熟度、色泽、大小均匀度。
- 到货验收标准是什么？不合格率超过多少可拒收或换货？
- 损耗谁承担？签收后发现内部质量问题，多久内可反馈？
- 是否支持抽检、留样？出现批量质量问题怎么赔？

**5. 结算与履约保障**
- 结算周期是现结、周结还是月结？旺季要不要押金或预付款？
- 断货、晚到、品质不达标有没有违约责任？怎么扣款或补偿？
- 合作期限怎么签？旺季保供条款能不能写进合同？
- 有没有最低起订量、返点、促销支持？

**6. 备选与应急**
- 如果连续断货，你能提供哪些替代品种或替代规格？
- 能不能给我介绍你的备用渠道，或者允许我旺季临时从别处补货？
- 出现价格暴涨时，有没有封顶价或优先供货约定？

谈的时候最好带一张表，把**品种、日供量、规格、价格机制、到货时间、缺货通知时限、违约责任**逐项写下来，让对方签字确认。旺季保供的核心不是“关系好”，而是**量、价、时、质、责**五个字都落到合同或订单里。另外自己也要留1—2家备选供应商，别把旺季押在一家身上。
