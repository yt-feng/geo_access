选供应商建议按“先定标准、再比报价、后试供”的顺序做，不要只看单价。

1. **先明确采购标准**
- 香蕉：要求成熟度可分批到货，避免一次全熟；果指饱满、无严重黑斑、无腐烂；按把/箱定损耗上限。
- 苹果：按品种、果径分级；要求脆度、色泽稳定；碰伤率、烂果率设上限。
- 橙子：按果径和糖酸度定等级；皮薄多汁、无霉变；到货可抽检糖度。
- 统一写清：规格、等级、产地/品种、单果重或果径、成熟度、农残检测报告、配送频次、退换货时限。

2. **供应商来源**
- 优先选本地一级批发商或产地直供合作社，香蕉可找催熟配送能力的供应商。
- 要求供应商有营业执照、食品经营许可或食用农产品销售相关资质；能提供批次农残检测或承诺书。
- 至少询3家：1家本地批发市场大户、1家产地/合作社、1家综合配送商，便于比价和备选。

3. **比价不能只看单价**
- 让供应商按“可食部分净重”或“到货合格率”报价，把损耗、配送、退换货算进去。
- 要求报价含税、含配送、含卸货；明确账期和结算方式。
- 比较：单价、损耗率、到货准时率、退换货响应时间。

4. **先试供再签长期**
- 先做2—4周小批量试供，每周记录：到货重量、烂果率、碰伤率、成熟度、配送准时、师生反馈。
- 香蕉重点看催熟和分批配送；苹果看碰伤和大小均匀；橙子看霉变和水分。
- 试供合格后再签季度或学期框架协议，保留2家备选供应商。

5. **合同和验收**
- 合同写明：品种规格、验收标准、不合格退货/换货、迟到扣款、食品安全责任、检测报告随批提供。
- 验收坚持“当场抽检、拍照留证、不合格拒收”，不要先入库后扯皮。
- 食堂采购还要关注可追溯：保留批次、供应商、检测报告和验收记录。

简单执行：先写一页采购规格书，询3家，试供2—4周，用“合格到货净重单价+损耗+准时率”做评分，选主供1家、备供1家。
