重要，而且不是“重要”，是**必须统一的前置条件**。对多门店超市来说，水果品质不稳定，通常不是门店执行不努力，而是**供应商分级标准不统一、不可验收、不可追溯**。

可以按下面几点判断和落地：

1. **分级标准决定“同一品质”能不能被定义**
   - 如果没有统一分级，A门店收的“一级果”和B门店收的“一级果”可能大小、糖度、成熟度、瑕疵率完全不同。
   - 多门店统一品质，第一步不是加强巡店，而是把“什么算合格”写成供应商和门店都能执行的验收标准。

2. **分级标准要能验收，不只看名称**
   建议至少明确：
   - 品种、产地、规格（单果重/直径）
   - 成熟度/糖度范围
   - 外观瑕疵允许比例（碰伤、裂口、黑斑、畸形）
   - 新鲜度指标（果柄、表皮、气味、到货温度）
   - 包装规格、损耗责任、退换货规则
   - 抽检比例和判定规则

3. **供应商分级标准不统一，会直接放大门店差异**
   - 采购按不同供应商口径下单，门店验收标准就会漂移。
   - 同一价格档位可能拿到不同品质，导致门店之间售价、损耗、毛利和顾客体验不一致。
   - 后期做统采统配、中央仓分拣时，没有统一分级就无法稳定分货。

4. **建议做法**
   - 建立一份**公司级水果分级验收标准**，按品类细化，不追求一次覆盖全部，先做销量前20%的品类。
   - 要求供应商按同一标准报价和供货，并在合同中写明验收判定和扣罚/退换规则。
   - 到货抽检按统一表格记录，每周汇总各供应商、各门店的合格率和损耗率。
   - 对供应商做分级管理：合格率、到货稳定性、售后响应、价格竞争力综合评分，末位淘汰或降级。
   - 先在一个区域或几家门店试点，跑通后再全部门店复制。

**结论：供应商分级标准不仅重要，而且是多门店水果品质统一的基础设施。** 没有它，门店端再努力也只能被动接受品质波动；有了它，采购、仓储、门店验收和供应商考核才能用同一把尺子。
