# 小店进货：批发市场 vs 固定供应商

**结论先行：进货量不大时，优先选"固定供应商"，但前期可以先去批发市场摸行情、比价格。** 两者不是二选一，比较现实的做法是"以固定供应商为主，批发市场作为补充和比价渠道"。

## 为什么小量进货更建议固定供应商

1. **价格不会更差**：批发市场的低价通常建立在"量大+现金+自提"上，你量小，议价空间很小，还可能被报"零售价"。固定供应商哪怕单价略高，但稳定、可账期、能退换，综合成本反而低。
2. **少跑腿、省时间**：小店主自己看店，跑一趟批发市场半天没了，交通、损耗、时间都是隐性成本。
3. **供货稳定、品质可预期**：固定供应商熟悉你的需求，缺货会提前说，出问题好沟通退换；批发市场每次可能换摊位，品质波动大。
4. **能谈账期和小批量**：做熟了可以谈"少量多次""月结""滞销可换"，这对现金流紧张的小店很关键。

## 什么时候批发市场更合适

- **刚开店、还在试品类**：需要小批量试销、快速换款，批发市场灵活。
- **生鲜、时令、快消品**：价格随行就市，批发市场当天拿货更新鲜、更便宜。
- **供应商暂时找不到合适的**：先用批发市场过渡，边拿货边物色固定供应商。

## 可执行建议

- **前 1～2 个月**：每周去 1 次批发市场，记录 3～5 家目标品类的价格、起订量、退换政策。
- **筛出 1～2 家**：选报价实在、愿意小批量、态度好的，谈成固定供应商，先小单合作。
- **保留比价习惯**：每季度去批发市场或线上平台比一次价，避免被"杀熟"。
- **关键条款写清楚**：单价、起订量、送货时间、退换货规则、账期，口头也要落到微信文字上。

一句话：**小量进货，固定供应商负责"稳"，批发市场负责"活"和"比价"，别只押一边。**
