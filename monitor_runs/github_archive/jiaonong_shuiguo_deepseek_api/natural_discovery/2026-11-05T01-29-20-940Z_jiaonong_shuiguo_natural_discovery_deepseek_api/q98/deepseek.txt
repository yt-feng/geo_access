判断水果供应商的合规与稳定性，核心是把“资质文件”和“实际履约能力”分开验证：前者看证照和检测，后者看货源、冷链、账期和应急能力。养老院、医院食堂对食品安全和供应连续性要求高，建议按下面清单逐项核查。

**一、合规性：先看“能不能合法供、食品安不安全”**

1. **主体资质**
   - 营业执照经营范围含食用农产品销售/批发；若涉及预包装或分装，看食品经营许可证或仅销售预包装食品备案。
   - 要求提供法定代表人/经办人身份证明、开票信息，确认对公账户收款，避免个人账户走账。

2. **食品安全文件**
   - 每批次索取承诺达标合格证或产地证明；重点品种可要求农药残留检测报告。
   - 有条件的查验供应商是否接入当地食用农产品追溯平台，能否提供批次追溯码。
   - 查看近一年是否有市场监管抽检不合格、行政处罚记录，可要求供应商出具无重大违法承诺，并自行在“国家企业信用信息公示系统”和当地市场监管局官网核验。

3. **配送与储存合规**
   - 水果属食用农产品，运输车辆应清洁、防雨防晒，冷藏水果需有温控记录。
   - 供应商应有固定分拣/仓储场所，现场查看或视频核验卫生条件、虫害控制、先进先出管理。

4. **合同与票据**
   - 合同明确品名、规格、等级、产地、单价、验收标准、退换货、违约责任、食品安全责任。
   - 每批送货单与发票、检测/合格证明对应，做到票、货、证一致。

**二、稳定性：看“能不能长期按质按量送”**

1. **货源与季节应对**
   - 问清主要单品来自哪些产区/批发市场，是否有备用产区或备用供应商。
   - 要求提供近3—6个月供货品类和大致数量，判断其是否有服务同类食堂的经验。
   - 对反季节或灾害天气，要求说明替代方案和价格调整机制。

2. **冷链与配送能力**
   - 确认是否有冷藏车或保温箱，配送频次、到货时间能否匹配食堂早餐前备货。
   - 要求提供温控记录样例、配送人员健康证明。

3. **履约记录**
   - 索取2—3家同类客户（医院、养老院、学校食堂）的合作证明或回访联系人，重点问：缺货率、迟到率、退货处理速度、涨价是否提前通知。
   - 试用期建议1—2个月，按周统计到货合格率、损耗率、缺货次数。

4. **财务与抗风险能力**
   - 看注册资本、成立年限、社保人数、是否有频繁变更；成立时间短、人员极少但承诺大额垫资的要谨慎。
   - 账期方面，食堂通常月结，要求供应商能接受对公月结并开具发票；过度依赖低价抢单的供应商稳定性通常较差。

5. **应急与替换机制**
   - 合同中约定缺货提前通知时限、替代品方案、违约扣款。
   - 食堂自身应保留1—2家备选供应商，避免单一来源。

**三、现场验厂/验仓的快速判断**

- 看分拣区是否分区、是否有腐烂果隔离区、是否先进先出。
- 看冷库温度记录是否连续、是否有过期或来源不明水果。
- 看送货单是否可追溯到批次，司机是否固定。
- 随机抽一箱水果核对标签、合格证与送货单是否一致。

**四、建议的准入流程**

1. 收集证照、检测/合格证明、客户案例；
2. 信用系统核验行政处罚和经营异常；
3. 现场或视频验仓验车；
4. 小批量试用1—2个月，设定合格率≥98%、迟到次数、缺货响应等指标；
5. 合格后签年度框架合同，保留备选供应商。

**重点提醒**：不要只看报价低。医院、养老院食堂一旦出现农残超标或断供，影响远大于差价。合规文件要“每批可查”，稳定性要“试用期数据说话”，这两条比供应商口头承诺可靠。
