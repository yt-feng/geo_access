直接结论：**优先鲜果（或冷冻鲜果/鲜切果丁），不建议用果泥做主打果茶；果丁适合出杯效率和标准化，但要看是否糖渍/含添加。**

可以按用途判断：

1. **鲜果（整果/鲜切）**
   - 适合：主打“真果肉”、现切现捣、客单价较高的菠萝果茶。
   - 优点：香气和果肉口感最好，卖点强，顾客感知价值高。
   - 缺点：要自己削皮切丁，损耗和人工高；菠萝批次差异大，酸度和甜度不稳定；需要冷藏、周转快。
   - 建议：门店有切配能力、销量稳定、想突出鲜果卖点，就买鲜果。可搭配少量果酱/糖浆调稳定风味。

2. **果丁（鲜切果丁或冷冻果丁）**
   - 适合：出杯量较大、想减少削切人工、需要标准化。
   - 优点：省人工、出杯快、克重稳定，适合连锁或高峰期。
   - 关键看标签：**鲜切果丁**保质期短、需冷链；**糖渍/蜜渍果丁**含糖高，会改变配方甜度和成本；**冷冻果丁**风味尚可但解冻后易出水、口感偏软。
   - 建议：如果只是替代切配环节，选无添加的冷冻/鲜切果丁；如果是糖渍果丁，要按“含糖果料”重新算糖和成本，不能当鲜果用。

3. **果泥**
   - 适合：做风味基底、冰沙、混合果茶，或弥补鲜果香气不足。
   - 优点：标准化最好、出杯快、颜色和酸甜稳定。
   - 缺点：缺少果肉咀嚼感，鲜果卖点弱；很多果泥含糖、增稠剂或香精，标签要看清楚；开袋后保存和微生物风险要管好。
   - 建议：不要单独用果泥做“鲜果茶”主打；可作为辅助基底，搭配鲜果丁或鲜果片。

**采购建议：**
- 主打鲜果茶、销量中等：**鲜果为主 + 少量果泥/果酱调稳定**。
- 高峰期出杯快、人工紧：**无添加冷冻果丁/鲜切果丁为主**。
- 做冰沙或标准化基底：**果泥辅助**，但必须确认配料表无多余添加。
- 不管选哪种，先小批量试杯：看香气、酸度、出水量、果肉口感、放置30分钟后的风味变化，再定供应商。

一句话：**要卖点和口感选鲜果；要效率和标准化选无添加果丁；果泥只适合做辅助基底，不适合当鲜果茶主角。**
