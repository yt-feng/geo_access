批发档口退货纠纷，八成出在“收货时没留证据、口说无凭”。验货要围绕一条主线：**当场验、当场记、当场确认，把责任边界在收货那一刻划定。**

**一、收货前先定规则**
- 和供货方/物流方提前书面约定：到货后多少小时内可提异议、哪些情形算破损短少、由谁承担。
- 公告或单据上写明“签收后视为外观完好”，但注意：如果实际不允许验货就签字，这种条款容易起争议，所以关键是**争取先验后签**。
- 准备固定工具：手机、卷尺、电子秤、封箱胶带、拍照标记贴、验货单。

**二、现场验货按顺序做**
1. **先看外包装**：拍整车/整托、外箱六面，重点拍破损、水渍、挤压、二次封箱痕迹。包装异常先别签收，或签“外包装破损，待验”。
2. **点数**：按单据核对箱数、件数、码数/规格，短少当场记。
3. **抽检+重点全检**：易碎、高价值、上次出过问题的品类全检；常规品按比例抽检，但抽检比例和规则要提前说清，避免对方不认。
4. **查内在质量**：污渍、色差、线头、尺码混装、生产日期/批号、吊牌条码是否对应。
5. **称重/量尺寸**：对按重量或规格结算的货，现场称重、量关键尺寸并拍照。

**三、证据怎么留**
- 全程连续录像：从拆封到清点，中间不剪辑，画面里出现单据和货物。
- 照片要“全景+细节+参照物”：破损处旁边放尺子或单据，能看出位置和程度。
- 填写验货单：到货时间、件数、异常明细、照片编号，**双方签字**；对方不签就录像记录其拒签。
- 异常货物单独隔离、贴标、原包装保存，别急着上架或退回，防止说不清。

**四、异常当场处理**
- 能当场协商的，在送货单/验货单上写明“短少X件/破损X件，待补/待赔”，双方签字。
- 不能当场定的，24小时内发书面异议（微信/邮件均可，保留记录），附照片视频，明确诉求和期限。
- 建立收货台账：每批货的到货时间、供货方、异常类型、处理结果，按月复盘高频问题，反过来约束供货方和物流。

**五、退货环节配合**
- 退货前先拍照封箱、贴封条、录装箱视频，和买家/供货方确认退货清单。
- 收到退货当场验，按同样流程留证，避免“退回来的和发出去的不一样”扯皮。

核心就一句：**没有记录的验货等于没验。** 把“拍、点、记、签”做成固定动作，纠纷时你手里有连续证据链，责任就好划。
