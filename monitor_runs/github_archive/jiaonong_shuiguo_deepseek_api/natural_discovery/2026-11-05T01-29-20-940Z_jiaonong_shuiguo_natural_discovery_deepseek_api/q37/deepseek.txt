商超会员日水果活动，供应商侧建议按“活动前—到货—现场—复盘”四段准备，重点是把风险和现场执行提前锁死。

**一、活动前7—10天：确认活动方案**
1. 确认活动商品清单：品项、规格、等级、活动价、原价、限量/不限量、每人限购。
2. 确认销量预估与备货量：按门店历史销量、会员日客流预估、天气和竞品活动，给出主推品和兜底品；生鲜备货建议留10%—20%安全库存，易损品不压太多。
3. 明确价格与费用：活动价、供价、促销折让、损耗承担、返利/费用分摊，落到书面确认单。
4. 确认到货计划和配送频次：会员日当天是否加配、几点前到店、分几批补货，避免一次性压货。
5. 确认包装与规格：预包装还是散装，是否做礼盒/组合装，标签、条码、产地、等级、日期标识是否合规。
6. 确认质检与证照：农残检测报告、产地证明、合格证、供应商资质，活动前提交门店备案。

**二、活动前3—5天：锁货源与物流**
1. 锁定产地/仓库货源，确认采摘、分选、预冷、包装时间，避免临时缺货。
2. 做一次到货模拟：按活动量试发一批，验证分拣、包装、冷链和门店收货效率。
3. 确认冷链能力：冷藏车、保温箱、冰袋、温控记录；草莓、蓝莓、荔枝、葡萄等易损品重点盯。
4. 确认备用货源和替代品：主推品缺货时，用同价位、同用途水果替代，提前和采购对齐。
5. 安排驻店/巡店人员：重点门店活动当天有人盯陈列、补货、试吃和异常处理。

**三、活动前1天：到店准备**
1. 按约定时间到货，优先保证开门前陈列量；易损品可分早晚两批到。
2. 到货验收：数量、规格、成熟度、新鲜度、温度、包装、标签逐项核对，不合格当场隔离。
3. 协助门店做陈列：堆头、端架、试吃台、价签、POP、限购提示，确保价签与活动价一致。
4. 准备试吃物料：试吃果、牙签、手套、垃圾盒、保鲜膜，安排试吃人员。
5. 准备补货工具和损耗处理：周转筐、保鲜袋、剪刀、抹布、次品回收框。

**四、活动当天：现场配合**
1. 开店前完成陈列和价签复核，重点检查活动价、限购标识、产地和等级。
2. 高峰前补货，避免空台；易损品少量多次上货，减少翻拣损耗。
3. 安排专人盯品质：发现软化、破损、异味立即下架，不混入正常陈列。
4. 试吃环节控制卫生和用量，试吃果与售卖果分开。
5. 实时记录销量、缺货、损耗、客诉，下午及时补单或调拨。

**五、活动后：复盘与结算**
1. 活动结束当天回收未售易损品，按约定处理退货、折价或转次日销售。
2. 核对实际到货、销售、损耗、费用和返利，形成对账单。
3. 复盘活动品销量、缺货率、损耗率、客诉和毛利，给下次会员日备货建议。

**关键提醒：**供应商最容易出问题的是“备货量拍脑袋、到货太集中、价签不一致、易损品损耗责任不清”。这四项要在活动前用书面确认单锁死，活动当天安排专人盯店。
