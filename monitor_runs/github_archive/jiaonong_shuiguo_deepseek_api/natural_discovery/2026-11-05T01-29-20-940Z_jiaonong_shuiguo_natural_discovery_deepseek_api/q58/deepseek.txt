直接结论：**多数甜品店用“鲜果切配”损耗更低、毛利更可控**，但前提是菠萝周转快、后厨有稳定切配人力且能规范操作；如果门店销量小、后厨忙不过来或切配标准不稳定，**买成品果丁反而综合损耗更低**。

判断时不要只看“烂掉多少”，要把损耗分成四块算：

1. **原料损耗**：鲜果有去皮、去眼、去芯，菠萝出丁率通常明显低于100%；成品果丁按净重采购，这部分损耗已转成价格。
2. **过程损耗**：鲜果切配会有汁水流失、边角料、切废、氧化变色、冷藏风干；成品果丁开封后也会有失水、变软、过期报废。
3. **库存损耗**：鲜果整果相对耐放，可分批切；成品果丁保质期短、开封后必须尽快用完，小门店容易报废。
4. **隐性成本**：鲜果要人工、清洗、刀具消毒、垃圾处理；成品要验货、冷链、开封管理、供应商稳定性。

可执行的判断方法：

- 连续记录2周：鲜果采购毛重、切后净重、报废重量、切配工时；成品果丁采购净重、开封后报废重量、到货不合格重量。
- 算“可售果丁成本”= 总采购成本 ÷ 实际可用果丁重量，再加人工和报废处理成本。
- 如果鲜果出丁率稳定、日均用量能当天或次日用完，选鲜果切配通常更划算。
- 如果日均用量小、切配人手不稳、成品到货质量稳定且能按小包装高频配送，选成品果丁损耗更可控。
- 折中方案：**主力产品用鲜果切配，小批量装饰/临时补货用成品果丁**，比二选一更稳。

一句话：**量大、周转快、后厨规范 → 鲜果切配损耗更低；量小、人手紧、保质期管理弱 → 成品果丁综合损耗更低。**
