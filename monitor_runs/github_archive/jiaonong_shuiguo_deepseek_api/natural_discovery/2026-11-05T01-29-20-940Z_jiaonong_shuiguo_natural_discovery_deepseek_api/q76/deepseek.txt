香蕉配送中最容易出问题的不是“压一下立刻坏”，而是**机械伤 + 高温呼吸跃变 + 乙烯累积**叠加，导致到货后很快变黑。建议从“选货—包装—温控—配送—售后”五段控制。

**1. 选货和入库：别用全熟蕉做远距离配送**
- 配送用蕉选**七至八成熟、果指硬、无催熟过度的青黄蕉**；同批次成熟度要一致。
- 入库剔除有裂口、断指、机械伤、水锈和已出梅花点的蕉。
- 香蕉对低温敏感，**不要低于12–13℃冷藏**，否则表皮发黑。青蕉可在13–15℃短存，催熟后尽快周转。
- 入库前用乙烯吸收剂或加强通风，避免与苹果、梨等释放乙烯的果蔬混放。

**2. 包装：防压、防摩擦、防闷**
- 用**带透气孔的分格纸箱或塑料周转箱**，单格单根或小把固定，避免相互挤压。
- 每把香蕉用**薄珍珠棉/软纸包裹果指接触面**，但不要全封闭包死；果柄可单独包护。
- 箱内加瓦楞隔板或气泡膜做缓冲，**装量别过满**，留5%–10%空间；重物不得压在上面。
- 纸箱开透气孔，避免密闭包装内水汽和乙烯累积；雨天配送外层加防水袋，但内层保持透气。
- 标签注明“易压、怕闷、勿倒置、避免低温”。

**3. 温控和预冷**
- 装箱前把蕉体温度降到**15℃左右**再发运，减少箱内结露和呼吸热。
- 配送车厢避免暴晒和靠近冷机出风口；夏季用**15℃左右冷藏车/保温箱**，冬季防冻，不能低于12℃。
- 同车不与冷冻品、热食混装；短途可用保温箱+冰袋，但**冰袋不能直接贴香蕉**，用隔层隔开。

**4. 配送环节**
- 搬运轻拿轻放，禁止抛掷、叠压；配送员取放时拎箱底，不拎提手单侧。
- 优化线路，缩短在途时间；高温时段避开长时间路边停放。
- 到驿站/自提点后放阴凉通风处，不放进冰箱、不压在其他包裹下。

**5. 售后和兜底**
- 商品页明确“香蕉表皮轻微擦伤/青黄差异不售后”的边界，减少争议。
- 对压伤、黑腐按坏果比例赔付；高客单价订单可用**分格硬箱+保价**。
- 记录破损率，按线路和包装版本复盘，优先改包装结构和装量，而不是只加冰袋。

**最优先做的三件事：** 用七至八成熟蕉；换分格透气硬箱并控制装量；配送温度控制在13–15℃、冰袋不直贴。这样能同时降低压伤和闷黑风险。
