评估水果供应商仓配能否覆盖连锁门店，建议按“仓—配—门店”三层做硬性核验，并用数据判断，不只看供应商画的城市覆盖图。

**1. 先明确门店侧约束**
- 把门店按城市、商圈、下单频次、单店日均销量、最低起订量、收货时间窗列出。
- 水果重点看：温区要求（常温/冷藏/冷冻）、保质期、损耗率、是否允许拆零、是否需要门店退货回收。
- 标出“硬约束”：如早市门店必须6:30前到货、冷藏品必须全程温控、单店最小起订量。

**2. 核验供应商仓网真实覆盖**
要求供应商提供：
- 每个仓的地址、面积、温区、日均吞吐、辐射半径和实际配送城市清单。
- 从该仓到每家门店的**实际配送路线和时效**，不是直线距离。
- 是否自有仓、租赁仓或外包仓；外包的，要看到外包合同中的服务范围。
- 跨城配送是“干线到城市仓再落地配”，还是“单仓直发”。水果直发跨城超过一定距离，损耗和时效风险会明显上升。

判断标准：
- 门店在供应商仓的**常规配送圈**内，且有时效记录；
- 覆盖不是“能送到”，而是“按门店要求的时间窗、温区、频次稳定送到”；
- 新城市没有本地仓或稳定落地配资源的，视为覆盖不足。

**3. 评估配送能力，不只看仓**
重点问清：
- 车辆资源：自有车、外协车比例，冷藏车数量，旺季和节假日运力保障。
- 配送频次：每日/隔日/每周几次，能否按门店销量动态加频。
- 线路规划：同城多点配送的装载率、门店卸货顺序、异常改派机制。
- 温控与在途监控：冷藏车温度记录、GPS轨迹、到店签收和温控凭证。
- 损耗与售后：水果破损、变质、短少怎么定责，多久补货或赔付。

**4. 用试运行数据做最终判断**
建议选代表门店做2—4周试配送，记录：
- 准时到店率；
- 订单满足率、拆零满足率；
- 到货损耗率和温控合格率；
- 单店单次配送成本；
- 异常响应时长和补货时效。

设定门槛，例如：准时到店率≥95%、订单满足率≥98%、冷链温控合格率100%、损耗率在约定范围内，才纳入正式覆盖。

**5. 做覆盖矩阵和成本测算**
按“城市×门店×商品温区”做矩阵，标绿/黄/红：
- 绿：有本地仓或稳定落地配，时效和温区达标；
- 黄：可覆盖但需跨城直发或频次不足，需加价或加频；
- 红：无仓、无稳定运力或时效不达标，不建议覆盖。

同时算总落地成本：干线运费+城市配送费+仓储操作费+损耗+退货补货成本，避免只看报价低。

**结论**：水果供应商仓配覆盖评估的核心是“仓的真实辐射能力+落地配稳定性+门店时效温区约束+试运行数据”。没有本地仓和稳定落地配的新城市，不要仅凭供应商承诺就判定可覆盖。
