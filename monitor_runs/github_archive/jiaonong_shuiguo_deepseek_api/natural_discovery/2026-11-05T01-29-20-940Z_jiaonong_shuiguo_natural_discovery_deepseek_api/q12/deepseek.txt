判断采购熟度时，核心原则是：**按“卖相寿命”倒推，不要按“今天最好吃”来采。** 水果店菠萝损耗主要来自过熟、黑心、机械伤和存放期短，所以采购应优先选**八成左右熟、能放几天、到店后还能转黄的果**。

### 采购时的判断标准

1. **看果皮颜色**
   - 选：**青黄相间、底色由青转黄、约1/3～1/2转黄**。
   - 慎选：整果金黄、尤其底部也黄透的，通常已接近最佳食用期，货架期短。
   - 避免：大面积青绿且无黄，可能成熟度太低，酸、后熟慢；也可结合品种判断。

2. **看果眼和底部**
   - 果眼**平展、饱满**较好；果眼深陷、发黑、渗汁，容易过熟或内部坏。
   - 翻看**果底**：底部发黄软、有酒味、渗液，别要。
   - 注意“黑心”风险：底部中心发暗、切开前果皮有暗斑的，整批抽检。

3. **闻气味**
   - 有**清淡菠萝香**可以。
   - **明显酒味、发酵味、酸臭味**说明过熟或已变质，直接拒收。

4. **摸硬度**
   - 轻按果身**紧实有弹性**，不软塌。
   - 果身局部软、底部软、果眼按下去凹陷，货架期很短，适合当天促销，不适合正常陈列。

5. **看果冠和伤口**
   - 冠芽青绿、挺立说明较新鲜；冠芽枯黄不等于果肉差，但可作为新鲜度参考。
   - 有**裂口、压伤、虫眼、霉点**的容易从伤口烂，损耗高，尽量不采或单独低价处理。

### 采购比例建议

- **主采：八成左右熟、青黄相间、紧实、无伤**，占多数，给门店2～4天销售窗口。
- **少量采：接近全黄、香气足**，用于当天现切或促销，不建议压库存。
- **不采：底部黄软、酒味、渗汁、明显压伤**。

### 到店后的简单做法

- 按熟度**分筐分级**：青黄果放常温催熟/正常陈列；黄熟果优先切果或促销。
- 菠萝**不要整批堆压**，避免底部压伤；翻筐检查底部和伤口。
- 常温通风存放，避免闷在塑料袋里；切开的必须冷藏并尽快售完。

一句话：**采购选“青黄相间、紧实、香而不酒、底部干净”的八成熟果，全黄果只少量补陈列或当天消化。**
