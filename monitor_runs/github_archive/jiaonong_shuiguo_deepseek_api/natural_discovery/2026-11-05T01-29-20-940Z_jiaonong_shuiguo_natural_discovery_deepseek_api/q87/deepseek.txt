旺季水果锁库存，核心不是“打个电话让供应商留货”，而是把**需求预测、预付/保证金、分批次锁量、验收标准、违约条款**做成一套可执行的协议。下面按可操作顺序给你方案。

## 1. 先算清“锁多少”，别拍脑袋
- 拉出近2–4周同品类销量、去年旺季同期、当前团购群增长、复购率，做**保守/基准/乐观三档预测**。
- 锁定库存只锁**基准销量的70%–80%**，留20%–30%靠现货市场补，避免压货和损耗。
- 按SKU拆分：爆款单品单独锁，长尾品用“优先供货权”而非硬锁量。

## 2. 锁库存的4种谈判工具（按力度从轻到重）
1. **意向锁量+优先供货权**：约定旺季期间每日/每周优先给你供货，价格按当日市场价下浮固定比例。适合关系一般、不想占资金。
2. **预付定金锁价锁量**：付10%–30%定金，锁定数量和价格区间，尾款发货前结清。合同写明“定金可抵货款，供应商违约双倍返还”。
3. **分批锁量+滚动补单**：先锁首周量，之后每周按实际销量滚动追加，供应商承诺产能优先给你。适合水果损耗大、怕压货的品类。
4. **包园/包棚或联合采购**：对爆款水果直接包下某片果园/大棚的产出，或联合周边几个团长拼单锁量，压低单价、提高供应商重视度。

## 3. 合同里必须写死的6条
- **数量与浮动**：锁定基础量，允许±10%浮动；超出部分按约定价优先供应。
- **价格机制**：锁价还是随行就市下浮；遇极端行情（如产地暴涨30%以上）的重新议价触发条件。
- **交货节奏**：按日/隔日分批到仓，避免一次性到货造成损耗。
- **质量标准**：糖度、单果重、坏果率上限（如≤3%）、规格分级，附验收照片/视频留证。
- **违约与赔付**：供应商缺货按缺口金额的X%赔付；你方取消需提前几天通知、定金如何处理。
- **不可抗力与替代方案**：产地天气、疫情、物流中断时的替代品种或退款规则。

## 4. 执行层面提前做的事
- **提前2–4周**和供应商谈，旺季前一周才谈基本没量。
- **多源备份**：每个爆款至少2家供应商，主供锁70%，备供锁30%或拿优先权。
- **到货即验**：每批抽检拍照、记录坏果率，作为扣款和后续谈判依据。
- **资金准备**：定金和首批货款提前备好，供应商更愿意给量。
- **信息透明换信任**：把你近期的团购销量数据适度给供应商看，证明你是稳定大客户，比空口承诺更容易拿到优先权。

## 5. 一句话判断标准
如果供应商愿意签**写明数量、价格机制、质量标准、违约赔付**的书面协议并收定金，才算真锁住；只口头说“给你留着”的，旺季大概率被高价截胡。
