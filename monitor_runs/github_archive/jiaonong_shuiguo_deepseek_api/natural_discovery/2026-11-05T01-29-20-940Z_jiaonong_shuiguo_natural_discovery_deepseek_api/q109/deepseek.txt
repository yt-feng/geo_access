优先谈**账期**，其次售后，最后配送。但结论取决于你的品类和现金流，先按这个顺序谈，同时守住两个底线。

**为什么账期优先**
- 水果是高损耗、高频补货品类，账期直接决定你的现金流和议价空间。
- 长期供应商愿意给账期，说明对你的合作稳定性有信心，也便于后续谈价格折让。
- 实操上争取“到货验收后7–15天”，并明确对账日、开票日、付款日，避免口头账期。

**售后第二**
- 水果非标，售后条款比配送更容易产生扯皮。优先谈清：损耗率上限、坏果赔付比例、赔付方式（补货/折价/退款）、拍照留证时限、当日反馈截止时间。
- 不要只谈“包售后”，要落到可执行的数字和时限。

**配送第三，但不能放松**
- 配送时效、到货温度、缺货替代规则、临时加单截止时间，这些影响履约稳定。
- 如果供应商配送已经稳定，配送可以少谈；如果经常迟到或缺货，配送要提到售后之前。

**建议谈判顺序**
1. 先谈账期和结算规则，锁定现金流。
2. 再谈售后赔付标准和反馈时限，降低损耗争议。
3. 最后谈配送频次、到货时间窗和缺货处理。
4. 价格放在这几项之后谈，用“账期+稳定采购量”换价格折让。

**判断标准**
- 你若现金流紧、单量大：账期最优先。
- 你若损耗高、品质波动大：售后最优先。
- 你若门店补货频繁、时效敏感：配送最优先，但仍建议先锁账期框架。

一句话：**先谈账期定现金流，再谈售后定损耗责任，配送作为履约底线同步确认，价格最后谈。**
