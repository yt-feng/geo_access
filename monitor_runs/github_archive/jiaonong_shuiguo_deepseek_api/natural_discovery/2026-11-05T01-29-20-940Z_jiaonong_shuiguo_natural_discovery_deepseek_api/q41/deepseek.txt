商超采购香蕉时，判断“催熟能力是否稳定”，重点不是看一批香蕉黄不黄，而是看**供应商/催熟库能否把不同批次都稳定催到可售状态**。可以从以下 6 个可执行维度判断。

### 1. 看批次一致性，而不是单批表现
重点要历史数据：
- 连续 3～5 批到货的**青度是否一致**（颜色、硬度、条指粗细、饱满度）
- 同一催熟条件下，**转黄时间差是否控制在 1 天内**
- 催熟后**色差、软硬差、青头比例**是否稳定

如果每批都要临时调整温度、乙烯浓度或时间，说明催熟能力不稳定。

### 2. 看催熟库的硬件与控制能力
香蕉催熟稳定性高度依赖设备：
- 库体是否**密闭、保温好**，温度波动是否小
- 是否有**强制空气循环**，不同货位温差是否小
- 温控精度能否做到 **±0.5℃左右**
- 乙烯/催熟气是否**均匀分布**，有无死角
- 是否具备**CO₂排放/换气**能力，避免催熟不均、果肉发软

商超可要求供应商提供催熟库温度记录、库内不同点位温差记录。

### 3. 看“到货青度—催熟方案”是否标准化
稳定催熟不是固定一套参数，而是有标准逻辑：
- 按**到货青度、条指、季节、产区、运输时长**分档
- 每档有对应催熟温度、湿度、乙烯浓度、时长
- 有**转黄目标**：例如几成黄到店、货架期几天
- 出库前有**硬度、色卡、青头比例**检查

采购时可问：同青度不同季节的催熟参数是否调整？是否有书面 SOP？

### 4. 做小批对比测试
最直接的方法：
- 同一供应商连续 3 批，各留**1 箱做同条件催熟对比**
- 记录：转黄天数、色差、青头率、软果率、货架期
- 看第 3 天、第 5 天、第 7 天的状态是否接近

如果同一条件下批次间差异明显，催熟稳定性不足。

### 5. 看催熟后货架表现
稳定催熟不仅“催得黄”，还要“黄得均匀、卖得住”：
- 催熟后**青头比例低且一致**
- **果指软硬均匀**，无明显软塌、水烂
- 到店后 **2～3 天货架期稳定**
- 不同批次**客诉率、损耗率**是否稳定

可要求供应商提供近 1～2 个月的催熟损耗率、退货率。

### 6. 看供应链前段稳定性
催熟不稳往往是前段不稳造成的：
- 产地采收青度是否一致
- 冷链运输温度是否稳定
- 到货是否有**受冷、受热、机械伤**
- 不同产区/季节切换时是否有过渡方案

受冷香蕉催熟后容易发黑、发软；受热香蕉转黄快但不耐放。采购要核对运输温度记录和到货果温。

### 采购可落地的判断清单
签合同或换供应商前，建议要求：
1. 连续 3 批同条件催熟对比记录；
2. 催熟库温湿度、乙烯浓度、换气记录；
3. 催熟 SOP 和异常处理方案；
4. 近 1 个月催熟损耗率、客诉率；
5. 小批试销 1～2 周，看货架期和色差。

**一句话判断：** 如果供应商能按到货青度分档、有温控和循环记录、连续多批同条件催熟结果接近、催熟后货架期稳定，才算催熟能力稳定；只看单批催得黄不可靠。
