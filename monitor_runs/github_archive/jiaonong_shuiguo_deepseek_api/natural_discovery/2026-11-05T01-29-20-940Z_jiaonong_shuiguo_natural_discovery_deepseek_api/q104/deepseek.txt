单位采购水果到货品质不一致时，核心是**先按约定标准验收、当场留证、分级处理，再按合同走售后**。下面给你一套可直接执行的做法。

## 一、到货前先明确验收标准
采购合同或订单里最好提前写清：
- **品种、规格、单果重量/果径、等级**
- **成熟度、糖度（如需要）、外观瑕疵允许比例**
- **产地、采摘/包装日期、冷链要求**
- **允许的不合格比例**，例如“次果率不超过5%”
- **验收时限**：到货后几小时内完成抽检
- **售后规则**：不合格部分补货、换货、退款或折价

如果没有书面标准，至少保留订单、聊天记录、样品照片作为依据。

## 二、到货验收怎么做
1. **先拒收明显严重问题批次**  
   如腐烂、异味、严重冻伤、明显以次充好，先拍照录像，暂缓签收或签“待检”。

2. **分层抽样，不要只翻表面**  
   按箱/筐随机抽，抽检箱数不少于总箱数的10%—20%；大货可分层抽上中下、里外层。

3. **按同一标准逐项记录**  
   记录：到货总数、抽检数、不合格数、主要问题（大小不一、青果、烂果、压伤、品种不符等）。

4. **当场拍照/录像留证**  
   拍全景、批次标签、开箱过程、问题果特写、称重照片；视频最好连续拍摄，能体现抽样过程。

5. **双方签字确认**  
   验收单写清合格数、不合格数、不合格比例、处理意见，送货人和验收人签字；对方不签就备注“拒签”并留存影像。

6. **分开存放**  
   合格品与问题品分区，问题品封存待处理，避免混放后责任不清。

## 三、品质不一致的分级处理
- **轻微不一致**（少量大小差异、个别瑕疵）：按约定折价或扣款，正常收货。
- **部分批次不合格**：合格部分签收，不合格部分拒收，要求补货/换货。
- **整体品质不符**：整批拒收或协商降价，写明原因。
- **腐烂、食品安全风险**：立即隔离、拍照、通知供应商，必要时销毁并索赔。

## 四、售后怎么走
1. **验收后第一时间发书面通知**  
   通过邮件/微信/采购系统发《到货异常通知》，附照片、抽检记录、不合格比例、诉求（补货/换货/退款/折价）和时限。

2. **按合同约定时限提出**  
   一般到货后24小时内提出，生鲜类越早越好；超过约定时限容易扯皮。

3. **明确责任和方案**  
   要求供应商书面确认处理方式；补货的约定到货时间，退款的约定到账时间，折价的约定金额。

4. **保留样品和记录**  
   问题样品封存到售后结束，验收单、照片、沟通记录统一归档。

5. **供应商反复出问题**  
   累计异常次数、不合格率，纳入供应商考核；合同里可约定质量保证金或扣款条款。

## 五、建议的验收单模板字段
到货日期、供应商、品种、订单数量、到货数量、抽检数量、不合格数量、不合格率、问题描述、处理意见、送货人签字、验收人签字、照片编号。

**一句话原则：标准前置、抽样留证、分级签收、书面售后。** 这样既能把当天验收做清楚，也能在后续退换货和扣款时有依据。
