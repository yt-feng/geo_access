判断茶饮连锁的菠萝供应商能不能稳定按规格送货，核心不是看样品，而是看“批量一致性+交付可控性”。可以按下面几步做可执行核验。

**1. 先把自己的规格写成可验收标准**
不要只说“菠萝”，要明确：
- 品种/产地：如金钻/台农/巴厘，是否允许混品种
- 成熟度：糖度区间、果肉颜色、是否允许后熟
- 规格：单果重量区间、果径、去皮/带皮、切块尺寸
- 加工形态：鲜果、冷冻果块、糖水罐头、果泥/果酱
- 缺陷率：黑心、烂心、机械伤、异味、纤维粗、酸度过高的允收比例
- 包装：每箱净重、内袋、抽真空/冷冻、标签批次
- 冷链：运输温度、到货中心温度、解冻/复冻限制
- 验收方法：抽检比例、糖度计/称重/目检/微生物或农残报告要求

没有这套标准，供应商“稳定”无法判断。

**2. 要求供应商提供连续批次记录，而不是单次样品**
重点看最近3—6个月、至少5—10个批次的：
- 糖度、单果重、缺陷率的实测记录
- 每批出货量和你的规格匹配度
- 是否有同一批次内波动大的情况
- 异常批次怎么处理、补货还是扣款

如果供应商拿不出记录，只愿意寄样品，稳定性风险高。

**3. 做小批量试单，按真实门店节奏压测**
建议分三批试单：
- 第一批小批量验规格和口感
- 第二批正常周采购量验交付
- 第三批安排在旺季/雨季/节假日前后，验抗波动能力

每批到货按统一表抽检：重量、糖度、缺陷率、中心温度、包装破损、批次标签。连续三批达标再谈放量。

**4. 现场审供应商的“交付能力”**
重点看：
- 原料来源：自有基地、合作基地还是多级收购；多级收购波动更大
- 分选能力：有没有重量/糖度分选线，还是人工混装
- 仓储：常温还是冷链，冷库容量是否覆盖你的订单
- 加工能力：去皮切块是否有标准作业和异物控制
- 排产与库存：能否为连锁客户留安全库存
- 物流：自有冷链还是外包，异常补货时效
- 追溯：批次能否追到基地/收购日/加工日

**5. 用“异常响应”判断真实稳定性**
问清楚并写进合同：
- 规格不达标时，多长时间补货或换货
- 旺季断供的赔付和责任
- 是否接受驻场抽检或视频验货
- 到货不合格的扣款/退货标准
- 价格调整机制，避免低价中标后降规格

**6. 建议的决策规则**
可以设定：
- 连续3批抽检合格率≥95%，缺陷率在允收范围内，才进入常规供应
- 任何一批缺陷率超标或冷链断链，暂停放量并复查
- 同时保留第二供应商，主供占比70%—80%，避免单点断供

**一句话判断：** 能提供连续批次数据、接受按你的验收标准抽检、在旺季仍能按约定补货的供应商，才叫能稳定按规格送货；只靠样品和口头承诺的不算。
