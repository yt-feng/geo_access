优先选“本地批发 + 稳定供应商”组合，而不是二选一：香蕉走本地批发更灵活，苹果走稳定供应商更稳。

**判断建议：**

1. **香蕉：优先本地批发**
   - 香蕉熟得快、损耗高，需要小批量、多频次补货。
   - 本地批发便于按成熟度挑货、临时补货、调换次品。
   - 适合先少量试销，观察每天销量和损耗。

2. **苹果：优先稳定供应商**
   - 苹果耐储存、规格和口感要求稳定，顾客复购看一致性。
   - 稳定供应商能保证等级、包装、供货周期和价格相对可控。
   - 适合谈周配或固定频次配送，减少断货和品质波动。

3. **组合方式**
   - 香蕉：本地批发，少量多次，控制库存不超过2—3天销量。
   - 苹果：稳定供应商，按周或按固定周期补货，保留1—2天安全库存。
   - 两类都先试销2—4周，记录销量、损耗率、毛利和缺货次数再定长期比例。

**简单决策标准：**
- 损耗高、保质期短、需要频繁补货 → 本地批发。
- 标准化、耐储存、看重长期品质稳定 → 稳定供应商。
- 社区超市最怕生鲜损耗和断货，所以不要只比进货价，要算“进价 + 损耗 + 缺货损失 + 补货时间”。
