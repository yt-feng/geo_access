线上水果差评主要来自两件事：**坏果**和**口感不稳定**。采购端要把这两件事拆开管，别只靠“挑好货”这种模糊要求。

**一、减少坏果：把标准写进合同和验收**

1. **按品种定采收成熟度**  
   线上销售要考虑物流时间，采购时明确“七八成熟采收、到仓后熟”的品种和比例，不要收已软熟或过熟的果。要求供应商按销售半径和运输时长倒推采收窗口。

2. **分级采购，不混级**  
   明确果径、单果重、着色度、糖度下限、伤果率上限。合同里写清“机械伤、裂口、霉变、软烂”的容许比例和赔付方式，避免到货后扯皮。

3. **包装和预冷是采购条件**  
   要求供应商采后尽快预冷，冷链运输；箱内加缓冲、透气孔，避免挤压和闷热。采购价里要把包装成本算进去，别为了低价牺牲包装。

4. **到仓验收做抽检记录**  
   每批抽检坏果率、软果率、异味、霉变，拍照留档。连续两批超标的供应商降级或淘汰。坏果率建议按品种设阈值，比如易损果控制在3%以内，超过即拒收或折价。

5. **缩短库存周转**  
   采购量按销量预测走，宁少勿多。线上水果最怕压货，库存时间越长坏果率越高。对易腐品种做“小批量、多频次”采购。

**二、减少口感不稳定：用数据而不是感觉**

1. **把糖酸度写进采购标准**  
   对主力品种约定糖度下限和酸度范围，比如柑橘类糖度不低于某值、酸甜比在某个区间。有条件的用折光仪抽检，没条件的至少做口感盲测记录。

2. **固定产区、固定供应商、固定采摘批次**  
   口感波动往往来自换产区、换批次、混收。尽量锁定核心产区和合作供应商，要求同一SKU来自同一采收批次，避免不同果园混装。

3. **区分“即食”和“后熟”**  
   线上卖即食果，采购时就要选成熟度到位的；卖需后熟的，要标注食用时机，并在仓内做催熟或温控管理。不要把两种货混在一个链接里卖。

4. **建立口感留样和复盘**  
   每批留样，记录糖度、硬度、香气、口感描述。收到差评后能回溯到批次和供应商，而不是笼统归因“水果就这样”。

**三、采购合同里必须写的几条**

- 品种、产区、采收批次、成熟度
- 果径/单果重/着色度/糖度下限
- 坏果率、软果率、机械伤率上限及赔付
- 预冷和冷链要求、包装标准
- 到货验收方式和抽检比例
- 连续不合格的淘汰机制

**一句话建议**：采购时把“坏果率”和“糖酸度”变成可抽检的合同指标，再配合小批量高频次采购和固定产区批次，差评率会明显下降。别指望靠售后补救，水果差评一旦上来，链接权重很难恢复。
