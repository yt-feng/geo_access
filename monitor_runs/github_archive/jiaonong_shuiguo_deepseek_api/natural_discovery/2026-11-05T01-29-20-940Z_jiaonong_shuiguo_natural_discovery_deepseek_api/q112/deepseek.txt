坏果率没有统一法定阈值，关键看合同约定和验收标准。实操建议：

1. **合同里最好明确约定**  
   常见做法是按批次抽样验收，约定：
   - 坏果率 ≤ 3%～5%：正常损耗，不赔付；
   - 超过约定阈值：按超出部分扣款或整批折价；
   - 超过更高阈值（如 10%～15%）：可拒收、退货或解除该批次合同。
   具体阈值要结合水果品类、运输距离、季节和采购价谈判，不能一刀切。

2. **没有约定时怎么办**  
   不能仅凭“超过多少”直接要求赔付，应先看：
   - 合同是否有质量标准、验收条款、损耗条款；
   - 双方交易习惯和行业标准；
   - 坏果是否属于运输、储存责任还是交付前质量问题。
   可先书面提出质量异议，保留抽样照片、视频、称重记录、验收单和第三方检测/见证记录，再按合同争议条款协商或索赔。

3. **建议写入合同的赔付公式**  
   例如：  
   “坏果率超过5%的，超出部分按该批次不合格果重量×采购单价×1.5扣减货款；坏果率超过15%的，采购方有权拒收该批次并要求退货，运费及因此产生的合理损失由供货方承担。”  
   这样比只写“超过多少赔付”更可执行。

简言之：**有合同按合同；没合同建议以3%～5%作为正常损耗参考线，超过部分主张扣款，超过10%～15%可主张拒收/退货，但最终要看证据和约定。**
