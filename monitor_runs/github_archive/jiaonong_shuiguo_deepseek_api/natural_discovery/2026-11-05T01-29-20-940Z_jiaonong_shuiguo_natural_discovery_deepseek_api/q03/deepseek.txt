第一次找水果供货商，别一上来就压量压价，重点是用小单验证“质量稳定性、损耗承担、结算规则”这三件事。可以按下面做：

## 1. 先定试单原则
- **每家只试3个单品**：香蕉、苹果、橙子各1箱/1件，别混太多品种。
- **不要只找一家**：找2～3家同时小试，同一品种对比。
- **试单期控制在1～2周**：看两次补货是否稳定，不只首次货好。
- **先谈清楚再拿货**：价格、规格、损耗怎么算、送货时间、退换规则、结款方式。

## 2. 三个单品分别怎么试
**香蕉**
- 重点看：到店成熟度、青黄比例、箱内是否有压伤、催熟是否均匀。
- 试单要求：明确“到店可售成熟度”，比如几分熟到店、几天内能卖完。
- 不要一次进太多，香蕉损耗最快，先试半件或小件。

**苹果**
- 重点看：规格是否统一、表皮碰伤、大小分级、脆度、箱底是否有烂果。
- 试单要求：问清是“净果”还是“毛重”，箱内坏果怎么赔。
- 同价位对比两家，切开看内部是否糠心、黑心。

**橙子**
- 重点看：酸甜度、皮厚薄、水分、大小均匀度、烂果率。
- 试单要求：现场或到店抽切2～3个，别只看外表。
- 问清产地和批次，橙子不同批次口感差异大。

## 3. 到店验收必须做
- **当场抽检**：每箱随机翻到底层，不只看上面。
- **拍照留证**：到货时间、箱体、坏果、规格对比都拍。
- **记录数据**：每箱净重、坏果数、可售率、实际售价、当天卖完没有。
- **坏果当场分开**：让供货商明确是补货、扣款还是下次抵扣，别口头说“下次再说”。

## 4. 谈供货商时问清楚这几句
1. 这批货是净重还是毛重？箱皮、纸托算不算重量？
2. 坏果率多少以内你负责？超出怎么赔？
3. 送货到店还是自提？几点送？临时补货多久能到？
4. 价格是当天价还是锁价？第二天涨价怎么算？
5. 结款是现结、周结还是压一批？退换货怎么走？
6. 能不能固定批次和产地？换批次提前说不说？

## 5. 试单判断标准
试单后按这几个指标选：
- **可售率**：比如100斤到店，坏果和损耗多少，实际能卖多少。
- **口感稳定性**：第二次补货是否和第一次一致。
- **损耗承担**：出问题是否爽快处理，比价格低更重要。
- **送货稳定性**：是否准时、是否临时换货。
- **毛利空间**：按你店实际售价算，去掉损耗后还有没有利润。

## 6. 建议的试单节奏
- 第1天：2～3家各拿小批量，记录到货质量。
- 第2～3天：看销售速度、损耗、顾客反馈。
- 第4～7天：让表现好的那家补第二次货，验证稳定性。
- 第2周：选1家主供、1家备选，先别签长期独家。

一句话：**第一次试单不是比谁便宜，而是比谁送货稳、坏果认账、第二批货还一样好。** 先把香蕉这种高损耗品试明白，再扩到苹果橙子。
