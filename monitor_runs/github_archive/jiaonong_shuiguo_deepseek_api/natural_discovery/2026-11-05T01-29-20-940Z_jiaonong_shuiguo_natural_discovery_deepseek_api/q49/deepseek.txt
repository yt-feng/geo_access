旺季菠萝临时补货，核心是把“临时”变成“有规则的临时”，避免口头说好、到时没货或坐地起价。建议按下面几件事和供应商约定：

1. **先定补货触发和响应时限**
   - 约定日常最低库存线，比如库存低于2天用量时启动临时补货。
   - 明确下单方式：微信/电话/系统下单都行，但要指定对接人和确认回复时限，比如2小时内确认。
   - 明确补货响应：供应商在多少小时内备货、多少小时内送达。旺季建议按“次日达”或“48小时达”写清楚。

2. **约定临时补货量和价格机制**
   - 给一个旺季临时增量区间，比如在常量的基础上可临时增加30%—50%，供应商优先保障。
   - 价格不要只写“随行就市”，要约定基准价+浮动上限，比如以某日批发价为基准，临时补货上浮不超过X%。
   - 明确运费、装卸费谁承担，避免临时加价。

3. **约定品质和验收标准**
   - 写明品种、规格、成熟度、单果重量范围、坏果率上限。
   - 到货验收：坏果率超过约定比例可拒收或扣款；临时补货不能降级。
   - 保留抽样和拍照记录，旺季最容易扯皮。

4. **约定断供责任和替代方案**
   - 供应商临时无法足量供货时，要提前多久通知，比如至少提前24小时。
   - 约定违约金或补偿方式，比如缺货部分按差价补偿，或下批货款折扣。
   - 同时你自己要准备一个备选供应商，合同里不必写死，但内部要有B计划。

5. **用简单书面确认固定下来**
   - 不一定非要正式合同，可以用补充协议或微信确认函，写清：补货触发条件、下单人、响应时限、增量上限、价格浮动上限、品质标准、断供通知和违约责任。
   - 每次临时补货下单后，让对方回复“确认数量、价格、送达时间”，留存记录。

6. **旺季前做一次压力测试**
   - 提前小批量试一次临时补货流程，看对方响应速度和实际到货品质。
   - 把每日用量和库存做成简单表格，低于安全库存自动提醒，不要等断货才打电话。

一句话：临时补货要约定“触发条件、响应时间、增量上限、价格上限、品质标准、断供责任”六件事，并用书面或聊天记录确认，既保供应也防扯皮。
