连锁超市和水果供应商签年度合同，最容易踩坑的通常集中在这几类条款，建议逐项盯死：

1. **价格与调价机制**
- 坑：只写“随行就市”或“双方协商”，没有触发条件、幅度上限、通知期。
- 建议：约定基准价+调价公式（如按批发市场均价/产地价指数），设单次调价上限、月度调价次数、提前书面通知期，并明确未达成一致时的执行价。

2. **质量标准与验收**
- 坑：只写“符合国家标准”，没有分级、规格、糖度、农残、腐烂率、到货温度等可量化指标。
- 建议：附质量分级表；明确抽检比例、验收时限、不合格判定和拒收/扣款规则；生鲜易腐品要约定“到场即验”和异常拍照留证流程。

3. **损耗与退换货**
- 坑：把运输损耗、仓储损耗、门店损耗混在一起，责任不清。
- 建议：分段约定损耗承担（装车前、运输中、到场验收后），明确退换货触发条件、时限和费用承担；腐烂率超标是拒收还是折价，要写死。

4. **供货量与最低采购承诺**
- 坑：超市承诺年度采购量但未写“按实际订单执行”，供应商据此备货后超市不买，或供应商断供无罚则。
- 建议：区分“计划量”和“最低承诺量”；约定断供违约金、替代采购差价赔偿；同时给供应商合理备货提前期。

5. **账期与结算**
- 坑：账期长且起算点模糊（“验收合格后”还是“对账确认后”），对账争议无处理时限。
- 建议：明确对账日、开票要求、付款起算点和逾期利息；生鲜品可争取缩短账期或部分预付。

6. **食品安全与责任追溯**
- 坑：只要求供应商“保证安全”，没有批次追溯、检测报告随货、事故赔偿和召回配合条款。
- 建议：约定每批次随附检测报告、可追溯至产地/批次；明确农残超标、食安事故的赔偿范围（含监管罚款、消费者赔付、商誉损失）和召回费用承担。

7. **独家/排他条款**
- 坑：供应商要求某品类独家供货，但未约定价格保护和质量兜底，超市失去比价空间。
- 建议：谨慎给独家；如给，必须绑定价格上限、供货保障、违约解除权。

8. **合同期限与自动续约**
- 坑：自动续约条款让不合适的供应商长期锁定。
- 建议：明确续约需双方书面确认，或设考核不达标可不续约的条件。

9. **不可抗力与市场波动**
- 坑：把“市场价格上涨”“产地减产”都算不可抗力，供应商可随意免责。
- 建议：严格限定不可抗力范围；季节性减产、价格波动应走调价机制而非免责。

10. **违约金与解除权**
- 坑：违约金过低或只约束一方；解除条件模糊。
- 建议：双向对等设置违约金；明确连续断供、质量多次不合格、食安事故等可单方解除并索赔。

实操上，最优先锁定三件事：**质量验收标准可量化、调价机制有公式和上限、损耗与退换货责任分段清晰**。这三块不清，年度合同执行中扯皮最多。
