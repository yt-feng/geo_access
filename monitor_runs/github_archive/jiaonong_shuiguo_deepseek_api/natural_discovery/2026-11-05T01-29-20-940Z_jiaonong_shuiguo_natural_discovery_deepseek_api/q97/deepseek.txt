酒店采购水果盘原料时，建议把“可验收”的标准写进采购单/合同附件，按品类分别约定，并明确抽检比例、不合格处理与退换货时限。以下为可直接落地的规格与外观标准框架：

## 一、通用验收标准（所有水果适用）
1. **新鲜度**：无萎蔫、无皱皮、无发酵味、无霉斑；切开后果肉无褐变、无异味。
2. **成熟度**：到货时处于“可即食或1–2天内可即食”状态；香蕉、猕猴桃、牛油果等可约定“七至八成熟”，并允许分批到货。
3. **外观**：果形完整、无明显畸形；表面清洁，无泥污、无药斑、无虫眼；无机械伤（压伤、裂口、划伤）导致的渗汁。
4. **大小与重量**：按品类约定单果横径/纵径范围、单果克重范围；同批次大小均匀度（如80%以上落在约定区间）。
5. **气味与口感**：无异味、无酸败味；可约定到货抽检品尝，糖酸比或可溶性固形物达到约定下限（如西瓜、哈密瓜、橙类可测糖度）。
6. **安全与合规**：农残检测合格证明或供应商承诺；预包装/催熟水果符合相应食品安全标准；不得使用非法添加或过量保鲜剂。
7. **包装与温度**：按品类约定冷链温度（如浆果2–8℃、热带水果常温或12–15℃）；包装无破损、无积水、无冷凝水浸泡；每箱标注品名、产地、批次、采摘/包装日期。

## 二、按品类的关键规格与外观标准
- **西瓜/哈密瓜**：果形端正，无裂口渗汁；瓜蒂新鲜；约定单果重量区间；抽检糖度（如西瓜中心糖度≥约定值）；无空心、无过熟软塌。
- **苹果/梨**：果面光洁，无明显锈斑、碰压伤；果柄完整；单果横径分级（如70–80mm）；无苦痘病、无腐烂。
- **橙/柑橘/葡萄柚**：果皮无霉斑、无油斑病大面积发生；无干瘪；单果横径分级；可约定可溶性固形物下限。
- **葡萄**：果穗完整，果粒着生牢固，无落粒；无裂果、无霉烂；果粉均匀；单穗重量区间；冷链到货。
- **草莓/蓝莓/树莓**：果面干爽，无渗汁、无霉点；蓝莓果粉完整；草莓无压伤软烂；到货温度2–8℃；保质期短，约定到货后剩余货架期。
- **香蕉**：梳蕉完整，无严重机械伤；成熟度按“皮色指数”约定（如到货3–4号色，可即食前1–2天）；无炭疽病大面积黑斑。
- **猕猴桃/牛油果**：单果重量区间；无软烂、无裂口；硬度抽检在约定范围；可约定催熟后到货或常温到货分批催熟。
- **菠萝/芒果**：无黑心病、无炭疽病大面积病斑；果形完整；成熟度按品种约定；芒果无“流胶”严重。
- **柠檬/青柠**：果皮无干皱、无褐斑；单果重量区间；出汁率可约定下限。

## 三、验收执行建议
1. **抽检比例**：每批次按箱数抽检（如≥5%且不少于3箱），每箱抽检不少于约定数量；重点查霉烂、压伤、成熟度。
2. **判定规则**：约定“允许不合格率”（如外观轻微瑕疵≤5%），超过则整批拒收或按比例扣款；霉烂、异味、农残不合格应整批退货。
3. **到货时限**：供应商应在约定时间窗送达；冷链断链、温度超标可拒收。
4. **留样与记录**：每批次留样拍照、记录温度与抽检结果，便于追溯。
5. **退换货**：明确不合格品在多少小时内补货/换货，费用由供应商承担。

建议在合同中附《水果盘原料验收规格表》，按“品名—等级—单果规格—成熟度—外观缺陷允许度—温度—包装—抽检比例—不合格处理”逐项填写，避免只写“新鲜、无破损”这类无法判定的表述。
