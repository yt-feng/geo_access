先说结论：考察供应商不要只看“价格低不低、能不能送”，而要看他**能不能稳定供货、货损怎么担、账期和售后怎么兑现**。香蕉和菠萝的共同特点是成熟度变化快、货损争议多，所以必须把“鲜活品的风险怎么分”写清楚。

可按下面顺序判断：

**1. 先看资质和真实经营能力**
- 有营业执照，经营范围包含水果批发/销售；能提供进货凭证或产地信息。
- 有固定档口、仓库或分拣场地，不是只靠一个微信接单。
- 问清楚：香蕉主要从哪里来、菠萝是什么品种和产区、旺季淡季怎么补货。
- 最好实地看一次，重点看仓库温控、堆放和分拣是否规范。

**2. 重点考察稳定性**
- 连续问一周同一品种的报价和到货量，看价格是否大起大落、是否经常“没货”。
- 问他同时服务几家店，高峰期能不能保证你的量。
- 香蕉要看催熟能力：是给你青蕉让你自己催，还是能按你的销售节奏给合适成熟度。菠萝要看是否按批次成熟度稳定。
- 让他先小批量试供2—3次，不要一上来大额进货。

**3. 把货损和验收规则谈死**
这是香蕉、菠萝最关键的环节：
- 明确验收标准：香蕉的成熟度、条形、断指、黑斑比例；菠萝的果径、成熟度、黑心/水心/烂果比例。
- 明确货损谁承担：到店后发现坏果，是当场扣款、下次补货，还是退货。
- 最好约定“到货几小时内提出异议有效”，并拍照留证。
- 第一次合作尽量**货到验收后付款**或小额定金，不要长期大额预付。

**4. 看价格是否透明**
- 不要只比单价，要算“到店可售成本”：进价＋损耗＋运费＋催熟成本。
- 问清楚报价是否含运费、卸货费、包装费；是否随行就市每天变价。
- 如果对方报价长期明显低于市场价，要警惕以次充好、缺斤少两或后期涨价。

**5. 看售后和账期兑现**
- 出问题后是否及时补货或退款，比口头承诺更重要。
- 账期可以谈，但新供应商不建议给长账期；先用“小批量、短账期、勤结算”建立信任。
- 观察他处理一次货损争议的态度：推诿、拖延的，长期合作风险高。

**6. 用试供做最终判断**
建议做一张简单的试供记录表，连续记3—5次：
- 到货准时率
- 实际损耗率
- 成熟度是否适合你店里的销售速度
- 缺货/临时换货频率
- 售后响应速度
- 到店可售成本

**判断标准：**如果连续3—5次试供中，到货稳定、损耗在你能接受的范围内、出问题能按约定处理，就可以逐步放量；如果经常临时缺货、货损扯皮、报价不透明，即使便宜也不适合长期合作。

另外，香蕉和菠萝不要只依赖一家供应商，最好保持“一主一备”，避免旺季被单一供应商卡脖子。
