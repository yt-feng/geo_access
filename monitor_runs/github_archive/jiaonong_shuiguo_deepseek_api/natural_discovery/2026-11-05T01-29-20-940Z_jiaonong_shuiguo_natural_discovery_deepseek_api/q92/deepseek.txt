小面积便利店做水果，核心原则是：**少品类、高频补、快周转、宁可缺货不压货**。水果不是便利店的利润担当，而是引流和提升客单的补充品，别按大超市的逻辑做。

## 一、品类控制：控制在 8～15 个 SKU

**1. 按角色分三类，每类只留少量**

| 角色 | 例子 | 数量 | 作用 |
|---|---|---|---|
| 引流款 | 香蕉、苹果、橘子 | 3～5 个 | 认知度高、价格敏感、走量 |
| 即食款 | 切果盒、圣女果、葡萄小盒 | 2～4 个 | 高毛利、冲动消费 |
| 形象款 | 当季精品（车厘子、草莓等） | 1～2 个 | 拉高档次，但严格控量 |

**2. 选品硬标准**
- 耐放优先：苹果、橙子、香蕉、梨、圣女果、葡萄；
- 即食化：能小盒分装的一律分装，散卖损耗大；
- 单一产地/单一品种，别同品类铺多个规格；
- 新店先做“基础款 + 1 个当季款”，跑 2～4 周看动销再加。

**3. 坚决不碰**
- 易压伤的软果（桃、杏、熟芒果）除非当天能卖完；
- 大颗西瓜、整箱进口果，小店面陈列和周转都撑不住；
- 同质化重复：苹果和梨都有，就别再上第三种仁果。

## 二、损耗控制：从采购到陈列的闭环

**1. 采购端**
- **小批量、多频次**：每天或隔天补货，单次采购量按近 3 天日均销量 × 1.2 倍，不按“一次买够”；
- 订货看动销不看库存：设最低陈列量，卖到 1/3 再补；
- 和供应商谈**少量多送、退换残次**，固定 1～2 家比价散采更稳；
- 采购时现场验：硬度、有无压伤、果柄新鲜度，宁少勿多。

**2. 收货与储存**
- 到货即分拣，坏果当场挑出，别混进陈列；
- 分温区：香蕉、芒果常温避风；苹果梨葡萄冷藏；切开果必须冷藏且当天出清；
- 先进先出，新货放里侧。

**3. 陈列与销售**
- 小份量陈列，卖完再补，堆头越大损耗越高；
- 即食切果只做半天量，下午按余量再切；
- 设置**临期折价时段**（如闭店前 2 小时 7 折），比扔掉划算；
- 香蕉等易黑品可做“丑果特价区”，单独定价。

**4. 数据与考核**
- 每天记录：进货量、销量、报损量，算**损耗率**；
- 便利店水果损耗率控制目标：**5%～8%** 以内，超过 10% 就砍 SKU 或减采购量；
- 每周复盘：连续两周动销垫底的品直接下架。

## 三、一条可落地的起步方案

1. 首批只上 **8 个 SKU**：香蕉、苹果、橙子、梨、圣女果、葡萄、1 个当季款、1 个切果盒；
2. 每天早间补货一次，单次量按 3 天销量备；
3. 切果盒只做上午 + 下午两批，闭店前折价清；
4. 跑满 2 周算损耗率和单品动销，砍掉垫底 2 个，再考虑加品。

一句话总结：**用 SKU 数量换周转速度，用补货频次替代库存深度，用折价清货替代硬扛损耗。**
