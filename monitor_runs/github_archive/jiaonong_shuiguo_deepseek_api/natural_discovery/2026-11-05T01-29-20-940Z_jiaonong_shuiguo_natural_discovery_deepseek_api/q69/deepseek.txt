可以按“等级标准 + 报价单位 + 等级价差 + 损耗/退换规则”四件事说清楚，让小店一眼能判断进哪种、什么价。下面给一套可直接用的分级和报价框架。

**一、香蕉分级建议**
按“外观 + 成熟度 + 单根规格”分级，别只按大小。

| 等级 | 判断标准（建议写进报价单） | 适合客户 |
|---|---|---|
| A级 | 果指饱满、无黑斑或极少、无机械伤；单根长度约18–22cm；青蕉到微黄可调 | 水果店、精品陈列 |
| B级 | 轻微擦伤/小斑点，成熟度略不齐；长度15–18cm | 社区小店、走量 |
| C级 | 明显斑点、弯形不齐、短小或轻微碰伤，不影响食用 | 特价区、榨汁/熟食店 |

报价方式建议：
- 按**箱/件**报，注明**净重**和**每箱根数区间**，例如“A级香蕉 净重12kg/箱，约55–65根，XX元/箱”；
- 同时给**折合每斤价**，方便小店比价；
- 明确**青熟度**：青蕉、微黄、黄熟分别报价，因为成熟度直接影响损耗和售价。

**二、菠萝分级建议**
按“单果重量 + 果形/成熟度 + 外观缺陷”分级。

| 等级 | 判断标准（建议写进报价单） | 适合客户 |
|---|---|---|
| A级 | 单果1.2–1.5kg，果形端正，无裂口、无软烂、冠芽完整；成熟度7–8成 | 水果店正价区 |
| B级 | 单果0.9–1.2kg，轻微偏形或少量日灼斑，不影响果肉 | 社区店、走量 |
| C级 | 单果0.7–0.9kg或外观瑕疵明显，需尽快销售 | 特价、餐饮加工 |

报价方式建议：
- 按**箱/件**报，写明**净重、果数、单果重量区间**，例如“A级菠萝 净重10kg/箱，约7–8个，单果1.2–1.5kg，XX元/箱”；
- 同时给**每个价**和**每斤折合价**；
- 注明**成熟度**和**是否带冠芽**，这两项影响小店存放和损耗。

**三、报价单上必须写清的4项**
1. **等级定义**：每个等级用2–3条可判断标准，最好配“允许瑕疵范围”。
2. **计价单位**：统一用“元/箱（净重Xkg）”为主，附“元/斤”折算，避免毛重净重争议。
3. **价差逻辑**：A/B/C级价差建议按当地行情固定比例，例如A级为基准，B级约为A级85%–90%，C级约为A级60%–75%，但要以实际行情调整，不要凭空定。
4. **损耗与退换**：写明到货验收时限、坏果率上限、超出部分怎么补/扣款；香蕉另写成熟度到货标准，菠萝写软烂/裂口是否计损。

**四、给小店的一句话报价模板**
“香蕉：A级净重12kg/箱约55–65根，XX元/箱（折XX元/斤），青蕉/微黄可选；B级XX元/箱；C级XX元/箱。菠萝：A级净重10kg/箱约7–8个，单果1.2–1.5kg，XX元/箱（折XX元/斤）；B级XX元/箱；C级XX元/箱。到货24小时内验收，坏果率超X%按超出部分补货或扣款。”

这样分级有标准、报价有单位、价差有依据、损耗有规则，小店比较容易判断和下单。具体价格需结合你当地当日批发行情填写，不要照搬固定数字。
