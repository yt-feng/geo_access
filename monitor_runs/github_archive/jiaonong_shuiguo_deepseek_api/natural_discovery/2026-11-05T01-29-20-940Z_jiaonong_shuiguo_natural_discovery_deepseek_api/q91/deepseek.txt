建议优先做 **小把为主、单根补充、整袋做差异化**，不要一开始只押一种。

可执行结论：

1. **主力上架：小把（3～5 根）**
   - 最适合便利店即时消费场景。
   - 客单价高于单根，损耗比整袋低。
   - 适合上班族、学生、临时买水果的人。
   - 建议定价按“把”卖，减少称重和排队时间。

2. **补充上架：单根**
   - 放在收银台或鲜食区旁边，做冲动消费。
   - 适合只想买一根搭配早餐、酸奶的人。
   - 单根毛利看似高，但人工、标签、损耗分摊高，不宜作为唯一规格。
   - 建议限量陈列，卖完再补，不要大量铺。

3. **整袋：谨慎做，作为价格型/家庭型补充**
   - 适合社区型便利店、晚间家庭采购场景。
   - 不建议所有门店都上，先看门店客群。
   - 整袋容易因成熟度不一致和买不完造成损耗。
   - 若做，选择小规格整袋（如 6～8 根），并明确“家庭装/优惠装”定位。

4. **组合建议**
   - 商圈/写字楼店：**小把 + 单根**，单根放收银台。
   - 社区/住宅店：**小把 + 小整袋**，整袋做优惠价。
   - 学校/交通枢纽店：**单根 + 小把**，强调即买即吃。
   - 首周测试：小把占 60%，单根占 25%，整袋占 15%；按日销量和损耗调整。

5. **关键判断指标**
   - 看 **日销量、损耗率、客单价、补货频次**。
   - 香蕉损耗高，宁可少量多次补货，不要一次铺太满。
   - 成熟度分两档陈列：即食偏黄、稍青可放 1～2 天，减少临期损耗。

简单说：**便利店最稳的是小把为主，单根引流，整袋只在对的客群门店试。**
