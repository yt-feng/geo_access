可以，但通常不是“供应商单方面无偿全包”，而是按品类、销量、合作层级谈支持方式。给你可执行判断：

1. **陈列支持**
   - 常见形式：供应商提供陈列道具/堆头物料、陈列图建议、派人协助周末堆头。
   - 费用：小供应商多半只给物料和陈列建议；大供应商或重点单品可承担部分陈列费、端架费。
   - 你要提前确认：道具归属、是否回收、陈列期限、是否绑定进货量。

2. **海报/宣传支持**
   - 常见形式：供应商提供产品图片、卖点文案、海报模板、线上素材；重点促销可分摊海报/DM/社群投放费用。
   - 注意：海报价格、规格、活动档期要书面确认，避免供应商素材与门店实际售价不一致。
   - 若供应商出费用，通常要求露出品牌或主推其单品。

3. **试吃支持**
   - 生鲜水果试吃较常见，供应商可提供试吃品、一次性物料、促销员或承担部分试吃损耗。
   - 关键约定：试吃损耗比例、试吃品是否计入进货、促销员费用谁承担、食品安全责任和保质期要求。
   - 高损耗水果如草莓、葡萄、切果类，供应商一般愿意配合试吃，但会换促销排面或销量承诺。

**谈判建议：**
- 先按“重点促销单品”谈打包支持：堆头陈列+海报素材+周末试吃，比单次要支持更容易拿到。
- 写入促销协议：支持内容、数量、费用、时间、验收标准、是否绑定最低进货量。
- 不要只口头承诺；试吃尤其要确认食品安全、人员健康和损耗归属。

一句话：能提供，但你要把“支持形式、费用分担、绑定条件、责任归属”谈清楚。
