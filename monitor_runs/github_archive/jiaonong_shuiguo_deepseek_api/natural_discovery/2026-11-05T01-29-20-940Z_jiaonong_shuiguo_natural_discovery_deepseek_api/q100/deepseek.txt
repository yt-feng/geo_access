要减少香蕉熟过头浪费，核心是“少量多次采购 + 分级成熟度收货 + 按成熟度分流使用”。可执行做法：

1. **按用量定采购量，少量高频**
   - 按前2周实际消耗量定日均用量，采购量控制在日均用量的1.5～2天，不要一次囤一周。
   - 每周固定2～3次到货，夏天可增加到每周3～4次。

2. **收货时按成熟度分级，不只看外观**
   - 要求供应商把香蕉分成“偏生、适熟、即食”三档供货，例如：偏生（果皮基本青绿、果肉硬）、适熟（黄中带绿、适合2～3天内用）、即食（全黄、少量斑点，当天用）。
   - 验收时抽检果指硬度、果柄状态、有无黑斑和机械伤。拒绝“整车同一成熟度”的大批量到货。

3. **按成熟度分流使用**
   - 偏生：常温存放，后排先用；可用纸箱或布遮盖催熟，避免暴晒。
   - 适熟：优先做水果、酸奶搭配、烘焙原料。
   - 即食/斑点蕉：当天做成香蕉牛奶、香蕉面包、香蕉燕麦粥、蒸糕等，或冷冻保存做奶昔。
   - 有轻微碰伤的香蕉优先内部加工，不要继续陈列。

4. **储存上控温控湿、分开催熟**
   - 香蕉适宜存放约12～15℃，食堂不具备条件时放阴凉通风处，避免冷藏导致表皮变黑。
   - 未熟和已熟香蕉分开放，熟香蕉不要和苹果、梨等催熟水果混放。
   - 悬挂或单层摆放，减少压伤；不要用塑料袋密封，防止水汽积聚。

5. **建立“临期熟蕉”处理机制**
   - 每天闭餐前检查一次，把次日必须用完的香蕉标记出来。
   - 设定替代菜单：熟蕉优先用于早餐奶昔、下午加餐、烘焙，而不是继续做餐后水果。
   - 提前和档口/烘焙间约定“熟蕉消化量”，例如每天最多处理多少公斤。

6. **供应商条款**
   - 合同里写明成熟度分级、到货抽检标准、不合格退换货；可要求供应商配合小批量多批次配送。
   - 对连续到货过熟的供应商减少订单或更换。

一句话：**把“一次买很多”改成“按成熟度分批到、按成熟度分用途用”，熟蕉当天进入加工渠道，基本就能把浪费压下来。**
