先看一个总原则：**坏果责任不是“谁弱谁有理”，而是按“交付时风险转移 + 是否属于运输/仓储/商品本身问题 + 顾客是否及时验收举证”来划分。** 生鲜电商通常对“到货即坏”承担首问责任，但可以根据实际原因向供应商、承运方追偿；顾客则需要及时拍照、保留实物并在约定时效内反馈。

具体可分四类判断：

1. **到货签收前/开箱即发现坏果**
   - 一般由商家承担。因为消费者尚未实际取得合格商品，商家应负责退款、补发或按坏果比例赔付。
   - 若外包装明显破损、渗漏、异味，顾客应当场拒收或拍照留证；拒收后责任主要在商家和承运方之间划分。
   - 商家不能简单用“生鲜不退不换”免责，除非已显著提示且坏果不属于商品质量问题。

2. **签收后短时间内发现内部腐烂，外观正常**
   - 先看商家承诺的售后时效，如“签收后24小时内坏果包赔”。顾客在时效内拍照/视频并提供坏果比例，商家通常应赔。
   - 若顾客延迟数天才反馈，且无法证明到货时已坏，责任可能转向顾客储存不当，商家可拒赔或协商部分赔付。
   - 水果“个别自然损耗”与“批量坏果”要区分：少量轻微瑕疵通常按比例补偿；大面积腐烂、霉变、异味则更可能是商品或冷链问题。

3. **运输环节导致**
   - 如暴力分拣、冷链断链、延误导致腐坏，商家对顾客先承担责任，再依据承运合同向物流方追偿。
   - 顾客一般不需要直接找快递公司索赔，除非是到付/自提等特殊约定。

4. **顾客自身原因**
   - 签收后长时间常温存放、未按说明冷藏、反复开箱、超时未取件等造成的坏果，责任在顾客。
   - 但商家需举证说明储存要求已明确告知，且坏果与顾客行为有因果关系，不能仅凭推测拒赔。

**可执行的处理建议：**
- 顾客：签收时拍外包装和开箱视频；坏果与好果分开拍照，保留坏果；在售后时效内提交订单号、照片、坏果数量/比例。
- 商家：设置清晰的坏果赔付规则，按比例赔或补发；对批量投诉倒查批次、供应商和冷链；保留签收时间、温控和物流记录。
- 平台：优先适用平台售后规则；商家不能以格式条款一概免除坏果责任。

一句话：**到货即坏、批量腐烂、冷链/运输问题，主要由商家对顾客负责；顾客超时反馈或储存不当，顾客担责；商家赔付后可向供应商或物流追偿。**
