连锁商超招长期水果供应商，评分标准建议围绕“长期稳定供货能力”设计，而不是单纯比价。可按100分制设置，参考如下：

**一、商务与资质 10分**
- 营业执照、食品经营/生产许可、种植/合作社资质、检验检测能力：4分
- 近2年无重大食品安全处罚、无严重失信记录：3分
- 合作意愿与响应机制，如是否接受年度框架协议、账期、退换货条款：3分

**二、供货保障能力 30分**
- 自有基地/长期合作基地面积、产区分布、品种覆盖：8分
- 年供应能力与招标品类/预估采购量匹配度：6分
- 冷链仓储、分拣加工、运输能力及到店时效：6分
- 淡旺季、极端天气、节假日保供方案和备选产区：6分
- 断货应急与替代方案、履约保证金/违约承诺：4分

**三、质量与食品安全 25分**
- 农残检测体系、批次检测报告、可追溯体系：8分
- 质量标准与验收标准是否明确，如糖度、规格、外观、损耗率：6分
- 食品安全管理制度、召回机制、保险：5分
- 过往供货质量稳定性、客诉率、退货率：6分

**四、价格与成本 20分**
- 报价水平及价格构成透明度：8分
- 价格调整机制是否合理，如随行就市、周期调价、锁价比例：6分
- 损耗承担、运费、包装、退换货成本：4分
- 账期与结算条件：2分

注意：长期供应商不宜“最低价中标”，价格分控制在20%左右较合适，避免低价切入后质量下滑。

**五、服务与协同 10分**
- 订单响应、补货频率、临时加单能力：3分
- 驻场/对接人员配置、信息化对接能力：3分
- 促销档期、新品导入、陈列支持：2分
- 售后处理时效：2分

**六、可持续发展与长期合作 5分**
- 种植计划与商超采购计划的协同能力：2分
- 食品安全、环保、用工合规：2分
- 长期合作承诺与投入，如专用包装、定制规格：1分

**关键设置建议：**
1. 设**资格门槛**：食品许可、检测报告、无重大处罚、最低供货能力，不满足直接废标。
2. 设**否决项**：虚假资质、重大食品安全事故、无法提供可追溯证明。
3. 价格分不宜过高，建议20分左右；质量、供货保障合计不低于50分。
4. 要求投标方提供**近6个月真实供货案例、检测报告、基地证明、保供预案**，并保留现场考察权利。
5. 评分细则尽量量化，如“自有基地≥500亩得X分”，避免主观打分。
6. 中标后设**3—6个月试用期**，将评分承诺写入合同，未达标可淘汰或扣款。

整体权重可简化为：资质10、供货保障30、质量安全25、价格20、服务10、长期合作5。这样既能筛出稳定供应商，又不会陷入纯低价竞争。
