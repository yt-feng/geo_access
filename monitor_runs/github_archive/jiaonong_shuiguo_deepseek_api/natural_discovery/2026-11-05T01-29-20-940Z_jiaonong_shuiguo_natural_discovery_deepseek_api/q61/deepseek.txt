判断香蕉一手货源稳不稳，别只看对方怎么说，重点核这几项，能当场验证的优先验证：

1. **看产地控制力**
   - 问清是自有基地、长期包园，还是市场倒手。
   - 要求看基地照片/视频不够，最好视频通话看蕉园、催熟库、包装线，并让对方说明具体产区、面积、月供量。
   - 一手货源通常能说清“哪片产区、什么品种、什么规格、什么时候有货”。

2. **看供货节奏是否匹配你**
   - 让对方给出近3个月每周实际发货量、主要规格（如7-9把/箱、单根重、青蕉成熟度）。
   - 问旺季/雨季/台风季怎么保供，是否有备用产区。
   - 稳定供货方敢给“最低周供量+缺货补偿/替代方案”，只承诺“要多少有多少”的要警惕。

3. **看催熟和品控能力**
   - 批发档口要的是到货后可催熟、货架期稳定。问清催熟库容量、批次管理、出库成熟度标准。
   - 要求先小批量试单，连续2-3批看：青蕉均匀度、机械伤、条蕉饱满度、催熟后色差和软硬一致性。

4. **看合同和结算是否规范**
   - 稳定供货方通常有明确规格、验收标准、损耗处理、到货时限、价格随行就市机制。
   - 警惕要求大额预付、临时加价、不给验货就催款。
   - 首次合作建议小单现结或短账期，别一上来押大额保证金。

5. **看物流和到货记录**
   - 问发货地、常用物流/冷链方式、到货时效、夏季高温和冬季寒潮怎么处理。
   - 要求提供近期真实发货单/物流单（可打码），并随机抽一单核对时间、数量、到货地。

6. **做交叉验证**
   - 让对方给2-3个同城或邻近市场的老客户，你侧面问：缺货频率、质量波动、售后是否扯皮。
   - 查企业资质、经营年限、是否有固定档口/冷库；个人贩子不是不能合作，但要把验收和付款节点卡紧。

7. **用试单做最终判断**
   - 连续试3批，每批记录：到货损耗率、催熟合格率、实际供货比承诺少多少、售后响应时间。
   - 三项稳定再谈长期价和账期。稳定供货的核心不是价格最低，而是“规格稳定、缺货有预案、售后不赖账”。

一句话：**能带你看真实产地/催熟库、敢签规格和保供条款、经得起连续小批量试单和客户回访的，才叫稳定一手货源。**
