可以做一个“**基础刚需 + 关联搭配 + 分级套餐**”的组合促销，不建议只做简单捆绑降价。香蕉、菠萝、苹果的消费场景不同，组合促销要围绕“顺手多买”和“提升客单”设计。

### 1. 主推套餐：设计三档，拉开客单

**A. 9.9元尝鲜组合**
- 香蕉2根 + 苹果1个 + 菠萝切块1小盒
- 目的：降低尝试门槛，带动切果/小份装销量。
- 注意：标“限量/每日X份”，避免无限量拉低毛利。

**B. 19.9元家庭果盘组合**
- 香蕉1把（约1kg）+ 苹果3个 + 菠萝1个或半只
- 目的：覆盖家庭一周水果需求，是提升客单的主力。
- 可加一句：“比单买省3—5元”，具体以门店价格核算，不要虚构。

**C. 29.9元办公室/聚会组合**
- 香蕉1把 + 苹果6个 + 菠萝1个 + 免费切盒服务或赠送1份菠萝切块
- 目的：拉高客单，适合周末、团购、办公室场景。

### 2. 用香蕉做“引流”，用苹果做“利润”，用菠萝做“场景”
- **香蕉**：价格敏感、购买频次高，可做“加1元多1把”或“买苹果加购香蕉享特价”，用来带动客流。
- **苹果**：耐储存、家庭常备，适合做“满2斤送菠萝切块券”或“苹果+菠萝”组合，提升客单。
- **菠萝**：现场切盒、试吃引流，和苹果组合成“酸甜果盘”，提高冲动购买。

### 3. 促销机制：满额升级，而不是直接打折
建议设置：
- 单买三样不优惠；
- 买“苹果2斤+香蕉1把”送菠萝切块5折券；
- 满29元免费切盒；
- 满39元送小份菠萝或苹果1个。

这样比“三样一起打折”更容易提高客单价，也保护毛利。

### 4. 陈列和话术
- 三品集中陈列，打“早餐果 / 家庭果盘 / 办公室果盒”标签；
- 香蕉旁边放苹果和菠萝切盒，做动线关联；
- 话术用：“香蕉配苹果，再加菠萝切盒，满29免费切好带走。”

### 5. 关键控制点
- 香蕉损耗高，组合里不要放太多，避免顾客只挑香蕉；
- 菠萝切盒要控制出品量，按小时补货；
- 每天记录三档套餐销量、客单价、毛利，连续3天不动销就调组合；
- 不要虚构“省多少”，按门店实际售价核算。

**最可直接执行的方案：**
先上“19.9元家庭果盘组合”作为主推，配“满29元免费切盒”，再用9.9元小组合引流。跑一周后看套餐销量和客单变化，再决定是否加29.9元聚会组合。
