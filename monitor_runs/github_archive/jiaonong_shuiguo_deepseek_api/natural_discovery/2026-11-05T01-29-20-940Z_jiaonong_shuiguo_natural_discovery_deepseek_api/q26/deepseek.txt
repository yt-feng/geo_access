做小包装香蕉，采购和包装要围绕“少进货、快周转、控压伤”来做。重点注意这些：

1. **规格先定小**
   - 单份建议 **2–3根、约400–600克**，家庭一次吃完，减少剩半根。
   - 按根卖容易大小不均，按份卖要抽检单份重量，别让顾客觉得“这袋少”。
   - 可以设两个规格：尝鲜装2根、家庭装4–5根，小包装主推2–3根。

2. **采购成熟度要偏生一点**
   - 社区店周转慢，进货选 **七成熟左右、果身硬、棱角略明显** 的香蕉，到店后自然转黄。
   - 不要进全黄或已起糖斑的货做小包装，分装、搬运、摆架都会加速软烂。
   - 问清供应商催熟批次，尽量同一批成熟度一致，避免一袋里一根黄一根青。

3. **包装要透气、防压、看得见**
   - 优先用 **带透气孔的食品级PE袋/网袋+托盘**，不要完全密封，否则水汽大、易发黑霉变。
   - 袋装不要勒太紧，香蕉最怕挤压和磕碰，果指接触处容易黑斑。
   - 标签贴在袋面或托盘侧面，别直接贴果皮；日期、规格、价格要清楚。
   - 若用托盘覆膜，膜上打孔，且不要抽真空。

4. **分装时机**
   - 到货后先整箱存放、通风散热，**卖前再分装**，不要一次全部分完。
   - 分装时戴手套，轻拿轻放，剔除已有裂口、黑腐、断果的，不要混进小包装。
   - 分装后避免堆叠超过2层，防止下层压伤。

5. **损耗控制**
   - 小包装香蕉损耗主要来自压伤、过熟、冷害和失水。门店温度低时不要放冷柜，香蕉适合 **12–15℃左右通风存放**，低于10℃易冷害发黑。
   - 每天早晚挑一遍，把起斑、软化的先做临期折扣或拆袋散卖，别等坏在袋里。
   - 进货少量多次，夏天尤其缩短补货周期；小包装宁可下午补一次，也不要早上堆满。
   - 记录每批到货日、成熟度、分装量、报损量，连续看一周就能定出合理进货量。

6. **采购合同和验收**
   - 验收看：果指完整、无大面积黑斑、无霉点、果柄不腐烂、箱内无明显水汽。
   - 和供应商约定小包装用果的退换或补损规则，比如到店24小时内黑腐、压伤比例超标可补。
   - 要求供应商提供食品级包装材料证明，袋、托盘、标签都要符合食品接触要求。

简单说：**进偏生货、小份分装、透气防压、少量多次、每天挑损**。先按2–3根一份试卖一周，根据报损和动销再调规格和进货量。
