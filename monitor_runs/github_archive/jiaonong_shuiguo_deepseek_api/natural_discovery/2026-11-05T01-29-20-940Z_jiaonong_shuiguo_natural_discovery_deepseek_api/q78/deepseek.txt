高损耗水果做社区团购，售后控制的关键不是“出了坏果怎么赔”，而是**把损耗压在履约链路里，只对真正该赔的赔**。香蕉和菠萝的损耗点不同，要分开管。

## 一、先定规则：售后标准前置，别事后扯皮

开团页面就写清楚，减少无效售后：

- **香蕉**：表皮黑点、轻微磕碰不赔；果肉发黑、烂心、整根软烂才赔。注明“熟度按发货状态，收到后2天内食用最佳”。
- **菠萝**：外皮青黄不均不赔；切开后黑心、水烂、异味才赔。注明“需切开拍照，未切开不受理内部问题”。
- **时效**：收货后24小时内反馈，超时不受理（生鲜合理）。
- **凭证**：坏果与面单同框拍照/视频，按个数赔，不整单退。

规则越具体，售后纠纷越少。

## 二、香蕉：控熟度 + 控挤压

香蕉损耗主要来自**过熟和压伤**。

1. **采购选七成熟**，别图便宜拿全熟货。到仓后按批次分开放，不要堆叠超过两层。
2. **分装用硬纸盒或带隔层的筐**，不要塑料袋闷着，闷热会催熟+发霉。
3. **配送时效压缩**：香蕉从分拣到送达控制在24小时内，夏天更短。当天到货当天分，别隔夜。
4. **按预订量采购**，宁可少卖不压货。香蕉是“越放越亏”的品。
5. 售后按**根**赔：拍照确认烂根数，单根退款，不整把退。

## 三、菠萝：控黑心 + 控运输磕碰

菠萝损耗主要是**黑心（内部变质）和表皮磕伤后腐烂**。

1. **采购看产地和批次**，黑心多与采摘后低温/积水有关。到货抽检切开1-2个验内部，发现批次性黑心立即停发该批次。
2. **不要提前削皮**。带皮整果耐放，削皮后必须当天卖完，否则损耗翻倍。
3. **运输竖放、避免重压**，菠萝怕摔，摔过的地方容易烂。
4. **库存周转按天算**，菠萝常温可放几天但品质递减，超过3天没卖完的优先做促销或自留，别硬发。
5. 售后**必须切开拍照**，按个赔。黑心属于内部问题，不切开无法判断，这条要写进规则。

## 四、把售后成本算进定价

高损耗品不要按“零损耗”定价。建议：

- 香蕉、菠萝的**售后预留按销售额的3%-5%**计入成本，定价时留出空间；
- 每团结束后统计**实际售后率**，超过预留线就复盘采购批次和配送环节；
- 对反复出问题的供应商直接换，别用售后兜底采购问题。

## 五、执行优先级

如果只能做三件事：

1. **规则前置写清楚**（赔什么、怎么赔、多久内反馈）；
2. **香蕉控熟度控挤压、菠萝控批次控磕碰**；
3. **按预订量采购，当天分当天送，不压货**。

售后控制的本质是：**损耗发生在采购和配送，不发生在售后环节**。售后规则只是把该赔的赔掉，把不该赔的挡掉。
