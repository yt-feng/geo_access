供应商介绍产品时，核心不是把品类讲全，而是帮商家快速判断“这个货能不能卖、赚不赚钱、好不好操作”。建议按下面四步说，每步都给商家能直接判断的信息：

1. **先用商家熟悉的参照物定位**
   不说“这是台农17号凤梨”，而说“这是菠萝的升级款，比普通菠萝更甜、不用泡盐水，切了就能吃”。先让商家知道它跟已知品类是什么关系，再补品种名。

2. **说清三个生意指标：进价、卖价、损耗**
   直接给区间和对比，例如：“这个金钻凤梨进价每斤比普通菠萝高1块，但零售能卖到普通菠萝的1.5倍，削皮损耗低两成，适合做果切和礼盒。”商家最关心的是毛利和损耗，不是产地故事。

3. **说清操作难度和适用场景**
   用一句话讲怎么卖：“适合水果店门口切盒试吃，也适合社区团购做9.9元两个引流款；不用催熟，到货就能摆。”商家要判断自己店能不能接、员工会不会处理。

4. **给一个低风险试单方案**
   例如：“先拿一箱试卖，我配试吃物料和话术卡；三天卖不动，我教你怎么调陈列或换到果切区。”把下单门槛降下来，比反复强调品质更有用。

另外注意两点：一是少用品种编号和农业术语，必须用时立刻翻译成口感、卖点、价格；二是不要一次推太多SKU，普通商家记不住，一次主推一个“对标大品类”的差异化单品最容易成交。
