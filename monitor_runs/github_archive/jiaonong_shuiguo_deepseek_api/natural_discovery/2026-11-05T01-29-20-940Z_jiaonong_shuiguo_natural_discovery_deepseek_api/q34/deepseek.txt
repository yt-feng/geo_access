结论先说：**在商超水果品类里，通常“损耗低”对最终毛利的影響大于“进货价格低”**。但前提是价格低不能以明显牺牲品质为代价。更准确地说：

> **毛利 = 销售额 − 成本 − 损耗损失**  
> 水果是高频、短保、强损耗品类，**损耗是毛利的第一杀手**，采购价只是成本端的一部分。

## 为什么损耗通常更关键

1. **水果损耗杠杆远高于采购价差**
   - 假设售价10元/斤，采购价从6元降到5.5元，毛利率提升约5个百分点。
   - 但如果损耗率从15%升到25%，相当于多损失10%的货值，往往直接把毛利吃回去甚至变负。
   - 低价货如果品质差、货架期短、卖相差，损耗会快速放大。

2. **低价常常伴随隐性成本**
   - 到货成熟度高、伤果多、规格不齐、批次不稳定；
   - 需要更多挑拣、降价促销、报损；
   - 占用冷库和人力，影响周转；
   - 顾客复购下降，损失的是销售额而不只是单品毛利。

3. **水果毛利靠周转和鲜度**
   - 低损耗意味着更高“可售率”、更快周转、更少打折；
   - 同样销售额下，损耗每降1个百分点，几乎直接转化为毛利。

## 什么情况下“价格低”更重要

- 品类是**高周转、耐储、标准化程度高**的品项，如苹果、梨、橙、部分根茎类；
- 你有稳定冷链、强控损能力、快速出货渠道；
- 低价来自产地直采、批量优势，而非品质降级；
- 该品项用于引流，且损耗可控。

## 可执行的判断方法

采购决策不要只看进价，算**“到岸可售成本”**：

> 到岸可售成本 = （采购价 + 运费 + 加工挑拣 + 损耗）÷ 可售率

例子：
- A货：进价6元，损耗15%，可售率85%，到岸可售成本≈7.06元；
- B货：进价5.5元，损耗25%，可售率75%，到岸可售成本≈7.33元。
B看起来便宜，实际更贵。

## 给商超采购的优先级建议

1. **先控损，再压价**：把损耗率、货架期、到货合格率作为硬指标；
2. **分品类定策略**：
   - 叶菜、浆果、桃李等短保高损品：优先低损耗和鲜度；
   - 苹果、梨、橙、瓜类等耐储品：可更重视价格和批量；
3. **看综合毛利，不只看单品进价**：算上损耗、促销、报损、复购；
4. **低价必须可验证**：同一品质标准下比价，否则不是真低价。

**一句话：低价决定你“理论上能赚多少”，损耗决定你“实际能剩下多少”。水果品类里，后者通常更影响最终毛利。**
