做餐饮客户，核心不是“档次越高越好”，而是**按出餐方式分规格、按损耗算成本**。菠萝和香蕉建议这样备货。

## 菠萝：按“谁削皮、怎么出餐”分三档

| 规格 | 适合客户 | 备货建议 |
|---|---|---|
| **整果大果（1.2–1.5kg/个）** | 有后厨削皮能力的中餐馆、食堂、果汁店 | 主力规格，占比约50–60% |
| **整果中果（0.8–1.2kg/个）** | 小型餐饮、快餐、甜品店 | 走量款，占比约30% |
| **去皮净果/鲜切块（真空或保鲜盒）** | 茶饮店、披萨店、轻食、外卖店 | 高毛利但损耗高，先小批量试 |

关键点：
- **餐饮更看重出成率和稳定甜度**，不是看单个大小。可主推“去皮净果”，省人工、出餐快。
- 菠萝品种上，**金钻/台农**甜度高、纤维少，适合直接入口和果汁；普通巴厘种价格低，适合做炒饭、咕噜肉等熟食。
- 整果要按**成熟度分**：7成熟给需要存放的客户，9成熟给当天用的茶饮店。

## 香蕉：按“熟度”比按大小更重要

| 规格 | 适合客户 | 备货建议 |
|---|---|---|
| **大把蕉（整串/整箱，青转黄）** | 食堂、早餐店、水果捞店 | 主力，按箱走 |
| **单根分级蕉（中号，约18–20cm）** | 茶饮店、甜品店、外卖果切 | 走量款 |
| **熟蕉/芝麻蕉（8–9成熟）** | 当天做奶昔、香蕉派、甜品 | 小批量、高频补 |
| **冷冻香蕉段/泥（如有条件）** | 饮品连锁、烘焙 | 差异化，锁客户 |

关键点：
- 餐饮客户最怕**香蕉今天青、明天黑**。要按**熟度分级供货**：给茶饮店7–8成熟，给食堂可稍青一点。
- 香蕉规格重点看**单根重量和长度一致性**，果切和饮品店要求整齐，食堂可接受略不齐。
- 可提供**催熟服务或催熟柜合作**，这是绑定餐饮客户的好抓手。

## 实操建议

1. **先跑10–20家目标客户**：茶饮、快餐、食堂、甜品店各问3–5家，问清“自己削皮还是买净果”“每天用量”“能接受什么熟度”。
2. **首批备货比例**：菠萝整果70% + 净果30%试水；香蕉整箱青蕉为主，另备少量熟蕉做样品。
3. **报价按“净重/出成率”报**，餐饮老板更认这个，不要只报毛重箱价。
4. **设最小起送量和固定配送日**，餐饮客户要的是稳定，不是一次性低价。

一句话：**菠萝卖“省人工的净果方案”，香蕉卖“熟度稳定的分级方案”**，比单纯拼价格更容易拿下餐饮客户。
