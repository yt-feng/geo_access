判断一批香蕉的熟度和坏果风险，核心是“看颜色、摸果身、查果柄/果指、闻气味、抽样切开”，并且要按“整批一致性”来判断，而不是只看几根样品。

**1. 看颜色和成熟阶段**
- 青绿硬果：适合长途运输和囤货，但要看是否“死青”（怎么放都不黄）。
- 转色期：果身由绿转黄、果尖先黄，通常耐放性较好。
- 黄熟期：整体黄、果柄仍偏绿，适合近期出货。
- 过熟：大面积深黄、出现褐色斑点，货架期短，坏果风险高。
- 注意颜色是否均匀：整批如果青黄混杂严重，说明成熟度不齐，后续催熟和出货难统一。

**2. 摸果身和果指**
- 正常：果身饱满、略有弹性，不软塌。
- 风险信号：局部发软、按下去不回弹、果指间粘连渗液，说明已过熟或内部腐坏。
- 青果如果异常发软，可能是冻伤、浸水或病害，不是正常后熟。

**3. 查果柄、果轴和切口**
- 果柄青绿、干爽为正常；发黑、发霉、渗液要警惕。
- 整把果轴如果有黑腐、霉斑，容易从内部蔓延。
- 切口或伤口多、机械伤明显的货，坏果风险高，尤其夏季。

**4. 闻气味**
- 正常有清淡果香。
- 有酸味、酒味、发酵味，说明已过熟或内部开始腐烂，整批风险上升。

**5. 抽样切开和翻箱**
- 不要只看表层，随机翻到底层和中间箱。
- 抽几根切开看果心：果心发黑、发褐、空心化，说明内部坏变。
- 看箱底是否有汁液、霉毛、压伤果，箱底渗液的货要谨慎。

**6. 判断整批风险**
- 成熟度一致、果柄青绿、果身饱满有弹性、无酸酒味、箱底干爽：风险较低。
- 青黄混杂严重、局部软塌、果柄发黑、有酒味、箱底渗液：坏果风险高，压价或拒收。
- 夏季高温、运输时间长、多次转手的货，即使表面正常也要加大抽样比例。

**可执行建议：** 进货前随机抽3—5箱，每箱翻到底层，看颜色一致性、摸软硬、查果柄和箱底，再切2—3根看果心；只要出现“局部软塌+果柄发黑+箱底渗液”中的两项，就按高风险货处理，不要只看表层卖相。
