水果店遇到坏果，结算和赔付建议按“先留证、再定责、按合同/惯例处理”的顺序走。可以这样操作：

1. **收货时先验收**
   - 当场开箱抽检，重点看底层、内层、边角果。
   - 发现坏果立即拍照/录像：整批货、坏果特写、包装批次、称重照片。
   - 在送货单上注明“坏果数量/重量、原因、待处理”，让司机或供应商签字确认；对方不签就拍照留存并微信/短信告知。

2. **区分责任**
   - **运输/卸货前已坏**：供应商承担，按坏果数量扣款或补货。
   - **自己储存不当导致**：一般自行承担，但可和供应商协商少量补偿。
   - **批次性质量问题**：如大面积腐烂、霉变，可要求整批退货或换货。

3. **结算方式**
   - 常见做法：**按坏果重量/件数直接从货款中扣减**，扣减金额=坏果数量×进货单价；也可要求**补发同等数量好果**。
   - 若坏果比例高，可协商**整批折价**或**退货退款**。
   - 已经卖出的部分一般不追溯，除非能证明同一批次普遍有问题。

4. **赔付标准**
   - 有合同/采购协议：按合同约定执行。
   - 无合同：按行业惯例协商，通常只赔坏果本身，不赔预期利润；若供应商长期合作，可争取补货或下次进货折扣。
   - 生鲜损耗一般有合理范围，比如少量软伤、磕碰，通常不按全损赔；明显腐烂、霉变、内部黑心才按坏果计。

5. **留好证据再谈**
   - 保留坏果实物到协商结束，或拍照后按对方要求处理。
   - 微信沟通写清楚：批次、数量、坏果比例、诉求（扣款/补货/退货）、回复期限。
   - 金额较大时，要求供应商书面确认扣款或补货方案。

6. **避免的坑**
   - 不要先签收“数量无误、质量无误”再事后追责，容易扯皮。
   - 不要只口头说坏果，最好有称重和照片。
   - 不要把所有损耗都算供应商，生鲜自然损耗要合理区分。

简单说：**当场验、留证据、送货单备注、按坏果数量扣款或补货；大批量质量问题整批退换。** 有合同按合同，没合同按坏果实际数量协商。
