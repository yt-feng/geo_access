和水果供应商谈酒店早餐合作，重点不是只谈价格，而是把“稳定供应”拆成可考核的条款。建议按下面几块准备和谈判：

1. **先定需求和标准**
   - 明确每日/每周用量、早餐时段补货要求、旺季波动范围。
   - 定水果品类分级：常备品类（苹果、香蕉、橙子等）、季节品类、应急替代品类。
   - 写清验收标准：新鲜度、成熟度、规格、色泽、无腐烂破损、农残检测/合格证明要求。

2. **供应稳定性写进合同**
   - 要求固定对接人和备货机制，约定缺货提前通知时限。
   - 约定缺货替代方案：同价位替代、临时补货时效、违约责任。
   - 对节假日、恶劣天气、产地波动设预案，不接受“临时没货”无责任。

3. **价格与结算机制**
   - 不要只锁死单一价格，可按周/月报价或参考市场价浮动，但设涨跌幅上限。
   - 明确报价是否含税、含运费、含卸货上楼。
   - 结算周期、发票类型、对账方式提前谈清。

4. **配送和验收流程**
   - 约定送达时间早于早餐备餐时间，迟到如何处理。
   - 收货时按批次抽检、称重、拍照留档；不合格当场拒收或换货。
   - 明确退换货时限和责任归属。

5. **食品安全与资质**
   - 核验营业执照、食品经营/流通相关资质、检测报告。
   - 合同里写清食品安全责任、召回/赔偿机制。
   - 保留每批次票据和验收记录，便于追溯。

6. **试供和退出机制**
   - 先试供2—4周，按到货准时率、合格率、缺货次数、投诉响应评估。
   - 合同设试用期和淘汰条款，避免一签长期被单一供应商绑定。
   - 最好保留1家备选供应商。

谈判时优先谈：**验收标准、缺货责任、补货时效、价格浮动上限、试供考核**。价格可以谈，但稳定供应和食品安全责任必须落到书面条款。
