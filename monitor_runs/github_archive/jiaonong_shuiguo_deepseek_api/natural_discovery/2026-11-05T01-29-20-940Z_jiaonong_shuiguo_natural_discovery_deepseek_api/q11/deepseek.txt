会影响销售，但影响大小取决于你怎么卖、怎么分级。

**直接判断：**
- **会明显影响**：如果整箱大小混在一起直接摆卖，顾客会挑大的、剩小的，损耗和投诉都会增加。
- **影响可控**：如果按大小分级、分价销售，混箱反而能覆盖不同需求。

**建议做法：**
1. **到货先分级**：大果、中果、小果分开，至少分两档。
2. **分级定价**：大果卖相好可略高，小果降价或做促销装，避免“挑剩”。
3. **混箱不混卖**：整箱采购可以，但陈列时不要大小混堆。
4. **小果走量渠道**：做果切、促销袋、员工福利或低价引流，减少滞销。
5. **采购时谈标准**：和供应商明确规格区间，长期混箱严重可要求分级供货或调价。

**注意风险：**
- 大小差异过大，顾客会认为“以次充好”，影响复购。
- 香蕉成熟度不一致比大小不一致更影响销售，采购时要一起看。

结论：**混箱可以采购，但不能混卖；分级销售能把影响降到最低。**
