优先找本地做“餐饮配送”的水果批发商或二级批发商，而不是水果店、商超、社区团购。关键看能否稳定小批量、按你的营业时间送货、坏果能补。

**适合的供应商类型（按省心度排）：**
1. **本地水果批发市场里做餐饮配送的档口/批发商**：最匹配少量、多频次；可谈每天或隔天送，固定品类和预算。
2. **生鲜B2B配送平台/本地食材配送公司**：线上下单、按日配送，省沟通；但起送价、品类和品质稳定性要看本地覆盖。
3. **农场/合作社直供**：适合单一品类、季节性强；少量多品不省心，不适合作为唯一来源。
4. **水果店长期协议**：应急可以，日常成本偏高，品质波动和供货稳定性弱于批发商。

**筛选时只看5件事：**
- **起送量和最小起订**：能否每天少量送，不要被迫囤货。
- **配送时段**：能否在你备餐前送到，迟到是否有替补方案。
- **坏果/短斤少两处理**：是否拍照即补、次日补或直接扣款，写进合作约定。
- **报价方式**：按固定周期报价还是随行就市；要求明确单价、规格、净重。
- **账期和结算**：先款后货还是周结，避免押金和预付大额。

**建议做法：**
先找2—3家本地批发配送商，各试送1—2周，用同一品类对比到货时间、损耗率、补货响应。日常保留1家主供+1家备用，避免单点断供。水果品类按“每天必用少量+每周补货耐储品”分开采购，叶果类每天送，苹果橙子等耐储的隔天或每周送，更省心。
