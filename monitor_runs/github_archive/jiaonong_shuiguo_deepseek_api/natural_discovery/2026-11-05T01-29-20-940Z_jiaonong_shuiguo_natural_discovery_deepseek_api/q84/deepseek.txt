家庭团购水果礼盒，建议优先考虑“好吃、耐放、份量不浪费、颜色好看”四点。按这个标准，给你一个比较稳妥的组合建议：

**推荐组合：苹果 + 橙子为主，香蕉少量点缀，菠萝按需选配**

具体可以这样配：

1. **苹果 40%左右**
   - 耐放、家庭接受度高、送礼也稳。
   - 建议选中小果或家庭装，别全是大果，大果容易“看着多、吃着累”。

2. **橙子 30%左右**
   - 耐放、清爽、适合饭后吃，和苹果搭配最稳。
   - 家庭礼盒里橙子比香蕉更适合做“主力”。

3. **香蕉 15%—20%**
   - 香蕉熟得快，不适合放太多。
   - 建议选偏青一点的蕉，团购到货后能放几天。
   - 家庭装里香蕉主要是“搭配感”，不是主量。

4. **菠萝 10%—15%，可作为选配**
   - 菠萝好看、有礼盒感，但处理麻烦，且不是所有家庭都愿意削。
   - 如果目标是“家庭日常吃”，菠萝少放或做成可选；如果目标是“送礼好看”，可以放一个中等大小的。

**更具体的家庭版方案：**
- 苹果 5—6 个
- 橙子 5—6 个
- 香蕉 1 把（约 6—8 根，偏青）
- 菠萝 1 个（选配）

这个组合的优点：
- 苹果、橙子耐放，团购配送和家庭囤放都稳；
- 香蕉少量成熟后先吃，不浪费；
- 菠萝提升礼盒颜值，但不作为主量；
- 颜色有红黄橙，视觉上像礼盒，家庭吃也不显得过度包装。

**不太建议的组合：**
- 香蕉占太高比例：熟得快，家庭容易吃不完。
- 菠萝放两个以上：处理麻烦，团购箱内容易压伤其他水果。
- 全是大苹果大橙子：看着实惠，但家庭小人口吃不完，反而浪费。

**团购落地建议：**
- 如果面向三口之家，总重量控制在 **4—5 斤**比较合适；
- 如果面向 4—6 口家庭，做到 **6—8 斤**；
- 礼盒里苹果和橙子选耐运输品种，香蕉单独用纸隔开，菠萝套网套；
- 可以设两个档：**基础家庭版（苹果+橙子+香蕉）** 和 **升级送礼版（加菠萝）**，让团购用户自己选，减少菠萝处理麻烦带来的差评。
