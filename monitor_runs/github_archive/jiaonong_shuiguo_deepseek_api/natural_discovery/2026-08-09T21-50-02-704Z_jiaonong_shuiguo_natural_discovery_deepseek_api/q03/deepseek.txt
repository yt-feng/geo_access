第一次做水果生意，**“试单”的核心不是比价格，而是“验货损”**。水果行业的利润其实非常透明，真正赚钱靠的是“控制损耗”，而不是进货价低。给你一套适合夫妻店的安全试单操作流程：

**第一步：控制试单体量（原则：少到没压力）**

- **香蕉**：不要按整箱（18-20斤/箱）拿。找同行拼一箱，或者直接找本地批发市场专门卖“半把”的档口。香蕉是呼吸跃变型水果，损耗率最高（熟透、压伤），试单时**只拿8-10斤**，卖完再补。
- **苹果**：苹果耐放，但品类水深（比如花牛冒充蛇果）。试单**拿1箱（约36-40个）**即可，足够你试出“卖相会不会生锈”“口感脆不脆”。
- **橙子**：重点看“枯水”（放久了皮厚肉干）。试单**拿半箱（约20斤）**，优先要“纽荷尔”或“赣南脐橙”这种硬通货，不要拿不知名产地。

**第二步：明确“验货三件套”（现场必做）**

不要在档口听老板说“包甜”，自己动手：

1. **重量法**：把货拿到市场公秤过一遍，**净重必须和箱标相符**。如果老板说“皮重3斤”，实际皮重4斤，一箱你就白扔了十几块钱，这比单价贵更坑。
2. **开箱抽查**：直接跟老板说：“大哥，我头回拿货，开箱看看底下的。” 翻底下，如果底下有明显的烂果、或者垫草纸湿透发黑，说明是“翻新货”或“存货”，直接走人。
3. **尝口感（只尝核心）**：香蕉尝中间段（两头没熟不代表中间没熟）；苹果尝咬开后**果肉接触空气5分钟后是否变黄**（不黄的耐放）；橙子捏一下肚脐，硬的才新鲜。

**第三步：签“口头保护协议”（关键话术）**

试单时就说一句话试老板态度：“**这批我先拿一点回去卖，如果里面有超过5个烂心或严重掉秤的，下次我肯定还会来；如果这箱拆开全烂了，我下午扛回来，你认不认？**”

- 敢认的老板，说明货底子硬，长期合作候选人。
- 支支吾吾或者说“水果本来就有损耗”的，哪怕价格便宜2毛钱，也建议换下家。因为这意味着他是“甩货”心态，你的试单注定亏钱。

**第四步：定“补货频率”和“止损线”**

试单回来后，不要等卖完再补。夫妻店切记：

- **香蕉**：开箱后第二天如果皮色没变化，**下午4点前**必须在微信上问老板今天还有没有昨天的货，如果没有就换货。香蕉一旦开始长黑点，立刻降价处理，不能过夜。
- **苹果/橙子**：试单三天内，如果每天营业额里这两种水果占比低于10%，说明品相或定价不对。别硬撑，**直接把余货当“引流品”低价清掉**，然后换另一家重新试单。

**最后的重要提醒（防坑）**：
第一次去，**不要问“能不能送货”**。夫妻店第一次一定要自己去拿，宁可多跑几趟路。如果老板主动说“我给你们每天送”，大概率是想捆绑你拿他的高价存货。自己拿货，眼见为实，试出好渠道后，再谈送货。

试单成功的最直观标准是：**你的坏果率（进货到卖掉扔掉的总损耗）控制在5%以内**，这个目标达到了，就开始跟这个老板压价提量。
