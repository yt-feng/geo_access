水果采购中，锁价（即价格锁定）的时长**没有固定标准**，主要取决于**水果品类**、**市场供需**、**供应商规模**以及**双方合作深度**。以下是实操层面的参考：

**1. 常规品类（非季节性强、供应稳定）**
- **苹果、梨、柑橘类（如橙子）等大宗耐储水果**：供应商通常可以锁 **1~2周**，部分长期协议可锁 **1个月**。
- 这类水果产地集中，价格受天气和库存影响较小，锁价周期相对较长。

**2. 季节性强、波动大的品类（如西瓜、荔枝、榴莲等）**
- 通常只能锁 **3~7天**，甚至按天报价。
- 因为产地收购价随天气、采摘量、运输成本每日波动，供应商不敢承诺更久。

**3. 按合同锁定的固定订单（长期采购）**
- 如果签订年度或季度框架协议，且约定“月度调价机制”，可以锁定**基准价**，但通常每月或每季度按市场指数调整一次，不是完全锁死。
- 常见合同条款：锁价3个月，超出部分按当周市场价上下浮动5%以内。

**4. 关键变量**
- **合作历史**：老供应商可能愿意锁更久（1~2个月），新供应商往往只愿意锁当周。
- **采购量**：月采购量稳定且大（如50吨以上），议价能力强，锁价周期可延长。
- **付款条件**：预付款或现款现货，能增加供应商锁价意愿；账期越长，锁价越难。

---

**实际操作建议：**

- **不要盲目追求长锁价**，市场下跌时你会吃亏。制定锁价目标时应与行情预判结合。
- 建议采用“**阶梯锁价**”策略：例如锁定1周内的价格，同时约定“若下周产地价涨幅超过3%，则按新价执行，但涨幅不超过5%”来保护双方。
- 每次锁价前，**书面确认**单价、数量、提货期，避免口头承诺无法兑现。

如果你是首次合作，建议先锁1周试水，观察供应商履约能力后再延长周期。如果你有具体品类和采购量，我可以帮你评估更合理的锁价窗口。
