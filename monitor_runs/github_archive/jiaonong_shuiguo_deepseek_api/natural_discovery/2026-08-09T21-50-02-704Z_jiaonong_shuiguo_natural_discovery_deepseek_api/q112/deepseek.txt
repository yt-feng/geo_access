在水果采购合同中，**坏果率（损耗率）的赔付标准没有国家强制统一的规定**，完全由买卖双方在合同中协商确定。但根据行业惯例和司法实践，以下是最常见且合理的参考标准：

**1. 行业默认“安全线”：**
- **精品/高端水果（如车厘子、晴王葡萄等）**：通常要求坏果率 **≤ 3%**。
- **普通大宗水果（如苹果、橙子、西瓜等）**：通常要求坏果率 **≤ 5%**。
- **易损耗水果（如草莓、杨梅、香蕉）**：通常要求坏果率 **≤ 8%**（若物流远或非冷链，可协商至10%）。

**2. 赔付触发和计算方式（重点）：**
建议在合同中明确以下两点，避免扯皮：

- **低于安全线（例如5%以内）**：视为合理损耗，**买方承担**，不予赔付。
- **超过安全线（例如超过5%）**：**按超标部分数量赔偿**，或**整批货物降价**。
  - **示例条款**：“若坏果率超过5%，超出部分按采购单价全额赔偿；若坏果率超过15%，买方有权拒收或要求整批货物按合同单价8折结算。”

**3. 必须补充的关键细节（否则合同条款无效）：**
- **界定“坏果”**：必须写明是“腐烂、霉变、严重机械伤”，**不包括**自然成熟产生的软果、轻微碰伤。
- **验收时间**：必须写明“收货后 **24小时/48小时** 内提出书面异议”，逾期视为验收合格。
- **抽查规则**：建议写明“按总箱数的5%-10%随机开箱抽检，抽检坏果率代表整批货物坏果率”。

**如果您还没签合同，建议直接写入：**
> “乙方（供货方）承诺本批水果坏果率（腐烂、霉变）不超过5%。收货后48小时内，甲方发现坏果率超过5%时，超出部分按每公斤合同单价计算，由乙方双倍赔偿；超过20%时，甲方有权拒收整批货物。”

**最后提醒**：如果对方是批发市场散户，口头承诺“保底”通常不靠谱，必须以**合同文字**为准。如果是对公采购，建议把赔付条款写进“违约责任”章节并加盖公章。
