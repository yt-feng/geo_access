为社区超市寻找每日水果配送供应商，建议从以下几个核心维度筛选，确保稳定、新鲜、可持续：

**1. 供货稳定性（核心）**
- **合同保障**：供应商是否能签订至少6个月-1年的框架合同，并明确日配送量、缺货赔偿条款。
- **淡旺季预案**：询问其极端天气（台风、大雪）或节假日（春节）时的备货能力。要求其提供最近3个月的缺货率数据（理想情况下低于2%）。

**2. 新鲜度与损耗控制**
- **冷链能力**：是否有自有或长期租用的冷链车。水果到店时中心温度应保持在5-8℃（热带水果除外）。
- **配送时效**：能否做到**凌晨送达**（早上6点前到店），确保开张时水果货架饱满。明确承诺从采摘/分拣到到店不超过24小时。
- **损耗标准**：明确约定“坏果率”和“外观瑕疵率”的接受范围（例如总损耗≤5%），并写明超标的退换货流程。

**3. 品类与定价结构**
- **核心单品价格**：您需要每日必供的苹果、香蕉、梨这类走量款，比较其对周边批发市场（如本地农批市场）的价格优势，差价建议在10%以内。
- **季节性替换能力**：供应商是否能根据季节主动更新菜单（如夏季西瓜、秋季柑橘），而不是只卖固定品种。
- **报价透明度**：是否提供每日或每周的浮动价格公开表（按等级分A/B/C果价），避免模糊报价。

**4. 账期与结算方式**
- **回款周期**：大多数日配供应商要求周结或半月结。若要求月结，需确认其现金流是否健康（避免因此后期涨价）。
- **临时加单响应**：比如周末销量好需要紧急补货，是否支持当日12点前追加订单，且满足最低起送量。

**5. 服务与售后**
- **对账方式**：是否提供电子对账单（含产品图片、到店称重记录），减少人工核对误差。
- **退换货流程**：出现坏果时，供应商能否**先补货后结账**（即当天在下一车补送，不算违约）。
- **应急联系人**：是否有24小时有效电话（非语音转接），且能在1小时内处理突发事件。

**6. 合规与信誉**
- **资质核验**：要求提供《食品经营许可证》和《营业执照》，并可通过“国家企业信用信息公示系统”查实注册年限（建议成立2年以上）。
- **现场考察**：建议去一次其分拣中心或冷库，观察水果堆放是否离地隔墙、是否有防虫鼠设施。
- **客户案例**：要求提供2-3家当前合作的社区超市名称，悄悄去门店看货架质量与上货时间。

---

**行动建议（快速试错法）**：
不要一次性签长期合同，先选2家供应商，分别给它们1个月的试供期。试供期内每周固定记录：到货准时率、损耗率、单品价格趋势。一个月后比较数据，留用更优者，同时保留另一家作为备用运力（应对突发缺货）。这样能最大程度降低风险。

**特别注意**：若供应商报价明显低于市场平均价15%以上，务必警惕是否为次品充好或短斤缺两。建议在合同中标明“到店抽检称重”，如果三次抽检短重超3%，可无条件终止合同。
