判断水果供应商是否靠谱，不能只听他口头承诺，要建立一套**可验证的标准**。作为长期生意，核心是**品质稳定性**和**售后兑现能力**。

以下是针对香蕉和菠萝这两个具体品类，给你的一套实操判断清单：

### 1. 看“货不对板”的风险（重点看香蕉）
- **香蕉催熟风险**：香蕉分为**进口蕉**（如都乐、佳农）和**国产蕉**（如海南、云南）。国产蕉价格低但成熟度不均，进口蕉稳定但贵。
  - **关键测试**：第一次合作，**只进一箱**。到货后检查是否“硬心”（中间芯发黑）或“熟过”（表皮有黑点且果肉软烂）。**靠谱供应商敢让你开箱验货**，不靠谱的会说“行业规矩，整箱卖”。
- **菠萝的“黑心”问题**：菠萝容易有**黑心病**（外表金黄，切开内部变黑）。**不能只抽上面两层**，要求抽检**中下层**的菠萝，切开看中心。如果供应商推脱“切开就不能卖了”，说明他心里有鬼。

### 2. 看“损耗”责任的划分
这是最核心的试金石。签合同时必须写明：
- **香蕉**：到店后**2-3天内**出现的严重熟烂（非人为磕碰），供应商是否按比例赔付？靠谱的会承诺“**摔坏、冻伤、黑心**”包赔，不靠谱的会说“运输风险自负”。
- **菠萝**：是否承诺**常规果眼发霉不赔，但切开黑心赔**？如果对方说“水果是生鲜，卖出概不负责”，直接pass。

### 3. 看“时间线”与“价格”的匹配度
- **问清楚货从哪里发**：如果他说是广西/海南直发，但发货地是本地批发市场，那他只是个**中间商**，价格必然虚高。
- **看价格波动**：菠萝和香蕉是期货价。靠谱供应商会提前一天告诉你明天涨价/降价，并允许你调整订单。如果价格**永远低得离谱**，大概率是拿次果充好果，或者短斤缺两。

### 4. 看“付款模式”与“账期”
- **不要轻易垫资**：第一次合作，**坚决要求现款现货**，或者“押一批结一批”。
- **警惕“低价+预留押金”**：如果对方要求你先付几千块押金，且价格明显低于市场价，100%是骗局（卷款跑路重灾区）。

### 5. 实操验证法（让他“露馅”）
你可以直接打电话给他，说：
> “老板，我这边菠萝卖得慢，这批货到店如果烂了3个，我拍照给你，你能直接给我补货吗？”

**观察他的反应**：
- **靠谱类型**：“你拍视频给我，是黑心还是摔伤，确认了下次送货给你抵扣。”
- **不靠谱类型**：“那你自己得注意保存，天气热没办法”“这种损耗我们不管”。

### 6. 关键数据指标参考（避免被忽悠）
- **香蕉**：到货时**果把颜色应为青绿色**，如果到货就带黄，说明放了很久，不耐放（除非你要现卖）。
- **菠萝**：成熟的菠萝**眼（果目）应饱满突出**，且**闻起来有明显香甜味**。如果供应商送货时菠萝还是全青的，说明他给你的是**未熟采摘果**，这种货切开可能是白芯，口感极差。

---

**最终建议**：
先小额试单（比如各进20斤），**全程录像开箱**。如果这批货在**3天内无大损耗、且口感稳定**，再谈长期合作。另外，最好同时备选**2家供应商**，不要长期依赖一家，这样你才有议价权和安全感。
