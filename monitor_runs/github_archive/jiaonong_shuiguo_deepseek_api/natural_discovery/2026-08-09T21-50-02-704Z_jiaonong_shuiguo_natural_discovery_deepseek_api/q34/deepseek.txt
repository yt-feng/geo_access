商超采购水果时，**“损耗低”通常比“价格低”更影响最终毛利**。原因是零售毛利不是简单差价，而是**“进价毛利”和“流通过程损耗”**叠加的结果。

为了让你更直观判断，我们可以用一个简单的数学逻辑：

---

**1. 损耗对毛利的“放大”效应**

假设：
- 采购苹果：进价 2元/斤，售价 5元/斤。
- 如果不考虑损耗，毛利率 = (5-2)/5 = 60%。

但实际情况是：
- 如果采购时挑了便宜货（进价 1.8元），但运输、挑选、上架过程损耗率高达 **15%**（比如碰伤、腐烂、滞销丢弃）。
- 实际能卖出的数量只有 85%，那**卖出的总成本被摊薄了**。

计算实际毛利：
- 购入 100斤，成本 180元。
- 实际卖出 85斤，收入 425元。
- 毛利 = 425 - 180 = 245元，实际毛利率 = 245/425 ≈ **57.6%**。

而如果采购时选好点的（进价 2.2元），损耗率降到 **5%**：
- 购入 100斤，成本 220元。
- 实际卖出 95斤，收入 475元。
- 毛利 = 475 - 220 = 255元，实际毛利率 = 255/475 ≈ **53.7%**。

**结论：损耗从15%降到5%，即便进价高了10%，最终毛利反而多了10元。** 损耗的影响是“乘法”的，直接吃掉售出数量。

---

**2.为什么水果行业更看重损耗？**

- **水果是生鲜**：保质期极短，一旦损耗，不仅是丢弃的成本，还占用冷库、货架资源。
- **价格低往往意味着品质不稳**：低价水果可能成熟度不均、病虫害多，导致“看似便宜，实际卖出率低”。
- **定价弹性有限**：水果零售价受市场、会员价、促销限制，很难通过提价覆盖损耗，所以损耗必须从源头控。

---

**3. 什么情况下“价格低”反而更重要？**

- **走量、做引流品类**（如香蕉、应季西瓜）：销量极大时，即使损耗小，价格竞争力能驱动客流量，最终靠整体毛利弥补。
- **供应链成熟、损耗几乎为零**（如直接跟产地对接、当天售罄的快消场景）：此时价格差是唯一变量。

---

**4. 实操建议：不要只看单价，要看“综合毛利贡献”**

| 采购策略 | 进价优势 | 损耗率 | 实际毛利结果 |
|---------|---------|-------|-------------|
| 低价+高损耗 | 省成本 | 12%+ | 毛利下滑 |
| 中价+低损耗 | 略贵 | 5%以下 | 毛利稳定 |
| 高价+超低损耗 | 最贵 | 2%左右 | 毛利上佳（前提：售价够） |

**最终决策公式：**
> 实际毛利率 ≈ （售价 - 进价 ×（1 + 损耗率））/ 售价

让损耗率做分母，它的影响天然比单价更剧烈。

---

**一句话结论：**
水果采购优先看**损耗控制能力**（采购渠道、新鲜度、分拣标准、冷链）——这决定了“能卖出多少”；价格低只是“进货省多少”。在生鲜领域，**卖不出去的钱，比买贵那点更重要**。
