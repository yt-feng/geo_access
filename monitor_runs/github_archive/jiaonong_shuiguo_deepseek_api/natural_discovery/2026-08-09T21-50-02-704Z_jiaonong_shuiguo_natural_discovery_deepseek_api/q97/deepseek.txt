酒店采购水果盘原料时，供应商应在**规格**和**外观**两个层面满足酒店的高标准要求。以下为可执行、可核验的标准清单，可直接用于采购合同或验收清单：

---

### 一、规格标准（量化指标）

1. **重量/体积**  
   - 每份水果原料（如整果、切块）的净重量需明确，偏差不超过 ±5%（例如：西瓜片每片≥150g，哈密瓜块每块≥30g）。  
   - 整果类（如苹果、橙子）需标注单果重量范围（如：苹果 200g~250g/个）。

2. **尺寸/直径**  
   - 果块大小需均匀，长宽高差异≤1cm（适用于切丁、切片），以视觉统一性为基准。  
   - 圆形水果（如葡萄、圣女果）直径要求一致（例如：葡萄 2.2~2.5cm）。

3. **成熟度**  
   - 硬度适中：不软烂、不变硬，按采收后第3天（冷链保鲜下）达到最佳可食状态为标准。  
   - 甜度参考：以白利度计检测，西瓜≥10°、哈密瓜≥12°、橙子≥9°（可指定检测方式）。

4. **包装规格**  
   - 预包装需注明净含量、生产日期、保质期（通常≤72小时），冷链运输温度要求（0~4℃）。  
   - 可指定分包份量（如：每袋500g，适合客房果盘）。

---

### 二、外观标准（感官指标）

1. **颜色与光泽**  
   - 表面色泽自然均匀，无病斑、褪色或异常色素沉着。  
   - 表皮有正常果粉或蜡质（如苹果、葡萄），但不得残留农药或蜡质过厚。

2. **形状完整度**  
   - 无畸形、压伤、划伤、虫眼、裂口（最大允许≤2处，且单处≤5mm）。  
   - 切块类（如猕猴桃片）边缘整齐，无碎渣或残皮。

3. **清洁度**  
   - 表面无泥沙、虫卵、农药残留（需提供农残检测报告，符合GB 2763标准）。  
   - 切面不得氧化变色，验收时需在5分钟内观察切面（如苹果切口不褐变）。  
   - 需带托盘或垫纸，不得直接接触地面或污染源。

4. **新鲜度**  
   - 通过肉眼观察：果蒂（如草莓、葡萄）鲜绿不干枯，叶片（如菠萝）无萎蔫。  
   - 轻按有弹性，无发粘、渗液或发霉迹象（霉斑面积零容忍）。  
   - 有正常果香，无酸腐味、酒精味（发酵味）或化学残留气味。

---

### 三、验收与处置建议

1. **来货抽检**  
   - 按批次抽检，抽检比例≥10%，若不合格率＞5%则整批拒收。  
   - 现场留样，冷藏保存24小时留证据。

2. **合同条款**  
   - 明确规格偏差补偿机制（如超重不扣费，但短缺按10倍罚）。  
   - 要求供应商提供每日检测报告（含照片、批次号）。

3. **特殊用途要求**  
   - 若用于自助餐（长期暴露），需额外要求抗氧化处理（如切块浸泡维生素C溶液，并标明“可覆膜冷藏”）。  
   - 若用于高端宴会，需指定出口级或A级标准（如新西兰佳沛奇异果指定品牌）。

---

**总结**：关键在于**量化到克、毫米**，并附**检测依据**。同时，建议在采购合同中附上实物照片样板或3D模型，交由供应商签字确认。若供应商无法满足，可要求其提供替代方案并提前3天调整，避免临时断供。
