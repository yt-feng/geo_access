关注点排序建议：**切果损耗 > 甜度 > 外观 > 大小**。理由如下：

1. **切果损耗（优先）**  
   - 这是直接决定利润的核心。菠萝皮厚、眼深，切果损耗率通常高于其他水果（可达30%-40%）。若损耗过高，即使进货便宜也可能亏本。  
   - 操作建议：  
     - 进货时试切1-2个，估算实际出肉率（果肉重量/总重）。  
     - 优先选表皮较薄、芽眼浅的品种。  
     - 若卖整果，损耗虽不直接呈现，但会影响定价和促销策略（如切片销售可提高溢价）。

2. **甜度（卖点）**  
   - 决定复购率和口碑，但无法在进货时直接测量。  
   - 实操方法：  
     - 试吃：现场切开尝，选择糖度≥12%（用糖度计或凭经验）。  
     - 选品种：如金钻菠萝（海南产）甜度通常高于普通大果。  
     - 看季节：冬春菠萝（2-4月）甜度最佳，夏秋季酸度高。

3. **外观（吸引眼球）**  
   - 影响即兴购买，但不可过度追求。  
   - 关键点：  
     - 颜色金黄均匀、无褐斑（避免黑心）。  
     - 叶片翠绿不干枯（表示新鲜）。  
     - 轻轻按压，有弹性但不软烂（过软说明过熟）。

4. **大小（次要）**  
   - 大小只影响单价，不影响利润结构。  
   - 建议：  
     - 优先选1.5-2斤/个的“单身果”（一人食友好）。  
     - 大果（>2.5斤）损耗率可能更高（果皮厚、肉纤维粗）。  
     - 小果（<1斤）则果肉少，不建议进货。

**最终操作建议**：  
- 批量进货前，先试切5-10个，记录出肉率、甜度和外观，选综合分最高的批次。  
- 若无法试切，优先选色泽金黄、叶片直立、果型匀称的，并避免进大果（损耗风险高）。  
- 销售时段上，早上摆整果显眼睛，午后切盒促销（用损耗果肉做成水果杯，提升毛利）。
