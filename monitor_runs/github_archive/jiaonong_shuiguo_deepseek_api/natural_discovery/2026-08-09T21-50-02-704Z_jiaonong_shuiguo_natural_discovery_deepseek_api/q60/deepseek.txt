面对茶饮店水果到货不合格的情况，想要在不影响营业的前提下补货，核心在于**建立“快速响应、责任清晰、质量兜底”的补货机制**，而不是简单约定“坏了换一箱”。以下是具体的操作建议和合同/协议要点：

### 一、立即止损的应急补货方案（1-3天内）

这部分主要针对**当下这一批货**，建议按以下顺序操作：

1.  **拍照留证 + 拒收/隔离**：
    -   当着送货员的面，对不合格水果（发霉、腐烂、果肉褐变、农残超标等）拍照、录像，并单独堆放，**不要混入正常库存**，避免交叉污染。
    -   若已入库，需第一时间挑拣，并将坏果照片发给供应商。

2.  **电话/微信锁定“紧急补货”**：
    -   不要只发消息，**直接打电话**给供应商负责人，明确表示：“这批货请立即安排补发同数量合格品，明天上午10点前必须到店，否则我店将直接从其他渠道采购，差价由你方承担。”这一步不是为了吵架，而是为了确认对方是否具备加急送货能力。

3.  **同步启动“替代方案”**：
    -   如果供应商无法在2小时内明确承诺明天到货，**立刻联系附近批发市场或备用供应商**（建议平时至少储备1-2家）。
    -   购买替代品的差价、运费，**务必索要收据或转账记录**，这是后续从原供应商货款中扣除或索赔的依据。

### 二、长期合作协议中的“补货条款”设计（防止再次发生）

这部分是根本，应在采购合同或供应商月度协议中明确以下关键条款：

1.  **补货响应时效（硬性指标）**：
    -   约定：**“接到不合格通知后，供应商须在X小时内（建议24小时内）完成同规格、同品质的补货送达。若超时，乙方（你的茶饮店）有权启用备选供应商，由此产生的额外采购成本（含运费）由供应商承担。”**

2.  **“无理由更换”与“二次验收”**：
    -   条款示例：**“对于到货时发现的不合格品，甲方（供应商）承诺在接到通知后予以‘先行换货、异议后置’处理。即：先补发合格品，原不合格品由乙方拍照留存后统一销毁或退回，双方再就责任归属进行核验。补货到店后，乙方需在2小时内二次验收，不合格即刻拒收，不计入乙方成本。”**

3.  **质量分级与惩罚措施**：
    -   明确约定：**“单批次不合格率超过5%（或属于腐烂、霉变等严重问题），除补货外，该批次货款按8折结算；若2个月内出现3次以上不合格，乙方有权单方解除合同并扣除质保金。”**

4.  **“即食性”特殊条款**：
    -   针对茶饮店用量大的**柠檬、橙子、西瓜、芒果**等，可加注：**“甲方需保证水果在到店时可立即使用，不能有表皮软化、内部发苦、榨汁率低于N%的情况（具体数值由店方自定）。若因货品质量问题导致门店饮品出品瑕疵或顾客投诉，供应商需承担相应客诉损失。”**

### 三、实操中必须注意的三个细节（防坑指南）

-   **补货到达时间按“小时”计算**：谈判时供应商往往会说“后天或明天下午”，一定要敲死到“**上午营业前（如10点前）**”或“**下午2点前（高峰前）**”，因为奶茶店高峰期是下午和晚上。
-   **保留“不合格证据链”**：视频、照片要拍清**外包装标签（显示日期）**和**水果内部真实状态**。如果急着用了，剥开皮切开拍内部，这能防止供应商说“是你们存放不当导致的”。
-   **留用“备胎供应商”**：即使合作一直很稳定，店里也要存有**最近市场的送货电话**。一旦原供应商掉链子，你第一时间能调用，同时把这个切换动作告知原供应商，会大大增加其履约动力。

**总结一句话**：核心不是“约定怎么补”，而是“约定补不来怎么办”（启动备选+赔偿），并且把响应时间从“天”压缩到“小时”。如果供应商不愿意签这类条款，说明其货源不稳定，建议尽快更换为更重视契约的长期伙伴。
