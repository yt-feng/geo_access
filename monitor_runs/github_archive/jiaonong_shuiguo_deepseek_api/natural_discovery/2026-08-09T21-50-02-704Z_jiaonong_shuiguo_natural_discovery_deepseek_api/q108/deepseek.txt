采购方核实水果供应商“全国配送”的实际覆盖能力，不能只听口头承诺，必须通过**可验证的书面材料、技术系统、过往案例和真实测试**四个维度来交叉确认。

以下是具体的核实步骤和操作建议：

### 第一步：索要官方资质与区域授权文件（排除皮包公司）
1. **查验营业执照经营范围**：明确标注“道路货物运输”、“冷链运输”或“供应链管理”，而非仅仅是“批发零售”。
2. **索要《食品经营许可证》**：证明其具备跨区域分销的合法资质。
3. **检查区域代理/加盟授权书**：如果供应商是“总代”，要求其出示下游分销商的名单及授权合同。如果声称全国配送但只在产地有档口，要警惕其是否为转单赚差价。

### 第二步：核实物流网络与自建/合作冷藏体系
水果易腐，冷链是核心。让供应商提供以下三项中的**任意两项**作为佐证：
- **干线物流合同**：要求供应商提供其与顺丰冷运、京东物流、跨越速运或区域冷链车队的**年度框架协议**复印件（关键信息可打码但需有合同编号和甲方名称）。
- **分仓分布截图**：如果在全国设有多仓，要求提供WMS（仓储管理系统）的仓库列表截图或分仓租赁合同。重点核实**一二线城市是否必有仓**，因为“全国配送”通常指“全国主要城市”，而非“全国所有县镇”。
- **实时履约记录**：询问最近三个月内发往**新疆、西藏、海南、黑龙江**等边远地区的发货记录，这些区域最能检验真实能力。

### 第三步：要求提供“赔付承诺”书面条款
真正的全国配送能力，体现在**售后契约**上。
- 要求供应商在合同中**明确写入**：“因配送时效导致的水果变质/损坏，按货值100%赔付”。
- 询问**断链（冷机停机）处理流程**。如果对方支支吾吾或仅承诺“酌情补偿”，说明其冷链履约能力大概率不达标。

### 第四步：程序化“灰度测试”（最有效的实战验证）
**不要直接下大单**，通过小规模订单测试系统承载力和真实时效：
1. **分时段下单测试**：分别在**周一、周三、周五**（避开周末订单少时段的“特殊照顾”）下单发往**3个不同难度的城市**（如：省会城市、地级市、县级市）。
2. **记录交付时间节点**：
   - 下单后 **24小时**内是否强制上传物流单号？
   - 包装是否使用**EPP泡沫箱 + 高分子锁水纸**，还是普通纸箱？
   - 物流轨迹是否在**对应城市分拨中心**有停留记录（停留超2小时可能意味着常温放置）。
3. **验收标准**：如果无法在承诺时效内到达，或到达后果汁流失率超过3%，则该“全国配送”能力不可信。

### 第五步：看“鲜度保险”或与平台方的对赌协议
部分头部供应商会与美团快驴、拼多多买菜等平台签订对赌协议（如：准时率低于95%则罚款）。你可以询问：
> “你们目前给XX大平台供货，合同里约定的整体履约时效考核标准是多少小时？最近一个季度的达标率是多少？”

如果对方能说出具体的**考核数字**（如：省会城市48小时内，前置仓冷链车温控在0-4℃），说明是真有系统管理；如果只能回答“我们速度快”，则建议放弃。

---

**最终决策建议：**
不要依赖单一证据。**“合同承诺+冷链车月租协议+一次跨省对赌测试”**三者缺一不可。最稳妥的做法是：让供应商在合同里写明“**首单若超过承诺时效12小时，整单免单**”，这一条就能过滤掉90%的“伪全国配送”供应商。
