针对社区超市销售小包装香蕉，在采购和日常管理中，**损耗控制和包装规格**是核心，直接决定毛利。以下是具体注意事项：

**一、采购源头与包装规格（订货时定规矩）**

1.  **明确“小包装”标准**：不要模糊地说“小份”，建议明确**单串或单盒重量**。例如：**每盒/每袋净重500g±50g**，或者**每串3-4根**（约450-550g）。这决定了进货和定价的基准，防止供应商混装大果。
2.  **选择“催熟度”而非“全熟度”**：**采购时必须选择“7-8成熟”**（果皮青黄相间，果肉硬实）。全熟的香蕉不耐搬运挤压，到店2天内就会发黑。到货后颜色太绿（太生）也不行，顾客不买。
3.  **分批采购，小量多次**：社区店日销量有限，**不要一次囤一周量**。建议**2-3天补一次货**，每批次采购量控制在**预计2-3天售完**的量，减少积压。
4.  **包装形态选择**：
    - **透明盒装（首选）**：能防止压伤，且方便顾客看果形。盒底需带**透气孔**，否则盒内易积水汽烂柄。
    - **袋装（次选）**：必须用**带孔保鲜袋**，不能密封，且只能装同成熟度。若装不同熟度（一青一熟），熟果会加速青果腐烂。
    - **避免过度精美包装**：小包装盒成本（约0.3-0.5元/盒）会吃掉毛利，除非定位高端，否则建议使用普通透明快餐盒或带透气孔的PE袋。

**二、到货验收（防损耗的第一道关）**

1.  **检查“果把”伤口**：小包装香蕉最容易在**连接果柄处断裂**。到货时开箱抽查，若发现果柄处有大量发黑、渗液，说明打包或运输时碰撞严重，建议拒收或折价。
2.  **检查“尖头”状况**：香蕉尖端（花蒂残留处）若开裂或发黑，极易在盒内串味发霉。抽查时，若超过10%的尖头发黑，整批应拒收。
3.  **检查“袋内水汽”**：若用手摸包装袋内侧有明显水珠，说明采后未充分预冷或冷藏运输中断，此批货极易在货架上快速变黑，不建议接收。

**三、店内陈列与库存管理（降低销售端损耗）**

1.  **“先进先出”与“翻面”**：冷柜内堆叠的香蕉，底层温度低易冻伤（表面变褐）。**每天开档必须上下、前后翻动一次**，防止局部受冻。
2.  **分开熟度陈列**：如果确实混进不同成熟度，**青一点的放上层/里侧，黄熟一点的放下层/外侧**，方便顾客优先拿走熟的，避免熟果压坏生果。
3.  **定价策略辅助损耗**：小包装香蕉是**时节性商品**，超过第3天未售出的，**不要继续原价卖**。建议设定**“临期折扣”**（如第3天下午打8折），亏损远小于扔掉的全损。

**四、给你一个采购时的“3查”动作（实操口诀）**

- **查箱盖**：纸箱盖若有明显水渍，说明运输中挤压严重。
- **查果柄**：随机掰断一根果柄，看断面是否白色、干爽（新鲜）还是发黑（不新鲜）。
- **查袋底**：提起包装袋，看袋底有无黑色黏糊状碎屑，有则说明内部霉烂。

**总结建议**：初期小批量试错，**进“无把”的真空小包装**（即切断果把，独立包装）损耗率最低，虽然成本高2-3毛/根，但货架期比带把香蕉长1-2天。优先考虑这一款式起步。
