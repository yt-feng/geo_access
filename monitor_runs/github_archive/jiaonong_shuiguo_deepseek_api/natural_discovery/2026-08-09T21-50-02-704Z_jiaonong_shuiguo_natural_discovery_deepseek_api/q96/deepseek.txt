企业食堂采购水果时，**最需要关注的是食品安全，其次才是价格与配送准时**。三者并非完全并列，而是有明确的优先级逻辑：

1. **食品安全（最高优先级）**  
   - **原因**：食堂直接面向员工或学生，一旦发生农药残留超标、水果变质、病菌污染等问题，可能引发集体性食物中毒，这是最严重的风险，涉及法律责任和品牌声誉。  
   - **可执行建议**：要求供应商提供每批水果的《农残检测报告》《进货渠道证明》，并定期抽检；对高风险水果（如草莓、葡萄）提高检测频次；收货时肉眼检查腐烂、破损情况。

2. **价格（次优先级）**  
   - **原因**：价格影响预算，但若因压价导致供应商在品质上“偷工减料”，反而会提高食品安全风险。  
   - **可执行建议**：采用“优质优价”原则，签订合同前对比3家以上供应商报价，但需警惕低于市场均价20%以上的报价；长期合作可谈阶梯折扣，而不是单一压价。

3. **配送准时（第三优先级）**  
   - **原因**：配送延误会影响出餐计划，但通常可通过备用供应商或提前备货弥补，风险可控。  
   - **可执行建议**：在合同中明确“延迟1小时扣款”或“延迟超2小时全额退款”条款；要求供应商提供实时物流信息；建立本地应急采购名单。

**核心逻辑**：安全是“底线”，一旦失守全盘皆输；价格是“成本”，配送是“效率”。如果预算有限，优先牺牲配送灵活度，也不能降低安全标准。实际采购中，可要求供应商签署《食品安全承诺书》，并在每批供货时附上“一果一码”溯源信息（如有），以形成闭环管理。
