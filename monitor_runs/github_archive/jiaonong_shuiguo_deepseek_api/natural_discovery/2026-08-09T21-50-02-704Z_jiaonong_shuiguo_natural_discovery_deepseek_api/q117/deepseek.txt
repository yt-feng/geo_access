对于水果采购方来说，试卖新品最稳的**核心原则是：能快速卖完，且不造成滞销损耗**。一般来说，**首批试卖量控制在日常同类畅销水果日销量的 30%～50%** 是最稳妥的。

具体建议如下：

**1. 按“3-5天消化周期”备货**
不要按周备货，只备 **3-5天** 的量。如果这个量能顺利卖完，再追加第二批。备货公式参考：
> **试卖量 = 预估日均销量 × 4天（保险系数）**
> 预估日均销量可以参考同类产品（如柑橘类换苹果类），如果拿不准，第一天只进 **20～30斤** 或 **1～2箱** 试水。

**2. 按渠道差异化设定**
- **社区团购/线上预售**：先上架 **50～100份** 预售，售完即止，零风险。
- **商超/生鲜门店**：先摆 **半个堆头或1个端架**，首批 **50～150斤**（视门店客流而定），卖完再补。
- **批发/二级分销**：先拿 **1～2件**（标准箱），不要整板压货。

**3. 关键观察期（前48小时）**
试卖不是只看销量，重点看 **“复购”和“损耗”**：
- **前2天**：如果销量好且顾客有回头问的，第三天立刻加大订货量；
- **如果前2天销量平平**，果断停止补货，把现有库存打折促销清掉，避免积压变质。

**4. 给供应商的谈判技巧**
试卖期一定要跟供应商提前谈好 **“补货优先权”** 和 **“尾货处理条款”**：
- 例如：**“首批进50件，3天内卖不动，剩余的可按成本价退回或换成其他畅销品”**。
这样可以把风险压到最低，供应商也愿意配合，因为他们是长期利益方。

---

**最后提醒一句**：水果的“稳”不在于量大，而在于**新鲜度和周转率**。宁可少赚，不可压货，这是水果生意的铁律。
