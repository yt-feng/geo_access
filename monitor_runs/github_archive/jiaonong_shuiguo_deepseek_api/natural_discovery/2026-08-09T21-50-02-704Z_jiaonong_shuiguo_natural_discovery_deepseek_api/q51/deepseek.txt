针对茶饮店水果口味波动的问题，**强烈建议固定产地或供应批次**，但这需要结合成本和品控策略，不能一刀切。

以下是具体建议和可执行方案：

**1. 核心原则：固定产地 > 固定供货商 > 固定批次**

- **固定产地（最重要）：** 不同产区的水果（如云南夏黑葡萄 vs 新疆无核白）在糖度、酸度、香气上差异巨大。产地的“水土”直接决定基本风味骨架。
- **固定供货商：** 在产地下选1-2家稳定、有分选能力的供应商，避免今天买A家、明天买B家，导致品质参差。
- **固定批次/规格标准：** 明确采购规格（如单果克重、糖度阈值、成熟度），而不是迷信“同一批货”。因为同一批货里也可能有坏果或成熟度不均。

**2. 实际执行策略（平衡口味与成本）**

- **建立“风味配方”而非“单一水果”：** 如果你的招牌果茶用的是某款水果，可以尝试**混合产地**。例如：用云南芒果（浓郁）+ 海南芒果（清甜）按7:3比例混合，既能稳定整体风味，又降低单一产地天气风险。
- **签订“保量保价”合同：** 对核心水果（如草莓、葡萄、水蜜桃）和关键供应商签订季度或年度框架协议，锁定主产地，并要求供应商提供**质检报告（糖度、酸度、农残）**。合同中注明“允许因不可抗力更换产地，但必须提供替代样品测试”。
- **设置“风味阈值”验收制度：** 不要只看外观。收货时用便携糖度计（Brix计）抽检，例如规定草莓糖度需≥10%，低于此标准拒收或降级使用（如做果酱而非鲜果茶）。这样比固定批次更科学。

**3. 应对波动的“兜底方案”**

即使固定了产地和批次，也无法100%防止极端天气或病虫害。建议：

- **预备2-3个备选产地：** 例如主采福建东魁杨梅，但提前联系浙江仙居、云南抚仙湖的供应商作为替补，且提前测试其风味差异。
- **产品结构冗余：** 对容易波动的水果（如热带水果），在菜单上设计**“当季限定”或“售罄即止”**，或提供替代选项（如换为冷冻果浆/浓缩汁），避免因单一水果断供影响整条产品线。

**4. 具体采购操作建议**

- 每次采购时要求供应商提供**“批次编号”**，并留样封存。如果这批水果风味好，下次优先复购；如果变味，可直接追溯。
- 建立**“感官品评记录表”**：每次到货后，由店长或品控员盲测（区分外观、香气、酸度、甜度、后味），评分并录入台账。3-6个月后，你就能知道哪些产地/供应商最稳定，再据此微调采购策略。

**总结：** 不要仅仅固定“产地”或“批次”这两个词，而是固定“标准”和“追溯体系”。产地是基础，批次是过程，**最终目标是让每一杯茶的酸甜度、香气在±5%的误差内可控**。如果成本允许，优先锁定核心产区的核心供应商，并搭配混合产地的对照组。
