针对便利店面积小、损耗高、采购难的问题，核心逻辑是**少进货、勤补货、卖得快**。以下是可落地的具体建议：

**一、品类控制：做“精选店”而不是“水果店”**
便利店的水果不能按水果店逻辑铺货，**SKU数量要严格控制**（建议控制在10-15个以内）。

- **主打“即食”和“单果”**：不要进货整箱。优先选择**香蕉、苹果、梨、柑橘类**（橙子、沃柑）这些日常高频、易储存的品种。
- **紧跟“尝鲜季”**：时令水果（如当季的草莓、西瓜）可以适量进，但过季水果坚决不碰。
- **增加“果切/果捞”**：这是便利店的核心利润点。把不容易整售的（如菠萝、哈密瓜、芒果）切成小盒装。**注意：果切必须当天做，当天打折清完。**
- **谨慎碰的品类**：**榴莲、山竹、杨梅**等价格贵或极易损耗的，除非预订单，否则不要进货。

**二、采购策略：少批量、多频次**

- **“做减法”采购**：不要按照“预估销量”进货，而是按照**“当天最低必售量”**进货。宁可卖断货，也不压货。
- **绑定核心供应商**：找1-2家能**日配**（每天送货）的本地批发商。下午4点前订货，第二天早上到货。这样你每天卖的都是鲜货。
- **利用“半成品”**：如果供应商能提供去皮、切好的果肉，哪怕贵一点，也比自己切省人工、降损耗。

**三、损耗控制：全流程止损**

1.  **收货即验**：到货当场检查，磕碰、压伤的拒收或折价。
2.  **陈列与翻面**：货架不要堆得太满（只放前面两排），下面的存货要垫泡沫垫。**每天早晚各检查一次，把压坏的、有瑕疵的挑出来，瑕疵果立即做成果切或特价处理。**
3.  **“黄金4小时”**：水果在常温下，尤其是夏天，超过4小时品质会明显下降。建议：
    - **早高峰**：摆少量全果。
    - **下午**：转为主推果切（配叉子）。
4.  **临期处理**：每天下午6点后，对当日果切和第二天的囤货做**“第二件半价”**或**“晚间折扣”**，尽量做到“当日清”或“隔日清”，不放过夜。

**核心心法：**
记住一句话——**“损耗不是省出来的，是卖出来的”**。便利店空间小，水果不是引流主力，而是**冲动型消费**（搭配便当、饮料）。与其追求品种全，不如做到**“样样都新鲜，个个卖得快”**。如果连续三天某个单品卖不动，立刻下架。
