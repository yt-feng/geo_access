在超市采购环节，为了应对市场监管部门的农残抽检并保障商品质量，建议你提前向供应商索要以下核心资料，并做好存档备查：

**一、法定必备资质（证明“合法身份”）**

1. **营业执照**：确认供应商经营范围包含“水果销售/批发”或“初级农产品”。
2. **食品经营许可证**：如果是食用农产品（水果）销售，需提供有效的食品经营许可证。

**二、农残合格证明（证明“产品安全”）**

**这是应对抽检最关键的证据**，按优先级索要：

1. **当批次农残检测报告**：要求供应商对每次送货（或每批入库）提供对应的检测报告。报告需包含：
   - 检测机构名称（需具CMA或CNAS资质）。
   - 检测项目（重点看：有机磷类、氨基甲酸酯类、拟除虫菊酯类等常见高毒、禁限用农药）。
   - 判定标准（GB 2763《食品安全国家标准 食品中农药最大残留限量》）。
   - **注意**：报告上的商品名称、生产日期/批次必须与实际收货完全一致。
2. **产地证明或承诺达标合格证**：如果供应商来自规模化基地，可要求提供产地证明（当地政府或基地出具）或食用农产品承诺达标合格证（新《农产品质量安全法》明确要求）。
3. **如供应商为农户或合作社**，可要求提供其自身的检测记录或委托第三方检测的年度报告。

**三、质量追溯资料（证明“来源可查”）**

1. **进货台账**（供应商需提供其上游来源的清晰记录，包括产地、农户或批发市场名称）。
2. **运输及储存记录**：特别是对温湿度敏感的水果，可要求提供冷链物流单据，用以证明储运环节未造成二次污染。

**四、应对抽检的“责任承诺”**

1. **质量安全承诺书**：明确供应商对供货批次内农残超标的赔付及法律责任。
2. **召回协议条款**：如发生抽检不合格，供应商需配合立即召回并承担相应费用。

---

**给你的实操建议（针对抽检）：**

- **快检自查**：在收货现场或入库前，使用**快速检测卡**（如酶抑制率法）对高风险单品（如绿叶菜、草莓、葡萄、柑橘类）进行抽查，保留阴性结果记录。
- **批次对应**：将供应商提供的检测报告编号、送货单号、库房入库单号**三单关联**并存档至少2年，否则抽检时即使报告合格，若无法证明批次对应，依然可能被认定违规。
- **补充说明**：如果供应商无法提供当批次报告，可要求其提供**同品种近期（7日内）的检测报告**，并让其在送货单上签字确认“该批次品质与报告一致”。

**法律依据参考**：根据《食品安全法》第六十五条，食品经营者（超市）**必须**要对食用农产品进货查验记录，未按规定建立并遵守进货查验记录制度的，将面临责令改正、警告甚至罚款。因此，索证索票不仅是找供应商要，更是**超市自身的法定义务**。

如果供应商明确拒绝提供上述资料，建议立即终止合作，因为该类供应商在面临抽检时风险极高，且会牵连超市承担连带责任。
