这是一个典型的**水果店经营决策**，没有绝对的“唯一正确答案”，但可以根据**店铺定位、客流时段和损耗控制**，采用**分层销售**的策略。

以下是具体分析，帮你直接做决定：

### 1. 核心结论：建议“两条腿走路”
**最稳妥的方案是：整果必卖 + 提供“代削皮”服务（收费或免费），同时备少量“去皮净果”给赶时间的顾客。**

---

### 2. 三种模式的优劣势对比

| 模式 | 优势 | 劣势 | 适合场景 |
| :--- | :--- | :--- | :--- |
| **只卖整果** | 损耗几乎为零，库存压力小，单价高（称重卖） | 顾客回家削皮麻烦，容易流失“懒人”顾客；如果削皮技术差，顾客体验差 | 社区店、老客为主，追求高毛利 |
| **只卖去皮好的** | 客单价高（加工费溢价），即买即吃，能提升销量 | **损耗巨大**（去皮后水分流失快，隔夜变软），且无法辨别内部是否黑心，废果率极高 | 商场店、写字楼店、人流密集、追求周转快的店 |
| **让顾客自己挑（+代削）** | 顾客有参与感，看到新鲜果肉，信任度高；**损耗可控**（现场去皮，削多少卖多少） | 需要人工成本，且削皮速度要快；排队时易造成拥堵 | **绝大多数水果店的推荐做法** |

---

### 3. 具体执行建议（实操细节）

#### A. 整果是“基本盘”
- **卖点**：摆放在显眼位置，作为引流品。
- **话术**：可以跟顾客说“自己挑的放心，回去现削更甜”。
- **技巧**：准备一个削皮器，**免费帮顾客削好装盒**。这样一举两得——顾客觉得服务好，你也没有产生“去皮果”的库存损耗。

#### B. 去皮果是“效率品”（只做少量）
- **做法**：**只做2-3盒**放在保鲜柜里，用保鲜膜盖好，贴标签“现削”。
- **定价**：价格可以比整果贵15%-20%（比如整果5元/斤，去皮果按6元/斤或按盒卖）。
- **关键**：**下午5点前没卖完的，立即降价促销**（比如买一送一或当样品送），**坚决不过夜**。因为变色的菠萝会砸掉招牌。

#### C. 给顾客自己挑的“坑”要提前规避
- **问题**：顾客挑的菠萝可能没熟透（发青），或者局部有烂点，回家找麻烦。
- **对策**：
  - **分级摆放**：把熟度高的（皮黄、闻着香）挑出来，摆在一起标“即食”，降价处理；把生一点的标“放几天再吃”。
  - **承诺**：如果顾客挑到回去发现是坏的，凭小票无条件换。这样敢让顾客挑，反而建立信任。

---

### 4. 最终建议（按店铺类型）
- **如果你在小区/菜市场**：**主打整果+免费代削**。不用备去皮果，因为邻居大多愿意自己动手，偶尔需要帮忙削。
- **如果你在商场/写字楼**：**整果一半，去皮果一半**。且去皮果要用透明盒子装，冰镇卖，标注“免洗即食”。
- **如果你在旅游景点/夜市**：**只卖去皮果（切成块状）**，用竹签叉着卖，走量，当日清。

**一句话总结**：不要只卖整果（流失客户），也不要只卖去皮果（损耗致命）。**摆整果吸引目光，备少量去皮果满足快节奏，现场代削做增值服务**，这是最平衡的生意模式。
