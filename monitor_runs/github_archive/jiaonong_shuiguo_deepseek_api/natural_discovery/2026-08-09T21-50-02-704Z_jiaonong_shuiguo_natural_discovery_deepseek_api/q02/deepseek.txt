在进货时，四项指标的优先级建议按以下顺序权衡，并根据你的店型和周期灵活调整：

**核心排序：熟度 > 坏果率 > 价格 > 送货速度**

**1. 熟度（最重要，直接决定“可卖时间”）**  
- **为什么排第一**：香蕉是典型的“后熟型水果”，到货时的熟度决定了你还能放几天。  
- **具体做法**：选7-8成熟（果皮黄中带绿、果身硬挺）的货，给自己留下2-3天销售窗口。过熟货（全黄、有麻点）看似卖相好，但可能一天内就变黑，损耗极高。  
- **例外**：如果你的店在写字楼/地铁口，卖的是“即食需求”，可适当进九成熟货，但必须当日清完。

**2. 坏果率（决定隐形损耗和口碑）**  
- **为什么排第二**：哪怕价格便宜，如果一箱里有15%以上发黑、发软、断裂的，你不仅损失成本，还会影响整体陈列。  
- **建议标准**：开箱抽检，坏果率要≤5%。低于此标准的货，即使单价贵0.2-0.3元/斤，也更划算（因为坏果直接亏钱且占空间）。

**3. 价格（在熟度和品质过关后再谈）**  
- 在熟度和坏果率没问题的情况下，尽量压低进价。因为香蕉毛利本身不高（通常在20%-30%），价格差0.5元/斤可能就是10%的利润差。  
- 可以谈“阶梯价”：一次多进两箱，每斤可让利0.1-0.2元。

**4. 送货速度（影响最小，但需有底线）**  
- 香蕉不是急鲜货（不像叶菜），提前一天订货，次日到货即可。但如果供应商承诺“24小时内送到”却拖到36小时，会增加熟化风险。  
- **实用底线**：要求供应商有“当日达”能力，但不必为此多付20%运费。你可以接受慢一天，但绝不能接受到货时已经熟透。

---

**给你的具体操作建议（按你的店铺情况微调）：**

- **如果店铺日均销量≤40斤（小流量）**：重点谈熟度。进7成熟货，可以放3-4天。坏果率控制在5%以内，价格略高可接受，送货速度无所谓（约好次日到即可）。
- **如果店铺人流集中（如早市、学校门口）**：进8成熟货，掐准时间段上架，当天下午卖完。此时坏果率比价格更重要，因为多出10%坏果会直接让你亏本。
- **一个额外技巧**：选供应商时，先小批量试订两次（每次1-2箱），实际看它的到货熟度和坏果率再定长期合作。好供应商甚至会主动帮你避雷。

**提醒**：不要为了追求最低价进整箱货，除非你确认当天能卖完。否则熟透了，损失远超那点差价。
