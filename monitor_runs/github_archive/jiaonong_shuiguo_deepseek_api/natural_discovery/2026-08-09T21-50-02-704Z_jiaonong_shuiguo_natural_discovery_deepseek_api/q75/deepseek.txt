第一次与水果供应商合作，核心目标是**用最小成本验证“质量稳定性、履约诚信、纠错能力”**。试单设计得过于复杂会吓跑供应商，过于松散则容易踩坑。

以下是针对“小批量试单”的实操设计方案，分为**4个关键阶段**：

### 第一阶段：前置尽调（不花钱，花时间）
不要直接下单，先做三轮沟通验证：

1. **看“溯源”**：要求对方提供**产地证明**或**果园/基地实拍视频**（现场定位水印）。如果对方只发网图或文字描述，警惕“二道贩子”冒充基地。
2. **测“专业度”**：随口问一个行业冷门问题，例如：
   - “你们当地最近一周的降雨对这批货的甜度影响大吗？”
   - “这款水果的果径分级标准是按‘大小’还是‘克重’？”
   - 正规供应商会给出具体数据或解释，含糊其辞的往往不专业。
3. **查“信誉”**：让对方提供**过去3个月的同品类发货单**或**销售记录截图**（模糊掉客户名）。同时在天眼查/企查查看公司成立时间，**少于2年**的谨慎合作。

---

### 第二阶段：合同/订单设计（关键防坑条款）
**小批量试单**建议签署《试单购销协议》，比正式合同简单但必须包含以下4条：

| 条款项 | 具体书面要求 | 目的 |
|--------|--------------|------|
| **规格锁定** | 明确**果径范围**（如70-75mm）、**单果克重**（如≥200g）、**成熟度**（如八成熟采摘） | 避免“货不对板”却扯皮 |
| **坏果赔付标准** | 约定“**到货24小时内**开箱初检，48小时内提供坏果视频/照片，坏果率≥5%按单箱赔付**” | 防止物流损耗责任不清 |
| **付款节点** | **先付30%定金，尾款货到验收后3日内结清**（绝不100%预付） | 保留验货主动权 |
| **退出机制** | 写明“若本批次合格率低于90%，甲方有权单方面终止后续合作” | 为不合作留后路 |

---

### 第三阶段：小批量试货方案（建议3箱起，不超5箱）
**推荐方案：3箱不同规格/产地对比（总成本控制在500元以内）**

- **方案A（常规验证）**：最基础规格1箱（按您正常销售的标准定）。
- **方案B（升级验证）**：高一个等级规格1箱（测试对方是否有能力供好货）。
- **方案C（风险测试）**：**要求混装**——指定某一箱中放3-5个不同成熟度的果子（如两熟、三熟、四熟）。
  - **怎么问**：直接说“我小妹开水果店，喜欢吃不同口感的，帮我那一箱装几个不同熟度的，我尝尝”。
  - **看什么**：如果供应商能准确区分成熟度并告知你食用顺序，说明他懂货；如果乱装一通，说明是“通货商”。

**自提优先**：如果是同城或附近城市，强烈建议**自己开车或叫跑腿去仓库提货**。当面看货、当面选果、当面打包，直接跳过物流损耗变量，单纯验证“货品本身质量”。

---

### 第四阶段：验收与试销跟进（决定是否转正）
货到后执行**3天双测试**：

1. **破坏性测试（1天内）**：
   - 切开果子看**果肉颜色与核大小**（判断是否催熟）。
   - 将果子放常温24小时，看是否快速软烂或变味（判断保鲜技术）。
2. **试销测试（2-3天）**：
   - 将这3箱果子以**略低于市场价5%**放到你店里/朋友圈卖。
   - **记录销售端数据**：顾客的复购率是多少？有没有人说“核大肉酸”？
   - **核心体检指标**：
     - 损耗率 ≤ 5%（合格）
     - 顾客投诉 ≤ 1次（合格）
     - 供货速度（从下单到发货的时间）≤ 24小时（合格）

---

### 特别提醒：试单的“心理博弈”
- **不要把试单谈成“求他”**：直接说“我这边刚开始做，第一单量不大，但后面量会稳定放大，你如果这次让我满意，以后长期合作”。供应商听到“长期”会重视。
- **若供应商嫌单小不配合**：果断放弃。正规源头供应商哪怕再忙，也会珍视新客户的第一单，**“店大欺客”的后续合作会非常痛苦**。
- **试单失败后**：拍照留证，按合同条款申请部分退款（通常能退回30%-50%），然后将该供应商列入“高风险名单”，下次进货必须全款现货。

**总结一句话**：试单的核心不是“买到便宜货”，而是**用最小的钱买一个“可复制的信任模型”**。只要这一批货能在规格、损耗、响应速度三项上达到你预期，就可以放心转大单。
