商超水果采购要压低成本，核心逻辑不是“砍价”，而是**“用确定性换价格，用数据换议价权”**。品质下降往往是因为供应商在价格被压死后，被迫在分拣、包装或成熟度上做手脚。

以下是4个可行的谈判策略，建议按顺序执行：

**1. 用“包销协议”换“源头价”**
不要在单一批次上狠压价，而是谈**长期框架**：
- 话术：“如果这个品类我每月固定给你XX吨的保底量，连续签6个月，你在出厂价上直接让利8%，行不行？”
- 逻辑：供应商最怕库存和损耗。你给他确定性，他给你毛利。品质标准写进合同（如糖度≥13、损伤率≤2%），价格锁定，违约赔付。

**2. 谈“扣重率”而不是“单价”**
水果箱重、含水冰块、包装重量是隐性成本。压低单价容易扯皮，但谈**净重标准**更有效：
- 话术：“你按带箱毛重报价，折算下来我实际到手净果成本高了不少。咱们按果品净重计价，我把损耗责任担起来，你每斤多让5毛纸箱钱。”
- 实操：现场抽称3箱，按平均扣重率折算成单价，直接写入采购单。

**3. 用“尾货折扣”和“分档采购”保品质**
品质由**等级分选**保证，而不是靠统货赌运气：
- 谈判时要求供应商按S、M、L三级分选，你只采购特级果（占总量约70%）。
- 话术：“我按市场价采购你的特级果，但你的次级果（B级）我按特价30%收走，帮你清库存，但前提是特级果质量必须保持稳定。”
- 这样既不压死核心品质线，又帮供应商消化了难卖的部分，他自然愿意让步。

**4. 谈“履约服务”而非单纯砍价**
品质风险由供应商承担，价格才有空间：
- 要求供应商承诺“到店后24小时内出现腐烂、黑心、重量不足，凭开箱记录照价赔偿或换货”。
- 谈判话术：“如果你敢把这个条款写进合同，我可以接受你单价上浮2%，但总成本还是低于市场，因为我的损耗从8%降到3%。”
- 这本质上是把“压价的矛盾”转化为“风险分担的共赢”。

---

**特别提醒（避免踩坑）：**
- **不要**要求供应商“便宜又最好”，这会导致他偷换产地或成熟度（比如用催熟瓜替代自然熟瓜）。
- **判断品质的硬指标**：在谈判现场随机切开2个果看芯部颜色（糖度仪测Brix值）、捏硬度、看果蒂新鲜度。品质不达标的，宁可放弃，也不要用降价弥补。

**最终话术模板（可直接用）：**
> “张总，我这月要20吨金果，特级果11.5元/斤。但我要你保证：①净重按去箱去冰算；②糖度≥12.5，坏果率≤1.5%；③你写进合同，有质量包赔。你能做到，我今天就签续季度合同，量给你翻倍。你算一下，够不够成本？如果能，我按11.3跟你定。”

这样谈下来，供应商的利润空间是有的（靠量大和次级果变现），品质风险也在你控制中，且成本比市场平均低10%-15%。
