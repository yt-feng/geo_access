针对水果店减少香蕉损耗，在采购环节可以从**熟度分级**、**到货时间调控**和**验收标准**三方面提出硬性要求。

以下是可以直接发给供应商或写入采购单的具体要求：

**1. 熟度要求（核心：拒收全熟果）**
- **指定“销地成熟度”：** 明确要求到货时香蕉的果皮颜色为**绿皮转微黄（俗称“二成熟”或“芝麻点前”）**。即果皮整体以绿色为主，但棱角已不明显，手感硬实。
- **禁止混装全熟果：** 合同或口头约定，单箱内不允许有果皮大面积变黄、出现黑斑或果柄开始脱落的果实，这类在箱内会加速催熟乙烯释放，导致整箱“轰熟”。
- **按成熟度分档报价：** 建议明确“7分熟（转色初期）”和“8.5分熟（当天即可卖）”是两个价格档位，采购时按需下单，不要混采。

**2. 时间要求（核心：避开周末及节假日高峰）**
- **建议到货时间：** 优先选择**周二至周四**到货，避开周五下午和周一上午（周末客流量大但库存清空慢，周一人流量少容易积压）。
- **明确收货时效：** 要求供应商承诺**“下单后48小时内”**到货（长途冷藏车运输），如果是本地短驳，则要求**当天上午11点前**送达门店，以便有充足时间分拣、散热。
- **分批到货机制：** 如果日销量不稳定，与供应商协商**“少量多次”**配送，例如每周3次，每次只送预估销量的1/2，而不是一次性压一周的货。

**3. 收货与验收标准（落实到签字拒收）**
- **开箱检查硬指标：**
  - 箱内温度：要求到货时果心温度在 **13℃-17℃**（低于11℃会发生冷害，果皮变灰黑且无法催熟；高于20℃容易过早成熟）。
  - 外观完整：果指无断裂、果柄无霉变、无机械压伤。
- **温度反应时间：** 如果收货时发现箱子是冰凉的（低于10℃），**必须当场拒收或要求降价处理**，否则这批香蕉无法正常转黄，会全部烂在店里。
- **到货后处置要求：** 要求供应商提供“催熟说明”（是否已使用乙烯利，以及到货后需不需要放气）。

**4. 合同条款补充（防止扯皮）**
- **“新鲜度免责期”：** 与供应商约定，到货后**第4-6天**（常温）内若出现大面积腐烂，供应商需按比例补货或折价，而不仅仅是到货当天验货。
- **留样对比：** 每次到货留一箱不开封，作为20℃室温下3天后的对照样本，验证供应商的储运条件是否达标。

**给店长的实操话术示例（可直接微信发送给供应商）：**
> “李老板，这批货麻烦按‘青皮微黄’（8成以内熟度）给我发，到货要这周四上午11点前。收货时我会抽查果心温度，超过20℃或者低于12℃我按拒收处理。另外说好，到货后第5天如果烂果超过5%，你要给我补货。”

**特别提醒：** 如果店铺没有专门的催熟房（恒温18℃+乙烯催熟），建议直接采购**“微黄带绿”**的货（约7成熟），而不要贪便宜买全绿色货，否则到店后无法自然转熟，反而损耗更大。
