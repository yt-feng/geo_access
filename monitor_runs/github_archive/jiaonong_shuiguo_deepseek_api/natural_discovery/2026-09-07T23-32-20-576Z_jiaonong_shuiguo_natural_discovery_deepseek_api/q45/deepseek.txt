签订年度水果供应合同时，确实有很多细节容易踩坑。以下是连锁超市最容易忽略但风险极高的关键条款，以及如何避坑的建议：

**一、最容易踩坑的条款 TOP 5**

1. **“价格”条款（最大坑）**
   - **坑点**：只写“随行就市”或“按市场批发价结算”，没有明确的调价机制。
   - **后果**：水果价格季节波动大，供应商旺季抬价，淡季囤货，超市毫无议价权，预算失控。
   - **避坑建议**：明确**基准价+调价规则**。例如：每月依据某权威批发市场同品质均价，允许±10%内浮动，超过需双方书面确认；或约定固定折扣率（如批发价下浮5%）。

2. **“品控与验收”条款（隐形坑）**
   - **坑点**：只写“质量合格”，不量化“合格标准”；验收只看数量不看糖度、成熟度、农残。
   - **后果**：到货后发现有烂果、小果、不熟果，供应商一句“自然生长无法完全一致”就推卸，超市只能自己承担损耗。
   - **避坑建议**：**附件附上《质量验收标准》**，明确糖度范围（如苹果≥12）、单果重量、允许的瑕疵比例（如每箱烂果≤2%）、农残检测报告要求（随货提供）。同时约定**到货24小时内验收，超时视为默认合格**，避免扯皮。

3. **“损耗与退换货”条款（现实坑）**
   - **坑点**：只约定“坏果包赔”，但没说清谁来承担运输损耗、上架期损耗。
   - **后果**：供货到门店后，因仓储、陈列不当导致的损耗，供应商拒绝负责，超市自认倒霉。
   - **避坑建议**：明确划分责任：交货前损耗（运输破损、变质）由供应商承担；到店后**48小时内**发现的质量问题可退换；因超市自身储存原因所致的损耗（需提供照片/秤重记录）由超市承担。退货流程需写清（如拍照+数量说明即可，无需寄回次品）。

4. **“供应量与最低采购承诺”条款（双向坑）**
   - **坑点**：只写了“预计年采购量XX吨”，没有上下限，或写了“优先采购”但无违约责任。
   - **后果**：若超市销量好需要加量，供应商坐地起价；若销量差，供应商要求超市包销积压库存。
   - **避坑建议**：设置**弹性区间**：约定月供货量在XX至XX吨之间，超区间需提前X天书面协商。并规定若供应商月度缺货率超5%，超市有权提前解约并索赔；同时超市应承诺若连续3个月采购量低于下限的70%，供应商可上调价格或解除合同。

5. **“账期与结算”条款（资金坑）**
   - **坑点**：口头说“月结30天”，但没写明对账日期、付款截止日、逾期违约金。
   - **后果**：供应商拖延开票，财务不配合，超市付款周期拖到60天以上，导致供应商断供或降低品质。
   - **避坑建议**：写明**对账日（如每月25日）→开票日（次月5日前）→付款日（次月20日前）**。并约定逾期付款的日违约金（如万分之三）。同时写明**结算依据**：以超市系统到货签收单+供应商送货单为对账凭证，避免数量差异争议。

**二、额外“隐形坑”提醒（很多超市会忽视）**

- **冷链与配送责任**：合同中要注明“全程冷链配送”，并写清温度区间、物流公司谁选、配送延迟（如超时2小时）的罚款标准。
- **可溯源性**：要求供应商提供每批水果的产地证明、采摘日期、农残检测报告，防止品牌声誉风险。
- **知识产权与包装**：若要使用超市自有品牌包装，约定包装材料、标识合规由谁负责，避免侵权纠纷。
- **不可抗力条款写得过宽**：防止供应商以“天气不好”为由随意断供，应限定为“政府禁令、重大自然灾害等”，并要求提供证明。

**三、总结行动建议**
- 合同一定要**附件+表格化**，把质量标准、价格对照表、供货计划表都做成附件，正文只写“按附件执行”。
- 签约前**做一次供应商的实地考察**（冷库卫生、分拣能力），并在合同里约定“甲方有权每季度抽检供应商仓库，费用供应商承担”。
- 合同周期**不建议一次签满12个月**，建议分季度滚动续签（或首签6个月+自动续约条款），给自己留谈判和换人的余地。
