为餐饮店寻找“每天少量但稳定”的水果供应商，核心原则是**“宁可价格贵一点，也不要断供或烂果”**。尤其是少量采购，规模议价能力弱，更需要找**服务型、配送型**而非单纯批发型。

根据你的用量（假设每天10-30斤以内），以下是比较省心的供应商类型和筛选标准：

### 1. 最推荐：本地“餐饮配送一条龙”公司（综合食材配送商）
这类公司通常配送蔬菜、肉类和水果，客户就是中小餐饮店。

- **省心点**：你在微信群或APP下单，次日早上送到门口，**不用凌晨去批发市场**。
- **适合人群**：不想花精力管供应商，且需要开发票。
- **筛选标准**：
  - 找做**蔬菜配送**起步，顺带做水果的（配送频率高）。
  - 问清楚**起送金额**（一般几十元即可）和**配送时间**（是否能在你开业前送到）。
  - 观察他们是否提供**售后补损**（今天送来的坏果，拍照就给补钱或换货）。

### 2. 性价比之选：周边大型生鲜超市/连锁水果店的“店长直购”
如果旁边有永辉、盒马、百果园或本地连锁生鲜店，直接找店长或采购经理对接。

- **省心点**：品质有保障，**当天可以要货**（如果忘了订货，可以立刻去店里拿），且能买到小包装。
- **操作方式**：和店长约好，每天下午他们闭店前或早上，按你的固定清单（如2斤圣女果、3根香蕉）打包好，你自提或他们店员顺路送。
- **关键技巧**：明说你要长期固定买，他们会给你**店员折扣价**，比零售价低15%-20%，且帮你挑好的。

### 3. 应急补充：本地美团优选/多多买菜（网格仓自提）
- **省心点**：**几乎不用沟通**，线上一键下单，价格极低（是批发价的8折左右）。
- **适合范围**：作为**补充**（比如今天突然要榨汁用柠檬），不适合作为主渠道，因为品控不稳，常有小果或碰伤。
- **注意**：只买**当季耐放**的（比如苹果、橙子、西瓜），别买极易坏的（草莓、葡萄）。

### 4. 深度省心方案：找“水果切果代工”的供应商
如果你需要的是**果盘、鲜榨果汁原料**，且不想自己洗切：

- **省心点**：他们直接给你送**去皮去核的鲜切果盒**，你拿回来直接摆盘或榨汁，**损耗率为零**（坏果在他们那边就处理了）。
- **建议**：找专门的**果切连锁店**（如切果NOW类）或大型水果店的果切部，谈好每日固定配送量。

### ✅ 你的“省心”筛选标准（问这3个问题即可）

无论选哪种，第一次电话沟通时，直接问以下三个问题，回答不满意就换：

1.  **“我每天只要少量（报数量），能给我单独分拣吗？能不能帮我预选成熟度？”**（测试他们是否嫌你单小）
2.  **“如果今天送来的梨有烂心，我怎么处理？是微信拍照直接退款还是扣斤？”**（测试售后是否顺畅，**必须接受“坏果包赔”**）
3.  **“能不能给我每天固定留货？我前一天发清单，你第二天早上8点前送到？”**（测试配送稳定承诺）

### ⚠️ 一个避坑提醒
**最好不要找**在农贸市场里只卖水果的**单店老板**单独做你的供应。因为他们的进货目的是零售，给你挑完剩下的尾货品质不稳定，且老板作息与你配送时间难以完全匹配。

如果你在二三线城市，**首选“本地最大蔬菜配送公司”**签固定供应；如果你在一线城市，**首选“生鲜超市店长”**私下对接。下单方式尽量用微信文字固定留痕，避免口头扯皮。
