在超市采购水果时，为了应对市场监管部门的农残抽检并确保合规经营，你**应提前向供应商索取并留存**以下核心资料。这些资料既是采购合规的“通行证”，也是发生抽检不合格时用于追溯和申诉的重要依据。

**1. 农业生产环节的资质与承诺（原件或加盖公章的复印件）**
- **《食用农产品合格证》/《产地准出证明》**：这是最基础的“身份证”，证明该批水果产自合法种植基地，且供应商承诺其质量合格。
- **种植基地的《营业执照》或《法人身份证》**：用于确认产地主体身份。
- **由供应商或基地签字盖章的《农残安全承诺书》**：明确承诺不含禁限用农药，如有违规愿承担全部责任。

**2. 批次抽检与检测报告（随货同行）**
- **该批次的农残检测报告**：优先索要**第三方权威机构（如SGS、华测、省市级质检院）**出具的**带有CMA或CNAS标志**的报告，且报告日期应接近供货日期。
- 若供应商无法提供第三方报告，必须要求其提供**基层快检室**出具的《快速检测合格证明》（但需注明该报告仅对采样样本负责，不能完全替代法检）。
- **注意**：必须要求报告上的**产品名称、供应商名称、发货日期**与本次采购一致，严禁用“通用报告”代替批次报告。

**3. 购销凭证与追溯信息（管理台账）**
- **正规的购销合同或订单**，明确载明水果品种、数量、产地。
- **增值税发票或销货清单**，这是财务和抽检追溯的必备凭证。
- **完整的物流运输单**（车牌号、驾驶员信息），确保运输过程无二次污染或非法添加。

**4. 供应商内部质量控制文件（可选择索取）**
- 供应商的《农药使用记录》或《田间档案》，但需由供应商自愿提供，若涉及商业机密，应在合同条款中约定“供应商承诺农药使用符合国标”。

**5. 特别风险防控：高检出率品种**
- 针对**豇豆、芹菜、韭菜、草莓、葡萄**等高风险品种，**必须强制要求**供应商提供**同一产季**的第三方专项检测报告（针对毒死蜱、氧乐果、克百威等禁限用农药增项检测）。

---

**给你的落地操作建议（关键）**：

1. **留存不等于摆设**：所有纸质资料必须**随货同步存档**，且保存期限建议**不少于6个月**（各地监管要求不同，建议参照食品安全法最低2年）。
2. **验收环节核验**：在收货时，**核对检测报告上的“批号/生产日期”**是否与实物外包装标签完全吻合，防止张冠李戴。
3. **配套自检机制**：对于无法提供第三方报告的供应商，**超市采购方应执行“先快检、后上架”**，每日对高风险品进行农药残留快检，并做好不合格销毁记录。
4. **签订合同约束**：在采购合同中明确加入**“无条件退换货及承担抽检不合格赔偿”**条款，将供应商风险转嫁给制度。

**特别注意**：如果供应商提供的是“复印件”，务必请对方在复印件上**加盖鲜章**，否则在药监部门执法时可能被视为无效追溯凭证。
