判断一批香蕉的熟度和坏果风险，是批发采购中最关键的环节。以下是可执行的实操建议，分为**看、摸、闻、称、问**五个步骤：

---

### 一、判断熟度（核心：看颜色+手感）

| 判断维度 | 具体操作 | 结论 |
|---------|---------|------|
| **整体颜色** | 抽3-5箱看果皮颜色 | 全绿带青茬 = 未熟；黄绿过渡（果柄稍绿、果身微黄）= 7-8成熟（适合自然催熟）；全黄无青 = 已熟（2-3天内必须售完）；出现黑点 = 过熟 |
| **果肉硬度** | 用手轻捏香蕉中段 | 坚硬、捏不动 = 果肉白硬，未熟；有弹性、微微软 = 最佳存储期；一捏就凹下去 = 已软，风险高 |
| **果柄状态** | 看果柄（香蕉把） | 新鲜微青 = 近期割下；干枯发黑 = 存放过久 |
| **果皮光泽** | 均匀光泽带果粉 = 新鲜；暗沉无光 = 老化 |

**关键提醒**：如果目标是批发到二级市场（超市/水果店），建议选**黄绿各半（约7成熟）**的货，这样商家有3-4天销售窗口。如果下游客户是即买即走的散户，可选**8-9成熟（全黄带少许绿端）**。

---

### 二、坏果风险排查（现场实操）

1. **翻箱看底层**  
   不要只看顶层，用手把最上层香蕉挪开，重点抽查**中间偏下**的箱子。坏果常隐藏在底下，因为堆放时重力挤压导致。

2. **看果蒂和果把连接处**  
   发黑、发霉、有白色菌丝 = 灰霉病，会传染。如果一批货里超过 **2-3%** 出现这种，整批风险极高，建议放弃。

3. **闻气味**  
   靠近箱子闻——如果有**甜腻发酵味**或**酸味**，说明有腐烂果；正常香蕉只有淡淡青草气。用鼻子贴近果皮缝隙闻更准。

4. **按压抽查**  
   随机挑5-8根，轻捏中段和两端。如果捏到局部发软但其他地方硬 = 内部开始霉变（外伤导致），这类果外观好看但切开已有黑心。

5. **掂重量（可选）**  
   同样体积的香蕉，明显偏轻的往往水分流失快，耐运输性差。

---

### 三、降低风险的谈判话术与策略

- **先谈后验**：先表明“我要验货”，要求卖家开箱配合。
- **抽样比例**：单批200箱以上，至少开箱验6-8箱（上中下各2-3箱）。
- **保留证据**：发现明显坏果时，用手机拍下具体箱号和坏果特写，再谈议价或换货。
- **约定标准**：签单前口头确认“若到货30%出现腐烂/严重黑柄，支持部分退货或折价”，避免事后扯皮。

---

### 四、特别提示（切勿忽略）

- 如果当前是**夏季/高温**（超过32℃），即使外观全绿，也可能在运输中“闷熟”自热——这类货风险高，建议只拿成熟度偏低（果皮全绿但果身饱满）的货。
- 如果天气连续**多雨**，蕉农可能提前抢收，果肉硬但糖分不足，口感差，后期易出现黑心。
- **坚决不拿**：果柄渗出褐色汁液、果皮有明显黑斑且按压有软烂感的货——这是炭疽病或运输碰撞后的霉变，不可逆。

---

**一句话总结**：最优拿货标准 = **果皮黄绿分明（7成）、果柄青绿、捏起来有弹性但不软、无发酵味、箱内无渗水迹象**。拿到这种货，再配合催熟库控制温度（以18-20℃缓慢催熟），风险最低。
