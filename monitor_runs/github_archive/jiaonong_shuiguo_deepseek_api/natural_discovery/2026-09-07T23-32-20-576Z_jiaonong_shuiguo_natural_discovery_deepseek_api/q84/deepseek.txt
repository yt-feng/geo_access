针对家庭水果礼盒，组合的核心是**营养均衡、耐储存、日常消耗快、老人孩子都爱吃**。以下推荐几套实用方案，你可以根据预算直接选用：

**方案一：经典实惠型（性价比最高）**  
搭配：**苹果（4个）+ 橙子（4个）**  
适合：预算有限、注重日常营养。苹果香蕉最耐放，橙子补充维C，家庭消耗最快，不易浪费。

**方案二：周末分享型（分量足）**  
搭配：**苹果（3个）+ 橙子（3个）+ 香蕉（1把，约5-6根）**  
特点：香蕉不立即吃完容易熟透，建议在礼盒内放一张“香蕉先吃”提示卡，这种组合适合周末多口之家。

**方案三：轻奢型（菠萝升级）**  
搭配：**橙子（3个）+ 菠萝（1个）+ 苹果（2个）**  
注意：菠萝必须附送削皮刀或切好密封，且需提醒“当天食用”，否则容易氧化变味。适合送礼或想多尝鲜的家庭。

**要点提醒（直接影响体验）：**
- **香蕉不与苹果/菠萝混放**：苹果和菠萝会释放乙烯催熟香蕉，导致香蕉快速变黑。若必须混放，请用软纸单独包裹香蕉。
- **苹果选脆甜的**（如红富士），孩子老人更喜欢；橙子选赣南脐橙或冰糖橙，酸度低。
- **包装分层**：底部放菠萝（硬），中层橙子，顶层苹果，香蕉用气泡纸单独隔开，避免压伤。
- **若团购量大有议价空间**，建议追加“免费代削菠萝”服务，这是家庭客户最在乎的痛点。

**一句话决策**：如果是自家吃，选**苹果+橙子**最稳；如果走量开团，主推**苹果+橙子+香蕉**（成本低且好看）；如果要拉高客单价，就加菠萝并提供现场切盒服务。
