判断香蕉一手货源是否稳定，不能光听对方口头承诺。以下是一些具体、可操作的方法：

**1. 看“三个周期”的稳定性**
- **看可追溯的供货记录**：要求对方提供过去半年或一年的发货记录（物流单、产地出货单、结算流水），重点看是否有**季节性的断供**。香蕉主产区（云南、广西、海南及进口国如菲律宾、老挝）有季节性，但要看他是否有多个产地可切换（如冬季靠进口或海南，夏季靠本地）。
- **问“淡旺季”问题**：直接问：“如果遇到台风、霜冻或口岸检疫（进口货），你通常怎么保供？”稳定档口会给出备选方案（如提前锁货、换口岸、用冷库缓冲），而不只是说“没问题”。

**2. 实地考察与物理证据**
- **看冷库/周转场**：最好去对方档口或仓库，看是否有**恒温库**、香蕉催熟房或周转能力。如果只有“车到货走”没有仓，说明抗风险能力弱，雨季或集中到货时容易断供。
- **看装箱标签与产地证明**：要求看当批货的产地证明（如云南河口、缅甸、菲律宾产地证），并核对包装箱上的唛头、品种、日期是否与发你的货一致。稳定供货商一般会有固定的包装厂合作，中途换厂也属正常，但应有书面告知。

**3. 小额试单 + 压力测试**
- **先做2-3次小批量试单**（如一周一柜或两车），观察**到货准时率**和**货损率**。稳定供货意味着断供频率低，且坏条率（通常5%以内为佳）有兜底赔付承诺。
- **“突然加单”测试**：在非旺季，临时提出加量20-30%，看对方是否能在3天内接单。能快速“拼货”或调货的，说明上游果园/农场关系稳固；推三阻四的，多半只是二道贩子临时找货。

**4. 核心风险点：警惕“中间商包装”**
- 真正的“一手货源”通常能提供**农户/农场的包销合同**或冷库入库单。如果对方只给你看微信群里的报价截图，或无法指出具体农场、砍蕉码头位置，大概率是转了好几手的“截货客”——他们价格低，但香蕉品控参差，且随时可能因为上游另卖而断供。

**5. 合同与结算方式**
- 稳定供货商敢签**长期供货框架协议**，约定保底数量、质量等级和违约责任。如果对方只接受现金随行就市、不签任何违约条款，基本可以判定为不稳定。
- **付款模式**：一手货源通常要求“预付款+尾款”或“定金锁价”。若对方要求全额预付才发货，风险极高；反之，主动支持账期（老客户）说明其现金流健康。

**最后建议**：最稳妥的做法是**同时保持2个以上备选供应商**（一个主供、一个应急），哪怕找到稳定货源也别把所有鸡蛋放一个篮子里。香蕉是易腐品，产地变动快，稳定是相对的，管理风险比寻找绝对稳定更重要。
