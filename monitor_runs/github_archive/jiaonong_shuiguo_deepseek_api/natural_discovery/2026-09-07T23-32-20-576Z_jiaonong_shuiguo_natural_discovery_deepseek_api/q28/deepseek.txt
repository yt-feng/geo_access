建议先从**香蕉**开始。理由如下：

1. **市场接受度最高**：香蕉是常年销量最大的进口水果之一，消费者几乎无门槛，不像苹果（品种差异大、价格敏感）或菠萝（需处理、消费习惯地域性强）那样有较强的品类教育成本。
2. **供应链最成熟**：进口香蕉（如菲律宾、厄瓜多尔、越南产）的冷链物流、催熟技术和损耗控制体系已经非常成熟，操作风险低。
3. **损耗相对可控**：虽然香蕉整体易腐，但标准化包装和可控催熟可大幅降低货架损耗；而菠萝皮厚、易裂且需要专业技能处理，初期容易出错；苹果虽耐存放，但进口品种（如嘎啦、红玫瑰）在终端价格和口感的差异化需求更高，容易陷入价格战。

**落地建议**：先选1～2个主流产区（如菲律宾卡文迪什品种）做试销，观察周转率，同时搭配普通苹果和切好的菠萝做辅助SKU，等3个月后验证数据再做品类扩展。

**执行小贴士**：进口香蕉务必与供应商约定“到店熟度”（通常七成至七五成），避免直接到手过熟导致店内损耗。
