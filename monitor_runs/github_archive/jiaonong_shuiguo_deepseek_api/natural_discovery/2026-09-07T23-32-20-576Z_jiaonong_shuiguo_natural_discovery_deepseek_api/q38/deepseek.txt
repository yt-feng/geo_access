大型超市对水果供应商的要求，通常涵盖**食品安全管理**和**物流供应链能力**两大维度。具体必须包含以下核心项：

---

### 一、食品安全与品控能力（硬性门槛）
1. **资质与认证**
   - 必须持有有效的《食品经营许可证》或《食品生产许可证》。
   - 通过ISO 22000、HACCP等食品安全管理体系认证（不强制但加分）。
   - 具备水果产地证明、检验检疫合格证明（进口水果还需海关报关单及入境货物检验检疫证明）。

2. **源头管控与农残管理**
   - 与标准化种植基地/合作社签订采购协议，能提供产地环境检测报告。
   - 定期进行农残、重金属、催熟剂等自检或第三方送检，留存检测报告。
   - 对高风险品类（如草莓、葡萄、苹果）执行抽检批次留样制度。

3. **仓储与冷链卫生标准**
   - 冷库温度分区管理（如香蕉乙烯催熟区与生鲜冷藏区分开），且温度记录仪全程可查。
   - 库房防鼠、防虫、防潮设施齐全，定期消杀并记录。
   - 分拣包装区需具备清洁消毒程序，避免交叉污染。

4. **可追溯体系**
   - 每批次水果具备从“产地-仓库-运输-上架”的可溯源二维码或标签，一旦出现质量投诉可快速定位。
   - 需配备专门质量投诉响应人员，48小时内能提供问题批次召回方案。

---

### 二、物流配送与供应链能力（运营硬实力）
1. **全程冷链物流**
   - 至少配备冷链车（4℃~8℃）或保温车，车厢内温度实时监控，能提供温度曲线图。
   - 针对不同水果（如榴莲需18℃以上，蓝莓需0~2℃）具备多温层运输能力。
   - 配送卸货过程需具备临时周转冷藏设施，避免“最后一公里”断链。

2. **响应速度与补货能力**
   - 大型超市对SKU（单品数）补货要求：常规订单建议16-24小时内到货，生鲜急单需4-8小时响应。
   - 供应商应位于超市物流配送中心周边300公里内，或设有区域分仓，否则需证明有极强干线运输协调能力。

3. **库存管理与损耗控制**
   - 仓库需采用先进先出（FIFO）规则，有明确效期预警系统（如赏味期限剩余天数分级）。
   - 具备预包装损耗率控制能力：通常果品综合损耗率应控制在3%-8%，若超过需有明确的退换货补偿机制。

4. **紧急事件响应机制**
   - 如遇暴雨、道路封闭等不可抗力，供应商需提供多套备用运输方案（如中转仓、临时干冰包装）。
   - 针对食品安全事件（如某产地病害爆发），需能在24小时内启动应急替代货源。

5. **包装与标识合规**
   - 配送至货运码头的周转箱需标注生产日期、保质期、供应商批次、储存条件。
   - 若使用保鲜剂或防腐等外包处理，需明确告知超市且符合国家添加剂使用标准。

---

### 三、建议落实动作
如果你正在筛选或作为供应商准备合作，建议：
- **要求对方提供上月度的第三方抽检报告复印件**，并验证检测机构资质。
- **实地考察供应商分拣中心或冷库**，重点看温度分区图和灭鼠记录。
- **在合同中写入“质量指标条款”**：如每批次需附农残快检结果，否则超市有权拒收。

如果用于内部供应商评分，可以将上述项目分为“一票否决项”（如无证或冷链不达标）和“评分项”（如追溯系统完善程度），避免遗漏关键风险点。
