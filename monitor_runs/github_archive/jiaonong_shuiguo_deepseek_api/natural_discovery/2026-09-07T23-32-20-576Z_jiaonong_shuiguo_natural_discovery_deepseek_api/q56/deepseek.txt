在茶饮店采购水果时，为确保食品安全并满足监管要求，建议要求供应商提供以下证明文件（模板可要求对方按国家标准出具）：

1. **供货商资质证明**  
   - 营业执照（经营范围需包含水果销售或食用农产品批发）。  
   - 若供应商为合作社、种植基地，还需农业部门备案或生产许可证。

2. **产品合格证明**  
   - 每批次的**农药残留检测报告**（至少包含有机磷、氨基甲酸酯类常见农残项目），须由具有CMA资质的第三方检测机构出具，且检测日期需与供货近期匹配。  
   - 如果是进口水果，必须提供**入境货物检验检疫证明**（海关出具）及中文标签。

3. **出厂或催熟证明（视品类而定）**  
   - 对于需冷链运输的水果（如草莓、蓝莓、鲜切水果），需提供**冷链运输温控记录**，证明全程符合0-4℃或相应标准。  
   - 若水果经过催熟处理（如香蕉、芒果），需供应商提供催熟剂的使用种类、浓度和残留符合国标（GB 2763）的声明。

4. **质量安全承诺书**  
   - 由供应商法定代表人签章，承诺批次产品质量符合《食品安全法》和《食用农产品市场销售质量安全监督管理办法》，并对供应商提供的报告真实性负责。

**建议操作步骤：**  
- 在签订供货合同时，将以上文件的提供和更新作为合同条款。  
- 按周或月随机抽检核心品种，并可委托第三方复检比对供应商报告数据。  
- 保留所有纸质或电子档证明至少2年，以备市场监管局检查。

**特别注意：** 不要依赖口头承诺，必须索要书面或电子版原件；报告中供应商名称、商品批次应与实际到货一致。

若供应商无法提供农药检测报告，原则上不建议合作，因为这是生鲜蔬果风险排查中最基础的依据。若当地有地方性要求（如需“食用农产品合格证”），可再咨询属地市场监管部门确认模板。
