水果店想减少香蕉损耗，核心在于“分批次到货”和“控制成熟度”，而不是一次性进大量。以下是针对采购环节的具体要求和操作建议：

**1. 熟度要求（最关键）**
- **拒绝全熟货**：明确要求供应商发送“青熟”或“微转黄”的香蕉（表皮底色偏绿，无明显果斑）。
- **具体操作**：在采购单上注明“催熟度要求：3-4成（果皮青绿，果肉硬）”，避免发“7-8成熟”的即食香蕉，因为到店后很快会过熟霉变。
- **额外要求**：明确禁止供应商使用乙烯利催熟过度（香蕉打开包装有浓烈酒味或果柄发黑即是问题）。

**2. 到货时间要求**
- **分三批间隔到货**：不要一次性进一周的量。建议每周到货2-3次，每次间隔2-3天，这样既能保证不断货，又不会大量积压。
- **到店当天温度**：要求供应商使用冷藏车（常温车夏天易焖坏），到店卸货时表皮温度不得超过25℃（避免高温灼伤）。
- **避开高峰时段**：要求供应商在早上开门前或晚上闭店后到货，避免在白天客流高峰时段搬运造成挤压碰撞。

**3. 采购时额外附加的条件（写在合同或口头明确）**
- **损坏包赔**：要求供应商承诺“到货时若有10%以上黑斑、撞伤或果柄腐烂，按比例折价或补货”。
- **附赠催熟建议**：请供应商给出每箱可存放天数建议（例如“该批香蕉常温可放3天，冷藏可放5天”），便于安排库存。
- **要求小箱规格**：选用重量轻、单层纸箱（比如5公斤/箱）代替大箱，方便翻面检查，减少底层压坏。

**4. 实操时的验收动作**
- 到货时**抽开3-5箱**，检查果皮是否有针孔（催熟痕迹）、是否有压痕。
- 用手轻捏果柄：如果果柄一捏就烂出水，说明过熟，拒收。
- 入库时不要叠放太高（最多叠4箱），留缝隙通风。

**预算与建议：**
如果店铺销量不稳定，第一周可以先采购最低起订量（比如2箱），观察卖完所需时间，再根据销速调整下次采购数量。一般来说，**“到货后预计可卖2-3天”** 是比较安全的采购节奏。
