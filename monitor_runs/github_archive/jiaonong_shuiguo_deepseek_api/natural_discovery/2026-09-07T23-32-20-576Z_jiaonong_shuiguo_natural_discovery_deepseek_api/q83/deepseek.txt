收到货后发现坏果，责任划分需要根据**具体原因**来确定。总的来说，可以按以下几个环节梳理：

1. **产地/包装环节**：如果果子在发货前就存在内部损伤、病虫害、过度成熟，或者包装防震、防压措施不达标（比如没放泡沫网、果箱太薄），导致运输过程中容易挤坏，这主要责任在**商家/供应商**。
2. **物流运输环节**：如果是快递途中摔打、挤压、长时间滞留（比如高温天在路上多放了一天），导致果子被闷坏或压坏，责任主要在**物流承运方**。但消费者通常无法直接找物流索赔，仍需由商家先行赔付，商家再向物流追偿。
3. **收货环节（消费者）**：如果买家签收后没有及时开箱验收、未按储存条件（如需冷藏却常温放置）存放，造成后续腐败，责任主要在**消费者本人**。但注意：如果坏果占比极小（比如一箱10个坏了1个），且非整箱腐烂，通常属于正常损耗，商家一般不承担全部退款，但应提供部分补偿或补发。

---

**实操建议（对顾客/商家均适用）：**

- **消费者角度**：签收后当日内开箱，拍下坏果照片（最好带外包装和全箱俯拍），立即联系客服。如果坏果超过约定比例（如超过10%），可要求退款、补发或按比例赔付；超时未验收再申述，商家可拒赔。
- **商家角度**：如客户证据清晰，建议主动按“坏果包赔”条款处理；如怀疑物流问题，应留存运单和照片向快递投诉，而不是让客户等快递理赔结果。

**如果实在无法判定环节**，生鲜行业通用原则是**“谁面对消费者谁先赔”**（即商家先行赔付），商家再依证据追偿供应链或物流。这样可以更快解决纠纷，也符合平台规则。
