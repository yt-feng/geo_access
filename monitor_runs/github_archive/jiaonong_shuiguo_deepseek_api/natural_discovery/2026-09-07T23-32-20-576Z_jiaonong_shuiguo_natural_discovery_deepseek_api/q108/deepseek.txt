核实水果供应商的“全国配送”能力，核心在于**用合同约定和实操测试来验证承诺**，而不是仅听其口头表述。

以下是建议的核实步骤与具体操作方案，可直接执行：

**第一步：明确“全国”的定义边界（先问清细节）**
- 询问具体覆盖范围：是覆盖所有地级市，还是仅限省会城市？是否包含偏远县镇或新疆、西藏、海南等特殊区域？
- 确认配送时效标准：不同区域的正常时效（如：次日达、隔日达）是多少？生鲜水果对时效要求高，需明确延误的赔偿标准。

**第二步：要求提供业务证明（书面证据）**
- 索要**近1-3个月的配送订单记录/物流签收单**（可脱敏客户信息），查看其发货地、目的地分布。
- 要求提供与第三方冷链物流（如顺丰冷运、京东冷链）或自有车队签订的**合作协议复印件**，核实合作网点的覆盖区域。
- 检查营业执照经营范围，是否包含**道路货运**或**冷链运输**资质。

**第三步：进行小规模“落地测试”（最关键）**
- 不要直接下大单。**先在不同区域（如华东、西南、东北各选一个非一线城市）下小额试单**。
- 在下单时，主动要求对方提供“干线运输单号”和“末端配送轨迹”。
- 测试重点是**到货后的损耗率**和**实际签收时效**。如果试单就出现延误、拒收或严重破损，实际大批量合作风险极高，建议更换供应商。

**第四步：后台查询核查（穿透式验证）**
- 如果对方称与某快递公司合作，可以在试单发货后，**直接拨打该快递官方客服（如顺丰95338），报单号核验**该网点的服务范围是否覆盖目的地。
- 要求对方提供**全国各区域仓库/分拨中心的具体地址和联系人**，然后抽查其中一个地址，搜索该地址是否真实存在（可通过地图实景查看）。

**第五步：合同约束（法律兜底）**
- 在采购合同中**明确写入**：配送范围、分区域时效承诺（如：下单后48小时内到达省会城市）、延误/损耗的违约金比例（如：超时按货值2%/天扣罚）。
- 要求供应商书面承诺“如因地域无法配送导致拒收，运费由供方承担”，并约定**定期复核**（如每季度末要求更新配送覆盖清单）。

**补充实操建议（避坑提示）：**
- **警惕“全国配送”= 只发一件代发**：确认是整车/整柜冷链直达，还是仅支持快递散货。水果批量采购拼车比散件便宜且损耗低。
- **要求提供“生鲜赔偿细则”**：确认因配送延误导致的腐烂生果，是按重量全额退款，还是仅赔运费。
- **不要轻信销售话术**：要求对接人提供**售后客服电话**，并自行拨打测试是否能接通并快速响应。

如果对方无法提供试单记录、合作协议或拒绝小额试单，基本可判定其“全国配送”能力有限，建议分批从多个区域供应商采购以降低风险。
