在茶饮店选购菠萝原料时，**出汁率通常比甜度更重要**，但两者需结合具体产品定位和成本控制来权衡。

**核心逻辑：**
1. **出汁率直接决定成本和用量**：茶饮店通常用菠萝做果肉、果酱或果汁。出汁率高的菠萝，单位重量能榨出更多汁液，意味着：
   - 制作同样杯量的饮品，原料消耗更少，毛利更高；
   - 果渣较少，方便后续果肉加工或打碎成绵密口感，减少浪费。

2. **甜度可以后天调整**：茶饮甜度主要由糖浆、果糖或蜂蜜调节。若菠萝本身偏酸或甜度不足，完全可以通过加糖或搭配高甜水果（如芒果、草莓）中和，但出汁率低则难以补救，只能增加菠萝用量，推高成本。

3. **出汁率影响口感一致性**：出汁率高的菠萝，果肉纤维更疏松多汁，做成的饮品更顺滑清爽，不容易出现“干柴”或“渣感”，这对茶饮的体验影响极大。

**例外情况（甜度更重要时）：**
- 如果你做的是**轻果茶、冰沙**，且不额外加糖（主打“0糖”卖点），那么甜度必须够，否则会酸涩；
- 如果主打**小众高价位果茶**，强调菠萝果肉本身的风味（比如做菠萝水果桶），甜度与香气（如台农17号菠萝）更重要，出汁率可适当让步。

**实践建议：**
- **先定产品再选原料**：若做菠萝汁/茶底，优先选高出汁率品种（如巴厘菠萝、海南金钻）；若做果肉爆汁感饮品，可要求供应商提供“高糖+中高汁率”样品，测试出杯后的酸甜平衡。
- **测试方法（成本测算）**：让供应商提供3种不同菠萝样品（高低甜度×高低出汁率），按你店内的标准配方试做（含固定糖量），计算：
  - 每500ml所需菠萝克数；
  - 成品的酸甜接受度；
  - 顾客盲测打分（重点评价“果味浓郁度”）。
- 最终选品时，以“**出汁率≥45%**（按标准入料法），甜度可在9-12度（Brix）之间，不足则用糖补”为安全线。

**一句话总结：** 除非你走“无添加糖”赛道，否则优先选高汁率的菠萝，甜度交给配方糖浆控制，这样既省钱又不容易翻车。
