做水果团，香蕉和菠萝确实是损耗“重灾区”，但也是稳定复购的“机会点”。控制售后不能靠“事后赔”，要靠“事前选、事中管、事后快”。

直接给你一套可落地的实操方案，分三步走：

**一、源头和选品：把风险扼杀在进货前**

1.  **只做“七成熟”或“树上熟”分级**：香蕉采购标准必须明确——表皮全绿或微黄（约七成熟）到货，避免到仓就成熟到不能放。菠萝要选**冠芽鲜绿、果眼饱满、按压微弹**的，坚决不收过熟发软的果。
2.  **“预售+到货锁定”模式**：不要盲采。先开团预售，根据订单量去批发市场或产地直采，到货后按订单分拣。如果当天到货损耗超5%，优先把有瑕疵的果挑出来做“黄香蕉/熟菠萝特价”，不发给正价客户。

**二、配送与包装：这两样东西怕“闷”和“摔”**

1.  **香蕉必须“悬挂/竖放”而非平躺**：运输中如果平放，接触面会被压出黑斑。打包时用**气泡柱或报纸**隔离，带柄朝上，箱体留透气孔。
2.  **菠萝要“套网套+带刺隔离”**：因为菠萝自带的刺会划伤其他水果，也容易被压坏。务必单独套网袋，**不要和易损的草莓、葡萄放同一袋**。
3.  **“到货即通知”**：建议在自提点放一个**“催熟小贴士”**（香蕉放苹果能催熟、菠萝削皮后要泡盐水等），降低因用户不会处理造成的“误售后”。

**三、售后政策：核心是“分级赔付”，不是“全赔”**

这是控制成本的关键：

- **黑斑/轻微软烂（表皮有瑕，果肉完好）**：属于**正常损耗**，不赔。但建议每单附赠“售后免责卡”，写明“因运输挤压导致的外观瑕疵不影响食用，不在售后范围”。
- **果肉褐变/内部腐烂/断头**：属于**品质问题**，凭**开箱视频**（注意：必须要求用户切开看果肉，香蕉剥皮、菠萝横切）秒赔，无需退货。
- **售后防杠规则**：群里明确写“**生鲜类不支持7天无理由，签收后24小时内凭视频赔付**”，且只赔该单水果的款项或等值积分，**不赔现金红包**，防止羊毛党。

**给管理者的一个警惕点**：如果某一批香蕉/菠萝的售后率连续两周超过10%，不是用户问题，是**你的进货渠道或冷链有问题**，建议立刻换供应商，而不是继续用“售后赔”来硬扛。
