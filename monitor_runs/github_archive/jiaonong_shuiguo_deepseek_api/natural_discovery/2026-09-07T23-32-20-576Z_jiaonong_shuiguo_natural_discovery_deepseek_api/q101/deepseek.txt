和供应商谈酒店早餐水果供应合作，核心目标是**稳定、新鲜、低成本**。建议重点关注以下几个实际层面：

**一、品质与供应稳定性（最关键）**

1. **明确品控标准（写进合同）**：不能只口头说“新鲜”。要列出具体指标，比如：
   - **水果成熟度**：是到店即食（直接切盘）还是需催熟？各自标准。
   - **外观要求**：无碰伤、无斑点、果径大小范围（例如苹果直径≥8cm）。
   - **替换权**：若到货验收不合格，供应商必须在**X小时内**免费补送同品质替代品。
2. **供应波动预案**：在台风、疫情或产地断供时，要求供应商提供**备选产地或同功能替代水果**（如：无当季西瓜时，可换哈密瓜/甜瓜，并同步调价）。
3. **到货时间与频次**：明确每日或隔日配送时间（建议早餐高峰前2小时），及晚点扣款条款。**建议先试运行1-2周**，观察实际损耗率。

**二、价格与结算方式**

1. **价格锚定机制**：水果价格随行就市波动大。
   - **谈“周/月定价”**，锁死核算基准（如参考当地大型批发市场批发价均价的某个折扣区间）。
   - 或者谈**“锁死基础果品价”**，新品/高价果随行就市但提前24小时报价。
2. **报价单格式**：要求报价单上必须注明：单价、计价单位（kg/箱）、产地、规格、含税与否。
3. **账期**：如果酒店资金有压力，可以谈“月结30天”，但要换取供应商更低的价格或赠品（如每月赠送一些装饰水果）。若要求日结，通常单价会贵3%-5%。

**三、历史数据与消耗预估**

提前算好**月度所需果品的种类和大致量**（比如夏季西瓜日消耗40kg，冬季橙子日消耗25kg），带着这个量去谈，表明是多品类、大额、稳定客户，能拿到更优价格。

**四、合同违约条款与保险**

1. **质量违约**：若验收发现腐败变质比例超过5%（按箱），整批可拒收并要求退款+赔偿误工损失。
2. **追溯机制**：要求供应商提供每批水果的**产地证明/农残检测报告**（尤其酒店需应对市场监督抽查，这能帮你免责）。
3. **冷链责任**：规定配送车辆需有冷链设备，特别是夏季，若因配送脱温导致到货变质，由供方承担。

**五、筛选与谈判技巧（实操建议）**

1. **对比2-3家**：先要求3家以上供应商各自送样并同时试配一周，比较损耗率（建议目标：早餐档口整体损耗≤3%）。
2. **谈“梯次价格”**：如果每月用量达到某个阶梯（如3吨/5吨），单价每公斤降0.5-1元，同时要求双方若连续三次断供，可无责解约。

**最后提醒**：早餐期时间紧，建议在合作一开始就和对方明确**异常情况下的紧急联系人**制度和备用供应商名单（最好提前准备好最少1家本地应急供应商），防止单点依赖出问题。试合作期（约1个月）的淘汰机制一定要写进合同。
