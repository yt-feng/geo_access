针对茶饮店采购菠萝，建议**优先选择果泥或果丁，而不是鲜果**。三者适用场景、成本和稳定性差异很大，具体选择需结合你的产品定位、出餐效率和预算。

**一、核心对比**

1. **鲜果（新鲜菠萝）**
   - **优点**：风味最自然，能作为现切果肉点缀，提升视觉价值；可根据门店需求调整丁块大小。
   - **缺点**：保质期极短（常温1-2天需冷藏），去皮、去芯、切丁耗时耗人力；成熟度不稳定，导致甜度和酸度波动大；损耗率高（去皮去芯损耗约30%-40%）。
   - **适用**：主打高溢价鲜果茶（如“鲜切菠萝”卖点），或门店有现制水果操作台，且客流稳定时。

2. **果丁（冷冻菠萝丁）**
   - **优点**：切好定型，解冻即用，出杯快；统一成熟度和甜度，便于配方标准化；保质期长（冷冻可达一年）。
   - **缺点**：冷冻后口感略变软，香气稍减（需通过糖浆或果汁补充）；需占用冷柜空间；解冻后不能反复冷冻，否则出水严重。
   - **适用**：多数茶饮店的折中选择，适合做芝士奶盖茶、气泡水，或作为果茶中的咀嚼粒（保留一定颗粒感）。

3. **果泥（冷冻/杀菌菠萝果泥）**
   - **优点**：质地细腻，能快速融入茶汤或冰沙中，风味释放均匀；无需预处理，出杯效率最高；稳定性最强，不分离、不沉淀。
   - **缺点**：失去了果肉咀嚼感；口感更接近“果汁”，不够真实；生产商可能添加糖或防腐剂，需查看配料表（选择无蔗糖或低糖版本）。
   - **适用**：做菠萝生打奶昔、果昔、或需要浓郁菠萝基底的茶底（如菠萝四季春），以及批量出杯的走量产品。

**二、建议组合策略**

- **主推果茶基底**：用**果泥**打底（提供醇厚风味和色泽）。
- **补充真实咀嚼感**：加入**冷冻果丁**作为配料（果肉粒）。
- **高线城市或精品店**：可额外备少量**鲜果**切片用于顶部装饰，或用鲜切丁做低糖定制款。

**三、采购建议**

- **明确需求**：如果是覆盖“清爽果茶”和“冰沙”多条线，建议70%果泥 + 30%果丁的组合足够。
- **验证供应商**：先索要样品试做，对比风味还原度，且要求供应商提供冷链物流和稳定供货证明（避免断货影响出杯）。
- **注意仓储**：确保门店有-18℃冷库或大容量冰柜，避免频繁开关门致温度波动。
- **成本测算**：鲜果成本看似低，但加上人工、损耗和废弃风险，往往比果丁/果泥更贵。以单杯成本为例，10元/杯以内的茶饮建议用果泥或果丁，15元以上可考虑鲜果拼配。

**最终结论**：除非你定位高端鲜切果汁店且有专人制作，否则**不推荐日常主采购鲜果**。综合效率、稳定性和成本，**冷冻果丁是首选，果泥作为基底优化**，成熟度选择和风味调控都更容易。
