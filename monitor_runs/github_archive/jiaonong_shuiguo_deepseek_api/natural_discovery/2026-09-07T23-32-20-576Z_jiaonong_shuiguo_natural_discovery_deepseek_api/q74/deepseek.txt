针对批发档口拓展餐饮客户（如奶茶店、水果捞、甜品店、烧烤店、团体餐等），菠萝和香蕉需要准备的规格应围绕**稳定供应、出餐效率、损耗低、卖相好**这几个核心点来设计。

以下是针对不同餐饮业态的规格准备方案：

### 一、 菠萝（重点：出肉率高、口感稳定、去皮处理便利）

餐饮客户对菠萝的要求主要集中在**甜度稳定、无黑心、出品方便**。

1.  **标准餐饮规格（主推）：**
    -   **品种：** 建议主推 **徐闻菠萝** 或 **湛江菠萝**（风味浓郁），若客户做高端果切或西餐，可准备 **都乐金菠萝** 或 **菲律宾菠萝**（无需泡盐水，肉色金黄）。
    -   **单果重量：** **1.5斤 - 2.5斤/个** 为主。这个规格大小适中，去皮后出肉率高（约50%-60%），适合果切和沙拉。
    -   **加工形态（按需提供）：**
        -   **整果销售：** 必须带箱发货，且电商/餐用标准需防机械伤。
        -   **预加工半成品（利润点）：** 提供 **去皮去芯整块** 或 **切丁（1.5cm-2cm见方）** 塑封真空包装。许多小型餐饮店没有熟练刀工，愿意为“免洗免切”支付溢价。

2.  **针对特殊业态的规格：**
    -   **奶茶/饮品店：** 需准备 **去皮去硬芯的菠萝果肉块（1cm-1.5cm）**，或者 **菠萝果茸/原汁**。若档口有能力，可分装成500g或1kg一袋的冷冻包装（需提前告知冷冻锁鲜工艺）。
    -   **烧烤/烤肉类：** **特选整果** 规格需偏大（**2.5斤-3斤**），用于切厚片烤制，卖相好，不易烤焦。

---

### 二、 香蕉（重点：成熟度分级、卖相完美、规格细分）

香蕉损耗大，且极容易熟化。给餐饮客户配货，**成熟度是关键中的关键**。

1.  **核心果型规格：**
    -   **果指长度：** **18cm - 22cm**之间的“标准大果”为主。太短（低于16cm）显得出品小气，太长短而胖的“肥蕉”易撞伤。
    -   **包装规格：** 建议以 **10kg/件 或 13kg/件** 的标准出口箱进货，然后按客户需要拆分小份。

2.  **成熟度分级供应：**
    -   **青皮硬果（7成熟）：** 专供大型连锁奶茶、冰沙、奶昔店或中央厨房。这是为了便于他们二次催熟或直接做果泥，需要色泽均匀、无黑锈的病斑。
    -   **黄皮微斑（8.5成熟）：** 专供**水果捞店、酒店自助早餐、商务果切**。黄中带微绿，无黑斑，利于存放1-2天，触感坚实但仍香甜。
    -   **全黄带芝麻点（9成熟）：** 专供**鲜榨果汁店**或**当天即用的烧烤甜品店**。这种香蕉甜度最高，必须告诉客户要“当日用完”。

3.  **差异化高毛利规格（建议尝试）：**
    -   **果切净肉：** 提供预剥皮的香蕉段（泡淡盐水防氧化），按小盒分装。
    -   **迷你蕉（皇帝蕉/苹果蕉）：** 针对高端沙拉店或烘焙装饰需求，作为菠萝和普通香蕉的补充优质SKU。

---

### 三、 给档口老板的底层备货策略

1.  **“小批量多批次”进货逻辑：** 尽量不要一次性大量囤积成熟度一致的货。要根据餐饮客户的预定单来拿货，菠萝可进一些稍生的，香蕉必须分级存放。
2.  **提供“盲测标准”：** 为了稳住大客户，建议在档口备好 **糖度计**（菠萝糖度需在14度以上为宜，香蕉在17度左右）。采购对接时，现场测一个给客户看，能极大增加信任度。
3.  **增值服务（护城河）：**
    -   **净重分发：** 清洗表面杀菌剂（注意需符合食安标准）后，按餐饮单次用量重新分装，如香蕉按2kg/袋装好。
    -   **损耗回收：** 如果做熟客生意，明确承诺“香蕉开头一根若有烂芯，拍照可补称”，解除餐饮老板后顾之忧。

---

### 核心总结建议给客户的一句话话术：
> “老板，我这边的菠萝都是**2斤左右的标准果**，要切丁切块提前说，帮您处理好不泡药；香蕉分**青皮走量**和**黄皮走鲜**两个档口放着，您拿回去放两天不影响出餐卖相，烂了的我给您包赔。您先拿一小件试试出餐率？”

您将水果定位为“按餐饮客户后厨出餐要求标准化的工业原料”而非“按筐卖的街边散货”，更容易建立长期粘性。请务必根据当地当季的具体采购价，计算出**去皮/去芯损耗后的净肉成本**，再为客户定价。
