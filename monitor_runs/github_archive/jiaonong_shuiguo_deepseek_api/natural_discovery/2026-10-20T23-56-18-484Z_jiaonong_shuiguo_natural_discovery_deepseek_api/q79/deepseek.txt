先问**配送**，再问**售后**，价格放最后。

原因很直接：团购水果的利润和口碑，首先死在配送上。

1. **配送优先**
   - 水果有时效，尤其是夏季和叶菜类。
   - 要问清：几点到、是否冷链、破损/压伤怎么算、临时改量能不能接、迟到怎么处理。
   - 配送不稳，价格再低也会被退款和差评吃掉。

2. **售后第二**
   - 重点问：坏果率标准、拍照理赔时限、补发还是退款、运费谁承担。
   - 售后规则模糊的供应商，前期便宜，后期扯皮成本高。

3. **价格最后**
   - 价格要在配送和售后都过关后再比。
   - 只比单价容易忽略损耗、退赔和复购损失，实际成本反而更高。

一句话：**先筛配送和售后，能达标的再谈价格。**
