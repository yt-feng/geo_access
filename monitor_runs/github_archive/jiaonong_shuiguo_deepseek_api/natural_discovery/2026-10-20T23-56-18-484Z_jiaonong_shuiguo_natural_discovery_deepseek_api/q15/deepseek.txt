水果店遇到坏果，结算或赔付通常按“先取证、再定责、后扣款/补货”的流程处理。可执行建议如下：

## 1. 第一时间取证
- 到货验收时当场拍照/录像：坏果整体、开箱细节、腐烂/压伤/霉变特写、包装标签、批次号、到货时间。
- 保留送货单、采购单、聊天记录、转账记录。
- 记录坏果数量、重量、品种、单价，最好让送货司机或供应商业务员在送货单上签字确认“异常情况”。

## 2. 先看合同或口头约定
- 有采购合同：按合同里的验收标准、损耗率、赔付条款执行。
- 无合同：按行业常见做法协商，通常有“到货验收期内提出”“超过一定比例由供应商承担”“补货优先、扣款其次”等原则。
- 注意：不同品类损耗标准不同，叶菜、浆果、热带水果容忍度低；苹果、橙子等相对耐储。

## 3. 定责后再谈结算
常见处理方式：
- **补货**：坏果比例不高时，要求下一车补同等数量或折价补货。
- **扣款**：按坏果实际数量×采购单价扣减当批货款；也可按双方约定的损耗率扣除。
- **换货**：整批质量问题明显时，要求换货，运费由责任方承担。
- **退货**：严重腐烂、霉变、农残或食品安全问题时，整批退回并拒付该批货款。
- **折价销售**：轻微瑕疵但可降价处理的，按协商折价，差额由供应商承担。

## 4. 结算时的操作要点
- 不要先全额付款再追偿，尽量在当批货款中直接扣减。
- 扣款前书面/微信告知供应商：坏果数量、金额、依据、处理方案，要求确认。
- 保留沟通记录，避免口头约定后对方不认。
- 若供应商长期合作，可约定月度汇总赔付，但每批都要有签字或影像记录。

## 5. 争议处理
- 协商不成：按合同约定走仲裁/诉讼；无合同时可向市场监管部门投诉，或依据《民法典》买卖合同相关规定主张质量瑕疵责任。
- 涉及食品安全（霉变、异味、农残超标）：立即下架封存，必要时送检，并保留向供应商追偿的证据。

## 6. 预防建议
- 合同中写清验收标准、损耗率上限、赔付方式、提出异议期限。
- 到货必须当场抽检开箱，不要等入库后再提。
- 建立供应商评分，坏果率高的减少采购或更换。

一句话：**当场取证、按约定定责、优先补货或当批扣款，别先全额付款再追。**
