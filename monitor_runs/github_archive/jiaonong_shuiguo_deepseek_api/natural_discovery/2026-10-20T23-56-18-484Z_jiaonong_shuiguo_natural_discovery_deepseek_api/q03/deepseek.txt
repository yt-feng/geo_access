第一次找供货商，核心不是“找最便宜的”，而是用最小成本验证四件事：**货稳不稳、损耗谁承担、价格有没有坑、补货跟不跟得上**。香蕉、苹果、橙子正好是三种不同考验，建议分开试。

## 一、试单前先定好规则

1. **只试3–5天量**，每样先拿1–2箱，别听“整板更便宜”就压货。
2. **固定验收标准**，提前说清楚：
   - 香蕉：几成熟到店（建议7成熟左右，青黄可催），单根粗细、有无黑斑、掉把率。
   - 苹果：果径大小、着色、硬度、碰伤率，是否允许轻微风疤。
   - 橙子：果径、皮厚、酸甜度、空壳/干水比例。
3. **当场称重、当场抽检**，别等卖完再扯皮。
4. **问清损耗和售后**：坏果怎么赔、多少比例起赔、是补货还是扣款、几小时内反馈有效。
5. **确认配送**：到店时间、起送量、运费、临时补货加不加价、节假日怎么安排。

## 二、三种货分别怎么试

**香蕉：试“催熟和周转”**
- 第一次别拿全熟，拿7成熟，观察到你店后几天转黄、黑斑出现速度。
- 重点看：掉把多不多、催熟是否均匀、箱内有没有压伤。
- 香蕉周转快、损耗高，价格差几毛不如供货稳定重要。问清是不是同一批催熟、能不能按你销量分批送。

**苹果：试“等级和碰伤”**
- 同一规格拿两箱，开箱逐层看，别只看上面一层。
- 重点看：果径是否一致、碰伤和裂口比例、硬度（捏一下、切一个看）。
- 苹果耐放，可以借它验证供货商是否“以次充好”、等级是否虚标。

**橙子：试“干水和口感”**
- 切开2–3个尝酸甜、看汁水，重点查干水、空壳、皮厚。
- 问清产地和批次，同一品种不同批次口感差别很大。
- 橙子损耗隐蔽，卖相好不代表好吃，务必自己试吃再上架。

## 三、比价别只比单价

让供货商报**到店价**，包含运费、装卸、损耗赔付后的实际成本。可以同时找2–3家各试一小单，同一规格对比：

- 到店单价
- 实际可售率（开箱后能卖的比例）
- 坏果赔付是否爽快
- 补货响应速度

算下来“可售成本 = 到店总价 ÷ 可售重量”，这个比标价真实。

## 四、第一次合作的实操建议

- **先小单现金或短账期**，别一上来压大额预付。
- **每次到货拍照留证**：开箱、称重、坏果特写，微信发给对方确认。
- **固定一个对接人**，口头承诺让他微信文字确认一遍。
- **试单期2–3周**，前几次都亲自验收，稳定后再放量。
- 香蕉可以稍多试一点周转，苹果橙子先各1–2箱，卖动再补。

一句话：**香蕉看催熟和掉把，苹果看等级和碰伤，橙子看干水和口感；每样小单试、当场验、把赔付写进微信里。** 谁家赔付痛快、补货及时，再谈量价。
