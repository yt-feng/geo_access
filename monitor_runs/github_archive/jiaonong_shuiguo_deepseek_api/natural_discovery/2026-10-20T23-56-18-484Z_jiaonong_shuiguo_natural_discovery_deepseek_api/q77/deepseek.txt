优先结论：**大多数生鲜电商先做“整果”为主线，切配作为补充/高毛利差异化，冷冻原料不作为面向家庭消费者的主推，除非你有稳定的餐饮/B端渠道或强冷冻供应链。**

判断维度可以按下面这套直接筛：

1. **整果更适合线上主卖**
   - 耐运输、标准化程度相对高，按重量/规格卖，履约简单。
   - 损耗主要在仓储催熟和磕碰，但可通过七成熟采摘、网套+纸箱、产地直发控制。
   - 适合做引流款、家庭装、礼盒装，客单可通过规格拉开。
   - 风险是菠萝品种差异大、成熟度难统一，差评集中在“酸、青、坏果”。要配熟度分级和售后规则。

2. **切配适合做补充，不适合一开始铺太大**
   - 优点是即食便利、客单价和毛利更高，适合办公室/年轻家庭/水果捞场景。
   - 但鲜切菠萝对冷链、洁净加工、保质期要求高，线上履约半径短，损耗和食安风险明显高于整果。
   - 适合在核心城市仓或前置仓覆盖范围内做“次日达/当日达”，不建议全国快递发鲜切。
   - 若做，优先小规格、预售/定时达、可追溯批次，别把它当低损耗标品。

3. **冷冻原料更适合B端或特定场景**
   - 冷冻菠萝块/果泥适合餐饮、茶饮、烘焙、果汁店，家庭线上零售需求相对窄。
   - 优点是保质期长、损耗低、易标准化；缺点是家庭复购场景弱、冷链成本高、解冻口感受质疑。
   - 如果没有B端订单或冷冻仓配能力，不建议作为线上主推SKU。

**可执行组合建议：**
- 第一阶段：整果为主，做2-3个规格（家庭装、礼盒装、尝鲜装），重点控熟度和坏果率。
- 第二阶段：在核心城市试点鲜切小规格，只覆盖短半径，验证复购和损耗。
- 冷冻原料：单独走B端渠道或作为果切/饮品原料包，不混在家庭生鲜主推里。

一句话：**线上卖菠萝，整果打基本盘，切配做核心城市增量，冷冻原料走B端或场景化，不要三者在同一阶段平均用力。**
