# 旺季提前锁定水果库存的实操建议

核心思路：**用“确定性”换供应商的“优先权”** —— 让供应商觉得把货留给你比散卖更划算、更省心。

## 一、提前锁定（时间窗口）

- **提前1–2个月**做旺季销量预测，按SKU拆分到周，直接给供应商看你的预估量，谈判时这是筹码。
- **签框架协议+周滚动订单**：总量锁定，具体发货按周确认。避免一次性压死自己也给供应商缓冲。
- 水果有季节性，**上市前就定好产地/果园**（如提前对接产区代办、合作社），比旺季临时抢货便宜且稳。

## 二、锁价与锁量的机制

| 方式 | 适用 | 要点 |
|---|---|---|
| 预付定金锁货 | 爆款单品（如车厘子、沃柑） | 定金比例10%–30%，写明违约双倍返还 |
| 保底量+浮动量 | 常规水果 | 承诺最低采购量，换优先供货权 |
| 价格联动条款 | 价格波动大的品 | 约定按产地当日价±固定差价结算，避免单方毁约 |
| 分级锁货 | 多SKU | 爆款锁死，长尾品灵活补 |

## 三、合同里必须写清的条款

1. **优先供货权**：旺季你的订单优先级高于散客。
2. **品质标准**：规格、糖度、坏果率上限（如≤5%），附验收标准。
3. **缺货违约责任**：供应商断供的赔偿或补货义务。
4. **账期与结算**：旺季可适当缩短账期换更好价格/优先权。
5. **不可抗力与天气条款**：水果受天气影响大，约定减产时的分配规则。

## 四、多供应商与备份

- **主供+备供**：每个爆款至少2家供应商，主供占70%、备供30%，防止单点断供。
- 建立**产地直采**通道作为兜底。
- 旺季前**小批量试单**验证供应商履约能力。

## 五、其他加分动作

- 给供应商**稳定回款记录**和**长期合作承诺**，比压价更能换到优先权。
- 提前告知**提货节奏**，让供应商安排采摘和物流。
- 考虑**共享仓储/前置仓**，减少供应商配送压力，换取让利。

**一句话结论**：旺季锁库存的关键不是“多给钱”，而是**提前给量、给确定性、签好违约条款、留好备供**。
