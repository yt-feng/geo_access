给公司下午茶采购批量水果，选供应商时建议按“能不能稳定批量配送”来筛，而不是只看单价。可以按下面几步判断：

1. **先定配送场景**
   - 人数、预算/人、食用时间（下午几点到）、是否需要洗切装盘。
   - 批量下午茶优先选：耐放、易分食、不需要现场处理的水果，如圣女果、葡萄、橘子/砂糖橘、香蕉、苹果、梨、蓝莓盒装；少选易压伤、易氧化、需现场切的如西瓜整颗、芒果、火龙果大量切块。

2. **供应商类型优先级**
   - 优先：本地水果批发商/配送商、团餐/下午茶综合配送商、有企业客户案例的生鲜平台。
   - 次选：大型商超团购、品牌水果连锁的企业团购。
   - 不建议：纯零售水果店临时大单、个人微商、无固定仓配的临时摊贩。

3. **必须核验的资质与能力**
   - 营业执照、食品经营相关资质（若涉及洗切分装更要有相应许可）。
   - 是否有固定分拣场地、冷链/保温配送车辆。
   - 能否按约定时间送到公司指定楼层/前台。
   - 能否提供批次检测或进货凭证（至少能说明货源和农残把控）。
   - 是否有企业批量配送合同/对公账户/发票。

4. **试单再签**
   - 先下一个小批量试单：看准时率、损耗率、大小均匀度、成熟度、包装是否抗压、是否漏发。
   - 试单重点看“到货可食率”和“坏果率”，不是只看照片。

5. **合同里写清楚**
   - 品种规格（单果重量/等级）、数量、单价、总价。
   - 送达时间窗、迟到处理。
   - 坏果/压伤/不熟的处理：拍照留证，按比例补送或退款。
   - 临时加单/减单截止时间。
   - 发票类型和账期。

6. **对比报价时统一口径**
   - 按“可食部分单价”或“人均成本”比，不按整箱毛重比。
   - 要求分项报价：水果、清洗切配、包装、配送、税。
   - 至少找3家，同规格同数量比价。

**简单判断标准：** 能提供企业批量配送案例、有固定仓配、能试单、坏果有赔付、能开票且准时送达的供应商优先。价格最低但无仓配、无合同、无赔付的，不建议选。
