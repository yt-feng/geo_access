建议把“资料索取”分成三层：**主体资质、批次检测、过程控制**。抽检前最有用的是能对应到具体批次、品种、产地的资料，而不是只有一张年度报告。

**1. 主体与资质类（首次合作或年度更新）**
- 供应商营业执照、食品经营/生产许可（按业态）
- 产地证明或采购合同/订单，能追溯到具体果园、合作社或产地
- 供应商质量安全承诺书/供货协议中的农残责任条款
- 若为进口水果：入境货物检验检疫证明、海关报关单等

**2. 批次检测类（每批或高频抽检品种重点要）**
- **该批次**的农药残留检测报告：报告日期、样品名称、批号/采收日期、检测项目、检测方法、判定依据、结论要齐全
- 报告出具机构应有 CMA 资质（必要时 CNAS）；要核对报告编号可查询
- 检测项目不要只看“合格”二字，重点看是否覆盖当地常用农药和 GB 2763 中对应水果的限量项目
- 高风险品种（如草莓、葡萄、柑橘、叶菜类水果等）可要求供应商提供更高频次检测或第三方抽检报告
- 如供应商只有快检报告，要区分快检与实验室法定检测，快检不能替代法定检测报告

**3. 过程控制类（用于评估风险和追责）**
- 农药采购/使用记录（供应商或产地端）
- 采收前安全间隔期执行记录
- 供应商对产地的巡检/抽检记录
- 不合格品处理记录、召回记录
- 运输和仓储温控记录（尤其易腐水果）

**实操建议：**
- 在采购合同里写明：**每批随货提供批次检测报告；抽检不合格时供应商承担检测费、退换货及监管处罚相关责任；报告造假追责**。
- 建立“批次—报告—入库单”对应台账，抽检时能快速调取。
- 对无法提供批次报告的供应商，要求其书面说明并提高自检频次；长期无法提供的，建议降级或更换。
- 不要只收“年度型式检验报告”，它不能证明当前批次安全。

一句话：**优先要“能对应这批货的 CMA 农残检测报告 + 产地追溯信息 + 合同中的质量责任条款”，其次才是资质和过程记录。**
