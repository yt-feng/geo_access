香蕉和菠萝的售后问题，核心是**把“损耗”从售后环节前移到选品、到货、售卖节奏和规则设计上**。下面按可执行动作给你一套判断标准和控制方法。

## 一、先定规则：不同品做不同售后承诺

高损耗品不能和苹果橙子用同一套售后标准。

**香蕉**
- 建议承诺：**“到货有青有熟属正常，按催熟说明放置；出现黑腐、断裂、大面积压伤可售后”**
- 不建议承诺“不甜包退”“软了包退”，否则熟度争议会吃掉利润
- 售后时限：**收货后24小时内**，超时只做安抚不退款
- 赔付标准：按根/按比例，比如坏3根以上按根赔付，超过50%整单退

**菠萝**
- 建议承诺：**“外观瑕疵（叶冠干、皮色不均）不售后；切开黑心、烂心、明显酸败可售后”**
- 必须要求**切开拍照/视频**再判责，不然无法区分是果本身问题还是放置过久
- 售后时限：**收货后48小时内**，且要求未切开常温放置不超过2天
- 赔付标准：黑心烂心按个赔，口感酸不做售后（除非整批明显未熟）

## 二、到货验收：把问题挡在团长手里

团长是最后一道关，必须给**可执行的验收动作**，不能只说“检查一下”。

**香蕉验收**
1. 看：整把有无发黑、水烂、霉点
2. 摸：果指是否过软出水
3. 分：青蕉和熟蕉分开放，熟蕉优先卖/优先配送
4. 记录：到货拍照，坏果当场挑出，不进入售卖池

**菠萝验收**
1. 闻：底部有无酒味、酸腐味
2. 按：果身是否局部软塌
3. 看：底部有无霉斑、渗液
4. 抽切：每批抽1-2个切开看是否黑心，有问题整批预警

建议给团长一张**验收 checklist**，到货10分钟内完成，拍照留档。

## 三、售卖节奏：高损耗品要“快进快出”

- **香蕉**：不要一次全催熟。按到货量分2-3批催熟，青的先卖“可放”，熟的当天主推
- **菠萝**：到货后2天内必须清完，超过2天优先做特价或切果，不拖到第3天
- 团购文案要**提前管理预期**：香蕉写明“自然成熟，个别表皮有斑点不影响食用”；菠萝写明“需削皮后食用，外观不影响果肉”
- 设置**截单和到货时间**，避免用户收货后放几天再来说坏

## 四、售后判责流程：减少扯皮

建议固定四步：

1. **要证据**：坏果照片/视频，菠萝必须切开图
2. **对时限**：香蕉24小时、菠萝48小时，超时说明原因后酌情
3. **定比例**：按坏果数量/整单比例赔，不按情绪赔
4. **留记录**：同一用户频繁售后、同一批次集中售后，分别处理——前者标记，后者找供应商

## 五、供应商和批次管理

- 香蕉优先选**七成熟左右**到货，太熟到团长手里必烂
- 菠萝要求供应商**控水、不催熟过度**，到货抽切
- 每批记录：到货时间、数量、坏果率、售后率。**售后率超过5%的批次，下一批换供应商或降量**
- 和供应商约定**坏果补偿比例**，把售后成本部分转移回去

## 六、最省事的组合策略

如果刚开始做，建议：

- 香蕉：**按把卖、限当日/次日自提、24小时坏果按根赔**
- 菠萝：**按个卖、要求切开售后、48小时黑心赔**
- 首团少量测试，记录售后率，再决定放量
- 文案统一加一句：**“生鲜有自然差异，坏果拍照秒赔，口感偏好不在售后范围”**

一句话总结：**香蕉控熟度节奏，菠萝控切开证据；规则前置、验收留痕、批次追责，售后就不会失控。**
