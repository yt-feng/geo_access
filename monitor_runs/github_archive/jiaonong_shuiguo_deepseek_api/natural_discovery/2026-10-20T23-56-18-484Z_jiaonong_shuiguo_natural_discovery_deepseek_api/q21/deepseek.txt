超市采购水果时，供应商通常需要提供以下几类检测报告或进货证明：

1. **产地证明或供货证明**  
   - 产地证明、供货合同、订单、送货单等，用于证明水果来源和进货渠道。

2. **农药残留检测报告**  
   - 由具备资质的检测机构出具，常见为农残快检报告或定量检测报告。
   - 超市一般要求批批附带或定期提供，重点检测项目包括有机磷、氨基甲酸酯类等。

3. **食用农产品合格证**  
   - 根据《食用农产品市场销售质量安全监督管理办法》，供应商应提供食用农产品合格证或产地证明等文件。
   - 合格证通常由生产者或供应商开具，承诺产品符合质量安全要求。

4. **检验检疫证明（进口水果）**  
   - 进口水果需提供海关出具的入境货物检验检疫证明、报关单等。
   - 部分进口水果还需提供原产地证明。

5. **营业执照及食品经营许可证**  
   - 供应商的营业执照、食品经营许可证或食用农产品销售相关资质文件。

6. **其他专项检测报告**  
   - 如重金属、保鲜剂、二氧化硫等检测报告，视水果品种和超市要求而定。
   - 有机水果需提供有机产品认证证书；绿色食品需提供绿色食品证书。

**实际操作建议：**  
- 超市应建立供应商档案，留存上述证明文件的复印件或电子版，并定期更新。  
- 对高风险水果（如草莓、葡萄、叶菜类）可要求批批提供农残快检报告。  
- 具体文件要求以当地市场监管部门规定和超市内部采购制度为准。
