建议先从**香蕉**试水，但只适合作为“引流/稳定销量”品类，不要把它当高毛利进口差异化主角；真正要建立“稳定进口水果”能力，更优先的顺序是：**香蕉 → 苹果 → 菠萝**。

判断依据：

1. **香蕉：最适合先跑通供应链**
   - 消费频次高、价格敏感、销量稳定，顾客教育成本最低。
   - 进口香蕉（如菲律宾、厄瓜多尔等产地）在国内供应链成熟，规格和催熟流程相对标准化。
   - 风险是毛利薄、损耗和催熟管理要求高。适合先用来测试：订货周期、催熟房/陈列条件、日销量、损耗率。

2. **苹果：第二顺位，适合做稳定利润和差异化**
   - 耐储运、损耗低、货架期长，比香蕉更容易管理库存。
   - 进口苹果（如新西兰、美国、南非等产地）有礼盒、精品果和日常果不同层次，可做差异化。
   - 缺点是消费者对国产苹果接受度高，进口苹果需要清楚卖点，否则容易价格倒挂。

3. **菠萝：不建议作为第一个稳定进口品类**
   - 损耗和成熟度管理更麻烦，顾客对酸度、成熟度、削皮服务敏感。
   - 进口菠萝有差异化卖点，但销量波动大，更适合作为阶段性单品或试销，而不是先建立稳定基本盘。

可执行建议：
- 第一步：用进口香蕉做4周试销，记录日均销量、损耗率、毛利、缺货天数。
- 第二步：同步小批量引入1—2个进口苹果SKU，观察复购和价格接受度。
- 第三步：菠萝先做周末促销或试吃，不签长期大单。
- 选品原则：先选**耐储、标准化、复购高**的；香蕉负责客流，苹果负责稳定，菠萝负责尝鲜差异化。
