判断“能不能按时到车”，核心不是听供应商口头保证，而是把**承诺拆成可验证的节点**，并保留可追责的信息。你可以按下面几步做：

1. **先问清“到车”定义**
   - 是到产地装车、到批发市场卸货，还是到指定冷库？
   - 具体日期、时间窗口、车牌号、司机电话、装车点、卸货点。
   - 要求供应商在订单里写清“最迟到车时间”和“超时处理”。

2. **查供应商的履约能力**
   - 看最近3—5单的实际到车记录，不只看他说。
   - 问清楚：自有车队还是临时调车？产地装车是谁负责？遇到下雨、堵车、查超载有没有备选车？
   - 新供应商先小批量试单，不要一上来压大单。

3. **要求关键节点主动回报**
   - 装车完成时间、车牌号、司机电话、当前所在位置。
   - 最好让司机直接加你微信，装车后拍车板、货量、封条、车牌。
   - 约定“装车后2小时内必须发车牌和司机电话”，否则视为风险信号。

4. **用合同/聊天记录锁定责任**
   - 写明：到车时间、货品规格、数量、损耗标准、超时违约金或降价条款。
   - 付定金前确认：若不能按时到车，供应商是否负责调车、补差价或退款。
   - 不要只接受语音承诺，关键内容落到文字。

5. **提前准备备选**
   - 同一批次至少问2—3家供应商，保留一家备用。
   - 对时效敏感的货，优先选有固定车队、固定装车队的供应商，而不是纯中间商。
   - 到车前一天再次确认司机和车牌，发现司机临时换、车牌对不上、装车点含糊，要提高警惕。

6. **看风险信号**
   出现这些情况，按时到车概率明显下降：
   - 只给“大概”“没问题”，不给车牌和司机；
   - 装车时间一拖再拖；
   - 临时换车、换装车点；
   - 报价明显低于市场且催你付全款；
   - 不愿意写到车时间和违约责任。

**最实用的做法**：新供应商先小单试履约；老供应商每单仍要“车牌+司机电话+装车照片+最迟到车时间”四项确认。这样你判断的不是“他怎么说”，而是“车和货是否已经进入可追踪状态”。
