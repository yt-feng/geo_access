直接说结论：旺季临时补货不能只靠“打个电话加单”，要在原供货合同之外做一份**临时补货补充协议/旺季保供备忘录**，把触发条件、加单提前期、价格、质量、违约和替代方案写死。下面是可直接落地的做法。

**一、先判断要不要签补充协议**
- 如果只是偶尔加一两箱：用微信/邮件下单并让对方书面确认“品名、规格、数量、单价、到货时间、验收标准”即可，保留记录。
- 如果旺季持续加量、频次高、金额大：必须签补充协议，避免临时涨价、插单排后、以次充好。

**二、补充协议必须写清的7项**
1. **临时补货触发与量**
   - 约定“单次加单≥X箱或周加单≥Y箱”走临时补货流程；
   - 设月度/旺季累计上限，超过上限另议价格，防止供应商坐地起价。
2. **提前期**
   - 写明“常规加单提前24小时，紧急加单提前6小时”之类，按你的门店补货节奏定；
   - 明确供应商确认时限，比如“收到加单后2小时内书面确认是否可供”。
3. **价格机制**
   - 临时补货单价不高于原合同价，或约定“按原合同价+固定运费”，不接受随口浮动；
   - 如遇市场价波动，约定调价上限和提前通知期。
4. **规格与质量**
   - 写清品种、成熟度、单果重量区间、瑕疵率上限、农残检测要求；
   - 验收不合格的退换货时限和费用承担。
5. **交付与验收**
   - 到货时间窗口、卸货地点、谁验收、验收单签字；
   - 迟到超过X小时的处理方式。
6. **违约与保供**
   - 供应商临时断供的违约金或补偿；
   - 连续两次未按确认量供货，你可启用备用供应商且不视为违约。
7. **备用与替代**
   - 约定你有权同时向第二供应商临时采购，不违反独家条款；
   - 明确替代品种/规格的书面确认流程。

**三、操作上建议这样做**
- **提前锁定旺季框架量**：旺季前1个月和主供应商谈“基础量+弹性量”，弹性部分给一个价格区间，临时补货在弹性量内按约定价走。
- **加单必须书面化**：微信可以，但要固定模板：品名/规格/数量/单价/到货时间/验收标准，对方回复“确认”才算生效。
- **保留第二供应商**：菠萝旺季容易缺货，至少备一家备用，补充协议里不要写排他条款。
- **到货即验**：称重、抽检、拍照留证，验收单双方签字，异常当天书面提出。
- **对账清晰**：临时补货单独建台账，和常规供货分开对账，避免混单扯皮。

**四、谈判话术参考**
“旺季我们用量会涨，但不想临时压价，也不想你临时断供。我们把弹性量、提前期和价格区间先定下来，你按确认单供货，我们按验收单结算，超过弹性量再另议。这样你排产有数，我们门店不断货。”

一句话：**用书面确认单管日常加单，用补充协议管旺季弹性和违约，同时保留第二供应商。**
