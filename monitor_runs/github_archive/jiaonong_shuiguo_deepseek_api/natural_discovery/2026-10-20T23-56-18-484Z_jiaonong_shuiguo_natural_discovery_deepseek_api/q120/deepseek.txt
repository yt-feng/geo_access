供应商介绍产品时，建议按“商家听得懂、算得清、敢下单”的顺序说，少讲品种术语，多讲用途、卖点和风险。

可以直接用这个结构：

1. **先说它像什么、卖给谁**
   - “这个菠萝比普通菠萝更甜、更软，适合做鲜切水果和水果捞，不是拿来做菜的。”
   - “这个香蕉个头偏小，适合便利店单根卖和早餐店配餐，不适合做大宗批发。”

2. **用商家熟悉的品类做对比**
   - “口感介于普通香蕉和粉蕉之间，但比粉蕉便宜。”
   - “外形像凤梨，削皮就能吃，不用挖眼，损耗比普通菠萝低。”
   - 对比维度只说：甜度、软硬、个头、出肉率、损耗、保存时间、适合场景。

3. **直接算账，不要只报单价**
   - “一箱进价XX元，单果大约X斤，按你卖X元/斤，毛利大概X元。”
   - “鲜切出肉率约X%，比普通菠萝少损耗X%，做水果捞更划算。”
   - 商家最关心：进价、卖价、损耗、保质期、一天能卖多少。

4. **明确适合和不适合的场景**
   - “适合水果店散卖、鲜切、水果捞、奶茶店原料。”
   - “不适合长途批发，熟得快，建议3天内卖完。”
   - 不要只说“很好卖”，要说“在什么店、什么场景好卖”。

5. **主动说风险和售后**
   - “这批熟度偏高，适合近场销售，不建议压货。”
   - “坏果按比例补，拍照即可，不用整箱退。”
   - 商家听到风险可控，才更容易下单。

6. **给一个小单试销方案**
   - “先拿半箱试卖，卖得动再补；这周订两箱送陈列标签。”
   - 比一上来推整柜更容易成交。

一句话模板：

> “这个产品你可以把它当成‘升级版普通菠萝’来卖：更甜、不用挖眼、鲜切损耗低，适合水果店鲜切和水果捞。一箱X元，单果约X斤，按你现在的卖法毛利大约X元。缺点是熟得快，建议3天内卖完，坏果按比例补。你先拿半箱试卖，卖得动再补。”

核心原则：**别教育商家认识新品种，而是帮他把新品种归到他熟悉的货架和算账方式里。**
