做香蕉蛋糕时，采购应优先关注**成熟度**，价格放在第二位。原因是香蕉的成熟度直接决定蛋糕的甜度、香气、含水量和组织结果，价格低但成熟度不对，反而会造成配方不稳、成品风味差和损耗。

建议按以下标准判断：

1. **优先选熟度合适的香蕉**
   - 做香蕉蛋糕通常适合用**表皮大面积转黄、带少量褐斑、果肉软但未流汁**的香蕉。
   - 这时淀粉转糖较充分，香气足、甜度高，能减少额外加糖，蛋糕更湿润。
   - 太青的香蕉：香气弱、涩味重、甜度低，蛋糕风味不足，还可能让组织偏干。
   - 过熟发黑、果肉水化或有酒味的香蕉：不适合直接用于出品，容易带来异味、发酵味和配方水分失控。

2. **价格只作为次级筛选**
   - 在成熟度合格的前提下，再比较单价、出肉率和损耗。
   - 不要因为便宜大量采购青香蕉或过熟香蕉；前者需要等待后熟，后者可用窗口很短。
   - 可计算“可用果肉成本”，而不是只看带皮重量价格。

3. **按使用计划分批采购**
   - 烘焙店最好根据未来2—3天用量采购，成熟度略分档：一部分即用，一部分放1—2天再用。
   - 香蕉后熟快，库存管理比单纯压价更重要。

4. **例外情况**
   - 如果只是做香蕉风味不突出、用量很小的产品，价格权重可以提高，但仍不能用过熟变质果。
   - 若采购青香蕉后自行催熟，需要有稳定温湿度条件和提前计划，否则不建议为低价牺牲成熟度。

结论：**成熟度是质量与配方稳定的第一门槛，价格是在合格成熟度基础上的成本优化项。**
