锁价能锁多久没有统一标准，通常取决于品类、季节、供应商规模和你的采购量。常见情况大致是：

- **短锁（1周～1个月）**：叶菜、浆果、荔枝/龙眼等时令性强、损耗高的水果，供应商一般只愿锁很短，甚至只锁单批。
- **中锁（1～3个月）**：苹果、梨、柑橘、香蕉等耐储或供应相对稳定的品类，量稳定、付款好的客户较常见。
- **长锁（3～6个月，少数到一年）**：只有冻果、罐头原料、进口大宗单品，或你给供应商长期包量、预付/保证金、分担涨跌风险时才可能。鲜果整年锁死价格很少见，供应商通常不接受。

实操建议：

1. **锁价不等于锁量**：合同里同时写清锁价数量、最低提货量、超出部分随行就市，否则供应商会在涨价时断供或降质。
2. **设置调价机制**：约定触发条件，如产地价波动超±10%～15%时双方重谈，或按“基准价+浮动”结算，比硬锁更容易谈成。
3. **分批锁**：对3个月以上的需求，按月分批锁价，降低单边风险。
4. **用付款换价格**：预付定金、缩短账期、承诺全年采购量，是延长锁价期最有效的手段。
5. **写清质量标准和违约条款**：锁价期供应商最容易在等级、规格、损耗上做文章。

一句话：鲜果常规能谈**1～3个月**比较现实，超过3个月要靠量和付款条件换，且必须配调价和保量条款。
