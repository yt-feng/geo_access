社区超市找日配水果供应商，建议按下面几类条件逐一核实，先小批量试配再定长期合作。

**一、配送与履约能力**
- 能否每天固定时段送达，节假日是否照常；社区店通常需要早于营业高峰前到货。
- 起送量、配送费、临时补货是否支持，缺货或延迟如何补偿。
- 是否有冷链车或保温箱，夏季高温和叶菜类损耗如何控制。
- 配送范围是否覆盖你门店，路程时间多长，遇雨雪、交通管制有无备用方案。

**二、货源与品质稳定**
- 货源是产地直采、批发市场代采还是二级分销，直采比例越高通常价格和新鲜度越可控。
- 是否有稳定基地或长期合作档口，换季时品种能否跟上。
- 到货标准要写清楚：规格、成熟度、净重、允许损耗率、农残检测报告是否随批提供。
- 要求看近期实际到货样品，而不是只看图片或口头承诺。

**三、价格与结算**
- 报价是否含税、含运费，是否随行就市每日报价；调价提前多久通知。
- 账期怎么定，押金或保证金多少，退换货和损耗赔付规则。
- 对比时按“到店净成本”算，不只看单价，把损耗、运费、退换成本算进去。

**四、退换与售后**
- 坏果、缺斤少两、规格不符能否当天退换或下次补货抵扣。
- 售后响应时间，是否有专人对接，节假日能否联系上。
- 建议前两周每天记录到货合格率、损耗率和缺货次数，用数据判断。

**五、资质与合规**
- 营业执照、食品经营相关资质是否齐全，能否提供进货凭证和检测报告。
- 是否有固定经营场所和冷库，避免纯中间人转手导致品质不稳。

**六、试配建议**
- 先选3—5个高频单品（如苹果、香蕉、柑橘、时令叶果）试配2—4周。
- 同时接触2—3家供应商比价，但不要只压价，日配稳定性比低价更重要。
- 合同里写明到货时间、品质标准、损耗上限、退换规则和违约处理。

简单说，优先看**日配稳定性、冷链能力、到货标准可量化、售后响应快**这四项；价格放在同等稳定性的供应商之间比较。
