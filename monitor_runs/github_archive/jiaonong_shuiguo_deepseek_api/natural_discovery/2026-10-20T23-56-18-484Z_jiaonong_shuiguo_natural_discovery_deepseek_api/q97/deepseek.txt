酒店采购水果盘原料时，建议把“规格和外观标准”写进采购合同或验收单，并按品类分别约定。下面按通用可执行口径给出。

## 一、通用规格要求

1. **品种与产地**
   - 明确具体品种，不接受“同类替代”。
   - 约定产地或允许产区范围；进口水果需提供报关、检验检疫证明。

2. **等级与大小**
   - 按品类规定单果重量或横径范围，例如：
     - 苹果：单果 180–220g，横径 75–85mm；
     - 橙子：单果 180–250g，横径 70–80mm；
     - 西瓜：单果 4–6kg；
     - 草莓：单果 15–25g，一级果。
   - 同批次大小均匀，允许误差一般不超过 ±10%。

3. **成熟度**
   - 到货时适合 1–3 天内切片出品：不过生、不过熟。
   - 香蕉、芒果、猕猴桃等后熟水果约定到货成熟度，如香蕉 6–7 成熟，芒果 7–8 成熟。

4. **新鲜度与货架期**
   - 从采摘/采收至到货时间尽量不超过约定天数。
   - 叶菜类、浆果类要求冷链运输，到货中心温度一般 0–8℃（按品类调整）。
   - 不得有异味、发酵味、霉味。

5. **安全与合规**
   - 农残符合 GB 2763；污染物符合 GB 2762；食品添加剂符合 GB 2760。
   - 提供批次检测报告或承诺书；进口水果提供入境货物检验检疫证明。
   - 可约定定期第三方检测，不合格批次退货并承担损失。

6. **包装与标识**
   - 包装完好、无破损、无受潮；标注品名、产地、等级、净重、采收/包装日期、供应商信息。
   - 周转筐清洁消毒，不得使用回收污染包装。
   - 冷链品类到货温度记录随货同行。

## 二、外观标准（验收可判定）

1. **果形**
   - 具有品种典型形状，无严重畸形、无双果连体（除非品种特性）。
   - 允许轻微自然差异，但不接受明显畸形果。

2. **色泽**
   - 达到品种成熟应有的色泽，色泽均匀。
   - 不接受青果冒充成熟果（需后熟品种除外，按约定成熟度）。

3. **表面与果皮**
   - 果面清洁，无泥土、药斑、鸟粪、汁液污染。
   - 无腐烂、霉变、软烂、开裂、明显虫眼、机械伤。
   - 允许极轻微表皮瑕疵，但不影响切片出品率。

4. **新鲜度外观**
   - 果柄新鲜，不干枯发黑（适用于需要带柄验收的品类）。
   - 叶菜类无黄叶、萎蔫、水渍状；浆果类无渗汁、无压伤。

5. **缺陷率控制**
   - 建议约定：腐烂霉变果 0 容忍；严重机械伤、虫害果不超过 2%；轻微外观缺陷不超过 5%。
   - 抽样按批次随机抽取，例如每批不少于 10 件或按 5% 抽检，发现超标加倍抽检，仍超标则整批退货。

6. **规格一致性**
   - 同箱/同批次大小、颜色、成熟度基本一致。
   - 混装果盘原料可按组合约定，但每品种仍需符合各自标准。

## 三、建议写入合同的验收条款

- **验收方式**：到货现场抽检 + 温度记录 + 证照核查。
- **不合格处理**：腐烂霉变、农残超标、规格严重不符的，整批退货；供应商承担运输及酒店损失。
- **替换与补货**：不合格批次应在约定时限内补货，不影响酒店出品。
- **扣罚标准**：可按缺陷率设置阶梯扣款，但腐烂霉变应直接退货。
- **留样**：每批次留样 24–48 小时，便于追溯。

## 四、按品类的简明示例

- **苹果/梨**：单果 180–220g，横径 75–85mm，无碰压伤，无腐烂，色泽典型。
- **橙/柚**：单果 180–250g，果面清洁，无干疤、无霉变，果皮无严重失水。
- **葡萄**：果穗完整，无落粒、无渗汁、无霉变，果粉自然。
- **草莓/蓝莓**：单果规格均匀，无压伤、无渗汁、无霉变，冷链到货。
- **西瓜/哈密瓜**：单果重量约定，无裂口、无软烂，成熟度适合 1–2 天内出品。
- **香蕉/芒果**：到货成熟度按约定，无黑斑腐烂，后熟时间可控。

核心原则：**品种等级写清楚、大小重量可量化、成熟度可判断、缺陷率可抽检、安全证照可追溯、不合格可退货**。这样酒店验收时才有明确依据。
