旺季谈水果供应，核心是把“断货风险”拆成可约定的条款。和供应商谈时按下面几组问题问，并要求关键项写进合同或订货单：

**一、供货能力与优先级**
1. 旺季你每天/每周能稳定给我供多少量？最低保供量是多少？
2. 我这类门店你有几家客户？旺季同时爆单时，按什么顺序分配货源？
3. 能不能给我“旺季优先供货”承诺？断供时提前多久通知我？
4. 你有没有备用产地/备用货源？主产区受灾或涨价时怎么补？

**二、品质与验收**
5. 各品类分级标准是什么（大小、糖度、熟度、瑕疵率）？按什么标准验收？
6. 到货损耗率大概多少？坏果、次果怎么赔、怎么换？
7. 熟度怎么控制？我门店要“即卖即熟”还是可以催熟？催熟谁负责？
8. 农残检测报告、产地证明能不能随货提供？

**三、价格与结算**
9. 旺季价格怎么定？是随行就市还是锁价？锁价锁多久、锁哪些品？
10. 涨价提前几天通知？我能不能有“老客户价”或阶梯价？
11. 账期怎么算？现结、周结还是月结？押金、保证金要不要？
12. 运费、装卸、包装费谁承担？起送量多少？

**四、配送与时效**
13. 每天几点前下单、几点送到？能不能按我营业时间送？
14. 配送范围、频次、车辆冷链情况？夏天高温怎么保鲜？
15. 临时加单最晚什么时候能接？加急要不要加价？
16. 缺货、迟到、送错怎么处理？有没有违约金或补货承诺？

**五、售后与风险**
17. 到货不合格当场拒收还是事后索赔？索赔时限多久？
18. 断货导致我损失的，有没有补偿机制（补货、折价、违约金）？
19. 合作期内你能不能同时供我周边同行？有无区域保护？
20. 合同签多久？旺季结束后价格和量怎么调整？退出机制是什么？

**谈判时特别要盯住的3件事：**
- **保供量+缺货罚则**：只口头承诺“优先供”没用，要写最低日供量和断供补偿。
- **验收标准+损耗赔付**：水果损耗是最大隐性成本，坏果率、赔付方式必须白纸黑字。
- **价格调整机制**：旺季涨价常见，要约定提前通知期和锁价品类，避免临时被抬价。

建议先小批量试供1—2周，验证到货准时率、损耗率和品质稳定性，再签旺季正式协议。
