茶饮店控制水果供应商的食品安全风险，建议按“资质证明 + 检测报告 + 随货凭证 + 协议与记录”四类索取和留存。具体如下：

**1. 主体资质证明**
- 营业执照（经营范围含水果销售/农产品销售）
- 食品经营许可证（若供应商从事预包装食品、鲜切水果、果浆等加工销售）；仅销售初级食用农产品通常可免于食品经营许可，但需确认当地监管口径
- 若是进口水果：海关报关单、入境货物检验检疫证明
- 若是鲜切水果：属于即食食品，供应商应有相应食品生产/经营资质，并符合即食加工卫生要求

**2. 产品合格证明与检测报告**
- 农产品承诺达标合格证（优先索取，尤其针对规模化种植基地）
- 第三方检测报告：农残、重金属等，报告应与供应品种、批次对应，注意报告日期和检测项目
- 供应商自检报告（如有）
- 进口水果的检验检疫证明

**3. 随货凭证**
- 每批次送货单/销售凭证，注明品名、数量、日期、供应商
- 产地证明或采购凭证（从批发市场采购时保留市场出具的凭证）
- 冷链运输温度记录（如供应鲜切水果、浆果等需冷链的品类）

**4. 协议与内部记录**
- 食品安全协议或采购合同，明确农残超标、变质、异物等问题的责任和退换货机制
- 供应商档案：许可证复印件加盖公章、联系人、地址
- 进货查验记录：每批留存证明文件，保存期限不少于产品保质期满后6个月；无明确保质期的，保存不少于2年（按食品安全法进货查验记录要求执行）

**实操建议：**
- 对新供应商做一次现场或视频审核，重点看仓储、分拣、鲜切加工卫生和虫害控制。
- 对高风险水果（草莓、葡萄、切果等）提高抽检频次，可自购农残快检设备做批批快检。
- 证照到期前提醒更新，检测报告按品种和季节滚动更新，避免“一份报告用一年”。
- 鲜切水果风险显著高于整果，若门店自行鲜切，应把供应商资质审核和门店加工卫生控制分开管理。
