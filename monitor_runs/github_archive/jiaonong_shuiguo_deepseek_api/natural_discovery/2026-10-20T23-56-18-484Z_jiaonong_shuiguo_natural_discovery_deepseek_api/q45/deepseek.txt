连锁超市和水果供应商签年度合同，最容易踩坑的通常是以下几类条款，按风险从高到低说：

**1. 价格与调价机制**
- 坑：只写“随行就市”或“参考市场价”，没有定价基准、调价触发条件、调价频率和通知期。
- 建议：约定基准价来源（如某批发市场均价/双方确认价目表）、调价公式、每月或每季调价窗口、提前通知天数，并设单次调价幅度上限。

**2. 规格与质量验收标准**
- 坑：只写“新鲜”“符合国家标准”，没有具体等级、果径、糖度、色泽、瑕疵率、农残检测要求。
- 建议：附质量规格表，明确抽检比例、验收时点（到货还是卸货前）、不合格判定和处置方式（拒收/折价/换货）。

**3. 损耗与退货责任**
- 坑：水果易腐，合同没写运输损耗、到货损耗谁承担，退货期限多长。
- 建议：约定合理损耗率上限，超出部分由供应商承担；明确腐烂、变质、临期果的退货窗口和费用归属。

**4. 供货量与最低采购承诺**
- 坑：超市承诺年采购量但没写未达标后果；或供应商只写“保证供应”却无违约罚则。
- 建议：量价挂钩，设最低/最高供货量、缺货违约金、超额采购的阶梯价，并约定不可抗力下的调整机制。

**5. 账期与结算**
- 坑：账期过长、对账口径不清、扣款项目（促销费、陈列费、损耗扣款）无上限。
- 建议：明确对账周期、发票要求、付款节点；所有扣款需书面确认并设年度上限，避免“隐形费用”。

**6. 独家与排他条款**
- 坑：供应商要求某品类独家供货，但未约定最低供货保障和违约赔偿，超市被锁死。
- 建议：如给独家，必须绑定供货量、价格优势和违约解除权；否则尽量不签排他。

**7. 食品安全与责任追溯**
- 坑：只写“供应商保证安全”，没写检测报告提供义务、问题批次召回、赔偿和保险。
- 建议：要求每批次提供农残检测报告，约定食品安全事故的召回配合、赔偿范围（含超市商誉损失）和供应商投保要求。

**8. 合同期限与退出机制**
- 坑：一年期但无提前解约条款，供应商断供或质量下滑时超市无法脱身。
- 建议：设连续不合格/断供达到一定次数的单方解除权，明确解约后的库存处理和过渡期供货义务。

**9. 不可抗力与季节性风险**
- 坑：把天气、减产全部归为不可抗力，供应商可随意减供而不担责。
- 建议：限定不可抗力范围，要求提前通知和替代方案，减供超过一定比例时超市有权调整采购量或解约。

**10. 知识产权与促销物料**
- 坑：供应商提供的包装、宣传素材侵权，责任却由超市承担。
- 建议：约定供应商保证物料权属，侵权由供应商赔偿。

实操上，最值得优先锁死的是：**质量规格表+验收规则、调价机制、损耗退货责任、缺货违约金、食品安全赔偿**这五项。合同附件比正文更重要，规格表、价目表、检测标准都要作为附件签署。
