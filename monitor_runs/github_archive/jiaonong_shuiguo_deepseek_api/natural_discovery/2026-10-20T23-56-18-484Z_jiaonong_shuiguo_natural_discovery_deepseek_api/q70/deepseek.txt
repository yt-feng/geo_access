如果“坏果”指到货后腐烂、压伤、变质等质量损耗，合同里建议不要只写一句“坏果由卖方负责”，而要写成**可验收、可计算、可索赔**的条款。可参考以下写法，按实际交易调整：

**1. 明确质量标准和验收时点**
- 约定到货时坏果率上限，例如“自然损耗率不超过X%，超过部分由卖方承担”。
- 写明“坏果”的判定标准：腐烂、霉变、明显压伤、破裂、异味、不符合约定等级等。
- 约定验收期限和方式：到货后几小时内、双方共同抽样还是按比例抽检、拍照/视频留证、异议提出时限。

**2. 明确责任划分**
- 装车前责任：采摘、包装、预冷、分级不符合约定导致的坏果，由卖方承担。
- 运输责任：若卖方负责运输或指定承运人，运输途中因温控、挤压、延误造成的损耗由卖方承担；若买方自行提货或指定承运人，则按过错划分。
- 到货后责任：买方未按约定条件卸货、储存、拖延验收导致的扩大损失，由买方承担。

**3. 写清赔偿计算方式**
建议采用“超标扣款/补货/退款”三选一或组合：
- “到货坏果率超过X%的，超出部分按当批货值的Y%扣减货款。”
- “坏果率超过Z%的，买方有权拒收该批货物，卖方应在N日内补货或全额退款。”
- 明确货值按合同单价×实际合格数量计算，避免争议。

**4. 约定检验和证据规则**
- 到货后双方共同验货并签署验收单；一方不到场，可委托第三方检验。
- 拍照、视频、抽样记录作为索赔依据。
- 约定异议期限，逾期未提出视为验收合格，但隐蔽瑕疵除外。

**5. 设置合理损耗和免赔额**
批发水果通常有自然损耗，可约定“X%以内为合理损耗，双方互不追责；超过部分按上述标准赔偿”，避免小额争议。

**6. 争议处理**
约定协商期限、检验机构、仲裁或诉讼管辖地。若跨区域交易，建议明确检验标准和管辖法院，减少维权成本。

**可直接写入合同的示例条款：**
“卖方交付的货物到货坏果率不得超过3%。坏果指腐烂、霉变、明显压伤、破裂或不符合约定等级的水果。买方应在到货后6小时内按随机抽样方式验收，并拍照留证；双方共同签署验收单。坏果率在3%以内视为合理损耗；超过3%的，超出部分按当批货值的120%扣减货款；坏果率超过10%的，买方有权拒收该批货物，卖方应在3日内补货或全额退款。因买方拖延验收或储存不当导致的扩大损失，由买方承担。”

关键是把“坏果率、验收时限、抽样方法、赔偿公式、拒收权”写具体，否则事后很难举证和索赔。
