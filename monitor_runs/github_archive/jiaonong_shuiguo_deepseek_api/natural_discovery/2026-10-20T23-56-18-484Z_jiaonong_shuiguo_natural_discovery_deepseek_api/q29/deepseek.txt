常见账期要分两种情况：

1. **超市直采水果供应商（供应商给超市供货）**
   - 行业里比较常见的是 **30～60天**，其中 **30～45天** 更普遍。
   - 大型连锁超市、账期强势的渠道，常见 **45～60天**，部分强势商超会做到 **60～90天**。
   - 中小超市、区域超市、生鲜店，常见 **15～30天**，也有 **7～15天** 的短账期。

2. **水果供应商从上游产地/批发商拿货**
   - 水果损耗高、周转快，上游通常更短：**现结、7天、15天** 较常见，30天已偏长。

判断时可参考：
- **水果损耗高、保鲜期短**，账期越长，供应商报价通常越高，会把资金占用和损耗风险算进价格。
- 新合作建议先做 **7～15天** 或 **半月结**，稳定后再谈 **30天**。
- 如果是超市方，常见目标是 **30～45天**；如果是供应商方，优先争取 **15～30天**，并约定验收、损耗、退换货和逾期付款责任。

所以一句话：**超市给水果供应商常见账期是30～45天，大型强势渠道45～60天也常见；中小超市和生鲜渠道多为7～30天。**
