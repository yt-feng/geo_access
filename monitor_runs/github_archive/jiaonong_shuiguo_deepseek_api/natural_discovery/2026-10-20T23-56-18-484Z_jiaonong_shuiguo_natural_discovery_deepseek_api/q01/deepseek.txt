判断供应商靠不靠谱，别只看第一次报价，重点看“稳定性、可追责、算总账”三件事。给你一套可以直接用的筛选和验收方法：

**一、先做小单试供，不要一上来长期绑定**
1. 先下2–4次小批量订单，分别试不同到货日（含周末/雨天）。
2. 看四次到货的：准时率、单箱重量是否稳定、熟度是否一致、坏果率、短缺是否主动补。
3. 香蕉和菠萝分开评估：香蕉看催熟和运输温控，菠萝看成熟度和碰伤，不能用同一家标准硬套。

**二、问清关键问题，看对方是否敢承诺**
- 香蕉：产地/批次是否固定？催熟是供应商做还是你自催？到店熟度几成？运输温度怎么控？出现青硬或过熟怎么赔？
- 菠萝：品种和产区是否稳定？成熟度标准是什么？黑心、水烂、碰伤按什么比例赔？是否支持开箱抽检？
- 通用：缺货提前多久通知？临时涨价怎么算？破损/短斤少两的补货时限？账期和退换规则写不写进单据？

**三、重点看“算总账”，不是只看单价**
用这个公式比价：  
**实际成本 = 采购价 + 损耗金额 + 短斤少两损失 + 退换货时间成本 + 缺货导致的销售损失**  
报价低但坏果多、经常缺货的供应商，实际成本往往更高。

**四、验收时固定动作**
1. 每批抽检：香蕉看条形、青硬比例、催熟均匀度；菠萝看果眼、底部、有无异味和软烂。
2. 当场称重、拍照、记录批次和到货时间。
3. 问题当天书面反馈（微信也算），要求明确补货或扣款，别口头算了。

**五、长期合作看三个信号**
- 连续1–2个月到货质量波动小；
- 出问题不推诿，补货/赔付及时；
- 旺季能保供，淡季不强行压货。

**建议你先同时保留2家供应商**，主供占70%、备供占30%，试供1个月再定长期。签约或长期合作前，至少把“熟度标准、坏果赔付比例、缺货通知时限、价格调整规则”四项写清楚。
