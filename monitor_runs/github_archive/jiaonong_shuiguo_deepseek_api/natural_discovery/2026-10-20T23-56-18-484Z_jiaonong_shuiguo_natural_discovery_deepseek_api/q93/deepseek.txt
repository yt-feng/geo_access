优先顺序建议：**包装与冷链/陈列条件 > 配送频次 > 保质期标注**。但不是只看一个，三者要配套管理。

1. **包装是底线，先看**
   - 菠萝切块属于即食鲜切水果，风险主要在切后微生物污染和汁液渗漏。
   - 包装要能密封、防渗漏、便于冷藏陈列，最好有明确切分/包装时间。
   - 如果包装只是保鲜膜简单覆盖、汁液外渗、冷凝水积在盒底，保质期写得再短也不稳。

2. **配送频次决定实际新鲜度**
   - 鲜切菠萝货架期短，配送频次低会导致门店压货、临期集中。
   - 建议按日销量定频次：高销量店每日配送，低销量店小批量高频，避免一次压多天量。
   - 配送频次要和“切分时间—到店时间—上架时间”一起记录，不能只看到店日期。

3. **保质期标注要管，但不是唯一判断**
   - 保质期必须有，且应与包装方式、冷藏条件、配送周期匹配。
   - 更实用的是设“切分时间+到店时间+最晚售完时间”三段控制，临期下架。
   - 如果保质期标注很长但包装和冷链一般，反而说明管控有问题。

**可执行建议：**
- 包装：选密封防漏盒，标签写切分日期/时间、到店时间、保质期、储存条件。
- 配送：按销量小批量高频配送，门店冷藏陈列，不常温堆放。
- 保质期：短保管理，设临期下架点；每天检查渗漏、胀盒、异味、变色。
- 验收：到店测温度、查包装完整性、查切分时间，不合格拒收。

一句话：**先保包装和冷链，再用配送频次控库存，保质期是结果不是唯一抓手。**
