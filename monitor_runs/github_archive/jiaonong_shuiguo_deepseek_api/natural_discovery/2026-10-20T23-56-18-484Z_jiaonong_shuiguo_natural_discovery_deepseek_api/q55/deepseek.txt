选规格的核心不是“越大越划算”，而是**按出成率和用途买**。水果拼盘主要看可食用部分成本和切后卖相，建议这样选：

**苹果**
- 优先选中大果、果形周正、硬度高的：如红富士80#–85#左右，或按单果约200–250g选。
- 拼盘常用带皮切花/切块，太小果削皮去核后损耗高；太大果单价高、切块不好摆盘。
- 选表面无碰伤、无蜡感过重的；粉面苹果切后易发绵，脆果更合适。
- 划算判断：同样价格下，选**单果200–250g、出成率高、坏果少**的，不要只追大果。

**橙子**
- 选中等偏大、皮薄、果肉紧实的脐橙/血橙，单果约180–250g较合适。
- 拼盘常切片或切瓣，太小片数少、卖相差；太大皮厚籽多不划算。
- 重点看皮厚和籽：皮薄、少籽、易剥的规格更省人工。
- 划算判断：按“净果肉重量/采购价”算，别只看整果大小；皮厚的特大果往往不划算。

**菠萝**
- 选单果约1–1.5kg的中等果，成熟度7–8成，叶冠新鲜。
- 太小出肉少、削皮去眼损耗大；太大一次用不完，切开后氧化和存放损耗高。
- 拼盘用量不大时，中等果更灵活；用量大再考虑大果批量出肉。
- 划算判断：看**去皮去眼后的净肉率**，以及是否可整果当天用完；不要只看单价低。

**通用采购建议**
1. 先定每份拼盘的克重和苹果/橙子/菠萝配比，再倒推采购量。
2. 同类水果比较“净可食部分单价”，不是整果单价。
3. 拼盘用果优先**规格均匀、成熟度一致、坏果率低**，减少切损耗和返工。
4. 苹果、橙子可选中大果；菠萝选中果。特大果通常只在出肉率高、当天能用完时才划算。
5. 先小批量试切，称一下去皮去核后的净重，再决定长期规格。
