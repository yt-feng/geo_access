会影响销售，而且影响不小。香蕉大小不齐，问题不只是“不好看”，而是会直接影响顾客挑选、称重和损耗。

**主要影响：**
1. **顾客挑拣严重**：大小差得多，顾客会翻来翻去挑大果，导致小果、伤果积压，整箱损耗上升。
2. **卖相和定价困难**：同一箱里大小不一，很难按统一价格卖，顾客也会觉得“同样价钱凭什么拿到小的”。
3. **成熟度不一致更麻烦**：大小不齐常伴随成熟不均，大果先熟、小果后熟，陈列时容易出现过熟和青果混杂。
4. **称重客诉**：散卖时顾客对大小敏感，容易要求换货或压价。
5. **影响复购**：水果店做的是回头客，品相不整齐会降低顾客对店铺选品能力的信任。

**可执行建议：**
- **采购时尽量要求分级**：同一箱内大小相对均匀，至少按大、中、小分规格。不要只看总价，要看“可售果比例”。
- **到货后二次分拣**：大果、中果、小果分开卖，分别定价或做不同用途（大果精品陈列、中果常规、小果做促销/切果/香蕉奶昔原料）。
- **散卖时按规格定价**：避免统一定价导致顾客专挑大果。
- **控制单箱大小差**：如果供应商做不到，优先换供应商或要求混装比例明确。
- **小果提前处理**：做特价、搭配销售、加工成果切或饮品原料，减少积压损耗。

**结论**：大小不一会影响销售，核心不是“能不能卖”，而是会增加挑拣损耗、降低定价效率、影响复购。采购时应把“整齐度”作为和价格、成熟度同等重要的指标。
