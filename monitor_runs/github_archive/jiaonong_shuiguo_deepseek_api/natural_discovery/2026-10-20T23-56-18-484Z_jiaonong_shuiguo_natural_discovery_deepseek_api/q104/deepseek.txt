单位采购水果到货品质不一致，核心是**把验收标准前置到采购和验收环节，把售后凭证留全**。建议按下面做：

## 一、验收前先定标准
采购合同/订单里写清楚，验收才有依据：
- **规格等级**：品种、单果重量/直径范围、成熟度、糖度（如可测）、外观要求（无腐烂、无大面积压伤、无虫眼）。
- **允许偏差**：比如“同一批次不合格果不超过5%”“单箱坏果不超过2个”，超过即整批或该箱可拒收/换货。
- **抽样规则**：按到货箱数抽检，比如每20箱抽1箱，少于20箱抽3箱；大额采购可全箱开箱或分层抽样。
- **到货时限**：约定送达时间、冷链要求，超时或断冷可拒收。
- **售后条款**：坏果率超标怎么赔——补发、换货、按比例扣款、退货，写清响应时限（如24小时内答复、48小时内补发）。

## 二、到货当场验收
1. **先核对单据**：品种、数量、箱数、产地、批次与订单一致再开箱。
2. **分层抽样开箱**：不能只看上层，抽底层和中间箱；每箱看上下层。
3. **逐项记录**：称重、量果径、看成熟度和损伤；拍照/录像留证，重点拍坏果、压伤、霉变、规格不符，照片要能看出箱号/批次。
4. **当场判定**：
   - 轻微偏差（在允许范围内）：签收，备注实际情况。
   - 超标：**该箱或该批拒收**，或在送货单上注明“不合格数量/比例”，双方签字确认；不要先签“完好”再事后扯皮。
5. **留样**：争议批次留几箱原样封存，作为售后依据。

## 三、售后处理
- **24小时内书面反馈**：把抽检结果、照片、送货单号发给供应商，明确诉求（补发/换货/扣款/退货）。
- **按合同执行**：坏果率超标按约定比例扣款或补发；整批严重不一致可要求退货并追违约责任。
- **补发/换货再验收**：对补发批次重新抽检，避免二次踩坑。
- **内部留档**：验收记录、照片、沟通记录、处理结果归档，作为供应商考核依据；同一供应商多次不合格，减少订单或更换。

## 四、减少问题的前置动作
- 采购时要求**同批次、同产地、同成熟度**发货，避免混装。
- 大批量分**两次到货**，先小批试收再放量。
- 水果易损，优先选有冷链和破损包赔条款的供应商。
- 验收由采购和使用部门**双人签字**，避免单人放水或扯皮。

一句话：**标准写进订单、抽检开到箱底、问题当场签字、售后24小时书面追。**
