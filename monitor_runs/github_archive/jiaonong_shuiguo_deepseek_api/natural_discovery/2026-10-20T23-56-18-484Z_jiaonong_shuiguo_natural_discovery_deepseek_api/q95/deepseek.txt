学校食堂采购香蕉、苹果、橙子这类常见水果，选供应商的重点不是“谁报价最低”，而是**稳定供货、食品安全可追溯、损耗可控、结算合规**。建议按下面几步做。

## 1. 先定采购标准，再找供应商

采购前把三类水果的验收标准写清楚，避免后期扯皮：

- **香蕉**：按成熟度分级，食堂一般选7成熟左右、到校后1–2天可食用的；要求无黑斑腐烂、无冻伤、果指完整。
- **苹果**：明确品种、果径范围、糖度大致要求、外观（无碰伤、无虫眼、无药斑），区分鲜食和加工用途。
- **橙子**：明确品种和产地范围、果径、可食率、酸甜度，要求无霉变、无裂果。
- **通用要求**：农残检测合格、来源可追溯、包装标识齐全、运输冷链或通风条件符合要求。

标准越具体，供应商报价越可比，验收也越有依据。

## 2. 供应商准入看五个硬条件

1. **证照齐全**：营业执照、食品经营许可证（或食品生产/流通相关许可）、供货资质；如果是产地直供，要有产地证明或合作社资质。
2. **检测能力**：能提供农残检测报告，最好有批次检测；至少要承诺批批可检、可追溯。
3. **供货稳定性**：有固定产地或一级批发渠道，能说明旺季淡季怎么保供，是否有备用货源。
4. **配送能力**：能否按学校要求的时间、频次配送；车辆是否清洁、有无防雨防晒防污染措施；能否配合晨检式验收。
5. **售后与结算**：坏果怎么退换、损耗怎么算、账期能否接受、能否开合规发票。

## 3. 比价不要只看单价

建议用“综合成本”比较：

- 报价是否含税、含运费、含卸货；
- 验收合格率、坏果率；
- 退换货响应时间；
- 最小起订量和配送频次；
- 账期和结算方式。

可以要求供应商按“周报价+随行就市浮动规则”报价，避免长期锁价导致质量下降，也避免完全随行就市导致预算失控。常见做法是约定一个基准价，再按当地批发市场监测价或产地价浮动，幅度写进合同。

## 4. 建议的选商流程

1. **发布采购需求**：写清品种、规格、数量、配送频次、验收标准、结算方式。
2. **资格初审**：收证照、检测报告、供货案例。
3. **实地或视频考察**：看仓储、分拣、运输和货源。
4. **小批量试供**：先试供2–4周，重点看到货质量、准时率、坏果处理。
5. **综合评分**：质量与安全40–50分、价格20–30分、供货与配送15–20分、售后与合规10–15分，按学校实际调整。
6. **签框架合同**：明确质量标准、价格调整机制、退换货、违约责任、食品安全责任。

## 5. 合同里必须写清的点

- 每批次随货提供检测报告或承诺抽检；
- 验收标准和不合格处理方式（拒收、换货、扣款）；
- 价格调整触发条件和幅度；
- 配送时间、频次、车辆和人员卫生要求；
- 食品安全事故的责任承担；
- 发票和结算周期；
- 合同期限和退出机制。

## 6. 一个实用建议

不要只选一家。香蕉、苹果、橙子可以**主供+备供**各一家，或者按品类分供应商。主供保证日常，备供防止断供和议价被动。试供期重点看“坏果率”和“准时率”，这两个指标比报价更能反映真实成本。

总结：先写验收标准，再查资质和检测，小批量试供，按质量安全优先的综合评分选商，合同写清价格浮动和退换货。这样选出来的供应商更稳，也更适合学校食堂的合规要求。
