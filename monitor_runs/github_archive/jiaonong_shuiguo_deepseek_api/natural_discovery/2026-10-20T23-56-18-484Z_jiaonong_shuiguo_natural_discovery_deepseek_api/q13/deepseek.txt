小水果店做附近小区团购，供应商要重点看“能不能帮你稳定履约”，不只是价格低。建议要求供应商支持以下服务：

1. **小批量、多频次配送**
   - 支持按团购订单量分次补货，避免一次压货。
   - 能接受起订量较低、临时加单/减单。
   - 明确配送时间窗口，最好能配合小区团购的固定截单和到货时间。

2. **分级分拣和按团包装**
   - 能按你给的规格分拣：大果/中果、净重、每份装袋或装盒。
   - 支持贴团购标签、按小区/楼栋/团长分装，减少你二次分拣人工。
   - 次果、坏果比例要有约定，不能把损耗转嫁给你。

3. **品控和售后兜底**
   - 到货坏果、烂果、短斤少两的赔付标准要写清。
   - 支持拍照/视频报损，按比例补货、退款或下次抵扣。
   - 对团购常用单品能提供稳定等级，不要今天一个规格明天一个规格。

4. **价格和库存稳定**
   - 团购价要有一段锁价期，避免你已开团、供应商临时涨价。
   - 能提前给次日/当周可售品类和库存，方便你开团。
   - 爆品缺货时能提前通知，并给替代品建议。

5. **冷链和包装支持**
   - 易坏水果要有冷链或保鲜配送。
   - 提供适合小区自提的包装方案：透气、防压、防潮，最好能印你的店名/团购信息。
   - 夏季高温、冬季防冻要有对应措施。

6. **结算和账期灵活**
   - 支持日结、周结或按团结算，押金和账期别太重。
   - 退货、补损、优惠差价能清晰对账。
   - 能开收据/发票或至少提供规范送货单。

7. **选品和开团支持**
   - 定期给适合社区团购的爆品清单、建议零售价、毛利空间。
   - 能提供水果保存、催熟、口感卖点等素材。
   - 支持试销小样或小批量测款。

8. **应急履约能力**
   - 临时爆单能加量配送。
   - 出现品质问题时能当天补货或给出处理方案。
   - 有备用联系人，不要团购截单后找不到人。

你可以用一份简单表格筛供应商：**起订量、配送频次、分拣包装、损耗赔付、锁价周期、账期、应急补货**。优先选“愿意小批量配合、售后痛快、分拣省你人工”的供应商，而不是单纯报价最低的。
