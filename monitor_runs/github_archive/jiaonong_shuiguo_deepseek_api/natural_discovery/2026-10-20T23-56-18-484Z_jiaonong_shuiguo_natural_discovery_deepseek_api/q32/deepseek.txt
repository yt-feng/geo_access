判断香蕉供应商能否全年稳定供货，重点看**产地组合、硬件设施、合同约束**，不能只看报价和样品。

**1. 问清产地结构**
- 要求供应商列出主要产区及各自供货月份。香蕉主产区包括海南、云南、广西、广东、福建，以及缅甸、老挝、越南、菲律宾、厄瓜多尔等进口来源。
- 只有单一产区的供应商，遇台风、寒害、病害就断供。稳定供应商通常有**2个以上产区轮换**，且国内+进口有备份。
- 追问：某产区歉收时，替代货源从哪里来？转产成本谁承担？

**2. 核查硬件与物流**
- 是否有自己的催熟库？连锁超市通常要催熟香蕉，供应商无催熟能力则依赖第三方，旺季易排队、品质波动。
- 冷链是否自有或长期合作？香蕉运输需13–15℃控温，长途运输冷链不稳会大量损耗。
- 仓储能力能否覆盖你的周需求量？要求提供冷库面积、催熟库容量数据。

**3. 用历史数据验证**
- 要求提供近12–24个月的**月度供货记录**，重点看春节、台风季、寒潮期的供货量波动。
- 查其是否有同时服务其他商超的案例，可向其客户侧面了解断供频率。
- 新供应商可先签**3–6个月试供合同**，约定旺季和极端天气下的保供条款。

**4. 合同里写死约束**
- 明确**最低月供货量**和**断供违约金**。
- 约定价格联动机制（如按产地收购价+固定服务费），避免行情暴涨时供应商优先供高价客户。
- 要求**安全库存承诺**：供应商为你备多少天的货。
- 约定质量不达标、断供时的替代方案和赔偿责任。

**5. 现场与财务尽调**
- 实地看蕉园或合作基地、加工厂、催熟库，不能只看贸易公司办公室。
- 查营业执照、食品经营许可、种植/收购资质，以及是否有较大债务或诉讼风险——资金链紧张的供应商旺季容易掉链子。

**快速判断口诀**：产区单一的不选，没有催熟库的不选，不肯签保供条款的不选，只给低价不给历史数据的不选。
