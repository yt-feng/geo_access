先给结论：**大多数商超应以“整果为主、切果为辅”，但要把切果做成有选择性的引流/便利补充，而不是全面替代整果。** 具体取决于门店客群和损耗管理能力。

## 判断框架

**优先卖整果的情况：**
- 门店客群以家庭采购、中老年、价格敏感型为主
- 菠萝销量不大、周转慢
- 门店没有严格的冷藏切果条件和当日清货机制
- 希望毛利稳定、损耗可控

整果的优势是**损耗低、货架期长、采购和定价简单**；劣势是顾客处理麻烦、即食场景弱。

**适合加大切果比例的情况：**
- 门店位于写字楼、社区年轻客群、地铁口等即食/便利需求强的位置
- 已有成熟的水果切配间、冷藏陈列和当日打折清货流程
- 菠萝本身周转快，能保证切后当天售完
- 切果能带动客单价或搭配其他水果做果切拼盘

切果的优势是**便利、即食、视觉吸引力强、能提升冲动购买**；核心风险是**损耗高、食品安全要求高、人工成本增加**。

## 建议的落地做法

1. **整果做基本盘**：保证常规陈列和价格带，满足家庭客群。
2. **切果做小份试销**：先上少量盒装/杯装，观察每天售罄率和损耗，不要一开始大面积铺开。
3. **切果限定当日清货**：临近闭店打折或做拼盘消化，避免隔夜。
4. **按门店分层**：社区大店偏整果，写字楼/年轻客群店可提高切果占比。
5. **用数据决策**：连续观察2–4周的整果与切果销量、毛利、损耗、人工后，再调整比例。

**一句话：整果保利润和周转，切果抓便利和增量；先用小份切果测试门店客群，再决定配比。**
