# 判断水果报价波动是否合理的方法

## 一、先建立“基准价”体系

1. **锁定同期市场参考价**：每天记录本地批发市场（如新发地、江南市场等）同品类同规格的均价，作为对照基准。供应商报价偏离市场均价 ±10%~15% 以内，通常属于正常波动。
2. **区分品类敏感度**：
   - 叶菜类、浆果类（草莓、蓝莓）波动大，日波动 10%~20% 属正常；
   - 苹果、柑橘、根茎类耐储果波动小，日波动超过 5%~8% 就要问原因。
3. **建立自己的历史价格库**：按品类、规格、产地记录 30~90 天价格曲线，看当前价处在历史区间的什么位置（分位数）。

## 二、要求供应商“报价带依据”

- 报价单附带：产地、规格等级、包装、到货时间、**当日产地收购价或市场行情截图**。
- 对涨价要求说明具体原因：产地天气、减产、运输涨价、节日备货等，**可验证的原因**才算数。
- 提前约定“触发式调价”条款：只有市场价波动超过约定阈值（如 ±8%）才允许调价，且需提供凭证。

## 三、用简单规则快速判断

| 现象 | 判断 |
|---|---|
| 涨跌方向与主流市场一致、幅度接近 | 合理 |
| 连续单向上涨但市场平稳 | 可疑，要求解释 |
| 只涨不跌（市场已回落仍报高价） | 不合理，议价 |
| 同一供应商对不同客户报价差异大 | 查价，要求统一价目 |
| 波动频繁但无任何依据 | 换供应商或转固定价+浮动机制 |

## 四、机制上减少被动

- **签浮动价公式**：结算价 = 市场参考价 × 固定系数，双方每天按同一公开行情源核算，避免扯皮。
- **多源比价**：至少保持 2~3 家合格供应商，每周交叉询价。
- **锁价与期货结合**：对用量大的耐储品类，谈周价或半月价，减少日频波动暴露。
- **异常抽查**：对报价明显偏离的批次，实地或电话核实产地行情。

## 五、关键提醒

判断的核心不是“今天涨没涨”，而是**报价能否被独立行情源验证、波动方向是否与市场同步、供应商是否愿意提供依据**。愿意透明报价的供应商，即使价格略高，长期合作风险也更低。
