# 采购端降低坏果与口感不稳定的可执行做法

线上卖水果，差评基本集中在两件事：**到手坏**和**不好吃/不稳定**。前者靠供应链和品控解决，后者靠选品和验收标准解决。

## 一、从源头减少坏果

**1. 按“运输耐受度”选品和选产地，而不是只看价格**
- 优先选耐储运品种（如苹果、梨、橙、柚子），高损耗品种（草莓、水蜜桃、荔枝、杨梅）要么不做，要么限定同城/短途、冷链直达。
- 同一品种不同产地耐储性差异大，固定 2–3 个经过验证的产区，别频繁换供应商换产地——换一次产地，口感和损耗都会波动。

**2. 采购时明确“成熟度”而不是“大小好看”**
- 线上发货必须采购**七八成熟**的果，全熟果好看但到手就烂。
- 在合同/订单里写清采摘成熟度、果径、糖度区间、允许瑕疵比例，口头约定一定会翻车。

**3. 把验收标准量化，写进采购合同**
至少约定这几项：
- 糖度下限（用糖度计抽检，如≥11°）
- 果径/单果重区间
- 坏果率上限（如到货抽检坏果≤3%，超标整批退换或扣款）
- 软果、裂口、机械伤、霉变的判定标准
- 包装方式（泡沫托、网套、纸箱层数、冰袋/保温要求）

**4. 控制采购批量与周转**
- 小批量、高频次补货，比一次性囤大货坏果率低得多。
- 采购量按近 7–14 天实际销量定，生鲜别赌库存。

## 二、减少口感不稳定

**1. 锁定供应商和批次，建立“批次档案”**
- 每批记录：产地、采摘日期、糖度抽检值、到货坏果率、客户差评关键词。
- 连续 2–3 批口感投诉上升，就暂停该供应商/产地，而不是等差评堆积。

**2. 到货抽检要固定动作**
- 每批随机抽 10–20 个，测糖度、捏硬度、切开看内部（褐变、空心）。
- 抽检不合格的批次不上架，或降级做特价/果切，别混发。

**3. 分级销售，别把不同品质混在一个链接**
- 按糖度/果径分等级定价，标注“酸甜口/纯甜口”，降低“和描述不符”的差评。
- 对口感波动大的品种（如猕猴桃、芒果），在详情页写清“需放软后食用”，减少因未熟误判的差评。

**4. 仓储和发货环节别毁掉采购成果**
- 不同水果分开存，乙烯释放大的（香蕉、苹果）别和易催熟的混放。
- 夏季加冰袋/保温箱，冬季防冻；发货前再筛一遍，软果、碰伤果不上车。

## 三、兜底机制

- **预留售后预算**：按销售额 2%–5% 计提坏果赔付，主动“坏果包赔、拍照即赔”，比事后扯皮更能压差评。
- **差评归因**：每周把差评按“坏果/不甜/不新鲜/物流慢”分类，坏果类追到批次和供应商，口感类追到品种和成熟度。

一句话总结：**选耐运品种、锁固定产地、量化验收标准、小批量高频周转、分级销售、坏果包赔兜底**——这六件事做到位，坏果率和口感投诉会明显下降。
