从食堂管理角度，**按斤结算最容易控成本但验收工作量大；按箱结算最省事但容易吃亏；按份结算适合净果直接分发但单价最高、灵活性差**。没有绝对最好，按水果品类和管理能力分开用最稳。

**结论建议：**
- **大宗、耐储存、易称重的水果**（苹果、梨、柑橘、香蕉等）：**按斤结算**。便于比价、控损耗、按需采购，适合食堂主用量。
- **标准化程度高、整箱规格稳定的水果**（箱装苹果、橙子、提子、西瓜等）：**按箱结算**，但合同必须约定**净重、规格、损耗率、缺斤少两处理**。只写“按箱”不写净重，最容易出问题。
- **净果、果切、直接分发到窗口或员工的水果**：**按份结算**。管理最简单，但采购单价通常更高，适合小份分发或外包配送。

**管理判断标准：**
1. **验收能力弱、人手少**：优先按箱/按份，减少称重环节。
2. **想控成本、抓比价**：优先按斤，要求送货单、验收单、复称记录。
3. **混合模式最实用**：主量水果按斤，辅果/净果按份，整箱促销品按箱但明确净重。

**关键控制点：**
- 按斤：必须复称，扣皮重，记录损耗。
- 按箱：合同写清箱规、净重、允许误差、破损谁承担。
- 按份：明确每份克数/个数、包装成本、退换规则。

一句话：**想省钱按斤，想省事按箱，想省人按份；食堂最推荐“按斤为主、按箱为辅、按份补缺”的混合结算。**
