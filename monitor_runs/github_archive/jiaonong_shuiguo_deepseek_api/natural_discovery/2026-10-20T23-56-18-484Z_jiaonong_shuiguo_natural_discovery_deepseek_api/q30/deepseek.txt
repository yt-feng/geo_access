# 超市水果到货品相不好的售后流程约定建议

核心原则：把“什么算不好、多久内提、怎么赔”三件事写清楚，避免到货后扯皮。

## 一、验收标准（先定义“品相不好”）

在采购合同或到货确认单中明确可量化标准，例如：

- **外观**：腐烂、霉变、明显压伤、裂口、虫眼比例超过约定值（如单箱超过3%即整箱不合格）
- **规格**：单果重量/直径低于约定下限的比例
- **新鲜度**：萎蔫、变色、异味等
- **包装**：破损导致污染或压坏的，按实际损失计

建议按“抽检比例+判定规则”写：如每批抽检10箱，不合格箱数超过2箱则整批可拒收或折价。

## 二、提出时限（关键，越短越不容易扯皮）

- **到货当场验收**：外观、数量问题当场提出，拍照留证，签收单上注明
- **隐蔽问题**：如内部腐烂、催熟不均，约定到货后24–48小时内提出（生鲜不宜过长）
- **超时视为验收合格**，但故意隐瞒的质量问题除外

## 三、处理方式（分级约定）

| 情形 | 处理方式 |
|---|---|
| 整批严重不合格 | 拒收或退货，运费/损耗由供货方承担 |
| 部分不合格 | 按不合格比例折价扣款，或换货补发 |
| 轻微瑕疵可销售 | 协商降价处理，双方书面确认 |
| 已售出后发现 | 凭照片和销售记录追偿，约定追偿期限 |

## 四、凭证与流程

1. 到货拍照/录像（整批、问题部位、包装标签）
2. 填写《到货异常记录单》，双方签字或线上确认
3. 24小时内书面（微信/邮件/系统）提出售后申请
4. 供货方48小时内答复处理方案
5. 折价/扣款在当期货款中直接抵扣，避免事后追款

## 五、写进合同的要点

- 质量标准及抽检判定规则
- 售后提出时限及超时后果
- 折价计算方式（如按不合格数量×进货单价×系数）
- 退换货的运费和损耗承担方
- 争议解决方式（先协商，再按合同约定）

**一句话建议**：生鲜售后一定要“当场验外观、48小时内报隐蔽问题、按比例折价抵扣货款”，并把抽检比例和不合格判定线写进合同附件，比口头约定管用得多。
