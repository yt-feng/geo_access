# 小商家采购水果：现金结算 vs 月结账期的风险对比

## 一、现金结算的风险

**1. 资金占用压力**
水果是高频、易腐、需持续补货的品类，现金结算意味着每批货都要即时出钱。旺季（如节假日、应季水果集中上市）补货量大时，现金流容易被抽紧，一旦销售回款慢，可能出现"有货卖但没钱进下一批"的断档。

**2. 无账期缓冲，抗波动能力弱**
遇到天气导致到货延迟、售价临时下跌、或下游客户拖欠货款时，现金结算没有时间差缓冲，损失直接落在当期现金上。

**3. 交易凭证与售后风险**
现金交易若无规范单据（收据、过磅单、验收记录），出现短斤少两、品质不符、坏果率过高时，**举证和追责困难**。建议即使现金结算也坚持"过磅单+验收签字+拍照留证"。

**4. 安全与合规风险**
大额现金携带、存放有盗抢风险；现金支出若无票据入账，税务上可能无法税前扣除，账务也不清晰。

**5. 议价劣势**
现金虽常能拿到"现结价"折扣，但如果供应商知道你只能现结，在紧俏货上议价空间反而受限。

## 二、月结账期的风险

**1. 信用与坏账风险（对供应商而言）**
月结本质是供应商给你授信。若你的门店销售不及预期、回款慢，月底付不出款，会损害合作关系，严重时被停供、断货——水果断货对客流伤害很直接。

**2. 账期条款模糊的陷阱**
"月结"常见歧义：是货到后30天，还是自然月月底统一结？逾期是否计息、有无滞纳金？**不写清楚，容易在结算日产生纠纷**，甚至被供应商单方面缩短账期或要求补保证金。

**3. 隐性成本转嫁**
愿意给账期的供应商，报价通常比现结价高几个百分点（相当于把资金成本计入货价）。小商家若没算这笔账，会误以为"账期是免费的"。

**4. 品质与损耗责任不清**
账期交易中，若验收环节松懈，坏果、短斤问题在月结对账时才暴露，容易与供应商扯皮，且此时货已售出，退换困难。

**5. 依赖单一供应商的风险**
账期往往绑定固定供应商，一旦对方涨价、断供或经营出问题，你临时切换现结渠道会面临现金流突变。

## 三、给小微水果商的可执行建议

| 场景 | 建议做法 |
|---|---|
| 新供应商/新品类 | 先现金小额试单，验品质和结算习惯，再谈账期 |
| 核心走量品类 | 争取"部分账期"（如先付70%、月底结30%），而非全月结 |
| 账期合同 | 白纸黑字写明：结算日、逾期条款、品质不合格的退换与扣款规则 |
| 现金交易 | 坚持过磅单、验收签字、留存照片，票据入账 |
| 现金流管理 | 预留至少1–2周进货现金，不把全部资金压在账期依赖上 |
| 供应商结构 | 至少保留2家可现结的备选供应商，防止被断供卡脖子 |

**一句话总结**：现金结算风险在"现金流紧+举证难"，月结风险在"信用透支+条款模糊+隐性加价"。小商家较稳妥的做法是**核心品类争取短账期并写清条款，边缘品类现结，同时保留现结备选渠道**，把两种方式的优点都用上、风险都控住。
