# 水果供应商大客户：账期与额度怎么谈

先说结论：**水果品类不要谈“账期”，要谈“信用额度+结算频率”的组合。** 水果是生鲜，周转快、损耗高、价格波动大，纯账期（比如月结60天）对这个行业是错配的，双方都吃亏。你要的是“资金占用可控的滚动授信”。

## 一、谈之前先算清自己的账

- **你的资金缺口**：日均采购额 × 想覆盖的天数。比如日采2万，想压15天资金，缺口就是30万。
- **你的毛利缓冲**：水果批发毛利一般在10%~20%，账期每拖30天，相当于吃掉相当一部分利润（按年化12%资金成本算，30天账期≈1%采购额的成本）。**给自己定一个上限：账期成本 ≤ 毛利的一定比例**，算出来才知道能谈到多少。
- **你的回款节奏**：下游是现款、周结还是月结？上游账期必须短于下游回款周期，否则你在垫资，现金流会断。

## 二、账期：用“阶梯授信”替代“一口价账期”

推荐结构（按合作时间递进）：

| 合作阶段 | 额度 | 结算方式 |
|---|---|---|
| 试单/前1-2个月 | 5万~10万 | 现款或3天结 |
| 稳定3个月后 | 20万~30万 | 周结，或15天滚动 |
| 半年以上、无逾期 | 再上浮30%~50% | 半月结/月结，但设封顶 |

关键话术：**“我不是要账期，我是要一个可预期的资金安排。你按这个阶梯给我授信，我保证不超额度、不拖结算。”** 供应商最怕的是“没上限的赊账”和“说不清什么时候付”，不是怕给钱。

## 三、额度：谈“额度上限+超限现结”，而不是谈“无限赊”

- 额度锚定在**你月采购额的一定比例**（常见30%~50%），而不是拍脑袋。
- 明确规则：**额度内走账期，超额度部分现结或预付**。这条对供应商是定心丸，对你也是硬约束。
- 约定**额度调整机制**：连续3个月按时结算、采购量达标，自动上浮；出现逾期，额度冻结。

## 四、用“给供应商的好处”换条件

谈判是交换，不是索取。你手里有这些筹码：

1. **采购量承诺**：承诺月采购量下限，换更高额度。
2. **付款确定性**：固定每周X日打款，雷打不动。供应商对这种“确定性”的估值很高。
3. **缩短账期换价格**：比如“我接受7天结，你给我2%的价格折让”，比硬要60天账期更划算，因为你的资金成本大概率高于2%。
4. **预付一部分**：比如30%预付+70%账期，供应商接受度会高很多。

## 五、必须写进合同/协议的口径

- 结算日、逾期处理（滞纳金或暂停供货）
- 额度上限与超限规则
- **质量与损耗的责任划分**（水果到货烂果、短斤缺两怎么扣款）——这条不谈清楚，账期谈得再好也会吵架
- 价格随行就市时的调价与对账机制

## 六、避坑提醒

- **别用“账期”当压价工具**：水果供应商利润薄，账期压太狠，他会用缺斤短两、以次充好找回来。
- **别口头承诺**：额度、结算日一定落到纸面，哪怕是一页纸的框架协议。
- **留一家备用供应商**：单一供应商给足你账期，本质是你在依赖他，议价权会流失。

一句话：**谈“阶梯授信+超限现结+固定打款日”，比谈“月结多少天”更容易成，也更稳。**
