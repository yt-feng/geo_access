结论先说：**多数餐饮连锁更适合“中央厨房/区域配送中心统一收货”，门店只做例外和临收**。但是否绝对更好，取决于水果品类、门店密度、冷链能力和结算模式。下面给你可判断的框架。

## 一、优先选中央厨房统一收货的情形

满足以下任意几条，建议统收：

1. **门店数量≥10家，且相对集中**
   - 便于集中验收、统一议价、统一品质标准。
   - 供应商对接一个口，减少门店各自砍价、吃回扣、标准不一。

2. **水果以耐储品类为主**
   - 苹果、橙子、柠檬、香蕉、西瓜、哈密瓜、火龙果、部分根茎类。
   - 这类适合统采、分拣、二次配送。

3. **有冷藏/恒温分拣能力**
   - 中央厨房能做出入库、温控、成熟度分级、先进先出。
   - 没有冷链却硬统收，损耗会反噬。

4. **需要标准化出品**
   - 果切、饮品、甜品、沙拉对糖度、规格、成熟度要求稳定。
   - 统收更容易做验收标准和留样追溯。

5. **总部要控采购合规和成本**
   - 统一合同、统一账期、统一发票、统一对账。
   - 门店只报量、收货确认，减少现金采购和飞单。

## 二、更适合门店分开收货的情形

1. **高损耗、强时令、成熟度敏感品类占比高**
   - 草莓、蓝莓、葡萄、桃、荔枝、杨梅、芒果、牛油果等。
   - 多一道中转就多一次磕碰和温变，门店直收可能更新鲜。

2. **门店分散、配送半径大**
   - 跨城市、跨区域，中央仓到店超过数小时，水果二次配送成本高。
   - 这时更适合“区域仓统收+门店临收”混合。

3. **单店销量小、品类杂**
   - 统配起送量不经济，容易压库存。
   - 门店按日少量补货更灵活。

4. **当地有强势批发市场/供应商**
   - 门店能拿到更短链路、更优价格和更新鲜批次。
   - 但必须纳入总部价格和品质监控。

## 三、推荐的落地模式：混合收货，不是二选一

比较稳的做法是：

- **A类：统收统配**
  - 耐储、标准化、量大、用于果切/饮品基底的品类。
  - 中央厨房统一验收、分拣、贴标、配送。

- **B类：区域仓统收，门店直配**
  - 由区域配送中心验收，供应商直接配到门店或短驳。
  - 总部控合同和标准，门店只确认数量品质。

- **C类：门店临收**
  - 高损耗鲜果、应急补货、地方特色水果。
  - 设白名单、限金额、限品类，必须拍照留证、当日录入系统。

## 四、判断公式

你可以用这四个指标打分：

| 指标 | 偏向统收 | 偏向门店收 |
|---|---|---|
| 品类耐储性 | 高 | 低 |
| 单店日均用量 | 大 | 小 |
| 冷链与分拣能力 | 强 | 弱 |
| 门店密度/配送半径 | 集中/短 | 分散/长 |

四项里三项偏统收，就统收；两项以上偏门店，就混合或门店直收。

## 五、统收必须配套的管控点

否则统收会变成“总部压货、门店损耗”：

1. **验收标准量化**：规格、糖度、成熟度、瑕疵率、温控区间。
2. **到店二次验收**：数量、破损、温控记录，责任可追溯。
3. **损耗归属**：中央仓、配送、门店三段分开统计，别一笔糊涂账。
4. **订货机制**：门店报量+总部审核+安全库存，不要纯拍脑袋统配。
5. **供应商考核**：到货合格率、批次新鲜度、缺货率、客诉率。
6. **临收白名单**：哪些品类允许门店买、限额多少、怎么报销。

## 一句话建议

**如果你们是10家店以上、有中央厨房和冷链、水果以耐储和标准化出品为主，优先中央厨房统一收货；高损耗鲜果和远距离门店用“区域仓统收+门店临收”补位。不要所有水果一刀切统收，也不要全放门店。**
