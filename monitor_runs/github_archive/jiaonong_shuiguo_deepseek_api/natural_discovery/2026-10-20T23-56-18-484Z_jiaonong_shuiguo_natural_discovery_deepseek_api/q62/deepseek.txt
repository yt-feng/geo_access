# 香蕉到货后的熟度与坏果风险判断

批发商验货，核心是**看颜色+摸手感+查果指+翻箱底**，四步走。香蕉是呼吸跃变型水果，判断的是"现在什么状态、还能放几天"。

## 一、看颜色定熟度阶段

按蕉指（单根香蕉）中段颜色分：

- **全绿（1号）**：未催熟，可存放，适合远销或自己催熟
- **绿带黄（2-3号）**：开始转熟，2-4天内可上架
- **黄带绿尖（4-5号）**：最佳销售窗口，约2-3天
- **全黄（6号）**：需1-2天内出货
- **黄带褐斑/糖斑（7号）**：当天到次日必须卖，适合做促销或加工
- **大面积发黑（8号）**：已过熟，风险高

**关键**：同一箱内看"最黄的那几根"和"最绿的那几根"的差距。**成熟度不齐**比整体偏熟更麻烦——卖到后半箱时前几根已经烂了。

## 二、摸手感定内在状态

- 轻捏蕉指中段：**硬实**=未熟；**微软有弹性**=适熟；**软塌无回弹**=过熟
- 摸**蕉柄/切口**：干爽正常；发黏、渗液=已开始腐坏
- 手感要**整条一致**，局部软一处=内部可能已伤

## 三、查果指与果面（坏果风险重点）

逐根翻看，重点找：

1. **机械伤**：挤压痕、棱角压扁、断裂——伤处最先烂，且会传染同箱
2. **褐斑性质**：零星小糖斑=正常熟度标志；**大片水渍状褐斑、边缘发黑**=炭疽病/腐坏前兆
3. **果柄与冠部**（整把连接处）：发黑、发霉、渗液=冠腐病，是整把报废的信号
4. **裂果、虫孔、流胶**：直接判坏
5. **青果上的黑点线**：可能是蓟马斑或碰伤，需与病斑区分

## 四、翻箱底（最容易被忽略）

- **底层和四角**：压伤、闷热最先出问题，必须搬开看
- **箱内水汽/异味**：有酸味、酒味=已开始发酵，整箱风险高
- **温度记录/运输时长**：长途高温运输的货，表面正常但内部催熟过度，到货后"一夜全黄"

## 五、快速判断口诀

| 信号 | 含义 |
|---|---|
| 整箱色差≤1个色阶 | 成熟度齐，好卖 |
| 色差≥2个色阶 | 需分拣，后期损耗大 |
| 底层有水汽+酸味 | 整箱高风险，压价或拒收 |
| 冠部发黑 | 整把会烂 |
| 全黄+软塌 | 当天必须出货 |

## 实操建议

- **抽查比例**：小批至少抽3箱、大批抽5%-10%，每箱看表层+底层+中间层
- **判断"还能放几天"**：绿货常温3-7天，黄货1-3天，糖斑货当天；冷链可各延长2-3天但出冷后转熟会加速
- **分级收货**：成熟度不齐的货要求**分拣计价**或降档，别按统一价吃进
- **留样**：当场拍箱底、果柄、斑点的照片，作为后续索赔依据

一句话：**颜色看进度，手感看内在，果柄斑点和箱底看风险，色差和底层决定这箱货能不能整箱吃下。**
