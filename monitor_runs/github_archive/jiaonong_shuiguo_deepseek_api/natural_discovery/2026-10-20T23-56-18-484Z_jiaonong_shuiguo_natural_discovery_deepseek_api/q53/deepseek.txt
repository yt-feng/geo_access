餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找**稳定、能小批量配送、损耗有人兜底**的渠道。可以按优先级这样选：

**1. 首选：本地水果批发市场里做“餐饮配送”的档口**
- 找那种明确给餐厅、奶茶店、食堂送货的档口，不要找纯零售摊。
- 优点：价格比零售低，能每天送，缺货可临时补。
- 谈的时候重点确认：起送量、送货时间、坏果怎么赔、能不能固定品项和规格。
- 适合：每天用量少但品类固定，比如苹果、橙子、柠檬、西瓜等。

**2. 次选：本地生鲜配送平台/食材B2B平台**
- 适合小店，省心在于线上下单、次日达、有售后。
- 缺点：价格可能略高，小批量起送和配送费要算清楚。
- 重点看：是否支持小额起送、缺货替换规则、售后拍照赔付是否爽快。

**3. 备选：附近水果店长期合作**
- 适合每天只要几斤、十几斤的店。
- 找离店近、经营稳定的水果店，谈固定配送或每天顺路送。
- 优点是灵活、沟通快；缺点是价格和品质稳定性不如批发档口。

**不建议一开始找：**
- 大型产地直供：量太小，别人不重视。
- 多个渠道分散买：看似灵活，实际每天比价、催货、处理坏果最费心。
- 只按低价选：水果损耗和断供会抵消差价。

**最省心的合作方式：**
固定1家主供应商 + 1家备用。跟主供应商约定：
- 每天固定时间送；
- 固定品项和大致数量；
- 坏果/烂果按比例赔付或下次补；
- 临时加单截止时间；
- 缺货提前通知，不擅自换品。

**判断供应商是否靠谱，看4点：**
1. 能不能稳定每天送小量；
2. 坏果赔付爽不爽快；
3. 缺货会不会提前说；
4. 送货时间是否固定。

如果你们店每天用量很小，比如5—10斤以内，优先找**附近水果店长期送**；如果每天十几斤以上且品类多，优先找**本地批发市场做餐饮配送的档口**。
