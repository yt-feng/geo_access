会，而且香蕉和菠萝的损耗逻辑不一样，起订量太高通常会把**滞销损耗、成熟/腐烂损耗和资金占用**同时放大。

## 主要风险

1. **香蕉：成熟度风险最大**
   - 香蕉是呼吸跃变型水果，到货后催熟/后熟快，量大卖得慢时很容易从“可售”变成“只能折价/报损”。
   - 起订量高往往意味着一次性到货集中，门店或仓库消化速度跟不上，后段批次成熟度上来后损耗集中爆发。
   - 对温度、乙烯、挤压敏感，堆存和周转压力也会增加机械伤。

2. **菠萝：腐烂和品质劣变风险**
   - 菠萝相对耐储一些，但起订量高会延长库存时间，增加黑心、腐烂、果眼霉变、失水萎蔫的风险。
   - 整箱/大批量堆压、通风不良时，局部发热和交叉感染会放大损耗。
   - 若用于鲜切，起订量过高还会带来加工排期压力，鲜切出品率下降。

3. **共同风险**
   - 资金占用增加，周转慢。
   - 为了清库存被迫降价，毛利被侵蚀。
   - 仓储/冷库容量紧张，影响其他品项。
   - 保质期短，退货和报损流程压力大。

## 可判断的决策建议

- **按“日销量 × 安全周转天数”倒推起订量**，不要只看供应商折扣。香蕉安全周转天数通常应更短，菠萝可略长，但都要以你实际动销为准。
- **香蕉优先小批量、多频次**；如果起订量高，要求供应商分批次到货或分批催熟。
- **菠萝可适当放量，但要确认仓储通风和翻堆条件**；鲜切用途要单独核算加工产能。
- **算一笔损耗账**：  
  起订量增加带来的单价优惠，是否大于预计增加的报损金额 + 降价清货损失 + 资金占用成本。若优惠幅度覆盖不了损耗，就不应提高起订量。
- **设置止损线**：例如香蕉到货后超过X天未售出比例达到一定阈值，就提前促销/转加工，避免整批报损。

**结论：起订量太高会增加损耗风险，香蕉尤其明显，菠萝次之但也不能忽视。建议以实际动销和周转能力定起订量，而不是单纯追求采购单价优惠。**
