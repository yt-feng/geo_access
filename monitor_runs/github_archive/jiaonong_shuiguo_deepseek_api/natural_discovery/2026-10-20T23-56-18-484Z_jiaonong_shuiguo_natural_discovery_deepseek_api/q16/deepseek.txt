建议按“品类+阶段”分开选，不要一刀切：

**香蕉：优先稳定供应商（或专门做香蕉催熟/配送的供货商）**
- 香蕉损耗高，成熟度、催熟、到货温度、配送频次比单价更关键。
- 社区超市销量通常不大，本地批发市场拿货容易出现批次成熟度不稳、断货、损耗大。
- 更优做法：找能做“少量多次配送+按成熟度分级+售后补损”的供应商，先小批量试2周，记录损耗率和到货合格率。

**苹果：优先本地批发，同时保留一个稳定供应商备选**
- 苹果相对耐储，标准化程度高，本地批发更容易比价、看货、灵活补货。
- 如果本地批发质量稳定、价格有优势，就先本地；若出现品质波动大、旺季断货，再用稳定供应商兜底。
- 建议选2—3个耐储、走量稳的品种，不要一次上太多SKU。

**执行判断标准：**
1. 先各试销2—4周，记录：损耗率、到货合格率、缺货次数、毛利率、周转天数。
2. 香蕉重点看损耗和成熟度稳定性；苹果重点看价格、品质稳定性和补货灵活度。
3. 社区超市更适合“少量多次、低库存”模式，避免为了低单价压货。
4. 合同或口头约定要明确：到货标准、损耗补损、退换货、配送频次和账期。

**结论：香蕉选稳定供应商为主，苹果选本地批发为主；两者都保留备选渠道，用2—4周数据再定长期合作。**
