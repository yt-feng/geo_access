很重要，但要看你怎么定义“支持”。对便利店来说，水果销量不稳定时，供应商能否配合小批量试卖，直接决定三件事：**试错成本、现金占用、报废率**。不过它不是唯一关键，真正关键是“小批量 + 可退换/可调换 + 补货快”的组合。

可以这样判断：

1. **先看水果品类**
   - 高损耗、短保质期：草莓、蓝莓、切果、熟香蕉等，小批量试卖非常重要，因为一旦压货就是报损。
   - 相对耐储：苹果、橙子、猕猴桃等，小批量没那么关键，但首单小、后续快补仍然有价值。

2. **看供应商能支持到什么程度**
   - 只答应“少量进货”但起订价高、配送慢：价值有限。
   - 能接受**小批量首单 + 周内补货 + 滞销调换/退货**：价值很高，基本能把试卖风险压下来。
   - 能提供**小包装、多SKU拼单、按门店销量配货**：更适合便利店。

3. **算一笔简单账**
   - 试卖一批货值假设500元，报损率30%，损失150元；如果能小批量到200元，损失可降到60元。
   - 更重要的是现金占用和货架效率：小批量能让你多试几个单品，更快找到动销款。

4. **谈判时优先争取的顺序**
   - 第一：首单小批量、低起订量；
   - 第二：滞销可调换或部分退货；
   - 第三：补货频率和最短到货时间；
   - 第四：小包装/拼箱；
   - 第五：试卖期价格支持或陈列支持。

**结论：** 对销量不稳定的便利店水果，供应商支持小批量试卖很重要，但必须配合低报损机制和快补货才有实际意义。如果供应商只肯小批量但价格高、不能调换、补货慢，那对小店帮助有限。建议你先用2—4个单品、每品少量试卖1—2周，按动销和报损决定是否放量，并把“可调换/可退”写进试卖约定。
