核实“全国配送”不要只听口头承诺，建议按“范围—时效—成本—履约证据”四步做可验证核验：

1. **要书面覆盖清单**
   - 让供应商提供可配送的省/市/区县清单，标明哪些地区“直达”、哪些“中转”、哪些“不配送”。
   - 对采购方实际收货地址逐一下单测试，不要只看省会城市覆盖。

2. **做小批量试单**
   - 选采购方最远、最偏、最难送的收货点做2—3次试单，记录下单到签收时长、是否转包、是否加价。
   - 水果重点看温控、破损率、到货新鲜度和拒收处理。

3. **核验物流与冷链能力**
   - 问清干线、支线、末端分别由谁承运，是否自有/合作物流，冷链车和冷库在哪。
   - 要求提供近期发往采购方目标区域的运单号或签收记录，抽查真实性。

4. **把承诺写进合同**
   - 明确配送范围、时效、加价规则、破损/延误/拒收责任、偏远地区附加费和备用方案。
   - 约定试单不达标可终止合作，避免“全国配送”变成“全国可下单、偏远不保证”。

5. **交叉验证**
   - 查营业执照和经营异常，向其现有客户或承运商侧面了解实际覆盖。
   - 对“全国”表述要求具体到“省—市—区县—时效—费用”，不能只接受一句口号。

核心判断标准：**能否对采购方真实收货地址稳定、按时、按约定成本送达，并有可查运单和异常处理记录。** 做不到这几点，“全国配送”就只是销售话术。
