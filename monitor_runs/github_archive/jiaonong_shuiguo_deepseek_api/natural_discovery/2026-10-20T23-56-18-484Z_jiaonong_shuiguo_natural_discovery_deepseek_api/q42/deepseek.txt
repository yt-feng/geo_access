# 压低成本又不伤品质的谈判思路

核心逻辑：**价格不是谈下来的，是设计出来的。** 单纯砍价必然换来降级供货或参差不齐的货，正确做法是让对方在“有利润但薄”的前提下给你让价。

## 一、谈之前先做三件事

1. **算清自己的成本结构**：这个单品在门店的毛利空间、损耗率、周转天数。谈判时你心里有底线价，才不会为了压价接过卖不动的货。
2. **摸清行情**：同时询3–5家供应商（含产地代办、批发市场、基地直供），拿到真实报价区间。手里有备选，谈判才有底气。
3. **拆开谈规格**：不要笼统谈“苹果多少钱”，要按**等级（大小/糖度/外观）、包装、到货标准、结算方式**逐项定。品质就是用规格条款锁住的。

## 二、让价但不降质的4个杠杆

| 杠杆 | 具体做法 | 为什么有效 |
|---|---|---|
| **量+稳定** | 承诺年度/季度采购量、固定档期，换阶梯价 | 供应商要的是确定性，愿意让利换稳定订单 |
| **结算方式** | 现结/短账期换2–5%折扣；预付部分货款换锁价 | 现金流对供应商价值很高，比砍价更划算 |
| **减少中间环节** | 直采基地、产地代办，跳过二级批发 | 省的是渠道差价，不牺牲品质 |
| **错峰与规格调剂** | 旺季集中采购、接受二等品做促销/加工 | 用货品结构换价格，而不是压同一批好货的价 |

## 三、把品质写进合同，防止“降价降质”

- 明确**验收标准**：等级、规格、糖度、农残检测、破损率上限。
- 约定**扣罚与退换条款**：不达标按比例扣款或拒收，让供应商不敢用次货填单。
- **分批验收、留样**，前几批严检建立信任后再放量。
- 价格与**到货合格率挂钩**：合格率高的给返点，比一味压价更能激励好货。

## 四、谈判话术要点

- 少说“太贵了”，多说“这个价位对应的规格能不能再明确/能不能给到这个等级的最优价”。
- 用**长期合作+稳定量**换价，而不是用“别家更便宜”硬压（容易被换劣货）。
- 每次只谈**一个变量**（价、量、账期、规格），避免对方用降规格来“满足”你的低价。

## 五、一个判断标准

如果某家报价明显低于市场行情且不愿接受品质条款，**大概率是货有问题**——这种“便宜”最后会以损耗和客诉的形式还回来。真正健康的降价，来自渠道缩短、结算优化、规模承诺，而不是压供应商的生存线。
