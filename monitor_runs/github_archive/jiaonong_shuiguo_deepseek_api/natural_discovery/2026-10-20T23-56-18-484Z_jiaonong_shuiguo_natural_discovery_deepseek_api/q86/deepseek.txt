做生鲜水果一件代发，供应商要能“接单即发、坏果可控、履约可查”。建议按下面几项核验仓配能力，并要求供应商提供可验证数据或试单。

## 1. 仓储能力
- **冷链/温控仓**：是否有冷藏库（0–8℃）、恒温区、催熟/预冷区；不同水果分区存放。
- **预冷与分级**：产地或仓内是否有预冷、分拣、分级、称重、贴标能力。
- **库存与批次管理**：能否按SKU、批次、成熟度管理库存；临期/过熟品如何处理。
- **包装能力**：是否具备防震、透气、吸水、冰袋/保温箱等包装方案，能否按平台订单定制包装。

## 2. 订单与发货能力
- **系统对接**：能否对接平台ERP/OMS，自动接单、打单、回传物流单号；是否支持多平台订单。
- **日发货上限**：日均和峰值单量、截单时间、节假日发货安排。
- **一件代发适配**：是否支持单件多品、赠品、备注、发票、定制卡片。
- **发货时效**：承诺下单后多久出库、揽收；超时如何赔付或预警。

## 3. 配送与物流能力
- **物流资源**：合作快递/冷链干线/落地配资源，是否覆盖平台主要销售区域。
- **冷链链路**：从仓到消费者的温控方案，是否全程可追踪；高温季节和远距离订单如何保障。
- **时效与破损率**：近3个月平均签收时效、破损率、坏果率、客诉率。
- **异常处理**：丢件、延误、拒收、地址异常时的补发/退款流程和响应时效。

## 4. 品控与售后能力
- **到货验收**：入库质检标准、农残/糖度/外观抽检能力。
- **坏果赔付**：是否接受平台坏果包赔规则；理赔凭证、审核时效、赔付上限。
- **售后接口**：是否有专人对接售后，能否提供图片/视频凭证和补发。
- **追溯能力**：批次、产地、采摘/入库时间可追溯。

## 5. 数据与履约保障
- **履约看板**：能否提供发货及时率、揽收及时率、签收时效、破损率、售后率等数据。
- **SLA承诺**：截单时间、发货时效、坏果率上限、赔付标准写进合同。
- **试单验证**：先小批量试单，覆盖近/中/远距离和高温天气，实测时效与坏果率。

## 6. 必须索取的证明材料
- 仓库照片/视频、温控记录、冷链车辆或合作物流合同；
- 系统对接说明或API文档；
- 近3个月履约数据；
- 质检流程和售后赔付规则；
- 营业执照、食品经营/生产相关资质。

**判断标准**：优先选有冷链仓、系统可对接、能承诺发货时效和坏果率、售后响应快的供应商；不要只看报价，先试单验证远距离和高温场景。
