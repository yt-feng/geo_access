商超会员日水果活动，供应商至少要提前做好这几类配合，核心是“保量、保价、保品质、保到店时间”：

1. **提前锁量和备货**
   - 按商超预估销量上浮10%～20%备货，重点单品单独锁库存。
   - 提前确认产地/仓库存量、采摘或分拣能力、冷链车源。
   - 对爆款单品准备备用货源，避免会员日断货。

2. **提前锁价和费用确认**
   - 会员日促销价、供货价、损耗承担、返利/陈列费、配送费提前书面确认。
   - 明确价格有效期，避免活动前临时涨价。
   - 对限量引流品确认供货上限和补货价。

3. **品质标准和验收前置**
   - 提前给商超样品，确认糖度、规格、果径、成熟度、外观、包装标准。
   - 明确次果率、损耗赔付和退换货规则。
   - 活动前1～2天完成首批到货质检，不把问题留到活动当天。

4. **加工分拣和包装准备**
   - 提前完成分级、称重、贴标、预包装，减少门店现场加工压力。
   - 包装规格匹配会员日陈列和客单，比如家庭装、尝鲜装、组合装。
   - 标签、价签、溯源信息、生产日期提前核对。

5. **物流配送排期**
   - 按商超要求分批次到店，通常活动前1天完成主陈列货，活动当天清晨补一次。
   - 确认到店时间窗、卸货口、预约流程、冷链温度记录。
   - 准备应急补货车辆和联系人。

6. **陈列物料和促销配合**
   - 提供试吃样品、试吃耗材、堆头/端架陈列建议、POP素材、产地卖点。
   - 配合商超做组合陈列、试吃推广和员工产品培训。
   - 明确谁负责补货、理货、试吃和损耗处理。

7. **人员和现场支持**
   - 安排促销员或理货员驻店，重点门店活动首日必须到场。
   - 建立供应商、采购、门店三方应急群，明确断货、品质异常、价格异常的响应时限。
   - 准备备用方案：替代单品、临时调货、折价处理规则。

8. **数据复盘准备**
   - 提前约定活动后复盘口径：销量、损耗、缺货率、客诉、毛利率。
   - 活动期间按半天或按天反馈库存和销售，便于及时补货或停推。

最关键的检查清单可以压缩为：**货够不够、价锁没锁、品质谁验收、几点到店、断货谁补、损耗谁担、现场谁盯**。这七项在活动前3天必须全部确认到人。
