判断水果供应商的合规与稳定性，建议分“资质核验—现场与流程—供货能力—合同约束—试供评估”五个环节，不要只看报价和样品。

**一、合规资质先核验**
1. 营业执照经营范围包含食用农产品/食品销售；若涉及预包装或切配水果，应有食品经营许可证。
2. 要求提供近批次水果的农残检测报告或承诺书；能提供产地证明、进货凭证、合格证明更稳。
3. 查验送货人员健康证（尤其接触直接入口水果时）、运输车辆卫生情况。
4. 通过国家企业信用信息公示系统查经营异常、行政处罚、严重违法失信记录；有食品安全处罚的要重点评估。
5. 发票、对公账户、合同主体三者一致，避免个人账户收款。

**二、现场与流程看管理**
1. 有条件实地看分拣/仓储场所：是否分区、防鼠防虫、冷藏条件、先进先出。
2. 问清退货和召回流程：农残超标、腐烂、短斤少两如何处理，多久补货。
3. 看索证索票是否规范：每批能否追溯到产地/批发市场，票据是否随货。

**三、稳定性看供货能力**
1. 要求说明主要产地、备选产地和旺季淡季供应方案；单一产地依赖风险高。
2. 问清日/周供应量上限、配送车辆数、配送时间窗，能否满足食堂开餐前到货。
3. 查其服务过的同类客户（医院、养老院、学校食堂），可要求提供合作证明或回访。
4. 关注价格波动机制：是否随行就市、有无锁价周期，避免低价中标后断供或降质。

**四、合同里写死关键条款**
1. 品名、规格、等级、单价、数量、配送频次、到货时间。
2. 质量标准：新鲜度、成熟度、农残合格、无腐烂霉变；验收标准和抽检比例。
3. 退换货时限、缺货违约金、连续缺货或质量不合格的解除权。
4. 食品安全责任：因供应商原因造成食安事故的赔偿与追责。
5. 结算周期、发票类型、对公账户；禁止转包或随意更换产地需报备。

**五、先试供再定长期**
建议先小批量试供2—4周，按批次记录：到货准时率、验收合格率、腐烂率、重量偏差、退换响应时间、价格稳定性。设定量化门槛，例如准时率≥95%、验收合格率≥98%、退换4小时内响应，再签长期合同。同时保留2家备选供应商，避免单一依赖。

对养老院/医院这类高风险场景，优先选有同类食堂服务经验、能提供每批检测凭证、接受高频抽检和违约条款的供应商；价格明显低于市场且资质材料不全的，不建议采用。
