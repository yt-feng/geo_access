采购香蕉做茶饮或甜品，不能按水果店“即买即吃”的思路来，要按**使用场景 + 到货时间 + 后熟节奏**分层采购。给你一套可直接执行的判断标准。

## 1. 先按用途定熟度

| 用途 | 推荐熟度 | 外观/手感 | 原因 |
|---|---|---|---|
| 香蕉奶昔、冰沙、果泥 | 7～8成熟到全熟 | 通体黄、少量芝麻黑点、按压微软 | 甜度高、易打泥、香气足 |
| 香蕉果肉装饰、切片 | 6～7成熟 | 黄色、两端略青、手感偏硬 | 不易氧化发黑、切片成形好 |
| 烤香蕉、焦糖香蕉 | 7成熟左右 | 黄皮、无明显黑斑、稍硬 | 加热后不易烂 |
| 香蕉磅蛋糕、玛芬、香蕉面包 | 9成熟～过熟 | 表皮大面积黑斑、果肉软 | 甜度和香气最足，适合捣泥 |
| 香蕉布丁、慕斯夹层 | 8～9成熟 | 黄皮带斑、软但不流水 | 香气够且不出水太多 |

**核心原则：**
- 当天打泥/做奶昔：用**8成熟左右**。
- 做蛋糕/烘焙：专门采购**过熟香蕉**，不要和装饰用混。
- 做装饰：用**偏生一点**的，避免出品前就发黑。

## 2. 采购时的验收标准

到货时逐箱抽检，不要只看最上面一层。

**合格判断：**
- 果指饱满，棱角不明显。
- 黄皮带少量“芝麻点”可用于当天打泥。
- 两端无明显青绿、无大面积黑腐。
- 果柄完整，无霉斑。
- 按压有弹性，不是硬邦邦，也不是一按一个坑。

**拒收或降级：**
- 整箱青硬：不能当天用，只能算后熟库存。
- 大面积黑斑且果肉流水：只适合立刻做烘焙泥，不能做装饰。
- 表皮破损、发霉、酸味：直接拒收。
- 冷链运输后表面结露严重：容易快速黑变，要单独存放。

## 3. 采购节奏：少量多次 + 分批后熟

香蕉是呼吸跃变型水果，到店后会继续成熟，不要一次囤太多。

建议：
- **每天用量的 1～2 天量**：买8成熟，直接可用。
- **3～5 天用量**：买6～7成熟，店内自然后熟。
- **烘焙专用**：单独采购过熟香蕉，或把外观不佳但未腐败的香蕉熟成后冷冻果泥。

如果门店日均用量稳定，按“**今日用、明日熟、后日备**”三批滚动采购最稳。

## 4. 店内熟度管理

- 青香蕉：常温、避光、通风，不要进冰箱。
- 7～8成熟：常温存放，每天翻箱，避免压伤。
- 已到使用熟度：优先使用，必要时冷藏延缓1天，但冷藏后表皮会黑，不影响果肉。
- 过熟香蕉：去皮、切段、真空或密封冷冻，做烘焙泥/奶昔，标注日期，建议3～5天内用完。
- 不要和苹果、梨等释放乙烯的水果混放，除非你想加速后熟。

## 5. 给采购单的可执行写法

可以直接这样下单和验收：

> 香蕉分两批：A批7～8成熟，黄皮带少量芝麻点，用于当天奶昔和果泥；B批6～7成熟，黄色两端略青，用于3～5天周转。另采购少量9成熟黑斑香蕉专用于烘焙。到货抽检底层，青硬、破损、发霉、流水的一律拒收或降级。

**一句话总结：装饰用偏生，打泥用8成熟，烘焙用黑斑过熟；采购按1～2天可用量 + 3～5天后熟量分批滚动，不要整批同熟度。**
