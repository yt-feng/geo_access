节假日水果需求暴增，锁货源的核心是**把“临时抢货”变成“提前锁量、锁价、锁品质、锁运力”**。建议按下面执行，越早启动越好，节前一般至少提前3—4周进入锁定动作，进口或反季节单品提前6—8周。

**1. 先做需求预测，不要凭感觉订货**
- 拉出近2—3年同节假日、同门店、同品类的销量，按门店分级：社区店、商圈店、大店分别给系数。
- 重点单品单独预测：礼盒果、车厘子/草莓/阳光玫瑰等高客单，以及苹果、橙子、香蕉、西瓜等走量品。
- 设定“基础量+安全库存+应急量”。安全库存一般按节日高峰日销的1.5—2天备，易腐品压缩到1天以内。
- 输出一张《节日锁货清单》：品名、规格、预计销量、锁货比例、最晚到货日、替代品。

**2. 分级锁定供应商，不把鸡蛋放一个篮子**
- 核心走量品：与2—3家主力供应商签节日保供协议，锁定60%—70%需求量，留30%—40%机动。
- 高客单礼盒/稀缺品：提前锁定产地或一级批发商，支付定金锁货，约定规格、糖度、果径、包装和赔付标准。
- 每个重点品类准备1—2个备用供应商，避免单一产地天气、物流或涨价断供。
- 优先选择有冷库、分选能力和稳定车队的一级供应商，减少中间环节。

**3. 合同里必须写清楚“锁什么”**
- 锁数量：约定节日期间最低供货量和每日到货节奏。
- 锁价格：约定价格浮动区间或固定价+运费分离，避免节前坐地起价。
- 锁品质：写明果径、糖度、成熟度、损耗率上限、包装标准。
- 锁运力：明确到货时间、卸货门店、冷链要求、延误赔付。
- 锁违约：断供、迟到、品质不达标要有罚则和替代方案。

**4. 用“订单+定金+分批到货”锁定**
- 提前下节日框架订单，支付10%—30%定金锁货源，尾款按到货验收结算。
- 采用分批到货：节前3天集中到主量，节中每日补货，避免一次性压库造成损耗。
- 对易腐高频品如草莓、荔枝、葡萄，要求供应商按日配送，超市保留调量权。

**5. 提前锁物流和仓储**
- 节假日最难的不只是货，还有车。提前锁定冷链车、城配车辆和装卸工。
- 大店提前腾出冷库和堆头位置，礼盒类提前完成预包装。
- 设置区域分仓或中转仓，节前把耐储品前置到离门店更近的仓。

**6. 建立节日应急机制**
- 每日跟踪销量、库存、到货和损耗，达到阈值立即触发补单。
- 准备替代品清单：某单品断供时，用同价位、同用途水果替换，礼盒可调整组合。
- 与本地批发市场保持2—3家现货渠道，作为最后兜底，但只用于补缺口，不承担主量。

**7. 节前执行时间表**
- 节前6—8周：完成需求预测，接触产地/一级供应商，锁稀缺品。
- 节前4周：签保供协议，下框架订单，付定金，锁冷链运力。
- 节前2周：确认分批到货计划，完成礼盒包装和堆头陈列。
- 节前1周：每日跟进产地天气、价格和到货，启动应急库存。
- 节日期间：日销日清，动态补单，控制损耗。

一句话：**主量靠协议锁，稀缺靠定金锁，运力靠提前锁，缺口靠备用渠道补。** 重点不是订得越多越好，而是锁住60%—70%的确定量，保留30%—40%的灵活量。
