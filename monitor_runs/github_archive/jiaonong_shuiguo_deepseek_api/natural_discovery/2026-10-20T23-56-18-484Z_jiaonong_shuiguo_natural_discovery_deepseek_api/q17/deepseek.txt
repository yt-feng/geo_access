# 社区超市水果新鲜度与库存控制

核心思路：**水果不是“卖完再补”，而是“按天周转、按品质定价、按损耗止损”**。下面按可落地的动作说。

## 一、订货：用数据定“订多少”，不要凭感觉

1. **按周转天数订货，不按销量订货**
   - 叶菜类、草莓、葡萄、桃：目标周转 ≤1 天
   - 苹果、梨、橙、香蕉：1.5~2 天
   - 库存上限 = 日均销量 × 目标周转天数，超过就砍单。

2. **每天固定时段盘点+看销量**
   - 建议早上开门前盘一次、晚上闭店前盘一次，记录“昨日销量、剩余量、损耗量”。
   - 连续记 2~3 周，就能算出每个单品的日均真实销量（含损耗），订货按这个数的 80%~90% 下，留出波动余地。

3. **小批量、多频次**
   - 社区店客流有限，宁可每天订、两天订一次，也不要一次压三天货。热门单品可以隔天订，冷门单品一周两订。

## 二、收货：把不合格的挡在门口

- 到货当场抽检：看外观、摸硬度、闻气味，**烂果、软果、霉点当场挑出退货或折价**，不要收进来再处理。
- 按单品设一个“最低可接受成熟度”，比如香蕉到货要偏青，桃要偏硬，给货架期留时间。
- 收货后立刻拆箱透气，**不要带原箱闷着**，尤其草莓、葡萄、桃。

## 三、陈列与保鲜：让“先进先出”真正执行

1. **少量多补**：货架每次只摆半天的量，卖完再补，减少顾客翻拣造成的损伤。
2. **先进先出**：新货放后排/下层，旧货放前排，每天理一次货。
3. **分区存放**：
   - 香蕉、芒果、木瓜等热带水果**不进冷柜**，常温阴凉；
   - 草莓、葡萄、桃、叶菜进冷藏，但注意别和释放乙烯的水果（苹果、香蕉）混放，会催熟。
4. **及时挑拣**：每天早晚各挑一次软果、碰伤果，挑出来立刻转“特价区”，别留在正价区拖累整体。

## 四、定价与止损：用价格换周转

- **临界品提前降价**，不要等坏了再降。比如桃到第二天下午还硬，就做“第二件半价”或组合装；香蕉出现芝麻点就转“熟香蕉特价”。
- 设**每日损耗上限**（比如销售额的 3%~5%），超了就说明订货或陈列有问题，第二天减量。
- 临期品可以做**果切、拼盘、果汁**（如果条件允许），把损耗转成毛利，但要注意卫生和当日售完。

## 五、几个关键指标，每天看一眼

| 指标 | 怎么看 | 目标 |
|---|---|---|
| 单品周转天数 | 库存÷日均销量 | 叶菜/浆果≤1天，耐储≤2天 |
| 损耗率 | 损耗金额÷进货金额 | 控制在 5% 以内 |
| 缺货率 | 断货单品数÷在售单品数 | 热门单品尽量不断 |
| 特价区占比 | 特价销售额÷水果总销售额 | 10%~20%，太高说明订货偏多 |

## 六、最简单的起步动作

如果现在还没数据，先做三件事：
1. **连续 7 天记录每个单品的销量和剩余**；
2. **订货量先砍 20%**，宁缺勿压，观察一周再调；
3. **每天闭店前把软果挑出来，第二天一早做特价**，形成固定动作。

坚持两周，你就能看出哪些单品是“真畅销”、哪些是“压货王”，然后按单品调整订货频率和量。核心就一句：**水果的钱是周转出来的，不是囤出来的。**
