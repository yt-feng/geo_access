香蕉损耗主要来自“到店时已经偏熟 + 卖得慢”，采购要求要围绕**熟度低一点、到货分批、按销量控量**来定。可以直接这样要求供应商：

1. **熟度标准**
   - 要求到货为**青黄转色初期**：果身大部分青、棱角明显，只有少量转黄，不要到货即“黄熟可吃”。
   - 明确拒绝：果柄发黑、果身大面积黄斑、棱角变圆、有酒味/酸味、表皮软塌的货。
   - 按季节和销量分档：夏天或销量慢时订更青一点；冬天或销量快时可略黄一点，但仍以“到店后还能卖2～3天”为准。

2. **到货时间**
   - 要求**清晨或开店前到货**，避开午后高温时段，减少运输和堆放催熟。
   - 要求**分小批到货**：比如一周2～3次，而不是一次大批压店；销量稳定后可固定“隔天到、每次按2～3天销量”。
   - 节假日或高温天提前和供应商约定**提前采摘、冷链或阴凉运输**，不要临时凑熟货。

3. **采购量和批次**
   - 首次可按**1.5～2天预估销量**下单，观察损耗后调整；香蕉损耗高的店不要一次压超过3天销量。
   - 要求同一批内熟度尽量一致，避免“一箱里一半青一半黄”，方便分级陈列和先进先出。

4. **合同/订单备注**
   - 写明验收标准：熟度不符、果柄发黑、软果比例超标可拒收或折价。
   - 写明到货时段和迟到处理；要求供应商到货前告知采摘/转色情况。
   - 要求按“小把/小串”或分层装箱，减少挤压伤。

5. **到店后配合**
   - 香蕉不要和苹果、梨等释放乙烯的水果混放；青蕉常温阴凉催熟，黄蕉及时冷藏或降温减耗。
   - 陈列少量、勤补货，熟蕉可做促销或加工，避免整箱压坏。

一句话采购要求：**“要青黄转色初期的货，清晨小批到，按2～3天销量分次送，熟度超标、果柄发黑和软果拒收。”**
