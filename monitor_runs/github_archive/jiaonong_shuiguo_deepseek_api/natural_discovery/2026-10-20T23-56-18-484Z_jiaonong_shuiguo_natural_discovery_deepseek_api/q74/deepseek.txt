批发档口拓展餐饮客户，菠萝和香蕉的核心是**稳定、可切配、出成率高、损耗可控**。规格建议按餐饮用途分层准备，不要只备一个统货。

**菠萝建议准备：**
1. **鲜切/果盘店用**：单果1.2–1.5斤，成熟度7–8成，果眼浅、果芯小，适合现削现切。
2. **餐饮后厨/饮品店用**：单果1.5–2斤，7成熟左右，便于运输和催熟，适合做菠萝炒饭、咕咾肉、果汁。
3. **烘焙/中央厨房用**：可备去皮菠萝块或菠萝丁，规格1–2cm丁、3–5cm块，冷冻或真空包装，减少后厨人工。
4. **高端餐饮/自助餐用**：单果2斤以上，外观周正，成熟度8成，做展示和鲜切。

**香蕉建议准备：**
1. **饮品店/甜品店用**：单根120–150g，7–8成熟，果指均匀，适合现剥打泥、做奶昔。
2. **餐饮果盘/自助餐用**：单根150–180g，8成熟，果皮无大面积黑斑，到店后1–2天可用。
3. **烘焙/中央厨房用**：可备冷冻香蕉泥或去皮香蕉段，按需分装，减少熟度波动和损耗。
4. **快餐/茶饮连锁用**：优先固定单根重量区间和到货成熟度，比如“每箱净重、每把根数、到货7.5成熟”，比只报“大果/中果”更容易成交。

**拓展餐饮客户的实操建议：**
- 先问客户用途：鲜切、热菜、饮品、烘焙，规格完全不同。
- 给餐饮客户报**到货成熟度、单果/单根重量区间、箱规、次果率、可退换标准**，比报产地更重要。
- 初期可做“菠萝+香蕉”组合试样包：菠萝按7成熟和8成熟各半，香蕉按7成熟和8成熟分两批，让后厨实际测出成率和损耗。
- 餐饮客户最在意**稳定供货和损耗**，建议固定每周供货频次，并保留1–2个替代规格，避免断货。
