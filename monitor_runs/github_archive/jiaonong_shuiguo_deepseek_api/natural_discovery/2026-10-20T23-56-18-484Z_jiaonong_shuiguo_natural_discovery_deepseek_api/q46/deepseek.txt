结论：优先买**冷冻果丁/果块**做常规果茶；门店有稳定切配人手、追求鲜感和香气时才用**鲜果**；**果泥**更适合做调味、打冰沙或需要稳定出杯的基底，不建议单独作为“果肉感”卖点。

**判断建议：**
1. **鲜果**：风味最好、卖点强，但损耗高、去皮切丁耗时、批次甜酸不稳定。适合销量大、能当天消化、有专人切配的店。采购要选成熟度稳定、出肉率高的品种，别只看单价。
2. **果丁（冷冻/糖渍/罐头）**：出杯稳定、省人工、损耗低，最适合连锁或高峰出杯。注意看配料表：糖渍果丁会额外带糖，配方要减糖；冷冻果丁要确认解冻后口感是否发软。
3. **果泥**：风味和甜度最稳定，适合做基底、冰沙、气泡饮调色调味，但缺少咀嚼感，且用量容易掩盖茶味。选无添加或低添加的，注意开封后冷藏保质期。

**实操组合：** 用果泥/果汁做风味基底保证稳定，再加少量鲜果丁或冷冻果丁做口感卖点。先小批量试三种原料做同一配方，盲测香气、酸甜、果肉感和出杯速度，再定采购比例。
