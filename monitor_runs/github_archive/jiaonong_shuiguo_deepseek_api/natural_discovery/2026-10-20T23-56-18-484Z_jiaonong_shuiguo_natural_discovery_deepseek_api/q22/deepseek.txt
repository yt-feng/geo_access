可以按“高频带低频、整件拉客单”的思路组合，不要只做单品打折。

**1. 主推组合：香蕉+苹果“每日果盘包”**
- 内容：香蕉1把 + 苹果3—4个，装透明袋/网袋。
- 定价：组合价略低于单买合计，但让顾客感觉“够一周早餐/果盘”。
- 目标：香蕉是高频引流品，苹果是耐储刚需品，组合后容易从“买一把香蕉”变成“买一袋水果”。
- 陈列：放在入口或称重台旁，标“早餐果盘组合”“办公室分享装”。

**2. 高客单组合：菠萝+苹果“家庭果切/待客装”**
- 内容：整只菠萝 + 苹果4—6个，或预切菠萝盒+苹果。
- 定价：做两个档位，小份组合价、家庭装更高客单。
- 话术：突出“待客、饭后水果、周末家庭装”。
- 注意：菠萝客单高但处理麻烦，可提供免费削皮/切块服务，作为组合增值点。

**3. 阶梯促销：满额升级**
- 买香蕉+苹果组合，加9.9元换购小菠萝/菠萝切盒。
- 或“水果组合满39元送削菠萝服务/送保鲜袋”。
- 目的：不直接降主品价格，用换购和服务拉高客单。

**4. 动态清货组合**
- 熟香蕉+菠萝切盒做“今日鲜果盒”，限时价，放在收银台。
- 苹果做耐储基础款，不参与过度打折，避免伤价格带。

**执行建议：**
- 组合不超过2—3个，避免顾客选择困难。
- 标价签写清“单买合计X元，组合价Y元”，让优惠可判断。
- 香蕉按成熟度分“即食/两天后食”，减少损耗。
- 每周看组合销量、客单价、损耗率，保留销量最好的1个组合，淘汰弱的。

优先落地：**香蕉+苹果早餐袋**做主引流组合，**菠萝+苹果家庭装**做高客单组合，再用“加价换购菠萝切盒”提客单。
