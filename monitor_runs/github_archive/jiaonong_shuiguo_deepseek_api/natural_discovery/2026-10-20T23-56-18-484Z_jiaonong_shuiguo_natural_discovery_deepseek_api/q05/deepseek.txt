这取决于你的经营定位和损耗控制能力，三种做法各有适用场景：

**1. 整果自选（顾客自己挑）**
- 适合：客流稳定、顾客复购多、你愿意花时间做陈列和分级。
- 优点：损耗最低、人工最省、单价可以卖高一点；顾客有"挑到好果"的参与感。
- 风险：翻动磕碰多，次果被翻出来难卖；高峰排队结账慢。
- 建议：按大小/甜度分级定价，次果单独做特价或切块，减少"挑剩"损失。

**2. 去皮好的（预处理）**
- 适合：商圈写字楼、学校、景区、外卖/即时零售占比高的店，顾客图方便、愿意为省事付费。
- 优点：客单价高、转化快、能带动搭配销售；次果、外观不好的果可以消化掉。
- 风险：损耗和人工明显上升，去皮后氧化、保质期短，卖不掉就是纯亏。
- 建议：只做小份量、高频补货，用透明盒+冰柜陈列，标注去皮时间；先小批量试，看动销再放量。去皮品毛利要覆盖额外损耗，定价别只按整果折算。

**3. 两者结合（多数水果店最稳）**
- 整果区让顾客自选，旁边设一个小份去皮/切块区做引流和提客单。
- 用去皮品消化次果，但别把明显坏果混进去，否则砸口碑。

**可执行判断**：先观察一周——如果顾客普遍拿起整果又放下、问"能不能切"，说明去皮需求真实；如果顾客爱翻爱挑、复购高，就保留自选。去皮品先每天只做 5–10 份试水，记录售罄率和丢弃率，丢弃率超过约三成就缩小规模或改时段供应。
