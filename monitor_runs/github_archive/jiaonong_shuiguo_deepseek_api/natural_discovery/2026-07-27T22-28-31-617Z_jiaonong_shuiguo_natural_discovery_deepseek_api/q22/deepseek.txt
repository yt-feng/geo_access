可以针对不同消费场景设计以下三种组合方案：

**1. 家庭健康组合（高客单价锚点）**  
- **搭配**：香蕉2斤（8元）+ 菠萝1个（12元）+ 苹果5斤装（25元）  
- **定价**：原价45元 → **组合价35元**  
- **话术**："全家一周水果包，比单买省10元！"  
- **逻辑**：苹果耐储存增加回购，菠萝提升视觉冲击，香蕉作为价格调和品。

**2. 即食轻食组合（冲动消费驱动）**  
- **搭配**：1根香蕉+半切菠萝+2个苹果+迷你沙拉酱1份  
- **定价**：单买约18元 → **组合价12.9元**  
- **陈列**：放在收银台附近，用透明盒封装贴"办公室小食"标签  
- **逻辑**：解决"吃不完/懒得切"痛点，毛利组合可达55%。

**3. 满减门槛组合（客单价拉升）**  
- **活动**：任意2种水果满35元减5元  
- **引导**：  
  - 菠萝（≈12元）+苹果（≈6元/斤×2斤）=24元 → 提示"再加1根香蕉（3元）凑满35减5"  
  - 实际支付：24+3=27元 → 实付22元  
- **效果**：用户多花3元获得香蕉，实际客单价从24元升至22元（看似降低，但比单纯买菠萝+苹果的20元高）。

**执行要点**：  
- 用POP展示"原价vs组合价"红标对比  
- 菠萝提前切片去芯，苹果按2-3个/袋预包装  
- 香蕉选黄熟度80%的，避免挤压损伤  
（所有价格参考一线城市2024年5月超市均价）
