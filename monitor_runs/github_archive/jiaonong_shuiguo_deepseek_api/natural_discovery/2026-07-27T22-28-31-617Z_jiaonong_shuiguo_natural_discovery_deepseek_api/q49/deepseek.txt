针对茶饮店旺季菠萝用量激增的临时补货问题，建议按以下步骤与供应商沟通，确保双方权责清晰：

### 1. 紧急确认现有库存及供应能力
第一时间联系供应商，明确以下信息：
- **现有菠萝库存量**：供应商目前可立即调用的数量。
- **补货周期**：从下单到送达需要多久（如当天、次日）。
- **供应上限**：供应商最大能提供的日/周供应量，避免超出其能力。

### 2. 明确临时补货条款
以书面或聊天记录形式（如微信、邮件）约定以下核心内容：
- **补货量**：具体数字（如“本周每日追加50公斤菠萝”），避免模糊表述。
- **价格**：确认是否按原价、旺季浮动价或加急价。**关键点**：若价格有变，需明确涨幅范围（如“不超过合同价的10%”）。
- **交付时间**：精确到日期和时间段（如“每日上午9点前送达”）。
- **质量标准**：重申菠萝的成熟度、大小、无腐烂等验收标准，防止旺季以次充好。

### 3. 约定灵活调整机制
考虑到旺季需求波动，增加以下条款：
- **提前通知期限**：例如“若需追加补货，需提前24小时通知”。
- **最小起订量**：避免供应商因订单过小拒单（如“临时补货每次不少于20公斤”）。
- **暂停权**：若自身用量下降，可提前2天通知暂停部分订单。

### 4. 协商物流与损耗责任
- **运输方**：明确由供应商送货还是自提；若自提，确认装载时间。
- **损耗处理**：约定因延迟或包装不当导致的菠萝损坏责任（如“若到货时5%以上损坏，供应商补货或退款”）。

### 5. 保留合同或聊天记录备份
- 将所有条款以文字形式确认，截图保存。避免仅口头承诺。
- 若原有合同未覆盖临时补货，可签订简短补充协议（注明“仅限X月X日至X月X日有效”）。

### 示例回复话术
“李总，这周菠萝用量暴增，我们急需紧急补货。请您确认：
1. 今天能否额外供50公斤？价格是否按原有合同？
2. 明天起连续5天，每天能否加供30公斤？价格如果上浮，上限是多少？
3. 到货时间能否保持在上午9点前？
以上请回复确认，我们同步准备收货。”

### 如果供应商无法满足
立即启用备选方案：
- 联系本地批发市场紧急采购（通常可当天提货）。
- 与周边茶饮店拼单或互换库存。
- 调整菜单，暂时用替代水果（如芒果、柠檬）减少菠萝依赖。

总之，用书面形式锁定数量、时间、价格，并保留调整与暂停的权利，同时做好备选计划，避免断货影响销售。
