水果店遇到坏果时，与供应商的结算或赔付方式通常取决于以下因素：合同约定、交易习惯、坏果比例、责任归属（运输中损坏还是到货后变质）。

通用处理流程和建议如下：

1. **及时拍照留证**：发现坏果后，第一时间拍摄清晰照片或视频，能看清坏果数量、品种、外观（如腐烂、压伤、发霉）以及包装箱上的生产日期、批次号等标识。

2. **确认责任环节**：
   - 如果是运输途中因挤压、碰撞或温度不当导致的损坏，通常由物流或运输方负责。
   - 如果是到货后存储不当（如未及时入冷库、混放导致催熟）导致的变质，则责任在水果店。
   - 如果到货时已明显变质或虫蛀，属于供应商发货质量问题，由供应商承担。

3. **按约定标准协商**：
   - **常见赔付比例**：
     - 坏果率低于5%时，很多供应商只补发相应数量或抵扣下次货款。
     - 坏果率5%~20%时，供应商应承担全部坏果的货款，或按实际坏果数量折扣退款。
     - 坏果率超过20%时，可要求整箱退货或整批重新调换。
     - 若整批严重腐烂（如超30%~50%），可直接要求全额退款并赔偿运费损失。
   - **如有合同**：严格按合同条款执行（比如“5%以内由买方承担，超出部分卖方承担”）。
   - **无约定时**：可参照行业惯例或《中华人民共和国民法典》第六百一十条关于质量不符的规定，要求修理、更换、退货或减少价款。

4. **谈判与结算操作**：
   - **明确沟通时间**：建议在收货24小时内（特殊易腐水果更短）反馈，避免被推诿为保管不当。
   - **协商方案**：
     - 退换货：供应商补发等量好果。
     - 抵扣货款：按坏果价值从应付账款中扣除。
     - 折扣结算：坏果率折算成折扣，按折后价付款。
   - **保留证据**：保留所有聊天记录、邮件、通话录音（注意合法性）、单据照片，必要时可联系批发市场管理方或当地消协介入。

5. **特殊情况处理**：
   - 反复出现高坏果率的供应商，应考虑更换并记录在案。
   - 如果是成熟度不均造成的“软果”（可变软但不腐烂），通常不算坏果，只是品质需协商。

**建议行动步骤**：
1. 立即统计坏果数量占总到货量的百分比。
2. 发送清晰证据给供应商负责人，同时提出你认为合理的处理方案（如“这批坏果约12%，请按12%折价或补款”）。
3. 如果供应商拖延或拒绝，可书面明确告知最后期限并保留追责权利。

最终结论：**依据具体坏果率、合同约定及责任归属，按比例折价、补货或全退是最常见的三种方式。无约定时，基于诚信原则和行业惯例（坏果率5%以下自行承担，5%以上由供应商承担）协商解决。**
