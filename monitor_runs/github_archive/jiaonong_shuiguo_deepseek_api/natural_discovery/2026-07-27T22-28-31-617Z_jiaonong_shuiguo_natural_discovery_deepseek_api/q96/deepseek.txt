企业食堂采购水果时，**食品安全是首要关注点**，其次是价格和配送准时性。以下是具体建议：

1. **食品安全（第一优先级）**  
   - 确保供应商有资质（如营业执照、食品经营许可证），水果来源可追溯（产地、采摘日期、农药残留检测等）。  
   - 检查水果新鲜度（无腐烂、虫蛀或异常色泽），避免因变质导致食物中毒。  
   - 要求供应商提供定期检测报告（如农残、重金属等指标）。  

2. **价格（第二优先级）**  
   - 在保障安全的前提下，通过比价（至少3家供应商）、批量采购或季节性采购降低单价。  
   - 注意：避免单纯追求低价而忽视水果品质，以免浪费或影响职工健康。  

3. **配送准时性（第三优先级）**  
   - 与供应商明确配送时间（如每日/每周固定时间），延迟可能导致水果损耗或影响食堂运营。  
   - 签订合同时约定违约条款（如延迟扣款、补偿）。  

**操作建议**：  
- 优先选择有长期合作经验、行业口碑好的供应商。  
- 建立“安全-价格-时效”的评分机制，定期综合评估供应商表现。  
- 如预算允许，可额外要求供应商提供“可退换货”服务（如水果到货后4小时内可退换）。
