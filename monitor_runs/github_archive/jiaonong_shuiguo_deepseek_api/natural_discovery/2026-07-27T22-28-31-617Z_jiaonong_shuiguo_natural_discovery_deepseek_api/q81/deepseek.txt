建议支持小批量高频补货。原因如下：

1. **适应即时零售特点**：即时零售平台用户对配送时效要求高（通常30-60分钟），订单波动大、单品批量小。小批量高频补货能更快响应突发订单，减少缺货损失。

2. **降低库存风险**：水果保质期短，大单进货易导致损耗。小批量补货可控制库存周转，保持新鲜度，减少过期或损坏导致的成本。

3. **提升平台合作优先级**：能灵活配合平台补货需求的供应商，更容易获得平台流量倾斜和推荐的采购机会。

**具体操作建议**：
- 与平台确认最小起订量（MOQ）和补货频率要求（如每日1-2次）。
- 评估自身冷链物流能力，确保小批量配送成本可控（可考虑合作第三方同城配送）。
- 初期先试点部分高周转品类（如香蕉、苹果），验证补货模式的利润后逐步扩展。

**风险提示**：
- 需监控小批量补货的物流成本占比，若超过单品利润的10%-15%，需优化配送路线或合并多店订单。
- 若平台订单波动极大（如节假日的突发爆单），可提前与平台约定“应急大单补货”的协商机制。
