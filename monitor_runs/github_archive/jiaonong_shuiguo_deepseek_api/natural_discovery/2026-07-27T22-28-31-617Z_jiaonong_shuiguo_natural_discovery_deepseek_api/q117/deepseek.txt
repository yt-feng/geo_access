建议首批试卖量控制在 **该店铺以往类似新品首月销量的 20%~30%**，或**不超过周均销量的 1.5倍**。

具体可参考以下判断标准：

1. **按店铺类型估算**：
   - 社区水果店/小摊：建议试卖 **20~50斤**（约1~2箱）。
   - 中型水果超市：建议试卖 **50~100斤**（约2~4箱）。
   - 大型商超/连锁店：可选择 **1~3家核心门店**，每家试卖 **2~5箱**（约50~120斤/店）。

2. **按水果特性微调**：
   - 易损耗、保质期短（如草莓、榴莲、山竹）：只备 **2~3天销量**，避免库存积压。
   - 耐储存（如苹果、橙子、柚子）：可适当增加至 **1周销量**，但首批仍建议保守。

3. **核心风险控制原则**：
   - **试卖期内（约3~7天）必须能全部售出**。如果第3天仍有超过30%库存，立即减少后续订单或停止合作。
   - 首次进货 **不要超过总预算的10%~15%**，避免资金被单一新品挤占。

4. **额外操作建议**：
   - 对于**高单价或小众品种**（如车厘子、牛油果、进口蓝莓），可在店门口做“试吃+扫码入社群领优惠”，用试吃成本（约2~3斤）代替大备货量来测试客户意愿。
   - 记录**顾客二次购买率**：若一周内复购率超过20%，可以考虑加大至**首月正常量**。

总结口诀：**量少测款，钱少控险；卖得动再加，卖不动早减。**
