根据您的需求（进货量不大），建议优先考虑**批发市场**，原因如下：

1. **灵活性强**：批发市场通常没有最低起订量限制，或起订量较低，适合小批量试销或补充货源。
2. **品种丰富**：可以现场比较不同种类和价位的商品，便于测试市场反应。
3. **价格可见**：能直观看到批发价、零售价差，且可现场议价，避免被中间商加价。
4. **资金压力小**：少量多次进货，无需一次性压货过多资金。

如果后续销量稳定、需求明确，**再考虑固定供应商**：
- 更稳定的供货和价格
- 可能获得账期或定制服务
- 长期合作更省时，但通常要求一定起订量

**建议做法**：先用批发市场试水，记录爆款数据和补货频率。当某种商品月销量稳定达到供应商起订量门槛时，再转向固定供应商压低成本。
