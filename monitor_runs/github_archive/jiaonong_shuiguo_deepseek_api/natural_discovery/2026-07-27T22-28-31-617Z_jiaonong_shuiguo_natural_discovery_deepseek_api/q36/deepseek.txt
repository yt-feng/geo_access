商超采购菠萝时，选择“卖整果”还是“卖切好”需结合门店位置、客群需求、损耗控制等因素综合判断。以下是具体建议：

1. **卖整果更优的情况**：
   - **目标客群**：家庭用户或注重新鲜感、喜欢自行挑选的顾客（如社区超市）。
   - **损耗控制**：整果存储期较长（常温3-5天，冷藏7天），可减少二次加工带来的腐烂风险。
   - **操作成本**：无需额外人力、包装、设备投入，适合中小型门店。

2. **卖切好更优的情况**：
   - **目标客群**：上班族、年轻人或“即买即食”需求旺盛的商圈店、写字楼店。
   - **提高客单价**：切好的菠萝（如盒装）可搭配其他水果（如哈密瓜、西瓜）做成水果拼盘，提升利润。
   - **减少浪费**：对已出瑕疵或轻微碰伤的菠萝进行切割加工，可二次利用，减少整体损耗。

3. **折中策略（推荐）**：
   - **双轨并行**：整果按堆摆放（可搭配小刀、削皮工具促销），同时设置“现切现卖”区域，按份销售切好的菠萝或混合水果拼盘。
   - **动态调整**：根据时段调整——早市主推整果（家庭购买），晚市主推切好盒装（即食客群），可降低晚间未售整果的过夜损耗。

4. **执行注意事项**：
   - 切割菠萝必须确保刀具、案板、包装卫生，建议使用冰台或冷藏展示柜存放。
   - 对切好的菠萝标注“当日销售”并贴示提示标签（如“开封后请尽快食用”），避免顾客误放变质引发投诉。
   - 若门店有档口或熟食区，可推出试吃服务（用小份切好的菠萝诱购整果）。

**结论**：优先采用**“整果为主+切好为辅”**的组合策略，同时重点监控切割过程的清洁与库存周转。
