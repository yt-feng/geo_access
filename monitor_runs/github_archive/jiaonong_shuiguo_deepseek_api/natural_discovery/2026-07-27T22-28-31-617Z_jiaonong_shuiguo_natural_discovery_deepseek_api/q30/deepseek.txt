针对超市水果到货品相不好的售后流程，建议按以下步骤约定，确保权责清晰、可执行：

1. **验收标准前置**：在采购合同或订单中明确约定水果品相的具体标准，例如：允许多少比例的轻微碰伤、腐烂、大小差异等（如“腐烂率不超过3%”），并附上实物照片或评分示例作为参考。

2. **即时反馈机制**：收货后24小时内（或更短时间如2小时，根据水果易腐性调整）完成验收。如发现品相问题，应立即拍照或视频留证，并填写《到货异常报告》，记录问题品种、数量、照片和发现时间。

3. **处理方式灵活分级**：
   - **轻微瑕疵**：如表皮微小擦伤、颜色不均，可协商折价处理（如打8折），或转为特价促销商品。
   - **中度问题**：如明显碰伤、轻度腐烂，超市可选择拒收对应批次，或要求供应商补发等价好货。
   - **严重劣果**：如大面积腐烂、虫蛀，超市有权整批拒收，并追溯责任方赔偿（含运费、损耗）。

4. **时限与补偿标准**：
   - 供应商需在收到退货通知后48小时内退款/补发，超时按货值每日1%赔付。
   - 如因品相问题导致超市二次销售损失（如顾客投诉退换），供应商需承担20%的惩罚性补偿。

5. **不可抗力豁免**：因台风、运输事故导致的质量问题，双方协商协商（如保险理赔后分摊50%损失）。

6. **争议处理**：保留所有照片、报告和书面沟通记录，优先协商；若无法解决，可约定由第三方检测机构（如SGS）鉴定，费用由责任方承担。

**参考示例条款**：  
“甲方（超市）在到货后6小时内发现水果品相不符本合同附件一《品质标准》，可向乙方（供应商）发出书面通知。乙方应在12小时内确认，并选择以下之一：1）折扣（降幅≥20%）；2）补发同品种等量好货；3）退款含本单货值及30%违约金。若乙方超时未处理，视为同意整单退款及支付违约金。”

**建议**：先用小批量试运行该流程1-2个月，并定期复盘品相标准是否合理，动态调整条款。
