批发档口要拓展餐饮客户（如奶茶店、果汁店、甜品店、烧烤店等），菠萝和香蕉的规格建议如下：

### 一、菠萝规格建议
餐饮客户对菠萝的需求主要是**新鲜、易处理、出肉率高**，具体规格：

1. **成熟度**：  
   - **7-8成熟**（果皮微黄、按压坚挺）——适合茶饮店、果汁店（现切或制浆），运输和储存期3-5天。  
   - **9成熟**（果皮金黄、香气浓郁）——适合甜品店、自助餐（当天食用），需快速周转。

2. **大小分级**：  
   - **小果（0.8-1.2斤/个）**：适合烧烤店做菠萝烤肉串、早餐店做散装切块，单价低、损耗小。  
   - **中果（1.3-1.8斤/个）**：最主流规格，奶茶店、果汁店制浆不浪费果肉，甜品店做菠萝冻、果切拼盘。  
   - **大果（2斤以上/个）**：适合大型餐饮中水果沙拉、果盘，或自营品牌如菠萝炒饭、菠萝咕咾肉（需注意单个重量是否超过客户使用成本）。

3. **去头、去皮/切块服务**：  
   - **原果供应**：客户有后厨人员可自己处理。  
   - **预切菠萝肉（真空包装）**：奶茶店、果汁店更愿意采购，省人工、提高效率，规格可提供 **200g/袋** 或 **500g/袋**（常见单杯用量或调浆量）。

4. **品种推荐**：**菠萝凤梨（金菠萝、甜蜜蜜）** 比普通菠萝出肉率高10%-15%，纤维少、不用挖眼，更受餐饮端欢迎。

### 二、香蕉规格建议
餐饮端香蕉主要用于**奶昔、果切、烘焙（香蕉蛋糕）、烧烤（烤香蕉）**，重点在**成熟度控制**和**耐储性**：

1. **成熟度分级**：  
   - **黄熟1-2级（果皮全黄、果肉结实）**：6天左右自然熟化——适合烘焙店（制作香蕉泥）、甜品店（香蕉船），口感偏硬不烂。  
   - **黄熟3-4级（泛轻微芝麻点）**：2-3天内使用——适合果汁店（奶昔、香蕉牛奶）、烧烤店（炭烤香蕉），此时果肉软糯香甜。  
   - **黄熟5级（大量芝麻点、果肉极软）**：需24小时内消费或冷冻——适合做果酱、调理包（部分连锁烘焙店会要这种带烂点品种，用于快速出酱）。

2. **大小/包装**：  
   - **中大果（单根18cm以上、重量140g+）**：餐饮客户常用，手拿有分量，切块不嫌小。**建议按把**（梳把整齐，每把5-7根，约1.8-2斤），方便称重。  
   - **特小果（单根12-15cm）**：仅适用幼儿园、儿童餐等特供场景，常规餐饮端少要。  
   - **切段真空包装**（高端外卖/茶饮用+）：部分中高端饮品店会要求**提前切段去头尾**，每段5cm左右，真空袋装（例如500g/袋，约10段），减少店内损耗。

3. **耐储性辅助**：  
   - 建议提供**已熟成但不过熟**的香蕉（黄熟2-3级）。如客户订货后不立即使用，可协商发货时搭配未转色的青香蕉（绿柄黄条），到店后自行催熟，延长销售周期。

### 三、针对不同餐饮客户的组合建议
- **茶饮/果汁店**（主打菠萝汁、香蕉芒果奶昔）：  
  → 菠萝：中果（1.5斤左右）+ 预切菠萝肉（真空，200g/袋）；香蕉：黄熟3-4级大把，或真空切段。  

- **烧烤/火锅店**（菠萝牛肉串、烤香蕉）：  
  → 菠萝：小果（1斤内，整颗或切块）；香蕉：黄熟3级中果（切成厚段后售价友好）。  

- **甜品/烘焙店**（菠萝蛋糕、香蕉奶油夹心）：  
  → 菠萝：大果（出肉率优先，可要求去皮去心）；香蕉：黄熟2-3级（香蕉泥用） + 黄熟5级（特价采购做酱）。  

- **大型连锁中央厨房**（统一配送果切）：  
  → 建议提供**预切菠萝丁（1.5cm³）、香蕉片（0.5cm厚）** 真空袋装或冻品，按**10kg/箱**通路规格，低于小份单价。

### 四、额外提醒
- **包装标准**：带皮原果用透气网袋或纸箱（防止碰伤），切肉/切段需使用食品级真空袋，标签注明储存温度（菠萝: 6-8°C ，香蕉: 12-14°C 不可冷藏）。  
- **保质与损耗**：可提供“到店出现发黑/霉变（24小时内）”的免费退换承诺，餐饮客户对此敏感。

按以上规格准备后，可主动提供**样品试切**或**一份试用装**给潜在客户，降低尝试门槛。
