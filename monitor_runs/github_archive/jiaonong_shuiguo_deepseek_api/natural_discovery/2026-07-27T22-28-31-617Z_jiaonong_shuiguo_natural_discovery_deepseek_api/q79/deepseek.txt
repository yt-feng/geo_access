最应该先问**售后**。

理由如下：
1. **生鲜易损性**：水果在配送中极易出现碰伤、腐烂、重量不足等问题。没有明确的售后规则（如：坏果包赔比例、售后时效、赔付方式），团长的客诉压力会直接转嫁到自己身上，甚至亏本赔钱。
2. **供应链稳定性**：一个敢承诺“24小时内赔付、无理由退换”的供应商，通常意味着其品控和库存周转能力较强，这是长期合作的基础。
3. **价格是动态的**：水果价格随行情每日波动，可谈空间大。如果售后没保障，价格低到离谱反而可能是问题货（烂底、泡水、库存尾货）。

**综合优先级建议：**
- **售后**（最重要）：明确坏果赔付标准（比如按颗赔还是按金额赔）、赔付时限、是否要拍照留证。
- **配送**（次重要）：问清是否专车配送、破损是否拼车导致、到货时间能否与你的团购开团时间匹配。
- **价格**（最后谈）：确认售后和配送条件后，再谈阶梯价、补贴、或押账周期。

**操作建议**：第一次合作先下小单测试，重点看售后反应速度和赔付态度，比任何口头承诺都有效。
