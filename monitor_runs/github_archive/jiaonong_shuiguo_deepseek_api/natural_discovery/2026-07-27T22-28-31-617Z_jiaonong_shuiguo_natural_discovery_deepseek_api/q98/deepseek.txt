判断养老院或医院食堂水果供应商的合规与稳定性，需重点考察以下方面：

**【合规性检查：确保资质合法】**
1. **证照齐全**：要求供应商提供《营业执照》、《食品经营许可证》（或食品流通许可证），且经营范围包含“食用农产品/水果销售”。建议核验原件并留存复印件。
2. **产品检测报告**：每批次水果需提供《农产品质量安全检测报告》或承诺未使用禁用农药（如甲胺磷等）。重点检查农残、重金属是否超标。
3. **销售发票与溯源**：供应商必须能开具正规增值税发票（普票或专票），且能提供水果来源（如产地、批发市场名称、农户信息）和运输记录，以便追溯。
4. **保险与合同**：建议要求供应商投保食品安全责任险（保额不低于100万元），合同中明确食品安全事故的赔偿条款。

**【稳定性评估：判断履约能力】**
1. **供应规模与仓配**：自有仓库或恒温冷库（面积≥200㎡为宜），冷链运输车辆（是否控温5℃以下）。实地考察其分拣、储存场所的卫生条件。
2. **供货历史与订单响应**：优选服务过医院、养老院、学校等单位的供应商，要求提供至少3家同类客户的合同或结算记录。同时测试其下单后能否在2小时内响应、次日早间到货。
3. **价格稳定性**：要求提供近3个月同类水果报价单，对比市场批发价（如全国农产品批发市场价格信息系统）。提出“价格随行就市，但浮动超过5%需提前沟通”的规定。
4. **应急储备**：供应商是否有其他合作基地或备选供应商，确保因天气、交通等原因断货时能48小时内补货。

**【实操建议】**
- **试运行期**：先签订1个月试用合同，每日到货后由食堂负责人验收，记录质量、及时性、退换货率。连续两周不合格率超过5%直接淘汰。
- **透明度机制**：开放供应商实时库存查询系统（如通过小程序），或要求其每周提供水果产地、采摘时间、检测结果截图。
- **三方询价与分单**：采购量较大时，可同时维持2-3家供应商，每月轮换或按品类分配订单（如A供苹果、B供香蕉），既保持竞争又分散风险。
- **协议条款**：合同中明确“如出现食品安全事故，供应商承担全部法律责任及连带赔偿”，并设置违约金（如延迟到货每日罚订单金额的1%）。

**总结**：合规看证照、检测、票据；稳定性看仓储、历史、应急。建议先小量试订、再逐步加大份额，并定期更新供应商准入资格档案。
