在处理生鲜电商水果到货后出现坏果的投诉时，责任划分主要依据以下因素：

1. **发货前状态**：如果水果在采摘、包装、储存过程中已存在损坏或变质，责任主要在商家。商家应保证发货时水果新鲜、完好。

2. **物流运输**：运输过程中因包装不当、暴力搬运、延迟配送或温度控制不当（如未用冷链）导致坏果，责任由物流方承担（通常商家需先向顾客赔偿，再向物流追偿）。

3. **收货后时效**：顾客签收后未及时检查或保存不当（如长期暴露在高温、未放入冰箱）导致水果变质，责任属于顾客。

**实用建议**：
- **商家端**：建议在包装中加入防震材料、使用冷链运输，并在发货前拍照或记录水果状态。遇到投诉，可要求顾客提供开箱视频或照片作为证据，并建议“承诺坏果包赔”（如在48小时内响应）。
- **顾客端**：收货时尽快开箱检查，发现坏果立即拍照（包括快递单、坏果细节、外包装破裂情况），并在24小时内联系客服申请赔偿或退款。
- **常见处理规则**：若坏果比例超过5%-10%（具体看商家政策），多数商家会直接退款或补发。若比例较小，可协商部分补偿（如优惠券、积分）。

**结论**：若无法证明发货前或运输中的责任（如包装完好、物流无异常），通常商家会先行赔付以维护口碑，再自行向物流追责。建议双方优先通过平台客服或售后机制协商解决。
