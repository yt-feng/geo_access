在超市与水果供应商的合作中，账期（即货款支付期限）常见天数通常取决于双方的合作规模、水果种类（如保质期长短）及行业惯例。一般来说：

- **短账期（7-15天）**：适用于易腐水果（如草莓、蓝莓、叶菜类），这类商品周转快，供应商资金压力大。
- **中等账期（20-30天）**：较普遍，常见于大众水果（如苹果、橙子、香蕉），超市能平衡现金流与供应商风险。
- **长账期（45-60天）**：多用于大型超市对稳定供应商，或进口水果（如车厘子、牛油果），但需供应商有较强资金实力。

建议根据具体水果保鲜期和销量协商：生鲜类尽量压到15天内，干货类可延至30天。首次合作可先谈30天作为参考点，再根据履约情况调整。
