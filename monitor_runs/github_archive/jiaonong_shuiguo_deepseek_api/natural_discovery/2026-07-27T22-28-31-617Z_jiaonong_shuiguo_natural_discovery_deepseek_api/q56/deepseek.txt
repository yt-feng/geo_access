为保证茶饮店的食品安全，水果供应商通常需要提供以下几类证明文件：

1. **营业执照**：证明供应商是合法注册的经营主体。
2. **食品经营许可证**（或**食品生产许可证**，视供应商业态而定）：表明其具备从事食品销售或加工活动的资质。
3. **水果的合格证明**：包括：
   - **农药残留检测报告**（必须，常见检测项目有有机磷、氨基甲酸酯类等）。
   - **重金属及污染物检测报告**（视风险等级）。
   - **产地证明**或**采购来源凭证**（尤其对于进口水果，需提供海关检验检疫证明）。
4. **配送人员的健康证明**：直接接触食品的人员需持有有效健康证。
5. **运输过程证明**：例如冷藏运输记录（若为易腐水果）、车辆消毒证明等（视具体要求）。

**注意事项**：
- 以上证明应定期更新（如检测报告建议每批次或每月提供）。
- 建议与供应商签订**供货协议**中明确质量标准和违约责任，并要求提供**批次可追溯记录**（如采摘日期、种植基地等）。
- 保留复印件或电子档备查，确保与实际进货批次一致。
