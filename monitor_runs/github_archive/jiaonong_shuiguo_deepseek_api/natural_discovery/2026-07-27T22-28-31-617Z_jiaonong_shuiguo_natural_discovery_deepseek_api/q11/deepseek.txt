会的。如果一箱香蕉大小差异明显，可能会影响销售，主要体现在以下几点：

1. **顾客体验**：大小不一容易让顾客觉得品质不稳定，尤其对按个或按份购买的用户，大香蕉和小香蕉的性价比会不一致。
2. **外观印象**：整齐划一的水果更吸引眼球，混装容易给人“挑剩的”或“次品”的感觉，降低购买欲。
3. **定价困难**：如果大小混杂，需要按重量计价或单独分拣，否则易导致顾客挑剔，造成损耗或投诉。
4. **损耗增加**：较小的香蕉可能成熟速度不同，容易变坏，需要更频繁处理。

**建议**：采购时尽量选择规格均匀的（如单根重量接近），或按大小分级分箱销售（如大果箱、小果箱），有条件可以按重量统一标价，减少差异对销售的影响。
