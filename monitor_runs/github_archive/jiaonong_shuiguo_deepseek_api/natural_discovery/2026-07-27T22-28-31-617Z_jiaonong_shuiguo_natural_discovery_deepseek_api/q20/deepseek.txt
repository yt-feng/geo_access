社区超市选择每日配送的水果供应商时，建议重点考察以下条件：

1. **稳定供货能力**  
   - 供应商是否能保证全年不间断供货，尤其是非应季水果的货源渠道（如进口或大棚产品）。  
   - 是否有应对极端天气、物流中断等突发情况的备用方案。

2. **新鲜度与质量控制**  
   - 每日配送的水果是否采后预冷处理，包装是否防挤压（如使用透气泡沫箱、独立套袋）。  
   - 是否有明确的分拣标准（如糖度、尺寸、成熟度检测），退货或换货政策（如腐烂率超过5%无条件更换）。

3. **配送时效与频率**  
   - 能否满足“次日凌晨送达”或“指定时间段送达”（如早6点前到店）的需求。  
   - 是否需要分批配送（如部分易损水果分两批次到货），配送车辆是否冷链封闭。

4. **价格与支付方式**  
   - 是否支持按周/月结算账期，以及价格浮动机制（如与批发市场行情挂钩的调价规则）。  
   - 能否提供少量试销期（如前两周按样品价供货），降低初期风险。

5. **品种与定制化**  
   - 是否涵盖常见水果（苹果、香蕉、柑橘）及高频平价品种（如应季西瓜、葡萄），也可提供小众爆品（如阳光玫瑰、蓝莓）。  
   - 是否支持根据社区人群属性调整品种（如中老年偏好软糯水果，年轻人偏好酸甜新品）。

6. **资质与合规性**  
   - 供应商的营业执照、食品经营许可证是否齐全，水果产地证明及农药残留检测报告是否可追溯。  
   - 是否投保产品责任险（覆盖因质量问题导致的消费者纠纷）。

**建议行动**：优先选择有3年以上本地配送经验的供应商，可要求实地考察其分拣车间、冷库及运输车辆。同时对比2-3家供应商的报价（含损耗补偿条款），并签署至少包含“滞销品按周退换”条款的合同。
