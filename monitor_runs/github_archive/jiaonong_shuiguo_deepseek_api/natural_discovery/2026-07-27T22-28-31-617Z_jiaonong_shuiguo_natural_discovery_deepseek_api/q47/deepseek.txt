为茶饮店采购香蕉时，控制熟度需根据具体用途分阶段处理，以下是可操作的建议：

1. **按用途选择熟度**  
   - **做甜品（如香蕉布丁、奶昔）**：选 **完全成熟（表皮有黑斑、稍软）**，甜度最高、易打泥。  
   - **做饮品（如香蕉牛奶、冰沙）**：选 **7-8成熟（表皮全黄、果肉稍硬）**，避免过熟导致氧化变黑或影响口感。  
   - **做装饰切片**：选 **6-7成熟（带绿头、硬挺）**，不易氧化且易切出形状。

2. **采购验收标准**  
   - **颜色**：拒绝表皮全绿（未熟）或全黑（过熟），优先黄皮带少量褐斑的批次。  
   - **触感**：轻捏香蕉中部，略有弹性但果肉不软塌。过软易烂，过硬会涩。  
   - **果柄**：新鲜香蕉果柄半绿半黄，干枯或发黑说明存放过久。

3. **到店后催熟或保鲜**  
   - **需延长使用期**：购入7成熟香蕉，分开存放（未熟放通风处，已熟冷藏）。  
   - **快速催熟**：将青香蕉与苹果/番茄同装纸袋，室温22-25℃下2-3天变黄。  
   - **抑制过熟**：已成熟的香蕉用保鲜膜包起果柄冷藏，可延长2天使用期。

4. **记录与调整**  
   - 每次采购记录用量和损耗，若某款饮品耗量高，可适当提高熟度；装饰类则降低熟度。  
   - 建议每周采购2次小批量，避免一次性库存过大。

最终通过试做验证：饮品需香蕉味突出且不涩，甜品需顺滑无纤维感。
