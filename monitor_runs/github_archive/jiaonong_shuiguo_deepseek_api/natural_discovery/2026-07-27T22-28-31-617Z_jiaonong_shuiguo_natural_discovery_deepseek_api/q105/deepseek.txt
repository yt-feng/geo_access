水果锁价的时间通常取决于市场行情、品种特性和双方合作关系，一般分为以下几种情况：

1. **短期锁价（1-2周）**：适用于价格波动较大的时令水果（如荔枝、杨梅），或产量不稳定的品种。适合快进快出、库存周转快的采购。
2. **中期锁价（1-3个月）**：适用于大宗、耐储存的水果（如苹果、橙子、猕猴桃），或进口水果（如车厘子、牛油果）在产季前谈判。需供应商有稳定仓储能力。
3. **长期锁价（一个产季或半年）**：适用于大型连锁超市或长期合作关系，需签订框架协议，并约定价格调整机制（如随大宗商品指数浮动）。
4. **极端情况**：部分稀缺水果（如顶级榴莲、松茸）几乎无法锁价，只能按现货价或短周期议价。

**实操建议**：
- 优先与信誉好、产量稳定的供应商谈判，并明确锁价期间的违约责任（如供应商涨价如何赔偿）。
- 小批量试锁，观察供应商履约能力后再扩大。
- 在合同中加入“价格调整条件”（如遇自然灾害、运费暴涨等可重新议价）。
- 对高频采购品种，可尝试“阶梯锁价”：比如每月固定量、价格分梯度锁定。

具体可结合你的采购品类、采购量和市场周期，与供应商协商试运行。
