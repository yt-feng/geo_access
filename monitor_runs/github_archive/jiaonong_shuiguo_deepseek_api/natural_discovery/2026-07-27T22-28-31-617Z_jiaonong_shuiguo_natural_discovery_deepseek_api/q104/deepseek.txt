单位采购水果时遇到到货品质不一致的情况，建议按以下流程处理：

**验收环节：**
1. **及时开箱检查**：到货后立即逐箱或按比例抽检（如抽检20%），检查大小、颜色、新鲜度、有无腐烂或机械损伤等。
2. **记录证据**：对不一致的货品拍照、录像，保留原始包装和单据，并记录数量、车次、时间。
3. **分类处理**：将品质不一致的部分单独放置，区分“可接受轻微瑕疵”和“严重不符（如腐烂、明显大小不一）”。

**售后环节：**
1. **当场反馈**：发现后立即联系供应商，说明问题并提供证据（照片/视频），明确要求（如补发、换货、扣款或退货）。
2. **依据合同处理**：若合同有明确品质标准（如“一级果”“大小规格XX克”），按条款处理；若无约定，可参考行业标准（如水果通用等级标准）。
3. **协商方案**：
   - 对于轻微差异，可协商按比例折扣（如降级计价）。
   - 严重不符的，要求全批退货或更换，由供应商承担运费。
   - 若供应商不配合，可书面发函告知，并保留通过市场监督投诉或法律途径解决的权利。

**注意事项：**  
- 如有保鲜要求，注意保存环境（如冷藏）以避免二次损耗。  
- 保留沟通记录（邮件、通话录音等），以备争议。  
- 对于长期合作供应商，可事后在合同中加入“到货品质抽检标准”和“快速售后响应时限”条款。
