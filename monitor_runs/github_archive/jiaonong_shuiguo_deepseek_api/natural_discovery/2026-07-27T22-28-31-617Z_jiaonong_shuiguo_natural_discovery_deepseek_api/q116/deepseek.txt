小商家采购水果时，两种结算方式的主要风险如下：

**现金结算风险：**
- **资金压力**：需立即支付全部货款，占用流动资金，可能影响其他周转。
- **质量不可溯**：若水果有腐烂、损坏或与约定不符，因已付清款项，后续追索或退货较难。
- **无账期缓冲**：一旦遇到销售困难或货损，自身承担全部损失。
- **缺乏风险保障**：无合同或凭证情况下，出现纠纷（如缺斤少两）时维权困难。

**月结账期风险：**
- **信任风险**：若对方不守信，可能到期拖欠账款或拖延支付，影响供应商的现金流。
- **隐形费用**：部分账期可能隐含利息或涨价风险（如供应商为补偿账期提高单价）。
- **管理成本**：需跟踪对账、催款，增加人力与时间成本。
- **断供风险**：若多次延迟付款，供应商可能暂停供货，影响季节性水果采购。

**建议：**
- 小额或首次合作时优先现金结算，增强议价能力；对大额、长期供应商可尝试短期账期（如半月结）。
- 无论哪种方式，尽量签订书面协议明确质量、数量、结算时间及违约责任（如滞纳金）。
- 预留10-20%尾款在验货后支付，能有效降低质量风险。
