根据水果店常见销售经验，推荐以下4种搭配方案（考虑颜色、口感、季节性及寓意）：

---

**✅ 方案一：「红黄福袋」礼盒（经典走量款）**  
- **搭配**：苹果（红色）+ 橙子（橙色）  
- **比例**：6个苹果 + 6个橙子  
- **核心卖点**：红橙配色喜庆，寓意“平安吉祥、心想事成”
- **适合场景**：日常走亲访友、节日送礼  
- **注意事项**：苹果选脆甜的红富士，橙子选甜度高、皮薄（如脐橙）

---

**✅ 方案二：「热带风情」礼盒（差异化款）**  
- **搭配**：香蕉（黄色）+ 菠萝（金黄）  
- **比例**：1串香蕉（约5-6根） + 1个菠萝  
- **核心卖点**：颜色亮眼，有异域感，适合年轻顾客拍照发圈  
- **适合场景**：朋友聚会、露营、餐后水果  
- **注意事项**：香蕉要带熟度适中的（不能太青或过熟），菠萝可提前削皮切块（配牙签）

---

**✅ 方案三：「平安如意」混搭礼盒（大众安全款）**  
- **搭配**：苹果（红色）+ 橙子（橙色）+ 香蕉（黄色）  
- **比例**：4个苹果 + 4个橙子 + 1串香蕉  
- **核心卖点**：三种水果形状、颜色、口感互补（脆-多汁-软糯），价位适中  
- **适合场景**：亲友拜访、长辈送礼  
- **注意事项**：香蕉需单独用纸包好，避免挤压

---

**✅ 方案四：「富贵满堂」豪华款（高价款）**  
- **搭配**：苹果 + 橙子 + 菠萝 + 香蕉  
- **比例**：3个苹果 + 3个橙子 + 半个削皮菠萝 + 5根香蕉  
- **核心卖点**：种类丰富、摆盘美观；菠萝切块用保鲜膜封好  
- **适合场景**：商务送礼、重要节日  
- **注意事项**：需配泡沫托盘或竹篮，价格可上浮30%-50%

---

**💡 实战建议**：
1. **包装成本**：水果礼盒≈ 水果成本 ×1.5-2倍定价（含纸盒/保鲜膜/丝带）
2. **库存提示**：香蕉、菠萝不耐放，建议按订单备货，避免腐烂损耗
3. **试卖技巧**：优先主推方案一（红橙），可搭配“买礼盒送手写祝福卡片”
4. **避坑提醒**：绝对避免将苹果与香蕉混放（乙烯会使苹果变软），可用隔层分开
