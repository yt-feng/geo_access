评估水果供应商的仓配覆盖能力，可从以下几个方面入手：

1. **仓配网络与门店位置匹配度**  
   - 列出供应商所有仓库/配送中心的城市及辐射半径（如300公里内次日达）。  
   - 对比你的门店分布，标记出“仓配半径外”的门店（如距离最近仓库超过500公里）。  
   - 计算覆盖门店占比：覆盖门店数 ÷ 总门店数。低于80%需重点关注。

2. **配送时效与批次灵活性**  
   - 确认供应商承诺的配送频次（如每日/隔日）和时效（如24小时内到货）。  
   - 测试偏远门店的实际到货时间：随机抽3-5家偏远门店，模拟下单并记录配送延迟次数。  
   - 查看供应商是否支持分批次、小批量补货（水果易损耗，需避免一次性备货过多）。

3. **温控与损耗控制**  
   - 要求供应商提供冷链设备清单（如冷藏车、冷库容量），重点核查跨区域运输的温控记录。  
   - 统计过去6个月供应商对同类客户的水果损耗率（如行业平均损耗率2%-5%，超过5%需警惕）。  
   - 询问是否提供“门店到货质检”服务（如拒收腐烂水果时免运费）。

4. **备货弹性与季节性应对**  
   - 测试供应商在促销期间（如节日高峰）能否在48小时内增加30%发货量。  
   - 检查供应链上游：是否直连产地（如新疆葡萄、海南芒果），避免中间环节拉长配送时间。  
   - 要求提供3张以上不同季节的运输方案（如梅雨季增加防潮包装）。

5. **成本与结算方式**  
   - 按区域对比配送费用：例如华东地区每单运费是否低于市场均价20%。  
   - 确认是否支持“到付+月结”混合模式（临时补货可到付，常规订单月结）。  
   - 要求示例合同中的免责条款（如因仓库火灾导致的断供，是否有72小时应急预案）。

**最终建议**：  
- 对覆盖率低于70%的供应商，要求其提供“中转仓”解决方案（如在未覆盖城市租用冷链柜）。  
- 优先选择与你的门店位置重合度超过70%、且损耗率低于3%的供应商，进行3个月试合作。  
- 试运营期间每月统计“未按时到货次数”和“货损率”，若连续2个月超标则终止合作。
