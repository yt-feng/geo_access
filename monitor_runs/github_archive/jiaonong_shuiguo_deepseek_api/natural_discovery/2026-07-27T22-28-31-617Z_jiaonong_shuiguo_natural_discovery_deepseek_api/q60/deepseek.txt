针对茶饮店水果到货不合格的情况，建议按以下方式与供应商约定补货条款，确保快速恢复正常营业：

1. **明确验收标准与时效**  
   合同中需写明水果的规格（如成熟度、大小、无腐烂、无机械损伤等），并约定到货后**2-4小时内**完成验收。若发现不合格，立即拍照留证并通知供应商。

2. **补货响应时间**  
   约定供应商在收到不合格反馈后**2小时内**确认补货或替换方案，最晚在**24小时内**送达同等级或更优品质的水果。若无法及时补货，供应商需承担当天销售额损失（按历史日均销量计算）。

3. **补货方式与费用**  
   - 若供应商能立即补货，优先选择就近仓库调拨或**加急物流**，运费由供应商承担。
   - 若因季节或短缺无法补货，需提供**可替代水果清单**（例：用当季芒果替代未到货的杨梅），并确保口味与成本接近。

4. **违约金与赔偿**  
   写明供应商未在约定时间内补货时，需支付当天该批水果总价**20%-30%**的违约金，并报销额外采购成本（如从其他渠道紧急调货的差价）。

5. **备用方案**  
   与1-2家备用供应商维持协议，当主供应商无法履约时，能**4小时内**启动调货。日常库存可保有一种可替代的水果半成品（如冷冻芒果果茸），避免断货。

**执行建议**：  
- 使用**标准化验收清单**（附照片与秤重记录），减少纠纷。
- 优先选择**本地或同城供应商**，缩短补货物流时间。
- 保留违约条款的法律效力，例如通过合同注明“若因原料问题导致门店停业，供应商需承担当日预估营业额损失”。

提前锁定上述条款并书面化，能大幅降低营业中断风险。
