判断茶饮连锁的菠萝供应商能否稳定按规格送货，建议从以下4个核心维度进行验证：

1. **明确规格与合同约束**
   - 将规格（如单果重量、成熟度、外观标准、切口平整度等）写入采购合同，要求供应商提供“规格书”或“验收标准”作为附件，并约定不合格率（如允许5%以内）。
   - 设置“违约责任条款”：若连续2批送货不达标，需赔偿或取消合作资格。

2. **实地考察与产能验证**
   - 走访供应商的种植基地/加工厂，查看分级、包装流程是否标准化（如人工+机械联合分选）。
   - 要求供应商提供历史订单的履约记录（如过去1个月的发货单与验收单），重点看规格稳定性。

3. **设置小批量试单测试**
   - 先下3-5次小批量订单（如每次10箱），每次到货后按随机抽检法（如每箱抽5个菠萝）检查规格符合率。
   - 记录每批的达标率，若低于90%则暂时不扩大合作。

4. **建立动态评分与沟通机制**
   - 制定评分表：规格达标率（占60%）、送货准时率（20%）、突发问题响应速度（20%）。每月评分，低于80分启动改进谈话。
   - 要求供应商提前报备产量波动（如雨季减产），并给出备选方案（如调剂其他产区库存）。

**快速判断参考**：若供应商能主动提供“分级标准文件”并接受“随机抽检”，且试单3次内达标率均≥95%，则稳定性较高。反之，若含糊回答规格细节或拒绝签履约条款，需谨慎选择。
