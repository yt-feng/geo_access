这取决于具体的业态规模和成本控制需求。以下是两种模式的优缺点对比，供你决策参考：

**1. 中央厨房统一收货（集中采购配送）**

- **优点**：
  - **品质与成本**：统一验收标准，减少门店损耗；批量采购议价能力强，单价通常更低。
  - **品控稳定**：中央厨房可配备专业验收人员和设备，按规格分级，减少门店因人员不专业导致的品质分歧。
  - **资金与库存**：集中管理应付账期，易于利用期货或季节波动囤货；核心库存由中央仓承担，门店可零库存运作。
- **缺点**：
  - **二次损耗**：水果在中央加工、分拣、运输至门店的过程中易碰伤、失水，特别是草莓、芒果等敏感品类。
  - **配送时效高**：需要冷链运输且到店时间需精确到班次，否则门店收货时可能已不新鲜。
  - **需求预测难**：若门店销量波动大，中央统一采购易产生滞销积压。

**2. 门店分开收货（门店自行采购或供应商直送）**

- **优点**：
  - **新鲜度**：门店可根据当日销售情况小批量、多频次采购，采购时间灵活，水果上架即售。
  - **品种灵活度**：每个门店可针对当地消费偏好采购小众或区域特色水果。
  - **减少流通环节**：供应商直送可省去中央分拣时间，最快实现产地到货架。
- **缺点**：
  - **品控风险**：各门店验收标准参差不齐，易出现以次充好、缺斤短两。
  - **成本更高**：单个门店采购量小，议价能力弱，单价和配送费都更高。
  - **效率低下**：每个门店需安排专人对接供应商、验收、记账，管理成本翻倍。
  - **合规风险**：小供应商无法提供正规发票和追溯单，财务和食品安全风险增加。

**建议选择模式（分情况）：**

- **推荐「中央统一收货」的情况**：
  连锁门店数超过10家、每日水果用量稳定、标准化程度高（如沙拉连锁、果切工坊）、自有冷链配送体系成熟。
  *可搭配策略*：耐储存水果（苹果、橙子、哈密瓜）走中央集采；易损水果（草莓、蓝莓、荔枝）由门店根据销量向中央申请，设置最小起订量。

- **推荐「门店分开收货」的情况**：
  门店数量很少（2-3家）、位置偏远或分散、主营整果销售且客流量极低。
  *可搭配策略*：门店可直接与本地批发商或果农对接，总部只制定价格上限和采购标准。

- **折中方案（混合模式）**：
  大多数连锁最实际的做法：
  1. **核心畅销款（占80%用量）**：中央统一集采，直接配送到店（不经过中央加工），保留水果原包装以减少损耗。
  2. **小众/应季款**：供应商直送门店，总部统一指定供应商和价格，门店负责验收并拍照上传系统。
  3. **紧急补货**：允许门店就近市场现货采购，但需走线上审批流程。

**操作建议**：
- 无论采用哪种模式，**必须建立统一的验收标准**：比如尺寸、糖度、新鲜度图片参照表。
- 在初期，建议先在小范围内（3家店）试点统采模式，对比损耗率、毛利率、顾客投诉率后再全链条推广。
