建议优先选择**单根**和**小把（3-5根）**的组合包装，原因如下：

1. **单根**：适合即买即吃的顾客（如上班族、学生），单价低、购买灵活，能减少浪费。
2. **小把**：适合家庭或少量囤货需求，满足多根购买但不想买整袋的消费者。
3. **避免整袋**：除非有明确家庭大份量需求，否则容易因成熟度不均导致滞销，且保鲜难度高。

**执行建议**：  
- 初期可测试单根和3根小把，占生鲜区约70%的货架面积。  
- 整袋可作为“特价家庭装”少量上架，标注“适合催熟或冷冻”。  
- 注意香蕉成熟度分级（青熟、金黄、带斑），避免整袋混入不同熟度导致口碑问题。  

**数据参考**：多数便利店和超市销售数据显示，单根和小把的动销率比整袋高40%以上（行业经验值）。
