便利店卖菠萝切块时，**三者都需要关注**，但核心优先级建议如下：

1. **保质期**（最重要）：菠萝切块属于鲜切水果，易氧化变质。需明确标注生产时间和保质期（通常冷藏条件下不超过24-48小时），建议采用“当日报废”或“限时打折”策略，避免食品安全风险。

2. **包装**（直接影响销售）：  
   - 需使用**防雾、透气**的食品级包装（如PET托盘+盖膜），避免水汽凝结加速腐烂。  
   - 包装上应标明“切开时间”和“保质期至”，方便消费者判断。  
   - 推荐小份装（200-300克）以降低单次库存压力。

3. **配送频次**（影响损耗率）：  
   - 根据门店销量，建议**每日配送1-2次**，避免积压。  
   - 若门店空间有限，可采用“按需配送”（如早高峰前送第一批，午市后加送一次）。  
   - 若销量不稳定，可设置最低订货量并关联实时监控系统（如货架巡检提醒）。

**实操建议**：  
- 优先控制保质期（如超过4小时未售出做打折处理）。  
- 包装上使用**可撕贴标签**动态调整到期时间。  
- 配送频次需与**分时段销售数据**挂钩（例如：下午高峰期前补货）。  

最终目标：**保质期>包装>配送频次**，但需根据门店实际损耗率数据动态调整优先级。
