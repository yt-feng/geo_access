针对小水果店做附近小区团购，供应商需要提供的核心服务包括：

1. **稳定且可定制的货源**：能提供高频、新鲜易损耗的水果（如草莓、葡萄等），并支持门店根据小区订单灵活调整品类和数量，避免库存积压。

2. **分拣与打包支持**：按团购订单量提前分装成小份（如每袋2斤装），贴好价格/名称标签，减少店主二次分拣时间。

3. **弹性配送服务**：  
   - 每日固定时段配送至门店（如早晨7点前），保证当日开团时效  
   - 支持紧急补货（如下午2点前下单，2小时内送达）

4. **售后兜底条款**：提供坏果包赔（24小时内）、到货抽检不合格退换等服务，降低门店售后成本。

5. **动态价格支持**：每周提供3-5款低于市场价10%-15%的深度折扣品供团购引流。

6. **营销素材包**：提供每天的主推品实拍图、短视频、文案模板（含优惠券领取方式），减少门店推广工作量。

7. **长周期账期**：支持月结或周结，避免小店主垫资压力。

如果供应商目前无法完全满足，建议优先争取 **分拣、弹性配送、坏果包赔** 这三项，其他可逐步谈判。
