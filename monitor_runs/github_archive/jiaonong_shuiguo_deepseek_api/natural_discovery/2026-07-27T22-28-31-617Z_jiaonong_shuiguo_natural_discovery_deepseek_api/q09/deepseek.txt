和供应商洽谈时，建议提前确认以下关键问题，以降低断货风险并保障合作稳定：

1. **供货能力与稳定性**  
   - 每日/每周最大供货量是多少？历史旺季最大单笔订单处理量？  
   - 是否有备用供应商或产地，以应对突发状况（如自然灾害、物流中断）？

2. **价格与付款条款**  
   - 旺季价格是否会浮动？是否可以签订“保价协议”（提前锁定价格上限）？  
   - 付款账期能否延长（如货到后15-30天结款）？是否需要预付定金？

3. **品质与分级标准**  
   - 供应商如何定义“A级/一级果”？是否有第三方质检报告？  
   - 若到货水果出现腐烂、缩水、规格不达标等问题，赔付比例和流程如何？

4. **物流与时效**  
   - 从订单确认到送达门店需要几天？是否支持分批到货？  
   - 配送过程中是否全程冷链？若因运输导致损耗，由谁承担？

5. **违约与应急机制**  
   - 若供应商断货，需提前几天通知？是否有补货替代方案？  
   - 合同是否约定违约金（如断货按货值20%赔偿）？

**追加建议**：  
- 首次合作先小批量试单，观察对方实际履行能力。  
- 保留2-3家备选供应商，避免单边依赖。  
- 旺季前1个月签订书面协议，明确以上条款。
