建议从以下四个方面核实水果供应商的全国配送能力，每一步都可操作、可验证：

1. **要求提供配送覆盖清单与时效承诺**  
   - 请对方出具具体的“可配送城市/地区清单”（精确到地级市或县级）。  
   - 索要“各区域到货时效承诺表”，例如：华北24小时、华东48小时等。  
   - **验证方法**：随机抽查清单中3-5个非省会城市，在快递官网查询“从供应商仓库到该城市的快递时效是否匹配其承诺”。

2. **测试性下单，追踪实际物流**  
   - 选择3个不同省份的偏远地区（如西部县级市、东北村镇、南方海岛）进行小批量试买。  
   - 记录实际发货时间、运输节点、送达时效。  
   - 比对试单结果与供应商的承诺，若2/3以上试点未达标，说明覆盖能力存疑。

3. **查看长期合作的物流合同与历史签收记录**  
   - 要求提供与顺丰、京东、德邦等主流快递公司的**长期合作协议**（可隐去价格）。  
   - 要求展示过去1个月内发往5个不同省份的**签收记录截图**（含运单号、签收时间、客户签字）。  
   - 随机抽查其中1个运单号，在快递官网验证真实性。

4. **关注生鲜冷链与保质期管理**  
   - 针对易腐水果，必须要求供应商说明不同季节的**冷运方案**（如全程冷链车、航空冰袋等）。  
   - 询问以下风险控制措施：  
     - 当目的地温度超过30℃时是否暂停发运  
     - 因物流延迟导致水果损坏的赔付标准  
     - 极端天气下的应急预案（如改发航空、启用备用冷库）  
   - 可要求提供过去半年内因物流问题产生的**客诉率统计**，低于0.5%通常为合格水平。

**最终判断标准**：通过以上四个维度核实后，若供应商能同时满足“清单覆盖90%需求省份+第三方物流合同+无投诉间隔>3个月+一次试单成功率100%”，则基本可视为具备全国配送能力。若只有口头承诺且无法出示任何证据，建议谨慎合作。
