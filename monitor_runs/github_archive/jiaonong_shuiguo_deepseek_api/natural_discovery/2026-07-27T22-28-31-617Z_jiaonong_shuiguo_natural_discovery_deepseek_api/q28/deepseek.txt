建议先从**进口香蕉**开始引入。

理由如下：
1. **消费习惯最成熟**：香蕉是中国进口水果中销量最大的品类之一（主要来自菲律宾、厄瓜多尔等），消费者认知度高，几乎不吃“亏”，试错成本低。
2. **稳定性强**：香蕉对供应链的适应性较好，只要控制好成熟度（通常超市通过催熟柜调节），损耗率可控，不像菠萝易腐、苹果品种偏好波动大。
3. **引流效果好**：进口香蕉（如都乐、佳农品牌）常做促销价商品，能快速吸引客流，为后续进口水果区培养用户。

**操作建议**：先以“整箱装/品牌进口香蕉”切入，进价约80-120元/箱（13-15公斤），零售定价合理（比如2-3元/根），配合试吃和“进口水果专区”标识，观察两周销量后再逐步增加菠萝（如都乐金菠萝）或苹果（红玫瑰、爱妃等）。
