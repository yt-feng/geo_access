采购小包装香蕉时，建议关注以下关键点：

1. **包装设计**  
   - **透气性**：香蕉呼吸作用强，包装需有通风孔（如微孔薄膜），避免内部湿气积聚加速腐烂。  
   - **量级适中**：常见小包装为 **500g-1kg**（约4-6根），避免过重导致挤压；顶部留缓冲空间。  
   - **防腐处理**：可在包装内加入乙烯吸附剂（如活性炭小包）延迟成熟。  
   - **标签规范**：清晰标注品名、产地、成熟度（如“七成熟”）、包装日期及储存方式。

2. **损耗控制**  
   - **成熟度选择**：采购 **七至八成熟**（果皮翠绿带黄）的香蕉，避免全熟运输中软化、褐变。  
   - **低温防寒伤**：香蕉不耐12℃以下低温，运输中需保温（如泡沫箱+衬垫），到货后存放于 **13-15℃** 恒温区。  
   - **分拣标准**：拒收有机械伤、黑斑、柄部干裂或发霉的果实；包装前筛选，确保无“碰伤”隐患。  
   - **到货检查**：开箱后先排查冻害（果皮发灰、果肉发硬）或挤压引发的褐斑，按成熟度分架销售（未熟与全熟隔离）。

3. **包装可操作性**  
   - 防潮内衬（如食品级PE膜）隔离水分，避免果柄受潮霉变；包装封口处留 **易撕口** 便于顾客打开透气。  
   - 避免使用易吸湿的纸箱包装（香蕉呼吸产生水汽会导致纸箱软化垮塌），优先选环保塑料篮或带孔的瓦楞纸箱。  
   - 单果套袋（保鲜膜贴附）可减少磕碰，但需确认透气性，否则会加速熟制进程。

**执行建议**：  
- 与供应商签订 **包装损耗约定**（如规定包装后自然损耗≤3%）；到货后48小时内抽查10%包装，统计冻害/机械伤比例。  
- 设置 **“香蕉专柜”** 不与其他水果混放（乙烯敏感），并配有“未熟/即食”标签引导顾客选择。
