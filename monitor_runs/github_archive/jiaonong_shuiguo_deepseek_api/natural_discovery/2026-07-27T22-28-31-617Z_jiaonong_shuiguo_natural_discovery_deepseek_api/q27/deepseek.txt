判断超市苹果和橙子的大小规格是否适合门店销售，可以从以下几个方面快速评估：

1. **参考供货商标准或行业通用规格**  
   - 苹果常见等级：  
     大果：直径≥80mm（约网球大小以上）  
     中果：直径70-80mm  
     小果：直径≤70mm（通常不适合门店零售）  
   - 橙子（以脐橙为例）常见等级：  
     大果：直径75-85mm（约成人拳头大小）  
     中果：65-75mm  
     小果：≤65mm（部分特级果可能偏小，需看品种）

   **实操建议**：向供货商索要规格表，或直接用卡尺测量10个样品。

2. **观察外观一致性**  
   - 同一批水果大小差距不应超过10%（如大部分苹果直径75-82mm，个别小于70mm或大于85mm需剔除）。  
   - 形状：苹果应圆润、无明显畸形；橙子需饱满、无干瘪或瘦果。

3. **结合门店定位和顾客预期**  
   - **精品超市**：优选大果（苹果≥80mm，橙子≥75mm），整齐度极高。  
   - **社区超市/平价店**：中果更为常见（苹果70-80mm，橙子65-75mm），价格适中。  
   - **促销/特价区**：小果（苹果<70mm，橙子<65mm）需标记“小果”，价格对应调低。

4. **检查损伤和软硬度**  
   - 苹果：果柄新鲜，无软化、黑斑或虫眼。  
   - 橙子：手感紧实，轻捏不塌陷，果皮无霉变。柑橘类注意底部无绿色（未熟）。

5. **进行抽样称重（辅助判断）**  
   - 苹果：大果单果重约200-250g，中果150-200g。  
   - 橙子：大果单果重250-350g，中果180-250g。  
   - 若重量超出范围，需复核具体品种（如红富士苹果可能更重）。

**快速现场判断流程**：  
1. 随机取10个水果，用卡尺测最大和最小直径。  
2. 目测形状、颜色、表面损伤。  
3. 摸硬度，闻气味（橙子应有清香，苹果无发酵味）。  
4. 对照门店常规定价或等级标签，优先选用大小均匀、无损伤的批次。

最后，注意避免**过度依赖标准**：若某个批次整体偏小但价格明显便宜（如未达到常规直径），只要标注“小果”且质量好，也可根据库存和客群决定是否购入。
