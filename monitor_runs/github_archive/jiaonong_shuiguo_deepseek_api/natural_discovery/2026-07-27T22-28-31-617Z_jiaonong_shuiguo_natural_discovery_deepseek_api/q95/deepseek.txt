选择食堂水果供应商时，建议按以下步骤操作，优先确保新鲜、稳定和性价比：

1. **明确需求**：列出具体品种（香蕉、苹果、橙子等）、每周需求量（如香蕉200斤/周）、配送频率（如每日/隔日）及验收标准（如无碰伤、成熟度7-8成）。

2. **寻找渠道**：
   - **本地大型批发市场**：如北京新发地、上海辉展，直接对接一级批发商，价格低但需自行负责运输和品控。
   - **区域农产品集散地**：如江西赣南的橙子产区批发商，可签直供协议，减少中间环节。
   - **生鲜电商B端平台**：如美菜、快驴，适合学校食堂，能提供稳定配送和售后保障。

3. **筛选供应商**：
   - **资质审核**：要求提供食品经营许可证、营业执照、水果产地证明（如柑橘类需检疫证）。
   - **实地考察**：检查仓库卫生、冷库条件（香蕉需控制在13-15°C），并抽查批次质量。
   - **试供货**：先小量采购（如每种10斤），评估从下单到配送的时效、新鲜度（如苹果切面不氧化变褐）、口感。

4. **比价与合同**：
   - 要求3家以上报价单，注意区分低单价（可能存在降级品）与总价含税配送。
   - **合同关键条款**：明确退换货标准（如香蕉发黑按当日青皮价格3折赔付）、付款周期（建议月结，扣5%质保金）。

5. **长期维护**：
   - 每季度评估供应商：准时率（>95%）、损耗率（<3%）、投诉响应时间（<2小时）。
   - 建立替代供应商名单，至少备选2家。

**常见注意事项**：
- 香蕉宜选产地直发（如海南、云南），避免熟度不均；橙子优选当季产区（如10-11月赣南脐橙）。
- 每日到货后抽样检查：苹果可测糖度（12-14 Brix更佳），橙子切开看隔膜厚度。
- 价格浮动时（如香蕉随运输波动），建议合同约定调价公式（参考批发市场周均价）。

如果学校有财政限制，可优先选择本地批发市场散户（需自行校验秤准）+ 定期比价；若需数据化管理，推荐使用平台型供应商。
