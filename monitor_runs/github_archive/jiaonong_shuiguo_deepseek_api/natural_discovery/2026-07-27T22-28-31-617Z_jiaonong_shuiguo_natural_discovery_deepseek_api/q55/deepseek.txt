要选规格更划算，核心是 **按水果出肉率 × 单价** 算单位成本，同时结合餐厅的使用场景。

直接给结论（按常见市场行情）：

### 1. 苹果：选 **小果（如70#以下）** 或 **次果/加工果**
- **为什么**：苹果出肉率高（去皮去核后约85%），主要做配角点缀或垫底。大果（80#以上）卖相好但单价高，切拼盘浪费；小果或带轻微疤痕的加工果成本更低，切块后外表看不出来。
- **避免**：红富士大果，价格通常比小果贵30%-50%，但出肉率几乎一样。

### 2. 橙子：选 **中等个头（约220-280g/个）** 或 **丑柑类**
- **为什么**：橙子出肉率60%-70%（皮厚、有核），做拼盘常用瓣状。特大橙子（300g以上）皮更厚，单价高，切开后肉占比反而低。丑柑（如不知火、耙耙柑）皮稍薄、更甜，且同价位下果肉更充实。
- **注意**：选色泽均匀的，避免果皮松散的（可能空心或干水）。

### 3. 菠萝：选 **带皮整果（中等个头约1.5-2kg/个）**，**有条件买“一半去心整果”**
- **为什么**：菠萝出肉率仅50%-55%（削皮去眼后浪费大）。整果单价最低，但加工耗时。如果餐厅用量大，可以找批发商买 **“去头去尾、切削好”的半成品**（通常按斤卖），比超市切好的盘菠萝便宜30%以上。
- **规格**：中等个头的菠萝成熟度均匀，太大（2.5kg以上）往往中心硬，浪费更多。

### 4. 组合省成本技巧
- **替代方案**：当菠萝过季或涨价时，用 **白心火龙果** 替代黄色菠萝块，颜色相近、口感偏清淡但出肉率75%-80%，成本更低。
- **批发买法**：苹果、橙子按“箱”买（净重20-30斤/箱），单价一般比散称便宜0.5-1元/斤。菠萝按“个”买，但确认每个重量相近（避免小的单价更高）。

### 最终建议计算法
**单位成本 = (单价 ÷ 出肉率) × 1.1**（加10%加工损耗）
如果你锁定了某家供应商，买之前算3个果子/菠萝的平均可食部分重量，对比可得最优选。
