针对酒店采购水果盘原料，供应商应保证以下核心规格和外观标准：

1. **新鲜度与成熟度**：所有水果必须新鲜，无腐烂、霉变或变软现象。成熟度应适中，不过生也不过熟（如香蕉无大面积褐斑，草莓无白尖软塌）。

2. **外观完整性**：
   - **无机械损伤**：无压痕、碰伤、划痕或切口（如西瓜无裂缝，芒果无挤压黑斑）。
   - **无病虫害**：表面无虫眼、虫蛀痕迹、病斑或霉点。
   - **形状规整**：优选大小均匀，无明显畸形或严重不对称（如苹果、橙子需接近圆形）。
   - **色泽自然**：符合该品种正常颜色，无异常变色、褪色或斑驳（如葡萄应呈均匀紫黑色，青提呈黄绿透亮）。
   - **表皮洁净**：无泥土、农药残留、蜡质堆积或水分结露（需干燥无黏腻感）。

3. **规格一致性**：
   - **大小分级**：同一批次水果按重量或直径实现标准化（如草莓单颗≥15克，千禧果直径≥2cm）。
   - **包装内均匀度**：单件包装中水果个头偏差不超过±10%，避免大小混杂。
   - **成熟度同步**：若需即食，所有水果应达到相同食用状态，不得出现半生半熟。

4. **附加标准**（根据水果类型）：
   - **浆果类（蓝莓/树莓）**：无软烂、无破裂流汁，盒装无受潮变形。
   - **瓜类（西瓜/哈密瓜）**：切开后瓜瓤色泽均匀，无空洞、发白或软烂带酸味。
   - **核果类（桃子/李子）**：无果核松动、发苦或果肉褐变。
   - **热带水果（芒果/火龙果）**：无果肉黑丝（芒果）、黑芯（火龙果）或异常发酵味。

**验收建议**：到场后按10%比例开箱抽检，记分扣款——出现1个明显腐烂可扣单箱50%价格。若供应重复出现规格不一致或外观缺陷，应更换供应商或要求提供书面原料标准清单。
