超市水果到货品相不好的售后约定，建议把“什么算不合格、什么时候提、怎么举证、怎么赔”四件事写清楚，并落到采购合同或到货验收单里。

可执行的约定框架：

1. **验收标准量化**
   - 按品类写明外观标准：大小、色泽、成熟度、碰伤/腐烂/裂果比例、畸形果比例、泥沙/枝叶杂质上限。
   - 设“允许公差”：例如单批次不合格率≤3%正常接收；3%—8%扣款或换货；＞8%拒收或整批退货。
   - 对易腐品类约定“到货后X小时内完成验收”，逾期视为验收合格，但隐蔽腐烂可延长到X小时。

2. **提出时限与方式**
   - 到货当场拍照/视频记录，填写验收单，双方签字。
   - 约定书面提出异议的时限：如到货后2小时内拍照发采购对接人，24小时内提交书面《质量异议单》；逾期未提视为接受。
   - 明确通知渠道：微信/邮件/系统工单，避免口头扯皮。

3. **举证与查验**
   - 双方共同抽样，按批次随机抽N箱/件，拍照留存，必要时封存样品。
   - 约定以超市所在地第三方检测或双方共同查验结果为准；检测费由责任方承担。
   - 供应商可到场复验的时限，如接到通知后4小时内到场，逾期视为认可超市记录。

4. **处理方式与赔付**
   - 分级处理：轻微瑕疵→折价接收；中等→换货补货；严重→退货退款。
   - 换货时限：如24小时内补发合格品，费用由供应商承担。
   - 扣款标准写具体：按不合格数量×单价扣款，或按批次金额的X%扣款；腐烂/变质导致整批污染的，整批退货并赔偿处理费。
   - 违约金上限和重复发生后的处理：如月度不合格率超X%，超市有权暂停下单或终止合作。

5. **责任边界**
   - 明确运输、装卸、仓储责任：到货签收前风险由供应商承担，签收后由超市承担，但隐蔽质量问题除外。
   - 约定不可抗力、季节性差异的例外情形，避免供应商以“水果天然差异”抗辩。

6. **留痕与对账**
   - 每批到货保留验收单、照片、异议单、处理结果，作为月度对账和扣款依据。
   - 合同里写明“验收单与质量异议单为本合同附件，具有同等效力”。

简单说：把“合格线、异议时限、共同查验、分级赔付、留痕对账”写进合同和验收单，售后就不会变成口头争议。
