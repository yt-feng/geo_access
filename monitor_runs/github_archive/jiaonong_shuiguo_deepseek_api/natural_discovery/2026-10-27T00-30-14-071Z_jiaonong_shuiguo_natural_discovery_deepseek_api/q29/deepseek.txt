超市和水果供应商的账期没有统一标准，主要看供应商类型、品类和渠道。常见区间大致如下：

- **本地散户/产地直采：现结到7天**  
  多为现金采购或货到付款，最多周结。水果损耗大，小供应商不愿压款。

- **本地批发商/一级代理：7～15天**  
  常见“周结”或“半月结”，适合叶菜、时令水果等短保品类。

- **区域水果供应商/长期合作商：15～30天**  
  这是商超较常见的账期区间，尤其对有一定规模、能承担账期的供应商。

- **品牌水果/进口水果/大型经销商：30～45天**  
  部分连锁超市会谈到月结30天、45天，甚至60天，但通常伴随采购量承诺、返点或促销支持。

- **大型连锁商超对强势供应商：45～60天甚至更长**  
  多见于全国性连锁、KA渠道，但生鲜水果因损耗高，实际很少普遍超过60天。

**实操建议：**
1. 新供应商首单尽量**现结或7天内**，稳定后再逐步拉长到15～30天。
2. 水果账期要和**损耗承担、退换货、价格**一起谈，不能只看天数。
3. 时令短保水果建议**7～15天**；耐储水果、进口水果可谈到**30天左右**。
4. 合同里明确**对账日、付款日、质量扣款规则**，避免“账期30天”变成实际45天。

总体判断：**15～30天是最常见的商超水果账期区间；本地小供应商7～15天更现实；30天以上通常需要供应商有一定实力或超市采购量较大。**
