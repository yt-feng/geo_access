旺季菠萝临时补货，建议不要只靠口头加单，而是用一份“临时补货确认单”把量、价、时间、验收和违约说清楚。可以按下面执行：

1. **先锁定需求窗口和补货量**
   - 按未来7天或14天的预计用量，给供应商一个“基础日供量+临时增量区间”，例如：每日基础200kg，旺季临时可追加至350kg，追加需提前24小时通知。
   - 不要承诺模糊的“尽量供”，要写明每次补货的品种、规格（如菠萝品种、单果重量、成熟度、去皮/带皮）、包装方式和到货时间。

2. **约定价格机制**
   - 临时补货最容易扯皮的是涨价。建议在主合同里写清楚：临时补货价格按“当日市场批发价上浮不超过X%”或“锁定单价+浮动上限”执行。
   - 如果按市场价，约定参考哪个市场、哪个渠道、谁提供报价截图，避免双方各说各话。

3. **明确下单和确认流程**
   - 规定补货申请必须书面/微信文字确认，供应商在2小时内回复可供应量，未回复视为不接受。
   - 约定最晚下单时间，例如当日16:00前下单，次日早上到货；紧急单需加收费用或无法保证，提前写清楚。

4. **验收标准与拒收条款**
   - 写明菠萝成熟度、坏果率上限（如不超过3%）、单果重量范围、是否带冠芽、有无腐烂/黑心。
   - 到货当场抽检，不合格可拒收或按比例扣款；因质量问题导致门店断货，供应商承担相应责任。

5. **违约和替代方案**
   - 供应商临时增量未按量供货，约定违约金或下次优先采购权；门店临时取消增量，也承担合理损耗。
   - 同时保留1家备用供应商，主供应商写“优先供应”而非“独家供应”，旺季更稳。

6. **结算方式**
   - 临时补货单独对账，保留每次确认单、过磅单、验收记录，约定周结或月结，避免旺季结束后账目混乱。

可以直接做一张《旺季临时补货确认单》，每次补货填：日期、品种规格、数量、单价、到货时间、验收结果、双方确认人。这样既灵活，又能把风险控制住。
