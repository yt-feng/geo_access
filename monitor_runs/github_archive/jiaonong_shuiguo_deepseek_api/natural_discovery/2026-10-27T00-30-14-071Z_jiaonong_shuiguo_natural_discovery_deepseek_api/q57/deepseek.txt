建议优先选**中央厨房统一收货**，但前提是你已经具备或愿意补齐冷链、仓储和配送能力；如果门店分散、单店用量小、水果品类以易损鲜果为主，且中央厨房配送半径过长，则采用**“中央厨房统采统收 + 门店少量应急补货”**的混合模式更稳。

判断框架如下：

**1. 优先中央厨房统一收货的情况**
- 门店数量多、单店水果用量小且分散，统一收货能集中议价、统一验收标准。
- 水果主要用于中央厨房加工（切果、沙拉、饮品配料、烘焙馅料等），收货后需要分拣、清洗、切配。
- 已有冷藏库、催熟/暂存区、冷链车和按门店分拨的配送体系。
- 希望控制食品安全追溯、供应商准入和损耗责任。
- 适合品类：苹果、橙子、柠檬、西瓜、哈密瓜等相对耐储或可标准化分级的品类。

**2. 门店分开收货更好的情况**
- 水果以整果现售或门店现场鲜切为主，消费者对新鲜度、成熟度要求高。
- 中央厨房到门店配送距离远、频次低，叶菜类、浆果类、热带鲜果等易损品类经二次分拨后损耗明显上升。
- 门店有独立冷藏条件，且店长能承担验收责任。
- 单店采购量足够大，供应商可直送门店并保持价格优势。
- 适合品类：草莓、蓝莓、樱桃、荔枝、芒果、牛油果等成熟度敏感、易碰伤品类。

**3. 推荐混合模式**
- **统收统配**：耐储、标准化程度高、用于加工的品类，由中央厨房统一收货、分级、分拨。
- **门店直送**：高易损、成熟度敏感、门店现售品类，由总部锁定供应商和价格，供应商直送门店，门店按统一标准验收并上传记录。
- **应急补货**：门店保留小额应急采购权限，但设金额上限、品类白名单和事后审计，避免失控。

**4. 决策前重点算三笔账**
- **损耗账**：统收后二次分拨增加的损耗，是否低于集中采购节约的成本。
- **冷链账**：中央厨房到门店的配送频次、温控和装载率是否支撑水果品质。
- **责任账**：谁验收、谁承担损耗、谁处理客诉，必须在制度里写清楚。统收模式容易出现“中央厨房说门店保管不当，门店说收货时已有问题”的扯皮。

**结论**：如果中央厨房具备冷链和分拨能力，且水果以加工用、耐储品类为主，选统一收货；如果水果以门店鲜售、高易损品类为主，选“总部统采定价 + 门店直收验收”的混合模式，不要一刀切。
