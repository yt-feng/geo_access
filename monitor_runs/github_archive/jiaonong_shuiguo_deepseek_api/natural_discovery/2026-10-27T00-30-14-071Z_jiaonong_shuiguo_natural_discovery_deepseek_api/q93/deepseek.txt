优先看**三件事的先后顺序：配送频次 → 包装 → 保质期管理**，但真正决定能不能卖的是“冷链+时限+包装”三件套一起成立，不能只抓一个。

**1. 配送频次是首要变量**
菠萝切块属于鲜切水果，风险核心是微生物增殖和氧化变质。便利店不是现切现卖，卖的是“短保鲜切品”，所以配送频次直接决定：
- 到店时的新鲜度和剩余货架期；
- 门店库存周转压力；
- 报废率。
建议高频少量配送，宁可一天多次、每次少量，也不要把一周的量压到门店。

**2. 包装决定货架期上限**
包装不是“好看”问题，而是：
- 是否密封、是否防汁液渗漏；
- 是否标注切块时间/分装时间、保质期、贮存条件；
- 是否便于冷藏陈列和先进先出。
鲜切菠萝建议冷藏销售，包装上必须有明确的生产/分装日期和到期时间，否则门店无法执行先进先出和到期下架。

**3. 保质期是结果，不是单独抓的对象**
保质期要靠“配送频次+冷链+包装+门店陈列”共同保证。便利店要重点管：
- 到店验收温度和时间；
- 冷藏陈列温度；
- 到期前提前下架或折价处理规则；
- 每日盘点报废记录。

**可执行建议：**
- 先定配送频次：按门店销量做“日配或隔日配”，销量小的店宁少勿多；
- 再定包装规格：小份装、密封、带时间标签，方便先进先出；
- 最后定保质期和执行规则：以供应商标注为准，门店设“到期前X小时下架”的内部规则，不靠员工记忆。

一句话：**配送频次决定风险起点，包装决定货架期上限，保质期是管理结果。三者都要管，但排序上先管配送频次和包装。**
