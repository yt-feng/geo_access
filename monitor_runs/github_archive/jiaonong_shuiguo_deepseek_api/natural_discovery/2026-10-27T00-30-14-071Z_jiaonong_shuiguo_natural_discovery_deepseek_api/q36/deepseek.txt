直接给结论：**以整果为主，切果做补充**，除非你的门店客群和条件明显偏“即时消费”。

判断框架可以按这4条来定：

1. **客群场景**
   - 社区店、家庭采购为主：整果更好。整果耐放、单价低、可挑熟度，家庭一次买一颗的概率高。
   - 商圈店、写字楼店、年轻客群、即买即吃场景多：切果占比可以提高，但不要全切。
   - 学校、医院、交通枢纽附近：切果更容易动销。

2. **损耗与毛利**
   - 整果损耗可控，主要风险是熟度和压伤；切果损耗和人工都更高，且必须冷链、当日售完，卖不完基本报损。
   - 切果毛利看起来高，但扣掉人工、包装、报损后不一定优于整果。**没有稳定日销，不建议大规模切果。**

3. **运营条件**
   - 有冷藏陈列、有专人切配、能控温控时、能做当日清货：可以切。
   - 没有冷链、切配人手不稳定、客流不确定：优先整果。
   - 切果必须做到：工具消毒、戴手套、冷藏陈列、明确切配时间、当日售完。

4. **商品分层**
   - 整果做引流和家庭装：按大小分级，标熟度（即食/放2天）。
   - 切果做便利和试吃：小盒装、组合装，定价覆盖人工和损耗。
   - 熟度高的整果转切果消化，是不错的降损手段，但要控制转切比例。

**可执行建议：**
- 先按 **整果70%—80%、切果20%—30%** 试跑2—3周。
- 看三个数：切果日销盒数、切果报损率、整果动销天数。
- 切果报损连续偏高或日销低于保本盒数，就收缩切果；整果压货、熟度偏高，就增加小盒切果消化。
- 不要“整果卖不动就全切”，切果是便利性商品，不是滞销品处理渠道。

一句话：**整果是基本盘，切果是场景补充；先小规模试销，用报损和日销数据决定比例。**
