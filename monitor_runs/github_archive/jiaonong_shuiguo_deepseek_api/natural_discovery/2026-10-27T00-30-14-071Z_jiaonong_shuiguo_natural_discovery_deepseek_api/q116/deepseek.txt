小商家采购水果，现金结算和月结账期各有风险，核心区别是：现金结算主要承担“钱货两清后的质量与短斤少两风险”，月结主要承担“赊账信用、对账和现金流风险”。可以按下面判断和防范。

**一、现金结算的风险**
1. **质量与售后被动**：现场付款后，若回去发现烂果、规格不符、短斤少两，追责和换货难度较大。水果非标、易损耗，事后举证难。
2. **价格波动风险**：现金采购常是即时价，遇到行情上涨可能拿不到稳定价；遇到低价大批量囤货，又可能因损耗吃利润。
3. **现金管理和安全风险**：小额频繁现金交易，容易出现找零差错、假币、丢失，账目也不容易留痕。
4. **采购员道德风险**：如果由员工现金采购，可能出现虚报价格、拿回扣、私吞差价，老板难核验。
5. **供应商不稳定**：纯现金关系松散，旺季好货可能优先给长期合作或账期客户。

防范：坚持当场验货、过秤、拍照留样；小额多频、不要一次压太多货；用微信/支付宝/银行转账留痕，少用纯现金；采购员轮换并保留小票；和供应商约定“坏果率超过约定比例可补货或扣款”。

**二、月结账期的风险**
1. **信用与坏账风险**：月结本质是供应商给你赊账，若你经营波动或对账不清，容易拖欠、被停供，甚至影响后续采购。
2. **对账纠纷**：水果价格随行就市、损耗高，若平时没有逐笔确认单价、数量、扣损，月底容易“说不清”，供应商可能把损耗、运费、扣款都算进来。
3. **现金流错觉**：账期会让手头现金看起来宽裕，容易多进货、扩库存，但水果损耗快，卖不掉就是净亏，月底集中付款时压力大。
4. **供应商加价或捆绑**：月结供应商通常会把资金成本计入价格，或要求最低采购量、指定品种，实际单价可能高于现金价。
5. **依赖单一供应商**：长期月结容易形成依赖，一旦对方涨价、断供或收紧账期，短时间难切换。
6. **合同与票据风险**：口头月结容易扯皮，缺少书面账期、对账日、付款日、质量扣款标准，出现纠纷时小商家举证难。

防范：签简单书面协议，写明账期天数、对账日、付款日、质量扣损规则；每批货当场确认数量单价并留微信记录；每周或每旬对一次账，不要拖到月底；保留一定现金储备，不把账期当利润；月结供应商不要只留一家，至少备一个现金或短账期渠道。

**三、怎么选**
- 单次金额小、质量难追溯、行情波动大：现金或现结更稳，但必须验货留痕。
- 采购稳定、供应商可靠、你能做好对账和现金流管理：月结可缓解资金压力，但要书面化、勤对账、控库存。
- 更稳妥的是“短账期+部分现结”：比如7天或15天账期，或月结但每批货当场确认价格数量，既留现金流又不至于风险过大。

一句话：现金结算怕“货不对板后没抓手”，月结怕“账对不清、现金流失控、供应商绑死”。小商家最关键不是选哪种，而是验货留痕、逐笔对账、保留备用供应商和现金储备。
