节假日水果需求暴增，核心是**把“临时抢货”变成“提前锁量、锁价、锁品质”**。建议按下面几步做：

1. **提前做需求预测，不按平时销量备货**
   - 拉出过去2—3年同节假日的销售数据，按品类拆：礼盒果、散装果、进口果、应季果。
   - 结合今年节假日天数、天气、促销计划、门店数，做“基准量+安全库存”。
   - 重点抓爆款单品，不要所有品类平均加量，避免压货。

2. **提前锁定主供应商产能，签框架协议**
   - 节前45—60天和核心供应商谈节假日供货框架：约定品类、规格、数量区间、到货批次、违约赔付。
   - 对易缺货单品（如车厘子、阳光玫瑰、礼盒装水果）提前支付定金或预付款锁量。
   - 不要只依赖一个供应商，每个核心单品至少备2家，主供70%、备供30%。

3. **锁价但不赌死价格**
   - 对大宗常规果锁“浮动价+上限价”，避免节假日被临时抬价。
   - 对高价值礼盒果可锁固定价，但约定品质标准和拒收条件。
   - 合同中写清：节假日期间涨价需提前书面通知，超市有优先采购权。

4. **产地直采+区域批发市场双通道**
   - 大宗应季果提前对接产地合作社或一级批发商，锁“产地直发”计划。
   - 同时保留本地批发市场应急采购通道，用于补缺口。
   - 提前谈好应急调货响应时间，比如24小时内到店。

5. **提前锁定物流和仓储**
   - 节假日物流紧张，提前和承运商约定冷藏车、到货时间、卸货窗口。
   - 冷库提前预留库容，礼盒包装材料提前到仓。
   - 对易损耗水果安排分批到货，避免一次性压库。

6. **建立分级备货机制**
   - A类爆款：提前锁量70%—80%，节前3—5天到货。
   - B类常规果：锁量50%—60%，滚动补货。
   - C类长尾果：按周下单，依赖批发市场快速补。
   - 每天跟踪销量和库存，节假日期间按“日销×剩余天数”动态追加。

7. **用预售和团购反向锁定需求**
   - 节前10—15天开放水果礼盒预售、企业团购、社区团购。
   - 用预售订单量反推采购量，减少盲目备货。
   - 预售可收定金，既锁客又降低库存风险。

8. **合同里写清品质和验收标准**
   - 明确糖度、规格、成熟度、损耗率、包装标准。
   - 约定节假日到货抽检和拒收规则，避免“有货但品质不达标”。
   - 对礼盒果要求供应商提前打样确认。

**执行上最关键的三件事：节前45天启动供应商谈判，节前30天签完核心单品锁量协议，节前15天完成预售和物流确认。** 同时每天做“销量—库存—在途”三张表，缺货风险按单品红黄绿分级管理。这样既锁得住货源，也不至于压太多库存。
