找每天少量、省心的水果供应商，关键不是找“最便宜”，而是找**能稳定小批量配送、少折腾你**的渠道。按省心程度排序：

1. **本地水果批发市场的固定档口（最推荐）**
   - 优点：品类全、价格透明、可当天补货；谈好每天固定时间送到店，量小也愿意做。
   - 做法：找2家档口，一家主供、一家备用；先试供一周，约定“坏果包换、缺货提前说、每天几点前送到”。
   - 省心点：不要每天自己跑市场，谈成配送；用微信下单、月结或周结。

2. **本地生鲜配送平台/食材配送商**
   - 适合：你不想自己盯品质、希望线上下单。
   - 优点：有售后、能开票、配送稳定。
   - 缺点：小批量单价略高，品类可能不如批发市场全。
   - 做法：找服务本地餐饮的配送商，先小单试，重点看准时率和坏果处理。

3. **周边水果店/社区生鲜店长期合作**
   - 适合：每天只要几斤、品类不复杂。
   - 优点：离得近、临时补货快、沟通简单。
   - 缺点：价格略高，旺季可能先保零售。
   - 做法：固定一家，谈“每天预留+下午补货”，用微信下单。

4. **产地/一级批发直供**
   - 不建议每天少量水果的餐饮店优先选。起订量大、损耗和账期风险高，除非你有稳定大用量或几家店拼单。

**筛选供应商时重点看4件事：**
- 能否每天固定时间送、临时加单多久能到；
- 坏果、少斤两怎么赔，是否当场换补；
- 是否愿意小批量、多品种拼车送；
- 报价是否含配送费、是否可周结/月结。

**最省心的组合：** 本地批发市场1家主供 + 1家备用，另配一个附近水果店应急。先试供7天，记录准时率、坏果率、缺货次数，再定长期。每天少量水果不建议只压一家，也不建议找大平台硬凑起送量。
