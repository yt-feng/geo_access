最应该先问**售后（尤其是坏果赔付规则）**，配送和价格排在后面。

原因很直接：水果是非标、易损、高损耗品类，团购团长真正怕的不是单价高一点，而是**坏果、少斤、延迟到货后责任不清，最后团长自己贴钱、掉口碑**。价格可以谈，配送可以换，但售后规则不先说清，出一次批量坏果就可能把整团利润和信任赔进去。

建议按这个顺序问：

1. **售后优先问清**
   - 坏果率多少以内包赔？按颗、按斤还是按比例赔？
   - 签收后几小时内报损有效？需要什么照片/视频？
   - 赔现金、补货还是抵扣下批货款？补货多久到？
   - 少斤、规格不符、整批不熟/过熟怎么处理？
   - 责任边界：到货即签收，还是团长分拣后才发现也算？

2. **配送其次问清**
   - 到团点的时间窗口是否固定？迟到怎么补偿？
   - 是否冷链/防压包装？破损率历史数据多少？
   - 起送量、运费、临时加单/减单规则？
   - 谁卸货、谁分拣、异常件谁对接？

3. **价格最后谈，但要谈“到手综合成本”**
   - 不只看单价，要算：损耗率 + 赔付比例 + 运费 + 分拣人工 + 售后扯皮成本。
   - 要求供应商给近几批同品类的**实际坏果率/赔付记录**，比口头承诺有用。

一句话判断标准：**售后规则含糊的供应商，价格再低也别先大量试单；配送再快，坏果不赔就是团长兜底。** 首次合作建议小批量试单，用一两次真实售后体验再决定是否放量。
