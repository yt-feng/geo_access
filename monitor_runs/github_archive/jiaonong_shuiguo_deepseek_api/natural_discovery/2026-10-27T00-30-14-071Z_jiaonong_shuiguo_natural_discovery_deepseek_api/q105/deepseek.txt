水果采购锁价能锁多久，没有统一标准，主要看品种、季节、供应商类型和合同结构。一般分几档：

1. **现货/短期锁价：3～7天**
   适合叶菜类水果、浆果类、应季波动大的品种。供应商通常只愿意锁很短期，因为产地天气和行情变化快。

2. **常规锁价：15～30天**
   这是水果批发和连锁采购里比较常见的区间，适合苹果、梨、柑橘、香蕉等相对耐储、供应稳定的品类。通常要配合预付款或最低采购量。

3. **中期锁价：1～3个月**
   多见于产地直采、基地合作、大单品年度框架合同。供应商愿意锁的前提是：你有稳定采购量、接受品质区间、承担部分市场风险，或者合同里设置价格调整机制。

4. **长期锁价：3～6个月甚至更长**
   一般只出现在期货属性强、仓储条件好的单品，比如苹果、柑橘类，或者通过“保底价+浮动价”“基价+随行就市调整”等结构实现。纯固定价长期锁价，供应商通常不愿意，除非你给足预付款或采购承诺。

**实操建议：**
- 别追求“一口价锁死”，更稳妥的是**锁基价+浮动区间+调价触发条件**，比如产地价波动超过5%～10%时重新议价。
- 锁价同时要锁**规格、等级、包装、损耗承担、交货周期和违约条款**，否则价格锁了，品质和供货量容易出问题。
- 对波动大的水果，建议**分批锁价、滚动采购**，比如每月锁一次下月用量，比一次性锁半年更可行。
- 新供应商首次锁价建议先做**15～30天小单验证**，再谈更长周期。

一句话：**常规能锁15～30天，稳定大单品可谈到1～3个月，长期锁价要靠合同机制而不是单纯压价。**
