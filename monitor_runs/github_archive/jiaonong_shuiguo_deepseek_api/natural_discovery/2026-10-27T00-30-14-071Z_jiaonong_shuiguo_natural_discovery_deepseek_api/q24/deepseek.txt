超市采购要把“担心”变成可核查的资料，建议向供应商要这几类材料，并按批次对应：

1. **主体资质**
   - 营业执照
   - 食品经营许可证/食品生产许可证（按供应商类型）
   - 供货商与生产主体的关系证明（如经销授权、产地直供证明）

2. **批次检测报告**
   - 与到货批次对应的农残检测报告，优先要 **CMA/CNAS资质机构**出具的报告
   - 报告上要能对应：品名、产地、生产/采摘日期或批号、检测项目、检测结果、报告编号、签发日期
   - 不能只要“一份常年通用报告”，要按批次或至少按产季/供货周期更新

3. **产地与种植信息**
   - 产地证明或基地信息（地址、种植主体）
   - 若为基地直供，要种植基地备案/良好农业规范认证等资料（如GAP、绿色食品、有机认证，视采购定位）
   - 农药使用记录或投入品管理记录（能提供则更好）

4. **承诺与追溯文件**
   - 质量安全承诺书/供货质量协议，明确农残超标责任、退换货和赔偿
   - 批次追溯信息：从哪里来、何时采、何时发、运输方式
   - 快检记录（供应商自检或配送中心快检）

5. **运输与储存环节**
   - 运输车辆/冷链记录（如适用）
   - 不与有毒有害物品混运的承诺或记录

实操建议：  
- 合同中写明“每批随货提供批次检测报告或快检报告，超市有权抽检，不合格拒收并追责”。  
- 对高风险水果（如草莓、葡萄、叶菜类）提高抽检频次。  
- 收到资料后核对“报告批次=到货批次”，避免张冠李戴。  
- 保留供应商资料和抽检记录，便于监管检查和追溯。
