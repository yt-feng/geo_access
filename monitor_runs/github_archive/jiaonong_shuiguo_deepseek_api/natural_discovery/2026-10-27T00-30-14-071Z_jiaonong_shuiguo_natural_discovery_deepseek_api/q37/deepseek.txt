商超会员日水果活动，供应商要提前配合的核心是：**保量、保品、保价、保到货节奏、保现场**。可按下面清单推进：

1. **提前确认活动机制**
   - 确认会员日时间、活动单品、活动价、限购规则、预计销量/备货量。
   - 明确促销费用、折扣承担比例、损耗承担、返利或补差规则。
   - 确认是否做堆头、端架、试吃、直播、社群团购等。

2. **锁定货源与产能**
   - 活动前7—10天锁定产地/基地货量和采摘计划，避免临时缺货。
   - 对易缺货单品准备备用产区或备用供应商。
   - 大单品按预计销量的1.2—1.5倍备货，鲜度敏感品分批到货。

3. **品质标准前置**
   - 按商超验收标准提前分级：糖度、果径、色泽、成熟度、瑕疵率、农残检测。
   - 活动前3—5天发样品确认，避免到货后因等级不符拒收。
   - 明确成熟度：会员日当天售卖的要控制到“到店即适售”，不能太生或太熟。

4. **价格与费用确认**
   - 活动价、供货价、毛利空间、促销补差提前书面确认。
   - 明确运费、装卸费、损耗补贴、退货规则。
   - 避免活动前临时涨价或变相减量。

5. **包装与陈列物料**
   - 提前备好活动装、家庭装、小规格尝鲜装。
   - 包装标签、价签、产地信息、追溯码、会员日专属标识提前确认。
   - 堆头箱、周转筐、陈列道具、试吃物料按门店需求提前送达。

6. **物流与到货节奏**
   - 活动前1—2天完成首波铺货，活动当天清晨补货。
   - 按门店分货，避免大仓二次分拣延误。
   - 冷链品全程温控，易损品加隔板、防压包装。
   - 准备应急补货车辆和联系人。

7. **门店现场支持**
   - 重点门店安排促销员/理货员，负责补货、挑拣、试吃、叫卖。
   - 提前培训产品卖点、保存方法、试吃话术。
   - 高峰期协助门店快速处理次果、断货、陈列补位。

8. **售后与应急**
   - 明确质量问题响应时限，如2小时内答复、当日补货或退换。
   - 准备断货替代单品方案。
   - 活动后48小时内完成对账、损耗确认和补差结算。

**最关键的三个提前动作：**活动前7天锁货锁价、前3天送样确认标准、前1天完成首波到店铺货。供应商最好和商超采购共同做一张“会员日水果活动准备表”，逐项打勾确认，避免活动当天扯皮。
