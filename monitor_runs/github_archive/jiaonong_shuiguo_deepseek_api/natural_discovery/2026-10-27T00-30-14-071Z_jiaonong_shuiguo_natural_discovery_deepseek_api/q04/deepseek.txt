采购香蕉时，核心是**按销售节奏分批要不同熟度，并把“到货时熟度”写进采购要求**，而不是只写“要熟的/别太熟”。

可以这样要求供应商：

1. **按批次分开下熟度**
   - 未来1–2天要卖的：到货熟度 **6–7成**，表皮微黄、无黑斑，果肉稍硬，适合当天和次日销售。
   - 2–4天要卖的：到货熟度 **5–6成**，青黄相间，室温自然转熟。
   - 不要求一次性全到齐；同一车可混装不同熟度，用颜色/标签区分批次。

2. **明确到货时间**
   - 要求 **早上开门前到货**，避开午后高温和当日销售高峰后到货。
   - 每周固定到货2–3次、小批量高频，而不是一次大量囤货。
   - 节假日或高温天提前说明：到货熟度再降半成到一成。

3. **写清验收标准**
   - 到货时青黄比例、表皮无大面积黑斑、无裂口、无机械伤、果柄完整。
   - 抽查切开：果肉不应发软出水；有酒味、酸味拒收。
   - 约定“到货熟度不符可退换/降级”的条款。

4. **要求包装和运输**
   - 用透气筐/纸箱，不要密封塑料袋闷着。
   - 运输避免暴晒和挤压，码放不超过规定层数。
   - 到货后门店立即拆箱通风、分级陈列，青果和熟果分开。

5. **采购单示例写法**
   “香蕉分两批：A批到货6–7成熟，明后两天销售；B批5–6成熟，3–4天销售。每周二、五开门前到货，单批不超过预估2天销量。到货青黄相间、无黑斑裂口，熟度不符可退换。”

关键判断：**不要追求“到货刚好全熟”，而要“青熟搭配、少量多次、到货时间早于销售高峰”**，这样最能减少放坏。
