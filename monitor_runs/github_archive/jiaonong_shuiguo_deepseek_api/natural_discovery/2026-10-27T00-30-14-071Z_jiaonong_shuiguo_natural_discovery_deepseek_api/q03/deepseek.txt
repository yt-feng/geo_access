第一次试单，核心不是“找最便宜的”，而是用最小成本验证四件事：**货稳不稳、损耗多大、账期和退换是否可接受、补货是否及时**。水果尤其香蕉损耗大，建议按下面做。

## 1. 先定试单原则

- **只试 3 个单品**：香蕉、苹果、橙子各 1 箱或半箱，不要一次铺满。
- **小批量、多频次**：宁可两天补一次，也别一次压 3 天货。
- **先现金后账期**：第一次尽量现结或货到付款，别一上来谈月结。
- **同一天对比 2 家**：不要只找一家，至少对比两家报价和到货质量。
- **先看退货规则**：坏果怎么算、多久内可退、是否上门换，谈清楚再下单。

## 2. 三个单品怎么试

**香蕉**
- 试单量：1 箱，按你店 2～3 天销量估。
- 重点看：到货成熟度（青黄比例）、有没有催熟过度、果指是否饱满、断指和黑斑多少。
- 建议：第一次要“七成熟左右”，别要全黄。香蕉最怕压货，试单当天就记录软化速度。
- 问清楚：是国产还是进口、催熟方式、损耗是否包换。

**苹果**
- 试单量：1 箱，选耐放的常见品种。
- 重点看：大小是否均匀、有没有暗伤和碰压伤、口感是否脆、表皮是否打蜡过重。
- 建议：现场随机翻箱看底层，不要只看上面一层。
- 问清楚：规格（70/75/80 果等）、产地、是否分级、坏果率怎么算。

**橙子**
- 试单量：1 箱，选当季主流品种。
- 重点看：皮厚薄、酸甜度、水分、有没有霉变和软果。
- 建议：切开 2～3 个试吃，别只凭外观。
- 问清楚：产地、规格、是否催熟、保质期大概几天。

## 3. 试单当天要记录的表

每家供货商记这几项，方便第二次决策：

| 项目 | 记录内容 |
|---|---|
| 报价 | 单价、是否含运费 |
| 到货时间 | 约几点到、是否准时 |
| 外观 | 大小、颜色、碰伤 |
| 口感 | 随机试吃结果 |
| 损耗 | 当天坏果数/总箱数 |
| 退换 | 坏果是否补、多久内 |
| 结算 | 现结/账期、能否微信下单 |
| 补货 | 最小起送量、当天能否补 |

## 4. 建议的试单节奏

- **第 1 天**：找 2 家各拿香蕉、苹果、橙子小批量，当天记录。
- **第 2～3 天**：观察损耗和顾客反馈，看香蕉软化速度、苹果橙子有没有坏。
- **第 4 天**：算实际毛利和损耗率，再决定主供和备供。
- **第 1 周**：主供 1 家、备供 1 家，别把鸡蛋放一个篮子。

## 5. 第一次谈供货商要问的 7 句话

1. 最小起送量和起订金额是多少？
2. 今天下单什么时候能到？
3. 坏果、压伤、霉变怎么退换？多久内有效？
4. 香蕉成熟度能不能按我要的来？
5. 价格是随行就市还是固定几天？
6. 能不能先现结，后面再谈账期？
7. 临时补货当天能不能送？

## 6. 避坑提醒

- 不要第一次就谈月结，供货商容易把次货给新店。
- 不要只看单价，算上损耗和运费再比。
- 香蕉别一次进太多，夫妻店走量慢，宁缺勿压。
- 苹果橙子可以稍耐放，但也要翻箱检查底层。
- 供货商如果拒绝小批量试单，直接换下一家。

总结一句：**每家先拿小批量三品试 3 天，重点看损耗和退换，主供备供各留一家，第一次现结不压货。**
