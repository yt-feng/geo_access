先说结论：**按“打算几天吃完”选成熟度，并在到店前先定好采购量和用途**，比到店后反复捏更有效。

可执行做法：

1. **先定用途和吃完时间**
   - 当天或第二天吃：选**通体黄色、少量小褐斑**的。
   - 3～5天吃完：选**黄中带一点青、两端仍偏绿**的。
   - 一周左右吃完：选**整体偏青黄、没有褐斑**的，回家常温催熟。
   - 要做奶昔/香蕉面包：可买**已有较多褐斑**的，但当天用掉。

2. **到店看三处，不用反复捏**
   - **颜色**：按上面的成熟度选。
   - **两端**：发黑、发软或有霉点的不选。
   - **果柄和棱角**：果柄青绿通常更生；棱角明显也更生；圆润饱满偏熟。轻捏应**略有弹性**，一捏就凹说明过熟。

3. **按串买，别拆散挑**
   - 同一串成熟度通常接近，整串拿更不容易混进太生或太熟的。
   - 需要不同成熟度时，买**两小串**：一串偏黄现吃，一串偏青后吃。

4. **控制采购量**
   - 常温下香蕉熟得快，按**每人每天1～2根**估算，别一次买太多。
   - 夏天或室温高时，优先买偏青一点的；冬天可买偏黄一点的。

5. **回家后分开存放**
   - 偏青的常温放，别进冰箱。
   - 已熟的单独放，减少互相催熟；想延缓成熟可把果柄包住或放阴凉处。
   - 已经过熟的尽快吃掉或冷冻做奶昔。

一句话判断：**今天吃选黄带小斑，几天吃选黄带青，慢慢吃选青黄无斑；两端发黑发软不要。**
