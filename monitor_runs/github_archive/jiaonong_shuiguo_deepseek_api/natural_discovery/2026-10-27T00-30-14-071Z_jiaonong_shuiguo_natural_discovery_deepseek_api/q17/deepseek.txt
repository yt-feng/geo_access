# 社区超市水果鲜度与库存控制

核心思路：**水果是"快进快出"生意，靠周转赚钱，不靠囤货赚钱。** 控制要点分四块。

## 一、订货：按销量定，不按感觉定

- **记录每日销量**：每种水果按天记"进货量、销量、损耗量"，坚持2–3周就能看出每个品类的日均销量和波动规律。
- **订货量公式**：次日订货 ≈ 近7天同星期日均销量 × 调整系数（周末/节假日上调，雨天下调）。
- **少量多次**：叶菜类、浆果类（草莓、蓝莓）每天进；苹果、橙子、梨等耐储的可以2–3天进一次。
- **按ABC分级**：
  - A类（畅销、易烂）：草莓、葡萄、香蕉、叶菜——小批量、高频率。
  - B类（中速周转）：苹果、橙子、柚子——正常批量。
  - C类（慢销、耐储）：少量进或按订单进，避免占货架。

## 二、分级与陈列：让损耗变销售

- **按成熟度分批摆**：到货后分"即销"（已熟）和"待熟"两批，即销的先上货架，待熟的放后场或阴凉处。
- **先进先出**：新货放后面，旧货放前面，每天翻拣。
- **分级销售**：轻微碰伤的果做"特价果篮/切开果盘"，别等烂了再扔。
- **控制陈列量**：货架只摆半天到一天的销量，存量放后场，卖完再补——陈列多看起来满，但损耗大。

## 三、储存：不同水果不同待遇

- **香蕉、芒果、牛油果**：常温，不能进冷柜（会黑皮）。
- **苹果、梨**：冷藏，但**苹果会释放乙烯催熟其他水果**，要和其他水果分开。
- **草莓、蓝莓、葡萄**：冷藏、不洗、透气包装，挑出坏果再存。
- **西瓜、哈密瓜**：常温阴凉，切开后冷藏当天卖完。
- **西红柿**：常温，冷藏会失味。

## 四、库存与损耗管理

- **设安全库存线**：每个品类定"最低库存"和"最高库存"，低于下限补货，接近上限停订。
- **每天定时盘点**：闭店前查一次，记录损耗（报损原因：烂、碰伤、滞销）。
- **损耗率监控**：一般水果店损耗率控制在5%–10%较健康，超过就查订货和储存环节。
- **临期促销**：每天下午/闭店前对熟透、临期果打折或做果切，比扔掉划算。
- **快速清库存的硬手段**：搭配销售（买满送一个苹果）、切果盒、做特价堆头。

## 一句话执行清单

> 每天记销量 → 按7天数据订货 → 少量多次 → 分成熟度陈列 → 货架只摆半天量 → 每天翻拣+报损 → 临期打折清货。

坚持记录2–3周，你会发现"压在店里"的货主要是订多了或订错了品种，数据会直接告诉你该砍哪个品类。
