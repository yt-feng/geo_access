判断“能不能全年稳定供货”，不要只看供应商口头承诺，要按“产能—产地—品控—物流—合同”五层核验，并做小批量试单。

**1. 先核产地与产能结构**
- 问清香蕉来自哪些产区、各产区占比和切换月份。单一产区很难全年稳定，通常需要多产区组合。
- 要求提供种植基地/合作社名单、面积、年产量、可供应档期，最好能视频或实地看基地和包装厂。
- 看其旺季和淡季的供货量差异，要求给出过去12个月逐月供货记录或合作客户证明。

**2. 核品控与催熟能力**
- 香蕉全年稳定不仅是“有货”，还要成熟度、条果规格、色泽、伤疤、药残稳定。
- 问是否有自有或固定合作的催熟库、冷链车，催熟批次记录和损耗率。
- 要求提供农残检测报告、品控标准书，并明确到货验收指标：青果成熟度、单果重、条数/箱、机械伤比例、腐烂率。

**3. 核物流半径与应急方案**
- 香蕉怕低温也怕高温，问清运输温度、到店时效、旺季车辆保障。
- 要求说明台风、寒潮、主产区减产、节假日运力紧张时的替代产区和备用车辆方案。
- 南方到北方长距离运输，重点看其是否具备稳定冷链和途中温控记录。

**4. 用试单和压测验证**
- 先做4—8周小批量试单，覆盖正常周和节假日周，记录到货合格率、短缺率、迟到次数、损耗率。
- 突然追加10%—20%订单，看其响应速度和是否临时找货。
- 要求提供淡季月份供货承诺，并写入合同。

**5. 合同锁定关键条款**
- 写明年度/月度最低供货量、规格标准、验收不合格处理、缺货违约金、替代产区报备。
- 约定价格调整机制，避免旺季坐地起价。
- 保留第二供应商，主供占比控制在60%—70%，避免单一依赖。

**可直接问供应商的5个问题：**
1. 过去12个月每月实际供货量是多少？淡季哪几个月？
2. 主产区受灾时，替代产区在哪里、切换需要几天？
3. 催熟库和冷链车是自有还是外协？旺季能否保证？
4. 到货合格率、腐烂率、短缺率的歷史数据是多少？
5. 能否接受4—8周试单，并把淡季最低供货量写进合同？

结论：能提供“多产区+逐月供货记录+品控冷链能力+接受试单和违约条款”的供应商，才更可能全年稳定；只靠口头承诺和低价的不建议作为主供。
