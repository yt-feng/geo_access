选这类供应商，核心不是“谁家水果最好”，而是“批量配送场景下谁最稳”。建议按下面几个维度筛选和验证：

**1. 先定采购条件，再去比供应商**
- 人数与预算：按人均10–20元估算，明确总预算。
- 配送频次：一周几次、固定周几送。
- 配送地点与时间窗：公司地址、能否进楼、是否需要前台签收。
- 品种要求：是否要切配、是否要独立小包装、是否忌口（如芒果易过敏）。
- 结算方式：月结还是现结，能否开票。

**2. 优先找“有企业配送能力”的供应商，而不是纯零售水果店**
可考虑三类：
- 本地水果批发商/配送商：价格低，适合大批量，但服务和切配能力参差。
- 生鲜B2B配送平台：有企业客户服务、可开票、配送稳定，价格中等。
- 连锁水果店的企业团购/配送业务：品质稳定、售后方便，价格偏高。

**不建议**直接找菜市场摊贩或纯社区团购，批量配送和售后容易出问题。

**3. 重点验证五个能力**
- **批量供应稳定性**：能否保证每次品种、数量、成熟度一致。
- **配送准时率**：要求提供企业客户案例，问清迟到怎么处理。
- **品控与损耗**：到货坏果率承诺多少，坏果如何补赔。
- **切配与包装**：下午茶场景建议选“洗净可即食”或“切配独立装”，减少行政工作量。
- **售后响应**：有问题多久响应、是否补送。

**4. 用“小单试配”代替只看报价**
先下1–2次试订单，重点看：
- 是否准时到；
- 实际到货与样品是否一致；
- 坏果比例；
- 包装是否适合办公室分发；
- 出问题后处理速度。

**5. 合同/订单里写清楚**
品种规格、数量、单价、配送时间、坏果赔付标准、临时加单规则、发票与结算方式。批量采购最怕口头承诺。

**简单判断标准**：能稳定准时送、坏果有明确赔付、能开票、试单品质一致的供应商，优先选；只拼低价的，长期容易在品质和售后上出问题。
