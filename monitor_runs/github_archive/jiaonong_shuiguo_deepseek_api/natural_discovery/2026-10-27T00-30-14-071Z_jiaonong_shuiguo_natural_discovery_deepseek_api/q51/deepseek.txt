要固定，但不要只固定一个点，建议“固定标准 + 主辅供应 + 批次验收”。

**采购策略**
- **固定产区/品种/等级，不固定单一供应商**：水果口味波动主要来自品种、成熟度、季节和运输。锁定产区、品种、规格、成熟度区间，比单纯锁一个批次更有效。
- **主供应商 + 备选供应商**：主供占70%—80%，备选20%—30%，避免断供或品质下滑时被动换料。
- **按批次验收，不按“长期合同”放行**：每批测糖度、酸度、香气、出汁率、颜色、软硬度，设可接受区间；超区间降级、退货或调整配方。
- **固定加工规格**：如冷冻果浆、果茸、浓缩汁可显著降低鲜果波动；鲜果类则固定切割规格、成熟度和到货时限。

**运营配套**
- 建立**感官+理化验收表**，每批留样。
- 配方设**微调窗口**：糖酸比可小范围补偿，但设上限，避免掩盖劣质原料。
- 对招牌产品用**稳定性更高的原料形态**（冷冻/浓缩/复配），对强调新鲜的品类保留鲜果但缩短供应半径。

**判断标准**
如果某产地/批次连续3批关键指标稳定、门店盲测差异小，可加深合作；若批次差异导致门店投诉或配方频繁调整，就应增加备选供应或改用更稳定的原料形态。核心是固定“品质标准”，而不是固定“某一批货”。
