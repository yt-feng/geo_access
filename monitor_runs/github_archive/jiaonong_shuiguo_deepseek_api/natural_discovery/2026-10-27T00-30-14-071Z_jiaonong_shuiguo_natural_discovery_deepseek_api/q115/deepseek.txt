水果供应商客户经理响应慢，对门店经营的影响主要集中在“损耗、缺货、客诉、现金流”四条线上：

1. **生鲜损耗上升**
   - 到货质量问题（烂果、规格不符、重量不足）不能及时反馈处理，门店只能先收货或自行折价处理。
   - 退换货、补货延迟，易腐水果错过最佳销售窗口，直接报损。
   - 价格/促销资源申请慢，门店无法及时做折价清货，损耗扩大。

2. **缺货与销售损失**
   - 临时加单、调货、替换品种响应慢，热销品断货，顾客转购竞品。
   - 节假日、周末备货窗口错过，错过高峰销售。
   - 新品/季节性商品上架延迟，陈列和营销计划被打乱。

3. **客诉与口碑受损**
   - 顾客买到质量问题水果后，门店因供应商处理慢无法快速赔付或补发，客诉升级。
   - 缺货或品质不稳定导致复购下降，影响门店生鲜口碑。

4. **现金流与对账风险**
   - 退货、折让、费用核销确认慢，账期对账拖延，占用门店资金。
   - 价格变动、促销补贴确认不及时，容易产生结算争议。
   - 长期响应慢会迫使门店增加安全库存，进一步压占现金流。

5. **运营效率与员工负担**
   - 店长/采购反复催单、追问题，管理时间被消耗。
   - 门店被迫临时找替代供应商，采购成本和不稳定性上升。
   - 内部排班、陈列、促销计划频繁调整，执行混乱。

**可执行判断标准：** 若客户经理对常规问题超过半天未回复、紧急缺货/质量问题超过2小时未响应，且月度发生3次以上，就应视为服务风险，启动备选供应商或升级到供应商管理层。
