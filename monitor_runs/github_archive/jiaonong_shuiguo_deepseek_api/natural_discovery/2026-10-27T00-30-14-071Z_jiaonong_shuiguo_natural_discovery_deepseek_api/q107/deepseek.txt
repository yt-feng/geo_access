会，而且香蕉和菠萝的损耗风险不一样，要分开看。

**香蕉：起订量高，损耗风险明显更高**
- 香蕉是呼吸跃变型水果，到货后还会继续成熟，销售窗口短。
- 起订量高会带来集中催熟、集中上架，一旦动销慢，很容易从“黄熟”变“过熟发黑”。
- 如果冷链、催熟库位、货架陈列能力跟不上，高起订量会直接放大损耗。
- 建议：按日销量或3～5天动销测算起订量，优先小批量高频补货；宁可贵一点拿小包装，也不要一次性压大货。

**菠萝：起订量高，损耗风险中等但更可控**
- 菠萝相对耐储，完整果比香蕉好放，但高起订量仍会带来占库、老化、黑心、霉变和周转压力。
- 如果是鲜切菠萝，损耗风险会显著上升，因为切后果肉保质期很短。
- 建议：整果可按7～10天动销预估，鲜切按1～2天动销预估；高起订量时优先做整果，不要轻易转鲜切。

**判断是否增加损耗，看四个条件：**
1. 你的日均销量和起订量能覆盖几天？
2. 仓储温湿度、通风和催熟条件是否匹配？
3. 补货频率能否做到小批量、多频次？
4. 有没有降价促销、加工转化如果切/果切/果汁的出口？

**结论：**
起订量太高会增加损耗风险，香蕉尤其明显，菠萝次之但也不能忽视。采购时不要只看单价便宜，要算“采购价+预计损耗+资金占用”。如果起订量导致香蕉覆盖超过3～5天销量、菠萝整果超过7～10天销量，就要谨慎；鲜切菠萝超过1～2天销量则风险偏高。
