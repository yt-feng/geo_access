可以，但要看品类、采购量、合作关系和促销形式。多数供应商对周末促销会有条件支持，常见是价格折让、赠品、陈列物料、试吃物料，而不是无条件返点。

**可执行判断：**

1. **先看供应商类型**
   - 一级批发商/产地直供：价格支持空间较大，但通常要求起量或提前报备。
   - 二级批发/本地配送商：更可能给物料、赠品、陈列支持，直接降价空间小。
   - 品牌水果/包装果：可能有品牌方或经销商的活动物料、试吃、买赠支持。

2. **周末促销可争取的支持**
   - **价格支持**：针对1—2个引流单品做周末特价，要求供应商给“促销价”或“阶梯返利”，不要全店普降。
   - **物料支持**：海报、价签、堆头围挡、试吃盒、试吃签、购物袋、帐篷/遮阳伞等。
   - **赠品/买赠**：小果、次果、试吃装、关联品搭赠。
   - **账期/退换**：生鲜损耗大，可谈促销期间滞销品换货或部分损耗补偿。
   - **人员支持**：大供应商偶尔可派促销员或试吃员，但水果店规模小一般较难。

3. **谈判时怎么说**
   - 提前3—7天报备：“本周六日做周末引流，计划主推XX单品，预计采购量比平时增加X%，能否给促销价/物料/试吃支持？”
   - 给对方明确回报：堆头位置、价签露出、店员主推、朋友圈/社群宣传。
   - 不要只问“能不能便宜”，要问“我做到多少量，你能给什么支持”。

4. **注意**
   - 口头支持要落到微信文字：价格、数量、物料清单、送达时间、退换条件。
   - 不要为拿支持压过多库存，水果损耗高，周末促销单品控制在2—3个。
   - 如果供应商不支持，可改为“供应商出赠品/物料，门店出流量和陈列”的轻合作。

总体：**能谈，但通常是“有条件支持”**。优先谈引流单品的促销价和物料，比直接要现金返点更容易成。
