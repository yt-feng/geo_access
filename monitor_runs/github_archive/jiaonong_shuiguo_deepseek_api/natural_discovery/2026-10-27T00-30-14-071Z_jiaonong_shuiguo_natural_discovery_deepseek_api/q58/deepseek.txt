直接买成品果丁的损耗通常更低，但要看“损耗”怎么算。

**结论：**
- **只算门店端损耗**：成品果丁更低。门店不用去皮、去眼、切配，几乎只剩拆袋和少量氧化/过期损耗。
- **算全链条综合成本**：要比较“鲜果出成率+人工+冷链+报废”。鲜果如果出成率低、人工贵、当天卖不完，成品果丁往往更划算；如果鲜果出成率高、销量稳定、人工便宜，鲜果可能更省。

**判断方法：**
1. 称重测鲜果出成率：菠萝毛重 → 去皮去眼切丁后净重，算出成率。
2. 算鲜果真实成本：`毛重单价 ÷ 出成率 + 切配人工分摊 + 报废成本`。
3. 算成品果丁真实成本：`采购单价 + 解冻/沥水损失 + 开封后报废 + 冷链占用`。
4. 只看损耗率：成品果丁通常占优；看总成本：用第2、3项对比。

**实操建议：**
- 甜品店用量小、切配人手少、要求规格统一：**优先成品果丁**。
- 用量大、当天能卖完、有熟练切配人员：**鲜果可能更省**。
- 无论选哪种，都要记录3天实际出成/报废数据再定，不要只凭经验。
