找水果供应商，先看能不能达到“每天稳定配送”的底线，再看价格。建议按以下顺序筛选：

**一、配送能力（最优先）**
1. **是否有每日配送线路覆盖你所在区域**：直接问“到我这个地址，每天几点前能到？一周几配？临时加单怎么算？”。
2. **配送时间是否匹配你的营业**：社区超市一般早上开门前到货最好，问清是凌晨配、早市配还是下午配。
3. **缺货/补货响应**：当天卖断货能否补、补货截止时间是几点、补货是否加运费。
4. **车辆和冷链**：叶菜、浆果、切果类是否冷藏车或保温箱配送；夏天没有冷链，损耗会很高。
5. **起订量和配送费**：每天配送往往有最低起订额，低于起订额是否加收配送费，要算进毛利。

**二、货源与品质稳定性**
1. **货源结构**：是产地直采、一级批发市场代采，还是二级批发转手。社区超市单店量不大，找“批发市场代采+稳定档口”往往比硬追产地直采更现实。
2. **每日到货批次是否稳定**：连续观察几天同品类的规格、熟度、大小是否一致。
3. **损耗处理**：坏果、烂果、重量不足怎么赔，是下次补货抵扣还是当场退换，要写清楚。
4. **农残检测/合规**：能否提供检测报告或进货凭证，至少要有可追溯的进货票据。

**三、价格与结算**
1. **报价方式**：是每日随行就市报价，还是一周/一月锁价；锁价品类通常只有少数耐储果。
2. **是否含税、含运费、含损耗**：把“到店可售成本”算出来再比价，不要只看单价。
3. **账期**：日配供应商常见现结或周结，能接受短账期的优先；押款太重的供应商后期容易断供。
4. **价格调整机制**：节假日前、天气异常时怎么调价，提前约定。

**四、商品结构匹配**
1. **能否覆盖你的常卖品**：苹果、香蕉、柑橘、梨等引流果，以及叶菜类、时令果。
2. **规格是否适合社区店**：小包装、散装、整箱比例，是否支持你按需拆箱。
3. **是否愿意做少量多品**：社区超市单品类量小，供应商能否接受“多品种、小批量、每日配”。

**五、实地验证（建议必做）**
1. 让对方连续送3—5天小批量试单，记录到货时间、损耗率、缺货率。
2. 去对方档口或分拣点看一眼，确认不是临时拼货。
3. 问2—3家同类社区超市该供应商的口碑，重点问“断供过没有、坏果赔不赔”。

**谈判时可直接问的清单：**
- 每天最晚几点下单、几点到店？
- 低于起订额加多少配送费？
- 坏果损耗赔付标准是什么？
- 节假日是否正常配送？
- 能否先试配一周？

**判断标准：** 先选2家能每日配、赔付清楚、试单损耗低的供应商，各占一部分品类，避免单供应商断供。价格放在第二位，日配水果的核心风险是断货和损耗，不是单价差几毛。
