# 门店多、单店量小：适合的水果供货模式

## 先判断你的核心矛盾

店多单店量小，意味着**每个SKU在每个店的需求都很零散**，但汇总起来总量未必小。所以关键不是"找大供应商"或"找小供应商"，而是解决两件事：

1. **集单能力**：能不能把多店需求汇总成一张有议价力的订单
2. **配送颗粒度**：供应商愿不愿意按店、按小批量、高频次送货

## 适合的几种模式（按推荐优先级）

**① 区域批发市场＋统采分拨（最现实、门槛最低）**
- 在本地一级批发市场找2–3家档口做"主供＋备供"，由你方或第三方做分拣、按店配送。
- 谈法：按周报量、按日下单，档口给"量价挂钩"的阶梯价；你自己承担或外包城配。
- 适合：门店集中在一个城市、单店日销几十到几百公斤。

**② 产地/基地直采＋城市分仓（量大后升级）**
- 当汇总日销量稳定（比如单品单日过吨），直接对接产区合作社或代采商，进城市分仓再配店。
- 前提：必须有分仓或中转点，否则单店量小会被配送成本吃掉利润。

**③ 区域水果配送商/供应链公司（省心型）**
- 找专做"多店小批量配送"的本地生鲜供应链商，一站式供货、按店配送、账期可谈。
- 代价：单价通常比批发市场高5%–15%，但省人省车省损耗，单店量小时反而划算。
- 适合：门店分散、自己没有分拣配送能力。

**④ 供应商联营/代销（降低损耗风险）**
- 对叶菜、浆果等易损高损耗品，让供应商以"联营、卖不完退换"方式供货，你只承担部分损耗。
- 适合：损耗难控的品类先试水。

**⑤ 多店拼单＋集中订货日（组织手段，不是供货商）**
- 固定每周2–3个订货日，各店统一报量、供应商一次送、你分拨到店。用"频次换价格"。
- 这是所有模式的基础动作，先把订单聚起来才有议价权。

## 不建议的做法

- **每店单独找小贩供货**：价格高、品质不稳、对账乱。
- **一开始就自建产地直采+自配送**：单店量小、门店多，配送成本会先把你拖垮。
- **只找一家独家供应全品类**：水果品类差异大，单一供应商难做好所有品，且议价被动。

## 落地建议（可直接执行）

1. **先跑2周数据**：统计各店销量前20个SKU的日销量、损耗率。
2. **按品类拆供货**：主销大单品（苹果、香蕉、柑橘）走批发市场统采或产地直采；高损耗品走配送商或联营；长尾小众品走批发市场现采。
3. **选2家主供＋1家备供**，签"周报量、日下单、阶梯价、损耗责任"条款。
4. **建一个集单机制**（微信群/订货表/轻量系统），固定截单时间，先集单再送货。
5. **算清"到店成本"**：单价＋配送分摊＋损耗，三者加起来比较，别只看进货价。

**一句话结论**：门店多单店量小，优先用"区域批发市场统采＋自己分拨"或"本地多店配送型供应链商"，先把多店订单聚起来换议价权；等某几个单品日销稳定过吨，再逐步升级到产地直采＋城市分仓。
