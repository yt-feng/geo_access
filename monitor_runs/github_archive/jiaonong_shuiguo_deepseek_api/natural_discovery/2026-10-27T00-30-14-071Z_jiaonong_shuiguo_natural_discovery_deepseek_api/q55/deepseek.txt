选规格的核心是“按出成率和用途买，不按单价买”。水果拼盘要优先算可食用部分成本，而不是整箱/整果单价。

**苹果**
- 拼盘常用：中果到中大果，单果约180–250克更稳。太大切出来份量难控、边角料多；太小削皮去核后出成率低。
- 采购看：果径和单果重都要问，别只问“80果/85果”；优先选果形周正、无碰伤。拼盘用可以选二级果/统货，但碰伤、软果比例要控制在很低。
- 划算判断：按“去皮去核后每100克成本”比较，通常中果统货比精品大果更适合拼盘。

**橙子**
- 拼盘常用：中果，单果约150–220克，皮薄、易剥、汁水足。太大切瓣显得粗，太小剥皮损耗高。
- 采购看：问清是净重还是毛重、箱内坏果率。拼盘建议选外观一般但新鲜度好的统货，不必追礼品级。
- 划算判断：橙子出成率受皮厚影响大，先小批试剥，算“剥皮后每100克成本”，比整箱价更有意义。

**菠萝**
- 拼盘常用：中等果，单果约1–1.5公斤更合适；太大一次用不完、氧化和损耗高，太小削皮去眼后出成率低。
- 采购看：拼盘可用鲜切菠萝原料或标准规格菠萝，重点看成熟度和去眼损耗。若门店量大，直接对比“鲜切菠萝净料成本”和“整果自削成本”，把人工算进去。
- 划算判断：整果自削只有在人工低、量大、当天用完时才划算；否则鲜切净料更稳。

**通用采购建议**
1. 先定每份拼盘的水果克重和切法，再反推单果规格，避免“大果切小份”浪费。
2. 苹果、橙子可买统货/二级果做拼盘，但坏果率要低；菠萝优先看净料出成率。
3. 每次到货抽3–5个称重、去皮去核测出成率，记录“净料成本/100克”，连续对比2–3批再定长期规格。
4. 小批量试规格：同一品种同时试中果和大果各一箱，按净料成本和切配效率选，不要只看整箱报价。
