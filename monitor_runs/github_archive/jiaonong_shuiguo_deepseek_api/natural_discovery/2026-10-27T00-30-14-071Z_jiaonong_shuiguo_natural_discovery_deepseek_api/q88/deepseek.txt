线上水果最怕差评，核心不是“买到最好的果”，而是“把不可控的鲜果变成可预期的商品”。采购端建议抓四件事：

1. **先定分级标准，再谈采购价**
   - 按品种写清收货标准：单果重/直径、糖度下限、酸度上限、软硬度、着色率、瑕疵面积上限。
   - 把“坏果率”“口感不稳定”拆成可验收指标，比如：到货坏果≤2%，糖度抽检合格率≥95%，同批次糖度极差≤2度。
   - 没有标准的供应商只会按“统货”给你，差评是必然的。

2. **产地和批次要集中，不要频繁换货**
   - 同一品种尽量固定2—3个主产区、固定合作社/代办，减少“这批甜下批酸”。
   - 要求供应商按批次记录：采摘时间、天气、成熟度、预冷时间、运输方式。
   - 雨天采摘、未预冷、长途常温运输的批次，口感波动和坏果风险明显更高，采购时要避开或降级。

3. **成熟度采购，不要采购“全熟到货”**
   - 线上销售有物流时间，采购应按“到达消费者时最佳”倒推成熟度，而不是按产地全熟采购。
   - 易软烂品种（如水蜜桃、草莓、蓝莓、芒果）优先选七至八成熟、耐运输的批次，并做小批量到货测试。
   - 对后熟型水果，明确催熟/回温方案，否则消费者收到“硬得不能吃”或“到手已烂”都会差评。

4. **到货验收和抽检必须制度化**
   - 每批到货抽检：外观、坏果、糖度、口感、重量，留样拍照。
   - 设置“首件试销”：新供应商/新批次先小批量卖，看退货率、差评关键词、复购，再放量。
   - 对坏果率超标的批次直接拒收或降级做活动款，不要混入正价链接。

另外，采购只能降低一部分风险，售后策略也要配套：坏果包赔、按比例赔付、差评回访。采购端把“批次可追溯+分级验收+小批试销”跑顺，坏果和口感不稳定会明显下降。
