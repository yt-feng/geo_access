社区超市卖小包装香蕉，采购和包装重点抓这几件事：

1. **按成熟度分批采购**
   - 小包装周转慢，别一次全拿同一成熟度。
   - 采购时选“青黄之间”的为主，少量拿已经可售的黄熟蕉；青蕉在店催熟或自然转黄，减少到店即烂。
   - 要求供应商按成熟度分级，不要混装。

2. **包装规格别太小、别密封**
   - 常见做 **2—3 根/袋** 或 **400—600g/盒**，太小单袋成本高、也不好标价。
   - 用**打孔保鲜袋**或透气膜，别用完全密封袋，香蕉呼吸产生水汽，闷袋容易发黑、长霉。
   - 盒装留透气孔，袋装不要扎得太紧；标签贴在袋面，不直接贴果皮。

3. **尽量整把分包，减少切口**
   - 香蕉按“把”分装，少切段；切开的果肉易褐变、流汁，损耗明显。
   - 必须切段时，刀具清洁，切口尽快售出，不做长保质期陈列。

4. **采购时控制单次量和批次**
   - 小包装按 **1—2 天销量** 下单，宁少勿多，勤补货。
   - 同一批到货做颜色标记或先进先出，先卖黄熟的，青的放后场转色。
   - 采购合同里约定到货成熟度、机械伤和霉变率，超标的拒收或换货。

5. **运输和收货防压伤**
   - 香蕉怕压、怕冻、怕闷。整箱运输别堆太高，避免重物压。
   - 收货检查：果指有无压伤、裂口、黑斑扩散、霉点；箱内有无水汽。
   - 夏季避免高温闷车，冬季避免冷风吹，受冷后表皮发黑、果肉难熟。

6. **陈列和损耗管理**
   - 小包装不要堆叠挤压，单层或少量叠放。
   - 黄熟蕉放显眼快销位，青蕉后场或阴凉处转色，别混在一起。
   - 每天挑出黑斑、软烂、破袋的，及时折价或下架，避免污染其他袋。
   - 记录每天销量和报损，按实际动销调整采购规格和数量。

简单说：**采购按成熟度分批、单次少量；包装要透气、整把、2—3根小规格；运输防压防闷；陈列先进先出、勤挑损。**
