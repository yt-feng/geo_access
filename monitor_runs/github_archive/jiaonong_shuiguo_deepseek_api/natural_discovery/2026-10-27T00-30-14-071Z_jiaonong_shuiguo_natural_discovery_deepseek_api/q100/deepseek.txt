# 学校食堂采购香蕉：避免熟过头浪费的实操建议

核心思路是**控制"到货成熟度"和"到货后的熟化速度"**，而不是等到快坏了再处理。具体可按下面几点执行：

## 1. 采购环节：按成熟度下单，不只看数量

- **明确要求到货成熟度**：优先采购"绿黄期"（果身大部分偏绿、仅两端转黄）或"黄绿期"（约3–4成黄）的香蕉，避免采购已大面积变黄、出现黑斑的货。下单时把成熟度要求写进采购单或验收标准。
- **按消耗节奏分批到货**：香蕉在常温下3–5天就会从"可吃"走向"过熟"。按食堂每天实际用量，把一次大批量改成**每周2–3次小批量**到货，宁可频次高、单次少。
- **结合供应渠道**：如果供应商只能给成熟度偏高的货，可要求其提供"催熟程度较低"的批次，或改从能控制成熟度的批发渠道进货。

## 2. 验收环节：当场用标准卡住

- 制定简单的**验收标准**：果指饱满、无大面积黑斑、果柄青绿、手感偏硬。成熟度过高或已有软烂、异味的直接拒收或折价。
- 验收时**抽检箱内中层和底层**，香蕉堆压处最容易闷熟、发黑。

## 3. 储存环节：控温、控乙烯、控挤压

- **温度**：香蕉怕冷，**不宜放冰箱冷藏**（低于12℃会冻伤发黑）。常温阴凉通风处存放即可，理想约13–15℃。
- **通风与分散**：不要整箱闷着堆叠，开箱、分筐、留出通风间隙，降低堆内温度和乙烯浓度。
- **隔离乙烯源**：香蕉自身释放乙烯会催熟周围果实，**不要和苹果、梨等一起堆放**；成熟度不同的香蕉也尽量分开放。
- **悬挂或单层摆放**：减少受压面积，避免压伤处先烂。

## 4. 使用环节：先熟先出，动态调整菜单

- **先进先出、熟者先出**：每天检查，把最熟的先用于当餐（直接分发或做香蕉牛奶、香蕉粥等），避免"总拿新的、旧的烂掉"。
- **按成熟度分流用途**：偏熟的香蕉可用于加工类菜品（如香蕉饼、奶昔、烘焙），减少直接售卖时的品相损失。
- **建立日消耗台账**：记录每天领用和剩余，据此调整下次订货量，形成"消耗—采购"闭环。

## 5. 兜底处理

- 对已过熟但仍可食用的香蕉，及时转做加工品或员工餐，不要等到变质。
- 与供应商约定**少量多次、可退换**的条款，降低单次压货风险。

**一句话总结**：把住"到货别太熟、到货后勤通风、按成熟度先熟先出、小批量高频次采购"这四关，基本能显著减少熟过头浪费。
