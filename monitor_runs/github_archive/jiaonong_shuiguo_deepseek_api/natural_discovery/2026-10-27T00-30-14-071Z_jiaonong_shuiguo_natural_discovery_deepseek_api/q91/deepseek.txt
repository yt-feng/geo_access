建议优先上架**单根散卖 + 小把（3~5根）为主，整袋只做补充**，具体看门店客群。

可执行判断：

1. **单根最适合便利店**
   - 便利店核心是“即时消费、低决策成本”，单根适合当早餐/加餐顺手买。
   - 降低顾客尝鲜门槛，减少“买多了吃不完”的顾虑。
   - 缺点是损耗和称重/贴标工作量高，需选外观较好、大小均匀的香蕉。

2. **小把（3~5根）作为主力组合**
   - 适合家庭少量购买、办公室分享。
   - 比整袋更容易控制成熟度和损耗。
   - 建议固定规格、明码标价，避免现场称重拖慢收银。

3. **整袋谨慎上**
   - 只适合社区型、家庭客群明显、客流稳定的门店。
   - 整袋容易因成熟度不一致、顾客吃不完而滞销，香蕉又极易过熟变黑。
   - 若上整袋，建议小规格（如5~6根）、透明或半透明包装，标注成熟度/食用建议。

4. **实操建议**
   - 初期按 **单根50%、小把40%、整袋10%** 试销1~2周。
   - 每天记录销量、报废量、客单价，按“售罄率+损耗率”调整。
   - 香蕉按成熟度分级：偏绿放小把/整袋，熟度高的拆单根快速卖。
   - 单根可放在收银台附近或早餐组合区，小把放果蔬架，整袋放社区店入口冷藏/常温果蔬区。

结论：**便利店香蕉以单根和小把为主，整袋只做少量补充；不要一开始就主推整袋。**
