大型超市（商超/连锁卖场）对水果供应商的要求，通常按“**准入资质—食品安全体系—冷链与物流—追溯与召回—交付与应急**”五个方面审查。下面按可执行标准列出。

## 一、必须的证照与准入资质
1. **营业执照**，经营范围含水果种植/收购/销售或农产品供应链。
2. **食品经营许可证**（若供应商自行分拣、包装、销售预包装或切果）；仅销售初级农产品按当地监管要求执行，但商超一般仍要求提供。
3. **种植/养殖端证明**：基地证明、合作社协议、收购合同；外采需提供产地证明或购销凭证。
4. **检验检测报告**：农残、重金属等按品类和商超标准提供，通常要求**批次检测+年度全项检测**。
5. **从业人员健康证**（接触直接入口或分拣包装人员）。
6. **包装材料合规证明**（食品级接触材料检测报告）。
7. 进口水果需**入境货物检验检疫证明、报关单**等。

## 二、食品安全管理能力
1. **可执行的食品安全管理制度**：供应商审核、进货查验、农残控制、虫害防治、卫生消毒、不合格品处置、召回制度。
2. **农残与污染物控制**：有基地用药管理、安全间隔期管理；能按商超要求提供第三方检测或快速检测记录。
3. **分拣包装场所合规**：地面墙面易清洁、防鼠防虫、通风温控、清洁消毒记录、人员卫生管理。
4. **不合格品与客诉处理**：有隔离、销毁/退货记录和原因分析。
5. **追溯与召回**：能做到**批次可追溯到产地/地块/收购商**，并在约定时限内完成下架召回。
6. 最好具备**ISO 22000、HACCP、GAP/GGAP、BRCGS**等体系认证；大型商超常将其作为加分或准入门槛。

## 三、冷链与物流能力
1. **冷链温控**：按品类设定温度（如叶菜/浆果冷藏、热带水果防冷害），运输车辆有**温度记录仪和全程可回放记录**。
2. **仓储能力**：冷藏库、保鲜库、分拣区，温湿度监控和异常报警。
3. **运输合规**：食品运输车辆清洁消毒记录，**不与有毒有害物品混装**；周转筐清洁和分区管理。
4. **配送时效与履约**：能按商超DC（配送中心）或门店约定频次、时段送货，具备订单履约率和缺货率管理。
5. **包装与损耗控制**：适合商超陈列的包装规格、防压防潮、先进先出；有损耗率数据。
6. **信息化能力**：订单、库存、批次、温度、检测报告可电子化对接；能提供送货单、批次码、检测报告随货或线上可查。

## 四、交付与应急能力
1. **产能与稳定性**：多产地/多基地备份，能应对季节和天气波动。
2. **应急保供方案**：缺货替代、临时调货、疫情/灾害预案。
3. **质量异常响应**：客诉和抽检不合格的响应时限、赔偿与整改机制。
4. **保险与责任**：食品安全责任险通常为加分项，部分商超要求。

## 五、商超现场审核常见“一票否决”项
- 无证经营或证照过期；
- 农残检测不合格或无法提供批次检测；
- 冷链断链且无温度记录；
- 无法追溯批次来源；
- 分拣场所严重卫生/虫害问题；
- 使用非食品级包装或违规保鲜剂。

**结论**：大型超市水果供应商的底线是“**证照齐全+批次可检测+冷链可记录+批次可追溯+不合格可召回**”；在此基础上，体系认证、多基地保供和信息化对接决定能否进入核心供应商名单。不同商超标准不同，实际准入以其《供应商准入审核表》和《生鲜商品质量标准》为准。
