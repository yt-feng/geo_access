# 坏果责任条款怎么写：给批发商的实操建议

## 先定核心思路：按"损耗率分级 + 举证责任"设计，不要写"坏了谁赔"这种模糊表述

生鲜到货损耗不可能为零，合同的关键不是追求"全赔"，而是**划出一条合理的容忍线，线内自担、线外追责，并明确怎么算、谁来证明**。

---

## 一、必须先写清的四个要素

**1. 损耗率与计价基数**
- 明确"损耗率 = 坏果数量 ÷ 到货总数量"，并约定**以合同约定的验收标准（品类、等级、成熟度、单果规格）为判断坏果的依据**。没有验收标准，"坏果"就是各说各话。
- 写清计数方式：按件/箱抽检还是全检、抽样比例多少、抽样不合格时是否整批按比例折算。

**2. 分级责任（分段计价，最实用）**
建议设三档，直接在合同里写成公式：
- 损耗率 ≤ 约定容忍线（如3%，按品类定）：买方自担，不追责；
- 容忍线 < 损耗率 ≤ 上限（如10%）：超出部分按数量折价扣款；
- 损耗率 > 上限：买方有权拒收该批，或整批按约定折扣结算，运费/装卸费由卖方承担。

**3. 验收与异议期限**
- 写明到货后多少小时内完成验收（生鲜通常24小时内，易腐品可更短），**逾期未提异议视为验收合格**——这一条对批发商是双刃剑，但能避免事后扯皮，建议保留。
- 异议必须书面（含微信/邮件等可留痕方式）+ 附照片/视频/第三方记录，否则不成立。

**4. 举证与检验**
- 约定：坏果争议以**到货当场拍照录像 + 双方在场确认**为准；一方拒不到场，另一方可单方记录并视为有效。
- 大额批次可约定送第三方检测或由市场管理方见证，费用由责任方承担。

---

## 二、条款示例（可直接改写进合同）

> **第X条 到货质量与坏果责任**
> 1. 卖方交付货物应符合附件《验收标准》约定的品类、等级、成熟度及单果规格。
> 2. 买方应在到货后24小时内完成验收，并以书面方式（含微信、电子邮件）提出质量异议，附照片或视频；逾期未提出的，视为验收合格。
> 3. 经确认的坏果率不超过3%的，由买方自行承担；超过3%至10%的部分，按该部分货物对应价款从应付货款中扣减；超过10%的，买方有权拒收该批货物，卖方应退还已收货款并承担该批货物的往返运费。
> 4. 坏果率以抽样检验结果按比例折算全批计算，抽样比例为每批随机抽取不低于5%的箱数。
> 5. 双方对坏果数量有争议的，以到货当场共同确认的记录为准；一方经通知拒不到场的，另一方单方留存的影像记录可作为认定依据。

---

## 三、批发商要额外注意的坑

- **别只写"卖方保证无坏果"**：这种绝对化条款在生鲜领域几乎无法执行，反而在诉讼中容易被认定约定不明。
- **扣款要挂钩具体金额**：写"按比例扣减货款"而不写基数，容易算不清。
- **拒收权要配运费条款**：否则拒收后货压在车上，损失谁承担会吵起来。
- **产地/运输环节责任要分清**：如果是买方自提或指定物流，途中损耗责任归属要单独约定，别一股脑算给卖方。
- **保留批次追溯**：约定每批货带产地、采摘日期、装箱单，便于事后定责。

一句话总结：**用"验收标准 + 损耗率分级 + 时限内书面异议 + 影像举证"四件套，把坏果责任变成可计算、可执行的条款，而不是一句笼统的承诺。**
