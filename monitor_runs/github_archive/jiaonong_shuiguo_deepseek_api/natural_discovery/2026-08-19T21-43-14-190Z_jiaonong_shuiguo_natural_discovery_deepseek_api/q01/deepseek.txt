判断水果供应商是否靠谱，不能只看价格，要**“看人、看货、看流程”**。结合你长期进香蕉和菠萝这两个品类的特点，我给你几条实操性强的判断标准：

**一、 核心看“货”——针对香蕉和菠萝的特性**

1.  **香蕉（需催熟，损耗高）：**
    -   **看成熟度分级：** 靠谱的供应商不会给你全青的或全黄的。香蕉要进“黄绿相间”的，并且能明确告诉你这批货是几成熟（比如7成熟），以及到店后几天能自然变黄。
    -   **看催熟工艺：** 直接问“是树上熟还是乙烯催熟？”或者“到货后需要放几天？”如果对方支支吾吾，或者承诺“今天进明天就黄”，那你到手可能全是烂的。
    -   **看把与把之间的缝隙：** 现场验货时，看香蕉的“把柄”是不是发黑、发粘。发黑说明在冷库里放久了，容易整把腐烂。

2.  **菠萝（易发霉，切口易变质）：**
    -   **看底部切口：** 这是最关键的。新鲜菠萝底部切口应该是**白嫩、湿润、无黑点**的。如果切口发黑、干瘪、有霉斑，说明已经放了很久。
    -   **看芽眼和果肉颜色：** 芽眼凹陷处如果发黑，内部可能已经变质。可以要求开一个“样品果”看果肉颜色（金黄且无黑心）。
    -   **看产地和季节：** 靠谱供应商会主动告诉你当前菠萝的产地（如海南、徐闻、菲律宾）和当季口感（偏酸还是偏甜），而不是笼统说“好货”。

**二、 核心看“人”——供应商的“软实力”**

3.  **问清“损耗赔付”规则：**
    -   不要问“坏了包赔吗？”，要问**“如果到货拆箱，坏果率超过5%怎么算？是当场折价、换货还是下次抵扣？”** 靠谱的供应商敢明确给你书面（微信聊天记录）承诺具体赔付比例，不靠谱的只会说“你放心，我这边货很好的”。

4.  **试探其“行情专业性”：**
    -   问一句：“最近菠萝产地收购价跌了，你们批发价降了吗？”或者“最近雨天多，香蕉催熟时间是不是要延长？”
    -   靠谱的供应商会跟你聊天气影响、产地行情、运输物流，甚至建议你**“这周菠萝别多进，暴雨容易水烂”**。如果对方只会说“都便宜，你多拿点”，那他就是单纯的搬运工，风险大。

5.  **送货稳定性测试：**
    -   不要只下一次大单。靠谱的做法是：**做三次“小额高频”测试单**。
    -   周一进一箱，周三进一箱，周六进一箱。观察他送货是否准时、货品是否稳定在同一品质、结算是否清晰。如果三次都稳定，且送货单上明确写了品名、单价、重量、备注，那基本可以长期合作。

**三、 实操避坑“三刀”测试法**

6.  **“暗箱”测试：** 收货时，一定要**随机切开中间层的箱子**（不要只看顶层）。很多供应商喜欢“上面大下面小，上面好下面差”。
7.  **“记账”测试：** 第一次结账时，故意给现金或当面点清，看他是否会主动确认**“重量是去了皮（筐子重量）的”，还是按毛重算**。按毛重（连筐带水）算的，直接拉黑。
8.  **“背调”测试：** 问他要一两个老客户的联系方式（证明他敢给你），或者直接去他档口看**有没有其他水果店老板在长期蹲点要货**。

**总结你的决策点：**

-   **如果供应商能做到：** 明确告知成熟度、敢承诺坏果赔付、主动提供产地信息、结算单据清晰——**这就是靠谱的**，即使价格贵1-2毛/斤也可以接受，因为“损耗”远比“进价”更吞利润。
-   **如果供应商只会说：** “你放心”、“都是好货”、“别人都这么拿”——**坚决不碰**。

**最后提醒：** 香蕉和菠萝都是呼吸跃变型水果（采后还会继续成熟），**永远不要把宝押在“压货”上**。靠谱的供应商标准里最重要的一条是**“他敢跟你签‘按周调货’合同，而不是逼你大批量囤货”**。
