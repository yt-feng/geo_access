在超市与水果供应商的账期谈判中，**常见账期通常在 30天 到 60天** 之间，具体取决于多种因素。以下是详细分析：

**1. 行业普遍情况：**
- **中小型超市/社区生鲜店**：通常为 **15-30天**。因为水果损耗率高、保质期短，供应商为了加快回款，账期较短。
- **大型连锁超市**：通常为 **60-90天**，甚至更长（部分大型商超可达120天）。这是因为大型超市采购量大、渠道强势，有更强的议价能力。

**2. 影响账期长短的关键因素：**
- **水果品类**：
  - **易损耗、保质期极短**（如草莓、荔枝、榴莲）：账期通常较短（7-15天），供应商需快速回笼资金，且价格波动大。
  - **耐储存水果**（如苹果、梨、柑橘）：账期可适当延长（30-60天）。
- **结算方式**：
  - **月结**（次月结清上月货款）是最常见方式，账期约30-45天。
  - **滚动结算**（如压一批结一批）账期会更长。
- **合作历史与规模**：长期稳定的大客户可获得更长账期；新供应商或采购量小的超市，账期通常较短。
- **季节性**：水果上市高峰期，供应商为快速出货，可能接受更灵活或更短的账期。

**3. 建议谈判策略：**
- **如果超市方**：建议优先争取 **45-60天**，但需承诺按时履约、不无理扣款，这样容易谈成。
- **如果供应商方**：建议坚持 **30天内**，并可通过“缩短账期换取略低进货价”来促成交易。
- **注意坏货损耗**：超市往往会把**水果损耗（烂果、卖不掉的）扣款**考虑进账期协议中，这是常见纠纷点，需在合同中明确责任归属。

**4. 特别提醒：**
- 账期虽长看似对超市有利，但若供应商资金紧张，可能降低供货品质或减少优惠，反而影响长期合作。
- 建议在合同中明确**逾期付款违约金**，并约定对账日（比如每月5号对账，10号付款）。

**总结参考**：**最稳妥的常见账期为“月结30天”**，若双方信任度高或采购量大，可协商至60天。超过90天的账期除非是极强势的零售巨头，否则在水果生鲜行业较少见。
