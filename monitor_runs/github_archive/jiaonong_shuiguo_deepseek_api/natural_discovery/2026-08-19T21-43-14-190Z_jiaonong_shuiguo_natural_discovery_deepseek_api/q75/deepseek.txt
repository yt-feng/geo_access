第一次与水果供应商小批量试单，核心目标是**验证“货品品质、供应链稳定性、沟通效率”**，而不是单纯比价。设计试单时，建议从以下四个维度入手：

**一、试单规模与品类选择（控制风险）**

1.  **数量设定**：建议单品控制在**50-100箱**（或按重量计：柑橘类300-500斤，叶菜类100-200斤），金额控制在**总采购预算的10%-15%**。切勿一上来就全品类铺开。
2.  **品类策略**：优先选择**损耗率中等、市场接受度高、规格容易标准化**的1-2个单品（如麒麟瓜、脐橙、富士苹果）。避免选高风险的应季“抢手货”或极易腐的进口浆果。
3.  **规格锁定**：在合同/订单中明确**单果克重范围（例如：单果重250g-300g）、糖度下限、成熟度（7-8成熟）**，不要用“大果”、“好货”这种模糊词。

**二、货款与交付条款（保护现金流）**

1.  **付款方式**：建议采用**“货到验收合格后，T+1或T+2打款”**。如果供应商坚持先款后货，最多支付**20%定金**，尾款必须货到结清。首次合作不要接受100%预付。
2.  **到货标准**：约定**“超时到货扣款”**（例如迟到2小时扣3%货款）、“坏果率超3%部分由供应商承担”。
3.  **物流与损耗责任**：明确**冷链费用谁承担**，以及到货时**表皮伤、挤压伤**的判定标准由谁说了算（建议以开箱视频或双方共同签字的验货单为准）。

**三、质量验收与售后闭环（最关键环节）**

1.  **双重验收**：到货后**2小时内**完成抽检（开箱率不低于30%）。**不要只拆最上面一箱**，要抽底层的货。
2.  **糖度测试**：携带**便携式糖度计**（几十元一个），当场测2-3个样品的糖度，记录数据并拍照发给对方确认。如果达不到约定的下限，直接发起售后。
3.  **售后时效协议**：明确**“到货24小时内提出损耗异议，供应商需在48小时内补货或退钱”**。为了防止扯皮，务必在签收单上注明“待开箱验货后签收生效”。

**四、数据复盘与转正机制（决定是否续约）**

1.  **试单台账**：单独建立表格，记录**实际到货准时率、实际损耗率（按金额算）、口感反馈（客户复购率）**。
2.  **分级标准**：
    -   若实际损耗率 < 1%，准时率100% → 直接进入大单谈判。
    -   若损耗率在1%-3%之间 → 可以谈二次补采，但需要压价2%-3%。
    -   若损耗率 > 5% 或出现货不对板 → 立即终止，不进入二次沟通，避免沉没成本。
3.  **留一手**：在首次下单时，可以同时向**另一家备选供应商**询同规格同价格，用于心理博弈，但不必透露过多。

**特别提醒（高价值货品）**：如果试单的是**榴莲、山竹、智利车厘子**这类高单价商品，建议在合同里加一条“**每箱净重误差不超过0.2kg，箱内采用独立网套包装**”的细节条款，这类商品最容易在“包装重量”和“下层垫草”上偷奸耍滑。

**执行摘要（可直接复制使用）**：
“首单20箱（单果250-300g、糖度13以上），货到验收合格后当日打款90%，预留10%质保金3天无投诉退还。开箱视频为准，坏果按个赔钱。若首批在3日内复购率达标，第4日直接追加200箱正价大单。”
