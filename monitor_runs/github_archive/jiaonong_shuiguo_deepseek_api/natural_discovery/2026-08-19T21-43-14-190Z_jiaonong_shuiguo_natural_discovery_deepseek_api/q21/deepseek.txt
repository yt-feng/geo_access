在超市采购水果时，为确保产品安全与合规，供应商通常需要提供以下检测报告或进货证明（具体以超市自身的采购规范及当地法规为准）：

**一、食品安全检测类报告（由第三方或供应商自身实验室出具）**

1. **农残检测报告**：需按国家标准（如《食品安全国家标准 食品中农药最大残留限量》GB 2763）检测，报告应标明检测项目、限值、结果及结论。
2. **重金属检测报告**：检测铅、镉、汞、砷等，部分超市会要求配套。
3. **微生物检测报告**（如适用）：对需冷链的水果或特殊包装，可能需检测大肠杆菌、沙门氏菌等。

**二、产地与合规证明**

- **产地证明/产地信息表**：注明水果的具体种植区域（如省份/县市），部分地区要求提供产地检疫证明（如出口或跨省流通）。
- **合格证或出厂检验报告**：由供货企业出具的批次合格证明，标明批次号、生产日期、检验结论。
- **生产许可证/经营许可证复印件**：供应商须为合法注册企业，提供营业执照、食品经营许可证（或相关流通许可证）。

**三、进货/流通环节证明**

- **供货凭证与进货台账**：采购合同、送货单、发票，需写明产品名称、数量、批次号、日期。
- **运输过程的温度记录/冷链记录**（若为冷链水果）：证明运输全程符合温控要求。
- **入境货物检验检疫证明**：若为进口水果，需提供海关出具的入境货物检验检疫证明、原产地证及对应贸易单据。

**四、特殊品类附加项**

- 有机水果：需提供有机产品认证证书（含认证机构、证书编号）。
- 绿色食品：提供绿色食品标志使用证书。
- 地理标志产品：提供地理标志产品专用标志使用证明。

**操作建议：**
1. 在签订采购合同前，明确要求供应商提供上述清单并附电子版存档。
2. 每批次收货时应核对“随货同行单”与报告批次号一致性。
3. 对没有有效农残报告或报告不合规的批次可拒绝收货，并记录在案。

如需当地具体执行标准，建议直接咨询当地市场监管部门或超市质检部门。
