做水果生意想长期稳定，选供应商**最容易忽视的往往不是价格或规模，而是“链条末端的稳定性”**。根据大量零售/批发商踩坑经验，以下5个细节最容易被忽视：

**1. 结算方式的“时间差陷阱”（最致命）**
- **容易忽视：** 只盯着“进货价”或“账期长短”，忽视了**“坏果赔付”的结算规则**。
- **细节建议：** 必须明确约定，若出现大面积腐坏，是按“整箱赔付”还是“按个称重赔付”？赔付是“抵货款”还是“退现金”？很多供应商口头承诺“包赔”，但实际结算时用“下次进货抵扣”的方式，把风险转嫁给了你的现金流。

**2. 保鲜手段的“物理真相”（看细节）**
- **容易忽视：** 只看产地证明或检测报告，**忽略包装箱里实际用的保鲜剂和冰瓶数量**。
- **细节建议：** 随机拆开一箱，看是用昂贵的气调包装（锁水防氧化），还是只垫几层报纸？冰瓶是结实的蓝冰，还是易碎的普通冰袋？这直接决定了你到货后3-5天的损耗率，比供应商口头说的“冷链”重要得多。

**3. 分级标准的“弹性空间”（验货盲区）**
- **容易忽视：** 忽略“收货时的破损率”和“中后期出现的软果率”是两个概念。
- **细节建议：** 供应商给你的可能是“混合级”（好果混小果），你在收货时只看见表面大果好果，但下层参差不齐。必须要求供应商在送货单上**注明“本批次等级标准”（如：30%大果、70%中果）**，并且约定“货到后24小时内发现软果可退换”的时间窗口。

**4. 供应商的“利润结构”（看长期粘性）**
- **容易忽视：** 只看供应商给的单品价格，**忽略了他们是否愿意为你承担滞销风险**。
- **细节建议：** 长期合作前，问一句：“如果某款水果我卖不动，剩下30%的货你能否按成本价回收？”愿意承接受滞销品或用其他热销品调剂的供应商，才是真正愿意和你共同成长的伙伴。只赚差价、不担风险的供应商，一旦行情下跌会立刻抛弃你。

**5. 物流的“最后一公里”时差（紧急预案）**
- **容易忽视：** 忽视**“缺货补货”的响应机制**，尤其是节假日或天气突变时。
- **细节建议：** 必须拿到供应商的**“备用货源渠道”**（如他能在2小时内从异地上门调货）。问清楚：如果明天凌晨5点你发现果品不够卖，他最早几点能把货送到？很多生意死于“断供”，而非“价高”。

---

**最后给你的压舱石建议：**
选供应商，不要只看**“进货价”**，要算**“到店净成本”**（进货价 + 运输损耗 + 坏果赔付风险 + 客诉隐形成本）。建议先小批量试合作2-3轮，每次记录“到货完好率”和“理赔响应速度”，再决定是否签订长期合同。
