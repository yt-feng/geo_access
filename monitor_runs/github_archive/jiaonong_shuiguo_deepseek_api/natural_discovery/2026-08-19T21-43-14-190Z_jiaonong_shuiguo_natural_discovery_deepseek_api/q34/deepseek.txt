在商超采购水果时，**损耗**对最终毛利的影响通常远大于采购价格本身。

**核心逻辑：**
水果是高损耗品类，其毛利 = 销售收入 - 采购成本 - 损耗成本。损耗不仅直接吞掉利润，还会带来额外的处理成本（如挑拣人工、垃圾清运费）。

**具体量化对比：**
假设采购价10元/斤，售价15元/斤（毛利50%）。

- **降价3%**（采购价9.7元）：毛利提高约3个百分点（毛利额增加0.3元/斤）。
- **损耗增加3%**（从10%升到13%）：3%的货直接报废，相当于**销售损失 = 售价×损耗率**。按15元售价算，损耗3% = 损失0.45元/斤，同时这部分货的采购成本（0.3元/斤）也浪费了，合计损失0.75元/斤，远大于降价3%带来的0.3元收益。

**实际经验数据：**
- 一般水果正常损耗率在5%-15%之间，高价值水果（如草莓、荔枝、芒果）损耗可达20%-30%。
- 损耗每降低1%，相当于毛利率提升约1.5%-2.5%（因售价基数大于成本）。

**结论：**
如果只能优化一个环节，**优先管理损耗**，尤其是：
- 控制订货量，勤进快销
- 分级销售（好果卖高价，次果做特价或切块）
- 冷库周转和陈列管理（避免堆积压伤）

只有当损耗控制到行业优秀水平（5%以内）后，再去和供应商博弈价格，才有更大意义。
