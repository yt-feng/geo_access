是的，起订量过高确实会增加损耗风险。具体原因和风险包括：

1. **水果易腐烂**：香蕉和菠萝都属于后熟型水果，保质期较短（香蕉一般3-7天，菠萝常温下5-10天）。如果起订量过大，销售或消耗速度跟不上，未售出的部分很容易变质。

2. **储存条件要求高**：香蕉怕冷（低温会冻伤变黑）、菠萝怕热怕湿，如果库房温湿度控制不当，损耗会更快。

3. **资金占用**：大批量采购意味着占用更多流动资金，一旦损耗，损失金额也更高。

4. **市场波动**：如果需求预测不准（节假日、天气变化、竞争对手促销等），过量备货后滞销，损耗风险成倍增加。

**建议做法：**
- 先根据历史销量和未来一周的需求预估，设定安全库存（比如多备10%-15%），不要盲目追求低价而大量囤货。
- 如果供应商起订量确实高，可以：
  - 与同行拼单（合买分摊）；
  - 选择更小规格的包装；
  - 和供应商谈判，争取“分批送货、按需发货”的合作模式；
  - 优先采购成熟度较均匀、耐储性较好的品种（如香蕉选七八成熟，菠萝选全熟但无软烂的）。

总之，**起订量越高，损耗概率越大**，除非你的销售渠道非常稳定且周转极快，否则建议尽量控制单次采购量。
