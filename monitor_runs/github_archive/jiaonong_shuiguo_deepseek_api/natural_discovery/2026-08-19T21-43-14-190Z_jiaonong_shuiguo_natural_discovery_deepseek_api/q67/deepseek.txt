作为批发商，代理品牌时最核心的风险就是**区域保护**（市场范围）和**串货**（货源管理）。提问要直接、有威慑力，最好让对方**白纸黑字写进合同**。

以下是我为你整理的**5个必问问题**及**话术参考**，按重要性排序：

### 1. 区域保护边界（问“地图”）
**问题：** “请问我们代理的区域是**以行政区域（如省/市）为准**，还是以**具体门店/商圈（KA卖场、社区店）为准**？如果我在合同范围内开发了客户，但该客户在隔壁区域也有分店，这个配送权归谁？”

**潜台词：** 防止口头承诺“整个市都是你的”，结果合同只写“指定商超”。一定要确认电商、团购、社区团购是否也属于你的保护范围。

### 2. 串货处罚机制（问“证据链”）
**问题：** “如果我发现我区域内有**非我供应的货**流通（比如跨区低价货），我需要提供什么证据（如：货品溯源码、包装批次、进货小票）？品牌方承诺的**首次处罚、二次清退**的具体条款是什么？会补偿我的市场投入吗？”

**潜台词：** 很多品牌只看“有没有抓现行”，不看“你的损失”。必须要求**溯源码一对一绑定区域**，否则无法证明串货。

### 3. 销售任务与区域收回（问“扣点”）
**问题：** “如果我在保护区域内完成不了**首年基础销量**，区域保护是否会失效或缩减？如果被收回，我手里的**库存和已铺货网点**怎么处理？品牌方是否会回购或允许我低价甩货？”

**潜台词：** 很多品牌用“完不成任务就划走一块区域”来逼迫批发商压货。必须问清楚，否则你打下的市场可能成别人的嫁衣。

### 4. 电商与直播专供款（问“产品线”）
**问题：** “贵品牌是否有**电商专供款**或**直播爆款**？这些产品是否也会发货到我所在区域？如果线上价格比我的拿货价还低，我是按市场价卖还是跟随降价？这部分的区域保护怎么算？”

**潜台词：** 现在最大的串货来源就是**线上**。如果不问清楚，你辛辛苦苦铺的店，顾客转头在直播间下单了。

### 5. 违约保证金与扣罚标准（问“钱”）
**问题：** “合同中对我的**保证金**扣除标准具体是什么？如果是**我的下游客户**（二级批发商）私下窜货，我被处罚后，是否有权利向品牌方调取该批货的**溯源码最终流向**来自证清白？”

**潜台词：** 明确**连带责任**的边界。你罚我钱可以，但如果是我的下家乱搞，你得配合我抓出那个人，不能让无辜的批发商背锅。

---

### 关键谈判话术（压迫感强，逼对方表态）：
> “王总，我认可你们品牌，但水果生意损耗大、利润薄。如果区域保护只是挂在嘴上，今天隔壁市来窜一车，明天电商来冲击一次，我这盘牌就死定了。**咱们合同里必须明确：串货证据只要我能提供完整溯源，** 你按串货货值**双倍**赔偿我的市场损失。如果这条款做不到，这代理费我是真不敢交。”

### 最后的防坑提醒：
- **不要信口头承诺**：所有关于“谁的区域谁卖”的话，必须写进合同的“补充协议”里，并且**盖上品牌方公司公章**。
- **要样品溯源**：签合同前，让他拿一箱当前最新批次的货，你扫一下二维码或包装码，看能否显示**生产经销商归属地**。如果扫码查不到区域信息，这个品牌连防窜货系统都没建好，建议直接放弃。
