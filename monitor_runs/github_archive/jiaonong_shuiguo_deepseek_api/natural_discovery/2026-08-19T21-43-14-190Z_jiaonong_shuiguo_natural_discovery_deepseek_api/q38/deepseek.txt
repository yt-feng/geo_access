大型超市（如沃尔玛、永辉、盒马、Costco 等）对水果供应商的准入标准非常严格，通常从**食品安全体系**和**物流履约能力**两个维度进行硬性考核。以下是必须具备的核心能力清单：

---

### 一、食品安全体系能力（合规底线）

1.  **源头基地资质与可追溯性**
    -   拥有自有基地或长期合作的备案基地（具备GAP（全球良好农业操作规范认证）、绿色食品证、无公害认证等至少一项）。
    -   **全链路批次追溯**：从种植、农事记录（施肥、打药）、采摘到配送，每个SKU都要能通过二维码或ERP系统回溯到具体地块和操作人。
2.  **农残与重金属检测能力**
    -   必须配备**自有快速检测实验室**，对每批次水果进行有机磷、氨基甲酸酯等常规农残快筛（做到当日出货前出报告）。
    -   定期送检第三方（如SGS、华测）进行重金属（铅、镉）及高关注度农残（如多菌灵、百草枯）的定量检测。
    -   关键技术指标：**出具“一果一码”或批次农残检测报告**，且能实时上传至超市系统。
3.  **采后处理卫生标准**
    -   分选、包装车间需通过HACCP（危害分析与关键控制点）或ISO 22000认证。
    -   明确**冷链断点控制**：采后预冷（核心温度降至4℃以内，时间不超过8小时）、分选环境温湿度记录、工器具消毒计划。
4.  **储运虫害与微生物控制**
    -   针对鲜切水果（如鲜切菠萝、西瓜盒），需具备**低温切配资质**，且有完善的致病菌监控计划（如沙门氏菌、大肠杆菌）。
    -   对非鲜切水果，需有虫害防治记录，避免蟑螂、果蝇等带入超市卖场。

---

### 二、物流履约能力（效率与品质保障）

1.  **全程冷链运输（0-10℃差异化控制）**
    -   **专用冷藏车**：必须配备温度实时监控（GPS+温度记录仪），保证整车温度波动不超过±1.5℃。
    -   可执行 **“冷库到门店冷链不脱冷”** 的标准化交接流程，需提供卸货时的车厢温度截图。
    -   特殊品类（如香蕉、榴莲催熟库）需具备专门的催熟温控库（乙烯浓度控制）。
2.  **快速响应与准时交付**
    -   **日配/次日达**能力：T+0订单（上午下单，当日晚间或次日凌晨送达超市DC（配送中心）或门店）。
    -   订单满足率要求：通常需达到**98%以上**，突发缺货需有补货预案（如周边基地应急调拨）。
3.  **包装与装卸耐受性**
    -   包装需符合**超市陈列要求**（如整箱规格统一、净含量误差允许±1%），且具备抗压、防潮、透气设计（如气调包装+冰袋）。
    -   需满足**防损要求**：在装卸过程中，实现**轻拿轻放、不挤压、不倒置**的规范化操作，破损率需控制在**1%以内**。
4.  **逆向物流与损耗处理**
    -   必须有能力承接**门店退换货及残次品回收**，并在24小时内完成调换或补偿。
    -   需有明确的**自主损耗承担机制**（如约定在途损耗超过2%时由供应商负责）。

---

### 三、额外差异化能力（大型超市重点考察项）

-   **数字化对接能力**：能够对接超市的EDI（电子数据交换）系统，实时上传库存、检测报告、温度轨迹。
-   **分批次柔性供应**：满足超市**每周促销档期**（如周二会员日）的大单量突增需求，且能承受±30%的订单波动。
-   **产地直采背书**：具备产地证明、采摘时间证明，能在超市端展示“产地溯源”，增强消费者信任。

---

### 检验建议（给超市采购方/供应商自查）：

-   供应商需一次性提交：**三证（营业执照、食品经营许可证、产品检测报告）**、**质量管理体系证书**（HACCP或ISO22000）及**3个月的冷链运输温度记录**。
-   要求供应商进行“盲测”：随机抽一车货，在到店时，由超市品控人员现场测果心温度、开箱检查箱内是否有冷源存留（如冰袋是否仍处于微冻状态）。

*注意：某些超市（如山姆、Costco）还要求供应商提供 **“食品安全责任险”** 保单，且赔付额度需覆盖上架货值。*
