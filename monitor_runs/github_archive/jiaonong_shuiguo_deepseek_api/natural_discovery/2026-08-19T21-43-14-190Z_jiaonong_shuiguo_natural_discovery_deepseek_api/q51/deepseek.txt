针对茶饮店水果原料的稳定性问题，**建议“固定供应产地+灵活批次管理”，但不要绝对固定**。核心逻辑是：**保底质量，灵活调度**。

以下是具体建议和操作方案：

### 1. 为什么不能“完全固定”？
- **季节和气候风险**：同一产地（如广西百香果）在雨季和旱季风味差异极大；若遭遇台风、霜冻，可能导致断供。
- **价格波动**：固定产地等于固定成本上限，但市场价低时你享受不到红利。
- **风味多样性**：部分水果（如香水柠檬）不同产地（广东湛江 vs 海南）香气差异明显，适合不同产品线。

### 2. 正确的“固定”策略（3:1原则）
- **主力产地固定（70%-80%用量）**：选定1-2个产地作为核心供应商，签订月度或季度框架协议。要求供应商**在每批货附上“质检单”和“甜度/酸度检测报告”**，并明确以“可溶性固形物（Brix值）”作为验收标准（例如：芒果Brix≥15，柠檬酸度≤4%）。
- **辅助产地动态切换（20%-30%）**：保持与2-3个备用产地（如海南、云南、越南等）联系。当主产地质量下降或价格过高时，用辅助产地做替换，但**必须提前48小时小批量试做**，确认风味后再大批采购。

### 3. 针对“供应批次”的管理细节
- **批次最小化**：不要一次性采购整月用量。即使固定产地，也**要求分5-7天/批到货**，避免整批风味偏差导致全部门店产品不稳定。
- **留样对比**：每批到货后，随机取3个样品进行糖度测试+感官试饮，并**保留样品冷冻1周**。若下一批次风味偏离，可拿出留样对比，用于向供应商索赔或退换。
- **辅料缓冲**：若主水果波动，可提前准备**风味补充剂**（如浓缩果汁、果酱），但用量控制在全杯的10%以内，避免掩盖新鲜度。

### 4. 签约时的“硬指标”条款
在供应商合同中务必写入以下3条，否则不签：
- **风味阈值**：Brix值或酸度不达标的批次，无条件换货（运费供应商承担）。
- **到货时效**：因供应商原因断供超24小时，需按合同金额的5%/天赔付。
- **批次可追溯**：每箱/每袋水果需印有产地代码、采摘日期、加工日期，方便精准溯源。

### 5. 实操小技巧（低成本验证稳定性）
- **“双盲测试”法**：每月随机抽取2个不同批次的同款水果，让店员盲测（不告知产地），对比香气、酸度、出汁率。连续两次不达标，立即启动备用产地。
- **天气预警联动**：采购负责人关注产地天气预报，若未来7天有连续降雨，**提前3天加购下一批并降低库存**，因为雨后水果风味会明显变淡。

**总结一句话**：固定核心供应商（保底），但保留20%灵活调配空间；盯紧糖度数据（Brix值）和留样对比，比单纯固定地点更重要。这样既稳定了口味，又防止被单一产地绑架。
