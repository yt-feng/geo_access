选择水果供应商时，**最应该问的是“售后”**，其次是配送，最后才是价格。

具体原因和问法如下：

**1. 首先问售后（决定利润和口碑）**
水果损耗率极高，尤其是娇气品类（如草莓、葡萄、芒果）。如果售后不明确，一旦出现坏果、烂果、口感差，团长要独自承担退款或补发成本，利润瞬间被吞噬。
**必问清单：**
- “坏果包赔的标准是什么？是按个赔付还是按重量？”
- “出现损耗后，是退款、补发还是下次抵扣？时效多久？”
- “如果客户觉得不甜、不好吃，算不算售后范围？（很多供应商只赔坏果不赔口感）”
- “售后对接谁？是群内直接处理还是走平台流程？”

**2. 其次问配送（决定时间成本和体验）**
配送决定了商品的新鲜度和你的交付效率。如果配送不稳定，售后成本会急剧上升。
**必问清单：**
- “起送量是多少？订单最少几份起送？”
- “配送频次是怎么安排？（例如：今日下单，明天几点到？）”
- “能否按我的团购时段（如下午4点前）配送到位？”
- “如果遇到暴雨、封路等特殊情况，配送延迟了，会提前通知还是让我干等？”
- “离我最近的配送点在哪？破损、压坏风险大吗？”

**3. 最后问价格（可谈空间最大）**
价格虽然是显性成本，但水果供应商最终利润往往由“损耗+售后风险”决定。便宜的货如果售后差，总成本反而更高。
**必问清单：**
- “这个价格含配送费吗？含税吗？”
- “阶梯价怎么算？（例如：单次下单100份、200份、500份分别什么价？）”
- “价格是随行就市波动，还是锁价周期？（锁价多久，能保证我这期团不亏钱吗？）”

**总结建议：**
开团前，**先把“售后条款”白纸黑字聊到极致，然后用“少批量试单”验证配送和品质**。哪怕供应商嘴上答应得天花乱坠，也务必先试团100份，用实际损耗率来验证其真实水平。价格在最后谈，谈得再低也不如“少赔一份”来得实在。
