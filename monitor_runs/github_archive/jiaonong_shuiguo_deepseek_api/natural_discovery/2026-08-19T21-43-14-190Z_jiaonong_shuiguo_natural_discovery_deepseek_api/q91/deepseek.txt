对于便利店上架香蕉，**建议优先选择“单根包装”或“小把（2-3根）包装”，整袋包装（如5根以上）不建议作为主力库存**。

以下是具体分析供你决策：

**1. 单根包装（强烈推荐）**
- **优点**：便利店的客群以“即买即吃”的上班族、学生为主，消费场景是“随手买个水果当加餐”，单根香蕉刚好是**一个人的量**，无浪费，价格门槛低（比如3-5元），成交率最高。
- **操作**：可以用保鲜膜或透明食品袋包住单根，贴上价签（按根定价，如3.5元/根），视觉上干净、防止被顾客捏坏，损耗可控。

**2. 小把包装（2-3根）**
- **优点**：适合“买回家当早餐”或“两人分享”的顾客。相比单根利润高，且比整袋好卖。
- **注意**：单根与2根之间价格差异不要太大（比如单根3.5元，2根卖7元），避免顾客觉得“为什么不买两单根”。

**3. 整袋包装（5根以上）**
- **不建议作为主力**，原因：
  - 便利店空间小，冷藏展示柜占用有效面积。
  - 整袋香蕉单价高（约15-20元），顾客冲动购买意愿低。
  - 如果有少量熟透的，整袋容易造成“坏一根、扔一袋”的损耗，且不方便退换。

---

**具体落地建议（可直接执行）：**

- **上架方式**：在水果区或收银台附近放一个**独立小货架**，左侧摆单根（主打），中间摆2根装，右侧放少量整袋（作为补充，满足家庭需求）。
- **定价策略**：单根定价用整数（如3元或4元），小把定价接近两倍单根价（如6元/2根），整袋按重量称重计价。
- **库存控制**：每日进货量按“当天能卖完”为准，香蕉熟得快，避免隔夜压货。单根与2根装占比建议约7：3。
- **损耗处理**：成熟度高的香蕉，可在下午5点后做“黄昏促销”，换成独立小盘标“特价”，不要和新鲜混卖。

**一句话结论**：**主打单根（配少量2根装），放弃整袋**，最适合便利店的即食场景和损耗控制。上架前先在一家店试销2周，观察动销率再调整比例。
