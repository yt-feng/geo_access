采购香蕉用于茶饮或甜品时，熟度控制非常关键，因为不同熟度直接影响口感（甜度、软硬度）和用途。以下是一些实操建议，分场景和标准：

### 1. 明确用途，反向定熟度
先想清楚你做的产品需要什么状态：

| 用途 | 理想熟度 | 挑选标准 |
|------|---------|---------|
| 香蕉奶昔/冰沙 | 全熟（表皮有黑点） | 手感软，甜度高，香气浓 |
| 香蕉切片装饰/甜品顶 | 微熟偏硬 | 表皮金黄，两头微绿，切面不易塌陷 |
| 香蕉果酱/烤香蕉 | 过熟（表皮深黑） | 果肉软糯，容易捣烂 |
| 香蕉拿铁/咖啡类 | 中熟（黄中带绿） | 果肉有颗粒感，不会太过糊化 |

### 2. 采购时按“到达门店当天”来定
- 如果今天下单、明天到店，**首选8-9成熟**（表皮全黄、无黑点）。
- 如果是本地市场自采，**选7成熟**（表皮黄绿相间），因为门店常温放置24-48小时即可到全熟。

### 3. 物理挑选标准（用手和眼）
- **手感**：轻轻捏两端，太硬（脆）说明未熟，太软（塌）说明过熟。要选有弹性、略微软的。
- **表皮颜色梯度**：全黄最好，两端带一点绿色代表还能放1-2天，有少量芝麻点代表最甜。
- **避开**：有淤伤（碰坏）、表皮裂开、有霉斑的，即使便宜也不能要，因为香蕉一旦破损会加速腐烂。

### 4. 采购时的损耗控制策略
- 不要一次买满一周的量，香蕉成熟速度不一致且快，建议**按3天周转量采购**。
- 如果量大，可以要求供应商供货时**分两批熟度**（比如60%熟度+40%全熟），让门店自行调节。
- 到货后立刻拆箱，避免闷在纸箱里加速催熟，常温阴凉处存放。

### 5. 如果买回来熟度不对怎么办
- 太青（不熟）：放在不透气的纸袋里，加一个苹果或番茄，室温放置一晚即可催熟。
- 有点过熟（软但没坏）：优先做果酱、烘焙类，不要做鲜切产品。

### 6. 货架期与保存
- 全熟香蕉在25℃左右只能放2天，**必须当天计划用量**，不然就直接进冷藏（冷藏会变黑但果肉不变质，适合做奶昔）。
- 如果当天用不完，提前剥好冷冻，做冰沙类产品没问题。

**总结口诀**：当天用全熟，隔天用九成，切配用八成，烘焙用超熟。采购前先问后厨明天做什么，再决定下单熟度，比任何标准都管用。
