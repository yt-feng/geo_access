在企业食堂采购水果时，**食品安全永远是第一优先级**，其次是**价格合理性**，最后才是**配送准时性**（但三者缺一不可）。

原因很简单：食品安全直接关系到员工的身体健康和企业的声誉，一旦出现食物中毒或农药残留问题，后果是灾难性的；价格影响成本控制，食堂需要性价比；配送准时影响日常供应的连续性，但偶发延误可以通过备货缓冲。

**给您的具体建议（按优先级执行）：**

1. **食品安全（必须100%达标）**  
   - 要求供应商提供《营业执照》《食品经营许可证》和每批水果的**农药残留检测报告**（需有CMA/CNAS认证）。  
   - 现场验货时检查水果是否新鲜、有无腐烂、碰伤，**不带病果**。  
   - 对于高风险水果（如草莓、葡萄），建议定期抽检或要求提供第三方检测报告。  
   - 明确合同条款：如因水果质量问题导致事故，供应商需承担全部责任。

2. **价格（合理即可，不必最低）**  
   - 对比3-5家供应商的报价，**参考当地批发市场均价**，防止虚报或恶意低价。  
   - 签订长期合同时，绑定**价格浮动机制**（如参考产季价格指数），避免一次性过高或过低。  
   - 警惕“低价陷阱”：价格过低可能意味着水果品质差、储存时间久，反而增加损耗和风险。

3. **配送准时性（用合同约束）**  
   - 与供应商约定明确的到货时间窗口（如每日上午9点前），并设置**违约处罚条款**（如迟到扣款）。  
   - 在食堂建立**安全库存（如1-2天用量）**，即使配送延迟也能正常供餐。  
   - 优先选择有固定冷链运输车和自有仓库的供应商，能更稳定地控制配送时效。

**总结执行顺序：**  
先审核资质与检测报告（食品安全）→ 再谈价格和合同条款（成本与质量平衡）→ 最后用条款和库存保障配送。
