社区超市经营水果，核心是做**高频、短保、小批量**的生意。控制新鲜度和库存的关键在于**“以销定采”**和**“批次周转”**，而不是“进多进全”。

这里给你一套可落地的执行方案，直接对照调整：

### 一、 采购端：从源头控量（减少滞销的第一步）

1. **逼出“分次下单”**：不要一次性订一周的量。
   - **叶菜/浆果类（草莓、葡萄）**：建议**日配**，每天凌晨拿当日量。
   - **根茎类（苹果、梨、土豆）**：可以3-5天补一次。
2. **选“后期熟”品种**：进产区货时，优先选**采收时带一点生、放2-3天会变甜**的水果（如香蕉、猕猴桃、芒果、牛油果）。这样做的好处是，货架期比“熟透即卖”的品种多出2天。
3. **砍掉“边缘”品类**：社区店不适合卖“稀有水果”或“整箱礼盒”。除非有预售，否则**只做大众高频款**（苹果、香蕉、橙子、西瓜、梨）。

### 二、 店里陈列：用“复购”拉速度

1. **设置“今日鲜区”**：在门口或收银台边放一个黄色小筐，标注**“今日到货，当日清空”**。这个位置只放当天新进的或者最多放2天的水果，价格可以略低于正常价（比如打9折），目标不是赚钱，是**制造我每天都买得到的新鲜感**。
2. **混搭促销（消化库存）**：发现某一种水果（如圣女果）进了3天没卖完，不要单独降价。可以**“买酸奶送圣女果一把”**或者**“买西瓜送半斤烂桃（挑出来的熟果）做的果切”**。把滞销品变成畅销品的赠品，成本极低，清货极快。

### 三、 库存预警线（关键动作）

设定**“48小时生死线”**：

- **超过48小时未售出** → 立即转成果切、鲜榨果汁或酸奶捞专区（这是社区店最常见的止损手段，因为果切毛利高）。
- **超过72小时未售出** → **必须**摆到门口特价筐，价格下调30%-50%，**当天下班前必须清完**。宁可亏一点，不要留到第二天烂掉扔了亏更多。
- **严禁“翻堆”**：早上卖剩下的，如果看着还行，**不要混进新到的货里**。必须分开放，否则顾客挑走新的，留下旧的，明天旧的就变成烂货，形成恶性循环。

### 四、 动态订货公式（简单算账）

每天闭店前，用这个公式决定明天进多少：

> **明日进货量 = 今日销量 × 1.2（安全系数） - 今日库存**

- 如果今天进货100斤，卖了80斤，剩20斤。
- 那明天就进：80 × 1.2 = 96，减去库存20 = **进76斤**。
- 如果今天剩的超过25%（比如剩30斤），那明天**砍掉该品类的进货量50%**，直到库存降到安全线以下。

### 五、 对付“压货”的终极手段（降低损耗）

1. **预售制**：在社区群里每天下午发第二天到的货单（图片+价格），**顾客接龙预订**。第二天到货后按单分装，**按需供应**，这是最彻底零库存的办法。即使做不到全预售，至少周末或大件（西瓜、整箱）这么做。
2. **分装售卖**：别整箱卖。可以把大筐苹果、橙子**按“1斤两斤”分装成小袋**。减少顾客挑拣触摸带来的损耗，也方便家庭小份量购买，卖得更快。
3. **冷柜强制保鲜**：如果店里没冷柜，**夏天不要进叶菜和草莓**。因为室温下半天就会变色，损耗率极高。必备风幕柜或有雾化功能的保鲜柜存草莓、蓝莓、葡萄。

### 六、 给你的每日必做清单

- **开门前**：看昨天的库存，超过48小时的**立刻**分到打折区。
- **上午**：把当天新货摆到主通道最显眼处，卖相最好的放在前面。
- **午后**：观察销量，如果某品类下午3点只卖了40%，立刻开始小额促销（买二送一）。
- **闭店前1小时**：把所有能切成块的、能榨汁的，全部处理掉（果切、果汁），**绝不隔夜**。

**最后一句核心提醒**：社区超市永远不是“进回来等顾客买”，而是**“顾客买什么，才去进什么”**。如果连续3天某个水果没动，直接放弃这个品类，不要恋战。库存控制不好，赚的钱全压在烂果里。
