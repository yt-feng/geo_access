对于餐饮店每天少量水果的采购需求，建议优先考虑以下几点，让供应链更省心：

**1. 首选“社区生鲜店/菜市场固定摊位”**
- **为什么省心**：这类供应商通常有稳定的进货渠道，可以按“斤”或“个”少量购买，且能现挑现选，确保当天新鲜度。你可以和老板约定“每日固定留货”，他每天按你的要求备好，你直接取或他送货。
- **合作细节**：先观察一周，选一家品质稳定、态度好的老板，明确告知每日预估用量（如每天3斤苹果、2把香蕉），让他提前按你的损耗率备货。重点是**建立“今日送剩余可退换”的默契**。

**2. 若用量较小且稳定，可找本地水果批发市场的“二级分销商”**
- **为什么省心**：批发市场的一级批发商通常整箱起售，不适合你。但市场中会有专门面向小餐饮、水果捞店的分销商，他们提供**混合拼配**（如按你的菜单配好每日所需种类，按小份计价）。
- **合作前提**：需要你提前一天下单，早上送到店。建议先试合作3天，核对**果损率**（如香蕉碰撞、草莓软化等），约定好送到时若发现问题可当场换货。

**3. 最关键：谈好“品质验收标准”与“分担损耗”**
- **省心核心**：供应商必须承诺**当天送到的水果，若有坏果/不新鲜，拍照后即刻补偿或补送**。少量购买最怕一次性买多放坏，所以要约定“按每日用量送货”，不要囤货。
- **附加项**：让供应商帮你做**预处理**（如去皮、切块），虽然单价略高，但能节省后厨时间，且减少你自己存放造成的损耗。

**4. 不建议的选择**
- 大型商超（价格高且需自己挑拣）
- 纯线上生鲜平台（起送价高、配送费贵，且无法现场验货）

**行动建议**：这两天直接去离店最近的农贸市场，找2-3家水果摊，表明“我是旁边餐饮店的，以后每天在你家拿一点水果，能不能帮忙留货？”多数摊主愿意接长期小客户。你先试一周，记录每日实际用量和坏果率，然后确定固定一家即可。

**一句话总结**：找本地菜市场的固定水果摊点，约定每日留货、次日取，明确坏果包换，这是成本最低且最省心的模式。
