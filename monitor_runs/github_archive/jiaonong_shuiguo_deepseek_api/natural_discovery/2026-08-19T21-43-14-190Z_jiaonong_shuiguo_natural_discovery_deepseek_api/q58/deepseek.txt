在甜品店的菠萝采购中，**直接买成品果丁的损耗通常更低，但综合成本和品质风险需要权衡**。具体分析如下：

---

### 1. **损耗对比（核心）**
- **鲜果切配损耗**  
  - 整果去皮、去芯、修边后，通常损耗率在 **25%~35%**（视菠萝成熟度和切配技术）。  
  - 若店员操作不熟练、刀具损耗、存放不当（如切后氧化、出水），实际损耗可能更高，且每次切配会产生时间成本和人工成本。

- **成品果丁损耗**  
  - 供应商已按规格切好，您无需再承担切配损耗，但需注意：  
    - **运输途中挤压、出水、氧化**，到店后可能需挑拣，正常损耗约 **5%~10%**。  
    - 若供应商按净重计价（而非毛重），则几乎无额外损耗。

---

### 2. **关键变量与结论**
| 场景 | 损耗更低的一方 | 原因 |
|------|----------------|------|
| **门店销量稳定、单次用量大**（如出品量超20kg/天） | 鲜果切配 | 批量切配效率高，损耗可控，且单价更低（通常整果成本比果丁低30%~40%）。 |
| **门店销量小、使用零散**（如间歇性出品） | 成品果丁 | 避免整果存放变质，且无需额外雇人或占场地。 |
| **要求统一规格、出餐快**（如连锁标准化） | 成品果丁 | 切配均匀，减少操作差异。 |
| **对新鲜度要求极高**（如现切果盒） | 鲜果切配 | 成品果丁切好时间无法完全掌控，可能氧化。 |

---

### 3. **实际操作建议**
- **选成品果丁时**：  
  - 优先选真空包装或冷链配送，收货时检查包装破损、出水情况。  
  - 要求供应商提供“净重”报价，避免把包装和化冰水算进重量。  

- **选鲜果切配时**：  
  - 使用锋利刀具，预留切配时间，切后立即冷藏或用淡盐水浸泡（减少氧化）。  
  - 计算时把 **人工费 + 水电费** 计入“损耗”中，不要只看原料重量。  

---

### 4. **最终推荐（按常见小店）**
如果您是中小甜品店，并没有稳定大流量，**建议优先用成品果丁**，把节约的人工和损耗用于提升出品效率。  
但如果您每天能稳定卖出20份以上菠萝类甜品，且店内人手充裕，**买整果自制**会更划算——但记住，切配损耗**不可能为零**，必须按30%预估成本。  

补充提示：如果当地有大型批发市场，整果价格波动大，可考虑“整果为主 + 应急果丁”的混合模式，以灵活应对损耗和新鲜度。
