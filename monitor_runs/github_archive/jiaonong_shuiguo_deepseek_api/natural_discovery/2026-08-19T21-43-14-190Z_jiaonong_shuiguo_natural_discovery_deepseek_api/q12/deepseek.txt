在采购菠萝时，判断合适的熟度需要兼顾“到店后能尽快卖出”和“存放损耗”两方面。以下是可操作的判断要点：

**1. 看外观颜色（最直观）**
- 成熟度适中的菠萝：表皮呈**亮黄色或黄中带绿**（黄占70%左右），整体色泽均匀。这样的菠萝到手后常温放1-3天即可全熟，适合刚开卖就出货。
- 若表皮**全黄且发暗、发软**，说明过熟，采购回来可能当天卖不完就会烂芯，损耗大。
- 若表皮**大面积青绿**，则偏生，口感酸涩，需放很久，期间水分流失，也可能耗损。

**2. 闻气味（关键）**
- 成熟菠萝在果柄处或底部能闻到**浓郁香甜的果香**，这是糖分转化的标志。香气过浓甚至带酒味，说明已过熟；几乎无香气则偏生。

**3. 摸硬度与弹性**
- 轻按果体，**微软且有弹性**（像按熟透的芒果）为佳；过硬说明未熟，过软则内部可能已发酵变质。
- 注意底部（果脐）位置，若**按压有明显凹陷或发软发黑**，必是损耗品，不要采购。

**4. 掂重量（辅助）**
- 同等大小，选**手感更沉**的，水分更足，果肉更紧实，耐存放且出肉率高。

**5. 看果眼与果柄**
- 果眼（表面凸起）**大而稀、颜色深黄**的通常更甜；果柄切口**新鲜湿润**（不干枯、不发霉），则采摘时间较短，适合存放。

---

**给水果店的实际建议：**
- 采购时**优先选黄中带绿、微弹、有清香**的“7-8成熟”果，这样上架后1-2天内基本能自然熟透，避免了“全熟果买回来当天卖不完就烂”的痛点。
- 分两批采购：一批当天可卖（全熟偏黄），一批略生（黄带绿）备次日，能有效分散损耗风险。
- 进货回来后**果柄朝上竖放**，通风阴凉处保存，避免堆压碰撞。
