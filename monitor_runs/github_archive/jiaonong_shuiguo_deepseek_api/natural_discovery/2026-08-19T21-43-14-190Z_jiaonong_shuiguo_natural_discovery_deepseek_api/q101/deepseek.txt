和供应商谈酒店早餐水果供应合作时，建议从以下几个关键维度入手，确保稳定性和成本可控：

**1. 明确“稳定”的定义并写进合同**
- **品种与规格**：列出早餐常用水果的固定清单（如香蕉、苹果、橙子、西瓜、哈密瓜、圣女果等），以及每种的成熟度、甜度、大小规格、单果重量范围。**不要只写“水果”，要写具体品名+等级标准**。
- **交货频率与时间**：明确每日/隔日配送，最晚送达时间（通常要求早5:00-6:00前到货），以及缺货时的替补规则。
- **质量验收标准**：现场抽检比例（如每箱抽3-5个），坏果率控制线（建议≤3%），超标的退换货流程。

**2. 价格机制要防止“坐地起价”**
- 合同期建议为**3-6个月**，并约定价格浮动规则：以市场批发价为基准（如参考当地农产品批发市场周均价），设定±5%~10%的联动区间，超过部分双方协商调整。
- 明确“报价含税、含运费、含损耗”，避免后期加收包装费、搬运费等隐形费用。

**3. 供应保障与风险预案**
- 要求供应商提供**第二货源**（比如同一品种有A、B两个种植基地或批发档口），并写入合同，确保其自身断货时有替补渠道。
- 约定不可抗力（如台风、疫情封控）时的启动机制：供应商应提前24小时通知，酒店有权从备选供应商采购，差额由原供应商承担（视谈判力度）。
- 要求供应商提供**每日到货单**，记录品名、数量、重量、验收结果，作为结算凭证。

**4. 结算与账期**
- 建议初期采用**周结或半月结**，待合作关系稳定后（如连续2个月无投诉）可转为月结。
- 结算必须以实际签收数量为准，禁止“按箱估算”式结算。
- 扣款条款：每次违约赔付当日货款10%-20%，月度累计3次违约，酒店有权单方解除合同。

**5. 现场沟通要点**
- 先谈**最坏情况**：直接问“你万一缺货怎么办？”看对方能否给出具体替补方案，而不是空口保证。
- 要求**免费试供一周**，测试其实际配送准时率、水果新鲜度和损耗率后再签长期合同。
- 确认对方是否有**食品经营许可证**、是否提供每批水果的**产地证明或农药残留检测报告**（早餐供应涉及食安风险，不能省）。

**6. 法律文本要点**
- 在合同中写明：质量标准以**国家鲜食水果标准（GB/T 19841-2005等）**为最低底线，酒店方保留现场拍照留证和第三方检测权。
- 约定争议解决方式（建议当地仲裁，避免诉讼周期长）。

**最后提醒**：早餐水果损耗率高，务必在合同中写明“酒店仅对可食用部分付款，不可食用的腐烂部分不计费”，并要求供应商在配送时主动剔除残次品，这是减少扯皮的关键。
