判断水果批发商拿到的香蕉熟度和坏果风险，可以通过以下步骤快速评估：

1. **观察外观颜色**：香蕉皮颜色是判断熟度的直观指标。青绿色说明未熟，黄中带绿或全黄是合适的中等熟度，出现褐色斑点（“芝麻点”）或局部变黑则表明过熟。注意：如果整把香蕉中混杂明显黑斑或软烂区域，坏果风险高。

2. **检查果柄和切口**：看香蕉把手（柄）处是否干枯、发黑或有霉斑。若果柄颜色鲜绿或微黄，说明新鲜；若变黑、干瘪，可能内部已开始变质。切口处若有异味或黏液，表示细菌感染风险大。

3. **触摸硬度**：轻捏香蕉中部（不要捏两头），均匀的软硬度说明成熟度一致。如果部分部位软塌、有凹陷或流汁，表示有内部损伤或腐烂。偏硬则未熟，过软则易坏。

4. **闻气味**：正常香蕉有淡淡香味。若闻到酒味、酸味或发霉味，说明有发酵或腐烂问题，坏果风险高。

5. **抽查内部**：随机选1-2根从中间掰开（或切开），检查果肉颜色和质地。理想的果肉是淡黄、无褐斑、质地均匀。出现褐斑、黑丝、水渍状或软烂，说明内部已坏。

6. **评估运输和储存条件**：询问批发商是否全程冷链运输，若运输温度过高或波动大（常见于闷热天气），会增加催熟不均和霉变风险。检查包装箱是否有水渍、发霉或虫蛀痕迹。

**快速结论**：优先选外观全黄或黄绿均匀、无黑斑、果柄鲜绿、硬挺有弹性、无明显异味的香蕉。若发现超过10%的香蕉有黑斑或软烂，风险较高，建议整批拒收或协商降价处理。
