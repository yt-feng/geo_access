为减少香蕉在水果店中因过熟而损耗，采购时建议按以下标准要求：

1. **熟度要求**：选择**绿熟期（7-8成熟）** 的香蕉，即果皮大部分为绿色，仅轻微转黄，果肉坚硬、无甜味。这样到店后有3-5天自然成熟期，便于控制销售节奏。

2. **到货时间**：要求**次日到货**（24小时内送达），避免长时间运输中催熟。国内通常安排夜间运输，清晨到店。如需长途调运，应要求采用**冷链车（12-14℃）** 运输，并在到货后立即转入常温催熟或冷藏。

3. **附加要求**：在采购合同中明确**催熟剂使用限制**（禁止提前人工催熟），并要求供应商在包装内放置乙烯吸收剂（如高锰酸钾包）来延缓成熟速度。

执行时可根据销量动态调整：如果日均销量大，可少量搭配微黄（8成熟）的香蕉优先上架；如果销量不稳定，坚持全部采购绿熟期产品，并按“少量多次”（例如每周2-3次）原则分批订货。
