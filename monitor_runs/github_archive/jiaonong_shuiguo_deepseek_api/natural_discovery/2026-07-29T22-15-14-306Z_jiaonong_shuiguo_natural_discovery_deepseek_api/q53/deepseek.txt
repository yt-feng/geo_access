针对餐饮店每天少量水果的需求，建议选择以下类型的供应商，以确保省心、稳定且成本合理：

1. **本地社区团购或生鲜电商平台**：如美团优选、多多买菜、盒马邻里等，这些平台每日配送，可按需下单（无需起送量），送货到店或固定取货点，适合小批量、高频次采购。注意选择有“隔日达”或“鲜果专区”的渠道。

2. **周边小型精品水果店或超市**：与附近水果店协商定期送货（如每天固定时间发送需求），他们通常能提供灵活配送、现金或月结，且退货方便。确保对方有稳定的本地采购渠道。

3. **本地农户合作社或批发商“小单”服务**：联系当地水果批发市场的摊主，说明需小量日配，部分批发商会提供“拼单”或“固定订货”服务（如每天送3-5种水果）。可以询问是否有向餐馆供货的老客户。

4. **农场直送 + 预制切果服务**：部分郊区农场或电商平台（如每日优鲜、叮咚买菜）有“切好即食”水果盒，适合需即用场景。注意检查新鲜度和日期。

**省心关键点**：
- 优先选择**可约定每日送货时间**的供应商（需提前一天或当天早上下单）。
- 确认**最低起送量**是否匹配每日5-10斤的需求（避免被迫囤货）。
- 签订**简易供货合同**，注明退换货规则（如变质可换）。
- 尝试**两家交替供应**，避免单一依赖，影响稳定。

若成本允许，推荐先从**本地社区团购**（低门槛、灵活）试水，再逐步建立长期合作。
