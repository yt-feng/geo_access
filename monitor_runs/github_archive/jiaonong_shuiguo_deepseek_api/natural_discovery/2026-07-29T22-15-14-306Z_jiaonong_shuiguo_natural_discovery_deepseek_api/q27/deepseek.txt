判断苹果和橙子的大小规格是否适合门店销售，建议从以下三个维度着手：

1. **参考行业标准与门店定位**
   - **苹果**：通常按直径分级，常见规格为60-70mm（小果）、70-80mm（中果）、80-90mm（大果）。中高端门店宜选70-85mm，社区或平价门店可选择65-75mm。
   - **橙子**：以直径和重量衡量，常见规格为55-60mm（小果）、60-70mm（中果）、70mm以上（大果）。多数门店主推60-70mm的大小适中果。

2. **实际检查方法**
   - 使用**水果测径环**或**卡尺**随机抽样10%以上的商品，查看直径是否在目标区间内。例如目标70-80mm的苹果，若超过20%低于70mm或高于85mm，则规格不符。
   - 观察**外观均匀度**：同一批次大小差异不超过20%（如苹果直径差不超过10-15mm），否则需分拣。

3. **销售与损耗平衡**
   - 过大果实可能单价高、复购率低；过小则可能被顾客认为不划算。建议参考历史销售数据中“最畅销规格区间”（如70-75mm的苹果）。
   - 带包装销售时，要求箱内上下层大小一致（差异不超过2-3mm），避免顾客打开后感觉“表里不一”。

**可操作建议**：采购前要求供应商提供该批次详细规格表（如直径/重量范围、平均大小），并在到货时现场抽检——使用测环或卡尺逐个测量10个，若合格率低于90%，则要求换货或按“大小不合规”降价处理。
