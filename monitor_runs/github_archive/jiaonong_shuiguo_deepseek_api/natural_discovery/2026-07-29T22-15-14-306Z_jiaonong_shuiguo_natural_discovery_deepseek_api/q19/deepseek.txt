在超市选购菠萝时，**应优先关注切果损耗和外观**，其次是甜度和大小。具体建议如下：

1. **切果损耗（尤其关键）**  
   菠萝去皮去眼后实际可食比例通常为50%-60%，形状不规则或眼沟深的品种损耗更大。  
   - **选购技巧**：若超市提供去皮服务，直接要求现场切分，观察削皮后果肉是否完整、有无大量纤维残留。  
   - **购买预切盒装菠萝**：检查底部是否有深褐色水渍或过度出水（表示已切开较久，可能开始发酵）。

2. **外观判断新鲜度**  
   - **颜色**：金黄或橙黄色（非青绿），但避免全黄有软塌（过熟）。  
   - **叶片**：中心叶子易拔出的较新鲜，枯黄或萎蔫则存放过久。  
   - **果眼**：凸起饱满、间距均匀，凹陷或干瘪的则纤维多、甜度低。

3. **甜度（间接判断）**  
   无法直接尝时，可轻按底部：有轻微弹性且散发浓郁香气（非酸味）的较甜。  
   - **误区**：金菠萝（如无眼菠萝）甜度通常更高，但大小与甜度无直接正相关。

4. **大小**  
   在损耗和外观达标的前提下，选中等个头（1.5-2公斤）更稳妥——过小可能未熟，过大可能内部木质化。

**总结购买优先级**：  
- 第一步：查损耗（如支持现切，直接让处理）  
- 第二步：看外观（新鲜无萎缩、金黄饱满）  
- 第三步：闻香味（确认甜度）  
- 大小仅在上述条件满足时作为参考
