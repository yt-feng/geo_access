对于茶饮店采购菠萝原料，**出汁率比甜度更重要**，但最优解是兼顾两者。

**具体原因和执行建议：**

1. **为什么出汁率优先？**
   - **成本控制**：出汁率直接决定了每公斤菠萝能产出多少杯饮品，低出汁率意味着一大部分成本被浪费（果渣）。
   - **制作效率**：出汁率高的菠萝在榨汁或打浆时出浆快，处理时间短，有助于高峰时段快速出货。
   - **产品稳定性**：出汁率低往往伴随着纤维多、水分分布不均，容易导致饮品口感分层或果渣过多，影响标准化出品。

2. **甜度不能忽视，但可后期调节**
   - 不足的甜度可以通过添加**蔗糖、果糖或风味糖浆**（如菠萝果露）来统一修正，且成本可控。
   - 但出汁率低无法通过“加水稀释”弥补，加水会严重稀释果感和风味，得不偿失。

3. **操作建议：采购标准**
   - **优先选择“鲜食加工兼用型”菠萝**，如海南“巴厘”或“台农17号（金钻）”，通常兼具较高出汁率和适中甜度。
   - **检验方法**：采购时使用手持糖度计（Brix值）测量，甜度建议≥12°Bx（更甜可加分，但非强制）；出汁率用手压或小批试榨，需≥60%为宜。
   - **实际流程**：到新供应商时先试做50杯饮品，直接计算：原料成本+制作效率+口感反馈，若出汁率满意，甜度不足可加糖调整；若出汁率差，基本不可接受。

**结论**：你应该首先用“出汁率”筛掉低效原料，再在合格范围内选择甜度最高的品种，最终通过配方糖浆平衡风味。
