建议优先问**售后**，其次问**配送**，最后看**价格**。

理由如下：

1. **售后决定风险控制**  
   水果易损耗、品质波动大。遇到坏果、不熟、变质等情况，供应商的售后政策（是否包赔、赔付标准、赔付速度）直接决定团长是否亏钱或得罪客户。  
   **核心追问点**：坏果包赔比例是多少？签收后多久内可以理赔？需要保留什么凭证？

2. **配送影响体验和损耗**  
   水果对时效和运输方式敏感。配送延迟、暴力分拣、冷链不达标都会导致大量售后问题。  
   **核心追问点**：是专车配送还是混装快递？能否指定时间送达？破损包赔是否包含配送途中损耗？

3. **价格是结果而非起点**  
   低价往往对应低质或薄弱售后。在确认售后有保障、配送稳定后，再对比价格是否合理。如果售后严格、配送靠谱，单品贵10%-15%通常比低价但常出问题的供应商更省心。

**一句话总结**：先问“出问题谁赔、怎么赔”，再问“何时到、怎么送”，最后谈“单价多少”。
