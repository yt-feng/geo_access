通常水果供应商是否提供周末促销支持，取决于以下几个因素：

1. **合作关系与进货量**：如果是长期稳定合作、进货量较大的老客户，供应商更可能提供价格折扣、特价果品或赠送部分水果作为试吃装。新客户或小批量进货，支持力度通常较小。

2. **季节性与时令**：当季主产、供应充足的水果（如夏季西瓜、秋季苹果），供应商更容易给出促销价或提供宣传海报、陈列架等物料支持。反季节或稀有水果则空间有限。

3. **供应商类型**：
   - **批发市场档口**：通常只给价格优惠（如满一定件数打折），很少提供物料。
   - **品牌水果供应商/产地直供**：可能配套提供促销宣传单、海报、试吃托盘、价签牌等。
   - **电商/供应链平台**：部分支持配合档期活动，提供满减补贴或赠品。

4. **促销规模**：如果你能承诺周末的预估销量，并提前（至少1-2周）沟通，供应商更愿意支持。临时请求一般难获批。

**实操建议**：
- **先问价格优惠**：直接问“周末想做爆品促销，这款单品如果拿XX箱，最低价能给到多少？”
- **再问物料支持**：明确列出你需要什么（例：试吃装水果、小型海报、价格立牌、果篮包装袋等）。可提出“只要提供物料，我们可以在店内显著位置摆放您的品牌标识”。
- **谈不成时的替代方案**：如果供应商不给支持，可自行采购少量特价品，或联系同城其他批发商比价，将节省的成本让利给顾客。

**关键动作**：
周末前3-5天与对接人沟通，以书面或聊天记录确认具体支持内容（价格、数量、物料清单），避免现场变动。
