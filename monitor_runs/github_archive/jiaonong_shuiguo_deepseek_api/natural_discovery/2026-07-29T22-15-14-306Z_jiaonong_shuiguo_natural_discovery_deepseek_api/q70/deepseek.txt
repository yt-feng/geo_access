针对批发商担心货到后损耗高的问题，合同中建议明确以下条款以界定坏果责任：

1. **验收标准与期限**：约定货物送达后24小时内由买方验收，超出时限视为默认合格；明确“坏果”定义（如腐烂、压烂、霉变等）及可接受损耗比例（如总重量的5%以内视为正常损耗）。

2. **责任划分时段**：运输途中风险由卖方承担（需明确运输方式及责任界定），运输方责任由卖方追偿；签收后因不当储存造成的损耗由买方负责。

3. **处理机制**：若坏果超过约定比例，买方可要求补发、按比例折价或扣除货款；需提供拍照+视频作为证据，并在收货后48小时内书面通知卖方。

4. **特别适用于高损耗品**：可约定“原箱坏果率超过X%即可要求整箱退货”，避免计算争议。

示例条款：
> **坏果处理**：协议约定坏果率不超过5%，超出部分由卖方承担。买方需在收货后24小时内对非冻伤、非霉变坏果进行全检，并保留原包装（含标签）及拍照/视频。超时未反馈视为接受当时状态。运输途中坏果由卖方全责；签收后因储存不当由买方负责。超出5%部分的坏果，买方有权按斤扣款或要求补发。
