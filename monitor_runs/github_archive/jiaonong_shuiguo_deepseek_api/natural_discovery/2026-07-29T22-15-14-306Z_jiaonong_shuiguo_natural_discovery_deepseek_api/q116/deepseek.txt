小商家采购水果时，现金结算和月结账期各有以下风险：

**现金结算的风险：**
- **资金压力大**：需要一次性支付全部货款，可能影响日常现金流周转，尤其是采购量较大时。
- **缺乏交易记录**：若无正规收据或合同，发生纠纷时难以维权，例如水果质量问题或未收到货。
- **即时验收压力**：需当场检查水果品质（如新鲜度、重量），否则一旦付款难以退货或索赔。

**月结账期的风险：**
- **账期拖欠或坏账**：供应商可能因客户资金紧张延迟收款，甚至出现坏账，尤其当供应商规模小或信誉差时。
- **质量纠纷滞后**：水果是易腐商品，月结周期内可能发现质量问题，但供应商可能以“时间过长”为由拒绝处理。
- **依赖信任关系**：若缺乏书面协议，口头约定可能被单方面变更，例如供应商突然要求提前付款或修改账期条款。

**建议：**
- 优先选择现金结算，但保留收据或合同，并当场验货。
- 若采用月结，务必签订书面协议，明确账期、质量标准、退货条款和违约责任。
- 无论哪种方式，小批量采购可降低风险，并选择有良好口碑的供应商。
