对于商超采购菠萝，建议根据门店具体情况决定，以下是两种方式的优缺点及适用场景分析：

1. **卖整果**  
   - 优点：保质期更长（常温可放3-5天），消费者可自行挑选，适合注重新鲜感和“自己切”习惯的顾客；损耗低，只需简单清洁。  
   - 缺点：需要顾客自己处理（去眼、切皮），可能会影响对“不熟悉处理菠萝”的顾客的吸引力；如果是高峰期，部分顾客可能因等待加工而放弃购买。  
   - 适合：社区型超市、人流量较平稳的门店、水果品质较高（如金菠萝）的情况。

2. **卖切好的（预切盒装）**  
   - 优点：方便快捷，适合即食消费者（如办公族、年轻顾客）；减少店内加工压力，提升坪效；可搭配其他水果做果切组合，提高客单价。  
   - 缺点：保质期短（冷藏仅1-2天），损耗风险高（需精确预估销量）；需要严格卫生管理和低温展示，成本（包装、人工、冷链）增加。  
   - 适合：写字楼店、商圈店、客流量大且节奏快的门店、对溢价接受度高的区域。

**建议方案**：  
- **双轨并行**：整果和切好各占一定比例。整果主打价格优势和新鲜感，预切盒装主打便捷（可放在冷藏区或收银台附近）。  
- **动态调整**：观察近期销售数据，若整体菠萝类整体周转慢（如滞销超过40%），则减少整果量；若预切盒装日损耗超过15%，则适当降低备货量。  
- **试销期**：先以整果为主（约60-70%），同时小批量试点预切装（如每天20-30盒），观察复购率及损耗数据后再优化比例。

**特别提醒**：菠萝切开后易氧化褐变，预切装需用保鲜膜密封或充氮包装，并标注“即食”及“冷藏保存不超过24小时”。
