可以和供应商谈锁价，但需要满足一定条件并注意以下策略：

1. **锁价的可行性**：
   - 季节性水果（如西瓜、荔枝）锁价难度大，供应商通常只接受短期（1-2周）锁价。
   - 常年稳定供应的水果（如苹果、橙子）较易谈判，可尝试按月锁价。
   - 需明确锁价范围（如整果/切果）、质量标准（如糖度、规格）。

2. **谈判条件**：
   - 承诺最低采购量（如每月固定订单），降低供应商风险。
   - 接受价格浮动条款（如市场价上涨超10%时双方分担差价）。
   - 签订保底协议，约定供应商优先供应权。

3. **风险控制**：
   - 加入“不可抗力条款”（如产地灾害导致断供可调整价格）。
   - 与2-3家供应商同时谈判，形成竞争性报价。
   - 优先选择本地或区域供应商，减少物流波动影响。

4. **替代方案**：
   - 与供应商共建小型冷库，分摊储存成本，淡季采购锁价。
   - 采用“保底价+浮动价”模式（如市场价低于保底价时按市场价结算，高于保底价时保底价结算）。

建议从小批量、短周期试签，根据数据调整后再扩大锁价范围。
