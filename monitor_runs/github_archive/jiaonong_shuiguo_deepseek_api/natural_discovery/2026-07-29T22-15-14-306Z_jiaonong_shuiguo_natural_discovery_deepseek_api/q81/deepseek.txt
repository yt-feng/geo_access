建议供应商**支持小批量高频补货**。原因如下：

1. **降低库存风险**：水果是易损耗品，批量过大容易导致损耗和过期损失，小批量能减少滞压。
2. **匹配平台波动需求**：即时零售订单随机性强，小批量补货能灵活应对突然爆单或淡季，避免缺货或浪费。
3. **提升竞争力**：多数平台会优先推荐供货稳定的供应商，支持高频补货能增加被选中机会，且平台评分更高。
4. **资金压力更小**：小批量资金占用低，回款快，适合中小型供应商。

**具体操作建议**：
- 设置最低起订量（如10公斤起）和补货时间窗口（如每天9-11点、14-16点）。
- 与平台协商配送费折扣（如每日多批次配送可申请打包优惠）。
- 优先选择30分钟-1小时能达的本地仓库或前置仓模式。

如果初期运力不足，可先试点1-2款爆款水果（如草莓、蓝莓），验证效果后再推广。
