针对小面积便利店的水果经营，核心策略是：**少进、勤进、快销、精选**。以下是具体建议：

**一、品类控制：做减法，选爆品**

1.  **聚焦“高频、耐放、易打理”的3-5个单品**，比如：苹果、橙子、香蕉（最走量）、梨、火龙果。这几种对保鲜设备要求低，存储简单。
2.  **坚决避免“多而全”**：不卖草莓、蓝莓、芒果等极易损耗的时令水果，除非有专门的冷藏柜并作为高毛利引流品。
3.  **引入“引流+高毛利”组合**：比如用香蕉（低价引流）+ 红富士（大众常购）+ 每日精选1-2款小份装应季水果（高毛利）。
4.  **设置“组合小包装”**：将几种水果切好或混装成小份（200g-300g），单价低，适合一人食或解馋，减少库存压力。

**二、损耗控制：从进到售全流程**

1.  **采购环节**：
    -   **每日少量多次**：和供应商约定每日或隔日配送，根据前一日销量预估2-3天的量。
    -   **严格验收**：到货时当场检查成熟度（如香蕉不能太生或太熟）、有无机械伤、病虫害。拒收不合格品。
    -   **分级采购**：部分水果（如苹果）可采购“二级果”（外观稍差但口感一样），降低成本。

2.  **存储与陈列**：
    -   **常温区/风幕柜**：香蕉、苹果、橙子等可常温避光存放；切好的水果、浆果需冷藏（4-8℃）。
    -   **先进先出**：每天检查，将快成熟的或隔夜水果放在最前边，并贴上“今日特价”或“尽快食用”标签。
    -   **少摆勤补**：展架只放当日预估销量的60-70%，货品从后台库存补，避免长期暴露在常温下。

3.  **销售与止损**：
    -   **动态定价**：午后和晚间对卖相稍差的进行打折促销（如“9.9元一盒”）。
    -   **二次加工**：皮损、切开的水果立即处理成**切盘、果汁或水果沙拉**（需要冷藏展示柜和卫生许可），以更高毛利售出。
    -   **设定“止损单”**：明确每种水果的“最佳赏味期”和“报废期”，过期坚决下架（可转员工福利或加工）。

**三、日常操作模板（以50平米门店为例）**

-   **进货清单**：每日到货：香蕉1箱 + 苹果3箱（规格：小果）+ 橙子2箱 + 精选时令品（如葡萄/西瓜，带皮，1-2箱）。
-   **陈列**：门口黄金位置摆香蕉（限时促销），中间架放苹果/橙子，收银台附近放小份切盘。
-   **监控指标**：每日记录每种水果的**进-销-存**，**单品损耗率**控制在**3%以下**（标准：香蕉不超过5%，苹果2%）。一旦某个单品日销量连续两天低于进货量50%，立即暂停进货。

**总结**：宁愿有时断货，也不要积压库存。对于小门店，**香蕉是生命线，苹果是压舱石**，其他都是“周末限定”或“顾客点名才进”。
