对于食堂采购水果的管理，建议优先采用**按斤结算**，这是最透明、易核算的方式。具体分析如下：

- **按斤结算**：  
  优点：价格透明，便于核对重量，避免因容器（箱子）重量或水果大小不均造成的隐性损耗；适合批量采购，也容易根据实际消耗调整采购量。  
  缺点：需要现场称重，可能增加人工和耗时。

- **按箱结算**：  
  优点：快速结算，适合标准化包装（如同一规格的苹果箱）。  
  缺点：箱体重量（皮重）可能未被计入，导致实际果重不足；不同批次或不同水果的箱内品质、大小差异大，容易引发纠纷。

- **按份结算**：  
  优点：适合即食水果（如切好的果盒），方便直接售卖或配餐。  
  缺点：标准化难，每份重量、新鲜度不一；成本核算复杂，难以控制损耗。

**综合建议**：  
- 大宗常规采购（如苹果、梨、橙子）用**按斤结算**，选几家供应商比价，搭配随机抽检重量。  
- 如果供应商信誉好且包装标准统一（如整箱标注净重），可用按箱结算，但需定期抽查实际净重。  
- 已加工好的水果（如切块拼盘）才考虑按份结算，同时要求供应商提供明确重量或规格标准。

**执行要点**：  
1. 建立采购记录表，登记每次水果种类、重量、价格和供应商。  
2. 定期比对实际消耗与采购量，及时发现损耗异常。  
3. 可指定专人验收并随机复秤，避免短斤少两。
