在超市采购香蕉避免过生或过熟，可以参考以下实用方法：

1. **看颜色和状态**  
   - **最理想**：香蕉整体呈亮黄色，两端带少量绿色（无青柄）。这种处于“七八分熟”，室温下可放2-3天。  
   - **太生**：通体青绿色，手感硬。需放置多日才能吃。  
   - **太熟**：出现大块黑斑、表皮发软、有汁水渗出（尤其柄部），内部可能已软烂。

2. **检查表皮细节**  
   - 避免有**破裂、软坑或霉点**（可能已过熟或受损）。  
   - 捏一下香蕉柄：如果**柄部发黑、干枯**，说明存放较久。

3. **根据食用时间选择**  
   - **当天/明天吃**：选**全黄、无青绿色**，略带芝麻点也可。  
   - **2-3天后吃**：选**黄色带微绿**，捏起来略硬。  
   - **需要更久储存**：选**绿色为主，微黄**，室温下慢慢成熟。

4. **避开“混装加速”**  
   - 超市常把**过熟香蕉**（有黑斑、变软）和较生的放在一起，乙烯会催熟其他香蕉。尽量从成串中挑选**颜色相对均匀**的。

5. **额外技巧**  
   - 买回后如果太生，可以**和苹果/梨一起放纸袋**（产生乙烯）快速催熟。  
   - 如果一次买多串，把**最熟的单独拿出**先吃，其余分散放置（别堆叠）。

**总结**：优先选**亮黄、微带青、表皮光洁**的香蕉，根据需求判断绿色程度。避开有明显黑斑、软塌或柄部发黑的。
