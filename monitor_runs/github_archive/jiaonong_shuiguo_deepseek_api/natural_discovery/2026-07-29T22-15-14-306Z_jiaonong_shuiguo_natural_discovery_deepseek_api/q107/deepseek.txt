是的，起订量太高确实会增加损耗风险。具体分析如下：

1. **库存压力**：高起订量意味着一次性采购量大，如果销售速度跟不上，水果容易因存放时间过长而变质（尤其是香蕉和菠萝这类易腐水果）。
2. **储存条件要求高**：香蕉对温度敏感（最佳储存温度13-15°C），菠萝也需通风避免过熟。大量库存若存储不当（如冷库容量不足、分拣不及时），会加速腐败。
3. **分拣难度**：批量进货时，可能混合不同成熟度的水果。若无法快速分级销售（如熟的先卖），滞留在库房的部分会过度成熟，导致损耗。
**建议**：
- 根据历史销售数据和周转天数，计算合理起订量。
- 与供应商协商阶梯价格或小批量试购，降低首单风险。
- 设计促销活动（如分拆包装、搭配销售），加速消化库存。
- 强化供应链协同（如预售、到货前冷库预冷），减少损耗。
