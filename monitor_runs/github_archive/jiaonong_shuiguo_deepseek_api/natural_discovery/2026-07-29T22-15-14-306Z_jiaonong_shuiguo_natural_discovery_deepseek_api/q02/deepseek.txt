对于小水果店来说，**熟度**和**坏果率**是最关键的，其次是**价格**，**送货速度**相对次要。以下是具体建议：

1. **熟度（优先）**：香蕉是后熟水果，进店时熟度需控制在7-8成熟（青皮微黄）。如果太生（全青），顾客可能等不及成熟而流失；太熟（有黑斑）则不耐放，易损耗。建议选择进库后2-3天可自然转黄的批次。
   
2. **坏果率（硬指标）**：香蕉运输中容易碰撞导致“黑指甲”（果皮碰伤）或腐烂。进店后应立即抽查整箱底部和中间层，坏果率超过5%应要求换货或折价。高坏果率会直接吃掉利润。

3. **价格（预算平衡）**：如果熟度和坏果率都合格，再对比价格。小店铺量小，不必追求最低价，重点找“性价比稳定”的供应商。可尝试和批发商谈“保价保质”的小批次合作。

4. **送货速度（次要）**：香蕉不耐久放，但通常批发市场可次日达。只要送货时间在24小时内，且能固定时间到货（避开营业高峰期），就不必过分追求“极速”。建议优先选择能稳定配送、且允许临时加单的供应商。

**简单操作法**：初见供应商时，先要1箱样品放到店试卖3天，观察转色速度、损耗比例和顾客反馈，达标后再长期合作。
