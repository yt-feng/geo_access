对于餐饮连锁企业而言，中央厨房统一收货通常比门店分开收货更优，具体分析如下：

**推荐方案：中央厨房统一收货**

**优势：**
1. **成本控制更优**：集中采购量大，可争取更低单价；减少配送频次和总物流成本。
2. **品质更稳定**：中央厨房可统一验收标准、清洗、分切，降低门店自检误差和损耗。
3. **减少门店负担**：门店无需单独安排人力和场地接收、处理水果，专注服务与销售。
4. **食品安全可控**：统一冷链管理和加工环境，符合监管要求，易溯源。

**需注意的挑战：**
- 需具备分拣、暂存及冷链配送能力。
- 门店需求差异大时（如不同规模店），需精准预测并分装配送。
- 配送距离过远或门店分散时，可能增加二次运输时间和成本。

**判断条件**（考虑门店分开收货的情况）：
- 门店位于不同城市且物流网络不完善，或门店对水果成熟度有实时独立要求（如即切即用）。
- 中央厨房规模小、设备不齐全，且门店有独立验收能力。

**建议优先实施路径**：
1. 评估中央厨房处理能力、冷链半径和预测准确度。
2. 对高损耗或短保水果（如莓果、香蕉）试行中央统一分装后配送。
3. 初期可对少数旗舰店保留门店直采权限，作为对比参照。

若连锁门店超过10家且配送半径在合理范围内（如同城或同区域），中央厨房统一收货效益更显著。
