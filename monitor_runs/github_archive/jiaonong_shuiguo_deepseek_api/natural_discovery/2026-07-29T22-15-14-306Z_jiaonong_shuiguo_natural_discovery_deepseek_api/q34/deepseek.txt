在商超采购水果时，**损耗低通常比价格低对最终毛利的影响更大**。原因如下：

1. **损耗直接影响可售数量**：水果属于易腐商品，如果损耗率高（如变质、磕碰），即使采购单价很低，实际可销售的数量减少，会导致单位成本上升，拉低毛利。
2. **毛利公式的结构**：最终毛利 = 销售收入 - 商品成本。低价采购虽然能降低成本，但如果损耗达到10%-20%（常见于水果），实际成本会因“损耗部分”被摊高，而低价带来的节省可能被抵消甚至反超。
3. **损耗的副作用**：高损耗还会导致增加人工理货、折价处理等隐性成本，并可能影响顾客体验从而降低复购率。

**建议操作策略**：
- 优先选择供应稳定、品控严格的供应商（即使单价略高），控制损耗在5%以内。
- 针对易损水果（如草莓、葡萄）可引入预包装或冷链环节，采购时对成熟度、包装状态做检查。
- 如果必须采购低价水果，需确保周转速度快（比如做促销或限量采购），避免库存积压导致损耗。

简单对比：假设进价10元/斤，售价20元/斤，损耗20%时，实际毛利率为（20-10×1.25）÷20 = 37.5%；若进价12元/斤但损耗5%，实际毛利率为（20-12×1.05）÷20 = 37%，几乎持平。损耗降低带来的收益可与降价竞争相仿甚至更优。
