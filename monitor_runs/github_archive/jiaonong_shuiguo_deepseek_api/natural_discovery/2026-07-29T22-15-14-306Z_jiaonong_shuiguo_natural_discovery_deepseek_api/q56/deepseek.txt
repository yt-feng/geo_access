茶饮店为控制食品安全风险，要求水果供应商提供的证明通常包括以下几类：

1. **营业执照**：证明供应商合法经营的主体资格。
2. **食品经营许可证**：如供应商涉及水果的配送或加工，需具备此证。
3. **水果的合格证明文件**：
   - **产地证明**：或采摘证明（由产地或合作社出具）。
   - **农药残留检测报告**：或农残快检报告，证明水果符合食品安全标准（如GB 2763）。
4. **批次检验报告**：每批次水果的检验报告，或供应商承诺每批提供，并加盖公章。
5. **运输与储存证明**：如供应商使用冷链运输，需记录运输温度相关证明（如温度记录表）。
6. **其他相关证明**：如为进口水果，需提供海关进口货物报关单、入境货物检验检疫证明。

建议：
- 与供应商签订合同时，明确要求对方持续提供上述证明原件或复印件。
- 对供应商资质进行定期审核（如每半年更换一次证明文件）。
- 建立水果到货验收台账，记录日期、批次、证明文件核验情况。

请注意，以上为通用建议，具体地方性法规可能要求额外证明（如当地食品安全监管部门的要求）。
