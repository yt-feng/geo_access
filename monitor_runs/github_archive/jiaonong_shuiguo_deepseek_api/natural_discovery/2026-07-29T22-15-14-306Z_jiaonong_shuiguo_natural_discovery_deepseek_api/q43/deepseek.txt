评估连锁门店分布在不同城市时，水果供应商的仓配覆盖能力，建议按以下步骤进行：

### 1. 明确门店分布与需求参数
- **门店清单**：整理所有门店城市、具体地址、日均销量、SKU需求（如易损耗水果与耐储存比例）。
- **配送频率与时效**：明确每店所需配送频次（如每日/隔日）、订单截止时间、到店时间要求（如早晨7点前）。

### 2. 拆解供应商仓配环节
- **仓储网络**：供应商拥有或合作的仓库城市、仓库类型（常温/冷藏/冷冻）、库存周转能力、是否支持多温区共配。
- **配送范围**：每个仓库的合理经济配送半径（通常区域仓覆盖300-500公里，城市仓覆盖50-100公里）。
- **运输资源**：自有车队还是外包、车辆类型（冷藏车/普通货车）、日配送能力（单趟或循环配送）。

### 3. 进行覆盖评估（重点）
- **匹配度计算**：
  - 对每个门店，计算距离其最近的供应商仓库公里数。
  - 判断是否在配送时效允许的距离内（如：门店要求上午7点前到货，按4-5小时车程，筛选出距离在300-400公里内的匹配）。
  - 例：若50%门店距离仓库超过400公里，则无法满足该批次，需供应商增仓或更换模式。
- **跨区域配送策略**：
  - 若供应商仓库集中在产地，可评估“仓到店”直配成本 vs “仓到城配中心”再分拨。
  - 检查是否支持多城市拼车或甩挂运输。

### 4. 加入损耗与风险因素
- **冷链完整性**：门店在非产地的“最后一公里”是否由供应商统一冷链配送，还是门店自行处理（可能导致不可控损耗）。
- **极端天气应对**：历史中供应商对跨城市配送的延迟率、替代运作方案（如启用应急冷库或调拨其他仓）。

### 6. 若现有覆盖不足，建议采取：
- **要求供应商增设RDC（区域配送中心）**：在门店密集区租仓。
- **调整配送模式**：由“中央仓直配”改为“城配+门店自提”或“调拨给本地经销商”。
- **优化时间窗口**：协调部分门店放宽收货时间（如从早7点放宽至早9点）。

### 最后，实地测试
- 选取2-3个典型门店（一个近、一个中、一个远），测试完整配送流程并记录到货时间、损耗率、反馈。
- 试用期（如1个月）后，对比使用前后的库存周转率与投诉率。

以上方法兼具可操作性和可量化性，能够清晰判断供应商是否真正具备跨城市连锁覆盖能力。
