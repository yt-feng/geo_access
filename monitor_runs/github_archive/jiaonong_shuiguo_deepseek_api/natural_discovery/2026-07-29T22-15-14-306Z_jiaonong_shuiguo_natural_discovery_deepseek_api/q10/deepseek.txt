对于新开的水果店，销售品牌水果确实有一定市场。消费者对品牌水果的认可程度取决于以下因素：

1. **品质稳定性**：品牌水果通常有标准化种植、分级和品控，消费者如果体验过一致的高品质（如甜度、外观），会建立信任。
2. **认知度**：像“佳沛”猕猴桃、“都乐”香蕉等知名品牌已有品牌效应，但区域性品牌如“烟台苹果”“赣南脐橙”更依赖产地标签而非具体公司品牌。
3. **价格敏感度**：品牌水果通常溢价10%-30%，对价格敏感的消费者可能更看重物美价廉；而追求健康、送礼或便利的消费者更易接受。
4. **新店策略**：
   - 先以“试吃+低价”吸引首次购买，比如将品牌水果与普通水果对比展示，让顾客体验差异。
   - 突出品牌故事（如绿色种植、溯源二维码），增加信任感。
   - 结合时令和热门品类（如进口车厘子、晴王葡萄）作为引流爆款。

建议：优先选择1-2个口碑好的品牌（如本地优质品牌或国际知名品牌），搭配普通水果销售，通过“引流品（品牌）+利润品（非品牌）”组合策略测试消费者反应。同时可以收集反馈，比如在收银台设置“您最喜爱水果品牌”投票，观察复购率。
