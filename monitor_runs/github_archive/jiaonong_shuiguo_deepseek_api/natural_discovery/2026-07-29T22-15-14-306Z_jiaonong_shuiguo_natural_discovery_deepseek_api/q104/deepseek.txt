针对单位采购水果到货品质不一致的情况，建议按以下流程处理验收和售后：

### 验收阶段
1. **当场开箱抽查**：每批次随机抽取不少于20%的箱数（整箱水果需拆包检查），重点查看成熟度、有无腐烂/机械损伤、规格是否与合同一致。如发现明显问题，立即拍照、录像留证。
2. **使用验收标准对照**：对照采购合同或协议中约定的等级（如一级果、特级果）、品种、果径大小、成熟度（如：苹果着色度≥80%）进行比对。若无明确标准，可参照《JJF 1239-2010 原产地水果等级》或行业惯用标准。
3. **登记验收单**：标明到货数量、品牌、批次号、实际品质描述，由送货方和收货方双人签字确认。批次不合格率超过10%或存在单一严重问题（如大量腐烂），可直接拒收整批货物。

### 售后阶段
1. **固定证据**：完整保留问题水果的实物（或密封冷冻保存）、包装、配送单据、聊天记录/通话录音。如涉及批量变质，还需及时通知供应商到场确认。
2. **依据合同索赔**：一般合同会约定“到货后24小时内反馈异议”。超时可能视为默认合格，务必在时限内书面或系统内提交《品质异议单》。
3. **协商处理方案**：
   - **部分让步接收**：接受品质稍差的批次，但按比例扣减价款（如：腐烂超過15%的部分按行价50%计价），或要求供应商补发等量合格水果。
   - **要求换货**：不合格部分在3~5个工作日内补发或更换，运费由供应商承担。
   - **全额退货**：问题严重（如缺斤短两超5%或变质灭失销售价值），可要求全额退款，并赔偿因延误造成的损失（需提前明确违约责任）。
4. **升级投诉**：若供应商推诿，可向合同签订地市场监督管理局（12315）或消费者协会（单位采购可拨打12345政务热线）投诉。涉及生鲜产品的，可同步要求检验机构出具质量鉴定报告（如：果蔬农残、新鲜度检测）。

### 注意事项
- 避免先签字后验货，先签字即视为认可。
- 保留采购合同、付款凭证、验收单据至少两年，以防后续法律纠纷。
- 若单位采购量较大，建议签订合同时增加“看货确认”条款，允许预付比例款后实地到供应商仓库验货再发运。

以上流程同时适用于线下批发和电商采购。如果供应商是固定合作方，建议在合同周期内约定“不合格率年度累计不超过X%”的惩罚机制。
