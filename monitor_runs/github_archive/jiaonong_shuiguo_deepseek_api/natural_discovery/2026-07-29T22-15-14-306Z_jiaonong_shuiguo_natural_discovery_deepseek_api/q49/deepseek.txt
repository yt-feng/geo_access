针对茶饮店旺季菠萝临时补货的情况，建议按以下步骤操作，确保快速、稳定且成本可控：

1. **确认紧急需求与库存**：先精确统计未来3-7天的实际菠萝用量（如每天多出的杯量），计算缺口。同时联系现有供应商，确认其是否能短期加量，以及最快到货时间。

2. **明确补货条件**：与供应商沟通时，说明是临时补货，需约定以下内容：
   - **价格**：旺季可能涨价，尽量按原合同价或协商一个短期浮动比例（如每斤上浮不超过5%）。
   - **质量**：要求新鲜度、大小、甜度等标准与常规供货一致，并预留退换货条款。
   - **交货时间**：明确具体到货日期和时段（如次日11点前）。
   - **最小起订量**：询问能否按实际需求分批小量补货，避免囤货。

3. **签订临时补充协议**：以书面形式（如邮件、微信确认或简易订单）记录上述约定，避免口头承诺。内容包括：品名（如菠萝，去皮/带皮）、数量、单价、总价、交货地点、验收方式。

4. **预留应急方案**：若原供应商无法满足，可联系备用供应商（如当地批发市场或生鲜平台），但需额外注意：优先选择可当日配送、有质检报告的商家；临时价格可能偏高，可尝试要一个“批量梯度价”（如首次试单按原价，后续加量适当优惠）。

5. **验收与结算**：到货后立即检查菠萝外观、气味、重量，按约定标准验收。不合格品拍照留证，及时沟通退换或扣款。结算按合同期限执行，避免因旺季付款延迟影响后续合作。

**核心提醒**：旺季容易断供，建议提前1-2天发出补货需求，并与供应商确认物流安排（如冷链运输、司机联系方式）。同时，考虑将部分菠萝制成冷冻果泥或罐头，以缓解短期原果压力。
