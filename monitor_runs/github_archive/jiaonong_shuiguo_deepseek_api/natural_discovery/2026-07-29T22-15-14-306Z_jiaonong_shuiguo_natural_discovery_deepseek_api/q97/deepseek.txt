在酒店采购水果盘原料时，供应商应确保以下规格和外观标准，以保证出品质量与客户满意度：

**一、规格标准**
1. **品种与尺寸**：按酒店要求提供指定水果品种（如哈密瓜、西瓜、芒果、草莓等），每种水果的成熟度一致，单个重量或尺寸符合餐盘搭配要求（例如西瓜片厚度一致、草莓大小均匀）。
2. **清洁度**：无泥沙、虫卵、农药残留（需提供农残检测报告），表皮无污渍、胶带残留或蜡质涂层。
3. **包装与防护**：使用食品级包装材料，运输过程中应有防震、防挤压措施，避免水果碰撞损伤或变质。

**二、外观标准**
1. **新鲜度**：果蒂鲜绿、果皮有光泽，无萎缩、干瘪或失水现象；切开后色泽自然，无氧化发黑或褐变（如苹果、梨）。
2. **完整性**：无机械损伤（如压痕、划痕、磕碰），无虫蛀、霉斑、软烂、流汁或裂口（如葡萄、樱桃易裂果需特别留意）。
3. **成熟度**：达到可食用成熟度但不过熟（如香蕉无黑斑、芒果软硬适中、火龙果皮色均匀），且同批次成熟度一致，方便整盘摆放。
4. **无异味**：无发酵酸味、霉味或化学药品气味（如部分进口水果防腐剂残留）。

**三、其他要求**
- **冷藏运输**：对易腐水果（如草莓、蓝莓、荔枝）需全程冷链，温度控制在0-4℃，到货时内温需达标。
- **批次允许误差**：单批次外观瑕疵率建议≤5%（如极少轻微碰痕），且供应商需提前告知可能存在的自然缺陷（如猕猴桃形状不一）。

**建议采购流程**：
- 在合同中明确上述标准，附参照图片或规格表。
- 到货时随机抽样检查，不合格批次退回或按比例扣款。
- 对长期供应商可要求定期第三方质检报告。
