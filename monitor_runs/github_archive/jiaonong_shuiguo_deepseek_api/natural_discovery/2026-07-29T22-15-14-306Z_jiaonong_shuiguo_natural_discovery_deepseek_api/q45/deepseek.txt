连锁超市与水果供应商签订年度合同时，以下几类条款最容易踩坑，需重点审查：

1. **价格调整机制不明确**  
   - **风险**：年度合同可能约定固定价格，但水果受季节、天气、运输成本影响价格波动大，供应商可能要求临时加价或单方解约。  
   - **建议**：明确价格浮动范围（如参考批发市场均价±10%）、调价周期（如每月/每季调整）及触发调价的条件（如连续3日涨幅超过15%）。

2. **品质标准模糊**  
   - **风险**：仅写“新鲜”“无损伤”等模糊表述，可能导致到货时超市方嫌弃品相，供应商拒绝退货。  
   - **建议**：附明确等级标准（如国标一级；果径、糖度、色号具体指标）、验收流程（到货后24h内抽检比例）、劣果判定规则（如单箱坏果超过5%可整箱拒收）。

3. **交货时间与地点弹性过大**  
   - **风险**：供应商可能以“根据库存调整”延迟交货，超市方因缺货损失销售；或送货到错误门店增加二次转运成本。  
   - **建议**：明确每周/每日最低到货量、到货时间窗口（如上午8-10点）、具体门店名称及违约罚则（如延迟1日扣货值5%）。

4. **生鲜损耗分担缺失**  
   - **风险**：水果在运输、上架后自然腐烂损耗（如草莓3天损耗10%），合同未约定则超市方可能全担损失。  
   - **建议**：约定合理损耗率（如草莓≤8%，香蕉≤5%），超出部分由供应商补货或折扣结算。

5. **单方解约条款不公**  
   - **风险**：供应商可能因高价卖出他人而随意终止合同，但超市方因投入促销资源难以退出。  
   - **建议**：设定双向解除条件（如供应商月供货量低于约定80%累计3个月，超市方有权解约并索赔），并规定提早通知期（至少30天）。

6. **退换货条件苛刻**  
   - **风险**：超市方发现部分水果变质要求退回，供应商可能要求“整单退货”或“拍照后自行销毁”不补货。  
   - **建议**：明确退换货流程（如48小时内书面通知 + 拍照留存）、处理方式（部分变质折价结算，严重则供应商24小时内补发）。

7. **付款周期与质量保证金**  
   - **风险**：账期过长（如到货后90天付款）可能压垮小型供应商；或保证金用于惩罚超市方主观拒收。  
   - **建议**：账期控制在30-45天；保证金比例≤10%，且仅用于扣罚供应商的实质违约（如供货掺假），需双方签字确认。

**行动建议**：  
- 找有生鲜经验的律师审合同，尤其注意“争议解决”条款（约定本地法院管辖，避免去供应商所在地打官司）。  
- 首次合作可先签3个月短期合同，积累数据后再签年度协议。  
- 附件保留所有订单、验收单、品质照片等证据，避免口头承诺。
