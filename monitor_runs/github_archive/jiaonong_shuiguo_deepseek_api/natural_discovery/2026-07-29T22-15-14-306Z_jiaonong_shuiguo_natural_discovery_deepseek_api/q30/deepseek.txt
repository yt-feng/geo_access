针对超市水果到货品相不好的情况，建议在采购合同中明确以下售后流程约定：

1. **验收标准**：明确品相要求（如颜色、大小、无损伤、无腐烂等），可附照片或样品作为参照。
2. **验收时限**：收货后24小时内（或合理时间）完成验收，超时视为认可品相。
3. **问题处理流程**：  
   - 收货方发现品相不符时，需在验收期内拍照留存证据，并书面通知供货方。  
   - 双方协商处理方式：退货、换货、折扣或补偿（如按比例扣减货款）。  
4. **责任划分**：若因运输或包装不当导致品相受损，应在合同中明确责任方。  
5. **争议解决**：约定仲裁或法院管辖地优先。  

建议保留书面凭证（合同、验收记录、沟通记录）以备争议。
