选择适合批量配送的水果供应商，建议从以下几方面评估：

1. **品质与品种稳定性**：要求供应商提供样品（如整箱苹果、香蕉等），检查有无碰伤、腐烂、过度成熟；确认是否能稳定供应你需要的品种（如当季水果、耐运输品种如哈密瓜、柑橘、苹果等）。

2. **配送能力与时效**：明确是否能在指定时间（如下午茶前2小时）送达，以及配送范围是否覆盖你的公司地址。可要求试用配送一单，观察包装是否防撞（如分隔纸箱、泡沫网套）、配送时效是否达标。

3. **价格与批量优惠**：对比3-5家供应商的单价（需按箱或按斤报价），计算含配送费的总价。批量采购通常可谈折扣，例如每周固定采购、月结等方式争取更低价格。

4. **资质与售后**：查验供应商营业执照、食品经营许可证（如需）。明确水果收货后24小时内出现变质、损坏是否包退换，以及赔偿比例（如按重量或金额）。

5. **应急与灵活性**：确认如果临时增加采购量或更改品种，供应商能否快速响应。可要求备选方案（如提前确定应急供应商）。

**具体操作建议**：
- 初期可先自提或小批量试单（如采购10箱不同水果），验证口感、新鲜度和包装。
- 长期合作前，签订合同明确配送时间、质量标准、付款周期（如交货后7天结算）。
- 部分生鲜电商平台（如美菜、叮咚买菜企业版）或当地批发市场商户也提供企业配送服务，可多渠道比较。

请注意：以上建议无需核实来源，但具体供应商信息（如电话号码、链接）需你自行搜索当地资源。
