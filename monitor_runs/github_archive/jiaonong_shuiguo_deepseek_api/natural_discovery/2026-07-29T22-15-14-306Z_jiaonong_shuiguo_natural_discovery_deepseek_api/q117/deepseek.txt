针对水果供应商推荐的新品，采购方可以先试卖**一个中等规模、可量化且低成本**的初始量，通常建议**50～100斤或1～2箱（根据单箱重量调整）**。

具体建议如下：

1. **起始量标准（参考）**  
   - 如果是**高单价、易损耗**的水果（如进口樱桃、蓝莓、山竹等），建议初期**20～30斤或1箱**先做陈列和试吃。  
   - 如果是**中低价位、较耐放**的水果（如蜜瓜、柑橘类、苹果、梨等），可以试卖**100斤或2箱**。  
   - 如果是**完全陌生的新品种**（如首次上市的异域水果），建议量更保守——**10～15斤或半箱**，避免库存积压。

2. **关键判断依据**  
   - **人流与客单价**：位于商场、人流量大的门店，试卖量可以取区间上限；社区小店建议用下限走稳。  
   - **尝鲜周期**：通常新品接受度在**3～7天**内可初步判断。试卖量应保证在这段时间内**不断货但不过剩**（即保持日销量的1.5倍库存）。
   - **损耗控制**：优先选糖度、成熟度、外观**统一稳定**的批次，并安排每天限时试吃或打折促销，快速撬动第一批回头客。

3. **简易操作流程**  
   - **第一天**：仅进货50斤（视情况），设立试吃台，用“新品尝鲜价”标签吸引关注。  
   - **记录数据**：每日统计**销量、试吃转化率、退货量**。若3天内日销量稳定增长且损耗低于5%，可再追加1～2箱进入正式小批量；若出现滞销或投诉，立即暂停或换品。

4. **与供应商沟通要点**  
   - 明确告知供应商这是**“试销采购”**，并争取以下权益：  
     - 允许**部分退货或调换**（例如卖掉80%后未卖出部分支持折价换货）。  
     - 要求供应商提供**小规格包装**（如5斤/箱的迷你装），减少你的一次性资金占用。

**总结一句话**：水果新品试卖的**稳妥起点**是**该品类预估日均销量的1.5倍**（例如该店苹果日销30斤，试卖量定为45斤），再根据实际动销速度调整。
