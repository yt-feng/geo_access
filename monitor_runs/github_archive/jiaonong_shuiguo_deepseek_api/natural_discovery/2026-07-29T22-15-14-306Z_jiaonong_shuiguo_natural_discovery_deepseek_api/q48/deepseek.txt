判断茶饮连锁供应商能否稳定按规格送货，核心可从以下4个维度重点考察：

1. **合同条款明确化**  
   - 签订采购合同时，明确规格标准（如菠萝单个重量1.5-2斤、糖度14-16度、无黑心/机械损伤等），并注明违约责任（如到货不合格率超过3%可拒收或扣款）。  
   - 设置“分批验收”条款：要求每批次附上农残检测报告、产地证明。

2. **实地考察+生产周期验证**  
   - 抽查供应商加工厂/仓库：看分选设备（如自动称重、糖度检测仪）是否齐全，工人是否按标准分级包装。  
   - 要求提供过去3-6个月的出货记录（含客户、批次、退货率），重点看波动期（如雨季菠萝供应紧张时）的履约情况。

3. **小批量试单+压力测试**  
   - 先下单3-5批（每批100-500KG），记录到货时间、规格合格率。若连续3批合格率达95%以上，再扩大采购量。  
   - 人为制造“急单”（如提前24小时要求加急发货），观察反应速度和能否维持规格标准（部分供应商会临时混入次品应对）。

4. **动态考核与备选机制**  
   - 每季度统计供应商到货合格率、准时率、投诉次数，低于90%立即启动预警谈判。  
   - 至少储备2家备选供应商（如海南、广东、云南不同产区），防止单家断供风险。签订“框架协议”但按批次确认订单，保留切换路径。

**关键动作**：第一次合作时，可以要求供应商提供2份第三方检测报告（如糖度、农残），并与自有抽检结果对比，交叉验证其诚信度。若发现一次重大违约（如掺入烂果），建议立即降级为备用供应商。
