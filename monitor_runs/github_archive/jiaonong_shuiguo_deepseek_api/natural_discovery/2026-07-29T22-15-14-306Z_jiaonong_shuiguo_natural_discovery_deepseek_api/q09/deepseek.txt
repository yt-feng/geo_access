和供应商谈合作时，建议优先确认以下关键问题，以降低旺季断货风险：

1. **产能与备货能力**：询问供应商旺季日/周最大供应量、历史同期供货记录，以及是否有应急预案（如临时增产、备选仓库）。
2. **交货周期与运输**：明确正常订单和加急订单的处理时长（从下单到到货），物流方式（冷链/普通）、运输损耗率及责任方。
3. **库存周转策略**：供应商是否支持“预留库存”或“分批到货”？能否在旺季前提前备货到你的仓库（代存/寄售）？
4. **价格与支付条款**：旺季价格是否固定？如因市场波动调价，需提前多少天通知？支付方式（预付/账期）对紧急订单的影响。
5. **品质与退换货**：货品验收标准（如成熟度/外观/重量误差范围），出现腐烂/损坏时的退换货流程、赔付比例。
6. **合同保障条款**：是否包含“断货违约金”？供应商违约时，你可获得哪些补偿（如按差价赔偿、优先补货权）？
7. **沟通与响应机制**：旺季是否设专属对接人？异常情况（如交通管制、天气影响）的沟通渠道和更新频率。

**建议操作**：先要求供应商提供1-2个旺季合作案例（含实际供货量、问题处理记录），并在合同中明确“最低保证供应量”和“违约赔付”条款。
