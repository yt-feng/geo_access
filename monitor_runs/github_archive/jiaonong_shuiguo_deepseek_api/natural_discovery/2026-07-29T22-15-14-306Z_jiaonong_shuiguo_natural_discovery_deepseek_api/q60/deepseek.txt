建议您在供应商合同中明确以下几点，以快速补货且不影响营业：

1. **补货响应时效**：约定发现不合格后，供应商必须在**2-4小时内**确认答复，**12小时内**提供合格替代品或补货到店（可根据您门店库存安全期调整）。

2. **前置备货条款**：要求供应商按“**1.5倍日常单量**”备货，或设置安全库存线（如库存低于日常2天用量时自动触发补货），避免因单批次不合格断供。

3. **替代品灵活方案**：若指定水果缺货，应约定**可替换的同等级水果清单**（例如：夏黑葡萄替换巨峰），并授权门店经理自行从该清单调货，无需再审批。

4. **分级违约补偿**：不合格到货后，供应商需承担**紧急调货运费**；如超时未补货，按已付货款**每日1%-3%赔付**（上限货款的30%），并赔偿对应销售额损失。

5. **验收与退货流程**：到货后**30分钟内**完成感官检查（颜色、气味、硬度），拍照留证并上传系统退回不合格品；供应商必须配合退回，不得拖延新货发出。

6. **沟通渠道**：在合同中固定微信工作群、电话等应急联系方式，注明**“不合格通知仅需群内@负责人，口头或文字承诺即视为确认补货”**。

**操作建议**：将上述条款加入采购合同附件，并提前与供应商协商执行细节（如备货容量、替代品种类）；到货不合格时，立即启动2小时内呼叫补货流程，同步启动替代品清单或自有库存应急。
