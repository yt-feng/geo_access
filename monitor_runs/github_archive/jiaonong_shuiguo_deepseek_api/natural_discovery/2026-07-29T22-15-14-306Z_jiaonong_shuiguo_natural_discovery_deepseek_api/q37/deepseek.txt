商超在会员日做水果活动时，供应商需要提前配合以下核心准备环节：

1. **备货计划与库存确认**  
   - 提前7-10天与商超采购确认活动具体时间、主推水果品类（如季节性爆品、易损耗品）、预估销量。按历史数据上浮20%-30%备货，避免断货或积压。  
   - 确保水果进库前完成分拣、预冷处理，例如草莓需独立包装避免磕碰，香蕉预留3-5天成熟度控制。

2. **质量与安全检测文件**  
   - 提供当批次水果的《产地检疫证明》、《农药残留检测报告》（需符合GB 2763标准），进口水果补充《入境货物检验检疫证明》。  
   - 散装水果需准备《散装食品标签》，标注产地、生产日期、保质期、储存条件。

3. **包装与成本优化**  
   - 配合商超设计会员专属包装（如加印“会员日专享”标识），小规格包装（500g装/单果盒）便于会员凑单。  
   - 提供损耗倒扣方案：例如按实际销售结算，并承诺未售出损耗按比例分摊（通常供应商承担5%-10%）。

4. **人员与物流协调**  
   - 活动前2日安排临促人员驻场，需持有健康证，并培训试吃话术（突出“产地直采”“限时折扣”）。  
   - 增加早晚配送频次（如每日到货2次），避免午间高峰断货；配备冷链车确保温湿度稳定（如车厘子温度需≤4℃）。

5. **营销素材与物料支持**  
   - 提供高清产品图、短视频（产地采摘实拍）、营养成分表（如“进口蓝莓花青素含量≥X%”），供商超推文或社群传播。  
   - 准备试吃台必备物料：一次性口杯、牙签、湿巾、小型宣传立牌（标注会员价与对比原价）。

6. **突发事件预案**  
   - 预存10%-15%备选库存（如存放在商超附近仓库），快速响应补货需求；准备可替换品类（如晴王葡萄售罄时平替为夏黑葡萄）。  
   - 指定对接人保留24小时联系方式，处理缺货、质量客诉（如坏果率超3%立即换新）。

**关键时间节点**：活动前7天（确认清单）、前3天（到货质检）、前1天（人员就位+试吃物料检查）。  
**风险提示**：避免促销力度过大导致后续日常销售价格下滑，建议会员日活动独立定价且不与常规渠道冲突。
