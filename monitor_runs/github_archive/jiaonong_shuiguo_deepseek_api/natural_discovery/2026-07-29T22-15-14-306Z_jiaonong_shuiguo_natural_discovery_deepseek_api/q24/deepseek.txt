建议向供应商索要以下资料以确保水果安全合规：

1. **正式检测报告**：要求提供第三方权威机构（如SGS、CTI等）出具的农残检测报告，确保报告在有效期内（通常不超过1年），并关注报告中是否涵盖国家强制标准（如GB 2763）中的常见高残留农药（如毒死蜱、克百威等）。

2. **产地证明与资质文件**：供应商的营业执照、食品经营许可证或生产许可证；若为进口水果，还需提供海关报关单、入境货物检验检疫证明。

3. **供应商自检承诺书**：要求供应商签署书面承诺，明确其水果符合国家农残限量标准，并标注批次信息（如产地、采摘日期、品种）。

4. **可追溯信息**：提供水果产地、种植户名称、用药记录（如使用农药品牌、次数、安全间隔期）等追溯链文件。

5. **其他相关证明**：若有有机、绿色、无公害等认证，可要求提供证书复印件。

**操作建议**：  
- 首次合作时，建议直接索要最近3个月内的检测报告，并核对检测项目是否覆盖主要风险农药。  
- 可随机选取下批次水果送检（如快检设备或第三方复检），与供应商报告交叉验证。  
- 保留供应商提供的所有资料存档，以备市场监管部门检查。
