对于社区超市增加香蕉和苹果，建议优先选择**稳定供应商**，理由如下：

1. **品质和供应稳定性**：香蕉和苹果属于日常高频消费品，稳定供应商能提供标准化的品质和全年稳定的货源，避免本地批发因季节、天气导致的断货或品质波动。
2. **售后与成本控制**：稳定供应商通常有明确的退换货政策，减少损耗风险；长期合作还可争取更优价格或账期。本地批发虽可能单次价格略低，但需自行承担运输、挑选和损耗成本，且价格波动大。
3. **社区超市特点**：社区超市以固定客群为主，保持商品质量和供货稳定比短期差价更重要，缺货或品质差会直接影响口碑。

**执行建议**：
- 先联系2-3家当地或区域的水果供应商，要求提供样品和报价，重点考察其冷链配送能力、退货条款及过往合作案例。
- 可同时与本地批发市场保持联系，作为应急补货或促销时的备选渠道。

若超市位置距批发市场极近（如步行5分钟），且人工成本低，可**少量尝试本地批发**作为补充，但主力货源仍需依赖稳定供应商。
