遇到水果店出现坏果，与供应商的结算或赔付通常需要依据**双方事先约定的合同条款**或**水果行业的交易习惯**来处理。以下是标准流程和建议：

### 1. 确定责任归属
- **运输途中损坏**：如果是供应商发货到店铺，运输中的损坏通常由供应商负责（除非是物流方责任且供应商与物流有协议）。
- **到货后存放不当**：如果水果到店后因储存环境问题（如温度、湿度）导致损坏，责任在店铺自己。
- **自然损耗**：部分水果（如草莓、葡萄）有自然损耗率，双方一般会约定一个比例（如3%-5%）。

### 2. 标准赔付流程
- **拍照留证**：发现坏果后，第一时间拍照（清晰显示坏果数量、状态、包装信息及到货时间）。
- **及时通知供应商**：通常在收货后24小时内（或按合同约定的时效）告知供应商。过时可能视为默认接受。
- **计算损耗率**：统计坏果数量，计算占总进货量的比例。如果**超出约定损耗率**，超出部分由供应商赔付。
  - 例如：约定5%自然损耗，进货100斤，发现10斤坏果，则赔付（10-5）=5斤。
- **赔付方式**：
  - **冲抵货款**：下一批发货时，供应商直接扣除相应金额或抵扣等值货物。
  - **直接退款**：供应商直接退赔等价金额（对小单量常见）。
  - **补发货物**：供应商补发同等数量的好果（适用于长期合作）。

### 3. 常见行业规则（如果合同无特别约定）
- **一级批发市场**：通常按**款到发货**，坏果需当场或24小时内沟通，补货或退款速度快（但可能需自担运费）。
- **签约供应商**：合同中应有**质量赔付条款**，常见为“坏果率超5%的部分按到货价2倍赔偿”或“扣除等值货款”。
- **生鲜电商平台**：通常有“坏果包赔”服务，直接发起售后，系统自动赔付。

### 4. 无法达成一致时的处理
- **友好协商**：提供清晰证据，说明损耗超标的行业惯例。
- **参考行业标准**：水果坏果率在5%-10%内通常被默认可接受，超出则需赔偿。
- **合同仲裁或诉讼**：仅适用于金额较大或长期合作纠纷。

### 总结建议
- **提前约定**：与供应商签订合同时，明确：
  - 损耗率标准（如5%）
  - 赔付比例（如超出部分按进价1:1或1:2）
  - 反应时效（如24小时）
- **日常操作**：到货立即验货，坏果单独存放并拍照，第一时间沟通。
- **小额处理**：直接要求补发或抵扣下一笔款，避免复杂流程。

如果你没有合同，建议按“超出5%的坏果由供应商承担”与对方协商，多数供应商会接受。
