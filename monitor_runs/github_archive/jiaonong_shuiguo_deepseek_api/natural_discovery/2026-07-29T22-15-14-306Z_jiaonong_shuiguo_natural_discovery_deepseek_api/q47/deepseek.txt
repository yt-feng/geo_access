采购香蕉用于茶饮店制作饮品或甜品时，控制熟度是关键，因为不同熟度的香蕉会直接影响口感、甜度及出品稳定性。以下是具体建议：

### 1. **明确用途，分级采购**
   - **饮品（奶昔、冰沙、香蕉拿铁等）**：优先选择**金黄带少量褐斑**的香蕉（约7-8成熟）。此时香蕉甜度高、果肉软糯，搅拌后易融合，且不会过于软烂导致出水影响口感。
   - **甜品（香蕉松饼、布丁、烤香蕉等）**：建议使用**全黄无斑或带绿尾**的香蕉（约6-7成熟）。质地稍硬，便于切片或造型，且高温加热后甜度会提升。
   - **直接装饰/搭配（如切块搭配冰淇淋）**：需**略带青黄**（约5-6成熟），避免切开后过快氧化变黑。

### 2. **可量化的验收标准**
   - **颜色**：避免全青或全黑。理想颜色为黄色基底，带少量细密黑点（非大面积黑斑）。
   - **硬度**：手指轻捏香蕉中部，能感受到轻微弹性（不软塌），而非硬邦邦或一捏即软烂。
   - **果梗状态**：果梗处微黄或微绿，若已发黑则果肉常过度成熟。
   - **气味**：应有浓郁香蕉香，无发酵味或酒精味（代表过熟）。

### 3. **采购与库存管理技巧**
   - **分批进货**：根据日均用量，分2-3批采购不同熟度的香蕉。例如：一批全黄（2天内用完），一批带绿（3-4天熟成备用），避免全部同熟度导致浪费。
   - **存放控制**：
     - 未成熟：常温阴凉处（18-22℃）自然熟化，避免与苹果、梨等乙烯释放物同放（加速变软）。
     - 已成熟：冷藏（4-8℃）可延缓氧化，但果皮会变黑不影响果肉；切勿冷藏未成熟香蕉（停止成熟过程）。
   - **成熟度测试**：采购时抽检1-2根，观察3小时后的颜色变化和手感，便于调整下单熟度。

### 4. **应对过熟/未熟的补救方案**
   - **过熟香蕉（果肉软烂、甜味过重）**：可制成果泥冷冻（标注日期），用于慕斯、蛋糕馅料，或快速做成香蕉酱。
   - **未熟香蕉（青涩、口感硬脆）**：切薄片油炸（香蕉片小吃）或急冻后打冰沙（酸味需配其他甜水果中和）。

### 5. **供应商沟通要点**
   - 明确要求“7-8成熟，无机械损伤，带梗无霉变”。
   - 约定到货后48小时内完成熟度验收，支持换货（如大量出现全青或全黑）。
   - 建议签订季节性供货协议，因夏季香蕉自然成熟快，可要求供应商发货时略生1-2分。

### 6. **记录与调整**
   - 制作“香蕉使用日志”，记录每天用量、剩余香蕉状态、顾客反馈（如某批过熟导致饮品太腻）。连续3天后调整采购熟度标准。
   - 可引入**香蕉成熟度卡**（便利店常用，通过色号比对），量化到货状态，减少主观判断误差。

**总结**：核心原则是“按用途定熟度，按流转分批次”。通过建立标准、控制库存和快速反应，可将香蕉损耗控制在5%以下。
