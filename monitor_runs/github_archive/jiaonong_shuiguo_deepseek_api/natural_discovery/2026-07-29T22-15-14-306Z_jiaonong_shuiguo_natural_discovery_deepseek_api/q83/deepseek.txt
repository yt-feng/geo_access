对于生鲜电商水果到货后出现坏果的问题，责任划分通常遵循以下原则，结合具体环节判断：

1. **发货前的品质问题（电商/供应商责任）**  
   - 如果坏果在发货前已存在（如水果不新鲜、有霉斑、未达到约定成熟度），责任由电商平台或供应商承担。
   - 电商需提供发货前质检证明（如照片、视频），否则默认承担过错。

2. **物流运输中的损坏（物流方责任）**  
   - 若包装符合防震防压标准（如泡沫网、隔板、冰袋等），但物流暴力分拣、运输时间过长或温度不当导致坏果，责任归物流公司。  
   - 若包装明显不足（如裸装、无缓冲），电商需承担连带责任。

3. **收件后保存不当（顾客责任）**  
   - 需明确到货时间：通常生鲜类要求“24小时内验货”。若顾客延迟取件、未及时开箱、存储不当（如放常温而非冷藏），责任归顾客。  
   - 电商应提醒验货及保存要求（如“到货后请立即开箱检查”）。

4. **模糊地带及处理建议**  
   - **时间界限**：多数电商规定“签收后24-48小时内可申请售后”，超过时效可能会推诿。建议顾客立即拍照留证，联系客服。  
   - **部分坏果**：按比例退赔（如坏3个退赔30%），而非全单退款，除非坏果超过50%或全损。  
   - **复杂情况**：若坏果原因不明（如既像冻伤又像碰撞），可要求电商提供物流温度记录、发货视频等，协商共摊损失。

**实用建议**：  
- 顾客：收货后立即开箱检查并拍摄视频（含面单、内物、坏果特写），保留快递底单；优先通过平台客服申请“坏果包赔”或“烂果全赔”。  
- 电商：规范包装（标注易碎/需冷藏）、发货前质检留存凭据、明确售后条款（如“24小时内反馈”）。  
- 若责任难以划分，可申请平台介入或消费者协会调解（凭物流单据、聊天记录）。  

**常见默认规则**：生鲜电商通常承诺“坏果包赔”，但需顾客及时举证；物流损坏一般由电商先行赔付再追偿。最终责任以合同条款或平台规则为准，建议优先协商解决。
