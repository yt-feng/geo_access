旺季锁库存，核心是用**确定性和分层激励**换供应商的优先权，不要只靠口头“到时候多给我留点”。可以按下面几步做：

1. **先做需求预测，别报虚数**
   - 按过去同期销量、当前预售/团购群接龙、天气和节假日，给每个单品做“保守/基准/乐观”三档预测。
   - 和供应商只锁定“保守量”的硬库存，基准量签意向，乐观量靠补货机制。
   - 报虚数会导致供应商备货后你吃不下，下一季就失去信用。

2. **提前锁量，合同写清“三件事”**
   - **锁量锁价**：约定某时间段内最低供货量、单价、规格、等级。
   - **锁优先级**：约定缺货时你排第几顺位、提前几天通知、违约怎么赔。
   - **锁替代方案**：主品缺货时，同价位替代品的供应责任和价差谁承担。
   - 旺季锁货通常需要**预付定金或保证金**，建议定金对应锁量，尾款按到货结算，别一次性全款。

3. **用分层激励换优先权**
   - 对核心供应商：预付定金 + 承诺最低采购量 + 缩短账期，换旺季优先排产/优先发货。
   - 对多个供应商：同一单品至少锁2家，主供锁60%-70%，备供锁30%-40%，避免单一供应商断供。
   - 对愿意锁量的供应商，可以给“淡季也稳定采购”的承诺，这比旺季临时加价更有吸引力。

4. **把“锁库存”变成“锁到仓”**
   - 约定发货时间、物流责任、到仓时限和损耗标准。
   - 水果非标，合同里写清糖度、大小、坏果率、验收标准和拒收处理。
   - 旺季要求供应商**分批到货**，比如每周两次，降低你仓配压力和损耗。

5. **提前留应急池**
   - 预留10%-20%预算做现货采购，旺季现货价高但能救急。
   - 和本地批发市场/二级供应商保持联系，作为临时补位。
   - 对爆款单品做预售或限购，用前端节奏控制后端压力。

6. **现在就能做的动作**
   - 今天列出旺季TOP10水果单品，做三档销量预测。
   - 明天和主供、备供分别谈：锁量比例、定金、到仓时间、缺货赔付。
   - 合同里加一条：供应商在锁量期内不得把约定量转售给更高价客户，否则按差价倍数的违约金处理。
   - 到货前3天二次确认，到货前1天确认物流，别等缺货才催。

一句话：**用保守量+定金锁硬库存，用备供和应急池兜底，用合同把“优先权”和“违约成本”写死。**
