先给结论：**优先级是 保质期管控 ＞ 包装 ＞ 配送频次**，但三者不是独立取舍，而是按“鲜切菠萝”这个品类的风险结构来排。

**1. 保质期（最高优先）**
鲜切菠萝是高风险鲜切水果：切开后微生物易繁殖、汁液多、易氧化出水，便利店又是冷藏陈列+顾客自取，温控波动大。核心要盯：
- 加工后到废弃的时间窗（按门店冷藏条件定，通常很短，且必须写死到“几小时”而非只写日期）
- 到货/加工时间标签、临期下架规则
- 冷藏温度记录和陈列柜温度
- 每天固定时段检查并执行报废，不能靠店员目测

这是食品安全和客诉的第一风险点，必须做成SOP和可检查记录。

**2. 包装（第二优先）**
包装直接影响保质期能否守住：
- 是否密封防汁液渗漏、防交叉污染
- 是否适合冷藏陈列、是否易开启且能复封
- 标签是否清晰印加工时间/保质期/储存条件
- 透气与结露问题（结露会加速变质）
包装选错，保质期规则再严也会被实际条件击穿。

**3. 配送频次（第三优先，但是保质期的支撑条件）**
频次本身不是目的，目的是**缩短门店库存周转和暴露时间**。如果配送频次高但门店囤货、陈列时间长，等于没用。判断标准是：
- 单店日均销量能否支撑“少量多次”
- 到货后多久能上架、上架后多久能卖完
- 频次提高带来的成本是否被报损下降抵消

**可执行判断：**
- 先定死保质期规则和温控/报废SOP，这是底线；
- 再选能匹配该保质期的包装形式；
- 最后用销量数据倒推配送频次，做到“以销定配、少进快周转”。
如果资源只够先做一件事：**先把保质期标签、临期下架和冷藏温控做成可检查的硬规则**，其他两项围绕它配。
