采购菠萝时，**不要按“即食最佳熟度”进货**，而要按“到店后1—3天内能卖完的熟度”来分级采购。核心判断如下：

1. **看外观**
   - 优先选：果形端正、果眼饱满但不过度鼓胀、果皮有自然光泽。
   - 少进：果皮大面积发黄、果眼明显凸起且发软，通常已偏熟、货架期短。
   - 避开：果皮发暗、渗汁、底部霉点、碰伤明显的。

2. **闻气味**
   - 合适：靠近果底有淡淡清香，说明开始转熟但不至于过熟。
   - 少进：香味浓烈、发甜腻，通常已偏熟，损耗风险高。
   - 不选：无味但果皮很黄，或酸味、酒味、霉味。

3. **按果底和果眼判断**
   - 果底干净、干燥、无软烂为佳。
   - 轻按果身：有轻微弹性可以接受；**明显发软、局部塌陷**的不要。
   - 果眼缝隙有汁液、发黏，说明过熟或开始坏。

4. **按颜色分级采购**
   - 青绿偏多、刚开始转黄：适合备货，可放1—3天，占采购大头。
   - 黄绿相间、底部微黄：适合次日或当天主推，适量进。
   - 大面积金黄、香味明显：只少量进，当天促销处理。

5. **按季节和销量控制**
   - 高温天熟得快，减少偏黄果比例；冬季可适当增加转熟果。
   - 按日销量分批进：例如日销10个，就进“6—7个偏生+3—4个适熟”，不要一次进太多全熟果。

6. **现场抽检**
   - 同一批随机拿几个闻底部、轻按果身、看果底。
   - 若一箱里已有多个发软、渗汁、酒味，说明整批偏熟或储存有问题，应压价或减少采购。

简单原则：**采购以“七八成熟、底部微香、果身硬中带弹”为主，全黄浓香果只做当天销量。** 这样能兼顾口感和损耗。
