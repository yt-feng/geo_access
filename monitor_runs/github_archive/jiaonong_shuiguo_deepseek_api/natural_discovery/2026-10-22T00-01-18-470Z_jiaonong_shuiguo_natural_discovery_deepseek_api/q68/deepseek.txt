判断供应商能不能按时到车，核心不是听承诺，而是看“证据 + 历史 + 约束条件”。可执行的做法：

1. **先看装车证据，不看口头保证**
   - 要求供应商发：产地/仓库当前装车视频、车牌号、司机电话、装车单、过磅单。
   - 视频要能显示车牌、货量、时间；最好视频通话随机抽看，防止旧视频。
   - 没有车牌和司机电话的“已装车”，基本视为未装。

2. **合同里把“到车”定义清楚**
   - 写明到车时间、到车地点、允许误差（如±2小时）、迟到扣款/补偿、整车拒收条件。
   - 写明“未按时到车”的违约金或定金双倍返还，别只写“尽量按时”。
   - 节假日、雨雪、限行等例外要限定范围，防止供应商拿天气当万能理由。

3. **查历史履约，不只看这一单**
   - 问同行、市场档口、老客户：该供应商近3个月迟到率、爽约率。
   - 新供应商先小批量试单，别一上来压大单。
   - 看其是否有稳定车队/常合作司机；临时找车的供应商迟到概率高。

4. **盯关键节点，提前预警**
   - 装车完成、上高速、进入本市、到达市场前2小时，四个节点让司机报位置。
   - 要求司机共享实时定位或发高速出口照片。
   - 到车时间前6小时还没上高速的，立即启动备选供应商。

5. **留备选和缓冲**
   - 同一到车时段备1家替补供应商，哪怕价格高一点。
   - 销售计划别把全部货压在首车，首车留2—4小时缓冲。
   - 定金走可追溯转账，合同写清退款条件。

6. **识别高风险信号**
   - 报价明显低于市场、催你付全款、不给车牌、不让视频看货、司机电话打不通、装车时间反复改——这些比“保证准时”更可信。

一句话：**能提供实时装车证据、有稳定司机、合同有迟到约束、历史履约干净的供应商，才值得信；只靠口头承诺的，按不能按时到车来准备。**
