# 学校食堂水果供应商选择建议

## 一、先明确采购特点

学校食堂和普通餐饮不同，核心约束是：**食品安全可追溯 + 价格稳定 + 供货连续 + 验收可执行**。香蕉、苹果、橙子都属于耐储运品类，但特性不同，选供应商时要分开看。

- **苹果**：耐储，可集中采购、分批消化，重点是分级和果径一致性。
- **橙子**：季节性强，重点是糖酸比、出汁率和产地稳定性。
- **香蕉**：后熟管理最关键，重点不是“买的时候多黄”，而是供应商能否按需控熟、分批到货。

## 二、供应商类型与适配

| 类型 | 优点 | 风险 | 适合场景 |
|---|---|---|---|
| 产地合作社/种植基地直供 | 价格低、溯源清楚 | 单品季节性强，配送能力弱 | 苹果、橙子等主单品，可签季节合同 |
| 本地一级批发商 | 品类全、配送灵活 | 货源杂，溯源链条长 | 香蕉等需频繁补货的品类 |
| 专业水果配送商（含冷链） | 分拣、控熟、配送稳定 | 加价率高 | 香蕉后熟管理、多品类小批量 |
| 商超/平台集采 | 票据规范、验收简单 | 价格偏高，规格受限 | 应急补货或小规模学校 |

**建议组合**：苹果、橙子走“基地/一级批发商 + 年度框架协议”，香蕉走“有控熟能力的专业配送商”，避免单一供应商包全部品类。

## 三、必须核验的资质与条件

1. **证照**：营业执照、食品经营许可证（或食用农产品销售相关备案）、供货商法人信息。
2. **溯源**：每批次能提供产地证明或进货凭证；承诺批批可查。
3. **检测**：农药残留检测报告（第三方或自检），至少按批次或按周期提供。
4. **配送能力**：车辆是否专用、是否冷链（香蕉尤其）、能否按学校作息时段到货。
5. **保险与责任**：是否有食品安全责任险，出现质量问题如何退换、赔偿。

## 四、验收标准要写进合同

不要只写“新鲜、无腐烂”，要可量化：

- **苹果**：果径分级（如70/75/80mm）、着色率、无碰压伤、硬度抽检。
- **橙子**：可溶性固形物（糖度）下限、出汁率、无青果和霉变。
- **香蕉**：到货成熟度（如青转黄程度）、单把重量、无机械伤；约定“按使用进度分批催熟/到货”。
- **通用**：腐烂率上限（如≤3%）、缺斤短两处理、退货响应时限（如24小时内补货）。

## 五、比价与定价机制

- 不要只比单次报价。要求供应商按**周/月报价 + 市场价联动**，约定参考当地批发市场均价或产地价，设涨跌幅上限。
- 苹果、橙子可签**季节锁价 + 分批提货**；香蕉价格波动大，适合**周期定价 + 保量协议**。
- 结算上保留**质量保证金**（如月货款的5%–10%），验收合格后返还。

## 六、试用与淘汰机制

1. 先给1–2周小批量试用，重点看：到货准时率、损耗率、香蕉成熟度控制、异常响应速度。
2. 建立**月度评分**：质量40%、价格25%、配送20%、服务15%，连续两个月不达标即约谈或替换。
3. 至少保留**两家备选供应商**，防止断供。

## 七、容易踩的坑

- **只看报价低**：低价往往靠降规格、混级、缩短账期找补，验收要卡死规格。
- **香蕉按“到货即用”采购**：应要求供应商按学校使用节奏控熟，否则集中变黄造成损耗。
- **没有批次台账**：每批留样、留票据，出事才能追溯。
- **口头约定退换**：腐烂率、补货时限必须写进合同。

## 结论

优先选**证照齐全、能批批溯源、有检测报告、配送稳定**的供应商；苹果和橙子倾向基地/一级批发商锁价直供，香蕉倾向有控熟能力的专业配送商。合同里把**规格、腐烂率、成熟度、补货时限、价格联动**写清楚，再用小批量试用和月度评分做动态管理，比单纯比价更可靠。
