酒店采购水果盘原料时，供应商应保证的规格和外观标准，建议写进采购合同或验收单，至少包括以下几类。

**一、通用规格标准**

1. **品种与等级**
   - 明确具体品种、产地范围、等级（如一级果、特级果），不接受以次充好或混级。
   - 同一批次品种、成熟度、大小应基本一致。

2. **单果重量/尺寸**
   - 按品种约定单果重量范围或直径范围，例如苹果、橙子按直径分级，西瓜、哈密瓜按单果重量分级。
   - 约定允许偏差，如±5%～10%，超偏差部分可拒收或降级计价。

3. **成熟度**
   - 到货成熟度应适合酒店当天或短期内使用：即食类达到可食用成熟度，需存放的略生。
   - 不得过熟、软烂、发酵、有酒味。

4. **新鲜度与保质期**
   - 明确采摘/采收后到送货的时间上限。
   - 叶菜类、浆果类要求更高，如当日或次日配送。
   - 到货剩余货架期应满足酒店使用周期。

5. **安全与合规**
   - 农药残留符合国家食品安全标准，供应商提供检测合格证明或承诺书。
   - 不得使用非法保鲜剂、染色剂、催熟剂超标。
   - 预切水果原料还需符合即食食品卫生要求。

6. **包装与标识**
   - 包装完好、无破损、无污染，标签注明品名、产地、等级、重量、采收/包装日期、供应商信息。
   - 冷藏/冷链品种到货温度符合约定，并记录温度。

7. **供货与退换**
   - 约定缺货替代规则、到货不合格的退换货时限和费用承担。
   - 批量不合格可整批拒收。

**二、外观标准**

1. **果形**
   - 具有品种典型形状，无明显畸形、偏果、裂果。

2. **色泽**
   - 色泽正常、均匀，符合品种成熟特征，无大面积青斑、褪色、日灼斑。

3. **表面**
   - 果面清洁，无泥土、药斑、虫粪、霉斑、污渍。
   - 无腐烂、霉变、发酵、异味。

4. **损伤**
   - 无明显机械伤、压伤、磕碰伤、划伤、冻伤、烫伤。
   - 允许轻微表皮瑕疵但不得影响切配和出品，具体可约定“外观缺陷面积不超过单果表面积×%”。

5. **病虫害**
   - 无活虫、虫卵、虫蛀孔、病斑。
   - 不得带有检疫性有害生物。

6. **大小一致性**
   - 同批次用于水果盘的水果大小、颜色、成熟度应相对一致，保证摆盘美观。

7. **果梗与切口**
   - 带梗品种果梗新鲜、不干枯；预切水果切口平整、无褐变、无汁液外溢。

**三、建议验收方式**

- 每批抽检比例、抽检数量写清楚，如按箱抽检、按件称重。
- 到货现场检查：数量、重量、温度、包装、外观、成熟度、异味。
- 对农残检测报告、产地证明、冷链温度记录留存。
- 不合格判定标准量化，例如：腐烂果比例超过×%、单果重量超偏差超过×%、外观缺陷超×%即判不合格。

**四、合同里建议明确一句话**

“供应商保证所供水果符合国家食品安全标准及本合同约定的品种、等级、规格、成熟度和外观要求；到货验收不合格的，酒店有权拒收、要求换货或退货，相关费用由供应商承担。”

这样既便于验收，也能在出现质量争议时有明确依据。
