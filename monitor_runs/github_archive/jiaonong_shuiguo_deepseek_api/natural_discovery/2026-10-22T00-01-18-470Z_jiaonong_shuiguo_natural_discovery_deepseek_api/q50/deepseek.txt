**出汁率更重要，但甜度是底线，不能二选一瞎选。**

具体判断：

1. **出汁率优先**
   - 茶饮店菠萝主要用于榨汁、捣果肉、做果茶。
   - 出汁率低意味着同样出品要用更多原料，成本直接上升，废料也多。
   - 出汁率稳定，出品杯量、口感浓度才稳定。

2. **甜度是底线指标**
   - 甜度不够可以用糖浆补，但酸涩感重、风味寡淡的菠萝很难救。
   - 甜度太低通常伴随成熟度不足，果香弱、涩感重，会拉低整杯茶饮的风味。
   - 所以甜度不需要“极高”，但要达到**可接受的最低甜度**，且酸涩不能过重。

3. **实际采购建议**
   - 先定用途：  
     - 榨汁为主：出汁率权重更高，甜度达标即可。  
     - 捣果肉/吃得到果肉：兼顾果肉质地和甜度，出汁率可略降。
   - 设两个门槛：  
     - 甜度设**最低准入线**，低于线不采购；  
     - 在达标原料中，按**出汁率、单价、损耗率**综合算“每杯原料成本”再选。
   - 不要只看单果甜度或单价，要算：**每杯实际可用果汁/果肉成本 + 人工处理成本 + 废料成本**。

**结论：**  
甜度决定这杯能不能好喝，出汁率决定这杯能不能赚钱。采购时**甜度设底线，出汁率做主要筛选指标**；如果只能强调一个，选出汁率，但甜度不达标的一律不要。
