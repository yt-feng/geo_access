水果店遇到坏果，先按“**先固定证据、再分类定责、最后按合同/惯例结算**”走，避免口头扯皮。可执行做法如下：

1. **收货当场验货**
   - 开箱拍照/录像：坏果比例、批次、箱号、到货时间、温度/包装状态。
   - 当场在送货单上注明“发现坏果X箱/X斤，待协商”，不要先签“数量无误、质量合格”。
   - 能挑出的坏果单独堆放，不要混入好果销售。

2. **区分责任类型**
   - **运输/到货前已坏**：供应商承担，按坏果数量退款、补货或折价。
   - **隐蔽性坏果**（外表正常、切开/几天后坏）：一般要求在约定异议期内提出，通常24—48小时内，越快越好；有合同按合同。
   - **自己储存不当**：水果店承担，不能转嫁给供应商。
   - **自然损耗/正常失水**：按行业惯例或合同约定的损耗率处理，通常不全部算供应商责任。

3. **结算方式优先顺序**
   - **有合同/供货协议**：按约定赔付比例、退换货规则、账期扣款执行。
   - **无明确合同**：先协商，常见处理是：
     - 坏果部分**按进货价退款**；
     - 或**补发同等数量好果**；
     - 或**下一批货款中直接扣减**；
     - 坏果比例较高时，可要求整批折价或退货。
   - 不建议按零售价索赔，除非合同明确约定；一般以进货价/实际损失为基础。

4. **形成书面确认**
   - 微信/短信/对账单写清：批次、到货日期、坏果数量/比例、处理方式、扣款金额。
   - 让对方回复“确认”，避免月底对账时对方不认。
   - 扣款前保留照片、送货单、聊天记录。

5. **月底对账**
   - 对账单列明：正常货款、坏果扣款、补货未到、上次遗留问题。
   - 扣款有依据再扣；没有确认的争议款项先挂账，不要单方面全扣导致断供或纠纷。

6. **长期预防**
   - 合同写明：验收标准、异议期限、坏果赔付比例、补货时限、扣款方式。
   - 高频坏果的供应商降低采购比例或更换。
   - 对易坏品类约定“到货抽检比例”和“开箱验货后签收”。

一句话：**当场留证、按批次定责、按进货价退补或扣款、书面确认后再结算**。如果对方长期不认，保留证据并逐步减少合作。
