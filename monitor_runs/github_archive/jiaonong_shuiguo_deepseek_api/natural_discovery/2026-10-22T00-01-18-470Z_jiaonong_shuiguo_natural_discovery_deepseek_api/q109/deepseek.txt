优先谈**售后**，其次**账期**，最后**配送**。

理由很直接：长期合作里，配送通常是最容易标准化的，账期是资金条款但可替代性相对高，售后才是长期合作真正的风险兜底。水果是非标、易损耗品类，售后规则不清楚，前面谈得再好都会在损耗、品质波动、缺斤少两上反复扯皮。

**建议的谈判顺序和重点：**

1. **售后优先谈清楚**
   - 坏果/烂果的判定标准：按比例赔、按箱赔还是补发？
   - 报损时限：到货后几小时内反馈有效？
   - 损耗率容忍线：比如3%以内自担、以上供应商承担。
   - 补发时效和运费谁承担。
   - 连续多批次不合格的退出或降价机制。

2. **账期第二谈**
   - 先确认结算周期（周结/半月结/月结）和起算点。
   - 账期本质是价格的一部分，供应商给长账期往往会在单价里找回来，所以要连同单价一起看综合成本。
   - 长期合作可争取“阶梯账期”：合作满一定周期或月采购额达标后延长账期。

3. **配送最后谈**
   - 重点不是“送不送”，而是频次、到货时间窗、临时加单响应、缺货替代方案。
   - 配送出问题通常可以用备选供应商或自提兜底，谈判优先级最低。

**一句话判断：** 售后决定你亏不亏，账期决定你现金流紧不紧，配送决定你顺不顺。长期合作先保不亏，再谈钱，最后谈体验。
