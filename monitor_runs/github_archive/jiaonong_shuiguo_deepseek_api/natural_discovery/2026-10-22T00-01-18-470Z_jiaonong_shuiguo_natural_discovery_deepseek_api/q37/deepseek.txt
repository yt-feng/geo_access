商超会员日水果活动，供应商要提前配合的重点不是“多送货”，而是把**货、价、陈列、损耗、履约**五件事在活动前锁死。建议按下面清单推进：

## 1. 活动前7—10天：确认活动方案
- **确认单品和价格**：会员日主推哪些水果、引流款/利润款/形象款分别是什么，供应商承担多少促销折让。
- **锁量**：按门店预估销量给出分日、分门店供货量，避免活动当天断货或压货。
- **锁品质标准**：明确规格、糖度、果径、成熟度、包装方式、允许瑕疵率。
- **锁到货时间**：活动前一天或当天凌晨到仓/到店，避开早高峰。
- **确认退换货与损耗分担**：临期、破损、品质不达标怎么处理，谁承担。

## 2. 活动前5—7天：备货与品质预控
- **产地/仓端备货**：按锁量多备10%—15%安全库存，但不要盲目压货。
- **成熟度控制**：会员日集中销售，香蕉、芒果、牛油果等后熟水果要按销售节奏控制成熟度，避免集中过熟。
- **预冷与冷链**：浆果、荔枝、葡萄、车厘子等提前预冷，冷链车温控记录可查。
- **包装适配**：会员日走量快，尽量用易陈列、易称重、易携带的包装，减少门店二次分装。
- **质检前置**：供应商发货前自检，附质检/农残合格证明，避免到店拒收。

## 3. 活动前3—5天：物流与门店对接
- **分店分货单**：按门店销量分配，不要平均分货。
- **到货预约**：和商超仓配/门店确认收货窗口、卸货口、验收人手。
- **应急补货方案**：明确活动当天补货联系人、补货时限、临时加单响应时间。
- **陈列物料配合**：价签、POP、试吃物料、堆头围挡、保鲜冰袋等谁提供、何时到店。
- **人员支持**：重点门店可安排供应商促销员或理货员，协助补货、挑拣、试吃。

## 4. 活动前1—2天：最终确认
- **再次确认库存和到货车辆**，尤其是引流单品。
- **确认价格生效时间**，避免收银系统与价签不一致。
- **确认临期/瑕疵处理口径**，避免活动当天扯皮。
- **确认天气预案**：高温、暴雨会影响到货和客流，提前准备替代单品或补货路线。

## 5. 活动当天：驻场与快速响应
- **重点单品不断货**：安排专人盯库存，低于安全线立即补货。
- **现场挑拣**：及时挑出坏果，避免影响整堆陈列。
- **试吃支持**：引流款安排试吃，供应商提供物料和人员。
- **数据反馈**：当天销售、缺货、损耗、客诉及时同步，便于次日调整。

## 6. 活动后：复盘与结算
- **损耗核对**：按约定处理退货、折价、报损。
- **销售复盘**：哪些单品卖爆、哪些备多了，形成下次会员日备货参考。
- **履约评分**：到货准时率、品质合格率、补货响应速度，纳入供应商考核。

**一句话总结**：供应商提前要配合的是“锁单品、锁价格、锁数量、锁品质、锁到货、锁损耗责任”，活动当天还要有人盯补货和挑拣，活动后一起复盘。这样商超会员日水果活动才不容易出现断货、品质翻车和损耗扯皮。
