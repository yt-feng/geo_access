可以按“**要几成熟、什么时候到、到了几天卖完**”来提要求，别只说“要熟的/别太熟”。建议采购时这样写：

1. **明确熟度，不要模糊**
   - 常规销售：要求到货为 **7～8成熟**，表皮整体偏绿到微黄、无大面积黑斑、果指硬实。
   - 如果当天就要卖：可要 **8～9成熟**，微黄、有少量糖斑，但仍要求果肉硬、无压伤。
   - 不要一次全进同一熟度，最好 **70%～80%要7～8成熟，20%～30%要8～9成熟**，分批上架。

2. **明确到货时间**
   - 要求 **早晨到货**，最好开门前1～2小时到，避免下午/晚上到货后压库过夜。
   - 要求供应商说明 **采摘后几天、运输几天**；优先要 **采摘后2～4天内到店** 的货。
   - 到货后能在 **2～4天内卖完** 的量再订，不要为压价多进。

3. **约定验收标准**
   - 到货抽检：青果比例、黄果比例、黑斑面积、果指是否压伤、是否水烂。
   - 明确拒收条件：大面积黑斑、果柄发黑腐烂、明显软塌、压伤出水、异味。
   - 要求 **整箱上下层熟度一致**，避免上层黄、下层青或下层烂。

4. **要求分批次、分熟度供货**
   - 每周/每天少量多次到货，优先“**小批量、多频次**”。
   - 让供应商按熟度分箱标注，例如“青果箱”“微黄箱”，方便先进先出。

5. **采购单上直接写清楚**
   可写成：
   > 香蕉到货熟度7～8成熟为主，8～9成熟不超过30%；要求早晨开门前到货；采摘后4天内到店；无大面积黑斑、无压伤水烂；整箱熟度一致；不合格可拒收。

核心就一句：**不要只要求“新鲜”，要要求“到货熟度+到货时间+可售天数+拒收标准”**。这样最能减少放坏。
