先把问题拆成三类：**授权范围、区域保护、串货认定与处罚**。和品牌方谈时不要只问“有没有区域保护”，要问成可写进合同、可执行的条款。

**一、授权与区域范围**
1. 授权区域具体到哪些市/区县？是独家、排他，还是非独家？独家是否有最低进货量/年度任务？
2. 授权渠道是什么：商超、农贸、餐饮、电商、社区团购、直播是否都包含？线上销售算不算跨区？
3. 授权期限多久，续约条件是什么？未完成任务是否降级或取消独家？
4. 品牌方在授权区域内直营、自营电商或给其他大客户供货，是否受限？

**二、区域保护**
1. 同一区域是否还授权其他批发商？已有几家？品牌方能否书面列出。
2. 保护是“只保护线下”，还是线上线下都保护？品牌方官方旗舰店/直播带货发到本区算不算冲击？
3. 跨区客户主动来找我进货，我能不能卖？需要报备吗？
4. 区域内出现低价乱价，品牌方是否有控价机制？谁执行、多久处理？

**三、串货认定与处罚**
1. 串货怎么定义？以收货地址、物流单、产品编码还是举报为准？
2. 产品是否有批次码/追溯码？能否用于查串货？查询权限给不给我？
3. 发现串货后流程是什么：举证、核查、处罚、申诉，各多少天？
4. 处罚标准是什么：罚款金额、扣保证金、停货、取消授权？是否区分首次和恶意？
5. 我被别人串货冲击时，品牌方对我有什么保护义务？不处理怎么办？
6. 保证金多少、什么情况下扣、退还条件？

**四、必须落到合同里的点**
- 授权区域、渠道、独家性、期限；
- 品牌方直营/电商供货边界；
- 串货定义、举证责任、处理时限、处罚上限；
- 品牌方对区域内乱价的管控义务；
- 退出机制：未续约后库存如何处理、保证金退还时间。

**谈判时最关键的三个问题：**
“我这个区域现在还有没有别的授权商？请写进合同。”
“线上和官方直播卖到我区域，算不算串货？怎么处理？”
“别人串货到我区域，你们多久处理、不处理我能不能解约？”

建议让对方把回答写进合同附件或授权书，口头承诺不要作为依据。
