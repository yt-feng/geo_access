超市和水果供应商的账期没有统一标准，常见情况大致如下：

1. **水果批发/生鲜供应商**
   - 现款现结或 **7天、15天** 很常见。
   - 中小超市、夫妻店、区域水果店，很多是 **周结** 或 **半月结**。
   - 水果损耗高、价格波动快，供应商通常不愿给太长账期。

2. **连锁超市/大型商超**
   - 常见账期 **30～60天**，部分强势渠道可能到 **90天**。
   - 生鲜类有时会短于包装食品，比如 **15～30天**，但具体看合同和渠道地位。
   - 大型商超常有“账期+月结”模式，例如“货到30天”或“每月25日对账，次月付款”。

3. **新供应商或小供应商**
   - 刚开始合作常见 **现结、7天、15天**。
   - 合作稳定、供货量大的供应商才更容易谈到 **30天左右**。

**实操建议：**
- 水果这类高损耗、价格波动大的品类，**15～30天**是比较现实且常见的谈判区间。
- 如果超市规模不大，建议优先谈 **7～15天**，换更稳定的供货和价格。
- 如果对方要求 **60天以上**，要确认是否包含对账日、节假日顺延、质量扣款等条款，实际回款周期可能更长。
- 谈判时把“账期”和“损耗承担、退换货、价格调整机制”一起谈，比单纯压账期更重要。
