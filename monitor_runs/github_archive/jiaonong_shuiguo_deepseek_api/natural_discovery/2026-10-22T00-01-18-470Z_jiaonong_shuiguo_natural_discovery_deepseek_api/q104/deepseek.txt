单位采购水果出现品质不一致，验收和售后要抓住“标准前置＋抽检留证＋分级处理＋书面索赔”四条线。

**一、验收前先定标准**
- 合同或订单里写清品种、规格（大小/单果重）、成熟度、糖度或口感要求、允许次果率（如≤3%—5%）、包装和到货时限。
- 明确“合格判定方法”：按箱抽检还是按批抽检、抽检比例、谁共同验货、异议提出时限。
- 约定不合格处理方式：拒收、换货、折价、补发、退货退款及违约金。

**二、到货验收怎么做**
1. **现场共同验收**：采购、使用部门（食堂/工会等）和供应商同时在场，拍照/录像记录外包装、批次、开箱过程。
2. **分层抽检**：不能只看上层，按到货箱数随机抽取，一般不少于总箱数的5%—10%，大单可分批抽；每箱上中下都看。
3. **逐项记录**：品种是否对版、单果大小、色泽、成熟度、腐烂/压伤/虫害/裂果数量、净重是否足称、包装是否破损受潮。
4. **现场分级**：合格、可折价接收、拒收三档。轻微不一致可折价；腐烂变质、以次充好、规格严重不符的整批拒收或换货。
5. **填写验收单**：写明到货数量、抽检数量、不合格数量及比例、处理意见，双方签字；供应商不到场可单方记录并拍照，及时书面通知。

**三、售后处理**
- **时限内提异议**：到货当天或合同约定期限内发书面异议（微信/邮件/函件均可，保留记录），附照片、视频、验收单。
- **按约定主张**：换货的明确补发时间；折价的按不合格比例扣款；退货的约定运费和退款时限；影响使用的可依合同主张违约金。
- **留样备查**：不合格样品冷藏留存至争议解决，防止扯皮。
- **建立供应商评价**：同一供应商多次品质不一致，降低评分、减少订单或列入黑名单。

**四、制度上防复发**
- 采购时要求供应商提供分级标准或样品封样，到货对照封样验收。
- 大额采购可约定分批到货、分批验收、分批结算，降低一次性风险。
- 验收单、照片、沟通记录、付款凭证统一归档，便于对账和追责。

一句话原则：**标准写进合同，验收当场抽检留证，不合格当场分级处置，售后在时限内书面主张。**
