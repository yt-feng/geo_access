建议直接向供应商要“可核验、可追溯、能对应批次”的资料，而不是只要一张泛泛的检测报告。清单如下：

1. **批次对应的农残检测报告**
   - 要求报告上的品名、产地、供应商/生产主体、采样日期、检测日期与本次到货批次能对应。
   - 优先要**第三方检测机构出具**的报告；确认检测项目覆盖常见高风险农药，并看报告是否在有效期内。
   - 不要接受“只给一份年度报告、无法对应批次”的做法。

2. **产地/供货证明与追溯信息**
   - 产地证明、供货商营业执照、种植基地或合作社信息。
   - 要求提供**批次号/采收日期/包装日期/运输单据**，确保出了问题能追溯到具体批次。

3. **承诺达标合格证或产地准出材料**
   - 国内食用农产品常见“承诺达标合格证”；可要求随批次提供。
   - 若是基地直供，可要基地自检记录、投入品使用记录（农药采购/使用记录）。

4. **供应商自检或快检记录**
   - 供应商入库快检记录、抽检记录；确认检测时间、检测项目、结果和操作人。
   - 快检只能作为筛查，不能替代第三方检测。

5. **进货查验与质量协议**
   - 合同中明确农残超标责任、退换货和赔偿条款。
   - 要求供应商随货提供送货单，注明批次、数量、产地，便于超市留存进货查验记录。

6. **高风险品种加码**
   - 对叶菜、草莓、豇豆、韭菜、芹菜等高风险品类，可要求**每批第三方报告或批批快检+定期第三方检测**。
   - 对新供应商、新产地首批货，建议提高检测频次。

**判断标准**：报告必须“对得上批次、看得清项目、查得到主体”；只有复印件没有批次对应、只有合格证没有检测记录、报告日期与到货批次明显脱节的，都不算充分。超市自身也应保留进货凭证和抽检记录，形成可追溯闭环。
