小商家采购水果，现金结算和月结账期的核心风险不同：现金结算主要怕“钱付了、货不对/人跑了”，月结主要怕“账越滚越大、质量争议拖成坏账”。分开看：

**现金结算的风险**
1. **资金安全风险**：现场付现或转账后，若对方缺斤少两、以次充好、临时换货，追回困难；尤其是流动批发商、临时档口。
2. **无凭证风险**：现金交易常缺合同、磅单、发票，出现质量或数量争议时举证难。
3. **采购员舞弊风险**：现金经手人容易虚报单价、数量或吃回扣，小商家往往没有双人验收。
4. **现金流占用**：现结虽然不欠账，但会占用周转资金，旺季集中采购时压力大。
5. **假币/转账错误风险**：现金有假币风险，转账有账号填错、付错对象风险。

**月结账期的风险**
1. **坏账风险**：水果保质期短、损耗大，一旦销售不畅，月结款可能拖欠甚至形成坏账。
2. **质量争议后置**：当月多次送货，月底统一结算时才发现某批货有问题，责任和扣款容易扯皮。
3. **账期被拉长**：口头约定月结，实际变成“月结变两月结”，供应商可能停供或涨价。
4. **价格被动**：账期通常伴随更高报价或隐性利息，小商家议价能力弱。
5. **对账风险**：送货单、磅单、退货单不齐，月底对不上账，多付或漏付。
6. **供应商依赖风险**：长期月结容易形成单一供应商依赖，对方断供时临时找货成本高。

**可执行建议**
- **现金结算**：坚持“验收后付款”，当场过磅、拍照留证；索要收据或送货单；采购和付款分离，避免一人经手。
- **月结账期**：签简单书面协议，明确账期、对账日、质量异议期、退货扣款规则；每批货签收单留存；设置账期上限，比如不超过30天、不超过月采购额的某个比例；定期对账并书面确认余额。
- **混合策略**：新供应商先现金或短账期试合作，稳定后再给月结；大额采购可部分预付、部分月结，降低单边风险。

总体原则：现金结算防“货权与凭证”，月结防“账期与对账”。小商家最好做到每批货有单据、每笔账有确认、采购与付款分离。
