超市采购水果时，通常要把“供应商资质、进货凭证、检验检测材料”分开准备。可执行的做法如下：

**1. 供应商主体资质**
- 营业执照
- 食品经营许可证（或食品生产许可证，视供应商类型）
- 供货商与超市的采购合同/供货协议
- 若为进口水果，还需海关进口货物报关单、入境货物检验检疫证明

**2. 进货证明/溯源凭证**
- 每批次的送货单、销售单或采购订单，需有品名、数量、日期、供货商盖章或签字
- 发票或收据
- 产地证明、种植基地/合作社供货证明（如供应商为产地直供）
- 承诺达标合格证：食用农产品生产者/收购者按规定开具的合格证，是常见进货凭证之一

**3. 检测报告**
- 供应商或产地提供的**农产品质量安全检测报告**，常见为农药残留检测
- 超市自检或委托第三方检测的报告（很多连锁超市会对高风险水果批批或定期抽检）
- 检测报告应关注：检测机构资质（CMA/CNAS）、样品名称、批次/日期、检测项目、结论
- 报告不必每个水果品种每天都全新，但应与进货批次、供应商、品种能对应；超市验收时通常要求“批次可追溯”

**4. 实际验收建议**
- 首次合作：收集资质证照+至少一份有效检测报告
- 每批进货：送货单/发票+承诺达标合格证或产地证明；高风险品种（如草莓、葡萄、柑橘类）可要求批次农残检测报告
- 建立供应商档案和进货台账，保存期限按当地市场监管要求执行，一般建议不少于6个月至2年，具体以属地规定为准

**判断标准：** 能证明“谁供的、哪一批、检了什么、是否合格、从哪里来”。如果供应商只能提供营业执照，不能提供批次凭证或检测材料，超市验收时应谨慎，必要时自行抽检或拒收。不同地区市场监管部门对食用农产品进货查验的具体材料要求可能略有差异，建议以当地监管要求为准。
