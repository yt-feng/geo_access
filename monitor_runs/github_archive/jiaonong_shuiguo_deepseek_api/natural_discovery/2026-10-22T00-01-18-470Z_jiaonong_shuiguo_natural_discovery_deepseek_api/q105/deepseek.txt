水果锁价能锁多久，取决于品类、季节、供应商类型和锁价方式。一般可分几档：

1. **现货单批锁价：1～7天**
   适合叶菜类水果、浆果类、当季大量上市且价格波动快的品种，如草莓、荔枝、樱桃。供应商通常只愿意锁很短时间，甚至只锁当天装车价。

2. **短期框架锁价：15～30天**
   适合苹果、梨、橙、柚子、香蕉等耐储运、供应相对稳定的品种。常见做法是约定“锁价不锁量”或“锁量锁价+浮动区间”，超过期限重新议价。

3. **季度/产季锁价：1～3个月**
   适合产地集中、可以提前备货的品类。比如柑橘类产季、苹果入库后、进口香蕉等。通常需要采购方给量承诺、预付定金或分批提货，供应商才愿意锁这么久。

4. **半年以上：少见，通常不是真正固定价**
   水果价格受天气、产地减产、物流、汇率影响大，供应商很少愿意长期无条件锁死价格。半年以上多采用“保底价+浮动机制”“价格上限”“随行就市但优先供货”等变通方式。

**实操建议：**
- 耐储水果优先谈 **30天左右**，用“锁量换锁价”，比如承诺月度提货量。
- 易腐、时令水果不要追求长锁价，改为 **分批锁价+保底采购量**。
- 合同里写清：锁价期限、锁价数量、质量标准、超出数量的计价方式、天气/产地重大减产时的调价条款。
- 对供应商来说，最长能接受的锁价通常不超过 **一个产季或一个备货周期**；超过这个周期，即使签了固定价，也容易因质量下降或履约纠纷变成“纸面锁价”。

所以，比较现实的目标是：**常规水果锁15～30天，耐储大宗品种争取1～3个月，半年以上用浮动机制而不是硬锁价。**
