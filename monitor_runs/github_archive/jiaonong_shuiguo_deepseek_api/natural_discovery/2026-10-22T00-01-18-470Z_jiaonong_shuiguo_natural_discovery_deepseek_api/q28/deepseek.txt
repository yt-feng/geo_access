建议先从**香蕉**试水，但要把“稳定进口水果”理解为分阶段组合，而不是一次只押一个单品。

**为什么优先香蕉**
- 需求稳定、周转快，顾客对香蕉的接受度最高，试错成本低。
- 进口香蕉供应链成熟，全年可供应，适合先跑通冷链、报关、损耗和补货节奏。
- 单价相对低，超市容易做陈列和促销，能快速验证进口水果区是否有人买。

**香蕉的主要风险**
- 损耗对温湿度敏感，催熟和库存管理要求高；如果门店销量不够快，损耗会吃掉毛利。
- 进口香蕉和国产香蕉价差有限，顾客不一定为“进口”支付明显溢价，容易变成价格战。

**菠萝和苹果的位置**
- **菠萝**：适合做第二梯队。进口菠萝有差异化卖点，但季节性和损耗更明显，顾客处理成本也高，不建议第一家店先上。
- **苹果**：适合做稳定补充，但进口苹果与国产苹果竞争激烈，消费者对产地和品种敏感，需要较强选品和定价能力；周转慢于香蕉，不适合作为“先验证动销”的首选。

**可执行的上架顺序**
1. 先上1—2个进口香蕉SKU，小批量、高频补货，观察2—4周的动销率、损耗率和毛利。
2. 香蕉跑通后，再加入1个进口菠萝SKU做差异化测试，控制订货量，避免整箱压货。
3. 苹果放在第三阶段，优先选有明确品种/产地卖点的进口苹果，小陈列试销，不与其他国产苹果混价竞争。

**判断标准**
- 香蕉周动销率能稳定在较高水平、损耗可控，再扩品。
- 如果香蕉都出现明显滞销或损耗过高，说明门店的进口水果客流和冷链能力还不成熟，应先解决基础运营，而不是换品。
