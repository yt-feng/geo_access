连锁超市要降门店坏果率，合同里建议把“验收标准、责任归属、赔付计算、扣款执行、举证与时效”写清楚，避免只写“按质论价”或“坏果包赔”这种没法执行的条款。

**1. 先定义“坏果”和验收口径**
- 按品类分别定义：腐烂、霉变、软烂出水、开裂、虫蛀、冻伤、压伤、异味、成熟度不符等，最好附图片标准或封样。
- 明确验收时点：到店卸货时、开箱抽检时、上架前；以及抽检比例（如每批次抽3箱/5%）。
- 区分“表面瑕疵”和“可销售性缺陷”，避免把所有磕碰都算坏果。

**2. 约定坏果率阈值和赔付方式**
建议用“批次坏果率”分段处理，而不是一刀切：
- 坏果率≤约定免赔率（如2%）：不赔付或按实际挑出重量补货；
- 超过免赔率至某比例：按超出部分货值赔付，或整批折价；
- 超过较高比例（如10%）：买方有权拒收整批、要求换货或退货，运费和损耗由供方承担。
赔付基数建议写“该批次进货金额”或“坏果对应货值”，并明确是否含税、含运费。

**3. 赔付形式要可选且可执行**
合同里写清优先级：补货＞换货＞折价＞现金赔付/账扣。门店最需要的是“可账扣”，所以约定：
- 供方确认后，超市可在当期货款中直接扣除赔付款；
- 供方逾期不确认的，视为认可抽检结果；
- 扣款需附验收单、照片、称重记录，供方有异议应在约定时限内提出。

**4. 责任归属和例外**
- 到店验收前发生的腐烂、压伤、冻伤由供方负责；
- 验收后因门店储存温度、堆压、超期陈列造成的坏果由超市承担；
- 运输环节若由供方或指定承运人负责，运输损伤计入供方责任；若超市自提，则按交接点划分。
- 明确不可抗力、季节性自然损耗是否除外，但“自然损耗”不能成为坏果免责的万能条款。

**5. 举证、时效和月度汇总**
- 每批留存验收单：批次、数量、抽检数、坏果数、坏果率、照片、处理方式、双方签字。
- 约定异议期，如供方在收到验收结果后24/48小时内未提出书面异议，视为确认。
- 月度汇总坏果率和赔付金额，连续超标可触发整改、降级、暂停供货或解约。

**6. 建议写入的条款示例**
“供方交付商品坏果率超过2%的，超出部分按该批次对应货值赔付；超过5%的，买方有权整批拒收或要求换货；超过10%的，买方有权退货并解除该批次订单，运输及销毁费用由供方承担。赔付款买方可从应付货款中直接扣除，供方应在收到验收记录后48小时内确认，逾期视为认可。”

核心是把“坏果率”变成可抽检、可计算、可扣款的数字，并区分到店前和到店后的责任，否则合同写了也容易扯皮。
