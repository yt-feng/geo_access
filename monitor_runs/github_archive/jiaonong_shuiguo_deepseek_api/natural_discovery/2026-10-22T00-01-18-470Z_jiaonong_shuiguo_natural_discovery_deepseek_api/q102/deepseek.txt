需要。企业福利采购水果礼盒，供应商通常应同时支持开发票和定制包装，但要把要求写进采购条件里，避免口头承诺。

判断标准：

1. **开发票：必须支持**
   - 企业采购入账、报销、税务合规都需要发票。
   - 优先要求能开**增值税专用发票**（一般纳税人可抵扣）；至少能开**增值税普通发票**。
   - 确认发票品名、税率、开票时效，以及是否支持先票后款或随货开票。

2. **定制包装：建议支持，是否强制看福利场景**
   - 如果用于员工福利、节日慰问、客户答谢，定制包装能体现企业标识和仪式感，通常建议要求。
   - 定制内容一般包括：企业LOGO、祝福语、贺卡、外箱/礼盒腰封、手提袋等。
   - 需确认起订量、打样费、打样周期、包装材质和食品安全接触要求。

3. **采购时建议明确写入合同或订单**
   - 发票类型、税率、开票时间；
   - 定制包装的起订量、设计确认流程、打样和交付周期；
   - 包装出错或发票不合规时的退换、补开责任；
   - 水果礼盒的品控、破损赔付和配送时效。

结论：**开发票是硬性条件；定制包装建议作为供应商筛选条件，尤其企业福利场景应要求支持。** 若采购量小，可接受标准包装加贴企业标签作为折中方案。
