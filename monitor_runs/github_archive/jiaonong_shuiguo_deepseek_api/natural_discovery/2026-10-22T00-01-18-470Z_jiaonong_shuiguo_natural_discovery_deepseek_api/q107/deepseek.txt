**香蕉**
- 起订量高，最大风险是集中到货后短期内催熟、转黄、起斑，销售窗口很短。
- 若仓储温度、通风和催熟管理跟不上，高起订量会直接放大压伤、过熟和报废损耗。
- 香蕉对“到货成熟度”很敏感；起订量高时若不能分批到货，损耗风险明显增加。

**菠萝**
- 菠萝相对耐储一些，但高起订量会带来集中成熟、黑心/腐烂筛查压力和库容占用。
- 整箱堆压、通风不良时，底层果更容易闷坏。
- 若销售速度跟不上，削皮鲜切或加工渠道又没有提前锁定，损耗也会上升。

**判断建议**
1. 看“日销量 × 到货后可售天数”能否覆盖起订量；覆盖不了就会增加损耗。
2. 优先谈分批到货、分成熟度到货，而不是一次性大货。
3. 香蕉重点控到货成熟度和催熟节奏；菠萝重点控库容、通风和翻箱筛查。
4. 若起订量无法降低，先锁定鲜切、果汁、团购或促销等消化渠道，再下单。

所以：**会，起订量太高通常会增加损耗风险；香蕉比菠萝更敏感，但两者都需要用分批到货和销售消化能力来对冲。**
