选哪种，主要看你门店的**出杯量、人工、菜单定位和稳定性要求**。直接给结论：

**大多数茶饮店：鲜果 + 冷冻果丁/果泥组合最稳；单店小量、主打鲜切可买鲜果；连锁或高峰期人手紧，优先果丁/果泥。**

具体判断：

1. **鲜果菠萝**
   - 适合：主打“鲜切/现切”、客单价较高、有专人处理水果、日销量可预估的店。
   - 优点：卖点强、香气自然、顾客感知好。
   - 缺点：去皮去眼费人工，成熟度不稳定，损耗高，甜酸波动大，旺季品质差异明显。
   - 建议：只用于招牌鲜果茶或装饰性果肉；采购时选成熟度适中、可当天或次日用完的量。

2. **冷冻果丁**
   - 适合：需要果肉感、出杯量中等、想减少切果人工的店。
   - 优点：开袋即用或简单解冻，果肉感保留较好，规格稳定，损耗低。
   - 缺点：解冻后口感略软，香气不如鲜果，需控制解冻量和时间。
   - 建议：作为菠萝果茶的主力原料之一，搭配少量鲜果提升卖点。

3. **果泥/冷冻果浆**
   - 适合：出杯量大、标准化要求高、做冰沙/果昔/调味型果茶、连锁门店。
   - 优点：甜酸稳定、出杯快、易定量、损耗低，适合SOP。
   - 缺点：果肉感弱，鲜果卖点不足；部分产品含糖或添加剂，要看配料表。
   - 建议：选配料干净的冷冻果泥或果浆，注意可溶性固形物和酸甜度，先小样测试再定。

**采购建议：**
- 单店日销低于30杯：少量鲜果，现切现用，避免囤货。
- 日销30–100杯：冷冻果丁为主，鲜果少量做招牌和装饰。
- 日销100杯以上或连锁：果丁/果泥做基底，鲜果只做顶部果肉或限定款。
- 无论选哪种，先做**盲测对比**：同一配方下比较香气、酸甜、果肉感、出杯速度和成本，再定采购比例。

一句话：**要卖点和鲜感选鲜果，要效率和稳定选果丁/果泥，实际经营建议组合使用。**
