建议优先上架**单根 + 小把（3~5根）**，整袋作为补充，而不是只做一种包装。判断依据主要是便利店场景：即时消费、客流快、货架小、损耗敏感。

具体建议：

1. **单根：必须上**
   - 适合即时吃、搭配早餐、临时购买。
   - 降低顾客决策门槛，单价低、试错成本低。
   - 能消化外观稍差但完好的香蕉，减少整把滞销损耗。
   - 建议定价略高于按斤折算，覆盖人工和损耗。

2. **小把（3~5根）：作为主力**
   - 适合家庭少量购买、办公室分享。
   - 比整袋灵活，比单根客单价高。
   - 建议控制在3~5根，不要绑太大把，避免一次买不完放坏。
   - 用透明袋或扎带固定，标清价格，减少称重排队。

3. **整袋：谨慎上，作为补充**
   - 只适合社区型、家庭客群明显的门店，或做特价引流。
   - 整袋容易因成熟度不一致、吃不完而损耗。
   - 若上架，建议小规格（6~8根）、明确特价、放在动线末端或收银台附近快速消化。

4. **成熟度要分开**
   - 单根放**偏黄可即食**的，满足即时消费。
   - 小把可放**微黄带一点绿**的，给顾客1~2天缓冲。
   - 整袋适合**稍绿**的，避免买回家就坏。

5. **先小规模测试**
   - 第一周同时上单根和小把，整袋只少量试销。
   - 记录每天销量、报废量、客单价。
   - 若单根销量高但损耗低，扩大单根；若小把复购好，增加小把排面；整袋若周损耗超过销量，直接下架。

**结论：便利店香蕉以“单根引流 + 小把走量”为主，整袋只做少量补充和特价，不要一开始就主推整袋。**
