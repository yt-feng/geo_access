优先关注 **切果损耗**，其次 **甜度**，再看 **外观**，最后才是 **大小**。理由和可执行判断如下：

1. **切果损耗优先**
   - 超市卖菠萝通常有鲜切/果切需求，损耗直接决定毛利。
   - 重点看：去皮去眼后出肉率、黑心/水心比例、空心比例、尾部霉变率。
   - 建议到货抽检：随机切3—5个，记录“可售果肉重量/整果重量”。出肉率稳定且黑心少，比单纯大果更有价值。

2. **甜度第二**
   - 甜度影响复购和差评，但不是唯一指标；酸度高、甜度低的果可以做果切拼盘或促销，损耗高的果却很难救。
   - 可执行标准：到货测糖，设定最低可接受糖度；低于标准的不要按鲜食主推，转促销或加工。

3. **外观第三**
   - 外观影响陈列和顾客第一眼购买，但超市菠萝常带皮销售或现场削皮，外观缺陷可通过削皮、切块消化。
   - 关注：果形端正、无严重机械伤、无霉斑、冠芽新鲜。外观差但内质好的，适合做果切。

4. **大小最后**
   - 大小影响单价和陈列，但不是核心盈利指标。大果未必出肉率高，小果也可能损耗低。
   - 建议按客群定规格：家庭客群中等偏大，单人/果切场景中小果也可。

**一句话结论：**  
超市卖菠萝，先卡“切果损耗和出肉率”，再卡“甜度底线”，外观用于分级陈列，大小按客群搭配。损耗控制不住，甜度再高、果再大也可能不赚钱。
