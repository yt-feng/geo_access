判断水果供应商靠不靠谱，别只看谁报价低，重点看“稳定性、损耗责任、账期和应急能力”。给你一套水果店能直接用的判断方法：

1. **先小批量试供2—4周**
   - 香蕉、菠萝都是损耗敏感品，别一上来签长期大单。
   - 每周固定进2—3次小批量，观察：到货成熟度是否一致、破损率、缺斤少两、迟到频率。
   - 香蕉重点看：青度是否统一、有没有催熟过度、运输中是否压伤；菠萝重点看：大小是否均匀、有没有黑心/水烂、叶冠是否新鲜。

2. **看他的货源和分级能力**
   - 靠谱供应商能说清楚产地、季节、规格等级，比如香蕉按把/梳/箱、菠萝按果径分级。
   - 问一句：“如果我这周要偏青的香蕉、下周要偏黄的，你能不能稳定分出来？”能稳定分级的，通常更可靠。
   - 只回“都有、都差不多、来了再说”的，风险较高。

3. **明确损耗和售后规则**
   - 进货前谈清楚：到货破损、黑心菠萝、香蕉压伤/催熟不均，怎么赔、多久内反馈有效。
   - 最好第一次就试一次售后，看对方是否痛快补货或扣款。
   - 不肯承担合理损耗、所有风险都推给门店的，长期合作会很难受。

4. **看供货稳定性和应急能力**
   - 问：节假日、雨天、产地涨价时能不能保量？临时加单多久能到？
   - 观察他是否经常“今天有、明天没”，或者总用不同规格混发。
   - 香蕉、菠萝都需要持续走量，断货比贵一点更伤生意。

5. **价格要对比“到手成本”**
   - 不要只比箱价，要算：净重、损耗率、运费、卸货费、售后扣款。
   - 比如A报价低但每箱损耗高、经常少称，实际到手成本可能更高。
   - 让供应商连续报同一规格2—3周价格，看波动是否透明、是否临时加价。

6. **看账期和合同习惯**
   - 长期合作建议有简单书面约定：品名、规格、单价、送货时间、验收标准、损耗处理、结账周期。
   - 先款后货可以接受，但最好保留“质量问题可扣款/补货”的条款。
   - 账期突然放宽或催你大量囤货的，要警惕。

7. **侧面打听**
   - 问周边同行、批发市场熟人：这个供应商是否经常换名字、是否拖欠上游、售后是否拖拉。
   - 看他自己的仓库/档口是否干净、分拣是否规范、工人是否熟练，这些比口头承诺可靠。

**实操建议：**  
同时找2家供应商，一家主供、一家备供。香蕉和菠萝各试供3—4周，记录每次的到货时间、净重、损耗率、售后响应。连续几次稳定、售后痛快、价格透明的，再逐步放量签长期。不要因为一家便宜就断掉备供，水果生意最怕断货和品质不稳。
