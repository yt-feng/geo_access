判断香蕉供应商能否全年稳定供货，不能只听“我们全年都有货”，要把**产能、产区、催熟与冷链、合同约束、历史履约**拆开验证。给你一套可执行的判断方法：

### 1. 先看其货源结构是否“多产区+多基地”
香蕉是区域性、季节性作物，单一产区很难全年稳定。重点问清：
- 货源来自哪些产区/国家/省份，各产区占比多少；
- 每个产区的上市窗口期，是否覆盖你全年的采购节奏；
- 是否有自有基地、长期合作基地或仅靠市场临采；
- 遇到台风、寒害、病害时，替代产区在哪里。

**判断标准：** 能给出12个月货源排期表，且至少2—3个产区能互相接续，而不是“到时候再找货”。

### 2. 看其加工与冷链能力
全年供货不只是“有香蕉”，还要能稳定出**合格商品蕉**：
- 是否有固定催熟库，催熟能力是否匹配你的日/周销量；
- 冷链车、冷库、周转仓是否自有或长期锁定；
- 旺季和节假日能否保证配送频次；
- 香蕉成熟度、青蕉/黄蕉比例能否按门店需求调整。

**判断标准：** 催熟与冷链能力要能覆盖你的峰值销量，而不是只覆盖日均销量。

### 3. 用历史履约数据验证，不听口头承诺
要求供应商提供近12个月：
- 月度实际供货量、缺货次数、缺货原因；
- 到货合格率、损耗率、退换货记录；
- 旺季/节假日供货记录；
- 主要客户名单及合作年限，最好能侧面核实。

**判断标准：** 近12个月无连续断供、缺货有预案、合格率稳定。新供应商可先小批量试单2—3个月，跨一个旺季验证。

### 4. 合同里写死“稳定供货”的责任
不要只签价格和账期，要加：
- 月度/季度最低供货量及峰值保供量；
- 缺货通知时限和替代方案；
- 断供违约金或补偿条款；
- 价格调整机制，避免涨价时优先供别人；
- 质量标准、损耗承担和退换货规则。

**判断标准：** 供应商敢承诺保供量并接受违约条款，比口头说“没问题”可靠得多。

### 5. 做压力测试
可要求供应商：
- 提供一次突发增量订单的响应方案；
- 说明主要产区受灾时的替代货源和切换时间；
- 带你实地看基地、催熟库、冷库；
- 给出上游种植户/合作社的合作证明。

### 6. 不要只依赖一家
即使供应商看起来稳定，也建议：
- 主供应商占70%—80%，备选供应商占20%—30%；
- 备选供应商也保持小单持续合作，确保随时能切换；
- 建立安全库存，覆盖3—7天销量，节假日适当提高。

**一句话判断：** 能拿出“多产区货源排期+催熟冷链能力+近12个月履约记录+合同保供条款”的供应商，才基本具备全年稳定供货能力；只靠口头承诺和市场临采的，不建议作为主供应商。
