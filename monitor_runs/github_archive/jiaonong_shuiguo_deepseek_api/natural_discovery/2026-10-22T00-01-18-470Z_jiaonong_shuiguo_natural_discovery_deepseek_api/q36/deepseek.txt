先说结论：**多数商超应“整果为主、切果为辅”，不要二选一。** 整果保客流和毛利，切果保转化和客单，关键看门店客群和损耗控制能力。

**判断建议：**

1. **整果更适合做主力**
   - 菠萝整果耐放、损耗低、毛利空间更好，适合家庭采购和价格敏感客群。
   - 整果有“挑、称、现场削”的体验感，能带动生鲜区人气。
   - 采购上整果便于分级、控损，退货和尾货处理空间更大。

2. **切果更适合做补充和增量**
   - 适合年轻客群、上班族、小家庭、即食场景，能提高转化率和客单价。
   - 切果能消化外观瑕疵果、提升尾货利用率，但**对操作卫生、冷藏、时效要求高**。
   - 切果损耗和人工成本高，必须控制产量和时段，不能全天大量陈列。

3. **按门店类型定比例**
   - 社区店、家庭客群为主：整果占70%—80%，切果20%—30%。
   - 商圈店、写字楼店、年轻人多：整果50%—60%，切果40%—50%。
   - 高端精品超市：可提高切果和果切拼盘比例，但要做冷藏和当日清货。
   - 低毛利、低客流门店：优先整果，切果只做少量试销。

4. **可执行的陈列和控损做法**
   - 整果做堆头或端架，标清品种、甜度、产地和吃法。
   - 切果放冷藏柜，小份装、分时段补货，下午和晚间做折扣清货。
   - 切果用瑕疵果做原料要先分级，不能把变质果切进去。
   - 设“现场削皮”服务，兼顾整果销售和即食需求。
   - 每周看三个数：整果损耗率、切果损耗率、切果售罄率。切果连续滞销就减量或停做。

**简单决策标准：**  
如果门店家庭客多、人工紧、冷藏条件一般，**整果为主**；如果年轻客多、即食需求强、有冷藏柜和稳定人工，**切果比例可提高**。最稳的是整果做基本盘，切果做测试和增量。
