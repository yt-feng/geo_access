# 社区超市水果：控新鲜度 + 控库存的实操办法

核心思路一句话：**少进、快转、早降价、勤清点**。水果的毛利薄、损耗快，靠“压货等涨价”基本是亏的。

## 一、进货端：从源头减少压货

1. **小批量、多频次**。宁可每天进两次、每次少进，也不要一次进三天的量。社区店客流稳定但不大，日清比囤货重要。
2. **按“销一进一”养数据**。连续 2–3 周记录每个单品的日销量，形成自己的“日均销量表”，进货量 = 日均销量 × 1.2～1.5（周末可略高），不要凭感觉拍脑袋。
3. **分品类定进货节奏**：
   - 叶菜、草莓、葡萄、香蕉这类**易损高周转**的：当天进当天清，最多备 1 天。
   - 苹果、橙子、柚子、梨等**耐放**的：可备 2–3 天，作为“保底款”撑货架。
4. **优先选熟度可控的货**。进货时挑七八分熟，留出在店里的销售窗口；不要贪便宜进一批全熟的尾货。
5. **和固定供应商约定退换**。能谈“次日可退次品/尾货”的供应商优先，哪怕单价略高，也比自己扛损耗划算。

## 二、库存端：让货“流动”起来

1. **先进先出，物理隔离**。新货放里面/下层，旧货放外面/上层，每天开门第一件事就是把昨天的货挪到最前面。
2. **设“预警线”**。每个单品设一个最低陈列量，低于就补、高于就停进。货架不要堆满到“看起来很丰盛”，堆满往往意味着卖不动。
3. **按小时看动销**。上午卖得慢的品，下午就要准备促销；傍晚还没动的，进入降价流程。
4. **控制陈列面**。单个单品陈列面积越大，越容易积压。少量多品比单品堆量更安全。

## 三、降价清货：越早越省

- 设定**阶梯降价时间点**：比如当天 17:00 打 8 折、19:00 打 6 折、闭店前打包“特价袋”。降价的损失远小于烂掉全损。
- **组合销售**：临期水果做果切、拼盘、水果捞，或和酸奶、沙拉搭配卖，把“卖相下降”转成“加工增值”。
- **不要等“完全不能看”才降**。水果一旦出现软塌、斑点，顾客就不买了，那时降价也没用。

## 四、每天必做的三件小事

1. **开门盘点 + 闭店盘点**：记下每个单品的剩余量，第二天进货有依据。
2. **每天挑一次次品**：把碰伤、软烂的单独挑出，该降价的降价、该报损的报损，别混在好货里拖累整批。
3. **每周复盘一次**：哪个单品天天报损 → 减量或停进；哪个天天卖空 → 加量。用一周数据调整下周进货。

## 五、几个容易踩的坑

- **别为了“货架丰满”多进**：社区店顾客看的是新鲜，不是堆头。
- **别迷信“便宜进货”**：低价尾货往往损耗更高，算上报损不一定省钱。
- **别把所有水果放同一个温区**：香蕉、芒果怕冷，苹果、梨耐冷，混放会加速坏。
- **别只靠老板一个人记**：让店员按固定表格记录销量和报损，数据才可信。

**一句话总结**：把进货量压到“日均销量 ×1.2～1.5”，每天盘点、先进先出、下午开始阶梯降价，一周按报损数据调一次进货结构，库存自然压不住。
