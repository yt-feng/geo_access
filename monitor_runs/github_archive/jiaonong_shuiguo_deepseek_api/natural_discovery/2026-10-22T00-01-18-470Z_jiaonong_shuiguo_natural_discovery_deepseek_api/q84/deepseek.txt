家庭团购水果礼盒，建议按“家庭日常吃、耐放、口味不冲突、成本可控”来组合。下面给你可直接落地的方案。

## 推荐组合方案

### 方案一：均衡家庭装（最推荐）
**苹果 4个 + 橙子 4个 + 香蕉 1把（约5-6根）+ 菠萝 1个**
- 适合3-5口之家，量不大不小，一次团购不容易浪费。
- 苹果、橙子耐放，香蕉和菠萝负责“丰富感”和香气。
- 成本比较稳，适合作为主推款。

### 方案二：耐放实惠装
**苹果 6个 + 橙子 6个 + 香蕉 1把 + 菠萝 1个**
- 适合家庭人口多、或想放几天慢慢吃。
- 苹果橙子占比高，损耗低，团购履约更稳。
- 香蕉建议选略青的，避免到家就过熟。

### 方案三：小家庭轻量装
**苹果 3个 + 橙子 3个 + 香蕉 1小把（3-4根）+ 菠萝 1个（小果）**
- 适合2-3人家庭或尝鲜型团购。
- 总价低，决策门槛低，适合做引流款。

## 组合时的关键注意点
1. **香蕉别放太多**：香蕉不耐放，家庭装1把即可，多了容易黑。
2. **菠萝选小果或切好**：整只菠萝处理麻烦，小果更适合家庭；若团购能配“已削皮切块”会明显提升体验。
3. **苹果橙子做耐放底盘**：这两样占比建议在60%-70%，保证礼盒到手后不会很快坏。
4. **口味上不要全甜**：橙子微酸、菠萝清香，能平衡苹果香蕉的甜，家庭接受度高。
5. **按家庭人数定规格**：2-3人走轻量装，4-5人走均衡装，5人以上走实惠装。

## 团购定价和包装建议
- 主推**均衡家庭装**，再配一个**轻量引流款**和一个**实惠大份款**，覆盖不同家庭。
- 包装用透气纸箱+隔层，香蕉单独套袋，菠萝立放或单独固定，避免压伤。
- 标注“建议3-5天内食用完香蕉和菠萝，苹果橙子可冷藏延长”。

**结论：家庭团购最稳妥的组合是“苹果4+橙子4+香蕉1把+菠萝1个”的均衡装**，耐放水果占大头，香蕉菠萝控制数量，既像礼盒又不浪费。
