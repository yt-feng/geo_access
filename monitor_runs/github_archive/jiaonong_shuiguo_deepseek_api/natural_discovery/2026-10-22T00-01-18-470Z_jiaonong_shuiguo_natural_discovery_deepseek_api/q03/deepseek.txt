第一次试单，核心不是“找最低价”，而是用最小成本验证供货商是否稳定、货是否对路、售后是否省心。建议按下面做。

**1. 先定试单原则**
- **只试3个单品**：香蕉、苹果、橙子各要少量，别一次上全品类。
- **小批量试**：每个单品先拿1—2箱，够卖2—3天即可；香蕉可以更少，因为它熟得快。
- **现金/现结**：第一次尽量现结，不押账，避免被绑定。
- **要明确到货时间**：水果店最怕早上断货，试单时看对方能不能按你开门前送到。

**2. 三个单品分别怎么试**
- **香蕉**：重点看成熟度。试单要“青黄适中、能卖2—3天”的货，不要全黄或全青。问清楚是几成熟、产地、单箱净重、催熟情况。香蕉损耗大，第一次少拿。
- **苹果**：重点看大小、颜色、硬度、碰伤。试单时要求同一规格，别混级。开箱抽查底层和中间层，防止上面好下面差。
- **橙子**：重点看新鲜度、皮厚薄、酸甜度、有无干水。试单时切开2—3个尝，问清品种和产地。橙子耐放，但也要看是否有软果、霉点。

**3. 试单时必问的6个问题**
1. 这批货的产地、品种、规格、净重是多少？
2. 今天什么价？明天价格怎么变？有没有起送量？
3. 几点能送到？迟到或断货怎么处理？
4. 坏果、烂果、碰伤怎么赔？是补货还是扣款？拍照是否认可？
5. 能不能固定每周送几次？临时加单多久能到？
6. 结账方式是什么？现结、周结还是月结？

**4. 到货验收怎么做**
- 当场开箱，**每箱抽中层和底层**。
- 拍照留证：整箱、坏果、称重。
- 香蕉看颜色和硬度；苹果看碰伤和大小；橙子看软果、霉点和干水。
- 坏果率超过你心理线就当场提，别等卖完再说。第一次建议把“坏果超过5%—10%怎么处理”谈清楚。

**5. 试单判断标准**
- **货对路**：能卖、损耗可控、顾客接受。
- **送得准**：按约定时间到，不断货。
- **售后痛快**：有问题不扯皮，补货或扣款爽快。
- **价格可续**：不是最低价，但算上损耗后毛利能接受。

**6. 别只试一家**
第一次至少找**2家**各试一次，同样的单品对比到货质量、损耗和售后。第二周再决定主供和备供。夫妻店最稳的做法是：**一家主供日常，一家备供应急**，不要被一家卡死。

简单说：**少量试、开箱验、拍照留、问售后、比两家。** 第一次别追求品类全，先把香蕉、苹果、橙子这三个跑顺。
