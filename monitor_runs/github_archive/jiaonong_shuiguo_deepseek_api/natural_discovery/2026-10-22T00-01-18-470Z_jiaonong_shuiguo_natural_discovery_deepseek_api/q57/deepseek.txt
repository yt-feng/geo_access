建议默认选“中央厨房统一收货”，但要做分级：高频易损水果可由区域仓/中央厨房统一控标准后再配送门店，极少数超短保、强本地化单品保留门店直收权限。

**一、优先中央厨房统一收货的理由**
1. 品质标准统一：糖度、规格、成熟度、农残检测、验收口径一致，减少门店凭经验收货导致参差。
2. 议价与集单能力更强：总部或区域集采，价格、返利、账期更可控。
3. 食品安全与追溯更稳：供应商准入、批次留样、检测报告、冷链记录集中在中央厨房，出问题可召回和定责。
4. 减少门店操作负担和舞弊空间：门店只管接货和使用，不用做供应商谈判、验收和退货博弈。
5. 便于加工分流：中央厨房可做分拣、催熟、切配、坏果剔除，再按门店销量配送，降低损耗。

**二、门店分开收货适用的场景**
1. 叶菜、浆果、鲜切水果等极短保品，中央厨房二次分拣配送反而增加损耗和时间。
2. 门店密度低、配送半径大，统一配送成本高于本地直采。
3. 地方特色水果或季节性单品，本地供应商响应更快、价格更优。
4. 门店已有成熟品控能力和称重验收流程，且总部能远程稽核。

**三、可执行判断标准**
- 若门店数≥20家、单店水果SKU较稳定、需要统一食安审计：选中央厨房统一收货。
- 若水果占营收比高、损耗率对毛利影响大：用“中央厨房统收统配+区域仓前置+门店少量直收”的混合模式。
- 对每个SKU做四象限：保质期短且配送半径长→门店直收；标准化程度高且量大→中央厨房统收；高单价礼盒/加工果→中央厨房；本地特色小批量→门店直收但总部批价备案。

**四、落地要点**
1. 建立统一验收标准：品种、规格、糖度、成熟度、瑕疵率、农残抽检、冷链温度。
2. 中央厨房设水果验收区和催熟/分拣区，按门店订单做越库或简单加工。
3. 门店直收品必须总部准入供应商、锁价、拍照上传验收、异常48小时反馈。
4. 考核指标看：到店合格率、损耗率、缺货率、单公斤履约成本、门店投诉率，按季度切换模式。

结论：多数连锁餐饮应选中央厨房统一收货作为主模式，门店直收只作为短保和本地化补充，不要所有水果都让门店各自收货。
