批发档口要把退货纠纷压下去，核心不是“验得快”，而是“验得可追溯、责任当场厘清”。建议按下面做：

**一、收货前先定规则**
1. 和供应商书面约定验收标准：数量、规格、色差、破损、脏污、短装、批次差异的判定口径。
2. 明确异常处理时限：到货后几小时内反馈、拍照要求、补发/扣款/退货规则。
3. 对老供应商也保留抽检记录，避免“熟客货”出问题扯皮。

**二、到货当场验，别先入库**
1. **先点总数再拆细**：外包装件数、每件数量、箱唛与送货单是否一致。
2. **按比例抽检+重点全检**：高退货率品类、高单价品类、新供应商首批货全检或高比例抽检；稳定老货可抽检，但保留记录。
3. **验货顺序**：数量→规格型号→外观（破损/脏污/色差）→功能/尺寸→包装。发现问题立即隔离，不混入合格品。
4. **双人复核**：仓管初验，店长或采购复验异常项，避免一个人说了算。

**三、全程留证，证据要能对上**
1. 到货先拍**整车/整托/外包装**照片，再拍拆箱、标签、问题部位。
2. 视频要连续：从外包装完整状态拍到开箱、清点、问题特写。
3. 每批货建验收单：日期、供应商、单号、数量、抽检比例、异常明细、处理结果、双方签字。
4. 问题货单独区域存放，贴“待处理”标识，防止误卖后变成售后纠纷。

**四、异常当场定责**
1. 能当场判定的：短装、破损、明显色差，直接让送货人签字确认，或当天发书面确认。
2. 不能当场判定的：封样留存，约定复检时间和责任方。
3. 供应商不认的，以验收单+照片视频+封样为准，避免口头扯皮。

**五、把验收结果反推到销售端**
1. 验收合格才上架，问题货不进入销售库存。
2. 对经常出问题的供应商做到货合格率统计，连续不达标就调整采购比例或换供应商。
3. 销售端标注批次和验收状态，客户退货时能快速判断是货品问题还是售后问题。

**最简落地版：**一张验收单+一个固定验货区+一套拍照视频模板+异常当场签字。先把这三样跑一周，退货纠纷里“说不清是谁的责任”的部分会明显下降。
