# 坏果责任条款写法建议

核心思路：**把"损耗"拆成可测量的标准 + 可操作的处理流程 + 明确的责任分摊**，避免只写一句"坏果由卖方负责"导致扯皮。

## 一、先定标准：什么叫"坏果"

合同里必须给出可判断的定义，建议写明：

- **约定验货时点**：到货后__小时内（如24小时）完成验收，逾期视为验收合格（但要给合理时限）。
- **约定抽样方法**：如"按每车/每批随机抽取__箱，每箱抽__个"，或按整车比例抽检。
- **约定坏果认定标准**：如腐烂、霉变、明显软化渗液、机械损伤面积超过__%、异味等，逐项列明。
- **约定合格阈值**：如"坏果率≤3%视为合格；超过3%的部分由卖方承担"。

## 二、责任分摊：按比例还是按档位

两种常见写法，选一种：

| 方式 | 写法示例 | 适用 |
|---|---|---|
| 比例扣款 | 坏果率超出3%的部分，按对应货值从货款中扣除 | 损耗波动小、易计量 |
| 档位处理 | 3%–5%：扣款；5%–10%：扣款+补货；>10%：买方有权拒收或退货，运费由卖方承担 | 损耗风险大 |

建议同时约定**运费和退货运费由谁承担**，以及**补货的时限**（如7日内补发）。

## 三、流程：谁来验、怎么留证

- 验货由双方共同进行，或委托第三方（如市场检测机构）出具报告。
- 拍照/视频留证要求：坏果集中摆放、标注批次、带时间水印。
- 异议期限：买方应在验收后__小时内书面提出异议，附证据；逾期视为认可。

## 四、兜底条款

- **不可归责于卖方的情形**：买方指定运输方式/承运人、买方延迟卸货、不可抗力等造成的损耗，卖方不担责。
- **质量保证金**：可约定扣留货款__%作为质量保证金，验收合格后__日内支付。
- **违约金上限**：明确坏果赔偿以该批次货值为限，避免无限责任。

## 五、实操提醒

1. **别只写"坏果包赔"**——没有标准就无法执行，诉讼中也难举证。
2. **抽样比例要写死**，否则双方各抽各的，结果对不上。
3. **验货时限要合理**，太短对买方不利（货到即验不现实），太长对卖方不利。
4. 如果走冷链，把**温度记录**作为交接凭证写入合同，损耗争议时能区分是运输问题还是货物本身问题。
