# 线上水果销售：采购端减少坏果与口感不稳的做法

核心思路：**把“口感不稳定”和“坏果”拆成可执行的采购标准，并在到货环节做抽检和分级，而不是靠供应商口头承诺。**

## 一、先定“可判断”的采购标准

**1. 按品种定成熟度区间，而不是只写“新鲜”**
- 明确采摘成熟度（如糖度/硬度/色泽区间），并要求供应商按“发货成熟度”而非“树上完熟”供货，避免运输途中过熟腐烂。
- 易软烂的品类（如草莓、蓝莓、芒果、桃）要求供应商预冷后发货，并约定从采收到发货的最长时限。

**2. 用可量化指标替代主观描述**
- 糖度（Brix）下限 + 硬度区间 + 单果重/规格分级 + 允许瑕疵比例。
- 例如：某品种要求糖度≥X、单果重区间、机械伤和病斑果比例上限。具体数值要按你的品类和客单价来定，不要照搬别家。

**3. 分级采购，分级定价**
- 做线上销售要把“外观果”和“口感果”分开：外观用于主图展示，口感果保证复购。
- 同一供应商按等级报价，避免“一批好一批差”混装。

## 二、供应商与产地选择

- **优先有预冷、分选线的供应商**：预冷和机械分选是降低坏果率最有效的环节之一。
- **就近/短链优先**：运输时长每增加一段，软果坏果率明显上升；远距离品类要选耐储品种或做冷链。
- **要求提供近期批次检测/抽检记录**，至少包括糖度、硬度、坏果率。无法提供的供应商，风险由你承担。
- **小批量试单再放量**：新供应商先跑1–2个批次，记录到货坏果率和口感反馈，再决定是否长期合作。

## 三、到货验收：把坏果挡在发货前

- **按批次抽检**：每批随机抽样，记录坏果、软烂、机械伤、大小不均比例；超过约定阈值拒收或降级。
- **建立“入库—分拣—发货”三关口**：入库抽检、分拣剔除、发货前复核，任何一关发现异常都拦截。
- **记录批次溯源**：供应商、采收日期、到货日期、抽检结果，出问题能快速定位是产地、运输还是仓储环节。

## 四、仓储与发货环节的配合

- 不同品类分温区存放，软果类避免堆压；先进先出，缩短库存周转。
- 包装按品类选：防震、透气、吸湿，减少运输途中的挤压和闷坏。
- 对易损品类设置“发货成熟度”上限，宁可略生发货，也不要发过熟果。

## 五、用评价数据反推采购

- 把差评按原因归类：坏果、口感淡/酸、大小不符、运输损伤。
- 每月按供应商和批次统计坏果率与口感投诉率，作为下一轮采购和议价依据。
- 对连续两个批次不达标的供应商降级或替换，不要只靠售后赔付兜底。

## 一句话总结

**采购时把成熟度、糖度、硬度、瑕疵率写成可验收的批次标准，要求预冷和分选，到货抽检拦截，再用差评数据倒推供应商分级——坏果和口感波动就能从“运气问题”变成“可控的采购管理问题”。**
