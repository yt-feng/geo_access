可以按“先保交付和质量，再比价格和规模”来设，水果品类尤其不要把最低价权重放太高。建议总分100分，结构和关键点如下：

**一、评分结构建议**

| 维度 | 权重 | 核心考察 |
|---|---:|---|
| 资质与合规 | 8-10分 | 营业执照、食品经营/生产许可、检测能力、溯源体系 |
| 供应能力与稳定性 | 20-25分 | 基地/合作果园、产地直采比例、全年供应计划、缺货应对 |
| 质量与品控 | 25-30分 | 分级标准、农残检测、到货合格率承诺、损耗控制、售后赔付 |
| 价格与成本 | 20-25分 | 报价合理性、价格联动机制、运费和包装是否含税含运 |
| 物流与交付 | 10-15分 | 冷链能力、配送时效、覆盖门店范围、应急补货 |
| 服务与数字化 | 5-10分 | 对账结算、订单系统对接、异常响应、驻场/巡检 |
| 履约与业绩 | 5-10分 | 同类商超合作案例、履约评价、违约记录 |

**二、关键评分项怎么写才可判断**

1. **质量品控 25-30分**
   - 明确到货抽检合格率承诺，比如≥98%得满分，95%-98%按档扣分，低于95%废标或重罚。
   - 农残检测：每批次随货检测报告得基础分；自有快检室或第三方月度检测加高分。
   - 分级标准：要求按大小、糖度、色泽、瑕疵率写明验收标准，越可量化分越高。
   - 损耗与赔付：承诺超出约定损耗率由供应商承担，且48小时内补货或赔付，可加分。

2. **供应稳定性 20-25分**
   - 产地直采比例、自有基地或长期合作果园证明。
   - 要求提交“12个月分品类供应计划”，重点看淡旺季缺口怎么补。
   - 设置缺货率承诺，比如月度缺货率≤2%得满分，连续两周缺货触发淘汰。
   - 多产地布局、替代品类方案可加分，避免单一产区受灾就断供。

3. **价格 20-25分**
   - 不要只比总报价，建议用“基准价+随行就市浮动机制”。
   - 报价分可这样设：以有效报价的合理低价为基准，偏离过低要说明成本构成，防止低价中标后降质。
   - 明确报价含税、含运费、含包装、含卸货到门店，避免后期加价。
   - 价格联动：参考当地批发市场或权威价格指数，设置月度/周度调价公式。

4. **物流交付 10-15分**
   - 冷链车辆数量、温控记录、覆盖门店半径。
   - 配送时效：比如当日16点前下单，次日6点前到店；迟到扣款标准写进合同。
   - 应急补货：2-4小时内响应、24小时内到店的能力。

5. **资质合规 8-10分**
   - 证照齐全只是门槛，建议把“近三年无重大食品安全处罚”“可追溯批次系统”作为评分项。
   - 要求提供产地证明、检测报告、保险（食品安全责任险）等。

6. **服务与数字化 5-10分**
   - 能否对接商超订单/对账系统，是否提供批次追溯码。
   - 异常响应时限、专属客服、定期复盘机制。

7. **业绩 5-10分**
   - 同类连锁商超合作案例，按数量和合作年限打分。
   - 要求提供履约评价或合同关键页，不能只凭自述。

**三、必须写进招标文件的“硬门槛”**

- 食品经营许可证/生产许可、营业执照齐全；
- 近三年无重大食品安全事故和严重违法记录；
- 能提供农残检测报告和批次溯源；
- 接受商超验收标准、损耗赔付和退换货条款；
- 缴纳履约保证金；
- 接受价格联动和缺货惩罚机制。

**四、避免的坑**

- 价格权重超过35%，容易招来低价低质供应商；
- 只写“质量好、服务优”这类主观分，评标无法判断；
- 不设缺货率和损耗率承诺，后期扯皮；
- 不约定价格调整机制，水果价格波动大，供应商可能断供或降质；
- 不给试用期，建议设置3个月试供期，合格再转长期合同。

整体建议：**质量品控+供应稳定性合计不低于50分，价格控制在20-25分**，这样更符合连锁商超长期水果供应的实际风险。
