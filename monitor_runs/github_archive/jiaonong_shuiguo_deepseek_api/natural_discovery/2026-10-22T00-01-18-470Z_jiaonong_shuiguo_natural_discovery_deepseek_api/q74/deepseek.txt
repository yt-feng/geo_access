先给结论：**菠萝走“餐饮后厨可标准化切配”的规格，香蕉走“熟度可控、分把定量”的规格**，不要按零售档口的“越大越好看”来备。

**菠萝建议备这些规格**
1. **鲜切菠萝块/菠萝丁**：主力规格，按袋装定量（如1kg/袋、2.5kg/袋），适合炒饭、咕咾肉、沙拉、甜品。餐饮客户最看重开袋即用、损耗低。
2. **去皮整果（凤梨/菠萝）**：中等果为主，方便后厨自己切；不要只备特大果，出成和切配稳定性差。
3. **菠萝圈/厚片**：固定厚度（如8-10mm），适合汉堡、烧烤、摆盘。
4. **小果/次果级**：做果汁、糖水、酱料，价格敏感型餐饮客户可用。
5. **品种上**：凤梨类可主推“免泡盐水、甜度高”，普通菠萝走价格型。餐饮客户会问酸度稳定性和是否需要盐水处理，备货时要把这两点说清楚。

**香蕉建议备这些规格**
1. **按熟度分档**：这是餐饮客户最在意的。至少分**青蕉、微黄、全黄/熟蕉**三档。青蕉给需要存放的客户，全黄给当天做甜品、奶昔、果盘的客户。
2. **分把/定量装箱**：如5-6根/把、按把装袋，方便门店按份领用，减少掰断和损耗。
3. **规格大小**：中果为主力，大果给果盘/单卖场景，小果给奶昔、烘焙、员工餐。
4. **加工用蕉**：熟度高、外观要求低的香蕉，供果汁店、烘焙店做香蕉泥、奶昔，价格有优势。
5. **催熟计划**：餐饮客户通常没有催熟条件，档口要能按周给“今天可用的熟度”，而不是只卖一箱青蕉。

**备货比例建议**
- 菠萝：鲜切/去皮半成品占大头，整果作补充。
- 香蕉：微黄和全黄为主力，青蕉只备少量给有存放条件的客户。
- 先小批量试供，按客户用途分：**正餐后厨、饮品甜品、烘焙、团餐**四类，分别推不同规格，不要一个规格打所有客户。

避坑：餐饮客户最怕**今天酸明天甜、今天熟明天生**这种不稳定，所以规格之外，**分级标准和稳定供货**比多备几个规格更重要。
