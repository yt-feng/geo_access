小面积便利店做水果，核心原则是：**少SKU、高频补、只做“顺手买”场景，不做全品类水果店**。下面按品类和损耗分别给可执行做法。

## 一、品类控制：控制在8–15个SKU

**选品结构建议（按面积小、周转快排序）：**

1. **引流款（2–3个）**：香蕉、苹果、橙子。耐放、认知度高、价格敏感，用来建立“这家店有水果”的印象。
2. **即食款（3–5个）**：小番茄、葡萄/提子、切好的果切、单根香蕉。针对上班族、学生“买了就吃”。
3. **季节款（2–3个）**：当季最便宜、最好卖的1–2个单品，如夏天西瓜（可切盒卖）、冬天砂糖橘。不要同时上多个季节品。
4. **利润款（1–2个）**：精品小包装（如蓝莓小盒、车厘子小盒），量少、单价高、走礼品或尝鲜。

**明确不做的品类：**
- 易碰伤、难存放的：水蜜桃、草莓、枇杷（除非当天能卖完且冷链到位）。
- 大件整颗西瓜、整箱水果——占地方、切开卖不完就是损耗。
- 长尾稀有水果——周转慢，小门店扛不住。

**陈列量控制：** 每个SKU陈列不超过1–2层，卖完再补，货架永远“看起来满”但实际库存小。水果区面积建议控制在门店的5%–10%。

## 二、损耗控制：从采购到报废全链路

**采购端：**
- **小批量、多频次**：每天或隔天采购，单次采购量按“预估日销×1.2”下单，宁缺勿压。
- **按销售数据订货**：记录每个SKU近7天销量，订货量=日均销量×（1+安全系数0.2–0.3），新品先试小量。
- **叶菜类/浆果类当天进当天清**，不隔夜。
- **和供应商谈“少量多配”**：哪怕单价略高，也比压货损耗划算；优先找本地批发市场或二级批发商，起订量低。

**收货端：**
- 当场验货：碰伤、软烂、过熟的拒收或折价，别“先收下再说”。
- 按成熟度分级：熟度高的当天陈列促销，生一点的正常卖。

**陈列与库存：**
- **先进先出**，新货放后面，旧货放前面。
- 香蕉、苹果等释放乙烯的不要和叶菜、浆果混放。
- 易损品用小筐、浅陈列，避免堆压。
- 每天早晚各理一次货，挑出次品及时处理。

**销售端去损耗：**
- **临期折价**：当天卖相下降的水果，傍晚做“特价盒”“10元3盒”，比扔掉强。
- **果切/果盒**：把品相稍差但没坏的水果切盒卖，提升附加值，但必须当天切当天清，冷藏展示。
- **组合销售**：水果+酸奶、水果+沙拉，提高客单和周转。

**数据与复盘：**
- 每天记录：进货量、销量、报废量、折价销量。
- 每周算每个SKU的**损耗率**，连续两周损耗高的直接砍掉。
- 小门店损耗率控制目标：整体5%–10%以内，浆果类可放宽但必须当天清。

## 三、一句话执行清单

- SKU：8–15个，引流2–3、即食3–5、季节2–3、利润1–2。
- 采购：每天/隔天小批量，按7天销量×1.2订货。
- 陈列：浅陈列、勤补货、先进先出。
- 去损耗：临期折价+果切当天清。
- 复盘：每周砍掉高损耗SKU。

如果门店没有冷藏柜，建议进一步压缩浆果和切果品类，只保留香蕉、苹果、橙子、小番茄这类常温耐放的，损耗会明显下降。
