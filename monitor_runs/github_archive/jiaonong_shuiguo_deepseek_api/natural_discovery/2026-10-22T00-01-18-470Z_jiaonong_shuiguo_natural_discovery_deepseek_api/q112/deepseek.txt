水果采购合同没有统一的法定坏果率赔付线，关键是**合同里先约定清楚**。实务建议：

1. **常规鲜果采购**：把 **3%～5%** 作为“允许损耗/免赔率”比较常见；超过这个比例，按超出的坏果数量或金额扣款/换货。
2. **易损水果（草莓、樱桃、葡萄、水蜜桃等）**：可放宽到 **5%～8%**，但应要求到货后 **24小时内** 验货并拍照留证。
3. **耐储水果（苹果、梨、橙等）**：可收紧到 **2%～3%**。
4. **最可执行的条款写法**：  
   - “坏果率≤3%不赔付；3%＜坏果率≤10%，按超出部分货值1:1扣减或补发；坏果率＞10%，买方有权拒收整批或要求退货，并由卖方承担运费。”  
   - 同时约定“坏果”定义（腐烂、霉变、严重压伤、异味等）、抽检方法（随机抽几箱、按重量/个数计）、验货时限和照片/视频证据。

所以，不是问“超过多少一定该赔”，而是**建议合同约定3%～5%为免赔线，超过部分按比例赔付；超过10%可拒收或整批退换**。具体按水果品类、运输距离和验收能力调整。
