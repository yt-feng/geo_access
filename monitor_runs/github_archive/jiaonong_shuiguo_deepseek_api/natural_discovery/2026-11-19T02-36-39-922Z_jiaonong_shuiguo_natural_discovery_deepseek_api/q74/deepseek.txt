做餐饮客户，菠萝和香蕉的规格要围绕“出餐稳定、损耗可控、后厨好处理”来定，不能照搬零售档口的统货思路。建议按以下规格准备：

**菠萝**
- **鲜切/饮品店用**：主推单果1.2～1.5kg的中果，成熟度7～8成，果眼浅、心小。按箱给餐饮客户，注明单果重量区间和每箱个数，方便他们算杯量成本。
- **后厨现削/烘焙用**：可备1.5～2kg大果，成熟度6～7成，耐放、出肉率高。适合做菠萝炒饭、咕噜肉、披萨配料。
- **不建议餐饮渠道主推**：过熟果、小果统货。餐饮最怕今天甜明天酸、切开黑心，损耗会直接吃掉毛利。
- **关键动作**：给餐饮客户报“出肉率参考”和“到货成熟度”，比如“中果7成半熟，到货可放2～3天，切开即用”。

**香蕉**
- **饮品/甜品店**：主推单根120～150g的中把蕉，成熟度3～4号色（偏青黄），到店后2～3天转黄正好用，避免一到位就全黄。
- **餐厅果盘/后厨用**：可用150～180g大把蕉，成熟度4号色，出餐品相好。
- **烘焙/香蕉泥用**：可单独报“熟蕉/处理蕉”规格，价格低、成熟度高，但必须明确是加工用途，不能混进鲜食箱。
- **关键动作**：香蕉按“色号+单根重+每箱把数”报规格，餐饮客户最需要可预期，不要只报“一箱多少斤”。

**档口备货建议**
- 菠萝：中果和特大果各备一个主规格，按箱陈列，标注单果重、成熟度、建议用途。
- 香蕉：青黄（3～4号色）为主，少量4～5号色做急用；加工熟蕉单独放、单独报价。
- 给餐饮客户做一张简单规格卡：品名、单果/单根重、成熟度、每箱规格、建议用途、到货后可放天数。餐饮采购看这个比看报价单更快。

如果只能先备两个规格：**菠萝备1.2～1.5kg、7～8成熟中果；香蕉备120～150g、3～4号色中把蕉**，覆盖饮品店和中小餐厅最常见需求。
