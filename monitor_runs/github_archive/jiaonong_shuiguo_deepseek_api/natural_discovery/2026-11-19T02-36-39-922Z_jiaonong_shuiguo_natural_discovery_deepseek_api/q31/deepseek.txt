连锁商超招长期水果供应商，评分标准的设置关键是把“长期稳定”和“水果品类特性”落到可核验的条款上，而不是只看报价。建议按百分制设置，权重和评分点如下：

**一、总体权重建议**
| 维度 | 权重 | 说明 |
|---|---|---|
| 价格与商务条件 | 25–30分 | 不以最低价为唯一标准，设成本分析 |
| 产品质量与食品安全 | 25–30分 | 长期合作的核心，必须可核验 |
| 供应保障与履约能力 | 20–25分 | 产地、仓配、产能、天气/季节应对 |
| 服务与运营配合 | 10–15分 | 订单响应、退换货、促销支持 |
| 企业资质与可持续发展 | 5–10分 | 合规、财务、ESG可作为加分项 |

**二、各维度具体评分点**

1. **价格与商务（25–30分）**
- 报价按品类/规格分项评审，避免一个综合折扣率包打天下；建议以“基准价+浮动机制”报价，便于长期调价。
- 设置成本构成说明（采购、分选、包装、冷链、损耗、税费），异常低价要扣分或要求说明。
- 账期、结算方式、年度返利/量价阶梯单独评分。
- 建议价格分采用“合理低价法”而非“最低价法”，防止低价中标后降质。

2. **产品质量与食品安全（25–30分）**
- 明确验收标准：糖度、规格、色泽、成熟度、农残检测、损耗率上限，写入评分表并附检测方法。
- 要求提供近6–12个月第三方检测报告、产地证明、承诺达标合格证；有自有检测室或快检能力的加分。
- 样品盲评：现场或寄样评分，占质量分的较大比重，避免只看文件。
- 质量稳定性：要求提供历史供货记录、退换货率、客诉率，作为评分依据。
- 可追溯体系：批次追溯、产地到门店的链路是否可查。

3. **供应保障与履约（20–25分）**
- 产地资源：自有基地、合作基地、产地直采比例，需合同或证明。
- 产能与峰值供应能力：按商超日均/大促需求量给出承诺供应量，并说明缺口应对方案。
- 冷链与仓配：冷链车辆、预冷设施、区域配送中心、到店时效。
- 季节性与灾害应对：反季节供应方案、极端天气/疫情等应急预案。
- 履约记录：过往合作客户的履约评价、违约记录；新供应商可用银行资信、履约保函替代。

4. **服务与运营配合（10–15分）**
- 订单响应时间、紧急补货能力、退换货政策。
- 促销与新品支持：堆头、试吃、节日礼盒、新品开发配合度。
- 信息化对接：能否接入商超的订单/库存/追溯系统。
- 驻场或专属对接人员配置。

5. **企业资质与可持续发展（5–10分）**
- 营业执照、食品经营许可、种植/养殖相关资质、ISO22000/HACCP等。
- 财务健康度：审计报告、纳税记录、涉诉情况。
- ESG加分：绿色种植、减药减肥、包装减量、员工保障、扶贫助农等，需有可核验材料。

**三、设置时要注意的几条规则**
- **资格项与评分项分开**：证照齐全、无重大食品安全事故、无严重失信记录应设为门槛，不占分。
- **可核验**：每个评分点都要写明“提供什么材料、如何核验”，否则评标时无法打分。
- **防止低价陷阱**：设置成本红线，报价明显低于成本需提供说明，否则作无效或扣分处理。
- **长期合同配套条款**：评分标准要与合同挂钩，如质量不达标扣款、连续不合格退出、年度考评机制、价格调整公式。
- **分品类差异化**：叶菜、根茎、进口水果、礼盒类的权重应不同，叶菜更重冷链和时效，礼盒更重包装和规格稳定性。
- **试供期**：建议中标后设1–3个月试供，试供考核结果纳入正式合作，降低长期风险。

**四、一个可直接用的简化模板**
- 价格商务30分：分项报价15、成本合理性5、账期返利5、价格调整机制5
- 质量安全30分：验收标准符合度10、检测报告与追溯8、样品盲评10、历史质量记录2
- 供应履约25分：产地资源8、产能承诺6、冷链仓配6、应急预案5
- 服务配合10分：响应与退换货5、促销与信息化5
- 资质ESG5分：资质2、财务1、ESG加分2

最后提醒：评标办法要在招标文件中写清楚“评分细则、证明材料清单、无效标情形”，并保留现场考察或样品复检环节，评分才可落地。
