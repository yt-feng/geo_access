要，但不能只靠“固定产地/固定批次”这一招，应该做“双层固定+验收标准+替代预案”。

**结论**
- **水果风味波动大、且是招牌产品的原料：要固定产地，并尽量固定供应商/加工批次。**
- **但不要固定到单一产地、单一批次、单一供应商**，否则遇到断货、品质下滑、价格暴涨会很被动。
- 更稳的做法是：**固定“品种+产区+等级+成熟度+验收指标”，批次可追溯，同时保留1个备用产区/供应商。**

**为什么固定产地和批次有用**
1. 同一品种在不同产区、海拔、气候、成熟度下，糖酸比和香气差异明显，茶饮店最怕的就是“配方没变、味道变了”。
2. 固定产地能减少大方向波动；固定供应批次/加工批次能减少采收期、仓储和冷链造成的二次波动。
3. 对连锁或爆款产品，批次可追溯还能快速定位“这批水果为什么变酸/变淡/出汁率低”。

**但不能死固定**
- 水果是农产品，同一产地不同年份也会波动，固定产地不等于味道稳定。
- 单一产地遇到减产、雨季、病虫害、物流中断，会直接断供。
- 单一批次固定不现实，鲜果批次寿命短；应固定“规格标准”，而不是迷信某个批次号。

**建议采购落地做法**
1. **写清采购规格**：品种、产区范围、等级、单果重/果径、成熟度、糖度范围、酸度范围、出汁率、色泽、瑕疵率。
2. **每批验收**：糖酸比、香气、果肉状态、出汁率、坏果率；招牌产品可做小样杯测/盲测。
3. **固定主力+备用**：主力产区/供应商占70%—80%，备用产区/供应商占20%—30%，定期小批量测试。
4. **批次可追溯**：记录产地、采收/加工日期、供应商、验收结果；出现风味偏差能追溯到批次。
5. **配方留弹性**：设定糖度/酸度微调规则，比如通过糖浆、酸度调节或拼配不同批次，把最终杯感拉回标准。
6. **季节切换预案**：提前准备替代品种或替代产区，避免旺季断供时临时换料导致口碑波动。

**一句话**
**要固定产地和供应体系，但固定的是“标准+主力来源+可追溯批次”，不是把命押在单一产地或单一批次上。**
