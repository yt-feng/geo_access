**结论：在商超水果采购里，损耗低对最终毛利的影响通常大于进价低；但两者不是二选一，核心是“毛利 = 售价 − 进价 − 损耗成本”，要看哪个环节把利润吃掉了。**

可以按下面判断：

1. **水果是典型高损耗品类，损耗对毛利是放大打击**
   - 水果毛利本身不厚，且易腐、易碰伤、周转要求高。
   - 进价降 5%，只直接增加约 5% 的进货成本差额；
   - 损耗率如果从 8% 升到 15%，等于可售商品少了约 7 个百分点，且损耗部分还分摊了采购、冷链、人工、陈列成本。
   - 对多数商超，**损耗波动几个百分点，就足以吃掉全部采购议价空间**。

2. **价格低只有在“能卖出去、低损耗”时才成立**
   - 低价进货若品质差、成熟度高、规格不稳，会带来更高挑拣、降价处理和报废。
   - 低价但周转慢，也会增加保鲜成本和机会成本。
   - 所以低价必须换算成**“可售成本”**：进价 ÷ 可售率，而不是只看毛进价。

3. **什么时候价格低更关键？**
   - 需求稳定、周转很快、品质稳定、损耗可控的爆款单品；
   - 有明确促销走量，能在保鲜期内卖完；
   - 采购价差异很大，且低价货源品质不下降。
   这种情况下，进价低会明显提升毛利。

4. **什么时候损耗低更关键？**
   - 叶菜、浆果、熟度高的水果等易损品；
   - 门店客流不稳定、冷链陈列能力一般；
   - 采购量预测不准、库存周转慢；
   - 品质波动大、需要频繁挑拣降价。
   这类情况下，低损耗对毛利保护更直接。

**实操建议：**
- 不要只比进价，要比 **“可售毛利率”**：  
  `可售毛利率 =（销售额 − 可售商品采购成本 − 损耗成本 − 直接运营成本）÷ 销售额`
- 对新货源做小批量试销，记录到货品质、挑拣率、降价率、报废率、周转天数。
- 优先选择**品质稳定、损耗可控、周转匹配**的货源；低价货源只有在试销验证损耗不上升后才放量。
- 用单品分层：走量爆品可偏价格，易损高毛利品更偏损耗和品质。

一句话：**价格低决定你“有没有毛利空间”，损耗低决定你“能不能把毛利留住”。在水果商超采购中，通常后者对最终毛利更硬、更直接。**
