采购香蕉时，把“熟度”和“到货时间”写成可验收的硬标准，比只说“别太熟”有效得多。

**一、采购要求怎么写**

1. **按色卡定熟度**
   - 要求供应商按香蕉色卡发货，常用1—7级色卡中：
     - 到货即卖：3—4级（果身偏绿、棱角明显、少量转黄）
     - 2—3天内卖：4—5级（黄多于绿、棱角开始圆）
     - 当天促销：5—6级（基本全黄、少量糖斑）
   - 水果店常规采购建议主采**3.5—4.5级**，不要一次全进5级以上。
   - 合同或订单注明：“以到货验收时色卡级别为准，超过约定级别上限的部分拒收或折价。”

2. **分批次、分熟度下单**
   - 同一批不要全要一个熟度。可按销量拆成：
     - 60%—70%：3.5—4级，用于后续2—3天
     - 20%—30%：4.5—5级，用于当天和次日
     - 少量5.5级以上只做促销，不进常规库存
   - 要求供应商“按门店销量分筐/分箱标注熟度”，不要混装。

3. **到货时间要求**
   - 优先要求**清晨到货、门店开门前完成验收**，避开午后高温时段。
   - 运输要求冷藏车或阴凉运输，车厢温度建议**13—15℃**，不要低于12℃以免冷害，也不要常温暴晒。
   - 订单写明：“到货时间不晚于X点；延迟到货且熟度上升的，按降级或折价处理。”

4. **验收标准写清楚**
   - 果指饱满、无严重机械伤、无霉点、无大面积黑斑。
   - 允许少量“芝麻斑”，但糖斑面积大、果肉软塌的拒收。
   - 抽查箱内中层和底层，不能只看表面。
   - 到货时记录：色卡级别、箱温、到货时间、抽检坏果率。

**二、给供应商的简短话术**

> “我们香蕉按色卡验收，常规主采3.5—4.5级，5级以上需提前确认。请清晨X点前到货，冷藏车13—15℃运输，分筐标注熟度。到货熟度超过约定上限或延迟到货导致熟度上升的，按降级或折价处理。”

**三、门店配合**

- 到货后立即拆箱通风，不要闷在塑料袋里。
- 香蕉存放**13—15℃**，不要放冷藏柜；夏天避免靠门口暴晒。
- 按熟度分区陈列，先卖高熟度，绿蕉放后区。
- 每天记录销量和损耗，下一单按“前3天日均销量×1.2”左右控制采购量，宁少勿多、勤补货。

核心是：**用色卡定级、分批下单、清晨到货、验收留记录**。这样比笼统要求“发青一点的”更能减少放坏。
