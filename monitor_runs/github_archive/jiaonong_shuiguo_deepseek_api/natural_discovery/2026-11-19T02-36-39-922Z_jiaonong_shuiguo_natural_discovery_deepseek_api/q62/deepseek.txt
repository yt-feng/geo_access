判断一批香蕉，核心看“颜色、硬度、棱角、气味、果柄切口、箱内环境”六项，再结合你计划卖几天来定拿货熟度。

**1. 先定拿货熟度**
- 当天到店/次日就卖：拿5～6成熟偏黄、果身开始转色但条棱仍明显的货。
- 2～3天卖完：拿4～5成熟、青黄交界、硬身货。
- 超过3天：拿3～4成熟青货，但风险更高，必须有冷藏或催熟条件。
- 批发走量快、天气热：宁拿偏青，不拿偏黄。

**2. 看颜色**
- 整箱颜色均匀、青中带黄最好。
- 出现“黄里带黑点”且点密集成片，说明已过熟或运输伤热。
- 局部先黄、局部仍青，可能是受冷或催熟不均，后期易花皮、软烂。
- 果指根部先黄、尖端仍青，常见于催熟不匀，卖相会差。

**3. 摸硬度和棱角**
- 轻捏果身有弹性、不软塌；条棱明显说明还硬身。
- 果身发软、棱角消失，熟度高，坏果风险大。
- 同一箱里若有多根明显软塌，整箱风险上升。

**4. 查坏果和机械伤**
- 重点翻看底层、箱角、靠箱壁的果指。
- 果柄发黑、发霉、流胶，说明切口感染或闷箱。
- 果指有裂口、压伤、擦伤，后期易变黑腐烂。
- 黑斑小而分散、干爽，多为运输擦伤；黑斑大、湿软、凹陷，按坏果处理。
- 抽查比例建议不低于10%，大货至少翻3～5箱底层。

**5. 闻气味和看箱内环境**
- 有酒味、酸味、霉味，说明已发酵或霉变，整批谨慎。
- 箱内有水汽、纸箱发软、垫纸潮湿，坏果风险高。
- 摸箱内温度，发热闷箱的货熟得快、烂得快。

**6. 看果柄切口和蕉串状态**
- 切口新鲜、干爽、无霉点为好。
- 切口发黑、长毛、流汁，说明采收或运输环节有问题。
- 蕉梳连接处发黑软烂，后期易整梳脱落。

**7. 拿货决策建议**
- 现场做“三箱抽查”：每箱看底层、摸硬度、闻气味。
- 要求开箱验底层，不接受只验上层。
- 问清产地、采收时间、运输时长、是否催熟；催熟货熟度不均，风险更高。
- 合同或单据写明“坏果率超过约定比例可退换”，并现场拍照留证。
- 天气热、运输远、箱内潮湿、有酒味、底层软烂，满足两项以上就压价或拒收。

**简单口诀：** 看色匀、摸身硬、查底层、闻气味、看切口、验箱温；宁青勿黄，宁干勿湿，底层不行整批慎拿。
