判断香蕉批发档口的一手供货商是否稳定，重点看“货源组织能力”和“履约记录”，不要只看报价。可以按下面几步核验：

1. **先确认他是不是真正的一手或一级**
   - 问清产地：是自有/合作基地、产地代收点，还是从大型批发市场倒货。
   - 要求看产地装车视频、包装厂/催熟库照片、近期发货单，最好视频通话看现场。
   - 问香蕉主要来自哪里（如云南、广西、海南、老挝、越南、菲律宾等），不同产季是否有多产区替补。只有单一产区且无替补的，断供风险高。

2. **看供货结构和抗风险能力**
   - 日均能稳定供多少件/吨，旺季和淡季分别多少。
   - 有几个产区、几个催熟库或合作包装厂，是否受单一天气、单一果园影响。
   - 是否有冷库/催熟库、运输车辆或固定物流合作。香蕉对温控和催熟要求高，没有这些很难稳定。

3. **用“小单试供+连续到货”验证**
   - 先小批量试单，不要一上来压大单或付全款。
   - 连续走2—3车/批次，观察到货时间、数量误差、青黄成熟度、伤果率、条蕉均匀度。
   - 记录每批：约定到货时间 vs 实际时间、扣损比例、坏果率、补货响应速度。稳定供应商的关键是波动小，不是某一次特别好。

4. **查履约和纠纷记录**
   - 要求提供近3个月给其他档口的发货记录或合作档口联系方式，侧面问：断货频率、涨跌价时是否临时毁约、售后是否认账。
   - 问清缺货时怎么处理：是提前通知、同价调其他产区，还是直接违约。
   - 看合同/聊天记录里是否明确：规格、成熟度、到货时间、损耗赔付、价格随行就市的上浮上限。

5. **看价格和账期是否“异常友好”**
   - 明显低于市场价、承诺无条件赊销、催你大额预付的，要警惕。
   - 稳定一手货源通常价格有竞争力，但不会长期离谱低价；账期也取决于合作深度。
   - 建议付款方式：首批小额定金+到货验收后付尾款，稳定后再谈账期。

6. **关键风险信号**
   - 只发图片视频，拒绝实时视频看库/装车；
   - 说不清产区、说不清催熟环节；
   - 报价随你问价立刻大幅让利；
   - 要求全款私账、催大额预付；
   - 上一批损耗大就推给物流或天气，没有赔付方案；
   - 旺季前大量收预付款，但给不出近期连续发货记录。

**实操建议：**先按“小单试供—连续3批—再谈账期和量”的节奏走。每批留好聊天记录、发货单、验收照片。稳定供货不是靠对方口头保证，而是靠连续履约记录和缺货时的处理方式验证。
