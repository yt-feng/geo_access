旺季临时补货，关键不是“打个电话让供应商多送点”，而是提前把**补货触发条件、响应时限、价格和品质标准、违约责任**写成一份简单的临时补货协议或补充条款。可以按下面执行。

## 一、先定清楚补货规则

1. **约定临时补货的触发条件**
   - 例如：现有库存低于2天用量，或单日销量超过预估量的120%时，可发起临时补货。
   - 明确谁发起、以什么方式发起：微信、电话后补书面确认，或邮件/订货单。
   - 明确正常订单和临时补货的区分，避免供应商把临时单当正常单拖延。

2. **约定响应时限**
   - 例如：收到补货通知后2小时内确认能否供货，确认后24小时内送达门店。
   - 写明最晚到货时间，以及逾期如何处理。
   - 如果供应商无法满足，应提前告知，便于你启动备选供应商。

3. **约定补货数量和规格**
   - 按箱/公斤/个约定，写明品种、成熟度、单果重量范围、去皮/带皮、是否要求冷链。
   - 临时补货价格不要只写“随行就市”，否则旺季容易被抬价。可约定：
     - 按当日市场批发价上浮不超过X%；
     - 或按原合同价执行，临时加急费每单固定X元；
     - 或设置价格上限。

4. **约定品质验收标准**
   - 明确糖度、外观、腐烂率、黑心/坏果比例。
   - 例如：坏果率超过5%可拒收或按比例扣款；到货温度不符合冷链要求可拒收。
   - 写明验收时限，比如到货后30分钟内抽检，超时视为验收合格，避免扯皮。

## 二、和供应商谈的时候抓三个点

- **给供应商确定性**：承诺旺季最低采购量或优先采购权，换取临时补货优先级。
- **设置备选机制**：主供应商无法按时供货时，你有权从备选供应商补货，主供应商不得因此要求赔偿；同时可约定主供应商连续两次违约，你方可减少其份额。
- **把违约写轻但可执行**：不建议写过高违约金，容易谈崩。可写“逾期超过X小时，当批货款扣减X%”或“承担因此产生的替代采购差价”。

## 三、建议的协议核心条款模板

> 1. 临时补货以微信/电话通知为准，供应商应在2小时内确认，确认后24小时内送达。
> 2. 临时补货价格按原合同价执行，加急配送费每单____元；或按当日市场价上浮不超过____%。
> 3. 到货验收标准：坏果率≤____%，不符合标准的部分按实扣减货款，坏果率超过____%可整批拒收。
> 4. 供应商逾期送达超过____小时，当批货款扣减____%；因缺货导致门店断货的，供应商承担替代采购差价。
> 5. 本条款仅适用于____年____月____日至____月____日旺季期间。

## 四、操作上别只依赖一家

旺季菠萝用量突增，**至少保持一家备选供应商**，哪怕平时只少量采购。临时补货协议再细，也不如手里有第二个货源。同时门店每天记录菠萝用量和库存，提前1—2天触发补货，不要等断货再谈。
