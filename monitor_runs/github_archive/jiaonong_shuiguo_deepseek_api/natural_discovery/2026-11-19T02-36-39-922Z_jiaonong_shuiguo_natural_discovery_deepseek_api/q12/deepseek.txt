关键是把“采购熟度”和“预计售完时间”对齐，而不是一味挑最熟的。菠萝是后熟型水果，采购后还会继续变熟，但速度受温度影响很大。

**可执行判断：**

1. **按售完周期定熟度**
   - 1～2天内能卖完：可采**七八成熟**，果身开始转黄、有淡淡果香。
   - 3～5天卖完：采**六至七成熟**，以青黄为主，果香不明显，室温下逐步转熟。
   - 超过5天：只适合少量补货，且要有冷藏或阴凉通风条件，不建议大批量压货。

2. **看外观**
   - 果皮由青转黄、颜色均匀，鳞目饱满、不干瘪。
   - 基部开始泛黄、果顶仍偏青，通常耐放一些。
   - 避开表皮发暗、软塌、渗汁、霉点、明显撞伤的果。

3. **闻果香**
   - 基部有清淡果香：适合近期销售。
   - 香味浓、发甜甚至发酵味：已偏熟，损耗风险高，只适合当天促销。
   - 完全无香且很青：可放，但要控制量。

4. **按果身和果眼**
   - 果身硬实、按压有轻微弹性为宜；一按一个坑说明过熟。
   - 果眼浅、鳞目平展的通常成熟度较好；果眼深且尖、整体很青的偏生。
   - 叶片容易从果顶拔下可作为辅助判断，但不能只看叶子。

5. **看切口和基部**
   - 基部无渗液、无软腐、无异味。
   - 切口新鲜、不发黑；切口发黑或汁液多，说明存放久或已过熟。

6. **采购策略**
   - 同一批货**分熟度采购**：少量七八成熟用于当天和次日，多数六至七成熟用于后续几天。
   - 到店后按熟度分区摆放，先卖黄的，青的放阴凉通风处催熟。
   - 高温季节缩短采购周期，宁可少量多次补货，不要一次压太多。
   - 切开销售或做果切的，选熟度稍高但果身仍硬实的，别用已经发软有酒味的。

简单记：**看基部转黄、闻淡香、按有弹性、算好几天卖完。** 最稳妥的是“多数六至七成熟＋少量七八成熟”搭配进货。
