按“斤”结算最适合食堂水果采购的日常管理，建议作为主规则；箱/份只作为辅助或例外。

**结论：优先按斤，箱装可折斤验收，份装只用于即食分餐。**

- **按斤结算：最好管理、最公平**
  - 优点：数量可复核、单价可比价、损耗和退货好算；适合苹果、香蕉、橘子等散装水果。
  - 管理要点：固定验收秤、去皮称重、当场记录毛重/净重；约定允许误差（如±2%）；坏果当场扣重或退换。

- **按箱结算：适合标准化箱装，但必须“折斤验收”**
  - 风险：箱内大小不一、垫纸/冰袋/包装增重，容易扯皮。
  - 管理要点：合同写清净重、规格、允许差异；验收抽检并记录“箱重—皮重—净重”；价格按净重折算每斤单价对比，不能只看箱价。

- **按份结算：只适合切好/即食/固定份量**
  - 风险：份量不透明、单价偏高、不好比价。
  - 管理要点：限定每份克重、份数、适用场景（如会议、值班、分餐），并要求供应商按份标注净含量。

**落地建议：**
1. 主采购合同统一按斤计价和结算。
2. 箱装水果按净重折斤入库，包装物不计价。
3. 份装水果单独列目录，限定克重和单价，不混入散装比价。
4. 验收单固定三栏：毛重、皮重、净重；双方签字，坏果扣重。
5. 每月用“净重单价”横向比价，避免箱价/份价掩盖真实成本。

一句话：**散装按斤、箱装折斤、份装限场景；全部落到净重和验收记录上，最好管理。**
