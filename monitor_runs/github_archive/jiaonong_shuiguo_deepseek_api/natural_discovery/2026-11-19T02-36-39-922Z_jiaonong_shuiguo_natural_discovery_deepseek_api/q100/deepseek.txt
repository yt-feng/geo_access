可以按“采购—验收—储存—加工—兜底处理”五步控制。

1. **采购别一次买太多**
- 按“日均用量×1—2天”采购，香蕉不耐放，不要按周大量囤。
- 优先选**七成熟左右、表皮偏绿黄**的香蕉；已经全黄、带褐斑的只适合当天/次日用。
- 和供应商约定分批次送货，比如每周2—3次小批量，而不是一次送完。

2. **验收时分级**
- 到货立即分成三类：**青黄可存放、黄色即用、过熟急用**。
- 过熟香蕉不要直接入库，标注“优先使用”，当天做香蕉牛奶、香蕉粥、烘焙或水果捞。
- 拒收明显软烂、渗液、霉变、大面积黑斑的货。

3. **储存要控温通风**
- 香蕉不宜低温冷藏，**未熟香蕉放阴凉通风处，约13—15℃较合适**；不要放冰箱冷害。
- 悬挂或单层摆放，避免堆压；不要和苹果、梨等释放乙烯的水果混放，会催熟。
- 已切开或去皮香蕉需冷藏并尽快使用。

4. **食堂使用顺序**
- 实行“先进先出+熟度优先”：先用手捏偏软、表皮黄的，青的留后。
- 每天早班检查一次，把次日会过熟的香蕉提前转到加工岗。
- 菜单搭配上，香蕉可用于早餐、加餐、水果捞、奶昔、粥品、烘焙，不要只做整根分发。

5. **设兜底机制**
- 每天记录到货量、使用量、剩余熟度；连续几天剩余多，就下调采购量。
- 对轻微过熟但未变质的香蕉，开发固定加工用途；明显变质则按食品安全规定废弃，不用于加工。
- 和供应商谈少量多次配送、退换货条件，降低一次性压货风险。

关键判断标准：**表皮大面积褐斑、果肉软烂渗水、有酒味或霉点就不要再用**；只是表皮有少量斑点、果肉正常的，优先加工使用。
