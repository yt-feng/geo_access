# 生鲜水果坏果投诉的责任划分

核心判断标准：**坏果发生在哪个环节、由谁控制风险，责任就主要落在谁身上。** 实操中按下面几步判定：

## 一、先确定坏果的性质和发生时间

1. **到货即坏（签收时或签收后短时间内发现）**
   - 运输途中挤压、摔伤、冷链断链 → 主要由平台/商家承担（商家对交付前的商品质量负责）。
   - 采摘时已内伤、成熟度过高、未做分级 → 商家/供应商责任。

2. **签收后过一段时间才坏**
   - 正常生理成熟（如香蕉、芒果后熟）→ 一般不算坏果，看商家是否提前告知。
   - 储存不当（顾客未冷藏、闷在塑料袋里）→ 顾客责任为主。
   - 但若商家未标注储存方式或标注不清 → 商家承担部分责任。

3. **个别坏果 vs 大面积坏果**
   - 少量（如1-2个）通常按"坏果包赔/按比例赔付"处理，属商家售后范围。
   - 大面积腐烂、发霉、异味 → 优先怀疑批次质量或冷链问题，商家责任重。

## 二、按主体划分

| 情形 | 主要责任方 |
|---|---|
| 运输破损、冷链失效 | 平台/商家（可向物流追偿，但不转嫁给顾客） |
| 货源本身质量差（内伤、过熟、霉变） | 商家/供应商 |
| 商品详情未告知易损、未标注储存条件 | 商家（告知义务缺失） |
| 顾客签收后未按要求储存、放置过久 | 顾客 |
| 顾客自身原因（如要求放门口暴晒数小时） | 顾客，商家可减责 |
| 无法判断原因 | 一般由商家先行赔付，再内部追责（对顾客有利原则） |

## 三、实操建议

**对商家/平台：**
- 建立"坏果包赔"规则并明确时限（如签收24/48小时内凭照片申请），规则要写进商品页。
- 要求顾客提供坏果照片、外包装、快递单，便于判断环节。
- 少量坏果按比例退款或补发；大面积坏果全额退或重发，并追溯批次和物流。
- 保留发货前质检、冷链记录，用于向供应商或物流追偿。

**对顾客：**
- 签收时当场验货，拍照留证（坏果+包装+面单）。
- 按商品要求储存，尽快申请售后，别拖过时限。
- 主张依据：《消费者权益保护法》下商家对交付商品质量负责；生鲜易腐不等于免责。

## 四、一句话结论

**交付前的问题（运输、货源、冷链、告知缺失）由商家/平台负责；交付后因顾客储存不当造成的坏果由顾客负责；原因不明时商家先行赔付再内部追责。** 具体比例看坏果数量、时间和证据，规则应事先在商品页写清。
