建议按“降低损耗 + 让顾客有参与感”来组合，而不是三选一：

1. **主推整果自选**  
   菠萝单价不高、顾客喜欢看外观和闻香味，整果自选能减少“切开后不甜”的纠纷。陈列时标明品种、甜度、产地和价格，旁边放“教你怎么挑”的小提示。

2. **保留少量去皮整果或切块**  
   给赶时间、不会削皮、买来马上吃的顾客。去皮果要冷藏展示、当天处理、明确标注“建议当日食用”，并适当加价覆盖人工和损耗。

3. **不建议大量提前去皮**  
   菠萝去皮后氧化快、出水、卖相差，损耗和客诉都高。可以现场代削皮：顾客挑整果，付款后免费或低价代削，既保新鲜又提升体验。

4. **可以设“试吃 + 帮挑”**  
   高峰期安排店员帮顾客挑，切一小块试吃。比让顾客完全自己挑更容易成交，也能减少挑坏果。

**结论：以整果自选为主，现场代削为辅，少量去皮/切块做便利补充。** 关键是别把去皮果做成常规库存，只做即时消费和引流。
