开团购前，先把供应商按“能不能支撑你稳定履约”来筛，重点看这些服务：

1. **稳定供货与分级**
   - 能否按你的团购量稳定供货，临时加单/减单是否灵活。
   - 能否按大小、甜度、成熟度分级报价，避免同一团里品质参差。
   - 是否支持“预售锁货”，避免今天有明天没。

2. **少量多批次配送**
   - 能否每天或隔天送到店/自提点，而不是一次压大量货。
   - 是否支持按团购截单时间分段配送。
   - 配送是否含卸货、码货，迟到或漏送怎么处理。

3. **售后与损耗分担**
   - 坏果、烂果、重量不足、规格不符的赔付标准要写清。
   - 是否支持拍照报损、按比例补货/退款。
   - 生鲜易损耗品最好谈“损耗包赔比例”或售后额度，别只口头承诺。

4. **包装与分装支持**
   - 能否按团购份量预包装，贴品名/规格/日期标签。
   - 是否提供保温箱、冰袋、周转筐等，或支持押金借用。
   - 自提点分拣是否需要你人工再做，最好让供应商按团单分好。

5. **价格与账期**
   - 团购价是否含配送、包装、损耗。
   - 是否支持周结/月结或押金模式，避免全部现结压现金流。
   - 调价机制要明确：节假日、天气波动时提前多久通知。

6. **品控与检测**
   - 能否提供产地/批次信息，农残检测或合格证明。
   - 是否接受你定期抽检，出现批量质量问题如何召回和补偿。

7. **促销与新品支持**
   - 是否给团购专属价、试吃装、爆品支持。
   - 能否配合做“今日到货”“限量秒杀”等素材图。

8. **退换货与应急**
   - 缺货时能否同价替换或及时通知。
   - 出现食品安全问题时的责任划分和响应时限。

建议你先用**小批量试团**验证：连续试 2–4 周，重点记录到货准时率、坏果率、售后响应速度、加单成功率。合同或聊天记录里至少写清：规格、单价、配送时间、售后赔付、调价通知、缺货处理。供应商能满足“稳定少量配送 + 明确售后 + 可分装”这三条，附近小区团购才容易做稳。
