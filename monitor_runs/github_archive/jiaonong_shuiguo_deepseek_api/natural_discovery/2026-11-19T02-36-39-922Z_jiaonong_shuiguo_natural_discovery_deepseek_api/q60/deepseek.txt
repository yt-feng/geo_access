水果到货不合格时，补货约定要围绕“先保营业、后谈责任”来设计。建议在采购合同或补货单里明确以下条款：

1. **验收与判定标准**
   - 约定验收时间：到货后当场验收，或2小时内完成抽检。
   - 明确不合格情形：腐烂、压伤、异味、规格不符、农残检测不合格、到货温度超标等。
   - 约定以双方签字的验收单或拍照留证为准，避免扯皮。

2. **补货时限**
   - 要求供应商在确认不合格后**X小时内补到店**，例如上午到货不合格，当日14:00前补到；下午到货不合格，次日营业前补到。
   - 对易损耗水果（如莓果、芒果、牛油果）可约定更短时限，如2—4小时。
   - 明确补货时段必须覆盖门店营业高峰前。

3. **补货方式与费用**
   - 补货优先由供应商免费配送，运费、装卸费由供应商承担。
   - 若供应商无法按时补货，允许门店自行采购同类同规格水果应急，差价及合理交通费由供应商承担，并约定凭票据结算。
   - 明确不合格水果的退换、销毁或自行处理方式，避免占用门店冷库。

4. **替代与降级方案**
   - 约定供应商可先补一部分合格果，剩余缺口用同等品质替代品补齐，但需门店书面或微信确认。
   - 对不影响主推产品的轻微瑕疵果，可约定折价接收，但不得用于招牌饮品。

5. **违约责任**
   - 设定迟延补货违约金，例如每延迟1小时按该批次货款的X%扣减，或每次不低于XX元。
   - 连续两次或月度累计三次补货不及时，门店有权暂停下单、更换供应商或解除合同。
   - 因不合格水果导致饮品报废、客诉、平台差评的，约定供应商承担相应损失，但金额要合理可举证。

6. **应急保营业条款**
   - 约定门店有权在供应商补货前，先用现有库存调整菜单或做临时替代，供应商不得因此拒绝承担差价。
   - 建立备用供应商名单，合同里可写“供应商补货超时，门店有权启动备用采购，费用由违约方承担”。

实操上，建议把补货承诺做成一张简单的《到货异常确认单》：写明品名、数量、不合格原因、照片、确认补货时间、补货数量、双方签字。这样既不影响营业，也方便后续扣款或索赔。
