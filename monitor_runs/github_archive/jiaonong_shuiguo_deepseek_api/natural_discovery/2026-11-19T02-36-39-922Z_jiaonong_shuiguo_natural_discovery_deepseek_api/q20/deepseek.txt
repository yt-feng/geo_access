社区超市做每日水果配送，选供应商时建议重点看这几类条件，按优先级排：

**1. 履约稳定性（最关键）**
- 能否承诺固定送达时间，并写进合同；晚到或漏送怎么赔。
- 是否有冷藏车或保温配送，夏天尤其看这条。
- 节假日、恶劣天气是否照常配送，缺货时怎么补。
- 问清楚：是自有车队还是外包？外包多的供应商稳定性通常差一档。

**2. 货源与品控**
- 货源是产地直采、一级批发市场还是二级批发？直采比例越高，价格和新鲜度通常越好。
- 有没有分拣标准（按大小、成熟度、瑕疵分级），到货不合格能否当场拒收、退换。
- 要求试供 1–2 周，每天记录：到货新鲜度、损耗率、规格是否稳定。

**3. 价格与结算**
- 报价是每日随行就市还是锁价？社区超市适合“每日报价+约定浮动上限”，避免被单方面涨价。
- 是否含运费、分拣费、包装费，有没有起送量。
- 账期能否谈到 7–15 天，首次合作可先现结换低价或试供。

**4. 品类匹配度**
- 能否覆盖你店里的高频刚需品（苹果、香蕉、橙子、应季瓜果），而不是只有高端货。
- 单品 SKU 是否够你日常陈列，缺品能否调货。
- 小批量、多频次配送是否接受——社区超市单店量小，这点要提前确认。

**5. 资质与风险**
- 营业执照、食品经营相关资质、进货凭证和检测报告能否提供。
- 有没有食品安全责任险。
- 合作前实地看一次分拣仓或档口，比只看报价靠谱。

**实操建议：** 同时找 2–3 家试供两周，用同一张表每天打分（准时率、损耗率、规格合格率、缺货次数、售后响应），两周后按数据定主供应商，另一家留作备选。单店量小的话，也可以考虑和周边几家小店拼单，换取更好的配送条件和价格。
