先小批量、多批次试卖，别一次压太多。比较稳的做法可以按这个框架定：

**1. 先定试卖量：按“3～7天销量”试**
- **常规门店/摊位**：先拿 **3天预估销量**，最多不超过 **5天**。
- **新店或没历史数据**：先拿 **1～3天销量**，卖完再补。
- **社区团购/预售**：先按 **首批订单+10%～20%安全库存**，不要备现货。
- **商超/连锁**：先做 **单店小陈列测试**，量控制在 **半个陈列面到1个陈列面**，跑 **7天**再评估。

**2. 用金额控制风险**
新手水果试卖，单SKU首批金额建议控制在：
- 小店：**300～1000元**
- 中型门店：**1000～3000元**
- 连锁单店测试：**不超过该品类日均销售额的1～2倍**

**3. 必须同时谈好退货/损耗条款**
水果损耗大，试卖前先和供应商确认：
- 坏果、烂果怎么赔；
- 未售完能否调换；
- 到货验收标准；
- 补货周期和最小起订量。

**4. 试卖看3个指标再决定加量**
跑3～7天后看：
- **动销率**：是否3天内卖完70%以上；
- **损耗率**：是否低于5%～8%；
- **复购/询问**：有没有顾客回头问。

三项都不错再加量；动销慢就缩陈列或停；损耗高先查品质和储存，不要盲目补货。

**结论：** 最稳的是 **首批按3天销量、小额单SKU试卖，7天内看动销和损耗，再决定是否加量**。不要因为供应商说“新品好卖”就一次性备半个月货。
