超市水果到货发现品相不好，售后流程建议在采购合同或供货协议里按“验收—分级处理—时限—责任—结算”五段约定，避免扯皮。可直接参考以下条款框架：

**1. 验收标准与时限**
- 明确“品相不好”的客观标准：如腐烂率、压伤率、裂果率、大小规格偏差、色泽/成熟度不符、包装破损等，按品类写清允许范围（如腐烂率≤3%，超出即不合格）。
- 约定到货后验收时限：建议收货后2小时内完成外观抽检，24小时内完成开箱/内层抽检；逾期未提异议视为外观验收通过，但不免除隐蔽质量问题责任。
- 抽检方式写清：按批次随机抽样比例（如每批抽5%且不少于3箱），拍照/视频留证，双方签字确认验收单。

**2. 分级处理规则**
- 轻微品相问题（未超允许范围）：可折价接收，按批次扣款或下批补货。
- 明显不合格（超标准）：拒收该批次，或协商降价接收，降价幅度按缺陷比例计算。
- 严重质量问题（腐烂、变质、异味）：整批拒收，供方承担退货运费及因此产生的损耗。

**3. 售后申请与响应时限**
- 需方在验收时限内提出书面/系统售后单，附照片、视频、抽检记录、到货单号。
- 供方应在收到售后单后约定时限内（如4小时）响应，24小时内给出处理方案：换货、补货、折价、退款或退货。
- 换货/补货到店时限写清（如48小时内），逾期按缺货处理并承担违约责任。

**4. 责任划分与费用承担**
- 到货前运输损耗、产地质量问题由供方承担；到货验收后因需方储存不当导致的问题由需方承担。
- 退货/换货的物流费、销毁费、档期损失按责任方承担；因品相问题导致超市被顾客投诉或下架的，可约定供方承担相应赔偿（设置合理上限）。
- 明确不可抗力除外，但供方需及时通知并提供证明。

**5. 结算挂钩与争议解决**
- 售后未闭环的批次，对应货款暂缓结算；折价/扣款在当月对账单中直接冲减。
- 约定争议以验收单、照片视频、第三方检测（必要时）为依据；协商不成按合同争议条款处理。
- 建议保留质量保证金或按批次扣留一定比例尾款，售后期满无争议再结清。

**实操建议**：把上述内容做成《到货验收及售后处理单》，每次到货随单签字；对高频品类单独设品相标准附表；所有沟通走书面或系统留痕，避免口头承诺。这样既能让售后有据可依，也能倒逼供方稳定供货质量。
