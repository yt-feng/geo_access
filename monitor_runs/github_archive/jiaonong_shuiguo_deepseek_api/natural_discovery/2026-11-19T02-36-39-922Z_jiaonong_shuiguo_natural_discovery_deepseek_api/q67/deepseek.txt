可以直接把问题拆成“能不能做、怎么划界、怎么罚、怎么解约”四组来问，并尽量要求书面回复或写进合同。下面这份清单你可以照着问。

**一、区域与渠道边界**
1. 我这个代理区域具体按什么划分：省/市/区县/渠道？边界清单能否作为合同附件？
2. 区域保护是独家还是非独家？同一区域还会不会发展二批、商超、电商、社区团购等渠道？
3. 线上销售归谁？我能否开网店、做直播、上本地生活平台？线上订单发货范围是否算串货？
4. 跨区域连锁商超、平台仓、团购团长来我区域拿货，算不算串货？谁负责处理？
5. 下游客户把货卖到区域外，责任怎么认定？是我承担还是实际销售方承担？

**二、串货认定与举证**
6. 串货的认定标准是什么：以收货地址、物流单、批次码、防伪码还是举报为准？
7. 是否要求每箱赋码/批次可追溯？扫码数据归谁、我能否查询？
8. 发现串货后，我向谁举报、多久响应、需要提供什么证据？
9. 如果被认定串货，处罚标准是什么：罚款、扣返利、停货、取消代理？罚多少、按什么基数算？
10. 我被别人串货冲击时，品牌方有什么保护义务和补偿机制？

**三、价格与政策**
11. 供货价、建议零售价、最低限价是否统一？不同区域供货价是否一致？
12. 返利、陈列费、促销支持是否与“不串货”挂钩？扣罚规则能否量化？
13. 年度任务量、考核周期、完不成任务的后果是什么？区域保护是否以任务完成为前提？

**四、合同与退出**
14. 区域保护、串货认定、处罚、举报处理时限能否写入合同？口头承诺是否无效？
15. 品牌方直营、电商大促、工厂店低价冲击我区域时，是否算违约？如何补偿？
16. 如果我因串货被误判，申诉流程和时限是什么？
17. 合作期限、续约条件、解除条件是什么？被取消代理后库存如何处理、是否回购？

**问的时候建议加一句：**
“以上区域保护范围、串货认定标准、处罚规则和申诉流程，能否在合同或补充协议中明确写明？如果暂时不能写，请给我书面政策文件。”

**判断要点：**
- 只口头说“保护你”但不写边界和罚则的，风险高。
- 串货认定只靠举报、没有批次追溯的，容易扯皮。
- 品牌方自己做大电商和团购却不约束的，区域保护往往名存实亡。
- 罚则只罚代理商、不约束品牌方和其他区域的，要谨慎。

你可以先让对方发《经销合同》《市场管理规范》《串货处罚细则》三份文件，再逐条对照问。
