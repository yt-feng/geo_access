选择下午茶水果供应商，重点看“批量配送稳定性”和“损耗控制”，建议按下面几步筛选：

**1. 先定采购标准，再找供应商**
- 明确人数、预算/人、配送频次、配送时间窗口。
- 定水果结构：2–3种易分发水果为主（香蕉、橘子、小番茄、葡萄、切盒西瓜），少用易压伤/需现场处理的（草莓、芒果整果、榴莲）。
- 要求供应商能提供“按份分装”或“果切盒”，减少现场分发和损耗。

**2. 供应商类型选择**
- **本地水果批发商/配送商**：适合批量、价格低，但需确认是否支持小批量多频次配送和分装。
- **生鲜平台企业购**：流程规范、发票和售后好，价格略高，适合行政省事。
- **连锁水果店/果切店**：适合小批量、高频次，配送灵活，但批量价优势弱。
- **中央厨房/团餐供应商**：适合同时有果切和下午茶其他食品需求，卫生资质较全。

**3. 重点核验资质和履约能力**
- 营业执照、食品经营许可证；做果切的要有相应卫生资质和冷链条件。
- 问清配送车辆是否冷链、到货时间误差范围、破损/坏果赔付规则。
- 要求试单：先小批量配送一次，看准时率、新鲜度、分装质量、发票响应。

**4. 报价要算“到手可用成本”**
不要只比单价，要算：单价 + 配送费 + 分装费 + 损耗率 + 售后赔付。批量配送常见坑是“低价但损耗高、缺斤少两、临时加配送费”。

**5. 合同/订单里写清楚**
- 品种、规格、单份重量、到货时间、验收标准。
- 坏果率上限（如超过5%补送或退款）、缺货替代方案、临时加单截止时间。
- 结算方式和发票类型。

**6. 建议的筛选流程**
找3家：1家本地批发配送、1家生鲜企业购、1家连锁果切店；各试单1次；按“准时率、新鲜度、分装、售后、到手成本”打分；选1家主供+1家备选。

如果公司人数在50人以上、每周固定下午茶，优先找支持“按份分装+冷链配送+月结开票”的本地配送商，比单纯找水果店更稳。
