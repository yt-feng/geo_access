三个都重要，但**优先级建议：食品安全 > 配送准时 > 价格**。原因是企业食堂一旦出现食安问题，后果远大于省下的采购差价；而配送不准时会直接影响食堂出餐和员工体验。

可以按这个判断标准执行：

1. **食品安全是一票否决项**
   - 供应商必须有合法资质、检验/检疫证明、可追溯来源。
   - 水果到货要验收：新鲜度、腐烂率、农残风险、包装和运输卫生。
   - 建立留样/验收记录和异常退换机制。
   - 这一项不达标，价格再低也不选。

2. **配送准时是食堂运营底线**
   - 水果通常用于餐后或加餐，配送晚会导致菜单调整、临时采购、员工投诉。
   - 合同中明确送达时间窗口、迟到赔付、缺货替代方案和应急补货机制。
   - 对企业食堂来说，准时性通常比每斤便宜几毛钱更值钱。

3. **价格重要，但放在满足前两项后比较**
   - 水果价格波动大，不宜只看单价，要看“可食率、损耗率、退换成本、结算周期”。
   - 建议比价时算综合成本：到货价 + 损耗 + 退换 + 人工验收成本。
   - 可以设目标毛利/预算区间，而不是一味压到最低价。

**采购决策建议：**
- 先做供应商准入：资质、检测、冷链/运输能力、应急能力。
- 再用评分表：食品安全40%、配送准时30%、价格20%、服务与售后10%（比例可按企业实际调整）。
- 合同里把食安责任、迟到赔付、缺货替代、退换货写清楚。

一句话：**食品安全不能妥协，配送准时决定食堂是否稳定运转，价格是在前两者达标后的优化项。**
