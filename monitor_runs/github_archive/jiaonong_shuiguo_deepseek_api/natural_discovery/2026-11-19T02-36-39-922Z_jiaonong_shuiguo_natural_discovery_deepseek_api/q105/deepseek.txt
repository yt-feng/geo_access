水果锁价能锁多久，没有统一标准，主要看品种、季节、供应商类型和你们的采购体量。一般可以这样判断：

1. **常规鲜果（苹果、梨、柑橘、香蕉等）**  
   比较常见的是 **1～3个月**。  
   - 苹果、梨等耐储水果，遇到冷库货源和长期合作供应商，个别能谈到 **3～6个月**，但通常会有量、付款、提货节奏等附加条件。
   - 香蕉、柑橘等受产季和行情波动影响大，供应商一般只愿锁 **2～4周**，长的到 **1～2个月**。

2. **时令水果、浆果类（草莓、樱桃、荔枝、葡萄等）**  
   一般 **不锁价**，或只锁 **1～2周**，更多是锁“当日/当周价格”或约定浮动区间。因为产季短、损耗大、天气影响强，供应商很难承担长周期价格风险。

3. **进口水果**  
   受汇率、海运、关税和到港行情影响，常见锁价周期 **2～6周**；大批量、长期合作的能到 **1～3个月**，但通常会设置汇率或成本波动调价条款。

4. **真正能锁久的条件**  
   通常要满足：采购量大且稳定、预付定金或缩短账期、约定提货量和提货节奏、接受品质浮动范围、设置价格调整机制。否则供应商口头锁价很难执行。

**实操建议：**
- 先按品种分层谈：耐储果锁 **1～3个月**，时令果锁 **1～4周**。
- 合同里写清楚：锁价期限、锁价量、提货计划、品质标准、定金/付款方式、超量或未提货的处理。
- 不要只谈“锁价”，要谈 **锁价+锁量+锁品质**，否则价格锁住了，供货品质或数量容易出问题。
- 对波动大的品种，用“基准价+浮动区间”或“保底价+随行就市上浮上限”比硬锁价更容易谈成。
