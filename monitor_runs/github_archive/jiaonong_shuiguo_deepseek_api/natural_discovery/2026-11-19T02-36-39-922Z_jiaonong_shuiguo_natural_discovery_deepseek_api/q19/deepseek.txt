优先看**切果损耗（出肉率/坏心率）**，其次甜度；大小和外观只作为分档定价和陈列参考。原因很简单：超市卖菠萝是毛利生意，损耗和可售部分直接决定赚不赚钱。

可执行判断顺序：

1. **切果损耗优先**
   - 看：去皮去眼后的出肉率、黑心/水心/烂心比例、尾部是否发软、切口是否褐变。
   - 建议：同批次抽切3—5个，记录出肉率和坏心率。坏心率高、出肉率低的批次，哪怕外观好也别主推。
   - 因为菠萝有“外表好、里面黑心”的风险，损耗是最大隐性成本。

2. **甜度第二**
   - 看：香气是否足、果眼是否平、底部是否有甜香；有条件用糖度计抽测。
   - 建议：按糖度分“鲜食甜果”和“加工/促销果”，不要混价卖。
   - 甜度决定复购和差评，但不如损耗直接伤利润。

3. **外观第三**
   - 看：果形端正、果眼浅、无机械伤、冠芽新鲜、无霉斑。
   - 外观主要用于陈列和分级，不能替代切开抽检。

4. **大小最后**
   - 大小影响定价和客群：家庭装偏中等，促销可做大果，鲜切可接受大果。
   - 不要为“大”牺牲出肉率和甜度。

**采购决策建议：**
- 先定损耗红线：比如抽切坏心率超过一定比例就拒收或压价。
- 再定甜度分级：甜度达标做主推，不达标走促销/鲜切。
- 外观做陈列分级，大小做价格带。
- 如果只能关注一个指标：**关注切果损耗**，它最接近真实毛利。
