没有一刀切的答案，关键看你**货源稳定性、客户结构、资金与库存能力**。给你一个可执行的判断框架。

## 先判断：你属于哪种批发商

| 特征 | 更适合每天议价 | 更适合签一段时间价格 |
|---|---|---|
| 货源 | 产地分散、靠市场代卖/临时调货 | 有稳定产地基地或长期供应商 |
| 客户 | 散客、小商贩、临时单多 | 超市、连锁水果店、食堂、电商仓 |
| 品类 | 叶菜类、时令强、易腐、价格日变 | 苹果、梨、柑橘、土豆等耐储品类 |
| 资金/库存 | 资金紧、不敢压货 | 有冷库、能承受短期库存 |
| 风险承受 | 能快速跟价、反应快 | 更怕客户流失和现金流波动 |

## 实务建议：多数批发商用“混合策略”

1. **核心客户锁价，散客随行就市**
   - 对超市、连锁店、长期大客户，签 **7～15天** 的框架价，约定“随产地价浮动超过±8%～10%可重新议价”。
   - 对散客和小商贩，每天按市场价报。

2. **耐储品类适当锁价，易腐时令品尽量日议**
   - 苹果、梨、柑橘、根茎类：可锁 **2～4周**。
   - 叶菜、草莓、荔枝、水蜜桃等：以 **1～3天** 或当日价为主，避免赌行情。

3. **锁价必须带“浮动条款”**
   不要签死固定价。建议写清：
   - 基准价 + 随产地/批发市场均价浮动；
   - 单日涨跌超过约定幅度可重议；
   - 最低采购量、付款账期、质量标准、损耗承担。

4. **每天议价不等于每天赌价**
   每天议价的核心是**快进快出、低库存**。你要做到：
   - 每天记录产地价、市场批发价、你的成交价；
   - 库存周转控制在 **1～3天**；
   - 不因“明天可能涨”而大量压货，除非你有冷库和稳定下游。

5. **签一段时间价格的核心是换稳定**
   锁价会让利一部分给客户，换取：
   - 稳定销量；
   - 减少每天谈判成本；
   - 降低客户被同行抢走的风险。
   但锁价比例建议控制在总销量的 **30%～60%**，不要全部锁死。

## 一个简单决策规则

- **今天能卖完、货源天天变** → 每天议价。
- **客户要长期稳定、品类耐储** → 签7～30天，但带浮动条款。
- **价格波动剧烈（单周涨跌超15%）** → 缩短锁价周期到3～7天，或改为“保底价+浮动”。
- **你库存超过3天销量** → 不要再追涨锁价，优先出货。

**结论：** 不要二选一。建议 **“大客户短锁价 + 散客日议价 + 耐储品类适度锁价 + 易腐品类快进快出”**，锁价合同必须带价格浮动和重议条款。这样既不被日议价拖死，也不被长锁价赌死。
