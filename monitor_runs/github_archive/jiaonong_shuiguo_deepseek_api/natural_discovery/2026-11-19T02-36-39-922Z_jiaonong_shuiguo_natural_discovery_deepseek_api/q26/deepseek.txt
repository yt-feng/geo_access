社区超市卖小包装香蕉，采购时重点抓“包装规格是否适配门店客流”和“香蕉后熟损耗是否可控”两件事。建议按下面清单判断和执行。

**一、包装规格**
1. 优先选**单根/2-3根小包装**，而不是整串再门店分装。社区超市客流小、购买频次高，小包装能减少顾客翻拣和整串买走后剩余蕉的损伤。
2. 包装重量按门店主力客群定：单人/小家庭多，选**300-500克/袋**；家庭客多可设500-800克/袋。不要盲目上大袋。
3. 包装材质要**透气、不闷水**：优先打孔PE袋、网袋或透气膜，避免全密封袋内结露，结露会加速黑斑和柄部霉变。
4. 袋上留**通气孔和可视窗口**，但孔不要大到掉蕉、压伤。标签贴在不压果肉的位置。
5. 采购时确认包装是否**耐搬运**：提手袋、封口强度、底部承重。社区店补货频繁，包装破袋是隐性损耗。
6. 包装标识要写清**品种、规格、产地/供应商、包装日期**，便于先进先出和追溯。

**二、采购时的香蕉状态**
1. 不要采购已经全黄、香气浓的香蕉做小包装，运输和上架会迅速过熟。选**微黄带绿、果指饱满、棱角略圆**的货。
2. 按门店周转定成熟度：日销快可选稍黄；日销慢选偏绿，到店后自然转黄。
3. 检查**蕉柄切口、果指连接处**。柄部发黑、发霉、流汁的不要，小包装里一根坏蕉会污染整袋。
4. 避免**机械伤**：压痕、擦伤、裂果、果皮水浸状。小包装会放大外观瑕疵，顾客挑拣后剩余就是损耗。
5. 问清供应商**催熟批次和到货成熟度**，不同批次不要混装混放，否则黄绿不均、难以统一上架。

**三、损耗控制**
1. 采购量按**日均销量×1.5-2天**控制，社区店不宜一次压太多货。香蕉后熟快，库存天数越长损耗越高。
2. 到店后**拆箱透气、分级**：黄度高的先上架或做促销，偏绿的放阴凉通风处后熟。不要整箱闷着。
3. 小包装**现包现上**，不要提前大量包好。包好后袋内湿度高，久放易柄腐、黑斑。
4. 上架陈列**单层或少量叠放**，避免重压；远离冷柜出风口和阳光直射。香蕉怕冷，不要进冷藏。
5. 每天**挑出黑斑严重、软烂、柄腐**的单根，及时折价或下架，避免污染同袋。可设“熟蕉特价袋”减少报损。
6. 记录**到货量、上架量、折价量、报损量**，连续一周就能算出合理采购规格和日订货量。

**四、采购合同/验收要点**
- 明确**包装规格、每袋根数/重量、允许破损率**，比如破袋率、柄腐率、机械伤率上限。
- 约定**到货成熟度和批次一致性**，不合格可拒收或折价。
- 要求供应商**按小包装或可门店分装的形式供货**，减少二次分装伤果。
- 验收时抽检**袋内结露、封口、通气孔、果指状态**，不要只看外箱。

**优先执行顺序：**先定小包装规格和日订货量 → 再选透气包装 → 验收时严控成熟度和机械伤 → 到店分级、现包现上、每日挑损。这样比单纯压低采购价更能降损耗。
