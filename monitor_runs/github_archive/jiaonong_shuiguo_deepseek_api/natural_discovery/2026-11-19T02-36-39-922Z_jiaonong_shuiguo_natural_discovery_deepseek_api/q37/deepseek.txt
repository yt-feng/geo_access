商超会员日水果活动，供应商要提前配合的重点不是“多送几箱货”，而是把**货、价、质、陈列、补货、售后、风险**七件事锁死。建议按时间倒排准备：

**一、活动前7—10天：锁需求与锁价**
- 与商超确认活动时间、门店范围、会员价/折扣机制、预估销量、主推单品和引流单品。
- 明确供货价、促销让利承担方式、损耗和滞销处理、退货换货规则，避免活动后扯皮。
- 按门店分解备货量，预留10%—20%安全库存；易损高价水果不宜盲目压货。

**二、活动前5—7天：锁品质标准**
- 按商超验收标准提前分级，明确果径、糖度、成熟度、外观、包装规格。
- 准备试吃样品和质检/产地相关证明，商超需要的话提前报备。
- 对活动主推品做一次到货模拟验收，发现容易退货的批次提前换货。

**三、活动前3—5天：锁到货与补货**
- 确认各门店送货时间窗口、卸货口、验收人员、冷链或常温运输要求。
- 制定活动首日“开门前到货”和活动中“日补货/半日补货”计划，明确补货触发线，如库存低于安全库存或动销超预期。
- 安排专人对接商超采购和门店生鲜主管，活动期间保持电话畅通。

**四、活动前1—3天：锁陈列与物料**
- 配合商超确定堆头、端架、冷藏柜位置，提供价签信息、产地卖点、试吃物料、包装袋/盒、陈列道具。
- 主推品和引流品分开陈列，避免互相挤占；易压伤水果控制堆高。
- 提前培训或安排驻店/巡店人员，负责补货、挑拣、试吃和鲜度维护。

**五、活动前1天：锁货与应急**
- 确认首批货已到店或已在途，重点门店可提前铺货。
- 准备应急预案：爆量缺货、到货品质不达标、冷链中断、门店临时加单、活动价执行错误。
- 明确售后响应时限，比如门店反馈质量问题后几小时内换货或折价处理。

**六、活动中：锁执行**
- 每日跟进销量、库存、损耗、缺货和客诉；高动销门店增加巡店频次。
- 及时挑出软伤、压伤、过熟果，做折价或试吃处理，避免影响整堆形象。
- 不擅自改价、改规格、改包装；所有变更走商超采购确认。

**七、活动后：锁结算与复盘**
- 核对实际到货、退货、损耗、促销让利和结算数量。
- 复盘动销率、缺货率、损耗率、客诉率，形成下次会员日备货和选品建议。

一句话判断供应商是否准备到位：**活动前能说清每个门店送多少、什么时候送、什么标准、谁对接、缺货怎么办、质量出问题谁多快处理。** 这六项都有明确答案，才算配合到位。
