家庭场景优先考虑“好吃、耐放、一家人一顿能吃完、成本别浪费”。建议做 **2个主打组合 + 1个高端组合**，不要所有水果平均混装。

### 推荐组合

**1. 日常家庭装：苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个**
- 适合3—5口之家，水果种类全，价格好控制。
- 苹果、橙子耐放；香蕉和菠萝负责“马上吃”的香气和新鲜感。
- 注意香蕉不要和苹果、橙子混在一个袋里，乙烯会催熟，最好分格或分袋。

**2. 耐放实惠装：苹果6个 + 橙子6个 + 菠萝1个，香蕉单独小把**
- 适合一次买一周水果的家庭。
- 苹果、橙子耐储，菠萝可放几天；香蕉少量配，避免发黑浪费。
- 团购文案可写“耐放家庭箱，香蕉单独装”。

**3. 送礼/改善型：苹果4个 + 橙子4个 + 香蕉1把 + 菠萝1个 + 少量提子或猕猴桃**
- 礼盒观感更好，但成本会上升。
- 如果坚持只放这四种，就把苹果、橙子选大果，菠萝选小果，香蕉用独立纸袋，整体更整齐。

### 组合原则
- **比例建议：苹果和橙子占60%—70%，香蕉20%左右，菠萝1个即可。** 菠萝重、占体积，多了不划算。
- **香蕉少放、单独放。** 家庭最怕香蕉一次催熟吃不完。
- **苹果、橙子选耐放品种。** 礼盒里最怕“好看但不耐放”。
- **按家庭人数分档：** 3口之家做小箱，5口之家做大箱；不要只做一个规格。
- **礼盒内部分区：** 苹果橙子一层，菠萝固定角落，香蕉独立袋，避免压伤。

### 不建议
- 不建议四种水果等量混装：菠萝偏重、香蕉易熟，家庭实际体验不好。
- 不建议香蕉和苹果、橙子紧挨着放：会加快香蕉变黑。
- 不建议礼盒里放太多菠萝：占重、占体积，家庭一次也吃不完。

**最稳的家庭团购款：苹果4 + 橙子4 + 香蕉1小把 + 菠萝1个，香蕉独立包装。**
