选规格的核心不是“越大越划算”，而是按**出成率、损耗和出盘比例**算单份成本。给你一套可直接判断的方法：

**1. 先定每盘用量**
建议水果拼盘按可食部分配比：苹果30%、橙子35%、菠萝35%。假设一盘净果肉300g，则：
- 苹果净肉90g
- 橙子净肉105g
- 菠萝净肉105g

**2. 各品种选规格建议**

**苹果**
- 优先选**单果180–220g的中果**。太大切块后边角料多，太小削皮去核后出成率低。
- 餐厅常用**80–85mm果径**较稳；做拼盘不建议追求90mm以上大果，除非整果展示。
- 出成率按75%–80%估。若净肉需90g，毛重约115–120g，即半颗中果左右。
- 采购看：果形端正、无磕碰，磕碰果做拼盘损耗高。

**橙子**
- 选**单果200–250g、果径75–80mm**的中大果，皮薄、易分瓣、汁水适中。
- 太小分瓣碎、出成率低；太大单价高且一瓣过大，摆盘不好控制。
- 出成率按60%–65%估（去皮、去络、去籽）。净肉105g需毛重约165–175g，约大半个橙子。
- 优先选**表皮紧实、无浮皮**的，浮皮果切瓣易烂。

**菠萝**
- 餐厅最划算通常是**单果1.2–1.5kg的中等果**，不要盲目选2kg以上大果：大果芯粗、边角多，切块规格不匀。
- 若用量稳定，直接买**已去皮菠萝/菠萝块**更省人工，但要比较净重单价：用“毛重单价÷出成率”换算。
- 菠萝出成率约50%–60%（去皮、去眼、去芯）。净肉105g需毛重约180–210g。
- 选果看：果眼浅、香气足、无黑心；过熟果切盘易出水。

**3. 最划算的判断公式**
统一按**可食净重成本**比较：
> 净重成本 = 采购毛重单价 ÷ 出成率

例如菠萝毛重8元/kg、出成率55%，净重成本约14.5元/kg；去皮菠萝若18元/kg，则毛果更划算。苹果、橙子同样算。

**4. 餐厅实操建议**
- 固定**单盘净重和切块数**，再倒推采购规格，避免员工随手切导致每盘成本波动。
- 苹果、橙子选**中果**，菠萝选**1.2–1.5kg中果**，通常是拼盘场景的平衡点。
- 如果只做拼盘、不做整果展示，优先买**规格均匀的中果**，比大果更划算、出品更稳定。
- 每周按实际出成率复盘一次：记录毛重、净重、废料重量，连续两周就能定出你家最划算的规格。
