大型超市对水果供应商的要求，实质上是“食品安全合规能力+冷链物流稳定性+可追溯与召回能力+持续供货能力”的组合。可按以下清单判断一家供应商是否合格。

## 一、食品安全能力

**1. 主体资质与合规文件**
- 营业执照、食品经营许可证/食品生产许可证（按业态）。
- 供货品种的产地证明、检测报告；进口水果需报关单、入境货物检验检疫证明。
- 农药残留检测能力或与第三方检测机构稳定合作，能按批次提供检测报告。
- 包装材料符合食品接触材料要求，有相应检测或合规声明。

**2. 源头与种植管理**
- 基地备案或稳定合作基地，能说明产地、品种、采收期。
- 农业投入品管理：农药、化肥采购和使用记录，安全间隔期执行。
- 有农残自检或委托检测制度，重点品种批批检测或高频抽检。
- 重金属、霉菌毒素等风险品种有针对性控制。

**3. 采收与初加工卫生**
- 采收工具、周转筐清洁消毒，避免落地污染。
- 分级包装场所防蝇防鼠防尘，人员健康证和卫生操作规范。
- 清洗用水符合生活饮用水标准；打蜡、保鲜剂使用符合国家标准并有记录。

**4. 仓储与运输卫生**
- 仓库防虫防鼠、温湿度控制、先进先出。
- 不与有毒有害物品混存混运；运输车辆清洁、消毒记录。
- 冷链品种全程温控，有温度记录可查。

**5. 追溯与召回**
- 能实现“批次—基地/供应商—采收日期—检测结果—发货去向”的追溯。
- 有不合格品隔离、下架、召回流程和演练记录。
- 能配合超市做供应商审核、飞行检查、抽检不合格处置。

**6. 食品安全管理体系**
- 建议具备ISO 22000、HACCP或类似体系；至少有一套成文的卫生标准操作程序和关键控制点管理。
- 有食品安全责任人、员工培训记录、投诉与事故处理记录。

## 二、物流与供应链能力

**1. 冷链能力**
- 预冷：采后快速预冷设施，缩短田间热。
- 冷藏仓储：按品种分温区储存，温湿度监控和报警。
- 冷链运输：冷藏车/保温车，实时温度记录，装卸货环节不断链。
- 对易损品种（浆果、荔枝、车厘子等）有专门包装和温控方案。

**2. 仓配与履约**
- 有分拣、分级、包装能力，能按超市标准做规格化和标准化。
- 订单履约稳定：准时率、缺货率、破损率可量化。
- 配送频次和窗口能匹配超市日配/隔日配要求，节假日和促销期有保供预案。

**3. 库存与损耗管理**
- 先进先出、批次管理，临近保质期预警。
- 损耗率控制能力和数据记录，能配合超市做库存周转。
- 异常天气、交通管制、产地减产时有替代产地或备选物流方案。

**4. 信息化与单据**
- 订单、发货、温控、检测报告等单据电子化，能与超市系统对接或按要求提供。
- 每批次可提供送货单、检测报告、产地信息，做到票货同行。

## 三、快速判断标准

超市采购或审核时，可重点看四项硬指标：
1. **证照和检测报告是否齐全、是否按批次提供。**
2. **是否有真实可运行的追溯和召回记录，而不只是文件。**
3. **冷链是否全程有温度记录，装卸环节是否断链。**
4. **准时交付率、破损率、抽检合格率是否有连续数据。**

如果供应商只能提供资质文件，但拿不出批次检测、温控记录和追溯台账，通常不适合作为大型超市的核心水果供应商。
