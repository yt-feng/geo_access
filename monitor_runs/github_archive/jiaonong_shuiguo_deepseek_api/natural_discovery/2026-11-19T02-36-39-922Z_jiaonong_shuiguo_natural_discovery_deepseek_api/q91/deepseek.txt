建议优先上架 **单根 + 小把**，整袋作为补充，不要一上来只做整袋。

**推荐组合**
1. **单根：必上**
   - 适合便利店“即买即吃”场景，冲动购买率高。
   - 定价低、决策门槛低，能带动客流。
   - 适合放在收银台附近或门店入口小货架。

2. **小把（3—5根）：主力**
   - 适合家庭临时补货、办公室分享。
   - 客单价高于单根，损耗比整袋可控。
   - 建议按“3根/4根/5根”中选一种，不要规格太多。

3. **整袋：谨慎上，作为补充**
   - 适合社区型便利店、家庭客群明显的门店。
   - 整袋成熟度难控，损耗和滞销风险最高。
   - 若上架，建议小规格、低库存、可拆袋销售。

**判断建议**
- **写字楼/商圈店**：单根为主，小把少量。
- **社区/住宅店**：小把为主，单根和整袋少量。
- **学校/车站/医院**：单根优先。
- **冷链和鲜度管理弱**：先只做单根和小把，暂不上整袋。

**执行上注意**
- 香蕉成熟度分批：单根放稍熟、可立即吃的；小把放略生一点的。
- 单根容易掉柄、卖相变差，可用小标签或托盘陈列。
- 先试销1—2周，看“单根销量、小把销量、损耗率、整袋滞销率”再调整。
- 如果只能选一个：**选小把**；如果能选两个：**单根 + 小把**。
