坏果率没有全国统一的法定赔付线，关键看合同约定和验收环节。可执行建议如下：

1. **合同里优先写“分级验收+阶梯赔付”**
   不建议只写一个“超过X%就赔”，而要写清楚：
   - 抽样方法：到货后按箱/批次随机抽检，比如每批抽5%且不少于10箱；
   - 坏果定义：霉变、腐烂、严重压伤、虫蛀、异味、非品种特性畸形等，最好配图片标准；
   - 计算口径：按重量还是按个数；是“单箱坏果率”还是“整批加权坏果率”；
   - 免赔容忍度：行业常见做法是设 **1%—3%的合理损耗免赔**，超过部分再赔，但这不是法定标准，需双方谈定；
   - 赔付阶梯：例如超过3%后，按超出部分货值赔付；超过5%可拒收该批次或要求整批折价；超过10%可退货并索赔运费、冷藏费等直接损失。

2. **如果合同还没签，建议这样写**
   - 坏果率≤3%：正常验收，不赔；
   - 3%＜坏果率≤5%：按坏果重量对应货值的1.5—2倍扣款或赔付；
   - 5%＜坏果率≤10%：该批次折价20%—30%，或退货并由供方承担运费；
   - ＞10%：买方有权拒收整批，供方承担退换货费用及因此产生的直接损失。
   具体比例要结合水果品类、运输距离、季节和采购价谈，易腐水果可适当放宽，高价精品果应收紧。

3. **验收时限要写死**
   到货后24小时内完成抽检并书面通知；逾期未提异议视为验收合格。易腐水果建议缩短到6—12小时，并保留开箱视频、称重记录、坏果照片和第三方检测记录。

4. **没有约定时怎么主张**
   不能直接说“超过多少必须赔”，要按《民法典》合同编主张质量不符合约定：先看双方交易习惯、行业标准或供方承诺；再以实际坏果造成的损失为限索赔。此时证据比比例更重要。

**结论：** 合同里建议把合理损耗设在1%—3%，超过3%开始阶梯赔付，超过5%可折价/拒收，超过10%可整批退货并索赔直接损失。最终以双方书面约定为准，不要只依赖“行业惯例”。
