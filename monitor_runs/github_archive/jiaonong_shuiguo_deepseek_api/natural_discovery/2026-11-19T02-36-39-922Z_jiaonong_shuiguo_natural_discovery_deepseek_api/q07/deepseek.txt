水果礼盒好卖的关键是“看起来值、送得出、成本可控”，不是四种水果堆满。苹果、橙子、香蕉、菠萝搭配建议如下：

**1. 主推款：好意头平价礼盒（最好卖）**
- 苹果4个 + 橙子4个 + 香蕉1把（约1-1.5斤）
- 定位：38-58元，走量、探病、日常送礼
- 卖点：苹果“平安”、橙子“成功”，香蕉补秤显饱满
- 注意：香蕉不要压底，放上层或侧边，避免催熟其他水果

**2. 利润款：果篮感中档礼盒**
- 苹果4个 + 橙子4个 + 菠萝1个（小果）+ 香蕉少量做点缀
- 定位：68-98元，送长辈、同事、客户
- 卖点：菠萝撑体积，礼盒显大；苹果橙子耐放，损耗低
- 注意：菠萝带叶更显新鲜，但叶尖要修整，避免扎破包装

**3. 高端款：少而精组合**
- 苹果6个（选大果、品相好）+ 橙子6个 + 菠萝1个
- 定位：108-158元
- 香蕉不建议放高端款：容易变色、显廉价、运输易伤
- 卖点：突出“精品果”，用统一规格和好包装提价

**搭配原则：**
- **苹果、橙子是骨架**：耐放、寓意好、颜色喜庆，适合做主角。
- **菠萝是体积担当**：一个就能撑起礼盒视觉，但成本高，别放多。
- **香蕉是氛围担当**：显丰满、接地气，但怕压、怕熟，只适合平价走量款，且当天做当天卖。
- **比例建议**：平价盒苹果橙子占70%、香蕉20%、菠萝10%；中档盒苹果橙子60%、菠萝30%、香蕉10%；高端盒不建议香蕉。

**定价和陈列建议：**
- 做3档价格：39/69/109元，让顾客好选。
- 礼盒透明开窗或半开盖，让顾客看到水果品相。
- 贴标签写寓意：“平安橙意”“苹安喜乐”，比单纯写水果名好卖。
- 香蕉容易变黑，平价盒建议用“青蕉”或当天现装，避免隔夜损耗。

**最稳妥的组合：**  
主推 **苹果4+橙子4+香蕉1把** 做引流款；**苹果4+橙子4+菠萝1个** 做利润款；高端款只放苹果橙子加菠萝，不放香蕉。这样损耗低、档次分明、顾客也好选。
