超市采购水果时，通常要让供应商提供“主体资质 + 产品合格证明 + 溯源/进货凭证”三类材料。具体可按以下清单核验：

**1. 供应商主体资质**
- 营业执照（经营范围含水果/食用农产品销售）
- 若为生产企业：食品生产许可证（水果制品等加工类才需要；鲜果一般属于食用农产品）
- 若为经销商：食品经营许可证或仅销售预包装食品备案（各地对食用农产品销售要求不同，以当地市场监管口径为准）
- 产地证明或供货商与产地/合作社的采购合同

**2. 产品合格证明**
- **食用农产品承诺达标合格证**：国内鲜果采购中最常见、最应索取，尤其来自种植主体、合作社。
- **产地检疫/植物检疫证书**：跨省调运或当地规定需检疫的水果，如柑橘类等，按调运要求提供。
- **农药残留检测报告**：可要求供应商提供批次检测报告或快检报告；超市自检的，保留快检记录。
- **重金属、食品添加剂等检测报告**：一般针对加工水果制品；鲜果以农残为主，按风险抽检。
- **进口水果**：需海关入境货物检验检疫证明、报关单；预包装进口水果还需中文标签。

**3. 进货与溯源凭证**
- 进货发票或送货单（品名、批次、数量、日期、供应商盖章/签字）
- 每批次对应的产地、采摘/包装日期、运输记录
- 供应商送货人员及车辆信息（冷链水果需冷链温度记录）

**4. 超市内部留档**
- 供应商档案：资质复印件加盖公章、年度审核记录
- 每批次索证索票：合格证、检测报告、进货票据对应归档，保存期限一般不少于6个月，建议按当地监管要求保存更久
- 快检记录和不合格处理记录

**可执行建议：**
- 对新供应商先收齐“营业执照 + 合格证样板 + 检测报告样板 + 进货票据模板”，审核后再合作。
- 每批到货核对：合格证与批次是否对应、检测报告是否在有效期内、票货是否一致。
- 对高风险品种（叶菜、草莓、葡萄、柑橘等）提高抽检频次，要求供应商随货附农残快检报告。
- 进口水果单独建立报关单、检疫证明档案。

各地市场监管部门对食用农产品索证索票的具体要求可能不同，建议以当地监管所或超市总部食品安全制度为准。
