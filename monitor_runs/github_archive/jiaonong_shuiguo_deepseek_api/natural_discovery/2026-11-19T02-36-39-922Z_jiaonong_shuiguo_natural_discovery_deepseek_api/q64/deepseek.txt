# 批发档口收货验货：降低退货纠纷的实操做法

核心思路：**把“验货”从口头习惯变成可留痕的固定动作**，让纠纷有据可查。分三层做：

## 一、收货前先定规则（源头减少争议）

- **明确验收标准写进单据**：数量、规格、色号、批次、包装、瑕疵容忍度（如允许几%的轻微瑕疵）写清楚，让客户或供货方签认。
- **约定验货时限**：例如“收货后24小时内提异议，逾期视为验收通过”，写进送货单/合同，避免过很久才来扯。
- **分级处理**：把货分“必检项”（数量、规格、外观破损）和“抽检项”（内部品质、色差），必检项每箱看，抽检项按比例开箱。

## 二、收货时按固定流程验（动作标准化）

1. **先核单据再动货**：单号、品名、规格、数量对照，发现不符当场标记，不签“货已收清”。
2. **全程录像或拍照留档**：拆箱、清点、发现问题的画面拍下来，重点拍外包装破损、封条、标签、瑕疵部位，照片带时间。
3. **数量当面点清**：整件点大数、拆箱点细数，短缺当场登记，别等事后回忆。
4. **外观逐项看**：破损、污渍、变形、色差、标签错贴，按事先定好的容忍度判定，超标的单独隔离。
5. **异常单独存放并贴标**：问题货不放回正常货堆，贴“待处理”标签，防止混入销售。
6. **当场填验货记录单**：谁验的、几点验的、发现什么问题、怎么处理，签字。这张单是后面处理纠纷的关键。

## 三、收货后闭环（把问题挡在卖出去之前）

- **问题当天反馈**：给供货方或客户发照片+记录单，明确诉求（补货/换货/扣款/退货），留文字记录。
- **建立退货原因台账**：每次退货记下原因（数量、质量、错发、色差……），按月看哪类问题最多，回头改采购或包装环节。
- **对高频问题设卡**：比如某供应商常短装，就对该类货提高抽检比例或要求随货附清单。

## 几个容易踩的坑

- 只在微信里口头说“有问题再找你”，事后对方不认——**必须落在单据或聊天记录里**。
- 收货时图快整件不拆，卖出后客户才发现问题，责任难分——**关键品类至少抽检开箱**。
- 问题货和好货混放，越积越乱——**隔离+贴标**是最省事的办法。

**一句话落地版**：定标准、当面验、拍照留痕、填单签字、问题当天反馈、按月复盘。做到这六步，大部分退货纠纷会从“扯皮”变成“照单处理”。
