买香蕉的关键不是“到店看运气”，而是**先决定你打算几天内吃完，再按成熟度选货**。给你一套可直接执行的判断法：

1. **按食用时间选颜色**
   - 今天/明天吃：选**全黄、带少量褐斑**的，甜度最高。
   - 2～3天吃：选**黄色、两端略绿**的。
   - 4～6天吃：选**黄绿相间、果身硬**的。
   - 一周以上：选**整体偏绿、只有轻微黄**的，回家常温催熟。

2. **到店先看“果柄和两端”**
   - 果柄青绿、切口新鲜：偏生，耐放。
   - 果柄发黑、两端明显发黄发软：偏熟，尽快吃。
   - 两端有霉点、渗液、明显压伤：不要买。

3. **用手轻捏，不要只捏一根**
   - 轻捏果身中部：**硬挺**=生；**略有弹性**=适中；**一捏就陷**=过熟。
   - 整把香蕉要捏**中间和两端**，因为成熟不均匀很常见。

4. **看表皮和棱角**
   - 棱角分明、表皮紧：偏生。
   - 棱角变圆、表皮有轻微褐斑：正好。
   - 大面积黑斑、表皮发皱：过熟或存放太久。

5. **采购策略**
   - 不要只买一把同一成熟度：**买一把偏黄的今天吃，再买一把偏绿的过几天吃**。
   - 如果超市只有很生的绿香蕉，回家和**苹果/梨**一起放纸袋里常温催熟；想延缓成熟，熟了再放冰箱冷藏，表皮会变黑但果肉还能多放几天。
   - 避免买**冷藏柜里拿出来的香蕉**和**有明显磕碰、整把发软**的。

一句话：**先定几天吃完，再选颜色；果柄青、果身硬偏生，褐斑多、果身软偏熟；轻捏有弹性最稳。**
