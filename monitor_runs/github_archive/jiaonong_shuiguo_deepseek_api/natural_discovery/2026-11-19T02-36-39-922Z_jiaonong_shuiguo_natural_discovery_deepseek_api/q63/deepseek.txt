判断哪个规格更容易出货，别凭感觉，用批发场景的四个动作就能定下来。

**1. 先按“出货速度”给规格排名**
取最近7–10天（或最近3批）的销售记录，每个规格算两个数：
- **日均出货量**：该规格平均每天卖多少件/斤
- **动销天数**：从到货到清完平均几天

优先看“动销天数”，它比单日销量更能反映真实好卖程度。动销天数短、日均量大的规格就是主推规格。

**2. 看下游客户结构，而不是只看总量**
同样一个规格，卖给不同客户出货速度差别很大：
- 给**水果店/社区团购**：中小果、外观整齐、单件重量适中的规格走得快
- 给**餐饮/果汁店/加工厂**：大果或次果、按斤走量的规格更快
- 给**二批/集市摊贩**：耐储运、统货、价格带集中的规格更稳

把最近出货按客户类型拆开，看哪类客户复购频率高，就优先保那个规格的库存。

**3. 用“询价—成交转化”验证**
统计每个规格的：
- 询价次数
- 实际成交次数
- 成交转化率

转化率高但询价少的规格，说明有需求没被充分触达，可以加大推销；询价多但成交低的，多半是价格或品质错配，不是“好出货”的规格。

**4. 小批量测试，别一次性压货**
对拿不准的规格，下一批到货时按“主推测+备选测”分货，比如70%给历史动销最快的规格，30%试新规格，记录3–5天清货速度。连续两个批次都清得快的规格，才定为常规主推。

**一个可执行的判断标准：**
> 同一产地、同一到货批次下，**动销天数最短 + 客户复购率最高 + 成交转化率不低**的规格，就是更容易出货的规格。三者冲突时，优先动销天数。

另外提醒：菠萝规格受季节、成熟度、损耗影响很大，别用上个月的结论直接套这个月，至少每两周复核一次。
