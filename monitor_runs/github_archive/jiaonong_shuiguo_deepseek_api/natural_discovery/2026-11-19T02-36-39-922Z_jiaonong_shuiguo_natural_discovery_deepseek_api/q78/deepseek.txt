香蕉和菠萝的售后，核心不是“出了问题怎么赔”，而是**把损耗前置到选品、到货、分拣和履约环节**，售后规则只做兜底。下面按可执行动作讲。

## 一、先定死“什么能赔、什么不赔”

开团页和群里提前公示，避免扯皮：

- **香蕉**：表皮黑点、轻微磕碰、青蕉偏硬 → 不赔（属正常成熟过程）；整把发黑腐烂、果肉变质、断把超过1/3 → 赔或补。
- **菠萝**：外皮青、少量斑点 → 不赔；切开黑心、水烂、酸败、明显空心烂芯 → 全额赔或补发。
- **时效**：签收后24小时内凭照片申请，超时不处理（生鲜通用）。
- **凭证**：坏果和包装同框拍照，不用退回，直接补或退。

规则要短、要发在群里置顶，别藏在详情页。

## 二、香蕉：控熟度比控损耗更重要

1. **采购要“青一点”**：到社区时七成熟左右，别拿已经黄透的。夏天尤其要压熟度，冬天可略熟。
2. **按到货日分批卖**：当天到、当天提，不设“次日自提”拖成熟。
3. **分拣时剔出已熟过头的**：单独做“即食特价”或团长自留，不混进正常团。
4. **包装别闷**：用透气袋或纸箱，别用密封塑料袋捂；夏天可加干燥纸。
5. **到货先开箱散热**：整箱闷着最容易催熟腐烂。
6. **承诺写“自然成熟可能有少量黑点”**，把预期打在前面。

## 三、菠萝：控“黑心”和“水烂”

1. **选品种和产地**：优先选耐运输、黑心率低的批次，别只看低价。
2. **到货抽检切开**：每批随机切2–3个看芯，发现黑心率高直接整批退货或降级处理，别硬卖。
3. **不要提前削皮**：带皮卖，削皮后极易出水变质。
4. **存放避水避压**：阴凉通风、别叠太高，底部受潮最容易烂。
5. **按需订货**：菠萝单果重、客单价高，首团少量试水，别一次压太多库存。
6. **明确“黑心包赔”**：这是菠萝售后最主要场景，规则越干脆，复购越稳。

## 四、履约环节的硬动作

- **到货当天完成分拣和通知**，生鲜拖一天损耗翻倍。
- **自提点阴凉通风**，香蕉别放太阳下或暖气旁，菠萝别泡水。
- **团长分拣时二次挑果**：坏果当场剔，别让用户拿到再售后。
- **设置“坏果包赔”额度**：按销售额预留3%–5%做售后预算，超过就说明选品或履约有问题，要查批次。
- **每批记录损耗率**：香蕉、菠萝分开记，连续两批损耗高就换供应商或换规格。

## 五、售后话术要“快赔不纠缠”

- 用户发图 → 团长直接判断 → 补发或退款，**不要求退回坏果**（退回成本更高）。
- 小额直接赔，大额或疑似批量问题再上报。
- 群内公开处理1–2例，反而能建立信任，但别刷屏。

## 六、最该盯的三个指标

1. **到货损耗率**（分拣剔除比例）
2. **售后率**（售后单量/订单量）
3. **单品复购率**

香蕉售后率控制在3%以内、菠萝5%以内算正常；持续超标就查采购熟度、运输时长和自提点存放，而不是靠放宽赔付硬扛。

一句话：**香蕉靠控熟度和快周转，菠萝靠抽检切芯和带皮卖，售后靠提前公示规则加快速补赔。**
