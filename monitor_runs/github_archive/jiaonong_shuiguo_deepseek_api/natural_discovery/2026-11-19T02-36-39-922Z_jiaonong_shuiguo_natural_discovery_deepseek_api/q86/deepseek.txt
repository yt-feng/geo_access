生鲜平台做水果一件代发，供应商的仓配能力核心不是“有仓库、有快递”这么简单，而是能稳定支撑**小单、多SKU、易损耗、时效敏感、售后可追溯**的发货模式。建议按下面几类能力逐项核验。

## 一、仓储能力

1. **生鲜专用仓或可控温分区**
   - 常温、冷藏、催熟/后熟区能分开；香蕉、芒果、猕猴桃等后熟水果不能和易串味、易冻伤品混放。
   - 仓库有温湿度监控和记录，能提供近30天记录更可信。
   - 有防虫防鼠、通风、垫板离墙离地等基本条件。

2. **一件代发作业能力**
   - 支持单件拣货、多SKU合并订单、赠品/卡片/定制包装。
   - 有WMS或至少订单管理系统，能对接平台订单，支持批量打单、面单回传、库存同步。
   - 日峰值处理能力要问清楚：日常多少单、峰值多少单、爆单时几小时能发完。

3. **库存准确与批次管理**
   - 能按批次/到货日管理库存，先进先出，避免新旧货混发。
   - 库存准确率建议要求≥99%；有临期/催熟状态标记。
   - 能提供每日可售库存，避免平台超卖。

4. **质检与分级**
   - 收货有糖度、硬度、果径、瑕疵、成熟度抽检记录。
   - 发货前有二次分拣，能按平台标准分级；烂果、裂果、畸形果剔除。
   - 能提供质检标准和抽检比例，而不是只口头承诺“坏果包赔”。

## 二、加工与包装能力

1. **预冷/保鲜处理**：浆果、荔枝、樱桃等需要预冷；需要催熟的水果有催熟房和成熟度控制。
2. **包装适配快递**：防撞、防压、透气/保湿、冰袋/吸水纸/泡沫箱等按品类匹配；能提供跌落测试或至少试发数据。
3. **贴标与合规**：产地、等级、净重、保质期/食用建议、追溯码等标签规范；有食品相关资质和包装材料合规证明。

## 三、配送与履约能力

1. **快递资源与时效**
   - 有稳定合作的快递/落地配，能覆盖平台主要销售区域；生鲜线路优先。
   - 明确承诺：下单后多久出库、揽收时效、核心区域时效、偏远地区是否发。
   - 能提供近期的揽收及时率、签收时效、破损率数据。

2. **冷链或控温运输**
   - 需要冷链的品类，要有冷藏车/保温箱/冰袋方案，并能监控运输温度。
   - 一件代发常用“泡沫箱+冰袋+快递”，要问清楚不同季节、不同区域的温控方案。

3. **异常处理**
   - 爆单、天气、疫情、快递停发时的备用方案；能否切换快递、分仓发货。
   - 有客服对接人和售后时效承诺，比如坏果照片审核多久、补发/退款多久完成。

## 四、售后与追溯能力

1. **坏果赔付机制**：按比例赔付还是按单赔付，举证要求、审核时限、责任划分要写进合同。
2. **批次追溯**：从订单能追到批次、到货日、质检记录、发货人，出现批量问题时能快速锁定。
3. **退款/补发执行**：供应商是否承担坏果成本、补发运费，是否有售后保证金。
4. **数据回传**：发货时间、快递单号、签收状态、售后原因能回传平台，便于考核。

## 五、建议的准入核验清单

签约前建议让供应商提供并现场/视频核验：

- 仓库照片/视频、温控记录、消防与食品相关资质；
- WMS截图或订单对接演示，确认能接平台订单；
- 近30天日均单量、峰值单量、出库及时率、破损率、售后率；
- 质检标准和抽检记录样例；
- 包装方案及试发报告；
- 快递合同或合作证明、覆盖区域和时效表；
- 售后流程、赔付标准和对接人；
- 试发测试：选3-5个SKU，发核心区域和偏远区域各若干单，考核到货品质、时效、包装和售后响应。

## 六、合同里建议写死的指标

- 出库时效：如16:00前订单当日出库，揽收不超过X小时；
- 库存准确率≥99%，超卖/缺货责任；
- 坏果率/售后率上限及赔付标准；
- 发货错误率、漏发错发处理时限；
- 峰值保障：大促期间日处理能力不低于X单；
- 数据回传和月度考核，不达标触发整改或清退；
- 售后保证金或质量保证金。

**一句话判断标准**：供应商要能做到“按单拣配、按批次质检、按品类控温包装、按承诺时效揽收、按批次追溯、按标准赔付”，并且这些能力有系统记录和近期数据可验证，才适合做水果一件代发。
