会影响，但通常不是“致命影响”，关键看你怎么卖。

**结论：大小不一会影响销售，尤其影响礼盒/精品陈列的卖相，但可以通过分级销售把影响降到最低。**

具体判断：

1. **散卖/日常零售：影响较小**
   - 顾客买香蕉主要看成熟度、颜色、有无碰伤，大小不齐只要不是特别夸张，接受度较高。
   - 但如果同堆里大小差太多，会显得货乱、品质不稳，影响挑选和成交。

2. **精品陈列/礼盒/送人：影响明显**
   - 大小不一会显得不整齐，降低“精品感”，礼盒场景尤其不适合混装。
   - 这类销售最好按大小、色泽分级，统一规格。

3. **建议的实操做法**
   - **分级卖**：大果、中果、小果分开放，分别定价；中小果可做促销或搭配果切。
   - **统一陈列**：同一堆里尽量放大小接近的，避免视觉混乱。
   - **按用途引导**：家庭自吃主推性价比，中果小果更合适；送礼主推整齐大果。
   - **控制采购标准**：如果长期大小差异大，说明供应商分级不稳定，应在采购时要求按规格分级或更换货源。
   - **注意成熟度一致**：比大小更影响销售的是成熟度不齐，一箱里软硬差异大反而更容易造成损耗和投诉。

所以：**大小不一会影响销售，但不是不能卖；核心是把“混装”变成“分级销售”，把问题转成价格梯度。** 如果采购价有明显优势，大小不齐完全可以接受；如果按精品价采购，就应要求供应商分级。
