采购香蕉时，关键不是“买最黄的”，而是按到店后的使用节奏控制成熟度，并减少机械伤和乙烯聚集。可执行做法：

1. **按用途选成熟度**
   - 当天/次日做甜品：买**黄中带少量青尖**、果肉还硬的，不要买全黄带黑点的。
   - 需立即出品：可买七至八成熟，到店后短期催熟。
   - 避免一次全买同一成熟度，分批到货。

2. **采购时挑果**
   - 选**果皮完整、无磕碰、无挤压痕**的；香蕉变黑常从机械伤开始。
   - 果柄切口干净，不发霉。
   - 不要选整串已全黄、果柄发黑、有酒味的。

3. **运输和到店搬运**
   - 用周转筐平放，**不要堆压**，避免果指受压。
   - 避免暴晒、闷热车厢；夏季运输尽量通风。
   - 到店后轻拿轻放，不要提果柄单根拽。

4. **到店后储存**
   - 放在**阴凉通风处**，理想约13–15℃，避免低于10℃冷藏，香蕉会冷伤发黑。
   - 不要和苹果、梨、番茄等释放乙烯的果蔬混放。
   - 整串悬挂或弓背朝上放置，减少受压面积。
   - 用保鲜膜包住**果柄**可减缓成熟，但不要整根密封，避免闷湿。

5. **分熟度管理**
   - 将已黄的、稍青的分开存放。
   - 已熟香蕉优先使用；可去皮冷冻或做香蕉泥，减少损耗。
   - 每天挑出有伤、过熟的先处理，避免乙烯影响整批。

6. **采购量控制**
   - 按日销量和甜品配方用量下单，热天适当减少单次采购量、增加频次。
   - 与供应商约定到货成熟度，比如“黄带青、硬身、无黑点”。

一句话：**买硬身黄中带青、无磕碰的香蕉，分批到货，13–15℃通风存放，包果柄、不冷藏、不混放乙烯水果，先熟先用。**
