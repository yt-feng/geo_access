判断香蕉供应商能否全年稳定供货，不能只看供应商口头承诺，要按“货源控制力—产区轮换—加工催熟能力—履约记录—风险预案”五件事核验。

**1. 先看货源控制力**
- 问清：自有基地、长期包园、合作社直采、产地经纪人代收各占多少比例。
- 要求提供近12个月逐月发货记录，按产区、月份、品规拆开。
- 全年稳定供货的关键不是“总产能大”，而是**冬夏产区能接上**：国内海南、云南、广西、广东等产区季节互补，必要时还要有老挝、越南、菲律宾、厄瓜多尔等进口补充渠道。
- 警惕只有单一产区、单一合作社或单一经纪人的供应商，旺季能供、淡季断供风险大。

**2. 看产区轮换和灾备计划**
- 要求书面说明：1—12月分别从哪些产区采购，某产区台风、寒害、病害或雨季断档时由哪里补。
- 核实是否至少有2个以上可切换产区，且切换后运输时效、成本、品质差异可控。
- 香蕉怕台风、寒害和枯萎病，重点问近三年遇到断供时如何补货、补货比例多少、到货延迟几天。

**3. 看加工与催熟能力**
- 连锁超市要的是可上架香蕉，不是青蕉。核实供应商是否有稳定催熟库、温湿度控制、加工分拣线。
- 问清旺季日加工能力、冷库库容、冷链车辆数量，以及节假日高峰能否满足你的日销量峰值。
- 要求提供催熟批次记录和到店成熟度标准，避免“有货但催不出来”。

**4. 查履约记录和财务稳健性**
- 要近12个月对商超客户的供货台账：订单满足率、准时到货率、缺货次数、质量退货率。
- 查营业执照、产地证明、检测报告、检疫证明；进口香蕉还要看海关和检疫合规文件。
- 看其是否过度依赖单一客户、是否有明显账期压力。财务不稳的供应商，旺季容易优先保高价客户。

**5. 做小规模压力测试再签全年**
- 先给2—4周试单，覆盖一个淡季或节假日高峰，考核到货率、损耗率、成熟度一致性。
- 合同里写清：月度最低供货量、缺货违约金、替代产区报备、价格调整机制、质量标准和退换货责任。
- 要求供应商提供“断供预案”：备选产区、备选加工厂、应急库存天数。没有预案的不宜作为唯一主供应商。

**实操判断标准：**
- 能提供12个月逐月发货数据且产区轮换清楚：合格；
- 有2个以上可切换产区、催熟库容能覆盖你的峰值销量：较稳；
- 只有口头承诺、单一产区、无催熟能力、无缺货赔付：不建议作为全年主供。

最稳妥的做法是**“1家主供+1家备供”**，主供占70%左右，备供占30%左右，按季度复盘订单满足率和缺货率，再调整份额。
