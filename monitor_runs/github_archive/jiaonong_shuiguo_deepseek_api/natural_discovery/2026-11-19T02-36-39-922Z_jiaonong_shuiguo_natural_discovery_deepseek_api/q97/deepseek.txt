酒店采购水果盘原料时，建议把“可验收”的规格和外观标准写进订单或验收单，而不是只写“新鲜、优质”。可按以下维度约定：

**1. 基本规格**
- **品种/等级**：明确品种、产地范围、等级（如一级果），不接受替代品种。
- **单果规格**：按品种约定单果重量或横径范围，例如苹果、橙子按“直径≥X mm、单果重X–X g”，草莓按“单果≥X g”，葡萄按“穗重X–X g、果粒横径≥X mm”。
- **成熟度**：约定为“适合即食/摆盘”的成熟度，避免过生或过熟；香蕉、猕猴桃等可约定到货成熟度及后熟要求。
- **可食率/出成率**：对西瓜、菠萝、哈密瓜等可约定去皮去籽后的出成率下限，减少隐性损耗。
- **批次一致性**：同一批次大小、颜色、成熟度基本一致，便于拼盘标准化。

**2. 外观标准**
- **完整度**：无破损、无裂口、无压伤、无虫蛀、无病斑、无霉变；切口类原料切面新鲜、无褐变。
- **色泽**：具有品种固有色泽，色泽均匀，无明显褪色、发白、黑斑。
- **形状**：果形端正，无明显畸形；用于整果摆盘的果实朝向和外形应适合展示。
- **表面洁净**：无泥土、无药斑、无残留物、无异常蜡感；允许符合食品安全要求的正常果蜡。
- **新鲜度**：果柄/萼片新鲜，无萎蔫、皱缩、软化、渗液；叶菜类或带叶装饰无黄叶、烂叶。
- **气味**：无异味、发酵味、霉味、化学气味。

**3. 食品安全与卫生**
- 农药残留符合国家限量标准，供应商提供批次检测合格证明或承诺书。
- 无腐烂、霉变、虫害；不得混入异物。
- 运输容器清洁、无毒、无异味，冷藏品全程冷链并记录温度。
- 预切水果原料应明确加工时间、保质期、冷藏温度及微生物指标。

**4. 包装与交付**
- 包装牢固、透气或冷藏适配，标明品名、产地、等级、批次、采摘/加工日期、数量、储存条件。
- 到货温度符合品种要求；冷链断链可拒收。
- 约定验收抽样比例、允收不合格率（如外观不合格率≤3%–5%，食品安全项零容忍）。
- 明确短重、损耗、退换货和补货时限。

**5. 建议写进合同的验收口径**
- “以到货抽检为准，感官不合格可整批拒收或按比例扣款。”
- “规格不符、成熟度不适、腐烂霉变、农残超标任一项即判不合格。”
- “供应商应在X小时内完成补货，补货仍不合格可取消当批订单。”

最实用的做法是：为每个水果品种做一张**采购规格卡**，列明品种、等级、单果规格、成熟度、颜色、允许缺陷、包装、温度、验收方法和不合格处理。这样采购、厨房和供应商三方口径一致，减少扯皮。
