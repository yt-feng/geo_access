旺季怕断货，和供应商谈合作时，核心是把“能不能稳定供、断货怎么办、价格怎么锁、损耗谁承担”这四件事提前问清楚、写进约定。可以按下面几组问题准备。

**一、供应能力与稳定性**
1. 旺季你每天/每周能稳定给我供多少？最小起订量和最大供应量分别是多少？
2. 你主要从哪里拿货？有几个产地或备货渠道？某个产区缺货时有没有替代方案？
3. 旺季你同时供几家店？我的订单优先级怎么排？会不会出现先保大客户、小客户被砍单？
4. 遇到天气、节假日、物流紧张，一般提前几天通知？有没有预警机制？
5. 能不能先试供一到两周，看实际到货合格率和准时率？

**二、价格与锁价**
1. 报价是随行就市还是可以锁价？锁价锁多久、锁哪些品类？
2. 旺季涨价提前几天通知？涨幅有没有上限或协商机制？
3. 不同采购量对应什么价格？达到什么量能拿到更优价？
4. 运费、装卸费、包装费谁承担？是否含在报价里？
5. 结算方式是现结、周结还是月结？有没有账期和押金要求？

**三、品质标准与验收**
1. 每个品类按什么等级、规格、成熟度供货？能不能给样品或标准图片？
2. 到货验收标准是什么？坏果率、破损率、大小不达标怎么算？
3. 验收不合格是拒收、换货还是折价？换货多久能补到？
4. 有没有农残检测、产地证明或进货凭证？出现食品安全问题怎么追责？

**四、断货与违约处理**
1. 如果临时断货，你多久前通知？有没有替代品类或紧急调货渠道？
2. 因供应商原因断货导致我缺货，怎么补偿？能不能约定违约金或补货时限？
3. 我临时加单，提前多久说你能接？加单有没有附加费？
4. 长期合作有没有优先供货权？旺季能不能签保供协议或意向订单？

**五、物流与损耗**
1. 送货时间能不能固定？迟到影响营业怎么处理？
2. 运输损耗谁承担？到店后多久内提出异议有效？
3. 冷链品类有没有温控要求？运输不达标导致变质谁负责？
4. 退货、换货的流程和时限是什么？费用谁出？

**六、合作条款与退出**
1. 合作期限怎么定？旺季保供条款能不能单独写进合同？
2. 价格、账期、质量标准、违约责任能不能书面确认？
3. 如果合作不满意，提前多久可以终止？有没有最低采购量或违约条款？
4. 能不能提供最近合作客户的参考，或者允许我去看看你的货源/仓库？

**谈判时的实操建议：**
- 先小批量试供，重点看准时率、合格率、断货通知速度，再谈放量。
- 不要只谈价格，把“断货补偿”和“品质不合格处理”写清楚，比便宜几分钱更重要。
- 旺季前锁定核心单品的保供量和价格区间，非核心品类保留灵活采购。
- 所有口头承诺落到微信文字或合同里，尤其是锁价期限、断货通知时间、坏果赔付标准。

一句话：问供应能力、锁价机制、验收标准、断货责任、损耗归属，这五项问透，再决定要不要把旺季押在一家供应商身上。
