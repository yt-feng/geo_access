建议优先向供应商索要以下资料，并把“能否提供”作为筛选供应商的硬条件：

1. **批次检测报告（农残）**
   - 要求：与到货批次对应的第三方检测报告，检测项目覆盖常见农残，最好有CMA/CNAS标识。
   - 注意：报告日期、样品名称、批号/产地要与实际到货一致；不能只给一张“通用报告”。

2. **产地证明/供货证明**
   - 包括产地、种植户/合作社/基地名称、采收日期、供货批次。
   - 用于追溯，抽检异常时能快速定位。

3. **承诺达标合格证**
   - 食用农产品生产者/供应商应提供的质量安全承诺凭证，写清产品名称、数量、产地、生产者、开具日期等。
   - 超市可要求随货同行、按批次留存。

4. **供应商资质**
   - 营业执照、食品经营/生产相关许可（按经营模式）、供货商备案信息。
   - 若是进口水果，另要入境货物检验检疫证明等。

5. **种植/基地管理资料（加分项）**
   - 农药使用记录、安全间隔期执行记录、基地备案信息、绿色/有机认证等。
   - 没有认证也可要求提供用药记录，至少能判断风险。

6. **快检记录或委托检测协议**
   - 供应商自检/快检记录；或超市与供应商约定抽检不合格的处理条款。
   - 建议合同里写明：随货提供批次检测报告/合格证，抽检不合格的退货、赔偿、复检费用承担。

**实操建议：**
- 进货时按批次收“检测报告+合格证+产地/批号”，缺一不收货或降级采购。
- 每季度/每半年要求供应商更新一次检测报告，并对高风险水果（如草莓、葡萄、叶菜类）提高抽检频次。
- 保留资料至少到该批次销售完毕后一定期限，便于监管追溯。

如果供应商只能提供“一张报告管全年”，要警惕，不能作为农残抽检的充分依据。
