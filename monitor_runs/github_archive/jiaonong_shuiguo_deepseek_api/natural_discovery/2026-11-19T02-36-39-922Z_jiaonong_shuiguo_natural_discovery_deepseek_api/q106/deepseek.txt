先给结论：判断“合理波动”不能只看涨跌幅，要建立**可比报价 + 波动基线 + 触发规则**三层机制。水果报价每天变是常态，但采购方要能区分三类情况：正常季节性/天气波动、供应商借机抬价、以及报价结构不透明导致的假波动。

## 一、先统一“可比口径”

很多波动不是市场变了，而是报价口径变了。每次询价必须固定以下要素：

1. **规格等级**：品种、果径/克重、等级（特级/一级）、产地、包装（箱重、净重）。
2. **计价单位**：按净重还是毛重，含不含箱、含不含运费、卸货费。
3. **交货条件**：到货价还是产地价，账期、起订量、损耗承担方。
4. **报价时点**：每天几点前有效，是否含税。

只有同一口径下的日价才能比较。否则先要求供应商补全报价单，再谈波动。

## 二、建立自己的“波动基线”

不要凭感觉判断，用数据建基线：

- **按单品建价格带**：每个品类记录近30/90天的成交价，算出中位数和正常波动区间（例如用近30天价格的±10%或历史分位数作参考）。
- **按周看趋势，不按天看单点**：日波动噪音大，重点看3日/7日均线是否持续偏离基线。
- **区分季节性和事件性**：应季转换、主产区天气、节假日备货、运输受限，属于可解释波动；无对应事件却持续单边上涨，才需要警惕。
- **多源比价**：至少2—3家同规格供应商报价 + 批发市场行情/产地信息交叉验证，单家报价不作为判断依据。

## 三、设“触发规则”，把判断变成动作

建议采购方直接定规则：

| 情形 | 判断 | 动作 |
|---|---|---|
| 日涨跌在基线区间内，且有天气/季节/行情解释 | 合理波动 | 正常执行，记录原因 |
| 连续3天上涨且累计超基线上限 | 疑似异常 | 要求供应商书面说明原因，同时向备选供应商询价 |
| 涨幅明显高于同期市场均价 | 不合理 | 暂停下单或改配额，启动比价/议价 |
| 报价低得异常 | 警惕 | 核对规格、净重、新鲜度、是否临期或混级 |
| 同一供应商报价频繁跳变但无行情依据 | 报价不稳定 | 要求锁价周期（如3天/7天），或改用阶梯价 |

## 四、采购方的实操建议

1. **要求供应商报“价格构成”**：产地收购价、包装、损耗、运费、利润各占多少，便于识别哪一段在涨。
2. **谈短期锁价或浮动公式**：例如“以某批发市场同规格均价为基准，上下浮动不超过X%”，减少每日博弈。
3. **保留2—3家合格备选**，异常时能快速切换配额，这是最有效的议价工具。
4. **记录每次波动的归因**：天气、节气、产区切换、运输、供需。积累1—2个月后，你自己的基线比任何外部说法都可靠。
5. **关注质量同步变化**：价格降了但果径、新鲜度、损耗率变差，实际成本可能更高，要按“到货可用成本”比较，而不是只看单价。

一句话：**合理波动 = 同口径 + 有基线 + 可解释 + 多源验证**。超出这个范围的，不急着接受，先要说明、再比价、最后用配额和锁价机制约束。
