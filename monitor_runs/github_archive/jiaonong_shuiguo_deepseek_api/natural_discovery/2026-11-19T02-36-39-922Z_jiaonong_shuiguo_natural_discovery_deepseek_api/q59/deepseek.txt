可以谈，而且餐饮店做水果锁价是常见操作，但要看品类和方法。直接给你可执行建议：

**1. 先判断哪些水果适合锁价**
- **适合锁价**：苹果、梨、橙、柠檬、香蕉、冷冻水果、罐头水果等耐储、供应稳定、有期货或标准化分级的产品。
- **不适合硬锁价**：草莓、蓝莓、荔枝、樱桃、芒果等季节性强、损耗大、价格波动大的鲜果。这类更适合“保底量+浮动价”或短期周报价。

**2. 锁价谈法（不要只谈一个固定价）**
- **短期锁价**：锁1–4周，适合鲜果，约定每周按市场指数±固定幅度调整。
- **中长期锁价**：锁3–6个月，适合耐储水果，约定固定价+最低采购量。
- **保底+浮动**：设定基准价，市场价格超过±10%–15%时双方重新议价或按公式调整。
- **阶梯价**：按月度采购量给不同锁价档位，量越大锁价越稳。

**3. 合同里必须写清楚**
- 锁价品类、规格、等级、产地、包装标准；
- 锁价期限、最低采购量、超量/欠量处理；
- 价格调整触发条件（如批发市场均价连续N天波动超X%）；
- 质量验收标准、损耗率上限、退换货规则；
- 付款账期、配送频次、缺货违约责任；
- 不可抗力与市场极端波动的重新议价机制。

**4. 谈判筹码**
- 承诺稳定采购量和年度框架协议；
- 接受分级采购（好果做鲜食、次果做果汁/甜品）；
- 淡季也保持一定采购量，换取旺季锁价；
- 多家供应商比价，但不要只压价，给供应商合理利润才能锁住。

**5. 风险提醒**
- 锁价不等于锁成本：还要锁规格、损耗和运费，否则供应商可能在品质上缩水。
- 鲜果锁价期限不宜过长，建议1个月内滚动锁价。
- 合同里保留“市场价大幅低于锁价时重新协商”的条款，避免自己吃亏。
- 先小批量试单，验证供应商履约能力再签长期锁价。

**结论**：能谈，但建议“耐储果中长期锁价+鲜果短期锁价或保底浮动”，合同写清规格、量、调价机制和违约条款，比单纯谈一个固定价格更稳。
