香蕉配送的两个核心风险要分开治：**压坏是机械损伤问题，变黑是成熟/冷害问题**。控制思路是“选对货、控好温、护好形、管好期”。

**1. 货源和成熟度：不要发全熟蕉**
- 配送香蕉建议采购**七至八成熟**的青蕉或微黄蕉，到消费者手中再自然转黄。全黄蕉配送损耗率会明显上升。
- 优先选**厚皮、耐运输品种**（如部分巴西蕉、威廉斯蕉），并要求供应商做去轴、分级。
- 入库后按成熟度分仓，**先进先出**，黄度高的先配短距离订单，不要混发。

**2. 温度：防冷害比防热更关键**
- 香蕉**低于12℃易冷害**，表皮发黑、果肉变硬；高温则加速成熟和腐烂。配送环节尽量控制在**13–18℃**，避免冷链直吹或贴冰袋。
- 夏季用**隔热袋+少量蓄冷材料**，蓄冷剂不要直接贴果；冬季北方要防冻，加保温层。
- 不要和苹果、梨等释放乙烯的水果混装，否则催熟变黑。

**3. 包装：固定+缓冲，防挤压和摩擦**
- 单根或小把用**透气保鲜袋/网套**，再放**带隔档的硬质内托**，避免相互挤压。
- 外箱用**抗压瓦楞箱**，箱内留缓冲（纸隔板、珍珠棉），但不要完全密封，需留透气孔。
- 香蕉**不要平堆重压**，装箱时果指朝上或侧放，减少受压面；每箱重量控制在配送可承受范围，避免底层压伤。
- 悬挂或分格包装适合高客单价订单；普通订单用“网套+隔板+抗压箱”性价比最高。

**4. 配送时效和履约设计**
- 香蕉属于**短保高损品**，优先做**同城次日达/半日达**，跨城长距离配送损耗难控。
- 订单页面标注“青蕉发货，收货后常温放置转黄”，管理消费者预期，减少“变黑=坏果”的投诉。
- 高温时段和远距离订单可**限售或加价**，用履约范围换损耗率。

**5. 验收和售后兜底**
- 出库前抽检黄度、机械伤、果柄状态，有伤果不上线。
- 制定明确赔付标准：轻微表皮黑点 vs 果肉软烂分开处理，拍照理赔，降低纠纷成本。
- 记录每批次损耗原因（压伤/冷害/过熟），反向调整采购成熟度和包装方案。

**最优先做的三件事**：改发七至八成青蕉；包装加隔档和抗压箱；配送温度避开12℃以下和高温直晒。这三项通常能砍掉大部分压坏和变黑问题。
