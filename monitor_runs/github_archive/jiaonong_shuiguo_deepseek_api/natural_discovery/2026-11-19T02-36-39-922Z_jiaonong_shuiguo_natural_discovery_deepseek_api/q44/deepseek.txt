判断供应商售后是否稳定，不要只听口头承诺，重点看“历史行为”和“可验证机制”。给你一套可执行的考察办法：

**1. 先要售后条款落到合同/订单里**
- 明确响应时限：如到货后2小时内响应、24小时内给处理方案。
- 明确赔付标准：菠萝黑心病/水烂、香蕉青熟不匀或催熟后不软等，按比例补货、折价还是退货。
- 明确责任边界：运输损耗、催熟损耗、自然损耗各谁承担。
- 写清对接人、电话、备用联系人，不接受“只有一个销售微信”。

**2. 用“小单压力测试”验证**
先下1–2个小批量订单，故意在到货后当天反馈1个合理售后问题（如个别批次成熟度不符），观察：
- 多久回复；
- 是否主动给方案；
- 补货/折价是否按承诺执行；
- 第二次再反馈时是否还理你。
稳定售后通常第一次就流程清楚，而不是靠人情拖延。

**3. 查历史记录和同行口碑**
- 要求供应商提供近3个月同类商超客户的售后处理记录（脱敏即可），看是否有闭环。
- 问本地同行、批发市场熟客：出问题时是“补得快”还是“拖到你自己认”。
- 看供应商是否长期做生鲜，临时倒货型供应商售后通常不稳定。

**4. 看其内部是否有售后岗位/流程**
稳定供应商一般有：专职客服或售后对接、异常登记表、补货/赔付审批流程、冷链或催熟配合能力。只靠老板一人拍板的，规模一大就容易失联。

**5. 设置考核和备选**
- 合作前3个月按月统计：响应时长、解决时长、赔付执行率。
- 连续2次超时或1次拒赔，就启动备选供应商。
- 菠萝和香蕉最好各保留1家主供+1家备供，避免被单一供应商拿捏。

**判断标准一句话：** 愿意把售后写进合同、敢让你小单测试、能拿出历史处理记录、出问题按流程赔而不是靠磨嘴皮的供应商，才算售后响应稳定。
