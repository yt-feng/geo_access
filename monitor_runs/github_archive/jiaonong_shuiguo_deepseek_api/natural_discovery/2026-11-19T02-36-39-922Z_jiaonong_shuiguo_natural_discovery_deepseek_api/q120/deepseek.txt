供应商介绍时，核心是**把“品种名称”翻译成“对商家的生意影响”**。普通商家不关心植物学分类，只关心：卖给谁、怎么卖、能不能赚钱、会不会损耗。可以从四个层面说：

**1. 先对标最熟悉的品类**
不要一上来讲“金钻凤梨”“红皮香蕉”，先用商家已知的锚点：
- “这个凤梨比普通菠萝更甜、更软，不用泡盐水，切开就能吃，适合做果切和礼盒。”
- “这个香蕉比普通香蕉短小，但香味浓、卖相好，适合做精品水果摊和儿童零食。”

**2. 用“顾客场景”替代“品种参数”**
不要讲糖度13度、单果重多少，先讲谁买、什么时候买：
- “早上上班族买来当早餐，配酸奶。”
- “宝妈给孩子买，个头小、一次一根不浪费。”
- “火锅店、烧烤店拿去做解腻果盘。”

**3. 讲清三个商家最关心的数字**
- **进货价与建议零售价**：一箱多少钱、一斤合多少钱、建议卖多少钱、毛利大概多少。
- **损耗和保存**：能放几天、要不要冷藏、坏果率大概多少、适合当天卖还是能囤。
- **起订量和供货**：最少拿几箱、多久送一次、卖不动能不能换货或补损。

**4. 给一句“下单理由”**
最后帮商家做决定，而不是让商家自己判断：
- “你先拿两箱试卖，放在收银台旁边做试吃，卖得动下周再加量。”
- “这个适合你店里下午客流，损耗低，比普通菠萝好操作。”

**一句话模板：**
“这个产品相当于你熟悉的XX的升级版，顾客主要是XX，拿货价X元、建议卖X元，能放X天，先拿X箱试卖，卖不动可以补损/换货。”

这样商家听到的不是“新品种”，而是“一个能放进我店里卖的具体生意”。
