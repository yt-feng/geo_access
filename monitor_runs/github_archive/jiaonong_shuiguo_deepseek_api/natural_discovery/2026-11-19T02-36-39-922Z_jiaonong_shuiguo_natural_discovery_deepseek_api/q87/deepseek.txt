旺季锁水果库存，核心是“用确定性的承诺换供应商的优先权”，而不是只靠口头打招呼。可以按下面几步做：

**1. 先做需求预测，给出可承诺的量**
- 按品类、周次拉出旺季预测：历史同期销量、当前预售/团购开团量、增长率，做成“保守/基准/冲刺”三档。
- 给供应商的是“基准量+浮动区间”，例如基准10吨/周，上下浮动15%，而不是一个虚高数字。
- 明确到货节奏：每周几次、每次多少、什么规格等级。水果最怕只锁总量不锁规格。

**2. 提前签锁量协议，别只靠微信**
合同或锁量确认单里至少写清：
- 锁定品类、规格（果径/糖度/等级）、数量区间、周次
- 锁价方式：固定价、保底价+浮动、随行就市但有上限
- 到货时间、验收标准、损耗责任、缺货违约或补偿
- 天气/减产等不可抗力的处理：替换规格或顺延，而不是直接断供

**3. 用预付款/定金换优先权**
旺季供应商资源紧张，愿意给“优先供货权”的通常是给了确定性的客户：
- 支付10%–30%定金锁量，约定抵扣货款
- 或承诺旺季总采购额，换供应商把你这单排进优先池
- 对核心单品可做“保底采购量”，超出部分随行就市

**4. 多源备份，别把单一供应商当唯一解**
- 每个核心单品至少2家供应商：主供70%、备供30%
- 提前谈好备供的“应急插单”能力，旺季前做一次小批量试单验证
- 产地直采+一批市场档口组合，降低单一产区天气风险

**5. 锁定物流和仓储衔接**
水果爆单断供经常不是没货，是运力或分拣跟不上：
- 和供应商确认旺季发运能力、装车时间、冷链条件
- 自提或到仓的，提前预约仓位和卸货时段
- 对易损品设定到货验收和短保处理规则，避免压货损耗

**6. 用信息透明换信任**
每周给供应商同步一次你的团购开团数据、售罄率、退货率，让对方知道你的量是真实的。供应商更愿意把货留给“计划稳定、回款快”的客户。

**7. 回款速度本身就是筹码**
旺季可以谈“货到7天/15天结”，比账期长的客户更容易拿到优先权。如果现金流允许，这是比压价更有效的锁货手段。

一句话判断标准：**能写进锁量单的量、价、规格、到货时间、违约责任，才算真锁住；只口头说“给我留点”的，旺季大概率被截胡。**
