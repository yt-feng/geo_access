低价香蕉最容易出问题的不是“便宜”，而是**低价承诺了不该承诺的品质**。建议从选品、分级、定价话术、履约和售后五个环节控制：

1. **选品上避开“不适合团购”的香蕉**
   - 不要用熟度太高、表皮有伤的香蕉做低价引流，运输和分拣会放大投诉。
   - 优先选产地稳定、可做后熟的青蕉或七成熟蕉，到仓后再控温催熟。
   - 低价款明确是“统货/家常款”，不要和精品蕉混卖。

2. **必须做分级和验收标准**
   - 到货抽检：青硬、黑斑、断指、机械伤、果柄霉变分别设比例上限。
   - 例如：黑斑面积超过果面1/3、断指、明显压伤的不入低价团；坏果率控制在可接受范围，超出部分供应商承担。
   - 分拣时把“外观不完美但可食”的次果单独做特价，不要混进正常团。

3. **定价和文案要管理预期**
   - 低价款标题写清“家常果/统货/大小略有差异/表皮可能有轻微斑点”，不要用“精品大果”这类词。
   - 不承诺“个个金黄”“无黑点”；可以承诺“坏果包赔”，但把赔付标准写具体。
   - 避免超低价限时抢造成集中催单和履约崩盘。

4. **履约环节控温控时**
   - 香蕉怕挤压、怕高温、怕冷害，团长自提点不要暴晒，不要和重物混放。
   - 到货后尽快分装，减少反复搬运；夏季缩短从到仓到自提的时间。
   - 包装用透气筐或纸箱，不要用密封塑料袋闷着。

5. **售后前置，降低投诉升级**
   - 开团页明确售后规则：坏果拍照赔付、多久内反馈、按比例赔还是补发。
   - 对低价团设置“快速赔付”通道，小金额直接按比例赔，避免团长和用户拉扯。
   - 把高频问题做成团长话术：黑点是否可食、催熟方法、为什么大小不一。

6. **算清低价的经济账**
   - 低价引流可以，但不要把售后成本漏算。把预计坏果赔付率计入毛利，坏果率高的批次宁可不做。
   - 如果供应商无法稳定供货，低价爆单反而会带来集中投诉。

核心原则：**低价可以卖“性价比”，不能卖“精品预期”；用分级把次果单独处理，用明确售后把纠纷前置。**
