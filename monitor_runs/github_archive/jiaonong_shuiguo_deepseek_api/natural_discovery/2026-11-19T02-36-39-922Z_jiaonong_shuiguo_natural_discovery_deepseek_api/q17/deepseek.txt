社区超市做水果，核心不是“多进便宜货”，而是把损耗和周转算清楚。给你一套能直接落地的控制方法：

1. **按销量定进货量，不按感觉补货**
   - 每个单品连续记录7天销量，算出日均销量。
   - 日常进货量控制在日均销量的1—1.2倍；周末、节假日按1.3—1.5倍备货。
   - 新品先小批量试销，比如一次只进半天到一天的量，卖得动再放大。

2. **把水果分成三类管理**
   - **快销品**：香蕉、苹果、橙子等，保持不断货，但库存不超过2—3天销量。
   - **易损品**：草莓、葡萄、桃子、叶菜类水果，按“当天进当天卖”为主，库存不超过1天销量。
   - **耐储品**：柚子、哈密瓜、部分进口水果，可备3—5天量，但也要设上限。

3. **设定库存红线**
   - 给每个单品设“最高库存”和“最低库存”。
   - 低于最低库存才补货；高于最高库存停止进货，先促销消化。
   - 每天闭店前盘一次易损品，发现剩货第二天优先做特价或果切。

4. **用陈列和促销主动消化库存**
   - 易损水果放最显眼位置，小份量、多频次上架，避免一次堆太多。
   - 下午或闭店前对临期水果做“限时特价”“买二送一”或果切处理。
   - 果切必须当天做当天清，不要隔夜再卖。

5. **收货和储存卡住新鲜度**
   - 收货时看成熟度，不要一次进太熟或太生的货；香蕉、芒果等可进略生的，分批催熟。
   - 水果不要挤压堆放，易损品用浅筐、分层摆放。
   - 冷藏和常温分开：草莓、葡萄、切果冷藏；香蕉、芒果常温避风；苹果和香蕉尽量分开放，避免催熟。
   - 每天早晚各挑一次坏果，坏果立刻剔除，避免传染。

6. **建立简单可执行的日报**
   每天记三件事：进货量、销量、损耗量。连续记两周，就能看出哪些单品压货、哪些不够卖。每周淘汰1—2个周转最差的单品，把货架和资金让给动销好的。

7. **供应商和小批量补货**
   - 易损水果尽量找本地供应商，少量多次补货，哪怕单价略高，也比压货损耗划算。
   - 和供应商谈好退换货或次品补偿，减少收货风险。

一句话原则：**耐储品控上限，易损品控当天，临期品主动促销，每天看销量和损耗再补货。** 先坚持两周记录，库存压力会明显下降。
