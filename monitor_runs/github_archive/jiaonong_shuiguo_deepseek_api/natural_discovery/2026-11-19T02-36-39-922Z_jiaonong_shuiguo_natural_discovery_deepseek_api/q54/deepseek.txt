优先关注**成熟度**，价格只作次要筛选。  
原因很直接：香蕉成熟度决定蛋糕的香气、甜度、含水量和组织结构，价格再低，成熟度不对也会影响出品稳定。

**可执行判断标准：**
1. **做香蕉蛋糕/香蕉磅蛋糕**：选**表皮黄、带少量黑点、手感微软**的香蕉，香气足、甜度高、易压泥。
2. **不要选全青香蕉**：淀粉多、香气弱、甜度低，蛋糕风味不足，还可能发涩。
3. **不要选大面积发黑、软烂出水**：适合香蕉面包，但风味偏发酵、酸味重，且含水量高，配方需调整，新手不建议。
4. **采购策略**：按“使用当天或次日”的成熟度买；需要囤货时，买**七成熟偏黄**，室温催熟，不要为便宜买过生或过熟。
5. **价格判断**：在成熟度合格的前提下比价；若价格低但成熟度差一个等级，通常不值得，除非你有稳定催熟/处理能力。

**一句话：先按成熟度分级定用途，再在同等级里选价格。** 对烘焙店来说，成熟度是质量变量，价格只是成本变量。
