超市和水果供应商的账期没有统一标准，常见区间大致如下：

- **现款现结/货到付款**：常见于首次合作、小批量、叶菜/草莓/荔枝等易损耗高、价格波动大的品类。
- **7～15天**：生鲜水果较常见的短账期，适合中小超市、区域供应商，风险相对可控。
- **30天**：较普遍的月结账期，很多商超与稳定供应商会采用“月结30天”。
- **45～60天**：常见于连锁超市、大型渠道或强势零售商；对供应商资金压力较大。
- **90天及以上**：多见于大型商超、平台型渠道或特殊谈判结果，不是水果生鲜的普遍常态，供应商通常会把资金成本计入报价。

实际谈的时候建议把握几点：

1. **按品类分账期**：易腐、价格波动大的水果用短账期；耐储品类可适当延长。
2. **新供应商先短后长**：先7～15天或首批现结，稳定后再谈30天。
3. **账期与价格联动**：账期越长，采购价通常应相应上浮或要求返利，否则供应商会把资金成本转嫁到报价里。
4. **明确起算日和结算方式**：是送货签收日、对账日还是发票日后起算，差异很大；最好约定固定对账日和逾期付款责任。
5. **控制额度**：即使给30天账期，也建议设信用额度，避免单方面敞口过大。

如果是中小超市，**15～30天**是比较常见且容易谈成的区间；连锁商超超过30天也常见，但供应商报价通常会提高。
