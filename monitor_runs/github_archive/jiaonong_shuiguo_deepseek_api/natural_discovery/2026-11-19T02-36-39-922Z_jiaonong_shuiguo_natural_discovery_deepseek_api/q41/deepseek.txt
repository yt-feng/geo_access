判断香蕉催熟能力是否稳定，核心不是看“现在黄不黄”，而是看**批次一致性、催熟响应速度、后熟曲线和货架期表现**。商超采购可以用下面这套可执行方法。

**1. 先看货源和批次稳定性**
- 固定产区、固定季节、固定供应商的催熟表现通常更稳定；频繁换产地/换供应商时，催熟差异会明显变大。
- 要求供应商提供：采摘成熟度、运输温度、到货时间、是否经过乙烯处理、催熟库记录。
- 同一供应商连续3—5批做记录对比，看“到货青度—催熟到目标色—上架后返青/发软”的波动。

**2. 看到货青蕉的“底子”**
- **饱满度**：蕉指饱满、棱角由明显变圆，说明成熟度够，催熟响应更稳定；过瘦的蕉催熟后容易软而不香。
- **青度一致**：同一箱内颜色、粗细、长度差异小，催熟后成熟均匀。
- **果柄和切口**：切口新鲜、无霉、无褐变；果柄粗壮不干缩。
- **无冷害/水伤**：表皮有暗褐斑、水渍状、蕉指发软，催熟能力通常不稳定。
- **无机械伤**：擦伤、压伤处催熟后先黑先软，造成批次花杂。

**3. 做小批催熟测试**
采购不能只靠供应商口头承诺，建议每批或每换供应商时做小样：
- 取同批次3—5箱，按门店拟用催熟条件处理。
- 记录：起始色级、催熟温度湿度、乙烯浓度/时长、达到目标色级所需天数。
- 观察：是否整箱同步转色、有无“青头”“硬心”、果指是否均匀变黄。
- 目标不是“能催熟”，而是**多次测试的天数波动小、色级整齐、软硬一致**。

**4. 看后熟曲线是否可控**
稳定催熟能力表现为：
- 转色顺序正常：先褪绿再转黄，色级推进均匀；
- 达到可售色级后，货架期有可预期天数；
- 不出现“催熟快、软得也快”的短货架期；
- 不出现“外表黄、果心硬”或“表皮黄、果肉生”的不同步。
采购可要求供应商给出该品种/产地的催熟曲线参考，并用自己门店数据校正。

**5. 看催熟库和操作管理**
如果供应商或配送中心负责催熟，重点查：
- 库温、湿度是否稳定并留记录；
- 乙烯浓度/熏蒸时间是否按批次调整；
- 不同成熟度是否分库/分垛处理；
- 有没有预冷、通风、CO₂积累控制；
- 催熟后是否及时降温上架。
催熟能力稳定，本质是**操作标准化+按批次微调**，不是一套参数全年不变。

**6. 用数据做供应商评估**
建议采购建立简单台账，每批记录：
- 供应商/产地/到货日期；
- 到货青度、饱满度、均匀度；
- 催熟天数、目标色级达成率；
- 上架后2—3天软果率、黑斑率、返青/青头率、损耗率。
连续比较后，优先选择**催熟天数波动小、色级整齐、货架期稳定、损耗低**的供应商，而不是单批催得最快的。

**7. 现场快速判断口诀**
采购现场可先做初筛：
- 同箱颜色、粗细、饱满度是否一致；
- 果柄是否新鲜、蕉指是否硬实；
- 有无冷害斑、水渍、压伤；
- 问清采摘成熟度和运输温度；
- 小批试催，看“转色齐不齐、软硬匀不匀、上架后稳不稳”。

结论：**催熟能力稳定=批次底子一致+催熟响应可预测+后熟均匀+货架期可控。** 采购最有效的办法是固定供应商、按批小样测试、建立催熟与损耗台账，用连续数据判断，而不是凭单次外观或供应商承诺。
