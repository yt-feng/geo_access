酒店早餐水果供应要稳定，核心是“规格可验收、价格可预期、断供有预案、责任可追溯”。和供应商谈合作时，建议重点盯以下几类事项：

**1. 先定采购标准，别只谈价格**
- 明确品种、等级、单果规格（如苹果直径、橙子克重）、成熟度、外观瑕疵容忍度。
- 早餐场景要区分“直接摆台”和“后厨切配”两种用途，切配果可用二级果降成本，摆台果要外观稳定。
- 约定农残检测、产地证明、冷链温度记录等随货资料要求。

**2. 供应稳定性写进合同**
- 明确每日/每周订货量、下单截止时间、送达时间窗口、卸货入库责任。
- 约定最低供货保障和缺货替代方案：缺货时供应商需提前多久通知、能否用同价位同品类替代、替代品是否需酒店确认。
- 设置旺季/节假日保供条款，比如春节、大型会议期间不得随意减量。

**3. 价格机制要防“随行就市”失控**
- 可约定月度或季度定价，参考当地批发市场均价，设涨跌幅上限。
- 明确报价是否含税、含运费、含卸货；临时加价需提前书面确认。
- 对损耗、退货、补货是否收费写清楚。

**4. 验收和退换货规则**
- 到货当场验收：数量、重量、规格、新鲜度、包装、温度。
- 不合格品如何退换、多久内补送到、是否影响当日结算，都要写明。
- 建议保留验收单和照片，作为对账和索赔依据。

**5. 食品安全与资质**
- 核验营业执照、食品经营/生产相关许可、检测报告。
- 明确运输车辆清洁、冷链断链责任、食安事故赔偿。
- 要求供应商对因水果质量问题导致的客诉或损失承担相应责任。

**6. 结算与违约条款**
- 账期、对账周期、发票类型、付款方式写清楚。
- 设置延迟送货、缺货、质量不达标的违约金或扣款标准。
- 约定合同期限、续约条件、提前解约通知期。

**7. 备选供应商和试供期**
- 不要只签一家，至少保留一家备选。
- 先试供2—4周，按早餐实际消耗和客诉情况评估，再定长期合同。
- 试供期重点看：到货准时率、损耗率、规格一致率、临时补货响应速度。

谈判时最值得坚持的三条：**验收标准书面化、缺货补货有时限、价格调整有上限**。这三条直接决定早餐水果能不能“稳定”。
