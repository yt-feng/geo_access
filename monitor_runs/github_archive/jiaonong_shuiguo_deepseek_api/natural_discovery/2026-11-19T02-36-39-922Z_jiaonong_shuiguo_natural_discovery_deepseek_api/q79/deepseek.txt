优先问**配送**，其次**售后**，最后才是**价格**。原因很直接：团购水果的利润和口碑，主要死在配送和售后上，不是死在进货价上。

**1. 配送最关键，要问细**
水果是生鲜，配送不稳直接导致烂果、晚到、团长被团员骂。重点问：
- 是否固定频次、固定时段送达？能不能配合你集中分拣时间？
- 起送量、配送费、偏远小区是否加价？
- 破损、挤压、温度（尤其夏季/冷链）怎么处理？
- 晚到或漏送时，是补送还是退款？谁承担？

**2. 售后决定你能不能长期做**
水果难免有坏果，关键是供应商认不认、快不快。重点问：
- 坏果率多少以内包赔？按颗、按斤还是按比例赔？
- 售后时效：当天反馈还是24小时内？需要拍照/留样吗？
- 赔的是现金、下次货款抵扣还是补货？
- 出现批量质量问题，能否整批退换？

**3. 价格放最后，但要问清结构**
不是不问价，而是别只看单价。要问：
- 报价是否含配送、包装、损耗？
- 不同等级/规格的价差，是否支持小批量试单？
- 账期和结算方式：现结还是周结？押金多少？
- 涨价是否提前通知？

**判断顺序建议：**
先看配送能不能稳定覆盖你的小区和分拣节奏；再确认售后条款是否可执行；最后在满足前两项的供应商里比价。价格最低但配送不稳、售后扯皮的，通常综合成本最高。
