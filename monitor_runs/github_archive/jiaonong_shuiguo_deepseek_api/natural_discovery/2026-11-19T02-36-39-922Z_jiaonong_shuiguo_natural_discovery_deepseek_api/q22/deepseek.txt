可以用“引流果+利润果+凑单果”做组合，核心不是简单打折，而是让顾客为了“更划算”多买一件。建议直接落地成下面几种促销：

1. **组合装促销：香蕉+菠萝+苹果“果篮/果盒套餐”**
   - 设两档：
     - 小份家庭装：香蕉1把 + 菠萝1个 + 苹果4个，原价合计约XX元，套餐价便宜10%—15%。
     - 大份聚会装：香蕉2把 + 菠萝1个 + 苹果8个，套餐价便宜15%—20%。
   - 关键：套餐必须比单买“一眼能算清便宜”，标签写“单买省X元”。
   - 香蕉做引流，苹果做稳定销量，菠萝拉高客单。

2. **“1+1+1换购”：买苹果满额，加价换香蕉/菠萝**
   - 买苹果满20元，加1元换1把香蕉；加5—8元换菠萝1个。
   - 适合把只买苹果的顾客往组合消费拉，客单价提升明显。
   - 注意换购价要低于单买价，但不要低到伤毛利。

3. **“香蕉引流、菠萝提客单、苹果做满赠”**
   - 香蕉设置明显低价小份引流，放在入口；
   - 菠萝做“整颗特价+切盒加价购”，切盒利润更高；
   - 苹果做“满38元送香蕉1把”或“满58元加9.9元换菠萝”。
   - 这样顾客为了满赠/换购，会自然多买苹果或其他水果。

4. **“周套餐+周末家庭装”错位**
   - 工作日推小份组合，降低决策门槛；
   - 周五到周日推大份家庭装，主打“一次买齐”。
   - 比如：周末家庭果篮=香蕉1把+菠萝1个+苹果6个，定价比单买低12%，再送1个柠檬/切果盒券。

5. **陈列和话术要配合**
   - 三品相邻陈列，但香蕉放外侧引流，菠萝放组合区中间，苹果放端头；
   - 价签写清三行：
     - “单买合计XX元”
     - “套餐价XX元”
     - “省XX元”
   - 员工话术统一：“香蕉单买也便宜，但拿套餐更划算，苹果菠萝都带上了。”

6. **控毛利建议**
   - 香蕉毛利低，适合引流，不宜在套餐里放太多；
   - 菠萝损耗和削切成本高，尽量推整颗+切盒加价购；
   - 苹果相对耐储，适合做满赠门槛和套餐主体。
   - 套餐折扣控制在10%—15%起步，周末大份可到20%，但要用苹果和香蕉的量控制成本。

最推荐先试这一套：**小份家庭套餐（香蕉1把+菠萝1个+苹果4个，省10%）+ 苹果满38元加9.9元换菠萝 + 香蕉入口引流价**。执行一周后看三个指标：套餐销售占比、客单价提升、菠萝损耗率，再调整折扣和份量。
