很重要，但重要性不在“供应商愿不愿意给一次小批量”，而在“能不能把试卖变成低风险的常规能力”。对便利店水果这种高损耗、需求波动大的品类，小批量试卖基本是刚需。

判断供应商是否值得合作，可以看这几点：

1. **起订量是否可降到单店可消化**
   - 水果保质期短，一次压货卖不掉就是直接损耗。
   - 如果供应商只肯按整箱、大周转箱起订，试卖意义很小。
   - 关键不是“绝对小”，而是“单店单次订货量能覆盖3—7天销量，且允许换品”。

2. **是否支持多频次、小批量补货**
   - 比一次性小批量更重要的是补货频率。
   - 比如一周2—3次配送到店，卖得动再加单，卖不动不再压货。
   - 这能明显降低便利店的水果损耗和现金流占用。

3. **是否接受试卖期退换/调拨/损耗分担**
   - 小批量试卖如果没有退换机制，风险仍全在门店。
   - 可谈：首单试卖、滞销品调拨到其他店、临期折价支持、坏果赔付标准。
   - 不必追求全退，但要有明确的质量赔付和滞销处理规则。

4. **是否愿意按门店/商圈做差异化供货**
   - 社区店、写字楼店、学校店水果需求不同。
   - 供应商能支持不同门店小批量拼单或分品供货，试卖才有效。
   - 否则所有店统一配大货，还是容易滞销。

5. **试卖是否有明确评估周期**
   - 建议以2—4周为一个试卖周期，看动销率、损耗率、毛利额，而不是只看销量。
   - 连续两周动销低于预期就换品或停订。
   - 供应商配合度高，试卖才有迭代价值。

实操建议：

- 首轮选3—5个单品，每店每单品少量陈列，不做大堆头。
- 和供应商约定“首单小批量+48小时内可补一次+坏果按标准赔付”。
- 用动销率和损耗率决定加单或淘汰，别用感觉补货。
- 如果供应商完全不愿小批量、不愿多频次、不愿承担质量损耗，那这个供应商更适合做应急备选，不适合做便利店水果主力。

结论：**小批量试卖很重要，但真正要谈的是“小批量起订+高频补货+损耗分担+快速换品”这一整套低风险试错机制。** 只给一次小批量、后续仍压大货的供应商，支持力度其实不够。
