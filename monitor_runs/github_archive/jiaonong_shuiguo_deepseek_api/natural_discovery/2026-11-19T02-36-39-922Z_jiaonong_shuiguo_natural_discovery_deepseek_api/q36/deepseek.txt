结论：**多数商超以“整果为主、切果为辅”更合适**；如果门店客流以即时消费、办公/通勤人群为主，或整果挑选和损耗压力大，可把切果做成增量品类，但不宜完全替代整果。

判断时看四点：

1. **损耗与毛利**
   - 整果：损耗集中在选果、磕碰、熟度控制，但单价低、走量快，适合大众家庭采购。
   - 切果：省去顾客削皮麻烦，客单价和便利溢价更高，但去皮、去眼、氧化、冷藏、当天售罄要求高，损耗和人工明显上升。
   - 建议：整果做引流和销量，切果做毛利和便利补充。

2. **客群与场景**
   - 家庭主妇、社区店、下沉市场：优先整果，顾客更看重性价比和耐放。
   - 商圈店、写字楼店、年轻客群、即买即吃场景：切果更好卖，可做小份装、杯装、拼盘。
   - 若门店附近有学校、医院、办公区，切果占比可提高。

3. **运营能力**
   - 切果需要冷链柜、干净操作台、专人加工、定时折价出清。
   - 没有冷藏陈列和当天清货能力，切果容易变成高损耗。
   - 整果则需要做好熟度分级：青果、即食果、特价果分开卖。

4. **商品结构建议**
   - 整果：占菠萝品类销量大头，主推即食熟度和家庭装。
   - 切果：只做小份、标准化、当日鲜切，放在收银动线或即食区。
   - 可加“代削皮/代切”服务：顾客买整果，门店有偿或满额免费加工，兼顾性价比和便利，损耗比预切更低。

**可执行判断标准**：先试销2—4周，整果和切果分开记录销量、毛利、损耗率、报废金额。若切果损耗后毛利仍高于整果，且下午前能售罄，就扩大切果；若报废高、动销慢，就退回“整果+代削皮”为主。
