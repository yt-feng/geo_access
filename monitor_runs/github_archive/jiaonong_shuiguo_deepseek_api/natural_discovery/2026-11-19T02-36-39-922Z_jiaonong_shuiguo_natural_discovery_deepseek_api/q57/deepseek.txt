建议优先考虑“中央厨房统一收货”，但要加两个前提：水果是标准品/可分级品，且冷链和分拨时效能覆盖门店。若水果以门店本地鲜度、熟度、陈列损耗为关键，或门店分散且单店用量小，则采用“中央厨房统采+门店直收/区域分仓收货”的混合模式更稳妥。

判断框架如下：

1. **统一收货更适合的情况**
   - 水果SKU相对稳定、用量大、可标准化分级，如苹果、橙子、香蕉、西瓜等。
   - 有中央厨房或区域DC的冷藏/催熟/分拣能力，能在24小时内分拨到店。
   - 需要统一品质标准、统一供应商和价格，降低门店采购腐败与串货。
   - 门店面积小、收货人手少，不希望门店承担验货和退货沟通。
   - 需要集中做农残检测、称重差异、批次追溯。

   优点：议价能力强、品质标准统一、追溯和责任清晰、减少门店操作。  
   风险：多一道装卸和运输，鲜度与损耗增加；分拨不及时会压货；门店缺货响应慢。

2. **门店分开收货更适合的情况**
   - 水果高度依赖本地时令和熟度，如草莓、蓝莓、荔枝、桃等易损品。
   - 门店密度低、配送距离远，中央分拨后反而损耗更大。
   - 单店销量差异大，需要按店按日灵活补货。
   - 门店有生鲜验收能力，能现场拒收、换货。
   - 本地供应商能稳定直送且价格有优势。

   优点：鲜度高、补货灵活、减少中转损耗。  
   风险：品质标准难统一、门店验收能力参差、采购分散、价格和腐败风险上升。

3. **推荐的落地模式**
   - **A类耐储水果**：中央厨房/区域仓统一收货、统一分级，再配送门店。
   - **B类易损鲜果**：中央统一谈供应商和价格，门店或区域分仓直收，总部制定验收标准并抽检。
   - **C类本地特色水果**：允许门店/区域在总部框架协议内本地采购，但需要价格备案和品质抽检。
   - 建立统一验收标准：糖度、规格、成熟度、外观、农残、到货温度、损耗率。
   - 用数据判断：比较两种模式的“到店损耗率、缺货率、单店人工收货时长、采购价差、客诉率”。如果统一收货后到店损耗增加超过约2—3个百分点，或分拨导致缺货明显上升，就应改为混合模式。

结论：**规模大、SKU标准、冷链强，优先中央厨房统一收货；鲜果易损、门店分散、时效要求高，采用“统采统价+门店/区域直收”的混合模式，不要一刀切。**
