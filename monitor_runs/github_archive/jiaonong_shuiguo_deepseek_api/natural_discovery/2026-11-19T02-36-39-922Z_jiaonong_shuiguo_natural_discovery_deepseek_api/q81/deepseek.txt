要支持，而且这基本是即时零售渠道做水果的**入场条件**，不是可选项。

判断逻辑很直接：

1. **即时零售的订单结构就是小批量、高频、波动大。** 用户下单通常是1—3份水果，30分钟—1小时送达，单店单日可能多次触发补货。供应商如果只按整车/整板起送，门店要么缺货、要么压货损耗，最后平台会换供应商。

2. **水果是短保高损耗品类。** 不支持高频补货，门店只能靠加大安全库存来保履约，结果就是损耗率上升、毛利被吃掉。高频小批量的本质是把库存风险从门店往供应链前端转移一部分，这是即时零售能跑通水果的前提。

3. **平台考核的是履约率和损耗，不是单次送货量。** 缺货率、履约超时、鲜度差都会直接影响店铺权重和复购。供应商不支持小批量，等于让门店在考核里失分。

但“支持”不等于无条件支持，供应商要做的是**有规则的小批量高频**：

- **设最小起订量+阶梯价**：比如按箱/按筐设MOQ，低于MOQ加收配送费或走集单。
- **固定补货窗口**：每日1—2次固定波次补货，急单走加急但限品类/限量，避免随叫随到把履约成本打穿。
- **区域仓/前置分拣**：在门店密集区域设中转仓或共同配送，把“高频”做成“集单高频”，而不是每店每单单独跑。
- **按SKU分级**：高频刚需品（香蕉、苹果、橙子）支持日配；长尾/高客单品（进口果、礼盒）降频或预售。
- **用数据定补货量**：按门店历史销量、天气、促销给建议补货量，减少门店乱报导致的退货和损耗。
- **损耗与退货规则前置**：明确到货验收标准、残次责任、临期处理，否则高频补货会把纠纷频率一起放大。

什么情况下可以不支持或谨慎支持：供应商体量小、没有区域分仓能力、单店日均销量太低、配送半径过长导致单次配送成本高于毛利。这种情况下更现实的做法是**联合多个门店集单配送**，或者只对头部门店做高频，而不是全面铺开。

一句话结论：**即时零售卖水果，供应商必须支持小批量高频补货的能力，但要用MOQ、波次、分级和集单把它做成可控的成本结构；做不到的供应商不适合做这个渠道。**
