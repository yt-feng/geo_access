小商家采购水果，现金结算和月结账期各有风险，核心差别是：**现金结算把风险放在“货和钱当场是否对得上”，月结把风险放在“账期内的信用和现金流”。**

**一、现金结算的风险**
1. **质量与数量当场难追溯**：水果易损耗，现金付完后发现短斤少两、以次充好、内部腐烂，追责和换货难度较大。
2. **资金占用和假币、找零风险**：大额现金携带不安全，需防假币、错账、找零纠纷；现金流出后周转空间变小。
3. **无账期缓冲**：当天采购当天付款，若销售不及预期，损耗和压货风险全由自己承担。
4. **凭证不足**：现金交易若没有规范单据，后续对账、退货、税务和维权都缺少证据。
5. **采购人员道德风险**：现金经手环节多，容易出现虚报价格、私拿回扣或账实不符。

**二、月结账期的风险**
1. **信用风险**：供应商可能因你拖欠、逾期而停供、涨价或降低供货优先级；严重时影响旺季供货。
2. **现金流风险**：水果销售回款快但损耗大，若月结到期集中付款，容易形成短期资金压力。
3. **对账纠纷**：送货单、退货单、损耗扣款、价格变动若记录不清，月底容易扯皮。
4. **隐性成本**：月结价格可能高于现金价，或附带最低采购量、指定品类等条件。
5. **依赖单一供应商**：账期越舒服越容易依赖一家，一旦对方断供，短期切换成本高。

**可执行建议**
- 现金采购：坚持**当场验货、称重、留样/拍照、开规范收据**，大额尽量转账留痕；对易腐品分批少量采购。
- 月结采购：签简单书面协议，明确**账期、对账日、付款日、退货和损耗扣款规则**；每车货签送货单，定期对账。
- 组合使用：**畅销易耗品可现金锁价，常规品类用短账期**；不要把所有采购押在一种结算方式上。
- 设底线：现金采购不超过当日预算；月结欠款不超过可承受的**7—15天销售额**，并预留至少一期账期的现金。

简单判断：**看重价格和现货可控，用现金但把验收凭证做足；看重现金流和稳定供货，用月结但把对账和付款纪律做严。**
