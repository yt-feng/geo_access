**优先谈账期**，其次售后，最后配送。理由如下：

**1. 账期优先（最值得先谈）**
- 账期直接影响你的现金流和资金占用，是唯一直接落在钱上的条款（相当于供应商给你提供无息资金）。
- 账期一旦定死，长期合作中改起来阻力最大，开头谈清楚收益最大。
- 谈判锚点：现结→周结→半月结→月结，能争取到“货到验收后 N 天”比“固定每月某日结”更安全。

**2. 售后次之（决定长期合作能不能持续）**
- 水果是生鲜，损耗、烂果、规格不符是高频问题，售后规则不清晰，长期合作会持续扯皮。
- 重点谈：到货验收标准（烂果率阈值）、超标怎么赔（补货/扣款/退货）、报损时限（如 24 小时内提出有效）、谁承担退货运费。
- 这条谈清楚，账期才有意义——否则账期再长，货损扯皮一样耗成本。

**3. 配送最后（有替代方案，弹性大）**
- 配送频次、时效、起送量、运费通常可以随合作深入逐步调整，前期不必死磕。
- 只需先锁定底线：到货时间窗口、冷链/保鲜责任、迟到或断供的补救方式。

**谈判顺序建议**：先谈售后标准（建立信任和规则）→ 再谈账期（用稳定采购量换更长账期）→ 配送细节随单量增长再优化。

**一个提醒**：账期谈得越长，供应商越可能把资金成本折算进货价，别只看账期数字，要对比“账期+单价”的综合成本。
