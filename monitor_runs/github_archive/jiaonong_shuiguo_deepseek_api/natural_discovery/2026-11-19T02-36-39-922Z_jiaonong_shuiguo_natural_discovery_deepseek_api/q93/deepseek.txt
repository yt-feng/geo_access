优先看**配送频次和门店操作规范**，包装和保质期是并列的硬约束，不能只盯一个。按优先级给你可执行判断：

1. **配送频次/补货节奏最关键（决定风险上限）**
   - 菠萝切块属于高水分、易氧化、易受微生物污染的鲜切水果，风险不在“保质期标签”，而在**切开后的时间与温度累积**。
   - 如果门店日均销量小、配送频次低，容易出现“切了卖不完、反复冷藏、临近保质期打折”的循环，损耗和食安风险都高。
   - 建议：按门店销量分组设定补货频次；高销量店每日配送/隔日配送，低销量店减少切块规格或改为整果现切。

2. **包装是第二关键（直接影响货架期）**
   - 必须用**食品级、密封性好的包装**，最好有防氧化/防串味能力；标签要能贴牢、不易被冷凝水泡花。
   - 包装不密封会导致氧化变色、失水、交叉污染，保质期标得再短也难控。
   - 建议：统一包装规格和封口标准，门店不得裸卖或简易保鲜膜随意包。

3. **保质期是结果指标，不是唯一管理点**
   - 鲜切菠萝的保质期应基于**冷链温度、切分卫生、包装方式**验证后设定，不能照抄供应商标签。
   - 建议设“**切开时间+废弃时间**”双标签，临期前打折或下架；超过时限直接废弃，不做二次冷藏续命。

4. **配套必须盯的三件事**
   - **冷链温度**：冷藏柜温度记录，切块存放不超过规定温度。
   - **门店切分卫生**：刀具、砧板、手套、消毒频次。
   - **先进先出与陈列量**：小批量多频次上架，避免久放。

**结论**：如果只能选一个重点，选**配送频次/补货节奏**，因为它决定切块在门店的周转速度；但包装和保质期必须同时达标，否则频次再高也控不住食安和损耗。建议用“销量—配送频次—包装规格—保质期验证”四件套一起管理。
