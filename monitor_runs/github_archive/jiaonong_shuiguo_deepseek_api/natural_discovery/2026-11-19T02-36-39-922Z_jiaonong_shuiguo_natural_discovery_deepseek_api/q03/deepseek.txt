# 第一次试单，核心是"小批量、分开验、留退路"

**试单原则**：首单每样只拿**1件（箱/筐）**，别听"整板便宜"就囤。香蕉、苹果、橙子损耗特性不同，要分开验。

---

## 一、香蕉（最难伺候，最该谨慎）

- **只拿1箱青蕉**（7成熟左右），别拿黄蕉。黄蕉到你手上基本只剩2天货架期。
- **开箱数"把"**：看有没有散把、断指、机械伤。问清"净重"还是"毛重"，香蕉行规常按毛重报，实际差不少。
- **催熟问清楚**：供货商是否代催熟、催熟后到店要几天。自己催熟要有条件（温度15–18℃、通风），夫妻店没条件就找"催熟好、当天能卖"的。
- **验收标准**：整箱无黑斑、无霉点、把型完整。

## 二、苹果（最耐储，适合放大试单量）

- 可以拿**2–3箱**，试"耐放度"和"回头客反应"。
- **看箱底**：抽查最下面一层，防止上面好下面烂/小果。
- **问产地和规格**：同样"红富士"，80果和75果差价明显，按个卖还是按斤卖要匹配你的定价。
- **验收**：硬实、无软塌、无碰伤，切开看有没有"糖心"或内部褐变（挑1–2个切）。

## 三、橙子（看皮、看汁、看掉秤）

- 拿**1–2箱**，重点看**皮厚薄和水分**。
- **现场切1个**：榨一下，汁水足的才留。皮厚、干瘪的别要。
- **问打蜡和保鲜处理**：打蜡橙卖相好但部分顾客介意，心里要有数。
- **验收**：果皮紧实、无软斑、掂着有分量（掉秤严重的说明放久了）。

---

## 试单动作清单（照着做）

1. **先谈"试单价+账期"**：首单现金或短账期，别一上来就压款；问清"不好卖能不能换/退"，哪怕只换一部分。
2. **每样单独开箱验**，不当场开箱的货不签收。
3. **称重核对**：随机抽1箱过秤，对比报价单的净重，算出真实单价。
4. **记损耗**：试单后3–5天记下每样烂了几个、掉了多少秤，作为下次谈判依据。
5. **同时找2家**：一家主供、一家备选，防止断货被拿捏。

**一句话**：香蕉少拿快验、苹果适量看箱底、橙子切开看水分，首单宁少勿多，用损耗数据决定第二次进多少。
