可以，但要看你和供应商的合作层级、采购量、账期和结算方式。一般能争取到三类支持：

1. **价格支持**
   - 周末短期促销价、临时返利、满量返点、特价单品。
   - 越是你稳定采购、走量大的品类，越好谈；新供应商反而更愿意给首促支持。
   - 常见形式是“限周末/限单品/限数量”的特价，而不是全面降价。

2. **物料支持**
   - 陈列筐、价签、海报、试吃台、围裙、遮阳棚、促销贴纸等。
   - 品牌水果或包装类供应商更常给物料；散货批发商通常物料少，但可给价签和陈列建议。

3. **其他支持**
   - 账期放宽、滞销换货/补损、送货频次增加、派促销员或试吃人员。
   - 这些对水果店周末促销往往比单纯降价更实用。

**怎么谈更有效：**
- 提前1—2周沟通，明确周末档期、主推单品、预计采购量和促销价。
- 直接给供应商两个方案：A“你给特价，我加大陈列和主推”；B“你给物料/试吃，我承担场地和人工”。
- 优先找你想主推的单品供应商，用“周末集中走量+后续稳定采购”换短期支持。
- 把支持写清楚：价格有效期、数量上限、物料谁出、何时到位、滞销怎么处理。

**判断能不能要到：**
- 你月采购稳定、单品走量大、结款准时：通常能要到价格或物料。
- 你采购分散、量小、临时拿货：价格支持较难，物料可试着要价签/海报，别期待太高。
- 供应商本身在做品牌推广：物料和试吃支持更容易谈。

建议先列3—5个周末主推单品，分别找对应供应商谈“限时特价+物料+补损”组合，不要只问“能不能便宜点”。
