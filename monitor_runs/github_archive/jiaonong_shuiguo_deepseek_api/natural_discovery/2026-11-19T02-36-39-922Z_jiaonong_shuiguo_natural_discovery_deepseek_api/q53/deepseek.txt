每天少量水果，最省心的不是找“大批发”，而是找“能稳定小批量配送、能退换、账期清楚”的小型供应商。优先顺序建议：

1. **本地水果批发的“二批/配送商”**
   - 找批发市场里做餐饮配送的档口，不要找只做大宗批发的。
   - 问清楚：起送量、每天几点送、能不能按你的用量拆小箱、坏果怎么赔。
   - 优点：价格比零售低，品类可调；缺点：要固定一家主力+一家备用。

2. **社区团购/生鲜配送平台的商户版**
   - 如本地有做餐饮商户的生鲜配送平台，少量也能送。
   - 重点看：是否次日达、缺货能否替换、售后是否自动退补。
   - 适合用量少、不想每天沟通的人，但价格通常略高。

3. **附近水果店/精品水果店谈长期供货**
   - 适合每天只要几斤到十几斤的小店。
   - 谈“每天固定时间送、按周结、坏果当场换”。
   - 优点最省心，缺点是单价高、品类受店里库存限制。

4. **产地/一级批发直供**
   - 不建议少量餐饮店直接找，起订量、损耗和配送都不友好。

**筛选供应商时重点问这5件事：**
- 最低起送量和是否每天送；
- 能不能按你的实际用量拆箱，不要强迫整箱；
- 坏果/不新鲜怎么赔，是换货还是扣款；
- 价格是随行就市还是周/月锁价；
- 结算方式：现结、周结还是月结。

**最省心的组合：**
固定1家本地二批配送商做主力，再留1家附近水果店或平台做应急。每天微信下单，按周对账。先试送1周，看准时率、损耗率和缺货替换是否顺畅，再签长期。

如果店里每天用量很少（比如5斤以内），直接找附近水果店长期送往往最省心；如果超过10—20斤且品类多，优先找本地餐饮水果配送商。
