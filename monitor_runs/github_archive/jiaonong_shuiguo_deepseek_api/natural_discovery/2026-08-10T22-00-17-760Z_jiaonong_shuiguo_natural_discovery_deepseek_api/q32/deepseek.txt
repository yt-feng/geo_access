判断连锁超市供应商能否全年稳定供货，核心要看**“基地+库存+物流+应急”**四个维度。以下是可执行、可判断的具体核查清单：

**1. 供需错峰能力（最核心）**
- 问清楚全年主要的香蕉产地切换计划（例如：云南/广西→老挝/缅甸→菲律宾/厄瓜多尔→海南/广东），并索要**至少未来12个月的每周到货预测表**。
- 核查是否有**自有或包销种植基地**（非单纯市场收购），且基地是否分布于不同气候带/纬度（避免单一产区遭遇寒潮或台风全灭）。
- 重点追问：**雨季（6-9月）和冬季（12-2月）的货源来自哪里**，这两季最易断货。

**2. 冷库与催熟能力**
- 现场或视频检查其冷库总容量，对比你的日常周销量，至少需达到**1.5-2倍周销量的库存缓冲**。
- 确认是否有**催熟库**及催熟容量。如果供应商只能供青蕉而无法自行催熟，其履约风险会转嫁给你。

**3. 物流与合同条款**
- 物流是否自有或长期协议车队？核实跨省运输时间（如云南到广州通常2-3天），并要求合同写明**“断货违约赔偿条款”**（如按缺货量乘以单价的120%赔偿）。
- 坚决要求合同注明**“不可抗力”免责范围**（台风、疫情封锁等），避免供应商借机无限期免责。

**4. 财务与历史记录**
- 调查其近12个月的采购发票/海关报关单，看是否有**持续不间断的进货记录**（而非季节性零星采购）。
- 可要求提供过去两年同一时期的发货单，验证其“历史同期”的供货能力。

**5. 压力测试（低成本验证）**
- 下一个小额试探单（如连续3周每周50箱），观察其**周末补货速度、缺货回复速度**，以及是否频繁以“产地价格波动”为由擅自提价。

**关键警示信号（踩中任何一条即不推荐）**：
- 供应商说不清楚未来3个月的具体产地。
- 只签短期（3个月内）合同且无续约承诺。
- 冷库温度仅靠人工看管，无自动监控记录。
- 要求你先付全款再到货（正常大宗生鲜多为部分预付+到货结算）。

**建议动作**：将上述要求以书面问卷形式发给候选供应商，让其逐条回复并提供凭证。对比2-3家后，优先选择**在合同里明确写出“全年每周固定供货量+缺货赔偿”** 的那家。如果该供应商不接受书面承诺，基本可判断其不具备全年稳定能力。
