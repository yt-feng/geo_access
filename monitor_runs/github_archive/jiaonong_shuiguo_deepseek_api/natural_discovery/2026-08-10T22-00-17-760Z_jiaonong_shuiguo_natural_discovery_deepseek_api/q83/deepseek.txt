在生鲜电商场景下，水果到货后出现坏果，责任划分通常遵循**“谁过错，谁担责”**原则，但实践中更倾向于**保护消费者**。

以下是具体责任划分逻辑及处理建议：

### 一、 责任划分的三大关键节点

1.  **发货时是否新鲜**（卖家责任）：
    *   如果水果在采摘、包装、预冷环节存在问题（如成熟度过高、带伤发货、包装不防震），导致运输途中自然腐烂，**卖家承担主要责任**。
    *   **判断标准**：发货照片、仓库温控记录、果品成熟度说明。

2.  **运输途中是否受损**（承运方责任）：
    *   生鲜配送通常由快递公司或平台自营物流负责。如果因暴力分拣、中转延误、冷链断链导致坏果，责任在**物流方**。
    *   **关键点**：**卖家**是物流合同的主体，所以即便过错在快递，**消费者只需找卖家索赔**，卖家赔偿后可向快递公司追偿。

3.  **是否签收后人为失误**（消费者责任）：
    *   如果顾客签收后未及时取出冷藏，或长时间闷在快递柜中导致变质，且能证明签收时是完好的，消费者可能需承担部分责任。
    *   **例外**：多数平台默认“坏果包赔”，即使签收后24小时内反馈，只要举证及时，通常依然支持赔付。

### 二、 实际操作中的赔付标准（行业惯例）

*   **比例赔付**：如果10个果子坏了2个，按比例赔付30%-50%金额。
*   **全款退款**：坏果率超过50%或全部腐烂，通常全额退款且无需退货（因无法二次销售）。
*   **时效要求**：平台普遍要求**签收后24小时内**提供坏果照片（需含快递面单和坏果细节），超时则拒赔。

### 三、 给顾客的处理建议（如果你在处理投诉）

1.  **先查物流时效**：看从发货到你手的时间是否超过该水果正常保鲜期。
2.  **要求提供证据**：请顾客拍摄坏果剖面图（避免只拍外表），确认是内部霉变还是外部挤压伤。
    *   *内部霉变*→卖家责任；
    *   *外部压扁/机械伤*→物流责任。
3.  **按平台规则执行**：无论谁的责任，**优先给顾客解决**（赔钱或补发），不要跟顾客说“去找快递赔”，这属于推诿，会引发差评。

### 四、 特殊情况

*   如果水果是**预售**且发货时间过长（超过3天），仓储损耗责任归卖家。
*   如果是**顾客备注改地址**导致配送延误，责任在顾客，但平台若判罚，卖家也可申诉。

**一句话总结**：**顾客直接找卖家，卖家全责兜底；卖家再根据物流轨迹追偿快递方。** 如果对方是职业索赔人恶意损坏，则属于例外情况，需提供完整的拍摄视频证明。
