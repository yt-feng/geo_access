在水果采购中，现金结算和月结账期（供应商给30天或45天账期）各有不同风险，下面列出关键点以便你判断：

**一、现金结算（即时付款）的风险**
- **资金占压**：一次性付清货款，如果水果损耗大（如易烂的草莓、荔枝），这部分钱会立刻变成沉没成本。
- **质量风险**：货款已付后，若到货后发现品质不达标、缺斤少两，追讨或换货难度较高，因为供应商已拿到钱，谈判筹码弱。
- **无账期缓冲**：一旦遇到天气突变、市场行情暴跌，库存水果卖不出去，损失全部自己承担，没有现金流缓冲。

**二、月结账期（先货后款）的风险**
- **坏账风险**：如果供应商实力弱或信誉一般，可能存在货已卖出、但之后供应商跑路或停供给货，导致后续补货中断。
- **账务管理压力**：需要建立台账记录每笔进货日期、金额、到期日，逾期忘记付款会失去账期资格，甚至被加收违约金。
- **供应链话语权弱**：小商家通常是“先款后货”或者“现结”，能拿到账期往往意味着你必须是该供应商的稳定大客户；如果突然被停账期，短期资金流会紧张。
- **隐含利息成本**：月结并非免费，通常供应商会把账期成本折算进单价（即同品质水果，账期采购价比现结价高几个点），需计算总成本。

**三、实操建议**
- 如果供应商可提供“现结价”和“账期价”，建议优先选**现结小批量多频次**，控制单次库存，避免资金压死。
- 对高价易损耗水果（葡萄、车厘子）尽量现结，并在收货当天开箱验货。
- 对常规耐储水果（苹果、橙子、梨）可尝试谈“小额月结”（如首批现结，第二期起月结），并约定“逾期付款违约金”和“品质问题无条件退货”条款，写入合同或微信留凭证。
- 不要同时给多个供应商欠款，最多保持1-2家账期，防止集中爆雷。
