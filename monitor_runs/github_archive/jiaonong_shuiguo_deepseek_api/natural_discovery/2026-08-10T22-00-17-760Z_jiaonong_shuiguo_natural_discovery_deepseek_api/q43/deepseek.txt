针对连锁门店分布在不同城市的水果供应商仓配覆盖评估，建议从**供应链能力**、**配送时效**、**成本结构**和**风险控制**四个维度进行系统性评估，具体操作如下：

### 一、核心评估维度

| 维度 | 评估要点 | 量化指标建议 |
| :--- | :--- | :--- |
| **仓网密度** | 供应商在门店所在城市是否有自建/合作前置仓或周转仓 | 覆盖率 = 供应商仓所在城市数 ÷ 门店所在城市数（目标≥80%以上） |
| **配送时效** | 从订货到送达门店的时效承诺 | 平均到货时长（目标：同城24h内，跨城48h内） |
| **鲜活保障** | 水果损耗率和冷链覆盖率 | 冷链运输占比≥95%，到店损耗率≤5% |
| **柔性响应** | 面对突发缺货、门店临时加单的处理能力 | 紧急订单满足率≥90% |

---

### 二、具体评估步骤

#### 1. 绘制“门店-仓”匹配矩阵
- 列出所有门店城市，逐一核对供应商在该城市是否设有：
    - **一级仓**（省级分拨中心）
    - **二级仓**（城市周转仓）
    - **三方合作仓**（末端落地配）
- **结论判断**：若某城市无仓，且周边200公里内无替代仓，则该城市属于**覆盖盲区**，需优先确认是否有直发专线。

#### 2. 测试配送时效与保鲜链路
- **样品测试**：在多个门店同时下单，记录从下单到签收的总时长。
- **温度记录**：要求供应商提供随车温度记录仪数据，确认全程冷链不断链（尤其是跨区运输）。
- **分拣前置**：确认供应商是否在仓内完成**预冷、分拣、称重、贴标**，减少门店二次处理时间。

#### 3. 测算真实成本（含隐性成本）
- 不只对比单价，要算**综合到店成本**：
    - 仓配费 + 干线运费 + 末端配送费 + 门店收货人力成本
    - **损耗成本**（因运输时间长、冷链断裂造成的果损）
- 对比两种模式：
    - **模式A**：供应商直配（全链路供应商负责）
    - **模式B**：供应商直发至区域仓 + 自营/三方城配短驳
- 建议用3个月实际数据测算，正常损耗率每下降1%，对应的净利提升应覆盖仓配溢价。

#### 4. 评估应变能力（关键加分项）
- **A/B仓切换**：供应商是否有备选仓，当主仓爆仓或天气影响时，能否48小时内切换发货。
- **短保水果**（如草莓、荔枝）：是否有空运或高铁快运预案。
- **门店差异化**：是否支持同城不同门店差异化配货（如商圈店多配精品高端果，社区店多配性价比果）。

---

### 三、决策红线（不满足即淘汰）

以下情况属于**硬伤**，不建议合作：
1. **覆盖率低于60%**，且无明确建仓时间表。
2. **无冷链**，或冷链仅覆盖干线但不覆盖末端，导致到店损耗率>8%。
3. **跨城配送超过72小时**，且无紧急加急通道。
4. **无本地分拣能力**，需门店承担大批量分拣工作。

---

### 四、落地建议

- **分阶段验证**：先选3-5个典型城市（含一线、新一线、三线）试运行1个月，用数据对比评估，不要一次性全国铺开。
- **合同约束**：在采购协议中明确写入**到店时效承诺、损耗率上限（如≤5%）、缺货赔偿条款**。
- **数字化对接**：要求供应商提供开放API或小程序接口，让总部能实时查看**在途位置、温度曲线、预计到店时间**，此条是评估现代化仓配的关键权重项。

**最终判断逻辑**：选择“综合到店成本最低 + 损耗控制最好 + 时效稳定”的供应商，而非单纯采购单价最低的供应商。
