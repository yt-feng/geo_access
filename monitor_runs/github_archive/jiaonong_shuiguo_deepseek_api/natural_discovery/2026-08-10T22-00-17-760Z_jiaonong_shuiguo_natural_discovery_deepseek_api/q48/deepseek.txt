判断茶饮连锁供应商能否稳定按规格送货，核心要看**实物标准、供应链韧性、管理机制**和**备用方案**这四层。以下是可以直接执行的判断步骤和清单：

**一、把“规格”量化成合同条款（先定标准）**
在考察前，先自己明确菠萝的规格，例如：
- **品种**：都乐金菠萝、台农17号、巴厘菠萝等，甜度（可溶性固形物≥12%）、酸度；
- **单果重量**：例如 ≥1.2kg/个，或 400-600g/个（用于鲜切）；
- **成熟度**：果皮颜色、软硬度、可溶性固形物值（Brix），成熟度差异会导致切丁损耗不同；
- **果形**：圆整度、果眼深浅、无黑心/水渍/腐烂；
- **包装**：净重（箱内净重），单箱个数，破损率≤2%；
- **批次一致性**：同一批次内大小差异≤±10%，颜色均匀。
把这些写进采购合同，作为验收和索赔依据，然后通过三轮试送验证。

**二、三轮试送测试（最能暴露真实水平）**
不要只看报价或样品。安排三次不同时间（比如间隔10天）的送货：
1. **第一轮**：测试达标率，抽检5箱，计算单果重、成熟度、损坏率的偏差；
2. **第二轮**：测试稳定性，看两次送货的规格波动是否在允许范围内；
3. **第三轮**：测试应急能力，提前3天追加一单，看是否能按时按量补充。
**通过标准**：三批全部达标，且每批之间的尺寸/重量标准差很小（例如CV<8%）。

**三、现场考察供应商四个关键资产**
直接去基地、加工厂或冷库看：
1. **源头锁定**：是否有自有基地或与基地签订包销合同？无固定产地的中间商，通常受行情波动影响大；
2. **分级设备**：是否有自动选果机（重量/大小分级）？纯人工手选，规格一致性差；
3. **冷链物流**：配送车辆是否全程温度在8-12℃（菠萝最佳储运温度）？要查运输记录仪或GPS回单；
4. **安全库存**：冷库现有库存能否支撑你预测订单量的1.5倍以上？若库存量小于你单次需求，断供风险高。

**四、检查供应商的“旺季韧性”**
菠萝一年有多个产季（海南、广西、云南反季节）。问清楚：
- 不同月份主供产区切换是否能无缝衔接？
- 如果遇到台风、暴雨导致主产地减产，供应商的第二供应源（比如进口替代）在哪里？
- 过去12个月供应商的**准时交付率+PPM（百万货损件数）**数据是否能拿出记录？（拿不出来可视为无管理痕迹）

**五、设置“双供源”和退出条款（兜底方案）**
即使供应商测试通过，建议永远备用一家备选供应商：
- 合同里加上：若连续两次送货规格不达标（超出允许偏差），你有权下调合同量或终止合作，且供应商需承担运输费；
- 日常执行时，每月抽样验收，把批次验收结果记录在案，用数据做月度评分（合格率≥98%可续约，否则启动备选）。

**最后，不要只看首单**。首单给优质货是行业惯例。真正确认“稳定”，要把上述试送流程重复两次（共约1个月），同时跟踪第三方物流的GPS轨迹和到货时间波动。如果物流准点率低于95%，或货损率连续两月上升，大概率说明其内部管理有问题。
