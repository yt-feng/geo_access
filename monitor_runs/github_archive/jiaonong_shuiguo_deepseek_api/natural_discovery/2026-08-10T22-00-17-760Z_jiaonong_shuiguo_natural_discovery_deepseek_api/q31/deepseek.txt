在连锁商超的长期水果供应商招标中，评分标准的核心应围绕**“稳定供货能力”**、**“品质与安全”**、**“成本与账期”**以及**“应急与履约”**四个维度。因为水果是生鲜品，损耗快、季节性强，因此评分标准与普通百货招标有显著不同。

以下是具体的评分标准设置建议（建议采用百分制）：

### 一、 商务资质与综合实力（权重约15%）
-   **企业规模与基地资源（6分）**：要求供应商提供自有或合作种植基地证明（如土地流转合同、合作社协议）。优先考虑拥有稳定货源基地，而非纯采购批发型的供应商。
-   **资质与认证（5分）**：食品经营许可证、农产品合格证、绿色食品认证或有机认证等。拥有GAP（全球良好农业操作规范）认证加分。
-   **行业经验（4分）**：近三年服务过大型商超（如永辉、沃尔玛、大润发等）的合同证明或案例清单。

### 二、 产品质量与食品安全（权重约30%）
这是商超最核心的底线，权重必须最高。

-   **品控体系（10分）**：供应商是否拥有独立的质检团队及农残快检设备？能否提供每批次的检测报告。
-   **分级包装标准（10分）**：要求明确水果的规格（如芒果的单果克重、糖度范围）、成熟度标准（如香蕉的催熟度控制），以及对包装材料（如防震网套、吸水纸）的标准化要求。评分时看其方案是否具体可行。
-   **可追溯性（10分）**：是否支持二维码溯源，能追溯到具体产地、采摘日期和运输批次。

### 三、 供货能力与履约保障（权重约25%）
针对长期合作，重点考察其抗风险能力。

-   **冷藏/冷链物流能力（10分）**：是否拥有自有冷链车或稳定的第三方冷链合作，以及从产地到门店的时长承诺（例如：采摘后24小时内送达配送中心）。
-   **多品类供应能力（5分）**：是否能提供“一站式”的水果采购（即能同时供应苹果、柑橘、热带水果等），这有助于商超减少对接成本。
-   **供应稳定性与“备胎”机制（10分）**：请供应商阐述当主产区遭遇灾害或价格暴涨时，是否有备用货源地的替换方案。评分时看方案的响应速度和可操作性。

### 四、 价格与商务条款（权重约20%）
-   **价格竞争力（10分）**：建议采用“每周或每月联动定价”机制。评分时重点看其**报价单价的含杂率、净果率**，以及承诺的**价格浮动幅度上限**（例如：批发市场均价±5%以内）。
-   **账期与费用（10分）**：给商超的账期天数（如30天、60天）、是否支持“先货后款”的试销期，以及能否承担部分入仓费和陈列损耗补偿。

### 五、 售后服务与营销支持（权重约10%）
-   **损耗退换货机制（5分）**：明确规定因非商超人为原因导致的腐烂、变质水果，供应商承诺的包退换比例和时间（例如：24小时内响应）。
-   **营销配合度（5分）**：在节假日（如春节、中秋）或新品上市时，供应商能否提供促销资源（如试吃装、促销物料或专项价格补贴）。

---

### 额外建议（请在标书中体现）：

1.  **设立“安全门槛”**：建议将**“无农残超标记录”**和**“无重大违约史”**设为资格预审的否决项，而非评分项。如果某供应商分项得分再高，但历史有食安问题，直接淘汰。
2.  **样品盲评环节**：技术部分（质量和口感）建议采用暗标评审，让评委盲测水果样品，按甜度、口感和新鲜度打分，以避免价格分占主导导致“劣币驱逐良币”。
3.  **动态淘汰机制**：在合同签订后，建议设定季度考核，将“到货准时率”和“验收合格率”作为连续合作的核心KPI，这些可以在招标文件中作为附则写明，作为后续续约的依据。

**总结**：商超招标最担心的是“低价中标后断供”或“品质参差”。因此，请务必将**食品安全（30%）**和**供应链韧性（25%）**的权重设置高于单纯的**价格分（20%）**。这能筛选出真正有实力的长期合作伙伴。
