在超市卖菠萝时，**最需要优先关注的是“切果损耗”和“甜度”，其次才是外观，最后是大小**。理由如下：

1. **切果损耗（成本核心）**  
   超市利润极薄，菠萝去皮去眼后损耗很大（通常损耗率在30%～40%）。如果采购的菠萝果眼深、皮厚、形状不规则，切出来净重少，顾客抱怨“不划算”，同时增加人工和垃圾处理成本。**建议优先选择果眼浅、皮薄、圆柱形、成熟度一致的品种，能有效降低损耗。**

2. **甜度（复购与口碑）**  
   甜度直接决定顾客是否回头。菠萝有“酸度”和“糖度”两个指标，甜度高的（如糖度13%以上）更受欢迎。采购时可以抽检切开试吃，或看产地（菲律宾、泰国金菠萝，海南、广东台农品种通常更甜）。**宁可价格略高，也要保证甜度稳定。**

3. **外观（视觉吸引）**  
   外观影响第一眼购买欲。要求果皮金黄均匀、无黑斑、无烂点、叶片翠绿挺拔。**但外观可以轻度修饰（如套袋、摆放），甜度和损耗无法掩盖，所以外观排在第三。**

4. **大小（次要）**  
   大小主要影响定价和陈列。大果单价高但单个重量大，适合家庭；小果方便一人食。**不需要过度纠结大小，只要大小匀称、按重量卖即可，避免大小混杂导致顾客挑拣。**

**操作建议**：
- 进货时试切2～3个，记录损耗率和口感。
- 现场设置“切果服务”，将切好的菠萝用保鲜盒零售，损耗率可控时利润反而更高。
- 若主要面向年轻群体或办公场景，可主打“免切即食”的鲜切菠萝，此时损耗直接决定是否亏本。

**一句话结论**：**切果损耗 > 甜度 > 外观 > 大小**。采购时优先试切测损耗，再尝甜度，外观和大小作为筛选条件。
