在超市采购苹果和橙子时，判断大小规格是否适合门店销售，主要从**果径（厘米）**、**单果重**、**外观一致性**以及**消费定位**这四个维度来把握。以下是可落地的判断标准：

### 一、核心硬指标（用卡尺或目测）

**1. 苹果（以红富士/嘎啦为例）**
- **优质零售规格：果径 75mm ~ 85mm**。
  - **75mm**：适合家庭日常食用，走量快。
  - **80mm**：送礼、精品区首选，溢价空间大。
  - **85mm以上**：不建议常规货架大量囤，容易显得“过大”，除非做论个卖的礼盒装。
- **淘汰标准**：果径 <70mm，在门店容易显得“小气”，除非做低价引流款；果径 >90mm 且着色不均，容易有“空心”或“糖心不足”的风险。

**2. 橙子（以赣南脐橙/新奇士为例）**
- **优质零售规格：果径 70mm ~ 85mm**。
  - **70-75mm**：适合榨汁或散装称重，性价比高。
  - **80mm**：标准送礼规格，果皮紧实，口感最佳。
- **淘汰标准**：果径 <65mm 的果子通常皮厚、酸度高，不适合零售；果径 >90mm 的“大果”往往果皮过厚，水分流失快，容易“干渣”。

---

### 二、实操判断技巧（不用仪器）

1. **“一手握”法则（适用于苹果）**
   - 正常成年男性，大拇指和中指能相对握住苹果最粗处，且指间刚好留出**1指宽**的缝隙 → 果径约80mm，最理想。
   - 握不住 → 偏大；握起来空荡荡 → 偏小。

2. **“两指夹”法则（适用于橙子）**
   - 用食指和拇指轻轻夹住橙子最宽处，能轻松夹住且不费力 → 约70-75mm。
   - 夹住后手指不能合拢 → 偏大；一夹就陷下去 → 皮厚或过熟，不推荐。

---

### 三、门店销售适配性判断（关键）

| 门店类型 | 推荐规格 | 理由 |
|---------|----------|------|
| **社区生鲜店/菜场** | 苹果75-80mm，橙子70-75mm | 家庭主妇/老人采购，讲究性价比，太大浪费。 |
| **精品超市/进口水果区** | 苹果85mm+，橙子80mm+ | 送礼/高收入客群，重颜值和仪式感。 |
| **连锁便利店** | 苹果65-70mm（小果），橙子55-60mm（小果） | 单颗包装销售，一次吃完，不浪费。 |

---

### 四、容易踩的坑（务必规避）

- **只看个头，不看均匀度**：同一箱里如果大小混杂超过10mm，顾客会反复挑拣，导致损耗高。建议采购时要求**单规格占比达到90%以上**。
- **忽略果柄**：苹果果柄湿润有弹性 → 新鲜；橙子果蒂颜色鲜绿（若为带叶脐橙）→ 现摘。大小合适但果柄干枯，建议降级处理。
- **甜度与规格挂钩**：**苹果**“越大越甜”不成立，反而**80-85mm**的果糖度积累最足；**橙子****65-70mm**的小果往往酸度高，**75-80mm**是酸糖比平衡点。

---

### 五、快速决策清单（采购现场用）

✅ 苹果：果径在**75-85mm**之间 → 直接采购。  
✅ 橙子：果径在**70-80mm**之间 → 直接采购。  
⚠️ 苹果<70mm 或 >90mm → 只作为促销款，不占主货架。  
⚠️ 橙子<65mm 或 >85mm → 只能做“特价散装”，绝不进精品区。  

**最后一句话总结**：选**中间档**（苹果80mm、橙子75mm左右），永远最稳妥——进可攻（标高价）、退可守（打折卖）。
