在超市水果区做组合促销，核心是**“高频带动低频、季节性带动常规、价格锚定带动冲动”**。针对香蕉、菠萝、苹果这三类水果，我给你几个可直接落地的组合方案：

---

**方案一：早餐/健康场景组合（利润优先）**
- **组合内容**：香蕉2根 + 苹果1个（或2个） + 菠萝半个（切好装盒）
- **定价策略**：设一个“原价合计XX元，组合价XX元”（例如原价15元，组合价12.8元），但**重点包装“膳食纤维+维C”话术**。
- **理由**：香蕉是快消高频品（损耗率低），苹果是耐储常规品，菠萝是季节性高毛利品。这个组合覆盖了“搭配酸奶、燕麦”的早餐场景，客单价提升明显，同时菠萝的切盒加工能减少损耗、提升毛利。

**方案二：家庭分享/果盘组合（走量）**
- **组合内容**：菠萝1个（整只）+ 苹果4个（散装或网袋）+ 香蕉1把（约6根）
- **定价策略**：不要直接打折，而是**“买菠萝+苹果，香蕉半价”**（或赠品方式）。菠萝和苹果定价略高于成本，香蕉作为“钩子”打5折，顾客会感觉“占了便宜”，实际客单价很高。
- **理由**：家庭采购偏好“大份量”，菠萝整只看着值，苹果耐存放，香蕉半价能快速清库存。

**方案三：视觉堆头+限时组合（冲动消费）**
- **组合内容**：菠萝切块试吃 + 苹果切丁试吃 + 香蕉整根（带皮）
- **陈列**：在堆头旁边放一个“今日组合价”小黑板，例如“香蕉+苹果+菠萝=9.9元/份”（用制冰盒或小塑料碗装，每份是1/4菠萝+1个苹果+1根香蕉的切块）。
- **理由**：试吃触发食欲，切块减少顾客处理麻烦，9.9元定价是冲动线，适合晚餐时段或周末。

---

**执行细节（关键）：**
- **菠萝要提前“去皮切半”或“带皮整卖”**，切半的毛利高，整卖的损耗高，建议主推切半。
- **苹果选两种**：一种是普通红富士（走量），一种是高端品种（如阿克苏）做“加价换购”吸引决策。
- **香蕉要放在组合的最外侧或最下方**，因为它是“顺手加购”的首选，不要让菠萝遮住它。
- **促销话术**侧重“今天买回家马上能吃，不浪费”，避免让顾客觉得“买多了吃不完”。

---

**如果只能选一种，强烈推荐方案一**，因为它让菠萝（毛利高）带动了香蕉（快消）和苹果（耐储），且切盒菠萝能显著降低损耗，客单价提升最明显。
