在商超采购水果时，**损耗低**通常比**价格低**更影响最终毛利，尤其是在高损耗品类（如草莓、荔枝、香蕉）中。原因如下：

**1. 损耗对利润的杠杆效应远大于价格**
- **毛利公式**：毛利 = （售价 - 进价 - 损耗成本）÷ 售价。损耗直接吃掉“可售数量”。
- **举例**：假设进价10元/斤，售价20元/斤，进货100斤。
  - 若价格低5%（进价9.5元），但损耗高达20%（可售80斤）→ 毛利 = 80×（20-9.5）= 840元。
  - 若价格高5%（进价10.5元），但损耗仅5%（可售95斤）→ 毛利 = 95×（20-10.5）= 902.5元。
  - 可见：**多花5%的进价成本，换来了更高的可售量，毛利反而增加约7.4%**。

**2. 低价货源往往伴随更高隐性损耗**
- 低价果通常来自：统货（大小不均）、成熟度不一致、运输条件差（挤压、碰撞）、储存时间更长。
- 这些因素会直接导致：**上架期缩短、顾客挑剩后的严重损耗、退货报损**。
- 例如，收购价便宜0.5元/斤的香蕉，可能因成熟度不均，在货架期多烂掉10%~15%，最终毛利反而更低。

**3. 损耗直接影响顾客体验和复购**
- 高损耗会导致挑拣后卖相变差，顾客翻捡频率增加，进一步加剧损耗，形成“损耗-卖相差-更多损耗”的恶性循环。
- 而健康度高、损耗低的果品，即使单价略高，也能靠快速周转和稳定品质提升整体毛利。

**4. 商超的实际情况：损耗控制是核心KPI**
- 大型商超（如永辉、盒马）在水果采购中，通常把“损耗率”作为首要考核指标，甚至比采购价权重更高。
- 因为：**损耗是“真金白银”的消失，而采购价只是“成本”，两者对净利率的敏感度不同**（损耗直接减少收入，价格只改变单位成本）。

---

**建议**：
- **优先选择损耗低的货源**：成熟度适中、包装防护好、冷链运输到位的货，即使单价高10%，通常更划算。
- **不要迷信绝对低价**：采购时要求供应商报“净损耗率”，即实际到货后剔除烂果后的可用率。
- **在实际操作中**：
  - 对于高损耗水果（草莓、车厘子、葡萄、叶菜类）：**损耗权重应占首要地位**，宁可高价买好货。
  - 对于低损耗水果（苹果、橙子、柚子、瓜类）：价格差异影响更大，可在品质筛选后适度追求低价。

总之，**“可销售的品质果量”才是毛利的根本来源**，而非单纯的进价数字。
