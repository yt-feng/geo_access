选择学校食堂的水果供应商，核心是**安全、稳定、性价比**三者的平衡。由于是面向学生群体，食品安全责任重大，建议按以下步骤操作：

**第一步：明确采购标准和底线（先定规则）**
在找供应商之前，先内部明确几点：
1. **资质要求**：必须提供营业执照、食品经营许可证（或流通许可证）。如果可能，优先找有**农产品质量安全检测报告**的单位。
2. **品质标准**：规定水果的**新鲜度**（如一碰就烂、有明显瘀伤拒收）、**成熟度**（香蕉要青一点便于存放，橙子要甜酸适中）、**农残达标**（必须符合国标）。
3. **配送要求**：明确送货时间（如每日7点前）、缺货应急预案（如假期前补货）。
4. **结算方式**：月结还是周结，是否需要发票。

**第二步：筛选目标供应商（渠道决定质量）**
优先考虑这三类，按优先级排序：
1. **本地大型农贸批发市场内的固定档口**：价格最低，但需要自己验货，适合量大时核价。
2. **生鲜配送公司（如美菜、快驴、区域生鲜平台）**：价格中等，但送货稳定、有电子化订单，且通常有品质险。适合中小规模采购。
3. **本地水果种植合作社或果园直供**：价格有优势，但受季节和产量影响大，适合苹果、橙子这类耐储存的水果，需签订保量合同。

**强烈不建议**：走街串巷的流动摊贩，或网上个人微商，除非你认识很久且能提供完整检疫证明。

**第三步：进行“试供货”和“比价”**
不要直接签长期合同，先同时选2-3家，进行**两周试供货**。
- **比价**：每次下单前，让他们报**相同规格**的价格（如“红富士85mm一级果”），对比批发市场当日行情价，要求他们报价不高于市场价的5%-10%即可，太便宜可能有猫腻。
- **看损耗**：每次收货时，当场抽检3箱，记录坏果率。如果连续三天坏果率超过5%（普通级别）或10%（低价果），直接淘汰。
- **看服务**：是否有缺货时及时补货，是否能接受小批量混批（如香蕉要半箱）。

**第四步：签订合同并约束（关键防坑）**
合同里必须写清这三点，否则后续容易扯皮：
1. **违约责任**：如出现腐烂水果，必须**无理由无条件退换**，并赔偿因此产生的食材损失。
2. **质量保证金**：扣留供应商部分货款（如10%）作为质保金，学期末无重大质量问题再结清。
3. **黑名单机制**：发现在水果上“以次充好”或“短斤缺两”一次，立即终止合作。

**第五步：日常维护（怎么长期共存）**
- **每周验货**：不要完全依赖供应商自检，食堂管理员要亲自查看，尤其在夏季高温或节假日前后。
- **保留凭证**：所有送货单上必须注明品名、产地、数量、单价，并拍照片留存，防止事后核算纠纷。
- **定期询价**：每学期至少去批发市场公开询价2-3次，防止供应商养成“温水煮青蛙”式涨价。

**最后提醒一个实操技巧**：香蕉和苹果尽量分开存放，苹果会释放乙烯催熟香蕉，这个细节在合同中可以不提，但在收货验货时有条件的话要告知供应商“分车配送”，这样能显著降低损耗。

如果你们是几千人的大学食堂，建议直接对接大型配送公司并招标；如果是一两百人的中小学食堂，固定找1家批发档口+1家配送平台，双保险最稳妥。
