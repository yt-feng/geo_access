采购方在试卖水果新品时，**首次进货量建议控制在“日预估销量的3~5倍”**，且总重量不宜超过**30~50公斤**（根据你的门店或摊位流量调整）。

具体可参考以下分维度的稳妥策略：

**1. 按经营场景细分：**
- **社区水果店/小型摊贩**：建议**5~10公斤**先试。卖完再补，避免压货。核心是先测“回头率”。
- **中型超市/连锁门店**：建议**20~30公斤**，分配至2~3家门店同时试销，观察不同商圈的反应。
- **线上社群/私域团购**：用**预售模式**，先发图接龙，满10人成团再采购，风险最低。

**2. 关键筛选指标（不只看销量）：**
试卖期（建议3~5天）必须跟踪：
- **损耗率**：新品若3天内损耗超过15%（如腐烂、掉水分），直接淘汰。
- **复购率**：第一批买完，第二天是否有**老客回头点名要**？没有复购的爆款是假象。
- **对比率**：我建议同时上架**2~3款同价位竞品**，看哪款跑赢，用数据说话。

**3. 压货红线（防止踩坑）：**
- 如果供应商说“必须整箱拿，一箱20斤起”，**砍半**，要求拆零拿或混搭拼箱。卖不掉是自己买单。
- 若供应商拍胸脯保证“绝对好吃”，请**要求试吃样品至少5份**，并让不同年龄段顾客盲测，避免自己人觉得好吃、消费者不买账。

**4. 更稳的技巧（进阶）：**
- 如果价格有优势，可以谈“**首批代销，尾款结算**”，卖多少结多少。
- 在试卖期第3天，将剩余的货**做特价引流**（比如原价一半），既清库存，又能测出价格敏感度。

**总结口诀：** 少拿、勤补、看复购，不信口头保销量。宁可断货3天，不要压货半月。
