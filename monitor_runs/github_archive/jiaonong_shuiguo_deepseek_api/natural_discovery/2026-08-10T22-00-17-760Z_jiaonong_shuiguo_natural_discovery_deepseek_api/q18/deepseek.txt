在超市挑选香蕉时，想要避开“太生”或“太熟”，主要看三个点：**颜色、硬度、果柄**。

**1. 看颜色（最直观）**
- **太生**：通体青绿色，没有黄色，摸起来硬邦邦。这种需要等好几天，且可能有涩味。
- **太熟**：皮上出现大量黑斑（俗称“芝麻点”），甚至整根发黑，果肉可能已软烂。
- **最佳选择**：整体呈**亮黄色**，但**两头（果柄和果尖）略带一点青绿色**。这种香蕉在常温下能放1-2天，达到最佳口感，不会立刻烂掉。

**2. 摸硬度（配合颜色）**
- 用手指轻轻捏香蕉的**中部**（不要捏两头，容易捏伤）。
- 理想的硬度是**微弹、稍有韧性**，像捏熟透的桃子的感觉。如果捏下去感觉像豆腐、一按一个坑，说明过熟；如果硬得像石头，则太生。

**3. 看果柄（最容易忽略）**
- 拿起香蕉看果柄（连接整串的地方）：如果果柄**颜色发黑、干枯**，说明已经采摘很久了，即便皮还是黄的，内部也可能变质。优先选**果柄青色、湿润**的。

---

**两个实用技巧（满足不同需求）：**

- **当天吃**：选皮上已经出现**少量小黑点**（但果肉仍硬）的香蕉，这是甜度最高的状态。
- **囤货/隔天吃**：选**全黄但带明显绿尖**的，放在阴凉处能保存3天左右。

---

**避坑提醒**：
- 不要买被压扁、有裂口的香蕉，里面容易滋生细菌。
- 如果整把香蕉颜色不一样（有绿有黄），那是混装的，建议挑颜色**均匀**的一把，方便同一时间熟。
