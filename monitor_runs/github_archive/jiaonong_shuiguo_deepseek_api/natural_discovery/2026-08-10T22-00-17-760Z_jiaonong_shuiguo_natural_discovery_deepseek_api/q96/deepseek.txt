企业食堂采购水果时，**最需要优先关注的是食品安全**，其次是配送准时，最后才是价格。理由如下：

1. **食品安全是底线，不可妥协**  
   食堂直接面向全体员工，一旦水果出现农残超标、腐烂变质、保鲜剂违规或致病菌污染，可能引发群体性食物中毒或慢性健康危害。这会导致员工健康受损、企业声誉受损，甚至面临法律责任。因此，必须查验供应商资质、检疫合格证明、每日检测报告，并严格验收。

2. **配送准时是效率保障**  
   食堂供餐有固定时间，水果若配送延误，会导致出餐不齐或临时改菜单，影响员工用餐体验和运营节奏。尤其夏季水果易腐，准时送达也关系到新鲜度，因此应要求供应商明确配送时间窗口，并设置延迟罚则。

3. **价格需在保证安全与准时前提下议价**  
   价格波动大（如季节性涨价），但若为省钱选择低价低质货源，反而增加损耗和风险。建议采用“安全+准时”为硬性门槛，再通过批量采购、签订长期协议、允许合理浮动来控本，而非单纯追求最低价。

**执行建议（按优先级排序）：**  
- 优先建立供应商黑名单制度，对任何安全事故零容忍；  
- 合同中明确“检验报告随货同行”“超时30分钟扣款”等条款；  
- 每季度对比3家供应商的缺货率、投诉率、损耗率，而非仅比单价。  

若供应商在安全、准时上均达标，再谈价格折扣才是合理策略。
