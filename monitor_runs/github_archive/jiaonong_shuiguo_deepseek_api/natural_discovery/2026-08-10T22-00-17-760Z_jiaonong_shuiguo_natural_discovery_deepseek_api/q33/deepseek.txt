**很重要，而且是多门店统一品质的基石。**

供应商的分级标准不仅是“标签”，更是你采购、验收、定价和售后索赔的**法律与商业依据**。具体体现在以下4个核心层面：

**1. 验收与索赔的“尺子”**
- 如果没有明确分级（如特级、一级、二级），当某个门店收到次果时，你和供应商之间会陷入“公说公有理”的扯皮。明确标准后，**到货抽检不合格可以直接拒收或按比例扣款**。

**2. 门店执行的一致性**
- 分级标准可以转化为**门店的“上架手册”**。例如：特级果（直径≥80mm、无瑕疵）用于精品陈列；一级果（直径70-80mm、允许轻微瑕）用于普通货架。**没有标准，店长只能凭感觉定价和陈列**，导致各门店售价和品质混乱。

**3. 价格与数量的精准匹配**
- 高等级果价格高，低等级果走量快。统一分级标准后，总部可以**按门店客群特性**（社区店 vs 高端店）差异化配货，同时确保同等级果在全部门店口味、外观一致。

**4. 避免供应商“以次充好”**
- 标准越模糊，供应商越倾向于混装。必须要求供应商在**供货合同附件**中写明分级细则（含糖度、果径、碰伤面积、成熟度等），并附上**样品照片**作为补充协议。

---

**落地建议（可执行）：**

1. **不要只依赖供应商标准**：供应商的标准可能是“内部毛利最大化”标准。你需要基于**你的顾客投诉数据**和**高端店、社区店的动销差异**，与供应商共同制定**你的企业级标准**（建议写进合同）。
2. **量化指标**：例如苹果，基准标准可以是——**果径≥75mm、糖度≥13°、磕碰伤面积≤1cm²、无腐烂**。纸面描述必须对应实物样品。
3. **联合验收机制**：总部品控定期**随机抽查到货批次**，不能只靠门店收货员目测。
4. **动态回购机制**：如果供应商分级标准过严，导致果品积压，合同里可以约定**损耗共担比例**，避免供应商虚高定级。

**核心结论**：分级标准不是“锦上添花”，而是你管理供应商、控制损耗、统一顾客体验的唯一抓手。没有标准，统一品质就是空谈。建议立刻梳理现有供应商的书面标准，并与门店店长实际开箱验收的情况做一次交叉比对。
