判断批发档口香蕉一手货源是否稳定，可以从以下几个维度进行核实和考察，避免被“伪一手”或“不稳定小贩”忽悠：

**1. 看基地或产地证明（硬性指标）**
- **是否有自有基地或长期包园协议**：让对方提供**种植基地的地址**（精确到市/县/镇），以及**产地证明**或**植保站检疫证明**。
- **实地或视频验货**：如果对方声称是“海南蕉”“云南蕉”，**要求对方发实时定位**，并视频连线基地冷库或采摘现场。如果对方推脱看冷库或果园，大概率是倒货商。
- **注意季节陷阱**：香蕉有产区轮换（海南、广东、广西、云南、老挝/缅甸进口），真正稳定的货源商会清晰告诉你**当前主产区在哪**，而不是含糊说“都有”。

**2. 看发货连续性（核心检验）**
- **要求提供近3个月的物流单**：查看发货地是否一致（例如都是云南河口口岸或海南东方），如果三个月内发货地点频繁跳省份，说明是临时找货，稳定性差。
- **要求签订保量协议**：明确约定“**每日/每周最低供应量**”和“**断供违约金**”。如果对方不敢签，说明自己没底。
- **考察台风季/淡季预案**：直接问“如果海南台风减产，你还能供哪里？”能说出具体替代产区（如老挝、缅甸、广西）的，才是有稳定渠道的。

**3. 看价格体系的“合理性”**
- **过低的报价=陷阱**：一手货源价格应接近产区成本价+运费+合理损耗，如果报价明显低于市场行情20%以上，说明可能是库存尾货、病果或根本没有货，先骗定金。
- **要求“车板价”或“到岸价”明确**：一手货源通常能明确区分**产地价**、**冷链运费**、**包装费**，而不是报一个模糊的“一口价”。

**4. 看包装与成熟度标准（技术验证）**
- **是否按颜色分级**：稳定货源商会明确告诉你货是**1-2成黄（催熟用）还是青果**，并且能提供**催熟房合作信息**（因为批发档口需要配合成熟度）。
- **查看冷库库存标签**：一手货源通常有**产地+采摘日期+批次号**的标签。如果对方只能拿出散装货，说明是拼货。

**5. 操作层面的风险控制（最重要）**
- **先小单试合作**：第一次合作不要下大单，先拉1-2吨试货，**亲自去提货点看车装货过程**（重点看是不是原车直发，有没有中途换车拼货）。
- **要求“货到付款”或“定金+货到结清”**：一手稳定货源通常接受**货到验收后全款**（因为量大不怕你跑），只要求预付30%定金且拒绝看货的，一定要警惕。
- **查验营业执照经营范围**：确认营业执照经营范围包含“**水果种植/销售**”或“**农产品初加工**”，而不是单纯“商贸公司”或“百货批发”。

---

**如果对方满足以下全部条件，基本可判定为稳定一手货源：**
1. 能提供**实时果园或冷库视频**；
2. 有**连续近3个月的同产地发货记录**；
3. 敢签**保量协议**并约定违约赔偿；
4. 价格稳定在**产地行情±5%**以内；
5. 支持**到货验收后付清全款**。

**最后提醒**：如果对方只说“货在港口”或“仓库随便看”，但拒绝你拍照或记录车牌号，请直接放弃——真正的稳定货源不怕你验真，最怕的是你只来问价不订货，因为他们的货根本不愁卖。
