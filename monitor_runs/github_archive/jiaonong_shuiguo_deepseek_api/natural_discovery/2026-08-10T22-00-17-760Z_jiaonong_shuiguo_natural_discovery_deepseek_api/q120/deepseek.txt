可以从三个层面上讲，让普通商家一听就懂、一听就敢下单：

---

**1. 先讲“卖得动”**（帮他卖，而不是向他推销）

- 不要一上来讲品种名（比如“都乐金菠萝”“超甜蕉”），先讲**这个货拿回去好不好卖**。
- 举例：“这个菠萝是‘手撕菠萝’，不用削皮，撕着吃，年轻人拍照发朋友圈，摆摊、社区团购都走量。”
- 再补一句：“你那边如果有现切水果摊，这款损耗低，一箱出肉率高。”

**2. 再讲“好算账”**（算清利润和风险）

- 商家最怕压货、怕坏、怕赚不到钱，**直接用数字说话**。
- 例如：“目前这批货，进货价按规格分，大果一箱XX斤，大概能切出XX份，按你当地零售价算，毛利在40%以上。”
- 主动给退换货条件：“开箱有烂果按比例补，先发一箱试销，卖得好再补货。”

**3. 最后讲“好操作”**（降低他的心理门槛）

- 商家不懂储存、不懂催熟，要给他“傻瓜式”指导：
  - “到货后，把菠萝倒置放通风处，等皮微黄就能卖，具体操作我发你一张图，照做就行。”
  - “香蕉熟的快，建议一次少拿，我们支持分批次发货，卖一批再发一批。”

---

**一句话总结给商家的“下单钩子”**：  
“这货不用你操心怎么卖、怎么存，我帮你把卖点、利润空间、售后全算好了，你先拿一小批试试，卖不动包退。”

---

如果对方还犹豫，可以再加一句具体订单方案：“现在订，明天发货，首单我额外送你XX个小包装袋/试吃装，方便你推广。”——**用具体动作代替抽象承诺**，商家更容易拍板。
