针对水果店减少香蕉损耗的问题，建议从**采购标准**和**供应链节奏**两方面进行严格把控。以下是具体、可执行的要求：

### 一、 对熟度（色号）的硬性要求
香蕉的成熟度通常用“色号”来标识（1-8号）。**建议采购“色号4.5-5.0”的香蕉（即黄绿微转，但果柄仍带绿）**。

- **具体标准**：表皮大部分呈黄色，但果柄和棱角处仍可见绿色，捏起来有弹性但不过软。坚决抵制采购全黄（6号）或带黑点（7号）的货，这类货在店里最多只能放1-2天。
- **原因**：到店后自然存放，可维持3-4天的黄金销售期。如果采购过生（3号以下），虽然耐放，但甜度不够，顾客尝了不买，同样造成浪费。

### 二、 对到货时间的“双段式”要求
不要只要求“今天到”，要精确到**每天的到店时间窗口**：

1. **首段（早晨档）**：要求**每日上午9:00前**到货。理由：这是客流高峰前，方便员工立刻拆箱、上架、理货，避免在库房闷热环境下堆放。
2. **次段（补货档）**：如果下午需要补货，要求**下午14:00-15:00**到货。理由：错开午间高温时段，防止香蕉在运输车或店门口暴晒后熟化加速。

### 三、 附带“冷链与包装”条款（容易被忽略）
- **强调“常温运输，忌密封”**：在采购单或合同备注中写明“必须透气包装（带孔塑料袋），不可使用密闭泡沫箱运输”。香蕉需要释放乙烯气体（催熟气体），密封会导致到货时已大面积发黑。
- **温度要求**：运输车厢温度控制在 **13-15℃**（香蕉的适宜保存温度）。低于11℃会冻伤变黑，高于20℃会加速成熟。

### 四、 现场验收的“罚款级”标准
采购时口头要求不算数，要在供应商协议里写明**“到货即检”**：
- **轻微瑕疵**：允许有3%-5%的轻微压伤或斑痕，但必须先表面完好。
- **绝对拒收项**：一旦发现果柄断裂超过20%、或表皮有弥漫性发黑迹象（冻伤或捂伤），现场直接拒收，不计入货款。这能强制供应商提供“耐存放”的批次。

### 五、 库存周转的“采购量”建议（补充给店长）
- **首单量**：进店前3天不大量囤货，首批进货量控制在 **日销量的1.5倍** 以内。
- **销售节奏提示**：将香蕉摆放在通风、避免阳光直射的展位，并**每半天翻动一次**，让底部透气。同时设置“今日特价”标签，在色号达到6号时立即打折清货，而非等到7号再处理。

**总结一句话给采购员**：“色号4.5，上午9点到，带孔透气袋，13度车厢，违者拒收。” 按此标准执行，香蕉在店的耗损率通常能降低约70%。
