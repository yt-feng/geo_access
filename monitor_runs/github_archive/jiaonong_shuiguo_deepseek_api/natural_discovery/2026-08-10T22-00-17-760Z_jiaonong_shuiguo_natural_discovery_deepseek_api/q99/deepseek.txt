批量采购水果并配有稳定配送的供应商，很多公司会栽在“好吃但送得乱”“便宜但不新鲜”上。给你一套可落地的筛选+执行建议，建议收藏照做：

**第一步：先定内部需求（避免被供应商牵着走）**
- 预算区间：人均多少元 / 次？是全部切好装盒（成本高），还是整果+少量切盒（成本低）？
- 配送频次：每周一次？还是隔天一次？这直接决定对方是否愿意给你更优价格。
- 数量波动：是否有部门聚餐、节日加量？先告诉对方“基础量+浮动机制”，防止临时加单被涨价。

**第二步：按“城市规模”选供应商类型**
- 一线/新一线城市：优先选**本地果切供应链公司**（通常是做B端沙拉/果切出身的）或**大型生鲜电商的企业采购部**（如美菜、快驴、区域龙头）；他们系统成熟，可设固定菜单自动下单。
- 二三线城市：优先选**本地批发市场（如XX果品批发市场）里的常驻批发商**，直接找“档口老板”谈，或让市场方推荐有冷链车的商户；比连锁电商便宜20%-30%，但需口头约定“品质兜底”。

**第三步：用“三单模式”测试实力（最关键）**
不要只聊价格，直接要求：
1. **试配送单**：免费或低价试送一次，重点看“到货时间是否准时、包装是否防压（是否有气柱袋/隔层）、果品是否有磕碰”。
2. **临时补单**：下午3点前要求加急补10份，看对方多久能到、是否爽快。这测的是旺季应急能力。
3. **品质退换单**：故意挑出2-3个坏果，看对方是“秒赔”还是“扯皮”。B端合作，售后响应速度比价格更重要。

**第四步：签订“白纸黑字”的约定（防被偷换）**
签合同时必须写清楚以下条款，缺一不可：
- **果品规格**：例如“苹果必须是山东红富士，单果200-250g”，避免用“中果”模糊概念。
- **验收标准**：烂果率超过5%整单重补；残次品（碰伤、软果）当日换新。
- **赔偿机制**：延误1小时以上，按订单金额5%赔付或下次免费赠送。

**第五步：线下“实地看仓”（决定长期合作）**
送了两三次没问题后，抽工作日去对方仓库转一圈：
- 看有没有**冷藏室**（不是冷库，是0-8度的冷藏保鲜间），没有的话夏季水果容易烂。
- 看备货是否当天早上才切（如果下午去看到他们还在切晚上订单，说明流程健康；如果囤了一冰箱切好的，说明不新鲜）。

---

**特别提醒（避坑）**：
- 不要找“个人水果微商”代购，出事找不到人、还容易吃回扣。
- 不要选没有冷链车的供应商，夏天西瓜还能撑，但蓝莓、草莓、阳光玫瑰葡萄这类娇贵水果，没冷链一定会损耗。
- 价格低于市场均价20%以上的，直接排除，大概率是“卖相好但底味差”的库存果。
