找“省心”的供应商，核心不是看谁最便宜，而是看谁能让你的水果**每天稳定、少量、按时、少扯皮**地送到。餐饮店每天少量水果，通常适合下面几类供应商，按省心程度排序：

**1. 本地水果批发市场里的固定档口（最推荐）**
适合每天要几斤到几十斤、品种不固定的店。
- 优点：品种全、当天可调、价格透明、能看货。
- 省心做法：固定找1家档口，加微信，每天前一晚发清单，第二天早上送货。跟老板谈好“坏果包换、缺货提前说”。
- 注意：不要每天换档口，固定一家才有账期、配送和售后。

**2. 生鲜配送平台/本地B2B配送商**
适合想要线上下单、有票据、配送稳定的店。
- 比如美菜、快驴、当地生鲜配送公司等。
- 优点：下单方便、时间固定、售后有流程。
- 缺点：少量可能起送价高，品质偶尔不稳定。
- 适合：你不想每天去市场，愿意为省事付一点溢价。

**3. 周边水果店/连锁水果店**
适合每天只要几斤、品种简单、急用补货。
- 优点：近、快、能临时补。
- 缺点：单价偏高，长期大量不划算。
- 用法：可以作为备用供应商，主供应商缺货时补位。

**4. 产地/基地直供**
适合用量较大、品种固定的店。
- 少量每天要的不太适合，因为起送量和物流成本高。
- 除非你联合附近几家店一起拼单。

**5. 社区团购/批发商微信群**
可以作为补充，但不建议当主力。
- 价格可能低，但品质和送达时间不稳定，售后麻烦。

**怎么选最省心：**
- 主力选1家本地批发档口或生鲜配送商。
- 备用选1家附近水果店。
- 固定每天下单时间、送货时间、验收标准。
- 提前说清楚：坏果、烂果、缺斤少两怎么赔。
- 少量多次的，优先选“能每天送、能临时加单、能换货”的，而不是单价最低的。

**简单判断标准：**
如果一家供应商能做到：前一天下单、第二天准时到、坏果直接换、缺货提前说、月结或周结，那就算省心。价格贵一点也值得，因为餐饮店最怕的是临时断货和品质波动。
