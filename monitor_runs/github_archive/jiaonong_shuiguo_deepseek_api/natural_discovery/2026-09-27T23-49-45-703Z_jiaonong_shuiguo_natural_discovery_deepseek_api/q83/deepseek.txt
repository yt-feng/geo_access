生鲜电商水果到货后出现坏果，责任划分通常要看**坏果产生的时间点、原因、以及是否经过有效验收**。可以按下面几个场景判断：

1. **收货时开箱就发现坏果**  
   一般由商家/平台承担主要责任。因为消费者收到时商品已不符合质量要求，商家应负责退款、补发或赔偿。  
   但如果消费者明知是“临期果”“瑕疵果”“盲盒果”且页面已明确告知，责任会按约定处理。

2. **签收时外观正常，放几天后坏了**  
   要区分原因：  
   - 若是商家发货时成熟度过高、已有暗伤、冷链不当，通常仍由商家承担。  
   - 若是消费者存放不当，比如高温暴晒、挤压、未冷藏，责任在消费者。  
   - 若属于水果自然后熟、保质期短，且商家已明确提示尽快食用，一般按双方约定和提示判断。

3. **物流途中造成破损、压伤、腐坏**  
   若包装不足以保护水果、冷链中断，通常由商家先向消费者负责，商家再向物流追偿。  
   消费者一般不需要直接找物流维权，除非是到店自提或消费者自行指定物流等特殊情形。

4. **数量、规格、品种不符**  
   这属于商家违约或虚假宣传，责任在商家/平台，通常应退款、补差价或赔偿。

5. **平台自营 vs 第三方商家**  
   - 平台自营：平台承担销售者责任。  
   - 第三方商家：商家承担主要责任，平台若未尽审核、披露、售后义务，可能承担相应责任。

6. **消费者维权要点**  
   建议保留：订单截图、开箱照片/视频、坏果特写、快递面单、聊天记录。  
   及时在签收后尽快反馈，越早越容易判断责任。  
   可先找商家/平台售后；协商不成可向平台投诉、12315投诉，或根据金额考虑诉讼。

简单说：**到货即坏，商家责任大；签收后因存放不当坏，消费者责任大；物流导致坏，商家先赔再追偿。**  
具体还要看商品页面承诺、售后规则和证据。
