判断菠萝哪个规格好出货，核心不是看“哪个规格好”，而是看**你的下游客户是谁、他们按什么场景采购**。批发出货快慢，通常由这几个变量决定：

1. **下游渠道**
   - 走**农贸/水果店**：中果、大果往往更快，因为按个卖、家庭消费多。
   - 走**商超/精品店**：偏好外观整齐、重量稳定的规格，大小均匀比单纯大个更重要。
   - 走**餐饮/果汁/烘焙**：更看出肉率、酸甜稳定、去皮成本，大果或加工专用规格可能更快。
   - 走**电商/团购**：小果或中等果有时更快，因为单价低、配送友好、适合家庭一次吃。
   - 走**礼盒/节庆**：大果、外观好、果形正的规格更吃香。

2. **规格本身**
   菠萝常见按重量分：
   - 小果：约 0.8–1.2 斤/个
   - 中果：约 1.2–1.8 斤/个
   - 大果：约 1.8–2.5 斤/个
   - 特大果：2.5 斤以上
   
   但不同产地、品种标准不一样，不能只看斤重，还要看**果径、果形、成熟度、是否带冠芽**。

3. **判断哪个规格更好出货的实操方法**
   - **看历史出货数据**：过去 2–4 周，哪个规格出库量最大、复购最多。
   - **看询价集中度**：客户问得最多、还价最少的规格，通常就是好走的。
   - **看库存周转天数**：同样进价下，周转最快的规格就是好出货的。
   - **看损耗**：某个规格虽然卖得快，但烂得快、退换多，实际不一定更赚。
   - **看毛利**：出货快不等于赚钱，要算“周转速度 × 单件毛利”。
   - **小批量试销**：同一批货分 2–3 个规格，各放 3–5 天，记录出货速度和客户反馈。

4. **简单决策公式**
   优先推：
   **周转天数短 + 退货损耗低 + 单件毛利不低于平均 + 客户复购稳定** 的规格。

   如果只能看一个指标，先看**周转天数**；如果只能看两个，再看**损耗率**。

5. **常见经验**
   - 夏天、果汁店、餐饮渠道：中大果常更快。
   - 家庭零售、社区团购：中果通常最稳。
   - 商超精品：均匀中大果更好卖。
   - 礼盒：大果、外观好的规格更快。
   - 小果不一定慢，如果价格低、适合电商或路边摊，也可能走得快。

最稳妥的做法：**别凭感觉押一个规格，先按渠道分客户，记录 1–2 周的出货速度、损耗和毛利，再调整主推规格。**
