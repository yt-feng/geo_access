核心原则：**香蕉采购不能只看“熟度”，要按“到货后你计划卖几天”来倒推采收成熟度和到货时间。** 香蕉是后熟水果，到店时越生，货架期越长，但可能需要催熟或等黄；到店时越黄，越容易马上卖但损耗快。

给你一套可直接用在采购单/供应商沟通里的要求：

1. **按销售节奏定到货熟度**
   - 计划 **1～2天内卖完**：到货可要求 **3～4级**，即大部分转黄、果指饱满、无青硬感，适合直接上架。
   - 计划 **3～5天卖完**：到货要求 **2～3级**，即果身开始转黄、棱角尚在，放到店里后逐步黄熟。
   - 计划 **5天以上慢慢卖**：到货要求 **1～2级**，即青果为主、硬身、无黄斑，后续自然或人工催熟。
   - 如果店铺没有催熟条件，不要轻易进太青的货，否则会出现“一直不熟、突然一起熟”的情况。

2. **到货时间要求**
   - 最好要求 **清晨或上午到货**，当天完成分拣、上架、挑出伤果。
   - 避开 **下午高温时段到货**，尤其是夏季，车厢和卸货过程会加速后熟。
   - 如果一天多次补货，香蕉适合 **少量多次**，不要一次压太多库存。
   - 要求供应商 **按你指定的售卖高峰前1天到货**，而不是“有货就送”。

3. **采购时明确写进要求的指标**
   - 成熟度：按 **1～5级** 约定，例如“到货以2.5～3级为主，黄果不超过20%”。
   - 青硬比例：青果比例、微黄比例、黄熟比例要写清楚。
   - 果指状态：无黑斑、无裂口、无压伤、无冻伤、果柄不发黑霉变。
   - 温度：要求 **冷链或控温运输**，一般香蕉运输适宜 **13～15℃**，避免低于12℃冻伤，也避免高温捂熟。
   - 包装：纸箱或塑料袋不要完全密封，避免催熟气体积累；要求有通风孔。
   - 批次：同一批成熟度尽量一致，不要青黄混装太严重。

4. **和供应商约定的到货规则**
   - 要求“**按需分级到货**”，不是统一发一种熟度。
   - 要求“**可拒收标准**”：黑斑超过多少、压伤超过多少、冻伤、发霉、果柄腐烂，直接拒收或扣款。
   - 要求“**到货温度记录**”，特别是夏季和冬季。
   - 要求“**分批到货**”：比如周三、周五各到一批，而不是周一一次性到一周的量。

5. **店里配合动作**
   - 到货后立刻 **拆箱、通风、分拣**，把黄果、伤果挑出先卖。
   - 香蕉不要直接贴冷柜出风口，也不要暴晒。
   - 陈列时 **少量上架、后仓存放**，后仓保持阴凉通风。
   - 黄熟果可以单独做特价区，避免拖累整批。
   - 如果太青，可放苹果或乙烯利催熟；如果太黄，尽快冷藏或加工，但香蕉冷藏易变黑，最好尽快销售。

**一句话采购要求模板：**
“请按我店销售计划到货：计划3～5天卖完，要求到货成熟度2～3级，青果为主、微黄不超过30%，清晨到货，控温13～15℃，无黑斑、无压伤、无冻伤、无发霉；黄熟果和伤果可拒收。后续分2～3批到货，不要一次压货。”
