酒店采购水果盘原料时，建议在采购合同或收货标准中明确以下规格和外观要求，便于验收和索赔：

**一、通用规格标准**
1. **品种与产地**：明确具体品种（如红富士苹果、海南贵妃芒）、产地或允许的替代范围。
2. **单果重量/尺寸**：按品种规定单果克重区间或直径（如苹果直径75–85mm），避免大小混杂。
3. **成熟度**：约定可即食或需后熟的成熟度（如香蕉七成熟、牛油果硬熟），并注明后熟天数。
4. **可食率**：约定去皮去核后的出成率下限，如西瓜可食率≥60%、菠萝净果率≥50%。
5. **糖度**：对甜度敏感品种可约定糖度范围（如西瓜中心糖度≥11°Brix）。

**二、外观标准**
1. **新鲜度**：果蒂鲜绿或无明显干枯，无萎蔫、皱皮、发酵味。
2. **完整性**：无破裂、压伤、虫眼、霉斑、明显机械损伤。
3. **色泽**：符合品种固有颜色，着色均匀，无明显青斑或褪色。
4. **形状**：果形端正，无明显畸形（轻微自然差异可接受）。
5. **表面洁净**：无泥土、药斑、污渍；允许少量自然果粉。
6. **成熟均匀度**：同批次成熟度基本一致，避免生熟混杂。

**三、包装与运输**
1. 使用食品级周转箱或纸箱，内衬缓冲材料。
2. 标注品种、等级、重量、采摘/包装日期。
3. 冷链品种全程温控，到货温度符合约定。

**四、验收与处理**
1. 到货按批次抽检，记录重量、尺寸、糖度、外观缺陷率。
2. 约定不合格率上限（如外观缺陷≤5%），超标可拒收或扣款。
3. 对易腐品种约定到货后最佳使用时限。

**五、按用途补充**
- **果切/拼盘**：更强调出成率、色泽一致、无籽或少籽。
- **整果摆台**：更强调外观、大小均匀、无瑕疵。
- **榨汁**：可放宽外观，但需约定糖度、酸度和出汁率。

建议把这些指标写入采购订单附件，并保留每批次验收照片和记录，作为退换货依据。
