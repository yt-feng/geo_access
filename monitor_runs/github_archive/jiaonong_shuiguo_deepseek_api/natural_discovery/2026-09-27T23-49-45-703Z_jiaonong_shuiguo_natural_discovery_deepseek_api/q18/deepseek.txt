想买到“当天能吃、放两三天也不坏”的香蕉，关键是看**颜色 + 手感 + 果柄**，而不是只看黄不黄。

## 先定用途，再决定买什么状态
- **今天/明天吃**：买全黄、带少量小黑点的。
- **2～3天内吃**：买黄色为主、两端略绿的。
- **4～6天后吃**：买整体偏绿、但已经有一点黄意的。
- **别买**：通体深绿发硬、或大面积黑斑且果肉软塌的。

## 到店怎么挑
1. **看颜色**  
   - 全绿：太生，通常还要放很久。  
   - 黄中带绿：适合放几天。  
   - 全黄：基本可吃。  
   - 黄带黑点：最甜，但最好1～2天内吃完。  
   - 大面积黑、发暗：过熟或已损伤。

2. **看棱角**  
   香蕉越圆润，通常越熟；棱角分明、很硬，通常偏生。

3. **轻捏果身**  
   - 硬：生。  
   - 微软有弹性：刚好。  
   - 一按就陷：过熟。  
   注意别捏中间，容易压伤。

4. **看果柄和果蒂**  
   - 果柄青绿：较新鲜、偏生。  
   - 果柄发黄/干缩：成熟中。  
   - 果柄发黑、发霉：不新鲜或存放过久。

5. **看表皮损伤**  
   有裂口、压伤、渗水的不要买，这种会很快烂，还会影响整串。

## 如果超市只有一种状态，怎么办
- **只有很生的**：买回家和苹果/熟香蕉放同一个纸袋里，1～2天会催熟。  
- **只有很熟的**：当天吃可以；想放久一点就别买，或买回家立刻冷藏果肉、尽快吃。  
- **想兼顾几天**：买一串里“黄中带绿”的，回家后把熟得快的先吃，生的继续放。

## 买回家后怎么放
- **没熟透**：室温放，别冷藏。  
- **已熟透**：可以冷藏，表皮会变黑，但果肉能多撑2～3天。  
- **想催熟**：纸袋 + 苹果/梨，别用密封塑料袋闷。  
- **想减缓成熟**：分开单根放，减少挤压；熟后冷藏。

一句话：**想当天吃就买全黄微斑，想放几天就买黄中带绿、果柄青、果身微软不塌的。**
