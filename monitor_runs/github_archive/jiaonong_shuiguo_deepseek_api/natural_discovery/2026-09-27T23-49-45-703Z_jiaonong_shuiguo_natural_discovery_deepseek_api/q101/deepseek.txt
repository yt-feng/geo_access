和水果供应商谈酒店早餐合作，重点不是“压价”，而是把**稳定供应、品质一致、损耗可控、责任清晰**写进合作条件。建议按下面几项准备和谈判：

1. **先定需求和标准**
   - 明确每天/每周用量：品种、数量、规格、成熟度、切配要求。
   - 写清验收标准：新鲜度、甜度、大小、颜色、成熟度、无腐烂/冻伤/虫害。
   - 区分“整果供应”和“切果/净果供应”，后者要问加工环境、包装、冷链和保质期。

2. **重点谈稳定供应能力**
   - 问清产地、季节替代方案、雨天/节假日/旺季如何保供。
   - 要求备用货源或替代品种，避免单一产地断供。
   - 约定缺货、迟到的处理：提前通知时间、替代方案、赔偿或扣款。

3. **价格和调价机制**
   - 不要只谈一个固定价，水果价格波动大，建议谈“基准价+随行就市浮动”或周期报价。
   - 明确报价是否含税、含运费、含卸货、含切配、含包装。
   - 约定调价提前通知期，比如提前3—7天书面确认。

4. **验收和退换货**
   - 约定到货时间、验收人、验收方式。
   - 不合格如何处理：拒收、换货、补货时限、费用谁承担。
   - 最好留样或拍照记录，避免扯皮。

5. **食品安全和资质**
   - 要求营业执照、食品经营许可证、检验检疫/农残检测报告等。
   - 切果供应商还要看冷链、加工卫生、从业人员健康证。
   - 约定食品安全责任：因水果问题导致客人投诉、处罚或赔偿，供应商承担相应责任。

6. **配送和现场配合**
   - 配送频次：每日送、隔日送还是每周几次，要匹配酒店早餐和库存能力。
   - 到货时间要避开早餐高峰，最好固定时间段。
   - 包装、周转筐、垃圾回收、卸货位置提前说清。

7. **损耗和库存风险**
   - 早餐水果损耗高，能谈“按需配送、少量多次”最好。
   - 对易损水果如草莓、蓝莓、切果，明确损耗承担比例。
   - 避免一次性压太多库存，尤其是保质期短的切果。

8. **结算和合同**
   - 明确账期：月结、半月结还是货到付款。
   - 约定发票类型和开票时间。
   - 合同里写清合作期限、试用期、退出机制、违约条款。
   - 建议先试合作1个月，再决定是否长期签。

9. **谈判时可用的底线**
   - 必须保供：不能因涨价或天气随意断供。
   - 必须可退换：品质不达标不能强制收货。
   - 必须可追责：食品安全问题要有明确责任。
   - 必须价格透明：不能临时加运费、加工费、包装费。

10. **建议先做一张对比表**
   - 供应商A/B/C分别列：价格、品种、配送频次、退换货、资质、账期、应急能力。
   - 不要只选最便宜，优先选**稳定、响应快、能处理异常**的。

简单说，谈的时候抓住一句话：**“你可以不是最低价，但必须稳定、达标、出问题能负责。”** 这样酒店早餐水果供应才不容易天天救火。
