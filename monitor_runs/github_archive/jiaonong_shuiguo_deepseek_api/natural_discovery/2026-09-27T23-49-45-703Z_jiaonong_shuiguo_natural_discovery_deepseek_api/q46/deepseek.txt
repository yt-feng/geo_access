**优先建议：按你的出杯量、人工和后厨条件来选。大多数茶饮店最适合“鲜果 + 冷冻果丁/果泥搭配”，而不是只选一种。**

直接给判断：

| 原料 | 适合情况 | 优点 | 缺点 |
|---|---|---|---|
| 鲜果 | 主打现切、鲜果茶、客单价较高、出杯量不大 | 香气自然、卖点强、可做装饰 | 损耗高、去皮切果费人工、季节和熟度不稳 |
| 果丁 | 需要稳定出杯、做果肉感、连锁或外卖多 | 操作快、口味稳定、损耗低 | 果肉口感和鲜切有差距，部分产品偏软 |
| 果泥 | 做冰沙、果茶基底、批量标准化 | 浓度稳定、调味方便、成本可控 | 鲜果香气弱，容易“酱味重”，不适合强调现切 |

**怎么选：**
1. **如果你店里主打“鲜切菠萝果茶”**：买鲜果，但只适合日均销量稳定、有人工切果的门店。否则损耗和人工会把利润吃掉。
2. **如果追求出杯稳定和效率**：选冷冻菠萝果丁或果泥。果丁做果肉感，果泥做基底和调味。
3. **如果做菠萝冰沙、菠萝气泡茶、批量外卖**：果泥更合适，搭配少量鲜果装饰即可。
4. **如果预算有限又想做鲜果概念**：用冷冻果丁做主体，出杯时加少量鲜切菠萝装饰，平衡成本和卖点。

**采购时重点看：**
- 是冷冻还是常温？冷冻果丁/果泥通常比常温果酱更接近水果风味。
- 糖度、添加剂、果肉含量。果泥如果已经加糖，配方里的糖浆要减。
- 规格和解冻方式。果丁解冻后是否出水、变软。
- 季节替代方案。菠萝旺季用鲜果，淡季用冷冻果丁/果泥补位。

**简单结论：**
- 小店、销量一般、有人工：**鲜果为主，少量果泥调基底。**
- 外卖多、连锁、追求稳定：**冷冻果丁 + 果泥为主，鲜果只做装饰。**
- 只选一种且想省事：**选冷冻果丁**，比果泥更有果肉感，比鲜果更稳定。
