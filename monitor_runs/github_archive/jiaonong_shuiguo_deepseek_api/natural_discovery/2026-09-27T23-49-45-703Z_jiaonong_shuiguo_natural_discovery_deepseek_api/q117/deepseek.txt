建议按“最小可验证量”试卖，不要一次压太多。可以按这个思路定：

1. **先定试卖目标**
   - 不是看供应商说能卖多少，而是看你要验证三件事：
     - 顾客愿不愿意买；
     - 复购和损耗能不能接受；
     - 毛利和周转是否划算。

2. **试卖量建议**
   - **单店、单品类**：先从 **1～3 箱** 或 **20～50 公斤** 起试，具体看包装规格。
   - **多店/连锁**：选 **2～3 家代表性门店**，每店 **1～2 箱**，总试卖量控制在 **正常单品周销量的 10%～20%**。
   - **高损耗、易腐水果**：再降一半，先拿 **半箱到1箱** 试。
   - **耐储存水果**：可以到 **1～3 箱**。
   - **如果供应商要求起订量高**：不要硬吃，先谈 **拼柜、混装、小包装、首批特价或可退换**。

3. **试卖周期**
   - 一般 **3～7 天** 看首轮动销。
   - 叶菜、浆果、荔枝龙眼等短保品，**1～3 天** 就要判断。
   - 苹果、橙子、梨等耐储品，可以拉到 **7～14 天**。

4. **判断标准**
   - **动销率**：3天内卖出 <30%，要谨慎；>60% 可考虑补货。
   - **损耗率**：超过 **5%～10%** 就要重新算账，叶菜浆果更严。
   - **毛利率**：扣掉损耗、运费、人工后，是否还高于你现有同类品。
   - **复购**：有没有顾客回头问、点名买，比首次促销销量更重要。
   - **退货/投诉**：口感、成熟度、大小、压伤问题多，就不适合放量。

5. **实操建议**
   - 首批只签 **试销协议**，约定可退换、可调价、可换货。
   - 同时试 **2～3 个竞品**，同价位、同陈列、同周期对比。
   - 不要只看“卖完没有”，要看 **卖完赚没赚、顾客回不回头**。
   - 数据达标后再按 **20%～30%** 逐次加量，不要直接从试卖跳到大批量。

一句话：**单店先 1～3 箱，多店先 2～3 家店、每店 1～2 箱，跑 3～7 天；动销、损耗、毛利、复购都过关，再逐步放量。**
