和品牌方谈代理，区域保护和串货是必须提前问清、写进合同的两件事。下面按“问什么、怎么问、注意什么”给你一套可直接用的清单。

## 一、先问清楚：区域保护到底保护什么

不要只问“有没有区域保护”，要把它拆成可核验的条款：

1. **授权区域范围**
   - 是独家还是非独家？独家的话，保护范围是省、市还是区县？
   - 区域内是否已有其他代理商？如果有，是并存还是给你划走？
   - 线上（电商、直播、社区团购）算不算你的授权区域？这块最容易出问题。

2. **保护的具体承诺**
   - 品牌方在授权期内，是否承诺不再授权第二家？
   - 品牌方自己会不会在你的区域直接卖货（自营、直播、大客户直销）？要明确“品牌方自营是否受区域限制”。
   - 保护期和你的代理期是否一致？会不会出现“代理3年，保护只给1年”。

3. **业绩与保护挂钩**
   - 区域保护是否附带销量任务？完不成会怎样——缩小区域、取消独家、还是直接解约？
   - 任务按什么口径算：进货额、出货额还是终端销售额？按进货额算对你风险最小，按终端销售额算你要多留余地。

## 二、再问清楚：串货怎么定义、怎么处理

串货的核心是“谁算违规、怎么举证、怎么罚、你能不能追责”：

1. **串货的定义**
   - 是“跨授权区域销售”，还是也包括“低于指导价销售”？
   - 你的下线分销商把货卖到别的区域，算不算你串货？责任怎么划分？
   - 电商平台上的第三方卖家低价卖同品牌，算不算串货？品牌方管不管？

2. **举证与查处**
   - 发现串货后，向谁举报、多长时间响应？
   - 需要你提供什么证据（批次号、物流单、购买记录）？
   - 品牌方是否有产品追溯/防串货码？能不能查货是哪个区域出的？

3. **处罚与赔偿**
   - 对串货方的处罚是什么：罚款、扣保证金、停货、取消代理？
   - 你因串货受到的损失，品牌方赔不赔？怎么赔？
   - 如果品牌方自己不作为，你有没有权要求补偿或调整任务？

4. **你自己的责任边界**
   - 你区域内出货给下游，下游串货，责任算谁的？
   - 你要求下游签不串货承诺，品牌方认不认这个免责？

## 三、谈判时怎么问，话术示例

可以直接用这几句：

- “咱们这个区域保护，是合同里写独家，还是口头承诺？保护范围含不含线上？”
- “如果品牌方自己或别的代理在我区域卖货，我有什么救济？是补差价、扣任务，还是我可以终止合作？”
- “串货的判定标准写进合同哪一条？我举报后多久处理，处理结果怎么反馈？”
- “我下面的分销商如果串货，责任怎么分？我提前签了约束协议，能不能免责？”
- “区域保护的销量任务，按进货还是按终端？完不成是缩区域还是解约，有没有缓冲期？”

## 四、必须落到合同里的关键点

口头承诺不算数，重点看合同是否写明：

1. 授权区域、渠道、期限、独家性；
2. 品牌方及关联方不得在授权区域直接或间接销售（除非约定例外）；
3. 串货定义、举报流程、处理时限、处罚标准；
4. 品牌方不作为时的违约责任或你的退出/补偿权；
5. 线上渠道归属，是否允许你开网店、直播，平台低价怎么管；
6. 保证金、任务、返利与区域保护的联动关系。

## 五、给你的判断建议

- **只给口头区域保护、合同不写的，基本可以视为没有保护。**
- **只保护线下、线上放开低价卖的，串货风险极高，慎接。**
- **区域保护绑定高任务、又没有缓冲和补偿的，等于把风险全压给你。**
- **品牌方对串货没有追溯码、没有处理机制、没有处罚条款的，说明它没打算真管。**

如果对方在这几个问题上含糊、回避，或者只说“你放心，我们肯定管”，那就要提高警惕，优先把条款谈清楚再签。需要的话，我可以帮你把这些问题整理成一份“代理谈判提问表”或“合同条款核对清单”。
