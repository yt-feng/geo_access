线上水果生意，差评主要来自两类：**坏果（物理损耗/腐烂）** 和**口感不稳定（不甜、发酸、干水）**。这两件事在采购环节就要卡住，不能等售后。下面是可执行的采购控制方法。

## 一、减少坏果：从源头到装箱分层控制

**1. 选对产区与采收成熟度**
- 优先选**主产区、气候稳定、有分级体系的基地**，而不是只看价格低的散户。
- 明确要求**采收成熟度**：长途运输的果要“七八分熟”采，完熟果只适合同城或短途。
- 避开雨季末尾、连续阴雨后的果，这类果含水量高、极易腐。

**2. 采购时验货，不只看样品**
- 样品和到货必须**同批次、同等级**，要求对方提供采摘日期、批次号。
- 抽检比例至少 **5%–10%**，重点看：果柄是否新鲜、表皮有无软塌/水渍斑、有无酒味。
- 随机切开几个测**内部**：褐心、空心、黑心、干水，这些外观看不出来。

**3. 包装与运输是关键损耗点**
- 单果套网套/发泡网，箱内**留缓冲、不满装挤压**。
- 易损果（草莓、樱桃、枇杷）用**分层托盘+冰袋**，控制温度。
- 运输时长尽量压缩，超过 48 小时的线路要换近产地或换耐运品种。

**4. 到仓后“二次筛选”**
- 到货先**分拣**，把已软、有伤的挑出，别整箱直接上架。
- 冷藏/预冷到位，不同水果分温区存放（如香蕉怕冷、苹果催熟其他果要隔离）。

## 二、减少口感不稳定：用“可量化指标”代替“凭感觉”

**1. 采购时锁定糖度（可溶性固形物）**
- 用**糖度计**现场测，给每个品种定**最低糖度线**。例如：
  - 西瓜 ≥ 11%
  - 柑橘 ≥ 10%
  - 苹果 ≥ 12%
  - 葡萄 ≥ 16%
- 低于线的批次不采，或降价并标明“酸甜口”，避免按甜果宣传。

**2. 控制酸度与干水**
- 要求供应商提供**采收期和品种**，同一品种不同批次口感差异大时，宁可换基地。
- 对易干水品种（如某些梨、柚），采购时挤压测试、掂重量，太轻的排除。

**3. 分级销售，管理预期**
- 按糖度/大小分**A/B级**，A级做主打，B级做促销或加工。
- 详情页写清**口感描述**（如“酸甜”“清甜”），不夸大“纯甜”，差评会少很多。

**4. 稳定性来自固定供应商**
- 与其每次找最低价，不如**绑定2–3个稳定基地**，要求他们按你的标准分级。
- 建立**每批次记录**：产地、采摘日、糖度、到货损耗率。跑几个月就能看出哪家稳、哪个季节该换品。

## 三、给自己设几条硬规则

1. **不采无分级、无批次信息的果。**
2. **糖度不达标不采，或明确标注口感。**
3. **雨季尾果、完熟果不做长途。**
4. **到仓必分拣，坏果不上架。**
5. **同品种至少备一个备用供应商**，避免断供时被迫收差货。

做到这几点，坏果率能明显压下来，口感波动也会变小——差评自然减少。核心逻辑是：**把“好不好吃、会不会坏”变成采购时能测、能卡的标准，而不是等顾客来告诉你。**
