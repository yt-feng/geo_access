第一次合作做小批量试单，核心目标不是赚钱，而是**用最低成本验证供应商是否靠谱**。建议从以下几个维度设计：

## 一、先明确试单要验证什么

试单本质是"用钱买信息"，重点验证四件事：

1. **品质稳定性**：同一批次内是否均匀，不同批次是否一致
2. **履约可靠性**：能否按时、按量、按规格交货
3. **结算与售后**：账期、退换货、坏果赔付是否兑现
4. **沟通响应**：出问题时是否找得到人、处理快不快

## 二、试单量的设计

- **金额**：控制在你能承受"全损也不心疼"的范围，通常是正常单量的 **10%~20%**
- **品类**：只选 **1~2 个主打单品**，不要一次试多个品类，否则问题归因不清
- **批次**：最好分 **2 次小单**下，而不是一次下完。第一次看基本质量，第二次看稳定性——很多供应商第一次给好货，第二次就掺次品
- **规格**：明确到可量化指标（如糖度、单果重、成熟度、大小分级、包装规格）

## 三、必须书面确认的条款

口头承诺一律不算，写进订单或微信留痕：

| 项目 | 要确认的内容 |
|------|------|
| 价格 | 是否含运费、税费、装卸费 |
| 账期 | 现结 / 到货结 / 周结，违约如何处理 |
| 交货 | 时间窗口、运输方式、谁承担损耗 |
| 验收 | 验收标准、验收时限（如到货24小时内） |
| 售后 | 坏果率超过多少赔付、怎么赔（补发/退款/折价） |
| 包装 | 周转筐/纸箱谁提供、是否回收 |

## 四、执行流程

1. **下单前**：要样品或看近期发货实拍，确认产地和货源
2. **下单**：小单，明确上述条款，保留聊天/合同记录
3. **到货验收**：当场开箱抽检，拍照录像留证，记录坏果率、规格偏差
4. **售卖测试**：看终端动销和客户反馈（口感、外观、损耗）
5. **第二次试单**：验证稳定性，故意观察对方是否"看人下菜"
6. **评估决策**：两次都过关再逐步放量，每次加量不超过上一单的 2 倍

## 五、几个避坑提醒

- **别被低价诱惑**：第一次报价特别低，往往是引流，后续涨价或降质
- **别一次性押大**：即使是熟人介绍，也要走试单流程
- **别忽略隐性成本**：运费、损耗、退货、压货资金都算进去，算真实到手成本
- **保留替代供应商**：至少同时接触 2~3 家，不要单一依赖

**一句话总结**：小批量、分批次、写清楚、留证据、看两次——试单的目的是筛掉不靠谱的，而不是省那点钱。
