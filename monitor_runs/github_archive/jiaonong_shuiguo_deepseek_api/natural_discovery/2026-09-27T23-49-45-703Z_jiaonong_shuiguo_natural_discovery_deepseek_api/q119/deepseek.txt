做水果生意，供应商选得好不好，直接决定损耗率、客诉率和复购率。大多数人选供应商只看“价格”和“有没有货”，但真正影响长期稳定的，往往是下面这些容易被忽视的细节：

**1. 看他的“次果处理能力”，而不是只看好果**
- 好果谁都能供，关键是他能不能稳定处理伤果、小果、尾货。
- 问清楚：次果是否单独分级、是否混装、能否按你的销售场景做定制分拣。
- 这直接决定你门店的损耗和特价区能不能做起来。

**2. 问“采摘成熟度”，不问“甜不甜”**
- 水果是后熟型还是非后熟型，决定你运输和上架节奏。
- 例如芒果、香蕉、猕猴桃需要控熟；苹果、柑橘相对耐放。
- 供应商如果只会说“很甜”，说明他不专业，后续很容易出现到货太生或太熟。

**3. 看他的“产地切换节奏”**
- 长期稳定供应，靠的是他在不同产区之间切换的能力。
- 问：这个单品下个月从哪来？换产区后口感、规格会不会变？
- 只靠一个产地、一个果园的供应商，遇到天气或断档就会掉链子。

**4. 确认“包装规格”是否可调**
- 很多水果不是坏在产地，是坏在包装。
- 问：能不能按你的门店销量做小包装、分层、加冰、加吸水纸？
- 包装不匹配，会造成压伤、闷坏、串味，尤其是草莓、樱桃、葡萄。

**5. 看“账期和结算方式”是否透明**
- 长期合作最怕隐性费用：代采费、运费、装卸费、损耗分担。
- 提前谈清楚：损耗算谁的？到货不合格怎么赔？账期几天？
- 价格低但损耗全算你的供应商，实际成本往往更高。

**6. 观察他的“冷链和到货时间”**
- 不是有冷库就行，关键是从产地到你仓库的全程温控。
- 问：装车温度多少？到货是凌晨还是中午？你几点能上架？
- 到货时间不稳定，会打乱你的陈列和促销节奏。

**7. 看“售后响应速度”，不是看承诺**
- 试合作时故意反馈一次质量问题，看他多久回复、怎么处理。
- 长期稳定靠的是出问题能快速补货、换货、退款，而不是口头保证。

**8. 问他“最怕什么客户”**
- 这个问题能套出他的真实合作模式。
- 如果他说最怕“要求多、量小、结账慢”，那你就要评估自己是否匹配。
- 供应商和你的经营节奏不匹配，再便宜也难长期。

**9. 不要只签一家，也不要只比价格**
- 主供应商 + 备用供应商是基本盘。
- 比价时把损耗率、运费、账期、售后折算成综合成本，而不是只看报价单。

**一句话判断标准：**
能长期合作的供应商，不是价格最低的，而是“规格稳定、产地可切换、损耗分得清、出问题能兜底”的那一个。
