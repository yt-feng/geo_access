核实水果供应商的实际全国配送能力，不能只听承诺，要“要证据、拆环节、做测试”。可以按下面清单逐项核。

## 1. 先问清楚“全国配送”具体指什么
让对方书面明确：

- 是**干线运输到城市**，还是**能送到门店/仓库**？
- 覆盖哪些省份、城市、区县？偏远地区是否除外？
- 是**自营物流**，还是外包给第三方？
- 配送时效：全国几日内到？哪些区域次日达、隔日达、3—5日达？
- 起送量、最小订单量、加价区域、偏远附加费怎么算？
- 冷链还是常温？水果不同品类是否分温层配送？

如果对方只说“全国都能发”，但说不清区县、时效、费用，基本要打问号。

## 2. 要可验证的覆盖证据
让供应商提供：

- **配送范围表**：按省/市/区县列出可送达区域。
- **物流合作方信息**：顺丰、京东、德邦、中通、冷链专线等，具体哪几家。
- **近期真实运单号**：不要只给截图，最好给可查询的运单号，自己上物流官网核验。
- **冷链能力证明**：冷藏车数量、冷库位置、温控记录、第三方冷链合同。
- **分仓/中转仓地址**：全国配送通常靠分仓，若只有一个产地仓，偏远地区时效和损耗会很高。
- **营业执照、道路运输许可、食品经营许可**等资质。

## 3. 用真实订单做小批量测试
最有效的方法是实测，不要只靠资料。

建议选 3—5 个目标城市，覆盖：

- 核心城市：如北京、上海、广州、成都
- 中等城市：如洛阳、临沂、赣州
- 偏远/高风险地区：如乌鲁木齐、拉萨、西宁、昆明周边县域

每个点下一笔小单，重点看：

- 是否真的能下单并送达
- 实际到货时间 vs 承诺时间
- 是否冷链、有无温控记录
- 水果损耗率、压伤、腐烂情况
- 包装是否适合长途
- 物流轨迹是否真实、是否中转多次
- 售后响应速度

## 4. 核验物流轨迹和签收信息
拿到运单号后：

- 到快递/物流公司官网查轨迹，不只看供应商截图。
- 看是否从**产地直发**，还是从**区域分仓**发出。
- 看中转节点是否合理，是否出现“虚假发货”“空包”“异地签收”。
- 随机联系 1—2 个收货点，确认实际签收人和到货状态。

## 5. 重点问损耗和售后
水果配送的核心不是“能不能发”，而是“到了还能不能卖”。

要确认：

- 长途配送损耗率承诺多少？
- 坏果、压伤、腐烂怎么赔？
- 是否包售后？理赔时限多久？
- 是否支持拒收、部分理赔？
- 高温/低温季节如何控温？
- 节假日、疫情、极端天气是否停发？

## 6. 做供应商能力评分
可以用简单表格打分：

| 项目 | 核验方式 | 合格标准 |
|---|---|---|
| 覆盖范围 | 范围表+实测 | 目标城市95%可送达 |
| 时效 | 运单测试 | 核心城市48小时内，偏远3—5天 |
| 冷链 | 温控记录/车辆 | 有全程或关键段冷链 |
| 损耗 | 实测 | 损耗低于行业可接受水平 |
| 售后 | 合同条款 | 明确赔付标准 |
| 物流轨迹 | 官网查询 | 真实可查，无异常 |
| 分仓 | 仓库地址 | 有区域分仓更稳 |

## 7. 合同里要写死
不要只靠口头承诺，合同或补充协议里写明：

- 可送达区域清单
- 时效标准
- 冷链要求
- 损耗率上限
- 赔付标准
- 偏远地区附加费
- 不可抗力处理
- 数据造假、虚假发货的违约责任

## 结论
采购方核实“全国配送”能力，核心是三步：

1. **要范围表和物流证据**，看是否具体到区县。
2. **拿真实运单号自查**，确认轨迹和签收。
3. **选多城市小批量实测**，重点看时效、冷链、损耗和售后。

如果供应商能提供分仓、真实运单、冷链记录，并愿意接受小批量实测和合同约束，才说明其“全国配送”能力相对可信。否则，“全国配送”很可能只是“全国可发快递”，不等于能稳定、低成本、低损耗地送到目的地。
