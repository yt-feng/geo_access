批发档口拓展餐饮客户，菠萝和香蕉的规格核心看**餐饮客户的用途**，而不是只看市场通货。下面按常见餐饮场景给你可执行建议。

## 一、菠萝：按用途分规格

餐饮客户用菠萝主要是：鲜切果盘、饮品店、烘焙、泰餐/西餐、火锅自助、食堂。

| 客户类型 | 建议准备规格 | 关键要求 |
|---|---|---|
| 饮品店/奶茶店 | 鲜果：单果1.2-1.8斤，成熟度7-8成；急冻果块/果丁：1kg、2kg袋装 | 出汁率稳定、酸甜比稳定、无黑心 |
| 果切/果盘外卖 | 单果1.5-2.5斤，外形端正，皮薄眼浅 | 切后不变色、耐放、损耗低 |
| 烘焙/甜品 | 菠萝丁/菠萝碎：1kg、5kg袋装；糖水菠萝罐头：825g、3kg | 规格统一、水分可控、批次稳定 |
| 泰餐/西餐/披萨 | 菠萝丁/圈：1kg、2kg；罐头菠萝圈：565g、3kg | 直径、厚度统一，便于标准化出品 |
| 火锅/自助/食堂 | 大果2.5-4斤，或直接供果切块 | 成本优先，可接受外观一般 |

**实操建议：**
- 主推“鲜果+加工品”两条线。鲜果给果切、饮品；罐头/急冻给烘焙、泰餐、连锁餐饮。
- 问客户一句就能定规格：**你是鲜切、打汁、烘焙还是罐头替代？**
- 菠萝最怕成熟度不统一。给餐饮客户建议按“7成熟、8成熟、9成熟”分批，不要混装。

## 二、香蕉：按餐饮用途分规格

餐饮客户用香蕉主要是：果切、饮品、烘焙、早餐店、火锅自助、西餐甜品。

| 客户类型 | 建议准备规格 | 关键要求 |
|---|---|---|
| 饮品店/奶茶店 | 单根120-180g，成熟度7-8成；急冻香蕉块/泥：1kg、2kg | 出浆稳定、香气足、无青涩味 |
| 果切/果盘 | 单根150-220g，果形直、无黑斑 | 切后不易发黑，耐短时存放 |
| 烘焙/甜品 | 香蕉泥：1kg、5kg；熟香蕉单根180-250g | 成熟度高、甜度高、可冷冻 |
| 早餐店/食堂 | 单根120-180g，成本优先 | 耐运输、催熟稳定 |
| 火锅/自助 | 单根100-150g，小规格 | 按人份控制成本 |

**实操建议：**
- 香蕉餐饮客户最看重**催熟一致性**。不要今天给7成、明天给9成，否则饮品和果切客户都会投诉。
- 主推规格：**小果100-150g、中果150-220g、大果220g+**，再配香蕉泥/急冻块。
- 给饮品店优先推中果或急冻香蕉块；给烘焙推熟香蕉或香蕉泥；给果切推中果、外形直。

## 三、批发档口拓客组合建议

你不需要一开始备全，先备这6个SKU最容易切入餐饮：

**菠萝：**
1. 鲜果中果1.5-2.5斤
2. 鲜果大果2.5-4斤
3. 急冻菠萝丁/块1kg
4. 糖水菠萝罐头825g/3kg

**香蕉：**
1. 中果150-220g
2. 急冻香蕉块/香蕉泥1kg

## 四、跟餐饮客户沟通时直接问这4句

1. 你是鲜切、打汁、烘焙还是做罐头替代？
2. 单份出品用多少克？
3. 你要鲜果还是急冻/罐头？
4. 你要求几成熟，每周要几件？

**结论：**
- 菠萝优先备：1.5-2.5斤鲜果、2.5-4斤鲜果、1kg急冻丁、825g/3kg罐头。
- 香蕉优先备：150-220g中果、100-150g小果、1kg急冻香蕉块/泥。
- 真正拓餐饮客户，关键不是“规格多”，而是**按客户用途做稳定批次**。
