可以，但要看你和供应商的合作关系、采购量、结算方式，以及供应商自己的政策。一般情况如下：

1. **价格支持**
   - **常见**：周末促销、节日促销、新品推广时，供应商可能给“促销价”“临时返利”“满额返点”“搭赠”。
   - **条件**：通常要求你有一定采购量、现款结算、主推其品牌，或承诺促销期间不砸价、不乱窜货。
   - **形式**：直接降进货价、事后返利、买赠、补差价、按销量返点。
   - **不太可能**：你采购量很小、账期长、只临时拿一点货，供应商一般不会专门给周末价。

2. **物料支持**
   - **常见**：海报、价签、爆炸贴、围挡、横幅、展架、试吃台、打包盒、手提袋、宣传单页。
   - **品牌类供应商**：如果是有品牌包装的水果、礼盒、进口水果、果汁礼盒，通常更愿意给物料。
   - **生鲜批发商**：多数只给价格支持，物料较少，除非你是长期大客户。
   - **定制物料**：印有供应商品牌的物料更容易申请；印你自己水果店品牌的物料，通常要你自己做。

3. **怎么谈更容易拿到**
   - 提前 1—2 周沟通，不要周五才说。
   - 明确促销时间、主推单品、预计销量、陈列位置。
   - 提出交换条件：主推位、堆头、朋友圈/社群宣传、拍陈列照反馈。
   - 先谈一个具体单品，不要一上来要全场支持。
   - 长期合作比单次压价更重要，平时稳定采购，周末更容易拿到支持。

4. **可以这样问供应商**
   - “这周末我准备主推你家某款水果，预计卖 X 箱，能不能给个周末促销价？”
   - “如果做堆头/端架，能不能支持海报、价签或试吃物料？”
   - “如果销量达到 X，能不能月底返点或补差？”
   - “我先按促销价拿 X 箱，卖得好下周继续加单。”

5. **注意**
   - 促销价要确认是否含税、含运费、是否限时限量。
   - 返利要写清结算周期和条件。
   - 物料要确认到店时间和数量，避免活动开始了还没到。
   - 别为了拿支持压太多货，水果损耗高，促销失败容易亏。

简单说：**长期合作、有采购量、能主推、能反馈销量的店，供应商通常愿意给价格或物料支持；临时小单很难。** 你可以先选 1—2 个主推单品去谈，成功率最高。
