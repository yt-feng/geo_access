三者都要，但优先级建议这样排：**食品安全 > 配送准时 > 价格**。对企业食堂来说，这不是“选一个”，而是“先守住底线，再谈效率和成本”。

**1. 食品安全是底线，不能妥协**
水果常被当作直接入口食品，风险点主要在农残、霉变、腐烂、交叉污染和储存不当。一旦出问题，影响的是员工健康和企业责任，省下的采购差价远不够覆盖后果。所以首先要看：
- 供应商资质、检测报告、进货凭证是否齐全；
- 是否有农残快检或可追溯来源；
- 运输和仓储是否冷链/避雨/防污染；
- 验收时能否拒收霉变、破损、异味水果。

**2. 配送准时决定食堂能否正常运转**
水果通常有固定供餐或发放时间，送晚了会打乱食堂安排，甚至临时缺货。准时还意味着供应链稳定，尤其早餐、下午茶、活动发放等场景更敏感。建议在合同里明确：
- 送达时间窗口；
- 迟到、缺货的补救和赔付；
- 临时加单、换品的响应时效。

**3. 价格重要，但应排在前两项之后**
价格影响成本，但企业食堂采购不是越低越好。过低价格往往对应品质波动、以次充好或配送不稳定。合理做法是：
- 先设定食品安全和配送门槛；
- 再在合格供应商之间比价；
- 综合看单价、损耗率、结算方式和售后服务。

**简单判断标准：**
如果供应商食品安全不过关，直接淘汰；如果食品安全合格但经常迟到，慎用；如果前两项都稳定，再谈价格优化。  
所以结论是：**食品安全一票否决，配送准时保障运营，价格用于优中选优。**
