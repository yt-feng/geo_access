# 小水果店做小区团购：供应商需要支持哪些服务

做小区团购和普通批发进货是两回事，核心差别在于**订单不稳定、要分拣、要配送、售后多**。所以选供应商时，重点看这几类服务：

## 一、基础供货能力

| 服务项 | 为什么重要 |
|---|---|
| **稳定供货、不断货** | 团购一旦开团，缺货就要退单，伤客情 |
| **品类齐全** | 一个团能凑齐引流款+利润款+爆款，不用跑多家 |
| **按团购规格包装** | 比如5斤装、10斤装，直接能发，不用自己再分 |
| **支持小批量起订** | 小店资金有限，一次进太多损耗大 |

## 二、价格与结算支持

- **团购专属价/阶梯价**：量大更便宜，你才有利润空间
- **支持先货后款或账期**：团购回款有周期，现金流压力小
- **价格保护**：团购期间别突然涨价
- **支持一件代发**（如果不想囤货）

## 三、分拣与配送

这是最容易踩坑的环节：

- **按订单分拣打包**：最好能按你给的订单表分好，你直接配送
- **配送到店/到小区**：是否送货上门，还是自提
- **配送时效**：水果怕放，最好当天到、支持次日达
- **冷链/保鲜**：夏天做团购，没有冷链损耗会很高

## 四、售后与损耗处理

- **坏果包赔**：明确赔付比例和流程，比如坏果超5%怎么算
- **退换货支持**：整批质量问题能退换
- **损耗承担约定**：运输途中坏果谁负责，提前说清

## 五、营销与运营支持（加分项）

- **提供团购素材**：图片、文案、活动方案，省你时间
- **支持定制包装/贴牌**：提升小区信任感
- **爆品推荐和选品建议**：帮你搭配引流款和利润款
- **数据反馈**：哪些品好卖，辅助你下次开团

## 六、合作前的必问清单

1. 起订量多少？能不能小批量试单？
2. 团购价怎么算？有没有阶梯价？
3. 能不能按订单分拣？配送范围覆盖哪些小区？
4. 坏果怎么赔？多久内反馈有效？
5. 结算是现结还是账期？
6. 团购期间价格会不会变？

---

**给你的实操建议**：

先别急着签大供应商，**找1-2家本地批发市场或产地直供做小批量试单**，重点测试三件事：分拣是否省心、配送是否及时、坏果赔付是否爽快。跑通1-2个小区后再放量，风险最小。
