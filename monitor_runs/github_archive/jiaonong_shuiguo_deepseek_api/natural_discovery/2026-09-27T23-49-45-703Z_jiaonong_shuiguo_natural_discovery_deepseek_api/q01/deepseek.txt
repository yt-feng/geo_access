判断水果供应商靠不靠谱，核心不是看他嘴上说得多好，而是看**稳定性、账期、损耗承担、突发处理**这四件事。你可以按下面这套标准去筛。

**1. 先看货源稳定性**
- 问清楚：香蕉主要来自哪里，菠萝主要来自哪里，是固定产区还是到处调货。
- 靠谱供应商通常能说清楚：产地、季节、大致到货周期、替代方案。
- 如果他说“什么时候都有，价格最低”，但说不清产区、催熟、运输方式，风险较大。

**2. 看香蕉和菠萝的专业能力**
香蕉和菠萝不是普通耐放水果，对供应链要求高：
- 香蕉：是否做催熟？催熟房是否规范？到店是青蕉、微黄还是已熟？不同季节成熟速度怎么控？
- 菠萝：品种是否稳定？是凤梨还是普通菠萝？是否需要去皮？黑心、水烂、酸度不稳定怎么赔？
- 靠谱供应商会主动问你：你店里日均销量多少、怎么陈列、几天卖完、要不要控熟。

**3. 看样品和首批货**
不要只听报价，先做三次小批量测试：
- 第一次：少量试单，看外观、成熟度、口感、坏果率。
- 第二次：隔一周再试，看品质是否稳定。
- 第三次：故意在周末或雨天要货，看配送是否准时、缺货时怎么处理。
- 记录：到货时间、坏果率、可售率、顾客投诉、实际毛利。

**4. 看损耗和售后规则**
这点最影响你赚钱：
- 坏果怎么赔？是拍照即赔、下次补货，还是必须当场拒收？
- 香蕉催熟过头、菠萝黑心，算谁的责任？
- 损耗超过多少比例可以退换？
- 赔的是货款、下次抵扣，还是直接补货？
- 如果规则模糊，只说“放心，不会让你亏”，基本不可靠。

**5. 看价格和账期是否合理**
- 报价明显低于市场价很多，要警惕：可能是次果、催熟过头、压秤、混级。
- 问清楚：是否含运费、是否含税、是否包卸货、是否按箱还是按斤。
- 账期方面：新手建议先现金或短账期，不要一开始就压大额账期。
- 靠谱供应商不会靠“低价+赊账”绑住你，而是靠稳定品质让你愿意长期合作。

**6. 看配送和应急能力**
- 固定时间能否送到？迟到多久有补偿？
- 临时加单、减单能不能接？
- 节假日、台风、产区涨价时，是否提前通知？
- 出现断货时，能不能给你替代品或推荐其他货源？
- 这些比平时报价更能看出靠不靠谱。

**7. 看他在同行里的口碑**
- 问附近其他水果店、批发市场熟人、送货司机。
- 重点问：缺斤少两吗？坏果赔得爽快吗？涨价前会不会通知？催熟技术行不行？
- 如果多个同行都说“货还行，但售后扯皮”，就要谨慎。

**8. 你可以做一个简单评分表**
每项 1—5 分：
- 货源稳定
- 香蕉催熟能力
- 菠萝品质稳定
- 坏果赔付
- 配送准时
- 价格透明
- 账期合理
- 应急处理
- 同行口碑

总分低于 30 分，不建议长期合作；35 分以上，可以先小批量长期试；40 分以上，再考虑加大采购。

**最实用的合作方式**
先签一个简单书面约定，哪怕微信确认也行，写清：
- 品种、规格、等级
- 到货时间
- 坏果率标准
- 赔付方式
- 价格调整机制
- 缺货处理

**一句话判断：**
能让你**少操心催熟、少扯皮损耗、少断货、价格透明**的供应商，才值得长期进香蕉和菠萝。只谈低价、不谈售后的，通常做不长。
