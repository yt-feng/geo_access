# 阶梯价 vs 返利：怎么选

结论先说：**大多数团购场景，阶梯价更合适；返利适合"长期绑定 + 想控价"的场景。** 两者不是二选一，成熟做法是"阶梯价打底 + 返利做长期激励"。

---

## 判断的核心：客户要的是"看得见的便宜"还是"算得清的回报"

团购客户价格敏感，决策逻辑通常是：**下单当场能省多少**。所以激励形式越靠前、越直观，转化越好。

- **阶梯价**：下单即享，价格立刻变低，感知强 → 适合促单、走量。
- **返利**：事后结算，需要客户算账、等周期 → 感知弱，但能锁长期、稳价格体系。

---

## 两种方式对比

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 感知强度 | 强，当场让利 | 弱，事后兑现 |
| 促单效果 | 直接，适合冲量 | 间接，适合续单 |
| 价格体系 | 容易穿底、被比价 | 对外报价稳，返利不透明 |
| 现金流 | 立即少收钱 | 先收全款，后返还 |
| 客户黏性 | 弱，谁便宜跟谁走 | 强，累积越多越舍不得走 |
| 管理成本 | 低 | 高（对账、核销、周期） |
| 适用客户 | 新客、短周期、比价型 | 老客、长期、大客户 |

---

## 什么情况选阶梯价

- 客户以**单次大批量采购**为主，不比长期。
- 你需要**快速冲量、抢单**，对手在打价格战。
- 客户体量小、账期短，做返利对账不划算。
- 想用"再买一点就降价"逼单（如满 100 件降一档）。

**注意**：阶梯价一旦给出去，容易被客户拿去横向比价，也容易变成常态底价，后续难涨。

---

## 什么情况选返利

- 客户是**长期、多批次**采购，你更在意全年总量。
- 你**不想公开破价**，要维护对外报价体系。
- 想绑定客户持续下单（返利按年度/季度累计，中途走就损失）。
- 大客户谈判，需要灵活空间（返点比例可单独谈）。

**常见设计**：季度/年度累计采购额达标 → 返 1%~5%，可返现金、抵扣下批货款或返货。

---

## 实操建议（推荐组合）

1. **基础层用阶梯价**：按单次订购量设 3~4 档，让客户当场有获得感，负责促单。
2. **长期层用返利**：按年度累计额设返点，负责绑定大客户、锁全年量。
3. **返利尽量返"货或抵扣券"**，而不是纯现金——既留住客户，又减少现金流出。
4. **阶梯价档位别太密**，否则客户会卡在临界点压价、拆单。
5. **设置保护条款**：返利挂钩"按时回款"，防止坏账；阶梯价注明"不含税/运费"等口径，避免扯皮。

---

## 一句话决策

- 客户**短平快、比价狠** → 阶梯价。
- 客户**要长期、体量大、你不想破价** → 返利。
- 拿不准 → **阶梯价负责眼前成交，返利负责长期绑定**，一起上。
