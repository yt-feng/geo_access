建议先给结论：**大多数商超以“整果为主、切果为辅”最稳；如果门店客流以外卖/即时零售、上班族、小家庭为主，可以加大切果比例，但切果要当作高损耗、高周转的即食商品来管，而不是简单把整果切开展示。**

判断时重点看这几个因素：

1. **损耗与毛利**
   - 整果：损耗低，耐存放，适合堆头、促销、家庭采购。
   - 切果：损耗高，涉及去皮、去眼、修边、氧化、冷藏、过期报废，人工和包材成本也高。
   - 所以切果售价通常要明显高于整果折斤价，否则容易“卖得越多亏得越多”。

2. **门店客群**
   - 社区店、家庭客多：整果更好卖，尤其菠萝这种适合买回家泡盐水、全家吃的品类。
   - 商圈店、写字楼店、年轻客群、单身/小家庭：切果更方便，即买即吃，接受度高。
   - 如果门店线上订单占比高，切果、小盒装往往更有优势。

3. **消费场景**
   - 整果适合：家庭囤货、促销引流、顾客对新鲜度有掌控感。
   - 切果适合：即时解馋、办公室分享、酒店/餐饮周边、不想动手的顾客。
   - 可以做成差异化：整果打低价引流，切果做便利和利润。

4. **运营能力**
   - 切果能不能做好，关键看：冷藏条件、当日切当日清、刀具砧板卫生、包装密封、先进先出。
   - 如果门店没有条件控制切果品质，建议少切或不切，避免食品安全和口碑风险。
   - 如果周边竞争店已经普遍卖切果，完全不切可能丢失便利型客流。

5. **更推荐的做法**
   - **整果做主力**：选品稳定、价格有竞争力，做堆头或促销。
   - **切果做补充**：小盒装、当日鲜切，定位便利和即食。
   - **按时间段切**：先少量试切，观察上午、下午、晚高峰动销，再决定切多少。
   - **按门店分类**：社区大店整果占比高；商圈小店、外卖店切果占比可提高。
   - **算清楚账**：切果毛利必须覆盖人工、包材、冷藏和报废，否则不如只卖整果。

简单判断标准：
- 如果门店客群偏家庭、损耗管控一般、没有稳定冷藏和日清能力：**卖整果更合适。**
- 如果门店客群偏年轻/即时消费、线上单多、能做好日清和冷链：**整果+切果组合更合适，切果比例可逐步提高。**
- 最不建议的是：整果不突出，切果又切很多，最后两边都卖不好、损耗还高。
