连锁商超选长期水果供应商，建议把评分标准设计成“能验证的硬指标”为主，而不是只看报价低。可以按下面框架设置，总分100分。

## 一、建议评分结构

| 维度 | 建议权重 | 核心目的 |
|---|---:|---|
| 价格与成本 | 25–30分 | 防止低价中标后以次充好 |
| 产品质量与稳定性 | 25–30分 | 水果是核心，必须可量化 |
| 供应保障与履约能力 | 15–20分 | 保证不断货、不缺斤少两 |
| 食品安全与合规 | 10–15分 | 一票否决项单独设 |
| 服务与协同 | 5–10分 | 长期合作看配合度 |
| 可持续与产地能力 | 5–10分 | 长期稳定、抗风险 |

生鲜水果建议质量+食安+履约合计不低于55分，否则容易变成“低价内卷”。

## 二、各维度具体评分项

### 1. 价格与成本 25–30分
不要只比较“报价单”，要比较综合成本。

可设：
- 报价竞争力 15分：以招标基准价或最低有效价为基准，按公式折算，避免恶意低价。
- 价格调整机制 5分：是否接受随行就市但有上限、有调价周期。
- 损耗与退货成本 5分：损耗率承诺、坏果包赔比例。
- 账期与结算配合 5分：能否接受商超账期、对账效率。

注意：如果供应商报价明显低于市场均价，应要求提供成本说明，否则价格分不应给满。

### 2. 产品质量与稳定性 25–30分
这是最需要量化的一块。

可设：
- 样品盲测 10分：由采购、品控、门店代表盲测甜度、外观、口感、成熟度。
- 规格达标率 8分：按品种设定果径、单果重、糖度、色泽、成熟度标准。
- 批次稳定性 7分：过去6–12个月供货批次的合格率、退货率。
- 产地与品种优势 5分：是否核心产区、是否有稳定基地、品种是否匹配商超定位。

建议把“糖度、果径、成熟度、破损率”写进合同附件，评分时逐项打分。

### 3. 供应保障与履约能力 15–20分
长期供应商最怕旺季断货、淡季消失。

可设：
- 日供应能力 6分：能否覆盖商超所有门店，旺季峰值供应能力。
- 冷链与物流 5分：冷链车辆、仓储、配送时效、到店温度记录。
- 应急补货 4分：突发缺货时几小时内补货，是否有备用产地。
- 历史履约 5分：过往合同履约率、准时到货率、缺货次数。

### 4. 食品安全与合规 10–15分，建议设一票否决
可设：
- 检测报告 4分：农残、重金属、保鲜剂等按批次检测。
- 溯源体系 4分：能否追溯到地块、批次、采摘日期。
- 认证资质 3分：绿色食品、有机、GAP、HACCP等，按适用性给分。
- 食安事故记录 4分：近三年有无重大食安处罚或抽检不合格。

以下情况建议直接废标：
- 提供虚假检测报告；
- 近三年有重大食品安全事故；
- 拒不接受商超飞检或第三方抽检。

### 5. 服务与协同 5–10分
可设：
- 售后响应 3分：坏果、短装、质量异议的处理时效。
- 对账与开票 2分：票据规范、对账及时。
- 促销与新品配合 3分：能否配合商超做堆头、促销、新品导入。
- 信息化对接 2分：能否对接订单、库存、追溯系统。

### 6. 可持续与产地能力 5–10分
可设：
- 自有基地或长期合作基地 3分；
- 抗气候风险能力 3分：多产区布局、保险、储备；
- 社会责任 2分：用工合规、环保包装等；
- 长期合作意愿 2分：是否愿意签1–3年框架协议。

## 四、招标设置时的关键建议

1. **先定准入，再打分。**  
   营业执照、食品经营许可、检测能力、冷链能力、无重大违法记录，作为资格审查。

2. **质量分必须现场验证。**  
   只让供应商交资料，最后一定选到“会写标书”的，不一定是“会种水果”的。样品盲测、基地飞检、批次抽检要写进流程。

3. **价格分不要唯低价。**  
   可以设“低于基准价一定比例需作成本说明”，防止恶意低价后断供或降质。

4. **把评分承诺写进合同。**  
   评分时承诺的糖度、果径、损耗率、补货时效，要转成合同条款和扣款机制，否则评分没有约束力。

5. **设置动态淘汰。**  
   长期供应商不是一次中标管终身。建议季度考核，连续不达标降级或退出。

6. **分品类设权重。**  
   叶菜类更看重冷链时效，根茎类更看重耐储和价格，精品水果更看重产地和糖度。不要所有水果用同一张评分表。

## 五、一句话结论

连锁商超水果招标评分，建议采用“质量30 + 价格30 + 履约15 + 食安15 + 服务5 + 可持续5”的结构，食安设一票否决，质量用盲测和批次数据验证，价格看综合成本而非最低报价，并把中标承诺全部写进合同。
