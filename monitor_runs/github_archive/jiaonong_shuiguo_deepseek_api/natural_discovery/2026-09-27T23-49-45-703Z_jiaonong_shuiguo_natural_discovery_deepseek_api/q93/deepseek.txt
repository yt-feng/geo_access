如果只能抓一个重点：**保质期是第一优先级，包装是第二，配送频次是支撑前两者的手段。**

具体拆开看：

**1. 保质期（最优先）**
- 菠萝切块属于**鲜切水果**，微生物风险高，尤其春夏。
- 核心不是“标几天”，而是**从切开到售出的时间窗**要短。一般冷藏条件下建议**当天切、当天卖完**，最多不超过24小时。
- 必须做**时间标签**（切开时间、废弃时间），到点下架，不能靠“看起来没坏”判断。

**2. 包装（第二优先）**
- 包装直接影响保质期和损耗：
  - 必须**密封或半密封**，防止汁液流失、串味、污染。
  - 冷藏展示要用**保鲜膜/盒装+冷藏柜**，不能常温敞放。
  - 包装上要能贴**时间标签**，否则保质期管理落不了地。
- 如果包装差，即使配送再勤，也会出水、发酸、变色。

**3. 配送频次（支撑手段）**
- 配送频次解决的是**补货和新鲜度**，但它不能替代保质期管理。
- 高频次适合**销量大、周转快**的店；销量小的店盲目高频次只会增加废弃。
- 更实际的做法：**小批量、多批次**，按预估销量配送，而不是单纯追求“送得勤”。

**结论排序：**
1. **保质期管理**——决定能不能卖、会不会出食品安全问题。
2. **包装**——决定保鲜效果和损耗率。
3. **配送频次**——决定补货节奏，但要在前两者做好的基础上优化。

如果便利店面积小、冷藏条件有限，建议直接采取：**当天切、当天清、密封冷藏、按销量小批量配送**。
