会，而且通常影响挺直接。香蕉是典型的“外观分级定价”水果，同一箱里大小不一，主要会带来这几个问题：

1. **卖相差，顾客挑拣多**
   顾客买香蕉往往按“把”拿，大小混杂会显得不整齐，容易翻来翻去，增加损耗。

2. **成熟不一致**
   大果和小果在同一箱里，成熟速度可能不一样。有的已经黄熟，有的还青，陈列和促销都难统一。

3. **定价困难**
   如果按统一价格卖，大果划算、小果难卖；如果分开卖，又增加分拣人工。最后往往是小果剩下来，变成损耗。

4. **影响复购和口碑**
   顾客如果买到一把里大小差很多，容易觉得“货不匀”“不值”，下次可能换店。

5. **损耗和利润被吃掉**
   香蕉本身怕压、怕碰、后熟快。大小不一分拣后，小果、伤果、过熟果更难及时处理，损耗率会上升。

**实际建议：**

- 采购时尽量按等级拿货，比如同一箱大小相对均匀，别只看总价便宜。
- 如果已经进了大小不一的货，最好**开箱分拣**：大果、中果、小果分开陈列，按不同价格或不同用途卖。
- 小果可以捆小把、做特价、做果切、榨汁或做香蕉奶昔原料，别和大果混在一起硬卖。
- 陈列时把外观整齐的放在显眼位置，混装货放促销区，减少顾客挑拣。
- 下次采购明确要求供应商：**同一批次、同一规格、成熟度接近**，哪怕单价稍高，通常也比混装货好卖。

简单说：**会影响销售，而且影响不小。** 如果量不大、能分拣，还能补救；如果长期混装，最好换采购标准。
