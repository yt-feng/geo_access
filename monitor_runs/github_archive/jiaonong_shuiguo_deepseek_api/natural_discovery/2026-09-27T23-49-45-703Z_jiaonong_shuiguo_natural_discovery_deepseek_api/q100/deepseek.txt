学校食堂采购香蕉避免熟过头浪费，核心是**控制采购节奏、分级使用、改变储存和加工方式**。可按下面执行：

1. **按成熟度分批采购，不一次进全熟蕉**
   - 和供应商约定：每次送来的香蕉以**青黄相接、7成熟左右**为主，少量当天直接可吃的黄熟蕉。
   - 不要只按“数量”下单，要按**未来2—3天用量**下单。香蕉后熟快，尤其夏天，囤3天以上就容易过熟。
   - 可要求供应商分规格配送：青蕉、微黄蕉、即食黄蕉分开。

2. **采购量按“用餐人数×实际消耗”倒推**
   - 统计前1—2周香蕉实际领用量，而不是只看采购量。
   - 如果每人每次供应半根到1根，按窗口实际就餐人数估算。
   - 遇到节假日、考试周、天气变化，就餐人数波动大时，采购量要下调。

3. **储存要分温区、分成熟度**
   - **青蕉/微黄蕉**：放在阴凉通风处，理想温度约13—15℃，不要放冰箱冷藏，容易冻伤发黑。
   - **已经黄熟、准备1—2天内吃的**：可放冷藏减缓继续成熟，但表皮会变黑，不影响果肉即可尽快使用。
   - **不要和苹果、梨、番茄等释放乙烯较多的果蔬混放**，会加速香蕉成熟。
   - 成串香蕉可拆开、悬挂或单层平放，减少压伤和局部过热。

4. **建立“成熟度分级使用”规则**
   - 青蕉：留作后续2—3天。
   - 微黄蕉：正常窗口供应。
   - 黄熟蕉：优先当天供应，或放冷柜/冷藏暂存。
   - 过熟但未变质：转做香蕉牛奶、香蕉粥、香蕉饼、烘焙辅料、水果捞等，不再直接摆窗口。
   - 已发黑流汁、有酒味或酸味：坚决报废，不能加工再用。

5. **和档口联动，提前处理临熟蕉**
   - 每天下午检查库存，把第二天会过熟的香蕉提前挑出。
   - 通知面点、饮品、烘焙档口第二天优先使用。
   - 可设“香蕉特价窗口”或“香蕉牛奶套餐”，加快消耗。

6. **供应商条款要写清楚**
   - 约定成熟度标准、验收标准、退换货条件。
   - 如果到货过熟，应当天退换或折价，不能把损耗全压给食堂。
   - 对连续配送过熟的供应商，减少订单或更换。

7. **做简单台账，形成闭环**
   - 记录：到货日期、数量、成熟度、领用量、报废量、加工消耗量。
   - 每周复盘：哪种采购量、哪家供应商、哪个季节损耗最低。
   - 根据数据调整下周订单，而不是凭感觉采购。

最有效的组合是：**少量多次采购 + 7成熟为主 + 分温区储存 + 过熟前转加工 + 每日盘点**。这样能明显降低香蕉熟过头报废。
