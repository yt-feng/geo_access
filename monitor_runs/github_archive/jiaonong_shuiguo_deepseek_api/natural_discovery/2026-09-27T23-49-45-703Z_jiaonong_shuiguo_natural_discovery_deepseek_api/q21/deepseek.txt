超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果种类、来源（国产/进口）、以及超市自身的风控要求：

**一、主体资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视经营业态）
- 若为进口商，还需进出口相关资质

**二、进货凭证类**
- 供货合同或采购订单
- 发票或送货单
- 上一级供应商的资质和进货凭证（用于追溯）
- 食用农产品进货查验记录（批发市场或产地直采时常见）

**三、检测报告类**
- **农药残留检测报告**：最常见，通常要求符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》
- **重金属检测报告**：如铅、镉等，部分品类要求
- **食品添加剂/保鲜剂检测**：如柑橘类可能涉及保鲜剂
- **微生物检测**：一般鲜果较少，但即食类或切果需要
- **产地环境检测**：部分基地直采或有机认证产品会提供

**四、合格证明类**
- 农产品合格证（食用农产品合格证制度推行后较常见）
- 产地证明或基地备案证明
- 绿色食品、有机食品、地理标志等认证证书（如有宣称）

**五、进口水果额外需要**
- 海关入境货物检验检疫证明
- 报关单
- 中文标签或标签审核相关材料
- 输出国官方植物检疫证书

**六、超市实操建议**
- 要求供应商提供**批次对应的检测报告**，而非仅一份通用报告
- 检测报告应有 CMA 或 CNAS 资质标识
- 保留进货台账，便于追溯
- 对高风险品类（如叶菜、草莓等农残易超标品种）可要求更频繁检测或自行抽检

具体清单会因超市规模、地区监管要求和水果品类不同而有差异，建议以当地市场监管部门要求和超市内部采购标准为准。
