优先谈 **账期**，其次 **售后**，最后 **配送**。

原因很直接：长期合作里，账期直接影响你的现金流和议价地位，是“钱”的问题；售后决定出问题时谁承担损失，是“风险”的问题；配送通常最容易通过流程和标准优化，属于“效率”的问题。

可以按这个顺序判断：

1. **账期最优先**
   - 水果损耗高、价格波动大，账期谈不下来，你等于一直在给对方垫资。
   - 重点谈：账期天数、起算时间、结算方式、是否压保证金、逾期怎么处理。
   - 如果对方是长期供应商，可以接受“阶梯账期”：合作稳定后从现结逐步到 15 天、30 天。

2. **售后第二优先**
   - 水果非标品，坏果、少货、规格不符很常见。售后不清晰，最后都是你承担损耗。
   - 重点谈：坏果率标准、赔付方式、补发还是扣款、拍照留证时限、责任归属。
   - 最好写成一句话：**到货验收后 X 小时内反馈，按实际坏果比例扣款或补发，不扯皮。**

3. **配送最后谈，但不能不谈**
   - 配送频次、时间、起送量、临时加单、运费谁承担，这些影响运营，但通常有替代方案。
   - 重点谈：固定配送日、截单时间、迟到处理、冷链要求、临时补货是否加价。
   - 如果配送不稳定，可以要求“迟到超过 X 小时，当次运费减免或补偿”。

一个实用谈判顺序是：

**先谈账期 → 再谈售后赔付 → 最后用配送细节换让步。**

比如：
- 你要 30 天账期，对方不同意，可以退到 15 天，但要求售后坏果全额赔。
- 对方要现结，你可以要求配送频次增加、免运费、坏果包赔。
- 如果对方账期和售后都不让，那配送再便宜也不建议长期深度绑定。

一句话总结：**账期保现金流，售后保利润，配送保体验。长期合作先保钱和风险，再谈效率。**
