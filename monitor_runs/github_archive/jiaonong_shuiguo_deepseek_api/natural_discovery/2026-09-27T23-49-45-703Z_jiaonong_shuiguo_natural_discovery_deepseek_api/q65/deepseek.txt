结论：**不要“二选一”，而要做分层定价**——把采购和销售拆开，核心货源锁一段时间的价，边角货源每天随行就市。具体取决于三个变量：你的毛利厚度、货源是否可替代、以及你有没有议价能力。

**一、先判断你属于哪种情况**

| 你的处境 | 更适合 |
|---|---|
| 毛利薄（<10%）、价格波动大 | 锁价为主，减少日频议价 |
| 毛利厚、周转快、有稳定下游 | 每天议价，赚波动差价 |
| 单一产地、别处拿不到货 | 倾向签一段时期，保供应 |
| 货源多、可随时换供应商 | 每天议价，谁便宜拿谁 |
| 小批发商、议价弱 | 签一段时期锁成本，别赌行情 |
| 有冷库/加工能力、能囤货 | 低价期锁长期，高价期短约 |

**二、为什么极端做法都容易亏**

- **全每天议价**：价格上行时你天天被抬价，利润被吃掉；而且每天谈价耗人力、伤关系，供方一有更好的买家就先不给你。
- **全签固定长约**：价格一旦大跌，你按高价进货、按市价卖，直接亏；价格大涨，供方可能违约或降质，你反而拿不到货。

**三、可执行的分层方案**

1. **核心量锁价（约60%–70%）**：和你最稳定、质量最靠谱的产地/一级商签 **2–4周** 的滚动协议价，而不是半年长约。到期重谈，既稳供应又不过度暴露。
2. **弹性量随行就市（约30%–40%）**：每天或隔天议价，用于补缺、试新货源、抓低价机会。
3. **加价格条款**：
   - 设“浮动区间”：约定基准价±5%内不变，超出部分双方按比例分担。
   - 设“重谈触发线”：单周涨跌超某幅度就重新议价，避免一方硬扛。
   - 锁量不锁价、或锁价不锁量，二选一，别两个都死锁。
4. **用工具对冲波动**：有条件的可通过远期/期货（如苹果、红枣等有期货品种）做部分套保，但这不是所有批发商都适用，量小就别碰。

**四、一句话决策规则**

- 你**赌不准行情、又怕断供** → 锁一段时间的价（滚动短约）。
- 你**周转快、货源多、想赚差价** → 每天议价。
- 大多数批发商 → **核心锁价 + 边角日议**，这才是稳态。
