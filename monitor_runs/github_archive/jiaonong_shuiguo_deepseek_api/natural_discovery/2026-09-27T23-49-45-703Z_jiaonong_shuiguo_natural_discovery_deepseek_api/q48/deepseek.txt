判断的核心不是“供应商说能不能”，而是**用可验证的证据和试单来压测他的供货稳定性**。给你一套可直接照做的判断框架：

## 一、先锁定“规格”是什么
茶饮用的菠萝通常是：
- **鲜果**：品种（如金钻凤梨/台农17/都乐金菠萝）、单果重（如1.2–1.5kg）、成熟度（几成熟发货）、糖度（如≥14°Brix）、无黑心/水心病比例
- **冷冻果肉/果丁/果泥**：块型尺寸、糖度、是否加糖、菌落标准、包装规格
- **罐头/浓缩汁**：固形物、糖度、酸度、包装

**关键点**：规格必须写成可检测的数字（重量、糖度、直径、成熟度、破损率上限、农残标准），不能只写“大果”“新鲜”。标准越模糊，越无法判断他稳不稳定。

## 二、用这些问题筛掉不靠谱的
1. **产地是自有基地、合作社还是市场倒货？** 倒货商在旺季最容易断供或换规格。
2. **同一产区一年能供几个月？** 如果只有2–3个月，说明是季节性货源，旺季外必须找替代。
3. **有没有分选线/冷库？** 有分选才能稳规格，有冷库/冷链才能稳品质。
4. **日/周供货能力上限是多少？** 问具体数字，再对照你的需求。
5. **要一份近3个月的检测报告和出货记录**，而不是口头承诺。

## 三、必须做“试单压测”
- **小批量试单**：连续下3–5批，每批抽检重量、糖度、破损率、成熟度。
- **故意压交期**：下一次急单（比如48小时内到货），看他能否履约。
- **故意加量**：在某批把量提到平时的1.5–2倍，看是否掉规格。
- **旺季前锁量**：提前1–2个月确认旺季排产，看是否愿意签供货协议。

如果试单期间就出现：批次间糖度差大、单果重不达标、到货成熟度忽高忽低、缺斤少两，基本可以判定不稳定。

## 四、看合同和违约机制
- 写清**规格标准、抽检方法、不合格处理（退货/折价/补货）**。
- 约定**最低供货量+违约赔偿**，尤其是旺季。
- 要求**备用货源条款**：主供应商断供时，他有义务提前通知并协助过渡。

## 五、更稳的做法
- **不要只靠一家**：主供应商+备选供应商，比例约7:3。
- **按产区错峰采购**：不同产地成熟期不同，能拉长稳定供应窗口。
- **签“保量+保价”框架协议**：旺季锁量，淡季锁价或浮动规则写清。
- **到货即检**：糖度计、电子秤、成熟度抽检，数据留档，作为后续谈判依据。

一句话判断：**愿意让你验厂、验货、试单压测，并且敢把规格和违约写进合同的供应商，才可能稳定；只谈价格、不肯试单、规格含糊的，基本不稳。**
