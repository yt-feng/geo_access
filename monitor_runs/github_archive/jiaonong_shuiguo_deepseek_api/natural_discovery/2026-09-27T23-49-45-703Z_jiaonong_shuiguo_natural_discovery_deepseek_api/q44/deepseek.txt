判断供应商售后是否稳定，不要只听承诺，要按“可验证的动作”来压测。可以分四步做：

1. **先看合同里的售后条款是否可执行**
   - 明确响应时限：例如到货后出现烂果、黑心、催熟不均、青果不熟等问题，几小时内响应、几小时内给处理方案。
   - 明确责任边界：按批次、按比例、按损耗率赔付，还是补货、换货、退款。
   - 明确证据要求：照片、视频、开箱记录、温度记录、抽检记录由谁提供、多久内提交。
   - 明确对接人：不能只写“业务员”，要写具体售后负责人、备用联系人、电话、微信/企业群。
   - 如果没有这些条款，售后稳定基本无法保证。

2. **用历史记录验证，而不是听口头保证**
   - 要求供应商提供近3个月同类商超客户的售后处理记录，至少看：投诉批次、响应时间、处理结果、是否重复发生。
   - 问清楚：菠萝和香蕉分别的常见售后问题是什么，过去半年各发生几次，平均多久解决。
   - 如果对方说“基本没售后”，反而要警惕，可能是没记录、没上报，或客户不敢反馈。

3. **小额试单做压力测试**
   - 先下2—3个小批量试单，故意覆盖不同风险点：香蕉不同成熟度、菠萝不同产地/批次。
   - 到货后按标准抽检，发现问题立即按合同流程报售后，记录对方第一次响应时间。
   - 重点看：是否主动给方案，是否推诿到物流/门店，是否要求先补款再处理，是否拖延到超过水果货架期。
   - 试单期间可以设置一个“非工作时间问题”，比如晚上或周末反馈，看是否有备用响应机制。

4. **看供应链能力，不只看客服态度**
   - 菠萝、香蕉售后稳不稳，核心取决于供应商有没有稳定货源、催熟能力、冷链和区域仓。
   - 问清楚：香蕉是否自己催熟，催熟周期和到店成熟度怎么控制；菠萝是否有固定产地和分级标准。
   - 如果供应商依赖多个临时批发商拼货，售后响应通常不稳定，因为责任链太长。
   - 有区域仓、有备用货源、有质检人员的供应商，售后通常更可靠。

5. **把售后表现纳入考核**
   - 合作后按月统计：投诉率、平均响应时长、一次解决率、赔付/补货及时率。
   - 约定连续两次超时或一次严重推诿，就降级、暂停下单或扣保证金。
   - 对商超来说，最有效的是“售后响应和账期/返利/续约挂钩”，否则供应商没有动力。

简单判断标准：
- 能给出书面售后条款、具体对接人、历史处理记录，并愿意小额试单压测的，相对可靠。
- 只靠口头承诺“有问题找我”、没有时限、没有赔付标准、没有备用联系人的，售后大概率不稳定。
- 生鲜尤其要看“响应后多久能补货或赔付”，因为香蕉和菠萝货架期短，拖一天损失就扩大。
