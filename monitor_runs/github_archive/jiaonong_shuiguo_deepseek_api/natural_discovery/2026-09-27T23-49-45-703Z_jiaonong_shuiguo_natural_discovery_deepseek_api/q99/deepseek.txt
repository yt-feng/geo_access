选批量配送水果的供应商，关键不是找“最便宜”，而是找**履约稳定、损耗可控、能开发票、售后不扯皮**的。可以按下面几步筛。

**1. 先明确自己的需求**
- 人数：30人、100人、300人，采购方式差别很大。
- 频次：每周一次、每月一次、临时下午茶。
- 预算：人均5元、10元、15元，直接决定选品类。
- 形式：整果、果切、拼盘、果汁。
- 时间：必须几点前送到，是否要摆台、分装、垃圾清理。
- 发票：能否开专票/普票，是否对公付款。

**2. 优先考虑的供应商类型**
- **本地水果批发市场档口**：适合量大、预算低，但配送和售后不稳定。
- **生鲜B2B平台**：如美菜、快驴、蜀海等，适合公司采购，有发票和对公流程。
- **连锁水果店/区域水果连锁**：适合中小批量，品质稳定，可谈企业月结。
- **专业企业下午茶/团餐配送商**：省心，能配套果切、摆台，但单价高。
- **本地农场/合作社直供**：适合追求新鲜和特色，但品类季节性强，履约波动大。

**3. 重点看这几个硬指标**
- **准时率**：下午茶最怕迟到，要求写进合同或订单备注。
- **损耗处理**：坏果、压伤、不熟，是否当场补送或退款。
- **果切资质**：如果买果切，必须有食品经营许可证、操作间卫生条件。
- **配送能力**：是否有冷藏车、保温箱，是否专人对接。
- **结算方式**：能否月结、对公转账、开票。
- **应急预案**：临时加量、换品、天气影响时怎么处理。

**4. 建议的筛选流程**
1. 先找3—5家本地供应商，要求提供企业客户案例。
2. 让对方按你的人数、预算出2—3套方案。
3. 先试单一次，不要一上来签长期。
4. 试单时重点看：到货时间、水果新鲜度、大小是否均匀、有没有坏果、发票是否顺畅。
5. 试单合格后再谈月结、固定配送日、价格锁定。

**5. 适合批量配送的水果选择**
- 稳妥型：香蕉、橘子、苹果、圣女果、葡萄、西瓜。
- 颜值型：蓝莓、草莓、车厘子、阳光玫瑰，但损耗高、价格波动大。
- 省事型：果切拼盘，但必须确认资质和配送温度。
- 避坑：榴莲、山竹、软桃、熟透芒果，批量配送容易压坏或争议大。

**6. 合同或订单里一定要写清楚**
- 品种、规格、单果重量范围、数量。
- 送达时间、地点、联系人。
- 坏果率标准，比如超过5%怎么赔。
- 补送时限，比如2小时内补送。
- 发票类型、账期、付款方式。
- 临时取消或改单的规则。

**简单结论：**
小公司、频次低，优先找**本地连锁水果店或企业下午茶配送商**；中大公司、长期采购，优先找**生鲜B2B平台或批发市场档口+固定配送**。不管选谁，先试单，再签长期，把坏果赔付和准时送达写清楚。
