学校食堂采购常见水果，选择供应商的核心不是“找最便宜的”，而是先保稳定、安全、可追溯，再比价格。可以按下面几步做。

**1. 先定采购标准**

- **香蕉**：要求成熟度可控，别一次全熟。食堂最好能分批次到货，表皮无明显黑斑、无腐烂、无冻伤。
- **苹果**：要求大小相对均匀、硬度好、无明显磕碰伤。适合选耐储存品种。
- **橙子**：要求水分足、无干疤、无霉变，大小均匀，便于按个分发。
- **通用要求**：农残检测合格、可提供产地或批次信息、坏果率有上限、可按约定时间送货。

**2. 供应商类型怎么选**

- **大型水果批发商/配送公司**：适合食堂，能开票、能稳定配送、有检测报告，但价格通常不是最低。
- **产地合作社或果园**：价格可能好，但配送、分拣、开票、售后不一定跟得上，适合采购量大且学校有仓储能力时。
- **本地农贸批发市场商户**：灵活、价格有优势，但稳定性、票据和检测报告要重点核验。
- **生鲜平台或区域配送商**：服务规范，适合中小食堂，但要注意是否支持学校采购所需的资质和结算流程。

一般建议：**主供应商选配送能力强的，辅供应商选本地批发商或产地商**，避免单一供应商断供。

**3. 重点核验哪些资质**

- 营业执照、食品经营许可证或相关许可。
- 水果农残检测报告，至少能按批次提供。
- 进货凭证、产地证明或批发市场来源凭证。
- 配送车辆和仓储卫生情况。
- 是否能开具正规发票，是否符合学校财务结算要求。
- 有没有食品安全责任险，有则更好。

**4. 比价不要只看单价**

同一品种要按“可食用率”和“坏果率”算实际成本。比如苹果便宜但磕碰多、橙子便宜但干水，实际成本反而高。可以让供应商按：

- 到货价
- 坏果率
- 规格等级
- 配送频次
- 是否含税含运费
- 售后补货规则

一起报价，再横向比较。

**5. 建议的筛选流程**

1. 列需求：品种、规格、月用量、送货频次、结算方式。
2. 找 3—5 家供应商报价，至少包含 1 家配送公司、1 家本地批发商、1 家产地或合作社。
3. 要求送样，食堂和后勤一起看外观、口感、成熟度、坏果情况。
4. 小批量试供 2—4 周，记录到货准时率、坏果率、补货速度。
5. 综合评分后定主供应商和备选供应商，签合同明确质量、价格、退换货和违约责任。

**6. 合同里必须写清楚**

- 品种、规格、等级、单价或调价机制。
- 送货时间、地点、频次。
- 坏果率上限，比如超过多少包退包换。
- 农残检测报告随批次提供。
- 食品安全责任和赔偿条款。
- 结算周期和发票要求。
- 断供、迟送、质量不达标的处理办法。

**简单判断标准：**
能稳定送货、能提供检测和票据、坏果率低、售后补货快、价格在合理区间，就优先选。只便宜但不稳定、不给票据、检测报告拿不出来的，不建议作为学校食堂主供应商。
