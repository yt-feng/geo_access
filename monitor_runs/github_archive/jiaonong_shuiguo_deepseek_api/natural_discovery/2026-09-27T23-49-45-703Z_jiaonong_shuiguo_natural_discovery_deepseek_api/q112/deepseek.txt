水果采购合同里没有统一的法定赔付阈值，关键看合同约定和验收标准。实务上可以这样处理：

**1. 有合同约定时，按合同执行**
- 常见约定是：坏果率超过 **3%～5%** 就要索赔或扣款；超过 **5%～10%** 可要求退货、换货或按比例赔偿。
- 生鲜水果因易损，行业内较常见的是：**5%以内**视为合理损耗，**超过5%**开始协商赔付，**超过10%**通常可主张退货或拒收。
- 具体比例要看品种、运输距离、包装方式和合同写的是“到货验收”还是“卸货后一定时间内验收”。

**2. 没有明确约定时**
- 可依据《民法典》关于质量不符合约定的规定，要求对方承担违约责任，包括减少价款、赔偿损失、退货、换货等。
- 但你需要证明：坏果率确实超标、损失金额、以及坏果是在交付前就存在，而不是你收货后储存不当造成的。

**3. 实操建议**
- 合同里最好写明：**验收时间、验收地点、抽样方法、坏果率计算方式、超过多少赔付、按什么标准赔付**。
- 例如可写成：  
  “到货后24小时内验收，按随机抽样不少于10箱计算坏果率。坏果率≤5%视为合理损耗；超过5%的部分，按超出比例扣减货款；超过10%的，买方有权拒收或要求退货，卖方承担运费及损失。”
- 收货时立即拍照、录像、称重、记录批次和抽样数据，并让司机或送货人签字确认。

**结论：**
如果合同没写，通常可参考 **超过5%提出索赔协商，超过10%主张退货或拒收**；但最终以合同约定和实际验收证据为准。建议签合同时就把坏果率赔付条款写清楚，避免事后扯皮。
