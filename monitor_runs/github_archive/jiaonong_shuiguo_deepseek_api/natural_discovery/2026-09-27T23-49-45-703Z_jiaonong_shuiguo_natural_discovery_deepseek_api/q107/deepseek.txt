**1. 香蕉**
- 香蕉通常是青蕉到货，需要催熟或自然转黄。起订量太高会导致：
  - 一柜/一批集中转黄，短时间内必须卖完，否则很快出现黑斑、软烂。
  - 如果冷库温度控制不好，低于适宜温度会冻伤，表皮变黑但果肉未必熟。
  - 催熟批次安排不过来，容易出现“前面没熟、后面全熟”的断档或积压。
- 风险点：**集中转黄 + 销售速度跟不上 = 高损耗**。

**2. 菠萝**
- 菠萝相对耐储，但起订量太高也有风险：
  - 整果堆放通风差时，容易发霉、黑心、内部褐变。
  - 夏季高温下，成熟度高的菠萝货架期很短。
  - 如果门店或仓配端没有稳定周转，尾部货会因外观变差、切果品质下降而报损。
- 风险点：**耐储不等于不损耗，高起订量会把损耗推迟到后期集中爆发**。

**3. 什么情况下起订量高不一定更危险**
- 你有稳定的大客户、团购、餐饮渠道，能在 2–3 天内消化大部分货。
- 冷链和催熟能力匹配，能分批出库、分批催熟。
- 采购价优势足以覆盖预计损耗，且损耗率仍低于替代采购方案。
- 香蕉、菠萝分批次到货，而不是一次性集中到仓。

**4. 可执行的判断方法**
建议用简单公式估算：
- 预计日销量 = 过去 7–14 天同品类日均销量 × 季节系数
- 安全起订量 ≈ 预计日销量 × 可接受周转天数
- 可接受周转天数：
  - 香蕉：通常 2–4 天，夏季更短
  - 菠萝：通常 3–7 天，夏季偏短
- 如果起订量 > 安全起订量，就要么拆单、要么找分货渠道、要么谈更低采购价来覆盖损耗。

**5. 降低风险的做法**
- 要求供应商分批到货，而不是一次发齐。
- 香蕉按青度分批催熟，先卖先熟。
- 菠萝到货后及时通风、分级，先处理成熟度高的。
- 对高起订量品类设置损耗红线，比如超过 5%–8% 就调整采购量。
- 用促销、切果、果汁、烘焙原料等方式消化尾部库存。

**结论**：起订量太高会显著增加香蕉和菠萝的损耗风险，尤其是香蕉。关键不是单纯看起订量，而是看**起订量是否超过你的实际周转能力**。如果周转天数超过 4 天（香蕉）或 7 天（菠萝），风险通常就偏高了。
