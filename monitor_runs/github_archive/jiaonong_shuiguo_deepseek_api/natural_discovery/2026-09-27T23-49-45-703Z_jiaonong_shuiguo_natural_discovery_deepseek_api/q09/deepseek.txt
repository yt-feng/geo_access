旺季最怕的不是价格谈不拢，而是货到不了、到了品质不对、临时涨价。和供应商谈之前，先把下面几类问题问清楚，最好写进供货协议或微信确认留痕。

**一、供货能力与优先级**
- 旺季你每天/每周最多能稳定供我多少量？爆款单品（如西瓜、车厘子、阳光玫瑰）能保证多少？
- 如果我临时加量30%~50%，提前几小时/几天通知你能调到货？
- 旺季你同时供几家店？我排在第几优先级？断货时先保谁？
- 你有没有备用产地或二级供应商？主产地受灾/封路时怎么补？

**二、价格与调价机制**
- 报价是当天有效、一周有效还是随行就市？旺季会不会临时涨？
- 涨价提前多久通知我？能不能约定单日涨幅上限？
- 量大有没有阶梯价？长期合作有没有返点或保底价？
- 运费、装卸、损耗算谁的？到店价还是产地价？

**三、品质与验收标准**
- 规格怎么定？比如西瓜几斤起、糖度多少、车厘子什么等级？
- 次果、烂果、大小不均的比例允许多少？超标怎么赔或补？
- 是产地直发还是市场调货？能不能先发样品确认？
- 到货后发现品质不达标，多久内可以拒收或换货？

**四、交货与物流**
- 每天几点前下单、几点到店？能不能固定时段配送？
- 旺季物流会不会延迟？延迟超过几小时怎么处理？
- 缺货、少货、错货怎么补？补货多久到？
- 谁负责卸货？冷链水果有没有冷藏车？

**五、结算与风险**
- 结算是现结、周结还是月结？旺季要不要押金或预付款？
- 如果供应商断供，有没有违约赔偿？怎么算？
- 能不能签旺季保供协议，把量、价、罚则写清楚？
- 出现食品安全问题（农残、变质）责任怎么划分？

**六、实操建议**
- 不要只谈一家，旺季至少备2~3个供应商，主供+备用。
- 先小批量试单，看准时率、损耗率、售后响应，再放量。
- 所有承诺尽量落到文字：微信、合同、报价单都行，别只靠口头。
- 自己留3~5天安全库存，尤其是易储存的品类。

一句话：旺季谈判核心不是压价，而是把“量、价、质、时、赔”五个字问死。
