超市采购在水果农残抽检上，核心是“**要得到、看得懂、能追责**”。建议提前向供应商要以下资料，并按优先级处理：

**1. 每批次的检测报告（最重要）**
- 要**该批次**的农残检测报告，不是一张通用报告。
- 报告上要有：样品名称、批次/采摘日期、检测项目、检测结果、检测依据（如 GB 2763）、检测机构、报告编号、签发日期。
- 重点看是否覆盖常见高风险农药，以及结果是否为“未检出”或“符合 GB 2763”。

**2. 供应商资质**
- 营业执照、食品经营许可证/食品生产许可证（视主体而定）。
- 若是种植基地直供，要种植主体资质或合作社证明。

**3. 产地与追溯信息**
- 产地证明、基地名称、采摘/收购日期、批次号。
- 能对应到具体果园/大棚/合作社，便于出问题时追溯和召回。

**4. 承诺与责任文件**
- 质量安全承诺书：承诺符合 GB 2763，农残不超标。
- 供货合同/质量协议：写明农残超标时的退货、赔偿、检测费承担、召回责任。
- 若供应商是批发商，要求其提供上游来源和对应检测报告。

**5. 自我检测或快检记录（如有）**
- 供应商自检报告、快检记录、入库验收记录。
- 有条件的可要求提供第三方抽检报告或飞行检查记录。

**6. 包装与标签信息**
- 预包装水果要有标签：品名、产地、生产日期/批号、保质期、供应商信息。
- 散装水果至少要能提供批次和产地信息。

**实操建议：**
- **按批次索证索票**，不要一次要一张长期通用的报告。
- 对高风险水果（如草莓、葡萄、豇豆类、叶菜类）提高抽检频次。
- 收货时做**快速检测**或送第三方抽检，费用和责任在合同里写清。
- 保留所有报告、合同、聊天记录、进货单，至少保存到该批水果售完后6个月以上，便于监管核查和追责。

如果供应商只能提供“一份报告管一年”或“报告和批次对不上”，这本身就是风险信号，建议暂缓采购或要求补检。
