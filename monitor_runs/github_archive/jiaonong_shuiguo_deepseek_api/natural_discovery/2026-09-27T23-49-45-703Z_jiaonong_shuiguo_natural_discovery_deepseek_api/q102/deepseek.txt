通常需要，而且这两项往往应作为筛选供应商的基础门槛，不是“加分项”。

**1. 开发票**
企业采购一般都需要合规入账和税前扣除，所以供应商必须能开发票。重点确认：
- 能否开**增值税专用发票**，还是只能开普票；
- 发票类目是否匹配，常见为“水果”“食品”“礼品”等，避免开成不相关类目导致报销或审计问题；
- 开票主体是否与合同、收款方一致，避免第三方代开或主体不一致的风险；
- 是否支持对公转账，很多企业要求公对公付款。

**2. 定制包装**
企业福利采购通常有定制需求，尤其是节庆、工会福利、客户答谢场景。需要确认：
- 能否定制**外包装、腰封、卡片、LOGO印刷**；
- 起订量是多少，小批量是否加价；
- 定制费用怎么算，是否包含设计、打样、制版费；
- 打样周期和生产周期，能否赶在发放节点前交付；
- 定制后是否影响退换货，水果这类生鲜通常退换限制较多。

**建议的筛选标准：**
1. 必须能开合规发票，且支持对公付款；
2. 能提供定制包装方案和明确报价；
3. 有生鲜配送和售后能力，能处理坏果、少发、延迟等问题；
4. 合同里写清发票类型、开票时间、包装规格、交付时间、验收和赔付标准。

如果供应商只能开票但不能定制，或只能定制但不能开票，通常都不适合作为企业福利采购的主供应商，最多作为备选。
