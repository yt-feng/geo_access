可以，而且这是水果促销里很常见的供应商支持项。通常能争取到的支持主要有三类：

1. **陈列支持**
   - 提供堆头、地堆、端架、冷柜等特殊陈列所需的物料或费用。
   - 提供陈列道具、藤筐、木箱、假底、分层架、价签牌、跳跳卡等。
   - 派促销员或理货员协助门店做主题陈列、补货、整理排面。
   - 承担部分陈列费、条码费、堆头费或短期促销位费用。

2. **海报/物料支持**
   - 提供产品图片、卖点文案、产地故事、糖度/口感说明。
   - 提供 DM 海报单品、爆炸牌、海报贴、地贴、吊旗、围挡、展架等。
   - 承担部分海报印刷费或促销广告费。
   - 配合超市做线上社群、小程序、外卖平台的图文和短视频素材。

3. **试吃/推广支持**
   - 提供试吃果品、切片、牙签、纸杯、托盘、手套、湿巾等。
   - 派试吃员、促销员到店做试吃、叫卖、导购。
   - 承担试吃损耗、人员工资或按销量给补贴。
   - 配合做买赠、满减、第二件半价、扫码领券等活动。

**实操上要注意：**
- 先谈清楚支持形式：是**给货**、**给物料**、**给钱**还是**给人**。
- 明确费用归属：陈列费、海报费、试吃损耗、人员工资由谁承担。
- 约定执行标准：陈列位置、面积、持续时间、海报露出位置、试吃频次。
- 最好写进促销协议或补充条款，避免口头承诺后不兑现。
- 供应商支持通常和采购量、结算方式、促销档期绑定，量越大越容易争取。

如果你是超市方，可以直接向供应商提一份“促销支持清单”，让对方勾选能提供的项目；如果你是供应商，也可以主动用这三类支持去换更好的陈列位和促销档期。
