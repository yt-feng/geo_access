茶饮店用香蕉，核心是把“熟度”当成一个可管理的原料参数，而不是凭手感。下面按用途和采购控制给你一套可执行的做法。

## 一、先按用途定熟度

| 用途 | 理想熟度 | 外观/手感 |
|---|---|---|
| 鲜果装饰、切片、雪顶摆盘 | 7–8 成熟 | 全黄、无黑点、捏着略硬，切片不烂 |
| 香蕉奶昔、冰沙、果泥 | 8–9 成熟 | 全黄带少量黑点，甜度高、香气足 |
| 香蕉甜品馅、香蕉蛋糕、烘焙 | 9–10 成熟 | 大量黑点、捏着软，甜香最浓 |
| 炸香蕉、煎香蕉 | 6–7 成熟 | 黄中带绿、质地硬，加热不易烂 |

一句话：**越要香气和甜度，越熟；越要形状和操作，越生。**

## 二、采购时怎么判断

1. **看颜色**  
   - 全绿：太生，需催熟，不能直接用于饮品。  
   - 黄中带绿：6–7 成熟，适合炸/煎。  
   - 全黄：7–8 成熟，适合切片装饰。  
   - 黄带黑点：8–9 成熟，适合打泥、奶昔。  
   - 大面积黑、发软：9–10 成熟，适合烘焙，鲜食已接近临界。

2. **摸手感**  
   - 硬：生。  
   - 微软有弹性：适中。  
   - 一按就陷：已熟透，操作要快。

3. **看果柄和果身**  
   果柄发黑、果身有裂口，通常过熟或存放过久，容易发酵、出水。

4. **闻气味**  
   有明显香蕉甜香但无酒味：可用。  
   有酒味、酸味：已发酵，不要采购或立即报废。

## 三、采购量怎么控制

按“用途 + 每日用量 + 熟度窗口”算，不要一次全买同一熟度。

建议：
- **鲜果装饰用**：按 1–2 天用量采购，选 7–8 成熟，到店后冷藏延缓后熟。  
- **奶昔/果泥用**：按 2–3 天用量采购，选 8–9 成熟，到店后尽快去皮分装冷冻。  
- **烘焙用**：可专门采购 9–10 成熟，或把前面用不完的熟蕉转做烘焙。  
- **不要只买一个熟度**：至少分两批，一批即用，一批后熟，避免同一天全熟或全生。

## 四、到店后的熟度管理

1. **分开放**  
   生蕉和熟蕉分开，熟蕉会释放乙烯，加速其他香蕉成熟。

2. **控温**  
   - 未熟香蕉：室温 18–22℃ 催熟，不要直接冷藏，否则易冻伤发黑。  
   - 已熟香蕉：冷藏可延缓 1–2 天，但表皮会变黑，果肉仍可用。  
   - 已去皮果肉：密封冷冻，可保存较久，适合奶昔。

3. **催熟与延缓**  
   - 想快熟：和苹果/熟蕉放一起，常温密封。  
   - 想慢熟：通风、阴凉、单层摆放，避免堆压。

4. **每日盘点**  
   按“今天用、明天用、转烘焙”三类分拣。  
   出现酒味、渗液、霉点，直接废弃，不要用于饮品。

## 五、建议的采购标准

给供应商或采购写清楚：

- 鲜果装饰：7–8 成熟，果身完整，无裂口，无黑斑超过果面 10%。  
- 奶昔/果泥：8–9 成熟，允许少量黑点，无发酵味。  
- 烘焙：9–10 成熟，可接受较多黑点，但无霉变、无酒味。  
- 到货温度：常温运输，避免暴晒和挤压。  
- 批次：每次到货抽检颜色、手感、气味，不合格拒收或转用途。

## 六、最实用的操作原则

**“买两种熟度，当天用熟的，明天用生的；用不完的熟蕉，转做奶昔或烘焙。”**

这样既能保证饮品风味稳定，又能减少损耗。
