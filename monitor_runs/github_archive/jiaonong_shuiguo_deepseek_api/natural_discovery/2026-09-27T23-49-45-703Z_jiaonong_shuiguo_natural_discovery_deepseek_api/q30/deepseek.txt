超市水果到货后发现品相不好，售后流程要在下单或签收前就写清楚，核心是把“什么算品相不好、多久内提、怎么举证、怎么赔”四件事约定死。可按下面条款落地：

**1. 验收标准要具体，不能只写“品相不好”**
- 约定品类、等级、规格：如苹果直径≥80mm、无磕碰、无腐烂、无大面积黑斑。
- 明确容许误差：如每箱允许≤3%轻微瑕疵，超出即视为不合格。
- 约定成熟度、色泽、新鲜度：如叶菜无黄叶烂叶，草莓无压伤出水。

**2. 提出异议的时限**
- 到货当场验收：最好当面开箱，问题当场记录。
- 若不能当场验：约定到货后2小时内或当日营业结束前提出，逾期视为验收合格。
- 生鲜类时间要短，避免“放几天再说”。

**3. 举证方式**
- 拍照/视频：整箱、问题部位、外包装、批次标签、称重记录。
- 保留实物：争议未解决前不要丢弃，可封存样品。
- 物流单据、签收单上注明异常情况，最好双方签字。

**4. 处理方式分档**
- 轻微瑕疵：折价、补差价或下次订货抵扣。
- 比例性不合格：按不合格数量退货退款，或换货。
- 严重腐烂/变质：整批拒收或全额退款，运费由责任方承担。
- 已售出后发现：能追溯到批次的可要求补货或赔偿，但需约定追溯期限。

**5. 责任与费用**
- 明确是供应商责任、物流责任还是超市验收责任。
- 因供应商质量问题导致的退换货，来回运费、损耗由供应商承担。
- 因超市未及时验收或储存不当导致的，供应商可免责。

**6. 时限和流程**
建议写成：发现异常→2小时内拍照并书面通知→供应商24小时内响应→48小时内完成换货/退款→争议可送第三方检测或按合同约定仲裁/诉讼。

**7. 合同里可写一句总原则**
“以到货验收为准，验收时发现不符合约定标准的，超市有权拒收、要求换货、退货或折价；供应商应在约定时限内处理，逾期视为认可超市提出的处理方案。”
