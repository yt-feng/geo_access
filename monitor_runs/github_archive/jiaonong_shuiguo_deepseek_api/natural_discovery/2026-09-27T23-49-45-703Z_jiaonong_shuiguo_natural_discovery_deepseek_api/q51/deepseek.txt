要固定，但不要只固定“产地”这一个维度，更实用的是固定“品种+产区+供应批次+验收标准”的组合。

先给结论：

**建议固定供应批次和核心供应商，产地可以作为重要筛选条件，但不宜只认产地。**  
因为水果口味波动不只来自产地，还来自品种、成熟度、季节、天气、采摘后处理、运输和储存。

具体可以这样判断和操作：

1. **固定供应批次的优先级最高**
   - 同一批水果的糖酸度、香气、成熟度更接近，茶饮出品最稳定。
   - 采购时尽量按“批次”验收和留样，而不是只写“某地产某水果”。
   - 如果换批次，先做小批量测试，再决定是否全面切换。

2. **固定产地有用，但要看是否真能稳定**
   - 固定产区能减少大范围风味差异，比如不同气候、土壤、品种带来的差别。
   - 但同一产地不同果园、不同采摘时间、不同成熟度，口味仍可能差很多。
   - 所以更准确的做法是：固定“产区+品种+果园/合作社+采摘标准”。

3. **必须建立可量化验收标准**
   不要只靠“尝一口感觉差不多”。建议至少记录：
   - 糖度
   - 酸度或糖酸比
   - 香气表现
   - 果肉颜色、硬度、出汁率
   - 成熟度
   - 瑕疵率、损耗率
   - 到货温度、运输时长

4. **要接受季节性波动，并提前做配方预案**
   - 同一产地也不可能全年完全一致。
   - 可以设定一个可接受波动范围，超出范围就调整配方，比如微调糖浆、茶底、酸度平衡或水果用量。
   - 对核心爆款，最好准备 A/B 两个供应方案，避免单一产地断供或风味崩掉。

5. **采购策略建议**
   - 核心产品：固定供应商 + 固定批次标准 + 每批留样 + 到货检测。
   - 非核心产品：可允许产地和批次适度变化，但要有验收底线。
   - 换季或换产地时：先门店小范围测试，再逐步替换。
   - 和供应商约定：品种、产区、采摘成熟度、加工方式、冷链条件、批次一致性要求。

一句话总结：  
**不要只固定产地，要固定“品种、产区、批次、验收标准”这一整套。批次稳定比产地名义更重要，验收标准比口头承诺更重要。**
