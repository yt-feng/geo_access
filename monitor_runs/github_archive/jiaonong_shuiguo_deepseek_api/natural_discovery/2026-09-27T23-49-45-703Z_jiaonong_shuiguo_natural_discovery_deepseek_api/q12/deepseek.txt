采购菠萝时，目标不是“挑最熟的”，而是按你预计几天卖完，分批拿不同熟度，减少集中过熟造成的损耗。

**一、先按销售节奏定熟度**

- **当天或次日就能卖完**：可以拿成熟度高的，香气明显、果皮偏黄，现场能直接削。
- **2～3天卖完**：拿“刚开始转黄、香气淡”的，放店里继续后熟。
- **3～5天以上**：拿青一点、果眼紧、香气很弱的，但不要长期低温乱放，菠萝怕冷害。

**二、现场判断菠萝熟度的实用方法**

1. **看果皮颜色**
   - 青绿：生，适合存放。
   - 青黄相间、底部开始转黄：适合2～3天销售。
   - 整体金黄、底部深黄：熟，最好当天卖。
   - 发暗、发褐、果眼塌陷：过熟或开始坏，别拿。

2. **闻底部香气**
   - 几乎没味：偏生。
   - 底部有淡淡果香：适合短存。
   - 香气浓、甜味冲：熟，需尽快卖。
   - 有酒味、酸馊味：已过熟或发酵，别拿。

3. **捏果身**
   - 硬邦邦：生。
   - 稍软但有弹性：成熟度合适。
   - 一按就陷、局部软烂：过熟或伤果。

4. **看果眼和底部**
   - 果眼扁平、间隙小，通常成熟度较高。
   - 果眼很深、很尖，偏生。
   - 底部发黑、发霉、渗汁，直接不要。

5. **掂重量**
   - 同样大小，偏重的水分足、果肉好。
   - 明显轻的，可能失水或内部空。

**三、采购比例建议**

如果你一天卖10个左右，可以这样配：

- 熟果：20%～30%，当天现卖。
- 半熟果：50%，2～3天卖。
- 偏生果：20%～30%，后面慢慢转熟。

夏天温度高，熟果比例再降；冬天或空调房，可适当提高半熟果比例。

**四、到店后的管理**

- 不要全部堆在一起，按熟度分区。
- 熟果放最前面，优先削、切盒、做促销。
- 半熟果放阴凉通风处，别暴晒。
- 已切开的必须冷藏，当天尽量卖完。
- 每天挑一次，把开始软、香气重的先处理，别等坏了再削。

**五、简单判断口诀**

**青的存，黄的卖，香的先削，软的促销，酒味的扔。**

采购时最好直接跟供货商说清楚：你要“几成黄、能放几天”的货，不要只说要菠萝。这样比单靠现场挑更能稳定控制损耗。
