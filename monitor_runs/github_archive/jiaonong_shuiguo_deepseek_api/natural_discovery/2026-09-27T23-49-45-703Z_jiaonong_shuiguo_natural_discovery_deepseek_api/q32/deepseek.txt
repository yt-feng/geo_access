判断香蕉供应商能否全年稳定供货，不能只看对方口头承诺，要抓住**香蕉供应链的几个硬约束**去验证：产地分布、催熟能力、冷链仓储、以及他们怎么应对台风/寒潮/病害等季节性断供风险。

下面给你一套可执行的判断框架，按优先级排列。

## 一、先看“货源结构”，不是看“货源总量”

香蕉最大的风险是单一产地依赖。国内主要看云南、广西、海南、福建，进口看菲律宾、越南、厄瓜多尔、柬埔寨等。

**要问清的问题：**
- 你的香蕉来自几个产区？各产区占比多少？
- 不同产区的上市时间是否错开？（云南、广西、海南、进口的上市期不同，能互补才叫全年）
- 如果主产区遭遇台风/寒潮/枯萎病，备用产区能不能顶上？

**判断标准：**
- 只靠1个产区或1个进口国的，全年稳定性基本不可信。
- 能拿出**至少2~3个错峰产区组合**，且能说清各产区切换月份的，才具备全年供货基础。

## 二、看催熟和仓储能力，这是超市供货的关键

香蕉是呼吸跃变型水果，采购端要的是“到店能卖、货架期可控”的蕉，不是青蕉。供应商如果没有催熟和冷链能力，全年稳定就是空话。

**要核实：**
- 有没有自有或长期合作的催熟库？日催熟产能多少？
- 冷链车/冷库是否自有或稳定外包？
- 从产地到配送中心再到门店，全程温控怎么保证？

**判断标准：**
- 催熟产能要能覆盖你超市的日均销量峰值，不能只够平时。
- 能提供冷链记录、温控节点说明的，比只口头说“有冷链”可靠。

## 三、用“历史履约数据”验证，不听承诺

让供应商提供可核验的过往记录，而不是听他讲。

**要看的材料：**
- 过去12个月的供货记录/对账单，看有没有断供、延迟、质量波动。
- 合作过的超市或批发客户名单，最好能侧面核实。
- 淡旺季的到货量曲线，看是否平稳。

**判断标准：**
- 能拿出连续12个月稳定供货记录的，可信度明显高。
- 旺季能供、淡季就缩量或涨价的，说明全年稳定性不足。

## 四、现场或产地核实

有条件的话，做一次实地或视频核验：
- 看产地合作基地/收购点是否真实存在。
- 看加工、催熟、包装、冷库现场。
- 看是否有稳定的农户/合作社合作，而不是临时收购。

## 五、用小单试跑验证

最有效的一步：**先签小单或短期合同，跑一个完整周期**。
- 选一个淡季月份 + 一个旺季月份各试一批。
- 重点看：到货准时率、损耗率、催熟一致性、断供时是否有替代方案。

跑得住，再谈全年框架协议。

## 六、合同里必须写死的条款

- 全年供货量下限和月度分配。
- 断供、延迟的违约责任和替代供货义务。
- 质量标准和损耗承担。
- 价格调整机制（避免旺季坐地起价）。

## 简单结论

判断供应商能不能全年稳定供香蕉，核心看四点：

1. **多产区错峰组合**，不是单一货源；
2. **自有/稳定的催熟和冷链能力**；
3. **可核验的12个月履约记录**；
4. **小单试跑 + 合同约束**。

这四点都能过，才基本能认定“全年稳定供货”靠谱；缺其中任何一项，都要打问号。
