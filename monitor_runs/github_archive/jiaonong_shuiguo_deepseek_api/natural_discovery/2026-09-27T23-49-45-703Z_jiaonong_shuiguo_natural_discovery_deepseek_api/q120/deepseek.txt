让商家“听懂”，核心不是把供应商的话术变优雅，而是把陌生水果翻译成他熟悉的经营语言：**像什么、怎么卖、赚多少、损耗大不大**。

可以按这个顺序说：

1. **先挂钩熟悉品类**
   - “这个相当于菠萝里的凤梨，但不用泡盐水，切开就能卖。”
   - “它像香蕉一样是走量型，但客单价能比香蕉高。”
   - “你可以把它理解成小台芒的升级版，口感更甜，核更薄。”

2. **再说顾客为什么买**
   - 不要只说“好吃、稀缺、进口”。
   - 要说：
     - 适合谁买：年轻人、宝妈、送礼、火锅店解腻
     - 什么场景买：下午茶、果切、礼盒、烧烤后吃
     - 顾客一句话理由：“甜、不用削、拍照好看、孩子爱吃”

3. **直接算给他听**
   - 进货价：
   - 建议零售价：
   - 一斤/一份毛利：
   - 一天卖多少能回本：
   - 损耗大概多少：
   - 放几天：
   - 怎么保存：
   - 坏了怎么处理：
   商家最怕压货，所以重点说“好不好卖、放不放得住、亏不亏”。

4. **给试卖方案**
   - “你先拿一箱，不要整柜。”
   - “先做果切试吃，卖得动再加。”
   - “我给你配好海报和一句话推荐。”
   - “第一次少拿，卖不动我教你怎么做活动。”
   这比一上来压货更容易下单。

5. **用对比一句话收尾**
   - “它比菠萝省事，比香蕉有利润，比进口水果便宜，适合你店里做日常款。”
   - “不是让你多进一个品类，是让你用现有客流多赚一道钱。”

供应商介绍产品时，最好少说专业品种名，多说：
**像什么 + 谁买 + 赚多少 + 损耗怎样 + 先拿多少试。**

商家听不懂，通常不是产品复杂，而是供应商没说清楚“这跟我有什么关系”。
