做香蕉、菠萝这类高损耗水果团，售后控制的核心不是“出了问题再赔”，而是**把损耗拦在分拣、配送、自提三个环节之前**，同时把规则讲清楚，避免扯皮。可以按下面几步做。

## 1. 选品和采购端：先降低“先天损耗”

**香蕉**
- 不要采全熟，采**7成熟左右**，到自提点刚好转黄。
- 夏天选偏青一点，冬天可稍熟一点。
- 整箱到货后先开箱散热，别闷着，香蕉怕捂。
- 有黑斑、裂口的单独挑出，不要混进正常团。

**菠萝**
- 优先选**带冠芽、果眼浅、无软塌**的。
- 到货后检查底部有没有发软、渗汁，这类基本会烂。
- 切开卖的菠萝损耗更大，尽量做**整果团**，少做现切。

**通用原则**
- 高损耗品不要做“超低价引流”，否则品质一定崩。
- 采购量按历史履约率倒推，比如上次100单坏15单，这次就少备20%。
- 和供应商谈**到货坏果包赔比例**，把风险往上游转移一部分。

## 2. 分拣打包：把坏果挡在出库前

- 香蕉：按把分，不要硬掰，掰伤的地方第二天就黑。
- 菠萝：套网套或纸包裹，冠芽朝上，避免压伤。
- 每单拍照留底，尤其是香蕉成熟度、菠萝外观。
- 坏果直接挑出，**宁可少发，不要混发**。混发一单，售后三单。

## 3. 配送和自提：控制时间和温度

- 香蕉、菠萝都怕闷、怕压、怕高温。
- 夏季尽量**上午到货、上午分拣、当天自提**，不要隔夜。
- 自提点放阴凉通风处，不要放太阳直射或暖气旁。
- 自提时间设短一点，比如当天18:00前取完，超时容易坏。
- 团长提醒话术要具体：
  - 香蕉：收到后挂起来，别放冰箱。
  - 菠萝：阴凉处放，切开尽快吃。

## 4. 售后规则：提前说清楚，减少扯皮

建议在团购页面和群里提前公示：

**香蕉售后标准**
- 轻微黑斑、表皮擦伤：正常，不售后。
- 大面积发黑、流水、果肉软烂：按比例赔。
- 因个人存放不当导致坏果：不赔。

**菠萝售后标准**
- 外观轻微磕碰：不售后。
- 切开后黑心、烂心、严重酸败：全额赔或补发。
- 已切开、已削皮后放坏：不赔。

**通用规则**
- 售后时效：自提后**24小时内**反馈，超时不受理。
- 凭证：坏果和包装一起拍照，不要只拍局部。
- 赔付方式：优先**补发或退单果金额**，不要整单退，控制成本。

## 5. 用数据复盘，而不是每次都拍脑袋

每团记录：
- 到货总数
- 分拣淘汰数
- 售后单数
- 售后原因（黑斑、烂心、压伤、超时等）
- 供应商批次

连续做3团就能看出：
- 哪家供应商的香蕉不能要
- 夏天菠萝要少备多少
- 哪个自提点经常超时

## 6. 最实用的止损策略

- **香蕉**：做“青蕉团”，让用户自己放熟，售后率最低。
- **菠萝**：做整果团，不做现切；现切只做少量预售。
- **高损耗品单独开团**，不要和叶菜、草莓混在一起配送。
- **设置坏果包赔上限**，比如单团售后预算不超过销售额的5%。
- **超过阈值就换供应商或停团**，不要硬撑。

一句话：高损耗水果的售后，靠的是**采购成熟度控制 + 快速分拣 + 短时自提 + 明确规则 + 数据复盘**。把这几步做好，售后能从“赔钱救火”变成“可控成本”。
