茶饮店控制水果供应商的食品安全风险，建议按“资质证明 + 检测报告 + 交易凭证 + 现场管理”四类材料来收，且要保留原件或加盖公章的复印件，并定期更新。

**一、供应商主体资质**
1. 营业执照（经营范围含水果种植、销售、收购或农产品批发等）。
2. 食品经营许可证或食品生产许可证（如供应商属于食品经营者；仅销售食用农产品的，按当地规定可能只需营业执照和备案）。
3. 若为进口水果，还需提供：
   - 海关进口货物报关单；
   - 入境货物检验检疫证明；
   - 中文标签或相关合规证明。

**二、产品合格证明**
1. 食用农产品合格证/承诺达标合格证（很多地区要求种植户或收购商出具）。
2. 农药残留检测报告：
   - 供应商自检报告，或第三方检测机构出具的合格报告；
   - 重点看有机磷、氨基甲酸酯类等农残项目；
   - 报告应在有效期内，且批次能对应。
3. 如水果有切开、鲜切、冷冻等加工行为，还需按加工食品要求提供出厂检验报告或第三方检测报告。
4. 若供应商声称“有机”“绿色”“无公害”，需提供对应认证证书，并核实证书编号和有效期。

**三、交易与追溯凭证**
1. 每批送货单/销售单，注明品名、规格、数量、产地、批次、送货日期。
2. 发票或收据，便于追溯。
3. 供应商联系人、电话、地址、产地信息。
4. 建议签订采购合同或质量保证协议，明确农残、腐败变质、异物等责任。

**四、茶饮店内部管理要求**
1. 建立供应商档案，一供应商一档。
2. 每批水果到货验收：看外观、气味、温度、包装、标签、合格证和检测报告。
3. 对高风险水果（如草莓、葡萄、切果）可做快速农残检测或送检。
4. 留存进货台账，做到“来源可追、去向可查”。
5. 定期对供应商做现场审核或要求其提供产地证明、种植记录。

**简要清单，可直接向供应商索要：**
- 营业执照
- 食品经营许可证/食品生产许可证（如适用）
- 食用农产品合格证/承诺达标合格证
- 农药残留检测报告（批次对应）
- 进口报关单和检验检疫证明（进口水果）
- 有机/绿色/无公害认证（如宣称）
- 送货单、发票、合同
- 供应商联系人及产地信息

如果供应商只能提供营业执照，不能提供批次检测报告或合格证，建议不要直接用于鲜切或直接入口的水果，至少要先做入库快检并保留记录。具体证件要求各地市场监管口径略有差异，可再向当地市场监管部门确认。
