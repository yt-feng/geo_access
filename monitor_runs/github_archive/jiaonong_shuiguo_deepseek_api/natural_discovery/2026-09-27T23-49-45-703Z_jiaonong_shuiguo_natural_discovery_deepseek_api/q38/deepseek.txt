大型超市对水果供应商的要求，核心是两点：**食品安全能力**和**物流履约能力**。可以按下面这几类能力来判断。

## 一、食品安全能力

### 1. 资质与合规
- 营业执照、食品经营许可证（或食品生产许可证，视加工情况）
- 种植/养殖基地备案或合作协议
- 若涉及进口水果：报关单、入境货物检验检疫证明
- 产品检测报告（农残、重金属等），最好能按批次提供

### 2. 源头管控
- 基地有统一的农业投入品管理（农药、化肥使用记录）
- 有采收前安全间隔期控制
- 对土壤、水源有基本监测
- 能追溯：从批次 → 基地 → 采收 → 加工 → 发货

### 3. 加工与分选环节
- 分选、包装车间符合食品卫生要求
- 有清洗、消毒、异物防控措施
- 包装材料符合食品接触材料标准
- 冷链环节温控记录完整

### 4. 检测能力
- 自检或委托第三方检测
- 常规项目：农药残留、重金属、微生物（视品类）
- 能提供批次检测报告，超市通常会抽检复核

### 5. 追溯与召回
- 批次可追溯
- 有问题产品能快速召回
- 有食品安全事故应急预案

## 二、物流能力

### 1. 冷链能力
- 水果多数需要冷链：预冷、冷藏运输、冷库储存
- 全程温控记录，不同品类温区不同
- 冷藏车、冷库、周转筐等设备齐全

### 2. 仓储与分拣
- 有符合要求的仓库，分区存放，防虫防鼠
- 能按超市订单分拣、组配
- 先进先出，减少损耗

### 3. 运输与配送
- 能按时配送到超市门店或配送中心
- 有固定线路和时效保障
- 运输过程防挤压、防日晒、防污染

### 4. 订单与信息协同
- 能对接超市的订单系统
- 有库存、在途、到货信息反馈
- 异常情况能及时沟通处理

### 5. 损耗与应急
- 有损耗控制方案
- 对缺货、延迟、质量异常有应急处理能力
- 能配合超市做退换货

## 三、大型超市通常还会重点看

- **规模与稳定性**：能否长期稳定供货
- **标准化程度**：分级、包装、规格是否统一
- **食品安全记录**：有无处罚、召回、投诉历史
- **审核配合度**：能否接受超市或第三方审核
- **保险**：产品责任险等

## 四、简单判断标准

如果供应商能做到这几点，基本就具备大型超市要求：

1. 资质齐全，批次检测报告可提供
2. 源头可追溯，有农残控制
3. 全程冷链，温控有记录
4. 能稳定按时配送
5. 有召回和应急机制
6. 能配合超市审核和抽检

如果你是要**入驻超市**或**筛选供应商**，可以进一步按品类（如叶菜、浆果、进口水果）细化要求。
