小面积便利店做水果，核心思路不是“品类齐全”，而是 **少SKU、快周转、高频补货、敢于下架**。水果是典型的高损耗、低毛利、强时效品类，门店面积越小，越要用“精选+预售+组合”的方式控制风险。

下面给你一套可执行的控制方法：

## 一、品类控制：只做“少量爆款+即时消费”

小店不适合做全品类水果店，建议控制在 **8–15个SKU**，按角色分配：

| 角色 | 举例 | 作用 |
|---|---|---|
| 引流款 | 香蕉、苹果、橘子 | 认知度高、价格透明、带动进店 |
| 利润款 | 蓝莓、圣女果、切果盒 | 毛利高、客单提升 |
| 即时款 | 单根香蕉、1个苹果、小盒切果 | 满足“马上吃” |
| 季节款 | 西瓜、草莓、荔枝 | 应季冲量，但周期短 |
| 搭配款 | 水果+酸奶、水果+沙拉 | 提高客单，减少裸卖损耗 |

**淘汰原则：**
- 连续3天销量低于设定底线，下架；
- 损耗率超过10%的单品，先减量，再考虑停售；
- 同类型只留1–2个，比如苹果只留1种红富士+1种青苹果，不要5种。

**不要做的品类：**
- 易压伤、易熟过头的：水蜜桃、芒果整箱、熟透牛油果；
- 需要现场加工且客流不足的：大份果切、复杂果盘；
- 价格波动大且顾客比价强的：车厘子、榴莲，除非有稳定客群。

## 二、采购控制：小批量、多频次、按预估卖量下单

### 1. 用“日均销量×保鲜天数”定采购量
公式：
> 采购量 = 日均销量 × 可售天数 × 安全系数（0.8–1.0）

例如香蕉日均卖20根，保鲜期2天，安全系数0.8：
> 20 × 2 × 0.8 = 32根

不要一次进50根，宁缺勿损。

### 2. 采购频次
- 叶菜类、浆果类：每天或隔天；
- 苹果、橙子、香蕉：2–3天一次；
- 西瓜、整箱水果：按预订或周末冲量，不常备库存。

### 3. 采购渠道
- 优先本地批发市场早市，少量多次；
- 能当日退换的供应商优先；
- 与周边水果店拼单，降低起订量；
- 对高损耗品，尝试“代销”或“联营”，卖不完可退。

## 三、损耗控制：从收货到出清全流程

### 1. 收货
- 当场开箱检查，拒收压伤、过熟、发霉；
- 香蕉、芒果等后熟水果，按成熟度分批收货；
- 记录到货时间，先进先出。

### 2. 陈列
- 小面积用 **少量多层**，不要堆满；
- 易损水果放浅筐，减少翻动；
- 切果、浆果放冷藏柜；
- 香蕉不要冷藏，避免黑皮；
- 每天挑出“次果”，及时处理。

### 3. 库存与补货
- 设“最小陈列量”，卖到一半再补；
- 后仓不囤易腐品；
- 用标签写清到货日期，先进先出；
- 每天闭店前盘点，记录损耗。

### 4. 出清与转化
- 傍晚设“今日水果特价区”；
- 轻微瑕疵的做切果盒或果汁，但必须当天售完；
- 组合销售：水果+酸奶、水果+面包；
- 会员群预售：今天到货，晚上自提，减少陈列损耗。

## 四、数据指标：每天看这4个就够

1. **单品日均销量**：决定要不要留；
2. **损耗率**：损耗金额÷销售额，控制在5%–8%以内；
3. **周转天数**：库存÷日均销量，最好1–3天；
4. **毛利额**：不是毛利率，小店要算“卖出去赚多少钱”。

## 五、小面积门店的推荐模型

**面积小，建议做“便利店水果角”：**
- 2–3个引流款：香蕉、苹果、橘子；
- 2–3个利润款：蓝莓、圣女果、切果盒；
- 1–2个季节款：西瓜、草莓；
- 1个组合款：水果+酸奶。

**采购原则：**
- 首单少量试销；
- 卖得好再加量；
- 卖不动立即停；
- 宁少勿多，宁缺勿损。

## 六、最实用的执行口诀

> 少品类、小批量、多频次、快出清、看数据、敢下架。
