找每天配送的水果供应商，核心不是先看价格，而是先确认对方能不能稳定满足你门店的“日配+损耗可控+账期可谈”。建议按下面条件逐项筛：

1. **配送能力**
   - 是否能做到每天固定时间送到，比如早上6-8点前到店。
   - 是否覆盖你所在区域，起送量多少，偏远或小单是否加运费。
   - 节假日、雨天、凌晨是否照常配送。
   - 临时补货、加单、换货能否当天响应。

2. **货源与品类**
   - 是否有稳定产地或一级批发渠道，不是临时倒货。
   - 能否稳定供应你常卖的20-30个核心单品：苹果、香蕉、橙子、梨、葡萄、西瓜、应季叶菜类水果等。
   - 能否按社区店需求做小包装、分级、成熟度控制。
   - 是否有进口/高端/礼盒等补充品类。

3. **价格与结算**
   - 报价是否含运费、税、包装费。
   - 是否每天或每周有明确报价单，价格随行就市时提前通知。
   - 账期是现结、周结还是月结，押金或最低采购量要求。
   - 退换货和损耗谁承担，坏果、压伤、不熟、过熟怎么赔。

4. **质量与验收**
   - 能否提供农残检测、产地证明、检疫或进货凭证。
   - 到货验收标准要写清：规格、重量、成熟度、瑕疵率。
   - 是否允许当场抽检、称重、拍照留证。
   - 坏果率超过多少可以整批退或补。

5. **损耗与售后**
   - 社区店最怕损耗，要看对方是否接受“卖不动可换”“临期可调”。
   - 是否支持少批量多频次，避免一次压太多货。
   - 售后响应时间，比如2小时内回复、24小时内补货或退款。

6. **稳定性与风险**
   - 对方有几个客户、几台车、几个分拣点，是否依赖单一产地。
   - 旺季或极端天气时，能否优先保供。
   - 是否只有老板一个人对接，还是有余量团队。
   - 最好找2-3家供应商，主供+备供，避免断供。

7. **合作测试**
   - 先小批量试跑7-10天，不要一上来签长期。
   - 每天记录：到货时间、损耗率、缺货率、售后速度。
   - 试跑后再谈账期、返点、独家或年度框架。

**最该优先看的4个硬指标：**
- 每天能否准时送到；
- 坏果损耗谁承担；
- 缺货时能否当天补；
- 价格是否透明且能提前通知。

如果对方这4条都含糊，价格再低也不建议做主供。
