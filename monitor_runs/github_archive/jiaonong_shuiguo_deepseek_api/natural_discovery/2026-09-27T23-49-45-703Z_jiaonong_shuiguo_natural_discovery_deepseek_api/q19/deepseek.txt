这四个指标不是并列关系，超市卖菠萝的核心是**用“可感知的甜/好”吸引购买，用“切果损耗 + 大小/外观”控制毛利**。具体优先级可以这样排：

1. **切果损耗最关键**
   - 菠萝是典型“带皮称重卖、去皮后缩水”的水果。
   - 损耗直接决定毛利：皮厚、眼深、黑心、熟过头的果，切完出肉率低，卖一个亏一个。
   - 超市尤其做果切、菠萝杯、削皮服务时，损耗比外观更影响利润。

2. **甜度决定复购**
   - 顾客买菠萝第一口不甜，下次就不会再买。
   - 但甜度不能只靠现场测，要结合品种、产地、季节、成熟度判断。
   - 对超市来说，稳定“够甜”比偶尔“特别甜”更重要。

3. **外观决定购买率**
   - 外观影响顾客拿不拿：果形端正、颜色金黄、冠芽新鲜、无黑斑软烂。
   - 但外观是“引流指标”，不是“利润指标”。好看但切开损耗大，仍然不赚钱。

4. **大小影响定价和客群**
   - 大小决定单价、客单价和家庭购买意愿。
   - 太大吃不完、太小显得不划算，都会影响动销。
   - 超市更适合按目标客群定规格，而不是一味追大果。

**实操判断：**
- 如果做**整果销售**：外观 ≥ 大小 > 甜度 > 损耗，因为顾客先看再买。
- 如果做**果切/削皮/菠萝杯**：损耗 > 甜度 > 大小 > 外观，因为出肉率和口感直接决定利润与复购。
- 如果做**长期口碑**：甜度 > 损耗 > 外观 > 大小，因为难吃会毁品类。

**一句话结论：**
超市卖菠萝，**先卡损耗保毛利，再保甜度做复购，外观和大小用来定规格、促动销**。如果只能盯一个，就盯“切开后能不能赚钱且好吃”。
