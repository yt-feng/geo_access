整体通常 **直接买成品果丁的损耗更低（账面上更可控）**，但这不等于成本更低。要分两种“损耗”看：

**1. 原料损耗率**
- **鲜果切配**：菠萝要去皮、去眼、去芯，实际出果率大概 **45%～60%**，取决于品种、成熟度和工人手艺。也就是说买 10 斤鲜果，可能只剩 5～6 斤可用果肉。
- **成品果丁**：供应商已经完成去皮切丁，你拿到的基本是净料，损耗主要在拆袋、沥水、挑拣、过期报废，通常能控制在 **3%～8%**。
- 所以单看损耗，成品果丁明显更低。

**2. 综合成本损耗**
成品果丁虽然损耗低，但单价通常更高，而且可能有：
- 糖水/果汁增重，沥水后实际果肉变少；
- 冷链不到位导致发酵、变酸；
- 规格不合适，做装饰或大颗粒产品时还要二次改刀，反而产生新损耗；
- 起订量和保质期限制，卖不完只能报废。

鲜果切配虽然出果率低，但：
- 原料单价低；
- 成熟度、酸甜度、颗粒大小自己可控；
- 边角料还能做菠萝汁、菠萝酱、菠萝馅，实际浪费可能没那么高；
- 但依赖人工，旺季切配压力和人工成本会上升。

**建议怎么选：**
- **如果门店销量大、出品稳定、人工紧张**：买成品果丁更省事，损耗更可控，适合连锁或标准化要求高的店。
- **如果销量不大、想控成本、有熟练后厨**：买鲜果自己切，综合成本可能更低，但要把出果率算进去。
- **如果做表面装饰、要求颗粒完整**：鲜果现切往往卖相更好，成品丁容易碎、出水。
- **如果做内馅、打汁、做酱**：成品果丁或冷冻果丁更合适，损耗低且稳定。

**最简单的判断公式：**
> 鲜果实际成本 = 鲜果单价 ÷ 出果率 + 人工切配成本  
> 成品实际成本 = 成品单价 ÷ 沥水后净重率 + 报废损耗

把这两个数算出来，哪个低选哪个。只看损耗率，成品果丁更低；看总成本，要看你的销量、人工和菜单用途。
