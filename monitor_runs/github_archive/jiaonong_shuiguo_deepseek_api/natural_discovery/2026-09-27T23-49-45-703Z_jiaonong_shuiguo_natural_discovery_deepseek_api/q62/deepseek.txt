判断一批香蕉，核心是“看颜色、摸硬度、看棱角、查果柄和切口、抽检内部”，再结合季节、运输和仓储条件判断风险。

**1. 先看颜色和成熟阶段**
- 全青、硬：通常是催熟前或远途运输货，熟度低，后续可控，但若受冷或过生，可能出现“青硬不熟”。
- 青中带黄、果身转黄：开始进入可催熟或自然后熟阶段。
- 黄多青少、果尖仍绿：适合近期销售，耐放性一般。
- 全黄、果柄仍绿：熟度较高，适合快速出货。
- 全黄、果柄发黑、果身出现黑斑：已接近或进入过熟期，坏果风险高。
- 果皮发暗、发灰、无光泽：可能受冷、闷伤或老化，催熟后易发黑、发软、烂心。

**2. 摸硬度和弹性**
- 硬实、无弹性：熟度低，耐运输，但可能催熟困难。
- 稍有弹性、手感饱满：熟度适中，适合批发周转。
- 明显发软、按压不回弹：过熟或内部已开始腐烂。
- 局部软陷：大概率是压伤、碰伤，后续会从伤处发黑腐烂。
- 整体发软但果皮还黄：可能是“闷熟”或受热，货架期短。

**3. 看棱角和果形**
- 棱角明显、果身饱满偏硬：熟度低，通常较耐放。
- 棱角变圆、果身鼓胀：熟度上升。
- 果身过于圆鼓、发软：过熟。
- 果形干瘪、起皱：失水或存放过久。

**4. 查果柄、切口和果轴**
- 果柄青绿、切口新鲜：采摘和运输时间较近。
- 果柄发黑、干枯、切口发褐：存放时间长，后熟或腐烂风险增加。
- 果柄处发霉、长白毛/绿毛：直接高风险，可能已感染。
- 果轴中心发黑、发软：可能从内部开始烂，整箱风险大。

**5. 抽检内部和箱内情况**
批发拿货不能只看外层，要抽几箱、几把检查：
- 打开箱看底层、中间层有没有压伤、水烂、霉斑。
- 摸箱内温度：发热说明呼吸作用强，后熟快，坏果风险上升。
- 看有没有酸味、酒味、霉味：有酒味说明已发酵，过熟或内腐。
- 随机剥开几根：果肉是否透明、发暗、发软、褐变；中心是否发黑。
- 看黑斑类型：少量芝麻斑通常是熟度表现；大面积黑斑、凹陷黑斑、霉斑是坏果风险。

**6. 结合来源和条件判断风险**
高风险信号：
- 产地或运输途中受冷，果皮发暗、发灰。
- 箱内发热、有水汽，说明闷箱。
- 到货时已经全黄、果柄黑、果身软。
- 同一批货颜色成熟度差异很大，说明混装或存放不均。
- 有霉味、酒味、酸味。
- 底层大量压伤、水烂。

低风险信号：
- 颜色青绿均匀，果身硬实，棱角明显。
- 果柄青绿，切口新鲜。
- 箱内干燥、不发热、无异味。
- 抽检果肉洁白、脆硬、无褐变。

**7. 给批发商的实操建议**
- 拿货前先问：采摘时间、运输温度、是否催熟、到货几天。
- 现场至少抽 3—5 箱，重点看底层和中间层。
- 青硬货可以拿，但要确认不是冷伤；冷伤香蕉催熟后容易发黑、烂心。
- 已全黄、发软、有酒味的货，除非当天能清掉，否则不要大批拿。
- 如果做短途批发，可拿“青中带黄、硬实”的货，自己控温催熟。
- 如果做零售快销，可拿“黄多青少、稍有弹性”的货，但必须快进快出。
- 分等级卖：好果先出，黑斑和软果降价快销，霉变果直接剔除，避免传染。

简单记：**青硬耐放，黄软快销；果柄青鲜风险低，果柄发黑风险高；箱内发热有酒味，基本别大量拿。**
