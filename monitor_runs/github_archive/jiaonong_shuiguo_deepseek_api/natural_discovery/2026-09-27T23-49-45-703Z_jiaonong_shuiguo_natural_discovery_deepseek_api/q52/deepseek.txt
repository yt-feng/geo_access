采购香蕉时，要抓住一个核心：**买成熟度合适的，而不是买最黄的**。到店后很快变黑，通常是因为采购时已经过熟，或者运输储存中受了热、挤压、乙烯积聚。

具体可执行做法：

1. **按用途选成熟度**
   - 如果当天或1—2天内用完：买**微黄、带少量青肩**的，果肉已开始软化但表皮还没大面积转黄。
   - 如果2—4天内用完：买**青黄交接、整体偏绿转黄**的，到店后自然熟。
   - 不要买表皮全黄、带黑点、果柄发黑的，那种到店后基本会迅速变黑。

2. **采购时逐把检查**
   - 看果柄：发黑、发霉、渗液的不要。
   - 看棱角：棱角明显说明还偏生；果身圆鼓、捏着软说明过熟。
   - 看表皮：有压伤、擦伤、裂口的不要，这些位置最先变黑。
   - 闻气味：有明显酒味、发酵味的不要。

3. **运输和到店后别闷着**
   - 不要用密封塑料袋长时间装，香蕉会释放乙烯，闷着熟得更快。
   - 用透气筐、纸箱，留通风口。
   - 避免暴晒、靠近暖气、放后备箱高温闷着。
   - 轻拿轻放，减少磕碰。

4. **到店后分开处理**
   - 先按成熟度分：青一点的放后面，黄的先用。
   - 悬挂或平放，不要堆压。
   - 如果店里温度高，放阴凉通风处；如果已经很熟，可冷藏延缓表皮变黑，但冷藏后表皮仍会变黑，适合做奶昔、烘焙、果酱的尽快处理。
   - 把已经明显成熟的和青的分开，避免乙烯催熟整批。

5. **和供应商约定**
   - 要求按“青黄交接”或“微黄”发货，不要发全黄果。
   - 要求采摘后尽快冷链或通风运输，避免高温车。
   - 到货当场抽检，过熟的拒收或折价，并尽快用于加工品。

6. **如果已经快黑了**
   - 立刻剥皮、切段、冷冻，做香蕉奶昔、冰沙、香蕉蛋糕。
   - 或加糖熬成香蕉果酱。
   - 不要继续常温堆放，否则会很快影响其他香蕉。

一句话：**买青黄交接、无压伤、通风运输、到店分成熟度存放，先熟先用。**
