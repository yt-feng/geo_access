判断水果报价波动是否合理，关键不是看“涨没涨”，而是看**波动是否有可解释的原因、幅度是否落在该品类的正常区间、以及是否和外部信号一致**。可以按下面这套方法操作。

## 一、先建立“合理波动”的基准

对每个常采单品，记录并滚动更新这几个指标：

1. **历史波动区间**
   - 近30天、90天的最低价、最高价、均价
   - 日环比波动率 =（今日价-昨日价）/昨日价
   - 正常品类日波动通常在 **±3%~8%**；叶菜、浆果、荔枝等易腐品可达 **±10%~20%**；根茎类、苹果、梨等耐储品通常 **±2%~5%**。

2. **季节性与产地切换规律**
   - 换季、主产区转换、大棚转露天时，价格本就会跳变。
   - 例如国产樱桃上市初期高、集中上市后快速回落，这种“先高后低”是合理趋势。

3. **等级与规格差异**
   - 同一品种不同规格、糖度、果径、包装，价差可能很大。
   - 报价波动要先确认是不是“同规格对比”，否则容易误判。

## 二、判断单日报价是否合理的四个检查

1. **看幅度**
   - 是否超过该单品历史日均波动率的2倍。
   - 连续多天单向大幅上涨，比单日跳涨更值得警惕。

2. **看方向是否一致**
   - 同期多个供应商是否同向变动。
   - 只有一家突然涨/跌，通常是该供应商自身问题，不是市场波动。

3. **看外部信号**
   - 天气：产地暴雨、寒潮、台风会推高短期价格。
   - 节假日：节前备货涨、节后回落。
   - 汽油/冷链运费、人工、包装材料变化。
   - 批发市场行情、期货或行业报价是否同步。

4. **看质量与成本结构**
   - 报价低但规格下降、损耗率上升，实际成本可能更高。
   - 报价高但包含分拣、配送、账期，也可能合理。

## 三、建立可执行的采购判断流程

1. **每天收集至少3家同规格报价**，取中位数作为参考价。
2. **计算偏离度**：某家报价 ÷ 当日参考价 - 1。
   - 偏离在 ±5% 内：正常
   - 偏离 5%~10%：要求说明原因
   - 偏离超过10%：暂停下单或比价替代品
3. **连续3天偏离超过阈值**，启动供应商复核。
4. **设置调价触发条件**：只有天气、产地、节假日、运费等可验证因素出现时，才接受大幅调价。
5. **保留记录**：报价、规格、天气、到货质量、损耗率，形成自己的价格数据库。

## 四、哪些情况算“不合理波动”

- 无天气、无节日、无产地变化，却连续涨价。
- 只有一家涨，其他家稳定。
- 涨价同时规格、等级、净重悄悄下降。
- 报价随你下单量变化，量大反而更贵。
- 不接受锁价、不接受说明成本构成。
- 用“明天还要涨”制造紧迫感，催你当天大量下单。

## 五、实操建议

- **短期锁价**：对耐储品签3~7天锁价；对叶菜等日波动大的，约定“随行就市但封顶涨幅”。
- **设置价格上限**：超过参考价一定比例需二次审批。
- **多源采购**：主供应商+备用供应商，避免被单一报价绑架。
- **把损耗算进去**：实际到手成本 = 采购价 + 运费 + 损耗 + 分拣人工。
- **定期复盘**：每周对比自己的采购价与市场均价，偏差长期偏大就调整供应商结构。

一句话：**合理的波动一定能在天气、产地、季节、规格、供需里找到解释；找不到解释、又只有一家在动、还伴随规格缩水，就大概率不合理。**
