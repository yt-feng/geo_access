生鲜平台做水果一件代发，供应商的仓配能力至少要覆盖以下几个维度：

**一、仓储能力**
- **温控分仓**：水果品类对温度敏感，供应商需具备常温、冷藏、甚至部分品类的冷冻仓储条件
- **多区域布仓**：一件代发是单件直发消费者，如果只从一个仓发货，跨区域时效和损耗都会失控。供应商最好在核心消费区域（华东、华南、华北等）有分仓或云仓资源
- **催熟/暂存能力**：部分水果（香蕉、芒果、猕猴桃等）需要催熟或后熟处理，供应商要有对应的处理场地
- **库存管理精度**：水果保质期短，需要实时库存同步、批次管理、先进先出，避免发旧货

**二、加工与包装能力**
- **分级分拣**：按规格、糖度、外观分级，一件代发对单果标准一致性要求高
- **预冷处理**：采摘后快速预冷，延长货架期
- **电商件包装**：防震、透气、保温（冰袋/泡沫箱/保温袋），能扛住快递暴力分拣和运输途中的温差
- **定制化包装能力**：能否贴平台品牌标签、放售后卡、按平台要求做礼盒装

**三、配送与履约能力**
- **快递资源整合**：与多家快递有协议价，能根据目的地选择最优快递，尤其是偏远地区
- **面单与系统对接**：能对接平台的订单系统，实现自动接单、打单、发货回传
- **时效承诺能力**：不同区域能承诺的时效（如次日达、48小时达）是否稳定
- **售后件处理**：坏果、漏发、错发的补发或退款流程是否顺畅，能否承担售后损耗

**四、品控与售后能力**
- **到货质检**：入仓时抽检糖度、成熟度、损伤率
- **在库巡检**：定期检查库存品质，及时剔除变质品
- **售后响应**：有专人处理平台转来的售后，响应时间可控
- **损耗率数据**：能提供历史损耗率数据，让平台评估真实履约成本

**五、系统与数据能力**
- **WMS/OMS系统**：能对接平台ERP或订单系统，实现库存、订单、物流信息实时同步
- **发货时效数据**：能提供揽收时效、签收时效等数据
- **异常预警**：库存不足、物流异常时能主动通知平台

**实操建议：**
平台在筛选供应商时，可以要求对方提供：分仓分布图、快递合作清单及报价、历史损耗率、系统对接方案、售后SOP。先小批量试跑1-2个SKU，重点看发货时效、破损率和售后响应速度，再决定是否扩大合作。
