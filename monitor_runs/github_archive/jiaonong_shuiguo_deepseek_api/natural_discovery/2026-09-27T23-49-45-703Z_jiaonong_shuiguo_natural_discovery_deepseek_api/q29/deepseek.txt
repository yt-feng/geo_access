超市和水果供应商的账期没有统一标准，通常取决于**超市规模、水果品类、供应商议价能力和合作模式**。常见区间可以这样判断：

1. **现结/货到付款**
   - 常见于：小超市、单店、批发市场拿货、新供应商首次合作。
   - 特点：供应商风险低，但采购价通常没有优势。

2. **7～15天**
   - 比较常见于：中小超市、区域连锁、部分生鲜供应商。
   - 适合水果这种高损耗、周转快的品类，供应商资金压力相对可控。

3. **15～30天**
   - 是很多超市和水果供应商合作中比较常见的账期。
   - 区域连锁超市、中型供应商之间较常见。
   - 对超市来说能缓解现金流，对供应商来说仍可接受。

4. **30～45天**
   - 常见于：大型连锁超市、强势渠道、长期稳定供应商。
   - 供应商通常要有一定资金实力。
   - 往往伴随更低的供货价或更严格的品质、损耗、退货条款。

5. **45～60天甚至更长**
   - 多见于大型商超、电商平台、供应链公司。
   - 对水果供应商资金压力较大，一般只有规模大、利润空间够、或能走量的供应商才接受。
   - 中小水果供应商通常不太愿意接受。

**实际谈判时，建议这样判断：**
- 如果是**中小超市**，15～30天比较常见，也较容易谈成。
- 如果是**大型连锁超市**，30～45天甚至60天都可能出现。
- 如果是**新供应商或小供应商**，建议先争取7～15天或货到付款，稳定后再放宽。
- 如果是**叶菜、浆果等易损耗水果**，账期通常更短，因为损耗和退换货争议大。
- 如果是**苹果、橙子、瓜类等耐储水果**，账期可以相对长一些。

**谈判时可用的折中方案：**
- 前1～2个月做7～15天账期，稳定后调整为30天。
- 部分现结、部分账期，比如30%现结，70%月结。
- 设置账期上限，比如“月结30天，但超过30天未结可暂停供货”。
- 把账期和价格绑定：账期越长，供货价适当上浮；账期短，价格可优惠。

简单说：**水果供应商比较常见的账期是15～30天，大型超市常见30～45天，中小超市或新合作常见7～15天。** 具体还要看谁更强势、水果损耗风险和供货稳定性。
