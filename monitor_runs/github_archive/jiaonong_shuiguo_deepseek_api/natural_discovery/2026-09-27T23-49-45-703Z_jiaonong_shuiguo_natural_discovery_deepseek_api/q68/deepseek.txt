判断供应商能不能按时到车，核心不是听他口头承诺，而是看他有没有可验证的**履约能力**和**违约成本**。可以按下面几步做：

**一、先看硬条件**
1. **产地和路线**：问清是哪个县/镇收的货，走哪条高速，大概多少公里、正常几小时。路线越远、越经过拥堵或天气多变区域，误点概率越高。
2. **车辆是否落实**：要求提供车牌号、司机电话、车型载重。只有“正在找车”基本等于没保障。
3. **装车进度**：问他今天收了多少、还差多少、几点开始装。没到装车环节，到车时间都是预估。

**二、用历史记录筛人**
1. 问最近3车发给谁，能不能给一个同行电话核实。
2. 看之前合作是否准时，迟到后怎么处理。
3. 新供应商第一次合作，不要给大单，先小批量试一车。

**三、合同/聊天里写死关键点**
1. **到车时间**：写具体到“某日几点前到市场”，不要写“明天到”。
2. **迟到责任**：每迟几小时扣多少，超过多少小时可拒收或降价。
3. **货损标准**：颜色、成熟度、条蕉/梳蕉、烂果比例，避免他到不了车还怪你压价。
4. **定金条件**：最好车已装好、车牌已定再付定金，别提前打全款。

**四、当天动态跟踪**
1. 装车后要**装车视频**，看到货和车牌。
2. 上高速后要**定位或服务区照片**。
3. 预计到达前3-4小时再确认一次，若他说“堵车”，让他发定位和路况截图。
4. 如果明显赶不上，立刻启动备选：问二级市场、其他供应商、调整销售计划。

**五、几个高风险信号**
- 只肯电话说，不肯发车牌、司机电话、装车视频。
- 反复说“马上装”“下午一定走”，但没有具体时间。
- 报价明显低于市场，还要求先打定金。
- 同一车货同时卖给几个人。
- 迟到后只道歉，不谈赔偿。

**实操建议**：第一次合作，定金少给，合同写迟到扣款，要求装车视频+车牌+司机电话。到车时间前4小时做最后确认。如果对方连车牌和装车视频都给不了，基本可以判断这车按时到不了。
