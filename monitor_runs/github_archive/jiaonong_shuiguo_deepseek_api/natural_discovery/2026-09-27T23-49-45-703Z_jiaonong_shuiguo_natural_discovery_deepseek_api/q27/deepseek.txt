判断苹果和橙子的大小规格是否适合门店销售，主要看**目标客群、售卖方式、损耗和价格带**，不是单纯越大越好。

## 1. 先明确门店销售方式
不同卖法对应不同规格：

- **散卖/堆头**：规格可以宽一点，但要大小相对均匀，方便顾客挑。
- **预包装/盒装**：必须按果径或重量分级，外观整齐。
- **礼盒/精品**：偏大果、外观好、颜色均匀。
- **社区生鲜/日常消费**：中等规格更好卖，太大单价高，太小显得不划算。
- **餐饮/果汁/切果**：可接受小果、二级果，但出汁率和坏果率要控制。

## 2. 苹果怎么判断
苹果常用**果径，也就是横截面直径**分级，单位一般是毫米。

常见参考：

- **小果**：约 65–70mm，适合低价散卖、家庭日常、儿童餐。
- **中果**：约 70–75mm，门店最稳妥，接受度最高。
- **中大果**：约 75–80mm，适合精品陈列、礼盒。
- **大果**：80mm 以上，适合礼盒、高端客群，但日常动销可能慢。

判断适不适合门店：
- 同批次果径差异最好控制在 **5mm 以内**，否则顾客会觉得大小不一。
- 看**单果重**：一般中等苹果 160–220g 比较适合门店。
- 看**果形、色泽、碰伤、锈斑、虫眼**。规格再合适，外观差也难卖。
- 试销时看：顾客是否反复挑大果、剩下小果，或嫌单价高。

## 3. 橙子怎么判断
橙子也常用**果径**，但还要看出汁率、皮厚、籽和酸甜度。

常见参考：

- **小果**：约 55–65mm，适合榨汁、低价促销，不太适合精品散卖。
- **中果**：约 65–75mm，门店主力规格，好剥、好卖、价格适中。
- **大果**：约 75–85mm，适合礼盒、精品，但皮可能偏厚。
- **特大果**：85mm 以上，要谨慎，容易出现皮厚、干渣、单价高。

判断适不适合门店：
- 同一陈列区果径差最好控制在 **5–8mm 以内**。
- 看**单果重**：中等橙子 180–250g 通常比较合适。
- 看**皮厚和可食率**：皮太厚会显得不划算。
- 看**新鲜度**：果蒂青绿、表皮油胞饱满、无软烂。
- 如果主要卖榨汁，小果可以，但坏果率和出汁率要算清楚。

## 4. 采购时的实操判断
可以按这个流程：

1. **定售价和毛利**  
   先算门店能卖多少钱，再倒推采购价。大果进价高，若卖不动就是损耗。

2. **看目标顾客**  
   社区店：中等规格最好卖。  
   高端店：中大果、礼盒果更合适。  
   学校/工厂店：中果、小果、性价比规格更合适。

3. **抽样测规格**  
   随机抽 20–30 个，量果径、称单果重，算平均值和最大最小差。

4. **做陈列测试**  
   同一品种分两种规格试卖 3–7 天，看：
   - 哪个规格动销快；
   - 顾客挑剩情况；
   - 损耗率；
   - 实际毛利。

5. **控制损耗**  
   苹果和橙子都怕压伤。大果未必利润高，如果损耗高、周转慢，就不适合。

## 5. 简单判断标准
适合门店销售的规格，通常满足：

- 大小均匀，顾客一眼看不出明显差异；
- 单果大小符合门店主流客群；
- 售价顾客能接受；
- 损耗低，周转快；
- 同规格可稳定供货，不是这批大、下批小；
- 陈列后好看，挑剩少。

一句话：**苹果看 70–80mm、橙子看 65–75mm 往往是比较稳的门店主力带，但最终要用目标客群、售价、损耗和试销数据来定。**
