单位采购水果遇到品质不一致，核心是**验收时留证据、分等级、按合同扣款或退换**。下面按可执行流程说。

## 一、验收前先明确依据

1. **看采购合同/订单**
   - 是否约定品种、规格（果径、单果重）、等级、成熟度、产地、糖度、外观标准。
   - 是否约定验收标准、抽样比例、不合格处理方式、赔付比例。
   - 是否约定到货时间、冷链要求、破损率上限。

2. **没有明确标准时，先补书面确认**
   - 微信、邮件、订单备注都算，但要写清：品种、规格、数量、等级、可接受瑕疵比例。
   - 避免只口头说“要好的”。

## 二、到货验收怎么做

### 1. 当场验收，别先入库
- 到货后先拍照、拍视频：整车/整批、外包装、标签、生产日期、产地。
- 称重或点件，核对数量。
- 随机抽样，不要只翻上面一层。
  - 大货建议按 5%–10% 抽检，量少则全检。
  - 每箱至少抽上、中、下三层。

### 2. 按维度记录
逐项检查并记录：
- 品种是否一致
- 规格是否一致（大小、单果重）
- 成熟度是否一致（生青、过熟）
- 外观：碰伤、压伤、腐烂、虫眼、裂口、日灼
- 新鲜度：果柄、表皮皱缩、异味
- 温度：冷链水果是否失温
- 包装：是否挤压、受潮、污染

### 3. 分等级判定
建议现场分成三类：
- **合格**：符合约定标准
- **次品/降级**：可食用但不符合约定等级，可协商降价接收
- **不合格**：腐烂、变质、严重破损、品种不符，拒收或退换

### 4. 留证
- 拍照要带时间、地点、批次。
- 抽样过程最好录像。
- 让送货人签字确认验收结果。
- 拒收或扣款要当场出具书面记录。

## 三、售后处理方式

按问题严重程度处理：

| 情况 | 处理建议 |
|---|---|
| 少量次品 | 按合同扣款，或供应商补货 |
| 批次品质不一致 | 分等级计价，降级部分按低价结算 |
| 腐烂/变质/品种不符 | 拒收该批次，要求退换 |
| 已入库后发现 | 24小时内反馈，保留实物和照片 |
| 影响使用 | 要求补发、换货或全额退款 |
| 多次发生 | 记入供应商考核，减少订单或更换 |

**关键：售后要及时。** 水果易腐，拖久了责任难界定。建议到货后 2–4 小时内完成验收，发现问题当天书面反馈。

## 四、和供应商沟通的话术要点

不要只说“品质不好”，要说清：
- 哪一批、哪一箱、哪个品种
- 不合格比例多少
- 具体问题是什么
- 依据哪条合同/订单标准
- 要求怎么处理：扣款、补货、换货、退货
- 回复时限

示例：
> 本批到货抽检 10 箱，其中 3 箱存在明显压伤和腐烂，不合格率约 30%，与订单约定的“无腐烂、碰伤率低于 5%”不符。请于今天 17:00 前确认换货或按不合格部分扣款处理，并附验收照片。

## 五、建议单位内部固定流程

1. 采购下单时写清验收标准。
2. 到货必须两人以上验收。
3. 当场抽样、拍照、签字。
4. 不合格部分单独存放，别和合格品混。
5. 当天出验收单，双方确认。
6. 扣款、退换货写进结算单。
7. 建立供应商评分：品质、时效、售后。

## 六、如果供应商不认账

- 拿出合同、订单、验收照片、签字记录。
- 找第三方见证，如食堂负责人、仓管、纪检或采购部门。
- 涉及金额大，可要求复检或请市场监管/质检介入。
- 后续保留更换供应商的权利。

一句话总结：**验收要当场、抽样要随机、判定要分等级、留证要完整、售后要当天书面提出。**
