这三个都不是“最应该”先问的，正确顺序是先问**售后（尤其是坏果怎么赔）**，再问**配送（时效+损耗责任）**，最后谈**价格**。原因很简单：水果是非标、易损、高损耗品类，团长赚的是“信任差价”，一次售后翻车会直接掉粉，而掉粉的损失远大于每斤便宜几毛钱。

具体判断标准：

**1. 先问售后（决定你能不能做长久）**
- 坏果、烂果、压伤的赔付标准是什么？按个赔、按斤赔、还是按比例补？
- 拍照报损的时限是多久？超过多久不认？
- 是补货、退款还是抵扣下次货款？
- 有没有“整箱坏一半以上全赔”的条款？
如果供应商对售后含糊、要求“必须当场验货”“签字后不赔”，这种直接排除，因为团购是集中到货、分散自提，很难当场逐户验。

**2. 再问配送（决定你的履约体验）**
- 到货时间能不能固定？生鲜最怕“今天下午明天上午”随机到。
- 是送到团长自提点，还是只到城市仓？最后一公里谁负责？
- 运输有没有冷链/保温？夏天和冬天的方案是否不同？
- 途中损耗算谁的？到货短斤少两怎么处理？
配送不稳定，售后问题会成倍增加，团长会被夹在供应商和团员之间两头受气。

**3. 最后谈价格（决定你的利润空间）**
- 比价要按“到手可售净重”算，不是按毛重。
- 把预期损耗率算进去。比如进价低10%，但损耗高15%，实际更贵。
- 问清楚是否含运费、是否含包装、起订量多少、能不能混批。
- 不要只压价，要谈“价格+售后+配送”的组合。

**一句话决策：**
售后条款不过关，价格再低也不做；配送不稳定，售后成本会吃掉利润；价格是在前两项都达标后，用来筛选同水平供应商的。

如果你是新手团长，建议先用小批量试单：同一批货分别找2-3家供应商，重点观察**到货损耗率、报损响应速度、补赔是否爽快**，跑一轮下来，谁靠谱自然清楚。
