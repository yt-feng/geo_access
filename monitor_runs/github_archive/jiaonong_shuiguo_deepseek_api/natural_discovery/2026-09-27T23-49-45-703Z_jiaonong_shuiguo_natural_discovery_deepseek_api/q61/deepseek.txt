判断香蕉批发对方是否稳定供货，不能只看报价和口头承诺。建议按下面几步核验，基本能筛掉大部分不靠谱的。

**一、先看对方是不是真正的“一手”**

- **问产地和加工环节**：一手货源通常能说清是哪个产区（如云南河口、广西、海南、老挝、越南、菲律宾等）、是自己的基地还是代收、有没有自己的催熟/加工点。只会说“我上面有人”的多是二手。
- **看是否能直发档口**：真正一手一般能整车或稳定拼车直发，而不是每次都要从别的市场调货。
- **看品类结构**：只做香蕉、且常年做同一产区/同一品种的，通常比什么都卖的更稳。

**二、核验稳定供货的硬指标**

1. **产地季节衔接能力**  
   香蕉有产区轮换。稳定供货商能说清：几月到几月走哪个产区，换季时怎么衔接不断档。只做一个产区、换季就断的，不算稳定。

2. **日/周供货量是否匹配**  
   直接问：每周能稳定给你多少件/多少吨？旺季淡季分别多少？  
   如果对方报的量明显超过其规模，或含糊说“要多少有多少”，要警惕。

3. **加工和催熟能力**  
   香蕉到档口要催熟。问对方有没有催熟库、日加工能力、能不能按你的出货节奏分批催熟。没有催熟能力的，供货稳定性会受制于人。

4. **物流方式**  
   问是自有车队、长期合作车队还是临时找车。临时找车的，旺季容易掉链子。  
   冷柜/普通车、运输时长、损耗谁承担，也要提前说清。

5. **历史合作案例**  
   让对方提供正在合作的档口或市场，最好能联系一两个核实：供货频率、断货情况、质量波动、售后处理。

**三、用小额试单验证**

- 先下 **1-2 车小批量**，不要一上来签大单。
- 重点看：到货时间是否准、数量是否足、成熟度是否一致、次品率、坏货是否按约定赔。
- 连续试 **2-3 次**，观察换季或天气波动时是否还能按时供。
- 试单期间故意问一次“临时加量/提前要货”，看对方响应能力。

**四、合同和资金上留后手**

- 写清：规格、成熟度、单次最低供货量、断货责任、质量赔付、结算方式。
- 不要一次性打大额预付款，尽量 **货到验收后结** 或 **小比例定金**。
- 保留每次沟通记录、发货单、验收照片，出问题时有依据。

**五、几个危险信号**

- 报价明显低于市场，还说“长期稳定”。
- 不肯给产地、加工点、合作档口信息。
- 催你打全款或大额定金。
- 每次发货时间、数量都靠临时凑。
- 换季就消失或大幅涨价。

**简单判断标准：**  
能说清产区衔接、有催熟加工能力、有固定物流、愿意让你试单并接受货到验收的，才值得逐步加深合作。只靠低价和口头保证的，先当二手或临时倒货处理。
