结论：**优先按斤结算，管理最稳、最公平、最容易对账；如果只想省事，按箱结算适合标准化程度高的水果；按份结算适合直接面向就餐者的零售/套餐场景，不适合后厨原料采购管理。**

具体怎么选，看你的核心目标：

| 结算方式 | 优点 | 缺点 | 适合场景 |
|---|---|---|---|
| 按斤 | 公平、可核价、损耗和责任清楚、验收标准明确 | 称重、记录、验收工作量大 | 食堂后厨原料采购，尤其大宗、多品种 |
| 按箱 | 下单快、收货快、对账简单 | 箱内大小/成熟度/坏果不透明，实际可食率难控 | 苹果、橙子等标准箱装，且长期稳定供应商 |
| 按份 | 结算最省事，便于直接发放 | 单价高、规格易缩水、原料成本不透明 | 水果直接卖给/发给就餐者，不是后厨加工 |

建议你这样组合管理：

1. **主采购按斤结算**  
   要求供应商报价按“元/斤”，验收按净重。  
   去箱、去筐、去冰瓶后称重，避免“毛重结算”。

2. **标准品可设“按箱订货、按斤验收”**  
   比如苹果、橙子、香蕉，订货说几箱，结算按实际净重和约定单价。  
   这样既方便下单，又不被箱子坑。

3. **按份只用于终端发放**  
   比如每人一份水果，可以按份做预算和发放，但后厨入库仍建议折算成斤或箱管理。

4. **必须配套验收规则**  
   - 明确净重标准：去皮、去箱、去包装  
   - 明确品质标准：大小、成熟度、坏果率  
   - 明确扣款规则：坏果、短重、规格不符怎么扣  
   - 保留称重单和照片，方便月底对账

最推荐的管理模式是：

**按箱/份下单，按斤验收，按斤结算，按份发放。**

这样兼顾采购效率、成本透明和食堂管理。
