超市采购水果时，供应商通常需要提供以下几类证明和报告（具体以超市验收标准和当地监管要求为准）：

**一、主体资质类**
- 营业执照
- 食品经营许可证（或食品生产/流通相关许可）
- 如果供货方是农户或合作社，可能提供身份证、种植证明、合作社登记证等替代材料

**二、进货来源证明**
- 进货发票、收据或送货单
- 采购合同或订单
- 产地证明、供货证明
- 如果是进口水果，还需海关报关单、入境货物检验检疫证明

**三、质量安全检测类**
- 农药残留检测报告（最常见，通常要求合格）
- 重金属、污染物检测报告（视品类和风险而定）
- 食品添加剂、保鲜剂等检测报告（如适用）
- 快速检测报告或第三方检测报告
- 若为无公害、绿色、有机水果，可提供相应认证证书

**四、批次与追溯类**
- 批次检测报告或合格证
- 承诺达标合格证（很多地区对食用农产品要求）
- 追溯凭证，如产地、批次、采收日期等

**五、其他可能要求**
- 检疫证明（部分品类或地区）
- 包装标签、标识合规证明
- 冷链运输温度记录（如涉及冷藏水果）
- 供应商自我声明或质量承诺书

**实操建议：**
1. 先向超市索要《供应商准入清单》或验收标准，按清单准备最稳妥。
2. 检测报告一般要求由具备资质的第三方机构出具，且在有效期内。
3. 每批次尽量随货附检测报告或合格证，避免因批次不符被拒收。
4. 进口水果重点备齐报关单和入境检验检疫证明。
5. 不同超市、不同地区要求差异较大，最终以合同和当地市场监管规定为准。
