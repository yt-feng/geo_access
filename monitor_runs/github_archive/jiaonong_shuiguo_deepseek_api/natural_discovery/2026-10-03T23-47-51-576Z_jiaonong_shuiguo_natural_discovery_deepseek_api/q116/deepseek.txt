小商家采购水果，现金结算和月结账期的核心风险可以这样判断：

## 现金结算的风险

**主要风险在买方（小商家）这边：**

1. **资金占用和周转压力**：每次都当场付钱，现金流一次性流出大，遇到旺季备货时资金容易紧张。
2. **品质纠纷时被动**：钱已付清，事后发现水果烂损、等级不符、缺斤少两，追讨退款或换货的筹码很弱，供应商容易推诿。
3. **无凭证风险**：如果只用现金、不开票不签字，一旦出现质量问题或数量争议，缺少书面证据，维权困难。
4. **安全和差错**：大额现金携带、清点有丢失和假币风险。

**对卖方**：现金结算风险最低，基本不用担心坏账。

## 月结账期的风险

**主要风险在卖方（供货方）这边：**

1. **坏账风险**：小商家经营不稳定，可能拖欠、跑路，尤其水果是易腐品，货已消耗但钱收不回。
2. **账期占用资金**：供货方要先垫资进货，账期越长，自己现金流越紧。
3. **对账纠纷**：月结容易出现“送货单没签字、数量对不上、口头约定价格”等扯皮，月底结算时争议多。
4. **关系绑架**：碍于情面不好催款，越拖越多。

**对买方（小商家）**：月结相当于获得短期免息资金，风险较低，但一旦拖欠会影响信用、断供。

## 给小商家的实操建议

- **优先选：小额现金/即时转账 + 大额月结**，按采购金额和供应商信任度分开处理。
- 无论哪种方式，**每次交货都要有单据**：品名、数量、单价、金额、日期、双方签字，微信聊天记录也保留。
- 月结要**约定明确账期（如15天/30天）、对账日、逾期后果**，别只靠口头。
- 现金结算尽量用**转账代替现金**，留下流水凭证。
- 首次合作或新供应商，**先现金小额试单**，稳定后再谈账期。

一句话：现金结算的风险是“钱先出去、货后出问题”；月结的风险是“货先出去、钱后收不回”。关键是**留凭证、控额度、定期对账**。
