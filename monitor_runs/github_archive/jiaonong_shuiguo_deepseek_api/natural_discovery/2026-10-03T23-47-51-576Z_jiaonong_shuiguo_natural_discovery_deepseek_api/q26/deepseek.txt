社区超市卖小包装香蕉，核心不是“把整把拆小”，而是同时控制**采购成熟度、分切方式、包装透气性和陈列周转**。否则小包装会明显比整把卖损耗更高。

下面按采购和门店操作分开说。

**一、采购时要注意**
1. **不要按整把成熟度统一采**
   小包装通常要求顾客买回去1—2天内能吃完或刚好转黄。采购时应优先选**青一点、但已开始转色**的香蕉，例如7成熟左右，避免采已经全黄、带糖斑的货。

2. **按销售速度倒推采购量**
   小包装单包克重小，看起来卖得快，但实际客单低，容易剩。建议先按：
   - 日均整把销量
   - 预计小包装转化率
   - 损耗率  
   倒推采购。初期宁可少采，分2—3次补货，不要一次拆太多。

3. **优先选果指均匀、无机械伤的货**
   小包装会放大外观问题。采购时挑：
   - 果指粗细均匀
   - 无压伤、擦伤、裂口
   - 果柄完整
   - 无发霉、黑斑扩散  
   有伤的适合做特价整把，不适合拆小包装。

4. **关注冷链和到货温度**
   香蕉怕冷又怕闷。采购时问清运输温度，通常不宜长期低于12—13℃。到货后若温度低、果皮发暗，拆小包装后更容易黑变。

5. **算清包装成本**
   小包装会增加：
   - 保鲜膜/袋
   - 托盘或扎带
   - 标签
   - 人工分切时间  
   如果包装成本超过售价的8%—12%，就要重新定规格或售价。

**二、包装要注意**
1. **要透气，不要完全密封**
   香蕉会释放乙烯，完全密封会加速成熟和腐烂。可用：
   - 打孔保鲜袋
   - 微孔膜
   - 网套+托盘+透气膜  
   不建议用完全密封的普通塑料袋长时间包住。

2. **按“根数”而不是“重量”更稳**
   小包装常见2—3根一包。按根卖顾客更容易判断，也便于统一定价。若按重量，需注意每包差异不要太大。

3. **果柄和切口要处理**
   拆分后切口易氧化、发霉。可保留一小段果柄，切口尽量平整，必要时用食品级材料包住切口或尽快售卖。

4. **避免挤压**
   香蕉怕压。包装不能太紧，尤其不能用硬盒强压。托盘+透气膜或网套比抽真空更合适。

5. **标签不要贴果皮**
   标签贴果皮会撕伤表皮，加速黑变。应贴在包装膜或托盘上。

**三、损耗控制要点**
1. **先进先出，但香蕉要“按成熟度先出”**
   不是单纯按到货日期，而是把最黄的先卖。青的可以稍后上。

2. **少量多次分切**
   不要早上把一天的量全拆完。建议分2—3次拆包，每次只拆1—2小时能卖完的量。

3. **陈列不要堆压**
   小包装平铺或单层斜放，避免多层堆叠。堆压处最容易出黑斑和烂果。

4. **温度别太低**
   香蕉不适合普通冷藏陈列。门店若放冷柜，温度过低会导致果皮变黑。一般应在阴凉通风处陈列，避免阳光直射和风口直吹。

5. **每天挑次品**
   早上、下午各挑一次。出现黑斑、软烂、渗液的立即下架，能打折的打折，不能卖的及时报损，避免传染其他包装。

6. **设定损耗警戒线**
   香蕉本身损耗较高，小包装通常比整把更高。建议初期把损耗控制在**8%—12%**以内观察；若连续超过15%，说明采购量、成熟度或包装方式有问题。

**四、建议的起步方案**
- 规格：2—3根/包，约300—500克
- 成熟度：采购7成熟左右，到店后自然转黄
- 包装：托盘+打孔膜或网套+透气袋
- 分切：每天分2—3次，每次少量
- 陈列：阴凉通风、单层、避免堆压
- 定价：按根或按包统一定价，减少称重人工
- 复盘：连续记录3—5天销量、损耗、报废原因，再调整采购量

最需要盯的是三点：**别采太熟、别一次拆太多、包装必须透气**。这三项做好，小包装香蕉才可能既好卖又不亏损耗。
