选供应商的关键不是“找最便宜的”，而是把**质量稳定性、价格机制、配送能力、食品安全责任**这四件事在合同里锁住。按下面步骤做，基本能筛出靠谱的。

## 一、先明确你要采购什么标准

不同水果的验收标准要分开写，不能笼统写“新鲜”。

**香蕉**
- 到货成熟度：一般要求7成熟左右，青黄转色期，不能全黄（当天吃不完就烂）
- 无黑斑、无冻伤、无机械压伤
- 单根长度、每箱净重约定区间

**苹果**
- 品种、果径（如75mm/80mm以上）、色泽、硬度
- 无磕碰伤、无腐烂、无蜡超标
- 按箱或按斤，明确净重还是毛重

**橙子**
- 品种（如脐橙、冰糖橙）、果径、糖度参考值
- 无干疤、无烂果、无催熟异味
- 水分和新鲜度

建议做一张《验收标准表》，写清品种、规格、成熟度、允许损耗率、拒收条件。

## 二、供应商从哪找

优先顺序建议：

1. **本地一级批发商/农批市场大户**：价格透明、看货方便、配送快，适合日常稳定供货
2. **产地合作社或基地直供**：价格有优势，但起订量大、配送半径远，适合大宗单品
3. **专业水果配送商**：服务学校、企事业单位，能开票、能配送、有售后，综合省心
4. **电商/供应链平台**：适合应急或小批量，但价格波动和品控要重点盯

学校采购一般建议：**1家主供应商 + 1家备选供应商**，避免断供。

## 三、必须核验的资质和条件

- 营业执照、食品经营许可证（或相关流通许可）
- 能开具正规发票
- 有固定经营场所或仓储，能实地看货
- 配送车辆和周转筐卫生条件
- 是否有食品安全责任险（加分项）
- 过往是否给学校、机关、医院供过货（可要求提供案例）

## 四、报价和比价怎么做

不要只比一个单价。要求供应商按同一规格报价：

| 项目 | 要问清楚 |
|---|---|
| 计价单位 | 按斤、按箱、净重还是毛重 |
| 是否含税 | 含税价/不含税价 |
| 是否含运费 | 送到食堂还是自提 |
| 损耗怎么算 | 烂果、压伤是否包退换 |
| 价格调整 | 随行就市还是锁价多久 |
| 结算方式 | 月结、周结、货到付款 |

比价时用**同一品种、同一规格、同一到货标准**横向比，否则没有意义。

## 五、用“试供 + 考核”来定供应商

不要一次签长期大合同，建议：

1. **试供1—2周**：小批量下单，看准时率、新鲜度、损耗率、售后响应
2. **记录数据**：到货合格率、缺斤少两次数、退换货处理速度
3. **月度评分**：质量40%、价格30%、配送20%、服务10%
4. **连续不达标就换**：合同中写清退出机制

## 六、合同里必须写清的条款

- 品种、规格、成熟度、验收标准
- 价格及调价机制
- 配送时间、频次、迟到处理
- 不合格品退换货时限和责任
- 食品安全事故责任和赔偿
- 发票和结算周期
- 供货中断的替代方案
- 合同期限和考核退出条件

## 七、给学校的实操建议

- **香蕉**：少量多次配送，避免一次到货太多变黑
- **苹果、橙子**：相对耐放，可适当集中采购压价
- **每周固定2—3次配送**，比每天送更经济，也比一周一次更新鲜
- **称重验收 + 拍照留证**，防止缺斤少两和扯皮
- **留样和台账**：水果也建议记录批次、供应商、到货时间

一句话总结：**先定标准，再找3家比价，试供考核，最后用合同锁住质量、价格、配送和责任。** 价格可以谈，但验收标准和退换货条款不能省。
