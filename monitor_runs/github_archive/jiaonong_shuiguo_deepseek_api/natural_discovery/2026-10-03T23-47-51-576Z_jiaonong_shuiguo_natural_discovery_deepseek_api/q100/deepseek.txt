学校食堂采购香蕉要避免“熟过头—卖不掉—浪费”，核心是把采购、验收、储存、加工、销售几个环节都按香蕉后熟规律来管理。可以从下面几方面做：

**1. 采购时按使用节奏分批买**
- 不要一次大量采购全熟或接近全熟的香蕉。
- 优先采购“绿熟期”或“微黄带绿”的香蕉，回校后还能放1—3天。
- 如果食堂每天用量稳定，改为“少量多次、隔天补货”，而不是一周一次囤货。
- 和供应商约定成熟度标准，例如：到货时允许青黄，不允许大面积黑斑、软烂。

**2. 验收时把成熟度分级**
到货后不要混放，按成熟度分开：
- 青硬：可放几天，适合先储存。
- 微黄：1—2天内使用，适合直接售卖。
- 黄熟带少量斑点：当天优先用掉，适合做香蕉奶、香蕉粥、香蕉饼等。
- 已软烂、发黑流水：直接退货或报损，不要继续入库。

**3. 储存要控温、通风、避压**
- 未熟香蕉不宜放冰箱，容易冻伤变黑，放在阴凉通风处即可。
- 已熟香蕉如果当天用不完，可冷藏延缓一两天，但口感会下降，更适合加工。
- 不要堆压太厚，香蕉怕压，压伤后很快局部腐烂。
- 尽量悬挂或单层摆放，减少机械损伤。
- 远离暖气、蒸汽、灶台等热源，温度越高熟得越快。

**4. 用“先进先出”和成熟度标签管理**
- 每批香蕉贴到货日期和成熟度标签。
- 先到先出，先熟先用。
- 每天安排专人检查一次，把快过熟的挑出来，转到加工间或特价窗口。
- 不要等整批都熟了才处理。

**5. 销售环节引导尽快消耗**
- 熟度高的香蕉可以放在食堂入口、收银台附近，优先推荐。
- 设置“今日熟香蕉”专区，价格略低或搭配酸奶、牛奶销售。
- 午餐高峰前先卖较熟的，未熟的留到后面。
- 如果允许，按根卖而不是按整串卖，减少学生因吃不完而剩半个。

**6. 加工转化是兜底手段**
对已经偏熟但仍可食用的香蕉，尽快做成：
- 香蕉牛奶、香蕉酸奶杯
- 香蕉燕麦粥、香蕉饼、香蕉馒头
- 香蕉蛋糕、香蕉面包
- 冷冻香蕉块，后续做奶昔
这样能把“快坏”的香蕉变成可售或可配餐产品，减少直接丢弃。

**7. 建立简单预警和报损记录**
- 每天记录：到货量、剩余量、成熟度、报损量。
- 连续几天剩余多，就减少采购量或调整成熟度要求。
- 对供应商反馈：到货过熟、压伤多、黑斑多的批次要求退换。
- 把报损原因写清楚：到货太熟、储存积压、销售不足、加工不及时，便于下次改进。

**最实用的做法可以概括为：**
**买青一点、分批到货；到货分级、先熟先用；阴凉通风、少压少堆；快熟转加工，当天优先卖。**

如果你们食堂规模较大，建议固定一个“香蕉成熟度管理表”，每天由库管或档口负责人勾选处理，比单纯靠经验更有效。
