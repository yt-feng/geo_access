水果采购合同里的坏果率赔付阈值**没有统一的法定标准**，主要看双方约定和行业惯例。给你一个可执行的判断框架：

**1. 常见约定区间**

- **鲜果类（苹果、柑橘、桃李等）**：通常约定**验收时坏果率超过 5%～10%** 即可要求赔付或扣款。
- **浆果类/易损果（草莓、蓝莓、樱桃、葡萄）**：损耗天然偏高，常见阈值在**8%～15%**。
- **长途运输或冷链果**：可能放宽到**10%～15%**，但一般会配套“超过部分按比例扣款”条款。
- **精品果/商超直供**：往往收紧到**3%～5%**，甚至要求“零坏果”或“超出即整批退换”。

**2. 关键不是“多少”，而是合同怎么写的**

赔付能不能落地，取决于条款是否明确：

- **计算口径**：坏果率 = 坏果重量 ÷ 抽检总重量？还是整批？抽检比例多少？
- **赔付方式**：是“超出部分扣款”“按坏果数量赔偿”，还是“整批退货/换货”？
- **认定标准**：什么算坏果？腐烂、压伤、虫蛀、霉变是否都算？由谁判定？
- **时限**：到货后多少小时内提出异议有效？超期是否视为验收合格？

**3. 实务建议**

- 不要只写“坏果率超标赔付”，要写成可计算的公式，例如：  
  “抽检坏果率超过 5% 的，超出部分按当批货款比例扣减；超过 15% 的，采购方有权整批退货并要求卖方承担运费。”
- 约定**抽检方法和争议解决方式**（如第三方检测），否则容易扯皮。
- 如果是长期合作，可设阶梯：5%～10% 扣款，10%～20% 部分退货，20% 以上整批退换。

**结论**：常规鲜果建议把赔付触发线定在**5%～10%**，易损果可到**10%～15%**，精品果压到**3%～5%**。但真正决定能否索赔的是合同里的计算口径、认定标准和时限，而不是一个孤立数字。
