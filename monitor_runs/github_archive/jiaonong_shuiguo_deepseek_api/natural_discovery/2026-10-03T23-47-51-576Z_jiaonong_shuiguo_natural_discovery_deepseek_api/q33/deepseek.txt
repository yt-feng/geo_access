重要，而且往往是统一品质的前置条件。对多门店超市来说，水果品质不统一通常不是门店执行问题，而是源头分级标准不统一导致的。

**为什么供应商分级标准重要**

1. **决定“同一品质”的定义权**
   如果供应商按自己的标准分“一级、二级”，不同供应商的一级可能完全不是一回事。门店按名称采购，收到的货在糖度、大小、成熟度、外观上就会有差异。

2. **影响门店间一致性**
   多门店要统一品质，必须让不同门店、不同批次拿到的是同一规格。没有统一分级，A店和B店即使都订“一级果”，实际体验也可能不同。

3. **影响定价和损耗**
   分级不清会导致采购价与品质不匹配，好果差果混装，门店要么卖不上价，要么损耗上升。分级标准越清晰，越容易做等级定价、陈列分级和促销分级。

4. **影响验收和追责**
   有标准才能验收。否则门店说“不够甜、太小”，供应商说“这就是一级”，扯皮成本很高。

**但只看供应商标准还不够**

多门店超市要统一水果品质，建议至少做到：

- **建立自己的采购分级标准**：按品类定义大小、色泽、糖度、成熟度、损伤率、单果重等指标。
- **要求供应商按你的标准供货**：不是接受供应商现成标准，而是让供应商对照你的验收标准分级。
- **统一验收方式**：比如糖度抽检、克重抽检、外观抽检比例，各门店执行同一套。
- **按品类做差异化标准**：苹果、柑橘、香蕉、草莓的分级维度不同，不能一套标准打天下。
- **保留样品和批次记录**：出现争议时可对照，也能反向筛选供应商。

**结论**

供应商的分级标准重要，但更重要的是：超市要有一套自己的、可验收的分级标准，并让供应商按这套标准稳定供货。否则多门店统一水果品质很难真正落地。
