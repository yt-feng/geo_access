社区超市做水果，损耗和库存是生死线。下面按“进货—陈列—定价—清货—复盘”给你一套能直接执行的打法。

## 一、进货：少量多次，按销量定

1. **先定SKU，别贪多**
   - 社区店水果控制在 **15–25个单品** 就够，分三类：
     - 引流款（苹果、香蕉、橙子）：天天有，走量
     - 利润款（葡萄、蓝莓、进口果）：毛利高但少进
     - 尝鲜款（当季热销）：每周2–3个，卖完就换
2. **按“日销量×1.5”订货**
   - 比如苹果一天卖20斤，就进30斤左右，别一次进100斤。
   - 易坏的（草莓、葡萄、桃）按 **1天量** 进；耐放的（苹果、橙、柚）可2–3天量。
3. **固定进货节奏**
   - 每周2–3次小批量，比一次大批量强。
   - 早市/凌晨进货，当天上架最新鲜。
4. **看天气和节假日**
   - 下雨天、工作日销量降，少进；周末、节假日多进20–30%。

## 二、收货：当场验，不合格就退

- 看：颜色、软硬、有无霉点、碰伤。
- 摸：太软、出水、发黏的直接拒收。
- 称：抽查重量，防止缺斤少两。
- **原则：宁可少收，不收次货。** 一批烂果会拖垮整店口碑和利润。

## 三、陈列：分区摆放，先进先出

1. **按成熟度分区**
   - 未熟/耐放：苹果、橙、柚，常温架。
   - 已熟/易坏：草莓、葡萄、桃，冷藏或冰台。
   - 热带果（香蕉、芒果）别冷藏，会黑。
2. **先进先出**
   - 新货放后面/下面，旧货放前面，先卖旧货。
   - 每天开门前翻一遍，挑出软果、碰伤果。
3. **少量多次补货**
   - 货架别堆太满，堆满显多但压货。每次补“看起来满”即可。
4. **挑出来的伤果立刻处理**
   - 能削的做果切/拼盘，不能的做特价，别放回原货架。

## 四、定价：用价格换速度

- **引流款微利**：苹果、香蕉定低价，带人流。
- **利润款正常价**：葡萄、蓝莓保持毛利。
- **临期/软果动态降价**：
  - 当天下午：9折
  - 傍晚：7折
  - 闭店前：5折或打包卖
- **果切/拼盘**：把快坏的果做成盒装，毛利反而高。

## 五、清货：每天必须清，别过夜

1. **每日三次检查**：早、午、晚各一次，挑坏果。
2. **设置“清货时段”**：下午4点后开始打折，晚8点后大力清。
3. **组合销售**：买大送小、满减、搭配酸奶/沙拉。
4. **闭店前处理**：
   - 能冷藏的冷藏，明天优先卖。
   - 不能放的做果切、榨汁、员工内购或联系食堂/果汁店回收。
   - **绝不让烂果过夜上架。**

## 六、库存管理：用简单表格就能管

每天记三样：
- 进货量
- 销售量
- 损耗量

一周后你就能算出：
- 每个单品日均销量
- 损耗率（目标控制在 **5%以内**，叶菜/浆果可放宽到8%）
- 哪些品该砍、哪些该加

**订货公式：**
> 明日订货量 = 近3天日均销量 × 天气系数（0.8–1.3） − 现有库存 + 安全库存（1天量）

## 七、几个硬规矩

1. **不压货**：宁可卖断，别卖烂。断货明天补，烂货天天亏。
2. **少SKU、快周转**：单品越少，管理越轻。
3. **当天事当天清**：水果不过夜，库存不过周。
4. **数据说话**：连续两周卖不动的品，直接下架。
5. **和供应商谈退换**：部分易坏品可谈“卖不完可换”，降低风险。

## 八、一周落地清单

- 第1天：盘点现有单品，砍掉滞销的，定15–25个核心品。
- 第2天：建每日进销存表，开始记录。
- 第3天：按“日销×1.5”调整订货量。
- 第4天：货架分耐放/易坏区，贴先进先出标识。
- 第5天：设下午4点清货时段，试打折。
- 第6天：做果切/拼盘，处理伤果。
- 第7天：复盘损耗率，调整下周订货。

核心一句话：**少量多次进货，先进先出陈列，当天清货不过夜，用数据定订货量。** 做到这四点，水果压货和损耗基本能控住。
