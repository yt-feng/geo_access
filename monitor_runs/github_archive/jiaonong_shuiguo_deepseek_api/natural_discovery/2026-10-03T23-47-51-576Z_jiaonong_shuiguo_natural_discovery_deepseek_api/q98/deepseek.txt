判断水果供应商是否合规、稳定，核心是看五件事：**主体资质、食品溯源、冷链与仓储、履约记录、合同约束**。下面给你一份可直接拿去用的采购核查清单。

## 一、合规性：先看“证”和“票”

**必须核验的资质**
1. **营业执照**：经营范围含“水果批发/零售/农产品销售”，且在有效期内。
2. **食品经营许可证**（如涉及预包装或加工）：核对许可项目和有效期。
3. **对公账户**：打款必须走对公，拒绝只给个人微信/支付宝收款，这是识别皮包公司的重要信号。
4. **开票能力**：能否开具增值税发票。养老院、医院财务通常要求正规票据，不能开票的直接排除。

**每批次必须提供的证明**
- **进货凭证/产地证明**：说明水果来源，尤其是批量采购。
- **农残检测报告**：优先要供应商自检报告；重点品类（叶菜类、草莓、葡萄等）可要求第三方检测报告。注意报告要有**批次/日期对应**，而不是一张通用旧报告反复用。
- **检疫合格证明**：进口水果需有海关入境货物检验检疫证明。

**警惕信号**
- 资质证照含糊、拒绝提供原件或清晰复印件；
- 报价明显低于市场价（往往靠以次充好或来源不明）；
- 只肯现金/私人转账、无法开票。

## 二、稳定性：看“供得上、供得稳、供得新鲜”

**供应能力**
1. **货源结构**：是自有基地、长期合作产地，还是临时从批发市场倒货？前者更稳。
2. **多品类覆盖**：能否稳定供应苹果、香蕉、橙子等常规品类，而非季节性断供。
3. **淡旺季预案**：问清楚台风、寒潮、节假日涨价时怎么保供、怎么锁价。

**冷链与仓储**
- 是否有冷藏库、冷藏车，运输途中是否有温控记录；
- 到货时抽检：看果温、看有无挤压腐烂、看包装是否规范。

**履约记录（最关键）**
- 要求提供**近半年同类客户名单或供货案例**，最好能联系1—2家（如其他养老院、医院、学校食堂）核实；
- 试供期建议1—2个月，期间统计：**准时到货率、缺货次数、质量退换率、投诉响应速度**。

## 三、把风险写进合同

不要只靠口头承诺，建议在合同中明确：
1. **质量标准**：按品类约定规格、成熟度、单果重量、允许损耗率（如腐烂率≤3%）。
2. **验收与退换**：到货当场验收，不合格整批退回，费用由供应商承担；约定退换时限。
3. **价格机制**：约定调价需提前书面通知，或按市场指数定期调价，防止随意涨价。
4. **违约责任**：缺货、迟到的赔偿标准；连续两次质量不合格可终止合同。
5. **食品安全责任**：因水果农残或质量问题导致食品安全事故的，供应商承担全部责任。
6. **票据与结算**：明确发票类型、账期。

## 四、实操建议

- **不要独家依赖一家**：至少保留2家合格供应商，主供+备供，防止断供。
- **建立供应商档案**：资质、检测报告、履约评分都归档，每季度复评一次。
- **坚持索证索票**：每批次留存进货凭证和检测信息，这也是食堂食品安全监管的硬要求。
- **先小批量试供**：试供合格再签长期合同，比一开始就签大单稳妥得多。

**一句话判断**：能提供齐全资质和批次检测、有冷链、能对公开票、有可核实的同类客户供货记录、且愿意把质量与违约条款写进合同的供应商，基本就是合规且稳定的；缺其中任何关键项，都要打问号。
