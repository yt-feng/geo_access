如果目标是稳定出品、控制损耗和人工，优先顺序通常是：

**果泥 ≥ 鲜果 > 果丁**  
但具体要看你做什么产品、门店操作能力、成本和风味定位。

## 1. 先按产品用途选

| 用途 | 推荐 | 原因 |
|---|---|---|
| 菠萝果茶，要喝到果肉感 | **鲜果 + 少量果泥/果丁搭配** | 鲜果香气自然，果肉有咀嚼感 |
| 冰沙、奶昔、混合果茶 | **果泥** | 出杯稳定、易计量、少人工 |
| 装饰、顶部果肉、咀嚼小料 | **果丁** | 使用方便，但风味和香气通常弱于鲜果 |
| 大批量、连锁、外卖占比高 | **果泥为主，鲜果为辅** | 标准化强，减少削皮切果损耗和口味波动 |

## 2. 三种原料的优缺点

### 鲜果
**优点：**
- 香气最自然，消费者感知价值高
- 适合做“鲜切菠萝”“手捣菠萝”这类卖点
- 可同时做装饰和果肉

**缺点：**
- 要削皮、去眼、切块，人工高
- 损耗大，成熟度不稳定
- 季节和批次差异明显，今天甜明天酸
- 外卖久放后容易出水、变味、口感下降

**适合：**
- 中高端门店
- 主打鲜果现制
- 客流稳定、有人手现场处理
- 菠萝当季且采购渠道稳定

### 果丁
**优点：**
- 开袋即用或简单处理，操作快
- 大小统一，适合做小料、装饰
- 比鲜果稳定，损耗低

**缺点：**
- 很多果丁是糖水浸泡或冷冻款，菠萝本身香气弱
- 容易偏甜，需要调整糖浆
- 有的口感软烂，没有鲜果脆感
- 成本按可食用部分算未必低

**适合：**
- 做顶部装饰
- 做咀嚼小料
- 门店人手紧张，但又想保留果肉感

### 果泥
**优点：**
- 出杯最稳定，计量方便
- 风味、酸甜度、颜色更统一
- 适合连锁、外卖、高峰出杯
- 损耗低，培训简单

**缺点：**
- 果肉感和鲜果香气通常弱一些
- 品质差异大，要选对供应商
- 有些产品香精感重、后味假
- 开袋后保存和冷藏管理要严格

**适合：**
- 冰沙、果茶基底
- 连锁标准化
- 外卖占比高
- 高峰期快速出杯

## 3. 更实际的采购建议

### 如果你是小店/单店
建议：
- **鲜果为主**：做招牌菠萝果茶，突出鲜切卖点
- **果泥为辅**：用于高峰期、外卖、冰沙或稳定酸甜度
- **果丁少量**：只做装饰或小料，不建议当主力

### 如果你是连锁/外卖多
建议：
- **果泥为主**
- **鲜果做差异化门店现切**
- **果丁用于装饰或咀嚼小料**
- 建立标准配方：果泥克数、糖浆克数、茶汤克数、冰量固定

### 如果预算有限
优先买：
1. **冷冻菠萝果肉/果丁**：比鲜果稳定，比部分果泥有果肉感
2. **浓缩菠萝汁或果泥**：做基底
3. 少量鲜果：只做装饰或招牌款

## 4. 判断供应商的实操标准

买果泥时重点看：
- 配料表：是菠萝果泥，还是“菠萝味饮料浓浆”
- 果肉含量/固形物含量
- 是否加糖、加香精、加色素
- 解冻或开袋后风味是否发闷
- 和茶汤混合后是否发苦、发酸、分层

买果丁时重点看：
- 是糖水浸泡、冷冻还是冻干
- 大小是否均匀
- 口感是脆还是软烂
- 糖水浓度会不会影响配方
- 解冻后出水多不多

买鲜果时重点看：
- 品种：香水菠萝、金钻菠萝、台农等风味不同
- 成熟度：太生酸涩，太熟易烂
- 出肉率：一般削皮去眼后损耗不小
- 季节价格波动

## 5. 结论

**最推荐组合：果泥 + 鲜果。**

- **果泥**负责稳定、效率、外卖和基底
- **鲜果**负责香气、卖点和差异化
- **果丁**只作为装饰或小料补充

如果你只选一种：
- 追求标准化和效率：选**果泥**
- 追求鲜果卖点和口感：选**鲜果**
- 只想省事做小料：选**果丁**，但不建议作为菠萝果茶的核心原料。
