从经营角度，**最稳的组合是：整果为主，去皮服务做增值，让顾客“可挑但不过度翻拣”。**  
不建议只卖去皮好的，也不建议完全放任顾客自己挑。

具体可以这样定：

1. **整果作为主售卖形态**
   - 成本最低，损耗最小。
   - 顾客觉得新鲜、可自己判断。
   - 适合按个、按斤、按甜度分级卖。

2. **去皮好的只做少量现切/预订**
   - 适合赶时间、不会削、当场要吃的人。
   - 但去皮后保质期短、氧化快、损耗高。
   - 最好“现场削”或“当天削当天清”，不要大量提前削好摆着。

3. **让顾客挑，但要有限度**
   - 可以挑，但最好由店员帮忙拿、帮忙翻。
   - 完全让顾客自己翻，容易捏坏、摔坏、堆乱，增加损耗。
   - 可以按成熟度分区：今天吃、放两天、做菜/榨汁，减少乱挑。

4. **更赚钱的做法**
   - 整果按个卖，标甜度或品种。
   - 加“免费削皮/收费削皮”服务。
   - 削皮后切块装盒，溢价卖。
   - 熟度高的做特价或鲜切，减少报废。

一句话：**主卖整果，现场削皮，有限挑选，少量预削。**  
这样兼顾损耗、体验和利润。
