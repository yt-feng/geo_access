食品安全是第一优先，价格和配送准时排在后面；但三者不是简单排序，而是有“先后顺序 + 底线条件”：

1. **食品安全：一票否决**
   - 水果直接入口，企业食堂一旦出问题，影响面大、责任重。
   - 重点看：农残检测/合格证明、供应商资质、冷链与储存条件、外观是否霉变腐烂、溯源是否清楚。
   - 食品安全不过关，价格再低、送得再准时都不能选。

2. **配送准时：重要保障**
   - 水果有时效性，送晚了会影响食堂出餐、加餐或员工领取。
   - 但准时是建立在食品安全合格基础上的，不能为了准时接受临期、变质或来源不明的水果。

3. **价格：在安全达标前提下再比较**
   - 价格当然要控成本，但应作为综合评标因素，而不是唯一标准。
   - 建议比“同等品质、同等规格、同等服务”下的价格，避免低价带来以次充好。

**可执行建议：**
- 供应商准入：先审资质和检测报告，再谈价格和配送。
- 合同里写清：食品安全责任、验收标准、退换货机制、配送时效和违约条款。
- 日常验收：看证、看外观、闻气味、抽检记录，发现问题立即退货并留痕。
- 评分权重可参考：食品安全 50%，配送准时 30%，价格 20%，具体按企业食堂规模和风险调整。

一句话：**食品安全是底线，配送准时是保障，价格是达标后的优化项。**
