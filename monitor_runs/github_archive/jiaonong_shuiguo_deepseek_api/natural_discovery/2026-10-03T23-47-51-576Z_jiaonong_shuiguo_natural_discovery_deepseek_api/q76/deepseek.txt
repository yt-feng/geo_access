生鲜电商卖香蕉，配送损耗主要来自两类：**物理压伤**和**乙烯催熟/低温冷害导致的变黑**。分开控制更有效。

**一、物理压坏**

- **选对成熟度发货**：不要发全黄熟蕉。发**青黄交接、硬度较高**的香蕉，约7成熟，到用户手里正好转黄，抗压性也强。
- **单根或小把独立防护**：整把香蕉互相挤压最容易黑。可用**珍珠棉网套**单根包裹，或把整把用**气泡膜/瓦楞纸隔层**包住，再入箱。
- **包装留空隙但不晃动**：箱内用**充气袋、纸隔板、珍珠棉填充**固定，避免运输中滚动碰撞。香蕉怕“晃”也怕“挤”。
- **竖放或悬挂思路**：香蕉自然状态下是悬挂的，受重力小。装箱时尽量让**弯曲朝上、减少承重面**，或设计卡槽固定。
- **控制堆码层数**：香蕉箱不要压太重，堆码不超过2-3层，重物不压在香蕉上。

**二、变黑（催熟+冷害）**

- **控温最关键**：香蕉对低温敏感，**低于13℃会冷害发黑**，高于25℃又加速成熟。配送全程尽量保持**13-18℃**。夏季用保温箱+冰袋（冰袋不要直接贴香蕉），冬季防冻。
- **通风排乙烯**：香蕉自身释放乙烯，密闭会加速变黄变黑。包装上留**透气孔**，或用**微孔保鲜袋**，不要完全密封。
- **避免和催熟水果混放**：苹果、猕猴桃、番茄等乙烯释放大的不要和香蕉同箱。
- **缩短在途时间**：同城尽量**当日达/次日达**，减少中转。
- **到货后提示用户**：告知“青黄交接属正常，室温放置1-2天自然转黄”，避免用户以为坏了。

**三、可落地的操作组合**

推荐方案：**7成熟青黄蕉 + 单根珍珠棉网套 + 瓦楞纸隔层 + 透气纸箱 + 13-18℃保温配送 + 同城次日达**。这套对压伤和变黑都能明显改善。

如果做高端礼盒，可加**独立卡槽+微孔膜**；如果走低价走量，至少做到**网套+透气箱+控温**，别裸装挤压。

核心判断标准：发货时香蕉要**硬、青黄、无黑斑**；到货时允许**少量转黄**，但不该有**大面积压痕、水烂、发黑**。
