优先顺序很清楚：**先盯保质期和包装，再按门店销量定配送频次**。三个都重要，但作用和抓手不同。

**1. 保质期是底线，最容易出食品安全问题**
- 菠萝切块属于鲜切水果，便利店通常是冷藏短保，一般当天或 1 天内卖完最稳。
- 必须明确：加工时间、冷藏温度、到期时间，最好精确到“几点前必须下架”。
- 超过时限直接报损，不要靠闻味道判断。

**2. 包装决定品质和损耗**
- 要能密封、防漏汁、防串味、方便看日期。
- 包装上应标：加工日期/时间、保质期、保存条件。
- 如果门店自己切，重点查刀具、砧板、手套、冷藏展示柜卫生。

**3. 配送频次影响的是周转和损耗，不是第一优先级**
- 配送频次要根据单店日均销量定：卖得快的店一天多配，卖得慢的店少配或干脆不卖。
- 频次太高，门店库存积压，过期报损多；频次太低，容易缺货或临期品硬撑。
- 更有效的做法是：小批量、多频次、按销量补货，而不是一次配很多。

**实际管理建议：**
- 责任人每天开店、午间、晚间各查一次日期。
- 到期前 1 小时做打折或下架处理，别等过期。
- 连续几天报损高的门店，先减配送量，再评估是否继续卖。
- 包装上必须有清晰时间，不然保质期管理就是空的。

一句话：**保质期管安全，包装管品质，配送频次管周转。先保证前两个，再优化第三个。**
