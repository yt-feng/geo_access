做水果礼盒，核心不是“把水果凑齐”，而是让顾客一眼觉得**值、好看、送得出手**。苹果、橙子、香蕉、菠萝这四种里，香蕉和菠萝其实不太适合做主力礼盒，原因很直接：

- **香蕉**：容易压伤、变黑，礼盒里放两三天就显旧。
- **菠萝**：带皮占地方、扎手，削皮后又容易出水，不适合混装。
- **苹果、橙子**：耐放、颜色好、寓意好，才是礼盒主力。

所以建议你按“主力+点缀”的思路来配，而不是四种平均放。

---

## 一、最好卖的三种搭配方案

### 方案1：平安橙意礼盒（最稳，主推）
- **苹果 4个 + 橙子 4个 + 香蕉 2根**
- 寓意：平安、成功、招财
- 适合：日常送礼、探病、回礼
- 定价建议：成本价 × 1.8～2.2倍
- 注意：香蕉只放2根，且用独立小纸托固定，别贴着苹果

### 方案2：旺来发财礼盒（节庆最好卖）
- **苹果 4个 + 橙子 4个 + 小菠萝 1个**
- 寓意：平安、发财、旺来
- 适合：开业、春节、乔迁
- 注意：菠萝选小个的，套网套，竖放固定，别让叶子扎到其他水果

### 方案3：混搭尝鲜礼盒（年轻人/公司团购）
- **苹果 3个 + 橙子 3个 + 香蕉 2根 + 小菠萝 1个**
- 适合：员工福利、朋友互送
- 注意：这种礼盒必须当天送当天吃，不适合久放

---

## 二、真正影响好卖的4个细节

### 1. 苹果和橙子要选“大小一致”的
礼盒最怕大小不一。顾客不会称重，但一眼就能看出“这盒是不是随便凑的”。  
苹果选红富士、阿克苏这类红亮耐放的；橙子选脐橙、冰糖橙，颜色要橙黄均匀。

### 2. 香蕉不要整串放，要单根或两根本
整串香蕉在盒里一压就黑。用气泡膜或纸托单独固定，最好放在最上层，不承重。

### 3. 菠萝要么不放，要放就放小菠萝
大菠萝放进去，整个盒子重心全偏了，还扎手。小菠萝套网套，竖着卡在角落，反而显得礼盒有分量。

### 4. 垫材和包装决定“能不能卖上价”
同样的水果，用拉菲草、牛皮纸、透明盖盒，能比塑料袋装多卖30%以上。  
颜色搭配：红苹果 + 橙橙子 + 黄香蕉 + 绿菠萝叶，本身就很好看，包装用牛皮纸或白色最稳。

---

## 三、定价和陈列建议

- **引流款**：苹果4 + 橙子4，简单透明盒，定价低，放在门口。
- **利润款**：苹果4 + 橙子4 + 小菠萝1，包装精致，放收银台旁边。
- **节庆款**：加贺卡、丝带，春节写“平安旺来”，开业写“生意兴隆”。
- **不要做**：四种水果平均放、香蕉放中间、菠萝不套网套。

---

## 四、一句话总结

**苹果和橙子做主力，香蕉最多两根做点缀，菠萝只放小个的做节庆款。**  
最好卖的是“苹果+橙子”基础盒，利润最高的是“苹果+橙子+小菠萝”礼盒。香蕉和菠萝不是不能放，而是不能当主角。
