**优先谈账期，其次售后，最后配送。**

理由很直接：长期合作里，真正吃掉你利润和现金流的，往往不是配送慢半天，而是账期和坏果赔付规则。

**1. 账期：最值得先谈**
- 水果是高频、易损耗、现金流压力大的品类，账期直接决定你的资金周转。
- 优先争取：**现结/周结 → 半月结 → 月结**，能压到更短就更好。
- 如果供应商坚持长账期，你要把价格、损耗赔付、退换条件一起打包谈，不能只让一方占优。
- 关键不是“账期越长越好”，而是**账期和你的销售回款周期匹配**。你卖得快，就没必要背长账期换高价。

**2. 售后：第二重要，必须写清楚**
- 水果合作最容易扯皮的就是：烂果、压伤、规格不符、缺斤少两、到货时间延误导致变质。
- 要谈的不是“有问题可以退”，而是：
  - 坏果率超过多少算供应商责任
  - 是按比例赔、补发，还是直接扣款
  - 拍照/视频取证时限
  - 退款或补货到账时间
- 售后规则模糊，后面每一单都可能变成情绪消耗。

**3. 配送：重要，但通常排第三**
- 配送时效、频次、起送量、临时加单、节假日保供，确实影响运营。
- 但配送问题多数可以通过备选供应商、调整下单节奏来缓冲。
- 除非你做的是高端鲜果、餐饮日配、社区团购履约，配送时效直接决定客户体验，那它可以提到第二甚至第一。

**一句话结论：**
先谈**账期**，因为影响现金流；再把**售后赔付规则**谈死，因为决定长期合作成本；最后谈**配送**，除非你的业务对时效极度敏感。
