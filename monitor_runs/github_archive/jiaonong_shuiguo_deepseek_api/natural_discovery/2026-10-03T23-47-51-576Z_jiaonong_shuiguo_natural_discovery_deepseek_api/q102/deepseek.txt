需要，而且这两项通常应作为基础准入条件写进采购要求。

**1. 开发票**
- 企业采购一般必须取得合规发票，否则财务无法入账、报销或税前扣除。
- 优先要求供应商能开**增值税专用发票**，用于抵扣；如果对方只能开普票，要提前确认是否影响你方财务要求。
- 发票内容应与实际采购一致，常见为“水果”“水果礼盒”“食品”等，避免开成“办公用品”“礼品”等不实品名。

**2. 定制包装**
- 企业福利水果礼盒通常需要体现企业标识、节日祝福、员工关怀等信息，所以定制包装很常见。
- 定制范围一般包括：外盒 logo、腰封、贺卡、手提袋、贴纸等。
- 要提前确认：起订量、打样费、打样周期、设计文件由谁提供、是否支持小批量定制、定制后是否影响交期。

**3. 采购时建议明确写进合同或订单**
- 是否含税、税率、发票类型和开票时间
- 定制内容、打样确认方式、版权/logo使用
- 起订量、单价、包装费是否另计
- 交期、配送范围、破损赔付和售后
- 水果品种、规格、净重、产地、成熟度、验收标准

**结论：**
开发票和定制包装不是“可选加分项”，对企业福利采购来说基本是必备条件。若供应商不能开发票，通常不建议合作；若不能定制包装，则要看企业是否接受通用包装。建议至少找 2—3 家同时满足这两项的供应商比价。
