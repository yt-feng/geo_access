优先关注成熟度，但要看用途：

1. **做香蕉泥/磅蛋糕/马芬**：选**熟透、带黑斑**的香蕉。这种香蕉淀粉已转糖，香气足、甜度高，成品风味明显更好，还能减少额外加糖。价格低但生青的香蕉，烤出来发涩、香气弱，通常不划算。

2. **做装饰片/夹层/需要成型**：选**刚熟、无黑斑**的香蕉，便于切片、摆盘，不易烂。

3. **采购判断顺序**：
   - 先确认用途对应的成熟度；
   - 再比较价格；
   - 最后看损耗和出肉率。

**结论**：如果做香蕉泥类烘焙，成熟度比单价更重要；如果只做装饰，成熟度标准不同，再比价格。真正该算的是“每份成品可用的熟香蕉成本”，不是单纯看每斤价格。
