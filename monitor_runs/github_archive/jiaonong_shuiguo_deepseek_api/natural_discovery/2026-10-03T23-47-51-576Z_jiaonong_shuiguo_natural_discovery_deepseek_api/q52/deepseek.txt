甜品店用香蕉，最怕的不是“熟”，而是到货时已经熟过头，到店后一两天就发黑。要避免这种情况，核心是**采购时控制成熟度，到店后控制温度和乙烯**。

### 1. 采购时：买“青一点”的
- 选**表皮青绿、转黄面积少**的香蕉，通常7成熟左右。
- 不要买已经全黄、带黑点、柄部发黑的，那种当天到店就可能很快变黑。
- 如果甜品店做香蕉泥、香蕉酱、烘焙内馅，可以买**偏生、耐放**的；如果做装饰切片，才需要稍熟但不过熟。

### 2. 运输和到货：避免闷热、挤压
- 香蕉怕闷、怕压、怕高温。运输时不要用密闭塑料袋长时间装。
- 到店后第一时间拆开包装，检查有没有发热、水汽、压伤。
- 被压伤、磕伤的香蕉会先黑，应优先挑出来先使用。

### 3. 到店后：分情况保存
**未熟或偏青：**
- 放在阴凉通风处，室温约 **12～16℃** 最好。
- 不要直接放冷库或冰箱冷藏，低温会冻伤，表皮更快变黑。

**已经转黄、准备用：**
- 放阴凉处，尽快用完。
- 如果必须延缓，可放 **10～12℃** 左右环境，但很多店没有这个条件，所以更实际的是**少量多次采购**。

**已经熟透：**
- 剥皮后冷冻保存，做香蕉泥、奶昔、烘焙内馅。
- 不要继续室温放着等它“撑住”。

### 4. 关键：隔离乙烯
香蕉自己会释放乙烯，乙烯又会催熟自己和其他水果。
- 不要和苹果、梨、番茄、牛油果等一起放。
- 不要用密封箱闷着，适当通风。
- 如果店里量大，可以用乙烯吸收剂，但小甜品店通常没必要，控制采购量更有效。

### 5. 最实用的采购策略
- **少量多次**：按2～3天用量采购，不要一次囤一周。
- **分批成熟**：一部分偏青，一部分刚好能用。
- **先熟先用**：每天检查，把最熟的挑出来优先做香蕉泥、酱、蛋糕。
- **到店即分拣**：青的、黄的、熟的分开，不要混放。

一句话：**买青一点、别冷藏、别闷着、别和催熟水果放一起，少量多次进货。** 这样基本能避免到店后很快变黑。
