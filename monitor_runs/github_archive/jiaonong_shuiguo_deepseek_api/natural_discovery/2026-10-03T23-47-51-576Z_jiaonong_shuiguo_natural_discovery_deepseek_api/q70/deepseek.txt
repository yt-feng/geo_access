# 批发合同坏果责任条款要点

核心原则：**验收前风险归卖方，验收后归买方**，并把"验收标准、时限、比例、处理方式"写死，避免扯皮。


## 一、必须明确的四个要素

| 要素 | 合同应写明 | 常见陷阱 |
|------|-----------|---------|
| **验收标准** | 明确"坏果"定义（腐烂/压伤/霉变/规格不符分别算不算） | 只写"坏果"不定义，双方理解不同 |
| **验收时限** | 到货后 X 小时内验完（如 24h/48h），逾期视为合格 | 不写时限，买方无限期索赔 |
| **坏果比例** | 允许≤X%（如 3%/5%）为正常损耗，超出部分由卖方担责 | 不写比例，一颗坏果也要全赔 |
| **处理方式** | 超出部分按"补货/退款/折价"哪种方式，折算单价怎么算 | 只写"卖方负责"但没说怎么负责 |


## 二、可参考的条款写法

> **第X条 验收与坏果责任**
> 1. 买方应在货物到达交货地点后 **24 小时**内完成验收，逾期未提出异议的，视为验收合格。
> 2. 双方确认，**坏果比例在 3% 以内**的，属于正常运输损耗，买方不得据此主张索赔。
> 3. 经双方共同确认（或第三方检测）坏果比例**超过 3%** 的，超出部分由卖方按以下方式承担：
>    - 以当批次**实际结算单价**折算，由买方在应付款中直接扣除；或
>    - 卖方在 X 日内补发同等数量合格货物。
> 4. 因买方**储存不当、二次搬运或延迟验收**造成的损耗，卖方不承担责任。
> 5. 双方对坏果比例有争议的，以 **[约定的第三方/质检机构]** 检测结果为准，检测费由责任方承担。


## 三、买卖双方各自该争取什么

**如果你是买方（批发商）：**
- 验收时限尽量长（考虑物流延误、人手）
- 坏果比例门槛压低（如 2%~3%）
- 争取"先验后付"或"扣款权"，不要先全额付款再谈赔偿
- 保留单方委托检测的权利

**如果你是卖方：**
- 验收时限尽量短，避免货物放几天后算你头上
- 明确"运输损耗"与"质量瑕疵"区分，长途运输的合理损耗要约定免责
- 限定赔偿上限（如不超过该批次货款的一定比例）
- 要求买方提供验货照片/视频等证据，防止虚报


## 四、配套留证据的操作建议

1. **装车/发货时拍照录像**，记录货物状态、数量、封箱情况
2. **到货后当场开箱抽检**，拍视频，双方在场确认
3. **书面确认单**：每次到货签验收单，写明抽检比例和结果
4. 争议批次**单独存放、封存样品**，别混入销售，否则无法核验

---

**一句话总结**：合同里写清"验收时限 + 允许损耗比例 + 超标怎么赔 + 争议谁检测"，四样齐全，坏果纠纷基本能落地解决。
