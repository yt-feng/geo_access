建议优先做“整果为主、切果为辅”的组合，而不是二选一。核心判断看三点：损耗、客流场景、毛利结构。

**1. 整果更适合作为基本盘**
- 菠萝整果耐放、损耗低，采购和陈列简单。
- 顾客对整果价格敏感，适合做引流和走量。
- 适合家庭采购、囤货型顾客。
- 缺点是客单价低，而且现在很多顾客嫌削皮麻烦。

**2. 切果更适合作为毛利和便利性补充**
- 切好的即食菠萝客单价更高，毛利通常更好。
- 适合上班族、单人家庭、即时消费场景。
- 能减少顾客处理成本，提升冲动购买。
- 缺点是损耗大、保质期短、对卫生和冷链要求高，卖不掉就只能报损。

**3. 怎么定比例，看门店类型**
- 社区店、家庭客群为主：整果占70%—80%，切果占20%—30%。
- 商圈店、写字楼店、年轻人多：切果可以提到40%—50%，整果仍保留。
- 如果门店没有冷藏条件、客流不稳定，切果比例要压到20%以下，甚至只做预订或少量试销。

**4. 关键执行点**
- 切果必须算清损耗率：去皮去芯后出成率通常只有50%—60%，定价要覆盖损耗。
- 切果要标注制作时间，尽量当日清货，超过时限直接报损或做折扣。
- 整果可以做“免费削皮”或“现场削皮”服务，兼顾便利和低损耗。
- 用整果做低价引流，用切果做利润和场景补充，不要用切果替代整果。

**结论**：大多数商超最适合“整果为主、切果为辅”。如果门店客流年轻、即时消费强、冷链和现场加工能力够，再逐步提高切果比例；否则不要盲目主推切果，损耗很容易吃掉利润。
