判断超市采购的苹果和橙子规格是否适合门店销售，可以从以下几个可执行维度入手。

## 一、先明确门店定位和客群

不同门店对规格的要求不同：

| 门店类型 | 适合的果径 | 原因 |
|---------|-----------|------|
| 社区生鲜店 | 中等偏小 | 单价低、走量快、家庭日常购买 |
| 精品超市 | 中大果 | 卖相好、客单价高 |
| 水果专营店 | 分级明确 | 按大小分档定价，满足不同需求 |
| 便利店 | 小果/即食装 | 单人份、便携 |

**先定标准，再验货**，不要反过来。

## 二、苹果的规格判断

**1. 看果径（横径）**
- 用游标卡尺或分级圈测量
- 常见分级参考：
  - 小果：65–70mm
  - 中果：70–75mm
  - 大果：75–80mm
  - 特大：80mm以上
- 同一批次果径差异应控制在5mm以内，否则陈列和定价都困难

**2. 看均匀度**
- 随机抽10–20个，最大和最小差值超过10mm，说明分级不严
- 大小混杂会导致顾客挑拣、损耗上升

**3. 看外观匹配度**
- 果形端正、着色均匀、无明显畸形
- 规格达标但卖相差，同样不适合门店

## 三、橙子的规格判断

**1. 看果径**
- 常见分级：
  - 小果：55–60mm
  - 中果：60–65mm
  - 大果：65–70mm
  - 特大：70mm以上
- 橙子比苹果略小，但同样要求批次内均匀

**2. 看重量感**
- 同等大小下，手感越重越好（水分足）
- 轻飘飘的说明失水或皮厚，不适合门店

**3. 看皮厚和可食率**
- 皮过厚会降低顾客满意度
- 可切开1–2个抽检

## 四、现场验货的可执行步骤

1. **抽样**：每批次随机抽20–30个，不要只看表面
2. **测量**：用分级圈或卡尺逐个过，记录最大/最小/平均值
3. **算差幅**：极差超过10mm，要求供应商重新分级
4. **看损耗**：抽检中有无压伤、腐烂、病斑，超过3%–5%需谨慎
5. **对照门店标准**：不符合目标客群的规格，直接拒收或降级采购

## 五、关键判断原则

- **均匀度比绝对大小更重要**：顾客要的是“看起来一致”，不是“个个都大”
- **规格要匹配定价**：大果卖高价，中果走量，不能混着卖
- **损耗率决定利润**：规格不统一会直接推高挑拣损耗
- **先小批量试销**：新品种先采少量，观察动销和损耗再放量
