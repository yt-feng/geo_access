结论：**看规模定策略——单店日销量小（香蕉+苹果合计 < 50斤）选本地批发市场；有稳定客流、日销量大或要做长期定价，选稳定供应商。** 更稳妥的做法是**两者结合**：本地批发保灵活，稳定供应商保基础量。

**为什么这样选：**

- **本地批发市场**：价格随行就市、可以每天少量拿、能看到实物挑货，适合刚上架试水、销量不确定、现金流紧的小店。缺点是品质和价格波动大，节假日或天气差时可能拿不到好货，早市去晚了只剩尾货。
- **稳定供应商（产地直供/一级批发商/果蔬配送公司）**：价格锁定或协议价、送货上门、品质相对稳定、缺货有保障，适合销量已经跑起来、需要稳定毛利和减少采购人力的店。缺点是通常有起订量、账期或押金要求，价格未必是当天最低。

**具体怎么判断：**

1. **先试两周本地批发**：记录香蕉、苹果每天的销量、损耗、售价和毛利。香蕉损耗高（易压伤、催熟快），苹果损耗低但占资金。
2. **算临界点**：如果香蕉日销稳定超过 20–30斤、苹果超过 30–50斤，就该找稳定供应商谈协议价，通常比零售批发便宜 10%–20%。
3. **香蕉和苹果分开处理**：香蕉周转快、损耗大，更适合本地每天少量补货或找专业香蕉催熟供应商；苹果耐储，可以一次从稳定供应商拿一周的量，压低单价。
4. **不要只签一家**：主供应商保基础量，本地批发做补充和比价，避免被单一供应商卡价或断货。

**一句话**：起步期用本地批发试水，销量稳定后转稳定供应商做主渠道，本地批发留作补充。
