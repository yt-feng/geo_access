水果店遇到坏果，结算和赔付通常按“先分清责任和环节，再按合同/行业惯例处理”来走。核心原则是：**坏果不能按好果全价结算，但也要看坏果是在到货前就有，还是到货后因自己存放、分拣、销售造成。**

下面按常见流程说清楚。

## 1. 先判断坏果出在哪个环节

### 到货验收时就发现坏果
比如开箱就有腐烂、压伤、发霉、冻伤、裂口、软烂。

这种情况一般属于供应商责任，处理方式通常有：

- **当场拒收坏果部分**：只收好果，坏果不计重、不计价。
- **扣重结算**：总重量里扣掉坏果重量，按好果重量结算。
- **折价结算**：坏果比例不高时，双方协商整批降价，比如按 8 折、7 折结算。
- **换货补货**：供应商下次补同等数量好果，或本次补发。
- **直接赔付**：如果坏果已经付款，供应商退还对应货款，或按合同赔违约金/损耗。

### 到货时没发现，上架后才发现
比如外表正常，里面烂心、黑心、熟过头。

这种要看：

- 是否在**合理验收期内**发现；
- 是否有**照片、视频、批次、称重记录**；
- 是否属于**隐蔽瑕疵**，而不是水果店自己放坏的。

如果证据充分，仍可要求供应商按比例赔偿或补货。  
如果已经超过约定验收期，或明显是门店储存不当导致，供应商通常不认。

### 门店自己存放、分拣、销售造成
比如没冷藏、堆压、反复搬动、放太久、挑剩的烂掉。

这部分一般由水果店自己承担，不能要求供应商赔。  
但如果能证明是供应商发货时已有隐患，比如批次本身成熟度过高，可以协商分担。

## 2. 常见结算方式

实际操作里，水果批发和供应商结算常按这几种：

### 方式一：扣重结算
公式：

**结算重量 = 到货总重量 - 确认坏果重量**

结算金额 = 结算重量 × 单价

适合坏果明显、能现场分拣的情况。

### 方式二：按比例折价
比如一车货 20% 坏果，整批按 80% 结算，或双方谈一个折扣。

公式：

**结算金额 = 总金额 × 协商折扣**

适合坏果分散、难以逐箱扣重的情况。

### 方式三：坏果补货
本次先按好果结算，供应商下次补发同等数量或等值水果。

适合长期合作供应商。

### 方式四：退货退款
坏果部分退回，供应商退对应货款；运费和损耗谁承担要提前说清。

### 方式五：按合同赔付
如果合同里有质量条款，比如：

- 坏果率超过 5% 由供应商承担；
- 超过 10% 可退货；
- 隐蔽瑕疵 24 小时内反馈有效；
- 赔偿按货值 1 倍或 2 倍；

那就按合同执行。

## 3. 赔付通常怎么算

常见算法有这些：

1. **按坏果货值赔**  
   坏果 50 斤，单价 3 元，赔 150 元。

2. **按整批折价赔**  
   总货值 5000 元，坏果率 20%，协商整批按 8 折，少付 1000 元。

3. **按实际损失赔**  
   除了货款，还包括运费、人工分拣费、损耗、延误销售损失。  
   但这类损失通常要合同有约定，否则供应商一般只认货款部分。

4. **补货抵扣**  
   下次进货时直接少发同等金额，或本次欠货下次补。

## 4. 和供应商沟通时建议这样做

### 第一时间留证据
- 到货时间、批次、车牌/单号；
- 开箱视频；
- 坏果照片，最好带整体和局部；
- 称重记录；
- 分拣记录；
- 和供应商的聊天记录。

### 尽快反馈
最好在约定验收期内反馈。  
没有约定的话，生鲜一般越早越好，通常当天或 24 小时内。  
拖久了，供应商容易说是门店自己放坏的。

### 先谈方案，不急着吵
可以直接说：

> 这批货开箱发现坏果，已分拣称重，坏果 X 斤，占比 X%。  
> 建议按扣重结算，或者坏果部分补货。  
> 你看是这次扣款，还是下次补？

### 长期合作要定规则
最好提前约定：

- 验收标准：坏果率多少以内正常，多少以上赔；
- 验收时间：到货后几小时内反馈有效；
- 结算方式：扣重、折价还是补货；
- 隐蔽瑕疵怎么处理；
- 运费和退货费谁承担；
- 超过比例是否整批退货。

## 5. 一个简单判断表

| 情况 | 通常谁承担 | 常见处理 |
|---|---|---|
| 到货开箱就烂 | 供应商 | 扣重、折价、补货、退款 |
| 隐蔽烂心，及时反馈 | 协商，多由供应商担 | 按比例赔或补货 |
| 超过验收期才发现 | 水果店风险大 | 很难索赔 |
| 门店存放不当 | 水果店 | 自己承担 |
| 合同有明确质量条款 | 按合同 | 扣款、退货、违约金 |
| 长期供应商 | 协商优先 | 下次补货或抵扣 |

## 6. 最实用的建议

1. **坏果一定要当场分拣、称重、拍照。**
2. **结算时优先扣重，其次折价，最后补货。**
3. **不要先把坏果扔掉再找供应商，否则很难举证。**
4. **长期合作一定把坏果率、验收时间、赔付方式写进订单或合同。**
5. **如果坏果比例很高，比如超过 20%—30%，可以要求整批退货或重新议价。**

一句话总结：  
**到货前就坏的，供应商担；到货后自己放坏的，自己担。结算上一般是扣重、折价、补货或退款，关键看验收时间和证据。**
