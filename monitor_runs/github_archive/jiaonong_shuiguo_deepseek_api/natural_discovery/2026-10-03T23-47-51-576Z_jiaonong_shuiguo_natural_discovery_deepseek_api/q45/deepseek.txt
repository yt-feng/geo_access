连锁超市和水果供应商签年度合同，最容易踩坑的不是价格，而是**价格调整机制、损耗归属、验收标准、账期和退换货**这几块。下面按风险从高到低说，附上可操作的防范建议。

**1. 价格与调价机制（最常见的大坑）**
- 坑：合同只写"随行就市"或"参考市场价"，没有具体基准、调价周期、审批流程。结果行情一涨，供应商单方面提价或断供；行情一跌，超市又不好压价。
- 建议：约定明确基准价 + 调价公式（参考哪个批发市场、哪个平台、哪几天的均价）+ 调价触发幅度（如波动超5%才可调）+ 提前多少天书面通知 + 双方书面确认才生效。

**2. 损耗与验收标准（水果特有）**
- 坑：合同只写"按国家标准验收"，但水果没有统一强制标准，现场扯皮。或者损耗全归超市，导致实际成本远高于报价。
- 建议：把验收标准量化写进合同附件——品种、规格（果径/单果重）、糖度、成熟度、外观（疤痕、虫眼比例）、含水/腐烂容许率。明确验收时点（到仓/到店）、抽检比例、不合格的处理方式（拒收/降级/扣款）。约定运输途中损耗和到店后自然损耗各由谁承担。

**3. 账期与结算**
- 坑：口头说"月结"，合同没写清结算周期、对账方式、付款起算日。实际拖到60天甚至更久，供应商资金压力大，最后要么涨价要么断供。
- 建议：写明"货到验收合格后X天付款"、对账单确认时限、逾期付款违约责任。连锁超市常用账期换低价，但要把账期成本算进净价里比较。

**4. 退换货与质量责任**
- 坑：只写"质量问题可退货"，但没定义什么是质量问题、退货运费谁出、是否影响当期货款。
- 建议：区分"验收时发现"和"售出后投诉"两种情形，分别约定责任和处理时限。明确食品安全问题（农残超标等）的赔偿和召回责任，这部分建议要求供应商提供检测报告并写进合同。

**5. 供货量与最低采购承诺**
- 坑：超市承诺年采购量换取低价，但没写"未达量怎么办"；或供应商承诺保供，但没写断供违约金。
- 建议：量价挂钩要写清——未达最低量时的价格回调或补差；供应商断供的违约金和替代采购差价赔偿。

**6. 独家/排他条款**
- 坑：供应商要求某品类独家供货，但没约定价格保护，导致超市失去比价空间。
- 建议：如接受独家，必须绑定价格上限或年度降本承诺，并保留因质量问题终止独家的权利。

**7. 合同期限与续约/退出**
- 建议：明确生效日、到期日、续约条件、提前终止的情形（连续质量不合格、断供、食品安全事故等），以及终止后的库存和货款清算。

**实操建议**：把验收标准、价格基准、损耗分担做成合同附件，越具体越好；生鲜类合同建议一年一签但设季度回顾机制，根据实际履约数据调整。签字前让采购、财务、品控三方各审一遍，重点看钱和责任的条款。
