连锁商超选长期水果供应商，评分标准要围绕“长期稳定”来设计，而不是单纯比价格。建议按下面框架设置，总权重可按企业偏好调整：

**一、价格与成本（建议25%-30%）**
- 报价竞争力：对标市场批发价/历史采购价
- 价格稳定性：是否承诺周期内价格波动区间，而非随行就市
- 成本透明度：是否含物流、损耗、包装、退换货成本
- 账期接受度：能否接受商超账期（长期合作关键）

注意：价格权重不宜过高，否则会吸引低价低质供应商，长期反而损耗大。

**二、产品质量与标准化（建议20%-25%）**
- 规格达标率：单果重量、糖度、外观等是否符合验收标准
- 农残检测：是否提供批次检测报告、是否可追溯
- 分级能力：能否稳定供应同一等级产品
- 损耗率承诺：到店损耗是否可控

**三、供应稳定性与产能（建议20%左右，长期合作核心）**
- 自有基地/合作基地规模：能否覆盖商超全年需求
- 季节性缺口应对：淡季如何补货
- 历史履约率：过去合作或参考客户的准时到货率
- 抗风险能力：极端天气、疫情等情况下是否有预案

**四、物流与配送能力（建议10%-15%）**
- 冷链能力：是否全程冷链，温控记录
- 配送时效：能否按商超要求频次、时间到店
- 覆盖范围：能否覆盖商超所有门店或区域仓
- 应急补货能力

**五、服务与配合度（建议10%左右）**
- 退换货政策：质量问题如何处理，是否主动承担
- 对账与结算配合：单据是否规范
- 响应速度：问题反馈后处理时效
- 是否愿意配合商超做促销、定制包装

**六、企业资质与可持续性（建议5%-10%）**
- 营业执照、食品经营许可、种植/加工资质
- 财务健康度：能否支撑长期账期
- 过往合作案例：是否有连锁商超供货经验
- 食品安全事故记录：一票否决项

**建议设置的一票否决项：**
- 无法提供农残检测或溯源
- 近三年有重大食品安全事故
- 资质造假
- 无法接受商超基本账期和验收标准

**实操建议：**
1. 先做资格预审，过滤掉不达标的，再进入打分。
2. 价格分用“基准价±浮动”方式，避免最低价中标。
3. 对“长期稳定”类指标，要求投标方提供历史数据或承诺函，并写入合同。
4. 评标时引入样品盲测和实地考察，光看标书容易失真。
5. 合同里把评分承诺转化为考核条款，比如月度履约率、损耗率、退货率，不达标扣款或退出。

简单说：**价格占三成，质量和稳定占五成，服务和资质占两成**，这样选出来的供应商更可能长期合作，而不是低价进来后不断出问题。
