找每天配送的水果供应商，建议重点看以下条件：

1. **配送频次与时效**
   - 能否承诺每天固定时间送达，而不是“隔天”“凑单送”。
   - 下单截止时间、到店时间是否匹配你的营业节奏。
   - 临时加单、补货、节假日是否还能配送。

2. **起送量与配送费**
   - 每天起送金额或起送件数是否适合社区超市，避免为了凑量压库存。
   - 配送费、远距离附加费、楼层/卸货费是否另算。
   - 是否支持小批量多品类混送。

3. **货源稳定性**
   - 是否有稳定产地、批发市场档口或一级代理资源。
   - 应季水果和反季水果能否持续供货。
   - 爆款断货时，能否提前通知并给替代品。

4. **品质与损耗**
   - 是否支持看样、试供、首批小单测试。
   - 坏果、压伤、规格不符怎么赔补：补货、退款还是下次抵扣。
   - 损耗率大概多少，是否有售后时限，比如到货2小时内反馈。

5. **价格与结算**
   - 报价是否含税、含运费、含包装。
   - 价格随行就市时，是否提前报备调价。
   - 结算是日结、周结还是月结，能否对公/对私灵活处理。

6. **品类匹配度**
   - 是否覆盖你社区客群常买的水果：苹果、香蕉、橙子、梨、葡萄、西瓜、时令爆品等。
   - 能否按你的要求做分级：普通果、精品果、促销果。
   - 包装规格是否适合社区店陈列和家庭购买。

7. **资质与安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 水果农残检测、进货凭证能否提供。
   - 冷链水果如蓝莓、草莓、车厘子是否有冷藏配送能力。

8. **合作灵活性**
   - 是否要求签长期独家协议。
   - 退换货门槛高不高。
   - 能否先试合作1—2周再定长期。

实际筛选时，可以这样做：

- 先找3—5家本地批发市场档口、产地直供商、生鲜配送平台比价。
- 每家先下小单测试3—7天，重点记录：到货时间、坏果率、补货速度、价格波动。
- 优先选“每天能送、起送低、售后快、品类稳”的，而不是单纯报价最低的。
- 合同或口头约定要写清：配送时间、起送量、损耗赔付、调价机制、结算周期。

一句话：社区超市选每日水果供应商，核心不是找最便宜的，而是找**每天送得稳、坏果赔得快、起送门槛低、品类适合社区客群**的。
