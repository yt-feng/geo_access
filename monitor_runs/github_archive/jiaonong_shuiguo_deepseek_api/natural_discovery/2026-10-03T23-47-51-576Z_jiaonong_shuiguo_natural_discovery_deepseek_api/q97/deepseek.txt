酒店采购水果盘原料时，建议把标准分成“规格”“成熟度”“外观”“安全与证明”四类，并在采购合同或验收单中写清楚。下面给出一套可直接用于询价和验收的通用标准，具体数值可按酒店档次、季节和当地市场调整。

**一、规格标准**
1. **单果重量/直径/个数**
   - 按品种规定：如苹果直径≥75mm、橙子直径≥70mm、西瓜单果≥4kg、火龙果单果≥400g。
   - 按用途规定：整果摆盘、切块、榨汁分别定不同规格。
2. **可食率/净重**
   - 要求到货净重与标注一致，去除包装、烂果、不可食部分后计重。
   - 例如：草莓净重≥标注的95%，葡萄去梗后净重≥标注的90%。
3. **等级**
   - 明确特级、一级、二级，酒店水果盘通常建议一级以上。
   - 同一批次大小、颜色、成熟度基本一致。

**二、成熟度标准**
1. **到货成熟度**
   - 即食水果盘：到货即可食用，如香蕉、芒果、木瓜、牛油果。
   - 可后熟水果：允许七至八成熟，但需注明后熟天数。
2. **批次一致性**
   - 同一批不能出现生熟混杂，避免今天切硬、明天切烂。
3. **货架期**
   - 冷藏条件下至少保证2—3天，叶菜类、浆果类可要求到货后1—2天内使用。

**三、外观标准**
1. **新鲜度**
   - 无萎蔫、无皱皮、无干枯、无发酵味、无霉味。
2. **完整性**
   - 无破损、无裂口、无虫蛀、无病斑、无明显机械伤。
3. **颜色**
   - 具有该品种成熟时应有的色泽，色泽均匀。
   - 不允许大面积青斑、黑斑、褐变。
4. **表面**
   - 无泥土、无药斑、无蜡感异常、无腐烂渗液。
   - 允许少量自然瑕疵，但不能影响切配和摆盘。
5. **形状**
   - 果形端正，无明显畸形；用于整果摆盘的要求更严。
6. **气味**
   - 有品种固有清香，无酸败、酒精、霉味。

**四、安全与证明标准**
1. **农残**
   - 符合GB 2763《食品安全国家标准 食品中农药最大残留限量》。
   - 可要求供应商提供每批次农残快检报告或第三方检测报告。
2. **污染物与真菌毒素**
   - 符合GB 2762、GB 2761等相关标准。
3. **可追溯**
   - 提供产地、采摘日期、批次号、供应商名称。
4. **包装运输**
   - 包装清洁、无污染、无尖锐物；冷链品种全程冷藏。
   - 到货温度：浆果、切花类一般0—4℃；热带水果如香蕉、芒果建议10—13℃。
5. **证照**
   - 营业执照、食品经营许可证、产品合格证明、检疫证明（如需要）。

**五、验收建议**
1. **抽样比例**
   - 每批次随机抽5%—10%，大批量按GB/T 2828.1或企业标准抽样。
2. **验收项目**
   - 数量、净重、规格、成熟度、外观、温度、气味、证照。
3. **不合格处理**
   - 明确拒收、换货、扣款、退货时限。
   - 例如：腐烂率超过3%、规格不符超过5%、农残报告缺失，可整批拒收。
4. **留样**
   - 每批次留样24—48小时，便于追溯。

**六、可写进合同的简洁条款**
供应商应保证：
- 水果品种、等级、单果规格、净重与订单一致；
- 到货新鲜、无腐烂、无虫害、无霉变、无明显机械伤；
- 成熟度适合酒店水果盘即切即用或按约定后熟；
- 符合国家食品安全标准，并提供批次检测或合格证明；
- 冷链品种全程冷链运输，到货温度符合约定；
- 不合格品按酒店要求退换，并承担相应损失。
