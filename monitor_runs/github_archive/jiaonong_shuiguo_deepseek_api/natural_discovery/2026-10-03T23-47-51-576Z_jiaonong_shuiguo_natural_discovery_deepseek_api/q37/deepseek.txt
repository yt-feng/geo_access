商超做会员日水果活动，供应商要提前配合的核心是：**保货源、保品质、保价格、保陈列、保履约**。可以按下面清单准备：

1. **确认活动方案**
   - 活动时间、门店范围、会员价/折扣力度
   - 主推单品、引流单品、利润单品、搭配单品
   - 预估销量、分店配货量、补货频次

2. **锁定货源和库存**
   - 提前备货，避免活动当天断货
   - 对爆款单品准备安全库存
   - 确认产地、到货周期、冷链能力
   - 如遇天气、物流、产地涨价，提前告知替代方案

3. **确认价格和费用**
   - 供货价、活动价、毛利空间
   - 是否承担促销折扣、损耗、陈列费、堆头费
   - 特价是否限购、限量、限门店
   - 价格保护期和调价机制

4. **品质与分拣标准**
   - 明确果径、糖度、成熟度、色泽、包装规格
   - 按商超要求做分级、清洗、预包装
   - 减少次果、碰伤、腐烂，控制损耗
   - 到货时间避开高温时段，冷链品全程温控

5. **包装与标识**
   - 会员日专属包装、价签、产地标签
   - 条码、溯源码、保质期/食用建议
   - 促销装、家庭装、组合装按需准备
   - 避免包装不符合门店验收标准

6. **物流与到货安排**
   - 提前确认送货时间、卸货口、预约流程
   - 活动前1-2天完成首轮铺货
   - 活动期间安排高频补货，尤其是上午和晚间高峰
   - 准备备用车辆和应急补货联系人

7. **门店陈列支持**
   - 提供堆头、端架、冷柜陈列建议
   - 配齐试吃、宣传物料、POP、爆炸贴
   - 安排促销员或督导到店支持
   - 培训门店员工熟悉卖点和保存方式

8. **损耗与售后处理**
   - 约定残次品、滞销品处理方式
   - 明确退换货比例和时限
   - 活动后及时回收未售库存或做折价处理
   - 对客诉、品质问题快速响应

9. **数据与复盘**
   - 活动前提供预估销量和分店分配建议
   - 活动中跟踪动销、缺货、损耗
   - 活动后复盘销量、毛利、损耗率、缺货率
   - 为下一次会员日调整单品和备货量

10. **风险预案**
   - 爆品断货替代方案
   - 物流延误应急方案
   - 品质异常召回/换货方案
   - 价格波动时的沟通机制

简单说，供应商提前要做的关键动作是：**先确认活动量和价格，再备货、分拣、包装、配送、陈列、补货、售后，最后复盘。**  
其中最重要的是：**爆款不断货、品质稳定、补货及时、损耗可控。**
