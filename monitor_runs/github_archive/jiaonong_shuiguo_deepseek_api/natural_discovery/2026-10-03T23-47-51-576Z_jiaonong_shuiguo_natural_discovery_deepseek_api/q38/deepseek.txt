大型超市对水果供应商的要求，核心是两条：**食品安全合规能力**，以及**稳定的冷链与履约能力**。具体通常包括以下几类能力。

**一、食品安全能力**

1. **资质与合规**
- 营业执照、食品经营许可证/食品生产许可证（视加工情况）
- 若涉及进口水果，需有入境货物检验检疫证明、报关单等
- 产品检测报告，重点包括农残、重金属、霉菌毒素等
- 符合GB 2763等食品安全国家标准

2. **源头与过程控制**
- 自有基地或稳定合作基地，能提供产地证明和种植管理记录
- 农业投入品管理：农药、化肥使用记录，安全间隔期控制
- 采收、分级、包装环节的卫生控制
- 建立批次追溯体系，做到来源可查、去向可追

3. **检测与验收**
- 具备自检能力或委托第三方检测
- 到货按超市标准验收：农残快检、外观、成熟度、糖度、单果重、瑕疵率等
- 不合格品隔离、退货、召回机制

4. **仓储与包装安全**
- 仓库防鼠、防虫、防潮、防交叉污染
- 包装材料符合食品接触材料标准
- 预包装产品标签合规：品名、产地、等级、净含量、生产日期、保质期、贮存条件等

5. **人员与制度**
- 从业人员健康证、食品安全培训
- HACCP、ISO 22000、GAP等体系认证通常是加分项，大型超市往往优先选择
- 食品安全事故应急预案和召回演练记录

**二、物流与履约能力**

1. **冷链能力**
- 采后预冷：尽快去除田间热
- 冷藏/保鲜运输：按品类控制温湿度，如叶菜、浆果、热带水果要求不同
- 冷库分拣、暂存、周转
- 全程温度记录和异常报警

2. **仓储与分拣**
- 具备与超市订单量匹配的仓库和分拣能力
- 支持按门店、按SKU、按批次分拣
- 先进先出/先熟先出，控制损耗和临期

3. **运输与配送**
- 自有或稳定合作冷链车队
- 能覆盖超市DC（配送中心）或门店，按时送达
- 具备旺季、节假日、促销期增量履约能力
- 配送频次稳定，支持日配、隔日配等模式

4. **信息化与追溯**
- 订单、库存、批次、温度数据可记录
- 能与超市系统对接，如EDI、WMS、TMS
- 出现质量问题时能快速定位批次并召回

5. **损耗与应急管理**
- 有水果损耗控制方案：分级、包装、温控、周转
- 缺货、延迟、质量异常的替代和补货机制
- 自然灾害、疫情、交通管制等情况下的应急预案

**三、大型超市通常还会重点看的能力**

- **规模化稳定供应**：不是一次能供，而是全年稳定供
- **标准化分级**：大小、色泽、糖度、成熟度符合超市商品标准
- **成本与账期承受力**：能接受账期、返利、促销支持等条件
- **售后与赔付**：质量问题的退换货、扣款、赔偿机制清晰
- **可持续发展**：环保包装、减少浪费、社会责任等越来越多被纳入考核

**简单判断标准：**
如果一家水果供应商能做到：**资质齐全、批次可追溯、农残可控、全程冷链、按时履约、异常可召回**，基本就具备进入大型超市供应链的基础条件。若还能提供体系认证、规模化基地和系统对接能力，竞争力会明显更强。
