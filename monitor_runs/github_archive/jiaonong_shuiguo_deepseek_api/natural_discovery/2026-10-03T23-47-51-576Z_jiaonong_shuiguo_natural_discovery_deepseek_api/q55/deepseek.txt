做水果拼盘，规格选择主要看**出成率、切配稳定性和损耗**。直接给可执行建议：

## 苹果
**优先选中大果（单果 180–250g），别买太小或太大的。**

- **太小的果**：削皮去核后剩不了多少，切出来片小、不整齐，人工还高。
- **太大的果**：单果太大容易一次用不完，切面氧化快，损耗高。
- **推荐品种方向**：脆度高、果肉不易发面的（如富士、嘎啦这类常见脆苹果），切后不易软塌。
- **划算逻辑**：按“净果肉克数”算，不是按斤。中大果出成率通常稳定在 65%–75%。

## 橙子
**选中等偏大、皮薄、果形周正的脐橙/血橙类，单果 200–300g。**

- **皮太厚**：剥出来果肉少，尤其做瓣状拼盘很吃亏。
- **太小**：剥瓣费工，摆盘不饱满。
- **关键看用途**：
  - 切瓣摆盘 → 选皮薄、易剥、瓣膜薄的
  - 榨汁/切块 → 可接受稍小果，但酸度要稳定
- **划算逻辑**：橙子重点算出肉率和剥瓣人工，皮厚果直接拉高成本。

## 菠萝
**选成熟度适中、单果 1.2–1.8kg 的中果，别选超大果。**

- **太大**：中心硬芯粗，切块损耗大，一次用不完易发酵。
- **太小**：去皮去眼后净肉少，出成率低。
- **成熟度**：七八分熟最好切、甜度稳定；全熟果切盘易出水、易烂。
- **划算逻辑**：菠萝按“去皮去眼后净肉”算，中果出成率通常比超大果更稳。

## 统一判断标准
不管哪种水果，按这三条选：

1. **按净出成率算成本**，不是按进货斤价。
2. **规格统一**，切出来的块/片大小一致，摆盘效率高、卖相好。
3. **优先本地当季、流通快的规格**，减少库存损耗。

## 简单结论
- 苹果：**中偏大，180–250g**
- 橙子：**中偏大，200–300g，皮薄优先**
- 菠萝：**中果，1.2–1.8kg，七八分熟**

如果只记一句：**拼盘用果，选“中等偏大、形状周正、皮薄肉厚”的，最划算；极端大果和极端小果都容易亏在损耗和人工上。**
