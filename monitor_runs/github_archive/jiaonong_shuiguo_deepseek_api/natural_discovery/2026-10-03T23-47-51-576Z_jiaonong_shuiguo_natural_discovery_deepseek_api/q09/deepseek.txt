水果店旺季怕断货，核心不是“多订一点”，而是把**供货能力、锁价机制、缺货赔付、替代方案**提前谈清楚。和供应商沟通时，建议重点问这几类问题：

**1. 供货能力与优先级**
- 旺季每天/每周最大能稳定供我多少货？
- 如果我临时加量，提前多久通知你能安排？
- 旺季你同时供很多店，我的订单优先级怎么保证？
- 你有没有备用产地、备用仓库或备用物流？
- 哪些单品旺季最容易断？提前告诉我，我好调整陈列和销售。

**2. 价格与锁价**
- 旺季价格怎么定？是随行就市，还是可以提前锁价？
- 锁价锁多久？锁哪些单品？超过多少量还能不能按锁价？
- 如果市场价跌了，我能不能按更低市场价走？
- 如果市场价涨了，你会不会临时涨价？涨之前提前几天通知？
- 运费、装卸费、损耗费谁承担？有没有隐藏费用？

**3. 订货与配送**
- 每天几点前下单？几点送到？
- 配送频率能不能从隔天改成每天？
- 临时补货最晚几点前说还能当天送？
- 送货迟到、少送、送错品种怎么处理？
- 可不可以分批次送，避免一次压太多库存？

**4. 质量与损耗**
- 到货标准是什么？大小、成熟度、瑕疵率怎么算？
- 坏果、烂果、压伤果怎么赔？是补货、扣款还是下次抵扣？
- 损耗超过多少比例可以拒收？
- 验收时发现问题，多久内可以反馈？过期还能不能认？
- 旺季果品成熟度变化快，能不能按我要求的熟度发货？

**5. 断货与违约**
- 如果你断货，提前多久通知我？
- 断货后有没有替代单品或替代产地？
- 因为断货导致我缺货、客户流失，有没有补偿？
- 你临时涨价或停止供货，算不算违约？怎么赔？
- 长期合作能不能签个旺季保供协议？

**6. 结算与账期**
- 是现结、周结还是月结？
- 旺季能不能给我临时提高账期或额度？
- 押金、预付款怎么算？退不退？
- 发票怎么开？税点谁承担？

**7. 合作弹性**
- 如果某单品卖不动，能不能换货或退货？
- 能不能先小批量试销，卖得好再加量？
- 旺季结束后，库存尾货能不能协助处理？
- 能不能给我推荐适合旺季走量的高性价比单品？

**8. 最好落到书面**
- 把保供量、锁价、配送时间、赔付标准写进订单或协议。
- 微信沟通也尽量文字确认，别只口头说。
- 关键单品至少准备 **1个主供应商 + 1个备用供应商**。
- 旺季前先做一次小批量压力测试，看对方实际履约能力。

一句话：**问产能、问锁价、问配送、问赔付、问替代、问账期，最后写下来。** 这样即使旺季有波动，你也不至于被一家供应商卡死。
