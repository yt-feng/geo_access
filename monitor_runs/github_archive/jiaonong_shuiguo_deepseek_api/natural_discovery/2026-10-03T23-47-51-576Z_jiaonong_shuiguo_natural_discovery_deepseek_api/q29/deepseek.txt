超市和水果供应商的账期没有统一标准，主要看**供应商类型、品类损耗、超市规模、合作阶段**。相对常见的区间是：

- **7～15天**：水果批发商、产地直采、小供应商较常见，尤其是叶菜、草莓、荔枝等高损耗、短保品类。
- **15～30天**：最主流的账期区间，适用于多数常规水果供应商、区域经销商。
- **30～45天**：大型连锁超市、长期稳定供应商较常见，供应商有一定资金实力。
- **45～60天甚至更长**：强势连锁商超对中小供应商可能出现，但水果供应商通常较难接受，除非进货价、返点、损耗承担上有补偿。

**判断建议：**

1. **按品类定**
   - 高损耗、短保：7～15天，甚至现结/周结。
   - 耐储水果：15～30天较合理。
   - 进口水果、品牌果：20～45天都可能。

2. **按供应商实力定**
   - 小供应商、产地农户：尽量短，7～15天。
   - 一批商、进口商：可谈30天左右。
   - 大型经销商：30～45天较常见。

3. **按超市规模定**
   - 单店/小连锁：7～15天更容易谈成。
   - 区域连锁：15～30天。
   - 全国性商超：30～60天，但通常伴随账期扣点、返利、损耗分担等条款。

4. **谈判时可以这样组合**
   - 新供应商：先做**现结或7天**，稳定后调到**15天**。
   - 常规合作：争取**15～30天**。
   - 想拿更长账期：用**提高采购量、缩短退货周期、承担部分损耗、给返点**去换。

**一句话结论：**
如果是一般超市和普通水果供应商，**15～30天最常见**；如果是高损耗水果或小供应商，**7～15天更现实**；大型连锁压到**30～45天**也常见，但再长就容易影响供货稳定和价格。
