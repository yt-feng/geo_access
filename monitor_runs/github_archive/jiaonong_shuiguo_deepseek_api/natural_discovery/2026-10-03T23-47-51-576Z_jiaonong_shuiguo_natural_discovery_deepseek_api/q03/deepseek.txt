夫妻店第一次找水果供货商，试单的核心目标是：**用最小成本验证供货商是否靠谱**，而不是一上来就压价或大量进货。下面按品类给你具体做法。

## 一、先明确试单要验证什么

1. **品质稳定性**：同一批货里大小、成熟度是否均匀
2. **损耗率**：到手坏果、压伤、发霉比例
3. **账期与结算**：现结还是周结、是否收押金
4. **配送时效**：说几点到就几点到，缺货是否提前说
5. **售后态度**：坏果认不认、补不补

## 二、三个品类的试单逻辑不同

**香蕉**
- 最考验供货商，因为催熟程度直接决定你能不能卖。
- 第一次只要**1箱或半箱**，指定“青转黄”状态，别要全黄。
- 到货后记录：几天转黄、有没有黑斑、催熟是否均匀。
- 重点问：是不是自己催熟，还是从批发市场倒手。倒手的通常不稳定。

**苹果**
- 相对耐放，适合看**分级和箱规**。
- 试单要**整箱**，当场开箱抽查底层（底层常放小果、次果）。
- 看：果径是否一致、有没有磕碰、箱底是否垫纸增重。
- 问清产地和品种，别只要“红富士”三个字。

**橙子**
- 重点看**新鲜度和水分**，以及是否打蜡。
- 试单1箱，切开2-3个看瓤、尝甜度。
- 看果蒂是否发干、表皮是否发皱，判断存放时间。
- 问清是当季鲜果还是冷库货。

## 三、试单操作步骤

1. **同时找2-3家**供货商，每家下小单，别只试一家。
2. 每单金额控制在**200-500元**，够你观察一周。
3. 收货时**当场验货拍照**，坏果单独称重记录。
4. 记录一张简单表格：到货时间、损耗率、售价、几天卖完。
5. 观察一周后再决定是否转为主供。

## 四、第一次谈的时候必须问清的问题

- 起送量多少？低于起送量怎么算？
- 送货费、搬运费谁出？
- 坏果怎么赔？按比例还是下次抵扣？
- 价格随行就市还是锁价？多久调一次？
- 能不能看样品再下单？
- 旺季缺货时优先保谁？

## 五、判断要不要继续合作的硬标准

- 损耗率：香蕉超过10%、苹果橙子超过5%，先别长期合作。
- 售后：第一次出问题就推诿的，直接换。
- 账期：小店现金流紧，能谈到周结最好，别被要求大额押金。
- 配送：连续两次迟到或缺货不提前通知，换。

## 六、给你的实操建议

第一家供货商不要给独家，**保持两家轮换**，既防断货，也有议价空间。试单期用现金现结，别急着谈账期，先看货稳不稳。等你摸清哪家香蕉催得好、哪家苹果分级实，再逐步把量集中过去。

一句话：**小单多试、当场验货、记录损耗、一周复盘**，比听供货商怎么吹都管用。
