会，而且通常**起订量越高，损耗风险越大**，但关键不只看总量，还要看下面几个条件。

**1. 香蕉和菠萝都属于高损耗风险品**
- **香蕉**：后熟快，怕压、怕冷、怕乙烯积聚，成熟后销售窗口短。起订量太大，容易出现“前一批还没卖完，后一批已经熟过头”。
- **菠萝**：相对耐放，但怕低温冷害、怕堆压，整果损耗常来自黑心、腐烂、磕碰。起订量高会拉长库存时间，增加腐损概率。

**2. 起订量高会不会增加损耗，主要看这几个变量**
- **日销量是否稳定**：如果日均销量稳定且能覆盖起订量，风险可控；如果波动大，高起订量会直接变成库存压力。
- **补货周期**：补货越慢，单次起订量越高，库存天数越长，损耗越高。
- **仓储条件**：香蕉需要通风、适温、分熟度管理；菠萝需要避冷害、防堆压。条件差时，高起订量会放大问题。
- **成熟度**：香蕉如果是青果，可缓冲几天；如果是黄熟果，起订量高几乎必然增加损耗。
- **渠道消化能力**：有没有促销、加工、团购、果汁/烘焙等兜底渠道。没有兜底渠道，损耗更明显。

**3. 简单判断方法**
可以用一个粗算：
- **安全库存天数 = 起订量 ÷ 日均销量**
- 香蕉一般建议库存天数尽量短，通常**1—3天**更安全，具体看成熟度和季节。
- 菠萝可略长，但也不建议盲目超过**3—7天**，尤其夏季或仓储一般时。

如果算出来：
- **≤2天**：损耗风险通常较低。
- **3—5天**：要盯紧成熟度和动销。
- **>5—7天**：香蕉风险很高，菠萝也要警惕。

**4. 降低损耗的可执行做法**
- **拆单/混拼**：和供应商谈小批量、多频次，或香蕉菠萝混拼降低单品起订压力。
- **分批次到货**：不要一次全到，按成熟度分批。
- **先进先出**：按到货时间和熟度严格管理。
- **催熟分级**：香蕉按青、微黄、黄熟分开存放和销售。
- **设置止损线**：比如香蕉到某成熟度就转促销、加工或员工内购。
- **用数据定起订量**：按过去2—4周日均销量和波动来倒推，而不是只看供应商要求。

**结论**：起订量太高**大概率会增加香蕉和菠萝的损耗风险**，尤其是香蕉。真正决定风险的是“起订量对应多少天库存”和“有没有能力在成熟窗口内卖掉”。如果库存天数超过3—5天，又没有促销或加工兜底，就不建议接受太高起订量。
