判断水果供应商靠不靠谱，核心不是听他怎么说，而是用“小批量试单 + 固定标准验收 + 连续几次复盘”来验证。香蕉和菠萝都是后熟型水果，供应商的靠谱程度主要体现在成熟度控制、损耗承担、补货稳定性和售后态度上。

你可以按下面这套方法判断。

**1. 先小批量试单，不要一上来长期大采购**
- 第一次只进你正常量的一部分，比如香蕉 3～5 箱、菠萝 10～20 个。
- 连续试 2～3 次，看每次到货质量是否稳定，而不是只看一次好不好。
- 试单时故意观察：迟到怎么办、坏果多怎么办、规格不对怎么办。

**2. 看香蕉的关键指标**
- 到货成熟度：你要根据卖货速度选。当天卖得快，可以要稍黄一点；要放几天，就要偏青、硬身、无黑斑。
- 颜色是否均匀：一箱里如果青黄差异太大，说明分拣或催熟不稳定。
- 蕉指饱满度：太瘦、太细、空心的，卖相差。
- 有没有药水味、酸味、酒味：有酒味说明已经过熟或存放不当。
- 果柄和切口：发黑、霉变、腐烂的要挑出来，说明冷链或存放有问题。
- 损耗承诺：香蕉容易在运输和催熟中出问题，靠谱供应商一般愿意对严重坏果、烂柄、霉变做补货或扣款。

**3. 看菠萝的关键指标**
- 成熟度：你要的是“能放几天再卖”还是“到店就能卖”。太青的菠萝酸、难卖；太熟的容易烂。
- 果眼和表皮：果眼浅、表皮新鲜、无大面积软塌和霉斑。
- 底部和冠芽：底部发黑、发软、有汁液，通常内部已坏或存放太久。
- 重量感：同样大小，手感沉的通常水分足；轻飘飘的可能失水或空心。
- 香味：有自然果香可以，但酒精味、酸腐味说明过熟。
- 规格一致性：大小、成熟度是否统一，直接影响你定价和陈列。

**4. 看供应商本身的可靠性**
- 能不能稳定供货：连续几次都能按约定时间、数量、规格到货。
- 价格是否透明：是否随行就市，还是看人报价；有没有临时加价、以次充好。
- 是否愿意让你验货：靠谱的通常不怕你开箱、抽检、拍照。
- 售后是否明确：坏果怎么算、多久内反馈、补货还是退款、运费谁承担。
- 有没有固定产地或合作果园：能说清货源、季节、品种和催熟方式的，通常比“什么都有、什么都能低价”的更稳。
- 同行口碑：问附近水果店、批发市场熟人，重点问“坏果多不多、售后拖不拖”。

**5. 用几次交易做判断**
可以给供应商打分，连续 3 次后基本能看出来：

- 到货准时率
- 规格符合率
- 坏果率
- 成熟度稳定性
- 售后响应速度
- 补货或退款是否爽快
- 价格是否稳定合理

如果连续 3 次里，有 2 次出现明显坏果多、成熟度失控、售后推诿，就不适合长期合作。哪怕价格便宜，也会被损耗吃掉利润。

**6. 长期合作要提前谈清楚**
- 香蕉：品种、每箱重量、每根大概几指、催熟程度、到货颜色、坏果赔付标准。
- 菠萝：品种、单果重量范围、成熟度、是否带冠芽、黑心烂心怎么赔。
- 账期和结算：现结、周结还是月结，别只靠口头。
- 退换货：拍照留证，规定几小时内反馈有效。
- 备用供应商：至少留 1～2 家备选，防止一家断供或质量下滑。

**简单判断口诀：**
香蕉看“颜色匀、蕉指饱、柄不烂、成熟稳”；菠萝看“果眼浅、底部好、手感沉、无酒味”。供应商看“连续三次稳定、坏果敢赔、售后不拖、价格不乱”。

最稳的做法是：先试单，再小批量连续合作，最后再谈长期账期和固定供货。不要因为单价低就长期绑定，水果店真正怕的是损耗和断货。
