如果每天只要少量水果，最省心的思路不是找“最便宜的大批发商”，而是找**能稳定小批量配送、少起送、售后简单**的本地供应商。可以按下面优先级选：

1. **本地生鲜配送平台/食材供应链平台**
   - 比如本地的餐饮供应链、生鲜B2B平台、社区团购批发平台。
   - 优点：手机下单，次日或当日送，有起送门槛但比大批发市场灵活。
   - 适合：每天几斤到几十斤，品类固定。
   - 注意：看清起送价、配送费、缺货替换规则。

2. **附近水果店/精品水果店**
   - 直接谈长期供货，每天按菜单送。
   - 优点：距离近、反应快、量少也愿意送，临时加单方便。
   - 适合：用量小、要求新鲜、希望随叫随到。
   - 谈法：按月结或周结，约定每天几点前送到、坏果怎么补。

3. **农贸市场固定摊位**
   - 找一个摊位长期合作，不要每天临时买。
   - 优点：价格通常比水果店低，能挑货。
   - 缺点：需要自己或店员去取，配送不稳定。
   - 适合：店离市场近，员工顺路能拿。

4. **本地果园/种植户直供**
   - 适合单一品类用量稳定，比如每天要西瓜、圣女果、柠檬。
   - 优点：新鲜、价格可能好。
   - 缺点：品类少，季节性明显，配送不一定省心。
   - 适合：作为补充供应商，而不是唯一供应商。

5. **批发市场小批量代采**
   - 如果本地有批发市场，可以找市场里的小档口谈“每天小批量配送到店”。
   - 优点：品类全、价格低。
   - 缺点：起送量可能高，凌晨交易，售后麻烦。
   - 适合：附近有市场，且能找到愿意跑腿配送的档口。

**最省心的组合建议：**
- 主供应商：本地水果店或生鲜配送平台，负责每天稳定送。
- 备用供应商：农贸市场固定摊位或另一家水果店，防止缺货。
- 少量应急：附近水果店临时补。

**选供应商时重点问清 6 件事：**
1. 最低起送量是多少？
2. 每天几点前下单、几点送到？
3. 配送费怎么算？
4. 缺货时是否提前说，能否替换？
5. 坏果、烂果怎么赔或补？
6. 结账周期：现结、周结还是月结？

**不太建议：**
- 只找一家大批发商：量小可能不重视你。
- 每天临时去市场买：最耗人工，价格也不稳定。
- 只看单价最低：小批量配送费和损耗会把便宜吃掉。

简单说：**用量小就找附近水果店或本地生鲜配送平台做长期固定配送，再留一个农贸市场摊位备用，最省心。**
