小店做水果，核心不是“品类齐全”，而是**少量、高频、快周转**。建议按下面这套逻辑控制：

## 一、先定品类结构：只做“便利店场景”的水果

**优先保留 3 类：**
1. **即食型**：香蕉、苹果、橙子、圣女果、提子、蓝莓盒装
2. **小份装**：切好的果切、单颗苹果/橙子、小盒蓝莓
3. **高频刚需**：香蕉、苹果、橙子、梨

**谨慎或不做：**
- 大西瓜、整箱芒果、榴莲、菠萝蜜等大体积/高损耗品
- 需要催熟、易压伤、保质期极短的水果
- 客单价高但周转慢的进口小众水果

**品类数量建议：**
- 20㎡以下：5～8个SKU
- 20～50㎡：8～12个SKU
- 每个品类只留1～2个规格，不要同品多规格

## 二、采购量：按“日销”倒推，不按感觉补货

**核心公式：**
> 采购量 = 预估日销 × 覆盖天数 ×（1 + 安全系数） - 现有库存

- 覆盖天数：1～2天，最多3天
- 安全系数：10%～20%
- 新品首次采购：只进最小包装，卖3天再决定是否保留

**举例：**
香蕉日销约15份，现有库存5份，覆盖2天：
采购量 = 15×2×1.1 - 5 ≈ 28份
宁可少进，卖断也比烂掉强。

## 三、损耗控制：从进货到陈列全链路

**1. 采购端**
- 固定1～2个稳定供应商，要求小批量、多频次配送
- 明确验收标准：成熟度、伤果率、大小均匀度
- 伤果、过熟果当场拒收或折价

**2. 库存端**
- 先进先出，新货放里面，旧货放前面
- 香蕉、芒果等热带水果不要冷藏；苹果、梨、提子可冷藏
- 果切必须冷藏，当天未售完及时处理

**3. 陈列端**
- 小堆头、浅陈列，不要堆太满
- 每2～3小时挑一次伤果、软果
- 设“临期折扣区”，轻微瑕疵果及时打折，不要等烂掉

**4. 销售端**
- 推果切、小份装，降低整颗卖不掉的风险
- 搭配酸奶、沙拉、早餐场景做组合
- 高峰期前补货，低峰期不大量上架

## 四、用数据做淘汰，不靠感觉

每天记录：
- 每个SKU的进货量、销量、损耗量、损耗金额
- 连续3天销量低于进货量50%的，直接淘汰
- 损耗率超过10%的品类，先减量，再考虑下架

**健康指标参考：**
- 综合损耗率：控制在5%～8%
- 单品类损耗率：香蕉、提子等易损品可放宽到10%
- 果切损耗：尽量控制在5%以内

## 五、最实用的执行原则

1. **少进勤补**：每天或隔天补，不囤货
2. **只做小份**：小盒、小袋、单颗卖
3. **快进快出**：3天卖不动的品直接换
4. **动态淘汰**：每周复盘一次，砍掉尾部SKU
5. **损耗前置**：验收、冷藏、挑拣、折扣，四个动作不能省

一句话：**便利店水果不是比谁品类多，而是比谁周转快、损耗低。** 先做少而精，再根据真实销量慢慢加品。
