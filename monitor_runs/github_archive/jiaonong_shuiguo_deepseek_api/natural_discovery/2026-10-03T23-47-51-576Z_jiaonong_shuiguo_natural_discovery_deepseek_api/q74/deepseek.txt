批发档口拓展餐饮客户，菠萝和香蕉的规格要按**餐饮用途倒推**，而不是按零售喜好准备。下面给你一套可直接落地的规格建议。

## 一、菠萝：餐饮客户主要分三类用途

### 1. 饮品/甜品店（茶饮、糖水、烘焙）
- **主推规格**：
  - 去皮菠萝整果：单果 1.0–1.5kg，成熟度 7–8 成，当天或次日可用
  - 菠萝块/菠萝丁：1–1.5cm 方丁，真空袋或保鲜盒装，2.5kg/袋、5kg/袋
  - 菠萝片：0.8–1cm 厚圆片，适合装饰、烘焙、汉堡
- **关键要求**：糖度稳定、酸度别太高、无黑心、无酒精味。
- **建议备货比例**：整果 40%，切块/切丁 40%，切片 20%。

### 2. 中餐/火锅/烧烤店
- **主推规格**：
  - 去皮整果：1.2–1.8kg，成熟度 6–7 成，耐放
  - 半成品菠萝块：3–5cm 块，适合炒饭、咕咾肉、烤串
  - 菠萝盅：小果 0.8–1.2kg，专门做菠萝饭
- **关键要求**：出肉率高、果眼浅、削皮损耗低。
- **建议备货比例**：整果 60%，半成品块 30%，菠萝盅 10%。

### 3. 团餐/食堂
- **主推规格**：
  - 大果统货：1.5–2.0kg，按箱走，价格敏感
  - 去皮切块：5kg/袋，冷冻或冷藏，方便大锅菜
- **关键要求**：便宜、稳定、耐储存，对品相要求低。


## 二、香蕉：餐饮客户主要看成熟度和单根规格

### 1. 饮品/甜品/烘焙
- **主推规格**：
  - 单根 120–150g，长度 18–22cm
  - 成熟度：到店 6–7 成，2–3 天转黄可用
  - 冷冻香蕉泥：1kg/袋、5kg/袋，做奶昔、烘焙
- **关键要求**：香气足、无青涩味、无大面积黑斑。
- **建议备货比例**：生蕉 50%，熟蕉 30%，香蕉泥 20%。

### 2. 早餐店/快餐店/食堂
- **主推规格**：
  - 单根 100–130g，长度 15–18cm
  - 成熟度：到店 7–8 成，可直接吃或当天用
  - 按把/按箱：5–8 根/把，或 10kg/箱
- **关键要求**：大小均匀、表皮干净、耐搬运。
- **建议备货比例**：熟蕉 70%，生蕉 30%。

### 3. 火锅/烧烤/自助餐
- **主推规格**：
  - 单根 100–120g，小果更好，摆盘不浪费
  - 成熟度：7 成，耐放 2–3 天
  - 可提供冷冻香蕉段：3–4cm 段，5kg/袋
- **关键要求**：整齐、无伤、无药水味。


## 三、给档口的实操建议

1. **先问用途，再报规格**
   餐饮客户最怕“今天来的货和昨天不一样”。你先问清楚：做饮品、炒菜、烘焙还是直接吃。

2. **菠萝主推三个SKU**
   - 去皮整果 1.2–1.5kg
   - 菠萝丁 1cm / 3cm 两档
   - 菠萝盅 0.8–1.2kg

3. **香蕉主推三个SKU**
   - 生蕉 6–7 成，单根 120–150g
   - 熟蕉 7–8 成，单根 100–130g
   - 冷冻香蕉泥/段

4. **报价按“可用部分”算**
   餐饮客户更关心出肉率、损耗率、每份成本。比如菠萝去皮后出肉率 50–60%，你要按净重报，不然客户觉得贵。

5. **先小批量试单**
   每个规格先备 1–2 箱，让客户试用 3–5 天。稳定后再放量，避免压货。

6. **建立固定标准**
   比如：菠萝单果重 ±10%、糖度 12–14°、香蕉单根重 ±10%、成熟度按天数标注。餐饮客户一旦认可，复购率会很高。
