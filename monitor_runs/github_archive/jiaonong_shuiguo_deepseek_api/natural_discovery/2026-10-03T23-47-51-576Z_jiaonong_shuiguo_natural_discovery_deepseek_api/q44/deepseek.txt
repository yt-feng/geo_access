要判断供应商售后是否稳定，不能只听承诺，重点看**合同条款 + 历史记录 + 实测响应**三方面。给你一套可直接执行的判断方法：

## 一、先看合同和制度，不靠口头承诺

1. **售后条款是否写进合同**
   - 明确响应时限：如“2小时内响应，24小时内给出处理方案”
   - 明确责任划分：到货腐烂、短重、成熟度不符、农残超标分别怎么赔
   - 明确赔付方式：补货、折价、退款、扣款，写清比例和时限
   - 明确对接人：不能只留一个业务员，要有客服/售后专线

2. **看是否有标准售后流程**
   - 有没有报损单、验收单、异常反馈模板
   - 有没有分级处理机制：小问题补货、大问题整批退换
   - 有没有固定售后对接窗口，而不是每次找不同人

> 如果供应商连书面售后条款都不愿写，基本可以判定售后不稳定。

## 二、查历史记录，看真实履约能力

1. **要近3—6个月同类商超客户案例**
   - 重点问：菠萝、香蕉这类易损生鲜的售后频率
   - 看是否有退货单、补货记录、客诉处理记录

2. **看数据指标**
   - 到货合格率
   - 售后响应平均时长
   - 补货/赔付完成率
   - 月度客诉次数

3. **向同行打听**
   - 问其他商超采购：这家供应商出问题后拖不拖、赔不赔
   - 生鲜行业口碑比合同更真实

## 三、小批量实测，直接验证响应

这是最有效的方法：

1. **先下小批量试单**
   - 故意在验收时提出1—2个真实问题：如成熟度不均、轻微压伤、短重
   - 记录对方多久回复、多久给方案、多久执行

2. **看响应动作，不只看态度**
   - 合格：2小时内回复，当天给方案，48小时内补货或赔付
   - 不合格：反复推诿、要求你先卖、拖延到下一批再补

3. **测试非工作时间**
   - 周末或晚上反馈一次问题
   - 看是否有值班机制。生鲜问题往往等不起

## 四、重点看菠萝和香蕉的专项售后

这两种水果售后点不同：

**菠萝**
- 重点：黑心、烂心、成熟度不足、运输冻伤
- 要看供应商是否接受切开抽检后按比例赔付

**香蕉**
- 重点：催熟不一致、青蕉不熟、运输压伤、到货后快速变质
- 要看是否支持“到货后24—48小时内报损”，以及是否配合催熟方案

如果供应商对这两类没有明确售后标准，只笼统说“有问题找我们”，风险很高。

## 五、简单判断标准

满足以下4条以上，可认为售后较稳定：
- 合同写明响应和赔付时限
- 有固定售后对接人和专线
- 能提供近3个月售后记录
- 小批量试单响应及时
- 同行口碑无重大拖欠赔付
- 支持到货后24—48小时报损
- 非工作时间也能联系到人

反之，出现以下情况要警惕：
- 只口头承诺，不写合同
- 出问题让你“先卖卖看”
- 每次对接人都不同
- 补货一拖再拖
- 拒绝小批量试单
- 没有同类商超案例

**最实用的做法：**
先小批量试单，同时把售后条款写进合同，再对比2—3家供应商的实测响应速度。谁在真实出问题后处理快、赔得清，谁才值得长期合作。
