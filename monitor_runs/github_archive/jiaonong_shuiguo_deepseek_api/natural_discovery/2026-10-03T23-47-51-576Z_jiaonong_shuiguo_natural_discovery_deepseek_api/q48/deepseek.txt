判断菠萝供应商能否稳定按规格送货，本质是核查三件事：**有没有稳定货源**、**能不能按你的标准分级**、**履约记录是否可靠**。建议按以下步骤做，每一步都有可判断的依据。

**1. 先把自己的规格定死，再谈稳定**
供应商无法稳定，很多时候是采购方规格模糊。要明确写进合同/订单：
- 品种（如金钻凤梨、巴厘菠萝、台农等）
- 单果重量区间（如1.2–1.5kg/个）
- 成熟度（几成熟采摘，到店后可放几天）
- 糖度下限（用糖度计量，如≥14°Brix）
- 外观（无黑心、裂口、日灼、机械伤比例上限）
- 规格分级方式（按重量、按直径、按箱装个数）
- 包装（箱重、每箱个数、是否带冠芽）
- 到货温度/运输方式（常温还是冷链）
规格越具体，供应商越难糊弄，冲突也越容易判定。

**2. 核查供应商的货源来源**
重点问清楚：
- 是自有种植基地、长期合作果园，还是市场倒货？
- 主产区在哪里，是否依赖单一产区/单一季节？
- 产季之外怎么供？有没有跨产区调配能力（如海南、广东、云南、菲律宾/泰国进口）？
- 是否有分选线、冷库、催熟/控温能力？
只看贸易商或批发市场拿货的，稳定性和规格一致性通常最差。有基地+分选+仓储的，履约能力最强。

**3. 要求提供持续供货证据**
让对方给可验证的材料：
- 近3–6个月的出货记录（给同类连锁客户的送货单/对账单，可打码）
- 分选标准文件、质检记录
- 产地证明、检测报告（农残、重金属）
- 冷库/加工厂照片或实地看
不要只看样品，样品谁都能做好。要看出货的**批次一致性**。

**4. 做小批量试单，测真实履约**
先下2–4周、多批次的试单，重点记录：
- 准时到货率
- 每批规格达标率（抽检重量、糖度、坏果率）
- 批次之间差异大不大
- 出问题时响应和补货速度
连续几批都稳定，才谈长期。

**5. 用条款把稳定性锁住**
合同里写清：
- 规格不达标怎么判、怎么赔、怎么退换
- 准时率/达标率考核（如达标率低于95%扣款或终止）
- 缺货、延迟的违约责任
- 价格调整机制（随行就市还是锁价）
- 是否要求备货或安全库存
- 多供应商备份，避免单点依赖

**6. 判断“能不能稳定”的几个快速信号**
- 敢不敢让你实地看基地/分选线
- 能不能说清产季衔接方案
- 是否只靠一个产区、一个代办
- 报价是否明显低于市场且不愿签规格条款
- 试单时前几批好、后面开始波动
出现后两条，基本可判断不稳定。

**结论**：稳定送货=稳定货源+明确规格+分选能力+履约记录+合同约束。先定标准，再验货源，再用试单和条款验证，不要凭样品和口头承诺下单。
