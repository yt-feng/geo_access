评估这个问题，核心不是“供应商能不能发货”，而是他的仓配网络能不能支撑你不同城市门店的**时效、损耗、成本**三条底线。可以按下面这个框架来判断。

## 一、先明确你的约束条件

评估前先把自己的需求量化，否则无法判断供应商是否匹配：

- **门店分布**：哪些城市、多少家店、单店日均用量
- **配送频次**：日配 / 隔日 / 每周2-3次
- **时效要求**：从下单到到店多少小时（水果尤其看重这个）
- **温控要求**：常温、冷藏、部分冷冻
- **验收标准**：损耗率上限、到货新鲜度、单店最小起送量

## 二、看供应商的“仓”覆盖

关键不是问他有几个仓，而是问清每个仓的**位置+服务半径**：

1. **仓的层级**：CDC（中心仓）还是 RDC（区域仓）/前置仓。水果通常需要区域仓+城配才能保鲜。
2. **服务半径**：每个仓能覆盖多远（多少公里/多少小时车程）。超过半径就会拉长时效、增加损耗。
3. **城市匹配度**：把你的城市列表和他每个仓的覆盖圈做叠图，看有没有城市落在“空白区”或“边缘区”。边缘区的城市往往时效和损耗都不稳。
4. **产能**：仓的日均处理量、峰值处理量，能否承接你的量而不挤压其他客户。

## 三、看“配”的能力

这是水果供应链最容易出问题的地方：

- **干线**：产地/中心仓到区域仓的运输频次和时长
- **城配**：区域仓到门店的车辆、频次、是否冷链
- **最后一公里**：能否做到门店级配送，还是只能到城市集散点（后者你要自己再加一段）
- **温控贯通**：全程冷链还是断链，水果断链损耗会明显上升
- **应急能力**：缺货、爆仓、天气/交通异常时的备选方案

## 四、用几个可量化的指标打分

建议对每个候选供应商按城市维度打分：

| 维度 | 评估点 |
|---|---|
| 覆盖 | 你的城市里，几家在其仓配覆盖圈内 |
| 时效 | 下单到到店小时数，是否满足门店营业节奏 |
| 损耗 | 承诺损耗率 + 历史实际损耗 |
| 成本 | 到店价、起送量、附加费（冷链/偏远/小单） |
| 弹性 | 临时加单、峰值、门店增减城市的响应 |
| 稳定性 | 缺货率、准点率、投诉率 |

## 五、实操建议

1. **按城市分区**：把你的门店按城市/区域分组，逐个匹配供应商覆盖，而不是整体谈。
2. **做覆盖热力图**：核心城市（量大、时效要求高）优先找有本地仓+城配的供应商；边缘城市可接受干线+第三方城配组合。
3. **小范围试跑**：先选1-2个城市、少量门店试运行2-4周，实测时效、损耗、缺货，再决定扩不扩。
4. **多供应商组合**：全国性供应商打底，区域供应商补空白/补时效，避免单点依赖。
5. **合同里写清**：时效、损耗上限、缺货赔付、覆盖城市调整机制。

一句话总结：**先量化自己的时效和损耗底线，再看供应商的仓是否落在你门店所在城市，最后用试跑数据验证，而不是只看他“覆盖多少城市”的宣传。**
