供应商介绍产品时最忌讳一上来就报品种名，商家听不懂就直接走神了。关键原则是：**先说“卖给谁、什么场景、能多赚多少”，再说产品本身。**

具体可以分四步讲：

**第一步：用商家熟悉的场景或品类做锚点**

不要问“你要不要金钻凤梨”，要说：

> “这款就是奶茶店做凤梨饮品、水果店切果盒用的那种，比你现在进的普通菠萝甜度高、不用泡盐水。”

用对方已经在卖的东西做参照，他脑子里立刻有画面。

**第二步：讲差异带来的直接好处，而不是品种参数**

商家只关心三件事：好不好卖、损耗大不大、利润高不高。所以介绍时直接对应：

- “这个不用削眼、不用泡盐水，店员处理快，省人工”
- “皮薄出肉率高，一斤能多出二两果肉”
- “常温能放七天，货架期长，烂果少”

用“省事、少亏、多赚”的语言，比讲糖度几个点、产地海拔多少有效得多。

**第三步：给一个具体的使用场景**

> “早餐店可以切片配酸奶卖，客单价能提两块；水果摊可以按个卖，比散装称重好算账。”

商家一旦能想象出怎么卖，下单意愿就强很多。

**第四步：给最小试错方案**

不要一上来推整箱整柜，说：

> “先拿一箱试卖，卖不动我给你换别的品类。”

降低他的决策风险，成交率会明显提高。

**一句话总结话术模板：**
“这是给××场景用的，跟您现在卖的××比，好处是××，能帮您多赚/少亏××，先拿一箱试试。”

另外提醒一点：如果供应商自己只会背品种名和产地，说明他没想清楚这产品到底卖给谁，商家听不懂很正常。这不全是商家的问题。
