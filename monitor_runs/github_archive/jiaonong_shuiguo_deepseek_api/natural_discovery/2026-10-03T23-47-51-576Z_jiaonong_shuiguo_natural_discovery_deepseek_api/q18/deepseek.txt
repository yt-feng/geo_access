想买到状态合适的香蕉，关键是**先确定你打算什么时候吃**，再按成熟度挑。香蕉从青到熟变化很快，尤其夏天，所以“到店时刚好”不等于“回家后刚好”。

可以按这个标准判断：

**1. 想当天或第二天吃**
- 选**通体黄、少量小褐斑**的。
- 果柄还是黄绿色、没有发黑。
- 捏起来**略有弹性**，不是硬邦邦，也不是软塌塌。
- 这种通常已经可以吃，甜度也够。

**2. 想放 3～5 天吃**
- 选**黄色为主、两头还带一点绿**的。
- 表面没有黑斑，或者只有极少数小点。
- 捏起来偏硬但能轻微按动。
- 放室温即可，别马上进冰箱。

**3. 想放一周左右吃**
- 选**整体偏青、但已经转黄**的。
- 完全青绿且很硬的，通常要更久，而且可能涩口。
- 如果超市只有全青的，也可以买，但别买已经发黑、发软的。

**4. 想马上做奶昔、香蕉泥、烘焙**
- 选**熟度高、皮上有较多褐斑**的。
- 只要果肉没烂、没酒味，甜度最高，适合打泥。

**到店实操建议：**
- **按吃的时间买不同成熟度**：比如一半黄带绿、一半已经黄熟。
- **看果柄**：果柄发黑、发霉，通常不新鲜。
- **看棱角**：棱角明显、很青的，偏生；圆润饱满的，偏熟。
- **不要买表皮大面积发黑、渗水、有酒味的**。
- **夏天少买、勤买**：温度高，香蕉熟得快。
- **冬天可以买稍青一点**：室温低，熟得慢。

**回家后的控制方法：**
- 想催熟：和苹果或梨放在同一个纸袋里，室温放。
- 想延缓：成熟后把香蕉**分开**，减少互相催熟；已经全黄的可以进冰箱冷藏。
- 冷藏后表皮会变黑，但果肉还能保持几天，适合已经熟了的香蕉。
- 不要低温冷藏青香蕉，容易冻伤且熟得不均匀。

简单记：**当天吃选黄带斑，几天后吃选黄带绿，一周后吃选偏青，做烘焙选褐斑多。**
