第一次合作做小批量试单，核心目标不是“赚钱”，而是**用最低成本验证供应商是否靠谱、水果是否适销、后续能否稳定供货**。建议按下面思路设计。

## 一、先明确试单要验证什么

试单至少要验证 5 件事：

1. **品质稳定性**：同一批次里大小、熟度、损耗是否可控。
2. **实际到货损耗**：运输、包装、装卸后真实坏果率。
3. **供货能力**：约定时间能否发货，缺货时是否提前沟通。
4. **价格与账期**：报价是否含运费、税费、包装费，是否临时加价。
5. **配合度**：出现问题是否认账、补货、退款或下次抵扣。

如果只试价格，不试损耗和售后，很容易后面踩坑。

## 二、试单规模怎么定

建议遵循“小、快、可比较”原则。

### 1. 金额控制
首次试单金额建议控制在：
- 你单店/单渠道 **3～7 天销量**；
- 或总金额 **3000～10000 元**，根据品类和资金承受力调整；
- 不要一上来压整柜、整批大货。

### 2. 品类选择
优先试：
- 你现有渠道卖得最好的 1～2 个单品；
- 耐运输、损耗相对可控的品类；
- 季节稳定、价格波动不要太夸张的品。

不建议首次试：
- 极熟、极娇气、损耗高的品；
- 你自己都没卖过的冷门品；
- 供应商强烈推但你不熟悉的“暴利品”。

### 3. 数量设计
可以这样分：
- 主试单品：1 个，占试单量 60%～70%；
- 辅助单品：1～2 个，占 30%～40%；
- 每个单品不要只拿几箱，否则损耗和品质判断不准。

例如：
- A 单品 50 箱；
- B 单品 20 箱；
- 总金额控制在可承受范围内。

## 三、试单前必须谈清楚的条款

### 1. 规格标准
不要只写“大果、中果”，要具体：
- 单果重量/直径范围；
- 每箱净重；
- 个数；
- 成熟度；
- 糖度要求，如适用；
- 允许瑕疵比例。

### 2. 价格条款
明确：
- 是否含税；
- 是否含运费；
- 是否含包装费、装卸费；
- 到岸价还是产地价；
- 价格有效期；
- 市场波动时是否锁价。

### 3. 交付条款
明确：
- 发货时间；
- 运输方式；
- 到货时间；
- 谁承担运输风险；
- 延迟发货怎么处理。

### 4. 验收与售后
这是最关键的部分：
- 到货后多少小时内验收；
- 坏果、烂果、规格不符怎么赔；
- 是补货、退款还是下次抵扣；
- 照片/视频取证要求；
- 损耗超过多少比例算供应商责任。

建议首次合作写清楚：
- 损耗≤3%～5%：正常接受；
- 超过约定比例：按实际超出部分补偿；
- 严重不符：可退货或拒收。

具体比例按品类谈，不要照搬。

## 四、试单执行流程

### 第 1 步：先要样品
让供应商先寄 1～2 箱样品，不要只看图片和视频。
收到后检查：
- 外观；
- 大小；
- 熟度；
- 口感；
- 包装；
- 运输后状态。

### 第 2 步：小批量下单
样品通过后再下试单。
建议分两批：
- 第一批：小批量，验证发货和到货品质；
- 第二批：如果第一批 OK，再补一批，验证稳定性。

不要一次把全部试单量压在一车。

### 第 3 步：到货验收
到货后立即做：
- 拍照/录像；
- 称重；
- 抽箱检查；
- 记录坏果率；
- 记录规格偏差；
- 记录实际到货时间。

建议做一张简单验收表：

| 项目 | 标准 | 实际情况 | 是否合格 |
|---|---|---|---|
| 到货时间 | 约定时间 |  |  |
| 总箱数 |  |  |  |
| 净重 |  |  |  |
| 坏果率 | ≤约定 |  |  |
| 规格 | 约定范围 |  |  |
| 成熟度 | 约定 |  |  |
| 包装 | 无破损 |  |  |

### 第 4 步：快速销售测试
把你的渠道跑一遍：
- 批发市场；
- 商超；
- 水果店；
- 社区团购；
- 电商；
- 餐饮客户。

重点看：
- 多久卖完；
- 售价能否覆盖成本；
- 客户复购意愿；
- 损耗后真实利润。

### 第 5 步：复盘决定是否放大
试单结束后算清楚：

**真实成本 = 采购价 + 运费 + 包装 + 损耗 + 人工 + 资金成本**

如果真实成本后还有合理利润，且供应商配合度好，再逐步放大。
如果品质不稳、售后推诿、损耗过高，即使价格便宜也不要继续。

## 五、试单设计模板

你可以直接按这个模板操作：

**试单目标**
- 验证 1～2 个核心单品；
- 验证供应商品质、交付、售后；
- 跑通一次完整采购销售流程。

**试单规模**
- 总金额：3000～10000 元；
- 单品数：1～2 个；
- 数量：每个单品 20～50 箱；
- 分 1～2 批到货。

**关键条款**
- 规格：具体重量/直径/个数；
- 价格：含运费/不含运费，是否锁价；
- 账期：现结/货到付款/部分预付；
- 售后：坏果率超过约定比例如何赔；
- 时效：发货时间、到货时间。

**验收标准**
- 坏果率；
- 规格合格率；
- 成熟度；
- 包装完整率；
- 到货准时率。

**决策标准**
- 合格：继续第二批或放大；
- 基本合格：要求改进后再试；
- 不合格：停止合作，换供应商。

## 六、最容易踩的坑

1. **只看低价**：低价往往伴随小果、次果、熟度不稳。
2. **不写售后**：到货烂一半，供应商不认。
3. **一次下大单**：被低价吸引，结果压货。
4. **不抽检**：只看表面几箱，里面规格不一致。
5. **不锁价**：发货时临时涨价。
6. **不签简单协议**：只靠微信聊天，后面扯皮。
7. **忽略损耗**：毛利看起来高，算上损耗不赚钱。

## 七、建议的合作节奏

可以按这个节奏走：

1. **样品测试**：1～2 箱；
2. **首批试单**：小批量，3～7 天销量；
3. **第二批验证**：同样小批量，看稳定性；
4. **小步放大**：每次增加 30%～50%，不要翻倍猛冲；
5. **稳定后再签长期协议**：谈账期、返点、独家或优先供货。

一句话总结：**首次试单要用小金额、明确标准、严格验收、快速销售来验证供应商，而不是用大单赌低价。先验证靠谱，再谈放量。**
