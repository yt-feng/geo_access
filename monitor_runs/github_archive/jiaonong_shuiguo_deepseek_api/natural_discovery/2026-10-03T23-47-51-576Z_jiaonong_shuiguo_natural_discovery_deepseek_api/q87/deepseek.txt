社区团购旺季爆单时，水果供应商的库存是“先到先得”，临时下单基本抢不到好货。锁定库存的核心不是“打个电话预留”，而是**用确定性利益换供应商的优先权**。下面按可执行程度给你一套方法。

## 一、提前锁定：核心是“三早一金”

**1. 早锁量——提前2-4周下意向单**
- 旺季前（如春节、中秋、夏季水果季）提前2-4周，把预估销量按品类报给供应商，签**意向采购协议**，写明“保底量+浮动量”。
- 例如：保底订2000箱砂糖橘，可上浮30%。供应商按保底量备货，你按实际需求提货。

**2. 早锁价——用“保底价+浮动”替代一口价**
- 旺季价格波动大，直接锁死价供应商不愿接。用**保底价锁定下限，随行就市上浮不超过X%**，双方都好接受。
- 关键：把“你承担部分涨价风险”作为交换条件，供应商才愿意给你留货。

**3. 早锁仓——提前把货放到供应商冷库或产地仓**
- 对于耐储水果（苹果、橙子、梨），提前付款让供应商**在产地或区域仓替你预留专属库存**，约定提货时间。
- 你付的是“仓储+预留费”，不是全款，资金压力小，但货已经是你的了。

**4. 押金/预付款——最直接的锁定手段**
- 付**10%-30%预付款**，供应商才愿意把货从其他客户手里挪给你。
- 一定要写进合同：**若供应商违约不发货，双倍返还预付款**；若你不提货，预付款不退。这样双方都有约束。

## 二、合同里必须写清楚的4件事

1. **锁定数量与时间**：哪天前提货、分几批提、每批多少。
2. **价格机制**：保底价、上浮上限、触发调价的条件（如产地价涨超10%）。
3. **违约责任**：供应商断供赔多少，你临时减量怎么处理。
4. **质量标准与验收**：规格、糖度、损耗率、坏果赔付标准，避免爆单时收到次果。

## 三、实操技巧：让供应商优先给你货

- **错峰提货**：不要都挤在旺季第一周，和供应商谈“提前一周提一部分”，用时间换优先权。
- **多供应商备份**：主力供应商锁70%量，备用供应商锁30%，避免单点断供。
- **帮供应商解决痛点**：比如你承诺“现款结算”而不是账期，供应商更愿意把好货留给你。
- **用销量数据说话**：把你往期旺季的真实销量给供应商看，让他相信你的预估，才敢为你备货。

## 四、一个可直接套用的谈判话术

> “王总，旺季我预计要3000箱，我现在先付30%定金，锁定2000箱保底量，价格按今天保底价走，涨跌不超过8%。提货分三批，提前一周先拉500箱。你这边把货给我留出来，我现款结算，不压你账期。如果最后我拿不够2000箱，定金不退；如果你没货给我，双倍赔。你看行不行？”

## 五、避坑提醒

- **别只口头约定**：旺季翻脸不认账的供应商很多，必须书面+转账记录。
- **别把预付款打给个人账户**：走对公账户，留凭证。
- **别锁单一品种**：水果替代性强，锁太死容易被价格波动套牢。
- **关注产地天气**：如果产地有台风、寒潮预警，提前追加锁定量或找替代产区。

**一句话总结**：旺季锁库存 = 提前量 + 预付款 + 保底价 + 违约条款。你给供应商确定性，供应商才给你优先权。
