批发商在谈水果品牌代理时，区域保护和串货是核心利益点，问得越具体越好。建议按下面几个维度去问，并要求对方把答案写进合同。

## 一、先明确"代理"性质

- 你拿到的是**独家代理、区域独家经销，还是普通授权**？三者权利差别很大。
- 独家的话，独家范围是**省、市还是具体渠道**（比如只限商超、只限批发市场）？
- 有效期多久？续约条件和考核标准是什么？

## 二、区域保护要问的问题

1. 我的**授权区域边界**具体怎么划（按行政区、按市场、按渠道）？
2. 品牌方在**我区域内**还有没有其他代理/经销商？如果有，怎么处理？
3. 品牌方**自己会不会在我区域内直接供货或开直营**？
4. 品牌方通过**线上电商、直播、社区团购**卖到我的区域，算不算侵犯我的区域保护？
5. 如果发现区域内出现其他货源，品牌方**怎么处理、多久处理、有没有赔偿**？

## 三、串货/窜货要问的问题

- 串货的定义是什么？跨区域销售、低价倾销是否都算？
- 品牌方怎么**监控和识别串货**（有没有溯源码、批次号、区域编码）？
- 抓到串货方后，**处罚措施**是什么（罚款、断货、取消代理）？
- 我作为受害方，**举报流程和响应时限**是什么？
- **举证责任**在谁？我要提供什么证据才算数？
- 串货造成的损失，品牌方**赔不赔、怎么赔**？

## 四、必须写进合同的关键条款

| 条款 | 要求写清楚的内容 |
|---|---|
| 授权范围 | 区域、渠道、独家/非独家、期限 |
| 区域保护 | 品牌方及第三方的供货限制、线上销售限制 |
| 串货认定 | 定义、识别方式、举报流程、举证责任 |
| 违约责任 | 罚款金额、断货、取消代理、赔偿标准 |
| 价格体系 | 供货价、建议零售价、最低限价 |
| 退出机制 | 期满/违约后库存怎么处理、保证金退还 |

## 五、几个提醒

- **口头承诺不算数**，一定要落到书面合同。
- 问清楚**"区域保护"是否覆盖线上**，现在水果串货很多来自电商和直播。
- 关注**考核指标**（进货量、销售额），达不到是否会被取消独家。
- 保留好**沟通记录**，尤其是对方对区域和串货的承诺。
- 水果有**保鲜期**，还要问清退换货、破损承担、滞销处理。

按这几组问题去谈，基本能把区域保护和串货的风险点覆盖住。核心原则是：**让品牌方把承诺写进合同，并约定违约后果**。
