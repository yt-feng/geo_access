水果店控制菠萝损耗，核心是“采购时按销售节奏分批选熟度”，不要一批全拿同一个成熟度。判断时可以按下面这套方法做。

## 一、先定采购熟度：按计划卖几天来选

菠萝从采购到过熟很快，尤其气温高时。建议：

- **当天或次日就能卖完**：可以选**7～8成熟**，表皮开始转黄，香味明显，能直接切。
- **2～3天卖完**：选**5～6成熟**，表皮青黄相间，按下去稍微有弹性，放店里继续后熟。
- **3天以上或天气热**：尽量选**4～5成熟**，偏青、硬一点，但要看品种，有些品种后熟差，不能太青。

简单说：  
**能快卖就采熟一点，卖得慢就采生一点，但不要生到切开发白、没味。**

## 二、现场判断菠萝熟度的实用标准

### 1. 看表皮颜色
- **全青**：很生，酸、硬，后熟慢，适合远距离运输或天气冷时短存。
- **青中带黄，基部先黄**：比较适合水果店采购，后续能卖。
- **半黄到大部分黄**：接近可食，适合1～2天内卖完。
- **全黄、甚至发暗**：熟过头风险高，容易水烂、发酒味。

注意：有些品种即使熟了也偏青，不能只看颜色，要结合下面几条。

### 2. 看果眼和果皮
- 果眼**饱满、平整、间隙小**，通常发育好。
- 果皮**紧绷有光泽**，比皱缩的好。
- 如果果皮发皱、果眼塌陷，说明放久了或失水。

### 3. 闻底部香味
- 把菠萝翻过来闻底部：
  - **几乎没味**：偏生。
  - **有清甜菠萝香**：适合近期销售。
  - **香味浓、带酒味**：过熟，损耗风险大，尽量别采。

### 4. 按压判断
- 用手指轻按底部或侧面：
  - **硬邦邦**：生。
  - **稍软有弹性**：成熟度合适。
  - **一按就凹、软塌**：过熟或开始坏。

### 5. 看冠芽和底部
- 冠芽**青绿、挺立**：较新鲜。
- 冠芽枯黄、底部发黑发软、有汁液：不新鲜或已开始腐烂。
- 底部切口新鲜、无霉斑、无酒味，很重要。

### 6. 掂重量
- 同样大小，**越重越好**，说明水分足。
- 太轻可能失水或放久了。

## 三、采购时的组合策略

不要只拿一个熟度，建议：

- **20%～30% 选熟一点**：当天就能切果切、做促销。
- **50%～60% 选中等熟度**：2～3天主力销售。
- **10%～20% 选偏生一点**：天气热或周末备货时缓冲。

如果店里主要卖整果，可以偏生一点；如果卖果切、果汁，可以偏熟一点，但必须当天处理。

## 四、减少损耗的关键动作

1. **到店后按熟度分开放**：熟的分出来先卖，生的放阴凉通风处。
2. **不要堆太厚**：菠萝怕压，堆压容易伤、发霉。
3. **避免暴晒和闷热**：高温会加速过熟。
4. **每天检查底部**：有酒味、发软、渗汁的马上挑出，别传染其他果。
5. **熟度高的优先做果切或促销**：不要等它自然坏。
6. **采购量按销量倒推**：比如每天卖20个，2天卖完，就按40个左右采购，再留少量安全库存。

## 五、最实用的采购口诀

**一看颜色，二闻底香，三按弹性，四掂重量，五看底部。**  
**快卖采熟，慢卖采生；分批采购，熟先销售。**
