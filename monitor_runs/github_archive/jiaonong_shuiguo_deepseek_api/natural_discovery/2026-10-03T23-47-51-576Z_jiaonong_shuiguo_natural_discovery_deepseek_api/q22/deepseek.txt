可以按“引流款 + 利润款 + 搭配款”来组合，核心不是把三样都降价，而是让顾客从“买一根香蕉”变成“买一组水果”。

**1. 组合方案：香蕉+菠萝+苹果做“果切/果篮组合价”**
- 香蕉：引流，单价低、购买频次高，适合做价格锚点。
- 菠萝：提升客单，单价中等、有季节感，适合做搭配主角。
- 苹果：稳定利润和耐储，适合做凑单和家庭装。
- 建议设两档：
  - 小份组合：1根香蕉 + 1盒菠萝 + 2个苹果，定价略低于单买合计，但高于香蕉单独购买。
  - 家庭组合：1把香蕉 + 1个菠萝 + 4-6个苹果，做“周末家庭果盘套餐”。

**2. 促销话术要具体**
不要只写“组合优惠”，要写：
- “买菠萝，加1元换1根香蕉”
- “苹果满10元，送菠萝试吃盒”
- “香蕉+苹果+菠萝家庭装，立减3元”
这样顾客能立刻算清便宜多少。

**3. 陈列上做联动**
- 把香蕉放在水果区入口，做引流。
- 菠萝和苹果放在相邻端头，旁边放组合价签。
- 组合商品用同一个购物篮或网袋预包装，减少顾客自己搭配的决策成本。
- 试吃重点放菠萝，因为菠萝香气强，容易触发即时购买。

**4. 用“加价购”提高客单**
最有效的是：
- 买苹果满15元，加3元换半个菠萝；
- 买菠萝，加2元换一把香蕉；
- 买任意两样，第三样打8折。
这样比直接全场打折更能保住毛利。

**5. 注意损耗和库存**
- 香蕉熟得快，适合当天组合、当天清。
- 菠萝切开后损耗高，最好做试吃和果切组合，不要大量预切。
- 苹果耐放，可以承担利润和凑单角色。
- 每天复盘：组合卖出多少、香蕉是否被单独买走、菠萝是否剩货、苹果是否只是凑单。

**6. 可执行的周促销节奏**
- 周一到周四：主推“加价购”，清香蕉和菠萝。
- 周五到周日：主推“家庭果盘组合”，拉高客单。
- 每天下午4点后：把熟香蕉和切菠萝做“限时组合”，减少损耗。

**一句话建议：**
用香蕉引流，用菠萝做加价购，用苹果做凑单和利润，设“小份组合”和“家庭组合”两档价格，重点考核组合购买率，不要只考核单品销量。
