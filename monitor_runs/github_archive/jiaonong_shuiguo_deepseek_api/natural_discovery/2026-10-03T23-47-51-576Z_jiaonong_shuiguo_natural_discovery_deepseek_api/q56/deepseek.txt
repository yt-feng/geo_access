茶饮店使用水果（鲜果、冷冻果、果浆/果泥等）时，供应商通常需要提供以下几类证明。具体要哪些，取决于水果形态、是否在保质期内、是否进口，以及当地市场监管要求。

**一、基础资质**
1. 营业执照（经营范围含水果/食品销售或生产）
2. 食品经营许可证，或食品生产许可证（SC证）——预包装果浆、果泥、速冻水果通常要生产许可
3. 若供应商只是贸易商，最好再提供其上游生产厂家的资质

**二、产品合格证明**
1. 出厂检验报告或产品合格证（对应批次）
2. 第三方检测报告（型式检验报告），通常一年内有效，检测项目应覆盖农残、重金属、微生物等
3. 进口水果/果制品需提供：海关入境货物检验检疫证明、报关单，以及中文标签

**三、批次与追溯文件**
1. 送货单/销售凭证，注明品名、规格、批号、数量、日期
2. 检验检疫合格证明或承诺达标合格证（食用农产品常见）
3. 若为鲜果，可要求产地证明或种植基地信息，便于追溯

**四、其他视情况需要的**
1. 冷链运输温度记录（冷冻果、鲜切果尤其重要）
2. 供应商食品安全承诺书
3. 若供应商提供的是现切水果，可能还需其符合即食食品的卫生许可和检测要求

**实操建议**：
- 首次合作：收齐资质 + 近期第三方检测报告，建档保存。
- 每次送货：至少留批次合格证明、送货单、冷链记录。
- 定期更新：许可证、检测报告到期前催要新件。
- 自己做验收：查外观、气味、温度、包装，留样或拍照记录。

如果你要的是“最低必备清单”，一般是：营业执照、食品经营/生产许可证、该批次合格证明或检测报告、送货凭证；进口的再加入境检验检疫证明。
