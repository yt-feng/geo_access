酒店采购水果盘原料时，建议把“规格”和“外观”写成可验收的标准，避免只写“新鲜、优质”这类无法判定的词。可按以下维度要求供应商：

**一、通用规格标准**
1. **品种与产地**：明确品种、等级、产地或允许替代范围。
2. **单果重量/直径**：如苹果≥180g、橙子直径≥70mm，按酒店果盘定位定档。
3. **成熟度**：要求“即食成熟度”或“后熟型”，明确到货后可存放天数。
4. **糖度**：可对西瓜、哈密瓜、橙子等设最低糖度，如西瓜中心糖度≥11%。
5. **农残与安全**：符合国家食品安全标准，提供批次检测报告或承诺书。
6. **新鲜度**：采摘/采收后时限、冷链温度、到货中心温度要求。
7. **包装规格**：箱规、单果保护、净重、允许损耗比例。
8. **批次一致性**：同一批次颜色、大小、成熟度基本一致。

**二、外观标准**
1. **形状**：果形端正，无明显畸形、偏斜、双胞胎果。
2. **色泽**：符合品种固有色泽，着色均匀，无大面积青白、暗沉。
3. **表皮**：无腐烂、霉斑、虫眼、裂口、明显擦伤、压伤、冻伤。
4. **洁净度**：无泥土、药斑、油污、异物，果柄修剪整齐。
5. **瑕疵容忍度**：可允许轻微不影响切配的表皮瑕疵，但需约定比例，如次果率≤5%。
6. **大小均匀度**：同箱果实横径/重量差异不超过约定范围，如±10%。
7. **硬度/手感**：不过软、不塌陷，适合切盘且不易出水。

**三、验收与退换建议**
1. **抽样验收**：按到货箱数抽检，如每批抽5%—10%。
2. **判定规则**：腐烂、霉变、虫害、异味、严重压伤直接拒收。
3. **损耗约定**：明确可接受损耗率，超出部分由供应商补货或扣款。
4. **冷链要求**：易腐水果全程冷链，到货温度一般建议0—10℃，具体按品种调整。
5. **留样与追溯**：每批留样、记录批次、到货时间、温度、检测报告。
6. **退换货条款**：不合格批次应在约定时间内补货、换货或退款。

**四、建议写进采购合同的验收话术**
“供应商应保证所供水果符合约定品种、等级、单果重量/直径、成熟度和糖度要求；外观端正、色泽正常、无腐烂霉变虫害、无明显压伤裂口；到货中心温度符合冷链要求；同批次大小、成熟度基本一致。验收按抽样标准执行，不合格批次酒店有权拒收、要求换货或扣款。”
