会，而且通常**显著增加损耗风险**，尤其是香蕉和菠萝都属于后熟型、易损型水果。

核心判断是：

1. **香蕉更怕起订量过高**
   - 香蕉会继续后熟，温度、乙烯、挤压都会加速变黄、起斑、发软。
   - 如果一次到货太多，门店/仓库消化速度跟不上，就容易出现：
     - 黄熟过快，来不及卖
     - 搬运挤压造成黑斑、断指
     - 冷库温度不当导致冻伤或成熟不均
   - 所以香蕉的起订量高，通常会直接拉高报损率。

2. **菠萝相对耐放，但也会增加风险**
   - 菠萝比香蕉耐储存，但过高起订量仍会带来：
     - 长期库存导致底部发霉、黑心
     - 表皮失水、果眼凹陷
     - 夏季高温下内部发酵、汁液外溢
   - 如果采购的是已成熟菠萝，而不是青果，损耗会更快。

3. **关键看“周转天数”，不是只看起订量**
   可以用一个简单判断：
   - 香蕉：理想周转最好控制在 **2-4天**，超过就容易高风险。
   - 菠萝：常温下通常可放 **5-10天**，但夏季或已成熟果会缩短到 **3-5天**。
   - 如果起订量导致周转天数超过上述范围，损耗风险就明显上升。

4. **降低损耗的做法**
   - 按“日均销量 × 安全周转天数”反推订货量，而不是被起订量牵着走。
   - 香蕉到货后分批催熟、分批上架，不要一次全部推熟。
   - 菠萝优先采青果或半熟果，按成熟度分区存放。
   - 和供应商谈：
     - 降低起订量
     - 多频次小批量配送
     - 混装拼柜
     - 支持临期/滞销调换
   - 如果起订量无法降，宁愿提高单次采购频率，也不要一次性压太多库存。

结论：**起订量太高会增加损耗风险，香蕉比菠萝更敏感。** 如果周转天数超过安全范围，节省的采购成本很可能抵不过报损、降价和品质下降带来的损失。
