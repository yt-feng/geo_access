小水果店做附近小区团购，供应商至少要能支持这几类服务，否则团购很容易卡在供货、履约和售后上：

1. **稳定供货与每日报价**
   - 能提前给次日/当周报价，最好每天固定时间更新。
   - 支持小批量补货，不是只接大单。
   - 爆品、应季品有相对稳定货源，缺货能提前通知。

2. **分级与品质标准**
   - 明确什么是团购级、家庭级、次果级。
   - 糖度、大小、产地、成熟度、瑕疵容忍度要有标准。
   - 最好能按小区团购需求做简单分级，比如按份、按袋、按箱。

3. **分拣、打包与贴标**
   - 支持按团购订单分拣，而不是只发大筐。
   - 能代打包成一份一份，方便团长直接分发。
   - 可贴小区名、团购批次、品名、重量、保存方式等标签。

4. **冷链或保鲜配送**
   - 易坏水果要有冷藏、保温、泡沫箱、冰袋等支持。
   - 能配送到小店、团长点或指定自提点。
   - 配送频次最好能配合团购周期，比如隔日达、次日达。

5. **起订量与价格阶梯**
   - 低起订量适合小店试团。
   - 量大时有阶梯价，方便做爆款和利润测算。
   - 运费、包装费、损耗承担方式要提前写清。

6. **售后与损耗处理**
   - 坏果、烂果、少重、错发怎么赔，要有明确规则。
   - 支持拍照理赔、按比例赔付或下次补货抵扣。
   - 生鲜损耗率最好有约定，比如超过多少由供应商承担。

7. **退换货与临期处理**
   - 未拆封、未分拣的货能否退换。
   - 临期水果能否调换或做特价支持。
   - 团购取消、截团后加单、临时改量怎么处理。

8. **营销与素材支持**
   - 提供产品图、卖点、产地、口感描述。
   - 能给小店或团长提供团购文案、海报素材。
   - 支持试吃装、引流款、组合套餐。

9. **结算与对账**
   - 支持微信、支付宝、对公转账等常用方式。
   - 能按批次对账，提供送货单、电子明细。
   - 月结、周结、押金、账期要提前谈好。

10. **系统与订单对接**
   - 最好能接小程序、微信群接龙、表格订单。
   - 支持按订单汇总发货，减少小店自己二次分拣。
   - 能提供库存、价格、物流信息查询。

对小水果店来说，最关键的优先级是：**稳定货源、按份分拣、坏果赔付、低起订量、配送时效**。  
前期可以先找2—3家供应商，分别试跑一个小区团购，重点看：到货损耗、分拣准确率、售后响应速度、结算是否清楚。这样比只看价格更稳。
