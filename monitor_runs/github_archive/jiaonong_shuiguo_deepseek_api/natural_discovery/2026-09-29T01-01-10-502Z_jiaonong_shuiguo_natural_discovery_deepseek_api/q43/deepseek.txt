评估水果供应商的仓配覆盖，核心不是看他“有多少仓”，而是看**从仓到店的实际履约链路能不能稳定支撑你所有门店**。建议按下面几个维度逐项打分或排雷。

## 1. 先画清你的门店需求地图
先把连锁门店按城市/区域分组，标出：
- 门店数量与单店日均水果用量、峰值用量
- 对时效的要求：日配？隔日配？是否要求早市前到店
- 温层要求：常温、冷藏、冷冻
- 特殊品类：鲜切、浆果、叶菜类等易损品
- 门店收货条件：是否有冷库、收货时间窗、卸货条件

这一步是基准，否则供应商说“覆盖全国”也没法判断是否真覆盖你。

## 2. 评估供应商仓配网络的“真实覆盖”
不要只看仓库清单，要问清并核验：

**仓的层级与功能**
- 是总仓、区域仓、城市前置仓，还是只做中转？
- 每个仓是否具备水果所需的温控、分拣、催熟/暂存能力？
- 仓到店的配送半径和预计时效是多少？

**覆盖匹配度**
- 你的门店是否都在他的配送半径内？
- 哪些城市是自营仓配，哪些是外包/第三方？
- 外包段的服务标准是否和自营一致？

**关键指标**
- 仓到店平均时效、准时率
- 配送频次与截单时间
- 最小起订量、配送门槛
- 覆盖门店数 / 你实际门店数的匹配比例

## 3. 看履约稳定性，不只看覆盖范围
水果损耗高、时效敏感，重点看：
- 冷链断链风险：装卸、中转、最后一公里是否全程温控
- 缺货/断供历史：同一城市是否经常靠临时调货
- 异常处理能力：坏果、短少、延迟的响应时效和赔付机制
- 旺季/节假日/极端天气下的履约预案

可以要求供应商提供：
- 近 3–6 个月你目标城市的准时率、破损率、缺货率
- 典型门店的配送路线和时效样本
- 异常订单处理记录

## 4. 做“门店级”覆盖测试
最有效的方法不是听介绍，而是选点实测：
1. 选你门店最密集的城市、最偏远的城市、最难履约的品类
2. 让供应商做一次真实或模拟配送
3. 记录：下单到到店时长、到店温度、损耗率、单据准确性
4. 对比现有供应商或行业基准

如果条件允许，可以先在 1–2 个城市试点，再决定是否扩到全国。

## 5. 评估成本与扩展性
- 仓配费用是否随门店增加而线性增长，还是能规模摊薄
- 是否支持你未来 6–12 个月的开店计划
- 多供应商并行时，能否按城市/区域灵活切换
- 是否支持统仓统配、越库、门店直送等不同模式

## 6. 建议的评估结论形式
可以给每个供应商按下面维度打分：
- 覆盖匹配度（门店是否在配送范围）
- 时效达标率
- 冷链完整性
- 履约稳定性
- 异常处理能力
- 成本合理性
- 未来扩展能力

最后输出：
- 哪些城市可全量切换
- 哪些城市只能部分品类或部分门店合作
- 哪些城市需要备选供应商或自建前置仓

## 一句话判断标准
**如果供应商能把你最偏远的门店、最易损的品类、最严格的时效，在旺季也稳定送到，才算真正覆盖；否则只是“地图上有仓”。**
