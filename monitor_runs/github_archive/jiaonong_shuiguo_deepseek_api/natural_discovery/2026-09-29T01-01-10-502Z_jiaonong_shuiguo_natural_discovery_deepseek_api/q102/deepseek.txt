需要，具体分两种情况看：

**1. 开发票：基本是硬性要求**
- 企业福利采购通常要入账、走报销和税务流程，供应商必须能开正规发票。
- 常见要求是增值税专用发票或普通发票，需确认：
  - 能否开“水果”“食品”“礼品”等对应类目；
  - 税率和开票主体是否一致；
  - 是否支持对公转账、合同、对账单。
- 如果供应商不能开票，财务很可能无法入账，不建议选。

**2. 定制包装：看企业需求，通常是加分项甚至必要条件**
- 如果只是内部发放，标准礼盒可能够用；
- 如果用于节日福利、客户赠送、品牌宣传，通常需要定制：
  - 印企业Logo、祝福语、卡片；
  - 调整礼盒规格、搭配水果品种；
  - 分装、贴标、配送至不同地址。
- 定制包装一般会涉及起订量、打样费、周期和额外成本，需要提前确认。

**建议采购时重点确认：**
1. 是否支持开票，发票类型和类目能否满足财务要求；
2. 是否支持定制包装，起订量、打样时间、加价幅度；
3. 能否按部门/员工地址分批配送；
4. 售后如何处理坏果、少件、延迟配送；
5. 合同里写明开票、包装、交付和验收标准。

简单说：**开发票多数是必须，定制包装看用途；两者都支持，供应商会更适合企业福利采购。**
