# 超市门店多但单店量不大，适合的水果供货模式

这种"多店、小量、分散"的结构，核心矛盾是：**单店要货少，但门店数量多，导致物流、损耗、品控都难做**。适合的模式要同时解决"小批量"和"多网点"两个问题。

## 一、推荐的几种模式

**1. 本地批发市场 + 配送商代采（最务实）**
- 由本地水果配送商/批发商按你的门店清单，每天/隔天从批发市场代采、分拣、配送到各店。
- 优点：起量门槛低，不用自己建采购团队，灵活。
- 缺点：加价率通常 10%–20%，价格随行就市，品控靠对方。

**2. 区域配送商统采统配（适合门店 10 家以上）**
- 选 1 家区域水果供应链公司做总供应商，统一采购、统一分拣、按门店要货单配送。
- 优点：品控和账期更稳定，能压价，减少你管理多个供应商的成本。
- 缺点：对供应商依赖大，需签好品质和缺货赔付条款。

**3. 产地直采 + 区域分仓（中期目标）**
- 对走量大、耐储的品类（苹果、柑橘、土豆类根茎）直接对接产地，集中到区域分仓再分拨到店。
- 优点：毛利最高。
- 缺点：需要冷库/分仓和分拣能力，单店量小的时候要先做几个爆品试水，别全品类直采。

**4. 单品爆品统采 + 其余本地补货（混合模式，最推荐）**
- 20% 的走量单品（香蕉、苹果、柑橘、应季爆款）统一从产地/大供应商集中采购；
- 80% 的长尾品类就近从批发市场/配送商补，按需下单。
- 这是"多店小量"结构下性价比最高的组合。

## 二、判断你该选哪种

| 你的情况 | 建议模式 |
|---|---|
| 门店 < 10 家，无仓储 | 本地配送商代采 |
| 门店 10–30 家，有小型分拣点 | 区域配送商统采统配 |
| 门店 30+ 家，有冷库/分仓 | 爆品产地直采 + 长尾本地补 |
| 想做自有品牌/稳定毛利 | 混合模式（爆品直采+长尾本地） |

## 三、关键落地建议

1. **按品类分层管理**：爆品统采、长尾本采，别追求全品类直采。
2. **要货制而不是配货制**：各店按实际销量下单，减少强配造成的损耗。
3. **设损耗红线**：水果损耗通常 8%–15%，超过就要查是订货不准还是配送问题。
4. **配送频率**：叶菜/浆果类高频（每日），根茎/耐储类低频（2–3 天）。
5. **结算与账期**：优先找能接受"月结+损耗赔付"的供应商，把风险转移出去。
6. **起步先做 5–8 个爆品**：用爆品把单店量做起来，再谈直采和压价，量是谈判筹码。

## 四、一句话结论

**多店小量，不要自建重资产供应链。起步用"本地配送商代采 + 爆品统采"的混合模式，等单店销量和门店数上来，再逐步把走量品类转成产地直采。**
