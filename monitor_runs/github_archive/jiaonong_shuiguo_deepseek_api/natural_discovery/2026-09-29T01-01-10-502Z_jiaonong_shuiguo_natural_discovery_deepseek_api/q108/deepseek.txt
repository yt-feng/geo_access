核实水果供应商“全国配送”的实际覆盖能力，不能只听说，要按**可送达、可保鲜、可履约、可赔付**四个层面去验证。可以这样操作：

1. **先要覆盖清单，不要只要一句“全国”**
   - 要求供应商提供：常发省份、城市、偏远地区是否覆盖、哪些区域不接单。
   - 重点问：新疆、西藏、青海、内蒙古、宁夏、甘肃、海南、东北、云贵川偏远市县是否可达。
   - 让对方明确：是快递可达，还是能保证水果时效和破损率。

2. **按真实收货地址做试单**
   - 选采购方实际有需求的几个代表性地址：一线城市、省会、地级市、县级市、偏远乡镇。
   - 每个地址下一笔小单，测试下单、打单、发货、中转、签收全流程。
   - 不要只测一个总仓附近地址，那不能代表全国。

3. **核对物流合作方和路由**
   - 问清楚合作快递/冷链：顺丰、京东、中通、圆通、德邦、专线冷链等。
   - 要求提供面单截图或物流轨迹样例，看是否真的能从产地发到目标区域。
   - 水果类要特别确认：是否冷链、是否空运、陆运时效、中转次数。

4. **验证时效和损耗**
   - 要求供应商给出不同区域的承诺时效，例如：华东24-48小时、华南48小时、西北72小时以上。
   - 试单时记录：发货时间、到达时间、温度状态、破损率、腐烂率。
   - 对采购方来说，“能到”不等于“能用”，损耗超标就是不可履约。

5. **确认售后和赔付规则**
   - 问清楚：延误、破损、腐烂、丢件怎么赔。
   - 是否按比例赔、是否补发、是否要提供开箱视频和面单照片。
   - 赔付响应时间、打款时间也要写进合同或订单条款。

6. **查履约数据和案例**
   - 要求提供近3个月发往目标区域的发货记录、签收率、售后率。
   - 可让对方给2-3个同类客户案例，最好能直接联系核实。
   - 注意区分“发过”和“稳定发”，偶尔发一单不代表覆盖能力强。

7. **小批量多区域试跑**
   - 不要一上来签全国大单。
   - 先做2-4周、5-8个地址的小批量试单。
   - 统计：准时率、破损率、售后率、客服响应、异常处理能力。

8. **把承诺写进合同**
   - 覆盖范围、时效标准、冷链要求、损耗上限、赔付标准、违约责任都要写清楚。
   - 不要接受“全国可发”这种模糊表述，要具体到省份、城市、偏远地区。

简单判断标准：
- 能提供明确覆盖清单：基本可信。
- 能配合多地址试单：值得继续谈。
- 能提供真实物流轨迹和售后数据：可进入小批量合作。
- 只说“全国都能发”，但不愿试单、不愿写赔付：风险很高。

采购方最稳的做法是：**先小单多地址试跑，再用数据决定是否放大合作。**
