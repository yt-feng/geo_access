选水果拼盘的规格，核心不是“买越大越划算”，而是看**出成率、损耗、人工和卖相**。按餐厅常用做法，给你一个直接可执行的判断：

**苹果**
- 选**中等偏大、果形端正、硬度高**的：直径约 75–85mm，单果 180–250g。
- 太小的削皮去核后出成率低，切出来片小、拼盘显空；太大的单价高，切块后容易氧化、卖相粗。
- 餐厅常用：**红富士、嘎啦、青苹果**。红富士耐放、颜色稳；青苹果适合配色。
- 划算规格：**80mm 左右一级果或二级果**，不要礼盒果。礼盒果溢价高，切盘不划算。

**橙子**
- 选**中等大小、皮薄、汁多、易剥或易切**的：直径约 70–80mm，单果 180–250g。
- 太小出肉少；太大皮厚、白瓤多，切瓣后不整齐。
- 餐厅常用：**脐橙、血橙、伦晚、夏橙**。血橙颜色好但价高，适合高端拼盘；普通拼盘用脐橙更稳。
- 划算规格：**70–75mm 统货或二级果**，只要无烂、无干疤即可。做拼盘不需要礼盒级外观。

**菠萝**
- 选**成熟度适中、果眼浅、圆柱形**的：单果 1.2–1.8kg 最实用。
- 太小削皮去眼后剩肉少；太大容易中间硬、边缘熟度不均。
- 餐厅常用：**金钻凤梨、都乐菠萝、台农17号**。金钻凤梨不用盐水泡，出成率高，适合拼盘。
- 划算规格：**1.5kg 左右、7–8 成熟**。太生酸，太熟切块易烂。
- 如果用量大，直接买**去皮菠萝块/菠萝丁**有时更划算，但要看是否泡糖水、是否耐放。

**直接结论：**
- 苹果：**80mm 左右，180–250g/个**
- 橙子：**70–75mm，180–250g/个**
- 菠萝：**1.2–1.8kg/个，优先金钻凤梨**

**更划算的采购原则：**
1. **拼盘用二级果、统货果最划算**，只要无腐烂、无严重磕碰。
2. **不要买礼盒果、精品果**，外观溢价高，切开后差别不大。
3. **按出成率算成本**，不是按斤价算：
   - 苹果出成约 75–85%
   - 橙子出成约 55–70%
   - 菠萝出成约 45–60%
4. **用量大就固定规格**，让供应商按直径/单果重分级，减少切配浪费。
5. **菠萝如果人工贵，买去皮净果更划算**；苹果、橙子建议买毛果自己处理。
