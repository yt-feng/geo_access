优先谈 **账期**，其次是 **售后**，最后才是 **配送**。前提是：这家供应商已经长期合作、整体履约稳定，你不是在重新筛供应商，而是在优化合作条件。

排序理由很直接：

1. **账期最值得优先谈**
   - 它直接影响你的现金流和资金周转。
   - 对长期合作供应商来说，账期通常是最有谈判空间、也最能量化的条件。
   - 水果行业价格波动大、损耗高，账期多一点，你应对压货、损耗、回款慢的空间就大很多。
   - 优先目标不是“越长越好”，而是争取一个稳定、可执行、双方都能接受的账期，比如从现结/短账期谈到月结、半月结，或部分账期+部分现结。

2. **售后第二优先**
   - 水果是非标品，损耗、等级不符、到货不新鲜、批次差异都很常见。
   - 售后规则不清，长期合作里最容易扯皮，也最容易吃掉利润。
   - 重点谈清楚：坏果率标准、照片/视频举证时限、补货还是扣款、运费谁承担、整车/整批异常怎么处理。
   - 售后谈清楚，比配送快半天更重要，因为它直接决定你卖出去之后会不会亏。

3. **配送最后谈**
   - 配送重要，但它通常更偏执行层，而且很多问题可以通过排单、前置沟通、固定时段来优化。
   - 除非你现在经常因为配送迟到、缺货、临时加价导致门店断货，否则它优先级低于账期和售后。
   - 配送重点谈：固定送达时段、临时加单规则、缺货提前通知时限、迟到或漏送的补偿方式。

一个更实用的谈判顺序是：

**先谈账期 → 再谈售后赔付规则 → 最后把配送时效和异常处理写进合作条款。**

如果你只能谈一个，选 **账期**。  
如果你能谈两个，选 **账期 + 售后**。  
如果三个都能谈，把配送作为“执行保障”打包进去，但不要让它挤掉前两个的核心利益。

补充一句：如果这家供应商目前是唯一货源、你替换成本很高，那账期可能很难大动，这时就优先谈 **售后规则**，因为它更容易落地，也能立刻减少损耗争议。
