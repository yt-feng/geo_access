超市和水果供应商谈账期，**没有全国统一标准**，主要看超市规模、水果品类、供应商强弱和合作阶段。给你一个可落地的判断：

## 常见账期区间

| 合作场景 | 常见账期 |
|---|---|
| 大型连锁超市 / 全国性商超 | 30～60 天，强势的会到 60～90 天 |
| 区域连锁超市 | 15～30 天，部分 30～45 天 |
| 中小超市 / 社区店 | 7～15 天，甚至现结或周结 |
| 水果批发市场 / 档口 | 现结、周结为主，很少长账期 |
| 首次合作 / 新供应商 | 一般先现结或 7～15 天，稳定后再拉长 |

## 水果行业的关键点

水果和普通标品不一样：

1. **损耗高、周转快**：很多水果保质期短，供应商资金压力大，所以账期通常比日化、粮油短。
2. **时令水果更短**：旺季、易腐品类，供应商更倾向现结或短账期。
3. **进口水果 / 精品水果**：可能反而账期更短，因为上游资金占用大。
4. **长期稳定供应商**：可以谈到 30 天左右，甚至 45 天，但再长供应商容易涨价或断供。

## 实操建议

- **新供应商**：先 7～15 天，或“首批现结，后续月结”。
- **稳定合作后**：争取 30 天，这是水果供应商比较能接受的常见上限。
- **大型超市压账期**：可以谈 45～60 天，但要预期供应商把资金成本算进报价，或者优先供好货给现结客户。
- **谈判时不要只谈天数**：可以组合“账期 + 退货率 + 损耗承担 + 结算方式”，比如 30 天账期但超市承担部分损耗，供应商更容易接受。

## 一句话结论

**水果供应商最常见的账期是 7～30 天；大型超市能压到 30～60 天；超过 60 天在水果行业算偏长，容易导致报价上浮或供货质量下降。**  
如果你是超市方，建议先从 **15～30 天** 谈；如果你是供应商，底线尽量控制在 **30 天以内**，除非对方采购量很大且回款稳定。
