判断水果供应商靠不靠谱，核心不是“他说得有多好”，而是**持续供货能力、品质稳定性、价格透明度、售后承担意愿**这四件事。你可以按下面这套方法去筛。

## 1. 先看硬资质，但别只看证件
要看：
- 营业执照、食品经营相关资质是否齐全
- 是否有固定档口、仓库、冷库，还是临时倒货
- 是否能稳定提供同一产地、同一等级的货
- 是否敢让你去现场看货、看库存、看分拣

如果对方只有微信、报价很飘、今天有货明天没货，通常不适合长期合作。

## 2. 重点试这4件事

### ① 连续试供3到5次
不要第一次就大量进。  
分几次小批量进香蕉和菠萝，观察：
- 到货时间是否稳定
- 成熟度是否一致
- 损耗率是否忽高忽低
- 规格是否和报价一致

靠谱供应商的特点是：**每次差不多，而不是偶尔特别好。**

### ② 看香蕉和菠萝的专业度
香蕉要问：
- 产地：云南、广西、海南、菲律宾、厄瓜多尔等
- 是青蕉还是催熟蕉
- 催熟程度、到店后能放几天
- 夏天和冬天运输方式是否不同

菠萝要问：
- 品种：巴厘、金钻、凤梨等
- 是否去皮、是否带冠芽
- 成熟度标准
- 坏果怎么赔

如果对方回答含糊，只会说“很甜”“很好卖”，专业度就不够。

### ③ 看损耗和售后
长期合作最怕的不是价格高一点，而是**坏果不认**。  
提前谈清楚：
- 坏果、烂果、黑心菠萝怎么算
- 是补货、折价还是退款
- 几小时内反馈有效
- 运输破损谁承担

靠谱供应商通常会主动给标准，不靠谱的会说“水果都这样”。

### ④ 看价格是否透明
不要只比单价，要比：
- 毛重还是净重
- 是否含箱、含纸、含冰瓶
- 是否包运费、卸货费
- 等级是否一致

有的报价低，但箱皮重、次果多，实际成本更高。

## 3. 用这几个信号快速排除

**不靠谱信号：**
- 报价明显低于市场，还催你打款
- 每次规格不一样，催熟度靠运气
- 出问题就推给物流或天气
- 不让你看货，只发几张旧图
- 频繁换产地、换品种，却说“都一样”
- 要求长期大额预付，但不签简单供货单

**靠谱信号：**
- 有固定档口/仓库，能现场看货
- 敢小批量试供，不急着让你压货
- 主动说清损耗、售后、结算方式
- 香蕉和菠萝的产地、等级、成熟度说得清楚
- 出现坏果愿意按约定处理

## 4. 建议你这样合作
1. **先小批量试3次**，每次记录到货时间、损耗率、口感、售后。
2. **签简单供货单**，写清品种、等级、规格、单价、结算、售后。
3. **不要只依赖一家**，香蕉和菠萝各留1个主供应商+1个备选。
4. **每周对比一次**：进价、损耗、售卖速度、顾客反馈。
5. **账期要谨慎**：长期合作可以谈账期，但初期最好货到验收后结算。

## 5. 最实用的判断标准
你只问自己一句话：

**“如果我今天订一批香蕉和菠萝，他能不能按说好的时间、规格、成熟度送到，坏了还认账？”**

如果答案稳定是“能”，就值得长期合作。  
如果每次都要靠运气、靠催、靠扯皮，价格再低也不适合长期做。
