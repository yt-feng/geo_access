旺季锁库存，核心不是“打个电话让供应商留着”，而是用**可执行的合同条款 + 资金/订单确定性**换供应商的优先权。按下面几步做，落地性最强：

**1. 提前锁定，别等爆单才谈**
- 水果旺季通常提前 **30–60 天**谈锁量，进口/稀缺单品更早。
- 先做销量预测：按去年旺季单量、复购率、增长率，拆到“单品 × 周 × 仓”。没有预测，供应商不会给你留货。

**2. 用“预付定金 + 保底量”换优先供货**
- 谈**保底采购量**：比如承诺旺季每周至少拿 X 箱，供应商按此备货。
- 付**定金/预付款**（常见 10%–30%），这是最有效的锁货手段。
- 约定**阶梯价**：拿货越多单价越低，激励你冲量、也激励供应商保供。

**3. 合同里必须写死的条款**
- **锁量不锁价**或**锁价锁量**：明确旺季单价上限，防坐地起价。
- **优先供货权**：你下的订单在同等条件下优先于散客。
- **违约赔偿**：供应商断供、少供，按差价或订单额比例赔。
- **质量标准**：规格、糖度、损耗率、拒收标准写清楚，避免旺季以次充好。
- **到货时效**：约定发货/到仓时间，迟到算违约。

**4. 多源备份，别押一家**
- 主供应商占 60%–70%，备用 1–2 家占 30%–40%。
- 提前让备用供应商小批量试单，旺季才能随时切换。

**5. 用确定性换资源**
- 给供应商看你的**历史结算记录、回款周期**，回款快是最大筹码。
- 可以谈**包销尾货**：你帮他消化非标果，他给你优先权。
- 旺季前**提前打款**，比口头承诺管用得多。

**6. 执行节奏**
- 旺季前 60 天：谈框架、签协议、付定金。
- 前 30 天：确认首周排产、物流、包装。
- 前 7 天：每日对单，确认库存和发运。
- 旺季中：按日滚动下单，别一次性压太多导致损耗。

**一句话总结**：锁库存 = 提前预测 + 保底量 + 预付定金 + 违约条款 + 多源备份。只靠关系口头约定，旺季一定被撬单。
