卖香蕉最容易出问题的不是“坏”，而是**压伤后发黑**和**成熟过快**。控制要点可以分成四段：采购成熟度、包装、温控、配送时效。

**1. 采购时选对成熟度**
- 不要采全黄熟蕉，选**青黄交接、七成左右成熟**的货。
- 要求供应商做**去乙烯处理或预冷**，到仓后尽快分拣，剔除已有机械伤、黑斑、软身的。
- 香蕉怕冷，**低于12℃会冻伤变黑**，所以不能按普通叶菜那样冷藏。

**2. 包装防压**
- 用**带透气孔的硬质纸箱或塑料周转箱**，不要用软袋直接装。
- 每根之间用**珍珠棉网套、纸浆托或气泡膜**隔开，重点保护蕉指弯曲处和果柄。
- 箱内不要装太满，留**10%—15%空间**，避免运输中相互挤压。
- 整箱码放时**不要超过3层**，重物不能压在上面。
- 果柄朝同一方向排列，减少戳伤相邻香蕉。

**3. 温控与催熟管理**
- 配送环境尽量保持**13—15℃**，这是香蕉比较安全的区间。
- 夏天用**冷藏车但温度不能过低**，冬天要防冻，避免放在车尾门口。
- 如果卖的是即食黄蕉，可在仓内统一催熟后再发，但**催熟后必须快发**，不能再长期存放。
- 包装箱内可放**乙烯吸收剂**，延缓后熟和变黑。

**4. 配送时效和末端**
- 同城尽量**当日达或次日达**，跨城不卖熟蕉。
- 末端配送避免电动车暴晒、后备箱高温闷放。
- 用户收到后提示：**不要放冰箱冷藏**，阴凉通风处存放；已切开或过熟再冷藏。
- 如果做预售，按订单量催熟，减少库存积压。

**5. 售后判断标准**
- 轻微表皮黑点、局部压痕，通常不影响食用，可提前在详情页说明。
- 大面积发黑、果肉软烂、有酒味，属于配送损耗，应直接赔付。
- 建议按**“坏果包赔”**做，但要求用户提供整箱照片，避免单根索赔扯皮。

**最有效的组合方案：**
青黄蕉采购 + 预冷去乙烯 + 网套分隔 + 硬箱透气 + 13—15℃运输 + 同城次日达 + 乙烯吸收剂。

如果只选一个最关键的，就是：**别让香蕉在配送中受冻、受热、受挤压，并且缩短在途时间。**
