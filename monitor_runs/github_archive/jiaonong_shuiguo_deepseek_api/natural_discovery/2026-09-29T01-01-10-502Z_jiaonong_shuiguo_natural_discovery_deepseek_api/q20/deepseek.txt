社区超市做水果，核心不是“找到供应商”，而是找到能稳定匹配你客流和损耗的供应商。建议重点看这几类条件：

1. **配送稳定性**
   - 能否每天固定时间送达，比如早上6–8点前到店。
   - 节假日、雨天、旺季是否照常配送。
   - 缺货时是否提前通知，能否补送或替换。

2. **品类与等级**
   - 是否覆盖你日常销量大的基础水果：苹果、香蕉、橙子、梨、葡萄、西瓜、应季水果等。
   - 能否按你的要求分等级：通货、精品、小果、大果。
   - 是否支持小批量多品类，而不是只供一两种。

3. **价格与结算**
   - 报价是否含运费、装卸费、框子费。
   - 是否随行就市，还是能锁价几天。
   - 结算周期是现结、周结还是月结，是否压账。
   - 残次、破损、重量不足怎么扣款或补货。

4. **质量与损耗**
   - 到店后烂果、压伤、熟过头的比例大概多少。
   - 是否允许当场验收、拍照留证、当天反馈。
   - 次品能否退换，还是只能自己承担损耗。
   - 有没有冷链或保鲜运输，尤其夏天和叶菜类水果。

5. **起送量与价格优势**
   - 每天最低起送量是多少，是否适合社区店小批量。
   - 量大能否再谈价，量小是否加价。
   - 是否比本地批发市场拿货更有优势，算上损耗和人工后是否真的划算。

6. **售后与响应**
   - 出问题后多久能回复、补货或退款。
   - 是否有固定业务员对接，还是每次换人。
   - 旺季断货时有没有备用渠道。

7. **资质与安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 是否有农残检测或进货凭证。
   - 万一出现食品安全问题，能否追溯和承担责任。

8. **实地判断**
   - 先去本地批发市场问2–3家，再让供应商试送一周。
   - 试送期间记录：到货时间、损耗率、缺货次数、售后速度、实际毛利。
   - 不要只看报价低，水果损耗和断货对社区店影响更大。

简单说，优先选：**能每天送、品类全、损耗低、售后快、结算不压资金**的供应商。最好同时保留一个主供应商和一个备用供应商，避免旺季被卡货。
