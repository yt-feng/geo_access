选学校食堂水果供应商，核心看四件事：**资质合规、稳定供货、质量可控、价格透明**。香蕉、苹果、橙子都属于高频大宗水果，建议按下面步骤做。

**1. 先定准入硬门槛**
供应商至少要有：
- 营业执照
- 食品经营许可证（或食品生产/流通相关许可）
- 水果批次检测报告或产地证明
- 对公账户，能开正规发票
- 有固定分拣场地、冷藏或常温仓储能力
- 配送车辆和人员健康证明

学校食堂涉及食品安全，**没有食品经营许可的个体果贩不建议直接准入**，可以让他们挂靠有资质的配送公司。

**2. 按品类分别找货源**
不要只用一家供应商包全部，常见做法是：
- **苹果**：优先找产地合作社或大型批发市场一级商，耐储存，适合批量采购。
- **橙子**：找产地直发或区域一级批发商，注意季节和糖酸比。
- **香蕉**：最容易损耗，建议找有催熟能力的供应商，能按食堂用量分批次配送。

如果学校规模不大，可以找**本地农产品配送公司**统一配送；如果规模大，建议苹果、橙子走产地或一级市场，香蕉单独找专业催熟配送商。

**3. 用试供和验收筛供应商**
不要只看报价，先让2—3家试供1—2周，重点看：
- 到货准时率
- 单次缺斤少两情况
- 坏果率：香蕉一般控制在5%以内，苹果、橙子3%以内
- 规格是否稳定：比如苹果单果重、橙子直径、香蕉每把根数
- 是否愿意按食堂要求分拣、去皮、切配或小包装

验收时按批次抽检，记录**品种、数量、规格、成熟度、伤果数、到货时间**，作为月度评分依据。

**4. 报价和结算要定规则**
建议采用：
- **周期性报价**：每周或每两周报价一次，参考当地批发市场均价。
- **价格联动**：约定随行就市，但涨幅超过一定比例需提前书面确认。
- **账期结算**：月结为主，避免长期现金预付。
- **质量扣款**：坏果超标、规格不符、迟到，按合同扣款或退货。

**5. 合同里必须写清楚**
- 供货品类、规格、单价、调价机制
- 配送时间、频次、最低起送量
- 验收标准和退换货规则
- 食品安全责任和赔偿条款
- 发票、账期、违约责任
- 不得转包或临时换货源

**6. 实际筛选顺序**
可以按这个流程走：
1. 网上或当地市场监管局查资质；
2. 让供应商提供报价单和样品；
3. 实地看仓库、分拣场、冷藏条件；
4. 试供2周，记录坏果率和准时率；
5. 综合评分后签年度或学期合同；
6. 保留2家备选供应商，防止断供。

**简单判断标准：**
- 只报价低、没资质、不能开票的，不选；
- 能稳定送、坏果少、规格稳、售后快的，优先；
- 香蕉供应商要有催熟和冷链能力，苹果橙子供应商要有产地或一级市场渠道；
- 至少保留一家备选，避免单一供应商卡脖子。

如果是中小学或幼儿园食堂，还要额外注意当地教育局或市场监管部门对大宗食品采购的集中招标要求，有些地区规定必须通过统一平台采购。
