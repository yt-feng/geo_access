大型超市水果供应商要把货稳定送进商超体系，通常必须在**食品安全**和**物流交付**两条线上同时达标。重点不是“有没有证”，而是能否持续满足超市的审核、抽检、追溯和履约要求。

## 一、食品安全能力

### 1. 主体资质与合规文件
- 营业执照、食品经营许可证或食品生产许可证（视加工环节而定）
- 若涉及进口水果：海关报关、检验检疫证明、入境货物检验检疫证明
- 种植/加工基地的备案或合作协议，能说明货源合法稳定
- 产品检测报告：农残、重金属、真菌毒素等，按品类和超市要求提供
- 从业人员健康证，尤其涉及分拣、包装、即食鲜切环节

### 2. 农残与污染物控制
- 有明确的验收标准：农残限量、重金属、外观、成熟度、缺陷率
- 能提供第三方检测或自检报告，且检测项目与品类匹配
- 对高风险品类（叶菜、草莓、葡萄、柑橘等）有更频繁的抽检机制
- 出现不合格时，能快速召回、隔离、追溯并给出纠正措施

### 3. 追溯体系
- 能做到“从批次到门店”的正向和反向追溯
- 每批货有批次号、产地、采收日期、加工日期、检测状态
- 记录保存期限符合法规和超市合同要求
- 一旦超市或监管抽检有问题，能在规定时间内定位到具体批次和货源

### 4. 加工与仓储卫生
- 分拣、包装、预冷、催熟等环节有卫生管理制度
- 冷链温度记录完整，尤其是切果、浆果、叶菜等易腐品类
- 防虫防鼠、清洁消毒、交叉污染控制到位
- 包装材料符合食品接触材料要求

### 5. 质量稳定与商品化处理
- 能按超市标准做分级、规格、成熟度、糖度、色泽控制
- 有标准化包装、标签、条码和保质期标识能力
- 能处理催熟、预冷、保鲜、气调等商品化处理
- 对损耗率、到店合格率、客诉率有数据管理

### 6. 审核与应急能力
- 能通过超市或第三方机构的验厂、飞行检查
- 有食品安全事故应急预案、召回流程、客诉处理机制
- 有保险（如产品责任险）更有利于进入大型商超
- 能配合超市做年度审核、整改闭环和文件更新

## 二、物流与供应链能力

### 1. 冷链能力
- 具备预冷、冷藏、冷链运输、冷库储存的完整链条
- 运输车辆有温度监控和记录，能导出温度曲线
- 不同温区水果能分温管理，避免混装导致冻伤或催熟
- 对断链有应急处理方案和责任界定

### 2. 仓储与库存管理
- 有符合超市订单波动的仓储容量和分区管理
- 先进先出、批次管理、效期管理执行到位
- 库存数据可对接或可提供，避免超卖和断货
- 对易腐品有日清、周清和损耗控制机制

### 3. 运输与配送履约
- 能按超市要求的频次、时间窗、门店点位配送
- 有自有或稳定合作的冷链车队，运力可弹性调整
- 能处理多门店、小批量、多频次配送
- 到店交接有单据、温度记录、数量和质量确认

### 4. 订单与信息系统
- 能接收超市订单系统或EDI对接
- 有ERP/WMS/TMS等系统支持订单、库存、批次、物流追踪
- 能提供发货通知、到货确认、对账和异常反馈
- 数据可追溯，能支持超市做履约考核

### 5. 品控与异常处理
- 装车前、运输中、到店后有质量检查节点
- 对压伤、腐烂、温度异常、短少等问题能快速补货或赔付
- 有退货、换货、召回和销毁流程
- 能统计到店合格率、准时率、损耗率并持续改进

### 6. 供应稳定性与产地能力
- 有稳定产地、合作社或自有基地，避免季节性断供
- 对天气、病虫害、物流中断有备选货源和替代方案
- 能按超市销售计划做长期供应和促销备货
- 有分级包装能力，适应商超标准件和门店陈列要求

## 三、大型超市通常重点审核的几项

1. **证照齐全且有效**
2. **农残检测合格且可追溯**
3. **冷链不断链，温度记录可查**
4. **批次追溯能到门店**
5. **到店合格率和准时率稳定**
6. **异常召回和赔付机制明确**
7. **能通过验厂和飞行检查**
8. **系统对接和单据规范**

## 四、简单判断标准

如果一家水果供应商能做到以下四点，基本具备进入大型超市的基础能力：

- 每批货有检测报告和批次追溯
- 全程冷链有温度记录
- 能按门店订单准时配送
- 出问题能快速召回、补货和整改

如果缺少其中任何一项，通常很难长期稳定供货，尤其是叶菜、浆果、鲜切水果等高风险品类。
