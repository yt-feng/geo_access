做水果礼盒，核心不是“凑够四种水果”，而是**按送礼场景和价位分层搭配**。苹果、橙子、香蕉、菠萝这四样里，香蕉和菠萝其实不太适合做主力礼盒——香蕉易压伤、催熟其他水果，菠萝带刺占空间、处理麻烦。但它们可以当“氛围配角”或低价引流款。

下面给你几套实际好卖的搭配方案：

**1. 基础走量款（58-88元）**
- 苹果 6个 + 橙子 6个 + 香蕉 1把（小把）
- 定位：日常探病、同事分享、小区团购
- 卖点：颜色亮、分量足、成本低
- 注意：香蕉单独用纸包一下，别直接贴苹果

**2. 中档送礼款（98-138元）**
- 苹果 8个 + 橙子 8个 + 菠萝 1个（小果）
- 定位：节日送长辈、客户轻礼
- 卖点：菠萝撑体积，看起来“大盒”
- 注意：菠萝要选小果、削好皮单独装盒，否则扎手

**3. 高档果篮款（158-228元）**
- 苹果 6个 + 橙子 6个 + 菠萝 1个 + 香蕉 2根（装饰用）
- 再加1-2样高价水果：车厘子/蓝莓/猕猴桃/阳光玫瑰
- 定位：送领导、商务、重要节日
- 卖点：层次感强，有“贵气”
- 注意：香蕉只做视觉点缀，不要多放

**4. 纯苹果橙子款（最稳）**
- 苹果 + 橙子 两种为主，比例 1:1 或 2:1
- 定位：企业团购、批量送礼
- 卖点：耐放、不易坏、寓意好（平安、成功）
- 这是最不容易出售后问题的组合

**关键实操建议：**

- **香蕉别和苹果橙子混放**：苹果释放乙烯，香蕉会很快变黑。要隔开或最后放。
- **菠萝必须预处理**：要么削皮装盒，要么整个但用网套+独立隔层，否则刺破其他水果。
- **礼盒高度靠菠萝和苹果撑**，橙子填缝，香蕉做颜色点缀。
- **定价按“水果成本 × 2.2~2.8”**，礼盒包装和损耗要算进去。
- **最好卖的是“苹果+橙子”打底，再选1样特色水果**，四样全上反而杂。

**如果只选一个组合先试：**
> 苹果8 + 橙子8 + 菠萝1（小）+ 香蕉2根装饰，定价108-128元，节日前后最好卖。
