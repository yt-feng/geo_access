采购香蕉做茶饮或甜品，关键不是“越黄越好”，而是按用途分阶段采购，并用“表皮颜色+手感+使用窗口”来控熟度。

**1. 先按用途定熟度**

- **做果泥、奶昔、冰沙、香蕉牛奶**：用**7～9成熟**，表皮黄、带少量褐点，果肉软甜、香气足。
- **做香蕉块、切片装饰、烤香蕉、焦糖香蕉**：用**5～7成熟**，表皮黄但基本无褐点，果肉成型，切了不烂。
- **做香蕉蛋糕、香蕉面包、松饼**：用**9～10成熟**，表皮大量褐点甚至发黑，甜度高、香气浓，压泥最合适。
- **做香蕉果酱、熬煮馅料**：用**9成熟以上**，糖分高，更容易出胶和出香。

**2. 采购时这样判断**

- **颜色**：
  - 全绿：太生，不适合直接出品。
  - 绿黄相间：适合需要放几天的门店。
  - 全黄：可立即用于切片、装饰或轻果泥。
  - 黄带褐点：适合果泥、奶昔、烘焙。
  - 大面积褐黑：只适合当天做泥、烘焙或果酱，不适合装饰。
- **手感**：
  - 硬：生，需催熟。
  - 稍软但有弹性：适合切片、烤制。
  - 明显软、按压有陷：适合打泥、烘焙。
- **果柄和棱角**：
  - 棱角明显、果柄青绿：偏生。
  - 棱角变圆、果柄转黄：接近可食用。
- **气味**：有明显香蕉甜香即可用；有发酵酒味说明过熟，不建议再采购入库。

**3. 门店采购策略**

- **不要一次只买一个熟度**。按未来 2～4 天用量，分三档采购：
  - 即用档：黄带少量褐点，当天到次日用。
  - 过渡档：全黄，1～2 天后用。
  - 储备档：绿黄相间，3～5 天后用。
- **每天盘点熟度，先进先用**。把过熟香蕉优先转到烘焙、果泥、果酱，不要硬撑做装饰。
- **控制库存天数**。香蕉后熟快，夏季尤其明显，门店最好按 2～3 天销量采购，不要按一周囤。
- **分开存放**。香蕉会释放乙烯，催熟其他水果；未熟香蕉可和苹果、梨放在一起催熟，熟香蕉要单独放、减少挤压。
- **冷藏要注意**。完全成熟后可冷藏 1～2 天延缓过熟，但表皮会变黑，适合打泥不适合装饰；生香蕉不要冷藏，容易冻伤、后熟不均。

**4. 简单执行标准**

- **当天做装饰/切片**：采购全黄、无褐点、手感稍软。
- **当天打泥/奶昔**：采购黄带褐点、手感软。
- **明天到店用**：采购全黄或黄多绿少。
- **3 天后用**：采购绿黄相间。
- **烘焙/果酱**：专门留过熟香蕉，不占正常出品库存。

一句话：**按出品方式定熟度，按销售速度分批采购，熟香蕉转泥和烘焙，生香蕉单独催熟。**
