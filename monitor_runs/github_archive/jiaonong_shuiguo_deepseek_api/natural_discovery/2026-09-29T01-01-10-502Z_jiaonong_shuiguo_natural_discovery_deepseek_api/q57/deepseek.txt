优先建议：**中央厨房统一收货更好**，但前提是你具备“中央厨房能统一定价/统采、能做质检分级、能按门店订单分拣配送、冷链不断链”这四个条件。不满足时，门店分开收货反而更稳。

**一、统一收货的核心优势**
- **成本更低**：总部集中采购，量大议价强，减少门店各自找供应商的价格差和灰色空间。
- **标准统一**：水果等级、成熟度、糖酸度、规格可以由总部定标准，避免A店收好货、B店收次货。
- **食安可控**：供应商资质、农残检测、批次追溯集中在中央厨房，责任链更清楚。
- **减少门店负担**：门店只需验收配送单和外观，不用每天跟多个果贩扯皮。
- **数据集中**：采购、损耗、门店用量能统一分析，方便做SKU优化和菜单调整。

**二、什么时候门店分开收货更合适**
- 门店数量少，比如少于5家，且分布分散。
- 水果讲究“当日鲜、本地鲜”，中央厨房配送会多一次装卸和运输，反而增加损耗。
- 中央厨房没有冷藏、分拣、检测能力，只是多一道转手。
- 门店有强本地化需求，比如不同城市水果品种、成熟度要求差异大。
- 配送半径太长，常温车或断链配送会导致到店后品质下降。

**三、判断标准**
你可以用这4个问题判断：
1. **门店是否足够密集？** 同城或300公里内能形成配送圈，统一收货更划算。
2. **水果是否高度标准化？** 苹果、橙子、香蕉、西瓜等适合统采；杨梅、荔枝、本地时令鲜果可能更适合门店直采。
3. **中央厨房能否做质检和分拣？** 能，就统一；不能，就别硬统。
4. **损耗谁承担？** 如果统一配送后损耗仍由门店承担，门店会抵触，容易变成形式统一。

**四、推荐模式**
多数餐饮连锁更适合：**中央厨房统一采购+分级+配送，门店只做最终验收**。  
但可以保留例外：**高时效、强本地化、低标准化水果，允许门店在总部白名单内本地直采**，价格和供应商仍由总部管控。

**五、落地建议**
- 总部定水果验收标准：品种、规格、成熟度、糖度、农残、腐烂率。
- 中央厨房做批次质检，按门店订单分拣，冷链配送。
- 门店收货只核对：数量、温度、外观、批次，异常2小时内反馈。
- 每月看三个指标：采购价差、配送损耗率、门店投诉率。如果统一后损耗和投诉明显上升，再调整品类，不要一刀切。

一句话：**能统则统，统不了就“总部控标准+门店本地收”，但不要把采购权完全放给门店。**
