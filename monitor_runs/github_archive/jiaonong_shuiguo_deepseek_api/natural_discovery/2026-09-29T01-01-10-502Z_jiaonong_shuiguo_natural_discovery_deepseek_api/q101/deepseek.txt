和水果供应商谈合作，核心不是“把价格压到最低”，而是把**稳定供应、品质一致、损耗可控、账期清楚**写进合作条件。酒店早餐水果通常每天都要用，断供或品质波动比单价贵一点更麻烦。

下面按谈判前、谈判中、合同里三块说。

**一、谈判前先把自己的需求算清楚**

1. **确定水果清单和规格**
   - 固定常用：西瓜、哈密瓜、苹果、橙子、香蕉、圣女果、火龙果等。
   - 明确规格：大小、成熟度、甜度、单果重量、是否去皮切块。
   - 早餐水果最好选耐放、易切、出成率高的，减少损耗。

2. **预估用量和波动**
   - 按客房入住率、早餐人数、季节变化估算日用量。
   - 给出平日量、周末量、旺季量，让供应商知道波动范围。
   - 如果酒店有宴会或团队，提前说可能临时加量。

3. **确定配送要求**
   - 配送频率：每天送、隔天送还是每周几次。
   - 到货时间：早餐前必须到，比如凌晨5点前或前一晚送达。
   - 验收地点、卸货方式、谁签收。

4. **设定品质标准**
   - 新鲜度、无腐烂、无虫害、无过度成熟。
   - 切果类要明确是否冷链、包装、保质期。
   - 最好写“验收不合格可拒收或换货”。

**二、谈合作时要重点确认的条件**

1. **价格机制**
   - 不要只谈一个固定单价，水果价格波动大。
   - 可以约定：每周或每两周按市场价调一次，或按批发市场行情浮动。
   - 明确报价是否含税、含运费、含装卸。

2. **供应稳定性**
   - 问清产地、季节替代方案、缺货时怎么补。
   - 要求供应商提供备用货源，避免单一产地断供。
   - 约定缺货、迟到的违约责任。

3. **品质与验收**
   - 到货后按标准验收，不合格当场记录、拍照、拒收。
   - 约定换货时限，比如2小时内补送。
   - 定期复盘，比如每月看一次投诉和损耗。

4. **账期和结算**
   - 常见账期：月结30天、45天、60天，看酒店财务流程。
   - 明确对账日、发票类型、付款方式。
   - 避免口头约定，所有价格和账期写进合同或订单。

5. **损耗与退换**
   - 水果有自然损耗，要区分“正常损耗”和“供应商责任”。
   - 腐烂、压伤、规格不符应由供应商负责。
   - 切果类如果当天未用完，是否可退换要提前说清。

6. **食品安全与资质**
   - 要求营业执照、食品经营许可证、检验合格证明。
   - 切果供应商还要有冷链和卫生资质。
   - 配送人员健康证、车辆卫生也要关注。

**三、合同或框架协议里必须写的条款**

- 品名、规格、单价或调价机制
- 配送时间、频率、地点
- 验收标准和不合格处理
- 缺货、迟到、品质问题的违约责任
- 账期、发票、付款方式
- 食品安全责任和赔偿
- 合同期限、续约、终止条件
- 保密和廉洁条款，避免采购人员私下拿回扣

**四、实操建议**

1. **先小批量试供**
   - 不要一上来就签长期大单，先试供2到4周。
   - 看准时率、新鲜度、损耗率、服务响应。

2. **至少保留两家供应商**
   - 主供应商负责日常，备用供应商应急。
   - 避免被一家卡住，尤其是旺季。

3. **建立简单验收表**
   - 每天记录：到货时间、品种、数量、品质、拒收原因。
   - 这些记录是后续谈判和换供应商的依据。

4. **不要只盯价格**
   - 便宜但损耗高、经常断供，综合成本更高。
   - 重点看“可食部分成本”和“每份早餐水果成本”。

5. **注意廉洁和流程**
   - 采购、验收、付款最好分开人或至少留痕。
   - 比价、询价、审批记录保存好。

**一句话总结：**
谈水果供应商，要把**规格标准、配送时间、调价机制、验收退换、账期结算、违约责任**六件事写清楚；先试供、留备选、看综合成本，不要只压单价。
