连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是**价格调整机制、损耗归属、验收标准、账期结算、独家/返利、不可抗力**这几块。下面按风险从高到低说，并给出可写进合同的建议。

**1. 价格机制：只写“随行就市”或“年度固定价”都容易出事**
- 坑：固定价遇到产地涨价，供应商断供或降质；随行就市又没定义参照市场、报价周期、涨幅上限，超市被动挨宰。
- 建议：写“基准价+调价公式”。例如以某产地批发市场/权威指数周均价为参照，约定调价触发条件（涨跌超5%）、提前通知天数、双方确认方式。同时约定供应商不得因市场涨价单方停供。

**2. 损耗与验收：水果是非标品，最容易扯皮**
- 坑：只写“按国家标准验收”，但水果没有统一可执行国标；到货腐烂、规格不符、成熟度不够时，责任和扣款不清。
- 建议：约定具体验收维度——品种、规格（单果重/果径）、成熟度、糖度、色泽、机械伤比例、腐烂率上限、抽检比例。明确“到货验收”和“上架后短期损耗”的责任分界，比如到货24小时内发现的品质问题由供应商承担，之后按约定比例分担。

**3. 供货量与弹性：承诺量定太高，淡季卖不掉；定太低，旺季断货**
- 坑：年度最低采购量写死，完不成要赔；或者只写“按订单供货”，供应商旺季优先给别人。
- 建议：设“保底量+弹性区间”，比如月度基准量±20%内供应商必须保障，超出部分提前X天协商。同时约定旺季优先供货义务和违约后果。

**4. 账期与结算：账期长+对账慢，供应商容易断供或抬价**
- 坑：只写“月结60天”，但没写对账日、发票、扣款争议怎么处理。超市各种费用（进场费、促销费、损耗扣款）直接从货款里扣，供应商不认。
- 建议：明确对账日、开票要求、付款日；所有扣款必须有事前书面确认或合同依据，禁止单方随意扣款。争议部分先付无争议款，避免整笔拖欠。

**5. 返利与费用：年度返利、通道费最容易埋雷**
- 坑：口头承诺返利，年底按“含税销售额”还是“实际结算额”算不清；各种促销费、陈列费没有上限。
- 建议：写清返利基数、税率口径、计算周期、支付方式；费用项目列清单并设年度总额上限，未列明费用不得收取。

**6. 独家与排他：签了独家，反而被绑死**
- 坑：约定某品类独家供应，但没约定价格竞争力、断供时的解约权。供应商涨价或断供，超市没法换人。
- 建议：独家条款必须配“价格不高于同期市场可比价”和“连续断供/质量不达标可解除独家”的出口。

**7. 质量安全与追溯：出一次食安事件，责任要能追到供应商**
- 建议：要求供应商提供检测报告、产地证明、农残合格证明；约定因供应商原因导致下架、罚款、赔偿的，由供应商承担，并可设质量保证金。

**8. 不可抗力与解约：别把“市场行情变化”当不可抗力**
- 坑：供应商用“天气/行情”当不可抗力随意断供。
- 建议：不可抗力严格限定为自然灾害、政策禁令等，且需及时通知和证明；行情波动属于商业风险，不算不可抗力。同时约定连续断供、质量不合格达到一定次数的解约权和赔偿。

**9. 合同期限与续约：年度合同别自动续约**
- 建议：到期前X天双方书面确认是否续约；不自动续约，避免被动延续不利条款。

**一句话总结**：水果年度合同的核心是把“非标品”变成“可执行标准”，把“随行就市”变成“有公式的调价”，把“各种扣款”变成“有事前依据”。价格、损耗、验收、结算这四项写清楚，基本能避开八成坑。
