建议不要二选一，而是**以整果为主、切果为辅**，按门店客群和损耗能力决定切果占比。

**直接判断：**

1. **如果门店客流以家庭采购、中老年、价格敏感型为主**  
   优先卖整果。整果损耗低、毛利可控、顾客信任度高，适合做引流和走量。

2. **如果门店在商圈、写字楼、年轻社区，或下班高峰客流明显**  
   切果更适合做增量。顾客买的是“即时方便”，愿意为省事付溢价。

3. **如果门店没有冷链、切果当天卖不完、员工操作不规范**  
   不要主推切果。切果最大的风险不是卖不动，而是食品安全和损耗。

**核心对比：**

- **整果优势：** 损耗低、库存好管、价格透明、投诉少、适合促销走量。  
- **整果劣势：** 顾客回家自己削，便利性差，客单价低。

- **切果优势：** 便利、即食、客单价和毛利通常更高，能吸引年轻人和即时消费。  
- **切果劣势：** 需要冷藏、刀具砧板消毒、时效管理，卖不完基本报损，人工成本高。

**建议的采购和运营策略：**

- **采购端：** 整果按日常销量采购，切果用外观稍差但内部合格的果，避免用烂果切盘。
- **陈列端：** 整果做堆头，切果放冷藏柜或收银动线附近。
- **定价端：** 切果按“整果成本 + 人工 + 损耗 + 目标毛利”定价，不要只按整果斤价换算。
- **时段端：** 切果集中在上午和傍晚前切，晚高峰后减少切量。
- **安全端：** 切果必须冷藏，标注制作时间，当天未售完按制度报损，不要第二天继续卖。

**结论：**
大多数商超最适合的是：**整果保基本销量，切果做便利增量。**  
如果只能选一个，社区型、价格敏感型门店选整果；商圈型、年轻客群、即时消费强的门店选切果。
