生鲜水果到货后出现坏果，责任划分通常要看**坏果产生的时间点、原因、以及各环节是否有过错**。实务中一般涉及四方：产地/供应商、平台/商家、物流/配送、顾客。

下面按常见情形说清楚。

## 一、先判断坏果是什么原因造成的

1. **发货前就已变质/以次充好**
   - 责任在供应商或商家。
   - 比如采摘时已过熟、分拣不严、把尾货混入、冷库储存不当。
   - 这种情况商家应先赔顾客，再向供应商追责。

2. **运输/配送环节温控不当、挤压、延误**
   - 责任在物流或平台配送方。
   - 比如冷链断链、暴晒、长时间滞留、暴力分拣。
   - 顾客一般仍找商家/平台索赔，商家再向物流追偿。

3. **到货时完好，顾客收货后放置过久或保存不当**
   - 责任在顾客。
   - 比如未及时冷藏、拆开后常温放几天、自己磕碰。
   - 商家通常不承担，但可协商部分补偿。

4. **难以判断或混合原因**
   - 按公平原则和证据分担。
   - 常见处理是商家承担主要责任，顾客承担少量，或平台先行赔付。

## 二、对顾客的责任原则

对消费者而言，通常不需要先分清是供应商还是物流的问题。

- 顾客在平台/商家购买，**合同相对方是商家/平台**。
- 到货即发现坏果，商家应承担退换、补发或退款责任。
- 如果是“签收后发现”，要看是否在合理验收期内、是否拍照留证、是否按说明保存。

简单说：**顾客先找商家，商家不能把责任推给物流让顾客自己追。**

## 三、责任划分的常见比例参考

没有统一法定比例，按过错和证据判断，常见处理思路：

| 情形 | 主要责任 | 常见处理 |
|---|---|---|
| 发货即坏、分拣不严 | 商家/供应商 | 全额退款或补发 |
| 冷链断链、配送延误 | 物流/平台 | 商家先赔，再追物流 |
| 外包装完好、内部少量坏果 | 商家为主 | 按坏果比例部分赔 |
| 顾客未及时取货/保存不当 | 顾客 | 协商少量补偿或不赔 |
| 原因不明 | 共担 | 平台/商家多承担 |

## 四、实操建议

**对顾客：**
- 到货后尽快开箱，拍开箱视频或照片。
- 保留坏果、包装、面单、聊天记录。
- 在平台售后时效内申请，要求补发/退款。
- 不要轻易接受“生鲜不支持退货”作为拒绝理由，坏果属于质量问题。

**对商家/平台：**
- 建立分拣、温控、时效标准。
- 要求配送方留温控和签收记录。
- 售后先赔顾客，再按合同向供应商或物流追偿。
- 对高频坏果品类设置损耗率和赔付规则。

**对供应商/物流：**
- 按合同承担相应违约责任。
- 若因自身过错导致坏果，应赔偿商家损失。

## 五、一句话结论

**顾客到货发现坏果，原则上先由商家/平台对顾客负责；商家再根据坏果是产地、分拣、冷链、配送还是顾客保存问题，向相应责任方追偿。**  
核心判断标准是：**坏果在哪个环节产生，谁有过错，谁就承担相应责任。**
