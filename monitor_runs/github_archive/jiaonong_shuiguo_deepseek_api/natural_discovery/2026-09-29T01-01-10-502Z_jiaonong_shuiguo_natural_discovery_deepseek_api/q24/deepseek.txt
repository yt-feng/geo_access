超市如果要防范水果农残抽检风险，采购前应优先向供应商索取以下几类资料，并注意资料要和对应批次、产地、日期匹配：

1. **批次检测报告**
   - 要求提供与本次供货批次对应的农残检测报告。
   - 报告最好由具备资质的第三方检测机构出具，如 CMA/CNAS 资质机构。
   - 重点看检测项目是否覆盖常见高风险农药，以及是否按国家标准判定合格。
   - 报告日期应覆盖该批次采收或发货时间，不能拿旧报告反复用。

2. **产地证明或供货证明**
   - 产地证明、基地证明、合作社证明、收购凭证等。
   - 用于确认水果来源，出现问题时能追溯。

3. **供应商资质**
   - 营业执照。
   - 食品经营许可证或食用农产品相关经营资质。
   - 若供应商是种植基地，可要求提供种植基地信息、备案或相关认证。

4. **承诺书/质量保证协议**
   - 供应商出具农残合格承诺书。
   - 合同中明确：若抽检不合格，供应商承担退货、赔偿、罚款及法律责任。
   - 最好约定每批次随货提供检测报告或合格证。

5. **食用农产品合格证**
   - 国内很多地区推行“食用农产品合格证”。
   - 可要求供应商随货提供，至少包含品名、产地、数量、开具日期、生产者或供应商信息、承诺事项。

6. **追溯信息**
   - 品种、产地、采摘日期、包装日期、批次号。
   - 如果能做到“一批一码”或随货追溯码，更利于超市应对检查。

7. **高风险水果的额外资料**
   - 对草莓、葡萄、豇豆、韭菜、芹菜等高风险或易超标品类，可要求更严格的批批检测。
   - 必要时超市自己再做快速检测或送检。

实操建议：

- **不要只收一张报告**：要核对报告上的品名、产地、批次、日期是否和到货一致。
- **尽量批批索取**：至少对高风险水果、新供应商、换产地时批批检测。
- **合同里写清楚**：供应商必须随货提供合格证明，抽检不合格由供应商承担全部损失。
- **保留记录**：进货台账、检测报告、合格证、合同、沟通记录都要存档，至少保存到保质期满后一段时间，通常建议不少于6个月，具体按当地监管要求。
- **超市可自检**：有条件的门店或配送中心做农残快检，发现问题立即封存并上报。

简单说：**要“一批一报告、一证一来源、合同带责任”**。核心资料是：批次农残检测报告、食用农产品合格证、供应商资质、产地/追溯证明、质量承诺与赔偿协议。
