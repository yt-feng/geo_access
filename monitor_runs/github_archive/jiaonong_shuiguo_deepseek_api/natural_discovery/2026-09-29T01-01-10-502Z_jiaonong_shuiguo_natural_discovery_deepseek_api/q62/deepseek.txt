判断一批香蕉，核心看“颜色、硬度、棱角、柄端、果指状态、气味和温感”，再结合你打算几天内卖完来决定能不能拿。

**1. 先看颜色和成熟阶段**
- 全青、硬：适合远途或放几天再卖，但要看有没有“青而不熟”的僵果风险。
- 青黄相间、果指饱满：通常催熟中或即将转黄，适合计划 2–4 天内出货。
- 黄多青少：熟度已高，适合快批快走。
- 全黄、带少量糖斑：适合零售即食，但批发周转要非常快。
- 大面积黑斑、发暗、出水感：坏果风险高，压价也要谨慎。

**2. 摸硬度和看棱角**
- 果身很硬、棱角明显：偏生。
- 果身微软、棱角变圆：熟度上来。
- 局部软塌、按下去不回弹：可能内伤或过熟。
- 同一箱里软硬差异大：说明成熟不均，后面损耗会高。

**3. 看果柄、果轴和切口**
- 果柄青绿、切口新鲜：货龄相对短。
- 果柄发黑、干缩、霉点：存放久或冷链有问题。
- 果轴切口发黑、有黏液、异味：腐损风险大。
- 有白色霉、灰色霉、黑霉：不要只看表面，整箱都可能传染。

**4. 看果指和果皮细节**
- 果指饱满、表皮紧致：状态好。
- 果皮起皱、失水：放久了或冷链反复。
- 果指有压伤、裂口、虫眼、水渍斑：坏果起点。
- 果尖发黑、发软：可能过熟或冷害。
- 表皮有少量糖斑正常，但黑斑连片、凹陷、渗汁就不行。

**5. 闻气味和摸温度**
- 有正常香蕉香：熟度合适。
- 有酒味、酸味、发酵味：已经过熟或内部腐坏。
- 有霉味、土腥味：仓储或运输卫生差。
- 箱子摸起来过热：可能已开始发热催熟，后面烂得快。
- 摸起来过冷或果皮发暗：可能冷害，催熟后容易发黑不发软。

**6. 抽样判断坏果风险**
不要只看最上面一层：
- 从不同位置抽 3–5 箱，每箱看上中下三层。
- 随机拿 10–20 根，检查柄端、果尖、侧面。
- 轻捏果身，找软塌、空心感、渗液。
- 把可疑果切开看：中心发黑、发褐、空腔、异味，说明内部坏。
- 如果一箱里明显坏果超过 3%–5%，整批风险就偏高；超过 10% 要非常谨慎，除非当天能低价清掉。

**7. 结合你的销售周期判断**
- 1–2 天卖完：可以拿黄熟度高的，但必须现场挑掉坏果。
- 3–5 天卖完：拿青黄相间、硬度中等的。
- 5 天以上：拿青硬货，但要求冷链和催熟条件稳定。
- 没有冷库、天气热：不要拿高熟度货，损耗会很快放大。

**8. 拿货时的实操建议**
- 要求开箱抽查，不接受只验样箱。
- 问清采摘时间、催熟状态、运输温度、是否淋雨或受冻。
- 看箱底有没有汁液、霉斑、压烂痕迹。
- 同一批货如果成熟度差异大，按低熟度那部分定价，不要按最好那层定价。
- 合同或单据写明：坏果率、验收标准、能否退换。
- 拿回来后先分拣：青的、黄的、软的、伤的分开，别混放，否则熟度会互相催。

一句话：**青硬看周转，黄软看速度，柄端和果尖看腐损，抽样看整批。** 如果颜色不均、柄端发黑、局部软塌、有酒酸味，这批货坏果风险就高。
