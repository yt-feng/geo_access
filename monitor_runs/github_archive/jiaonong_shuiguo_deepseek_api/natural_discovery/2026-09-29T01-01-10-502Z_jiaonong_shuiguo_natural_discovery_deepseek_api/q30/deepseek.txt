超市水果到货后发现品相不好，售后流程建议在采购合同或供货协议里提前约定，重点写清“验收标准、时限、处理方式、责任划分、证据要求”五件事。可以按下面条款思路约定：

**1. 验收标准和验收时限**
- 到货后由超市指定人员在当场或约定时间内验收，例如“卸货后2小时内完成初验，24小时内完成复验”。
- 明确品相标准：大小、色泽、成熟度、机械伤、腐烂率、病虫害、冻伤、异味、畸形果比例等。
- 约定可接受比例，例如“轻微瑕疵果不超过5%，腐烂果不超过1%”；超过即视为不合格或按比例扣款。

**2. 不合格处理方式**
- 分级处理：可退货、换货、折价接收、部分拒收。
- 约定优先级：能换货的换货；不能换货的退货；超市愿意接收的，按折价比例结算。
- 写清费用承担：退换货产生的运费、装卸费、损耗由供货方承担，除非是超市存储不当造成。

**3. 异议提出时限**
- 超市应在约定时间内提出书面异议，最好附照片、视频、验收单。
- 超过时限未提出，可视为验收合格；但隐蔽瑕疵可另约更长时间，例如“内部腐烂到货后48小时内可提出”。
- 供货方应在收到异议后约定时间内回复并处理，例如24小时内答复、48小时内完成换货。

**4. 证据和单据**
- 到货验收单：记录品种、数量、批次、到货时间、验收结果、双方签字。
- 照片/视频：整批、局部、问题果特写、称重或计数过程。
- 留存样品：有争议时可封存样品，约定保存期限。
- 沟通记录：微信、邮件、书面函件均可作为附件。

**5. 责任划分和扣款**
- 明确是供货方责任、运输责任还是超市责任。
- 若是供货方责任，可约定扣款、补货、赔偿损耗。
- 若是运输方责任，由供货方先向超市处理，再向承运方追偿。
- 若是超市收货后储存不当导致，供货方不承担责任。

**6. 结算和争议解决**
- 不合格部分可暂缓结算，处理完再结算。
- 约定争议解决方式：协商、调解、仲裁或诉讼，并写明管辖地。
- 可约定质量保证金或账期扣款机制。

**简单可执行的条款示例：**
“水果到货后，超市应在2小时内完成初验，24小时内完成复验。腐烂、严重机械伤、异味、冻伤等不合格果比例超过约定标准的，超市有权拒收或要求换货；供货方应在48小时内完成换货。因供货方原因产生的退换货费用由供货方承担。超市提出异议应附照片、验收单等证据。逾期未提出异议视为验收合格，但隐蔽瑕疵可在48小时内提出。不合格部分货款暂缓结算，处理完毕后按实际合格数量结算。”

如果你要的是“已经到货后怎么处理”，实操上就是：先拍照留证、隔离不合格品、24小时内书面通知供货方、要求换货或折价、同步暂缓结算，并保留验收单和沟通记录。
