最应该先问**售后**，其次是**配送**，最后才是**价格**。

原因是团购团长真正怕的不是“进货贵一点”，而是：

1. **坏果、烂果、缺斤少两谁赔**
2. **赔付标准是否清晰**
3. **多久内反馈有效**
4. **要不要拍照、留证、按比例赔还是全赔**
5. **赔付是补货、退款还是下次抵扣**

水果是非标品，损耗高，一旦售后规则模糊，你赚的那点差价很容易被赔光，还会伤群内信任。

顺序建议这样排：

**第一问：售后**
重点问：
- 坏果怎么赔？按个数、重量还是比例？
- 需要多久内反馈？签收后2小时还是24小时？
- 拍照要求是什么？切开拍还是整箱拍？
- 补发还是退款？退款多久到？
- 团长垫赔还是供应商直接赔？
- 如果整批品质差，能不能整单退换？

**第二问：配送**
重点问：
- 到货时间是否稳定？
- 送到团长自提点还是小区门口？
- 破损、延误、漏送怎么处理？
- 能不能按团购节奏分批送？
- 临时加单、改单来得及吗？

**第三问：价格**
价格当然重要，但要放在售后和配送之后谈。
因为低价如果没有售后兜底，等于把风险转嫁给你。
你真正要比的是：
- 到手价
- 损耗率
- 赔付后实际成本
- 复购率和群口碑

一句话总结：  
**先问售后，再问配送，最后谈价格。售后不清，价格再低也别做。**
