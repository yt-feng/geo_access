餐饮店每天少量水果，想省心，核心不是找“最便宜”，而是找**稳定、能小批量、能按你要的规格处理、售后不扯皮**的供应商。建议按下面优先级选：

1. **本地水果批发市场的固定档口**
   - 适合：每天少量、品类会变、想当面看货。
   - 省心点：可以谈每天固定时间送货，坏果当场换。
   - 注意：要固定一家，不要每天换摊；提前一天发清单，约定规格，比如“苹果80-85果、香蕉七成熟、柠檬一级果”。
   - 适合预算有限、离市场近的店。

2. **本地生鲜配送平台/ B2B 食材平台**
   - 适合：不想自己跑市场，要手机下单、次日达。
   - 省心点：有起送量、售后流程、发票，通常能覆盖水果、蔬菜、肉蛋。
   - 注意：小餐饮可能起送门槛高，水果品质波动比专门水果商大。适合作为补充，不要全押一家。

3. **专门做餐饮水果配送的本地供应商**
   - 适合：每天少量但要求切果、去皮、分装。
   - 省心点：能按餐饮标准做净果、果切、拼盘，按份配送。
   - 注意：一定要确认是否冷链、几点送到、坏果怎么赔、临时加单能不能接。
   - 如果你们要做果盘、免费水果、套餐配水果，这类最省心。

4. **附近大型水果店/连锁店谈长期供货**
   - 适合：量很小，比如每天5-20斤。
   - 省心点：店就在附近，临时缺货能补，质量肉眼可见。
   - 注意：价格通常比批发市场高，但省时间、省损耗。可以谈“每天固定送”或“自提留货”。

5. **社区团购/美团优选等**
   - 只适合极少量、非核心出品。
   - 不建议作为餐饮主供应商：品质不稳定、无法按成熟度定制、售后和时效不可控。

**最省心的组合建议：**
- 主供应商：本地批发市场固定档口，或餐饮水果配送商。
- 备用供应商：附近水果店/生鲜平台。
- 每天固定时间发第二天的清单，固定规格、固定送货时间、固定结账周期。
- 先试一周：看准时率、坏果率、是否缺斤少两、临时补货响应。

**选供应商时重点问这几句：**
- 每天最少送多少？起送价多少？
- 能不能按我要求的成熟度、大小、品种送？
- 坏果、压伤、不熟怎么赔？拍照就赔还是退货？
- 几点前下单，几点送到？
- 能不能临时加单？节假日送不送？
- 能不能开票？月结还是现结？

**如果你们量真的很小：**
优先找**附近水果店长期留货+自提/顺路送**，比找批发商更现实。量小的时候，批发商不一定愿意稳定服务，生鲜平台又容易起送不够。

一句话：**少量水果最省心的不是找大平台，而是找本地能小批量、固定送、坏果包赔的固定供应商；最好再留一个附近水果店做备用。**
