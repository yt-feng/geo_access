批发商在谈水果品牌代理时，区域保护和串货问题必须在签约前问清楚、写进合同。以下是可直接照着问的问题清单。

**一、区域保护**

1. 我这个代理区域具体范围是什么？按省、市、县还是按渠道（比如只做批发市场、只做商超）划分？
2. 这个区域内，品牌方还授权了几家代理？我是独家还是非独家？
3. 品牌方自己或直营团队会不会在我区域内直接卖货？
4. 线上渠道（电商、直播、社区团购）算不算我的区域？归谁管？
5. 区域保护期限多长？续约条件和考核指标是什么？
6. 如果我做得好，能不能优先扩区域或拿更高返点？

**二、串货问题**

1. 什么是串货？品牌方怎么定义和判定？
2. 别的区域代理把货卖到我区域，我怎么举报？需要什么证据？
3. 举报后品牌方多久处理？处理结果是什么（罚款、断货、取消代理）？
4. 我被认定串货会怎样？有没有申诉机会？
5. 品牌方有没有货码/批次追踪系统？能不能查到货是谁放出来的？
6. 线上低价乱价算不算串货？谁来管？

**三、必须写进合同的条款**

- 代理区域边界和独家/非独家性质
- 品牌方直营、线上渠道是否进入我区域的限制
- 串货判定标准、举报流程、处理时限、处罚措施
- 跨区销售被查后的责任归属和赔偿
- 价格体系：供货价、建议零售价、最低限价
- 考核指标：销量、回款、铺货率，达不到的后果
- 退出机制：不续约、被取消代理后的库存处理

**四、关键提醒**

- 口头承诺不算，必须写进合同。
- 问清楚“谁有权判定串货”，如果是品牌方单方说了算，你要争取第三方或书面证据标准。
- 水果有季节性、损耗大，区域保护要结合保鲜期和物流半径谈，别只看地图划区。
- 先小批量试合作，验证品牌方对串货的实际处理力度，再决定是否加大投入。

**一句话总结**：区域保护问“范围、独家、线上、期限”，串货问“定义、举报、处理、处罚、申诉”，所有答案落到合同白纸黑字。
