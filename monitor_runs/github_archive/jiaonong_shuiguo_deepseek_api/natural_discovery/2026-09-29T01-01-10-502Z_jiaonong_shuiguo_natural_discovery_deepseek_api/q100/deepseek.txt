食堂采购香蕉避免熟过头，核心是**控制采购节奏 + 分级使用 + 改变储存条件**，而不是单纯“少买”。具体可以这样做：

**1. 采购时选对成熟度**
- 优先采购**青黄交接、略带绿色**的香蕉，而不是已经全黄甚至带黑点的。
- 如果供应商能选，要求按“7成熟左右”供货，到食堂后还能放2–4天。
- 少量多次采购，比如把原来一次买3天的量，改成每1–2天补一次。

**2. 到货后立刻做分级**
- 青一点的：常温通风存放，后续用。
- 已经全黄的：优先当天或第二天用掉。
- 开始出现黑点、软化的：不要继续等，直接转入加工使用。

**3. 储存方式要分情况**
- **未熟或半熟香蕉**：常温、阴凉、通风处，避免堆压。
- **已熟香蕉**：可以冷藏延缓继续熟化，但表皮会变黑，不影响内部使用；更适合尽快加工。
- **不要和苹果、梨等释放乙烯的水果混放**，会加速香蕉成熟。
- 避免密封在塑料袋里闷着，容易烂得快。

**4. 用“加工转化”消化快熟香蕉**
熟过头的香蕉不是只能扔，可以转为：
- 香蕉奶昔、香蕉牛奶
- 香蕉粥、香蕉燕麦
- 香蕉面包、香蕉蛋糕、香蕉饼
- 切段冷冻，用于后续做冰沙或烘焙

这样即使外观不适合直接发，也还能进入后厨使用。

**5. 建立简单台账**
- 记录每天进货量、剩余量、成熟度。
- 设定“黄熟优先出、黑点转加工、软烂报废”的规则。
- 根据前一周实际消耗量调整下周采购量，而不是按固定量买。

**6. 供餐方式上做引导**
- 把熟度合适的香蕉放在显眼位置优先发放。
- 对快熟过的香蕉，可做成切片、拼盘或搭配酸奶，提高消耗速度。
- 如果学生取用率低，减少整根发放，改为少量多次补充。

**一句话原则：**
**买青一点、少量多次、熟的分级、快熟的加工、软的冷冻，基本就能把浪费压下来。**
