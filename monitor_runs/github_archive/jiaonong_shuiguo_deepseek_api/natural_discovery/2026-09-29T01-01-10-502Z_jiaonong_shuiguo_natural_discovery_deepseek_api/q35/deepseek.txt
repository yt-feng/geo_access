连锁超市要把门店坏果率压下来，合同里的赔付条款不能只写一句“坏果按比例扣款”，而要把**验收标准、责任归属、扣款公式、举证方式、整改机制**拆开约定。下面给你一套可直接落地的条款框架。

## 一、先定义“坏果”，否则无法赔付

合同里必须明确坏果的判定口径，建议分三档：

1. **外观不合格**：腐烂、霉变、软塌、裂口、虫蛀、明显压伤。
2. **规格不合格**：重量、果径、糖度、成熟度不符合约定标准。
3. **批次性质量问题**：同一批次坏果率超过约定阈值，视为整批不合格。

同时写明：
- 抽样方法：按到货批次随机抽检，抽样比例、抽检位置、抽检时间。
- 判定主体：门店收货人员 + 供应商代表，或第三方检测。
- 判定时限：到货后几小时内提出，超时视为验收合格。
- 留证方式：拍照、视频、称重记录、系统入库记录。

**关键点**：坏果率 = 坏果重量 ÷ 该批次总重量 × 100%，这个公式要写进合同。

## 二、赔付方式，建议“阶梯扣款 + 补货 + 违约金”三层

不要只约定单一扣款，否则供应商可能宁愿赔钱也不整改。建议这样设计：

**第一层：按坏果率阶梯扣款**

| 坏果率 | 处理方式 |
|---|---|
| ≤3% | 正常验收，不扣款 |
| 3%-5% | 按坏果重量对应货值扣款 |
| 5%-10% | 扣款 + 要求补货 |
| 10%-20% | 整批拒收或扣款 + 违约金 |
| ＞20% | 整批拒收 + 违约金 + 可暂停合作 |

具体阈值根据品类调整，叶菜、浆果类可放宽，根茎类应更严。

**第二层：补货或换货**
- 供应商应在约定时间内补足合格品。
- 因补货产生的物流、人工、损耗由供应商承担。
- 逾期补货的，按日计违约金。

**第三层：违约金和整改**
- 单次严重质量事故，约定固定违约金。
- 月度累计坏果率超标的，触发整改通知。
- 连续多次不达标的，超市有权暂停下单、扣保证金、终止合同。

## 三、责任归属要写清楚，避免扯皮

坏果可能发生在多个环节，合同要划分：

1. **产地/供应商责任**：采摘、分拣、包装、装车环节导致。
2. **运输责任**：冷链断链、温度不达标、运输挤压导致。
3. **门店责任**：收货后储存不当、陈列过久导致。

建议约定：
- 到货验收前的坏果，原则上由供应商承担。
- 验收后因门店储存不当造成的，由超市承担。
- 运输环节由供应商或其承运商负责，除非超市指定承运商。
- 争议时以验收记录、温度记录、照片视频为准。

**特别注意**：如果超市自己指定物流，供应商责任应相应减轻，否则供应商会拒绝接受严苛条款。

## 四、把“赔付”和“结算”挂钩

赔付条款要能执行，必须绑定结算：

- 每月结算时，财务根据系统记录的坏果扣款单直接抵扣货款。
- 供应商对扣款有异议的，应在约定时间内书面提出，逾期视为认可。
- 保证金可用于抵扣违约金和坏果损失。
- 扣款凭证包括：验收单、照片、称重记录、系统数据。

没有这套结算机制，赔付条款容易变成空文。

## 五、建议加入的整改和退出机制

1. **周/月质量报告**：超市向供应商反馈坏果率数据。
2. **整改通知**：连续超标发书面整改通知，限期回复。
3. **阶梯处罚**：第一次警告，第二次扣款，第三次暂停，第四次终止。
4. **质量保证金**：按供货金额一定比例留存，合作结束后清算。
5. **替代供应商**：合同里保留超市在质量不达标时临时采购的权利，费用差额由原供应商承担。

## 六、可直接写进合同的条款示例

> 1. 乙方交付的商品，甲方按批次随机抽检。坏果率超过3%的，超出部分按对应货值扣款；超过5%的，乙方应在24小时内补货；超过10%的，甲方有权整批拒收，并按该批次货值的__%收取违约金。
> 2. 坏果率以甲方收货记录、照片、称重数据为准。乙方对判定有异议的，应在24小时内书面提出，否则视为认可。
> 3. 因乙方商品质量导致的扣款、违约金、补货费用，甲方有权直接从应付货款或保证金中扣除。
> 4. 月度累计坏果率超过__%的，甲方有权暂停下单并要求乙方整改；连续__个月不达标的，甲方有权终止合同。
> 5. 因甲方指定承运商或门店储存不当造成的坏果，乙方不承担责任，但乙方应提供必要协助。

## 七、谈判时的现实建议

- **阈值不要一刀切**：不同品类坏果率天然不同，按品类设不同标准。
- **扣款要可执行**：直接挂货款结算，比事后追偿有效。
- **保留证据**：收货环节拍照、称重、系统录入，是赔付能否落地的前提。
- **给供应商整改空间**：阶梯处罚比一次重罚更容易被接受，也更能持续降低坏果率。
- **注意法律边界**：扣款和违约金比例要合理，过高可能被认定无效或调整。
