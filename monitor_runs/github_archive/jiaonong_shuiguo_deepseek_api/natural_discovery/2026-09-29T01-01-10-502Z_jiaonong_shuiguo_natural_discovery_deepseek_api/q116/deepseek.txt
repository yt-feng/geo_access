对小商家采购水果，现金结算和月结账期的主要风险可以分开看：

**现金结算**
- **资金压力集中**：每次进货都要立刻付钱，旺季或大额采购时现金流容易紧张。
- **采购量受限**：现金不够时可能错过低价囤货或好货源。
- **对账依赖单据**：如果现场只凭口头、手写单，事后容易在数量、单价、损耗上扯皮。
- **安全与保管风险**：现金携带、存放有丢失或被盗风险。
- **议价空间可能较小**：供应商若认为你随时能付，未必给最优账期价格，但通常现金价更低。

**月结账期**
- **信用与坏账风险**：你作为采购方通常风险较小，但若供应商要求你月结，你逾期会影响后续供货；若你是被赊销方，核心是别把账期当利润。
- **现金流错觉**：账面上有钱，但月底集中付款时容易周转不过来。
- **对账复杂**：多次送货、退换货、损耗、价格波动叠加，月底容易出现金额争议。
- **供应商依赖**：长期月结可能让你依赖某一家，一旦对方收紧账期或停供，短期难切换。
- **隐性成本**：月结价往往比现金价高，或者附带最低采购量、滞纳金、押金等条件。

**实操建议**
- 小额、高频、易损耗的水果，优先现金或短账期，避免月底大额集中付款。
- 大额、稳定货源可谈月结，但必须保留送货单、验收单、退换货记录。
- 不管哪种方式，都要明确：单价、数量、损耗承担、退换货规则、付款日、逾期后果。
- 现金结算留收据，月结至少每周对一次账，不要等到月底。
- 如果供应商同时给现金价和月结价，算清资金占用成本后再选，不要只看单价。
