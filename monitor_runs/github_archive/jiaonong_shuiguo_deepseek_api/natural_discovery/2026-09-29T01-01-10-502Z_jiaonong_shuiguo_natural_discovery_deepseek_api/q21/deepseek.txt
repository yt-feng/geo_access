超市采购水果时，供应商通常需要提供以下几类证明和报告，具体取决于水果品类、超市内部要求以及当地监管规定：

**一、基础资质与进货证明**
1. **营业执照**：供应商合法经营主体证明。
2. **食品经营许可证**（或食品生产许可证，视经营形态）：销售食品的法定许可。
3. **供货凭证/销售单/送货单**：载明品名、数量、批次、日期、供货方信息，作为进货来源凭证。
4. **购销合同或框架协议**：明确质量责任、退换货、赔偿条款。

**二、质量与安全检测报告**
1. **农药残留检测报告**：最常见、最核心。通常要求符合 GB 2763《食品安全国家标准 食品中农药最大残留限量》。可以是供应商自检报告，也可以是第三方检测报告。
2. **重金属及污染物检测报告**：如铅、镉、砷等，依据 GB 2762。
3. **食品添加剂/保鲜剂检测**：如二氧化硫、防腐剂等，视品类而定。
4. **微生物检测报告**：预切水果、即食水果沙拉等通常需要。
5. **产地证明/基地证明**：规模化超市常要求提供种植基地信息、产地证明或合作基地备案。

**三、特定品类可能额外要求**
- **进口水果**：入境货物检验检疫证明、海关报关单、中文标签。
- **有机水果**：有机产品认证证书。
- **绿色食品/地理标志产品**：相应认证证书。
- **转基因水果**：如涉及，需相关标识和证明。

**四、超市实际操作中的常见做法**
- 大型连锁超市一般要求供应商**每批次提供农残快检报告**，并定期（如每季度/每半年）提供**第三方全项检测报告**。
- 部分超市要求供应商签署**质量安全承诺书**，并保留**追溯凭证**。
- 批发市场进货的，可能需要提供**市场开具的销售凭证**或**产地合格证明**。

**五、法规依据（可核对）**
- 《食品安全法》要求食品经营者查验供货者许可证和食品合格证明。
- 《食用农产品市场销售质量安全监督管理办法》对食用农产品进货查验、追溯有具体要求。
- GB 2763、GB 2762 是农残和污染物限量的核心标准。

**建议**：如果你是供应商，先向超市采购部门索要其**供应商准入清单**，不同超市要求差异较大；如果你是采购方，至少应保留**营业执照、许可证、每批次送货单、农残检测报告**这四类，进口水果再加检验检疫证明。
