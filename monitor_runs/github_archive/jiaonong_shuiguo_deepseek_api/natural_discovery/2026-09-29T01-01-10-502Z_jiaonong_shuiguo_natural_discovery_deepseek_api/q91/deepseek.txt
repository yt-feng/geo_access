优先选 **小把（3～5根）为主，单根做补充，整袋谨慎少量试销**。理由和建议如下：

1. **小把最匹配便利店场景**
   - 便利店客群多是即买即吃、1～2人份。
   - 3～5根刚好一两次吃完，不易浪费。
   - 比单根更有客单价，比整袋更容易决策。

2. **单根适合做流量和搭售**
   - 适合早餐、临时充饥、搭配酸奶/面包/咖啡。
   - 建议放在收银台附近或鲜食区，做“顺手买一根”。
   - 缺点是损耗高、客单价低，不能作为唯一规格。

3. **整袋只适合特定门店**
   - 社区店、家庭客多、晚上下班买菜场景强的店，可以少量上。
   - 写字楼、商圈、学校店通常不适合，买整袋的人少。
   - 整袋要控制库存，避免熟度上来后集中报损。

4. **更细的执行建议**
   - 主力规格：小把 3～5 根，定价看当地香蕉零售价，通常比整袋单价略高。
   - 辅助规格：单根，放在高频动线。
   - 测试规格：整袋先按小批量试，观察3～7天动销和报损。
   - 熟度管理：便利店不要上太生的香蕉，最好到店即可吃；同时避免一次性全熟。
   - 陈列：香蕉怕压，最好挂陈或单独浅盘陈列，不要堆在底部。

5. **判断标准**
   - 如果单根日销高、小把动销也高：保留单根+小把。
   - 如果小把卖得最好：扩大小把，减少单根。
   - 如果整袋连续几天动销差或报损高：下架或只接受预订。

结论：**便利店上香蕉，优先小把，单根补位，整袋试销。**
