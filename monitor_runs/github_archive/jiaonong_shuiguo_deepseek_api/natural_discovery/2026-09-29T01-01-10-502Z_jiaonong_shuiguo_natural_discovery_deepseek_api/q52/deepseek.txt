采购香蕉时，想避免到店后很快变黑，关键是从**采购成熟度、运输存放、后厨管理**三方面控制。可直接按下面做：

1. **不要买全熟蕉**
   - 到店后还要放 1–3 天：买 **微黄、带一点绿头** 的香蕉。
   - 当天或次日就用：买 **黄中带少量绿**。
   - 已经出现黑点、果柄发黑、香味很浓的，适合立刻做香蕉泥/烘焙，不适合再存放。

2. **按用途分开买**
   - 做装饰、切片：要偏生一点，耐放。
   - 做奶昔、香蕉泥、烘焙：可以买熟一点的，但当天处理。
   - 不要一次全买同一成熟度，最好分 2–3 个批次。

3. **采购时检查果柄和伤口**
   - 果柄发黑、发霉、流汁的不要。
   - 有明显压伤、裂口、碰伤的不要，这些地方会先变黑并传染。
   - 整串比散装更耐放，散装蕉更容易因伤口快速坏。

4. **运输别闷、别压、别晒**
   - 用透气筐，不要用密封塑料袋长时间装。
   - 避免叠压，香蕉受压后很快出黑斑。
   - 夏天避免后备箱高温闷放，冬天避免冷风吹。

5. **到店后立即分拣**
   - 先挑出压伤、裂口、过熟的，优先用完或冷藏做加工。
   - 好蕉不要洗，表面有水会加速腐烂。
   - 保持果柄完整，不要提前掰散。

6. **存放位置很重要**
   - 放在 **阴凉、通风、避光** 处，理想约 12–15℃。
   - 不要放冰箱冷藏室长期存，香蕉皮会很快变黑；如果只是延缓内部成熟，可短期放较凉区域，但皮色仍可能变差。
   - 不要和苹果、梨、番茄等释放乙烯的水果放一起，会催熟。
   - 可以和其他水果分开，减少互相催熟。

7. **用物理方法延缓**
   - 果柄用保鲜膜包一下，可减少乙烯从果柄释放，但果身不要密封。
   - 悬挂存放，减少受压。
   - 大量采购时可分小批，不要全部堆在一个箱子里。

8. **建立“先进先出”规则**
   - 每次到货贴日期标签。
   - 先熟先用，后熟后用。
   - 每天检查一次，发现黑点蕉立即转做香蕉泥、奶昔、蛋糕等，不要等它影响整串。

9. **如果已经快熟透**
   - 立即去皮、切段、冷冻，做奶昔或烘焙原料。
   - 或做成香蕉果酱、香蕉泥，加少量柠檬汁延缓氧化。
   - 不要继续和好蕉混放。

简单判断标准：
- **想放 2–3 天**：买绿头微黄、果柄青绿、无伤的。
- **想放 1 天**：买黄中带绿、无黑点的。
- **当天用**：买成熟但无腐烂的。
- **到店后越快变黑，通常说明采购时已过熟、有压伤、温度高或和催熟水果混放。**

最有效的组合是：**买偏生一点 + 不压不闷 + 阴凉通风 + 不和苹果梨混放 + 每天分拣先进先出。**
