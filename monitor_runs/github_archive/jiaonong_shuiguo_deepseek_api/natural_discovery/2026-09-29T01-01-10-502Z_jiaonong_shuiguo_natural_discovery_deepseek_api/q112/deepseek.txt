水果采购合同里的坏果率赔付阈值**没有统一法定标准**，主要靠合同约定。实践中可按以下规则把握：

**1. 常见合同约定区间**
- **3%以内**：多数视为合理自然损耗，一般不赔。
- **3%～5%**：可要求按比例扣款或补货。
- **超过5%**：通常可要求赔付、退货或换货。
- **超过10%**：一般可认定为重大质量问题，可拒收、解除合同并索赔。

**2. 影响阈值的因素**
- 水果种类：浆果类（草莓、蓝莓）易损，阈值可放宽到5%～8%；苹果、柑橘等耐储运的，可压到3%以内。
- 运输距离和方式：长途冷链 vs 短途常温，标准不同。
- 是“到货验收”还是“入库后验收”：后者坏果率可能因存放上升，需明确责任节点。
- 是否约定“自然损耗”与“腐烂变质”分开计算。

**3. 建议写进合同的关键条款**
- 明确验收时间点（如到货后24小时内）。
- 明确抽检比例和方法（如每批随机抽10%）。
- 分档约定：
  - 坏果率≤3%：正常接收；
  - 3%＜坏果率≤5%：按坏果重量扣款；
  - 5%＜坏果率≤10%：扣款+补货；
  - ＞10%：拒收或解除合同，并赔偿损失。
- 约定赔付计算方式：按坏果重量×单价，或按整批货值一定比例。
- 约定争议检测机构。

**4. 实操建议**
- 不要只写“坏果率超标赔偿”，要写清**超标多少、怎么算、谁承担运费、多久内提出**。
- 首次合作可先定5%作为赔付起点，稳定后再收紧。
- 保留验收照片、视频、物流记录，作为索赔依据。
