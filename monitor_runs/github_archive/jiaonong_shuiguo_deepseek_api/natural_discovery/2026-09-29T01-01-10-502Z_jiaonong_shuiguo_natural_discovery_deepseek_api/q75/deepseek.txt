第一次合作做小批量试单，核心目标不是赚多少利润，而是**用最小成本验证：品质稳定性、损耗率、供货履约能力、结算配合度**。下面按可执行步骤拆解。

## 一、先定试单目标（决定设计方向）

试单要回答4个问题：
1. 到货品质是否稳定达标（不是最好，是稳定）
2. 实际损耗率多少（运输、存放、挑拣后）
3. 对方能否按约定时间、数量、规格发货
4. 售后和结算是否配合（坏果认不认、账期能不能谈）

如果这4点没验证，试单就等于白做。

## 二、品类选择：选“能暴露问题”的品

- **优先选1-2个单品**，不要一次上多个品，否则问题分不清是品的问题还是供应商的问题。
- 选**中等损耗、周转快、有明确分级标准**的品（如苹果、柑橘、香蕉），比选草莓、荔枝这类极难储运的品更公平，也比选土豆、洋葱这类太耐放的品更能暴露问题。
- 如果目标就是做高损耗品，那就直接试高损耗品，但要把损耗预期写进合同。

## 三、批量设计

- **单批不要太大**：以“能覆盖一次真实销售/分货”的最小量为主，通常是你正常单次采购量的 **20%-30%**。
- **建议试2-3批**，而不是只试1批。1批可能是偶然好或偶然坏，2-3批能看出稳定性。
- 每批之间**间隔3-7天**，观察对方持续供货能力。
- 总试单量控制在你能承受“全损也不影响现金流”的范围内。

## 四、规格与验收标准必须提前写死

试单最容易扯皮的就是标准模糊。要在下单前确认：

| 项目 | 要写清楚的内容 |
|---|---|
| 品种/产地 | 具体品种、产区 |
| 规格 | 单果重、直径、箱重、个数 |
| 等级 | 一级/二级比例，允许次果比例 |
| 成熟度 | 几成熟采摘、到货可售期 |
| 包装 | 箱型、内衬、码放方式 |
| 到货温度 | 冷链还是常温 |
| 验收标准 | 抽检比例、坏果判定线 |
| 允收比例 | 例如坏果≤5%，超标怎么赔 |

## 五、验收动作（试单必须做）

1. **到货当场抽检**：至少抽3箱/3个点位，不要只看表面。
2. **分层检查**：底层、中层最容易出问题。
3. **记录数据**：到货总重、挑拣后可用重、坏果重、损耗率、可售天数。
4. **拍照留证**：开箱、坏果、包装、运单。
5. **当天反馈**：把问题发给供应商，看对方响应速度和态度——这比果子本身更能判断能不能长期合作。

## 六、结算与风险控制

- 首单建议**现款现货或小比例预付**，不要一上来给账期。
- 如果对方要求预付，预付比例尽量低，且约定“验收不合格可退/可补”。
- 明确**运费、损耗、坏果赔付**由谁承担。
- 保留一次“补货/换货”的追责机会，测试售后。

## 七、试单结束后的决策

试单后按这几条打分：
- 品质稳定性（2-3批是否一致）
- 实际损耗率 vs 承诺损耗率
- 履约准时率
- 售后响应与赔付执行
- 价格是否有竞争力且可持续

**只要品质稳定、损耗可控、履约靠谱，就可以放大批量；任何一项反复出问题，就不要因为价格便宜而放量。**

## 八、一个简单的试单节奏模板

- 第1批：最小量，验品质和包装
- 第2批：略增量，验稳定性和履约
- 第3批：正常单次量的50%-70%，验持续供货和售后
- 三批通过后再谈长期价、账期、独家或返点

一句话总结：**试单不是试价格，是试“稳定交付能力”。批量要小、批次要多、标准要死、验收要严、结算要稳。**
