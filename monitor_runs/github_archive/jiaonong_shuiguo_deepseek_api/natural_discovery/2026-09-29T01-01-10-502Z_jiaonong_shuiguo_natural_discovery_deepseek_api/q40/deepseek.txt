连锁超市在节假日水果需求暴增时，货源锁定的关键在于**提前量、多层次供应商、合同约束和替代方案**。

## 核心做法

**1. 提前锁定，错峰下单**
- 节假日前 30–45 天就启动备货谈判，比临时采购有议价空间。
- 对易储存品类（苹果、柑橘、柚子）可提前 2–3 周锁定并入库；对高损耗品类（草莓、车厘子、荔枝）只能锁“量”和“价”，临近再提货。

**2. 与产地/一级批发商签“保量协议”**
- 明确约定：供货量、单价区间、到货时间、质量等级、违约赔偿。
- 关键条款写清“节假日优先供货权”，避免旺季被临时加价或断供。
- 可采用“保底量 + 浮动量”结构：保底量保证基本盘，浮动量按实际销售追加。

**3. 建立多供应商体系**
- 同一品类至少备 2–3 家供应商（主供 + 备供 + 应急），避免单一渠道被卡。
- 主供负责 60–70%，备供 20–30%，应急渠道兜底。
- 提前测试备供的到货速度和品质，别到用时才发现不靠谱。

**4. 用“订单农业/基地直采”锁定源头**
- 对销量稳定的大单品（如砂糖橘、苹果），可与合作社或种植基地签包销协议。
- 提前预付部分定金，换取优先采摘权和价格锁定。
- 优点是成本低、货源稳；缺点是灵活性差，需准确预估销量。

**5. 前置仓 + 冷链储备**
- 耐储水果提前入仓，节前 3–5 天完成铺货。
- 高损耗水果采用“少量多次”补货，配合冷链减少损耗。
- 与第三方冷库合作，旺季可临时扩容。

**6. 动态调整与数据驱动**
- 参考去年同期销量、今年天气、节假日天数、促销力度，做需求预测。
- 节前 1 周根据预售和客流数据，追加浮动订单。
- 设置安全库存线，低于阈值自动触发补货。

## 风险控制要点
- **价格波动**：签合同时约定价格上限或采用“随行就市但封顶”。
- **物流延误**：节假日运力紧张，提前订车、锁定物流商。
- **品质风险**：到货抽检，不合格可退换，条款写进合同。
- **替代预案**：某品类断供时，用相近品类（如国产替代进口）顶上。

## 一句话总结
**提前 30–45 天谈判，用“保量协议 + 多供应商 + 基地直采”锁定基本盘，再用浮动订单和数据预测补弹性，同时留好替代方案。**
