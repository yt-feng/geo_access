连锁商超水果供应商招标，评分标准建议围绕“长期稳定供货能力”来设计，而不是单纯比价格。建议总分100分，大致可按以下权重分配：

**一、价格与成本（25–30分）**
- 报价竞争力：15–20分，不只看单价，要比同品类、同规格、同等级的可比价。
- 价格稳定性：5–10分，考察是否承诺一定周期内价格波动范围、调价机制是否透明。
- 账期与结算条件：5分，能否接受商超账期、是否有供应链金融支持。

**二、产品质量与品控（25–30分）**
- 产品符合性：10分，规格、等级、糖度、农残标准是否达标。
- 品控体系：8–10分，是否有质检报告、溯源体系、批次留样、第三方检测。
- 损耗率承诺：5–8分，约定到货损耗上限及赔付方式。
- 样品实测：5分，盲测口感、外观、新鲜度。

**三、供货与履约能力（20–25分）**
- 日/周供应量与峰值保障：8–10分，能否覆盖旺季、节假日、促销增量。
- 冷链与物流：5–8分，仓储、冷链车辆、配送时效、到店准时率。
- 缺货/断供应急方案：5–7分，备用产地、替代品种、补货响应时间。

**四、企业资质与稳定性（10–15分）**
- 种植基地/合作产地：5分，自有基地或长期协议产地优先。
- 财务健康与经营年限：3–5分，避免中途断供风险。
- 证照与合规：3–5分，营业执照、食品经营许可、检疫证明等。

**五、服务与协同（5–10分）**
- 售后响应：3–5分，质量问题处理时效、退换货机制。
- 配合促销与定制：2–5分，能否配合商超做包装、规格、活动档期调整。

**六、加分项（5–10分，可另设）**
- 数字化对接能力：可对接商超ERP、自动补货系统。
- 可持续/社会责任：绿色种植、助农、碳足迹等。
- 长期合作承诺：愿意签2–3年框架协议、共同投资品控。

**关键设置建议：**
1. **价格分不宜过高**，建议不超过30分，否则容易引来低价低质供应商。
2. **设置“一票否决”项**：农残超标、重大食品安全事故、虚假资质，直接废标。
3. **区分“商务分”和“技术分”**：技术分（质量、供货、品控）建议占60%以上。
4. **引入试供期**：中标后先试供1–3个月，试供合格再签长期合同。
5. **动态考核**：合同内约定季度评分，连续两次低于阈值可降份额或退出。

如果你们是区域连锁、门店数在几十家以内，可以适当降低“数字化对接”权重，提高“本地配送时效”和“小批量多频次配送”的分数。需要的话，我可以帮你按具体门店数、品类（如叶菜、浆果、进口果）细化成一版可直接用的评分表。
