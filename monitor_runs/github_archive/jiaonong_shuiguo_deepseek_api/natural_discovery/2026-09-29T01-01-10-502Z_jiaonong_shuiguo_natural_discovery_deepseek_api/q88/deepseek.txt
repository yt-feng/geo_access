线上水果最怕的不是“偶尔坏果”，而是坏果率不稳定 + 口感批次波动。采购端要从“凭经验收货”改成“按标准、按批次、按数据收货”。重点抓这几件事：

**1. 先定分级标准，不要只按产地和价格收**
把每个单品做成可执行的收货标准，至少写清：
- 果径/单果重范围
- 成熟度（几成熟采摘，到仓后几成熟）
- 糖度下限（如柑橘≥11°Brix，具体按品类定）
- 硬度/软果率上限
- 外观缺陷容忍度（裂口、虫眼、压伤、日灼、霉斑）
- 坏果率上限，比如到仓抽检坏果≤3%，超过就拒收或折价

没有标准的采购，最后只能靠售后赔钱。

**2. 按批次抽检，不要只看样品**
供应商送的样品通常是最好的。到货后按批次抽：
- 同一产地、同一采摘日、同一包装线为一批
- 每批随机抽，不要只抽上层和门口
- 记录：坏果率、软果率、糖度、单果重、成熟度、异味
- 连续3批不稳定的供应商，降级或暂停

**3. 控制采摘成熟度和运输温度**
口感不稳定，很多不是品种问题，而是：
- 早采导致糖酸比不够
- 后熟不均匀
- 运输温度波动大
- 堆压导致内伤

采购时要问清：
- 采摘日期和采摘成熟度
- 预冷是否做了，预冷到多少度
- 运输温度记录
- 到仓时间
- 是否有乙烯管理或催熟环节

能提供温控记录的供应商，优先合作。

**4. 用“坏果率+口感”双指标考核供应商**
不要只考核坏果率。口感也要量化：
- 糖度
- 酸度或糖酸比
- 香气/异味
- 肉质（脆、绵、渣感）
- 一致性问题：同一批里甜淡差异大不大

可以每周做盲测，采购、客服、运营一起打分。连续两批口感不达标，就换供应商或换产区。

**5. 包装和物流要按品类设计**
不同水果怕的东西不一样：
- 草莓、蓝莓：怕压、怕闷、怕高温
- 芒果、猕猴桃：怕低温冻伤、怕后熟不均
- 苹果、梨：怕磕碰、怕长期失水
- 柑橘：怕挤压、怕霉变传染

采购时要同步确认：
- 内包装是否防震
- 是否有吸水/透气设计
- 是否单层摆放
- 是否混装导致串味或压伤
- 快递时效是否匹配成熟度

**6. 建立“批次追溯”和售后归因**
每批货要能追溯到：
- 供应商
- 产地
- 采摘日
- 到仓日
- 抽检结果
- 发货订单

这样出现差评时，能判断是采购问题、仓储问题还是快递问题，而不是一律赔钱了事。

**7. 实操上最有效的几个动作**
- 新供应商先小批量试销，不要一上来大货
- 每批到仓必抽检，数据留档
- 设置坏果率红线，超过就拒收/折价
- 对高客诉品类做成熟度分开发货
- 售后差评按批次反查，不按客服感觉处理
- 同一单品至少备2个产区或2个供应商，避免单点波动

一句话：**采购时把“坏果率”和“口感一致性”变成可抽检、可记录、可追责的指标，差评才会从随机变成可控。**
