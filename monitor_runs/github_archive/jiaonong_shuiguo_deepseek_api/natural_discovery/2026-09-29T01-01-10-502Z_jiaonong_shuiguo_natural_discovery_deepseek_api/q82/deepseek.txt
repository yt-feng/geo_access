低价香蕉最大的投诉来源其实不是“便宜”，而是**顾客用正常香蕉的标准去验收**。想避免投诉，核心是三件事：**选对货源、控制成熟度、管理预期**。下面按可执行程度说。

**1. 货源端：低价不等于处理货**
- 专门找产地直发的“青蕉/催熟蕉”，而不是超市挑剩的尾货。尾货皮花、压伤多，再便宜也必投诉。
- 明确跟供应商约定：单根重量、条数/把、允许的伤疤比例。低价可以接受“外观普通”，但不能接受“烂、黑心、断把”。
- 优先选**耐运输、后熟慢**的品种，比如部分巴西蕉、威廉斯蕉，别用太娇气的。

**2. 成熟度：这是投诉高发点**
- 社区团购到货到自提点通常要1-2天，所以**收货时应该是青的或微黄**，让顾客拿回家自己放2-3天。如果到货就全黄，路上必烂。
- 给顾客的提示要写死：“收到偏青，常温放2-4天变黄，别放冰箱。” 这条能挡掉大量“没熟就送来了”的投诉。
- 夏天尤其要控，温度高催熟快，宁可发更青的。

**3. 预期管理：低价要提前说清**
- 商品页别只写“香蕉”，要写清：**规格（几斤/几根）、成熟度（青/微黄）、可能有的外观问题（轻微花皮、大小不均）**。
- 明确“低价原因”：产地直发、需自行催熟、外观不挑。顾客接受了再买，投诉率会明显下降。
- 售后规则前置：比如“轻微花皮不售后，烂心/断把包赔”，写清楚反而减少扯皮。

**4. 履约细节**
- 分装时把明显坏的挑出来，别混进去，一颗烂蕉会毁一单口碑。
- 自提点别堆在太阳下或闷箱里，通风、阴凉存放。
- 到货当天尽量通知取货，减少在自提点滞留时间。

**5. 售后兜底**
- 设置简单的赔付标准：坏几根赔几根，或整单退，别让顾客举证太麻烦。低价单的售后成本往往比吵架低。
- 收集投诉原因，如果集中在“没熟”“烂”，就调货源或调成熟度，而不是硬扛。

一句话：**低价可以，但别让顾客觉得“又便宜又差”。把成熟度往后放、把预期往前说、把坏果挑出来，投诉能降一大半。**
