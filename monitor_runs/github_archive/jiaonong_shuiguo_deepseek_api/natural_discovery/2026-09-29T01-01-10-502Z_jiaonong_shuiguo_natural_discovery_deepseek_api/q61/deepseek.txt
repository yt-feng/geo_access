判断批发档口的香蕉供货方稳不稳定，核心看**货源基础、履约记录、风险承受力和合作可控性**。香蕉是典型的“产地集中、催熟周转快、价格波动大”的品类，不能只看对方报价低不低。

**一、先看他的货源根基**
1. **是不是直接对接产地或一级渠道**：稳定供货方通常能说清香蕉来自哪个产区（如云南、广西、海南、老挝、缅甸、菲律宾、厄瓜多尔等），有自己的代办、合作基地或长期产地采购团队。只说“我什么货都有、全国发货”的，多数是中间倒手。
2. **有没有催熟能力或固定催熟档口**：香蕉到批发环节通常要经过催熟。对方如果有自己的催熟库、稳定合作的催熟档口，说明他能控制出货节奏和品质，不是完全靠临时抓货。
3. **季节性产区切换能力**：香蕉产区有淡旺季。稳定的供货方会在不同季节切换产区，能解释“现在主发哪里、下个月切哪里、为什么”。讲不清季节切换的，断供风险高。

**二、看履约和交付表现**
1. **历史履约记录**：让他提供近几个月的发货记录、装车视频、磅单、物流单。重点看是否连续、是否长期固定线路。
2. **答应你的量能不能持续兑现**：可以先用小批量试单，连续下3—5次，观察每次到货时间、数量、品质是否稳定。一次好不代表稳定，连续稳定才算。
3. **装车和物流是否可控**：稳定供货方通常有固定车队或长期合作物流，能告诉你大概几点装车、几天到、走哪条线。临时找车、反复改时间的，履约风险大。
4. **坏货和售后怎么处理**：香蕉运输中容易受温度、挤压、催熟影响。提前问清：短斤少两、青黑、烂柄、夹生怎么赔，是否补货，响应时间多久。敢明确承诺并实际执行的，更可靠。

**三、看价格和账期是否合理**
1. **报价是否跟行情联动**：香蕉价格波动大，稳定供货方会按产地行情、等级、催熟状态报价，而不是长期报一个明显低于市场的死价。低于行情太多，往往是用低价钓单，后面以次充好或断供。
2. **是否愿意谈账期或定金比例**：一手货源如果实力稳，通常能接受合理定金、货到验货、部分账期等安排。要求全款预付、且不愿提供任何凭证的，要谨慎。
3. **能不能接受验货和视频看货**：稳定供货方不怕你看货。装车视频、催熟库视频、磅单、质检照片都能提供。总是推脱的，风险高。

**四、看风险承受和合作意愿**
1. **有没有固定经营场所和主体**：档口、仓库、催熟库、营业执照、长期工人，这些都是稳定性的信号。纯线上、无固定场所、只靠个人微信转账的，抗风险能力弱。
2. **愿不愿意签简单供货协议**：哪怕不是正式合同，也要有品名、等级、数量、价格、交付时间、验收标准、赔付方式的书面确认。愿意签的，通常更规范。
3. **是否只做你一单**：稳定供货方会关心你的档口销量、走货速度、结算习惯，愿意和你排长期计划。只催你打款、不关心后续的，多半是做一次性生意。

**五、实操验证方法**
1. **小单试三次**：第一次少量，第二次加量，第三次故意要求调整到货时间或等级，看对方响应和兑现。
2. **突击看货**：有条件就去他的档口、催熟库或装车现场看，重点看库存、工人、装车流程是否正常。
3. **问同行**：在批发市场里打听这个供货方的口碑，尤其是坏货处理、断供记录、结账是否扯皮。
4. **查物流和磅单**：连续几次核对物流单、磅单、装车视频是否一致，防止“转手拼货”冒充一手。
5. **留备用渠道**：即使找到稳定供货方，也要同时维持1—2个备用货源。香蕉行情和产区变化快，单一渠道风险大。

**简单判断标准：**
- 能说清产地、催熟、季节切换；
- 能连续小批量稳定交付；
- 敢提供装车、磅单、售后承诺；
- 报价跟行情走，不异常低；
- 有固定场所和主体，愿意签简单协议。

满足这些，基本可以判断为相对稳定的供货方。只满足“价格低、马上有货、全款预付”的，不建议直接当主力货源。
