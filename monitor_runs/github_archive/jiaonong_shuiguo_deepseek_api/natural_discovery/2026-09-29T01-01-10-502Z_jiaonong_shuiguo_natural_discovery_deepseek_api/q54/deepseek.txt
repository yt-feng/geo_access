优先看成熟度，但要用“用途”来决定成熟度标准，价格排第二。

**判断规则：**

1. **做香蕉磅蛋糕、香蕉马芬、香蕉面包**
   - 优先选**熟透、表皮有黑点、果肉软甜**的香蕉。
   - 这种香蕉甜度高、香气足，还能减少糖量，成品更湿润。
   - 如果只是少量黑点、没有腐烂，最适合烘焙。

2. **做装饰、夹心、慕斯、果肉丁**
   - 选**七八成熟、外形完整、不过软**的香蕉。
   - 太熟容易出水、发黑、塌陷，影响卖相和口感。

3. **做香蕉泥、冷冻果泥、批量蛋糕胚**
   - 可以用**熟度较高但未腐烂**的香蕉，性价比通常更好。
   - 但必须现场检查：果肉是否发酸、发黑、渗水、有酒味。

**采购时怎么判断：**
- 看：表皮黄中带黑点，但无大面积黑斑、霉点、裂口。
- 摸：轻按有弹性，不是硬邦邦，也不是一按就烂。
- 闻：有浓郁香蕉香，无酸味、酒味、发酵味。
- 切开：果肉乳白或淡黄，中心不发黑、不水化。

**价格什么时候优先？**
只有在以下情况才更看价格：
- 当天就要打成泥、马上高温烘焙；
- 熟度只是偏熟，没有腐烂；
- 供应商稳定，能保证到货后 1—2 天内用完；
- 你做的是重口味蛋糕，香蕉只是辅料，不是主要风味来源。

**建议采购标准：**
- 主风味香蕉蛋糕：成熟度优先，选带黑点的熟蕉。
- 装饰用香蕉：成熟度优先，选完好、七八成熟。
- 批量打泥：成熟度合格的前提下比价。
- 任何已经腐烂、发酸、渗水的香蕉：再便宜也不要买。

一句话：**先定用途，再定成熟度；成熟度不合格，价格再低也不划算。**
