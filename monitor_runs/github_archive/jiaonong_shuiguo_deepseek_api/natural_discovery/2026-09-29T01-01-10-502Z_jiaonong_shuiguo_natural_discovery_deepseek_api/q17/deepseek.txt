社区超市做水果，核心就一句话：**把“进货”从凭感觉改成按数据补货，把“鲜度”从靠人盯改成按时间节点处理。**下面给你一套能直接落地的做法。

**一、先定品类策略，别所有水果一个管法**

把水果分成三类，管理方式完全不同：

| 类型 | 例子 | 策略 |
|---|---|---|
| 引流款 | 香蕉、苹果、橘子 | 少量高频补，允许微利甚至平价，保证常来有人气 |
| 利润款 | 车厘子、草莓、蓝莓、阳光玫瑰 | 按订单/预售走，宁缺勿压，损耗不起 |
| 走量款 | 西瓜、哈密瓜、应季大单品 | 看天气和周末，集中上、快速清 |

关键：**利润款绝不留库存过夜**，当天没卖完当天处理掉，不然损耗直接吃掉利润。

**二、库存控制：按“天数”而不是按“箱数”进货**

1. **先测真实销量**：连续记2周，每天每个单品卖了多少斤/盒。没有这个数，后面全是猜。
2. **设定安全库存天数**：
   - 叶菜类、草莓、蓝莓：0.5～1天
   - 香蕉、葡萄、桃子：1～1.5天
   - 苹果、橙子、柚子：2～3天
3. **补货公式**：
   订货量 = 预估日销 × 安全天数 − 现有库存 − 在途
   预估日销要乘一个天气/周末系数：下雨天叶菜降30%，周末走量款加50%。
4. **少量多次**：宁可一天补两次，也不要一次进三天的货。社区店离批发市场近的话，这点最容易做到。

**三、鲜度控制：给每个单品定“时间节点”**

不是等坏了才处理，而是到点就动作：

- **上架当天**：正常价，摆最好位置。
- **第2天**：挑出次果，做“特价筐”或切果盒，价格降20%～30%。
- **临期/软化**：立刻转成果切、果汁、拼盘，或者绑赠（买满送）。
- **当天闭店前**：还卖不动的，直接打折清，别留到明天——**留过夜=第二天更卖不掉**。

具体动作：
- 叶菜、草莓类：**当天清**。
- 香蕉：单独放，别和苹果、梨放一起（乙烯催熟），夏天可冷藏延缓。
- 切开的瓜果：必须冷藏+当天卖完，不隔夜。

**四、减少压货的三个硬手段**

1. **预售/接龙**：微信群提前一天接龙，按单进货，几乎零损耗。社区店最适合这招。
2. **组合销售**：果切盒、水果拼盘、酸奶水果杯，把次果变成高毛利品。
3. **动态定价**：上午原价，下午3点后打折，晚上清仓。用价格换周转，比烂掉强。

**五、每天必做的3件事（10分钟搞定）**

1. 早上收货：当场验货，坏果直接退/拒收，别不好意思。
2. 中午巡场：挑出软化、碰伤的，转到特价或果切。
3. 闭店盘点：记录每个单品剩多少、扔了多少。**损耗率超过10%就要查原因**（进多了？定价高了？摆放不对？）。

**六、一个简单判断标准**

- 如果某个水果**连续3天都剩**，说明进货量或定价有问题，下批直接减半。
- 如果某个水果**经常断货**，说明进少了，加20%试一周。
- 目标：**叶菜类当天清空，利润款不过夜，走量款2天内周转完。**

按这个做，社区超市水果损耗能压到5%～8%，比行业平均低不少，货也不会压在店里。核心就是：**数据定进货，时间定处理，价格换周转。**
