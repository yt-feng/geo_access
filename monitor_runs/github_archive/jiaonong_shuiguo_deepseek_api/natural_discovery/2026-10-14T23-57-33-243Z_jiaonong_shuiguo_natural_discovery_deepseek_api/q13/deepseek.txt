小水果店做附近小区团购，供应商至少要能支持这几类服务，否则你后面容易卡在货源、损耗、配送和售后上。

**1. 稳定供货与每日报价**
- 能每天或提前一天给报价单，最好有图片、规格、产地、箱重。
- 支持你按团购量订货，不是只做大宗批发。
- 旺季、节假日、天气异常时还能相对稳定供货。
- 能告诉你哪些品今天适合做团购，哪些容易翻车。

**2. 小批量、多品类混批**
- 小区团购通常不是一次只要一两种水果，而是苹果、香蕉、橙子、葡萄、应季品搭配。
- 供应商要支持混批，单品类起订量别太高。
- 最好能按小箱、小件、半件起配，降低你压货风险。

**3. 分拣、打包和标品化**
- 能不能帮你按团购订单分拣成“每份几斤”“每袋几颗”。
- 能不能贴标签、装袋、装箱，甚至按小区订单分好。
- 品相要相对统一，否则团购用户收到大小不一、熟度不一，投诉会很多。

**4. 质量分级与售后保障**
- 明确分级标准：大果、中果、小果，精品、普通、处理果。
- 坏果、烂果、压伤、少重怎么赔，必须有规则。
- 最好支持拍照理赔、补货、退款或下次抵扣。
- 生鲜损耗高，没有售后兜底，你很容易白忙。

**5. 配送支持**
- 能送到你店里，或送到指定小区自提点。
- 能按你要求的时间段配送，比如团购截单后次日早上到。
- 冷链或保鲜运输能力要看你卖什么，叶菜类水果、浆果类要求更高。
- 如果供应商能直送小区自提点，会省你很多事。

**6. 包装与耗材支持**
- 提供适合团购的纸箱、塑料袋、网套、泡沫箱、冰袋等。
- 能配合你做统一规格包装，方便团长分发。
- 包装上最好能贴品名、重量、保存方式、售后说明。

**7. 预售与锁价支持**
- 小区团购常先收款再采购，供应商要能接受你提前锁量、锁价。
- 支持截单后统一发货，而不是你边卖边缺货。
- 价格波动大的水果，要提前说清涨跌规则。

**8. 营销与素材支持**
- 提供水果实拍图、短视频、文案、产地介绍、口感卖点。
- 能给你做团购海报或价格表更好。
- 至少能及时告诉你：今天什么值得推、什么不建议推。

**9. 结算灵活**
- 支持现结、周结、月结，或押金合作。
- 能开发票或收据，方便你记账。
- 退换货金额能清楚对冲，不要每次扯皮。

**10. 应急补货和调货**
- 团购爆单时能临时补货。
- 某个品质量不行时能快速换品。
- 附近有仓或中转点，响应会快很多。

**你选供应商时，重点问这8个问题：**
1. 起订量多少？能不能混批？
2. 每天几点报价？价格保留多久？
3. 能不能按份分拣打包？
4. 坏果怎么赔？多久内反馈有效？
5. 送到店还是能送小区？
6. 截单后多久能到？
7. 能不能提供图片文案？
8. 结算方式是什么？

**最适合小水果店做小区团购的供应商，不是价格最低的，而是：**
- 小批量能拿货；
- 品质稳定；
- 售后不扯皮；
- 配送及时；
- 能帮你做标品和素材。

如果只能优先看三项，我建议先看：**售后赔付、分拣打包、配送时效**。这三项直接决定你能不能长期做小区团购。
