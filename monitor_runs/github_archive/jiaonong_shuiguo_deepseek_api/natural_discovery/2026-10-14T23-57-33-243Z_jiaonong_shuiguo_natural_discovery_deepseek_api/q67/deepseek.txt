批发商在谈水果品牌代理时，区域保护和串货是必须提前问清的核心条款，不能等签完合同再补。下面按“问什么、怎么问、看什么”给你一份可直接用的清单。

## 一、先问清楚“区域”到底怎么划

别只问“给我哪个区”，要问具体到可执行的程度：

1. **授权区域范围**：是省、市、还是具体到某几个区县？有没有写明“仅限XX市XX区”？
2. **渠道范围**：只限线下批发市场、商超、还是也包含社区团购、电商、直播？很多串货纠纷就出在“渠道没限定”。
3. **客户范围**：是否允许你供货给跨区域的连锁商超？如果对方总部在外地，算不算串货？
4. **独家还是非独家**：该区域内你是唯一代理，还是厂家还能再放第二家？如果是独家，要写进合同。

**判断标准**：如果对方说“大方向给你，具体再说”，基本等于没有区域保护。

## 二、问串货规则：定义、罚则、执行

串货不是问“允不允许”，而是问“怎么认定、怎么罚、谁来查”。

1. **串货定义**：合同里有没有明确写“未经许可将产品销往授权区域以外”算串货？注意有的厂家把“跨渠道销售”也算串货。
2. **编码追溯**：产品有没有箱码/批次码？能不能追溯到发货区域？没有追溯手段，串货根本查不了。
3. **处罚标准**：扣保证金、取消返利、断货、取消代理权？分别对应什么情节？要问清“首次、二次、严重”的阶梯。
4. **举报与举证**：你发现别人串货进来，向谁举报？多久处理？需要你提供什么证据？厂家不处理怎么办？
5. **误伤条款**：如果你的货被二级批发商转卖到外地，算你的责任吗？合同里有没有“下游客户行为由谁承担”的约定。

**判断标准**：只口头说“我们管”，但合同里没有追溯码、没有罚则、没有处理时限的，区域保护基本是空的。

## 三、问厂家自己会不会“破价”

很多串货其实是厂家自己放货造成的：

1. **厂家直营/电商**：厂家自己有没有开网店、直播带货？价格是否低于给你的供货价？
2. **其他区域代理**：同品牌其他区域代理的拿货价是否和你一样？如果不一样，低价区必然往高价区串。
3. **返利政策**：返利是按量还是按区域？如果按量，大代理为了冲量低价甩货，就会串到你的区域。

**判断标准**：如果厂家自己都在低价出货，区域保护就是一张纸。

## 四、问合同里的“退出与赔偿”

1. **厂家违约**：如果厂家在你区域内又授权别人，或自己直供，你怎么索赔？有没有违约金？
2. **你被认定串货**：申诉流程是什么？能不能先举证再处罚？
3. **保证金**：串货扣多少？什么情况退还？
4. **终止后库存**：代理权终止后，剩余库存怎么处理？能不能继续在区域内清货？

## 五、面谈时可以直接照着问的话术

- “我这个区域的独家授权，能不能写进合同？如果厂家再放第二家，怎么赔？”
- “串货怎么认定？有没有箱码追溯？发现串货后你们多久处理？”
- “如果我的下游客户把货卖到外地，算我串货吗？”
- “厂家自己电商和直播的价格，会不会低于我的供货价？”
- “其他区域代理拿货价和我一样吗？不一样的话怎么防止低价区串过来？”
- “串货处罚是扣保证金还是直接取消代理？有没有申诉机会？”

## 六、最后判断能不能签

满足以下几条再考虑签：
- 区域写死到区县，独家或明确非独家；
- 有追溯码，串货可查；
- 罚则阶梯清晰，有处理时限；
- 厂家自己不乱价、不乱放货；
- 厂家违约有赔偿条款。

如果对方对区域保护含糊、对串货只说“放心”、合同里没有追溯和罚则，建议不要先打款压货，宁可再谈或换品牌。
