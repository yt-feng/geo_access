做水果生意，供应商选得好不好，往往比卖得努不努力更重要。很多人只盯着“价格低不低、货好不好看”，但真正决定能不能长期稳定的，恰恰是那些容易被忽视的细节。下面这些点，建议你在合作前重点考察：

**1. 供货稳定性，而不是单次质量**
- 很多供应商第一次给你发的货很好，第二第三次就开始参差不齐。
- 要问清楚：这个品类他是一手货源还是调货？旺季淡季分别能保证多少量？
- 优先选有自己基地、合作社或长期固定产地的，而不是临时拼货的倒爷。

**2. 损耗率和售后规则**
- 水果必然有损耗，关键是**损耗算谁的**。
- 合作前明确：坏果、烂果、规格不符怎么赔？是补货、扣款还是下次抵扣？
- 有些供应商口头承诺很好，但没写进单据，出问题就扯皮。一定要落到文字或聊天记录里。

**3. 分级标准是否一致**
- “一级果”“精品果”这些词每家定义不同。
- 要确认：是按大小、糖度、色泽还是外观分级？有没有明确的数字标准？
- 标准模糊的供应商，长期合作一定会在验收时产生纠纷。

**4. 结算方式和账期**
- 现结、周结、月结，直接影响你的现金流。
- 有些供应商前期让你赊账，后期突然要求现结，打乱你的资金安排。
- 反过来，如果你长期拖欠，供应商也会在旺季优先把好货给别人。

**5. 物流和到货时效**
- 水果是和时间赛跑。要问：发货地离你多远？用什么冷链？正常几天到？
- 遇到天气、节假日延误，他有没有备用方案？
- 到货时间不稳定的供应商，会让你错过最佳销售窗口。

**6. 是否只做你一个客户**
- 如果供应商同时给附近多家同行供货，旺季时他优先保谁？
- 可以侧面了解他的客户结构，避免自己只是“备胎”。

**7. 价格波动的沟通机制**
- 水果价格随行就市，关键是**调价是否提前通知、是否有依据**。
- 突然涨价、临时加价、看你好卖就抬价的，要警惕。

**8. 人品和履约记录**
- 多问同行、多观察几次小批量合作。
- 看他遇到问题时是主动解决还是推卸责任。这一点比任何合同都重要。

**总结一句：**
选供应商，不要只看“这批货好不好”，要看“长期出问题时他靠不靠谱”。把损耗、分级、售后、账期、时效这几条提前谈清楚、写下来，比单纯压价更能让你长期稳定赚钱。
