判断菠萝供应商能不能稳定按规格送货，核心不是看他“有没有货”，而是看他有没有**稳定的产地组织能力、分级加工能力、冷链履约能力**。茶饮连锁用菠萝通常是鲜果切丁、冷冻果肉、果酱/果茸原料几种形态，判断重点不同，但底层逻辑一致。

下面给你一套可执行的判断框架。

## 1. 先明确你的“规格”是什么

茶饮连锁的菠萝规格通常包括：

- **品种**：如台农、金钻、巴厘、MD2等，不同品种糖酸比、香气、纤维感不同。
- **成熟度**：几成熟采摘，到店后催熟还是工厂加工。
- **果径/单果重**：如单果1.2-1.8斤、1.8-2.5斤等。
- **加工形态**：鲜切丁、冷冻丁、果泥、果茸、糖渍果肉。
- **固形物/糖度**：如Brix≥12、≥14。
- **切丁尺寸**：如10×10mm、15×15mm。
- **包装**：袋装、桶装、真空、IQF冷冻。
- **冷链要求**：鲜果常温还是冷藏，冷冻品-18℃。
- **异物与农残标准**：符合国标及你司验收标准。

如果规格没写到“可验收”的程度，供应商稳定不稳定就无从判断。先有验收标准，再谈供应商能力。

## 2. 看供应商的产地组织能力

稳定送货的前提是稳定原料。

重点问：

- 菠萝来自**自有基地、合作基地，还是市场散收**？
- 基地在哪个产区？广东徐闻、海南、福建、云南，还是进口菲律宾、泰国？
- 是否跨产区调配？比如海南旺季结束切广东，广东结束切进口。
- 一年能供几个月？淡季怎么补？
- 遇到台风、寒潮、病害时，有没有备选产区？

**判断方法：**
要求供应商提供近12个月的**产地采购记录、产区切换计划、淡旺季供应表**。如果他说“全年都能供”，但说不出具体产区衔接，基本不可靠。

## 3. 看分级加工能力

茶饮要的是规格一致，不是一车好果里混小果、青果、烂果。

重点看：

- 是否有**分选线**：按重量、果径、糖度、颜色分级。
- 是否有人工修整、去皮、去眼、切丁。
- 冷冻品是否有IQF单冻设备，还是整块冻后再切。
- 是否有金属探测、X光异物检测。
- 车间是否具备SC食品生产许可，做冷冻/果茸尤其要看。

**判断方法：**
去工厂实地审厂，重点看：
1. 原料区是否按产区/批次分开；
2. 分选标准是否贴在工位；
3. 成品抽检记录是否连续；
4. 不合格品怎么处理；
5. 同一规格连续3批的切丁尺寸、糖度、色泽是否稳定。

如果供应商只是贸易商，没有加工能力，就要看他对上游工厂的控货能力，否则规格波动会很大。

## 4. 看冷链与履约能力

很多供应商不是没货，是**送到你仓库时已经不符合规格**。

重点问：

- 鲜果：采摘后多少小时进冷库？运输温度多少？
- 冷冻品：从工厂到仓、到门店，是否全程-18℃？
- 是否有**温度记录仪**，能否随车提供？
- 自有冷链还是外包？外包车队是否固定？
- 旺季日产能多少？你单店日需求×门店数，他能不能覆盖？
- 紧急加单响应时间多久？
- 缺货时怎么补？赔货还是降级？

**判断方法：**
要求试单，不要只看样品。试单要覆盖：
- 旺季一次；
- 淡季一次；
- 紧急加单一次；
- 连续3批到货验收。

每批记录：到货时间、温度、数量、规格合格率、损耗率、门店投诉。

## 5. 用“小批量连续试单”验证，而不是靠谈判

最有效的方法：

### 第一步：样品确认
封样，双方签字，保留标准样品。

### 第二步：小批量试单
连续3-5批，每批不要太大。按你的验收标准打分：
- 规格合格率≥98%？
- 糖度波动范围？
- 切丁完整率？
- 冷链温度达标率？
- 到货准时率？
- 破损/腐烂率？

### 第三步：压力测试
故意在旺季或节假日附近下一单，看他是否优先保你。
再下一单紧急加单，看他响应速度。

### 第四步：看异常处理
一批货不合格时，他是推诿、拖延，还是24小时内补货、承担损失。这比正常交货更能判断稳定性。

## 6. 合同里要写死的条款

- 规格标准：品种、糖度、果径、切丁尺寸、成熟度、包装。
- 验收方式：到货抽检比例、不合格判定。
- 合格率：如单批规格合格率低于97%拒收或扣款。
- 冷链温度：全程-18℃或0-4℃，温度记录随货。
- 准时率：如月度准时率低于95%触发整改。
- 缺货赔偿：断货影响门店的违约金。
- 产区切换：提前通知，切换后需重新送样确认。
- 追溯：批次号可追溯到产地、加工日期、生产线。

## 7. 快速判断清单

你可以用这8个问题筛供应商：

1. 你的菠萝具体来自哪个产区？全年怎么衔接？
2. 自有基地还是市场收购？占比多少？
3. 有没有分选线和冷冻加工线？
4. 近3个月同一规格的出厂检验记录给我看。
5. 旺季日产能多少？给我供多少？
6. 冷链自有还是外包？温度记录能不能随货？
7. 连续3批不合格怎么赔？
8. 能不能先连续试单3批，按我们的验收标准打分？

如果这8个问题有3个以上答不清楚，基本不能作为稳定供应商。

## 结论

判断菠萝供应商能否稳定按规格送货，关键看四点：

**产地组织能力 + 分级加工能力 + 冷链履约能力 + 异常赔付能力。**

最可靠的方式不是听承诺，而是：
**封样 → 连续试单 → 旺季压力测试 → 异常处理测试 → 合同锁标准。**

能连续3-5批稳定达标，且旺季不断货、异常能补货的，才值得进入茶饮连锁的稳定供应商池。
