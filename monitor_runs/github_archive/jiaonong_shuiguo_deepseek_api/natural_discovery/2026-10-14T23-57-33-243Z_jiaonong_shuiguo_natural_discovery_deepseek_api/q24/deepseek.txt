可以按“入场前资料 + 批次资料 + 检测安排”三层来要，核心是让每批水果都能追溯到来源，并有合规证明或检测依据。

**一、供应商资质类（首次合作/年度更新）**
1. 营业执照  
2. 食品经营许可证或食品生产许可证（按实际经营模式）  
3. 若供应商是种植基地：产地证明、种植主体信息、统一社会信用代码等  
4. 若供应商是批发商/贸易商：上游来源说明、供货基地或合作社名单  
5. 双方签订的采购合同/质量协议，明确农残超标责任、退换货和赔偿条款

**二、批次随货资料（每批都要）**
1. **承诺达标合格证/食用农产品合格证**：很多产地已推行，能作为产地出具的质量安全承诺  
2. **产地证明或购货凭证**：证明这批货从哪来、由谁供  
3. **检测报告**：  
   - 优先要**该批次**的农残检测报告；  
   - 报告应由具备 CMA/CNAS 资质的检测机构出具更稳妥；  
   - 重点看检测项目是否覆盖常见高风险农药，如有机磷、氨基甲酸酯类、拟除虫菊酯类等；  
   - 注意报告日期、样品名称、批次号/产地要与到货一致。  
4. **送货单/销售单**：写明品名、规格、数量、产地、批次、采摘或包装日期  
5. **包装标识信息**：品名、产地、生产者或供应商、生产日期/批号等

**三、检测与抽检安排**
1. 要求供应商提供**近期的第三方检测报告**，但不要只看一份通用报告，最好按批次或按产地定期提供  
2. 超市自己或委托第三方做**入场快检**，重点做农残快检；对高风险品种可提高抽检频次  
3. 对无法提供合格证明或快检异常的批次，应先暂停上架，必要时送法检  
4. 建立供应商档案和批次台账，做到“一批一码/一批一档”，出现问题能快速召回

**四、重点提醒**
- 不要只收“一份年度报告”就长期放行，农残风险跟批次、产地、季节、用药习惯关系很大。  
- 报告要看**项目、限值、结论、资质、批次对应关系**，不是只看“合格”两个字。  
- 如果供应商只能提供复印件或模糊照片，要求加盖公章或提供可核验的电子报告。  
- 对叶菜、豇豆、韭菜、芹菜、草莓、葡萄等高风险品类，建议提高抽检比例。

简单说，提前要的是：**资质 + 合格证/产地证明 + 批次检测报告 + 送货凭证 + 质量协议**。到货后再配合超市自检或第三方抽检，这样对农残抽检风险最可控。
