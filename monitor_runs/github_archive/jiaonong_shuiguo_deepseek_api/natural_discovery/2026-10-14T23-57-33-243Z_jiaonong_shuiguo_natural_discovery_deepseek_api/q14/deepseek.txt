可以，而且大多数水果供应商**是愿意给周末促销支持的**，但支持力度和形式取决于你的采购量、合作稳定性、促销品项、季节和供应商类型。

可以按下面几类去谈：

1. **价格支持**
   - 常见形式：周末专供价、满件返利、爆品补贴、买赠搭赠。
   - 供应商一般更愿意支持：
     - 当季大量上市、容易走量的水果
     - 他们库存压力大的品项
     - 你承诺集中采购、主推位置的品项
   - 不太容易拿到：
     - 稀缺高价水果
     - 你采购量小、合作不稳定
     - 临时到周五才提周末促销

2. **物料支持**
   - 常见形式：海报、价签、爆炸贴、吊旗、帐篷、试吃盒、包装袋、围裙、展架。
   - 品牌型供应商或一级批发商更容易给物料。
   - 本地批发市场档口通常物料少，但可能给价签、纸箱、试吃果。

3. **账期和损耗支持**
   - 有些供应商愿意给：
     - 周末促销品临时赊销
     - 卖不完可换货
     - 损耗补贴
     - 次品补货
   - 这类支持比单纯降价更值钱，但通常只给长期稳定客户。

4. **怎么谈更有效**
   - 提前 3～7 天沟通，不要临时压价。
   - 明确说清：促销时间、主推品项、预计采购量、陈列位置、活动形式。
   - 用“量”换“价”，比如：周末两天集中采购多少箱，要求专供价或搭赠。
   - 可以要求组合支持：价格降一点 + 给海报价签 + 送试吃果。
   - 承诺活动后反馈销量，方便下次继续争取资源。

5. **现实判断**
   - 如果你是长期客户、采购量稳定：大概率能拿到价格或物料支持。
   - 如果你是新店、小量采购：一般能拿到少量物料或搭赠，直接降价较难。
   - 如果供应商本身是二级、三级批发：支持空间小，最好直接找一级批发或产地供应商谈周末爆品。

一句话：**能谈，但要提前谈、用量谈、用主推资源谈。供应商最愿意支持“能帮他出货”的周末促销。**
