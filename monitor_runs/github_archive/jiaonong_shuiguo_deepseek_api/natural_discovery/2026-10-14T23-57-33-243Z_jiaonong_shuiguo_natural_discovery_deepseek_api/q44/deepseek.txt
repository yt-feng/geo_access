判断商超供应商的售后响应是否稳定，核心不是听承诺，而是看“机制+证据+试单”。可以从下面几个方面核查：

**1. 先看合同里有没有可执行的售后条款**
- 是否明确响应时限，比如到货后几小时内反馈、24小时内给处理方案。
- 是否明确赔付或补货标准，比如坏果率超过多少、缺斤少两、成熟度不符怎么赔。
- 是否写明对接人和升级路径，避免只有业务员口头承诺。
- 是否区分“品质问题”和“运输损耗”，防止互相推责。

**2. 用试单验证，而不是一次大单**
- 先下小批量试单，故意覆盖不同环节：正常到货、少量坏果、规格不符、延迟到货。
- 记录从反馈到回复、从回复到解决的实际时间。
- 看对方是主动跟进，还是需要反复催。
- 试单阶段就能看出响应速度和态度。

**3. 查历史履约和售后记录**
- 要求供应商提供近几个月的售后处理记录，比如补货单、赔付记录、客诉闭环记录。
- 向同行或同行采购打听，重点问：出问题时找不找得到人、处理快不快、会不会赖账。
- 看其是否长期给同类商超供货，长期合作通常比临时低价供应商更稳。

**4. 看对接机制是否“去个人化”**
- 如果只有一个业务员能对接，他请假或离职后售后容易断。
- 稳定供应商通常有客服群、售后专线、备用联系人、订单系统工单。
- 可以问：非工作时间出问题怎么处理？业务员离职后谁接手？

**5. 用数据指标判断**
建议给供应商设几个简单指标：
- 首次响应时间：比如2小时内。
- 解决闭环时间：比如24到48小时。
- 补货/赔付执行率：承诺后是否按时执行。
- 重复问题发生率：同类问题是否反复出现。
- 缺货或延迟到货后的主动通知率。

**6. 菠萝和香蕉要分开看**
- 香蕉后熟快，售后重点看到货成熟度、催熟配合、压伤和延迟到货处理。
- 菠萝重点看黑心、烂心、果眼、规格和糖度问题。
- 如果供应商对这两种商品的售后标准说不清，通常响应也不会稳定。

**7. 简单判断信号**
比较可靠的供应商：
- 敢写售后条款。
- 试单出问题能快速补货或赔付。
- 有固定对接群和备用联系人。
- 历史记录能拿得出来。

风险较高的供应商：
- 只口头承诺“有问题找我”。
- 合同回避赔付标准。
- 出问题后推给运输、天气或门店。
- 试单阶段就拖延、失联或要求先撤诉再处理。

实操建议：先小单试，再签短周期合同，把响应时限、赔付标准、对接人和升级路径写进去；连续合作2到3个批次后，再根据实际售后数据决定是否放量。
