针对餐饮客户（茶饮、糖水、烘焙、火锅店、快餐、酒店早餐等），菠萝和香蕉的规格思路是**按用途分级**，而不是按零售“好看”来备货。下面给你一套可直接对照备货的规格建议。

## 一、菠萝

餐饮客户用菠萝，主要分四类用途：**鲜切果盘/沙拉、茶饮果汁、糖水甜品、披萨/烘焙/炒饭**。对应规格如下：

| 用途 | 建议规格 | 理由 |
|---|---|---|
| 茶饮、果汁店 | 单果1.2–1.8斤，成熟度7–8成，果眼浅 | 出汁率稳定，去皮损耗小 |
| 鲜切果盘、沙拉 | 单果1.5–2.5斤，果形圆正，成熟度8成 | 切块整齐，卖相好 |
| 糖水、甜品 | 单果2–3斤，成熟度8–9成 | 甜度高，煮后香气足 |
| 披萨、烘焙、炒饭 | 单果2.5斤以上，成熟度7成左右 | 耐切、耐烤，酸度适中 |
| 高端酒店/自助餐 | 单果1.8–2.5斤，外观干净、无黑心 | 摆盘和鲜切标准高 |

**菠萝备货关键点：**
- 餐饮客户最怕**黑心、水心、果眼深**，损耗会直接吃掉利润。
- 茶饮客户通常更看重**出汁率和甜度稳定性**，不是果子越大越好。
- 如果做鲜切配送，建议直接推**去皮菠萝、菠萝块、菠萝丁**，比卖整果更有粘性。
- 规格上可以分：**小果1.2–1.8斤 / 中果1.8–2.5斤 / 大果2.5斤以上**，让客户按用途选。

## 二、香蕉

餐饮客户用香蕉，主要分：**早餐/果盘、茶饮、烘焙、火锅店免费水果、酒店自助**。香蕉对成熟度非常敏感，规格要按“使用时间”来配。

| 用途 | 建议规格 | 成熟度 | 理由 |
|---|---|---|---|
| 茶饮店（香蕉奶昔、果泥） | 单根120–180g，整箱净重稳定 | 7–8成，到店后2–3天用 | 出泥率高，甜度稳定 |
| 烘焙（香蕉蛋糕、面包） | 单根150–220g | 8–9成，甚至带斑点 | 香气浓，压泥效果好 |
| 酒店早餐、自助餐 | 单根130–180g，外观直、无擦伤 | 7–8成 | 摆盘好看，剥皮完整 |
| 火锅店、快餐免费水果 | 单根120–160g，成本优先 | 7成左右 | 控制损耗，走量快 |
| 鲜切果盘 | 单根150–200g，果形好 | 7–8成 | 切片整齐，不易发黑 |

**香蕉备货关键点：**
- 餐饮客户最怕**到货太熟、当天用不完就发黑**，所以成熟度要按客户使用节奏分。
- 可以分：**青熟蕉7成 /  ready-to-eat 8成 / 烘焙用9成**。
- 茶饮客户通常要**稳定单根重量**，方便按根或按克计价。
- 火锅、快餐客户更看重**单价和耐放**，可以推7成青熟蕉。
- 如果做鲜切或果泥配送，香蕉可以按**去皮香蕉段、香蕉泥**供货。

## 三、建议你先这样备货

如果你刚开始拓展餐饮客户，建议先按下面这个组合试：

**菠萝：**
- 小果1.2–1.8斤：给茶饮、果汁店
- 中果1.8–2.5斤：给鲜切、糖水、酒店
- 大果2.5斤以上：给烘焙、披萨、炒饭

**香蕉：**
- 7成青熟，单根120–160g：给火锅、快餐、免费水果
- 8成熟，单根130–180g：给酒店早餐、鲜切果盘
- 9成熟，单根150–220g：给烘焙、香蕉泥

## 四、和餐饮客户谈的时候，重点问这4个问题

1. **你主要拿来做啥？** 鲜切、榨汁、烘焙、免费水果，规格完全不同。
2. **你希望到货后几天用完？** 决定香蕉成熟度和菠萝熟度。
3. **你要整果还是加工品？** 去皮、切块、切丁、果泥，利润和粘性更高。
4. **你每天用量大概多少？** 用量稳定的客户，可以谈固定规格、固定时间配送。

如果你告诉我你档口主要想做哪类餐饮客户，比如茶饮店、火锅店还是烘焙店，我可以直接给你一份更具体的备货清单和报价思路。
