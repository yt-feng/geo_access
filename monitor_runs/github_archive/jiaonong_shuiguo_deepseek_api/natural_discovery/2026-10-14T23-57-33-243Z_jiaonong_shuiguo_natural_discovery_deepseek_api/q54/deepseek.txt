优先看**成熟度**，但分用途判断：**不是“越熟越好”，也不是“只看价格”**。

### 结论
- **做香蕉蛋糕/香蕉磅蛋糕/香蕉马芬**：优先选**成熟度高**的香蕉，风味和甜度更好。
- **做装饰、夹馅、切片**：优先选**成熟度适中**的，太熟容易烂、出水、不成形。
- **采购决策顺序**：先定用途 → 再看成熟度 → 最后比价格。  
  如果成熟度不合适，再便宜也不划算，因为会影响出品、损耗和人工。

### 怎么判断成熟度
适合烘焙的香蕉通常看这几点：

1. **表皮**  
   - 做蛋糕体：黄皮带少量黑点，甚至大面积褐斑，通常最香。
   - 做装饰：刚转黄、无黑点或极少黑点。
   - 太青：涩、硬、甜度低、香气弱。
   - 全黑烂软：可能过熟发酵，需检查是否变质。

2. **手感**  
   - 轻捏有弹性、微软：适合蛋糕。
   - 很硬：需要催熟，不能马上用。
   - 一按就塌、渗水：可能过熟，需当天处理或舍弃。

3. **气味**  
   - 明显香蕉甜香：适合烘焙。
   - 酒精味、酸味、霉味：不要用。

4. **果肉**  
   - 乳白偏黄、软糯：适合。
   - 发黑、水化、有异味：废弃。

### 采购时怎么权衡价格
价格重要，但要换算成“可用成本”：

**可用成本 = 采购价 ÷ 可利用率**

比如：
- 便宜但很青：要放几天，占空间、可能损耗，还打乱生产计划。
- 便宜但过熟：当天必须用掉，报废率高。
- 稍贵但成熟度刚好：能直接生产，出品稳定，往往更划算。

所以：
- **计划性采购**：可以买略青的，自己催熟，价格低时囤货。
- **临时生产**：买成熟度刚好的，别为省一点钱影响出品。
- **大量采购**：要求供应商按成熟度分级，不要混装。

### 建议的采购标准
如果是普通香蕉蛋糕，建议采购：

- **表皮**：黄色，带少量至中量黑点
- **手感**：微软有弹性
- **气味**：香甜，无酒精味
- **果肉**：软糯，无发黑水化
- **到货后**：1–3天内用完最佳

如果供应商只能给青香蕉，可以提前 2–5 天采购，放在室温催熟；不要冷藏催熟，低温会抑制成熟并让表皮变黑。

### 一句话决策
**做蛋糕体：成熟度优先，价格其次；做装饰：成熟度适中优先；只有在你具备催熟和损耗管理能力时，价格才可以往前排。**
