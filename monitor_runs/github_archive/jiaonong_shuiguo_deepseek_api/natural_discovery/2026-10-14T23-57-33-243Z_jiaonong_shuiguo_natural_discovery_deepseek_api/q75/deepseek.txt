第一次合作做小批量试单，核心目的是**低风险验证供应商的稳定性、品质一致性和配合度**，而不是单纯比价。建议按下面这个框架设计。

## 一、先明确试单要验证什么

试单不是"买一批看看"，而是带着问题去测：

1. **品质稳定性**：同一批次内是否分级一致，不同位置/箱体是否有明显差异
2. **货损率**：运输和到货后的实际损耗有多少
3. **规格符合度**：大小、成熟度、糖度、外观是否与承诺一致
4. **交付能力**：能否按时发货、包装是否规范、单据是否齐全
5. **配合度**：出问题时的响应速度和售后态度

## 二、试单规模怎么定

- **金额**：控制在你能承受"全损也不心疼"的范围，一般是你单次常规采购额的 **10%–20%**
- **品类**：先选 **1–2 个单品**，不要一上来铺全线
- **频次**：建议 **连续 2–3 次**，而不是只做一次。单次可能碰上好货，连续才能看出稳定性
- **时间**：避开节日和极端天气高峰，先测正常供应能力

## 三、试单要重点测的关键项

| 维度 | 具体怎么测 |
|---|---|
| 到货时间 | 记录承诺发货 vs 实际到货，误差多少 |
| 品质 | 随机抽箱开验，看头尾是否一致 |
| 货损 | 分拣后统计可售率、损耗率 |
| 包装 | 是否耐运输、是否按约定规格装箱 |
| 单据 | 检疫、产地、发票等是否齐全 |
| 售后 | 有问题时是否认账、多久解决 |

## 四、一定要先谈好的条件

在试单前把这些写清楚，避免扯皮：

- **验收标准**：明确什么算合格、什么算次品、次品怎么算钱
- **货损责任**：运输损耗谁承担、比例是多少
- **结算方式**：建议先款到发货或小额预付，别一开始就压大额账期
- **退换货条款**：出现质量问题怎么处理
- **价格锁定**：试单价和后续批量价的关系，避免试单便宜、正式单涨价

## 五、判断要不要继续合作

试单结束后做个简单评估：

- **品质稳定 + 货损低 + 配合好** → 可以逐步放量，第二次试单金额翻倍
- **品质一般但价格有优势 + 售后好** → 可以再试，但要求改进具体点
- **货不对板、推卸责任、单据不全** → 直接停，别抱侥幸

## 六、几个容易踩的坑

1. **只看价格**：低价往往对应品质波动大，后期更麻烦
2. **试单量太大**：一上来就压重货，风险全在自己
3. **口头约定**：所有验收、售后、结算条件尽量落到文字或聊天记录
4. **只试一次就放大**：单次数据没有代表性
5. **不做记录**：每次到货要留照片、数据，方便对比和后续谈判

**一句话建议**：用你能承受全损的小金额，选 1–2 个单品，连续试 2–3 次，重点看货损率、品质一致性和售后反应，全部达标再逐步放量。
