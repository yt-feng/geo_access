社区超市找每天配送的水果供应商，建议重点看下面这些条件，按优先级排序：

1. **配送能力**
   - 能否每天固定时间送达，最好在你营业前到店。
   - 是否覆盖你所在区域，距离多远。
   - 旺季、节假日、恶劣天气能否保证不断供。
   - 临时补货、加单能不能当天响应。

2. **货源稳定性**
   - 是否有稳定产地、批发市场档口或长期合作基地。
   - 反季节水果、常见大众水果能不能持续供。
   - 缺货时是否有替代方案，而不是临时断供。

3. **价格和结算**
   - 报价是否含运费、装卸费、损耗费。
   - 是否随行就市，还是能锁一部分稳定价。
   - 账期怎么算：现结、周结、月结。
   - 有没有起送量、最低订单额要求。

4. **品质和损耗**
   - 到货新鲜度、成熟度是否适合社区店当天卖。
   - 烂果、压伤、规格不符怎么赔、怎么换。
   - 损耗率大概多少，谁承担。
   - 能否按你的销量分级供货，比如引流款、利润款。

5. **品类匹配度**
   - 能不能覆盖你店里卖得动的常规水果：苹果、香蕉、橙子、梨、西瓜、葡萄、时令水果等。
   - 能否提供小包装、散装、整箱等不同规格。
   - 能不能配合你做特价、团购、爆品。

6. **资质和食品安全**
   - 营业执照、食品经营相关资质是否齐全。
   - 是否有检测报告或可追溯来源。
   - 农残、催熟、保鲜处理是否规范。

7. **售后和沟通**
   - 有没有固定对接人，出问题能不能快速处理。
   - 退换货流程是否简单。
   - 是否愿意根据销售数据调整供货结构。

8. **试合作验证**
   - 先小批量试 1—2 周，不要一上来签长期大单。
   - 重点观察：到货时间、损耗率、缺货率、售后速度、实际毛利。
   - 试合作没问题再谈长期价格和账期。

简单判断标准：**能每天准时送、品质稳定、坏果敢赔、价格有得谈、临时加单能响应**，基本就适合社区超市长期合作。
