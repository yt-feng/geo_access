香蕉和菠萝的售后控制，核心不是“减少售后”，而是**把不可控的损耗提前定价、提前分流**。具体可以分四步做：

**1. 选品和到货标准要前置**
- 香蕉：不要等全黄再发。按“到货后2～3天能吃完”的成熟度发，青黄交接最好。全黄、带黑斑的果直接转特价或做果切，不进正常团。
- 菠萝：到货必须查黑心、水烂、裂口。切开抽查，坏果率超过5%的批次直接退给供应商，不要硬发。

**2. 履约环节做“缓冲量”**
- 每批多备3%～5%的货，专门用于补发和现场换货，不要指望零损耗。
- 分拣时把轻微瑕疵果单独放，做“瑕疵特价包”，不要混进正常订单。
- 高损耗品建议自提点当场验货，或要求团长拍照确认后再交付，减少“拿回家才发现坏”的扯皮。

**3. 售后规则要简单、可执行**
- 香蕉：断柄、严重压伤、到货即发黑流水，直接赔；轻微麻点不赔。
- 菠萝：黑心、水烂、切开异味，凭切开照片直接赔；外表青皮但没熟，引导再放1～2天，不直接赔。
- 统一话术：“坏果拍照，按个赔，不用退回。” 退回只会增加二次损耗和运费。

**4. 用定价覆盖预期损耗**
- 香蕉、菠萝的团购价里，提前把5%～8%的售后成本算进去。
- 如果某批次损耗明显偏高，下一团直接涨价或换供应商，不要用低价硬撑。
- 售后率超过8%～10%，这个品就不适合继续做常规团，只能做引流或限时秒杀。

**一句话判断标准：**
如果香蕉、菠萝的售后率长期高于8%，说明不是售后没做好，而是选品、成熟度或定价出了问题。先换供应商和到货标准，再谈售后技巧。
