旺季断货的核心不是“供应商答不答应”，而是你有没有把**备货责任、到货确定性、缺货赔付**写清楚。和供应商谈时，建议按下面几组问题逐条确认，能写进合同的尽量写进去。

**一、供货能力与优先级**
1. 旺季你每天的稳定供应量是多少？峰值能到多少？
2. 我这种单品/品类，你手上还有几个大客户？旺季会不会优先保他们？
3. 如果我临时加单，提前多久通知你能排上？加单上限是多少？
4. 你有没有自己的种植基地/冷库/分拣线，还是纯转手？转手的话上游是谁？

**二、价格与锁价**
1. 旺季价格怎么定？是随行就市还是可以提前锁价？
2. 锁价锁多久？锁量还是锁价不锁量？
3. 如果市场价跌了，我能不能按跌后的价拿？涨了你怎么保证不临时加价？
4. 运费、包装、损耗算谁的？到店价还是产地价？

**三、品质与规格**
1. 等级怎么分？大小、糖度、成熟度、外观标准能不能书面确认？
2. 次果率、损耗率大概多少？超出部分怎么补？
3. 能不能按我的销售节奏控制成熟度？比如今天到货明天能卖，而不是今天到明天就软。
4. 有没有质检报告或产地证明？农残、保鲜剂怎么控？

**四、到货与物流**
1. 旺季发货时效是几点前下单、几点到店？延迟怎么算？
2. 用冷链还是普货？温度记录能不能给？
3. 路上损耗谁承担？到店验收发现问题，多久内可以拒收或索赔？
4. 如果物流爆仓/天气原因延误，你有没有备用线路或备用仓？

**五、库存与备货机制**
1. 能不能给我设安全库存？比如旺季每天保底多少件在途/在仓？
2. 我能不能提前打款锁货？锁货后如果我不提，能存多久？
3. 你能不能接受“我预估销量、你提前备货”的模式？预估偏差怎么处理？
4. 断货时你的补救方案是什么？调货、换品、还是赔付？

**六、结算与风险**
1. 账期怎么算？现结、周结还是月结？旺季会不会要求预付？
2. 缺货、迟到的赔付标准是什么？按订单金额比例还是按损失利润？
3. 如果连续断货，我能不能无条件换供应商？有没有违约金？
4. 合作期限怎么定？旺季临时提价或减量，有没有约束？

**七、实操上最该盯的3件事**
1. **保底量+锁价**：别只谈“尽量供”，要谈“每天至少给我多少件，价格锁到几号”。
2. **到货时间和验收标准**：写清楚几点到、什么品质算合格、不合格怎么赔。
3. **备用供应商**：旺季至少备2家，主供占70%，备供占30%，避免被一家卡死。

谈的时候可以带一张表，把“品名、日保底量、峰值量、锁价、到货时间、损耗赔付、账期”逐项填，双方签字确认。这样比口头承诺靠谱得多。
