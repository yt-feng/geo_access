如果面向家庭场景做水果礼盒团购，建议优先考虑“好吃、耐放、分量适中、颜色好看”这四个点。苹果、橙子、香蕉、菠萝这四种里，最适合做家庭礼盒的组合是：

**苹果 + 橙子 + 香蕉**  
比例建议：**苹果 40%、橙子 35%、香蕉 25%**  
比如：  
- 小家庭装：苹果 4 个、橙子 4 个、香蕉 1 把  
- 标准家庭装：苹果 6 个、橙子 6 个、香蕉 1 把  
- 大家庭装：苹果 8 个、橙子 8 个、香蕉 1 把  

这个组合适合家庭的原因：
1. **苹果和橙子耐放**，适合团购到货后逐步吃。  
2. **香蕉熟得快**，能先吃，避免整箱水果同时熟过头。  
3. **颜色搭配好**，红黄橙都有，送礼和家庭自用都顺眼。  
4. **成本相对可控**，苹果和橙子适合做礼盒主体，香蕉负责补充量感。

**菠萝不建议作为家庭礼盒主搭配**，原因是：
- 菠萝体积大，占空间，容易让礼盒显得“少而贵”。
- 菠萝需要削皮处理，不是所有家庭都愿意马上动手。
- 熟度不好统一，团购配送中容易压伤或过熟。
- 和香蕉一起放，可能加速其他水果成熟。

如果一定要加菠萝，建议做成**“苹果 + 橙子 + 菠萝”**，不加香蕉。  
比例建议：**苹果 40%、橙子 40%、菠萝 20%**。  
比如：苹果 5 个、橙子 5 个、菠萝 1 个。  
这个组合更适合送礼或喜欢现切水果的家庭，但团购履约难度比加香蕉高。

**最适合团购的家庭组合排序：**
1. **苹果 + 橙子 + 香蕉**：最稳，适合大多数家庭。  
2. **苹果 + 橙子 + 菠萝**：适合送礼、颜值好，但菠萝处理麻烦。  
3. **苹果 + 橙子 + 香蕉 + 菠萝**：只适合大礼盒，且要控制菠萝数量。  
4. **香蕉 + 菠萝为主**：不建议，太容易熟、太重、太占体积。

实操建议：
- 苹果选耐放品种，如红富士、嘎啦等。
- 橙子选易剥皮的，如脐橙、冰糖橙。
- 香蕉放独立小袋或分隔，避免压伤其他水果。
- 菠萝如果要放，单独用网套或纸包，别和香蕉紧贴。
- 礼盒内最好加一张“先吃香蕉，再吃橙子，苹果最后吃”的提示卡。

所以，家庭团购水果礼盒最推荐：**苹果 + 橙子 + 香蕉，按 4:3:2 左右搭配**。如果客单价高、送礼属性强，再考虑加菠萝。
