酒店采购水果盘原料时，建议把规格和外观标准写进采购单或验收标准，供应商至少应保证以下几类要求：

**一、基本规格标准**
1. **品种与等级明确**  
   写明具体品种、产地、等级，如“红富士苹果 80# 一级”“阳光玫瑰葡萄 特级”。不同酒店档次可对应不同等级，避免只写“新鲜水果”。

2. **单果重量/果径/个数**  
   例如：苹果单果 200–250g，橙子果径 70–80mm，西瓜单果 4–5kg。按份出品的水果盘，最好直接约定“每份用量”和“可切出有效块数”。

3. **成熟度适中**  
   要求到货时达到“即切即用”或“1–2 天内可用”的成熟度。过生口感差，过熟易烂、损耗高。香蕉、芒果、牛油果等呼吸跃变型水果要特别约定成熟度。

4. **新鲜度与货架期**  
   供应商应保证到货时距采摘/加工时间合理，并预留足够使用期。叶菜类配果、莓果类尤其要控制。

5. **安全与合规**  
   农残、重金属、保鲜剂、蜡层等符合国家食品安全标准；预切水果需符合即食食品卫生要求。需要时可要求提供检测报告、合格证、产地证明。

**二、外观标准**
1. **色泽正常**  
   具有该品种应有的颜色，不能明显发青、发黑、发褐或色泽不均。

2. **果形完整端正**  
   无明显畸形、裂口、虫眼、病斑、机械伤、压伤、冻伤、日灼伤。

3. **表面洁净**  
   无泥土、药斑、霉点、异物；允许少量自然果粉，但不能有黏腻、渗液、异味。

4. **大小均匀**  
   同一批次、同一品种尽量整齐，便于摆盘和切配。酒店水果盘通常对外观一致性要求较高。

5. **无腐烂和霉变**  
   到货验收时不得有腐烂、霉变、发酵味、酸败味。隐蔽性内部变质也要允许退货。

6. **果柄/蒂部状态良好**  
   如葡萄、樱桃、蓝莓等，果柄新鲜、不干枯、不脱落过多；草莓、提子等无严重掉粒。

**三、切配与出品适配要求**
1. **可切率与损耗率**  
   建议约定可切率，例如苹果可切率≥85%，西瓜可切率≥70%。供应商不能只保证“整果好看”，还要保证切开后可用。

2. **切后表现**  
   苹果、梨、香蕉等要求切后不易迅速褐变；西瓜、哈密瓜等要求无空心、无厚皮、无严重白瓤。

3. **规格统一**  
   如酒店要求水果块 2cm×2cm、片厚 3mm，供应商若提供预切水果，应按此规格执行。

4. **包装与冷链**  
   易损水果应分层、分格、缓冲包装；莓果、切果、叶菜类需冷链运输。到货温度建议按品种控制，一般冷藏水果 0–8℃，热带水果避免低温冻伤。

**四、验收与退换货条款**
建议在合同或采购单中明确：
- 验收标准：品种、等级、单果重、果径、成熟度、色泽、损伤比例；
- 抽检比例：如每批次抽检 10%–20%；
- 不合格处理：外观不合格、腐烂、规格不符、成熟度不符可拒收或退货；
- 损耗补偿：因供应商质量问题导致的切配损耗，由供应商补货或扣款；
- 到货时间：按酒店使用节奏分批到货，避免一次性压货。

**五、简单可执行的验收口径**
可以写成类似：
> 供应商应保证所供水果为约定品种、等级和产地，新鲜、无腐烂霉变、无异味、无虫害及明显机械伤；单果重量/果径符合订单要求，成熟度适合酒店当日或次日切配使用；同一批次大小、色泽基本一致；切开后可切率不低于约定比例；农残及食品安全指标符合国家标准。不符合上述标准的，酒店有权拒收、退货或要求补货。

如果你们酒店是做自助餐或宴会水果盘，建议再按“整果展示类”和“切配出品类”分别定标准，因为前者更看外观，后者更看可切率、成熟度和切后稳定性。
