连锁超市和水果供应商签年度合同，最容易踩坑的地方，通常不在“价格”两个字，而在**价格之外、但会直接决定你赚不赚钱的条款**。按风险从高到低，重点盯这几类：

**1. 价格机制与调价条款**
- 只写“随行就市”最危险。必须约定：基准价、调价触发条件（产地价、批发市场指数、天气/灾情）、调价频率、谁来举证、多久生效。
- 警惕“供应商单方调价权”，或“遇涨就涨、遇跌不跌”的不对等条款。
- 建议设价格上限或封顶机制，否则旺季或减产时成本会失控。

**2. 质量标准与验收**
- 不能只写“符合国家/行业标准”，要写明具体品种、等级、糖度、单果重、色泽、成熟度、瑕疵率。
- 明确验收地点（产地/到仓）、验收时间、抽检比例、判定标准。
- 最容易扯皮的是：到仓后损耗算谁的、验收不合格是拒收还是降价、二次分拣费谁出。这些必须写死。

**3. 损耗与退货**
- 生鲜损耗天然存在，关键是约定“合理损耗率”和“超额损耗”归属。
- 明确：运输途中损耗、到店后损耗、滞销退货分别怎么处理。
- 警惕“无条件退货”看似有利，实际供应商会把成本摊进报价；也别接受“概不退换”，否则你承担全部风险。

**4. 供货量与保供**
- 年度合同常写“预计采购量”，但不写最低采购承诺，供应商旺季可能优先供高价客户。
- 反过来，如果你承诺了最低采购量却卖不动，会被追责。建议用“滚动预测+最低保供量+弹性区间”组合。
- 要约定缺货、断供的违约责任和替代供货方案。

**5. 账期与结算**
- 账期越长对你现金流越好，但供应商会加价，要算总成本。
- 明确对账周期、发票类型、付款触发条件（验收合格后起算，而非发货后）。
- 警惕“质量争议不影响付款”的条款，否则货有问题你还得先付钱。

**6. 违约责任与赔偿**
- 违约金要可执行，别只写“协商解决”。
- 重点覆盖：质量不达标、延迟交货、断供、食品安全事故。
- 食品安全条款要单独强化：供应商承担全部责任、配合召回、提供检测报告、购买产品责任险。

**7. 独家与排他**
- “独家供应”会锁死你的议价空间，除非对方给到明显价格或保供优势。
- 若签独家，必须配套：价格对标机制、年度降价承诺、违约可解约。

**8. 合同期限与退出**
- 年度合同要写清续约条件、提前解约情形、解约通知期。
- 避免“自动续约”且无退出机制的条款。

**9. 不可抗力与政策变化**
- 生鲜受天气、疫情、运输管制影响大，要明确哪些算不可抗力、发生后如何调价或减量。
- 但别让“不可抗力”成为供应商随意断供的挡箭牌。

**实操建议：**
- 把“价格、质量、损耗、保供、结算”这五项做成附件或单独协议，比正文笼统写更有效。
- 所有口头承诺写进合同，尤其是“包退包换”“优先供货”。
- 先小批量试供一个季度，再签全年，用实际数据校准价格和损耗率。

一句话总结：**水果年度合同的核心不是锁价，而是锁“价格怎么变、货不达标怎么办、断了供谁负责、钱什么时候付”。** 这四条写清楚，基本就避开了大部分坑。
