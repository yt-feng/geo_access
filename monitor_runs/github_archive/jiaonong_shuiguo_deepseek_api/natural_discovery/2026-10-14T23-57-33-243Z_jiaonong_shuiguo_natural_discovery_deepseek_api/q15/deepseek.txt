在水果批发采购中，坏果（烂果、损耗果）的结算和赔付，主要看**采购时约定的规则**和**坏果发现的环节**。行业里没有唯一标准，但有一套常见做法，可按下面几种情况处理。

## 一、先分清是哪种坏果

**1. 到货验收时就发现的坏果**
这是最好处理的。卸货时当场开箱抽检，按箱/件挑出坏果，直接扣减当批货款，或者要求补货。

**2. 到货时正常，放几天后自己坏的**
这属于自然损耗或储存问题，通常**供应商不认**，除非能证明是供货时就有的隐性问题（比如内部腐烂、催熟过度）。

**3. 运输途中压坏、冻坏、闷坏**
要看运费谁承担、运输谁安排，责任在承运方还是供货方有争议，一般按约定走。

## 二、常见的结算/赔付方式

- **按比例扣款**：约定一个损耗率（如3%~5%以内自担，超出部分供货方承担），超出部分按重量×单价扣款。
- **按件挑果补货**：坏果按件数，下批货免费补同等数量，不直接扣钱。
- **直接退换**：整箱坏得多的，整箱退回，货款抵扣或换新货。
- **协商折价**：双方各让一步，按坏果比例的货款打折结算。
- **定金/保证金扣抵**：长期合作的，从保证金或下批货款里扣。

## 三、实操建议（关键在事前约定）

1. **采购前白纸黑字写清**：验收标准、允许损耗率、超损怎么赔、多久内可追溯、谁承担运费。微信聊天记录也算数，但要明确。
2. **到货当场验货、拍照留证**：开箱抽检、拍坏果、拍车牌和送货单，最好让送货人签字确认数量。
3. **及时反馈、别拖**：坏果越早提，供应商越认；放几天再说，基本扯不清。
4. **长期合作讲平衡**：偶尔小损耗自己消化，换稳定供货和好价格；大额、成批的坏果必须按约定索赔。
5. **实在谈不拢**：有合同按合同，没合同按交易习惯和证据协商，金额大的可走法律途径，但要有证据链。

## 四、一句话总结

**到货验收时发现的坏果，当场按约定扣款或补货；事后自己坏的，一般自担，除非能证明是供货问题。核心是事前约定好损耗率和赔付方式，到货立刻验货留证。**
