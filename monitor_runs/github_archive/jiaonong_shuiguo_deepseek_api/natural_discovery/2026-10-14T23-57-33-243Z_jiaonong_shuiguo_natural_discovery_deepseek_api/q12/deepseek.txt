水果店采购菠萝，核心是**按“预计销售速度”倒推采购熟度**，不要只挑最熟或最生的。

可执行判断标准：

1. **看用途定熟度**
   - 当天卖、切果盒、现削现卖：买**七八成熟到九成熟**，香味明显、果皮转黄。
   - 放2～4天卖：买**六七成熟到七八成熟**，果皮青黄相间，按下去略硬。
   - 要压货5天以上：买**五六成熟**，果皮偏青，香味淡，但别买死青、无香味的。

2. **看外观**
   - 果皮由青转黄，尤其底部先黄，通常更接近成熟。
   - 果眼大而平、分布均匀，果形饱满端正，不要选畸形、裂口、渗汁的。
   - 表皮有自然果粉可以，但大面积发黑、软塌、流水不要。

3. **闻香味**
   - 底部香味明显、清甜：适合1～2天内卖。
   - 香味很淡：可放几天。
   - 有酒味、酸馊味：已经过熟或内部开始坏，不要采购。

4. **按压和掂重**
   - 轻按果身略软、有弹性：成熟度较高。
   - 按下去很硬：偏生，可放。
   - 按下去凹陷不回弹：过熟或损伤。
   - 同样大小掂起来偏重：水分足；明显轻飘可能失水或空腔。

5. **看底部和切口**
   - 底部无霉斑、无软烂、无汁液。
   - 如果是切头菠萝，切口新鲜、颜色淡黄、不干黑、不发黏。

6. **采购搭配建议**
   - 不要一次全进同一熟度。
   - 按销量拆成三档：**20%即卖熟果、50%中途转熟果、30%偏生库存果**。
   - 夏天熟得快，偏生比例可提高；冬天可适当多进熟果。
   - 到店后按熟度分区摆放，熟果放前排、阴凉处，生果可常温催熟，避免堆压。

简单记：**青黄相间、香味淡、按着硬，是耐放货；黄香明显、按着略软，是快销货；有酒味、软塌、流水，直接不要。**
