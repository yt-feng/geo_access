评估水果供应商仓配覆盖，核心不是看它“有没有仓”，而是看它能否稳定支撑你多城市门店的**时效、品质、成本和弹性**。建议按下面框架逐项打分和验证。

**一、先明确你的评估口径**

1. **门店分布**
   - 城市清单、门店数量、单店日均水果销量
   - 门店类型：商圈店、社区店、交通枢纽店、景区店
   - 下单频率：日配、隔日配、每周2-3配

2. **水果品类要求**
   - 高频刚需：苹果、香蕉、橙子、西瓜、葡萄等
   - 高损耗：草莓、蓝莓、芒果、荔枝、樱桃等
   - 是否需要冷链、催熟、分拣、切果

3. **服务标准**
   - 到店时效：当日达、次日达、定时达
   - 损耗率上限：比如≤3%或≤5%
   - 缺货率、退换货响应、食安追溯要求

**二、评估供应商仓配覆盖的6个维度**

1. **仓网布局**
   - 供应商在哪些城市有仓：中心仓、区域仓、前置仓、门店中转仓
   - 仓到门店的直线距离和实际配送距离
   - 是否覆盖你所有门店城市，还是只覆盖核心城市
   - 跨城调拨能力：A城缺货时能否从B城仓补

2. **配送时效**
   - 下单截止时间、分拣时间、发车时间、到店时间
   - 是否支持夜间配送、凌晨配送、预约时段
   - 冷链车/常温车比例，是否全程温控
   - 高峰期、节假日、恶劣天气下的时效保障

3. **冷链与品质能力**
   - 是否有冷藏、冷冻、恒温分区
   - 水果到店温度记录是否可查
   - 分拣标准：大小、成熟度、糖度、外观
   - 损耗责任如何划分：运输损耗、到店验收损耗、门店存储损耗

4. **成本结构**
   - 配送费：按车、按件、按重量、按门店
   - 起送门槛、远距离附加费、冷链附加费
   - 退换货物流成本谁承担
   - 隐性成本：压货、损耗、门店收货人工、临时补货加急费

5. **系统与协同**
   - 是否支持API/ERP对接，门店能否线上下单
   - 库存可视化：各仓库存、在途库存、门店可订量
   - 对账、结算、发票是否线上化
   - 异常预警：缺货、延迟、温控异常

6. **弹性与风险**
   - 旺季、大促、节假日能否加车加人
   - 单一仓故障时是否有备用仓
   - 产地直发、批发市场补货、区域调拨是否灵活
   - 食安事故、疫情、交通管制下的应急预案

**三、用一张评分表做量化**

可以给每个维度设权重，比如：

| 维度 | 权重 | 关键指标 | 评分1-5 |
|---|---:|---|---:|
| 仓网覆盖 | 20% | 覆盖门店城市比例、仓距 | |
| 配送时效 | 20% | 准时率、支持频次 | |
| 冷链品质 | 20% | 温控、损耗率、验收合格率 | |
| 成本 | 15% | 单店配送成本、附加费 | |
| 系统协同 | 15% | 对接能力、库存可视化 | |
| 弹性风险 | 10% | 旺季保障、应急预案 | |

总分低于3.5分，或任一核心项低于3分，建议不纳入主供应商。

**四、必须做实地和试运行验证**

1. **实地看仓**
   - 看分区、温控、分拣线、库存周转
   - 看水果新鲜度、残次品处理
   - 看车辆是否冷链、是否混装

2. **试配2-4周**
   - 选3-5家代表性门店：远距离、高销量、低销量各一家
   - 记录：准时率、缺货率、损耗率、客诉、实际到店成本
   - 对比承诺值与实际值

3. **压力测试**
   - 临时加单、临时改量、节假日配送
   - 要求紧急补货，看响应速度
   - 模拟温控异常或食安问题，看处理流程

**五、常见判断标准**

- **覆盖广但仓少**：可能跨城直发，时效和损耗风险高。
- **仓多但单仓小**：灵活但成本高，适合高密度城市。
- **只覆盖核心城市**：边缘城市门店可能被牺牲，需设替代供应商。
- **冷链强但成本高**：适合高价值、高损耗水果，不适合所有品类。
- **系统弱但价格低**：门店多、订单复杂时，人工对账和缺货会拖垮运营。

**六、最终建议**

对连锁门店，建议采用**“1+1+N”供应商结构**：

- 1家主供应商：覆盖核心城市，仓配稳定，系统对接好
- 1家备选供应商：覆盖边缘城市或补位
- N家区域/品类供应商：处理高损耗、特色水果、临时补货

评估时不要只看报价，要算**到店综合成本**：
**到店综合成本 = 采购价 + 配送费 + 损耗 + 门店收货人工 + 缺货损失 + 退换货成本**

如果供应商能做到：覆盖你80%以上门店城市、核心城市次日达、损耗率≤5%、系统可对接、旺季有预案，就可以作为主供应商候选。再用2-4周试配数据决定是否签约。
