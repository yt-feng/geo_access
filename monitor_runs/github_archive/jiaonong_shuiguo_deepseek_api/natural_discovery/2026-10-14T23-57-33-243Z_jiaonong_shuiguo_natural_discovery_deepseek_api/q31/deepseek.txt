连锁商超招长期水果供应商，评分标准建议围绕「能不能长期稳定供货 + 品质可控 + 价格合理 + 风险可管」来设计。以下是一套可直接落地的评分框架，你可按自己品类（叶菜类水果、浆果、进口果等）微调权重。

## 一、总体结构建议（100分制）

| 维度 | 建议权重 | 核心考察点 |
|---|---|---|
| 商务与价格 | 25–35分 | 报价竞争力、账期、价格调整机制 |
| 供应与履约能力 | 20–25分 | 产地/基地、产能、冷链、配送时效 |
| 品质与品控 | 15–20分 | 规格标准、农残检测、损耗率、退换货 |
| 企业资质与信誉 | 10–15分 | 证照、规模、合作案例、诉讼记录 |
| 服务与响应 | 5–10分 | 对接团队、异常处理、售后 |
| 可持续与长期合作 | 5–10分 | 扩产能力、独家/优先权、信息化 |

长期供应是重点，所以「供应能力+品控」合计不应低于40分，避免只比低价。

## 二、各维度细项与评分标准

### 1. 价格与商务（30分）
- 报价水平（15分）：与市场均价/历史采购价对比，分档打分，不唯最低价。
- 价格调整机制（8分）：是否约定随行就市、调价周期、涨跌幅上限、触发条件。
- 账期与结算（4分）：能否接受月结/账期，是否收取额外资金成本。
- 运费与税费（3分）：到岸价是否含运费、税票是否齐全。

### 2. 供应与履约能力（25分）
- 产地/基地（8分）：自有基地、合作基地、合作社规模，是否可追溯。
- 产能与稳定性（7分）：日/月可供量、旺季保供能力、断供预案。
- 冷链与仓储（5分）：冷库、预冷、冷藏车、分拣包装能力。
- 配送时效（5分）：到仓时间、频次、准时率承诺、覆盖门店范围。

### 3. 品质与品控（20分）
- 规格标准（6分）：果径、糖度、成熟度、外观、包装是否按商超标准执行。
- 检测与合规（5分）：农残检测报告、产地证明、检疫证、追溯体系。
- 损耗与退换（5分）：到货损耗率承诺、不合格品退换、赔偿条款。
- 样品与试供（4分）：样品评分、试供期表现、门店反馈。

### 4. 资质与信誉（12分）
- 证照资质（4分）：营业执照、食品经营/生产许可、进出口资质等。
- 规模与案例（4分）：注册资本、年营收、与知名商超合作案例。
- 信用记录（4分）：涉诉、失信、食品安全处罚记录，一票否决项可单列。

### 5. 服务与响应（8分）
- 对接团队（3分）：是否有专职客户经理、响应时间。
- 异常处理（3分）：缺货、质量投诉、临期处理的时效方案。
- 售后与配合（2分）：促销配合、新品推荐、门店支持。

### 6. 长期合作与可持续（5分）
- 扩产与投资计划（2分）：未来1–3年产能提升承诺。
- 信息化对接（2分）：能否对接订单、库存、追溯系统。
- 优先/独家条款（1分）：区域或品类优先供应权。

## 三、必须设置的「否决项」
以下任一项不满足，直接废标或降为不合格，不进入打分：
- 无有效食品经营/生产资质；
- 近3年有重大食品安全事故或失信被执行人；
- 无法提供农残检测或产地证明；
- 报价明显低于成本且无合理解释，存在以次充好风险。

## 四、评标操作建议
1. **先资格后打分**：资质、检测、信用作为门槛，通过后再比价格和能力。
2. **样品+试供**：招标阶段要求送样，中标后设1–3个月试供期，试供不合格可终止。
3. **价格分不唯低**：可用「基准价±偏离」打分，防止恶意低价后断供或降质。
4. **长期条款写进合同**：保供量、调价机制、损耗率、退换货、违约赔偿、年度考核。
5. **动态考核**：季度/年度按准时率、损耗率、投诉率、退货率打分，与续约和订单量挂钩。

## 五、可直接用的简化版权重
- 价格与商务：30
- 供应与履约：25
- 品质与品控：20
- 资质与信誉：12
- 服务与响应：8
- 长期合作：5

如果你的商超以**高端水果/进口水果**为主，可把品质和冷链权重各加5分；如果以**大众走量水果**为主，可把价格和供应能力权重各加5分。
