大型超市对水果供应商的要求，核心是“能吃、能追、能稳、能赔”。下面按食品安全能力和物流能力两块说，并给出可判断的硬指标。

## 一、食品安全能力

### 1. 资质与合规
- 营业执照、食品经营许可证/食品生产许可证（按实际业态）。
- 若涉及进口水果：进出口权、入境货物检验检疫证明、海关报关单。
- 种植/加工环节：产地证明、基地备案、合作社或自有基地证明。
- 检测能力或第三方检测合作：农药残留、重金属、真菌毒素等按国标检测。

**判断标准：** 能提供近批次或近周期的第三方检测报告，且报告项目覆盖超市抽检重点，不是只有一张常年不变的“合格证”。

### 2. 农残与污染物控制
- 有明确的农药使用清单和禁用农药管控。
- 采收前有安全间隔期管理。
- 具备农残快检能力或固定送检机制。
- 对重金属、霉菌毒素有产地和品种风险评估。

**判断标准：** 能说清“这批货来自哪个基地、用了什么药、最后一次用药距采收多少天、检测结果如何”。

### 3. 采后处理与保鲜
- 分选、清洗、打蜡、催熟等工艺符合法规。
- 保鲜剂、蜡、催熟剂使用合规，有记录。
- 冷链前预冷能力，尤其是浆果、叶菜类水果。
- 包装材料符合食品接触材料标准。

**判断标准：** 能提供采后处理记录、添加剂使用记录、包装材料合规证明。

### 4. 追溯与召回
- 批次化管理：从基地、采收、加工、发货到门店可追溯。
- 有召回制度，能在约定时间内定位并召回问题批次。
- 有食品安全事故应急预案。

**判断标准：** 给定一个门店到货批次，供应商能在合理时间内查到对应基地和检测记录。

### 5. 品控体系与人员
- 有品控岗位和验收标准。
- 有供应商审核、基地审核、过程巡检记录。
- 从业人员有健康证明和食品安全培训。
- 通过 ISO 22000、HACCP、GAP 等认证是加分项，但不是唯一标准。

**判断标准：** 不是只看证书，而是看有没有日常记录、异常处理记录和整改闭环。

### 6. 保险与责任
- 产品责任险。
- 食品安全责任险。
- 明确质量赔付条款。

**判断标准：** 出问题时能赔、能换、能承担超市下架和召回损失。

## 二、物流能力

### 1. 冷链能力
- 不同水果温区管理：如浆果 0–4℃，热带水果 10–15℃等。
- 冷藏车、保温箱、冷库、预冷间。
- 全程温度记录，可导出温度曲线。
- 冷链断链应急处理能力。

**判断标准：** 能提供运输温度记录，且到货温度符合品类要求。

### 2. 仓储与分拣
- 水果专用库或分区存放，避免串味、压伤。
- 先进先出/按批次出库。
- 分拣线能按超市标准分级、称重、贴标。
- 仓储虫害控制和卫生管理。

**判断标准：** 到货规格一致、损耗可控、批次清晰。

### 3. 配送时效与覆盖
- 能覆盖超市门店网络，有固定线路和频次。
- 支持日配、隔日配、紧急补货。
- 节假日、促销期有运力储备。
- 到店时间窗口稳定。

**判断标准：** 不是“能送”，而是“按门店要求的时间、频次、温度稳定送到”。

### 4. 损耗与包装
- 有防压、防震、透气包装方案。
- 周转筐、托盘标准化。
- 运输损耗率可统计、可考核。
- 能配合超市做门店退货、换货、销毁流程。

**判断标准：** 能给出品类损耗率数据，并有降低损耗的具体措施。

### 5. 信息化与协同
- 订单、库存、批次、温度数据可对接或共享。
- 有异常预警：缺货、延误、温控超标。
- 能提供电子追溯码或批次信息。

**判断标准：** 超市能实时或准实时掌握到货、批次和异常情况。

## 三、超市通常最看重的硬门槛

1. **证照齐全**，尤其是食品经营/生产许可和进口检疫证明。
2. **批批检测或批批可追溯**，不是只靠年度报告。
3. **冷链不断链**，有温度记录。
4. **批次召回能力**，出问题能快速定位。
5. **稳定履约**，按时按量按温区到店。
6. **损耗可控**，有包装、预冷、分拣方案。
7. **责任可赔**，有产品责任险和明确赔付条款。

## 四、一句话判断

如果一家水果供应商只能提供“产地直发、价格便宜”，但说不清检测报告、批次追溯、冷链温度和召回流程，它通常达不到大型超市的准入要求。大型超市要的不是“能供水果”，而是“能稳定供安全水果，并且出问题能追、能赔、能控制损失”。
