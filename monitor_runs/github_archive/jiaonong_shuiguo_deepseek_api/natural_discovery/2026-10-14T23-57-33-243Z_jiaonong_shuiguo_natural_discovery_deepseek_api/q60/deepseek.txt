遇到水果到货不合格，核心是**把“补货”从口头承诺变成可执行条款**，同时让门店在等待补货期间能继续营业。可以从下面几个层面约定：

## 一、验收环节先留证据

- **当场验收、当场记录**：到货后规定时间内（如30分钟）完成验收，拍照/视频记录不合格水果的批次、数量、包装标签。
- **书面确认**：让送货员或供应商在送货单上签字确认“不合格品数量及原因”，避免事后扯皮。
- **不合格品暂存**：单独放置并标注“待退/待换”，不要混入合格品，防止误用。

## 二、补货条款要写清楚

1. **补货时限**  
   约定“验收确认后 X 小时内送达”，比如：
   - 同城供应商：4小时内；
   - 外地供应商：24小时内；
   - 紧急情况可要求“当日补发”。

2. **补货方式**  
   明确是“换货”还是“补发”：
   - 换货：不合格品退回，供应商补同等数量合格品；
   - 补发：不退回，供应商直接补发，避免门店因退货耽误时间。

3. **补货数量**  
   按“不合格数量 1:1 补足”，并可约定“因补货延迟导致门店缺货的，按缺货量追加补偿”。

4. **补货优先级**  
   写明“补货订单优先于常规订单处理”，防止供应商先发新单、拖补货。

## 三、不影响营业的替代方案

光靠补货可能来不及，所以要在合同里加“临时替代”条款：

- **允许门店自行采购替代**：若供应商未在约定时间内补货，门店可就近采购同等品质水果，费用由供应商承担或从货款中扣除。
- **允许调整菜单**：因缺货导致某款饮品无法制作，门店可临时下架或替换配方，供应商不得视为违约。
- **部分补货+部分退款**：如果补货周期长，可约定“先补一部分应急，剩余做退款或下次抵扣”。

## 四、责任与扣款要量化

- **逾期补货违约金**：如每延迟1小时扣当批货款的5%，或按缺货金额的倍数扣款。
- **质量保证金**：每月货款中预留一定比例作为质量保证金，出现不合格且未按时补货时直接扣除。
- **累计不合格处理**：如一个月内不合格超过3次，门店有权暂停合作或要求更换供应商。

## 五、操作上建议这样做

1. **合同附件写清验收标准**：糖度、成熟度、大小、新鲜度、无腐烂等，最好有图片示例。
2. **建立补货流程单**：验收不合格→填单→供应商确认→约定补货时间→门店签收。
3. **保留备用供应商**：至少有一家本地应急供应商，避免完全依赖单一来源。
4. **每日盘点**：对易坏水果设定安全库存，提前1天预警，减少到货不合格带来的断货风险。

简单说：**验收留证 + 限时补货 + 允许替代采购 + 逾期扣款**，这四件事写进合同或供货协议，就能在水果不合格时既保住营业，又不让供应商拖着你。
