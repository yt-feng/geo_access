优先级取决于你团购的模式和规模，但通常排序是：**售后 > 配送 > 价格**。原因如下：

**1. 售后最优先（先问）**
水果是生鲜里最容易出问题的品类：压伤、烂果、熟度不均、重量不足、规格不符。团购是“熟人关系 + 集中交付”，一旦售后处理慢或推诿，团员流失比省下的进货差价严重得多。
要问清楚：
- 坏果怎么赔？按比例还是按颗？
- 需要拍照/留证吗？多久内反馈有效？
- 退款/补发/抵扣下次货款，走哪种？
- 售后响应时限是几小时还是几天？

**2. 配送第二（决定你能不能按时开团）**
配送不稳，售后问题会成倍增加，而且团长要直接面对团员催单。
要问清楚：
- 到货时间能否固定？误差多大？
- 是送到自提点、团长家还是分拣点？
- 破损率一般多少？谁承担运输损耗？
- 旺季/节假日会不会延迟或加价？
- 起送量、配送费、临时加单怎么算？

**3. 价格第三（不是不重要，而是不能只看单价）**
低价往往藏在：规格缩水、熟度提前采摘、混级发货、损耗自己扛。
要算的是**到手可售成本**：
- 报价含不含运费、包装、损耗？
- 次果/坏果率大概多少？
- 同规格对比，别拿“大果价”比“中果价”。
- 是否能稳定供同品质，而不是这次便宜下次变差。

**一句话判断标准：**
如果你是小团长、靠熟人复购，**先保售后，再保配送，最后谈价格**；如果你量大、有分拣能力、能自己消化售后，价格权重才会上来。

**最实用的问法：**
“同样这批货，坏果率多少、坏了怎么赔、几点能送到、临时加单怎么办、这个价含不含运费和损耗？”——这五个问题基本能筛掉大部分不靠谱供应商。
