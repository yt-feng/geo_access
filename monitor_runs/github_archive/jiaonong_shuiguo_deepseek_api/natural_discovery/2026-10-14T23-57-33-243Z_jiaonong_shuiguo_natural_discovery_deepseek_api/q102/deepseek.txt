需要，而且通常这两项是**企业福利水果礼盒采购的基础门槛**，不是可选项。

**1. 开发票：必须支持**
- 企业采购要入账、报销、走财务流程，没有合规发票基本无法结算。
- 一般需要**增值税普通发票或专用发票**，具体看企业财务要求；能开专票的供应商更稳妥。
- 要确认：开票类目是否匹配（如“水果”“食品”“礼品”）、税率、能否对公转账、是否支持先票后款或账期。

**2. 定制包装：多数企业会要求**
- 福利礼盒通常要体现企业标识、节日祝福、统一视觉，所以需要支持定制。
- 常见定制包括：外盒 logo、腰封、贺卡、手提袋、封签、内托结构等。
- 要确认：起订量、打样费、打样周期、定制加价、是否影响交货时间。

**建议你在采购时直接按这4条筛供应商：**
1. 能否开企业抬头发票，类目和税率是否明确；
2. 能否对公付款、是否接受账期；
3. 定制包装的最低起订量和打样时间；
4. 水果品质标准、破损赔付、到货时效和售后处理。

如果供应商说“可以开票但类目不对”或“定制要另收高额打样费且周期很长”，就要谨慎评估，避免影响福利发放节点。
