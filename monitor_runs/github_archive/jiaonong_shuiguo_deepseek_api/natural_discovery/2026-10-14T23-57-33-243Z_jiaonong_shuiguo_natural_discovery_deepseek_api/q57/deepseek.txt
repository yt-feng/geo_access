结论先说：**多数餐饮连锁采购水果，优先推荐“中央厨房统一收货”，但要做分级管理，而不是一刀切。**  
如果水果主要用于中央厨房加工（切果、榨汁、做沙拉、做酱料等），统一收货明显更好；如果水果是门店直接售卖或对成熟度、陈列状态要求很高（如水果茶门店、果切店），则更适合“中央厨房统采统配 + 门店少量应急直收”的混合模式。

下面给你一套可判断、可落地的建议。

## 一、两种模式的核心区别

| 对比项 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 采购规模 | 集中，议价强 | 分散，议价弱 |
| 品控标准 | 容易统一 | 容易各店不一致 |
| 验收能力 | 可配专业品控 | 店长/员工兼职验收，能力参差 |
| 损耗管理 | 集中分拣，可分级利用 | 各店各自损耗，难追踪 |
| 物流成本 | 需二次配送 | 供应商直送门店 |
| 灵活度 | 较低 | 较高 |
| 食品安全追溯 | 更集中、更清晰 | 分散，追溯难度大 |
| 资金结算 | 统一对账 | 多店多供应商，对账复杂 |

## 二、什么情况下优先中央厨房统一收货

满足以下 3 条以上，建议统一收货：

1. **水果是原料，不是直接售卖商品**  
   比如做果汁、甜品、沙拉、酱料、烘焙馅料。

2. **门店数量较多，通常 10 家以上**  
   规模越大，集中采购和统一品控的价值越明显。

3. **有中央厨房或配送中心**  
   已有仓储、冷库、分拣、质检能力，增加水果品类边际成本低。

4. **水果损耗高、价格波动大**  
   统一收货后可以做分级：好果给门店，次果做加工，减少整体报废。

5. **需要统一食品安全溯源**  
   连锁品牌对供应商资质、农残检测、批次追溯要求高时，集中收货更可控。

6. **供应商愿意配合统配**  
   能按中央厨房标准送货、分拣、贴标、批次管理。

## 三、什么情况下门店分开收货更好

以下情况不要强行统一：

1. **水果直接面向顾客，成熟度要求极高**  
   比如水果茶、果切、鲜果陈列。统一收货再配送，容易压伤、过熟或不够熟。

2. **门店分布极散，配送半径大**  
   二次配送成本可能高于集中采购节省的成本。

3. **各门店销量差异极大**  
   统一配货容易造成有的店缺货、有的店积压。

4. **当地有强势供应商可直送**  
   门店直采更新鲜、成本更低、响应更快。

5. **中央厨房没有专业水果仓配能力**  
   没有冷库、分拣线、催熟/保鲜条件，统一收货反而增加损耗。

## 四、更优解：混合模式

大多数连锁餐饮更适合这套结构：

### 1. 统采统收统配
适合：苹果、橙子、柠檬、冷冻水果、罐头水果、长期稳定使用的加工原料。

做法：
- 总部谈供应商和价格
- 中央厨房统一收货、质检、分拣
- 按门店订单配送

### 2. 统采分收
适合：对新鲜度要求高、易损的水果，如草莓、蓝莓、芒果、牛油果、葡萄。

做法：
- 总部锁定供应商、价格、标准
- 供应商直送门店
- 门店按总部标准验收
- 数据回传总部，纳入供应商考核

### 3. 门店应急直采
适合：临时缺货、当地特色水果、突发促销。

做法：
- 设置金额和品类权限
- 必须用总部指定供应商或白名单
- 小票、照片、批次信息上传系统
- 月度审计

## 五、判断公式

你可以用一个简单公式判断：

**统一收货收益 = 采购降价 + 品控提升 + 损耗降低 + 管理简化**
**统一收货成本 = 仓储成本 + 二次配送成本 + 分拣成本 + 压货损耗**

如果收益明显大于成本，就统一收货。  
如果水果易损、门店要求新鲜度极高、配送成本高，就统采分收或门店直收。

## 六、落地建议

如果你现在要决策，建议按这 5 步做：

1. **按水果分级**  
   A 类：耐储运、加工用，统一收货。  
   B 类：易损、鲜度敏感，统采分收。  
   C 类：应急、本地特色，门店有限直采。

2. **统一验收标准**  
   规格、成熟度、糖度、农残、批次、温度、包装、损耗率。

3. **建立供应商考核**  
   到货合格率、损耗率、准时率、门店投诉率。

4. **上系统留痕**  
   门店收货拍照、称重、异常上报，总部可追踪。

5. **先试点再推广**  
   选 5—10 家门店和 2—3 个水果品类试跑 1—2 个月，对比损耗、成本、投诉、时效。

## 最终建议

- **加工型水果、耐储水果、门店多、有中央厨房：中央厨房统一收货更好。**
- **鲜食型水果、易损水果、门店散、配送远：门店分开收货或统采分收更好。**
- **最推荐：统采统配 + 统采分收 + 门店应急直采的混合模式。**
