结论先说：**最省损耗的做法是“整果为主 + 现场代削 + 让顾客先挑整果，再决定削不削”**。不建议大量提前削好摆着卖，也不建议完全让顾客自己挑到失控。

具体可以这样判断和操作：

1. **整果为主**
   - 菠萝整果耐放，损耗低，顾客也容易判断新不新鲜。
   - 整果可以按个卖、按斤卖，价格和毛利更可控。
   - 适合大多数水果店作为基础售卖方式。

2. **现场代削，而不是提前削好**
   - 顾客挑好整果后，店里再削皮、去眼、切块。
   - 这样顾客觉得新鲜、透明，也愿意为服务买单。
   - 提前削好的菠萝容易出水、氧化、变味，卖不掉就是损耗。
   - 如果一定要提前削，只做少量试吃或高峰时段备用，并且冷藏、尽快卖完。

3. **让顾客自己挑，但要有引导**
   - 顾客自己挑整果，参与感强，成交率通常更高。
   - 但完全放任容易把果子翻乱、捏坏，也容易挑走最好的、剩下难卖的。
   - 可以分档：
     - 普通整果：顾客自选
     - 精品整果：单独摆放，价格高一点
     - 已削好的：按盒卖，适合赶时间的人
   - 店员可以主动帮忙判断熟度，减少顾客挑错后回来投诉。

4. **最适合的组合**
   - **主推：整果自选 + 免费或加钱代削**
   - **补充：少量削好盒装，卖给赶时间或即食顾客**
   - **不建议：大量提前削好堆着卖**
   - **不建议：完全不让顾客挑，强推削好的**

5. **关键看你的客群**
   - 社区店、中老年多：整果为主，代削服务要有。
   - 商圈店、年轻人多、即食需求强：可以增加削好盒装比例，但仍控制量。
   - 如果菠萝品质不稳定：更要以整果为主，让顾客自己判断，减少售后。

一句话：**整果是基本盘，代削是增值服务，提前削好只是补充。让顾客挑整果，但由店员把控削和切的环节。**
