结论先说：**大多数茶饮店应该以「冷冻/冷藏果丁 + 少量鲜果」为主，果泥只做辅助，不建议长期用鲜果切丁做主料。** 具体怎么选，看你的定位、出杯量和想做什么产品。

**1. 鲜果（整颗菠萝现切）**
- 优点：新鲜感强，能做「手捣鲜果」卖点，香气和口感最好，适合高客单、强调现做的店。
- 缺点：损耗大（去皮、去眼、去芯很费人工），出品不稳定（季节、成熟度不同，酸甜差异大），高峰期切不过来，卫生和冷藏管理压力大。
- 适合：门店有专门备料人力、走精品现制路线、菠萝用量不大的店。

**2. 果丁（冷冻或冷藏预处理菠萝丁）**
- 优点：开袋即用，标准化程度高，酸甜和大小稳定，出杯快，损耗低，最适合连锁和高峰期。冷冻果丁能长期备货，价格也相对可控。
- 缺点：风味比现切鲜果略弱一点，解冻后口感偏软，不适合追求「脆感」的产品。
- 适合：**绝大多数茶饮店的主力选择**，尤其是做菠萝果茶、果粒茶、气泡茶。建议选冷冻锁鲜的，比糖水罐头果丁更接近鲜果味。

**3. 果泥（菠萝果泥/果浆）**
- 优点：风味浓、颜色稳定、易调甜度和酸度，出杯最快，几乎没有损耗。
- 缺点：没有果粒咀嚼感，容易被顾客觉得「像冲调」，纯用会拉低产品档次；部分果泥含糖和添加剂，需要看配料表。
- 适合：做基底调味、冰沙、奶昔，或和果丁搭配使用（果泥调味 + 果丁给口感）。

**给你的采购建议：**
- 主料选**冷冻菠萝果丁**，保证出杯效率和稳定性。
- 想要「鲜果感」，可以每天少量现切鲜果做top或手捣款，只放在高毛利招牌产品上。
- 果泥作为调味补充，用来统一酸甜度，不要单独撑起一款「鲜果茶」。
- 先小批量试三种，按同一配方做盲测，比风味、口感、成本和出杯速度，再定比例。

一句话：**果丁打底、鲜果做卖点、果泥调味道，是最稳的组合。**
