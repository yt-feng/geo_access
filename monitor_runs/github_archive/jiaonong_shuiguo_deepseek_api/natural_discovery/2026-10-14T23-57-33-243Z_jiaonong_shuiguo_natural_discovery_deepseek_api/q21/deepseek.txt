超市采购水果时，供应商通常需要提供以下几类证明或报告（具体以当地市场监管要求和超市内部验收标准为准）：

**1. 主体资质类**
- 营业执照
- 食品经营许可证（或食品生产许可证，视经营形式而定）
- 若为进口水果，还需海关相关资质及报关材料

**2. 进货来源证明**
- 进货凭证：发票、送货单、购销合同等
- 上游供应商的资质复印件
- 供货商与种植基地/批发市场的采购凭证
- 建立可追溯的进货台账

**3. 质量合格证明**
- 产地证明或供货证明
- 批次自检报告或委托检验报告
- 食用农产品合格证（部分地区推行“合格证+追溯码”）

**4. 检测报告类**
- **农残检测报告**：最常见，通常按批次提供，检测项目如有机磷、氨基甲酸酯类等
- **重金属检测报告**：铅、镉、汞、砷等，视品种和产地风险而定
- **食品添加剂/保鲜剂检测**：如二氧化硫、防腐剂等（针对特定水果）
- **微生物检测**：一般鲜果较少要求，但切果、预包装水果可能涉及
- **进口水果**：需检验检疫证明、入境货物检验检疫合格证明

**5. 包装与标签**
- 预包装水果需符合标签标识规定
- 进口水果需有中文标签

**6. 其他可能要求**
- 无公害、绿色、有机认证证书（若宣称）
- 地理标志产品相关证明（若宣称）
- 冷链运输温度记录（针对需冷藏水果）

**实操建议：**
- 首次合作时索要全套资质并留存复印件/扫描件
- 每批次索取对应检测报告或合格证，重点核对批次号与生产日期
- 进口水果重点核查检验检疫证明和中文标签
- 具体清单最好以超市所在地市场监管部门要求和超市内部验收制度为准，不同地区、不同超市差异较大
