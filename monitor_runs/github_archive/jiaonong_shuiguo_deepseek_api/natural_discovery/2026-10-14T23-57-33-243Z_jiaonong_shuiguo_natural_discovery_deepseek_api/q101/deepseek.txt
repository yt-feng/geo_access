酒店早餐水果供应，核心不是“买到便宜水果”，而是**长期稳定、品质一致、损耗可控、结算清楚**。和供应商谈合作时，建议重点看这几类问题：

1. **先定标准和规格**
   - 明确品类：苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等，哪些是固定供应，哪些按季替换。
   - 明确等级：果径、单果重量、成熟度、甜度、外观瑕疵允许范围。
   - 明确加工要求：是否要求去皮、切块、去核、装盒，还是酒店后厨自己处理。
   - 最好写进合同附件，避免“每次送来的货不一样”。

2. **确认供应能力**
   - 问清楚产地、季节替代方案、缺货时如何调配。
   - 是否有冷链、仓储、分拣能力。
   - 节假日、台风、极端天气、疫情等情况下，能不能保供。
   - 不要只依赖一家供应商，至少准备备用渠道。

3. **价格和调价机制**
   - 水果价格波动大，不能只谈一个固定价。
   - 可以约定：基准价+市场波动调整机制，或按周/按月报价。
   - 明确报价是否含税、含运费、含加工费、含包装费。
   - 避免后期出现“低价中标，后面不断加价”。

4. **验收标准要可执行**
   - 到货时间、地点、频次写清楚。
   - 验收项目：数量、重量、规格、成熟度、新鲜度、破损率、农残检测报告。
   - 不合格怎么处理：拒收、换货、补货时限、扣款标准。
   - 建议每次验收留记录、拍照，双方签字。

5. **损耗和退换货**
   - 水果损耗高，必须谈清楚：运输损耗、仓储损耗、加工损耗谁承担。
   - 坏果、烂果、规格不符，是否无条件退换。
   - 退换货响应时间，比如几小时内补送。
   - 如果酒店自己切配，要约定可食用率，而不是只看毛重。

6. **食品安全和资质**
   - 营业执照、食品经营许可证、检验检疫或农残检测报告。
   - 冷链运输温度记录。
   - 包装卫生、标签信息、保质期。
   - 发生食品安全问题时，责任和赔偿要写清楚。

7. **结算和账期**
   - 对账周期：日结、周结、月结。
   - 发票类型和税率。
   - 付款账期，比如月结30天、60天。
   - 逾期付款、逾期供货的违约责任。

8. **合同关键条款**
   - 合作期限、试用期、考核期。
   - 独家还是非独家供应。
   - 价格调整机制。
   - 质量违约、断供、食品安全事故的赔偿。
   - 终止合作和交接安排，避免突然断供。

9. **先试供再签约**
   - 建议先做2到4周试供。
   - 重点观察：到货准时率、规格稳定率、坏果率、补货速度、服务响应。
   - 试供合格再谈长期合同和账期。

10. **内部管理也要配合**
   - 早餐用量要有个大致预测，按入住率、团队客、节假日调整。
   - 后厨验收、切配、冷藏、摆放要有标准。
   - 每天记录消耗和损耗，才能判断供应商是否真的稳定。

简单说，谈合作时抓住四句话：**标准写清楚，价格有机制，验收可执行，断供有预案。**  
如果你们酒店早餐客流稳定，最好找有酒店或团餐配送经验的供应商，比单纯水果批发商更省心。
