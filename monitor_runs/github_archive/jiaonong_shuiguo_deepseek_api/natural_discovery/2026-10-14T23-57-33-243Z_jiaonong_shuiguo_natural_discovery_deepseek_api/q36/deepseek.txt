建议不要二选一，而是 **“整果为主、切果为辅/引流”** 组合卖。

核心判断：

1. **整果更适合作为主力**
   - 毛利通常更稳，损耗更低，不需要现场削切人工。
   - 顾客对“新鲜、完整”的感知更强，适合家庭采购。
   - 操作简单，适合大部分商超门店。
   - 但问题是：部分顾客嫌削皮麻烦，客单价和冲动购买可能不如切果。

2. **切好的更适合做增量**
   - 满足即食、年轻客群、办公室/小家庭、懒得削皮的人。
   - 能提升客单价和冲动购买。
   - 但损耗、人工、冷链、卫生、保质期要求高，卖不完基本报损。
   - 如果门店客流不够、周转慢，切果容易变成损耗黑洞。

3. **更可执行的组合方式**
   - **整果区**：主打低价、堆头、家庭装，做引流和基本销量。
   - **切果区**：只做小份、即食盒，放在收银前、水果区端头或冷柜边，主攻冲动购买。
   - **切果不要全天大量切**：按高峰时段分批切，比如上午、下午各一次，每次少量。
   - **整果和切果定价要拉开**：切果按“整果成本 + 人工 + 损耗 + 包装”加价，通常应明显高于整果单价，不能按整果斤价直接卖。
   - **用整果做促销，用切果做利润和便利**。

4. **什么情况下更适合主卖整果**
   - 门店客流一般、菠萝周转慢。
   - 没有稳定冷链或现场削切条件。
   - 人工紧张，无法保证切果卫生和时效。
   - 周边顾客以家庭、中老年为主。

5. **什么情况下可以加大切果比例**
   - 门店在商圈、写字楼、学校、社区年轻客群集中。
   - 客流大、周转快，切果能当天卖完。
   - 有冷柜、果切操作间、稳定人手。
   - 能控制报损，且切果毛利能覆盖损耗。

6. **简单决策口径**
   - 先按 **7:3 或 8:2** 试：整果占大头，切果占小头。
   - 观察 1—2 周：
     - 切果经常售罄、报损低：可提高到 6:4。
     - 切果经常打折、报损高：退回 9:1，只保留少量试销。
   - 关键看三个数：**切果报损率、切果毛利率、整果销量是否被带动**。

结论：  
**大多数商超门店，整果是基本盘，切果是增量品。**  
不要为了“看起来丰富”盲目上大量切果；更稳的做法是：整果做大销量，切果小份、分时段、控损耗，用来提客单和抓即食需求。
