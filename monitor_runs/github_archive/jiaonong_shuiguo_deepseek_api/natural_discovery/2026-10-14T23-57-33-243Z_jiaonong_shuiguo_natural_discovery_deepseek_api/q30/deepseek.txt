超市水果到货后发现品相不好，售后流程要在采购合同或供货协议里提前约定清楚，不能只靠口头或“有问题再说”。建议从以下五个方面写进条款。

**一、验收标准和时限**
- 明确“品相不好”的具体情形：腐烂、霉变、压伤、开裂、异味、成熟度过高或过低、大小/色泽不符合约定等级等。
- 约定到货后多久内完成验收，例如“收货后4小时内完成抽检，24小时内提出书面异议”，逾期视为验收合格。
- 约定抽检比例和判定方式，例如按到货件数抽检5%—10%，不合格率超过约定比例即整批可退。

**二、售后处理方式**
按问题严重程度分档约定，避免扯皮：
- 轻微品相问题：折价接收，按不合格比例扣款。
- 中度问题：部分退货，供应商补货或换货。
- 严重问题（腐烂、霉变、食品安全风险）：整批拒收或退货退款。
- 因品相问题导致超市无法销售的部分，供应商承担相应损失。

**三、责任和费用承担**
- 退换货产生的运费、装卸费、分拣费由责任方承担，通常由供应商承担。
- 因延迟补货导致超市断货或损失的，可约定违约金或赔偿方式。
- 明确不可抗力、运输损耗与供应商责任的边界，避免把所有损耗都算作供应商责任，也避免供应商把明显质量问题推给运输。

**四、时限和流程**
写清操作路径：
1. 收货方发现异常，拍照/录像留证，记录批次、数量、问题描述。
2. 在约定时限内书面通知供应商（微信、邮件、系统单据均可，但要能留痕）。
3. 供应商在约定时间内确认或到场复核。
4. 双方确认处理方式：折价、补货、换货、退货、扣款。
5. 完成退换或扣款后，双方签字/系统确认结案。

**五、证据和结算挂钩**
- 验收单、照片、视频、聊天记录、退货单都要留存。
- 约定“质量异议未处理完毕前，超市有权暂扣对应货款”，但扣款比例和期限要合理，避免被认定为无故拖欠。
- 明确对账和扣款凭证，防止后续对账纠纷。

**实操建议：**
- 新供应商先小批量试供，稳定后再放量。
- 把水果按品类分别约定标准，叶菜、浆果、柑橘、热带水果的耐储性差异很大，不能用同一套验收标准。
- 合同里写“以双方确认的验收标准为准”，并附上等级样品或图片，比单纯文字更可执行。

如果只是临时采购没有合同，至少用书面订单或聊天记录确认上述验收时限、退换方式和费用承担，否则事后很难主张。
