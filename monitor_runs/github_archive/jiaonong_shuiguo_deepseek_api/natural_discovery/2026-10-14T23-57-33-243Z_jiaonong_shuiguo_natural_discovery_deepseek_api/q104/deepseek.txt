单位采购水果，到货品质不一致时，验收和售后可以按下面这套流程处理，核心是**先固定证据、再分级验收、最后按合同/约定索赔或退换**。

**一、到货前先明确验收标准**

采购时就要把标准写进合同或订单，避免事后扯皮：

- 品种、规格、单果重量/直径、成熟度、产地
- 允许的坏果率、次果率，例如“坏果率≤3%”
- 糖度、外观、新鲜度要求
- 验收方式：全检还是抽检，抽检比例
- 不合格的处理方式：扣款、退换、补发、拒收
- 到货时限和冷链要求

**二、到货验收怎么做**

1. **当场验收，不隔夜**
   水果易腐，尽量到货即验，至少当天完成。延迟验收容易导致责任不清。

2. **先核对单据和数量**
   核对送货单、订单、品种、数量、规格是否一致。

3. **分层抽样检查**
   - 大批量：按比例抽检，比如每批抽5%–10%，或按箱抽。
   - 重点查底层、边角、被压部位，这些地方最容易藏坏果。
   - 每箱都要看，不能只看表面。

4. **按标准分级记录**
   建议分三类：
   - 合格：符合约定标准
   - 次果：外观差、轻微压伤，但不影响食用
   - 坏果：腐烂、发霉、异味、严重破损

5. **拍照/录像留证**
   - 整车/整批全景
   - 问题箱、问题果特写
   - 称重、计数过程
   - 送货单、批次号、时间
   最好让送货人现场签字确认。

6. **当场出具验收单**
   写明：到货数量、抽检数量、合格数、次果数、坏果数、不合格比例、处理意见。双方签字。

**三、品质不一致时怎么判定**

- 如果**坏果率超过约定比例**：按合同扣款、退换或拒收。
- 如果**部分箱合格、部分箱不合格**：可分批处理，合格部分收货，不合格部分退货或补发。
- 如果**整体品质不达标**：可拒收，并要求供应商承担运费和损失。
- 如果**只是轻微差异**：可协商折价接收，但要书面确认。

**四、售后怎么处理**

1. **第一时间书面通知供应商**
   通过微信、邮件、函件等可留痕方式，附照片、验收单、问题说明。

2. **提出明确诉求**
   常见诉求：
   - 补发合格水果
   - 退货退款
   - 按比例扣款
   - 折价接收
   - 赔偿因延误造成的损失

3. **约定处理时限**
   例如24小时内回复，48小时内补发或退款，避免拖延。

4. **保留不合格样品**
   封存部分问题果，作为后续协商或索赔依据。

5. **走合同约定的争议解决方式**
   协商不成，按合同约定的违约金、赔偿条款处理，必要时走法律途径。

**五、建议的实操流程**

1. 采购前：写清标准、坏果率、验收方式、售后条款。
2. 到货时：当场验收、抽检、拍照、签字。
3. 发现问题：当场记录，书面通知供应商。
4. 协商处理：补发、退换、扣款、折价。
5. 复盘：把问题供应商列入考核，后续调整采购比例。

**六、关键提醒**

- 不要先入库再验收，否则责任难界定。
- 不要只口头沟通，所有问题都要留痕。
- 不要全部拒收或全部接收，最好按比例分级处理。
- 合同里一定要写“坏果率”和“处理方式”，这是最有效的保障。
