最需要优先关注的是**食品安全**，其次才是价格和配送准时。原因很直接：

1. **食品安全是底线**
   食堂面向的是企业员工，一旦水果出现农残超标、霉变、腐烂、以次充好等问题，轻则影响员工健康，重则引发群体性食安事件、企业责任和声誉风险。这个风险不可逆，不能靠“便宜”或“准时”弥补。

2. **价格重要，但应排在安全之后**
   企业采购通常有成本控制要求，但水果价格波动大，过分压价容易导致供应商降低品质，比如用次果、临期果、催熟过度或储存不当的货。合理做法是：在符合安全标准的前提下比价，而不是先比价再放宽安全。

3. **配送准时是保障，不是第一目标**
   配送准时影响的是食堂出餐计划、水果新鲜度和员工体验。如果迟到，通常还能调整；但如果送来的是不合格水果，问题更严重。所以准时是“必须做到”的运营要求，但优先级低于食品安全。

**实操建议：**
- 供应商必须提供**批次检测报告/合格证明**，并约定抽检和退换货责任。
- 验收时重点看：新鲜度、有无霉变腐烂、气味异常、规格是否一致。
- 价格上设定**合理区间**，避免最低价中标。
- 配送上明确**时间窗口和迟到处理机制**，但不要用准时去交换安全让步。

一句话总结：**食品安全是一票否决项，价格是竞争项，配送准时是履约项。**
