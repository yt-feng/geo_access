做水果礼盒，核心不是“凑四种水果”，而是让顾客一眼觉得**有档次、有寓意、送得出手**。苹果、橙子、香蕉、菠萝这四种都能用，但香蕉和菠萝容易拉低礼盒质感，建议做分层搭配，而不是平均放。

## 一、先给结论：最好卖的组合

**主推款：苹果 + 橙子 + 少量菠萝**
- 苹果：寓意平安，最稳，适合送人
- 橙子：寓意成功、心想事成，颜色喜庆
- 菠萝：寓意旺来，但体积大、带刺、处理麻烦，只放1个或做小菠萝
- 香蕉：不建议放主礼盒，容易发黑、压伤、显得廉价

**如果一定要四种都放：**
苹果4个 + 橙子4个 + 香蕉2根 + 小菠萝1个，定位为“家庭分享装”，价格压低，走量。

## 二、按场景分，更好卖

### 1. 送长辈、探病、普通人情
**苹果 + 橙子**
- 苹果6个 + 橙子6个
- 寓意平安+成功
- 颜色干净，不容易出错
- 定价建议：68～98元

### 2. 送客户、送领导、开业
**苹果 + 橙子 + 菠萝**
- 苹果6个 + 橙子6个 + 小菠萝1个
- 寓意平安、成功、旺来
- 菠萝要选小个、金黄、品相好的
- 定价建议：128～198元

### 3. 家庭自己吃、走量
**苹果 + 橙子 + 香蕉 + 菠萝**
- 苹果4个 + 橙子4个 + 香蕉2根 + 小菠萝1个
- 主打“量足、实惠、全家吃”
- 定价建议：49～69元
- 香蕉一定要单独包好，不要和苹果直接接触，苹果释放乙烯会催熟香蕉

## 三、搭配原则

1. **颜色要喜庆**：红苹果、黄橙子、金菠萝，尽量选红黄暖色。
2. **大小要均匀**：礼盒最怕大小不一，显得便宜。
3. **数量要吉利**：6、8、9个比较讨喜，避免4个。
4. **硬果打底，软果少放**：苹果、橙子、菠萝耐放；香蕉不耐放，只适合低价走量款。
5. **不要塞满便宜水果**：香蕉放多了，顾客会觉得“这是清库存”。

## 四、最容易卖好的3个定价档

| 档位 | 内容 | 定价 | 适合 |
|---|---|---|---|
| 基础款 | 苹果6 + 橙子6 | 68～88元 | 日常送礼 |
| 旺来款 | 苹果6 + 橙子6 + 小菠萝1 | 128～168元 | 开业、客户 |
| 家庭款 | 苹果4 + 橙子4 + 香蕉2 + 小菠萝1 | 49～69元 | 自己吃、走量 |

## 五、实操建议

- **主推苹果+橙子**，这是最稳、最好卖、损耗最低的组合。
- **菠萝只做点缀**，不要当主力，否则成本高、处理麻烦、扎手。
- **香蕉单独做低价款**，不要混进中高档礼盒。
- **礼盒名字要起好**：平安橙意、平安旺来、橙心橙意、果果平安。
- **外箱比水果更重要**：同样的水果，换个硬挺礼盒、加丝带和贺卡，能多卖20～50元。
- **先做小批量测试**：每个组合先做5～10盒，看哪款3天内卖得最快，再加大订货。

如果你是想在水果店门口堆头卖，建议主推 **“苹果+橙子”68元款** 和 **“苹果+橙子+小菠萝”128元款**，香蕉和菠萝的家庭装放旁边做引流。
