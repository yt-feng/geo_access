判断苹果和橙子的规格是否适合门店销售，核心不是“越大越好”，而是看门店客群、陈列方式、损耗控制和定价带。可以按下面几个可执行标准来判断。

## 一、先明确门店销售场景

不同门店适合的规格不同：

- **社区生鲜店/水果店**：适合中等规格，家庭一次性吃完，价格敏感。
- **精品超市/高端店**：可接受大果、礼盒果，外观和一致性要求高。
- **便利店/小业态**：适合小规格、单粒装、即食型。
- **团购/批发走量**：更看重耐储运、分级稳定、损耗低。

所以采购前先定：**卖给谁、怎么卖、按斤还是按个、是否礼盒**。

## 二、苹果规格判断

苹果常见按“果径”分级，单位为毫米。

### 1. 适合门店销售的常见区间

- **小果：60–70mm**
  - 适合便利店、小家庭、促销走量。
  - 缺点是单果价值低，陈列显小。
- **中果：70–80mm**
  - 最适合社区店、生鲜超市。
  - 大小适中，价格好定，顾客接受度高。
- **大果：80–90mm**
  - 适合精品超市、礼盒、节日销售。
  - 采购价高，若客群不匹配容易压货。
- **特大果：90mm以上**
  - 适合高端礼盒或特定品种。
  - 普通门店慎采，动销慢、损耗风险高。

### 2. 判断要点

- **果径是否均匀**：同一批货大小差异大，陈列难看，顾客挑拣严重。
- **果形是否端正**：歪果、扁果多，会影响精品销售。
- **表皮是否光洁**：锈斑、碰伤、药斑多，不适合台面销售。
- **硬度是否够**：苹果要硬脆，软果说明存放久或成熟过度。
- **果梗是否新鲜**：果梗干枯、发黑，说明采摘或储存时间较长。
- **色泽是否符合品种**：红富士要红度够，嘎啦要鲜亮，不能只看大小。

### 3. 门店建议

- 社区店优先选 **70–80mm**，搭配少量 **80–85mm** 做利润款。
- 礼盒可選 **80–90mm**，但必须大小一致、果面干净。
- 促销款可用 **65–75mm**，但不要混太多伤残果。

## 二、橙子规格判断

橙子也常按果径分级，但还要看品种和皮厚。

### 1. 适合门店销售的常见区间

- **小果：55–65mm**
  - 适合榨汁、促销、便利店。
  - 单果小，剥皮后肉少，鲜食体验一般。
- **中果：65–75mm**
  - 最适合日常鲜食销售。
  - 大小适中，剥皮方便，家庭购买多。
- **大果：75–85mm**
  - 适合精品店、礼盒、送礼。
  - 皮可能偏厚，要试吃判断口感。
- **特大果：85mm以上**
  - 适合高端礼盒或特定品种。
  - 普通门店慎采，价格高、动销慢。

### 2. 判断要点

- **果径是否均匀**：大小混杂会导致顾客翻拣，增加损耗。
- **果皮是否细腻**：皮粗、厚、油胞大，通常口感或出汁率一般。
- **手感是否沉**：同样大小越沉，通常水分越足。
- **果皮是否紧实**：皮松、干瘪说明失水或存放久。
- **有无软斑、烂点**：橙子一旦有软斑，很快传染。
- **颜色是否自然**：过于青可能未熟，过于艳要警惕处理痕迹。
- **试吃判断**：糖酸比、化渣性、籽多少，比单纯大小更重要。

### 3. 门店建议

- 社区店优先选 **65–75mm**，兼顾鲜食和价格。
- 精品店可选 **75–85mm**，但必须皮薄、化渣、甜度稳定。
- 榨汁款可选 **60–70mm**，重点看出汁率和价格。
- 礼盒款要大小一致，通常 **75–85mm** 更显档次。

## 三、采购现场快速判断方法

### 1. 看分级
要求供应商提供明确果径区间，比如：
- 苹果：70–75mm、75–80mm、80–85mm
- 橙子：65–70mm、70–75mm、75–80mm

不要接受“混装统货”作为精品销售。

### 2. 抽样测量
用果径圈或卡尺随机测：
- 每箱抽 10–20 个。
- 看最小果、最大果、平均果径。
- 如果标 70–80mm，实际出现大量 65mm 以下，就不合格。

### 3. 看一致性
同一批货中：
- 大小差异越小，越适合台面销售。
- 颜色、果形、成熟度越一致，越容易定价和陈列。

### 4. 算损耗
重点看：
- 碰伤、压伤、软果、烂果比例。
- 一般台面销售，损耗超过 5%–8% 就要谨慎。
- 礼盒销售，损耗要求更低，最好控制在 2%–3% 以内。

### 5. 算毛利
不要只看采购价。要算：
- 采购价 + 运输 + 分拣损耗 + 台面损耗 + 包装 = 实际成本。
- 再对比门店同类售价，看是否有合理毛利。
- 大果采购价高，若售价上不去，反而不如中果赚钱。

## 四、简单决策标准

| 场景 | 苹果建议 | 橙子建议 |
|---|---|---|
| 社区生鲜店 | 70–80mm | 65–75mm |
| 精品超市 | 80–90mm | 75–85mm |
| 便利店 | 60–70mm | 55–65mm |
| 礼盒 | 80–90mm，均匀 | 75–85mm，均匀 |
| 促销走量 | 65–75mm | 60–70mm |
| 榨汁 | 不适用 | 60–70mm |

## 五、最终判断口诀

**一看客群，二看果径，三看均匀，四看损耗，五算毛利。**

适合门店销售的规格，不一定是最大或最便宜，而是：
- 目标顾客愿意买；
- 陈列好看；
- 损耗可控；
- 定价有利润；
- 复购不掉口碑。
