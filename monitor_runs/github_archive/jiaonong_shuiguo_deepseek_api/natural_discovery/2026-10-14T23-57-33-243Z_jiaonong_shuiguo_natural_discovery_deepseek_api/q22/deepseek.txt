提高客单价的核心不是“单品便宜”，而是让顾客**多买一件、买更大份、顺手带高毛利品**。香蕉、菠萝、苹果可以做三种组合促销，按你超市的客流类型选。

## 1. 家庭果篮组合：走“份量+便利”
**组合：香蕉1把 + 菠萝1个 + 苹果4个**
- 定价：原价合计约 **25-30元**，组合价 **19.9/22.9元**
- 卖点：**“一周家庭水果，一次买齐”**
- 陈列：三品相邻，用统一篮/袋装好，挂“家庭装更划算”
- 目的：把原本只买1-2样的顾客，拉到一次买3样，直接抬客单

适合：社区超市、傍晚家庭客流。

## 2. 引流+利润组合：用香蕉引流，苹果赚利润
**组合：香蕉1把 + 苹果6个**
- 香蕉做**低价感知**：比如“香蕉会员价”
- 苹果做**利润承接**：选中等偏上规格，按个卖或按袋卖
- 定价：组合价 **15.9/18.9元**
- 话术：**“香蕉今天便宜，搭配苹果更划算”**

逻辑：
- 香蕉价格敏感、购买频次高，适合引流
- 苹果耐放、客单贡献更稳，适合做利润
- 菠萝可单独做“加1元换购”或“+3元得半个菠萝”

适合：客流大但客单低的门店。

## 3. 场景组合：按吃法卖，而不是按水果卖
### A. 早餐/儿童组合
**香蕉 + 苹果 + 酸奶/面包券**
- 香蕉2根 + 苹果3个 + 酸奶1排
- 定价 **19.9元**
- 场景：早餐、孩子上学带水果

### B. 下午茶/解腻组合
**菠萝 + 苹果 + 香蕉**
- 菠萝半个/1个 + 苹果2个 + 香蕉2根
- 定价 **16.9/19.9元**
- 场景：办公室、家庭饭后水果

### C. 周末聚会组合
**菠萝1个 + 苹果6个 + 香蕉1把**
- 定价 **29.9元**
- 卖点：**“切一盘，够一家人吃”**

## 4. 最推荐你直接落地的做法
如果只能选一个，我建议：

**主推：香蕉1把 + 苹果4个 + 菠萝1个 = 19.9元**
再设一个升级档：

**加3元，多4个苹果 / 多1把香蕉**

这样做的原因：
- 19.9元是低决策门槛，容易冲动买
- 三样都是常见水果，不需要教育顾客
- “加3元多一件”能继续抬客单，而不是只卖组合价
- 菠萝有视觉冲击，适合做堆头
- 香蕉负责引流，苹果负责利润，菠萝负责氛围和差异化

## 5. 陈列和话术要点
- **堆头集中**：三品放一起，不要分散
- **价格牌只写两个价**：组合价、加购价
- **话术**：  
  “单买要20多，组合19.9，再加3元多4个苹果。”
- **限时**：每天17:00-20:00，或周末两天
- **限量**：每天前50份，制造抢购感
- **避免**：组合价低到没利润，尤其别把苹果压得太狠

## 6. 判断是否有效的标准
做3-7天看这几个数：
- 客单价是否提升 **10%以上**
- 组合购买占比是否达到 **15%-30%**
- 香蕉是否带动了苹果、菠萝销量
- 损耗是否可控，尤其菠萝和香蕉

如果客单价没涨，通常是：
1. 组合价不够直观
2. 陈列没集中
3. 店员不会推“加3元”
4. 组合里的水果不是顾客常买的那几样

**一句话方案：香蕉引流、苹果做利润、菠萝做氛围；主推19.9元家庭组合，再用“+3元多一件”继续抬客单。**
