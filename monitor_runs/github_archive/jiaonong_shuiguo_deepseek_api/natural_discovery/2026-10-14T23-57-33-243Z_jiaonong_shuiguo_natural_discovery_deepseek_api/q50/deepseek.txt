**先看你的用途，再分优先级：**

**1. 如果是做“水果茶/菠萝茶饮”的主料（果肉感重要）**
→ **出汁率更优先，但甜度不能太低。**
因为这类产品通常要的是：
- 果肉有存在感
- 咬下去有汁水
- 和茶底搭配后不寡淡

如果出汁率低，果肉干、柴、纤维感重，顾客第一口就觉得“不值”。甜度不够可以靠糖浆、果酱补，但**汁水感很难后期弥补**。

**2. 如果是做“菠萝果酱/浓缩汁/调味基底”**
→ **甜度更优先。**
因为这类产品最终会被稀释、调配，甜度稳定才能保证出品一致。出汁率反而可以通过工艺压榨、复配来补。

**3. 如果是做“鲜切菠萝/装饰块”**
→ **两者都要，但甜度略优先。**
顾客直接吃或看到果肉，甜度差会非常明显；出汁率只要不是特别干，影响相对小。

---

**实务判断标准：**

| 用途 | 第一优先 | 第二优先 |
|---|---|---|
| 水果茶主料 | 出汁率 | 甜度 |
| 果酱/浓缩汁 | 甜度 | 出汁率 |
| 鲜切装饰 | 甜度 | 出汁率 |
| 冰沙/打碎类 | 出汁率 | 甜度 |

---

**采购建议：**
- 先定产品类型，再定标准。
- 如果只能二选一，**水果茶店通常选出汁率高的**，因为甜度可用糖补，汁水感难补。
- 但要注意：**出汁率高≠一定好**，如果甜度太低、酸涩重，也会拉高糖浆成本，最后综合成本未必低。

**一句话结论：**
做水果茶，**出汁率优先**；做调味基底或鲜切，**甜度优先**。最稳的是按你的菜单定位，设一个“最低甜度+最低出汁率”的双门槛，而不是只选一个。
