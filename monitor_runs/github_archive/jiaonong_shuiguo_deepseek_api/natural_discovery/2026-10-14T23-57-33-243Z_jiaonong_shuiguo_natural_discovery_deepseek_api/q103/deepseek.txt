**结论：优先按斤结算，辅以“按份/按箱”做套餐或固定配餐。**  
如果食堂要“好管理”，关键不是哪个计价方式绝对最好，而是看你要控成本、控损耗，还是图省事。

**1. 按斤结算：最适合大多数食堂**
- **优点**：价格透明，方便比价、验收、核算成本；损耗和用量容易追踪。
- **缺点**：验收麻烦，要称重、录单；水果大小不一，人工成本高。
- **适用**：日常采购、用量大、想控成本、有专人验收的食堂。

**2. 按箱结算：适合标准化程度高的水果**
- **优点**：下单快、验收快、结算简单，适合苹果、橙子、香蕉等规格稳定的箱装水果。
- **缺点**：箱内品质不均、净重不稳，容易“按箱买、按斤亏”；退换货扯皮多。
- **适用**：供应商稳定、箱规明确、长期合作且能约定“净重/坏果率”的场景。

**3. 按份结算：适合直接面向用餐者的配餐**
- **优点**：管理最省事，按人头或按份发放，便于控制每人份量。
- **缺点**：采购端不透明，容易被供应商在“份量”上做文章；不利于成本核算。
- **适用**：水果作为套餐、加餐、会议餐固定发放，不单独售卖。

**建议的组合方案：**
- **采购端按斤**：和供应商签“按斤计价、按箱送货”，验收时抽检净重和坏果率。
- **内部发放按份**：比如每人每餐1个苹果/1根香蕉，方便窗口发放。
- **大宗稳定品类按箱**：如香蕉、橙子，约定箱规、净重、坏果率上限。
- **零散或高价值水果按斤**：如葡萄、草莓、车厘子，必须称重验收。

**一句话：**
想控成本、少扯皮，**按斤最好**；想省人工、发得快，**按份最好**；想下单验收快，**按箱最好，但必须把净重和坏果率写进合同。**
