判断香蕉和菠萝供应商靠不靠谱，不要只看报价，建议从下面6个方面实地验证。香蕉和菠萝都是“催熟/损耗敏感型”水果，供应商的稳定性比单次低价更重要。

**1. 先看它有没有稳定货源和加工能力**
- 香蕉：问清楚是哪里产的、是否自己做催熟。靠谱供应商通常有催熟库，能按你要的成熟度（如1-2号色、3-4号色）分批出货。如果只是转手倒卖，旺季容易断货或给你塞生蕉。
- 菠萝：问是海南、广东、云南还是进口，是否有固定基地或长期合作果园。菠萝季节性强，能跨产区调货的供应商更稳。
- 判断方法：要求看仓库、催熟库、冷库照片或视频，最好实地去一次。

**2. 看分级和规格是否稳定**
- 香蕉：问每箱净重、每把条数、单根重量范围、是否允许±0.5斤误差。靠谱供应商会按规格分拣，不会这箱大那箱小。
- 菠萝：问单果重量范围、成熟度、是否去冠、是否套袋、黑心/水心病比例怎么赔。
- 判断方法：连续3次下单，每次随机抽1箱称重、数数、切开看内部。规格波动小才靠谱。

**3. 看催熟和成熟度控制**
- 香蕉最怕“青蕉到店不熟”或“到店已经过熟”。靠谱供应商能根据你的销售速度给不同成熟度，比如今天卖的快给3号色，卖得慢给2号色。
- 菠萝要问是“青果”还是“熟果”，熟果适合直接卖，青果适合放几天。供应商如果不懂这些，基本是做批发的，不是做水果店供应的。
- 判断方法：让他发一批你指定成熟度的货，看能不能做到。

**4. 看损耗赔付和售后态度**
- 直接问：坏果、烂果、黑心菠萝、催熟失败的香蕉怎么赔？是按箱赔、按斤赔，还是下次补？
- 靠谱供应商会明确写赔付标准，比如“到货24小时内拍照，坏果超过5%按比例赔”。
- 不靠谱的常见话术：“水果都有损耗”“下次给你补点”“这个价格就这样”。
- 判断方法：故意下一次小单，然后反馈几个坏果，看他处理速度和是否爽快。

**5. 看价格是否透明、是否乱加价**
- 不要只比单价，要比“到店净重成本”。问清楚是否含运费、装卸费、箱子重量、是否包损耗。
- 香蕉价格波动大，靠谱供应商会提前告诉你“今天产地涨了，明天可能调价”，而不是到货才临时加价。
- 菠萝要问是否按个还是按斤，是否有“大小混装”压价。
- 判断方法：让他连续报一周价格，看是否跟市场行情大致同步，还是忽高忽低。

**6. 看合作门槛和账期**
- 靠谱供应商通常愿意先做现结小单，再谈账期。一上来就要求大额预付、压很多货的，要警惕。
- 问清楚起送量、配送频率、能否固定时间到店。香蕉和菠萝都需要稳定补货，配送不准时会直接影响你排面。
- 判断方法：先合作2-4周，每周2-3次小批量，观察断货率、准时率、损耗率。

**实操建议：**
- 同时找2-3家供应商，不要只依赖一家。香蕉一家主供、一家备用；菠萝按季节切换产区。
- 建一个简单表格，记录每次到货的：净重、坏果率、成熟度、准时率、售后响应。连续记1个月，谁靠谱一目了然。
- 第一次合作不要压大单，先试小单。试3次后再谈价格和账期。
- 香蕉重点看催熟，菠萝重点看黑心率和成熟度。这两个指标不过关，价格再低也别长期做。

一句话：**能稳定给你合适成熟度、规格不飘、坏果敢赔、配送准时的供应商，才值得长期合作。**
