核实水果供应商的全国配送能力，不能只听口头承诺，要落到**可验证的证据和试单**上。可以按下面几步做。

**一、先要书面配送范围，不要口头说**
让对方提供：
- 可配送省份/城市清单，最好具体到“偏远地区是否覆盖”（新疆、西藏、青海、内蒙古、海南、云贵川部分山区等）
- 哪些地区只能到市区、哪些能到县镇
- 是否支持冷链、是否支持一件代发/整车/零担
- 配送时效承诺和截单时间

**二、核验物流合作方**
- 问清用哪几家物流/快递：顺丰、京东、德邦、中通、跨越、当地专线等
- 要求提供物流合作凭证或系统截图，比如后台可下单范围、运费模板
- 直接拿几个目标城市的地址，让对方在系统里试算运费和时效
- 对水果而言，重点问：是否冷链、是否中转、破损/腐损怎么赔

**三、用真实地址做“盲测”**
选几个有代表性的收货地址：
- 一线城市
- 二三线城市
- 县级市
- 偏远地区
- 你实际要铺货的重点区域

让供应商分别报价并给出预计到达时间。注意看：
- 是否临时加价
- 是否说“能到”但实际只能到地级市，县镇要自提
- 生鲜是否走普通快递，导致时效过长

**四、小批量试单**
这是最有效的方式：
- 先下 3–5 个不同区域的小单
- 记录下单时间、发货时间、到达时间、包装状态、损耗率
- 检查是否真冷链、是否混装、是否有异味/压伤
- 试单后再判断能不能放量

**五、查履约和售后记录**
- 要求提供近期的配送数据：准时率、破损率、投诉率
- 问清售后流程：坏果怎么赔、多久内反馈、是否需要拍照、谁承担运费
- 看对方是否敢把赔付标准写进合同

**六、合同里写清楚**
建议明确：
- 配送覆盖范围及例外区域
- 时效标准
- 冷链要求
- 损耗/坏果赔付比例
- 临时加价或不可达时的处理方式
- 违约和退出机制

**七、交叉验证**
- 问同行或同区域采购方有没有合作过
- 查企业工商信息、经营异常、涉诉情况
- 如果对方是中间商，要确认它是否能直接调动产地和物流

**简单判断标准：**
如果对方只能口头说“全国都能发”，但拿不出区域清单、物流系统截图、冷链方案和试单数据，那实际覆盖能力通常要打折扣。真正有能力的供应商，一般敢让你指定地址试单，也敢把时效和赔付写进合同。
