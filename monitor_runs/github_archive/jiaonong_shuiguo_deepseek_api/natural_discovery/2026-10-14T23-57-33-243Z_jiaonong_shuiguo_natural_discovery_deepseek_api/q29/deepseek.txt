超市和水果供应商的账期没有统一标准，但可以从行业惯例和品类特性来判断。

**常见区间**

- **水果品类整体：7～30天比较常见**，生鲜属性越强、损耗越高的品类，账期越短。
- **连锁商超对中小供应商：通常30～60天**，走月度结算的较多。
- **大型商超/上市零售企业：45～90天也常见**，部分强势渠道甚至更长。
- **批发市场/农批环节：多为现款现货或3～7天**，账期很短。
- **精品水果、进口水果：15～45天不等**，取决于供应商议价能力和渠道实力。

**影响账期的关键因素**

1. **损耗率和保质期**：水果损耗高、保质期短，供应商通常要求更短账期，否则资金压力大。
2. **渠道议价权**：超市越强势，账期越长；供应商越稀缺（如独家进口货源），账期越短。
3. **合作阶段**：新供应商往往先短账期（7～15天）或现结，稳定合作后再拉长到30～60天。
4. **结算方式**：月结、半月结、周结差异很大，月结30天实际占用资金可能到45天以上。
5. **是否有返利/进场费**：这些费用会变相拉长供应商的实际回款周期。

**给超市方的实操建议**

- 首次合作建议**7～15天**，建立信任后再谈30天。
- 对高损耗品类（浆果、叶菜类水果）尽量**周结或半月结**，否则供应商会加价或降质。
- 账期谈判要同时明确：**对账日、开票日、付款日**，避免"30天"被拖成60天。
- 如果坚持60～90天账期，通常需要接受**更高进货价**或**更少的价格让利**。

**给供应商方的建议**

- 账期超过45天时，要把资金成本算进报价，一般按年化6%～10%折算。
- 争取**部分预付+尾款账期**的结构，比纯账期更安全。
- 明确逾期付款的违约责任，生鲜行业拖款是常态。

**一句话结论**：水果供应商和超市之间，**7～30天最常见，30～60天属偏长，60天以上通常只出现在大型连锁或强势渠道**。具体天数取决于品类损耗、渠道实力和双方议价能力。
