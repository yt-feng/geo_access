餐饮店每天少量水果，想省心，核心不是找“最便宜的”，而是找**履约稳定、能小批量、能按你要求预处理、售后不扯皮**的供应商。可以按下面顺序选。

**优先顺序建议**

1. **本地水果批发市场的固定档口**
   - 最适合每天少量、品类会变的情况。
   - 优点：可以当面挑，价格比零售低，量少也愿意送，谈得好可每天或隔天配送。
   - 注意：找有固定摊位、做餐饮客户多的档口，不要找流动摊贩。
   - 省心做法：固定一家主供 + 一家备用，提前一晚发第二天的品种、数量、规格。

2. **本地生鲜配送平台/餐饮供应链平台**
   - 比如本地的餐饮B2B配送、美菜类、快驴类，或区域生鲜配送商。
   - 优点：线上下单、次日达、售后相对规范，适合不想每天去市场的人。
   - 缺点：起送门槛、品质波动、热门水果不一定便宜。
   - 适合：你每天只要几斤到几十斤，且不想花时间议价。

3. **水果店/精品水果店长期合作**
   - 适合用量很小、要求品质稳定、需要切果或净果的店。
   - 优点：灵活、可临时补货、能按份切好。
   - 缺点：单价通常高于批发市场。
   - 适合：沙拉店、甜品店、饮品店用果量不大但要求外观和口感稳定。

4. **产地/一级批发商直供**
   - 只有当你某个单品用量稳定且较大时才划算，比如每天固定用大量柠檬、西瓜、橙子。
   - 少量多品不建议，因为起送量、物流、损耗都不划算。

**选供应商时重点看这几点**

- **能不能小批量配送**：起送金额、配送费、是否每天送。
- **能不能按规格供货**：比如柠檬70-80克、西瓜切块、苹果80以上、香蕉几成熟。
- **损耗谁承担**：坏果、烂果、缺斤少两是否补送或退款。
- **配送时间是否匹配**：餐饮店通常要早上到货，不能影响备餐。
- **是否支持临时加单**：周末、节假日、突然爆单时能不能补。
- **账期和结算**：日结、周结、月结，是否开票。
- **有没有替代方案**：主供断货时，备用供应商能否马上接上。

**最省心的合作模式**

- 固定1家主供，签简单供货协议或至少微信确认价格规则。
- 再留1家备用，避免主供临时涨价或断货。
- 每天固定时间下单，比如晚上8点前发次日订单。
- 要求“坏果包赔、缺斤少两补差、迟到提前说”。
- 对常用水果定标准，比如：
  - 柠檬：中等大小，无干疤；
  - 西瓜：固定品种和熟度；
  - 苹果：脆甜，无明显磕碰；
  - 香蕉：到货后2-3天可用。
- 每周对一次账，避免月底扯皮。

**如果你量真的很小**

比如每天只有几斤，最省心的往往是：
**附近水果店长期合作 + 每周谈一次价 + 要求早上顺路送。**
因为批发市场档口可能嫌量小，B2B平台又有起送门槛，水果店反而最灵活。

**一句话结论**

餐饮店每天少量水果，优先找**本地批发市场固定档口**或**本地餐饮生鲜配送商**；如果量很小又要求省心，就找**附近水果店长期合作**。关键是固定主供、留备用、提前下单、约定坏果赔付和配送时间。
