选择下午茶水果供应商，核心不是“哪家最好”，而是**按你们公司的配送条件、预算、人数和验收能力去匹配**。下面给你一套可直接执行的判断框架。

## 一、先定3个硬条件，再去找供应商

1. **人数和频次**  
   - 20人以下：更适合精品水果店、盒马/山姆等零售配送，或小批量团购。
   - 20–100人：找本地水果批发商、团餐配送商、企业福利供应商。
   - 100人以上或每周固定：直接谈本地批发市场档口、产地直供、专业企业下午茶配送商。

2. **配送地址和时间窗口**  
   - 写字楼是否允许外卖/货车进入，有没有货梯、前台签收限制。
   - 要求供应商能按你们指定时间送达，比如下午2点前，而不是“当天达”。

3. **预算和结算方式**  
   - 按人头算：如每人8–15元，适合切果盒、小份装。
   - 按斤/箱算：适合整果自切，成本低但需要行政分发。
   - 能否月结、开票、对公转账，这决定能不能走企业采购。

## 二、适合批量配送的供应商类型

| 类型 | 适合场景 | 优点 | 风险 |
|---|---|---|---|
| 本地水果批发市场档口 | 100人以上、频次高 | 价格低、品类多 | 配送和售后不稳定，需自己验货 |
| 企业团餐/福利配送商 | 30–300人 | 能开票、按人头配、配送稳 | 单价略高，水果品质看选品 |
| 生鲜电商企业购 | 20–100人 | 下单方便、发票规范 | 批量折扣有限，高峰期配送不稳 |
| 精品水果店/连锁店 | 20人以下 | 品质稳定、可切果 | 批量成本高 |
| 产地直供/果园 | 单品批量、季节性强 | 新鲜、成本低 | 物流损耗大，售后麻烦 |

## 三、筛选供应商的6个关键问题

直接问对方，回答含糊的基本可以淘汰：

1. **起送量和配送费怎么算？**  
   批量配送最怕“满多少才送”或临时加运费。

2. **能不能按人头分装？**  
   比如每人一盒混合果切，还是整箱到货需要你们自己分。

3. **坏果、压伤、不熟怎么赔？**  
   要求明确：签收后几小时内反馈，按比例退款还是补送。

4. **是否支持先送样品？**  
   先试一次小批量，比看图片靠谱。

5. **能不能固定每周菜单？**  
   批量配送要避免每次都临时选品，最好有季节水果轮换表。

6. **发票和结算是否规范？**  
   企业采购必须能开普票/专票，支持对公。

## 四、建议的采购方式

- **20人以下**：生鲜电商企业购 + 本地精品水果店，按次下单。
- **20–100人**：找1–2家本地企业配送商，签月度框架，按周送。
- **100人以上**：本地批发市场档口 + 专业配送商组合，一家保价格，一家保稳定。
- **高频下午茶**：优先选“整果 + 少量果切”组合，整果损耗低，果切体验好但成本高。

## 五、验收和避坑

1. **首次合作先小单测试**：不要一上来就签长期。
2. **到货当场抽检**：看底层、看箱底，不只看看表面。
3. **固定验收人**：行政或前台专人签收，拍照留证。
4. **避开高风险品类**：夏季少选草莓、蓝莓、切好的西瓜，损耗和投诉高。
5. **写清赔付标准**：比如坏果超过5%按整箱补或退款。

## 六、直接可用的选择标准

你可以按这个优先级打分：

1. 能按时送、能开票、能赔付：必须满足。
2. 价格在预算内：其次。
3. 能按人头分装：加分。
4. 能先试样品：加分。
5. 有企业客户案例：加分。

**结论**：批量配送优先找本地企业团餐/福利配送商或批发市场档口，不要只看生鲜电商。先定人数、预算、配送时间，再要求试送和明确赔付，基本就不会踩大坑。
