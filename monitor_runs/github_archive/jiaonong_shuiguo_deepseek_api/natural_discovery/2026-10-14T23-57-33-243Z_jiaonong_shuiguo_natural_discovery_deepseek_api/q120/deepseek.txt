供应商介绍时，核心不是讲“品种多专业”，而是帮商家快速判断三件事：**我能不能卖、好不好卖、赚不赚钱**。可以按下面这套话术来讲。

**1. 先挂钩商家 already 熟悉的大品类**
不要说“这是台农17号凤梨”，而要说：

“这个可以理解成**菠萝的升级款/替代款**：比普通菠萝更甜、不用泡盐水、切开就能吃，顾客接受度更高。”

“这个可以理解成**香蕉里的小众高毛利款**：像香蕉一样好卖，但单价能卖更高，适合做差异化和礼盒。”

先让商家用已知品类理解新品，降低认知成本。

**2. 用“顾客买它的理由”来讲，而不是用品种参数讲**
商家最关心的是顾客为什么买。可以说：

- **口感理由**：更甜、更香、不酸、不涩、无籽、皮薄、肉多。
- **使用理由**：不用削、不用泡、不用切、开袋即食、适合榨汁、适合送礼。
- **场景理由**：早餐、下午茶、儿童零食、健身代餐、节日礼盒、门店引流。
- **对比理由**：比普通菠萝贵一点，但顾客复购更高；比普通香蕉保质期长，损耗低。

**3. 直接给商家算账，不要只报供货价**
商家听不懂“产地、糖度、规格”，但一定听得懂：

“你进价一箱XX元，建议零售XX元，一箱大概能卖XX元，毛利XX元。损耗比普通菠萝低，因为不用现场削皮，卖不完还能做果切。”

最好直接说：
- 进货价
- 建议零售价
- 毛利空间
- 损耗率
- 保质期/存放天数
- 适合怎么卖：散卖、果切、礼盒、团购、外卖

**4. 用一句话对比表，让商家秒懂**
可以这样介绍：

| 商家熟悉的品类 | 这个产品 | 商家能得到什么 |
|---|---|---|
| 普通菠萝 | 手撕凤梨/金钻凤梨 | 更甜、不用泡盐水、好卖价更高 |
| 普通香蕉 | 小米蕉/皇帝蕉 | 单价高、礼盒好做、差异化 |
| 普通橙子 | 沃柑/耙耙柑 | 好剥、甜、复购高 |
| 普通苹果 | 瑞雪/维纳斯 | 差异化、送礼有面子 |

**5. 给“最小下单理由”，降低决策压力**
不要一上来让商家压货。可以说：

“你先拿一箱试卖，放在收银台旁边做试吃。如果一天能卖完，下次再拿三箱。这个品不占冷库，常温能放X天，卖不动还能做果切/果汁，不亏。”

**6. 一句话模板**
供应商可以直接套：

“王老板，这个你就把它当成**升级版菠萝**。普通菠萝顾客嫌削皮麻烦、要泡盐水，这个不用泡、切开就吃，更甜。你进价XX，建议卖XX，一箱毛利大约XX。你先拿一箱放门口试吃，好卖再补，不好卖也能做果切，不压货。”

**关键原则：**
- 先对标大品类：菠萝、香蕉、橙子、苹果。
- 再讲顾客理由：更甜、更方便、更好看、更适合送礼。
- 最后算商家账：进价、卖价、毛利、损耗、复购。
- 给低风险尝试：先小批量、试吃、果切兜底。

商家下单不是因为听懂品种，而是因为听懂了：**这个货容易卖，而且有钱赚。**
