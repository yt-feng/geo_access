优先谈 **账期**，其次 **售后**，最后 **配送**。

原因很直接：长期水果供应里，真正容易造成隐性亏损和关系失控的，通常不是配送慢半天，而是 **账期被拉长、对账不清、坏果赔付没有标准**。

可以按这个顺序判断和谈：

1. **账期最值得优先谈**
   - 水果损耗高、价格波动大，账期越长，你的现金流压力越大。
   - 重点不是只谈“多少天”，而是谈清楚：
     - 账期起算日：送货日、对账日还是开票日。
     - 对账周期：每周、每半月还是每月。
     - 付款方式：现结、周结、月结、货到付款。
     - 逾期责任：对方延迟对账或开票怎么处理。
   - 如果供应商愿意给更长账期，但价格明显上浮，要算资金成本，不一定划算。

2. **售后第二优先谈**
   - 水果非标品，坏果、压伤、规格不符、成熟度不稳定很常见。
   - 必须谈清楚：
     - 验收标准：品种、规格、糖度、成熟度、单果重、包装要求。
     - 赔付标准：坏果率多少以内免赔，超过怎么赔，是按斤赔、补货还是扣款。
     - 反馈时效：收货后几小时内报损有效。
     - 举证方式：照片、视频、抽检比例、整批还是单箱判定。
   - 售后不清晰，后面每次出问题都会扯皮，长期合作反而更累。

3. **配送最后谈，但不能不谈**
   - 配送重要，但通常可以通过备选供应商、库存缓冲、配送时间约定来缓解。
   - 重点谈：
     - 下单截止时间。
     - 送达时间窗口。
     - 临时加单、减单、改单怎么处理。
     - 缺货、迟到、送错货的补偿。
     - 是否冷链、装卸责任、到店验收流程。
   - 如果你们是餐饮、门店、生鲜零售，配送时效影响营业，那配送权重可以提高，甚至和售后并列。

**建议谈判策略：**
- 先谈 **账期 + 售后** 打包：用稳定采购量换更短账期或更明确赔付。
- 再谈 **配送**：要求固定送达窗口和异常处理机制。
- 最后谈 **价格**：价格不要单独谈，要和账期、售后、配送一起算综合成本。

一句话：  
**账期决定现金流，售后决定真实成本，配送决定运营稳定。长期合作先保现金流和赔付规则，再优化配送。**
