香蕉到店后很快变黑，核心原因通常不是“买得不对”，而是**温度、乙烯和机械损伤**叠加。按下面做，基本能把货架期从1～2天拉到3～5天，未熟青蕉还能更久。

**1. 采购时按成熟度分等级买**
- 优先买**青绿、棱角明显、手感硬**的香蕉，不要买已经通体金黄、带黑点的。
- 如果当天就要用，买“微黄带青肩”的；如果备2～3天，买更青的。
- 整串买比散买更耐放，散装香蕉伤口多、乙烯释放快。

**2. 运输和到店后先“散热”**
- 香蕉怕闷热。到店后不要立刻堆进密闭仓库或冰箱旁，先放在**阴凉通风处**摊开散热。
- 理想存放温度：**13～15℃**。低于12℃容易冻伤，皮会快速变黑；高于20℃会加速成熟。
- 不要放冰箱冷藏，除非已经熟透且准备马上做果泥/烘焙。

**3. 控制乙烯**
- 香蕉自身会释放乙烯，而且对乙烯很敏感。
- 不要和苹果、梨、番茄、牛油果等释放乙烯多的水果放一起。
- 如果店里空间小，可用**乙烯吸收剂**或单独隔离存放。
- 已熟香蕉和青香蕉要分开，否则青的会被催熟，熟的会更快黑。

**4. 减少机械损伤**
- 搬运时避免挤压、碰撞、摩擦。
- 不要为了省空间把香蕉压叠堆放。
- 有伤口、裂口、发软的香蕉先挑出来优先使用，不要和好货混放。

**5. 悬挂或单层摆放**
- 有条件就**悬挂**，减少受压面积。
- 没条件就单层摆放，果柄朝上或侧放，避免堆压。
- 不要用塑料袋长期闷着，容易积热和乙烯。需要保湿时用带孔保鲜膜或纸箱，留通风口。

**6. 分批次使用**
- 把香蕉按成熟度分成：青、微黄、熟、即用。
- 青的放最里面，熟的放最外面先消耗。
- 每天检查一次，把开始变黑的先拿去做奶昔、烘焙、香蕉泥，避免影响其他香蕉。

**7. 如果已经有点熟，怎么延缓**
- 立即移到13～15℃阴凉通风处。
- 和青香蕉隔离。
- 不要洗，表皮有水更容易黑。
- 如果只是表皮少量黑点、果肉正常，优先当天用完。

**简单执行版：**
买青一点 → 到店摊开散热 → 放13～15℃通风处 → 远离苹果梨番茄 → 不压不闷 → 青熟分开 → 每天挑熟先卖。这样基本能明显延缓变黑。
