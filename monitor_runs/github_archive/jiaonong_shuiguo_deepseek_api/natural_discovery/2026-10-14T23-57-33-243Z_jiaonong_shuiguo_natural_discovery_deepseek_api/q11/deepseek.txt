会有影响，但影响大小取决于你的销售方式和客户类型。

**1. 整箱卖给批发/水果摊客户**
影响较小。对方通常按斤或按箱走量，大小不一是常态，只要成熟度、品相、损耗率可控就行。关键是提前说清楚规格，避免对方以“大小不均”压价。

**2. 门店零售、散卖**
影响比较明显。香蕉零售很看外观整齐度，大小混在一起会让顾客挑拣，造成：
- 大的先被挑走，小的剩下来，损耗增加；
- 顾客觉得“品相不统一”，心理上觉得不新鲜或不值；
- 称重销售时，大小差异大容易引发挑货、翻箱。

**3. 做促销或切果盘、榨汁**
影响小。大小不一但成熟度一致的香蕉，适合做特价、按把卖、切果盒或加工用途，价格有优势反而好卖。

**建议你这样做：**
- 采购时先问清楚：同箱大小差异范围、成熟度是否一致、是否有青蕉混熟蕉。
- 如果门店零售，尽量按大小分拣：大的做精品陈列，小的做特价或加工。
- 如果整箱转手，提前和客户确认接受度，最好按“统货”定价，别按精品价卖。
- 看损耗：大小差异大往往意味着后熟不一致，小蕉可能熟得快或慢，库存周期要缩短。

**判断标准：**
- 差异在1-2个规格内、成熟度一致：影响不大。
- 大小混杂明显、成熟度还不一致：零售会影响销售和损耗，建议压价采购或改走加工/促销渠道。
