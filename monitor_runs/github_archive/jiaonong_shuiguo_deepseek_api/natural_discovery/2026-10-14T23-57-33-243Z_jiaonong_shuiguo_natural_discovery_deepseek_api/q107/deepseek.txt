会，而且香蕉和菠萝的风险点不一样。

**香蕉：起订量高，损耗风险通常更明显**
- 香蕉是后熟型水果，采购时一般偏生，但到货后会集中转熟。
- 如果起订量超过日销量，货会堆在仓库或门店后场，成熟速度很难压住。
- 一旦开始转熟，销售窗口很短，容易出现：发黑、起斑、软烂、压伤。
- 为降损耗，可能被迫提前打折，毛利被吃掉；不打折就报损。

**菠萝：起订量高，损耗更多来自周转和储存，不是后熟**
- 菠萝相对耐放，但高起订量会带来：库位占用、磕碰、冠芽刺伤、局部腐烂交叉污染。
- 如果是已削皮/切块的菠萝，损耗风险会大幅上升，保质期很短。
- 整果菠萝如果通风、温湿度、堆码不好，也会出现底部发霉、黑心、果眼腐烂。

**关键判断：不是“起订量高就一定亏”，而是看三个匹配**
1. **起订量 vs 日均销量**：如果起订量超过 3～5 天销量，风险就偏高。
2. **到货成熟度 vs 销售节奏**：香蕉越熟、菠萝越切好，风险越高。
3. **库容和温控 vs 批量**：有没有足够冷库、通风位、先进先出执行能力。

**可执行建议**
- 香蕉：按“天销量×1.5～2.5天”控首单；分批催熟/分批上架；到货先做成熟度分级。
- 菠萝：整果可适当放宽到 3～5 天销量；削皮切块严格按 1～2 天销量订。
- 和供应商谈：拆包、混装、小规格箱、分批次送货，比单纯压价更能降损耗。
- 设红线：某单品报损率连续高于 5%～8%，就下调起订量或改小包装。

**结论**
起订量太高会增加损耗风险，香蕉更敏感，菠萝稍好但也不能硬压库存。真正要算的是：  
**起订量带来的采购便宜，能不能覆盖多出来的损耗、资金占用和降价损失。**  
如果覆盖不了，就应该拆单、缩量或换供应商。
