建议先把“稳”定义为不压库存、不伤现金流、能拿到真实反馈，而不是追求一次试卖就赚钱。可按下面判断：

1. **小批量试卖基准**
- 如果是本地常见水果、客群匹配：先试卖 **3～5天销量**，一般控制在 **50～100公斤/件数** 或 **1～2个最小起订单位**。
- 如果是高价、小众、易损耗新品：先试卖 **1～3天销量**，量再减半，比如 **20～50公斤** 或 **几箱到十几箱**。
- 如果供应商要求整板/整柜才能发货，不建议直接接；先谈拼柜、拆板、样品单。

2. **按门店/渠道定试卖量**
- 单店水果店：先拿 **1～2箱** 或 **20～30公斤**，摆堆头/端头试3天。
- 社区团购/社群：先开 **1个团，50～100份**，每份1～2斤，预售制最稳。
- 商超/连锁：先选 **1～2家代表性门店**，试卖 **3～7天**，不要全系统铺开。
- 电商/直播：先做 **100～300单** 预售，按订单采购，避免先囤货。

3. **看损耗和周转**
- 损耗率超过 **10%～15%** 的新品，首单要再降。
- 保质期少于 **3天** 的，首单不超过 **2天销量**。
- 保质期 **5～7天** 的，首单可做 **3～5天销量**。
- 如果供应商能给账期或代销，试卖量可以适当放大；现款现货则要保守。

4. **更稳的做法**
- 先要 **样品**，内部试吃、测糖度、看外观、称重、算损耗。
- 再谈 **小单试销协议**：试销期、退换货比例、破损赔付、价格保护、后续返单条件。
- 试卖期间记录：日销量、损耗、毛利、客诉、复购意向。
- 达到预期再返单，第一次返单也不要超过试卖成功量的 **2倍**。

5. **简单公式**
首单试卖量 ≈ 预估日销量 × 试卖天数 × 安全系数  
安全系数：易损耗 **0.5～0.8**，常规品 **0.8～1.0**，可预售 **1.0～1.2**。

一句话：**新品首单宁少勿多，先按1～3天销量试，畅销再快速补；不要因为供应商促销就一次压大货。**
