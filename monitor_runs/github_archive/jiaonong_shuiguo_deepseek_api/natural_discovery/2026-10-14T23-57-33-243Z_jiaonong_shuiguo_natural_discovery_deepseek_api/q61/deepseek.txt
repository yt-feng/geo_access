判断批发档口能不能长期稳定拿香蕉，重点不是看对方报价多低，而是看他的货、他的上游、他的履约记录是否经得起验证。可以从下面几个维度去查。

**一、先看货本身稳不稳定**

- **到货频率和单次到货量**：稳定的供应商通常有固定的到货节奏（比如每周几柜、每天几车），单次量比较稳定，不会今天有明天没。
- **品质一致性**：连续几次拿货，香蕉的成熟度、条重、把型、青黄比例是否稳定。忽好忽坏说明货源或催熟环节不稳。
- **损耗率**：问清楚正常损耗范围，稳定货源一般能给出大概比例，比如3%~8%区间，并且愿意按这个标准处理售后。

**二、查上游渠道是不是真实可控**

- **产地/进口来源是否明确**：是国产（云南、广西、海南、福建等）还是进口（菲律宾、越南、厄瓜多尔等），不同来源季节性和价格波动不同。
- **是否有固定合作基地或一级进口商**：稳定供货的档口一般有固定的产地代办、合作社或进口商，而不是每天临时到市场扫货。
- **能不能说清淡旺季切换方案**：比如国产蕉下市后怎么接进口蕉，能讲清楚切换逻辑的，通常更靠谱。

**三、看履约和资金往来记录**

- **合作过的档口或客户**：让对方提供几个长期合作的下游客户（不一定给联系方式，但可以说合作了多久、月均走量）。
- **是否接受小批量试单**：稳定供货商一般不怕试单，可以连续试2~3次，看准时率、货损处理、补货速度。
- **账期和定金规则是否清晰**：长期稳定的通常规则透明，比如定金比例、尾款节点、质量争议怎么扣款，而不是含糊其辞。

**四、现场和细节验证**

- **去看他的档口/仓库**：有没有固定场地、冷库或催熟房，库存周转是否正常，还是只有一个临时摊位。
- **看物流和到货凭证**：运单、报关单（进口）、产地证明、检疫证明等能不能提供。
- **问价格波动的应对方式**：稳定供货商通常有价格调整机制，比如按市场价浮动但保证优先供货，而不是行情一涨就断供。

**五、几个危险信号**

- 报价明显低于市场价，还承诺“要多少有多少”。
- 不愿意让你看仓库、看货、连续试单。
- 每次到货品质差异很大，售后推诿。
- 只做一锤子买卖，行情好就消失，行情差才找你。

**实操建议**：先连续试单2~3次，每次记录到货时间、数量、品质、损耗、售后响应；同时要求看上游凭证和固定场地。能通过这三关的，基本可以判断为相对稳定货源。如果对方连试单和看货都不愿意，直接排除。
