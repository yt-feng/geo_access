做小包装香蕉，采购时重点盯这几件事：**熟度控制、分切方式、包装透气性、冷链和陈列条件**。香蕉损耗主要来自“压伤、催熟过头、切口发黑、冷凝水”，不是单纯保质期短。

**1. 采购熟度要按销售速度倒推**
- 小包装香蕉最好卖的是**3～5根/袋**，适合单人、小家庭。
- 采购时不要全拿黄熟蕉。建议：
  - 如果当天或次日能卖掉：拿**3～4级熟度**（青黄、微软）。
  - 如果要放2～3天：拿**2～3级熟度**（偏青、硬）。
  - 已经出现梅花点、果柄发黑的，只适合做即时促销，不适合做小包装。
- 同一批货熟度尽量一致，否则一袋里有的已熟、有的还青，顾客体验差，损耗也高。

**2. 分切和装袋方式**
- 能整根装就不要切段。切段后切口很快氧化发黑，还会出水、发黏。
- 如果必须切段，切口要平整，刀具干净，切后尽快冷藏并当天卖完。
- 装袋时保留果柄，不要硬扯，果柄撕裂会增加感染和霉变。
- 一袋不要装太满，避免封口后挤压。袋内留一点空间，减少压伤。

**3. 包装材料要透气，别完全密封**
- 香蕉会释放乙烯，完全密封会加速成熟和腐烂。
- 优先选**打孔PE袋、微孔保鲜袋、透气膜袋**，或袋身留透气孔。
- 不建议用完全密封的真空袋、厚实自封袋长期装。
- 如果店里湿度大、温差大，袋内易起冷凝水，水珠会加速霉变。可垫一张吸水纸或厨房纸。
- 标签别贴在蕉体上，贴在袋面或封口处，减少撕标伤果。

**4. 损耗控制的关键动作**
- 进货量按“日销×1.5～2天”控制，小包装香蕉不适合大量囤。
- 到货后先挑出压伤、裂口、发霉、过熟的，不要混装。
- 门店存放：**阴凉通风，避免阳光直射和空调直吹**。未熟的可室温，已熟的可冷藏，但冷藏后表皮会变黑，最好当天卖。
- 陈列不要堆叠超过2层，避免下层压伤。
- 每天早晚各挑一次，把过熟蕉转做促销、果切或员工内购，别等到烂在袋里。
- 如果做促销，建议“熟度高的单独放一个篮，标当天食用”，不要和正常品混卖。

**5. 采购时可以直接问供应商的条件**
- 这批蕉的采收熟度、到店熟度大概几级？
- 是否已经催熟？催熟后第几天？
- 包装是打孔袋还是密封袋？有没有透气孔？
- 可否按小规格、短周期、多批次配送？
- 出现压伤、霉变、切口发黑，是否支持退换或补损？

**6. 建议的小包装方案**
- 规格：3～5根/袋，约500～800克。
- 包装：打孔PE袋或微孔袋，袋内垫吸水纸。
- 熟度：到店2～3级，陈列后自然转黄。
- 陈列：单层或两层，阴凉处，避免挤压。
- 周期：按1～2天销量订货，熟蕉当天促销。

核心原则一句话：**小包装香蕉赚的是周转，不是库存。采购宁少勿多，熟度宁青勿过，包装宁透气勿密封，陈列宁松勿挤。**
