买香蕉想“到店状态刚好”，关键不是看颜色一个指标，而是按 **你打算几天内吃完** 来选成熟度，再配合存放方式。

## 1. 先定用途，再选颜色

- **当天/第二天吃**：选 **通体黄色、带少量小黑点** 的。最甜、口感最好。
- **2～3天吃完**：选 **黄色为主、两头略带一点绿** 的。到店不会太生，回家放一两天刚好。
- **3～5天吃完**：选 **黄绿相间、整体偏绿但已经转黄** 的。别选全绿硬邦邦的。
- **想放一周左右**：选 **绿色较多、但能看到黄色过渡** 的，回家常温催熟。
- **要做奶昔/烘焙**：反而可以选 **黑点较多但没烂** 的。

一句话：**别按“今天看起来最漂亮”选，按“你哪天吃”选。**

## 2. 到店快速判断，不只看颜色

看这几点更准：

1. **看棱角**  
   香蕉越圆润，通常越熟；棱角分明、很硬，通常偏生。

2. **轻捏中部**  
   有轻微弹性、不硬也不软塌，最好。  
   硬得像木头：太生。  
   一捏就陷、发软：太熟或已损伤。

3. **看果柄和果尖**  
   - 果柄全绿、果尖也绿：偏生。  
   - 果柄开始转黄褐，果尖黄：成熟中。  
   - 果柄发黑、果尖黑：偏熟。

4. **看黑点**  
   - 零星黑点：适合马上吃。  
   - 黑点很多且连片：偏熟。  
   - 黑点伴随发软、渗水、异味：不要。

5. **看有没有压伤**  
   表皮发暗、局部凹陷、破皮，回家后容易从伤处快速烂。

## 3. 超市里尽量别选这些

- **整把全绿、硬得没有弹性**：除非你打算放很多天，否则到店太生。
- **整把全黄且已有大片黑斑**：除非当天吃，否则很快过熟。
- **冷藏区拿出来的香蕉**：香蕉怕冷，低温容易表皮变黑、果肉不熟或发涩。
- **散装里被压在最下面的**：容易有暗伤。

## 4. 买回家后怎么控制成熟速度

- **想快点熟**：常温放，和苹果/梨放同一个纸袋里。苹果释放乙烯，能催熟。
- **想慢点熟**：常温阴凉处单独放，别堆压。  
  **不要直接放冰箱**，除非已经熟到你想停止继续熟。
- **已经熟透吃不完**：剥皮切段冷冻，做奶昔；或冷藏 1～2 天尽快吃。冷藏后表皮会变黑，但果肉若没坏还能吃。

## 5. 最稳的采购策略

如果你不是当天吃完，建议：

- **买两批**：一批黄色带少量黑点，今明两天吃；一批黄绿相间，后面吃。
- **不要只买一把全同熟度**，否则会同时熟、同时烂。
- **按人数买**：一个人每天 1 根左右，买 3～5 天量就够，别囤太多。

总结：  
**当天吃选黄带黑点；两三天吃选黄为主微绿；几天后吃选黄绿相间；一周左右选偏绿但已转黄。轻捏有弹性、无压伤、无异味的最稳。**
