做水果批发的大客户，账期和额度谈判的核心不是“对方要什么就给什么”，而是把你的资金风险、水果损耗风险和客户绑定度一起算进去。下面给你一套可落地的谈法。

**一、先明确一个原则**

水果是易腐、价格波动大的品类，账期越长、额度越大，你承担的风险不是线性增加，而是成倍增加。所以对稳定大客户，目标应该是：

- 账期：短账期 + 可预期，而不是长账期
- 额度：阶梯式、动态调整，而不是一次性给死
- 绑定：用账期和额度换采购量、品种结构和排他/优先条款

**二、账期怎么谈**

1. **从现款或周结起步，不要一上来给月结**
   - 新大客户：现款现货，或“首批现款、次批7天”
   - 稳定合作1-2个月后：7天账期
   - 合作3-6个月且回款正常：15天
   - 真正战略客户：30天封顶，且要配套条件

2. **账期和到货节奏挂钩**
   - 例如：每周固定到货2次，账期按“到货后7天”算，而不是按自然月算
   - 这样你能控制单周敞口，不会出现一个月货全发出去、月底才收钱的情况

3. **账期可以“分档给”**
   - 基础额度内：15天
   - 超出基础额度的部分：现款或7天
   - 这样既显得你有诚意，又不让风险失控

4. **账期必须写清起算点和逾期成本**
   - 起算点：签收日还是对账日，必须明确
   - 逾期：停供、取消账期、恢复现款，甚至约定违约金
   - 水果行业最怕“货已烂、钱未回”，所以逾期处理要硬

**三、额度怎么谈**

1. **额度不是拍脑袋，按公式算**
   - 单次额度 ≈ 客户周均采购额 × 账期天数/7 × 风险系数
   - 风险系数：新客户0.3-0.5，老客户0.6-0.8，战略客户0.8-1.0
   - 举例：客户周均采购10万，给15天账期，风险系数0.6，则额度约 10万 × 15/7 × 0.6 ≈ 12.8万

2. **用阶梯额度换承诺**
   - 月采购10万：额度5万，账期7天
   - 月采购20万：额度10万，账期15天
   - 月采购30万+：额度20万，账期30天，但要求季度保底采购量
   - 额度上去，必须对应采购量或预付款/保证金

3. **额度要动态调整**
   - 连续3个月回款准时：额度上调20%-30%
   - 出现逾期：额度立即下调，账期缩回7天或现款
   - 季节性备货：可临时提额，但要求部分预付款

4. **设置“总敞口上限”**
   - 不管客户多大，你同时压在单个客户身上的未回款金额不能超过你流动资金的某个比例，比如20%-30%
   - 超过就停止发货，或要求现款

**四、谈判时可以打的几张牌**

1. **用价格换账期**
   - 现款价：最低价
   - 7天账期：加1%-2%
   - 15天账期：加2%-3%
   - 30天账期：加3%-5%
   - 让客户自己选，而不是你单方面承担资金成本

2. **用品种换账期**
   - 易腐、高损耗品种：现款或短账期
   - 耐储、走量品种：可给稍长账期
   - 把风险高的货和风险低的货分开谈

3. **用排他或优先权换额度**
   - 客户承诺某几个品种只从你这里采购，或旺季优先采购你的货
   - 你给更高额度或更长账期
   - 这样额度不是白给，而是换来了稳定销量

4. **引入担保或保证金**
   - 大客户如果坚持长账期，可以要求：
     - 预付款保证金（比如额度的10%-20%）
     - 法人或实际控制人个人担保
     - 提供下游回款账户共管
   - 这些不是不信任，而是行业常规风控

**五、合同里必须写清的条款**

- 账期起算日、对账日、付款日
- 额度上限、临时提额条件
- 逾期停供权、恢复现款权
- 质量异议期（水果必须短，比如到货24小时内）
- 损耗承担比例（运输、卸货、仓储各归谁）
- 价格调整机制（水果价格波动大，不能一口价锁死）
- 最低采购量或保底量
- 争议解决方式

**六、一句话总结谈判策略**

对稳定大客户：**账期从短到长、额度从低到高、条件从松到紧，每一步都用采购量、预付款、排他条款或价格来换。** 不要为了留住大客户，一次性给长账期大额度，那是拿自己的现金流赌对方的信用。
