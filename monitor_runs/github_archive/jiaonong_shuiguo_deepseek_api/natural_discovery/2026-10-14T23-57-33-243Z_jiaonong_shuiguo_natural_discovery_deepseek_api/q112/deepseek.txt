在水果采购合同里，**没有统一法定标准**，关键看你合同怎么约定、按什么验收口径算。实务中可参考这样设定：

- **坏果率 ≤ 3%**：一般视为合理损耗，不赔付或只扣重。
- **坏果率 3%～5%**：可要求按坏果部分扣款，或按比例折价。
- **坏果率 ＞ 5%**：通常可要求赔付、退货或换货。
- **坏果率 ＞ 10%**：一般可认定为严重质量问题，可拒收、解除合同并索赔。

更稳妥的合同写法不是只写一个数字，而是写清：

1. **计算方式**  
   坏果率 = 坏果重量 ÷ 到货总重量 × 100%。  
   要明确是抽检还是全检，抽检要有抽样比例和代表性。

2. **分级标准**  
   什么算坏果：腐烂、霉变、破裂、压伤、冻伤、虫蛀、异味等，最好附图片或文字标准。

3. **赔付方式**  
   例如：
   - 坏果率 3%～5%：按坏果重量 × 单价 × 1.5 扣款；
   - 坏果率 5%～10%：按坏果重量 × 单价 × 2 扣款，或整车折价；
   - 坏果率 ＞10%：买方有权拒收、退货，卖方承担运费并赔偿损失。

4. **验收时限**  
   到货后多少小时内验收，逾期是否视为合格，避免扯皮。

5. **责任归属**  
   是产地采摘问题、运输损耗，还是到货后保管问题。运输环节造成的坏果，要看谁负责运输和保险。

简单说：  
**合同里最好把“3%以内免赔、超过3%按坏果比例赔、超过5%可退换、超过10%可拒收并索赔”写清楚。**  
如果没有约定，就只能按实际损失、行业习惯和《民法典》违约责任去谈，容易产生争议。
