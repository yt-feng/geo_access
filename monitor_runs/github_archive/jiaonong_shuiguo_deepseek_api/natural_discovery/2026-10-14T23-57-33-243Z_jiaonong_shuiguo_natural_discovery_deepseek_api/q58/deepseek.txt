通常**直接买成品果丁的综合损耗更低**，但前提是你能控制好成品果丁的验收、储存和效期。鲜果切配看起来原料便宜，实际损耗点更多，尤其是菠萝这种“去皮去眼去芯”损耗很高的水果。

可以按下面判断：

**1. 原料损耗对比**
- 鲜菠萝：去皮、去眼、去芯后，可食率一般大概只有 **45%～65%**，具体看品种、成熟度、刀工和是否保留芯。
- 成品果丁：供应商已经承担了这部分损耗，你买到的基本是可直接使用的果肉，按重量算利用率接近 **95%～100%**，主要损耗来自沥水、破损、过期和退货。

所以如果只比“从原料到能用果丁”这一步，成品果丁损耗明显更低。

**2. 鲜果切配的隐藏损耗**
- 人工切配时间成本高。
- 切多了用不完，冷藏后出水、发酸、变色。
- 切少了临时补货，影响出品。
- 不同批次成熟度不一致，甜度、酸度、软硬度不稳定。
- 菠萝芯、边角料如果不能二次利用，基本就是损耗。
- 员工操作不标准，出成率波动大。

**3. 成品果丁的隐藏损耗**
- 到货如果冷链不好，容易发酵、出水。
- 包装内可能有较多汁水，沥掉后实际可用量下降。
- 开封后效期短，用不完就报废。
- 供应商可能掺杂成熟度差、破损或边角料。
- 如果验收不严，损耗会从“后厨”转移到“仓库和报废”。

**4. 怎么选更划算**
可以简单算一笔账：

**鲜果切配实际成本 = 鲜菠萝采购价 ÷ 可食率 + 人工 + 切配损耗 + 报废**
**成品果丁实际成本 = 成品单价 ÷ 实际可用率 + 冷链储存 + 开封报废**

举例：
- 鲜菠萝 8 元/斤，可食率 50%，那可用果肉成本约 **16 元/斤**，还没算人工和报废。
- 成品果丁如果 18 元/斤，实际可用率 95%，可用成本约 **18.9 元/斤**。
两者可能很接近，但成品更省人工、更稳定。

**5. 建议**
- **门店销量大、出品稳定、人工紧张**：优先买成品果丁，重点管验收、冷链和开封效期。
- **销量小、想控成本、有人工且能利用边角料**：可以鲜果切配，但要做标准出成率。
- **最稳妥**：先小批量测试 1～2 周，分别记录：
  - 到货重量
  - 实际可用重量
  - 报废重量
  - 人工耗时
  - 顾客投诉/口感差异

结论：**单看损耗，成品果丁通常更低；看总成本，则取决于你的销量、人工和冷链管理。** 如果销量不大、储存条件一般，成品果丁反而可能因为开封报废而变贵。
