和水果供应商谈酒店早餐合作时，重点不是只谈价格，而是把“稳定供应”拆成可写进合同的条件。建议从以下方面注意：

1. **明确需求量和波动**
   - 给出每日/每周预估用量、早餐高峰时段、淡旺季波动范围。
   - 约定最小供货量和临时加单提前期，如加单需提前几小时通知。
   - 明确节假日、大型会议、团队入住时的增量能力。

2. **品项和规格标准化**
   - 列出常供水果清单，明确品种、等级、单果规格、成熟度、糖度/外观要求。
   - 早餐场景要区分：整果、切果、易氧化的水果。切果涉及加工资质和食品安全。
   - 约定允许的替代品项和替换规则，避免临时缺货随意换价高或低质水果。

3. **验收标准与退换货**
   - 写明到货时间、验收人、验收标准：腐烂率、碰伤率、大小均匀度、温度、包装完整度。
   - 设定不合格处理：当场拒收、部分扣款、补货时限。
   - 约定“缺货违约金”或应急补货责任，不能只靠口头承诺。

4. **价格与调价机制**
   - 不要只锁单价，要约定报价周期和调价依据，如按批发市场行情或固定周期复核。
   - 明确是否含税、含运费、卸货费、包装费。
   - 对临时加单、特殊品种、切果加工单独定价。

5. **供应稳定性保障**
   - 了解供应商的货源基地、冷链能力、备用货源、配送车辆和司机安排。
   - 要求提供备选供应商方案或应急库存方案。
   - 约定配送频次、到货时间窗，早餐用水果应避开厨房最忙时段并留出验收和加工时间。

6. **食品安全与资质**
   - 核验营业执照、食品经营/生产许可、检验检疫证明、农残检测报告。
   - 切果供应商需有相应加工资质和冷链条件。
   - 合同中明确食安责任、召回配合、留样和追溯要求。

7. **账期与结算**
   - 约定对账周期、发票类型、付款账期。
   - 设置质量保证金或首月观察期，避免前期供货好、后期降质。

8. **试供与考核**
   - 先签短期试供协议，如2—4周，按到货准时率、验收合格率、缺货次数、投诉响应速度考核。
   - 考核达标再签长期合同，并保留季度评估和淘汰机制。

9. **合同关键条款**
   - 供应品项、价格、频次、验收标准、违约责任、食品安全责任、保密与廉洁条款、不可抗力、终止条件。
   - 所有口头承诺写进合同或附件，尤其是“缺货几小时内补上”“临时加单不加价”等。

实操建议：先整理一份《早餐水果需求清单+验收标准》，让2—3家供应商按同一标准报价和试供，再比较价格、稳定性和响应速度。合同里最值得盯的三件事是：**验收标准、缺货补救、调价机制**。
