先问配送，再问售后，最后谈价格。原因很直接：团购水果的利润和口碑主要死在“到货品质和时效”上，价格再低，配送不稳或售后扯皮，团长会赔钱又丢客。

建议按这个顺序判断：

1. **配送（最优先）**
   - 问清楚：几点前下单、次日还是隔日到、送到团长点还是分送到户、破损/延误怎么处理。
   - 重点看：是否冷链、同城仓在哪、旺季爆单时是否保时效、临期/坏果是否随车换。
   - 判断标准：配送时效和履约稳定性说不清楚的供应商，价格再低也先排除。

2. **售后（第二优先）**
   - 问清楚：坏果率标准、理赔时限、拍照要求、退款还是补发、团长垫付还是供应商直退。
   - 重点看：售后响应速度、是否把风险转嫁给团长、是否按整单赔付还是按颗赔。
   - 判断标准：售后规则模糊、要求团长先垫赔的，要谨慎。

3. **价格（最后谈）**
   - 在配送和售后都能兜底后，再比价。
   - 不要只看进货价，要算：损耗率 + 售后成本 + 团长补贴/分佣 + 退换货时间成本。
   - 判断标准：综合成本低才是真便宜，单看单价容易踩坑。

一句话：**配送决定能不能卖，售后决定敢不敢卖，价格决定赚不赚。** 团长选供应商，先把配送和售后问成白纸黑字，再谈价格。
