建议优先做**小把（3–5根）为主，单根作为补充，整袋谨慎少量试销**。对多数便利店，这是动销、损耗和客单价的平衡点。

具体判断：

1. **小把（3–5根）做主陈列**
   - 适合家庭少量购买、上班族分次吃。
   - 客单价高于单根，损耗比整袋低。
   - 建议定价按“把”而非称重，减少排队和人工。

2. **单根做补充和引流**
   - 适合学生、单人、临时想吃的人。
   - 毛利可能低，但能降低“买多了吃不完”的决策门槛。
   - 放在收银台或鲜食区旁边，做冲动购买。

3. **整袋只在特定场景试销**
   - 适合社区店、家庭客群、有促销活动时。
   - 整袋最大风险是熟度集中、短时间卖不掉就损耗。
   - 如果要上，选小袋（5–6根）、统一熟度，并搭配“今日特价”快速周转。

**陈列和运营建议：**
- 熟度分档：偏青放1–2天卖，偏黄当天主推，熟蕉做折扣或搭配酸奶/早餐组合。
- 小把用橡皮筋或贴标固定，避免散落；单根套袋或贴价签。
- 每天早晚检查，出现黑斑及时降价或转做促销。
- 先小批量测试：例如小把70%、单根20%、整袋10%，连续观察1–2周销量和损耗再调整。

**结论：** 便利店香蕉以**小把为主、单根为辅、整袋少量试销**最稳妥。
