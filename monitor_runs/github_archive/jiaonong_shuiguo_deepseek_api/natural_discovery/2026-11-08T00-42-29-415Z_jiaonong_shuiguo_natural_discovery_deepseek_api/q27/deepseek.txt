判断门店销售规格，核心不是“越大越好”，而是看**客群、陈列、损耗、定价带和补货频率**是否匹配。可按下面步骤执行。

## 1. 先定门店销售场景
先明确这批货主要卖给谁：

- **社区店/生鲜小店**：优先中等规格、单价低、家庭一次买2—4个；
- **商圈店/写字楼店**：小规格、即食型更好卖；
- **高端超市**：大果、礼盒果可以，但要求外观一致、无瑕疵；
- **餐饮/果汁档口**：看出汁率、单果重量和采购成本，不必追求外观。

不同场景对应不同规格，不要一套标准全店通用。

## 2. 苹果怎么判断规格
苹果主要看**单果重量、横径、着色、硬度、果形整齐度**。

可执行判断：

- **单果重量**：门店零售常见中等果约150—250克/个；偏小果80—150克；大果250克以上。具体以当地消费习惯和竞品为准。
- **横径**：用分级板或卡尺抽检，重点看同一批是否集中在同一区间。大小混装会拉低陈列效果和售价。
- **外观**：着色均匀、果面干净、无明显碰压伤、果形端正。礼盒或高端陈列要求更严。
- **硬度与新鲜度**：抽检切果或用手轻按，明显发软、皱皮、有酒味的不适合正常货架销售。
- **一致性**：同一陈列层尽量同规格。混级严重时要么重新分拣，要么降级促销。

**适合门店销售的信号**：单果大小集中、外观整齐、手感硬实、无明显机械伤，且按当前售价算仍有合理毛利。

## 3. 橙子怎么判断规格
橙子主要看**单果重量、横径、果皮厚度、可食率、酸甜度、表皮完整度**。

可执行判断：

- **单果重量**：常见零售橙约150—250克/个；小果100—150克；大果250克以上。鲜食和榨汁用途标准不同。
- **横径**：同样用分级板抽检，重点看同批是否均匀。大小差异过大不利于按个或按份销售。
- **果皮与手感**：果皮细腻、有弹性、无明显干皱；过厚或粗皮会影响可食率和口感。
- **可食率与出汁**：可抽几个称重去皮测可食率；榨汁用途看出汁率和籽量。
- **瑕疵**：霉点、烂斑、明显压伤、裂口的直接剔除，不能按正常规格销售。
- **成熟度**：青硬果适合周转慢的门店少量陈列；即食消费场景应选成熟度适中的。

**适合门店销售的信号**：大小均匀、果皮完整有弹性、无腐烂霉变、切开可食率和口感稳定，按售价测算损耗后仍有利润。

## 4. 用“门店测试”快速验证
采购前或首批到货后做小规模测试：

1. **抽检**：每批随机抽20—30个，称重、量横径、记录瑕疵率和软烂率；
2. **陈列测试**：按拟售规格上架1—2天，看是否好堆叠、是否显小、是否容易被翻拣损伤；
3. **价格带测试**：按个卖、按斤卖、按份卖各测一下，看顾客接受度；
4. **损耗测算**：记录挑出次果比例。若瑕疵和损耗过高，即使进价低也可能不划算；
5. **补货判断**：畅销规格应能稳定补货；若供应商只能混级供货，要考虑分拣人工成本。

## 5. 直接可用的判断标准
可以给采购设一张简单验收表：

- 同批单果重量集中在目标区间；
- 横径差异不超过一个常用分级档；
- 外观瑕疵率控制在门店可接受范围内；
- 软烂、霉变、明显机械伤为零容忍；
- 按拟售价扣除损耗后仍有毛利；
- 陈列后不显得“小、乱、差”；
- 目标客群购买份量匹配，比如家庭装、即食装、礼盒装分开。

**结论**：苹果和橙子是否适合门店销售，重点看“规格是否集中、外观是否整齐、损耗是否可控、价格带是否匹配客群”，而不是单纯看单果大小。先定销售场景，再抽检重量/横径/瑕疵率，最后用小规模陈列和损耗测算验证。
