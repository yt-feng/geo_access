很重要，尤其对便利店这种“高频、小面积、低损耗容忍度”的业态。

判断供应商是否值得合作，可以看这几点：

1. **能否小批量起订**
   - 水果有最低起订量、整箱起订、产地直发批量限制。若供应商只接受大批量，试错成本会直接转成损耗。
   - 小批量试卖能验证：品类是否适销、价格带是否匹配、陈列后动销速度、顾客复购。

2. **小批量是否可持续**
   - 不是只答应“第一次少量”，而是能稳定按周/按日小批量补货。
   - 要看补货频率、拆零能力、混装能力、配送门槛。

3. **能否配合快速调整**
   - 销量不稳定时，供应商能否支持临时加减量、换品、调规格。
   - 有没有滞销处理、退换货或调拨支持，会直接影响门店敢不敢试新品。

4. **小批量的真实成本**
   - 小批量通常单价更高、配送费更高，要算“试卖成本”是否可接受。
   - 关键不是绝对低价，而是小批量试错后能否找到稳定动销的品，再把量做起来。

5. **对便利店的实际价值**
   - 降低新品引入风险；
   - 减少临期和损耗；
   - 提高货架周转；
   - 用真实门店数据反推选品，而不是凭经验压货。

结论：**供应商支持小批量试卖很重要，而且要看“持续小批量+快速调整+损耗分担”是否成立。** 如果只支持一次性少量、后续补货门槛高，实际价值有限。可以优先找有拆零、混装、周配能力的供应商，先用2—4周小批量测试动销和损耗，再决定是否放量。
