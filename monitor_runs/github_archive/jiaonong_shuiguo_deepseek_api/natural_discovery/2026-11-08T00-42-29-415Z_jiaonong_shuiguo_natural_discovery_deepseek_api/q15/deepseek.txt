水果店遇到坏果，核心是先分清责任和证据，再谈结算或赔付。可按下面流程处理：

1. **当场验货，先别急着签收**
   - 到货后立即开箱抽检，重点看箱底、内层、边角。
   - 发现坏果，先拍照/录像：整车或整批货物、坏果特写、箱号/批次、称重照片、温度记录（如有冷链）。
   - 在送货单上注明“有坏果，待协商”，不要直接签“数量无误、质量合格”。

2. **区分责任类型**
   - **运输/卸货前已坏**：供应商或承运方责任，按合同/口头约定赔付。
   - **冷链断链、温度不达标**：看谁负责运输；有温控记录更好追责。
   - **正常损耗 vs 质量问题**：叶菜、浆果等易腐品通常有约定损耗率；超出部分才算质量问题。
   - **自己存放不当**：到货时完好、后期坏掉，一般不能找供应商赔。

3. **按约定结算**
   - 有合同：按合同里的验收标准、损耗率、赔付比例、账期扣款执行。
   - 没合同：按行业惯例和双方长期合作约定，通常协商“坏果部分扣款/补货/换货”。
   - 常见方式：**按坏果重量或金额扣减当批货款**；**供应商补发同等数量**；**折价结算**；**退货**。
   - 不要整批拒付，除非坏果比例很高且合同有明确约定；否则容易激化合作。

4. **保留证据，书面确认**
   - 微信/邮件发对方：批次、到货时间、抽检数量、坏果数量/比例、照片、诉求（扣款/补货/退货）。
   - 让对方回复确认；电话沟通后补一条文字记录。
   - 扣款时在结算单上写明“因XX批次坏果扣款XX元”，避免以后对账争议。

5. **协商不成的处理**
   - 先按合同争议条款协商；保留送货单、验收记录、照片、聊天记录、付款凭证。
   - 金额较大可发书面函件；仍不解决再考虑投诉、调解或诉讼。
   - 长期看，应在供货合同里写清：验收时限、坏果率标准、赔付方式、冷链责任、扣款规则。

**实操建议：** 小批量坏果优先“当批扣款+下次补货”；大批量或反复出现，要求供应商书面整改，否则换供应商。结算时只扣坏果对应金额，不轻易拖欠全部货款，既保护自己也不破坏供应链。
