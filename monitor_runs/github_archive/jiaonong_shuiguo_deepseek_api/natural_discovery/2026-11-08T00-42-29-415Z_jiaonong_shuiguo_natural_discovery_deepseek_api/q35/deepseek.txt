连锁超市要把门店坏果率压下来，合同里不能只写“坏果包赔”，而要把**验收标准、责任分界、赔付计算、扣款/补货机制、举证与时效**写清楚。建议按下面结构约定，直接可作为采购合同或生鲜补充协议条款框架。

## 1. 先定义“坏果”和“坏果率”
合同里必须统一口径，否则赔付争议大。

建议约定：
- **坏果定义**：腐烂、霉变、软烂渗液、明显虫蛀、破裂导致变质、异味、严重机械伤影响销售等；轻微外观瑕疵（日灼、轻微擦伤不影响食用）不计入坏果。
- **坏果率计算**：  
  `坏果率 = 抽检坏果重量（或件数）÷ 同批次抽检总重量（或件数）×100%`
- **抽检规则**：按到货批次随机抽检，抽检比例可设5%—10%；抽检不合格时扩大抽检或全检。
- **判定时点**：以门店收货验收时点为准；但若合同约定“到货后24小时内发现隐蔽性腐烂仍可追溯”，要明确时限和举证方式。

## 2. 验收标准分档，绑定赔付比例
不要只写“超过多少赔多少”，建议设阶梯：

| 到货验收坏果率 | 处理方式 |
|---|---|
| ≤3% | 正常收货，不赔付 |
| 3%—5% | 按坏果重量对应货款扣减，或换货 |
| 5%—10% | 坏果部分全额扣减，并按该批次货款一定比例支付违约金（如2%—5%） |
| ＞10% | 超市有权拒收整批，供应商承担退货、补货及门店缺货损失 |

具体阈值按品类调整：浆果、叶菜可严；苹果、根茎类可略宽。**阈值不要一刀切**。

## 3. 赔付方式要可执行
建议约定“三选一”或组合：
1. **货款扣减**：按坏果重量×该批次结算单价扣减；
2. **补货替换**：供应商在约定时限内补足合格品，补货费用由供应商承担；
3. **违约金**：坏果率超过约定上限时，除扣减外另按批次金额比例支付违约金。

同时写明：
- 扣款在**当月货款结算时直接抵扣**，超市无需另行催告；
- 补货时限：如门店所在城市24小时内、偏远门店48小时内；
- 连续补货不合格的处理：超市可终止该批次或暂停下单。

## 4. 责任分界要写清
坏果责任不能全压供应商，否则供应商可能提高报价或拒签。建议分界：
- **到货验收前**：运输、采摘、包装、预冷等由供应商负责；
- **验收合格后**：门店储存、陈列、温湿度管理不当造成的坏果由超市承担；
- **隐蔽性腐烂**：约定到货后一定时限内（如12—24小时）可追溯，但超市需提供到货时间、储存条件、照片/视频等证据；
- **不可抗力或超市要求延迟收货**：相应责任另行协商。

## 5. 举证和时效
- 门店验收时拍照/录像留存，记录批次、车牌、到货时间、抽检数量、坏果数量；
- 供应商可派员到场复检，未到场视为认可超市抽检记录；
- 异议提出时限：如收货后24小时内书面/系统提交，供应商48小时内答复，逾期视为认可；
- 月度坏果率汇总可作为考核依据，连续两个月超阈值可触发整改、罚款或终止合作。

## 6. 建议加一条“质量考核与返利挂钩”
比单纯赔付更能降坏果率：
- 月度坏果率≤目标值：优先续约或给予奖励；
- 连续超标：阶梯扣款、减少订单量、暂停新品导入；
- 严重超标：解除合同并列入供应商黑名单。

## 可直接写入合同的条款示例
> 乙方交付的果蔬产品，甲方按每批次随机抽检不低于5%进行验收。坏果率≤3%的，甲方正常收货；坏果率3%—5%的，按坏果重量对应货款扣减；坏果率5%—10%的，坏果部分全额扣减，并按该批次货款的3%支付违约金；坏果率超过10%的，甲方有权拒收整批，乙方应在24小时内补货并承担退货费用。因甲方验收后储存、陈列不当造成的坏果，由甲方承担。隐蔽性腐烂甲方应在到货后24小时内提出并附照片、到货记录等证据。上述扣款及违约金甲方有权在当月货款中直接抵扣。

**核心建议**：合同里重点写死四件事——**坏果定义与抽检规则、阶梯赔付比例、货款直接抵扣权、连续超标的退出机制**。只写“包赔”而不写计算和抵扣，实际执行时很难落地。
