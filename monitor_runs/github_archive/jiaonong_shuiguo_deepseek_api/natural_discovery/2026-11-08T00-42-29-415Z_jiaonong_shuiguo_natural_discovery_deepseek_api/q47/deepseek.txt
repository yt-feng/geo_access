做香蕉饮品/甜品，采购熟度要“分用途定档”，不要只买一种熟度。核心判断：**看用途、看表皮、摸硬度、少量多批次，并让供应商按熟度分档供货。**

### 1. 按用途定采购熟度

- **饮品打泥、奶昔、冰沙、香蕉牛奶**：买 **7～8成熟**，表皮大面积黄色、两端略带一点绿，捏起来有弹性但不过软。  
  - 优点：甜度够、香气有，打泥颜色和稠度较稳定；太熟易发黑、发酸、出水。
- **甜品切片、装饰、香蕉船、松饼/吐司 topping**：买 **6～7成熟**，表皮黄中带绿、手感偏硬。  
  - 优点：切片成形好，不易塌。使用前可在店里常温催熟到合适状态。
- **香蕉蛋糕、磅蛋糕、香蕉面包、香蕉馅料**：可用 **8～9成熟**，表皮有少量黑点、香气浓、手感软。  
  - 优点：甜香足；但要控制黑斑面积，不能发酸、渗液。
- **焦糖香蕉、烤香蕉、煎香蕉**：建议 **7～8成熟**，太生不甜，太熟一煎就烂。

### 2. 采购验收标准

到货时按批次抽检：

- **表皮**：颜色均匀，无明显大面积黑斑、霉点、破损；果柄不发黑腐烂。
- **手感**：同一批次硬度基本一致；过软、渗汁、脱柄的拒收或降级急用。
- **气味**：有正常香蕉香，无发酵酸味、酒味。
- **切面抽检**：切开看果肉是否发黑、空心、过软流水。
- **温度与运输**：香蕉怕冷，**不要冷藏运输**；到店后未熟的可常温存放，已熟透的尽快使用或短期冷藏果肉。

### 3. 门店库存控制

- **不要一次全买熟**：按“今日用 + 明日催熟 + 后日备货”分档。
- **每日盘点**：把香蕉分为“即用熟果、1～2天催熟果、偏生库存”三筐，先进先出。
- **少量多次**：茶饮店香蕉用量通常不如芒果、草莓稳定，建议每次采购量控制在 **2～3天用量**，夏季缩短到 **1～2天**。
- **催熟管理**：偏生香蕉放常温、通风处，可和苹果/梨同放加速催熟；不要密封闷着，避免水汽导致霉变。
- **熟透处理**：出现少量黑点的优先做香蕉蛋糕/馅料或打泥；大面积黑斑、发酸、渗液直接报废。

### 4. 和供应商约定

采购时明确写清：

- 指定熟度档位，例如“7成熟，表皮黄中带绿，硬度适中”；
- 按批次分档供货，不要混装生熟；
- 到货验收标准：黑斑面积、软烂率、破损率；
- 退换货规则：软烂、霉变、发酵味超比例可退换。

**一句话建议：饮品用7～8成熟，装饰切片用6～7成熟，烘焙馅料用8～9成熟；采购按2～3天用量分档买，到店分筐催熟、先进先出。**
