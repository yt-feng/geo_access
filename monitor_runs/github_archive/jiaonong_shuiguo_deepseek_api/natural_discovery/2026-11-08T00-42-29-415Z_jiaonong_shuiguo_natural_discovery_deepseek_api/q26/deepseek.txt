社区超市卖小包装香蕉，采购和包装重点要围绕“少批量、快周转、控压伤”来做，可参考下面几条：

1. **按销售半径选规格**
   - 社区店更适合 **2～3根/袋、约300～500g/袋**，家庭即时消费为主。
   - 可再设 **1～2根尝鲜装**，但根数太少时切口多、失水快，损耗反而高。
   - 避免大袋装，社区店客流分散，大袋容易剩到发黑。

2. **采购成熟度要偏生**
   - 小包装周转慢于散装，进货宜选 **7～8成熟**，到店后自然转黄。
   - 不要采全黄或已起芝麻斑的货做小包装，装袋后呼吸热和挤压会加速软烂。
   - 按日均销量拆成 **1～2天用量** 补货，宁少勿多。

3. **包装材料要透气、防压**
   - 优先用 **带透气孔的PE袋/网袋+托盘**，不要完全密封；密封袋内水汽大，易发霉、柄部腐烂。
   - 袋底加 **吸水纸或薄海绵垫**，减少冷凝水浸泡。
   - 若用保鲜膜托盘，托盘要浅、膜要松，避免勒伤果指。
   - 标签别直接贴在蕉皮上，贴袋面或托盘边。

4. **分切和串型处理**
   - 尽量 **整串小把销售**，少做单根切分；切口暴露易褐变、流汁。
   - 必须切分时用锋利刀具，切口朝上或包纸，减少汁液污染其他蕉。
   - 剔除已断指、裂口、柄部发黑的果，不要混入小包装。

5. **采购验收看关键点**
   - 查 **果柄是否青绿、无霉斑**；柄部发黑软烂的整批易坏。
   - 摸硬度：偏硬有弹性为好，局部发软、出水的不收。
   - 看棱角：棱角明显偏生，圆润发黄偏熟；小包装宜选棱角略明显的。
   - 查冷害：皮色灰暗、有细密凹陷斑的不要。

6. **门店陈列控损耗**
   - 小包装 **冷藏柜或阴凉通风处** 陈列，避免阳光直射和靠近热源。
   - 不要堆叠超过2层，减少压伤。
   - 每天早晚挑出起斑、发软的袋装， **打折或拆袋散卖**，不要等坏透再处理。
   - 记录每天小包装销量和报损，按“昨日销量×0.8～1.0”定次日采购量。

7. **和供应商约定**
   - 明确 **到货成熟度、单根长度/粗细范围、允许破损率**，比如破损和霉柄比例控制在3%以内。
   - 要求分批到货，不要一次压太多库存；小包装最好由门店或配送中心分装，避免供应商提前分装后闷坏。

简单判断：**小袋、偏生、透气、少压、勤补、日清**。先小批量试销3～5天，按报损率调整规格和进货量。
