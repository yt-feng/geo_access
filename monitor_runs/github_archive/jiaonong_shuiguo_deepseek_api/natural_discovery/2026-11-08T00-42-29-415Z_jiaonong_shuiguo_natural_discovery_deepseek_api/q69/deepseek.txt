可以按“外观等级 + 单果规格 + 报价单位 + 是否含损耗/配送”四项一起说清楚，避免只报一个“统货价”后面扯皮。

**一、香蕉分级报价建议**
1. **A级/精品**：果梳整齐、无黑斑、无机械伤，单根长度和粗细较均匀；按**元/箱**报，注明净重、根数/把数、几成熟。
2. **B级/通货**：允许少量表皮轻微擦伤或小斑点，成熟度略不齐；按**元/箱或元/斤**报，注明“允许瑕疵比例”。
3. **C级/处理货**：明显碰伤、过熟、大小不齐，适合特价或加工；单独按**元/箱一口价**，注明不退换。
4. 报价必须带：**产地/品种、每箱净重、每箱把数或根数、成熟度（几成熟）、到店价/自提价、是否包损耗**。香蕉建议按箱报，因为小店更关心“一箱多少钱、能卖几天”。

**二、菠萝分级报价建议**
1. **A级**：果形端正、无裂口、无软烂、叶冠完整、单果重区间明确；按**元/个或元/箱**报，写清单果重量范围。
2. **B级**：果形稍偏、轻微擦伤或叶冠不完整，不影响食用；按**元/个**报，注明瑕疵类型。
3. **C级/处理**：裂口、软果、偏小果，按**元/箱或元/个清货价**，注明“当日处理”。
4. 菠萝务必报：**品种（如金钻/巴厘）、单果重区间、每箱个数、成熟度、是否削皮/带冠、到店价**。最好按“个”报给小店，因为菠萝大小差异大，只报箱价容易争议。

**三、给小店看的报价单格式**
| 品项 | 等级 | 规格 | 报价单位 | 价格 | 备注 |
|---|---|---|---|---|---|
| 香蕉 | A级 | 净重13kg/箱，约7-8把 | 元/箱 | XX | 7成熟，到店价 |
| 香蕉 | B级 | 净重13kg/箱，允许轻微斑点 | 元/箱 | XX | 不包损耗 |
| 菠萝 | A级 | 单果1.2-1.5kg，8个/箱 | 元/个 | XX | 带冠，8成熟 |
| 菠萝 | B级 | 单果1.0-1.2kg，有轻微擦伤 | 元/个 | XX | 当日售 |

**四、关键话术**
报价时直接说：“这是到店价，含/不含配送；A级按箱/个报，B级允许少量瑕疵；损耗超过X%怎么处理，当场验货当场确认。”这样小店能直接判断进哪个等级、卖什么价，减少后续争议。
