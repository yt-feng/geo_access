结论先说：**大多数商超以“整果为主、切果为辅”更合适**，切果适合做增量而不是替代整果。原因不是“哪个更高级”，而是两种形态的毛利、损耗、客流和运营能力要求不同。

### 判断框架

| 维度 | 整果 | 切好 |
|---|---|---|
| 毛利 | 单价低、毛利薄，但损耗可控 | 单价和毛利更高，但损耗风险大 |
| 损耗 | 主要看库存和成熟度，卖不掉还能降价清 | 切开后保鲜期很短，卖不掉基本报损 |
| 客群 | 家庭采购、价格敏感、囤货型 | 单身/小家庭、即时消费、办公场景 |
| 运营要求 | 低，理货即可 | 高，需要冷链、刀具消毒、包装、效期管理 |
| 引流作用 | 价格锚点，能带客流 | 提升客单和体验，但依赖整果品质 |
| 风险 | 滞销、过熟 | 食品安全、氧化变色、报损率高 |

### 建议做法

1. **整果做基本盘**：保持2—3个价格带（普通果、精品果、促销果），承担引流和家庭客群。
2. **切果做补充**：只切当天预估能卖完的量，优先用外观有瑕疵但品质正常的果，避免用好果大量切。
3. **切果比例控制**：初期建议切果占菠萝总销量的**10%—20%**，根据门店客流和报损动态调整；写字楼、社区年轻客群多的门店可上调，老年客群为主的门店下调。
4. **切果必须有冷链和效期标识**：否则不建议做，食品安全风险会吃掉毛利。
5. **用整果价格做对比锚点**：切果定价要能让顾客感知“方便有溢价”，但不能高到只买整果。

### 什么情况下更适合主推切果

- 门店位于写字楼、商圈、交通枢纽，即时消费强；
- 客流小、家庭采购少，整果容易滞销；
- 已有成熟冷链和日清机制；
- 菠萝品质稳定、切果报损可控。

### 什么情况下只卖整果或极少切果

- 社区店以家庭囤货为主；
- 没有冷链柜或人手不足；
- 菠萝到货成熟度不齐，切果损耗不可控；
- 食品安全管理能力弱。

**一句话：整果保客流和基本销量，切果提毛利和场景增量；先小比例试切，用一周的销量和报损数据决定要不要扩大。**
