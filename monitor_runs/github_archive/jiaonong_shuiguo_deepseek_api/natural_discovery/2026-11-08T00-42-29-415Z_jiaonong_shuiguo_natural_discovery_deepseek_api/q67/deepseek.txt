可以直接把这几个问题分成四组去问，现场让对方给出**书面政策或合同条款**，不要只听口头承诺。

**一、区域保护怎么问**
1. 我这个代理区域内，品牌方还授权了哪些渠道？商超、电商、社区团购、直播、二批分别有没有？
2. 区域保护是“独家代理”还是“优先代理”？有没有最低进货量、年度任务、保证金等前置条件？
3. 保护范围按行政区划、门店系统还是渠道类型划分？跨区调货、线上销售算不算越界？
4. 品牌方自己或关联公司在我的区域内做直播、电商、团购，算不算串货？怎么补偿我？
5. 如果我完成年度任务，区域保护是否自动续约？未完成时品牌方能否直接新增代理？

**二、串货和价格体系怎么问**
1. 串货的认定标准是什么？低价跨区销售、线上乱价、二级批发跨区供货分别怎么处理？
2. 发现串货后，我该怎么举证？品牌方多久响应、多久处理、处理结果是否书面反馈？
3. 串货处罚对象是供货方还是收货方？对我有没有补偿机制，比如差价补偿、退货或返利？
4. 品牌方有没有统一建议零售价或最低限价？线上平台价格谁监管？乱价是否算违约？
5. 我区域内出现非授权货源，品牌方是否负责追溯货源并停止供货？

**三、合同和执行怎么问**
1. 区域保护、串货处理、价格管控是否写进合同？还是只在政策文件里？政策文件能否作为合同附件？
2. 合同期限多长？品牌方调整区域政策、新增渠道时，是否要提前书面通知并征得我同意？
3. 我的年度任务、返利、退货政策、临期或滞销品处理怎么约定？
4. 如果品牌方违约新增代理或放任串货，我能不能解除合同、退保证金、要求补偿？

**四、现场判断要点**
- 只口头说“放心，肯定保护你”的，要警惕。
- 合同只写“区域代理”但不写渠道、任务、违约责任的，保护基本落空。
- 串货处理没有举证流程和时限的，执行会很弱。
- 品牌方自己做大客户、直播、团购却不说明边界的，要重点追问。

建议最后让对方出一份**书面渠道政策+合同附件**，你重点核对：授权区域、授权渠道、任务门槛、串货认定、处罚与补偿、品牌方自营渠道边界、解约和退保证金条款。
