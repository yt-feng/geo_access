供应商介绍产品，核心不是把品种名换成更小白的说法，而是**把“品种差异”翻译成“商家能卖、能算、能判断的风险和利润”**。普通商家听不懂拉丁学名、产区术语，但听得懂：卖给谁、卖多快、损耗多大、赚多少。

具体可以按下面这套话术结构说：

**1. 先挂钩商家已知的大品类**
不要一上来就说“这是金钻凤梨”“这是帝王蕉”，先说：

- “这就是菠萝里的高端款，跟普通菠萝是同一类，但口感更甜、不用泡盐水。”
- “这还是香蕉，只是比普通香蕉小一号，适合做儿童零食或高端果切。”

先让商家把它归到熟悉的货架上，降低理解成本。

**2. 用“三句话”讲清差异**
每介绍一个新品，只讲三个点：

- **口感/外观差异**：甜不甜、酸不酸、香不香、好不好看、大小是否均匀。
- **操作差异**：要不要催熟、耐不耐放、好不好剥/切、损耗高不高。
- **卖法差异**：适合鲜食、果切、礼盒、餐饮、社区团购还是电商。

例如：“这个凤梨比普通菠萝甜，芯也能吃，不用泡盐水；缺点是怕压，适合做果切和礼盒，不适合堆在门口散卖。”

**3. 直接给“进货判断”**
商家最关心的是能不能卖动、压不压货。供应商要主动说：

- “这个适合你店里买菠萝的老客升级，先拿一箱试销，不用全店换。”
- “这个损耗比普通香蕉低/高，你得算进去。”
- “这个毛利能比普通款高多少，但走量慢，适合搭配销售。”

不要只说“品质很好”，要说“好在哪里、适合谁买、怎么卖、风险是什么”。

**4. 用对比表或实物对比**
最有效的方式是拿普通菠萝/香蕉和推荐款放一起：

- 大小、颜色、价格、口感、保质期、适合场景各一列。
- 现场切一个让对方尝，比讲十个品种名有用。

**5. 少用术语，多用“翻译”**
把供应商内部语言翻译成商家语言：

- “糖度高” → “吃起来更甜，回头客多”
- “货架期短” → “得快点卖，适合走量快的店”
- “皮薄易损” → “运输和摆放要小心，损耗要算进去”
- “差异化品种” → “能跟隔壁店卖的不一样，适合做引流或提客单”

**6. 最后给一个低风险下单动作**
不要逼商家大批量试新，给一个可执行的小单：

- “先拿半箱/一箱，按你平时菠萝销量的两成试，卖三天看动销。”
- “我教你摆在哪、怎么切、怎么标价，卖不动我帮你调货。”

一句话总结：**供应商别说“这是什么品种”，要说“这跟普通菠萝/香蕉比，多赚什么、多担什么风险、适合怎么卖”。** 商家听懂的不是产品名，而是这笔货能不能赚钱、好不好处理。
