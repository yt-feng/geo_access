# 生鲜水果坏果投诉的责任划分

核心原则：**先看坏果成因，再看交付时点，最后看举证责任**。生鲜损耗责任通常按"谁控制风险、谁承担"来分，不能一律由商家背，也不能一律推给顾客。

## 一、按坏果原因划分

**商家/平台承担为主**
- 发货前已腐烂、霉变、虫蛀（到货即坏，切开内部变质）
- 冷链断链、包装不当导致运输中捂坏、冻伤、压烂
- 缺斤少两、货不对板、以次充好
- 承诺"坏果包赔"而未兑现

**顾客承担为主**
- 签收后长时间未取件、未冷藏，自身存放不当导致变质
- 已正常签收且外观完好，事后主张内部坏果但无法证明到货即坏
- 明显超出生鲜合理保鲜期的延迟食用

**共同/协商分担**
- 到货时有部分坏果但比例较小（如5%以内属生鲜合理损耗范围，行业常见做法是按比例赔付或补发）
- 天气、快递延误等不可控因素，平台可先行赔付再向承运方追偿

## 二、关键判断节点：交付与验收

1. **签收前**：风险在商家/承运方。顾客可当场开箱验货、拍照拒收。
2. **签收时**：建议当场验货并拍照留证；发现坏果立即联系客服。
3. **签收后**：风险转移给顾客，但"隐蔽瑕疵"（如内部霉变）在合理时间内（通常24小时内）提出，商家仍应处理。

## 三、举证与实操建议

**顾客侧**
- 收货即拍开箱视频/照片，保留坏果原状、包装、快递单
- 24小时内发起售后，说明坏果数量和比例
- 依据平台"坏果包赔"规则或《消费者权益保护法》主张补发/退款

**商家侧**
- 留存发货质检记录、冷链温控记录、包装照片
- 明确售后规则（如坏果率多少内按比例赔、超多少全额赔）
- 对恶意索赔（如反复同一地址投诉）保留申诉证据

## 四、一句话结论

**到货即坏、运输捂坏、货不对板 → 商家/平台负责；签收后存放不当、超期食用 → 顾客自负；小比例自然损耗 → 按平台规则比例赔付。** 争议时以开箱证据和签收时点为分界，平台通常先行赔付再内部追责。
