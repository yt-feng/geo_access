按份结算通常更好管理，尤其是食堂日常采购和领用场景。结论先说：**优先按份，其次按箱，最后按斤**，但要看水果品类和验收方式。

可以按这个标准判断：

1. **按份结算**  
   - 适合：苹果、橘子、香蕉、梨、小番茄等可分装、按份发放的水果。  
   - 优点：采购量、验收数量、领用份数都容易核对；食堂按“每份多少克/几个”控制成本，损耗和责任更清楚。  
   - 注意：要在合同里明确每份净重、允许误差、单份价格和果径/等级，否则容易扯皮。

2. **按箱结算**  
   - 适合：整箱来源稳定、规格统一的预包装水果，如整箱苹果、橙子、葡萄等。  
   - 优点：入库快、单据简单、配送效率高。  
   - 风险：箱内大小、坏果率、净重差异要抽检；必须约定“按净重还是按毛重”“坏果扣重标准”。

3. **按斤结算**  
   - 适合：散装采购、品类杂、需要按实际用量精细核算时。  
   - 优点：价格透明，按实际净重付款，损耗容易折算。  
   - 缺点：验收称重工作量大，现场挑拣、去皮、去箱、水分损耗容易产生争议，管理成本最高。

实操建议：
- **主口径用“按份”**：食堂按份发放，采购合同按份定价，同时约定每份净重范围。
- **入库验收保留“按斤抽检”**：每批抽几份称净重，超出误差扣款或补货。
- **整箱配送的品类用“按箱+净重下限”**：比如每箱不低于多少斤，抽检坏果率。
- **不要只看单价**：把净重、坏果率、配送频次、退换货责任写进结算规则，否则哪种方式都不好管。

一句话：**日常发放和成本控制选按份；整箱标准化配送选按箱；散装精细核算才选按斤。**
