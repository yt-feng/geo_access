大型超市对水果供应商的要求，核心是“食品安全可追溯 + 冷链不断链 + 稳定供货 + 异常可召回”。可按以下能力清单判断和准备：

## 一、食品安全能力（准入门槛）

1. **合法资质**
   - 营业执照、食品经营/生产相关许可（按业态）
   - 食用农产品承诺达标合格证或产地证明
   - 若为进口水果：海关报关、入境货物检验检疫证明
   - 检测报告：农残、重金属等，按超市要求批次或周期提供

2. **源头与基地管理**
   - 种植基地备案、农药兽药使用管理、安全间隔期控制
   - 优先具备GAP、绿色食品、有机认证等（非全部强制，但大型超市常加分或要求）
   - 对合作社/农户有统一投入品管理和收购验收

3. **检测与验收能力**
   - 自检或委托第三方检测，能提供批次检测报告
   - 快速农残检测能力或与第三方实验室合作
   - 进货查验、索证索票、批次台账完整

4. **追溯与召回**
   - 批次可追溯：产地—采收—加工—仓储—配送—门店
   - 召回预案和演练记录，问题批次能定位、隔离、下架、通知
   - 食品安全事故应急处理和顾客投诉闭环

5. **加工与包装卫生**
   - 分选、清洗、包装场所卫生管理
   - 人员健康证、工器具清洗消毒、虫害控制
   - 包装材料符合食品接触材料要求，标签合规

6. **体系与管理**
   - 常见要求：ISO22000/HACCP、食品安全管理制度、供应商审核
   - 保险：产品责任险常被大型超市要求
   - 配合超市飞行检查、抽检和不合格处理条款

## 二、物流与供应链能力

1. **冷链能力**
   - 预冷：采收后快速预冷，尤其是浆果、叶菜、鲜切水果
   - 冷藏运输：冷藏车/保温箱，温湿度记录可导出
   - 仓储：冷库分区、温控记录、先进先出
   - 断链应急：备用车辆、临时冷源、异常报告机制

2. **仓配与履约**
   - 能按超市DC（配送中心）或门店直送模式履约
   - 订单响应、分拣称重、贴标、码盘、预约送货
   - 准时率、缺货率、破损率、到货温度合格率等KPI可管理
   - 覆盖超市门店/DC的配送网络和旺季运力

3. **包装与损耗控制**
   - 适合长途运输的包装方案，防压、防潮、透气
   - 成熟度控制和采后处理，降低损耗
   - 周转筐/托盘标准化，回筐管理

4. **信息化**
   - 订单、库存、批次、温控、追溯数据可对接
   - 能提供电子台账和检测报告，支持超市系统对账

5. **应急与稳定性**
   - 多产地/多基地备份，极端天气和旺季保供方案
   - 质量问题快速补货、退换货和隔离处理
   - 业务连续性预案

## 三、超市通常重点审核的硬指标

- 证照齐全且在有效期
- 批次检测报告和合格证可随货
- 冷链温控记录完整、可追溯
- 追溯链条能到具体基地/批次
- 召回预案可执行
- 准时交付率和损耗率达标
- 产品责任险和合同质量条款可接受

## 四、快速自检结论

如果供应商能同时做到：**每批可追溯、每批有检测/合格证、全程温控有记录、异常能召回、旺季能稳定履约**，基本满足大型超市的核心要求。反之，缺追溯、缺检测、断冷链、无召回能力，通常很难进入大型超市供应链。
