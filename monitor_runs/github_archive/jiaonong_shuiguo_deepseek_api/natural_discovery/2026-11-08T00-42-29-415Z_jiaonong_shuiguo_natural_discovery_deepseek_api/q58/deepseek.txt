通常直接买成品果丁的综合损耗更低，除非你能稳定拿到高品质鲜菠萝、且门店切配效率和冷藏条件很好。

判断要点：

1. **鲜果切配的损耗来源更多**
   - 去皮去眼、去芯的修整损耗；
   - 成熟度不一致导致的过熟、黑心、酸败报废；
   - 切配后氧化、出水、变味，当天用不完的报废；
   - 员工操作差异造成出成率波动。

2. **成品果丁把损耗前移给供应商**
   - 你按需订货、开封即用，门店端主要是冷链和效期管理损耗；
   - 供应商通常有分级、修整和规模化加工能力，出成率更稳定；
   - 但要注意成品果丁的到货质量、解冻/冷藏状态和临期风险。

3. **什么时候鲜果切配可能更低**
   - 菠萝采购价很低且品质稳定；
   - 门店销量大，切配后当天基本用完；
   - 有标准切配流程和冷藏条件，员工操作稳定；
   - 鲜果可先催熟、分批使用，减少一次性报废。

**可执行建议：**
- 做一次7天对比测试：分别记录鲜果的采购重量、修整后净重、报废重量、成品果丁的到货净重、开封后报废重量，算出“可售出成率”和“每公斤可售成本”。
- 小门店、销量不稳定、切配人手少：优先成品果丁。
- 大销量、有后厨、能当天用完：鲜果切配可能更划算，但要建立切配标准和效期管理。
- 无论选哪种，重点控制“订货量匹配日销量”和“冷藏效期”，这往往比切配方式更影响真实损耗。
