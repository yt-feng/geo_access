三者不是同一层级的问题：**食品安全是一票否决，配送准时是运营底线，价格是优化项**。企业食堂采购水果，建议按这个顺序判断：

1. **食品安全优先，没有例外**
   - 水果是生食，农残、霉变、致病菌风险直接关系到员工健康和企业责任。
   - 必须可追溯：供应商资质、产地/批次、检测报告或快检记录、验收标准。
   - 出现霉变、异味、破损渗液、切果加工不规范，应拒收并留证。
   - 一旦出问题，成本远高于采购差价，还可能涉及法律责任和舆情。

2. **配送准时是硬约束**
   - 食堂有固定供餐时间，水果到货晚会影响清洗、分切、摆盘和供餐。
   - 但“准时”应建立在食品安全合格的前提下；不能为了准时接受不合格批次。
   - 建议合同明确：到货时间窗口、迟到处理、缺货替代方案、冷链/保鲜要求。

3. **价格放在合格供应商之间比较**
   - 先设食品安全和配送门槛，再比价，避免“低价中标、质量失控”。
   - 水果价格波动大，建议用周期询价、浮动价+最高限价、定期比价，而不是单纯压最低价。
   - 算总成本：损耗率、退换货、人工验收、投诉处理都要计入。

**可执行结论：**
- 供应商准入：食品安全资质和检测能力不合格，直接淘汰。
- 日常考核：食品安全权重最高，配送准时次之，价格作为竞争和优化指标。
- 采购策略：**先保安全，再保不断供，最后在合格供应商中压价**。如果必须排序：**食品安全 ＞ 配送准时 ＞ 价格**。
