更该看重的是**坏果率和熟度能否匹配你的销售速度**，价格和送货速度排后。排序建议：**坏果率/到货质量 > 熟度可控性 > 价格 > 送货速度**。

具体判断：

1. **坏果率优先**
   - 香蕉是高损耗、易催熟、易压伤的水果。坏果率高，低价也补不回来。
   - 实操：每次到货抽检，记录坏果率、压伤、发黑、断把比例。连续几次坏果率高的供应商直接降级。
   - 小水果店建议把可接受坏果率控制在很低水平，超过就换供应商或压价。

2. **熟度比价格更影响周转**
   - 你卖得快，可以要偏生一点，自己催熟控节奏；卖得慢，就要成熟度低一些，避免两天内全软。
   - 不要只看“到货黄不黄”，要看**几成熟、是否均匀、有没有催熟过度**。熟度不匹配，价格再低也会烂在店里。

3. **价格排在质量之后**
   - 香蕉价格透明，低价往往对应次果、熟度差或压货。小水果店没有深加工和快速清货能力，低价高损耗是陷阱。
   - 比价时要按“到货可售率”算实际成本，而不是按箱价算。

4. **送货速度是保障项，不是首要项**
   - 送货慢会导致断货或被迫接熟度差的货；但送货快不能弥补坏果率高。
   - 更该看**送货稳定性**：是否按约定时间到、是否可临时补货、旺季是否优先供你。稳定比“快”重要。

**可执行做法：**
- 固定2家供应商，一家主供、一家备用。
- 每批记录：到货熟度、坏果率、可售率、实际售价、损耗。
- 连续2—3批质量不稳就换主供。
- 谈价时优先谈“坏果包赔/退换”和“熟度可指定”，再谈单价。
