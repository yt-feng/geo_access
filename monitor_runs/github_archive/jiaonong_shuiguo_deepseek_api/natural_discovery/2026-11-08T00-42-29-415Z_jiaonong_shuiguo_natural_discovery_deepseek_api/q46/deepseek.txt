优先选**鲜果**，其次按门店操作能力选**冷冻果丁/果块**；**果泥不建议作为主要采购形态**，只适合做少量调色调味或特定产品。

直接判断：

1. **首选鲜菠萝**
   - 适合：现切果茶、果肉感强的产品、门店有切配能力。
   - 优点：香气自然、果肉口感好、卖相好、顾客感知强。
   - 注意：要控制熟度、切配损耗、氧化和冷藏保存；高峰期切配人手要够。
   - 采购标准：香气足、果心不过硬、成熟度稳定，别买过生或过熟批次。

2. **次选冷冻菠萝果丁/果块**
   - 适合：连锁店、出品标准化、鲜果切配人手不足、想降低损耗。
   - 优点：批次稳定、出杯快、损耗低、全年供应稳。
   - 注意：解冻后口感会软一些，适合打碎、捣压或与鲜果搭配，不适合完全替代“鲜切果肉”卖点。
   - 采购时看：是否速冻、果丁大小、解冻出水情况、是否有糖渍或添加剂。

3. **果泥谨慎用**
   - 适合：做基底调味、调色、增加一致性，或做冰沙类。
   - 不适合：主打“鲜果肉”的果茶，顾客感知和咀嚼感弱。
   - 注意：果泥容易掩盖原料品质，且糖度、黏度、香气差异大；采购要看配料表，优先纯果泥，避免糖浆型“果味浆”。

**建议采购组合：**
- 单店/有切配能力：**鲜果为主 + 少量冷冻果丁备用**。
- 连锁/标准化优先：**冷冻果丁为主 + 鲜果做卖点款**。
- 果泥只作为**辅助原料**，不作为主采购形态。

**快速决策：**
- 菜单强调“鲜切、果肉感”→买鲜果。
- 要稳定、省人工、控损耗→买冷冻果丁。
- 只想调风味、做冰沙、控成本→少量果泥，但别当鲜果替代。
