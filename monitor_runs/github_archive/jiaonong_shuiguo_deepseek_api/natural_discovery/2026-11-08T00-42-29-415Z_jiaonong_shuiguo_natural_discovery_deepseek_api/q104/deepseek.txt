单位采购水果出现品质不一致时，核心是把验收标准前置、现场留证、分级处置、售后闭环。下面按可执行流程说明。

## 一、到货前先明确标准
采购合同或订单中应写清：
- **规格等级**：品种、单果重量/果径、成熟度、糖度（如可测）、外观（色泽、果形、瑕疵比例）。
- **允许偏差**：例如同一批次中不符合标准的比例不超过5%—10%，超过即整批或该部分拒收/折价。
- **验收方式**：抽检比例（如每批随机抽3—5箱，每箱抽10—20个）、验收时限（到货后2小时内）。
- **售后条款**：品质不符时的补货、换货、退货、折价比例及响应时限。

## 二、到货现场验收流程
1. **核对单据与批次**：品名、数量、产地、采摘/包装日期、冷链温度记录（如适用）与订单一致。
2. **分层抽样**：不要只看表层。从上、中、下及不同箱随机抽取，记录抽样箱号和数量。
3. **逐项检查**：
   - 外观：腐烂、霉变、机械伤、裂果、虫害；
   - 成熟度：过生/过熟比例；
   - 规格：单果重量或果径是否达标；
   - 口感/糖度：按需抽测；
   - 温度与气味：有无异味、发热、冻伤。
4. **现场记录**：拍照/录像（含批次标签、问题果特写、整箱全景），填写验收单，双方签字确认。问题果单独封存留样。
5. **判定处置**：
   - 轻微偏差且在允许范围内：正常收货，备注提醒；
   - 部分不合格：按比例折价或挑出不合格部分退货补货；
   - 严重不符（腐烂、霉变、规格严重偏离）：拒收该批或整单，要求换货。

## 三、售后处理
1. **限时反馈**：验收发现问题的，当场或按合同时限书面通知供应商，附照片、抽检记录和验收单。
2. **明确诉求**：补发、换货、退货退款或折价，给出数量和金额计算依据。
3. **留样与隔离**：问题水果单独存放，避免混入合格品，必要时冷藏保存待供应商确认。
4. **跟踪闭环**：记录供应商响应时间、处理结果；同一供应商重复出现问题的，纳入考核或调整采购份额。
5. **内部留档**：验收单、照片、沟通记录、处理结果归档，作为后续索赔和供应商评价依据。

## 四、建议的验收单要素
到货日期、供应商、批次、品种、数量、抽样数量、不合格数量及比例、问题描述、现场照片编号、处置意见、双方签字、售后时限。

## 五、关键提醒
- **不要先签收再验**：签字即视为认可数量和质量，除非合同另有约定。
- **抽检要有代表性**：只查表层容易被“上面好、下面差”蒙混。
- **标准要可量化**：用“新鲜”“优质”这类主观词容易扯皮，尽量用比例、重量、果径等指标。
- **售后时限写进合同**：例如到货后24小时内提出品质异议有效，供应商48小时内响应。
