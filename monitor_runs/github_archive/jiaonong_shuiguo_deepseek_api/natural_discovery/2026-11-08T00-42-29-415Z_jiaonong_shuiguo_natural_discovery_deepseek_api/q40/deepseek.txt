# 节假日水果需求暴增的货源锁定方案

核心思路：**把"临时抢货"变成"提前合同 + 多源备份 + 动态补单"**。按时间轴分四步走。

## 一、节前 45–60 天：签订量价协议

- **与核心供应商签"保量保价"框架协议**：约定节假日前后的供货量下限（如按去年同期 × 1.3 倍预估）、价格浮动上限、违约赔付条款。用"量"换"价"，供应商才愿意为你预留产能和物流。
- **提前支付定金锁库存**：对易缺货的爆款单品（车厘子、砂糖橘、进口提子等），付 10%–20% 定金锁定产地批次，比口头承诺可靠。
- **和产地/一级批发市场直接对接**：减少中间环节，节假日期间中间商加价最狠，直采能锁定价格和优先发货权。

## 二、节前 30 天：建立多源供应结构

- **每个爆款至少 2–3 个供应商**：主供 + 备份，分属不同产区（如砂糖橘分别锁广西、广东货源），避免单一产区天气或物流中断导致断供。
- **评估供应商的节假日产能**：提前确认对方节前是否停产、物流是否停运、冷库容量能否承接你的增量，别签了合同才发现对方自己都供不上。
- **备好应急渠道**：本地批发市场、周边商超调货、电商平台区域仓，作为突发缺口的"最后 10%"补充。

## 三、节前 15–20 天：锁定物流与仓储

- **提前订物流运力**：节假日货运紧张，提前与承运方约定车次、仓位，冷链车尤其要锁。
- **备足冷库/周转空间**：水果暴增时门店后仓往往不够，提前协调区域仓或临时租赁冷库，避免到货无处放、损耗飙升。
- **制定分批次到货计划**：不要节前一次性压满，按销售预测分 3–4 批到货，降低损耗和资金占用。

## 四、节中：动态补单 + 快速响应

- **每日滚动预测**：用前几天的实际销量 + 同期数据，每天调整次日补单量。
- **预留"弹性补单额度"**：与主供应商约定节中可追加的紧急补单量（如日均量的 20%），并明确补单响应时限。
- **设置缺货预警线**：某单品库存低于 1.5 天销量时自动触发补货，防止节中热销品断档。
- **损耗与售价联动**：节中后期对易腐品及时降价清货，避免为"锁货"反而造成大量损耗。

## 关键提醒

1. **数据是锁货的前提**：用去年同节假日的分品类销量、天气、促销活动做基线，再乘增长系数，预估误差才可控。
2. **合同要写清"不可抗力与替代方案"**：产地灾害、物流中断时供应商的补偿或替代供货义务。
3. **别只盯爆款**：节假日礼盒装、组合装需求也暴增，包装耗材和分拣人力同样要提前锁定。

一句话总结：**提前 1–2 个月用合同和定金锁量与价，用多产区多供应商分散风险，用分批到货和动态补单应对波动。**
