# 甜品店采购香蕉防快速变黑：实操建议

香蕉变黑主要发生在**到店后2–4天**，核心原因是：①采购时成熟度已经偏高；②运输/储存温度不当（低温冷害或高温催熟）；③机械损伤和乙烯积聚。按下面几条执行即可明显延长货架期。

## 一、采购环节：卡成熟度，不贪便宜

- **优先买"绿尖黄身"的香蕉**：果身黄色、两端还带一点绿，或七成熟左右。甜品店通常需要2–3天内用完，这个成熟度到店后正好陆续转黄，不易直接发黑。
- **当场验货**：看果柄（发黑发软的不要）、看棱角（棱角明显偏生，圆润饱满偏熟）、摸硬度（轻按有弹性但不软塌）；整把中若已有1–2根明显黑斑，说明整把乙烯已高，尽量换货或当天优先处理。
- **按用量分批买**：宁可少量多次，别一次囤一周的量。按门店日均用量×2–3天的量下单最稳。

## 二、运输与到店收货

- **别用密封塑料袋闷着运**：香蕉呼吸放乙烯，闷在袋里会加速整体成熟。用透气的筐/纸箱，留通风口。
- **避免挤压和磕碰**：磕伤处会先黑。装箱时香蕉之间垫纸，不要堆压过重。
- **不要放冰箱运输**：低于约12℃会产生冷害，表皮很快发黑（果肉其实还没熟）。

## 三、到店后的储存（最关键）

1. **温度**：13–15℃最理想，阴凉通风处即可。**不要进冷藏柜**（除非已完全成熟且要延缓最后阶段，但表皮仍会变黑）。
2. **悬挂或单层平放**：减少受压面；整把可拆开单根存放，降低乙烯互相催熟。
3. **隔离乙烯源**：远离苹果、梨、番茄等释放乙烯的水果；香蕉自身也释放乙烯，存放区要通风。
4. **包果柄**：用保鲜膜单独包住整把的果柄（蒂部），能减缓乙烯从切口释放，是甜品店很实用的一招。
5. **已转黄的香蕉**：拆开单根、包裹果柄、放通风阴凉处，2–3天内用完；需要再拖1天可短时放冷藏，但表皮会变黑，**果肉仍可用**，适合做香蕉泥/烘焙，不适合做装饰摆盘。

## 四、门店内的"先进先出"和补救

- 每天挑出**最熟的2–3根**优先用于香蕉泥、奶昔、烘焙馅料，别等全黑才处理。
- 出现少量黑斑（芝麻斑）时是甜度最高的时候，正好做甜品；**大面积发黑、果肉软烂出水**才丢弃。
- 装饰用的香蕉（切片摆盘）当天现切，切后可刷少量柠檬汁减缓氧化。

## 一句话总结
**买七成熟、透气运、13–15℃阴凉通风存、包果柄、拆开单放、远离乙烯水果、先进先出优先做泥**——这样到店后基本能稳住3–5天不明显发黑。
