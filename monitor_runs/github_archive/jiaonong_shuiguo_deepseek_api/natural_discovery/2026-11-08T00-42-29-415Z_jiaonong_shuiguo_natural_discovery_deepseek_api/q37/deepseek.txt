商超会员日水果活动，供应商提前配合的核心是：**保量、保品、保价、保到货节奏、保现场可控**。建议按活动前7—10天启动，重点准备如下。

1. **确认活动方案与需求预测**
- 明确活动日期、时段、门店范围、会员价/折扣形式、限购规则、线上线下是否同享。
- 按门店拆分销量预测：正常日销量×活动系数，参考上次同类活动、天气、节假日、竞品价格。
- 确认SKU清单：引流爆品、利润款、常规款、应急替代品，避免只备一个爆品。
- 明确总备货量、分仓/分店配送量、安全库存和补货触发点。

2. **锁定货源与品质标准**
- 提前锁定产地/基地/批发市场货源，确认可采收量和替代货源。
- 约定验收标准：规格、糖度、着色、成熟度、果径、净重、包装、农残检测、破损率上限。
- 活动果建议“八成至九成熟到店”，既保证卖相又减少损耗；明确次果、软果、碰伤果处理规则。
- 提前做农残检测或索取合格证明，避免活动期抽检风险。

3. **价格与费用确认**
- 书面确认供货价、活动价、毛利空间、促销折让、返点、损耗补贴、配送费用承担方。
- 明确锁价周期，防止活动前产地涨价导致断供或临时提价。
- 约定价格保护：若市场价大幅波动，双方如何调量、调价或换品。
- 确认结算方式、账期、对账单据和发票要求。

4. **包装与加工准备**
- 提前备足活动包装：预包装盒、保鲜膜、标签、价签、称重贴、陈列道具。
- 如需门店分装，明确加工标准、损耗承担、加工人员和加工时间。
- 包装上预留会员价签位置，避免门店临时改价混乱。
- 对易损水果增加保护包装，减少配送和陈列损耗。

5. **物流与到货节奏**
- 制定分日、分店配送计划，活动首日提前到货，避免开门前集中卸货。
- 明确到货时间窗、卸货口、收货联系人、冷链要求。
- 生鲜水果优先冷链或控温运输，明确温度记录和异常处理。
- 设置活动期每日补货机制：上午售罄预警、下午补货、次日追加订单截止时间。
- 准备应急车辆和备用货源，防止爆单断货。

6. **门店陈列与试吃支持**
- 供应商配合提供陈列建议：堆头、端架、冷藏柜、关联陈列。
- 提供试吃样品、试吃切配支持、试吃损耗承担约定。
- 制作简易物料：产地卖点、甜度/口感说明、会员价爆炸贴、限购提示。
- 培训门店员工：品种特点、保存方式、挑果方法、活动规则。

7. **人员与现场支持**
- 活动首日安排供应商驻店或巡店人员，重点门店可驻场。
- 明确驻场职责：补货、理货、挑拣残次、试吃、反馈销售。
- 建立活动沟通群，门店、采购、供应商、物流四方实时响应。
- 约定突发问题处理时限，如断货2小时内响应、品质投诉当日处理。

8. **损耗与售后规则**
- 提前约定损耗率上限、残次果退换条件、活动结束后库存处理方式。
- 明确顾客投诉的赔付责任：品质问题由供应商承担或按比例分担。
- 活动尾期控制补货量，避免活动后大量库存和跌价损失。
- 对临期、软损水果提前约定折价销售或退回机制。

9. **风险预案**
- 天气风险：高温、降雨影响客流和水果品质，准备冷藏和防雨措施。
- 爆量风险：设置备用货源和替代SKU，避免单一爆品断货。
- 品质风险：到货抽检不合格的拒收、换货、补货时限。
- 价格风险：产地涨价时的锁价或调量机制。
- 舆情风险：会员价未生效、限购纠纷、称重差错的门店处理口径。

10. **活动前联合检查清单**
- 需求量和分店配送表已确认；
- 供货价、活动价、费用承担已书面确认；
- 样品已验收，品质标准已封样；
- 包装物料已到店；
- 物流时刻表和联系人已确认；
- 驻店/巡店人员已排班；
- 应急货源和替代SKU已落实；
- 损耗、退换、结算规则已确认。

最关键是：**活动前封样、锁量、锁价、锁到货时间；活动中每日复盘销量和库存，动态补货；活动后及时对账和处理尾货。** 供应商不要只报一个总供货量，要按门店、按日、按SKU拆到可执行。
