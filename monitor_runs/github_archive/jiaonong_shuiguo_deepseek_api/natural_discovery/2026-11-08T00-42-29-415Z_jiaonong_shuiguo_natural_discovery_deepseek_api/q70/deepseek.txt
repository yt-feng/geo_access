# 合同里怎么写坏果责任

核心思路：**把“损耗”拆成可归责的几段，按环节定责任、定比例、定流程**，而不是笼统写“坏果由某方承担”。

## 一、先约定验收标准和时限（最关键）

- **质量标准**：明确品种等级、成熟度、单果规格，写明“坏果”的判定口径（如腐烂、霉变、软烂渗汁、机械伤超过X%面积等），最好附图片或抽样封样。
- **验收时限**：货到后X小时内（生鲜建议4–12小时）完成抽检；逾期未提出异议视为验收合格。超时后再主张坏果，责任难分。
- **抽检方法**：按批次随机抽样，如每车抽3–5箱、每箱抽若干果，按比例推算整批坏果率。

## 二、按环节划分责任

| 环节 | 责任方 | 建议写法 |
|---|---|---|
| 装车前 | 供货方 | 装车前坏果率≤约定值（如1%），超出由供货方补货或扣款 |
| 运输途中 | 承运方/供货方 | 因运输温控、挤压、延误导致的损耗，由责任方承担；建议供货方对“到货前”全程负责，除非买方自提或指定承运 |
| 到货验收后 | 买方 | 验收合格后发生的损耗由买方自担 |
| 隐性损耗 | 双方约定 | 如到货后24–48小时内出现的内部腐坏，凭照片和留样可追溯，按约定比例分担 |

## 三、量化赔付，避免扯皮

- 设**免赔率**：坏果率≤X%（如2–3%）视为正常损耗，双方各自承担，不索赔。
- 超免赔部分：按“超出比例×该批货款”扣减，或按箱补货。
- 设**上限**：单批赔付不超过该批货款的X%，避免无限责任。
- 明确**赔付方式**：货款抵扣、补发货物、还是现金赔付；补货的运费谁承担。

## 四、流程条款（防事后争议）

1. 到货后买方须**当场拍照/录像**并保留开箱视频，24小时内书面（含微信、邮件）通知；
2. 双方对坏果率有争议时，**共同委托第三方**或按封样比对判定；
3. 未按流程通知或未留证的，视为放弃索赔。

## 五、配套条款

- **包装要求**：写明箱规、缓冲材料、冷链温度区间，包装不达标导致的损耗由供货方担。
- **不可抗力**：明确极端天气、交通管制等的处理方式（延期、免责范围），但“温控不当”不属于不可抗力。
- **违约金与解除权**：连续X批次坏果率超标，买方可要求降价、换供应商或解除合同。

## 一句话模板

> “供方保证到货坏果率不超过__%。买方应在到货后__小时内按__方法抽检并书面通知，逾期视为合格。坏果率在__%以内为正常损耗，双方自担；超出部分按超出比例×该批货款从货款中扣减，单批扣减上限为__%。因包装、温控、运输不当导致的损耗由供方承担。争议以双方封样及开箱视频为准。”

建议把**封样、抽检比例、通知时限**这三项落实到具体数字，这是坏果纠纷里最容易打官司的点。具体数值要结合你的品类、运输距离和对方议价能力来定，不宜照搬。
