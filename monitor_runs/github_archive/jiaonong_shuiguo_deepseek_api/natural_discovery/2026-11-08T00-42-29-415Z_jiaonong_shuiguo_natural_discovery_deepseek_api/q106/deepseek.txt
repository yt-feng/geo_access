判断供应商每天变价是否“合理”，关键不是看涨跌本身，而是看**波动是否有依据、是否可解释、是否与市场同步、是否在约定机制内**。建议采购方建立一套可执行的判断框架：

### 1. 先定“合理波动”的规则
在合同或采购制度里提前约定，而不是每天凭感觉判断：

- **基准价来源**：以当地批发市场均价、行业指数、产地收购价、物流成本等作为参照。
- **波动阈值**：例如单日涨跌超过3%～5%需书面说明；超过10%需提供依据或重新议价。
- **调价频率**：约定每日、每周或随行就市，但要有报价截止时间和生效时间。
- **异常处理**：连续多日单边上涨、只涨不跌、涨幅明显偏离市场时，触发复核。

### 2. 看波动是否与市场同步
重点比对三类信息：

- **产地端**：天气、采收期、病虫害、灾情、集中上市或断档。
- **批发端**：当地一级批发市场同品类均价和到货量。
- **成本端**：油价、冷链运价、包装、人工是否明显变化。

如果市场均价平稳，供应商却连续大幅涨价，就属于需要质询的异常；如果产地受灾、到货量骤降，涨价则相对合理。

### 3. 看品类特性
不是所有水果都适用同一波动标准：

- **叶菜、浆果、荔枝、樱桃等易腐短保品类**：日波动大是常态，应看品质等级和损耗率。
- **苹果、梨、土豆等耐储品类**：价格应相对稳定，日波动大反而异常。
- **进口水果**：受汇率、船期、关税、口岸通关影响，需单独设参照。
- **同一品类不同等级**：必须按规格、糖度、大小、产地分开比价，防止“以次充好式涨价”。

### 4. 要求供应商提供“涨价依据”
可要求其每日或每周报价附带：

- 产地收购价及变化
- 物流费用变化
- 到货量和库存情况
- 同市场可比报价
- 涨跌原因说明

对降价则不必过度质询，但要防止“先涨后降”或“低价低质”。

### 5. 建立历史价格台账
至少记录30～90天的：

- 供应商报价
- 市场均价
- 实际成交价
- 品质合格率
- 到货准时率

用历史均值、波动区间和同比/环比判断。比如某供应商报价长期高于市场均价5%以内可接受，突然高于15%就要核查。

### 6. 用“综合成本”而不是“单价”判断
水果采购的真实成本包括：

**单价 + 损耗率 + 退货率 + 配送费 + 账期成本 + 品质不合格损失**

有些供应商单价低但损耗高、次果多，实际成本更高；有些报价略高但稳定、可追溯，反而合理。

### 7. 设置异常信号
出现以下情况应重点核查：

- 连续3天以上单边上涨，且无市场依据
- 涨幅明显高于当地批发市场均价
- 只对采购方涨价，对其他客户未涨
- 报价频繁但成交价不透明
- 以“明天还要涨”催促下单
- 品质等级悄悄下调但价格不变或上涨
- 同一产地、同一规格，不同供应商报价差异过大

### 8. 建立简单可执行的判断表
每天或每周打分：

| 判断维度 | 正常 | 需说明 | 异常 |
|---|---|---|---|
| 与市场均价偏差 | ±3%内 | 3%～8% | 超过8% |
| 涨跌原因 | 有明确产地/物流依据 | 原因模糊 | 无依据 |
| 连续性 | 随行就市 | 连续2～3天同向 | 连续多日单边 |
| 品质一致性 | 规格稳定 | 轻微波动 | 降级不说明 |
| 历史价格 | 在区间内 | 接近上沿 | 突破历史区间 |

**结论：合理波动的核心是“可解释、可验证、可比较、在规则内”。** 采购方不必追求价格不变，而应要求供应商把涨价逻辑说清楚，并用市场价、历史价、品质和综合成本交叉验证。最有效的做法是：**合同里预设调价规则，日常建立价格台账，异常时要求书面依据，定期做供应商比价。**
