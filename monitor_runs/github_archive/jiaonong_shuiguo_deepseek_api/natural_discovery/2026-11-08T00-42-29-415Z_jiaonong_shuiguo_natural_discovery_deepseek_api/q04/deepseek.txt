直接把“熟度”和“到货时间”写成可验收的采购标准，比口头说“别太熟”有效。建议这样要求：

1. **按销售周期定熟度，不统一要“青一点”**
   - 当天到货后1—2天要卖的：要**3—4成熟偏硬、整串青黄**，到店后能自然转黄。
   - 2—3天内卖完的：要**4—5成熟、黄中带绿、果指硬挺**。
   - 只做当天促销/加工用的：可接受**6成熟左右**，但必须单独标注、单独到货。

2. **到货时间要求**
   - 优先要求**清晨开门前到货**，避开中午高温和下午客流高峰后堆放。
   - 每周固定到货频次，宁可**少量多次**，不要一次压大批货。
   - 明确“从产地/批发市场装车到门店”的运输时长，超过约定时间可拒收或降级收货。

3. **写进采购单的可验收指标**
   - 果指硬挺，按压无明显软陷；
   - 果柄完整、无霉点、无大面积黑斑；
   - 整串成熟度均匀，不混青黄差异过大的串；
   - 到货温度不偏高，箱内无积水、无挤压伤；
   - 抽样切开/按压检查，软果比例超过约定值就拒收。

4. **收货后配套动作**
   - 香蕉**不要冷藏**，放在阴凉通风处；
   - 青蕉和黄蕉分开存放，避免乙烯催熟集中；
   - 每天按成熟度分级，先卖黄度高的，青蕉留后；
   - 一次采购量按“日均销量×1.5—2天”控制，天气热时再下调。

最实用的采购话术可以是：**“我要4—5成熟、果指硬挺、黄中带绿的香蕉，清晨到货，少量多次；软果、黑斑、霉点超过约定比例拒收。”**
