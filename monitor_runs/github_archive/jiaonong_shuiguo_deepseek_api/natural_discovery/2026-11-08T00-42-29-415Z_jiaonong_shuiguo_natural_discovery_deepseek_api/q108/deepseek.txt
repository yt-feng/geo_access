不要只听“全国配送”这四个字，要把它拆成“能到哪些城市、多久能到、什么货能到、出了问题谁负责”来验证。建议按下面做：

1. **要覆盖清单，不要口头承诺**
   - 要求供应商提供可配送城市/区县清单，最好含：常发城市、次日达城市、冷链覆盖城市、偏远地区是否加价。
   - 让对方明确：是直达、干线+落地配，还是转包给第三方。

2. **用真实订单试发**
   - 选采购方实际收货地中“最远、最偏、最需要冷链”的1—3个点做试单。
   - 不要只试主城区，要试区县、园区、乡镇或冷链要求高的品类。
   - 记录下单到送达时长、温控记录、破损率、包装完整度。

3. **核实物流承运与落地配**
   - 问清承运商名称、干线线路、落地配合作方。
   - 要求提供近期发往目标区域的运单号或签收记录，可脱敏。
   - 对生鲜水果重点确认：是否全程冷链、是否控温记录、转运几次、到货是否开箱验货。

4. **查资质与合同责任**
   - 营业执照、食品经营/生产相关许可、冷链运输能力证明。
   - 合同里写清：覆盖范围、时效承诺、温控标准、破损/腐损赔付、延迟违约责任、偏远地区附加费。
   - 不要接受“全国可发”但时效和赔付模糊的条款。

5. **做小批量压力测试**
   - 先用小批量、多地址、不同品类试配。
   - 观察旺季、节假日、恶劣天气下的履约表现，尤其是水果集中上市期。
   - 让供应商提供异常处理流程：丢件、延误、腐损、拒收怎么处理，多久响应。

6. **交叉验证**
   - 向承运商或落地配网点核对该供应商是否真实合作。
   - 查企业信用信息、涉诉记录、经营异常。
   - 向同区域客户要可核实的合作证明，但注意隐私脱敏。

**判断标准**：能提供明确区县清单、有真实试单记录、合同写清时效和赔付、偏远/冷链区域不回避的，才算“实际覆盖能力”可信。只给全国地图、只口头保证、不愿试单或不愿写赔付的，按覆盖能力不足处理。
