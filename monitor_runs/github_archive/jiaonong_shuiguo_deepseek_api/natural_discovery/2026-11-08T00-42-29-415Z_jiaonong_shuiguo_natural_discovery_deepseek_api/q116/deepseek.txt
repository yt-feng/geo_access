# 小商家水果采购：现金结算 vs 月结账期

## 现金结算（现款现货）

**主要风险：**

1. **资金占用压力大**：水果是高频刚需，天天要进货，现金一付出去就压在货上。如果销售回款慢（比如你下游也有账期），容易出现现金流断档。
2. **无对账缓冲**：当场付钱，事后发现短斤少两、品质不符、规格不对时，钱已经出去了，只能靠当场验货。退货换货的谈判筹码弱。
3. **欺诈风险集中**：现金交易留下凭证少，遇到"以次充好""调包""临时加价"时举证困难；找零、大额现金携带也有安全风险。
4. **丢失账期红利**：放弃了用供应商资金周转的机会，规模扩张速度受限。

**但现金的优势**：通常能拿到更低单价、更好货源优先权，且不欠人情、不被断供要挟。

---

## 月结账期

**主要风险：**

1. **对账纠纷**：水果损耗率高、价格波动大，月底对账时"这批烂了多少算谁的""说好的价怎么变了"最容易扯皮，账期越长纠纷越难追溯。
2. **被动依赖与断供风险**：账期让你绑死在一家供应商上。一旦对方涨价、降质或突然停止供货，你因为"还欠着钱"很难立刻换人。
3. **隐性成本转嫁**：愿意给账期的供应商，往往已经把资金成本打进单价里（通常比现结贵几个点），表面宽松实则更贵。
4. **信用与法律风险**：赊账容易越滚越大，销售一旦下滑就还不上，轻则被断供、重则被起诉，还可能影响个人征信或经营信用。
5. **品质话语权下降**：欠着款，遇到质量问题往往"不好意思较真"，坏果只能自己吃下。

**账期的优势**：缓解现金流、便于月底统一核算、有质量问题时可从货款中扣抵。

---

## 实操建议

- **按品类分**：易损耗、需当天验货的（鲜果、叶菜类）优先现结换好价；耐储、标准化程度高的可谈短账期（7–15天）。
- **控制账期长度**：小商家建议不超过 **15–30天**，别接受"季结""半年结"。
- **现结也要留凭证**：每笔写清品名、规格、单价、重量，拍照留底，当场验货签字。
- **账期必设对账机制**：每次送货签收单双联、注明损耗扣减规则，月底对账有据可依。
- **不把鸡蛋放一个篮子**：即便有账期供应商，也保留 1–2 家现结备选，防止被断供卡脖子。
- **算真实成本**：把"账期单价 − 现结单价"折算成年化资金成本，再决定哪个更划算。

一句话总结：**现金买的是价格和主动权，账期买的是现金流但让渡了议价权和灵活性**。小商家资金薄，更适合"核心品类短账期 + 边缘品类现结"的混合策略，而不是全押一边。
