批发档口降低退货纠纷，收货验货的关键是**把“当场发现、当场确认、留下凭证”做成固定动作**，而不是事后扯皮。建议按下面做。

## 1. 先定规则，再收货
- **到货前明确验货时限**：比如司机在场时当面验；物流代收的，签收后2小时内开箱并拍照录像，超时视为无异议。
- **明确异常处理口径**：少件、破损、错款、脏污、色差、批次差异分别怎么处理，写进收货单/微信群公告。
- **只认“当场记录”**：口头说“有问题”不算，必须有照片/视频、件数、货号、批号、时间。

## 2. 收货时先点总件数，再开箱
- **先核对大数**：总箱数、总件数、封箱是否完整，外箱破损先拍外箱再开。
- **逐箱开验**：不要只抽一箱；至少做到“每箱开、每款点、异常拍”。
- **边验边录**：手机连续录像，从外箱面单、封口、开箱、清点、异常细节一镜到底，避免只拍局部。

## 3. 验货按固定清单走
建议每批货至少核对：
- **数量**：总件数、每款每色每码数量。
- **款号/颜色/尺码**：是否与订单一致，避免错款错码。
- **外观**：破损、污渍、线头、脱线、色差、印花瑕疵。
- **批次/吊牌/包装**：吊牌、条码、包装是否完整，是否混批。
- **功能/配件**：拉链、扣子、配件、赠品是否齐全。

## 4. 异常必须当场做“三件事”
1. **拍照/录像**：全景+面单+异常细节同框，最好放尺子或记号。
2. **在送货单上标注**：写清“少X件/破X件/错X款”，让送货人签字；对方不签就录像说明。
3. **当场发群/系统留痕**：把异常照片、件数、货号发到对接群，@对方确认，形成时间戳。

## 5. 收货单要能当证据
收货单至少包含：
- 到货时间、车牌/物流单号、总箱数总件数；
- 实收数量、异常数量及类型；
- 验货人、送货人签字；
- 异常照片编号或附件说明；
- 处理结论：拒收、换货、补发、折价、待确认。

## 6. 不同异常不同处理
- **外箱破损**：先拍外箱和面单，再开箱；内部完好可签收，内部破损让送货人签异常。
- **少件**：当场点总件数并让司机确认，别等卸完货再找。
- **错款错码**：单独放“异常区”，不要混入正品，拍照后当天反馈。
- **质量问题**：按比例抽检不够，纠纷多的品类建议全检或高比例检；发现批次问题整批隔离。
- **物流代收**：签收前尽量验外箱，签收后立即开箱录像，2小时内反馈。

## 7. 内部管理防扯皮
- **验货区和正品区分开**，异常货贴红标隔离。
- **谁验货谁签字**，每天汇总异常表。
- **每周复盘退货原因**：是收货没发现，还是发货本身问题，倒查责任。
- **对供应商建立到货合格率**：少件、破损、错款率高的供应商，调整抽检比例或结算方式。

一句话：**总件数当面点、开箱全程录、异常当场标、送货人签字、群里留痕、当天反馈**。做到这六步，退货纠纷会明显下降。
