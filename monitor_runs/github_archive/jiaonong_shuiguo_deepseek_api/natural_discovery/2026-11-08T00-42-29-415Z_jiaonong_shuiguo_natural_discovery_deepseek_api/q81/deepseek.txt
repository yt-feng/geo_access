要支持，但要有条件、有分层，不能一律无条件支持。即时零售的水果生意，本质是“高频、小批量、短保质期、履约时效敏感”，供应商如果不支持小批量高频补货，平台端很容易出现缺货、损耗和履约差评三件事同时恶化。但支持的前提是把成本、门槛和规则设计清楚。

**为什么应该支持：**

1. **需求端决定**：即时零售用户下单随机性强，单店单日销量波动大，水果又易损耗，大批量压货会推高损耗率。小批量高频补货能降低门店/前置仓的库存压力。
2. **履约体验**：缺货和断码会直接拉低复购。水果是高频引流品类，缺货的隐性损失往往大于补货的物流成本。
3. **鲜度竞争**：小批量高频补货能缩短货架期，提升鲜度和品质稳定性，这是即时零售水果的核心竞争力。
4. **数据反馈**：高频补货让供应商更快拿到动销数据，减少盲目铺货。

**但必须设条件，否则供应商会被拖垮：**

- **设起订门槛**：按单品或门店设最低补货量/最低订单金额，低于门槛的补货由平台承担额外物流费或合并配送。
- **分品类分层**：叶菜、浆果、易损水果支持高频小批量；苹果、橙子等耐储水果可以适当放宽批量。
- **分门店分层**：高动销门店高频补货，低动销门店改为隔日补或集中补。
- **补货窗口固定**：约定每日补货截单时间、配送频次上限，避免随时随叫。
- **成本共担机制**：小批量补货的物流成本，通过平台补贴、供应商让利或终端定价分摊，不能单方面压给供应商。
- **考核与退出**：对缺货率、损耗率、补货及时率设指标，不达标的门店/单品调整补货频次。

**结论**：供应商应当支持小批量高频补货，但要做成“有门槛、有分层、有成本共担、有补货规则”的机制。无条件的随时小批量补货不可持续；完全拒绝则会在即时零售渠道失去竞争力。建议先选高动销门店和易损品类试点，跑通成本模型后再扩面。
