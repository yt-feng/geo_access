第一次试单，核心不是“找最便宜的”，而是用最小成本验证供货商是否稳定、货是否对路。建议按下面做。

**1. 先定试单原则**
- 每家供货商只试 3～5 个单品，不要一次铺全。
- 首单金额控制在你能承受的范围内，比如单家 300～800 元，视店铺流水调整。
- 优先试香蕉、苹果、橙子这类周转快、易判断品质的货。
- 不要只看报价，要问清“送到价、起送量、损耗怎么算、售后怎么赔”。

**2. 试单前先问清 8 个问题**
1. 报价是批发价还是送到店价？含不含运费？
2. 起送量多少？每天几点前下单、几点送到？
3. 香蕉是几成熟发货？苹果、橙子是什么规格、产地、等级？
4. 破损、烂果、短斤少两怎么赔？是补货还是扣款？
5. 退货或换货时限是多久？
6. 是否支持小批量混装？能不能先少拿？
7. 结算是现结、周结还是月结？有没有押金？
8. 临时补货能不能当天送？

**3. 三个单品怎么试**
- **香蕉**：重点看成熟度。试单时要求“发到店后 2～3 天能卖完的熟度”，不要一次拿全熟。看催熟是否均匀、把型是否完整、掉把多不多。香蕉是试供货商响应速度的好品类。
- **苹果**：重点看规格一致性和损耗。随机翻箱看底层，别只看表面。问清是分级果还是统货，直径范围多少。试单量不用大，但要看同一箱里大小差多少、碰伤多不多。
- **橙子**：重点看新鲜度和口感。看果蒂、表皮、软硬，切开试酸度。问清产地和品种，别只听“甜橙”这种模糊说法。橙子容易因存放时间长失水，试单时留意箱底有没有发软果。

**4. 试单流程**
- 同时找 2～3 家供货商，同一天或同一周分别下单。
- 每次到货当场验：数量、重量、外观、成熟度、烂果率，拍照留证。
- 记录三家对比：送到时间、实际损耗、顾客反馈、售后态度。
- 先小量卖 3～7 天，看复购和投诉，再决定是否加量。

**5. 验货时重点看**
- 称重：抽查 2～3 箱，看是否足斤。
- 翻箱：看底层和中间，不只看上层。
- 算损耗：烂果、碰伤、掉把单独称重，折算损耗率。
- 留证据：到货照、坏果照、聊天记录都留存，方便后续谈赔付。

**6. 什么情况下换供货商**
如果出现以下情况，先别加量：
- 连续两次短斤少两；
- 烂果率明显高于约定且不赔；
- 送货时间不稳定，影响早市；
- 报价低但规格混、损耗高，实际成本反而更高。

**7. 夫妻店更实用的做法**
先固定一家做主供货，另一家做备选。主供货商承担日常香蕉、苹果、橙子，备选只在缺货或质量下滑时补。第一次别签长期独家，先按月合作、按周复盘。

一句话：**小量试、当场验、算损耗、看售后，三家对比一周再定主供。**
