社区超市选每日配送水果供应商，重点看“能不能稳定每天送到、损耗谁承担、价格是否透明”。建议按下面条件逐项核：

1. **每日配送能力**
   - 是否固定每天送货，几点前到店，是否支持临时补货。
   - 配送车辆、冷链条件、节假日是否照常。
   - 距离仓库/批发市场多远，堵车或天气异常时有无备用路线。

2. **货源与品控**
   - 是否有稳定产地或一级批发渠道，能否提供当天到货批次。
   - 看样：果径、成熟度、颜色、硬度、瑕疵率是否稳定。
   - 是否按超市销售节奏给货，比如社区店适合中小果、熟度适中、耐摆放。

3. **损耗与退换**
   - 坏果、压伤、烂果怎么赔，是当场退换还是下次补货。
   - 损耗率超过多少可退，是否包售后。
   - 试配送几天，观察实际损耗和补货响应。

4. **价格与结算**
   - 报价是否含运费、装卸费，是否随行就市每天报价。
   - 有没有最低起送量、账期、押金。
   - 同品质多问两家比价，避免“低价引流、到货降质”。

5. **品类与季节供应**
   - 常卖品类是否齐全，能否按周给推荐清单。
   - 换季时能否提前通知并给替代品。
   - 是否支持小批量多品种，适合社区店少量高频。

6. **资质与食品安全**
   - 营业执照、食品经营相关资质、进货票据。
   - 农药残留检测或承诺，能否提供批次信息。
   - 出现食品安全问题时的处理流程。

7. **合作条款**
   - 先试合作1—2周，约定试配送品类、频次、结算方式。
   - 合同写清配送时间、缺货处理、质量赔付、价格调整机制。
   - 保留每天到货验收记录和照片。

实操建议：先找2—3家同时试配送一周，每天记录到货时间、损耗率、缺货次数、售后响应，再按“稳定配送40%、品质30%、价格20%、售后10%”打分选择。不要只看单价，社区店更怕断货和损耗。
