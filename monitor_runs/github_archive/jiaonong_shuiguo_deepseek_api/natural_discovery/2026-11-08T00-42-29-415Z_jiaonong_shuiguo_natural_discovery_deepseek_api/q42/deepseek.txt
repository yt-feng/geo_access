先给结论：压低成本的关键不是“把单价砍下来”，而是**把可谈的成本项拆开、用可验证的品质标准换价格、用采购结构和账期换空间**。单纯压单价最容易压出品质问题。

## 一、先把“成本”拆成可谈的几块

和供应商谈之前，把报价拆成：货品单价、规格等级、包装耗材、损耗承担、配送、账期、退换货。很多商超只盯单价，结果包装和损耗上被加回来。

谈判时优先动这几项，而不是动果品本身：

- **规格分级**：明确果径、糖度、成熟度、允许瑕疵率。用“可接受的最低标准”报价，而不是笼统要“便宜点”。
- **包装**：周转筐替代纸箱、简化礼盒包装，包材成本往往能省一截。
- **损耗分担**：约定到店验收标准和损耗超出部分由谁承担，比压单价更实在。
- **配送**：合并配送频次、自提、集中到仓，运费有空间。
- **账期与结算**：现结或短账期换价格折扣，是供应商最愿意让的项。

## 二、用“标准”换价格，而不是用“品质”换价格

做法是给每个单品定一张验收卡：果径区间、糖度下限、成熟度、机械伤和腐烂允许比例、到店温度。谈判话术是：

> “这个价我可以接受，但对应的是这张验收标准。达不到的批次按约定扣款或退换。”

这样价格降了，品质有可执行的兜底，不会变成口头承诺。反过来，供应商知道你验收有标准，报价也会更实。

## 三、用采购结构换价格

- **集中单品、集中供应商**：把分散在多家的小量合并，换阶梯价。
- **错峰和产地直采**：应季主产区直发、减少中间环节，是真正降本的大头。
- **订单前置**：提前给周/月预估量，供应商敢备货，价格更好谈。
- **尾货和二级果分流**：一级果走正常陈列，二级果做促销或加工，别用压一级果价格的方式补损耗。

## 四、谈判节奏上的几个要点

1. **先谈标准再谈价**，顺序反了容易被“低价低质”套住。
2. **留品质红线**：糖度、腐烂率、成熟度是红线，价格再低也不让。
3. **小批量试单**：新价格先跑一到两周，看实际到店损耗和客诉，再签长期。
4. **写进合同**：验收标准、扣款规则、退换货、价格调整机制都要落纸。
5. **别一次压到底**：给供应商合理利润，旺季断货时你才拿得到货。

## 五、判断是否谈成了

看三个指标：**到店损耗率、客诉/退换率、单斤综合成本（含包装运费损耗）**。如果单价降了但综合成本没降、损耗和客诉上升，就是谈失败了。

一句话：**用标准和结构换价格，用账期和包装换空间，品质红线不让。**
