能，但要看你的采购量、账期和跟供应商的关系，通常不是“周末促销就自动给”。可以按下面判断和争取：

**1. 价格支持**
- **大概率能给**：你是稳定进货的老客户、周末促销有明确销量预估、单次订货量明显高于平时。
- **较难给**：临时小批量、新供应商、只想拿特价但没量、账期还长。
- **常见形式**：单品直降、阶梯返利、买赠（进10箱送1箱）、临期/尾货特价、促销期间差价补偿。直接要求“周末特价”不如给供应商一个**可核算的订货计划**，比如“周六日预计卖X箱，我一次性订X箱，能否给到每箱减Y元或搭赠物料”。

**2. 物料支持**
- 供应商通常更愿意给**陈列和宣传物料**，因为成本低、能带动其品牌销量。
- 可争取：堆头/端架陈列架、价签、海报、吊旗、试吃盒、购物袋、遮阳棚、促销员围裙等。
- 注意：物料常绑定品牌或单品，未必能覆盖你全店促销；定制类物料一般要提前几天到一周申请。

**3. 谈判要点**
- 先说清促销时间、主推单品、预计订货量和售价，让供应商能算账。
- 优先谈**单品支持**，不要一上来要全场折扣。
- 把价格支持和物料支持分开谈，价格谈不动时可换成搭赠、返利或物料。
- 确认支持是否有时限、是否要求陈列位置、是否影响后续退换货。
- 对生鲜水果要特别确认：促销价是否含损耗、是否可退换、配送频次和到货时间。

**4. 现实预期**
周末短促，供应商一般给的是**有限支持**：某个单品每箱减几元、送几个陈列箱/价签，或者搭赠少量货。想要较大力度，通常要配合更大的订货量、主推其品牌、或者把促销做成连续几周。

**可执行做法**：今天就列出周末主推的3—5个单品，给每个供应商发明确需求——“周六日主推，预计订X箱，能否给每箱减Y元或搭赠陈列物料，周五前到货”，让对方给方案，再比较哪家支持力度大。
