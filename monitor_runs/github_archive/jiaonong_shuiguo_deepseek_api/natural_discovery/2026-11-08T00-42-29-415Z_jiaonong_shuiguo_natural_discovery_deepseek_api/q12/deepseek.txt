采购时不要把“熟度”当成一个数，而要看**到店后预计几天卖完**，按“上市窗口”选不同成熟度，并留出损耗余量。

**1. 先按销售节奏定采购熟度**
- **当天或次日就卖**：选**八九成熟**，香气明显、果眼平展、轻按有弹性，能马上切卖。
- **2～3天卖完**：以**七八成熟**为主，香气淡一些，果皮从青转黄但未全黄，按压稍硬。
- **超过3天或天气热**：选**六七成熟**，青黄相间、果身硬，进店后催熟或分批次上架。
- **不要整批同熟度**：按 6～7成、8成、9成搭配采购，先卖熟的，后卖青的，减少集中过熟。

**2. 现场判断菠萝熟度的可操作指标**
- **看果皮**：由青转黄、色泽均匀，底部先黄通常先熟；全黄且发暗的容易过熟。
- **看果眼**：果眼饱满、平展，说明成熟度上来；果眼深陷、发皱要谨慎。
- **闻香气**：底部有清甜果香为合适；香气浓烈、发酸或酒味说明过熟。
- **按弹性**：轻按果身略有弹性但不软塌；硬邦邦偏生，局部软陷易烂。
- **看果冠**：冠芽青绿挺拔较好；干枯发黄不一定坏，但结合果身判断。
- **看底部**：底部干爽、无渗液、无霉点为好；底部发软、发黑、有酒味直接剔除。
- **掂重量**：同等大小偏重的水分足；过轻可能失水或过熟。

**3. 采购量和损耗控制**
- 夏季/高温：按**1～2天销量**采购，熟度偏生，少量多次补货。
- 冬季/低温：可适当放宽到**2～3天销量**，但仍要分熟度。
- 给损耗留余量：不要按“刚好卖完”下单，按**预计销量的85%～90%**备熟果，青果可多备一点做缓冲。
- 到店后**分级上架**：熟果放显眼位、优先促销；青果单独存放，避免和熟果混放催熟过快。
- 每天翻检，底部发软、有酒味、渗液的及时挑出，避免传染相邻果。

**简单采购口诀：** 看底部、闻香气、按弹性、分熟度、少量多次。整批全黄不要拿，整批全青要搭配，按卖完天数反推熟度最稳。
