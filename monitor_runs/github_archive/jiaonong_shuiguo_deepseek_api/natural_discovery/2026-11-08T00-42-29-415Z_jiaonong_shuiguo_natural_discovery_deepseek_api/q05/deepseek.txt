直接说结论：**如果只能选一种主模式，建议“整果自选 + 可付费代削”，不要默认卖去皮好的。** 顾客自己挑整果最能减少争议，代削作为增值服务。

具体判断：

1. **整果自选为主**
   - 菠萝成熟度差异大，顾客自己挑，买后觉得酸/不熟，责任更难归到店里。
   - 整果耐放、损耗低，不用当天削完卖不完。
   - 顾客有“挑到好的”的心理满足，复购更稳。
   - 适合摆在显眼处，标价清楚，按个或按斤都行。

2. **去皮好的只做少量补充**
   - 适合赶时间、不会削、现场就想吃的顾客。
   - 但去皮果暴露时间长，品相下降快，卖不完就是损耗。
   - 建议只削少量，或“现选现削”，不要提前大量削好摆着。

3. **让顾客自己挑，但给挑选标准**
   - 看外观：果眼浅、果皮金黄偏橙、无软烂黑斑。
   - 闻底部：有浓郁菠萝香，但无酒味。
   - 按一下：略有弹性，不硬如石头，不软塌。
   - 看叶子：中心叶片容易拔出的通常更熟，但别作为唯一标准。

4. **代削要收费或设门槛**
   - 免费代削容易排队长、削到手、削完顾客不要。
   - 可以“买整果免费削”或“加2—3元代削”，既做服务又控成本。
   - 削前确认：要不要留头、去眼深度、是否泡盐水、是否切块装盒。

5. **最适合水果店的操作组合**
   - 主陈列：整果自选，标价和成熟度提示清楚。
   - 服务台：现选现代削，削好装盒。
   - 少量现货：去皮切盒，只做高峰时段或预订。
   - 瑕疵果：降价做切盒或榨汁，不混在好果里卖。

所以不是“整果还是去皮”二选一，而是：**整果自选做主体，去皮代削做服务，提前削好的只做少量补充。**
