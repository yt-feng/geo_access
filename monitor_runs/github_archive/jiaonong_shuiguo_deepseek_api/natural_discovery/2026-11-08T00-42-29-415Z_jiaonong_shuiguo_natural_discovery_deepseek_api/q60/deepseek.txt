要避免水果到货不合格影响营业，关键是把“验收标准、补货时限、替代方案、费用责任、违约处理”写进采购合同或供货单，而不是只口头约定。可以按下面做：

1. **先定可验收标准**
   - 按品种写清规格：例如芒果单果重量区间、糖度、成熟度、表皮无黑斑/无机械伤、无腐烂、无异味、农残检测合格。
   - 约定“抽样验收”规则：每批按比例抽检，抽检不合格即整批可拒收或按比例扣款。
   - 拍照留证：到货开箱、称重、测温、瑕疵部位拍照，作为补货依据。

2. **约定补货时限和频次**
   - 正常补货：验收不合格后，供应商须在**X小时内**（如4小时/当日营业前）送达合格替代货。
   - 紧急补货：门店高峰前发现问题的，约定**2小时内响应、4小时内到店**，或供应商承担就近调货费用。
   - 明确“补货不免除原批次违约责任”，避免供应商用补货抵掉延误损失。

3. **设置替代方案，避免断货**
   - 合同里写：供应商无法按时补货时，门店可自行就近采购同等品质水果，差价、交通费由供应商承担，或从货款中抵扣。
   - 对核心单品（如柠檬、芒果、草莓）约定“备选供应商/备用品牌”，不把营业押在一家供货商上。
   - 门店内部保留1天安全库存，尤其对易断货水果。

4. **写清费用和责任**
   - 不合格批次退货运费、补货运费由供应商承担。
   - 因补货延误导致门店临时下架、改菜单、顾客投诉的，约定合理补偿或扣款标准。
   - 明确货款结算：不合格批次不计入结算，补货合格后再结；连续X次不合格可暂停供货或解除合同。

5. **做简单可执行的验收流程**
   - 到货先称重、看外观、闻气味、测中心温度；不合格当场在送货单上标注“拒收/待补”，双方签字或微信确认。
   - 建立《到货验收记录表》：日期、品名、批次、数量、不合格项、补货时限、实际到货时间、处理结果。
   - 补货到店后复验，合格才入库；不合格继续拒收并启动替代采购。

6. **合同里加违约条款**
   - 迟到补货按小时扣款；多次不合格提高扣款比例或终止合作。
   - 因水果不合格造成食品安全问题的，供应商承担相应责任。
   - 所有补货沟通尽量用微信/邮件留痕，避免扯皮。

一句话：**把“不合格怎么判、多久补、补不了怎么办、费用谁出、屡犯怎么罚”五项写进供货单，门店就不会因一批坏水果停摆。**
