超市和水果供应商的账期没有统一标准，但按行业常见情况，可参考这个范围：

- **本地/产地直采、叶菜和易损耗水果：7～15天**，甚至现结或周结。损耗高、保鲜期短，供应商通常不愿给长账期。
- **常规水果批发/经销商供货：15～30天**。这是超市与水果供应商较常见的区间。
- **大型连锁超市、强势渠道、进口水果或耐储水果：30～60天**。账期更长，但通常伴随更严格的验收、损耗扣款和返利条款。
- **超过60天**在水果品类里算偏长，中小供应商往往会把资金成本折算进报价，或要求缩短账期。

实操建议：

1. **先看品类**：叶菜、浆果、桃李等易损耗品，账期宜短；苹果、梨、柑橘、进口耐储水果可适当拉长。
2. **新供应商首期建议15～30天**，稳定合作后再按采购量谈阶梯账期。
3. **账期不是唯一条件**：要同时确认对账日、付款日、验收扣损规则、退货和滞销处理，否则“30天账期”可能实际拖到45天以上。
4. **谈判时可给供应商选择**：例如“现结/7天结算享较低单价，30天账期对应标准价”，比单纯压账期更容易达成。

一句话：**水果供应商常见账期是15～30天；易损耗品偏7～15天，大型连锁或耐储品可到30～60天。**
