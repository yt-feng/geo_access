学校食堂选水果供应商，建议按“准入—比价—试供—考核”四步走，重点抓资质、稳定性、验收和结算风险。

**一、先定供应商类型**
- **优先选本地一级批发商或产地合作社直供**：香蕉、苹果、橙子都是大宗常见果，直供少一道加价，新鲜度和补货速度也更好。
- **备选大型连锁配送商**：适合食堂品类多、要求统一开票和配送的，但价格通常略高。
- **不建议只选一家**：至少“1家主供+1家备供”，防止断供或临时涨价。

**二、准入资质要卡住**
要求供应商提供：
1. 营业执照、食品经营许可证（或食用农产品销售相关资质）；
2. 供货来源证明：产地证明、批发市场进货凭证、检测报告或承诺达标合格证；
3. 配送车辆和仓储条件说明，水果需有冷藏或通风保鲜条件；
4. 开票能力与对公账户；
5. 食品安全责任承诺书，明确农残超标、霉变、以次充好的退换和赔偿责任。

**三、比价不要只看单价**
建议用“到校含税单价+品质合格率+配送响应”综合比：
- 让供应商按**固定规格**报价，例如香蕉按每箱净重、苹果按果径等级、橙子按单果大小和糖度区间；
- 报价包含配送、装卸、损耗和税费，避免后期加价；
- 约定价格调整机制：常见水果可每周或每两周询价一次，参考当地批发市场均价，涨幅超过约定比例需书面说明；
- 试供1—2周，重点看到货合格率、缺斤少两、补货速度。

**四、验收标准写进合同**
- **香蕉**：成熟度适中，无黑腐、无机械伤，到校后能存放2—3天；
- **苹果**：果形完整、无明显碰伤和腐烂，规格均匀；
- **橙子**：无霉变、无干瘪，大小相对一致；
- 每批抽检，记录重量、数量、合格率；连续两次不合格可暂停供货或扣款；
- 明确退换货时限，例如到货2小时内可要求退换。

**五、合同和结算控制风险**
- 合同写清品名、规格、单价、数量、配送时间、验收标准、违约责任；
- 账期不宜过长，但可预留5%—10%质量保证金；
- 要求对公转账和正规发票，避免个人账户收款；
- 建立供应商年度考核：质量合格率、迟到率、价格合理性、服务响应，末位淘汰。

**最简可执行方案**：先找本地批发市场2—3家有资质的商户和1家合作社，统一规格报价，试供两周；按合格率和到校价打分，选1家主供、1家备供，签3—6个月合同，每周询价、每批验收、月度考核。
