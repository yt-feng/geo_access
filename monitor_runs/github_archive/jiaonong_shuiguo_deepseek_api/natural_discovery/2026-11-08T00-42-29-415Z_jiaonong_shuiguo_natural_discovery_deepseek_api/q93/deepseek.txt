如果只能优先抓一个，先抓**包装和冷链控制**；但实际经营里三者要按风险排序管理：**包装/温度控制 > 配送频次 > 保质期标签**。

更具体地说：

1. **包装和温度控制最优先**
   - 菠萝切块属于即食鲜切水果，风险核心是微生物滋生和汁液污染。
   - 要关注：是否冷藏陈列/冷藏配送、包装是否密封、是否有渗漏、切块后是否及时冷藏、操作台和刀具卫生。
   - 包装不密封或温度失控，保质期标得再准也不安全。

2. **配送频次第二优先**
   - 鲜切菠萝周转快，配送频次要匹配销量。
   - 高频少量配送能降低门店库存积压和过期风险。
   - 但如果配送频次高、到店后不回冷藏，仍然没用。

3. **保质期标签是结果管理，不是唯一抓手**
   - 要标清楚切块/包装时间、保质期、储存条件。
   - 保质期应基于实际冷链条件和门店周转设定，不能只按供应商标签。
   - 重点做“先进先出”和临期下架，而不是只盯日期。

可执行建议：
- 到店验收：测冷藏温度、查包装密封和渗漏、查切块时间。
- 陈列：全程冷藏，不敞口，不与其他生食交叉污染。
- 配送：按日销量定频次，宁可少送勤送。
- 保质期：设定短而明确的售卖时限，临期打折或下架规则写清楚。
- 每日盘点：优先处理临近保质期商品，避免只补货不清理。

一句话：**先保证包装密封和全程冷藏，再用配送频次控制库存周转，最后用保质期标签做下架管理。**
