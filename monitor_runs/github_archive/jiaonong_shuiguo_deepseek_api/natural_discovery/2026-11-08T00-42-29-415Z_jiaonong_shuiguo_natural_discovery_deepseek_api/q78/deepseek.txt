香蕉和菠萝做社区团购，售后控制的核心不是“坏了赔”，而是**把损耗前置到选品、到货、分拣、交付四个环节**，让售后率从“事后解释”变成“事前可管理”。下面按可执行动作讲。

## 一、香蕉：控制点在“到货成熟度”和“交付节奏”

香蕉是呼吸跃变型水果，团购最大的坑是**到货太熟、当天没取完，第二天集体发黑**。

**可执行做法：**
1. **订货只订7–8成熟**，到货青硬、能放2–3天。别贪“到货就能吃”，那是零售店逻辑，团购交付有延迟。
2. **按提货日倒推催熟**：夏天到货后常温1–2天出黄，冬天要催熟箱/乙烯利规范催熟。提货日当天早上检查，**有黑斑、软塌的单独挑出，不进提货点**。
3. **分拣标准写死**：单根有面积大于指甲盖的黑斑、果柄发黑、按压软陷的，一律走“瑕疵品内部处理”，不发给团长。
4. **交付话术前置**：团购页和取货通知里明确“香蕉为7–8成熟发货，常温放置1–2天转黄，请勿冷藏”。冷藏是香蕉售后第一大原因，必须在取货时口头提醒。
5. **售后规则**：香蕉签收后24小时内、**未切开且整根腐坏**可赔；局部黑斑、表皮擦伤不赔。提前写进团购详情，减少扯皮。

## 二、菠萝：控制点在“品种选择”和“去皮交付”

菠萝售后主要是三类：**黑心/水心病、酸涩不熟、去皮后出水变质**。

**可执行做法：**
1. **优先选耐储品种**：凤梨类（金钻等）比传统菠萝售后低，黑心率低、无需泡盐水，适合团购。普通菠萝要明确“需盐水浸泡”，否则口感投诉多。
2. **到货抽检切果**：每批随机切3–5个，看中心是否透明/褐变（黑心）、果肉是否水渍状。**抽检不合格整批退回供应商**，这是唯一能压住批量售后的动作。
3. **不做提前去皮**：菠萝去皮后2小时就开始出水、发酸。如果做鲜切，必须**提货当天现切、冷藏、4小时内交付**，且单独标注“鲜切当日食用”。整果团购则要求团长**不当场削皮**。
4. **成熟度分级**：到货按压微弹、底部有香气为可交付；硬如石头的单独放1–2天再发。**底部发软、有酒味、渗汁的直接剔除**。
5. **售后规则**：整果签收后**切开发现黑心/水心，凭切面照片全额赔**；因个人存放导致的发酸不赔。鲜切类签收后2小时内变质可赔。

## 三、通用机制：把售后率变成可考核指标

1. **设售后红线**：香蕉、菠萝单品类售后率超过**3%**就停团复盘；超过**5%**换供应商或改规格。
2. **团长端培训**：取货点**不堆叠、不闷袋、不冷藏**；香蕉挂放或平铺，菠萝通风放置。团长现场提醒比售后解释便宜得多。
3. **拍照留证流程**：团长到货拍整批照片、分拣剔除拍瑕疵品照片，售后凭“切面/腐坏照片+订单号”处理，**不接受口头描述**。
4. **供应商条款**：合同写明“黑心率/成熟度不达标整批退换”，把损耗压力往上游传，而不是自己全赔。
5. **小批量高频次**：高损耗品**宁可少订、次日补团**，不要一次压大批量。香蕉菠萝的损耗曲线在到货后48小时陡增，库存周转比毛利率更重要。

## 四、一句话判断标准

- 香蕉：**到货能放2天、提货当天不软塌**，售后就可控。
- 菠萝：**整果不提前削、切开黑心全赔、抽检不合格整批退**，售后就可控。
- 两者共同：**售后规则写在购买前，瑕疵品在交付前剔除，别让用户替你分拣。**

如果要做鲜切水果团，香蕉和菠萝都不适合作为鲜切主力，鲜切优先选耐氧化的品类，高损耗品以整果团为主更稳。
