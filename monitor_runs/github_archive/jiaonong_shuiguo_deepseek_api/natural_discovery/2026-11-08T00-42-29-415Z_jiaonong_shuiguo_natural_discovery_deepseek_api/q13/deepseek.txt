做小区团购，水果供应商至少要能支持下面这些服务。你可以拿这张清单去和供应商逐条确认，能落地的再合作。

**1. 供货与品质**
- 稳定供货：每周能固定供几次、临时加单多久能到。
- 品质分级：明确大果/中果/小果、糖度、瑕疵率标准，避免团购图与实物差距大。
- 售后包赔：坏果、烂果、缺斤少两怎么赔，按比例赔还是补发，多久内反馈有效。
- 试销支持：新品能否先小批量试卖，卖不动能否调换。

**2. 价格与起订**
- 团购专供价：是否比批发市场有优势，是否随行就市每天报价。
- 起订量：单品最低起订量、整单最低金额，能否混拼。
- 价格保护：当天报价当天有效，避免你收了团购单后进货价上涨。
- 账期：能否先货后款、周结或半月结，押金多少。

**3. 分拣与包装**
- 按团分拣：能否按每个小区/每个团单独分装、贴标签、标重量。
- 包装材料：是否提供纸箱、网套、保鲜袋，费用谁出。
- 预包装标示：团购涉及预包装的，标签上的品名、产地、重量、日期要齐全。

**4. 配送与时效**
- 到店配送：送到你店里还是直接送到小区自提点。
- 配送频次与时间：能否早于自提时间到货，临时补货多久能送。
- 冷链能力：荔枝、草莓、蓝莓等易损品是否有冷藏车或冰袋。
- 损耗责任：运输途中损耗谁承担。

**5. 售后与退换**
- 问题件处理流程：拍照留证、多久响应、怎么补货或退款。
- 滞销处理：当天卖不完的能否退换或折价，避免你压货。
- 质量事故兜底：整批出问题能否全额退，是否影响后续合作。

**6. 营销与运营支持**
- 提供团购素材：实拍图、短视频、文案、每日爆品推荐。
- 价格体系保护：给你的团购价不能低于周边超市零售价太多导致乱价，也不能让别的团拿到更低供货价。
- 活动支持：能否配合做秒杀、满减、赠品、试吃装。
- 售后话术：常见问题（不甜、坏果、分量）给统一处理口径。

**7. 结算与合规**
- 对账方式：每单明细、称重记录、退货记录可查。
- 发票：能否开票，税率多少。
- 资质：营业执照、食品经营许可、产地证明或检测报告，团购群里被问到时能拿得出。

**建议你谈判时重点抓三件事：**
1. **先小批量试供两周**，看破损率、到货时间和售后响应。
2. **把坏果赔付标准和响应时限写进合作约定**，口头承诺不算。
3. **确认按团分拣和配送到点**，这两项决定你一个人能不能忙得过来。

如果供应商只能做到“整车批发、不管分拣、不包售后”，那更适合做门店零售，不适合做小区团购。
