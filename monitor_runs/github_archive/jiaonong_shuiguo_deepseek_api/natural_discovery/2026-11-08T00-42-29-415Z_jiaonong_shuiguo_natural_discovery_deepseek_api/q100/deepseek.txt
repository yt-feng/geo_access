要避免香蕉熟过头浪费，核心是把“采购量、到货成熟度、存放方式、加工去向”四件事管住。可执行做法如下：

1. **按用量采购，不按库存图便宜**
   - 统计近2周香蕉实际消耗量，按“日均用量×到货周期天数×0.8～0.9”下单，留安全库存但不过量。
   - 临近周末、考试周、假期前减少采购量。
   - 与供应商约定分2～3次小批量到货，而不是一次大批量。

2. **明确到货成熟度标准**
   - 采购单写清：到货以“青黄、果指硬、无明显黑斑”为主，成熟度约7成；不要接收全黄、有酒味、果柄发黑的香蕉。
   - 验收时抽检：果皮颜色、硬度、有无机械伤和黑斑。熟度高的拒收或折价并当天优先使用。

3. **分区存放，先熟先出**
   - 青香蕉和熟香蕉分开存放，避免乙烯集中催熟。
   - 香蕉不宜冷藏，放在阴凉通风处；夏天避免阳光直射和靠近蒸箱、烤箱、热源。
   - 成串悬挂或单根分开可减缓压伤和集中成熟；已成熟的单根分离存放。
   - 张贴“先进先出”标识，每天早晚各检查一次，把最熟的移到“优先使用区”。

4. **把熟香蕉转为加工用途**
   - 出现少量黑斑但果肉正常时，优先用于香蕉牛奶、香蕉粥、香蕉饼、烘焙、水果沙拉等。
   - 食堂可设“今日熟蕉优先”窗口或员工餐消化。
   - 明确报废标准：果肉发黑、有酒味/酸味、流汁、霉变则不得食用，按餐厨垃圾处理。

5. **建立日跟踪和预警**
   - 每天记录到货量、消耗量、剩余量和熟度。
   - 设置阈值：剩余可售天数不足1天时停止采购；出现大量黑斑时启动加工菜单。
   - 每周复盘一次，调整下周采购量。

6. **供应商协同**
   - 与供应商约定可退换或调换的成熟度问题；长期合作可要求按学校用量分批配送。
   - 若供应商只能大批量供货，可联合附近学校或食堂集中采购、分装配送。

最有效的组合是：**小批量、控熟度、通风分存、先进先出、熟蕉转加工**。只要把到货成熟度和每日用量盯住，浪费会明显下降。
