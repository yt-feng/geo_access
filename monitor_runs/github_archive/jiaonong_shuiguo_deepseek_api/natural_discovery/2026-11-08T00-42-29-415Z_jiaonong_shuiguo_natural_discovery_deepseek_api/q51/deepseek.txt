要固定，但不能只固定“一个产地”，建议固定“标准+主供基地+备用基地+批次验收”。水果风味波动是茶饮店最常见的品质风险之一，完全不管会让同一款饮品今天偏酸、明天偏淡，顾客复购和口碑都会受影响。

可执行建议：

1. **固定品种和规格，比固定产地更重要**
   - 明确品种、成熟度、糖酸比、单果规格、采摘后存放时间。
   - 例如柠檬要区分黄柠/青柠、酸度范围、出汁率；芒果要规定品种和成熟度区间。
   - 只固定“某产地”但不管品种和成熟度，风味仍会波动。

2. **主产地/主供应商固定，但保留备用**
   - 选1家主供基地或供应商，锁定主要批次来源，保证风味基线稳定。
   - 同时准备1—2家备用供应，避免减产、雨季、病虫害时被迫临时换货。
   - 不建议长期只依赖单一产地，供应中断风险高。

3. **按批次验收，建立风味底线**
   - 每批到货做糖度、酸度、成熟度、外观和出汁率抽检。
   - 设定可接受区间，超区间就退货、降级使用或调整配方，不能“到了就用”。
   - 对门店可做简单杯测：固定糖量、固定茶底，比较酸甜和香气是否偏离标准。

4. **固定“可用批次”而不是死守“同一批次”**
   - 同一批次内风味最稳定，但水果批次不可能长期不变。
   - 正确做法是：固定供应商和品种，批次间用验收标准拉齐；必要时通过糖度/酸度微调配方补偿。
   - 如果某款产品极度依赖水果原味，比如鲜果茶，优先固定主供基地和采摘成熟度。

5. **合同里写清楚**
   - 品种、规格、成熟度、糖酸度范围、农残检测、到货温度、退换货标准。
   - 要求供应商提前告知换园、换批次、换品种，避免门店被动接受风味变化。

结论：**要固定产地和供应批次作为稳定风味的手段，但更关键的是固定品种、成熟度和验收标准；采用“主供固定+备用基地+批次检测+配方微调”的组合，比单纯固定一个产地更稳、更抗风险。**
