先说结论：**大多数生鲜电商起步阶段，切配菠萝（尤其是小份鲜切/即食）最适合线上卖；整果适合做引流款；冷冻菠萝更适合作为补充品类或面向B端/烘焙饮品场景，不建议作为主力线上单品。**

判断逻辑和建议如下：

1. **切配鲜切菠萝：最适合线上主推**
   - 优势：即食、省处理、客单价和毛利更容易做高；适合家庭小份购买，契合线上“便利性”需求。
   - 风险：保质期短、冷链要求高、损耗和食品安全压力大；切配后品质波动明显。
   - 建议：做小规格（250g/500g）、明确“冷藏即食/尽快食用”、优先同城或冷链覆盖好的区域；SKU不宜过多，先测试复购和损耗率。

2. **整果菠萝：适合引流和凑单，不适合作为唯一主力**
   - 优势：耐运输、损耗低、成本透明、适合做低价引流和家庭囤货。
   - 风险：线上用户看不到成熟度，易出现“收到不熟/过熟”的差评；客单价低，履约成本占比高。
   - 建议：做引流款或组合装，标注品种、成熟度、去皮难度和食用建议；控制大果重果的运费敏感度。

3. **冷冻菠萝：适合补充场景，不建议主力**
   - 优势：保质期长、损耗低、适合烘焙、饮品、冰沙等场景；履约相对稳定。
   - 风险：家庭直接食用心智弱，解冻口感不如鲜切；需要冷冻仓储和冷链，普通生鲜电商的冷冻履约体系未必匹配。
   - 建议：作为补充SKU，面向B端餐饮/饮品店或“冷冻水果+烘焙”组合销售；若冷链能力不足，不要重投入。

**可执行组合建议：**
- 主推：小份鲜切菠萝（即食），测试2-3个规格。
- 引流：整果菠萝，做低价尝鲜或组合装。
- 补充：冷冻菠萝，先小批量测试B端或特定场景。
- 关键指标：损耗率、冷链履约成本、差评原因（不熟/变质/出水）、复购率。鲜切菠萝若损耗和冷链成本压不住，就退回整果为主、鲜切仅同城。

**一句话：线上主力选鲜切，整果做流量，冷冻做补充；先看你的冷链能力和客群场景，不要三个品类同时重投。**
