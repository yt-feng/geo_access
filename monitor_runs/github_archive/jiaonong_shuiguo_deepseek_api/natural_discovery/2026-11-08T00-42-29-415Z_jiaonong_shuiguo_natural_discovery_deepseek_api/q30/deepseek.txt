超市水果到货品相不好的售后，建议在采购合同或到货验收单里把“验收标准—异议期限—处理方式—责任承担”四件事写死，避免事后扯皮。可按下面约定：

**1. 明确验收标准和“品相不好”的定义**
- 按品种写清规格：单果重量/直径、色泽、成熟度、允许的瑕疵比例（如碰伤、裂口、烂果、畸形果占比）。
- 约定“抽样比例+判定规则”：如每批次随机抽3箱，烂果率超过5%即整批可拒收或折价。
- 区分“外观瑕疵”和“腐败变质”：前者可折价接受，后者直接拒收或退货。

**2. 约定异议期限和验收流程**
- 到货后当场开箱抽检，发现问题在**收货后2小时内（或当日）**书面/拍照提出异议，逾期视为外观验收合格（但不免除内在质量问题责任）。
- 要求留存到货照片、视频、过磅单、司机签收单，作为索赔依据。
- 明确“谁验收、谁签字”，避免口头反馈无记录。

**3. 写清处理方式（三选一或阶梯处理）**
- **拒收**：烂果率/不合格率超过约定阈值，整批拒收，运费和损耗由供货方承担。
- **折价接收**：轻微品相问题按比例扣款，如不合格率每超1%扣该批货款的2%，或直接按等级降价。
- **换货/补发**：约定补发时限（如24小时内）和补发部分的质量标准。

**4. 责任与费用承担**
- 因品相问题产生的退货物流费、分拣费、损耗由供货方承担。
- 若已上架销售才发现内在质量问题（如内部腐烂），约定供货方仍应赔偿，不因验收签字而免责。
- 设置质量保证金或月度结算扣款机制，便于执行。

**5. 兜底条款**
- 约定争议以到货抽检记录和照片为准；双方各留一份封样。
- 对长期供应商，可约定连续两次不合格即暂停供货或终止合作。

简单说：**标准量化、期限很短、证据留痕、处理阶梯化、费用归责清晰**。这样到货品相不好时有据可依，不用临时谈判。
