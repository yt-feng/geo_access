这件事没有统一的法定“坏果率赔付线”，关键看合同约定和验收标准。实务上可以这样定：

1. **合同里最好明确“允许损耗率”**  
   常见做法是把“允许坏果率”写进验收条款，例如：
   - 坏果率 ≤ 3%：正常接收，不扣款；
   - 3%～5%：按超出部分扣款或折价；
   - ＞5%：买方有权拒收、要求换货或索赔；
   - ＞10%：可视为根本违约，解除合同并索赔。
   
   这些数字不是法定标准，只是采购谈判中较常见的区间；易腐水果、长途运输、不同品种可上下调整。

2. **“坏果率超过多少应该赔付”要分两层看**  
   - **有没有约定**：有约定按约定。合同写了超过5%赔付，就按5%。
   - **没有约定**：不能直接说“超过X%就必须赔”，要依据《民法典》合同编，看是否构成质量不符合约定、是否造成损失，按实际损失主张折价、换货、退货或赔偿。此时举证很重要。

3. **建议把赔付计算方式写清楚**  
   不要只写“超过5%赔付”，还要写：
   - 坏果率按数量还是重量计算；
   - 抽样比例、抽样方法、验收时限；
   - 超出部分按“超出比例×对应货款”扣款，还是整批折价；
   - 拍照、视频、第三方检测等举证方式；
   - 换货、退货、运费和损耗由谁承担。

4. **可执行建议**  
   如果你是采购方，合同里可写：  
   “坏果率≤3%正常验收；3%＜坏果率≤5%，按超出3%部分对应货款扣减；坏果率＞5%，买方有权拒收并要求换货，卖方承担运费；坏果率＞10%，买方有权解除合同并要求赔偿实际损失。”  
   如果你是供货方，则争取把允许损耗率设高一些，并限定验收时限和抽样方法，避免收货后很久再主张坏果。

简言之：**合同有约定按约定；没有约定就没有固定比例，建议在3%～5%区间谈判并写清计算和验收规则。**
