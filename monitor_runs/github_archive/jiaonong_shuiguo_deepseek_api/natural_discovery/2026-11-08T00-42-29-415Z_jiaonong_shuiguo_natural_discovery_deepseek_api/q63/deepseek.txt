判断哪个规格更容易出货，可以按“先看数据、再做小测、最后定主推”的顺序来，不要只凭感觉。

**1. 先看现有数据**
- 看最近7~14天各规格的**日均出货量**：哪个规格卖得最多、最稳定。
- 看**出货频次**：是每天有人拿，还是偶尔走一批。频次高通常比单次量大更好。
- 看**退换/损耗**：菠萝易损耗，规格太大卖不完、太小被嫌，都会影响实际出货。
- 看**客户结构**：水果店、餐饮、摊贩、社区团购对规格偏好不同。摊贩和社区团购通常偏好中小果、价格低；水果店和餐饮可能偏好中大果、品相稳定。

**2. 做小规模对比测试**
- 选2~3个候选规格，各拿少量货，同一时间段、同一客户群里报价。
- 记录：询价人数、成交单数、成交速度、客户复购意愿。
- 测试期不要太长，3~5天即可，避免菠萝变质影响判断。

**3. 看几个关键信号**
更容易出货的规格通常具备：
- 报价后**客户不犹豫**，很快下单；
- **复购或转介绍**多；
- **单箱/单件利润虽不高，但周转快**；
- **损耗低**，不需要频繁降价处理；
- 和周边批发市场主流规格接近，客户比价时不吃亏。

**4. 定主推和搭配**
- 把“出货最快、周转最稳”的规格定为主推，保证库存；
- 用另一个规格做**价格带补充**，比如主推中果，搭配小果走量、大果走精品客户；
- 每周复盘一次出货量和损耗，动态调整，不要一次定死。

**简单判断标准：** 同等陈列和报价下，哪个规格**成交单数最多、成交最快、退货最少**，哪个就更容易出货。
