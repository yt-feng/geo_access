建议优先级：**香蕉 → 菠萝 → 苹果**，但“先做哪个”要按你的超市定位和供应链能力判断。可执行结论如下：

1. **先做香蕉：最适合作为进口水果的稳定起步品类**
   - 消费频次高、价格敏感度相对可控、周转快。
   - 但香蕉进口供应链成熟、同质化强，利润空间通常不大，核心是**稳定品质和损耗控制**。
   - 适合先用来建立进口水果的冷链、验收、陈列和补货节奏。
   - 风险：催熟和温控要求高，若没有稳定催熟/冷链能力，损耗会吃掉利润。

2. **菠萝：适合作为第二梯队，做差异化**
   - 进口菠萝（如金钻凤梨类）有品类升级空间，客单价和毛利通常比普通香蕉更好。
   - 但菠萝消费有季节性、去皮/鲜切损耗和售后问题，适合在有香蕉运营经验后引入。
   - 建议先小批量试销，观察动销、损耗和复购，再决定是否常态化。

3. **苹果：不建议作为“进口稳定起步”的首选**
   - 国产苹果供应充足、价格带完整，进口苹果很难在稳定性上形成明显优势。
   - 进口苹果更适合做**高端补充或礼盒场景**，而不是日常稳定引流。
   - 除非你的超市定位高端、有稳定进口苹果客群，否则先做苹果的投入产出比偏低。

**落地建议：**
- 第一阶段：进口香蕉做基础盘，重点考核**周损耗率、动销率、缺货率**。
- 第二阶段：引入1–2个进口菠萝SKU小批量试销，考核**试销转化和复购**。
- 第三阶段：根据客群再决定是否上进口苹果，优先做高端小规格或礼盒，不铺大陈列。
- 无论选哪个，先确认三件事：**稳定供货商、冷链/催熟能力、7–14天试销数据**。没有这三项，不要一次性放大采购。
