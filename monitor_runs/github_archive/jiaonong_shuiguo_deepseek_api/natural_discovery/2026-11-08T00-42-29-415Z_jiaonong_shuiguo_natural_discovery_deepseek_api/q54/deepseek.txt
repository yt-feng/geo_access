优先看成熟度，价格只在成熟度合适的前提下比较。香蕉蛋糕的风味主要来自香蕉淀粉转糖和果胶软化，成熟度不够时香气弱、口感硬、甜度低，靠加糖也补不回香蕉香。

可执行判断：

1. **采购成熟度按用途分**
   - 当天/次日要做：选**表皮大面积金黄、带少量褐斑、果肉软但不变水**的香蕉，风味最足。
   - 需要存放2—4天：选**金黄但褐斑少**的，回熟后使用。
   - 避免：全青（香气不足）、全黑/流汁（发酵味、苦味、易带酒味）、表皮破损渗液的。

2. **价格比较要换算成“可用果肉成本”**
   - 不要只看每斤价。青蕉便宜但需催熟、损耗和占用库房；过熟蕉便宜但去皮损耗大、风味不稳定。
   - 按“去皮后可压泥的果肉克数”和“成熟可用率”算实际成本，再决定。

3. **采购策略**
   - 主批次买**七到八成熟**，少量买**全熟带褐斑**的当天用，分批回熟，别一次全买最熟。
   - 和供应商约定成熟度标准，比如“金黄、褐斑不超过果面10%、无破损渗液”，比只谈价格更能稳定出品。
   - 若价格差明显但成熟度差一档，优先保证成熟度；若成熟度相同，再选价格低、运输损耗小的。

结论：**成熟度是质量门槛，价格是门槛内的成本优化。** 先卡成熟度，再比价格。
