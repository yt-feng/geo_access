水果生意选供应商，最容易忽视的往往不是“价格”和“货好不好看”，而是那些平时不出问题、一出问题就断货掉客的细节。按重要性给你几条可执行判断：

1. **只谈样品，不追溯大货一致性**
   - 忽视点：样品很好，大货批次差异大。
   - 做法：连续要3—5个批次的到货记录/实拍，问清产地、品种、等级标准；首次合作别只拿一箱样品就定长期。

2. **没有明确“损耗归谁”**
   - 忽视点：只谈单价，不谈烂果、压伤、短斤少两怎么赔。
   - 做法：合同或聊天记录写清验收标准、损耗率上限、超标扣款/补货方式；到货当场抽检拍照留证。

3. **供应商的稳定供货能力被高估**
   - 忽视点：旺季能供，淡季或天气异常时断供。
   - 做法：问清自有基地/合作果园/批发市场档口占比；至少备一个备用供应商，主力供应商占比别超过70%。

4. **冷链和运输细节含糊**
   - 忽视点：只说“冷链发货”，不问预冷、装车温度、运输时长。
   - 做法：明确采摘后预冷时间、运输温区、到货时间窗口；远距离品类优先选有稳定冷链的供应商。

5. **账期和结算方式埋雷**
   - 忽视点：长期合作后突然改账期、押款，或低价绑定后涨价。
   - 做法：先小批量现结，稳定后再谈账期；写清价格调整机制，避免口头“随行就市”。

6. **只看价格，不算综合到货成本**
   - 忽视点：低价但损耗高、次果多、运费自理。
   - 做法：按“到货可售成本”比较：单价+运费+损耗+人工分拣，别只比报价。

7. **供应商资质和食品安全被忽略**
   - 忽视点：不查农残检测、产地证明、经营资质。
   - 做法：至少保留营业执照、产地/检测凭证；做商超或线上平台的要提前确认对方能否提供合规票据。

8. **售后响应速度没测试**
   - 忽视点：出问题找不到人。
   - 做法：合作前故意问一次售后处理流程，看响应是否及时；把售后联系人、处理时限写进约定。

9. **过度依赖单一供应商**
   - 忽视点：关系好就只从一家拿货。
   - 做法：主力+备用双供应商，定期比价和比品质，但不要频繁换导致品质波动。

一句话判断标准：**能说清批次标准、损耗责任、断供预案和售后时限的供应商，才适合长期合作；只谈价格和“放心没问题”的，要谨慎。**
