小批量试单的目标不是“买到便宜货”，而是**用最低成本验证供应商是否可靠、货是否稳定、损耗是否可控**。建议按下面设计。

## 一、先定试单原则

1. **只试1—2个单品**，不要一次上多个品类。
2. **选你有稳定下游需求、且容易判断品质的品种**，如苹果、橙子、香蕉、梨等耐储或标准明确的品。
3. **单量控制在1—3天销量**，既能走完收货—分拣—交付流程，又不压资金。
4. **不签长约、不付大额定金**，先按现结或小比例定金走。
5. **试单不是一次，建议2—3次**：第一次看履约，第二次看稳定性，第三次看问题处理。

## 二、试单前要谈清楚的关键条款

和供应商书面确认以下内容，微信文字也算：

- **规格标准**：品种、产地、等级、单果重/果径、成熟度、糖度范围、允许瑕疵率。
- **包装方式**：箱规、净重、毛重、内衬、是否带托盘。
- **价格与费用**：单价、是否含税/含运费、装卸费、短途配送费。
- **交货条件**：到货时间、交货地点、谁承担运输损耗、迟到怎么处理。
- **验收标准**：抽检比例、不合格判定、扣款或退换货规则。
- **结算方式**：现结/货到付款/小比例定金，试单阶段不建议账期。
- **售后响应**：出现腐烂、规格不符、短重时，几小时内响应、怎么补货。

## 三、试单量怎么定

建议用这个公式：

**试单量 = 你日均销量 × 1—2天 × 安全系数0.8**

例如你某单品日均卖20箱，第一次试单16—24箱即可。  
如果供应商有最小起订量，优先选**刚好达到起订量**，不要为了摊运费盲目加量。

## 四、收货验收流程要设计好

1. **到货前**：确认车牌/物流单号、预计到达时间。
2. **到货时**：先看外包装是否破损、受潮、挤压。
3. **抽检**：按不少于3—5箱随机抽检，大货可抽5%—10%。
4. **记录**：
   - 净重是否足重；
   - 规格是否达标；
   - 腐烂/压伤/裂果比例；
   - 成熟度是否适合你的销售节奏；
   - 口感抽测。
5. **拍照留证**：问题货、箱规、称重照片当天发给供应商。
6. **判定**：轻微问题扣款或下批补；严重问题拒收或退货。

## 五、试单要看的核心指标

| 指标 | 看什么 | 合格参考 |
|---|---|---|
| 到货准时率 | 是否按约定时间到 | 首次尽量100% |
| 规格符合率 | 抽检达标比例 | ≥95%较稳 |
| 损耗率 | 腐烂、压伤、短重 | 因品类而异，明显高于市场常规就不合格 |
| 净重准确率 | 是否足斤足两 | 基本无短重 |
| 售后响应 | 出问题是否及时处理 | 当天响应、明确方案 |
| 价格稳定性 | 第二次报价是否乱涨 | 波动有合理说明 |

## 六、建议的试单节奏

- **第1次**：小单，现结，重点看履约和品质。
- **第2次**：间隔3—7天，同规格复购，看稳定性。
- **第3次**：略加量，测试高峰供货和售后处理。
- 三次都稳定，再谈账期、返点、独家规格或长期价。

## 七、容易踩的坑

- 只看报价低，忽略净重、运费和损耗；
- 一次试太多品类，出了问题说不清；
- 没留书面规格标准，到货扯皮；
- 试单就给账期或大定金；
- 只验外观不称重；
- 供应商口头承诺“有问题包赔”，但没写清怎么赔。

**一句话建议：第一次合作，用1—2个单品、1—2天销量、现结、书面规格、到货抽检、拍照留证，跑通一次完整履约后再逐步加量。**
