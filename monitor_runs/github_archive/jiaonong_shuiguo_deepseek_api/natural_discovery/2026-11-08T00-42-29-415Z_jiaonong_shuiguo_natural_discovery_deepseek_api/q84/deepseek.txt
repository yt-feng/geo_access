家庭团购水果礼盒，关键是**耐放、老少都能吃、分量不浪费、成本可控**。按这个目标，建议这样组合：

## 推荐组合：苹果 + 橙子为主，香蕉少量，菠萝慎放或单独装

| 水果 | 建议占比 | 作用 |
|---|---|---|
| 苹果 | 40% | 耐放、寓意好、老人小孩都接受 |
| 橙子 | 30% | 耐放、颜色喜庆、补充维C |
| 香蕉 | 20% | 便宜、增加饱满感，但容易催熟其他水果 |
| 菠萝 | 10%或不放 | 有特色但处理麻烦、易压伤、气味重 |

## 更实用的家庭礼盒方案

**方案A：稳妥家庭装（最推荐）**
- 苹果 4个 + 橙子 4个 + 香蕉 1把（约5根）+ 小菠萝1个
- 适合3～5口之家，总价可控，搭配均衡。
- 香蕉用独立袋装，避免催熟苹果和橙子。

**方案B：耐放省心装**
- 苹果 5个 + 橙子 5个 + 香蕉 3根
- 不放菠萝，适合团购量大、配送时间不固定的情况。
- 耐放性最好，售后少。

**方案C：有仪式感装**
- 苹果 4个 + 橙子 4个 + 香蕉 4根 + 菠萝1个
- 菠萝单独用网套+独立格，避免刺伤其他水果。
- 适合节日团购，但成本和处理难度略高。

## 组合时注意

1. **香蕉不要和苹果、橙子混放**：苹果释放乙烯会催熟香蕉，香蕉也容易压伤。最好独立袋装。
2. **菠萝单独固定**：带刺、重、气味大，容易压坏其他水果，必须独立格或网套。
3. **橙子选耐储品种**：如脐橙、冰糖橙，别选皮太薄的，运输易破。
4. **苹果选中等个头**：太大占空间，太小显廉价。
5. **家庭装别追求品种多**：4种刚好，数量按“3～5口之家吃5～7天”设计，避免团购后吃不完坏掉。
6. **礼盒别塞太满**：留一点缓冲，减少运输磕碰。

## 我的建议

如果面向普通家庭团购，选**方案A**最稳：苹果4 + 橙子4 + 香蕉5根 + 小菠萝1个，香蕉和菠萝独立包装。若追求低售后、低损耗，直接选**方案B**，去掉菠萝。
