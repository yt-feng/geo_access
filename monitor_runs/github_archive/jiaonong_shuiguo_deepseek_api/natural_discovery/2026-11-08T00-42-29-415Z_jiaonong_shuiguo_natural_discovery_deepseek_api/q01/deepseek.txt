判断香蕉、菠萝供应商靠不靠谱，不要只看报价和样品，要按“能不能稳定供货、品质是否可控、账期和售后是否讲信用”三条线验证。给你一套可直接执行的办法：

**1. 先看资质和真实经营痕迹**
- 营业执照、食品经营许可证/食用农产品销售相关资质要能提供；做批发配送的还应能说明仓储、运输条件。
- 去现场看：是否有固定档口/仓库、冷库或通风库、装卸区、分拣区。香蕉和菠萝都怕温度、湿度管理不当，现场乱、混放、无温控的要谨慎。
- 看进货和出货记录是否连续，不要只看一天热闹。

**2. 用样品和小单试供**
- 连续试供2—3周，不要一次下大单。每周固定抽检：香蕉看成熟度均匀性、青硬比例、果指饱满度、机械伤和催熟一致性；菠萝看果眼深浅、果实大小均匀度、黑心/水心病、冠芽新鲜度、运输压伤。
- 每批记录：到货时间、数量、次果率、损耗原因、补货响应时间。次果率忽高忽低、解释含糊的，不能长期合作。
- 让供应商同时报“到店价”和“到店后损耗责任”，不要只比箱价。

**3. 重点问清香蕉和菠萝的供应能力**
- 香蕉：产地/催熟方式、到店是青蕉还是催熟蕉、催熟批次是否稳定、旺季淡季差价怎么算、断货时有无替代货源。
- 菠萝：品种和产区、是否按规格分级、黑心果和烂果怎么赔付、季节性断供怎么处理。
- 问一句“如果我每周固定要X箱，连续三个月，你用什么保证规格和成熟度一致？”回答越具体越可信。

**4. 验证履约和售后**
- 先谈清楚：缺斤少两、规格不符、次果超标、到货延迟分别怎么赔；最好写进供货单或微信文字确认。
- 故意测试一次小问题，比如要求换2箱次果或延迟半天补货，看对方响应速度和是否推诿。
- 账期不要一上来给太长。先现结或短账期，稳定后再谈周结/月结；对方若极力诱导大额预付、长期锁价，要警惕。

**5. 看价格是否“合理稳定”**
- 让2—3家供应商同时报价，比较同一规格、同一到货标准下的价格，不要拿不同等级比价。
- 报价明显低于市场且不愿说明原因的，通常会在规格、成熟度、损耗或秤上找回来。
- 长期合作价格可以随行就市，但调价要有依据、提前通知，不能今天一个价明天一个价。

**6. 观察几个危险信号**
- 样品很好，大货明显降级；
- 每次损耗都让你承担，售后只会说“水果就这样”；
- 催货时满口答应，实际经常迟到或少量多次补；
- 不愿提供固定联系人、仓库地址、称重和装车记录；
- 要求大额预付、频繁换收款账户、合同主体和收款主体不一致。

**实操建议：** 先选2家各试供3周，每周固定采购香蕉、菠萝各一批，按“次果率、到货准时率、售后响应、价格稳定性”打分，保留70%左右给主供应商、30%给备用供应商。这样既压得住品质，也不会被一家卡脖子。最关键的一句话：**能让你连续小单验证、出了问题肯按规则赔的供应商，才值得长期合作。**
