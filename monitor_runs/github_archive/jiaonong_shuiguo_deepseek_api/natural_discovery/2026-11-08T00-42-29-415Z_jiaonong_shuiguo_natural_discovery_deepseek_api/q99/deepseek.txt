选下午茶水果供应商，核心看四件事：**批量稳定性、配送时效、损耗赔付、开票结算**。可以按下面步骤筛选和判断。

**1. 先明确采购约束**
- 人数和预算：按每人 150–250g 水果估算，例如 50 人约需 8–12kg。
- 配送时间：下午茶通常要求当天下午 2–4 点前送达，需确认供应商能否固定时段配送。
- 场地条件：有无冰箱、能否接收、是否需要分装成小份。
- 结算要求：是否需要发票、对公转账、月结。

**2. 优先选“批量配送型”供应商，而不是零售水果店**
适合的类型：
- 本地水果批发商/配送商：价格低、品类多，但需确认是否支持小批量起送和分装。
- 企业团餐/下午茶综合服务商：通常含水果、零食、饮品，配送和售后更规范。
- 生鲜电商企业购渠道：时效稳定、开票方便，但价格略高。
- 本地农场或合作社直供：适合固定品类，需确认配送频率和损耗处理。

不建议只找单一零售水果店，除非对方明确有企业配送经验。

**3. 重点核验 6 个问题**
向供应商逐项确认，能明确回答的再进入比价：
1. **起送量和价格**：多少公斤起送？是否含配送费、分装费？
2. **配送时效**：能否固定下午时段送达？迟到如何处理？
3. **损耗和坏果赔付**：签收后发现坏果，按什么比例赔？是否拍照即赔？
4. **品控标准**：是否有分级标准？能否提供当日到货样品或实拍？
5. **分装能力**：能否按部门/人数分装成小份？是否额外收费？
6. **资质和结算**：营业执照、食品经营许可是否齐全？能否开票、支持月结？

**4. 用“小单试配”降低风险**
不要第一次就大额长期合作。先下一单测试：
- 到货时间是否准时；
- 实际品质与样品是否一致；
- 坏果率是否可接受；
- 分装是否规范；
- 售后响应是否及时。

试配合格后再签月度或季度框架，约定价格、配送时段、赔付标准。

**5. 比价时看“综合成本”而非单价**
把以下费用加总比较：
水果单价 + 配送费 + 分装费 + 预计损耗 + 售后成本。
批量配送中，坏果率和迟到率往往比单价更影响实际成本。

**6. 合同或订单里写清楚**
至少写明：品类规格、数量、送达时间、验收标准、坏果赔付比例、迟到处理、开票信息、结算周期。口头承诺尽量落到订单备注或聊天记录中。

**简单执行顺序**：先列人数预算和配送要求 → 找 3 家本地批量配送商询价 → 逐项确认上述 6 个问题 → 小单试配 → 比综合成本 → 签短期框架。
