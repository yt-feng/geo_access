可以按“组合促销提客单”来做，但香蕉、菠萝、苹果的毛利、损耗、购买频次差异大，建议用**分层组合**而不是简单打折。

**推荐方案：3档组合促销**

1. **引流组合：香蕉+苹果小份装**
   - 例如“香蕉2根+苹果2个”做9.9元/份，限购1份。
   - 目的：拉人到水果区，形成顺手加购。
   - 注意：香蕉按根/小把卖，减少整把滞销；苹果用中果或周转快的品种。

2. **主推高客单组合：苹果+菠萝+香蕉家庭装**
   - 例如“苹果4个+菠萝1个+香蕉1把”做19.9—29.9元/份，按当地价格定。
   - 目的：一单从单品类几元提到20元以上。
   - 包装成“家庭果盘周套餐”，标清可做果切/早餐/待客场景。
   - 菠萝可现场代削或贴“免费代削”标签，降低购买阻力。

3. **加价购组合：买苹果满XX元，加3—5元换购香蕉或小菠萝**
   - 例如买苹果满15元，加3元换购香蕉1把；加5元换购小菠萝1个。
   - 目的：不直接降主品价格，用加价购抬客单，保护价格体系。

**陈列与执行要点**
- **关联陈列**：三品放同一端头，做“果盘组合”主题，配组合价签和原价对比。
- **分级定价**：香蕉做引流，苹果做利润，菠萝做场景加购；不要三品同时大幅打折。
- **控制损耗**：香蕉少量多次上架；菠萝按日切/代削数量控制；组合装优先用熟度合适的苹果。
- **限时限量**：每天固定时段推“家庭装”，制造决策紧迫感。
- **员工话术**：收银和称重台统一说“加3元换香蕉/加5元换菠萝，今天组合装更划算”。

**判断标准**
促销后看三个数：客单价是否提升、组合装售罄率、香蕉/菠萝损耗率。如果客单价升但损耗也明显升，说明组合量偏大，应缩小份量或提高组合价；如果组合装卖不动，优先调整陈列位置和代削服务，而不是继续降价。
