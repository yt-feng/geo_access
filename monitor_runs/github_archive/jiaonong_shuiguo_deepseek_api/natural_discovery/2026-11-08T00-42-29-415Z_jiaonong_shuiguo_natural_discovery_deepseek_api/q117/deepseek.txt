建议按“先小批量、可退换、能复盘”的方式试卖，不要一次性压货。比较稳的做法是：

1. **先定试卖量：3～7天销量，不超过首单总采购额的10%～20%**
   - 单店/单仓：先从 **1～2箱/件/托** 起，或按 **20～50公斤/单品** 试。
   - 社区团购/小门店：先从 **10～30份** 起。
   - 多门店：先选 **2～3家代表性门店** 各小批量试，不要全门店铺开。

2. **按品类微调**
   - 耐储水果（苹果、橙、柚）：可稍多，3～5天量。
   - 易损水果（莓果、葡萄、桃、荔枝）：先 **1～2天量**，宁可补货。
   - 高客单新品：先 **10～20份** 测接受度。
   - 低客单引流品：可到 **30～50份**，但设止损线。

3. **首单必须谈条件**
   - 争取 **小起订量、混拼、破损包赔、未售可换货/退货**。
   - 约定到货验收标准：糖度、规格、成熟度、损耗率。
   - 先要样品做盲测和货架期测试。

4. **设止损和加单规则**
   - 试卖 **3天**看动销：售罄率低于50%先促销清货；高于80%且损耗可控再补单。
   - 损耗超过 **5%～8%**（易损品可放宽到10%）就暂停加单，先查冷链和陈列。
   - 复购/好评明显再进入常规采购。

5. **试卖前先算清毛利**
   - 扣除损耗、冷链、促销后毛利太薄的新品，不建议试。
   - 试卖期记录：日销量、损耗、客诉、复购、竞品价格。

**结论：先用“1～2箱/20～50公斤/10～30份、2～3家店、3～7天”的小单试卖，谈好退换和损耗承担，再按动销和损耗决定加单。**
