批发商担心货到后损耗高，合同里要把“坏果责任”写清楚，核心是明确**验收时间、验收标准、责任归属、扣款/赔付方式、证据和异议流程**。可以按下面思路写：

1. **明确验收期限和地点**
   - 例如：货物到达买方指定地点后，买方应在 **2小时内/4小时内/当日卸货时** 完成验收。
   - 逾期未验收或未提出异议的，视为数量、外观质量初步合格。
   - 但“隐蔽性损坏”可另设期限，例如到货后 **24小时内** 提出。

2. **明确坏果定义和判定标准**
   - 不要只写“坏果”，要具体：
     - 腐烂、发霉、软化、破裂、渗汁；
     - 冻伤、压伤、病虫害；
     - 规格不符、成熟度不符；
     - 单果损伤面积超过多少、整批坏果率超过多少。
   - 可约定：以双方共同抽样为准，抽样比例例如 **5%—10%**。
   - 可约定标准：坏果率≤3%为合格；超过部分由卖方负责。

3. **明确责任分担**
   - 装车前已存在的腐烂、病虫害、成熟度过高：卖方责任。
   - 运输途中因冷链中断、挤压、延误导致的损坏：按运输责任方承担。
   - 到货后买方储存不当导致的损坏：买方责任。
   - 建议写：卖方对到货验收时发现的坏果承担更换、补货、折价或退款责任。

4. **明确扣款或赔付方式**
   - 按坏果数量扣款：坏果重量×单价×倍数。
   - 按坏果率阶梯扣款：
     - 坏果率3%以内不扣；
     - 3%—5%按实际坏果金额扣；
     - 5%—10%按实际坏果金额的1.5倍扣；
     - 超过10%买方有权拒收或要求整批退货。
   - 也可约定：卖方补发同等数量合格果，运费由责任方承担。

5. **明确拒收和退货条件**
   - 例如：整批坏果率超过 **10%**，买方有权拒收全部或部分货物。
   - 拒收后卖方应在 **24小时内** 安排处理，否则买方有权自行处理，费用由卖方承担。
   - 易腐货物要特别注意：不宜长期存放，拒收后应允许买方紧急处置并保留证据。

6. **明确证据和通知流程**
   - 买方发现坏果后，应在约定时间内拍照、视频、称重、记录批次，并通知卖方。
   - 双方可约定：卖方接到通知后 **2小时内** 到场或远程确认；逾期视为认可买方记录。
   - 保留样品，必要时送第三方检测。

7. **明确不可抗力与免责**
   - 自然灾害、疫情管控、交通管制等不可抗力可部分或全部免责。
   - 但冷链设备故障、普通运输延误通常不能当然免责。

8. **建议直接写入合同的条款示例**

> 货物到达买方指定地点后，买方应在卸货时共同验收，并在到货后4小时内提出外观质量异议，24小时内提出隐蔽性损坏异议。坏果包括腐烂、发霉、软化、渗汁、冻伤、压伤、病虫害及不符合约定规格的果实。双方按不低于5%比例随机抽样，坏果率≤3%视为合格；超过3%的，超出部分由卖方按实际坏果数量对应货款的1.5倍向买方赔偿，或由卖方在24小时内补发合格货物。坏果率超过10%的，买方有权拒收该批货物，卖方承担由此产生的运费、卸货费及合理处置费用。买方应在发现坏果后拍照、称重并通知卖方，卖方逾期未确认的，视为认可买方验收记录。

9. **谈判时重点争取**
   - 验收时间不要太短，尤其是需要卸货、分拣的批发场景。
   - 坏果率阈值和扣款倍数要写具体。
   - 易腐货物要写“紧急处置权”，否则买方可能被拖住。
   - 补货、退款、扣款三种方式选哪种，要提前定好。
   - 运输责任方如果是第三方物流，最好在合同里写明卖方对运输环节向买方负责，卖方再向物流追偿。

简单说：**合同里不要只写“坏果由卖方负责”，而要写清楚“多久验收、什么算坏果、坏多少扣多少、怎么赔、多久回复、拒收怎么办”。**这样批发商到货后才有可操作依据。
