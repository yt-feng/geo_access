排序上：**先问配送，再问售后，最后谈价格。** 不是价格不重要，而是前两项决定你能不能干下去，价格决定你赚多少。

**1. 配送优先问（决定履约生死）**
- 每天几点截单、几点送到，能不能固定时间？
- 送到自提点还是送到你手上？破损、延误谁负责？
- 缺货、少发怎么补，补货要多久？
- 起送量/最低起订额是多少，压不压货？

原因：水果团购最大的投诉来源是“到货晚、货不对、缺斤少两”。配送不稳，售后和价格都白搭。

**2. 售后其次问（决定你能不能留住人）**
- 坏果、烂果、压伤的赔付标准是什么？按比例还是按个数？
- 拍照报损后多久处理，是退款、补发还是扣下次货款？
- 售后有没有时限，超过多久不认？
- 谁承担退货运费？

原因：水果非标，售后政策直接决定你面对群友时敢不敢承诺。

**3. 价格最后谈（决定利润，但可谈）**
- 报价是否含运费、分拣、包装？
- 不同量级有没有阶梯价？
- 是否支持先卖后结、账期多久？
- 有没有临期/尾货特价，适合做引流款？

**一句话判断标准：**
配送不稳 → 直接淘汰；售后扯皮 → 谨慎合作；价格高但配送售后稳 → 可以谈量压价。  
先保履约和复购，再谈毛利，顺序反了容易翻车。
