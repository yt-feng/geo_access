找能每天配送的水果供应商，社区超市重点看下面几项。你可以直接当成筛选清单用。

**1. 配送能力**
- 是否能做到每天固定时间送达，比如早上6–8点开门前到货。
- 是否支持一日多配，或者临时补货。
- 配送范围是否覆盖你所在区域，偏远或老社区要特别确认。
- 节假日、雨天、旺季是否能稳定送，不随意断供。

**2. 货源与品类**
- 是否有稳定产地或批发市场档口，不是临时倒货。
- 常规水果是否齐全：苹果、香蕉、橙子、梨、葡萄、西瓜、时令水果等。
- 能否按你的销量配货，而不是强行搭售滞销品。
- 季节性水果切换是否及时，能不能提前给推荐。

**3. 价格与结算**
- 报价是否透明，是否随行就市但有提前通知。
- 是否含运费、装卸费、损耗费，避免低价吸引后加价。
- 结算方式：现结、周结、月结，是否压货款。
- 能否提供每日对账单，方便你核对数量和金额。

**4. 品质与损耗**
- 到货新鲜度、成熟度是否稳定，适合社区店快周转。
- 坏果、碰伤、烂果怎么赔，是否包退包换。
- 损耗率大概多少，超过部分谁承担。
- 是否支持开箱验货，不合格当场退。

**5. 起送量与补货**
- 每天最低起送量是多少，小社区店能不能承受。
- 临时加单、减单是否灵活，截止时间几点。
- 爆款缺货时，能否及时替换或补其他品类。

**6. 资质与安全**
- 营业执照、食品经营相关资质是否齐全。
- 水果是否有农残检测或合格证明，尤其是叶菜类、草莓、葡萄等。
- 运输车辆是否清洁、冷藏或保鲜措施是否到位。

**7. 合作风险**
- 是否只靠一个供应商，建议至少备选1–2家。
- 先小批量试供1–2周，再决定长期合作。
- 合同里写清配送时间、品质标准、退换规则、价格调整方式。
- 观察对方是否经常迟到、缺货、以次充好。

**实操建议：**
先找本地批发市场、周边果园、区域水果配送商、社区团购供应链这几类。让对方连续试送3–7天，你记录：到货时间、损耗率、退货响应、价格波动、缺货次数。最后选“配送稳、损耗低、退换爽快”的那家，而不是单纯报价最低的。
