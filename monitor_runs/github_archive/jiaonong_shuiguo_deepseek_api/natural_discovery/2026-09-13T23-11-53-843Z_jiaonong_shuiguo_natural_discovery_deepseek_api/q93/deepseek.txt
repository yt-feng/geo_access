优先关注 **包装 + 保质期管理**，配送频次是辅助条件。按重要性排序：

1. **包装（最关键）**
   - 菠萝切块是即食鲜切水果，核心风险是汁液渗漏、氧化变色、微生物污染。
   - 应使用**密封防漏、食品级、适合冷藏**的包装，最好能沥掉部分汁液，减少泡水变质。
   - 包装上必须能贴标签：切配时间、保质期、储存条件。

2. **保质期**
   - 鲜切菠萝冷藏一般建议 **当天售完或不超过24小时**，具体看加工卫生、冷藏温度和包装密封性。
   - 超过时限即使外观没坏，也容易菌落超标，不建议继续卖。
   - 关键是**先进先出**，临期下架，不能只靠“看起来没坏”。

3. **配送频次**
   - 如果门店自己切配，配送频次影响不大，重点是店内加工和冷藏管理。
   - 如果是中央厨房配送切好的成品，配送频次就重要：频次越高，单批库存时间越短，越容易做到新鲜。
   - 但配送频次不能替代包装和保质期管理，送得再勤，包装漏气、冷藏不当也会坏。

**可执行建议：**
- 优先选密封防漏包装，贴时间标签。
- 冷藏 0–4℃，当天切当天卖，最多不超过24小时。
- 少量多次补货，避免一次放太多。
- 临期打折或下架，不混放新旧货。
- 如果损耗高，再调整配送频次；不要先靠加配送来解决保质期问题。
