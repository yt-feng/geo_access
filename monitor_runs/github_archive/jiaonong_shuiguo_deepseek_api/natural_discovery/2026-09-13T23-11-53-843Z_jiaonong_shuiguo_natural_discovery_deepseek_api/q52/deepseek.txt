采购香蕉时，想避免到店后很快变黑，核心是控制成熟度和储存环境。可以按下面做：

1. **买偏青、硬一点的香蕉**
   - 选表皮青绿、没有黑点、手感硬的。
   - 避免买已经发黄、带梅花点、手感软的，那种到店后很快会熟透发黑。

2. **不要一次买太熟的批次**
   - 如果每天用量稳定，可以分两批采购：一批偏青的备用，一批微黄的当天用。
   - 宁可买青一点，到店后自然催熟，也比买熟过头强。

3. **运输时避免挤压和高温**
   - 香蕉怕压、怕闷、怕热。装箱不要堆太满，避免硬物压伤。
   - 夏天尽量用空调车或阴凉处运输，别放在后备箱暴晒。
   - 到店后尽快卸货，不要长时间闷在车里或仓库角落。

4. **到店后不要直接放冷藏**
   - 未完全成熟的香蕉放冰箱容易冻伤，表皮会更快变黑。
   - 先放在阴凉、通风、避免阳光直射的地方。
   - 理想温度大约 13–15℃，湿度适中，不要靠近炉灶、烤箱、热水器。

5. **把香蕉挂起来或单层摆放**
   - 挂起来能减少受压，通风也好。
   - 如果平放，尽量单层，不要叠压。
   - 避免和苹果、梨、番茄等释放乙烯较多的水果放在一起，会加速成熟变黑。

6. **按成熟度分开管理**
   - 青的放一起，微黄的放一起，熟的分开。
   - 每天挑出已经软熟或开始发黑的，优先做甜品、奶昔、香蕉泥，不要继续和好香蕉混放。

7. **需要延缓时，可适当通风、降温，但别低于 12℃**
   - 如果店里空调较冷，也不要直接对着香蕉吹。
   - 成熟度较高、当天用不完的，可以剥皮后冷冻保存，做冰沙或烘焙用。

8. **采购量按销量走**
   - 香蕉变黑很多时候不是储存问题，而是一次买太多。
   - 按 1–2 天用量采购，旺季少量多次补货，比一次性囤货更稳。

简单判断：
- **想放得久**：买青的、硬邦邦的，阴凉通风挂起来，别冷藏、别压、别和苹果放一起。
- **已经黄熟**：尽快用掉，或剥皮冷冻，不要继续常温堆着。
