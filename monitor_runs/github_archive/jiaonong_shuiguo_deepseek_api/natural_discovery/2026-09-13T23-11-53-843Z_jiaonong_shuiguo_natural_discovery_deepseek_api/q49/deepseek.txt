直接给可落地的做法，分三步：先判断你要哪种补货模式，再谈具体条款，最后留好凭证。

**一、先定补货模式（选一种或组合）**

1. **框架协议 + 临时订单**：最推荐。平时签一份年度/季度框架协议，约定单价、质量标准、账期；旺季用微信/邮件发临时订单，供应商确认即生效。
2. **安全库存 + 触发补货**：约定你店里菠萝库存低于X箱（比如2天用量）时，供应商须在24/48小时内送到。
3. **紧急加单条款**：明确旺季（如4-9月）每周可临时加单几次、加单提前几小时通知、加价上限。

**二、必须谈清楚的条款**

- **数量弹性**：约定日常量的基础上，可临时上浮多少（如±30%），超出部分怎么算价。
- **提前期**：普通补货提前24小时，紧急补货提前4-6小时，分别对应什么价格。
- **价格机制**：旺季菠萝涨价是常态。建议约定"以某批发市场当日均价为基准，上浮不超过X%"，避免供应商随口涨价；或直接锁一个旺季价，但要求最低采购量。
- **质量标准**：写明品种、成熟度、单果重量范围、坏果率上限（如≤5%），到货抽检不合格怎么退换。
- **违约责任**：供应商断供或延迟怎么赔（如按缺货金额的X%），你临时取消订单怎么处理。
- **账期与结算**：临时补货是现结还是挂账，写清楚，避免旺季扯皮。

**三、操作上留证据**

- 所有临时补货走**文字记录**（微信、邮件、订单系统），不要只打电话。
- 每次到货**当场验收、拍照、记录批次**，有问题当天反馈。
- 保留1-2家备选供应商，旺季单一供应商容易掉链子。

**一句话建议**：旺季前1个月就把框架协议和弹性条款谈好，别等断货了才临时找供应商，那时候你没有任何议价权。
