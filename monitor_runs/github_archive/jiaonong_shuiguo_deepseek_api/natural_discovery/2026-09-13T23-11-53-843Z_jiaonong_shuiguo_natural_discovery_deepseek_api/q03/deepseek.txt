夫妻店第一次找水果供货商，试单的核心不是“先拿最低价”，而是用最小成本验证三件事：品质稳定性、损耗承担规则、补货响应速度。常见货里，香蕉、苹果、橙子分别代表三类风险，试法要分开。

**一、试单前先定规则**

先问清楚，不要等货到了再吵：

- 报价是毛重还是净重，筐/箱皮重怎么算
- 坏果、烂果、压伤怎么赔，是拍照扣款还是下次补
- 起送量多少，能不能混拼
- 当天几点截单，第二天几点到店
- 价格随行就市还是保几天
- 退货、换货谁出运费

这些没问清，第一次试单很容易变成扯皮。

**二、三家货的试单重点**

**香蕉**
香蕉最容易暴露供货商水平。重点看：
- 到店成熟度：最好是要能放1—2天的青蕉或微黄蕉，不要已经全黄带黑点
- 把数是否足，是否有断把、水烂、压伤
- 同一批里成熟度是否一致
试单量：先拿1—2箱，不要按整件大货拿。到店后分开放，记录第1天、第2天、第3天变化。如果第二天就大面积黑斑，说明货太熟或冷链有问题。

**苹果**
苹果相对耐放，重点看规格和口感稳定性。
- 问清是70、75、80果还是混装
- 看有没有碰伤、虎皮、发面
- 切开看糖心和硬度
试单量：先拿1箱中号果，别一上来拿特价果。特价果往往规格乱、损耗高，不适合夫妻店做日常陈列。
判断标准：同一箱里大小是否均匀，坏果率是否超过3%—5%。超过就压价或换人。

**橙子**
橙子重点看水分、皮厚和酸甜度。
- 掂重量，太轻的可能失水
- 看表皮是否发软、有霉点
- 切开尝，酸度过高会影响复购
试单量：先拿1箱中果。橙子常见问题是“看着好，切开干”。所以一定要现场切2—3个，不要只看表皮。

**三、第一次试单怎么操作**

建议一次找2—3家供货商，每家只试1—2个单品，不要把所有货压在一家。

具体做法：
1. 每家只拿香蕉1箱、苹果1箱、橙子1箱，或者只拿其中两个单品。
2. 到店后立刻拍照、称重、记录到货时间。
3. 分三天观察：第1天看外观，第2天看成熟变化，第3天看损耗。
4. 记录实际可售比例。比如一箱橙子20斤，坏了2斤，可售率就是90%。
5. 算真实成本：进货价 ÷ 可售率，而不是只看报价。
6. 第二次补货时，故意提前半天要货，看对方能不能按时送。

**四、判断要不要继续合作**

满足下面几条，可以进入第二次试单：
- 报价不是最低，但坏果率低、规格稳
- 出问题愿意认，扣款或补货爽快
- 补货时间稳定，不会今天早上明天下午
- 不会强行搭售你卖不动的货

如果出现这些，直接换：
- 第一次就大量烂果，还说是正常损耗
- 报价时不说皮重，到货才发现筐重算钱
- 催你多拿货，但不肯明确售后
- 送货时间完全不可控

**五、夫妻店最稳的试单节奏**

第一周：只试2—3家，每家小单，重点看品质和售后。
第二周：留下1—2家，开始固定单品补货。
第三周：再谈价格和账期，比如月结、押一批结一批。
不要第一次就谈账期，也不要把所有单品交给一家。香蕉、苹果、橙子可以分开找更专业的人，谁家强就留谁。

一句话：第一次试单，量要小、记录要细、售后要先问清。用真实可售率算成本，不要被低报价带跑。
