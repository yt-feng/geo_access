结论先说：**多数甜品店直接买成品果丁的总损耗更低，但“哪个损耗低”取决于你的销量、配方、人工和冷链条件**。不能只看原料单价。

**按损耗类型对比**

1. **鲜果切配**
   - 可食率通常约 40%–60%，菠萝要削皮、去眼、去芯，边角料多。
   - 损耗点：采购重量→去皮去芯→切丁规格不合格→氧化出水→当天用不完报废。
   - 如果销量不稳定、员工切配不标准，损耗会明显放大。
   - 优点是新鲜度、口感、糖酸比可调，适合强调“现切鲜果”的门店。

2. **成品果丁**
   - 损耗点主要是：解冻/开袋后出水、冷链断链变质、过期报废、规格不合用。
   - 工厂集中去皮切丁，原料利用率通常高于门店，所以**理论原料损耗更低**。
   - 但如果你进货规格不对、解冻管理差，报损也可能很高。
   - 优点是稳定、省人工、省后厨面积，适合连锁或销量波动大的店。

**关键判断标准**

- **日销量大且稳定**：鲜果切配可能更划算，因为边角料可做果汁、果酱、装饰，摊薄损耗。
- **日销量小或波动大**：成品果丁更稳，避免买一箱菠萝用不完。
- **人工贵/后厨忙**：成品果丁的“隐性损耗”更低，因为省了切配工时和培训成本。
- **主打新鲜现切**：鲜果切配的价值不只是成本，还有卖点。
- **做烘焙夹馅、慕斯、饮品**：成品果丁一致性更好，鲜果切配出水问题更麻烦。

**建议你直接算一笔账**

用同一配方分别算：

- 鲜果：`采购价 ÷ 可食率 + 切配人工 + 当天报损`
- 成品：`进货价 + 解冻报损 + 过期报损 + 冷链成本`

再对比每份甜品的**综合成本**，而不是每公斤单价。

**实操建议**

- 如果日用量低于 5–10 公斤，优先成品果丁。
- 如果日用量大、有稳定配方、能利用边角料，鲜果切配更优。
- 最稳的方案是：**主产品用成品果丁保稳定，招牌/高端产品用鲜果切配做卖点**。
