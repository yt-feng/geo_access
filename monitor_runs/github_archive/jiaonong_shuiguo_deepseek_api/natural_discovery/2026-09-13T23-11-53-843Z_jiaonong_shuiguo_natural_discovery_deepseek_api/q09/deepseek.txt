旺季怕断货，和供应商谈的时候，核心不是“能不能便宜”，而是“能不能稳定、优先、按你要的节奏供货”。建议提前问清楚下面几类问题。

**一、供货能力与优先级**
1. 旺季你每天/每周最大能给我供多少货？  
2. 如果同时有几个客户要货，我是什么优先级？  
3. 哪些品种你自有基地/长期合作基地，哪些是临时调货？  
4. 遇到下雨、降温、节假日，供货会受多大影响？  
5. 你能不能给我一个旺季保底供货量？如果做不到怎么赔？

**二、价格与调价机制**
1. 旺季价格怎么定？是固定价、随行就市，还是按等级报价？  
2. 一天一价还是几天一价？什么时候通知我调价？  
3. 如果我提前锁量，能不能锁价？锁多久？  
4. 量大有没有返点、账期、运费补贴？  
5. 次品、小果、伤果怎么算价？能不能退换？

**三、品质与验收**
1. 按什么标准分等级？糖度、大小、色泽、成熟度有没有明确标准？  
2. 能不能先发样品，确认后再批量？  
3. 到货后多久内可以验收？坏果率超过多少算供应商责任？  
4. 出现烂果、冻伤、压伤，是补发、扣款还是退货？  
5. 包装规格能不能按我的门店需求做？比如箱重、层数、防压措施。

**四、物流与到货**
1. 发货地在哪里？到我店通常多久？  
2. 旺季能不能保证当天发、次日达，或者按我指定时间到？  
3. 运费谁承担？能不能送到店？卸货谁负责？  
4. 物流途中损耗谁承担？  
5. 如果迟到导致我断货，有没有补偿或应急补货方案？

**五、结算与风险**
1. 是现结、周结还是月结？要不要押金？  
2. 缺货、迟到、品质不达标，怎么扣款或赔偿？  
3. 能不能签简单合同或供货协议，把保底量、价格机制、赔付写清楚？  
4. 如果旺季你供不上，我能不能临时从别处补货，你不限制？  
5. 有没有备用供应商？你能不能接受我同时保留第二供货渠道？

**六、旺季特别要问的**
1. 中秋、国庆、春节前，哪些品类最容易断？  
2. 能不能提前 7 天给你预报量？你提前备货？  
3. 爆款单品能不能给我留货？留货要不要定金？  
4. 如果临时加单，最快多久能补？加单上限多少？  
5. 能不能每周给我一个“可供清单+建议零售价”，方便我排采购。

**谈的时候最好落到这几条：**
- 保底供货量：写清楚每天/每周最少多少。
- 优先供货权：旺季先保你，还是按比例分。
- 价格机制：随行就市可以，但要有通知时间和上限。
- 品质标准：坏果率、等级、退换规则。
- 赔付条款：断货、迟到、品质差怎么赔。
- 备用方案：允许你临时补货，不搞独家绑定。

一句话：**旺季合作要谈“量、价、质、时、赔、备”六个字。** 尤其是保底量、优先权、赔付和备用渠道，这四条比单纯压价更重要。
