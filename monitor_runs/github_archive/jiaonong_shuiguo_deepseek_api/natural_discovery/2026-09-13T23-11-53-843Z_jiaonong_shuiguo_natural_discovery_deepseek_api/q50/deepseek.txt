**出汁率更重要（优先级更高）**，甜度可以通过配方里的糖浆、果糖或菠萝汁浓缩液来补，但出汁率是原料本身的硬指标，补不回来。

具体判断逻辑：

**为什么出汁率优先**
- 出汁率直接决定你的**原料成本和出品稳定性**。同样买10斤菠萝，出汁率30%和50%差出一大半可用原料，成本差可能到40%以上。
- 出汁率低的菠萝，往往意味着果肉纤维粗、水分少，榨汁后要么渣多、要么需要加水稀释，稀释后风味又被冲淡，反而要额外加香精/浓缩汁去补。
- 茶饮店菠萝通常用于**鲜果茶、菠萝汁、菠萝果肉**，出汁率和果肉得率直接挂钩。

**甜度为什么可以后补**
- 甜度是可以用糖浆、果葡糖浆、菠萝浓缩汁调节的，属于**配方层能解决的问题**。
- 但要注意：甜度太低的菠萝，酸度往往也偏高，可能需要更多糖来压酸，会拉高整体甜度和成本，这是次要考量。

**实操建议**
1. **先按出汁率筛**：要求供应商提供或自己实测出汁率，鲜榨场景建议选40%以上的品种（如台农、金钻、MD-2等，具体看季节和产地）。
2. **再尝风味平衡**：甜酸比合适、香气足的优先，香气是糖补不出来的。
3. **算综合成本**：按“每杯可用菠萝汁成本”而不是“每斤菠萝价格”来比价。
4. **季节替代**：非菠萝季如果出汁率差，直接用冷冻菠萝汁/浓缩汁更稳，别硬用鲜果。

一句话：**出汁率决定底线，甜度决定上限；底线不能用配方补，上限可以。**
