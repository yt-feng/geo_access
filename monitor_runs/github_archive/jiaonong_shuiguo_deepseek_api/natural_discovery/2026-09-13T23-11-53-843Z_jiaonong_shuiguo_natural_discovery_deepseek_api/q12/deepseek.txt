水果店卖菠萝，采购时最关键不是“买最熟的”，而是**买适合你预计销售节奏的熟度**。菠萝是后熟型水果，采购后还会继续变黄、变香，但过度成熟后损耗会明显上升。

给你一套可执行的判断方法：

1. **先定销售周期**
   - 预计 1～2 天卖完：可以采 7～8 成熟，表皮开始转黄、果香明显。
   - 预计 3～5 天卖完：采 6～7 成熟，青黄交界、香味淡。
   - 走量慢、要陈列：采 5～6 成熟，偏青、硬，后续慢慢转熟。
   - 做现削、切块、果汁：可以采 8～9 成熟，但必须当天或次日处理完。

2. **看表皮颜色**
   - 全青：太生，酸、硬、糖度低。
   - 青底带黄、黄绿相间：适合中短期销售。
   - 三分之一到一半转黄：适合 1～2 天卖。
   - 大面积金黄、果眼发亮：接近适口，但损耗风险高。
   - 出现褐斑、软塌、渗汁：已经过熟，不建议采购。

3. **闻香气**
   - 几乎无味：偏生，可放。
   - 靠近果底有淡淡菠萝香：比较合适。
   - 香气浓、甜腻、带发酵酒味：过熟，损耗高。
   - 有酸腐味、酒精味：不要采。

4. **按压果身**
   - 硬邦邦：偏生。
   - 轻按有弹性、不塌：合适。
   - 一按就凹、局部软：过熟或开始坏。
   - 果底发软、发黏：不要。

5. **看果眼和果形**
   - 果眼平、分布均匀、果形端正：成熟度较均匀。
   - 果眼深、尖、密：通常偏生。
   - 果底开裂、流汁、长霉：直接排除。

6. **看冠芽和果柄**
   - 冠芽青绿、挺立：较新鲜。
   - 冠芽枯黄、易拔：采摘久或过熟。
   - 果柄切口新鲜：到货时间短。
   - 果柄干黑、发霉：存放久或品质差。

7. **分批次采购，不要一个熟度**
   比较稳的做法是：
   - 60% 采 6～7 成熟，用于后续 3～5 天；
   - 30% 采 7～8 成熟，用于今明两天；
   - 10% 采 8～9 成熟，用于当天现削、试吃、促销。
   这样能兼顾陈列、销售和损耗。

8. **到店后做熟度分区**
   - 生果放阴凉通风处，不要直接暴晒。
   - 熟果优先陈列、试吃、削卖。
   - 过熟果立刻转切块、果汁、特价，不要继续摆。
   - 菠萝怕冷害，通常不建议长期低温冷藏，尤其未切开的青果。

9. **根据损耗反推采购熟度**
   如果你店里平均 3 天卖一批，建议主采 6～7 成熟；如果经常当天卖完，可以提高到 7～8 成熟；如果只能周末走量，工作日就多采 5～6 成熟，周末前再补熟果。

简单记：
**青黄相间、淡香、轻按有弹性，适合多数水果店；全黄浓香只适合快销；全青无香只适合放熟；软、酒味、流汁不要采。**
