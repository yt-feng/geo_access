生鲜水果到货后出现坏果，责任划分通常不是“一刀切”，主要看**坏果产生的时间点、原因和举证**。可以按下面几个层面判断：

## 一、先看责任主体

### 1. 商家/平台责任
如果属于以下情况，一般由商家或平台承担主要责任：

- 发货时水果已经不新鲜、有暗伤、熟度过高
- 包装不当，运输中挤压、闷坏
- 冷链断裂，比如该冷藏的没冷藏
- 承诺“坏果包赔”或“到货坏果赔付”
- 页面宣传与实际到货品质明显不符

这种情况下，顾客可以要求：
- 补发
- 退款
- 按坏果比例赔付
- 若涉及食品安全问题，还可主张相应赔偿

### 2. 物流责任
如果商家发货时是好的，坏果主要是运输环节造成，比如：
- 暴力分拣
- 运输延误导致腐烂
- 冷链中断
- 快递存放不当

那么商家通常先对顾客负责，之后再向物流追偿。也就是说，**顾客一般不需要直接找物流扯皮**，除非是顾客自己叫的快递或自提方式特殊。

### 3. 顾客责任
如果坏果是顾客原因造成，比如：
- 收货后长时间未取
- 未按要求冷藏
- 放置多天后才投诉
- 自己二次搬运导致损坏

这种情况下，商家可以不赔或只部分赔。

### 4. 不可抗力或自然损耗
水果属于易腐商品，轻微磕碰、个别软化、成熟度差异，有时属于合理损耗。但“合理损耗”不等于大量坏果。若坏果比例明显超出正常范围，仍应赔付。

## 二、关键判断标准

实际处理时，通常看这几点：

1. **签收时间**
   - 到货后立即或短时间内反馈，顾客更有利。
   - 放了两三天才说坏，责任认定会变难。

2. **坏果比例和程度**
   - 个别轻微磕碰：可能算正常损耗。
   - 大量腐烂、发霉、异味：通常商家责任。

3. **是否有开箱证据**
   - 开箱视频、照片、快递面单、坏果特写很重要。
   - 能证明是“到货即坏”，而不是存放后坏。

4. **商品承诺**
   - 是否标注“坏果包赔”“冷链发货”“次日达”等。
   - 有承诺的，按承诺执行。

5. **保存方式**
   - 需要冷藏的水果，顾客是否及时冷藏。
   - 是否按说明存放。

## 三、常见责任划分结果

| 情形 | 责任倾向 |
|---|---|
| 到货即大量腐烂、发霉 | 商家/平台主责 |
| 运输挤压、包装差导致坏果 | 商家先赔，再找物流 |
| 个别轻微碰伤、成熟软化 | 可能算正常损耗，协商部分赔 |
| 顾客延迟取货、未冷藏 | 顾客主责或自担 |
| 页面承诺坏果包赔 | 按承诺赔 |
| 无法判断原因 | 通常按协商或平台规则处理 |

## 四、顾客维权建议

1. **尽快拍照/录视频**
   - 快递外包装、面单、开箱过程、坏果细节都要拍。

2. **及时联系商家或平台**
   - 不要拖太久，最好到货当天或次日反馈。

3. **保留证据**
   - 聊天记录、订单截图、物流信息、照片视频。

4. **先协商，再投诉**
   - 协商不成可找平台客服。
   - 仍不解决可向12315、消协投诉。

5. **不要轻易扔掉坏果**
   - 在赔付完成前，最好保留实物或完整证据。

## 五、商家处理建议

1. 明确售后规则：坏果比例、赔付标准、举证时限。
2. 要求顾客提供开箱证据，避免“事后坏果”纠纷。
3. 改善包装和冷链，降低运输坏果率。
4. 对小额纠纷可快速赔付，降低客服和平台处罚成本。
5. 与物流约定破损、延误、冷链责任，便于后续追偿。

## 六、一句话结论

**如果是到货时就坏、且不是顾客保存不当，通常由商家/平台承担赔付责任；商家再根据运输合同向物流追偿。若是顾客收货后保存不当或延迟处理，则顾客承担相应责任。具体按坏果比例、时间、证据和平台规则来划分。**
