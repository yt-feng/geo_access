批发档口拓展餐饮客户，选品规格要围绕餐厅/茶饮/烘焙的**用量、加工方式、损耗控制**来定，而不是按零售习惯。菠萝和香蕉的推荐规格如下：

## 菠萝

餐饮客户主要用途：鲜切果盘、果汁/茶饮、菠萝炒饭、烘焙馅料、烧烤。

| 用途 | 推荐规格 | 说明 |
|---|---|---|
| 茶饮/果汁店 | 单果1.2–1.8斤，成熟度7–8成，可整箱或按个 | 出汁率高，方便门店自行去皮 |
| 餐厅果盘/甜品 | 单果1.5–2.5斤，成熟度8成 | 果形周正、切开好看 |
| 炒饭/烘焙/加工 | 大果2.5斤以上或直接供**去皮菠萝块/菠萝丁** | 加工厂/中央厨房更认净果 |
| 烧烤/泰餐 | 中等果，可带皮整只 | 对半烤、做菠萝饭 |

关键点：
- 餐饮更看重**稳定供货和出成率**，同一规格长期稳定比偶尔大果更重要。
- 可搭售**去皮菠萝**，毛利更高，也绑定客户。
- 菠萝有季节差（主要看产地：广东、海南、菲律宾、台湾等），要提前说明产季切换。

## 香蕉

餐饮客户主要用途：果盘、奶昔/饮品、烘焙、早餐、炸香蕉。

| 用途 | 推荐规格 | 说明 |
|---|---|---|
| 茶饮/奶昔 | 中果，单根120–150g，成熟度刚好 | 出肉稳定，好打泥 |
| 餐厅果盘 | 中到大果，单根150–200g，外观整齐 | 卖相优先 |
| 烘焙/加工 | 大果或直接供**冷冻香蕉泥/香蕉块** | 加工客户更看净重和稳定 |
| 早餐/食堂 | 中果，按箱走量 | 价格敏感，重性价比 |

关键点：
- 香蕉最大的痛点是**成熟度控制**，餐饮客户怕"今天太生、明天全黑"。要能按客户节奏供**不同成熟度批次**（青、微黄、熟）。
- 建议主推**中果稳定货源**，再配少量大果给果盘客户。
- 有条件的可做**催熟/分拣**，这是拉开和普通档口差距的地方。

## 给你的落地建议

1. **先分客户类型**：茶饮、正餐、烘焙、食堂，规格需求完全不同，别用一套货打天下。
2. **主推2–3个标准规格**，如菠萝"1.5斤果""去皮块"，香蕉"中果""大果"，方便客户下单。
3. **打样+试供**：先小批量送样，谈稳定周供，餐饮客户一旦用顺很少换。
4. **准备净果/半成品**（去皮菠萝、香蕉泥）作为增值项，提升粘性和利润。
