连锁超市和水果供应商签年度合同，最容易踩的坑集中在“价格机制、损耗责任、验收标准、账期与返利、独家/排他、不可抗力”六块。下面按可执行要点说明，并给出建议写法。

**1. 价格机制：别只锁“年度价”**
水果价格波动大，只写固定年度价，遇到减产涨价供应商易断供，遇到丰收降价超市又吃亏。
- 建议：约定“基准价+浮动机制”，例如按批发市场周均价或产地收购价指数联动，明确调价周期（周/月）、触发幅度（如±5%）、确认方式（书面/邮件）。
- 坑：只写“随行就市”，无指数、无确认流程，等于没约定。

**2. 损耗与质量责任：到店前还是到店后**
水果损耗高，责任划分不清最常见。
- 建议：明确“验收前损耗由供应商承担，验收后由超市承担”，并写清验收时限（如到货2小时内）、验收标准（糖度、大小、成熟度、农残报告）。
- 坑：写“按实际损耗分摊”但无分摊比例、无第三方检测，后期扯皮。

**3. 验收标准：必须可量化**
- 建议：按品类写规格，如单果重、果径、色泽、糖度、允许瑕疵率（如≤3%）、包装方式、冷链温度。
- 坑：只写“符合国家质量标准”，太笼统，无法拒收或索赔。
- 建议附“验收单模板”和“拒收/换货/扣款”流程。

**4. 账期与返利：现金流和隐形费用**
- 建议：明确账期起算点（收货验收合格后）、付款方式、逾期利息；返利写清计算基数（含税/不含税）、达成条件、结算时间。
- 坑：账期写“月结30天”但起算点模糊；返利写“年度返点”但未写未达标是否补差、是否可抵扣货款。

**5. 独家/排他：别把自己锁死**
- 建议：若签独家，必须约定最低采购量、价格保护、断供违约责任；若不想被锁，写“非独家，超市可多渠道采购”。
- 坑：只写“供应商为超市唯一水果供应商”，但无最低量、无退出机制，供应商涨价或断供时超市很被动。

**6. 不可抗力与断供：要可操作**
- 建议：列明不可抗力情形、通知时限、证明文件；约定断供时的替代采购权、差价索赔权。
- 坑：不可抗力条款过宽，供应商可借“天气原因”随意不供货。

**7. 其他易踩坑条款**
- 质量索赔：写清检测机构、索赔时限、扣款方式。
- 退换货：临期、滞销、品质不达标是否可退，退货运费谁承担。
- 知识产权/品牌：若涉及贴牌，写清商标归属。
- 合同期限与续约：写清自动续约条件、提前终止通知期。
- 争议解决：管辖法院或仲裁机构要明确，避免异地诉讼成本。

**建议动作：**
1. 先定“验收标准+价格联动+损耗责任”三项，这是水果合同核心。
2. 所有调价、验收、扣款、返利都要求书面或邮件确认，避免口头。
3. 签前让采购、财务、法务一起过一遍，重点看账期、返利、独家、断供。
4. 保留验收单、检测报告、沟通记录，作为后续索赔依据。
