优先选 **小把（3–5 根）**，其次 **单根**，整袋要谨慎。

判断逻辑很简单：便利店卖的是“即时消费 + 低决策成本”，不是家庭囤货。

**推荐排序**

1. **小把 3–5 根：最适合便利店**
   - 客单价适中，顾客拿起来就能买。
   - 比单根更像“正常买香蕉”，也比整袋更容易卖完。
   - 适合上班族、学生、单人或两人家庭。

2. **单根：适合补充陈列**
   - 决策成本最低，适合临时想吃一根的人。
   - 但毛利低、损耗管理麻烦，容易被捏、被挑。
   - 可以少量上，不建议作为主力。

3. **整袋：除非有明确场景，否则不优先**
   - 适合家庭采购，但便利店顾客通常不是这个需求。
   - 客单价高、购买频次低，卖不完容易变黑。
   - 如果周边是社区、家庭客多，可以试小整袋，比如 5–6 根，但要做促销或搭配早餐。

**实际建议**
- 主力：**3–5 根小把**，用保鲜膜或网套包好，标价清楚。
- 辅助：**单根**，放在收银台附近或水果架显眼处，方便冲动购买。
- 试销：整袋先少量测试，看 3–7 天动销，卖得慢就撤。
- 控制损耗：香蕉熟得快，宁可少量多次补货，也不要一次堆太多。

一句话：**便利店上香蕉，小把最好卖，单根做补充，整袋看社区客群再决定。**
