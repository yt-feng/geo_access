核心思路是把“买什么状态的香蕉”和“怎么用”管起来，而不是等它熟过头再救。

**采购端**

- 买青一点的香蕉。食堂用量大、周转快，采购时选“七成熟左右、果皮青绿、手感硬”的香蕉，回库后自然转黄，正好在几天内陆续可用完。
- 控制单次采购量。按前几天的实际消耗估算，宁可勤补货，不要一次囤太多。香蕉后熟很快，一次买两三天的量通常比买一周的更稳。
- 分批采购。同一批里可以一部分偏青、一部分偏黄，错开成熟时间，避免同一时间全熟。

**储存端**

- 不要冷藏未熟的香蕉。低温会冻伤、发黑，成熟反而更不均匀。
- 想延缓成熟，放在阴凉通风处，避免堆压、避免阳光直射。
- 把已经熟的和还青的分开存放。熟香蕉会释放乙烯，催熟旁边的青香蕉。
- 需要明显延缓时，可用保鲜膜包住香蕉根部（果柄），减少乙烯扩散，但效果有限，主要还是靠控制采购量和周转。

**使用端**

- 快到最佳食用期还没卖完/用完的，提前转到加工环节：做香蕉奶昔、香蕉面包/蛋糕、香蕉粥、水果捞等，熟度高的反而更适合。
- 和档口联动，临近成熟高峰时多安排含香蕉的菜品或加餐，加快消耗。
- 制定简单的“熟度分级”：青的摆卖，微熟的优先出餐，很熟的直接进加工，避免整批一起报废。

**最关键的一条**：算清“从到货到用完需要几天”和“这批香蕉几天会全熟”，让采购周期短于或等于消耗周期。只要周转快，浪费就会大幅下降。
