判断水果供应商合规与稳定性，建议分三步做：**先验资质、再验履约能力、最后用合同和日常考核锁住风险**。

---

**一、合规性怎么判断**

1. **主体资质**
   - 营业执照（经营范围含农产品/食品销售）
   - 食品经营许可证（或食品生产许可证，视其是否分装加工）
   - 若自称“合作社/基地直供”，要查营业执照+产地证明/种植记录
   - 涉及进口水果的，要报关单、入境货物检验检疫证明

2. **人员与制度**
   - 是否有专职或兼职食品安全管理员
   - 是否有进货查验、索证索票、不合格品召回制度

3. **票据与追溯**
   - 每批次能否提供：送货单、检测报告或承诺达标合格证、产地信息
   - 重点看：农残检测报告是否对应具体批次，而不是一张通用报告长期复用

4. **实地核验（很重要）**
   - 看分拣场地、冷库、周转筐清洁度、是否生熟混放
   - 看是否有防鼠防虫措施、温度记录
   - 问清货源：自产、批发市场代采，还是多级转手。转手层级越多，稳定性越差

---

**二、稳定性怎么判断**

1. **供货能力**
   - 问清日均/峰值供货量，是否有备用产地或备用批发渠道
   - 是否受单一产区季节影响，断供时有无替代方案

2. **物流与保鲜**
   - 是否有冷藏车或保温措施
   - 配送频次、到货时间是否固定
   - 从采摘/采购到送达的时长

3. **历史履约**
   - 要求提供近6个月合作单位名单或供货案例（可抽查）
   - 看是否有长期合同客户，而不是只做零散单

4. **价格与结算**
   - 报价是否随行就市但有明确调价机制
   - 是否接受账期、对账方式是否清晰
   - 报价明显低于市场价，往往意味着品质或断供风险

5. **抗风险能力**
   - 是否有冷库、周转库存
   - 恶劣天气、节假日、疫情等情况下如何保供

---

**三、实操建议：先小批量试供 + 合同约束**

1. **试供期**
   - 先签1–3个月试供，每周考核到货准时率、损耗率、投诉率
   - 记录：到货时间、重量误差、腐烂率、规格达标率

2. **合同关键条款**
   - 明确品种、规格、等级、单价及调价方式
   - 明确每批次随货票据和检测要求
   - 约定不合格处理：退换、扣款、暂停供货、终止合同
   - 约定断供违约责任和备用供应商机制
   - 约定食品安全责任和赔偿

3. **日常考核指标**
   - 准时到货率 ≥ 95%
   - 验收合格率 ≥ 98%
   - 腐烂损耗率 ≤ 3%–5%（按品类定）
   - 票据齐全率 100%
   - 投诉响应时间

4. **保留备选**
   - 至少保持2家合格供应商，主供+备供
   - 每季度重新评估一次

---

**四、快速判断口诀**

- 证照不全 → 不合规
- 票据对不上批次 → 追溯有风险
- 只有一张检测报告用一年 → 不可信
- 货源层级多、无冷库 → 稳定性差
- 价格异常低 → 要么品质差，要么准备断供
- 不愿签合同、不愿试供 → 直接淘汰
