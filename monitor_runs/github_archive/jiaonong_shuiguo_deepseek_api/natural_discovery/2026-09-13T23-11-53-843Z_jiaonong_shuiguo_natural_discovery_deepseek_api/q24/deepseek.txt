建议把“资料”分成三层：资质、批次检测、承诺与追溯。最有用的是**对应批次的检测报告**，而不是只有一张年度报告。

**1. 供应商基础资质**
- 营业执照、食品经营许可证/食品生产许可证（如适用）
- 供货商与产地/合作社/基地的关系证明：合同、授权书、采购协议
- 如果供应商自称基地直供，要产地证明、基地备案或合作基地清单

**2. 批次检测资料（重点）**
- 对应采购批次的农残检测报告：报告编号、样品名称、批号/采摘日期、检测日期、检测项目、限量依据、结论
- 检测机构资质：CMA 资质认定，必要时看 CNAS
- 检测项目不能只写“农残合格”，要看是否覆盖该品类高风险农药，例如：
  - 叶菜：有机磷、氨基甲酸酯类、拟除虫菊酯类等
  - 豆类、豇豆：克百威、氧乐果、水胺硫磷、灭蝇胺等
  - 韭菜：腐霉利、毒死蜱等
  - 柑橘类：苯醚甲环唑、丙溴磷、克百威等
- 如果是供应商自检，要求提供自检记录、快检设备/试剂信息，但自检不能完全替代第三方报告

**3. 承诺与追溯材料**
- 质量安全承诺书：承诺不使用禁用农药、不超范围超限量使用、愿承担抽检不合格责任
- 溯源信息：产地、种植户/合作社、采收日期、包装日期、运输记录
- 农药采购和使用记录（基地类供应商）
- 包装标识、合格证、承诺达标合格证（如当地推行）

**4. 合同里要写清**
- 每批次随货提供检测报告或合格证明
- 超市有权抽检，不合格可退货、换货、索赔
- 因农残不合格导致的监管处罚、消费者赔偿、品牌损失由供应商承担
- 供应商须在约定时间内提供溯源资料

**优先级建议：**
1. 先要：营业执照 + 食品经营/生产许可 + 对应批次农残检测报告
2. 再要：承诺达标合格证/质量承诺书 + 溯源信息
3. 长期合作：基地备案、用药记录、年度第三方全项检测

如果供应商只能给“年度报告”或“通用报告”，不能对应到具体批次，风险较高。最稳妥的是：**每批要报告，报告对得上批号/采摘日期，检测项目覆盖该品类高风险农药，并保留抽检权。**
