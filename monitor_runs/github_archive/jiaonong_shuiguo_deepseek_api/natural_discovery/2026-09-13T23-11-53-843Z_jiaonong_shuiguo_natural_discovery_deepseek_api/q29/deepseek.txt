超市和水果供应商的账期没有统一标准，主要看**谁强势、品类特性、结算方式**。常见情况大致如下：

**1. 连锁商超（大卖场/全国性超市）**
- **30～60天**最常见，部分强势系统会做到 **60～90天**。
- 如果是代销或联营，往往按**月结**，实际账期可能达到 **45～75天**。
- 大型KA（如永辉、大润发、华润万家等）对中小供应商，60天左右比较普遍；强势平台可能更长。

**2. 区域超市/中小连锁**
- **15～30天**比较常见，部分现结或周结。
- 本地水果供应商议价能力较强时，可能做到 **7～15天**。

**3. 水果品类特殊因素**
- 水果损耗高、周转快，供应商通常希望账期短。
- 进口水果、精品水果：供应商强势，可能 **现结或15天内**。
- 大宗普通水果：超市强势，**30～60天**更常见。
- 夏季高温易腐品类，供应商往往要求 **7～15天**甚至现结。

**4. 常见结算方式**
- **现结/货到付款**：供应商强势或新合作试单。
- **周结**：7天、14天。
- **半月结**：15天。
- **月结**：30天，但常按“对账后30天”执行，实际可能45天左右。
- **月结60天/90天**：大型超市对弱势供应商常见。

**5. 实操建议**
- 新供应商合作，先谈 **15～30天**，比一上来60天更容易成交。
- 如果超市要求60天以上，可以争取：
  - 缩短到 **45天**；
  - 或部分现结、部分账期；
  - 或提高供货价、降低促销扣点来补偿资金占用。
- 合同里要写清：**对账日、开票日、付款日、逾期违约金**。很多“30天账期”实际是从对账或开票后起算，不是送货后起算。

**一句话总结：**
- 中小超市：**15～30天**常见；
- 大型连锁：**30～60天**常见，强势的 **60～90天**也有；
- 水果供应商如果议价能力弱，容易被压到 **45～60天**；如果品类稀缺或易损，通常能谈到 **15～30天甚至现结**。
