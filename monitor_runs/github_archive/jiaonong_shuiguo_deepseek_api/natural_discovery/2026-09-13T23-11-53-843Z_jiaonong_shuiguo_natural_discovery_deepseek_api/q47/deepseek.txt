茶饮店采购香蕉，核心不是“买最熟的”，而是**按用途分层控制熟度**：后厨加工用、装饰用、直接售卖用，标准不同。

**1. 先按用途定熟度**

- **打泥/做基底**：用 **7–8 成熟**，果肉软但有弹性，甜度不够可补糖。太生涩、太熟易发黑发酸。
- **做奶昔/冰沙**：用 **8–9 成熟**，香气足、甜度高，打出来顺滑。
- **装饰切片/摆盘**：用 **6–7 成熟**，果肉硬挺，切片不烂，氧化慢。
- **烘焙/香蕉蛋糕**：用 **9–10 成熟**，表皮出现黑斑，甜度和香气最高。

**2. 采购时看这几个判断点**

- **表皮**：青黄=6成左右；全黄=8成；黄带少量黑斑=9成；大面积黑斑=10成。
- **手感**：轻捏有弹性=适中；硬=生；一按就凹=过熟。
- **果柄**：发黑、干缩说明放久了。
- **气味**：有明显酒味或酸味，不要用于直接出品。

**3. 采购策略**

- **不要一次只买一个熟度**。建议按“**当天用 + 1–2天后用 + 3–4天后用**”搭配采购。
- 当天打泥/奶昔：买 8–9 成熟。
- 装饰用：买 6–7 成熟，到店后常温或冷藏慢慢转熟。
- 烘焙用：单独买 9–10 成熟，或把快过熟的香蕉专门留用。
- 夏天熟得快，采购熟度整体下调半级到一级；冬天可适当买熟一点。

**4. 到店后的熟度管理**

- **未熟**：常温避风存放，不要直接冷藏，否则容易“僵熟”。
- **将熟**：和苹果/梨一起放纸袋或保鲜袋，可加速后熟。
- **已熟**：冷藏延缓，但表皮会变黑，果肉仍可用；最好 1–2 天内用完。
- **过熟**：去皮分装冷冻，做奶昔、果泥、烘焙，不要继续常温放。

**5. 简单执行标准**

- 装饰：6–7 成，硬挺。
- 奶昔/果泥：8–9 成，香甜。
- 烘焙：9–10 成，黑斑。
- 采购：按 3 天用量分批，熟度错开。
- 验收：青黄、硬、无酒味=可收；黑斑多、软烂、酒味=拒收或只能做烘焙。

一句话：**按出品倒推熟度，采购时错开批次，到店后分熟度存放。**
