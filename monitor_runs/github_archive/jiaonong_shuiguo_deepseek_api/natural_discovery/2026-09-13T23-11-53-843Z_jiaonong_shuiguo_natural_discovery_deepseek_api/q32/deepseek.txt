判断的核心不是听供应商口头承诺，而是**用产地结构、产能数据和历史交付记录去验证他有几个“篮子”**。香蕉是典型的季节性+区域性作物，单一产地几乎不可能全年稳定供货。

## 一、先问清三个关键问题

**1. 你的货源来自几个产地？**
- 只报一个产地（如只做海南或只做菲律宾）：**全年稳定供货基本不可信**，淡季必然断。
- 靠谱的结构通常是多产地接力：国产（海南/广西/云南）+ 进口（菲律宾/厄瓜多尔/越南/柬埔寨），按季节切换。

**2. 各产地的上市窗口覆盖哪几个月？**
让对方列出每个产地的具体上市月份，你把它拼成一张全年日历。如果中间有断档（比如 3—4 月、或国产结束后进口未接上），那就是风险点。

**3. 是自有基地、合作社还是纯贸易商？**
- 自有/长期合作基地 → 可控性强
- 纯贸易商 → 要看他能不能同时调动多个上游，抗风险能力更依赖他的渠道网络

## 二、验证供应能力的硬指标

| 考察项 | 判断标准 |
|---|---|
| 年供货量 | 是否明显大于你要的采购量（留出余量，建议供应商产能≥你需求的1.5倍以上） |
| 历史交付记录 | 要过去1—2年的发货台账/对账单，看有没有断供、延期 |
| 冷库/催熟能力 | 香蕉需催熟，看他有没有催熟库、日处理量是否匹配 |
| 产地切换预案 | 主产地受灾/涨价时，备用货源在哪、多久能切换 |
| 同类型客户 | 是否在给其他连锁超市稳定供货，可侧面核实 |

## 三、必须做的实测动作（别只看材料）

1. **要淡季样品试单**：旺季谁都能供，专门挑他声称的“最紧张月份”下小单，看能否按时按质交付。
2. **实地/视频验厂**：看加工线、冷库、催熟房是否真实存在，产能是否对得上。
3. **查产地靠不靠谱**：核心产地是否为真实主产区，可交叉核对公开的产区上市信息。
4. **签合同锁条款**：把全年分月供货量、断供违约责任、替代产地切换义务写进合同，用违约成本倒逼稳定性。

## 四、一句话结论

**只有“多产地接力 + 产能有余量 + 有淡季实交付记录 + 合同兜底”四条同时满足，才敢认定能全年稳定供货。** 单产地、纯口头、无淡季试单的，一律按“不能全年稳定”对待。
