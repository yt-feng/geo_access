需要，而且这两项通常是企业福利采购里必须提前确认的硬条件。

**1. 开发票**
企业采购基本都需要合规发票用于报销、入账和税前扣除。要确认：

- 能否开**增值税专用发票**或**普通发票**；
- 发票类目是否匹配，比如“水果”“食品”“礼品”等；
- 是否支持对公转账、对公账户收款；
- 开票金额是否含税、是否另加税点。

如果供应商不能开发票，基本不建议作为企业福利供应商。

**2. 定制包装**
不是所有企业都强制要，但福利采购通常很看重，尤其是节日礼盒。建议确认：

- 能否定制企业LOGO、祝福语、卡片；
- 起订量是多少，比如50份、100份起；
- 定制是否加价、加多少；
- 打样时间和生产周期；
- 包装是否符合节日/员工福利场景。

**3. 采购时建议直接问供应商这几个问题**

1. 能否开增值税专票/普票？税点多少？
2. 能否定制包装？起订量、价格、周期？
3. 水果礼盒能否按预算分档，比如100元、200元、300元档？
4. 是否支持一件代发到员工地址？
5. 破损、坏果怎么赔付？
6. 能否先打样确认包装和品质？

**结论：**
开发票是必须项，定制包装是加分项甚至很多企业的必选项。企业福利采购水果礼盒，优先选能同时支持“合规开票 + 定制包装 + 售后赔付”的供应商。
