想在超市买到“到家就能吃”或“放两三天刚好”的香蕉，关键是按**用途选颜色**，而不是只看大小。

1. **当天吃：选黄皮带少量褐点**
   - 最好选通体金黄、果柄还略青、表面有 1～3 个小黑点。
   - 这种通常已经软甜，到家就能吃。
   - 黑点很多、连成片，说明过熟，可能已经发酸或烂心。

2. **2～3 天后吃：选黄中带绿**
   - 选整体偏黄，但两端和果柄附近还带绿色。
   - 室温放 2～3 天会刚好成熟。
   - 如果超市冷气足、香蕉摸起来很硬，成熟会慢一点。

3. **4～5 天后吃：选偏绿、硬实**
   - 选绿色明显、捏起来硬、没有压伤。
   - 回家别放冰箱，室温催熟；想快一点，和苹果或梨装一个袋子里。
   - 一旦开始变黄，就要每天检查，避免突然过熟。

4. **千万别买的几种**
   - 果柄发黑、发霉。
   - 表皮大面积暗褐、软塌、渗水。
   - 有酒味、酸味。
   - 整串局部压伤发黑，会很快传染其他香蕉。

5. **到店判断小技巧**
   - **捏果柄**：果柄硬，说明还生；果柄软但果身不软，通常接近成熟。
   - **看棱角**：香蕉越圆越熟，棱角分明通常还生。
   - **看两端**：两头青说明还能放；两头黄甚至发黑说明熟得快。
   - **别选冷柜里的**：低温会让香蕉皮变黑，但里面可能还是生的，成熟不均匀。

6. **买回家后怎么控熟**
   - 想慢点熟：拆开、挂起来、通风、室温放，别闷在塑料袋里。
   - 想快点熟：和苹果/梨一起放纸袋里，室温催。
   - 已经熟了：剥皮冷冻，或冷藏 1～2 天延缓过熟；冷藏后皮会变黑，但果肉通常还能吃。

一句话：**当天吃选黄带点；两三天吃选黄带绿；想多放选青硬；有黑斑、酒味、压伤别买。**
