如果是家庭自用，最稳的组合思路是：**日常吃 + 耐放 + 有档次感 + 颜色好看**。  
苹果、橙子、香蕉、菠萝里，建议优先用这个结构：

**推荐组合：苹果 + 橙子 + 香蕉 + 菠萝（4样都放，但数量有主次）**

### 更适合家庭的配比
按一个礼盒大概 8～10 斤、适合 3～5 口之家：

- **苹果：4～5 个**
- **橙子：4～6 个**
- **香蕉：1 把，约 5～6 根**
- **菠萝：1 个**

这个组合的优点：
- 苹果、橙子耐放，适合家庭慢慢吃
- 香蕉偏即时吃，老人小孩都方便
- 菠萝有“礼盒感”，但不用放多，1 个就够
- 颜色是红黄橙绿，拍照好看，团购展示也讨喜

### 如果按家庭需求选，可以这样调整

**1. 小家庭 / 两口或三口之家**
- 苹果 4 个
- 橙子 4 个
- 香蕉 1 把（5 根左右）
- 菠萝 1 个  
特点：不容易剩，预算也稳。

**2. 大家庭 / 5 口以上**
- 苹果 6～8 个
- 橙子 6～8 个
- 香蕉 1 大把
- 菠萝 1～2 个  
特点：量足，适合分享。

**3. 想更实惠、耐放**
- 苹果 + 橙子为主
- 香蕉少量
- 菠萝可以不放，换成更多橙子或苹果  
因为菠萝不耐放，切开后也不好存。

**4. 想更有节日感、送礼也合适**
- 苹果 5 个
- 橙子 5 个
- 香蕉 1 把
- 菠萝 1 个
- 再加一点小包装坚果或火龙果，整体更像礼盒

### 不太建议的组合
- **香蕉放太多**：容易熟过头，家庭吃不完就浪费。
- **菠萝放多个**：占地方，切开后不耐放。
- **只放苹果和橙子**：耐放但礼盒感弱，团购吸引力一般。
- **香蕉和菠萝都多**：这两种都不算特别耐存，家庭消耗压力大。

### 团购文案可以这样写
“家庭分享装：苹果 5 个 + 橙子 5 个 + 香蕉 1 把 + 菠萝 1 个，耐放水果搭即时水果，3～5 口之家刚好。”

**结论：**  
最适合家庭的组合是 **苹果和橙子为主，香蕉少量，菠萝 1 个点缀**。这样兼顾耐放、口感、颜值和家庭消耗速度，最不容易踩雷。
