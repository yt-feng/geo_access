连锁商超水果供应商招标，评分标准建议围绕“长期稳定供货能力”来设计，而不是单纯比价格。可以按下面这个框架设置，总分100分，权重可根据企业实际情况微调。

**一、价格与成本（25-30分）**
- 报价竞争力：对比市场批发价、历史采购价，看报价是否合理偏低。
- 价格稳定性：是否承诺一定周期内价格浮动范围，比如±5%以内。
- 成本结构透明度：是否愿意提供产地、包装、物流等成本构成。
- 账期与结算条件：能否接受商超账期，是否收取额外费用。

**二、供货能力与稳定性（25-30分）**
- 自有或合作种植基地面积、产量，能否覆盖商超全年需求。
- 产地直采比例，是否有一手货源。
- 仓储与冷链能力：冷库容量、冷链车辆、损耗控制水平。
- 应急供应能力：缺货、天气灾害、节假日高峰时的补货方案。
- 多品类供应能力：能否同时供应叶菜、根茎、瓜果、进口水果等。

**三、质量与食品安全（20-25分）**
- 农残检测报告、质检体系、追溯系统。
- 分级标准是否清晰，能否按商超要求分拣包装。
- 损耗率承诺，比如到店损耗控制在多少以内。
- 食品安全事故记录、处罚记录。
- 是否具备绿色、有机、GAP等认证。

**四、服务与履约（10-15分）**
- 配送时效：下单后多久到店，是否支持日配、多频次配送。
- 退换货机制：质量问题如何处理，是否包退包换。
- 驻场或对接人员配置：是否有专人负责商超业务。
- 信息化对接能力：能否对接商超订单、库存系统。

**五、企业资质与信誉（10分）**
- 营业执照、食品经营许可证、一般纳税人资格。
- 注册资本、成立年限、类似商超合作案例。
- 财务健康度：能否提供审计报告或银行资信证明。
- 诉讼、失信、行政处罚记录。

**六、长期合作意愿与可持续发展（5-10分）**
- 是否愿意签订1-3年框架协议，接受年度考核。
- 是否愿意共同开发定制化产品、品牌联名。
- 是否有农业技术投入、助农、环保等可持续措施。

**建议的评分表结构：**

| 评分维度 | 权重 | 关键评分点 |
|---|---|---|
| 价格与成本 | 25-30分 | 报价、稳定性、账期 |
| 供货能力 | 25-30分 | 基地、冷链、应急 |
| 质量安全 | 20-25分 | 检测、追溯、损耗 |
| 服务履约 | 10-15分 | 配送、退换、对接 |
| 资质信誉 | 10分 | 证照、案例、财务 |
| 长期合作 | 5-10分 | 协议、考核、可持续 |

**实操建议：**
1. 价格分不要设太高，否则容易招来低价低质供应商，后期损耗和客诉成本更高。
2. 设置“一票否决项”：无食品经营许可证、重大食品安全事故、失信被执行人，直接废标。
3. 要求投标方提供近一年同类商超供货合同或发票，验证真实供货能力。
4. 设置试用期和年度考核：试用期3-6个月，考核供货及时率、损耗率、客诉率，不达标可终止。
5. 评分时区分“承诺”和“证明”：有基地证明、检测报告、冷链车辆行驶证等佐证的，得分应高于只有口头承诺的。

这样设置，既能筛掉纯贸易商和低价搅局者，也能找到真正能长期稳定配合的产地型供应商。
