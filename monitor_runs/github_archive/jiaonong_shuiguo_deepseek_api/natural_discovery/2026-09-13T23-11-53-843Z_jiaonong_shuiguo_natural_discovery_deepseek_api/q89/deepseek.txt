对价格敏感的团购客户，**多数情况下优先用阶梯价，返利作为补充**。核心判断标准是：客户是否愿意且有能力“先垫资、后拿返还”，以及你要的是“立刻降价感知”还是“长期绑定”。

**1. 阶梯价更适合什么情况**
- 客户价格敏感、决策快，看到“买100件单价8元，买300件单价6.5元”能立刻算清账。
- 客户不愿承担返利的不确定性，担心年底拿不到、流程复杂。
- 你的目标是**当场刺激放大单量**，缩短成交周期。
- 商品标准化、毛利空间清晰，可以直接按量让价。

优点：感知强、成交快、规则简单。
缺点：一旦给出去就是永久性底价，后续涨价难；客户容易只盯着最低档，甚至拆单比价。

**2. 返利更适合什么情况**
- 客户是长期合作、年度采购量可预测的团购方，比如企业福利、物业、学校、协会。
- 你不想直接击穿价格体系，希望**保护挂牌价和渠道价格**。
- 你想绑定客户全年采购，而不是单次冲量。
- 你有能力设置返利门槛、考核维度和结算周期。

优点：保价、绑长期、可设计“达量返”“季度返”“新品推广返”。
缺点：价格敏感客户对“先按原价买、后面再返”接受度低；现金流压力在客户侧；规则复杂容易引发纠纷。

**3. 更实用的组合做法**
- **前台阶梯价，后台返利**：小批量给阶梯价，让客户马上有感；达到年度/季度目标后再给返利，锁长期。
- **阶梯价设“可见档”，返利设“隐藏档”**：避免所有客户都拿到最低价。
- **返利不要只返钱**：可以返下次采购抵扣券、物流补贴、陈列费、专属新品，既保价又促复购。
- **设置双向约束**：返利与回款、退货率、窜货、最低采购频次挂钩，避免只压价不贡献。

**4. 快速判断表**
- 客户只做一单、比价凶、要立刻低价：**阶梯价**。
- 客户长期采购、要稳定供应、你怕乱价：**返利**。
- 客户价格敏感但又想长期合作：**阶梯价打底 + 返利锁年框**。
- 你的毛利很薄、现金流紧：**少用返利，多用阶梯价但设高门槛**。
- 你的品牌需要控价、有多个渠道：**返利优先，阶梯价谨慎**。

**结论**：如果只能选一个，价格敏感的团购客户先用**阶梯价**成交；如果客户有长期量且你要保价，用**返利**。最稳的是“阶梯价负责首次成交，返利负责长期绑定”，但规则必须简单、可算、可兑现。
