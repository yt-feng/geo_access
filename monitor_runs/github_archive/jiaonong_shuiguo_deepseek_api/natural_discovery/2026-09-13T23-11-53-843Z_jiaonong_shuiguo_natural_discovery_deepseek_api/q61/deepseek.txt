判断批发档口能不能稳定供香蕉，核心不是听对方怎么说，而是看**货源基础、履约记录、风险承受和合作机制**。可以按下面几步快速筛选。

**1. 先看对方是不是“真一手”**
- 问清香蕉来自哪里：是自有基地、长期包园，还是从产地市场倒手。
- 要求看**产地照片/视频、装车视频、包装厂或催熟库**，不是只发一张香蕉图。
- 问**日供应量、可选等级、可稳定供几个月**。稳定供货的人通常能说清：旺季、淡季、台风季分别怎么供。
- 如果对方什么规格都能供、价格还明显低于市场，大概率是中间商或临时拼货。

**2. 查履约记录**
- 让对方提供**最近3个月的发货记录**：装车单、物流单、过磅单、收款记录，敏感信息可打码。
- 问**固定客户有哪些类型**：超市、水果店、二级批发商。有长期固定客户，比只做散单更稳。
- 重点问：**断货过没有、为什么断、怎么补**。稳定供货的人不会回避问题，会讲清产地天气、节假日、运输延误等风险。
- 可以侧面打听：问对方合作过的物流司机、包装工、同行档口。

**3. 小单试合作**
- 先做**1-2车小批量试单**，不要一上来签大额长期合同。
- 试单看四点：**到货时间、实际重量、青黄成熟度、坏果率**。
- 连续试2-3次，观察**报价是否随行就市但不过分离谱、装车是否按时、售后是否认账**。
- 如果第一次就出现严重催熟不均、缺斤少两、拖延发货，基本可以淘汰。

**4. 看风险承受能力**
- 稳定供货方通常有**多个产地或多个合作基地**，不会只靠一个园子。
- 问清**台风、寒潮、节假日运输紧张时怎么保供**。
- 有没有**催熟库、冷库、分拣场地**。有加工能力的，比纯倒货的稳。
- 是否接受**定金+尾款、到货验收后结算**等合理账期。只要求全款预付、不接受验货的，风险高。

**5. 用合同或订单锁定关键条款**
- 写清：**品种、等级、单根重量/把重、成熟度、包装、数量、发货时间、验收标准、坏果理赔、缺货补偿**。
- 约定**替代方案**：如果某产地断货，是否能用同等级其他产地补，价格怎么算。
- 约定**违约和售后**：延迟发货、重量不足、质量不达标怎么赔。
- 不要只靠微信口头承诺，至少要有**盖章合同或可追溯的订单确认**。

**6. 几个危险信号**
- 报价长期明显低于市场，还说“要多少有多少”。
- 不肯视频看货、不肯提供装车单、不肯小单试。
- 催你大额打定金，收款账户和公司名称不一致。
- 一追问产地和断货应对就含糊其辞。
- 朋友圈全是盗图，发货视频重复用。

**实操建议：**
先让对方报**未来15天可稳定供应的量、等级和价格**，再要**最近3次发货凭证**，然后下**1车试单**。试单合格后，再谈月度框架。稳定供货不是看他说得多好，而是看**能不能连续三次按时、按质、按量交付**。
