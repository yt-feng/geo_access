生鲜平台做水果一件代发，供应商的仓配能力直接决定履约体验和损耗成本。核心需要具备以下几类能力：

**1. 仓储能力**
- **多温区仓储**：水果品类差异大，需要常温、冷藏（0-8℃）、部分热带水果的保温/防冻区。至少要有冷藏库，且能按品类分区存放，避免乙烯释放型水果（如苹果、香蕉）催熟其他水果。
- **专业保鲜设施**：气调库、预冷设备（差压预冷/真空预冷）对浆果、叶菜类水果很关键，能显著延长货架期。
- **库存管理系统**：WMS要能支持批次管理、先进先出、效期预警，最好能对接平台的订单系统实现库存实时同步，避免超卖。

**2. 加工与分拣能力**
- **分级分选**：按规格、糖度、外观分级，一件代发通常要求标准化包装，规格不统一会直接导致客诉。
- **打包能力**：防震、防压、透气包装，不同水果用不同方案（如草莓用托盘+缓冲、柑橘用网套+纸箱）。需要能按订单单品打包，而非整箱发货。
- **贴标与面单**：能打印平台面单、贴物流标签，支持多平台订单混发。

**3. 配送与物流能力**
- **快递资源**：与顺丰、京东冷链、中通等有稳定合作，能拿到生鲜专线价格。一件代发依赖快递网络，偏远地区时效和覆盖能力要提前确认。
- **冷链配送**：高价值易损水果（樱桃、蓝莓、荔枝）需要冷链快递或泡沫箱+冰袋方案，供应商要能根据目的地和季节选择配送方案。
- **时效承诺**：能保证揽收时效（如下午截单前当天发出），并支持物流轨迹回传。

**4. 订单与系统对接能力**
- **ERP/OMS对接**：能通过API或表格与平台订单系统打通，实现自动接单、自动回传单号。
- **售后处理**：能配合平台处理坏果、漏发、错发，有明确的赔付标准和补发流程。

**5. 品控与损耗管理**
- **到货验收标准**：有明确的收货质检流程，拒收不合格货源。
- **损耗率控制**：一件代发损耗通常要求控制在3%-8%以内（视品类），供应商要有数据追踪和持续优化能力。

**判断供应商是否合格的关键问题：**
1. 有没有冷藏库和预冷设备？面积多大？
2. 能否提供近3个月的一件代发损耗率和客诉率？
3. 快递合作方是谁？偏远地区时效如何？
4. 系统能否API对接，还是只能人工导单？
5. 坏果赔付标准和响应时间是多久？

如果供应商只具备普通仓库+快递发货，没有预冷、分级和冷链能力，建议只合作耐运输品类（如苹果、橙子），易损品类慎用。
