# 问区域保护和串货，核心要问清"边界、责任、处罚、证据"四件事

先给你一个判断标准：**一份靠谱的代理政策，应该能让你明确回答"我能在哪卖、别人越界了厂家怎么管、我被罚了凭什么、申诉找谁"。** 如果对方全是"放心我们会保护你"这种口头承诺，基本等于没有。

下面按你谈判时的实际顺序，给你可以直接照着问的话术和要盯的点。

## 一、先问"区域"的准确定义（最容易被模糊的地方）

- "我代理的区域具体是哪些省/市/县？有没有书面清单或地图？"
- "这个区域是独家还是多家代理？如果多家，各自负责哪块？"
- "我的客户群范围有没有限制？比如我只做批发市场档口，还是也能做商超、电商、社区团购、直播带货？"——**很多串货纠纷，本质是渠道授权没写清，不是真串货。**
- "线上算不算我的区域？厂家自己或别的代理在电商平台卖，算不算串我的货？"

## 二、问"区域保护"到底保什么

- "厂家在我区域内直营/直销吗？会不会自己开旗舰店跟我抢？"
- "厂家给别的区域代理的价格，会不会比我低、然后货流到我这里？"——这是最实际的串货来源。
- "如果我发现本区域有别的代理在卖，厂家承诺多久内处理？（要有天数，不是'尽快'）"
- "保护是只保护'品牌方主动铺的货'，还是也管'别的代理主动串过来'？"

## 三、问"串货的认定和处罚"

- "什么情况算串货？是按货流方向、按销售区域，还是按产品编码追？"
- "你们怎么追溯货源？有没有箱码/瓶码/批次码？"——**没有追溯码的，处罚基本执行不了。**
- "串货一旦认定，对串货方怎么罚？对我这个受害方有没有补偿？"
- "会不会'一刀切'罚我？比如货是从我区域出去的，但实际是二级分销商干的，责任算谁的？"

## 四、问"我自己的义务和风险"

- "我能不能跨区域接单？比如客户自己找上门要我发货到外省，这算不算违规？"
- "我如果被投诉串货，认定流程是什么？有没有书面通知、申诉期？"
- "处罚是扣保证金、取消返利、还是直接终止合同？有没有阶梯？"

## 五、要落到纸面的东西

口头承诺谈判时可以听，但**签约前必须写进合同或代理政策附件**：

1. 授权区域清单（越具体越好，别只写"华东地区"）
2. 授权渠道范围（线下/线上分别列）
3. 区域保护的具体承诺（厂家是否直营、保护期限）
4. 串货定义 + 追溯方式（编码规则）
5. 处罚标准 + 受害方补偿机制
6. 争议处理流程和时限

## 一句话判断对方靠不靠谱

如果厂家**能拿出一套带编码追溯、有明确处罚阶梯、有申诉流程的书面政策**，说明它是认真管渠道的；如果只会说"我们从来不管这些小事""你放心"——那区域保护大概率是空的，你交的钱买的是个"区域名头"而不是保护。

建议你谈的时候直接记笔记，把对方回答原话记下来，签约时逐条对合同。有具体品牌或政策文本，也可以发我看，我帮你挑里面的坑。
