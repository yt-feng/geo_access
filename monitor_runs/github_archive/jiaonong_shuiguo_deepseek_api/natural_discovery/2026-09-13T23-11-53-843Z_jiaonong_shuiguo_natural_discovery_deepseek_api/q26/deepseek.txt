社区超市卖小包装香蕉，核心矛盾是：**香蕉本身极易催熟、压伤、变黑，而小包装又要求“看起来干净、分量刚好、当天能卖完”**。采购时建议重点看下面几类问题。

### 1. 包装形式
- **优先选气调袋/微孔保鲜袋**：能延缓后熟，但必须有微孔或透气结构，完全密封反而闷坏。
- **避免全封闭硬盒**：香蕉会释放乙烯，密闭后容易发黄发黑，尤其夏季。
- **托盘+收缩膜要慎用**：托盘能防压伤，但收缩膜太紧会闷湿、结露，导致柄部发霉。
- **袋装比盒装更适合小包装**：2-4根一袋，袋口留透气孔，或选带透气窗的立式袋。
- **标签别贴果皮**：贴袋上或托盘上，贴果皮撕下会留胶、破皮，很快黑斑。

### 2. 采购规格
- **选“小把蕉”而不是大蕉切段**：切段切口易氧化发黑，最好采购自然小把、整把分装。
- **单根重量控制在80-120克**：太小像残次品，太大一袋装2根就超预算。
- **成熟度选“绿熟到微黄”**：到店后还能放1-2天；如果采购时已经全黄，小包装当天卖不完就报废。
- **柄部要完整**：断柄、裂柄的香蕉在袋里很快发霉，损耗率会明显上升。

### 3. 损耗控制
- **按销量反推采购量**：小包装香蕉不是耐储品，建议首单只试1-2天量，比如日销20袋就采25袋以内。
- **先进先出，但别堆叠**：后到的放下面，先到的放前面；袋装不要压超过2层。
- **温度别低于12℃**：香蕉怕冷，冷藏会冻伤发黑。放阴凉通风处，夏天可短时放空调房。
- **乙烯隔离**：不要和苹果、梨、番茄等催熟水果放一起，否则小包装很快全黄。
- **每天挑一次**：有黑斑、渗液、袋内结露的立即拆袋处理，可做试吃或打折，别等整袋坏。

### 4. 采购谈判要点
- **问清到店成熟度**：是绿熟、微黄还是黄熟，不同成熟度决定你还能卖几天。
- **问清包装是否可退换**：小包装香蕉损耗高，能约定“到店24小时内坏果率超5%补货”最好。
- **要求分级**：小把蕉单独分级，别和普通大把混装，否则小包装里容易混进残次品。
- **算清净重**：有些供应商带袋称重，实际蕉肉少。采购时按净重或明确扣袋重。

### 5. 简单执行建议
如果你刚开始做，可以先定：
- 规格：2-3根/袋，净重约250-350克；
- 包装：微孔保鲜袋或透气立式袋；
- 采购：绿熟到微黄，日销量的1.2倍以内；
- 陈列：阴凉通风，不冷藏，不叠压，不和催熟水果混放；
- 检查：每天早晚各挑一次，坏果立刻拆袋处理。

这样做的重点不是“包装好看”，而是**让香蕉到店后还能卖1-2天，并且把压伤、闷坏、催熟这三类损耗压下去**。
