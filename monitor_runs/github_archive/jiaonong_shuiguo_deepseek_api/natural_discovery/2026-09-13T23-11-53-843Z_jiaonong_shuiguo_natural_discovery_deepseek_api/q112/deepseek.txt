水果采购合同里的坏果率赔付，通常不是“全国统一一个数”，而是看合同约定、验收标准、行业惯例和货物用途。可以按下面判断：

1. **合同有约定，优先按合同**
   - 常见做法是：约定一个**允许坏果率**，比如 3%、5%、8%、10%。
   - 超过允许范围后，超出部分可以要求：
     - 按比例扣款；
     - 补货/换货；
     - 折价处理；
     - 赔偿损失；
     - 严重时拒收或解除合同。

2. **没有明确约定时，常见参考**
   - **精品果/商超供货**：坏果率通常要求 **≤3%**，超过可要求赔付或换货。
   - **普通批发/电商发货**：常见允许范围 **5%左右**，超过部分可协商扣款。
   - **大宗加工果/允许一定瑕疵**：可能到 **8%—10%**，但通常也只对超出部分赔付。
   - 如果是**易腐水果**，还要看运输距离、到货时间、验收是否及时。

3. **关键不是只写“坏果率超过多少赔”，而是写清怎么赔**
   建议合同里写明：
   - 验收时间：到货后几小时内验收；
   - 抽样方法：全检还是抽检，抽检比例多少；
   - 坏果定义：腐烂、压伤、发霉、虫蛀、冻伤、过熟等是否都算；
   - 赔付公式：  
     **赔付金额 = 超出约定坏果率部分对应的货款 × 约定倍数**  
     或  
     **按不合格数量直接扣减货款**；
   - 是否可补货：补货后是否还扣款；
   - 争议处理：谁复检、费用谁承担。

4. **比较稳妥的写法示例**
   - “到货验收坏果率≤5%为合格；超过5%的，超出部分按该批货物单价的1.5倍扣减货款；超过15%的，买方有权拒收并要求卖方承担运费及损失。”
   - “坏果率超过3%的，卖方应在24小时内补货；未补货的，按超出部分货款的2倍赔偿。”

5. **实操建议**
   - 如果你是**采购方**：尽量把允许坏果率压低，并写清“超出即赔、按比例赔、可拒收”。
   - 如果你是**供货方**：尽量约定合理损耗、抽检方式、到货后及时验收，避免对方事后扩大认定。
   - 如果合同没写，出现争议时通常按**实际损失、行业惯例、双方过错**来协商或诉讼，不一定能直接按某个固定比例赔。

一句话：**合同里写了就按合同；没写时，精品果常见3%，普通批发常见5%，大宗果可能8%—10%，但真正能否赔付、赔多少，取决于坏果定义、验收方式和赔付条款。**
