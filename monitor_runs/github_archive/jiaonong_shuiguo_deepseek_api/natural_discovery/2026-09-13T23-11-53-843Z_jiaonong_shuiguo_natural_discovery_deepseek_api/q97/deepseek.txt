酒店采购水果盘原料时，供应商应保证以下规格和外观标准，建议直接写入采购合同或验收单，作为收货判定的依据。

**一、通用规格标准**
1. **品种与产地**：明确具体品种、产区、等级，如“海南小台农芒果”“智利JJ级车厘子”，不接受口头模糊表述。
2. **单果重量/大小**：按品种约定单果克重或直径，如草莓单果≥15g、苹果直径≥75mm、西瓜单果≥4kg。
3. **成熟度**：约定到货成熟度，通常为7–8成熟，既能即时使用又有1–3天货架期；过生或过熟均应拒收。
4. **可食率**：规定去皮去核后的可用比例，如菠萝可食率≥55%、西瓜≥60%。
5. **糖度**：按品种约定，如西瓜中心糖度≥11°Brix、柑橘≥10°Brix，可用糖度计抽检。
6. **规格统一性**：同一批次大小、颜色、成熟度基本一致，便于摆盘统一。

**二、外观标准**
1. **新鲜度**：无萎蔫、皱皮、干疤、失水，果柄青绿或新鲜。
2. **完整度**：无裂口、破损、压伤、虫眼、病斑、霉变。
3. **色泽**：符合品种固有色泽，着色均匀，无青肩、褪色、褐变。
4. **形状**：果形端正，无明显畸形、双果、机械变形。
5. **洁净度**：表面无泥污、药斑、残留物，无腐烂汁液污染。
6. **气味**：具品种固有清香，无发酵、酸腐、霉味。

**三、食品安全与合规**
1. 提供农残检测合格证明或承诺书，必要时每批次抽检。
2. 符合GB 2763农药残留限量、GB 2762污染物限量。
3. 预切水果需符合即食果蔬卫生要求，冷链温度0–4℃。
4. 提供产地证明、检疫证明（进口水果）、供货资质。

**四、验收与退换**
1. **抽检比例**：建议每批次抽检5%–10%，大货按件抽检。
2. **拒收标准**：腐烂、霉变、虫蛀、异味、规格不符超过约定比例（如5%）可整批拒收。
3. **退换时效**：到货2小时内完成验收，不合格品24小时内退换。
4. **冷链要求**：运输温度按品种约定，如浆果0–4℃，热带水果10–13℃。

**五、建议写入合同的量化条款示例**
- “草莓：单果≥15g，着色≥90%，无霉变、无压伤，到货温度0–4℃。”
- “西瓜：单果4–6kg，中心糖度≥11°Brix，无裂口、无空心。”
- “车厘子：JJ级，单果直径≥28mm，果柄青绿，无软果、无裂果。”

**执行建议**：先按酒店水果盘常用品种列一张《原料规格验收表》，每项写明品种、等级、单果规格、成熟度、外观缺陷允许比例、温度要求，收货时逐项打勾，不合格直接拒收或扣款。这样供应商无法用“差不多”搪塞，酒店也能稳定出品。
