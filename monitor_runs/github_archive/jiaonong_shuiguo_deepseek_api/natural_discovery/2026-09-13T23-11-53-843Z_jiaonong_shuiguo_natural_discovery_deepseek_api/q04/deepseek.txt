要让香蕉少放坏，采购时核心是 **“按销售节奏分批要熟度，并要求到货时间可分批”**，不要一次全要同一熟度。

具体可以这样要求：

1. **按销售天数定熟度**
   - 当天到、1～2天卖完：要 **3～4成熟**，青黄、硬，适合再放1～2天。
   - 2～3天卖完：要 **4～5成熟**，微黄带绿，正好可开始上架。
   - 当天就要卖：要 **5～6成熟**，黄多绿少，但不要全黄。
   - 不要采购 **6～7成熟以上** 的香蕉作为主库存，除非当天促销或做果切。

2. **要求“到货时间分批”**
   - 不要一次全到货。
   - 可要求：**每周2～3次到货**，或 **隔天到货**。
   - 每次到货里再分：**一部分马上卖、一部分后熟1～2天**。
   - 例如：一次到货中，60%要4成熟，40%要3成熟。

3. **明确采收/催熟状态**
   - 问供应商：是 **自然熟** 还是 **催熟**。
   - 催熟香蕉后熟快，最好要 **刚到货时偏青**，不要已经发软。
   - 要求 **“未催熟或轻催熟，到店后还能放2～3天”**。

4. **要求冷链和运输条件**
   - 夏天要求 **冷藏车或冷链运输**，温度大约 **13～15℃**。
   - 不要低于 **12℃**，否则容易冻伤发黑。
   - 冬天注意防冻，不要放在暖气旁或暴晒。

5. **到货验收标准**
   - 果皮：青黄均匀，无大面积黑斑、无裂口、无发霉。
   - 硬度：手感硬实，不软塌。
   - 果柄：绿色或浅绿，不干枯发黑。
   - 温度：不烫手、不冰手。
   - 有异味、酒味、酸味直接拒收。

6. **采购量控制**
   - 按 **1～2天销量** 下单，不要按一周销量一次囤。
   - 夏天、雨天、节假日前后要减少单次采购量。
   - 如果只能一次大批量进货，就要求供应商 **分不同熟度装筐/装箱**，方便你分批上架。

一句话总结：
**采购时要求“分批到货、以3～5成熟为主、冷链运输、到货后还能放2～3天”，并按销售速度搭配不同熟度，就能明显减少香蕉放坏。**
