水果店遇到坏果，核心原则是：**先分清责任和损耗类型，再按合同/行业惯例处理，不能默认全由自己承担。** 具体可以按下面几步走。

## 一、先判断坏果属于哪种情况

1. **到货即坏（运输/供货问题）**
   - 开箱验收时就发现腐烂、压伤、发霉。
   - 责任通常在供应商或物流，应拒收或当场登记索赔。

2. **货到后短时间内坏（保鲜期问题）**
   - 比如承诺能放3天，结果1天就烂。
   - 要看是否属于供应商以次充好、催熟过度、冷链断裂。

3. **正常损耗**
   - 水果本身有呼吸作用，少量软果、碰伤属于行业正常损耗。
   - 这部分一般由水果店自己承担，或在采购价里已经预留。

4. **自己储存不当**
   - 温度、湿度、堆压、混放导致。
   - 这类通常不能找供应商赔。

## 二、结算和赔付的常见方式

### 1. 验收当场扣款
适合到货就发现坏果：
- 按坏果数量/重量，从当批货款里直接扣减。
- 例如：到货100箱，验收发现8箱坏果，按8箱金额扣款，或按比例折价。

### 2. 补货替换
供应商下次送货时补同等数量、同等品质的货。
适合长期合作、供应商愿意维护关系的情况。

### 3. 折价结算
坏果不退回，但按打折价结算。
例如：
- 轻微碰伤：按7折或8折结算；
- 严重腐烂：直接不计入货款。

### 4. 退货退款
坏果比例高、无法销售时：
- 整批退回，供应商退款或换货；
- 运费和责任由谁承担，按合同或过错方承担。

### 5. 按比例分摊
如果无法明确责任，或部分属于正常损耗：
- 供应商承担一部分，水果店承担一部分。
- 例如坏果率10%，双方各承担5%的损失。

## 三、和供应商谈赔付时怎么说

建议按这个顺序沟通：

1. **先给证据**
   - 到货时间、批次、照片/视频、称重记录、验收单。
   - 最好在收货后第一时间反馈，不要拖几天。

2. **明确诉求**
   - 是扣款、补货、退货还是折价，直接说清楚。
   - 例如：“这批坏果32斤，按采购价每斤5元，共160元，从本次货款里扣。”

3. **引用约定**
   - 有合同按合同；
   - 没合同按行业惯例：到货坏果由供货方负责，正常损耗由门店承担。

4. **保留书面记录**
   - 微信、短信、送货单备注都可以。
   - 避免只口头说，后面对方不认。

## 四、建议提前做的防范

- **签订采购协议**：写明验收标准、坏果率上限、赔付方式、退换货时限。
- **约定损耗率**：比如叶菜类、浆果类允许3%-5%正常损耗，超出部分供应商负责。
- **坚持当场验收**：尤其是草莓、蓝莓、荔枝、葡萄等易损水果。
- **拍照留证**：开箱、称重、坏果特写、批次标签。
- **分品类处理**：耐储水果和易腐水果用不同验收标准。

## 五、简单判断表

| 情况 | 通常谁承担 | 处理方式 |
|---|---|---|
| 到货就烂、发霉 | 供应商 | 拒收、扣款、补货 |
| 到货1天内大面积坏 | 看责任，多由供应商 | 退货、折价、索赔 |
| 少量软果、碰伤 | 水果店 | 正常损耗，自行承担 |
| 自己放坏 | 水果店 | 自行承担 |
| 合同有约定 | 按合同 | 按约定执行 |

**一句话总结：到货坏果找供应商扣款或补货；正常损耗自己承担；责任不清就按比例分摊。关键是当场验收、留证据、提前约定规则。**
