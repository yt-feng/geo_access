优先关注**成熟度**，价格其次。原因很直接：香蕉在烘焙里的作用不只是“提供香蕉味”，还直接影响蛋糕的**甜度、湿度、结构、色泽和保质期**。

**按用途判断成熟度：**

- **做香蕉磅蛋糕、马芬、香蕉面包**：选**完全成熟、表皮有明显黑斑、捏起来软但没烂**的香蕉。这种香蕉淀粉已大量转化为糖，甜度高、香气足、保湿性好，能减少额外加糖和液体，成品更湿润。
- **做香蕉奶油、夹馅、装饰片**：成熟度要适中，太软会出水、影响定型。
- **做需要保持形状的香蕉丁**：选稍硬、刚转黄的，但风味会弱一些。

**为什么价格不能放第一位：**
- 太生的香蕉烤出来香气淡、涩味重，还可能让蛋糕发干、组织紧实。
- 过熟到发黑流汁的香蕉水分和微生物风险高，容易让蛋糕湿黏、保质期缩短。
- 用成熟度不合适的香蕉，往往要靠加糖、加油、加香精去补救，综合成本未必低。

**采购建议：**
1. **按配方定成熟度标准**，不要只看“香蕉”两个字。
2. 大批量采购时，可买**七至八成熟**的香蕉，室温催熟到所需状态再用，比直接买全熟更可控。
3. 如果价格明显低但成熟度不对，只适合买回来**自行催熟**或用于允许调整配方的产品，不适合直接上线。
4. 建立简单验收标准：表皮颜色、黑斑比例、手感软硬度、是否渗汁、有无异味。

一句话：**先按产品需求匹配成熟度，再在合格范围内比价格。**
