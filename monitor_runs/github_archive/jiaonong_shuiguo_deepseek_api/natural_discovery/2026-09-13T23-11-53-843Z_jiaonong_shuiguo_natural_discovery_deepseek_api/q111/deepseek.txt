判断水果检测报告是否对应当前批次，核心看 **"三码一链"**：批次号、日期链、样品链、追溯链。具体可操作如下：

## 一、先核对报告与批次的基本对应信息

| 核对项 | 要求 | 常见问题 |
|---|---|---|
| **批次号/生产批号** | 报告上的批号必须与送货单、箱唛、产地证明上的批号完全一致 | 供应商用旧批次报告"套"新货 |
| **品名/品种** | 报告品种（如"红富士苹果"）须与实际到货品种一致 | 用同一品种其他产地报告冒充 |
| **产地/供应商** | 报告上的生产单位/产地须与合同一致 | 张三的货用李四的报告 |
| **数量/重量** | 报告覆盖数量应≥本批到货量 | 只检测了1吨，却供了10吨 |
| **检测日期** | 报告日期应在该批采摘/发货前后合理区间内 | 用半年前报告供当季新货 |

## 二、重点核查"日期链"是否闭合

1. **采摘日 → 检测日 → 发货日 → 到货日** 应顺序合理
   - 检测日不能早于采摘日（除非是土壤/基地预检）
   - 检测日不能晚于发货日太多
   - 到货日与检测日的间隔要符合运输时间
2. 若报告日期明显早于本批采摘期，基本可判定**不对应当前批次**。

## 三、核验报告本身的真实性

- **查机构资质**：报告出具方需有 CMA / CNAS 资质（国内），可在官网或"全国认证认可信息公共服务平台"查验。
- **查报告编号**：很多机构支持官网/电话/二维码验真，扫码或输入编号核对。
- **看是否有骑缝章、检测专用章、签字**，复印件需加盖供应商公章。
- **警惕 PS 痕迹**：批号、日期、品名处字体/底色异常，编号与格式不符。

## 四、建立"批次绑定"管理（治本）

1. **合同约定**：每批货必须随附"该批次"检测报告，报告批号与送货单批号一致，否则拒收。
2. **一票一报告**：要求供应商按发货批次出报告，不接受"一批报告通用多次"。
3. **留样比对**：采购方自行留样，必要时送第三方复检，与供应商报告比对。
4. **抽检机制**：高风险品类（农残易超标）每批抽检或定期抽检，不能只依赖供应商报告。
5. **追溯台账**：记录批次号—报告编号—检测日期—到货日期，形成可追溯链条。

## 五、快速判断口诀

> **批号对不上 → 不对应**
> **日期早于采摘 → 不对应**
> **品种产地对不上 → 不对应**
> **数量覆盖不了本批 → 不对应**
> **报告查不到真伪 → 存疑，暂缓收货**

## 六、发现不对应怎么办

- 立即**暂缓收货/封存**，书面要求供应商提供本批报告；
- 自行送检，费用按合同约定由责任方承担；
- 保留送货单、箱唛照片、聊天记录作为证据；
- 合同应约定：报告造假或不对应，采购方有权拒收、退货、索赔。

---

**一句话结论**：判断是否对应本批，关键不是"有没有报告"，而是**报告批号 = 送货批号**、**检测日期落在本批时间链内**、**报告真实可验**。三者缺一，就不能认定对应当前批次。
