做水果批发的大客户，核心矛盾是：**你要用账期换稳定销量，但水果是生鲜，坏账和损耗风险都高。**所以账期和额度不能一次谈死，要分层设计。

## 一、先想清楚你手里有什么牌

谈判前明确三点：

1. **你的替代成本**：这个大客户占你出货量多少？如果他跑了你多久能补上？占比越高，你越被动。
2. **他的替代成本**：你的货在他采购里占比多少？他换供应商要不要重新验货、磨合？
3. **你的资金承受力**：你能压多少货款不影响自己进货？这是硬底线。

## 二、账期怎么谈

**原则：先短后长，用履约表现换账期。**

| 阶段 | 建议账期 | 触发条件 |
|------|---------|---------|
| 试单期 | 现款或货到3天 | 前1-2个月 |
| 稳定期 | 7-15天 | 连续3个月按时结清 |
| 核心期 | 15-30天 | 半年以上、月采购额达标 |

谈判话术方向：
- 不要直接说"我要30天"，而是"**我们先按7天走，你稳定付款三个月，我主动给你延到15天**"——把账期变成你给的奖励，而不是他提的要求。
- 如果他坚持要长账期，用**价格换**：账期30天则单价上浮，现款则给折扣。让他自己算哪个划算。

**生鲜特别提醒**：账期最好和"到货验收"绑定。约定验收后几天起算，避免他拖着不验收占你账期。

## 三、额度怎么定

**额度 = 你能承受的坏账上限，不是他想拿多少货。**

分层设置：
- **初始额度**：按他1-2周的正常采购量设，别按他报的月需求量。
- **额度上调**：和账期一样，用履约记录换。按时结清 + 采购量稳定，再逐步加。
- **额度封顶**：设一个绝对上限，超过部分必须现款或预付。

关键条款：
- **账期和额度叠加控制**：比如"账期15天、额度10万"，意味着任意时点他欠你的钱不超过10万。要盯的是**在途欠款余额**，不是单笔。
- **超额处理**：超过额度的订单，要么现款，要么暂停发货。这条必须写进合同，否则额度形同虚设。

## 四、必须写进合同的保护条款

1. **逾期条款**：逾期几天起停货、收逾期利息（比如日万分之几）。
2. **对账机制**：固定周期对账，双方签字确认，避免扯皮。
3. **质量异议期限**：生鲜容易拿"货不好"当拖欠理由。约定到货后多少小时内提异议，过期视为验收合格。
4. **担保或抵押**：大额度可以要求法人个人连带担保，或保证金。
5. **停货权**：欠款超限或逾期，你有权立即停供且不担违约责任。

## 五、实操建议

- **别一开始就给最优条件**。先给一个"够好但不完美"的方案，留出让步空间。
- **用数据说话**：把他过去几个月的采购、付款记录拉出来，账期和额度调整都基于事实。
- **小额试水**：先跑一两个月的短账期，看他付款爽不爽快。付款习惯比采购量更能说明问题。
- **分散风险**：再大的客户也别让他占你出货量的一半以上，否则账期谈判你永远被动。

**一句话总结**：账期和额度都用"履约换"的方式逐步给，合同里写死停货权和封顶线，生鲜生意宁可少做一单，别做成一笔收不回的坏账。
