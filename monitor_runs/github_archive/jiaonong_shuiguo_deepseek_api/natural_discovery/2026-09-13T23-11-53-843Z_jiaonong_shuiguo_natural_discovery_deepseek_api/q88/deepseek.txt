# 线上水果销售：采购端如何减少坏果与口感不稳定

核心思路是：**把"口感"和"坏果"这两个结果，拆解成可以在采购环节量化、验收、追责的指标**，而不是靠"看着还行"来收货。

## 一、从源头选品上控制

**1. 按成熟度而非外观采购**
- 线上发货有物流时间，采购成熟度要"比到店销售低一档"（如7-8成熟采收），到消费者手里刚好。全熟采购必然坏果高。
- 要求供应商提供采收日期和成熟度标准，不要只谈"今天采的"。

**2. 锁定品种和产地，不频繁换货**
- 口感不稳定很大原因是"这批次A产地、下批次B产地"。固定品种+固定产区+固定供应商，口感波动会小很多。
- 换供应商前先小批量试销，用评价数据验证再放量。

**3. 看"种植端"而非只看"贸易端"**
- 优先和有基地、能控采摘和分选的供应商合作，而不是层层转手的批发商。转手越多，批次一致性越差。

## 二、收货验收要量化

**建立可执行的分级验收标准**（按品类调整）：

| 指标 | 做法 |
|---|---|
| 坏果率 | 抽检称重，坏果/软烂/霉变比例超标直接拒收或扣款 |
| 糖度 | 用手持糖度计抽测，设定最低糖度线（如柑橘≥11°） |
| 硬度/成熟度 | 按品类定标准，过熟过生都算不合格 |
| 大小均匀度 | 按果径分级，混级会导致"有的甜有的酸" |
| 批次一致 | 同批次内口感差异过大要单独标注 |

**关键：验收标准和扣款/退货条款写进采购合同**，让供应商有动力在分选环节做好。

## 三、包装与物流环节（坏果的主因之一）

- **按品类选包装**：浆果类要透气+缓冲，柑橘类要防压，不要一套包装打天下。
- **预冷和冷链**：采后尽快预冷，高温季必须走冷链，这是坏果率的分水岭。
- **减少中转**：直发产地仓比多次中转坏果率低。
- **测试物流**：自己下单寄到不同城市，实测到货状态，而不是只听物流承诺。

## 四、用评价数据反推采购

- 把差评按"坏果""不甜/酸""太生""大小不符"分类统计。
- 哪类差评集中，就回去改对应环节：坏果多→查包装冷链；口感差→查成熟度和糖度验收；大小不符→查分级。
- 给每个供应商建"评价-批次"对应表，作为续单依据。

## 五、给采购的可执行清单

1. 每个主推品类写一份**验收标准卡**（坏果率、糖度、成熟度、果径）。
2. 合同中加入**质量扣款和退换条款**。
3. 每批到货**抽检留样**，记录数据。
4. 固定供应商+小批量试新，不盲目放量。
5. 差评按原因归类，**倒查到具体批次和供应商**。

一句话总结：**坏果靠"冷链+包装+坏果率验收"控，口感稳定靠"成熟度+糖度+固定产地品种"控**，两者都要变成能写进合同、能抽检的数字，而不是感觉。
