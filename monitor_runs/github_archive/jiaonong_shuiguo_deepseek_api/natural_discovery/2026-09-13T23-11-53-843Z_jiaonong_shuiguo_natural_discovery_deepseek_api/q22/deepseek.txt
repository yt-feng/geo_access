可以按“引流款+利润款+搭配款”来组，别只做统一下调。香蕉适合引流，苹果适合走量和提客单，菠萝适合做搭配/加工增值。

**1. 组合方案：香蕉+苹果做“基础家庭装”**
- 内容：香蕉1把 + 苹果4-6个
- 定价：比单买合计便宜10%-15%，但设置门槛，比如“满15元享组合价”
- 目的：把只买香蕉的低客单顾客，顺手带到苹果
- 陈列：香蕉和苹果相邻，组合袋提前装好，标“家庭常备果盒”

**2. 组合方案：菠萝+苹果做“酸甜果切/果篮”**
- 内容：菠萝半个或1个 + 苹果3个
- 卖点：做成果切盒、沙拉原料包，或“煮水果茶组合”
- 定价：按加工后的便利性溢价，不按原料价简单相加
- 目的：菠萝单价感知低、处理麻烦，加工后能提价，苹果补体积和甜度

**3. 组合方案：三品“满减阶梯”**
- 买任意2种：减2元
- 买齐香蕉+菠萝+苹果：减5元或送小份果切
- 目的：让顾客从买1种变买3种，直接推高客单
- 注意：满减门槛要略高于当前平均客单，比如平均12元，就设满18减3、满25减5

**4. 用“香蕉引流，苹果赚钱，菠萝提感”**
- 香蕉：保持低价感知，放门口或端头，限购1-2把
- 苹果：做分级，普通款走组合，精品款单独高价
- 菠萝：提供免费削皮或半加工，但削皮后按份卖，溢价更高

**5. 陈列和话术**
- 堆头写：“香蕉+苹果=一周早餐果”“加菠萝立减5元”
- 组合袋上贴建议吃法：香蕉苹果奶昔、菠萝苹果茶
- 收银台提醒：“再加1个菠萝，三样齐了减5元”

**6. 关键控制**
- 别把三样都降价，否则客单可能上去、毛利下来
- 组合价要让顾客感觉省，但整体毛利不低于原单品平均毛利
- 每天看两个数：组合购买率、组合客单 vs 普通客单
- 如果菠萝损耗高，就主推削皮装或果切，不推整果堆头

简单执行版：  
**香蕉正常低价引流；苹果做4-6个家庭装；菠萝做削皮果切；三品齐购满25减5。**  
这样最容易把“只买香蕉”的人，拉到买苹果和菠萝。
