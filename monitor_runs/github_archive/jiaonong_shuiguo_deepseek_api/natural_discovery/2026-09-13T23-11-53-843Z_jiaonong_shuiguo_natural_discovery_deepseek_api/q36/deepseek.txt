结论：**大多数商超应以“整果为主、切果为辅”，但切果不是可有可无，而是用来拉客流和提客单的补充品类。** 具体怎么做，取决于你的门店类型、客流结构和损耗控制能力。

下面给你一套可执行的判断和操作建议。

## 一、先判断你的门店适合哪种为主

| 门店情况 | 更适合 | 原因 |
|---|---|---|
| 社区店、中老年客流多、价格敏感 | 整果为主 | 整果单价低、耐放、损耗小 |
| 商圈店、年轻人多、上班族多 | 切果占比可提高 | 即买即吃、复购强、能卖上价 |
| 水果专营/精品超市 | 整果+切果并重 | 切果做毛利和体验，整果做量和引流 |
| 普通大卖场 | 整果为主 | 客流杂、价格敏感、切果损耗难控 |

**判断标准很简单：**
- 如果你的顾客经常问“能不能帮忙削/切”，切果需求就真实存在。
- 如果你每天扔掉的切果超过备货量的 15%～20%，说明切果做多了或时段没控好。

## 二、整果和切果的各自价值

**卖整果的优势**
- 损耗低，可存放，压货风险小
- 单价低，更容易走量
- 适合家庭采购、送礼、囤货
- 操作简单，不需要额外人工和包装

**卖切果的优势**
- 即食，满足上班族、学生、单人家庭
- 单价高，毛利通常更好
- 能带动饮料、酸奶、沙拉等关联销售
- 切果卖相好，能提升水果区活力

**切果的核心风险**
- 损耗高，卖不掉就得扔
- 食品安全要求高，必须冷链、限时
- 人工成本高，削切、装盒、清洗都费人
- 一旦出现变质，投诉和口碑风险大

## 三、建议的实操比例

如果你没有特别数据，可以先按这个比例试：

- **整果：70%～80%**
- **切果：20%～30%**

然后再根据数据调整：
- 切果连续一周售罄率高、损耗低于 10%，可以加量
- 切果经常剩、损耗超过 20%，就减量或只做高峰时段

## 四、切果怎么做才不容易亏

1. **只做高峰期**
   - 上午 10 点后、下午 4 点后、周末全天
   - 不要一开门就大量切

2. **小批量、多批次**
   - 每次少切，卖完再补
   - 避免一次性切一大盘

3. **分规格定价**
   - 小盒：单人即食，走量
   - 大盒：家庭装，提客单
   - 拼盘：菠萝+其他水果，提高毛利

4. **严格时限**
   - 冷藏条件下建议当天售完
   - 超过时限直接下架，不要降价硬卖

5. **包装和标签要规范**
   - 标注切配时间、保质期、储存条件
   - 让顾客敢买

## 五、最稳妥的组合策略

**整果做流量，切果做利润和体验。**

具体可以这样安排：
- 整果区：堆头陈列，主打低价、新鲜、整箱购
- 切果区：靠近收银台或出口，主打即食、小份、拼盘
- 试吃：用切果做试吃，引导顾客买整果
- 关联陈列：切果旁边放酸奶、纸巾、牙签

## 六、一句话总结

**如果只能选一个，选整果；如果想提升毛利和年轻客群，必须加切果，但要小批量、控时段、严控损耗。**  
最理想的是：**整果为主，切果为辅，用切果带流量，用整果走销量。**
