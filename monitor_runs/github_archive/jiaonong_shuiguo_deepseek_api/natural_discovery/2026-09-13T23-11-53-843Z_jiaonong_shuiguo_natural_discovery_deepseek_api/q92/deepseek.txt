小面积便利店做水果，核心原则不是“品类齐全”，而是**少SKU、快周转、强控损**。可以按下面这套方法落地。

## 一、品类控制：只做“高频+好周转+低损耗”

### 1. 品类数量
- **面积越小，SKU越少**：一般控制在 **6～12个单品**。
- 每个品类只留 **1～2个规格**，不要同品多规格。
- 结构建议：
  - **引流款 2～3个**：香蕉、苹果、橘子/砂糖橘
  - **利润款 2～3个**：葡萄、提子、蓝莓、猕猴桃
  - **即食款 1～2个**：切果、果切、小番茄
  - **季节款 1～2个**：夏天西瓜/蜜瓜，冬天橙子/草莓

### 2. 选品标准
优先选：
- **周转快**：香蕉、苹果、柑橘、小番茄、葡萄
- **耐存放**：苹果、橙子、柚子、猕猴桃
- **易标准化**：按个卖、按盒卖、按份卖

谨慎做：
- 草莓、樱桃、杨梅、荔枝、龙眼、切开的西瓜
- 这些损耗高，除非客流很好、能当天清掉

### 3. 陈列面积控制
- 水果区占总面积 **5%～10%** 就够，不要超过15%。
- 用 **阶梯货架+小筐+挂钩**，提高单位面积产出。
- 不要大面积平铺，平铺会让顾客翻捡，增加碰伤。

## 二、采购控制：小批量、多频次、以销定采

### 1. 采购频率
- 最好 **每天1次**，至少 **隔天1次**。
- 香蕉、葡萄、草莓这类，尽量日配。
- 苹果、橙子、柚子可2～3天一次。

### 2. 采购量公式
按“日销量 × 补货周期 + 安全库存”来定：

> 采购量 = 日均销量 × 补货间隔天数 × 1.1～1.2

例如：
- 香蕉日均卖20斤，每天补货：采购22～24斤
- 苹果日均卖10斤，2天补一次：采购22～24斤

### 3. 首单测试
新品第一次只进：
- **1～2箱**
- 或 **1～2天预估销量**
卖得好再加，卖不动立刻停。

### 4. 按时间段采购
- 早市/上午到货：适合当天卖
- 下午补货：只补快消品，不补慢销品
- 晚上少补：避免隔夜损耗

## 三、损耗控制：从进货到售卖全流程

### 1. 收货环节
- 当场挑出烂果、压伤果，能退就退。
- 不要因为便宜就收尾货，尾货损耗通常更高。
- 香蕉、芒果等后熟水果，控制成熟度，不要一次全熟。

### 2. 储存环节
- **香蕉**：常温悬挂，不要冷藏。
- **苹果、橙子、柚子**：阴凉通风，可冷藏。
- **葡萄、蓝莓、草莓**：冷藏，但不要洗。
- **猕猴桃、芒果**：分开催熟，熟后冷藏。
- **乙烯敏感水果**：如西瓜、葡萄，不要和香蕉、苹果放一起。

### 3. 陈列环节
- 少量多次上架，卖完再补。
- 不要堆太高，避免压伤。
- 坏果立刻挑出，避免传染。
- 用“假底”减少陈列量，保持饱满感。

### 4. 定价与促销
- 早上正价，下午开始分级：
  - 一级果：正价
  - 二级果：8折
  - 轻微瑕疵：5折或做果切
- 晚上8点后：打包特价，当天清。
- 果切只使用当天完好水果，不要用烂果。

### 5. 数据记录
每天记录：
- 进货量
- 销售量
- 损耗量
- 损耗原因：压伤、腐烂、过期、顾客翻捡

连续记2周，就能看出：
- 哪些品不能做
- 哪些品采购量要减
- 哪个时段该促销

## 四、小面积便利店推荐组合

### 夏季
- 香蕉
- 小番茄
- 葡萄/提子
- 西瓜（切半或小份）
- 苹果
- 果切1～2款

### 冬季
- 砂糖橘
- 橙子
- 苹果
- 香蕉
- 猕猴桃
- 柚子

## 五、最关键的三条

1. **不要追求全，只做能当天或隔天卖掉的。**
2. **采购量宁少勿多，卖断比烂掉强。**
3. **每天挑坏果、每天调价、每天看数据。**

如果只能记一句话：**小面积便利店水果，做少、做快、做新鲜，靠周转赚钱，不靠毛利堆货。**
