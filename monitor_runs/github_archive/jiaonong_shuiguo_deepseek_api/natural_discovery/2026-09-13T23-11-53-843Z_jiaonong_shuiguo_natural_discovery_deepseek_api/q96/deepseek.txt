食品安全是底线，必须优先保证；但在实际采购决策里，三者不是简单排序，而是“食品安全一票否决、配送准时决定能不能用、价格决定划不划算”。

如果只能选一个最需要关注的，答案应是：**食品安全**。

原因是企业食堂面向的是集体就餐人群，一旦水果出现农残超标、霉变、腐烂、致病菌污染等问题，影响面大，后果远高于价格波动或配送延迟。价格贵一点、晚到一会儿通常还能补救；食品安全出问题，往往是群体性健康风险，还可能带来法律责任和舆情风险。

但实际采购中建议按这个顺序判断：

1. **食品安全先设为门槛条件**
   - 供应商资质齐全：营业执照、食品经营许可证等。
   - 水果可追溯：批次、产地、检测报告或承诺达标合格证。
   - 验收标准明确：新鲜度、腐烂率、异味、农残快检或抽检要求。
   - 不合格处理清晰：退货、换货、索赔、暂停合作。

2. **配送准时是保障条件**
   - 水果是生鲜，配送不准时会直接影响食堂出餐、加餐或员工福利发放。
   - 尤其夏季，延迟配送会增加损耗和变质风险。
   - 所以应把“准时率”写进合同，比如迟到多久扣款、多少次取消资格。

3. **价格是优化条件**
   - 在食品安全达标、配送稳定的前提下，再比价。
   - 不能单纯选最低价，因为过低价格可能意味着品质下降、以次充好或配送服务缩水。
   - 建议综合看“单价 + 损耗率 + 退换货成本 + 配送成本”。

比较实用的采购策略是：

- **准入阶段：食品安全不合格，直接淘汰。**
- **合作阶段：配送准时率不达标，限期整改或淘汰。**
- **稳定阶段：在合格供应商之间比价，择优或分单采购。**

所以，一句话总结：  
**食品安全最需要关注，是一票否决项；配送准时是硬指标；价格是在前两者满足后的竞争项。**
