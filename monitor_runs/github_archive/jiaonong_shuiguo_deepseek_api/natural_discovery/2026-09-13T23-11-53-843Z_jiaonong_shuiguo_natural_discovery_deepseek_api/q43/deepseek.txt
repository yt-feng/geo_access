评估连锁门店水果供应商的仓配覆盖，核心是判断“供应商仓配能力能否稳定、低成本地满足各城市门店的水果需求”。可以从下面几个维度来评估：

## 1. 仓网覆盖能力

- **仓库位置分布**：供应商在你门店所在城市或周边是否有仓，覆盖半径是多少。
- **覆盖城市清单**：明确哪些城市能直送、哪些需中转、哪些覆盖不到。
- **仓的类型**：总仓、区域仓、前置仓、城市配送站，不同类型对应不同的时效和成本。
- **多温层能力**：水果有常温、冷藏、冷冻需求，仓库是否具备对应温区。

判断标准：门店所在城市是否在供应商仓的常规配送范围内，超出范围的时效和成本是否可接受。

## 2. 配送时效与频次

- **配送时效**：下单到送达需要多久，是否能做到次日达、隔日达或定时达。
- **配送频次**：每周能送几次，是否支持高频补货。水果周转快，频次低会导致门店缺货或损耗。
- **门店收货窗口**：配送时间是否匹配门店营业和收货时段。
- **紧急补货能力**：临时缺货或爆单时能否加急配送。

判断标准：时效和频次能否满足门店水果的周转要求，尤其是高损耗、高动销品类。

## 3. 冷链与品控能力

- **全程冷链**：从出库到门店是否全程温控，是否有温度记录。
- **损耗率**：供应商历史配送损耗率是多少，是否可承诺赔付。
- **到货新鲜度**：果品成熟度、外观、规格是否符合门店标准。
- **质检流程**：是否有入库质检、出库复核、到店验收标准。

判断标准：冷链断链和损耗是否在可接受范围内，是否有明确的赔付和退换机制。

## 4. 成本结构

- **配送费**：按单、按重量、按体积还是按里程计费。
- **起送门槛**：最低起送量是多少，小门店能否满足。
- **偏远地区附加费**：非核心城市是否有额外费用。
- **综合到店成本**：货价 + 配送费 + 损耗 + 门店收货人力，算出每店每单真实成本。

判断标准：不是只看货价，而是看“到店综合成本”是否优于其他供应商或自配。

## 5. 系统与协同能力

- **下单系统**：是否支持线上下单、门店独立下单、总部统一结算。
- **库存可视**：门店能否看到供应商库存和可配送量。
- **对账与结算**：是否支持多城市、多门店自动对账。
- **异常处理**：缺货、破损、延迟的响应流程是否清晰。

判断标准：系统能否支撑多城市、多门店的日常运营，减少人工沟通成本。

## 6. 实际验证方法

- **试跑**：选 2–3 个代表性城市（核心城市、偏远城市、高销量门店）试合作 2–4 周。
- **数据记录**：记录准时率、缺货率、损耗率、到店成本、门店投诉。
- **门店访谈**：让店长反馈收货体验、水果质量、补货灵活性。
- **压力测试**：在节假日或大促期间测试供应商的履约稳定性。

## 7. 评估结论怎么下

可以给每个维度打分，最后看：

- **覆盖广度**：能覆盖多少比例的门店。
- **履约稳定性**：时效、缺货、损耗是否达标。
- **成本可控性**：到店综合成本是否在预算内。
- **扩展性**：新开城市时能否快速接入。

如果供应商只在少数核心城市强，其他城市靠中转或第三方，就要评估中转带来的时效和损耗风险。如果供应商覆盖广但频次低、冷链弱，也不适合水果这种高周转品类。

简单说：**先看仓网能不能到，再看时效和冷链稳不稳，最后算到店综合成本划不划算，并用试跑数据验证。**
