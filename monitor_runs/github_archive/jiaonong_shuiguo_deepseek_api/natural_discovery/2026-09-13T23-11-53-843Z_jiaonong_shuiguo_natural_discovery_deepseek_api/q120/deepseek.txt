普通商家听不懂，往往不是因为你讲得不够专业，而是因为你讲的不是他脑子里已有的“分类格子”。菠萝、香蕉他能秒懂，是因为他已有稳定的用途、客群和售卖场景。你要做的，就是把新产品塞进他已有的格子里。

**核心一句话：不要介绍“这是什么”，而要介绍“它相当于什么、卖给谁、怎么卖、赚多少”。**

下面给你一套供应商可直接照说的表达框架。

**1. 先归类，不要先报品名**
错误说法：“这是金钻凤梨，台农17号。”
正确说法：“你就把它当成菠萝里的升级款，比普通菠萝更甜、不用泡盐水，客单价能卖高一点。”

对新品：
“你就把它当成香蕉里的‘小份装高端款’，不是给全家囤货的，是给白领下午加餐的。”

商家一旦有了参照物，理解成本立刻下降。

**2. 用“三句话”说清卖点**
第一句：它像什么？
第二句：比常见的强在哪？
第三句：顾客为什么买？

例如：
“它像普通橙子，但皮更薄、更好剥，适合放办公室。
比普通橙子贵一点，但不用刀切，不脏手。
买的人主要是写字楼下午买来直接吃的。”

**3. 直接讲“怎么卖”，不要只讲“多好吃”**
商家关心的是：放哪卖、卖给谁、怎么定价、损耗大不大。
你可以说：
“这个你别放蔬菜区，放收银台旁边小筐里，9块9两个，主要抓顺手买的人。”
“这个适合做试吃，切一盘，转化很快。”
“这个耐放，损耗比草莓低，适合小店。”

**4. 用对比，不用术语**
不要用：糖度18、可溶性固形物、品种编号、产地海拔。
改成：
“比普通香蕉甜一档。”
“比菠萝软，不扎嘴。”
“比苹果小，一次刚好一个。”
“比进口的便宜三成，看起来差不多。”

**5. 给一个最小下单理由**
普通商家怕压货，所以不要一上来推整箱。
可以说：
“你先拿一箱试，放门口试吃，卖不动我教你换位置。”
“这个和香蕉放一起卖，不占新地方。”
“先拿20斤，卖得好再补，不用一次压太多。”

**6. 最容易听懂的话术模板**
“王老板，这个你就当它是‘XX的升级版/方便版/小份版’。
顾客主要是____，买回去____。
你放在____，卖____钱一份。
比你现在卖的____，好处是____。
你先拿____试，卖不动我帮你调。”

**7. 供应商常犯的错**
- 一上来讲品种、产地、证书。
- 只讲自己产品多好，不讲商家怎么赚钱。
- 用“高端、稀缺、精品”这种空词。
- 不告诉商家放哪、卖给谁、怎么定价。
- 一次推太多SKU，商家记不住。

**总结：**
商家下单，不是因为听懂了你的品种，而是因为听懂了“这东西能代替谁、卖给谁、怎么卖、风险小”。你把新品翻译成他熟悉的菠萝、香蕉、橙子、苹果，再补上场景和利润，他就更容易听懂并下单。
