直接结论：**通常“损耗低”对最终毛利的影响更大，尤其是水果这种高损耗、短保、非标品。** 但这不是二选一，真正的分水岭是：**低采购价能不能在不推高损耗的前提下成立。**

可以把它拆成一个很实用的判断框架：

**1. 先看毛利公式**
水果最终毛利大致是：

**毛利 = 销售额 - 采购成本 - 损耗成本 - 运营成本**

其中损耗成本不只是“烂掉的货”，还包括：
- 失水、萎蔫、碰伤、过熟
- 挑拣报废
- 打折清货
- 报损
- 因卖相下降导致的降价销售

所以低价采购如果带来更高损耗，可能把毛利吃回去。

**2. 为什么损耗通常更关键**
水果毛利率看起来可能不低，但净利很薄。举例：
- 采购价降 10%，如果原采购成本占售价 70%，毛利大约改善 7 个点。
- 损耗率从 8% 升到 15%，如果按销售额口径，可能直接吃掉 7 个点甚至更多。
- 更麻烦的是，损耗高的品类往往还会带来：排面变差、顾客挑剩、周转变慢、员工处理成本上升。

也就是说，**低采购价是一次性账面优势，高损耗是持续性利润漏损。**

**3. 但低价不是没用，关键看条件**
低价采购只有在这些条件下才真正提升毛利：
- 品质稳定，货架期够长
- 周转快，能在 1-2 天内卖完
- 门店有强促销能力，能快速清货
- 冷链、陈列、催熟管理跟得上
- 损耗能被控制在可接受范围内

如果低价货是尾货、次果、过熟果、远距离运输果，通常损耗会显著上升，最后未必赚钱。

**4. 实操判断标准**
采购决策不要只看“进价”，要算**综合毛利**：

**综合毛利率 =（销售额 - 采购成本 - 损耗成本）÷ 销售额**

判断一个低价机会能不能做，看三点：
- 预计损耗率会不会比正常货高 3 个点以上
- 高出来的损耗金额，是否超过采购价降低带来的节省
- 周转天数能不能控制在品类安全线内

简单说：
- **低价 + 低损耗 = 真优势**
- **低价 + 高损耗 = 假优势**
- **高价 + 低损耗 = 稳但可能没竞争力**
- **高价 + 高损耗 = 最差**

**5. 最终建议**
如果只能选一个作为采购核心指标，优先选**低损耗、高周转、稳定品质**。  
采购价要在“不牺牲损耗和周转”的前提下去谈。

更准确地说：  
**短期看进价，长期看损耗；最终毛利由损耗决定下限，由进价决定上限。**  
对商超水果来说，**损耗低通常比价格低更影响最终毛利。**
