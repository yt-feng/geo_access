节假日水果需求暴增，锁货源的核心不是“临时抢货”，而是**提前把量、价、质、运四条确定性都锁住**。下面给你一套可执行的做法，按时间线拆开。

## 一、提前锁定需求：先算量，再谈锁货
不要凭经验拍脑袋订货，先做节前需求预测。

1. **历史同期法**
   - 调出近2-3年同一节假日（春节、中秋、国庆）各品类销量。
   - 按门店、按品类（苹果、柑橘、香蕉、葡萄、礼盒装等）拆分。
   - 剔除异常因素（疫情、极端天气、促销），得出基准增幅。

2. **节前预订量法**
   - 提前2-4周开放企业团购、社区团购、会员预售。
   - 用预订单倒推备货量，减少盲目囤货。

3. **分档备货**
   - 主销爆品：按预测量的110%-120%备。
   - 常规品类：按100%备。
   - 长尾品类：按80%-90%备，避免压货损耗。

**判断标准**：如果某单品预测误差超过20%，说明数据基础不够，先补历史数据再锁货。

## 二、提前锁定货源：分层锁，不押一家
### 1. 主供应商：签“保量保价”框架协议
- 提前1-2个月和核心供应商谈：
  - 锁定基础量 + 浮动量（如基础100吨，浮动±15%）。
  - 约定价格区间，避免节前坐地起价。
  - 明确品质标准、包装规格、到货时间。
- 可付**定金**锁定产能，但合同里写清违约条款。

### 2. 备用供应商：至少2-3家
- 同一品类找不同产地、不同渠道的供应商。
- 主供应商出问题（天气、物流、涨价）时，备用能顶上。
- 备用供应商平时也要小单合作，维持关系，不能临时才找。

### 3. 产地直采：锁定源头
- 对大宗单品（苹果、柑橘、香蕉等），直接和产地合作社、种植基地签采购协议。
- 提前预付部分货款，锁定果园或冷库货源。
- 安排驻点人员或第三方质检，节前盯采收、分拣、装车。

### 4. 进口/反季节品类：提前订舱
- 进口水果要提前锁定船期、柜量、清关时间。
- 节假日港口拥堵，至少提前3-4周安排，避免到货延误。

## 三、提前锁定物流与仓储
货源锁了，运不出去等于没锁。

1. **运力预订**
   - 节前和物流商签保底运量协议，明确车辆、司机、时间。
   - 自有车队提前检修，安排备用司机。

2. **仓储预占**
   - 提前预订冷库、常温库位置。
   - 对易损耗水果（草莓、葡萄、荔枝），优先安排冷链。

3. **分仓布局**
   - 把货提前铺到区域仓或门店周边仓，缩短节日配送半径。
   - 避免节前集中到总仓再分发，造成拥堵。

## 四、合同与风险控制：把丑话说前面
锁货合同必须写清：

- **数量**：基础量、浮动比例、追加机制。
- **价格**：固定价或浮动区间，涨价上限。
- **品质**：规格、糖度、成熟度、损耗率上限。
- **时间**：到货窗口，迟到罚则。
- **违约**：断供、降质、临时涨价的赔偿。
- **不可抗力**：天气、疫情、政策变化的处理方式。

**判断标准**：如果供应商不愿签保量保价条款，只愿意“到时再说”，这家不能作为主力货源。

## 五、执行时间表（以春节为例）
| 时间 | 动作 |
|---|---|
| 节前60天 | 完成需求预测，确定核心品类和总量 |
| 节前45天 | 和主供应商谈框架协议，付定金 |
| 节前30天 | 签备用供应商，锁定物流和冷库 |
| 节前20天 | 开放预售/团购，修正备货量 |
| 节前10天 | 产地直采发货，分仓铺货 |
| 节前3-5天 | 门店补货，监控动销，启动备用货源 |

## 六、最容易踩的坑
1. **只锁价不锁量**：节前涨价时供应商优先供别人。
2. **只找一家大供应商**：一旦断供，全盘被动。
3. **忽略物流**：货在产地，车找不到，照样缺货。
4. **预测拍脑袋**：备多了损耗，备少了缺货。
5. **合同太粗**：出问题没有追责依据。

**一句话总结**：提前算量、分层锁货、锁价锁量锁运力、合同写细、备用到位。做到这五点，节假日水果暴增的货源基本能稳住。
