水果到货不合格时，补货约定要同时解决三件事：**当天营业不断料、责任和费用不扯皮、后续验收有标准**。可从下面几个层面在采购合同或供应商管理规则里约定。

## 一、先约定“什么算不合格”

不要只写“质量不好”，要写成可判断的标准，例如：

- **外观**：腐烂、发霉、明显压伤、虫蛀、异味，单箱/单批次不合格比例超过约定值（如 5% 或 10%）。
- **规格**：品种、产地、等级、单果重量/直径、成熟度不符合订单。
- **温度/新鲜度**：冷链水果到货中心温度超标、叶片萎蔫、切开后变色等。
- **证件**：农残检测、检疫、进货凭证缺失。

同时约定：**验收以门店或中央仓收货时为准，拍照/视频留证，双方确认后即认定为不合格。**

## 二、补货方式要分场景约定

### 1. 当场可补的
约定供应商在**到货后 X 小时内**（如同城 2–4 小时）补送合格品。  
补货数量 = 不合格数量 + 因分拣、报废造成的损耗数量。  
补货费用、运费由供应商承担。

### 2. 当天无法补的
约定替代方案，避免门店停售：

- 供应商**先退款或冲抵货款**；
- 允许门店**就近紧急采购**，差价由供应商承担；
- 或供应商从其他仓/其他客户订单中**调拨同品项**；
- 若都没有，门店可临时调整菜单，但供应商仍需承担断货造成的约定违约金。

### 3. 多次不合格的
约定阶梯处理：

- 第一次：补货 + 书面警告；
- 第二次：补货 + 扣款/违约金；
- 第三次：暂停供货资格、终止合同，并赔偿门店紧急采购差价。

## 三、把“不影响营业”写成硬约束

可以在合同里加几条：

1. **补货时限**：同城 4 小时内，异地 24 小时内；超时视为断货。
2. **断货赔偿**：按该品项日均销售额或约定金额赔偿，避免只赔水果成本。
3. **紧急采购权**：供应商未按时补货，门店有权自行采购，差价和运费由供应商承担。
4. **优先补货义务**：供应商不得以“没货”为由拒绝，需提供替代品或调拨。
5. **验收留证**：门店收货时拍照、称重、记录批次，作为补货和扣款依据。
6. **月度对账**：补货、退款、扣款在当月货款中直接冲抵，不用每次现金结算。

## 四、操作上建议这样做

- **下单时**：写明品名、规格、数量、到货时间、验收标准。
- **到货时**：当场开箱抽检，不合格部分单独存放并拍照。
- **确认后**：给供应商发书面通知（微信/邮件均可），写明不合格数量、补货时限、补货方式。
- **补货后**：二次验收，仍不合格则按断货处理。
- **月底**：把补货记录、扣款记录和货款一起对账。

## 五、可以直接写进合同的条款示例

> 供应商交付的水果经门店验收不合格的，应在接到通知后 4 小时内补送合格品，补货费用由供应商承担。逾期未补货的，门店有权自行采购，所产生的差价、运费及营业损失由供应商承担。同一品项月度累计不合格超过 2 次的，门店有权暂停其供货资格并扣减相应货款。

核心原则是：**不合格必须补，补不了就赔，赔的同时允许门店自救。** 这样才不会因为一车水果不合格，把当天营业拖垮。
