判断一批香蕉，核心是分“现在能不能卖/放”和“接下来几天会怎么走”，不能只看黄不黄。按下面步骤做，基本能判断熟度和坏果风险。

**一、先看整体成熟度：看颜色、棱角、果柄**
1. **颜色分级**
   - 全青：未熟，适合长途/囤货，但催熟要时间。
   - 青黄相间：开始转熟，适合计划2–4天内出货。
   - 黄多青少：接近可售，适合1–2天内走货。
   - 全黄：已熟，适合立即卖，风险是继续变软、起黑点。
   - 黄带黑斑：即食熟度，零售可以，批发风险高，必须快走。
   - 黑斑连片/发黑：过熟或即将坏，别大批拿。
2. **看棱角**
   - 果身有明显棱角：偏生。
   - 棱角变圆润：正在熟。
   - 果身圆鼓、微软：熟度高。
3. **看果柄和果轴**
   - 果柄青绿、切口新鲜：货新。
   - 果柄发黑、干缩、发霉：存放久或冷链有问题。
   - 果轴有白霉、黑霉、酸味：整批风险高。

**二、摸硬度，判断实际熟度**
- 硬实：生，耐放。
- 稍有弹性：中熟，较安全。
- 轻按就凹：熟，必须快卖。
- 局部特别软、像水袋：内部可能已烂。
注意：冷藏后的香蕉手感会偏硬，要回到常温再看，或直接看颜色和果柄。

**三、查坏果风险：重点看这5处**
1. **果柄和果轴**
   - 发霉、发黑、长毛：冠腐病/轴腐病风险，整箱可能继续传染。
2. **果皮**
   - 水渍状斑、透明软斑：冷害或细菌性软腐。
   - 黑斑小而散：可能是正常熟斑，能快卖。
   - 黑斑大、凹陷、连片：坏果风险高。
3. **果肉**
   - 切开看：中心发黑、发褐、发水、有酒味/酸味，说明内部已坏。
   - 外表好但果肉硬心发黑：可能是冷害或未熟受冻。
4. **气味**
   - 清香：正常。
   - 酒味、酸味、发酵味：过熟或腐烂，整批要谨慎。
5. **箱内情况**
   - 有汁液渗出、纸箱湿软、霉味：坏果已经发生，且会传染。
   - 底层果比上层明显软烂：运输压伤或堆压伤，损耗会高。

**四、按“拿货目的”判断**
- **想囤3–7天再卖**：拿全青或青黄相间，果柄青、无霉、无软斑。
- **想2–3天卖**：拿青黄相间到黄多青少，硬度稍弹。
- **想当天/次日卖**：拿黄熟、少量熟斑，但不能有软烂、酒味。
- **做特价快销**：黄带黑斑可以，但必须现场挑掉坏果，且不能有霉和酸味。

**五、现场快速验货方法**
1. 随机抽3–5箱，不要只看最上面。
2. 每箱查上、中、下三层。
3. 每层随机拿2–3把，看果柄、摸硬度、闻气味。
4. 对可疑果切开2–3个，看果肉中心。
5. 问清：采摘时间、催熟情况、运输温度、到货天数。
6. 算损耗：如果一箱已有5%以上软烂/霉变，整批风险明显偏高；超过10%建议压价或拒收。

**六、简单结论**
- **安全货**：颜色均匀、果柄青、硬度适中、无霉无酸味、箱内干燥。
- **可拿但要快走**：黄熟、少量小黑斑、个别软果。
- **风险货**：果柄发霉、果身水渍软斑、酒酸味、箱内渗汁、底层大面积软烂。
