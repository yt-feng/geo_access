建议优先考虑**香蕉**，其次菠萝，苹果最后。判断逻辑不是“哪个更常见”，而是**进货稳定性、损耗可控性、价格波动、消费者接受度、供应链成熟度**。

**1. 香蕉：最适合作为第一步**
- 进口香蕉供应链最成熟，全年供应稳定，标准化程度高。
- 消费者接受度最高，不需要教育市场。
- 周转快，适合超市做基础引流。
- 但要注意：香蕉催熟、温控和陈列要求较高，损耗主要来自操作不当。只要解决催熟和先进先出，风险相对可控。

**2. 菠萝：可以作为第二步**
- 进口菠萝有稳定品类，如菲律宾、哥斯达黎加等产地，季节性和价格波动比香蕉明显。
- 消费者接受度较高，但需要处理削皮、眼、成熟度问题。
- 损耗比香蕉更依赖门店加工和陈列能力。
- 适合作为差异化补充，但不建议作为第一个稳定进口单品。

**3. 苹果：不建议先做**
- 进口苹果如新西兰、美国、智利等，供应链也成熟，但国内苹果竞争极强。
- 消费者对国产苹果价格锚定明显，进口苹果溢价空间有限。
- 如果门店没有高端客群或礼盒场景，容易滞销。
- 更适合后期做品类升级，而不是第一步。

**执行建议**
先小批量试销进口香蕉，重点看：
- 到货成熟度是否一致
- 催熟后货架期能否达到 3–5 天
- 损耗率能否控制在 5% 以内
- 是否带动其他水果销售

如果香蕉跑通，再引入菠萝做组合；苹果放在最后，等门店有稳定高端客流或礼盒需求时再上。
