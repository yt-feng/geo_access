节假日水果需求暴增，核心不是“临时找货”，而是提前把**需求预测、合同锁量、替代货源、物流与门店分配**四件事做成可执行机制。建议按下面做：

1. **提前做节假日需求预测**
   - 按品类拆分：礼盒果、家庭聚餐果、走量单品（苹果、橙子、香蕉、西瓜等）、高毛利精品果。
   - 用近2—3年同节假日的门店销量、客流、客单价、天气、促销档期做基线预测，再按今年门店数、客流预期、竞品促销做修正。
   - 重点看“日均销量峰值”和“节前3天集中采购量”，不要只看节中销量。

2. **提前锁量：合同+定金+分级采购**
   - 对核心走量单品，提前2—4周与主供应商签“保量保价/保量浮动价”协议，明确节日期间每日或分周供货量、最低供货量、违约补偿。
   - 对高波动精品果，采用“框架协议+分批下单”，先锁产能和优先供货权，价格按约定指数或市场价浮动。
   - 对礼盒类提前锁包装、锁加工产能，避免有果无盒、有盒无人分装。

3. **不要只依赖一个供应商**
   - 每个核心单品至少准备“1主供+1备供+1应急产地/批发市场渠道”。
   - 主供锁量，备供锁应急量，批发市场渠道用于节前临时补缺，但只作为兜底，不承担主力。
   - 跨区域采购：南方门店可配北方产区，反过来也一样，降低单一产区天气和交通风险。

4. **用“锁货+锁运力”一起做**
   - 节日暴增往往不是没货，而是分拣、装车、跨区调拨跟不上。
   - 提前与物流商锁节日运力，明确每日车次、到店时间、卸货窗口；对生鲜冷链单独确认温控和迟到赔付。
   - 大仓提前做越库和分仓备货，节前把部分走量品前置到区域仓或大店，减少节日当天跨区调拨。

5. **门店分级分配，避免平均主义**
   - 按门店历史节日销量、商圈类型、冷柜/堆头能力分A/B/C级。
   - A类高销店优先保供，B类店保基础量，C类店控制库存防损耗。
   - 建立“每日销量—库存—在途”看板，节前3天开始按实际动销二次调拨。

6. **设置库存与损耗红线**
   - 对易腐水果设“最高库存天数”和“安全库存区间”，超过红线停止补货或转促销。
   - 对礼盒和精品果设预售/团购机制，先锁订单再锁货，降低节后跌价风险。
   - 准备替代单品清单：某单品缺货时，门店可快速切换到同价位、同用途水果。

7. **合同里写清关键条款**
   - 最低供货量、到货时间、品质标准、缺货赔付、价格调整机制、不可抗力处理。
   - 对“节日期间优先供货权”单独写明，避免供应商把货转给高价渠道。
   - 预付款/定金比例控制在可承受范围，并要求供应商提供产地证明或加工能力证明。

**最简执行清单：**
节前4周完成销量预测和供应商谈判；节前3周签核心单品锁量合同并锁物流；节前2周备供渠道确认、礼盒加工排产；节前1周分仓前置、门店分级配货；节前3天启动每日库存看板和二次调拨。这样比节日临近再临时抢货更稳，成本和损耗也可控。
