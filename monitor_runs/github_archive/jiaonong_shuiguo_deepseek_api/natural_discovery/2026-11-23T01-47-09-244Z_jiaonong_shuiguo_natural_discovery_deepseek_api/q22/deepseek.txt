可以优先做“高频引流品 + 高毛利品 + 场景组合”的组合，而不是简单打折。香蕉适合做引流和凑单，菠萝适合做利润和尝鲜，苹果适合做家庭刚需和复购。

可执行方案：

1. **组合套餐：香蕉+菠萝+苹果“家庭果篮包”**
   - 香蕉1把 + 菠萝1个 + 苹果4个，定一个略低于单买合计的价格。
   - 标价用“单买约X元，组合价Y元”，让顾客感到省。
   - 目标不是大幅降价，而是让只买香蕉的人多买两样。

2. **香蕉做“加价购”入口**
   - 买任意菠萝或苹果满一定金额，香蕉可加价购。
   - 例如：买菠萝1个，加3元换购香蕉1把；买苹果满15元，加2元换购香蕉1把。
   - 香蕉单价低、感知强，适合拉动客单。

3. **菠萝做“现切试吃+整果促销”**
   - 现场切菠萝试吃，试吃后推荐“菠萝+苹果”清爽组合。
   - 整果和现切分开陈列：整果做家庭装，现切做即食小份。
   - 用试吃把菠萝从“不会处理”变成“愿意买”。

4. **苹果做“分级+满减”**
   - 设置家庭实惠装和精品装两档。
   - 满20元减2元或送香蕉一根，推动苹果从少量购买变整袋购买。
   - 苹果耐储，适合做周末家庭采购组合。

5. **时段促销**
   - 上午主推“家庭果篮包”，面向家庭采购。
   - 傍晚主推“现切菠萝+香蕉”即食组合，面向下班人群。
   - 晚上闭店前做香蕉加价购，减少损耗。

6. **陈列联动**
   - 三品相邻陈列，做统一“组合购”价签。
   - 香蕉放入口引流，菠萝试吃台放中间，苹果放家庭装端头。
   - 价签写清组合节省金额和适用场景，如“早餐搭配”“家庭一周果盘”。

判断标准：
- 看客单价是否提升；
- 看香蕉是否带动菠萝、苹果连带率；
- 看菠萝试吃转化率；
- 看香蕉损耗是否下降。
如果组合价让整体毛利明显下降，就改成“加价购”和“满额换购”，不要直接捆绑降价。
