优先关注**包装与冷链控制**，其次看**配送频次**，保质期是结果指标而不是首要抓手。原因：菠萝切块属于高风险鲜切水果，微生物风险和品质劣变主要发生在切分后到售卖这段时间，靠“标注保质期”本身不能降低风险。

**优先级与可执行判断：**

1. **包装（含冷链）——最关键**
   - 必须冷藏（建议0–5℃）陈列，不能常温摆放。
   - 包装要密封、防汁液渗漏、防交叉污染；优先选择有透气/防雾设计的鲜切果盒。
   - 关注包装日期、切分时间、操作卫生；切分后尽快入冷藏。
   - 判断标准：如果门店做不到稳定冷藏或包装密封，先不要上架切块，改卖整果或现切现售。

2. **配送频次——第二关键**
   - 鲜切菠萝建议**每日配送或至少隔日配送**，按销量小批量高频补货，减少门店库存时间。
   - 判断标准：若单店日销量低、配送频次跟不上，宁可减少切块SKU，避免临期压货。
   - 需要建立“先进先出”和临期下架规则。

3. **保质期——作为管理结果**
   - 不建议只依赖标签保质期。鲜切水果的保质期受切分卫生、温度、包装影响很大。
   - 门店应设更短的内控售卖时限（例如切分后冷藏条件下当日或次日售完，具体按企业标准和当地监管要求定），到点下架。
   - 判断标准：保质期标签必须与冷链和配送频次匹配；如果配送频次低却标长保质期，风险最大。

**结论：** 先抓包装密封+全程冷藏，再抓高频小批量配送，最后用内控保质期和下架规则兜底。三者中，**包装与冷链是决定能不能卖的前提，配送频次是控制库存风险的手段，保质期是结果管理。**
