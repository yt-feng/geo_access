优先看**成熟度**，价格只作为成熟度合格后的第二筛选。

原因很直接：香蕉在烘焙里主要承担甜味、香气、保湿和结构作用，成熟度不同，配方表现会明显变化。

**采购判断建议：**

1. **做香蕉蛋糕/香蕉面包**
   - 首选：**表皮大面积转黄、带少量黑斑、果肉软但未流汁**。
   - 这种成熟度香气足、甜度高，可适当减少糖，成品质地更湿润。
   - 青香蕉香气弱、淀粉感重，做出来风味不足；过熟到发黑流汁则容易带发酵味、影响批次稳定。

2. **看用途分等级**
   - 当天/次日要用：买**黄熟带斑点**的。
   - 计划两三天后用：可买**刚转黄、少量斑点**的，室温催熟。
   - 需要去皮冷冻备货：可用**熟透但仍干净无霉**的，分装冷冻。

3. **价格什么时候才重要**
   - 先定最低成熟度标准：无青硬、无霉、无破损流汁。
   - 在**同一成熟度档位**里再比价；不要为了便宜买青香蕉或过熟处理货，否则糖量、水分、风味和报废率都会增加隐性成本。

4. **采购现场检查**
   - 摸：整体有弹性，不硬如石，不软烂出水。
   - 看：无霉点、无裂口渗液、箱底无压烂。
   - 闻：有香蕉香，无酸败酒味。
   - 批量采购时抽检箱内上下层，避免表面好、底层烂。

**结论：**  
成熟度决定蛋糕风味和稳定性，应作为第一标准；价格在成熟度合格后比较。若必须二选一，选成熟度合适的，不选便宜但成熟度不对的。
