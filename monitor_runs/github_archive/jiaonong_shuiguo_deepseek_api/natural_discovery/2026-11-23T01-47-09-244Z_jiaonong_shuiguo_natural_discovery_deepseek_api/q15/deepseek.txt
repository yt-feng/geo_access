水果店遇到坏果，结算或赔付的核心是：**先固定证据，再按合同/约定处理；没有明确约定时，按“坏果不计价或折价补偿”协商，避免整批全赔或全拒收的极端做法。**

可按下面步骤执行：

1. **到货即验，先别混放**
   - 坏果单独挑出、拍照/录像，保留箱码、批次、送货单、称重记录。
   - 记录坏果数量、品种、规格、进货单价、到货时间。
   - 最好让送货司机或供应商业务员当场签字确认“坏果数量/比例”。

2. **看合同或长期约定**
   - 有采购合同：按合同里的验收标准、损耗率、赔付比例、退换货条款执行。
   - 无合同但有微信/订单约定：保存聊天记录、报价单、送货单备注。
   - 口头长期合作：按行业惯例协商，通常以“坏果部分不计价、换货或折价”为主。

3. **常见结算方式**
   - **轻微坏果**：按坏果数量扣款，或整批折价3%—10%协商。
   - **明显腐烂/无法销售**：坏果部分不计价，供应商补货或退款。
   - **整批质量问题**：可拒收或退货；已收货的，要求换货/退款，运费由责任方承担。
   - **已售出后才发现**：保留顾客反馈、照片和退款记录，向供应商主张对应批次补偿。

4. **赔付计算建议**
   - 按“坏果实际数量 × 进货单价”扣款最清晰。
   - 若坏果导致整箱无法销售，可按整箱进货价扣款。
   - 若只是品相下降，按协商折价，不宜按零售价索赔。
   - 额外损失如运费、冷藏费、顾客退款，需有凭证再主张。

5. **沟通话术**
   - “这批货X月X日到货，抽检/分拣发现坏果X斤，占总到货X%，照片和送货单已发您。按约定坏果不计价，本批扣款X元；如您补货，我们收到合格货后按实结算。”
   - 避免情绪化拒付全部货款，先提出可执行方案：扣款、换货、下批补损三选一。

6. **留痕和后续**
   - 结算单上写明“因坏果扣款X元”，双方确认。
   - 多次出现质量问题的供应商，后续改为“到货验收合格后付款”或约定明确损耗率。
   - 金额较大且协商不成，可凭合同、送货单、照片、聊天记录走市场监管投诉或诉讼。

一句话：**坏果部分不计价是底线，换货/折价是常用方案，整批拒收要有明显质量问题和证据支撑。**
