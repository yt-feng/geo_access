建议以“整果为主、切果为辅”，但前提是先看你的门店类型和客流。不能一概而论，给你一个可执行的判断框架：

## 一、先按门店场景选主策略

| 门店类型 | 更适合的主打法 | 原因 |
|---|---|---|
| 社区生鲜店、菜市场档口 | **整果为主** | 客流价格敏感，整果毛利可控、损耗低，家庭客愿意自己削 |
| 商超大卖场、精品超市 | **整果+切果并行** | 有加工区、有即食需求，切果能拉高客单和冲动购买 |
| 写字楼/商圈便利店、水果切盒店 | **切果为主** | 即食、单人份需求强，整果反而周转慢 |
| 学校、医院、交通枢纽周边 | **切果为主** | 即时消费、无加工条件 |

## 二、整果 vs 切果的核心账

**整果优势：**
- 损耗低、货架期长、采购容错高
- 单价低、走量大，适合做引流
- 不需要加工人力和设备

**整果劣势：**
- 家庭变小后，大菠萝一次吃不完，购买门槛高
- 不会削皮的年轻客群流失

**切果优势：**
- 即食、便携，客单价和毛利率通常更高
- 能消化外观瑕疵果，降低整果报损
- 带动连带购买（酸奶、其他水果）

**切果劣势：**
- 需要加工间、刀具消毒、冷链和时限管理
- 切后货架期短，卖不掉就是纯损耗
- 人工成本高，出品标准化难

## 三、给你一个可落地的组合方案

1. **整果做引流**：选1—2个规格（如9.9元/个、称重），放在入口堆头，主打“回家自己削更划算”。
2. **切果做利润**：只做**小份盒装（约200—300g）**，定价对标周边便利店，放在收银台或即食区。
3. **切果原料用“次优果”**：外观有瑕疵但品质正常的果优先切盒，好果留整果卖，这是降损关键。
4. **先小批量测试**：切果每天限量出品，连续观察7—14天的**售罄时间、报损率、毛利率**，卖不完就减量，不要硬铺。
5. **设加工门槛**：没有独立加工间、冷藏条件和专人负责的门店，不建议做切果，合规和食安风险不划算。

## 四、判断结论

- 如果你门店**家庭客多、无加工条件**：卖整果。
- 如果**年轻客/即食客多、有加工和冷链**：整果保流量，切果赚毛利。
- 最稳的做法是**整果为主、切果小份限量试销**，用两周数据决定切果是否放量。

一句话：**整果是基本盘，切果是增量盘；先测损耗，再定比例。**
