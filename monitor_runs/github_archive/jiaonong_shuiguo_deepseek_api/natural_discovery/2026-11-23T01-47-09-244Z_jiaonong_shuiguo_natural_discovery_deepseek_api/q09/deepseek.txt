旺季怕断货，和供应商谈之前先明确：**你不是只问“能不能供”，而是要把“断货风险”拆成可执行条款。** 建议按下面几组问题问，并尽量落实到数量、时间、违约处理。

**1. 供应能力与旺季分配**
- 旺季你每天/每周能稳定给我多少箱/斤？按品类分别说。
- 你旺季主要供哪些客户？我在你客户里排什么优先级？
- 如果我临时加量，提前多久说你能接？最多能加多少？
- 你自有货源/基地/批发市场占比多少？某个单品缺货时替代方案是什么？
- 去年旺季你有没有断供过？哪些品类最容易断？

**2. 价格与锁价**
- 旺季价格怎么定？是随行就市还是提前锁价？
- 锁价锁多久？锁量不锁价还是量价都锁？
- 涨价提前几天通知？我有没有拒绝涨价或换品的权利？
- 同一规格、同一等级，给我的价格是否不高于你给同区域其他水果店的价格？
- 运费、装卸、损耗、包装费谁承担？到店价还是出库价？

**3. 品质标准与验收**
- 每个品类按什么等级、规格、成熟度、糖度、果径交货？
- 允许的坏果率/损耗率是多少？超出怎么赔或换？
- 到货后多久内可以提出质量异议？拍照留证是否有效？
- 次果、尾货、催熟果会不会混进旺季货里？怎么保证批次一致？

**4. 订单、配送与应急**
- 每天几点前下单？多久送到？旺季配送会不会延迟？
- 最少起订量多少？能不能多品拼车？
- 如果当天没送到，影响我营业怎么处理？
- 你有没有备用仓库/备用车辆？极端天气或交通管制时怎么保供？
- 临时缺某个单品，能否提前通知并推荐替代品？

**5. 断货与违约条款**
- 已确认的订单你断供，怎么赔？按缺货金额比例赔，还是补差价让我从别处调货？
- 连续断供几次我可以终止合作？
- 我临时取消订单，提前多久不承担责任？
- 质量问题导致的退货、换货、损耗，费用谁出？

**6. 结算与账期**
- 现结还是账期？账期多久？
- 旺季能不能临时提高授信额度？
- 退货、换货、赔款怎么在货款里扣？
- 对账周期和方式是什么？有没有书面单据？

**7. 合作稳定性**
- 你主要做哪些水果？哪些是你的强项，哪些是转手货？
- 能不能带我去看仓库/档口/基地？
- 有没有长期合作客户可以侧面了解？  
  注意：这条要礼貌问，对方不愿意提供也正常，不要强求。
- 如果我也从别家补货，你是否介意？最好提前说清楚，避免你以为我“二选一”。

**谈的时候重点抓三件事：**
1. **旺季保量协议**：写清品类、周供应量、加量提前期、优先级。  
2. **断供赔偿**：不要只听“放心，不会断”，要写“断了怎么补”。  
3. **品质验收标准**：坏果率、规格、异议时限写进单子或聊天记录。

最后提醒：口头承诺尽量落到微信文字、订单单或简单协议里，至少保留聊天记录。旺季前先小批量试单，观察准时率、损耗率和缺货时的处理态度，再决定是否把主量押给他。
