连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是**价格机制、质量标准、损耗责任、交付波动、账期和退出机制**。建议重点盯住下面这些条款：

1. **价格与调价机制**
   - 坑：只写“随行就市”或“参考市场价”，年底容易扯皮。
   - 建议：约定基准价、调价触发条件（如批发市场指数周均价波动超±5%）、调价频率、书面确认流程和生效时间。
   - 明确促销、临期、节日备货是否另定价。

2. **质量标准与验收**
   - 坑：只写“新鲜、无腐烂”，没有可执行标准。
   - 建议：按品类写清规格、糖度、大小、成熟度、农残检测、包装和冷链温度；约定抽检比例、验收时限、不合格判定和拒收/降级处理。
   - 明确农残超标、食品安全事件的召回、赔偿和终止权。

3. **数量与交付弹性**
   - 坑：年度总量写死，但门店销量波动大；或供应商只承诺“尽量供货”。
   - 建议：约定年度框架量+月度/周滚动订单，设置±10%—20%的弹性区间；明确缺货、迟延、短装的处理和替代供货义务。
   - 旺季、极端天气、节假日要有备货和应急供应条款。

4. **损耗与退换货**
   - 坑：水果损耗高，合同没写清到店前损耗、门店滞销、品质下降谁承担。
   - 建议：明确交付前的损耗由供应商承担；到店验收后的责任分界；滞销或临期是否可退换、比例上限、时限和费用。
   - 不要接受“一经验收概不负责”的笼统条款。

5. **账期、结算与扣款**
   - 坑：账期过长、对账口径不清、质量扣款和促销费用随意扣。
   - 建议：写清对账周期、发票要求、付款节点；所有扣款须有书面依据和双方确认；违约金、质量赔偿上限要合理。
   - 注意“暂扣货款”“无理由扣款”条款。

6. **独家/排他及最低采购量**
   - 坑：供应商要求独家供货，但超市又无法保证采购量；或最低采购量过高，完不成有罚则。
   - 建议：排他范围限定到品类/区域/渠道；最低采购量与实际销售预测挂钩；未达标责任要对等。

7. **违约、赔偿与退出**
   - 坑：只约束供应商，超市断货、迟延付款没有责任；终止条件模糊。
   - 建议：双向违约责任；明确重大质量事故、连续断供、农残超标等可直接解约；约定解约后的库存处理、尾款结算和过渡期。
   - 违约金不宜过高，避免被认定显失公平。

8. **不可抗力与市场异常**
   - 坑：把天气、疫情、价格暴涨都写成不可抗力，供应商可随意不供货。
   - 建议：限定不可抗力范围；约定异常行情下的协商机制和替代供应方案，而不是单方免责。

9. **知识产权与品牌宣传**
   - 坑：供应商要求门店使用其包装、宣传物料，后续费用或侵权责任不清。
   - 建议：明确包装、商标使用授权范围、期限和费用；促销物料谁提供、谁承担。

10. **合同期限与自动续约**
   - 坑：自动续约条款导致到期后被动续签。
   - 建议：明确续约需双方书面确认；年度复盘销量、质量、履约后再决定。

实操上，建议做三件事：**把质量标准和验收流程写成附件；把价格公式和调价流程写清楚；把损耗、退换货和扣款规则量化**。这三块最容易在履行中产生争议。合同条款最终应结合当地法规和双方实际业务，由法务或专业律师审核。
