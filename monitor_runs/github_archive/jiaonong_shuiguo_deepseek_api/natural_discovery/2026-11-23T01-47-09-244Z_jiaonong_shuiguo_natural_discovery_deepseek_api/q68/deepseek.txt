判断供应商能不能“按时到车”，核心不是听承诺，而是看 **他有没有稳定货源、装车能力、履约记录和可验证的排车证据**。你可以按下面这套方法做，比较适合水果批发这种时效强的场景。

### 1. 先看供应商类型，不看话术
优先判断他是哪一类：
- **自有基地/合作基地**：按时到车概率通常更高，但也要看采摘和装车队。
- **产地代收/经纪人**：灵活，但容易同时接多单，旺季容易压车。
- **二道贩子/信息部**：最需要警惕，常见问题是临时没货、换车、加价、拖延。

**建议**：新供应商第一次合作，不要只靠电话微信承诺，尽量要求视频看货、看装车现场或让当地熟人验货。

### 2. 要“可验证的排车证据”
不要只问“能不能按时到”，要让他给出具体信息：
- 车牌号、司机电话、车型载重；
- 装车地点、预计装车时间；
- 当前香蕉在哪块地/哪个冷库/哪个档口；
- 是否已定好装车工人和包装材料；
- 发车后要求拍 **装车视频、过磅单、车牌与货物同框照片**。

如果对方支支吾吾，只说“放心”“肯定到”，但给不出车牌和装车点，风险就高。

### 3. 看历史履约记录
问清楚并尽量核实：
- 最近一个月发过几车？
- 有没有固定线路和固定司机？
- 能不能提供两三个老客户联系方式？
- 之前有没有压车、换货、迟到记录？

水果行业里，**稳定比便宜重要**。一个报价低但经常拖车的供应商，综合损耗和档口空档成本更高。

### 4. 用“小单试合作”验证
第一次别直接下大单。可以：
- 先走一车小批量；
- 约定明确装车时间、到车时间、迟到处理；
- 观察他是否主动同步装车进度；
- 看装车质量、蕉条成熟度、包装是否符合约定。

一车试下来，比聊十次都准。

### 5. 合同/微信里写清楚时间节点和违约责任
至少写清楚：
- 约定装车时间；
- 约定发车时间；
- 约定到达市场/档口时间；
- 迟到几小时怎么处理；
- 临时没货、换货、加价怎么赔；
- 装车后必须提供车牌、司机电话、过磅单和装车视频。

微信聊天也算证据，关键节点让对方文字确认，不要只语音。

### 6. 旺季要额外留缓冲
香蕉旺季、雨季、节假日前后，装车和运输都容易延误。判断供应商时重点看：
- 他是否提前锁定工人和车辆；
- 是否有多台车备用；
- 是否敢明确告诉你“今天装不了”；
- 是否愿意给你排车顺序和备用方案。

**敢提前说风险的供应商，往往比满口保证的更可靠。**

### 7. 一个简单判断标准
如果供应商能做到下面 4 条，按时到车概率较高：
1. 能马上给出装车地点和车牌/司机信息；
2. 能视频看货或看装车现场；
3. 有近期稳定发车记录，愿意给老客户核实；
4. 愿意把时间节点和违约责任写进微信/合同。

反之，如果只会催你打定金、不给车牌、不给装车点、不让看货、临时换车换价，就要谨慎。

**实操建议**：新供应商先用“小单+明确时间节点+装车视频+过磅单+迟到扣款”合作一车；老供应商也保持每天确认装车进度。水果批发最怕档口断货，供应商的“可验证履约能力”比口头承诺重要得多。
