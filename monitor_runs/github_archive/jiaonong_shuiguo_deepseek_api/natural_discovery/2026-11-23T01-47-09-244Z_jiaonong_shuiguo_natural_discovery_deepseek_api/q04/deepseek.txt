可以直接把采购要求写成“熟度标准 + 到货节奏 + 验收与退换”三句话，采购时按这个提：

1. **熟度要求：分批次要不同熟度，不要一批全熟**
   - 主销批次：要**青黄交接、果指八成黄以内**的香蕉，果肉硬、无黑斑、无软塌，适合再放2～4天销售。
   - 即卖批次：可以少量要**表皮全黄但无黑点、无软化**的，最多1～2天卖完。
   - 明确拒收：**大面积黑斑、果柄发黑、明显软烂、有酒味/酸味、果指脱把**的不要。
   - 如果供应商按“几成熟”报价，建议要求：主批**七成熟左右**，即卖批**八至九成熟**，并写进订单备注。

2. **到货时间：少量多次，避开周末和高温时段**
   - 要求**分2～3次到货**，不要一次压大货；每次到货量按你1～2天销量定。
   - 到货尽量安排在**早上开门前或傍晚闭店前**，避开中午高温和周末前一天大量到货。
   - 明确“**下单后X小时/指定日期到货**”，比如每天早7点前到当日量，隔天补一次。
   - 节假日提前问清供应商放假和物流安排，要求**节前最后一次到货只给七成熟**。

3. **验收和退换要求：写进采购单**
   - 到货当场抽检：看果柄、果指硬度、表皮黑斑比例、有没有异味。
   - 要求供应商承诺：**到货24小时内发现过熟、软烂、黑斑超标的，可退换或折价**。
   - 同一供应商连续两次熟度超标，减少订单或换供应商。
   - 采购单上写清楚：品种、数量、熟度、到货时间、验收标准、退换条件，口头说容易扯皮。

一句话采购话术：**“我要七成熟为主、少量八至九成熟即卖，分早/晚两次到货，每次按1～2天销量给；到货有黑斑软烂超标的24小时内退换。”** 这样比只要求“别太熟”更能执行。
