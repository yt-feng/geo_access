下午茶水果批量配送，供应商选择核心看**稳定性、损耗控制、配送履约**三项，价格反而排后面。可以按下面的框架筛。

## 一、先明确需求再找供应商
- **人数与人均量**：按人均 150–250g 估算，20 人约 3–5kg，切果则按 200g/人。
- **形式**：整果（耐放、成本低）还是鲜切果盒（体验好、有加工损耗和食品安全要求）。
- **频次与时间**：每周几次、固定几点前送达，这直接决定供应商能否接单。
- **预算**：整果人均 5–10 元、鲜切人均 10–20 元是常见区间，先定上限再谈。

## 二、供应商类型对比
| 类型 | 优点 | 风险 |
|---|---|---|
| 本地批发市场果商 | 价格低、品类全 | 配送和售后弱，起送量要求高 |
| 生鲜电商企业购/B端 | 履约稳定、有发票和对账 | 单价略高，品类受平台限制 |
| 鲜切果盒专营店 | 开箱即食、体验好 | 需确认加工资质和冷链 |
| 本地果园/合作社 | 应季品质好、价格优 | 品类单一，配送不稳定 |

**建议**：日常整果选本地果商或生鲜B端；鲜切选有食品经营许可的专营店；重要活动可组合采购。

## 三、必查的硬性条件
1. **资质**：营业执照、食品经营许可证；做鲜切必须有，且确认加工环境。
2. **配送能力**：自有车辆或稳定合作物流，能否承诺送达时间窗、迟到如何处理。
3. **起送量与账期**：是否满足最低起送金额，能否月结、开票。
4. **售后条款**：坏果率标准（常见约定 3%–5% 内包赔或补送）、拍照报损流程、响应时效。

## 四、用试单验证，别只看报价
先小批量试 2–3 家，重点记录：
- **到货准时率**和包装完好度；
- **坏果率**：随机抽检称重，超过约定比例直接淘汰；
- **品相一致性**：大小、成熟度是否均匀；
- **售后响应**：报损后多久补送或退款。

试单 2–3 次稳定后再签长期协议。

## 五、合同里写清楚的条款
- 单品规格（如苹果直径、单果重量区间）；
- 送达时间窗与迟到违约金；
- 坏果率上限及赔付方式；
- 价格调整机制（应季水果价格波动大，约定调价周期）；
- 食品安全责任归属。

## 六、避坑提醒
- **别只比单价**：低价供应商常靠缺斤少两或高坏果率找补，算“实际可食用量单价”更准。
- **应季优先**：反季水果成本高、品质不稳定，下午茶选当季品类性价比最高。
- **鲜切慎选小作坊**：切果涉及清洗、刀具、冷藏，资质不全的食品安全风险高。
- **避开周一早高峰配送**：很多供应商周一爆单，容易迟到，可约定提前或错峰。
