大型超市的水果供应商，核心要同时满足“食品安全合规能力”和“冷链物流交付能力”。可按下面清单判断。

## 一、食品安全能力
1. **主体资质与许可**
   - 营业执照、食品经营许可证/食品生产许可证（如涉及分拣加工、切果）。
   - 种植/养殖源头合作证明、产地证明、购销合同。
   - 进口水果需海关报关、检验检疫证明等。

2. **农残与污染物检测**
   - 具备农残快检能力或委托第三方检测，按批次提供检测报告。
   - 能追溯检测批次与对应货源，出现异常可召回。
   - 重点品种有专项检测计划，如高风险叶菜、进口水果。

3. **追溯与记录**
   - 批次化追溯：产地—加工—仓储—配送—门店可查。
   - 进货查验、销售记录、不合格品处理记录完整。
   - 能配合超市做供应商审核和飞行检查。

4. **仓储与加工卫生**
   - 仓库防虫防鼠、温湿度监控、清洁消毒记录。
   - 分拣包装区符合卫生要求，人员健康证、工服、洗手消毒。
   - 生熟/不同品类分区，避免交叉污染。

5. **质量与召回体系**
   - 验收标准（糖度、硬度、色泽、规格、瑕疵率）。
   - 不合格品隔离、退货、销毁记录。
   - 召回预案和食品安全事故应急机制。

6. **保险与合规文件**
   - 食品安全责任险。
   - 员工健康证、培训记录。
   - 符合超市供应商准入审核表要求。

## 二、物流与冷链能力
1. **冷链设施**
   - 预冷能力：产地或中转仓预冷，缩短田间热。
   - 冷库、冷藏车、温控记录仪，按品类设定温度。
   - 全程温控记录可导出，异常报警。

2. **运输与配送**
   - 冷藏/保温车辆数量和调度能力匹配超市订单量。
   - 支持多温区配送，避免水果与冻品、常温品混装污染。
   - 按门店/DC时效配送，能应对早配、日配、节假日峰值。

3. **仓储与分拣**
   - 自有或稳定合作的DC/中转仓。
   - 分拣、贴标、包装能力，支持超市规格和标签要求。
   - 先进先出、批次管理、库存周转控制。

4. **损耗与品质控制**
   - 采后处理：分级、预冷、包装、保鲜。
   - 运输防震、防压、防日晒雨淋。
   - 到店验收合格率、损耗率可量化。

5. **数字化与应急**
   - 订单、库存、温控、追溯系统对接超市。
   - 缺货、延迟、温控异常有替代方案和赔付机制。
   - 台风、寒潮、旺季有备货和备用运力。

## 三、超市通常重点审核的硬指标
- 证照齐全且在有效期内。
- 每批次可提供检测报告或快检记录。
- 冷链全程温控记录可查。
- 追溯链条完整，能定位到批次和门店。
- 有召回、投诉、事故处理流程。
- 配送准时率、到货合格率、损耗率达标。
- 有食品安全责任险和应急能力。

**结论**：供应商至少要具备“合规证照+批次检测+可追溯+冷链温控+分拣配送+召回应急”六项能力；大型超市还会看其检测频率、温控记录完整性、配送准时率和异常处理机制。
