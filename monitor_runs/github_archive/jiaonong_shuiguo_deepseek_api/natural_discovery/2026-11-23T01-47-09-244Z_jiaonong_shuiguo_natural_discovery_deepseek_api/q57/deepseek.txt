结论：大多数餐饮连锁采购水果，优先采用“中央厨房/配送中心统一收货”，但按品类和门店能力做例外管理。

**统一收货更好的原因**
- **品控一致**：水果等级、成熟度、农残/证照、温控标准集中执行，减少门店“看人下菜”。
- **成本与议价**：集中采购、集中验收，损耗和责任可追溯，供应商更好管理。
- **食品安全**：统一索证索票、批次记录、快检和追溯，出问题能快速锁定批次。
- **效率**：门店少做验收、退货、对账，避免高峰期占用人手。
- **数据统一**：到货率、损耗率、退货率口径一致，便于考核供应商和门店。

**适合门店分开收货的例外**
- **极短保、易损、成熟度敏感**：如草莓、蓝莓、荔枝、桃等，长距离中转损耗大，可“统采+门店直配验收”。
- **门店密度低、配送半径大**：统一配送成本高于直送时。
- **门店有专业验收能力**：有冷藏库、验收员、快检能力，且能执行统一标准。
- **本地特色小批量**：区域限定、季节性强的水果。

**建议落地方式**
1. **A类统收**：苹果、橙、香蕉、西瓜等耐储水果，中央厨房统一收货、分拣、配送。
2. **B类直配统管**：短保易损水果由供应商直送门店，但必须用总部统一合同、标准、验收表和拍照留证，门店只做“到货验收”，不合格拒收并同步总部。
3. **设置验收红线**：糖度/成熟度、外观、温控、证照、批次、退货时限，统一写进合同和SOP。
4. **考核**：统一统计到货合格率、损耗率、退货率、门店验收差错率，按月复盘。
5. **小范围试点**：先选一个区域/10—20家门店跑3个月，对比损耗、人工、配送成本再定。

一句话：**能统收的统收，短保易损的“统采直配+总部强控验收”，不要放成门店各自采购。**
