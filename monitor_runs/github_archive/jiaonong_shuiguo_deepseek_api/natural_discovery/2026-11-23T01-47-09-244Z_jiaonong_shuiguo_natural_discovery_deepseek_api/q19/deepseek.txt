优先看**切果损耗**，其次甜度，再看外观，大小最后。原因和可执行判断如下：

1. **切果损耗优先**
   - 超市菠萝通常有整果卖和切果卖两种形态，切果损耗直接决定毛利。
   - 关注：去皮去眼损耗率、黑心/水心病比例、切开后氧化变色速度、当日切果报废量。
   - 可执行动作：到货先抽检切开2–3个，记录出肉率和坏果率；损耗高的批次改整果促销或做果汁，不硬切。

2. **甜度第二**
   - 甜度影响复购和切果试吃转化。
   - 可执行判断：用糖度计抽测，一般可售菠萝糖度建议在**12°Brix以上**；低于10°Brix的批次适合做促销或加工，不建议作为主推切果。
   - 没有糖度计时，看品种、产地、成熟度，试吃比只看颜色可靠。

3. **外观第三**
   - 外观决定第一眼购买，但不是利润核心。
   - 看：果眼深浅、表皮有无碰伤霉斑、冠芽新鲜度、果形是否端正。
   - 外观差但内部好的，可转切果；外观好但切开黑心的，必须降级处理。

4. **大小最后**
   - 大小主要影响定价和客群匹配，不是质量核心。
   - 大果适合家庭整果，小果适合切果杯或单人份；关键看出肉率和单果成本，不盲目追大。

**一句话结论：超市卖菠萝，先控切果损耗保毛利，再用甜度保复购，外观做陈列，大小做分层定价。**
