# 香蕉到货判断：熟度与坏果风险

## 一、先明确香蕉的“状态”指标（比颜色更重要）

批发环节判断香蕉，核心是**成熟阶段 + 生理状态**，颜色只是表象。

**看果指（果柄与果身连接处）**
- 果指饱满、棱角圆润 → 已进入成熟期，货架期短
- 棱角分明、果身偏瘦 → 偏生，耐放但需催熟

**看“青硬度”与“转黄位置”**
- 全青硬：可长期存放，需催熟，风险低但周转慢
- 青中带微黄（尖端或果指转黄）：正常催熟货，3–7天内会集中转黄
- 黄中带青（只果身中部黄）：已过最佳催熟点，容易出现“黄得快、烂得也快”
- 通体金黄：到货即需快速出货，风险最高

**摸硬度（最关键的可执行判断）**
用手轻压果身中段：
- 硬挺有弹性 → 生，安全
- 微软但回弹 → 临界，需当天决策出货
- 一压就陷、无回弹 → 已过熟，坏果风险高

## 二、坏果风险的四个检查点

1. **果柄/果轴**：发黑、发软、渗液 → 从轴心开始烂，整把风险高，切开看芯部。
2. **果指连接处**：发黑、离层、轻拉即脱 → 脱落和霉变会从这里扩散。
3. **表皮斑点**：零星芝麻斑（糖斑）正常；**大面积黑斑且斑下果肉软** → 已开始腐坏；斑点在果指两端集中更危险。
4. **气味**：开箱闻——有酒味/酸味说明已发酵，整箱风险高，不能只看外观。

## 三、抽样方法（可执行）

- 每批**随机抽3–5箱**，每箱**开箱看上下两层**（底层最易闷坏）。
- 每箱抽**中段和两端**各2–3把，重点看**箱底和靠箱壁**的果。
- 记录：转黄比例、软果比例、黑斑/霉变果数。**软果+黑斑果超过5%**，整批按高风险处理，压价或拒收。
- 同批不同箱差异大 → 说明运输/堆压不均，风险按最差箱估。

## 四、按用途决策

| 到货状态 | 适合用途 | 处理建议 |
|---|---|---|
| 全青硬 | 长期备货、催熟 | 可接，控制库温，分批催熟 |
| 青中带黄、硬 | 正常批发 | 优先出货，2–3天内走量 |
| 微软、局部转黄 | 快消/加工 | 当天促销或转加工，不压库 |
| 通体黄、软、有酒味 | 高风险 | 拒收或大幅压价，立即处理 |

## 五、一句话原则

**“看轴、摸身、闻味、抽底层”**——颜色只作参考，果轴发黑、果身无回弹、有酒味、箱底软果多，这四项中任意两项成立，就按坏果高风险处理。
