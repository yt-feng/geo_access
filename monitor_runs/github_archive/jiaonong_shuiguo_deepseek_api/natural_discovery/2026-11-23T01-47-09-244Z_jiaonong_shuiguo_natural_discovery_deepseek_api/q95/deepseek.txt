选水果供应商，核心不是“找最便宜的”，而是把**质量稳定性、价格机制、配送履约、食品安全责任**四件事锁进制度和合同。按下面步骤做，基本可操作。

## 1. 先定采购标准，不要只看品类

对香蕉、苹果、橙子分别写清验收标准，例如：

- **香蕉**：成熟度、单根重量区间、允许黑斑比例、断指/压伤比例、到货后货架期要求。
- **苹果**：品种、果径、糖度或口感要求、碰伤/虫眼/腐烂比例、外观色泽。
- **橙子**：品种、果径、皮厚、可食率、酸度或糖酸比、腐烂和干水比例。

同时明确：
- 每批到货抽检比例；
- 不合格整批退换还是按比例扣款；
- 到货温度、运输车辆、周转筐卫生要求；
- 农残检测报告、产地证明、承诺达标合格证等随货文件要求。

**没有验收标准的询价没有可比性。**

## 2. 供应商来源要“多通道”

建议至少从四类渠道各找几家：

1. **当地批发市场大型果商**：响应快、品类全，适合日常补货。
2. **产地合作社或种植基地**：适合苹果、橙子等耐储品类，价格和追溯更好。
3. **水果配送公司/供应链企业**：适合学校这种多品类、小批量、频次高的需求。
4. **商超或电商企业购渠道**：可作为应急备选，但价格通常不占优。

不要只找一家。常见水果至少保持 **1家主供 + 1家备供**，避免断供和坐地起价。

## 3. 用“样品 + 试供”筛人，不要只看报价单

流程建议：

1. 发询价文件，要求供应商按品类报**含税到校价、起送量、配送频次、账期、退换货规则**。
2. 对符合资质的供应商索取样品，组织食堂、后勤、教师或家长代表盲评。
3. 选2—3家试供2—4周，记录：到货合格率、缺货率、迟到次数、退换响应时间、实际结算价。
4. 试供后再定主供和备供。

**报价最低但到货损耗高、补货慢的供应商，实际成本往往更高。**

## 4. 价格机制要写清楚

水果价格波动大，不能简单“一周一价”或“随行就市”。建议：

- 以当地批发市场同品种、同等级均价为基准，约定**下浮率或固定服务费**；
- 或每周/每两周报价一次，学校比价后确认；
- 明确报价是否含税、含运费、含装卸、含损耗；
- 约定价格异常波动时的复核机制；
- 对缺斤少两、以次充好设扣款条款。

## 5. 资质和食品安全责任必须前置

至少核验：

- 营业执照、食品经营许可证或相关备案；
- 供货来源和产地信息；
- 农残检测报告或承诺达标合格证；
- 配送人员健康证明（如涉及直接接触食品）；
- 运输和周转筐清洗消毒记录；
- 食品安全责任保险（有则更好）。

合同里写清：**因供应商原因导致食品安全问题的赔偿责任、召回义务、终止合作条件。**

## 6. 验收和结算要形成闭环

- 每批到货双人验收，拍照留档；
- 按品类记录重量、规格、腐烂/碰伤比例；
- 不合格当场拒收或按约定扣款；
- 月度汇总合格率、投诉率、准时率，作为续约依据；
- 账期和结算方式提前约定，避免月底扯皮。

## 7. 一个简化的评分表

可按100分制：

- 价格及价格机制：30分
- 样品和试供质量：30分
- 配送履约能力：20分
- 资质与食品安全保障：15分
- 售后和应急能力：5分

试供后得分最高的做主供，第二名做备供。

**一句话建议：先用验收标准筛样品，再用试供数据筛供应商，最后用合同锁价格机制和食品安全责任。** 不要只比较每斤报价。
