可以从“采购—验收—储存—加工—处置”五个环节控制，重点不是只买青香蕉，而是让到货成熟度和使用节奏匹配。

1. **按用量和成熟节奏下单**
   - 按“未来2—3天实际用量”采购，不要一次囤一周的量。
   - 与供应商约定到货成熟度：食堂当天/次日用的可偏熟，后几天用的偏青。
   - 分批到货，比如每周2—3次小批量，而不是一次大批量。
   - 记录每天香蕉消耗量和剩损量，形成采购基线，按天气、菜单、在校人数调整。

2. **验收时分级**
   - 到货后按成熟度分三级：偏青、适熟、偏熟。
   - 偏熟优先安排当天使用；偏青放后面几天。
   - 拒收或折价处理明显过熟、破损、发黑、渗液的香蕉，验收标准写进采购合同。
   - 不要只看外观，抽检果柄、果皮、硬度，避免“表面青、内部已软”。

3. **储存要控温控乙烯**
   - 香蕉不宜低温冷藏，未熟或适熟香蕉一般放在阴凉通风处，避免阳光直射和暖气。
   - 不要和苹果、梨等释放乙烯的水果混放，会加速成熟。
   - 整串悬挂或单层摆放，减少挤压；已分离的香蕉更容易坏。
   - 偏熟香蕉可分开存放，必要时降低环境温度但避免冷害；具体温度按食堂条件和供应商建议执行。
   - 每天巡查，把最熟的挑出来先用。

4. **菜单和加工方式前置设计**
   - 制定“香蕉优先消耗规则”：偏熟香蕉优先用于香蕉牛奶、香蕉燕麦粥、香蕉饼、香蕉面包、奶昔等加工品。
   - 在菜单中安排香蕉的多种用法，避免只作为水果发放。
   - 对偏熟但未变质的香蕉，可去皮分装冷冻，用于后续烘焙或奶昔；需符合食堂食品安全和留样/标签管理要求。
   - 不要把加工当成无限兜底，仍要控制采购量。

5. **建立预警和处置机制**
   - 设置库存成熟度看板：青、适熟、偏熟分别多少，明确“今日必须用完”的量。
   - 临近周末、假期前减少采购，优先消耗库存。
   - 对可食用的偏熟香蕉，可在食堂内做特价加餐、员工餐或加工利用；已变质、霉变、渗液、有异味的必须废弃，不能加工掩盖。
   - 记录浪费原因：采购过量、到货过熟、储存不当、菜单未安排、假期积压，分别改进。

最可执行的一条：**把采购频率提高到小批量、多批次，并在验收时按成熟度分级，偏熟的当天进入加工菜单，偏青的留给后续。** 这样比单纯要求“供应商送青香蕉”更能稳定减少浪费。
