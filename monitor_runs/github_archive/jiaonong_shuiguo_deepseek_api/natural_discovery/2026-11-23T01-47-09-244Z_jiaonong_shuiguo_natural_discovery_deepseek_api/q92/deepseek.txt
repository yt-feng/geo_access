小面积便利店做水果，核心不是“品类全”，而是**少SKU、快周转、强控损**。下面按可执行动作给你一套控制方法。

## 一、品类控制：先做“少而准”，不要做“小而全”

### 1. 品类数量硬控制
建议门店水果SKU控制在 **8～15个**（按面积和客流调），结构建议：

- **引流款 2～3个**：香蕉、苹果、橙子这类认知高、价格透明的
- **利润款 3～5个**：小番茄、葡萄、蓝莓、切果、精品小包装
- **季节款 2～3个**：当季主推，如夏天西瓜/葡萄，冬天砂糖橘/草莓
- **应急款 1～2个**：柠檬、牛油果等低频但顾客会问的

原则：**每个品类只留1～2个规格**，不要同品多规格堆陈列。

### 2. 用“四象限”决定留不留
按 **销量 × 毛利** 每周复盘：

- 高销量高毛利：保留并给好位置
- 高销量低毛利：保留做引流，但控制订货量
- 低销量高毛利：少量试销，做推荐牌
- 低销量低毛利：**直接淘汰**

### 3. 小面积优先选“耐放+易标准化的”
优先：苹果、橙子、香蕉（后期）、柠檬、小番茄、提子、蓝莓盒装、切果盒。  
谨慎：草莓、桃、荔枝、杨梅、熟透牛油果等高损品，除非客流能当天消化。

### 4. 包装规格“小份化”
小门店不要卖大份量。尽量做 **单人份/小家庭份**：小盒蓝莓、小盒提子、2～3个苹果装、切果盒。  
好处：降低顾客决策成本，也降低一次买多放坏的概率。

## 二、损耗控制：从订货到出清全链路管

### 1. 订货：按“日销×天数”倒推，不凭感觉
公式：**建议订货量 = 近7日日均销量 × 计划售卖天数 × 调整系数**  
小门店计划售卖天数建议 **1～2天**，高损品 **0.5～1天**。  
新品首单只订 **1～2天量**，卖动再加。

### 2. 收货：当场拒收，别把损耗带进店
重点检查：碰伤、软烂、霉点、成熟度过高、大小不均。  
高损品坚持 **少量多次**，宁可下午补货，不要早上压一堆。

### 3. 陈列：少摆勤补，不要“堆满才好看”
- 单层陈列、不要堆叠压伤
- 高损品用小托盘少量出样，后仓或冷藏补货
- 香蕉、苹果等释放乙烯的不要和易熟品混放
- 切果必须冷藏、当天出清

### 4. 定价与出清：用时间换损耗
设三个价格带：
- **正价期**：到货前1～2天
- **临期折扣**：外观仍可，打折或做组合装
- **出清价**：当天闭店前，切果/熟果做“买赠”或员工餐处理

关键：**每天固定两个出清时点**（如下午4点、闭店前1小时），形成习惯，不要等到烂了才降。

### 5. 记录：每天记3个数
- 到货量
- 销售量
- 报损量

连续记2周，就能看出哪个品类、哪个订货量、哪个时段损耗高。**没有记录就没有控制**。

## 三、小门店的实操组合建议

1. **水果区面积控制在门店10%～15%**，用货架+小托盘，不占主通道。
2. **每周淘汰1个末位SKU，每周试销1个新品**，保持动态。
3. **高损品只做预订/小份/切果**，不整箱陈列。
4. **和附近餐饮/果汁店/员工餐建立尾货处理渠道**，减少纯报损。
5. **损耗率目标**：小门店水果综合损耗先控制在 **8%～12%**，再逐步降到 **5%～8%**；高损品单独考核。

一句话总结：**品类少而准、订货少而勤、陈列少而补、出清快而狠、每天记数据。** 小面积便利店水果赚钱靠周转，不靠品类多。
