旺季锁库存，核心不是“提前说一声”，而是用**可执行的小单+阶梯量承诺+违约条款+分批锁量**把供应商的产能提前占住。水果是非标、易腐、价格波动大的品类，只靠口头承诺基本锁不住。

建议按下面做：

1. **先做销量预测，不要凭感觉报量**
   - 按过去同期销量、当前社群增长、单品爆款概率，拆到“单品×周×预计日销量”。
   - 给供应商报两个量：**保底采购量**和**峰值追加量**。保底量用于锁定产能，峰值量谈优先供应权。
   - 水果按成熟期和采摘周期倒推，至少提前2—4周锁主推单品，节假日旺季提前4—6周。

2. **用“阶梯锁量”代替一次性压大单**
   - 和供应商约定：第1批小单试销，卖得好按约定比例追加，追加量在约定上限内供应商必须优先满足。
   - 例如：保底每周500箱，峰值可追加到800箱；追加需提前48小时下单，供应商保留对应货源。
   - 这样既降低你的压货风险，也让供应商敢给你留货。

3. **签书面锁量协议，写清关键条款**
   至少包括：
   - 锁定品种、规格、等级、产地、包装标准；
   - 保底量、追加量、追加提前期；
   - 锁价还是随行就市，若随行就市要约定浮动上限；
   - 质量标准、验收方式、坏果率上限；
   - 供应商违约不供货的赔偿或补货责任；
   - 你方未提货的止损方式，比如定金不退或按比例补偿。
   没有书面条款，旺季供应商很容易把货高价转卖。

4. **付定金或预付款，但控制比例**
   - 对核心单品可付**10%—30%定金**锁货，尾款按批次验收后付。
   - 定金对应明确批次和数量，不要一笔糊涂预付款。
   - 对合作久的供应商可用“保证金+账期”组合，减少现金压力。

5. **要求供应商做“分批次采摘/分仓备货”**
   - 水果不能一次性全采全发，约定按你的团购节奏分批采摘、分批到仓。
   - 让供应商在产地做预冷、分级、暂存，你按日提货。
   - 这样供应商敢备货，你也不至于一次压太多损耗。

6. **准备备选供应商和替代品**
   - 每个主推水果至少锁**2家供应商**，主供应商占70%，备选占30%。
   - 提前谈好替代品种，比如某种柑橘缺货时换另一产区或另一规格。
   - 旺季前测试备选供应商的履约能力，不要等断货才找。

7. **用数据换优先权**
   - 给供应商看你过去3—6个月的稳定采购记录、复购率、退货率，证明你是优质客户。
   - 承诺旺季结束后仍保持基础采购量，换取旺季优先排产。
   - 对供应商来说，稳定订单比一次性大单更有吸引力。

8. **建立每日库存和到货看板**
   - 每天盯：在途量、已锁未提量、供应商可追加量、团购预售量。
   - 预售先锁需求再锁货，避免“先压货再找销路”。
   - 一旦某单品预售超锁量80%，立即启动追加或替换。

一句话总结：**提前报量、小单试销、阶梯追加、书面违约、定金锁批、双供应商兜底**。最容易被忽略的是“追加提前期”和“违约赔偿”，这两条不写，旺季供应商临时变卦你几乎没有抓手。
