直接建议：**以“顾客自己挑整果”为主，现场提供去皮/切块服务；不建议大量预先去皮陈列。**

具体判断如下：

1. **主推整果自选**
   - 菠萝耐放、外观是重要购买依据，顾客喜欢自己看颜色、闻香味、按硬度、看底部。
   - 自己挑能减少“你帮我选的不好”这类纠纷。
   - 整果损耗低，卖不掉还能继续陈列。

2. **不要大量提前去皮**
   - 去皮后水分流失、氧化、易污染，保鲜期明显缩短。
   - 预去皮适合做少量“即买即走”的引流，但必须冷藏、当日清掉，不能作为主力。
   - 去皮果一旦卖相变差，只能降价或做果切，损耗高。

3. **服务比预加工更重要**
   - 顾客挑好后，现场免费去皮、切块、去眼，这是水果店相对商超的优势。
   - 可以设“整果区”和“少量鲜切盒区”两个位置：整果自选，鲜切盒只做小份、冷藏、当日售完。

4. **操作要点**
   - 整果按成熟度分区：即食区、放两天区，帮顾客按需求选。
   - 去皮工具保持清洁，切块后建议冷藏，并标注当天食用。
   - 鲜切盒控制数量，按前一日销量做，不要凭感觉大量备货。
   - 对不会挑的顾客，店员可协助判断，但让顾客确认。

一句话：**卖整果让顾客挑，去皮切块当服务，鲜切盒只做少量补充。**这样兼顾体验、损耗和毛利。
