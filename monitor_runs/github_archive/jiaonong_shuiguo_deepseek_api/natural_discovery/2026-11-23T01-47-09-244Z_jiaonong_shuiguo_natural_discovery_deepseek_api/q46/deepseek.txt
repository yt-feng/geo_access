优先建议：**先买鲜果做主打和现切展示，果丁作为稳定出品备选，果泥只用于特定款或测试。** 不要一上来三样都大量采购。

可以按这个决策：

1. **主推鲜果，适合门店有后厨切配能力、客流稳定、想做“鲜切菠萝”卖点**
   - 优点：香气和口感最好，顾客感知强，能做装饰和现切。
   - 风险：损耗高、去皮切配耗时、批次甜酸不稳定、高峰期出杯慢。
   - 建议：选成熟度稳定的凤梨/菠萝，门店做标准化切配和糖酸调整；每天少量多次备货。

2. **果丁适合大多数茶饮店做稳定出品**
   - 优点：省人工、规格统一、损耗低，适合连锁或高峰出杯。
   - 风险：风味通常不如鲜果，可能有汁水流失、口感偏软；要确认是冷冻果丁、糖渍果丁还是鲜切果丁。
   - 建议：优先选**冷冻果丁或鲜切冷链果丁**，先小批量测试香气、酸甜、出杯稳定性和解冻后口感。适合做菠萝果茶底料，不建议完全替代鲜果卖点。

3. **果泥只建议用于特定产品，不建议作为唯一采购形态**
   - 优点：出杯最快、甜酸稳定、适合做冰沙、浓果茶、复配饮品。
   - 风险：鲜感弱、容易有“酱感”，顾客对“鲜果茶”期待会落空；开袋后保存和微生物风险要管好。
   - 建议：选无添加或低添加的冷冻果泥/果浆，先做小样测试；可用于菠萝冰沙、菠萝气泡、复配百香果等，不建议单独标“鲜切菠萝果茶”。

**实操采购方案：**
- 单店起步：鲜果占 60%—70%，果丁占 30%—40%，果泥先不备或只备小包装测试。
- 高峰出杯压力大：鲜果做展示和顶料，果丁做主体，果泥做少数快出款。
- 连锁/外卖占比高：提高果丁比例，鲜果只保留主打款，果泥用于标准化程度高的产品。
- 先做 3 天小批量测试：同一配方分别用鲜果、果丁、果泥出杯，比较香气、酸甜、颜色、出杯时间、损耗和顾客反馈，再定比例。

一句话：**想卖“鲜”买鲜果，想稳出品买果丁，想快和 standardization 买果泥；最稳妥是鲜果+果丁组合，果泥小样测试后再上。**
