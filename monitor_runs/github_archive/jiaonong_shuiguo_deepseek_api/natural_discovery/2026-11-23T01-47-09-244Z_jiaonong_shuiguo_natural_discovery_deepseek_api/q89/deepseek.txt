给团购客户，**多数情况下“阶梯价”更适合价格敏感型客户；返利更适合作为第二阶段或补充工具**。判断标准不是哪个更优惠，而是客户是否愿意先垫资并等待结算、供应商是否需要控价防窜货。

### 直接建议
1. **主方案用阶梯价**
   - 价格敏感客户最在意“当下单价”，阶梯价直观、成交快、比价时更有优势。
   - 适合：团购团长、社群团购、企业集采、一次性或短期集中采购。
   - 设计要点：阶梯门槛要少（3档足够）、差价要明显、达到门槛自动生效，避免客户反复申请特批。

2. **返利用作补充，不要作为主机制**
   - 返利适合：长期稳定复购、需要保护公开价盘、防止跨渠道乱价、希望绑定客户全年采购量。
   - 缺点：客户要先按高价采购、后结算，价格敏感客户会担心“拿不到返利”或占用资金，成交阻力大。
   - 如果必须用返利，建议“低门槛返利+透明结算周期+书面规则”，否则客户不买账。

### 选择判断表
| 客户/场景 | 更合适 |
|---|---|
| 客户极度价格敏感、一次性大单 | 阶梯价 |
| 团长/社群团购、需要快速报价 | 阶梯价 |
| 长期复购、年度框架采购 | 阶梯价为主，返利补充 |
| 需要维护公开零售价/防窜货 | 返利或“暗返” |
| 客户资金紧张、不愿垫资 | 阶梯价 |
| 供应商想绑定全年任务量 | 返利 |

### 更稳的组合玩法
**“阶梯价 + 季度返利”**：
- 基础阶梯价给到客户即时优惠，解决成交；
- 季度/年度返利只针对超额部分或复购部分，绑定长期合作；
- 返利规则写清楚：计算口径、结算周期、是否含税、退货如何扣减。

### 注意事项
- 阶梯价要防止客户“拼单凑档”后拆单，规则里写明同一客户/同一收货主体合并计算。
- 返利不要口头承诺，必须有书面政策，否则价格敏感客户会认为有风险。
- 如果渠道价格体系敏感，优先返利；如果成交速度优先，优先阶梯价。

**一句话：价格敏感型团购客户，先用阶梯价成交；有长期复购和控价需求时，再加返利做绑定。**
