先给结论：**社区超市香蕉和苹果不建议只选一种渠道，而应按品类和经营阶段分开：香蕉优先“本地批发/就近拿货”，苹果优先“稳定供应商”。** 如果只能先选一个主渠道，选**稳定供应商**，再保留本地批发做补充和比价。

判断依据如下：

1. **香蕉：更适合本地批发为主**
   - 香蕉周转快、成熟度变化快，社区店最怕压货和过熟。
   - 本地批发拿货灵活，小批量、高频补货、按成熟度挑货更方便。
   - 但要加强验收：看果指饱满度、棱角、表皮、切口、是否催熟过重，并控制一次进货量。
   - 适合做法：本地批发为主，固定1—2家可靠档口，日配或隔日配。

2. **苹果：更适合稳定供应商为主**
   - 苹果相对耐储，但品质、规格、糖脆度、产地稳定性决定复购。
   - 稳定供应商能保证等级、规格、包装和持续供货，适合做长期价格和陈列。
   - 社区店苹果通常承担“日常水果基础款”，缺货和品质波动比几毛钱进价差更伤客。
   - 适合做法：稳定供应商供主推规格，本地批发只用于临时补货、促销或测试新品。

3. **不要只按进价选渠道**
   要算“综合到店成本”：进价＋损耗＋配送/自提时间＋退换货＋分级挑选成本＋缺货损失。香蕉损耗权重高，苹果稳定性和规格权重高。

4. **建议的试运行方案**
   - 前2—4周：香蕉本地批发选2家比价，苹果稳定供应商选1—2家比价。
   - 每批记录：进价、到店价、损耗率、售罄天数、顾客反馈、退换情况。
   - 用数据判断：香蕉看“周损耗率”和“补货频次”；苹果看“规格稳定率”“复购反馈”和“缺货次数”。
   - 设规则：本地批发作为弹性补充，稳定供应商作为主供；单一渠道占比不要超过70%，保留比价能力。

5. **采购时可直接问供应商的问题**
   - 香蕉：几天到货一次？可否按成熟度分档？过熟/黑斑怎么退换？最小起订量多少？
   - 苹果：规格是否稳定？产地和等级是否固定？破损率多少？能否周度锁价？断货提前多久通知？

**最终建议：香蕉以本地批发为主、稳定供应商备选；苹果以稳定供应商为主、本地批发补缺。** 这样既控制香蕉损耗，又保证苹果品质和复购。
