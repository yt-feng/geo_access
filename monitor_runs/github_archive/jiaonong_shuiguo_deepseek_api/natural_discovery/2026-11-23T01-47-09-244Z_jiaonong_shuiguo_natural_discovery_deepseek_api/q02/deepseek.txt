对小水果店进香蕉，优先级建议是：**坏果率 ≈ 熟度 > 送货速度 > 价格**。不是价格不重要，而是香蕉损耗太快，低价但坏果多、熟度不合适，最后亏得更多。

具体判断顺序：

1. **坏果率优先看**
   - 香蕉是易损品，坏果、压伤、发黑会直接变损耗。
   - 小水果店销量有限，一次进多，坏果率高的批次很难及时消化。
   - 建议先看开箱坏果比例和果柄、果身压伤情况。

2. **熟度决定你能不能卖得动**
   - 小水果店客流有限，最好进**七成到八成半熟**的香蕉，能放两三天逐步转黄。
   - 如果进已经全黄甚至起黑点的，当天卖不完就容易砸手里。
   - 如果进太青的，顾客当天不买，也占资金和陈列位。

3. **送货速度要稳定，不是越快越好**
   - 香蕉怕反复搬运和高温，送货稳定、轻拿轻放比单纯“快”更重要。
   - 但要避免高温时段送货、长时间压在车厢里。
   - 小水果店库存浅，送货频率比一次送很多更重要，能小批量勤补更稳。

4. **价格放最后比较，但要算“可售成本”**
   - 不要只看每箱进价，要算：进价 ÷ 可售比例。
   - 比如便宜10%，但坏果多两成，实际更贵。
   - 小水果店现金流紧，低价大批量进货风险反而高。

**实操建议：**
- 固定2～3个供货商，每次少量试单，记录坏果率、到货熟度、送货稳定性。
- 首次合作别大批量，先拿小批量看开箱和第二天转色情况。
- 香蕉进货原则：**宁少勿多、勤补货、熟度可控、坏果少**。
- 如果只能四选一排序：**坏果率 > 熟度 > 送货速度 > 价格**；如果熟度经常不可控，可以把熟度提到第一。
