结论先说：**对大多数茶饮店，出汁率优先于甜度；但真正要看的是“综合成本 + 风味稳定性”，不是两个指标二选一。**

判断逻辑如下：

1. **出汁率决定单杯成本**
   茶饮店用菠萝通常是榨汁、打泥或做果肉。出汁率低意味着同样一杯饮品要用更多原料，损耗、人工、备料时间都上升。出汁率每差 10%，长期成本差异会很明显。

2. **甜度可以用配方调节，出汁率不能**
   甜度低了可以加糖浆、调整糖度或拼配其他水果；但原料本身出汁少、纤维粗、果肉少，配方很难补救。茶饮店更怕“出不了量”，不怕“甜度略低可调”。

3. **但甜度不能完全不看，要看“糖酸比和稳定性”**
   菠萝甜度受季节、产地、成熟度影响大。只看出汁率容易买到酸涩、风味寡淡的原料。建议看：
   - 可溶性固形物（糖度）是否在可接受区间；
   - 酸度是否稳定；
   - 香气是否足；
   - 批次差异是否小。

4. **按用途分优先级**
   - **榨汁/做果茶底**：出汁率优先，甜度可调。
   - **做果肉、菠萝粒、装饰**：果肉率和口感优先，甜度次之。
   - **高端鲜果茶、主打“鲜菠萝”卖点**：风味和甜酸平衡更重要，不能只压成本。
   - **外卖占比高、标准化要求高**：批次稳定性最重要，出汁率和甜度都要设验收标准。

**可执行建议：**
- 先算出“每杯可用果汁/果肉成本”，不要只比原料单价。
- 设定验收标准：出汁率下限、糖度区间、酸度区间、果肉率、坏果率。
- 小批量盲测：同一配方下比较香气、酸甜平衡、是否涩口、放置后是否易分层。
- 如果预算有限，**选出汁率达标且糖酸比稳定的原料**，不要单纯选最甜的。

一句话：**出汁率是成本底线，甜度是风味参数；茶饮店应先保出汁率和稳定性，再用配方调甜度。**
