酒店早餐水果供应，核心是把“稳定”落到合同和日常管理里。和供应商谈合作，建议重点盯以下几项：

1. **明确品类、等级和规格**
   - 不要只写“苹果、香蕉、西瓜”，要写清品种、单果规格、成熟度、外观标准、允许瑕疵比例。
   - 早餐水果通常要求：到货即可用、成熟度适中、大小均匀、破损率低。建议附一份《验收标准》作为合同附件。

2. **约定供应量和弹性**
   - 给出日均用量、周末/节假日峰值、淡旺季浮动区间。
   - 约定最低起送量、临时加单截止时间、加单响应时间。
   - 对酒店临时接待、团队入住，最好有“48小时/24小时应急补货”条款。

3. **锁定价格机制**
   - 不要接受长期一口价，也不要接受完全随行就市。
   - 建议采用“基准价+浮动规则”：以当地批发市场或指定平台周均价为参考，约定上浮比例和调价周期。
   - 写清是否含税、含运费、含卸货到指定冷库/收货点。

4. **配送和冷链要求**
   - 明确配送频次、到货时间窗，最好在早餐备餐前完成验收。
   - 需要冷藏的水果，要求冷链运输并记录温度；切果类若涉及，必须明确加工资质、包装、保质期和温控。
   - 约定卸货、搬运、空筐回收责任。

5. **验收和退换货**
   - 收货时按标准抽检：数量、重量、成熟度、破损、腐烂、农残报告/合格证明。
   - 明确不合格处理：现场拒收、扣重、换货时限、累计不合格的处罚或终止条款。
   - 对“以次充好”“规格缩水”设置可量化的违约处理。

6. **食品安全资质**
   - 查验营业执照、食品经营许可、产地证明或检测报告。
   - 要求供应商提供农残检测合格证明，明确食品安全责任和追偿条款。
   - 保留每批次到货记录，便于追溯。

7. **结算和账期**
   - 明确对账周期、发票类型、付款账期。
   - 新供应商可先短期试合作，比如1个月，再签长期框架。
   - 避免大额预付款，最好按月对账结算。

8. **备用供应和退出机制**
   - 要求供应商说明备货来源和应急能力。
   - 酒店自身最好储备1家备选供应商，避免单一依赖。
   - 合同写清提前解约通知期、尾货处理、质量事故终止权。

9. **试合作验证**
   - 先小批量试供2—4周，重点看：到货准时率、损耗率、规格稳定性、临时加单响应。
   - 用数据说话，再谈长期价格和账期。

谈判时最值得坚持的三件事：**验收标准书面化、价格浮动规则透明、临时补货有响应时限**。这三项直接决定早餐水果能不能“稳定”。
