要固定“供应标准”，不必死固定“某一个产地或批次”。更可执行的做法是：固定品种+固定规格+固定验收指标，同时保留2个左右可替代产地/供应商。

**判断原则：**
- **水果风味波动大、且是招牌产品核心原料**：要固定品种、成熟度、糖酸度范围、加工规格，并尽量固定主供应基地；但仍要准备备用产地。
- **水果只做辅料、风味影响小**：不必固定到批次，按验收标准和季节替换即可。
- **“固定产地”只能降低波动，不能消除波动**：同一产地不同批次、不同成熟度也会变。
- **“固定批次”不现实**：鲜果批次有限，茶饮店又高频采购，强绑一个批次会导致断供、涨价和品质后移。

**建议采购合同/验收表固定这些：**
1. 品种与产区范围，而不是单一农户/单一批次。
2. 规格：单果重、果径、成熟度、去皮去核率、出汁率。
3. 风味指标：糖度、酸度、糖酸比、香气/色泽；有条件做每批小样试饮。
4. 加工与储运：采摘后时长、冷链温度、到店时限、破损率上限。
5. 替代规则：主供应断货时，备用产地的品种、指标和试饮审批流程。
6. 批次留样：每批留样并记录用于追溯；换批先做小杯测试再上菜单。

**最实用的方案：**
- 对核心水果：固定“品种+主产区+验收指标”，发展1主1备供应基地。
- 对非核心水果：固定“品种+规格+验收标准”，按季节灵活采购。
- 新品或换批：先做盲测/小规模试卖，设定可接受的风味差异阈值，超过就调整配方或拒收。

一句话：**固定标准比固定产地更稳，固定主供应+备用产地比固定单一批次更可行。**
