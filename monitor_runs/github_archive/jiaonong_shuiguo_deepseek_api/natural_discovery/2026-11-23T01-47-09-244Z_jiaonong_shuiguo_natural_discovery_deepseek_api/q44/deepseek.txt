判断供应商售后是否稳定，不要只听承诺，建议在采购前和试单期做可验证的动作：

1. **合同里写清响应机制**
   - 明确售后联系人、电话/微信、备用联系人。
   - 约定响应时限：如到货质量问题2小时内响应、24小时内给出处理方案。
   - 明确处理方式：补货、换货、折价、退货、费用承担。
   - 写清香蕉、菠萝的验收标准和责任划分，例如香蕉催熟度、机械伤、菠萝黑心/烂心的判定。

2. **试单阶段故意做小压力测试**
   - 先下小批量试单，记录从报问题到对方回复、到场、给出方案的实际时间。
   - 在非工作时间或周末发一次质量问题，看是否有值班响应。
   - 连续跟踪2—3批货，看是否每次都按约定处理，而不是只第一次积极。

3. **看其是否具备本地化处理能力**
   - 问清楚本地是否有业务员、仓配人员或合作档口，能否到店查看。
   - 香蕉、菠萝损耗快，若供应商只能远程口头答复，售后稳定性通常较弱。
   - 可要求提供近期同类商超客户的售后处理记录，但需交叉验证，不要只看对方自述。

4. **用对账和异常单验证**
   - 每次质量问题都走书面异常单或微信群留痕，要求对方确认。
   - 观察其是否主动闭环：补货是否按时到、折价是否在货款中兑现、是否反复推诿。
   - 统计一段时间内的响应率、按时解决率、重复问题发生率，作为续约依据。

5. **设置售后保证金或账期约束**
   - 可在合同中约定质量保证金，或把售后处理与账期、返利挂钩。
   - 对多次响应不及时的供应商设置退出条款。

简单判断标准：**能在合同里写清时限、在试单中实际做到、在异常单上留痕闭环、本地有人到场处理的供应商，售后响应才更可信。**
