评估水果供应商的仓配覆盖，核心不是看“它有多少仓”，而是看**你的门店网络与它的仓配网络是否匹配，以及水果这种品类下时效、损耗、成本能否同时成立**。建议按下面五步做可判断的评估。

## 1. 先画清自己的需求底图
按门店逐一列出：
- 城市、地址、门店类型（大店/小店/前置仓）
- 日均/峰值水果销量（按品类分：叶菜类水果、浆果、瓜类、苹果梨等耐储类）
- 要求的到店频次（日配/隔日配/一周2–3次）
- 收货条件（冷库、冷藏柜、卸货时间窗、是否可夜间收货）
- 可接受的缺货率与损耗率

这一步决定后面“覆盖”是按**城市覆盖**、**线路覆盖**还是**时效覆盖**来算。

## 2. 用“仓—店”距离和时效画覆盖圈
不要只问供应商“覆盖哪些城市”，要拿到：
- 每个仓的具体地址、服务半径
- 到各门店的**实际运输时长**（不是直线距离），分常温车/冷藏车
- 发车时间、截单时间、到店时间窗

判断标准建议：
- **日配品类**（草莓、蓝莓、叶菜类水果等）：仓到店车程尽量≤4–6小时，且能覆盖早市/营业前到店
- **隔日配**：≤8–10小时可接受
- **耐储品类**：可放宽到区域仓直发

把门店按“4小时圈/6小时圈/超6小时”分三档，超圈门店就是风险点。

## 3. 评估仓配能力，不只看仓库数量
重点核这几项：
- **仓的温区**：是否有冷藏（0–4℃）、保鲜、催熟/预冷能力；浆果和热带水果是否分开存
- **车辆资源**：冷藏车数量、是否自有/外包、高峰期能否加车
- **线路密度**：你的门店是否在它现有线路上；如果不在，是否愿意为你新开线路，起订量多少
- **分拣与越库能力**：能否做门店级分拣、贴标、按店配货
- **应急能力**：缺货补货、临时加单、天气/交通延误的替代方案

线路密度比仓的数量更关键：**同一个仓，能不能顺路覆盖你的门店，决定成本和时效。**

## 4. 用“覆盖矩阵”打分
做一个门店×供应商的矩阵，每家供应商对每家门店打：
- 时效是否达标（是/否）
- 是否在现有线路（是/否/需新开）
- 起订量是否满足（是/否）
- 温区是否匹配（是/否）
- 预估到店成本（元/店/次）
- 损耗风险（低/中/高）

然后看：
- **覆盖率** = 达标门店数 / 总门店数
- **线路经济性** = 单店配送成本是否低于你的毛利承受线
- **短板城市** = 哪些城市只有1家可选、或全部不达标

## 5. 做小范围验证再定
对候选供应商，选3–5家代表性门店（远郊、市中心、大店、小店各一）做2–4周试配，记录：
- 实际到店准点率
- 到货温度与品质合格率
- 损耗率
- 缺货/短装次数
- 单店单次配送成本

试配数据比供应商PPT可靠。

## 结论怎么下
可以按这个顺序判断：
1. **时效圈覆盖不了的门店**，直接列为不可用或需设前置中转。
2. **在时效圈内但不在现有线路**的，谈新开线路的起订量和加价。
3. **覆盖达标但成本过高**的，考虑合并配送频次、区域集单、或在该城市设二级仓/中转点。
4. **单一供应商覆盖过广**的，保留第二供应商做备份，尤其是浆果和叶菜类水果。

一句话：**水果供应商的仓配覆盖，要用“门店到仓的实际车程 + 线路是否顺路 + 温区是否匹配 + 单店配送成本”四项一起评，不能只看它有几个仓、覆盖几个城市。**
