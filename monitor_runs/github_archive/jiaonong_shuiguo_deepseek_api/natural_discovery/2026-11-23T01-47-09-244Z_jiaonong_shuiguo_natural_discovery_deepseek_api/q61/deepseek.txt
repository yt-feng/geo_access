判断香蕉批发商是否稳定供货，别只听承诺，按下面几项做交叉验证：

1. **看产地和季节衔接能力**
   - 问清主要货源来自哪里（如云南、广西、海南、老挝、越南、菲律宾等），以及不同月份怎么切换产区。
   - 稳定的供货商应有“主产区+备用产区”，能说清某个产区断档时从哪补。
   - 只靠单一产地、单一果园、单一季节的，断供风险高。

2. **现场看货和加工能力**
   - 最好去对方档口/加工厂看：是否有固定催熟库、冷库、分拣线、装卸工。
   - 香蕉需要催熟和温控，没有固定加工能力的“倒手商”稳定性差。
   - 看库存周转：货是不是长期在走，而不是临时堆一批。

3. **查实际履约记录**
   - 让对方提供近3个月给哪些批发市场/超市/水果店供货，最好能联系1—2个老客户侧面问：到货准不准、缺货怎么处理、质量波动大不大。
   - 不要只看微信朋友圈和宣传图。

4. **用“小单+连续单”测试**
   - 先下小批量试单，连续下3—4次，观察：到货时间、规格一致性、青蕉成熟度、损耗率、缺斤少两。
   - 稳定供货商的关键不是永远不出问题，而是出问题时能否补货、换货、赔付。

5. **问清断货预案和赔付规则**
   - 直接问：如果产地涨价、台风、封关、寒害导致断货，提前几天通知？能否从备用产区补？违约怎么赔？
   - 合同/聊天记录里写清：规格、成熟度、到货时间、损耗率上限、缺货补偿。

6. **看资金和物流是否自有/可控**
   - 有固定合作车队、能提供物流跟踪的，比临时找车可靠。
   - 付款方式上，坚持“小单现结、大单分批”，不要一开始就大额预付。

7. **警惕几个信号**
   - 报价明显低于市场价且催你大额打款；
   - 只有微信、没有固定档口和加工场地；
   - 说不清产地和催熟流程；
   - 一直强调“要多少有多少”，但拿不出近期发货记录。

实操建议：先小批量连续试3次，同时要求提供2个老客户电话回访，再谈长期合作。稳定供货的核心看三点：**有多产区调配能力、有固定加工和物流、出问题有赔付预案**。
