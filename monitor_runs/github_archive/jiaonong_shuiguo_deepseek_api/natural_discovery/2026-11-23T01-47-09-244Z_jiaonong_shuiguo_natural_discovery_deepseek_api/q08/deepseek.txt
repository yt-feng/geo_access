进货量不大时，通常更建议 **先以批发市场为主、逐步筛选并固定1～2个供应商**，而不是一开始就签固定供应商。原因和建议如下：

**1. 小店初期更适合批发市场**
- 起批量低、拿货灵活，适合试款、补货。
- 能看到实物、比较多家价格，便于摸清行情。
- 库存压力小，卖不动可及时调整品类。
- 缺点：价格未必最低、质量不稳定、供货连续性一般。

**2. 固定供应商适合“品类稳定后”再建立**
- 价格、账期、送货、售后通常更好谈。
- 质量更稳定，补货省心。
- 但小店量小，固定供应商可能不愿给好价格或好账期，容易被“绑定”。
- 若只依赖一家，断货或涨价时被动。

**3. 更稳妥的做法**
- **先跑批发市场**：同一品类找3～5家，记录价格、起批量、退换货规则。
- **小额试单**：对2～3家分别进少量货，比较质量、到货速度、售后。
- **逐步固定**：把复购高、质量稳的品类集中给1～2家供应商；低频、试新款仍走市场。
- **保持备选**：每个主力品类至少留一个备用供应商，避免被单一渠道卡住。

**判断标准很简单：**
- 品类刚起步、款式变化快、单次进货少 → 优先批发市场。
- 品类稳定、复购高、补货频繁、供应商能接受小批量 → 逐步固定供应商。
- 不要为了“固定”而一次压太多货；小店现金流和库存周转比名义上的低价更重要。
