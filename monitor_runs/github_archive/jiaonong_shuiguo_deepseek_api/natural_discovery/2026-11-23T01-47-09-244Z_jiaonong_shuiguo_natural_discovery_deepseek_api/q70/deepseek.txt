可以从“验收标准—责任划分—处理方式—举证与时限—价款调整”五个维度写，核心是把“坏果”定义清楚、把发现和索赔流程写死。

**1. 先定义“坏果/损耗”**
建议在合同中明确：
- 坏果范围：腐烂、霉变、开裂、严重压伤、冻伤、异味、虫蛀、非品种固有畸形等；
- 计算口径：以件/箱/斤为单位，按抽样或全检计算坏果率；
- 自然损耗与坏果区分：水分流失、轻微表皮擦伤等是否计入，单独约定上限；
- 等级标准：按品种、规格、成熟度约定合格果比例。

**2. 责任划分节点**
关键是约定风险转移时点，避免“到货后说不清”：
- 装车/发货前：供方对产地质量负责；
- 运输中：谁安排运输谁承担相应责任；若批发商自提，装车后风险可转移，但供方对“隐蔽性腐烂、以次充好”仍应负责；
- 到货验收：约定到货后多少小时内完成验收，逾期视为验收合格，但隐蔽瑕疵除外；
- 卸货后：因批发商储存不当导致的坏果，供方不担责。

**3. 坏果处理方式**
可组合约定：
- 轻微超标：按坏果重量/件数扣减货款；
- 超过约定比例：供方补发、换货或按比例退款；
- 严重超标：批发商有权拒收或整批退货，运费和装卸费由责任方承担；
- 已销售部分：按实际销售损失或约定折价赔偿，避免全部按零售价索赔导致争议。

**4. 举证与时限**
写清楚可执行流程：
- 到货后拍照/录像，保留包装、批次、车牌、卸货时间；
- 双方共同抽样，抽样比例和方法约定清楚；
- 异议应在到货后X小时内书面提出，附照片/视频/抽检记录；
- 供方应在X小时内回复或到场复验，逾期视为认可；
- 必要时约定第三方检测机构，费用由责任方承担。

**5. 价款与违约金**
- 约定坏果率对应扣款公式，例如“坏果率超过3%的部分，按实际坏果重量×到货单价扣减”；
- 约定严重违约的违约金或赔偿上限；
- 明确退货后的运费、装卸费、仓储费由谁承担；
- 保留质量保证金条款：尾款在验收合格后支付。

**建议直接写进合同的条款示例：**
> 到货后买方应在____小时内完成验收。经双方抽样确认，坏果率不超过____%的，买方按实际坏果重量×到货单价扣减货款；超过____%的，供方应在____小时内补发或按超标部分退款；超过____%的，买方有权拒收或整批退货，由此产生的运费、装卸费由供方承担。因买方储存、运输不当造成的坏果，供方不承担责任。买方逾期未提出书面异议的，视为验收合格，但隐蔽性腐烂除外。

最后提醒：不要只写“坏果由供方负责”，否则容易因比例、时限、举证不清产生扯皮。把“多少算坏、何时提、怎么证明、怎么赔”四项写具体，合同才真正可执行。
