社区超市卖小包装香蕉，核心是：**采购时按“小份、快周转、可控熟度”设计包装，并把损耗前置到采购标准里**。重点注意以下几类问题：

## 1. 包装规格与形式
- **单份重量别太大**：社区超市小包装建议按 **2—3根/份** 或 **300—500克/份** 设计，避免家庭一次吃不完。
- **按“根数+重量”双标注**：香蕉大小差异大，只标重量容易顾客觉得份量不均；只标根数又难定价。
- **包装要透气**：香蕉会释放乙烯，完全密封的塑料袋容易闷出水汽、加速黑斑和腐烂。优先用**带孔保鲜袋、网套+透气托盘、打孔膜**，不要用完全密封的硬盒。
- **减少挤压**：小包装堆叠时底层容易压伤，采购包装时选**有一定支撑的浅托盘或分隔盒**，或控制单袋装量，避免“一袋塞太多”。
- **标签位置**：价签不要直接贴在蕉皮上，贴在包装袋/托盘侧面，避免撕标伤皮。

## 2. 采购时的熟度控制
- 小包装周转慢于整把香蕉，**采购熟度要比大包装略生一点**：到店时以**微黄、果指饱满、棱角略明显**为宜，给门店留1—2天售卖窗口。
- 避免采购**已出现梅花点、果柄发黑、果指软塌**的货；小包装里只要有一根坏，整份就难卖。
- 分批到货：不要一次进太多同一熟度，按日销量分2—3批，**先熟先卖**。

## 3. 损耗相关采购标准
- **果柄和切口**：采购时看果柄是否新鲜、切口是否干净；切口发黑、渗液的容易从果柄开始烂。
- **机械伤**：重点查蕉指中段和底部有没有压痕、擦伤、裂口；小包装会放大外观缺陷，伤果不适合做小包装。
- **冷害和捂伤**：香蕉怕低温，采购运输避免低于 **13℃左右**；到货后若包装内壁有水珠、果指有异味，说明捂过，损耗会高。
- **批次一致性**：同一批小包装尽量用同一产地/同一熟度，避免顾客挑拣后剩下熟度差的。

## 4. 陈列与周转配合
- 小包装适合**平铺陈列、不要堆高**，堆叠不超过2层，减少压伤。
- 香蕉不宜放冷柜；社区超市可放**阴凉通风端架或收银台附近**，提高冲动购买、加快周转。
- 每天**晚市前挑出黑斑/软果**，可做折扣份或员工处理，避免整袋下架。
- 采购量按 **1.5—2天销量** 控制，小包装最怕“进得多、卖得慢”。

## 5. 建议直接写进采购单的要点
1. 规格：2—3根/份，300—500克/份，大小均匀。
2. 熟度：微黄、棱角略明显，无梅花点、无软塌。
3. 包装：带孔透气袋/网套+浅托盘，不密封、不贴皮标价。
4. 验收：果柄新鲜、无切口渗液、无压伤裂口、包装内无水汽。
5. 批量：按1.5—2天销量分批到货，先熟先卖。

简单说：**小包装香蕉的损耗，一半在包装透气防压，一半在采购熟度和批量控制。**
