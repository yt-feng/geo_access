连锁商超招长期水果供应商，评分标准建议以“稳定供货 + 品质安全 + 成本可控 + 长期协同”为主线，不宜简单最低价中标。可以直接采用下面这套可落地的100分制框架。

## 一、评分权重建议（100分）

| 维度 | 权重 | 核心判断 |
|---|---:|---|
| 价格与成本 | 30分 | 不是最低价，而是综合到岸成本、价格机制合理性 |
| 品质与食品安全 | 25分 | 一票否决项所在，重点看检测、追溯、损耗控制 |
| 供货保障与履约能力 | 20分 | 长期供应稳定性、产地资源、应急能力 |
| 企业资质与财务健康 | 10分 | 合法合规、抗风险能力 |
| 服务与协同能力 | 10分 | 退换货、账期、信息化对接、驻场服务 |
| 可持续发展与ESG | 5分 | 农残管控、包装、冷链、社会责任 |

如果商超特别看重品质，可把品质提到30分、价格降到25分；如果走大众化引流品类，价格可到35分。但品质安全建议不低于20分。

## 二、各维度具体评分项

### 1. 价格与成本（30分）
- 报价水平（15分）：以有效投标人的综合到岸价（含税、运费、包装、损耗补偿）为基准，最低价得满分，其余按比例折算。不建议用产地裸价比较。
- 价格调整机制（8分）：是否接受随行就市但有上限；是否有季度/月度调价公式；是否承诺大宗单品价格保护期。
- 账期与结算条件（4分）：能否接受商超账期、是否收取额外资金占用费。
- 降本与增值方案（3分）：分级包装、产地直发、带板运输、减少中间环节等。

### 2. 品质与食品安全（25分）
- 食品安全资质（6分）：营业执照、食品经营/生产许可、种植基地备案、绿色/有机认证等，按有效证件计分。
- 检测能力与报告（6分）：第三方检测频次、农残快检能力、重金属/真菌毒素检测覆盖；近12个月检测报告完整性。
- 溯源体系（5分）：批次可追溯、产地证明、投入品记录、采收记录。
- 样品与感官品质（5分）：现场盲评，按外观、规格、成熟度、口感、整齐度打分。
- 损耗控制承诺（3分）：到店损耗率承诺、不合格品赔付比例。

**一票否决建议**：提供虚假检测报告、近三年重大食品安全事故、农残超标被监管部门通报未整改的，直接废标。

### 3. 供货保障与履约能力（20分）
- 产地与产能（6分）：自有基地/长期协议基地面积、年可供货量、能否覆盖商超全年需求。
- 冷链与物流（5分）：冷链车辆、预冷能力、配送半径、到店时效。
- 应急保供方案（4分）：极端天气、产区减产、疫情/交通管制下的替代产区与备货方案。
- 历史履约（3分）：同类商超/生鲜渠道合作年限、履约评价、违约记录。
- 供货弹性（2分）：能否接受临时加单、小批量多频次配送。

### 4. 企业资质与财务健康（10分）
- 注册资本与经营年限（2分）
- 近两年营收与负债情况（3分）：要求提供审计报告或银行资信证明
- 纳税与社保合规（2分）
- 诉讼与失信记录（3分）：信用中国、裁判文书网查询，失信被执行人直接扣满或废标

### 5. 服务与协同能力（10分）
- 退换货与售后响应（3分）：响应时限、赔付标准
- 信息化对接（3分）：能否对接商超订单、库存、溯源系统，提供批次数据
- 驻场/巡店服务（2分）：陈列指导、品质巡检、促销支持
- 账期与发票合规（2分）

### 6. 可持续发展与ESG（5分）
- 农残与投入品管理（2分）
- 包装减量化与可回收（1分）
- 冷链能耗与碳排放管理（1分）
- 用工合规与社会责任（1分）

## 三、评审操作建议

1. **先资格后评分**：资质、食品安全、失信记录作为资格审查，不满足直接淘汰，避免“高分低质”。
2. **价格分用综合到岸价**：把运费、包装、损耗补偿、账期资金成本折算进去，防止低价中标后通过损耗和加价找补。
3. **样品盲评**：品质分中的感官项建议编号盲评，评审前统一标准。
4. **设置履约保证金与考核挂钩**：中标后按季度考核供货及时率、到货合格率、损耗率，考核结果与保证金、续约挂钩。
5. **长期合同分段**：建议“1+1+1”或“2+1”模式，首年考核合格再续约，避免一次签死。
6. **避免唯低价**：价格分超过40分容易引发恶性竞争，长期水果供应更应看稳定性和品质一致性。

## 四、可直接写进招标文件的废标条款

- 提供虚假资质、检测报告或业绩证明；
- 近三年发生重大食品安全事故或农残超标被立案查处；
- 被列为失信被执行人；
- 不具备食品经营/生产许可或种植基地合法来源证明；
- 不接受商超食品安全追溯和抽检要求。

这套框架的核心是：**价格决定入围，品质和履约决定中标，长期考核决定续约**。
