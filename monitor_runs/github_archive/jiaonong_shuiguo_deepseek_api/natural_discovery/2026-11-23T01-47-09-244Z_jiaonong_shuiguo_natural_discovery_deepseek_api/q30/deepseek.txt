超市水果到货品相不好，售后流程建议在采购合同或供货协议里按“验收—分级—时限—责任—补偿”五段写清楚，避免事后扯皮。

**1. 验收标准与时限**
- 明确“品相不好”的客观标准：腐烂、压伤、裂果、畸形、色泽不达标、大小不符、成熟度过高或过低等，最好按品类列验收指标（如烂果率≤3%、碰伤率≤5%）。
- 约定到货后验收窗口，例如卸货后2小时内完成抽检；逾期未提出异议视为验收合格，但隐蔽瑕疵除外。
- 抽检方式写清楚：按批次随机抽检比例（如每批抽5%且不少于10箱），以抽检结果推定整批。

**2. 分级处理**
- 轻微瑕疵：可折价接收，按瑕疵比例扣款。
- 中度瑕疵：要求换货或补发，费用由供货方承担。
- 严重瑕疵（腐烂、异味、食品安全风险）：整批拒收或退货，供货方承担运费及因此产生的损失。

**3. 售后申请时限与证据**
- 到货验收发现问题，应在验收窗口内书面（含微信、邮件、系统单据）通知供货方，附照片/视频、批次号、抽检记录。
- 若销售过程中发现隐蔽质量问题，约定发现后24小时内通知，并保留实物样本。
- 明确通知到达方式与联系人，避免“发了没人认”。

**4. 责任与费用**
- 换货、补货的运输费、装卸费由供货方承担；因品相问题导致超市降价处理的差价，按约定比例由供货方承担或从货款中扣减。
- 因腐烂、变质引发顾客投诉、监管处罚的，供货方承担相应责任，超市有权追偿。
- 约定扣款上限或计算方式，例如按该批次货款的10%—30%扣减，严重批次可全额拒付。

**5. 结算挂钩**
- 售后未处理完毕的批次，暂缓结算该批货款；换货完成并复验合格后再结算。
- 建立月度质量台账，累计瑕疵率超约定阈值的，可触发警告、调整供货比例或终止合作。

实操上建议把上述内容做成一张《到货验收及售后确认单》，每批签字留档；合同里再附一份按品类细化的品相标准表。这样既能让员工按流程执行，也能在纠纷时有据可依。
