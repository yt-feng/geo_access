需要，而且建议把这两项写进采购条件里。

**1. 发票：必须支持**
- 企业福利采购通常要入账、报销、税前扣除，供应商不能开合规发票会直接影响采购流程。
- 优先确认：能否开**增值税专用发票**或**普通发票**、发票类目（水果/农副产品/礼盒）、税率、开票时间。
- 有些个体农户或小型供应商无法规范开票，采购前要核验资质，避免后期无法入账。

**2. 定制包装：建议要求支持，但看采购规模**
- 企业福利礼盒通常需要体现企业标识、节日祝福、统一视觉，定制包装能提升福利感知。
- 要确认：起订量、定制费用、打样周期、包装材质与食品安全要求、是否加印企业LOGO和贺卡。
- 如果采购量小，供应商可能不支持免费定制，可改为“标准礼盒+定制贺卡/腰封”降低成本。

**建议采购条件写法：**
> 供应商须具备合法经营资质，能按采购方要求开具合规增值税发票；礼盒包装支持企业LOGO、祝福语等定制，并提供打样确认，包装材料符合食品接触安全要求。

**判断标准：**
- 不能开票 → 不建议合作。
- 采购量达到供应商起订量 → 要求定制包装。
- 采购量较小 → 至少要求定制贺卡、贴纸或腰封，并提前确认费用。
