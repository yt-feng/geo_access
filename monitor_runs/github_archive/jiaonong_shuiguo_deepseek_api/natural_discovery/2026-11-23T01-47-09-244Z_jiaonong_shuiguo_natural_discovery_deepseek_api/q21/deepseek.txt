超市采购水果时，供应商通常需要提供以下证明/报告（具体以当地监管要求和超市内部验收标准为准）：

**一、基础资质与进货证明**
1. **营业执照**（供应商主体资格）
2. **食品经营许可证/食品生产许可证**（按经营性质提供）
3. **供货合同/采购订单**
4. **送货单/销货清单**（品名、数量、批次、日期、供货方盖章）
5. **发票或收据**（财务与追溯用）

**二、水果质量与安全相关证明**
1. **产地证明或采购来源证明**（尤其对声称“某地特产”的）
2. **农产品质量安全承诺达标合格证**（国内食用农产品常见，鼓励/部分地区要求）
3. **农药残留检测报告**（第三方检测或供应商自检，通常按批次或定期提供）
4. **重金属等污染物检测报告**（视风险和企业要求）
5. **检疫证明**（进口水果需海关入境货物检验检疫证明；部分国产水果按当地要求）
6. **进口水果标签/中文标签及报关单**（进口情形）

**三、超市内部常要求的附加材料**
1. **供应商年度审核资料**（资质复印件加盖公章）
2. **批次检测报告或快检记录**
3. **冷链运输温度记录**（如涉及冷链水果）
4. **包装标签合规证明**（预包装水果需符合标签规定）

**判断建议：**
- 国内普通鲜果：至少索要**营业执照、食品经营许可证、送货单、合格证/产地来源证明、农残检测报告**。
- 进口水果：额外索要**入境货物检验检疫证明、报关单、中文标签**。
- 高风险或重点品类（如草莓、葡萄、柑橘等易农残超标品类）：要求**按批次提供农残检测报告**更稳妥。
- 最终以超市所在地市场监管部门要求和超市验收制度为准，采购前可让供应商提供清单并逐项核验。
