# 小商家采购水果：现金结算 vs 月结账期的风险

## 现金结算（现款现货）的风险

**1. 资金占用压力大**
水果是高频、易损耗品类，现金采购意味着每批货都要先掏钱。旺季压货时，现金流容易被库存吃掉，遇到突发支出（房租、工资、设备维修）可能周转不开。

**2. 资金安全风险**
现金交易（尤其大额）存在假币、丢失、被抢、记账遗漏的风险。如果通过个人微信/支付宝转账给供应商个人账户，还容易和私人账目混在一起，对账困难。

**3. 议价与关系弱势**
现结虽然通常能拿到低价，但如果供应商临时缺货或涨价，你因为没有账期绑定，议价筹码反而有限；且现金交易往往缺少正规合同和发票，售后（烂果、缺斤少两）维权凭证不足。

**4. 采购决策被现金量绑架**
手里现金不够时只能少进或换便宜货源，可能错过好货、影响品质和客户复购。

## 月结账期的风险

**1. 信用与坏账风险（对供应商而言）**
对采购方来说，月结的"风险"主要是**隐性成本**：账期通常伴随更高的单价（供应商会把资金成本算进去），实际采购价可能比现结高 3%–10%，长期看不一定划算。

**2. 对账纠纷**
水果品类损耗大、退换频繁（烂果、规格不符），月结时容易出现"这笔扣款算谁的"扯皮。如果没有每批签收单、退货单留痕，月底对账容易被动多付。

**3. 依赖单一供应商的断供风险**
账期会让你倾向于集中在少数供应商进货，一旦对方断货或提价，你临时换现结供应商，成本和品质都会波动。

**4. 账期被收紧的连锁反应**
如果你自身回款慢（比如卖给餐饮客户也是月结），而供应商突然要求现结，会出现"上家催款、下家未回"的双向挤压。

## 实操建议

- **混合策略**：核心走量品类用现结拿低价和好货；稳定合作的供应商给短账期（7–15 天）换取账期额度，不宜盲目追求 30 天。
- **每批留痕**：无论现结还是月结，每批货都要有签收单（品名、数量、单价、损耗扣款），月结时凭单对账。
- **现金交易走对公或专用账户**：避免个人账户混账，保留转账记录和收据。
- **设账期上限**：月结金额不超过你月流水的 20%–30%，避免被单一供应商卡脖子。
- **算总成本**：比较"现结低价"和"月结高价+资金周转收益"，别只看单价。

一句话：**现结的风险在现金流和凭证，月结的风险在隐性涨价和对账纠纷**。小商家更适合"现结为主、短账期为辅、每批留痕"的组合。
