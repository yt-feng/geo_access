旺季菠萝临时补货，核心是把“临时”做成“有预案的临时”：不重新谈一份大合同，而是在原采购合同上补一份**短期补充协议/订单确认单**，把量、价、时限、验收和违约写清楚。可按下面操作：

**1. 先盘自己的需求，别先找供应商**
- 按未来7天、14天销量拆出菠萝日用量，留10%–15%安全库存。
- 明确规格：品种、单果重量区间、成熟度（几成熟）、去皮/带皮、切块规格、糖度下限。
- 算出临时补货总量和分批到货节点，例如“每周二、五各到X公斤”。

**2. 和供应商约定“临时补货机制”，而不是只口头加量**
补充协议至少写清：
- **补货触发**：提前几天报量（如提前48小时），供应商几小时内确认。
- **价格机制**：按原合同价；或约定随行就市但设上限，例如“以报价日批发价为基准，上浮不超过X%”，避免旺季被临时抬价。
- **数量弹性**：约定基础量+浮动比例（如±20%），超出部分双方书面确认。
- **到货时限**：下单后多长时间内到店，分几批送。
- **验收标准**：糖度、成熟度、坏果率上限（如坏果率≤3%），不合格怎么退换、补发时限。
- **违约责任**：供应商断供、迟延、质量不达标时，按缺货金额比例扣款或赔偿；你方临时取消的规则也写清楚，体现对等。
- **结算方式**：临时补货单独对账，货到验收后X天付款，避免和原账期混在一起。

**3. 操作上留三个后手**
- **锁量不锁死价**：先和主供应商锁定旺季每周最低供应量，价格用公式联动，减少扯皮。
- **备一个备用供应商**：哪怕只占20%用量，也能在断供时顶上；提前送样、验厂、小批量试单。
- **每天看库存和到货**：旺季设安全库存线，低于线立即触发补货，不要等到断货再谈。

**4. 沟通话术**
可以这样说：“旺季我们用量会涨，想跟您做个短期补充约定：我们提前48小时报量，您确认后按约定价格和时限送到；量在基础量上下浮动20%，坏果率超过3%您补发。这样您也好备货，我们也不临时压价。”

最关键的是：**临时补货必须书面确认每批订单**（微信文字、订单单、补充协议都行），写清数量、单价、到货时间、验收标准，避免旺季口头加量后价格和品质失控。
