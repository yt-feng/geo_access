多门店、单店量小的核心矛盾是：**总采购量不小但单点分散，供应商不愿意为单店小批量高频送货，而门店又怕缺货或损耗。** 建议按“品类分层 + 供货模式分层”来配，不要用一种模式通吃。

## 一、先给结论：三种模式组合最合适

| 模式 | 适合品类 | 解决什么 |
|---|---|---|
| **区域配送中心/中转仓 + 本地供应商直送门店** | 苹果、橙子、香蕉等耐储大宗 | 集单降本，供应商只送到仓，再由仓配到店 |
| **本地批发市场/一级批发商“次日达”** | 时令、叶菜、易损、试销新品 | 灵活少量、无起订量压力，适合单店量小 |
| **产地/基地直采 + 第三方冷链落地配** | 单品爆量、促销大单品 | 抓毛利，但要先有稳定销量再谈 |

单店量不大时，**不建议一开始就做多产地直采**，物流和损耗会把毛利吃掉。

## 二、最推荐的主模式：本地供应商“集单配送”

做法：
1. 把所有门店的日需求汇总成一张总订单，按区域/线路拆成配送批次；
2. 找1–2家本地水果批发商或区域经销商做“总仓供货”，约定**每日/隔日统一送到区域中转点**；
3. 中转点再按门店分拣，用自有小车或第三方城配送到店；
4. 单店不单独向供应商下单，避免起订量问题。

关键谈判点：
- 起订量按**区域合计**谈，不按单店谈；
- 价格按“到仓价”，配送费单独算，方便比价；
- 约定损耗赔付和缺货替代规则；
- 账期先短后长，初期现结或周结换更低价格。

## 三、补充模式：本地批发市场“少量高频”

适合叶菜、草莓、荔枝、葡萄等易损时令品：
- 由门店或区域采购每天早上到本地一级批发市场补货；
- 只补“易损+试销”品类，大宗耐储品走集单配送；
- 优点是无起订量、当天可调；缺点是价格波动大、品质不稳定，需要固定2–3个靠谱档口。

## 四、什么情况下才做产地直采

满足以下条件再考虑：
- 某单品在所有门店合计日销量稳定，能凑够整车或半车；
- 有冷库或中转仓可承接；
- 能接受3–7天账期和一定损耗；
- 先从一个爆款单品试，不要全品类直采。

## 五、落地建议（可直接执行）

1. **先统计7天各店各品类销量**，算出区域合计日需求量；
2. **按耐储/易损/时令分三类**，分别对应集单配送、批发市场补货、少量直采；
3. **找2家本地供应商比价试供1个月**，重点看准时率、损耗率、缺货替代；
4. **设一个区域中转点**（哪怕是小仓），统一收货分拣，这是多店小量模式的关键；
5. **单品设最小陈列量和安全库存**，卖不动就减订，避免多店同时压货。

一句话：**用“区域集单+中转分拨”解决量小的问题，用“本地批发市场”解决灵活补货，产地直采只留给验证过的爆款单品。**
