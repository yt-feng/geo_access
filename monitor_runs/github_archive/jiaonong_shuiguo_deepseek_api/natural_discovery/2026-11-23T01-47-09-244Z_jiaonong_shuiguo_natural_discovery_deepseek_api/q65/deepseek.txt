没有一刀切的答案，关键看你面对的是哪类水果、波动来源是什么，以及你的客户结构。给你一个可判断的框架：

**1. 先分清价格波动的类型**
- **季节性/可预测波动**（如集中上市期、节前备货）：适合签一段时间价格，或签“基准价+浮动条款”。
- **天气、疫病、政策、突发事件驱动的剧烈波动**：日议价更能避免单边风险，但交易成本高。
- **产地收购价频繁跳动、一天几变**：完全锁价容易吃亏，应缩短锁价周期（3–7天）或采用“随行就市+保底/封顶”。

**2. 按品类和保质期决策**
- **不耐储、周转快**（叶菜、浆果、鲜桃等）：价格变化快，建议短周期议价（每日或每2–3天），避免库存贬值。
- **耐储、标准化程度高**（苹果、梨、土豆、柑橘等）：可以签1–4周甚至更长，但要留调价机制。
- **进口或期货属性强的品类**：参考批发市场行情指数，设浮动区间。

**3. 按客户和订单结构决策**
- **对下游是长期稳定大客户**：客户希望价格稳定，你可签“周价/半月价”，同时在采购端用短周期议价对冲。
- **对下游是零散、价格敏感的客户**：日议价更灵活，但要用报价单和定金减少扯皮。
- **有大额订单**：单独锁价，并约定“市场价偏离超过X%可重谈”。

**4. 推荐折中方案（多数批发商最实用）**
不要二选一，而是：
- **采购端**：短周期议价（每日/隔日），紧跟产地和批发市场行情。
- **销售端**：签“短期框架价”（如7天），约定浮动条件：当市场基准价涨跌超过5%–10%时重新议价。
- **库存端**：控制锁价敞口，锁价量不超过未来3–7天销量。

**5. 判断信号**
- 如果你**能较准确预判未来一周价格**且客户要稳定：签短周期价。
- 如果**价格一天一变、信息不对称大**：日议价或“随行就市”。
- 如果**你议价能力弱、客户强势**：尽量签带浮动条款的短期协议，别硬锁长价。

一句话：**采购端短周期跟市，销售端短周期锁价+浮动条款，锁价周期与水果保质期和销量匹配。** 这样既控制风险，又不至于每天陷在议价里。
