生鲜平台做水果一件代发，供应商的仓配能力不能只看“有仓库、能发快递”，要重点看**水果损耗控制、订单履约稳定性和售后可追溯**。建议按下面几项核验。

### 1. 仓储能力
- **温控仓**：至少有保鲜库/冷藏库，能按品类分温区存放；浆果、荔枝、樱桃等需冷链，普通柑橘苹果可常温但要有通风避晒。
- **分区与防串味**：生熟、不同水果、包材分开；避免乙烯释放大的水果与易受影响的混放。
- **库存与批次管理**：能按批次、采摘/入库日期先进先出，支持临期预警，避免把尾货发给消费者。
- **日处理能力**：看日均可入库量、峰值入库量、滞销处理能力，能否应对大促和产地集中上市。
- **质检与分级**：入库有糖度、硬度、外观、规格分级，能按平台SKU标准分拣；有坏果剔除机制。

### 2. 加工与包装能力
- **预冷能力**：产地或仓内能快速预冷，尤其是高温季节和浆果类。
- **分拣打包线**：能按订单做单果套网、吸塑盒、泡沫箱、冰袋、保温袋等组合包装。
- **包装适配快递**：能通过跌落、挤压、温湿度测试，降低运输损耗；不同气候线路有差异化包装方案。
- **贴单与面单能力**：支持平台电子面单、隐私面单、多快递公司切换。

### 3. 订单履约能力
- **系统对接**：WMS/OMS能与平台订单系统API对接，支持自动接单、库存同步、发货回传、物流轨迹回传。
- **发货时效**：承诺截单时间、当日/次日发货率；一件代发最怕压单，要看日常和峰值履约数据。
- **多快递与多仓发货**：能按收货地智能选仓选快递，偏远地区有明确覆盖范围。
- **异常订单处理**：缺货、地址异常、拦截、改址、补发能及时处理。

### 4. 物流与冷链能力
- **快递资源**：有稳定合作的快递/冷链快递，重点线路有时效保障；能提供发货时效和破损率数据。
- **冷链覆盖**：冷藏/冷冻品能发到哪些区域，是否全程温控，是否有温度记录。
- **最后一公里风险控制**：对高温地区、偏远地区能主动限发或升级包装。

### 5. 售后与追溯能力
- **坏果包赔机制**：明确赔付标准、举证要求、补发/退款流程和时效。
- **批次追溯**：能从订单追到批次、入库日期、质检记录、包装记录，便于处理客诉。
- **损耗数据**：能提供历史运输损耗率、坏果率、客诉率，按品类和线路拆分更好。
- **逆向物流**：坏果是否需退回、如何核销，避免平台和供应商扯皮。

### 6. 峰值与应急能力
- **大促/产地旺季产能**：日订单峰值处理量、临时用工和包材储备。
- **断货与天气应急**：暴雨、高温、快递停运时的替代仓、替代快递和主动通知机制。
- **库存共享与安全库存**：能否设置安全库存、超卖拦截和缺货下架。

### 建议平台重点核验的硬指标
1. 日均可发订单量、峰值可发订单量；
2. 截单后发货时效、48小时发货率；
3. 近3个月运输坏果率/客诉率，按品类和线路拆分；
4. 冷链覆盖区域和温控记录方式；
5. WMS/OMS对接能力与库存同步频率；
6. 坏果赔付标准和平均处理时长；
7. 是否有备用仓、备用快递和旺季用工方案。

### 合同里要写清楚
- 发货时效与超时赔付；
- 坏果率上限和超出后的赔付/补发；
- 库存准确性、超卖责任；
- 批次追溯和质检记录留存；
- 包装标准与运输测试责任；
- 大促产能保障和缺货处理；
- 数据回传字段和对接责任。

简单判断：**能存、能控温、能分级、能按单打包、能稳定发货、能追溯赔付**，才算具备一件代发水果的仓配能力。只满足“有货能发快递”的供应商，不建议直接上线。
