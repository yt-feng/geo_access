买香蕉时，先确定你打算几天内吃完，再按成熟阶段挑，不要只看颜色。

**到店挑选**
- **当天或第二天吃**：选全黄、带少量小褐斑的，果肉最稳。不要选大面积发黑或已经软塌的。
- **2～4天吃**：选黄中带一点青、两端还略青的。
- **4～6天吃**：选整体偏青、只有少量转黄的。
- **更久**：买整串很青的，回家常温分开放；不要买已经起黑点的。

**现场判断**
1. 看：根部发黑、果身有凹陷或裂口不要。
2. 摸：轻按有弹性但不过软；一按就陷下去说明过熟。
3. 看果柄：果柄干枯发黑通常放得久；青绿果柄一般较新。
4. 闻：有明显发酵酒味说明过熟。

**回家后的控制**
- 想快熟：和苹果放同一个纸袋，常温催熟。
- 想慢熟：拆开分放，阴凉通风，不要闷在塑料袋里；熟后放冰箱冷藏可延缓变黑，但表皮会变深，不影响果肉。
- 已经熟透吃不完：剥皮冷冻，做奶昔或烘焙。

**最实用的采购策略**：一次买两批——一批全黄带少量斑当天吃，一批偏青的分开催熟，比只买一串更不容易同时过熟或太生。
