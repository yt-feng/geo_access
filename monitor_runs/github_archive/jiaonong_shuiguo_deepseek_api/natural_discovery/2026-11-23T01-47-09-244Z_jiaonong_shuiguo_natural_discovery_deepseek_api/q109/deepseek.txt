优先谈**账期**，但前提是先守住配送和售后的底线条款。更可执行的排序是：

1. **账期最值得优先谈**
   - 水果损耗高、价格波动大，账期直接决定你的现金流和议价空间。
   - 重点谈：结算周期（如月结30/45天）、对账日、付款方式、逾期是否有宽限、涨价/降价时账期是否同步调整。
   - 注意：不要只换“更长账期”，要防止供应商把资金成本转进单价，或账期长但配送/售后缩水。

2. **配送是底线，必须先定标准再谈账期**
   - 水果履约核心是时效、温控、缺货补货、临期/损耗处理。
   - 明确：下单截止时间、到货时间窗、冷链要求、缺货替代规则、迟到/缺货违约处理、旺季保供优先级。
   - 配送标准不清，账期再长也会被断货和损耗吃掉利润。

3. **售后要量化，不能只口头承诺**
   - 明确：坏果率标准、拍照/留样举证、赔付比例、补发还是折价、响应时限、月度损耗上限。
   - 售后条款最好写进合同附件，并与账期挂钩，例如售后未闭环的争议货款可暂缓结算。

**谈判顺序建议：**
先谈配送和售后标准并写进合同 → 再谈账期 → 最后用年度采购量、稳定订单、独家/优先供货换更优账期。

如果只能先谈一个，选**账期**；但如果供应商配送和售后还没有量化条款，先把这两项底线锁死，否则账期谈下来也不可持续。
