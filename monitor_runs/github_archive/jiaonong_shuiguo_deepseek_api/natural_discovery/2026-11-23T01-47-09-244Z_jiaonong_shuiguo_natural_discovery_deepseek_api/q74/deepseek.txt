按餐饮客户（酒楼、快餐、茶饮、烘焙、食堂）实际用途，菠萝和香蕉建议准备以下几档规格，先小批量试销再定主力：

**菠萝**
- **按个头分级**：大果（约1.5–2kg/个，切果盘、宴席）、中果（约1–1.5kg，快餐、食堂、菠萝炒饭）、小果（约0.7–1kg，茶饮店现切、单人份）
- **按成熟度**：青果（7成熟，耐放，适合配送远、餐饮自行催熟）、黄果（8–9成熟，即用型，茶饮/水果捞/自助餐）
- **加工形态**：整果为主；可备少量去皮菠萝块/菠萝丁（真空或冷藏），供茶饮、烘焙、食堂直接使用
- **品种**：普通菠萝与凤梨分开报价，凤梨可做中高端餐饮和鲜食档

**香蕉**
- **按把/串规格**：大把（约1.5–2kg/把，食堂、酒店早餐）、中把（约1–1.5kg，快餐、茶饮搭配）、小把/单根分装（便利店式餐饮、儿童餐）
- **按成熟度**：青蕉（催熟配送，适合连锁餐饮统一管理）、黄蕉（7–8成熟即用）、熟蕉（9成熟，限当日或次日用，适合烘焙香蕉泥、奶昔）
- **加工形态**：整把为主；可备去皮冷冻香蕉段/香蕉泥，供茶饮、烘焙、冰品店
- **品种**：普通香蕉走量，小米蕉/皇帝蕉做差异化，供甜品店、高端餐饮

**备货建议**
- 主力：菠萝中果+黄果整果；香蕉中把+7–8成熟黄蕉
- 试销：凤梨中果、小米蕉、去皮菠萝块、冷冻香蕉段各少量
- 包装：整箱（菠萝约10–12个/箱，香蕉约12–15kg/箱）+ 小件周转装，方便餐饮试单
- 关键：餐饮客户更看重**稳定规格、稳定成熟度、可追溯批次**，先按“同规格同成熟度”做标准箱，再谈账期和配送频次。
