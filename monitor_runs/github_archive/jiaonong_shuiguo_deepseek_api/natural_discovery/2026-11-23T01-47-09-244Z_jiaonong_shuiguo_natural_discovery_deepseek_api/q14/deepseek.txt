能，但要分情况谈，不能默认供应商一定给。水果店周末促销常见可获得的支持有三类：

1. **价格支持**
   - **单品直降/特价供货**：对当季量大、易损耗、供应商也想走量的品，较容易谈。
   - **阶梯返利**：约定周末销量达到某档后返点，比直接降价更容易被接受。
   - **临期/尾货特价**：适合做引流品，但品质和损耗要控好。

2. **物料支持**
   - 陈列筐、POP价签、爆炸贴、试吃盒、手提袋、围裙、遮阳棚等。
   - 供应商通常更愿意给**自己品牌或主推单品**的物料，纯通用物料较少。

3. **人员与活动支持**
   - 试吃员、促销员、堆头陈列指导、新品推广方案。
   - 小供应商一般没有，品牌商或一级批发商更可能有。

**能不能给，主要看这几个条件：**
- 你的采购量是否稳定、是否集中在周末放大；
- 是否主推对方利润品或走量品；
- 是否愿意做堆头、端架、海报露出；
- 是否长期合作、结款是否准时；
- 促销是否只做一两天，供应商会算投入产出。

**建议你这样谈：**
- 先选2—3个周末主推单品，明确预估销量；
- 直接问：周末特价供货价、搭赠、物料、试吃支持分别能给什么；
- 用“销量承诺换支持”，不要只问能不能便宜；
- 把支持写成简单约定：供货价、数量、物料清单、送达时间、未卖完处理方式；
- 第一次合作先小范围试，别一次性压太多货。

**注意：** 水果损耗高，供应商给特价不等于你能赚钱。先算清毛利、损耗和人工，再决定促销力度。
