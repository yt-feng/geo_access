超市采购想把“农残抽检风险”前置到供应商资料审核，建议按“资质—检测—批次追溯—承诺与处置”四类要资料，并做成可核验的准入清单。

**1. 供应商主体与资质资料**
- 营业执照、食品经营/生产相关许可（按供应商类型）
- 供货商为种植基地/合作社的：产地证明、种植基地备案或合作协议
- 经销商/批发商：上游供货合同或授权链条，避免来源不明
- 联系人、发货地址、产地地址要能对应

**2. 农残检测资料（核心）**
- 每批次或每供货周期的**农残检测报告**：最好由具备CMA/CNAS资质的第三方检测机构出具
- 报告要能核对：样品名称、产地/供应商、抽样日期、检测项目、检出值、判定依据、报告编号
- 优先要求覆盖常见高风险项目和当地抽检重点农药；不能只给一张“合格结论”截图
- 供应商自检报告可作为辅助，但不能替代第三方报告；要约定第三方报告频次和抽检触发条件

**3. 批次追溯资料**
- 每批货的**批次号/采收日期/产地/地块或加工厂信息**
- 随货同行单、发货单、入库验收记录要能和在售批次对应
- 要求供应商提供追溯响应时限：出现抽检异常时，能在约定时间内提供该批次来源、数量、流向

**4. 承诺、协议与问题处置**
- 供货合同/质量协议中写明农残标准、检测责任、不合格退换货和赔偿
- 供应商书面质量承诺书：不采购、不使用禁用农药，遵守安全间隔期
- 约定超市可自行抽检、飞行检查，费用和不合格处置责任
- 不合格批次的下架、召回、封存和报告配合义务

**采购实操建议**
- 不要只收“一份年度报告”，要建立**供应商档案+批次报告台账**，每批货报告编号与入库单绑定。
- 对新供应商先小批量试供，首批要求第三方全项或重点项检测；稳定后再按风险调整频次。
- 报告要验真：核对检测机构资质、报告编号、样品信息与到货批次是否一致，防止套用旧报告。
- 对高风险品种（如叶菜、草莓、豇豆等当地抽检重点）提高检测频次和项目覆盖。

一句话：**要“资质链条+可核验的批次第三方农残报告+批次追溯信息+质量协议处置条款”**，并把它们写进准入和验收流程，而不是只在抽检前临时补资料。
