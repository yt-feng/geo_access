结论先说：**如果目标是“好管理、少扯皮”，优先选按斤结算；如果食堂量大且品种固定、验收能力一般，可以“按箱/件结算为主，按斤验收兜底”；按份结算只适合小食堂或固定套餐场景。**

具体对比如下：

**1. 按斤结算：最好管理，但验收成本高**
- 优点：价格透明，按实际用量结算，损耗和缺斤少两容易追责；适合多品种、用量波动大的食堂。
- 缺点：每批都要称重、记录、复核，人工耗时；水果大小差异大时，单价谈判要有标准。
- 适合：采购量中等、品种多、需要控制成本的食堂。

**2. 按箱/件结算：操作最快，但要防“箱内质量不稳”**
- 优点：下单、送货、入库都简单，适合苹果、橙子、香蕉等标准化箱装水果；减少称重工作量。
- 缺点：箱内大小、坏果、净重不一致时容易扯皮；单价可能被“箱规”模糊。
- 管理关键：合同里写清**箱规、净重下限、坏果率上限、抽检比例**，并保留按斤复核的权利。
- 适合：量大、品种少、供应商稳定、验收人手有限的食堂。

**3. 按份结算：最省事，但最不透明**
- 优点：适合直接分发给就餐者的场景，结算简单。
- 缺点：份量标准难统一，采购成本不透明，容易把“份”做成糊涂账；不适合大宗采购。
- 适合：小食堂、固定套餐、水果作为配餐附件而非主采购品。

**建议的落地做法：**
- **主结算方式用按斤**，尤其叶类、易损耗、价格波动大的水果。
- **标准化箱装水果可约定“按箱下单、按净重结算”**，即箱子计价但以抽检净重折算，兼顾效率和公平。
- **按份只用于最终分发环节**，不要作为采购结算主方式。
- 无论哪种，合同里必须写清：**净重、允许偏差、坏果率、抽检规则、退货和补货责任**。

一句话：**想管得清楚，按斤；想送得快，按箱但按净重复核；按份只适合末端分发，不适合作为采购主结算方式。**
