建议先做**香蕉**，但要把“稳定进口”理解成“稳定供应+稳定动销”，而不是只看进口标签。三者对比：

1. **香蕉：最适合先试**
   - 动销稳定、消费频次高，顾客对价格敏感但接受度高。
   - 进口香蕉供应链成熟，催熟和冷链要求高，但超市如果能解决催熟/温控，周转最快。
   - 风险是损耗和催熟管理；适合先小批量、固定周配，做1—2个SKU试销。

2. **菠萝：不建议作为第一款**
   - 单价和客单可以，但成熟度、口感波动、削皮服务和损耗都更麻烦。
   - 顾客购买频次低于香蕉，试错成本高。
   - 更适合在香蕉跑通冷链和陈列后，作为季节性增量品引入。

3. **苹果：适合做第二款或并行小试**
   - 耐储、损耗低、供应稳定，适合做价格带和礼盒。
   - 但进口苹果与国产苹果竞争强，顾客对“进口”溢价不一定买账，动销可能慢。
   - 适合先做小陈列、对比国产做差异化，而不是承担引流任务。

**执行建议：**
- 先选香蕉：找1家能稳定周配、支持催熟指导的供应商，首单少量，设7—14天观察期。
- 关键指标：到货损耗率、催熟合格率、日销量、毛利率、缺货次数。
- 跑通后再加苹果做耐储补充，最后用菠萝做季节增量。
- 如果门店没有催熟条件或冷链弱，则改为先做苹果小试，不要硬上香蕉。
