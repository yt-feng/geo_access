水果礼盒要“好卖”，核心不是把四种水果都塞满，而是**按送礼场景做分层**：低价走量款、主推利润款、高端体面款。苹果和橙子最稳，香蕉和菠萝负责“显丰富、提香气”，但香蕉不耐压、菠萝占体积且有刺，搭配时要做隔离和固定。

## 一、先定3个价位，别只做一个礼盒

| 档位 | 定位 | 建议组合 | 适合场景 |
|---|---|---|---|
| 基础款 39-59元 | 走量、员工福利、随手送 | 苹果6 + 橙子6 + 香蕉1把 | 社区、单位小福利 |
| 主推款 79-129元 | 利润主力、探病/串门 | 苹果6 + 橙子6 + 菠萝1 + 香蕉1小把 | 日常送礼、节日 |
| 高端款 159-229元 | 体面、商务/重要节日 | 大苹果8 + 精品橙8 + 菠萝1 + 香蕉少量点缀 | 商务、节庆 |

建议**主推79-129元款**，这个价位顾客决策快、你也有包装和损耗空间。

## 二、四种水果的搭配比例

- **苹果：占40%左右**，选大小均匀、红亮或品相好的，寓意平安，最稳。
- **橙子：占30%左右**，选颜色橙红、手感重的，寓意心想事成，耐放。
- **菠萝：每盒最多1个**，只在主推款和高端款放，提“分量感”和香气；必须立放固定，避免刺伤其他水果。
- **香蕉：只做点缀，不放多**，选小把、七八成熟，青一点更耐放；用隔板或纸托单独隔开，避免压伤和催熟其他水果。

简单记：**苹果橙子做主体，菠萝做门面，香蕉做点缀。**

## 三、更好卖的搭配技巧

1. **按寓意命名**：平安（苹果）、顺心（橙子）、旺来（菠萝）、蕉好运（香蕉），比“水果礼盒”好卖。
2. **做两个版本**：全耐放版（苹果+橙子+菠萝）适合提前备货；即食版（加香蕉）适合当天送。
3. **香蕉换成小把或单根装饰**：香蕉多了显廉价且易黑，少量反而精致。
4. **菠萝单独开窗或外挂**：不要和苹果橙子直接挤在一起，防止刺伤和串味。
5. **盒内加隔板/纸丝**：四种水果颜色丰富，但必须有分隔，否则运输后卖相差。
6. **标清重量和个数**：比如“约5斤/8件”，减少售后纠纷。
7. **做企业团购款**：基础款可印贴纸、加贺卡，单位福利最容易起量。

## 四、避坑

- 香蕉不要和苹果、橙子紧贴：苹果释放乙烯会催熟香蕉，容易发黑。
- 菠萝不要平放压住其他水果：刺和重量都会伤果。
- 高端款不要靠“多放香蕉”撑体积，改用大果苹果、精品橙和好包装。
- 先小批量试3种组合，看哪种价位和组合动销最快，再放大备货。

**最推荐先上的组合：79-99元主推款——苹果6个 + 橙子6个 + 菠萝1个 + 香蕉1小把，分隔包装，主打“平安顺心旺来”送礼场景。**
