判断超市采购的苹果和橙子“大小规格是否适合门店销售”，核心不是只看“大不大”，而是看**是否匹配门店客群、陈列方式、定价带和损耗控制**。可按下面执行判断。

## 一、先定门店销售场景
先明确这批次水果准备怎么卖：

1. **散装称重卖**
   - 苹果：单果重建议约 **160–220g**，直径约 **75–85mm** 较通用；社区店可接受 70–80mm。
   - 橙子：单果重建议约 **180–250g**，直径约 **70–85mm** 较通用。
   - 太小显得廉价、称重不划算；太大单价高，散客犹豫。

2. **礼盒/精品装**
   - 苹果：**80–90mm**，单果 **200–280g**；
   - 橙子：**75–85mm**，单果 **220–300g**；
   - 要求大小均匀、果形端正、色泽一致，允许少量瑕疵但外观必须整齐。

3. **家庭实惠装/促销装**
   - 苹果：**70–80mm**，单果 **150–200g**；
   - 橙子：**65–75mm**，单果 **150–220g**；
   - 重点是价格带和单袋总价，不追求大果。

## 二、现场可执行的判断方法
采购时带一把**卡尺/分级圈**和便携秤，按下面做：

1. **随机抽样，不要只看面上**
   - 每批随机抽 **30–50 个**，避开表层和箱口。
   - 记录单果重、横径、纵径。

2. **算均匀度**
   - 同一规格内，直径差最好控制在 **5mm 以内**，单果重差控制在 **20% 以内**。
   - 如果一箱里 65mm 和 85mm 混装严重，不适合直接上架，除非门店愿意人工分拣。

3. **看大小与门店价格带是否匹配**
   - 算“单果成本”和“建议零售单价”。
   - 例如苹果进价按斤算，若单果 250g，一斤约 2 个；门店若按个卖或按份卖，要确认顾客是否接受。
   - 大果若导致单果售价明显高于周边竞品，除非精品客群明确，否则慎采。

4. **看陈列承载**
   - 散装堆头：中等规格更稳，太大易滚落、挤压；
   - 风幕柜/中岛：整齐度比绝对大小更重要；
   - 礼盒：必须同规格，不能“大小混装”。

## 三、苹果和橙子的具体规格建议
### 苹果
- **社区超市/生鲜店散卖**：70–85mm，单果 160–220g，最稳妥。
- **精品超市**：80–90mm，单果 200–280g，要求果形正、着色好。
- **促销/家庭装**：65–80mm，单果 140–200g，但需控制总价。
- 注意：苹果大小不是唯一标准，**硬度、糖度、果面伤、果柄新鲜度**同样决定是否适销。

### 橙子
- **散卖通用**：70–80mm，单果 180–250g；
- **精品/礼盒**：75–85mm，单果 220–300g；
- **促销装**：65–75mm，单果 150–220g；
- 注意：橙子要区分品种，脐橙、冰糖橙、血橙大小标准不同，不能用一个尺寸硬套。

## 四、采购现场快速否决项
出现以下情况，即使大小合适也建议不采或降级处理：

- 同批大小差异超过 **10mm**，且门店无人力分拣；
- 单果过大导致预计售价超过门店主流价格带 **30%以上**；
- 果面机械伤、日灼、病斑比例高；
- 硬度不足、果柄干枯、有异味；
- 箱内上下层规格明显不一致，供应商混级。

## 五、最实用的落地标准
给门店定一张采购卡：

> 苹果：散卖 75–85mm、单果 160–220g、同批直径差≤5mm、伤果率≤3%；  
> 橙子：散卖 70–80mm、单果 180–250g、同批直径差≤5mm、伤果率≤3%；  
> 礼盒装统一上调 5mm，均匀度要求更严；促销装可下调 5–10mm，但总价必须落在门店主流价格带。

**结论：先按销售方式定规格，再抽样测直径和单果重，最后用均匀度、价格带、损耗率三项判断是否适合门店。** 大小只是门槛，均匀度和客群匹配才是能否上架销售的关键。
