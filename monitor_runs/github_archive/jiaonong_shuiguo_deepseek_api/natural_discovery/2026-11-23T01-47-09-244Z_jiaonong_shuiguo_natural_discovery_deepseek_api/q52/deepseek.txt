要避免香蕉到店后很快变黑，核心是**控制成熟度、减少机械伤、避开乙烯和冷凝水**。可执行做法：

1. **采购时选对成熟度**
   - 不要买已经全黄、带黑斑、果柄发黑的香蕉。
   - 选**7–8成熟**：果身偏黄但两端略绿，果柄青绿，手感硬实。
   - 甜品店如果2–3天内用完，可买“黄中带绿”；如果要放5天以上，买更绿一些。

2. **验货重点看伤和柄**
   - 拒收有明显磕碰、压伤、裂口、水烂的香蕉。
   - 果柄切口要干净；切口发黑、发霉的容易整串快速变黑。
   - 不要买整箱里已有几根软烂的，乙烯会催熟整箱。

3. **到店后立刻拆箱透气**
   - 不要原箱密封堆放，尤其纸箱内如有塑料袋，要打开或取出。
   - 香蕉怕闷、怕水汽，箱底有冷凝水要擦干。
   - 保留整串或连柄存放，不要提前单根掰下，伤口会加速变黑。

4. **存放温度和环境**
   - 未熟香蕉放**13–15℃**左右阴凉通风处，不要放冰箱冷藏。
   - 已成熟香蕉如需延缓，可短时间冷藏果肉用于当天加工，但带皮冷藏表皮会变黑，不适合展示。
   - 避免放在炉灶、烤箱、阳光直射、空调出风口旁。

5. **远离乙烯源和催熟水果**
   - 不要和苹果、梨、芒果、番茄等一起放。
   - 香蕉自身会释放乙烯，成熟度不同的要分开：**熟的先用，绿的单独放**。

6. **悬挂或单层摆放**
   - 有条件用挂钩悬挂，减少受压。
   - 不能悬挂就单层摆放，凸面朝上，避免堆叠压伤。
   - 每天挑出已软熟、有黑斑的先用掉，防止传染整批。

7. **采购节奏比储存更重要**
   - 甜品店按用量**少量多次采购**，比如每2–3天一次，而不是一次囤一周。
   - 和供应商约定到货成熟度，要求“黄中带绿、无压伤、果柄新鲜”。

一句话原则：**买绿一点、别压伤、拆箱透气、13–15℃通风、远离苹果梨、熟的先用了。**
