采购菠萝时，别按“已经熟了”来买，要按“到你店里还能卖几天”来定熟度。判断时优先看气味、果眼、果皮颜色、硬度和底部状态。

**实操判断标准**

1. **按销售节奏定熟度**
   - 当天或次日就能卖完：可买**七八成熟**，果皮从基部开始转黄，果身仍较硬。
   - 正常零售、计划卖2～3天：买**六七成熟**，青黄相间、以青为主但基部略黄，手感硬实。
   - 不要采购整果全黄、香气很浓、按压发软的，损耗会明显偏高。

2. **看果皮颜色**
   - 比较稳妥的是：**基部1/4～1/3转黄，上部仍青**。
   - 全青且没有黄色过渡的，可能过生，后续成熟不均匀。
   - 大面积深黄、果眼周围发褐的，通常已偏熟。

3. **看果眼和果形**
   - 果眼扁平、饱满、排列均匀，说明发育较好。
   - 果眼深陷、局部发黑或渗液的不要。
   - 果形略歪可以接受，但局部软塌的不行。

4. **闻气味**
   - 靠近底部闻：**有淡淡果香**最合适。
   - 没味道通常偏生。
   - 香气浓到冲鼻、带发酵味或酒味，说明过熟或内部已开始坏。

5. **按压和掂重**
   - 轻按果身应**硬实有弹性**，不能一按一个坑。
   - 同样大小选重的，水分足；明显轻飘的可能失水或内部空腐。
   - 重点摸底部和果眼凹陷处，局部发软的直接排除。

6. **看底部和切口**
   - 底部干燥、无霉、无渗液最好。
   - 底部发黑、发软、有酸味，内部腐烂风险高。
   - 切口新鲜但不湿黏；湿黏、发褐的不要。

7. **看叶片**
   - 冠芽青绿、容易拔起但不过松，通常较新鲜。
   - 叶片枯黄干缩说明存放久，但叶片状态只能辅助，不能单看。

**采购时的简单规则**

- **看天气预报**：未来几天高温，就买更青一点；阴凉、周转慢，也别买太熟。
- **少量多批**：菠萝损耗主要来自熟度集中，宁可每次少拿，按2～3天销量分批补。
- **到店分熟度摆放**：青的放常温催熟，七八成熟的优先陈列和促销，别混在一起压货。
- **抽检切开**：新供应商先抽1～2个切开看芯部，中心发褐、发水、香味异常就退货或降级处理。

一句话：**采购选“基部略黄、果身硬实、淡香、底部干净”的六七成熟果，最兼顾售卖期和损耗控制。**
