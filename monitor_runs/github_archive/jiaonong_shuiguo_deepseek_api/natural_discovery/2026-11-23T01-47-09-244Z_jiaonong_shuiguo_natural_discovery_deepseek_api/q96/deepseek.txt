三者不是同权重：**食品安全是底线（一票否决），配送准时是保障（影响食堂正常开餐和水果损耗），价格是优化项（在满足前两者基础上再谈）**。

如果必须给企业食堂一个可执行的优先级：

1. **食品安全优先**
   - 水果属于生鲜，容易出现农残、霉变、腐烂、交叉污染等问题。
   - 企业食堂一旦发生食安事件，影响面大、责任重，后续处置成本远高于采购差价。
   - 应要求供应商提供资质、检测报告/承诺书，明确验收标准、退换货和追责条款。

2. **配送准时其次**
   - 食堂供餐时间固定，配送延误可能直接影响当日供应。
   - 水果保质期短，配送不稳定也会增加库存和损耗。
   - 应约定配送频次、到货时间窗口、迟到处理和应急补货机制。

3. **价格放在第三，但不是不重要**
   - 价格应在食品安全和配送服务达标的前提下比较。
   - 只追求低价容易导致以次充好、缺斤少两、降低配送频次。
   - 建议用“综合成本”看：采购价 + 损耗率 + 退换货成本 + 管理成本。

**落地建议：**
- 设定准入条件：资质齐全、可追溯、验收合格率达标。
- 设定服务指标：准时率、缺货率、破损/腐烂率、退换响应时间。
- 在合格供应商中比价，而不是先比价再放宽食安和配送要求。
- 合同里明确：食安责任、验收标准、迟到/缺货/质量不合格的扣款或退出机制。

一句话：**先保安全，再保不断供，最后在合格供应商里控成本。**
