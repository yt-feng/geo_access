# 供应商介绍新品时，怎么让普通商家听得懂、敢下单

商家只认菠萝、香蕉这类大品类，说明他的判断框架是**“这东西我卖过、我知道怎么卖、我知道能赚多少”**。供应商要做的是把新品**翻译进这个框架**，而不是讲品种故事。

## 一、开场就用“对标法”定位

别先说品种名，先说“它相当于什么”：

- “这个你可以理解成**小一号的菠萝**，一个人一次吃得完，不用切开分装。”
- “口感接近香蕉的甜度，但**不像香蕉那样一熟就全烂**，货架期多三四天。”

对标锚点选商家最熟的品类，一句话让他脑子里有画面。

## 二、只讲商家关心的四件事

按这个顺序说，每项一两句，别展开：

1. **卖给谁**：什么场景、什么人群会买（家庭日常/送礼/餐饮采购）。
2. **怎么卖**：按个卖还是按斤卖、要不要切、好不好摆。
3. **能赚多少**：给他的进货价和周边同类零售价的差距，直接说“一斤你大概有X毛到X块的空间”。
4. **风险多大**：多久会坏、坏多少算正常、卖不动怎么办（能不能少拿、能不能换）。

## 三、用“试销方案”代替说服

商家不敢下单，核心是怕压货。直接给低门槛：

- “先拿**一箱**试，卖一周，卖得动再补。”
- “这批我给你**按小包装拆**，不用整件压。”
- 明确说售后：损耗怎么算、剩货怎么处理。

**降低首单金额，比任何话术都有效。**

## 四、避开三个雷区

- **别讲品种学名和产地故事开头**，商家没耐心，听完还不知道能卖多少钱。
- **别只夸好吃**，好吃不等于好卖，要给“谁买、怎么卖”的证据。
- **别一次推太多新品**，一次主推一个，让他聚焦。

## 五、一句话模板

> “这个你就当**小菠萝**卖，家庭买一个刚好，零售价能到X，你进货Y，一斤赚Z左右；存放比菠萝省心，先拿一箱试，卖不动我这边给你调。”

**核心逻辑：用他熟悉的品类做锚，用试销方案卸掉风险，用毛利数字给他下单理由。**
