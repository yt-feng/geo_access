茶饮店控制水果供应商食品安全风险，建议把证明分成“资质类、合格类、过程类、批次类”四层，并按水果风险分级索取。可直接执行的清单如下：

**1. 供应商主体资质**
- 营业执照（经营范围含水果/农产品销售或食品销售）
- 食品经营许可证或仅销售预包装食品备案凭证；若供应商只销售食用农产品，按当地监管要求核实是否需要许可/备案
- 若为进口水果经销商，还需海关相关经营资质及进口商备案信息

**2. 产品合格证明**
- 食用农产品承诺达标合格证（优先索取，尤其国产水果）
- 产地证明或进货凭证
- 检测报告：至少覆盖农药残留；高风险水果（如草莓、葡萄、柑橘、苹果、梨等）建议每批次或定期提供
- 进口水果：海关入境货物检验检疫证明、报关单

**3. 批次随货证明**
- 每批次送货单/销售凭证，注明品名、产地、数量、日期、供应商
- 该批次承诺达标合格证或快检/抽检报告
- 冷链水果的运输温度记录

**4. 过程与追溯证明**
- 供应商食品安全管理制度、快检能力或委托检测协议
- 产地/种植基地信息或采购来源清单，便于追溯
- 若供应商自称“有机”“绿色”等，需对应认证证书，但不应把认证替代农残检测
- 出现问题的召回和处置配合承诺

**茶饮店内部落地建议**
- 建立供应商档案：证照有效期、检测报告、批次凭证归档至少2年（按当地要求调整）
- 签订质量协议，明确农残超标、腐烂霉变、货证不符的退换和赔偿
- 到货验收做感官检查：霉变、破损、异味、虫害；高风险水果可自建快检或委托第三方
- 对供应商做年度/季度评分，检测不合格立即降级或停用

**判断标准**：证照齐全且在有效期内；每批能追溯到产地/供应商；农残检测合格；进口水果有入境检验检疫证明；冷链水果有温度记录。缺其中任一项，建议暂缓收货或要求补证。
