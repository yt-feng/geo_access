判断哪个规格更容易出货，不要凭感觉，建议用“小范围实测 + 出货速度数据”来定。可以按下面做：

1. **先按规格分档**
   - 按单果重量分：如 0.8–1斤、1–1.2斤、1.2–1.5斤、1.5斤以上。
   - 或按客户常用等级分：小果、中果、大果、精品果。
   - 每档单独记录，不要混装统计。

2. **看4个核心指标**
   - **日均出货量**：同一时间段每档卖了多少件/斤。
   - **出货速度**：从到货到卖完平均几天。
   - **询价转化率**：问某规格的客户里，实际下单比例。
   - **退换/剩货率**：哪档剩得多、损耗大。

3. **做7–10天小测试**
   - 每档保持合理库存，不要只摆一种规格。
   - 每天固定时间记录：到货量、销售量、剩余量、报价、成交价。
   - 重点看“同样库存下，哪档先清完”和“哪档复购多”。

4. **简单判断标准**
   - 出货量最大、清货最快、剩货少：主推规格。
   - 询价多但成交少：价格或品质匹配有问题，不一定是最好卖。
   - 出货慢但毛利高：可作为利润补充，不宜压太多库存。
   - 连续几天某规格剩货明显：下一批减少该规格采购。

5. **还要分客户看**
   - 商超/水果店：可能偏好中果、外观整齐。
   - 餐饮/榨汁/加工：可能偏好大果或性价比高的统货。
   - 零售摊贩：可能偏好中小果、价格敏感。
   
   所以“最容易出货”要分渠道判断，不能只看总销量。

**最简执行办法：** 下一批货把各规格分开码放，连续7天记录“每天各规格卖了多少、剩了多少、谁买走的”，7天后主推“剩货最少、清货最快、复购最多”的规格，同时减少滞销规格采购量。
