# 餐饮店每天少量水果，找什么供应商省心

先说结论：**最省心的不是“找一个大供应商”，而是“本地批发市场固定档口 + 一个备用渠道”的组合**。每天量少的话，别指望供应商给你多好的账期和服务，重点是把“少而稳”变成对方愿意接的小单。

## 按优先级试这几种

**1. 本地果蔬批发市场的固定档口（首选）**
- 优点：品类全、价格透明、当天可补货、能亲眼挑货，量少也卖。
- 做法：固定找 1–2 家，谈好“每天上午几点前送到/自提、少批量、次品包换”。混脸熟后，小单也愿意接。
- 注意：批发市场档口凌晨最忙，小单容易被排到最后，最好约定固定配送时段。

**2. 本地生鲜配送平台/B2B（如美菜、快驴这类，看当地覆盖）**
- 优点：线上下单、有起送门槛但可拼单、票据规范、省沟通。
- 缺点：品控看运气，水果新鲜度不如自己挑；起送量可能超过你“少量”需求。
- 适合：店里没人能早起跑市场、要发票、要稳定配送时间的。

**3. 社区水果店/夫妻店代采**
- 优点：离得近、量小也送、关系好可赊账、临时加单方便。
- 缺点：价格略高，品类受店里库存限制。
- 适合：每天就几斤、临时补货为主的店。

**4. 产地/一级批发商直供**
- 少量需求基本不划算，起订量大、配送不灵活，不建议作为日常主渠道，只适合做单品促销时临时谈。

## 判断供应商省不省心的 5 个硬指标

1. **是否接受小批量、固定频次**（每天或隔天），有没有最低起送量。
2. **缺货/次品怎么处理**：能否当天换补、拍照即赔，不用扯皮。
3. **配送时间是否固定**，迟到会不会影响你备餐/出餐。
4. **报价是否含配送、是否每天变价**，能不能给个大致价格区间。
5. **结算方式**：现结还是月结，小单一般现结更省事。

## 实操建议

- **先并行试 2 家两周**：一家批发市场档口、一家配送平台或社区店，记录到货时间、损耗率、缺货次数。
- **定一个“保底+机动”结构**：主供应商负责 80% 常规品类，备用渠道负责临时补货和主供应商缺货时兜底。
- **把要求写清楚**：每天几点前到、哪些品种、可接受损耗、次品处理方式，微信里留个文字约定，比口头靠谱。
- **少量采购优先选耐放的品类**（苹果、橙子、香蕉等），减少每天损耗和补货压力；易坏的浆果类按需少量买。

一句话：**每天量少，省心的关键是“固定档口混脸熟 + 一个备用渠道 + 把配送和售后规则提前谈死”**，而不是追求最低价。
