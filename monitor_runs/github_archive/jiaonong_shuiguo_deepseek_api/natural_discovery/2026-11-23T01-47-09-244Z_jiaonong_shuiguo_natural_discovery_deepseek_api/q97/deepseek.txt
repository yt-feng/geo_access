酒店采购水果盘原料时，建议在采购合同或验收标准里写清楚以下几类规格和外观要求，并按“可验收、可判定”的方式量化。

**一、通用规格要求**
1. **品种与等级**：明确每个水果的品种、产地、等级（如一级/特级），不接受以次充好或混装替代。
2. **单果规格**：规定单果重量范围或横径范围，例如苹果单果180–220g、橙子横径70–80mm，并允许的上下浮动比例。
3. **成熟度**：要求适合即食或短期展示的成熟度，不能过生（酸涩、硬）也不能过熟（软烂、发酵味）。
4. **新鲜度**：采摘/到货时间要求，如到货时距采摘不超过规定天数；叶菜类、浆果类应更短。
5. **安全与合规**：农药残留符合国家限量标准，提供产地证明、检测报告或承诺书；不得使用非法保鲜剂、染色剂、打蜡超标等。
6. **包装与标识**：标明品名、产地、等级、净重、采摘/包装日期、供应商信息；包装应防压、防潮、透气，避免运输损伤。

**二、外观标准**
1. **色泽**：具有该品种应有的自然色泽，色泽均匀，无明显褪色、发白、发黑或异常染色。
2. **形状**：果形端正，无明显畸形、偏斜、裂口；用于整果摆盘的水果应大小均匀、形状一致。
3. **表面缺陷**：无明显机械伤、压伤、擦伤、虫眼、病斑、霉点、腐烂、裂果、冻伤、日灼伤。
4. **洁净度**：表面无泥土、明显药斑、污渍、异物；允许少量自然果粉，但不能有霉变或黏液。
5. **新鲜度外观**：果柄、果蒂新鲜不发黑；叶片不萎蔫；浆果不渗汁、不塌陷；切果类切口平整、不变色、不干边。
6. **气味与口感**：无异味、发酵味、霉味；到货抽检口感应正常，无严重酸涩或水化。
7. **一致性**：同一批次颜色、大小、成熟度基本一致，便于酒店摆盘标准化。

**三、验收与判定建议**
- **抽样比例**：按到货件数或重量抽检，例如每批抽5%–10%，大货可分批抽。
- **缺陷容忍度**：明确允许的轻微外观缺陷比例，如单果轻微擦伤不超过表面积5%，且不影响食用和摆盘；严重缺陷如果腐、霉变、虫害应零容忍。
- **不合格处理**：约定拒收、换货、扣款标准；腐烂、霉变、农残超标可整批拒收。
- **留样与记录**：验收拍照留样，记录批次、温度、数量、缺陷情况，便于追溯。

**四、不同水果的补充重点**
- **苹果/梨**：重点看压伤、碰伤、果锈是否影响外观。
- **橙/柑橘**：看表皮油胞完整、无霉斑、无软腐，大小均匀。
- **葡萄/浆果**：看果粉完整、无渗汁、无落粒、无霉变，冷链到货。
- **西瓜/哈密瓜**：看果形周正、无裂口、无软塌，切果类要求切口新鲜。
- **菠萝/芒果**：看成熟度一致、无黑斑腐烂、无冻伤。
- **叶果类/小番茄**：看无萎蔫、无裂果、无虫害。

建议把上述内容整理成《水果原料验收标准表》，按品种列明规格、成熟度、缺陷允许范围和拒收条件，供应商签字确认后随货验收执行。
