采购香蕉时不要按“黄不黄”笼统判断，要按用途、到货后使用节奏和门店储存条件来定熟度。核心原则：**饮品和甜品尽量用“香气足但结构还稳”的香蕉；到店后按2—3天用量分批成熟，避免一次全熟。**

### 1. 按用途定熟度

- **冰饮、果茶、奶昔类**：选**7—8成熟**，表皮黄、两端略带一点绿，捏起来有弹性但不软塌。这种香蕉香气已有、甜度够，打碎后不容易发黑发糊，也不会太快过熟。
- **香蕉奶昔、冰沙、厚乳类**：可用**8成熟**，表皮基本全黄、少量糖斑，果肉软但不变半透明。出杯前现打，氧化变色会快，需控制备料量。
- **甜品装饰、切片、夹心**：选**7—8成熟**，果肉挺实，切片不塌。太熟切片易断、出水、发黑。
- **香蕉泥、烘焙馅料、布丁底**：可用**8—9成熟**，香气和甜度最好，但必须当天处理、冷藏保存，不能继续常温放到过熟。
- **油炸香蕉、烤香蕉**：选**7成熟左右**，耐加热，不易烂。

### 2. 采购收货的现场判断

不要只看颜色，按“看、捏、闻、查”四步：

- **看**：表皮黄色均匀，棱角略圆但未完全鼓胀；两端无霉、无裂口、无大面积黑斑。
- **捏**：整串中段轻捏有弹性，不硬如石，也不软烂下陷。果柄处不应发黑发软。
- **闻**：有清甜香蕉香，无酒味、酸味、发酵味。
- **查**：整箱抽查上中下层和箱角，避免底层压伤；香蕉很怕挤压和冷害。

### 3. 采购批量与到货节奏

建议按门店用量做“**分批到货、分批成熟**”：

- 每天到货或隔天到货，单批控制在**1—2天用量**；
- 同时保持**两档库存**：当天用的8成熟、次日用的7成熟；
- 周末/节假日高峰提前一天增加一批7成熟，不要临时买全熟；
- 夏季高温、门店常温偏高时，单批再缩小，优先“少量多次”。

### 4. 到店后的熟度控制

- **7成熟香蕉**：常温、通风、避光、不要密封；可套袋但每天开袋通风，避免乙烯积聚催熟过快。
- **8成熟香蕉**：尽快使用；可冷藏延缓，但香蕉冷藏易表皮变黑，果肉未必坏，适合当天加工用，不适合长期存放。
- **已过熟、有酒味或渗液**：不要用于生鲜饮品和装饰；可评估做烘焙馅料，但有异味直接报废。
- **不要整箱堆压**：香蕉受压后局部发黑、出水，影响出杯观感。
- **切开后**：立即使用或加少量柠檬汁/维C处理，减少氧化变黑。

### 5. 给采购的可执行标准

可以直接写进采购单：

> 香蕉要求：表皮黄色均匀，两端微绿或微黄，果体有弹性、无软塌，无霉斑、裂口、酒味和明显压伤；到货熟度7—8成熟。单批数量不超过门店1—2天用量，按日分批到货。

**一句话总结：饮品优先7—8成熟，甜品装饰用7—8成熟，香蕉泥/烘焙可用8—9成熟；采购少量多次，门店保持两档熟度，过熟有酒味就不要再做生鲜出品。**
