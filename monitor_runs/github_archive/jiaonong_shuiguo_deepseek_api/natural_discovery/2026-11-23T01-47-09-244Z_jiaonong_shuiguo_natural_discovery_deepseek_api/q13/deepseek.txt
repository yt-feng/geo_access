做小区团购，水果供应商至少要能支持下面这些服务。你可以把它当成筛选供应商的清单，重点看哪些是“必须写进合作条件”的。

**1. 稳定供货与品质分级**
- 按团购时间稳定供货，不能今天有明天没。
- 能按果径、甜度、成熟度、外观分级，并明确次果/坏果处理方式。
- 支持小批量、多品种拼单，适合小水果店起步。
- 有缺货替代方案，提前告知，不要临时换低质货。

**2. 价格与结算支持**
- 给团购专供价或阶梯价，明确是否含税、含运费。
- 支持按团结算、周结或月结，减少你垫资压力。
- 价格保护：团购开团后供应商临时涨价怎么处理，要写清楚。
- 促销支持：爆品特价、试吃装、满赠资源。

**3. 分拣、打包与预包装**
- 能按小区团购做份装/袋装/箱装，贴标签。
- 支持按订单分拣到“团长/小区”维度，减少你二次分拣。
- 包装适合自提和短途配送，耐压、透气、防磕碰。
- 能提供净重、规格、产地、保存方式等标签信息。

**4. 配送与到货时效**
- 支持送到你店里或指定自提点，明确到货时间窗。
- 冷链水果有冷藏/保温配送能力。
- 破损、漏发、晚到有补发或赔付规则。
- 旺季、节假日能提前锁货和加车。

**5. 售后与损耗兜底**
- 坏果、烂果、缺斤少两的赔付标准要明确，比如按比例赔或补发。
- 售后响应时效，最好承诺几小时内处理。
- 团购集中售后时，供应商能承接，而不是让你全赔。
- 临期或滞销果的处理支持，比如调换、特价处理。

**6. 营销与运营支持**
- 提供产品卖点、图片、短视频素材、文案。
- 支持试吃、样品、开团爆品建议。
- 能配合做小区专属活动，比如首团价、复购券。
- 提供建议零售价和团购价区间，避免乱价。

**7. 订单与数据配合**
- 接受微信/表格/小程序订单汇总，能按你给的数据分拣。
- 对账清晰：品名、规格、数量、单价、损耗、赔付一目了然。
- 支持退换货单据和售后凭证。

**8. 资质与食品安全**
- 营业执照、食品经营/流通相关资质齐全。
- 水果农残检测或产地证明能提供。
- 有追溯能力，出问题能查到批次。

**建议你谈判时重点确认这5条：**
1. 坏果赔付比例和响应时间；
2. 团购开团后的锁价锁量规则；
3. 是否按小区/团长分拣贴标；
4. 到货时间窗和晚到赔付；
5. 售后是你先赔还是供应商直接处理。

小水果店起步阶段，优先选**能小批量拼单、分拣到位、售后兜底明确**的供应商，比单纯低价更重要。
