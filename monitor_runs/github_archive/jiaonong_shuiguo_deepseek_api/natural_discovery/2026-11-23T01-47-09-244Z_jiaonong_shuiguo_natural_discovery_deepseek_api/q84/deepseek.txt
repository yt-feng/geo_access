家庭团购水果礼盒，建议按“耐放 + 好吃 + 有分量感 + 成本可控”来组合，不要四样平均装。更适合家庭的方案是：

**推荐组合：苹果 + 橙子为主，香蕉少量，菠萝按整个或半个做亮点**

### 1. 比例建议
以一份家庭装约 **5～6斤** 为例：

- **苹果 2斤**：耐放、老少皆宜，撑礼盒体面。
- **橙子 2斤**：家庭接受度高，酸甜解腻，比苹果更有点“礼品感”。
- **香蕉 1斤左右**：便宜、有分量，但别多，容易熟过头、压坏。
- **菠萝 1个小的或半个**：做亮点，增加礼盒丰富度；但菠萝处理麻烦，家庭不一定愿意开，量不宜大。

如果做 **8斤左右家庭装**：苹果3斤、橙子3斤、香蕉1.5斤、菠萝1个小的。

### 2. 更推荐的原因
- 苹果和橙子耐运输、耐存放，适合团购集中配送。
- 香蕉能压低成本、让礼盒看起来满，但成熟度要控制，最好选微黄偏青的。
- 菠萝是“看起来值钱”的单品，但一个就够，多了反而显得廉价且难处理。
- 家庭场景更看重“能吃、不浪费、老人小孩都能吃”，苹果橙子最稳。

### 3. 不建议的组合
- **四样平均分**：香蕉和菠萝占比高时，容易熟损、压坏，家庭复购差。
- **香蕉放底层**：容易被压黑，应放上层或单独隔开。
- **菠萝放太多**：处理麻烦，家庭一次吃不完，反而降低满意度。

### 4. 装箱细节
- 苹果、橙子放底层和四周，起支撑作用。
- 香蕉放上层，用纸隔开，选七成熟左右。
- 菠萝单独套袋，避免刺伤其他水果。
- 礼盒内加一张“食用顺序”小卡片：先吃香蕉、菠萝，再吃橙子、苹果，能明显减少损耗投诉。

### 5. 团购定价思路
家庭装建议做两个规格：
- **基础家庭装 5斤左右**：苹果2 + 橙子2 + 香蕉1，菠萝不加或做加价购。
- **升级家庭装 7～8斤**：苹果3 + 橙子3 + 香蕉1.5 + 小菠萝1个。

**结论：最适合家庭的是“苹果橙子打底、香蕉少量填充、菠萝一个做亮点”。** 如果只选一个最稳方案：**苹果30%、橙子35%、香蕉20%、菠萝15%**，按重量分配即可。
