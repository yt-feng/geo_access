结论：**多数甜品店买成品果丁的“可视损耗”更低，但综合成本不一定更低；如果门店客流稳定、切配和冷藏管理到位，鲜果现切的真实损耗也可以压到接近成品果丁。** 关键是看你要比较的是“损耗率”还是“总成本”。

### 1. 损耗怎么比
- **鲜果切配**：损耗包括去皮去眼、修边、氧化变色、切配过量、冷藏风干、过期报废。菠萝出成率通常约 **45%～60%**，管理差时真实可用率还会更低。
- **成品果丁**：损耗主要是开封后未用完、冷藏变味、汁水流失、临期报废。它把原料修整损耗转移给了供应商，门店端损耗通常更可控，但单价更高。

### 2. 什么情况下选成品果丁
适合：
- 日用量小且不稳定；
- 人手紧、切配空间不足；
- 菠萝只做点缀，用量少；
- 门店对出品标准化要求高，不想承担鲜果品质波动。

优点：**门店损耗低、出品稳定、省人工**。  
缺点：**采购单价高、口感略差、开封后仍有报废风险**。

### 3. 什么情况下选鲜果切配
适合：
- 每日菠萝用量稳定且较大；
- 有冷藏操作间和规范效期管理；
- 能做“按量切配、少量多次”；
- 有员工能稳定完成切配。

优点：**原料成本低、新鲜度和口感好**。  
缺点：**人工和修整损耗高，管理不好损耗会明显高于成品**。

### 4. 可执行的判断方法
建议做 **7天对比测试**：
1. 分别记录鲜果和成品果丁的**进货重量、采购金额、实际可用重量、报废重量、人工耗时**。
2. 计算：
   - 门店端损耗率 = 报废重量 ÷ 进货重量；
   - 真实可用成本 = 采购金额 ÷ 实际可用重量；
   - 再加上人工成本和冷藏占用。
3. 若鲜果真实可用成本不低成品果丁 **15%以上**，且日用量不稳定，优先成品果丁。
4. 若鲜果真实可用成本明显更低，且日用量稳定，选鲜果切配，但必须执行“少量多次切配、密封冷藏、当天用完”。

**一句话建议：小店、用量少、人手紧选成品果丁；用量稳定、管理规范选鲜果切配。不要只看单价，要算“实际可用成本+人工+报废”。**
