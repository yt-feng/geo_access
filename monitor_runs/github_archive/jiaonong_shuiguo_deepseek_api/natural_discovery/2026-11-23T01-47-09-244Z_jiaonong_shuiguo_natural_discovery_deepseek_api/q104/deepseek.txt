# 水果采购验收与售后处理建议

## 一、到货验收怎么做

**1. 先定标准再收货**
- 在采购合同/订单里写清：品种、规格（单果重量/直径）、等级、成熟度、允许的次果率（如≤5%）、包装要求、到货时限。
- 附上品质标准图或样品封存，避免"各说各话"。

**2. 到货时当场验收，别拖**
- **数量**：逐箱或抽箱清点，记录箱数、净重（去包装称重）。
- **抽样比例**：大批量按 10%–20% 随机抽箱，每箱再抽若干果检查；小批量可全检。
- **看外观**：大小是否一致、有无腐烂/碰伤/虫眼/裂口、色泽和成熟度是否统一。
- **切开抽检**：对成熟度、内部品质（如是否空心、糖度）抽几个切开看，必要时用糖度计。
- **拍照留证**：每批到货拍全景、问题果特写，标注时间、批次、箱号。

**3. 当场出具验收单**
- 记录合格数、不合格数、不合格原因，双方签字确认。不合格部分当场隔离，不要混入合格品。

**4. 分级处理**
- **轻微不一致**（如大小略差、少量次果在允许范围内）：按约定折价或让步接收。
- **明显不一致**（次果率超标、品种/等级不符、腐烂较多）：拒收该批或要求换货，并在验收单上写明。

## 二、售后怎么处理

**1. 第一时间书面通知供应商**
- 到货后尽快（建议 24 小时内，易腐水果越早越好）以微信/邮件/函件形式发《质量异议通知》，附照片、验收单、抽样记录，明确诉求：换货、补货、折价或退货退款。

**2. 保留证据链**
- 合同/订单、验收单、照片视频、沟通记录、称重记录。腐烂水果先拍照再隔离，必要时封存样品。

**3. 按合同条款索赔**
- 依据合同中的质量条款、违约责任、退换货约定执行；没有明确约定的，按《民法典》买卖合同相关规定主张减少价款、换货或解除合同。
- 因品质问题造成的额外损失（如活动延误、二次分拣人工），有证据的可一并协商。

**4. 建立供应商考核**
- 记录每批次合格率、售后响应速度，作为后续是否继续合作、调整采购份额的依据。连续出问题的供应商应约谈或替换。

## 三、实操小贴士

- **分批到货、少量多次**：尤其夏季，减少一次性大批量到货的腐烂风险。
- **验收时间避开高温时段**，到货后尽快入冷库或阴凉处。
- **约定"到货即验、逾期视为合格"的时限**要谨慎，别把验收窗口定得太短导致自己来不及检查。
- **留 5%–10% 尾款**待验收合格后支付，增加履约约束力。

核心原则：**标准前置、当场验收、书面留证、按约处理**。品质不一致不可怕，怕的是没标准、没记录、事后扯皮。
