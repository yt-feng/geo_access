判断水果供应商靠不靠谱，核心不是看他第一次报价多低，而是看**稳定性、损耗承担、账期和出问题后的处理态度**。给你一套可直接执行的判断方法，专门针对香蕉和菠萝这种“易损耗、成熟度敏感”的品类。

**1. 先看货源稳定性，不看嘴上承诺**
- 香蕉：问清楚是国产还是进口、主产区在哪、是否常年有货、催熟是供应商做还是你自己做。靠谱供应商会明确告诉你“哪几个月货源紧、价格会涨”，而不是拍胸脯说全年一个价。
- 菠萝：问品种和产季，比如海南、广东、云南等产区轮换，能否稳定供同一品种。如果他说“什么季节都有好货”，要警惕拼货、混级。
- 连续问三次不同时间的报价和库存，看说法是否一致。价格随行就市正常，但口径反复、含糊其辞就不靠谱。

**2. 必须实地或视频看货，重点看分级和成熟度**
- 香蕉：看催熟均匀度、青硬比例、是否有“水烂”“梅花点”过早出现。靠谱供应商敢让你看整批，不只给你看样品。
- 菠萝：看果形、成熟度一致性、黑心风险、冠芽新鲜度。问清楚“到店后几天内必须卖完”，敢给明确周转建议的更可靠。
- 第一次合作不要大单，先拿小批量试销，记录到店损耗率。香蕉和菠萝的正常损耗因季节和运输差异很大，重点看**他是否提前告知风险**，而不是出问题后推给天气。

**3. 看损耗和售后怎么约定**
- 明确问：到货后坏果、烂果、成熟度不符怎么赔？是补货、扣款还是退货？多久内反馈有效？
- 靠谱供应商会接受“开箱验货、拍照留证、按比例赔付”，并且愿意把规则写进微信或单据。只说“放心，不会有事”的，长期合作风险高。
- 注意区分“运输损耗”和“品质问题”。香蕉催熟过头、菠萝黑心，属于货源品质问题，不该让你全承担。

**4. 看送货时效和仓储条件**
- 香蕉对温度敏感，菠萝怕挤压和低温。问清楚送货车辆是否有温控、多久送一次、临时补货能不能当天到。
- 观察他仓库是否分品类存放、是否有催熟房。连仓储都混乱的供应商，长期稳定性通常差。
- 旺季和雨天各试一次送货，看是否准时、包装是否到位。这两次最能看出真实水平。

**5. 看账期和合作条款是否清楚**
- 长期合作建议先做“现结或短账期”，稳定后再谈账期。靠谱供应商会明确结算周期、价格调整机制，比如随产区行情每周报价。
- 警惕两种：一是报价明显低于市场还承诺长期不涨，二是一直催你大批量压货。水果行情波动大，违背常识的低价往往靠混级或后期补回来。
- 合同或微信里写清楚：品种、规格、等级、单价、送货时间、损耗赔付、涨价提前通知时间。

**6. 用三个小测试快速筛选**
- **试小单**：连续拿三次小批量，看品质是否稳定。
- **试售后**：故意在一次到货中如实反馈少量坏果，看他处理速度。推诿的直接降级。
- **试急单**：临时要一次补货，看响应能力。长期供应商必须能应对突发。

最后给你一个简单判断标准：**敢让你看整批货、敢明确说风险、敢约定赔付、价格随行就市但口径稳定的供应商，才值得长期合作。** 香蕉和菠萝别只盯单价，算“到店可售率”和“售后成本”才是真实进货成本。建议同时保留2家供应商，主供占七成、备供占三成，避免被单一供应商卡脖子。
