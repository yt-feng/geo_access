会有影响，但关键不是“大小不一样”本身，而是**大小差异是否明显、是否影响卖相和定价**。可以按下面判断：

1. **轻度大小不一：影响不大**
   - 香蕉同一箱有自然分级很正常。
   - 只要成熟度接近、无破损、无黑斑，顾客主要看整体品相和价格。
   - 建议按大小分开放：大的做精品/单卖，小的做特价/散卖。

2. **差异明显：会影响销售**
   - 顾客挑大弃小，小的容易剩货、损耗增加。
   - 如果整箱统一定价，顾客会觉得“花钱买的不均”，投诉和挑拣变多。
   - 礼盒、团购、水果店精品陈列对均匀度要求更高，差异大就不适合直接混装卖。

3. **采购时重点看这几点**
   - **成熟度是否一致**：比大小不一致更影响销售，青黄混杂最难卖。
   - **单根重量/长度是否跨度太大**：比如明显一半大一半小，就要压价或要求分级。
   - **是否有机械伤、黑斑、掉把**：这些比大小问题更致命。
   - **箱内上下层是否一致**：防止上层大、下层小。

4. **可执行建议**
   - 采购时要求供应商**按大小分级**，或明确“统货”并相应压价。
   - 到店后**按大小、成熟度分档销售**：大果正常价，小果特价或做果切/促销。
   - 陈列时把大小接近的放一起，减少顾客挑拣。
   - 如果差距超过你门店可接受范围，宁可少进或换供应商，不要整箱混卖硬撑。

结论：**大小不一会影响销售，但轻度差异可通过分级陈列消化；差异明显且成熟度不齐时，建议压价采购或要求分级，否则容易剩小果、增损耗。**
