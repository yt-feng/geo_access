更影响最终毛利的是**损耗低**，但前提是售价和销量不被低价采购破坏。可判断结论：

**1. 低价主要改善“毛利额”，损耗直接决定“毛利是否变成利润”**
- 水果毛利=销售额-采购成本-损耗成本-运营费用。
- 采购价低10%，若售价不变，毛利率提升有限；但损耗高5~10个百分点，往往会把毛利吃光。
- 水果尤其叶菜、浆果、熟度高的品类，损耗是毛利第一杀手。

**2. 低价如果伴随品质差、货架期短，会反向推高损耗**
- 便宜货源常见问题：成熟度高、规格不齐、冷库/运输链条差。
- 结果可能是：采购单价降5%，损耗率升8%，最终毛利更差。
- 所以“低价”必须看**可售率/货架期/到店品质**，不能只看采购单价。

**3. 用可执行公式判断**
单公斤毛利≈售价×可售率－采购价－分摊损耗－运营分摊。  
更直接看：  
**毛利额=销量×售价×可售率－销量×采购价－损耗处理成本。**  
采购决策时重点比较：
- 采购价下降幅度；
- 预计损耗率上升幅度；
- 售价能否维持；
- 周转天数是否延长。

**4. 经验判断**
- 对高损耗品类（草莓、葡萄、叶菜、熟香蕉、桃李）：**损耗低优先于价格低**。
- 对耐储品类（苹果、梨、柑橘、土豆、洋葱）：**价格低的权重可以上升**。
- 对引流品：可接受略高损耗，但要限定陈列量和周转。
- 对毛利品：必须优先低损耗和稳定品质。

**结论：**  
**最终毛利上，损耗低通常比价格低更关键；价格低只有在不显著推高损耗、且能维持售价和周转时才有价值。**采购考核应看“到店可售成本”和“损耗后毛利”，而不是单纯采购单价。
