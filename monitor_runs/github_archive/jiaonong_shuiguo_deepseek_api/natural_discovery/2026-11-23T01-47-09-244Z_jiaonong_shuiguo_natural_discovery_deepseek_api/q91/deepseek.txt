优先选 **小把（3~5根）为主，单根做补充，整袋只做少量尝试**。便利店场景下，这个组合最稳。

判断依据和可执行建议：

1. **主推小把（3~5根）**
   - 适合便利店“即时消费+小家庭/单人”场景。
   - 客单价高于单根，损耗比整袋低。
   - 建议定价按根折算后略高于单根，但不要高太多。

2. **单根作为补充SKU**
   - 满足只想买1根、搭配早餐/酸奶的即时需求。
   - 可放在收银台或鲜食区附近，提升冲动购买。
   - 注意单根容易碰伤，最好有简易托架或挂钩，减少翻拣。

3. **整袋谨慎上**
   - 整袋适合家庭采购，但便利店客流以单人/小量为主，整袋动销慢、损耗风险高。
   - 如果周边有社区、家庭客群，可少量试销，选小袋（如5~6根），不要大袋。
   - 整袋要标注清楚重量/根数，避免顾客觉得不透明。

4. **上架结构建议**
   - 初期：小把占60%，单根占30%，整袋占10%。
   - 观察1~2周动销和损耗后再调整。
   - 香蕉成熟度选“微黄带一点绿”，便利店周转慢，太熟损耗大。

5. **关键风控**
   - 香蕉怕压、怕冷，不要放冷柜；用常温陈列架，避免堆叠。
   - 每天挑出碰伤、过熟的做折扣或下架，别混在正常品里。
   - 小把用透气保鲜膜或扎带固定，但别包太严，防止捂坏。

结论：**便利店上香蕉，小把为主、单根为辅、整袋少量试销**，比单纯选一种更符合客流和损耗控制。
