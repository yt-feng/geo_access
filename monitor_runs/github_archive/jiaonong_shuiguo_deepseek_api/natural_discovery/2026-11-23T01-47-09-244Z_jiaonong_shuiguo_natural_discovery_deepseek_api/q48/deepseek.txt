判断菠萝供应商能不能稳定按规格送货，不要只看“有没有货”，要按下面6个维度做可验证的考察。核心是：把“规格”写成可验收的标准，再用样品、试单、现场审核和合同约束去验证。

**1. 先把规格定义到可验收**
不要只说“要菠萝”，要明确：
- 品种：如金钻凤梨、巴厘菠萝等，固定品种。
- 单果重量区间：如1.2–1.5kg/个，超出拒收或降级。
- 成熟度：糖度范围、果心状态、表皮颜色、有无黑心/水心。
- 外观：果形、无裂口、无腐烂、无机械伤、冠芽状态。
- 加工形态：整果、去皮、切块、冷冻/冷藏，包装规格。
- 到货温度、保质期、批次追溯要求。
- 验收方法：抽检比例、糖度抽测、称重抽检、坏果率上限。
只有这些写进采购标准，供应商“能不能稳定按规格送”才有判断依据。

**2. 看产地与季节供应能力**
菠萝有明显产季和产区差异。要问清：
- 自有基地、合作社还是多级贩子？自有/直采比例越高，稳定性通常越好。
- 主产区轮换能力：能否在主产区换季时仍稳定供货。
- 天气、台风、寒害等风险下的备货方案。
- 日均可供量、最大可供量、最小起订量，是否覆盖你的峰值需求。
要求供应商提供近6–12个月的供货记录，而不是只听口头承诺。

**3. 用样品和试单验证**
先做小批量试单，至少覆盖2–3个批次、不同时间段：
- 每批抽检重量、糖度、坏果率、成熟度一致性。
- 记录到货合格率、规格偏差率、损耗率。
- 观察连续供货时规格是否漂移。
试单建议设明确门槛，例如连续3批抽检合格率达到95%以上，再进入正式合作。不要用一次样品就下结论。

**4. 现场或视频审核供应链**
重点看：
- 分拣线是否按重量/外观分级，是否有糖度检测环节。
- 冷库、预冷、运输温控是否到位。
- 批次记录、农残检测报告、产地证明是否可追溯。
- 高峰期分拣和装车能力，是否依赖临时工导致规格不稳。
如果无法现场审核，至少要求视频看分拣和仓储，并核对检测报告的真实性。

**5. 用合同和验收条款锁住稳定性**
合同里写清：
- 规格标准、抽检方法、拒收条件、降级处理。
- 坏果率/规格偏差率上限及扣款规则。
- 缺货、延迟、质量不达标的违约责任和替代方案。
- 价格调整机制，避免行情波动时以次充好。
- 批次追溯和食品安全责任。
同时保留到货拍照、称重、抽检记录，作为后续考核依据。

**6. 建立供应商评分和备份机制**
合作后按月打分：
- 到货合格率、规格偏差率、准时率、缺货次数、投诉响应。
- 连续不达标就降级或替换。
不要只依赖一家供应商，至少储备1–2家备选，尤其是产季切换和台风季前。

**可执行判断标准**：如果供应商能提供明确产地和分级能力、近半年稳定供货记录、连续3批试单合格率≥95%、有温控和追溯体系、且合同接受规格偏差扣款，基本可判断具备稳定按规格送货能力。反之，只靠口头保证、无法说明产地、样品批次差异大、拒绝试单或验收条款的，不建议直接放量采购。
