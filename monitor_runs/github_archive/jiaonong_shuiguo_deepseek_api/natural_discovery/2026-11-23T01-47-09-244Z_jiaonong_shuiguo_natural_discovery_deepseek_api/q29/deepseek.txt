超市和水果供应商的账期没有唯一标准，常见区间大致如下，但要按“品类+渠道+供应商地位”分开看：

1. **大型商超/连锁超市，水果类常见账期**
   - **30～60天**较常见，尤其是连锁超市、区域龙头超市。
   - 强势全国性连锁、平台型渠道可能压到 **60～90天**，甚至更长，但对水果这种高损耗品类，实际操作中常会用“部分现结+部分账期”或缩短到 **30～45天**。
   - 中小超市、社区超市更常见 **15～30天**，部分生鲜品类 **7～15天**。

2. **水果批发/生鲜供应链行业惯例**
   - 水果损耗高、价格波动大，供应商通常更希望 **7～15天** 或 **周结**。
   - 超市如果要求 **30天以上**，供应商往往会在报价中加资金占用成本，或要求缩短账期、提高供货价、减少退换货责任。
   - 进口水果、精品水果因单价高、周转慢，账期可能比普通水果略长，但通常也不宜超过 **45～60天**。

3. **谈判时可参考的合理区间**
   - 新供应商首合作：**15～30天**较稳妥。
   - 稳定合作后：**30～45天**是较常见的平衡点。
   - 强势超市压价场景：**45～60天**可能出现，但供应商通常会要求价格上浮或缩短部分品类账期。
   - 超过 **60天**对水果供应商资金压力较大，除非采购量大、回款稳定、违约条款清晰。

4. **建议的谈判口径**
   - 超市方：可先提 **30天**，争取 **45天**，并把“对账日、开票日、付款日”写清楚，避免“账期30天”实际变成60天。
   - 供应商方：优先争取 **15～30天**；若接受45天以上，应把资金成本计入报价，或要求部分预付款/周结。
   - 合同里明确：**收货对账周期、发票提交时间、付款起算日、逾期违约金、退货扣款规则**。水果退货和损耗扣款若不清，账期名义30天也可能拖到60天以上。

**结论：** 水果供应商给超市的账期，常见是 **15～45天**；大型连锁超市常见 **30～60天**，但水果品类因高损耗，实际更偏向 **15～30天或30～45天**。谈判中 **30天左右**最普遍，**45天**是常见上限平衡点，**60天以上**属于偏强势压账期。
