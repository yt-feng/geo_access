水果生意长期稳定，选择供应商时最容易忽视的不是“价格”，而是以下几类“隐性稳定性”细节：

1. **同批次一致性，而不只是样品好**
   很多供应商样品挑得很好，但大货批次差异大。要关注：同一品种连续3批的规格、糖度、硬度、色泽、果径是否稳定；能否接受抽检和留样；是否愿意把关键指标写进供货标准。

2. **产地与季节切换能力**
   只问“现在有没有货”不够。要问清：主产区、次产区、替代产区怎么排；换季时货源是否连续；遇到减产、天气、节庆时如何保供。长期稳定靠的是供应链切换能力，不是单一产地。

3. **损耗责任和验收标准**
   最容易扯皮的是“到货坏果算谁的”。要提前明确：验收时限、抽检比例、坏果/压伤/腐烂/规格不符的判定标准、扣款或补货方式、运费和装卸责任。没有书面规则，长期合作很容易因损耗积累矛盾。

4. **采后处理和冷链细节**
   水果稳定性很大程度取决于采后。要关注：采摘成熟度、预冷是否及时、分级是否规范、包装是否适配运输、冷链是否连续、装车温度记录能否提供。尤其叶菜类、浆果类、荔枝等，冷链断链比价格更致命。

5. **供货峰值和履约能力**
   不要只看供应商“能不能供”，要看他“最忙时能不能供”。问清日均最大出货量、你所在区域的配送频次、旺季是否优先老客户、临时加单响应时间、车辆和人工是否自有或外包。

6. **财务和结算的可持续性**
   低价供应商可能靠压农户或账期撑量，一旦资金紧张就断供。要了解结算方式、是否要求预付、价格调整机制、涨跌价通知周期。长期合作应约定价格随行就市但透明调整，而不是口头锁价。

7. **售后响应和问题处理机制**
   要观察出现质量问题时，供应商是补货、折价还是推责；多久响应；是否有固定对接人；历史投诉如何处理。长期稳定供应商的核心不是永远不出问题，而是出问题能快速兜底。

8. **合规与票据**
   容易被忽视但影响长期经营：产地证明、检测报告、农残抽检、发票和合同主体是否一致。做商超、电商或团购时，这些会直接影响准入和售后。

建议落地做法：先用“小批量多批次”试供，连续跟踪3—4周，记录到货合格率、损耗率、规格偏差、响应时长和补货速度；再把验收标准、损耗责任、价格调整和保供条款写进简易供货协议。不要只选最便宜的，要选“波动最小、出问题能兜底”的。
