买香蕉时优先选**表皮黄但两端带一点青、摸起来硬实、没有黑斑**的。到店后想放得久，关键不是“等它熟”，而是**尽快降温、减少挤压、别密封闷着**。

可执行做法：

1. **采购时别买全熟蕉**
   - 做甜品常用的是“刚转黄、八九成熟”的香蕉。
   - 如果买回来马上用，可以选全黄；如果要放 2–3 天，选**黄中带青、蒂部还偏绿**的。
   - 避开：已经有黑点、表皮发软、整串发黑的。

2. **到店立刻拆袋、摊开**
   - 香蕉会释放乙烯，闷在塑料袋里会加速成熟变黑。
   - 到店后马上拆掉塑料袋，放在**通风、阴凉**处摊开。
   - 不要堆压，压伤的地方最先变黑。

3. **按成熟度分开存放**
   - 已经熟黄的：放阴凉通风处，尽快用；可冷藏延缓，但表皮可能变黑，果肉短期仍可用。
   - 还偏青的：常温放，别和熟蕉、苹果、梨等催熟水果放一起。
   - 如果店里冰箱够大：**熟香蕉可冷藏**，但要用纸包或装保鲜袋留口，主要延缓果肉过熟；表皮变黑不代表立即坏。

4. **不要整串挂着就不管**
   - 整串香蕉互相接触、底部受压，容易从接触点开始黑。
   - 可以**剪分成小把**，减少相互催熟和挤压。
   - 剪的时候留一点果柄，别撕伤表皮。

5. **控制采购量和使用顺序**
   - 甜品店最好采用“少量多次”采购，别一次囤太多。
   - 先进先用：熟的先做香蕉泥、奶昔、烘焙；青一点的留后面。
   - 如果当天用不完，熟蕉可去皮冷冻，做冰沙、香蕉泥、烘焙都方便。

6. **已经快黑了怎么救**
   - 表皮黑但果肉还香、不酸不酒味：尽快去皮冷冻或做熟制甜品。
   - 果肉发软出水、有酒味：不要再用于直接售卖。
   - 局部压伤变黑：先切除黑变部分，别等它扩散。

一句话：**买八成熟、到店拆袋摊开、分把通风、熟的冷藏或冷冻、少量多次采购**，基本就能避免到店后很快变黑。
