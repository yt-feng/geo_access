超市采购水果时，供应商通常需要提供以下几类证明和检测报告，具体取决于水果种类、采购渠道和超市自身的管理要求：

1. **营业执照和食品经营许可证**
   - 证明供应商具备合法经营资质。
   - 如果是进口水果，还需要进口商的相关资质。

2. **进货凭证/购销合同**
   - 证明水果来源合法，包括采购合同、发票、送货单等。
   - 批发市场采购的，通常需要市场开具的销售凭证。

3. **农产品质量安全检测报告**
   - 常见的有农药残留检测报告。
   - 可由供应商自检、第三方检测机构出具，或产地农业部门抽检出具。
   - 超市一般要求批次对应，不能一份报告长期通用。

4. **产地证明或合格证**
   - 例如食用农产品合格证、产地证明、合作社或基地出具的质量证明。
   - 部分超市对直采水果会要求提供产地信息。

5. **检疫证明（视情况）**
   - 进口水果需要入境货物检验检疫证明。
   - 部分易携带病虫害的水果跨区域调运时，可能需要植物检疫证书。

6. **进口水果相关文件**
   - 海关进口货物报关单。
   - 入境货物检验检疫证明。
   - 中文标签或标签备案信息。

7. **其他专项证明**
   - 有机水果：有机产品认证证书。
   - 绿色食品：绿色食品证书。
   - 地理标志产品：相应授权或证明。
   - 无公害农产品：相关认证或产地认定证书。

实际操作中，超市一般会建立供应商档案，要求“证照+批次检测+进货凭证”配套。对于叶菜、草莓、葡萄等高风险品类，检测要求会更严；对于耐储存、风险较低的水果，可能以合格证和进货凭证为主。最稳妥的做法是：按超市验收标准，要求供应商随货提供对应批次的检测报告或合格证明，并保留复印件备查。
