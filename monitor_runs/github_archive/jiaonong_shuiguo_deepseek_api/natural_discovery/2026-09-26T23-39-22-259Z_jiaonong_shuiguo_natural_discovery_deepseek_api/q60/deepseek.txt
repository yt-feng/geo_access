水果到货不合格时，核心是**先保营业，再谈责任**。建议从“约定条款”和“现场处理”两层同时抓。

## 一、采购合同/供货协议里要提前写清的条款

**1. 验收标准与时限**
- 明确验收标准：品种、规格、成熟度、糖度、外观、农残检测报告等，最好附照片或样品封样。
- 约定验收时限：到货后 X 小时内（如 2 小时）完成验收，逾期视为合格，避免扯皮。

**2. 不合格判定与处理方式**
- 分档处理：
  - **可折价使用**（轻微瑕疵）：按折扣结算，不退货。
  - **不可使用**：退货/换货。
- 明确“不合格”的判定依据，避免口头争议。

**3. 补货时效（关键）**
- 约定**补货到达时限**，例如：
  - 当日上午到货不合格 → 当日营业前补到；
  - 下午到货不合格 → 次日营业前补到，或当日紧急补。
- 写明**补货优先级**：补货订单优先于常规订单发货。
- 约定**替代方案**：若无法按时补货，供方需提供等值替代品或指定附近门店调货。

**4. 违约责任与损失分担**
- 逾期补货的违约金（按货款比例或固定金额）。
- 因缺货导致的营业损失如何分担（可约定保底赔偿）。
- 累计几次不合格可解除合作。

**5. 紧急调货机制**
- 约定供方有义务协助从其他渠道/仓库紧急调货。
- 明确紧急联系人及响应时间（如 30 分钟内回复）。

## 二、现场处理流程（不影响营业的操作）

1. **当场拍照、留证**：不合格水果、到货单、时间。
2. **先分拣**：能用的先用，减少损耗。
3. **立即通知供方**：电话+书面（微信/邮件）双通道，要求确认补货时间。
4. **启动备选**：
   - 附近门店调货；
   - 备用供应商；
   - 临时调整菜单（下架相关饮品或换配方）。
5. **记录缺货影响**：为后续索赔留依据。

## 三、建议写进协议的示例表述

> 供方所供水果经门店验收不合格的，供方应在接到通知后 X 小时内完成补货，且补货优先于常规订单。逾期未补货的，供方按该批货款的 X% 支付违约金，并赔偿门店因此产生的合理营业损失。若供方无法补货，应协助门店从其他渠道调货，费用由供方承担。

## 四、实操建议

- **不要只靠口头约定**，补货时限、违约金、替代方案都要落到书面。
- **保留备用供应商**，这是最实际的“不影响营业”保障。
- **验收标准越具体越好**，减少“这算不算不合格”的争议。
- 对小供应商，可约定**押金或账期扣款**，增强约束力。
