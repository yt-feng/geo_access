连锁商超找长期水果供应商，评分标准的核心不是“谁报价低”，而是“谁能在全年稳定供好货、控住损耗、配合门店节奏”。建议按**价格 30–35、质量与品控 25–30、供应与履约 20–25、服务与协同 10–15、资质与合规 5–10**来分配，具体可这样设：

**1. 价格（30–35分）**
不要只看单次报价，要看综合成本：
- 报价竞争力：15–20分，按品类/单品对比市场均价或基准价
- 价格稳定性：8–10分，考察是否接受季度/半年调价机制，是否承诺非不可抗力不随意涨价
- 账期与结算配合：5分，能否接受商超账期、对账流程
- 损耗承担与退换货成本：5分，坏果、次果、临期果怎么处理

**2. 质量与品控（25–30分）**
这是长期合作的关键：
- 样品与实地验货：8–10分，看外观、口感、糖度、成熟度、大小均匀度
- 农残检测与质检报告：5–8分，是否批批检测、能否提供第三方报告
- 分级标准：5分，能否按商超要求分等级、分规格
- 产地与季节供应能力：5–7分，是否有多产地、多产区调配能力，避免断供
- 冷链与保鲜能力：5分，采后预冷、冷链运输、仓储条件

**3. 供应与履约（20–25分）**
- 日均/峰值供货能力：6–8分，能否覆盖门店数和促销期增量
- 准时到货率：5–6分，参考历史履约数据或承诺
- 缺货应急方案：4–5分，是否有替代产区、替代品种、备用物流
- 门店覆盖与配送能力：5分，能否直送门店或仓配中心
- 信息化对接：3–5分，能否对接订单、库存、追溯系统

**4. 服务与协同（10–15分）**
- 售后响应速度：3–5分，坏果、少货、质量投诉多久处理
- 退换货政策：3–4分，是否主动承担、是否设免赔额
- 促销与新品配合：2–3分，能否配合商超做爆品、试吃、堆头
- 驻场或专人对接：2–3分，是否有专属客服/业务对接

**5. 资质与合规（5–10分）**
- 营业执照、食品经营许可、种植/养殖资质：2–3分
- 食品安全体系认证：2–3分，如ISO22000、HACCP、GAP等
- 追溯体系：2–4分，能否做到批次可追溯
- 保险与法律风险：1–2分，产品责任险、合同履约能力

**建议的评分表结构：**
| 维度 | 分值 | 关键打分点 |
|---|---|---|
| 价格 | 30–35 | 报价、调价机制、账期、损耗承担 |
| 质量与品控 | 25–30 | 样品、检测、分级、冷链 |
| 供应与履约 | 20–25 | 产能、准时率、应急、覆盖 |
| 服务与协同 | 10–15 | 售后、退换、促销配合 |
| 资质与合规 | 5–10 | 证照、认证、追溯、保险 |

**招标时特别建议加三条：**
1. **设置“试供期”**：中标后先试供1–3个月，试供不合格可终止或扣分。
2. **动态考核**：季度考核质量、准时率、损耗率、投诉率，和续约、份额挂钩。
3. **避免唯低价**：价格分过高容易招来“低价中标、后期降质”的供应商，长期水果供应尤其要重视稳定性。

如果你们门店多、品类杂，还可以按**苹果、柑橘、香蕉、浆果、进口果**等分品类招标，每个品类单独设权重，比“一刀切”更合理。
