超市水果到货后发现品相不好，售后流程最好在**采购/供货合同**里提前约定，不要只靠口头。核心是把“什么算品相不好、谁来判、什么时候提、怎么赔”写清楚。

可以按下面这套约定：

**1. 验收标准和时限**
- 到货后**当场验收**，或约定“到货后 X 小时内验收，逾期视为合格”。
- 明确品相标准：大小、颜色、成熟度、破损率、腐烂率、压伤率、虫眼、畸形、异味等。
- 最好量化，例如：
  - 腐烂/霉变：**超过 1% 可拒收**
  - 明显压伤/破损：**超过 3% 可要求折价或退换**
  - 规格不符：**超过 5% 可退货**
- 抽样方式也写清楚：按箱抽、按托盘抽、按比例抽，避免扯皮。

**2. 问题反馈流程**
- 收货方在验收期内拍照/录像，保留批次、箱号、到货时间、温度记录。
- 在约定时间内书面通知供应商，比如微信、邮件、系统工单都算，但合同里要写明有效通知方式。
- 通知内容：批次、数量、问题类型、照片、抽检结果、要求处理方式。

**3. 责任判定**
- 到货即发现：一般由供应商承担。
- 因收货方储存不当导致：由收货方承担。
- 责任不清时：可约定第三方检测或双方共同复检。
- 生鲜易腐，最好约定“**以到货验收记录为准**”，避免事后说不清。

**4. 处理方式**
可约定几种，按严重程度选择：
- 轻微：折价接收
- 中等：部分退货、换货、补货
- 严重：整批拒收、退货退款
- 因品相问题影响销售的：供应商承担损耗、运费、分拣费
- 多次不合格：可约定扣款、暂停供货、解除合同

**5. 退款/补货时限**
- 供应商确认后 **X 个工作日内**退款或补货。
- 补货必须同规格、同品质，且重新验收。
- 若逾期不处理，可约定按不合格货值的一定比例扣款。

**6. 证据和单据**
- 到货单、验收单、照片、视频、聊天记录、邮件、检测报告都要留存。
- 验收单最好双方签字，电子确认也可以。
- 写明“无验收记录视为未完成交付”或类似条款，防止供应商不认。

**7. 建议写进合同的示范条款**
> 买方应在到货后 4 小时内完成验收。若发现腐烂、霉变、严重压伤、规格不符等品相问题，买方有权拍照留证并书面通知卖方。腐烂率超过 1% 或破损率超过 3% 的，买方可要求折价、部分退货或整批退货；卖方应在 3 个工作日内完成退款或补货，逾期按不合格货值的 10% 支付违约金。因买方储存不当造成的问题，由买方承担。

**实操建议：**
- 生鲜类不要只写“品相不好可退货”，太模糊，容易争议。
- 最好把“不合格比例”和“处理档位”做成表格附在合同后。
- 首次合作可先小批量试单，验收标准跑顺后再放量。
- 如果是超市向供应商采购，验收权和扣款权要掌握在超市手里；如果是超市作为供货方，则要明确对方验收期限，避免无限期追责。
