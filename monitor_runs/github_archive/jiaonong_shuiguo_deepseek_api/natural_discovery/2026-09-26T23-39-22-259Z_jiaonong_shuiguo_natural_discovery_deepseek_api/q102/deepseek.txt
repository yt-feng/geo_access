结论：**通常需要支持开发票；定制包装是否必须，取决于你的采购规模、使用场景和预算。** 对企业福利采购来说，这两项都建议优先选择能支持的供应商。

**1. 开发票**
- **基本必须。** 企业采购要入账、报销、做成本费用，通常需要正规发票。
- 优先确认：能否开**增值税专用发票**或**普通发票**，发票内容能否开成“水果”“食品”“福利品”等符合财务要求的类目。
- 如果供应商不能开发票，财务往往无法正常入账，后续风险较大，不建议选。

**2. 定制包装**
- **不是所有场景都必须，但福利采购通常很加分。**
- 以下情况建议要求定制包装：
  - 想体现企业关怀，印企业名称、LOGO、祝福语；
  - 节日福利，如中秋、春节、端午；
  - 批量统一发放，需要外观整齐、有仪式感；
  - 用于客户赠送或员工表彰。
- 以下情况可以不定制：
  - 预算有限；
  - 采购量小，供应商起订量达不到；
  - 只追求水果品质，不强调品牌露出。

**3. 实操建议**
- 采购前直接问供应商这4点：
  1. 能否开发票？开什么票？税点多少？
  2. 定制包装起订量是多少？
  3. 定制是否额外收费？打样费、版费怎么算？
  4. 定制后交货周期多久？
- 如果采购量较大，建议把“开发票”和“定制包装”写进合同或采购订单，避免后期扯皮。

**一句话：开发票是硬门槛，定制包装是加分项。** 企业福利采购优先选两者都能支持的供应商，至少发票必须能开。
