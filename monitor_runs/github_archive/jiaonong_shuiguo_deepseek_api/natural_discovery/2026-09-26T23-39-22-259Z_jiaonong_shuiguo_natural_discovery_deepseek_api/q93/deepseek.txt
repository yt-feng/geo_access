对便利店卖菠萝切块来说，这三项不是三选一，而是都要看，但优先级和关注点不同：

1. **保质期最重要**
   菠萝切块属于即食鲜切水果，通常风险最高的是微生物滋生和氧化变质。  
   核心要盯：
   - 切好后冷藏条件是否稳定，一般建议 0～4℃。
   - 标注的食用期限是否合理，最好“当日切、当日售完”或不超过 24 小时。
   - 到点未售完必须下架报损，不能靠重新包装续命。
   - 是否冷链不断，特别是门店收货、暂存、陈列环节。

2. **包装是第二重要**
   包装直接影响保质期和卖相。  
   要关注：
   - 是否密封、防漏、防串味。
   - 是否适合即食，最好有盖或封膜，避免裸露。
   - 是否标注切制时间、保质期、储存条件。
   - 如果做气调包装或真空包装，能延长一点货架期，但成本更高，便利店未必需要。
   - 包装材料要食品级，且能冷藏使用。

3. **配送频次是保障条件**
   配送频次决定门店能不能做到“少批量、多频次”，从而减少临期和报损。  
   建议：
   - 如果门店销量一般，宁可每日 1～2 次小批量配送，也不要一次送很多。
   - 高销门店可每日配送，甚至分早晚两次。
   - 配送过程必须冷藏，不能常温车混送。
   - 配送频次要和门店销量、陈列量、报损率匹配。

**判断优先级：**
- 如果只能先改一件事：先抓**保质期管理和冷链**，因为这是食品安全底线。
- 如果保质期管住了但报损高：再优化**配送频次**，做到小批量、多频次。
- 如果容易变干、变味、漏汁、顾客不买：再优化**包装**。

**可执行建议：**
- 门店执行“切制时间 + 到期时间”双标注。
- 陈列量按 2～3 小时销量预估，不要一次性摆满。
- 每日记录报损，连续几天报损高就降低单次配送量、增加配送次数。
- 到期的菠萝切块直接下架，不要打折续卖到超期。

简单说：**保质期是底线，包装是保障，配送频次是减少损耗的手段。三者都要管，但先保食品安全，再谈损耗和卖相。**
