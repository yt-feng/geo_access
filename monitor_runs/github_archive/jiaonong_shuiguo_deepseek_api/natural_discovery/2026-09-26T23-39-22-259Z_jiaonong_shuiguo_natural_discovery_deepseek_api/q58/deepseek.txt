通常**直接买成品果丁的总损耗更低、更可控**，但前提是供应商靠谱、冷链和验收到位。鲜果切配看起来原料便宜，实际损耗点更多。下面按“损耗组成”帮你判断。

## 1. 鲜果切配的损耗点

鲜果菠萝从到店到能用，通常会有这些损耗：

- **去皮、去眼、去芯损耗**：菠萝可食率一般约 50%～65%，品种、成熟度、刀工不同差异很大。
- **切配边角料**：切丁大小不统一、修边会产生额外损耗。
- **成熟度不稳定**：太生酸、太熟软，不适合出品，可能整批报废。
- **存放损耗**：切开后氧化、出水、发酸、变质，尤其是夏天。
- **人工和时间成本**：切配耗时，员工操作不标准会放大损耗。
- **食品安全风险**：手部、刀具、砧板、容器不洁会导致变质或客诉。

所以鲜果切配的“真实成本”不是菠萝单价，而是：

> 采购价 ÷ 可食率 + 人工 + 切配损耗 + 冷藏损耗 + 报废风险

如果可食率只有 55%，那 10 斤鲜果实际只能用 5.5 斤，相当于原料成本直接翻倍。

## 2. 成品果丁的损耗点

成品果丁的主要损耗是：

- **到货重量不足**：带汁、冰衣、包装液可能占重。
- **品质不稳定**：软烂、发酵、异味、大小不达标。
- **解冻/开封后损耗**：出水、氧化、变质。
- **供应商不可靠**：以次充好、掺假、冷链断链。
- **单价更高**：这是成品果丁最明显的劣势。

但它的优点是：

- 开袋即用，**人工少**
- 切配损耗由供应商承担
- 规格统一，**出品稳定**
- 库存管理简单，按需解冻
- 食品安全责任部分转移给供应商

## 3. 怎么判断哪个更适合你

可以按这个标准判断：

| 情况 | 更建议 |
|---|---|
| 日均用量大、员工充足、有冷藏切配间 | 鲜果切配可能更省 |
| 日均用量小、人工紧、夏天高温 | 成品果丁更稳 |
| 对果丁大小、成熟度要求高 | 成品果丁更稳 |
| 有稳定可靠供应商、冷链好 | 成品果丁损耗低 |
| 只算原料单价、不算人工 | 鲜果看起来便宜 |
| 算总成本、算报废和人工 | 成品常更低 |

## 4. 实操建议

你可以做一个 **3 天对比测试**：

1. 买同规格鲜果和成品果丁各一批。
2. 记录：
   - 采购重量
   - 实际可用重量
   - 切配时间
   - 报废重量
   - 出品份数
   - 客诉/退货
3. 算出“每份甜品可用果丁成本”。

公式：

> 每份成本 =（采购成本 + 人工成本 + 报废成本）÷ 实际出品份数

如果鲜果切配的每份成本没有明显低于成品果丁 15%～20% 以上，通常不值得自己做，因为还要承担人工、食品安全和品质波动风险。

## 结论

- **只看损耗率**：成品果丁通常更低，因为切配损耗在工厂端已被规模化处理。
- **只看原料单价**：鲜果更便宜。
- **看总成本和稳定性**：大多数甜品店，尤其是中小店、用量不稳定或人工紧张的店，**直接买成品果丁更划算、损耗更可控**。
- **如果你日均用量很大、人工便宜、切配标准成熟**，鲜果切配可能更省，但必须把可食率和报废算进去。

简单说：**鲜果省单价，成品省总账。**
