**出汁率更重要，但前提是甜度不能低到需要大量补糖。**

原因是茶饮店用菠萝，核心成本不只是“甜”，而是**每杯能稳定出多少可用果汁/果肉，以及风味是否稳定**。可以这样判断：

1. **出汁率优先**
   - 出汁率低，等于同样重量原料做出的杯数少，损耗、人工、冷链、仓储成本都会被放大。
   - 茶饮店最怕的是“买回来一半是渣/芯/皮”，实际可用部分少。

2. **甜度不能单独看**
   - 甜度高但出汁率低，可能只是浓缩感强或成熟度高，实际每公斤出汁少，不一定划算。
   - 甜度低但出汁率高，可以通过糖浆、果酱、调味补甜；但如果酸涩、香气差，补也补不回来。

3. **更合理的采购标准**
   - 先定用途：
     - 做**鲜果茶、果肉型产品**：看出汁率 + 果肉率 + 香气。
     - 做**果汁、果酱基底**：看出汁率 + 糖酸比 + 风味稳定性。
   - 再算出“每公斤原料能出多少杯/多少毫升果汁”，而不是只问甜不甜。
   - 甜度建议用**糖度计测 Brix**，结合酸度一起判断；单独高甜可能腻，单独高酸可能需大量糖压酸。

4. **简单决策规则**
   - 如果两款原料价格接近：选**出汁率高、糖酸比合适、香气正常**的。
   - 如果甜度低但出汁率高、风味干净：可接受，靠配方补甜。
   - 如果甜度高但出汁率低、渣多、香气弱：不建议，除非做少量高端鲜果装饰。

结论：**出汁率是硬指标，甜度是配方可调指标；优先保证出汁率和风味干净，再要求甜度达到可接受范围。**
