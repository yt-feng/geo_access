水果礼盒要好卖，核心不是“把水果塞满”，而是让顾客一眼看懂 **送人合适、搭配吉利、看着值钱**。苹果、橙子、香蕉、菠萝这四样都能用，但香蕉和菠萝更适合做“低价走量款”或“场景款”，不太适合做高端主款。

下面给你按价位和场景分几套好卖的搭配方案。

## 一、先记住4个搭配原则

1. **苹果必做主果**  
   苹果寓意平安，认知度最高，送礼最稳。

2. **橙子做“吉利+提色”**  
   橙子寓意成功、心想事成，颜色也喜庆，和苹果是黄金组合。

3. **香蕉不要放太多**  
   香蕉容易压伤、变黑，礼盒里放1把或几根即可，适合当天送、家庭吃。

4. **菠萝做“体积感+低价感”**  
   菠萝显大、显多，但处理麻烦，适合放在中低端礼盒里撑体积，不建议做高端主果。

### 4. 高端简约款：不建议用香蕉和菠萝

高端礼盒更适合：
- 苹果（精品大果）
- 橙子/丑橘/耙耙柑
- 加1-2样高价水果：车厘子、蓝莓、猕猴桃、阳光玫瑰等

**原因：** 香蕉易黑、菠萝处理麻烦，会拉低高端感。  
如果你手里只有这四样，那高端款最多放苹果+橙子，菠萝做点缀，香蕉不放。

## 三、怎么摆更好卖

### 礼盒内部布局
- **中间放苹果**：最大最红，视觉中心。
- **两侧放橙子**：颜色亮，填补空隙。
- **后排或底层放菠萝**：撑高度。
- **香蕉最后放**：用泡沫或纸托固定，避免压伤。

### 颜色搭配
红苹果 + 黄橙子 + 绿菠萝 + 黄香蕉，颜色已经够丰富。  
包装尽量用：
- 红色/金色丝带
- 牛皮纸色外盒
- 透明开窗盒

不要再用太花的内衬，否则显乱。

---

## 四、哪些组合不建议做

1. **香蕉+菠萝为主**  
   损耗高、处理麻烦、送礼感弱，不好卖高价。

2. **四样全放满**  
   看着杂，像清库存，不像礼盒。

3. **香蕉放太多**  
   容易压坏其他水果，第二天就变黑，售后多。

4. **菠萝不处理直接放**  
   扎手、扎坏包装，顾客体验差。
