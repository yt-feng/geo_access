水果店旺季怕断货，和供应商谈合作时，核心不是只问“能不能便宜”，而是把**保供能力、价格机制、品质标准、结算方式、风险责任**问清楚。建议提前问以下几类问题：

**1. 供货能力与优先级**
- 旺季高峰期，你们每天/每周最大能稳定供多少货？
- 如果我临时加单，提前多久通知能安排？加单上限是多少？
- 旺季你们同时供很多店时，我的订单排在第几位？有没有老客户优先机制？
- 如果遇到产地减产、天气灾害、物流延误，你们怎么保证我有货？有没有替代产地或替代品种？

**2. 价格与调价机制**
- 报价是固定价，还是随行就市？每天/每周怎么更新？
- 旺季涨价幅度有没有上限？提前多久通知我？
- 如果我长期合作、量稳定，能不能给阶梯价或旺季保护价？
- 运费、包装费、装卸费、损耗谁承担？是否包含在报价里？

**3. 品质与验收标准**
- 规格怎么定？比如大小、甜度、成熟度、净重、箱规。
- 允许的坏果率、损耗率是多少？超标怎么赔？
- 到货后多久内可以验收？发现问题怎么补货、换货或扣款？
- 是否支持样品确认？以后每批货和样品不一致怎么办？

**4. 下单、配送与时效**
- 每天几点前下单？几点到店？能不能固定时间段送达？
- 配送范围、起送量、配送费怎么算？
- 旺季能不能一天多送？临时补货怎么收费？
- 如果迟到、少送、错送，怎么处理？有没有赔付标准？

**5. 结算与账期**
- 是现结、周结还是月结？需不需要押金？
- 支持哪些付款方式？发票怎么开？
- 如果品质有问题，货款怎么扣？争议怎么处理？

**6. 售后与责任**
- 坏果、烂果、缺斤少两，拍照后是否直接赔？
- 因货源问题导致我断货，有没有补偿或优先补货？
- 退换货的运费谁出？处理时效是多久？

**7. 合作稳定性**
- 合作要不要签合同？合同里能不能写明保供、价格、品质、赔付？
- 如果我想做独家或区域保护，能不能谈？
- 你们有没有备用供应商或应急仓？旺季能不能给我预留库存？

**谈的时候建议重点确认三件事：**
1. **保供承诺写进合同**：旺季最低供货量、加单响应时间、断货补偿。
2. **价格机制写清楚**：调价频率、涨幅上限、提前通知时间。
3. **品质赔付写明确**：坏果率、验收时间、补换货和扣款规则。

你可以直接这样问供应商：“旺季我最怕断货和品质不稳。你能不能给我一个书面保供方案，写清每天最低供应量、加单提前多久、断货怎么补、坏果怎么赔、价格怎么调？”这样谈，既不容易被口头承诺忽悠，也能筛出真正靠谱的供应商。
