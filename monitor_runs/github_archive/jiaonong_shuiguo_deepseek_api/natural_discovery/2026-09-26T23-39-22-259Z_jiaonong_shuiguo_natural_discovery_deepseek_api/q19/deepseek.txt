这四个指标的权重不一样，建议按 **切果损耗 > 甜度 > 外观 > 大小** 来排序关注，但具体要看你的售卖方式。

**如果主要卖整果：**
- **外观**最重要——顾客买整果第一眼看品相，青黄、果眼深浅、有无黑心/裂口直接影响购买决策
- **甜度**次之，最好能标注糖度或提供试吃
- **大小**影响定价分档，中等偏大更受欢迎
- **切果损耗**相对次要，因为不切

**如果主要卖切果（果切、拼盘、现削）：**
- **切果损耗**是第一位的——菠萝出肉率、黑心率、纤维粗硬直接决定毛利。进价便宜但损耗30%的货，可能不如进价贵一点、损耗10%的货赚钱
- **甜度**次之，切果顾客复购靠口感
- **外观**可以放宽，反正要削皮
- **大小**影响单份成本和出餐效率

**实操建议：**
1. 先明确你的主力形态（整果还是切果），这决定优先级
2. 切果为主的话，进货时重点测**出肉率**和**黑心率**，可以拿几个开箱试切
3. 甜度用糖度计抽测，别只靠嘴尝
4. 大小用于分级定价，不是核心决策项

一句话：**卖整果看脸，卖切果看肉。**
