水果店采购菠萝，核心原则是：**不要按“当下最好吃”的标准采购，而要按“到店后还能卖几天”的标准采购**。菠萝是后熟型水果，采购熟度要略低于即食熟度。

**一、判断菠萝熟度的可执行方法**

1. **看果皮颜色**
   - 全青：太生，适合远距离运输或计划放5～7天再卖。
   - 青黄相间、基部开始转黄：比较适合采购，通常到店后2～4天进入最佳售卖期。
   - 半黄以上：适合1～2天内卖完，不适合长途或大量囤货。
   - 全黄、发橙：已经偏熟，损耗风险高，只适合当天促销。

2. **看果眼**
   - 果眼扁平、间隙大：通常成熟度较高。
   - 果眼凸起、紧密、尖锐：偏生。
   - 果眼周围开始变浅、变平，是转熟信号。

3. **闻气味**
   - 无味或青草味：偏生。
   - 基部有淡淡菠萝香：适合采购。
   - 整果香气浓、甚至发甜发酵味：已熟或过熟，损耗快。

4. **按压基部**
   - 硬：偏生。
   - 轻微有弹性：较合适。
   - 明显软、陷：过熟，容易烂心。

5. **看叶片和基部**
   - 叶片翠绿、挺立：较新鲜。
   - 叶片枯黄、基部发黑或渗汁：不新鲜，损耗高。
   - 基部有霉点、软腐：不要采。

6. **掂重量**
   - 同样大小，偏重的水分足、果肉好。
   - 太轻可能失水或熟过头。

**二、按销售计划选熟度**

- **计划3天内卖完**：可采青黄相间、基部微香、按压略弹的果。
- **计划5～7天卖完**：采果皮偏青、无香或极淡香、基部硬的果，到店后自然转熟。
- **做促销或切果盒**：可采半黄以上、香气明显的果，但当天必须处理。
- **长途运输**：采青果，但不要太青，否则后熟不均、口感差。

**三、降低损耗的采购建议**

1. **分批采购，不要一次全采同一熟度。**
   例如：70%采青黄相间，20%采偏青，10%采半黄，保证每天都有可卖果。

2. **按销量倒推采购量。**
   如果日均卖30个，3天周期，安全库存约90个，但高温天要下调。

3. **要求供应商分级。**
   把“即卖果”和“后熟果”分开，避免熟果压仓。

4. **到店后按熟度分区。**
   熟果放前排、阴凉处，尽快卖；生果放通风处，促进后熟。

5. **高温高湿季节提高采购生度。**
   夏天菠萝后熟快，采购熟度要比冬天低一档。

6. **避免整批同一来源、同一熟度。**
   不同批次混采，能分散损耗风险。

**四、简单判断口诀**

**“青黄相间、基部微香、按压略弹、果眼变平”**——比较适合水果店采购。  
**“全青太生，全黄太熟，发软发香快处理。”**
