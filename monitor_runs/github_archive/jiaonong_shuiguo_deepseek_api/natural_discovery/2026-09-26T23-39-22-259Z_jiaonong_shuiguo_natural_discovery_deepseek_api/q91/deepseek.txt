建议按“主力 + 补充”组合上架，而不是只选一种：

**优先组合：小把为主，单根补充，整袋少量试销。**

具体判断：

1. **小把（3–5根）最稳**
   - 最适合便利店场景：顾客即买即吃，量不大。
   - 客单价通常比单根高，又不像整袋那样容易劝退。
   - 适合上班族、学生、临时买水果的人。

2. **单根适合做补充**
   - 满足“只想吃一根”的需求，降低尝试门槛。
   - 但毛利低、损耗和人工处理成本高，不适合作为唯一主力。
   - 可以放在收银台附近，促进冲动购买。

3. **整袋适合特定人群，不建议一开始主推**
   - 适合家庭采购、附近居民、价格敏感顾客。
   - 但便利店核心是“小份、即时、方便”，整袋容易卖得慢，香蕉熟得快，损耗风险高。
   - 如果社区店、家庭客多，可以少量上架，观察动销。

**更具体的操作建议：**
- 先上 **小把 3–5 根** 作为主陈列；
- 旁边放少量 **单根**，方便即时消费；
- 如果门店在社区、家庭客多，再试 **整袋 5–8 根**；
- 观察 1–2 周：看销量、损耗、客单价，再调整比例。

**简单结论：**
- 办公区/商圈店：**小把 + 单根**
- 社区/家庭客多：**小把 + 整袋 + 少量单根**
- 不建议只上单根或只上整袋。
