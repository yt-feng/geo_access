很重要，而且往往比“进货价便宜一点”更关键。便利店卖水果的核心矛盾不是毛利，而是**损耗和周转**。

**为什么小批量试卖重要：**

1. **水果损耗高且不可逆**
   水果保质期短，卖不掉基本就是报损。销量不稳定时，一次进多了，损耗会直接吃掉利润。小批量试卖能把“猜错”的成本控制住。

2. **单店销量差异大**
   同一个品牌，不同位置（写字楼、社区、学校、地铁口）的水果动销完全不同。供应商愿不愿意小批量、多频次供货，决定了你能不能按店测试，而不是一次性压货。

3. **测试成本低，决策更快**
   小批量试卖几款单品（比如香蕉、苹果、小番茄、切果），一两周就能看出哪些好卖、哪些滞销、什么价位能接受。没有这个支持，你只能靠经验赌，试错代价高。

4. **资金和货架都有限**
   便利店货架和冷柜空间小，资金也有限。小批量能让你把有限资源放在真正动销的品上，避免被滞销品占坑。

**判断供应商是否值得合作，可以看这几点：**

- 是否支持小批量、多频次补货（比如每周2–3次）
- 起订量是否低，能不能按单品而不是整箱搭配
- 能否接受滞销品调换、退货或换货
- 配送是否稳定、准时，缺货补货快不快
- 是否提供分级、包装、预冷等降低损耗的服务

**结论：**
如果供应商只愿意大批量压货，价格再低也要谨慎，因为销量不稳定时，损耗和资金占用很可能把价格优势抹平。反过来，能支持小批量试卖、快速补货和退换的供应商，即使单价略高，实际综合成本往往更低，也更适合便利店这种小业态。
