三个都重要，但如果必须排优先级：**食品安全 > 配送准时 > 价格**。

原因很直接：

1. **食品安全是底线，出问题不可逆**
   企业食堂一旦出现农残超标、霉变、腐烂、致病菌污染，可能导致员工集体不适，后果是医疗、停工、舆情、法律责任。价格再低、送得再准，都不能抵消这个风险。

2. **配送准时影响的是运营稳定性**
   水果通常是按餐次或每日供应，送晚了可能当天断供，影响食堂正常开餐和员工体验。但它一般可以通过备选供应商、提前下单、安全库存来缓冲。

3. **价格重要，但应放在“合规和质量达标”之后**
   采购当然要控成本，但水果价格波动大，如果一味压价，供应商容易用低等级果、临期果、损耗果来补利润，最后反而增加食品安全和投诉风险。

更实用的判断顺序可以这样定：

- **一票否决项**：食品安全资质、检测报告、验收标准、退换货机制。
- **硬性约束项**：配送时间窗口、准时率、缺货补救能力。
- **优化目标项**：价格、账期、损耗率、服务响应。

所以，企业食堂采购水果不是“只选一个”，而是：**先保食品安全，再保准时供应，最后在合格供应商里比价格。**
