卖香蕉最容易踩的坑是：**把香蕉当成普通果蔬来配送**。香蕉在配送途中压坏和变黑，本质是两个不同问题——**机械损伤**和**后熟/冷害**，要分开控制。

## 一、先搞清变黑的三种原因

| 类型 | 表现 | 主因 |
|---|---|---|
| 压伤黑 | 局部凹陷、发黑 | 堆叠挤压、碰撞 |
| 后熟黑 | 整体快速变黄变黑 | 温度高、乙烯积累 |
| 冷害黑 | 表皮发暗、黑斑 | 低于12℃存放 |

所以控制方案要对症下药，不是单纯"包厚一点"。

## 二、采购端：从源头决定损耗率

1. **按配送时效选成熟度**
   - 次日达/隔日达：选**青果或微黄**（7~8成熟），到货刚好可食
   - 即时配（1~3小时）：可选**已转黄**（9成熟）
   - 千万别用全熟果做长途配送，必黑

2. **要求供应商做去乙烯处理**，减少运输途中自我催熟。

3. **整串带轴运输**比单根更抗压，到仓再分切。

## 三、包装端：防压是核心

1. **单根或小把独立卡位**
   - 用带凹槽的纸浆托/珍珠棉托，让每根香蕉"悬空固定"，不互相压
   - 避免整把平堆

2. **加缓冲但别闷**
   - 底部和四周用珍珠棉或气泡膜，**顶部留透气**
   - 不要用完全密封的塑料袋，会积乙烯+水汽，加速变黑

3. **外箱抗压**
   - 选五层瓦楞，箱内**限高**（香蕉最多2~3层）
   - 箱体标注"勿压、向上"，但别只靠标识

4. **悬挂或立放优先**，平放时确保不叠太重。

## 四、配送端：控温和控时

1. **温度控制在13~15℃**
   - 高于20℃：快速后熟
   - 低于12℃：冷害发黑
   - 夏天用**冷藏但非冷冻**车，冬天注意防冻

2. **缩短在途时间**，香蕉对时间极敏感，能次日达就别拖到第三天。

3. **避免暴晒和后备箱高温**，最后一公里最容易翻车。

4. **与乙烯敏感/释放型商品分开**（如别和苹果、猕猴桃混装）。

## 五、可落地的执行清单

- [ ] 采购按配送时效定成熟度，长途只用7~8成熟
- [ ] 独立卡位+缓冲，顶部透气不密封
- [ ] 限高2~3层，五层抗压箱
- [ ] 全程13~15℃，冷链车+保温箱
- [ ] 承诺时效≤48小时
- [ ] 到货后引导用户"挂起来、别放冰箱冷藏室"

## 六、最容易被忽略的一点

**别把香蕉放进家用冰箱冷藏室**。很多"变黑"投诉其实是用户收货后自己放冰箱造成的冷害。在包裹里放一张提示卡，能显著降低这类差评。
