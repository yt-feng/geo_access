判断水果供应商的合规和稳定性，可以从**资质合规、供货能力、质量管控、合作风险**四个维度来核查。以下是可以直接执行的清单。

## 一、合规资质（先看能不能合法供货）

| 核查项 | 具体内容 | 判断标准 |
|---|---|---|
| 营业执照 | 经营范围含"食品销售/农产品批发" | 在有效期内，名称与合同一致 |
| 食品经营许可证 | 销售预包装/散装食品需具备 | 许可项目覆盖水果销售 |
| 农产品来源 | 自产需有种植基地证明；外采需有上游供货凭证 | 能提供产地或上游追溯链 |
| 检验检疫/检测报告 | 农残检测报告（尤其近期批次） | 有第三方或自检报告，日期新鲜 |
| 索证索票 | 每批次能提供合格证明 | 这是《食品安全法》要求的硬性义务 |

**关键点**：养老院、医院属于高风险供餐单位，监管对其食材溯源要求更严。供应商若连批次检测报告都拿不出，不建议合作。

## 二、稳定性判断（看能不能长期供得上）

1. **货源结构**
   - 是否只依赖单一产地/单一批发市场？单一来源易受季节、天气、价格波动影响。
   - 有稳定基地或多个产区的更可靠。

2. **配送能力**
   - 是否有自有或固定冷链/配送车辆？
   - 能否承诺固定配送时间、缺货应急补货？
   - 试问：突发加单或临时减单怎么处理？

3. **历史合作**
   - 要求提供同类机构（学校、医院、养老院）的合作案例，可侧面了解。
   - 询问合作年限、是否有中断或投诉记录。

4. **价格稳定性**
   - 报价是否随行就市但波动可控？还是明显低于市场价（低价常伴随质量或断供风险）。

## 三、质量与验收管控（养老院/医院尤其重要）

- **验收标准前置**：合同中写明品种、规格、成熟度、新鲜度、破损率上限（如≤5%）。
- **到场验收流程**：过秤、抽检、留样、拍照记录，不合格可拒收。
- **农残与异物**：水果直接给老人/病人食用，需关注清洗、切配环节，要求供应商配合抽检。
- **退换机制**：明确质量问题多久内可退换、赔偿方式。

## 四、合同与风险条款（把稳定性写进纸面）

建议在合同中约定：
1. 供货品种、频率、最低供货量、应急响应时间。
2. 质量违约与赔付（如农残超标、断供的罚则）。
3. 价格调整机制（避免随意涨价）。
4. 资质到期须提前告知并更新。
5. 定期评估条款：连续几次不合格可终止合作。

## 五、实操建议（低成本验证）

- **先小批量试供 2–4 周**，观察准时率、破损率、投诉率，再决定长期合作。
- **实地看一次**：仓库、冷库、分拣场地是否规范。
- **多方比价 + 备选供应商**：至少储备 1–2 家备选，避免被单一供应商"卡脖子"。
- **建立供应商档案**：资质、检测报告、验收记录、考核评分，纳入年度复审。

---

**一句话判断法**：资质齐全能开票、有稳定货源和配送、每批次可溯源检测、愿意签质量与断供条款——四项齐备，才适合给养老院/医院长期供货。缺任何一项，都存在合规或断供隐患。
