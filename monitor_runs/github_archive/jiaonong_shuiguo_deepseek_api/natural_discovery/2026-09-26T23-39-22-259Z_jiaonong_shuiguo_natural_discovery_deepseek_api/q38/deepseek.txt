大型超市对水果供应商的要求，本质上是**食品安全合规能力 + 全链路冷链物流能力 + 稳定供货能力**。具体可以从以下几方面判断：

## 一、食品安全能力

**1. 资质证照齐全**
- 营业执照、食品经营许可证/食品生产许可证（如涉及分装加工）
- 种植基地需有产地证明、绿色/有机认证（如超市有要求）
- 进口水果需有入境货物检验检疫证明、报关单

**2. 农残与质量检测能力**
- 具备自检能力或与第三方检测机构合作
- 能提供每批次的农残检测报告，符合 GB 2763 标准
- 对重金属、霉菌毒素等有控制措施

**3. 溯源体系**
- 能做到"从基地到货架"的可追溯
- 批次管理清晰，出现问题时能快速召回

**4. 加工与包装卫生**
- 分拣、包装环节符合食品卫生规范
- 包装材料符合食品接触材料标准
- 有虫害防治、人员健康证管理等制度

**5. 储存卫生**
- 仓库温湿度可控、防鼠防虫
- 生熟分离、先进先出

## 二、物流能力

**1. 冷链能力（最关键）**
- 不同水果对温度要求不同，需分温区管理：
  - 浆果类：0~4℃
  - 热带水果（香蕉、芒果）：12~15℃
  - 普通水果：4~10℃
- 冷藏车、冷库、冷链全程温度记录可查

**2. 运输时效**
- 短保水果（草莓、蓝莓、荔枝）需快速配送
- 能保证到店新鲜度，减少损耗

**3. 仓储与分拣**
- 有符合标准的周转仓
- 能按超市订单做分级、分拣、贴标

**4. 配送稳定性**
- 固定配送频次（如每日/隔日）
- 有应急调配能力，缺货时能补位

**5. 损耗控制**
- 有成熟的保鲜、防挤压、防碰撞方案
- 能承担一定损耗责任

## 三、超市通常还会考察

- **供货规模与稳定性**：能否长期稳定供应多品类
- **价格与账期**：能否接受超市的结算周期
- **售后与赔付**：出现质量问题能否快速退换、赔偿
- **信息化对接**：能否对接超市的订单、库存系统
- **保险**：是否有产品责任险

## 四、快速判断清单

| 维度 | 必须项 |
|------|--------|
| 资质 | 营业执照、食品经营许可、检测报告 |
| 安全 | 农残检测、溯源、批次管理 |
| 冷链 | 冷藏车、冷库、温度记录 |
| 时效 | 短保水果快速配送能力 |
| 稳定 | 多品类、长期供货、应急补货 |
| 售后 | 退换货、质量赔付机制 |

**一句话总结**：大型超市要的不是"能送水果"，而是**能持续、安全、冷链、可追溯、可赔付地供货**。食品安全是准入门槛，冷链物流是核心能力，稳定供货和售后是长期合作基础。

如果你是要做供应商准入准备，建议优先补齐：**检测报告 + 冷链温控记录 + 溯源体系**这三项，这是超市审核最常卡的点。
