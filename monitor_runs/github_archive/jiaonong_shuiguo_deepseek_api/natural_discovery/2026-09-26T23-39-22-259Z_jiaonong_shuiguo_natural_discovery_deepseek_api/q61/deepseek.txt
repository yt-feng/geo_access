判断批发档口能不能稳定供货，核心看“货、人、履约”三条线，别只看价格和口头承诺。

**1. 先看货的底层逻辑**
- 问清香蕉来源：是海南、云南、广西、老挝、缅甸还是菲律宾、越南、厄瓜多尔等进口货，不同产区上市季不同，单一产区很难全年稳定。
- 稳定供货商通常能说清：当前主产区、下个产区、过渡期怎么补货。
- 问等级和加工：条蕉、梳蕉、散把，几成熟发车，是否催熟，催熟几天到店，损耗大概多少。
- 看加工场地：有没有冷库、催熟房、分拣线、装车棚。没有固定场地的“一手货源”多半是倒手。

**2. 看履约能力**
- 要求看最近连续出货记录，比如装车视频、磅单、物流单、收款记录，不要只看一张货场照片。
- 问日供应量：日发几车、每车多少件、旺季能不能加量、下雨或封关时怎么处理。
- 问装车时效：下单后多久能装，能不能固定时间发车，延误怎么赔。
- 小额试单：先做1-2车小单，看数量、成熟度、青黄比例、坏果率、到货时间是否和承诺一致。

**3. 看资金和风险承担**
- 稳定供货商通常敢做“到货验收后结部分款”或“定金+尾款”，但不会长期让你纯赊账。
- 如果对方要求全款先打、拒绝视频看货、拒绝小单试货，风险很高。
- 问清楚烂果、短件、催熟不齐、运输冻伤怎么赔，最好写进微信文字或合同。

**4. 实地或视频核验**
- 最好去产地或档口实地看：冷库、催熟房、工人、装车现场、正在发的货。
- 去不了就视频连线，要求现场走一圈，看货堆、看车牌、看工人装箱，不接受提前录好的视频。
- 查对方营业执照、身份证、收款账户是否一致，别打给无关第三方。

**5. 几个危险信号**
- 价格明显低于市场，还说“常年大量一手”。
- 朋友圈全是网图，没有连续装车视频。
- 今天说海南，明天说老挝，后天说越南，但拿不出产地证明和物流单。
- 催你打全款，说“晚了就没货”。
- 出问题后只换人不赔钱，或者一直拖。

**实操建议：**
先小单试2-3次，固定同一规格和路线；每次记录到货时间、坏果率、实际成本；连续3次稳定后再谈账期和长期价。真正稳定的供货，不是他说自己稳，而是你能连续拿到同样品质、同样时间、同样数量的货。
