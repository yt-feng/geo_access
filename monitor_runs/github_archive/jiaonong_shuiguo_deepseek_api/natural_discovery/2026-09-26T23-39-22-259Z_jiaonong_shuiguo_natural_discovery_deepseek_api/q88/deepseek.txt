做线上水果，坏果和口感不稳定是两件事，要分开治：**坏果靠采购标准和品控流程控制，口感靠品种选择、成熟度管理和批次筛选控制。**

下面给你一套可执行的做法。

## 一、采购前：先定标准，再找货

很多坏果问题不是采购没选好，而是一开始没有写清楚标准。

**要明确写进采购要求的：**
- **品种 + 产地 + 规格**：比如“海南妃子笑，单果18-22g，果径2.8cm以上”
- **成熟度**：线上发货通常要**7-8成熟**，太熟路上必坏，太生口感差
- **糖度下限**：比如柑橘≥11°Brix，芒果≥14°Brix，写进合同
- **瑕疵容忍度**：虫眼、裂口、软斑、日灼、机械伤的比例上限
- **大小均匀度**：同一批货果径差异不超过多少
- **采摘时间**：雨后不能立刻采，带露水不能采，高温时段最好不采

标准越具体，后面扯皮越少。

## 二、选供应商：看这几点，不看嘴

**优先选：**
- 有分选线、冷库、预冷能力的基地或合作社
- 能稳定供同一个品种、同一片产区的
- 愿意让你抽检、愿意做批次记录的
- 发货前能提供糖度、大小、成熟度数据的

**尽量避开：**
- 只靠“今天货好”但没有稳定分选能力的
- 多家小农户拼货、来源混杂的
- 价格明显低于市场、但说不出品控流程的

**关键动作：**
- 先小批量试单，不要一上来压大货
- 试单要覆盖不同天气、不同采摘批次
- 记录每批次的坏果率、糖度、客户差评关键词

## 三、采购中：把品控做在发货前

线上水果最大的坑是“采购时看着好，到客户手里坏了”。所以要把控制点前移。

**1. 预冷**
叶菜、浆果、荔枝、樱桃这类，采后尽快预冷，能显著降低腐烂率。没有预冷的货，夏天坏果率会明显上升。

**2. 分选**
至少做三道：
- 去烂果、虫果、裂果
- 按大小分级
- 按成熟度分级

**3. 抽检**
每批次抽检，不要只看表面：
- 随机开箱，查底层
- 测糖度、测硬度
- 记录坏果率，超过阈值就拒收或降级

**4. 包装**
- 易损果用果托、网套、隔板
- 不要过度堆叠
- 夏天加冰袋、保温袋，但要注意冷凝水导致霉变
- 箱内留通风，不要全密封闷坏

**5. 批次管理**
同一批货绑定同一个批次号，出了问题能追溯到产地、采摘时间、分选记录。没有批次管理，差评来了你都不知道是哪批货。

## 四、口感不稳定：核心是成熟度和品种

口感差评通常来自：
- 太生，酸、硬、没味
- 太熟，软、烂、发酒味
- 批次之间差异大
- 品种本身不稳定

**解决办法：**
- **固定品种和产区**：不要这周A地，下周B地，口感一定飘
- **按成熟度采收**：不同品类要求不同，但要有明确成熟度指标，比如颜色、硬度、糖度、采摘天数
- **发货前试吃**：每批次自己试吃，不要只测糖度
- **按运输时间调整成熟度**：近途可以稍熟，远途要稍生，但不能牺牲基本口感
- **分等级销售**：大果、中果、小果分开卖，不要混装导致体验不一致

## 五、售后和评价管理：减少差评的实际动作

- **详情页写清楚**：品种特点、口感可能偏酸/偏甜、成熟度、保存方式
- **发货后主动提醒**：怎么催熟、怎么保存、多久内吃
- **坏果包赔要快**：让客户拍照即赔，不要反复扯皮
- **差评关键词监控**：比如“烂了”“酸”“没味”“太小”，按批次倒查
- **问题批次立刻停发**：不要抱着“这批应该没事”的心态继续发

## 六、最实用的一张检查表

采购时至少确认：

1. 品种、产地、规格是否明确？
2. 成熟度是否适合线上运输？
3. 糖度、硬度是否有数据？
4. 是否预冷？
5. 是否分选？
6. 坏果率抽检多少？
7. 包装是否防挤压、防闷热？
8. 是否有批次记录？
9. 试单评价如何？
10. 出问题能否追溯到具体批次？

**一句话总结：**
坏果靠“预冷 + 分选 + 包装 + 批次追溯”压下去，口感靠“固定品种产区 + 成熟度标准 + 每批试吃”稳下来。线上水果不是找最好的货，而是找**最稳定、最可控、最适合运输**的货。
