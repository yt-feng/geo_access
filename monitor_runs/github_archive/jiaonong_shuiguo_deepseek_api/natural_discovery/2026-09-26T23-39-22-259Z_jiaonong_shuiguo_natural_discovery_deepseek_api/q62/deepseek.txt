判断一批香蕉，核心看“成熟阶段 + 有没有潜伏的坏果 + 运输/储存条件”。批发场景下不能只看表皮黄不黄，要结合硬度、果柄、棱角、气味和箱内温度。

**一、先判断熟度处在哪个阶段**

1. **全青、硬、棱角明显**
   - 还没后熟，适合长途运输或需要自己催熟。
   - 风险：如果采得太生，催熟后容易“青硬不软”或口感差。

2. **青黄转色，果身仍硬**
   - 常见批发状态。适合再放几天销售。
   - 看转色是否均匀，若只有局部黄、其他还青，可能成熟不均。

3. **黄熟，果身微软，棱角变圆**
   - 可直接零售，但货架期短。
   - 适合快进快出，不适合再压货。

4. **全黄、果柄发黑、果身软**
   - 已接近或进入过熟。
   - 坏果风险快速上升，批发拿货要压价或只拿短途快销。

5. **出现黑斑、酒味、酸味**
   - 已过熟或开始腐烂，不建议拿。

**二、判断坏果风险的实操方法**

1. **摸果身和果柄**
   - 果身均匀微软正常；局部软陷、出水、发黏，说明内部可能已烂。
   - 果柄发黑、发霉、一碰就掉，说明存放久或受潮。

2. **看棱角和果指**
   - 棱角越明显越生；棱角变圆越熟。
   - 果指饱满、排列紧实较好；干瘪、脱把、断指多，损耗高。

3. **看表皮**
   - 少量芝麻斑可能是正常后熟。
   - 大片黑斑、凹陷斑、霉斑，尤其连成片，坏果风险高。
   - 表皮有擦伤、压伤、水渍，后续容易从伤处烂。

4. **闻气味**
   - 正常是清淡果香。
   - 有酒味、酸味、发酵味，说明箱内已开始腐烂或过热。

5. **查箱内温度和中心果**
   - 手伸进箱中间或摸底层果，如果明显发热，坏果风险高。
   - 香蕉对低温敏感，低于约12℃容易冷害；但批发现场更常见的是堆压发热、闷坏。
   - 箱内有水汽、滴水、纸箱软塌，说明湿度大或已出汁，风险高。

6. **抽箱、抽层、抽果**
   - 不能只看最上面一层。要抽底层、中间层、角落箱。
   - 每箱随机拿几根，重点看果柄、果指连接处、箱底有无汁液。
   - 如果一箱里坏果超过你心理阈值，比如明显软烂、霉变、酒味，整批要重新评估。

**三、给批发商的拿货建议**

- **要催熟后卖**：拿青黄、硬身、棱角尚明显的货，问清采摘时间、运输温度、是否已催熟。
- **要马上卖**：拿黄熟均匀、果身微软、无伤无味的货，但必须快销。
- **要压货**：只拿全青或刚转色、硬身、无冷害、无压伤的货。
- **坏果风险高的信号**：箱内发热、酒味、果柄霉黑、底层出汁、大片黑斑、局部软陷。
- **谈判要点**：要求开箱抽检，约定坏果率；保留样品和照片；问清产地、采摘日期、运输方式、是否冷链、是否催熟。

**四、简单现场口诀**

**看棱角、摸硬度、闻气味、查果柄、翻底层、摸温度。**
青硬可放，黄软快卖，黑斑酒味不要拿，箱热出汁风险大。
