要，但不能只靠“固定产地”这一条，更稳的是 **固定产地 + 固定品种/规格 + 固定供应批次 + 到货验收标准 + 备用货源**。茶饮店的水果风味波动，往往不是单一产地造成的，而是品种、成熟度、季节、运输、储存共同作用的结果。

可以按下面判断和操作：

1. **固定产地有价值，但别迷信产地**
   - 同一产地不同果园、不同采摘期，风味也会差很多。
   - 固定产地能减少大方向波动，但无法保证每批都一样。

2. **比固定产地更重要的是固定“供应批次逻辑”**
   - 要求供应商按相近采摘期、相近成熟度供货。
   - 同一款饮品尽量使用同一品种、同一规格、同一成熟度区间的果。
   - 例如柠檬要固定品种和单果重量区间，芒果要固定品种和成熟度，草莓要固定品种和糖酸比范围。

3. **采购时建议这样做**
   - 主供应基地固定 1 家，备用供应基地固定 1 家。
   - 每批到货做简单验收：糖度、酸度、香气、软硬度、出汁率、颜色。
   - 设定可接受波动范围，超出范围就调整配方、换用途或退换。
   - 对季节性强的水果，提前做替代方案，比如换品种、换配方比例、推限定款。

4. **什么时候必须换产地或批次**
   - 原产地进入雨季、尾季，风味明显下降。
   - 到货糖酸比偏离标准，影响招牌产品稳定性。
   - 供应商无法保证持续稳定供货。
   - 价格暴涨但品质不匹配。

5. **最实用的结论**
   - 招牌饮品：尽量固定产地、品种、批次，并做验收标准。
   - 普通饮品：可以允许产地轮换，但必须按糖酸度和成熟度重新校准配方。
   - 不要只签“固定产地”，要签“品质规格 + 验收标准 + 批次稳定性”。

一句话：**固定产地是手段，固定风味标准才是目的。** 如果只能选一个，优先固定品种、成熟度和验收标准，其次才是固定产地。
