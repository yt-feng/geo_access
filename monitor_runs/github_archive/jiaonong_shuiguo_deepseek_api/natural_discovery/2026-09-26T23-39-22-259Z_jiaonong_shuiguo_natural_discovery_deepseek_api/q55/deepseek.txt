选水果拼盘的规格，核心不是“越大越划算”，而是看**出成率、损耗、摆盘定位和进货价差**。按餐厅常用场景，可以这样判断：

1. **苹果**
   - 优先选**80–85mm中果**，不要盲目追大果。
   - 中果削皮去核后切块稳定，单个出成率通常更稳，摆盘也容易统一。
   - 大果看着气派，但单价高、切块后容易偏大，剩料和氧化损耗反而更明显。
   - 如果是高端拼盘、需要整片苹果扇面，可选85–90mm；普通自助餐用80mm左右更划算。

2. **橙子**
   - 优先选**70–75mm中果**，做切瓣、去皮橙肉都合适。
   - 太小出肉少、切瓣不好看；太大皮厚、白瓤多，人工去皮损耗高。
   - 如果主要是带皮切月牙瓣，75mm左右最稳；如果只取橙肉，选皮薄、手感重的品种比单纯看大小更重要。
   - 进货时按“同样重量下，皮薄、汁多、种子少”优先，不要只按直径。

3. **菠萝**
   - 优先选**1.2–1.5kg/个的中等果**。
   - 这个规格去皮去眼后出肉率较稳定，切块、切条、切片都好操作。
   - 太小果肉少、处理费工；太大容易中间硬芯粗，边角损耗高。
   - 如果拼盘需要菠萝圈或长条，选1.5kg左右；如果只做小方块，1.2–1.3kg更划算。
   - 成熟度选**七八分熟**，太生酸、太熟易烂，都会增加损耗。

4. **最划算的组合思路**
   - 苹果：80–85mm，按个数买，选硬脆品种。
   - 橙子：70–75mm，按重量买，选皮薄重手。
   - 菠萝：1.2–1.5kg，按个数买，选香气足、无软斑。
   - 如果拼盘是自助餐大量出，规格统一比单个大更重要；如果是对外售卖的高颜值拼盘，可以少量用大果做视觉中心。

5. **简单判断标准**
   - 同样预算下，选**出肉率高、切出来大小一致、边角料少**的规格。
   - 不要只看“斤价便宜”，要算**可摆盘部分每斤成本**。
   - 苹果和橙子建议固定一个规格长期采购，减少切配和摆盘波动；菠萝可以按季节和批次调整。

一句话：**苹果80–85mm、橙子70–75mm、菠萝1.2–1.5kg，通常是餐厅水果拼盘最稳、最不容易亏的规格。**
