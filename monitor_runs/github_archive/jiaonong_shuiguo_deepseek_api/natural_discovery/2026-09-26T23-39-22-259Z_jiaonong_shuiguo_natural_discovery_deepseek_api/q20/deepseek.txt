社区超市找每日配送的水果供应商，重点不是“谁价格最低”，而是能不能稳定、按你的节奏把货送到店里。建议按下面几个条件筛选：

1. **配送能力**
   - 是否支持每天配送，几点前能到店。
   - 临时补货、加单、换货能不能当天响应。
   - 配送范围是否覆盖你店位置，起送量多少。
   - 是否自有冷链车或稳定合作物流。

2. **货源稳定性**
   - 是否有固定产地、批发市场档口或一级供应商渠道。
   - 主推水果能不能全年稳定供，淡旺季怎么替代。
   - 是否经常断货、换品种、以次充好。

3. **品质与损耗**
   - 能否按规格分级，比如大小、糖度、成熟度。
   - 坏果、压伤、腐烂的赔付标准是什么。
   - 损耗率大概多少，是否支持拍照售后。
   - 是否适合社区店的小批量、多频次补货。

4. **价格与结算**
   - 报价是否含运费、包装费、分拣费。
   - 价格随行就市时，是否提前通知。
   - 账期、押金、结算方式是否清楚。
   - 能不能先小批量试单，再谈长期合作。

5. **售后与责任**
   - 缺货、迟到、品质不达标怎么处理。
   - 是否承诺坏果包赔、少货补送。
   - 有没有固定对接人，出问题能否快速找到人。
   - 是否愿意签简单供货协议，把配送时间、品控、赔付写清楚。

6. **实际试单验证**
   - 先试 3—7 天，观察到货时间、损耗、售后响应。
   - 对比 2—3 家供应商，不要一上来只签一家。
   - 记录每天到货合格率、缺货次数、临时加单响应速度。
   - 试单稳定后再谈账期和更低价。

简单判断标准：**能每天准时到、坏果有人赔、临时加单能响应、价格透明、试单稳定**，这五点比单纯低价更重要。
