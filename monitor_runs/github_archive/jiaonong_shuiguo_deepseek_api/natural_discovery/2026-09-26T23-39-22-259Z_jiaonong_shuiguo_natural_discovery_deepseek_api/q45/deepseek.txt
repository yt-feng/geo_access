连锁超市和水果供应商签年度合同，最容易踩坑的通常不是价格本身，而是“价格怎么定、货怎么收、损耗谁承担、卖不动怎么办”。重点盯以下几类条款：

**1. 价格与调价机制**
- 只写“随行就市”最危险，容易各说各话。要约定定价基准，比如以某批发市场、某产区报价或双方确认的行情为参考。
- 约定调价周期、触发条件、通知期限。比如“连续3日涨跌超5%可调价，需提前1天书面确认”。
- 防止供应商旺季涨价、淡季不降价。可以设“年度价格框架+月度/周度议价”两层机制。
- 注意“最低供货价”“独家供货价”是否让超市失去比价空间。

**2. 质量标准与验收**
- 水果非标品，最容易扯皮。不要只写“符合国家标准”，要写到品类、等级、单果重、糖度、着色、成熟度、瑕疵率、农残检测要求。
- 明确验收地点、验收时间、抽检比例、不合格判定标准。
- 约定不合格处理：拒收、换货、扣款、降价接收，分别适用什么情形。
- 留样和检测报告要写清楚。生鲜农残、重金属等检测不合格的责任和费用归属要明确。

**3. 损耗与退换货**
- 水果损耗高，必须区分“运输损耗、验收前损耗、验收后损耗、自然损耗”。
- 约定合理损耗率，比如运输环节2%—5%视品类定，超出部分由谁承担。
- 退换货条款要具体：哪些情况可退、几天内退、费用谁出、是否影响账期。
- 警惕“验收后概不负责”或“一切损耗由超市承担”的极端条款。

**4. 供货量与订单**
- 年度合同如果写死总量，但实际销售波动大，容易库存积压或断供。
- 建议写“预估量+滚动订单”，比如每周下单、提前1—2天确认。
- 约定最低起送量、缺货违约责任、不可抗力除外情形。
- 防止供应商“优先供高价渠道”，要写清楚超市订单的优先级和违约后果。

**5. 账期与结算**
- 账期、对账日、开票时间、付款方式要逐项明确。
- 注意“验收合格后60天付款”是否包含对账期，实际可能拖到90天。
- 扣款项目要列明：质量扣款、损耗扣款、促销费用、返利、进场费、条码费等，避免事后随意扣。
- 返利、返点、年度奖励要写清计算基数和结算时间。

**6. 促销与费用分摊**
- 堆头、端架、DM海报、试吃、损耗补贴等费用，谁承担、承担多少、怎么确认，要写进合同。
- 防止供应商口头承诺费用，事后不认。
- 促销降价部分，是超市承担、供应商承担还是按比例分担，要明确。

**7. 独家与竞品限制**
- 如果约定独家供货，要评估是否真有必要。独家容易导致价格失去竞争、断供风险集中。
- 若接受独家，要加“价格不高于同城同类渠道”“断供赔偿”“业绩不达标可解除”等约束。
- 竞品限制过宽，可能影响超市后续引入更优供应商。

**8. 违约与解除**
- 缺货、质量问题、频繁断供、价格欺诈、检测不合格，都要有明确违约责任。
- 违约金建议可计算，比如按未供货金额比例、按质量批次扣款。
- 约定解除条件，比如连续3次质量不合格、月缺货率超10%、严重食安问题。
- 注意“仅赔偿直接损失”是否足够，食安事件可能带来罚款、声誉和客诉损失。

**9. 食品安全与责任**
- 供应商要提供营业执照、食品经营许可证、检测报告、产地证明等。
- 因农残、变质、异物等导致顾客投诉、监管处罚、赔偿，责任和费用由谁承担要写清。
- 要求供应商购买产品责任险，并把超市列为附加被保险人，能显著降低风险。

**10. 不可抗力与政策变化**
- 天气、疫情、运输管制、关税、检疫政策都可能影响水果供应。
- 不可抗力不能滥用。要约定通知义务、证明文件、减损义务和后续处理。
- 政策导致成本大幅变化时，是调价、减量还是解除，要有路径。

**实操建议：**
- 不要签“一揽子年度固定价”，除非品种、等级、数量都非常标准。
- 把《质量标准》《验收细则》《扣款标准》《退换货流程》作为合同附件，比正文更关键。
- 所有口头承诺写进合同或补充协议。
- 先小批量试单1—2个月，再签全年大合同。
- 重点保留验收记录、检测报告、沟通记录，发生纠纷时这些比合同条款更管用。

一句话：水果年度合同的核心不是“锁价”，而是“锁标准、锁责任、锁调整机制”。谁承担损耗、谁决定价格、卖不动怎么办，这三件事写不清，后面一定扯皮。
