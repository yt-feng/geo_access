批发商在合同里写坏果责任，核心不是只写一句“坏果由卖方负责”，而是把**判定标准、责任分界点、举证方式、赔付计算、处理时限**写清楚。建议按下面结构写。

**1. 先定义“坏果”**
不要只写“坏果”，要列明标准，例如：
- 腐烂、发霉、流汁、异味；
- 严重压伤、裂口、破损导致无法销售；
- 病虫害、冻伤、日灼等；
- 规格不符：大小、成熟度、色泽、糖度等不符合约定。
可约定：**以双方确认的验收标准或封样为准**。

**2. 明确责任分界点**
最关键的是：货到后坏果算谁的。建议写：
- 装车前的质量风险由供货方承担；
- 运输由谁安排，风险就按约定转移；
- 到货卸货前，买方有权开箱抽检；
- 若运输由卖方负责，则到货前坏果由卖方承担；
- 若运输由买方自提或指定物流，则装车后风险由买方承担，但卖方对装车前已有隐蔽质量问题仍应负责。

**3. 约定验收期限和方式**
例如：
- 货到后 **24小时/48小时内** 完成验收；
- 按批次随机抽检，抽检比例不低于 **5%/10%**；
- 发现坏果应拍照、录像、保留样品，并在 **24小时内** 书面通知卖方；
- 逾期未提出异议，视为验收合格，但隐蔽瑕疵除外。

**4. 写清赔付计算**
不要只写“按实际损失赔偿”，要可计算。常见写法：
- 坏果率在 **3%以内**，视为合理损耗，双方各承担或买方承担；
- 超过 **3%** 的部分，由卖方按坏果数量对应的货款赔偿；
- 坏果率超过 **10%/15%**，买方有权拒收整批或要求退货退款；
- 因坏果导致买方被下游索赔、退货、运费、分拣费等，可约定由责任方承担，但要有票据证明。

示例条款：
> 到货验收时，经双方抽检确认，坏果率不超过3%的，视为合理损耗，买方承担；超过3%的，超出部分由卖方按该批次实际采购单价乘以坏果数量向买方赔偿。坏果率超过15%的，买方有权拒收该批次货物，卖方应在3日内退还已收货款并承担退货运费。

**5. 写清处理时限**
例如：
- 卖方应在收到通知后 **24小时内** 回复；
- **3日内** 完成补货、换货或退款；
- 逾期不处理，买方有权自行处理坏果，费用从货款中扣除。

**6. 保留证据和扣款权**
可约定：
- 买方有权从应付货款中直接扣除经确认的坏果赔偿款；
- 双方对坏果有争议时，可共同委托第三方检测；
- 检测费由责任方承担。

**7. 建议加一句“隐蔽质量问题不因验收而免责”**
因为有些坏果到货时看不出来，比如内部腐烂、冻伤后熟。可写：
> 验收合格不免除卖方对装车前已存在的隐蔽质量问题的责任，买方在合理期限内发现的，仍有权要求赔偿。

**简单可用的合同条款模板：**
> 卖方应保证交付货物符合双方约定质量标准。货到后买方应在48小时内验收，按不低于10%比例抽检。坏果率不超过3%的，视为合理损耗；超过3%的，超出部分由卖方按实际采购单价赔偿；超过15%的，买方有权拒收整批货物，卖方应退还货款并承担退货运费。买方发现坏果后应保留照片、视频及样品，并在24小时内通知卖方；卖方应在3日内完成补货、换货或退款。验收合格不免除卖方对装车前已存在隐蔽质量问题的责任。经确认的赔偿款，买方有权从应付货款中直接扣除。
