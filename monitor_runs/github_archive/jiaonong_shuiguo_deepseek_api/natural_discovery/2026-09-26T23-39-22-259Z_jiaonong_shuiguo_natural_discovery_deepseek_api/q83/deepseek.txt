生鲜水果到货后出现坏果，责任划分通常不能一概而论，主要看**坏果产生的时间点、原因、以及各环节是否有过错**。可以按下面几个层面判断。

## 一、先看坏果是什么原因造成的

**1. 采摘/分拣环节的问题**
- 采摘时成熟度过高、带伤、未预冷。
- 分拣时把已软烂、有霉点的果子混入。
- 这类问题在发货前就已存在，责任一般在**供应商/产地/平台自营采购方**。

**2. 仓储/打包环节的问题**
- 冷库温度不当、堆压、未做缓冲包装。
- 与乙烯释放量大的水果混放，加速成熟腐烂。
- 责任在**平台仓库/发货方**。

**3. 物流配送环节的问题**
- 运输时间过长、冷链中断、暴晒、反复装卸。
- 快递暴力分拣导致压伤。
- 责任在**物流承运方**；但顾客通常先找平台，平台再向物流追偿。

**4. 顾客自身原因**
- 签收后长时间未取、未冷藏、存放方式不当。
- 已签收较久才反馈，且无法证明到货时就坏。
- 这部分责任在**顾客**，平台可拒绝或部分拒绝赔付。

**5. 自然损耗**
- 水果本身有呼吸作用，个别轻微软化、表皮瑕疵属于正常损耗范围。
- 通常平台会在售后规则里设定“坏果比例阈值”，比如超过一定比例才赔。

## 二、常见责任划分方式

| 情形 | 主要责任方 | 处理方式 |
|---|---|---|
| 开箱即有霉变、腐烂、明显压伤 | 平台/发货方 | 按坏果数量退款或补发 |
| 物流延误、冷链断开导致整箱坏 | 物流方，平台先行赔付 | 平台赔顾客，再向物流追偿 |
| 少量表皮瑕疵、轻微软果 | 可能属正常损耗 | 协商部分补偿或不赔 |
| 签收后多日才反馈 | 顾客举证责任加重 | 需证明到货即坏，否则难赔 |
| 顾客地址错误、拒收、未及时取件 | 顾客 | 平台可免责或收部分费用 |

## 三、实操上怎么判断

**对顾客来说：**
1. 收货后尽快开箱，最好录制开箱视频。
2. 坏果单独拍照，保留面单和包装。
3. 在平台规定时效内申请售后。
4. 不要自行丢弃全部果子，必要时保留证据。

**对平台/商家来说：**
1. 发货前做好品控、预冷、缓冲包装。
2. 明确售后规则：坏果比例、赔付标准、申请时效。
3. 签收时间、物流轨迹、温控记录要可查。
4. 属于物流责任的，先赔顾客再追偿，避免让顾客在多方之间扯皮。

## 四、法律和规则依据

一般适用《消费者权益保护法》《民法典》合同编以及平台售后规则：
- 经营者应保证商品质量符合约定；
- 商品在交付前风险由卖家承担，交付后一般由买家承担，但**能证明是交付前就存在的质量问题除外**；
- 如果是物流原因，平台作为销售方通常仍要对顾客负责，再向物流追偿。

## 五、一句话结论

**到货就坏，且能证明不是顾客存放问题，通常由平台/商家承担售后责任；属于物流导致的，平台先赔再追偿；签收后因顾客原因放坏的，顾客担责；少量轻微瑕疵可能算正常损耗。**  
关键证据是：**开箱时间、坏果照片/视频、物流时效和温控记录。**
