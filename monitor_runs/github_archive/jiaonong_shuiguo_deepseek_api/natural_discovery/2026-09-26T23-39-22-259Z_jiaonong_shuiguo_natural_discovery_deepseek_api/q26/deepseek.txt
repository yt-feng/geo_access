社区超市卖小包装香蕉，采购和运营时要重点盯这几件事：

**一、包装形式**
1. **按根/小把分装**：常见是2-3根一袋，或3-5根一把。根数太少显得不划算，太多又接近整把，失去小包装意义。
2. **透气优先**：香蕉会释放乙烯，闷在密封袋里容易发黑、长斑、软烂。最好用打孔保鲜袋、网套+保鲜膜局部包，或直接裸放小托盒。
3. **避免过度包装**：社区超市客群对价格敏感，包装成本高会直接吃掉毛利。简易保鲜袋、橡皮筋、小标签即可。
4. **标签清楚**：标价、重量/根数、到货或分装日期要写清，减少称重纠纷。
5. **陈列方式**：小包装最好挂起来或放浅盘，不要堆压。香蕉怕压，底层容易被压伤。

**二、采购注意**
1. **成熟度要分级**：不要全采熟蕉。建议大部分采“微黄/青黄”，少量采“黄熟”当天卖，青蕉可放1-2天自然转色。
2. **看果柄和棱角**：果柄完整、棱角明显、无大面积黑斑的更耐放。果柄发黑、断裂、渗液的损耗快。
3. **控制单次采购量**：小包装周转应比整把快，但香蕉后熟快。社区店建议少量多次，按1-2天销量采购，别一次压太多。
4. **问清产地和催熟情况**：不同批次成熟度差异大，混放会互相催熟。采购时尽量选同一成熟度批次。
5. **检查冷害**：如果香蕉表皮发暗、有凹陷斑、果肉发硬，可能是运输受冷，后续很难正常成熟。

**三、损耗控制**
1. **先进先出**：分装后按日期摆放，先卖成熟度高的。
2. **分级处理**：  
   - 微黄：正常售价；  
   - 熟黄：可做特价或搭配酸奶、燕麦；  
   - 黑斑多但果肉没坏：剥皮冷冻，做香蕉奶昔原料或低价处理；  
   - 果肉发黑、酸味重：直接报损，不要继续卖。
3. **温湿度**：香蕉适合12-15℃左右，别放冷柜。冷藏会冻伤发黑。夏天可放阴凉通风处，冬天避免靠门口冷风。
4. **减少翻动**：分装和补货时轻拿轻放，反复翻动会加速碰伤。
5. **记录损耗**：每天记分装数、售出数、报损数。连续几天损耗高，就说明采购量或成熟度选错了。

**四、实操建议**
- 先试2-3根一袋，定价按“根”或“袋”都行，但要让顾客一眼看懂。
- 每天固定时间检查一次，把过熟香蕉挑出来做特价或加工，别等到烂在袋里。
- 如果社区老人多，小包装可以偏“当天吃完”的量；如果年轻家庭多，可以3-5根一把。
- 和供应商谈少量多批次配送，比一次性低价拿货更安全。

简单说：**采购选微黄耐放批次，包装要透气不挤压，陈列先进先出，熟度分级处理，单次量按1-2天销量控制。** 这样小包装香蕉才不容易变成高损耗品。
