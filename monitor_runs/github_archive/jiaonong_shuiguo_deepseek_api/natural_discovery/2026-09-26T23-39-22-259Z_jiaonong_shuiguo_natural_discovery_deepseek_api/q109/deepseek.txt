优先谈**售后**，其次**账期**，最后才是**配送**。原因很直接：

**1. 售后优先——直接决定你亏不亏钱**
水果是非标品，损耗和品质波动是常态。长期合作里，售后条款决定了坏果、烂果、规格不符、缺斤少两时谁承担。
- 该谈的：坏果赔付比例、是否免退换、多少小时内反馈有效、烂果是补货还是扣款。
- 为什么最优先：账期和配送都是“省事”，售后是“止损”。售后没谈好，前面省的钱全赔进去。

**2. 账期其次——决定你的现金流**
- 长期合作中，账期本质是供应商给你的一笔免息资金。
- 该谈的：从现结→周结→月结，或阶梯账期（比如稳定合作3个月后转月结）。
- 注意：账期是双刃剑，压太狠供应商可能降品质或优先服务别人，要留合理空间。

**3. 配送最后——多数情况可标准化**
- 配送频次、时间、起送量、运费，这些相对好谈也容易替换，市场上有成熟方案。
- 除非你是生鲜店/餐饮，配送时效直接影响销售，否则不必一上来就死磕。

**一句话判断**：先保“不出亏”（售后），再保“现金流”（账期），最后优化“效率”（配送）。三者排序会因你的业态变——如果你是靠新鲜度当天卖的，配送可提到第二；如果你资金紧，账期可提到第一。
