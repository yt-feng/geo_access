判断苹果和橙子的大小规格是否适合门店销售，核心不是“越大越好”，而是看**门店客群、售卖方式、损耗和毛利**。可按下面几步做。

## 1. 先按门店售卖方式定规格

### 苹果
常见适合门店销售的分档：
- **小果**：单果约 120–160g，适合社区店、散卖、低价引流。
- **中果**：单果约 160–220g，最适合日常散卖和家庭消费。
- **大果**：单果约 220–300g，适合精品店、礼盒、商超堆头。
- **特大果**：300g 以上，适合礼盒、节日果，不适合普通散卖，容易价高难动销。

判断标准：
- 散卖门店：优先中果，大小均匀，顾客拿取方便。
- 精品/礼盒：优先大果、特大果，但要求果形、颜色、瑕疵控制更严。
- 社区平价店：中果偏小即可，重点看价格和新鲜度。

### 橙子
常见适合门店销售的分档：
- **小果**：单果约 120–160g，适合榨汁、促销、社区散卖。
- **中果**：单果约 160–220g，最适合日常销售。
- **大果**：单果约 220–300g，适合精品陈列、礼盒。
- **特大果**：300g 以上，适合礼盒或特殊品种，普通门店慎采。

判断标准：
- 普通门店：中果最稳，顾客接受度高，损耗相对低。
- 榨汁需求强的门店：可采小果，但要有明确促销或榨汁场景。
- 礼盒/精品：大果可以，但要控制皮厚、空壳、干水问题。

## 2. 用“横径”比“重量”更标准

采购时最好问清或抽测**横径**，因为重量会受水分、品种影响。

参考：
- 苹果横径：
  - 65–70mm：小果
  - 70–80mm：中果
  - 80–90mm：大果
  - 90mm以上：特大果
- 橙子横径：
  - 60–65mm：小果
  - 65–75mm：中果
  - 75–85mm：大果
  - 85mm以上：特大果

如果供应商只给“70果、75果、80果”，通常指横径毫米数。门店采购要问清楚是**横径还是重量规格**，否则容易踩坑。

## 3. 看均匀度，不只看平均大小

门店销售最怕“大小混装”。判断方法：
- 随机抽 20–30 个，按横径或单果重分档。
- 如果同一箱里最大和最小差超过 20–30mm，或重量差超过 50–80g，就不适合直接上架。
- 均匀度差可以做特价混装，但不适合正价散卖或礼盒。

## 4. 结合门店客群判断

- **社区家庭店**：中果最合适，顾客买 3–5 个一顿吃，太大吃不完，太小显得不划算。
- **写字楼/便利店**：中果偏小、单果独立拿取方便，适合即食。
- **精品超市**：大果、均匀度高、外观好，可做高毛利。
- **水果专营店**：可同时做小果引流、中果主力、大果利润款。
- **礼盒/团购**：大果或特大果，但必须统一规格、无瑕疵。

## 5. 算损耗和毛利，别只看采购价

适合门店的规格要满足：
- **损耗可控**：苹果碰伤、橙子干水/烂果比例低。
- **售价能被接受**：按个卖时，顾客会直观比较大小和价格。
- **毛利够**：大果采购价高，如果售价上不去，反而压资金。
- **周转快**：中果通常周转最快，大果和特大果周转慢。

简单判断：
- 如果同品种中果每天能卖 3 箱，大果只能卖 1 箱，优先中果。
- 如果大果能做成礼盒，毛利率明显更高，可以少量采。

## 6. 采购现场快速判断法

1. 问供应商：规格是横径还是重量，具体范围是多少。
2. 随机抽 20 个，称重并量横径，看是否均匀。
3. 看表皮：苹果要无严重碰伤、虫眼；橙子要无严重干疤、软烂。
4. 试吃或切开：苹果看脆度、糖心；橙子看水分、化渣、甜酸比。
5. 按门店售价倒推：这个规格顾客会不会觉得贵或太小。
6. 先小批量试销 3–7 天，看动销和损耗，再决定是否放量。

## 结论

对大多数普通门店：
- **苹果优先 160–220g，横径 70–80mm 的中果。**
- **橙子优先 160–220g，横径 65–75mm 的中果。**
- 大果、特大果只适合精品、礼盒或特定客群。
- 最终看三点：**均匀度、动销速度、损耗毛利**。满足这三点，才是适合门店销售的规格。
