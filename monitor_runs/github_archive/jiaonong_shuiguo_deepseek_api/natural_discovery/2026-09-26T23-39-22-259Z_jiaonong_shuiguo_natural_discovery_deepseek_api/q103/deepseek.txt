# 结论先说

**按斤结算最容易厘清成本和损耗，按箱结算最容易管流程，按份结算最容易管发放。** 没有绝对最好，关键看你食堂最头疼的是哪一环。

## 三种方式对比

| 方式 | 优点 | 主要风险 | 适合场景 |
|---|---|---|---|
| **按斤** | 单价透明，成本可核算，损耗可追踪 | 需过秤、验收耗时，易被短斤少两 | 水果品种多、单价差异大、要控成本 |
| **按箱** | 收货快，流程简单，供应商好报价 | 箱内品质不均、大小不一，隐性损耗大 | 品种固定、批量大、信任供应商 |
| **按份** | 发放快，按人头配额好控制，避免浪费 | 单价被摊高，份量缩水难发现 | 直接分发给就餐者、按人定量 |

## 实际建议（多数食堂适用）

**采购环节按斤，发放环节按份，内部管理用箱折算。**

具体做法：

1. **采购按斤结算**——过秤验收，写清品种、单价、重量、金额。这是成本核算的基础。
2. **入库按箱/筐登记**——方便搬运和盘点，但登记时注明折算重量。
3. **发放或售卖按份**——比如"1 份 = 1 个苹果/半斤西瓜"，方便窗口操作。

## 判断标准（选哪种）

- 如果**成本失控、损耗说不清** → 选按斤
- 如果**收货太慢、供应商嫌麻烦** → 选按箱，但必须定规格（如每箱净重、果径）
- 如果**窗口发放混乱、有人多拿** → 选按份

## 避坑提醒

- 按箱结算一定要写**净重**和**规格标准**，否则"一箱"可以是 15 斤也可以是 20 斤。
- 按份结算要防止份量悄悄缩水，最好定期抽查称重。
- 无论哪种，**验收记录**都要留存，否则出问题无法追溯。

一句话：**用按斤管钱，用按箱管物流，用按份管发放**，三者结合最稳。
