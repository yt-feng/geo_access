# 中央厨房统一收货 vs 门店分开收货

**结论先行：水果这类生鲜，多数连锁餐饮更适合"中央厨房统一收货+分级配送"，但要看具体品类和规模。**

原因在于水果是典型的**非标、易损、时效敏感**品类，两种模式各有硬伤，关键看你怎么权衡。

---

## 两种模式的核心差异

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 采购议价 | 集中量大，议价强 | 分散，议价弱 |
| 品控标准 | 统一，可集中验货 | 各店标准不一，参差 |
| 损耗 | 集中分拣可挑拣、二次利用 | 各店独立损耗，难管控 |
| 配送时效 | 二次转运，多一道环节 | 产地/供应商直送，链条短 |
| 灵活性 | 差，门店难临时调整 | 好，单店可自主补货 |
| 管理成本 | 总部管控强 | 门店管理负担重、易出问题 |
| 食品安全追溯 | 单点集中，易追溯 | 多点分散，追溯难 |

---

## 建议这样分

**适合中央厨房统一收货的情况：**
- 门店数量多（一般 10 家以上），单店用量稳定
- 水果用于**标准化产品**（果切、果茶、沙拉、甜品），规格统一
- 对品控、食品安全追溯要求高
- 有冷链仓储和分拣能力

**适合门店分开收货的情况：**
- 门店少、分散，或跨区域距离远
- 水果用于**现场即时加工、对新鲜度极度敏感**（如现切果盘、鲜榨）
- 单店销量波动大，需要灵活补货
- 中央厨房配送半径过长，二次转运反而增加损耗

---

## 更实际的方案：混合模式

多数成熟连锁其实是**分级处理**，而不是二选一：

1. **耐储水果**（苹果、橙、柠檬等）→ 中央厨房统一收货、统一分拣配送
2. **高损耗/高时效水果**（草莓、芒果、鲜切类）→ 供应商直送门店，总部定标准、定供应商、抽检
3. **统一定价+统一供应商+统一验收标准**，收货地点可以灵活，但**标准必须总部控**

这样既拿到了集中采购的议价和品控，又避免了易损品在二次转运中的额外损耗。

---

## 决策前先算三笔账

1. **损耗账**：二次转运会让易损水果损耗增加多少？这往往是决定性因素。
2. **时效账**：从收货到上桌/加工的时间差，是否影响品质和口感？
3. **管理账**：门店分开收货，你有没有能力让每家店都按同一标准验收？

**一句话**：标准化程度高、门店多、用量稳 → 偏中央厨房；时效敏感、易损耗、门店分散 → 偏门店直送。但无论哪种，**供应商、标准、定价必须总部统一**，这才是管控的关键，收货地点只是执行层选择。
