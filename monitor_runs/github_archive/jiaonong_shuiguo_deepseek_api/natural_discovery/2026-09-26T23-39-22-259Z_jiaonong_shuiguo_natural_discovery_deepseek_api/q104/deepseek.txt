单位采购水果遇到到货品质不一致，可以按“先定标准、再验货、再分级处理、最后走售后”的流程来处理。

## 一、验收前先明确标准

采购时最好在合同或订单里写清楚：

1. **品种、规格、等级**：如苹果直径、单果重量、糖度、成熟度、产地等。
2. **外观标准**：色泽、大小均匀度、伤疤、虫眼、腐烂、畸形比例。
3. **新鲜度标准**：叶片/果柄状态、软硬度、气味、有无冷害或冻伤。
4. **允许误差**：例如“同等级果不低于90%，轻微外观瑕疵不超过5%”。
5. **验收方式**：抽检比例、抽检方法、不合格判定规则。
6. **售后条款**：不合格部分如何补货、换货、退款、折价。

如果没有书面标准，验收时容易扯皮。建议至少用微信、邮件确认一份“到货品质要求”。

## 二、到货验收怎么做

### 1. 先查数量和单据
- 核对送货单、订单、发票信息。
- 清点箱数、件数、总重量。
- 检查包装是否破损、受潮、挤压。

### 2. 抽检要代表性
- 不要只看最上面一层。
- 按比例随机抽检，比如每批抽5%—10%，大货至少抽3—5箱。
- 从不同位置、不同箱中取样。
- 对高价或易腐水果，抽检比例可提高。

### 3. 现场记录
- 拍照/录像：全景、包装、开箱、问题果特写。
- 记录：到货时间、车牌/送货人、批次、抽检数量、不合格数量。
- 让送货人签字确认，或当场发消息给对方确认。

### 4. 分级判定
可以把到货分成三类：

- **合格**：符合约定标准，正常入库。
- **轻微不合格**：如个头略小、外观瑕疵，可折价接收。
- **严重不合格**：腐烂、变质、品种不符、缺斤少两，应拒收或要求换货。

### 5. 验收单怎么写
建议写明：
- 订单号、到货日期、供应商；
- 品名、规格、数量；
- 抽检数量、不合格数量；
- 不合格描述；
- 处理意见：拒收/换货/补货/折价/退款；
- 双方签字或聊天记录确认。

## 三、售后怎么处理

### 1. 第一时间反馈
到货后尽快验收，最好在约定时限内反馈，比如2小时、4小时或当天。超过时限，供应商可能不认。

### 2. 提出明确诉求
根据问题程度选择：
- **补货**：数量不足或部分损坏。
- **换货**：品质不达标但还能退换。
- **折价**：轻微瑕疵，单位可接受，但要求降价。
- **退款**：严重变质、无法食用。
- **拒收**：整体严重不符，直接退回。

### 3. 保留证据
- 问题水果不要马上全部处理掉，先拍照、封样。
- 保留送货单、验收单、聊天记录、通话录音。
- 如果冷链或仓储有问题，也要记录温度和时间。

### 4. 约定处理时限
要求供应商明确：
- 多久回复；
- 多久补换货；
- 退款多久到账；
- 运费谁承担。

### 5. 如果对方不配合
- 先书面催告，保留记录。
- 按合同扣款或拒付相应货款。
- 金额较大时可走采购平台投诉、12315、市场监管投诉或法律途径。
- 后续将该供应商列入谨慎合作名单。

## 四、实用建议

1. **不要先入库再验收**：先验收，合格后再入库。
2. **不要口头说了算**：所有标准、问题、处理结果尽量留痕。
3. **不要全部拒收或全部接收**：按比例分级处理更现实。
4. **易腐水果要快**：到货后尽快验，避免责任说不清。
5. **建立供应商评分**：品质、准时率、售后响应都纳入考核。
6. **大额采购可留质保金**：验收合格后一段时间再付尾款。

简单说：**验收靠标准，判定靠抽检，处理靠分级，售后靠证据和时限。**
