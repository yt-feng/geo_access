判断茶饮连锁采购菠萝的供应商能否稳定按规格送货，核心是：**别只看样品和报价，要把“规格”变成可验收的条款，再用批次数据和产能证据去验证。** 具体可以按下面几步做。

**1. 先把“规格”定义到可验收**
不要只说“要菠萝”，要明确到：
- 品种：如金钻凤梨、台农、巴厘等，不同品种糖酸比和纤维感不同。
- 成熟度/糖度：如糖度≥12°Brix，或指定成熟度区间。
- 果径/单果重：如单果1.2–1.5kg，或按果径分档。
- 形态：整果、去皮整果、切块、果丁、冷冻果肉等。
- 加工方式：鲜切、速冻、糖渍、罐头等。
- 包装：真空袋、马口铁罐、冷冻箱，每箱净重、袋数。
- 交付：到货温度、冷链要求、到货时间窗口、每批允许的损耗率。
- 验收标准：抽检比例、不合格判定、退换货规则。

这一步做不细，后面所有“稳定”都无法衡量。

**2. 查供应商的“产能证据”**
- 问自有果园/合作基地面积、年产量、加工线产能。
- 看是否只做贸易转手，还是有自己的分选、切果、冷冻能力。
- 要求提供近6–12个月同规格产品的出货记录：月均供货量、最大单月供货量、主要客户类型。
- 关键问题：**旺季和淡季分别能供多少？** 茶饮采购往往旺季集中，供应商淡季能供不代表旺季能供。

**3. 用“小批量试单”验证稳定性**
不要一上来就签大单。建议：
- 先下3–5批小单，覆盖不同时间段。
- 每批按同一规格验收，记录：到货数量、合格率、糖度、单果重偏差、破损率、到货时间。
- 重点看**批间波动**，不是单批好坏。单批好可能是挑货，批间稳定才是能力。
- 试单期间故意安排一次紧急加单或提前/延后交付，看对方响应。

**4. 看供应链结构是否抗波动**
- 产地是否单一？单一产地遇到台风、雨季、病害就断供。
- 是否有多个合作基地或备用加工厂？
- 冷链是自有还是外包？外包的调度优先级如何？
- 原料是否受季节限制？如果是鲜果，反季节怎么解决？冷冻/罐头替代方案是否成熟？

**5. 合同里写死“稳定”的约束**
- 规格附件：作为合同附件，明确验收标准和抽检方法。
- 供货承诺：月最低供货量、旺季保供比例、紧急加单响应时间。
- 质量违约金：合格率低于约定值如何扣款、补货、赔偿。
- 替代方案：规格不达标时，是否允许降级使用，价格如何调整。
- 价格机制：原料波动时调价周期和幅度，避免旺季坐地起价。
- 退出条款：连续几批不合格可终止合作。

**6. 现场审厂或视频验厂**
重点看：
- 分选线是否按规格分级，还是人工随意挑。
- 冷库/冷冻库温度记录是否完整。
- 是否有批次追溯系统：哪批货来自哪个基地、哪天加工。
- 卫生和异物控制，茶饮连锁对食品安全要求高。

**7. 一个实用判断标准**
如果供应商能做到：
- 连续3批以上合格率≥95%；
- 批间糖度、单果重波动在约定范围内；
- 旺季能按承诺量交付；
- 有备用产地或加工方案；
- 验收不合格时愿意按合同补货或扣款；

那基本可以认为具备稳定按规格送货的能力。反之，如果样品很好但说不出产能、批次记录、备用方案，或者只愿意“先打款再发货”，风险就很高。

**建议动作**：先让对方填一份《规格与产能确认表》，再安排小批量试单，同时把验收标准写进合同附件。这样比单纯比价更能筛出真正稳定的供应商。
