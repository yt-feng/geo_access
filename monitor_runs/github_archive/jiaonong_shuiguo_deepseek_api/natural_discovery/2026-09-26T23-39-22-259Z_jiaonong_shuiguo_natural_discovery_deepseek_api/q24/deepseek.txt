超市采购如果担心水果农残抽检，核心不是只收一张“合格证”，而是要把**供应商资质、批次检测、来源追溯、责任约定**四类资料提前要齐。

建议向供应商索取以下资料：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按实际经营类型）
   - 若是种植基地直供，可要种植主体资质、产地证明或基地备案信息

2. **批次检测报告**
   - 每批次水果的农残检测报告，最好是第三方检测机构出具，或供应商自检报告
   - 报告要能对应到具体品种、产地、批次/采收日期
   - 重点看检测项目是否覆盖常见农残，如有机磷、氨基甲酸酯、拟除虫菊酯等，以及是否按 GB 2763 判定
   - 不要只收一份年度报告，抽检通常看的是“这一批货”

3. **承诺达标合格证/产地证明**
   - 食用农产品承诺达标合格证
   - 产地证明、采购凭证或上游供货凭证
   - 如果是进口水果，要入境货物检验检疫证明、报关单等

4. **追溯与台账资料**
   - 品种、数量、产地、采收/发货日期、运输方式
   - 上游供应商或种植基地信息
   - 批次号或可追溯编码，便于抽检不合格时快速定位和召回

5. **合同与责任条款**
   - 在采购合同里写明：供应商保证农残符合 GB 2763
   - 约定抽检不合格时的退换货、赔偿、检测费承担、召回配合责任
   - 约定供应商必须随货提供批次检测报告和合格证

6. **其他加分资料**
   - 绿色食品、有机产品、GAP 等认证，但要注意认证不能替代批次检测
   - 供应商近期的监管抽检记录、无不合格声明
   - 第三方快检或实验室检测能力说明

实操上，最稳妥的做法是：

- **首次合作**：审资质、看基地、签质量协议
- **每批到货**：索要该批次检测报告 + 承诺达标合格证 + 送货单
- **入库前**：超市自己做快检或抽样送检，保留记录
- **不合格时**：立即封存、退货/销毁、追溯上游，并向市场监管部门报告

一句话：**要“批次对应”的检测报告和合格证，不要只要“年度合格文件”；同时用合同把农残责任压给供应商。**
