商超做会员日水果活动，供应商要提前配合的重点，通常分这几块准备：

**1. 提前确认活动方案**
- 确认活动时间、持续天数、参与门店范围。
- 确认活动水果品类、规格、等级、包装形式。
- 确认促销价、供货价、毛利空间、费用分摊方式。
- 确认是限量抢购、第二件半价、满减还是会员专享价。
- 如果是会员专享，确认系统能否识别会员价，避免收银和标价不一致。

**2. 备货与产能准备**
- 按预估销量准备货源，不能只按日常量备。
- 活动前锁定产地或基地货源，避免临时缺货。
- 对易断货单品准备替代规格或替代品种。
- 提前安排采摘、分拣、打包、预冷，避免活动当天集中出货来不及。
- 如果是进口水果，提前确认报关、到港、清关时间。

**3. 质量与验收标准**
- 提前和商超确认验收标准：糖度、果径、颜色、成熟度、瑕疵率。
- 活动价容易引发顾客对品质更敏感，不能拿尾货、次果充数。
- 明确拒收标准，比如烂果率、压伤率、规格不符怎么处理。
- 对催熟类水果如香蕉、芒果，要控制到店成熟度，避免活动没结束就过熟。

**4. 包装与陈列配合**
- 按商超要求做预包装、称重码、条码、价签。
- 确认是否要统一活动包装、爆炸贴、会员日标识。
- 散装水果要提前分好等级，方便门店快速上架。
- 礼盒或组合装要提前打样，确认陈列尺寸和堆头效果。

**5. 物流与到店时效**
- 按门店订单分仓、分线路配送，避免所有货压到大仓再分。
- 活动前一天或当天清晨到店，保证开门前完成陈列。
- 对远距离门店预留冷链和运输时间。
- 明确缺货、迟到、破损的补货机制和责任人。

**6. 门店执行支持**
- 提前给门店做简单培训：卖点、保存方式、催熟判断、试吃话术。
- 安排促销员或督导到重点门店支援。
- 准备试吃物料、刀具、托盘、手套、垃圾桶。
- 对高客流门店，提前安排二次补货。

**7. 价格与系统配合**
- 提前把供货价、促销价、会员价录入系统。
- 确认称重码、PLU码、条码和活动价绑定正确。
- 避免出现标价签是会员价、收银机却是原价的情况。
- 如果做线上到家，确认线上库存和线下库存分开或同步。

**8. 库存与损耗控制**
- 活动前不要一次性把全部库存压到门店，分批到货。
- 对高损耗水果如草莓、蓝莓、荔枝，控制单店单次到货量。
- 提前约定活动后未售完库存的处理方式：退货、调拨、折价还是供应商承担。
- 明确损耗分担比例，避免活动结束扯皮。

**9. 售后与应急**
- 提前约定质量问题赔付标准。
- 准备活动期间应急联系人，门店能直接找到人。
- 对可能出现的集中投诉，提前准备补货、换货或退款方案。
- 如果活动爆量，提前确认能否临时加车、加人、加货。

**10. 活动前检查清单**
- 品项、规格、价格、毛利确认了吗？
- 货源、产能、到店时间确认了吗？
- 验收标准、损耗分担确认了吗？
- 条码、价签、会员价系统测试了吗？
- 门店陈列、试吃、促销员安排了吗？
- 应急补货和售后责任人明确了吗？

简单说，供应商不能只负责把货送到，还要提前配合商超把**货、价、质、量、时、场、系统、售后**这八件事对齐。会员日水果活动最容易出问题的不是没货，而是货不对、价不对、到店晚、品质不稳、损耗没人担。
