生鲜平台做一件代发水果，供应商的仓配能力不能只看“能发货”，核心要能支撑**低损耗、准时效、可追溯、能兜底**。建议重点核验以下几类能力：

**1. 仓储与保鲜能力**
- **温区匹配**：不同水果要求不同。常温暖库、冷藏0~8℃、部分热带水果需防冷害，不能混放。
- **分区与防串味**：苹果、香蕉等乙烯释放型水果要和其他易催熟水果隔离。
- **周转与库容**：要有日订单峰值处理能力，避免爆单后积压导致腐损。
- **质检分级**：入库验收、糖度/硬度抽检、成熟度分级、次果剔除。
- **打包环境**：有专门的打包区，能控制温度、湿度、虫害和交叉污染。

**2. 加工与包装能力**
- **一件代发专用包装**：防震、透气、防压、防潮，按果品定制，如珍珠棉、气柱袋、冰袋、保温箱。
- **预冷能力**：蓝莓、樱桃、荔枝等采后需快速预冷，否则货架期大幅缩短。
- **成熟度控制**：需要催熟或后熟管理能力，比如香蕉、芒果，不能发太生或太熟。
- **贴标与个性化**：能按平台要求贴面单、放售后卡、做品牌包装。
- **组合装能力**：多品项混装、赠品搭配、不同规格分拣。

**3. 配送与时效能力**
- **快递合作资源**：至少对接2~3家生鲜快递，能拿到稳定时效和价格，不能只依赖一家。
- **时效承诺**：核心城市次日达、周边城市隔日达，偏远地区要有明确时效或限售策略。
- **冷链/保温方案**：夏季高温、冬季防冻，需有对应季节包装和运输方案。
- **发货截单时间**：比如每天14点前订单当天发，超时顺延，平台要能对接。
- **异常件处理**：破损、延误、丢件、拒收的补发和退款流程要清晰。

**4. 订单与系统能力**
- **API对接**：能对接平台订单系统，自动抓单、回传运单号、同步库存。
- **库存实时性**：可售库存准确，避免超卖；有安全库存和预售锁库存机制。
- **面单打印**：支持平台电子面单，避免手工填单导致错发。
- **售后数据回传**：能按订单维度提供发货时间、快递单号、批次信息。

**5. 售后与兜底能力**
- **坏果包赔标准**：按比例赔付还是按颗赔付，需提前约定并系统化。
- **补发能力**：有备用库存，能在48小时内补发，而不是只退款。
- **批次追溯**：出现农残、催熟剂、冷链断链问题时，能追溯到采购批次和发货批次。
- **售后响应**：有专人对接平台客服，响应时间建议不超过2小时。
- **损耗承担**：运输损耗、快递延误损耗、签收后腐损的责任边界要写进合同。

**6. 建议平台重点核验的硬指标**
- 日均一件代发单量：能否稳定处理3000~10000单/天。
- 发货及时率：≥98%。
- 48小时到货率：核心区域≥95%。
- 坏果率：行业通常控制在3%~5%以内，高客单水果要求更低。
- 错发漏发率：≤0.5%。
- 售后响应：2小时内。
- 补发时效：48小时内。
- 系统对接：支持API/电子面单/库存同步。

**7. 合作前必须做的测试**
- 小批量试发：选3~5个城市，连续发7~10天。
- 极端天气测试：高温、降雨、低温各测一轮。
- 售后压力测试：故意模拟坏果、延误，看处理速度。
- 系统压测：大促峰值订单能否正常抓单和回传。
- 批次抽检：随机抽3批货，核验糖度、成熟度、农残报告。

简单说，供应商至少要具备：**匹配温区仓储 + 预冷/分级/定制包装 + 稳定快递时效 + API订单系统 + 坏果补发兜底**。缺任何一项，一件代发水果都很容易变成高售后、高损耗的生意。
