最应该先问**售后**，其次问**配送**，最后才压价格。

原因是团购团长的核心风险不是“进价高一点”，而是**坏果、烂果、缺斤少两、售后扯皮导致团长自己赔钱、掉信任**。水果是非标品，交付波动大，售后规则直接决定你会不会白干甚至倒贴。

可以按这个顺序判断：

1. **售后**
   重点问：
   - 坏果怎么赔？按个数、按重量，还是按订单比例？
   - 需要拍照吗？多久内反馈有效？
   - 是补发、退款，还是下次进货抵扣？
   - 团长先垫赔还是供应商直接赔？
   - 损耗超过多少算供应商责任？

   如果售后含糊，价格再低也别急着合作。因为一旦群里客户投诉，团长是直接面对信任损失的人。

2. **配送**
   重点问：
   - 到货时间是否稳定？能不能按你开团节奏送？
   - 送到自提点还是送到团长手上？
   - 破损、延迟、漏送谁负责？
   - 临时加单、减单怎么处理？
   - 冷链水果是否全程冷链？

   配送不稳定会直接影响履约，客户不会怪供应商，只会怪团长。

3. **价格**
   价格当然重要，但应该是在售后和配送能兜底之后再谈。
   重点不是单纯比低价，而是比：
   - 到手价
   - 损耗率
   - 售后赔付后的真实成本
   - 起订量
   - 结算方式
   - 是否压货

一句话建议：  
**先问售后规则，再问配送稳定性，最后谈价格和账期。**  
如果供应商只说“价格最低”，但售后和配送说不清楚，这种更适合试单，不适合长期主推。
