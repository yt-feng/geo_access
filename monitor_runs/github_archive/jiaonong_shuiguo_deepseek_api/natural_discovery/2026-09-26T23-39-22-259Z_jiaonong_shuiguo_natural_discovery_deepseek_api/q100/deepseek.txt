避免香蕉熟过头，核心是**控温、控乙烯、控压伤、控采购节奏**，同时给已经偏熟的香蕉找好“出口”。

可以按下面做：

1. **采购不要一次买太熟、太多**
   - 优先采购**颜色偏绿、硬实**的香蕉，比如 2–3 号色，而不是已经全黄带斑点的。
   - 按食堂日均用量分批次采购，比如每天或隔天到货，不要一次囤一周量。
   - 和供应商约定成熟度标准：表皮青黄、无黑斑、无软烂、无大面积压伤。

2. **到货后先分级**
   - 青一点的：正常存放，后续再用。
   - 黄熟但完好的：优先安排当天、次日使用。
   - 已出现黑斑、发软的：不要再常温放着，直接进入加工或促销使用。
   - 压伤、裂开的：单独挑出，避免污染和加速整批成熟。

3. **存放要避乙烯、避压、避高温**
   - 香蕉不要和苹果、梨、番茄等释放乙烯较多的果蔬混放。
   - 放在**阴凉、通风、10–15℃左右**的地方；食堂如果没有冷库，至少避免暖气边、灶台边、阳光直射。
   - 不要整箱堆压，最好挂起来或单层摆放，减少压伤。
   - 未完全熟的香蕉不要直接进冰箱冷藏，容易冻伤变黑；已经熟透的可以冷藏短存，但皮会变黑，果肉仍可尽快用。

4. **建立“先进先出 + 每日检查”**
   - 贴到货日期标签，旧货先用。
   - 每天查一次成熟度，把最熟的挑出来当天用。
   - 对快过熟的香蕉，提前转到档口做香蕉牛奶、香蕉粥、香蕉饼、香蕉面包、水果沙拉等。
   - 如果食堂有加餐、水果吧，可以把熟香蕉优先放在显眼位置，促进消耗。

5. **和菜单联动**
   - 采购前看未来几天菜单：如果已有香蕉直接吃、香蕉奶昔、香蕉燕麦等用量，再决定采购量。
   - 临近周末、假期前少采购，避免积压。
   - 对容易过熟的批次，提前安排加工菜单，而不是等坏了再处理。

6. **供应商管理**
   - 要求分批配送，不要一次送完全部。
   - 明确验收标准：成熟度、损伤率、黑斑比例。
   - 如果经常到货偏熟，可要求供应商调整采摘和配送时间。

简单判断标准：
- **青黄硬**：可存 2–4 天。
- **全黄无斑**：最好 1–2 天内用完。
- **出现黑斑、变软**：当天必须用掉或加工。
- **果肉发酸、发酒味、流汁**：不要再用。

最有效的组合是：**少量多次采购 + 阴凉通风存放 + 不与催熟果蔬混放 + 每天挑熟先用 + 快熟时转加工菜单。**
