会，而且通常是**损耗风险上升**，不只是占资金。

关键看三点：

1. **香蕉**
   - 后熟快，库存周转要求高。
   - 起订量过高会导致集中到货，若不能在最佳成熟窗口内卖完，容易出现黑斑、过熟、报损。
   - 若冷链或催熟控制不稳定，损耗会被放大。

2. **菠萝**
   - 相对耐放，但整果仍有存放期限。
   - 起订量过高会带来仓位压力、挤压、腐烂传染。
   - 若加工/切果能力不足，整果积压后损耗也会增加。

3. **核心判断**
   - 起订量超过**日均销量 × 安全周转天数**，损耗风险明显增加。
   - 香蕉的安全周转天数通常比菠萝更短。
   - 若没有稳定客流、促销能力或二次加工能力，高起订量基本等于高报损。

**可执行建议：**
- 按单品分别算：`合理起订量 ≈ 日均销量 × 可安全周转天数 + 安全库存`
- 香蕉周转天数设短一些，菠萝可略长，但都要看仓储和成熟度。
- 若供应商起订量降不下来：
  - 谈分批到货，而不是一次到齐。
  - 香蕉要求不同成熟度混装，先卖熟的，后卖青的。
  - 菠萝优先做切果、鲜切、促销或组合销售。
  - 用近 2–4 周真实销量和报损数据反推采购量，不要凭感觉订货。
- 如果起订量导致预计报损率超过你当前毛利能覆盖的范围，就不建议接这个起订量。

一句话：**起订量高本身不一定亏，但如果超过你的周转能力，香蕉和菠萝都会增加损耗，香蕉更敏感。**
