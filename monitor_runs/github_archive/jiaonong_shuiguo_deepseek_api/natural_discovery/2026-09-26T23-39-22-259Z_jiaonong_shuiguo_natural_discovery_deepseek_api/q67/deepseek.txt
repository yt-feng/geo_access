问品牌方时，建议把“区域保护”和“串货”拆成两套问题，因为这两件事经常被品牌方混着说。

**一、先问区域保护，核心是“有没有排他、范围多大、怎么落地”**

1. 我签的是不是**独家代理**？如果不是独家，同一区域最多放几家？
2. 保护范围是**按行政区**（省/市/区县）还是**按渠道**（商超/水果店/批发市场/电商）？我能不能覆盖全渠道？
3. 保护期多久？和合同期一致吗？续约时品牌方能不能单方面缩小我的区域或增加代理商？
4. 线上算不算我的保护范围？如果品牌方自己在电商卖，或授权其他商家发全国，算不算侵犯我的区域？
5. 品牌方直营、大客户、团购、直播渠道如果进我的区域，怎么处理？是给我供货、给我返点，还是直接绕过我？
6. 区域保护有没有**书面写进合同**？还是只在口头承诺或招商 PPT 里？
7. 如果我业绩没达标，品牌方能不能以此为由取消我的独家或缩小区域？达标标准是什么，谁认定？

**二、再问串货，核心是“怎么定义、怎么查、怎么罚、我被冲了怎么办”**

1. 你们怎么定义串货？是**跨区域销售**就算，还是低于指导价跨区卖才算？电商发全国算不算？
2. 如果别的区域代理商把货窜到我这里，我举报后你们多久处理？处理流程是什么？
3. 对串货方有什么处罚？罚款、扣保证金、断货、取消代理权，哪一条会真正执行？
4. 我被串货冲击时，品牌方赔不赔我的损失？有没有补偿机制？
5. 你们有没有**溯源系统**？比如箱码、批次码、一物一码，能不能查到货从哪个代理出去的？
6. 我自己的货如果被窜到别的区域，你们怎么处理我？会不会直接扣我保证金或断供？
7. 经销商、二批、终端门店从非我渠道拿货，品牌方管不管？管到什么层级？
8. 线上低价乱价、未授权店铺卖货，算不算串货？品牌方有没有控价团队？

**三、怎么判断对方靠不靠谱**

- 只谈“放心，我们保护你”，但拒绝写进合同的，基本不要信。
- 合同里只写“乙方不得串货”，却不写“甲方如何保护乙方区域”的，是单边条款。
- 区域保护写成“根据市场情况调整”的，等于没有保护。
- 保证金只罚你不罚别人的，要特别小心。
- 问一句关键话：**“如果我隔壁区域代理商窜货到我这里，你们具体怎么罚他、怎么补我？”** 看对方能不能说出流程、时效和处罚标准。说不出来，说明没有实际管控。

**四、最好写进合同的关键条款**

1. 授权区域、渠道、是否独家、保护期限。
2. 品牌方及其他代理不得跨区销售的义务。
3. 串货认定标准、举报流程、处理时限。
4. 串货方处罚标准，以及对被窜货方的补偿方式。
5. 溯源和查货机制。
6. 线上销售权限和控价规则。
7. 违约解除和保证金退还条件。

谈的时候最好让对方把“区域保护范围、串货处理流程、补偿标准”三项写成书面附件，不要只停留在招商话术里。
