选学校食堂水果供应商，核心不是“找最便宜的”，而是 **稳定供货 + 食品安全可追溯 + 价格透明 + 售后可追责**。香蕉、苹果、橙子这类常见水果，建议按下面几步做。

## 1. 先定采购标准，再谈供应商

不要先问供应商“你有什么”，而是先写清楚学校要什么。

**通用标准：**
- 必须能提供营业执照、食品经营许可证
- 能提供每批次农残检测报告或承诺书
- 有固定分拣、仓储、冷链或常温配送能力
- 能按学校指定时间送到食堂，不是送到校门口就结束
- 能接受退换货、补货、临时加单
- 能开正规发票，账期可谈

**分品类标准：**
- **香蕉**：成熟度可控，不能一到就全熟或全青；损耗率要写进合同
- **苹果**：规格统一，脆度、色泽、大小分级明确，耐储存
- **橙子**：酸甜度稳定，出汁率或可食率有基本要求，霉变率低

## 2. 供应商来源优先顺序

建议按这个顺序找：

1. **本地农产品批发市场大型档口**
   - 优点是品类全、价格透明、配送快
   - 适合作为主供应商或应急供应商
   - 要重点查是否有固定档口、能否长期稳定供货

2. **果蔬配送公司**
   - 适合学校食堂，能一站式配送
   - 重点看：是否有学校、企事业单位食堂配送案例
   - 要求提供分拣标准、退货规则、检测能力

3. **产地合作社或种植基地**
   - 苹果、橙子适合直接找产地
   - 香蕉通常需要催熟环节，最好找有催熟能力的供应商
   - 优点是源头可控，缺点是品类单一、起订量高

4. **大型商超或生鲜平台的企业购渠道**
   - 适合小批量、应急、审计要求高的学校
   - 价格通常偏高，但票据和售后规范

## 3. 重点核验这6项

**① 资质**
- 营业执照
- 食品经营许可证
- 从业人员健康证
- 如果是配送公司，还要看仓储和运输条件

**② 检测**
- 农残检测报告：不能只看一张全年通用的，最好按批次或定期提供
- 承诺书只能作为辅助，不能替代检测
- 学校有条件可做快检抽检

**③ 现场考察**
- 看仓库是否通风、防潮、防鼠虫
- 看分拣区是否干净
- 看是否有烂果混装
- 看冷链或常温车是否专用

**④ 试供**
- 先试供1—2周
- 记录到货时间、重量误差、损耗率、退换货响应
- 试供合格再签长期合同

**⑤ 价格机制**
- 不要只锁死单价，建议用“市场行情浮动+固定毛利率”或“每周报价确认”
- 香蕉、苹果、橙子季节波动大，一口价容易后期扯皮
- 报价要含税、含运费、含卸货到食堂指定位置

**⑥ 合同条款**
- 品种、规格、等级、单价、数量
- 送货时间、地点、验收标准
- 烂果率、损耗率上限
- 退换货时限
- 食品安全责任
- 违约和退出机制

## 4. 验收怎么做

食堂收货时建议固定动作：

- 核对品种、数量、重量
- 抽检外观：霉变、压伤、冻伤、异味
- 香蕉看成熟度，苹果看碰伤，橙子看发霉和干蒂
- 不合格当场拍照、登记、拒收或要求补换
- 每次验收留记录，月底汇总考核供应商

**建议设硬指标：**
- 到货合格率低于95%：警告
- 连续两次低于90%：暂停供货
- 出现食品安全问题：直接终止并追责

## 5. 推荐采购方式

**不要只选一家。**
建议：
- **主供应商1家**：负责日常大部分水果
- **备用供应商1家**：应急、比价、防止断供
- **产地直采1条线**：苹果、橙子可季节性地直采降本

这样既保供，又不会被单一供应商拿捏。

## 6. 最简可执行流程

1. 写采购标准
2. 找3—5家供应商
3. 查资质、看现场
4. 试供1—2周
5. 比价格、比损耗、比售后
6. 签合同，定主次供应商
7. 每周比价，每月考核
8. 不合格就换，不拖

**一句话总结：**
学校食堂选水果供应商，优先选 **证照全、能检测、可配送、敢退换、价格机制透明** 的本地配送商或大型档口；香蕉看催熟和损耗，苹果看分级和耐储，橙子看霉变和酸甜稳定；先试供再签长期，主供应商加备用供应商，别只图便宜。
