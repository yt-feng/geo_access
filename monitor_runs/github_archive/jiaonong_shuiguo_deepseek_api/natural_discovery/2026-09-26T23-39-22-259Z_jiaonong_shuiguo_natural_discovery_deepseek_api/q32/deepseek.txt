判断香蕉供应商能否全年稳定供货，不能只看对方承诺，要落到**产地结构、硬件设施、历史记录和合同约束**四个维度。下面给你一套可直接用的核查框架。

## 一、先看产地结构：单一产地必然有断供期

香蕉是热带作物，不同产区有各自的季节窗口和灾害风险。要求供应商回答：

- **有几个产区？** 只依赖一个产区（如仅海南或仅菲律宾）的，全年稳定基本做不到。
- **产区是否分散在不同纬度/气候带？** 理想状态是国产（海南、广西、云南）+ 进口（菲律宾、越南、厄瓜多尔、柬埔寨等）组合，错开上市期。
- **各产区的上市时间段是否衔接？** 让对方拉一张全年12个月的产地供货甘特图，看有没有空档。

如果对方只有一个产地、一种货源，直接判定为高风险。

## 二、看硬件设施：催熟和冷链决定"能不能接得上"

香蕉从产地到门店要经过催熟环节，稳定的核心在于：

- **是否有自有或长期合作的催熟库？** 几个库、总容量多少、能否覆盖你的日销量峰值？
- **冷链是否完整？** 产地预冷、运输温控、到仓再到门店，断一环就会造成品质波动和供货中断。
- **加工能力**：分拣、分级、包装能否按你的标准稳定输出。

可以要求实地看库，或看近期的出入库记录。

## 三、看历史履约记录：用数据而不是话术

让对方提供（或你侧面核实）：

- **过去12个月的月度供货量**，看你所在区域/类似客户的履约是否连续，有没有断供月份。
- **断供原因和补救记录**：遇到台风、船期延误、产地涨价时，他们怎么处理的？
- **合作客户名单**：是否长期服务其他连锁超市？同行长期合作是较强的信号。

如果对方拿不出任何历史数据，只靠口头保证，视为不可验证。

## 四、用合同和试单把风险锁死

- **试单验证**：先给2–3个月的中小批量，覆盖至少一个淡旺季交替期，观察实际到货率、品质合格率、缺货次数。
- **合同条款**：约定最低月供货量、缺货违约金、替代产地方案、价格调整机制（避免旺季坐地起价或断供）。
- **备选供应商**：即使主供应商稳定，也要保留1–2家备选，防止单点依赖。

## 快速判断表

| 信号 | 稳定 | 高风险 |
|---|---|---|
| 产地数量 | 多产区+进口组合 | 单一产地 |
| 催熟/冷链 | 自有设施、可核查 | 依赖临时外包 |
| 历史数据 | 12个月连续履约 | 拿不出记录 |
| 旺季应对 | 有替代方案 | 只承诺"没问题" |
| 合作客户 | 长期服务连锁 | 无同类客户 |

**结论**：能同时满足"多产区错峰+自有催熟冷链+可验证的连续履约记录"的供应商，才值得谈全年稳定供货。任何一条缺失，都用试单和合同条款去补，不要用信任去赌。
