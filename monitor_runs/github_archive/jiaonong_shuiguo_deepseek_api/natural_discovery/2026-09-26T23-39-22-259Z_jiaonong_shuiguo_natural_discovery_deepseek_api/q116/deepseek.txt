小商家采购水果，现金结算和月结账期各有风险，核心差别是：现金风险集中在“当场钱货两清但质量和售后难控”，月结风险集中在“账期占用现金流、对账和坏账”。

**现金结算的风险：**

1. **质量与数量当场难完全验清**  
   水果有隐蔽损耗，比如箱底压伤、内部腐烂、成熟度不均。现金付完后再发现问题，追责和退换会很难。

2. **价格随行就市，容易买在高点**  
   现金采购通常是一单一议。如果当天行情波动大，没有比价时间，可能比月结价更高。

3. **资金即时流出，周转压力大**  
   每天或每车都要付现金，旺季备货时占用大量流动资金，遇到突发支出容易紧张。

4. **票据和凭证不规范**  
   小商贩、产地代办常用手写单甚至无单。一旦出现质量问题、短斤少两，缺少可追溯证据。

5. **采购员道德风险**  
   如果是员工现金采购，容易出现虚报价格、吃回扣、虚增数量，老板不容易核查。

**月结账期的风险：**

1. **供应商抬价或缩量**  
   月结相当于供应商给你垫资，通常会在单价上加价，或者优先给现金客户好货，月结客户拿到的货等级可能偏低。

2. **现金流错觉，容易超采**  
   当月不付钱，容易感觉“资金宽松”，结果月底集中付款时压力很大。水果又是高损耗品类，卖不掉不等于不用付货款。

3. **对账纠纷多**  
   水果每天价格、等级、损耗都可能变。如果没有每日签收单、验收标准、退换货记录，月底容易因数量、质量、价格扯皮。

4. **供应商断供风险**  
   一旦你回款慢，供应商可能停止供货或降低供货优先级。水果季节性强，断供会直接影响销售。

5. **坏账和依赖风险**  
   如果长期只靠一家月结供应商，对方提价、换人、资金链出问题，你短期很难替代。反过来，如果你拖欠，也可能被追款甚至起诉。

6. **隐性成本高**  
   月结往往伴随押金、最低采购量、指定等级、延迟结算扣点等条件，实际成本可能高于现金价。

**更稳妥的做法：**

- 小额、紧急、行情波动大：现金结算，但要求当场验货、留样、写清品名等级数量。
- 长期稳定、量大：月结，但必须签简单协议，明确价格机制、验收标准、退换货规则、对账日和付款日。
- 不要只用一种方式。可以“部分现金拿好货 + 部分月结保供应”。
- 每天做采购验收单，拍照留证，月底按单对账。
- 控制月结额度，比如不超过月采购额的30%—50%，避免现金流被绑死。
- 现金采购尽量用转账并备注，减少无凭证现金交易。

简单判断：  
**现金结算怕买贵、买坏、没法追；月结怕压款、扯皮、被断供。**  
小商家最好把现金用于灵活补货，把月结用于稳定大宗，并且用验收单和对账制度把风险压住。
