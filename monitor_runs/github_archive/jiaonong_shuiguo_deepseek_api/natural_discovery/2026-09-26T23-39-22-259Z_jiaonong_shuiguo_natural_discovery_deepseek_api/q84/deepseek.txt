做家庭装水果礼盒，核心原则是：**数量适中、耐放、老少都能吃、切开方便**。按这个思路，苹果、橙子、香蕉、菠萝里，最稳妥的组合是 **苹果 + 橙子为主，香蕉少量点缀，菠萝不建议常规放或单独做选项**。

具体建议：

**1）推荐组合：苹果 + 橙子 + 香蕉（少量）**
- **苹果 4–6 个**：耐放、寓意好、全家都吃，适合当礼盒主角。
- **橙子 4–6 个**：颜色好看、补充维C、耐放，和苹果搭配最稳。
- **香蕉 2–3 根**：增加色彩和柔软口感，但香蕉不耐压、不耐放，必须少量，且要单独隔开。
- 适合：3–5 口之家，预算适中，配送时间不太长。

**2）如果想加菠萝：苹果 + 橙子 + 菠萝**
- **苹果 4 个 + 橙子 4 个 + 菠萝 1 个**
- 菠萝有分量、有仪式感，但处理麻烦，不是所有家庭都愿意自己削。
- 适合：家庭人口多、喜欢动手切水果、当天或次日能吃完的场景。
- 注意：菠萝会压坏其他水果，必须固定位置，别和香蕉放一起。

**3）不太建议：四种全放**
苹果、橙子、香蕉、菠萝全放，看起来丰富，但实际问题多：
- 香蕉容易压伤、催熟其他水果；
- 菠萝太重、带刺、占空间；
- 家庭装容易变成“量大但吃不完”，尤其小家庭。
如果一定要四种全放，建议做小份：苹果2、橙子2、香蕉1、菠萝1个小菠萝或半个处理好的菠萝。

**4）按家庭人数选**
- **2–3 人家庭**：苹果 3 + 橙子 3 + 香蕉 2，或苹果 3 + 橙子 3 + 小菠萝 1。
- **4–5 人家庭**：苹果 4–5 + 橙子 4–5 + 香蕉 2–3。
- **5 人以上/送长辈**：苹果 6 + 橙子 6 + 菠萝 1，香蕉可不放。

**5）团购包装建议**
- 苹果、橙子放底层，抗压；
- 香蕉放最上层，用纸隔开；
- 菠萝单独卡位，别让刺扎到其他水果；
- 如果做“家庭实惠装”，优先 **苹果 + 橙子**，这两样最不容易出错；
- 如果做“丰富尝鲜装”，再加香蕉或菠萝，但数量要少。

**一句话结论：**
家庭团购最推荐 **苹果 + 橙子 + 少量香蕉**；想加菠萝就做 **苹果 + 橙子 + 1个菠萝**。四种全放不是不行，但更适合大家庭或尝鲜装，不适合作为主推家庭款。
