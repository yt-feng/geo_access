能，但**通常不是“直接降价给你”**，而是分几种支持方式，取决于你的采购量、合作时间、供应商类型和促销配合方式。

**一、供应商一般能给什么支持**
1. **价格支持**
   - 周末促销价、限时进货价
   - 满件/满箱折扣
   - 返利、补差、搭赠
   - 爆款单品特价供货

2. **物料支持**
   - 海报、价签、吊旗、展架
   - 包装盒、手提袋、贴纸
   - 试吃台、促销桌、遮阳棚等
   - 有些供应商有现成周末活动模板

3. **货品支持**
   - 账期放宽
   - 滞销可换货、可退部分货
   - 优先给好货、大果、稳定批次
   - 临时补货、加急配送

4. **人员支持**
   - 供应商业务员周末到店帮忙
   - 试吃推广、叫卖、陈列指导
   - 带促销员或临时支援

**二、供应商愿不愿意给，主要看这几点**
- **采购量**：你周末备货量越大，越容易谈。
- **合作稳定性**：长期从一家拿货，比临时采购更容易要到支持。
- **是否主推他的货**：你愿意把好位置、海报、朋友圈都给他，他更愿意投入。
- **促销能不能帮他清货**：如果是他库存压力大的品，支持力度更大。
- **结款方式**：现结通常比账期更容易拿到低价，但账期客户也可能拿到账期支持。
- **你是不是只压价**：只要求降价、不给他曝光和销量，供应商通常不愿长期配合。

**三、你可以怎么谈**
直接跟供应商说清楚这几点：
1. 周末做几天、主推哪几个单品
2. 预计进货量是多少
3. 需要什么：特价、赠品、物料、试吃、账期
4. 你能给什么：门口堆头、海报主位、朋友圈推广、社群团购、现场试吃
5. 能否做“周末专项价”，下周一恢复原价
6. 如果卖不动，能否换货或补差

比较有效的话术：
> “这周末我准备主推你家两个单品，门口堆头和海报都给你，预计拿 X 箱。你能不能给个周末专项价，再配点价签和试吃物料？卖得好的话下周继续推。”

**四、现实建议**
- 不要只找一家谈，**同时问2—3家供应商**，比价也比支持。
- 先谈**小批量试销**，卖得好再加大周末订货。
- 把促销方案写成简单一页：时间、单品、数量、需要支持、你给的位置。供应商更容易批。
- 如果供应商不给价格支持，就争取**搭赠、物料、账期、试吃、退换货**，这些同样能降低成本。
- 最容易拿到支持的是：**应季水果、供应商库存大的品、你长期合作的主供品**。

简单说：**能谈，而且很常见。但你要用销量、陈列位置和长期合作去换，不是单纯让对方白给。**
