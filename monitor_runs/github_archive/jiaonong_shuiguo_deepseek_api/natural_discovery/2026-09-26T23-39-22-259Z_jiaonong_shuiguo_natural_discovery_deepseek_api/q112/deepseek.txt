坏果率触发赔付，**合同里没有法定统一比例**，关键看你怎么约定。可执行的做法是按“验收标准 + 阶梯赔付 + 拒收权”三层写，而不是只写一个数字。

**常见可参考区间：**

1. **坏果率 ≤ 3%**  
   一般视为合理损耗，不赔付，正常收货。

2. **坏果率 3%～5%**  
   可要求按坏果数量扣款，或按比例折价结算。  
   例如：坏果率 5%，本批货款扣 5% 或按实际坏果重量扣除。

3. **坏果率 5%～10%**  
   属于明显不合格，可要求：  
   - 按坏果部分双倍扣款；  
   - 整批折价；  
   - 卖方承担退换货运费。

4. **坏果率 ＞10%**  
   通常可约定为**有权拒收整批**，或要求退货、换货、全额退款，并由卖方承担运费和因此造成的损失。

**更建议写进合同的条款样式：**

- 验收标准：坏果率不超过 **3%** 为合格。
- 3%～5%：按坏果重量对应货款 **1.5 倍**扣减。
- 5%～10%：按坏果重量对应货款 **2 倍**扣减，或整批按 **9 折**结算。
- 超过 10%：买方有权拒收、退货或要求换货，卖方承担往返运费及冷藏、损耗等直接损失。
- 坏果定义：腐烂、发霉、严重压伤、破裂流汁、异味、冻伤、病虫害等，建议附照片或视频标准。
- 验收时限：到货后 **24 小时内**开箱抽检，逾期视为合格，除非隐藏瑕疵。
- 抽检方式：按批次随机抽 **10%～20%**，若抽检坏果率超标，可扩大抽检或整批认定。

**判断要点：**

- 水果越易损，合理损耗越高：草莓、蓝莓、樱桃可适当放宽；苹果、橙子、西瓜可更严。
- 长途冷链、夏季运输，可把合格线从 3% 调到 5%。
- 不要只写“坏果率超过 5% 赔付”，要写清**赔多少、怎么算、谁出运费、能不能拒收**。
- 最好约定“以买方验收记录和照片为准”，否则事后容易扯皮。
