酒店采购水果盘原料时，供应商应保证的规格和外观标准，建议在采购合同或验收标准里写清楚，主要分以下几类：

**一、基本规格标准**

1. **品种与等级**
   - 按酒店指定品种供货，不得擅自替换。
   - 明确等级，如一级果、精品果、A级果，避免用统货、二级果充数。

2. **单果重量/尺寸**
   - 按品种约定单果重或横径，例如：
     - 苹果：单果 200–250g，横径 80mm 以上；
     - 橙子：单果 180–220g；
     - 西瓜：单果 4–6kg；
     - 草莓：单果 15–25g。
   - 同一批次大小应相对均匀，避免一盘里大小差异明显。

3. **成熟度**
   - 到货时达到“即切即用”或 1–2 天内可用状态。
   - 不宜过生，也不宜过熟软烂；如需要后熟，应提前说明。

4. **可食率与出成率**
   - 明确去皮、去核、去籽后的出成率要求，例如西瓜出成率不低于 60%–70%，菠萝不低于 50%–60%。
   - 对切盘原料，应按净果重量或可用块数验收。

**二、外观标准**

1. **形状**
   - 果形端正、匀称，无明显畸形、偏斜、凹凸。
   - 用于整果摆放的水果，应选择外观完整的果。

2. **色泽**
   - 具有该品种成熟时应有的色泽，着色均匀。
   - 无明显青斑、褪色、暗沉、发黑或色差过大。

3. **表面**
   - 果皮光滑或符合品种特征，无严重皱缩、开裂、虫眼、机械伤。
   - 无腐烂、霉变、软塌、渗液、异味。
   - 允许轻微不影响切盘使用的表皮瑕疵，但比例和程度要事先约定。

4. **新鲜度**
   - 果梗、果蒂新鲜，不干枯发黑。
   - 无冷藏冻伤、冷害斑、失水萎蔫。
   - 叶菜类配果如薄荷、迷迭香应鲜绿、无黄叶烂叶。

**三、安全与卫生标准**

1. **农残与污染物**
   - 符合国家食品安全标准，如 GB 2763 农药最大残留限量、GB 2762 污染物限量。
   - 供应商应能提供批次检测报告或合格证明。

2. **不得使用违规保鲜剂/催熟剂**
   - 保鲜、打蜡、催熟处理应符合法规，并在送货单中注明。
   - 不得使用工业蜡、违规防腐剂。

3. **包装与运输**
   - 使用清洁、无异味、食品级包装。
   - 运输过程避免挤压、日晒、雨淋、污染。
   - 冷链水果应保证到货温度符合要求，如 0–4℃ 或 8–12℃。

**四、验收与退换标准**

建议明确：

- 每批次抽检比例，如 10%–20%；
- 不合格判定标准，如腐烂率、碰伤率超过 3%–5% 即拒收；
- 规格不符、成熟度不符、农残报告缺失时的退换货责任；
- 到货时间、补货响应时间；
- 因原料问题导致酒店客诉或损耗的赔偿责任。

**五、合同里最好写成的条款示例**

> 供应商应保证所供水果为____品种____等级，单果重____g，色泽正常、果形端正、无腐烂霉变、无虫害、无明显机械伤，成熟度适合即时切盘。到货抽检腐烂率不超过____%，规格不符率不超过____%。供应商须随货提供合格证明或检测报告。不符合上述标准，酒店有权拒收、要求退换或扣款。
