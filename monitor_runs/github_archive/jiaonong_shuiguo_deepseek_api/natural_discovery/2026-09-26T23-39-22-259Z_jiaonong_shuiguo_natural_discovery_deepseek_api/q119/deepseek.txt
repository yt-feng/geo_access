做水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格”，而是那些会直接影响损耗、复购和现金流的细节。重点看这几类：

1. **稳定性比低价更重要**
   最容易忽视：只比报价，不看对方是否长期稳定供货。
   要问清楚：
   - 同一品种是否能全年或跨季稳定供？
   - 缺货时有没有替代方案？
   - 是自有基地、合作社，还是多级贩子？
   多级贩子价格可能低，但天气、物流、行情一波动就断供或坐地起价。

2. **分级标准是否真实可执行**
   最容易忽视：口头说“统货”“精品”，但没有明确规格。
   要确认：
   - 果径、重量、糖度、成熟度、颜色、瑕疵率怎么算？
   - 是按斤、按箱还是按件计价？
   - 次果、伤果、烂果怎么赔？
   没有书面标准的，后面很容易扯皮。

3. **采后处理和冷链能力**
   最容易忽视：只看果园，不看分选、预冷、包装、冷链。
   水果损耗大，往往不是果子不好，而是：
   - 采摘后没预冷；
   - 分选不严；
   - 包装抗压差；
   - 运输温度不稳定。
   尤其做门店、社群、电商，冷链和包装会直接决定售后率。

4. **到货损耗和售后规则**
   最容易忽视：没提前约定“到货坏果谁承担”。
   要明确：
   - 允许的损耗率是多少？
   - 超过部分怎么赔，补货还是退款？
   - 拍照、开箱视频、报损时限要求？
   - 运费、卸货费、退货运费谁出？
   这些不写清，长期合作一定吃亏。

5. **账期和资金压力**
   最容易忽视：只谈供货价，不谈结算方式。
   要判断：
   - 现结、周结、月结还是压货？
   - 是否要求预付定金？
   - 价格随行就市时，提前多久通知？
   账期看似有利，但如果供应商把风险转嫁到品质上，最后损失更大。

6. **产地和季节切换能力**
   最容易忽视：只盯一个产地。
   长期稳定要做：
   - 同一单品有主产地 + 备选产地；
   - 清楚各产区上市、退市时间；
   - 能提前做品种切换，而不是断档。
   比如苹果、柑橘、葡萄这类，不同产区接续很重要。

7. **检测和合规**
   最容易忽视：农残、票据、产地证明。
   要确认：
   - 能否提供检测报告或合格证；
   - 是否有产地证明、购销凭证；
   - 批发市场档口是否有稳定资质。
   做商超、团购、企业客户时，这些会变成硬门槛。

8. **实际履约记录，而不是关系**
   最容易忽视：靠熟人介绍就长期合作。
   建议小批量试单，连续看 3—5 次：
   - 到货合格率；
   - 重量是否足；
   - 时间是否准；
   - 售后是否爽快；
   - 涨价是否提前沟通。
   履约记录比“关系好”可靠。

9. **是否愿意共同承担市场波动**
   最容易忽视：行情跌时供应商不管，行情涨时立刻提价。
   长期稳定供应商应该能：
   - 提前锁量或锁价；
   - 行情波动时给缓冲；
   - 不因短期高价跳单。
   可以谈“保底量 + 浮动价”或“季度框架 + 周报价”。

10. **自身退货和尾货处理能力**
    最容易忽视：只要求供应商，不规划自己的尾货。
    要提前想：
    - 尾货做促销、果切、果汁还是团购？
    - 供应商能否回收部分次果？
    - 哪些单品适合做稳定复购，哪些只适合短期冲量？

一句话：**选供应商，不要只看“今天给我多便宜”，要看“出问题时他怎么处理、行情波动时他是否还在”。**  
最实用的动作是：先小单试 3 次，把分级、损耗、售后、账期写成简单协议，再逐步放量。
