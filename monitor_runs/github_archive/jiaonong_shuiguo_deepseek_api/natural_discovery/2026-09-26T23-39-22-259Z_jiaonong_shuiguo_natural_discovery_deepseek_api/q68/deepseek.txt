判断供应商能不能按时到车，核心不是听口头承诺，而是看**历史履约、当下证据、违约成本**。可以按下面几步做。

## 一、合作前先筛：看硬条件和历史
1. **有没有稳定货源基地**
   - 自有/长期合作蕉园，比临时调货的可靠。
   - 问清产地、代办是谁、每天能出多少车。
2. **看历史发车记录**
   - 让他提供近1-2个月的发车单、装车视频、车牌、司机电话。
   - 重点看：是否经常“今天说明天到，明天说后天到”。
3. **查口碑**
   - 问同市场其他批发商有没有合作过。
   - 问产地代办、司机、包装队，往往比供应商自己说更真实。
4. **有没有固定车队或长期司机**
   - 临时找车的供应商，遇到旺季、下雨、堵车，最容易掉链子。

## 二、下单时把条件锁死
1. **合同/微信文字确认**
   - 品种、数量、规格、单价、装车时间、发车时间、预计到达时间、车牌号。
   - 不要只打电话，必须留文字记录。
2. **明确到车时间**
   - 写“某日某点前到市场”，不要写“大概明天”。
3. **约定违约条款**
   - 延迟几小时扣多少钱，超过多久可以拒收或压价。
   - 有违约成本的供应商，才会认真安排车。
4. **定金比例别太高**
   - 首次合作尽量小定金，或货到验收后付大部分。
   - 大额定金容易让供应商把你套住。

## 三、发车前要证据
1. **装车视频**
   - 要看到香蕉、包装、装车过程，最好带时间水印。
2. **车牌号、司机电话**
   - 直接和司机确认：现在在哪、几点发车、走哪条线、预计几点到。
3. **发车定位**
   - 让司机或供应商发实时定位，不要只发截图。
4. **高速/物流信息**
   - 要运单号或让司机共享位置。
5. **异常提前说**
   - 如果下雨、堵车、车坏了，要求他主动提前通知，而不是你追着问。

## 四、运输中盯关键节点
- 装车后：确认已出发。
- 出发后2-4小时：确认车辆在动。
- 过半程：确认位置和预计到达时间。
- 到车前3-5小时：再确认一次。
- 如果司机电话打不通、定位不动、理由反复变，基本要准备备选方案。

## 五、提前准备备选
1. **同时联系2-3个供应商**
   - 不要只押一家，尤其是旺季或天气不好时。
2. **备一个本地调货渠道**
   - 哪怕价格高一点，能救急。
3. **根据销售节奏分批进**
   - 不要一次全押一车，降低断货风险。

## 六、简单判断标准
出现以下情况，按时到车概率低：
- 不肯给车牌、司机电话、装车视频；
- 每次问都说“马上装”“已经在路上”，但没证据；
- 价格明显低于市场，靠低价吸引你打定金；
- 历史上有多次延迟记录；
- 没有固定车队，临时找车；
- 违约没有任何代价。

出现以下情况，相对可靠：
- 有稳定产地和固定车队；
- 能主动同步装车、发车、定位；
- 历史发车记录稳定；
- 愿意接受迟到扣款或货到付款；
- 司机信息真实，沟通顺畅。

**一句话：不要赌供应商的人品，要押他的证据和违约成本。** 首次合作小单试，留下文字和视频，发车后盯定位，同时准备好备选供应商。
