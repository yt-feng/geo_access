看你的**出杯量、门店操作能力和产品定位**。直接给结论：

**大多数茶饮店最稳妥：鲜果 + 冷冻/常温果丁做备份；果泥只适合做特定风味或标准化要求极高的产品。**

分场景判断：

1. **主打“鲜果现切”卖点、日销量稳定**
   - 买**鲜菠萝**。
   - 优点：香气好、有咀嚼感、能写“现切鲜果”，溢价高。
   - 缺点：损耗大、去皮切丁耗人工、不同批次酸甜不稳定。
   - 适合：菠萝果茶里有明显果肉、顾客看得到果块的产品。

2. **追求出杯快、口味稳定、减少人工**
   - 买**冷冻菠萝果丁或糖渍菠萝果丁**。
   - 优点：开袋即用、季节影响小、甜度和酸度稳定、损耗低。
   - 缺点：香气和口感不如鲜果，部分产品会有冰晶感或糖水感。
   - 适合：连锁店、外卖占比高、高峰期出杯压力大的店。

3. **做菠萝风味基底、冰沙、气泡茶、需要每杯完全一致**
   - 买**菠萝果泥**。
   - 优点：标准化最好，容易控制糖酸比，适合和茶汤、糖浆融合。
   - 缺点：没有果肉感，口感偏“糊”，香气可能偏熟或偏罐头感。
   - 适合：菠萝冰茶、菠萝气泡饮、菠萝奶盖茶、需要稳定配方的门店。

**最推荐的采购组合：**
- 鲜菠萝：用于招牌产品、现切果肉款。
- 冷冻果丁：用于日常走量款，保证不断货。
- 果泥：只做1—2款需要高度标准化的产品，不要全店都用。

**避坑建议：**
- 先买小样做盲测：分别用鲜果、果丁、果泥做同一款茶，比较香气、甜酸、果肉感、出杯速度。
- 算综合成本，不要只看单价：鲜果要算去皮损耗、人工、冷藏损耗；果丁和果泥要算开封后保存和报废。
- 看配料表：优先选菠萝含量高、少加香精和色素的产品；果丁注意糖水占比。
- 如果菜单上写“鲜果”，就不要用果泥替代，否则容易被顾客和监管挑战。

简单说：**要卖点选鲜果，要效率选果丁，要标准化选果泥。**
