核实水果供应商的“全国配送”，不要只看宣传口径，要把它拆成可验证的履约能力。建议按下面几步做。

**1. 先要求书面配送范围**
让供应商提供明确的覆盖清单，而不是“全国”两个字。至少写清：
- 可配送省份、城市、偏远地区是否排除
- 哪些地区只能发物流自提、不能送货上门
- 冷链覆盖到哪些城市，常温覆盖到哪些城市
- 起送量、最低配送量、加价区域
- 时效承诺：几小时达、次日达、隔日达、还是普通物流 3-5 天

如果对方只口头说“全国都能发”，但不愿意写进报价单或合同，风险较高。

**2. 用具体地址做测试**
不要问“你们能到河北吗”，要直接给真实收货地址测试。比如：
- 省会城市：石家庄某区某街
- 地级市：保定某县
- 偏远地区：云南昭通某县、内蒙古某旗、新疆某市
- 乡镇/村点：某县某镇某村

让对方逐条回复：能否送、几天到、是否冷链、是否加运费、是否送货上门。能覆盖和不能覆盖都要留痕。

**3. 要求提供近期真实运单**
让供应商提供近 1-3 个月的真实配送记录，最好能对应到：
- 发货地
- 收货城市
- 物流单号
- 签收时间
- 是否破损、投诉

注意保护隐私，可让对方脱敏提供。重点看是否真的发过偏远地区，而不是只发过一线城市。

**4. 核实物流合作方**
问清楚合作的是哪类物流：
- 顺丰、京东、中通、圆通等快递
- 冷链专线
- 城市配送车队
- 落地配公司

然后可抽 1-2 个物流单号去官方渠道查轨迹。如果对方说“自己配送”，要问自有车辆数、司机数、冷库位置、分仓位置。

**5. 做小批量试单**
这是最有效的方法。建议选 2-3 个代表性地址：
- 一个核心城市
- 一个普通地级市
- 一个偏远县/乡镇

各下一笔小单，实际测试：
- 是否接单
- 是否按时发货
- 物流轨迹是否真实
- 到货温度、包装、破损率
- 售后响应速度

试单后再决定是否放大采购。

**6. 合同里写清违约责任**
把“全国配送”转化为可执行条款：
- 配送范围附件
- 时效标准
- 冷链温控要求
- 破损赔付比例
- 超区、延迟、无法送达的处理方式
- 虚假覆盖的赔偿或解约条件

**7. 交叉验证**
可以问供应商几个问题：
- 你们在哪些城市有分仓？
- 偏远地区最近发过哪些单？
- 如果临时加急，能不能调车？
- 春节、疫情、台风天怎么保供？

如果回答含糊、前后矛盾，或者只说“没问题”“都能发”，但拿不出运单和覆盖清单，就应按“覆盖能力有限”处理。

**简单判断标准：**
- 只口头承诺，不写范围：不可信
- 能写范围，但不愿试单：谨慎
- 能提供真实运单，且偏远地区试单成功：可初步确认
- 多地址试单稳定、时效和冷链达标：可纳入正式供应商

核心一句话：**把“全国配送”拆成具体地址、具体时效、具体物流、具体赔付，再用小单验证。**
