便利店卖水果，核心逻辑是：**面积越小，越不能按“水果店”思路做，而要按“冲动消费+即时补缺”思路做。** 品类要少、周转要快、损耗要压到最低。下面给一套可执行的方法。

## 一、先定原则：小面积水果只做“三类角色”

1. **引流款**：1-2个，便宜、认知高、走量快  
   例如：香蕉、苹果、应季橘子。作用是把人带进店、带动其他消费。
2. **利润款**：2-3个，单价稍高、毛利好、耐放  
   例如：蓝莓小盒、圣女果、葡萄小串、进口橙。
3. **便利款**：1-2个，切好、洗好、即食  
   例如：果切盒、单根香蕉、小份葡萄。作用是提客单、降决策成本。

**不要做的：**  
- 同一种水果多个规格  
- 低频高价大果（整颗榴莲、整箱车厘子）长期陈列  
- 叶菜类、易压伤类大量铺货  
- 超过7个SKU，小门店基本管不过来

## 二、品类控制：用“3-5-2”结构

按陈列位和销量分配：

- **3成位置**给引流款：香蕉、苹果、应季橘橙
- **5成位置**给周转款：圣女果、葡萄、蓝莓、小番茄、黄瓜
- **2成位置**给利润/便利款：果切、精品小盒、进口果

更简单的做法：  
**总SKU控制在5-8个，单品不超过2个规格。**  
每天只允许1个“新品测试位”，卖不动3天就撤。

## 三、采购控制：少量多次，按天订货

小门店最怕一次采太多。建议：

1. **按销量订货，不按感觉订货**  
   连续记录7天：每个单品每天卖几份、剩几份。  
   订货量 = 前3天平均销量 × 1.1 - 现有库存。

2. **高频水果每天采，耐放水果2-3天采一次**  
   - 每天采：香蕉、葡萄、草莓、蓝莓、果切原料  
   - 2-3天采：苹果、橙子、柚子、猕猴桃  
   - 一周采：预包装果干、罐头类

3. **优先小包装、小规格**  
   例如：  
   - 葡萄按小串卖，不按整箱拆大串  
   - 蓝莓按小盒卖，不散装  
   - 苹果按3个装、5个装  
   - 香蕉按根卖或3根装

4. **和供应商谈“少量配送到店”**  
   宁可单价高一点，也要降低一次进货量。  
   小门店的损耗成本，通常比进货差价更贵。

## 四、损耗控制：从进货到出清全流程

### 1. 收货环节
- 当场拆箱检查，烂果、压伤果直接拒收或折价
- 香蕉、葡萄、草莓重点看：发黑、掉粒、出水
- 收货后立即分级：好果陈列，微伤果做果切或特价

### 2. 陈列环节
- 不要堆太高，小门店用浅筐、小托盘
- 香蕉不要和苹果、梨放一起，乙烯会催熟
- 葡萄、蓝莓冷藏或放阴凉处
- 果切必须冷藏，2小时内未卖完要处理

### 3. 定价与出清
- 正常价卖前2/3时间
- 下午4点后：微瑕果做“特价盒”
- 晚上8点后：果切、熟香蕉、软葡萄打折
- 闭店前1小时：买一送一或员工内购，不留到第二天

### 4. 每日复盘
每天关店前记录：
- 哪个单品剩最多
- 哪个单品损耗最大
- 哪个单品动销最快

连续3天卖不动的，直接停采。

## 五、最实用的执行表

你可以直接用这张表管：

| 项目 | 标准 |
|---|---|
| 水果总SKU | 5-8个 |
| 引流款 | 1-2个 |
| 利润款 | 2-3个 |
| 便利款 | 1-2个 |
| 订货频率 | 高频每天，耐放2-3天 |
| 单次订货量 | 不超过2天销量 |
| 损耗目标 | 控制在5%以内 |
| 出清时间 | 下午4点、晚上8点、闭店前1小时 |
| 淘汰规则 | 连续3天动销差就停 |

## 六、如果只能记一句话

**小便利店水果：少品类、小包装、勤补货、快出清。**  
宁可卖断，不要卖剩。卖断只是少赚，卖剩是直接亏。
