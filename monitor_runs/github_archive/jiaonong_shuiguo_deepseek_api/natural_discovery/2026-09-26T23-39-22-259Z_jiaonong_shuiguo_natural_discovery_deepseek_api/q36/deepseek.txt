结论先说：**多数商超应该“整果为主、切果为辅”组合卖，而不是二选一。** 如果只能选一个，通常整果更适合商超；切果更适合作为补充品类，用来提高客单价、降低损耗、覆盖即时消费人群。

判断逻辑主要看这几个方面：

1. **整果更适合商超的主销场景**
   - 客单价通常更高，按个/按斤卖都容易操作。
   - 耐存放、耐搬运，损耗相对可控。
   - 适合家庭采购、囤货、走亲访友等场景。
   - 商超有称重、收银、货架陈列体系，整果更匹配。

2. **切果更适合补充和增量**
   - 适合上班族、学生、单人家庭、即时食用人群。
   - 能带动冲动消费，尤其是放在收银台、冷柜、水果区端头。
   - 但损耗高、保质期短、对冷链和操作卫生要求高。
   - 如果门店客流不够、周转不快，切果很容易变成报损。

3. **关键看门店类型**
   - **社区商超/大卖场**：整果为主，切果少量试销。家庭采购多，整果更稳。
   - **写字楼/商圈便利店**：切果占比可以更高，因为即时消费强。
   - **生鲜精品超市**：整果+切果组合，切果做品质感和便利性。
   - **低客流小店**：不建议大量上切果，除非有稳定预定或外卖渠道。

4. **更可执行的组合建议**
   - 整果占菠萝品类 **70%—85%**，切果占 **15%—30%**，按客流调整。
   - 整果分规格：小果做低价引流，大果做家庭装，礼盒做高毛利。
   - 切果只做 **1—2 个规格**：即食杯/盒装，避免 SKU 过多。
   - 切果必须冷链陈列，标注切配时间，当天未售完及时折价或报损，不要第二天继续当鲜切卖。
   - 用整果做价格形象，用切果做便利和利润补充。

5. **一个简单判断公式**
   - 如果门店日均客流高、写字楼/年轻人多、有冷柜和外卖：切果可以做到 **20%—30%**。
   - 如果门店以家庭采购为主、客流一般、冷链弱：切果控制在 **10%以内**，甚至先不做。
   - 如果菠萝经常滞销、整果损耗大：可以少量切果消化，但前提是能当天卖完。

所以，最佳答案不是“整果好还是切果好”，而是：**整果做基本盘，切果做增量；先小批量测试切果周转，再决定占比。**
