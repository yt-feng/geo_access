小水果店做附近小区团购，水果供应商最好能支持这几类服务，按重要性排序：

1. **稳定供货与品质分级**
   - 能按团购订单量稳定供货，不缺斤少两。
   - 支持按规格分级，比如大果/中果、净重/毛重，避免售后扯皮。
   - 能提供当日或次日采摘、批次日期的信息。

2. **灵活起订量与补货**
   - 起订量低，适合小水果店先试团。
   - 支持临时加单、补货、少批量多频次配送。
   - 爆款缺货时能及时替换或推荐替代品。

3. **配送与分拣支持**
   - 能送到店里，或直接按小区团购点分拣配送。
   - 支持按团购订单分袋、贴标签、按小区/楼栋分装。
   - 配送时间能配合团购截单和次日自提节奏。

4. **价格与账期支持**
   - 给团购专供价，而不是普通批发价。
   - 支持阶梯价：量越大价格越低。
   - 能接受短期账期、押金少、或者先款后货灵活结算。

5. **售后与损耗承担**
   - 坏果、烂果、压伤果能包赔或补发。
   - 明确损耗比例和理赔时限，比如签收后24小时内拍照理赔。
   - 不把售后压力全推给小店。

6. **包装与物料支持**
   - 提供团购用的纸箱、网套、保鲜袋、冰袋等。
   - 能印小区团购标签、二维码、自提点信息。
   - 包装能承受短途配送和居民自提。

7. **选品与营销配合**
   - 能提供适合团购的爆款单品、应季水果组合。
   - 支持一件代发、预售、拼团套餐。
   - 提供图片、文案、价格建议，方便小店在群里发团。

8. **数据与对账**
   - 每批货有清晰对账单：品名、规格、数量、单价、金额。
   - 支持微信/表格/小程序下单，减少人工错单。
   - 退货、补货、扣款记录清楚。

9. **季节性应急能力**
   - 节假日、雨季、高温天能保供。
   - 爆单时能加班分拣和配送。
   - 出现天气导致到货延迟时，能提前通知并给方案。

简单判断供应商是否适合：
- 能不能小批量试单？
- 坏果谁赔、多久赔？
- 能不能按小区分拣贴标？
- 团购价是不是比批发价更有优势？
- 爆单时能不能加人加车？

对小水果店来说，最关键的其实不是“价格最低”，而是：**供货稳、损耗有人担、分拣配送省事、售后不扯皮**。这四点能解决，小区团购才容易长期做。
