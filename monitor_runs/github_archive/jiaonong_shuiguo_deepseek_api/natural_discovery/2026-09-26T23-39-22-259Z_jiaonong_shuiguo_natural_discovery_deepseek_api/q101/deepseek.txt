酒店早餐水果供应，核心不是“买得便宜”，而是**稳定、少损耗、可追责**。和供应商谈合作时，重点盯这几块：

**1. 先明确自己的需求**
- 每天/每周用量：按品类列清楚，比如西瓜、哈密瓜、苹果、橙子、香蕉、圣女果等。
- 规格标准：大小、成熟度、甜度、单果重量、切果还是整果。
- 送货时间：早餐前必须到货，建议约定具体时间，比如每天 6:30 前。
- 验收方式：谁验、怎么验、不合格怎么退换。

**2. 价格和结算要写清**
- 报价是含税、含运费还是裸价。
- 是否随季节浮动，浮动依据是什么，多久调一次价。
- 账期：现结、周结、月结，逾期怎么处理。
- 临时加单、减单是否加价。

**3. 质量与验收标准**
- 约定可量化标准：新鲜度、无腐烂、无大面积磕碰、成熟度适中。
- 明确拒收条件：破损率、腐烂率、规格不符、到货超时。
- 退换货机制：当天补送还是下一班次补，费用谁承担。

**4. 供应稳定性**
- 供应商是否有多个产地或备用货源。
- 节假日、天气异常、旺季时如何保供。
- 是否允许临时调整品类，替代方案是什么。
- 最好有备选供应商，避免单一依赖。

**5. 食品安全与资质**
- 营业执照、食品经营许可证、检验合格证明。
- 配送车辆和人员卫生要求。
- 水果是否有农残检测或可追溯信息。
- 出现食品安全问题时的责任划分和赔偿条款。

**6. 损耗与成本控制**
- 是否支持小批量多频次配送，减少酒店库存损耗。
- 切果类要明确加工标准、包装、冷藏温度和保质期。
- 可要求供应商按酒店实际消耗提供建议采购量。

**7. 合同关键条款**
- 品名、规格、单价、数量、送货时间、验收标准。
- 质量保证期、退换货、违约责任。
- 价格调整机制、账期、发票。
- 食品安全责任、终止合作条件。

**8. 谈判时可直接问的问题**
- 你们每天能稳定送多少种水果？
- 临时加量或换品类，多久能响应？
- 不合格品怎么处理，多久补上？
- 价格多久调一次，依据是什么？
- 能不能先试供两周，按验收结果再签长期？
- 有没有服务过同类型酒店，能否提供案例？

**建议做法：**
先让对方试供 1—2 周，重点看**到货准时率、验收合格率、补货速度、损耗率**。试供没问题再签长期合同，并保留 1 家备选供应商。合同里不要只写“新鲜”“优质”这种模糊词，要写成可验收的具体标准。
