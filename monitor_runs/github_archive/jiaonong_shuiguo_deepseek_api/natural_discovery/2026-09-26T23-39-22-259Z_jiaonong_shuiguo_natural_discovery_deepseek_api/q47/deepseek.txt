茶饮店用香蕉，核心不是“买最熟的”，而是**按用途分批控制熟度**。香蕉从青到过熟变化很快，采购和验收时要按你要做的产品类型定标准。

### 1. 先按用途定熟度
- **做香蕉奶昔、冰沙、奶茶：** 用**7～8成熟**最好。果肉有香蕉香，但不过软、不发酵，打出来不会太甜腻或发黑。
- **做香蕉泥、香蕉酱、甜品夹心：** 用**8～9成熟**。甜度高、香气足、容易压泥。
- **做装饰切片、果盘：** 用**6～7成熟**。太熟切片易烂，太生涩口。
- **做烘焙、香蕉面包、香蕉蛋糕：** 可以用**9成熟到表皮发黑但果肉未坏**的香蕉，甜度和香气最足。

### 2. 采购验收标准
- **看表皮：**  
  - 7成熟：黄底带少量青肩。  
  - 8成熟：基本全黄，无青肩。  
  - 9成熟：全黄，出现少量黑点。  
  - 过熟：大面积黑斑、渗汁、有酒味，不要用于饮品。
- **摸硬度：**  
  - 适合饮品：捏起来有弹性，不硬也不塌。  
  - 适合果泥：微软，能轻松压扁。  
  - 太软、出水：容易发酵，不建议采购。
- **看果柄和果身：**  
  - 果柄发黑、发霉、果身裂口渗汁的拒收。  
  - 有酒味、酸味、发酵味的拒收。

### 3. 采购策略
- **不要一次全买熟香蕉。**  
  建议按当天用量买“7～8成熟”，再留少量“9成熟”当天用。
- **分批采购：**  
  例如每天用30斤，可以买20斤7～8成熟、10斤9成熟；9成熟的当天优先做泥或甜品。
- **按销量预估：**  
  香蕉饮品销量不稳定时，宁少勿多。香蕉熟得快，损耗通常比柑橘、苹果高。
- **选择规格：**  
  饮品店更适合中等大小香蕉，单根果肉约80～120克，方便标准化。太大或太小都不利于控成本。

### 4. 到店后的熟度管理
- **未熟香蕉：** 常温阴凉处催熟，不要放冰箱。可和苹果、梨放一起加速成熟。
- **已熟香蕉：** 尽快使用；若当天用不完，可去皮切段冷冻，做冰沙奶昔。
- **接近过熟：** 立即做香蕉泥、香蕉酱或烘焙，不要继续放着。
- **冷藏注意：** 香蕉整根冷藏表皮会变黑，但果肉短期仍可用；最好去皮密封冷冻或冷藏。

### 5. 简单可执行标准
给店员一张验收卡：
- **青肩明显：** 拒收或放几天再用。
- **全黄无黑点：** 适合奶昔、切片。
- **少量黑点：** 适合果泥、甜品。
- **黑斑多、发软渗汁：** 拒收。
- **有酒味/酸味：** 拒收。

一句话：**饮品用7～8成熟，果泥甜品用8～9成熟，烘焙可用9成熟；采购时按用途分批买，熟香蕉当天优先消耗，避免整批过熟造成损耗。**
