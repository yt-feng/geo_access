判断水果供应商靠不靠谱，核心不是看他嘴说得多好，而是看“稳定性、品质一致性、账期和损耗承担”。香蕉和菠萝尤其明显：香蕉催熟、损耗、到货成熟度很关键；菠萝看产地、成熟度、黑心、烂心、重量。你可以按下面这套去筛。

**1. 先看货源和季节稳定性**
- 香蕉：问他主要从哪来，云南、广西、海南、老挝、缅甸、菲律宾、厄瓜多尔等。能不能全年稳定供，淡季怎么补。
- 菠萝：广东徐闻、海南、云南、福建、台湾地区、菲律宾等都常见。问清产季切换，别到断季就涨价或没货。
- 靠谱供应商会主动说：现在什么产地、什么规格、什么价格、能供多久。

**2. 看分级和规格是否清楚**
香蕉别只说“好香蕉”，要能说清：
- 每箱多少斤、几把、每把几根
- 条长、粗度、青熟度
- 是青蕉还是催熟蕉
- 是否允许轻微青斑、 mechanical damage

菠萝要问：
- 品种：金钻、巴厘、台农、凤梨等
- 单果重量范围，比如 1.2–1.5 斤、1.5–2 斤
- 成熟度：青果、黄果、几成黄
- 是否包黑心、烂心、水心

**3. 做“小批量试单”，别一上来压大货**
连续试 3–5 次，比一次大货更能看出问题。
- 第一次：少量拿，验到货成熟度、损耗、口感。
- 第二次：同规格复购，看是否一致。
- 第三次：故意在旺季/雨天/节假日前后拿，看供应稳不稳。
重点记录：
- 到货损耗率
- 能卖几天
- 顾客投诉
- 实际出成率

**4. 看损耗承担和售后**
这是最关键的。
- 香蕉：到货太生、太熟、催熟不匀、断把、发黑，谁承担？
- 菠萝：黑心、烂心、空心、果小，能不能补？
- 是“当面验货后不认”，还是“到店 24 小时内可报损”？
- 补货是补钱、补货，还是下次抵扣？
靠谱的通常有明确规则，不靠谱的常说“水果都这样”。

**5. 看价格是否透明**
不要只比单价，要算“到手可卖成本”：
- 进货价 + 运费 + 损耗 + 催熟费 + 人工 = 真实成本
- 香蕉要看“催熟后能卖几成”
- 菠萝要看“削皮后出肉率”
有的供应商单价低，但损耗高、规格虚，最后更贵。

**6. 看配送和账期**
- 能不能按你营业时间送？
- 临时加货、退换货响应快不快？
- 是否支持压一批结一批、周结、月结？
- 迟到、少货、串货怎么处理？
长期合作，配送稳定比便宜几毛更重要。

**7. 看他在同行里的口碑**
问周边水果店、批发市场熟人：
- 谁家香蕉催熟稳定
- 谁家菠萝黑心少
- 谁家售后不扯皮
但别只信一个人，至少问 3 家。

**8. 一个简单的靠谱供应商标准**
满足以下多数，基本可以长期合作：
- 货源清楚，产季切换有预案
- 规格分级明确，不玩模糊话
- 连续 3 次到货品质稳定
- 损耗有明确承担比例
- 售后响应快，不推责
- 价格随行就市，但不大起大落坑熟客
- 配送准时，少货能补

**9. 建议你实际这样做**
1. 先找 3 家候选供应商。
2. 每家少量试单 2–3 次，香蕉和菠萝分开测。
3. 建一张表：供应商、到货日期、规格、进价、损耗率、售后态度、回本天数。
4. 连续合作 1 个月后，选“综合到手成本最低、最省心”的 1–2 家主供，另留 1 家备用。
5. 不要只绑一家，香蕉和菠萝可以分开找更专业的供应商。

**一句话判断：**
能长期稳定给你“规格一致、损耗可控、售后认账”的，才叫靠谱；只会在拿货时便宜、出问题就推责的，再便宜也别长期用。
