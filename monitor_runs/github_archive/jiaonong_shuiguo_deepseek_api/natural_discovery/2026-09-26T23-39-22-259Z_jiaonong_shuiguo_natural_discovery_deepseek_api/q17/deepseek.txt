控制水果新鲜度和库存，核心是做到“以销定进、快进快出、分级处理”。给你一套可直接执行的做法：

1. **先定品类结构，不要什么都进**
   - 引流款：香蕉、苹果、橘子、梨，耐放、周转快，占销量大头。
   - 利润款：草莓、葡萄、芒果、车厘子等，少量高频补。
   - 尝鲜款：应季小众水果，只做小批量测试。
   - 原则：耐放水果占60%-70%，易损水果占20%-30%，尝鲜款不超过10%。

2. **按销量定进货量，不要凭感觉**
   - 记录每天每个单品的销量，连续记2周。
   - 进货量 = 过去3-7天日均销量 × 1.2-1.5（周末/节假日可上调）。
   - 新品首单只进1-2天预估量，卖得好再补。
   - 易坏水果如草莓、葡萄、桃子，按“半天到1天销量”进。

3. **固定补货节奏**
   - 叶菜、草莓、葡萄等：每天早市补一次，下午看情况少量补。
   - 苹果、橙子、梨等：2-3天补一次。
   - 香蕉：少量多次，避免一次性堆太多。
   - 补货前先看库存和天气，雨天、降温天少进。

4. **收货就要控品质**
   - 到货当场检查：烂果、压伤、过熟、规格不达标直接拒收或折价。
   - 香蕉、芒果等后熟水果，按成熟度分开放，先卖熟的。
   - 易损水果不要堆高，用浅筐、分层摆放。

5. **陈列和库存管理**
   - 先进先出：新货放里面，旧货放外面先卖。
   - 一天多次理货，挑出软果、烂果，避免传染。
   - 轻微瑕疵果可做“特价区”，不要和正价果混放。
   - 冷藏柜、风幕柜温度按品类调，草莓、葡萄、切果类要低温。

6. **用价格和促销快速清库存**
   - 当天卖相下降的，下午及时打折，不要等到烂。
   - 组合销售：香蕉+苹果、草莓+蓝莓做果盒。
   - 临近闭店做“限时特价”，比第二天扔掉划算。
   - 切果、果汁、果捞是消化临期水果的好办法，但要保证卫生。

7. **设定损耗红线**
   - 水果损耗率一般控制在5%-10%以内，易损单品可到10%-15%。
   - 每天记录损耗，哪款总烂就减少进货或换供应商。
   - 连续3天卖不动的单品，立即停进或减量。

8. **简单库存预警**
   - 给每个单品设最低陈列量和最高库存量。
   - 低于最低量：补货。
   - 高于最高量：促销或停进。
   - 易坏品当天清，耐放品不超过3-5天库存。

9. **和供应商谈好退换**
   - 易损水果尽量争取“坏果包赔”或“卖不完可换”。
   - 固定1-2个稳定供应商，比临时拿货更能控制品质。
   - 旺季提前锁量，淡季减少采购。

一句话总结：**耐放水果做基本盘，易坏水果小批量高频补，每天理货、先进先出，卖不动就降价或加工，连续不好卖就停进。** 这样能明显减少压货和损耗。
