水果店遇到坏果，结算和赔付要看**货是谁选的、坏在哪个环节、有没有约定**。通常按下面几种情况处理：

**1. 到货验收时当场发现坏果**
- 先拍照/拍视频，保留到货单、聊天记录、称重记录。
- 能挑出来的坏果，按实际坏果数量从本次货款里扣。
- 常见做法：坏果直接退货，不计入结算；或者按坏果重量/件数扣款。
- 如果坏得多，可以整批拒收或要求补发。

**2. 到货时没发现，事后才坏**
- 如果是供应商发货时就存在内伤、催熟过度、冷链断裂，责任在供应商，可以要求扣款、补货或赔偿。
- 如果是自己存放不当、温度不对、挤压、放置太久，通常不能要求供应商赔。
- 水果是易腐品，很多批发市场默认“出门不认”，所以关键看你们事先怎么约定。

**3. 长期合作供应商**
- 最好在合作前说清楚：
  - 坏果率在多少以内由水果店承担；
  - 超过多少由供应商补货或扣款；
  - 到货后几小时内可反馈；
  - 生鲜损耗、次果、烂果怎么计价。
- 常见约定是：**坏果率3%—5%以内自担，超过部分供应商补货或按比例扣款**。具体比例要看品类和行业惯例，不是统一标准。

**4. 结算方式**
常见有这几种：
- **直接扣款**：本次货款减去坏果金额。
- **补货**：下批货补同等数量或金额。
- **换货**：坏果退回，换好果。
- **折价**：坏果按低价处理，比如按半价或成本价结算。
- **月结抵扣**：如果月结，就在当月账单里扣。

**5. 实操建议**
- 收货时当场开箱抽查，最好拍视频。
- 坏果单独放，称重、计数、拍照。
- 第一时间发给供应商，别拖太久。
- 沟通时直接说：这批坏了多少斤/多少件，要求扣款还是补货。
- 如果供应商不认，先看合同、订单、聊天记录里有没有质量约定。
- 金额大且协商不成，可以找批发市场管理方、平台客服或按合同走法律途径。

一句话：**能证明是供应商责任的坏果，就按实际损失扣款、补货或退货；不能证明的，通常自己承担。最稳妥的是合作前把坏果率、反馈时限和赔付方式写清楚。**
