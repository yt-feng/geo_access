会，但影响多大取决于你打算怎么卖。

**结论先说：**
- 如果是**散卖/称重卖**：大小不一影响相对小，顾客会挑，但能卖完，只是损耗和挑剩概率高。
- 如果是**整箱卖/送礼/电商发货**：影响很大，大小不一会显得不专业，容易被压价、退货、差评。
- 如果是**做果切、榨汁、烘焙原料**：影响很小，甚至更看重成熟度和成本。

**具体影响点：**
1. **卖相差**：大小混杂会让顾客觉得“档次低”，同一箱里小的容易被剩下。
2. **定价难**：大的和小的成本一样，但顾客只挑大的，小的最后可能降价或损耗。
3. **损耗高**：挑剩的小果、青果、碰伤果，最后往往只能低价处理。
4. **客诉风险**：整箱卖时，顾客会觉得“图片/样品是大果，收到却有小果”，容易纠纷。
5. **周转慢**：如果同一批货大小差异明显，销售速度会被小果拖慢。

**可执行建议：**
- **采购时**：尽量按规格分级采购，比如大果、中果、小果分开，别混装太严重。
- **销售时**：
  - 散卖：大小分开摆，大的定高价，小的做特价或搭配促销。
  - 整箱：明确标注规格和允许误差，最好统一大小。
  - 加工：小果、熟果拿去做果切、奶昔、香蕉干，减少损耗。
- **如果已经进了混装货**：
  - 先挑出大果做利润款；
  - 中果正常卖；
  - 小果做特价、搭配酸奶/果切套餐，或者联系果汁店、烘焙店批量走货。

**简单判断：**
- 你卖的是“水果商品” → 大小不一影响大。
- 你卖的是“原料/加工品” → 影响小。
