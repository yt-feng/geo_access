香蕉、菠萝、苹果的组合促销，核心不是“都便宜”，而是用 **高频刚需 + 中频冲动 + 高感知价值** 拉开角色，让顾客从“只买香蕉”变成“顺手带一篮”。

**一、先定角色**
- 香蕉：引流品。价格敏感、购买频次高，适合做低价锚点，但别单独降太狠，否则只拉销量不拉客单。
- 菠萝：利润/冲动品。香气强、现场感强，适合切盒、试吃、搭配卖。
- 苹果：结构品。家庭常备、耐储存、客单贡献稳，适合做组合里的“压舱石”。

**二、三种可落地组合**

1. **9.9/12.9元“果切尝鲜盒”**
   香蕉1根 + 菠萝1/4个 + 苹果1个，切好装盒。  
   作用：降低尝试门槛，把菠萝和苹果塞进香蕉客的购物篮。  
   注意：必须现场切、当日清，标清时间，避免损耗和食安问题。

2. **“家庭一周果篮”满减组合**
   香蕉1把 + 菠萝1个 + 苹果4个，原价合计后减3-5元，或定价19.9/29.9。  
   作用：直接拉高客单，适合家庭客。  
   注意：苹果选中小果，菠萝选标准果，香蕉给足量，让顾客觉得“够一周”。

3. **“买香蕉+1元换购”**
   买香蕉满5元，加1元换购菠萝切盒或苹果1个。  
   作用：用低门槛加购把客单从5元拉到6-10元。  
   注意：换购品限量、限时段，制造“顺手就加”的感觉。

**三、陈列和话术**
- 三品放同一端头或同一岛台，按“香蕉引流—菠萝试吃—苹果组合”动线排。
- 价签写清楚：单买价、组合价、省多少。
- 话术用：“香蕉今天便宜，加1元带个苹果/菠萝盒，回家直接吃。”
- 试吃只试菠萝，因为菠萝转化最强；苹果靠“耐放、全家吃”说服。

**四、判断是否有效**
看三个数：
- 客单价是否提升：组合占比、加购率。
- 毛利是否守住：别用苹果和菠萝给香蕉陪跑，组合价要算清毛利。
- 损耗是否可控：菠萝切盒当天清，香蕉熟度分时段打折，苹果可做次日组合。

**五、避坑**
- 不要三个都做特价，否则只是整体降价。
- 不要组合里放太多香蕉，香蕉易熟、损耗大。
- 不要只做“便宜”，要做“省事、够吃、搭得好”。

如果只选一个先试：**买香蕉满5元，加1元换购菠萝切盒**。门槛低、转化快、最能拉客单。
