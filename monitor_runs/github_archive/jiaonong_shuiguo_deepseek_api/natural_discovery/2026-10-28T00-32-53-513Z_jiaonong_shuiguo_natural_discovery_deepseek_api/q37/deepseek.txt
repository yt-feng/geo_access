商超会员日水果活动，供应商提前配合的重点是把“货、价、陈列、履约、风险”五件事在活动前锁定。可按下面清单推进：

**1. 活动前7–10天：确认方案与备货**
- 与商超确认活动门店、档期、活动形式（折扣/买赠/会员价/满减）、预估销量和分店分配量。
- 锁定活动SKU、规格、等级、包装方式，避免临时换品。
- 按预估销量上浮10%–20%备货，热门单品准备替代货源。
- 确认价格：供货价、活动价、费用承担比例、损耗补贴、返利和结算方式，形成书面确认。

**2. 活动前5–7天：品质与包装准备**
- 提前做产地/批次筛选，明确成熟度标准，活动首日不能卖“催熟不够”或“过熟”的货。
- 按商超要求完成分级、称重、贴标、预包装，减少门店二次加工。
- 包装箱、托盘、保鲜袋、冰袋、标签等物料提前到店或到仓。
- 对易损水果（草莓、葡萄、水蜜桃等）做防压、防震、冷链方案。

**3. 活动前3–5天：物流与到店计划**
- 提交分店到货计划：到货时间、车次、数量、联系人，避开商超收货高峰。
- 确认冷链车、周转筐、收货预约和卸货人力。
- 首日货建议提前一天或清晨到店，留出验货和补货时间。
- 准备活动期间的紧急补货通道，明确补货响应时限（如2–4小时/次日达）。

**4. 活动前1–2天：陈列与门店配合**
- 按商超陈列图提供堆头、端架、保鲜道具和POP素材；价格牌、活动标识提前审核。
- 安排促销员/理货员到店，明确负责门店、到岗时间和补货频次。
- 与门店确认试吃、切果、称重台、垃圾清理等责任分工。
- 做一次首日到货预演，确认收货、上架、价签一致。

**5. 活动期间：履约与品控**
- 首日安排专人巡店，重点看库存、品质、价签、陈列饱满度。
- 建立日报：销量、库存、损耗、缺货、客诉，及时调整补货。
- 对临期或品相差的货提前制定折价/调拨/退回规则，避免门店自行处理引发争议。
- 客诉处理明确对接人和响应时限。

**6. 活动后：对账与复盘**
- 活动结束48小时内完成退货、损耗、费用和销量对账。
- 复盘动销率、损耗率、缺货率、客诉，作为下次备货依据。

**最关键的三项提前锁定：**
1. **书面确认活动价、费用承担和损耗规则**，避免事后扯皮；
2. **首日货提前到店并留足验货时间**，会员日最怕首日断货或品质翻车；
3. **明确补货响应时限和责任人**，活动期间销量波动大，补货慢会直接损失销售。

如果是具体品类（如叶菜类、浆果类、进口水果）或具体活动形式，可以进一步细化到备货比例和冷链要求。
