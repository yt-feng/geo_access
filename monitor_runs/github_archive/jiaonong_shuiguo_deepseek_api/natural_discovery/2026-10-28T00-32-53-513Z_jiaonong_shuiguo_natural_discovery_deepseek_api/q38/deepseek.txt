大型超市对水果供应商的要求，核心是“食品安全可追溯 + 冷链不断链 + 稳定供货 + 异常可召回”。可按下面清单判断供应商是否合格。

## 一、食品安全能力

1. **合法资质与主体合规**
   - 营业执照、食品经营/生产相关许可（按业态）、产地证明或供货证明。
   - 若为进口水果：入境货物检验检疫证明、报关单等。
   - 农药经营/使用来源合规，不得采购禁限用农药产品。

2. **产地与种植端管控**
   - 有固定基地或稳定合作基地，能提供基地清单、面积、品种、采收期。
   - 有农业投入品（农药、化肥）采购和使用记录。
   - 推行安全间隔期管理，采收前不得违规用药。
   - 优先具备良好农业规范认证，如GAP；有机、绿色食品等认证需真实有效。

3. **检测与验收能力**
   - 每批次能提供农残快速检测或第三方检测报告，检测项目覆盖高风险农药。
   - 具备入场验收标准：外观、成熟度、腐烂率、机械伤、异味、温度。
   - 对高风险品种（叶菜类水果如草莓、葡萄、柑橘等）提高抽检频次。
   - 能配合超市做飞行检查、第三方审核。

4. **追溯与记录**
   - 批次可追溯：基地—采收—加工—仓储—运输—门店，至少能追到批次和日期。
   - 保留进货查验、检测、销售、不合格品处理记录。
   - 包装标签规范：品名、产地、批次、日期、供应商信息。

5. **加工分选与卫生**
   - 分选包装场所清洁，防虫防鼠，人员健康证与卫生操作规范。
   - 清洗、打蜡、催熟等处理若涉及，须符合法规并有记录。
   - 不得使用非法保鲜剂、染色剂、违规催熟剂。

6. **不合格品与召回**
   - 有不合格品隔离、退货、销毁流程和记录。
   - 能配合超市在食品安全事件中快速召回、提供批次流向。
   - 有食品安全事故应急预案和责任人。

## 二、物流与冷链能力

1. **冷链设施**
   - 具备预冷能力，采收后尽快预冷。
   - 冷藏车/保温车数量与温控记录，运输温度符合品种要求。
   - 仓库分区：常温、冷藏、催熟、隔离区，避免交叉污染。

2. **温控与时效**
   - 运输全程温度可记录、可查询，异常能报警。
   - 按品种设定温区，如浆果类通常需更低温度，香蕉等需催熟温控。
   - 从采收、分选、装车到门店的时限可控，减少断链。

3. **包装与装载**
   - 使用透气、防压、防潮包装，周转筐清洁消毒。
   - 装车前检查车辆卫生、温度、异味；不得与化学品、生鲜肉类混装。
   - 堆码规范，防止挤压和机械伤。

4. **配送与门店交接**
   - 能按超市要求定时定量配送，支持多门店、小批量、高频次。
   - 交接时提供温度记录、检测报告、送货单，门店可验收。
   - 有缺货、延迟、质量异常的替代和补货方案。

5. **信息化与追溯**
   - 仓储运输系统能记录批次、温度、出入库。
   - 出现质量问题时能定位同车、同批次货物。

## 三、稳定供货与运营能力

- 多产地或多基地布局，降低单一产区灾害风险。
- 有分级分选能力，能按超市标准稳定供货。
- 有损耗控制、库存周转和旺季保供方案。
- 有食品安全管理员和对接超市的质量负责人。

## 四、超市审核时重点看什么

可要求供应商提供：
1. 资质证照与基地清单；
2. 最近批次检测报告和农残检测记录；
3. 冷链车辆温度记录样本；
4. 追溯演练记录：任选一批能否追到基地和门店；
5. 不合格品处理和召回预案；
6. 现场审核：分选场、冷库、车辆卫生。

**判断标准**：能提供批次检测、全程温控记录、可追溯批次、异常召回流程，且现场卫生和冷链设施达标，才算具备大型超市供应商的基本能力。仅有货源、没有检测和冷链记录的供应商，不适合直接进入大型超市供应体系。
