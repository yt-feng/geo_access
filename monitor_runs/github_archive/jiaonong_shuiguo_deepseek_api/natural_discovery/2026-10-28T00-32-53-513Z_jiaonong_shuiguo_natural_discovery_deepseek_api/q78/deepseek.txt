# 香蕉和菠萝的售后控制

高损耗品做社区团购，核心不是“售后兜底”，而是 **把损耗前置到可预期的范围内，再把售后规则定得让双方都不纠结**。下面按品类分开说。

## 香蕉

香蕉的问题集中在两头：**催熟不均** 和 **到货后集中变黑**。

**收货环节**
- 要青蕉或七成熟，不要熟蕉。熟蕉路上就是损耗。
- 到货后拆箱通风，不要闷在塑料袋里，乙烯积聚会整箱一起黄。
- 按到货时间分两批放：一批当天自提，一批留作次日或做“熟蕉特价”，避免全压到同一时点变成售后集中爆发。

**交付环节**
- 自提点写清“当天取走，隔夜不保熟”。香蕉在自提点放一晚再拿，变黑的责任很难界定，这条要提前说。
- 提货时提示：青的放常温，别放冰箱。很多人香蕉一冷藏就黑，然后来找售后。

**售后规则**
- 只对“切开/剥开后果肉发黑、有异味”赔，表皮黑点不算。香蕉表皮有黑点很常见，按表皮黑点赔会赔穿。
- 单根香蕉不单独售后，按整把或整份处理，否则一根一根报，人工成本比香蕉贵。

## 菠萝

菠萝的问题主要是 **熟度不均** 和 **内心黑心/水心**，外观看不出来。

**收货环节**
- 按“闻香 + 按压微弹”判断，不要只按颜色。青皮也可能熟，黄皮也可能生。
- 到货后抽检切开 2–3 个，看有没有黑心。整批有问题就整批转做“现切菠萝”或特价处理，不要照常发。
- 菠萝怕闷怕压，堆放别超过两层。

**交付环节**
- 明确“不代削皮”。代削皮一旦削开发现黑心，责任和损耗都归团方，不如让用户自己开。
- 提示用户：闻着香、按着微弹就是熟的；不熟的可放两天，不要直接冷藏。

**售后规则**
- 只对“切开后黑心、水心、异味”赔，外观青黄不一不赔。菠萝外观差异大，按外观赔争议无穷。
- 要求用户提供切开照片，一张图定责，减少来回沟通。
- 单次赔付设上限，比如按单个菠萝金额赔，不做整单退款。

## 通用机制

1. **预售 + 定量**：香蕉菠萝按预估量收单，宁少勿多。剩货比缺货贵。
2. **收货当天抽检**：每批抽 2–3 个切开/剥开，有问题当场决定整批走向（正常发 / 特价 / 现切 / 报损），不要等售后上门再处理。
3. **售后窗口短**：当天或次日中午前报，过期不候。高损耗品拖久了，证据和情绪都不可控。
4. **统一话术**：把“什么赔、什么不赔、怎么报”写成一张图，跟团页面就放，减少一对一解释。
5. **留损率预算**：香蕉菠萝按 5%–8% 预留售后/报损额度，算进定价，而不是事后硬扛。

一句话：**外观不赔、切开才赔、当天才赔、单件封顶**，配合收货抽检和定量预售，高损耗品的售后就能从“救火”变成“可算”。
