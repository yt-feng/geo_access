采购菠萝时，损耗主要来自“太生卖不动”和“太熟放不住”两头。比较合适的做法是：**按销售速度分级采购，主推七八成熟的菠萝，少量配一点九成熟的现切/促销，熟度判断以“底部香气+果皮颜色+手感+叶冠”综合看，不要只看颜色。**

**一、采购熟度怎么定**

- **主销整果：七八成熟最合适**
  - 果皮从底部开始由青转黄，约1/3～1/2转黄；
  - 底部有淡淡菠萝香，不刺鼻；
  - 手按果身略有弹性但不软塌；
  - 这样的货耐放，摆2～3天能自然转熟，适合大部分顾客。
- **快销/现切/促销：九成熟**
  - 果皮大部分转黄甚至带橙黄；
  - 底部香气明显；
  - 按压微软；
  - 适合当天切开卖或做促销，不建议压货。
- **尽量少采：全青或过熟**
  - 全青果：香气弱、酸度高，顾客买回去可能放坏也不甜；
  - 过熟果：底部发软、有酒味、汁水外渗，损耗会很快。

**二、现场判断的四个动作**

1. **闻底部**：菠萝的香气主要从底部散发。淡香=可放；浓香=快熟；酒味/酸味=过熟或开始坏。
2. **看转黄位置**：从底部往上转黄是正常规律。底部黄、上部青，通常比通体青更适合采购。
3. **按果身**：轻按有弹性、不硬如石、不软塌。局部软陷的要挑出。
4. **看叶冠和果眼**：叶冠青绿、易拔但不松散；果眼浅而平展、无渗液。叶冠枯黄、果眼发黑渗水的不要。

**三、按销量控制采购结构**

- 日销量稳定的店：**70%七八成熟 + 20%九成熟 + 10%略青**，略青的放在货架后排自然催熟。
- 天气热、客流快：提高九成熟比例，但当天要能切完/卖完。
- 天气冷、客流慢：降低九成熟比例，多拿七八成熟，避免集中转熟。
- 进货后**不要堆叠闷着**，放通风阴凉处，底部朝下或侧放，每天翻检一次，把转黄快的挑出来先卖或切果盒。

**四、简单可执行的验收标准**

采购时随机抽几个：**底部淡香、1/3左右转黄、按压微弹、无软陷无渗液**，这批就可以作为主销货。若一箱里超过两成已经通体黄软、有酒味，说明熟度偏高，只适合当天促销，不建议作为常规采购。
