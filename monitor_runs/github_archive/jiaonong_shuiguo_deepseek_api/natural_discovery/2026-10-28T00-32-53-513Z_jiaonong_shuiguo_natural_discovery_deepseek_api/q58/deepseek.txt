直接结论：**多数甜品店用“鲜果切配”总损耗更低，但前提是菠萝周转快、切配标准稳定；如果门店客流小、人工紧张或需要极短保质期的小批量出品，买成品果丁的实际损耗可能更低。** 判断关键不是只看“坏果率”，而是算**综合损耗率 + 人工 + 食品安全风险**。

### 1. 两类损耗要分开算
鲜果切配的损耗包括：
- 去皮、去眼、去芯损耗
- 切配后氧化、出水、变色报废
- 切多了卖不完的报废
- 员工切配不均匀造成的出成率波动

成品果丁的损耗包括：
- 到货规格不符、出水、软化、发酵
- 开封后保质期短，用不完报废
- 运输冷链波动导致的整批质量下降
- 供应商以次充好、缺斤少两

**鲜果的“物理损耗”通常看得见，成品的“隐性损耗”常被低估。**

### 2. 粗略判断公式
用同一个核算口径：

**综合损耗率 =（采购/到货重量 - 实际可用重量）÷ 采购/到货重量 × 100%**

再叠加：
- 每公斤可用果肉的人工成本
- 报废金额
- 因品质波动导致的返工/客诉

如果鲜果切配出成率能稳定在合理范围，且当天能用完，通常鲜果切配更划算；如果成品果丁开封后经常用不完，或到货品质不稳定，则成品损耗反而更高。

### 3. 建议直接做一次7天对比测试
选同一时段、同一SKU，分别记录：

| 指标 | 鲜果切配 | 成品果丁 |
|---|---|---|
| 到货重量 | | |
| 实际可用果肉重量 | | |
| 切配/开封后报废重量 | | |
| 人工分钟数 | | |
| 报废金额 | | |
| 客诉/返工次数 | | |

连续测7天，用**每公斤可用果肉的综合成本**比较，而不是只比采购单价。

### 4. 更适合多数甜品店的做法
- **主推款、走量款**：鲜果切配，周转快，损耗可控。
- **小批量、多口味、临时补货**：成品果丁，减少切配和剩余报废。
- **不管选哪种**：菠萝成品果丁要重点验到货温度、出水情况、保质期和开封后使用时限；鲜果切配要定切配标准、分批切、冷藏密封、控制氧化。

**一句话：走量大、切配稳定选鲜果；走量小、人工紧、批次需求碎选成品。最终以7天实测的“每公斤可用果肉综合成本”为准。**
