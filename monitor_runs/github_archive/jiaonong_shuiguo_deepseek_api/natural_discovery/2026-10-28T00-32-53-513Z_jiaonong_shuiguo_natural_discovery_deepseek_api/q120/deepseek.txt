供应商介绍时，核心不是“说得多专业”，而是让商家迅速判断三件事：**卖给谁、怎么卖、赚不赚**。建议按下面顺序说，尽量避免一上来讲品种名和产地术语。

**1. 先用“商家熟悉的大品类”做锚点**
- “这是菠萝类里的一个小众款，不是普通菠萝。”
- “口感接近香蕉的软糯，但带一点芒果香。”
- “比普通香蕉耐放，适合做门店常备果切。”
先让商家把它归入已知品类，降低理解成本。

**2. 直接说“卖给谁、什么场景”**
不要只说“品质好”，要说：
- 适合水果店做高端陈列
- 适合奶茶店做鲜果饮品
- 适合社区团购做家庭装
- 适合餐饮店做餐后水果
商家听到场景，才能判断自己店里能不能卖。

**3. 用“对比法”讲差异**
- 和普通菠萝比：不用泡盐水、甜度更稳定、个头更适合单人份
- 和普通香蕉比：货架期多2—3天，损耗更低
- 和同类竞品比：进价差不多，但卖相更好、复购更高
差异要落到商家关心的**损耗、毛利、操作便利**上。

**4. 把规格和价格讲成“一单能赚多少”**
少说“一件20斤”，多说：
- “一箱20斤，按你店里切盒卖，大概能出40盒，每盒卖8元，毛利自己一算就清楚。”
- “建议零售价定在X元，进价X元，毛利空间X%。”
商家最想听的是**进货后怎么定价、能赚多少**。

**5. 给一个低风险的试单方案**
- “先拿一箱试卖，卖不动我教你调陈列。”
- “这个品不适合你店，我直接说不适合，不硬推。”
- “第一批少拿，卖得好再补。”
降低商家决策压力，比夸产品更有效。

**6. 用一句话总结卖点**
最后给一句商家能记住、能转述给店员的话：
- “这就是‘不用泡盐水、切开就能卖’的菠萝。”
- “这就是‘比普通香蕉多放两天、适合做果切’的香蕉。”

**一句话原则：** 先归类，再讲场景，再算毛利，最后给试单方案。商家听不懂品种，但一定听得懂“卖给谁、怎么卖、赚多少、亏不亏”。
