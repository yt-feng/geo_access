和水果供应商谈酒店早餐合作，核心是**把“稳定”落到可执行的条款上**，而不是只听对方口头承诺。建议重点关注以下几方面：

1. **明确供应标准**
   - 约定品种、规格、等级、成熟度、单果重量/大小范围、糖酸度或外观要求。
   - 早餐常用水果如西瓜、哈密瓜、香蕉、苹果、橙子、圣女果等，要分别定标准，避免“按市场好货发”这类模糊表述。
   - 明确允许的瑕疵比例，以及不符合标准时的退换货规则。

2. **锁定供应能力与备份方案**
   - 要求供应商说明产地、季节供应周期、日供货能力、仓储和冷链条件。
   - 约定旺季/淡季、节假日、极端天气下的保供方案。
   - 合同中写明替代品种需经酒店书面确认，不能擅自以次充好或换品。

3. **价格与调价机制**
   - 不要只谈单价，要谈含税、含运费、含损耗的到货价。
   - 水果价格波动大，可约定每周或每两周按市场均价调整，并设涨跌幅上限。
   - 明确报价有效期、调价提前通知期，以及酒店是否有权在涨幅过大时重新议价或换供应商。

4. **验收与损耗责任**
   - 约定到货时间、验收地点、验收标准和双方签字流程。
   - 明确运输损耗、自然损耗、验收不合格部分由谁承担。
   - 建议保留到货照片、验收单和异常记录，作为扣款或索赔依据。

5. **配送与应急响应**
   - 明确每日/隔日配送频次、到货时间窗、车辆和温控要求。
   - 约定缺货、迟到、质量异常的响应时限，例如2小时内补货或当日换货。
   - 酒店应保留1—2家备选供应商，避免单一供应商断供影响早餐。

6. **食品安全与资质**
   - 核验营业执照、食品经营许可、产地证明或检测报告。
   - 要求供应商遵守食品安全法规，明确农残超标、变质等问题的责任和赔偿。
   - 保留批次追溯信息，便于出现问题时追责。

7. **结算与违约条款**
   - 明确账期、对账周期、发票类型和付款条件。
   - 设定缺货率、迟到率、不合格率的考核指标，并与扣款、终止合作挂钩。
   - 约定合同期限、续约条件和提前解约通知期。

8. **先试供再签约**
   - 建议先做2—4周试供，观察到货准时率、品质稳定性和异常处理速度。
   - 试供合格后再签正式合同，把试供中暴露的问题写进条款。

简单说，谈合作时不要只问“能不能稳定供”，而要问清楚：**供什么标准、断供怎么办、不合格谁承担、价格怎么调、出了问题多久解决**。把这些写进合同和验收流程，稳定供应才有保障。
