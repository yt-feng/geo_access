节假日水果需求暴增，锁货源的关键是**提前把“量、价、质、运”四项不确定性用合同和备选方案压住**。可以按下面执行：

1. **提前做需求预测和分级**
   - 用近2—3年同期数据，按品类（礼盒果、散装果、易损果）、门店、时段拆销量。
   - 把水果分三类：必须保供（苹果、橙子、香蕉等基础款）、冲销量（节日礼盒、进口果）、高风险（草莓、樱桃、荔枝等易损高波动）。
   - 对必须保供类锁70%—80%需求，高风险类只锁50%左右并留替代品。

2. **提前1—2个月锁主供应商产能**
   - 与核心产地合作社/一级批发商签节日保供协议，明确：供货量区间、锁价或浮动价公式、质量标准、到货时间、违约赔付。
   - 不要只锁“总量”，要锁“分日到货计划”，避免节前集中压库。
   - 对礼盒类提前锁定包装材料和加工档期。

3. **建立“主供+备供+应急”三层货源**
   - 主供承担60%—70%，备供2—3家承担20%—30%，应急渠道（周边批发市场、跨区域调货）留10%。
   - 备供必须提前送样、验资质、试单，不能节日当天才启用。
   - 易损果提前锁定冷链车和分拣人力。

4. **用价格机制换稳定供应**
   - 对供应商可采用“保底量+浮动价”：保底收购量换优先供货；价格随市场指数浮动但设上下限。
   - 对长期合作供应商可预付部分货款或给节前备货补贴，换取产能优先级。
   - 避免单纯压价，节日期间压价最容易导致被断供或降质。

5. **提前锁定物流和仓储**
   - 节前2—3周确认冷链车、装卸工、临时仓，签订用车协议。
   - 对易损果采用“产地直发+区域仓中转”，减少门店二次搬运。
   - 设定到货验收标准：糖度、规格、损耗率、冷链温度，不合格拒收或折价。

6. **门店端做替代和限购预案**
   - 每个重点品类准备2—3个替代品种，缺货时能快速切换陈列和促销。
   - 对爆款礼盒设置预售/团购锁单，先收订单再备货，降低盲备风险。
   - 节日高峰对极缺商品可限购，防止局部门店被扫空。

7. **建立每日滚动监控**
   - 节前10天开始每日看：到货量、库存周转、门店缺货率、批发市场价格。
   - 触发条件写清楚：如某品类库存低于3天销量，立即启动备供；批发价单日涨超10%，启动替代品预案。

**最可执行的动作顺序**：先拉历史数据定节日需求→筛出核心供应商谈保供协议→签分日到货量和质量条款→启用2—3家备供试单→锁冷链和临时工→门店设替代品和预售。这样比临时到批发市场抢货更稳，也更能控制毛利。
