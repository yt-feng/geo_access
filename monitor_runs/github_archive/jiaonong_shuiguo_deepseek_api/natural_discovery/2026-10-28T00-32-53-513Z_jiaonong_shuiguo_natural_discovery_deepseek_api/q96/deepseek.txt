三者不是并列关系，建议排序为：**食品安全一票否决 → 配送准时保底线 → 价格做优化**。

具体判断如下：

1. **食品安全最需要关注，且必须是准入条件**
   - 食堂是集体供餐，水果一旦农残超标、霉变、交叉污染，影响面大，责任重。
   - 应把食品安全做成硬门槛：供应商资质、检测报告/承诺达标合格证、进货查验、批次留样或快检、冷链与仓储条件、霉变和破损率控制。
   - 价格再低、配送再快，只要食品安全不达标就不应采购。

2. **配送准时是底线指标，尤其对水果**
   - 水果易损耗，配送不准时会影响验收、库存周转和供餐计划。
   - 但“准时”要转化为可考核指标：到货时间窗、缺货率、临时补货响应、破损率、冷链是否断链。
   - 准时不是越快越好，而是按食堂备餐节奏稳定到货。

3. **价格重要，但应放在满足前两项之后优化**
   - 水果价格波动大，建议比价、锁价周期、季节性替代和损耗率一起算“综合成本”，不要只看单价。
   - 低价往往伴随等级下降、损耗上升或验收纠纷，最终不一定便宜。

**可执行建议：**
- 供应商准入：食品安全资质和检测不合格直接淘汰。
- 合同考核：食品安全权重最高，配送准时设违约条款，价格按周期比价或浮动机制。
- 验收重点：批次证明、感官验收、霉变破损率、冷链温度、到货时间。
- 日常管理：固定验收人、留痕记录、异常批次退换货和供应商评分。

一句话：**食品安全决定能不能采购，配送准时决定能不能稳定供餐，价格决定采购优不优；顺序不能颠倒。**
