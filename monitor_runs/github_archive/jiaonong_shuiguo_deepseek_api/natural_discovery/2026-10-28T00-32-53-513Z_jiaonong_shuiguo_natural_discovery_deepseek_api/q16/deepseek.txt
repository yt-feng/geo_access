优先选**稳定供应商**，本地批发作为补充。香蕉和苹果都属于**高频、易损耗、毛利不高**的品类，核心不是“进价最低”，而是**稳定拿货、少损耗、能退换、不断货**。

可以按下面判断：

1. **香蕉：优先稳定供应商**
   - 香蕉成熟度、催熟和损耗很关键，批次不稳会直接影响售卖。
   - 稳定供应商更能保证规格、成熟度和持续供货。
   - 本地批发适合临时补货、处理短期价格波动，但不宜作为主渠道。

2. **苹果：可“稳定供应商为主，本地批发比价补充”**
   - 苹果相对耐储，本地批发若有明显价格和品质优势，可以适量采购。
   - 但主供货仍建议稳定供应商，保证品相、规格和长期价格可预期。
   - 可每周用本地批发价做一次比价，防止供应商价格偏离。

3. **建议的采购结构**
   - 主供应商：承担70%—80%的香蕉和苹果日常供货。
   - 本地批发：承担20%—30%，用于补货、试销新品、节庆冲量。
   - 先小批量试单2—4周，记录：到货损耗率、可售率、缺货次数、退换是否顺畅、实际毛利。

4. **选择稳定供应商时重点看**
   - 是否能固定送货频次和到货时间；
   - 坏果、熟度不符能否退换；
   - 香蕉能否按季节调整催熟程度；
   - 苹果规格是否稳定；
   - 报价是否含配送、是否临时涨价。

**结论：** 社区超市新增香蕉和苹果，主渠道选稳定供应商更稳；本地批发用来比价和补货。先用小批量试单，以“损耗率+可售率+缺货率”决定最终比例，而不是只看进价。
