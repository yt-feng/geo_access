对餐饮店来说，每天少量水果，最省心的通常是“本地二级批发商/水果配送商”，而不是产地直采或大型一级批发市场。建议优先找能提供 **次日达、起送门槛低、可退换、按你的菜单固定搭配** 的配送商。

可按下面顺序筛选：

1. **首选：本地水果配送商/二级批发商**
   - 优点：起送量低，能每天送，缺货可临时补，损耗和退换相对好谈。
   - 适合：每天几公斤到几十公斤、品类不固定的小餐饮。
   - 关键问清：起送金额、配送时间、当天缺货怎么补、坏果怎么赔、是否可临时改单。

2. **次选：附近水果店/社区生鲜店长期合作**
   - 优点：最灵活，少量也送，沟通快，临时加单方便。
   - 缺点：价格略高，品类受门店库存限制。
   - 适合：每天用量很小、对价格不特别敏感的店。

3. **备选：生鲜B2B平台**
   - 优点：下单方便、价格透明、有售后规则。
   - 缺点：起送门槛、配送时段和品质稳定性要看当地覆盖。
   - 适合：能接受平台规则、用量相对稳定的店。

4. **不太建议一开始就找产地直采/一级批发**
   - 量小议价弱，物流和损耗自己承担，每天少量反而不省心。

筛选供应商时重点看这5条：
- **起送门槛低**：几十元也能送。
- **配送稳定**：固定时段到店，迟到有说法。
- **售后明确**：坏果、少斤、不新鲜能否当场退换或下次抵扣。
- **可临时改单**：餐饮客流波动大，前一天晚上还能改量很重要。
- **账期和结算清楚**：先款后货还是月结，避免扯皮。

实操建议：先找2家同时试送1—2周，用同一份“每日水果清单”比价格、准时率、坏果率和临时补货能力，再定主供应商，另一家留作备用。这样最省心，也不容易被单一供应商卡住。
