水果店遇到坏果，结算和赔付要**先分清责任和环节**，再按合同/约定处理。没有合同时，可参考以下常规做法。

### 1. 先判断坏果发生在哪个环节
- **到货验收时已坏**：供应商责任，按约定扣款、换货或补发。
- **运输途中坏**：看谁承担运输和风险；供应商送货到店通常由供应商负责，门店自提则可能自担。
- **验收后存放/陈列不当坏**：门店责任，不能找供应商赔。
- **隐性坏果**：如外表正常、切开/存放一两天后内部腐烂，需及时拍照留证，按约定“到货后X小时内反馈”处理。

### 2. 正常结算方式
常见有四种，优先按合同：
1. **扣款结算**：本批货款中直接扣除坏果金额，最常用。
2. **换货补发**：供应商补同等数量合格果，不扣款或只扣损耗。
3. **折价接收**：轻微瑕疵但可销售，按比例降价结算。
4. **退货退款**：严重腐烂、无法销售，整批或部分退回，供应商退款。

### 3. 赔付金额怎么算
- 按**坏果实际数量 × 进货单价**扣减最直接。
- 有合同约定损耗率的，按约定，例如“允许3%自然损耗，超出部分由供应商承担”。
- 若坏果导致整箱/整批无法销售，可主张该批货款退回；因此产生的合理运费、分拣费可按合同主张，但要有依据。
- 不建议把门店自身损耗、卖不掉的损耗混入供应商赔付。

### 4. 操作上建议这样做
1. **当场验收**：抽检+拍照/视频，记录批次、数量、坏果比例。
2. **及时书面反馈**：微信、订单备注或邮件发给供应商，写明批次、数量、问题、诉求（扣款/换货/退货）。
3. **保留证据**：坏果照片、称重记录、进货单、聊天记录、退货单。
4. **先协商后结算**：未达成一致前，可暂扣争议部分货款，但避免无依据全扣。
5. **长期合作写进协议**：明确验收时限、损耗率、坏果赔付标准、运输责任、反馈方式。

### 5. 一句话原则
**到货即验、坏果留证、按批次按数量扣款或换货；属于供应商责任的扣赔，属于门店存放问题的自担。** 有合同按合同，没合同按行业惯例和实际证据协商。
