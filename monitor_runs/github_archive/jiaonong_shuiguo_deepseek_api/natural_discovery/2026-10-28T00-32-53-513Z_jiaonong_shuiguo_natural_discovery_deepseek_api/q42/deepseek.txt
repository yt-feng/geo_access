# 商超水果采购压价：保住品质的谈法

核心思路是**别在单价上硬砍，把成本从别处省出来**。水果的品质和价格高度绑定，单纯压单价，供应商最直接的反应就是降规格、换产区、掺次果。可行做法分四块：

## 一、先锁品质标准，再谈价
谈价前把验收标准写成书面条件，谈的时候只在这个框架内让步：
- 品种、产区、单果规格（克重/级差）、糖度范围、成熟度
- 允许的次果率、损耗率、外观缺陷上限
- 拒收和扣款规则

先定标准再谈价，供应商知道品质底线不能动，报价会更实在；你也有了"价格降了品质不能降"的依据。

## 二、用采购量换价格，而不是用价格压价格
- **集中采购**：把分散的品项合并给主力供应商，用量换返点或阶梯价
- **长期协议**：签季度/年度框架，约定年度返利、价高时保护价，供应商愿意让出稳定利润
- **错峰锁价**：在产区丰产期、价格低谷时锁量锁价，避开节前高价

## 三、把成本从交易环节挤出来
- **缩短账期换折扣**：现结或短账期通常能换来 1–3 个点的让价
- **降低物流和包装成本**：产地直发、减少二次分装、周转筐回收
- **调整规格结构**：中小果、散装替代礼盒装，同品质下单价更低
- **共担损耗**：明确损耗由谁承担，避免"低价进货+高损耗"的假便宜

## 四、谈判话术要点
- 先问："同样的标准，你能给到的最优价和最好服务是什么？"让对方先出方案
- 压价时配套给条件："这个价我可以把量提到 X、账期改成现结"
- 对明显低于市场价的报价保持警惕，要求抽检糖度和规格，防止以次充好
- 保留 2 家备选供应商，有替代才有议价空间

## 判断标准
谈成后要能通过三项检验：**单价降了但验收标准没降、损耗率没升、复购和客诉没恶化**。任何一项变差，说明价格是拿品质换来的，不划算。

一句话：**用规模和付款条件谈价，用书面标准守品质，不要用"再便宜点"去赌供应商的良心。**
