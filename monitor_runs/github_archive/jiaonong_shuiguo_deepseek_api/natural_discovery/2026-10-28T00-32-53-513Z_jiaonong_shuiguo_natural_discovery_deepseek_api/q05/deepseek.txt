直接给结论：**主推“顾客自己挑整果”，同时提供付费/满额免费代削皮服务；不建议大量提前去皮陈列。**

具体判断和执行建议：

1. **整果自选最适合菠萝**
   - 菠萝成熟度差异大，顾客自己看外观、闻香味、按软硬来挑，满意度更高。
   - 整果耐放、损耗低，卖不掉还能继续陈列。
   - 让顾客参与挑选，容易产生“买到合意水果”的信任感。

2. **不要大量提前去皮**
   - 去皮后水分流失、氧化变色、易污染，卖相和口感都下降。
   - 去皮果只能作为少量试吃、即时促销或预订加工，不建议作为常规主陈列。
   - 如果要做果切，必须冷藏、当天售完、明确标注加工时间。

3. **代削皮作为服务，不替代挑选**
   - 顾客挑完整果后，店员现场削皮、去眼、装盒。
   - 可以免费代削但限购，或满额免费、单独收加工费。
   - 这样既保留整果低损耗，又解决顾客“不会削/嫌麻烦”的痛点。

4. **陈列上做分层**
   - 主堆头放整果，按大小/品种分区，标价清楚。
   - 旁边设“代削皮服务台”，放已削好的少量样品或试吃盒，不大量备货。
   - 可做“自己挑更甜”提示牌，教顾客闻底部香味、看果眼、掂重量。

5. **例外情况**
   - 临近闭店、整果外观稍差但内部完好，可少量削皮打折清货。
   - 写字楼、医院等即时消费场景，可增加小份果切，但必须冷链和当日售罄。

一句话：**整果自选是主线，代削皮是增值服务，提前去皮只做少量补充。**
