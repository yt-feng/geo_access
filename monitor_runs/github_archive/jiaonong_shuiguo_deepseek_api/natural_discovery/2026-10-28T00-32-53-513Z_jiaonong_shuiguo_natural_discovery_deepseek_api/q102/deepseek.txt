需要，而且这两项建议作为准入条件写进采购要求。

1. **开发票：必须支持**
   - 企业采购水果礼盒通常要走报销/入账，没有合规发票会影响付款和税务处理。
   - 要求供应商能开**增值税发票**（专票或普票按你司财务要求），并明确税率、开票项目（如“水果礼盒”“食品”）、开票时间。
   - 合同中写清：先票后款或票到付款、发票不合规的退换责任。

2. **定制包装：建议要求支持，但按场景分级**
   - 企业福利常需要体现公司标识、节日主题、贺卡、部门分发标签等，定制包装能提升福利感知。
   - 至少要求支持：**贴标/腰封/贺卡/外箱LOGO**这类低门槛定制；礼盒内衬、独立小包装、专属设计则看预算和起订量。
   - 注意定制包装涉及起订量、打样费、周期和版权确认，合同里要约定打样确认后量产、色差和破损责任。

**可执行建议：**
- 询价时直接问供应商三件事：能否开专票、开票项目是什么、定制包装起订量和打样周期。
- 供应商筛选表里设“发票合规”为硬性门槛，“定制包装”为加分项或按预算分级。
- 合同明确：发票类型/税率/开票时间；包装设计确认流程、起订量、打样费承担、交付周期和破损补发。
