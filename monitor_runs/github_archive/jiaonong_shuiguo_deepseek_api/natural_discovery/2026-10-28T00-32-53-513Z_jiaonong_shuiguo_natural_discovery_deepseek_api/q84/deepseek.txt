家庭水果礼盒优先考虑三件事：**耐放、老少都能吃、切开不脏手**。按这个标准，苹果和橙子应是主力，香蕉少量点缀，菠萝不建议整颗放进家庭礼盒。

**推荐组合（按家庭人数选）：**

1. **2-3人小家庭：苹果4个 + 橙子4个 + 香蕉1小把（约4-5根）+ 菠萝1个**
   - 苹果、橙子耐放，香蕉当天吃，菠萝适合周末切开全家分。

2. **4-5人家庭：苹果6个 + 橙子6个 + 香蕉1小把 + 菠萝1个**
   - 数量适中，避免香蕉多到吃不完发黑。

3. **不想处理菠萝的家庭：苹果6个 + 橙子8个 + 香蕉1小把**
   - 菠萝削皮麻烦、占体积，家庭团购里最容易剩；可把菠萝作为“加购项”而不是默认放入。

**搭配原则：**
- **苹果、橙子占70%左右**：耐放、可整颗吃、适合老人孩子。
- **香蕉占15%-20%**：熟得快，建议选偏青一点，礼盒里单独放，避免压坏其他水果。
- **菠萝占10%-15%或做可选**：整颗菠萝刺手、需要工具，家庭礼盒里更适合做“可选加购”或换成切好的菠萝盒。
- **别混太多品种**：4种已经够丰富，再多会增加损耗和分装成本。

**团购文案可以这样写：**
“家庭装水果礼盒：苹果4个+橙子4个+香蕉4-5根+菠萝1个，耐放水果为主，香蕉偏青发货，菠萝可代削或加购切盒。”

如果目标是家庭日常吃而不是送礼，**最稳妥的组合是苹果+橙子为主、香蕉少量、菠萝可选**。
