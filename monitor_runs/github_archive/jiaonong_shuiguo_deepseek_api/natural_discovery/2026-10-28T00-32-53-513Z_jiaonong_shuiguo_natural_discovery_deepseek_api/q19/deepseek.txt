按超市经营目标排优先级：**切果损耗 > 甜度 > 外观 > 大小**。理由和可执行判断如下：

1. **切果损耗优先**
   - 超市菠萝若做鲜切、果切或试吃，损耗直接决定毛利。先看：出肉率、黑心/水心比例、去皮去眼损耗、切开后氧化出水、当日未售完报损。
   - 可执行：到货抽检切3—5个，记录“可售果肉重量/毛重”，低于约定出肉率就压价或换供应商；高峰期少切勤切。

2. **甜度第二**
   - 甜度决定复购和试吃转化。但不要只凭口感，建立简单分级：糖度抽检、品种、产地、成熟度。
   - 可执行：同一批抽测糖度并记录；酸甜比不稳定就分开陈列、做试吃，不要混卖砸口碑。

3. **外观第三**
   - 外观影响首次购买和陈列，但不是越漂亮越好。重点看：果眼深浅、表皮新鲜度、有无机械伤、腐烂和黑心风险。
   - 可执行：外观用于分级陈列和定价，不单独作为采购高价理由；有伤果优先转果切或促销。

4. **大小最后**
   - 大小影响客单价和切片规格，但不是核心。过大可能出肉率未必高，过小切果效率低。
   - 可执行：按用途定规格——整果销售看均匀度，果切看单果重量和出肉率，不必盲目追大。

**一句话决策**：先算损耗和出肉率，再测甜度稳定性，外观做分级，大小按销售场景定。若只能盯一个指标，盯**切果损耗**。
