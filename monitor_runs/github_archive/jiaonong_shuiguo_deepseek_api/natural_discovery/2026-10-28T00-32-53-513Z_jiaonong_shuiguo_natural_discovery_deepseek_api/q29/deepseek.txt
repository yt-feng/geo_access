超市和水果供应商谈账期，常见范围如下，但要看“谁强势、什么品类、是否冷链/进口”：

1. **最常见区间：30～60天**
   - **30天**：比较常见，适合本地水果、叶菜/易损耗品类、中小超市或新供应商磨合期。
   - **45天**：也比较常见，常出现在连锁超市与稳定供应商之间。
   - **60天**：大型商超、强势渠道较常见，尤其是账期从“收货日/对账日/开票日”起算时要特别确认。

2. **大型连锁/强势超市：60～90天也常见**
   - 60天较普遍，90天在强势KA渠道并不少见，但对水果供应商现金流压力很大。
   - 若遇“月结60天/90天”，实际回款可能比名义账期更长，因为还涉及对账、开票、付款日。

3. **水果品类要更短**
   - 叶菜、草莓、荔枝、水蜜桃等易损耗、短保品类，供应商通常希望**7～15天**或**周结/半月结**。
   - 苹果、橙子、梨等耐储水果，**30～45天**更常见。
   - 进口水果资金占用大，常见**30天左右**，强势渠道可能压到**45～60天**。

4. **谈判建议**
   - 新供应商先争取**15～30天**，稳定后再谈**45天**。
   - 明确账期起算点：**收货日、对账确认日、开票日**差别很大。
   - 约定**对账周期、付款日、逾期利息/违约金**，避免“名义30天、实际60天”。
   - 可组合：**部分现结+部分30天**，或**账期换价格/返利/损耗承担**。
   - 水果损耗高，账期内要明确**损耗承担、退换货、质量扣款规则**，否则账期越长约容易扯皮。

**结论：** 普通超市和水果供应商，**30～45天最常见；大型连锁常见60天，强势渠道可到90天；短保易损耗水果应争取7～15天或周结/半月结。**
