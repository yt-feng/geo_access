旺季锁库存，核心是“提前锁量、锁价、锁赔付”，不能只口头打个招呼。给你一套可直接执行的做法：

1. **先做销量预测，按品类分级锁量**
   - 把水果按爆款/常规/引流款分级，爆款锁到预估销量的70%～80%，常规款50%～60%，别全锁死，留调货空间。
   - 预测依据用：近30天日均销量、去年同期、社区团长预售/接龙数据、节假日和天气因素。
   - 输出一张“品类—周销量—锁量—备选供应商”表，和供应商谈之前先有数。

2. **和供应商签书面锁量协议，别只靠微信**
   协议至少写清：
   - 锁量：每周/每日最低供货量、最高可供量；
   - 锁价：锁价周期（如7天/15天），超量部分价格怎么算；
   - 品质标准：规格、糖度、瑕疵率、到货温度；
   - 违约责任：缺货赔付比例、延迟到货扣款、品质不达标退换；
   - 付款：可给少量定金锁货，尾款到货验收后付，定金比例别太高。

3. **用“定金+阶梯价+优先供货权”换供应商承诺**
   - 对核心爆款给10%～20%定金锁货，约定缺货双倍返还或按差额赔付。
   - 承诺旺季总采购量，换淡季也稳定合作的优先供货权。
   - 量大时分阶梯价，但锁价部分单独列，避免供应商后期以“行情涨了”毁约。

4. **同时锁2～3家供应商，主供+备供**
   - 主供占60%～70%，备供占30%～40%，避免单一供应商断货。
   - 备供也要提前给预估量，哪怕量小，保持合作关系，旺季才能临时加单。

5. **提前锁定物流和到货节奏**
   - 水果损耗大，约定分批次到货，比如每日/隔日到仓，避免一次压太多。
   - 明确到货时间窗口、冷链要求、验收标准，缺货时供应商几小时内补货。

6. **做库存预警和每日对账**
   - 设安全库存线：爆款低于2天销量就触发补货；供应商当日未按量发货，立即启动备供。
   - 每天和供应商对一次次日供货量，旺季最好建群+表格同步，留文字记录。

7. **付款和合同留证据**
   - 所有锁量、锁价、赔付约定走合同或盖章确认单，微信沟通也保留记录。
   - 定金走对公转账，备注“XX水果旺季锁货定金”，避免纠纷时说不清。

一句话：**先预测再谈量，书面协议锁价锁量锁赔付，主备供应商并行，分批到货+每日对账。** 这样爆单时不至于被供应商临时涨价或断货卡住。
