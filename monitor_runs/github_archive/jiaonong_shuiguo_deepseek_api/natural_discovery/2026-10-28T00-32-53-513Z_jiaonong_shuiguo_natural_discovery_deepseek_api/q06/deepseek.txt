适合。水果店销量不稳定时，供应商的关键能力不是“最低进货价”，而是**小批量、多频次、能临时补货、损耗可控**。原因很直接：

- **水果损耗高**：一次压货卖不动，坏果和降价处理会吃掉毛利。
- **销量波动大**：天气、节假日、周边人流都会影响日销量，大批量进货容易错配。
- **小批量多配能降低试错成本**：新品或少备的品类可以少量试销，第二天再补。
- **现金流更稳**：减少囤货占款，把库存压力转移给供应链。

但要注意，小批量多次配送通常会有代价：**单价略高、起送门槛、配送费、时段限制、品控不稳定**。所以判断是否适合，可以看这几个条件：

1. **供应商能否承诺固定频次**：比如每天1次或隔天1次，而不是“有空才送”。
2. **最小起订量是否低**：单品几箱、整单金额门槛是否在你能承受范围。
3. **临时补货能力**：当天上午卖得好，下午或次日早能否补到。
4. **损耗和退换规则**：坏果、压伤、不熟能不能换补，责任怎么算。
5. **价格差是否可接受**：小批量配送单价通常比大批发高5%—15%都常见，关键看综合损耗后是否更划算。
6. **品类覆盖**：常销水果能否一次配齐，避免多家供应商增加管理成本。

实操建议：**不要只找一家，采用“1家主供应商 + 1家补货供应商”**。主供应商负责每日基础量，补货供应商负责临时缺货和试销新品。先用2—4周记录每天销量、损耗和缺货次数，再和供应商谈固定配送频次与起送门槛。若单店日销量波动很大，小批量多次配送通常比追求低进价更划算。
