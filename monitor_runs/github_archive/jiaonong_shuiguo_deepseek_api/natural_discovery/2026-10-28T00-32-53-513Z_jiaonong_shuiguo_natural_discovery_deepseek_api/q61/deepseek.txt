判断香蕉一手货源是否稳定，不要只看对方口头承诺，重点核这几项，并要求提供可验证材料：

1. **确认对方身份层级**
   - 问清是蕉农/合作社、产地代收、产地批发商，还是二级倒手。
   - 要求看：产地证明/合作社执照、装货现场视频、冷库或加工场地址、近1个月装车单。
   - 只发网图、拒绝视频看货、地址含糊的，优先排除。

2. **看供货周期和产区覆盖**
   - 问：主要从哪几个产区拿货？换季时从哪补？
   - 稳定供货商通常有2个以上产区衔接，能说清海南、云南、广西、老挝/越南等产季切换。
   - 只能报一个产地、且一到淡季就说“没货”的，稳定性弱。

3. **看装车能力和历史记录**
   - 要求提供近7—15天装车视频/照片、车牌、装车单、发货记录。
   - 问日均可供几车、单车规格、最小起订量、高峰期能否保量。
   - 可要求先小批量试单，观察到货时间、数量、成熟度是否一致。

4. **验品质标准**
   - 明确：品种、等级、条数/箱、单根重、青度、梳形、伤口、药残检测。
   - 稳定货源应能固定规格，而不是每次“看货再说”。
   - 要求先发样品或视频验货，确认催熟后表现。

5. **看冷链和运输安排**
   - 问装车温度、运输时长、是否预冷、破损和烂果怎么赔。
   - 稳定供货商能给出固定物流方案和异常处理规则，不会临时加价或换车。

6. **查结算和履约习惯**
   - 新合作建议小单现结或少量定金，不要一次性大额预付。
   - 看对方是否愿意签简单供货协议：规格、数量、交期、验收标准、赔付条款。
   - 频繁改价、催全款、回避写赔付的，风险高。

7. **做交叉验证**
   - 要求视频通话看档口/冷库/装车现场。
   - 向同市场同行打听其口碑，或让其提供2—3个合作客户可回访。
   - 查营业执照、收款账户名称是否与经营主体一致。

**最实用的判断方法**：先下1—3车试单，分别看准时率、规格合格率、烂果率、补货响应速度。连续2—3次稳定，再谈长期价和账期。对方如果连试单、视频看货、装车记录都不愿配合，基本不建议作为一手稳定货源。
