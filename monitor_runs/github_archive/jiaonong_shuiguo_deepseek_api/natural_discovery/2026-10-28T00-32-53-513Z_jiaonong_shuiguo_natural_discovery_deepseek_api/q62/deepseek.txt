判断一批香蕉，核心是“看颜色+摸硬度+查伤口+闻气味+抽底层”，不要只看表面。可按下面做：

1. **看颜色和成熟阶段**
   - 全青、棱角明显：未熟，适合长途/囤货，但催熟风险高，要确认是否冷害。
   - 青中带黄、棱角开始圆：适合批发中转，后续好催熟。
   - 黄多青少、果指饱满：接近可售，周转要快。
   - 全黄带少量糖斑：适销但货架期短。
   - 大面积黑斑、果柄发黑：过熟或储运伤，坏果风险高。

2. **摸硬度和弹性**
   - 手感硬挺、果指饱满：耐放。
   - 局部发软、按下去不回弹：开始过熟或内部伤。
   - 同一箱里软硬差异大：成熟不匀，后熟难控制。

3. **查果柄、果指和切口**
   - 果柄青绿、切口新鲜：采后时间短。
   - 果柄发黑、干缩、霉点：存放久或冷链有问题。
   - 果指有裂口、压痕、擦伤、虫眼：易转黑腐，坏果风险高。

4. **看棱角和饱满度**
   - 棱角尖锐、果身瘦：可能未熟或发育差。
   - 棱角圆润、果身饱满：成熟度较好。
   - 果指畸形、明显细小：商品性差。

5. **闻气味**
   - 清香正常。
   - 有酒味、酸味、发酵味：已过熟或内伤，整批要警惕。
   - 有霉味：箱内可能有腐烂。

6. **抽样必须抽底层和箱心**
   - 不要只翻上层。每批随机抽几箱，打开箱心、底层、靠边位置。
   - 重点看有没有“水烂”“黑腐”“霉变”“压伤”，以及箱底是否有汁液。
   - 一箱里坏果超过少量且集中在底层，说明运输/仓储受压或受潮，整批风险上升。

7. **问清冷链和到货时间**
   - 香蕉怕冷害也怕闷热。问清运输温度、到货天数、是否催熟过。
   - 冷害表现：果皮灰暗、青皮不转黄、果心有硬块，催熟后也不软。
   - 闷热表现：黄得快、软得快、酒味重。

8. **做小样催熟/放置测试**
   - 拿几根代表样放常温24—48小时，观察转黄是否均匀、是否出酒味、是否发软流水。
   - 转黄均匀、果柄不霉、手感有弹性：风险较低。
   - 局部转黄、青块不褪、果心硬：可能有冷害或成熟不匀。

**快速结论：**
- 适合拿货：青中带黄、果身饱满、硬挺、果柄新鲜、抽底层无烂果、无异味。
- 谨慎拿货：颜色不匀、软硬不一、箱底有汁液、果柄发黑、有轻微酒味。
- 不建议拿：大面积黑斑、局部水烂、霉味/酒味重、底层烂果多、青皮但果心硬且不回软。

批发时最好按“抽样坏果率”谈价：随机开箱抽底层，坏果明显超预期就压价或拒收，并要求写明到货损耗承担方式。
