# 水果供应商需提供的证明清单

## 一、资质类（原件核验＋复印件盖章留存）

| 证明 | 说明 |
|---|---|
| 营业执照 | 经营范围须含水果销售/农产品销售 |
| 食品经营许可证 | 若供应商对水果进行切配、分装、包装等加工，属"食品销售/食品生产"范畴须有此证；仅销售初级农产品（未加工鲜果）按《食品安全法》可豁免，但**建议仍要求提供**，以便追责 |
| 仅销售预包装食品备案 | 如涉及预包装果品 |

## 二、产品合格类（按批次索取）

- **承诺达标合格证**（食用农产品，重点！）——农业农村部推行的产地准出凭证，是水果类最核心的批次证明
- **出厂检验报告/第三方检测报告**：重点看农残（如克百威、氧乐果等禁限用农药）、重金属项目；检测报告须有CMA/CNAS资质章，且批次或日期与到货对应
- **进货凭证/销售单据**：注明品名、产地、数量、日期，便于追溯

## 三、来源追溯类

- 产地证明或基地信息（合作社/果园名称、地址）
- 若为进口水果：**入境货物检验检疫证明**＋报关单
- 若供应商为贸易商而非产地直供：要求其提供上游产地或一级供应商的上述材料，形成完整链条

## 四、储运与人员类

- 运输车辆/冷链温控记录（尤其切果、浆果类需冷藏）
- 配送人员健康证（接触直接入口食品或切配环节时必须）
- 冷链交接温度记录单

## 五、合同层面的风控条款（比证明更关键）

1. 合同中明确**每批次随货提供承诺达标合格证＋检测报告**，缺一拒收；
2. 约定**抽检不合格的退换货、赔偿及停供条款**；
3. 要求供应商**每年更新资质**，证照到期前主动报备；
4. 保留**每批次留样**（门店侧配合），出现问题时倒查。

## 实操建议

- **首次合作**：全套资质＋近半年检测报告归档；
- **日常到货**：每批查验合格证与单据，肉眼验收（霉变、虫害、异味即拒）；
- **定期**：每季度或每半年自行送检1–2个高风险品类（如草莓、杨梅、切果），费用可在合同中约定分担。
- 建立**供应商档案台账**，证照有效期设提醒，避免过期证照仍在使用。

一句话判断标准：**能证明"这批水果从哪来、合不合格、谁负责"的三类材料（合格证＋检测报告＋进货单据）每批齐全，才算风险可控。**
