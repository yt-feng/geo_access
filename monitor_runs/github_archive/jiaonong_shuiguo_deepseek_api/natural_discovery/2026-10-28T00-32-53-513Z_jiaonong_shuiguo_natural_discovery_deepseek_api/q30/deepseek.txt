约定“到货品相不好”的售后流程，核心是把**验收标准、异议时限、处理方式、责任与费用**写进合同或订单条款，避免事后扯皮。建议按下面框架约定：

## 一、先明确“品相不好”的可执行标准
不要只写“品相良好”，要量化或可判定：
- 外观：颜色、光泽、果形、大小均匀度、机械伤/压伤/裂果/腐烂比例上限；
- 新鲜度：萎蔫、失水、软化、异味、霉变；
- 规格：单果重量/直径范围、等级（如一级果）；
- 允许偏差：例如“同批次不合格率不超过3%”“腐烂果不超过1%”。

## 二、约定验收与异议时限
- 到货后**当场抽检**，拍照/视频留证，记录车牌、批次、数量；
- 约定异议期：如“到货后24小时内提出书面异议，逾期视为验收合格”；
- 明确抽检比例和方法：如每车随机抽3箱，按不合格率判定整批处理方式。

## 三、约定处理方式（按不合格程度分档）
建议写清可选处理：
1. **轻微偏差**：折价接收，按不合格比例扣款；
2. **部分不合格**：退货/换货，或降级折价；
3. **严重不合格**（腐烂、霉变、异味）：整批拒收或退货退款；
4. **补货**：约定补货时限和运费承担。

## 四、责任与费用
- 运输损耗、装卸损伤、冷链断链的责任归属；
- 退货/换货的运费、卸货费、仓储费由谁承担；
- 因品相问题导致超市被消费者投诉/下架/罚款的，是否可追偿；
- 付款节点：可约定“验收合格后付款”或“异议未处理完暂扣部分货款”。

## 五、证据与流程
- 到货即拍照/录像，保留开箱视频；
- 异议以书面形式（微信/邮件/售后单）提出，注明批次、数量、问题、诉求；
- 供应商应在约定时限内回复处理方案，逾期视为同意；
- 建立售后台账，记录批次、问题、处理结果。

## 六、写进条款的示例表述
> “买方应在到货后24小时内完成抽检并书面提出品相异议，附照片/视频。不合格率≤3%的，按不合格数量折价扣款；3%–10%的，买方可选择换货或按比例扣款；＞10%或出现腐烂霉变的，买方有权拒收并要求退款，退货运费由卖方承担。卖方应在收到异议后48小时内答复，逾期视为认可买方诉求。”

## 七、实操建议
- 新供应商先小批量试单，把标准跑一遍；
- 把“品相标准”做成图文对照表附在合同后；
- 每次到货用统一验收单签字确认，避免口头承诺；
- 对高频问题设置阶梯扣款或保证金条款。

这样约定后，售后流程可判断、可执行、可追责。
