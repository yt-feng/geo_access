做水果长期生意，选供应商时最容易忽视的往往不是“价格”和“有没有货”，而是下面这些会慢慢吃掉利润和口碑的细节：

1. **稳定性比低价更重要**  
   只看报价便宜，容易忽略供应商是否常年有货、规格是否稳定。水果生意最怕今天一个规格、明天一个品质，售后和复购都会被拖垮。要问清楚：同一品种全年能供多久、断货时怎么补、是否有多产地备份。

2. **分级标准是否真实可执行**  
   很多供应商口头说“按大小分级”，实际混级、次果掺好果。要看他有没有明确分级标准：果径、糖度、成熟度、伤果率、色差容忍度。最好先小批量试单，按你门店或客户的标准验收。

3. **损耗责任怎么划分**  
   最容易忽视的是运输和到货后的损耗归属。要提前约定：运输烂果谁承担、到货几小时内可反馈、照片视频怎么留证、补货还是折价。没有这条，长期合作很容易扯皮。

4. **采后处理和冷链是否到位**  
   水果不是采下来就能卖。预冷、分拣、包装、冷链运输直接影响货架期。尤其做长期生意，要关注供应商是否有稳定冷库、是否混装串味、运输温度是否可控。便宜但冷链差的货，损耗会更高。

5. **账期和资金占用**  
   不要只看单价。现结、压批、账期不同，实际资金成本差别很大。长期合作要明确结算周期、对账方式、返利或损耗补偿规则，避免旺季被资金压住。

6. **售后响应速度**  
   水果问题有时效性，供应商能不能当天回应、快速补货，比合同写得多漂亮更重要。可以观察他对小问题的处理态度，长期合作看的是出问题后的解决能力。

7. **供应季节和产地切换能力**  
   单一产地依赖风险高。要问清楚产季结束后从哪里补、切换产地时品质能否衔接。长期稳定生意需要供应商有跨产区调配能力，而不是只做一季。

8. **包装和物流细节**  
   箱规是否统一、内衬是否到位、托盘和周转筐是否回收、装卸是否粗暴，这些都会影响终端卖相。很多损耗不是水果本身问题，而是包装和装卸造成的。

9. **是否愿意提供真实样品和历史数据**  
   靠谱供应商敢让你看真实批次，而不是只拿最好的样品。可以要求看近期发货记录、损耗反馈、客户类型，判断是否匹配你的客群。

10. **合作边界和独家性**  
    如果你做区域生意，要提前谈清楚是否给同区域其他客户供货、价格是否统一、促销支持怎么算。避免自己把市场做起来后，供应商低价放货给周边竞争者。

建议落地做法：先列一张供应商评估表，把“品质稳定性、分级标准、损耗责任、冷链能力、账期、售后响应、产地备份”做成可打分项；先小批量试单 2—3 周，再决定是否长期合作。长期稳定的核心不是找到最便宜的供应商，而是找到**品质波动小、出问题能兜底、规则提前说清楚**的供应商。
