建议把评分标准设计成“资格门槛+技术/履约能力+商务报价+长期合作保障”四段，水果品类尤其要防止“低价中标、后期以次充好”。

**一、先设资格门槛（不占评分，避免无效投标）**
- 营业执照、食品经营许可/食用农产品销售资质
- 近2年无重大食品安全处罚、无严重失信记录
- 具备产地直采或一级批发能力，能提供产地证明/检测报告
- 有冷链运输能力（车辆、温控记录）
- 能开具合规发票，接受账期和结算规则

**二、技术/履约能力评分（建议50—60分）**
1. **货源与产地能力（10—15分）**：自有基地、合作基地、产地直采比例、主产区覆盖、反季节供应能力。要求提供基地协议、产地证明，不接受只写“有渠道”。
2. **品控与食品安全（15—20分）**：农残检测能力、第三方检测报告频次、到货抽检合格率承诺、不合格品处理机制、追溯体系。可设置“承诺到货合格率≥98%”并挂钩罚则。
3. **冷链与物流履约（10—15分）**：冷链车辆数量、温控记录、配送频次、门店覆盖能力、应急补货时效。水果损耗高，重点看“到店时效”和“温控可验证”。
4. **品类供应与稳定性（5—10分）**：SKU覆盖、季节性切换方案、缺货替代方案、节假日保供能力。
5. **服务与售后（5—10分）**：退换货响应、损耗赔付、专属对接人、对账结算配合度。

**三、商务报价（建议25—35分）**
- 不要只比总价，建议按“品类报价+费率/加价率”综合评分。
- 设置**最高限价**和**异常低价审查**：低于成本或明显偏离市场价的，要求书面说明并提高履约保证金。
- 报价评分可用“基准价法”，但水果价格波动大，建议约定**价格联动机制**：以批发市场均价或产地价为基准，按周/月调价，避免中标后锁死价格导致断供或降质。

**四、长期合作保障（建议10—15分）**
- 履约保证金/质量保证金
- 食品安全责任险
- 违约与退出机制承诺：连续抽检不合格、断供、以次充好的处理
- 应急保供预案
- 信息化对接能力（订单、库存、追溯数据）

**五、权重建议**
- 技术/履约能力：50—60分
- 商务报价：25—35分
- 长期合作保障：10—15分
- 可加“现场考察/样品盲测”5—10分，水果很吃实际口感与到货状态，书面材料容易美化。

**关键控制点**
1. **样品盲测+到货抽检**写进评分和合同，不能只看投标文件。
2. **合格率、损耗率、断供次数**设为KPI，与结算、续约挂钩。
3. **不接受“最低价唯一决定”**，水果供应链低价往往意味着后期降质。
4. 评分表要可验证：每一项要求对应证明材料，避免评委主观打分过大。
