采购时把“熟度”和“到货时间”写成可验收的标准，比只说“别太熟”有用。建议这样要求：

**1. 按销售节奏分批要熟度**
- **当天—第2天要卖的**：要“黄熟但果尖不黑、果柄尚青、果身有轻微香味”，适合直接上架。不要整批都要这种，容易集中过熟。
- **第3—5天要卖的**：要“果身转黄、果柄青、棱角还略明显”的七八成熟蕉，到店后继续催熟/自然转黄。
- **备货缓冲**：保留一部分“青黄、硬身、无香”的蕉，作为后段销售和损耗缓冲。

**2. 到货时间要求**
- 优先要求**清晨到货或开店前1—2小时到货**，避免白天高温时段长时间装卸。
- 避开**午后高温到货**；如必须到，要求冷链车或遮阳运输，到店立即入阴凉通风处。
- 明确“**从产地/批发市场装车到门店不超过X小时**”，比如同城控制在2—4小时内，跨城按实际线路约定。

**3. 写进采购单的验收话术**
可以这样写：
> 香蕉要求：果柄青绿、果身无大面积黑斑、无裂果、无机械伤；按到货批次分熟度：A批黄熟可即售，B批七八成熟可2—3天转黄，C批青黄硬身作缓冲。到货时间不晚于每日开店前1小时，运输需遮阳通风，到货果温不得明显发热。不符合熟度或到货延迟导致集中过熟的，按约定折价或拒收。

**4. 配套做法**
- 每次到货**抽箱看内部**，不能只看表层。
- 到店后**拆箱、通风、分级**，熟的和青的分开放。
- 采购量按“**日销量×1.5—2天**”控制，高温季节再压缩。
- 和供应商约定**一周内可调熟度比例**，比如周一多要青黄、周五多要黄熟，避免周末后积压。

核心是：**不要把“熟度”说成一个模糊词，而是分成即售、过渡、缓冲三档，并把到货时间卡在开店前、避开高温时段。**
