优先建议：**先上“小把（3–5根）”作为主力，同时配少量单根，整袋只做补充或团购/家庭场景，不建议一上来把整袋当主包装。**

判断依据和可执行建议：

1. **主力选小把（3–5根）**
   - 便利店核心是即时消费和小家庭采购，小把比整袋更容易冲动购买。
   - 比单根更有客单价，也减少顾客“只买一根不好拿/不好意思”的阻力。
   - 建议定价按“把”标价，不要按斤称重，收银效率高。

2. **保留少量单根**
   - 满足“只想吃一根”“搭配早餐/酸奶”“控量”的顾客。
   - 单根适合做低价引流，但损耗和理货成本高，所以只保留少量，放在收银台或鲜食区附近。
   - 单根要选外观完整、大小均匀的，避免被挑剩。

3. **整袋谨慎上**
   - 整袋适合家庭采购、办公室分享、促销组合，但便利店场景转化率通常低于小把。
   - 如果上整袋，建议只做1–2个SKU，放在货架下层或端架，不要占黄金位。
   - 可做“整袋略优惠”的价格锚点，让小把显得更划算。

4. **按门店类型微调**
   - 社区店/家庭客多：小把为主，整袋可适当增加。
   - 商圈店/写字楼店：单根+小把为主，整袋少上或不上。
   - 学校/医院/交通枢纽：单根和小把优先，强调即买即吃。

5. **实操测试方法**
   - 先做2周测试：小把占60%，单根占25%，整袋占15%。
   - 每天记录销量、损耗、废弃量。
   - 如果单根损耗高，就减少单根；如果整袋动销慢，就改为预订或促销组合。

**结论：主力小把，辅助单根，整袋做补充；先小批量测试再调整陈列比例。**
