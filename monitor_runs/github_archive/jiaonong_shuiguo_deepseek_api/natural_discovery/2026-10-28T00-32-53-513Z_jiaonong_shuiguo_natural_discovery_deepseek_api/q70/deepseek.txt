# 坏果责任的合同写法建议

核心思路：**把“坏果”从模糊概念变成可计量、可举证、有处理流程的条款**。建议分五个层次写：

## 1. 先定义“坏果”标准（最关键）

不要只写“坏果”，要写明判定口径，例如：

> 坏果指符合下列任一情形的果实：霉变、腐烂、软烂渗汁；机械损伤面积超过单果表面积X%；虫蛀、病斑；单果失水皱缩影响商品性；不符合约定规格（如单果重低于约定下限）。

最好约定**抽样方法**：按批次随机抽取N箱、每箱抽N个，以抽样坏果率推算整批。抽样比例和判定人（双方现场共同验收或第三方）都要写明，避免事后扯皮。

## 2. 约定坏果率的责任分界

给出**阶梯式**而非一刀切的处理：

| 坏果率 | 处理方式 |
|---|---|
| ≤3%（自然损耗） | 买方承担，不扣款 |
| 3%–8% | 按实际坏果数量折价扣款 |
| >8% | 买方可拒收整批，或要求按比例降价并保留索赔权 |
| 因卖方包装/采摘不当导致 | 不受上述阈值限制，卖方全额担责 |

阈值按品类实际定，叶菜、浆果类通常更严。**自然损耗与卖方过失要分开写**，否则批发商容易把运输途中正常失水也算成卖方责任，或反过来卖方拿“自然损耗”挡掉所有索赔。

## 3. 明确责任归属的时间节点

写清**风险转移点**：装车时、到货卸货时还是验收合格时。建议约定“以到货后X小时内双方共同验收结果为准”，并规定超期未验收视为合格（防止买方拖延）。同时区分：运输方由谁指定——若买方指定承运人，运输致损责任相应转移。

## 4. 处理流程与举证

- 到货后**X小时内**书面（含微信/邮件）提出异议，附照片、视频、抽样记录；
- 双方在**X日内**共同复验或委托第三方检测，费用由责任方承担；
- 逾期未提异议视为验收合格。

## 5. 赔偿方式写具体

不要只写“赔偿损失”，要写计算方式：

> 赔款 = 坏果数量 × 该批次约定单价；或整批拒收时，卖方退还货款并承担买方已支付的合理运费。

可加**封顶条款**（如赔偿不超过该批次货款的X%），但注意：若卖方存在故意或重大过失（如明知腐烂仍发货），封顶条款不适用。

---

**一句话提醒**：批发商最容易吃亏的地方是“坏果”没定义、验收时限没写、举证责任没分配。把这三项落到纸面，比笼统写“卖方保证质量、坏果负责”有用得多。具体阈值和时限建议参照你所在品类的行业惯例和你与供应商的实际议价能力来定。
