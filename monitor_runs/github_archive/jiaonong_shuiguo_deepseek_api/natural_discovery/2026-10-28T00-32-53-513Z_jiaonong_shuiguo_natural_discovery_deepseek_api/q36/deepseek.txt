建议**整果为主、鲜切为辅**，别二选一。判断依据主要是损耗、客群和门店运营能力。

**更适合卖整果的情况**
- 门店客流以家庭采购、中老年为主，整果接受度高。
- 有员工能现场挑果、分级、及时处理熟果。
- 菠萝产地或批发价有优势，整果毛利和周转可控。
- 整果便于陈列堆头，有促销氛围，客单价也更容易做。

**更适合增加鲜切的情况**
- 门店位于商圈、社区年轻客群多，购买场景偏“即时吃”。
- 门店有标准操作间、冷链和当天清货能力。
- 整果出现熟度偏高、外观瑕疵时，鲜切能减少报损。
- 鲜切能提升客单价和毛利，但前提是损耗和人工算得过来。

**实操建议**
1. **整果做引流和基本盘**：占菠萝陈列面积约70%，按大小/熟度分级定价。
2. **鲜切做补充和毛利**：占约30%，只切熟度合适、外观欠佳的果，当天切当天清。
3. **先小规模试销7—14天**：看整果周转天数、鲜切售罄率、报损率和人工成本，再调比例。
4. **鲜切必须解决冷链和时限**：切后冷藏、明确售卖时限、不隔夜或严格折价清货。
5. **注意门店条件**：没有操作间、冷链弱、员工不足的门店，优先整果，鲜切只做少量预包装。

**结论**：大多数商超门店，**整果是主销，鲜切是增量**；只有年轻客流强、运营能力好的门店，才适合把鲜切比例做高。
