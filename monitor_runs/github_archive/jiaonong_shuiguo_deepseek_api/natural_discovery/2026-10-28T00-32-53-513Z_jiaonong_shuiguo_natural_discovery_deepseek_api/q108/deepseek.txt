核实“全国配送”不能只听口头承诺，建议按“先验证、再小单、后放量”的顺序做，重点核查以下6项，并要求供应商提供可验证材料。

1. **要配送范围清单，不要只看“全国”两个字**
   - 要求提供：可配送省份/城市清单、偏远地区是否排除、县级市/乡镇是否覆盖。
   - 重点问：新疆、西藏、青海、内蒙古、海南、黑龙江偏远地区、县乡地址是否加价或不到。
   - 判断标准：能给出城市级或邮编级范围表的，可信度高于只口头说“全国都能发”。

2. **核实仓储与发货地**
   - 问清：水果从哪个仓/产地发？有几个分仓？覆盖哪些区域？
   - 要求提供仓库地址、照片、租赁合同关键页或视频看仓。
   - 判断标准：只有一个仓却承诺全国次日达，通常不现实；多仓或产地直发要能对应线路。

3. **用真实收货地址做试单**
   - 不要只发总部地址，选3—5个有代表性的地址：一线城市、普通地级市、县级市、乡镇/偏远地区。
   - 每个地址下小单，记录：下单到发货时长、物流单号、实际承运商、到达时效、包装和损耗。
   - 判断标准：试单能覆盖你实际要发的区域，且时效、损耗可接受，才算有覆盖能力。

4. **核查物流合作与轨迹可查性**
   - 要求说明合作快递/冷链承运商，是否能提供全程温控和轨迹。
   - 试单时核对物流信息是否真实可查，是否出现“虚假发货”“转单”“到不了的件退回”。
   - 水果重点看：是否冷链、是否保价、破损/腐坏理赔规则。

5. **要求书面承诺与赔付条款**
   - 把配送范围、时效、偏远地区加价、损耗率、坏果赔付、超时处理写进合同或报价单。
   - 明确“不到/超时/腐坏”的责任和退款方式。
   - 判断标准：只愿意口头承诺、不愿写进合同的，风险较高。

6. **做小批量压力测试再放量**
   - 先下小批量多地址订单，连续测试1—2周，统计准时率、破损率、客诉率。
   - 达到约定标准后再扩大采购量，并保留备用供应商。

**可执行结论**：让供应商先提交“配送范围表+仓库信息+合作物流+赔付条款”，你用4类真实地址各下一单试发；试单全部可查、时效和损耗达标，再签小批量合同。任何一项不愿提供或试单失败，就不应按“全国配送”采购。
