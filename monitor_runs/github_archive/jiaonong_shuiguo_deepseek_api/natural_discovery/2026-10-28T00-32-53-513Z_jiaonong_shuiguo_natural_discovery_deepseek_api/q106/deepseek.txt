判断“合理波动”不要看单日涨跌，而要看**同类品种的比价、时间序列、成本构成、到货品质和市场横向报价**。可以按下面做：

**1. 先设“可解释波动”和“异常波动”两档**
- 合理波动：同一品种、同等级、同包装、同到货地，日环比在常见区间内，且能被天气、产地切换、节假日、运输、损耗解释。
- 异常波动：单日跳涨/跳跌明显超出历史区间；连续几天单边涨；不同供应商报价差异突然拉大；涨价但等级、包装、损耗没变。

**2. 用历史数据判断，不看单日报价**
建议每个核心单品保留至少30—90天报价，记录：日期、品种、等级、规格、包装、产地、到货市场、含税/不含税、运费、损耗率、报价方。计算：
- 7日移动均价；
- 日环比、周环比；
- 历史波动区间（如近30天P25—P75）；
- 当前价偏离移动均价的幅度。
超过历史常见区间且连续2—3天，才进入核查。

**3. 同品类横向比价**
同一市场、同一等级至少询2—3家供应商，比较“到岸净价”而不是表面单价。把运费、包装、损耗、账期、含税与否统一折算。若只有一家涨、其他家没涨，多半不是市场性波动。

**4. 拆成本，看涨价是否有依据**
水果日价主要受：产地收购价、季节性换茬、天气灾害、运输燃油/冷链、市场到货量、节假日需求、品质等级变化影响。要求供应商报价时同步给：产地、等级、规格、包装、到货量、是否换产地。不能解释的涨价，先按异常处理。

**5. 看品质和规格是否“暗涨”**
重点防：降等级、缩小规格、换便宜产地、增加损耗、减少净重、包装变差、把运费另算。判断合理波动必须锁定“同品质同规格同交付条件”。

**6. 建立简单规则**
可执行规则示例：
- 日涨幅在近30天正常区间内且能说明原因：正常采购；
- 连续2天超过区间上限：要求供应商书面说明并给替代报价；
- 单日异常跳涨：暂停下单，向2家以上备选供应商询价；
- 价格未变但到货合格率下降：按品质异常处理，不视为合理波动；
- 大单采购采用“当日市场均价+固定服务费”或“7日均价锁价”减少博弈。

**7. 合同和流程上留后手**
约定报价有效期、调价触发条件、等级验收标准、损耗上限、替代产地规则；保留每日报价截图/单据；对核心单品设价格预警线。这样采购方判断的不是“供应商说合不合理”，而是“是否符合约定和历史区间”。

一句话：**同品同质同交付条件下，看历史区间、横向比价和成本解释；单日小波动可接受，连续偏离、无法解释、只此一家涨或品质暗降，就不是合理波动。**
