小店做水果，核心不是“品类齐全”，而是“少SKU、快周转、强控损”。给你一套可直接落地的做法。

## 1. 品类控制：先做“窄而深”

**SKU上限建议：12～20个单品**（含季节性轮换），按角色分四类：

- **引流款（3～4个）**：苹果、香蕉、橙子、梨这类高频、耐放、价格敏感的。必须常备，定价略低拉客流。
- **利润款（3～4个）**：应季优质果，如当季草莓、车厘子小盒装，毛利高、走量适中。
- **便利款（3～5个）**：切果盒、小份装、单果装。小店最大优势是“买了就能吃”，别跟大超市拼整箱。
- **试销款（1～2个）**：每周只引1～2个新品，卖不动立即下架，不占长期排面。

**淘汰规则要写死**：单品连续3天日均销量低于阈值（比如低于2份/天）或损耗率超15%，直接下架，不恋战。

## 2. 采购量：按“日销×天数”倒推，别凭感觉

- **订货公式**：订货量 = 近7日日均销量 × 覆盖天数 ×（1+安全系数）− 现有库存。
- **覆盖天数分品类**：耐放果（苹果、橙、梨）2～3天；易损果（香蕉、葡萄、草莓、桃）1天甚至半天；切果原料当天进当天用。
- **少量多次**：小店宁可每天补、两天一补，也不要一次压一周货。单次采购金额控制在预估日销额的2～3倍以内。
- **按份采购**：能按小箱、小份、拼箱拿的，绝不整大箱。和供应商谈“小批量、高频次”供货，哪怕单价略高，也比损耗划算。

## 3. 损耗控制：从进货到出清全链路

**进货端**
- 只选1～2家稳定供应商，明确“到货验收标准”：坏果率超约定比例当场拒收或换货。
- 易损果避开周末前大量进货，按实际客流节奏补。

**陈列端**
- 小面积店用**少量多次上架**：排面只摆半天量，卖完再从后仓补，减少翻捡和压伤。
- 易损果单独小筐陈列，别堆高；香蕉、芒果等分开催熟/冷藏区。
- 每天早晚两次挑拣，坏果立即下架，避免传染。

**定价与出清**
- 设置**阶梯折扣**：临期/品相下降的果，下午起8折、闭店前5折或做“10元3份”组合包。
- 切果盒是损耗转化利器：品相稍差但完好的果，当天切盒卖出，标注制作时间。
- 建个门店社群，每天固定时段发“今日特价/临期包”，把尾货提前消化掉。

**数据端**
- 每天记三件事：进货量、销售量、报损量。每周算单品损耗率，超过10%～15%的品类砍掉或换供应商。
- 用“售罄率”判断：经常下午就卖空的品可略加量；经常剩到闭店的品减量或换品。

## 4. 小店特别提醒

- **面积小就别做全品类**：水果区占门店面积建议控制在10%～15%，用立式小货架+冷藏小柜，别铺大堆头。
- **优先做“便利”而非“便宜”**：小份装、切果、组合果篮，毛利和周转都比整箱走量更适合小店。
- **季节切换要快**：每月初定一次品类表，应季果只留1～2个试销位，卖不动一周内撤。

一句话原则：**品类做减法、采购做高频、陈列做小量、尾货做转化、数据做淘汰。** 先跑两周记录真实销量和损耗，再据此定SKU和订货天数，比任何经验都准。
