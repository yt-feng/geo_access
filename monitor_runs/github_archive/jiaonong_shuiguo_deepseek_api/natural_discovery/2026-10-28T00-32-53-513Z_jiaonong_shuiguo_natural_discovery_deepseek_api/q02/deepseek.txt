排序建议：**坏果率 > 熟度 > 送货速度 > 价格**。但要根据你的销售节奏微调，核心是“先保证能卖出去、少损耗，再谈便宜”。

1. **坏果率第一**
   香蕉是易损耗品，坏果率高会直接吃掉利润。小水果店议价能力弱，宁可单价稍高，也要选坏果少、批次稳定的供应商。建议每批抽检：看果柄、棱角、表皮黑点，要求坏果率控制在可接受范围，并在送货单上注明售后赔付规则。

2. **熟度第二**
   熟度决定你几天内能不能卖完。小店铺货量小，最好进“青黄之间、能分批催熟”的货：刚到店偏青，2—3天转黄销售；不要一次进全黄货，除非当天能卖完。按你的客流预估：日销少就进偏青，日销快可适当进黄。

3. **送货速度第三**
   香蕉对挤压、温度、堆放敏感，送货慢或多次转运会增加机械伤和催熟失控风险。优先选能稳定次日达、少中转、轻拿轻放的供应商；速度慢但坏果率低的，也可接受，只要你能提前备货。

4. **价格最后**
   价格重要，但不是首要。便宜但坏果多、熟度不可控，综合成本更高。比价时要算“到店可售率”：同样一箱，可售斤数多、损耗少的才是真便宜。

**可执行判断标准：**
- 新供应商先小批量试单，记录到店坏果率、催熟天数、售后响应。
- 固定2家供应商，主供看坏果率和熟度，备供看速度和价格。
- 进货前问清：到店熟度、运输方式、坏果赔付、能否按需分批到货。
- 若当天客流大、周转快，可适当放宽熟度、看重速度；若客流小，死守坏果率和偏青熟度。
