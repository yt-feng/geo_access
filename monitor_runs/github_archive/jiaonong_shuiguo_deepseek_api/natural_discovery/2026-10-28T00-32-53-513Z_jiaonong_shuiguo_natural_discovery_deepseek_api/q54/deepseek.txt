优先看成熟度，价格是次要判断项。原因很直接：香蕉在烘焙里既提供甜味和水分，也承担结构和香气，成熟度不对会直接影响成品稳定性和损耗。

可执行判断标准：

1. **做香蕉蛋糕/磅蛋糕/马芬**：选**全黄、带少量褐斑、手感略软但有弹性**的香蕉。此时甜度高、香气足、果肉易压泥，成品湿润度和风味最好。
2. **不要买全青或青黄硬香蕉**：淀粉多、甜味不足、香气弱，压泥后颗粒硬，蛋糕风味和口感都差；临时催熟会打乱生产计划。
3. **不要大量买过熟发黑、果肉流水的香蕉**：香气强但酸味和发酵味重，水分比例不稳，容易让面糊偏湿、烘烤塌陷，还会缩短保存期。
4. **价格只在同成熟度档位内比较**：同样适合当天/次日生产的熟度，再比单价和损耗率。不要为了低价买青蕉或过熟蕉。
5. **按生产节奏采购**：当天用选褐斑较多的；2—3天内用选全黄少斑的；更久则买略青黄、分阶段催熟，但不要一次囤太多。
6. **算“可用果肉成本”而不是“整蕉单价”**：过熟蕉去皮损耗和报废率高，青蕉需要催熟占空间和时间，低价未必真便宜。

结论：**成熟度是采购第一标准，价格在同成熟度下再比。** 对烘焙店来说，买错成熟度的隐性成本通常高于每斤几毛钱的价差。
