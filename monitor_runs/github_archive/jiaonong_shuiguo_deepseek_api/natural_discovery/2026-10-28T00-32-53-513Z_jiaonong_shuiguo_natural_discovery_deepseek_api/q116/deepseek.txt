# 小商家采购水果：现金结算 vs 月结账期的风险

## 现金结算的风险

**1. 资金占用与周转压力**
水果采购频次高、金额碎，现金结算意味着每批货都要即时掏钱。旺季（节日前）集中备货时，现金流可能被压得很紧，遇到突发情况（滞销、价格暴跌）没有缓冲。

**2. 无账期杠杆，议价能力弱**
现金付清后，对供应商几乎没有"欠款筹码"。出了问题（烂果率高、缺斤少两、以次充好）只能靠事后追偿，而水果是易腐品，事后举证困难，往往只能自己认亏。

**3. 对账与凭证风险**
现金交易若没有规范单据（送货单签字、批次重量、等级记录），出现纠纷时无据可查。部分现金交易不开票，也无法入账抵扣。

**4. 安全与操作风险**
现金携带、找零、假币、被偷被抢的风险，对早市、夜市采买尤其现实。

**现金结算的好处也要说清：** 通常能拿到更低单价或即时折扣，供应商关系简单，不背债，不会被账期绑架。

---

## 月结账期的风险

**1. 供应商信用风险反向传导**
你欠供应商钱的同时，供应商若因资金链断裂断供，你的货源会突然中断，而水果生意断货几乎等于当天没生意。

**2. 质量纠纷与扣款博弈**
月结意味着"先收货、后付钱"，看似有利，但供应商可能把好货优先给现结客户，给你的是尾货；出问题时双方容易陷入"扣不扣款、扣多少"的拉扯，影响后续合作。

**3. 账期管理失控**
水果损耗大、批次多，月底对账容易出现"这筐烂果算谁的"的争议。若没有每批次的验收记录，账目会越滚越乱，最后要么多付钱，要么关系闹僵。

**4. 隐性成本与依赖**
账期通常不是白给的——供应商可能把单价上浮几个点来覆盖资金成本；同时长期月结会让你对单一供应商形成依赖，议价空间反而被锁死。

**5. 违约与法律风险**
月结本质是赊账，一旦经营不善拖欠，可能面临催收、起诉，甚至影响个人征信（如果是个人名义赊账）。

---

## 给小商家的实操建议

| 场景 | 建议 |
|---|---|
| 新供应商 / 首次合作 | 先现金或短账期（7天）试单，验证质量稳定性 |
| 核心畅销品、高频采购 | 争取"部分现结 + 部分月结"混合模式，降低单方风险 |
| 月结合作 | 必须做到**每批次验收签字**（重量、等级、损耗），月底凭单对账 |
| 无论哪种方式 | 保留送货单、转账记录、聊天记录；现金交易也要开收据 |
| 现金流底线 | 月结总额不超过月采购额的 50%，避免被账期拖死 |

**一句话总结：** 现金结算的风险在"钱一次性出去、出问题没抓手"，月结的风险在"依赖供应商、对账和质量纠纷难扯清"。小商家更稳妥的做法是**短账期 + 严格验收单据 + 不把采购押在单一供应商身上**，而不是在"全现金"和"全月结"之间二选一。
