连锁超市和水果供应商签年度合同，最容易踩坑的集中在“价格机制、质量标准、损耗归属、交付与库存风险、结算与返利、违约与退出”六块。下面按可执行判断列出来：

1. **价格机制**
   - 坑：只写“随行就市”或“按市场价”，年底容易扯皮。
   - 建议：写清楚定价公式（基准市场/产地价+固定加价/折扣）、调价周期（周/月）、调价触发条件（涨跌幅超X%）、调价需双方书面确认，并约定价格上限或封顶机制。

2. **质量标准与验收**
   - 坑：只写“符合国家标准”，水果等级、糖度、大小、色泽、农残、新鲜度没量化。
   - 建议：附《质量验收标准表》，按品类写等级、规格、糖度、瑕疵率上限、农残检测要求；明确验收方式（到货抽检/第三方检测）、抽检比例、不合格处理（拒收/折价/退货）和复检费用承担。

3. **损耗与退货归属**
   - 坑：到货后才发现坏果，责任说不清；超市内部损耗让供应商背。
   - 建议：区分“到货前损耗”和“到货后损耗”。到货验收不合格由供应商承担；验收合格后超市存储不当由超市承担；明确退货时限、退货比例上限、退货运输费用谁出。生鲜尤其要写“短保品临期处理规则”。

4. **交付与库存风险**
   - 坑：年度合同只写总量，没写分批计划；旺季断供或淡季压货。
   - 建议：写月度/周度滚动订单机制、最低起订量、提前下单天数、缺货违约金、旺季优先供应条款；约定不可抗力（天气、疫情、交通管制）下的通知和替代方案。

5. **结算、返利与费用**
   - 坑：账期模糊、返利条件不清、进场费/促销费/损耗费乱扣。
   - 建议：明确账期（如月结30/60天）、对账日、发票类型和税率；返利写清计算基数（含税/不含税、实际回款额）、达成条件和支付时间；所有费用列清单并写明是否含在报价内，禁止口头扣费。

6. **违约、退出与知识产权/合规**
   - 坑：年度合同没写提前解约条件；供应商断供或超市拖欠货款没有对等责任。
   - 建议：写双方违约责任对等条款、连续断供/质量事故的解约权、提前通知期（如30/60天）、库存清退和尾款结算方式；要求供应商提供营业执照、食品经营许可、农残检测报告，并约定合规责任由供应商承担。

**签约前最该做的三件事**：把质量验收标准做成附件并双方签字；用历史数据测算全年采购量和价格波动区间；把“调价、退货、扣费”三类争议写成书面流程，避免年底集中扯皮。
