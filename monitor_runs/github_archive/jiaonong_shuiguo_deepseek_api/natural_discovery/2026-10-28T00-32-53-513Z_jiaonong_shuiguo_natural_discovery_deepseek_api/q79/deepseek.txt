最应该先问**配送**，其次**售后**，最后才是**价格**。

原因很直接：团购团长卖的是“确定性和口碑”，不是单纯倒卖水果。

**1. 配送优先问，因为它决定你能否履约**
水果有时效、易损耗，团长最怕的是：说好早上到，结果下午才来；说好送到自提点，结果让团长去搬；坏果率高还混在正常货里。你要重点问清楚：

- 几点前下单、几点送到？能否固定时段？
- 送到自提点还是送到团长指定位置？谁卸货？
- 破损、压伤、漏送怎么算？是否当场拍照确认？
- 临时加单、少货、晚到怎么处理？
- 冷链或普通配送？夏季高温怎么保证？

配送不稳，售后和价格都会变成空话。

**2. 售后第二问，因为它决定你亏不亏**
重点不是问“有没有售后”，而是问清楚规则：

- 坏果率超过多少可以整批处理？
- 是补发、退款还是下次抵扣？
- 拍照时限多久？需要整箱保留吗？
- 售后响应时间多长？谁对接？
- 临期、软烂、大小不符算不算售后？

**3. 价格最后谈，但要谈“到手成本”**
不要只比单价，要算：单价 + 损耗 + 配送费 + 售后损失 + 团长时间成本。低价但坏果多、配送乱，最后一定不赚钱。

**一句话判断：**
先选**配送稳、售后规则清楚**的供应商，再在同等条件下比价格。配送和售后都不过关的，价格再低也不要接。
