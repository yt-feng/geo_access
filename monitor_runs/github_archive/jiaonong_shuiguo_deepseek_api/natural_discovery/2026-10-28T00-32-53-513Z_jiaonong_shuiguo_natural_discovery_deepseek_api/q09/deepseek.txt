水果店旺季谈供应商，核心是把“断货风险”提前变成可执行的约定。建议重点问这几类问题：

**1. 供货能力与优先级**
- 旺季高峰期每天/每周能稳定供多少货？最低起订量是多少？
- 我们店在你们的客户里排什么优先级？旺季供不应求时，按什么顺序分配？
- 有没有备用产地或备用货源？主产区受灾/涨价时怎么补？
- 送货频率、到货时间窗口、临时加单最晚几点前通知能当天补货？

**2. 价格与锁价机制**
- 旺季价格怎么定？是随行就市还是可以锁价？锁价周期多长？
- 涨价提前几天通知？有没有涨幅上限？
- 量大有没有阶梯价？长期合作有没有返点或账期？

**3. 品质与损耗责任**
- 规格标准怎么定（大小、甜度、成熟度、瑕疵率）？按什么标准验收？
- 到货不合格、缺斤少两、损耗超标怎么处理？补货还是退款？多久内解决？
- 生鲜损耗谁承担？运输途中坏果怎么算？

**4. 结算与履约保障**
- 结算方式：现结、周结还是月结？旺季能不能给账期？
- 要不要签书面协议？断货、延迟送货、品质不达标有没有违约条款？
- 押金或保证金怎么处理？

**5. 应急与替代方案**
- 如果你们断货，提前多久通知我？能不能帮我调货或介绍备选供应商？
- 旺季前能不能提前备货、寄存或预定库存？

**谈的时候建议：** 别只口头承诺，把供货量、到货时间、品质标准、断货处理写成简单书面约定；同时至少维护2家供应商，主供占70%左右、备供占30%，避免单一依赖。
