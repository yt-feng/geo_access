会，而且香蕉和菠萝的损耗风险还不一样。

**结论：起订量高会明显增加损耗风险，尤其是香蕉；菠萝相对可控但也会被拖累。**

具体判断：

1. **香蕉：高风险**
   - 香蕉后熟快，到货后销售窗口短，起订量高容易造成集中催熟、集中变软，卖不完就报废。
   - 香蕉对温度、挤压、乙烯敏感，库存一多，搬运和堆压损耗也会上升。
   - 如果门店销量不稳定，高起订量基本等于把损耗风险提前锁死。

2. **菠萝：中高风险**
   - 菠萝耐储性比香蕉好一些，但高起订量会带来积压、失水、黑心、腐烂和周转慢的问题。
   - 菠萝体积大、占陈列和仓储空间，起订量高会挤压其他品类的周转。
   - 如果切果销售，起订量高还会增加切后未售完的损耗。

3. **共同风险**
   - 资金和库位被占用，导致不敢及时降价处理，损耗进一步扩大。
   - 到货集中时质检压力大，次果混入概率上升。
   - 销量预测一旦偏差，高起订量会放大偏差。

**可执行建议：**
- 先按最近4周日均销量和周末峰值测算，起订量尽量控制在**3—5天销量**内；香蕉建议更短，**2—3天**。
- 香蕉优先小批量、多频次补货；菠萝可略高，但别超过**5—7天**销量。
- 和供应商谈**拆包起订、混装起订、阶梯价**，不要只接受整箱高起订。
- 设置损耗预警线：香蕉到货后48小时未售出比例超过30%，就启动促销或调拨；菠萝7天内周转率低于预期就降价处理。
- 新供应商或新门店先小批量试单，跑通销量再提高起订量。

简单说：**起订量高不是绝对不行，但必须和销量周转匹配；香蕉尤其不能压货。**
