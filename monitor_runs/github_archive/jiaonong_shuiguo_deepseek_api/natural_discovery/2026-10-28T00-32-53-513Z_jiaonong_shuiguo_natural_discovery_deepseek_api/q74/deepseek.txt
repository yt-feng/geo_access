做餐饮客户，菠萝和香蕉的规格不要按“零售好看”来备，要按**后厨出成率、加工方式、配送稳定性**来分。建议你先按下面规格各备1—2个主推SKU，再用小批量试单验证。

### 菠萝：按加工方式分3档
1. **鲜切/果盘/饮品店主推**
   - 单果重：1.2—1.5kg/个，果形端正、无黑心
   - 成熟度：7—8成熟，到店可放1—2天转熟
   - 包装：9—12个/箱，净重约12—15kg
   - 适合：果汁、果切、甜品装饰

2. **后厨现削/炒饭/咕噜肉**
   - 单果重：1.5—2kg/个，出肉率高
   - 成熟度：8成熟，香气足但不过软
   - 包装：6—9个/箱，净重约12—18kg
   - 适合：热菜、炒饭、糖水

3. **低价走量/员工餐/团餐**
   - 单果重：1—1.2kg，允许果形略不规整
   - 成熟度：7成熟，耐放
   - 包装：10—12个/箱
   - 适合：对卖相要求低、成本敏感的客户

**关键提醒**：餐饮客户最怕菠萝黑心、过熟出水。建议主推“8成熟、单果1.5kg左右、箱装净重稳定”的规格，并明确到货后2—3天内用完。

### 香蕉：按用途分3档
1. **饮品店/甜品店/果切**
   - 规格：单根120—150g，每把5—6根
   - 成熟度：到店7—8成熟，可快速转黄
   - 包装：13—15kg/箱
   - 要求：无机械伤、无黑斑集中

2. **后厨/早餐/食堂**
   - 规格：单根150—180g，大小均匀
   - 成熟度：6—7成熟，耐配送
   - 包装：12—14kg/箱
   - 适合：按根配餐、批量使用

3. **低价走量/团餐**
   - 规格：单根100—130g，允许略小
   - 成熟度：6成熟，耐放
   - 包装：10—13kg/箱
   - 适合：成本优先、外观要求低

**关键提醒**：香蕉餐饮客户最在意“到店后熟速度可控”。建议主打“6—7成熟、单根150g左右、箱装12—14kg”，并给客户一个简单的催熟/存放建议。

### 建议你先这样备货
- **菠萝主推1款**：1.5kg左右/个，8成熟，6—9个/箱，净重12—18kg
- **菠萝辅推1款**：1—1.2kg/个，7成熟，低价走量
- **香蕉主推1款**：单根150g左右，6—7成熟，12—14kg/箱
- **香蕉辅推1款**：单根120—150g，7—8成熟，供饮品甜品客户

另外，给餐饮客户报价时最好同时给：**箱规、净重、单果/单根均重、成熟度、到货后建议使用天数、损耗处理方式**。这比只报“多少钱一斤”更容易成交。
