旺季菠萝用量突增，和供应商约定临时补货，核心是先锁“可执行承诺”，再留“弹性”，避免口头答应、到时没货或坐地起价。可以按下面做：

1. **先算清缺口和节奏**
   - 统计近7天实际用量、未来7天预估用量、现有库存、在途量。
   - 按“日用量×补货提前期+安全库存”算出每次临时补货量，别一次报一个拍脑袋的大数。
   - 把需求拆成“每日/隔日补货量”，供应商更容易接。

2. **和供应商签一个短期补充协议/订单确认**
   至少写清：
   - 品规：品种、单果重量区间、成熟度、是否去皮/切块、包装规格。
   - 数量：临时补货总量+每批最低/最高供货量。
   - 价格：临时补货价是随行就市还是锁定价；若浮动，约定参照哪个市场、浮动上限、调价提前通知时间。
   - 交期：下单截止时间、到店时间、迟到/缺货的处理。
   - 质量：坏果率、成熟度不达标、规格不符的退换货和扣款规则。
   - 结算：现结/账期、对账方式。
   - 违约：缺货赔偿、临时加价、连续断供的替代采购权。

3. **设置“弹性条款”而不是死合同**
   - 约定每日最低供货量+可追加比例，比如基础量之外可提前24小时追加30%。
   - 约定“优先供货权”：旺季期间你方临时订单优先于散客。
   - 约定“替代品规”：特定品种缺货时，可换同价位品种，需你方确认。

4. **用订单和沟通留痕**
   - 每次临时补货发书面订单（微信/邮件/系统订单均可），写明数量、到货时间、价格。
   - 供应商确认后截图存档；当天到货验收拍照、记录坏果率。
   - 不要只电话口头说，旺季最容易扯皮。

5. **准备备选供应商**
   - 临时补货不要只押一家，至少备1-2家本地批发商或二级供应商。
   - 提前问清备选方的起订量、配送时间、价格，写进通讯录。
   - 协议里保留“供应商连续2次未按约供货，可转向其他渠道且不承担违约责任”。

6. **可执行的谈判话术**
   “旺季我们用量会涨，但不想临时压你。我们按日给预估量，提前24小时下确认单；你给我们基础量+30%追加的优先供货，价格按约定市场价上浮不超过X%。缺货提前4小时通知，我们好调货。连续缺货两次，我们有权临时外采。”

7. **注意风险点**
   - 不要只约定总量不约定分批到货时间，否则供应商可能最后一天才送。
   - 不要接受“尽量供”这种模糊表述，要写最低供货量。
   - 价格浮动要设上限和通知期，防止旺季坐地起价。
   - 验收标准提前给供应商，避免到货后因成熟度扯皮。

简单说：**书面确认品规数量价格交期+每日滚动下单+最低供货量+追加比例+缺货处理+备选供应商**，这六件事做到，临时补货基本可控。
