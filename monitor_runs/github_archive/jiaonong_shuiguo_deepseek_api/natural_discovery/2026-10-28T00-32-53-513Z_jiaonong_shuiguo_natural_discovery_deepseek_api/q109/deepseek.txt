优先谈 **账期**，其次把 **售后** 写成可执行条款，最后再谈 **配送**。

原因很直接：长期水果供应里，账期影响你的现金流和议价权，售后决定坏果损耗由谁承担，配送虽然天天发生，但通常最容易通过固定规则解决，谈判收益反而最小。

建议按这个顺序谈：

1. **账期优先**
   - 先谈“结算周期 + 对账日 + 付款日”，不要只谈“月结”。
   - 例如：每周对账一次，次月10日前付款；或货到7天/15天付款。
   - 长期合作可争取阶梯账期：合作3个月后账期从现结延到7天，6个月后到15天。
   - 同时约定逾期付款是否影响供货价，避免供应商后面用涨价找补。

2. **售后第二，但必须写成条款**
   - 明确坏果率、短斤少两、规格不符、到货不新鲜的处理方式。
   - 建议约定：到货2小时内验收，坏果按实拍照计数，当场扣减或下批补货；超过约定坏果率可整批拒收。
   - 售后不谈清楚，账期再长也会被损耗吃掉。

3. **配送最后谈，但谈“规则”不是谈“感情”**
   - 固定下单截止时间、送达时间窗、临时加单规则、缺货替代规则。
   - 配送频率和起送量绑定价格：每日配送、隔日配送、满额免运费分别什么价。
   - 长期合作可要求旺季优先配送、节假日保供，但这类承诺要写进合同附件。

一句话判断：**账期决定你活不活得舒服，售后决定你亏不亏钱，配送决定你麻不麻烦。** 长期供应商谈判，先保现金流和损耗责任，再优化日常履约。
