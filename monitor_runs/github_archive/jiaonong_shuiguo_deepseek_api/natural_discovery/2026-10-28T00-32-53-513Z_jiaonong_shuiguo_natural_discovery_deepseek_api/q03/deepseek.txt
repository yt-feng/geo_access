第一次找供货商，别一上来就谈长期合作，用“小批量试单+明确验收标准”来筛人。按下面做：

**1. 先定试单原则**
- 每家供货商只试1次，单品少量：香蕉1箱、苹果1箱、橙子1箱，够卖2-3天即可。
- 同时试2-3家，别只押一家。
- 试单前问清：起送量、配送费、到店时间、是否可退换、账期还是现结、报价是否含税/含运费。
- 明确说“先试单，看品质和损耗再定长期”，避免被绑量。

**2. 每个单品重点看什么**
- **香蕉**：看成熟度（夫妻店最好要7-8成熟，别拿全黄或全青）、有无黑斑、掉把、催熟是否均匀；问清到店后几天能卖完，损耗谁承担。
- **苹果**：看果径是否均匀、有无碰伤/裂口/软果、箱内上下层是否一致；重点防“上面大果下面小果”。
- **橙子**：看皮是否发软、有无霉点、大小是否均匀、酸甜度是否稳定；试单时切开2-3个看汁水和口感。

**3. 试单当天要做记录**
到货后当场验：
- 称重：连箱重和净果重各记一次，算实际净重和单价。
- 抽检：每箱随机翻底层，看是否有压伤、烂果、大小混装。
- 拍照留证：坏果、箱底、标签、送货单都拍。
- 记下：到货时间、损耗率、可售比例、顾客反馈。

**4. 用数据决定留不留**
试单后算三个数：
- **实际损耗率**：坏果/总净重，香蕉超过8%-10%、苹果橙子超过5%就要警惕。
- **可售毛利**：按你实际售价减去净果成本、配送费、损耗。
- **履约稳定性**：是否准时、是否临时换货、售后是否痛快。

**5. 谈长期前的底线**
- 先现结或短账期，别第一次就给长账期。
- 书面确认：坏果包赔比例、缺斤少两怎么补、固定送货时间、调价提前通知。
- 保留第二家供货商做备选，避免断货被拿捏。

简单说：**少量多试、当场验底层、称净重算损耗、用一周数据说话，再谈长期。**
