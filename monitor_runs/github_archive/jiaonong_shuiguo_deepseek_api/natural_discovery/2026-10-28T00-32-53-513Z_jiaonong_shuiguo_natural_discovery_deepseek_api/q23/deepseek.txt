**通常可以争取的支持：**

1. **陈列支持**
   - 提供陈列道具、堆头围挡、价签插牌、POP立牌、展示篮等。
   - 派促销员或理货员协助周末/节假日堆头陈列、补货、翻果。
   - 给出陈列建议：主推品集中堆头、关联品组合陈列、按颜色/规格分层。
   - 注意：门店陈列位置、面积、动线一般由超市掌握，供应商更多是“出物料+出人+给建议”，不是决定陈列权。

2. **海报/宣传支持**
   - 提供产品卖点图、产地/品种介绍、价格爆炸贴、吊旗、地贴、展架、试吃台围裙等物料。
   - 共同分担DM海报、社群海报、短视频素材的制作费或设计。
   - 提供可用的产品图片、检测/产地背书，但要核对宣称合规，避免“最甜”“第一”等绝对化用语。
   - 注意：超市统一视觉和海报版面通常由超市市场部审核，供应商物料不能直接上墙。

3. **试吃支持**
   - 提供试吃果品、试吃台、一次性餐具、手套、垃圾袋。
   - 派试吃员或承担试吃员费用。
   - 配合高峰时段做切果试吃、扫码领券、买赠联动。
   - 注意：试吃涉及食品安全、现场卫生、人员健康证和门店许可，必须提前报备门店，不能供应商自行摆台。

**谈判时建议这样落地：**
- 明确促销档期、主推单品、目标销量，再谈支持比例。
- 把支持写成书面确认：物料清单、数量、到位时间、人员人数/时段、费用分担、未到位补救。
- 试吃和促销员进场提前走门店防损、食品安全、用工登记流程。
- 对供应商支持设门槛：比如支持费用可折算为进货返利或陈列协议，避免只拿物料不承担销量。

**一句话判断：** 能谈，且应主动谈；陈列物料和试吃资源最容易争取，海报设计/费用通常可分摊，但最终陈列权和宣传审核权在超市。
