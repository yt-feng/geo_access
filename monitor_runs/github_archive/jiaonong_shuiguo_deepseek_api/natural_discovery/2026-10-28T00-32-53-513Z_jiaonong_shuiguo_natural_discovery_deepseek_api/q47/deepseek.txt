采购香蕉做茶饮/甜品，关键不是“买一种熟度”，而是按用途分配熟度，并在门店用“外观+手感+气味”验收和分级。

**1. 先按产品定熟度**
- **香蕉牛奶、香蕉奶昔、香蕉冰沙、香蕉酸奶饮**：用**7～8成熟**，果肉完整、甜度上来但不发软，香气足，打碎后不易发酸。
- **香蕉果泥、香蕉酱、香蕉蛋糕/磅蛋糕、香蕉布丁**：用**8～9成熟**，表皮有明显黑点但果肉未流汁，甜度高、香气强，适合压泥。
- **装饰切片、香蕉船、水果茶顶饰**：用**6～7成熟**，果肉偏硬，切片不易碎，氧化慢。
- **香蕉脆片、油炸香蕉、烤香蕉**：用**6～7成熟**，太熟会吸油、软塌。
- **香蕉果酱/焦糖香蕉**：可用**9成熟**，但需当天消耗。

**2. 采购时的验收标准**
- **看**：表皮黄色均匀、无大面积青绿；允许少量芝麻黑点，但黑斑连片、凹陷、渗液不要。
- **摸**：整串手感一致，轻捏有弹性但不软烂；果柄干燥不发霉；果指无裂口。
- **闻**：有自然香蕉香，无酒味、酸味、霉味。有酒味说明过熟发酵。
- **查**：果柄和果指连接处无霉斑，箱内无压伤、汁液污染。

**3. 采购批量控制**
- **少量多次**：香蕉后熟快，门店按**2～3天用量**采购，夏天缩短到**1～2天**。
- **分批到货**：同一批里混装**6～7成熟和8～9成熟**，前者用于装饰/奶昔，后者用于果泥/烘焙。
- **避开青蕉整箱**：青蕉到店后催熟不可控，除非有独立催熟条件。
- **按销量倒推**：先统计各产品日均香蕉用量，再按熟度分档下单，避免“一箱全熟、两天用不完”。

**4. 到店后的熟度管理**
- **分级存放**：青黄果放阴凉通风处，熟果冷藏或放空调房；不要和苹果、梨等释放乙烯的水果混放，除非想加速后熟。
- **冷藏会抑制后熟**：8成熟以上可冷藏延缓；6～7成熟不要直接冷藏，否则表皮变黑、果肉不熟。
- **每天分拣**：出现黑点连片、软塌、酒味的立即转做果泥/烘焙或报废，不进入饮品装饰。
- **标注到货日和熟度**：用“青黄/黄/带黑点”三档标签，先进先出。

**5. 简单可执行的验收口诀**
“**黄中带青做装饰，黄带芝麻做奶昔，黑点连片做果泥，流汁酒味直接退。**”

如果门店没有催熟条件，建议采购时优先选**7成熟为主、少量8～9成熟**的组合，既保证饮品香气，又降低损耗。
