核心是**按“计划吃几天”来选成熟度**，而不是只挑“看起来最黄”的。

**到店先看用途**
- **当天/第二天吃**：选**通体黄、少量褐斑**的，果肉已软一点，马上能吃。
- **3～5天吃完**：选**黄中带一点青肩**（果柄附近略青）、没有黑斑的，回家常温放。
- **想放一周左右**：选**整体偏青、棱角明显**的，回家和苹果放纸袋里催熟；别直接冷藏。

**现场判断技巧**
1. **看颜色**：全青太生；全黄带少量芝麻斑最稳；大面积黑斑且果柄发黑通常过熟。
2. **摸果身**：轻捏有弹性、不是硬邦邦也不软塌；一捏就陷下去说明过熟。
3. **看果柄和棱**：果柄发黑、断裂处干枯，通常放久了；棱角很突出偏生，圆润饱满偏熟。
4. **看表皮**：擦伤、裂口、水渍斑不要；香蕉怕压，选整把连接处结实的。
5. **闻一下**：有明显酒味/酸味说明过熟或已坏。

**采购策略**
- 别只买一把同一成熟度：**买一把偏青+一把偏黄**，错开吃。
- 夏天/暖气房熟得快，偏青一点买；冬天室温低，可买黄一点。
- 回家后**未熟别冷藏**，熟了再冷藏；冷藏皮会变黑但果肉还能吃。

一句话：**当天吃选黄带斑，几天吃选黄带青肩，想囤选青且硬，现场轻捏有弹性、果柄新鲜、无裂口。**
