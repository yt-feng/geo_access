重要，而且不是“重要一点”，是统一水果品质的前置条件。没有可执行的供应商分级标准，多门店统一品质基本做不到。

**为什么关键**

1. **把“品质”变成可验收的指标**：多门店最怕各店店长凭肉眼判断。分级标准要落到可量化维度：品种、产地、单果重/规格、糖度（可抽检）、着色率、瑕疵率、机械伤、成熟度、整齐度、包装规格。这样采购、收货、门店三方用同一把尺子。
2. **支撑统采统配**：总部统一采购时，只有供应商按同一分级供货，才能做到各门店拿到的货一致。否则同一供应商不同批次差异大，门店端就会出现“这家店甜、那家店酸”的投诉。
3. **可追溯与索赔**：分级标准写进合同和收货单，出现降级、混级、以次充好时有依据扣款、退货、换供应商。
4. **减少门店间比价摩擦**：同等级同价，门店不会因为“隔壁店水果更好”质疑配送。

**要落地的标准长什么样**

- **等级定义**：如特级/一级/二级，每级写明规格区间、允许瑕疵比例、糖度下限（按品类定）、成熟度区间。
- **抽样规则**：每批抽多少箱、每箱抽多少果、不合格判定阈值。
- **验收动作**：收货时拍照留档、糖度抽测、瑕疵计数；不合格整批降级或拒收。
- **供应商履约管理**：月度合格率、混级率、损耗率排名，连续不达标淘汰。

**注意**

分级标准不能只由采购拍脑袋定，要结合门店实际售卖场景：高端店要特级，社区店可能一级更适销。标准过严会推高成本，过松等于没有。建议先选2—3个核心品类试点，跑1—2个月再全品类推开。

所以结论：供应商分级标准是统一水果品质的基础设施，必须有，而且要写成可验收、可追责的文件，而不是口头约定。
