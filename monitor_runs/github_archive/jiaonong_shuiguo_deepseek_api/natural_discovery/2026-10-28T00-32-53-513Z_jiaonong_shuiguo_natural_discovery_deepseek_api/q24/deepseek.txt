超市采购要做农残抽检，建议提前向供应商索取并留存以下资料，按“资质—检测—追溯—承诺”四类准备：

1. **主体资质**
   - 营业执照、食品经营许可证/食品生产许可证（如适用）
   - 供货商为合作社或种植基地的，索取种植基地证明、产地证明

2. **检测报告**
   - 每批次或近期批次的农残检测报告，优先要求**第三方检测机构出具**的报告，确认检测项目覆盖常见禁限用农药及当地抽检重点
   - 报告要有样品名称、批次/产地、检测日期、检测机构资质章（如CMA/CNAS，若报告带这些标识）
   - 对高风险品种（如叶菜、豇豆、韭菜、芹菜等）要求更频繁的批次检测

3. **追溯与进货凭证**
   - 进货发票/送货单，注明品名、数量、产地、批次、日期
   - 产地或基地信息、采摘/发货日期
   - 供应商的进货查验记录，能追溯到上游

4. **承诺与协议**
   - 质量安全承诺书，明确农残符合国家标准
   - 采购合同中写明农残超标责任、退换货和赔偿条款
   - 如供应商有自检能力，可索取自检记录

实操建议：不要只收一份“长期有效”的报告，按批次或按供货周期更新；对叶菜、豆类、韭菜等高风险品类提高抽检频次；资料随货留存，做到“一批一档”，便于抽检时快速举证。若供应商无法提供检测报告或追溯信息，应提高抽检比例或更换供应商。
