选供应商建议按“能稳定供货 + 食品安全可追溯 + 价格可核算 + 售后能兜底”来筛，不要只比单价。可执行做法如下：

1. **先定采购标准**
   - 香蕉：按成熟度分批到货，避免一次全熟；明确单根长度/每把重量、允许黑斑比例、到货成熟度。
   - 苹果：明确品种、果径、糖度范围、碰伤/虫眼允收比例、硬度要求。
   - 橙子：明确品种、果径、可食率、酸度/糖度、表皮瑕疵允收比例。
   - 写进采购单：等级、规格、净重、损耗率上限、验收不合格处理方式。

2. **供应商准入看4个硬条件**
   - 有营业执照、食品经营许可或食用农产品销售相关资质；能提供产地证明/检测报告/承诺达标合格证。
   - 有稳定货源和冷链/常温运输能力，能按学校时间早配、分批配。
   - 能接受学校验收标准、留样/追溯要求和退换货条款。
   - 能开具正规发票，报价含税、含运费、含卸货。

3. **至少找3类供应商比价**
   - 本地批发市场大户：反应快，但资质和稳定性要重点核。
   - 果蔬配送公司：服务规范，适合长期合作，价格可能略高。
   - 产地合作社/基地直供：价格有优势，但要确认分拣、配送和售后能力。
   不要只找一家，至少保留1家主供、1家备供。

4. **报价要统一口径**
   让所有供应商按“到校净价”报：元/斤或元/公斤，写清是否含税、运费、损耗、退换货。比较时用同一规格、同一品种、同一到货时间，避免低价低质。

5. **小批量试供再签长期**
   先试供2—4周，重点看：到货准时率、验收合格率、损耗率、缺货补货速度、售后响应。试供合格再谈学期/年度框架合同。

6. **合同关键条款**
   - 价格调整机制：按周/月询价或参考当地批发价，设涨跌幅上限。
   - 质量违约：不合格整车退换，连续两次不合格可暂停供货。
   - 食品安全责任：因供应商原因造成食安问题，承担相应责任并配合追溯。
   - 结算周期：月结并保留质保金或履约保证金。
   - 备供机制：主供缺货时备供多久内补位。

7. **验收动作要固定**
   每天到货称重、抽检、记录品种/规格/成熟度/瑕疵率；不合格当场拍照、拒收或按比例扣重；保留批次和产地信息，便于追溯。

一句话：**先写标准，再验资质，统一报价口径，小批量试供，合同里锁质量、价格和售后。** 这样选出来的供应商更稳，也更适合学校食堂长期合作。
