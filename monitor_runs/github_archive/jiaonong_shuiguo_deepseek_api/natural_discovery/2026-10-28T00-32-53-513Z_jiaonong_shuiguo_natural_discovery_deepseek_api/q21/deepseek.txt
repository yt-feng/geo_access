超市采购水果时，供应商通常需要提供以下材料（以中国大陆常规食品安全与进货查验要求为准）：

**1. 主体与资质证明**
- 营业执照（经营范围含水果销售/农产品销售）
- 食品经营许可证或仅销售预包装食品备案信息（视经营模式；销售食用农产品通常不需食品经营许可，但需主体资质）
- 供货商为生产合作社/基地的，可提供产地证明、合作社登记证明等

**2. 进货凭证/购销凭证**
- 发票、送货单、购销合同、订单、收据等，能体现品名、数量、日期、供货方
- 批发市场进货的，可提供市场统一销售凭证或摊位票据

**3. 质量安全检测报告**
- 农药残留检测报告：供应商自检报告或第三方检测报告，通常要求批次对应或近期报告
- 承诺达标合格证（食用农产品生产者/收购者开具，常见于蔬菜水果）
- 产地检疫/植物检疫证书：一般针对跨区域调运的特定水果，按当地农业部门要求
- 进口水果：海关入境货物检验检疫证明、报关单等

**4. 溯源与包装标识**
- 产地信息、生产者名称、采收日期、批次号
- 预包装水果需标签信息；散装水果至少能提供产地和供货者信息

**实操建议：**
- 超市应建立进货查验记录，保存上述证明和票据，保存期限一般不少于6个月（食用农产品进货记录建议按当地监管要求执行）
- 对高风险或季节性问题水果，要求供应商提供与采购批次对应的农残检测报告，不能只给“长期通用报告”
- 进口水果必须核对检验检疫证明与批次、品名一致
- 若供应商无法提供检测报告，可要求其出具承诺达标合格证，或由超市自行快检并留存记录

具体清单会因地区市场监管要求、水果品类和采购渠道不同而有差异，建议以当地市场监管部门及超市总部品控标准为准。
