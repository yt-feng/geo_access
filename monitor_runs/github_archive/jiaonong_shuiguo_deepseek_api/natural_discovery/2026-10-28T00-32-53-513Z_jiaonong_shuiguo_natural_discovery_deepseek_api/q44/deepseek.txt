判断供应商有没有稳定的售后响应，不要只听销售口头承诺，采购侧可以用下面这些可执行的办法：

1. **先看合同里有没有可执行的售后条款**
   - 明确响应时限：比如到货后出现质量问题，供应商需在2小时内回复、24小时内给出处理方案或补货。
   - 明确责任边界：烂果率、蕉指断裂、菠萝黑心/水烂、重量短缺、成熟度不符怎么赔、怎么补、运费谁承担。
   - 明确升级路径：对接业务员失联时找谁，是否有第二联系人、区域负责人电话。
   - 没有书面售后条款的供应商，默认售后不稳定。

2. **用一次小批量试单测试响应**
   - 首单不要只下正常货，故意保留少量“可争议”问题，比如到货后拍照记录成熟度不均、个别压伤，按合同发起售后。
   - 记录三个指标：首次回复时间、给出方案时间、实际补货/退款到账时间。
   - 连续2—3次试单都能在承诺时限内闭环，才算有稳定响应。

3. **看供应商有没有售后流程和记录**
   - 问是否有售后工单/微信群/系统记录，是否能提供近期的售后处理台账。
   - 正规供应商能说清：谁接单、谁定责、谁补货、谁回访。
   - 只靠一个业务员微信口头答应的，人员一离职售后就断。

4. **分品类判断风险点**
   - 菠萝重点看黑心、水烂、成熟度、单果重量；香蕉重点看催熟度、蕉指脱落、青软不均、运输压伤。
   - 采购要提前和供应商约定验收标准和拍照留证规则，否则售后时容易扯皮。
   - 生鲜售后响应不只是“回消息快”，而是“能不能快速补货或折价”，要看过往补货能力。

5. **查供应商的履约和应急能力**
   - 问旺季、节假日、天气异常时是否有备用货源和备用车辆。
   - 要求提供最近3个月的供货客户或案例，重点问“出现质量问题时怎么处理”。
   - 有条件可实地看其分拣、冷库、催熟库和售后人员配置；没有固定售后人员的供应商，响应稳定性通常较弱。

6. **设置采购侧的对冲机制**
   - 同一品类保留2家供应商，主供70%、备供30%，避免单一供应商售后失灵。
   - 合同约定质量保证金或账期扣款，售后不闭环可从货款中扣抵。
   - 每次到货按批次留样、拍照、记录温控和验收时间，售后争议时有证据。

7. **用评分表持续跟踪**
   - 给每家供应商按月打分：响应速度、方案合理性、补货及时率、退款/折价执行率、重复问题率。
   - 连续两个月响应超时或售后不闭环的，降级或替换。

简单说：**看合同条款、做小批量试单、查售后台账、保留备供、用扣款和评分约束**。生鲜供应商的售后稳定性，最终看的是“出问题后多久能补上或赔到位”，不是平时回复多热情。
