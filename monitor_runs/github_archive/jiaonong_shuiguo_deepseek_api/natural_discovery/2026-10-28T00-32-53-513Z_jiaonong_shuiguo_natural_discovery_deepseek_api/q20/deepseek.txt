社区超市找日配水果供应商，重点不是“谁便宜”，而是“每天不断货、损耗可控、出了问题能赔”。建议按下面条件逐项看：

1. **配送能力是第一位**
- 能否每天固定时段送达，是否支持早市前到店。
- 节假日、雨天、旺季是否照常配送。
- 临时补货的截止时间和响应速度。
- 配送车辆是否冷链或至少保鲜运输，装卸是否轻拿轻放。

2. **货源稳定性**
- 是否有稳定产地或一级批发市场档口，不是临时倒货。
- 同一品种能否持续供应，规格是否稳定。
- 换季时能否提前给替代品种建议。
- 要求看近一周实际供货单，不只看口头承诺。

3. **品质与验收标准**
- 明确每类水果的规格、成熟度、糖度、大小、允许损耗率。
- 是否支持到店验收、当场退换。
- 坏果、压伤、缺斤少两怎么赔，写进合作约定。
- 先小批量试配3—7天，看实际到店品质。

4. **价格与结算**
- 报价是否含运费、装卸费、包装费。
- 是否随行就市，调价是否提前通知。
- 账期、押金、起送量、退货扣款规则要清楚。
- 不要只比单价，要算“到店可售成本”：进价+损耗+退换损失。

5. **损耗与售后**
- 是否接受卖不完的少量尾货调换或协助处理。
- 售后响应时间，坏果赔付是补货还是扣款。
- 是否有固定业务对接人，避免每天换人沟通。

6. **资质与安全**
- 营业执照、食品经营相关资质是否齐全。
- 有检测报告或产地证明更好，至少能说清来源。
- 配送人员健康证、车辆卫生情况要看一下。

7. **试合作判断**
建议先选2家各试配一周，每天记录：到店时间、缺货次数、损耗率、退换响应、实际毛利。一周后按“不断货>损耗低>售后快>价格低”排序，不要只看报价。

一句话：**先看日配稳定性和售后赔付，再看品质规格，最后谈价格。** 能接受小批量试配、敢写到店验收和坏果赔付的供应商，优先合作。
