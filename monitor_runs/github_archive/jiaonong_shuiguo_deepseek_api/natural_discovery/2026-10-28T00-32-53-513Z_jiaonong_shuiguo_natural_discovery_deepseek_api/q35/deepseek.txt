连锁超市想降低门店坏果率，赔付条款不能只写“坏果按比例赔”，否则容易扯皮。建议在采购合同里把**验收标准、赔付触发、计算方式、扣款/补货路径、责任归属**写死，重点如下：

1. **先定义“坏果”**
   - 明确按品类写：腐烂、霉变、软烂、裂口、渗汁、异味、机械伤、冻伤、虫眼等。
   - 约定判定方式：抽检比例、抽样位置、拍照留证、双方现场确认；远程到货的，约定开箱验收时限，比如到货后2小时内提出异议。
   - 写明“表面瑕疵不影响销售”的除外情形，避免门店把正常损耗全算供应商。

2. **设定坏果率门槛和赔付触发**
   - 按批次约定：坏果率≤X%正常收货；X%—Y%部分扣款；＞Y%可拒收或整批退货。
   - 不要只按整批平均算，建议按**抽检样本坏果率**推算整批坏果数量，并设上限。
   - 对高损耗品类可单独设更严标准，比如叶菜、浆果、熟透水果。

3. **赔付计算方式要可执行**
   常见三种，合同里选一种或组合：
   - **按坏果重量/数量折价扣款**：赔付额=坏果数量×采购单价×赔付系数，系数可设1—2倍。
   - **整批折扣**：坏果率超过门槛后，整批按比例折价结算。
   - **补货+违约金**：供应商限期补足合格品，逾期按未补货金额日万分之几计违约金。
   - 建议约定“扣款优先从当期货款中扣除”，避免供应商事后不认。

4. **区分责任，别把门店损耗全压给供应商**
   - 到货验收前的坏果由供应商承担；验收签字后，因门店储存、陈列、温度不当造成的坏果，供应商不赔。
   - 约定冷链交接温度、到货时间、卸货责任，避免运输和门店环节混责。
   - 对“隐性坏果”设异议期，比如验收后24小时内发现内部腐烂仍可索赔，但需保留批次和照片。

5. **写清退货、换货和违约金**
   - 拒收后运费、销毁费、冷链返程费由谁承担要写明，通常由责任方承担。
   - 供应商多次批次不合格，可设阶梯处罚：警告、扣款、暂停下单、终止合同。
   - 违约金和扣款不要重复计算，避免条款被认定过高。

6. **配套操作条款**
   - 约定验收单据、照片、视频、第三方检测作为结算依据。
   - 约定对账周期和争议处理时限，比如3个工作日内复核。
   - 对生鲜品类可设月度坏果率考核，超过约定值从月度返利或保证金中扣。

一句话：合同里要写“**坏果定义+抽检规则+坏果率门槛+赔付公式+扣款路径+责任边界+争议时效**”。最推荐“抽检折算坏果量×单价×赔付系数，当期货款直接扣，超阈值可拒收并补货”的组合条款。
