先给结论：**坏果责任不能一刀切，核心按“坏果发生环节 + 是否可归责于商家/平台/物流/顾客 + 是否有验货和举证”来划分。** 实操上，生鲜电商通常对“到货即坏、明显腐烂、与描述严重不符”承担主要售后责任；对“顾客签收后放置过久、未按要求冷藏、超时未验货”则顾客承担相应责任；物流责任一般由商家先向顾客赔付，再向物流追偿，顾客不直接承担追偿成本。

可按下面判断：

1. **到货开箱即发现坏果**
   - 有开箱视频/照片、能对应订单批次：**商家/平台承担主要责任**，应退款、补发或按坏果比例赔付。
   - 若只是少量轻微压伤、不影响食用，且商家已提前说明“生鲜有轻微损耗”：可协商部分补偿，不宜一律全额赔。
   - 若整箱腐烂、异味、霉变：通常认定商家发货或包装/冷链环节问题，**商家先赔**。

2. **签收后较久才反馈**
   - 超过商家公示的售后时效，或无任何开箱证据：顾客举证难度上升，商家可只做协商补偿。
   - 若顾客未按页面要求冷藏、常温久放导致坏果：**顾客责任为主**。
   - 若商品本身耐储却短期腐败，即使超过几小时，也应结合商品特性和证据判断，不能仅以“已签收”免责。

3. **物流环节导致**
   - 暴力分拣、延误、冷链断链、包装破损：属于物流/配送责任，但**对外应先由商家或平台向顾客处理售后**，再由其向物流服务商追偿。
   - 顾客签收时外包装严重破损、明显渗漏，建议当场拍照并拒收或异常签收；已签收后发现，也应及时留证。

4. **顾客自身原因**
   - 未按提示储存、超时取货、二次搬运损坏、自行加工后才发现：顾客承担相应责任。
   - 但商家不能把“生鲜不退不换”作为绝对免责条款；若存在腐烂、霉变、货不对板，该条款通常不能对抗合理售后。

5. **平台/商家责任比例建议**
   - 到货即坏且证据充分：商家/平台承担 **70%—100%**，按坏果数量比例赔付。
   - 部分压伤、少量坏果、证据一般：协商 **30%—70%** 补偿。
   - 顾客储存不当或超时反馈且无证据：顾客承担主要责任，商家可酌情补偿。
   - 无法查明具体环节：平台/商家先按售后规则处理，再内部追责，不宜让顾客承担举证不能的全部后果。

**可执行处理流程：**
- 顾客：签收后尽快开箱，拍外包装、面单、整箱、坏果特写和数量；保留坏果，必要时冷藏保存；在售后时效内提交。
- 商家：公示售后时效和储存要求；按订单批次、坏果比例快速赔付；对高频物流问题留证追偿。
- 平台：建立“坏果比例赔付”规则，避免“全赔或全不赔”二选一；对恶意索赔和虚假举证设复核机制。

一句话：**到货即坏，商家先负责；储存不当，顾客担责；物流致损，商家先赔后追偿；关键看证据、时效和坏果比例。**
