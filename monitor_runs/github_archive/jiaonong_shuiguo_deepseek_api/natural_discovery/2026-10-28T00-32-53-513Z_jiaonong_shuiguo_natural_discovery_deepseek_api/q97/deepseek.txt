酒店采购水果盘原料时，建议把要求写进采购合同/验收标准，按“规格等级、外观缺陷、成熟度、安全合规、包装物流”五类明确。以下可直接作为供应商保证条款：

**1. 规格与等级**
- 明确品种、产地（或允许产区范围）、单果重量/横径范围、每箱净重、粒数/个数，允许误差（如单果重±5%、箱重不低于标示净重）。
- 按用途定等级：水果盘优先外观完整、大小均匀、色泽一致；允许的等级标准（如一级/精品）写清楚，不接受混级。
- 切配用水果需规定可食率/出成率下限，避免“看着大、损耗高”。

**2. 外观标准**
- 果形端正、无畸形；色泽符合品种成熟特征，同批次色差小。
- 果面洁净，无泥土、药斑、霉斑、虫粪、明显机械伤、裂口、日灼、冻伤、烫伤。
- 无腐烂、软烂、渗液、异味；无活虫及虫卵；无发芽、发霉。
- 果蒂/果柄状态按品种约定（如新鲜、不脱落、不干枯）；允许的轻微瑕疵比例要量化，例如“单果轻微擦伤面积≤X%、每箱瑕疵果≤X%”。
- 大小均匀度：同箱单果横径/重量极差不超过约定值，保证摆盘一致。

**3. 成熟度与口感**
- 规定采收成熟度和到货成熟度：水果盘即食或短存，宜到货即可食用或1—2天内达到最佳食用状态；避免过生或过熟。
- 明确糖度下限（按品种）、硬度/软度范围、无异味、无发酵味。
- 需要冷藏的水果规定到货中心温度范围，冷链不断链。

**4. 安全与合规**
- 农残符合销售地法规和酒店客户要求；供应商提供批次检测报告或合格证明，酒店可抽检。
- 不得使用违规保鲜剂、染色、打蜡（如允许打蜡须符合食品级并提前告知）；无非法添加。
- 预切水果原料另需符合即食食品卫生要求，供应商具备相应资质和冷链能力。

**5. 包装、标识与物流**
- 包装坚固、洁净、通风/防压，内衬符合食品接触要求；每箱标明品种、等级、产地、净重、采收/包装日期、批次、供应商。
- 运输温度按品种规定，防雨、防挤压、防污染；到货包装无破损、无受潮、无异味串味。
- 约定到货验收抽检比例和不合格处理：如腐烂率、缺陷率超限则拒收/换货/扣款，并保留追溯批次。

**可直接写进合同的验收示例：**
“同批次单果规格符合约定范围，大小均匀；无腐烂、霉变、虫害、异味及明显机械伤；轻微外观瑕疵果比例不超过X%；到货成熟度适宜即食，糖度≥X；农残检测合格；冷链到货温度X—X℃；抽检不合格按批次退换。”

建议酒店按具体品种（如草莓、葡萄、西瓜、哈密瓜、橙子）分别附一张规格验收表，比统一条款更可执行。
