结论：**绝大多数餐饮连锁应“中央厨房统一收货”为主，门店直收只作为例外补充**。是否例外，取决于水果品类、门店密度、配送半径和损耗管理能力。

**一、统一收货更好的理由**
1. **品质与验收标准统一**：水果分级、糖度、成熟度、外观标准集中执行，避免各店验收松紧不一。
2. **采购议价与规模优势**：集中订单量大，价格、账期、返利更好谈；供应商管理集中。
3. **食品安全可追溯**：统一索证索票、农残检测、批次记录，出问题能快速定位和召回。
4. **减少门店操作负担**：门店专注出品和服务，不用每天早市验货、搬货、退货扯皮。
5. **数据集中**：统一收货便于做采购分析、损耗分析、供应商考核。

**二、门店分开收货适用的例外**
1. **极短保鲜期、易损水果**：如草莓、蓝莓、荔枝、杨梅等，多一道中转就多一次损耗。
2. **门店密集且配送成本高**：中央厨房到店配送频次低、半径大时，门店直配可能更快。
3. **本地特色采购**：区域限定、时令性强的水果，门店就地采购更灵活。
4. **中央厨房产能或冷链不足**：没有足够冷藏库、分拣线时，强行统收会压货。

**三、建议的落地模式**
- **A类（耐储水果：苹果、橙、梨、西瓜等）**：中央厨房统收、统检、统配。
- **B类（易损短保水果：莓果、荔枝、桃等）**：中央厨房统一定供应商和标准，供应商直配门店，门店按统一标准验收并上传照片/数据。
- **C类（区域特色）**：区域仓或区域供应商统配，不建议完全放开门店自采。

**四、关键控制点**
- 建立**水果验收标准卡**：品种、规格、糖度、成熟度、允许损耗率、拒收条件。
- 统一**索证索票和农残检测**要求，门店直收也必须执行。
- 用**到货合格率、损耗率、门店投诉率**考核供应商和收货环节。
- 门店直收必须**系统留痕**：下单、收货、验收照片、退货记录，防止飞单和价格失控。

**一句话判断**：如果水果是标准化、耐储、量大，选中央厨房统一收货；如果是极短保、易损、区域性强，采用“统一供应商+直配门店+统一验收标准”的混合模式，而不是让门店自由采购。
