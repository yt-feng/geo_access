结论：大多数食堂选 **按斤结算最容易管住成本和验收**；如果水果品种固定、规格统一、验收人力少，可以 **按箱结算但要“按箱验收+折算单价”**；**按份结算只适合已经分装好的即食水果或加餐场景**，不适合作为主采购方式。

具体判断如下：

1. **按斤结算：最适合作为主方式**
   - 优点：单价透明，采购量、损耗、库存都好核；不同批次价格波动能自然反映。
   - 适合：苹果、香蕉、橘子、西瓜等散装、品种多、每日用量变化大的食堂。
   - 管理要点：必须配电子秤、验收单、去皮称重；定“最低净重/箱”或“单箱平均净重”防止箱内垫纸、冰袋、烂果充重。
   - 风险：验收工作量稍大，需要专人复称。

2. **按箱结算：适合规格高度稳定的品种**
   - 优点：收货快、流程简单，适合固定品牌/固定规格的箱装水果。
   - 适合：整箱苹果、整箱橙子、整箱梨等包装标准稳定、供应商长期合作的情况。
   - 管理要点：合同里写清“箱规、净重范围、坏果率上限、缺重扣款规则”；不要只看箱数，要抽检净重和品质，必要时折算成每斤单价做比价。
   - 风险：箱内大小不一、垫重、坏果多时，食堂容易吃亏。

3. **按份结算：只适合终端分发，不适合主采购**
   - 优点：分发快、份量统一，适合按人头配餐或加餐。
   - 适合：已经洗切分装好的水果杯、单人份水果、会议/活动茶歇。
   - 管理要点：明确每份净含量、可食率、分装日期和保质期；供应商要有分装和冷链能力。
   - 风险：单价通常最高，且“份量”容易缩水，不适合大食堂日常主采购。

**建议的组合管理方式：**
- 主采购：**按斤结算**，按周或按月询价。
- 固定规格品种：可**按箱采购，但验收按净重抽检、结算按箱价折算斤价**。
- 即食分装：**按份结算**，作为补充。
- 无论哪种方式，合同都要写清：净重、坏果率、退货扣款、验收抽检比例、价格随行就市规则。

一句话：**想控成本选按斤，想省验收选按箱但必须抽检净重，按份只用于分装即食。**
