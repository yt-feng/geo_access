选适合批量配送的水果供应商，重点看“稳定交付+食品安全+损耗可控”，不只比单价。可按下面顺序判断：

1. **先定采购参数**
   - 人数、预算/人、配送频次（每周几次）、配送时间窗口、是否需要洗净/切盒。
   - 下午茶场景建议选：易分发、不需复杂处理、耐放的水果，如香蕉、橘子/砂糖橘、圣女果、葡萄（需洗）、苹果、梨；少选易压伤、易氧化的草莓、蓝莓、切开的西瓜等，除非供应商能做分装。

2. **供应商类型优先级**
   - 本地水果批发商/配送商：适合批量、价格低，但要确认分拣和配送能力。
   - 生鲜B2B平台：履约稳定、票据齐全，适合行政采购合规。
   - 连锁水果店团购配送：适合小批量、高频次，价格略高。
   - 产地直采：价格有优势，但起订量大、售后和损耗风险高，不建议小公司首次采用。

3. **必须核验的资质与能力**
   - 营业执照、食品经营许可证（涉及切配/预包装需对应资质）。
   - 是否有固定仓储、冷链或保鲜运输；夏季配送尤其要看。
   - 能否提供农残检测报告或进货凭证。
   - 是否支持开票、对公付款、签订简单采购协议。
   - 配送准时率、异常补发机制、破损/坏果赔付标准。

4. **用试单验证，不靠口头承诺**
   - 先下1—2次小批量试单，按实际人数略多备5%—10%。
   - 重点看：到货时间、重量是否足、坏果率、大小是否均匀、是否按部门/楼层分装。
   - 建议验收标准写清楚：坏果率超过5%补发或扣款；迟到超过30分钟的处理方式。

5. **报价要按“可食用到货价”比较**
   - 不只看每斤价格，要算：单价×实际可用量+配送费+损耗+人工分装成本。
   - 要求供应商报含配送、含税、含分装的价格，避免低价中标后加收费用。

6. **合同/订单里写清楚**
   - 品种、规格、数量、配送时间、验收标准、坏果赔付、临时加单截止时间、发票类型、食品安全责任。

**实操建议：**同时找3家——1家本地批发配送、1家生鲜B2B平台、1家连锁水果店，按同一清单（如香蕉、砂糖橘、圣女果、苹果）试单一次，用“到货准时、坏果率、可食率、分装便利、售后响应”五项打分，选综合最优而非最低价。首次合作先签1个月，稳定后再谈账期和阶梯价。
