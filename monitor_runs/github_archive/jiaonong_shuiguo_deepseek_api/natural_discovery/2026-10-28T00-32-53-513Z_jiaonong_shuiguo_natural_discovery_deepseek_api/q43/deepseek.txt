评估连锁门店跨城市的水果供应商仓配覆盖，可以从“能不能送到”到“送得好不好、成本是否可控、风险是否可承受”分五层判断。

**1. 先画需求地图，而不是先看供应商**
- 按城市/商圈汇总门店：日均销量、SKU结构、最低起订量、到货时效、验收标准。
- 水果要单独区分温层：常温、冷藏、催熟/后熟、易损高损耗品。
- 标出门店补货频次：日配、隔日配、周配。水果的日配比例越高，对仓配覆盖要求越高。

**2. 评估供应商仓网“有效覆盖”，不只看有没有仓**
核心指标看：
- **仓到店距离与配送半径**：供应商声称覆盖某城市，要看其实际发货仓到门店的公里数、是否跨城直发。
- **覆盖门店比例**：该城市门店中，能在承诺时效内送达的比例。
- **时效达成率**：按门店所在城市分别统计，至少看近3个月。
- **冷链能力**：冷藏车/保温箱比例、全程温控记录、断链投诉率。
- **配送频次与截单时间**：能否支持门店早市前到货、临时补货。
- **起订量与拼车能力**：跨城门店少时，是否因起订量不足导致加价或降频。

**3. 算仓配成本是否可落地**
不要只比供货价，要算“到店总成本”：
- 供货价 + 运费 + 跨城调拨费 + 损耗赔付 + 门店验收人工 + 缺货带来的销售损失。
- 按城市、门店、SKU分别算单店单日履约成本。
- 重点看：低销量门店是否被高运费拖累；跨城直发是否比区域中转仓更贵；多供应商拼车是否可行。

**4. 做压力测试，验证覆盖韧性**
- 旺季/节日爆量时，仓配能否扩产能。
- 天气、交通管制、疫情/封控等异常下的替代路线。
- 单一仓覆盖多城市时，仓故障是否会导致多城断供。
- 水果品质波动大，滞销、退换货、损耗责任是否清晰。

**5. 给出可判断的结论标准**
建议设定准入线，例如：
- 目标城市门店时效达成率≥95%；
- 冷链断链投诉率低于约定阈值；
- 单店单日履约总成本不超过门店毛利可承受比例；
- 关键城市至少有“主供应商+备选路线/备选供应商”；
- 跨城配送半径和截单时间能匹配门店补货节奏。

**实操建议：先做小范围试点。** 选2—3个典型城市（高销量核心城市、低销量外围城市、跨城距离较远城市），让供应商按真实订单跑1—2个月，按门店统计时效、损耗、缺货、到店成本和投诉率，再决定是否扩大覆盖。这样比只看供应商仓网图更可靠。
