香蕉配送中最容易出问题的不是“压一下”，而是**机械伤+温度波动+乙烯累积**共同导致的黑斑和软烂。要控制压坏和变黑，建议从下面几件事同时做。

**1. 采收和入库就要按“配送用途”选货**
- 不要用完全黄熟的香蕉做电商配送，选**七到八成熟、果指饱满但未软**的货。
- 入库前剔除已有裂口、擦伤、水烂的果，单个坏果会释放乙烯催熟整箱。
- 到仓后尽快预冷，但香蕉怕低温，**不要低于12℃**，一般控制在**13–15℃**，避免冷害后变黑。

**2. 包装做“防压+防摩擦+透气”三件事**
- 用**带分隔的纸箱或塑料周转箱**，单果之间用纸板隔开，避免果指互相摩擦。
- 箱内加**瓦楞纸隔板或泡沫网套**，重点保护果指弯曲处和果柄。
- 不要用完全密封的塑料袋，香蕉呼吸会产生水汽和乙烯，容易闷黑；需要**开孔透气**。
- 装箱不要过满，留出缓冲空间，堆码层数按纸箱抗压测试来定，别凭感觉叠高。

**3. 配送环节控温、控湿、控乙烯**
- 夏季用**冷藏车但设定13–15℃**，不要直接吹冷风到果面；冬季防冻，避免低于12℃。
- 湿度控制在**85%–90%**，太干会失水发皱，太湿容易长霉。
- 车内不要和苹果、番茄等乙烯释放量大的果蔬混装。
- 长途配送可在箱内放**乙烯吸附剂**，但不能替代通风和温控。

**4. 最后一公里是重点**
- 骑手配送箱要加**硬质隔板**，香蕉放最上层，避免被其他商品压。
- 夏季高温时用**保温袋+冰袋**可以，但冰袋不能直接接触香蕉，需隔一层纸板，防止局部冷害发黑。
- 配送时效尽量控制在**2小时内**，高温天缩短到1小时内。

**5. 售后和验收标准要提前定**
- 明确“轻微表皮斑点”和“压伤软烂”的界限，拍照留证。
- 对压坏、变黑严重的订单做快速赔付，避免纠纷扩大。
- 记录每批次的损耗率，按线路和季节调整包装和时效。

**最优先做的三件事：**  
① 选七到八成成熟、无伤的货；② 用分隔纸箱+透气包装，禁止密封闷装；③ 配送全程13–15℃，最后一公里加硬隔板、冰袋不直接接触果面。做到这三点，压坏和变黑会明显下降。
