坏果率没有全国统一的法定赔付阈值，关键看合同约定；合同中常见的可执行写法是：

1. **到货验收坏果率 ≤ 3%**：视为合理损耗，不赔付。
2. **坏果率 3%～5%**：按坏果重量/金额扣款，或要求补货。
3. **坏果率 ＞ 5%**：买方有权要求按坏果部分全额赔付；可约定超过5%部分按1～3倍扣款。
4. **坏果率 ＞ 10%～15%**：可约定为根本违约，买方有权拒收整批、退货、解除合同并索赔。

更稳妥的合同条款应写清：

- **计算口径**：坏果率=不合格果重量÷该批次总重量×100%；抽样比例、抽样方法、验收时限。
- **“坏果”定义**：腐烂、霉变、虫蛀、严重压伤、冻伤、异味等分别列明。
- **赔付方式**：按坏果重量扣款、按坏果金额赔付、补货、退货、运费和检测费由谁承担。
- **分级处理**：轻微瑕疵不赔，严重坏果整批拒收。
- **时效与证据**：到货后24～48小时内验收，拍照/视频留存，逾期视为合格。

如果你问“超过多少应该要求赔付”，实务建议底线是：**超过3%开始扣款，超过5%要求明确赔付，超过10%保留拒收/解约权**。具体阈值还要结合水果品类、运输距离、季节和采购价谈判确定；易腐水果可适当放宽合理损耗，但赔付触发线不宜高于5%。
