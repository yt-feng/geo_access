优先选**切配（鲜切）**作为线上主推，**冷冻原料**作为补充SKU，**整果**只做引流或产地直发限定，不建议作为主力。

判断逻辑：

1. **整果**
   - 优点：损耗最低、客单低、适合产地直发/预售。
   - 缺点：线上履约中重量和成熟度争议大，菠萝有“削皮、去眼、泡盐水”的消费门槛，复购和溢价弱。
   - 适合：引流款、产地直发、团购大单；不适合作为核心利润款。

2. **切配/鲜切**
   - 优点：即食、省事，线上转化和复购最好；可做小规格、组合装、办公室/家庭场景；毛利可通过加工和包装提升。
   - 缺点：保质期短，对冷链、切配卫生、氧化和出水控制要求高；损耗和售后风险高于整果。
   - 适合：线上主力款，尤其一二线城市、即时零售/次日达渠道。前提是能稳定做到冷藏配送和短保管理。

3. **冷冻原料**
   - 优点：保质期长、损耗低、履约稳定，适合做冷冻果块、冰沙/烘焙/饮品原料；B端和家庭冷冻场景都能卖。
   - 缺点：C端认知偏“原料”，溢价有限；解冻口感不如鲜切；需要冷冻链路。
   - 适合：补充SKU、B端批发、组合装；不建议单独作为线上爆款主线。

**建议组合：**
- 主推：鲜切菠萝（小规格即食装 + 家庭装）
- 引流：整果产地直发/预售
- 补充：冷冻菠萝块（饮品/烘焙场景）
- 关键控制：鲜切做短保和冷链，整果做成熟度分级，冷冻做规格标准化。

一句话：**线上卖菠萝，鲜切最匹配“省事+复购”，整果适合引流，冷冻适合补品类；主力放鲜切，但必须先把冷链和短保售后算进模型。**
