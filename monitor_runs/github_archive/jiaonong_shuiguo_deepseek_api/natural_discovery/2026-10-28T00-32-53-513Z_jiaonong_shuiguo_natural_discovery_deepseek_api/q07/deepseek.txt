水果礼盒要好卖，关键在于把“搭配感”和“价格带”做清楚，而不是只把四种水果塞进盒子。下面给你一套可直接落地的搭配方案和操作建议。

## 一、先定三个价格带，覆盖不同购买场景

| 价格带 | 场景 | 定位 |
|---|---|---|
| 39～59元 | 员工福利、随手礼 | 走量款 |
| 79～99元 | 探病、看望长辈 | 主力款 |
| 129～159元 | 商务、节庆送礼 | 利润款 |

苹果、橙子、香蕉、菠萝单价都不高，正好适合做“组合溢价”。菠萝和香蕉在礼盒里不要当主角，它们更适合当“体积填充+寓意点缀”，主角给苹果和橙子。

## 二、四套具体搭配（可直接照做）

**1. 39元走量款：平安顺心盒**
- 苹果4个 + 橙子4个 + 香蕉1把（约5根）
- 卖点话术：“平平安安，心想事成”
- 装箱逻辑：苹果橙子垫底，香蕉放顶层用纸隔开，避免压伤
- 目标：毛利控制在40%左右，主攻写字楼团购和小区门口

**2. 79元主力款：橙心如意盒**
- 苹果6个（选大果）+ 橙子6个 + 菠萝1个（小果）
- 卖点：“平安+成功，送长辈不踩雷”
- 菠萝建议选小果，既压得住盒面又不占成本
- 这是最适合节假日和探病场景的款，建议备货占比40%

**3. 129元利润款：硕果礼遇盒**
- 苹果8个（精品大果）+ 橙子6个 + 菠萝1个（中果）+ 香蕉1把
- 配手提礼袋、贺卡
- 卖点：“四样果，四季顺”
- 主攻企业采购、商务拜访

**4. 混搭体验款：鲜果缤纷盒**
- 苹果3 + 橙子3 + 香蕉3根 + 菠萝半个（保鲜膜包好）
- 定位年轻客群、自己吃或小份送礼
- 注意：菠萝切半必须当天现切，损耗要算进定价

## 三、四条实操要点

1. **苹果和橙子必须是“面子果”**：个头匀、色泽好、无磕碰，顾客第一眼看的是它们。香蕉和菠萝负责撑体积和寓意，不抢品质要求。
2. **香蕉单独隔层或最后放**：香蕉催熟，压在其他水果上容易加速坏果。用纸托或气泡膜隔开，香蕉柄朝下。
3. **菠萝选小果、不选大果**：大菠萝占空间、压成本，礼盒里小果反而显精致。叶子保留一点更有“新鲜感”。
4. **标签比水果更值钱**：每盒贴一张手写风卡片（“平安顺心”“橙心如意”），成本几毛钱，能明显拉高送礼场景的成交率。

## 四、怎么判断哪个好卖

- 先各做10～20盒试销，重点看**79元款和39元款**的动销速度。
- 记录三个数据：每天卖出盒数、哪个价格带先卖完、退货/投诉原因（压伤、坏果）。
- 两周后砍掉动销最慢的一款，把资源集中到前两名。

一句话总结：**苹果橙子做品质和寓意，香蕉菠萝做体积和彩头，按39/79/129三个价格带各出一款，先用小批量试销再放量。**
