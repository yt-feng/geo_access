食堂采购香蕉要避免熟过头，关键是把“采购节奏、验收标准、催熟控制、库存周转、剩果再利用”这几件事一起管住。下面给可直接执行的做法：

1. **按用量下单，不按库存上限囤货**
   - 用近2—4周实际消耗量做基准，按“日均用量×到货间隔天数×1.1”下单，避免一次性大批量。
   - 香蕉属于后熟水果，建议每周至少到货2次，炎热季节可增加到3次，单次量控制在2—3天能用完。
   - 与供应商约定“少量多次、可临时补货”，把库存压力前移到供应端。

2. **验收时看成熟度，不只看外观**
   - 食堂一般适合收**微黄、果身硬、棱角尚明显**的香蕉，表皮全青可少量收，用于放置1—2天后使用；**大面积褐斑、果柄发黑、轻捏软塌**的拒收或折价当天用完。
   - 抽检比例建议不低于每批的5%—10%，重点看果柄、果身硬度和有无压伤。
   - 验收单上写明成熟度要求，作为退换货依据。

3. **控制催熟和存放环境**
   - 未熟香蕉不要和苹果、梨等释放乙烯的水果混放；需要催熟时可少量混放并每天检查。
   - 已开始变黄的香蕉放阴凉通风处，避免阳光直射和靠近蒸箱、灶台等热源。
   - 不要整箱密封闷放，箱口适当打开通风，减少水汽和压伤。
   - 香蕉不宜低温冷藏，食堂常温周转即可；夏季高温时可放空调房或通风库房，缩短周转天数。

4. **执行“先进先出+成熟度分区”**
   - 到货后按成熟度分三区：青硬区、微黄可用区、即用区。即用区放最外面，优先出库。
   - 每天早班检查一次，把开始出褐斑的香蕉移到“当天必用”区，由厨师优先安排。
   - 建立简单的库存看板：品名、到货日、数量、成熟度、预计用完日，避免压箱底。

5. **菜单端配合消化**
   - 把香蕉安排进早餐、加餐、水果杯、香蕉牛奶、烘焙（香蕉面包/松饼）等，成熟度高的优先做加工用途。
   - 熟透但未变质的香蕉可去皮冷冻保存，用于制作奶昔、烘焙，减少直接丢弃。
   - 每周根据菜单和消耗数据调整采购量，遇到放假、考试、天气变化提前减量。

6. **设置损耗红线并复盘**
   - 建议把香蕉损耗率控制在**3%—5%以内**，超过就查原因：下单过量、验收偏熟、存放不当还是菜单未消化。
   - 每周记录到货量、使用量、丢弃量，连续两周偏高就下调单次采购量或增加到货频次。

最有效的组合是：**小批量高频到货 + 收微黄硬果 + 每天分成熟度挑拣 + 熟果优先进菜单/加工**。这样比单纯“少买”更能稳定供应又减少浪费。
