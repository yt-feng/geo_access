可以按“引流品+利润品+连带品”做组合，而不是三样一起降价。建议如下：

1. **主推组合：苹果+香蕉“早餐果篮”**
   - 苹果2个+香蕉1把（3—4根），定价可为原价合计的85%—9折，但用固定组合价，例如“9.9元/份”。
   - 目的：香蕉是价格敏感引流品，苹果单价/毛利相对稳，组合后提升单次购买量。
   - 陈列：早餐场景牌“早餐搭配/办公室加餐”，放在入口端头。

2. **菠萝做加价购，不直接捆绑**
   - 买任意水果组合满15元，菠萝切盒加价5.9元换购；或整只菠萝“第二只半价”。
   - 菠萝客单高、气味强、试吃转化好，适合做加购和现场试吃，能拉高客单但不拖累苹果香蕉价格。
   - 切盒比整只更适合即时消费，减少顾客处理麻烦。

3. **设置三档价格锚点**
   - 基础档：香蕉单把特价，负责引流；
   - 组合档：苹果+香蕉9.9元，负责提客单；
   - 升级档：苹果+香蕉+菠萝切盒15.9—19.9元，负责拉高客单。
   - 顾客容易从基础档被引导到组合档，再被加价购带到升级档。

4. **执行细节**
   - 组合商品用统一透明袋/托盘，贴固定价签，减少称重排队。
   - 香蕉选成熟度适中、可即食的；苹果选耐放品种；菠萝现场试吃+切盒。
   - 每天记录组合销量、加购率、客单价，连续3—5天看效果；若组合销量高但毛利低，减少折扣幅度或缩小香蕉份量。
   - 避免“三样都打折”，否则只是牺牲毛利，不一定提高客单。

核心逻辑：**香蕉引流、苹果稳价、菠萝加购**，用场景组合和价格锚点把顾客从“买一样”推到“买一套再加一件”。
