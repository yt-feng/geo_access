判断香蕉供应商能否全年稳定供货，不能只听“全年都有货”的口头承诺，要按“产地结构—产能证据—合同约束—试单验证”四步核验。

**1. 先看它有没有多产区组合**
香蕉是区域性、季节性作物，单一产区很难全年稳定。要求供应商说明全年各月货源来自哪些产区，例如海南、云南、广西、广东及进口来源如何衔接，并画出月度供货地图。重点看：
- 是否只依赖一个产区或一个基地；
- 雨季、台风季、冬季寒害期的替代货源在哪里；
- 进口蕉是否有稳定的报关和冷链渠道。
如果供应商说不清月度产地切换，全年稳定基本不可信。

**2. 要可核验的产能和履约证据**
不要只看宣传册，要求提供：
- 自有或合作基地面积、株数、月均可出果量；
- 近12个月实际发货记录，按月列出供货量和缺货次数；
- 加工厂/催熟库的日处理能力和冷库容量；
- 主要客户类型和合作年限，可做背景核实；
- 农业投入品记录、质检报告和香蕉条斑病等检疫合规情况。
关键判断：它的“最大月供货量”是否明显高于给你的承诺量，是否有至少20%—30%的冗余产能。

**3. 用合同把“稳定”变成可追责条款**
合同里明确：
- 月度最低供货量和年度总量；
- 缺货、延迟、质量不达标的违约金和补货责任；
- 价格调整机制，避免旺季随意涨价或断供；
- 替代货源条款：主产区受灾时供应商必须在多少小时内启动备选产区；
- 质量规格：果指长度、成熟度、伤果率、农残和检疫要求。
没有违约责任的“稳定供货”没有约束力。

**4. 先试单再放量**
建议至少做3个月试供，覆盖一个淡季或风险期：
- 每周跟踪到货量、准时率、合格率、缺货次数；
- 突然追加20%—30%订单，测试其弹性；
- 要求提供一次产地或加工厂视频/实地核验；
- 对比2—3家供应商，避免单一依赖。

**快速判断口诀：** 说不清月度产区来源的不选；拿不出近12个月发货记录的不选；不愿签最低供货量和违约条款的不选；试单期出现两次以上无预警缺货的，不列为全年主供。最终应保留“主供+备供”双供应商结构，主供占比控制在70%左右。
