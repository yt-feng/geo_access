判断水果供应商靠不靠谱，别只听他说“产地直发、价格最低”，用下面这套可执行的检查清单，连续合作 2–4 周就能看出大概。

**1. 先小单试，不要一上来压大单**
- 首单只订 1–2 天销量，香蕉、菠萝各少量。
- 重点看：到货时间是否准、数量是否够秤、规格是否一致、坏果率多少。
- 连续试 3–4 次再谈长期价。一次好不算好，稳定才是靠谱。

**2. 看香蕉和菠萝的关键指标**
香蕉：
- 到货成熟度是否适合你店里的周转速度：太青可以放，太黄当天卖不完就风险大。
- 同批次颜色、条形、粗细是否均匀。
- 有没有明显机械伤、裂口、黑斑、水烂。
- 问清楚是“催熟后发”还是“生蕉自熟”，以及到店后大概几天到最佳售卖期。

菠萝：
- 果形是否端正，果眼深浅、是否有软烂、黑心、水浸状。
- 到货成熟度：叶冠新鲜度、底部气味、按压手感。
- 同批大小是否统一，因为你按个卖还是按斤卖，规格稳定性直接影响损耗和定价。

**3. 验货和售后要提前说清楚**
- 每次到货当场抽检：称重、数箱、切开 2–3 个菠萝、检查香蕉底层和箱心。
- 坏果率超过约定比例怎么赔：补货、扣款还是下次抵扣，必须提前书面或微信留痕。
- 注意“箱皮重量、填充物、催熟损耗”是否算进你的成本。
- 靠谱供应商不怕你验，怕验的通常有问题。

**4. 看供货稳定性，而不只是价格**
- 连续问 3 次：今天什么价、明天能不能供、断货时有没有替代方案。
- 旺季和天气不好时能否保量，比低价更重要。
- 问清楚货源是固定基地、批发市场倒手，还是多产地拼货。倒手不是不能合作，但价格和品质波动会更大。
- 香蕉、菠萝都是周转敏感品，供应商能否按你的销售节奏分批发货很关键。

**5. 看账期和结算是否清楚**
- 长期合作建议先款后货或短账期试起，不要一开始就给长账期。
- 每次单据写清：品种、规格、数量、单价、箱皮/填充物、赔付规则。
- 微信报价也要保留，避免口头价和结算价不一致。

**6. 用数据做最终判断**
合作前两周记录每个供应商：
- 到货准时率
- 实际净重与标称重量差
- 坏果率/损耗率
- 同规格均价
- 售后处理速度

**简单判断标准：**
连续 3 次到货时间稳定、净重不缩水、坏果率在你可接受范围内、出问题 24 小时内给方案，就可以逐步加量。只要出现“报价低但箱皮重、坏果不赔、经常断货、规格忽大忽小”，就别长期绑定。

另外，香蕉和菠萝最好别只绑一家供应商，至少保留一个备选，哪怕平时量小。水果生意最怕的不是价格高一点，而是断货和集中坏货。
