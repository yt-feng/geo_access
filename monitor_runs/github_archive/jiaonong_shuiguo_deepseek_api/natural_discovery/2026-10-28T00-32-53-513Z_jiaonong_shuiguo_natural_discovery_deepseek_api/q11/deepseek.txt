会有影响，但影响多大取决于你怎么卖。直接给判断和建议：

**会影响销售的情况**
- 同一箱大小差异明显，顾客挑大的、剩小的，损耗和翻拣成本上升。
- 按“统货一口价”卖时，大小不一会让顾客觉得不值，成交率下降。
- 送礼、果切、餐饮供货这类对规格一致性要求高的渠道，混装会压价或拒收。

**影响不大的情况**
- 社区水果店散卖，顾客本来就会挑，大小差异可通过分档消化。
- 你按大小分级定价：大果、中果、小果分开卖，小果做促销或果切，反而能减少损耗。
- 香蕉成熟度比大小更影响销售，大小略有不均但成熟度整齐，问题不大。

**可执行建议**
1. 开箱后先分级：大、中、小分开，别混在一起卖。
2. 大果走正常价或礼盒，中果做主推，小果做特价、果切、奶昔原料。
3. 采购时问清“规格是否均匀”，把大小均匀度写进采购要求；混装箱压价采购。
4. 算一笔账：如果分拣人工+小果折价损失超过混装省下的采购差价，就别买混装箱。
5. 香蕉重点看成熟度和碰伤，大小不齐不是最大风险，成熟度不齐才是。

结论：**大小不一会影响销售，但可以通过分级销售消化；真正要避免的是“大小混装还统一定价”**。
