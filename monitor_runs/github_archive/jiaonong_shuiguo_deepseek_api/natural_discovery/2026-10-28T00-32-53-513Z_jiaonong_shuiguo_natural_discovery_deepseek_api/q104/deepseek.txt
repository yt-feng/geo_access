# 单位采购水果：到货品质不一致的验收与售后处理

核心原则：**验收标准前置、到货当场分级、书面留痕、按合同走售后**。水果是生鲜，事后追责极难，验收动作必须在卸货现场完成。

## 一、验收前的准备（关键但常被忽略）

1. **把标准写进合同/订单**：每类水果明确品种、产地、规格（单果重或直径范围）、成熟度、糖度（如可测）、允许损耗率（行业常见 3%–5%，可谈）、包装要求。没有标准就没有"不一致"的依据。
2. **约定验收方式**：抽样比例（如每批随机抽 3–5 箱/件）、验收时限（到场后几小时内提出异议有效）、不合格判定规则（如单箱不合格率超 X% 整批可退）。
3. **约定售后条款**：补货时限、退换货责任、货款扣减方式、连续不合格的终止条款。

## 二、到货验收操作步骤

1. **先验后签**：卸货即验，不要先签收再慢慢看。签收单上注明"数量已收，品质待验"或直接现场验完再签。
2. **分层抽样**：不能只看最上面一层。从不同箱、不同层、箱底各取样品，重点看底部有无压伤、霉变。
3. **分类记录**：按"合格 / 轻微瑕疵（可折价接收）/ 严重不合格（拒收或退货）"三档分拣，逐箱拍照、称重、计数。
4. **当场出具验收单**：写明批次、数量、不合格数量与原因、处理意见，双方签字。微信/邮件确认也可，但要有文字记录。
5. **隔离存放**：不合格品单独堆放并贴标，避免与合格品混放后被"说不清"。

## 三、品质不一致的处置方式（按严重程度）

| 情形 | 建议处理 |
|---|---|
| 少量瑕疵、不影响使用 | 折价接收，按比例扣款并在验收单注明 |
| 部分批次不合格 | 合格部分收，不合格部分拒收/退货，要求限期补货 |
| 整批严重不符（品种错、腐烂、规格差太多） | 整批拒收，书面通知供应商，保留证据 |
| 已入库后发现内部腐烂 | 立即拍照录像、封存样品，24 小时内书面提出，按合同追责 |

## 四、售后跟进

1. **书面提出**：以验收单+照片+数量清单为依据，邮件或公函形式向供应商提出补货/退款/扣款要求，写明时限。
2. **跟踪闭环**：补货到货后重新验收，确认无误再结案；扣款要在结算单上体现。
3. **记录供应商表现**：建立简单的到货合格率台账，连续不合格的供应商列入观察或更换。
4. **留证据**：照片要含批次标签、称重读数、日期；样品保留至争议解决。

## 五、给采购人员的实操提醒

- 验收最好两人以上，一人点数一人看品质，避免单人说了算。
- 夏季/远途运输的水果，重点查箱底和中间层的压伤、霉变。
- 所有口头承诺（"下次补""给你打折"）都要落到书面，否则结算时容易扯皮。
- 如果单位有食堂/工会使用场景，提前和供应商说明"可食用标准"，比笼统说"品质不好"更有效。

一句话总结：**标准写进合同，验收在卸货现场做，不合格当场分级留证，售后凭验收单书面追。**
