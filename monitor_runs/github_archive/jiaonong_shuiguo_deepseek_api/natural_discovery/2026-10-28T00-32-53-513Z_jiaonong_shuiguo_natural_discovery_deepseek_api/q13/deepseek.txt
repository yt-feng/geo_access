做小区团购，水果供应商最该确认的是这5项服务能力，缺一项都容易在执行中出问题：

1. **分拣和打包服务**
   - 能否按团购单分装成“每份/每袋”，而不是整箱给你自己分。
   - 是否支持贴标签、按小区/团长分货。
   - 损耗品（草莓、葡萄、桃）是否做保护包装。

2. **按团购量报价和阶梯价**
   - 有没有起批量、阶梯价、周度稳定供货价。
   - 价格是否含包装、分拣、配送。
   - 临时加单、减单的截止时间和加价规则。

3. **配送时效和到货方式**
   - 能否次日达/定时送到自提点。
   - 到货时间是否固定，能否配合小区团购的截单和提货时间。
   - 是否支持多小区分点配送，还是只能送一个集中点。

4. **品质稳定和售后兜底**
   - 坏果、烂果、缺斤少两的赔付标准。
   - 售后响应时间，是否支持拍照理赔、补发或退款。
   - 同一品种能否稳定供货，避免今天有明天没。

5. **退换货和损耗处理**
   - 到货验收不合格能否拒收或换货。
   - 临期/滞销水果能否调换。
   - 损耗率大概多少，谁承担。

另外要重点问清：**是否支持小批量试单、是否签简单供货协议、账期还是现结、节假日能否保供**。小水果店做团购，供应商最值得优先选的是“能稳定分拣配送+售后不扯皮”的，而不是单纯报价最低的。
