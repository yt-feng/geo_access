社区超市卖水果，控制新鲜度和库存，核心是少进快转、按品质分级卖、缩短回本周期。下面给你一套可以直接落地的做法。

**1. 先定“少品类、高频次”的进货结构**
- 水果只做20～30个高频刚需单品，别贪多。叶菜类水果、浆果类最易损，SKU要更少。
- 进货频率按销量分三档：
  - 高周转（苹果、香蕉、橙子、梨）：每天或隔天进，单次量控制在1～2天销量。
  - 中周转（葡萄、桃、李、火龙果）：每天少量进，单次不超过1天销量。
  - 高损品（草莓、蓝莓、荔枝、车厘子、切果）：按预订+少量现货，当天进当天清，宁缺不压。
- 用“昨日销量×安全系数”定今日进货量，安全系数高周转1.1～1.2，高损品0.8～1.0。

**2. 用陈列和分级消化库存**
- 到货先分级：一级正价陈列，二级做“今日特价”或组合装，三级及时切果、榨汁或做员工餐，不要等烂了再处理。
- 高损品放冷柜或阴凉处，香蕉、芒果等不要进冷柜；苹果、梨、橙耐放但也要先进先出。
- 陈列量控制在“看着满但不压货”，叶菜类水果少量多次补货，制造新鲜感。

**3. 设置库存红线，每天闭店前盘点**
- 给每个单品设“最大库存天数”：高损品0.5～1天，中周转1～2天，高周转2～3天。超过就当天促销。
- 每天闭店前10分钟盘点，记录损耗和剩余量，第二天进货量直接按剩余量扣减。
- 每周看一次单品动销率：连续两周动销慢的，直接砍掉或换品，不要舍不得。

**4. 用价格和时段促销加速周转**
- 上午正价，下午4点后对易损品做“晚间特价”，闭店前1小时组合打包清货。
- 设“每日爆款”引流，但爆款选耐放、毛利可控的品，不要拿高损品冲量。
- 预包装、小份装能降低挑选损耗，也方便控制单份库存。

**5. 建立简单的进货台账**
- 每个单品记：进货量、进货价、售价、当日销量、损耗量、剩余量。一周就能看出哪些品该少进、哪些该停。
- 供应商尽量固定2～3家，要求小批量、多频次配送，谈好次品退换，别一次压大批量拿低价。

**关键判断标准：** 如果某个单品连续3天闭店剩余超过当日进货量的30%，就减量或停进；高损品当天没卖完的超过20%，第二天进货量直接砍半。先做到“高损品日清、耐放品2～3天周转”，库存就不会压死在店里。
