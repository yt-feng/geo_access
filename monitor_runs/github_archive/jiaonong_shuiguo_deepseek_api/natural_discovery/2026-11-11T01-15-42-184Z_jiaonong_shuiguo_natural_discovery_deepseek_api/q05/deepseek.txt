核心看你要解决的是**损耗、体验还是毛利**。一般水果店更稳的做法是：**整果为主，去皮/鲜切为辅，让顾客参与挑但由店员控品质。**

**建议这样定：**

1. **主陈列用整果，顾客可挑，但店员把关**
   - 菠萝整果耐放、损耗低、毛利更可控。
   - 顾客有“自己挑”的参与感，但你要设规则：顾客指哪个，店员帮判断熟度、有没有黑心、碰伤。
   - 避免顾客翻乱、捏坏、挑走后留下难卖的。

2. **去皮果只做“即时消费场景”**
   - 去皮果适合赶时间、当场吃、办公室/学生客群。
   - 但去皮后保质期短、氧化快、损耗高，必须冷藏、当日清货。
   - 建议**现削现卖**或少量预削，不要大量提前去皮。

3. **不要完全让顾客自己挑完就走**
   - 菠萝熟度差异大，顾客挑错会归因于店。
   - 最好“顾客选，店员确认”：看底部、闻香味、按弹性、看果眼。
   - 可贴熟度标签：今日吃/放两天吃。

4. **按客群分**
   - 社区家庭客多：整果为主，提供免费或低价代削。
   - 街边/商圈即时客多：设鲜切盒，少量去皮整果。
   - 高端客：整果+代削+试吃，体验优先。

**可执行结论：**
- 默认卖整果，允许顾客挑，但店员必须复核。
- 去皮果只做少量、冷藏、当日清。
- 用“免费代削/代切”替代大量预去皮，既降损耗又提体验。
- 设试吃和熟度标识，减少挑错退货。

一句话：**整果是基本盘，去皮是补充品，顾客挑是体验，店员把关才是品质控制。**
