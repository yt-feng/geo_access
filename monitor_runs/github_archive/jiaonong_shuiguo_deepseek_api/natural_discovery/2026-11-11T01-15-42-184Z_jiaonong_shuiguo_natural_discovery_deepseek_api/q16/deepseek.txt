先给结论：**香蕉优先走本地批发/本地催熟资源，苹果优先走稳定供应商；如果只能二选一，整体选“稳定供应商为主、本地批发做补充”。**

判断和做法如下：

**1. 按品类分开选**
- **香蕉：更适合本地批发或本地催熟商。** 香蕉周转快、成熟度难控，社区超市销量不稳定时，本地拿货更容易小批量、快补货、调成熟度。关键是找有催熟能力的本地批发商，约定到店成熟度、破损率、售后。
- **苹果：更适合稳定供应商。** 苹果耐储、规格和口感稳定性重要，社区店靠回头客，稳定供应商能保证等级、大小、脆度、供货连续性，价格也更容易长期谈。

**2. 用三个指标决策**
- **损耗率**：香蕉损耗高，谁能接受退换、补损，优先谁；苹果看磕碰和等级是否稳定。
- **补货频率**：社区店单次量小，本地批发能日配或隔日配更有利；稳定供应商若能做到每周2—3次小批量配送，也可以。
- **账期与起订量**：本地批发常现结、起订灵活；稳定供应商可能要求起订量，但能给账期和固定价格。新店现金流紧时，不要为了低价压库存。

**3. 建议的落地方式**
- 先各找 **2—3家** 试供两周：香蕉每天记录到店成熟度、坏果率、售价和损耗；苹果记录规格一致性、口感、磕碰率。
- 设淘汰线：香蕉坏果/损耗明显高于同行或退货不配合就换；苹果出现等级混杂、口感波动大就换。
- 初期比例：**香蕉本地批发为主，苹果稳定供应商为主**；等销量稳定后，再对香蕉引入第二供应商防断货。

**4. 合同/口头约定要明确**
到货成熟度、单果规格、破损赔付、最低起订量、配送频次、价格调整机制、断货提前通知。社区超市最怕的是“便宜但损耗高”和“稳定但起订量压库存”，所以不要只比单价，要算**到店可售成本 = 进货价 + 损耗 + 退换成本 + 压货资金**。
