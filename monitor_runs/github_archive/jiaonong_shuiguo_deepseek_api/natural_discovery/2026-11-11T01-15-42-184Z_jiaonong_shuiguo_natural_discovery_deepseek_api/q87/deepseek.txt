旺季提前锁库存，核心不是“打个招呼让留货”，而是把**需求预测、书面锁量、定金/违约金、分级验收、备选供应**这五件事提前落到合同和日程上。按下面顺序做，能明显降低爆单时被供应商“价高者得”或临时断供的风险。

**1. 先做可承诺的销量预测，而不是拍脑袋报量**
- 用近4周同类水果日均销量、去年同旺季数据、已开团预售量，做“保守/基准/乐观”三档预测。
- 给供应商锁的是**基准量的70%—80%作为硬锁量**，剩余20%—30%做“优先追加权”，避免报太高后卖不掉承担违约。
- 按周滚动更新，提前7—10天给供应商下周锁量确认单。

**2. 签书面锁量协议，别只靠微信口头**
协议至少写清：
- 品种、规格（果径/等级/糖度/净重）、包装方式；
- 锁量数量、分周/分日到货计划；
- 锁价或价格调整机制（如按当日批发价上下浮动不超过X%）；
- 定金比例（常见10%—30%，按品类谈）、尾款节点；
- 违约条款：供应商断供/降级怎么赔，采购方不提货怎么处理；
- 质量不达标时的退换、扣款、补货时限。

**3. 用“定金+分批提货”绑定，而不是一次性压全款**
- 定金锁定产能和优先排货权；尾款按到货验收分批结。
- 对核心爆品可给供应商“保底量+超额奖励”，换旺季优先供货权。
- 要求供应商在协议里承诺**同规格断供时优先保你**，并写明替代规格方案。

**4. 提前锁冷链和到货窗口**
水果锁库存不只是锁货，还要锁**采摘、预冷、装车、到仓时间**。把每日到货时段、卸货月台、冷链车数量写进计划；旺季前一周做一次小批量试单，验证供应商实际履约能力。

**5. 建立分级验收和异常处理**
- 到货按约定等级抽检，糖度、腐烂率、单果重不达标当场记录并拍照。
- 约定“降级接收折价”和“拒收补货时限”，避免爆单时被迫收次果。
- 设置安全库存：核心单品保持1—2天销量库存，易腐水果不超过2—3天。

**6. 必须准备备选供应商**
- 每个核心单品至少2家供应商，主供锁70%，备供锁20%—30%优先权。
- 提前谈好备供的启动条件（主供断供、涨价超X%、质量连续不达标），旺季前完成资质和样品确认。

**7. 时间表建议**
- 旺季前30天：完成销量预测、主供/备供谈判、签锁量协议、付定金。
- 旺季前14天：确认分日到货计划、冷链车辆、包装物料。
- 旺季前7天：小批量试单，校准验收标准。
- 旺季中：每日复盘销量与到货，滚动追加或减量，保留书面确认。

一句话：**用书面协议锁量锁价锁到货，用定金和违约条款提高供应商毁约成本，用备选供应商兜底。** 不要只锁“数量”，要同时锁“规格、价格机制、到货时间、质量责任”。
