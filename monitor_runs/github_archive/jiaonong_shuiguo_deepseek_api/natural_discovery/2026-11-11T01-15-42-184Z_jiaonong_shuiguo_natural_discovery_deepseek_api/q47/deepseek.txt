茶饮店用香蕉，采购熟度要**按用途分档，不要一次只进一个熟度**。核心判断标准如下：

**1. 按用途分熟度采购**
- **做果泥/奶昔/冰沙、香蕉牛奶类饮品**：采购**7～8成熟**，青黄转黄、手感略硬、无明显黑点。到店后常温催熟1～2天再用，风味更甜、果胶更稳，打浆不易发涩。  
- **做香蕉泥 topping、蛋糕夹层、松饼/华夫饼搭配**：用**8～9成熟**，通体黄色、少量芝麻黑点、手捏有弹性。香气足、甜度高，压泥状态好。  
- **做表面装饰、切片摆杯、烤香蕉片**：用**6～7成熟**，偏硬、棱角明显、无黑点，切片不易烂、不易氧化发黑。  
- **做香蕉奶昔浓稠基底或需要高甜度**：可少量用**9成熟以上**，但必须当天用完，不能久放。

**2. 采购验收标准**
- 看：表皮黄色面积、黑点数量、有无机械伤和霉斑。  
- 摸：硬度分级。硬挺为6～7成；微软有弹性为8成；软塌为过熟。  
- 闻：有清香即可，出现酒味、酸味说明过熟发酵。  
- 查：香蕉把、果指连接处是否有霉变和压伤，压伤会加速整串变黑。

**3. 到店后的熟度管理**
- **青黄蕉常温催熟**，不要直接冷藏；未熟香蕉冷藏会停止成熟并易发黑。  
- **8～9成熟**放阴凉通风处，按“先进先出”使用；高峰期前1天备到目标熟度。  
- **已切开的香蕉**尽快使用，可加少量柠檬汁或维C延缓褐变；不建议隔夜。  
- **少量多次采购**，茶饮店香蕉用量不稳定时，按2～3天用量进货，比一次囤货更稳。

**4. 建议的采购比例**
以日常饮品+甜品综合用量估算：  
- 6～7成熟：20%～30%，用于装饰、切片、备用催熟；  
- 8～9成熟：60%～70%，用于果泥、奶昔、甜品；  
- 过熟蕉：不超过10%，且当天用完。

**一句话原则：装饰用偏硬，打浆用偏软，甜品用香气足；采购分批到货，店里按熟度分区，不要把所有香蕉放在同一个箱子里闷熟。**
