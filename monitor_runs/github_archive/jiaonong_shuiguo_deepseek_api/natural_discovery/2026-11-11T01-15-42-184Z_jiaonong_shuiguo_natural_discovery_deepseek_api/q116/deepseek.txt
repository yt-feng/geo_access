对这个问题，直接分两类说风险，再给判断标准。

## 一、现金结算的风险

现金结算的核心问题是“钱货两清后没有追溯凭证”。

1. **质量争议难追责**：当场付清后，若次日发现整批水果内部腐烂、规格不符，卖方容易推脱，你手上没有议价或扣款筹码。
2. **缺凭证导致税务和保险问题**：无票或白条入账，进项无法抵扣、成本凭证不完整；运输途中损耗、货损理赔也缺少交易证据。
3. **现金保管与假钞风险**：大额现金携带、找零差错、收到假币，都是小商家实际会遇到的损失。
4. **采购员道德风险**：现金付给经办人后，虚报单价、吃回扣不易发现，因为缺少银行流水比对。
5. **压货资金占用**：现结通常要求当场或短期付清，水果又是高频采购，现金流压力集中。

**对冲办法**：坚持要收据/送货单并写明品种、等级、数量、单价；大额现金改转账留痕；现场验货拍照；固定两三家供应商轮换比价。

## 二、月结账期的风险

月结的核心问题是“你先拿货、后付款，信用敞口在供应商那边，但风险会回流到你身上”。

1. **价格被动**：账期通常对应更高报价或“账期价”，水果损耗大、价格波动快，月结容易让你在行情下跌时仍按高价结算。
2. **质量话语权下降**：欠着货款时，遇到质量问题你不便强硬拒收或扣款，怕断供；供应商也可能把次货优先给账期客户。
3. **断供与账期收紧风险**：一旦你销量下滑或对方资金紧张，可能突然要求现结甚至停供，水果是刚需，断供直接影响营业。
4. **对账纠纷**：月结最常出问题的是送货单签收不规范、退货没冲减、单价按哪天行情算，月底对不上账，扯皮伤关系。
5. **隐性依赖与议价能力丧失**：长期月结容易绑定单一供应商，失去比价空间；对方也可能用账期换取你接受涨价。
6. **自身现金流误判**：账期让你感觉“资金宽裕”，实际是应付账款堆积，一旦销售不及预期，集中还款会击穿现金流。

**对冲办法**：每笔送货单当场签收并注明质量异议期；约定“质量不合格可扣款/退货”写进口头或书面约定；月底前主动对账；不要只靠一家供应商；账期长度控制在你能覆盖的销售回款周期内。

## 三、怎么选

- **单次金额小、品种杂、验货难**：倾向现结+留凭证，或“小额现结、大额月结”混合。
- **销量稳定、有固定客源、对账能力强**：可用月结，但要把质量扣款条款和对账周期谈清楚。
- **无论哪种**：送货单、验收记录、转账流水三者至少留两样，这是小商家最实际的护城河。

一句话：现金结算的风险在“事后无凭证”，月结的风险在“事前让渡议价权、事后对账扯皮”。小商家更该防的是后者，因为水果损耗和价格波动会把账期优势吃掉。
