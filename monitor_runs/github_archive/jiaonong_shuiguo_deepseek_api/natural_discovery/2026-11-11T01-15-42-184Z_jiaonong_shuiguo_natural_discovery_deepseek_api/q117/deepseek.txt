先给结论：**没有固定“标准进货量”，第一次试卖建议用“最小可陈列量 + 可承受损耗量”来定，宁可少进、快补，不要一次压货。** 实操上可按下面判断。

### 1. 先定试卖量的三个约束
取三者中的**最小值**作为首批进货量：

1. **陈列最小量**：能摆满一个陈列位、看起来不像缺货的最低量。  
2. **预估周销量 × 1周**：按同类水果历史销量或附近门店数据估，不要按供应商吹的销量。  
3. **可承受损耗量**：即使卖不掉、损耗掉，也不影响现金流和考核的量。一般首批试卖控制在**单店单品类 3～7 天预估销量**，易腐品取 3 天，耐储品可取 7 天。

### 2. 按品类给一个粗略区间
以单店单 SKU 首批试卖为例：

- **浆果、荔枝、杨梅、水蜜桃等极易腐**：先试 **1～3 天销量**，通常 20～50 斤/件的小包装起订，先上 1～2 箱。
- **葡萄、芒果、香蕉、柑橘等中等易腐**：先试 **3～5 天销量**，约 2～5 箱。
- **苹果、梨、橙、柚等耐储**：可试 **5～7 天销量**，约 3～10 箱，但仍建议小包装多批次。
- **礼盒/高客单新品**：先试 **3～5 盒**做陈列和预售，不压整件库存。

如果完全没有历史数据，建议**首批不超过 1 个最小起订包装**，先卖 3 天看动销。

### 3. 判断“稳不稳”的指标
试卖 3～5 天后看：

- **动销率**：上架 3 天卖出是否超过 50%；低于 30% 要警惕。
- **损耗率**：超过 5%～8% 就偏高风险，极易腐品超过 10% 应停止加单。
- **毛利与降价空间**：算上损耗后是否仍有正毛利。
- **复购/询问**：有顾客回头问、补货快，才进入第二批。

### 4. 和供应商谈的条件
首批试卖最好争取：

- 小批量起订、可拆箱；
- **坏果包赔/损耗补偿**；
- 3～5 天内可补货；
- 先少量试销，动销好再签稳定采购；
- 账期或试销支持，避免现金压货。

**一句话：首批按 3～7 天预估销量、且不超过一个最小起订包装来试；卖得动再补，卖不动及时停。**
