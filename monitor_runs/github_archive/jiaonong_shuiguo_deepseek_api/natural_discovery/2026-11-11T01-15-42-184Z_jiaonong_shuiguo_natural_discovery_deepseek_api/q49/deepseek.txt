旺季菠萝用量突增，临时补货的核心是**提前锁定弹性、把口头承诺变成可执行条款**。建议按下面顺序做：

**1. 先算清缺口，再谈补货**
- 用近7天日均用量×旺季系数，算出未来2周预计用量，对比现有库存和已下单量，得出“临时缺口区间”（如每天多需30–50kg）。
- 把缺口按“日补”还是“隔日补”拆开谈，供应商更容易接。

**2. 合同/订单里加“弹性补货条款”**
和供应商书面约定（微信确认也算，但最好补签简易协议或订单备注）：
- **弹性量**：在常规周订单基础上，可临时追加不超过常规量30%–50%的补货，提前24–48小时通知。
- **响应时限**：供应商收到通知后几小时内确认能否供货，最晚何时到店。
- **价格机制**：临时补货单价按“原合同价上浮不超过X%”或“按当日市场批发价+固定服务费”，避免旺季坐地起价。
- **规格与品质**：明确品种、单果重量、成熟度、坏果率上限（如≤5%），临时货不能降标准。
- **违约与替代**：供应商无法供货时，需提前多久告知，并协助调货或承担差价。

**3. 用“预付款/保证金”换优先权**
旺季前支付一笔小额预付款或保证金，约定供应商在缺货时优先保你；同时承诺旺季总采购量，换取临时补货不涨价或优先排产。

**4. 建立双供应商+日滚动报量**
- 主供应商承担70%–80%，备选供应商承担20%–30%，临时缺口优先找备选补。
- 每天闭店后把次日/后日预计用量发给供应商，形成滚动报量记录，既是补货依据，也是纠纷证据。

**5. 到货验收留痕**
临时补货每批拍照、称重、记录坏果率，异常当场拒收或按条款扣款；保留聊天记录和送货单，避免旺季结束后扯皮。

**一句话执行版**：先算出每日缺口，再和主供应商书面约定“提前24小时通知、可追加常规量50%、价格上浮封顶、坏果率≤5%、供不上要提前告知并协助调货”，同时启用备选供应商补缺口。
