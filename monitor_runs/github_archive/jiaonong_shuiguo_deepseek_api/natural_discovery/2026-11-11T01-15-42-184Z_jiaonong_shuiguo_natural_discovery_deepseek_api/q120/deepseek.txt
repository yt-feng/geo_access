供应商介绍时，核心不是讲自己有什么货，而是把“陌生品种”翻译成商家熟悉的**卖法、利润和风险**。可以按这个结构说：

1. **先对标大品类**  
   不说“这是凤梨释迦”，而说：  
   “它像菠萝一样好切好卖，但口感更甜、籽少，适合做果切和礼盒。”

2. **直接给卖法**  
   “这个适合三种卖法：散卖按个、果切按盒、节庆做礼盒。散卖走量，果切拉毛利，礼盒做团购。”

3. **给价格带和毛利判断**  
   不说进货价多便宜，而说：  
   “你那边普通香蕉卖5块，这个可以卖8到10块，毛利能多3到4块；但损耗比香蕉高，建议先小批量试。”

4. **讲清缺点和风险**  
   商家最怕压货。要主动说：  
   “它怕冷、熟得快，一次别进太多；前3天卖不动就要转果切或促销。”

5. **给试单方案**  
   “先拿一箱试卖，配一张话术卡：怎么挑、怎么放、怎么推荐。卖得动再补。”

6. **用一句话总结**  
   “这个品不是让你换掉香蕉菠萝，而是给你多一个高毛利补充品，先小量试，不压货。”

一句话原则：**别讲品种故事，讲“怎么卖、赚多少、会不会烂手里”。**
