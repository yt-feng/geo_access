判断“大小规格是否适合门店销售”，核心不是只看单个果大不大，而是看**规格是否稳定、是否匹配你门店的客群和售卖方式、损耗是否可控**。可按下面几步做。

**1. 先按售卖方式定规格带**
- **散卖/称重**：消费者偏好中等、均匀、好拿的规格。苹果通常按横径或单果重分档，橙子按横径或单果重分档；不要混入明显偏小或偏大的果。散卖最忌讳“大小混杂”，会拉低感知。
- **按个卖/礼盒/精品陈列**：规格要更整齐，可以接受整体偏大，但必须同档一致；礼盒还要看果形、色泽、瑕疵。
- **餐饮/团购/促销**：可接受偏小或规格略宽，但要明确标注等级和用途，避免门店客诉。

**2. 用“抽检+分档”判断规格稳定性**
采购现场不要只看上面一层。随机从不同箱、不同层抽检，至少几十个样品，按你的目标规格分档计数：
- 目标规格内的比例是否高，例如是否达到你设定的合格率；
- 超小、超大、畸形、伤果比例；
- 同一箱内最大和最小差异是否过大。
如果一箱里跨了两三个明显规格，散卖就容易出现“挑剩”和损耗。

**3. 结合门店客群定“适销规格”**
- 社区店/家庭客群：中等规格、性价比高、单次购买量适中更合适；
- 商圈店/精品店：外观整齐、规格偏大、包装友好更合适；
- 学校/工地/食堂周边：可接受偏小规格，但要好剥好分；
- 老年客群多：不要过大过重，拿取和食用便利性重要。
规格没有绝对标准，关键是**你的主力客群愿不愿意按这个大小反复买**。

**4. 看规格与价格带是否匹配**
同样品种，规格跨档会直接影响定价。采购时要问清：这档规格对应的进货价，门店预计售卖方式下的毛利和损耗。若大果进价高但门店客群不认，或小果便宜但挑剩严重，都不适合。建议用“**预计售价×可售率－进货成本－损耗**”粗算，而不是只比进货单价。

**5. 现场可执行的验收动作**
- 定一个书面规格标准：品种、横径或单果重区间、允许误差、瑕疵上限；
- 到货抽检不同箱/层，记录合格率和不合格原因；
- 对混装、规格跨档明显的批次拒收或降级处理；
- 先小批量试销，观察顾客挑选后的剩余规格和损耗，再调整采购档位。

**简单判断标准**：如果目标规格占比高、同箱差异小、门店主力客群拿起来不觉得太大或太小、试销后挑剩和损耗可控，就适合；如果规格混杂、超小超大比例高、顾客反复挑剩，就不适合，应换档或换供应商。
