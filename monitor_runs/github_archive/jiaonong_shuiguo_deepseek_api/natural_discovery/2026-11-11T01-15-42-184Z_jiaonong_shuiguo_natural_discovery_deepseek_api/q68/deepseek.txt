判断供应商能不能按时到车，核心不是听他口头保证，而是看“可验证的履约条件”。给你一套批发商可直接用的判断方法：

**一、先问清四个硬信息**
1. **产地/装货点具体位置**：精确到县、镇、冷库或包装厂，越具体越可靠。
2. **装车计划时间**：哪天几点开始装、装多久、装完几点发车。
3. **车辆是否已定**：车牌号、司机电话、车型载重、是否冷链车。
4. **到货时间与路线**：预计几个小时、走哪条高速、途中是否中转。

如果供应商连车辆和装货点都说不清，基本可以判定“没排上”，不要押太多。

**二、看三个可验证动作**
- **要装车视频/照片**：装货前拍冷库或包装厂现场，装车中拍车牌和装车进度。能实时发视频的比只发文字可靠。
- **直接和司机通话**：确认司机是否知道装货点、装货时间、到货市场。供应商说“车定了”但司机不知情，多半是拼凑车源。
- **要车辆定位**：装车后让司机开共享位置或发定位截图，看是否真在往你市场方向走。

**三、用历史记录判断**
- 问供应商近一周发过几车、到过哪些市场，能否提供上一车司机的联系方式或装车单。
- 老供应商看**近三次到车准点率**；新供应商先小批量试一车，不要第一车就压大单。
- 注意“车多但都晚”的供应商：可能车源是临时调的，装货排队不可控。

**四、合同/口头约定要落到可执行条款**
- 明确“装车完成时间”和“市场到场时间”，不要只写“尽快”。
- 约定晚到怎么处理：比如超过几小时扣运费、香蕉熟度风险谁承担、是否可以改档口。
- 定金比例控制在能承受范围，尾款到场验货后付。

**五、临发车前的三个检查点**
1. **装车前2小时**：确认车辆已到装货点，要现场视频。
2. **装车完成时**：要车牌、装车单、司机电话，确认发车。
3. **途中**：看定位是否朝你方向走，预计到场前3小时再确认一次。

**简单判断口诀：**
> 说得清装货点、叫得出车牌、找得到司机、发得了定位、有历史到车记录——五项里缺两项以上，就要降低订货量或换供应商。

另外，香蕉对温度和时间敏感，优先选有冷链车或熟悉香蕉运输的司机；如果供应商只保证“车会到”但不保证“冷链和时效”，也要把熟度风险算进去。
