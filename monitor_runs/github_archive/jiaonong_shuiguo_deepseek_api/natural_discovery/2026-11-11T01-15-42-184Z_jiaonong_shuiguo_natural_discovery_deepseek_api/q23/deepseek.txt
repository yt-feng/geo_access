可以，而且这通常是水果促销里最值得向供应商争取的资源。建议按“先谈支持包，再定费用归属，最后落到陈列和活动执行”的方式推进。

**供应商常见可提供的支持**
1. **陈列支持**
   - 提供堆头、端架、地堆的陈列方案或物料，如围挡、价签、POP、果篮/托盘。
   - 派人到店做陈列指导，或承担部分陈列搭建。
   - 对重点单品给“陈列位置+陈列量”要求，配合返利或专项补贴。

2. **海报/宣传支持**
   - 提供单品海报、爆炸贴、吊旗、促销员围裙等物料。
   - 承担部分海报印刷费，或提供电子图给超市做社群/小程序宣传。
   - 联合做“供应商品牌+超市促销”的联合海报，费用按约定分摊。

3. **试吃/活动支持**
   - 提供试吃果品、试吃台、一次性用品、试吃员。
   - 派促销员驻店做试吃推广，或给试吃损耗补贴。
   - 配合做“买赠、满减、扫码领券”等联合活动，供应商承担赠品或券成本。

**谈判时建议明确**
- 支持形式：物料、人员、费用、货品损耗分别由谁承担。
- 费用归属：海报印刷、试吃损耗、促销员工资是否计入供货价或单独核销。
- 执行标准：陈列位置、陈列天数、试吃时段、海报张贴位置和数量。
- 核销方式：拍照验收、签到表、销售数据对比，避免口头承诺。
- 排他条件：供应商是否要求独家陈列或最低陈列量，避免影响其他单品。

**可执行的谈判话术**
“这次水果促销我们计划给重点单品做端架/地堆和试吃，希望供应商按‘陈列物料+海报支持+试吃损耗补贴’给一个支持包。费用可以按销售返点或专项核销，但需要明确陈列位置、执行天数和验收方式。”

如果供应商规模较小，通常更愿意给**货品损耗补贴和试吃果品**；品牌供应商更可能给**物料、促销员和联合海报**。建议先选1—2个重点单品做试点，用销售增量数据再谈下一档支持。
