直接给结论：**默认以整果为主，切果作为补充；但要看门店客群和客流结构，不能一刀切。** 判断逻辑如下。

## 先判断你的门店属于哪类
| 门店特征 | 更优选择 |
|---|---|
| 社区店、中老年客群多、家庭采购为主 | 整果为主，切果少量试销 |
| 商圈店、写字楼店、年轻人/单身客群多 | 整果+切果并重，切果占比可提高 |
| 客流大、冲动消费强、即食需求明显 | 切果优势明显 |
| 客流小、损耗管控能力弱 | 优先整果，慎上切果 |

## 整果 vs 切果的核心权衡
**整果优势**
- 损耗低、保质期长、毛利更稳
- 采购和陈列简单，适合走量
- 顾客可自行判断成熟度，投诉少

**整果劣势**
- 菠萝去皮麻烦，年轻/单身客群购买意愿低
- 客单价和即食转化有限

**切果优势**
- 即食、便利，能拉高冲动购买和客单价
- 对年轻客群、办公场景吸引力强
- 可做果切拼盘，提升连带销售

**切果劣势**
- 损耗高、保质期短，对冷链和日清要求高
- 人工成本增加，品控不稳定易引发投诉
- 卖不动就是直接报损

## 可执行建议
1. **先小规模试销**：选1—2家代表性门店，切果按日配少量，观察3—7天动销和报损率。
2. **设止损线**：切果日报损率超过10%—15%，或下午仍剩一半以上，就收缩或改整果为主。
3. **分时段上架**：切果上午少量、午晚高峰前补货，避免全天陈列导致品质下降。
4. **整果做引流，切果做利润**：整果保销量和价格形象，切果做便利溢价。
5. **看数据再定比例**：以“切果销售额占比、报损率、毛利率、客诉率”四个指标决定是否扩大。

**一句话：没有冷链和日清能力就别主推切果；有年轻客流和即食场景，就用切果做增量，但整果仍是基本盘。**
