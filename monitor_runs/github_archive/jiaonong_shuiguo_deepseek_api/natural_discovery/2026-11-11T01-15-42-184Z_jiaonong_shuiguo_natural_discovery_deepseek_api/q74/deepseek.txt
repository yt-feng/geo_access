面向餐饮客户，菠萝和香蕉的规格要从**后厨加工效率、出品稳定性、损耗控制**三个角度定，不能沿用零售档口的卖法。建议按下面备货：

**菠萝**
- **主推：鲜果，单果1.2–1.8斤，7–8成熟**
  - 适合现切果盘、炒饭、咕噜肉、饮品装饰。
  - 餐饮要的是“出成率稳定”，不要太大果（芯粗、边角多）也不要太小果（削皮工时高）。
- **备货比例：70%鲜果 + 30%预加工**
  - 预加工包括去皮去眼、切块/切片、真空小包装（1kg/袋或2kg/袋），主攻没时间削菠萝的小店和连锁快餐。
- **规格分级**
  - A级：1.5–1.8斤/个，果眼浅、芯细，供中高端餐厅和果切店。
  - B级：1.2–1.5斤/个，供快餐、食堂、饮品店。
  - 次果/小果：做菠萝炒饭、熬酱、饮品店打果泥，低价走量。
- **包装**：鲜果用周转筐按10kg/筐；预加工品用食品级真空袋，标注去皮日期和保质期。
- **验收话术**：向餐厅明确“按箱/按筐开箱验货，坏果率超过5%当箱补换”。

**香蕉**
- **主推：青蕉（7成熟）到黄蕉（8–9成熟）分档供应**
  - 餐饮用香蕉场景不同，成熟度必须分开：果盘/甜品要8–9成熟即用；香蕉船、烘焙、奶昔可用7–8成熟；油炸香蕉、拔丝香蕉要偏生一点。
- **规格**
  - 单根150–200g，整把整齐、无机械伤，适合果盘和甜品摆盘。
  - 单根120–150g，适合饮品店、食堂、员工餐，成本低。
  - 大蕉/粉蕉可单独备，供东南亚菜、油炸和炖煮场景。
- **成熟度供应方案**
  - 每周固定两天送“即用黄蕉”（8–9成熟），保证当天能用。
  - 同时送“催熟过渡蕉”（7成熟），让客户自己控熟，减少压货。
  - 对连锁客户可做“按成熟度分级装箱”，箱标注明到货成熟度和建议使用天数。
- **包装**：按把/梳装箱，避免整串挤压；每箱不超过12–15kg，箱内加垫纸。
- **损耗承诺**：香蕉是餐饮客户最怕的品，建议明确“到货24小时内发现黑腐/断裂超3%可换补”，这是拉开批发档口差距的关键。

**给餐饮客户的首推组合**
- 小型餐饮/快餐：菠萝B级鲜果 + 预切菠萝块1kg装；香蕉120–150g/根，7–8成熟。
- 中高端餐厅/果切店：菠萝A级鲜果 + 香蕉150–200g/根，8–9成熟即用装。
- 饮品店：菠萝次果/果泥原料 + 香蕉偏熟小果，按周配送到店。

**实操建议**
先不要一次上全规格。选3–5家目标餐饮客户做两周试供，记录他们的**实际用量、加工方式、报废原因**，再定常备规格和每周配送频次。餐饮客户真正下单的理由是“规格稳定、损耗可赔、送货准时”，不是单价最低。
