要支持，但不要无条件支持；建议按门店分层、品类分层、收费与考核规则配套来做。

**结论**
即时零售平台卖水果，供应商应支持小批量高频补货，因为这是平台履约和损耗控制的刚性需求；但供应商必须通过起订量、补货频次、加急费、品类差异化和数据协同，把成本转回可控范围。

**为什么必须支持**
- 即时零售订单碎片化、履约时效短，门店库存过深会带来损耗，过浅会缺货掉单。
- 水果非标、易损、保质期短，靠“大批量少频次”会把损耗和缺货同时放大。
- 高频补货能提升有货率、降低门店报损，也是平台考核供应商的重要维度。

**但不能无条件支持的原因**
- 小批量高频会推高供应商拣配、物流、包装和人工成本，单均履约成本可能倒挂。
- 水果批次品质波动大，高频补货若品控跟不上，会放大客诉和退货。
- 若无起订门槛，门店会把补货压力全部转嫁给供应商，形成“平台要时效、供应商扛成本”的失衡。

**可执行建议**
1. **按门店分层**：高销门店支持日配甚至一日两配；低销门店设最低起订量或隔日配，避免无效高频。
2. **按品类分层**：叶菜、浆果、切果等易损高周转品支持高频小批量；苹果、橙子、根茎类等耐储品降低频次、提高单次批量。
3. **设补货规则**：明确起订金额/件数、截单时间、加急补货附加费、缺货罚则与损耗责任归属。
4. **用数据协同**：基于销量、库存、报损、缺货率做补货建议，而不是门店随意下单；供应商参与补货参数校准。
5. **收费与考核对称**：小批量高频可收配送或操作附加费；同时平台应给高有货率、低损耗的供应商流量或账期支持。
6. **试点再推广**：先选高销门店和易损品类跑2—4周，看有货率、报损率、单均履约成本三项指标，再决定扩围。

**判断标准**
支持小批量高频补货的前提是：有货率提升和报损下降带来的收益，能覆盖新增履约成本；否则应通过起订量、频次和品类分层来约束，而不是简单拒绝或全盘接受。
