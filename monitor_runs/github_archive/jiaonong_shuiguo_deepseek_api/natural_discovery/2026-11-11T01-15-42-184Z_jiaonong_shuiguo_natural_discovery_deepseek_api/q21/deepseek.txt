超市采购水果时，供应商通常需要提供以下证明和报告。具体要哪些，取决于水果品类、是否为初级农产品、是否声称“绿色/有机/地理标志”、以及当地市场监管和超市自身的索证索票制度。

**一、基础进货证明（几乎都要）**
1. **营业执照**：供应商主体资格证明。
2. **食品经营许可证/食品生产许可证**：预包装水果制品、鲜切水果、果汁等深加工产品需要；单纯销售初级食用农产品通常按初级农产品管理，但仍应核验主体资质和当地要求。
3. **供货凭证/销售单/送货单**：载明品名、规格、数量、生产日期或采摘日期、供货商名称及联系方式、收货单位等。
4. **产地证明或采购凭证**：证明水果来源，如产地证明、收购凭证、合同、发票等。
5. **承诺达标合格证**：很多地区对食用农产品要求开具承诺达标合格证，尤其是规模化生产主体；超市应索取并留存。

**二、检测报告类（按风险和要求）**
1. **农残检测报告**：最常见。可以是供应商自检报告、产地检测站报告或第三方检测报告。重点看检测项目是否覆盖禁限用农药和常规农残，报告是否在有效期内、批次是否对应。
2. **第三方型式检验报告**：大型超市或连锁采购常要求每品类/每产地提供有效期内的第三方检测报告，如农残、重金属等。
3. **快检结果**：超市自有快检室或配送中心对每批水果做农残快检，保留快检记录；供应商可提供产地或批发市场的快检合格凭证。
4. **进口水果**：需提供海关入境货物检验检疫证明、报关单等；预包装进口水果还应有中文标签。
5. **特殊声称**：如“有机”“绿色食品”“地理标志”，需提供对应认证证书和标志使用证明；有机产品还需有机码/销售证等。

**三、超市实操建议**
- 建立**供应商档案**：营业执照、许可证、合格证、检测报告、供货凭证按供应商和批次归档。
- 执行**索证索票和进货查验记录**：每批记录品名、数量、供货者、日期、产地、检测报告编号或快检结果。
- 对高风险品类（叶菜、草莓、葡萄、豇豆等）提高抽检频次；对普通水果可采取“合格证+快检+定期第三方报告”组合。
- 报告要核对**批次、日期、检测机构资质（CMA/CNAS）和检测项目**，不能只看一张过期报告。
- 各地监管要求可能有差异，建议以当地市场监管部门对食用农产品索证索票的具体规定为准。

简言之：**基础三样是营业执照/许可资质、供货凭证和承诺达标合格证；检测上以农残检测报告或快检合格记录为核心，进口水果加检验检疫证明，特殊认证加对应证书。**
