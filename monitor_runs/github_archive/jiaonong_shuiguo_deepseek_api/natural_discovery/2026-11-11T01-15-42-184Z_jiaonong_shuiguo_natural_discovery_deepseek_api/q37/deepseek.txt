商超会员日水果活动，供应商要提前配合的重点可以按“货、价、陈列、履约、风险”五块准备：

1. **货量与品质锁定**
   - 提前确认活动预估销量、主推单品和备货量，按会员日峰值备货，避免当天断货或压货。
   - 锁定采摘/到货批次，明确成熟度、规格、糖度、大小标准；活动前1—2天到货，留出分拣和熟度调整时间。
   - 准备备用货源和替代单品，防止主推品缺货或品质波动。

2. **价格与费用确认**
   - 提前锁定活动供货价、促销价、毛利空间和费用分摊（特价补贴、损耗、陈列费、促销员费用等）。
   - 明确价格有效期和调价机制，避免活动前临时涨价。
   - 对临期、尾货、损耗处理方式提前约定，避免结算争议。

3. **包装与陈列物料**
   - 按门店陈列需求准备统一规格的箱装、托盘、网套、标签、价签、POP、试吃物料等。
   - 提前完成分拣、预包装、贴标，减少门店现场加工压力。
   - 配合门店做堆头、端架、冷藏柜陈列方案，明确陈列量和补货频次。

4. **物流与到店履约**
   - 提前排定配送时间、车辆、卸货门店和联系人，避开门店客流高峰。
   - 活动前完成首轮铺货，活动当天安排补货车辆和应急调货机制。
   - 明确冷链要求，尤其浆果、切果、叶菜类水果的温控和到店验收标准。

5. **人员与现场支持**
   - 安排促销员、试吃员或理货员到店支持，提前培训产品卖点、试吃话术和补货标准。
   - 明确供应商现场负责人和门店对接人，建立活动当天快速响应群。
   - 准备试吃份量、牙签、手套、垃圾袋等消耗物料。

6. **质量与售后预案**
   - 活动前提供质检报告或产地证明，明确验收标准和退换货规则。
   - 对坏果、压伤、熟度不均等制定快速换货或折价处理方案。
   - 活动当天安排巡店，发现品质问题及时下架、补货或换品。

7. **数据与复盘准备**
   - 提前和采购确认活动目标：销量、引流、毛利、损耗率。
   - 活动期间按单品记录到货量、销量、损耗、缺货和客诉。
   - 活动后48小时内配合复盘，调整下次会员日备货和促销结构。

一句话总结：供应商要在活动前把**货备足、价锁死、品质稳、物料齐、配送准、人员到、售后快**，并与商超采购和门店店长形成一张明确的对接清单。
