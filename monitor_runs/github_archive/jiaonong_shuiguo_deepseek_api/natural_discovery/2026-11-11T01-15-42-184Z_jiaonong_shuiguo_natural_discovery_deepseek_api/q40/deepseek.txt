节假日水果需求暴增，锁货源的核心是**把“临时抢货”变成“提前合同 + 分仓备货 + 替代方案”**。建议按下面几步做：

**1. 提前做需求预测，不按日常销量订货**
- 拉出近2—3年同节假日的单品销量、缺货率、损耗率，按门店/品类做基线。
- 节日备货量一般按日常销量的1.5—3倍分档，易腐水果不宜一次性压太多，按“节前3天、节中补货、节后收尾”分批次锁量。
- 重点锁高频刚需品：苹果、梨、橙、香蕉、西瓜、葡萄、礼盒装水果；网红/高毛利品做弹性备货。

**2. 提前签“框架协议 + 滚动订单”**
- 节前1—2个月与主力供应商签节日保供协议，明确：品类、规格、预估量、价格浮动机制、最低供货量、违约赔付、到货时间。
- 不要只签总量，要拆成周/日滚动订单，给供应商稳定预期，也保留天气、客流变化时的调整空间。
- 对核心单品可支付少量定金锁价锁量，但合同里写清质量标准和退换货条款。

**3. 产地直采 + 多源备份**
- 主力货源走产地合作社/大型批发市场，提前锁定采摘窗口和冷链车。
- 每个核心单品至少备2—3个供应商，分主供、备供；跨产区布局，避免单一产区天气或交通中断。
- 对节日礼盒、精品果，提前确认包装厂产能和到店时间。

**4. 分仓备货，控制损耗**
- 节前把货分到中心仓和门店周边前置仓，不要全压总仓。
- 易腐水果“少量多次”补货，耐储水果可提前7—10天备货。
- 设定安全库存和补货触发线，例如某单品库存低于3天销量自动补单。

**5. 用替代品和价格机制兜底**
- 每个爆款准备2—3个替代单品，主货短缺时快速切换陈列和促销。
- 节日期间适当提高敏感单品安全库存，但用动态定价、组合礼盒消化库存，避免节后集中损耗。

**6. 物流和应急条款写进合同**
- 明确到货时间窗、冷链温度、验收标准、缺货赔付。
- 节日期间安排专人盯供应商发货和在途，提前锁定备用车辆。
- 对天气、交通、疫情等不可抗力，约定替代供货或退款机制。

**可执行清单：**
节前60天：盘点历史数据，定节日单品和备货量；  
节前45天：签主力供应商保供协议，开发备选供应商；  
节前30天：锁定产地采摘和冷链运力，定分仓计划；  
节前15天：下第一轮滚动订单，检查包装和礼盒产能；  
节前7天：按日补货，启动库存预警；  
节日期间：每日复盘销量和缺货，动态调拨。

一句话：**用历史数据定量、用合同锁主供、用多源防断供、用分仓降损耗、用替代品兜底。**
