# 批发商谈供应商账期与额度的实操思路

先说结论：**账期和额度不是“谈”出来的，是“换”出来的。** 供应商愿意给你账期，本质是在评估两件事——你的周转能力（还得上）和你的不可替代性（不敢失去你）。所以谈判前先把自己的“筹码结构”想清楚，再上桌。

## 一、先想清楚你手里有什么

供应商给账期的真实逻辑是：**风险可控 + 收益可期**。你要证明这两点：

- **量的确定性**：你能给出月度采购量承诺（哪怕区间），而不是“有单就下”。稳定大客户的价值就在于可预测，这是你最硬的筹码。
- **回款历史**：如果你之前合作过、付款干净，这是最好的背书。没有历史就先从小额短账期做起。
- **替代成本**：你能否接受换供应商？你能不能带来新渠道（比如你覆盖的终端客户是供应商想进的）？这些都是筹码。
- **风险对冲**：愿意给保证金、接受分批结算、接受质量对赌，都能换取更高额度。

## 二、账期怎么谈：阶梯式，别一步到位

不要一上来就要“60天账期”。水果是生鲜，供应商现金流压力大、损耗风险高，直接要大账期很容易被拒或抬价。推荐**阶梯设计**：

1. **起步期（1-3个月）**：现款或7天账期，换取价格优惠或优先供货。目的不是省钱，是建立“付款干净”的记录。
2. **成长期**：谈到15-30天账期，同时给出月度采购量承诺。这时可以提“账期内按时付，超期自愿付违约金”的条款，降低对方顾虑。
3. **稳定期**：以半年以上的稳定采购记录为据，谈45-60天账期 + 年度返点。此时你已经是“大客户”，议价权自然上来。

关键话术方向：**“我承诺月采购X万、账期30天、到期T+1必付，逾期按日息付违约；作为交换，我要价格下浮X%和旺季优先供货。”** 把账期和你的承诺绑定，对方才敢给。

## 三、额度怎么定：跟账期一起谈，别分开

额度本质是“赊销上限”，要和账期联动，否则会出现“账期长但额度低、旺季不够用”的尴尬。建议：

- **额度 = 月均采购额 × 账期倍数 × 安全系数**。比如月采购10万、账期30天，额度给到10-15万比较合理（覆盖一个账期+缓冲）。
- **设动态调整机制**：连续3个月按时付款，额度自动上浮20%；出现逾期，额度冻结或下调。把它写进合作框架，双方都有预期。
- **旺季单独申请临时额度**：水果有季节性，旺季前1个月申请临时提额，用“旺季销量数据+预付款比例”做交换。

## 四、必须谈清楚的几个条款（容易被忽略）

1. **账期起算点**：是发货日、到货日还是对账日？生鲜损耗多，务必写清“以到货验收合格日为起算”，否则扯皮。
2. **质量扣款与账期分离**：坏果扣款怎么算、是否影响账期付款？建议约定“质量争议单独结算，不影响无争议货款按期支付”，否则账期形同虚设。
3. **价格与账期的联动**：现款价和账期价通常不同。要问清“账期是否暗含价格上浮”，把账期成本换算成年化，判断值不值。
4. **违约与终止**：逾期几次触发降额、断供？提前写清楚，避免旺季被卡脖子。

## 五、如果你的目标是“绑定稳定大客户”

注意你问的是“做稳定大客户”，那账期谈判要服务于**客户粘性**，不只是压供应商。思路是：

- 你给终端大客户的账期，要和你从供应商拿到的账期**错配出正现金流**（比如供应商给30天、你给客户45天，中间靠预付款或自有资金补）。
- 用“稳定采购量 + 准时付款”换供应商的**优先供货权和价格保护**，再把这个确定性传导给你的大客户，形成“你稳定—供应商稳定—客户稳定”的闭环。

## 一句话行动建议

先跑1-3个月现款/短账期建立记录，同时整理你的月采购量预测和终端客户结构，然后带着“量承诺+付款承诺+违约条款”去谈阶梯账期和联动额度，把质量扣款、起算点、调额机制写进框架协议。**别只谈数字，要谈交换条件。**
