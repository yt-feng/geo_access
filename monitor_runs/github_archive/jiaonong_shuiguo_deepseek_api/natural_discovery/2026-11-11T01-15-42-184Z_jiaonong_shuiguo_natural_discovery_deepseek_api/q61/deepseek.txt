判断香蕉一手货源稳不稳，别只看对方说“有基地、天天发”，重点看可验证的供货能力。可按下面顺序查：

1. **看产地和季节覆盖**
   - 问清主产区：广西、云南、海南、老挝、越南、菲律宾等。单一产区在换季时容易断供。
   - 要求对方说明“现在到未来3个月”分别从哪发货、哪个月可能缺货。说不清季节切换的，稳定性通常一般。
   - 一手货源最好能对应到具体产区、合作社/基地或长期代办，而不是只说“市场调货”。

2. **查实际发货记录**
   - 让对方提供近期连续发货的凭证：装车单、过磅单、冷链/普通车车牌、发货视频。注意看日期是否连续、品种规格是否一致。
   - 要求视频通话看现场：加工棚、催熟库、装车位、当天在装的货。只发仓库照片不够。
   - 问“昨天发了几车、发往哪里、什么规格”，再核对单据。前后对不上要警惕。

3. **看规格和品质稳定性**
   - 香蕉关键看：条蕉/梳蕉、每把条数、单条重量、长度、青度、成熟度、伤疤、水烂、黑星病、把型整齐度。
   - 让对方报“到货标准+允许次品率”，比如次品率多少、短斤少两怎么赔。只报低价不报标准的，后期容易扯皮。
   - 先小批量试单2—3次，不要第一次就大额打款。试单看：到货青度是否一致、催熟后是否掉把、货架期是否够、损耗是否在承诺范围内。

4. **看催熟和冷链能力**
   - 批发档口要稳定，催熟库和温控很关键。问清是否有自有/合作催熟库、库容多少、催熟周期几天。
   - 要求看催熟库现场和温湿度记录。香蕉催熟不稳，货源再便宜也难做。
   - 远距离发货要确认运输方式：冷链车、棉被车还是普通车，途中温度怎么控。

5. **看结算和履约方式**
   - 优先选能“货到验货后付款”或“定金+到货尾款”的，不接受长期大额预付。
   - 合同/聊天记录写清：规格、数量、单价、到货时间、次品率、短斤少两赔付、断供违约金。
   - 观察对方是否愿意承担试单风险。越回避赔付条款，越要谨慎。

6. **做压力测试**
   - 临时加单：看能否在24—48小时内补一车。
   - 换规格：比如从梳蕉换条蕉，看是否能稳定供。
   - 问淡季供货：旺季谁都有货，淡季还能不能按周稳定发，才是真稳定。
   - 查同行口碑：问同市场其他档口、司机、包装工，比听对方自夸可靠。

**简单判断标准：**能说清产区切换、能连续提供发货单据、愿意视频看现场、接受小批量试单和赔付条款、淡季仍能稳定发车的，才算比较稳。只要对方只强调低价、催你大额打款、拒绝看现场和试单，基本不建议作为一手稳定货源。
