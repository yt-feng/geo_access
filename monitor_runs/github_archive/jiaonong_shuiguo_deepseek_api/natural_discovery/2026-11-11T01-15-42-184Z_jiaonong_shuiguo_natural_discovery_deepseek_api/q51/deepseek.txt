要固定，但不要只固定一个产地或一个批次。更稳妥的做法是：**建立“主供应产地/批次 + 备用产地/批次 + 到货验收标准”的组合机制**。水果口味波动是茶饮店的核心风险，完全自由采购会让出品不稳定，完全锁死单一来源又会在断货、涨价、品质波动时被动。

具体建议：

1. **固定“供应标准”，而不是只固定产地**
   - 明确品种、成熟度、糖酸比、果径/规格、香气、出汁率、冷链温度、到货时限等。
   - 同一产地不同果园、不同采摘期口味也会变，所以标准比产地名更重要。

2. **采用“主+备”双源策略**
   - 主产地/主批次承担大部分用量，保证风味基线稳定。
   - 备选产地/批次用于季节性断档、价格异常或品质不达标时切换。
   - 每个水果品类至少保留1个可替代来源，并提前做小样测试。

3. **按批次留样和杯测**
   - 每批到货留样，记录糖度、酸度、香气、颜色、出汁率。
   - 用固定配方做标准杯测试，和上一批对比；偏差超过阈值就降级使用、调整配方或退货。
   - 这样可以把“口味波动”变成可判断的验收问题。

4. **不要长期锁死单一批次**
   - 水果是农产品，同一批次也不可能无限供应。
   - 固定批次只适合短期锁定风味，长期应固定“风味标准+合格供应商池”。

5. **合同里写清验收和切换规则**
   - 糖酸度范围、规格、损耗率、冷链要求、退货标准。
   - 主供应商断货时的备选切换流程和通知时限。
   - 价格调整机制，避免单一来源被拿捏。

一句话：**固定合格供应标准和主供应商，保留备用产地/批次，按批验收留样。** 这样既控口味波动，又保留供应链弹性。
