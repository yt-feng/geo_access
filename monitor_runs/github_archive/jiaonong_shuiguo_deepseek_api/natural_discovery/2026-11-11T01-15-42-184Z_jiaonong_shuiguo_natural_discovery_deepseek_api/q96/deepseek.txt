三者在企业食堂采购里不是同一权重，建议按 **食品安全一票否决 → 配送准时保运营 → 价格优化** 来排。

**1. 食品安全是底线，最优先**
水果常直接生食，农残、霉变、致病菌、来源不明风险都高。应关注：供应商资质与检测报告、批次验收、冷链/储存条件、退换货和追溯机制。食品安全出问题，成本和准时都失去意义。

**2. 配送准时是硬约束**
食堂供餐时间固定，水果晚到会直接影响菜单和员工体验，尤其是早餐、下午茶或接待场景。建议明确到货时间窗、迟到赔付、节假日保供和应急替代方案。

**3. 价格重要，但不排第一**
水果价格波动大，应比“综合成本”而非单纯单价：损耗率、规格稳定性、结算方式、退换货成本都要算进去。可设价格区间和调价机制，避免低价低质。

**可执行做法：**
- 准入：食品安全资质和检测不合格直接淘汰。
- 考核：准时率、验收合格率、投诉率设硬指标。
- 比价：在合格供应商中比综合成本，不单纯最低价。
- 备选：至少保留1家应急供应商，防止断供。

一句话：**食品安全决定能不能买，配送准时决定能不能用，价格决定划不划算。**
