优先看**成熟度**，价格放在第二位。原因是香蕉在烘焙里的作用不只是“提供甜味”，而是直接影响蛋糕的**组织、香气、甜度和水分**：

- **做香蕉蛋糕/香蕉马芬**：最适合用**表皮有明显黑斑、八九成熟到过熟**的香蕉。此时淀粉转糖充分，甜度高、香气足，压泥后水分和结构也更适合蛋糕体。
- **表皮全黄、刚熟**：香气和甜度不足，蛋糕风味会偏淡，可能需要额外加糖或香精，不划算。
- **表皮发青、偏硬**：淀粉多、甜度低、香气弱，压泥后颗粒感重，蛋糕容易发干、风味不足。
- **过熟到发黑流汁、有酒味或霉点**：不要用于烘焙，风味和卫生风险都高。

采购建议：

1. **按用途定成熟度**：当天或次日要做，直接买带黑斑的熟蕉；需要存放几天，买黄中带少量黑斑的，回熟后再用。
2. **不要为低价买生蕉**：生蕉需要催熟时间，占用库存和损耗风险；如果低价但成熟度不够，实际使用成本可能更高。
3. **价格比较要换算到“可用果肉”**：过熟蕉出肉率低、损耗大；生蕉需额外催熟和等待。比较每公斤**可用蕉泥成本**，而不是只看采购单价。
4. **批量采购分批回熟**：一次不要全买同一成熟度，按2—3天用量分批，避免集中过熟报废。
5. **验收标准**：表皮黑斑均匀、果肉软但不流汁、无霉无酒味、剥皮后无明显黑腐。
