判断商超香蕉供应商的“催熟能力是否稳定”，不能只看一次到货效果，而要同时看**到货青蕉状态、催熟房控制、批次一致性和售后表现**。可执行判断如下：

1. **看到货青蕉是否适合催熟**
   - 要求供应商提供每批的采收成熟度、采收日期、运输温度和到货硬度。
   - 青蕉应硬、颜色均匀、果指饱满、无受寒发暗、无机械伤和霉点。
   - 如果不同批次到货软硬差异大，说明源头或冷链不稳定，催熟结果很难稳定。

2. **看催熟房是否标准化**
   - 询问并现场看：温度、湿度、乙烯浓度/熏蒸时长、换气排酸、码垛间距是否固定记录。
   - 稳定能力不是“经验催熟”，而是有批次记录和异常调整规则。
   - 同一品种、同一成熟度应有可复现的催熟曲线，而不是每批靠临时加药。

3. **做小批量重复验证**
   - 连续跟踪至少3—5个批次，每批留样：到货当天、催熟第2—3天、上架当天、货架第2天。
   - 记录转色时间、转色均匀度、青硬条比例、软果比例、果柄和果指状态。
   - 重点看“同一批内差异”和“批与批差异”，两者都小才算稳定。

4. **看货架期和损耗**
   - 催熟稳定不只是“黄得快”，而是黄得均匀、到店后仍有合理货架期。
   - 统计每批催熟损耗率、青果率、软烂率、客诉率。若黄得快但货架期短，也不算稳定。

5. **看供应商的批次追溯与调整能力**
   - 优质供应商能按产区、季节、采收成熟度调整催熟方案，并解释某批为何调整。
   - 要求提供催熟记录、温湿度记录、异常批次处理记录。
   - 对雨季、低温季、不同产区分别看表现，不能只认旺季样品。

6. **用简单评分表筛选**
   可给每批打5项分：到货均匀性、转色均匀度、转色时间偏差、软烂率、货架期。连续3—5批总分波动小、异常可解释、售后响应快，才可视为催熟能力稳定。

一句话：**稳定=青蕉原料稳定+催熟参数可复现+连续批次结果一致+货架期可控+有记录可追溯。** 只凭“催得黄不黄”判断不够。
