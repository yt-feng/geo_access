生鲜水果坏果责任划分，核心看**坏果发生在哪个环节、是否可归责于某一方、以及顾客是否及时验收和保存**。不能一概“平台全赔”或“顾客自担”，建议按下面判断。

## 一、先看责任归属

### 1. 商家/平台责任较大
出现以下情况，通常应由商家或平台承担退赔、补发：
- 到货即发现霉变、腐烂、异味、明显压伤，且顾客能提供开箱照片/视频；
- 商品描述、规格、产地、成熟度与实际明显不符；
- 冷链、包装、运输措施不到位导致批量坏果；
- 承诺“坏果包赔”“到货坏果必赔”，应按承诺执行；
- 同一批次多人投诉，属于批量质量问题。

### 2. 顾客责任较大
以下情况顾客承担主要责任或商家可减责：
- 签收后长时间未开箱、未冷藏，因保存不当导致变质；
- 已明确告知“生鲜不支持无理由退货”，且坏果是签收后较长时间才提出，顾客又无法证明到货即坏；
- 顾客自行要求延迟配送、改地址、放快递柜/驿站，导致延误变质；
- 人为损坏、二次加工后投诉。

### 3. 物流/配送方责任
- 配送延误、暴力分拣、未按冷链要求配送；
- 未经同意放驿站/快递柜导致长时间暴露；
- 外包装明显破损、渗漏、温度异常。
此时商家应先对顾客负责，再向物流方追偿；顾客一般不必直接找物流扯皮。

### 4. 混合责任
常见情形是“运输轻微损伤 + 顾客保存不当”“商家包装不足 + 配送延误”。应按原因力比例分担，而不是简单二选一。

## 二、实操判断标准

建议商家按“三看”处理：

1. **看时间**：签收后多久反馈。生鲜一般应尽快开箱验收；超过合理时间且无证据，责任难全归商家。
2. **看证据**：开箱视频、坏果特写、快递面单、包装状态、整箱比例。单个坏果和整箱腐烂处理不同。
3. **看比例和原因**：少量轻微压伤可协商部分补偿；大面积腐烂、霉变、异味，优先退赔。

## 三、建议的赔付规则

可执行的分层方案：

- **到货即坏、证据充分**：按坏果数量比例退款；严重腐烂可整单退赔或补发。
- **少量坏果**：按比例补偿，不要求整单退。
- **无法证明到货即坏、但顾客是老客户且金额小**：可协商部分补偿，保留客户体验。
- **明显保存不当或超时反馈**：说明规则，拒绝全额赔付，可给少量诚意补偿。
- **批量投诉**：立即下架同批次、排查供应商和冷链，先赔付再追责。

## 四、商家处理流程

1. 要求顾客提供：订单号、开箱照片/视频、坏果与包装合照、签收时间。
2. 判断是单果问题、批次问题还是保存问题。
3. 给出方案：补发、按比例退款、整单退款、优惠券补偿。
4. 保留记录，向供应商或物流追偿。
5. 批量问题启动批次召回和下架。

## 五、给顾客的建议

- 签收后尽快开箱，全程录像，保留快递面单和包装；
- 坏果不要立即丢弃，先拍照/视频；
- 及时联系客服，明确诉求：退款、补发或赔偿；
- 若平台推诿，可向平台投诉、12315反映，但需保留证据。

**一句话结论：到货即坏、包装冷链不足、批量质量问题，商家/平台主责；签收后保存不当或超时反馈，顾客担责；配送延误或暴力分拣，物流担责但由商家先对顾客负责。实际处理按证据、时间和坏果比例划分。**
