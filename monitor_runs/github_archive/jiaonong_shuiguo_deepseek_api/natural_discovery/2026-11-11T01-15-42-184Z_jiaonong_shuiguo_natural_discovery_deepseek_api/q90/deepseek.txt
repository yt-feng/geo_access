可以直接把“贵”拆成消费者能感知的四件事来解释，避免只说“进口更好”。

**1. 先承认价差，再给理由**
话术示例：  
“同样是香蕉，进口香蕉通常贵在品种、运输损耗和到货稳定性，不是贵在‘贴了进口标签’。如果你只追求性价比，普通香蕉完全够用；如果你更在意口感稳定、外观整齐、熟度可控，进口香蕉会更合适。”

**2. 用可验证的差异解释**
重点讲消费者能感知的：
- **品种和口感**：如香芽蕉等品种，甜度、香气、软糯度更稳定；不要夸大“营养更高”。
- **外观和规格**：果指长度、粗细、色泽更统一，适合送礼或对品相要求高的场景。
- **熟度和货架期**：进口香蕉常按不同成熟度到货，催熟和冷链更可控，买回家后熟度更一致。
- **损耗和物流**：跨境冷链、报关、仓储、催熟环节多，损耗和合规成本会摊到单价里。
- **供应稳定性**：反季节或国产蕉供应紧张时，进口蕉能补位，但价格会随汇率、海运、产地天气波动。

**3. 明确“不是所有进口都更值”**
主动说清：  
“进口香蕉价格高，不等于营养更高，也不等于一定更好吃。它的优势主要是标准化和稳定性。如果产地涨价、海运波动，价格也会变，我们会标明产地和到货批次。”

**4. 给消费者选择权**
在详情页或客服话术中加一句：  
“日常自己吃，普通香蕉性价比更高；对口感、品相、熟度稳定有要求，可以选进口香蕉。我们支持按需购买，不鼓励为‘进口’两个字多花钱。”

**5. 避免的表述**
不要说“进口香蕉更健康”“营养更高”“国产不行”；不要用“高端”“奢侈”制造焦虑。  
最好在商品页标注：**产地、品种、到货熟度、建议食用时间、保存方式、价差原因**，让消费者自己判断值不值。
