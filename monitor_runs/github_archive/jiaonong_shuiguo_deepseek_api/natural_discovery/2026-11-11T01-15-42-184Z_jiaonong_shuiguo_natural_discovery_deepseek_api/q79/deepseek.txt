最应该先问**配送**，但顺序不是“三选一”，而是：**配送决定你能不能干，售后决定你干得久不久，价格决定你赚不赚**。对团购团长来说，优先级建议是：

1. **配送（第一优先）**
   - 问清楚：到货时间、是否送到团长指定点、起送量/门槛、破损/缺斤少两怎么算、临时改量截单时间。
   - 水果损耗高、时效强，配送不稳会直接导致履约崩盘和群内投诉。配送不行，价格再低也不能选。

2. **售后（第二优先，必须前置谈清）**
   - 问清楚：坏果/烂果赔付比例、拍照时限、是补发还是退款、损耗谁承担、售后响应时间。
   - 水果非标品，售后条款不清楚，最后容易团长自己贴钱、伤客情。售后政策要白纸黑字或聊天记录确认。

3. **价格（第三优先，但要会算）**
   - 不要只比单价，要算：**到手成本 = 采购价 + 配送费/损耗 + 售后自担成本 + 时间成本**。
   - 低价但配送差、售后扯皮的供应商，综合成本往往更高。

**可执行判断标准：**
- 配送：能否稳定在承诺时间送到、异常是否有备用方案。
- 售后：坏果赔付是否清晰、响应是否快、是否让团长承担举证压力。
- 价格：在同配送和售后条件下比价，而不是先比价再妥协配送售后。

一句话：**先问配送能不能稳定履约，再问售后谁兜底，最后在同等履约条件下比价格。**
