水果采购合同里没有统一的法定“坏果率赔付线”，关键看合同约定和验收标准。实务上可这样定：

1. **合同应明确约定赔付触发线**
   - 常见做法：**坏果率超过3%—5%** 即启动赔付或扣款；
   - 叶菜、浆果等易腐品可放宽到**5%—8%**；
   - 苹果、柑橘、根茎类等耐储水果可收紧到**2%—3%**。
   这只是行业常见区间，不是法定标准，最终以双方合同为准。

2. **赔付方式要写清楚**
   建议约定：
   - 坏果率≤约定免赔率：不赔；
   - 超过免赔率：按“超出部分比例”扣款，或按坏果重量全额扣款；
   - 坏果率超过更高阈值（如10%—15%）：买方有权拒收、退货、解除当批订单并要求赔偿。

3. **验收和举证条款不能少**
   - 约定验收时限（如到货后24小时内）；
   - 约定抽检方法、抽样比例、拍照/视频留证；
   - 约定腐烂、压伤、冻伤、病虫害等是否都计入“坏果”；
   - 约定争议时由第三方检测或双方共同复检。

4. **没有约定时怎么办**
   只能依据《民法典》合同编主张质量问题，要求减价、换货、退货或赔偿，但举证和谈判成本较高。所以**最好在合同里直接写死坏果率阈值、扣款公式和拒收权**。

一句话：**不要问“超过多少必须赔”，而要在合同里写明“超过多少启动赔付、怎么赔、谁来认定”。** 常见触发线可参考3%—5%，易腐品可适当放宽。
