年度水果采购合同最容易踩坑的，通常不是价格本身，而是“价格怎么变、货怎么交、坏果算谁的、账怎么结”这几类条款。按风险从高到低说：

**1. 价格与调价机制**
- 只写“随行就市”或“参考市场价”最危险，年底必然扯皮。要约定基准价、调价触发条件（如批发市场均价波动超过±X%）、调价频率（如每月/每旬一次）、调价依据的第三方数据源，以及调价需双方书面确认。
- 警惕“供应商有权单方调价”或“超市有权要求按最低市场价供货”，后者供应商往往会在品质上找补。

**2. 质量标准与验收**
- 不能只写“符合国家标准”，水果要具体到品种、等级、糖度、单果重、色泽、农残检测要求。最好附质量标准附件并约定抽样比例和判定规则。
- 明确验收时限（如到货后几小时内验收）、验收地点（门店还是配送中心）、谁有验收权。逾期未验收是否视为合格，要写清楚。

**3. 损耗与退货责任**
- 水果损耗是最大争议点。要区分：到货时可见瑕疵、运输途中损耗、门店存储不当损耗、滞销损耗。各自责任方和承担比例必须写明。
- 退货条款要约定触发条件（如坏果率超过X%）、退货比例、退货运费谁承担、是否补货。避免“无条件退换”这种看似有利实则供应商会涨价或降质的条款。

**4. 交货与缺货罚则**
- 约定交货时间窗、最低供货量、缺货通知时限。罚则要对等：供应商缺货有违约金，超市临时取消订单或压车卸货也要有对应责任，否则供应商会把罚款成本计入报价。
- 注意“超市可无责取消订单”这类条款，实际执行中会推高供应商报价或导致旺季断供。

**5. 账期与结算**
- 明确账期起算日（收货日还是对账确认日）、对账周期、发票要求、逾期付款责任。常见坑是“验收后60天付款”但验收单迟迟不签，账期实际被拉长。
- 如果有返利、进场费、促销费，要写清计算基数（含税/不含税、按销售额还是进货额）和支付方式，避免年底被扣得不明不白。

**6. 独家与排他**
- 谨慎签“独家供应”。如果签，要约定最低采购量或保底销售额，否则供应商被锁死而超市可随时换人，供应商会用低质货对冲风险。反之超市也要防止供应商同时供竞品导致价格失控。

**7. 不可抗力与市场异常**
- 水果受天气、疫情、运输管制影响大。约定不可抗力通知义务和举证责任，并设置“价格异常波动”的协商机制（如连续X天涨幅超Y%可重新议价），避免一方硬扛或单方毁约。

**8. 终止与过渡**
- 约定提前终止的通知期、库存处理方式（超市是否必须收购在途和在库合格品）、质量保证金的退还条件。否则年底换供应商时，尾货和保证金容易变成纠纷。

**实操建议**：把质量标准、验收单格式、调价公式做成合同附件；价格条款尽量用“基准价+浮动规则”而非固定价；损耗责任按环节拆分而不是笼统写“由供应商承担”；所有罚则检查是否对等。签约前让采购和财务各过一遍账期与返利条款，让门店运营过一遍验收和退货可执行性。
