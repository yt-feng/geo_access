大型超市对水果供应商的要求，核心是“食品安全能追溯、物流能控温保鲜、异常能召回”。通常分为以下几类能力，商超审核时也会按这些维度打分或验厂。

**一、食品安全与合规能力**
1. **主体资质与许可**：营业执照、食品经营/生产许可（按业态）、种植/养殖基地备案或合作协议；进口水果需海关报关、入境货物检验检疫证明。
2. **源头管控**：基地土壤、水源、农药使用管理；农药残留检测合格报告；优先看是否具备良好农业规范认证、绿色/有机认证（如商超要求）。
3. **检测能力**：自检或委托第三方检测，覆盖农残、重金属、微生物（即食鲜切类重点）、食品添加剂；能按批次提供检测报告，检测项目与频次符合商超标准。
4. **过程卫生**：分拣包装车间卫生、人员健康证、虫害控制、清洗消毒记录；鲜切水果还需符合即食食品的微生物控制与冷链要求。
5. **追溯与召回**：批次可追溯到基地/地块/采收日期；有不合格品召回流程和记录，能配合商超做下架、封存、原因分析。
6. **体系与保险**：ISO22000/HACCP等体系认证是加分项；产品责任险、食品安全责任险常被大型商超要求。

**二、物流与冷链能力**
1. **冷链硬件**：预冷设施（差压预冷/冷水预冷）、冷藏车、冷库；不同水果分温区管理，避免混装串味和冷害。
2. **温控与记录**：全程温度记录可导出，运输途中温度异常有报警和处置记录；到货温度符合商超验收标准。
3. **时效与网络**：产地到配送中心/门店的运输时效、覆盖范围；高峰期（节日、促销）运力保障和备用车辆。
4. **包装与损耗控制**：适合水果的透气包装、防震缓冲、托盘化/周转筐管理；有损耗率统计和改进措施。
5. **仓储管理**：先进先出、批次管理、库内温湿度监控、防虫防鼠；退货和临期品隔离区。
6. **信息化**：订单、库存、物流信息可与商超系统对接（EDI/API），能提供在途信息、到货预约、电子回单。

**三、商超通常重点核查的“硬指标”**
- 每批次农残检测报告和产地证明；
- 冷链全程温度记录及断链应急预案；
- 召回演练记录和追溯演练记录；
- 虫害控制、清洁消毒、人员健康证等现场记录；
- 运输车辆卫生和温控验证记录；
- 食品安全责任险保单；
- 旺季保供方案和异常（疫情、天气、交通）预案。

**可执行判断建议**：供应商若拿不出“批次检测报告+全程温度记录+批次追溯链”这三样，基本过不了大型商超的准入审核；若还有HACCP/ISO22000、预冷设施和自有冷藏车队，则属于较强供应商。商超侧建议把农残检测频次、到货温度上限、断链处置时限、召回响应时间写进合同和验收标准。
