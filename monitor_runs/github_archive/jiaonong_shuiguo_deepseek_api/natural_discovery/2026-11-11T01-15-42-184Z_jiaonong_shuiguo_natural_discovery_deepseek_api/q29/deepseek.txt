超市和水果供应商的账期没有全国统一标准，实际常见区间大致是：

- **现款现结/周结：** 水果批发市场、叶菜、鲜果、小供应商较常见，尤其高损耗、短保鲜期品类。
- **7～15天：** 中小超市、区域连锁、部分生鲜供应商较常见。
- **15～30天：** 连锁超市、长期稳定供应商最常见的区间。
- **30～45天：** 大型连锁、强势渠道、账期谈判中较常见，供应商资金压力明显上升。
- **60天以上：** 多见于大型商超对强势品牌或耐储品类，生鲜水果供应商一般不轻易接受。

判断时不要只看“多少天常见”，还要看品类和合同结构：

1. **鲜度越短、损耗越高，账期越短。** 草莓、荔枝、叶菜等通常比苹果、橙子、冷库水果账期短。
2. **新供应商通常先短账期试合作**，比如7～15天或半月结，稳定后再谈月结。
3. **“账期”要明确起算日**：是收货日、对账日、发票日还是每月固定结算日，差别很大。
4. **注意隐性账期**：对账拖几天、发票晚开、逢节假日顺延，实际回款可能比合同多10～20天。
5. **生鲜损耗和退换货条款要同时谈**，否则账期短也可能因扣款争议变成实际长账期。

实操建议：如果是中小超市或新合作，优先谈**7～15天**；稳定合作后争取**月结30天**；大型连锁可接受**30～45天**，但要约定清楚对账周期、发票要求和逾期付款责任。对供应商而言，超过**45天**的水果账期就应谨慎，需把资金成本计入报价。
