能，但通常要主动谈，而且“支持力度”取决于三件事：你是哪个渠道/量级、促销品是不是供应商主推品、你能不能给到可核验的增量。水果供应商常见支持形式有：

1. **价格支持**
   - 周末特价供货、限时返利、满量返点；
   - 指定单品“促销价”，通常要求你承诺销量或陈列位置；
   - 尾货/临期品低价，但品质和损耗风险要自己控。

2. **物料支持**
   - 堆头/端架陈列物料、价格牌、海报、吊旗；
   - 品牌方或一级批发商有时能给试吃物料、包装袋、贴纸；
   - 生鲜供应商物料一般不如快消品牌多，别预期太高。

3. **其他支持**
   - 账期或少量赊销；
   - 滞销/品质问题的换货补损；
   - 帮你协调爆品货源、优先供货。

**怎么谈更有效：**
- 提前一周左右谈，别周五才开口；
- 明确写出周末促销单品、预计销量、陈列位置和活动价；
- 优先谈你采购量大的供应商和当季主推品；
- 用“增量”换支持：比如“这个周末我主推你家的XX，预计卖X箱，能不能给促销价/返利/物料”；
- 小水果店议价弱，可以联合附近同行拼量谈，或先要物料和小额返利，别一上来压价。

**注意：**
- 价格支持最好落到书面/微信记录，写清数量、价格、活动时间、退换货规则；
- 生鲜损耗大，低价支持不一定真划算，要算毛利和损耗；
- 供应商口头承诺的“卖不完退”要确认条件，避免扯皮。

结论：一般能给，但要主动谈、拿增量换，且小店的物料支持通常有限，价格返利比物料更现实。
