采购时优先选“青黄交接、硬实、无磕碰”的香蕉，避免买已经全黄、表皮有黑点或软塌的；到店后按成熟度分开，青一点的常温催熟，黄熟的冷藏或尽快加工，能明显延缓变黑。

可执行做法：

1. **采购标准**
   - 选**果身硬、棱角还略明显、两端青绿**的香蕉，适合放1–3天。
   - 避免：表皮大面积黑点、果柄发黑、磕碰伤、整串过软、有酒味。
   - 尽量买**整串/带果柄**的，少买散装断柄果，伤口会加速变黑。

2. **运输与到店处理**
   - 不要压、不要闷在密闭高温车厢；到店后先**拆袋通风**，避免乙烯积聚催熟。
   - 有磕碰、裂口的先挑出，优先做香蕉泥、奶昔、烘焙，不要留在整串里传染。

3. **存放方式**
   - **未熟/偏青香蕉**：常温、阴凉通风处，不要冷藏；可和苹果放一起催熟，但甜品店要控量。
   - **已黄熟香蕉**：尽快用；需要拖1–2天时，**果柄包保鲜膜后冷藏**，表皮会变黑但果肉可保持较好，使用前再剥皮判断。
   - **不要整串堆压**，可悬挂或单层摆放；避免阳光直射和靠近烤箱、热源。

4. **采购节奏**
   - 按“今天用、明天用、后天用”分三档采购：今天用选黄熟，明天用选黄中带青，后天用选偏青。
   - 少量多次比一次囤多更稳，尤其夏季。

5. **到店后快速降损**
   - 每天早晚挑一次，熟度高的先做**香蕉泥、夹馅、奶昔、磅蛋糕**等。
   - 已局部变黑的，切除黑变部分后尽快加热加工；有酒味、果肉发黏的不要用。

一句话：**买硬实青黄蕉、整串不磕碰、到店通风分成熟度、黄熟冷藏包果柄、按用量分批采购。**
