找每天配送的水果供应商，核心不是“找最便宜的”，而是先保证每天能稳定送到、损耗可控、账算得清。建议按下面条件逐项看。

1. 配送能力
- 是否承诺每天固定时段送达，节假日是否照常。
- 起送量、配送范围、配送费、临时加单截止时间。
- 缺货或迟到怎么补、怎么赔。
- 是否有冷藏车或保温箱，夏季叶菜、浆果类是否冷链。

2. 货源与品类稳定性
- 是否有稳定产地或一级批发渠道，不是临时倒货。
- 常卖品类能否长期稳定供应，断货时有无替代方案。
- 是否支持小批量多品种，适合社区超市少量高频。
- 是否可先看样品、试配送1—2周再定。

3. 品质与验收标准
- 明确验收标准：规格、成熟度、大小、色泽、瑕疵率、农残检测或承诺。
- 到货后多久内可提出质量问题，怎么退换补。
- 损耗率大概多少，坏果是否包赔，是否按箱扣重。
- 最好每次到货留照片、称重记录，避免扯皮。

4. 价格与结算
- 报价是否含税、含运费、含包装。
- 价格随行就市时，提前一天报价还是当天报价，涨跌规则要写清。
- 账期、结算方式、对账周期；押金或保证金是否合理。
- 不要只看单价，要算“到店可售成本”：单价+运费+损耗+退换成本。

5. 资质与风险
- 营业执照、食品经营相关资质、产地或检测证明。
- 是否给正规票据，能否签简单供货协议。
- 供应商是否只靠一个货源，抗风险能力如何。
- 是否有其他社区超市、便利店客户，可侧面了解履约情况。

6. 试合作判断
建议先小批量试2周，重点记录：准时率、缺货率、坏果率、退换响应速度、实际可售毛利。连续稳定后再扩大采购，不要一上来签长期大单或压太多库存。

简单判断标准：每天能按时到、坏果有人认、缺货有替代、账目对得清，这四条比“价格最低”更重要。
