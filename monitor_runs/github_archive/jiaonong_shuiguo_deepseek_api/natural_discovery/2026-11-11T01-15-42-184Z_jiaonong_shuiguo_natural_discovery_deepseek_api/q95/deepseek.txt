选这类高频、低单价、易损耗水果的供应商，关键不是找“最大最便宜”的，而是找**能稳定按你的验收标准供货、损耗可控、票据合规**的。可以按下面步骤做。

**1. 先定采购和验收规则，再谈供应商**
不要先让供应商报价。食堂先明确：
- 品种和等级：如香蕉要几分熟、单根重量范围；苹果要果径范围、无严重碰伤；橙子要甜度/酸度可接受、无干水。
- 包装规格：箱装净重、是否允许±误差、是否含包装重量。
- 验收标准：腐烂、压伤、开裂、冻伤、异味、成熟度不达标的比例上限。
- 退换规则：到货不合格多少比例可整批退，多少比例可换货，多久内响应。
- 结算方式：账期、发票类型、对账周期、价格调整机制。
- 食品安全材料：营业执照、食品经营许可或相关资质、送货人员健康证、批次检测或承诺达标合格证等，按当地监管要求收集。

**2. 供应商来源优先顺序**
建议同时找 3 类，形成比价和备份：
- 本地一级批发商或水果集散市场大户：价格和品类有优势，但要多抽检、盯等级。
- 产地合作社/基地直供：适合苹果、橙子等耐储品，香蕉不一定适合；要看其是否有稳定分拣和配送能力。
- 合规的食材配送公司：价格通常略高，但票据、配送、售后更规范，适合作为主供或备份。

不要只找一家。香蕉损耗快，最好有本地备份供应商，避免断供。

**3. 用“小批量试供+盲检”筛选**
让候选供应商按同一规格送 2—3 次小批量，每次到货做记录：
- 实际净重与标称是否一致；
- 坏果率、压伤率、成熟度合格率；
- 到货时间是否稳定；
- 换货响应速度；
- 票证是否齐全。
连续 2—3 次稳定的，再进入正式比价。只比单价容易被“毛重当净重、等级虚高、坏果不退”吃掉差价。

**4. 报价要比“可食用净成本”**
不要只看每斤价格。按同一验收标准折算：
可食用净成本 ≈（采购总价 + 退换货运费/损耗）÷ 实际可食用净重。
同时看账期和发票。能开合规发票、账期合理的供应商，即使单价略高，综合成本可能更低。

**5. 合同里写清楚几个关键条款**
- 价格随行就市，但要有报价周期和调价提前通知；不能当天随意涨。
- 质量标准、抽检比例、拒收和换货时限。
- 缺货预案：主供断货时，多久内补位，是否承担替代采购差价。
- 食品安全责任和票据留存。
- 月度考核：连续几次验收不合格，降为备选或退出。

**6. 日常管理做简单台账**
每次到货记录供应商、批次、净重、坏果率、退换情况。每月按“合格率、准时率、售后响应、价格稳定性”打分。香蕉这类易损耗品要单独看损耗，不要和苹果、橙子混在一起评价。

**实操建议：**
先由食堂定 1 页验收标准，再邀请 3—5 家送样试供；主供选配送稳定、售后快的，备供选本地批发大户；苹果、橙子可适当引入产地直供比价，香蕉优先本地短链供应。这样比单纯招标最低价更稳。
