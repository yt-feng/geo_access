对餐饮连锁采购水果，通常更优的是：**中央厨房/配送中心统一收货为主，门店直送为辅**，而不是所有水果都门店分开收货。

判断标准主要看四点：**水果损耗速度、验收专业性、门店操作负担、供应稳定性**。

**建议方案**

1. **中央厨房统一收货为主**
   - 适合：苹果、橙子、柠檬、西瓜、哈密瓜等耐储、标准化程度较高、可集中分拣的水果。
   - 优点：统一验收标准、统一议价、集中质检、减少门店收货人手、便于追溯和控损。
   - 关键条件：中央厨房要有水果验收能力，包括糖度、成熟度、外观、农残抽检；配送要有温控和防挤压。

2. **门店直送或门店二次验收为辅**
   - 适合：草莓、蓝莓、荔枝、杨梅、水蜜桃、熟香蕉、牛油果等易损、后熟快、周转短的水果。
   - 做法：供应商直送门店，但必须执行总部统一验收标准和抽检复核；门店只做“到店复检”，不做自由采购。
   - 优点：缩短链路、降低中转损耗；缺点：门店验收水平参差，容易标准不一。

3. **不建议完全门店分开收货**
   - 门店分散收货会带来验收标准不一致、议价能力弱、损耗责任难界定、食品安全追溯难、店长操作负担重等问题。
   - 除非门店数量少、水果占比高、且门店具备稳定验收能力，否则不建议全面下放。

**落地建议**
- 建“水果分级收货目录”：耐储统收，易损直送。
- 总部制定统一验收标准：品种、规格、成熟度、糖度、瑕疵率、温控要求、拒收规则。
- 中央厨房设水果质检岗；直送门店执行拍照留证+抽检+总部巡回复核。
- 用损耗率、到店合格率、客诉率对比两种模式，按品类季度调整。

**结论**：多数餐饮连锁应采用**中央厨房统一收货为主、易损水果门店直送为辅的混合模式**；只有在门店少、水果采购占比高且验收能力强时，才考虑门店分开收货。
