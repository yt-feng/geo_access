这四项要看“你卖货的节奏”，但对小水果店，优先级通常是：

**坏果率 ≥ 熟度 > 送货速度 > 价格**

更具体地判断：

1. **坏果率第一**
   - 香蕉是高损耗品，坏果多、催熟伤、压伤多，价格再低也可能亏。
   - 看整箱底层、箱角、果柄和果指中段有没有黑斑、软烂、霉点。
   - 小水果店客单低，坏果只能扔或降价处理，实际成本很高。

2. **熟度第二，但要按你的出货速度选**
   - 卖得快：可以进略生一点，7成熟左右，耐放。
   - 卖得慢：不要进太青也不要进太黄，选转色均匀、能撑2—3天的。
   - 如果供应商能稳定给“按天分批次”的熟度，比单纯便宜更重要。
   - 香蕉最怕一批全熟，当天卖不完第二天就变损耗。

3. **送货速度第三**
   - 香蕉周转快，送货慢会增加压伤和熟度失控。
   - 尤其夏天，送货慢、车厢闷热，到店就可能提前转黄。
   - 但速度不是越快到越好，关键是**稳定、按约定时间到、冷链或通风条件别太差**。

4. **价格排最后，但不是不看**
   - 价格要在“坏果率可控、熟度合适、送货稳定”的前提下比。
   - 低价但坏果率高、熟度不可控，等于把利润转成损耗。
   - 建议算“到店可售成本”：进价 + 损耗 + 挑拣人工 + 降价处理损失，而不是只看每箱进价。

**给小店的实操建议：**
- 固定2—3家供应商轮换，别只压一家价。
- 每次到货当场抽检：箱底、果柄、软果比例，坏果超过约定比例就拍照留证、扣重或退换。
- 按销量进货：先小批量试熟度，稳定后再放量。
- 夏天宁可少量多次进，别一次压太多货。

一句话：**先保坏果率和熟度可控，再要求送货稳定，最后谈价格。**
