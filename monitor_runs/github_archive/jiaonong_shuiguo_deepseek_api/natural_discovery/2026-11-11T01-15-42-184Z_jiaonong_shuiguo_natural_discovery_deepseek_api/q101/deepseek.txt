和水果供应商谈酒店早餐合作，重点不是“把价格谈低”，而是把**稳定供应、品质一致、损耗可控、责任清晰**写进合作条件。可以从下面几方面准备和谈。

**1. 先明确自己的需求**
- 早餐水果品类：常备品类和轮换品类分开，如苹果、香蕉、橙子、西瓜、哈密瓜、圣女果等。
- 每日用量和波动：按淡旺季、入住率给区间，不要只给一个平均数。
- 规格要求：单果大小、成熟度、甜度、外观、是否预切、是否去皮。
- 送货时间：早餐开餐前到位，留出验收和备餐时间。
- 包装和退换：周转筐、预包装、坏果怎么退换。

**2. 重点谈供应稳定性**
- 要求供应商说明产地、季节替代方案、缺货时的替代品类和提前通知时间。
- 约定最低供货保障和紧急补货响应时间，比如几小时内补货。
- 不要只依赖一家供应商，可设主供应商+备用供应商，避免单一来源断供。
- 明确节假日、极端天气、物流中断时的应对方案。

**3. 把品质标准写清楚**
- 用“可验收”的标准描述，如大小等级、成熟度、无腐烂、无严重磕碰、农残检测要求。
- 约定验收抽检比例和不合格处理方式：拒收、换货、扣款或终止合作。
- 对预切水果要特别约定加工环境、包装、保质期和冷链温度。
- 早餐水果如果切开供应，要明确切配责任是在酒店还是供应商，避免责任模糊。

**4. 价格和结算方式**
- 不要只比单价，要比较含税、含运费、含包装、含损耗后的综合成本。
- 价格调整机制要写清：按周/按月调价，参考什么市场行情，涨跌幅上限。
- 结算周期、发票类型、对账方式提前谈好，避免财务流程影响供货。
- 损耗责任要明确：验收前坏果谁承担，验收后储存不当谁承担。

**5. 食品安全和资质**
- 要求供应商提供营业执照、食品经营许可、产品检测报告或合格证明。
- 了解其冷链能力、仓储卫生、运输车辆和人员健康管理。
- 合同中加入食品安全责任条款，出现问题时能追溯、能索赔。
- 酒店内部也要做好验收记录、留样和储存温度记录。

**6. 合同里建议写明的关键条款**
- 品类、规格、数量区间、送货时间和地点。
- 质量标准、验收流程、不合格处理。
- 价格及调价机制、结算周期。
- 缺货、迟送、质量问题的违约责任。
- 食品安全事故的责任和赔偿。
- 合同期限、试合作期、退出机制。
- 保密和廉洁条款，避免采购人员私下利益输送。

**7. 实操建议**
- 先做2—4周试合作，按真实早餐场景验收，不只看样品。
- 建立每日验收表：品类、数量、外观、成熟度、温度、不合格处理。
- 定期复盘损耗率和客人反馈，用数据谈下一轮价格和服务。
- 对供应商保持至少两家备选，但主供应商给稳定量，换取更好响应。

一句话总结：**谈合作时把“每天能不能按时送到、品质是否稳定、坏了谁负责、缺货怎么办”这四件事写进合同，比单纯压价更重要。**
