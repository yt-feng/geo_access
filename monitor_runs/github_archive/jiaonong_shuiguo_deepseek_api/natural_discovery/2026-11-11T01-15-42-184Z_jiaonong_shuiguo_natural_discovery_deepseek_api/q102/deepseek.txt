需要，而且这两项应在采购前写成明确准入条件。

1. **开发票：必须支持**
   - 企业采购水果礼盒通常需要报销、入账和税前扣除，供应商应能开具合规发票。
   - 优先要求开具**增值税发票**，并确认发票类型、税率、开票项目（如“水果礼盒”“农产品”“食品”等）与企业财务要求一致。
   - 合同里写明：开票时间、发票类型、抬头/税号、票货一致、拒开或错开的处理责任。

2. **定制包装：建议支持，是否“必须”看用途**
   - 如果是员工福利、节日慰问、客户礼品，定制包装通常有价值：印企业Logo、祝福语、福利卡、统一视觉。
   - 若只是内部普发、预算有限，标准包装也可接受，但应要求包装牢固、食品级、适合冷链/运输。
   - 定制包装要提前确认：起订量、打样费、设计稿确认周期、加价、交期、版权责任、包装食品安全合规。

**可执行建议：**
在询价/招标文件中直接列明：
- 必须能开具合规增值税发票；
- 定制包装是否强制、最低起订量、打样和交期；
- 发票与包装费用是否含在报价内；
- 验收标准包括包装完好、标识合规、票货一致。

如果供应商不能开票，建议直接排除；不能定制包装的，可作为备选，但要在评分或比价中体现差异。
