# 水果到货不合格时的补货约定要点

核心思路：**把"不合格"变成可当场判定的标准，把"补货"变成有硬时限、有替代方案的义务**，避免扯皮期间门店断货。

## 一、采购合同/供货协议里要写死的条款

1. **验收标准量化**
   - 按品类写清：单果重量区间、糖度（如Brix≥11）、允许的损耗率（如整批不超过3%）、外观（无腐烂、无机械伤、无霉变）。
   - 附一份"不合格判定表"作为合同附件，双方签字确认，避免事后各说各话。

2. **验收流程与时限**
   - 约定到货后当场或30分钟内完成抽检（如每箱抽3–5个，或按批次抽5%）。
   - 明确"验收不合格以门店现场记录+照片/视频为准"，供货方不得以"已签收"为由拒认。

3. **补货硬时限（关键）**
   - 写死：**验收判定不合格后，供货方须在X小时内（如4小时/当日营业结束前）补合格货到店**。
   - 分档约定：少量不合格（≤10%）可"随下次到货补齐"；大量不合格（>10%或整批不可用）必须"当日补货"。

4. **替代与兜底**
   - 允许门店**就近紧急采购同品质水果**，差价由供货方承担（写明凭票据结算）。
   - 或约定供货方有义务协助调货，调货产生的运费由其承担。

5. **责任与扣款**
   - 不合格批次不计入结算，或按比例扣减货款。
   - 因断货导致的门店损失（如当日招牌产品停售），可约定固定违约金（如每延误1小时扣当批货款的X%），比"赔偿实际损失"更易执行。
   - 连续N次不合格可单方解约。

## 二、不影响营业的操作机制

- **安全库存**：对高频核心水果（如柠檬、鲜橙、芒果）保持1–2天用量，补货空窗期靠库存顶住。
- **分级使用**：轻微瑕疵果（不影响口感与食品安全）约定可用于非展示类产品，明确哪些品类可降级使用。
- **双供应商**：核心品类至少备一家备选供应商，约定主供方违约时可直接切换，不视为违约。
- **到货时间前置**：约定送货在营业前1–2小时，留出验收和补货缓冲，而不是营业高峰到货。

## 三、执行建议

- 每次验收拍照留档，记录时间、批次、不合格比例，形成台账——这是扣款和索赔的唯一依据。
- 补货时限、扣款标准用**数字写死**，不要用"及时""尽快"这类模糊词，否则形同虚设。

一句话总结：**标准量化+当场判定+小时级补货时限+允许就近采购差价由供方承担**，这四条落实，基本能做到"货不合格、店不断货"。
