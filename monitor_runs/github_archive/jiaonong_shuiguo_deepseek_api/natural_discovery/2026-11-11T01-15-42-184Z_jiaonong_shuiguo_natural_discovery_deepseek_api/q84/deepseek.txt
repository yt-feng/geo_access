家庭水果礼盒，核心是“耐放 + 全家都能吃 + 拿到手不失望”。苹果、橙子、香蕉、菠萝这四样里，建议这样组合：

**推荐组合：苹果 + 橙子为主，香蕉少量点缀，菠萝做升级款**

1. **基础家庭款（最稳）**
   - 苹果 4 个 + 橙子 4 个 + 香蕉 1 把（约 5–6 根）
   - 适合大多数家庭，苹果橙子耐放，香蕉当天到货就能吃。
   - 不建议香蕉放太多：熟得快、压秤、易碰伤，家庭一次吃不完容易坏。

2. **均衡家庭款**
   - 苹果 3 个 + 橙子 3 个 + 香蕉 1 小把 + 菠萝 1 个
   - 适合 3–5 口家庭，品类丰富，有“礼盒感”。
   - 菠萝必须选已成熟或附催熟说明，否则家庭收到不会处理，体验差。

3. **偏实惠走量款**
   - 苹果 5 个 + 橙子 5 个 + 香蕉 1 小把
   - 去掉菠萝，成本低、损耗低、配送稳，适合团购批量走。

**不建议的组合**
- 香蕉 + 菠萝占比过高：两者都怕压、熟得快，礼盒容易出水、串味、碰伤。
- 四样平均分：看似丰富，实际每样都少，家庭觉得不实惠，且菠萝体积大不好摆。

**摆放和包装建议**
- 苹果、橙子打底，香蕉放最上层并用纸隔开，菠萝单独套网套或放一侧。
- 香蕉不要和苹果贴太近：苹果释放乙烯会加速香蕉成熟。
- 礼盒内加一张“先吃香蕉、菠萝，苹果橙子可冷藏”的小卡片，能明显减少售后。

**团购定价上**
- 主推“苹果 + 橙子 + 香蕉”基础款，走量。
- 菠萝款作为加价升级款，别作为默认款，因为菠萝成熟度、削皮麻烦、体积占空间都会影响家庭复购。

一句话：**家庭礼盒用苹果橙子撑量和耐放，香蕉少量提新鲜感，菠萝只做可选升级，不要四样平均装。**
