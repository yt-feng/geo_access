重要，而且对多门店超市来说，供应商的水果分级标准不是“参考项”，而是统一品质的基础设施。原因和建议如下：

**1. 分级标准是统一品质的“共同语言”**
多门店最大的问题是各店验收人员凭感觉判断，同一批货在不同门店可能被判定为不同等级。供应商若有明确、可执行的分级标准（如按果径、糖度、着色度、瑕疵率、成熟度分档），采购和门店验收才有统一依据，才能做到“同价同质”。

**2. 直接影响损耗和毛利**
水果是非标品，分级不清会导致：好货里混次货，门店拒收或折价；次货混进好货，顾客体验下降、复购受损；各店实际拿到手的品质不一致，定价和促销难以统一。分级标准越清晰，验收争议越少，损耗越可控。

**3. 便于跨门店对标和考核**
有了统一分级，才能统计各门店的收货合格率、损耗率、客诉率，并判断问题出在供应商、物流还是门店存储。否则数据不可比，管理动作也无法精准。

**4. 分级标准要“可验收”，不能只写在合同里**
建议要求供应商提供可量化的分级描述，最好附带样品对照或照片标准，并在合同中约定验收规则：抽检比例、不合格判定、扣款或退货机制。仅写“一级果”“精品果”这类模糊词，实际执行中很容易扯皮。

**5. 注意分级标准与门店定位匹配**
不同门店客群不同，未必要全店统一一个等级，但同一等级的标准必须统一。可以按门店业态设“标准版”和“高配版”采购规格，但每个规格对应的分级参数要一致。

**可执行建议：**
- 与核心供应商共同确定3—5个关键量化指标（果径、糖度、着色、瑕疵率、成熟度）；
- 制作图文验收标准卡，发到每个门店；
- 到货抽检按标准打分，低于阈值拒收或降级结算；
- 每月汇总各店验收数据，反向评估供应商分级稳定性。

结论：供应商分级标准非常关键，但关键不在“有没有标准”，而在“标准是否量化、可验收、能执行到每个门店”。
