会影响，但影响大小取决于你卖的方式和客群。直接给判断和建议：

**会影响的场景**
1. **按箱/按斤统货卖**：大小差异大，顾客挑大果、剩小果，损耗和差评会增加。
2. **礼盒/团购/精品陈列**：大小不一会显得不整齐，压价、退货概率高。
3. **同价混卖**：顾客会觉得“花同样的钱买到小的亏”，容易翻拣造成机械伤。

**影响不大的场景**
1. **散客按斤自选**：香蕉本身有大小分级习惯，顾客接受度较高。
2. **用于促销/特价区**：明确标注“大小果混装、特价”，顾客预期被管理好。
3. **餐饮、果汁、烘焙等B端供货**：更看成熟度和出成率，大小敏感度低。

**采购和销售建议**
- **先定销售方式再定采购标准**：做精品陈列就要求相对均匀；做特价走量可以接受混装，但采购价要压下来。
- **分級卖，不要硬混**：到店后按大、中、小分开放，大果正常价，小果做特价或搭配促销，减少挑拣损耗。
- **控制“极差”**：同一箱里最大和最小差距别太夸张。差距过大时，即便均价便宜，实际损耗和人工分拣成本也会吃掉利润。
- **看成熟度一致性**：香蕉销售更关键的是成熟度均匀。大小略有不一但成熟度一致，比大小均匀但生熟混杂更好卖。
- **算损耗账**：如果混装导致顾客翻拣严重、蕉指擦伤，损耗率上升，采购便宜的那点差价可能不划算。

**结论**：大小不一不是绝对不能采，但会明显影响精品销售和同价混卖。建议采购时要求供应商说明分级情况，到店后分级销售；做精品或礼盒则尽量选均匀货。
