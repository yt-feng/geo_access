水果店旺季谈供应商，核心是把“断货风险”提前变成可执行条款。建议按下面几组问题问，并要求对方给出明确答复或写进合作约定。

**1. 供应能力与旺季保障**
- 旺季你每天/每周最多能稳定给我供多少货？按品类分别说。
- 你现在的上游货源是产地直采、批发市场还是二级批发？旺季会不会被上游截断？
- 我这类店你目前供了几家？旺季会不会优先保大客户、把我排后面？
- 如果出现极端天气、产地减产、物流中断，你的备用货源在哪里？
- 旺季缺货时，提前多久通知我？有没有替代品类或替代产地推荐？

**2. 价格与调价机制**
- 旺季价格怎么定？是锁价、随行就市还是按周报价？
- 调价提前几天通知？能不能给我一个价格上限或涨幅范围？
- 同一品类不同等级怎么分？我拿的是哪一级，验收标准是什么？
- 量大能不能阶梯价？旺季保量前提下价格能不能稳定？
- 运费、装卸费、损耗谁承担？有没有隐藏费用？

**3. 订货与配送**
- 每天几点前下单？多久能送到？旺季配送时效会不会变？
- 起订量多少？能不能小批量多频次补货，降低压货风险？
- 配送车辆和保鲜条件怎么样？叶菜、浆果、热带水果怎么分区运输？
- 临时加单接不接？加单截止时间和响应时间是多少？
- 送货晚到或漏送怎么处理？有没有补偿或应急补货方案？

**4. 质量与损耗**
- 到货验收标准是什么？坏果率、成熟度、大小规格怎么判定？
- 到货不合格怎么退换？退换响应时间多久？
- 运输损耗和门店自然损耗怎么分？损耗率超过多少由你补？
- 能不能先少量试供，再逐步放量？
- 有没有质检或产地证明？农残检测报告能不能随批次提供？

**5. 结算与风险条款**
- 结算是现结、周结还是月结？旺季资金紧张能不能给账期？
- 缺货、迟送、质量不达标有没有违约责任？怎么赔？
- 合作期限怎么定？旺季保供条款能不能单独写进合同？
- 如果我临时换供应商或减少采购量，有没有约束？
- 出现价格争议、质量争议时，按什么流程处理？

**6. 现场要确认的实操问题**
- 让对方带最近一周的供货单和报价单，看真实供货节奏。
- 问清楚“最忙的时候你几点能到店”，最好约定具体时段。
- 要求提供2—3个同类水果店客户作为参考，侧面了解旺季保供情况。
- 先小批量试供一周，记录到货时间、损耗率、缺货次数，再决定是否放量。

谈的时候建议把最关键的三件事写清楚：**旺季每日保供量、缺货提前通知时间、质量不达标退换和赔偿**。口头承诺容易落空，落到订单或合同里才有约束力。
