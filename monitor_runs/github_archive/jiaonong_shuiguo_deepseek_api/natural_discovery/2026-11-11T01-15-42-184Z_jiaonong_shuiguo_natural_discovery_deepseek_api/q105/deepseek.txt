水果锁价没有统一“标准期限”，能锁多久主要取决于品种、季节、供应商类型和定价方式。一般可参考：

- **鲜果短周期锁价：1～2周**最常见，适合叶菜类水果、浆果、桃李等易腐且行情波动大的品类。
- **常规水果月度锁价：15～30天**较常见，适合苹果、梨、橙、香蕉等供应相对稳定的品类；通常只锁“基础价+浮动规则”。
- **大宗/产地直采锁价：1～3个月**可行，但供应商一般会要求预付款、最低采购量或价格调整条款。
- **反季节或进口水果：很难真正锁价**，多数只能锁7～15天，或采用“锁量不锁价、随行就市+封顶价”。
- **全年锁价基本不现实**，除非你接受较高溢价或供应商有强套保能力。

实操上建议这样谈：

1. **锁价不锁量、锁量不锁价要分清**：明确是固定单价，还是基准价+市场涨跌幅联动。
2. **设置价格调整触发条件**：如产地批发价涨跌超过5%～10%、极端天气、运费大幅变化时可重谈。
3. **锁价期限分档**：核心稳定品锁30天，波动品锁7～15天，新品先短锁试单。
4. **用预付款/订单量换锁价**：供应商通常只对确定采购量给锁价。
5. **合同写清品质标准、损耗、运费、违约和调价机制**，否则锁价容易变成“锁了价但降了品质”。
