判断水果供应商靠不靠谱，别只看“报价低不低”，重点看稳定性、履约和售后。你可以按下面这套标准逐项打分，能较快筛掉不靠谱的。

## 1. 先看供货稳定性
香蕉和菠萝都属于后熟、易损品类，稳定性比单价更重要。

- **问产地和季节转换方案**：香蕉主要看广西、云南、海南及进口来源；菠萝看广东徐闻、海南、广西等。靠谱供应商能说清楚“这周从哪来、下个月换哪”，而不是含糊说“都有”。
- **问日供应量和补货时效**：你要多少箱/件，他能否稳定每天或隔天送？临时加量多久能到？
- **看是否只做转手**：如果他自己没有分级、催熟或仓储能力，旺季容易断供或质量波动大。香蕉尤其看催熟能力，菠萝看分级和成熟度控制。

## 2. 验货标准要提前谈死
长期进货最容易扯皮的是“什么算合格”。合作前把标准写进报价单或简单协议：

- **香蕉**：按梳/把整齐度、青熟度（几成熟）、条径、长度、机械伤、黑斑、掉把率约定。比如“到店青熟度7成，黑斑面积不超过X%，掉把率低于X%”。
- **菠萝**：按单果重量区间、果形、冠芽完整度、黑心病/水心病比例、成熟度约定。比如“单果1.2—1.5斤占比≥90%，黑心切开率≤X%”。
- **验收方式**：到店抽检几箱，不合格怎么退换、多久补货、损耗谁承担，提前说清。

## 3. 看价格和账期是否“太反常”
- **报价明显低于市场价**：大概率会在等级、成熟度、重量或后期补货上找回来。长期合作要对比“同等级同规格”的到店价，不是只看箱价。
- **是否含运费、装卸、损耗**：问清到店价是否包送、包卸、包退换。
- **账期**：新供应商建议先现金或短账期小批量试，稳定后再谈账期。不要一上来压大账期，容易拿到尾货或被迫接受质量波动。

## 4. 实地或视频看三个地方
- **仓库/档口**：看分拣是否规范、有没有催熟房或冷库、坏果是否及时清理。
- **在途和到店损耗**：连续试3—5次，记录每次到店损耗率、合格率、补货响应。
- **售后态度**：故意提一次合理退换，看他是否爽快、是否要求你承担不合理损耗。售后推诿的，长期一定出问题。

## 5. 小批量试合作，用数据决定
建议先试2—4周，每周2—3次，记录：

| 指标 | 看什么 |
|---|---|
| 到店合格率 | 香蕉掉把/黑斑，菠萝黑心/烂果 |
| 重量/规格偏差 | 是否缺斤少两、等级混装 |
| 补货时效 | 临时加货几小时到 |
| 退换响应 | 是否当天处理 |
| 价格波动 | 是否随行就市但提前告知 |

试合作期不要只找一家，至少备2家：一家主供、一家备用。香蕉和菠萝可以分开找，因为催熟和产地优势不同。

## 6. 几个危险信号
- 只说“便宜、什么都有”，说不清产地和等级；
- 不愿意小批量试，催你大量压货；
- 验收标准含糊，出了问题说“水果都这样”；
- 报价随行就市但从不提前通知，到货才涨价；
- 退换货推给司机或让你自己承担损耗。

**最实用的做法**：先让2—3家供应商按你的验收标准各送一次小批量，同一天到货对比，记录合格率、损耗、补货速度和售后。连续3次稳定达标的，再谈长期价和账期。这样比听任何承诺都靠谱。
