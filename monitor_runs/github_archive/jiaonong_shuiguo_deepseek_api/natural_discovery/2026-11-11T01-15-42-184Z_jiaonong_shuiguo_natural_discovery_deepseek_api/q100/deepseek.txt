采购香蕉想避免熟过头，关键不是“买更绿的香蕉”这么简单，而是把**采购量、成熟度、到货节奏、存放条件和消耗顺序**一起管住。可执行做法如下：

1. **按实际消耗量下单，不按“整箱便宜”囤货**
   - 统计近2周香蕉日均用量，按“日均用量×到货周期×0.8~0.9”下单，留出损耗缓冲。
   - 食堂水果通常有集中消费时段，按餐次拆分：早餐、午餐、加餐分别估算。
   - 如果供应商只能整箱起订，宁可增加配送频次，也不要一次压太多。

2. **采购时明确成熟度，不要只写“香蕉”**
   - 要求到货为**7~8成熟**：果皮整体偏绿、棱角明显、无大面积黑斑，手感硬实。
   - 合同或订单备注：到货当天可少量黄熟用于次日消耗，其余应能存放3~5天。
   - 验收时抽检：青绿比例、黑斑比例、软烂果比例。熟透、发黑、开裂的拒收或折价。

3. **少量多次配送，拆开成熟批次**
   - 把一周采购拆成2~3次配送，每次到货成熟度错开。
   - 要求供应商分批采摘/分批装筐，避免一箱里“上面熟、下面生”或整批同时转黄。
   - 到货后立即分拣：青果、微黄果、即食果分开存放，按成熟度贴标签。

4. **存放要避热、避压、避密封**
   - 香蕉不宜低温冷藏，室温阴凉通风处存放即可；夏天避免靠近灶台、暖气、阳光直射。
   - 不要整箱密封闷放，可开箱透气；悬挂或单层摆放，减少压伤。
   - **不要和苹果、梨、西红柿等释放乙烯的果蔬混放**，会加速成熟。
   - 已转黄的香蕉可移到更凉通风处，尽快进入当日消耗。

5. **建立“先熟先出”的消耗顺序**
   - 每天检查一次，把最黄的香蕉贴“优先使用”标签，放在取餐动线最前面。
   - 食堂窗口可作餐后水果优先消耗熟果；青果留后两天。
   - 对轻微黑斑但未软烂的香蕉，可优先用于制作香蕉粥、香蕉奶昔、烘焙等，但要有明确加工流程和食品安全控制。

6. **设置预警和止损线**
   - 定义分级：青绿可存、微黄2天内用、黄熟当天用、软烂报废。
   - 每天记录库存和成熟度，出现“黄熟果超过次日预计用量”时，立即调整菜单或减少后续配送。
   - 与供应商约定退换货条款：到货成熟度过高、短期集中转黄的，可换货或补货。

7. **用菜单和加工消化临界香蕉**
   - 在香蕉转黄高峰期安排香蕉相关菜品或加餐，如香蕉燕麦、香蕉牛奶、香蕉面包等。
   - 但加工只能作为辅助，不能替代采购控制；软烂、异味、霉变的香蕉不得加工使用。

最有效的组合是：**小批量、多频次、7~8成熟到货、按成熟度分区、先熟先出、每日预警**。如果只能记住一条：不要一次买够一周的量，把配送频次提上去，比单纯买青香蕉更可靠。
