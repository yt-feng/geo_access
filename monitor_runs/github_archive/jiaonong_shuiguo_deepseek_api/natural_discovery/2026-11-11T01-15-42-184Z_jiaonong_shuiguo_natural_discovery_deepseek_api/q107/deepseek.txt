会，而且香蕉和菠萝的损耗风险对起订量尤其敏感。结论是：**起订量越高，损耗风险通常越大；但风险大小取决于品类成熟度、仓储条件和周转速度，香蕉比菠萝更敏感。**

**判断要点：**

1. **香蕉：高起订量风险最大**
   - 香蕉是呼吸跃变型水果，到货后仍会后熟，催熟、温度、乙烯浓度稍控制不好就集中变黄变黑。
   - 起订量高意味着单批到货多、上架窗口短，若日均销量跟不上，很容易在2—5天内出现批量软腐、黑斑。
   - 建议：起订量尽量按“预计3—5天销量”倒推，不要只看单箱便宜；到货后分批催熟、先进先出，库温稳定在13—15℃左右并避免与乙烯敏感品混放。

2. **菠萝：风险中等，但高起订量会放大仓储和成熟度问题**
   - 菠萝相对耐储，但高起订量会带来堆压、通风不良和过熟批次积压；夏季尤其容易底部腐烂、黑心病。
   - 若采购的是已催熟/黄熟果，周转窗口更短；青果虽耐放，但后熟不均会影响销售。
   - 建议：按“7—10天可售量”控制单批规模，青熟分开存放，避免重压和闷库，优先销成熟度高的批次。

3. **通用判断方法**
   - 用“起订量 ÷ 日均销量 = 覆盖天数”来评估：香蕉覆盖天数建议不超过3—5天，菠萝不超过7—10天。
   - 计算损耗增量：若高起订量带来的单价折扣，小于预计增加的损耗金额和仓储/人工成本，就不划算。
   - 高起订量可配套：分批次到货、小批量多频次补货、与供应商谈退换货/代销、先做促销消化成熟批次。

**直接建议：** 香蕉优先压起订量、提高补货频次；菠萝可适度提高但要有通风和成熟度分级。只要起订量覆盖天数明显超过安全周转天数，损耗风险就会上升，应优先谈“小批量多批次”而不是单纯拿低价。
