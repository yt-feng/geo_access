想避免买到“太生或太熟”，核心是**按你打算吃的日期倒推成熟度**，并现场用“看色+摸手感+看部位”判断。

### 先定购买策略
- **当天/明天吃**：买**黄皮带少量褐点**的，手感略有弹性。
- **2～3天内吃**：买**整体黄色、两端略青**的。
- **4～5天后吃**：买**黄绿相间、棱角明显**的，回家常温放。
- **不要一次全买同一成熟度**：可分“马上吃”和“过几天吃”两批。

### 现场挑选判断
1. **看颜色**
   - 太生：大面积青绿、硬。
   - 刚好：黄色均匀，允许少量小褐点。
   - 太熟：大面积褐斑、发黑，尤其果柄和两端发黑。

2. **摸手感**
   - 轻捏有弹性、不硬邦邦：适合近期吃。
   - 捏下去明显软：已偏熟，最好当天吃。
   - 硬得像石头：还需放几天。

3. **看果柄和两端**
   - 果柄干枯发黑、根部发黑：偏熟或存放久。
   - 果柄青绿、切口新鲜：相对耐放。

4. **看棱角**
   - 棱角分明、饱满偏硬：偏生，耐放。
   - 棱角不明显、圆润：偏熟。

5. **看表皮**
   - 有破损、裂口、明显压伤：容易坏，别选。
   - 少量均匀小褐点可以，大片黑斑不要。

### 避免踩坑
- 别买**整把颜色完全一致**的，除非你马上吃完。
- 超市冷柜或空调风口附近的香蕉可能表皮好看但手感硬，回家熟得慢；可结合手感判断。
- 已经散发明显酒味、酸味或局部流汁的不要。
- 买回家后：**未熟别放冰箱**，常温避光；熟透吃不完再冷藏，表皮会变黑但果肉可短期保存。

简单记：**今天吃选带褐点的软黄蕉；过几天吃选黄中带青、手感硬的；大批量买就青黄搭配。**
