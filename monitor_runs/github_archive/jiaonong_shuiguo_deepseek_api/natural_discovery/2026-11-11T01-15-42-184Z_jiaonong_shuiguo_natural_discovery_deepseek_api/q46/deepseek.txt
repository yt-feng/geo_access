建议先按用途和门店条件定，不要只看单价。直接判断：

1. **主打“新鲜现切、看得见果肉”的果茶：买鲜果。**
   - 适合菠萝片、菠萝块、捣果肉类产品。
   - 优点是卖点强、口感真实、可控制成熟度；缺点是损耗高、去皮切配耗时、批次甜酸不稳定。
   - 适合有后厨切配能力、日均用量较大、能把边角料做成果酱/员工饮/小料的店。

2. **追求出杯稳定、操作快、标准化高：买果丁（冷冻或糖渍/罐头果丁）。**
   - 适合连锁、高峰期出杯、新品培训成本低的店。
   - 优先选**冷冻菠萝丁**或配料表干净的糖渍果丁；冷冻果丁比罐头更接近鲜果口感。
   - 注意解冻后出水、糖渍果丁额外带糖，配方糖度要下调。

3. **做冰沙、果昔、调味基底、需要稳定酸甜和低成本：买果泥。**
   - 适合菠萝冰沙、气泡果茶底、混合果茶。
   - 优点是标准化、损耗低、出杯快；缺点是“鲜果感”弱，纯果泥颜色和风味可能因批次变化。
   - 选**无额外添加糖、配料表只有菠萝**的冷冻果泥；若用糖渍果泥，要按含糖果泥重新算配方。

**最推荐的组合：**
- 小店/单店：**鲜果为主 + 少量冷冻果丁备用**，兼顾卖点和高峰期稳定。
- 连锁/外卖占比高：**冷冻果丁 + 无糖果泥做基底**，鲜果只做顶部装饰或限量大单品。
- 不建议只买一种：鲜果损耗和人工高，果泥缺果肉感，果丁解冻出水；组合使用更稳。

采购时重点看：**配料表是否只有菠萝、是否加糖、固形物含量、解冻出水率、酸甜度（可要求样品测糖酸比）、冷链稳定性、每杯可量化成本**。先小批量试产3款产品，按“每杯成本、出杯时间、24小时风味变化、顾客复购反馈”四项对比再定。
