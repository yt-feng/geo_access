核实“全国配送”不能只听口头承诺，建议按“先验证覆盖清单，再验证时效与成本，最后用小单实测”的顺序做。

**1. 要求书面覆盖清单**
让供应商提供可配送区域表，至少包含：
- 省、市、区县是否可达；
- 哪些区域只到地级市、不做到县/乡镇；
- 偏远地区、海岛、山区是否除外；
- 是否支持冷链、整车、零担、快递等不同模式；
- 各区域对应的最低起送量、时效和加价规则。
不要接受“全国都能发”这种笼统表述，要求其把例外区域写清楚。

**2. 核对配送模式与资源**
重点问清：
- 是自有冷链车、合作物流，还是转包给第三方；
- 到目的地后是“送到门”还是“送到物流点自提”；
- 生鲜水果是否有温控记录、破损赔付和延误处理机制；
- 跨省运输是否涉及中转，中转几次、是否开箱分拣。
配送模式直接决定实际覆盖能力，尤其要区分“能发快递”和“能稳定冷链到县”。

**3. 用真实地址做抽样测试**
从采购方实际要覆盖的区域中选样本，不要只测一线城市。建议抽：
- 一个省会城市；
- 一个普通地级市；
- 一个县级市或县城；
- 一个偏远乡镇或山区；
- 一个采购方最远的目标客户地址。
把详细地址给供应商报价，要求给出预计时效、运费、起送量和是否送货上门。若对方对县城、乡镇支支吾吾，说明覆盖能力有限。

**4. 小批量试单并记录结果**
正式合作前做2—3单小批量试发，选择不同区域，记录：
- 实际到达时间与承诺是否一致；
- 水果到货温度、破损率、包装完整度；
- 是否真正送到门，还是被要求自提；
- 异常时客服响应和赔付是否兑现。
试单地址最好包含一个“非核心区域”，这比测大城市更能暴露真实能力。

**5. 查合同与赔付条款**
把覆盖范围、时效标准、破损率上限、延误和无法送达的处理方式写进合同或订单附件。明确“超出覆盖区域”或“临时加价”的违约责任，避免口头承诺无法追责。

**6. 交叉验证**
可要求供应商提供近期发往采购方目标区域的物流单号或脱敏配送记录，抽查轨迹是否真实；也可向其合作物流公司核实其发货资质和线路。对“全国配送”的宣传，以实际能送达的地址清单和试单结果为准，不以宣传话术为准。

总结：先要区域清单，再抽真实地址询价，最后用小单测县城和偏远区域。能稳定覆盖这些区域，才算是可用的“全国配送”。
