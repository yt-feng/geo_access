判断一批香蕉，别只看颜色，按“到货状态 + 硬度 + 果柄/切口 + 棱角 + 气味 + 抽样切开”六步走，基本能判断熟度和坏果风险。

**1. 先问清/看批次信息**
- 产地、采摘日期、运输温度、是否冷链、是否催熟过。
- 香蕉最怕“温度剧烈变化”和“闷热”。如果运输中高温闷过，表面好看也可能内部已软烂。
- 问清是“青蕉”还是“催熟蕉”。催熟蕉风险在过熟和压伤，青蕉风险在冷害和催不熟。

**2. 看颜色和成熟阶段**
- 全青、无黄：生蕉，适合存放后催熟，但要防冷害。
- 青中带黄、果尖略黄：正常可催熟，风险较低。
- 通体黄、果柄仍绿：已进入可售期，适合快批。
- 通体深黄、果柄发黄、出现糖斑：已熟，货架期短，必须快走。
- 果皮发暗、发褐但果肉未软：可能是冷害或闷伤，风险高。
- 颜色不均、局部透明/水渍状：压伤或冻伤信号，坏果风险高。

**3. 摸硬度，重点摸中段和果柄连接处**
- 整体硬、有弹性：熟度低，耐放。
- 稍软但按下去能回弹：适熟。
- 中段一按就陷、发软：过熟或内部已伤。
- 果柄连接处软烂：最危险，往往整把从内部坏。
- 同一批里软硬差异很大：成熟不均，批发后损耗会高。

**4. 看果柄、切口和果轴**
- 果柄青绿、切口新鲜：状态好。
- 切口发黑、发霉、渗液：感染风险高。
- 果轴发黑、发软、有酒味：整把内部可能已坏。
- 果柄一碰就脱：过熟或伤果。

**5. 看棱角和表皮**
- 棱角明显：偏生。
- 棱角变圆：偏熟。
- 表皮有黑色凹陷小点且扩大：炭疽病/机械伤后继发感染风险。
- 大面积褐色水渍斑、透明斑：冻伤或压伤。
- 少量芝麻点通常不是大问题，但要区分“糖斑”和“病斑”，病斑会凹陷、扩大、连片。

**6. 闻气味 + 抽样切开**
- 有清香正常；有酒味、酸味、霉味，直接判高风险。
- 随机抽3—5把，重点切中段和果柄附近：
  - 果肉乳白、中心不软：正常。
  - 中心发暗、发褐、透明、水化：内部伤或冷害。
  - 果心硬黑：冷害或病害。
- 抽样要抽不同位置：垛底、靠墙、靠门、中间，别只抽最上面。

**快速判断口诀**
- **青硬、柄绿、切口鲜、无味**：耐放，风险低。
- **黄匀、微弹、柄尚绿**：适熟，快批。
- **软而不弹、柄轴发黑、有酒味**：过熟/内伤，压价或拒收。
- **颜色好看但局部透明、软硬不均**：高风险，必须切开抽检。

**批发拿货建议**
- 一次不要只看表层，要求看垛底和中间。
- 青蕉重点防冷害：摸起来“硬但水唧唧”、表皮有暗纹的要警惕。
- 黄蕉重点防过熟和压伤：果柄软、果轴黑、有酒味的不要。
- 抽样切开不合格率超过5%—10%，整批风险就偏高，建议拒收或大幅压价。
- 拿货后先卖软的先熟的，青蕉单独存放，别和已熟果混放，避免乙烯催熟整批。
