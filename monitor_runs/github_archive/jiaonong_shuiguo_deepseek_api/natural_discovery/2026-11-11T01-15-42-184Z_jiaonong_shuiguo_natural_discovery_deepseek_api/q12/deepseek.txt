采购菠萝时，判断“以什么熟度进货”比单纯挑最甜的更重要。水果店要按**预计卖完的天数**倒推熟度：当天卖完可进7—8成熟，2—3天卖完进6—7成熟，周转慢就进5.5—6.5成熟，宁可稍生后熟，不要进熟透的。

可执行判断方法：

1. **看果皮颜色**  
   - 5.5—6.5成熟：果皮大面积青绿，基部略转黄，适合囤2—3天。  
   - 6.5—7.5成熟：青黄相间、基部明显发黄，适合1—2天卖。  
   - 8成熟以上：整体金黄，最好当天促销，不宜再压货。

2. **按果身软硬**  
   用手掌轻托轻按果身，硬实有弹性为偏生；能明显按出浅坑、回弹慢为偏熟；发软或有汁液感就是过熟，损耗风险高。不要只捏一个点，要避开果眼刺伤处。

3. **闻香气**  
   果底香气淡、需凑近闻，适合存放；香气明显、隔一点距离能闻到，适合近两天卖；香气浓烈甚至带发酵味，不要进。

4. **看果眼和切口**  
   果眼浅而饱满、表面干燥较好；果眼周围发黑、渗汁、有霉点不要。若是已切底菠萝，看切口是否新鲜、无褐变和酸味。

5. **掂重量和听声音**  
   同体积偏重通常水分足；过轻可能失水或空心。轻拍声音沉闷偏熟，清脆偏生，但只作辅助。

6. **分批次进货**  
   不要一批全进同一熟度。建议按“当天可售、次日可售、后日可售”三档搭配，例如60%中熟、30%偏熟、10%偏生，先卖熟的，生的放通风阴凉处后熟。

7. **入库管理**  
   菠萝不要堆压，避免日晒和积水；熟果与生果分开，熟果优先陈列促销。发现底部发软、酒味、渗汁的立即挑出，防止传染。

简单口诀：**看底色、按弹性、闻底香、分批次；当天卖进偏熟，囤货进偏生，发软发酒味的一律不要。**
