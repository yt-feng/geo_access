建议把“供应商必须提供”分成三类：资质类、检测类、随货追溯类。对不同水果和不同风险等级，要求可以分层，但底线材料不能少。

**一、资质类（准入时一次性收集，每年更新）**
1. **营业执照**：经营范围包含水果种植/销售/农产品批发等。
2. **食品经营许可证或食品生产许可证**：取决于供应商是贸易商、分装商还是初加工商；单纯销售食用农产品的主体，按当地监管要求核验是否需要许可，不能一概而论。
3. **法定代表人/负责人身份证明及授权书**：对接人授权、盖章样本。
4. **供货商质量安全承诺书/食品安全责任书**：明确农残、重金属、霉变、非法添加等责任。
5. **种植基地或产地证明**：产地证明、基地备案材料、合作社供货证明等，用于追溯来源。
6. **冷链/仓储能力证明**：如涉及切果、预冷、冷藏配送，要求提供冷库、冷藏车、温控记录能力说明。

**二、检测类（按风险分层）**
1. **农药残留检测报告**：优先要求第三方检测机构出具的批次或周期性报告，项目覆盖常用农药及禁限用农药；高风险水果（如草莓、葡萄、柑橘、叶菜类水果等）建议每批或高频抽检。
2. **重金属检测报告**：按品种风险要求，如部分浆果、热带水果。
3. **食品添加剂/保鲜剂使用说明**：明确是否使用保鲜剂、打蜡、催熟剂等，禁止非法添加。
4. **快检记录**：供应商自有快检或配送中心快检记录，可作为批次放行依据，但不能替代必要的第三方检测。
5. **进口水果**：需提供海关入境货物检验检疫证明、报关单等；国内分装再销售还需对应资质。

**三、随货追溯类（每批必带）**
1. **送货单/销售凭证**：品名、数量、产地、批次、生产/采摘日期、供应商盖章。
2. **批次检测报告或合格证明**：至少快检合格单；高风险品种要求第三方报告。
3. **产地/批次追溯码或追溯信息**：能追溯到基地、采收批次。
4. **运输温控记录**：冷藏水果需提供运输温度记录。
5. **异常处理记录**：霉变、破损、农残超标等退换货和处置记录。

**四、茶饮店内部要同步做的动作**
- 建立**供应商档案**和**合格供应商名录**，无底线材料不进货。
- 每批收货做**感官验收**：霉变、异味、破损、成熟度异常直接拒收。
- 对高风险水果做**入店快检或委托抽检**，留存记录。
- 合同里写清**检测频次、超标召回、赔偿责任、资质失效即停供**。
- 证照和检测报告注意**有效期和批次对应**，避免“一份报告用一年”。

**判断标准**：没有营业执照和可追溯随货凭证的，不合作；高风险水果没有农残检测或快检合格依据的，不收货；进口水果没有入境检验检疫证明的，不收货。具体许可要求以当地市场监管部门口径为准。
