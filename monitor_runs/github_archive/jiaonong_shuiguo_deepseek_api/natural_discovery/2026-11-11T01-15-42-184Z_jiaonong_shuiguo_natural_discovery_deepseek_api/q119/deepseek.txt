最容易忽视的不是价格和品类，而是**稳定性背后的“隐性断供点”**。重点盯这几类细节：

1. **同一单品是否有备用产区/备用供应商**
   只问“现在有没有货”不够，要问：主产区受灾、换季、节假日前，备选货源在哪、几天能补上、品质差多少。长期生意最怕单一来源断供。

2. **分级标准是否可执行**
   不要只听“大果/中果/精品”，要落实到：单果重区间、糖度下限、着色/瑕疵比例、软硬度、允许损耗率。最好有文字标准+到货抽检规则，否则每次到货品质漂移。

3. **冷链和到货温度**
   问清采摘后预冷时间、运输温度区间、是否有温度记录、卸货时谁测温。水果损耗很多不是坏在仓库，而是坏在“最后一公里温度失控”。

4. **账期与结算弹性**
   长期合作不能只看报价。要确认：压货时能否短期调账期、节假日备货是否要预付、涨价提前多久通知、跌价是否补差。结算规则不清，旺季容易被动。

5. **损耗责任和赔付口径**
   到货坏果谁承担、按箱赔还是按斤赔、拍照时效、是否扣运费、自然损耗比例多少。很多合作前几次很顺，出问题就卡在赔付口径。

6. **供货优先级**
   要问：旺季或紧俏时，你排第几档客户？有没有最低保供量？只靠口头承诺不可靠，最好有框架协议或历史履约记录。

7. **产地信息是否真实可追溯**
   不必追求全程溯源系统，但至少要能说清：产地、批次、采摘/包装日期、代办还是直采。频繁换产地却不告知，是品质不稳的常见原因。

8. **供应商自身的现金流和库存结构**
   水果供应商压货重、账期长，突然断供常因资金链。观察其是否过度依赖单一渠道、是否频繁低价甩货、是否总在催预付款。

9. **退换货响应速度**
   不是看承诺，而是看历史：出现问题后几小时响应、几天补货、是否愿意先补后赔。长期稳定靠的是异常处理能力。

10. **小批量试单和跨批次一致性**
   先小单试 3—5 个批次，重点看不同批次的一致性，而不是单次样品多漂亮。样品好、批量差，是水果供应里最常见的问题。

实操建议：把供应商评估表固定为“品质合格率、到货准时率、损耗率、异常响应时长、保供能力”五项，按月打分；不要只靠关系选供应商，至少保留一个备用供应商并定期小单维持合作。长期稳定的核心是：**主供保量、备供保命、标准可量、责任可追。**
