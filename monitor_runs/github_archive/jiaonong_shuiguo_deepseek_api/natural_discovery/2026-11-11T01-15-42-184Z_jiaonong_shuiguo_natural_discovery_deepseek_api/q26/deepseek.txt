社区超市卖小包装香蕉，采购和包装要围绕“快周转、少压伤、控熟度”来做，重点注意这些：

1. **按销售速度定包装规格**
   - 社区店客流有限，优先做 **2～3 根/袋、约 500～800g/袋**，避免大袋卖不完。
   - 可设两种规格：单人/小家庭装2～3根，家庭装5～6根；不要一开始铺太多SKU。
   - 包装上明确标价，减少称重排队和顾客翻拣。

2. **采购时控制熟度，不要只买“黄透的”**
   - 小包装周转慢于散装，采购熟度要偏“能放1～2天再卖”的：到店可售，次日仍不黑斑。
   - 分批到货：一部分即售熟度，一部分略青后熟；避免整批同时过熟。
   - 拒绝已大面积黑斑、果柄发黑、果指发软、有酒味或酸味的货。

3. **包装材料要透气、防压、防潮**
   - 用带透气孔的保鲜袋/PE袋或开孔吸塑盒，不要完全密封；密封易积水、闷出酒味和霉变。
   - 袋内可垫薄吸水纸或厨房纸吸冷凝水，但不要用报纸直接接触果肉。
   - 避免硬质深盒叠压，香蕉怕压，盒深不要超过果指高度太多。

4. **采购和到店验收看压伤与机械伤**
   - 重点查袋装/箱装底层、边角果，压伤后很快变黑出水。
   - 果柄切口要整齐，切口发黑、流汁多的批次损耗高。
   - 到店后轻拿轻放，不要整箱倒扣、堆高；小包装不要叠超过2～3层。

5. **陈列包装要防“顾客翻拣损耗”**
   - 小包装最好有透明可视区，但封口要牢，减少顾客拆袋挑换。
   - 袋上打孔或留透气口，陈列时单层或阶梯摆放，避免阳光直射和靠近热源。
   - 不要把香蕉和苹果、梨等释放乙烯的水果紧挨着大量混放，会加速过熟。

6. **损耗管理要前置**
   - 采购量按“日销×1～1.5天”控制，香蕉不适合大量囤货。
   - 每天早晚挑一次：黑斑明显的可拆袋转特价散卖或做果切/香蕉奶昔原料，别等整袋报废。
   - 记录每批到货熟度、售罄时间、报损原因，连续2～3周就能定出适合本店的采购规格和熟度。

7. **注意标签和称重合规**
   - 小包装若预包装称重，标签要含品名、净含量、价格、包装/分装日期；不要只贴总价不标净重。
   - 现场分装要保持工具清洁，烂果、黑柄果不要混入新包装。

简单执行标准：**小规格、偏生一点到店、透气袋/盒、轻堆少叠、按日销1～1.5天采购、每天挑拣转特价**。这样小包装香蕉的压伤和过熟损耗会明显下降。
