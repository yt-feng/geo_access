建议把“品相不好”拆成可验收的标准、时限、举证和赔付四件事，写进采购/供货合同或售后补充协议，避免到货后扯皮。可按下面约定：

## 1. 先约定验收标准
不要只写“品相良好”，要量化：
- **外观**：腐烂、霉变、裂果、压伤、虫眼、畸形、着色不均的比例上限；
- **规格**：单果重量/直径、每箱个数、大小均匀度；
- **新鲜度**：果柄状态、失水皱缩、异味、成熟度；
- **包装**：箱损、渗漏、挤压变形；
- **抽检规则**：按批次随机抽检多少箱/多少果，不合格率超过约定比例即整批可拒收或按比例扣款。

示例：腐烂/霉变果超过2%、压伤果超过5%、规格不符超过5%，即判定该批次不合格。

## 2. 约定到货验收时限和方式
- 到货后**当场或24小时内**完成外观、数量、包装验收；
- 隐蔽瑕疵（如内部腐烂、异味）可约定**48小时内**提出；
- 验收时拍照/录像，保留批次、箱号、称重记录；
- 超过时限未提出异议视为外观验收合格，但食品安全问题不受此限。

## 3. 约定异议举证
- 买方提供：到货照片/视频、抽检记录、称重单、库存温度记录、开箱视频；
- 卖方可在约定时间内复检或委托第三方；
- 双方对质量有争议时，送有资质检测机构，费用先由提出方垫付，最终由责任方承担。

## 4. 约定处理方式
按不合格程度分档：
- **轻微**：折价接收，按不合格比例扣款；
- **中度**：换货/补发，运费由供方承担；
- **严重**：整批拒收、退货退款，供方承担来回运费及合理损耗；
- **食品安全问题**：立即下架、封存、退货，供方承担检测费、监管处罚及顾客索赔等直接损失。

## 5. 约定售后响应时限
- 供方收到异议后**2小时内响应，24小时内给出处理方案**；
- 换货/补货到店时限；
- 退款/扣款结算时限，例如次月对账时直接抵扣。

## 6. 约定责任和例外
- 因买方储存不当、超时未售、温度失控导致的品相下降，供方不担责；
- 因运输造成的损坏，明确由供方或承运方承担；
- 生鲜易腐品可约定“不适用无理由退货”，但质量不合格仍按约定处理。

## 7. 落到单据上
每次到货保留：送货单、验收单、抽检照片、异常记录、售后沟通记录。合同里写明“验收单签字仅代表数量和包装初验，不代表外观质量最终认可”，避免签字后无法追责。

一句话：**标准量化、时限明确、照片留证、分档赔付、超时免责**，这五点写清楚，售后流程就可执行。
