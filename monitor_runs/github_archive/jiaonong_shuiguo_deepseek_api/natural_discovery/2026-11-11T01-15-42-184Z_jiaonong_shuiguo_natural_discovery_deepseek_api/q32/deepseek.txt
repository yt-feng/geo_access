判断香蕉供应商能否全年稳定供货，不能只听“有基地、能供全国”，要按季节性、货源结构、硬件能力和履约记录逐项验证。

**1. 先看货源结构，不看口头承诺**
- 要求供应商列出全年各月份的货源来源：自有基地、合作基地、批发市场补货各占多少。
- 重点问清：国产蕉淡季（一般冬春部分时段）从哪补？是否依赖云南、广西、海南、老挝、缅甸、越南、菲律宾、厄瓜多尔等不同产区轮换？
- 如果供应商只有单一产区、单一基地，全年稳定供货风险高；能明确说出“几月主供哪里、备用哪里”的，更可信。

**2. 看基地和加工能力**
- 自有或长期合作基地面积、所在产区、是否分散在多个气候带，决定抗灾能力。
- 是否有自己的催熟库、冷库、分拣包装线。香蕉全年供应不仅是“有货”，还要能按超市成熟度标准分批催熟。
- 催熟库容量能否覆盖你的日销量和周转天数，旺季、淡季是否都能排产。

**3. 用历史履约数据验证**
- 要求提供近12个月对连锁商超或大型渠道的供货记录：月度供货量、缺货次数、平均到货合格率。
- 重点看淡季月份是否仍有稳定出货，而不是只看全年总量。
- 可向其现有客户侧面核实：是否出现过断供、临时涨价、以次充好。

**4. 做小规模试单和压力测试**
- 先签短期试供，覆盖一个淡季月份，不只在旺季试。
- 设定连续8—12周、每周固定量的订单，观察缺货率、到货准时率、青黄蕉比例、成熟度一致性。
- 故意询问“下月需求增加30%能否满足”，看其响应是否有具体方案，还是只口头答应。

**5. 合同里锁关键条款**
- 约定月度最低供货量、旺季增量响应时间、缺货替代方案和违约赔偿。
- 明确规格、成熟度、损耗率、农残检测责任。
- 约定价格调整机制，避免旺季临时大幅涨价。
- 要求提供备用货源方案，并写明主供和备供切换条件。

**简单判断标准：**能说清全年各月货源、有多个产区备份、有催熟冷链设施、能提供淡季供货记录、愿意先试供一个淡季的供应商，才值得进入全年稳定供货候选；只强调“基地大、价格低”但说不清淡季来源的，应谨慎。
