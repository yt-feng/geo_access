优先找**本地做“餐饮配送”的果蔬供应商**，而不是水果店或批发市场散买。省心的核心是：每天少量、稳定、能退换、能开票、按时送到。

**推荐顺序：**

1. **本地餐饮果蔬配送商**
   - 找给餐馆、食堂、奶茶店供货的配送公司。
   - 优点：按需下单、每天配送、品类可拼、缺货可替换、月底对账。
   - 问清楚：起送量、配送时间、临时加单截止时间、坏果怎么赔、是否含税开票。

2. **本地农贸批发市场的固定档口**
   - 找愿意做“小批量日配”的档口，谈固定合作。
   - 优点：价格比配送商低，可现场看货。
   - 缺点：要自己盯品质和配送，省心程度不如配送商。

3. **生鲜平台的企业采购/餐饮专供**
   - 适合少量、标准化需求，如柠檬、圣女果、苹果等。
   - 优点：下单方便、售后规则清楚。
   - 缺点：价格略高，临时加单不灵活。

4. **附近水果店长期合作**
   - 只适合极少量、应急补货。
   - 不建议作为主供应商：品类和价格不稳定，配送也不专业。

**筛选供应商时重点问这5件事：**
- 每天几点前下单、几点送达；
- 最低起送金额和配送费；
- 坏果、少货、晚到怎么赔；
- 能否固定规格，比如按个、按斤、按盒；
- 能否月结和开票。

**最省心的做法：**
主供应商选1家本地餐饮果蔬配送商，再备1家水果店或档口应急。先试配1—2周，重点看准时率、坏果率和临时加单响应。合同不用复杂，但把“每日下单截止时间、送达时间、坏果赔付、临时加单”写进微信确认即可。
