判断“合理波动”不要只看涨跌幅度，而要把报价拆成可核算的基准和触发条件。给你一套可直接执行的判断框架：

## 1. 先定“基准价”，不要用昨天价判断今天价
- 建立**7日/30日移动均价**和**同期历史价**（去年同周），当日报价与移动均价比较。
- 对每个单品设“正常波动带”：例如叶菜±10%、根茎类±5%、进口果±8%（按你实际品类历史波动率定，不要照搬）。
- 超出波动带才进入“需解释”流程，带内视为正常。

## 2. 把报价拆成成本项
要求供应商按：**产地收购价 + 包装 + 冷链/运输 + 损耗率 + 服务费**拆分。  
判断重点：
- 产地端是否真有天气、集中上市、减产等事件；
- 运费是否受油价、线路、冷链紧张影响；
- 损耗率是否异常抬高（常见隐性涨价手段）。

## 3. 用“多源比价”验证，而不是听一家解释
- 同日向2–3家供应商询同规格同等级报价，看偏离度；
- 对照批发市场公开行情、产地行情（能核验的渠道）；
- 同一供应商连续报价做趋势线，突然跳涨要书面说明。

## 4. 设合同化的“调价触发条款”
合理波动的核心是**规则先行**：
- 约定调价周期（如每周一次，不随日报随意变）；
- 约定触发条件（产地价连续3日超±X%、极端天气、政策/运费突变）；
- 约定举证责任：供应商提供产地票据、行情截图、运输单据；
- 约定封顶幅度和回溯调整机制。

## 5. 看“报价行为”而不只看“报价数字”
以下信号通常不是合理波动：
- 只涨不跌，或跌价滞后于市场；
- 同一天不同采购员拿到不同价；
- 以“明天还要涨”催单；
- 拒绝拆分成本、拒绝提供产地依据；
- 涨价的品类恰好是你刚需、替代性差的品类。

## 可落地动作
1. 建一张单品价格表：日报价、7日均价、30日均价、历史同期、波动率、是否超带。
2. 超带即要求供应商24小时内提交调价说明+凭证。
3. 每月复盘一次：哪些涨价被市场验证，哪些是虚涨，纳入供应商评分。
4. 对高频波动品类保留2家以上备选供应商，形成比价压力。

一句话：**合理波动=有基准、有成本依据、有多源验证、有合同规则；否则就按异常报价处理。**
