便利店卖香蕉，建议以**小把（2～4根）为主，单根为辅，整袋谨慎尝试**。理由如下：

1. **小把最匹配便利店场景**
   - 便利店顾客多是即时消费，一次吃1～2根，买一整袋压力大。
   - 小把看起来比单根更完整、更卫生，也方便拿取。
   - 可以按“把”定价，减少称重和收银时间，适合高峰时段。

2. **单根适合做补充**
   - 适合只想马上吃一根的顾客。
   - 但单根容易在货架上被反复摸、碰伤，损耗较高。
   - 如果做单根，最好用保鲜膜包裱或放在固定小托盘里，并标清价格。

3. **整袋适合特定情况，不建议作为主力**
   - 整袋适合家庭采购，但这更接近社区超市或水果店的需求，不是便利店核心客群。
   - 整袋占用货架空间大，若卖不动，香蕉很快出黑点，损耗会吃掉利润。
   - 除非门店在住宅区、客流有家庭客群，或能做“整袋优惠价”，否则先不要大量上。

4. **更稳妥的上架组合**
   - 主力：小把，2～4根，按把卖。
   - 补充：单根，放在收银台附近或鲜食区，方便冲动购买。
   - 测试：整袋只做少量，观察1～2周动销和损耗。
   - 香蕉要控制订货量，少量多次补货，避免一次性上太多导致变黑。

5. **关键判断指标**
   - 如果单根和小把动销快、损耗低，就继续做。
   - 如果整袋一周都卖不完，或者每天都有明显碰伤、发黑，就下架整袋。
   - 如果顾客经常问“有没有一整袋”，再考虑恢复整袋。

简单说：**便利店优先卖小把，单根做便利补充，整袋只做测试，不要一开始就重仓。**
