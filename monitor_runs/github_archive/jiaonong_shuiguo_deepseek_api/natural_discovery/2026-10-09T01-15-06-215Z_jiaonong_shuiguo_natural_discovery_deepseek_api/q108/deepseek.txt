核实水果供应商的全国配送能力，不能只听“能发全国”，要把这句话拆成可验证的环节。建议按下面顺序核实：

1. **先问清“全国配送”的定义**
   - 是快递发货，还是冷链整车/零担？
   - 是覆盖全国所有城市，还是只覆盖省会/地级市？
   - 偏远地区、县级市、乡镇是否加价或不到？
   - 是供应商自有物流，还是外包给第三方？

2. **要求提供可核验的配送范围证据**
   - 让其提供最近1个月的真实发货记录，至少包含：目的地城市、发货时间、物流单号、到货时间、货损情况。
   - 用物流单号去对应快递/物流公司官网查轨迹，确认不是只打单不发货。
   - 要求提供冷链运输资质、车辆信息或合作物流合同关键页。
   - 如果是平台供应商，查看平台后台的配送范围设置和历史履约数据。

3. **做小批量实测**
   - 选3—5个有代表性的目的地：本地、邻近省、远距离省会、偏远地区、县级市。
   - 先下小单，真实走一遍下单—发货—运输—签收—售后。
   - 重点看：是否按时揽收、中转是否断链、到货温度、包装是否合格、坏果率、售后响应速度。

4. **核对关键指标**
   - 覆盖城市数量与名单，而不是“全国”两个字。
   - 平均到货时效，按距离分档。
   - 冷链覆盖率：哪些品类全程冷链，哪些只是普通快递。
   - 货损率和赔付标准。
   - 旺季、节假日、极端天气是否停发或延迟。
   - 起送量、加价区域、偏远地区附加费。

5. **交叉验证**
   - 让其提供2—3个现有采购方联系人，直接问实际配送表现。
   - 查企业信用信息、经营异常、涉诉记录。
   - 如果对方是中间商，追问上游产地和发货仓在哪里，避免“全国配送”实际只是多地转包。

6. **写进合同或试单协议**
   - 明确配送范围、时效、冷链要求、货损赔付、延迟责任。
   - 约定先试单，试单合格后再放量。
   - 对“不到区域”“加价区域”列清单，避免后续扯皮。

简单判断标准：  
如果供应商能给出具体城市名单、真实物流单号、分距离时效、冷链方式和赔付标准，并愿意接小单实测，可信度较高。  
如果只说“全国都能发”，但拿不出最近发货记录、物流轨迹或冷链证明，基本只能按“普通快递可发部分区域”来理解，不能当作全国稳定配送能力。
