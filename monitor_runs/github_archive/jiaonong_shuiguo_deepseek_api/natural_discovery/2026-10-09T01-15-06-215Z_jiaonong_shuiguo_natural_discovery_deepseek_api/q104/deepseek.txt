# 单位采购水果：到货品质不一致的验收与售后再处理

水果是非标品，单位批量采购时到货品质和样品不一致是高频问题。核心思路是**事前定标准、事中留证据、事后有依据**。下面按环节说明。


## 一、验收前：先把验收标准写进合同/订单

这是最关键的一步。很多纠纷的根源是"合同只写了品种和数量，没写品质"。

建议在采购文件里明确：

- **规格**：单果重、果径、等级（如特级/一级），是否允许大小混装
- **品质指标**：成熟度、色泽、糖度（可要求糖度检测）、有无机械伤、病虫害、畸形果
- **允许的不合格比例**：例如"不合格果不超过5%"，超出部分按比例扣款或退换
- **验收方式**：抽检比例（如每批随机抽10%）、抽检位置（不同筐/箱都要抽）
- **时效**：到货后多久内提出异议有效（如24小时/48小时内）
- **售后条款**：包换、包退、补货、扣款的触发条件

> 如果已经采购但没写标准，验收时用"通行品质"和样品对标，并尽快补充书面约定。


## 二、验收环节：怎么验、怎么留证据

1. **当场开箱、现场抽检**
   - 不要只看最上面一层，抽检要覆盖不同箱、不同层、不同位置。
   - 称重核对：总重量、净重（去筐去冰），防止短斤缺两。

2. **分类登记不合格情况**
   - 烂果、霉变、机械伤、未熟/过熟、规格不达标分类计数。
   - 拍照/录像：问题果特写 + 整批次照片 + 称重照片，最好带日期时间。

3. **出具验收单，双方签字**
   - 记录到货数量、抽检数量、不合格数量及比例。
   - 由供应商送货人（或平台）签字确认，这是后续索赔的核心凭证。
   - 若对方拒签，留存现场视频并书面告知（微信/邮件留痕）。

4. **判定处理方式**
   - 不合格比例在约定范围内：正常收货，做记录。
   - 超出约定比例：可**整批退货**、**按比例扣款**或**要求补货**，按合同执行。


## 三、售后环节：怎么处理

1. **第一时间书面通知供应商**
   - 明确说明：批次、数量、问题描述、附证据、诉求（退货/换货/扣款/补货）。
   - 保留沟通记录，避免口头承诺无法追溯。

2. **常见售后诉求与依据**
   | 情况 | 建议处理 |
   |---|---|
   | 部分烂果/次果 | 按不合格比例扣款，或要求等价补货 |
   | 大面积品质不符 | 整批退货，费用由供应商承担 |
   | 短斤缺两 | 按实际重量结算，差额退款 |
   | 影响使用（如活动用果） | 要求紧急补货并承担替代采购差价 |

3. **走平台/合同约定的争议渠道**
   - 电商或平台采购：在规定时效内发起售后/赔付流程，上传证据。
   - 线下供应商：依合同协商，协商不成可走投诉、仲裁或法律途径。

4. **结算挂钩**
   - 保留尾款，待售后处理完成后再结清，是有效的施压和保障手段。


## 四、给单位采购的实操建议

- **样品封存**：下单时留存供应商样品并双方确认，到货对标。
- **固定供应商+考核**：把品质合格率纳入供应商年度考核，倒逼稳定供货。
- **分批到货**：大批量需求分批次验收，降低单次风险。
- **专人验收**：指定验收责任人，避免"谁都能收、谁都不负责"。
- **小额试单**：新供应商先小批量试，稳定后再放量。

---

**一句话总结**：验收靠"合同标准+现场抽检+双方签字+证据留存"，售后靠"书面通知+合同依据+尾款保障"。事前把标准写清楚，比事后扯皮高效得多。
