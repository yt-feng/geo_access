酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购单或验收标准，避免只写“新鲜、优质”这种无法验收的表述。可按以下维度要求供应商：

**一、规格标准**

1. **品种与产地**
   - 明确品种名称，如红富士苹果、皇冠梨、巨峰葡萄、台农芒果等，不接受口头简称。
   - 对酒店固定菜单用的品种，最好锁定产地或品牌，避免同一品种不同产区导致口感差异。

2. **单果重量/大小**
   - 按品种设定单果重量区间，如苹果180–220g、橙子200–250g、火龙果400–500g。
   - 或按直径/长度设定，如芒果单果300–400g、香蕉长度18–22cm。
   - 同一批次大小差异不宜过大，通常控制在±10%–15%以内。

3. **成熟度**
   - 要求“可即食或1–2天内达到可即食成熟度”。
   - 香蕉、芒果、牛油果等后熟型水果，可约定到货成熟度，如芒果7–8成熟、牛油果硬熟但可后熟。
   - 草莓、蓝莓、葡萄等即食型水果，到货即应达到食用成熟度。

4. **新鲜度与货架期**
   - 明确到货时剩余货架期，如叶菜类不适用，但水果可要求：草莓到货后至少24–48小时可用，苹果、橙子等至少3–5天。
   - 不接受隔夜切果、预切果冒充鲜果，除非另行约定。

5. **包装与净重**
   - 明确毛重、净重、允许误差，通常净重误差不超过±2%–3%。
   - 要求标明品名、规格、数量、采摘/包装日期、供应商信息。
   - 易损水果如草莓、蓝莓、无花果，需有防压托盘或独立格包装。

6. **食品安全与合规**
   - 提供农残检测合格证明或批次检测报告。
   - 进口水果需提供入境货物检验检疫证明。
   - 预切水果需符合即食食品卫生要求，冷链温度通常0–4℃。
   - 拒绝使用催熟剂超标、染色、打蜡不合规的产品。

**二、外观标准**

1. **颜色**
   - 具有该品种成熟时应有的色泽，如苹果红润、芒果金黄带红晕、葡萄紫黑均匀。
   - 不接受明显青白、褪色、发黑、褐变。

2. **形状与完整性**
   - 果形端正，无畸形、无严重偏斜。
   - 无裂口、无破损、无虫眼、无病斑、无霉变。
   - 果蒂、果柄状态良好，如草莓蒂鲜绿、葡萄果梗青绿。

3. **表面与清洁度**
   - 表面干净，无泥污、无药斑、无残留物。
   - 允许少量自然果粉，如葡萄、蓝莓，但不能有霉斑。
   - 不允许有明显机械伤、压伤、擦伤。

4. **硬度与手感**
   - 按品种要求：苹果、梨应硬脆；芒果、牛油果按后熟要求；草莓、蓝莓应饱满有弹性。
   - 不接受软烂、出水、凹陷、发黏。

5. **气味**
   - 具有品种自然清香，无发酵味、酸腐味、霉味、化学异味。

6. **均匀度**
   - 同一批次颜色、大小、成熟度应基本一致，适合酒店果盘标准化摆盘。
   - 混装果盘可允许不同品种，但每个品种内部应均匀。

**三、验收与退换建议**

1. **抽样验收**
   - 每批次按5%–10%抽样，少于50箱可抽3–5箱。
   - 不合格率超过约定比例，如5%，可整批拒收或按比例扣款。

2. **明确拒收项**
   - 霉变、虫蛀、腐烂、异味、严重压伤、农残证明缺失。
   - 规格与样品严重不符，如单果重量低于下限10%以上。

3. **退换货条款**
   - 到货2小时内完成验收，不合格品供应商应在24小时内补换。
   - 因原料问题导致酒店客诉或浪费，可约定由供应商承担相应责任。

**四、可直接写进采购单的简版条款**

> 供应商应保证水果原料品种纯正、新鲜可即食，单果规格符合约定区间，同批次大小均匀，成熟度适宜，无腐烂、霉变、虫蛀、异味、严重机械伤及病斑。到货净重误差不超过±3%，并提供农残检测或相关合格证明。验收不合格率超过5%时，酒店有权拒收或要求24小时内补换。预切水果须冷链0–4℃配送，符合即食食品卫生要求。
