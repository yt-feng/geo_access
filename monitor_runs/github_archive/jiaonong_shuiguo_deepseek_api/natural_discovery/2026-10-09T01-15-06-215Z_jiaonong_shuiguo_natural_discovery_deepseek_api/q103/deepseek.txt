结论先说：**按斤结算最容易管住成本，按箱结算最省事但最容易吃亏，按份结算只适合终端零售式供餐，不适合食堂采购。**

按三种场景拆开看：

1. **按斤结算：最适合食堂采购主模式**
   - 优点：单价透明，能横向比价，能按实际到货量结算，损耗和短斤少两容易发现。
   - 缺点：验收麻烦，需要称重、记录、复称，人工成本高。
   - 适合：苹果、香蕉、橘子、西瓜等大宗、易分拣、价格波动大的水果。

2. **按箱结算：最省事，但管理风险最大**
   - 优点：下单、收货、结算快，适合标准化包装水果，如整箱苹果、整箱橙子。
   - 缺点：箱内大小、成熟度、坏果率不透明，容易出现“箱子好看、里面差”；净重和毛重也容易扯皮。
   - 适合：长期合作、规格稳定的供应商，且必须约定**净重、规格、坏果率、退换标准**。
   - 不建议：作为唯一结算方式。

3. **按份结算：只适合分餐到人**
   - 优点：按人头或按份发放，方便控制每人摄入量，结算简单。
   - 缺点：采购端不透明，供应商容易用次果充数；食堂很难判断单价是否合理。
   - 适合：水果切配后按份发放、会议茶歇、固定套餐。
   - 不适合：作为食堂原料采购的主要结算方式。

**建议的实操方案：**

- **主结算方式：按斤结算。**
- **辅结算方式：对标准化程度高的水果，可按箱采购，但按净重折算单价。**
- **终端发放：可以按份，但采购结算仍按斤或按净重。**
- **验收必须做三件事：**
  1. 称净重，不看毛重；
  2. 抽检坏果率，超过约定比例扣款或退货；
  3. 固定每周比价，防止长期合作后价格虚高。

一句话：**采购端按斤，入库按净重，发放可按份。按箱只能作为包装形式，不能作为主要结算依据。**
