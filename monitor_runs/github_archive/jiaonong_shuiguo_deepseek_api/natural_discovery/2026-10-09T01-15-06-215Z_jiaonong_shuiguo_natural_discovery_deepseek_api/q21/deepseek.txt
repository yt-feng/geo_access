超市采购水果时，供应商通常需要根据水果品类、来源、超市自身验收要求以及当地监管要求，提供以下几类证明或报告。实际执行中，不同超市和地区会有差异，但可以按这个框架判断。

**一、基础经营资质证明**
1. **营业执照**：供应商合法经营主体证明。
2. **食品经营许可证**或食品生产许可证：销售预包装或散装食品通常需要。
3. **供货商与生产商/种植基地的关系证明**：如授权书、采购合同、合作社证明等，用于证明货源合法。

**二、进货来源与合格证明**
1. **进货凭证/采购发票/送货单**：证明水果来源、批次、数量、日期。
2. **产地证明**：如产地供货证明、基地证明、合作社证明。
3. **合格证/自检报告**：供应商或产地对批次水果出具的快检或自检合格证明。

**三、检测报告类**
1. **农药残留检测报告**：
   - 常见为第三方检测机构出具的合格报告，或供应商快检报告。
   - 超市通常关注有机磷、氨基甲酸酯类等农残项目。
2. **重金属及污染物检测报告**：
   - 如铅、镉、砷、汞等，尤其针对产地环境风险较高的品类。
3. **食品添加剂/保鲜剂检测报告**：
   - 如水果是否使用违规保鲜剂、打蜡、染色等。
4. **微生物检测报告**：
   - 主要针对即食水果、鲜切水果、预包装水果。
5. **转基因检测报告**：
   - 如涉及转基因水果或超市有相关要求时提供。
6. **植物检疫证书**：
   - 跨区域调运、进口水果或特定病虫害风险水果常需要。

**四、进口水果额外证明**
1. **入境货物检验检疫证明**。
2. **海关报关单/通关单**。
3. **输出国或地区官方植物检疫证书**。
4. **中文标签**：预包装进口水果需有符合要求的中文标签。

**五、超市实际验收常见要求**
1. **批次对应**：检测报告或合格证明最好与到货批次、日期对应。
2. **报告有效期**：很多超市要求检测报告在合理期限内，如近半年或近一年内，具体看品类和风险。
3. **快检制度**：部分超市会自行对农残进行快速检测，供应商需配合。
4. **承诺书/质量保证协议**：供应商承诺所供水果符合食品安全标准。
5. **追溯信息**：能提供从产地到门店的追溯链条。

**六、简单判断标准**
供应商至少应能提供：
- 营业执照；
- 食品经营许可证；
- 进货凭证或产地证明；
- 对应批次的农残检测合格报告或快检合格证明；
- 进口水果另加海关和检疫证明。

如果超市采购的是普通散装水果，核心是**来源合法、批次可追溯、农残合格**。如果是鲜切、即食或进口水果，要求会更严格。建议在采购合同或验收标准中明确列出所需报告种类、有效期和批次对应要求，避免到货时扯皮。
