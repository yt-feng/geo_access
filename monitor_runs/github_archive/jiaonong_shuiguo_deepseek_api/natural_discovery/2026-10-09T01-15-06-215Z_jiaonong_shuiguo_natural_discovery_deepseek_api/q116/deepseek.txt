# 小商家水果采购：现金结算 vs 月结账期的风险对比

## 现金结算（一手交钱一手交货）

**主要风险：**
- **资金占用压力大**：每次采购都要立刻掏钱，旺季或备货期现金流吃紧，容易周转不开。
- **采购量受限**：钱不够就只能少进货，可能错过好价格、好货。
- **议价能力弱**：现结虽然有时能拿到小折扣，但如果量小，供应商未必给好价。
- **跑单/被骗风险**：先付款后发货时，遇到不靠谱供应商可能收钱不发货或发次货。
- **无账期缓冲**：一旦某批货卖不动，钱已经付出去了，亏损直接砸在手里。

**相对优势**：不欠人情、不背债务，供应商关系简单，不容易被追账。

---

## 月结账期（先拿货，后付款）

**主要风险：**
- **对账纠纷**：水果损耗、等级差异、退货部分容易扯皮，月底对账时经常"说不清"。
- **逾期违约风险**：卖得慢或回款慢，到期付不出钱，可能被断供、加收滞纳金，甚至影响信誉。
- **隐性成本**：账期价通常比现结价高，相当于变相付了"利息"。
- **依赖单一供应商**：长期月结容易绑定一家，一旦对方涨价或断供，你临时换货源很被动。
- **坏账/赖账双向风险**：你欠供应商的钱是风险；如果供应商把账期当筹码，也可能在关键时刻卡你。
- **管理成本上升**：需要专门记账、跟踪应付账款，小商家容易漏记、错记。

**相对优势**：缓解现金流压力，能先进货后卖货，用卖货的钱付款。

---

## 给小商家的实操建议

1. **别走极端**：可以"部分现结 + 部分短账期"组合，降低单一风险。
2. **账期写清楚**：品级标准、损耗归属、退货规则、付款日、逾期责任，白纸黑字或微信留痕。
3. **控制账期额度**：月结金额别超过你一个月能稳定回款的额度。
4. **留备用供应商**：至少有两家可切换，避免被账期"套牢"。
5. **现结争取折扣**：现金结算时主动谈价，把资金优势换成成本优势。

**一句话总结**：现金结算的风险是"钱压货"，月结的风险是"货压钱+对账扯皮"。小商家最稳妥的是控制单笔金额、明确规则、保留切换余地。
