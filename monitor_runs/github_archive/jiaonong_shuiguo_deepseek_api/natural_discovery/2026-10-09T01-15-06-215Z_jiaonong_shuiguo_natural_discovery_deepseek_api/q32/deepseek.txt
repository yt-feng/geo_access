判断香蕉供应商能否全年稳定供货，不能只听承诺，要看他有没有“跨产区调度能力+冷链+催熟+资金垫付”这几项硬条件。可以按下面步骤核查和判断。

**一、先问清他的货源结构，而不是只看他有没有货**
香蕉是热带作物，单一产区很难全年稳定。重点问：
1. 他有几个产区？分别在哪里？
2. 各产区大概什么季节上市？
3. 遇到台风、寒潮、病害时，备用产区是哪个？
4. 是自有基地、合作基地，还是市场调货？

如果供应商只有一个产区，或者只说“从批发市场拿货”，全年稳定供货能力通常不可靠。较稳的供应商一般能覆盖云南、广西、海南、广东，以及缅甸、老挝、越南、菲律宾、厄瓜多尔等不同产区，并说明不同月份的切换逻辑。

**二、要求提供全年供应计划表**
让对方给出按月份排列的供应计划，包括：
- 每月主要货源产地
- 预计可供数量
- 规格，如每箱净重、每根条数、单根重量
- 价格区间或定价方式
- 替代产区

重点看淡季，比如国内产区交替期、台风季、春节前后，是否仍有明确货源。只给旺季报价、不谈淡季的，要谨慎。

**三、核查冷链和运输能力**
香蕉对温度敏感，运输和仓储不当会直接影响到店品质。要确认：
1. 是否全程冷链，适宜温度通常约13到15摄氏度，具体按品种和成熟度调整；
2. 是自有冷藏车还是临时外包；
3. 从产地到你们配送中心或门店需要多久；
4. 是否具备港口、口岸或产地仓资源；
5. 旺季、节假日运力紧张时怎么保障。

没有稳定冷链的供应商，即使有货源，也可能出现集中到货、品质波动、断供。

**四、核查催熟和加工能力**
连锁超市通常需要按门店销售节奏分批催熟。要问：
1. 供应商是否有催熟库；
2. 能否按你们要求的成熟度、到店时间分批出货；
3. 是否支持贴标、分拣、分级、包装；
4. 出现青蕉、熟蕉、机械伤时如何处理。

只做原条批发、不做催熟和分级处理的供应商，适合作为补充，不一定适合作为全年主供应商。

**五、用历史履约数据验证**
不要只看样品和口头承诺，要查：
1. 过去12个月每月实际供货量；
2. 断供、延迟、质量退货记录；
3. 主要客户名单，尤其是连锁超市或大型水果渠道；
4. 是否有长期合同和履约保证金；
5. 突发情况下，比如台风、封关、运价上涨时的处理案例。

可以要求提供近几个月的发货单、报关单、质检记录，敏感信息可脱敏，但要能交叉验证。

**六、做小规模试单和压力测试**
建议分三步：
1. 先小批量试单，连续试4到8周，观察到货准时率、损耗率、成熟度一致性；
2. 在淡季或节假日附近追加一次试单，看其调度能力；
3. 要求其书面承诺最低月供量、替代产区方案、违约处理方式。

关键指标可以定为：
- 准时到货率，比如不低于95%；
- 质量合格率，比如不低于95%；
- 月供货量偏差，比如不超过正负10%；
- 缺货提前通知时间，比如不少于7天；
- 替代货源启动时间，比如3到5天内。

**七、合同里必须写清楚的条款**
1. 全年最低供货量和分月计划；
2. 价格调整机制，避免随行就市随意涨价；
3. 替代产区或替代供应商条款；
4. 质量标准、验收标准和退换货规则；
5. 断供、延迟、质量事故的赔偿；
6. 履约保证金或账期约束；
7. 不可抗力下的通知和补救义务。

**八、实操判断标准**
可以这样快速判断：
- 能说清多产区全年切换逻辑，加分；
- 有自有或长期合作基地，加分；
- 有冷链、催熟库、分拣能力，加分；
- 能提供过去12个月履约数据，加分；
- 愿意签最低供货量和违约条款，加分；
- 只靠一个产区、临时调货、没有冷链催熟，减分；
- 只给低价但回避淡季保障，减分。

**结论**
最稳妥的做法不是找一家“全能供应商”，而是“1家主供应商+1家备选供应商”。主供应商负责全年基础量，备选供应商在淡季、台风季或主供应商出问题时补位。签约前一定要看产区结构、冷链催熟能力、历史履约数据，并通过淡季试单验证。这样比单纯比价更能判断能否全年稳定供货。
