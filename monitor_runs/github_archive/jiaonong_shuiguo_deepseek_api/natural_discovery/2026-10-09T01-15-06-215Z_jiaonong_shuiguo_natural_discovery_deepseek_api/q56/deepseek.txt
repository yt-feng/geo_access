茶饮店使用水果，供应商至少应提供以下证明，具体按水果类型和用途分：

**基础资质（所有供应商）**
- 营业执照
- 食品经营许可证（或食品生产许可证，视其性质）
- 供货合同/框架协议，明确质量责任和追溯条款

**产品合格证明**
- 产品出厂检验报告（COA），对应批次
- 第三方检测报告（CMA/CNAS资质），覆盖农残、重金属等
- 若为进口水果：入境货物检验检疫证明、报关单

**追溯与过程证明**
- 批次追溯信息（产地、采摘/加工日期、批次号）
- 冷链运输记录（温度监控），适用于需冷藏的水果
- 种植环节证明：如绿色食品、有机认证、GAP认证（非强制，但可作为加分项）

**针对高风险水果（如即食、鲜切）**
- 致病菌检测报告（沙门氏菌、大肠杆菌等）
- 供应商的食品安全管理制度或现场审核记录

**建议操作**
1. 每批次索证索票，留存不少于保质期满后6个月（无保质期的不少于2年）。
2. 对供应商做年度审核，重点查检测报告真实性和冷链能力。
3. 即食水果要求供应商提供鲜切加工资质和卫生检测。
4. 建立台账，做到“一批一档”，便于追溯。

如果供应商无法提供第三方检测报告或冷链记录，建议不纳入合格供应商名单。
