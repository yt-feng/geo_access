这个问题关键要看你的**客群、损耗承受力和人手**，不是单纯哪个更好。直接给判断：

**结论：多数社区水果店，最优是「整果为主 + 现场削皮/切块付费服务」，不建议只卖去皮好的，也不建议完全让顾客自己挑。**

分开说：

**1. 只卖去皮好的——风险最大**
- 菠萝去皮后保鲜期短，几小时到一天就发暗、出水、变味，卖不掉就是纯损耗。
- 你得提前判断当天销量，卖少了不够、卖多了全扔。
- 除非你客流稳定、走量快（比如景区、写字楼午市），否则别当主力。

**2. 只卖整果、让顾客自己挑——省事但赚得少**
- 损耗低、库存好管，但客单价上不去，很多人嫌削皮麻烦就不买了。
- 让顾客自己挑容易翻车：挑来挑去、捏坏果、挑完不要，反而增加损耗和纠纷。
- 适合：客流小、人手少、主打低价的店。

**3. 最推荐：整果陈列 + 你帮挑 + 付费代削**
- 整果摆出来，但**由你或店员帮顾客挑**（看外观、掂重量、闻底部），既显专业又能控制损耗。
- 提供「免费削皮」或「削皮+切块加1~2元」，这是溢价点，也能带动销量。
- 想再进一步：把削好的装盒，**只做少量、现削现卖**，卖不完的当天打折或做果汁，别压库存。

**判断你该选哪种，看三个指标：**
- 日客流大、复购高 → 可以多备削好的。
- 人手少、客流不稳 → 整果为主，削皮当服务。
- 周边竞争激烈 → 用「帮挑+代削」做差异化，比单纯降价强。

一句话：**整果保损耗，代削提客单，帮挑控品质。** 三者结合最稳，别走极端。
