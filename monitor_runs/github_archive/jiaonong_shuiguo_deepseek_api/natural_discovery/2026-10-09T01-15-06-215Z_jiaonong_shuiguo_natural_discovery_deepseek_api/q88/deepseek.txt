做线上水果，坏果和口感波动主要来自“采购标准不清 + 供应链不可控”。要减少差评，建议从采购端抓这几件事：

**1. 先定“可量化”的采购标准，而不是凭感觉**
- 按品类定：糖度、单果重、果径、着色度、成熟度、硬度、含水率。
- 例如橙子可定糖度区间、果径范围；草莓可定单果重、红度比例、软果率上限。
- 标准要写成收货验收表，供应商按表供货，采购按表拒收。

**2. 按“销售周期”倒推采摘成熟度**
- 线上水果通常有1-5天物流期，采购不能只买“当下最好吃”的，要买“到用户手里刚好能好吃”的。
- 需要和产地确认：采摘成熟度、催熟/后熟方式、冷链时长。
- 对呼吸跃变型水果（如芒果、猕猴桃、香蕉、牛油果），要明确“发货成熟度”和“到货可食成熟度”两个节点。

**3. 分级采购，不要混级发货**
- 把货分成：A级线上主推、B级促销/次渠道、C级加工或线下。
- 混级是差评重灾区：一箱里大小不一、熟度不一，用户会直接评价“有的烂有的生”。
- 采购合同里写清楚：允许的次果率、坏果率、大小差异范围，超标怎么赔。

**4. 用“小批量多频次”替代一次性压货**
- 水果口感随批次波动大，一次采太多，后面批次成熟度变化快。
- 按日销量拆成小批次，缩短库存周转。
- 对高客单、易坏品类，宁可少采勤补，也不要赌库存。

**5. 产地端做“预冷 + 分选 + 包装”三件事**
- 预冷：采后尽快去除田间热，尤其是浆果、樱桃、荔枝。
- 分选：按糖度、重量、外观机器或人工分级，别让农户自己混装。
- 包装：按品类选透气、防压、防震方案，减少运输磕碰。
- 这三项不到位，采购标准再高也会在物流里崩掉。

**6. 建立“到货抽检 + 用户反馈”闭环**
- 每批到仓抽检：坏果率、糖度、软硬度、重量。
- 把抽检数据和售后评价挂钩，找出是产地问题、物流问题还是包装问题。
- 对连续两批不达标的供应商，降级或暂停，不要只靠口头提醒。

**7. 采购合同里写清“坏果赔付”和“口感责任”**
- 坏果率超过约定值，按比例扣款或补发。
- 糖度低于约定值、成熟度不符合销售周期，也要有责任条款。
- 保留每批样品和检测记录，避免扯皮。

**8. 针对不同品类做差异化采购**
- 浆果类：最怕压伤和霉变，重点看预冷、包装、到货时限。
- 柑橘类：相对耐运，但怕失水、浮皮，重点看成熟度和保鲜。
- 核果类：怕软烂，重点看硬度、冷链和采摘熟度。
- 热带水果：怕冷害和后熟不均，重点看催熟方案和温控。

**一句话总结：**
采购端减少差评，核心不是“买到好果”，而是**把“用户收到时仍然稳定好吃”写成标准，并让产地、物流、验收都按这个标准执行**。先抓糖度/成熟度/坏果率三个硬指标，再抓预冷、分选、包装三个动作，差评会明显下降。
