要减少香蕉放坏，采购时核心是：**按“预计售完时间”倒推到货熟度和到货节点，而不是只要求“新鲜”。**

可以这样要求供应商：

1. **到货熟度**
   - 如果计划 **1—2天内卖完**：可以要到货 **5—6成熟**，即果肉开始软、但表皮仍偏青，适合当天到第二天逐步转黄。
   - 如果计划 **2—3天内卖完**：建议要到货 **4—5成熟**，表皮青绿、只有少量转黄迹象，给门店留出催熟和销售时间。
   - 如果计划 **3天以上分批卖**：要到货 **3—4成熟**，整体青硬，后续按需催熟或自然转黄。
   - 不建议采购 **7成熟以上** 的香蕉，除非当天就能大量售出，否则很快会出现梅花点、发软、发黑。

2. **到货时间**
   - 优先要求 **早上开门前到货**，不要下午或晚上到货。香蕉到店后需要分拣、上架、散味、降温，早上到货能留出完整销售日。
   - 如果门店销量集中在下午和晚上，可以要求 **清晨到货 + 少量多次补货**，避免一次压太多。
   - 避开高温时段到货，尤其是夏季中午到下午。运输和卸货暴晒会明显加速成熟和腐烂。

3. **采购时最好写进要求**
   - 明确成熟度：例如“表皮青绿，棱角明显，果肉硬，转黄面积不超过10%”。
   - 明确到货时间：例如“每日7:00前到店，夏季不超过8:00”。
   - 明确批次：要求同一批成熟度一致，不要青黄混装，否则难管理。
   - 明确包装和温度：要求透气筐或纸箱，不要密封塑料袋；夏季尽量冷藏车或阴凉运输。
   - 明确验收标准：到货后抽检，太熟、发软、裂口、水烂、严重擦伤的可拒收或折价。

4. **门店配合**
   - 到货后先不要全部上架，按成熟度分开：青的放阴凉通风处，黄的优先摆面。
   - 香蕉怕压、怕闷、怕高温，也怕冷害。未熟香蕉不要直接放冷库低温，熟香蕉可适当降温但不宜过低。
   - 少量多次采购比一次大量采购更能减少损耗。

简单说，采购要求可以写成：  
**“按2—3天销售量分批到货，清晨到店；到货成熟度4—5成，表皮青绿、少量转黄，果肉硬；成熟度一致，透气包装，夏季冷链或阴凉运输；过熟、发软、水烂拒收。”**
