做水果礼盒，核心不是“凑齐四种水果”，而是**按送礼场景设计卖点**：好看、寓意好、耐运输、成本可控。苹果、橙子、香蕉、菠萝这四种里，菠萝和香蕉其实不太适合做主力礼盒，原因后面说。

## 一、先判断这四种水果适不适合做礼盒

| 水果 | 礼盒优势 | 礼盒劣势 |
|---|---|---|
| 苹果 | 耐放、寓意平安、颜色喜庆、可做主角 | 太普通，单放显得廉价 |
| 橙子 | 耐放、寓意成功/心想事成、颜色好 | 也偏常见 |
| 香蕉 | 便宜、颜色亮 | 极不耐压、易黑、催熟其他水果，不适合长途/久放 |
| 菠萝 | 有气势、寓意旺来 | 扎手、占空间、易压坏、处理麻烦、气味重 |

**结论：**
- 如果做**同城现送/当天自提**：可以放香蕉、菠萝，靠“丰满、喜庆”卖。
- 如果做**外卖、快递、放几天再送**：香蕉和菠萝尽量别放，或只做小比例点缀。
- 最好卖的礼盒，通常是：**苹果 + 橙子做基础，再加1-2种耐放水果提升档次**，比如猕猴桃、火龙果、葡萄、石榴、芒果、哈密瓜。

## 二、如果只用这四种，推荐3种搭配方案

### 方案1：平安成功礼盒（最稳、最好卖）
**苹果 + 橙子**
- 苹果：4个或6个
- 橙子：4个或6个
- 寓意：平安 + 心想事成/成功
- 适合：探病、看望长辈、普通商务、节日走亲
- 优点：耐放、成本低、损耗小、好包装
- 定价：建议走中低价位，靠量卖

这是四种里**最容易复制、最好卖**的组合。

### 方案2：平安旺来礼盒（适合节日、开业）
**苹果 + 橙子 + 菠萝**
- 苹果：4个
- 橙子：4个
- 菠萝：1个（放底部或侧边固定）
- 寓意：平安 + 成功 + 旺来
- 适合：开业、乔迁、春节、公司送礼
- 注意：菠萝要选小果，否则盒子很大；必须用珍珠棉/纸托固定，防止扎破其他水果
- 定价：可以比方案1高20%-40%

### 方案3：缤纷喜庆礼盒（只适合同城现送）
**苹果 + 橙子 + 香蕉 + 菠萝**
- 苹果：3个
- 橙子：3个
- 香蕉：1把（小把，5-6根）
- 菠萝：1个
- 适合：门店自提、同城当天送达、图热闹的顾客
- 缺点：香蕉容易黑，菠萝占地方，整体利润可能被损耗吃掉
- 建议：不要作为主推款，可以做“拍照款”“开业花篮平替款”

## 三、真正好卖的搭配逻辑

### 1. 按价格分三档
- **引流款**：苹果+橙子，走量，利润薄
- **主推款**：苹果+橙子+1种中档水果，比如猕猴桃/火龙果，利润最好
- **高端款**：苹果+橙子+葡萄/车厘子/芒果/石榴，送礼有面子

### 2. 按场景配
- 看长辈：苹果 + 橙子 + 猕猴桃
- 开业乔迁：苹果 + 橙子 + 菠萝，加贺卡“平安旺来”
- 探病：苹果 + 橙子 + 香蕉（当天送），别放气味重的菠萝
- 情侣/闺蜜：苹果 + 橙子 + 葡萄/草莓，颜色好看
- 商务送礼：苹果 + 橙子 + 车厘子/芒果，包装要硬挺

### 3. 礼盒里水果数量
- 小盒：4-6个，适合39-69元
- 中盒：6-8个，适合69-129元
- 大盒：8-12个，适合129-299元
- 不要塞太满，留空间放贺卡、丝带、填充纸，显得高级

## 四、如果坚持用这四种，怎么提高好卖度

1. **改名字**
   - 平安成功礼盒
   - 平安旺来礼盒
   - 四喜临门礼盒（但香蕉菠萝要现送）

2. **做大小分级**
   - 苹果选红富士，颜色统一
   - 橙子选脐橙/沃柑，大小一致
   - 香蕉选小把、青一点，送到时刚好黄
   - 菠萝选小菠萝/凤梨，不扎手、不用削眼

3. **包装比水果更重要**
   - 用硬纸盒，不要软箱
   - 加珍珠棉网套
   - 加贺卡：平安、成功、旺来
   - 丝带颜色按场景：红金适合开业春节，米白适合探病

4. **控制损耗**
   - 香蕉单独装袋，别和苹果橙子直接贴放，苹果会催熟香蕉
   - 菠萝单独隔开，防止扎破
   - 礼盒不要提前太久做，最好接单后现装

5. **定价建议**
   - 苹果+橙子：成本低，定39-69元
   - 苹果+橙子+菠萝：定69-99元
   - 四种全放：定89-129元，但只限同城
   - 加贺卡、代写祝福，可多收5-10元

## 五、最直接的建议

如果你刚开始做，**主推“苹果+橙子”基础款，利润款加猕猴桃或火龙果，节日款加菠萝做“平安旺来”**。  
香蕉和菠萝不要同时作为主力，尤其香蕉，损耗高、投诉多。  
四种全放的礼盒可以做，但定位成“同城现送喜庆款”，不要作为快递款或长期主推款。

一句话：  
**苹果橙子保底，菠萝提寓意，香蕉只做现送点缀；真正好卖的是场景明确、包装体面、损耗低的组合。**
