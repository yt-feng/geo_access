批发档口降低退货纠纷，核心是**把“验收标准”和“责任时点”提前固定下来**，并且让验货结果留下可追溯证据。建议按下面做：

## 1. 先定规则：收货前就写清楚

在订单、送货单或微信确认里固定这几项：

- **验货时限**：比如到货后 2 小时内、当天营业结束前，逾期视为外观无异议。
- **验货方式**：抽检还是全检；抽检比例多少，比如每款抽 10% 或每箱抽 3 件。
- **合格标准**：颜色、尺码、数量、破损、污渍、线头、色差、做工、配件缺失等，最好用文字+图片示例。
- **责任划分**：
  - 外包装破损、数量短少：当场拍照，算物流/供货方责任。
  - 隐蔽瑕疵：约定几天内可反馈，比如 24–48 小时。
  - 人为损坏、已剪标、已下水、已销售：一般不退。
- **退货条件**：不影响二次销售、原包装齐全、未经使用、按原单批次退回。

## 2. 收货时：先看外箱，再开箱

**第一步：核对总数和外包装**
- 看送货单、箱数、件数、款式是否一致。
- 外箱破损、潮湿、二次封箱，先拍照/拍视频，再开箱。
- 最好在快递员或送货员在场时确认明显破损。

**第二步：开箱验货**
按“先大后小、先外后内”：

1. **数量**：每款每色每码点数，和送货单对。
2. **外观**：破损、污渍、明显色差、抽丝、破洞。
3. **规格**：尺码、颜色、型号、吊牌、洗标。
4. **配件**：拉链、扣子、腰带、备用扣、包装袋。
5. **功能**：能试的试拉链、试扣、试穿或试通电。
6. **批次一致性**：同款不同箱是否颜色/版型差异大。

## 3. 验货结果必须留证

不要只口头说“有问题”。建议固定证据：

- **整体照**：货堆、外箱、送货单同框。
- **细节照**：瑕疵特写 + 吊牌/尺码 + 问题位置。
- **视频**：从开箱到发现问题连续拍，避免被说“事后弄坏”。
- **记录表**：款号、数量、问题类型、比例、处理意见。
- **双方确认**：能让送货员签字就签字；不能就微信发给对方确认。

## 4. 发现问题后怎么处理

建议分三类：

- **当场能定的**：数量短少、明显破损、错款错码。当场记录，要求补发、换货或扣款。
- **需要复核的**：色差、隐蔽瑕疵、功能问题。先隔离，不要上架，24 小时内反馈。
- **不影响销售的**：轻微线头、可整理褶皱。可协商折扣接受，避免整批退。

## 5. 档口内部执行要点

- 固定一个人负责验货，不要谁有空谁看。
- 验货区、待处理区、合格区分开，避免问题货混卖。
- 用简单表格或手机表格登记，每天汇总。
- 对经常出问题的供应商，提高抽检比例或改为全检。
- 退货时要求原包装、原批次、未经使用，减少“卖不动就退”。

## 6. 一句话原则

**收货前定标准，收货时拍证据，发现问题先隔离，责任时点写清楚。**
这样退货纠纷会从“扯皮”变成“按规则处理”。
