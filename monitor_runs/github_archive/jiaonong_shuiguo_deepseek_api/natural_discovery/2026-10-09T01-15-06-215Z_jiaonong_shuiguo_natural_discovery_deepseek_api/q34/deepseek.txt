结论先说：**在商超水果品类里，损耗低通常比采购价格低更影响最终毛利**；但两者不是二选一，真正决定毛利的是“**进价 + 损耗 + 售价 + 周转速度**”的组合。

可以拆成三个判断：

1. **采购价低，只决定“理论毛利空间”**
   - 进价低 10%，如果售价不变，看起来毛利提高。
   - 但如果品质差、货架期短、动销慢，最后烂掉、折价、报损，会把低进价优势全部吃掉。
   - 水果是非标、易腐商品，低进价往往伴随更高损耗风险。

2. **损耗低，直接保护“已经赚到的毛利”**
   - 水果损耗通常包括：自然失水、磕碰、腐烂、挑拣、试吃、折价、报损。
   - 损耗每降低 1 个百分点，往往直接转化为毛利提升。
   - 很多商超水果的真实亏损，不是进价高，而是**卖一半、烂一半、折价一半**。

3. **最终毛利更接近这个逻辑：**
   **毛利 = 销售额 - 采购成本 - 损耗成本 - 运营成本**
   其中损耗成本既包括报损，也包括因品质下降导致的降价销售。

所以实务上可以这样判断：

- **如果损耗已经很高**：优先降损耗。比如冷链、周转、订货准确率、陈列方式、先进先出、日清折价。
- **如果损耗已经控制得不错**：再谈压低进价。否则低进价可能只是把利润从前端移到后端报损。
- **最影响毛利的，通常是“高损耗 + 低周转”**，而不是单纯进价高一点。
- **最理想的采购不是最低价，而是“在可接受损耗内，综合成本最低、周转最快”的价格。**

一句话总结：  
**采购价低决定你“可能赚多少”，损耗低决定你“最后能留下多少”。对水果这种高损耗品类，后者通常更关键。**
