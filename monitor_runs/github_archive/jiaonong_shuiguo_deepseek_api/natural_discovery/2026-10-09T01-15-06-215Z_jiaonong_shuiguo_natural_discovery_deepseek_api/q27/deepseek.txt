判断苹果和橙子的规格是否适合门店销售，核心不是看“大小好不好看”，而是看**门店客群、销售场景、损耗承受能力和定价带**是否匹配。可以从下面几个维度直接判断。

## 1. 先按门店类型定规格方向

| 门店类型 | 苹果更适合 | 橙子更适合 | 判断逻辑 |
|---|---|---|---|
| 社区生鲜店 | 中果为主，75-80mm常见 | 中果为主，65-75mm常见 | 家庭日常购买，讲性价比 |
| 精品水果店 | 大果、特级果，80-90mm | 75-85mm | 送礼、尝鲜、高客单 |
| 便利店 | 小规格、即食装 | 小果或即食切果 | 单人消费、便利性 |
| 商超堆头 | 统货或分级明确 | 统货或分级明确 | 走量、价格敏感 |
| 线上团购/社群 | 中大果但性价比强 | 中大果但甜度稳定 | 图片预期和复购很关键 |

所以第一步不是问“多大算好”，而是问：**我的顾客是买来天天吃，还是买来送礼？**

## 2. 苹果怎么判断规格是否合适

苹果常见按横径分：

- 60-65mm：偏小，适合特价、儿童果、切果，不太适合精品陈列
- 65-70mm：小中果，适合社区店低价引流
- 70-75mm：中果，社区店、商超常见，家庭装主力
- 75-80mm：中大果，适合大多数门店正常销售
- 80-85mm：大果，适合精品店、礼盒、高客单
- 85mm以上：特大果，适合礼盒，不适合普通散卖走量

判断要点：

1. **看整齐度**：同一批苹果大小是否均匀，比单纯大小更重要。大小混杂会拉低陈列感。
2. **看果径一致性**：如果标75mm，实际60-85mm混装，就不适合做标准规格销售。
3. **看单果重量**：苹果通常单果150-250g比较适合家庭散卖；低于120g偏小，高于300g偏大。
4. **看门店定价**：如果周边顾客主要买10元3斤，进80mm以上大果容易卖不动。
5. **看损耗**：大果磕碰后损耗金额更高，小果虽然便宜但卖相差，都会影响毛利。

简单判断：
- 社区日常销售：**70-80mm，单果150-220g**较稳。
- 精品/礼盒：**80mm以上，单果220g以上**更合适。
- 引流特价：**65-75mm**可以，但不要长期做主推。

## 3. 橙子怎么判断规格是否合适

橙子常见按横径分：

- 55-60mm：小果，适合榨汁、特价，不适合主陈列
- 60-65mm：中小果，社区店可做性价比
- 65-70mm：中果，适合日常散卖
- 70-75mm：中大果，适合大多数门店主推
- 75-80mm：大果，适合精品店、礼盒
- 80mm以上：特大果，适合礼盒，散卖风险较高

判断要点：

1. **看皮厚和可食率**：橙子不是越大越好，太大可能皮厚、干水。
2. **看手感重量**：同样大小，越重通常水分越足。
3. **看整齐度**：橙子大小不一会影响陈列和按个销售。
4. **看销售方式**：
   - 按斤卖：65-75mm通常更稳。
   - 按个卖：70-80mm更好看，但定价要高。
   - 榨汁：小果、次果可降低成本。
5. **看品种**：脐橙、冰糖橙、血橙、沃柑规格接受度不同，不能只用一套标准。

简单判断：
- 社区日常散卖：**65-75mm**较合适。
- 精品主推：**70-80mm**较合适。
- 礼盒：**75-85mm**，但必须整齐、表皮好。
- 榨汁/特价：**60-70mm**可考虑。

## 4. 到货时用这5步快速判断

1. **抽箱测果径**：随机抽20-30个，用卡尺量横径，看是否符合采购标准。
2. **看均匀度**：最大和最小差距超过10-15mm，就不适合做统一规格。
3. **称单果重**：苹果、橙子都称一下，判断是否空壳、干水。
4. **看表皮和硬度**：规格合适但表皮花、软、烂，也不能正常销售。
5. **算毛利和损耗**：按预计售价、损耗率、皮重、坏果率算，卖完是否还有合理毛利。

## 5. 最实用的采购判断标准

你可以直接按这句话判断：

> **规格是否适合门店，不看绝对大小，而看是否匹配客单价、是否整齐、是否好陈列、是否能在预期损耗内卖出合理毛利。**

具体执行：
- 社区店：苹果70-80mm，橙子65-75mm，优先整齐度和性价比。
- 精品店：苹果80mm以上，橙子75mm以上，优先外观、甜度、礼盒感。
- 便利店：小包装、小果或切果，优先即食和便利。
- 团购：中大果但甜度稳定，优先复购和图片一致性。

如果一批货大小混杂、单果重不达标、表皮差、损耗高，即使个别果子很大，也不建议作为门店主销规格采购。
