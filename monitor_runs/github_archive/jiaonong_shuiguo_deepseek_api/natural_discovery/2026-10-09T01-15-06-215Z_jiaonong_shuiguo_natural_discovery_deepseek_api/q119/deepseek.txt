水果生意想做长期稳定，选供应商时最容易忽视的不是价格、品类这些明面条件，而是一些“隐形成本”和“风险条款”。下面按容易被忽略的程度列出来，并给出可执行的判断方法。

**1. 只谈价格，不谈损耗归属**
- 忽视点：同样报价，A家损耗5%，B家损耗15%，实际成本差很多。
- 怎么做：要求明确“到货损耗率”和“售后赔付标准”。比如到货24小时内坏果率超过X%由供应商承担，并写进订单或对账单。

**2. 不核验供应商的“稳定供货能力”**
- 忽视点：旺季或天气异常时，供应商自己都拿不到货，你的店就断货。
- 怎么做：问三个问题：主要合作产地是哪里？遇到减产时优先保谁？有没有备用产地或备用供应商？最好在淡季试单，观察其履约率。

**3. 忽略“分级标准”是否一致**
- 忽视点：口头说“大果”“精品”，实际每批大小、成熟度、糖度不一样，导致客诉和退货。
- 怎么做：要求提供书面分级标准（单果重、果径、糖度、成熟度、外观），并保留每批到货样品拍照或留样。首次合作先小批量试，确认标准稳定再放量。

**4. 不查资金结算和账期风险**
- 忽视点：只关注自己能不能赊账，没想过供应商如果资金链紧张，可能突然断供或要求现结。
- 怎么做：了解对方结算习惯，是否长期压款给上游。合作初期可小额现结，稳定后再谈账期。账期越长，越要确认对方能承受。

**5. 忽视物流和冷链细节**
- 忽视点：只问“包不包运费”，不问运输温度、装卸方式、到货时间窗口。
- 怎么做：明确冷链车还是普通车、途中温度记录、卸货责任方、迟到或压车怎么处理。水果损耗很多发生在运输环节，不是产地。

**6. 不验证供应商的“售后响应速度”**
- 忽视点：出问题时找不到人，或者拖到水果全烂了才回复。
- 怎么做：合作前测试一次售后：故意反馈一个小问题，看对方多久回复、是否推诿。长期稳定靠的是出问题能解决，不是永远不出问题。

**7. 忽略“季节切换”的衔接**
- 忽视点：某个产地季末质量下降，供应商不提前通知，你还按原标准进货。
- 怎么做：要求供应商提前告知产季切换时间，并允许你在切换期调整订单量或暂停进货。合同里可写“质量不达标可拒收或降价”。

**8. 只看供应商，不看供应商的上游**
- 忽视点：供应商本身也是中间商，上游一涨价或断货，他就失控。
- 怎么做：尽量了解其货源是自有基地、长期合作农场还是市场倒货。倒货型供应商价格可能低，但稳定性最差。

**9. 不记录历史履约数据**
- 忽视点：凭感觉觉得某家“还行”，没有量化依据。
- 怎么做：简单建表记录每批：到货损耗率、准时率、售后响应时长、客诉次数。三个月后自然能看出谁真正稳定。

**10. 忽视“退出机制”**
- 忽视点：合作久了不好意思换，或者没有备选，被单一供应商绑定。
- 怎么做：永远保持至少两家可替代供应商，哪怕第二家只占20%采购量。合作条款里写清终止合作的条件和过渡期。

**一句话总结：**
选水果供应商，长期稳定看的不是“最低价”，而是**损耗可控、标准一致、履约稳定、售后可追、退出有备选**。优先把损耗归属、分级标准、售后响应这三条写清楚，能避开大部分坑。
