水果锁价能锁多久，没有统一标准，主要看品种、季节、供应商类型和你们的采购量。一般可以这样判断：

1. **常规鲜果（苹果、梨、柑橘等耐储品类）**
   - 常见锁价周期：**1～3个月**
   - 供应稳定、冷库货源充足时，部分能谈到**一个产季**，比如苹果从入库到次年春节后。

2. **时令水果（荔枝、龙眼、杨梅、樱桃等）**
   - 基本只能锁**当季一段短窗口**，常见是**1～4周**
   - 因为产期短、天气影响大、价格波动快，供应商通常只愿意锁很短时间，甚至只锁单批货。

3. **进口水果（车厘子、榴莲、山竹等）**
   - 常见锁价：**单船期或单批次**，约**2～6周**
   - 受海运、汇率、产地行情影响大，长期锁价很难，一般会约定浮动区间或调价机制。

4. **大宗长期合作、有冷库和订单支撑的**
   - 可以谈到**3～6个月**，甚至**一年框架价**
   - 但通常不是完全固定价，而是“基准价+浮动条款”，比如随产地收购价、运费、汇率调整。

实际谈判时，供应商愿不愿意锁、锁多久，主要看这几点：

- **你的采购量和稳定性**：量越大、计划越稳，越容易锁长。
- **付款条件**：预付、现结、短账期，更容易拿到长锁价。
- **是否接受保底量**：承诺最低采购量，供应商才敢锁。
- **是否接受浮动机制**：完全固定价很难，带涨跌幅度限制的更容易谈成。
- **品种和季节**：耐储、非时令、供应集中上市的，更容易锁；反季节、灾害敏感品种很难锁。

比较实用的谈法是：

- 短期锁价：**1个月固定价**，适合时令果和波动大的品种。
- 中期锁价：**3个月基准价+浮动上限**，比如涨跌超过5%再调。
- 长期合作：**季度定价或产季定价**，同时约定质量、损耗、到货时效和违约条款。

所以，如果你问“一般能锁多久”，可以记一个大致范围：

**时令果 1～4周，常规果 1～3个月，进口果按船期/批次，长期合作可到 3～6个月甚至一个产季，但多半附带浮动或保量条件。**
