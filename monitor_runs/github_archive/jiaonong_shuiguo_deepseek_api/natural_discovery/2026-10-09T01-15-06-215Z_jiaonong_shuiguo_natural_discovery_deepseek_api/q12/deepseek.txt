水果店卖菠萝，损耗主要来自“过熟发黑、发酸、出水”和“生青不甜、卖相差”。采购时不要只按一个标准，最好按**销售节奏**分批次拿货。

判断菠萝熟度可以从这几方面看：

1. **看颜色**
   - **全青、发硬**：太生，甜度低，酸涩，适合放几天再卖。
   - **青黄相间，基部开始转黄**：比较适合采购，回店后还能放1-3天。
   - **通体金黄、底部深黄**：接近完熟，适合当天或次日卖完，不适合囤。
   - **果眼发黑、底部褐变、有酒味**：已经过熟或开始腐坏，不要拿。

2. **闻气味**
   - **几乎没味**：偏生。
   - **有清甜菠萝香，靠近底部明显**：熟度较好，适合近期销售。
   - **香味很浓、带酒味/酸馊味**：过熟，损耗风险高。

3. **按压手感**
   - **硬邦邦**：生。
   - **轻压有弹性，不塌陷**：合适。
   - **一按就软、局部凹陷出水**：过熟或伤果，别要。

4. **看叶片和果柄**
   - 叶片鲜绿、挺立，说明较新鲜。
   - 叶片枯黄、果柄干黑、底部发霉，说明存放久或品质下降。
   - 但注意：叶片状态不等于熟度，主要看新鲜度。

5. **看果形和果眼**
   - 果形匀称、果眼饱满平整的通常品质更稳。
   - 果眼深陷、发黑、流汁，往往过熟或储存不当。

6. **按采购计划搭配熟度**
   比较实用的做法：
   - 当天/次日要卖：拿**7-8成熟**，青黄相间、有香味、轻按微弹。
   - 2-3天内卖：拿**6-7成熟**，偏青黄、香味淡。
   - 特价促销或现切：可拿**8-9成熟**，但必须当天处理完。
   - 尽量少拿**全黄、浓香、软底**的货，除非确定当天能清掉。

7. **回店后管理**
   - 菠萝怕闷、怕压、怕潮。
   - 不要堆太高，底部容易压伤出水。
   - 放在通风阴凉处，避免暴晒。
   - 按熟度分区：熟的先卖，生的后卖。
   - 每天挑一遍，轻微过熟的及时切果盒、做促销，别等坏掉。

简单记：**采购选“青黄相间、有清香、轻按微弹、底部不黑不软”的菠萝最稳；全青太生，全黄太熟，有酒味必坏。**
