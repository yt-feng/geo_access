多门店、单店量小的超市，核心矛盾是：**总采购量不小，但单店单次进货量小、配送频次要求高**。适合的模式要同时解决"起订量"和"补货频次"两个问题。

## 优先考虑的模式

**1. 区域批发市场直采 + 自建/第三方城配**
- 每个区域找一个一级批发商或产地代办，按总需求量谈价，再统一分拣配送到各店。
- 优点：不用承担种植端风险，品类灵活，适合水果这种损耗高、价格波动大的品类。
- 关键点：把各店需求汇总成一张总订单，以"总采购量"去谈，而不是单店去谈。

**2. 产地直发 + 销地分拣中心**
- 对1-2个大单品（如苹果、柑橘、香蕉）走产地直采，到销地租一个小仓做分拣，再向门店配送。
- 适合单店量虽小但总数可观的情况，能砍掉中间环节，毛利更高。
- 前提：需要有稳定的大单品走量，否则分拣仓成本摊不平。

**3. 供应链平台/生鲜B2B（如美菜类模式）**
- 直接对接平台，按门店下单，平台负责配送到店。
- 优点：零起订量压力、品类全、账期灵活，适合快速起盘。
- 缺点：毛利被平台吃掉一部分，长期看价格没优势。

**4. 联营/代销模式**
- 找本地水果供应商在店内铺货，卖完结款，损耗由供应商承担一部分。
- 适合新店或水果品类还没做起来的门店，降低库存和损耗风险。

## 不太适合的

- **纯产地直采单店配送**：单店量小，物流成本会吃掉利润。
- **多级批发商层层加价**：水果本就低毛利，中间环节太多不划算。
- **完全自建冷链车队**：门店多但单店量小，车辆利用率低，成本高。

## 实操建议

1. **先分清品类**：走量单品（香蕉、苹果、应季大品）走产地/大批发直采；长尾小单品走平台或本地批发补货。
2. **集中下单、集中配送**：把所有门店需求汇总，按固定频次（如隔日）统一配送，别让每店单独进货。
3. **设一个销地中转仓**：哪怕很小，也能把"产地大货"拆成"门店小份"，这是解决单店量小的关键环节。
4. **用总盘子谈价**：跟供应商谈的是全部门店的总量，不是单店量，这样才拿得到好价格。
5. **控制损耗优先于压价**：水果毛利本来就薄，损耗控制不好，再低的进价也白搭。

如果门店集中在同一城市，**区域批发市场直采 + 自建小型分拣点 + 统一城配**通常是最平衡的方案；如果门店分散在不同城市，建议按城市各自对接本地供应链平台或批发商，不要强行全国统一采购。
