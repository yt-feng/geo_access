判断菠萝哪个规格更容易出货，核心不是看“哪个规格最好卖”，而是看**你的下游客户是谁、他们拿货后怎么卖、什么规格损耗低、周转快、利润稳**。可以从下面几个维度直接判断。

**1. 先按下游渠道分，不同渠道主推规格不同**
- **水果店/社区店**：通常偏好 **单果2.5～3.5斤**，大小适中，顾客一次买一个不心疼，陈列也好看。
- **商超/精品超市**：偏好 **3～4斤、果形端正、外观一致**，因为要按个卖或做礼盒，颜值和标准化更重要。
- **路边摊/流动摊贩**：偏好 **2～3斤小果或中等果**，进货价低、动销快，按个卖容易成交。
- **餐饮/果汁店/烘焙店**：偏好 **大果4斤以上或统货**，因为按重量出肉，大果出肉率高，加工方便。
- **电商/社区团购**：偏好 **2.5～3.5斤**，因为物流成本敏感，太大超重、太小差评多，中等规格最稳。

**2. 看周转速度，不要只看单斤利润**
- **小果/中果**：单价低，走量快，适合价格敏感型市场，但去皮损耗占比可能高。
- **大果**：出肉率高，加工客户喜欢，但零售端按个卖时价格高，普通顾客可能犹豫。
- **统货**：省分拣成本，适合批发给摊贩或加工厂，但利润薄，靠量。
- 判断方法：连续记录 **3～7天**，看每个规格的 **出货斤数、出货速度、退货/损耗、客户复购**。哪个规格“当天能清、第二天还来拿”，就是更容易出货的。

**3. 看季节和价格带**
- **旺季/低价期**：中果、小果走量最快，因为顾客囤货、摊贩敢拿。
- **淡季/高价期**：大果和精品果相对好卖，因为渠道要利润，宁愿卖少一点但卖贵一点。
- **节日前**：礼盒装、大果、果形好的规格更容易出货。
- **日常**：2.5～3.5斤中果通常是批发市场最稳的规格。

**4. 用简单数据判断，不靠感觉**
你可以让档口或业务员每天记一张表：

| 规格 | 当天到货量 | 当天出货量 | 剩余量 | 出货价 | 损耗 | 客户复购 |
|---|---:|---:|---:|---:|---:|---:|
| 2斤以下 |  |  |  |  |  |  |
| 2～2.5斤 |  |  |  |  |  |  |
| 2.5～3.5斤 |  |  |  |  |  |  |
| 3.5～4斤 |  |  |  |  |  |  |
| 4斤以上 |  |  |  |  |  |  |

重点看三个指标：
- **出货率 = 当天出货量 ÷ 到货量**：越高越好。
- **周转天数 = 剩余库存 ÷ 日均出货**：越短越好。
- **复购客户数**：同一个客户连续拿同一个规格，说明这个规格真的适配他的生意。

**5. 实操建议**
- 如果你刚做批发，**优先主推2.5～3.5斤中果**，这是大多数零售和团购渠道最容易接受的规格。
- 同时配一点 **大果给果汁店/餐饮**，配一点 **小果给摊贩**，不要只押一个规格。
- 如果某个规格连续3天出货率低于60%，要么降价清，要么换渠道，不要硬等。
- 如果某个规格连续3天出货率高于90%，且客户复购多，就加大采购比例。

**一句话结论：**
**批发菠萝最容易出货的规格，通常不是最大或最小，而是2.5～3.5斤的中果；但最终要看你的客户结构。零售和团购选中果，加工渠道选大果，摊贩选小果。用“出货率+周转天数+复购”三个指标连续测一周，就能判断你手里哪个规格最好出。**
