超市卖菠萝，**不能只盯一个指标**，但优先级要看你的经营模式。给你一个可执行的排序：

**1. 切果损耗优先（决定真实利润）**
如果是超市现场削皮/切块卖，损耗是第一位的。菠萝皮厚、眼深、两端切掉多，出肉率可能只有 45%–60%。采购时如果只看外观漂亮，但出肉率低，毛利会被吃掉。  
建议：看**果形是否端正、果眼深浅、皮厚薄、成熟度是否适合当天切**。同样进价，出肉率差 10%，利润差很多。

**2. 甜度第二（决定复购和口碑）**
超市不是一次性买卖，甜度不稳定会导致顾客下次不买。  
建议：按品种和批次抽检，别只看颜色。常见判断：  
- 闻底部有无明显果香；  
- 按压果皮略有弹性，不是硬邦邦；  
- 同一批货做糖度抽检，低于标准就降价快销或做切果促销。

**3. 大小第三（决定定价和陈列）**
大小主要影响定价、陈列和顾客选择，不一定越大越好。  
- 太大：单价高、家庭客犹豫，切果后不好卖；  
- 太小：出肉少、看起来不值；  
- 最好分规格：小果引流、中果主销、大果做礼盒或切果。

**4. 外观第四（决定第一眼吸引力）**
外观重要，但排在后面。因为超市卖菠萝，顾客最终吃的是果肉。外观只要没有明显腐烂、黑心、虫眼、严重碰伤即可。  
注意：**外观太青不一定耐放，太黄不一定甜**，要结合品种和成熟度判断。

**结论：**
- 做**整果堆头**：甜度 + 外观 + 大小，损耗次之。  
- 做**现场切果/果切**：切果损耗第一，甜度第二，大小第三，外观第四。  
- 做**促销走量**：损耗和进价第一，甜度达标即可，外观可放宽。

**最简单判断标准：**  
先算“每斤进价 ÷ 出肉率 = 每斤净肉成本”，再看甜度能不能支撑售价。如果出肉率低、甜度又不稳，外观再好也别多进。
