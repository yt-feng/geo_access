水果采购合同里的坏果率赔付阈值，**没有统一法定标准，主要看合同约定和行业惯例**。给你几个可操作的判断基准：

**常见合同约定档位**
- **5%以内**：多数生鲜采购合同的“合格线”，一般不赔或仅扣减对应货款。
- **5%–10%**：属于明显超标，通常按超出部分扣款，或按坏果比例折价。
- **10%以上**：可要求整批退货、换货，或按合同违约金条款索赔。
- **15%–20%以上**：很多合同视为“根本违约”，可拒收、解除合同并索赔。

**建议你在合同里这样写**
1. 明确“坏果率＝坏果重量÷到货总重量”。
2. 设两档：**超过5%扣款，超过10%可退换，超过15%可解约索赔**。
3. 约定抽检方式（随机抽样比例、检验时限、谁承担检测费）。
4. 约定赔付计算：如“超出5%的部分按货值双倍扣减”或“按整批货值×坏果率×2赔付”。
5. 约定到货后几小时内提出异议（生鲜通常24小时内）。

**没有合同约定时**
可依据《民法典》买卖合同相关规定，以“质量不符合约定”要求减少价款、退货或赔偿损失，但坏果率多少算不合格，需靠证据（照片、视频、第三方检测、聊天记录）和交易习惯来主张，举证难度较大。

**实操建议**
- 收货时当场开箱抽检、拍照录像、过磅记录，最好让司机或送货方签字确认。
- 先按合同阈值发书面异议，再谈扣款或索赔。
- 若合同没写，参考你所在品类惯例：叶菜、浆果类容错低（3%–5%），苹果、橙子等耐储类可放宽到5%–8%。
