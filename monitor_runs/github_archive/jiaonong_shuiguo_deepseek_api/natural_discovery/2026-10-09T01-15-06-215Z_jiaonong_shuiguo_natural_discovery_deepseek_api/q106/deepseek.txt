判断水果报价波动是否合理，核心不是看涨跌多少，而是看**波动是否有可解释的原因、是否落在历史规律内、是否与市场大盘同步**。可以按下面几步做。

## 1. 先建立“基准价”，不要凭单日报价判断

对每个品类、规格、产地，记录：

- 近7天、30天成交价
- 季节正常区间（比如砂糖橘11月到次年1月低价，反季节高价）
- 不同产地/等级的价差
- 自己历史采购价

没有基准，单看今天涨5毛还是跌5毛，没法判断。

## 2. 看波动的“归因”是否成立

合理波动通常能对应到具体原因：

| 原因 | 表现 |
|---|---|
| 天气 | 产地暴雨、寒潮、台风，短期减产或运输受阻 |
| 季节 | 上市初期价高，集中上市期价低，尾期又涨 |
| 节日 | 春节、中秋前需求涨，节后回落 |
| 供需 | 某产地集中出货，价格短期跳水 |
| 运输/油价 | 运费上涨，跨区域报价跟涨 |
| 品质 | 规格、糖度、外观变化，价格自然不同 |

如果供应商只说“今天涨了”，但说不出天气、产地、等级、运费等具体原因，就要警惕。

## 3. 对比多个来源，看是不是“单独涨你”

至少做三件事：

1. **问2-3家同类供应商**同一规格、同一产地、同一交期的报价
2. **看批发市场行情**：如当地大型农批市场当日均价
3. **看产地端信息**：产地收购价、天气、上市量

如果市场整体平稳，只有一家对你涨，通常不是合理波动，而是针对你或想试探。

## 4. 用“波动幅度+频率”设阈值

可以内部定规则，比如：

- 日波动在 **±3%以内**：视为正常，直接执行
- **±3%-8%**：要求供应商提供原因和依据
- **超过±8%**：必须比价，或暂缓下单、换备选
- 连续3天同方向上涨：启动复盘，不盲目接受

阈值按品类调整。叶菜、浆果波动天生大；苹果、土豆等耐储品类波动应较小。

## 5. 看是否与大盘同向

合理波动通常是“同涨同跌”：

- 市场普涨，供应商涨：合理
- 市场平稳，供应商涨：不合理
- 市场下跌，供应商不降：需要谈
- 市场涨，供应商涨幅明显更大：要查是否加价

## 6. 合同和机制上提前锁风险

比每天判断更有效的是：

- **约定调价机制**：参考某批发市场均价，超过一定幅度才调
- **锁价期**：比如7天、15天锁价，期间不随日报波动
- **阶梯价/保底量**：量大给优惠，减少随意涨价
- **备选供应商**：至少2-3家，避免被单一供应商拿捏
- **留样和验收标准**：防止以“品质更好”为名变相涨价

## 7. 一个简单判断流程

每天收到报价后问：

1. 和昨天比，涨跌多少？
2. 和市场其他家比，是否一致？
3. 和近30天比，是否在正常区间？
4. 供应商能否说出具体原因？
5. 原因是否可验证（天气、产地、运费、节日）？
6. 如果无法解释，是否有备选方案？

**结论：**
合理波动 = **有原因 + 与市场同步 + 在历史区间内 + 幅度可接受**。  
不合理波动 = **无原因 + 只对你涨 + 偏离历史区间 + 频率过高**。

最实用的做法是：建立自己的价格台账，每天记3个数据——供应商报价、市场均价、你的成交价。坚持一个月，你就能看出谁在正常调价，谁在借波动加价。
