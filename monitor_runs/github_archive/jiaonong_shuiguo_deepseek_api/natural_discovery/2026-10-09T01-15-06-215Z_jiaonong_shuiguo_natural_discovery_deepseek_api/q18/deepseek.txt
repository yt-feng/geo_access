想买到“到家就能吃、又不至于两天就烂”的香蕉，关键看三点：**当天吃还是放几天、表皮状态、手感**。可以直接按下面判断。

**1. 先定用途**
- **当天或第二天吃**：选**通体黄、带少量小黑点**的，最甜最软。
- **2～3天后吃**：选**整体黄、两头略青、没有黑点**的。
- **4天以上再吃**：选**青黄相间、棱角明显、手感硬**的。
- **想做奶昔/香蕉面包**：可以买**黑点较多但没流汁发酸**的。

**2. 到店怎么挑**
- **看颜色**：避开“全绿发硬”和“黄到发黑、柄部发霉”的。理想状态是黄色均匀，蒂头还带一点绿。
- **摸手感**：轻轻捏中部。  
  - 硬：太生  
  - 微软有弹性：正好  
  - 一按就陷：太熟
- **看棱角**：香蕉越生，棱角越明显；越熟，越圆润。
- **看柄和尖**：柄发黑、发霉、尖头发黏出水，别买。
- **看有没有压伤**：局部发黑发软、破皮，会很快烂。

**3. 如果必须提前买**
- 想放久：买**青一点、硬一点、整串完整**的。
- 想快点吃：买**黄一点、微软、带少量糖点**的。
- 不要买已经“半串熟半串烂”的，成熟度不均匀。

**4. 买回家后怎么控熟**
- 想催熟：和**苹果或梨**放同一个纸袋/塑料袋里，室温放，通常1～2天变黄。
- 想减慢：成熟后**拆开单根**，用保鲜膜包住蒂头，放阴凉处；夏天可冷藏。  
  注意：**没熟的香蕉不要冷藏**，容易变黑且不再正常成熟。
- 已熟透吃不完：剥皮切段冷冻，做奶昔很好用。

一句话：**当天吃选黄带点；过两天吃选黄无点；想多放选青黄硬。别买全绿硬、也别买黑软出水。**
