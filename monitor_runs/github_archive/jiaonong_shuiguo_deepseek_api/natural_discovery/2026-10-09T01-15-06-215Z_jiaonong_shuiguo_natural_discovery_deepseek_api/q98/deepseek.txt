判断养老院或医院食堂的水果供应商，核心是两条：**合规资质能不能兜住法律责任，供应能力能不能兜住每天的出餐**。可以按下面的清单逐项核查。

## 一、合规性核查（硬门槛，缺一不可）

1. **主体资质**
   - 营业执照：经营范围要含"食品销售/食用农产品销售"，注意注册时间、是否在营。
   - 食品经营许可证（或食品生产/流通许可）：这是关键。水果若只是初级农产品销售，部分情形可豁免，但**配送到食堂、涉及分拣包装的，通常仍需食品经营许可**，让对方明确说明并提供。
   - 若对方是批发市场档口或个人，要求提供其上游的进货凭证和产地证明。

2. **产品合规文件**
   - **农残检测报告**：每批次或定期（如每月）提供，最好有第三方检测机构出具。
   - **产地证明 / 合格证**：食用农产品合格证、产地检疫等。
   - **进货台账**：能追溯上一级供应商，这是《食品安全法》要求的。

3. **人员与场所**
   - 配送人员健康证。
   - 仓储、分拣场所的卫生条件（可实地看一次）。

4. **票据合规**
   - 能开正规发票，对公账户收款。只收现金、走个人账户的要警惕。

## 二、稳定性核查（决定会不会断供、掉品质）

1. **货源结构**
   - 是自有基地、长期合作产地，还是每天去批发市场现买？前者稳定，后者受行情波动大。
   - 问清楚：旺季淡季、极端天气时怎么保供？

2. **配送能力**
   - 有没有自有/固定冷链车？水果对温度敏感，尤其夏季。
   - 配送频次、到货时间是否固定，能否应对临时加量。

3. **历史与口碑**
   - 合作过哪些同类单位（其他养老院、医院、学校食堂），能否提供参考客户。
   - 经营年限、是否有过食品安全处罚记录（可查"国家企业信用信息公示系统"）。

4. **履约与应急**
   - 合同里写明：**缺货替代方案、质量问题退换、断供违约责任**。
   - 是否接受**试供期**（如先合作1–2个月），用小批量验证稳定性。

## 三、实操建议

- **先小后大**：不要一上来签长期大单，先试供1个月，看准时率、损耗率、退货响应速度。
- **留样与验收**：每次到货验收记录（品种、数量、外观、温度），保留样品和单据，出问题可追溯。
- **多家备份**：主供应商 + 1家备选，避免单点依赖。
- **合同写清**：资质有效期、检测报告提供频率、违约条款、结算方式。

## 四、快速判断口诀

> **证照齐、报告全、能开票、有冷链、有台账、敢试供、有备选**——满足这些，基本可控。

如果对方在"食品经营许可证"或"农残检测报告"上含糊其辞，直接排除，无论价格多低。养老院和医院的服务对象是高风险人群，食安出事的代价远高于省下的采购差价。
