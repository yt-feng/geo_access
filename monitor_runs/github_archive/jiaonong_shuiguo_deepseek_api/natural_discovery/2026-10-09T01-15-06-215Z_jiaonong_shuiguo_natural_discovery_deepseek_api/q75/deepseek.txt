和小批量试单的核心目标不是赚钱，而是**低成本验证供应商是否值得长期合作**。建议按下面的框架设计：

## 一、先明确试单要验证什么

| 维度 | 具体验证点 |
|------|-----------|
| 品质 | 成熟度、大小均匀度、损耗率、农残/质检 |
| 规格 | 是否与约定一致（品种、等级、单果重、箱规） |
| 时效 | 下单到到货时间、冷链是否断链 |
| 稳定性 | 同批货里好果/次果比例 |
| 服务 | 沟通响应、退换货态度、开票能力 |
| 价格 | 报价是否含隐藏费用（运费、装卸、损耗） |

## 二、试单规模怎么定

- **数量**：按你正常单批量的 **10%~20%**，或直接 1~2 个整托/整箱起。
- **金额**：控制在你能承受全额损失、且不心疼的范围内（比如几千元级）。
- **SKU**：只试 **1~2 个品类**，不要一次铺开。
- **频次**：连续试 **2~3 次**，单次看不出稳定性。

## 三、试单前必须锁死的条款

1. **书面规格书**：品种、等级、单果重区间、糖度、成熟度、包装箱规、净重/毛重。
2. **验货标准**：允许损耗比例（如到货坏果≤3%），超标怎么赔/补。
3. **价格结构**：是否含运费、装卸、税，报价是到岸价还是产地价。
4. **账期**：首单建议 **现款现货或先款后货**，别一开始就赊账。
5. **时效与冷链**：发货时限、运输方式、温度要求。
6. **退换货机制**：质量问题如何认定、谁承担运费。

## 四、执行流程

1. **索样/看货**：先要样品或产地实拍视频，别只看图片。
2. **小额下单**：按约定规格下单，留存聊天/合同记录。
3. **到货验收**：
   - 当场开箱抽检（按比例抽，如每托抽 3~5 箱）；
   - 记录：到货时间、温度、外观、坏果数、重量差；
   - **拍照/录像留证**，这是后续扯皮的依据。
4. **反馈与复盘**：每次试单后给供应商书面反馈，看对方改进态度。
5. **决策**：2~3 次试单后，符合标准再逐步放量，不要一次跳到满仓。

## 五、常见坑

- 只谈价格不谈损耗，最后损耗吃掉利润；
- 口头约定规格，到货“差不多”；
- 首单就大额预付，被卷款或发次货；
- 没有留证，出问题无法追责；
- 只看一次表现就签长期，忽略季节性波动。

## 六、一句话原则

**小批量、多频次、留证据、看响应**——试单是试“人+货+流程”，不是试“能不能便宜”。
