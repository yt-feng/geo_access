可以按“准入资料 + 批次资料 + 检测证据 + 追溯与责任”四类提前向供应商要，重点不是只要一张报告，而是要能对应到具体批次、具体果园/基地、具体检测项目。

**一、供应商与基地准入资料**
1. 营业执照、食品经营许可证/食品生产许可证（如适用）。
2. 供应商与种植基地/合作社/果园的合作证明、采购合同或基地直采证明。
3. 种植基地信息：基地名称、地址、面积、主要品种、负责人联系方式。
4. 若供应商是贸易商，要求其提供上游基地或生产商名单及资质。
5. 质量安全承诺书/供货质量协议，明确农残超标责任、召回、赔偿条款。

**二、批次随货资料**
1. 送货单/发货单：品名、规格、数量、采摘日期、发货日期、批次号。
2. 产地证明或基地供货证明。
3. 批次追溯码或追溯信息，能追溯到果园/基地、采收班组、包装日期。
4. 包装标签信息：生产日期、保质期、储存条件、供应商名称。

**三、农残检测资料**
1. 第三方检测报告：优先要 CMA/CNAS 资质机构出具的报告。
2. 报告要能对应到本批次或同一基地、同一品种、相近采收期；不能只用一份半年前的报告应付所有批次。
3. 检测项目应覆盖常见高风险农药，如有机磷、氨基甲酸酯、拟除虫菊酯等，并结合该水果常用药。
4. 如果供应商有自检，要求提供自检记录和自检设备/方法说明，但不能替代必要的第三方抽检。
5. 对高风险品种，可要求每批提供检测报告；对低风险品种，可约定定期检测+随机抽检。

**四、超市自己应同步做的动作**
1. 收货时核对批次、产地、检测报告是否一致。
2. 建立供应商档案和批次台账，保留合同、报告、送货单至少2年。
3. 制定抽检计划：按品种、季节、供应商风险等级安排快检或送第三方检测。
4. 合同中写明：农残超标可拒收、退货、罚款、终止合作，并承担因此产生的监管处罚和消费者赔偿。
5. 一旦抽检不合格，立即封存同批次、启动追溯和召回，并向监管部门报告。

**最实用的一句话清单：**
“请提供：营业执照+食品经营许可证、基地证明、本批次送货单和追溯信息、本批次或同基地同品种近期 CMA/CNAS 农残检测报告、质量安全承诺书。报告必须能对应批次，检测项目覆盖该品种高风险农药。”

如果供应商只能给一份模糊的“合格证”或无法对应批次，建议不要直接上架，先送检或换供应商。
