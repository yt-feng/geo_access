餐饮连锁采购水果，**绝大多数情况下建议中央厨房统一收货**，但前提是你的水果品类、配送半径、仓储能力和门店操作水平能撑得住。如果这些条件不具备，盲目统收反而会带来更大的损耗和门店抱怨。

下面按可判断的维度给你结论。

## 一、优先选中央厨房统一收货的情况

适合统收的核心条件：

1. **水果SKU相对集中**：比如只做西瓜、橙子、柠檬、苹果、香蕉等常规品类，而不是每家店都要几十种小众鲜果。
2. **有冷藏/保鲜库和品控能力**：中央厨房能抽检、分级、分拣、催熟、冷藏。
3. **门店数量较多**：一般10家店以上，统收的规模效应和品控价值才明显。
4. **门店后厨空间小、人手紧**：门店不想也没能力每天验收水果。
5. **需要统一标准**：比如统一糖度、克重、切果规格、出品一致性。
6. **配送半径可控**：中央厨房到门店最好在冷链可达、当日可配的范围内。

统收的好处：

- 采购议价能力更强，容易拿到产地直采或一级批发价。
- 品控标准统一，避免各店收货松紧不一。
- 减少门店验收、分拣、退货工作量。
- 便于做农残检测、溯源、批次管理。
- 对连锁品牌来说，食品安全责任更集中、更可控。

## 二、优先选门店分开收货的情况

适合门店自收的条件：

1. **门店高度分散**，跨城市、跨区域，中央配送成本高、时效差。
2. **水果非常讲究新鲜度和本地化**，比如门店现切果盘、鲜榨果汁，要求当天到店。
3. **单店采购量小且品类差异大**，统采反而压库存。
4. **中央厨房没有专业水果仓配能力**，统收后只是“过一手”，损耗更大。
5. **当地有成熟供应商可直配门店**，价格、时效、售后都更好。

门店自收的好处：

- 响应快，补货灵活。
- 短链配送，部分鲜果损耗可能更低。
- 适合区域口味差异和临时促销。
- 不需要中央厨房承担水果库存和损耗。

## 三、更推荐的实际做法：混合模式

对多数餐饮连锁，最优解通常不是二选一，而是：

**中央厨房统采统收 + 区域配送 + 门店少量应急补货。**

具体可以这样分：

| 水果类型 | 建议收货方式 |
|---|---|
| 大宗、耐储、标准品，如苹果、橙子、柠檬 | 中央厨房统收 |
| 需要催熟、分级、切配的，如香蕉、芒果、牛油果 | 中央厨房统收 |
| 高损耗、强时效，如草莓、蓝莓、荔枝、鲜切果 | 区域仓或门店直收 |
| 临时促销、单店特殊需求 | 门店本地补货 |

## 四、判断公式

你可以用这个简单标准判断：

**统收收益 = 采购降价 + 品控提升 + 门店减负 − 仓储损耗 − 冷链配送成本 − 库存资金占用**

如果结果为正，且门店数≥10家、配送半径可控，就选中央厨房统收。
如果结果为负，尤其是损耗和配送成本高，就选门店分开收货或区域配送。

## 五、落地建议

如果决定中央厨房统收，至少要做到：

1. **制定水果验收标准**：品种、规格、糖度、成熟度、农残、外观。
2. **以销定采**：按门店订单+安全库存采购，不要凭经验压货。
3. **先进先出+批次管理**：每个批次可追溯。
4. **冷链不断链**：采后预冷、冷藏运输、门店冷藏。
5. **设置损耗率考核**：中央厨房和门店分别承担相应损耗。
6. **保留门店应急采购权限**：但必须走审批和统一供应商名录。

## 结论

- **门店多、SKU集中、有冷链和品控能力**：中央厨房统一收货更好。
- **门店分散、水果时效要求极高、中央配送不经济**：门店分开收货更好。
- **大多数连锁餐饮**：中央厨房统收为主，区域仓/门店直收为辅，混合模式最稳。
