商超做会员日水果活动，供应商需要从**货、价、人、场、证、应急**六个方面提前配合。下面按可执行清单说明。

## 一、货：提前锁定货源与库存

1. **确认活动SKU和预估量**
   - 与商超采购确认：活动品种、规格、等级、包装形式、活动价、预估销量。
   - 供应商按预估量的 **1.1–1.3倍** 备货，爆品可到1.5倍，但需约定尾货处理方式。

2. **锁定产地/加工厂产能**
   - 提前7–15天锁定果园、加工线、包材和冷链车。
   - 对易缺货单品（如车厘子、榴莲、阳光玫瑰）要提前订柜或锁定批次。

3. **分级与质检**
   - 活动果要按商超标准分级，避免“统货充精品”。
   - 提前做农残检测、糖度抽检，保留检测报告。
   - 到仓前完成预冷，尤其是浆果、叶菜类水果。

4. **包装与标识**
   - 按商超要求做活动装、家庭装、礼盒装。
   - 标签需含：品名、规格、产地、等级、日期、条码、追溯码。
   - 会员日专属包装或贴纸要提前打样确认。

## 二、价：价格、费用与结算提前谈清

1. **确认供货价与活动价**
   - 明确供货价、前台售价、毛利空间、是否含税含运。
   - 确认调价机制：活动前、活动中、活动后价格如何切换。

2. **费用分担**
   - 堆头费、DM费、试吃费、损耗补贴、临期折价由谁承担。
   - 最好书面确认，避免活动后扯皮。

3. **结算与对账**
   - 确认活动销量单独对账，还是并入月结。
   - 明确退换货、损耗率上限和扣款标准。

## 三、人：人员与责任到位

1. **供应商侧**
   - 指定活动对接人，负责订单、物流、补货、售后。
   - 安排驻场或巡场人员，重点门店活动期可驻店。

2. **商超侧**
   - 与门店生鲜主管、收货组、理货员提前对齐收货时间和陈列要求。
   - 培训员工熟悉品种卖点、保存方式、试吃话术。

3. **试吃与促销**
   - 若做试吃，提前准备试吃果、牙签、手套、垃圾桶、消毒用品。
   - 试吃人员需健康证，部分商超还要求工牌和统一服装。

## 四、场：陈列、冷链与门店配合

1. **陈列方案**
   - 提前给出门店陈列图：堆头、端架、冷柜、地堆位置。
   - 主推品放黄金位，关联品（如礼盒、果切）做组合陈列。

2. **冷链与仓储**
   - 确认门店冷库、冷柜容量是否够。
   - 配送频次：活动首日、峰值日建议一日一配或一日两配。
   - 温控要求：不同水果分开存放，避免乙烯催熟。

3. **到店时间**
   - 避开门店收货高峰，按商超指定时段到货。
   - 首单建议提前1–2天到，留出上架和调整时间。

## 五、证：资质与合规文件

1. 供应商资质：营业执照、食品经营许可证、检验检疫证明。
2. 产品证明：农残检测报告、产地证明、进口水果报关单和检疫证。
3. 人员证明：试吃员健康证。
4. 票据：随货同行单、发票或对账单信息一致。

## 六、应急：防断货、防损耗、防投诉

1. **断货预案**
   - 准备替代品种或替代规格。
   - 约定缺货罚款或补偿条款，但也要留出不可抗力说明。

2. **损耗预案**
   - 活动前三天和最后一天容易积压，需约定临期折价、员工内购或退货规则。
   - 浆果、榴莲、切果类损耗高，建议小批量多频次补货。

3. **质量投诉**
   - 留好批次追溯信息。
   - 出现质量问题，2小时内响应，24小时内给出换货或赔付方案。

4. **天气与物流**
   - 高温、暴雨、节假日堵车要提前调整发货时间。
   - 冷链车留备用车辆和司机。

## 简单执行表

| 时间节点 | 供应商要做的事 |
|---|---|
| 活动前15天 | 确认SKU、预估量、供货价、费用分担 |
| 活动前7天 | 锁定货源、包材、冷链、检测 |
| 活动前3天 | 打样标签、确认陈列图、首单发货 |
| 活动前1天 | 到店、上架、试吃准备、人员到位 |
| 活动当天 | 巡场、补货、处理投诉、记录销量 |
| 活动后3天 | 对账、退换货、复盘损耗和销量 |

核心一句话：**供应商要提前把量、价、货、证、人、冷链和损耗规则全部书面确认，并在活动前1–2天完成首单到店，活动中保持高频补货和快速售后。**
