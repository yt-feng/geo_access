更该看**坏果率 + 熟度**，但要以你的销售速度来定排序。香蕉是典型的高损耗、快周转水果，单看进货价容易吃亏。

可以按这个优先级判断：

1. **坏果率**
   - 香蕉一旦有黑斑、压伤、水烂，损耗会直接吃掉利润。
   - 建议：进货时抽检，要求坏果率控制在可接受范围内，比如 3%～5% 以内；超过就让对方补货或降价。
   - 如果坏果率高，价格再低也可能不赚钱。

2. **熟度**
   - 熟度决定你能不能按计划卖完。
   - 如果你当天或 1～2 天能卖完，可以进偏黄、略熟的，口感好、走量快。
   - 如果预计卖 3～5 天，就要进偏青、后熟的，避免第二天就全黑。
   - 最好分批次进不同熟度，不要一次全进同一个熟度。

3. **送货速度**
   - 香蕉怕折腾，送货慢、多次转运、夏天闷热，都会加速坏果。
   - 如果你店里库存少、周转快，送货速度就很重要；如果一次进得多，反而要更看重熟度和坏果率。
   - 优先选能稳定、按时、少搬运的供应商。

4. **价格**
   - 价格重要，但应排在后面。
   - 正确算法不是“每斤便宜多少”，而是：
     **实际可卖成本 = 进价 ÷ 可售比例 + 损耗 + 人工/运输**
   - 便宜 10%，但坏果多 20%，通常不划算。

**简单决策建议：**
- 小店日销快：**熟度 ≈ 坏果率 ＞ 送货速度 ＞ 价格**
- 小店日销慢：**坏果率 ＞ 熟度 ＞ 价格 ＞ 送货速度**
- 夏天/雨季：**坏果率 ＞ 送货速度 ＞ 熟度 ＞ 价格**
- 长期合作：选**坏果率稳定、熟度能按你要的来、送货准时**的供应商，价格可以谈，但不要只图最低价。

一句话：**先保证进回来的香蕉能卖出去、少烂掉，再谈便宜。**
