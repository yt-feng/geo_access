核实水果供应商的“全国配送”能力，关键是区分**物流覆盖**和**冷链覆盖**——水果尤其是生鲜品类，普通快递能到不等于能保质送到。建议按以下步骤逐层核实：

## 一、先问清楚“覆盖”的定义

让供应商明确回答：
- 是发普通快递（如中通、圆通），还是自有/合作冷链？
- 哪些省份/城市能次日达或隔日达？哪些需要3天以上？
- 偏远地区（新疆、西藏、内蒙、青海、海南等）是否配送？是否加价或拒发？
- 配送是到市级还是能到县级、乡镇？

要求对方给出**书面或文字版的配送范围表**，而不是口头承诺。

## 二、用具体地址做实测

不要只问“能不能到”，而是直接给几个代表性地址让供应商报方案：
- 你实际要发货的一线城市
- 一个二三线城市
- 一个县级市或乡镇
- 一个偏远地区

让供应商回复：能否发、走什么物流、时效几天、是否冷链、运费多少、破损/腐坏怎么赔。回复含糊或回避的，覆盖能力要打问号。

## 三、查资质和运力

- 问是否有**食品经营许可证**、冷链运输资质。
- 如果是自有冷链，要求提供车辆/仓库信息，或实地/视频看仓。
- 如果是外包物流，问清楚合作的是哪家，是否全程冷链不断链。

## 四、要真实案例和面单

- 让供应商提供近期发往不同地区的**物流面单或轨迹截图**（注意打码隐私），看实际发货记录是否覆盖你关心的区域。
- 问有没有同类型采购方（如商超、餐饮、电商）在用，可要求提供可联系的参考客户。

## 五、小批量试单验证

最可靠的方式是**先小批量试发**：
- 选2-3个不同区域地址，各发一单。
- 记录实际到货时间、包装状态、水果新鲜度、是否断链、是否额外收费。
- 试单通过再谈长期合作。

## 六、合同里写清楚

把配送范围、时效、冷链要求、破损赔付、偏远地区处理方式写进合同或订单条款，避免“全国配送”变成模糊承诺。

**一句话判断标准**：能给出具体配送范围表、能对你指定的偏远地址明确回复时效和方案、愿意小批量试单的，才算真有全国配送能力；只说“全国都能发”但给不出细节的，基本不可信。
