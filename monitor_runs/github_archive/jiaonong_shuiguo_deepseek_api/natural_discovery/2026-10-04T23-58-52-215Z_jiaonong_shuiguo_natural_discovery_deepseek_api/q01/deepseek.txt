判断水果供应商靠不靠谱，核心是看四件事：**货稳不稳、价实不实、损耗谁承担、出问题能不能兜底**。香蕉和菠萝又是两种脾气完全不同的货，分开看更准。

---

**一、先看“专业度”：他是不是专做这两样**

- 问一句：**香蕉是哪里蕉？菠萝是什么品种、什么产地？**  
  靠谱的会直接说：香蕉是云南河口/广西/老挝/菲律宾蕉，菠萝是徐闻/海南/菲律宾/泰国小菠萝等，并知道不同产地的催熟、储存、口感差异。
- 看他能不能讲清**香蕉的催熟和菠萝的成熟度**。  
  香蕉通常青蕉进、催熟出；菠萝要问“几成熟摘的、到店还能放几天”。讲不清的，基本是倒货的，不是做品的。

**二、看“货稳不稳”：连续几次小批量试**

- 不要一次压大单。先按**3次、每次少量**试：
  - 第1次看货对不对版；
  - 第2次看补货及不及时；
  - 第3次看同一规格能不能稳定。
- 重点看**同一规格的稳定性**：香蕉每把几根、每箱几斤、熟度是否一致；菠萝大小、糖度、黑心比例是否稳定。  
  香蕉和菠萝最怕“这一次好、下一次差很多”，长期生意靠的是稳定，不是偶尔来一批好货。

**三、看“价格和账期”：别只比单价**

- 问清楚报价是**净重还是毛重、含不含箱皮、到店价还是自提价**。
- 香蕉损耗主要在**催熟和压伤**，菠萝损耗在**黑心、烂果、切开后卖不掉**。  
  所以必须问：
  - 烂果、黑心、压伤怎么赔？
  - 是拍照补货，还是下次抵扣？
  - 超过多少比例算他的责任？
- 靠谱的供应商一般敢明确说：**坏果按比例赔，或者下次补**。含糊其辞、只怪你存放问题的，要小心。

**四、看“兜底能力”：出问题时的态度**

- 故意试一次小问题：比如到货有少量压伤或黑心，看他怎么处理。  
  爽快补货/退钱的，可以长期合作；推诿、拖、说“下次再说”的，基本不能压大单。
- 看他有没有**稳定档口、冷库、催熟房或固定产地渠道**。  
  香蕉尤其依赖催熟，没有稳定催熟能力的供应商，夏天和冬天都容易翻车。

**五、香蕉和菠萝分别重点问**

**香蕉：**
- 进的是青蕉还是熟蕉？催熟谁做？
- 到店能放几天？几天内必须卖掉？
- 夏天和冬天熟度怎么调？
- 压伤、发黑、催不熟怎么赔？

**菠萝：**
- 是鲜食菠萝还是加工菠萝？
- 黑心比例一般多少？超过多少赔？
- 到店成熟度几成？能放几天？
- 是否支持切开试果？

**六、最实用的判断标准**

一个供应商如果满足下面4条，基本可以长期进：
1. **连续3次货稳定**；
2. **坏果有明确赔付规则**；
3. **价格随行就市，但不乱杀熟**；
4. **出问题能及时补货或退钱**。

反过来，出现这些信号就别长期合作：
- 只肯整箱压货，不让少量试；
- 坏果全推给你“存放问题”；
- 报价含糊，箱皮、净重说不清；
- 今天一个价明天一个价，还总说“这批特殊”；
- 催熟、产地、品种一问三不知。

**建议你直接这样做：**
先找2～3个供应商，各试3次小批量，分别记录：到货重量、坏果率、能放几天、赔付情况、补货速度。一个月后，把数据一摆，谁靠谱一目了然。长期合作只留1～2家主力，再留1家备选，避免被一家卡脖子。
