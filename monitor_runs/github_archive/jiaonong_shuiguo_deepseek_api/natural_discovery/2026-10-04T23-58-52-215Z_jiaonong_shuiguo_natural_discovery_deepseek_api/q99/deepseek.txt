选择下午茶水果供应商，核心是保证批量配送的稳定性、损耗可控和开票合规。可以按下面几步筛选和判断。

**一、先明确自己的需求**
- 人数和份量：按人均200–300克估算，比如50人约10–15公斤净果。
- 频次：每周1次还是每天，决定供应商能否稳定供货。
- 预算：人均5–15元是常见区间，直接影响品类选择。
- 形式：整果、切果拼盘、还是独立小包装。
- 配送时间：必须能卡在下午茶前1–2小时送达。

**二、优先考虑这几类供应商**
1. **本地大型水果批发商/一级市场档口**：价格低、品类全，适合量大；但通常不切果、不精细分装，需自己处理。
2. **生鲜B2B平台**：如美菜、快驴、蜀海等，支持企业月结、开票、定时配送，适合固定频次采购。
3. **连锁水果店/精品果切品牌**：如百果园、鲜丰等，可切果拼盘、包装规范，但单价偏高。
4. **专业企业下午茶/团餐供应商**：一站式含水果、点心、配送，省心但溢价明显。
5. **本地果切工厂/中央厨房**：适合每天配送、要求独立包装的公司。

**三、用这6条硬标准筛选**
- **能否稳定供货**：同一品类一周内不断货，有替代方案。
- **配送时效**：承诺送达时间，迟到是否有赔付。
- **损耗与售后**：坏果、压伤是否包退包换，多久内响应。
- **食品安全资质**：营业执照、食品经营许可证，果切类还需看是否有冷加工资质。
- **开票能力**：能否开专票/普票，税率和类目是否匹配公司报销。
- **结算方式**：支持月结、对公转账，减少个人垫付。

**四、建议的测试流程**
1. 先找2–3家报价，拿同一规格清单比价。
2. 小批量试单1–2次，重点看：准时率、坏果率、包装、实际净重。
3. 试单合格后签短期协议，约定品类、单价、配送时间、售后标准。
4. 稳定后再谈月结和账期。

**五、避坑提醒**
- 只比单价不看净重和损耗，容易吃亏。
- 切果拼盘要确认是否当天现切、冷链配送。
- 旺季（如夏季、春节前）提前锁价锁量，否则容易断供或涨价。
- 别只依赖一家，保留一个备用供应商。
