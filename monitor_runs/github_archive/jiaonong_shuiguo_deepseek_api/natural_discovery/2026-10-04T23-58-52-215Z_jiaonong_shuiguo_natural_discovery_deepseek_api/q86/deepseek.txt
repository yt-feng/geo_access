生鲜平台做水果一件代发，供应商需要具备的核心仓配能力可以拆成四块：**仓、配、包、逆向**。

**一、仓储能力**

- **产地仓/销地仓布局**：水果一件代发通常有两种模式。产地直发（如新疆哈密瓜、赣南脐橙）要求供应商在产区有仓，能就近采摘、分选、打包；销地仓模式则要求供应商在平台主要销售区域有分仓，缩短时效。
- **温控能力**：不同水果对温度要求差异大。浆果类（草莓、蓝莓）需冷藏，热带水果（芒果、香蕉）需恒温或催熟管理，普通柑橘类可常温。仓库需有分区温控，而不是一个冷库通吃。
- **库存管理与批次追踪**：水果保质期短，必须做到先进先出、按批次管理，能追溯采摘/入库日期。系统需与平台对接，实时同步库存，避免超卖后发不出货。
- **日处理订单能力**：一件代发是散单，不是整箱批发。供应商需要能承接日均几百到几万单的拣货、打包产能，峰值（大促、节日）要有弹性。

**二、配送能力**

- **快递资源与协议价**：水果一件代发主要走快递。供应商需有稳定的快递合作，尤其是能发往全国主要城市的时效件。偏远地区、高温季节的配送方案要提前明确。
- **时效承诺**：平台通常要求 48h/72h 达。供应商要能给出不同区域的时效标准，并且实际达成率可考核。产地直发到偏远地区时效会明显拉长，需要提前在商品页或规则中约定。
- **冷链/保温包装配送**：对温度敏感的水果，需要泡沫箱+冰袋+保温袋的组合，且要验证在途温度是否可控。夏季高温线路可能需要冷链快递或航空件。
- **异常处理**：快递延误、破损、丢失的响应机制。供应商要有专人对接快递客服，能主动拦截、改址、补发。

**三、包装能力**

- **防损包装设计**：水果易碰伤，需要按品类设计内衬、隔板、网套、气柱袋等。包装要能通过跌落测试或实际运输测试。
- **标准化打包流程**：一件代发的包装必须标准化，否则效率低、损耗高。包括称重、贴单、封箱、交接快递的流水线作业。
- **耗材供应稳定性**：泡沫箱、冰袋、纸箱等耗材要能稳定供应，大促前提前备货。

**四、逆向与售后能力**

- **坏果包赔的履约能力**：平台通常要求坏果包赔。供应商需要能按比例赔付或补发，且有拍照/视频审核流程，防止恶意索赔。
- **退货处理**：水果退货成本高，通常不支持无理由退货，但质量问题需要补发或退款。供应商要有快速补发通道。
- **数据反馈**：能提供损耗率、时效达成率、坏果率等数据，供平台考核和优化。

**判断供应商是否合格，可以重点看几个硬指标：**

1. 是否有对应品类的温控仓，而不是普通仓库。
2. 日均散单处理能力是否匹配平台预估单量，峰值能否翻倍。
3. 快递时效达成率和坏果率的历史数据。
4. 是否支持平台系统对接（订单、库存、物流轨迹）。
5. 坏果包赔的响应速度和补发时效。

如果供应商只具备“有货、能发快递”，但缺少温控、标准化包装和售后响应，一件代发的体验会很快崩掉，平台端会集中收到坏果和时效投诉。
