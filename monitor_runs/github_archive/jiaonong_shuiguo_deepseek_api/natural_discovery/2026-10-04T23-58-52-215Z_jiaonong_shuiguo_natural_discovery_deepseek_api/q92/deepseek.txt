小面积便利店做水果，核心逻辑不是“品类齐全”，而是**少SKU、高频补、快周转、敢下架**。下面给你一套可直接执行的做法。

## 一、先定品类策略：只做“顺手买”的水果

小店面水果区通常只有1–3个货架或1个冷柜，建议控制在**6–10个单品**，最多不超过12个。

**优先选这四类：**

1. **即食型**：香蕉、苹果、橘子、猕猴桃、小番茄  
2. **小份型**：单个苹果、2个装猕猴桃、小盒蓝莓、小份葡萄  
3. **高频型**：香蕉、苹果、橘子、梨  
4. **场景型**：早餐搭配（香蕉+酸奶）、下午茶（小番茄+蓝莓）、解酒/送礼（小份礼盒，仅节假日）

**不建议做：**
- 整颗大西瓜、整箱葡萄、榴莲、菠萝蜜等大体积或高损耗品
- 需要现场切配的果切（除非有冷柜+专人+高周转）
- 低频高价进口水果，除非周边客群明确且稳定

**品类结构建议：**
- 引流款：香蕉、橘子（1–2个，价格敏感）
- 利润款：蓝莓、猕猴桃、小番茄（2–3个）
- 便利款：苹果、梨、即食小份（2–3个）
- 季节款：只保留1–2个应季单品，过季立即换

## 二、采购控制：用“少量多补”代替“一次囤足”

小店面最怕一次性采购过多。建议按以下规则执行：

1. **首单试销**：每个新品只进**最小包装单元**，比如1箱或1盒，先卖3天。
2. **按销量补货**：  
   - 日销>5份：每天补  
   - 日销2–5份：隔天补  
   - 日销<2份：7天内淘汰，不再补
3. **补货量公式**：  
   **次日补货量 ≈ 前3天日均销量 × 1.2 – 当前库存**  
   宁可少补，不要多补。
4. **采购频次**：能每天补就每天补；至少**每周2–3次**，避免一次进一周的量。
5. **供应商选择**：优先本地批发市场或能小批量配送的供应商，接受单价略高，换取低库存风险。

## 三、损耗控制：从收货到出清全流程

### 1. 收货环节
- 当场验货：烂果、压伤、过熟直接拒收或折价。
- 按“先进先出”上架，新货放里面，旧货放外面。
- 香蕉、猕猴桃等后熟水果，未熟时常温，熟后转冷柜或打折区。

### 2. 陈列环节
- 不要堆叠过厚，水果怕压。
- 每层只摆**1–2层**，减少翻动损伤。
- 冷柜温度：多数水果**4–8℃**；香蕉、芒果等热带水果不宜久放冷柜。
- 每天至少**2次挑拣**，把软伤、过熟挑出，避免传染。

### 3. 定价与出清
- 正常价：前70%销售期
- 微瑕价：出现轻微软伤时，**8折**快速出
- 出清价：临近保质期或过熟，**5–6折**，放在收银台附近
- 不可售：立即下架，不要留在货架影响观感

**关键原则：**  
**损耗不是“扔出来的”，是“拖出来的”。**  
该打折时立刻打折，比最后扔掉更划算。

### 4. 每日动作清单
- 早上：收货、挑拣、上架、标价
- 中午：翻堆、挑软伤、补货
- 晚上：出清、记录销量、决定次日补货
- 闭店前：将易损水果转冷藏或处理

## 四、用数据盯住3个指标

1. **动销率**：某单品3天没卖动，直接淘汰。
2. **损耗率**：水果整体损耗控制在**5%–8%**以内；超过10%说明品类或补货有问题。
3. **毛利额**：不要只看毛利率。小店面要算**毛利额 = 销量 × 单件毛利**，低毛利但高周转的香蕉、橘子也值得做。

## 五、最简执行方案（可直接照做）

- SKU：6–8个
- 核心单品：香蕉、苹果、橘子、小番茄、猕猴桃、蓝莓
- 采购：每周2–3次，每次只补3天量
- 陈列：1–2层，不堆高
- 挑拣：每天2次
- 出清：微瑕8折，过熟5折，不可售立即扔
- 淘汰：3天不动销就换品
- 目标：损耗≤8%，水果区面积不超过门店10%
