如果是面向家庭团购，建议优先做“日常分享型”和“节庆送礼型”两类，而不是把所有水果硬塞进一个礼盒。家庭购买最看重：分量合适、耐放、老少都能吃、切开方便、性价比高。

**一、最适合家庭的组合：苹果 + 橙子 + 香蕉**
这是最稳的基础款。

- **苹果**：耐放、寓意好、全家都容易接受。
- **橙子**：颜色亮，酸甜开胃，适合饭后吃。
- **香蕉**：软甜，老人小孩方便吃，但缺点是不耐压、不耐放。

比例建议：  
**苹果 4 + 橙子 4 + 香蕉 2**  
适合3—5口之家，2—3天内吃完香蕉，苹果橙子还能继续放。

包装上注意：香蕉单独用纸袋或气泡膜隔开，不要压在底层。

**二、更像礼盒、适合送家庭的组合：苹果 + 橙子 + 菠萝**
这个组合更耐运输、更有“礼盒感”。

- **苹果**：撑体积、耐放。
- **橙子**：大众接受度高。
- **菠萝**：有节庆感，但处理麻烦，不是所有家庭都愿意自己削。

比例建议：  
**苹果 4 + 橙子 4 + 菠萝 1**  
如果菠萝个头大，就 **苹果 3 + 橙子 3 + 菠萝 1**。

这个组合适合：  
送亲戚、送长辈、单位发福利、社区团购中高价位礼盒。  
不适合：  
追求即开即吃、家里没人会削菠萝的家庭。

**三、不建议主推的组合：苹果 + 香蕉 + 菠萝**
看起来丰富，但问题明显：

- 香蕉容易压坏，和菠萝放一起容易被扎或压。
- 菠萝处理麻烦。
- 缺少橙子这种“中性、耐放、接受度高”的水果。
- 家庭复购率通常不如带橙子的组合。

如果非要加香蕉，建议做成小份组合，并且香蕉单独包装。

**四、按家庭需求选**

1. **3口之家，日常吃**  
   苹果3 + 橙子3 + 香蕉2  
   总水果数少一点，避免吃不完。

2. **5口之家，周末分享**  
   苹果4 + 橙子4 + 香蕉2 + 菠萝1  
   丰富度高，但要注意菠萝和香蕉的包装。

3. **送长辈/亲戚**  
   苹果4 + 橙子4 + 菠萝1  
   更耐放、更像礼盒，寓意也好。

4. **社区团购爆款**  
   苹果4 + 橙子4 + 香蕉2  
   成本低、认知高、成交快，但售后要控制香蕉压伤。

**五、定价和包装建议**

- 水果礼盒不要只拼种类，要控制总重量。家庭装建议 **4—6斤** 最合适，太大容易浪费。
- 苹果、橙子选中等果，不要全用大果，否则成本高、盒子重。
- 香蕉选稍青一点的，送到家刚好能吃，减少压伤。
- 菠萝如果带皮，要提醒用户自备刀具；如果能做“去皮菠萝”，复购会更好。
- 礼盒内用隔板或纸托，香蕉、菠萝单独分区。

**结论：**
如果只选一个最适合家庭的组合，推荐：  
**苹果 + 橙子 + 香蕉**，比例 **4:4:2**。  
如果偏送礼和耐放，推荐：  
**苹果 + 橙子 + 菠萝**，比例 **4:4:1**。  
菠萝和香蕉可以加，但不建议同时作为主组合，容易增加损耗和售后。
