商超采购香蕉时，判断催熟能力是否稳定，核心不是只看“这批黄不黄”，而是看供应商/催熟商能否在不同批次中把成熟度、时间窗和货架表现控制在一个可预测区间内。可以从以下几个可执行维度判断：

1. **看批次一致性，而不是单批表现**
   - 连续跟踪3—5批同一产地、同一供应商的香蕉：
     - 到货青度是否接近；
     - 催熟后转黄时间是否接近；
     - 同批果实成熟是否均匀；
     - 到店后第2—4天是否集中出现黑斑、软烂或青硬不熟。
   - 如果每批差异都很大，说明催熟能力不稳定，而不是偶发问题。

2. **看催熟记录是否可追溯**
   - 稳定供应商通常能提供：
     - 催熟温度、湿度、乙烯浓度/熏蒸时间；
     - 催熟批次号、入库时间、出库时间；
     - 目标成熟度，如几号色、几成熟。
   - 若供应商只说“自然熟”“放药了”，但拿不出参数记录，稳定性通常难保证。

3. **用“色卡+硬度+时间”做三方验证**
   - 采购现场可用香蕉色卡判断成熟阶段，从1号绿到7号黄。
   - 同时按压果身中段，记录硬度变化。
   - 关键看：
     - 从青到可售黄的时间是否稳定；
     - 达到可售成熟度后，能否维持2—3天良好货架期；
     - 是否出现“外表黄、果心硬”或“外皮好、果肉已烂”的脱节。

4. **看同箱、同托盘内的均匀度**
   - 随机抽几箱、几层、几个位置：
     - 箱内上下层成熟度是否差太多；
     - 托盘边角和中心温度是否差异大；
     - 果指大小、饱满度是否混杂。
   - 催熟稳定的货，同批内差异应可控；差异过大，说明催熟房管理或冷链不均匀。

5. **看到货后的“后熟曲线”**
   - 采购不能只看收货当天，要看到店后表现：
     - 第1天：青黄比例；
     - 第2天：转黄是否均匀；
     - 第3天：是否达到销售峰值；
     - 第4天：是否开始快速起斑、软化。
   - 如果每批峰值时间飘忽，门店排面、促销和损耗都会失控。

6. **看损耗和投诉数据**
   - 稳定催熟能力的直接结果：
     - 次果率低；
     - 黑斑、裂果、青硬果少；
     - 门店报损稳定；
     - 顾客投诉“买回去不熟”或“第二天就烂”少。
   - 建议按供应商、产地、季节做月度对比。

7. **做小批量对比测试**
   - 新供应商不要一上来全量采购。
   - 同一时间采购2—3家样品，在相同门店条件下观察5—7天。
   - 记录：
     - 转黄天数；
     - 均匀度；
     - 货架期；
     - 损耗率；
     - 口感。
   - 稳定者再放量。

8. **关注季节和产地切换**
   - 香蕉催熟稳定性很受产地、季节、运输冷链影响。
   - 菲律宾、厄瓜多尔、越南、国产等不同来源，催熟参数需求不同。
   - 如果供应商在换季、换产地时仍能保持相似到店表现，说明其催熟体系较成熟。

简单判断标准：
- **稳定**：连续多批转黄时间接近，同批均匀，到店后2—3天货架表现可预测，损耗低。
- **不稳定**：批次间差异大，同箱成熟不匀，常出现青硬、假熟、快速腐烂，门店损耗波动大。

采购时可直接问供应商四个问题：
1. 最近5批的催熟参数和到店成熟度记录能否提供？
2. 同批香蕉从催熟出库到门店销售峰值通常几天？
3. 换产地或换季节时，参数怎么调整？
4. 如果到店后成熟不匀，责任和补损机制是什么？

能清楚回答并持续用数据验证的，催熟能力通常更稳定。
