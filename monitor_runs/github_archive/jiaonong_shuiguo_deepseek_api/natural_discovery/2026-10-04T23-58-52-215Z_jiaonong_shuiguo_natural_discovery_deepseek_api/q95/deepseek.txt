学校食堂采购水果，重点不是“找最便宜的”，而是找**能稳定供货、质量可控、票据齐全、出问题能追责**的供应商。香蕉、苹果、橙子都属于高频大宗水果，建议按下面思路选。

**一、先定采购标准，再谈供应商**
不要只写“新鲜香蕉、苹果、橙子”，要写成可验收的标准：
- 香蕉：八成熟左右，无黑斑腐烂，单根无明显压伤，到货后能放1—2天。
- 苹果：大小相对均匀，无烂心、无大面积碰伤，硬度正常，品种固定。
- 橙子：无发霉、无干瘪，表皮无明显药斑，规格按直径或重量分档。
- 统一要求：农残检测合格或承诺达标，坏果率低于约定比例，比如到货验收坏果超过5%可退换。

**二、供应商来源优先级**
1. 本地大型农产品批发市场有固定档口的商户：响应快，适合小批量、多频次。
2. 果蔬配送公司：能开票、有分拣、能按学校时间送，适合长期合作。
3. 生产基地或合作社直供：价格可能好，但品种单一，配送能力要核实。
4. 电商平台或连锁供应链：流程规范，但价格和售后要对比。

学校食堂一般建议选**1家主供应商+1家备选供应商**，避免单一供应商断供。

**三、重点核验这几项**
- 营业执照、食品经营许可证或相关资质。
- 水果来源证明、进货票据、农残检测报告或承诺书。
- 配送车辆是否清洁，是否生熟分开，是否有防雨防尘措施。
- 是否能按约定时间送到，比如每天早上6:30前到校。
- 是否有固定联系人，坏果、少斤短两能不能当天补换。
- 结算方式、账期、发票类型是否清楚。

**四、比价不要只看单价**
建议用“综合到校价”比较：
- 单价
- 损耗率
- 配送费
- 退换货成本
- 开票成本
- 账期资金成本

比如A家单价低但坏果多、不能开票，实际可能比B家更贵。

**五、试用和考核**
先让供应商试供1—2周，重点看：
- 到货准时率
- 验收合格率
- 坏果处理速度
- 票据是否齐全
- 学校临时加单能不能配合

考核合格再签长期合同。合同里写清：品名、规格、单价或调价机制、送货时间、验收标准、退换货规则、食品安全责任、违约处理。

**六、简单可执行的选法**
可以让3家供应商同时报价同一规格的香蕉、苹果、橙子，连续试供一周，按“质量40%、价格30%、配送20%、资质售后10%”打分，得分最高者为主供应商，第二名备选。

核心就一句：**先定验收标准，再找有资质、能开票、能稳定配送的供应商，用试供和考核决定长期合作。**
