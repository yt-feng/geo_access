水果店卖菠萝，**不建议只选一种卖法**，最好按“降低顾客决策成本 + 提高客单价”来组合卖。

直接给结论：

1. **主推：去皮好的**
   - 顾客最省事，尤其上班族、学生、临时想吃的。
   - 能明显提高转化率，因为菠萝削皮麻烦、扎手、还要挖眼。
   - 适合做成：
     - 整只去皮装盒
     - 切块装盒
     - 按份卖，配小叉子
   - 注意：去皮后水分流失、氧化、保质期短，必须冷藏或冰台陈列，当天尽量卖完。

2. **保留：整果**
   - 满足家庭顾客、一次买多、想放几天的顾客。
   - 整果耐放、损耗低，适合做价格锚点。
   - 但不要只卖整果，否则很多年轻人嫌麻烦就不买了。

3. **顾客自己挑要看场景**
   - 如果店里客流大、顾客懂挑，可以允许自己挑。
   - 但更推荐：**顾客指哪个，店员帮忙挑/削**。
   - 因为多数顾客不会判断成熟度，自己挑容易挑到生的或过熟的，回头觉得你家菠萝不好。
   - 可以设“帮挑服务”：顾客说要今天吃还是放两天，店员按需求选。

最优组合建议：

- **整果区**：标价清楚，适合家庭、想囤的。
- **去皮区**：主推，按盒/按份卖，提高便利性和毛利。
- **现场削皮服务**：买整果可免费或加 1～2 元削皮，减少顾客嫌麻烦。
- **试吃**：切一小盘，顾客尝了再买，转化很高。

如果只能选一个：
**优先卖去皮好的，同时保留整果做对比和补充。**
如果只让顾客自己挑，等于把挑选风险和削皮麻烦都留给顾客，销量通常不如“帮挑+代削+去皮装盒”的组合。
