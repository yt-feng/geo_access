生鲜水果到货后出现坏果，责任划分通常要看**坏果产生的时间点、原因、以及平台/商家的承诺**。可以按下面几个层面判断：

## 1. 先看坏果是什么原因造成的

**（1）发货前就已经坏了或品控不合格**
- 比如装箱时就有霉变、压伤、过熟。
- 责任在商家/供应商，属于商品质量问题。
- 顾客有权要求退款、补发或赔偿。

**（2）运输过程中造成的**
- 比如冷链断链、挤压、暴晒、配送延误。
- 如果商家自己发货并选择物流，通常由商家先对顾客负责，商家再向物流追偿。
- 如果是平台配送，平台通常要承担配送环节责任。
- 如果是顾客自己选的第三方物流，责任划分会更复杂，但商家仍可能因包装不当承担部分责任。

**（3）顾客收货后存放不当或超过售后时限**
- 比如放到第二天才开箱、没有冷藏、签收后长时间未处理。
- 这种情况商家责任会减轻，甚至不承担。
- 但前提是商家事先有明确提示，比如“签收后24小时内售后”“需冷藏”。

**（4）自然损耗与个别坏果**
- 生鲜水果允许有一定比例的自然损耗，但“允许损耗”不等于可以大量坏果。
- 如果只是个别轻微碰伤，通常协商部分补偿；如果坏果比例高，应视为质量问题。

## 2. 责任划分的常见规则

| 情形 | 主要责任方 | 顾客可主张 |
|---|---|---|
| 到货即大量坏果、霉变 | 商家/供应商 | 退款、补发、赔偿 |
| 运输挤压、延误导致坏果 | 商家或平台先赔，再向物流追偿 | 退款、补发 |
| 顾客未及时取货/存放不当 | 顾客 | 可能无法全额赔 |
| 平台承诺“坏果包赔” | 平台/商家按承诺执行 | 按承诺赔付 |
| 顾客自己选物流且包装合格 | 视合同和过错划分 | 向物流或商家主张 |

## 3. 关键判断标准

1. **开箱时间**：是否在合理时间内开箱并拍照。
2. **证据**：坏果照片、视频、快递面单、聊天记录。
3. **坏果比例**：个别坏果还是大面积坏果。
4. **商品承诺**：是否标注“坏果包赔”“冷链发货”“48小时售后”等。
5. **包装与冷链**：商家是否按生鲜要求包装、加冰、保温。
6. **签收与售后时限**：是否超过平台或商家规定的售后时间。

## 4. 实务建议

**对顾客：**
- 到货后尽快开箱，拍完整视频和坏果特写。
- 保留快递面单、包装、聊天记录。
- 在售后时限内申请退款/补发。
- 不要先扔坏果，必要时保留证据。

**对商家/平台：**
- 明确售后规则，比如签收后24小时内反馈。
- 对高损耗水果设置合理赔付比例。
- 保留发货前质检、装箱、冷链记录。
- 与物流约定生鲜损坏追偿条款。

**一句话总结：**
如果坏果是发货前或运输中造成的，通常由商家或平台先对顾客负责；如果是顾客收货后存放不当或超时反馈，责任会转到顾客。实际划分要看证据、坏果比例和平台承诺。
