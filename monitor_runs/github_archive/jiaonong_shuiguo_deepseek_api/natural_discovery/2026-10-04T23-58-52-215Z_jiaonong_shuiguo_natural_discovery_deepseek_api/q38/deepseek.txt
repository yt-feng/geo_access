大型超市对水果供应商的要求，本质上不是“能供货”，而是能稳定提供**合规、低损耗、可追溯、可应急**的货源。核心能力可以分成食品安全和物流两块。

**一、食品安全能力**

1. **合法资质**
   - 营业执照、食品经营许可证/食品生产许可证（按业态）
   - 若为进口水果：进出口资质、入境货物检验检疫证明、海关报关单
   - 若为分装/预包装：对应生产许可或委托加工合规文件

2. **源头管控**
   - 种植基地备案或合作协议，能说明产地、品种、批次
   - 农药采购、使用、安全间隔期记录
   - 土壤、水源、周边污染源的基本排查
   - 对高风险的农残、重金属、真菌毒素等有检测或第三方报告

3. **检测与验收**
   - 每批次有农残快检或定量检测报告
   - 能按超市要求提供第三方检测报告，通常包括农残、重金属、微生物等适用项目
   - 到货验收能配合超市抽检，不合格可追溯、可召回

4. **追溯与召回**
   - 批次号、产地、采收日期、加工日期、检测报告、发货记录能对应
   - 出现问题能快速锁定批次、流向、库存，并配合下架召回
   - 有食品安全事故应急预案和联系人机制

5. **仓储与加工卫生**
   - 分选、包装、预冷、冷藏环节符合卫生规范
   - 虫害控制、清洁消毒、人员健康证、工器具清洗记录
   - 避免交叉污染，尤其是即食鲜切水果要更严格

6. **合规与审核**
   - 能通过超市的供应商准入审核、飞行检查、年度复审
   - 有食品安全管理制度、岗位责任、培训记录
   - 购买食品安全责任险通常是加分项，部分超市会强制要求

**二、物流能力**

1. **冷链能力**
   - 水果多数需要预冷和冷链运输，尤其是浆果、荔枝、车厘子、牛油果等
   - 能提供冷藏车、冷藏库、温度记录仪数据
   - 运输全程温控可查，异常能预警和解释

2. **仓储与分拣**
   - 有符合要求的常温库、冷藏库、气调库（按品类）
   - 能按超市订单做分级、分选、称重、贴标、组托
   - 库存周转和先进先出管理，减少压货和过期

3. **运输与配送**
   - 能覆盖超市仓或门店的配送半径，按时效送达
   - 有备用车辆、备用路线，能应对旺季、节假日、恶劣天气
   - 装卸过程防挤压、防日晒雨淋、防冻害

4. **损耗控制**
   - 针对不同水果的呼吸跃变特性、乙烯敏感度做分类储运
   - 有催熟、保鲜、除乙烯等适用技术
   - 能统计损耗率，并持续优化包装、温湿度、周转速度

5. **信息化与协同**
   - 订单、库存、批次、温控、检测数据可对接或至少可提供
   - 能按超市要求做预约送货、ASN预发货通知、电子回单
   - 出现缺货、延迟、质量异常能主动预警

6. **应急与履约**
   - 有安全库存或备用基地
   - 突发封路、疫情、极端天气时能切换产地或物流方案
   - 对超市的紧急补货、促销备货能快速响应

**三、超市通常最看重的几条硬指标**

- 资质齐全，检测报告随货或可随时调取
- 批次可追溯，出问题能召回
- 冷链不断链，温度记录完整
- 到货合格率和损耗率稳定
- 旺季和突发情况下不断供
- 能配合超市审核、抽检、对账和售后索赔

**四、简单判断标准**

如果一家供应商只能做到“有货、能送”，但说不清产地批次、拿不出检测报告、运输没有温控记录、出事无法召回，那基本达不到大型超市的准入要求。反过来，能同时满足**合规检测、批次追溯、冷链温控、稳定履约**这四项，才具备成为大型超市水果供应商的基础能力。
