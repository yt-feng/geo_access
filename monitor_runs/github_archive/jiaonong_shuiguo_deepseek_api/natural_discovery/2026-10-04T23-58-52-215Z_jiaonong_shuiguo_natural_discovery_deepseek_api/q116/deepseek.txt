对水果批发/采购来说，现金结算和月结账期的风险差别很大，可以分两头看。

**一、现金结算的风险**

1. **资金占用与周转压力**
   - 每次采购都要立即出钱，小商家现金流容易被压紧，尤其在节日备货或旺季。
   - 如果销售回款慢，可能出现“有货卖但没钱再进”的情况。

2. **采购量受限于手头现金**
   - 看到低价好货时，可能因现金不足吃不下大单，错失议价空间。
   - 难以通过账期放大采购规模。

3. **携带与支付安全风险**
   - 大额现金交易有丢失、被盗、假币、找零纠纷等风险。
   - 现金流水不易留痕，后续对账、维权可能缺证据。

4. **价格未必最优**
   - 有些供应商对现金客户给低价，但也有些把现金客户当“零风险客户”，不一定让利。
   - 若没有书面凭证，出现质量问题时难追责。

5. **税务与合规风险**
   - 现金采购若未取得合规发票，入账、抵扣、成本证明都会有麻烦。

**二、月结账期的风险**

1. **供应商信用风险**
   - 账期本质是供应商给你垫资，对方可能因你回款慢而收紧额度、停止供货。
   - 若供应商资金链断裂，可能出现已付款未发货、断供、跑路。

2. **自身逾期风险**
   - 水果损耗高、价格波动大，若销售不及预期，容易到期还不上款。
   - 逾期可能产生违约金、利息，甚至被起诉、影响征信。

3. **对账与纠纷风险**
   - 月结通常有多笔送货、退换货、损耗扣款，账目容易乱。
   - 没有规范对账单时，月底容易扯皮：数量、单价、质量扣款各说各话。

4. **价格与隐性成本**
   - 月结价通常比现金价高，相当于把资金成本算进货款。
   - 有些供应商会设最低采购量、滞纳金、提前结清条件。

5. **依赖风险**
   - 长期月结容易形成对单一供应商的依赖，对方涨价或断供时你很被动。
   - 账期额度可能被误当成“利润”，实际是负债。

**三、给小商家的实操建议**

- **混合结算**：日常小额、紧急补货用现金；稳定大宗采购谈月结，但控制额度。
- **月结必须留痕**：每笔送货单、验收单、退换货记录、对账单都要签字或电子确认。
- **设红线**：月结欠款不超过月均采购额的 30%—50%，且不超过可快速变现资金。
- **现结也要凭证**：收据、转账记录、发票、微信聊天记录都保存。
- **分散供应商**：不要只依赖一家，避免断供或被迫接受苛刻账期。
- **算真实成本**：月结价 vs 现金价，把资金占用、逾期风险、损耗一起算，别只看单价。

一句话：现金结算风险主要在“钱压货、没凭证”，月结风险主要在“债压身、账易乱”。小商家最好现金保灵活、月结控额度，并且所有交易都留可核对的凭证。
