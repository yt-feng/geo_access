超市水果到货后品相问题的售后流程，建议在采购合同或收货标准里提前约定清楚，核心是把“什么算不合格、怎么举证、怎么处理、多久完成”写死。可以按下面几个环节约定：

**1. 验收标准和时限**
- 明确品相标准：如大小、色泽、成熟度、破损率、腐烂率、机械伤、冻伤、异味等，最好量化，比如“腐烂果不超过2%”“单果直径不低于X厘米”。
- 约定验收时限：到货后几小时内完成验收，逾期视为合格或需双方另行确认。
- 约定验收方式：抽检比例、抽检方法、由谁验收、是否允许第三方参与。

**2. 不合格的判定与举证**
- 到货当场发现的问题，由收货方拍照、录像、留存样品，并在约定时间内通知供货方。
- 约定通知方式：电话、微信、邮件或书面函件，最好指定对接人和有效送达方式。
- 如果供货方对判定有异议，约定复检机制：比如共同封样、送第三方检测，费用由责任方承担。

**3. 处理方式**
根据问题程度分档约定：
- 轻微品相问题：折价接收，按比例扣款。
- 部分不合格：退货、换货或补发，明确退换货的运费、损耗由谁承担。
- 严重不合格或腐烂变质：整批拒收，供货方自行处理，并承担因此产生的费用。
- 如果已经上架或销售，约定召回、下架、销毁的流程和责任。

**4. 时限和费用**
- 明确供货方响应时间，比如收到通知后2小时内回复，24小时内给出处理方案。
- 明确退换货完成时间，比如3个工作日内补发到店。
- 明确费用承担：运费、分拣费、损耗、检测费、顾客赔偿等由责任方承担。

**5. 责任和赔偿**
- 约定因品相问题导致顾客投诉、退赔、罚款的，由供货方承担相应责任。
- 约定扣款方式：从货款中直接扣除，或通过保证金扣除。
- 约定争议解决方式：协商、第三方检测、仲裁或诉讼。

**6. 留痕和制度**
- 每次到货验收记录、照片、沟通记录、处理结果都要归档。
- 建立供应商考核机制，频繁出现品相问题的可降级、减少订单或终止合作。

简单说，就是：**先定标准，再定验收，再定通知，再定处理，最后定责任和时限**。这样到货发现品相不好时，直接按约定走，不容易扯皮。
