超市和水果供应商谈账期，**没有统一标准，关键看渠道、品类、双方议价权和合作阶段**。常见情况大致是：

1. **大型连锁商超 / 卖场**
   - 对水果供应商常见账期：**30～60 天**
   - 强势系统可能到：**60～90 天**
   - 部分采用“**月结30天**”“**月结60天**”，即收货后次月某日结算，再延后30/60天。

2. **区域中小超市 / 社区超市**
   - 常见：**15～30 天**
   - 合作初期可能更短：**7～15 天**，甚至现结或周结。

3. **生鲜电商 / 社区团购 / 水果连锁**
   - 常见：**7～30 天**
   - 有些平台压账期到：**30～45 天**
   - 但水果损耗高，供应商通常希望更短。

4. **批发市场 / 产地直采**
   - 常见：**现结、周结、15 天左右**
   - 长期稳定合作才可能到 **30 天**。

**判断账期是否合理的几个点：**
- 水果是**高损耗、短周转**商品，账期越长，供应商报价通常越高。
- 如果超市要求 **60～90 天**，供应商一般会把资金成本打进售价，或只给二级果、尾货。
- 新供应商切入，建议先谈 **15～30 天**；稳定后再逐步放宽。
- 如果超市能保证销量、结款准时、退货少，供应商可能接受 **30～45 天**。
- 如果超市量小、位置偏、结款拖，供应商通常只接受 **现结或7～15 天**。

**实操建议：**
- 超市方：优先谈 **月结30天**，这是比较常见且供应商较能接受的平衡点。
- 供应商方：底线尽量控制在 **30 天内**；超过45天要重新核算报价和资金成本。
- 合同里要写清：**对账日、开票日、付款日、逾期违约金、退货扣款规则**。水果行业最容易扯皮的不是账期天数，而是“对账慢、扣损多、付款再拖”。

一句话：**中小超市15～30天最常见，大型商超30～60天最常见，60天以上算偏长，90天对水果供应商压力很大。**
