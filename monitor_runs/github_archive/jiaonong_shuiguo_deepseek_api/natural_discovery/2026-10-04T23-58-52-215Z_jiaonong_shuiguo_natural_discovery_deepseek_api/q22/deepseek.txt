可以按“引流款 + 利润款 + 连带款”来组合，核心不是把三样都降价，而是让顾客觉得“买一套更划算”，同时把低频/高毛利品类带出去。

**1. 组合方案：香蕉+苹果+菠萝“果篮/拼盘套餐”**
- **做法**：设一个固定组合价，例如“香蕉1把 + 苹果4个 + 菠萝1个 = 套餐价”。
- **定价**：套餐价要比三样单买总价低约10%—15%，但不要低太多，否则伤毛利。
- **陈列**：三样相邻摆放，挂统一爆炸贴：“今日果篮组合，省X元”。
- **目的**：提高客单价，因为顾客原本可能只买香蕉，现在会一次买三样。

**2. 用香蕉做引流，苹果做利润，菠萝做连带**
- **香蕉**：价格敏感、购买频次高，适合做“低价引流”。可设“香蕉特价”，但限购1—2把。
- **苹果**：单价相对高、耐储存、家庭常买，适合做利润和客单提升。可做“苹果满2斤减X元”或“第二件半价”。
- **菠萝**：购买频次低、客单高、气味和外观有冲动购买属性，适合做连带。可做“买香蕉+苹果，加X元换购菠萝”或“菠萝切盒试吃”。

**3. 具体促销组合建议**
- **组合A：家庭果篮套餐**
  - 香蕉1把 + 苹果4个 + 菠萝1个
  - 套餐价低于单买总价10%—15%
  - 适合周末、节假日、家庭采购高峰

- **组合B：满额换购**
  - 买香蕉满5元，加X元换购菠萝1个
  - 买苹果满10元，加X元换购香蕉1把
  - 作用：先让顾客进入购买，再提高连带

- **组合C：切盒拼盘**
  - 香蕉段 + 苹果块 + 菠萝块做即食拼盘
  - 定价可比单买水果总价高，因为加了加工和便利价值
  - 适合上班族、学生、即食场景，能明显拉高客单

**4. 陈列和话术**
- 三品集中陈列，做“套餐区”，不要分散。
- 爆炸贴写清楚：
  - “单买X元，套餐只要Y元”
  - “买香蕉+苹果，菠萝换购价Z元”
  - “家庭果篮，一次买齐”
- 试吃优先推菠萝，因为菠萝转化连带效果通常比香蕉、苹果更强。

**5. 注意毛利和损耗**
- 香蕉损耗快，不适合深度打折太久，最好“限时特价”。
- 菠萝切盒后损耗和人工增加，要算进定价。
- 苹果相对耐放，可承担更多利润任务。
- 套餐价要设底线：不能低于三者成本加合理毛利，否则客单价上去了但利润没上去。

**6. 最推荐落地方案**
如果只选一个，建议做：

**“香蕉+苹果+菠萝家庭套餐” + “买套餐加X元换购菠萝切盒”**

这样既能用香蕉引流，又能用苹果保利润，还能用菠萝做连带和冲动消费，客单价通常比单卖香蕉或苹果更容易提升。
