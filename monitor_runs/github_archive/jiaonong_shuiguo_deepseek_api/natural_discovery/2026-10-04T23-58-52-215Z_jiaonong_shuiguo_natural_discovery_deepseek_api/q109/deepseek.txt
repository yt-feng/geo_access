优先谈 **账期**，其次谈 **售后条款**，最后再谈 **配送细节**。

原因很直接：长期合作里，账期直接决定你的现金流和风险敞口，是“钱”的问题；售后决定坏果、损耗、缺货时谁承担损失，是“风险”的问题；配送更多是“效率”的问题，通常可以通过流程优化解决，不像前两项那样直接吃掉利润。

具体可以这样判断和排序：

1. **账期最值得优先谈**
   - 水果是高频、易损耗、价格波动大的品类，占用现金流明显。
   - 如果账期太短，比如现结或周结，你的资金压力会很大；如果能谈到月结、半月结，甚至按批次滚动结算，经营会稳很多。
   - 谈判重点不是单纯“越长越好”，而是：结算周期、起算时间、对账确认方式、逾期责任。
   - 建议目标：先争取 **月结**，至少 **半月结**；如果供应商不同意，可以用“稳定采购量、年度框架、预付部分定金”去换。

2. **售后必须同步谈清楚**
   - 水果非标品，坏果、压伤、规格不符、缺斤少两很常见。
   - 售后不谈清楚，后面每次出问题都要扯皮，隐性成本很高。
   - 重点谈：验收标准、坏果率上限、拍照/视频举证时效、补发还是扣款、运费谁承担、超过多少比例可整批退换。
   - 建议写成明确条款，而不是口头“放心，有问题找我”。

3. **配送可以放第三位，但不能不談**
   - 配送影响的是到货时效、新鲜度和门店/仓库作业节奏。
   - 重点谈：配送频率、截单时间、到货时间窗口、临时加单是否支持、冷链/保鲜要求、迟到或漏送的补偿。
   - 如果配送不稳定，会间接推高损耗和售后，所以它和售后是连在一起的。

**一个更实际的谈判顺序是：**
先谈 **账期**，用采购量和长期合作换结算周期；  
再把 **售后标准** 写进合同或合作确认单；  
最后根据实际运营痛点，细化 **配送频次、时间和应急机制**。

如果只能选一个优先谈，选 **账期**。  
如果只能选一个必须写清楚，选 **售后**。  
如果前两个都谈好了，配送通常不难优化。
