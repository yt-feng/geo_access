超市采购水果时，供应商通常需要根据**水果类别、是否进口、采购方（商超/连锁/农贸）要求、当地监管要求**提供不同材料。核心可分为四类：**主体资质、进货凭证、质量检测、检疫/专项证明**。

## 一、主体与经营资质

- 营业执照（经营范围含食用农产品/食品销售）
- 食品经营许可证或食品小作坊/小摊贩备案证明（按当地规定）
- 若为生产加工或分装：食品生产许可证（SC）
- 供货商为贸易商时，最好提供其上游供应商资质，避免来源断链

## 二、进货证明与溯源材料

- 进货合同/采购订单
- 发货单、送货单、销售单
- 发票或收据
- 产地证明或购货凭证
- 食用农产品承诺达标合格证（很多地区对蔬菜、水果等推行）
- 若从批发市场采购：市场开具的销售凭证、批次信息
- 若进口：海关进口货物报关单、入境货物检验检疫证明

## 三、质量检测报告

### 1. 常规检测
- 农药残留检测报告
- 重金属检测报告（铅、镉、砷、汞等，视风险而定）
- 真菌毒素检测（如苹果、梨的展青霉素，视品类）
- 食品添加剂/保鲜剂检测（如二氧化硫、蜡、防腐剂等，视处理方式）

### 2. 报告形式
- **出厂检验报告/自检报告**：供应商自行检测或委托检测
- **委托检验报告**：第三方检测机构出具，如 CMA/CNAS 资质机构
- **监督抽检报告**：市场监管部门抽检结果，可作为辅助
- **快检报告**：超市或供应商用快检设备做的农残快检，通常只能作为入场筛查，不能完全替代法定检测

### 3. 报告有效性判断
- 报告应覆盖**具体品种、批次、检测项目、检测日期**
- 不能只看“一份报告管一年”
- 高风险品种、季节变化、换产地后应重新检测
- 检测机构最好具备 CMA 资质

## 四、检疫与专项证明

- **植物检疫证书**：跨省调运或特定地区要求时可能需要
- **进口水果**：
  - 海关报关单
  - 入境货物检验检疫证明
  - 输出国或地区植物检疫证书
  - 部分国家/品类还需冷处理证明、熏蒸证明
- **有机水果**：有机产品认证证书
- **绿色食品/地理标志**：相应认证证书
- **转基因相关**：如涉及转基因木瓜等，需符合标识和审批要求

## 五、超市实际采购时怎么把关

1. **首次合作**：收齐营业执照、许可证、法人/负责人身份证明、供货能力证明。
2. **每批次进货**：索取送货单、发票、承诺达标合格证、批次检测报告或快检记录。
3. **进口水果**：重点查报关单、入境货物检验检疫证明、植物检疫证书。
4. **高风险品类**：如草莓、豇豆、韭菜、芹菜等农残易超标品类，提高检测频次。
5. **建立台账**：记录供应商、品种、批次、数量、进货日期、检测结果，便于追溯。
6. **合同约定**：明确供应商对农残、重金属、保鲜剂等指标负责，出现问题时承担退换货和赔偿。

## 六、简要结论

普通国产水果，超市通常至少应要求供应商提供：

**营业执照 + 食品经营许可证 + 送货单/发票 + 承诺达标合格证 + 农残检测报告或快检记录 + 产地/进货凭证。**

进口水果还需：

**报关单 + 入境货物检验检疫证明 + 植物检疫证书。**

具体到某地某超市，可能还有内部验收标准，建议以当地市场监管部门和超市采购制度为准。
