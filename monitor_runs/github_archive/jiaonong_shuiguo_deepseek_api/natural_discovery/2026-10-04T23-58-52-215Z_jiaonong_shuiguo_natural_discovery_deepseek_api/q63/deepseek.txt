判断哪个规格更容易出货，可以按下面这个框架来快速测。

**一、先分清“规格”指什么**
菠萝批发里常见规格维度有：
- 重量/个头：如 2斤、3斤、4斤以上
- 等级：一级果、二级果、统货
- 品种：台农、金钻、凤梨、巴厘等
- 成熟度：青果、黄果、半黄
- 包装：散装、筐装、箱装

如果你说的是“哪个斤两好卖”，重点看：**当地终端怎么卖、什么价带、谁在买**。

**二、快速判断方法**
1. **看下游客户类型**
   - 供水果店：3-4斤中果通常最好走，大小均匀、摆着好看、损耗低。
   - 供路边摊/小贩：2-3斤小果走量大，因为单价低、顾客好接受。
   - 供酒店/果汁店/冷饮店：看净重和出肉率，常要 4斤以上大果或统货。
   - 供社区团购：中果、标准箱最稳，太大反而犹豫。

2. **看价格带**
   - 10元3个、10元2个这类场景，决定规格的不是斤两，是“个数感”。
   - 如果当地主流是“10元2个”，那单果 3斤左右最好出。
   - 如果主流是“按斤卖”，4斤以上大果反而更容易被挑。

3. **看季节**
   - 旺季集中上市：中果、统货走得快，因为便宜。
   - 淡季或节日：大果、礼盒装更好出，客单价高。
   - 高温天：黄果、熟度高的走得快，但损耗也大。

4. **看损耗**
   - 太熟的果：零售快，但批发不敢压。
   - 太生的果：耐放，但零售端要催熟，小客户不爱拿。
   - 所以“更好出货”的规格，往往是**耐放 + 外观整齐 + 价格适中**的那个。

**三、最实用的测试办法**
不要凭感觉，直接做 3 天小测试：
- 同一批货里分 3 个规格：小果、中果、大果
- 每个规格给 3-5 个不同下游客户
- 记录：谁拿、拿多少、多久复购、退货/损耗多少
- 看两个指标：
  1. **周转速度**：几天卖完
  2. **复购率**：客户会不会再拿

通常结论是：
- **中果最稳**，适合大多数批发场景。
- **小果走量快但利润薄**，适合低价市场。
- **大果利润高但受众窄**，适合礼盒、餐饮、特定渠道。

**四、一句话判断**
如果你不知道选哪个，先主推**3-4斤、外观均匀、七八成熟的中果**，同时配一点小果走低价、大果走利润。三天后看哪个复购多、退损少，就加大哪个。
