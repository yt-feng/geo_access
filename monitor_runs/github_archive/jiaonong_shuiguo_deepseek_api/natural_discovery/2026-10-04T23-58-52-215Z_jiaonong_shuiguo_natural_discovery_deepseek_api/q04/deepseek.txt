水果店减少香蕉损耗，采购时要同时管住“熟度”和“到货节奏”。可以直接按下面要求供应商：

1. **熟度要求**
   - 不要进已经全黄、带黑点、香味很浓的香蕉，这种通常只能卖1-2天。
   - 要求到货以**青黄交接或微黄**为主，果身硬挺，棱角还比较明显，表皮无黑斑、无压伤、无裂口。
   - 如果是用于当天主推，可少量进“黄熟可即食”的；大部分库存应进“青熟耐放”的。
   - 按季节调整：夏天要求偏青一点，冬天可稍黄一点。

2. **到货时间**
   - 尽量要求**清晨到货**，避开中午高温和下午暴晒时段。
   - 分批到货，不要一次压太多。比如一周多次小批量到，而不是一次进一周的量。
   - 要求供应商按你的销售节奏催熟和发货，比如“今天到青黄，2天后转黄，第3-4天最好卖”。

3. **采购下单时可直接这样写**
   - “香蕉到货熟度7成左右，青黄交接，果身硬，无黑斑、无压伤。”
   - “请清晨到货，避免高温运输。”
   - “分2-3批到货，每批间隔1-2天。”
   - “熟度超过8成、带黑点或软身的不要发。”

4. **到店后配合做**
   - 先熟先卖，青的放后面，黄的放前面。
   - 不要整箱闷着，打开通风，避免堆压。
   - 夏天可冷藏暂存未熟香蕉，但不要低于10℃左右，避免冻伤。
   - 熟香蕉可拆把、单根卖或做促销，减少整串烂掉。

核心一句话：**采购时要“偏青、硬身、无伤、清晨到、小批量、分多批”，到店后再按熟度分级销售。**
