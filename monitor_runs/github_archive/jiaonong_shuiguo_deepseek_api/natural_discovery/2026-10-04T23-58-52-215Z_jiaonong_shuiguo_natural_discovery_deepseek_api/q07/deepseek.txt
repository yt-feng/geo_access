做水果礼盒，核心不是“凑满一箱”，而是**让顾客一眼看出送礼场景和价格档位**。苹果、橙子、香蕉、菠萝这四种里，苹果和橙子是礼盒主力，香蕉和菠萝更适合做“分量感”和“特色感”，但要注意香蕉易压、菠萝扎手，搭配和包装要控制好。

下面给你几个比较好卖的组合方向，可以直接照着试。

---

## 一、先定价格和场景，再定搭配

水果礼盒好不好卖，先看你是卖给谁：

| 场景 | 建议定价 | 搭配重点 |
|---|---|---|
| 日常走亲访友 | 39～69元 | 苹果+橙子为主，看着满、颜色亮 |
| 节日送礼/公司福利 | 79～129元 | 苹果+橙子+菠萝，显得高档 |
| 高端商务/探病 | 129元以上 | 精品苹果+进口橙/澳橙，菠萝少量点缀 |
| 家庭自吃/实惠装 | 29～49元 | 苹果+橙子+香蕉，量大实惠 |

**不建议把香蕉当高端礼盒主角**，因为香蕉容易黑、怕压，放久了卖相掉得快。菠萝可以撑体积、有热带感，但带皮菠萝扎手、占地方，很多顾客其实更愿意买削好的。

---

## 二、4种水果的角色定位

- **苹果**：礼盒基础款，寓意平安，耐放、好看，必须有。
- **橙子**：颜色亮、寓意吉利，和苹果是黄金搭档，销量最稳。
- **香蕉**：便宜、显多，但易压易黑，适合中低端盒或家庭装。
- **菠萝**：有特色、显档次，但处理麻烦，适合做点缀或高端热带风。

---

## 三、推荐直接用的5种搭配方案

### 1. 平安如意盒（最好卖，主推）
**苹果 + 橙子**
- 比例：苹果6个 + 橙子6个，或苹果8个 + 橙子4个
- 定价：49～69元
- 卖点：平安+心想事成，颜色红黄搭配，送礼不出错
- 适合：日常送礼、探亲、节日基础款

这是最稳的款，苹果橙子都耐放，损耗低，顾客也认。

### 2. 金玉满堂盒（中端走量）
**苹果 + 橙子 + 香蕉**
- 比例：苹果6个 + 橙子4个 + 香蕉1把
- 定价：59～79元
- 卖点：分量足、价格适中、看着满
- 注意：香蕉要选稍青一点的，别放太熟，最好用隔层固定

这个适合社区店、家庭客，显得“东西多”。

### 3. 热带风情盒（有特色，适合年轻人）
**苹果 + 橙子 + 菠萝**
- 比例：苹果4个 + 橙子4个 + 小菠萝1个
- 定价：69～99元
- 卖点：热带感、有档次、拍照好看
- 注意：菠萝选小个的，或者用削好真空装的，避免扎手和占重

这个适合节日、公司小福利、年轻客户。

### 4. 四喜临门盒（节日款）
**苹果 + 橙子 + 香蕉 + 菠萝**
- 比例：苹果4个 + 橙子4个 + 香蕉1小把 + 小菠萝1个
- 定价：89～129元
- 卖点：四种水果、寓意丰富、体积大
- 注意：这个组合容易“看着大但不值钱”，菠萝和香蕉成本要算清楚，别亏

适合春节、中秋、开业、乔迁。

### 5. 高端精简盒（利润款）
**精品苹果 + 精品橙子 + 小菠萝点缀**
- 比例：苹果6个 + 橙子6个 + 菠萝1个
- 定价：129～199元
- 卖点：少而精，果形统一，包装高级
- 注意：苹果橙子要选大小一致、无瑕疵的，菠萝只做点缀

这个不做量，做利润和形象。

## 四、怎么摆更好卖

1. **颜色要跳**：红苹果、黄橙子、绿香蕉、黄菠萝，摆的时候红黄为主，绿色点缀。
2. **上层放苹果橙子**：耐压、好看；下层放菠萝；香蕉单独固定，别压。
3. **每个盒贴标签**：写“平安如意”“四喜临门”“送长辈”“送朋友”，顾客不用问。
4. **做三个价格档**：49元、79元、129元，顾客容易选中间。
5. **门口堆头放主推款**：只推1～2个组合，别摆太多，选择困难反而不好卖。
6. **允许换果**：比如“苹果可换等值橙子”，能减少库存压力。

---

## 五、最建议你先试的组合

如果你想快速试水，先做这两个：

**主推走量款：**
- 苹果6个 + 橙子6个
- 定价49～59元
- 走“平安如意”概念

**中端利润款：**
- 苹果4个 + 橙子4个 + 小菠萝1个
- 定价79～99元
- 走“热带风情/有面子”概念

香蕉先不要大规模做进礼盒，除非你当天能卖掉，或者顾客明确要实惠装。菠萝要用小个的，最好能代削皮。

---

## 六、关键提醒

- **香蕉和菠萝损耗高**，礼盒里放它们，必须当天或隔天卖掉。
- **苹果橙子最稳**，可以多备，香蕉菠萝按订单少量备。
- **别只按重量凑**，要按“视觉满、颜色好、寓意好”来配。
- **先做小批量测试**：每个组合先做5～10盒，看哪种卖得快，再加大。
