优先排序：**切果损耗 > 甜度 > 外观 > 大小**。如果只能抓一个指标，先抓切果损耗，因为它直接决定毛利。

**1. 切果损耗（最优先）**
- 菠萝是典型“带皮称重卖、去皮后缩水”的品类，出肉率通常只有 **50%~65%**，差异极大。
- 损耗高意味着：进货价再低、卖相再好，也可能不赚钱。
- 应关注：单果去皮后净重、黑心/烂心比例、切果报废率。
- 可执行动作：按批次抽测出肉率，低于标准线的供应商直接压价或换货。

**2. 甜度（第二优先）**
- 甜度决定复购和口碑，尤其对鲜切、果切、饮品店客户。
- 应关注：糖度（Brix）是否稳定，而不是偶尔一两个甜。
- 可执行动作：用糖度计抽检，设定最低收货糖度线；按甜度分级定价或分渠道销售。

**3. 外观（第三优先）**
- 外观影响成交率，但对超市来说，菠萝常被削皮或切块卖，外观权重低于损耗和甜度。
- 应关注：果形是否端正、有无明显黑斑、裂口、烂眼。
- 可执行动作：外观差的转做果切或特价，不要硬当鲜果卖。

**4. 大小（最后）**
- 大小主要影响定价和陈列，不直接决定品质。
- 大果不一定甜，小果不一定差；关键是大小是否均匀、是否符合目标客群。
- 可执行动作：按规格分档，统一陈列和定价，避免顾客挑拣造成损耗。

**简单决策口径：**
- 做鲜切/果切：**损耗第一，甜度第二**。
- 做整果零售：**甜度第一，外观第二，损耗仍要卡**。
- 做低价引流：可以牺牲大小和外观，但不能牺牲损耗控制，否则越卖越亏。
