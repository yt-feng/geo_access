连锁超市和水果供应商签年度合同，最容易踩的坑集中在“价格与行情波动、质量验收标准、损耗与退货、账期与结算、供应保障、知识产权与渠道限制”这几块。下面按风险从高到低说，并给出可操作的条款写法。

## 1. 价格条款：别签“全年一口价”
水果价格随季节、产区、天气波动极大，固定价要么供应商亏本毁约，要么超市高价吃亏。

**踩坑点**：只写单价，不写调价机制、不写基准。

**建议写法**：
- 采用“基准价 + 随行就市调整”：约定以某批发市场/行业协会周度均价为基准，±X% 内不调，超出部分双方按比例分担。
- 明确调价频率（如每两周一次）、触发条件、确认方式（书面/系统确认）。
- 约定“价格异常波动”条款：单周涨幅超 15% 时双方重新协商，协商不成可暂停供货而非直接违约。

## 2. 质量标准与验收：写“新鲜”等于没写
“新鲜、无腐烂”这种描述在纠纷时无法执行。

**踩坑点**：标准模糊、验收时点不清、农残检测责任不明。

**建议写法**：
- 按品类分别约定等级标准（大小、糖度、色泽、成熟度、单果重），能引国标/行标就引用。
- 明确验收：到货后 X 小时内完成验收，逾期视为合格；抽样比例和判定规则写清。
- 农残/食品安全：要求供应商提供每批次检测报告，责任由其承担；超市可抽检，不合格整批退。
- 约定“隐蔽瑕疵”处理：验收合格后 X 天内发现内部腐烂等，仍可追责。

## 3. 损耗与退货：这是水果合同最大的利润黑洞
水果损耗率高，谁承担损耗直接决定盈亏。

**踩坑点**：只写“不合格退货”，不写正常损耗、不写退货运费谁出。

**建议写法**：
- 约定合理损耗率（如叶菜 5%、浆果 8%），在此范围内超市自担，超出部分供应商补货或折价。
- 退货条件、时限、运费承担写清楚；生鲜退货往往无法二次销售，要约定折价或补货而非简单退款。
- 明确“门店端损耗”与“配送端损耗”的责任分界点（如签收即转移）。

## 4. 账期与结算：别被“账期”拖死现金流
**踩坑点**：账期过长、对账口径不清、扣款无依据。

**建议写法**：
- 账期（如货到 30/60 天）+ 对账周期（每周/每月）+ 付款触发条件写清。
- 所有扣款（质量扣款、返利、促销费、损耗扣款）必须列明项目和计算方式，禁止“其他扣款”开口条款。
- 约定逾期付款违约金，也约定供应商开票义务和票据不合规的处理。

## 5. 供应保障与独家/排他
**踩坑点**：只约定超市的采购量，不约定供应商的最低供货义务；或签了排他却无对价。

**建议写法**：
- 约定最低供货量/供货响应时间，断供的违约责任。
- 若要求供应商不向竞品供货（排他），必须给对价（保底采购量或返点），否则条款可能被认定不公平。
- 约定不可抗力（天气、疫情、政策）下的免责和替代供应方案。

## 6. 容易被忽略但很致命的条款
- **返利/返点**：写清计算基数（含税/不含税、是否扣除退货）、结算时间、未达量是否倒扣。
- **促销与陈列费**：年度合同常捆绑，要写明频次、费用、效果不达标如何处理。
- **合同期限与自动续约**：避免“到期自动续约一年”导致被动。
- **终止与过渡**：约定终止后尾货处理、未结货款、库存回购。
- **争议解决**：管辖法院/仲裁地选对自己有利的，别默认对方所在地。

## 优先级建议
如果只能改三条，按这个顺序：
1. **价格调整机制**（防行情风险）
2. **质量验收 + 损耗退货规则**（防利润黑洞）
3. **账期与扣款明细**（防现金流和隐性扣费）

签之前建议让采购、财务、法务三方各过一遍，尤其把“损耗率、账期、扣款项”三个数字单独拉出来算一遍全年影响，再决定是否签字。
