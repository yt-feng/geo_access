选水果拼盘的规格，核心不是“越便宜越好”，而是看**出成率、单份成本和切配损耗**。按餐厅常用场景，可以这样判断：

1. **苹果**
   - 优先选**中等偏大、果形端正、表皮无伤**的。
   - 太小的削皮去核后出成率低，切出来片小、摆盘不饱满；太大的单价高，但出成率也高。
   - 餐厅常用：**80–90mm 果径**比较稳，做拼盘切片、切块都合适。
   - 如果只做小份配盘，可选 **75–85mm**；如果做多人拼盘，选 **85–95mm** 更划算。

2. **橙子**
   - 重点看**皮厚薄、籽多少、汁水足不足**。
   - 皮太厚的，切瓣后白瓤多、卖相差，实际可食部分少。
   - 餐厅常用：**中果到大果，单果 200–300g** 左右比较合适。
   - 做橙瓣拼盘，选**皮薄、易剥、少籽**的品种；做鲜切橙片，选**果形圆整、横切面好看**的。
   - 如果按箱买，别只看斤价，要算**可切瓣数/可摆盘份数**。

3. **菠萝**
   - 最影响划算程度的是**去皮去眼后的净肉率**。
   - 菠萝规格通常看单果重量：**1.2–1.8kg** 的商用菠萝比较通用。
   - 太小：削皮去眼后剩得少，切块少，人工成本高。
   - 太大：单次用不完，切开后存放损耗大，除非当天用量很大。
   - 如果做菠萝块、菠萝片，选**果眼浅、肉厚、成熟度适中**的；太熟的切盘容易出水塌形。
   - 餐厅用得多，优先选**稳定净肉率**，而不是单果最大。

**简单判断公式：**
> 实际划算度 = 净可用果肉重量 ÷ 采购总价  
> 再叠加：切配人工 + 损耗 + 当天未用完报废

**直接建议：**
- 苹果：选 **80–90mm 中大果**，果形好、无伤。
- 橙子：选 **200–300g 中大果**，皮薄少籽。
- 菠萝：选 **1.2–1.8kg 商用中果**，果眼浅、肉厚。
- 如果餐厅走量，三种都优先找**规格稳定、出成率稳定**的供应商，不要只追最低斤价。
- 如果做高端拼盘，苹果和橙子可以略大一号，菠萝反而要选成熟度均匀的，避免一盘里软硬差太多。

更实用的做法是：让供应商分别报“箱价、单果重、可切份数”，你按**每份拼盘的水果成本**去比，而不是按斤价去比。
