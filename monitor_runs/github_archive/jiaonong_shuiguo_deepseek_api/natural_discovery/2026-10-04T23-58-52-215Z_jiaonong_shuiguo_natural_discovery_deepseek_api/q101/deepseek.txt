酒店早餐水果供应，重点不是“买到便宜水果”，而是**稳定、可控、可追溯、损耗可算**。和供应商谈合作时，建议重点抓以下几项：

1. **明确供应标准**
   - 品种、规格、等级要写清楚，比如苹果直径、香蕉每根长度/成熟度、西瓜单果重量、橙子酸甜度要求。
   - 约定成熟度：早餐水果不能太生，也不能太熟。比如香蕉、芒果、牛油果要说明“到货即用”还是“可存放1-2天”。
   - 外观和口感标准：无腐烂、无严重磕碰、无虫害、无过度冷害，切开后色泽和口感稳定。

2. **确定供货频率和响应时间**
   - 是每日配送、隔日配送，还是每周几次？早餐高峰必须保证不断货。
   - 临时加单、节假日、大型团队入住时，供应商能否加急补货？补货响应时间要写进合同。
   - 到货时间要避开早餐备餐高峰，最好固定时段，便于验收和入库。

3. **价格与调价机制**
   - 不要只谈一个“单价”，要谈**计价方式**：按斤、按箱、按个还是按净重。
   - 水果价格波动大，合同里要写调价周期和依据，比如每周/每半月参考当地批发市场价，或约定涨跌幅超过多少才调价。
   - 明确是否含税、含运费、含卸货费，避免后期加价。
   - 对损耗、坏果、规格不符要有扣款或补货规则。

4. **验收和退换货规则**
   - 到货必须现场验收：数量、重量、规格、成熟度、新鲜度、温度。
   - 不合格品怎么处理？是当场拒收、补送，还是按比例扣款？要写清楚时限。
   - 建议保留验收记录和照片，尤其是坏果、短缺、规格不符，方便月度对账和索赔。

5. **食品安全与资质**
   - 供应商要有营业执照、食品经营许可证，涉及进口水果还要有入境货物检验检疫证明等。
   - 要求提供农残检测报告或承诺符合食品安全标准，能追溯批次最好。
   - 配送车辆、周转筐、冷藏条件要符合要求，避免交叉污染。
   - 酒店方也要保留索证索票记录，便于监管检查。

6. **损耗与成本控制**
   - 早餐水果损耗通常来自：切配废弃、成熟度不当、库存积压、员工操作不规范。
   - 和供应商谈时，可以要求按“净果率”或“可用率”结算，或者对易损品种约定更高补损比例。
   - 建议先统计酒店日均用量、峰谷用量、常用品种和切配方式，再谈供应方案，否则容易被供应商牵着走。

7. **合同关键条款**
   - 供应品种、规格、单价、频率、到货时间。
   - 质量标准、验收方式、退换货和赔偿。
   - 价格调整机制、结算周期、付款方式。
   - 违约责任：断供、迟送、以次充好、食品安全问题怎么赔。
   - 合同期限和退出机制：试用期、考核不合格可终止。
   - 保密和廉洁条款，避免采购人员拿回扣。

8. **建议先小范围试合作**
   - 先选1-2个品种、1-2周试供，观察到货稳定性、损耗率、员工反馈和客人满意度。
   - 试供合格后再签长期合同，并保留2家备用供应商，防止单一供应商断供。
   - 每月复盘：到货合格率、断供次数、损耗率、投诉次数、实际成本。

简单说，谈合作时要盯住五件事：**标准写清、价格透明、验收严格、退换明确、断供有罚**。这样早餐水果供应才稳，成本也可控。
