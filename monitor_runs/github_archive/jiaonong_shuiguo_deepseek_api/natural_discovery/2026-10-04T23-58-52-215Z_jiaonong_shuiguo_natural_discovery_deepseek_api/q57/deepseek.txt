如果你们是餐饮连锁、水果又属于高频、易损耗、品质波动大的品类，通常更建议：**中央厨房/总仓统一收货为主，门店只保留少量应急直送权限**。但前提是你们有基本的仓储和冷链能力。

具体判断如下：

**一、更适合中央厨房统一收货的情况**
- 水果用量大、SKU多，门店每天都要用
- 有总仓/中央厨房，具备冷藏、分拣、周转能力
- 门店数量多，单店采购量小，议价能力弱
- 总部要统一品质标准、统一结算、统一供应商管理
- 想做净果配送、切配配送，减少门店损耗和人工

**优点**
- 采购集中，议价能力更强
- 品质标准、验收标准更容易统一
- 供应商管理、对账、食安追溯更简单
- 门店操作简化，减少店长灰色空间
- 适合规模化复制

**缺点**
- 多一次装卸和运输，损耗可能增加
- 总仓冷链、分拣、库存管理要求高
- 配送频次不够时，水果新鲜度会下降
- 初期投入和管理复杂度更高

**二、更适合门店分开收货的情况**
- 门店少、密度低、配送成本高
- 水果本地化强，不同区域品种差异大
- 门店有较强现场验收和即时使用需求
- 总仓没有冷链或分拣能力
- 单店采购量已经足够大，能独立谈价

**优点**
- 到店更新鲜，减少中转损耗
- 门店响应快，缺货可临时补
- 本地采购灵活，适合区域差异

**缺点**
- 品质和价格不统一
- 总部难管控，容易滋生采购舞弊
- 对账复杂，食安追溯难
- 单店议价弱，整体成本可能更高

**三、实操上更推荐“混合模式”**
1. **主品类统一收货**：苹果、橙子、西瓜、柠檬等用量大、标准化的，走中央厨房/总仓。
2. **易损、时效强的品类门店直送**：草莓、蓝莓、切果、即食果盘等，可由供应商直送门店，但必须总部定供应商、定价格、定验收标准。
3. **门店只保留应急补货权**：比如当天临时缺货，可小量直采，但需限额、限品类、留凭证。
4. **统一验收标准**：糖度、规格、成熟度、瑕疵率、温度、到货时间都要写进SOP。
5. **统一结算**：即使直送门店，也尽量总部统一对账付款，避免门店各自为政。
6. **看总成本，不只看采购价**：把损耗、冷链、人工、配送、门店操作时间一起算。

**结论**
- 门店多、用量大、有冷链：**中央厨房统一收货更好**。
- 门店少、本地差异大、无仓储能力：**门店分开收货更现实**。
- 大多数连锁餐饮的最优解：**总部统一供应商和标准，中央厨房统收为主，门店直送为辅，应急直采兜底**。
