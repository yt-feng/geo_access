找社区超市的水果日配供应商，核心要看**能不能稳定、准时、按你的销量供货**，而不是只看价格。建议按下面顺序判断：

1. **配送能力**
   - 是否承诺每天配送，几点前到店。
   - 节假日、雨天、凌晨能否正常送。
   - 临时补货、加单、减单的截止时间和响应速度。
   - 配送范围是否覆盖你所在区域，是否有冷链车或保温箱。

2. **货源稳定性**
   - 是否有固定产地、批发市场档口或一级代理渠道。
   - 常见水果是否常年有货，换季时能否提前给替代品。
   - 爆款、应季果、进口果的到货周期和缺货率。

3. **品控和损耗**
   - 是否支持验货、坏果包赔、缺斤少両处理。
   - 次果率大概多少，损耗由谁承担。
   - 是否按成熟度分拣，适合社区店当天卖还是可放几天。
   - 有没有农残检测、保鲜处理、包装标准。

4. **价格和结算**
   - 报价是否随行就市，是否每天更新价单。
   - 是否含运费、装卸费、包装费。
   - 账期还是现结，押金多少，退换货怎么扣款。
   - 同一单品不同规格的毛利空间，别只看进价低。

5. **售后和替换**
   - 坏果、烂果、规格不符时，多久内可申请售后。
   - 是否支持换货、补货、退款，流程是否简单。
   - 配送迟到、漏送、少送怎么赔偿。

6. **合作灵活性**
   - 起送量、最小起订量是否适合社区店。
   - 能不能先小批量试供 1–2 周。
   - 是否允许你根据销售数据调整每天订货量。
   - 是否只供你一家，还是周边同行也供，价格会不会乱。

7. **实地核验**
   - 去对方仓库、档口或分拣点看一眼。
   - 看库存、冷库、分拣台、配送车和员工操作。
   - 问 2–3 家正在合作的社区店，了解准时率和售后。

**建议你先做一个小测试：**
选 5–8 个高频水果，让 2–3 家供应商同时试供 7 天。每天记录：到货时间、损耗率、缺货次数、售后响应、实际毛利。7 天后，选“准时率最高、损耗最低、售后最快”的那家，而不是单纯报价最低的。
