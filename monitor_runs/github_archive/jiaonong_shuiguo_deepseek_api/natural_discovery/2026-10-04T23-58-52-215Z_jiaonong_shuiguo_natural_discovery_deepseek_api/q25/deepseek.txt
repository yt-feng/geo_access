针对“门店多、单店量不大”的超市，核心矛盾是：**总采购量有规模，但单店配送频次高、单次批量小、损耗风险大**。适合的模式要同时解决“采购有价格优势”和“配送不压库存”两件事。下面按可行性和适配度排序。

## 1. 区域批发市场统采 + 第三方城配分拨（最常见、启动快）
- **做法**：总部或区域仓统一从一级批发市场/产地代办采购，集中到区域分仓，再按门店订单用第三方城配（或自有小车）次日配送到店。
- **适合**：门店数已有一定规模（比如30家以上），但单店日均水果销量不高。
- **优点**：不绑定单一供应商，品类灵活，起量后能拿到批发价；门店不用自己跑市场。
- **关键控制**：建立“以销定采+安全库存”机制，按门店前7天动销下单，减少叶菜类、浆果类高损耗品囤货。
- **风险**：分拨环节增加人工和损耗，需要冷链或至少温控暂存。

## 2. 产地/基地直采 + 区域分仓 + 门店直配
- **做法**：对苹果、橙子、香蕉、西瓜等耐储或大单品，直接对接产地合作社/基地，走区域分仓再配门店。
- **适合**：有1—2个区域分仓、能承担账期和起订量的连锁超市。
- **优点**：毛利空间最大，品质和供应稳定。
- **注意**：产地直采通常有起订量，单店量小必须靠“多店拼单”凑整车；不适合所有品类都直采，只做核心大单品。

## 3. 城市共享仓/生鲜共配平台
- **做法**：接入当地生鲜供应链平台或共享仓，由平台按门店订单分拣、配送。
- **适合**：门店分散、自建仓不划算、想轻资产运营的连锁。
- **优点**：不用自建冷链和分拨团队，按单付费，起量门槛低。
- **缺点**：平台加价后毛利变薄，品类和品质受平台约束，数据不在自己手里。
- **判断标准**：如果平台配送费+加价后，综合成本仍低于自采+自配，且损耗由平台承担较多，就值得用。

## 4. 供应商“多店拼车、定时定点”配送
- **做法**：找1—3家本地水果供应商，约定每周固定几天，按你汇总的各店订单，一车跑多店。
- **适合**：门店在同一个城市或同一配送圈内，单店量小但门店密度够。
- **优点**：不用自建物流，供应商承担分拣和配送，账期也好谈。
- **关键**：合同里写清缺货补货、损耗归属、临期处理、价格随行就市机制。
- **风险**：依赖供应商，容易被单一供应商卡价或断供，建议至少两家备份。

## 5. 门店“少量多频”补货 + 中央厨房/加工中心预处理
- **做法**：对果切、拼盘、礼盒等，由中央加工中心统一处理，门店只做陈列和销售。
- **适合**：有加工能力、想提高水果附加值的连锁。
- **优点**：降低门店操作难度和损耗，提升毛利。
- **注意**：加工中心要靠近门店集群，否则配送成本吃掉利润。

## 选择建议（按你的阶段）
| 阶段 | 推荐模式 |
|---|---|
| 刚起步、门店<20家 | 本地批发市场统采 + 第三方城配，或直接找供应商拼车配送 |
| 20—50家、同城密集 | 区域分仓 + 供应商多店拼车 + 核心单品产地直采 |
| 50家以上、跨区域 | 区域分仓 + 产地直采 + 共享仓/共配平台组合 |
| 想轻资产 | 共享仓/共配平台 + 供应商定时配送 |

## 落地时要盯住的4个指标
1. **单店日均销量和动销率**：决定补货频次和订货量。
2. **损耗率**：水果行业通常控制在5%—10%以内，叶菜和浆果更高。
3. **配送成本占比**：一般不超过销售额的3%—5%，否则模式不成立。
4. **采购价与批发市场差价**：直采或统采必须明显低于门店自采价，否则没有意义。

## 一句话结论
**优先做“区域统采/分仓 + 多店拼车配送”，核心大单品再叠加产地直采；如果自建仓不划算，就用本地共享仓或共配平台过渡。** 不要每个店单独找供应商，也不要为了直采压一堆库存。
