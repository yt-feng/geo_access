买香蕉想避开“到店太生或太熟”，核心是先想清楚**打算几天吃完**，再按用途挑颜色和手感，而不是只看黄不黄。

可执行判断：
- **当天或第二天吃**：选**通体黄、少量褐斑**，闻到明显香蕉香。太软、黑斑多的只适合当天做奶昔/烘焙。
- **2～3天吃完**：选**大部分黄、蒂头略绿、没有黑斑或只有一两个小斑点**。
- **3～5天吃完**：选**黄绿相间、蒂头绿、整体硬实**。回家放室温，别马上冷藏。
- **想放更久**：选**明显偏绿、硬、无擦伤**。但太生的香蕉可能放很久仍发涩，别买“全绿发硬还带伤”的。

到店快速检查：
1. **看蒂头**：绿色=偏生；黄褐/发黑=偏熟。
2. **看表皮**：均匀黄最好；黑斑多=熟；大面积青绿=生。
3. **轻捏中部**：硬=生；略软有弹性=刚好；一按凹=过熟。
4. **闻一下**：有清香=可吃；酒味/发酵味=过熟。
5. **看伤口**：有裂口、压伤、发霉的不要，会加速腐烂。

采购策略：
- 如果超市离家远、路上还要逛：**比目标熟度再偏生一点**。
- 如果想今天吃、又想后面还有：**黄绿各买几根**，不要一把全同熟度。
- 回家后：熟香蕉**不要放冰箱**，室温阴凉处；已经熟透再冷藏，皮会变黑但果肉可多撑几天。
- 想催熟：和苹果/梨放同一纸袋，室温。想减速：分开、通风、避免挤压。

一句话：**按“几天吃完”选颜色；当天吃选黄带斑，2～3天选全黄无斑，3～5天选黄绿相间，想放久选绿硬无伤。**
