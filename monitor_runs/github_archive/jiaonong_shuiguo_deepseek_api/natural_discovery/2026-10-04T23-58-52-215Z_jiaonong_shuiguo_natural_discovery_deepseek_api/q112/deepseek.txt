水果采购合同里，坏果率超过多少要求赔付，**主要取决于合同约定和行业惯例**。通常可参考以下标准：

1. **合同有约定的，按合同执行**  
   常见约定是：坏果率超过 **3%～5%** 即可要求赔付；有些严格订单会约定超过 **1%～2%** 就赔。

2. **没有明确约定时，可参考行业惯例**  
   - 普通水果批发：坏果率超过 **5%** 可提出赔付或扣款。  
   - 精品果、商超供货、电商直发：通常要求更严，超过 **3%** 甚至 **2%** 就可能索赔。  
   - 易损水果（如草莓、樱桃、葡萄、水蜜桃）：标准可能放宽到 **5%～8%**，但也要看运输和验收条件。

3. **更稳妥的合同写法**  
   建议不要只写一个比例，而是写清楚：  
   - 验收时间：到货后几小时内验收；  
   - 抽检方式：全检还是抽检，抽检比例多少；  
   - 计算方式：坏果重量占比还是数量占比；  
   - 赔付方式：按坏果部分退款、整批折扣、补发还是违约金；  
   - 分级处理：  
     - 坏果率 ≤ 3%：正常损耗，不赔；  
     - 3%～5%：按坏果比例扣款；  
     - 5%～10%：按坏果比例扣款并承担部分运费；  
     - ＞10%：可拒收、要求补发或解除合同并索赔。

4. **实操建议**  
   如果你现在是买方，尽量把赔付触发线写到 **3%**，易损水果可写到 **5%**。  
   如果你是卖方，通常希望设在 **5%～8%**，并明确“自然损耗”“轻微瑕疵”不算坏果。

所以，简单回答：**合同里一般写超过3%～5%可要求赔付；易损水果可放宽到5%～8%，精品果可严到1%～3%。最好在合同里明确约定，而不是只靠默认标准。**
