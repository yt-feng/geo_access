超市如果担心水果农残抽检，采购时不要只要一句“合格”，建议提前向供应商索取并留存以下资料，按“资质—检测—溯源—承诺”四类要：

1. **供应商主体资质**
   - 营业执照
   - 食品经营许可证或食品生产许可证（按实际业态）
   - 若供应商是代办/贸易商，还要其上游果园、合作社或加工厂的资质

2. **批次检测资料**
   - 该批次水果的农残检测报告
   - 报告必须是第三方检测机构出具，优先 CMA/CNAS 资质
   - 报告项目应覆盖常见高风险农残，如有机磷、氨基甲酸酯、拟除虫菊酯等，不要只看“合格”两个字
   - 报告日期、批次号、品名要与到货批次对应

3. **溯源与合格证明**
   - 产地证明、供货证明或基地备案信息
   - 承诺达标合格证，尤其是食用农产品承诺达标合格证
   - 若是进口水果，要海关入境货物检验检疫证明
   - 采购合同或订单中写清农残超标责任、退换货和赔偿条款

4. **供应商书面承诺**
   - 质量安全承诺书
   - 农残不超标承诺
   - 同意超市或监管抽检，若不合格承担检测费、下架损失和法律责任

实操上建议：

- **首次合作**：要全套资质 + 第三方检测报告 + 样品检测。
- **长期合作**：每批要承诺达标合格证；高风险品种如草莓、豇豆、芹菜、韭菜、葡萄等，定期要第三方报告。
- **到货时**：保留批次号、送货单、检测报告，最好自己用快检设备做抽检并留记录。
- **合同里写明**：供应商提供资料不实或抽检不合格，超市有权拒收、退货、索赔。

一句话：**要资质、要批次检测报告、要溯源凭证、要书面承诺，并且所有资料必须和到货批次对得上。**
