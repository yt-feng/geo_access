做批发档口拓展餐饮客户，菠萝和香蕉的规格思路不一样：菠萝看“加工方式+熟度”，香蕉看“熟度+单根大小”。餐饮客户最在意的是**出成率稳定、损耗可控、到货即可用**，所以规格要围绕这两个品类分开设计。

## 一、菠萝：按加工场景分规格

餐饮端用菠萝主要有四类：鲜切果盘/自助餐、烘焙装饰、热菜（菠萝咕咾肉、菠萝炒饭）、饮品（菠萝汁、菠萝茶饮）。对应备货规格：

| 规格方向 | 建议标准 | 适配客户 |
|---|---|---|
| 大果（鲜切/果盘） | 单果1.5–2.5kg，果形正、芽眼浅、无黑心 | 自助餐、水果店、酒店 |
| 中果（通用型） | 单果1.0–1.5kg，成熟度7–8成 | 中小餐馆、快餐 |
| 小果（饮品/烘焙） | 单果0.8–1.2kg，酸甜比稳定 | 茶饮店、烘焙房 |
| 去皮菠萝（半成品） | 整条去皮、去眼，真空或冷藏 | 后厨人手紧的餐厅 |
| 菠萝块/丁（净菜） | 1–2cm丁，冷链配送 | 炒饭、咕咾肉、披萨 |

**关键点：**
- 餐饮客户更认“去皮净果”而不是带皮果，因为省人工、损耗算得清。
- 熟度要分两档：**7成熟**适合再放1–2天，**8–9成熟**适合当天用。
- 一定要问客户是做冷菜还是热菜：热菜可用偏酸、成熟度略低的；果盘要甜度高、香气足的。

## 二、香蕉：按熟度和单根规格分

香蕉餐饮端主要用于：果盘、早餐、烘焙（香蕉蛋糕/奶昔）、饮品。核心变量是**熟度**和**单根重量**。

| 规格方向 | 建议标准 | 适配客户 |
|---|---|---|
| 大蕉/大果 | 单根180–220g，长度20cm+ | 果盘、酒店自助 |
| 中果（通用） | 单根120–160g | 餐馆、食堂、饮品店 |
| 小果/小米蕉 | 单根60–100g | 高端果盘、儿童餐 |
| 青蕉（耐放） | 5–6成熟，可放3–5天 | 需要囤货的客户 |
| 黄熟蕉（即用） | 7–8成熟，当天至2天内用 | 早餐、烘焙、奶昔 |
| 冷冻香蕉块/泥 | 去皮切块速冻 | 烘焙、奶昔、冰品 |

**关键点：**
- 餐饮客户最怕香蕉“今天到、明天黑”，所以要主动提供**不同熟度批次**，让客户自己排使用节奏。
- 烘焙和奶昔客户更认**冷冻香蕉块/泥**，比鲜蕉稳定，不受季节和熟度波动影响。
- 果盘客户要的是“颜值一致”：长度、弯曲度、无疤无黑点比单纯大小更重要。

## 三、给档口的实操建议

1. **先分客户类型再定规格**，不要只按水果大小分。  
   - 茶饮/烘焙 → 菠萝净果、香蕉冷冻块/泥  
   - 餐馆/食堂 → 中果菠萝、中果香蕉，熟度7成  
   - 酒店/自助 → 大果菠萝、大果香蕉，熟度8–9成

2. **报价按“净出成”算，而不是按毛重。**  
   餐饮客户最容易被“去皮后剩多少”说服。比如菠萝去皮后出成率约50–60%，香蕉去皮约65–70%，把这个数据标出来，比单纯报低价更有竞争力。

3. **提供“到货即用”和“可存放”两个版本。**  
   即用型：熟度到位、可当天加工；  
   存放型：熟度偏低、可放3–5天。  
   这样客户能按自己的翻台和库存节奏下单。

4. **首批建议主推3–4个SKU，不要铺太全。**  
   例如：  
   - 菠萝：中果带皮 + 去皮净果 + 菠萝丁  
   - 香蕉：中果7成熟 + 黄熟即用 + 冷冻香蕉块

5. **用样品测试代替口头承诺。**  
   给餐饮客户送“同规格小样”，让他们实际切、实际出成、实际做菜，比发规格表更有效。
