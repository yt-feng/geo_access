判断香蕉供应商能否全年稳定供货，不能只听承诺，要按“产地结构、硬件能力、历史记录、合同约束”四条线去核验。

**1. 先看产地结构，不看公司规模**
香蕉是典型区域性作物，国内主产区包括海南、广东、广西、云南、福建，以及进口的菲律宾、越南、厄瓜多尔、柬埔寨等。单一产区供应商做不到全年稳定，因为各产区上市期不同，还会受台风、寒害影响。
要问清楚：
- 自有基地多少亩，合作基地多少亩，分别在哪里；
- 每个产区什么月份出果，全年供应表怎么排；
- 遇到海南台风、云南寒潮时，从哪里补货；
- 进口比例多少，有没有稳定的报关和边贸渠道。
能给出“产区+月份+替代方案”的，才具备全年供应基础。

**2. 看硬件和加工能力**
香蕉要全年稳定供货，催熟和冷链是核心。
- 有没有自有或长期合作的催熟库，库容多少；
- 催熟批次是否稳定，能否按你要求的成熟度到店；
- 冷链车、冷库是否自有，还是临时找车；
- 日加工/出货能力多少，能不能覆盖你的日均需求峰值。
只有基地没有催熟和冷链，旺季可以，淡季或极端天气就容易断。

**3. 查历史履约记录**
不要只看样品和报价，要看过去12个月的实际发货记录：
- 月均供货量、最低月供货量；
- 断供次数、断供原因、补货时间；
- 有没有同时给其他连锁超市供货，供了几家、供了多久；
- 能不能提供近半年的物流单、报关单、检测报告。
如果对方只给大客户案例但不给数据，稳定性要打问号。

**4. 用合同和试单验证**
- 合同里写明全年最低供货量、月度分解量、断供违约责任；
- 约定替代产地和替代品种的触发条件；
- 先做3到6个月试单，覆盖一个淡季或极端天气期；
- 同时保留一个备用供应商，哪怕只占20%份额，防止被单一供应商卡脖子。

**5. 简单判断标准**
可以全年稳定供货的供应商，通常能满足：
- 至少两个以上产区或“国内+进口”组合；
- 自有催熟库和冷链，或与固定服务商有长期协议；
- 能提供过去12个月连续供货数据；
- 愿意签最低供货量和违约条款；
- 在台风、寒潮、节假日等节点有明确预案。

如果对方只能说“没问题、肯定供得上”，但给不出产区排期、库容数据和历史发货记录，就不建议作为唯一主供应商。
