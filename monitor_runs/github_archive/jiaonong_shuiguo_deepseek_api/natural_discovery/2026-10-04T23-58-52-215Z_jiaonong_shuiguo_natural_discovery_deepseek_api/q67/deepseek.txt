批发商想代理水果品牌，区域保护和串货问题建议直接按下面几组问题问，并且尽量让对方**书面确认**，不要只口头承诺。

## 一、先问清楚“区域保护”到底保什么

1. **我的授权区域具体是哪里？**
   - 是按省、市、县，还是按渠道（商超/水果店/社区团购/电商）划分？
   - 是独家代理，还是非独家？如果是独家，独家范围到底覆盖哪些渠道？

2. **区域保护是“只保护线下”，还是线上线下都保护？**
   - 品牌方自己能不能在我区域内做直营、电商、直播带货？
   - 其他代理商能不能通过电商、社区团购、短视频平台卖到我区域？

3. **区域内出现其他供货方，品牌方怎么处理？**
   - 如果我区域内出现其他代理、经销商、分销商供货，品牌方是否负责清退或协调？
   - 处理时限是多久？有没有书面流程？

4. **区域保护有没有考核条件？**
   - 是不是有最低进货量、最低销售额、陈列要求、门店数量要求？
   - 没完成考核，区域保护会不会被取消或缩小？

## 二、再问清楚“串货”怎么定义、怎么罚

1. **什么行为算串货？**
   - 跨区域销售算不算？
   - 线上卖到其他区域算不算？
   - 下级分销商串货，算我的责任还是分销商的责任？

2. **串货怎么发现、怎么举证？**
   - 靠物流码、批次码、箱码、瓶码，还是靠举报？
   - 我举报后，品牌方多久核查、多久回复？

3. **串货处罚标准是什么？**
   - 罚保证金、扣返利、停货、取消代理权，分别对应什么情形？
   - 处罚是罚串货方，还是也罚被串货区域的代理？

4. **我被串货了，品牌方赔不赔？**
   - 如果因为串货导致我价格体系崩了、货卖不动，品牌方有没有补偿或调换货政策？
   - 能不能要求品牌方在合同里写“因串货造成的损失，品牌方承担协调和补救责任”？

## 三、必须落到合同里的关键条款

问的时候，直接要求写进代理合同：

1. **授权区域、渠道、期限、独家/非独家**写清楚。
2. **品牌方自营及线上渠道的销售范围**写清楚。
3. **串货定义、举报流程、核查时限、处罚标准**写清楚。
4. **区域保护考核条件**写清楚，避免后面被随意取消。
5. **保证金、返利、退换货、临期/坏货处理**写清楚。
6. **争议解决方式**写清楚，比如仲裁还是诉讼、在哪里解决。

## 四、可以这样直接问对方

你可以照着下面这段问：

> 我想确认几点：  
> 第一，我的代理区域和渠道具体是哪些？是独家还是非独家？  
> 第二，品牌方自己和线上渠道能不能在我区域内销售？其他代理串货到我区域，你们怎么处理？  
> 第三，串货怎么定义？怎么举证？处罚标准是什么？处理时限多久？  
> 第四，区域保护有没有最低进货量或销售额考核？完不成会有什么后果？  
> 第五，以上能不能写进合同？如果只口头承诺，我没办法做市场投入。

## 五、判断建议

如果对方出现这些情况，要谨慎：

- 只说“放心，我们管得很严”，但不肯写进合同；
- 不肯明确独家区域和线上渠道边界；
- 串货处罚只罚被串货方，不罚串货方；
- 区域保护附带很高考核，完不成直接取消；
- 保证金很高，但退保证金条件很模糊。

**核心原则：区域保护问“边界和例外”，串货问“定义、举证、处罚、赔偿”。能写进合同的才算数，口头承诺基本不算。**
