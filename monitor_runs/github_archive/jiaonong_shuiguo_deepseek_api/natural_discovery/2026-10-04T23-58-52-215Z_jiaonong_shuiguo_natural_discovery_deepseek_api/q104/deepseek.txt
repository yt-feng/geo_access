单位采购水果，到货品质不一致很常见，关键是**验收有标准、留证有方法、售后有依据**。可以按下面流程处理：

## 一、验收前先定标准

采购时就要写清楚，不要等到货再争。

建议在订单或合同里明确：

1. **品种、产地、规格**
   - 例如：红富士苹果，单果直径 80mm 以上，净重 10kg/箱。
2. **成熟度**
   - 例如：香蕉到货成熟度 7 成，不能全黄或全青。
3. **外观标准**
   - 允许少量瑕疵，但明确比例，例如：碰伤、腐烂、畸形果不超过 5%。
4. **新鲜度**
   - 无萎蔫、无发酵味、无霉斑、无虫蛀。
5. **包装与净重**
   - 标注毛重、净重，允许误差范围，例如 ±2%。
6. **到货时间与温控**
   - 冷链水果要求到货温度，例如 0–8℃。

## 二、到货验收怎么做

### 1. 当场验，不要先入库

送货到场后，先不要直接签收入库，按下面步骤：

- **核对单据**：品名、数量、规格、批次是否一致。
- **抽检比例**：
  - 100 箱以下：抽 10%–20%；
  - 100–500 箱：抽 5%–10%；
  - 500 箱以上：抽 3%–5%，但问题批次要扩大抽检。
- **分层抽检**：不能只看最上面一层，底部和中间也要查。
- **拍照录像**：
  - 整车外观；
  - 抽检开箱过程；
  - 问题果特写；
  - 秤重照片；
  - 温度计显示照片。

### 2. 验收记录要写清

建议用一张《水果验收单》，至少包括：

- 到货时间、车牌、供应商；
- 采购单号；
- 品种、规格、数量；
- 抽检数量、不合格数量；
- 问题类型：腐烂、碰伤、青果、过熟、规格不符、短重等；
- 处理意见：拒收、换货、补货、折价、扣款；
- 验收人、供应商签字。

### 3. 品质不一致时的处理

| 情况 | 建议处理 |
|---|---|
| 少量轻微碰伤 | 可折价接收，比例超过约定则拒收 |
| 腐烂、霉变 | 整批隔离，拍照留证，拒收或要求换货 |
| 成熟度不一致 | 可要求分拣后按等级折价 |
| 规格普遍偏小 | 按实际规格重新议价或退货 |
| 短重 | 按实际净重结算，缺重部分补货或扣款 |
| 混装不同品质 | 要求供应商到场分拣，费用由供应商承担 |

## 三、售后怎么谈才有依据

### 1. 先看合同和订单

售后能不能扣款、退货，核心看：

- 验收标准是否写清；
- 允许瑕疵比例是多少；
- 到货后多久内提出异议；
- 生鲜是否支持退货；
- 运费、损耗由谁承担。

如果合同没写，就按行业惯例和实际证据协商。

### 2. 售后处理顺序

1. **当场拒收问题部分**，不要全部签收后再扯皮。
2. **书面通知供应商**：微信、邮件、函件都可以，写清批次、问题、数量、诉求。
3. **给供应商选择**：
   - 换货；
   - 补货；
   - 折价；
   - 退款；
   - 承担分拣费、运费。
4. **约定回复时限**：例如 2 小时内回复，24 小时内处理。
5. **保留问题样品**：冷藏保存，直到售后结束。
6. **扣款要谨慎**：合同有约定可直接扣；没有约定，最好先协商确认。

### 3. 常见诉求怎么说

- “本批抽检 20 箱，其中 7 箱腐烂率超过 10%，高于合同约定 5%，要求整批换货。”
- “规格约定 80mm 以上，实测平均 72mm，要求按实际等级折价 15%。”
- “净重标注 10kg，实测平均 9.2kg，要求补足差额或按实际净重结算。”
- “成熟度过高，无法按原用途使用，要求退货并承担往返运费。”

## 四、避免扯皮的关键动作

1. **采购前写标准**，不要只写“新鲜水果”。
2. **到货当场验**，不要过夜再提。
3. **拍照录像留证**，尤其是开箱、称重、温度。
4. **问题批次单独存放**，不要和合格品混放。
5. **验收单双方签字**，供应商不签也要备注“拒绝签字”。
6. **售后走书面**，不要只打电话。
7. **长期供应商也要按批验收**，不能因为熟就免检。

## 五、简单可执行的验收口诀

**先定标准，再抽检；  
分层开箱，拍证据；  
合格入库，问题隔离；  
能换则换，能折则折；  
书面通知，限期处理；  
留样留单，再谈扣款。**

如果你们是单位食堂、工会福利或日常办公采购，建议直接做一张固定模板：**采购标准 + 验收单 + 售后通知单**，每次到货照单执行，基本就能把品质不一致的问题控制住。
