食堂采购香蕉避免熟过头，核心是**控制采购节奏、按成熟度分批使用、入库后抑制后熟**，而不是只靠“买少一点”。

可执行做法：

1. **按使用时间倒推采购成熟度**
   - 当天或次日吃的：买已经黄熟、可直接吃的。
   - 2—3天后用的：买微黄、刚转色、果肉还硬的。
   - 3天以上才用的：买青绿、未完全成熟的。
   - 不要一次性全买同一成熟度，否则会集中熟过头。

2. **分批采购，少量多次**
   - 把一周采购量拆成2—3次。
   - 每次到货后标注到货日期和成熟度，先进先出。
   - 食堂用量稳定的话，按“日用量×1.5天”作为安全库存较实用，避免堆货。

3. **入库后抑制后熟**
   - 香蕉怕低温冻伤，**不建议直接放普通冰箱冷藏**，表皮会变黑。
   - 放在阴凉、通风、避光处，理想温度大致在13—15℃左右。
   - 不要和苹果、梨、番茄等释放乙烯较多的果蔬混放，会加速香蕉成熟。
   - 未熟香蕉可适当密封或套袋，减少乙烯影响；已熟香蕉要分开，尽快用掉。

4. **按成熟度分级使用**
   - 青硬：留放，后续再用。
   - 微黄：优先用于次日早餐、加餐。
   - 黄熟：当天直接分发或做香蕉牛奶、香蕉粥。
   - 过熟但未变质：尽快做香蕉饼、香蕉蛋糕、奶昔、果酱等加工品。
   - 已发黑、发酸、流汁、有酒味：不要食用，及时报损。

5. **和供应商约定成熟度**
   - 采购时明确要求“几成 熟”，比如七成熟、八成熟，不要只写“香蕉多少斤”。
   - 要求分批次配送，避免一次送完全部黄熟香蕉。
   - 对易熟水果可约定“到货成熟度不达标可退换”。

6. **建立简单台账**
   - 记录：到货日期、数量、成熟度、计划使用日期。
   - 每天检查一次，把快过熟的挑出来优先处理。
   - 连续记录几周后，就能算出食堂实际消耗速度，采购量会更准。

一句话：**青黄分开、少量多次、阴凉通风、远离催熟果蔬、快熟快用、过熟加工。** 最关键的是采购时按“使用日期”买对应成熟度，而不是只看价格和总量。
