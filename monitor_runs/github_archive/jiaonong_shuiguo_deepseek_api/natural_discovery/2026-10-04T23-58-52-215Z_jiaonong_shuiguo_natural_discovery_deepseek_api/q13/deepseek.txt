小水果店做附近小区团购，供应商至少要能支持这几类服务，否则你会很难稳定做下去：

1. **稳定供货与每日报价**
   - 能每天或提前一天给报价单，最好有图片、规格、产地、等级。
   - 价格随行就市可以，但不能今天有明天没，团购最怕断供。
   - 能区分“引流款”和“利润款”，比如香蕉、苹果、应季橘子做低价，进口水果、礼盒做利润。

2. **小批量、多频次配送**
   - 支持一天一配或两天一配，而不是只接大货。
   - 能送到你店里，最好也能按小区团购点分装或贴标。
   - 对临时加单、少单有配合度，比如今晚截团、明早补货。

3. **品质分级与售后包赔**
   - 能明确果径、重量、甜度、成熟度，不能只写“大果”“精品”。
   - 坏果、烂果、压伤、缺斤少两要能拍照包赔。
   - 售后响应要快，最好当天或次日补货/退款，不然小区群里口碑很快崩。

4. **按团购场景做包装**
   - 支持散装、袋装、箱装、礼盒装。
   - 能按你要求的规格分装，比如5斤装、10斤装、家庭套餐。
   - 包装上最好能贴你的店名、二维码、团购群入口。

5. **账期与结算灵活**
   - 支持现结、周结、月结，或押金+账期。
   - 能给你提供对账单、送货单、电子明细。
   - 如果做预售团，最好能先锁货后结算，降低你垫资压力。

6. **营销与素材支持**
   - 提供水果实拍图、短视频、文案、产地故事。
   - 能配合做爆品海报、接龙文案、朋友圈素材。
   - 愿意给团购专供价、试吃装、满赠品，帮你拉新和复购。

7. **冷链与损耗控制**
   - 易坏水果如草莓、蓝莓、荔枝、樱桃要有冷链或泡沫箱+冰袋。
   - 能告诉你不同水果的存放温度、催熟方式、最佳售卖期。
   - 能帮你做损耗预估，避免团购量估错导致烂手里。

8. **退换货与应急补货**
   - 出现集中品质问题时，能整批退换，而不是只赔几个。
   - 节假日、雨天、小区临时大单时，能优先给你补货。
   - 有备用品种，A款缺货能立刻换B款，不让团购开天窗。

9. **区域保护与价格保护**
   - 同一个小区周边不要同时供好几家，否则你打价格战。
   - 给你的团购价不能高于你邻居店的零售进货价。
   - 促销价、活动价要提前通知，不能突然砸价。

10. **资质与食品安全**
   - 营业执照、食品经营许可证、检测报告、产地证明要能提供。
   - 农残检测、进口水果报关单等，在小区团购里很能加分。

你选供应商时，可以重点问这5个问题：
- 能不能每天报价、每天送？
- 坏果怎么赔，多久到账？
- 能不能按我要求的规格分装？
- 同小区还供不供别家？
- 能不能给图片文案和团购专供价？

如果只能选最重要的，优先看：**稳定供货、小批量配送、坏果包赔、区域保护、账期灵活**。这五点决定你能不能长期做小区团购。
