酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分成可验收的条款写进采购单或合同，避免只写“新鲜、优质”这类无法判定的描述。可按以下维度要求供应商：

**一、规格标准**

1. **品种与产地**
   - 明确具体品种，如红富士苹果、皇冠梨、圣女果、巨峰葡萄、麒麟瓜等，不接受“同类替代”除非酒店书面同意。
   - 约定产地或品牌范围，保证批次稳定性。

2. **单果规格**
   - 按重量或直径分级，例如苹果单果 180–220g、橙子直径 70–80mm、西瓜单果 4–6kg。
   - 同一批次大小均匀，避免一盘水果里明显大小不一。

3. **成熟度**
   - 到货成熟度以“即切即用”或“可存放 2–3 天”为目标。
   - 要求可食成熟度，不能过生、过熟；香蕉、芒果、牛油果等后熟水果需约定到货硬度或成熟阶段。

4. **净重与出成率**
   - 明确毛重、净重、允许损耗范围。
   - 对需要去皮去核的水果，可约定出成率，如西瓜出成率不低于 60%–65%，避免“带皮称重、切后不够用”。

5. **包装规格**
   - 按箱、按篮、按托盘约定数量，如每箱 12 个、每篮 500g。
   - 内包装应透气、防压、防潮，外箱标注品名、等级、重量、采摘或包装日期。

6. **食品安全与合规**
   - 农残符合国家限量标准，必要时提供检测报告。
   - 预切水果需符合即食食品要求，冷链温度通常控制在 0–4℃。
   - 提供可追溯信息：批次、供应商、基地或加工厂。

**二、外观标准**

1. **新鲜度**
   - 果面有自然光泽，无萎蔫、皱皮、干疤、明显失水。
   - 果梗新鲜，切口不褐变、不发霉。

2. **完整性**
   - 无破损、裂口、压伤、虫蛀、病斑、霉变。
   - 允许的轻微瑕疵应限定比例，例如外观瑕疵果不超过 5%，且不影响切盘。

3. **颜色与成熟外观**
   - 颜色符合品种特征，如苹果红度均匀、芒果转色适度、葡萄果粉完整。
   - 避免青涩、褪色、日灼斑、药斑。

4. **形状与大小**
   - 果形端正，无明显畸形。
   - 同批次大小、颜色、成熟度基本一致，便于摆盘美观。

5. **清洁度**
   - 无泥土、枝叶、虫体、虫卵、明显灰尘。
   - 不允许有异味、腐烂味、发酵味。

6. **温度与运输状态**
   - 到货温度符合品类要求：浆果类通常 0–4℃，热带水果如芒果、香蕉不宜长期低于 10–12℃。
   - 无冷害、冻伤、挤压变形。

**三、验收与退换建议**

- **抽检比例**：每批次随机抽检 5%–10%，大货可按箱抽检。
- **判定规则**：不合格率超过约定比例，如 5%，整批拒收或按比例扣重。
- **退换货**：霉变、腐烂、虫蛀、异味、严重压伤应无条件退换。
- **留样**：每批次留样 24–48 小时，便于追溯。
- **记录**：验收单记录品种、规格、数量、温度、外观、不合格情况。

**四、可直接写进采购单的简版条款**

> 供应商应保证所供水果盘原料品种、产地、规格与订单一致；单果大小均匀，成熟度适于即切即用；果面新鲜、清洁、无腐烂、霉变、虫蛀、异味、严重压伤及明显畸形；农残符合国家限量标准；到货温度符合品类要求；同批次外观瑕疵率不超过 5%，不合格品无条件退换；预切水果须冷链配送并提供批次追溯信息。

如果酒店对摆盘要求高，还可以进一步按“早餐水果盘”“行政酒廊果盘”“宴会果盘”分别设定等级，因为不同场景对大小、颜色和出成率的要求不同。
