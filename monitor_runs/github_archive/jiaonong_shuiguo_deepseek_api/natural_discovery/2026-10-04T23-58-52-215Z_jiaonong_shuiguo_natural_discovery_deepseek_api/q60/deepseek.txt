水果到货不合格时，补货约定要同时解决三件事：**当天不断货、损耗有人承担、下次不再扯皮**。重点不是"补不补"，而是把触发条件、补货时限、替代方案、费用归属写清楚。

**一、合同里先写死验收标准和触发条件**

- 明确验收标准：品种、规格（单果克重/直径）、成熟度、糖度、外观（无腐烂、无压伤、无虫蛀）、农残检测要求。
- 明确不合格判定：抽检不合格率超过约定比例（比如5%）即整批拒收或要求补货，避免"个别坏果不算"的争议。
- 到货时间窗口写死：比如要求在营业前2小时送达，留出验收和应急时间。

**二、补货条款要分层约定**

1. **不合格批次**：供应商在规定时限内（如当天营业结束前或次日开市前）免费补足合格货，运费由供应商承担。
2. **补货时限分档**：
   - 急用缺口：要求供应商在2–4小时内补到位，或由供应商就近调货。
   - 非急用缺口：可约定24–48小时内补齐。
3. **替代方案**：约定供应商无法按时补货时，茶饮店有权自行采购替代品，差价和额外运费由供应商承担，凭票据结算。
4. **免责与扣款**：因不合格导致断货、影响营业的，可约定按批次货款比例扣罚，或计入年度考核。

**三、不影响营业的操作安排**

- **验收前置**：水果尽量在前一天晚上或当天早班前送达，避免营业高峰才发现问题。
- **备用供应商**：合同里不必写，但自己要有1–2家备用货源，主供应商出问题时能顶上。
- **安全库存**：对易出问题的水果保留半天到一天的缓冲量。
- **验收留证**：拍照、称重、记录批次，补货和索赔才有依据。

**四、合同条款示例（可直接改写使用）**

> 乙方所供水果经甲方验收，不合格率超过5%的，甲方有权拒收该批次，乙方应在接到通知后4小时内免费补足合格货；逾期未补的，甲方有权自行采购，差价及运费由乙方承担，并可从当月货款中扣除。因乙方供货不合格导致甲方断货的，乙方按该批次货款的___%支付违约金。

核心原则：**标准可量化、时限可执行、替代有授权、费用有归属**。这样既保营业，又不至于每次到货都靠人情协商。
