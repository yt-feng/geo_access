社区超市卖小包装香蕉，核心不是“把香蕉装进小袋”这么简单，而是要同时解决**采购成熟度、包装透气性、重量规格、损耗分摊**四件事。下面按可执行要点说明。

**一、采购时先定包装规格，再倒推采购标准**

1. **规格建议**
   - 社区超市适合做 **2–3根装** 或 **300–500g装**，不要做太小，否则人工和包装成本占比过高。
   - 如果面向单人/小家庭，优先 **2–3根、约350–450g**；如果做促销引流，可做 **500g家庭小份装**。
   - 同一门店规格不要超过2种，否则分拣、称重、补货都会乱。

2. **采购成熟度**
   - 小包装香蕉最好采购 **青黄交接、七成左右成熟** 的货，不要直接采全黄或已出梅花点的。
   - 因为小包装后顾客翻动多、货架期短，全黄香蕉当天卖不掉就容易变黑。
   - 采购时明确要求供应商按“到店后2–3天可售、4–5天内售完”的节奏发货。

3. **采购单位**
   - 尽量按 **整箱/整梳** 采购，到店再分装，不要直接采购已经分好的小把。
   - 已分好的小把往往切口多、失水快、损耗高，而且你无法控制分切时间。
   - 如果供应商能提供“整梳小把”，要确认是否带轴、切口是否新鲜、有无药水处理。

**二、包装要注意的关键点**

1. **必须透气**
   - 香蕉呼吸强度高，包装不能完全密封。完全密封会闷出黑斑、发软、发酸。
   - 优先选 **打孔 PE 袋、透气膜袋、网袋+标签**，不要用完全密闭的普通塑料袋。
   - 如果门店自己打孔，孔要均匀，不要只打几个大孔导致局部失水。

2. **不要挤压蕉柄和蕉身**
   - 香蕉最怕压伤，压伤处会先黑先烂。
   - 小包装不要用太紧的扎带勒住蕉柄，也不要用硬盒强行塞满。
   - 托盘+收缩膜可以，但收缩膜不能太紧，且要有透气孔。

3. **标签和称重**
   - 如果按份卖，标签要标 **份重、价格、包装日期**；如果按斤卖，要标 **净含量**。
   - 社区超市建议按份卖，减少称重排队，但份重必须稳定，否则顾客会觉得“这袋小那袋大”。
   - 标签不要贴在蕉身正面，最好贴在蕉柄或包装袋边缘，避免撕标签伤果皮。

4. **分装时机**
   - 到店后不要立刻全部分装。先整箱存放，按销售节奏分装。
   - 分装最好在 **销售前半天到1天** 完成，分太早会加速切口失水和黑变。
   - 分装时戴手套，避免手汗和摩擦；刀具要干净，切口尽量平整。

**三、损耗控制要抓的环节**

1. **温度**
   - 香蕉怕冷也怕热。社区超市如果没有冷库，不要放风口直吹，也不要放冷藏柜。
   - 适宜存放约 **13–15℃**，社区店可放在阴凉通风处，避免阳光直射和空调直吹。
   - 夏天高温时，小包装香蕉最好少量多次分装，不要一次摆满货架。

2. **先进先出**
   - 小包装香蕉必须做 **先进先出**，补货时把旧货放前面。
   - 每天至少检查2次，把出黑点、发软、裂口的挑出来。
   - 轻微黑点的可以降价做“即食香蕉”专区，不要和正常品混放。

3. **损耗分摊**
   - 小包装香蕉的损耗通常比整梳高，采购时要把损耗算进毛利。
   - 建议按 **8%–15%** 预估损耗，夏季和分装越细损耗越高。
   - 如果损耗连续一周超过15%，要检查：采购成熟度是否太高、包装是否闷、分装是否太早、货架是否被压。

4. **减少翻拣**
   - 顾客翻动越多，蕉身越容易伤。
   - 可以用小托盘或小筐陈列，减少直接手抓；标签朝外，顾客不用翻。
   - 不要堆叠太高，香蕉承压后底层容易烂。

**四、采购谈判时可以要求供应商配合的事**

- 按门店销售节奏分批送货，不要一次送太多全黄货。
- 提供整梳小把，减少门店分切。
- 明确到货成熟度标准，比如“青黄交接、无黑点、无压伤”。
- 约定坏货处理：到货即有黑斑、压伤、裂口的，能否退换或补差。
- 包装材料如果由供应商提供，要确认是否透气、是否食品级。

**五、最实用的执行清单**

采购时看：
- 成熟度：七成左右，青黄交接。
- 蕉柄：新鲜、无霉、无裂。
- 蕉身：无压伤、无黑斑、无裂口。
- 整梳：尽量整箱整梳，到店分装。

包装时做：
- 2–3根或350–500g一份。
- 透气袋/打孔袋，不密封。
- 不勒蕉柄，不挤压蕉身。
- 标签贴边缘，标份重和日期。

损耗时管：
- 13–15℃阴凉通风。
- 先进先出，每天挑2次。
- 轻微黑点降价处理。
- 损耗按8%–15%预估，超过就查原因。
