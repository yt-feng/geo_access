供应商要把“产地+品种+规格+口感+用法+损耗+价格”说成商家能立刻算账的话，商家才容易下单。不要先讲种植故事，先讲“你拿去怎么卖、能赚多少”。

可以按这个顺序说：

1. **先说它相当于什么**
   - “这个不是普通菠萝，是凤梨类，削皮就能吃，不用泡盐水。”
   - “这个香蕉不是大把熟蕉，是小把装，适合做办公室下午茶。”
   用商家熟悉的品类做锚点，他才听得懂。

2. **说清规格和到货状态**
   - 几斤一箱、几个一箱、单果多重。
   - 是青的、黄的、还是催熟好的。
   - 到货后能放几天，几天后必须卖完。
   商家最怕“说不清一箱到底有多少、好不好分”。

3. **说口感差异，但只用一句话**
   - “比普通菠萝甜，酸味低，纤维少。”
   - “香蕉更糯，皮薄，卖相好。”
   不要长篇讲风味层次，商家要的是卖点。

4. **说适合怎么卖**
   - 水果店散卖、切果盒、奶茶店原料、烧烤店配菜、社区团购。
   - “这个适合做切盒，不出水，放两小时不黑。”
   - “这个适合烤着卖，烤完更甜。”
   直接告诉他客户场景，他就能判断要不要进。

5. **说损耗和利润**
   - 坏果率大概多少。
   - 次果怎么处理。
   - 进货价、建议零售价、一箱能赚多少。
   例如：“一箱20斤，进价80，零售切盒能卖160左右，损耗按2斤算。”
   商家听懂利润，比听懂品种更重要。

6. **给最小起订和试单方案**
   - “先拿一箱试，卖不动我教你做切盒/团购。”
   - “混搭一箱也可以，菠萝+香蕉+小番茄。”
   降低第一次下单压力。

7. **最后给一句明确推荐**
   - “如果你店在社区，我建议先拿小果，便宜好卖。”
   - “如果你做奶茶店，就拿大果，出肉率高。”
   不要让他自己选一堆参数。

一个可直接套用的话术：

> 王老板，这个你把它当成“不用泡盐水的凤梨”就行。一箱20斤，大概8到10个，单果2斤左右。到货是青黄之间的，放2到3天变黄就能卖。口感比普通菠萝甜，酸少，切盒不容易出水。你店里可以整个卖，也可以切盒，一箱进价80，散卖能卖150到180，坏果一般1到2个。你先拿一箱试，卖得好我再给你配香蕉和小番茄，凑成社区团购套餐。

核心原则：**少讲品种，多讲场景；少讲口感，多讲损耗；少讲产地，多讲利润。**
