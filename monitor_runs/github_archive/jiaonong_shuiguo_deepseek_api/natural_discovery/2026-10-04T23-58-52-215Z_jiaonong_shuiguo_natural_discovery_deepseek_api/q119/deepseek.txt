水果生意想长期稳定，选供应商时最容易忽视的，往往不是“价格高不高、货好不好”这些明面上的问题，而是一些会慢慢拖垮利润和口碑的细节。重点看这几类：

**1. 只谈样品，不谈大货一致性**
很多供应商样品很好，但批量发货时等级、糖度、个头、成熟度不稳定。  
要确认：  
- 是否能按固定等级、规格、糖度、成熟度供货  
- 大货和样品差异怎么处理  
- 是否支持抽检、留样、复检  
长期稳定靠的是“每一批都差不多”，不是“偶尔特别好”。

**2. 不看清损耗责任怎么分**
水果损耗高，最容易扯皮的是运输、装卸、仓储、上架前腐烂由谁承担。  
要提前写清：  
- 到货验收标准  
- 破损、腐烂、冻伤、压伤超过多少算不合格  
- 是补货、扣款还是退货  
- 运输温控和时效谁负责  
否则每次出问题都靠关系解决，很难长期。

**3. 忽略供应季节和产地切换能力**
单一产地、单一品种的供应商，旺季可能很便宜，淡季就断供或品质下滑。  
要看供应商是否有：  
- 多产地调配能力  
- 替代品种或等级方案  
- 淡季稳定供货计划  
长期稳定不是永远一个价，而是断货时有人能补位。

**4. 只比采购价，不算综合成本**
低价水果可能带来更高损耗、更差卖相、更多售后。  
要算综合成本：  
- 采购价 + 运费 + 损耗 + 人工分拣 + 售后赔偿  
- 资金占用和账期  
- 因品质问题导致的客流损失  
有些供应商单价高一点，但到店可售率高，反而更赚。

**5. 不重视账期和资金压力**
水果周转快，但现金流也紧。  
要确认：  
- 现结、周结、月结还是押款  
- 是否有起订量、返点、保证金  
- 价格波动时是否锁价  
账期太短会压现金流，账期太长又可能隐含高价或质量风险。

**6. 没有备选供应商**
只靠一个供应商，一旦天气、物流、产地灾害、内部管理出问题，你就被动。  
建议至少保留：  
- 1个主供应商  
- 1个备选供应商  
- 1个应急市场/批发渠道  
并且定期小批量测试备选，不要等断货才找。

**7. 忽略售后响应速度**
水果问题往往时效很强，今天不处理，明天就烂更多。  
要观察：  
- 出问题后多久回复  
- 是否愿意补货或承担部分损失  
- 是否有固定对接人  
- 节假日、凌晨到货时能否联系上  
响应慢的供应商，价格再好也难长期合作。

**8. 不记录供应商表现**
凭感觉选供应商，很容易被关系、话术影响。  
建议建简单台账，记录每批：  
- 到货合格率  
- 损耗率  
- 实际可售率  
- 售后处理速度  
- 价格波动  
连续记3个月，谁稳定、谁爱扯皮，一目了然。

**9. 忽视合同外的“软约定”**
比如：  
- 是否优先给你好货  
- 涨价前是否提前通知  
- 紧俏时是否保你量  
- 是否允许临时调整规格  
这些不写进合同，但决定长期合作体验。最好用微信、邮件留下记录。

**10. 只看供应商，不看上游**
有些供应商也是中间商，上游一断，他就没货。  
要尽量了解：  
- 他是产地直采、合作社、批发市场还是二级贩子  
- 是否有冷库、分选线、物流能力  
- 上游合作是否稳定  
层级越短，通常越稳，但也要看其专业能力。

**简单判断标准：**
一个值得长期合作的供应商，通常能做到：  
- 大货和样品差距小  
- 损耗责任清晰  
- 淡季也能供  
- 出问题响应快  
- 价格随行就市但不过山车  
- 愿意和你一起做长期稳定，而不是只做一锤子买卖。

如果你刚开始做，建议先小批量、多批次测试，别一上来就签长期大单。连续合作2—3个月，看合格率、损耗率和售后，再决定是否加深合作。
