第一次合作做小批量试单，核心目标不是赚钱，而是**用最低成本验证供应商是否靠谱**。试单设计要围绕这个目标来。

## 一、先明确试单要验证什么

试单前先想清楚，你要从这次合作里得到答案的几个问题：

1. **品质稳定性**：到货品相、成熟度、大小是否和样品/描述一致，损耗率多少
2. **履约能力**：能不能按时发货，包装是否到位，运输途中损耗多大
3. **配合度**：出问题时响应快不快，愿不愿意补损、换货
4. **价格与账期**：报价是否实在，有没有隐藏费用（包装费、运费、代收等）
5. **长期潜力**：这个品能不能稳定供应、随季节波动多大

## 二、试单规模怎么定

- **单品单批次为主**：先只试1~2个品种，不要一次铺开多个SKU
- **数量控制在能卖完、亏得起**：一般是常规采购量的10%~20%，或者按你能在3~5天内消化掉的量来定。水果易损耗，压货就是压钱
- **宁可多试几次，不要一次下大**：同一供应商可以分2~3次小单，观察稳定性，比一次中单更能看出问题

## 三、试单谈判要盯住的条款

| 项目 | 建议 |
|------|------|
| 价格 | 明确是否含运费、包装费、损耗承担方式 |
| 账期 | 首次合作建议现款或小额定金+到货结清，别一上来就压款 |
| 验收标准 | 提前约定等级、规格、糖度/成熟度、允许损耗比例 |
| 补损规则 | 超出约定损耗部分怎么赔、怎么补，白纸黑字 |
| 发货时效 | 下单到发货、在途时间写清楚 |
| 退换货 | 出现严重质量问题能否退货或折价 |

口头承诺不算，关键条款尽量走聊天记录或合同，方便后续追责。

## 四、到货后的验收动作

1. **当场或第一时间开箱抽检**：不同位置抽样，别只看表面
2. **记录数据**：到货重量、坏果率、成熟度、包装完好度，拍照留证
3. **快速分销测试**：看终端客户/下游反馈，口感、卖相、复购意愿
4. **算真实成本**：把损耗、运费、退货都算进去，看实际毛利，而不是只看报价

## 五、几个容易踩的坑

- **只看报价低就下单**：低价往往对应低等级或高损耗，算总账才准
- **一次试太多品种**：问题混在一起，说不清是供应商问题还是品类问题
- **不约定补损**：水果损耗是常态，没约定就只能自己扛
- **没留证据**：出问题时空口无凭，供应商容易推诿
- **试单顺利就立刻放大**：至少稳定合作2~3次再考虑加量

## 六、一个可执行的试单节奏

1. 先要样品/小样，确认基本品质
2. 下第一批小单（常规量的10%~15%），重点看履约和包装
3. 到货验收+分销，记录数据和问题
4. 有问题就沟通，看对方配合度
5. 顺利的话再下1~2次小单，验证稳定性
6. 稳定后再逐步放量，同时保留备选供应商

**一句话原则**：试单是花钱买信息，不是买货。把验证目标、验收标准、补损规则定清楚，比纠结单价几毛钱更重要。
