水果店卖菠萝，控制损耗的关键是：**采购时不要按“已经熟了”来进，而要按“能在货架期内刚好成熟”来进**。具体判断可以分几步：

1. **看外观**
   - 想要耐放一点：选**表皮偏青绿、果眼紧密、没有明显发黄**的。
   - 想尽快卖：选**基部开始转黄、果眼稍开**的。
   - 如果整颗已经**通体金黄、果眼大而松**，通常熟度高，适合1～2天内卖完，不适合长途或久放。

2. **看基部**
   - 菠萝基部，也就是靠近底部那一端，通常最先转色、最先变软。
   - **基部发黄、有轻微果香**：熟度开始上来。
   - **基部发软、汁水渗出、有酒味**：过熟或开始坏，损耗风险大。

3. **闻气味**
   - 靠近基部闻：
     - 几乎没味：偏生，可放。
     - 有清甜菠萝香：适熟，适合尽快卖。
     - 香味浓、发酸、发酒：过熟，别多进。

4. **按压判断**
   - 轻轻按基部：
     - 很硬：生，耐放。
     - 稍软有弹性：熟度合适。
     - 一按就凹、皮发软：过熟，损耗高。

5. **看叶片**
   - 叶片青绿、挺立：通常较新鲜。
   - 叶片干枯、基部发黄发软：放置时间可能偏长，熟度也偏高。

6. **采购策略**
   - 如果店里客流稳定、周转快：可以进**基部微黄、有淡淡香味**的，减少催熟等待。
   - 如果周转慢或天气热：进**表皮偏青、基部硬、无香味**的，放在阴凉通风处慢慢熟。
   - 夏天高温：尽量少进高熟度果，因为菠萝后熟快，两三天就可能软烂。
   - 冬天低温：可以适当进熟一点的，但注意防冻伤。

7. **简单分级**
   - **青皮硬果**：可放3～7天，适合囤货。
   - **基部微黄、略香**：可放1～3天，适合正常销售。
   - **全黄浓香、基部软**：当天到次日必须卖完，适合促销或切果盒。

实际采购时，最稳的办法是：**同一批里青、黄搭配进，青的压库，黄的引流，按“先熟先卖”轮换**。这样比全部进熟果或全部进生果，损耗都更低。
