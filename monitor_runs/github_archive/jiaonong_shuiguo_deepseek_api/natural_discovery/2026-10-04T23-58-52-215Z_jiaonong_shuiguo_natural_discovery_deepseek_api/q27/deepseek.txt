判断苹果和橙子的规格是否适合门店销售，可以从**目标客群、陈列方式、定价带、损耗率**四个角度快速判断：

## 1. 先定销售场景
- **社区店/便利店**：适合中小规格，方便单次购买、即食。
  - 苹果：单果约 **160–220g**，直径约 **70–80mm**
  - 橙子：单果约 **180–250g**，直径约 **70–85mm**
- **精品超市/礼盒**：适合大果、均匀果。
  - 苹果：单果约 **220–300g**，直径约 **80–90mm**
  - 橙子：单果约 **250–350g**，直径约 **80–95mm**
- **批发/家庭囤货**：可接受更大规格，但要注意价格敏感度。

## 2. 看大小是否均匀
门店销售最怕“一箱里大小差太多”。
- 同批次果径差异最好控制在 **5–10mm 内**
- 单果重量差异最好控制在 **20–30g 内**
- 如果大小混杂，适合做促销装、散装，不适合做精品陈列或礼盒。

## 3. 看陈列和包装适配
- 苹果：常见托盘、礼盒、保鲜袋。果径太大可能装不下或压伤。
- 橙子：常见网袋、礼盒、散装堆头。果径太大堆头容易滚落，太小显得不饱满。
- 如果要按“几个装”卖，先算：
  - 5kg 箱装苹果，单果 200g，约 25 个；单果 250g，约 20 个。
  - 10kg 箱装橙子，单果 200g，约 50 个；单果 250g，约 40 个。
  这直接影响定价和毛利。

## 4. 看损耗和货架期
- 大果通常单价高，但一旦碰伤、失水，损耗金额更大。
- 小果单价低，周转快，但顾客可能觉得“不够吃、不划算”。
- 门店若客流不稳定，优先选**中等规格、硬度好、耐运输**的货。

## 5. 简单执行标准
采购时可以直接这样判断：
1. **量 10 个果**，算平均单果重和最大最小差。
2. **看果径**，用卡尺或分级圈，确认是否集中在同一规格带。
3. **试装**，按门店包装方式装一盒/一袋，看是否美观、是否挤压。
4. **算售价**，按目标毛利率反推：
   - 售价 = 采购成本 ÷（1 - 目标毛利率）
   - 如果算出来高于周边同类门店，规格可能偏大或采购价偏高。
5. **问客群**：门店主要卖即食、家庭装还是礼盒？规格跟着客群走。

## 6. 快速结论
- **社区日常销售**：苹果 70–80mm、橙子 70–85mm 最稳。
- **精品/礼盒**：苹果 80–90mm、橙子 80–95mm 更合适。
- **大小差异超过 10mm 或重量差超过 30g**：不适合做精品，建议做散装或促销。
- **如果包装后显得空、挤、滚、压**：规格就不适合当前门店销售。
