水果锁价能锁多久，没有统一标准，主要取决于品类、季节、供应商类型和你的采购量。大致可以按下面判断：

1. **常规鲜果（苹果、梨、柑橘、香蕉等）**
   - 一般能锁 **1～3个月**。
   - 供应稳定、耐储存的品类，遇到长期合作供应商，可能锁 **3～6个月**。
   - 超过一个产季或跨季，供应商通常不愿锁，因为天气、产量、运费会变。

2. **应季水果（荔枝、龙眼、桃、西瓜、葡萄等）**
   - 通常只能锁 **1～4周**，甚至按周锁。
   - 因为上市期短、价格波动大，供应商一般只接受短期锁价或随行就市。

3. **进口水果**
   - 常见锁 **2～4周**，部分稳定单品可到 **1～2个月**。
   - 受汇率、海运费、关税、到港品质影响，长锁难度大。

4. **大宗长期采购**
   - 如果你采购量大、付款条件好、能接受分级定价，可能谈到 **3～6个月**。
   - 但通常会附带条件：比如锁量不锁价、保底量、价格调整机制、品质等级范围。

**比较现实的做法：**
- 短期锁价：**1个月**，最容易谈成。
- 中期锁价：**1～3个月**，适合常规水果。
- 长期锁价：**3～6个月**，只适合耐储、供应稳、量大且长期合作的品类。

**谈判时要注意：**
- 锁价要同时锁 **规格、等级、包装、运费、税费、付款方式**，否则供应商可能降品质。
- 最好加“天气、政策、运费大幅波动时可重新协商”的条款。
- 如果供应商坚决不锁长价，可以改成 **保底价+浮动上限**，比死锁更现实。

简单说：**鲜果一般锁1～3个月；应季果锁几周；进口果锁2～4周；量大长期合作最多3～6个月。**
