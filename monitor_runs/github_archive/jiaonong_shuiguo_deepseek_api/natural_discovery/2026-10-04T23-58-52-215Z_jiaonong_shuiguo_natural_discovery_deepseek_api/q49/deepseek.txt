旺季菠萝突然放量，最怕的是临时口头加单后供应商涨价、拖时间或给次果。建议你按下面几步和供应商把临时补货约定清楚。

**一、先锁定核心条款**
和供应商补签一份简单的《旺季临时补货确认单》，哪怕微信文字确认也行，但要有这几项：

1. **临时增量上限**：约定旺季期间每天/每周最多可临时加多少件，比如“日常300斤基础上，每周可临时追加不超过200斤”。
2. **提前下单时间**：比如“临时补货需提前24小时下单，当日15:00前下单次日到”。
3. **价格机制**：写死临时补货单价，或约定“按当日市场价上浮不超过X%”，避免坐地起价。
4. **规格和品质标准**：明确品种、成熟度、单果重量范围、糖度、无黑心/烂心比例等，最好附照片或样品。
5. **违约责任**：供应商未按时到货或品质不达标，怎么赔、怎么退换。

**二、用“保底+弹性”方式谈**
不要只谈临时加单，容易被动。可以这样谈：
- 承诺旺季整体采购量不低于某个数；
- 供应商保证日常供应稳定，并预留临时增量能力；
- 临时增量部分价格可以略高，但要有上限。

**三、提前做两件事降低风险**
- **提前备样封存**：旺季前和供应商一起确认标准样品，双方各留一份，到货争议时有依据。
- **准备备选供应商**：至少再找1家能应急供货的，哪怕价格稍高，也能防止被单一供应商卡住。

**四、执行层面的小技巧**
- 每次临时补货都用微信或邮件确认：品种、数量、单价、到货时间、品质要求，让对方回复“确认”。
- 到货当场抽检，拍照留证，不合格直接按约定退换。
- 如果用量波动大，可以改成“隔日补货+安全库存”模式，而不是天天临时加单。

**一句话建议**：把临时补货写成有数量上限、提前期、价格上限和品质标准的书面确认，再留一个备选供应商，基本就能稳住旺季菠萝供应。
