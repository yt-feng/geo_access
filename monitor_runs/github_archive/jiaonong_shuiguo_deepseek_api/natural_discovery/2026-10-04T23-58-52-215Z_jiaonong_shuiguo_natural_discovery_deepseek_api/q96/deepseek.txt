最需要优先关注的是**食品安全**。对企业食堂来说，这不是“三者随便选一个”的问题，而是有明确优先级：

**食品安全 > 配送准时 > 价格**

原因很直接：

1. **食品安全是底线，出问题代价最大**
   企业食堂面对的是员工集中用餐。水果一旦出现农残超标、霉变、腐烂、致病菌污染等问题，可能导致群体性健康事件。后果包括员工健康受损、企业停工、赔偿责任、监管处罚和声誉损失。省下来的采购差价，远不足以覆盖一次食安事故的成本。

2. **配送准时是硬约束，但通常可以通过合同和备选供应商管理**
   水果配送不准时，会影响食堂供餐计划，尤其是早餐、下午茶或接待场景。但这个问题一般可以通过约定到货时间、设置迟到扣款、准备备用供应商来缓解，属于运营问题，不是底线问题。

3. **价格重要，但不应排在第一位**
   企业食堂采购通常追求性价比，但水果价格波动大，如果一味压价，容易倒逼供应商降低品质，比如用临期果、次果、未成熟果，反而增加食安和浪费风险。合理做法是：在满足食品安全和配送要求的前提下，再比价、议价。

实际操作上，建议这样排序和管理：

- **准入阶段**：供应商必须有营业执照、食品经营许可证，水果批次可追溯，能提供农残检测报告或合格证明。
- **验收阶段**：重点查新鲜度、有无霉变腐烂、包装是否污染、冷链是否合规。不合格直接拒收。
- **配送阶段**：合同写明到货时间、温控要求、迟到处理、退换货机制。
- **价格阶段**：用季度比价、多家询价、阶梯报价控制成本，而不是牺牲质量换低价。

一句话总结：**食品安全是一票否决，配送准时是履约要求，价格是优化目标。顺序不能倒。**
