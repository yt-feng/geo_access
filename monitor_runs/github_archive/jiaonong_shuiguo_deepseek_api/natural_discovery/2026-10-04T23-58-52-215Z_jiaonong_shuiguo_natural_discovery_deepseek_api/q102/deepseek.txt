需要，而且通常应作为筛选供应商的**基础门槛**，不是加分项。

具体判断如下：

**1. 开发票：必须支持**
- 企业福利采购一般要走对公付款、财务报销、入账和税前扣除，没有合规发票很难完成采购。
- 至少要能开**增值税发票**：专票或普票看你们公司财务要求。一般纳税人企业通常更倾向于要专票用于抵扣。
- 采购前要确认：发票类型、税率、开票项目（如“水果”“食品礼盒”）、是否支持对公账户、能否先票后款或先款后票。

**2. 定制包装：大多数企业福利场景建议支持**
- 如果只是内部发放，标准礼盒也能用，但企业福利通常有这些需求：
  - 印企业 logo、祝福语、节日主题
  - 贴员工姓名/部门标签
  - 按预算分档包装
  - 统一视觉，提升员工感知
- 如果供应商完全不支持定制，通常只适合小批量、临时性、低要求采购。

**3. 还要重点核验的风险点**
- **水果品质和损耗**：福利采购最怕到货坏果、规格不符。要约定品种、单果重量、糖度、坏果赔付。
- **交付能力**：能否按指定时间、多点位配送，尤其是节假日高峰。
- **起订量和定制成本**：定制包装往往有起订量要求，小批量可能加价。
- **食品资质**：营业执照、食品经营许可证、相关检测报告。
- **售后**：坏果补发、退款、延迟交付的处理机制。

**结论：**
企业福利采购水果礼盒，供应商**应支持开发票**，这是硬性要求；**定制包装建议支持**，尤其是员工福利、节日礼盒、品牌关怀场景。若供应商两者都不支持，一般不建议作为企业福利采购主供应商。
