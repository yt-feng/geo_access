要避免香蕉到店后很快变黑，核心是控制 **成熟度、温度、乙烯、机械损伤** 这四件事。

**1. 采购时别买太熟的**
- 选 **青黄相接、果柄仍偏绿、手感硬实** 的香蕉，不要选已经全黄、带黑点、发软的。
- 如果计划1～2天内用完，可以买稍黄一点的；如果要用3～5天，尽量买偏青的。
- 要求供应商发 **未催熟或轻度催熟的货**，而不是已经催熟到位的即食香蕉。

**2. 运输和到店后不要堆压**
- 香蕉怕压、怕摔。纸箱不要堆太高，避免底层被压伤。
- 到店后先 **开箱散热、检查**，把已经发软、破皮、有黑斑的挑出来，避免传染其他香蕉。
- 不要直接扔在潮湿地面或闷热角落。

**3. 控制存放温度**
- 香蕉最适合的存放温度大约是 **13～15℃**。
- 不要放冷藏：低于约12℃容易冻伤，表皮会快速变黑。
- 夏天如果室温超过25℃，尽量放阴凉通风处，或放空调房/冷库缓冲间，但别贴近冷风口。
- 冬天避免放在暖气旁或温差大的地方。

**4. 减少乙烯影响**
- 香蕉自身会释放乙烯，催熟自己，也会催熟其他水果。
- 到店后尽量 **分小批存放**，不要一大箱闷着。
- 不要和苹果、梨、猕猴桃、牛油果等一起放，它们也会释放乙烯。
- 如果条件允许，可用 **乙烯吸收剂** 或通风降低乙烯浓度。

**5. 悬挂或单层摆放**
- 有条件就 **悬挂起来**，减少受压。
- 没条件就 **单层平放**，果柄朝上或侧放，避免堆叠。
- 不要用塑料袋长期密封，容易闷出黑斑；可套透气纸袋或保鲜袋但要开口。

**6. 按用量分批处理**
- 当天用的和后面几天用的分开存。
- 已经熟了的优先用掉，或去皮冷冻做奶昔、烘焙、香蕉泥。
- 需要延缓成熟时，可把偏青的放阴凉处；已经黄的尽快用完。

**7. 采购频率比一次囤货更重要**
- 甜品店如果每天用量稳定，最好 **少量多次采购**，比如每2～3天一次。
- 一次买太多，后面必然会有压伤和过熟。

**简单判断标准：**
- 想放3天以上：买 **青、硬、无黑点** 的。
- 想放1～2天：买 **黄中带绿、硬实** 的。
- 已经全黄、有黑点、发软：当天尽量用完，别再存。

如果店里没有13～15℃的恒温条件，最实用的做法就是：**少量多次采购 + 到店开箱散热 + 单层/悬挂 + 不冷藏 + 远离其他水果**。
