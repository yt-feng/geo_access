可以按“等级 + 规格 + 单价 + 起批量”四个维度报价，最清楚。香蕉和菠萝分级逻辑不同，建议分开列。

**一、香蕉分级报价**
按“外观 + 长度/把重 + 成熟度”分：

| 等级 | 标准 | 报价方式 |
|---|---|---|
| A级 | 果形直、无黑斑、无擦伤，长度均匀 | 按斤/按箱报 |
| B级 | 轻微花皮、少量斑点，不影响卖相 | 按斤/按箱报 |
| C级 | 花皮多、成熟偏快，适合促销 | 按斤/按件清货价 |

报价模板：
- A级：__元/斤，__斤/箱，__箱起批
- B级：__元/斤，__斤/箱，__箱起批
- C级：__元/斤，__斤/箱，__箱起批

香蕉最好再标一句：**“以到货当天成熟度为准，催熟果另议。”**

**二、菠萝分级报价**
按“大小 + 成熟度 + 外观”分：

| 等级 | 标准 | 报价方式 |
|---|---|---|
| 大果 | 单果__斤以上，果形正 | 按个/按斤 |
| 中果 | 单果__—__斤 | 按个/按斤 |
| 小果 | 单果__斤以下 | 按个/按斤 |
| 次果 | 歪果、擦伤、熟度高 | 按件/按斤清 |

报价模板：
- 大果：__元/个，__个/箱，__箱起批
- 中果：__元/个，__个/箱，__箱起批
- 小果：__元/个，__个/箱，__箱起批
- 次果：__元/斤，__斤/件，清货价

菠萝最好标明：**“是否去皮、是否带冠、是否催熟、糖度范围”**，否则小店很难判断值不值。

**三、最清楚的报价单格式**
建议直接这样发给小店：

> 香蕉：
> A级 __元/斤，__斤/箱，__箱起批
> B级 __元/斤，__斤/箱，__箱起批
> C级 __元/斤，__斤/箱，__箱起批
>
> 菠萝：
> 大果 __元/个，__个/箱，__箱起批
> 中果 __元/个，__个/箱，__箱起批
> 小果 __元/个，__个/箱，__箱起批
> 次果 __元/斤，__斤/件，清货价
>
> 备注：价格含/不含运费；到货__小时内验货；生鲜损耗__%内不售后。

**四、关键建议**
1. **香蕉按斤更稳**，因为催熟后重量和损耗变化大。  
2. **菠萝按个更好卖**，小店容易算毛利。  
3. **一定要写起批量、运费、售后规则**，否则分级再清楚也容易扯皮。  
4. **同一等级不要混装**，混装会直接导致小店压价。  
5. **每周更新一次价格**，香蕉菠萝波动快，报价单要带日期。
