建议按“销售场景 + 损耗控制”来选，通常不是三选一，而是组合上架。

**直接结论：**
- **主推小把装**：3–5根一把，最适合便利店冲动购买和单人/双人即食。
- **搭配单根卖**：只适合放在收银台附近，作为“顺手加购”，但损耗和称重/定价麻烦。
- **整袋装谨慎上**：适合家庭客群明显的社区店，否则容易滞销、发黑、压损。
- **最稳做法**：小把装为主，单根做补充，整袋只在部分门店或特定时段试销。

**判断依据：**

1. **购买人数**
   - 单人、上班族、学生：更愿意买1–3根，小把或单根。
   - 家庭采购：更可能买整袋或大把。
   - 便利店主流客群通常是即时消费，所以小把装最匹配。

2. **损耗控制**
   - 香蕉熟得快，整袋一旦卖不完，损耗集中且金额高。
   - 单根虽然灵活，但顾客挑拣多，容易碰伤、掉把。
   - 小把装相对平衡：单价不高，份量合适，挑拣损耗较小。

3. **陈列与运营效率**
   - 单根需要逐根定价或称重，收银效率低。
   - 小把可以按“把”定价，比如3元/把、5元/把，方便快速结算。
   - 整袋适合直接标价，但占陈列面，周转慢时容易变黑。

4. **毛利与客单价**
   - 单根客单价最低，但能提高购买频次。
   - 小把客单价适中，最容易跑量。
   - 整袋客单价高，但购买频次低，适合家庭社区店。

**可执行建议：**
- 先做7天测试：
  - A区：小把装，3–5根，占60%陈列。
  - B区：单根，放收银台，占20%。
  - C区：整袋，占20%，只试社区店或晚间家庭客流。
- 每天记录：销量、报废量、顾客询问。
- 7天后保留周转最快、损耗最低的规格，淘汰滞销规格。
- 如果门店面积小、客流以即时购买为主：直接只上小把装。
- 如果门店在社区、家庭客多：小把 + 整袋。
- 如果门店在写字楼、地铁口、学校旁：小把 + 单根。

**简单决策表：**
- 写字楼/地铁口/学校：小把为主，单根补充。
- 社区家庭店：小把 + 整袋。
- 面积很小/人手少：只做小把。
- 想测试新品：三种都小批量上，7天看数据再定。

一句话：**便利店卖香蕉，优先小把装；单根做顺手购；整袋只适合家庭客群明显的店，且必须试销。**
