可以，而且这通常是做自有品牌水果时供应商最常提供的支持之一，但要看你和供应商的合作深度以及品类。

**供应商通常能提供的包装和规格支持包括：**

- **规格分级**：按果径、重量、个数、糖度等做分选，比如“单果≥80mm”“6个装”“净重2.5kg”等。
- **包装形式**：礼盒、托盘+收缩膜、网套、纸箱、手提袋、保鲜袋等，供应商一般有现成模具或合作包材厂。
- **贴牌/定制包装**：在包装上印你的商超品牌、Logo、产地、追溯码等，通常需要达到一定起订量。
- **预包装与条码**：做称重码或固定条码的预包装，方便门店直接上架。
- **产地直发或代分装**：部分供应商可代做分选、包装、贴标后直发门店或仓。

**但要注意几个现实约束：**

1. **起订量**：定制包装一般有最小起订量，量小可能只能贴不干胶标签，不能定制彩箱。
2. **包材成本归属**：要提前谈清包材费、制版费、贴标费由谁承担，是否计入采购价。
3. **品控责任**：包装后出现烂果、重量不足、规格不符，责任怎么划分，要在合同里写清楚。
4. **供应稳定性**：自有品牌最怕断货和品质波动，建议至少锁定一个主供应商加一个备用。
5. **合规标识**：预包装水果的标签要符合当地法规，包括品名、净含量、产地、生产商/分装商、保质期/贮存条件等。

**建议你这样做：**

- 先选1-2个单品试点，比如苹果、橙子、猕猴桃这类标准化程度高的。
- 让供应商提供包装样品和规格标准书，你拿实物做门店测试。
- 合同里明确：规格、损耗率、包装标准、交货周期、退换货和违约责任。
- 如果供应商只能供散货、不能做定制包装，你可以找第三方分选包装厂，但成本和管理复杂度会上升。

简单说：**能，但要在合作前把规格、包装、起订量、成本和责任谈清楚，最好先小批量试点。**
