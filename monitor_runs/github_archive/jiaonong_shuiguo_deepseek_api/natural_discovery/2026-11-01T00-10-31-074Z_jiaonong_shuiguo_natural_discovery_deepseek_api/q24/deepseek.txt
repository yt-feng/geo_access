可以按“批次”要，别只要一张年度报告。建议向供应商索要并留存以下资料：

1. **该批次水果的农残检测报告**
   - 优先要 **CMA/CNAS 资质检测机构**出具的报告。
   - 报告上要能对上：品名、产地、供应商/生产单位、**批次或采收日期**、检测项目、检测结果、报告编号和日期。
   - 不要接受“只写水果品类、没有批次”的通用报告。

2. **供应商的进货凭证和产地证明**
   - 采购合同/订单、发票或送货单，能追溯这批货从哪来。
   - 产地证明、种植基地信息或合作社/农场名称。
   - 如果是批发市场进货，要市场开具的销售凭证和供货商信息。

3. **供应商资质**
   - 营业执照。
   - 食品经营许可证或食用农产品销售相关资质（按当地要求）。
   - 如果是生产企业/合作社，尽量要种植或生产环节的质量承诺/管理制度。

4. **承诺书/质量保证协议**
   - 明确农残超标责任、退换货和赔偿条款。
   - 要求供应商承诺按食品安全标准供货，并配合抽检不合格追溯。

5. **快检记录（如有）**
   - 供应商自检或市场快检记录可作为辅助，但不能替代法定检测报告。

6. **重点品种加码**
   - 对高风险或抽检常出问题的品种（如叶菜、豇豆、韭菜、草莓、葡萄等），建议**每批要报告或批批快检**，并在合同中约定抽检不合格处理。

实操建议：收货时把“报告批次号、送货单批次、实物标签”三者核对一致；资料至少留存到该批次销售完毕后一个合理期限，通常按你们内控和监管要求保存。若供应商拿不出批次检测报告，优先换供应商或对该批做第三方送检，别只靠口头保证。
