水果礼盒要好卖，核心不是“凑四样”，而是**让顾客一眼看懂用途、价格和分量**。苹果、橙子、香蕉、菠萝这套组合可以做，但建议按场景拆成3档，而不是只做一个混合装。

### 1）主推款：日常送礼/探病款（最好卖）
**配置建议：苹果4个 + 橙子4个 + 香蕉1把（约5-6根）+ 菠萝1个**
- 寓意：苹果平安、橙子吉利、香蕉招财、菠萝旺来，话术好讲。
- 定位：**39-59元档**，走量款。
- 包装：透明手提礼盒或牛皮纸盒+果篮纸丝，不要过度包装。
- 关键：香蕉容易催熟其他水果，**香蕉单独套袋**，礼盒内放隔板。

### 2）中档款：节日/走亲访友款
**苹果6个 + 橙子6个 + 香蕉1把 + 菠萝1个**
- 定位：**69-99元档**。
- 卖点：分量足、颜色齐、适合上门。
- 可加一张手写卡片：平安吉利、事事旺。

### 3）小份尝鲜款：办公室/随手礼
**苹果2个 + 橙子2个 + 香蕉3根 + 小菠萝1个**
- 定位：**19-29元档**。
- 用小型开窗盒，主打“一人食/下午茶”。
- 不建议大量备货，先试销。

### 搭配和陈列注意
- **苹果、橙子耐放，做视觉主位；香蕉、菠萝做颜色点缀。**
- 香蕉不要和苹果、橙子紧贴，苹果释放乙烯会加速香蕉和菠萝成熟。
- 菠萝选小果或凤梨，降低礼盒重量和成本。
- 礼盒上直接贴标签：**“平安吉利旺来盒”**，比写“水果礼盒”好卖。
- 定价用尾数8/9，设**买两盒减5元**，主推企业团购和探病场景。

### 不建议的做法
- 四样等量硬凑，成本高、看着乱。
- 用熟香蕉做礼盒，运输后容易发黑。
- 菠萝带冠芽太长，盒子不好封，建议切冠或选小果。

**结论：先主推“苹果4+橙子4+香蕉1把+菠萝1个”的39-59元款，用“平安吉利旺来”做卖点；节日再加量到69-99元款。** 先各备10-15盒试销，看哪种场景卖得快再调整。
