会增加，而且香蕉的风险通常比菠萝更高。

**判断要点：**
1. **香蕉**：后熟快、货架期短，起订量过高会显著放大催熟不均、过熟、碰伤和滞销损耗。尤其是按“件/箱”起订且单箱重量大时，门店或小仓很难在最佳窗口内卖完。
2. **菠萝**：相对耐储，但整箱起订量高仍会带来集中成熟、机械损伤、冷害或黑心病等风险，周转慢时损耗也会上升。
3. **共性风险**：起订量高会压低周转速度、增加库位占用和翻拣次数，先进先出执行不到位时，损耗会从“个别坏果”变成“整批过期/过熟”。

**可执行建议：**
- 先按近4周日均销量×配送周期×1.2~1.5倍安全系数测算起订量，不要只看单价折扣。
- 香蕉优先争取“小规格箱、多频次配送”，并明确到货成熟度；菠萝可适当集中采购，但要控制单批到货量并检查成熟度一致性。
- 对比“单价下降省下的钱”与“预计损耗金额+库位/人工成本”，若预计损耗率上升超过采购折扣收益，就不应提高起订量。
- 设置到货验收标准：香蕉看色卡和机械伤，菠萝看果眼、底部和有无异味；不合格批次拒收或折价，避免损耗后移。
- 高起订量批次先做小范围试销或分仓分流，不要一次性全压在主仓。

结论：**起订量高确实增加损耗风险，香蕉更敏感；应优先用小规格、多频次和销量测算来对冲，而不是单纯追求采购折扣。**
