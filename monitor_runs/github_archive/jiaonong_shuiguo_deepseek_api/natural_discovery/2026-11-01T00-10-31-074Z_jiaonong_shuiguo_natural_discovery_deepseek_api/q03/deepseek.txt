第一次试单，核心不是“找最低价”，而是用最小成本验证供货商的**稳定性、损耗承担、结算规则**。夫妻店建议按下面做：

## 一、先定试单原则
1. **少量多品**：每个供货商第一次只拿香蕉、苹果、橙子各1—2箱，别一次压太多。
2. **先试再签**：不交押金、不签长期独家、不承诺月采购量。
3. **同一标准比价**：同规格、同等级、同到店价比较，别拿A家统货比B家精品。
4. **保留证据**：每次到货拍照、称重、记录坏果数，微信文字确认价格和售后。

## 二、三类货怎么试
**香蕉**
- 重点看：成熟度、催熟是否均匀、青蕉/黄蕉比例、运输压伤。
- 试单量：先拿1箱，要求“到店可售成熟度”，不要全青或全黄。
- 问清楚：几天内能卖完的熟度、出现黑斑/压伤怎么补。

**苹果**
- 重点看：规格是否统一、大小是否掺差、碰伤率、口感脆度。
- 试单量：1箱中果或小果，夫妻店走量款优先。
- 问清楚：是按斤还是按箱结算、箱内净重、坏果包赔比例。

**橙子**
- 重点看：皮厚薄、干水率、酸度、大小均匀度、烂果率。
- 试单量：1箱，切开抽检3—5个。
- 问清楚：是否当季产地直发、干水果怎么算、能否换货。

## 三、到货当天必做5件事
1. **称净重**：去掉箱皮、垫纸，核对实际净重。
2. **抽检**：每箱抽10%看坏果、压伤、规格。
3. **拍照留档**：整箱、标签、坏果特写、称重照片。
4. **记录售后响应**：坏果报给供货商，看多久回复、是否爽快补。
5. **算真实毛利**：到店价＋损耗＋人工分拣＝真实成本，再对比售价。

## 四、给供货商的确认话术
可以直接发微信：
> 第一次先试单：香蕉1箱、苹果1箱、橙子1箱。请确认到店价、净重、规格、坏果包赔比例、出现质量问题多久内反馈有效、补货还是退款。先不签长期，试单合适再继续。

## 五、判断是否继续合作
继续合作看4点：
- 连续2—3次到货**规格稳定**；
- 坏果率能控制在你能接受的范围内，且售后不扯皮；
- 价格不是最低但**真实成本低**；
- 缺货、换货、配送时间靠谱。

不建议第一次就找“全场最低价”的流动批发车，优先选本地批发市场有固定档口、能微信留痕、愿意小量试单的供货商。试单期控制在1—2周，三家比完再定主供和备供。
