需要，而且这是企业福利采购里应当前置确认的两项供应商能力，不能等到下单后再补问。

**1. 发票：必须支持，建议写进采购条件**
- 企业福利采购通常需要报销入账，供应商应能开具合规发票。
- 下单前确认：发票类型（增值税专用发票/普通发票）、税率、开票项目（水果/礼盒/食品等）、开票时间、是否支持先票后款或款到开票。
- 若涉及员工福利发放，还要确认发票抬头、税号、备注栏要求，避免后续财务退票。

**2. 定制包装：多数企业福利场景需要，但取决于用途**
- 如果是节日福利、客户答谢、员工关怀，通常需要定制包装，如企业LOGO、贺卡、祝福语、统一视觉。
- 需提前确认：起订量、设计稿确认周期、打样费用、打样时间、包装材质、是否额外收费、定制后是否影响退换货。
- 水果礼盒有保鲜和运输要求，定制包装不能牺牲防护性，建议同时确认冷链/防撞/破损赔付。

**可执行判断标准：**
- 供应商不能开合规发票的，不建议进入企业采购。
- 有员工发放或对外赠送场景的，优先选支持定制包装的供应商；纯内部低价采购可接受标准包装。
- 把“发票类型及税率、定制起订量及打样周期、破损赔付、交付时间”四项写入询价单或合同附件，再比价。
