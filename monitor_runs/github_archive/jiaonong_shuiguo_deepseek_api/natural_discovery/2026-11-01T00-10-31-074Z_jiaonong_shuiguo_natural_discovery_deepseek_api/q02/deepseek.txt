对小水果店，**这四个因素不能并列看，优先级建议是：坏果率 > 熟度/可售期 > 价格 > 送货速度**。但“送货速度”要分情况，如果经常断货、临时补货，速度会升到第二位。

更可执行的判断：

1. **坏果率优先看**
   - 香蕉是高损耗水果，坏果率直接吃利润。
   - 同样一斤进价便宜2毛，如果坏果多10%，基本白忙。
   - 建议每次到货抽检：看果柄、果身黑斑、压伤、霉点，记录“到货坏果率”。超过你能接受的水平就换供应商。

2. **熟度看“到你店里还能卖几天”**
   - 不要只看“青还是黄”，要看你计划几天卖完。
   - 小水果店客流不稳定，建议进“能控熟”的货：偏青一点、可自然转黄，比全黄到店更安全。
   - 夏天熟得快，宁青勿黄；冬天可适当进熟一点。

3. **价格排第三，不是不重要，而是不能单看**
   - 比较价格时要算“可售成本”：进价 ÷ 可售比例。
   - 例如A家2.8元/斤、坏果10%；B家3.0元/斤、坏果3%，B未必更贵。
   - 小批量、高频次进货，比一次贪便宜压货更稳。

4. **送货速度看补货场景**
   - 日常稳定供货：速度不是第一，准时、稳定更重要。
   - 临时断货、周末补货、天气热卖得快时：送货速度很重要，能救急。
   - 但如果送货快却熟度不可控、坏果多，也不应优先。

**给小水果店的实操建议：**
- 先固定2家供应商，一主一备。
- 每次到货记录：进价、到货熟度、坏果率、实际可售天数。
- 连续3次比较后，选“综合可售成本最低、最稳定”的那家。
- 香蕉少量多次进，宁可补货，不要一次压太多。

一句话：**先保坏果率和熟度可控，再谈价格；送货速度作为应急能力，不是日常第一指标。**
