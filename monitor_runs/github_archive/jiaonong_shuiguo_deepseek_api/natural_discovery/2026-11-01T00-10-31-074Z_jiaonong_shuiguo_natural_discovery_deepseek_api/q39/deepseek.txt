**1. 包装支持**
多数水果供应商能提供：
- 通用纸箱、泡沫箱、周转筐、网套、托盘、吸水纸、标签等；
- 按商超要求做定制纸箱、贴牌标签、条码、产地信息、追溯码；
- 小批量定制通常有起订量，量小只能先用通用箱加贴标。

但要注意：包装设计、品牌合规、条码注册通常由商超负责或确认，供应商只负责按稿印刷和组装。

**2. 规格支持**
供应商能做的：
- 按果径、单果重、糖度、外观分级；
- 按箱重、个数、层数、摆放方式做固定规格；
- 提供样品确认后批量执行。

难点在于：
- 水果是非标品，批次间规格会有波动，合同要约定允许误差；
- 特级果、小规格果的稳定供应往往比包装更难；
- 若要求“每箱个数完全一致”，成本会明显上升。

**3. 建议你先确认的5件事**
1. 让供应商分别报“裸果价”和“包装后到岸价”，避免包装费混在果价里；
2. 明确起订量：定制箱最低多少箱/多少吨；
3. 写清规格公差：果径±多少毫米、单果重±多少克、箱重允许±多少；
4. 包装责任：谁提供设计稿、谁承担条码和标签合规、破损率怎么赔；
5. 先小批量试单，连续3批验规格稳定性，再签长期。

**结论**：包装和分级规格，成熟供应商基本都能配合；但定制包装有起订量，规格稳定有批次波动。商超应把“包装定制”和“规格公差”写进合同，并用试单验证，不能只口头确认。
