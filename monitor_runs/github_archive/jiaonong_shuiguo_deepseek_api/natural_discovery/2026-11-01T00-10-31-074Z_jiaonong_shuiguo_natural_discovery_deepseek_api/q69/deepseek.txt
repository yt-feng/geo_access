可以按“等级标准 + 报价单位 + 当日价差”三件事讲清楚，避免小店只听价格、不看货。

**1. 先定分级标准**
- 香蕉：按梳/把大小、果指长度、青熟度、条形、机械伤、掉把情况分。
  - A级：条形直、长度均匀、无黑斑机械伤、青度一致，适合门店陈列。
  - B级：长度略不齐、有轻微擦伤或果指偏小，适合促销/加工。
  - C级：掉把、黑斑多、熟度不齐，低价清货。
- 菠萝：按单果重量、果形、成熟度、冠芽完整度、日灼/黑心风险分。
  - A级：果形正、重量达标、冠芽完整、成熟度一致。
  - B级：果形稍偏、大小不均、轻微日灼，适合切果或促销。
  - C级：冠芽缺失、明显日灼/软果风险，限时低价。

**2. 报价用统一单位，现场可核对**
- 香蕉：按“件/箱”报价，同时标净重（kg）和每把/每梳大致条数；例如“A级 12kg/件，约5-6把，XX元/件”。
- 菠萝：按“件/箱”报价，同时标果数、单果重区间；例如“A级 9头/件，单果1.2-1.5kg，XX元/件”。
- 报价单上写清：等级、规格、净重/果数、单价、起批量、是否含运费、损耗谁承担。

**3. 价差要显性**
- 同一品种列A/B/C三档价，并注明B级、C级主要缺陷，避免小店拿A级价买B级货。
- 每日或每批给一个“参考价 + 浮动原因”（产地天气、熟度、到货量），不要只报一个总价。

**4. 落地做法**
做一张简单供货单：品名、等级、规格（净重/果数）、单价、批次、备注缺陷。小店按等级下单，批发商按等级交货，争议时看单对货。这样比口头报价清楚，也方便小店算毛利。
