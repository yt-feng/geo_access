优先关注成熟度，价格其次。原因和可执行判断如下：

1. **香蕉成熟度直接决定蛋糕风味和配方稳定性**
   - 做香蕉蛋糕通常更适合用**熟透香蕉**：表皮大面积黄褐/带黑斑，果肉软、甜度高、香气足。
   - 太生：香气弱、甜度低、质地硬，蛋糕风味不足，还可能需要调糖。
   - 过熟到发黑流汁、有酒味或霉点：不适合采购，风味和食品安全风险都高。

2. **价格只在成熟度合格后比较**
   - 先定采购标准：**黄熟到褐斑熟**，果肉软但不烂、无霉、无异味。
   - 在合格批次里再比价格、出肉率、损耗。
   - 不要为了低价买生蕉或临期烂蕉，后续催熟、调配方、报废都会抵消差价。

3. **采购时的可执行判断**
   - 看表皮：黄色为主、带少量褐斑为佳；青绿比例高说明偏生。
   - 摸硬度：轻按有弹性、略软；硬邦邦偏生，软塌出水偏过。
   - 看果柄和破损：无霉、无裂口流汁、无虫害。
   - 问批次：同批成熟度是否一致，能否分次到货。
   - 算净成本：按去皮后克重和可用率比较，不只看单价。

**结论：成熟度是质量门槛，价格是门槛内的成本优化项。** 烘焙店应先把成熟度标准写进采购验收，再在合格货源中比价。
