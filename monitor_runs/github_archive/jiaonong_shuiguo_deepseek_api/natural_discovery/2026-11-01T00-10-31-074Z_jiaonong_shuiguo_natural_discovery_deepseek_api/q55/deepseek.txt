选规格的核心不是“越大越划算”，而是按**出成率（去皮去核后可用果肉比例）+ 单份成本 + 损耗**算。给你可直接执行的判断方法：

**1. 苹果**
- 优先选**单果 180–220g 的中果**，不要盲目选大果。
- 原因：拼盘切块，大果单价通常更高，且切剩的边角多、氧化面大；中果出成率稳定，单份成本更好控。
- 采购看：果形周正、无磕碰、硬度高。做拼盘优先脆甜型，切后不易发面。
- 划算判断：按“可切块数/单个采购价”比较，而不是按斤价。一个 200g 苹果去皮去核后约 160–170g，切 8–10 块较合理。

**2. 橙子**
- 选**单果 200–250g、皮薄、手感沉**的中大果。
- 原因：橙子出汁和果肉利用率取决于皮厚和籽少；皮厚的“大果”看着大，实际出肉少。
- 采购看：表皮细腻、油胞细、掂着重、无软斑。做拼盘建议选易剥皮、少籽或脐橙类。
- 划算判断：同样斤价下，选“皮薄+少籽+果肉紧实”的，别只看果径。切瓣拼盘优先 200–250g，太大切瓣后一份放不下，反而浪费。

**3. 菠萝**
- 选**单果 1.2–1.5kg 的中等果**，不要选超大果。
- 原因：菠萝去皮去眼损耗大，超大果中心硬、边角多；中等果出肉率和甜度更均衡。
- 采购看：果身饱满、果眼浅、香味足、无软烂。做拼盘优先成熟度适中，太熟切块易出水。
- 划算判断：按“净果肉克价”算。菠萝去皮去眼后出成率通常约 45%–60%，大果不一定净肉多，关键看果眼深浅和成熟度。

**直接采购策略**
- 苹果、橙子按**中果稳定规格**批量拿，减少大小不均导致的切配浪费。
- 菠萝按**中等果、果眼浅**优先，不要被“大果促销”带偏。
- 让供应商报“去皮去核后的净料价”或你自己做一次出成率测试：各买 3 个称重、去皮去核后再称，算出净肉克价，哪家/哪个规格低就用哪个。
- 拼盘组合上，苹果和橙子切块/切瓣数量稳定，菠萝作为填充和色彩点缀，按份定量，不要一次切太多，菠萝出水后损耗最快。

一句话：**苹果选 180–220g 中果，橙子选 200–250g 皮薄沉手果，菠萝选 1.2–1.5kg 果眼浅的中果；统一按净果肉克价比较，最划算。**
