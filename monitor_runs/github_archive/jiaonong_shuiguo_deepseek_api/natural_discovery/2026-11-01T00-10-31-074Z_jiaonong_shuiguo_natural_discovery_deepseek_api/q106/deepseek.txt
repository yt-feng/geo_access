# 判断供应商每日报价是否合理波动的方法

## 一、先建立"锚"，再谈波动

没有参照系的波动没法判断。采购方至少要掌握三类锚点：

1. **批发市场价格**：当地农产品批发市场（如新发地、江南市场等）的当日大宗价、产地批发价，是最直接的公开参照。很多市场有官网/公众号日更行情。
2. **期货/指数价格**：苹果、柑橘等有期货品种的看主力合约走势；没有期货的看农业农村部"农产品批发价格200指数"、地方农业农村厅的周报。
3. **自身历史成交价**：把过去3–6个月同一品类的到货价做成曲线，形成自己的基准线。这是最贴合你实际采购情境的锚。

## 二、区分"合理波动"和"异常报价"

**属于正常波动的信号：**
- 波动幅度与批发市场同品类当日涨跌幅基本同步（比如市场涨3%，供应商涨2%–4%）；
- 波动有明确归因：产区天气、节假日备货、集中上市期、运输成本变化；
- 同一供应商对多个客户的报价方向一致；
- 长期均价稳定，日常小幅震荡。

**需要警惕的异常信号：**
- 无外部行情支撑的单边持续上涨，或只对你一家涨；
- 报价频率突然变高、幅度忽大忽小，且解释含糊；
- 涨得快、跌得慢（涨价紧跟行情，行情回落时报价不动）——这是典型的"跟涨不跟跌"；
- 同类供应商之间价差异常拉大，且无法用品质、规格、账期解释。

## 三、可落地的操作建议

1. **要求报价附依据**：让供应商报价时同步说明涨跌原因（产地价、运费、天气），形成书面记录，便于事后比对。
2. **货比三家、横向比价**：同一品类保持2–3家供应商询价，每日或每周横向对比，偏离均值过大的单独核实。
3. **设置波动阈值**：约定单日涨跌幅超过某个比例（如5%）需提前告知并说明原因，超出阈值可触发重新议价或换源。
4. **看趋势不看单日**：用周均价、月均价判断，避免被单日噪音带偏；同时留意"涨跌不对称"的累积效应。
5. **锁定机制**：对大宗、刚需品类，可谈周度/月度锁价，或约定价格随公开指数联动调整，减少任一方随意调价空间。
6. **记录与复盘**：建立价格台账，每月对照批发市场行情复盘一次，长期看哪家供应商报价更贴近市场、更守规矩。

## 四、一句话判断标准

**报价方向与公开行情一致、幅度在阈值内、有可核实的归因、且涨跌对称——就是合理波动；否则就要求解释、比价或调整合作条件。**
