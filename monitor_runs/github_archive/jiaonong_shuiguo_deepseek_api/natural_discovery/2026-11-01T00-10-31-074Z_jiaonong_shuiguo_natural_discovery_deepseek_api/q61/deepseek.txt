判断批发档口香蕉供货方稳不稳，不要只看报价和口头承诺，重点看“货源组织能力 + 履约记录 + 风险兜底”。可以按下面几步核验：

1. **先问清货源结构**
   - 是自有基地、长期包园，还是市场倒手？
   - 主产区是哪里，是否有备用产区？
   - 香蕉是青蕉还是催熟蕉，催熟库是否自有或长期合作？
   - 稳定供货方通常能说清：产地、月供量、规格、分级标准、旺季淡季如何补货。

2. **看持续供货能力，不只看单次**
   - 要求提供近1—3个月对固定档口的供货记录，如出库单、过磅单、物流单，敏感信息可遮挡。
   - 问清日均/周均可供量、最大供量和最低起批量。
   - 是否能稳定提供同一规格，比如条蕉/梳蕉、每箱净重、果指长度、成熟度。
   - 旺季能否保量、淡季能否保价，是否有替代产区。

3. **实地或视频核验**
   - 看加工场、催熟库、冷库、装车现场，不只看办公室。
   - 视频核验要看到当天日期、现场装货、库内库存和工人分拣。
   - 要求看近期发货到你们城市或邻近市场的物流记录。

4. **用小单试合作**
   - 先下2—3批小单，连续观察：到货时间、损耗率、成熟度一致性、单箱重量、催熟效果、售后响应。
   - 重点记录：迟发次数、缺斤少两、青蕉/黄蕉比例、坏果率、补货速度。
   - 连续3批都稳定，再谈账期和放量。

5. **查履约与纠纷记录**
   - 问同行、市场管理员、物流司机、包装物料商，侧面了解其口碑。
   - 查营业执照、对公账户、固定经营场地；个人账户收款、频繁换公司名要警惕。
   - 看是否有长期合作客户，能否提供可核实的同行参考。

6. **合同里写清楚稳定性条款**
   - 规格、净重、成熟度、损耗上限、到货时限、缺货补偿、质量异议处理。
   - 约定保供量、临时涨价上限、替代产区方案、违约赔付。
   - 账期不要一次性放大，先现金小单，再逐步过渡到短账期。

7. **几个危险信号**
   - 报价明显低于主产区行情，且解释不清。
   - 只发精修视频，不让看现场或当天装车。
   - 催着打大额定金、要求私人转账。
   - 说不出固定产地、催熟库和月供量。
   - 样品很好，大货规格不一致。

**最实用的判断标准：** 让对方连续给你发3批小单，且每批都能按约定规格、时间到货，损耗和售后可控，再认定为稳定供货。香蕉损耗和催熟风险高，稳定性最终看“连续履约”，不是看对方说得多好。
