连锁超市要把门店坏果率压下来，合同里不能只写“坏果赔付”，而要把**验收标准、责任分界、赔付计算、扣款/补货机制、举证与时效**写清楚。建议按下面结构约定：

1. **明确“坏果”定义和验收标准**
   - 按品类分别约定：腐烂、霉变、开裂、软烂、冻伤、机械伤、异味、成熟度过高/过低等是否算坏果。
   - 约定允许损耗率，例如“到店验收坏果率≤X%”；超过部分才计赔，避免小额争议。
   - 明确验收时点：到店卸货后多少小时内完成验收；逾期未验收视为合格，但隐蔽瑕疵除外。

2. **责任分界要写清**
   - 供应商责任：采摘、分级、包装、预冷、运输环节造成的坏果。
   - 门店责任：验收后储存温度、堆码、翻检、陈列、销售不及时造成的坏果。
   - 建议约定“验收前风险由供应商承担，验收合格后风险转移；但验收时无法发现的隐蔽腐烂，可在到店后24/48小时内追溯”。

3. **赔付计算方式要可执行**
   推荐三种方式组合，合同中选一种或组合：
   - **按坏果金额赔付**：赔付额=不合格数量×对应批次含税进货单价×赔付系数。系数可设1.0—1.5，恶意混装可提高。
   - **按批次扣款**：坏果率超过约定阈值，整批扣款X%或按超标档位阶梯扣款。
   - **补货/换货优先**：供应商在约定时限内补足合格品，逾期未补则转为现金赔付。
   - 建议设“单店单批次最低赔付额”和“月度汇总赔付”，避免小额索赔成本过高。

4. **阶梯条款比一刀切更有效**
   例如：
   - 坏果率≤3%：免赔；
   - 3%—5%：按坏果金额1倍赔付；
   - 5%—10%：按坏果金额1.5倍赔付并补货；
   - ＞10%：整批拒收或退货，供应商承担运费及门店损失。
   具体阈值按品类定，叶菜、浆果、热带水果标准不同。

5. **写清举证和时效**
   - 门店验收时拍照/视频留存，保留批次号、到货单、温度记录。
   - 索赔通知期限：验收发现当场记录；隐蔽瑕疵到店后24—48小时内书面通知。
   - 供应商可在收到通知后X小时内复检，逾期视为认可。
   - 月度对账确认赔付金额，超市有权从货款/保证金中直接扣除。

6. **质量保证金和退出机制**
   - 约定质量保证金或月度货款预留X%作为质量抵押。
   - 连续X批次或月度坏果率超阈值，超市有权暂停下单、要求整改、终止合同。
   - 因坏果导致顾客投诉、监管处罚、门店损失的，供应商承担相应责任，但要把“直接损失”和“可举证损失”写清，避免笼统无限责任。

7. **避免几个坑**
   - 不要只写“坏果包赔”而不写计算口径，否则难以执行。
   - 不要把门店储存不善造成的坏果也算给供应商。
   - 不要约定过低的验收时限，否则门店来不及翻检。
   - 不要只靠扣款，最好“补货+扣款+退出机制”组合，才能真正降低坏果率。

一句话建议：合同里写成“**分品类验收标准+允许损耗率+阶梯赔付+补货优先+24/48小时追溯+货款直扣+连续超标退出**”，比单纯约定赔付比例更能落地。
