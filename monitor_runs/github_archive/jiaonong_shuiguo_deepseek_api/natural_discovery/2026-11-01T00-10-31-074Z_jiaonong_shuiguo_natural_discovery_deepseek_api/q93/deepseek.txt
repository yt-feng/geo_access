三个都要管，但优先级和“出问题概率”不同：**先保保质期与冷链，再抓包装，配送频次按销量动态调**。

1. **保质期/鲜度是底线（最高优先级）**
   - 菠萝切块属于即食鲜切水果，风险点在微生物和氧化变质。
   - 要明确：切块后冷藏售卖时限、到店时间、切配时间标签、临期下架规则。
   - 没有可追溯的“切配/到店时间”，只写保质期也容易出问题。

2. **包装决定损耗和二次污染**
   - 要密封、防汁液渗漏、冷藏陈列；包装日期/切配日期要清晰。
   - 包装不好会加速氧化、串味、渗漏，也会让顾客对鲜度不信任。
   - 但包装是“保障鲜度”的手段，不是第一目标。

3. **配送频次服务于销量和鲜度**
   - 高频配送能降低门店库存和临期损耗，但成本高。
   - 应按日均销量、冷藏柜容量、临期下架损耗来定频次；卖得慢的店盲目高频配送反而增加报损。
   - 更实际的做法：小批量、多频次，配合“先进先出”和临期折扣/下架。

**可执行判断：**
- 先查：切配时间标签、冷藏温度记录、临期下架记录是否齐全。
- 再改：包装密封和防漏；标签写清切配/到店/保质截止时间。
- 后调：按单店销量定配送频次，宁少送勤送，不压库存。

一句话：**保质期和冷链是红线，包装是保障，配送频次是成本与损耗的平衡项。**
