直接结论：**最好卖“整果可自挑”，同时提供付费/免费的代削服务；不要主卖提前削好的去皮果。**

分三种情况判断：

1. **整果让顾客自己挑：最适合主模式**
   - 菠萝成熟度差异大，顾客自己挑有参与感，也减少“你帮我挑的不好”的纠纷。
   - 整果耐放、损耗低、毛利高、不占人工。
   - 建议按成熟度分区或贴标：今天吃、放两天、做菜用，降低挑选门槛。

2. **去皮好的：只适合少量做引流/便利品，不适合大量备货**
   - 优点是方便、客单价可能更高，适合下班人群、切果盒、小份尝鲜。
   - 缺点是削皮后氧化、出水、变味快，卖不掉就是损耗；且顾客会怀疑不新鲜、缺斤少两。
   - 如果做，建议**现削现卖、限量、明码标价、当天清**，不要提前大批削好摆着。

3. **让顾客自己挑：应该做，但要给标准**
   - 完全放任会让顾客挑半天、翻乱果堆、成熟度判断错误。
   - 可以教一句口诀：“闻底部有香味、按着略软、叶子好拔的熟；硬邦邦的放两天。”
   - 提供“帮挑服务”但说明：帮挑按成熟度推荐，不保证口味偏好。

**最稳的组合：**
- 主陈列整果，按成熟度分两区：即食区、耐放区；
- 设一个代削台，买整果可免费或加1—2元代削；
- 去皮果只做小份现削，卖完即止；
- 明确标示“整果可自选，代削后不退换”。

这样兼顾损耗、毛利、体验和纠纷控制。**核心不是“卖哪种”，而是“整果自选 + 现削服务”组合。**
