可以优先找本地“餐饮水果配送商”或“生鲜B2B平台”，而不是去批发市场或超市零买。最省心的选择标准是：

1. **做餐饮客户为主的本地水果配送商**
   - 优点：可按餐饮店需求小批量、多品种配送，通常支持次日达，退换货相对好沟通。
   - 找法：在地图/本地生活平台搜“水果配送 餐饮”“生鲜配送”，或问附近餐厅老板推荐。
   - 适合：每天少量、品种会变、不想自己挑货的店。

2. **生鲜B2B平台**
   - 优点：线上下单、价格透明、配送稳定，适合小批量日常补货。
   - 注意：起送价、配送费、品质稳定性要试单确认；不同城市覆盖差异大。

3. **本地农贸批发商/水果档口做固定配送**
   - 优点：价格通常比平台低，可谈固定配送。
   - 缺点：需要自己筛选，品质波动要盯；适合老板有空验货的店。

4. **不建议长期靠超市/便利店零买**
   - 临时补货可以，但每天少量采购会费时，价格也高。

**最省心的落地做法：**
- 先选2家本地餐饮水果配送商试单1周；
- 约定：每天固定时间送、可小批量起送、坏果包退、临时加单截止时间；
- 每周对一次账，固定1—2个联系人；
- 先少量试，不要一上来签长期独家。
