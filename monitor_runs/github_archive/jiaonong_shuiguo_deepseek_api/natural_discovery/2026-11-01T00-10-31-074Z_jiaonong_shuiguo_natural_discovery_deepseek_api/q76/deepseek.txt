香蕉配送的核心矛盾是：**怕压、怕闷、怕冷、怕乙烯催熟**。要控制压坏和变黑，建议从“选货—包装—温控—配送—售后”五段一起做，单靠包装不够。

**1. 选货和发货成熟度**
- 不要发全熟蕉。配送半径短的，发7～8成熟；跨城次日达发6～7成熟；高温季节再降半成熟度。
- 优先选条蕉或梳蕉，少用整把大串，整串受力集中更易压伤。
- 入库后剔除已碰伤、发黑、裂口的果，伤果会释放乙烯，加速整箱变黑。
- 发货前做“预冷+控乙烯”：尽快降到13～15℃，不要低于12℃；库内用乙烯吸附材料，香蕉不要和苹果、梨、番茄等催熟果蔬混放。

**2. 包装重点是“防压+防闷+防串味”**
- 用带透气孔的抗压纸箱，箱体不要过高，堆码层数受限。
- 内部用瓦楞隔板或纸浆托把香蕉分隔固定，避免相互挤压；单根接触面可加薄纸包裹，但不要用完全密封的塑料袋。
- 填充用轻质缓冲材料，避免重压；箱内留少量缓冲空间，但香蕉不能晃动。
- 箱体标注“易压/怕闷/勿倒置”，且不要用真空或完全密封包装，否则水汽积聚更易发黑。

**3. 温控和通风**
- 香蕉适宜储运温度约13～15℃。低于12℃易冷害，表皮变黑；高于20℃成熟快、易软烂。
- 夏季避免暴晒和车厢高温，冬季避免靠近冷源。配送箱不要直接放冰袋贴香蕉，可用隔板隔开。
- 运输中保持适度通风，减少箱内水汽和乙烯积聚。

**4. 配送环节可执行动作**
- 按距离分层：同城即时配发较熟蕉，跨城用次日达并控温；超过2～3天的不建议卖鲜香蕉。
- 配送箱内加隔板，香蕉单独放上层，不与重物混装。
- 骑手端提示“勿压、勿倒置、勿放后备箱高温处”；到货后尽快入柜或交付。
- 高温天缩短揽收至送达时长，优先安排早配或晚配，避开中午暴晒时段。

**5. 售后和损耗兜底**
- 商品页明确成熟度、保存方法和轻微表皮斑点说明，降低“变黑即坏”的误判。
- 设置压坏/严重黑变的拍照赔付规则，按比例赔付，控制纠纷成本。
- 用少量试发数据跟踪不同路线、季节、包装的坏果率，再调整成熟度和包装层数。

一句话原则：**发偏生、控13～15℃、分隔固定、透气不密封、限时送达。** 如果只做一件事，优先把“成熟度+抗压分隔+温控时效”三件事同时做到。
