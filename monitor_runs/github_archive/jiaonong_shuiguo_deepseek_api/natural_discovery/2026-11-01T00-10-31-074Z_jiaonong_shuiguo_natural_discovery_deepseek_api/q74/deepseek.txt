做餐饮客户，菠萝和香蕉的规格要按“后厨用法”倒推，不能按零售果形走。下面给可直接备货的规格建议，并附判断标准。

**菠萝（餐饮客户）**
- 主推：**净果/去皮菠萝**，单果净重约 **1.0–1.3kg**，成熟度7–8成，适合切块、炒饭、咕噜肉、饮品。餐饮最省人工，档口可做代削代切。
- 次推：**整果鲜菠萝**，单果 **1.2–1.8kg**，果形端正、无黑心，适合有后厨削皮能力的正餐店和饮品店。
- 小规格：**单果0.8–1.0kg**，适合小餐饮、快餐、甜品杯，减少损耗。
- 分级要求：按大小分2–3级，同箱单果差不超过200g；糖度建议 **12–14°Brix** 以上；无冠芽可接受，但冠芽完整更耐放。
- 避坑：不要给餐饮推太大果（>2kg），出成率不稳、单次用不完易损耗。

**香蕉（餐饮客户）**
- 主推：**青蕉/七成熟蕉**，单根 **120–150g**，整箱 **13–15kg**，适合后厨控熟、早餐店、饮品店；到店后自行催熟，损耗可控。
- 次推：**熟蕉（8–9成熟）**，单根 **100–130g**，适合快餐、甜品、沙拉、儿童餐，要求到店2–3天内用完。
- 小规格：**小米蕉/皇帝蕉**，单根 **50–80g**，适合甜品、果盘、高端餐饮，按盒或小箱供。
- 分级要求：按每把/每根粗细分级，同箱单根差不超过20g；无严重机械伤、无炭疽黑斑；熟蕉到店果肉硬度适中，不软烂。
- 避坑：餐饮客户最怕“今天到货明天全熟”，熟蕉必须按订单节奏供，不能压货。

**档口备货组合建议**
- 菠萝：净果1.0–1.3kg占60%，整果1.2–1.8kg占30%，小果0.8–1.0kg占10%。
- 香蕉：七成熟120–150g占60%，熟蕉100–130g占30%，小米蕉占10%。
- 报价单位用**净重/箱**和**单果规格区间**同时标，餐饮采购最容易判断。

**判断是否匹配餐饮客户的标准**
- 能否稳定做到同箱规格差≤200g（菠萝）、≤20g（香蕉）；
- 能否按周固定配送2–3次，熟度可调；
- 能否提供去皮/切块代加工；
- 损耗责任和到货熟度标准写进供货单。

先拿3–5家目标餐饮做小批量试供，按他们的菜品用量反推规格，比一次性压大货更稳。
