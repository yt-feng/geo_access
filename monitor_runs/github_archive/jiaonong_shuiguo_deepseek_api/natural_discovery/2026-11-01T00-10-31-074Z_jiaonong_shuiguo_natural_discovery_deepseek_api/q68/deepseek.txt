判断供应商能不能按时到车，核心是“把口头承诺变成可验证的证据”，重点看下面几项：

1. **看产地和装车资源**
   - 问清香蕉来自哪个产区、哪个县/镇、哪个包装点。
   - 确认供应商是自有基地/长期合作包装点，还是临时调货。
   - 临时调货的，按时率通常更低，要重点核实。

2. **看当天实际装车进度**
   - 不要只听“已经装好了”，要让他发**装车现场视频**：车到包装点、工人装车、车牌入镜。
   - 视频里核对车牌号、包装点门头或仓库标识。
   - 要求发**车辆定位截图**或司机电话，直接和司机确认到哪了、装了多少、几点能发车。

3. **核实车辆和司机**
   - 要车牌号、司机姓名、电话，最好有行驶证或车辆照片。
   - 直接联系司机，问“现在在哪、装了多少、预计几点上高速”。
   - 如果供应商拒绝给司机电话，或司机说法和供应商不一致，要警惕。

4. **看合同/订单里的到车条款**
   - 明确写：**到车时间、到车地点、迟到违约责任、压车费谁承担、香蕉质量标准**。
   - 不要只写“尽快到车”。要写到具体日期和时段。
   - 约定迟到超过几小时可拒收或降价，才有约束力。

5. **看供应商过往履约记录**
   - 优先选合作过、按时率高的供应商。
   - 新供应商可要求提供近期发货记录、装车视频、司机反馈。
   - 小额试单一次，再放大批量。

6. **看天气和路况**
   - 香蕉主产区遇台风、暴雨、寒潮，或高速管制，会直接影响到车。
   - 让供应商说明当前产区和途经路线的天气、交通情况，并保留备选供应商。

7. **用付款方式控风险**
   - 不要提前全款。可定金+到车验货后付尾款。
   - 合同里约定迟到扣款或拒收权，比口头催促有效。

**一句话判断：** 能提供车牌、司机电话、装车视频、明确到车时间，并愿意写进合同的供应商，按时到车概率高；只给口头保证、拒绝给司机信息、装车视频含糊的，要按高风险处理。
