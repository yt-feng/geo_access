社区超市选每天配送的水果供应商，建议按下面这些条件逐项核验，能明显降低踩坑概率：

1. **本地仓/分拣中心距离**
   - 优先选离店30–60分钟车程内、有本地分拣仓的供应商。
   - 问清楚：凌晨几点分拣、几点发车、到你店大概几点。每天配送最怕“承诺早到、实际中午到”。

2. **配送稳定性与频次**
   - 是否真正支持每天配送，而不是“满额才送”或“隔天送”。
   - 节假日、雨天、春节前后是否照常送，临时加单/减单截止时间。
   - 问最近3个月有没有断供、迟到，最好让其提供合作门店可回访。

3. **品类结构与产地直采能力**
   - 社区超市需要的是高频刚需果：苹果、香蕉、橙子、梨、西瓜、应季爆品等。
   - 看其是否能稳定供这些基础款，而不是只有高端礼盒。
   - 问产地/批发市场来源、是否有基地直采，避免二级三级批发加价。

4. **品质标准和验收规则**
   - 明确等级、规格、成熟度、瑕疵率、单果重范围。
   - 要求书面验收标准：比如坏果率超过多少可拒收、可换货。
   - 先试送3–7天，每天记录到货品质，别只看样品。

5. **价格与调价机制**
   - 是否每天报价、按什么市场价联动，调价提前多久通知。
   - 有无配送费、起送门槛、押金、损耗补贴。
   - 不要只比单价，算“到店可售成本”：进价+配送+损耗+退换成本。

6. **损耗与售后**
   - 坏果、压伤、熟度不符怎么赔：当场换、下次补、还是折价。
   - 售后响应时间，是否有专人对接。
   - 每天配送的供应商，售后响应比价格更重要。

7. **冷链与包装**
   - 需要冷藏的果品是否有冷链车/保温箱。
   - 是否分店分筐、贴标签、按订单分拣，减少你店内二次分拣人力。
   - 包装是否回收，筐/箱押金怎么算。

8. **结算与账期**
   - 现结、周结还是月结；是否支持对账明细。
   - 小超市建议先短期结算，跑顺1个月再谈账期。

9. **供应能力与风险**
   - 是否有备用货源，单一品种缺货时能否替代。
   - 公司经营时长、是否有固定冷库/车辆、司机是否固定。
   - 避免过度依赖一家，最好主供+备供各一家。

10. **试合作方案**
   - 先签1个月试配，约定每天配送时间、验收标准、坏果赔付。
   - 试配期重点看：准时率、到货新鲜度、缺货率、售后速度。
   - 连续一周迟到或坏果率超标，直接换。

**最简可执行清单：** 让供应商提供①本地仓地址和发车时间②每天配送证明③近3个月合作门店回访④书面验收和赔付标准⑤首月试配报价。五项齐全再合作。
