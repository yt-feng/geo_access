结论：**多数商超更适合“整果为主、鲜切为辅”的双组合**；是否加大鲜切比例，取决于门店客流结构、损耗管控能力和冷藏陈列条件。可以按下面几条判断。

### 1. 先看门店客群
- **社区店、中老年客群多、家庭采购为主**：整果更合适。顾客看重价格和耐放，整果毛利空间也更好控制。
- **商圈店、写字楼店、年轻客群多、即食需求强**：鲜切更有优势，能抓住下午茶、办公室零食、即买即吃场景。
- **靠近学校、医院、交通枢纽**：鲜切更容易动销，但必须小份、低单价、当日清货。

### 2. 看损耗和操作能力
- **整果优势**：耐储存、损耗低、操作简单、采购容错率高；缺点是客单价受重量影响，部分顾客嫌处理麻烦。
- **鲜切优势**：提升即食便利性和客单价，能消化外观不佳但品质正常的果；缺点是去皮损耗大、保质期短、需要冷藏和卫生管理，卖不掉就是直接损耗。
- **判断标准**：如果门店没有稳定冷藏陈列、专人控损和当日清货机制，鲜切不宜做多。

### 3. 建议的陈列和销售结构
- **整果做引流和家庭装**：选1—2个主流品种，按个或按斤卖，保证价格带清晰。
- **鲜切做补充和即食场景**：小盒装、当天切当天清，控制在总菠萝销量的**20%—30%**起步，卖得好再逐步提高。
- **不要一开始就全切**：鲜切比例过高，损耗和人工会把毛利吃掉。

### 4. 采购上的可执行建议
- 整果采购选**成熟度适中、耐运输**的货，分批催熟，避免一次到货全熟。
- 鲜切专用果可以采购**成熟度略高、外观要求低但内部品质正常**的货，降低成本。
- 鲜切必须做到：冷藏陈列、标注切制时间、当日未售完及时折价或下架，不隔夜主推。

### 5. 简单决策表
| 门店情况 | 建议 |
|---|---|
| 社区家庭客为主、冷链弱 | 整果为主，鲜切少量试销 |
| 年轻客群多、有冷藏柜 | 整果+鲜切并重，鲜切不超过三成 |
| 客流大但损耗管控弱 | 整果为主，鲜切只做小份引流 |
| 即食需求强、可当日清货 | 可提高鲜切比例，但每日盯损耗 |

**一句话：整果保基本盘和毛利，鲜切抓便利和增量；先小比例试销，用一周动销和损耗数据决定是否扩量。**
