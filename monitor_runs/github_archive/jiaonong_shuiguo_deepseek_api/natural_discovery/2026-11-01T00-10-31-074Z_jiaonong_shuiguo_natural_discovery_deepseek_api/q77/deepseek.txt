结论先行：**大多数生鲜电商优先做“切配（鲜切即食/净果）”，整果作为引流和低损耗补充，冷冻原料更适合做B端、烘焙/茶饮渠道或作为长尾SKU，不建议作为线上C端主力。**

判断逻辑如下：

1. **整果**
   - 优点：单价低、认知简单、无需加工、适合做爆款引流；耐运输性比鲜切好，货架期相对长。
   - 缺点：品质波动大（熟度、黑心、酸度）、售后纠纷多；毛利低；用户复购依赖促销；大果重、履约成本占比高。
   - 适合：产地直发、团购、低客单引流款、对价格敏感的用户。
   - 线上定位：**引流SKU/基础款**，不适合作为唯一主力。

2. **切配（鲜切菠萝/净果）**
   - 优点：即食便利，客单价和毛利更高；标准化程度高，适合城市即时零售和家庭场景；能通过规格（果切盒、净果块）做差异化。
   - 缺点：冷链要求高、损耗和微生物风险高、保质期短；加工资质和品控要求高；配送半径受限。
   - 适合：前置仓、即时零售、社区团购次日自提、办公室/家庭即食场景。
   - 线上定位：**C端主力利润款**，但必须解决冷链、保质期和品控。

3. **冷冻原料**
   - 优点：货架期长、损耗低、适合跨区域销售；标准化好，适合茶饮、烘焙、餐饮B端。
   - 缺点：C端家庭复购场景弱；解冻后口感与鲜果差异明显；需要冷链仓储，C端履约成本高；消费者教育成本高。
   - 适合：B端供应链、茶饮/烘焙原料、冷冻果切长尾SKU。
   - 线上定位：**B端或补充SKU**，不建议作为C端主推。

**可执行建议：**
- 若你做**前置仓/即时零售**：主推切配，整果做低价引流，冷冻只做少量长尾。
- 若你做**产地直发/团购**：主推整果，切配谨慎做（配送半径和损耗难控），冷冻不做C端主力。
- 若你做**B端供应链**：冷冻原料和整果分级供货优先，切配看客户是否需要。
- 选品组合建议：**整果引流 + 切配赚钱 + 冷冻补长尾/B端**，不要单押一个形态。

关键判断指标：损耗率、冷链成本、售后率、复购率、客单价。切配能否成立，核心看你能不能把**损耗和冷链**控制在毛利可覆盖的范围内。
