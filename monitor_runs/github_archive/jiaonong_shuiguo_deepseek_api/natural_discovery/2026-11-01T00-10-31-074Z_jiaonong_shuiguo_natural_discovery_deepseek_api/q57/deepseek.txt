对餐饮连锁采购水果，通常更建议“中央厨房统一收货为主、门店直收为辅”的混合模式，而不是一刀切。

**建议结论**
- **水果品类稳定、标准化程度高、门店用量大**：中央厨房统一收货更好。
- **高时效、易损耗、门店个性化强或冷链覆盖不到**：门店分开收货更好。
- **多数连锁餐饮**：采用“统采统收+区域分仓/门店直收”的混合模式最优。

**对比判断**

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|---|---|---|
| 品控标准 | 更统一，便于验收标准和追溯 | 标准易不一致，依赖店长/店长执行 |
| 采购成本 | 集中采购议价强，物流可合并 | 小批量、多频次，单价和运费偏高 |
| 损耗控制 | 适合耐储水果，但二次分拣和配送会增加损耗 | 适合高时效水果，减少中转 |
| 食品安全追溯 | 批次、供应商、检测记录更集中 | 分散记录，追溯难度高 |
| 门店运营负担 | 门店轻，专注经营 | 门店要收货、验货、处理异常，负担重 |
| 配送时效 | 依赖中央厨房分拣和冷链排线 | 更贴近门店需求，响应快 |
| 资金与库存 | 集中库存，可能压货 | 门店库存分散，易缺货或积压 |

**可执行建议**
1. **先按水果分级**  
   - A类：苹果、橙子、西瓜、香蕉等耐储/用量大/标准明确，走中央厨房统一收货。  
   - B类：草莓、蓝莓、鲜切水果、叶菜类水果等易损高时效，走区域分仓或门店直收。  
2. **设定统一验收标准**  
   糖度、规格、成熟度、外观、农残检测、到货温度、破损率、拒收规则都要写进采购合同和收货SOP。  
3. **建立“中央厨房+区域分仓”而非所有门店直收**  
   门店直收适合少量应急或特殊品类，不建议全部门店各自收货，否则品控和成本会失控。  
4. **算总成本，不只看采购价**  
   比较“采购价+运费+分拣费+损耗+门店人工+缺货损失”，通常中央统收在中大规模下总成本更低。  
5. **设置例外清单**  
   明确哪些水果允许门店直收、单次金额上限、供应商白名单、必须上传验收照片和批次信息。  
6. **用数据复盘**  
   按月看各品类损耗率、到货合格率、门店投诉率、综合成本，再调整统收/直收比例。

**一句话判断**
门店数量多、水果用量稳定、食安要求高，优先中央厨房统一收货；水果易损、配送半径长、门店需求差异大，采用区域分仓或门店直收补充。混合模式通常比单一模式更稳。
