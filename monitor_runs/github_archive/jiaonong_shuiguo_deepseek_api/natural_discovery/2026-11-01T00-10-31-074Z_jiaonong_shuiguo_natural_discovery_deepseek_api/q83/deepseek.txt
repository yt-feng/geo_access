# 生鲜水果坏果投诉的责任划分

生鲜水果的坏果责任不能一概而论，核心看**坏果发生在哪个环节、以及是否在平台承诺的售后范围内**。可以按下面几个层次判断：

## 一、先定责：按环节划分

| 环节 | 典型情形 | 责任归属 |
|---|---|---|
| 产地/供应商 | 采摘成熟度不当、分拣不严、带病果混入 | 供应商/采购方 |
| 仓储 | 冷库温度失控、堆压、存放超期 | 平台仓储方 |
| 配送 | 冷链断链、暴晒、挤压、延误 | 物流/配送方（平台自营则平台担） |
| 顾客端 | 签收后长时间未取、未冷藏、自行磕碰 | 顾客 |
| 不可归责 | 水果自然特性（如熟果运输中轻微软伤）、极端天气延误 | 按平台规则/协商 |

**举证关键**：到货时间、开箱照片/视频、坏果比例、冷链记录。谁主张谁举证，但生鲜"开箱即拍"是通行做法。

## 二、按坏果比例和性质定处理方式

行业通行做法（各平台细则不同，以平台公示规则为准）：

- **少量个别坏果**（通常低于5%）：多按比例退款或补发，一般不要求退回。
- **较大比例坏果**（如超过20%~30%）：整单退款或补发，顾客提供开箱证据。
- **整箱腐烂/异味**：全额退款，平台可追溯供应商或冷链责任。
- **顾客自身原因**（签收后放置过久、未按提示冷藏）：平台可拒赔或部分赔付。

## 三、实操建议

**对顾客**：
1. 签收当场或尽快开箱，拍视频/照片（含包装、坏果特写、整体数量）。
2. 在平台承诺的售后时效内（常见24~48小时）提交。
3. 不要自行丢弃全部坏果，保留证据至处理完毕。

**对商家/平台**：
1. 售后规则要前置公示（坏果率、时效、举证要求），避免争议。
2. 建立"坏果率—供应商/物流"归因台账，超阈值追责上游。
3. 对小额投诉优先"秒赔"，大额再走举证核验，平衡体验与成本。

## 四、法律底线

依据《消费者权益保护法》和《食品安全法》，若水果**变质、腐败**属于不符合食品安全标准，消费者可要求退款；造成损害的还可主张赔偿。平台"生鲜不支持七天无理由"不等于"坏果不赔"——**质量问题不受无理由退货限制**。

---

**一句话结论**：坏果责任按"产地—仓储—配送—顾客"链条归因，以开箱证据和坏果比例定赔付；平台不能用"生鲜不退"免除质量责任，但顾客也需在约定时效内举证。具体比例和时效以你所用平台的公示售后规则为准。
