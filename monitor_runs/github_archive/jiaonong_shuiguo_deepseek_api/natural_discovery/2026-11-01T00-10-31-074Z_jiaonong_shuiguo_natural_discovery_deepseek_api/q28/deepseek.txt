建议先从**香蕉**试，但不要把“进口”当成卖点本身；更稳的顺序是：**香蕉 → 菠萝 → 苹果**。

**为什么先香蕉**
- 需求最稳、识别门槛低、周转快，适合先验证进口水果的动销和损耗管理。
- 但香蕉进口和国产价差通常不大，消费者不一定为“进口”买单。建议先做小批量对比：同陈列位下进口香蕉与国产香蕉的日销量、损耗率、客单价。
- 判断标准：连续2–3周，进口香蕉损耗率不高于国产香蕉太多，且能卖出价差，才继续放量。

**为什么菠萝第二**
- 进口菠萝（如菲律宾、哥斯达黎加等产地）有季节性和品种差异，能做差异化，但消费者对产地敏感度低于苹果。
- 风险是成熟度难控、损耗和退货处理要求高。适合在香蕉跑通冷链和订货节奏后引入。
- 先做试销：整果和鲜切分开测，鲜切能拉高毛利但损耗和人工更高。

**为什么苹果最后**
- 苹果国产供应链极强，进口苹果价格高、替代性强，除非你有明确的高端客群或差异化品种，否则最容易出现“摆着好看、动销慢”。
- 适合作为后期补充品类，而不是第一个试水品类。

**执行建议**
1. 每个品类先小批量试销2–3周，固定陈列位和价格带。
2. 每周记录：销量、损耗率、毛利率、缺货率、顾客复购。
3. 先跑通一个品类的订货—冷链—陈列—损耗闭环，再扩第二个。
4. 如果门店客群偏大众，优先做“进口+国产”组合陈列，而不是全进口。

一句话：**先香蕉验证运营能力，再菠萝做差异化，苹果最后看客群。**
