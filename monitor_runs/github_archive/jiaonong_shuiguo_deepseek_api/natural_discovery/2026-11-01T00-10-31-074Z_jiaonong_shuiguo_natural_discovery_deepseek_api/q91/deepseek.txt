优先做“小把（3～5根）+ 单根补充”，整袋只做少量试销，不建议一开始只上整袋。

判断建议：

1. **主推小把 3～5 根**
   - 便利店消费多是即时、单人、小家庭场景，小把决策成本低。
   - 比单根更像“商品”，有客单提升空间；比整袋更容易冲动购买。
   - 包装上建议透明可见、标价清晰，避免顾客挑拣造成损耗。

2. **保留单根销售**
   - 适合搭配早餐、酸奶、临时购买场景。
   - 能降低“吃不完”的顾虑，也方便定价和试水。
   - 但单根容易让顾客挑拣、增加损耗，最好统一规格或只放少量。

3. **整袋少量试销**
   - 适合家庭采购，但在便利店通常不是高频即时需求。
   - 如果周边是社区、家庭客群，可上少量整袋；如果是写字楼、商圈，整袋优先度低。

4. **上架策略**
   - 先各上少量，观察 1～2 周：销量、损耗率、顾客是否拆把挑单根。
   - 若单根卖得快但损耗高，改为小把为主、单根少量。
   - 若整袋动销差，及时下架，避免香蕉过熟造成损耗。
   - 香蕉成熟度高，建议少量多次补货，比一次性大包装更稳。

结论：**以 3～5 根小把为主，单根作为补充，整袋仅少量试销；根据社区/商圈客群和损耗数据再调整。**
