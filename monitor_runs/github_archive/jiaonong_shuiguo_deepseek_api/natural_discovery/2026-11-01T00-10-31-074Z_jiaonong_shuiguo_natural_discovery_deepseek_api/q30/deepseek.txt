建议把“到货验收—分级处理—时限—赔付/退换—留证—责任”写进采购合同或售后补充协议，并让门店按同一套SOP执行。可直接用以下条款框架：

**1. 验收标准与时限**
- 到货后约定验收窗口，如“卸货后2小时内完成抽检；冷链水果1小时内”。
- 明确品相标准：腐烂、霉变、裂果、压伤、规格不符、成熟度异常分别定义。
- 抽检比例和判定规则：如按箱抽检，不合格率超过约定比例（例如5%）即整批可拒收或折价。
- 验收单必须双方签字，拍照留存，注明箱号、批次、数量、问题类型。

**2. 分级处理**
- **拒收**：腐烂霉变、严重压伤、异味、规格严重不符。
- **折价接收**：轻微品相问题但不影响食用，按约定折扣结算。
- **换货**：可补货且不影响销售的，约定换货时限和运费承担。
- **报损**：已收货后发现隐蔽问题，约定报损比例和证据要求。

**3. 售后响应时限**
- 供应商应在收到通知后约定时间内响应，如2小时内确认、24小时内给出处理方案。
- 换货/补货时限：如48小时内到店；冷链商品应更短。
- 逾期未处理的默认规则：视为认可门店提出的折价或退货方案。

**4. 赔付与费用**
- 明确折价比例、退货退款、换货补货三种方式。
- 因品相问题产生的挑拣费、报损费、运费由责任方承担。
- 可约定质量保证金或月度结算扣款机制，避免单次扯皮。

**5. 留证与对账**
- 到货照片、验收单、聊天记录、退货单、报损单作为结算依据。
- 每月对账时列明售后扣款明细，双方确认后结算。

**6. 责任边界**
- 区分运输损伤、供应商原货问题、门店储存不当。
- 约定“收货后超过约定时限未提出异议”的后果，但隐蔽瑕疵除外。
- 生鲜易腐品建议约定“当日反馈有效”，避免隔夜后责任不清。

**7. 争议处理**
- 先按验收单和照片协商；协商不成按合同争议条款处理。
- 对高频问题供应商设置淘汰或降级机制。

实操上，最关键是三件事：**验收标准可量化、反馈时限写死、扣款/退换规则可直接执行**。不要让售后停留在“品相不好可协商”，否则每批货都会扯皮。
