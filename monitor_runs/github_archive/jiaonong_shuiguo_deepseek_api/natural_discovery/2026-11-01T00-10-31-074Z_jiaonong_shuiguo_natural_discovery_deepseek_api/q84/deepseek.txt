家庭团购水果礼盒，建议按“耐放+当季+个头适中+少损耗”来搭，不要只追求品种多。更推荐两种组合：

**方案1：家庭实惠型（最推荐）**
- 苹果：4个（耐放，老人孩子都吃）
- 橙子：4个（耐放，寓意好，适合秋冬）
- 香蕉：1把（约5-6根，熟得快，先吃）
- 菠萝：1个（增加礼盒感，但要求商家削好或选小果）

比例建议：苹果和橙子占60%-70%，香蕉20%，菠萝1个点缀。适合3-5口之家，总重约5-6斤，价格容易控制。

**方案2：更省心型（减少菠萝风险）**
- 苹果4个 + 橙子4个 + 香蕉1把 + 小菠萝1个，或把菠萝换成2个火龙果/1盒小番茄。
- 如果团购配送时间长、家庭不一定当天吃，菠萝容易压伤、切口难保存，建议不作为必选。

**组合时注意：**
1. 香蕉单独装袋，避免压苹果橙子，也避免乙烯催熟其他水果。
2. 菠萝选小果或让商家削皮装盒；整只带皮更适合送人，不适合怕麻烦的家庭。
3. 苹果、橙子选中等个头，礼盒显满又不浪费；别用大果撑重量。
4. 家庭装优先“好吃好分”，少放奇异果、草莓等易损高价果。
5. 定价上，水果成本控制在售价的60%-70%，留出损耗和配送空间。

如果只选一个组合：**苹果4+橙子4+香蕉1把+小菠萝1个**，最适合家庭团购。
