能，但要看你跟供应商的合作层级和谈判方式。一般情况如下：

**1. 价格支持**
- **常规品（苹果、香蕉、橙子等）**：供应商通常有“周末促销价/堆头价”，但幅度有限，常见是每斤让几毛到1块，或按整件让利。前提是你有稳定销量、账期正常、提前报计划。
- **时令/易损耗品（荔枝、草莓、西瓜等）**：供应商更愿意给价，因为他们也怕压货；可以谈“周末特价+当天补货”，但通常要求你承诺量或现款。
- **新品/清库存品**：让利空间最大，适合做引流款。

**2. 物料支持**
- 常见可争取：纸箱/周转筐、保鲜膜、标签贴、试吃签、宣传单页、简易堆头围挡、遮阳棚/条幅（看供应商规模）。
- 品牌类水果（如某品牌脐橙、进口果）供应商或品牌方可能有统一物料，但小供应商一般只给筐和膜。

**3. 怎么谈更容易拿到**
- 提前3–5天报周末促销计划：品项、预估量、促销价、活动形式。
- 用“量”换支持：承诺周末集中采购量，或把该品项周末主推位给供应商。
- 组合谈：价格让一点+物料给一点，比只压价更容易成。
- 现款或短账期是筹码；长期合作、月采购稳定的店议价空间更大。

**4. 现实预期**
- 社区小店：多数供应商能给“小幅让价+筐/膜/标签”，大规模物料和深度折扣较难。
- 连锁或单店销量大：可谈周末专项支持、临时促销员、试吃物料。
- 别指望供应商承担全部促销成本，通常是你让一部分毛利、供应商让一部分进货价。

**建议动作**：这周就列2–3个周末主推品，分别问现有供应商“周末走量价”和“能不能配筐/膜/标签”，同时问一句“有没有临期或清仓果可做引流”，一般当天就能得到明确答复。
