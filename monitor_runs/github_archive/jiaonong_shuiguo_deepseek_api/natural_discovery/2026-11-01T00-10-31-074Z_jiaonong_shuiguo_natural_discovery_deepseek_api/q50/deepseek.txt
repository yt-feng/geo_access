对茶饮店来说，**出汁率通常比甜度更重要**，但前提是甜度不能“明显不够、需要大量额外加糖去补”。

可以按这个优先级判断：

1. **先看出汁率**  
   茶饮店用菠萝多数是做果茶、果酱、果肉装饰或复配。出汁率低意味着：
   - 同样克重可用的果汁/果肉少，原料成本变高；
   - 出品不稳定，容易一杯汁多、一杯汁少；
   - 操作更费工，压汁/切配损耗大。  
   所以采购时应优先选**出汁率高、果肉纤维适合出品**的品种和成熟度。

2. **甜度看“底线”和“稳定性”**  
   甜度不是越高越好。茶饮里通常还会加糖浆、果酱或茶底调和，菠萝本身只要**甜酸平衡、无明显生青味、酸涩感低**即可。  
   如果甜度太低，会导致：
   - 每杯需要额外加更多糖，配方成本上升；
   - 酸感突出，掩盖茶香；
   - 不同批次甜度波动大，出品不稳定。  
   因此甜度要求是：**达到你配方的最低可接受甜度，并且批次稳定**，而不是追求最高甜度。

3. **实际采购建议**  
   - 做**鲜果茶、果肉型饮品**：优先出汁率+果肉率，甜度中等、酸不刺口即可。
   - 做**菠萝果酱/浓缩汁复配**：甜度可让供应商标准化，出汁率仍影响原料利用率。
   - 做**装饰果片**：外观和果肉完整度优先，甜度、出汁率都要让步。
   - 设定验收标准时，建议同时写：**出汁率下限、可溶性固形物/糖酸比范围、成熟度、纤维粗细、坏果率**，不要只盯甜度。

简单结论：**甜度决定“要不要多补糖”，出汁率决定“原料成本和出品稳定性”；茶饮店采购应优先保证出汁率达标，再要求甜度稳定且不低于配方底线。**
