连锁商超水果供应商招标，建议把评分标准做成“资格门槛+技术/服务评分+商务价格评分+履约激励”的结构。水果品类损耗高、季节波动大、食品安全敏感，不能只比价格。

可直接落地的框架如下（总分100分，可按企业规模调整权重）：

**一、资格门槛（不计分，不满足即废标）**
- 营业执照、食品经营/生产许可齐全，种植基地或合作社来源可追溯
- 近2年无重大食品安全处罚、无严重失信记录
- 具备与商超门店数量匹配的配送能力和冷链车辆
- 能提供农残检测报告、产地证明、批次追溯方案
- 接受商超的质量标准、账期和违约条款

**二、技术与管理评分（建议35—40分）**
1. 货源稳定性与基地能力（10—12分）：自有基地/长期合作基地面积、主推单品年供应量、反季节或跨产区补充能力、极端天气保供方案。
2. 质量与食品安全体系（10—12分）：农残自检频次与项目、第三方检测报告、分级标准（糖度、果径、色泽、瑕疵率）、不合格品召回与赔付机制。
3. 冷链与配送能力（6—8分）：冷链覆盖率、到店频次、准点率承诺、破损与温控异常处理流程。
4. 损耗与库存管理（5—6分）：缺货率承诺、损耗承担比例、临期/尾货处理方案、紧急补货响应时间。
5. 信息化与追溯（4—5分）：批次追溯系统、订单对接方式、每日库存与到货数据回传能力。

**三、服务与履约评分（建议20—25分）**
- 售后响应时限（如2小时内响应、24小时内处理）
- 退换货与质量异议处理机制
- 促销档期、节日高峰的备货保障
- 配合门店陈列、分级包装、定制规格的能力
- 试供期表现：可设置1—3个月试供，按到货合格率、准点率、缺货率打分

**四、商务评分（建议35—40分）**
- 报价（25—30分）：按品类分别报价，采用“基准价+下浮率”或“市场行情联动价”，避免单纯最低价中标；设置异常低价澄清机制。
- 账期与结算（5分）：能接受商超账期、支持月结或票据结算。
- 履约保证金与违约条款接受度（5分）：质量不合格、缺货、迟到的赔付标准。

**五、加分项（不超过5分）**
- 有机/绿色认证、地理标志产品
- 产地直采比例高、助农或乡村振兴项目
- 可提供定制包装、品牌联名或独家品种
- 数字化溯源到田块/批次

**关键设置建议**
1. **价格分不宜过高**：水果损耗和品质波动大，价格分建议不超过40分，防止低价中标后以次充好。
2. **按品类分包招标**：叶菜、浆果、柑橘、进口果的供应链差异大，按品类分别设权重和评分，避免一家通吃。
3. **设置履约后评价**：中标后按季度考核到货合格率、准点率、缺货率、客诉率，与续约、份额调整挂钩。
4. **明确废标红线**：农残超标、虚假产地、转包分包、连续缺货，直接终止合作。
5. **试供期条款写进合同**：试供不合格不进入正式供应，降低选错供应商的风险。

如果门店规模较大，建议把“技术评分”中的质量体系和冷链能力权重再提高；如果是区域中小商超，可适当简化，重点看货源稳定性、配送时效和价格联动机制。
