判断一批香蕉，核心是“看颜色+摸硬度+查果柄/切口+翻箱抽查”，不要只看表层。

**1. 先定用途，再定熟度**
- 要马上卖/两三天卖完：选黄中带少量绿、果身略软但有弹性。
- 要囤几天再卖：选青黄、果身硬、果柄青绿。
- 已经全黄、带黑斑、果身软：只适合当天促销，不适合批量囤。

**2. 看颜色和成熟阶段**
- 全青硬：后熟空间大，但要看冷害和催熟是否失败。
- 青黄转色均匀：较稳。
- 黄中带绿尖：常见耐储状态。
- 全黄、果指根部发黄、棱角消失：已接近可售，风险变高。
- 大面积黑斑、黑腐从果柄往下走：坏果风险高。

注意：香蕉“芝麻斑”少量出现通常是熟度到了，不等于坏；但斑点多且果肉发软、渗水、有酒味，就是过熟或腐坏。

**3. 摸硬度和弹性**
- 好货：果身硬挺或略软但有回弹，不塌陷。
- 风险货：捏着发软、局部塌陷、表皮发亮渗水、指压后不回弹。
- 同一箱里软硬差异大，说明成熟不均，后熟会很难控。

**4. 查果柄、切口和果轴**
- 果柄青绿、切口新鲜：较好。
- 果柄发黑、干缩、霉点：说明存放久或受潮，腐烂会从柄部扩散。
- 整把果轴发黑、有酸味：整把风险高。
- 切口有白色霉丝、黑霉：不要只看表面果指，翻箱。

**5. 翻箱抽查，不看表层**
至少抽上、中、下三层和箱角：
- 底层是否压伤、出水、发黑。
- 箱内是否有酒味、酸味、霉味。
- 塑料袋/包装内是否有水汽凝结；水汽重易催腐。
- 随机拿几根捏果指中部和两端，看是否局部软烂。
- 看果指与果指接触面、贴箱面是否压伤。

**6. 判断坏果风险的几个信号**
高风险：
- 有酒味、酸味、霉味。
- 果柄/果轴发黑霉变。
- 果身渗水、发亮、局部塌陷。
- 箱底有水或包装内水汽重。
- 同一批软硬差异很大。
- 受冷后表皮发暗、催熟不均，常见“青硬不熟+局部软烂”。

**7. 实操建议**
- 现场切开1—2根可疑果：看果肉是否褐变、中心是否发黑、是否有异味。
- 问清到货时间、运输温度、是否催熟、是否受冷；香蕉怕低温，冷害后表面看着青，后熟会花皮、发黑。
- 大批量拿货先小批试后熟：留一箱放24—48小时，看转色是否均匀、是否出酒味。
- 合同/单据上写明熟度、坏果率标准和验收方式；现场拍照留证。
- 砍价不如控风险：成熟不均的货即使便宜，损耗和人工分拣也会吃掉利润。

一句话：**青黄均匀、果柄新鲜、果身硬挺有弹性、翻箱无水汽无酒味、软硬一致**的货相对安全；**柄黑、轴黑、渗水、酒味、软硬差异大**的货坏果风险高。
