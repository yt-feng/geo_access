超市和水果供应商的账期没有全国统一标准，常见区间大致是：

- **现结/7天**：多见于叶菜、草莓、荔枝等易损耗、保鲜期短的单品，或新供应商试合作。
- **15～30天**：水果供应商较常见的账期，尤其是常规单品、稳定合作的中小超市。
- **30～45天**：连锁超市、区域商超较常见，通常伴随月度对账。
- **45～60天**：大型连锁、强势渠道偶尔会有，但对水果这类高损耗品类不算普遍，供应商往往会在价格里加资金成本。
- **超过60天**：水果供应里较少见，除非是大型连锁且供应商有较强资金实力，或者用“高供货价换长账期”。

实操建议：

1. **按品类分账期**：易腐单品短账期甚至现结，耐储单品可30天左右。
2. **按供应商规模分**：小供应商给15～30天更现实，大供应商可谈30～45天。
3. **明确对账和付款日**：比如“每月5日前对账，15日前付款”，比只写“30天”更可执行。
4. **注意隐性成本**：账期越长，供应商报价通常越高；谈账期时要和价格、损耗承担、退换货一起谈。
5. **新供应商先短后长**：先15天或现结试合作，稳定后再逐步延长。

如果你是中小超市，**15～30天**是比较常见且容易谈成的起点；如果是连锁商超，**30～45天**更常见。
