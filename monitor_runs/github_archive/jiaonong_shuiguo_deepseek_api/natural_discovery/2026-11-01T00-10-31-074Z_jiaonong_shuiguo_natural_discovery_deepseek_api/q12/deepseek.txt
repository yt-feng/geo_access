采购菠萝时，熟度判断的目标不是“挑最熟的”，而是按预计售卖速度分层进货：大部分进“次日到最佳食用期”的果，少量进“当天可卖”的果，避免一次全进全熟果。

**现场判断方法：**

1. **看果皮颜色**：青绿偏黄、底部开始转黄，适合放1–2天卖；整体金黄、无青肩，适合当天或次日卖；大面积深黄发橙、果眼发暗，熟度偏高，少进。
2. **看果眼和底部**：果眼浅而饱满、底部（果座）新鲜无霉斑为好。底部发软、渗汁、有酒味，说明过熟或已开始坏。
3. **闻气味**：靠近底部闻，有清淡菠萝香说明接近适售；香味浓甜甚至带酒味，说明过熟，别多进；完全没香味说明偏生。
4. **按手感**：轻按有弹性、不软塌最好；硬得像石头偏生；一按一个坑、局部发软，熟过头或内部已坏。
5. **看叶片和切口**：冠芽青绿挺立较新鲜；切口干燥、无汁液、无褐变为好。冠芽容易拔掉不一定代表熟，别单靠这一条。
6. **掂重量**：同样大小，手感沉、水分足更好；轻飘的可能失水或空心。

**采购比例建议：**
- 如果日销稳定：约60%–70%进“黄中带青、1–2天转熟”的果，20%–30%进“整体金黄、当天可卖”的果，10%以内进“全熟果”用于促销或现切。
- 如果天气热、客流不确定：减少全熟果，多进偏生一点的果。
- 到货后按熟度分区摆放，全熟果放显眼位置优先卖，偏生果放后排或阴凉处。

**简单可执行的验收标准：** 整批货里，允许少量全熟果，但软塌、渗汁、酒味明显的果比例应控制在很低；超过一定比例就说明这批货熟度偏高，损耗风险大。
