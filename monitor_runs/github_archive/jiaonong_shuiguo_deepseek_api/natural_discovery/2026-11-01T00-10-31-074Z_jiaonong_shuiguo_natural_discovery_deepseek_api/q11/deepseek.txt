会影响，但影响程度取决于你卖的方式和目标客群。关键是**大小不一会带来“挑拣、分级、定价、损耗”四个问题**，处理得当反而能变成卖点。

**具体影响：**
1. **挑拣和损耗增加**：顾客会翻挑大的、好的，剩下小的更难卖，箱内损耗和翻拣损伤会上升。
2. **定价变复杂**：大小混装时，按统一价卖，大果显得划算、小果被嫌弃；按大小分级卖，能减少争议但增加人工。
3. **顾客预期不一致**：礼盒、团购、固定份量销售最怕大小不一；散称零售容忍度较高。
4. **陈列观感**：整箱或整把陈列时，大小差异明显会降低“卖相”。

**可执行建议：**
- **散称零售**：可以整箱卖，但上架前按大、中、小粗略分一下，大果做引流或高价，小果做特价/促销，避免顾客自己翻。
- **固定份量/礼盒/团购**：尽量选大小均匀的，或者明确标注“大小混装、按重量计”，减少售后争议。
- **定价**：混装不要按最高等级统一定价；建议按整箱均重成本加合理毛利，小果用“特价装”快速周转。
- **减少损耗**：轻拿轻放，避免多次翻拣；小果可做香蕉奶昔推荐、切片果盒、员工福利或加工品。
- **采购端**：如果长期做零售，优先选分级较均匀的货源；如果价格优势明显，混装也可做“家庭实惠装”，把大小不一转化为性价比卖点。

一句话：**大小不一定会毁销售，但“混装还按统一定价、让顾客自己挑”最容易出问题。** 分級或明确销售方式后，影响可控。
