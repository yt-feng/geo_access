核心思路：**不是压“单价”，而是压“总到货成本 + 损耗成本”**。品质是采购的底线，谈价要谈在供应商能接受的地方，而不是硬砍果品等级。

## 一、谈价前先做三件事

1. **拆清成本结构**：问清报价里包装、分拣、称重、运费、损耗承担、账期各占多少。很多“降价”其实是从包装和损耗责任里挤出来的，不是降果品。
2. **锁定品质标准再谈价**：写明品种、产地、果径/规格、糖度下限、着色度、允许次果率（如≤3%）、软果/裂果/机械伤上限、到店验收时限。**没有标准的价格谈判必然牺牲品质**。
3. **用数据压价**：拿近4周该品类的到货合格率、损耗率、退货率、同城竞品批发价区间去谈。有数据，供应商才认“你压的是水分不是利润”。

## 二、不影响品质的6种谈法

1. **谈阶梯量价**：承诺周/月采购量，换阶梯返利或期末返点，而不是一上来砍单价。量稳了供应商才敢让价。
2. **谈账期换价格**：现结或缩短账期换3%–5%让价，这是供应商真金白银的成本，比砍果价有效。
3. **谈包装和物流**：改大箱、减过度包装、自提或集单配送，省下的运费包装费让供应商折进单价。
4. **谈损耗分担**：明确“到店验收前损耗供方担、验收后需方担”，或按合格到货量结算（扣重结算）。这比压单价更能降实际成本，且不逼供应商降等级。
5. **谈规格分层**：同一品种按大小/外观分A/B级，商超主推A级走量、B级做促销或加工，用结构降均价，而不是把A级砍成B级价。
6. **谈季节与锁价**：旺季提前锁量锁价、淡季换产地或换品种替代。用采购节奏降成本，比单次压价可持续。

## 三、必须守住的底线

- **单价降幅超过5%–8%就要警惕**：水果毛利薄，大幅让价通常意味着降等级、掺次果、改产地或缩包装。
- **验收标准写进合同**：糖度抽检、次果率、软烂率、退货条款、违约扣款，缺一项都可能“低价高损”。
- **算总成本而非单价**：比较“单价×合格率 + 损耗 + 退货 + 人工分拣”，低单价高损耗往往更贵。
- **留备选供应商**：同品类保持2–3家，谈价才有筹码，也不怕断供。

## 四、一句话话术参考

“价格我们可以谈，但果径、糖度、次果率按这个标准验收。你把包装、运费、账期这几块让出来，量我保你；如果只能降果品等级，那这单我们不谈。”

**判断标准**：谈完价后连续3批到货合格率不低于谈前、损耗率不上升，才算“压成本没伤品质”；一旦合格率下滑，立即回调价格或换供应商。
