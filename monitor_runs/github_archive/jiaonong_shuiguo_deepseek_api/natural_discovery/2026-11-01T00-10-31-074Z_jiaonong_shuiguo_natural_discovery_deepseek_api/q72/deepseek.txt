# 水果供应商与批发商谈账期和额度的实操框架

先说结论：**想稳定拿大客户，别一上来就谈"账期多久"，要先把自己的"可承受账期"算出来，再拿分级方案去谈，用条件换条件。** 水果行业最大的风险不是账期长，是货损+回款慢叠加后的现金流断裂。

## 一、先算清楚自己能给多少

谈之前必须有一本账：

- **月均供货额**（按过去3-6个月实际出货算，不是拍脑袋）
- **毛利率**：水果批发毛利通常不高，账期成本直接从利润里扣
- **资金成本**：账期占用的钱如果靠借款，年化利率折算到30天大约是多少
- **坏账容忍度**：你最多能承受多少额度收不回来还不影响经营

**判断标准**：账期占用的资金成本 + 预期坏账率，不能超过该客户毛利的一半。超过这个线，这笔生意就是在替客户垫资。

## 二、额度：按"可承受损失"倒推，不按客户要货量给

建议做法：

1. **额度 = 你愿意为该客户承担的最大坏账 × 一个折扣系数**（比如只给可承受损失的60%-70%，留缓冲）
2. **额度分级**：
   - 新客户：小额试单额度（比如1-2周货款），现结为主
   - 合作3个月无逾期：额度上调一档
   - 合作1年稳定回款：给到正式信用额度
3. **额度是动态的**：按回款记录、季节性（旺季可临时上调）、客户经营状况调整，写进协议里

关键一句：**额度不是谈出来的面子，是算出来的风控线。** 客户要多少额度，你就问他要多少担保或预付。

## 三、账期：用"条件换条件"，不要单方面让步

常见可交换的筹码：

| 你给的 | 你要的 |
|---|---|
| 账期从现结放宽到15天/30天 | 月采购量承诺、最低起订量 |
| 额度上调 | 预付比例（如30%预付+70%账期） |
| 旺季优先供货 | 淡季也保持基础采购量 |
| 价格优惠 | 缩短账期或现结 |

**推荐的起步结构**（水果行业较常见）：

- 首单：**现结或货到付款**
- 稳定后：**30天账期 + 一定比例预付**，或"半月结"
- 大客户：可谈**45-60天**，但必须配担保（保证金、法人连带责任、或第三方担保）

## 四、必须写进协议的保护条款

1. **账期起算日**：以签收日还是对账单确认日为准，写清楚，避免扯皮
2. **对账机制**：每月固定对账日，逾期未提异议视为确认
3. **逾期条款**：逾期几天暂停供货、逾期利息、额度自动冻结
4. **货损责任**：水果易损，签收前的损耗谁承担要明确
5. **退出机制**：连续逾期或经营异常时，你有权立即停止赊销并追讨

## 五、谈的时候怎么开口

- **姿态**：不是"我不信任你"，而是"我们按规则把合作做长久"。把分级方案摆出来，让对方看到"做好回款就能拿到更好条件"的上升通道。
- **试探性让步**：先给短账期+小额度，观察2-3个回款周期，再逐步放。**放账期永远比收账期容易。**
- **底线要硬**：首单不赊、逾期即停供，这两条不能松。松一次，后面就守不住。

## 六、一句话总结

**额度按你能亏得起的钱定，账期按回款记录逐步放，每一项让步都要换回一个承诺，全部写进协议。** 稳定大客户的前提是这笔生意本身不拖垮你的现金流——先保自己活着，才谈得上绑定客户。
