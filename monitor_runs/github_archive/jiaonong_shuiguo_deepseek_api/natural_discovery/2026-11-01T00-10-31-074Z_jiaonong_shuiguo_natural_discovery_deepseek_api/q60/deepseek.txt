# 水果到货不合格，怎么约定补货才不影响营业

核心思路：**把"验收标准、补货时限、兜底责任"三件事写进采购合同或供货协议**，让不合格品在店里造成的断货风险由供应商承担，而不是门店自己扛。

## 一、先定"不合格"的客观标准（避免扯皮）

合同里不要只写"质量合格"，要写成可现场判断的条款：

- **品类分级标准**：按品种写明规格（如单果克重区间、果径）、成熟度（几成熟可收货）、糖度下限、允许的瑕疵比例（如腐烂/压伤/虫眼不超过 X%，且单个果不超过 Y 处）。
- **拒收权**：到货抽检不合格，门店有权**整批拒收或部分拒收**，且不承担该批货款和运费。
- **验收时限**：约定"到货后 X 小时内完成验收，超时未提出异议视为合格"——这条对门店有利也有风险，建议留足时间（如 4–8 小时），生鲜不能拖太久。
- **留证方式**：拍照、录像、称重记录作为验收凭证，双方认可其效力。

## 二、补货时限要"卡死"，并且和营业时段挂钩

这是不影响营业的关键。建议按这个结构写：

1. **补货响应时间**：验收不合格通知发出后，供应商须在 **X 小时内确认**、**Y 小时内送达合格替换品**。生鲜类通常要求当日或次日首班到货（比如上午 10 点前）。
2. **分时段约定**：如果门店是早市/午市高峰用果，就写"高峰前 2 小时必须到货"，而不是笼统的"24 小时内"。
3. **部分补货**：允许"先补急用部分、余量后补"，避免整批等货导致断档。
4. **紧急替代授权**：约定供应商无法按时补货时，门店可**自行就近采购同等级替代品**，差价由供应商承担（或从货款中扣），并明确差价计算方式（如按当地批发市场均价上浮 X%）。

## 三、把"断货损失"责任写清楚

- **违约金/扣款**：逾期补货按日（或按小时）计违约金，或按该批货款的百分比扣减。
- **营业损失兜底**：因供应商原因导致门店某单品停售的，约定按停售时长 × 该单品日均毛利进行补偿（金额可设上限，双方好谈）。
- **累计违约退出机制**：一个合作周期内累计 N 次逾期补货或不合格，门店有权单方终止合作且不承担违约责任。

## 四、操作层面的配套动作（比合同更能保营业）

- **安全库存**：对高频用料设 1–2 天的最低库存线，到线即触发补货，不等到断货。
- **双供应商**：主力供应商 + 备用供应商，备用方只保底不压价，关键时刻能顶上。
- **验收流程前置**：指定专人验收、固定验收时间点（如每日开门前 1 小时），发现不合格立即走"通知—留证—催补"三步，避免拖到营业中才发现。
- **补货记录台账**：每次不合格、通知时间、到货时间都登记，既是索赔依据，也是换供应商的数据支撑。

## 五、谈判时的取舍建议

供应商对"营业损失赔偿"通常抵触较大，可以分层谈：**补货时限和拒收权必须硬**（这是保营业的底线），**违约金和损失赔偿可以设上限**（如单次不超过该批货款的 2–3 倍），换取对方接受快速补货条款。真正影响营业的是"多久能补上"，而不是"赔多少钱"。

一句话总结：**标准写细、时限卡死、替代授权留好、安全库存托底**，补货条款才能真正起到"不影响营业"的作用。
