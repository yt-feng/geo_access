旺季菠萝用量突增，和供应商约定临时补货，核心是把“临时”变成可执行的规则，而不是每次靠电话求人。建议从下面几件事一次谈定，写进补充协议或采购单备注。

**1. 先给供应商一个可预期的量**
- 按过去7天实际用量，估算未来2周日均用量和峰值日用量，给供应商一个区间，比如“日均80箱，峰值120箱”。
- 明确补货提前期：常规提前24小时下单，紧急补货提前6小时或当天上午下单。
- 说明旺季起止时间，避免供应商以为只是偶然一次。

**2. 约定补货机制**
- **触发条件**：库存低于安全库存（如2天用量）时自动补货，或每周固定两次对账补单。
- **补货量**：按“日均用量×补货周期+安全库存”计算，写清最小起订量和单次上限。
- **响应时限**：供应商收到补货通知后几小时内确认、几小时内送达，逾期怎么处理。
- **优先供应**：旺季期间同等价格下优先保障你的补货需求，可接受适度加价换取优先权。

**3. 价格和品质条款要锁定**
- 临时补货价格按约定基准价上浮不超过某个比例，或直接锁定旺季价格区间，避免坐地起价。
- 规格、成熟度、单果重量、坏果率标准与常态一致，补货批次同样验收，不合格可拒收或扣款。
- 明确损耗承担：运输损耗、到货坏果由谁承担，避免临时货品质下降。

**4. 付款和违约**
- 临时补货可约定现结或缩短账期，换取供应商优先响应。
- 约定供应商未按时按量补货的违约责任，比如赔偿临时高价采购差价，或下一批次折扣。
- 你方临时取消补货的，提前几小时通知，避免供应商压货损失。

**5. 留备用方案**
- 同时谈1—2家备用供应商，主供应商补货不及时可切换。
- 旺季前适当增加冷库安全库存，把“临时补货”比例控制在总用量30%以内，降低对单一供应商的依赖。

**可直接写进补充协议的条款示例：**
> 旺季期间（X月X日至X月X日），需方提前24小时下达补货单，供方须在12小时内确认、24小时内送达；紧急补货提前6小时通知，供方须在12小时内送达。补货价格按基准价上浮不超过5%。供方未按时按量供货的，按缺口金额的20%赔偿需方临时采购差价。品质验收标准与主合同一致。

最后提醒：口头约定容易在旺季扯皮，哪怕是一页纸的补充确认，也要把量、时间、价格、违约四件事写清楚，双方签字或微信书面确认都行。
