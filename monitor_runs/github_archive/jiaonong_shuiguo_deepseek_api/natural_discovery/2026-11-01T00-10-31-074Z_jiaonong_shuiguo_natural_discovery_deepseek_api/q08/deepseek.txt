# 小店拿货：批发市场 vs 固定供应商

结论先说：**进货量不大、刚开业或品类还在试水的阶段，批发市场更合适；等某几个品类跑出稳定销量后，再把这些品类转成固定供应商。** 不必二选一，按品类分开处理最划算。

## 两种方式的取舍

**批发市场更适合的情况**
- 单次进货少、频次高，需要小批量、多品种混着拿
- 还在试探哪些货好卖，需要随时换品、看新款
- 对价格敏感，愿意花时间比价、挑货
- 不需要账期，现款现货更省心

代价是：价格不是最优、品质批次不稳定、每次要花时间跑、断货时没好办法。

**固定供应商更适合的情况**
- 某几个品类已经卖得稳，销量可预测
- 需要稳定品质和持续补货，不想每次重新挑
- 量大到能谈价格、谈账期、谈退换
- 希望省下跑市场的时间

代价是：起订量门槛、换供应商有磨合成本、容易被单一货源卡住。

## 可执行的建议

1. **先跑 1–2 个月批发市场**，记录每个品类的销量、复购、退货情况。
2. **把销量前 20% 的品类挑出来**，这些是值得找固定供应商的。
3. 找固定供应商时，**同一品类至少备 2 家**，避免断货被拿捏；先小单试合作，看品质稳定性和响应速度。
4. 长尾、季节性、试新款继续走批发市场，保持灵活。
5. 算一笔账再决定：固定供应商的单价优势，要能覆盖起订量带来的压货成本和资金占用，才算真划算。

## 一句话判断标准

**销量稳、可预测 → 固定供应商；销量不稳、在试错 → 批发市场。** 按品类拆开，别整体二选一。
