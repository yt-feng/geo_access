水果店遇到坏果，和供应商结算或赔付，核心是先分清责任和证据，再按合同/约定处理。可执行做法如下：

1. **先保留证据**
   - 到货当场或开箱时拍照/录像：坏果比例、包装批次、运单、温度记录（如有）。
   - 保留进货单、送货单、微信/合同约定、验收签字记录。
   - 不要先把坏果扔掉或混放，便于复核；易腐品可协商后视频销毁或拍照后处理。

2. **按验收时点分责任**
   - **到货验收时发现**：属于供应商交货质量问题，应当场拒收、扣减数量或要求换货；已签收但当场开箱发现的，及时书面/微信通知供应商并留证。
   - **签收后短期內发现**（如内部腐烂、催熟不均）：看合同约定的验收期限和保质责任；无约定时按行业惯例和过错分担，不能无限期把自然损耗全推给供应商。
   - **因门店储存不当**（温度、挤压、过期）造成的坏果，一般由门店自行承担。

3. **结算方式优先按合同**
   - 有合同/供货协议：按约定的质量标准和赔付条款执行，如扣款、换货、补发、退货退款。
   - 无书面合同：按双方长期交易习惯和本次协商处理，建议形成书面确认（微信文字也算）。
   - 常见可接受方案：
     - 坏果部分**退货退款**或**下批补货**；
     - 按坏果金额**在当期货款中扣减**；
     - 坏果比例较高时，整批退货或要求供应商承担运费；
     - 长期合作可约定月度汇总扣款，但每笔要有记录。

4. **赔付范围要合理**
   - 一般赔直接损失：坏果货值、退货/换货运费。
   - 门店主张间接损失（如客诉赔偿、停业损失）需要有合同依据或供应商过错证明，否则较难全额支持。
   - 不要未经协商直接大额扣款，容易引发对账争议；应先发对账函/微信确认。

5. **操作顺序建议**
   - 发现坏果 → 拍照留证 → 当天通知供应商 → 协商方案（换货/扣款/退货）→ 书面确认 → 结算时执行。
   - 供应商不认：先核对送货单和验收记录；仍争议可找批发市场管理方、行业协会调解，或按合同走诉讼/仲裁。

**一句话原则：到货验收环节把质量问题确认清楚，按合同和证据扣减或换货；签收后因储存造成的损耗自己承担，不混账、不口头大额扣款。**
