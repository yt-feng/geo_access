酒店采购水果盘原料时，建议把“规格标准”和“外观标准”分开写进采购验收单，供应商至少应保证以下内容。

## 一、通用规格与验收标准

1. **品种与产地**
   - 品种名称、等级、产地明确，不得以次充好或混装。
   - 同一批次品种、成熟度、规格基本一致。

2. **新鲜度**
   - 无腐烂、霉变、异味、发酵、虫蛀、虫卵。
   - 无冷害、冻伤、机械伤导致的渗汁或软烂。
   - 到货时中心温度符合冷链要求，冷藏水果一般保持在适宜低温，不得断链。

3. **成熟度**
   - 即食水果盘原料应达到“可即食成熟度”：外观成熟、口感适口，切开后不硬不烂。
   - 需短期存放的品种可略偏生，但不能酸涩难入口。

4. **规格尺寸**
   - 按品种约定单果重量、横径、长度或切块尺寸范围。
   - 同批次大小均匀，允许误差范围写清楚，例如单果重量偏差不超过±10%。
   - 切配类原料应约定块形、厚度、长度，避免大小不一影响摆盘。

5. **洁净与安全**
   - 表面无泥土、明显农残风险、蜡层异常、污渍。
   - 提供合格证明或农残检测报告，符合国家食品安全相关标准。
   - 包装材料清洁、无毒、无异味，标签完整。

6. **包装与标识**
   - 外箱牢固、防压、防潮；内包装透气或按品种需要保鲜。
   - 标签注明品名、产地、等级、净重、采摘/包装日期、供应商信息。
   - 不得混入非约定品种或残次果。

7. **冷链与到货要求**
   - 需冷藏品种全程冷链，到货温度符合约定。
   - 到货时间、批量、包装完整性可追溯。
   - 破损率、次果率设定上限，例如外观不合格率不超过3%—5%，超出部分拒收或折价。

## 二、外观标准

供应商应保证：

- **果形端正**：无明显畸形、偏斜、凹陷。
- **色泽正常**：具有该品种成熟时应有的色泽，无大面积青斑、褐变、黑斑。
- **表面完整**：无裂口、明显擦伤、压伤、刺伤、日灼、冻伤。
- **无病虫害**：无虫眼、虫粪、霉点、病斑。
- **无污染**：无泥污、药斑、异常蜡质、异物。
- **大小均匀**：同批次规格一致，适合统一摆盘。
- **果柄/切口状态**：需保留果柄的品种应新鲜不干枯；切配原料切口平整、无褐变、无汁液流失。
- **适合摆盘**：无明显疤痕、畸形果、阴阳面严重等影响酒店出品卖相的问题。

## 三、建议写入合同的关键条款

- 明确每个品种的**等级、单果规格、成熟度、允许缺陷比例**。
- 明确**拒收标准**：腐烂、霉变、异味、严重压伤、规格不符、温度超标可整批拒收。
- 明确**抽检比例和判定方法**：如每批随机抽检10%，不合格率超5%可拒收。
- 明确**索赔与补货时限**：到货2小时内提出异议，供应商24小时内补货。
- 要求随货提供**检测报告/合格证**，并保留批次追溯信息。

一句话：酒店水果盘原料的供应商应保证“品种等级明确、规格均匀、成熟可即食、新鲜无病害、外观端正无伤、冷链不断链、包装标识可追溯”，并将这些标准量化写进验收单和合同。
