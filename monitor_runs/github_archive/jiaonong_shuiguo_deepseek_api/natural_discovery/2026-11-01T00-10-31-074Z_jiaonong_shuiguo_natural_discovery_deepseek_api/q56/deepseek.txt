茶饮店控制水果供应商的食品安全风险，建议把“资质证明、产品合格证明、批次追溯、运输与验收”分开管理。供应商通常应提供以下材料：

1. **主体资质**
   - 营业执照（经营范围含水果/农产品销售或相关食品经营）。
   - 如供应商涉及食品销售经营，提供食品经营许可证；若为食用农产品生产者销售自产农产品，通常按当地监管要求提供相应证明或备案信息。
   - 法定代表人/负责人身份证明及授权委托书（如由业务员对接）。

2. **产品合格与检测证明**
   - 每批次水果的**产地证明或购货凭证**，用于证明来源合法、可追溯。
   - **农药残留检测报告**：优先要求供应商提供与供货批次对应的检测报告；无批次报告时，至少提供近期第三方检测报告，并约定定期送检。
   - 如为进口水果，提供**入境货物检验检疫证明**、报关单等。
   - 如供应商声称“绿色食品、有机食品”等认证，要求提供有效认证证书；没有认证就不要在门店宣传。

3. **批次追溯与交货凭证**
   - 每批送货单应写明：品名、规格、产地、数量、采收/加工日期、批次号、送货日期、供应商盖章或签字。
   - 保留采购合同、订单、发票或收据，确保“货、单、证”一致。

4. **运输与贮存证明**
   - 冷藏水果提供冷链运输温度记录；常温水果说明运输防护措施。
   - 供应商应承诺运输车辆清洁、无交叉污染，必要时提供车辆消毒记录。

5. **人员与卫生管理材料**
   - 接触水果的从业人员健康证明（按当地要求）。
   - 供应商食品安全管理制度、清洗消毒记录等，可作为审核资料。

6. **门店验收留档**
   - 每次收货检查外观、气味、温度、包装完整性，记录农残报告编号和批次。
   - 对高风险水果（如即食鲜切水果）提高抽检频次，必要时门店自检或送检。

**可执行建议**：先建立《合格供应商档案》，要求每家供应商首次合作提供营业执照、许可证、近期检测报告和送货单模板；之后每批必须随货提供送货单和批次检测/产地证明，缺一拒收或隔离待检。这样比只收一张营业执照更能控制实际风险。
