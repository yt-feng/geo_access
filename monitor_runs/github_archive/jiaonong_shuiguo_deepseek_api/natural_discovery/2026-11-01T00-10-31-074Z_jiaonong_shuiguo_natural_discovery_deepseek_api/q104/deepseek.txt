# 单位采购水果：到货品质不一致的验收与售后处理

## 一、验收前先立标准（关键前提）

品质不一致的争议，80% 出在“标准没写清楚”。采购合同或订单里应明确：

- **规格等级**：果径/单果重范围、等级（特级/一级）、糖度下限
- **外观标准**：允许的瑕疵比例（如碰伤、裂口、霉变≤某百分比）
- **成熟度**：可售期要求（到货后能存放几天）
- **抽样规则**：按箱/按批次抽检比例（如每批随机抽 5%–10%）
- **验收时限**：到货后多少小时内提出异议有效
- **售后条款**：不合格部分怎么处理（退、换、折价）

## 二、到货验收怎么做

1. **当场开箱抽检，不要只签字收货**。按批次随机抽箱，逐箱翻看上下层（供应商常“上好后差”）。
2. **分层记录**：把“合格数 / 轻微瑕疵 / 严重不合格（霉变、腐烂、未熟、过熟）”分别计数并拍照，照片带时间、箱号。
3. **称重核对**：净重是否足秤，剔除包装和冰袋。
4. **按批分区**：不合格的单独堆放并贴标签，避免和合格品混放后被“一起算账”。
5. **当场出具验收单**：写明批次、抽检数、不合格数、不合格比例、处理意见，双方签字。这是后续售后的唯一依据。

## 三、品质不一致的处理方式（按严重程度）

| 情况 | 处理建议 |
|---|---|
| 少量瑕疵（在合同允许比例内） | 正常收货，记录备查 |
| 部分批次不合格（如 10%–30%） | 不合格部分退货或按比例折价，合格部分照收 |
| 大面积不合格（如超 30% 或整批霉变） | 整批拒收，要求换货或退款 |
| 不影响食用但品相差 | 协商折价，用于内部食堂等非对外场景 |

原则：**能分拣就分拣处理，不要“一刀切”全退或全收**，既减少损失也便于和供应商谈。

## 四、售后跟进

1. **书面留痕**：验收单 + 照片 + 沟通记录（微信/邮件）一并保存。
2. **限时反馈**：到货当天或合同约定时限内书面通知供应商，逾期容易被拒。
3. **明确诉求**：退货、换货、折价、补货，写清数量、金额、时限。
4. **复验**：换货到货后重新抽检验收，不要因为“是补发的”就免检。
5. **记录供应商表现**：把每次不合格率记入供应商档案，作为下次采购和评标的依据；同一供应商反复出问题，考虑调整份额或更换。

## 五、几个容易踩的坑

- **只签字不验货**：签字即视为认可，后续维权困难。
- **口头协商不留证据**：一定要落到验收单或聊天记录。
- **抽样只抽表层**：务必翻箱、抽不同位置。
- **拖延反馈**：超过合同约定时限，供应商可拒绝售后。
- **没有“允许瑕疵比例”**：轻微瑕疵属正常，全按不合格算会激化矛盾。
