判断水果供应商靠不靠谱，重点不是听他怎么说，而是用几次小批量试单把关键指标验出来。香蕉和菠萝的差别很大：香蕉看催熟和到货成熟度，菠萝看产地、糖度和损耗。可以按下面这套方法做。

**1. 先小批量试单，不要一次押大**
- 首次每家供应商只订1-2箱香蕉、1-2箱菠萝，连续试3次，间隔几天，看稳定性。
- 固定同一规格下单，比如香蕉要求几成熟到货、每箱净重多少、单根粗细范围；菠萝要求品种、单果重范围、成熟度。规格写进订单，后面才有对比依据。

**2. 验收时当场记录四个数**
- **净重差**：去掉箱子和填充物称重，看是否低于约定净重。
- **损耗率**：坏果、压伤、黑斑、腐烂比例。香蕉重点看机械伤和催熟不均，菠萝重点看黑心病、烂心、日灼。
- **成熟度**：香蕉到货是青的还是已经黄，催熟是否均匀；菠萝看底部颜色、果眼、香味，切开抽查黑心。
- **可售率**：实际能上架卖的部分占进货金额的比例，比单纯看坏果数更直观。

连续3次记录，如果某家损耗率忽高忽低、净重经常不足，就不适合长期合作。

**3. 看供货稳定性，不只看价格**
- 问清楚：香蕉是哪里调的货、催熟是自己做还是外购；菠萝是固定产地还是随行就市。产地和季节变化大时，供应商能不能提前告知。
- 问断货时怎么处理：有没有替代规格、能否提前一天确认次日货量。长期做生意，稳定比便宜几毛钱更重要。
- 观察送货时间是否固定。水果店早市很关键，经常迟到或临时改量的供应商，长期会拖累你。

**4. 看售后和账期态度**
- 明确坏果怎么赔：是下次补货、折价还是现金退。看他是痛快处理还是反复扯皮。
- 先做现结或短账期，合作稳定后再谈账期。不要因为对方给长账期就放松质量要求。
- 保留每次验收照片和称重记录，出问题时有依据。

**5. 用“对比试单”做最终判断**
同时找2-3家供应商，各试3次，按同一规格比较：净重达标率、损耗率、到货成熟度、送货准时率、售后响应。选综合最稳的一家做主供，另一家做备供，不要只押一家。

**简单判断标准：**
- 连续3次净重基本达标、损耗率稳定且能接受、送货准时、坏果售后不扯皮，就可以进入长期合作。
- 如果价格明显低于市场、但净重经常不足或损耗忽高忽低，通常不适合长期做。
- 香蕉和菠萝都怕催熟和储存问题，供应商是否懂这两类货、能否给你到货成熟度建议，也是靠谱程度的一部分。

最后提醒：所有约定尽量落到订单或聊天记录里，尤其是规格、净重、损耗赔付和送货时间。长期合作靠的是可重复的验收数据，不是一次见面印象。
