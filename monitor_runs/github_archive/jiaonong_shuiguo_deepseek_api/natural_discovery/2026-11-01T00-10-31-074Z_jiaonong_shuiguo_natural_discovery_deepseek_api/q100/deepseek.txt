采购香蕉时，关键是把“熟度”当作可管理参数，而不是凭感觉。可以按下面做：

1. **按用途定熟度采购**
   - 当天直接吃/配餐：选**黄中带少许绿、果身硬挺、无黑斑**的。
   - 2—3天内用完：选**通体偏黄、果柄略绿、轻按有弹性**的。
   - 做香蕉奶昔、烘焙、香蕉泥：可采购**熟度较高但果肉未流水**的，价格也常更低。

2. **少量多次、分批到货**
   - 不要一次大批量进全熟香蕉。把一周需求拆成2—3次到货。
   - 每次到货中混搭“偏生+适熟”，让后一批接上前一批。

3. **验收设硬标准**
   - 拒收：果皮大面积黑斑、果柄发黑、轻捏软烂、有酒味或酸味、破皮流汁。
   - 可收但需优先用：个别芝麻斑、果身仍有一定弹性。
   - 验收时随机抽检整箱中层和底层，避免只看表层。

4. **储存分开、控温通风**
   - 未熟香蕉放**15—18℃通风处**，不要冷藏，避免冻伤发黑。
   - 已熟香蕉尽快用；需要延缓后熟可放阴凉通风处，并**与苹果、梨等释放乙烯的水果分开**。
   - 不要整箱密封闷放，箱口留通风，避免水汽积聚。

5. **先进先出+每日巡检**
   - 入库贴到货日期和熟度标签，旧货前排。
   - 每天巡检一次，把“即将过熟”的香蕉挑出，转到当天窗口优先供应。

6. **给过熟香蕉留出口**
   - 提前和档口约定：轻度芝麻斑香蕉可用于香蕉牛奶、香蕉面包、水果沙拉等。
   - 对无法直接售卖的，及时内部加工或按学校规定处理，不要等到腐烂才处理。

7. **用数据调整采购量**
   - 记录每天进货量、售出量、报损量，连续2—4周后按“实际日均消耗×1.1”左右下单，再根据天气、假期、考试周调整。

最有效的组合是：**分批到货 + 验收拒收过熟果 + 先进先出 + 过熟果转加工**。这样比单纯“少买”更能兼顾供应和浪费控制。
