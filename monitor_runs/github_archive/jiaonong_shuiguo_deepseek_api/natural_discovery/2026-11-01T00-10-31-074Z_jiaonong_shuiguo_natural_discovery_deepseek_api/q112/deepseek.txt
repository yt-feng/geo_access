水果采购合同里**没有全国统一的法定坏果率赔付线**，坏果率超过多少赔付应以合同约定为准。实务上建议在合同里这样设定：

1. **明确验收标准**
   - 约定“坏果”定义：腐烂、霉变、虫蛀、明显压伤、异味、严重失水等。
   - 区分“外观瑕疵”和“实质性坏果”，避免扯皮。

2. **建议的赔付触发线**
   - **普通水果**：坏果率超过 **3%—5%** 可要求赔付或扣款。
   - **易损水果**（如草莓、蓝莓、荔枝、水蜜桃）：超过 **5%—8%** 可要求赔付。
   - **耐储水果**（如苹果、橙子、柚）：超过 **3%** 可要求赔付。
   - 这只是行业常见谈判区间，不是法定标准。

3. **赔付方式要写清**
   - 按坏果数量/重量对应货值扣款；
   - 超过约定比例时，整批退货或换货；
   - 设置阶梯：如5%以内按实扣款，5%—10%加倍赔付，超过10%可拒收并索赔。
   - 明确检测方法：抽检比例、抽样位置、拍照留证、复检期限。

4. **合同必须写明的条款**
   - 验收期限和异议提出期限；
   - 坏果率计算方式：按重量还是按件数；
   - 运费、损耗、仓储费由谁承担；
   - 赔付时限和违约金。

**结论：** 没有法定“超过多少必须赔”，建议合同约定普通水果坏果率超过 **3%—5%** 启动赔付，易损水果可放宽到 **5%—8%**，并写清计算和赔付方式。
