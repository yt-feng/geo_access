水果采购合同里并没有一个“国家标准规定的坏果率”，坏果率超过多少可以要求赔付，主要由**合同约定**决定。实务上可按下面判断：

**1. 合同有约定：按合同执行**
- 若合同写明“坏果率≤3%”“超过5%可拒收”“超过X%按比例扣款/赔偿”，就直接按约定。
- 常见写法：到货验收坏果率超过 **3%—5%**，超出部分按重量扣款；超过 **10%—15%**，可整批拒收或要求退换。
- 易腐水果如草莓、荔枝、杨梅，阈值通常更严；苹果、橙子、柚子等耐储水果可稍宽。

**2. 合同没约定：按“合理损耗 + 超出部分赔付”谈**
- 一般可把 **3%—5%** 视为合理运输损耗区间。
- 超过这个区间，采购方通常可以要求：
  - 超出部分按实际坏果重量扣款；
  - 因坏果导致整批降级的差价赔偿；
  - 严重时退货、换货、拒收，并由供货方承担运费或损失。
- 如果坏果率很高，比如 **超过10%—15%**，即便合同没写，也较容易主张供货方违约或质量不符。

**3. 建议写进合同的具体条款**
可以这样约定：
> 到货后24小时内验收。坏果率≤3%视为正常损耗；超过3%的部分，按实际坏果重量×采购单价扣款；坏果率超过10%，采购方有权拒收或要求换货，由此产生的运费、仓储费及损失由供货方承担。

**4. 关键不是只看比例，还要看证据**
- 验收时间、验收标准、抽检方法要提前写清。
- 拍照/视频、过磅单、验收记录、聊天记录都要留。
- 若合同写“以到货当日验收为准”，过期再提坏果，可能难获支持。

**结论：**
没有统一法定比例。最稳妥是合同约定 **3%—5%为合理损耗，超出部分赔付；超过10%—15%可拒收或换货**。如果合同没写，通常也可主张超过合理损耗的部分由供货方赔偿，但需要证据和协商/诉讼支持。
