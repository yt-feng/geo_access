提高水果区客单价，核心不是“让顾客多买香蕉”，而是**让顾客从买单一水果变成买组合/多品类**。香蕉、菠萝、苹果的客单价与毛利结构不同，适合做“引流+搭售+组合”三层促销。

## 先看三个品项的角色

| 品项 | 角色 | 特点 |
|---|---|---|
| 香蕉 | 引流品 | 购买频次高、价格敏感、易冲动购买 |
| 菠萝 | 利润/加工品 | 有加工门槛，可做切块/整颗，毛利空间较大 |
| 苹果 | 稳定品/搭配品 | 家庭常购、耐储存、适合组合 |

**建议组合逻辑：香蕉引流，苹果稳客单，菠萝拉毛利。**

## 可直接落地的4种促销方案

### 方案1：组合价，但不要简单打折
设三个组合，价格按“单买总价打9折左右”设计：

- **早餐组合**：香蕉1把 + 苹果4个 = 组合价
- **下午茶组合**：菠萝1个（可代切）+ 苹果3个 = 组合价
- **家庭装组合**：香蕉1把 + 菠萝1个 + 苹果6个 = 组合价

关键点：
- 组合价要标出“单买价”和“省多少”，让顾客有感知。
- 组合装用统一托盘/网兜/纸袋，放在入口或主通道。
- 不要三个品项都降价，只让香蕉让利，苹果和菠萝保持正常毛利。

### 方案2：加价购，比直接降价更保毛利
例如：
- 买苹果满10元，加3元换购香蕉1把；
- 买菠萝1个，加5元换购苹果4个；
- 买任意水果满15元，加6元换购切块菠萝1盒。

**加价购的好处**：顾客原本只买苹果，现在多买香蕉或菠萝，客单价直接上去，且不是全场打折。

### 方案3：按场景打包，而不是按品类打包
顾客不是按“香蕉、菠萝、苹果”买东西，而是按场景买：

- **儿童水果盒**：香蕉+苹果+菠萝切块，小份装，适合放学加餐；
- **办公室分享装**：整颗菠萝+香蕉+苹果，附一次性叉子/切刀；
- **减脂轻食组合**：苹果+菠萝+香蕉，标注热量和食用建议。

场景越具体，顾客越容易觉得“我需要”，而不是“你在清库存”。

### 方案4：试吃+切块，把菠萝变成高客单入口
菠萝整颗购买有决策门槛，但切块后试吃能显著降低门槛。

操作：
- 现场切菠萝，试吃后推荐“菠萝+苹果+香蕉”组合；
- 切块菠萝单独定价，同时买组合可减2元；
- 试吃台旁边直接放组合装，缩短决策路径。

## 定价与陈列建议

**定价：**
- 组合价 = 单买总价 × 0.88～0.92；
- 加价购商品选香蕉或小份菠萝，成本低、感知强；
- 不要做“买一送一”，会拉低水果区价格形象。

**陈列：**
- 入口放香蕉，主通道放组合装，端头放菠萝试吃；
- 组合装放在苹果和菠萝之间，形成动线；
- 用大字标“组合价”“省X元”“可代切”，比写品名更有效。

## 一个简单可执行的周促销节奏

| 时间 | 动作 |
|---|---|
| 周一到周三 | 香蕉低价引流，推苹果+香蕉组合 |
| 周四到周五 | 菠萝试吃，推菠萝+苹果加价购 |
| 周末 | 家庭装组合、办公室分享装，主推高客单 |

## 判断是否有效的指标

不要只看销售额，看这三个：
1. **客单价**：水果区每单金额是否提升；
2. **连带率**：每单水果品类数是否从1.2提升到1.5以上；
3. **菠萝动销**：菠萝是否从低动销变成组合入口。

如果组合装销量高但客单价没涨，说明只是把原价购买变成了打折购买，需要减少折扣、增加加价购。
