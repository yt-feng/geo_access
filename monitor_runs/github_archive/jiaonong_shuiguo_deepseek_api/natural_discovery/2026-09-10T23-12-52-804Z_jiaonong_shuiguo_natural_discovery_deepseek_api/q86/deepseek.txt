生鲜平台做一件代发水果，供应商至少要把“产地发得出、路上坏得少、售后扛得住”这三件事跑通。建议重点核验以下仓配能力：

**1. 仓端：分拣打包 + 品控 + 库存**
- **产地仓/前置仓能力**：能否在产地或销地设仓，支持按单拣货、打包、贴面单，而不是只能整车发货。
- **水果专用包装**：有没有防震、透气、防压、保温/冰袋方案，不同品类（浆果、柑橘、芒果、榴莲）要分开配置。
- **品控分级**：能否按成熟度、糖度、果径、外观分级，并做到“坏果不上单、次果不混发”。
- **库存同步**：能否实时回传库存，避免平台超卖；临期/易腐库存要有锁单和清仓机制。
- **日处理峰值**：平时和爆单日能处理多少单，必须给明确数字，最好看历史大促数据。

**2. 配端：时效 + 温控 + 覆盖**
- **快递/专线资源**：是否绑定稳定快递，能否拿到生鲜优先揽收、优先中转、优先派送。
- **发货时效**：截单时间、当日揽收率、48小时/72小时送达覆盖率要能承诺并监控。
- **温控链路**：常温、冷藏、冷冻分别怎么走；夏季高温、冬季防冻是否有对应方案。
- **区域覆盖**：哪些省份可发、哪些偏远地区不发、哪些地区售后率明显偏高。
- **轨迹可视化**：平台能否看到揽收、中转、派送、签收节点，异常件能否主动预警。

**3. 售后与逆向：坏果包赔 + 快速响应**
- **坏果率承诺**：按品类给出可接受的坏果率上限，比如3%—5%或更低，并写入合同。
- **理赔规则**：拍照/视频标准、审核时效、赔付比例、是否补发或退款。
- **逆向处理**：拒收、退货、二次派送怎么处理，生鲜一般不支持原路退回，要有就地销毁或折价方案。
- **客服响应**：售后工单多久响应、多久闭环，是否支持平台侧对接。

**4. 系统与协同能力**
- **订单对接**：能否对接平台ERP/OMS，支持自动接单、打单、回传物流单号。
- **异常处理**：缺货、地址异常、天气延误、快递停发时，能否自动拦截并通知平台。
- **数据回传**：发货时效、签收时效、坏果率、售后率能否按日/周回传。

**5. 建议的准入核验清单**
- 让供应商提供近30天：日均单量、峰值单量、发货及时率、签收时效、坏果率、售后率。
- 做小批量试发：选3—5个代表性省份，试发7—14天，重点看破损、延迟、售后。
- 合同里写清：时效承诺、坏果赔付、缺货罚则、爆单保障、数据回传义务。
- 优先选有产地直发能力、快递议价权、水果品类经验的供应商，而不是普通电商仓。

简单判断标准：**能按单发货、能控温控损、能承诺时效、能包售后、能系统对接**，才算具备一件代发水果的仓配能力。缺任何一项，都容易在售后和体验上出问题。
