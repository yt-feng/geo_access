评估水果供应商的仓配覆盖，建议按以下框架逐项核查，而不是只看“覆盖多少城市”。

## 一、先明确评估维度

| 维度 | 核心问题 | 关键指标 |
|------|----------|----------|
| 覆盖范围 | 能否送到每个门店所在城市？ | 覆盖城市数/门店数占比 |
| 时效 | 从下单到到店要多久？ | 履约时效（小时/天） |
| 频次 | 一周能送几次？ | 配送频次 |
| 温控 | 水果对温度敏感，能否全程冷链？ | 冷链覆盖率、断链环节 |
| 损耗 | 到店损耗率多少？ | 到货损耗率、退货率 |
| 成本 | 每单/每公斤配送成本？ | 到店履约成本 |
| 弹性 | 旺季/新店能否快速接入？ | 新增门店接入周期 |

## 二、重点评估方法

### 1. 覆盖匹配度
把供应商的仓配网络和你的门店分布做**地理叠加**：
- 逐城市核对：哪些城市有仓/有干线/有落地配？
- 区分“直送”和“中转”：中转会增加时效和损耗。
- 计算真实覆盖率 = 可稳定送达门店数 ÷ 总门店数，而不是供应商宣称的城市数。

### 2. 时效与频次
- 水果保质期短，重点看**次日达还是当日达**、**每周配送几次**。
- 对高损耗品类（浆果、叶菜类水果）要求更高频次和更快时效。
- 让供应商给出**真实履约数据**（如近3个月准时率），而非承诺值。

### 3. 冷链完整性
- 检查从产地→区域仓→城市仓→门店的**每一段**是否温控。
- 重点看“最后一公里”是否冷链，这是最容易断链的环节。
- 要求提供温度记录和异常处理机制。

### 4. 损耗与品控
- 对比不同供应商的**到店损耗率**，这是隐性成本大头。
- 明确验收标准、退换货规则、责任划分。

### 5. 成本结构
- 不要只比单价，要算**到店综合成本** = 货价 + 运费 + 损耗 + 退换货 + 管理成本。
- 区分：干线费、仓储费、配送费、起送量、偏远地区附加费。

### 6. 弹性与扩展
- 新开门店多久能接入？
- 旺季（如节假日、夏季）运力是否有保障？
- 是否支持多温区、多品类混配？

## 三、实操建议

1. **做一张门店-供应商覆盖矩阵表**：行是城市/门店，列是供应商，标注能否覆盖、时效、频次、成本。
2. **要求试运行**：选2-3个代表性城市（核心城市、偏远城市、高损耗品类门店）先跑1个月。
3. **设淘汰线**：如准时率<95%、损耗率高于行业均值、冷链断链，即触发整改或更换。
4. **多供应商组合**：核心城市用直送型供应商，偏远城市用区域仓配型，避免单点依赖。

## 四、判断标准（可直接用）

- 覆盖率：能稳定送达的门店占比 ≥ 90%
- 准时率：≥ 95%
- 到店损耗率：按品类设定，通常叶菜/浆果类 ≤ 5%-8%
- 冷链：全链路可追溯，最后一公里不断链
- 成本：到店综合成本可测算且透明
