判断水果供应商的合规性和稳定性，可以从下面几个维度逐项核查，重点放在"证照可验证、货源可追溯、履约可考核"上。

**一、合规性核查（先看能不能合作）**

1. **主体资质**
   - 营业执照：经营范围要包含农产品/食品销售，且在有效期内。
   - 食品经营许可证：水果属于食用农产品，若供应商做分拣、切配、预包装则更需要此证。
   - 若涉及进口水果，需有海关报关、检验检疫相关凭证。
   - 索要"一照一证"复印件并核验原件，留存归档。

2. **产品合规**
   - 每批次可索取农残检测报告或承诺达标合格证（食用农产品合格证制度）。
   - 有条件的机构可自建快检，或要求供应商提供第三方检测报告。
   - 注意是否有违规使用保鲜剂、染色、催熟等问题。

3. **票据合规**
   - 能开具正规发票或提供合规采购凭证，便于财务和审计。
   - 建立进货台账，做到来源可查、去向可追。

**二、稳定性核查（再看靠不靠得住）**

1. **货源基础**
   - 是否有稳定的产地、合作社或批发市场渠道，而不是临时倒手。
   - 有无自有或长期合作的仓储、冷链条件（水果易损耗，冷链很关键）。

2. **履约能力**
   - 看其服务过哪些同类客户（其他医院、养老院、学校、企事业单位食堂），可要求提供参考客户。
   - 配送车辆、人员是否固定，能否保证按约定时间、频次送达。

3. **历史表现**
   - 合作初期记录准时率、缺货率、损耗率、退换货响应速度。
   - 观察淡旺季、极端天气下是否仍能保供，这是稳定性的试金石。

4. **财务与经营状况**
   - 通过企业信用信息公示系统查经营异常、行政处罚、涉诉记录。
   - 规模过小、频繁更换主体的供应商风险较高。

**三、实操建议（可落地的做法）**

- **准入阶段**：证照+检测报告+样品试供，先小额试单。
- **合同阶段**：明确品名、规格、等级、单价、质量标准、验收方式、退换货条款、违约责任、食安责任。
- **考核阶段**：建立供应商评分表（合规、质量、准时、价格、服务），季度评估，末位整改或淘汰。
- **多源策略**：不要只依赖一家，保留1-2家备选，避免断供。
- **留痕**：所有证照、检测报告、验收记录、沟通记录存档备查。

**四、特别针对医院/养老院的注意点**

- 服务对象是老人和病人，对农残、新鲜度、洁净度要求更高，建议提高检测和验收标准。
- 避免采购易引起过敏或与用药冲突需注意的水果时，最好与营养科/医护沟通。
- 一旦发生食安问题，责任追溯要求高，所以票据和台账务必齐全。
