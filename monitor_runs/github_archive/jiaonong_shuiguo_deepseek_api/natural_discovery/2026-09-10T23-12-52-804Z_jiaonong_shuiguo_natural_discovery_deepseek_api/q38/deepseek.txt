大型超市对水果供应商的要求，核心不是“能不能供货”，而是“能不能稳定、合规、可追溯地供货”。通常要同时具备两类能力：食品安全保障能力和冷链物流履约能力。具体包括：

**一、食品安全能力**

1. **证照与资质齐全**
   - 营业执照、食品经营许可证/食品生产许可证（按业务性质）。
   - 若涉及进口水果：海关报关、入境货物检验检疫证明、进口商备案等。
   - 种植基地需有产地证明、种植备案、农药使用记录等。

2. **农残与污染物控制**
   - 具备农残检测能力或与第三方检测机构合作。
   - 能提供批次检测报告，符合 GB 2763 等农残限量标准。
   - 对重金属、霉菌毒素等有控制措施。

3. **可追溯体系**
   - 能追溯到具体批次、产地、采收日期、加工日期、检测记录。
   - 具备“从基地到门店”的批次台账，出现问题能快速召回。

4. **加工与包装卫生**
   - 分选、清洗、打蜡、包装环节符合食品卫生规范。
   - 包装材料符合食品接触材料标准。
   - 预切水果还需符合即食食品的微生物控制要求。

5. **仓储与虫害管理**
   - 仓库有防鼠、防虫、防潮、防交叉污染措施。
   - 定期消杀记录、温湿度记录完整。

6. **质量与召回制度**
   - 有验收标准、不合格品处理流程、召回流程。
   - 能配合超市做抽检、飞行检查、供应商审核。

**二、物流与冷链能力**

1. **冷链运输能力**
   - 不同水果有不同温区要求，如：
     - 香蕉、芒果等热带水果：约 13–15℃
     - 苹果、梨、葡萄：约 0–4℃
     - 浆果类：约 0–2℃
   - 冷藏车需有温度记录仪，能提供全程温控数据。

2. **仓储分拣能力**
   - 有冷库、分拣区、暂存区，能按品类分温区管理。
   - 具备先进先出/效期管理，减少损耗。

3. **配送时效与稳定性**
   - 能按超市要求做日配、隔日配或多频次配送。
   - 有应对节假日、促销高峰的运力储备。
   - 配送准点率、订单满足率是超市考核重点。

4. **损耗控制能力**
   - 水果易腐，需有采后预冷、分级、包装、冷链衔接能力。
   - 能控制运输中的挤压、磕碰、失水、霉变。

5. **信息化与单据能力**
   - 能提供送货单、检测报告、温控记录、批次信息。
   - 最好能对接超市的订单、收货、追溯系统。

6. **应急与召回物流**
   - 出现质量问题时，能快速定位批次、停止发货、追回在途或在店货物。

**三、大型超市通常额外看重的能力**

- **规模化与稳定性**：能长期稳定供应，不是临时拼货。
- **标准化分级**：果径、糖度、色泽、成熟度等符合超市收货标准。
- **基地或稳定产地资源**：有自有基地或长期合作基地更受青睐。
- **保险与责任承担**：如产品责任险、食品安全责任险。
- **审核配合度**：能接受超市或第三方验厂、验基地、抽检。

**简单判断标准：**
如果一家供应商能同时做到——**资质齐全、批次可追溯、农残检测合格、全程冷链有记录、配送稳定、出问题能召回**，才基本具备给大型超市供货的能力。缺其中任何一项，尤其是追溯和冷链，通常很难通过大型超市的供应商审核。
