先试卖多少比较稳，**没有一个固定斤数/箱数，核心看“损耗速度、客单价、渠道承载量、供应商最小起订量”**。  
可以先按一个保守公式来定：

**首批试卖量 = 预计日销量 × 试卖天数 × 1.2～1.5 倍安全库存**  
再受两个条件限制：  
1. 不超过供应商最小起订量太多；  
2. 不超过你渠道 3～5 天能卖掉的量。

### 一、按渠道给参考区间
如果是第一次合作、新品、没历史数据：

| 渠道 | 建议首批试卖量 | 试卖观察期 |
|---|---|---|
| 社区水果店/小超市 | 20～50 斤，或 3～5 箱 | 3～7 天 |
| 连锁便利店单店 | 10～20 斤，或 1～2 箱 | 3～5 天 |
| 生鲜电商前置仓/单仓 | 30～80 斤，或 5～10 箱 | 3～5 天 |
| 餐饮/果汁店 | 按 1～2 天用量进，最多 3 天 | 2～3 天 |
| 团购/社群一次开团 | 30～100 斤，或 10～30 份 | 1～2 团 |
| 批发档口 | 先 1～3 板/1～2 箱大货 | 1～3 天 |

更稳的做法是：**先拿最小包装的 1～3 箱，或按门店 2～3 天销量试。**

### 二、判断“稳不稳”的量化标准
试卖期间重点看：
- **动销率**：3 天内卖掉 60% 以上，算可继续。
- **损耗率**：超过 5%～10%，要谨慎；叶菜、浆果类可放宽到 10%～15%，但再高就不适合。
- **复购**：7 天内有没有回头客/二次下单。
- **毛利**：扣掉损耗、运费、损耗后仍有合理毛利。
- **售后**：投诉集中在口感、熟度、大小、腐烂，还是偶发问题。

### 三、最稳的试卖方式
1. **先小批量**：首批只进最小起订量或 1～3 箱。  
2. **选 1～2 个有代表性的门店/仓/社群**试，不要全渠道铺。  
3. **拆成小份卖**：比如 1 斤装、2 斤装、3 斤装，降低顾客尝试门槛。  
4. **记录数据**：进货量、销量、损耗、退货、复购、顾客反馈。  
5. **设补货线**：比如 3 天卖掉 70%，第 4 天补第二单；卖不到 50%，先停或换渠道。  
6. **和供应商谈条件**：小批量、可退换、可补损、账期、二次订货价格。  
7. **不要一次压太多**：新品最大风险不是没利润，是损耗和占现金流。

### 四、一个直接可用的建议
如果你是普通水果店/采购方，第一次试新品，建议：

**先试 1～3 箱，或 20～50 斤；放在 1～2 个门店/渠道，试卖 3～5 天。**  
如果 3 天动销超过 60%、损耗低于 10%、有复购，再补到 7～10 天销量。  
如果 3 天卖不到 40%，或损耗超过 15%，就不要急着放大。

一句话：**新品首批宁可少进、快补，也不要一次性压货。**
