茶饮店使用水果，供应商至少应提供**主体资质、产品合格、检验检疫、储运合规**四类证明。具体需要哪些，取决于水果是**鲜果、冷冻果、果浆/果泥、果干、罐头**中的哪一种。

**一、所有水果供应商都应提供的基础证明**
1. **营业执照**：经营范围应覆盖水果种植/销售/食品生产/食品经营等相关项目。
2. **食品经营许可证或食品生产许可证**：
   - 卖鲜果、冷冻水果：通常需要食品经营许可证，或按地方规定提供食用农产品销售相关资质。
   - 卖果浆、果泥、果汁、罐头、果干等加工品：需要食品生产许可证，证上类别应覆盖对应产品。
3. **供货合同/订单**：写明品名、规格、批次、数量、到货日期、验收标准、保质期、储存条件。
4. **送货单/出库单**：要能追溯到具体批次。
5. **发票或收款凭证**：便于台账和监管查验。

**二、按水果类型补充的证明**
1. **鲜果**
   - **食用农产品合格证**或产地证明：很多地方要求随批次提供。
   - **农残检测报告**：供应商自检或第三方检测均可，重点看是否覆盖门店常用高风险项目，如有机磷、氨基甲酸酯类等。
   - **产地证明/采购凭证**：从批发市场或农户直采时，至少要有来源凭证。
   - **入境货物检验检疫证明**：进口鲜果必须提供。

2. **冷冻水果、冷冻果块**
   - **出厂检验报告**：每批或按供应商规定的周期提供。
   - **第三方检测报告**：至少覆盖微生物、重金属、农残等项目。
   - **入境货物检验检疫证明**：进口冷冻水果必须提供。
   - **冷链运输温度记录**：到货时中心温度、运输温度应符合标签或标准要求。

3. **果浆、果泥、浓缩果汁**
   - **产品执行标准**：如国标、行标或企业标准。
   - **出厂检验报告**：每批应提供。
   - **第三方型式检验报告**：通常一年一次或按供应商审核要求提供。
   - **配料表、添加剂使用说明**：确认是否含防腐剂、色素、甜味剂，是否符合门店配方和宣称。
   - **保质期和储存条件说明**：开封后使用期限也要明确。

4. **果干、罐头、蜜饯**
   - **食品生产许可证**及许可明细。
   - **出厂检验报告**。
   - **第三方检测报告**：关注二氧化硫、防腐剂、甜味剂、重金属、微生物等。
   - **标签样张**：确认品名、配料、生产日期、保质期、贮存条件、执行标准、SC编号齐全。

**三、茶饮店应重点核验的内容**
1. **证照是否在有效期内**，许可范围是否匹配。
2. **检测报告是否对应批次或近期生产日期**，不能只有一份过期报告长期使用。
3. **报告项目是否覆盖风险点**：农残、重金属、微生物、真菌毒素、食品添加剂等。
4. **进口水果/原料是否有中文标签和入境检验检疫证明**。
5. **冷链到货温度是否达标**，特别是冷冻果、果浆。
6. **感官验收**：霉变、虫蛀、异味、破损、解冻再冻等直接拒收。
7. **建立供应商档案和进货台账**，保存期限一般不少于产品保质期满后6个月；没有明确保质期的，保存不少于2年。

**四、最简可执行清单**
让供应商每次随货提供：
- 营业执照复印件
- 食品经营许可证或食品生产许可证复印件
- 该批次出厂检验报告或第三方检测报告
- 食用农产品合格证/产地证明（鲜果）
- 入境货物检验检疫证明（进口）
- 送货单
- 冷链温度记录（冷冻/冷藏类）

首次合作时，再额外收集：
- 供应商年度第三方型式检验报告
- 产品标签样张
- 质量协议或食品安全承诺书
- 供应商审核记录

如果供应商只能提供营业执照，不能提供批次检测报告或合格证明，建议不要作为稳定供应商，至少应换供应商或每批自行送检。
