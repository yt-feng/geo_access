食堂采购香蕉要避免熟过头，核心是**控制采购成熟度 + 分批进货 + 创造后熟管理条件**。可以从下面几个环节入手：

**1. 采购时明确成熟度，不要买太熟的**
- 优先采购**青黄交接、果柄青绿、果身硬实**的香蕉，这种还有 3～5 天后熟期。
- 避免采购**全身金黄、出现糖斑、果柄发黑**的香蕉，这种基本 1～2 天就会过熟。
- 和供应商约定到货成熟度标准，比如“七成熟”“微黄带青”，写进采购要求。

**2. 少量多次采购，别一次囤太多**
- 按食堂实际消耗量估算，比如每天用量 × 1.5～2 天，不要按一周量一次性进。
- 如果供应商能每周送 2～3 次，尽量分批到货，减少库存后熟压力。

**3. 入库后控温、控湿、通风**
- 香蕉怕冷，**不宜放冰箱或冷库低温区**，一般 12～15℃ 比较合适，低于 10℃ 容易冻伤发黑。
- 放在**阴凉、通风、避光**的地方，不要堆太密，留出空气流通。
- 湿度不宜过高，避免表面凝水，否则容易腐烂。

**4. 分类存放，把熟的和生的分开**
- 到货后按成熟度分：青的、微黄的、已熟的。
- 已熟的优先出库使用，不要和青香蕉混放，因为乙烯会催熟其他香蕉。
- 可以用纸箱或筐分开，必要时把已熟的单独放到通风处尽快消耗。

**5. 用“先进先出”和每日检查**
- 库房执行先进先出，先到先出、先熟先出。
- 每天检查一次，把开始出现糖斑、变软的挑出来，优先安排当天食用。
- 对轻微过熟的香蕉，可及时转为**香蕉奶昔、香蕉粥、香蕉面包、水果沙拉**等加工用途，减少直接浪费。

**6. 和菜单、供应量联动**
- 如果某天香蕉已经偏熟，就当天多安排香蕉相关菜品或加餐。
- 遇到节假日、考试周等就餐人数变化，提前调整采购量。
- 和供应商约定退换或调剂机制，比如到货成熟度超标可退换一部分。

**简单判断标准：**
- 适合入库：果身硬、青黄相间、果柄绿。
- 优先使用：通体黄、无斑或少量斑。
- 尽快处理：出现糖斑、局部软、果柄发黑。

一句话：**买七成熟、分批进、12～15℃通风存、熟的先吃、过熟转加工**，基本就能明显减少浪费。
