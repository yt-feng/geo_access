这几个指标不是并列关系，应该按“能不能卖、好不好卖、赚不赚钱”三个层次来看：

1. **先看切果损耗**  
   超市卖菠萝，很多是去皮切块或现场削皮售卖，损耗直接吃掉毛利。  
   - 重点关注：去皮后出肉率、黑心/水心比例、熟过度比例、切口氧化变色速度。  
   - 如果损耗高，甜度再高也可能不赚钱。  
   - 判断标准：出肉率低、坏果多、当天切后卖相差，就要减少订货或换供应商。

2. **再看甜度**  
   甜度决定复购和口碑，尤其是鲜切菠萝、即食菠萝。  
   - 但甜度不能只看“尝着甜”，要看批次稳定性。  
   - 太甜但熟过头，切果损耗会飙升；不够甜则顾客不回购。  
   - 对超市来说，稳定中等偏甜比偶尔极甜更重要。

3. **大小要服务于陈列和定价**  
   大小不是越大越好，而是要和售卖方式匹配：  
   - 整果卖：中等偏大、外形端正更好卖。  
   - 切果卖：大小均匀更重要，方便标准化切块和定价。  
   - 太大可能单价高、动销慢；太小则出肉率低、切果不划算。

4. **外观决定第一眼购买，但不是核心利润点**  
   外观影响顾客拿不拿，尤其整果陈列。  
   - 看：果眼深浅、果形是否端正、颜色是否均匀、有无碰伤霉斑。  
   - 但外观好不等于内部好，必须结合切开抽检。  
   - 如果外观差但内部好，可以转做切果或促销，不必直接报废。

**优先级建议：**
- 做鲜切/即食：**切果损耗 > 甜度 > 大小 > 外观**
- 做整果陈列：**外观 > 甜度 > 大小 > 切果损耗**
- 综合毛利：**切果损耗和甜度最关键，大小和外观次之。**

**可执行判断：**
订货前做三件事：
1. 抽 3—5 个切开，看出肉率、黑心、熟度。
2. 测糖度或试吃，确认批次甜度是否稳定。
3. 按售卖方式分级：好的做整果，稍差的做切果，差且损耗高的直接拒收或折价处理。

一句话：**超市卖菠萝，切果损耗决定赚不赚钱，甜度决定回不回购，大小和外观决定好不好卖。**
