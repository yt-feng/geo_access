小面积便利店做水果，核心原则是：**少品类、小批量、快周转**。

**一、品类控制**

1. **只做3-5个核心单品**
   - 选高频刚需：香蕉、苹果、橙子/砂糖橘、圣女果、葡萄（季节性强）。
   - 避免同时上超过6个SKU，货架和冷柜都撑不住。

2. **按季节轮换，不全年铺满**
   - 夏季：西瓜切盒、葡萄、桃子、李子。
   - 冬季：砂糖橘、苹果、橙子、梨。
   - 每季主推2-3个，其余做补充。

3. **优先选耐放、易处理的品类**
   - 香蕉、苹果、橙子损耗低、无需冷藏。
   - 草莓、蓝莓、切果损耗高，除非客流稳定，否则少碰。

4. **按消费场景选品**
   - 上班族：即食小份、切盒、单根香蕉。
   - 家庭客：小份装、2-3个苹果一袋。
   - 不做大份量，避免顾客买不完、门店卖不掉。

**二、损耗控制**

1. **小批量高频补货**
   - 每次进货量控制在1-2天销量，宁可缺货也别压货。
   - 香蕉、葡萄等易损品每天补，苹果橙子可2-3天补一次。

2. **设定安全库存**
   - 按前7天日均销量×1.2-1.5倍作为单次进货上限。
   - 新品先试1-2箱，卖得动再追加。

3. **分级陈列与定价**
   - 好果正常价，轻微瑕疵果及时打折或做切盒。
   - 切盒当天必须售完，隔夜直接报损，不二次销售。

4. **温控和陈列**
   - 香蕉、芒果常温避风；葡萄、圣女果、切盒冷藏。
   - 不要堆叠过厚，底部容易压伤。
   - 先进先出，新货放后面。

5. **每天两次巡检**
   - 早上开店、下午高峰前各查一次，挑出软伤果。
   - 发现熟过头的立即降价或加工，不等烂掉。

6. **建立简单台账**
   - 记录每天进货量、销量、报损量。
   - 连续3天报损高的单品，直接砍掉或减量。

**三、实操建议**

- 起步阶段：先做香蕉+苹果+橙子+1个季节单品，共4个SKU。
- 进货：找本地批发市场或生鲜供应链，少量多批，别一次囤。
- 定价：毛利定在25%-35%，损耗高的品类可到40%。
- 止损线：单品日损耗超过进货量10%，连续一周就淘汰。

一句话总结：**面积小就做“少而精、快进快出”，用销量数据决定留哪些、进多少，不靠感觉囤货。**
