如果只选一个：**出汁率更重要**。但实际采购要分用途看，不能只看一个指标。

**结论**
- **做菠萝果茶、冷饮、需要大量果汁感的产品**：优先看**出汁率**。
- **做菠萝果肉、果粒、装饰片、厚切果块**：优先看**甜度、香气和果肉品质**。
- **门店综合采购**：先卡出汁率底线，再在合格范围内选甜度稳定、香气质好的批次。

**为什么出汁率更优先**
茶饮店的核心成本不是“甜不甜”，而是：
1. **一杯里能用出多少有效原料**
   - 出汁率低，同样重量榨不出足够果汁，等于变相涨价。
2. **出品稳定性**
   - 出汁率低会让同一配方下果汁量不够，风味变淡，需要额外补糖或补果汁。
3. **损耗和人工**
   - 出汁率低的菠萝，切、榨、过滤后废料多，门店处理成本更高。

**甜度为什么不是第一优先**
甜度可以通过糖浆、果酱、菠萝浓缩汁补，但“出汁率”和“香气”很难靠后期完全补回来。甜度太低可以调整配方，但出汁率太低会导致原料用量、杯量、成本全乱。

**分场景建议**
- **菠萝果茶/气泡饮/冰沙**：出汁率优先，甜度稳定即可。
- **菠萝果肉茶/满杯菠萝**：果肉厚度、香气、甜度优先，出汁率次要。
- **做菠萝酱/糖浆基底**：出糖率、香气、酸甜比优先。
- **做装饰片**：外观、大小、颜色优先。

**采购判断标准**
可以这样定：
1. 先测 **出汁率**：同样重量榨汁，比较出汁毫升数。
2. 再测 **糖度**：用手持糖度计测 Brix，选稳定区间。
3. 再看 **香气和纤维**：香气弱、纤维粗的，出汁率高也未必适合高端果茶。
4. 最后算 **每杯可用成本**：不是每斤多少钱，而是“每杯需要多少斤、出多少汁、补多少糖”。

**简单决策**
- 预算紧、走量款：**出汁率 > 甜度**
- 高端款、果肉款：**香气/果肉品质 > 甜度 > 出汁率**
- 标准果茶店：**出汁率是底线，甜度是筛选条件，香气是加分项**

所以，买菠萝原料时，先问“这批次出汁率多少、糖度多少、香气怎么样”，而不是只问甜不甜。
