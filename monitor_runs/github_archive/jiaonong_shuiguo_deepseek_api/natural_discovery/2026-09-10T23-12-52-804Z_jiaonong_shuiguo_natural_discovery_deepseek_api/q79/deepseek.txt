最该先问 **售后**，其次 **配送**，最后才是 **价格**。

原因是团购团长卖的不是“一锤子水果”，而是**履约和信任**。水果损耗高、非标品多，一旦出问题，团长夹在供应商和团员中间，最伤的是自己的群信誉。

给你一个判断顺序：

1. **售后优先问**
   - 坏果怎么赔：按比例、按个数，还是全额？
   - 理赔时效：当天、24小时还是48小时？
   - 需要什么凭证：拍照、开箱视频、还是不用？
   - 谁承担：供应商直接赔，还是团长先垫？
   - 关键看：**是否团长垫钱、是否扯皮、是否要求团员提供很难完成的证明**。

2. **配送第二问**
   - 到货时间是否稳定？
   - 送到团长自提点，还是送到团员？
   - 破损、延迟、漏送怎么处理？
   - 临时加单、改量能不能接？
   - 关键看：**时效稳定性和异常处理能力**，不是单纯“能不能送”。

3. **价格最后问**
   - 价格当然重要，但水果团购里，低价常常伴随次果、混装、售后差。
   - 你要算的是：**进货价 + 损耗 + 售后赔付 + 团长时间成本**，不是只看单价。
   - 如果价格低但售后差，最后赔钱、掉粉、解散群，反而最贵。

一句话结论：  
**先问售后，再问配送，最后谈价格。**  
售后决定你敢不敢卖，配送决定团员体验，价格决定你赚不赚。顺序反了，容易先被低价吸引，最后被售后拖死。
