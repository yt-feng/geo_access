结论先说：**绝大多数甜品店，直接买成品果丁的“损耗率”更低；但损耗低不等于成本低，关键看你的用量、品控要求和人工成本。**

### 1. 损耗对比

**鲜果切配**
- 菠萝本身损耗高：
  - 去皮、去眼、去芯后，出肉率通常只有 **40%～60%**
  - 也就是买10斤鲜果，最后可能只剩4～6斤可用果肉
- 切配后还有：
  - 氧化、出水、变色
  - 冷藏保存时间短
  - 切多了卖不完只能报废
- 人工损耗也高：
  - 削皮、切丁耗时
  - 员工操作不稳定，大小不一、报废多

**成品果丁**
- 到手就是可用果肉，基本没有前处理损耗
- 损耗主要来自：
  - 开封后用不完
  - 冷藏过期
  - 解冻/沥水不当
- 但整体报废率通常明显低于鲜果现切

### 2. 什么时候成品果丁更划算

适合选成品果丁的情况：
- 日均用量稳定，但单次用量不大
- 店里人手紧，没时间削菠萝
- 对果丁大小、成熟度、出品稳定性要求高
- 不想承担鲜果挑果、催熟、切配的麻烦

这时成品果丁虽然单价高，但**综合损耗、人工、时间、品控成本**往往更低。

### 3. 什么时候鲜果切配更划算

适合鲜果切配的情况：
- 菠萝用量很大，每天能稳定消耗
- 有专人负责切配，人工不算额外成本
- 对“现切新鲜感”有明确卖点
- 能拿到很便宜、品质稳定的鲜果货源
- 有办法把边角料再利用，比如做菠萝酱、菠萝汁、装饰

这种情况下，鲜果切配的**单位成本**可能更低，但损耗和管理难度更高。

### 4. 直接判断标准

你可以用这个公式算：

**鲜果实际可用成本 = 鲜果采购价 ÷ 出肉率 + 人工成本 + 报废成本**

**成品果丁实际成本 = 成品单价 + 开封后报废成本**

举例：
- 鲜菠萝 4元/斤，出肉率50%，则果肉成本约 **8元/斤**
- 再加削皮切丁人工、报废，实际可能到 **10～12元/斤**
- 如果成品果丁低于这个综合成本，就选成品

### 5. 建议

- **用量小、人手少、品控要求高：买成品果丁。**
- **用量大、有人工、鲜果便宜且稳定：鲜果切配。**
- **最稳的做法：**
  - 主推产品用成品果丁保稳定
  - 特色款或高毛利款用鲜切菠萝做卖点
  - 分别记录1～2周的实际出成率、报废量和人工耗时，再决定主采购方式

简单说：**损耗上成品果丁更低；成本上要看你的规模和人工。**
