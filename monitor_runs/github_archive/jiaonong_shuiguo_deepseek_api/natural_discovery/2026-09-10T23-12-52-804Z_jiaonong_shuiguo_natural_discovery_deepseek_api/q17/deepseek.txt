控制水果新鲜度和库存，核心是两件事：**按销量订货、按成熟度卖货**。下面给你一套可直接执行的做法。

**1. 先定“订货量”，不要凭感觉**
- 连续记录 7~14 天：每个单品每天卖了多少、剩了多少、扔了多少。
- 订货公式用：  
  **明日订货量 ≈ 近 3 天平均销量 × 调整系数 − 现有库存**  
  天气热、周末、节假日可上调 10%~30%；雨天、工作日下调 10%~20%。
- 新手先做“少量多次”：宁愿下午补一次，也不要早上压一堆。

**2. 按水果类型分库存策略**
- **高损耗、快熟型**：草莓、蓝莓、香蕉、葡萄、桃、荔枝、芒果。  
  少量勤进，当天主推，隔夜就做特价或果切。
- **中损耗型**：苹果、橙子、梨、火龙果、猕猴桃。  
  可备 2~3 天量，但先进先出。
- **耐放型**：柚子、甘蔗、菠萝、部分瓜类。  
  可适当多备，但也要看季节和客流。

**3. 用“先进先出 + 分级销售”**
- 新货放里面/下面，旧货放外面/上面，避免旧货被压住。
- 每天分三档：
  - 好货：正常价，摆主位。
  - 轻微瑕疵：降价区、果切、拼盘。
  - 快坏：立刻做特价、员工内购或联系周边餐饮/果汁店。
- 不要等烂了再处理，水果一旦明显软化、出水、发霉，基本只能报损。

**4. 控制陈列量，不要堆太满**
- 陈列量按“半天到一天销量”放，卖完再补。
- 堆头太大看着热闹，但底层容易被压坏，也增加损耗。
- 易损水果用小筐、浅盘，减少翻动。

**5. 每天固定动作**
- 早上：检查到货，挑出压伤、过熟，先上旧货。
- 中午：看动销，卖得慢的提前调价或换位置。
- 傍晚：对快过夜的水果做组合促销、果切或特价。
- 闭店前：记录销量、损耗、库存，作为明天订货依据。

**6. 设几个简单预警线**
- 单品库存超过 2 天销量：停止补货，先促销。
- 损耗率连续 3 天超过 5%~8%：说明订货偏多或品类不对。
- 某单品连续 3 天卖不动：下架或减少订货，换品试销。

**7. 和供应商谈“小批量、多频次”**
- 尽量每日或隔日配送，减少一次压货。
- 能退换的品类优先合作，尤其是高损耗水果。
- 如果必须整箱进，先拆箱分装，按成熟度分开卖。

**8. 最实用的一个原则**
**“今天能卖完的，才是好库存；卖不完的，都是成本。”**  
所以宁可缺货补货，也不要为了看起来丰富而大量压货。先抓 3~5 个主力单品做数据，跑顺后再扩品。
