小商家采购水果时，现金结算和月结账期各有利弊，风险点也不同：

**现金结算的风险**
1. **资金占用压力大**：每次进货都要当场付钱，现金流紧张，尤其旺季囤货时容易周转不开。
2. **采购量受限**：手头现金不够就只能少进货，可能错过低价大批量采购的机会。
3. **安全与对账风险**：现金携带、保管有丢失被盗风险；如果没有正规票据，事后对账、维权困难。
4. **税务与凭证问题**：现金交易常缺正规发票，后续成本核算、税务处理容易出问题。

**月结账期的风险**
1. **供应商信任门槛**：新商家或小商家往往拿不到账期，或账期很短（如7天、15天），议价能力弱。
2. **隐性成本高**：账期价格通常比现金价高，相当于变相支付了“利息”，实际采购成本上升。
3. **容易过度采购**：因为不用当场付钱，容易多进货，导致水果损耗、滞销，最后反而亏钱。
4. **逾期风险与信用受损**：一旦回款慢、忘记付款，可能被停供、加收滞纳金，甚至影响行业口碑。
5. **依赖单一供应商**：长期月结容易绑定一家，若对方断供或涨价，切换成本高。
6. **账目混乱**：多笔月结叠加，若没做好台账，容易漏付、重复付或算不清真实成本。

**实用建议**
- **小额、高频、易损耗的品类**：优先现金或短账期，避免压货。
- **大额、耐储存、走量品类**：可谈月结，但要把账期价格和现金价对比，算清真实成本。
- **无论哪种方式，都要留凭证**：送货单、对账单、转账记录、发票尽量齐全。
- **控制账期额度**：月结金额不要超过自己可承受的现金流范围，建议设置上限。
- **分散供应商**：不要只依赖一家，现金和账期混合使用，降低断供风险。

简单说：现金结算风险在“现金流和凭证”，月结风险在“成本和信用”。小商家最好根据品类周转速度、自身现金流和供应商关系，混合使用两种方式，而不是一刀切。
