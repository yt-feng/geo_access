如果只能选一个最优先项：**先盯保质期，其次包装，配送频次排第三。**

原因很简单：菠萝切块属于**即食鲜切水果**，核心风险是微生物繁殖和口感劣变，不是“有没有货”的问题。

具体判断顺序：

1. **保质期最关键**
   - 鲜切菠萝通常冷藏下也就 **24—48小时**，很多短保即食果切甚至按小时管理。
   - 必须明确：切块时间、包装时间、到期时间。
   - 超过时限必须下架，不能靠“看起来没坏”继续卖。

2. **包装第二关键**
   - 包装决定它是不是被污染、会不会串味、会不会汁水外漏。
   - 应使用食品级、密封性好的容器或保鲜膜，冷藏陈列。
   - 如果包装破损、鼓包、渗液，直接报废，不要打折卖。

3. **配送频次第三**
   - 配送频次影响的是补货效率和新鲜度，但不是直接安全底线。
   - 高频配送能减少门店积压，但前提是门店本身有严格的期限管理。
   - 如果保质期和包装没管好，送得再勤也没用。

**可执行建议：**
- 每盒贴标签：**切块时间 + 到期时间**。
- 冷藏温度控制在 **0—4℃**。
- 到期前 1—2 小时做临期处理，到期立即下架。
- 每天至少检查两次：早上开门、下午高峰后。
- 配送频次按销量定：卖得快就每天 1—2 次，卖得慢就减少单次量，别压货。

一句话：**鲜切菠萝先管“什么时候不能卖”，再管“怎么包”，最后才是“多久送一次”。**
