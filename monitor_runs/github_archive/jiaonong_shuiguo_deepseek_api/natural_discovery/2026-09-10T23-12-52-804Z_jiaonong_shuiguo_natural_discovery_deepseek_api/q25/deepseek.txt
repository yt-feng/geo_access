多店、单店量小，核心矛盾是：**总采购量有议价空间，但履约成本高、损耗难控**。适合的供货模式取决于你的门店密度、配送能力和水果品类结构。

## 优先推荐：区域批发市场 + 集中分拣

如果门店在同一城市或周边，这是最现实的起步模式：

- **采购**：由总部或指定人员在当地一级批发市场集中采购，拿到比单店自采更低的价格
- **分拣**：设一个小型周转仓，按各店预估销量分装
- **配送**：每天或隔天用一辆车跑一圈门店

优点：灵活、门槛低、现金结算、品类可随时调整。缺点是价格仍受批发市场波动影响，品质稳定性一般。

**判断标准**：门店数量在 5–30 家、同城或邻近城市、日配送可达，这个模式最划算。

## 进阶选择：产地/基地直采 + 区域配送中心

当总采购量稳定到一定程度（比如单品类日采购 500 公斤以上），可以跳过批发市场：

- 直接对接产地合作社或大型种植基地
- 签订短期协议锁定价格和品质标准
- 用区域配送中心统一收货、分拣、配送

适合：有稳定销量预测能力、能承受一定账期和起订量、有冷链或常温仓储。

**注意**：单店量小意味着你必须靠“总仓集单”来凑量，否则产地不会给你好价格。

## 另一种思路：平台化供货 / 代采分账

如果不想自建采购和配送，可以考虑：

- 找本地生鲜供应链平台或 B2B 食材平台，按门店下单、平台配送到店
- 或与同区域其他非竞争超市联合集采，共享配送

优点：轻资产、省人力。缺点：毛利被平台吃掉一部分，品类和价格受制于人。

## 按品类拆开看

不同水果适合不同模式：

| 品类 | 适合模式 |
|------|----------|
| 苹果、梨、橙等耐储 | 产地直采或大批发，一次进多店分摊 |
| 香蕉、芒果等催熟类 | 找专业催熟商，按周配送 |
| 草莓、樱桃、蓝莓等 | 本地近郊基地或批发市场日配，控损耗 |
| 进口果 | 港口一级进口商或区域代理，按柜期集单 |

## 关键动作建议

1. **先算总仓集单能力**：把各店同品类需求合并，看能否达到供应商起订量
2. **测试 1–2 个核心单品直采**：不要全品类一起换，先跑通一个品
3. **建损耗核算**：单店量小，损耗率每高 1 个点就可能吃掉直采省下的钱
4. **配送频次匹配销量**：叶菜类水果日配，耐储类 2–3 天配一次
5. **保留批发市场作为补充渠道**：直采不能覆盖的临时缺货、小批量品类，仍走市场

## 一句话结论

**同城多店小量，优先“批发市场集中采购 + 自建周转仓分拣配送”；总量稳定后再对核心单品做产地直采；不想重资产就接本地供应链平台。** 关键不是找最便宜的货源，而是让“集单—分拣—配送—损耗”这条链路跑得过来。
