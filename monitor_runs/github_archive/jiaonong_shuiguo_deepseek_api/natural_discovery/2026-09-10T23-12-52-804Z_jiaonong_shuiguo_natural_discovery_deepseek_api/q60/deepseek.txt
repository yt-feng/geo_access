核心原则：**把“补货”约定成对供应商有硬约束、对门店有兜底的动作，而不是一句口头承诺。**否则水果坏了、缺货，营业照样受影响。

可以从下面几个层面去约定：

**1. 验收环节就锁定责任**
- 到货当场验：品种、数量、成熟度、有无腐烂/压伤/异味，拍照或录像留证。
- 验收单上写明：不合格品项、数量、批次、到货时间，双方签字确认。
- 约定验收标准，比如“腐烂率超过X%”“成熟度不符合约定”即整批或部分拒收。

**2. 补货时限要具体到小时，不要写“尽快”**
- 区分两类：
  - **影响出品的急用果**：约定当日几小时内补到，比如“验收后4小时内送达门店”。
  - **可暂缓的果**：约定次日营业前送达，比如“次日9:00前”。
- 写明“补货到店时间以门店签收为准”，避免供应商用发货时间糊弄。

**3. 补货方式要给门店选择权**
- 优先原品项补足；若原品项无货，允许**等价替换**或**按缺货金额退款/抵扣**。
- 约定门店有权选择：补货、换货、退款、抵扣下批货款，而不是只能等供应商安排。

**4. 用钱做担保，别只靠信任**
- 约定**质量保证金**或**账期扣款**：不合格批次对应货款暂不结算，补货合格后再结。
- 约定**违约金**：超时未补货，按缺货金额的X%或固定金额赔付。
- 若因缺货导致门店停售某产品，可约定赔偿该产品当日毛利损失，至少覆盖原料成本。

**5. 给门店留“自救”空间**
- 约定紧急情况下门店可**自行采购替代**，差价由供应商承担，凭票结算。
- 或者约定供应商授权门店从指定备选渠道调货，费用从货款扣。

**6. 把长期约束写进合同**
- 设定**月度/季度不合格率上限**，超过则降价、扣款或终止合作。
- 约定**累计几次超时补货**，门店可单方解除合同并要求赔偿。
- 所有补货记录、验收单、聊天记录都保留，作为对账和追责依据。

**一句话模板：**
“验收不合格的果品，供应商须在X小时内补足合格品到店；逾期按缺货金额X%赔付，门店有权自行采购、差价由供应商承担，并从当期货款中扣除。”

这样约定，才能让补货真正兜住营业，而不是出了问题再扯皮。
