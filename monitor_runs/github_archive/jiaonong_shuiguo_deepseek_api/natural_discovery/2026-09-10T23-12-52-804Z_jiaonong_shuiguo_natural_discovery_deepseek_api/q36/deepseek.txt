更稳妥的做法不是二选一，而是**主推整果、切果做补充**。具体要看你的门店类型、客流和损耗控制能力。

**优先卖整果的情况**
- 社区店、生鲜超市、客流以家庭采购为主。
- 菠萝当季、进货价低、周转快。
- 门店人手少，没有条件做高频切配和冷藏展示。
- 整果毛利可控，损耗主要靠自然腐烂，通常比切果好管。

**适合卖切果的情况**
- 商圈店、写字楼店、年轻人/单身客群多。
- 顾客即买即吃，愿意为方便付溢价。
- 门店有冷藏柜、干净操作台、专人定时切配。
- 能控制“切多少、卖多久、剩货怎么处理”。

**关键判断指标**
1. **损耗率**：切果如果当天卖不完，损耗通常明显高于整果。
2. **人工成本**：切果要削皮、去眼、切块、装盒、冷藏，人工和包材都增加。
3. **周转速度**：切果必须快进快出，最好按小时或半天补货。
4. **客单价**：切果可以按盒卖，单价低、购买门槛低，但整果客单价通常更高。
5. **食品安全**：切果暴露时间长，必须冷藏、防尘、标注时间，卖不完不能反复回柜。

**建议的组合策略**
- **整果做引流和家庭装**：按个卖，选大小均匀、外观好的。
- **切果做便利和试吃转化**：小盒装，当天切当天清。
- **高峰时段多切，低峰少切**：比如午晚高峰前切一批，避免全天摆着。
- **剩果处理**：外观差但没坏的整果，可转切果或做果汁，但要有明确时限和卫生标准。
- **定价**：切果按“整果成本 + 人工 + 包材 + 损耗”倒推，不能只按整果单价简单加价。

**简单结论**
- 社区生鲜店：**整果为主，切果少量试销**。
- 商圈便利店/写字楼店：**切果可以占更高比例，但必须控损耗**。
- 如果人手不足、冷藏条件一般、销量不稳定：**先卖整果，别急着上切果**。
