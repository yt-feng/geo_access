和一些水果品牌方谈代理，最怕的是问得太笼统，对方随口承诺，后面出问题没有依据。核心是把“区域保护”和“串货”拆成可验证、可写进合同的具体问题。

**一、先问清品牌方自己的渠道结构**

在问保护之前，先搞明白它现在怎么卖货。这决定了你的“独家”到底含金量多少：

- 这个品牌目前在本区域有没有代理？有几个？是独家还是多家？
- 品牌方自己有没有直营、电商、直播带货、社区团购？这些渠道算不算你的区域？
- 线上订单发到你的区域，算不算串货？怎么处理？
- 有没有给大型商超、连锁渠道直供？这些算不算例外？

这些不问清，后面的“独家”可能是假的。

**二、区域保护要问到具体颗粒度**

不要只问“有没有区域保护”，要逼出具体条款：

- 保护范围是省、市还是区县？边界怎么定义？
- 保护期内品牌方承诺不再发展第二家吗？如果是多家，怎么划分？
- 保护有没有期限？到期后怎么续？续的条件是什么？
- 如果品牌方自己要进你的区域开直营或做活动，提前多久通知？你有没有优先权？
- 保护是不是和你的进货量、销售额挂钩？达不到会被取消吗？标准是多少？

**三、串货问题要问到“怎么认定、怎么罚、怎么赔”**

串货条款最容易写成空话。要问：

- 串货的认定标准是什么？是跨区域销售就算，还是低价倾销才算？
- 谁来查？品牌方有没有稽查机制？你举报后多久响应？
- 查到串货方，品牌方怎么处罚？罚款、断货、取消代理？
- 你的损失怎么赔？是品牌方赔，还是从串货方保证金里扣？
- 如果串货来自品牌方自己的线上渠道，怎么处理？这条最容易被回避。
- 你有没有权拒绝给串货方供货？品牌方支不支持？

**四、必须落到合同里的几件事**

口头承诺没用，签之前确认这些写进合同：

- 区域范围（最好附地图或明确边界）
- 独家/非独家，以及例外渠道清单
- 串货认定标准和处罚机制
- 品牌方直营、电商、直播的边界
- 保护期限和续约条件
- 达不到销量时的处理方式，别让对方单方面取消

**五、谈判时的几个判断**

- 如果品牌方对“电商算不算串货”含糊其辞，大概率后面会出问题。
- 如果保护条款和进货量强挂钩，要算清自己能不能做到，别为了拿独家签个做不到的量。
- 如果品牌方说“我们从不串货”，但不肯写进合同，等于没说。
- 串货处罚如果只罚串货方、不赔你，你的实际损失还是自己扛。

一句话：把“保护”拆成范围、期限、例外、违约四件事，把“串货”拆成认定、稽查、处罚、赔偿四件事，每件都要有具体答案，能写进合同的才作数。
