优先关注**成熟度**，价格其次。原因是：香蕉在烘焙里的作用不只是“提供香蕉味”，还影响**甜度、湿度、香气、组织结构和上色**。成熟度不对，配方再便宜也容易做不出稳定产品。

可以按用途判断：

- **做香蕉蛋糕/香蕉磅蛋糕/香蕉马芬**：最适合用**熟到表皮出现黑点、果肉软但没坏**的香蕉。  
  这种香蕉淀粉已大量转成糖，甜度高、香气足、保湿性好，成品更湿润、颜色更漂亮。
- **如果香蕉还偏硬、发青**：  
  不是不能用，但需要额外熟化或调整配方。直接做会导致香气弱、甜度低、口感偏干，还可能带涩味。
- **如果已经过熟、发黑、有酒味或酸味**：  
  不适合直接做对外售卖的蛋糕，容易发苦、发酵味重，也可能影响食品安全和出品稳定性。

采购建议：

1. **先定用途，再定成熟度。**
   - 当天/次日做：买黑点熟蕉。
   - 计划囤货：买七到八成熟，回店后常温催熟。
   - 需要长期稳定：可考虑冷冻香蕉泥，但要注意解冻出水，配方需调整。

2. **价格只有在成熟度合适时才值得考虑。**
   - 便宜但太生：要花时间催熟，占用库存和空间。
   - 便宜但过熟：损耗高，风味和食品安全风险大。
   - 熟度刚好但略贵：通常更省事、更稳定，反而综合成本更低。

3. **看综合成本，不只看单价。**
   包括：催熟时间、损耗率、是否需要加糖/加香精/加油弥补、报废风险、顾客复购。

4. **建立店内标准。**
   比如：
   - 香蕉蛋糕专用：表皮 50% 以上出现黑点，果肉软糯，无酒酸味。
   - 到货验收：青蕉比例、黑点比例、压伤比例分开记录。
   - 催熟：常温避压，必要时和苹果一起放，加快成熟。

简单结论：  
**做香蕉蛋糕，成熟度是第一位，价格是第二位。**  
最理想的是买“熟度合适、价格合理”的香蕉；如果只能二选一，选熟度合适的。
