如果目标是“家庭自己吃”的水果礼盒，组合原则不是好看优先，而是：**耐放、好分食、口味有层次、成本不虚高**。  
苹果、橙子、香蕉、菠萝这4样里，香蕉和菠萝最容易出问题，所以不建议平均搭配。

**更推荐的家庭组合：**

1. **苹果 + 橙子 + 香蕉**
   - 适合：大多数家庭日常吃。
   - 比例建议：苹果40%、橙子35%、香蕉25%。
   - 优点：苹果耐放，橙子解腻，香蕉方便老人小孩吃。
   - 注意：香蕉成熟快，团购时最好选稍青一点的，并提醒用户先吃香蕉。

2. **苹果 + 橙子 + 菠萝**
   - 适合：家里人喜欢酸甜口、能接受切菠萝。
   - 比例建议：苹果40%、橙子35%、菠萝25%。
   - 优点：耐放性比带香蕉好，礼盒看起来也更像“礼盒”。
   - 注意：菠萝要削皮切块，家庭如果嫌麻烦，复购会差。

3. **苹果 + 橙子 + 香蕉 + 菠萝**
   - 适合：想显得丰富、但不想做高端礼盒。
   - 比例建议：苹果35%、橙子30%、香蕉20%、菠萝15%。
   - 优点：品类全，视觉丰富。
   - 缺点：香蕉和菠萝会拉低整体耐放性，投诉风险更高。

**不太建议的组合：**

- **香蕉 + 菠萝为主**：成熟快、易压伤、菠萝处理麻烦，家庭体验不稳定。
- **四样完全平均**：看起来公平，实际香蕉和菠萝占比过高，容易坏，苹果橙子反而被浪费。
- **只做苹果 + 香蕉**：太单调，橙子的清爽感没有，礼盒价值感弱。

**如果按家庭人数选：**

- **2-3人家庭**：苹果4个、橙子4个、香蕉1把、菠萝半个或小菠萝1个。
- **4-5人家庭**：苹果6个、橙子6个、香蕉1把、菠萝1个。
- **5人以上家庭**：苹果8个、橙子8个、香蕉1-2把、菠萝1个。

**团购实操建议：**

- 主推款选：**苹果 + 橙子 + 香蕉**，最好卖，家庭接受度高。
- 升级款选：**苹果 + 橙子 + 菠萝**，适合送礼或喜欢酸甜口的人。
- 四样混合款可以做，但香蕉和菠萝比例别超过35%，否则售后多。
- 包装上标注“建议先吃香蕉，菠萝切开后冷藏”，能明显减少差评。

一句话：**家庭吃优先选“苹果+橙子+香蕉”，想耐放好看选“苹果+橙子+菠萝”，四样都放可以，但香蕉菠萝要少。**
