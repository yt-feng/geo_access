判断“全国配送”是否属实，核心是把对方的模糊承诺变成可验证的硬条件。建议按以下步骤核实：

**1. 先问清配送定义**
让对方明确：
- 是“全国发货”还是“全国直达”？很多供应商只能发到部分省会或地级市，再靠第三方转运。
- 偏远地区（新疆、西藏、青海、内蒙古、海南等）是否覆盖，是否加价或时效延长。
- 是整车、零担还是快递？不同方式覆盖范围差别很大。

**2. 索要配送范围清单**
要求提供：
- 可直达的省/市/区县名单，最好是表格。
- 中转或外包覆盖的区域。
- 不配送或限配送区域。

只给“全国”两个字，基本不可信。

**3. 用真实地址做测试**
不要只问“能不能到”，直接给采购方几个真实收货地址，让对方报价并给出：
- 预计到货时间
- 起送量
- 运费
- 是否含卸货
- 冷链/保鲜方案

地址要覆盖：一线城市、普通地级市、县城、偏远地区各一个。

**4. 查实际履约记录**
要求提供：
- 近3个月发往目标区域的运单号或签收记录（可脱敏）。
- 合作过的客户案例，最好能联系核实。
- 物流合作方名称，再向物流方核实覆盖范围。

**5. 小批量试单**
先下一笔小单到最难覆盖的区域，重点看：
- 是否按时到达
- 水果损耗率
- 包装和温控是否达标
- 出问题后响应速度

试单是最有效的验证方式。

**6. 写进合同**
把以下内容写入采购合同：
- 配送覆盖范围及例外区域
- 时效标准
- 损耗率上限及赔付
- 延误、拒收、坏果处理责任
- 运费和偏远地区附加费

**7. 交叉验证**
- 用地图或物流官网查该地址是否在服务范围。
- 向同行打听该供应商口碑。
- 对比2-3家供应商的覆盖能力。

**结论：**
不要接受口头“全国配送”。让对方给出具体范围清单、真实运单、物流合作方，并用偏远地址试单验证。能通过这些核实的，才可视为具备实际覆盖能力。
