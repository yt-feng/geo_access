连锁超市和水果供应商签年度合同，最容易踩坑的地方通常不在“价格”本身，而在价格机制、损耗归属、验收标准、账期和返利这几个环节。下面按风险从高到低说，并给出可执行的条款建议。

**1. 价格条款：别只写一个固定价**
水果价格波动大，固定年价对一方必然不利，最后容易演变成扯皮或断供。
- 建议写成“基准价+调价机制”：约定每周或每旬参照某批发市场行情/指数调价，并写明调价触发幅度（如波动超5%启动）。
- 同时约定**价格保护**：供应商在合同期内给其他同级客户的供货价不得低于给本超市的价，否则补差。
- 坑点：只写“随行就市”等于没写，必须落到具体参照物、频率、确认方式。

**2. 损耗与退换：最容易亏钱的地方**
水果到店后烂损，责任划分不清是重灾区。
- 明确**验收时点**：到仓验收还是到店验收，谁承担卸货前损耗。
- 约定**损耗率上限**：如单批次损耗超X%，超出部分由供应商承担或补货。
- 区分“质量问题”和“超市保管不当”：前者供应商负责，后者超市自担。
- 坑点：口头约定“有问题就退”，但没有退换时限、凭证要求，供应商可拒认。

**3. 质量标准与验收：不能只写“新鲜”**
“新鲜”“优质”无法执行。
- 用可量化标准：品种、规格（单果克重/直径）、糖度、色泽、成熟度、农残检测要求。
- 附**验收标准附件**，并约定抽检比例、不合格判定和整批处置方式。
- 坑点：验收标准写得太宽，收货时超市没依据扣款；写得太严，供应商频繁拒供。

**4. 账期与结算：现金流风险**
- 明确账期天数、起算点（收货日/对账日/开票日），避免“月结”这种模糊表述。
- 约定对账周期和逾期付款、逾期交货的违约责任，双向对等。
- 坑点：账期过长叠加水果高损耗，供应商会变相加价或降低品质。

**5. 返利与费用：隐藏成本**
- 年度返利、进场费、促销费、损耗补贴等要写清计算基数（含税/不含税、按进货额还是销售额）和结算时间。
- 坑点：返利基数含糊，年底对不上账；费用名目多但没写进合同，事后被追缴。

**6. 供货保障与违约**
- 约定最低供货量、缺货处理、替代品种，以及断供的违约金。
- 反向也要约定超市的最低采购量，否则供应商可能要求赔偿。
- 坑点：只约束供应商不约束自己，合同可能被认定显失公平。

**7. 不可抗力与季节性**
- 明确极端天气、疫情、运输管制下的处理：是顺延、调价还是免责。
- 水果有季节性，约定不同季节的品种和供货计划，别用一份清单管全年。

**8. 终止与退出**
- 约定提前解约条件、库存处理、尾款结算和返利清算。
- 坑点：没有退出机制，合作恶化后货压在超市、款压在供应商。

**一句话总结**：把“价格怎么调、损耗谁承担、质量怎么验、账期怎么算、返利怎么结”这五件事写死，基本就避开了水果年度合同的主要坑。签约前最好让采购、财务、门店运营三方一起过一遍验收和结算条款。
