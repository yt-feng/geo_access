生鲜水果到货后出现坏果，责任划分通常要结合**坏果发生的时间点、原因、平台规则和证据**来判断。可以按下面几个层面处理：

**1. 先看坏果是什么原因造成的**
- **运输/配送过程中造成**：比如挤压、磕碰、冷链断链、配送延误导致腐烂。通常由商家或平台承担责任，因为消费者收到时已经不符合“完好交付”要求。
- **采摘、分拣、包装时 already 有问题**：比如发霉、烂心、成熟度过高，属于商品本身质量问题，商家责任。
- **顾客收货后存放不当**：比如高温放置、未冷藏、几天后才取件，导致变质，一般顾客责任，但商家如果能证明交付时是好的，可减轻或免除责任。
- **自然成熟/后熟现象**：有些水果到货后需要放几天才熟，若只是未熟、口感偏酸，不算坏果；但如果是腐烂、发霉、流汁，通常算质量问题。
- **不可抗力或异常天气**：如极端高温导致短时间内腐烂，平台一般仍会倾向保护消费者，但商家可据此与平台协商责任分担。

**2. 按交易关系看责任主体**
- **平台自营**：平台直接承担售后责任。
- **第三方商家发货**：商家是第一责任方，平台通常承担连带管理责任或先行赔付责任，具体看平台规则。
- **平台配送/第三方配送**：如果是配送环节导致损坏，商家赔付消费者后，可向配送方追偿。
- **团长/社区团购**：要看是团长仅代收，还是参与分拣、存放。若因团长存放不当导致坏果，团长可能承担相应责任。

**3. 常见责任划分比例**
没有统一法定比例，实务中常见：
- 签收后短时间内发现坏果，且能提供开箱视频/照片：商家通常全额或按坏果比例赔付。
- 坏果比例较小，比如一箱里坏几个：按比例退款或补发。
- 坏果比例较大、影响食用：全额退款或重新发货。
- 顾客延迟取件、存放不当：顾客承担部分或全部责任。
- 生鲜类通常不支持“七天无理由”，但质量问题仍可要求售后。

**4. 消费者维权时建议这样做**
- 收货后尽快开箱，拍**完整开箱视频**，展示快递单、包装、坏果整体和细节。
- 保留坏果，不要马上扔，必要时按平台要求拍照或视频验证。
- 在平台售后时效内申请，生鲜一般要求**24小时内**或按平台规定。
- 先找商家/平台客服，要求按坏果比例退款、补发或全额赔。
- 协商不成，可向平台投诉、向12315投诉，或根据金额考虑诉讼。

**5. 商家/平台处理时建议这样划分**
- 先判断是“个别坏果”还是“批量腐烂”。
- 个别坏果：按比例赔付，通常商家承担。
- 批量腐烂且配送时效正常：查冷链和包装，商家或配送方承担。
- 配送延误导致：配送方承担，商家可追偿。
- 顾客自身原因：可拒绝全额赔付，但要有签收时间、配送记录、沟通记录等证据。

**简单结论：**
- 到货就坏、开箱就有烂：一般商家/平台责任。
- 配送挤压、延误、冷链问题：商家先赔，再向配送方追偿。
- 顾客放坏了：顾客责任。
- 无法判断时：平台通常倾向消费者，按坏果比例赔付。
