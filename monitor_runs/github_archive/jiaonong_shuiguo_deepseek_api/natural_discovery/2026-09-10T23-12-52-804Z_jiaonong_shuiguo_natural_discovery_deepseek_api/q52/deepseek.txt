要避免香蕉到店后很快变黑，核心是控制**成熟度、温度、乙烯和机械损伤**。采购时按下面做最有效：

1. **买“偏生一点”的香蕉**
   - 选果皮整体偏绿、尖端微黄、没有黑斑的。
   - 如果预计 1–2 天用完，可以买“黄中带一点绿”的；如果当天用，才买全黄。
   - 不要买已经出现梅花点、黑斑、柄部发黑的，到店后基本很快继续黑。

2. **看果柄和切口**
   - 果柄青绿、切口新鲜、不发黑不发霉的更好。
   - 果柄已经干缩、发黑，说明采摘后放久了，后熟会更快。

3. **摸硬度**
   - 手感硬实、有弹性的耐放。
   - 已经明显发软、局部塌陷的不要，说明过熟或压伤，会从伤处开始黑。

4. **避免买“催得太狠”的货**
   - 如果整箱已经统一全黄、香味很浓、箱内发热，通常后熟已经启动，到店后黑得快。
   - 优先选成熟度参差不大、但整体偏生的货。

5. **运输和到店后别闷、别压、别冻**
   - 香蕉怕压，装箱不要堆太高，避免重物压。
   - 到店后立刻拆箱透气，不要长时间闷在塑料袋或密闭箱里。
   - 不要放冷藏，除非是做香蕉泥/冷冻用途；冷藏会冻伤，果皮更快变黑。
   - 放在阴凉、通风、约 13–18℃ 的地方最合适。

6. **远离乙烯来源**
   - 不要和苹果、梨、番茄、牛油果等释放乙烯较多的水果放在一起。
   - 如果店里同时有这些，香蕉要单独分区。

7. **按用量分批采购**
   - 甜品店最好“少量多次”，不要一次囤太多。
   - 采购量按 1–2 天用量算，比一次买一周更不容易黑。

8. **到店后处理**
   - 先挑出有压伤、裂口、发软的，优先使用。
   - 需要延缓后熟时，可把香蕉一根根分开，减少互相催熟。
   - 如果已经较黄但还没黑，可以适当降低环境温度，但不要低于 12℃ 左右。

简单判断标准：  
**买偏绿、硬实、柄青、无压伤、无黑斑的；到店后拆箱、通风、阴凉、别压、别冷藏、远离苹果梨番茄。**  
这样通常能明显延缓变黑。
