建议先做 **菠萝（或菠萝类如金钻凤梨）**，而不是香蕉、苹果。

原因按“稳定性 + 进口水果定位 + 超市可操作性”排序：

1. **香蕉：不建议作为进口水果切入点**
   - 国内香蕉供应量大、价格透明，消费者对“进口香蕉”感知弱。
   - 进口香蕉多为大品牌供应链，超市很难做出差异化。
   - 香蕉损耗、催熟、温控要求高，做不好反而亏。
   - 结论：适合作为基础品，不适合作为“进口水果引入”的突破口。

2. **苹果：不建议优先**
   - 国产苹果已经很强，进口苹果如新西兰爱妃、美国蛇果等有认知，但价格高、动销慢。
   - 消费者容易拿国产苹果比价，毛利和周转都容易被压。
   - 进口苹果季节性强，稳定全年供应不如菠萝可控。
   - 结论：可以做补充单品，不适合打头阵。

3. **菠萝/凤梨：更适合先试**
   - 进口凤梨如菲律宾、泰国、台湾地区产等有稳定供应链，全年相对可操作。
   - 消费者对“凤梨/菠萝”有进口认知，愿意为口感、甜度、免削皮等卖点买单。
   - 单价适中，试错成本低于进口苹果，高于香蕉但可控。
   - 可做试吃、切果、组合装，容易拉动复购。
   - 注意：菠萝也有损耗和成熟度问题，但比香蕉催熟简单，比苹果比价压力小。

**执行建议：**
- 先小批量试销 **进口凤梨**，选1—2个产地/品牌，做试吃和切果。
- 观察2—4周：动销率、损耗率、毛利、复购。
- 如果动销稳定，再引入 **进口苹果** 做高客单补充。
- 香蕉继续做国产或常规供应链，不纳入“进口水果突破”的首选。

一句话：**先菠萝/凤梨，再苹果，香蕉放最后。**
