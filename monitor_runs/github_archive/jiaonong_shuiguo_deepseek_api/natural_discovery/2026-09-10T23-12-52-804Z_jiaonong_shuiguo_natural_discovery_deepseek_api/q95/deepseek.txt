选学校食堂水果供应商，核心不是选“最便宜”，而是选“稳定、安全、可追溯、能按量按时送”。可以按下面这套标准来筛。

**1. 先定采购标准**
- 品类：香蕉、苹果、橙子这类大宗常见水果，优先选本地或周边大型批发市场、产地合作社、连锁配送商。
- 等级：按食堂用途定，比如苹果要脆甜耐放，香蕉要适合当天或次日食用，橙子要易剥、酸甜适中。
- 规格：按个数、重量、箱规统一，避免“今天大明天小”。
- 成熟度：香蕉不能太生也不能太熟，苹果、橙子要耐储存。
- 安全：农药残留检测、新鲜度、无腐烂、无严重磕碰。

**2. 供应商来源优先级**
1. 学校所在区县教育局或后勤统一招标的供应商；
2. 本地大型农批市场里有固定档口、能开票、有配送能力的商户；
3. 产地合作社或水果基地直供；
4. 连锁生鲜配送企业；
5. 个体批发商只作为补充，不建议单独长期依赖。

**3. 必须核验的资质**
- 营业执照；
- 食品经营许可证或相关流通许可；
- 水果农残检测报告或承诺达标合格证；
- 配送车辆和仓储卫生条件；
- 能否开具正规发票；
- 有没有学校、医院、企事业单位食堂配送经验。

**4. 重点看配送能力**
- 能不能每天或按约定频次准时送；
- 临时加单、换货、补货响应多快；
- 是否有冷藏或通风配送条件；
- 坏果、烂果怎么退换；
- 下雨、节假日、疫情等特殊情况能否保供。

**5. 比价不要只看单价**
建议用“综合到货价”比较：
- 单价；
- 损耗率；
- 退换货比例；
- 配送费；
- 账期；
- 开票成本；
- 人工挑拣成本。

比如便宜10%，但损耗20%，实际更贵。

**6. 建议的筛选流程**
1. 列3—5家候选供应商；
2. 要报价单和资质；
3. 小批量试供1—2周；
4. 每天记录到货重量、坏果率、口感、配送准时率；
5. 让食堂管理员、库管、厨师一起打分；
6. 选2家为主、1家备用，避免单一供应商断供。

**7. 合同里要写清**
- 品种、规格、等级、单价或调价机制；
- 送货时间、地点、频次；
- 质量标准；
- 退换货规则；
- 食品安全责任；
- 结算方式和账期；
- 违约和退出机制。

**8. 简单评分表**
可以按100分打分：
- 食品安全与资质：25分；
- 价格与成本：20分；
- 品质稳定：20分；
- 配送准时与应急：15分；
- 售后退换：10分；
- 开票与结算：10分。

总分高且试供稳定的，再签长期合同。

**结论：**
学校食堂选水果供应商，优先选有资质、能开票、配送稳定、可退换、有学校配送经验的本地供应商。先小批量试供，再按食品安全、品质、价格、配送、售后综合评分，最后采用“主供应商+备用供应商”模式，不要只图低价。
