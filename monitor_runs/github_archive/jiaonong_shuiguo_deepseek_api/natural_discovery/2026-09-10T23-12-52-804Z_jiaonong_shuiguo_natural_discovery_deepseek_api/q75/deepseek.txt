和小批量试单的核心目标不是“赚钱”或“压价”，而是**用最低成本验证供应商是否可靠、货是否匹配你的销售渠道**。所以设计思路要围绕“用可控的损失换真实信息”来做。

下面按可执行顺序给你一套方案。

## 一、先明确试单要验证什么

试单前先写下你真正要判断的点，避免只凭感觉：

1. **品质稳定性**：同一批次内是否有明显大小/成熟度/瑕疵差异
2. **规格一致性**：承诺的果径、等级、糖度、净重是否达标
3. **包装与损耗**：运输后压伤、烂果率、保鲜情况
4. **供货能力**：能否按约定时间、数量发出
5. **配合度**：出现问题时的响应速度和承担意愿
6. **结算与单据**：发票、磅单、质检记录是否规范
7. **价格结构**：报价是否含包装、运费、税费，是否有隐藏费用

把这些变成一张验收表，收货当天逐项打分。

## 二、试单规模怎么定

原则：**够验证问题，但亏了不伤筋动骨。**

- 金额上建议控制在你能承受“全损也不影响经营”的范围内，通常是单次进货预算的一小部分。
- 数量上要满足两个条件：
  - 能覆盖你目标渠道的一个最小销售单元（比如一个档口几天、一个线上链接一批、给几个老客户分）
  - 能暴露出批次内差异（太少看不出稳定性，比如只有一两箱，问题可能被偶然性掩盖）
- 品类上优先选：
  - 你**有稳定下游需求**的品类，便于快速消化
  - **耐运输、损耗相对可控**的品类，先别一上来试最娇贵的

不要为了凑量而试你卖不动的品。卖不掉本身就是损失，还会干扰对供应商的判断。

## 三、合作条款要提前谈清

第一次合作，口头承诺风险高，至少用微信/合同留下文字记录：

1. **规格标准**：明确品种、等级、果径范围、糖度、成熟度、单箱净重/毛重
2. **价格与费用**：单价、包装费、运费、装卸费、税费谁承担
3. **交货**：时间、地点、运输方式、谁负责途中损耗
4. **验收**：到货后多久内可提异议，按什么标准判定不合格
5. **售后**：烂果、规格不符、短重怎么处理——补货、扣款还是退款
6. **结算**：现款、货到付款还是账期；试单阶段建议**货到验收后再结清或留少量尾款**
7. **样品确认**：最好让供应商先寄样或提供近期实拍/视频，留存作为对照

## 四、验收流程要标准化

收货当天做这几件事，最好拍照/录像留证：

1. **称重**：抽几箱称净重，看是否短重
2. **开箱抽检**：随机抽若干箱，检查大小、颜色、成熟度、伤痕、霉变
3. **测关键指标**：糖度、硬度等，如果你有工具
4. **统计损耗**：把明显不可售的挑出来，算损耗率
5. **记录时间**：从发货到收货用了多久，途中是否冷链

建议做一张简单表格，把“承诺值 / 实测值 / 是否合格”记下来。这样第二次谈价或换供应商时有依据。

## 五、怎么判断这批试单算成功

不要只看“有没有赚钱”，看这几个信号：

- 规格达标率是否在可接受范围
- 损耗率是否低于你渠道能承受的线
- 交货是否准时
- 出问题时对方是否愿意承担
- 下游客户反馈是否正常（有没有投诉口感、外观）

如果品质和配合度都行，再逐步加量；如果只是价格便宜但损耗高、售后差，不要因为单价低就继续。

## 六、常见坑

- **只看报价不看净重和等级**：低价可能是小果、次果或短重
- **一次试太多品类**：问题混在一起，分不清是供应商问题还是品类问题
- **没留证据**：到货发现烂果，对方不认，你没法追责
- **跳过样品直接发大货**：第一次合作尤其要留样品对照
- **把试单当压价工具**：过度压价会让对方用次货补利润，反而看不清真实水平

## 七、一个可直接套用的试单结构

- 选 1 个主推品类，1 个备选品类
- 每个品类发 1 个最小可行批量
- 约定明确规格和验收标准
- 到货当天完成抽检和记录
- 试单结束后给供应商打分，再决定是否二次合作、加量或换人
