三者不是并列取舍，而是有优先级和底线关系：**食品安全是底线，配送准时是保障，价格是优化目标**。

对企业食堂来说，建议按这个顺序判断：

1. **食品安全优先，且必须一票否决**
   水果通常是生食或简单清洗后食用，一旦农残超标、霉变、腐烂、运输过程污染，直接引发员工健康问题，甚至群体性事件。企业食堂还要承担留样、索证索票、供应商资质、检测报告等责任。  
   所以食品安全不合格的供应商，价格再低、送得再快也不能用。

2. **配送准时是硬约束**
   食堂供餐时间固定，水果如果迟到，会影响当天供餐、加餐或福利发放；如果为了不等而提前大量囤货，又会增加损耗和变质风险。  
   因此配送准时不是“最好有”，而是必须稳定达标，尤其是早餐、午餐、下午茶等有固定时间点的场景。

3. **价格重要，但应在前两者达标后比较**
   水果价格波动大，企业采购如果只压价，容易买到等级低、成熟度差、损耗高的货，最后综合成本反而更高。  
   更合理的做法是：在食品安全和配送稳定合格的前提下，比价、比损耗率、比结算周期、比售后赔付。

实操上可以这样定权重：

- **食品安全：准入项，不合格直接淘汰**
- **配送准时：准入门槛，比如迟到率、缺货率超过标准就扣款或淘汰**
- **价格：评分项，在合格供应商之间比综合成本**

一句话总结：  
**先保安全，再保准时，最后谈价格；安全不过关，一切归零。**
