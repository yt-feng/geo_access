判断超市采购的苹果和橙子规格是否适合门店销售，重点不是“越大越好”，而是看**目标客群、陈列方式、损耗、价格带和周转**。可以按下面几个维度直接判断。

## 1. 先按门店定位定规格

### 社区超市/生鲜店
适合：
- 苹果：单果 160–220g，直径约 70–80mm
- 橙子：单果 150–220g，直径约 65–80mm

原因：
- 家庭日常购买多，按斤买，单果太大单价高，顾客犹豫。
- 中等规格陈列饱满，损耗相对低。

### 中高端超市/精品超市
适合：
- 苹果：单果 200–280g，直径约 80–90mm
- 橙子：单果 200–300g，直径约 75–90mm

原因：
- 顾客更看重外观、口感、礼盒感。
- 可做精品陈列、按个卖或礼盒装。

### 便利店/小业态
适合：
- 苹果：单果 120–180g
- 橙子：单果 120–180g

原因：
- 多为即食、单人份，太大吃不完，太小显得品质差。
- 适合按个卖，价格最好控制在顾客容易决策的区间。

## 2. 用“直径+重量+个数/箱”三重判断

采购时不要只看“80果”“75果”这种叫法，因为不同产地、品种标准不一致。建议同时记录：

| 指标 | 苹果 | 橙子 |
|---|---|---|
| 单果重 | 称10个取平均 | 称10个取平均 |
| 横径 | 卡尺量最大横径 | 卡尺量最大横径 |
| 每箱个数 | 实际数 | 实际数 |
| 箱净重 | 去掉箱皮 | 去掉箱皮 |
| 大小均匀度 | 最大最小差 | 最大最小差 |

判断标准：
- 同一箱里最大和最小差距最好不超过 15–20%。
- 如果大小混得太厉害，不适合做标准陈列，只适合散卖或促销。
- 如果标注“80果”，但实际很多只有 70–75mm，说明供应商分级不严，要压价或换货。

## 3. 看门店销售方式

### 按斤散卖
适合：
- 中等规格
- 大小相对均匀
- 果面干净、无严重花皮

不适合：
- 特大果，因为单价高，顾客容易只挑不买。
- 太小果，因为顾客觉得不划算。

### 按个卖
适合：
- 大小非常均匀
- 单果重量稳定
- 外观好

比如：
- 苹果 180–220g，按个卖 3.99–5.99 元
- 橙子 180–250g，按个卖 3.99–6.99 元

如果大小不一，按个卖会引发顾客挑拣，最后剩下小果和差果。

### 礼盒/果篮
适合：
- 大果、均匀、颜色好、无瑕疵
- 苹果 80–90mm 以上
- 橙子 75–85mm 以上

但要注意：
- 礼盒果损耗和包装成本高。
- 如果门店礼盒销量不稳定，不要大量压货。

## 4. 看损耗和货架期

苹果相对耐放，橙子也较耐放，但仍要注意：

- 大果不一定更耐放，有时大果更容易碰伤。
- 果径过大，堆叠时容易滚落、压伤。
- 果径过小，顾客翻拣多，损耗反而高。
- 表皮薄、软果、粗皮果，不适合长期陈列。

建议采购时抽检：
1. 随机拿 20 个，称总重，算平均单果重。
2. 量最大和最小横径。
3. 看有没有软果、裂果、压伤、霉点。
4. 放 2–3 天观察失水、发软、腐烂情况。
5. 试卖一天，看顾客挑拣后剩下的是大果还是小果。

## 5. 用价格带反推规格

先定门店想卖的价格，再反推规格。

例如：
- 苹果想卖 5.99 元/斤，采购价最好控制在 3.5–4.2 元/斤。
- 如果果径 85mm 以上，采购价可能到 5 元/斤以上，零售价就要 8 元以上，社区店可能不好卖。
- 如果果径 65–70mm，采购价低，但顾客可能觉得小，复购差。

所以：
- 大众门店：优先 70–80mm 苹果、65–75mm 橙子。
- 精品门店：优先 80–90mm 苹果、75–85mm 橙子。
- 促销引流：可用 65–75mm 苹果、60–70mm 橙子，但必须价格明显低。

## 6. 最实用的现场判断法

采购时直接做这 5 步：

1. **问清楚品种、产地、分级标准。**
2. **随机抽 10–20 个称重、量直径。**
3. **看大小是否均匀，最大最小差是否超过 20%。**
4. **对照门店主力客群和计划售价。**
5. **先小批量试卖 1–2 天，看挑拣、损耗、动销。**

## 7. 简单结论

适合门店销售的规格，通常满足：

- 苹果：单果 160–220g，直径 70–80mm，大小均匀，果面干净。
- 橙子：单果 150–220g，直径 65–80mm，大小均匀，皮薄但不过软。
- 中高端店可上浮到苹果 80–90mm、橙子 75–85mm。
- 便利店适合小果，160–200g 左右，按个卖。
- 礼盒适合大果，但不要作为主力散卖规格。

核心判断标准不是“大不大”，而是：**目标顾客买得起、愿意复购、陈列好看、损耗可控、周转够快。**
