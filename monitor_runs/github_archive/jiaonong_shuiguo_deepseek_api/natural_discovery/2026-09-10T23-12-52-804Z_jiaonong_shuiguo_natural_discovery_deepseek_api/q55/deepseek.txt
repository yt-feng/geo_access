做水果拼盘时，三种水果的“划算”不只是单价低，而是**出成率、损耗、切配稳定性和视觉填充效果**的综合结果。下面按实操给你判断标准。

**1. 苹果**
- **选规格**：优先选 70–80mm 的中等果，不要盲目追大果。
- **原因**：大果单价常更高，但拼盘里苹果多用于切片、切块、做扇形，中等果切出来大小均匀，边角料少；太大反而单份用量不好控制。
- **划算判断**：看“每个能出几片/几块”。如果 80mm 果比 75mm 果贵 20%，但只多出 10% 果肉，就不划算。
- **品种建议**：选脆度高、切开后不易发绵的，如红富士、嘎啦等。拼盘里常用红富士，颜色和硬度都稳。

**2. 橙子**
- **选规格**：优先选 65–75mm 的中果，做瓣切或圆片都合适。
- **原因**：橙子太大，去皮去络后损耗不一定低，而且一片太大占盘；太小的橙子出瓣少、切出来碎。
- **划算判断**：重点算“去皮后净重”。橙子皮厚、白络多，采购时要问或试：同样 10 斤，哪种去皮后净肉多。
- **品种建议**：选皮薄、易剥、酸甜稳定的，如脐橙、血橙看菜单风格。做拼盘要颜色亮，脐橙通常更稳。

**3. 菠萝**
- **选规格**：优先选 1.2–1.5kg 左右的中等果，或者直接买去皮菠萝/菠萝块。
- **原因**：菠萝削皮、去眼、去芯损耗很大，人工也高。如果餐厅量大，直接买净果有时比买整果更划算。
- **划算判断**：整果要算“去皮去芯后净重”。一般整菠萝可食部分约 50%–60%，如果净果价格低于这个折算价，就买净果。
- **品种建议**：选成熟度一致、酸甜稳定的。拼盘用菠萝常切三角块或厚片，太生酸、太熟软都不好摆。

**通用采购原则**
- **按“净出成率”比价，不按毛重比价**：苹果看切片数，橙子看去皮净肉，菠萝看去皮去芯净重。
- **按拼盘份数反推采购量**：先定每份拼盘里三种水果各多少克，再算总需净重，最后加 10%–15% 损耗。
- **规格统一比大小更重要**：同一批水果大小一致，切出来才好看，也少浪费。
- **旺季买当地当季果**：同规格下，当季果通常更便宜、成熟度也更稳。
- **量大时考虑净果/冷冻果**：菠萝、橙子如果切配人工高，净果或冷冻块可能更划算，但要注意口感和出水。

**简单结论**
- 苹果：选 70–80mm 中果，看切片数和脆度。
- 橙子：选 65–75mm 中果，看去皮净肉和出瓣率。
- 菠萝：选 1.2–1.5kg 中果，或直接比净果价格；整果按 50%–60% 出成率折算。
- 最终标准：**同样净重下，谁的净出成率高、切配稳定、损耗低，谁就更划算。**
