连锁商超找长期水果供应商，招标评分标准的核心不是“谁报价低”，而是“谁能在全年稳定供货、质量可控、损耗可控、出问题能兜底”。建议把评分分成五块，权重可按你的品类结构微调。下面给一套可直接落地的框架。

## 一、建议权重框架

| 评分维度 | 建议权重 | 核心判断 |
|---|---:|---|
| 价格与成本 | 25%-35% | 不是最低价，而是综合到仓成本 |
| 质量与品控 | 20%-30% | 能否稳定达标、可追溯 |
| 供货与履约 | 20%-25% | 全年不断供、旺季保供、应急能力 |
| 供应链与产地能力 | 10%-15% | 是否真有货源，不是倒手贸易商 |
| 服务与商务配合 | 5%-10% | 退换货、账期、对接效率 |

如果你做的是高端精品超市，质量和产地权重上调；如果是社区平价商超，价格和履约权重上调。

## 二、各维度具体评分项

### 1. 价格与成本（25%-35%）
不要只评“报价最低”，要评“综合成本”。

- 报价合理性：对比市场行情、历史采购价、同行价。
- 到仓价：含运费、包装、卸货、损耗补偿后的实际单价。
- 价格调整机制：是否接受随行就市，是否有涨跌联动公式。
- 账期与结算：能否接受月结、45天、60天等。
- 损耗承担：运输损耗、到仓不合格损耗由谁承担。

评分示例：
- 报价最低且到仓价清晰：满分
- 报价中等但损耗自担、账期好：可高于最低价者
- 报价明显低于市场：要扣分或重点核查，防后期断供或降质

### 2. 质量与品控（20%-30%）
水果最怕“送样好、大货差”。

- 样品与大货一致性：是否有标准，是否接受盲检。
- 农残检测：能否每批次提供检测报告，或接受商超抽检。
- 分级标准：果径、糖度、成熟度、色泽、瑕疵率是否明确。
- 可追溯性：能否追溯到产地、批次、采摘时间。
- 不合格处理：扣款、退货、换货、赔偿机制是否接受。
- 历史质量数据：给其他商超供货的合格率、退货率。

建议设置硬门槛：
- 连续两批次不合格，暂停供货资格。
- 农残超标一次，直接终止合作并追责。

### 3. 供货与履约（20%-25%）
长期供应商最关键的是“稳定”。

- 全年供应能力：淡旺季是否都能供。
- 旺季保供方案：节假日、台风、高温、春节怎么保。
- 缺货赔付：约定缺货扣款或补货时限。
- 订单响应：下单后多少小时送达。
- 冷链能力：是否有冷链车、冷库、温控记录。
- 应急能力：突发断货时能否 24-48 小时补位。
- 履约历史：过去一年准时交付率、缺货率。

### 4. 供应链与产地能力（10%-15%）
判断他是真供应商还是中间商。

- 自有基地或合作基地：面积、产量、品种。
- 产地直采比例：越高越稳。
- 仓储加工能力：分拣、包装、预冷、冷藏。
- 多产地布局：能否分散天气和季节风险。
- 合作证明：产地合同、合作社协议、收购凭证。
- 抗风险能力：是否有农业保险、灾后恢复方案。

### 5. 服务与商务配合（5%-10%）
长期合作，配合度很重要。

- 专属对接人：是否有客服、品控、物流对接。
- 退换货响应：几小时内处理。
- 促销支持：能否配合商超做特价、堆头、爆品。
- 新品推荐：能否按季节推荐替代品。
- 数据配合：能否提供批次、检测、物流数据。
- 合同条款：是否接受违约责任、保密、廉洁条款。

## 三、建议设置硬性门槛

以下不满足直接废标，不进入打分：

1. 营业执照、食品经营许可证齐全。
2. 近两年无重大食品安全事故。
3. 能提供农残检测报告或接受第三方检测。
4. 有冷链或符合水果运输的保鲜能力。
5. 能接受商超的质量标准和退货条款。
6. 有稳定产地或一级批发渠道证明。
7. 能接受账期和结算方式。
8. 同意廉洁承诺和违约追责。

## 五、招标时最容易被忽略的三件事

1. **不要只让供应商送样品。**  
   要突击去产地、仓库、冷库看大货，样品和大货不一致的直接淘汰。

2. **不要只签一年。**  
   长期供应商建议 1+1 或 2 年框架，设季度考核，不合格可退出。

3. **不要只评单价。**  
   水果损耗率差 3%-5%，实际成本就差很多。要把损耗、退货、缺货、账期一起算。

## 六、最终建议

你可以把评分标准浓缩成一句话：

> **价格合理、质量稳定、全年不断供、出问题能赔、愿意长期配合。**

如果只能设三个最关键指标，就盯：
1. 到仓综合成本；
2. 大货质量合格率；
3. 旺季和应急保供能力。

这三项决定长期合作成败，其他都是辅助。
