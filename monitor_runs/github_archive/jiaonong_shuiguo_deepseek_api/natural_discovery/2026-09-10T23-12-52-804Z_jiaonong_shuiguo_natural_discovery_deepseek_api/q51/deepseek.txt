要固定，但不能只固定“产地”这一个维度，更稳妥的是固定“供应批次 + 验收标准 + 备选方案”。

**建议这样处理：**

1. **主供应产地/批次要固定**
   - 水果风味波动主要来自品种、成熟度、气候、采摘期、储运。
   - 固定产地和批次能减少今天酸、明天淡、后天香的问题。
   - 对茶饮店来说，稳定比“偶尔特别好喝”更重要。

2. **但不要只写“固定产地”**
   - 同一产地不同果园、不同采摘期、不同成熟度也会有差异。
   - 应固定：
     - 品种
     - 果园或供应商
     - 采摘成熟度
     - 加工/冷冻/冷链方式
     - 到店验收标准

3. **采购合同里加“风味验收标准”**
   - 糖度范围，例如 Brix 值
   - 酸度或酸甜比
   - 香气描述
   - 色泽
   - 出汁率/出肉率
   - 是否有发酵味、青味、苦味
   - 解冻后状态，如是否出水、发软、变味

4. **保留 1–2 个备选批次**
   - 主批次断货或品质下滑时，必须有替代方案。
   - 备选批次也要提前测试，不能临时换。
   - 换批次时先做小批量杯测，再逐步替换。

5. **门店操作上做“标准化补偿”**
   - 即使固定批次，季节尾期也可能波动。
   - 可以通过糖浆、果酱复配、酸甜微调、出品比例微调来稳定。
   - 但核心原料不要频繁换，否则顾客会觉得味道变了。

6. **最实用的采购策略**
   - 主供应商：固定产地 + 固定加工批次 + 年度框架协议。
   - 备选供应商：同品种、同规格、同验收标准。
   - 每批到货留样，做风味记录。
   - 一旦某批次连续 2–3 次不达标，就暂停并切换备选。

**结论：**
茶饮店采购水果，应该固定产地和供应批次，但真正要固定的是“稳定风味标准”。只固定产地不够，必须把批次、成熟度、加工方式和验收指标一起锁住，同时准备备选批次，才能既稳定又不断供。
