水果店遇到坏果，和供应商结算或赔付，通常先看**采购时有没有约定**，再看**坏果发生在哪个环节、比例多少、是否可归责于供应商**。实务上可以按下面几步处理。

## 1. 先看合同或订单约定
优先看有没有这些约定：

- 是否约定“到货验收标准”
- 是否约定“坏果率上限”，比如超过3%、5%可扣款或补货
- 是否约定“损耗承担方”
- 是否约定“账期结算”和“质量异议期”
- 是否约定“生鲜不退货”或“坏果包赔”

如果有明确约定，按约定执行。  
如果没有书面约定，就看行业惯例和双方长期交易习惯。

## 2. 分清坏果责任
常见分法：

- **运输前就坏**：供应商责任，可要求补货、扣款或赔付。
- **运输中损坏**：看谁负责运输。供应商包送到店，通常供应商先承担，再向物流追偿。
- **到店后因存放不当坏了**：一般水果店自己承担。
- **自然损耗、成熟过快**：看约定。生鲜允许一定损耗，但超过合理范围可协商。
- **品种本身易损**：如草莓、杨梅、荔枝，通常坏果率容忍度会更高，但也不是无限承担。

## 3. 到货时及时验收和留证
这是最关键的一步。建议：

1. **当场开箱抽检**，不要等卖的时候才发现。
2. 拍照/拍视频：拍外箱、批次、日期、坏果特写、整体数量。
3. 记录坏果数量、比例、金额。
4. 让送货司机或供应商确认签字；如果是线上订货，及时发消息确认。
5. 在约定异议期内提出，比如24小时内、48小时内。超过期限，供应商可能不认。

## 4. 常见结算或赔付方式
可以按协商结果选一种或组合：

- **补货**：下次送货补同等数量好果。
- **直接扣款**：按坏果数量×进货单价，从货款里扣。
- **折价结算**：整批按比例降价，比如坏果10%，整批按9折结算。
- **退货**：坏果部分退回，供应商退款或换货。
- **共同承担**：自然损耗部分双方各承担一半，常见于长期合作。
- **保证金/质保金扣除**：有质量保证金的，按约定扣。

举例：  
进货100箱苹果，单价50元/箱，到货发现8箱严重坏果。  
若约定坏果包赔，可要求补8箱好果，或扣款400元。  
若约定坏果率超过5%才赔，则8%里超出5%的3%部分可协商赔付，即3箱×50元=150元。  
具体看合同。

## 5. 对方不认怎么办
可以按顺序处理：

1. 拿出到货验收记录、照片、聊天记录、送货单。
2. 先协商，提出明确方案：补货、扣款或折价。
3. 协商不成，暂停后续订单或调整结算。
4. 有合同约定的，按合同争议条款处理。
5. 金额较大时，保留证据，考虑发函、平台投诉或法律途径。
6. 长期合作供应商，最好形成固定规则，比如“坏果超3%扣款，超10%整批退换”。

## 6. 建议水果店平时这样做
- 签订简单供货协议，写清坏果率、验收期、赔付方式。
- 每批到货都抽检并拍照。
- 送货单上备注坏果情况，双方签字。
- 用微信/订单系统留痕，不要只口头说。
- 对易损水果单独约定损耗标准。
- 结算时把扣款明细列清楚，避免以后扯皮。

## 一句话总结
**有约定按约定；没约定就按责任和坏果比例协商，通常用补货、扣款、折价或退货解决。关键是到货及时验收、留证，并在异议期内提出。**
