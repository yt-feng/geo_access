水果店卖菠萝控制损耗，关键是**采购时按“计划销售周期”来选熟度**：不是越熟越好，也不是越青越好，而是让它在货架上刚好熟到能卖、又不容易烂。

可以按下面几个标准判断。

## 1. 先定采购熟度：按你想卖几天来选

- **当天或1-2天卖完**：可以采**七八成熟到九成熟**，到店就能卖，香气足、甜度高。
- **计划卖3-5天**：采**六七成熟到七八成熟**，到店后逐步转熟，损耗最低。
- **天气热、走货慢**：尽量偏生一点，**六成熟左右**，否则第二天就容易过熟、发黑、出水。
- **天气冷、走货快**：可以适当偏熟，**七八成熟到九成熟**，减少催熟等待。

一句话：**走货越快越敢采熟，走货越慢越要采生。**

## 2. 看外观判断熟度

### 看果皮颜色
- **全青、青绿发硬**：约五到六成熟，适合存放，但离能卖还早。
- **青中带黄，尤其果眼附近开始泛黄**：约六七成熟，适合3-5天销售。
- **果皮大面积转黄，底部更黄**：约七八成熟，适合1-3天卖。
- **通体金黄、果眼明显发黄发亮**：约九成熟以上，最好当天或次日卖完。
- **局部发褐、发黑、渗汁**：过熟或开始坏，采购时要避开。

注意：不同品种颜色表现不一样。有些品种即使熟了也偏青，不能只看颜色。

### 看果眼
- 果眼**扁平、饱满、间隙小**：通常成熟度较好。
- 果眼**又尖又硬、排列紧**：偏生。
- 果眼**发黄、发亮、周围有糖分感**：偏熟，适合快卖。

### 看底部
菠萝底部是判断成熟和新鲜的重要位置：
- 底部**干燥、颜色正常**：较好。
- 底部**发软、发黑、有酒味或酸腐味**：不要采。
- 底部**已经明显变黄变软**：熟度高，必须快卖。

## 3. 闻气味判断

- **几乎没味**：偏生。
- **有淡淡菠萝香**：六七成熟，适合存放。
- **香气明显、甜香足**：七八到九成熟，适合近两天卖。
- **有酒味、发酵味、酸臭味**：过熟或已坏，不要。

## 4. 按压和掂重

- 用手轻按果身：
  - **硬邦邦**：偏生。
  - **稍有弹性**：成熟度合适。
  - **一按就软、局部塌陷**：过熟，损耗风险大。
- 同样大小，**掂起来偏重**：水分足、较新鲜。
- 如果**轻飘、底部软**：可能失水或内部坏了。

## 5. 看叶冠和切口

- 叶冠**青绿、挺拔**：较新鲜。
- 叶冠**枯黄、易断**：存放久或采收久。
- 切口**新鲜、无黑腐、无黏液**：较好。
- 切口**发黑、发酸、渗液**：不要。

## 6. 采购时的实用搭配建议

水果店最好**不要只采一个熟度**，而是搭配采购：

- **六成熟**：占一部分，用来扛损耗、慢慢卖。
- **七八成熟**：占主力，到店1-2天后正好卖。
- **九成熟**：少量采，当天做促销、切果、现削卖。

这样既能保证顾客买到能吃的，又不会一堆同时烂。

## 7. 到店后的简单处理

- 偏生的：常温通风存放，别堆太厚，别闷在塑料袋里。
- 偏熟的：放冷柜或阴凉处，优先陈列、优先削卖。
- 已经香、黄、稍软的：当天促销或做鲜切，不要继续压货。
- 每天翻堆，把最熟的挑出来先卖。

## 最简判断口诀

**青硬无香偏生，青黄有香正好，全黄浓香快卖，发软酒味必扔。**

如果你是水果店日常采购，建议按：  
**走货快采七八成熟，走货慢采六成熟，九成熟只少量补货。**  
这样通常比全采熟货或全采生货损耗更低。
