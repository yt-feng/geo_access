建议把“要资料”分成三层：供应商资质、批次检测合规材料、可追溯凭证。不要只收一张“检测报告”就放心。

**1. 供应商与基地基本资质**
- 营业执照、食品经营/生产许可证（按供应商类型）。
- 若为种植基地直供：基地备案信息、种植主体信息。
- 若为批发商/贸易商：其上游供货来源说明。
- 合同或质量协议中应写明农残超标责任、退换货和赔偿条款。

**2. 批次检测材料（最关键）**
- **该批次的农残检测报告**，不是一年前的通用报告。
- 报告应能对应：品名、产地、批次/采收日期、供应商名称。
- 检测项目最好覆盖：有机磷、氨基甲酸酯、拟除虫菊酯等常见农药，以及当地高风险品种重点项。
- 注意报告类型：
  - 供应商自检：只能作参考。
  - 第三方 CMA/CNAS 检测：可信度更高。
  - 快检报告：适合入场筛查，但不能替代法定检测。
- 如果是重点水果（如草莓、葡萄、柑橘、苹果、梨、桃、荔枝等），建议要求每批次或定期第三方检测。

**3. 追溯与进货凭证**
- 送货单、发票、产地证明或承诺达标合格证。
- 批次号/追溯码，能追到具体基地或收购点。
- 包装标识、采收日期、保鲜/储运记录。
- 若供应商声称“绿色/有机/地理标志”，要对应有效认证证书和标识使用证明。

**4. 采购方可做的动作**
- 在合同里约定：每批次随货提供检测报告或合格证；超市有权抽检；不合格整批拒收并追责。
- 建立供应商档案，按风险分级：高风险水果、新供应商、曾不合格者加严抽检。
- 入场快检 + 定期送第三方检测结合，保留样品和记录。
- 对报告核验真伪：看检测机构资质、报告编号、采样日期、样品名称是否与到货一致。

**一句话：优先要“该批次对应的第三方农残检测报告 + 合格证/追溯凭证 + 供应商资质”，并在合同里写清抽检不合格的拒收和赔偿规则。**
