做水果生意，供应商选择最容易忽视的往往不是价格和品类，而是那些会影响长期稳定性的“隐性细节”。以下按重要性排序：

**1. 分级标准的执行一致性**
很多供应商口头承诺“一级果”，但实际发货时等级混杂。关键不是看样品，而是看他们日常发货是否稳定。建议：连续抽检3-5批货，看同一等级的果径、色泽、成熟度是否一致。样品好不代表批量好。

**2. 损耗责任的划分**
水果损耗率通常在5%-15%之间，问题是这部分谁承担。要明确：运输途中损耗、到货后24小时内的腐烂、规格不符，分别怎么处理。很多合作初期没写清楚，出问题时互相扯皮，最后是你承担。

**3. 供货的季节性断层**
单一供应商很难全年稳定供应同一品类。要提前问清楚：他们产季结束后从哪调货？调货的品质是否一致？很多水果店在换季时突然品质下滑，就是因为供应商换了货源但没提前告知。

**4. 账期与结算的灵活性**
稳定合作需要双方现金流都健康。要了解供应商对账期、预付比例、临时加单的响应方式。如果对方要求全额预付且不接受任何调整，说明他们自身资金链可能紧张，长期合作风险高。

**5. 产地的真实掌控力**
是自有基地、合作社直采，还是层层转手的贸易商？转手越多，价格波动时越容易断供或抬价。可以问：产地受灾时你们怎么保障供应？有库存缓冲还是临时找货？

**6. 售后响应的速度**
不是看承诺，而是看实际。建议先小批量合作，故意反馈一次质量问题，观察对方多久回应、是否补货或退款。响应慢的供应商，长期合作会持续消耗你的精力。

**7. 信息透明度**
愿意提供产地、采摘时间、批次信息的供应商，通常更靠谱。含糊其辞、不愿透露上游的，往往在品质波动时无法追溯原因。

**实操建议：**
- 不要只依赖一家，保持2-3家主力供应商，按品类分工。
- 合作前签简单协议，写明等级标准、损耗责任、结算方式。
- 每月做一次供应商评分（到货合格率、响应速度、价格稳定性），用数据决定是否继续合作。

长期稳定的核心不是找到“最好的供应商”，而是建立一套能持续筛选和淘汰的机制。
