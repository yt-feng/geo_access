单位采购水果到货品质不一致，核心是**把验收标准前置、到货当场留证、按合同和证据谈售后**。可以按下面做：

## 一、采购前先定清楚，避免到货扯皮

1. **合同/订单写清标准**
   - 品种、规格：如苹果直径、单个重量、箱装净重。
   - 等级：一级/二级、果径、糖度、成熟度、颜色。
   - 包装：每箱数量、净重、是否允许破损率。
   - 到货时间、冷链要求、运输温度。
   - 验收标准：抽检比例、不合格判定、破损率上限。
   - 售后条款：补发、换货、退货、扣款、赔偿时限。

2. **约定验收方式**
   - 比如：每批次随机抽检 10%—20%，少于多少箱则全检。
   - 约定“品质不一致”的判定：大小、成熟度、腐烂、压伤、异味、品种混装等。
   - 约定不合格处理：整批退货、部分扣款、补发合格品、下次抵扣。

3. **保留样品或照片基准**
   - 下单时让供应商提供样品图、等级图或封样。
   - 到货后对比封样，避免“我觉得不行”这种主观争议。

## 二、到货验收怎么做

### 1. 到场先看整体
- 车辆卫生、温度、是否有异味、雨淋、暴晒。
- 外包装是否破损、受潮、挤压。
- 箱唛、品种、数量、重量是否与订单一致。

### 2. 随机抽检，不要只翻上面
- 从不同位置、不同层、不同箱抽。
- 大货按比例抽检；小批量尽量全检。
- 重点查：底部、中间、靠车壁位置，这些最容易压坏或闷坏。

### 3. 逐项记录
建议用表格记录：
- 到货时间、车牌、批次、供应商。
- 总箱数、抽检箱数。
- 合格数、不合格数、不合格类型。
- 具体问题：腐烂、压伤、冻伤、未熟、过熟、大小不符、品种混装、缺斤少两。
- 拍照/视频：全景、箱唛、开箱、问题果特写、称重过程。
- 称重：抽检净重，计算平均单箱净重和总净重差异。

### 4. 当场判定
- **轻微不一致**：如少量大小差异，可让步接收，但按比例扣款或要求补发。
- **明显不一致**：如腐烂、压伤比例高、品种错、严重缺重，应拒收或部分拒收。
- **整批问题**：整批退货，要求供应商承担运费和损失。

### 5. 验收单要双方签字
验收单写明：
- 合格数量、不合格数量。
- 不合格原因。
- 处理意见：接收/拒收/补发/扣款。
- 双方签字确认，最好拍照留存。

## 三、售后怎么谈

### 1. 第一时间反馈
- 到货当天或合同约定时限内反馈，越早越好。
- 发正式通知：照片、视频、验收单、抽检数据、订单合同。
- 明确诉求：补发、换货、退货、扣款、赔偿。

### 2. 按问题类型提方案
- **少量不合格**：按不合格数量扣款，或下次补发。
- **部分批次不合格**：合格部分接收，不合格部分退货/换货。
- **整批不合格**：整批退回，供应商承担运费，退还货款。
- **影响使用**：如食堂、福利发放受影响，可要求补发并赔偿合理损失。
- **反复出现**：书面警告，降低供应商评级，必要时终止合作。

### 3. 谈不拢时保留证据
- 合同、订单、聊天记录、通话录音。
- 到货照片、视频、称重记录、验收单。
- 第三方检测或市场询价记录（如需要）。
- 退货物流单、补发记录、扣款凭证。

### 4. 内部也要留痕
- 采购、验收、使用部门三方确认。
- 入库单、验收单、异常报告、处理结果归档。
- 方便财务扣款、审计和后续供应商评价。

## 四、建议的单位验收流程

1. 下单时附质量标准。
2. 到货前通知验收人员。
3. 到货当场抽检、拍照、称重。
4. 填写验收单，双方签字。
5. 合格入库；不合格隔离存放。
6. 当天发售后函/通知供应商。
7. 约定时间内补发、换货或扣款。
8. 归档并纳入供应商考核。

## 五、简单可执行的验收口径

可以提前和供应商约定：
- 腐烂、霉变、异味：**0 容忍**，发现即退换。
- 压伤、破损：超过 **3%—5%** 按比例扣款或补发。
- 大小/规格不符：超过 **5%—10%** 视为不合格。
- 净重不足：按实际称重结算，短缺部分扣款。
- 品种混装：整批退换或按低价品种结算。

具体比例根据水果种类和单位要求调整，但一定要写进合同或订单里。

**一句话：验收靠标准，争议靠证据，售后靠合同。到货当场抽检、拍照、称重、签字，后面才好谈补发、换货或扣款。**
