超市和水果供应商的账期没有统一标准，主要看超市类型、供应商议价能力和水果品类。常见区间大致如下：

- **大型连锁商超/卖场**：30～60天较常见，部分强势渠道可到 60～90天，甚至“月结60天/90天”。
- **区域连锁超市/社区超市**：15～45天较常见，很多是“月结15天/30天”。
- **生鲜电商/平台**：7～30天较常见，部分平台按周结或半月结。
- **小型超市/夫妻店**：多为一周内、现结或周结，较少压长账期。

水果品类也要分开看：

- **普通大宗水果**（苹果、梨、柑橘等）：耐储存，账期可相对长，30～60天较常见。
- **高损耗/时令水果**（草莓、樱桃、荔枝、杨梅等）：供应商通常要求更短，7～15天，甚至现结/周结。
- **进口水果**：资金占用大、价格波动快，常见 7～30天，强势供应商可能要求现款或短账期。
- **本地直采/产地直发**：常见周结、半月结，或货到付款。

谈判时可以重点看这几个点：

1. **别只谈天数，要谈结算方式**：现结、周结、月结、月结30天、月结60天，实际现金流差别很大。
2. **明确起算时间**：是收货日、对账日，还是发票日？很多争议都在这里。
3. **设置阶梯账期**：新供应商先短账期，合作稳定后逐步延长。
4. **用采购量/稳定性换账期**：包销、长期合同、淡季支持，通常能换到更好条件。
5. **考虑损耗和退换货**：水果损耗高，账期长但退货扣款多，供应商实际回款未必好。

简单判断：

- 如果你是超市方，想压账期：先争取 **月结30天**，强势品类争取 **月结60天**。
- 如果你是供应商，底线建议：普通水果 **不超过30～45天**，高损耗水果 **不超过15天**，否则要加价或要求预付款。
- 行业里比较“中性、常见”的答案是：**30天左右最常见，60天算偏长，90天属于强势渠道压款。**
