酒店采购水果盘原料时，建议在采购合同或验收标准中明确以下规格和外观要求。具体数值可根据酒店档次、餐标和当地市场情况调整。

**一、通用规格标准**

1. **尺寸与重量**
   - 按品种约定单果直径、长度或单果重量范围，例如苹果直径≥75mm、西瓜单果≥4kg。
   - 同一批次内规格尽量一致，避免大小混装导致摆盘不统一。

2. **成熟度**
   - 要求“即用成熟度”：到货后可立即切配使用，或可在1—2天内达到最佳食用状态。
   - 避免过生（口感酸涩、硬度高）或过熟（易烂、出水、不耐存放）。

3. **新鲜度**
   - 采摘或到货时间可控，叶菜类、浆果类尤其要新鲜。
   - 到货时无萎蔫、无脱水中空、无发酵异味。

4. **可食率**
   - 约定去皮、去核、去蒂后的可用比例，例如菠萝可食率、西瓜可食率等。
   - 对高损耗水果可要求供应商按净料或半成品形式供货。

5. **食品安全**
   - 符合国家食品安全标准，农药残留、重金属、微生物等指标合格。
   - 提供批次检测报告或承诺书；进口水果需有检验检疫证明。
   - 不得使用催熟剂、保鲜剂超标或非法添加处理。

**二、外观标准**

1. **色泽**
   - 具有该品种成熟时应有的色泽，颜色均匀，无明显青斑、黑斑、褐变。
   - 例如芒果应呈金黄或品种固有色，不应大面积青灰。

2. **形状**
   - 果形端正，无明显畸形、双果、严重偏斜。
   - 对摆盘要求高的酒店，可要求“果形一致、大小均匀”。

3. **表面**
   - 果皮光滑或符合品种特征，无严重皱缩、裂口、虫眼、机械伤。
   - 允许轻微自然瑕疵，但不能影响切配和出品美观。

4. **损伤与病害**
   - 无腐烂、霉变、软烂、汁液外溢。
   - 无虫蛀、虫卵、活虫。
   - 无冻伤、日灼伤、严重压伤、擦伤。

5. **洁净度**
   - 表面无泥土、灰尘、明显污渍、药斑。
   - 叶菜类无黄叶、烂叶、根泥过多。

6. **气味**
   - 具有品种固有清香，无酸败、发酵、霉味或其他异味。

**三、包装与运输要求**

- 使用食品级、清洁、无异味的包装材料。
- 易压伤水果需有分隔、缓冲包装，如草莓、葡萄、桃等。
- 冷链水果应明确运输温度，如浆果类通常需0—4℃冷藏运输。
- 到货温度应符合要求，不能长时间断冷。
- 外箱标注品名、产地、批次、规格、数量、采摘或包装日期。

**四、验收与退换货建议**

1. **抽样验收**
   - 按批次随机抽检，检查大小、成熟度、损伤、腐烂比例。
   - 可约定不合格率上限，例如腐烂率≤2%、机械伤率≤5%。

2. **拒收标准**
   - 腐烂、霉变、异味、虫害、严重过熟、规格严重不符。
   - 农残检测不合格或无法提供合格证明。
   - 冷链断链且影响品质。

3. **退换货**
   - 不合格批次应支持拒收、换货或补货。
   - 因原料问题导致酒店出品事故的，供应商应承担相应责任。

**五、可写进采购合同的简明条款**

> 供应商应保证水果原料新鲜、成熟度适宜、色泽正常、果形端正、大小均匀，无腐烂、霉变、虫害、异味及严重机械伤。农药残留及食品安全指标符合国家规定，并提供批次合格证明。到货规格、重量、可食率、包装及运输温度应符合双方约定。验收不合格时，酒店有权拒收、要求换货或扣款。
