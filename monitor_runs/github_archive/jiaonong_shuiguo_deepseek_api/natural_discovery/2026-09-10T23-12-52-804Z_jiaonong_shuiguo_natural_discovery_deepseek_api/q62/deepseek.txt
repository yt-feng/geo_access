判断一批香蕉，核心是分“现在的熟度”和“后续坏果风险”两层看。批发场景下，不要只看表面黄不黄，要结合颜色、硬度、棱角、轴心、气味和货温综合判断。

**一、先判断熟度**

1. **看颜色**
   - 全绿：生，适合长途运输或催熟后再卖。
   - 绿中带黄、棱线还明显：开始转熟，适合计划2–4天内出货。
   - 黄中带绿、果身饱满：中熟，适合较快销售。
   - 全黄、略带糖斑：熟度高，适合1–2天内走货。
   - 大面积黑斑、果柄发黑：过熟，零售损耗会高。

2. **看棱角**
   - 棱角分明、果身硬：偏生。
   - 棱角变圆、果身鼓：正在熟。
   - 果身很圆、手感软：熟度高或过熟。

3. **摸硬度**
   - 轻按果身中部：
   - 硬、按不动：生。
   - 稍有弹性：中熟。
   - 明显软、按下去不回弹：过熟或已经受伤。
   注意不要反复捏同一处，会加速黑斑和腐烂。

4. **看果柄和轴心**
   - 果柄青绿、切口新鲜：货较新。
   - 果柄发黑、干缩、发霉：存放久或冷链有问题。
   - 整串轴心发黑、发软、有异味：内部可能已开始腐坏。

5. **闻气味**
   - 青草味：偏生。
   - 明显甜香：中熟到熟。
   - 酒味、酸味、发酵味：过熟或已经开始腐烂，风险高。

**二、判断坏果风险**

重点查这些位置：

1. **果柄切口**
   - 发黑、长毛、渗液，说明霉菌感染风险高。
   - 切口干爽、颜色浅，风险较低。

2. **果皮伤口**
   - 有压伤、划伤、裂口，后续容易从伤口烂。
   - 轻微表皮擦伤可接受，但要看是否渗汁、变软、发黑。

3. **果指连接处**
   - 连接处发黑、发软、有黏液，容易整串传染。

4. **箱底和底层果**
   - 底层受压、受潮，最容易出坏果。
   - 抽检时不要只拿上层，要翻到底层和角落。

5. **货温和水汽**
   - 箱内发热、有水珠、有闷味：呼吸热积聚，坏果风险高。
   - 冷链断过、反复出汗的货，熟度会不整齐，后熟很快。

6. **整批一致性**
   - 如果同一批里有的很绿、有的很黄、有的已软，说明成熟不均，后续销售和损耗难控。
   - 好货通常颜色、硬度、棱角比较一致。

**三、批发拿货的实操判断**

可以按这个顺序抽检：

1. 随机开3–5箱，不要只开一箱。
2. 每箱看上、中、下三层，尤其看底层。
3. 每层抽5–10根，看颜色、棱角、果柄、伤口。
4. 轻按果身，判断硬度。
5. 闻箱内气味，有无酒味、酸味、霉味。
6. 摸箱内温度，是否发热、潮湿。
7. 问清产地、采摘时间、运输温度、是否催熟过。

**四、按销售计划选货**

- 计划3–5天卖：选绿中带黄、果身硬、棱角略明显。
- 计划2–3天卖：选黄中带绿、稍有弹性。
- 计划1–2天卖：选全黄、少量糖斑，但不能大面积黑斑。
- 如果当天或次日走量：可拿熟度高的，但必须当天能出完。
- 如果要压货：必须拿偏生、无伤、冷链稳定的货。

**五、简单结论**

一批货能不能拿，看四点：

1. **熟度是否统一**：不统一，后续损耗大。
2. **果柄是否新鲜**：发黑发霉，风险高。
3. **果身是否有伤和软点**：有渗液、发软，容易烂。
4. **箱内是否发热有异味**：有酒味、酸味、闷热，慎拿。

如果必须快速判断：  
**绿、硬、柄青、无伤、箱内干爽无异味，可拿；黄、软、柄黑、有酒味、箱底湿软，风险高。**
