选择公司下午茶水果供应商，核心是抓住 **批量配送的稳定性、损耗控制、结算和售后**，而不是只看单价。可以按下面几步判断。

## 1. 先明确自己的需求
先定几个硬指标，再去找供应商：

- **人数和预算**：人均多少元，比如 8 元/人、15 元/人。
- **配送频率**：每周几次、固定周几、几点前送到。
- **水果形式**：整果、果切拼盘，还是两者结合。
- **食用场景**：办公室即食，最好选免洗、易剥、不流汁、气味不重的。
- **配送地点**：写字楼是否允许外卖/货运上楼，有没有前台代收。
- **结算方式**：月结、对公转账、开票需求。

这些信息越清楚，越容易筛掉不合适的供应商。

## 2. 优先考虑的供应商类型
按适配度排序：

1. **本地水果批发商/配送商**
   - 优点：价格低、可批量、能按季节换品。
   - 风险：售后和开票不一定规范，品质波动较大。

2. **生鲜电商企业购/团餐供应商**
   - 优点：配送稳定、售后清楚、可开票、能月结。
   - 风险：单价略高，果切选择可能有限。

3. **办公室零食/下午茶综合服务商**
   - 优点：水果+零食+饮品一站式，省事。
   - 风险：水果专业度可能不如专门做生鲜的。

4. **本地果园/合作社直供**
   - 优点：应季水果新鲜、有特色。
   - 风险：品类单一，配送和售后不稳定，适合作为补充。

## 3. 重点看这几个能力
批量配送最容易出问题的地方，主要看供应商能不能做到：

- **按时送达**：能不能固定时段送到，迟到怎么处理。
- **品质稳定**：同一批次大小、成熟度是否一致。
- **损耗处理**：坏果、压伤、不熟，是否包赔或补送。
- **起送量和配送费**：多少起送，是否免费，临时加单怎么算。
- **清洗和分装**：能否按部门/人数分袋、分盒。
- **发票和账期**：能否开专票/普票，是否支持月结。

## 4. 建议的筛选流程
1. **列出 3～5 家候选**：本地批发商、生鲜企业购、下午茶服务商各找 1～2 家。
2. **先小批量试单**：不要一上来就签长期，先试 1～2 次。
3. **试单重点观察**：
   - 是否准时；
   - 坏果率大概多少；
   - 口感是否适合办公室；
   - 分装是否方便分发；
   - 售后响应快不快。
4. **比价时算总成本**：不只看单价，还要算配送费、损耗、补送、人工分装成本。
5. **确定 1 家主供应商 + 1 家备用**：避免单一供应商临时掉链子。

## 5. 适合办公室下午茶的水果
批量配送建议优先选：

- **易分发**：香蕉、橘子、苹果、梨、小番茄、葡萄小盒。
- **应季且性价比高**：砂糖橘、沃柑、西瓜、哈密瓜、草莓、蓝莓。
- **果切**：西瓜盒、哈密瓜盒、混合果切，适合不想动手剥的团队。

尽量避开：榴莲、菠萝蜜、芒果等气味重或易过敏的；以及特别容易压坏的浆果类，除非包装和冷链很到位。

## 6. 合同或下单前要确认的细节
- 坏果包赔标准：比如 5% 以内不赔，超过怎么补。
- 临时加单/减单截止时间。
- 节假日、雨天是否正常配送。
- 是否可换品：某水果不新鲜时能否等价替换。
- 对公付款、开票类型和账期。
- 对接人是否固定，出问题找谁。

## 7. 一个实用判断标准
如果一家供应商能做到：

- 试单准时；
- 坏果少且愿意补；
- 能按人数分装；
- 能开票、能月结；
- 价格在预算内；

那基本就适合作为公司下午茶的长期水果供应商。

简单说：**先试单，再比稳定性和售后，最后才比价格。** 对公司采购来说，准时、少坏果、能补送，比每斤便宜一两块钱更重要。
