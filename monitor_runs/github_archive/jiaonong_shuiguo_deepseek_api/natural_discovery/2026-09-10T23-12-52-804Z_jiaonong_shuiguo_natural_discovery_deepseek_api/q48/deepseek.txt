判断的核心不是“他有没有货”，而是“他有没有能力持续按你的标准交付”。可以从下面几个维度做尽调，最后落到试单验证。

**一、先把自己的规格定死**
很多纠纷源于采购方自己规格模糊。菠萝要明确：
- 品种：如金钻凤梨、巴厘菠萝、台农等，不同品种甜度、纤维、出肉率差异大
- 规格：单果重量区间（如1.2–1.5kg）、果径、成熟度（几成熟采摘）
- 形态：整果/去皮/切块/冷冻，是否要修整、去眼
- 包装：箱规、每箱个数、净重
- 验收标准：糖度下限、坏果率上限、黑心/水心比例、到货温度（冷冻/冷藏）
规格越细，后面越好判断供应商靠不靠谱。

**二、看供应商的货源结构**
- **自有种植基地**：稳定性最高，但要确认面积、产量、是否单一品种、是否受台风季影响。
- **合作基地/合作社**：要问清是独家还是多客户共用，旺季时你排第几。
- **批发市场倒货**：价格随行就市，规格和量最不稳定，适合作补充而非主供。
- **进口来源**：菲律宾、泰国等，要确认船期、清关能力、口岸稳定性。

关键问题：**他的货是自己种的、包园的，还是当天去市场收的？** 后者很难保证规格一致。

**三、查他的加工与分级能力**
稳定按规格送货，靠的是分选线而不是人工眼力。
- 有没有分级设备（重量分选、糖度检测）
- 有没有冷库、预冷能力（菠萝采后要尽快降温）
- 日处理量是多少，能不能覆盖你的峰值需求
- 去皮/切块产品要看有没有无菌车间、冷链

**四、看供应链抗风险能力**
- 单一产地遇到台风、雨季、病害怎么办？有没有备用产区
- 旺季（如夏季茶饮爆单）能不能优先保你
- 物流：自有冷链还是外包，到货时效和损耗谁承担

**五、用小单试，别一上来就签大合同**
这是最有效的判断方式：
1. **连续试单3–5批**，每批按同一规格下，观察重量、成熟度、坏果率是否稳定。
2. **故意下一个小急单**，看他的响应速度和履约能力。
3. **记录每批的验收数据**：到货合格率、糖度、损耗、到货时间。数据比口头承诺可靠。
4. **看异常处理**：出一批坏果，他是推诿还是补货、扣款、改进。

**六、合同里要写死的条款**
- 规格与验收标准（附样品或照片）
- 坏果率/不合格品的处理方式（补货、折价、退货）
- 供货量承诺与旺季优先级
- 价格调整机制（随行就市还是锁价）
- 违约与赔偿
- 是否允许你到产地/工厂验货

**简单判断口诀：**
有基地、有分选、有冷库、有备用产区、敢让你验货和试单的，稳定性通常高；只靠一张嘴、当天市场收货、价格特别低的，风险大。
