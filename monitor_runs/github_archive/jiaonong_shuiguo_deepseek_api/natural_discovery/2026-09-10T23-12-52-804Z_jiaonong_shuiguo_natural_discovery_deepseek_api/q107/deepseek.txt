会，而且香蕉和菠萝的损耗风险对起订量特别敏感，原因不太一样。

**香蕉：高敏感**
- 香蕉是呼吸跃变型水果，采购后还会继续后熟，货架期短。
- 起订量一大，往往来不及在最佳成熟度窗口内卖完，容易出现“集中变黄—集中变黑”的损耗。
- 如果采购时成熟度偏青，看似能放，但后熟一旦启动，损耗会集中爆发。
- 冷链、催熟、分拣能力跟不上时，起订量越高，损耗放大越明显。

**菠萝：中等敏感，但更看周转和品相**
- 菠萝相对耐放，但起订量高仍会带来问题：
  - 占用仓储和资金，周转慢时容易过熟、发软、黑心。
  - 表皮碰伤、冠芽压伤会随堆压时间增加而扩大。
  - 如果按整箱/整托起订，尾货和品相下降的货更难处理。
- 相比香蕉，菠萝的损耗更多来自“压货时间”和“储存条件”，不是后熟速度本身。

**判断是否增加损耗，可以看这几个变量：**
1. **日均销量**：起订量是否超过 3–7 天销量。
2. **保质/最佳销售窗口**：香蕉通常按天算，菠萝按周算。
3. **仓储条件**：是否有冷藏、通风、分拣和催熟能力。
4. **补货频率**：能否小批量、多频次补货。
5. **下游渠道**：是否有加工、促销、团购等消化尾货的出口。

**可执行建议：**
- 香蕉：尽量按 1–3 天销量起订，宁可分次采购，也不要一次压 5 天以上。
- 菠萝：可适当放大到 3–7 天，但要有通风、避压、先进先出。
- 如果供应商起订量下不来，优先谈：拆托、混装、分批发货、代储，而不是硬吃库存。
- 算一笔账：起订量增加带来的单价优惠，是否大于预计损耗成本。通常香蕉的临界点比菠萝更低。

**结论**：起订量太高会显著增加损耗风险，香蕉尤其明显，菠萝次之。核心不是“能不能放”，而是“能不能在最佳窗口内周转掉”。
