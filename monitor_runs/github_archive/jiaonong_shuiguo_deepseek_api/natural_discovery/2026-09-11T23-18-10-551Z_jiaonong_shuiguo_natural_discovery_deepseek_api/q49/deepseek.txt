旺季菠萝用量突然变大，临时补货的关键是**提前锁量、明确时效、接受价格浮动、留好替代方案**。可以按下面几步和供应商约定：

**1. 先给供应商一个滚动预估**
不要只说“最近要多送点”，而是给出未来7天或10天的预估用量，例如：
- 日用量从多少升到多少；
- 预计持续几天；
- 最低保底量和最高需求量分别是多少。

这样供应商才好备货和排车。

**2. 约定临时补货机制**
可以直接和供应商谈一个“旺季临时补货条款”：
- **下单截止时间**：比如每天上午10点前下单，次日送达；10点后下单，视库存安排。
- **最小补货量**：比如每次临时补货不低于多少箱/多少公斤，避免供应商不愿跑。
- **到货时效**：比如24小时内到店，紧急情况48小时内。
- **配送频次**：从每周2次临时提高到每周3—4次，或按需加车。

**3. 价格和品质要写清楚**
旺季菠萝价格容易波动，建议约定：
- 基准价随行就市，但提前约定**浮动上限**，比如比基准价上浮不超过多少；
- 临时补货是否加收运费、加急费；
- 规格、成熟度、糖度、坏果率标准不变；
- 验收不合格如何退换、补送。

**4. 用“保底+浮动”锁量**
可以和供应商谈：
- 你承诺旺季每周最低采购量；
- 供应商承诺优先保障你的临时补货；
- 超出保底部分按临时价或阶梯价结算。

这样供应商有动力给你留货，你也不会被完全锁死。

**5. 准备备选供应商**
旺季不要只靠一家。至少再找1家备用供应商，哪怕价格略高，用于紧急补位。也可以临时用**冷冻菠萝、菠萝果酱、罐头菠萝**做部分产品替代，但要在菜单或培训中明确哪些产品不能用替代品。

**6. 最好落成简单书面确认**
微信、邮件都行，写清楚：
- 临时补货触发条件；
- 下单截止时间；
- 到货时间；
- 价格计算方式；
- 品质标准和退换规则；
- 违约责任或补偿方式。

**一句话建议：**
和供应商约定“**滚动预估 + 保底量 + 临时补货时效 + 价格浮动上限 + 备用供应商**”，比临时打电话催货更稳。
