判断香蕉这批货能不能拿、能放几天，核心看 **颜色、手感、果柄、棱角、气味、温差和箱内情况**。下面给你一套批发现场可直接用的判断方法。

## 1. 先看颜色：决定熟度阶段

香蕉熟度一般按颜色分：

- **全青、硬**：生货，适合长途或催熟，但不能马上卖。
- **青中带黄、果柄青**：开始转熟，适合拿货后 2–5 天卖。
- **黄身青柄**：适合近期出货，通常 2–3 天内要动销。
- **全黄、无青**：已经熟，适合马上卖，不耐放。
- **黄带黑点**：最佳食用期，但批发风险高，必须快出。
- **大面积黑斑、发暗**：过熟或开始烂，风险大。

**拿货建议：**
- 如果你 1–2 天能卖完：可拿黄身青柄或全黄。
- 如果 3–5 天卖：拿青中带黄、果柄青的。
- 如果要放一周以上：拿全青或刚转黄的，但要有催熟条件。

## 2. 摸手感：判断成熟度和内伤

不要只捏中间，要捏 **果身中段和果柄连接处**。

- **硬得像木头**：生，耐放但催熟慢。
- **微软有弹性**：熟度合适。
- **一按一个坑、回弹慢**：过熟，坏果风险高。
- **局部特别软**：可能有内伤、压伤、烂心。
- **整把发软但表皮没黑**：可能受热或闷过，风险高。

**注意：** 香蕉怕压，箱底和边角最容易伤。抽检时不要只看最上面一层。

## 3. 看果柄和切口：判断新鲜度和是否闷过

- **果柄青绿、切口新鲜**：通常较新鲜。
- **果柄发黑、干缩**：放久了或受热。
- **果柄发霉、长白毛/黑毛**：整箱风险高，容易传染。
- **切口流白汁**：刚采不久，偏生。
- **切口发褐、有酸味**：可能闷坏。

## 4. 看棱角和果形：判断饱满度和是否催过头

- **棱角明显、果身扁**：偏生，或肥水不足，口感可能差。
- **果身圆鼓、棱角不明显**：成熟度好。
- **果身特别圆但很软**：可能催过头，不耐放。
- **果指大小不均**：可能混级，卖相和熟度不一致。

## 5. 闻气味：最快发现坏果

- **青草味**：生。
- **正常甜香**：熟度合适。
- **酒味、酸味、发酵味**：已经有烂果或闷伤，整箱风险大。
- **霉味**：不要拿，或者必须开箱彻底挑。

## 6. 看箱内和温度：判断是否闷过、受冻、受热

- **箱壁有水珠、内衬潮湿**：容易发霉，坏果风险高。
- **箱内有黑水、汁液**：已有烂果。
- **摸箱体发热**：可能堆太久、闷过。
- **冷库拿出来后表面结露**：温差大，容易起黑点。
- **受冻香蕉**：皮暗、发灰，熟后不发黄，果肉硬心或水烂。
- **受热香蕉**：外黄内硬，或者快速发软、发酸。

## 7. 现场抽检方法

拿货时至少抽 3–5 箱，不要只抽一箱。

每箱重点查：
1. **上层**：看颜色和卖相。
2. **中层**：看熟度是否一致。
3. **底层和边角**：看压伤、烂果、汁液。
4. **果柄缝**：看有没有霉。
5. **随机捏 3–5 根**：判断软硬。
6. **闻整箱**：有没有酒酸味。

如果一箱里 **坏果超过 3%–5%**，就要压价或拒收。  
如果是 **霉变、酒味、黑水**，风险更高，建议不要拿。

## 8. 快速决策表

| 情况 | 判断 | 建议 |
|---|---|---|
| 全青硬、果柄青 | 生货 | 可拿，需催熟 |
| 青中带黄、微软 | 好货 | 适合 3–5 天卖 |
| 黄身青柄 | 近熟 | 2–3 天卖 |
| 全黄无青 | 已熟 | 1–2 天卖 |
| 黄带少量黑点 | 适熟 | 快出，别压货 |
| 大面积黑斑、软塌 | 过熟 | 不拿或极低价 |
| 有酒酸味、黑水 | 烂果风险 | 拒收 |
| 果柄发霉 | 传染风险 | 拒收 |

## 9. 拿货后的处理建议

- 青香蕉：放 **13–18℃** 催熟，别低于 12℃。
- 已熟香蕉：放 **12–14℃** 短期保存，尽快卖。
- 不要和苹果、梨等释放乙烯的水果混放，会加速熟。
- 开箱挑出坏果，避免传染。
- 不要反复搬动、压堆，香蕉很怕压。

**一句话：**  
拿香蕉先看颜色定熟度，再摸软硬定耐放，再看果柄和箱内定坏果风险；有酒酸味、黑水、霉柄、局部软塌的，尽量别拿。
