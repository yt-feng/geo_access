做水果礼盒，关键不是“凑齐四种水果”，而是**按送礼场景做组合，让顾客一眼知道买给谁、花多少钱**。苹果、橙子、香蕉、菠萝都能用，但搭配时要注意：香蕉和菠萝气味重、易催熟/压伤，最好别和苹果大量混放。

下面给你几套比较好卖的搭配和定价思路。

**一、先定场景，再定搭配**

1. **探病/看望长辈：稳当吉利型**
   - 苹果 + 橙子为主
   - 香蕉少量点缀
   - 菠萝不建议放，容易扎手、气味冲
   - 卖点：平安、心想事成、颜色亮、大小均匀
   - 适合：医院附近、社区店、中老年客群

2. **节日/开业/送礼：大气有面子型**
   - 苹果 + 橙子 + 菠萝
   - 香蕉可替换成提子、猕猴桃等更耐放水果
   - 卖点：果形大、颜色金红、有“旺来”“平安”“成功”寓意
   - 适合：春节、中秋、开业、商务小礼

3. **日常家庭/办公室分享：实惠好吃型**
   - 苹果 + 橙子 + 香蕉
   - 菠萝切盒另装，或整颗单独卖
   - 卖点：便宜、量足、拿起来就能吃
   - 适合：写字楼、学校周边、社区团购

4. **年轻化/拍照好看：网红混搭型**
   - 橙子 + 菠萝 + 苹果
   - 香蕉用少量小把蕉做造型
   - 卖点：颜色对比强，黄橙红绿都有
   - 适合：小红书、朋友圈、下午茶场景

**二、具体搭配比例建议**

以中号礼盒为例：

- **6粒装**：苹果2 + 橙子2 + 香蕉1 + 菠萝1小颗  
  适合39~59元档，走量。

- **8粒装**：苹果3 + 橙子3 + 香蕉2  
  适合49~69元档，最稳，不容易坏。

- **8粒装升级**：苹果3 + 橙子2 + 菠萝1 + 香蕉2  
  适合69~99元档，节日卖。

- **10粒装**：苹果4 + 橙子4 + 香蕉2  
  适合59~79元档，家庭分享。

如果菠萝整颗太大，建议：
- 用“小菠萝/凤梨”替代；
- 或者菠萝单独做“加购项”，不硬塞进礼盒。

**三、怎么摆更好卖**

1. **按价格分三档**
   - 39~49元：苹果+橙子+香蕉
   - 59~79元：苹果+橙子+香蕉+小菠萝
   - 99元以上：大果+凤梨+精品包装

2. **按人群贴标签**
   - “送长辈：平安橙意”
   - “送同事：分享装”
   - “开业送礼：旺来发财”
   - “探病慰问：清爽不串味”

3. **颜色搭配**
   - 红苹果 + 黄橙子 + 黄香蕉 + 绿菠萝冠
   - 对比强，拍照好看，但香蕉别压在最底下。

4. **包装别过度**
   - 透明开窗+手提袋最实用。
   - 内衬用蜂窝纸或珍珠棉，减少磕碰。
   - 香蕉单独用纸包一下，避免催熟其他水果。

**四、最容易踩的坑**

- 香蕉和苹果放一起会加速成熟，礼盒最好当天卖、当天送。
- 菠萝刺手、气味大，不适合和切开的水果混放。
- 礼盒不是水果越多越好，塞太满反而显廉价、易压坏。
- 如果顾客是送人，优先选“果形统一、颜色亮、无瑕疵”，比品种多更重要。

**五、直接可用的主推组合**

建议你先主推这3款：

1. **平安橙意盒**：苹果3 + 橙子3 + 香蕉2，49~59元，走量款。  
2. **旺来福气盒**：苹果3 + 橙子3 + 小菠萝1 + 香蕉1，69~89元，节日款。  
3. **全家分享盒**：苹果4 + 橙子4 + 香蕉2，59~69元，家庭款。  

如果只选一个最好卖的，我会选：**苹果 + 橙子 + 香蕉**。  
菠萝作为升级项或加购项，不要一开始就硬塞进所有礼盒。这样损耗低、接受度高、也更好定价。
