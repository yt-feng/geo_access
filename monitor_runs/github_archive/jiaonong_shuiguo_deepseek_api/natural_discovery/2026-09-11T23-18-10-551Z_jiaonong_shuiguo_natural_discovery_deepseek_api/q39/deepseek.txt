可以，但通常不是“裸果供应商”直接全包，而是取决于你找的供应商类型。商超做自有品牌水果，包装和规格支持主要有三种来源：

1. **产地/合作社/大型基地**
   - 能提供：分级、规格分选、简单装箱、贴标。
   - 不一定能提供：零售小包装、品牌化包装设计、条码/标签合规、稳定印刷。
   - 适合：你先定包装，让供应商按你的规格装。

2. **专业水果供应链公司/代工分装商**
   - 能提供：较完整的包装和规格支持，包括分选、称重、装盒、贴自有品牌标签、箱规设计、冷链一件代发。
   - 通常可配合：你出品牌和设计，他出包材采购、分装、打码、贴标。
   - 适合：商超真正做自有品牌水果的主力合作方。

3. **包装厂/包材商**
   - 能提供：包装结构、材质、印刷、条码位置、保鲜要求建议。
   - 不提供：水果本身。
   - 适合：你已确定果源，单独解决包装。

**供应商一般能支持到什么程度**
- 规格：果径、单果重、每盒/每袋数量、箱规、净重/毛重、等级。
- 包装：塑料袋、吸塑盒、纸盒、礼盒、网套、托盘、外箱。
- 标识：贴自有品牌标签、打印条码、生产日期、追溯码、产地信息。
- 分装：按你要求的克重/个数做零售小包装。
- 冷链：部分供应商可做预冷、冷藏配送。

**但要注意**
- 包装设计、品牌定位、条码申请通常要商超自己主导。
- 包材起订量、开版费、印刷费要谈清楚。
- 水果是非标品，规格允差、损耗率、退换货规则必须写进合同。
- 自有品牌标签合规：品名、产地、等级、净含量、生产商/分装商、日期、保存条件等要符合当地法规。
- 如果供应商同时给多个商超供货，要约定独家包装或防串货。

**建议你直接这样问供应商**
1. 能否按我司自有品牌做零售小包装？
2. 能否按我指定的果径/克重/个数分级？
3. 包材谁采购、谁承担开版费、起订量多少？
4. 能否贴标、打条码、喷码？
5. 损耗率、规格允差、到货不合格怎么处理？
6. 最小起订量、供货周期、冷链条件？
7. 是否接其他商超同类自有品牌？

**结论**
能做。优先找“水果供应链公司/分装商”谈，他们最能同时解决果源、规格、包装和贴标。单纯产地供应商通常只能解决果源和初分级，包装设计及合规标识要商超自己或包材商配合。
