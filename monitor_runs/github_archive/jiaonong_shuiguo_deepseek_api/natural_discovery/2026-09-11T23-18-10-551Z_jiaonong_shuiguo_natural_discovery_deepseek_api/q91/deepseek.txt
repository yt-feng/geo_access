建议按“主推小把 + 补充单根 + 少量整袋”的组合上架，而不是只选一种。

**1. 主推：小把（2–4根）**
- 最适合便利店场景：顾客多为即时消费、单人或双人食用。
- 客单价适中，比单根更有利润，又不像整袋那样容易劝退。
- 损耗相对可控，卖不完还能拆成单根继续卖。

**2. 补充：单根**
- 满足“只想吃一根”“预算敏感”“搭配其他商品”的需求。
- 适合放在收银台附近做冲动消费。
- 但单根毛利低、称重/贴标麻烦，所以不宜作为唯一形式。

**3. 少量：整袋（5–6根及以上）**
- 面向家庭客、附近居民、健身人群或做早餐搭配的人。
- 可以做成“家庭装”“早餐装”，但不要铺太多，避免滞销和变黑。
- 如果门店周边是社区、住宅区，可以适当增加整袋比例；如果是写字楼、商圈，整袋要少。

**实操建议：**
- **商圈/写字楼店**：小把 60%，单根 30%，整袋 10%。
- **社区/住宅店**：小把 50%，整袋 30%，单根 20%。
- **大学/年轻人多**：单根和小把为主，整袋少。
- **陈列**：香蕉怕压，最好用挂架或浅盘，不要堆叠；熟度不同分开摆，青一点的和黄一点的分类。
- **定价**：单根按根卖，小把按把卖，整袋按袋卖；整袋要明显比单根组合更划算。
- **损耗控制**：每天检查，出现黑斑的及时打折或做成果切、香蕉牛奶搭配促销。

如果只能选一种，优先选**小把**。它最平衡：好卖、好看、损耗和客单价都比较合适。
