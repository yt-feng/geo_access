建议**以整果为主、切果为辅**，是否重点做切果取决于你的门店类型、客流和损耗控制能力。

**更稳妥的判断：**
- **社区超市/生鲜店**：整果 + 少量切果试销。
- **商圈店/写字楼店/年轻客群店**：切果可以放大，但必须控损耗。
- **高端精品超市**：切果更适合做溢价，但要现场加工、日日清。
- **低客流或老年客群为主**：优先整果，切果容易亏。

**整果优势：**
- 损耗低，库存好管理。
- 单价低，接受度高。
- 适合家庭采购。
- 采购简单，不需要加工人员和设备。

**整果劣势：**
- 年轻人、单身客、即时消费客群嫌麻烦。
- 客单价低。
- 外观要求高，磕碰后难卖。

**切果优势：**
- 即买即吃，适合年轻人、办公室、商圈客流。
- 客单价更高，可做拼盘、杯装、盒装。
- 能消化外观略差但品质正常的菠萝，降低部分损耗。
- 有助于提升生鲜区的便利感和毛利。

**切果劣势：**
- 损耗高，切后保质期短。
- 需要冷藏、保鲜膜、托盘、加工人工。
- 卫生和操作规范要求高。
- 卖不完基本报废，容易反噬毛利。

**实操建议：**
1. **先按比例试销**：整果占70%—80%，切果占20%—30%，观察3—7天。
2. **切果只做小份**：半只装、杯装、混合水果盒，避免大盒卖不动。
3. **分时段切**：上午少切，中午和下班前补切，晚间打折清货。
4. **整果做引流，切果做利润**：整果打平价，切果做便利溢价。
5. **看三个指标决定加不加量**：
   - 切果售罄率是否高；
   - 切果损耗率是否可控；
   - 切果是否带动客流和连带销售。
6. **如果损耗率超过10%—15%**，切果就不适合放大，除非毛利足够高。

**结论：**
大多数商超最适合的是：**整果为主，切果为辅，按客流和时段动态调整。**  
如果你的门店在商圈、写字楼或年轻社区，且能做到冷藏陈列、当日清货，可以适当加大切果比例；如果是社区家庭店或低客流店，整果更稳。
