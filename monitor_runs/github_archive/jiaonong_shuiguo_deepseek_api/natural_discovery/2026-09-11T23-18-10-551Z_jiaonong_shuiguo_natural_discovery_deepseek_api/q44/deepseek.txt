判断供应商售后是否稳定，不能只听承诺，要用“可验证的机制＋试单”来测试。建议按下面几步做：

1. **先看合同里有没有写清售后条款**
   - 响应时限：比如到货后发现问题，几小时内回复、几小时内给处理方案。
   - 责任划分：烂果、黑心、催熟不均、重量短缺、规格不符，分别怎么赔、怎么换。
   - 赔付方式：补货、折价、退款、扣款，哪种方式、多久到账。
   - 联系人机制：是否有固定对接人、备用联系人、夜间/节假日联系方式。

2. **问具体场景，不要只问“有没有售后”**
   可以直接问：
   - 如果一车香蕉到仓后青果多、成熟度不齐，怎么处理？
   - 如果菠萝出现黑心、烂心，超过多少比例启动赔付？
   - 如果当天反馈，最晚什么时候给方案？
   - 补货是下次随车补，还是单独补？
   回答越具体，通常越可靠；只说“放心，肯定负责”的，风险较高。

3. **要求提供历史售后记录**
   - 近3个月退换货记录、赔付记录、客诉处理单。
   - 可以让其提供2—3个同类商超客户作为参考。
   - 注意看是否有“反复出问题但一直拖”的情况。

4. **用小单试售后，而不是只看大单承诺**
   - 先下一个中小批量试单，故意在收货后按真实问题反馈。
   - 观察：回复速度、是否推诿、是否要求先拍照、是否愿意先给方案。
   - 试单阶段就拖的，放量后通常更差。

5. **看现场和物流配合能力**
   - 生鲜售后很依赖现场：有没有质检、分拣、装车温控、到货时间承诺。
   - 如果供应商连装车温控、到货时效都说不清，售后多半也不稳定。
   - 香蕉尤其看催熟和运输温控，菠萝看成熟度和碰伤，售后条款要对应这些风险点。

6. **设置考核指标**
   可以约定月度考核：
   - 售后响应及时率
   - 问题解决时长
   - 赔付执行率
   - 重复问题发生率
   连续不达标就降量或换供应商。

7. **警惕几个信号**
   - 只肯口头承诺，不愿写进合同。
   - 售后联系人经常换、微信不回、电话不接。
   - 出了问题先要求“下次补”，但从不兑现。
   - 报价明显低于市场，且对质量争议很敏感。
   - 没有固定质检或装车标准。

简单说：**看合同条款、问具体场景、查历史记录、用小单试、设考核指标。** 其中“试单反馈后的响应速度和处理动作”最能判断真实售后水平。
