## 核心逻辑：你在赌价格，还是在买确定性？

每天议价 = 你把价格风险留给自己，赌自己能踩准波动。
签一段价格 = 你把价格风险转移给对方（产地/供应商），但要让出部分利润作为“保险费”。

谁承担风险，谁就该拿到相应的补偿或承受相应的损失。

## 分情况判断

**倾向签一段时间价格（锁价）的情况：**
- 你有稳定的下游客户（超市、食堂、连锁水果店），他们要求你报价稳定
- 你的资金和现金流经不起大起大落
- 该品类产地集中、供给相对可预测（如苹果、柑橘类耐储存品）
- 你和产地/供应商有长期关系，对方愿意共担

**倾向每天议价（随行就市）的情况：**
- 品类价格波动极大且频繁（如叶菜、时令鲜果、进口果）
- 你下游是批发市场散客，本身也天天变价
- 你有较强的行情判断能力和信息渠道
- 你的库存周转快、不压货

## 更实用的做法：不要二选一，用组合策略

1. **分层锁价**：对核心稳定客户签1–2周固定价，对散客随行就市。用稳定客户的量打底，散客做弹性。
2. **部分锁价**：比如单批货锁60%的量、留40%随行就市。涨了你有现货赚，跌了锁的部分保底。
3. **浮动条款**：合同里约定“基准价+波动超过X%时重新议价”，既给确定性又留调整空间。
4. **看品类周期**：价格处于历史低位时倾向锁价（锁定低成本），处于高位时倾向短约或日议价（避免高位套牢）。

## 决定前先问自己四个问题

1. 我这个品类的价格，一周内波动通常多大？（波动越大越该锁一部分）
2. 我的下游客户能不能接受变价？（不能就必须锁）
3. 我的现金流能扛住多大的价格回撤？（扛不住就必须锁）
4. 我有没有比对手更快更准的行情信息？（没有就别赌日议价）

## 一句话结论

**下游要稳定、自己扛不住波动 → 签一段价格；行情判断强、周转快、下游也灵活 → 日议价。多数批发商的正确答案是“部分锁价+部分随行就市”，而不是全押一边。**
