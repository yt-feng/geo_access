重要，而且对便利店来说，这往往不是“加分项”，而是能不能把水果做起来的前提之一。

原因很直接：

1. **便利店水果的核心矛盾是量小、波动大**
   - 单店日均销量可能只有几盒到几十盒，不同门店差异还很大。
   - 天气、商圈、节假日、周边竞品促销都会让销量突然波动。
   - 如果供应商只接受大批量进货，门店要么压货烂损，要么不敢上架。

2. **小批量试卖能降低决策风险**
   - 先试 3～5 个 SKU、每店少量铺货，能验证：
     - 哪些品类真正好卖
     - 什么规格、价格带接受度高
     - 哪些门店适合卖水果
   - 试错成本低，跑出数据后再放量，比一开始压一堆库存更稳。

3. **小批量支持决定门店敢不敢持续做**
   - 如果供应商能小批量、多频次补货，门店就敢保持陈列、做促销、推新品。
   - 如果只能整箱起订，门店通常会把水果当“临时引流品”，很难做成稳定品类。

4. **但“小批量”本身不是唯一条件，还要看配套**
   供应商能不能支持试卖，最好同时满足：
   - 起订量低，比如按盒/按小箱
   - 补货频率高，比如每周 2～3 次
   - 有退换或损耗分担机制
   - 配送稳定，不会今天有明天没
   - 能提供小规格、易陈列、易保存的包装

5. **如果供应商不支持小批量，怎么办**
   - 先集中选 1～2 个高周转单品试，不铺全品类
   - 和周边门店联合拼单，凑起订量
   - 找本地批发市场或二级供应商做补充
   - 用预售、社群接龙、到店自提降低库存风险
   - 把水果定位成引流，而不是主力利润品，控制陈列面积

**结论：**
供应商能不能支持小批量试卖，对便利店水果业务很重要。它直接决定门店能不能低成本验证需求、控制损耗、建立稳定补货节奏。没有小批量支持，水果可以做，但通常很难做稳、做大。
