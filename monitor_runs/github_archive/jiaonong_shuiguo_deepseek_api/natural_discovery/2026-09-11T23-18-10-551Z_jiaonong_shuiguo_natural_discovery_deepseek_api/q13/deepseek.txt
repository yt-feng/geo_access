小水果店做附近小区团购，水果供应商至少要能支持这几类服务，否则你后面会很容易被损耗、售后和配送拖垮：

1. **稳定供货与每日报价**
   - 能提前给次日或未来几天的报价单、规格、产地、等级。
   - 价格波动大的水果，最好能锁定当天或短期价格。
   - 能稳定供货，不是今天有明天没。

2. **按团购规格分拣打包**
   - 支持按你需要的份量分装，比如5斤装、3斤装、家庭装、尝鲜装。
   - 能贴标签、按小区或订单分框。
   - 最好能帮你做简单预分拣，减少店里人工。

3. **质量分级与坏果赔付**
   - 明确果径、甜度、成熟度、外观标准。
   - 支持到货后一定时间内坏果、烂果、压伤赔付。
   - 赔付方式要清楚：补货、扣款还是下次抵扣。

4. **冷链或保鲜配送**
   - 易坏水果如草莓、蓝莓、荔枝、葡萄，需要冷藏或冷链。
   - 普通水果也要有周转筐、防压包装。
   - 能按你截单时间配送到店或指定自提点。

5. **支持小批量、多频次补货**
   - 团购最怕一次压太多货。
   - 供应商最好能支持今天下单、明天到，或者一周多次补货。
   - 起订量不要太高，适合小水果店试水。

6. **售后响应快**
   - 有专门对接人，不是出了问题找不到人。
   - 坏果、少货、错货能当天或次日处理。
   - 能配合你给小区团长、顾客做售后。

7. **提供素材和卖点**
   - 水果图片、视频、产地信息、口感描述、保存方法。
   - 最好能给你统一话术，方便发小区群。
   - 有检测报告、产地证明更利于建立信任。

8. **结算灵活**
   - 支持日结、周结、月结，或押金+账期。
   - 对账清晰，按订单、品类、重量能核对。
   - 避免经常临时加价或隐藏运费。

9. **能配合做爆品和活动**
   - 团购需要引流品、利润品、搭配品。
   - 供应商能给你推荐当季爆款、组合套餐。
   - 活动期能保证货源，不临时断供。

10. **退换货和临期处理**
   - 没卖完或品质不达标时，能否退换。
   - 临期水果能否支持调换或折价处理。
   - 这点对小店现金流和损耗控制很关键。

你筛选供应商时，最该先问清楚这5个问题：
1. 起订量多少，能不能小批量多频次送？
2. 坏果怎么赔，多久内有效？
3. 能不能按团购份量分拣打包？
4. 配送频次和截单时间是什么？
5. 结算方式、账期、运费怎么算？

如果供应商只能做到“整车批发、不赔坏果、不拆包、不常送”，那更适合大店或批发市场，不太适合你做小区团购。小水果店做团购，核心不是找最便宜的，而是找**损耗低、售后快、补货灵活**的供应商。
