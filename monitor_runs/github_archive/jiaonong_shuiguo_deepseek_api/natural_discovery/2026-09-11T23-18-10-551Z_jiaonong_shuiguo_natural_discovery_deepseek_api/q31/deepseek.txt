连锁商超找长期水果供应商，评分标准的核心不是“谁报价低”，而是**在可稳定交付合格果品的前提下，综合成本最优、风险最低**。建议按百分制设置，权重可参考：

**一、报价与成本结构（30–40分）**
不要只看单品报价。要求供应商按品类报出：
- 含税到仓价、起订量、账期接受度
- 季节性价格波动机制
- 损耗承担方式（到仓前损耗、验收后损耗）
- 促销/临期/尾货处理价格

评分时可用“基准价/投标价×分值”，同时设异常低价审查，防止中标后断供或降质。

**二、质量与食品安全（25–30分）**
这是水果供应商的生死线，建议设为硬门槛+评分项：
- 农残检测报告、承诺达标合格证、产地证明
- 是否有自有基地或稳定合作基地
- 分选、预冷、冷藏、包装能力
- 到货合格率、客诉率、退货率的历史数据
- 是否接受商超飞检、第三方抽检

可规定：连续两次抽检不合格直接取消资格。

**三、供应稳定性与履约能力（15–20分）**
- 日均/峰值供应能力
- 多产地调配能力，能否应对台风、寒潮、减产
- 冷链车辆、仓储、配送时效
- 缺货替代方案
- 历史履约率、准时到货率

长期供应商最怕“旺季掉链子”，这部分权重不能低。

**四、品类匹配与商品力（10–15分）**
- 是否覆盖商超核心品类：苹果、柑橘、香蕉、葡萄、瓜类、浆果等
- 能否做差异化单品、地标产品、自有品牌定制
- 分级标准是否与商超客群匹配
- 新品开发和季节切换能力

**五、服务与协同（5–10分）**
- 对账、退换货、售后响应速度
- 是否配合门店促销、堆头、节日备货
- 信息化对接能力：订单、库存、溯源数据
- 驻场或区域服务团队

**六、企业资质与可持续性（5–10分）**
- 营业执照、食品经营许可、种植/加工资质
- 财务状况、诉讼与失信记录
- 食品安全事故、行政处罚历史
- 环保、用工合规

**建议的评标结构：**
- 技术/质量/履约：60–70分
- 价格：30–40分
- 商务资信：作为门槛或少量加分

**关键控制条款：**
1. 设置资格门槛：检测、冷链、供应能力不达标直接废标。
2. 价格分不唯低：低于成本价需书面说明。
3. 引入样品盲测和试供期：中标后先试供1–3个月。
4. 动态考核：季度评分，连续不达标降级或退出。
5. 多源供应：主供应商+备选供应商，避免单一依赖。

一句话：**水果长期供应商的评分，要把“质量安全、稳定履约、综合成本”放在前三，价格只是其中一项。**
