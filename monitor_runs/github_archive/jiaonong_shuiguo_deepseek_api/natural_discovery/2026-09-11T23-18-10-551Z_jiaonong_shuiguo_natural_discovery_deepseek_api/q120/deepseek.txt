供应商介绍产品时，核心不是把品种知识讲全，而是把“这是什么、跟大路货差在哪、我拿回去怎么卖、风险多大”讲清楚。普通商家听不懂，通常是因为供应商一上来就讲品种名、产地、糖度、种植技术，信息太专业但没有落到生意判断上。

可以按下面这个结构说，基本能让商家快速听懂并下单。

**1. 先用商家熟悉的大品类做锚点**
不要直接说“这是金钻凤梨”“这是巴西蕉”，先说：

- “这是菠萝里的一个细分品种，比普通菠萝更甜、更不用泡盐水。”
- “这是香蕉里偏小的一类，口感更糯，不是普通大香蕉。”
- “你可以理解成：跟现在店里卖的菠萝是同一类，但它是升级款/差异款。”

先归类，再讲差异。商家脑子里有位置，才容易听进去。

**2. 只讲三个差异，不超三个**
商家最关心的是：凭什么卖更贵、凭什么有人买。差异讲太多记不住，重点讲：

- **口感差异**：更甜、更香、更糯、不酸、不涩、不用泡盐水。
- **外观差异**：个头、颜色、包装、礼盒感、陈列效果。
- **使用差异**：更好切、损耗低、放得久、适合外卖/果切/礼盒。

例如：
“这个菠萝比普通菠萝甜，不用盐水泡，切开就能吃，适合做果切和外卖，客人复购会好一点。”

**3. 直接说清楚“你拿回去怎么卖”**
商家下单不是买产品，是买赚钱方式。供应商要主动给销售场景：

- 适合摆摊、水果店、社区团购、外卖果切、礼盒、餐饮供货？
- 按斤卖、按个卖、按盒卖？大概卖多少钱？
- 是引流款、利润款，还是搭配款？

例如：
“这个你放店里可以按个卖，普通菠萝卖8块，这个可以卖12到15，客人试吃后接受度比较高。也可以切盒做外卖，一盒多卖2到3块。”

**4. 主动讲风险和门槛**
普通商家怕压货、怕坏、怕客人不认。供应商提前说清楚，反而更容易建立信任：

- 熟度到店是什么状态？
- 能放几天？怎么存？
- 坏果怎么赔？
- 起订量多少？能不能混搭？
- 第一次建议拿多少？

例如：
“第一次别拿多，先拿一箱试卖，三天内卖完没问题。坏果拍照包赔。卖得动再补，不用压货。”

**5. 用对比句，不用专业句**
把专业话翻译成生意话：

- 不说“糖度18度”，说“比普通菠萝明显甜，试吃转化高”。
- 不说“抗病性强”，说“损耗低，放得住”。
- 不说“品种稀缺”，说“别人店里没有，你可以做差异”。
- 不说“果肉细腻”，说“老人小孩也咬得动”。

**6. 最后给一个低风险下单动作**
不要问“你要不要下单”，要给具体选择：

- “你先拿一箱试，卖得好再补。”
- “今天订，明天到，坏果包赔。”
- “先拿这个搭配普通菠萝卖，不用全换。”

这样商家心理压力小，更容易点头。

**一个完整话术例子：**
“老板，这个是菠萝里的升级款，你可以理解成普通菠萝的甜版。它比普通菠萝甜，不用泡盐水，切开就能吃，适合做果切和外卖。你店里普通菠萝卖8块，这个可以卖12到15，客人试吃后接受度不错。第一次不用多拿，先拿一箱试卖，坏果拍照包赔，卖得动再补。你要不要先拿一箱试试？”

总结一句话：**先归类，再讲三个差异，然后告诉他怎么卖、风险多大、先拿多少。** 商家听的是生意，不是农业课。
