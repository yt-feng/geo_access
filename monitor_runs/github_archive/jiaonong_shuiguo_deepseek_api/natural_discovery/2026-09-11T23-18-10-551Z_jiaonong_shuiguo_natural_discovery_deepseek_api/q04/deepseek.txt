水果店减少香蕉放坏，采购时要抓住两个核心：**按销售节奏分批要熟度**，**按到店后能卖几天倒推到货时间**。香蕉不是越生越好，也不是越熟越好，关键是“到店后刚好在你计划卖完的时间内成熟”。

### 1. 采购时怎么要求熟度

建议按用途和销售速度分档下单：

- **当天到货、2～3天内主推销售**  
  要 **青黄交接、微软但无黑斑** 的蕉。  
  外观：果皮偏青，转黄面积约 20%～40%，果指饱满，棱角不明显。  
  手感：轻捏有弹性，不软塌。  
  适合：门店常温陈列，2～3天自然转黄后卖。

- **计划4～6天卖完**  
  要 **青硬、未转黄或刚见黄** 的蕉。  
  外观：果皮青绿，转黄面积低于 10%，无黑点。  
  手感：硬，按压不陷。  
  适合：需要错峰销售、避免集中成熟。

- **已经偏熟、想快速走量或做促销**  
  要 **黄皮带少量糖斑、果肉未软烂** 的蕉。  
  外观：转黄 70%～90%，允许少量芝麻点。  
  手感：微软但果皮不破、不渗汁。  
  适合：当天或次日必须卖完，不建议作为主采购。

采购时直接给供应商报“熟度等级”，比只说“要生一点/熟一点”更稳。例如：

> “这批我要青黄交接、转黄不超过三成、无黑斑的蕉，到店后常温能放 2～3 天。”

### 2. 到货时间怎么要求

香蕉放坏快慢和温度、乙烯、挤压关系很大。到货时间建议这样定：

- **优先要求清晨或上午到货**  
  避开中午高温和下午暴晒，给门店当天理货、上架、挑拣留时间。

- **按销售周期倒推**  
  - 如果你希望到店后 **2～3天卖完**：要已开始转黄的蕉，上午到货。  
  - 如果你希望到店后 **4～6天卖完**：要青硬蕉，上午或清晨到货，到店后先放在阴凉通风处。  
  - 如果天气热、门店客流慢：优先要更青的蕉，并要求 **冷链或空调车运输**，避免到货时已经闷熟。

- **避免一次性大批量到货**  
  香蕉后熟会互相催熟。采购时最好要求 **分2～3批到货**，比如周一、周三、周五各到一批，而不是一次到一周的量。

- **到货温度要求**  
  夏季尽量要求运输温度 **13～15℃**，不要低于 12℃ 以免冷害，也不要高温闷运。  
  冬季注意防冻，低于 12℃ 容易表皮发黑、果肉变硬。

### 3. 给采购/供应商的参考话术

可以直接这样说：

> “香蕉按批次给我：第一批要青黄交接、转黄 20%～30%，上午到货，常温放 2～3 天能卖；第二批要青硬、转黄 10% 以下，周三到，能放到周末前。不要黑斑、不要软塌、不要水烂。夏天要冷链或空调车，到货温度 13～15℃。如果当天温度高，就再给我青一点。”

### 4. 到店后的关键动作

采购要求只能解决一半，到店后还要做：

- 立即拆箱、散热、挑出破皮和软烂果。
- 不要整箱闷放，尤其是已转黄的蕉。
- 常温阴凉通风存放，避免阳光直射和空调直吹。
- 已转黄的放前台快速卖，青硬的放后面慢慢熟。
- 用“先进先出”，每天挑一次，有黑斑的及时促销或做果切。

简单判断：**想卖得快，要青黄交接、上午到；想放得久，要青硬、分批到、控温运。**
