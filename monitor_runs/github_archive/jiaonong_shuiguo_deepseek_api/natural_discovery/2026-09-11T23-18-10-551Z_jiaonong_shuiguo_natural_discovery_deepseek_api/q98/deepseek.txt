判断供应商合规与稳定性，关键是“证件核验 + 实物流验证 + 财务约束”三条线同时做，不能只看报价低。

**一、合规审查（硬门槛，缺一不可）**

1. **主体资质**：营业执照经营范围须含“食用农产品销售/食品销售”；要求提供原件照片或现场核验，并核对法人、地址与对公账户一致。
2. **食品经营许可**：销售预包装/散装食品需《食品经营许可证》；仅卖初级农产品（未加工水果）部分情形可豁免，但仍建议要求提供，便于追溯。
3. **进货与检测凭证**：每批次提供产地证明或进货凭证、农残快检报告（或第三方检测报告）。养老院/医院属高风险供餐单位，建议要求每批可查。
4. **人员与运输**：送货人员健康证；冷链或保鲜车辆证明（尤其夏季、切果配送）。
5. **票据与开票能力**：能开正规发票，走对公账户，避免个人转账。这是后续追责和审计的基础。

**二、稳定性验证（看“能不能持续供”）**

1. **上游来源**：是自有基地、批发市场档口，还是二级转手？转手层级越多越不稳。要求说明主要产地和替代产地。
2. **供应能力**：问旺季/淡季日供量、断供时的备选方案、是否有冷库或合作仓储。
3. **历史履约**：要求提供近6个月与其他机构（学校、医院、养老院）的合作记录或合同复印件（可脱敏），并电话回访1—2家。
4. **抗风险**：极端天气、疫情、节假日涨价时是否锁价？是否有书面保供承诺？
5. **现场考察**：去仓库/档口看库存周转、卫生、分区、残次果处理。周转快的供应商通常更稳。

**三、落地管理机制（比选供应商更重要）**

1. **先小批量试供**：1—2周试供，观察准时率、损耗率、重量是否足、品质是否稳定，再签正式合同。
2. **合同写清**：品名、规格、单价或调价机制、配送频次、验收标准、退换货时限、缺货违约金、食品安全责任与赔偿。
3. **验收留痕**：每次送货称重、拍照、记录批号；建立台账，出现问题时能追溯到批次。
4. **定期复评**：每季度看准时率、投诉率、退换率、检测合格率，不达标就启动备选供应商。
5. **保持双供应商**：主供+备供，避免单一依赖，这是养老院/医院最实用的稳定性保障。

**四、快速识别风险信号**

- 只肯现金/个人收款、不愿开票；
- 无法提供任何批次检测或产地凭证；
- 报价明显低于市场且拒绝解释来源；
- 送货时间、品质频繁波动；
- 对接人频繁更换、公司注册时间短且无实际经营场所。

**建议操作顺序**：先查证照和票据能力 → 再要检测与产地凭证 → 实地看仓 → 小批量试供 → 签合同并保留备选供应商。这样既能过合规审计，也能把断供和食安风险压到最低。
