香蕉配送中最容易出问题的不是“压坏”，而是**催熟过快、机械伤后褐变、温度波动导致黑斑**。要控制，核心是：**选对成熟度 + 减少碰撞 + 控温控乙烯 + 缩短在途时间**。

### 1. 不要发全熟香蕉
- 最好发**青熟期**或**微黄期**香蕉，到消费者手里再自然转黄。
- 如果发已经全黄、带糖斑的香蕉，配送中几乎必然变黑。
- 按距离定成熟度：
  - 同城/半日达：可发微黄；
  - 跨城/次日达：发青熟；
  - 偏远/隔日以上：更青，但口感风险高，需配合催熟说明。

### 2. 包装重点防“压”和“磨”
- 用**带凹槽的纸浆托盘/珍珠棉托**单根固定，避免相互摩擦。
- 香蕉之间不要裸放，尤其不能和硬物混装。
- 整串卖可用**气柱袋或珍珠棉包裹整串**，再放入纸箱。
- 纸箱内留缓冲，但不要过松，避免运输中晃动碰撞。
- 箱体打透气孔，不能完全密封闷着。

### 3. 控制温度，不要忽冷忽热
- 香蕉对低温敏感，**低于12℃容易冷害，之后更快发黑**。
- 配送温度尽量在**13～15℃**左右，至少避免冷藏直吹。
- 夏季用**泡沫箱+冰袋**时，冰袋不能直接贴香蕉，要隔层。
- 冬季防冻，避免放在无保温的车厢外层。
- 最怕的是：冷库取出→常温暴晒→再进冷车，反复波动。

### 4. 减少乙烯和呼吸热
- 香蕉自身释放乙烯，会催熟自己和其他水果。
- 不要和苹果、梨、番茄等乙烯释放大的果蔬混装。
- 包装内可放**乙烯吸收剂**，但要注意食品接触安全。
- 装车前预冷，但香蕉不宜深度预冷，目标是去掉田间热、稳定温度。
- 配送箱不要长时间密闭积热，尤其夏季车厢内温度很高。

### 5. 缩短在途和分拣时间
- 香蕉每多一次分拣、中转，就多一次碰撞和温度波动。
- 尽量**产地/仓直发**，减少中转。
- 同城优先当日达，跨城优先次日达。
- 分拣时轻拿轻放，避免扔件、堆压。
- 配送员末端配送时不要放在暴晒的车筐、后备箱高温处。

### 6. 到货后引导消费者处理
- 收到后如果还青，放室温阴凉处自然熟。
- 不要立刻放冰箱，未熟香蕉放冰箱会冷害、变黑。
- 熟后再吃；如果已经熟透，可冷藏1～2天但表皮仍可能变黑。
- 在详情页提前说明：**轻微表皮黑点不等于坏，青蕉需催熟**，能减少售后。

### 7. 最实用的组合方案
如果是生鲜电商常规配送，建议：

**青熟香蕉 + 珍珠棉/纸浆托固定 + 透气纸箱 + 13～15℃运输 + 乙烯吸收剂 + 同城/次日达 + 到货催熟说明。**

这样做能明显降低压坏和变黑，但无法做到“全熟香蕉长途配送还不黑”。如果要做精品，最好卖**青熟蕉**，把“到货后熟”作为卖点，而不是追求发货时已经全黄。
