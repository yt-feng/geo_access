超市和水果供应商的账期没有统一标准，主要看**品类特性、渠道类型、供应商规模、双方议价权**。给你一个比较实用的判断框架：

## 常见账期区间

| 场景 | 常见账期 | 说明 |
|---|---|---|
| 大型连锁超市 + 大型供应商 | 30–60天 | 最常见是45–60天，从对账确认后起算 |
| 中小超市 + 本地批发商 | 7–30天 | 现结、周结、半月结都常见 |
| 生鲜水果（高损耗品类） | 7–15天居多 | 账期明显短于标品，因为损耗和资金占用高 |
| 产地直采/季节性水果 | 现结到15天 | 供应商资金压力大，往往要求预付或短账期 |
| 强势连锁（如部分全国性商超） | 60–90天 | 供应商议价弱时可能更长，甚至压到90天+ |

## 关键点

1. **水果是生鲜，账期天然比包装食品短。** 一般标品可以给到60–90天，水果通常做不到，供应商宁愿降价也不愿长账期。

2. **起算点很关键。** 是“送货日”“对账日”还是“开票日”？行业里常见的是**每月固定对账日对账，对账后30–60天付款**。谈的时候要写清楚。

3. **账期和价格是一对谈判筹码。** 
   - 你要长账期，供应商大概率提价；
   - 你给短账期或现结，通常能拿到更低进价或更好货源。

4. **对中小超市来说，现实选择是7–30天。** 想拿60天以上，要么你采购量大且稳定，要么你有很强渠道地位，否则供应商会转嫁成本或断供。

## 给你的建议

- 如果是**新合作、量不大**：先谈周结或半月结，建立信任后再延长。
- 如果是**稳定大超市**：目标30–45天，水果这个品类不要硬压到60天以上，容易拿不到好货。
- 合同里必须明确：对账周期、付款起算日、逾期利息、质量扣款规则。
- 别只看账期，算**综合成本**：进价 + 损耗 + 账期资金成本。

**一句话结论：水果供应商账期常见7–30天，大型商超稳定合作可到45–60天，60天以上属于强势渠道压价，通常伴随更高进价或更差货源。**
