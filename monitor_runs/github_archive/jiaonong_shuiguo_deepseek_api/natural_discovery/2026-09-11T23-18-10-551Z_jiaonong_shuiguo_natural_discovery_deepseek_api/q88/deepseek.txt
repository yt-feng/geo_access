线上水果销售，差评主要来自两件事：**坏果（腐烂、压伤、霉变）** 和 **口感不稳定（不甜、发酸、发绵、没熟/过熟）**。这两件事主要不是“卖”的问题，而是**采购和供应链**的问题。要减少，重点抓下面几件事：

**1. 先定“可接受标准”，不要只凭感觉收货**
采购前就要写清楚：
- 品种、产地、规格（单果重、果径）
- 成熟度（几分熟采摘）
- 糖度范围（比如可溶性固形物≥多少）
- 硬度、颜色、瑕疵允许比例
- 坏果率、压伤率、软果率上限

没有标准，采购就变成“看运气”，口感自然不稳定。

**2. 按销售半径和时效倒推成熟度**
- 近城次日达：可以采成熟度稍高，口感更好。
- 跨省2—4天：要采稍生一点，但必须能后熟且后熟均匀。
- 远距离或天气热：成熟度越高，坏果风险越大。

最怕的是：**为了口感采太熟，结果路上烂；为了不烂采太生，结果客户收到酸涩。** 所以要按线路定采摘成熟度，而不是全渠道一个标准。

**3. 产地端做分级，不要“统货混装”**
采购时尽量要求产地做：
- 大小分级
- 成熟度分级
- 瑕疵果剔除
- 软果、裂果、虫果、霉果单独处理

统货看起来便宜，但售后和差评成本通常更高。线上销售尤其要避免“上层好果、下层坏果”。

**4. 重点控制采摘和采后预冷**
很多坏果不是运输坏，是采后没及时降温。
- 高温季节采摘后尽快预冷
- 避免暴晒、堆压、长时间常温放置
- 草莓、蓝莓、荔枝、杨梅等娇气品类，预冷和冷链要求更高

口感不稳定也常和采后呼吸、失水有关，预冷做得差，糖度没变但口感会明显下降。

**5. 包装要按品类设计，不能一套包打天下**
- 易压伤：单果托、蛋托、格挡、气柱
- 易失水：保湿但不要闷烂
- 易后熟：适当透气
- 易冻伤：冬季防冷害

包装的目标不是“好看”，而是**减少挤压、摩擦、晃动和温湿度波动**。

**6. 采购时做小批量试销，不要一次压大货**
新产地、新供应商、新品种，先小批量走一遍完整链路：
- 采摘
- 分选
- 包装
- 运输
- 到货
- 放1—2天
- 试吃口感
- 统计坏果率

试销数据比产地口头承诺可靠。连续几批稳定，再放量。

**7. 建立批次验收和留样**
每批到货抽检：
- 坏果率
- 压伤率
- 糖度
- 硬度
- 口感
- 重量是否达标

留样拍照、记录批次。出现差评时，能快速判断是产地问题、运输问题还是仓储问题。没有批次管理，最后只会互相扯皮。

**8. 供应商要分级，不要只比价**
靠谱供应商通常具备：
- 能按标准分级
- 有预冷和冷链能力
- 愿意承担坏果售后
- 发货稳定
- 能提供采摘和批次信息

只拼低价的供应商，往往用统货、早采、混装来补利润，最后差评由你承担。

**9. 仓储和发货环节也要控**
- 先进先出
- 按成熟度分区
- 每天挑软果、坏果
- 高温天控制打包环境温度
- 避免发货前长时间积压

很多坏果是“到仓时还好，发出去时已经放坏了”。

**10. 售后规则要前置**
详情页和客服话术里明确：
- 哪些属于正常外观差异
- 哪些属于坏果包赔
- 怎么拍照理赔
- 口感主观差异怎么处理

这不是采购问题，但能减少口感类差评扩大化。

**一句话总结：**
减少坏果，靠**成熟度控制、预冷冷链、分级包装、批次验收**；减少口感不稳定，靠**品种产地固定、采摘标准、糖度硬度抽检、按线路定成熟度**。最有效的做法是：**先定标准，再小批量试销，用数据筛供应商，而不是靠感觉压货。**
