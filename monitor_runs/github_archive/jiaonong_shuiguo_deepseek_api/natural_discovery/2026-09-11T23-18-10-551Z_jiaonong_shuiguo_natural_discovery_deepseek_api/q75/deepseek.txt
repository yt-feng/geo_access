第一次合作就按“小批量、多维度、可复盘”来设计，核心目标不是赚钱，而是验证供应商的**品质稳定性、履约可靠性、价格真实性和售后态度**。

**一、先定试单目标（别只想着采一车货）**

建议明确4个验证点：

1. 品质是否稳定：同批次内差异大不大，大小、熟度、损耗是否可控。
2. 履约是否靠谱：能否按约定时间、数量、规格到货。
3. 价格是否有优势：含运费、损耗、扣重后，实际成本是否低于现有渠道。
4. 售后是否认账：坏果、短装、规格不符时，是否补发、退款或下次抵扣。

**二、试单规模怎么定**

按“可承受损失”倒推，不要按“想拿低价”倒推。

- 金额：控制在日常单品单次采购额的10%—20%，或你能接受全部损耗也不影响现金流的范围。
- 数量：建议从1—3个托盘、几十箱到一两百箱起步，具体看单品和物流。
- 品类：优先选1—2个你熟悉、好出手、周转快的单品，不要一次试很多品类。
- 规格：只试你最有把握卖的主流规格，不要为了低价拿偏门规格。

**三、试单必须写进合同或订单确认单**

至少锁定这些条款：

- 品名、品种、产地、等级、单果重/果径、糖度（如适用）、成熟度。
- 包装方式、每箱净重、毛重、箱规、托盘方式。
- 数量、单价、是否含税、是否含运费、装卸费谁承担。
- 到货时间、到货地点、收货人、验收时限。
- 扣重标准、损耗标准、坏果率上限。
- 售后规则：超过标准怎么赔、补、退，响应时间多久。
- 结算方式：建议首单“货到验收合格后付款”或“小比例定金+到货验收后尾款”，不要全款预付。

**四、验收要按标准做，不要凭感觉**

到货后建议当场或24小时内完成：

1. 点数：实际箱数、净重是否短装。
2. 抽检：随机开箱，不要只查表面箱。
3. 记录：拍照、视频、称重、坏果计数。
4. 分项判定：规格不符、成熟度不符、腐烂、压伤、冻伤、异味分别记录。
5. 出验收单：合格多少、扣款多少、退货多少、补发多少，双方确认。

**五、试单后怎么判断能不能继续合作**

建议用一张简单评分表：

- 品质合格率：低于95%要谨慎。
- 到货准时率：低于90%要谨慎。
- 短装/扣重异常：出现一次就要重点谈。
- 售后响应：24小时内不处理，基本不适合长期合作。
- 实际综合成本：把运费、损耗、扣重、资金占用算进去，再和现有供应商比。

**六、实操建议**

- 首单不要只谈价格，先谈标准和售后。
- 不要一次把全部采购量转过去，至少保留原有供应商。
- 试单最好连续做2—3次，因为一次好可能是运气，连续稳定才可靠。
- 如果供应商不愿明确规格、不愿承担合理售后、坚持全款预付，首单就要非常谨慎。
- 可以要求先寄样品，但样品只能看基本品质，不能替代到货验收。

一句话：首单设计成“小金额、清标准、严验收、可追责、能复盘”，比单纯追求低价更重要。
