## 两种机制的本质区别

| 维度 | 阶梯价 | 返利 |
|---|---|---|
| 激励时点 | 事前（下单即享） | 事后（达标后返还） |
| 客户感知 | 直观、即时、好比价 | 延迟、需要算账 |
| 供应商现金流 | 当期让利 | 延后支付，现金流友好 |
| 对客户约束力 | 弱（可只买一档就走） | 强（为拿返利持续冲量） |
| 适用心理 | 价格敏感、比价型 | 关系型、愿长期合作 |

---

## 怎么选：按客户类型判断

**1. 纯价格敏感、多头比价、随时会换供应商的客户**
→ 用**阶梯价**。他们要的是"看得见的低价"，返利对他们没有吸引力，因为不确定能不能拿到、也懒得等。

**2. 有稳定采购量、愿长期合作、但砍价很凶的客户**
→ 用**返利**。既保住了单价体面（不破坏价格体系），又把实惠给到，还能锁定全年采购量。

**3. 大客户/战略客户**
→ **阶梯价打底 + 年度返利封顶**。阶梯给基础竞争力，返利绑定年度总量和增量。

---

## 关键设计要点

**阶梯价：**
- 档位不要太多，3~4档为宜，档差要能刺激跳跃采购
- 最低档要守得住底线，避免被套到亏损
- 明确公布，作为"标准政策"，减少一对一谈判成本

**返利：**
- 门槛必须可达但有挑战（建议设在客户常规采购量的1.1~1.3倍）
- 返利形式优先用**货物/抵扣券**而非现金，锁定下次采购
- 设时间窗口（季度/年度），过期作废，制造紧迫感
- 返利比例阶梯化，避免"一刀切"

---

## 常见坑

1. **只给阶梯价**：客户买够一档就停，无法推动持续增量。
2. **只给返利**：价格敏感的客户根本不买账，直接流失。
3. **返利规则太复杂**：客户算不清就等于没有，还会引发结算纠纷。
4. **阶梯价公开 + 返利私下**：容易造成客户间比价矛盾，返利要设计成"统一政策"而非"特殊照顾"。

---

## 一句话决策

- 客户**只认低价、随时会跑** → 阶梯价
- 客户**有量、要长期、但压价狠** → 返利
- 客户**又大又重要** → 阶梯价保底 + 返利锁量
