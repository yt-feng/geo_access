社区超市卖小包装香蕉，核心矛盾是：**香蕉后熟快、怕压怕碰，小包装又会放大损耗和人工**。采购和包装要重点抓下面几件事。

**一、采购时要先定“规格”**
1. **按根重分级**  
   小包装通常按“把”或“根”卖，采购时就要明确：
   - 单根重量区间，比如 120–180g、180–250g；
   - 每包几根，比如 3 根、4 根、5 根；
   - 允许的果指长度和粗度。
   不要只按整箱毛重采购，否则分装后大小不一，顾客挑剩率高。

2. **控制成熟度**  
   小包装周转慢，采购成熟度要比大把香蕉略低。
   - 如果当天或次日能卖完，可选 3–4 成熟；
   - 如果预计卖 2–3 天，选 2–3 成熟更稳；
   - 已经黄熟、起芝麻点的，只适合做即时促销，不适合常规小包装。

3. **看果柄和果指状态**  
   优先选：
   - 果柄完整、切口干净；
   - 果指饱满、棱角不明显；
   - 无裂口、无黑斑、无压伤、无药害斑。
   果柄发黑、发霉、流汁的，分装后很容易整包烂。

4. **按销售场景定包装单位**  
   - 单人/小家庭：3–5 根一包；
   - 儿童零食：2–3 根一包；
   - 早餐搭配：4–6 根一包。  
   包装越大，客单价高但损耗风险也高；包装越小，损耗分散但人工和包材成本上升。

**二、包装要注意“透气、防压、防催熟”**
1. **不要完全密封**  
   香蕉会释放乙烯，密封后容易闷熟、发黑、出水。建议用：
   - 打孔保鲜袋；
   - 网套 + 透气标签；
   - 敞口托盘 + 收缩膜打孔。  
   如果必须用保鲜膜，要留透气孔。

2. **避免和催熟水果混放**  
   苹果、梨、猕猴桃、番茄等乙烯释放量高，和香蕉小包装放一起会加速变黄变黑。采购后仓储和陈列都要分开。

3. **防压防摩擦**  
   小包装最怕堆叠挤压。装箱时：
   - 单层摆放或加隔板；
   - 不要超过 2–3 层；
   - 果指朝上或侧放，避免果柄刺伤果皮；
   - 运输中减少晃动。

4. **包材要适配香蕉呼吸**  
   推荐：
   - 食品级打孔袋；
   - 网套；
   - 纸浆托盘；
   - 可降解透气膜。  
   不建议用完全密闭的硬盒，除非盒内有透气孔且能控制湿度。

**三、损耗控制要抓“采购量、陈列、折价”**
1. **小批量、高频次采购**  
   小包装香蕉不要一次进太多。可以：
   - 旺季每天补货；
   - 淡季隔天补货；
   - 按前 3–7 天销量预估，而不是按经验拍脑袋。

2. **先进先出，按成熟度分区**  
   店内至少分三区：
   - 未熟区：青黄，放后排或冷柜外；
   - 适熟区：黄亮，正常陈列；
   - 即食区：起斑，贴“即食优惠”或做试吃。  
   不要把所有成熟度混在一起卖。

3. **陈列温度要稳**  
   香蕉怕冷害，也怕高温。
   - 未熟香蕉：12–16℃左右较合适；
   - 已熟香蕉：10–13℃左右，但不宜长期低于 10℃；
   - 不要放冷柜风口直吹，也不要放暖气或阳光直射处。  
   社区超市如果没有专业催熟房，就靠采购成熟度来调节。

4. **设定损耗警戒线**  
   建议每天记录：
   - 进货根数/包数；
   - 销售包数；
   - 报损包数；
   - 折价处理包数。  
   如果某规格连续 3 天报损超过 8%–10%，就要调整采购量、包装根数或成熟度。

5. **及时折价和转化**  
   起斑但未坏的香蕉可以：
   - 做“即食香蕉”特价；
   - 切段试吃；
   - 搭配酸奶、燕麦做组合装；
   - 和烘焙区合作做香蕉蛋糕。  
   不要等到发黑出水才处理，那时只能报损。

**四、采购谈判和验收要写清楚**
和供应商约定：
- 成熟度范围；
- 单根重量和每包根数；
- 允许的机械伤、黑斑比例；
- 到货温度；
- 不合格怎么退换；
- 是否支持小批量高频配送。

验收时重点查：
- 箱内温度是否异常；
- 有没有压伤、裂口、发霉；
- 成熟度是否一致；
- 果柄是否新鲜；
- 单箱净重和根数是否达标。

**五、最实用的建议**
如果社区超市刚开始做，建议先试：
- **3 根一包，单根 150–200g，2–3 成熟采购，打孔袋包装，冷藏外陈列，每天补货。**
- 先试 1–2 周，记录销量和报损，再决定是否增加 4 根装、5 根装或即食装。

这样做的关键是：**采购定成熟度，包装保透气，陈列分成熟度，损耗靠高频小批量控制。**
