做家庭水果礼盒，建议优先考虑“常见、耐放、老少都能吃、开箱好看”这四个点。苹果、橙子、香蕉、菠萝里，最适合家庭组合的是：

**推荐组合：苹果 + 橙子 + 香蕉 + 菠萝（小份搭配）**
如果只选三种，更推荐：**苹果 + 橙子 + 香蕉**。  
如果做高端一点或节日款，再上：**苹果 + 橙子 + 菠萝**。

具体建议：

1. **苹果：做基础款，占比可以最大**
   - 优点：耐放、寓意好、家庭接受度高。
   - 建议选：红富士、冰糖心、嘎啦等。
   - 数量：大果 4—6 个，小果 6—8 个。

2. **橙子：做提亮和水分担当**
   - 优点：颜色好看、酸甜开胃、适合全家。
   - 建议选：赣南脐橙、冰糖橙、沃柑。
   - 数量：4—6 个。
   - 注意：不要和苹果堆得太挤，橙子皮容易被压伤。

3. **香蕉：适合做“马上能吃”的部分**
   - 优点：软、甜、老人小孩方便吃。
   - 缺点：不耐压、不耐放，夏天容易黑。
   - 建议：只放 1 小把，约 3—5 根。
   - 注意：香蕉要单独用纸包或放上层，避免压伤其他水果。

4. **菠萝：适合做视觉亮点，但不建议放太多**
   - 优点：体量大、有节日感、开箱显丰富。
   - 缺点：带皮占空间，削起来麻烦，部分家庭嫌酸。
   - 建议：放 1 个即可，选小菠萝或凤梨。
   - 注意：菠萝会压坏其他水果，最好放底部或单独隔开。

**家庭装搭配比例建议：**
- 经济家庭款：苹果 6 个 + 橙子 6 个 + 香蕉 1 把  
- 标准家庭款：苹果 6 个 + 橙子 6 个 + 香蕉 1 把 + 菠萝 1 个  
- 节日送礼款：苹果 8 个 + 橙子 8 个 + 菠萝 1 个 + 香蕉 1 把  
- 不建议：香蕉和菠萝放太多，容易压坏、成熟过快、整体显得乱。

**包装上要注意：**
- 苹果、橙子放底层，香蕉放上层，菠萝单独固定。
- 香蕉不要和苹果、橙子紧贴，苹果释放乙烯会催熟香蕉。
- 菠萝尖叶容易扎破包装，最好套袋或朝外固定。
- 礼盒不要塞太满，留一点缓冲，否则运输后容易碰伤。

**如果按家庭场景选：**
- 三代同堂：苹果 + 橙子 + 香蕉，最稳。
- 年轻家庭：苹果 + 橙子 + 菠萝，颜值高。
- 有老人小孩：苹果 + 香蕉 + 橙子，方便吃。
- 预算有限：苹果 + 橙子为主，香蕉少量点缀。
- 想显高档：苹果 + 橙子 + 凤梨，少放香蕉。

一句话：**家庭水果礼盒最稳的是“苹果和橙子做主力，香蕉少量即食，菠萝一个提气氛”。**
