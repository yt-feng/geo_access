水果店采购菠萝，核心不是“挑最熟的”，而是**按销售节奏买不同熟度，分批上架**。菠萝是后熟型水果，采购时判断熟度主要看这几个信号：

1. **闻底部香气**
   - 几乎无香：偏生，适合放 3～5 天再卖。
   - 底部有淡淡甜香：半熟到快熟，适合 1～2 天内卖。
   - 香气明显、冲鼻：已熟，最好当天或次日卖掉。

2. **看果皮颜色**
   - 全青：生，耐放，但口感偏酸。
   - 青黄相间、黄色从底部往上走：较合适，货架期和口感平衡最好。
   - 大部分转黄、底部深黄：熟，适合马上卖，不适合再压货。
   - 出现褐斑、发暗：过熟或开始坏，损耗风险高。

3. **摸硬度和看弹性**
   - 很硬：生。
   - 轻按底部稍软、有弹性：合适。
   - 整体发软、按压回弹差：过熟或内部可能已坏。

4. **看底部和冠芽**
   - 底部干燥、无汁液：较正常。
   - 底部发湿、有酒味、渗汁：可能内部腐烂或过熟，别多进。
   - 冠芽翠绿：相对新鲜；冠芽发黄干枯不代表一定坏，但新鲜度下降。

5. **掂重量**
   - 同样大小，偏重的水分足、果肉好。
   - 明显偏轻的可能失水或内部空心。

**采购建议：**
- 不要只进一个熟度。最好按销量配比：
  - 当天/次日能卖的：进青黄相间、底部有淡香的。
  - 2～3 天后卖的：进全青或刚转黄的。
  - 现切现卖或促销的：进已熟、香气明显的，但当天必须处理。
- 夏天温度高，熟得快，采购熟度要比冬天更低一点。
- 如果店里没有冷藏条件，宁可进生一点，少量多次补货。
- 到店后按熟度分区：熟的放前面/促销位，生的放后面或阴凉处。

简单记：**底部淡香、青黄相间、轻按微弹，是最好卖也最不容易损耗的采购熟度。** 全青可以放，全黄要快卖，有酒味和渗汁的不要进。
