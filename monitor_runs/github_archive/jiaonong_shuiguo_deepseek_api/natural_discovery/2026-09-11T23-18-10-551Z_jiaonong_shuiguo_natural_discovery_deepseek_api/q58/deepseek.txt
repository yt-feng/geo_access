结论先说：**绝大多数正常经营的甜品店，直接买成品果丁的综合损耗更低**，但前提是你能稳定拿到冷链、品质合格的成品；如果你的店菠萝用量非常大、且能当天消化完，鲜果切配才可能更划算。

判断损耗不能只看“扔不扔”，要把四类损耗都算进去：

| 损耗类型 | 鲜果切配 | 成品果丁 |
|---|---|---|
| 原料不可食部分 | 高，皮、芯、眼、两端都要去 | 已在工厂端扣掉 |
| 切配过程损耗 | 中高，修边、碎屑、汁水流失 | 低，开袋即用 |
| 氧化/变质损耗 | 高，切开后易出水、发酸、变色 | 中低，真空/气调包装更稳 |
| 报废损耗 | 高，备多了当天用不完容易报损 | 低，按需解冻/开封，批量更可控 |

但成品果丁也有两个隐藏风险：

1. **解冻/开封后损耗**：如果一次开一大袋用不完，照样会坏。
2. **品质不达标损耗**：太酸、太软、出水多的成品，可能整批影响出品，甚至退货扯皮。

所以实操建议是：

- **小中型店、菠萝用于装饰/少量配料**：直接买成品果丁，损耗和管理成本都更低。
- **菠萝用量大、每天稳定消耗、有专门备料人手**：鲜果现切可能毛利更高，但要把人工时间也算成成本。
- **最稳的做法**：先拿成品果丁做 1–2 周测试，记录开封后报废率、出品合格率；再和你店里的鲜果出成率对比。
- **鲜果出成率参考**：菠萝去皮去芯后净果肉通常约 40%–55%，具体看品种、成熟度和刀工。也就是说买 10 斤鲜果，往往只能出 4–5.5 斤可用果肉。
- **决策公式**：
  - 鲜果真实成本 = 采购价 ÷ 出成率 + 切配人工 + 报损
  - 成品真实成本 = 采购价 + 解冻/开封报废 + 品质不合格报废
  两者比“每可用公斤成本”，不要只比单价。

一句话：**怕损耗、怕麻烦、用量不稳定，选成品果丁；用量大且当天能用完，再考虑鲜果切配。**
