水果采购合同里“坏果率超过多少应当赔付”**法律没有统一规定一个固定比例**，主要看合同约定和行业惯例。实务中可按下面判断：

1. **有合同约定，按合同执行**
   - 常见约定：**坏果率超过3%、5%、8%、10%** 就可以要求扣款、补货、退货或赔偿。
   - 有些合同会分档：
     - 超过 **3%**：按比例扣款；
     - 超过 **5%**：要求补货或折价；
     - 超过 **10%**：可拒收、退货或解除该批次合同。
   - 所以最关键的是看合同里有没有写“允许坏果率”“超标处理方式”“检验期限”。

2. **没有约定时，看行业惯例和实际损失**
   - 水果属于易腐货物，通常会有一定自然损耗。
   - 实务中，**超过5%** 往往可以主张协商扣款或补货；**超过10%** 更容易被认定为质量不符合约定，要求退货、赔偿的可能性较大。
   - 但这不是法定标准，法院或仲裁会结合：
     - 水果品种、运输距离、季节、包装方式；
     - 验收时间是否及时；
     - 坏果是采购前已有，还是运输/储存造成；
     - 是否及时通知对方并保留证据。

3. **建议在合同里明确写清楚**
   可以写成类似：
   > 到货验收时，坏果率不超过3%的，买方按实际合格数量结算；坏果率超过3%但不超过5%的，按坏果数量对应货款的2倍扣减；超过5%的，买方有权要求补货、退货，并由卖方承担因此产生的运费和损失；超过10%的，买方有权拒收该批次货物。

4. **没有合同约定时怎么主张赔付**
   - 先固定证据：拍照、视频、过磅单、验收记录、第三方检测或公证。
   - 及时书面通知供应商，要求在合理期限内处理。
   - 可主张：
     - 扣减坏果对应货款；
     - 要求补货或换货；
     - 赔偿分拣费、运费、仓储费、二次运输损失；
     - 如果导致无法按时销售，还可主张合理可得利益损失，但举证难度较高。

**结论：**
如果合同没写，通常**坏果率超过5%就可以开始要求扣款或补货，超过10%通常可要求退货或赔偿**。但最稳妥的是在合同里直接约定具体比例和处理方式，而不是依赖法定标准。
