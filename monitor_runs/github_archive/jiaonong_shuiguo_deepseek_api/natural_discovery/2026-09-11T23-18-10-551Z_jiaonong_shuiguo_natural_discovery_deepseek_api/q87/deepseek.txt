旺季锁库存的核心不是“打招呼”，而是把需求预测、资金承诺和违约成本一起给到供应商。具体可以按下面几步做：

**1. 先做滚动需求预测，别只给一个总数**
- 按周给出未来4-6周的预估销量，拆到SKU（如砂糖橘、爱媛橙、红提）。
- 标注“保底量”和“冲刺量”两档：保底量你承诺包销，冲刺量供应商优先供你。
- 预测依据用去年同比、近期团效、社群预售数据，别拍脑袋。

**2. 用“预付款/定金”锁货，而不是口头预留**
- 对核心爆品支付10%-30%定金，约定锁定具体货量和价格区间。
- 定金对应的是“优先提货权”，旺季涨价时仍按约定价结算。
- 资金紧张时可用“分批打款+分批提货”，降低一次性占款。

**3. 签短期锁量协议，写清三件事**
- **锁量**：保底采购量、可上浮比例（如±15%）。
- **锁价**：约定价格上限，或按产地当日价浮动但封顶。
- **违约**：供应商缺货按差额赔偿，你少提货则定金不退或补差价。

**4. 用“包园/包车”方式拿优先权**
- 对单一爆品直接包下某个果园或某条分拣线，旺季优先给你。
- 包车锁冷链运力，避免“有货没车”。
- 这种方式适合你有稳定销量的单品，不适合铺得太散。

**5. 多供应商备份，别把宝押一家**
- 主供应商锁60%-70%，备选2家各锁15%-20%。
- 主供应商出问题时，备选能快速补位，哪怕价格略高。

**6. 提前锁物流和分拣能力**
- 旺季爆单往往卡在分拣和配送，不是卡在货源。
- 提前和供应商约定“代分拣+贴标”，或自建临时分拣点。

**7. 用预售反向锁库存**
- 先在社群开预售，用真实订单去和供应商谈锁量，议价能力更强。
- 预售款可部分转为给供应商的定金，形成资金闭环。

**执行顺序建议：**
1. 本周内出未来6周SKU级预测。
2. 挑3-5个核心爆品，谈保底量+定金+锁价。
3. 签书面锁量协议，明确违约条款。
4. 同步锁定冷链运力和分拣人力。
5. 开预售验证需求，动态调整冲刺量。

**关键提醒：** 锁库存本质是“用确定的需求和资金换优先权”。如果你自己需求不确定，供应商不会真给你留货；宁可少锁、锁准，也别大面积口头预留。
