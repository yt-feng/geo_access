判断供应商能不能按时到车，核心不是听承诺，而是看他有没有“可验证的确定性”。你可以按下面几层去查：

**1. 先看车源是不是他自己的**
- 问清楚：是自有车、长期合作车队，还是临时从信息部调车。
- 自有车/固定车队最稳；临时调车变数最大。
- 如果是调车，让他发**车牌号、司机电话、车辆定位**，你直接跟司机核对接货时间。

**2. 看历史履约记录**
- 让他在你之前合作过的市场档口/同行那里报几个名字，你侧面问：最近三个月有没有迟到、放空、临时换车。
- 重点问“最晚到过几次”“有没有到车当天才说车坏了”。
- 老供应商也要看最近状态，旺季车紧时谁都可能掉链子。

**3. 合同/聊天里把时间写死**
- 不要只写“明天到”，要写：**到车日期、最晚几点、到哪个市场、几号门、车牌号、司机电话**。
- 写清迟到怎么办：超过几小时扣多少钱、超过多久可拒收、定金怎么退。
- 微信聊天也算证据，关键信息让他文字确认，别只语音。

**4. 到车前做节点确认**
- 装车后确认一次：已装车、车牌、司机电话、预计出发时间。
- 出发后确认一次：现在到哪了、大概几点到。
- 到车前3—5小时再确认一次：有没有堵车、车况问题、会不会晚。
- 如果他说“在路上了”但给不出位置，基本要打问号。

**5. 看付款方式**
- 不要一上来全款。常见是定金+到车验货后付尾款。
- 如果对方要求全款才发车，而你又没法核验车源，风险很高。
- 可以要求“车到市场门口再付大部分”，至少保留一部分到验货后。

**6. 旺季和天气要提前加余量**
- 节假日、雨雪、高速管控、产地集中出货时，迟到概率明显上升。
- 这种时候要么提前1—2天锁车，要么同时备一个备用供应商。
- 别把当天销售全押在一辆车上。

**7. 最直接的判断信号**
- 能马上给车牌、司机电话、定位：相对靠谱。
- 只说“放心”“肯定到”“都是老关系”：不可靠。
- 到车前半天还查不到车在哪：高风险。
- 临时换车、换司机、换产地：要重新确认到车时间。

**实操建议：**
第一次合作，尽量**小批量试单**，别一车全压。到车时间写进合同，定金少付，尾款验货后付。到车前至少三次节点确认。这样即使他迟到，你也有止损空间。
