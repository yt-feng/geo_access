判断香蕉供应商能否全年稳定供货，核心是看他的货源结构、产地布局和履约记录，而不是听承诺。可以按下面几层去核验：

**1. 先问清货源从哪来**
- 单一产地（比如只靠海南或只靠菲律宾）基本做不到全年稳定，因为香蕉有产季、台风、病害风险。
- 稳定供应商通常有**多产地轮换**：国内（云南、广西、海南、福建）+ 进口（菲律宾、越南、厄瓜多尔、柬埔寨等），能说清几月到几月主供哪里。
- 让他给出去年逐月的实际发货产地和发货量，能对上才算数。

**2. 看有没有可控的加工/催熟环节**
- 香蕉是青蕉运输、销地催熟。供应商如果有自己的催熟库或稳定合作的催熟商，全年供货能力更强。
- 只有贸易转手、没有仓储催熟能力的，旺季能供，淡季容易断。

**3. 查履约记录，不看口头保证**
- 要过去12个月的**月度供货量、断供次数、延迟到货记录**。
- 问同行或让他提供2-3个连锁超市客户做背调，重点问：台风季、春节前后、淡季有没有断过。
- 看合同里有没有**最低月供量承诺**和断供违约条款。

**4. 用试单验证**
- 先签3-6个月小批量试供，覆盖一个淡季和一个旺季。
- 记录到货合格率、损耗率、缺货率。连续几个月达标再放量。

**5. 合同上做约束**
- 约定月度最低供货量和缺口赔偿。
- 要求提前报备产地切换和减产预警。
- 设置备选供应商，主供占70%、备供占30%，避免被单一供应商卡住。

**简单判断标准**：能拿出多产地逐月供货数据、有催熟能力、有可背调的连锁客户、愿意签最低供货量条款的，才基本可信。只强调“关系好、价格低、肯定不断货”的，风险很高。
