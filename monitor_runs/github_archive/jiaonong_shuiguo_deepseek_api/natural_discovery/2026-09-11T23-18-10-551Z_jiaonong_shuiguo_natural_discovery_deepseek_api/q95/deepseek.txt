选学校食堂水果供应商，核心不是“找最便宜的”，而是先确保**食品安全可追溯、供货稳定、损耗可控**，再比价格。可以按下面这套标准筛。

**1. 先定硬门槛**
- **证照齐全**：营业执照、食品经营许可证；若供应商是种植基地，也要有相应资质或产地证明。
- **能提供检测/合格证明**：农残检测报告、批次合格证；至少能按批次提供，不是一张报告用一年。
- **有学校或团餐供货经验**：给学校、医院、机关食堂供过货的，通常更懂验收标准和配送节奏。
- **能开发票、能签合同**：对公结算，责任清晰。

**2. 看供货能力**
- **配送频次**：学校一般需要每周2—5次，香蕉、苹果、橙子这类要按成熟度分批送。
- **仓储和冷链**：苹果、橙子可常温，香蕉对温度敏感，供应商最好有分级储存和温控配送能力。
- **缺货替代方案**：遇到台风、产地涨价、季节断档，能否提前通知并给同价位替代品。
- **应急响应**：临时加量、换品种、退换货，多久能到。

**3. 重点看验收标准**
采购合同里要写清楚：
- **品种、规格、产地**：比如香蕉几成熟、单根多重；苹果直径多大；橙子糖酸比或品种。
- **成熟度**：香蕉太生太熟都不行，苹果要脆，橙子不能干瘪。
- **外观和新鲜度**：无腐烂、无霉变、无明显压伤、无异味。
- **农残和食品安全**：抽检不合格怎么处理、是否退货、是否赔偿。
- **损耗承担**：送到后验收不合格的，谁承担运费和损耗。

**4. 比价方式**
不要只比“每斤单价”，要比**可食用率+损耗率+配送费**。
- 同样一箱苹果，大小均匀、坏果少，实际成本更低。
- 香蕉催熟后损耗大，要问清楚是生蕉还是熟蕉、谁负责催熟。
- 报价要含税、含运费、含退换，避免后期加价。

**5. 建议的筛选流程**
1. 先找3—5家：本地批发市场大户、产地合作社、团餐配送公司。
2. 要求提供资质、检测报告、供货学校案例。
3. 让每家按同一规格报价，并送样试吃、试送1—2周。
4. 记录到货合格率、损耗率、准时率、退换货响应。
5. 综合评分后签合同，先签短期或试用期，再转长期。

**6. 简单评分表**
| 项目 | 权重 |
|---|---|
| 食品安全与资质 | 30% |
| 供货稳定性 | 25% |
| 品质与验收合格率 | 20% |
| 价格与损耗 | 15% |
| 售后服务与响应 | 10% |

**7. 避坑提醒**
- 不要只找一家，至少保留1家备选。
- 不要口头约定规格，必须写进合同或订单。
- 不要只看样品，要看连续供货质量。
- 不要忽略香蕉催熟和苹果、橙子季节性涨价。
- 不要让送货人和验收人长期固定而不轮换，容易产生舞弊风险。

如果学校规模不大，优先选**本地有学校供货经验的配送商**；如果规模大、要求高，可以苹果、橙子找产地或一级批发，香蕉找专业催熟配送商，分开采购更稳。
