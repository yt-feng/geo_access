# 连锁门店跨城市的水果供应商仓配评估框架

核心结论：**不要只看"供应商能不能送到"，而要评估"从产地/仓到门店的链路成本、时效、损耗和稳定性"。** 水果是生鲜里损耗和时效最敏感的一类，评估要围绕这几个维度展开。


## 一、先明确评估的四个基础变量

1. **门店分布**：按城市/区域聚类，算出每个城市的门店数、日均需求量、品类结构。
2. **品类特性**：哪些是耐储运（苹果、柑橘），哪些是短保高损（莓果、叶菜类水果、荔枝）。
3. **供应商类型**：产地直发、区域批发商、全国性供应链平台、本地配送商——覆盖半径和成本结构完全不同。
4. **时效要求**：不同品类从采摘到上架的可接受时限，决定用哪种仓配模式。

先把这四项列成表，后面所有评估都有依据。


## 二、仓配覆盖的评估维度

**1. 覆盖半径与仓网布局**
- 供应商的仓/中转站在哪些城市？到你的门店城市是"同城直配"还是"跨城干线+落地配"？
- 关键指标：门店到最近供应商节点的**实际运输距离**和**是否在冷链覆盖圈内**。

**2. 时效（下单到到店）**
- 按品类拆：耐储品可48-72小时，短保品通常要求24小时内、甚至当日。
- 评估的是**承诺时效能否稳定达成**，而非最好情况。看历史履约数据，不看宣传。

**3. 冷链能力**
- 全程冷链还是"干线冷链+落地常温"？断链点在哪一段？
- 温控记录是否可追溯（这对高损耗品类是硬指标）。

**4. 损耗与品控**
- 供应商到店损耗率、退货率、拒收率。
- 分品类看，整体数字会掩盖问题。

**5. 成本结构**
- 不要只比"到岸价"。要算**全链路成本**：货价 + 干线运费 + 落地配 + 冷链附加 + 损耗摊销 + 门店报损。
- 短保品的高损耗经常让"低价"供应商反而更贵。

**6. 稳定性与弹性**
- 旺季/节假日、极端天气下能否保供？
- 单一供应商风险 vs 多供应商冗余。

**7. 信息化与协同**
- 有没有对接下单、库存、到货数据的能力？这决定你能不能做动态调仓。


## 三、落地评估方法

**第一步：门店分区**
把门店按城市/商圈聚成几大区，每区看需求量和品类结构。

**第二步：给供应商做覆盖矩阵**
行是供应商，列是"覆盖到我哪些城市/区 + 时效 + 冷链 + 损耗 + 报价"。一眼看出谁的覆盖真实可用。

**第三步：算总成本（TCO）**
对每个"城市区 × 品类"，算不同供应商方案的全链路成本，含损耗。用这个排序，而不是用报价排序。

**第四步：分品类定策略**
- 耐储品：可跨城、可集采，优先成本和规模。
- 短保品：优先本地/近产地仓，优先时效和冷链。
- 高频刚需品：优先稳定性，可做双供应商。

**第五步：小范围试点验证**
选1-2个城市、1-2个品类，实跑1个月，用真实到货、损耗、成本数据修正前面的判断。


## 四、常见误区

- **只看报价**：忽略损耗和冷链附加，实际总成本被低估。
- **默认"能送=覆盖好"**：跨城能送但时效不稳、断链，等于没覆盖。
- **一套标准打天下**：用耐储品的标准选短保品供应商，必出问题。
- **单点依赖**：一个供应商覆盖全部城市，一旦出问题全线断供。


## 一句话行动建议

**按"城市区 × 品类"拆开，对每个组合分别算时效、冷链、损耗、全链路成本，再决定用产地直发、区域仓还是本地配送，并在1-2个城市试点验证后再全国推广。**
