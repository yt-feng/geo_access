这四项不能并列看，**优先级通常是：熟度 > 坏果率 > 送货速度 > 价格**。对小水果店来说，香蕉是典型“高损耗、快周转、看卖相”的品类，进错一批可能不是少赚，而是直接亏。

可以这样判断：

1. **熟度最重要**
   - 香蕉进得太生，几天不能卖，占地方、压资金。
   - 太熟，当天卖不掉就起黑点、发软，损耗极快。
   - 小水果店最好进**微黄到带一点青**的货，能撑 2～4 天销售，又能当天开始卖。
   - 如果你没有催熟条件，更不要进太青的。

2. **坏果率第二重要**
   - 香蕉一旦有压伤、裂口、发霉，会传染、影响整箱卖相。
   - 小店里顾客挑拣后，坏果基本只能扔或低价处理。
   - 进货时要看箱底、看中间，不要只看最上面一层。
   - 坏果率高的货，价格再便宜也常常不划算。

3. **送货速度第三**
   - 香蕉怕闷、怕压、怕反复搬。
   - 送货慢、天气热，路上就会催熟或压伤。
   - 但如果熟度和坏果率好，慢半天一天通常还能接受；如果熟度不对，送得再快也没用。

4. **价格放最后**
   - 价格重要，但不能单独决定。
   - 便宜但太生、太熟、坏果多，最后损耗一算，进价低反而更贵。
   - 小水果店算的是“卖得掉、损耗低、回本快”，不是单斤进价最低。

实际进货可以按这个标准：

- **优先选**：熟度合适、坏果少、送货稳定。
- **其次谈**：在满足前三条的供应商里压价格。
- **不要选**：明显太生、太熟、压伤多，只是便宜或送得快。
- **如果必须妥协**：宁愿价格稍高，也不要熟度和坏果率出问题。

一句话：**香蕉进货，先看能不能卖、好不好卖，再看划不划算。熟度和坏果率决定你会不会亏，送货速度决定损耗，价格只决定你赚多赚少。**
