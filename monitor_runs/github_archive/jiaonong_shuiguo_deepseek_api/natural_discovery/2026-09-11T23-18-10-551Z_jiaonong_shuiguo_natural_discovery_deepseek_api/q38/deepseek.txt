大型超市一般会把水果供应商分成两类：**基地/产地型供应商**和**批发/配送型供应商**。无论哪种，通常都必须同时具备“食品安全合规能力”和“冷链物流履约能力”，否则很难进入商超体系，也很难长期稳定供货。

下面按超市实际审核和合作要求来列。

## 一、食品安全能力

### 1. 主体资质与合规文件
必须具备：

- 营业执照
- 食品经营许可证，或食品生产许可证，视经营模式而定
- 若为进口水果：进出口经营权、入境货物检验检疫证明、报关单
- 农产品承诺达标合格证，或产地证明
- 绿色食品、有机、GAP 等认证，不是所有超市都强制，但会加分

### 2. 农残与污染物控制
超市最关注的是：

- 农药残留检测合格
- 重金属、霉菌毒素等污染物符合 GB 2762、GB 2763 等标准
- 有批次检测报告
- 能提供第三方检测报告，如 SGS、华测、谱尼等
- 有自检能力或稳定合作的检测机构

如果供货给大型连锁超市，通常还要求：

- 每批次可追溯
- 检测报告能对应到具体批次、产地、采收日期

### 3. 追溯体系
必须具备“从产地到门店”的追溯能力：

- 产地信息：果园/基地名称、地址、负责人
- 采收信息：采收时间、批次号
- 加工信息：分选、包装、冷藏时间
- 物流信息：车辆、温度、到店时间
- 销售信息：供货给哪家超市、哪个门店

没有追溯体系，一旦抽检不合格，供应商会被直接淘汰。

### 4. 加工与包装卫生
需要具备：

- 分选、清洗、打蜡、包装环节的卫生控制
- 包装材料符合食品接触材料标准
- 避免交叉污染
- 员工健康证、工服、手套、消毒流程
- 防鼠、防虫、防尘设施

### 5. 召回与应急能力
大型超市会要求：

- 不合格品召回流程
- 食品安全事故应急预案
- 24 小时内可响应、可下架、可追溯
- 有问题批次隔离和销毁记录

## 二、物流与冷链能力

### 1. 冷链运输能力
水果供应商通常必须具备：

- 冷藏车或保温车
- 全程温控记录
- 不同水果分温区运输
- 装卸过程不断链

常见温区：

- 香蕉、芒果等热带水果：13–18℃
- 苹果、梨、葡萄：0–4℃
- 叶菜类水果如草莓、蓝莓：0–4℃
- 冷冻果品：-18℃以下

超市会查：

- 车辆温度记录仪
- 到店温度
- 运输轨迹
- 是否中途断冷

### 2. 仓储能力
需要具备：

- 冷藏库、保鲜库、气调库，视品类而定
- 分区存放，避免串味和交叉污染
- 先进先出管理
- 库存温湿度监控
- 虫害控制

### 3. 配送履约能力
大型超市通常要求：

- 按门店订单准时配送
- 能覆盖区域仓或门店
- 有固定线路和应急车辆
- 能处理节假日、促销期爆量
- 到货破损率、拒收率低
- 有退货、换货、补货机制

### 4. 包装与损耗控制
水果损耗高，超市很看重：

- 合适的周转筐、纸箱、保鲜袋
- 防压、防震、防潮
- 分级包装
- 到店新鲜度
- 损耗率可控

## 三、大型超市通常还会额外要求的能力

### 1. 标准化分级能力
能按超市要求做：

- 大小分级
- 糖度分级
- 外观分级
- 成熟度分级
- 统一包装规格

### 2. 稳定供应能力
- 有固定基地或稳定产地合作
- 能应对季节性断供
- 有替代产区
- 能保证全年或长周期供货

### 3. 财务与合规能力
- 能开增值税发票
- 能接受账期
- 有食品安全责任险
- 无重大违法记录
- 能通过超市验厂

### 4. 信息化能力
- 订单系统对接
- 库存和批次数据
- 检测报告电子化
- 温控数据可查
- 追溯码或二维码

## 四、最核心的硬门槛

如果只记重点，大型超市水果供应商通常必须同时具备：

1. **营业执照 + 食品经营许可证**
2. **农残检测合格 + 批次检测报告**
3. **可追溯体系**
4. **冷链运输和冷藏仓储**
5. **温控记录**
6. **召回和应急机制**
7. **稳定供货和准时配送**
8. **食品安全责任险**
9. **能通过超市验厂和年度审核**
10. **发票、账期、售后配合能力**

简单说：**食品安全是准入门槛，冷链物流是履约门槛，追溯和应急是长期合作门槛。** 三者缺一，很难进入大型超市供应链。
