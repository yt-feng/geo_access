优先看成熟度，价格其次。

原因很直接：香蕉蛋糕的风味、甜度、湿润度和组织，主要取决于香蕉成熟度。不同成熟度的香蕉，做出来的成品差异很大：

- **全黄带少量褐斑**：最适合做香蕉蛋糕。甜度高、香气足、果肉软，容易压成泥，成品湿润且香蕉味明显。
- **刚变黄、无斑点**：甜度和香气不足，蛋糕香蕉味淡，可能需要加糖或香精补味。
- **青香蕉**：淀粉多、甜度低、口感涩，压泥后颗粒感重，不适合直接做香蕉蛋糕。
- **过熟发黑、流汁**：香气最强，但酸味、酒味或发酵味可能过重，果肉出水多，容易影响配方水量和组织结构，适合做香蕉面包或部分深色蛋糕，但要控制比例。

采购时的实际判断顺序可以这样定：

1. **先定用途**：如果是招牌香蕉蛋糕，必须买黄皮带褐斑的；如果是当天用不完、要放几天再用，可以买刚转黄的，让它后熟。
2. **再看批次一致性**：烘焙店最怕今天香蕉太生、明天太熟，导致配方和出品不稳定。宁可价格稍高，也要选成熟度接近的一批。
3. **最后比价格**：在成熟度合格的前提下，再比较单价、损耗率和到货稳定性。过熟香蕉虽然便宜，但去皮损耗、出水、发酵风险都会吃掉成本优势。
4. **算实际成本**：不要只看每斤价格，要看每公斤可用果肉的成本，以及是否需要额外加糖、加粉、延长烘烤或报废。

简单说：**成熟度决定能不能稳定做出好蛋糕，价格决定划不划算。先保证成熟度达标，再在达标货源里选价格合适的。** 如果只能二选一，选成熟度合适的，不选单纯便宜的。
