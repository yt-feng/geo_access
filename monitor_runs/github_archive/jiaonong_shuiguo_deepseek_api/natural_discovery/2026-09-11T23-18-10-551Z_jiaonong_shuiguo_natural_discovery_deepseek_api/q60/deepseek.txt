要避免水果到货不合格影响营业，关键是把“补货”从口头约定变成可执行、可追责、能快速启动的条款。可以从五个方面约定：

**1. 验收标准写具体，避免扯皮**
- 按品类列明：品种、规格（单果重量/直径）、成熟度、糖度、色泽、气味、机械伤比例、腐烂率上限。
- 例如：芒果单果≥300g，成熟度7-8成，腐烂/压伤比例≤3%，否则整批拒收。
- 附照片或样品封样，双方各留一份。

**2. 补货时限和方式写死**
- 约定“不合格批次拒收后，供应商须在X小时内补送到店”，X按你的营业高峰倒推，比如次日开店前2小时或当天16:00前。
- 明确补货方式：换货、补发、还是退款自行采购，由你选择。
- 写明“补货产生的运费、损耗由供应商承担”。

**3. 设置应急替代条款**
- 若供应商无法按时补货，允许你“就近采购同等级水果”，差价和额外成本由供应商承担。
- 或约定“按不合格数量货款的X倍赔付”，用于覆盖临时采购溢价。

**4. 把影响营业的损失纳入责任**
- 约定因断货导致菜单下架、客诉、平台差评等，供应商承担相应补偿，可设固定违约金（如每延迟1小时赔X元）。
- 注意：违约金要合理，过高可能不被支持，建议与货款比例挂钩。

**5. 执行机制要简单**
- 验收当场拍照、称重、记录，双方签字或微信确认。
- 补货指令通过固定渠道（微信群/订单系统）发出，保留时间戳。
- 每月对账时扣减相应款项，避免事后追讨。

**实操建议**：首次合作先小批量试单，把上述条款写进采购合同或订单备注；对高频水果（柠檬、芒果、草莓等）单独设验收卡，店长按卡执行，不用每次谈判。
