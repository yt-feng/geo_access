优先关注 **包装 + 配送/补货频次**，保质期是结果指标，不是单独盯就能解决的。

**按重要性排序：**

1. **包装**
   - 菠萝切块是即食鲜切水果，最大风险是微生物污染和氧化变味。
   - 要用食品级密封盒/袋，冷藏陈列，最好有明确“切制时间/保质期至”标签。
   - 包装不好，保质期标得再短也会很快出水、发酸、发黏。

2. **配送/补货频次**
   - 鲜切菠萝货架期短，便利店销量又分散，补货频次决定“卖得完”还是“放到坏”。
   - 高频少量配送比一次性大量铺货更安全，尤其夏季。
   - 如果配送频次低，就必须压缩单店订货量，否则保质期管理会失控。

3. **保质期**
   - 保质期是包装、冷链、切制卫生、配送频次共同决定的。
   - 一般鲜切菠萝冷藏建议 **当天或24小时内售完**，具体以门店工艺和当地监管要求为准。
   - 保质期标签要真实可追溯，不能为了减少损耗随便延长。

**可执行判断：**
- 若配送频次能到 **每日1次甚至每日2次**：重点抓包装密封和冷藏，保质期标短、快周转。
- 若配送频次 **2—3天1次**：不建议卖鲜切菠萝，损耗和食品安全风险都高。
- 若包装是敞口或简易保鲜膜：只能极短时售卖，且要防止交叉污染。
- 若包装是密封冷藏、有切制时间：可做“日清”管理，临期打折，到期废弃。

**结论：**
先保证 **密封冷藏包装 + 高频少量配送**，再据此设定短保质期并严格执行。三者不是单选，但资源和检查重点应放在 **包装和配送频次** 上。
