最应该先问**售后**，再问**配送**，最后才压**价格**。

原因很直接：团购团长赚的是“信任差价”，不是单纯倒卖差价。

**1. 售后优先**
水果是高风险品类，坏果、压伤、熟度不均、重量不足都很常见。  
你要先确认：

- 坏果怎么赔，按个数还是按比例？
- 是补发、退款，还是下次进货抵扣？
- 拍照时限多久？
- 损耗率超过多少算供应商责任？
- 售后响应是当天还是隔天？

售后不清晰的供应商，价格再低也不能长期做。因为最后投诉都落在团长身上，群会散。

**2. 配送第二**
水果讲究时效和品相。  
重点问：

- 到你自提点还是到小区？
- 几点到，能否固定？
- 冷链还是普通车？
- 破损、延迟谁承担？
- 临时加单、减单怎么处理？

配送不稳，会直接导致履约事故。

**3. 价格第三**
价格当然要谈，但应该放在售后和配送明确之后。  
否则低价往往对应：

- 次果率高
- 售后扯皮
- 配送慢
- 缺斤少两

最后你省下的进货价，会以赔偿、掉粉、退群的形式还回去。

**最优顺序：**
先定售后规则 → 再定配送标准 → 最后比价格和账期。

**一句话判断：**
如果只能问一个问题，先问：“坏果和售后怎么赔，多久到账？”  
这个答不清楚，其他都不用谈。
