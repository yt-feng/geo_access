提升客单价的核心不是“让人多买一件”，而是**让顾客从买单品变成买组合，并觉得占了便宜但没多花冤枉钱**。香蕉、菠萝、苹果这组品项有个天然优势：**香蕉是高频刚需、菠萝是季节感强但决策偏重、苹果是家庭常备且价格敏感**。组合促销可以按这个逻辑做三层设计：

**1. 主推“水果拼盘组合包”，锚定一个心理价位**
把三样打包成“一周水果组合”，例如：
- 香蕉1把 + 菠萝1个 + 苹果4个，定价设在**比单买总价低15%左右**，但比你原本想主推的客单价高。
- 关键是让顾客感觉“买齐了”，而不是“多买了”。适合放在入口或称重台旁边，用大字写“省X元，够一家三口吃5天”。

**2. 用香蕉做引流，用菠萝和苹果做利润和加购**
香蕉价格透明、购买频率高，可以单独做“超低价引流”，但**不参与打折**，只作为“满额换购”或“加价购”的钩子：
- 买菠萝+苹果组合，加2元换购香蕉一把。
- 或满30元加3元换购香蕉。
这样香蕉不亏，反而把顾客从“只买苹果”拉到“买菠萝+苹果+香蕉”，客单价自然上去。

**3. 按场景做“二次组合”，而不是只做一次打包**
可以设三种场景组合：
- **早餐组合**：香蕉 + 苹果，主打快速、饱腹。
- **下午茶/解腻组合**：菠萝 + 苹果，主打酸甜清爽。
- **家庭囤货组合**：三样全包，量更大，价格更优。
每种组合用不同颜色标签区分，顾客选一个就比单买高，选两个就更高。

**4. 陈列和话术要配合**
- 把三样放在同一端头或同一冷柜，不要分散。
- 价签不要只写“组合价”，要写“单买XX元，组合省XX元”。
- 称重台员工一句话：“今天菠萝很甜，和苹果香蕉一起拿组合装更划算，要不要直接给您配一袋？”
- 组合包提前用透明袋装好，减少顾客犹豫。

**5. 控制损耗，避免为了客单价压货**
香蕉熟得快，菠萝切开后损耗高，苹果相对耐放。组合包最好**当天配、当天卖**，香蕉用稍青一点的，菠萝可以现场切或整颗卖。如果菠萝切块，必须冷藏并限时折扣，不然组合促销会变成损耗促销。

**可执行判断标准：**
- 如果组合包毛利率低于单卖总毛利率的70%，就不要硬推。
- 如果顾客只拿组合包里的香蕉，说明引流品设计失败，要改成“加价购”。
- 如果组合包销量高但客单价没涨，说明组合价太低，只是在替代原有购买，不是增量。

简单说：**香蕉负责让人进来，菠萝负责拉高感知价值，苹果负责稳住家庭采购，组合包负责把三样变成一单。** 先试一个端头、一个价格带，跑一周看客单价和损耗，再决定要不要扩到全场。
