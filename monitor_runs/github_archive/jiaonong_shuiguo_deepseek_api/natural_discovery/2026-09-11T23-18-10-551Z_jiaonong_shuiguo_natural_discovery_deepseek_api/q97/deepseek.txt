酒店采购水果盘原料时，建议在采购合同或验收标准里明确以下规格和外观要求，供应商应据此保证：

**一、基本规格标准**
1. **品种与产地**：明确具体品种、等级和产地，如“一级红富士苹果”“海南贵妃芒”，不接受以次充好或混装。
2. **单果重量/尺寸**：规定单果克重或直径范围，如苹果180–220g、橙子直径70–80mm，保证切盘出品大小统一。
3. **成熟度**：约定成熟度（如七至八成熟），既保证到货后可短期存放，又保证上盘时口感适中。
4. **可食率/净重**：可约定去皮去核后的净可食率，或按净重结算，减少损耗争议。

**二、外观标准**
1. **色泽**：色泽自然、均匀，符合该品种应有颜色，无异常发白、发青、发暗。
2. **果形**：果形端正、匀称，无明显畸形、偏斜。
3. **表皮**：果面光洁，无大面积斑点、锈斑、药斑；允许极小面积自然瑕疵，但不得影响切盘。
4. **无损伤**：无碰伤、压伤、裂口、虫眼、霉变、腐烂、冻伤。
5. **无病虫害**：不得携带活虫、虫卵、病斑、霉点。
6. **新鲜度**：果蒂新鲜、不枯萎，失水皱缩、发软、异味者拒收。
7. **清洁度**：无泥土、无严重农药残留气味，符合食品安全要求。

**三、食品安全与合规**
1. 农残符合 GB 2763 等国家食品安全标准，必要时提供检测报告。
2. 提供产地证明、合格证、批次追溯信息。
3. 包装、运输符合冷链或常温要求，避免二次污染。

**四、验收与退换**
1. 到货抽检比例、抽检方法写入合同。
2. 明确不合格判定：如腐烂、霉变、虫害、严重碰伤直接拒收或退换。
3. 约定到货时限、补货时限及损耗赔偿方式。

**五、可写进合同的简版条款**
> 供应商应保证所供水果品种、等级、产地与订单一致；单果重量/尺寸符合约定；成熟适度；色泽正常、果形端正、果面清洁；无腐烂、霉变、虫害、冻伤、严重碰伤及异味；农残符合国家食品安全标准，并可提供批次检测或合格证明。不符合上述标准的产品，酒店有权拒收、要求退换或按约定扣款。
