采购方试卖新品水果，建议先用“小批量、短周期、可复购”的方式测试，不要一次压太多货。具体量可以按下面几个维度判断：

1. **先定试卖量：按门店/渠道数估算**
   - 单店/单摊位：建议先试卖 **20～50斤**，或者 **1～3箱/件**。
   - 多门店：按 **每店20～30斤** 铺，总量控制在 **3～5天能卖完** 的量。
   - 如果是高客单、礼盒类或小众进口水果，先试 **10～20盒/件** 更稳。

2. **按销售周期控制：3～7天为一个试卖期**
   - 叶菜、浆果、荔枝、杨梅等易损水果：**1～3天**。
   - 苹果、橙子、梨、柑橘等耐储水果：**5～7天**。
   - 试卖期内重点看：动销速度、损耗率、复购意愿、顾客反馈。

3. **按采购金额控制：别超过总采购预算的5%～10%**
   - 如果新品单价高、损耗风险大，试卖金额控制在 **总水果采购预算的5%左右**。
   - 如果单价低、耐储存、供应商支持退换，可以到 **10%**。

4. **按供应商条件调整**
   - 供应商愿意 **赊销、换货、补损、退尾货**：可以适当多试，比如每店30～50斤。
   - 供应商要求 **现款现货、不退货**：建议压到最低，比如每店10～20斤，先测反应。
   - 首次合作供应商：最好先要 **样品**，再小批量试单，不要直接大货。

5. **试卖后看4个指标决定是否加量**
   - **动销率**：3天内卖掉70%以上，可以考虑补货。
   - **损耗率**：超过10%～15%，要谨慎加量。
   - **复购率**：有顾客回头买，说明有稳定需求。
   - **毛利空间**：扣掉损耗后仍有合理毛利，才值得放大。

6. **比较稳的执行方案**
   - 首次试卖：**每店20～30斤，或1～2箱，3天内卖完**。
   - 同步记录：销量、损耗、顾客反馈、竞品价格。
   - 卖得好：第二次按 **1.5～2倍** 加量。
   - 卖得一般：先换陈列、试吃、促销，不要急着补货。
   - 卖得差：及时止损，要求供应商换货或退尾货。

一句话：**首次试卖量控制在3～5天能卖完、金额不超过总预算5%～10%、每店20～30斤起步最稳。** 如果水果易损或供应商不包退换，还要再减半。
