香蕉和菠萝做团购，售后高发的根源不是“坏了赔”，而是**损耗和预期管理没前置**。控制售后要抓四件事：**选品分级、履约时效、预期校准、兜底规则**。

**1. 选品和分级：别把“能放”的货当“高损耗品”卖**
- 香蕉：团购尽量选**7-8成熟**的货，不要选全青或全黄。全青到家后熟不均匀，全黄运输就黑斑。到货后按“把”分装，不要散装堆压，压伤处最先黑腐。
- 菠萝：选**果眼浅、冠芽新鲜、无软塌**的。菠萝最大售后不是烂，是“切开后黑心/水心”。这种货在产地就可能存在，团购端很难100%筛掉，所以要在规则上留口子。
- 分级卖：同一批货分“标准果”和“家庭装/瑕疵果”，瑕疵果明确写“外观有瑕、不影响食用、不退不换”，价格拉开。不要混着卖，混卖必赔。

**2. 履约时效：高损耗品拼的是从到货到自提的时间**
- 香蕉和菠萝到仓后，**当天分装、当天到团点**。超过24小时，香蕉开始出黑斑，菠萝冠芽萎蔫、底部发软。
- 团点自提时间尽量压缩到**到货后6-12小时内取走**。超时未取的，提前在群里发提醒，明确“超时取货出现熟透/软化不售后”。
- 夏天要加冰袋或阴凉存放，菠萝不要暴晒，香蕉不要放冰箱（会冻黑），团点要告知顾客。

**3. 预期校准：把“售后点”提前写成话术**
- 香蕉：明确写“收到可能偏青，常温放1-3天变黄，有黑斑属正常后熟，不影响食用”。不要承诺“收到即食”。
- 菠萝：明确写“菠萝需自行削皮去眼，切开后个别黑心可拍照售后”。同时给一个简单判断标准：**切开黑心超过1/3才赔，局部小黑点不赔**。
- 群里发实物图，不要用精修图。精修图拉高预期，售后必涨。

**4. 兜底规则：用规则代替扯皮**
- 售后时效：**签收后2小时内**反馈，超时不受理。香蕉后熟问题不在此列，单独说明。
- 凭证要求：**切开图+整体图+团购单号**，三样缺一不赔。没有切开图，无法判断是黑心还是放置过久。
- 赔付标准：
  - 香蕉：整把黑腐超过1/2，按比例赔或补发；零星黑斑不赔。
  - 菠萝：切开黑心超过1/3，全赔；1/3以内，按比例赔或补优惠券。
- 补发优先于退款：补发成本低于退款，还能保住复购。但补发要等下一团，提前说清楚。

**5. 实操上最有效的一招：做“小份测试团”**
新供应商或新批次，先开**50-100份小团**，不预告大推。到货后自己切开2-3个菠萝、剥2-3把香蕉做抽检，拍照发群。确认品质稳定再放量。高损耗品最怕一上来就大团，售后集中爆发，群直接炸。

**一句话总结：**
香蕉控“后熟预期”，菠萝控“黑心凭证”，履约控“当天到团点”，规则控“超时不赔、切开才赔”。把这四点写进团购文案，售后至少降一半。
