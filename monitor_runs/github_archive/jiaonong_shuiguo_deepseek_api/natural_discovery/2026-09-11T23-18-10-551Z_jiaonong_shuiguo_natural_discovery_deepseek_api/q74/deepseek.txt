批发档口拓展餐饮客户，菠萝和香蕉的选品逻辑和零售完全不同：餐饮看重**出成率、稳定性、加工便利性**，不是好看。以下按规格给你可直接备货的判断标准。

## 菠萝（餐饮主要用途：鲜切果盘、饮品、菠萝炒饭、咕咾肉）

餐饮客户最在意两点：**削皮损耗**和**酸甜稳定**。

**按用途分规格：**

| 用途 | 建议规格 | 选品要点 |
|---|---|---|
| 鲜切/果盘 | 单果2.5–3.5斤，果眼中等 | 出成率高，切块规整 |
| 饮品/榨汁 | 3.5–5斤大果 | 出汁多，单果成本低 |
| 炒饭/热菜 | 2–3斤，成熟度7–8成 | 耐炒不易烂，酸甜适中 |
| 高端餐饮/西餐 | 指定品种（如台农、金钻） | 香气浓、糖度稳定 |

**关键动作：**
- 按“单果重量区间”报价，不要只按箱。餐饮客户算的是每斤净果成本。
- 菠萝季节性明显，主推**台农17号（金钻）** 这类糖度稳定的品种，餐饮回头率高。
- 提供**去皮净果**或代加工，能显著提高黏性，但你要核算人工。

## 香蕉（餐饮主要用途：鲜切、烘焙、奶昔、早餐）

香蕉最难的是**成熟度管理**，餐饮最怕今天到的货明天就发黑。

**按用途分规格：**

| 用途 | 建议规格 | 选品要点 |
|---|---|---|
| 鲜切果盘/酒店早餐 | 中果，长度15–18cm，4–5成青 | 到货后可控熟，减少损耗 |
| 烘焙/香蕉泥 | 大果或等外果 | 便宜、出肉多，对品相要求低 |
| 奶昔/饮品 | 中果，熟度略高 | 甜度高、易打浆 |
| 连锁早餐 | 统一长度、统一熟度 | 标准化是第一需求 |

**关键动作：**
- 餐饮客户要的是**可控后熟**，不是“已经全黄”。主推青熟蕉，让客户自己催熟。
- 按“每根长度+熟度”分级报价，比按箱更能打动餐饮采购。
- 香蕉等外果（弯度大、有斑点）走烘焙和果泥渠道，利润反而稳。

## 拓展餐饮客户的整体建议

1. **别按零售规格推**：餐饮要的是出成率、稳定供应、可加工，不是品相。
2. **做一张规格对照表**：把菠萝、香蕉按“用途—规格—熟度—报价单位”列清楚，直接发给采购。
3. **提供小批量试单**：餐饮换供应商谨慎，先给一周稳定小单，证明品质波动小。
4. **搭配供应**：菠萝+香蕉+其他常用水果打包，做“餐饮果切/饮品原料包”，比单品更容易锁客。
5. **核心卖点**：稳定、可控熟度、损耗承诺、按时配送——这四点比价格更能拿下餐饮客户。

如果你的目标客户是连锁餐饮还是单店，策略会有差别：连锁要标准化和账期，单店要灵活和起送量低。你可以告诉我具体客户类型，我再帮你细化报价和备货方案。
