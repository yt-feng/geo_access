做生鲜水果的一件代发，供应商的仓配能力直接决定履约体验和损耗率。核心要考察以下几方面能力：

**一、仓储能力**

1. **冷链仓储**
   - 水果品类对温度敏感，需具备冷藏库（0-10℃）、部分品类需气调库或恒温库
   - 不同水果温区要求不同（如榴莲、芒果需13-15℃，车厘子需0-4℃），供应商要有多温区管理能力
   - 仓库需有温湿度监控系统和记录

2. **库存管理**
   - 支持SKU级实时库存同步（通过API对接平台）
   - 具备先进先出/批次管理能力，避免临期果发货
   - 有安全库存预警和动态补货机制

3. **仓储规模与弹性**
   - 旺季（如节日、大促）能否临时扩仓或加班分拣
   - 单日峰值发货能力需匹配平台订单量

**二、分拣与包装能力**

1. **分拣能力**
   - 按单拣货（一件代发是单件拣选，非整箱批发）
   - 有品控分拣环节：剔除坏果、按规格分级
   - 支持定制化分拣（如按平台要求分大小果、贴标）

2. **包装能力**
   - 防震、防压、透气包装（水果需呼吸，不能全密封）
   - 冰袋/保温箱/泡沫箱等温控包装配置能力
   - 支持平台品牌包装或中性包装
   - 包装耗材库存充足，不因缺包材延误发货

**三、物流配送能力**

1. **快递资源**
   - 与顺丰、京东、中通等有稳定合作，尤其需有生鲜专线
   - 能拿到有竞争力的快递价格（一件代发快递成本占比高）
   - 支持指定快递或平台要求的面单格式

2. **发货时效**
   - 当日订单当日或次日发出（一般要求16:00前订单当日发）
   - 有截单时间管理和异常订单处理机制
   - 支持电子面单打印和物流轨迹回传

3. **配送网络**
   - 能否覆盖平台销售区域（尤其偏远地区是否发货）
   - 有冷链干线+落地配能力更优
   - 对易损品类可提供顺丰特快或空运

**四、系统与数据能力**

1. **系统对接**
   - 支持API/ERP对接，订单自动流转
   - 库存、发货、物流轨迹实时同步
   - 支持退换货逆向物流处理

2. **数据反馈**
   - 提供发货及时率、破损率、客诉率等数据
   - 能按平台要求做履约报表

**五、售后与兜底能力**

1. **坏果赔付**
   - 有明确的坏果包赔标准和流程
   - 支持按比例赔付或补发
   - 不推诿、响应快

2. **逆向处理**
   - 退货接收、二次分拣（可再售或报损）
   - 有报损核销流程

**六、关键考察指标（建议量化）**

| 指标 | 建议门槛 |
|------|----------|
| 发货及时率 | ≥98% |
| 48小时揽收率 | ≥95% |
| 坏果率 | ≤3%（视品类） |
| 库存准确率 | ≥99% |
| 客诉响应 | 24小时内 |
| 日峰值发货 | 匹配平台大促预估 |

**实操建议：**
- 先小批量试单，测实际发货时效和到货品质
- 要求供应商提供近3个月履约数据
- 合同里明确坏果赔付比例、发货时效罚则
- 优先选已有其他生鲜平台代发经验的供应商
- 旺季前做压力测试，确认产能弹性

如果供应商在冷链仓储、分拣包装、快递资源、系统对接这四项中缺任何一项，一件代发的履约质量都很难保障，建议谨慎合作。
