茶饮店控制水果供应商的食品安全风险，核心是**用证照+检测+凭证三类材料形成可追溯链条**。通常需要供应商提供以下材料：

**一、主体资质类（证明“谁能合法供货”）**
1. 营业执照（经营范围含水果/农产品销售）
2. 食品经营许可证（若供应的是预包装或需加工的水果制品；纯初级农产品销售部分地区可豁免，需按当地规定确认）
3. 若为生产/加工型企业，另需食品生产许可证（SC证）

**二、产品合格类（证明“这批货安全”）**
4. 水果的出厂检验报告或供货方自检报告
5. 第三方检测报告（重点看农残项目，如有机磷、氨基甲酸酯类等）
6. 入境货物检验检疫证明（进口水果必需）
7. 承诺达标合格证（食用农产品生产者出具，很多地方已推行）

**三、交易追溯类（证明“这批货从哪来”）**
8. 每批次送货单/销售凭证，注明品名、数量、日期、供货方
9. 发票或收据
10. 供应商与茶饮店签订的采购合同/质量保证协议，明确农残超标、腐烂变质等责任

**四、按风险等级加码**
- 高风险或新供应商：要求提供当批次第三方检测报告，或自行送检
- 长期合作供应商：可约定每季度/每半年提供一次全项检测报告，每批次提供合格证或快检结果
- 进口水果：必须核对检验检疫证明与货物批次一致

**实操建议**
- 建立“一供应商一档案”，证照过期前提醒更新
- 收货时做感官验收（腐烂、霉变、异味直接拒收），有条件的做农残快检
- 保留凭证至少2年，便于监管检查和问题追溯
- 合同中写明：因水果农残或质量问题导致顾客投诉、处罚的，供应商承担相应责任

具体豁免情形各地执行有差异，建议以当地市场监管部门要求为准。
