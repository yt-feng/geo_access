会增加，而且香蕉和菠萝的损耗逻辑不一样，要分开看。

**香蕉：起订量高，损耗风险最敏感**
- 香蕉是呼吸跃变型水果，采后仍会集中后熟，温度、乙烯、挤压都会加速变黄变黑。
- 起订量一高，通常意味着到货批次集中、堆压更重、周转时间更长；只要销售速度跟不上，就会从“青香蕉”很快变成“过熟蕉”，只能打折或报损。
- 风险点主要在：催熟节奏失控、冷库/常温库乙烯积聚、搬运擦伤、先进先出执行不到位。
- 判断标准：如果到货后 3—5 天内不能卖掉大部分，起订量就偏高。

**菠萝：起订量高，损耗更多是“隐性损耗”**
- 菠萝相对耐放，但高起订量会带来另一类问题：整箱挤压、果眼霉变、低温冷害、底部腐烂。
- 如果门店或仓库没有稳定周转，菠萝外表可能还行，但内部已经开始褐变或发酸，属于“看不出来但卖不掉”的损耗。
- 判断标准：如果 7—10 天内不能完成大部分周转，起订量就要谨慎。

**怎么判断起订量是否过高**
1. 用“日均销量 × 安全周转天数”倒推合理订货量。
   - 香蕉安全周转天数通常短，建议 2—4 天。
   - 菠萝可稍长，建议 5—7 天。
2. 看仓储条件：有没有独立温区、通风、乙烯隔离、防压堆码。
3. 看补货频率：如果供应商能一周多次小批量送，高起订量就没必要。
4. 算综合成本：不要只看单价便宜，要把报损率、打折率、人工分拣成本加进去。

**简单结论**
- 香蕉：起订量高，损耗风险明显更高，因为后熟快、窗口短。
- 菠萝：起订量高，损耗风险中等，但一旦周转慢，容易出现内部变质和整批降级。
- 如果起订量无法降低，优先谈“分批次到货”或“混拼订单”，而不是一次性压库存。
