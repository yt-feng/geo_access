判断菠萝哪个规格更容易出货，核心不是看“哪个规格最好”，而是看**你的下游客户是谁、在什么场景卖、周转速度要求多快**。可以按下面几个维度快速判断。

## 1. 先按客户类型判断

### 走批发市场、二级批发商
通常更容易出的是：
- **中果为主**：单果 1.2～1.8 斤左右，或按你当地习惯叫“2号果”“3号果”
- 原因：价格适中、卖相整齐、终端水果摊和超市都好接
- **大果**也有需求，但更适合礼盒、商超堆头、餐饮切果，走量不一定比中果快

### 走水果店、社区团购、路边摊
更容易出的是：
- **中果、小中果**
- 原因：单价低、顾客一次买一整个压力小，适合家庭消费
- 太大的果反而难卖，因为顾客觉得一次吃不完、单价高

### 走商超、精品水果店
更容易出的是：
- **外观均匀的中大果**
- 要求：果形正、冠芽好、无畸形、成熟度一致
- 这类客户不是单纯要便宜，而是要“好看、好陈列、损耗低”

### 走餐饮、果汁店、烘焙、食堂
更容易出的是：
- **大果或次级果**
- 原因：按重量出肉，对单果外观要求低，更看重出肉率和价格
- 如果是切块、榨汁，规格整齐度不重要，便宜、稳定供货更重要

### 走电商、直播、社区团购
更容易出的是：
- **中果、小果，按斤卖或按个数卖**
- 原因：运费敏感，大果运费高；顾客又怕小果太酸太小
- 通常“中大果混装”或“单果 1.5 斤上下”比较好讲卖点

## 2. 再看季节和成熟度

- **旺季刚上市**：中果、大果都好走，但中果周转最快
- **大量集中上市期**：价格战明显，中果最稳，大果容易压货
- **尾季**：小果、次级果走加工渠道更快
- **高温天**：熟得快，哪个规格都必须快进快出，这时不是规格问题，是成熟度问题

## 3. 用三个指标快速判断

你可以拿最近 7～15 天的出货数据算：

1. **出货速度**
   - 哪个规格从入库到卖完天数最短

2. **毛利额**
   - 不是毛利率，而是每箱赚多少钱
   - 有些小果毛利高但走量慢，不如中果周转快

3. **损耗率**
   - 哪个规格烂得少、压伤少、退换少
   - 菠萝怕压、怕熟，损耗低的规格才是真正好出货

公式可以简单记：
> 综合得分 = 日出货量 × 单箱毛利 − 损耗成本

得分最高的规格，通常就是你的主推规格。

## 4. 实操建议

你可以这样做：

1. **先分 3 档试销**
   - 小果
   - 中果
   - 大果
   各进少量，卖给同样类型的客户，记录 7 天出货速度。

2. **问下游客户一句话**
   - “你那边顾客更愿意买多大的？一次买几个？”
   - 这比你自己猜更准。

3. **主推中果，搭配大果和小果**
   - 中果做走量
   - 大果做利润和商超
   - 小果做低价、团购、加工

4. **不要只看规格，要看成熟度**
   - 同一规格，青果、黄果、熟果出货速度差很多
   - 批发环节通常青果耐放，但终端要黄果或半黄果

## 5. 一般结论

如果没有具体客户数据，通常：

- **最容易出货：中果**
- **利润较好：中大果**
- **加工渠道最快：大果、次级果**
- **电商团购较好：中果、小中果**
- **商超精品较好：均匀中大果**

所以，批发菠萝不要问“哪个规格最好”，而要问：
> **我现在的客户是谁？他们一次买多少？哪个规格周转最快、损耗最低、每箱赚得最多？**

按这个逻辑，你主推的规格就会很清楚。
