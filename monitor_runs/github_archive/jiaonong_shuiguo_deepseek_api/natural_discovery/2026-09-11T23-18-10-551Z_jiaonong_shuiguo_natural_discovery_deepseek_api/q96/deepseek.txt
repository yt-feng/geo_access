这三项不是同一层面的问题，不能简单三选一。对企业食堂采购水果来说，**食品安全是底线，配送准时是保障，价格是优化项**。如果必须排序：

**食品安全 ＞ 配送准时 ＞ 价格**

但实际决策要看场景：

1. **食品安全优先**
   - 这是不可妥协项。
   - 重点关注：农残检测、来源可追溯、新鲜度、有无腐烂霉变、冷链是否合规。
   - 一旦出问题，影响员工健康、食堂责任和企业声誉，省下的钱远远不够赔。

2. **配送准时其次**
   - 食堂供餐有时间点，水果不到位会直接影响当天供餐或加餐安排。
   - 尤其涉及早餐、下午茶、节日福利时，准时比单价便宜更重要。
   - 需要看供应商是否有稳定冷链、备用车辆、缺货补送机制。

3. **价格放在第三，但不是不重要**
   - 价格应该在满足食品安全和配送稳定的前提下比较。
   - 如果只追求低价，容易遇到以次充好、临期果、损耗高、缺斤少两。
   - 更合理的指标是“综合成本”：单价 + 损耗率 + 退换货成本 + 人工验收成本。

**可执行建议：**
- 先设食品安全门槛：资质、检测报告、溯源凭证、验收标准。
- 再设配送门槛：到货时间、迟到处理、缺货补送、冷链要求。
- 最后比价：按周/月报价，结合损耗率和实际到货质量综合评标。
- 合同中写清：农残超标、腐烂率超标、迟到、缺货的扣款或退出机制。

**结论：**
企业食堂采购水果，最需要优先关注的是**食品安全**；配送准时是保障正常运营的关键；价格应在两者达标后再谈。只盯价格，往往最后总成本更高。
