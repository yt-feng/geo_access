要避免香蕉到店后很快变黑，核心是**控制成熟度、减少机械伤、控制乙烯和温湿度**。采购时可以直接按下面几条执行：

1. **不要买已经全黄、带黑点的香蕉**
   - 最适合甜品店短周期使用的，是**微黄带一点绿、成熟度约 70%–80%** 的香蕉。
   - 如果到店当天就要大量用，可以买**黄中带少量绿**；如果 2–3 天内用完，再选更黄一点。
   - 已经通体金黄、果柄发黑、有酒味的，基本到店后很快会继续变黑。

2. **优先选“青熟”或冷链运输的货**
   - 香蕉通常是青果运输，到店后再催熟或自然熟。
   - 如果供应商能提供**冷链青蕉**，比常温熟蕉更耐放。
   - 采购时问清楚：采摘后是否做过催熟、运输温度多少、到店时成熟度几成。

3. **检查果柄和蕉串状态**
   - 果柄粗壮、颜色偏绿或浅绿，通常更新鲜。
   - 果柄发黑、干缩、开裂，说明采收或存放时间偏长。
   - 蕉指饱满但不过软，轻按有弹性，不要选软塌的。

4. **避免机械伤**
   - 香蕉变黑很大一部分来自**磕碰、挤压、摩擦**。
   - 采购时要求箱内分层、有垫纸或泡沫网套，不要堆压。
   - 搬运时不要拎蕉串，尽量托箱底；到店后减少反复翻动。

5. **到店后立刻做分拆和通风**
   - 不要整箱闷着放。开箱，把香蕉**单层或松散摆放**。
   - 如果蕉串很大，可以切成小串，但切口尽量少，切后尽快用。
   - 放在**阴凉、通风、避光**处，理想温度约 **13–15℃**。
   - 不要放冰箱冷藏室，香蕉怕冷，低温会冻伤变黑；除非是已经熟透且马上加工。

6. **隔离乙烯，别和苹果、梨、番茄放一起**
   - 苹果、梨、番茄、猕猴桃等会释放乙烯，催熟香蕉。
   - 香蕉自身也会释放乙烯，所以不要堆得太密。
   - 如果店里有乙烯吸收剂，可以放一包在存放箱或冷柜里。

7. **按使用量分批采购**
   - 甜品店最好**少量多次**，比如 2–3 天一批，而不是一次囤一周。
   - 如果每天用量稳定，可以和供应商约定每周送 2–3 次。
   - 当天用不完的熟蕉，可以去皮、切段、冷冻，用于奶昔、冰沙、香蕉泥，避免继续变黑报废。

8. **到店后先处理最熟的**
   - 按成熟度分三档：
     - 偏绿：继续常温放。
     - 微黄：优先做需要成型、切片的产品。
     - 全黄：马上做香蕉泥、酱、奶昔或冷冻。
   - 不要把所有香蕉混在一起，否则熟蕉会催熟青蕉。

简单记：**买微黄带绿、冷链青蕉、轻拿轻放、到店分拆、13–15℃通风、远离苹果梨、少量多次。**  
如果只能常温采购，就尽量选**果柄绿、蕉身硬挺、没有黑点**的货，并且 2–3 天内用完。
