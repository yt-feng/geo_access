生鲜水果到货后出现坏果，责任划分通常不能一概而论，关键看**坏果发生在哪个环节、是什么原因造成的，以及平台/商家/物流/顾客各自有没有过错**。可以按下面几个层面判断和操作。

## 一、先判断坏果类型和原因

1. **运输途中损坏**
   - 如挤压、摔伤、冻伤、闷热腐烂。
   - 常见于物流暴力分拣、包装不当、冷链断裂。
   - 责任通常在**商家或物流方**，具体看商家与物流的约定。对顾客而言，一般由**商家先承担售后责任**，商家再向物流追偿。

2. **商品本身质量问题**
   - 如发货时已过熟、霉变、内部腐烂、以次充好。
   - 责任在**商家/供应商**。
   - 顾客可要求退款、补发或赔偿。

3. **保鲜期短且正常损耗**
   - 如草莓、荔枝、水蜜桃等本身易损。
   - 若商家已明确告知“轻微碰伤不影响食用”“签收后尽快食用”，且坏果比例在合理范围，可能属于**正常损耗**。
   - 但“正常损耗”不能成为商家推责借口，若坏果比例高或已腐烂，仍应售后。

4. **顾客自身原因**
   - 如签收后长时间未取、未冷藏、放置过久导致变质。
   - 责任通常在**顾客**。
   - 但若是快递未经同意放门口、代收点导致延误，责任可能转回**快递/商家**。

5. **签收时已发现但未验收**
   - 若平台要求当面验收，顾客未验收就签收，事后维权会变难，但不等于商家完全免责。
   - 若外包装明显破损、有异味、渗液，顾客仍可拍照留证并投诉。

## 二、常见责任划分口径

| 情形 | 主要责任方 | 顾客该找谁 |
|---|---|---|
| 包装差、运输挤压 | 商家/物流 | 先找商家售后 |
| 冷链断链导致腐烂 | 商家/物流 | 先找商家 |
| 发货时就是坏果 | 商家/供应商 | 找商家 |
| 快递擅自放代收点导致变质 | 快递/商家 | 找商家或快递投诉 |
| 顾客签收后放坏 | 顾客 | 一般自行承担 |
| 少量轻微碰伤，且已提前告知 | 可能属正常损耗 | 协商处理 |
| 大量腐烂、霉变、异味 | 商家 | 可要求退款/补发/赔偿 |

## 三、对顾客的建议

1. **到货后尽快开箱拍照/拍视频**
   - 拍外包装、快递单、坏果整体、坏果细节。
   - 最好保留开箱视频，能证明不是事后调换。

2. **及时联系商家或平台客服**
   - 说明坏果数量、比例、是否影响食用。
   - 提出明确诉求：退款、补发、部分退款或赔偿。

3. **不要轻易扔掉全部坏果**
   - 协商完成前保留证据，必要时按客服要求处理。

4. **平台不处理时再升级**
   - 可申请平台介入、向消协投诉，或通过12315投诉。
   - 若涉及食品安全问题，可向市场监管部门反映。

## 四、对商家/平台的处理建议

1. **先售后、再追偿**
   - 对顾客，通常应优先处理售后，避免让顾客自己在物流和商家之间来回踢皮球。
   - 若是物流责任，商家再依据合同向物流索赔。

2. **建立坏果判定标准**
   - 如坏果比例超过多少可全额退，多少可部分退。
   - 明确易损品类的售后规则，减少扯皮。

3. **改进包装和冷链**
   - 易损水果用防震托、冰袋、泡沫箱、透气孔。
   - 高温/低温地区加强冷链和时效控制。

4. **保留发货和物流证据**
   - 发货前拍照、称重、记录成熟度。
   - 物流各节点温控和签收记录要可查。

## 五、一句话结论

**顾客收到坏果，通常先由商家承担售后责任；商家再根据坏果原因向物流或供应商追偿。若坏果是顾客签收后自身保存不当造成，则顾客承担。核心判断标准是：坏果发生在交付前还是交付后，以及各方是否有过错。**
