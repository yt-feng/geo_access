社区超市卖小包装香蕉，采购时建议重点关注以下四个方面，以控制损耗并提升销量：

**1. 包装形式和规格（影响损耗率）**

- **透气性优先**：香蕉是呼吸跃变型水果，包装必须带透气孔或使用专用网袋，❌忌用完全密封的塑料盒/膜，否则内部易积水汽，加快发霉和黑斑。
- **规格设计**：建议小包装3-5根（约500-700克），符合单人/小家庭单次食用量。太小（2根）单价低、包装贵；太大（6根以上）超出单次摄入范围，反而增加存放损耗。
- **接口处理**：果柄切口是否封蜡/热缩膜，若切口裸露，容易在货架期引发褐变和微生物滋生。采购时要确认供应商是否做了切口保护。

**2. 采购时的成熟度选择（核心损耗点）**

- **分级收货**：尽量选择**7-8成熟**（果身微黄、果棱尚存、果柄青绿）的香蕉。全绿（硬）需催熟，货架期短；全黄（软）易碰撞淤伤，当天卖不完第二天就发黑。
- **分批采购**：社区超市建议**少量多频**（如每2天补一次货），避免一次囤大量。若供应商支持，可要求按“今日售黄熟”、“明日售微黄”的梯度配货。

**3. 在途和收货后的物理损耗**

- **运输包装**：确认外箱是否分格/加垫纸，防止搬运时挤压、擦伤。香蕉碰撞后不会立刻显现，但24小时内果肉会变褐。
- **到店检查**：收货时开箱查验，剔除已破裂、软烂、果柄断裂的个体。这些应单独打折处理或退换，切勿混入小包装。
- **陈列损耗**：小包装不可堆叠过5层，以免底层受压。货架建议斜放（果柄朝上或侧放），能减少与台面的接触黑印。

**4. 库存与临期管理（清理损耗）**

- **定价策略**：小包装建议标“当日最佳食用”日期，当日未售完的，次日进行“熟透特价”清货，避免第3天烂果计提损耗。
- **保鲜技巧**：若短期存放，将未熟香蕉置于阴凉通风处（避免空调直吹），❌勿放进冷柜（低温会冻伤果皮发灰，反而加速褐变）；已装袋的香蕉如计划2天内售完，可在袋内放一包食品干燥剂吸收乙烯。

**总结建议：**
采购前要求供应商提供**透气小包装+成熟度分级+果柄保护**，合作初期试订半箱测试3天货架损耗率（目标≤5%）。若某批次到店已全黄，应争取供应商允许退换或给折扣，否则风险自担。
