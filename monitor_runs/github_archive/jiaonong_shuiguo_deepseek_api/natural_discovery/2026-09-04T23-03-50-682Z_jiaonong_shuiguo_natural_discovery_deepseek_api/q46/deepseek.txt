针对茶饮店采购菠萝做果茶，**推荐首选“鲜果”**，其次是“果丁”，不推荐首选“果泥”。具体原因和建议如下：

### 1. 为什么首选鲜果？
- **风味最自然**：鲜菠萝香气足，酸度、甜度和纤维感是深加工产品很难完全还原的。
- **适配性最广**：可以做“鲜切菠萝”或打汁，能满足门店高品质果茶定位。
- **成本可控**：目前菠萝（特别是如金钻、蜜宝等品种）产地价合理，若门店用量大，鲜果成本往往低于同品质果泥。

**注意**：鲜果需具备**冷藏条件**，且损耗率较高（去皮、去芯），需要后厨有切配人力，建议选**成熟度适中**的果（约7-8成熟），过熟易烂、过生涩口。

### 2. 何时选“果丁”？
- 用途：仅用于**装饰杯顶**或**提供咀嚼口感**，适合出杯快速的门店。
- 注意：市售“糖渍菠萝丁”含糖量高，会掩盖果茶本身的清甜；且口感偏软，缺乏新鲜脆甜，更适合做“低配平价”产品。**不建议作为主要风味来源**。

### 3. 为何不主推“果泥”？
- 果泥风味多经过灭菌或加糖调酸，香气损失明显，做出来的果茶容易有“罐头味”。
- 若用量很大且没有后厨，**可以选用“无添加纯菠萝果泥”**作为应急备货，但一定选配料表干净（仅菠萝、水）的，且要现用现调，避免久放分层。

---

### 实操建议（直接可执行）：
1. **主力配方用鲜果**：准备鲜菠萝片（约3-5mm）和鲜榨菠萝汁（自制，过筛去渣），保证茶底有新鲜果酸和果香。
2. **备少量“果丁”**：仅用于装饰或做“菠萝爆珠”替代，可用糖水菠萝丁增加视觉。
3. **试营业测试**：先采购少量鲜果试做3款（如菠萝青提茶、菠萝柠檬茶），对比鲜果VS果泥的差异，用顾客口味投票决定后续比例。

**如果门店日均菠萝消耗超过5公斤且人手紧张**，可考虑“鲜果切片+工业果泥（调配用）”混合模式，但果泥占比建议不超过30%。
