开水果店长期进货，最怕的就是供应商不稳定或者品质“掉链子”。帮你梳理几个**可执行、能落地**的判断标准，尤其是针对香蕉和菠萝这两种敏感水果。

**一、先看“硬指标”（可当场验证）**

1. **香蕉看“催熟”而非“青度”**  
   - 靠谱供应商必须能清楚告知“到货时是青蕉还是已催熟”。
   - 如果你要现货卖，他必须提供**7-8成熟度的香蕉**（绿中带黄），而不是全青或全软。如果全是全青的，说明他只做产地直发，你自己催熟会累死；如果全黄甚至有黑点，说明货架期已过，你拿回家两天就烂。
   - **问一句**：“这批货到仓几天了？途中温度怎么控的？”

2. **菠萝看“重量”和“声音”**  
   - 让他把菠萝拿起来掂一下，同样大小的菠萝，**手感越沉越好**，说明水分足、新鲜。
   - 用手轻轻弹一下菠萝果实中部，声音是**闷而实**的是好果，空响则果肉发干或内部有空洞。
   - 查看底部切口，切口**不发黑、不发黏**，现切果才是新鲜的。

**二、看“专业度”和“备货能力”（现场问话）**

3. **问他“缺货预案”**  
   靠谱供应商会告诉你：“如果这批货路上坏了，我明天早上能从附近档口补一批过来。” 如果对方支支吾吾或者说“这不行”，那你旺季断货就麻烦。

4. **敢不敢做“品质赔付”**  
   直接问：“如果到货开箱发现有8%以上烂果，怎么处理？”  
   靠谱的会说：“有图有真相，拍照片拍视频，次品超过比例，直接按斤退款或下次补货。”  
   如果没有这种约定，只让你“自认倒霉”的，基本不用长期合作。

5. **冷链和温度细节**  
   香蕉适宜13℃-15℃储藏，菠萝12℃-16℃。你可以问他：“到货后我常温放两天没问题吧？”  
   如果对方说“随便放”，说明他不专业（要么货很生，要么用了保鲜剂）。靠谱的会告诉你具体保存条件和最佳销售期。

**三、从“长期合作”看人品（试单法）**

- **首单只进“小批量”**：第一单进他**10-20箱**，哪怕利润薄，也要试。看两件事：  
  ① 到货时间是否准时（误差超4小时就不行）。  
  ② 次品率是否低于他能接受的范围。  
- **第二单再“压价”试探**：第二单你试着要求“加量不加运输费”或“尾款压一周”，靠谱的会同意或给出合理理由；如果立刻翻脸，说明利润全在暗处，合作不长久。

**四、几个“负向信号”要警惕（占一条就要换人）**

- 所有水果都“品质完美”，从不提损耗，反而是外行话。  
- 报价每次都低得离谱，低于市场价15%以上，大概率会以次充好或中途换货。  
- 从来不主动问你店铺位置和顾客群，只催你打款。  
- 朋友圈或档口从不更新实货视频，只有转账记录。

**最后给你一个实操小技巧**：  
去他档口时，**随便挑一箱最下面一层的香蕉/菠萝**看，最底层往往最能代表整批货的平均水平。如果底层都很好，这个供应商值得信赖；如果只上层漂亮，下面全是软果或烂果，直接Pass。

总之，水果供应商的核心不是“便宜”，而是“货架期长、损耗低、退换干脆”。你第一次进货前，可以先要他的**营业执照或档口编号**，拍下来，万一出问题有保障。祝你开店顺利！
