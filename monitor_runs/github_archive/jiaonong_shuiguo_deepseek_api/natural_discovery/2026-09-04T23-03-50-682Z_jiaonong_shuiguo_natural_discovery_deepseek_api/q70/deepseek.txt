好的，针对批发商担心货到后损耗高的问题，在合同中**明确“风险转移节点”**和**“损耗承担标准”**是核心。以下是一份可供参考的**合同责任条款建议**（包含关键维度），你可以根据实际货物（如水果、蔬菜、生鲜等）进行微调：

### 一、合同条款建议（核心条款）

**1. 鲜活易腐货物特定条款（推荐优先使用）**
> **第X条 货物风险与损耗分担**
> 1. 双方确认，本合同项下货物为**鲜活易腐商品**，其自然水分蒸发、呼吸作用及轻微碰伤属于**合理自然损耗**。
> 2. **风险转移**：标的物毁损、灭失及品质变质之风险，自**乙方（承运方/发货方）将货物交付甲方（批发商）指定收货人并完成签收**时起，转移至甲方。
> 3. **到货验收权利**：甲方有权在收货后 **【24】小时（或双方约定）** 内，对货物开箱抽检。若发现存在**非自然原因造成的腐烂、压伤、霉变**，甲方有权留存影像证据并通知乙方。
> 4. **责任划分**：
>    - 若全程冷链温控数据/物流轨迹显示**超温、延迟**且与损耗直接相关，责任由**乙方（承运方）**承担，甲方有权拒收该部分或要求按实价扣减。
>    - 若属于**品种自身特性导致的自然缩水**（如叶菜失水、个别轻微擦伤），若损耗率低于 **【3%~5】%（双方商定）** ，视为正常，甲方应照单全收。
>    - 若**损耗率超过【5】%**，甲方有权按下述方式处理：
>        a) 对该批次货物进行全检，将腐烂、变质部分**单独称重**，该部分金额由乙方在结算中**全额扣除**。
>        b) 若损耗率超过 **【8】%**，甲方有权对该批货物**拒收整批退货**，运费及相关损失由乙方承担。

**2. 一般货物通用条款（备选）**
> **第X条 质量异议期**
> 1. 甲方应在收到货物后 **【48】小时** 内完成质量查验。若存在坏果，应提供照片、视频及对方签收单作为证据。
> 2. 若甲方未在规定期限内提出异议，视为货物验收合格，甲方应按约支付货款。

### 二、法律风险提示与操作建议（重要）

1. **“自然损耗”必须量化**：
   - 法律上，运输途中轻微变质若属“合理损耗”，批发商需自行承担。合同里**必须写死一个百分比**（如3%或5%以内免赔），否则扯皮时法院很难支持你全部退货。

2. **物流责任方要分清**：
   - 如果货是**发货方找的物流**，则发货方对物流运输环节造成的损坏（如撞伤、冻伤）承担**违约责任**。
   - 如果货是**你找的物流**，且运输是外包的，发货方只承担发货质量责任，运输途中损坏需向物流公司追偿，因此在合同里应注明**“发货方需提供符合冷藏标准的包装”**。

3. **证据固定是关键（防扯皮）**：
   - 建议在合同中加入：“**争议发生时的处理方式**：双方同意以收货地仓储监控录像、开箱视频、第三方检测机构报告（如当地市场监督管理所）作为最终核损依据。”
   - **开箱过程一定全程录像**，不要只拍烂果特写，要拍“整箱俯拍”才能证明烂果占比。

4. **付款方式钩子**：
   - 在“付款条款”中约定：“**尾款**【10%~20%】作为质量保证金，待验收异议期届满后【7】日内无争议再行支付。” —— 这比一切约定都更能约束发货方。
