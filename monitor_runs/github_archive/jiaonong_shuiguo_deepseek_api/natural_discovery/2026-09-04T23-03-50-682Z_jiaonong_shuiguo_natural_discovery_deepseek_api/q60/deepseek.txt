遇到水果到货不合格，处理的关键在于**“立即止损”**和**“快速补位”**，而不是纠结于和供应商“打官司”。

在不动摇营业的前提下，建议你按以下步骤操作，并直接与供应商沟通约定：

### 第一步：当场取证，明确“不合格”等级
收货时（或8小时内），务必拍下**外包装、整箱水果、个别坏果特写**三张照片，并录制开箱视频。同时用甜度计或目测判断严重程度：

- **轻微瑕疵**（如少量压痕、表皮不美观，但内部完好）：可要求“折扣收货”或“补偿下一次订货”。
- **严重不合格**（如大面积软烂、发霉、内部褐变）：必须整批拒收或立即退货，不能留作原料。

### 第二步：立即启动“紧急备货”协议（核心约定）
与供应商电话沟通时，不要只说“退钱”，重点谈**“补货时效”**：

> “这批货我下午要用，请你在**2小时内**安排同等级别的车厘子补送，如果2小时到不了，我需要你今晚12点前直接退款，另外我的损失（营业额）需要你给到下次进货折扣。”

**给供应商的三种“补货死线”承诺：**

1. **当日补货**：若上午发现问题，约定下午14:00前送达。
2. **隔日补货**：若下午发现问题，次日开门营业前（比如早8:00）必须送达。
3. **退款+优先权**：若无法按时补，供应商需立刻全额退款，并承诺你拥有**下一批到货的优先采购权**（以低于市场价5%-10%优先拿货）。

### 第三步：书面留痕，堵住“口头扯皮”
在微信或订货单上发送一句话：

> “【订货协议补充】今日订单（单号：XXX）因水果腐烂度超20%，已拒收。请确认：1）立即退款；2）最迟于**X月X日X点**前补发同规格合格品；3）如超时未补，我方保留拒收+投诉系统/扣减预付金的权利。”

这样供应商为了维护长期合作，通常会给到你最紧急的补货排单。

### 第四步：店内“无感替代”保营业（同步进行）
在等待补货的1-2小时内，不要空着菜单：

- **饮品调整**：把需要该水果的招牌饮品改为“当季特调”（换用其他已合格水果替代，如香橙拼凤梨），在菜单旁手写小提示“今日臻选”。
- **小份足量**：告诉吧台“今日该款水果不足，每杯少放10克，但补足果肉粒，客人感知不到”。
- **如果实在无替代**：下架该款，主推“隐藏款”——用店内现有哈密瓜/蜜瓜做成气泡水抬高客单价，对冲损失。

### 第五步：跟供应商签订《补货条款》（长远防患）
如果你超过一个月遇到3次类似问题，强烈建议在下次进货合同中加入：

> **“当批次验收不合格超过15%时，乙方（供应商）必须在**6小时**内无理由补货一箱（或整批），且免除当次全部运输费。若逾期未补，甲方有权按当日饮品营业额估值的30%扣减货款。”**

---

**一句话总结**：不要纠缠“谁的责任”，直接要求“2小时补货或当场退款”，并用“下次采购折扣”换取对方加急。**你的时间成本 = 顾客流失成本**，水果不合格的钱可以亏，但当天的营业流水不能断。

如果供应商确实极为强势无法补货，那就立刻让店员去附近5公里内的生鲜超市按零售价买少量应急（只买当餐用量的话，成本可控），同时把结算单拍给供应商，要求其承担该差价。
