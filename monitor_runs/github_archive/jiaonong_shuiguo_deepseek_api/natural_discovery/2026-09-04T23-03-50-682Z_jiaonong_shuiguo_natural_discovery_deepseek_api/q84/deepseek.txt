针对家庭场景（常包含老人和孩子），做水果礼盒组合时，建议遵循**“口感温和+低致敏+开盒即食”**的原则，避免过酸、过硬、有籽或难处理的水果。

以下是几个经过验证的组合方案，你可以在团购文案中按“家庭装”或“亲子装”命名：

### 方案一：主打“省心免切”组合（最推荐）
**组合：苹果 4个 + 橙子 4个 + 香蕉 2把**（去掉菠萝）
- **理由**：香蕉完全无需刀具，老人剥皮即食，孩子也爱吃；苹果和橙子耐储存，不易在快递/转运途中磕坏（菠萝带刺、易碰伤）。
- **细节**：苹果选脆甜款（如洛川、烟台红富士），橙子选无籽或少籽的（如赣南脐橙、伦晚），避免切时麻烦。
- **建议话术**：“今天收到的礼盒，随手就能吃，不用刀不脏手。”

### 方案二：丰富色彩“仪式感”组合
**组合：苹果 3个 + 橙子 3个 + 香蕉 1把 + 菠萝 1个**
- **理由**：颜色丰富（红、黄、橙、绿），拍照好看，适合家庭聚会或过节送礼。
- **关键提醒**：菠萝必须**全熟偏甜**，且包装注明“请家人处理外皮，或商家提供去芯分割服务”（许多家庭老人不会正确处理菠萝）。
- **风险**：如果菠萝发酸或刺口，容易让团员不满意。建议团购时明确提示“本款菠萝为【金钻/凤梨】品种，低酸无眼，可手撕”。

### 方案三：高性价比“大分量”组合（适合常备）
**组合：苹果 6个 + 橙子 6个 + 菠萝 1个**（不配香蕉）
- **理由**：香蕉熟得快（2-3天就会变黑），如果礼盒要放2天以上，不建议优先放香蕉；而苹果+橙子可以放一周。
- **划算点**：批量采购苹果、橙子单价低，菠萝提鲜味，礼盒分量足，适合长期自用囤货。

---

### 给团购商家的“避坑”细则（直接影响回购率）：
1. **香蕉单独保护**：香蕉怕压，若装盒务必用气泡棉隔开，并与苹果（会释放乙烯催熟）分离放置，否则香蕉一夜变黑。
2. **菠萝处理选项**：在接龙表单里加一个勾选项：“需要去果皮（切片装盒） / 整只菠萝”，选择去皮的加收3-5元加工费，能大幅提升家庭订单吸引力。
3. **苹果和橙子的挑选红线**：家庭装中尽量不用金桔、橘子等带籽且容易“上火”（部分人口腔溃疡）的品种；橙子选皮薄的，不然老人切不动厚皮。
4. **附赠小卡片**：手写一句“给全家人的新鲜，苹果寓意平安，橙子心想事成”，能提升礼盒情感价值，利于社交平台传播。

### 最推荐组合总结版（供你直接复制到团购文案）：
> “【安心全家福礼盒】红富士苹果4个 + 信橙冰糖橙4个 + 菲律宾香蕉1串。无刺、无籽、免刀切，老人小孩都能直接啃。今日下单还送切菠萝神器。”

如果你今天一定要上菠萝，就用**方案二**并且强调“菠萝已催熟，收到即食”，同时把组合里的其他水果数量下调，因为菠萝体积大。
