在水果采购合同中，关于坏果率的赔付标准没有统一的法定数字，主要取决于双方约定的质量标准。但通常行业惯例和建议如下，供你参考：

**1. 常见约定比例（供参考）：**
- **精品/高端水果（如进口车厘子、晴王葡萄）**：坏果率通常应控制在 **1%-3%** 以内，超过即视为违约，需按比例赔付。
- **普通大宗水果（如苹果、柑橘、西瓜）**：坏果率一般在 **5%-10%** 以内可接受，超过5%或10%的部分，供应商需承担赔偿责任。
- **易损耗水果（如草莓、荔枝、杨梅）**：因保鲜难度大，合同常约定 **10%-15%** 的合理损耗，超过此比例需赔付。

**2. 关键操作建议：**
- **不要只写比例，必须写明“赔付计算方式”**。例如：“坏果率超过5%时，每超出1%按该批次货款总额的X%进行赔偿”，或“超出部分按斤折算金额退款”。
- **明确“坏果”定义**：如腐烂、发霉、明显机械伤导致无法售卖、冻伤等，避免后期扯皮。
- **约定验收时限与异议期**：例如“收货后24小时内开箱抽检，48小时内书面提出质量异议，逾期视为合格”。
- **写明拒收权利**：若坏果率超过 **15%-20%**，收货方有权整批拒收并要求换货或退款。

**3. 简单判断标准：**
如果你现在要签合同，建议直接将坏果率上限设为 **5%**（对大宗水果）或 **3%**（对精品水果），并搭配阶梯式赔付。如果对方坚持8%以上，则需警惕其供应品质风险。

**无需援引具体法律条文，合同自由约定优先。** 若未约定，则需依据《民法典》中“质量不符合要求”的违约责任处理，但举证和赔付计算会较麻烦，因此务必把比例写清楚。
