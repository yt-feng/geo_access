针对商超采购菠萝的销售策略，**建议采取“整果为主 + 切块为辅，动态灵活调整”的组合模式**，而非单一选择。具体原因和实操建议如下：

### 一、两种模式的利与弊对比

**1. 卖整果（保留原果）**
- **优势**：
  - 损耗低：菠萝表皮厚，不易碰伤，库存可存放3-5天。
  - 客单价高：单次购买金额大，适合家庭囤货。
  - 操作简单：无需切割，减少人力损耗。
  - **品质可验**：顾客能按、能闻、能挑选，信任度高。
- **劣势**：
  - 食用门槛高：需要削皮、挖孔，很多年轻顾客不会处理或嫌麻烦。
  - 购买冲动弱：体积大、占地方，且不是即食，散客购买率低。

**2. 卖切好的（盒装/杯装果切）**
- **优势**：
  - 即食便利：开盒即吃，迎合单身、白领、逛街客群的需求。
  - 单品毛利高：果切定价通常为整果的一倍以上，甚至可达2-3倍毛利。
  - 消耗次品：可以把磕碰、卖相不佳但新鲜完好的菠萝内部利用起来。
- **劣势**：
  - **损耗风险极大**：菠萝切开后氧化快，当天卖不掉只能报废（一般保质期不超过12小时）。
  - 食品安全压力大：需冷藏展示，且必须有“当日现切”标识，卫生风险高。
  - 人工成本高：需要专人或高峰期轮流切。

### 二、核心判断依据：门店客流与商圈类型

| 门店类型 | 建议策略 | 原因 |
|---------|---------|------|
| **社区型/家庭型门店**（早晚买菜为主） | **整果占7成，切果占3成** | 购买者多为家庭主妇/长辈，他们愿意买回家自己削，图实惠；切好的主要吸引年轻人临时解馋。 |
| **写字楼/步行街/医院附近门店**（上班族、流动客多） | **切果占6成，整果占4成** | 顾客多为即时消费，没有太多加工时间和工具，果切销售黄金期集中在午餐后和下班时段。 |
| **中高端商场店** | **切果为主，整果少量试吃引流** | 客群对价格不敏感，更在意颜值与便利，果切可以做精致杯装/拼盘形式，叠加溢价。 |

### 三、损耗控制与运营细节（决定成败）

如果无法完全掌握损耗率，**千万不要只卖切好的**。必须做以下配套动作：

1. **分时段控制切割量**
   - 上午10点前切一批（供午间），下午2点后切第二批（供下班/晚间）。
   - 同一批果切，如果到下午3点未卖完，立即降价20%-30%促销，或搭配酸奶/橙子做成水果捞。

2. **整果带动切果**
   - 用整果堆头作为视觉展示，现场提供免费试吃小块。顾客吃后往往会在“买整果”和“买果切”之间二选一，但试吃能让销量提升约15%。

3. **后援策略**
   - 果切盒上标注**“切制时间”**（如：10:00切制，建议当日食用）。
   - 假如一天预计卖出100斤菠萝，建议备货70斤整果、额外预留30斤转化的果切原料。若整果卖得好，果切需求下降，就少切；若整果卖不动，立即切开保存果肉止损。

### 四、最终建议

**标准答案：不要二选一。**

- **主力建议：** 以整果为主打（价格明示：如8元/斤、2个15元），旁边摆放已切好的小盒试吃，设“私人订制”服务（顾客选好整果后，现场免费代削皮）。
- **提高坪效的做法：** 在人流高峰时段（17:00-19:00），将卖剩下的少数整果直接现场切成盒装，搭配“买一盒送一个叉子”的即食场景。

**一句话总结：卖整果保底和降低风险，卖切好的赚取额外毛利与年轻客流。核心是看你会不会控损——如果只能二选一，建议先卖整果，等跑熟客流后再逐步增加果切比例。**
