在便利店卖菠萝切块，这三方面都需要系统化考虑，但优先级和具体做法可以这样拆解：

**1. 保质期（第一优先级）**  
这是食品安全和损耗控制的核心。菠萝切块属于高水分、高糖分水果，切开后极易氧化变质。  
- **冷藏条件**：必须严格控制在0-4℃环境，出售时需在冷藏柜展示。  
- **最佳赏味期/保质期**：建议短保（24-48小时），在包装上明确标注“当天切制”和具体过期时间点（精确到小时）。  
- **防伪措施**：建议在包装上打印“开切时间”或“保鲜截止时间”，并规定售卖期限（如开切后满12小时即报废）。

**2. 包装（直接影响切块寿命和购买意愿）**  
- **材质**：使用**透气性适中、防积水的PE或PP材质**盒装，盒底加吸水性纸垫，防止汁水浸泡果肉。  
- **密封与气调**：有条件的话用**气调包装（充氮/二氧化碳比例）**，能延长氧化褐变。普通便利店可用一次性透明盒+保鲜膜，但需在2小时内销售或复盖冰袋。  
- **标注与份量**：标明净含量（如200g/盒）、糖度提示（如“台湾凤梨·甜度15”），并附一次性果叉。切记不要使用铁签，易氧化发黑。

**3. 配送频次（损耗与新鲜度的平衡）**  
- **原则**：**小批量、多频次**。如果便利店日均销售10盒，建议由中央厨房或供应商**每日配送2次**（如上午开门前、下午2-3点）。  
- **依据**：上午配送用于午市，下午配送补充晚市，避免长时间在售。若门店动销慢，可减为每日1次但缩短售卖时限。  
- **应急补充**：周末或节假日需临时增配，或店内预留切块罐头原料（但口感差，不推荐长期替代）。

**额外关键点：冷链断链控制**  
从仓库到便利店，全程冷藏车（约4℃）。在收货时，店员用温度计抽查中心温度（应≤5℃），否则拒收。

**实操建议**  
- 在柜台显著位置放**“当日新鲜切制”**告示牌，提升可信度。  
- 每2小时检查一次冷藏柜温度，并记录在检查表（避免责任纠纷）。  
- 售卖前建议试吃1块，若发现甜度下降或发软，立即下架。

总结：**保质期设置（24h短保）> 包装（透气防渗漏+标签）> 配送频次（至少每日2次）**，三者互为条件。若便利店不具备冷链条件或销售不稳，建议改为**现切售卖**（顾客从整菠萝中挑，现切现装），能规避库存风险。
