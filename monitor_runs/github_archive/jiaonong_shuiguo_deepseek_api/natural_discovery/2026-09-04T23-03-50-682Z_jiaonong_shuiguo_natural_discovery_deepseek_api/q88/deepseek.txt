线上水果销售确实很考验供应链和品控，坏果和口感往往是差评的集中爆发点。要减少这些问题，不能只靠售后，而要从采购源头抓起。

以下是比较有效的几个实操方向，建议按优先级执行：

**1. 选对基地，不要只比价格**
- **实地或远程验厂**：尽量去产地，哪怕视频验果。重点看果园管理（是否套袋、有机肥使用情况）和分选线是否规范。
- **避开“通货”**：有些批发市场的“统货”混合了大小、成熟度，一定不要选。要选按**克重分级**或**糖度分级**的专供果。
- **锁定“头茬果”或当季果**：如果卖的是应季水果，优先产地直发，避免库存果或冷库果（口感断崖式下跌）。

**2. 锁定“套袋果”和“病虫害少”的产区**
- 如果卖苹果、梨、桃等易烂果，尽量采购**套袋果**，运输抗性远强于不套袋的。
- 采购时要求供应商出具**农残快检报告**，但这只是底线；更重要的是病虫害防控记录（比如是否使用低残留药），因为虫眼最容易在运输中霉变。

**3. 成熟度是口感的关键，但要结合物流天数**
- 7成熟发货适合远距离（2-3天），但口感偏脆偏酸；如果距离近（次日达）可以考虑8-9成熟，香甜度高。
- 建议让供货商按你的物流范围做“**梯度采摘**”：本地或次日达的发熟一点，远处发7成熟。
- 不要买“催熟果”。很多电商为了赶时间，用乙烯利催熟，外观红但口感寡淡，这是差评重灾区。

**4. 包装和分拣直接决定坏果率**
- 要求源头**“一果一坑”或“双网套+珍珠棉”**，而不是普通泡沫网。尤其是阳光玫瑰、水蜜桃、猕猴桃这类软果。
- 明确要求**“单果称重选果”，剔除坏果、软果、裂果**。很多差评是收到包装内只有1-2个烂的，其实根源是分拣不严。
- 温度敏感水果（如荔枝、杨梅）必须加**冰袋或专用冷链**，不要省这个钱。

**5. 建立“小批量试单+采购合约”机制**
- 不要一次性大量囤货。先订购首批小样（比如100箱），按你的标准发货测试，看破损率和客户反馈。
- 如果供应商稳定，可以用“**损耗率考核条款**”约束：比如坏果低于5%才结全款，高于10%要按比例赔。这样倒逼他们从源头提高鲜度。

**6. 建立“口头承诺无效，文字留痕”的制度**
- 采购单上必须写清楚：**糖度值（如≥12度）或成熟度范围、单果克重范围、允许坏果比例（≤2%）、发货温度要求**。
- 附上标准图片（切开内部图、虫眼图样例），让采购买手有直观标准，避免主观判断。

最后，给你一个可执行的口诀：
> **“产地专果不贪便宜，成熟度按距离切，套袋双网防碰伤，小单试错再放量，指标白纸黑字写清。”**

如果你们是刚起步，可以优先选择采购某省的核心产区（如山东烟台苹果、四川蒲江猕猴桃等），用当地专业合作社的标准化果，比杂乱的农批市场稳定得多。
