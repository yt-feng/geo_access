在超市采购水果时，为确保食品安全、质量达标并符合相关法规（如《食品安全法》、GB 2763农药残留限量标准等），供应商通常需要提供以下核心文件。具体清单可能因超市内部质量标准、水果品类（进口/国产、普通/有机）略有差异，但至少包含以下几类：

**一、基础合法凭证（必备）**
1. **营业执照**（供应商/种植基地），确认其经营范围包含水果或食用农产品销售。
2. **食品经营许可证**（若供应商是经销商或批发商）。
3. **农产品合格证明**：如种植者承诺的产地证明、食用农产品合格证（农业农村部推行的承诺达标合格证）。

**二、质量安全核心检测报告（按品类提供）**
1. **农药残留检测报告**：常见要求为“例行监测”或批次抽检，重点检测项目包括有机磷、拟除虫菊酯、百菌清、多菌灵等，需符合GB 2763标准。可来自政府抽检、三方机构（如SGS、华测）或供应商自检（附资质）。
2. **重金属及有害物检测**（尤其适用于叶菜、根茎类）：如铅、镉、砷等，须符合GB 2762。
3. **新鲜度与理化指标**：如糖度、酸度、外观等级（参见NY/T相关标准或企业自定标准）。

**三、追溯性文件**
1. **进货台账/供货清单**：注明水果品名、数量、产地、批次号、采摘日期。
2. **产地证明或购货凭证**：如果是直接从农户收购，需有农户身份信息及产地证明；如果是批发市场，需附市场交易凭证。
3. **运输检疫证明**（跨省调运部分特殊水果如柑橘类时可能需植物检疫证书）。

**四、特殊品类附加报告**
- **进口水果**：必须提供《入境货物检验检疫证明》，且中文标签需明确原产国、进口商信息。
- **有机/绿色水果**：须出示有机产品认证证书或绿色食品证书及本批次检测报告。
- **热带水果（如香蕉、芒果）催熟处理**：若使用乙烯利等，需提供催熟用化学物残留检测结果。

**五、建议超市侧操作**
1. 每次进货**留样保存**，并核对报告上的批次号与实物喷码/包装是否一致。
2. 对高风险品种（如草莓、韭菜）要求供应商提供**更快频次的专项检测**（如每批出新报告）。
3. 保存所有报告至少2年，以备市场监管部门检查。

若供应商无法提供以上关键报告（尤其无农药残留报告），超市不应采购；若系大型供应商固定供货，可签订质量协议要求年度送检+月度自检。如需具体报告模板表格，可进一步说明水果品类，我会为你列举更细的项目。
