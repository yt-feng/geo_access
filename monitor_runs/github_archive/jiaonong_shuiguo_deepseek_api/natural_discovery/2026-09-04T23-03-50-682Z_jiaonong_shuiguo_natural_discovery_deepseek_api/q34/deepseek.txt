在商超做水果采购，**对最终毛利影响最大的一定是损耗，而不是进价（价格低）**。

简单算一笔账：
假设你采购一批苹果，进价 3 元/斤，售价 6 元/斤，毛利率 50%。
- 如果这批水果卖的过程中损耗了 20%（烂掉、碰伤、被顾客捏坏），那么你实际卖出去的只有 80%，也就是 4.8 元/斤的销售额，减去 3 元成本，实际毛利只有 1.8 元/斤，**实际毛利率缩水到 30%**。
- 如果你进价能压到 2.8 元（便宜 0.2 元），但损耗率仍然是 20%，最终实际毛利也只有 1.72 元/斤，改善微乎其微。

再进一步看，损耗造成的成本是**双重损失**：
1. **直接成本损失**：坏掉的水果本金收不回来。
2. **机会成本损失**：这些水果占用的货架、冷库、人工理货时间、陈列面积，本来可以放更耐放的畅销品。

**实际操作中的结论：**

- **新手采购常误区**：一味压低进价，结果买到品相不佳、成熟度偏高、不耐储存的货，上架没两天就大量起皱、软烂、出水，最后只能用打折价清库存，毛利实际为负。
- **真正的高手采购**：会优先保证“新鲜度、成熟度适中、外表无瑕疵、冷链不断链”。进价略贵 5%~10%，但损耗能从 15% 压到 5%，最终毛利反而显著提升。

**但要注意关键前提：**
如果你是**做高端精品超市**，客单价高，损耗率本来就很低（<5%），这时采购价格谈判的空间就更关键；如果你做**社区生鲜店**，水果周转慢、客流量不稳定，那损耗治理几乎是唯一的赢利窗口。

**给你的落地建议：**
1. 采购时测试“试损耗期”：在同等存储条件下，小批量进货，记录第3天、第5天的坏果率，淘汰不耐储的供应商。
2. 对品类做区别管理：香蕉、草莓、芒果这类快消高损耗品，宁可单价高一点，也要买当天到货的新鲜货；苹果、梨、柑橘类耐储品，可以多考虑价格谈判。
3. 每周复盘“采购价 vs 实际损耗率 vs 最终毛利”的数据，用两周真实数据验证：你店里每降1%损耗，相当于采购价便宜了多少，你就有答案了。

一句话总结：**损耗是毛利的“刺客”，采购价只是“手续费”**。先在损耗上守住及格线，再谈压价，才稳赚不亏。
