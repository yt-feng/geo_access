针对小水果店进货香蕉，**优先级建议排序为：坏果率 > 熟度 > 送货速度 > 价格**（价格放在最后，因为“便宜”往往对应上述前几项的牺牲）。

具体理由和操作建议如下：

1. **坏果率（最核心，直接影响利润）**
   - 香蕉是典型的“重损耗”商品，一旦出现挤压、裂口或内部发黑（炭疽病），整把都要处理，损耗可能达到10%~30%。
   - 进货时，**当场拆箱检查**，重点看果柄是否断裂、果皮是否有黑斑或指甲印、包装纸内是否有积水。
   - 坏果率建议控制在3%以内，如果超过5%，哪怕价格再低也坚决不要。

2. **熟度（决定你的销货时间窗口）**
   - 香蕉熟得快，进得太生（全青）客户不买；太熟（表面大量黑点或软塌）当天卖不完就报废。
   - 根据你店铺的日均销量定熟度：
     - 周转快（1-2天卖完）：可进 **七至八成黄**（带少量绿头），放柜台上自然熟。
     - 周转慢（3天以上）：必须进 **六成黄以下**，否则第三天就是坏果。
   - 不要依赖老板说“很熟”，自己拿手捏中部，有明显的软度才算合格；硬邦邦的成熟度不够。

3. **送货速度（影响库存成本，但不急于一小时）**
   - 香蕉不像叶菜需要“抢鲜”，只要熟度合适，晚半天问题不大。
   - 关键是**稳定**：选择能固定时间（比如每天早上9点）送达的供应商，避免高峰期断货或突然缺货。
   - 如果你今天订，明天中午才到，且你销量小，那就说明该换供应商。

4. **价格（放最后，但要看“总成本”）**
   - 进货单价低1毛/斤意义不大，但若为此多出10%的坏果，反而亏更多。  
   - 比较价格时，算“净得售价”：假设进价1.8元和2.0元/斤，若2.0元的坏果率只有1%，而1.8元的坏果率8%，你卖同样的价，后者每斤多亏0.3元以上。
   - 另外，问清是否含运费、是否支持退换当天坏果，这是隐形价格。

**具体操作建议：**
- 首次合作小量试进（比如2箱），当天拆开检查坏果比例和口感（试吃一根）。
- 与供货商明确约定：**“坏果率超过5%按实际重量扣款或下次抵扣”**，写在送货单上，口头承诺无效。
- 旺季（春节、清明前后）提前3天预定，成熟度选偏低的六成黄，避免天气突变造成积压。
