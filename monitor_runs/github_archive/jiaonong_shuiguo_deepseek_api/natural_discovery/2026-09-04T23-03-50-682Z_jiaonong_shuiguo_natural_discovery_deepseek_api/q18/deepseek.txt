要为超市采购香蕉并确保到店时熟度合适，可以遵循以下几个核心原则：

1. **明确目标熟度（到店即食 vs. 补货架）**：
   - 如果是当天上架销售，建议采购**半熟偏生**的香蕉（果皮微绿、果肉微硬但有弹性），这样到店后2-3天内会自然成熟。
   - 如果是用于日常补货且货架周转快，可采购**七成熟**（表皮黄绿相间），到店后当天或次日即可达到最佳口感。

2. **关注产地与采摘成熟度**：
   - 催熟能力有限时，优先选择**产地成熟度在70%-75%**的香蕉（香蕉在采摘后无法继续增加糖分，只能将淀粉转化为糖，需预留足够成熟时间）。
   - 可要求供应商在产地暂停“气调催熟”，只做基础预处理，确保运输途中不会过度成熟。

3. **匹配运输与到店时间**：
   - 如果运输需2-4天（如产地到店），必须选择**更绿、更硬**的香蕉（成熟度65%左右），到店后结合催熟柜进行控制。
   - 如果运输仅1天内（本地近郊），可选略成熟（80%左右），到店后直接上架。

4. **拆箱检查与手测判断**：
   - 开箱时看**果柄颜色**：深绿→过生；黄绿→催熟初期；全黄→接近熟透。
   - 轻捏香蕉**中部与两端**：过硬且无弹性→偏生；微软有轻微回弹→偏熟；明显绵软→过熟（不适合长期陈列）。
   - 检查是否有**外伤或黑斑**：外伤会加速局部腐烂，影响陈列期。

5. **签订合同条款明确供应商标准**：
   - 在采购合同中写明“到货时成熟度区间”（如：表皮黄绿比例10%-30%），并约定**验收不合格可拒收或换货**。
   - 要求供应商提供采摘日期、装柜时间，必要时可附装箱照片/视频作为验收依据。

6. **店内催熟与陈列预留“缓冲”**：
   - 采购偏生时，到店后放入专用催熟柜（18-20℃，乙烯浓度适当）并按需调节；若无催熟柜，则置于通风阴凉处延缓成熟。
   - 货架实际陈列时，按照“先到先出”原则，并区分“今日可售”与“明后日可售”区域，避免销售完过熟批次。

**执行提示**：
- 不要只看外箱标签上的“A级/特级”，要结合实物性状共同判断。
- 可以合作前先要求供应商寄送3根试品，模拟你的运输条件后观察2-3天，确认成熟节奏符合需求再下单。

**特别提醒**：香蕉对温度极敏感，收货后避免存放在10℃以下（会冻伤变黑）或超过22℃（会加速熟软）。若到店时整体已经偏熟（摸着头尾软度均匀），需立即降价促销或分装冷冻处理，避免损耗。
