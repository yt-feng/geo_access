茶饮店在控制食品安全风险时，向水果供应商索要证明和文件是保障合规和溯源的关键步骤。供应商需要提供以下几类核心证明（包括但不限于）：

1. **营业执照**  
   - 证明供应商是合法经营主体，经营范围需包含水果销售或配送。

2. **食品经营许可证**（或食品生产许可证，若供应商为加工厂）  
   - 这是合法供货的必备证照，需在有效期内，且覆盖其实际经营类别。

3. **农副产品产地证明或合格证明**  
   - 例如：产地的《食用农产品合格证》、种植基地的“三品一标”证书（绿色食品、有机产品、无公害农产品、地理标志产品，若有）。

4. **水果的检验检疫合格证明**  
   - 若是进口水果，需提供《入境货物检验检疫证明》及对应报关单；国内果品，可要求供应商提供农残、重金属等项目检测报告（通常每批次或每月更新）。

5. **送货单/发货单及批次记录**  
   - 每批水果都应有明确的收货日期、品种、数量、产地、批次号，便于溯源。

6. **储存与运输承诺或资质证明**  
   - 若涉及冷链运输，供应商需提供冷藏车/冷库的温控记录或相关设备校准证明，以证明符合保鲜要求。

7. **供应商年度质量承诺书或食品安全责任书**  
   - 属于商业文件，明确供应商对质量安全的法律责任。

**实操建议**：  
- 茶饮店应建立供应商准入档案，首次合作时收取上述证照复印件并盖章（鲜章或电子章），之后每年复核或按季度更新。  
- 高风险环节（如鲜切水果、果汁）需额外要求每批次的《农药残留快速检测报告》或委托第三方检测。  
- 与供应商合同中应明确一旦发生抽检不合格，由供方承担赔偿及责任。

**注意**：不能凭口头保证或随意截图入档，所有文件必须真实且在有效期内。若供应商无法提供核心证照，建议优先考虑更换供应商。若涉及地方性法规（如某些城市要求本地准入门槛），请以当地市场监管局要求为准。
