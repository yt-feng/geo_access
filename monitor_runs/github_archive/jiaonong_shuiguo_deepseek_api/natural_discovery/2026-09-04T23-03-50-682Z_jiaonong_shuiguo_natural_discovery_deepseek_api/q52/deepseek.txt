甜品店采购香蕉避免快速变黑，核心是**控制成熟进程**和**保鲜储存**。以下分采购前、到店后、应急处理三块建议，供你直接操作：

---

### 一、采购源头上选对货（最关键）
1. **选成熟度略低的**：不要全挑全黄、带黑点的“熟香蕉”，应选**果皮整体偏青绿、棱角仍明显**的。这类到店后自然熟化，能撑2-4天。
2. **避开有损伤的**：检查果柄是否断裂、果皮是否有压伤或水渍，损伤部位接触氧气后发黑速度极快。
3. **按日用量分批采**：若要长期用，优先选7-8成熟的（微黄带青），短期（1天内）用可买全黄。

---

### 二、到店后的保鲜操作（重点）
1. **立即拆开密封包装**（塑料袋、保鲜膜），换成**透气纸箱或竹筐**，每层垫干燥纸，避免乙烯气体浓度过高加速催熟。
2. **单独存放，远离苹果/梨/成熟蜜瓜**：这些水果释放乙烯，会催熟香蕉。
3. **控制温度和湿度**：
   - 放**阴凉通风处**，最佳温度13-15℃（普通室内若超25℃会很快变黑）；
   - **不要放冰箱冷藏**（除非已熟透需要延长1-2天，但皮会先变黑褐，内部还行，适合做果泥、烤香蕉等）。
4. **悬挂或平放**：如果后厨有挂绳，用**挂钩挂起**（模拟原生长状态），减缓底部压伤；没有就**拱面朝上**平放（弧面朝上，减少接触面）。
   - 紧急采不到低成熟度的，可入库后用**小风扇低速吹风**10分钟，降低表面温度。

---

### 三、应急与补救技巧
- **分边处理**：成熟度最高的或已有斑点，当天优先做**香蕉泥、香蕉片、焦糖香蕉**，不要等。
- **微喷柠檬水？** 传统上切开的果肉可涂柠檬汁防氧化，但整根香蕉皮**不要碰水**，水分残留会加速霉变。
- **已开始变黑但内部完好**：不影响烘焙或熬酱，直接冷冻保存（剥皮切段密封冷冻），可攒一周用量。

---

### 总结执行清单
| 环节 | 行动 |
|------|------|
| 采购 | 选青黄相间、无伤、无挤压的 |
| 到店 | 拆袋透气、放阴凉架、原产地果柄向上挂 |
| 环境 | 远离其他水果、避免高温潮湿 |
| 紧急 | 变黑前排单用掉，或冷冻锁风味 |

如果店内订货量较大，建议找能提供“预熟度分级”的供应商，每周两次小批量到货，比一次性大批采购划算。
