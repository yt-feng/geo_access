在酒店采购水果盘原料时，供应商至少应保证以下规格和外观标准，以确保成品呈现优质、卫生且符合酒店档次：

---

**一、规格标准（可量化、可验收）**

1. **单果重量/大小等级**  
   - 每种原料须按品种明确大小（如西瓜按单瓜重、切块为指定克重；猕猴桃直径、芒果单果重），应分档（如S/M/L/XL），同一批次等级一致，偏差不超过±10%。

2. **成熟度（可溶性固形物/硬度）**  
   - 供应商应提供成熟度达标证明或标准：如香蕉7-8成熟、芒果8成熟、火龙果软硬适中；水果切开后应无生涩味、无过熟软烂。

3. **可食用率/出肉率**  
   - 如去皮去核后的净出肉率应≥要求（通常菠萝≥60%、西瓜≥50%、橙子≥45%），供应商报价时可注明测算基准。

4. **切配规格（若含预处理）**  
   - 若供应已切块水果：要求每块尺寸统一（如2×2×2 cm或指定形状），厚度一致，无连刀、无破损边。

---

**二、外观标准（可目测检查）**

1. **色泽均匀、自然**  
   - 成熟带来的天然颜色，无大面积褐变、无药斑、无催熟剂导致的青黄不均。切开切面不得氧化发黑，需有护色处理（如涂淡盐水）或低温配送。

2. **果皮/表面完整**  
   - 无机械伤、压伤、刺孔、裂纹、破皮；无虫蛀孔洞、虫卵附着，无病斑、霉斑、腐烂迹象。

3. **形状端正**  
   - 品种典型外形不应变形（如非畸形果），不得有萎缩、干瘪、凹陷。

4. **清洁度**  
   - 表皮无泥土、杂质、农残可疑残留；如去核、剥皮产品，内部无种子残留、果核碎屑，无苦涩白膜残留过多。

---

**三、附加底线要求（可合同化）**

- **新鲜度**：从采摘到交付≤48小时，冷链运输温度（如4℃）且有温度记录。
- **无农残超标**：须能提供对应批次的检测报告或产地合格证。
- **零腐败**：同一订单中，坏果率（霉变/腐烂）应为0%，允许的微伤率≤1%且不计入收费。
- **包装卫生**：外箱无压扁、内衬食品级隔离纸/膜，避免二次污染。

---

**建议采购方执行：**

- 到货即检，随机抽3-5箱，按上述标准逐一打分，不合格整批拒收或降级扣款。
- 与供应商签订《验收标准附件》，将规格外观白纸黑字固定，避免扯皮。
