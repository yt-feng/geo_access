选水果供应商时，**最应该优先问“售后”**，其次是“配送”，价格放在最后。

原因很简单：水果是生鲜，损耗率极高。价格再低、配送再快，一旦出现坏果、烂果，如果供应商不负责，你的损失和客诉会直接吃掉利润。

具体建议按以下顺序提问：

1. **售后政策（必须谈清楚，白纸黑字）**
   - 坏果包赔标准：是“坏一个赔一个”还是“整箱赔付”？理赔时效是几小时？
   - 赔付方式：是直接退款、补发，还是下次订单抵扣？
   - 责任界定：运输途中挤压、客户收货后超时未取，谁负责？
   - 签收要求：是否需要客户开箱验货？坏果是否需提供照片/视频？

2. **配送能力（影响新鲜度和体验）**
   - 从产地/仓库到你的城市，**全程冷链还是普通运输**？
   - 具体发货时间（是上午摘下午发，还是隔天发）？
   - 配送时效：今天发货，大概多久能到你的仓库或客户手中？
   - 是否支持分批/指定时间送达（比如避开周末）？

3. **价格（最后谈，且要结合品质）**
   - 不要只问“多少钱一斤”，要问**同价位下果径、甜度、成熟度**的标准。
   - 问清楚是否含包装箱、运费、税费。
   - 要一个阶梯报价（拿货量不同，价格怎么浮动）。

---

**给你一个决策建议**：
- 如果供应商售后含糊其辞（比如“差不多都会处理”），建议直接pass。
- 如果售后爽快、白纸黑字写清赔付，即使每斤贵5毛，也值得长期合作，因为省下的售后成本远高于差价。

**最后提醒**：签约前，**先小批量试单一次**，亲自检验售后和配送的兑现程度，再决定是否长期合作。
