要判断哪个规格的菠萝更容易出货，核心在于**匹配你的目标客户群和当前市场节奏**，而不是单纯看大小。判断的标准不是“哪个好”，而是“哪个卖得快、退货少”。

我给你一套可直接落地的判断方法，分为**短期试错**和**长期数据验证**两步。

### 第一步：先看你的下游是谁（明确主战场）

不同渠道，规格偏好完全不同：

| 你的批发客户类型 | 最容易出货的规格 | 判断依据 |
| :--- | :--- | :--- |
| **水果店/社区生鲜** | **中等果**（1.5斤-2.2斤/个） | 顾客自己吃，太大吃不完，太小没肉。性价比最稳。 |
| **餐饮/烘焙/果汁店** | **大果**（2.5斤以上） | 他们只在乎出汁率或出肉率，且大果损耗低，切块效率高。 |
| **路边摊/流动摊** | **小果或次级果**（1斤以下，或外观有小瑕疵） | 单价低，走量快，适合“10元3个”的促销场景。 |

**关键动作**：今天别问自己，直接问你最稳定的3个大客户的最近提货记录，他们的复购规格就是你的基本盘。

### 第二步：用“三个指标”做短期小批量试水（不要全押）

不要一次性进两种规格的大量货。用试销法，比如各进50箱，上架3天，记录以下数据：

1.  **翻单率（最核心）**：同一位客户，3天内是否第二次来拿这批货？如果客户吃了回头单，说明终端动销好，立刻加大该规格采购量到80%。
2.  **挑剔率**：客户开箱验货时，对**大小不均**的抱怨多不多？如果客户反复要求“再挑匀一点”，说明这个规格的下游客户很在意**单果重量一致性**，你要么严选，要么换挡。
3.  **走量速度**：批发市场有个规律——**早上9点前**被抢走最多的那款，就是当日硬通货。如果大果在9点前走完，别犹豫，后面几天就主打大果。

### 第三步：给你一个“大概率不会被套”的通用口诀

在你不确定时，按以下顺序排优先级：

**优先推“中等偏大”果（约2斤/个）**。

-   **理由**：它同时能卖给水果店和餐饮店。水果店嫌它比小果利润率高，餐饮店嫌它比大果便宜。两头都能上门，风险对冲能力最强。

---

**特别提醒（风险规避）**：
如果遇到**台风季**或**连续阴雨天**，请立刻**下调主推规格**，改推小果。因为恶劣天气下，消费者购买力下降，大果极易滞销放坏，而小果单价低、流转快，跌价损失最小。

**最后给你一个执行清单（明天就干）**：
1. 今天下午，给老客户群发消息：“明早到货，有1.8斤左右的A级果和2.8斤的特大果，你先留哪款？”统计回复最多的那个。
2. 明早到货后，把主推规格放在**摊位入口的第一个**，副推规格放第二排，观察5个小时。
3. 如果傍晚收摊时，主推规格的库存剩得比副推多，**立刻调整位置**，不要跟市场赌气。

一句话总结：**没有固定必出的规格，只有跟着客户订单走的规格。多赚的钱，来自比别人快半拍调整主推位置。**
