水果礼盒的搭配，核心逻辑是**颜色好看、口感互补、寓意吉祥、价格分层**。根据你的目标客群（自用、送长辈、送客户、送情侣），我给你几个直接可用的组合方案：

### 方案一：经典红黄绿搭配（性价比走量款）
**适合主流家庭、探望病人、走亲戚。**
- **搭配**：红苹果（3个）+ 橙子（4个）+ 香蕉（1把）。
- **优点**：香蕉是硬通货，人人都能吃；苹果红色喜庆，橙子金黄色贵气。成本低，大众接受度最高。
- **建议**：香蕉顶端不要切太齐，整把放盒角，摆成扇形，视觉上很满。

### 方案二：金玉满堂（送领导、客户、商务送礼）
**主打“高端感”和“好意头”。**
- **搭配**：橙子（6个）+ 菠萝（1个，竖切成两半斜放）。
- **优点**：橙子代表“心想事成（橙）”，菠萝谐音“旺来（菠萝台语）”，且菠萝体积大，能撑起礼盒的“档次感”。
- **建议**：菠萝一定要选叶子翠绿完整的，竖切带叶摆入，视觉冲击力强。如果盒子不够深，可只切半颗，但要用保鲜膜包好切面。

### 方案三：清爽解腻款（年轻人、提亲/过节）
**主打“多样少量”，适合新式伴手礼。**
- **搭配**：苹果（2个）+ 橙子（2个）+ 香蕉（2根斜放）+ **菠萝切丁块（一小碗）**，底层铺碎冰袋或生菜叶。
- **优点**：主打新鲜、尝鲜，菠萝现切配个竹签，视觉上像平切果盘，显得贴心。
- **建议**：说明是“开盒即食”，适合办公室下午茶场景。

### 方案四：万能金字塔公式（最稳妥的摆法）
如果不想太复杂，直接按**体积从大到小**摆放：
1.  **底层（承重）**：放**菠萝**（切半或整颗），占盒底一边。
2.  **中层（填缝）**：放**橙子**，一个挨一个码齐。
3.  **顶层（点缀）**：放**苹果**3个形成稳定三角形。
4.  **空隙（灵魂）**：**香蕉**不要整把放，拆开2-3根，自然弯曲地塞进苹果和橙子之间的空隙里，颜色金黄最能提亮。

---

### 关键提醒（直接影响好不好卖）：
- **避坑**：**香蕉和苹果、菠萝不能挨着放**！它们会释放乙烯催熟，两天内香蕉就会发黑、菠萝会变软。**香蕉必须用隔层（纸板/珍珠棉）和苹果/菠萝隔开**，或者香蕉放在礼盒最上层。
- **文案包装**：配一张手写小卡，例如“苹（平）安喜乐，前程（橙）似锦，香（相）伴一生，菠（发）财旺运”，能刺激购买欲望。
- **尺寸问题**：如果盒子是普通提篮，菠萝建议只买半颗并切好装入密封盒再放进去，否则盒子盖不上，显得松散。

**最推荐你先做“方案一”试水**，因为它成本可控，顾客看到红黄绿搭配就愿意买。如果一周内周转快，再考虑引入切块菠萝的“方案三”提高客单价。
