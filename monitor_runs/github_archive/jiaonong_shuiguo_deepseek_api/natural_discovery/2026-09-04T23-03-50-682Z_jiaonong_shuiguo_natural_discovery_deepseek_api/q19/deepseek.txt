在超市卖菠萝，**最核心的衡量标准是“综合毛利率”与“损耗控制”**，而非单一追求风味极致。具体优先级建议如下：

**1. 首要关注：切果损耗（决定性因素）**
- **为什么？** 超市不是水果店按个卖甜度，**切菠萝的损耗率直接决定毛利**。若整果损耗率超过25%，即便进货甜度极高，也可能卖一份亏一份。
- **具体操作**：进货时让供应商提供“去皮后出肉率”数据（一般45%-55%为合格），优先选**果型较圆、芽眼浅、果肉厚**的品种，这类果切削损耗低。若整果销售为主，损耗占比降低，则降级为次要考量。

**2. 次要关注：外观（直接决定陈列与顾客第一印象）**
- **标准**：果皮颜色均匀、无大面积褐斑或霉点，果眼排列整齐（俗称“帽子”）规则，果柄新鲜不发黑。
- **矛盾处理**：若外观漂亮但略生，可引导为“放两天再吃”；若外观瑕疵但不影响果肉，建议直接做**切块试吃装**，二次加工弥补外观缺陷，反而促进销售。

**3. 辅助关注：大小（影响定价心理）**
- **策略**：不建议只卖大果或小果。最佳是**大小分级供应**——大果（1.5kg以上）做高端整果定价，中果（1-1.5kg）做主力促销，小果（偏小）则切盒售卖。避免全部是大果导致客单价过高难动销。

**4. 甜度（降为“试吃口碑”而非进货硬指标）**
- **原因**：甜度是随批次波动的“体验属性”，且每个人口感偏好不同。应依靠**切块试吃、现场现切**来引导顾客，而不是在进货时因甜度否决一批果。
- **方法**：在收货时抽验1个果肉**糖度计**（12-16度为佳），但该数据只用于打分排序，不用于拒绝收货。真正要盯的是**成熟度与运输时间**，防止过熟导致内部发酵（切开会有一股酒精味）。

---

**最终执行建议（可直接落地）**：
- **收货标准单**：按“外观≥30分 + 损耗预估≥30分 + 大小规格≥20分 + 甜度抽检≥20分”打分，总分达标才收货。
- **日常陈列动作**：每天早晨切2-3个试吃品，切完立即用保鲜膜覆盖，避免变色后影响二次销售。
- **库存预警**：若库存果在库超过2天未售出，**立即转为“现切盒装”**并降价10%，避免整果烂在排面。

一句话总结：**先算损耗这本账，再用外观拉销量，最后用试吃话术补甜度短板。**
