在向供应商采购水果前，建议要求对方提供以下**核心资料**，以确保能有效应对市场监管局的农残抽检：

**1. 法定证照与合格证明（最基础）**
- **营业执照**：确认其经营范围包含水果销售或种植。
- **食品经营许可证**（或仅销售预包装食品备案，视当地要求）。
- **农产品合格证**（产地出具的食用农产品合格证，承诺不使用禁限用农药）。

**2. 源头检测报告（关键）**
- **第三方检测报告**：向供应商索取**最近三个月内**、由具有CMA或CNAS资质的第三方检测机构出具的水果报告，重点查看**农残项目（如有机磷类、氨基甲酸酯类、拟除虫菊酯类）**。需确保报告上载明的**批次/生产日期与您本次采购批次相符**。
- **快检报告**：若对方提供的是进货批次做快速检测（胶体金法等），需索取当批次的快检记录。

**3. 追溯与产地信息（应对抽检溯源）**
- **进货凭证**：供应商从种植基地或一级批发商采购的**购货清单、发票或入账凭证**，用以证明其进货来源合法。
- **产地证明或产地信息**：如水果来自全国绿色食品原料标准化生产基地，可索取相关证明；确保水果包装上有**产地、收获日期或生产批号**。

**4. 供货合同与承诺书（书面约束）**
- **质量安全承诺书**：供货方签章，承诺其供货水果符合《食品安全国家标准 食品中农药最大残留限量》（GB 2763）标准，并对违规承担全部责任。
- **购销合同**：合同中明确约定，若因农残不合格导致抽检通报或处罚，供应商应承担的一切经济损失及法律责任。

---

💡 **额外提醒（操作建议）：**
1. **索证留档时间**：以上资料妥善留存，保存期建议**至少长于该水果保质期后6个月**（如新鲜水果建议保存6个月以上）。抽检通常发生在采购后7-14天内，资料在手即可快速应对。
2. **防范“阴阳批次”**：务必核对检测报告上的**批号/规格**与实收货品**外箱喷码**是否完全一致，防止供应商用合格报告覆盖不合格批次。
3. **现场辅助手段**：收货时抽查果表有无明显药斑或异味，水果农残超标多表现在易积累的果皮（如草莓、葡萄、苹果）。可自行购买**农残速测卡**（酶抑制率法）做入仓快检，作为第一道防线。

如果对方无法提供**近期的第三方合格报告**，建议慎重采购，并可向当地市场监管部门或农业农村局咨询该供应商过往抽检信用记录（可申请信息公开）。
