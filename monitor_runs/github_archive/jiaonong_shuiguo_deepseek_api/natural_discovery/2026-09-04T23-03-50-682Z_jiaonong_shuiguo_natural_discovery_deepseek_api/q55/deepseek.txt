要判断哪种水果拼盘更划算，需要综合考虑**单价**、**出肉率**（可食用部分比例）和**损耗处理**。

以下是帮你做决策的具体方法和可执行建议：

### 1. 核心计算逻辑：算“净果成本”，而不是“毛果成本”
苹果、橙子、菠萝都有皮和核，不能直接拿进货单价比较。

**公式**：
\[
\text{净果成本（元/斤）} = \frac{\text{进货单价（元/斤）}}{\text{出肉率}}
\]

**出肉率参考（常见经验值）**：
- **苹果**：约 85% - 90%（去核去皮）
- **橙子**：约 65% - 70%（去皮去籽，最难的是很多品种水分足，建议按70%算）
- **菠萝**：约 45% - 55%（去皮去眼，切完损耗极大）

**举例**：
- 苹果 3元/斤 → 净果成本约 3.5元/斤
- 橙子 2.5元/斤 → 净果成本约 3.6元/斤
- 菠萝 1.5元/斤 → 净果成本约 3元/斤（按50%出肉率）

*所以，表面贵的苹果往往比便宜的菠萝更划算（按净肉算）。*

---

### 2. 选规格时的“隐藏坑”与建议

#### **苹果**  
- **建议选大果（8两以上）**：小果削皮费时间，且核占比高，出净肉率反而降低。
- **注意**：不要去选“颜值极高”的进口果，拼盘只需切块均匀，**国产红富士**性价比最高。
- 如果做**带皮切片**（消费者自己啃），可以按毛果算，但餐厅拼盘建议去皮。

#### **橙子**  
- 橙子是亏耗重灾区：厚皮品种（新奇士）出肉率极低，别买。
- **建议选薄皮、无籽品种**：如赣南脐橙、冰糖橙，皮薄肉满，出肉率可达72%以上。
- **规格方向**：中等规格（70-75mm果径）最划算，太大果皮厚且价高；太小肉干。
- **别买已经软了的**：软橙出汁率高但切粒易碎，摆盘难看。

#### **菠萝**  
- 菠萝是拼盘里**损耗王**，对新手餐厅最不友好。
- **建议规格**：买**带皮整果**（不要买现切好的，因为现切的一般是用便宜烂果做的，且你无法控损耗）。
- **挑“熟度”比挑大小重要**：熟透的菠萝出肉率高（但太熟容易出水），生菠萝硬且酸。
- **如果特别在意损耗**：考虑直接用**菠萝罐头**替代新鲜菠萝，虽然口感不同，但成本可控且无损耗。

---

### 3. 给你的具体行动步骤
1. **计算你附近的采购单价**。
2. 按上面出肉率把三种水果都换算成“净肉成本”。
3. **决策顺序**：
   - 如果三者净肉成本接近，**优先用菠萝**（口感独特，但必须切得漂亮）；
   - 如果成本差异大，选净肉成本最低的为主料；
   - 但不要三种都买成一样多，**压低损耗率高的水果占比**（如菠萝占比可少些，苹果多些）。

4. **实际操作检查**：
   - 请切水果的师傅测试一下，**花同样的时间**，哪种水果出盘量最多。人力成本也要算进去（菠萝切起来最耗时，如果人工贵，菠萝的隐性成本更高）。

### 4. 省成本小建议
- 菠萝**整只买**比切好的便宜 30%-50%。
- 苹果可以提前一晚切好泡盐水冷藏，第二天摆盘，减少早上损耗。
- 如果拼盘是**自助形式**，可以用整只菠萝做容器，把切块塞回去，视觉上成品更大更高级。

---

**总结一句话**：先看**净肉成本**，苹果最稳当，橙子要挑薄皮，菠萝看着便宜但实际最贵销（时间+损耗）。建议当天采购时用上面的公式快速心算，再决定各买多少。
