这是一个典型的“集权 vs. 分权”管理问题，没有绝对的好坏，取决于你企业的规模、门店分布、品类特性和管理能力。

**核心结论：**
**中央厨房统一收货（集采分送）通常更好，尤其是针对水果这种标准化要求高、损耗大的品类。** 但**必须配合“门店到货质量验收”的双重保障**，否则单纯集收容易失控。

以下是详细分析和决策建议：

### 一、为什么中央厨房统一收货更好？（核心优势）

1.  **品质稳定与源头把控**
    - 水果是生鲜，非标品。如果门店各自收货，不同店长对“甜度、硬度、瑕疵率”的标准不统一，导致连锁口感差异大。
    - 中央厨房或采购中心可以派专业品控人员到产区或批发市场源头验货，收货时按统一标准（如糖度测试仪、大小重量规格）检测，保证所有门店拿到的果品基线一致。

2.  **腐败损耗的可控性**
    - 中央厨房是**逆向物流的第一道关卡**。统一收货后，可以在常温库分拣或暂存，将已发霉、碰压伤的果品直接剔除或退回，避免劣质果流到门店造成顾客投诉和退赔。
    - 若门店直收，损耗数据分散，很难分清是采购问题、运输问题还是门店储存问题。集中到中央仓，责任归属清晰，便于追溯供应商。

3.  **规模采购的议价权**
    - 统一收货意味着统一采购量。你可以绕开中间商，直接与产地或大型一级批发商签订协议价，能降低 5%-15% 的成本，这部分毛利在餐饮业非常关键。

4.  **分拣与预处理效率高**
    - 中央厨房可以实现净切（如水果切配）、预包装（如按净重分装）、预冷（延长售卖期）。门店直收，这些工序得各店自己做，人员成本高且品质参差。

### 二、什么情况下门店分开收货更好？（适用场景）

1.  **门店距中央厨房过远**（如跨省），冷链运输成本高昂，且水果保鲜期短，路上耗损大于供应商直供。
2.  **门店体量极小的奶茶店/咖啡加盟店**，单店日采购量小，中央厨房配送成本高于就近菜市场购买（此时适合本地供应商直配，总部只定标准）。

### 三、执行蓝图：最优解是“混合模式”

不建议纯集收或纯分收，建议采用 **“供应商直送门店+中央仓抽检复核”** 或 **“中央仓全量收货+门店预检”**：

**方案 A（大店/高毛利店）：**
中央厨房统一收货 \(\rightarrow\) 快速分拣称重 \(\rightarrow\) 冷链车短途配送（1-2小时） \(\rightarrow\) 门店只负责**上架销售和冷藏储存**，不负责验货看底。

**方案 B（门店多且分散）：**
供应商按中央厨房下发的 **《订单规格书》** 直送门店，但门店**不得直接签字收下**。必须上传开箱照片/视频到数字化系统，中央厨房品控随机抽检或AI图片识别监控。若门店违反标准拒收，损失由供应商承担。

### 四、落地时的关键注意事项（防坑指南）

-   **水果安全放行标准**：收货时必须抽检“果心温度”（尤其在夏天，如果果心温度超过环境温度5℃以上，说明冷链断裂，极易变质，要拒收）。
-   **不要混合卸货**：绝不能将易催熟的水果（如香蕉、芒果、苹果）与高呼吸率蔬菜混放，否则会互相催熟到无法售卖。
-   **“两小时收货法则”**：无论谁收货，鲜果从装车到入冷库（4℃）的时间不能超过2小时，这是损耗控制的底线。

### 五、给你一个快速决策表（请对应现状）

| 企业现状 | 推荐模式 |
| :--- | :--- |
| 单城 20 家店以内，车程 < 1小时 | **中央厨房统一收货**（全控） |
| 跨区 / 跨省开店，但单站能承载 | **区域中心仓**（大区集收） |
| 加盟连锁，总部管控力弱 | **中央统一收货做配**（标准化权重 > 成本） |
| 高端鲜果切（如水果捞），强调净含量 | **绝对中央厨房**，门店严禁自采 |

**最后给一个落地建议**：
除非你是**只有几家小店且无法承担冷链车**，否则**务必坚持中央厨房统一收货**。
水果生意赚的从来不是“买便宜”，而是“损耗差”——中央厨房统一收货能让你在源头多花 5 分钱止损，却在门店端少扔 5 块钱废果，这笔账非常划算。如果目前规模小无法建中央仓，至少也要设置一个**“收货质检中心”**（哪怕是一间带空调的仓库），而非让店长各自为战。
