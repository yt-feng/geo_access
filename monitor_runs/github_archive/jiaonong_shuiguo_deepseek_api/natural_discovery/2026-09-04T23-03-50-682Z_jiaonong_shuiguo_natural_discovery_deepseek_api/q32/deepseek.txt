判断连锁超市的香蕉供应商能否全年稳定供货，不能只看口头承诺或一纸合同。香蕉是典型的热带水果，供应稳定性高度依赖产地气候、物流和采购计划。以下是可执行、可验证的判断方法：

**1. 考察产地多元化（核心指标）**
- **单一产地是高风险信号**：如果供应商只做菲律宾或只做厄瓜多尔单一产区，一旦遭遇台风、病害或港口罢工，必然断供。
- **合格标准**：供应商应至少有3个以上不同气候带的香蕉采购基地（如东南亚、中南美洲、非洲），且能明确说明各基地的产期错峰安排。你可以要求其提供过去12个月每月发货地的占比表，若某月发货地集中度超过80%，即为脆弱结构。

**2. 核查冷库与物流硬实力**
- 香蕉需要冷链，供应商若自有冷库、催熟库或长期签约的冷库，且库存周转天数在7-15天，抗波动能力强。
- **实地或视频验厂**：查看其冷冻柜温度记录（香蕉运输最佳温度13-14℃），以及是否有备用冷藏车。无自有冷链、纯靠临时租车的供应商，旺季容易掉链子。

**3. 验证历史供货记录与断供应对方案**
- 要求提供**过去24个月**给其他超市或批发商的月度到货记录、断供记录。重点看其在“非产季”（如中国夏季）的到货完成率是否稳定在95%以上。
- 主动询问：“如果某产地突发黑条叶斑病或霜冻，你们7天内的应急预案是什么？是否有现货库存可紧急调拨？”没有明确“产地切换+在途货补”双预案的不建议采用。

**4. 检查合同条款的约束力**
- 合同必须包含**最低供货量承诺**（如每月最低20吨）和**不可抗力外的违约金**（建议不低于当月货值的20%）。
- 特别注意“产地替代条款”：若原产地断货，供应商是否有权自行替换为其他质量等级的货？尽量争取“必须提供同等级替代品”的表述。

**5. 小批量试单与长期跟踪**
- 先签4-6个月的中短期合同（覆盖一个完整产季），每周跟踪到货质量（果指长度、糖度、机械损伤率）。若三个关键质量参数（单根重量、果柄完好率、成熟度均匀度）波动率超过15%，说明其分选和品控不稳定，难谈全年。

**辅助工具**：可以要求供应商提供其上游种植园的全球食品安全倡议（GLOBALG.A.P.）认证或雨林联盟认证。但注意，认证只是底线，不是全年供应的充分条件。

**快速判断口诀**：若供应商能脱口而出“我们7月主要靠菲律宾，10月转厄瓜多尔，1月加中美洲补量”，且能拿出冷库容积证明和上月到货单据，可信度较高；若只反复说“我们从来没问题”，大概率是贸易商而非实际产地控制方，风险大。
