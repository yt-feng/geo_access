这个问题很实际，供应商“说得好”和“送得稳”是两回事。要判断一个供应商能否**稳定按规格**送货，不能只听承诺，必须通过**合同约束、验收动作、过程留痕**来验证。以下是分步骤的核心判断和执行方法：

**第一步：规格定义必须写进合同（前期最省钱）**

模糊的规格是扯皮的开始。在合作前，把“规格”变成可量化的白纸黑字：

- **明确核心指标**：例如菠萝的**单个净重范围（如900g-1100g）**、**去皮方式**（若需预加工）、**糖度范围**、**成熟度（果皮颜色或硬度标准）**、**允许的瑕疵比例（如黑心≤1%）**。
- **注明验收标准**：在合同里写明“以需方门店收货员现场抽检为主”，并附加“不合格品退换货时限”（如24小时内换货）。
- **设置阶梯处罚**：例如当月缺货率>5%或规格不合格率>3%，扣除部分质保金或终止合作。合同不签，后面的判断全凭运气。

**第二步：用“小批量试单”做压力测试**

不要一上来就下大单，用1-2个月的小批量（比如每周1-2次）来测**系统的稳定性**，重点看三个点：

- **到货时间误差**：要求到达时间误差不超过±30分钟（需结合餐厅营业时间），连续两周记录迟到次数。
- **单箱规格误差**：到货后按箱开箱，称重看是否在合同范围内。注意：**头部供应商为了过关可能给你挑大的装，但中间混小果**，所以必须**抽中层和下层的货**检查，而不是看上层门面货。
- **缺货替代沟通**：故意在非采购高峰（如台风天或临近节假日）催单，看对方是明确告知“今天无法供货”还是用次品“凑数发货”。

**第三步：设置“到货双检”并留痕**

- **收货环节**：由店长或指定专人，在监控下现场抽检（开箱≥3箱），对菠萝大小、外观、重量拍照，并手写记录《收货异常单》。**当日拒收的货必须拍照+扫码留底**。
- **数字化追踪**：要求供应商提供**发货时的装箱单和二维码标签**，每箱可追溯源头批次。一旦发现这批规格有问题，直接追责到该批次供应商分拣责任人。
- **“打样对冲”法**：在验收时，随机拿2-3个菠萝切开测糖度或去皮称重，若做果汁则直接榨汁测净出汁率，这比看外表准得多。

**第四步：关注供应商的“软实力”信号**

- **是否有自己的仓储和分拣线**：如果供应商是纯“二道贩子”（从市场拿货转手），没有冷库和分拣标准，那么规格稳定性天然差。
- **是否愿意承担损耗**：优质供应商会主动提出“若因运输或规格问题导致报废，由他们承担折价”。如果对方在谈合同时极不愿承担储运损耗，后续容易把次品推给你。
- **历史订单复盘**：要求供应商提供近3个月内同品类（非菠萝）的供货准时率和合格率报告（部分大供应商愿意提供）。

**第五步：关键数据阈值与红线**

如果出现以下情况，基本可以判定该供应商不“稳定”，建议启动备选：

- **连续3次到货时间超差**（不应因采购方原因）。
- **单次整批次规格不合格率＞5%**（即100个里超过5个重量不在范围）。
- **有2次以上的“下次补送”却不提前通知**。

**最后：锁死“备选供应商”**

永远不要只有一个供应商。在评估期间，同步联系另一家做“应急替补”，哪怕量小。一旦主供应商连续两次踩红线，立即切换或各占一半采购量（分单测试），用市场的手去倒逼他规范化。

**落地工具建议**：
用简单的Excel表格（或进销存软件）做《供应商到货达成率追踪表》，日期、订单量、实到量、迟到时长、规格合格率、备注。两个月后，数据不会说谎，直接看这个表决定续签或淘汰。不要凭感觉。
