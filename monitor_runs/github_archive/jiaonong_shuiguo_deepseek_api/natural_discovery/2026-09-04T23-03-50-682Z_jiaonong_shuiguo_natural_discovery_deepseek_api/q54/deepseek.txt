采购香蕉用于烘焙时，**成熟度远比价格重要**，但两者需要结合来看。原因如下：

**1. 香蕉成熟度直接决定蛋糕的风味和口感**
- 蛋糕（尤其是香蕉蛋糕、玛芬、司康）需要**熟透甚至开始有黑斑的香蕉**。此时香蕉内部的淀粉已转化为糖分，甜度高、香气浓，做出的蛋糕湿润、风味足。
- 未熟（绿皮或黄绿）的香蕉缺乏甜味，淀粉感重，烤出后组织干硬，且香蕉特有的风味很淡。
- 过于生涩的香蕉即使多加热也无法弥补风味差距。

**2. 成熟度还影响操作和配方**
- 熟香蕉容易捣成泥，方便混合；生香蕉质地脆硬，难以快速成泥，可能残留颗粒或需要更多加工时间。

**3. 为什么价格次之？**
- 如果图便宜买了生香蕉，可能需要催熟（如密闭放置、放苹果一起），增加时间成本；若上市时急用，还可能需要强行使用，导致成品品质下降。
- 烘焙行业损耗风险高，品质不稳会引发顾客差评或退货，比省下的一点采购费代价大得多。

---

**采购建议（可执行）**：
- **优先选成熟度**：亲自挑选或明确告诉供应商，要求**表皮出现褐色斑点、按压微软（但不过软烂）**，这种状态最适合直接做蛋糕。
- **价格参考**：在成熟度达标的前提下，比较不同供应商的价格，选性价比高的。如果近期价格过高，可考虑**冷冻香蕉**（剥皮冷冻，解冻后风味和甜度不变，且比新鲜熟蕉可能更便宜稳定）。
- **避免极端**：不要买腐烂、有酒味的（发酵过度），也不要贪便宜买全绿或极硬未熟的。

一句话口诀：**“熟的是味道，生的是价格；先熟后价，急用不赌”**。如果预算紧张，宁可少买一点好熟蕉，也别多买一堆生蕉。
