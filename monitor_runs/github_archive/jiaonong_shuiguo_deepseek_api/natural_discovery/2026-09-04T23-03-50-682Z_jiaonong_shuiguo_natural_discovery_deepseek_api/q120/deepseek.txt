这是一个非常实际的问题。供应商在向普通商家推货时，**最大的误区就是“自嗨式介绍”**——讲采摘技术、讲甜度系数、讲冷链多先进，但商家心里只问三个问题：**压不压货？赚不赚？好不好卖？**

要让对方听懂并下单，建议改掉“分类词汇”，直接用“**算账思维+场景终端+对比词汇**”。以下是一套可以直接照搬的沟通框架：

### 第一步：把“大品类”翻译成“具体进货单位的钱”
不要先说“我们这个是金枕榴莲”，直接说：
> “老板，您平时进一箱香蕉走量，一箱利润大概20-30块对吧？你看我这个菠萝，**一箱进价X元，您这边零售至少能卖到X元，单箱毛利有X%**。您平时那种走量的货，是引客流；我说的这款，是您摆门口**拉高客单价的货**。”

**精髓**：普通商家对“大品类”有价格带记忆，用他熟悉的品类做价格锚点，然后立刻把“产地信息”换成“**利润信息**”。

### 第二步：用“傻瓜分拣”代替“专业品种”词
说“都乐金菠萝”、“巴厘种”大家听不懂，您直接说分级标准：

- 不要说“这个更甜”，要说：“**这个不用盐水泡，切开就能吃，回家省一道工序，客人不会因为麻烦而不要。**”
- 不要说“耐储存”，要说：“**您今天拿货，放个四五天，皮稍微黄一点，客人反而觉得熟透了更香，不容易砸手里。**”
- 不要说“规格统一”，要说：“**我这批货，个头大小基本都跟您拳头似的，不用您店里小妹再挑一遍坏果，损耗少。**”

**精髓**：商家最怕“货不好卖、损耗大”，您把专业词全部翻译成“**少操心、少扔钱**”的动作。

### 第三步：直接给“拉动销”的话术，教他怎么卖
这是**杀手锏**，能瞬间拉近距离。不要说“这菠萝卖得好”，而是直接把话递到对方嘴边：
> “您拿回去，门口立个小黑板，就写**‘树上熟香水菠萝，不酸不涩，能直接当水果吃’**。您听我的，您要是拿回去这箱没卖动，下次我给您补货优先挑，咱们长期合作，我不可能让您压货。”

**精髓**：普通商家不会卖新货，您教他一句“门口的广告语”，他就觉得您是帮他赚钱的，不是来赚他钱的。

### 第四步：给“退路”，降低心理防线
普通商家对大品类（香蕉苹果）习惯了有稳定客源，对新品有天然戒备。
您可以再补一刀：
> “这个您没见过不熟悉，太正常了。这样，我给您在箱子里配**一个试吃装**，您自己尝，觉得好再挂到价签上。或者您这周先拿半箱试试水，卖得好了再给我电话，马上给您补。”

### 总结一句话公式：
**（熟悉的品类做引子）** + **（用“操作省事”代替品种名）** + **（算出单箱利润）** + **（教一句门口叫卖语）** = **听懂+敢试单**

如果对方是夫妻老婆店，把“供应链”三个字删掉，把“行情趋势”删掉。他那柜台就一米长，他只看“这筐放到那儿，多久能变成钱”。
