针对便利店场景，**建议优先选择小把包装（2-4根）为主，搭配少量单根装**。

具体原因和操作建议如下：

**1. 为什么首选小把？**
- **消费场景匹配**：便利店客群多为个人即时消费，买2-3根正好是当天或两天的食用量，不会浪费，也方便携带。
- **客单价与毛利**：小把包装定价灵活（比如9.9元），比单根看着划算（心理上觉得“整把更值”），又比整袋（通常5斤以上）客单价低，容易冲动购买。
- **控损优势**：小把可去除烂果后重新捆扎，损耗可控；整袋一旦有一根坏，整袋基本报废。

**2. 为什么要有单根？**
- **满足“一根需求”**：部分顾客（比如只吃一根解馋、怕吃不完）会明确找单根。
- **高价止损**：当香蕉开始成熟过快、出现少量麻点时，可拆分成单根做“今日特价”（例如1.5元/根），能及时卖出减少报损。

**3. 不推荐整袋的原因**
- 整袋（通常5-10斤）在便利店动销慢，成熟度不好控制，容易集中变黑，损耗极高。
- 便利店货架空间有限，整袋占面积、周转慢。

**执行细节提醒**：
- 小把建议控制在2-4根/把，用扎带或保鲜膜封口，贴透明标签注明价格。
- 摆放位置要靠近收银台或冷柜出入口，香蕉不宜贴墙或贴近发热设备（成熟加快）。
- 分批进货：不要一次性进大量，优先选择颜色偏青（七成熟）的货，到店后自然熟化，能延长售卖期。

**总结**：80%陈列小把，20%陈列单根（用于应急和临期处理），整袋可作为线上团购或批发渠道的商品，不建议作为门店常规SKU。
