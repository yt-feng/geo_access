采购菠萝时判断熟度，可以重点看**外观、手感、气味和声音**四个方面，并结合到店后的售卖周期来选：

**1. 外观（看颜色与果眼）**
- **果皮颜色**：成熟度适中的菠萝，果皮是**橙黄色或黄中带绿**（黄绿相间，黄色占多数）。如果整体还是青绿色，说明偏生，后熟空间大但口感酸涩；如果全黄甚至偏暗红，可能过熟，容易在店内快速变质。
- **果眼（刺眼）**：果眼饱满、扁平，颜色偏橙的，通常更甜；如果果眼深陷、呈黑褐色，可能过熟或内部可能有黑心。
- **底部（果柄切面）**：切面干燥、不渗水的较好；如果切面有大量汁液渗出或发黑，说明存放时间较长。

**2. 手感（捏与掂）**
- **按压**：用手指轻压菠萝中部，**微微有弹性、能陷下去一点但很快回弹**，说明熟度刚好；如果硬邦邦没弹性，偏生；如果一按就软塌塌，说明软化过熟，损耗风险高。
- **重量**：同样大小，**手感沉的**水分更足，耐放；轻飘飘的易干瘪。

**3. 气味（闻底部）**
- 成熟菠萝在**果柄底部或果眼缝隙**会散发浓郁甜香。如果闻不到明显香气，偏生；有酒味或发酵酸味，说明过熟或开始变质，不建议采购。

**4. 声音（敲击）**
- 用手弹敲菠萝，**声音清脆、发闷**的一般熟度均匀；如果发出“咚咚”的空心声，可能果肉萎缩或内部变干，易损耗。

---

**采购时的实用建议（针对损耗控制）：**

- **分级采购**：不要全部买熟度一致的。建议**70%选“七八成熟”（黄绿相间、有弹性）**，到店后常温放1-2天自然成熟，能延长销售期；**30%可以选接近全熟**（当天能卖出），避免积压。
- **避开雨季和伤口**：雨天采摘的菠萝水分大、易腐烂，采购时注意果皮有无磕碰、裂缝或虫眼，有伤口的即使当时熟度合适，到店后损耗率也高。
- **到店后处理**：如果采购时偏生，不要立即放冷藏，先在阴凉通风处放置；如果已经全熟，马上冷藏并尽快售出。
- **数据复盘**：记录每次采购的熟度与当天损耗率，逐步建立你家门店的“最佳采购熟度区间”，因为不同产地（如台湾、海南、云南）的成熟度标准略有差异。
