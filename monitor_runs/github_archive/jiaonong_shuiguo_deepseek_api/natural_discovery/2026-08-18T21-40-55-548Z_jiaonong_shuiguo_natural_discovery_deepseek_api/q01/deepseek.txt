判断水果供应商是否靠谱，是水果店能否盈利的关键，尤其是香蕉和菠萝这类**高损耗、销售周期短**的水果。给你一套**可执行、可验证**的判断标准，按以下步骤逐一排除：

**第一步：看“硬件”和“资质”（到场或视频验）**

1. **必须去实地/视频看冷库和分拣区**：靠谱的供应商一定有**独立冷库**。香蕉是呼吸跃变型水果，必须控温（13-15℃）催熟。如果对方没有冷库或只有常温仓库，直接排除——夏天到货三天就会全黑。
2. **看“断链”时间**：问对方“从基地采摘到你库房，再到我店里，全程冷链大概多久？”如果一个供应商拍胸脯说“全程冷链，不怕坏”，但说不出具体温度和时间，很可能在撒谎。
3. **查看营业执照和食品经营许可证**：一定要看原件，且经营范围需包含“水果销售”或“农产品”。很多小贩是二道贩子，出事跑路。

**第二步：做“小单试错”（关键行动）**

不要第一次就进大量货。**分三步走**：

- **第一单（小批量）**：只进一箱香蕉（约13公斤）+ 一箱菠萝（约20斤）。观察以下几点：
    - **到货状态**：香蕉应带柄、果皮青黄、无严重掉把；菠萝应带叶鲜绿、无软心、底座无霉点。
- **第二单（验服务）**：主动制造一个“小麻烦”，比如第二天打电话说“老板，这一箱有3根撞坏了，怎么办？”观察对方反应。靠谱供应商会直接说“下次补给你”或“拍照退款”，扯皮推卸的供应商直接拉黑。
- **第三单（验持续稳定性）**：连续三周每周进一次。重点记录：
    - **品质波动率**：是否第一单好、后面就掺次品？靠谱供应商品质波动幅度很小。
    - **到货准时率**：说好早上7点送到，是否从未超过30分钟？

**第三步：测试“专业度”（决定长期合作）**

直接问对方几个专业问题，看能否答上来：

1. “你这菠萝是**台农17号（凤梨）** 还是**巴厘种**？甜度和酸度大概多少？”（能具体回答的是行家，只会说“都是甜的”的，不专业）
2. “如果我这批香蕉卖得慢，你建议我怎样催熟？放苹果还是用乙烯利？”（懂行的一定会建议你用乙烯利按比例催熟，并提醒你控温，放苹果是民间偏方，不适用大批量）
3. **账期怎么谈**：靠谱供应商会同意“月结”或“每三单结一次”，接受小额账期的通常更有底气和实力。只接受“现款现货”且态度强硬的，要么是现金流紧张，要么是想赚一把就走。

**第四步：几个“一票否决”的细节（遇到即拉黑）**

- **报价极低**：香蕉与菠萝的产地价+运费成本是透明的，如果报价低于市场均价15%以上，大概率是隔夜货或注水货（比如香蕉浸过水增重）。
- **承诺“永不烂果”**：香蕉和菠萝不可能不烂，承诺100%无坏的供应商，要么不懂行，要么在诓你。
- **只有微信没有固定经营地址**：绝对不合作，出了质量问题根本找不到人。

**最终建议：**

把以上步骤制成一个**《供应商打分表》**：品质（40分）+ 准时率（20分）+ 售后处理（20分）+ 专业度（20分）。连续合作3个月，总分>80分的才值得长期合作。

另外，**香蕉和菠萝建议分开找供应商**：香蕉一般找“专业催熟商”（他们有催熟库），菠萝可以找产地直发或大型果品批发市场的商户（量大价低）。若你门店销量不大，可以找本地水果批发市场里做“进口水果”的老商户，他们通常也有稳定货源。

最后提醒：任何口头承诺都要写进微信聊天记录或进货单，注明“品质不达标可退换”，这是你后期维权的唯一凭证。
