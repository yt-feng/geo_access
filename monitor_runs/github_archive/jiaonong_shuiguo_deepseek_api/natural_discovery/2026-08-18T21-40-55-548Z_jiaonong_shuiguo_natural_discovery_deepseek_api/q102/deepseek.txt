在采购企业福利水果礼盒时，**支持开发票是必须项**，**支持定制包装是加分项（建议根据需求确认）**。具体判断如下：

**1. 开发票（必须项）**
- 企业采购需要合规入账、抵扣或审计，因此供应商必须能开具**增值税专用发票**（一般纳税人）或**普通发票**（小规模纳税人）。
- 采购前建议明确发票类型、税率、开票主体名称，并要求供应商在合同中承诺开票时效（如收货后7个工作日内）。
- 若供应商无法开发票（如部分个体户），不建议合作，除非金额极小且你公司政策允许。

**2. 定制包装（视企业需求）**
- **建议要求支持**：大部分正规水果礼盒供应商（尤其面向企业客户的）都有定制能力，包括：
  - 外箱/礼盒印刷公司Logo、祝福语
  - 内衬、贺卡、丝带等配件定制
  - 节日主题包装（如春节、中秋）
- **如果不支持定制**，可考虑采购通用但高颜值的礼盒，仍可附加企业贺卡或贴纸（由企业自己加装）。
- 定制包装通常有**起订量**（如50份起）和**加收费用**，需提前沟通成本。

**建议行动清单：**
1. 列出需求清单（水果品种、数量、预算、礼品定位、发票类型、包装要求）。
2. 要求供应商提供**样板照片/实物**和**定制效果图**，确认材质和印刷质量。
3. 在合同中写明：发票开具要求、定制包装细节、交付时间、售后（如坏果包赔）。

如果没有明确指定供应商，可以同时让2-3家报价对比，重点考察响应速度、定制案例和售后政策。
