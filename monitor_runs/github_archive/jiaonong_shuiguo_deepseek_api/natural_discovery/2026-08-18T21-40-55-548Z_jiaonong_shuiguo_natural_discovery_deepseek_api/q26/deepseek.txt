针对社区超市销售小包装香蕉，采购和损耗控制是核心。以下是实操层面的注意要点：

**一、包装层面的关键问题**

1. **包装形态选择**
   - 首选**透气网袋**或**带孔保鲜膜**，避免全密封塑料袋（易积水加速腐烂）。
   - 小包装建议**2-3根/袋**或**4-5根/袋**，重量控制在500g-800g之间，符合单人/两日食用量。
   - 若做精品装，可在盒底垫吸水纸（防汁液浸渍果柄）。

2. **标签与信息**
   - 必须标注**“自然熟”或“催熟”**（避免消费者误以为放几天会变绿）。
   - 价签贴在外袋上，不要直接贴香蕉皮（胶残留会污染果肉）。

3. **成熟度分级包装**
   - 由于小包装通常无法挑拣，采购时应要求供应商按**“当日熟”和“明日熟”**分装，否则消费者买到太生的会投诉，太熟的次日就变黑。

**二、损耗控制要点**

1. **到货验收**（重点）
   - 检查**果柄是否断裂**（断裂处易发霉）。
   - 抽查**表皮是否有“虎皮斑”**（轻微淤伤会加速变黑）。
   - 拒绝**“水烂”**（果皮发暗、手感发软发黏）的货品。

2. **库存周转规则**
   - 香蕉是典型的**“后熟型”**水果，到货当天是最好卖的（颜色亮黄），**次日必须打折**或做“特价装”。
   - 社区超市建议**每日订货量控制在当日销量的80%**，宁可断货也不要积压过夜。

3. **店内摆放与售卖**
   - 货架避免阳光直射且**远离空调出风口**（冷风会冻伤果皮变黑）。
   - 小包装最好**平铺**，不要堆叠超过3层，否则下层被压出黑印。
   - 若当天卖不完，立即撤下冷藏（**10-12℃冷藏**，注意不要低于8℃，否则表皮发黑），次日作为“特价熟蕉”售卖（可做烘焙原料提示）。

**三、额外建议**

- 与供应商约定**“包退换”条款**：若到货当天发现整箱有超过5%的裂果或黑斑，直接换货或抵扣，否则损耗风险全部由超市承担。
- 如果社区有早餐/健身人群，可以尝试**预包装“熟度梯度”组合**（一根绿、两根黄、一根带黑点），卖点定为“每天吃一根不同熟度”，但成本较高，需测试销量。
