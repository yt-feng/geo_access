关于茶饮连锁采购菠萝时，判断供应商能否稳定按规格送货，这是一个非常实际的供应链管理问题。我无法直接核验具体供应商的信用或数据，但可以根据通用的供应链管理原则，给你一套**可执行、可判断**的评估框架。

核心思路是：**不要只听供应商“承诺”，要通过“合同锁定+试单验证+过程监控”来三维考核。**

具体操作建议如下：

**第一步：合同层面强制锁定（书面硬指标）**

在采购合同中，必须明确约定以下定量条款，这是后续追责的依据：

1.  **规格定义**：明确“按规格送货”的具体参数。例如：
    *   单果重量（如：1.2-1.5kg/个）。
    *   糖度（如：≥13°Brix，需现场抽检）。
    *   成熟度（如：果皮转黄比例或催熟批次要求）。
    *   包装方式（如：每箱净重、单层网套、防撞垫规格）。
2.  **到货合格率**：约定**开箱抽检合格率**（建议≥95%），低于此标准视为不合格批次。
3.  **违约条款**：重点写明**“连续两次/不达标率超X%时，我方有权暂停订单或扣除质保金”**。

**第二步：分阶段小单验证（风险过渡）**

不要上来就给大单，建议按“3-7-15”节奏测试：

*   **第一批（试单）**：下3天的量，重点看**现货周转能力**。
*   **第二批（观察单）**：下7天量，重点观察**跨天稳定性**（周一和周末的货是否质量一致）。
*   **第三批（正常单）**：下15天量，此时才基本确认其供应能力。

**关键判断指标**：在试单期间，观察供应商是否主动配合**第三方检测**（如农残、重金属），如果连检测报告都不愿意提供的，直接淘汰。

**第三步：建立“异常响应”压力测试（最有效的手段）**

这是判断供应链稳定性的黄金法则：

*   **测试方式**：在非节假日、非产季旺季时段，突然下达一个比平时多50%的**急单**，并且要求72小时到货。
*   **判断逻辑**：
    *   如果供应商半小时内能给出明确的备货方案和物流调度方案 → **稳定**。
    *   如果供应商回复“需要协调”或“可能要晚一天” → **不稳定**，说明其上游货源或冷链缺乏冗余度。
*   **评分标准**：建议把“按时交付率（OTIF）”设为月度考核红线，连续两个月低于95%直接切换备选供应商。

**第四步：实地验厂看“硬件分拣能力”**

如果条件允许，建议去供应商的加工厂实地看一次。重点看三点：

1.  **是否有自动分选线**：如果是人工目测选果，出问题的概率会显著高于有视觉分选秤的工厂。
2.  **冷库温度记录**：要求提供近一周的冷库温度曲线，看是否有断链（温度波动超±2℃说明冷链管理差）。
3.  **库存周转天数**：问他们期货（在途）和现货的比例，如果现货库存超过3天，说明可能积压，规格会不稳定。

**执行建议汇总（可直接落地）**：

| 考察维度 | 具体做法 | 达标线（硬指标） |
| :--- | :--- | :--- |
| 合同条款 | 写明糖度、单果重、合格率、违约金 | 合格率≥95%，罚则明确 |
| 试单节奏 | 先试3天，再试7天 | 连续两周无断供记录 |
| 压力测试 | 随机下达大额急单 | 72小时内到货且合格 |
| 硬件审计 | 实地看分选线/冷库 | 有分选设备，温度记录完整 |
| 备选机制 | 同时开发2家**产地不同**的供应商 | 避免单一产区气候风险 |

**最后特别提醒**：菠萝是典型的**“非标生鲜”**，同一棵树上下来的果都能差200g。如果你们要求极高的一致性（比如做果切或杯装，要求切块率一致），建议不要指望供应商“稳定按规格”，而是**在合同里约定“到仓后二次分选”**，即允许一定比例的次果，但次果由供应商承担折价费用。这样更现实。
