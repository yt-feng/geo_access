水果供应商推新品时，采购方采用“小批量试卖”是最稳妥的策略。具体数量没有绝对固定值，但建议按以下逻辑设定：

**一、核心原则：成本可控 + 数据可参考**
试卖量要足够产生销售数据（如复购率、损耗率），但又不能造成积压亏损。用**门店/渠道日均动销量**作为锚点最科学。

**二、推荐数量区间（根据渠道类型）**

| 渠道类型 | 建议试卖量 | 理由 |
|---------|-----------|------|
| **社区生鲜店 / 夫妻店** | **3-5天预估销量**（如日销20斤，试卖60-100斤） | 覆盖一个完整促销周期，能看到顾客反馈 |
| **商超 / 连锁便利店** | **首批1-2个标准陈列堆头**（约100-200斤/店，或按日均销量5-8倍） | 单店测试，避免多店同时铺货造成损耗 |
| **线上生鲜平台** | **7天限定秒杀/预售量**（如300-500份） | 用预售锁定需求，零库存压力 |
| **批发/餐厅供货** | **最小起订量的1.5-2倍**（如常规订100箱，试订150-200箱） | 测试厨师/顾客接受度，减少退换货风险 |

**三、必须搭配的“稳”动作**
1. **做产区对比试吃**：在门店设试吃台，记录“品尝后购买率”，淘汰口感不及预期的品种。
2. **约定退换货条款**：签合同时明确“非人为损耗，首批按X%退货或换新”。
3. **拆单分批发货**：别一次性到货，分2-3批间隔1-2天发，观察首批损耗再定后续量。

**四、止损红线**
- 若试卖期间**损耗率超过15%**（水果皮损+滞销），立即停售。
- 若**复购率（第二次购买同一水果的顾客/首次购买顾客）低于20%**，说明新品无优势，不建议正式上架。

**最终一句话**：**先试卖“3天能卖完的量的一半”**（即宁可断货也别压货），因为水果损耗快，断货还能补，压货只能亏。等跑通数据再逐步加量。
