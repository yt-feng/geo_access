针对长期合作的水果供应商，**“账期”通常是最值得优先谈的**，其次是“售后”，最后才是“配送”。

具体原因和建议如下，你可以根据自己的实际情况调整优先级：

**1. 账期（最优先）—— 关乎现金流和风险控制**
- **为什么优先：** 水果是易腐品，损耗率极高。如果你先付款或账期太短，一旦这批货出现质量问题或滞销，你不仅要承担经济损失，还要自己垫钱去处理售后。**账期就是你的“安全垫”**。
- **怎么谈：** 
  - 争取 **“月结”** 或 **“批结”**（即卖完一批结一批）。
  - 如果对方要求现结，可以要求 **“先货后款”**，并约定好“货到验收合格后X天付款”。
  - 关键点：**账期必须和“售后扣款”挂钩**。明确约定“因质量问题退货或损耗的金额，直接从当期货款中扣除”，这样你的现金流风险最小。

**2. 售后（次优先）—— 决定你可能亏多少钱**
- **为什么次优先：** 水果的售后纠纷特别多（烂果、重量短少、规格不符）。如果售后条款谈不拢，可能你谈下了长账期，但对方不认账，你照样亏本。
- **怎么谈：**
  - 明确 **“坏果包赔”** 的具体标准（比如：开箱损耗超过3%的部分，供应商全赔）。
  - 约定争议处理时限（例如：收货后24小时内反馈，供应商48小时内处理完毕）。
  - 退换货的运费由谁承担，必须写明。

**3. 配送（可适度让步）—— 可以替代优化**
- **为什么排最后：** 水果配送的核心是“时效”和“冷链”，虽然重要，但市场上有大量的第三方冷链物流或同城配送可以替代。如果供应商配送不行，你完全可以自己找车，把这部分成本算进采购价里。
- **怎么谈：**
  - 固定每日或每周的到货时间（避免高峰期）。
  - 约定“延迟到货”的赔偿标准（例如：晚到1小时，当批货价打9折）。
  - 如果供应商配送加价太高，可以谈“裸价自提”，自己组织物流。

---

**一句话总结谈判顺序：**
**先谈“账期”（现金流），再谈“售后”（止损），配送作为最后妥协筹码。**

**实操建议：**
谈判时不要直接说“我要账期”，而是打包谈：**“我们长期合作，我希望能签年框协议，你给我45天账期，同时承诺坏果次日下午上门换新，我保证每月的采购量不低于X吨。”**

这样对方觉得是长期大单，更容易在账期上让步。
