选择水果供应商时，**最应该先问“配送”和“售后”，最后再谈价格**。原因如下：

**1. 配送是“生存线”**  
水果是生鲜，损耗率极高。你需要先问清楚：
- 配送时效（是否当天/次日达，冷链还是普通物流）
- 起送量（是否适合你的团购规模）
- 配送成本（是否包邮或有阶梯价）
- 到货品质把控（如到货后是否验货、破损包赔）

**2. 售后是“信任线”**  
团购靠口碑，一旦供应出问题，你要能兜底。必须问：
- 坏果/烂果的赔付标准（如包赔比例、理赔时效）
- 是否支持退换货（尤其是长途运输中的损耗）
- 出现客诉时，供应商的处理速度（是否会推诿）

**3. 价格是“利润线”，但不能先比**  
如果直接比价，容易选到便宜但品质差的供应商。应该在确认配送和售后可靠后，再对比价格是否合理（市场行情价差异通常在5%~15%）。  
**例外情况**：如果某供应商价格低到明显不合理的水平（比如低于市场价30%以上），要直接警惕——要么是品质差，要么是售后没保障。

**建议的提问顺序**：
1. 先问“配送时效和覆盖范围”（确认能否满足你的团购周期）
2. 再问“售后赔付流程”（听对方讲得是否清晰、有担当）
3. 最后问“不同货量的价格阶梯”（并同步要求看样品或尝货）

**补充一点**：用“小批试单”来验证——先小量采购测试，同时观察配送、售后实操，再决定是否长期合作。这样比任何口头承诺都可靠。
