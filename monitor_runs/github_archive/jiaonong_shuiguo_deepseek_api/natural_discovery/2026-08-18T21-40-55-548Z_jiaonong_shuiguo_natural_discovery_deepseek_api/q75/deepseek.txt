针对水果批发商与供应商的**第一次合作**，建议采用 **“小批量、多维度、风险可控”** 的设计原则，避免因为货不对板、包装破损或运输损耗造成资金损失。

以下是具体的试单设计方案，分为**订单设计**、**品控设计**和**结算设计**三个核心部分：

### 一、 订单设计（控制首单体量）

1.  **限定SKU（单品项）**：不要一次试多种水果，**只挑1-2个**当季、走量快且不易腐坏的单品。例如：苹果、橙子、梨等耐储运水果，避免首批就做草莓、荔枝等高风险易损品。
2.  **锁定规格**：明确指出你要的标准（如大小：8-10头/斤，甜度：≥12%，或颜色、重量区间）。在合同中写明“按此规格验收”，避免供应商发“通货”滥竽充数。
3.  **控制件数**：建议**1件或2件起订**（哪怕只有1箱），或者按**整车混装**（拼车）的方式，但总货值建议控制在**1000-2000元**以内，或不超过你预期日销量的2倍。

### 二、 品控设计（重点防守）

这是试单最关键的一环，重点在于**打破信息差**：

1.  **验货前置（死规矩）**：**必须在装车发货前**，要求供应商提供**带日期的照片/视频**（如整箱开箱铺开、近拍瑕疵、糖度仪读数）。
    *   **警惕点**：如果供应商标榜“包甜包熟”，但拒绝提供糖度仪实测视频，大概率有水分。
2.  **物流包装举证**：
    *   要求使用**标准出口或纸箱+发泡网+珍珠棉**的包装。
    *   到货现场**开箱录像**，记录第一观感（是否有压伤、冻伤、腐烂）。
    *   **明确风险划分**：如果到货**第一时间**发现破损比例过高（如超过5%），拍照留证，直接拒收或要求供应商全额赔付（这是试单必须谈好的霸王条款）。
3.  **口感测试**：到货后，**务必当天试吃**。如果是果品，切开看“白心/黑心”，测糖度。**记录好数据**，这是决定是否长期合作的数据依据。

### 三、 结算与让步设计（建立信任基础）

1.  **付款方式**：首次合作，**绝不接受全额预付**。最安全的方式是：
    *   **方案A（稳妥）**：物流代收货款（货到验收合格后，物流代收）。
    *   **方案B（次稳妥）**：先付**20%-30%定金**，尾款在到货验货后，**3天内**结清。
    *   **方案C（压款）**：虽然第一次信任度低，但如果对方坚持，可协商“首批账期7天”（即到货后第7天付款），以此作为筛选对方资金实力和合作诚意的试金石。
2.  **损耗分摊协议**：明确约定“运输途中的正常损耗（如1%以内）由你承担，超过部分（如2%以上）由供应商承担”。这是首次合作最容易扯皮的点，必须白纸黑字写清。

### 四、 试单决策标准（给自己定KPI）

试单结束后，基于以下标准决定是否转正：

-   **及格线**：商品规格符合要求，到货损耗率**低于3%**。
-   **加分线**：供应商主动告知天气、行情变动，并给出替代方案，且送货时间准确（误差±1小时）。
-   **淘汰线**：货不对板、出现以次充好（如混装小果）、承诺甜度与实际差2度以上，直接拉黑。

### 附：给供应商的沟通话术建议（降低试单沟通成本）

> “王总，我们是第一次合作，为了长期稳定，首单我先打1000块试试水。**这单我不砍价，按你的市场价来**，但我要**验货视频**。只要这单货在我档口好评率超过90%，下次直接下翻倍的量，并且预付30%定金。你看行不行？”

**核心逻辑**：用“不砍价”换“验货权”，用“未来大单”换“当前高配合度”。如果连这么小的一单都不愿意配合验货流程的供应商，建议直接放弃。
