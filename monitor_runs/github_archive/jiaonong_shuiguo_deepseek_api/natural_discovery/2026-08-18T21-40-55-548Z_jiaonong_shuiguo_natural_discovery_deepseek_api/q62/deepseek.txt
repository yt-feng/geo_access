判断一批香蕉的熟度和坏果风险，主要看**触感、颜色、果柄和果肉状态**，同时结合运输时间和存储环境来评估风险。以下是具体操作步骤：

---

### 一、判断香蕉熟度（从生到熟）

1. **看果皮颜色**：
   - **全青（硬绿）**：未熟，通常需在批发市场放2-3天自然催熟。
   - **绿黄相间（“转色”）**：半熟，适合当天或次日销售。
   - **全黄（无青）**：已熟，1天内需售完，否则易过熟。
   - **黄中带黑点（“芝麻点”）**：熟透，甜度高但不宜久放，必须马上处理。

2. **摸手感**：
   - **捏果实中部**：硬实无弹性 = 生；稍微有弹性、能轻微按动 = 合适；软塌无力 = 过熟。
   - **捏果柄**：果柄硬而脆 = 新鲜；果柄发软、发黑 = 已开始腐坏。

3. **闻气味**：
   - **无味或青草味** = 偏生。
   - **浓郁香甜味** = 熟度适中。
   - **酒味或酸腐味** = 过熟或已开始发酵，不适合批发。

4. **看果柄切割面**：
   - 新鲜果柄切口清爽、呈淡绿色。
   - 切口发黑、发黏、有霉点 = 存放过久，风险高。

---

### 二、评估坏果风险（重点检查）

1. **外部伤痕**：
   - **压伤/碰伤**：表皮凹陷、发黑或渗水，容易引发霉变。
   - **裂口**：成熟过程中自然裂开，暴露果肉，极易滋生霉菌。

2. **霉斑与灰黑斑**：
   - 果皮上出现**白色绒毛**（霉菌）、**黑色霉斑**（炭疽病或运输霉变）→ 高风险。
   - 注意：**黑点均匀分布（芝麻斑）是正常熟化**，但**斑点连片、凹陷、带毛**就是病害。

3. **果肉状态**（可随机抽1-2根切开）：
   - 果肉洁白、紧实 = 好。
   - 果肉发黑、发褐、软烂 = 内部已坏。
   - 果肉中心有黑色硬块 = 冻伤或运输中严重受潮。

4. **整体一致性**：
   - 同一箱中如果**熟度差异极大**（一半青、一半黑），说明混装或储存条件差，风险高。
   - 有**明显异味**（如霉味、土腥味）的箱子优先排除。

---

### 三、降低风险的操作建议

- **抽检比例**：整批货正常抽查**10%-15%**（如20箱抽2-3箱），随机抽不同位置的箱子（中间和边缘都要看）。
- **看包装**：优先选择**有透气孔、无积水**的箱子；若箱内潮湿或有水珠，说明曾受潮，后期烂果概率高。
- **问清来源**：询问发货地、运输天数（超过5天的冷柜运输风险显著上升）、是否经过催熟（如有“催熟剂”标记，需注意批次新鲜度）。
- **谈判条款**：与供货商约定“若到货后24小时内开箱发现坏果比例超过X%（如3%），可当场换货或扣款”。
- **到货后处理**：立即开箱通风，分离过熟果和生果，不要混放，否则生果会被催熟，熟果会更快烂。

---

### 一句话总结：
**“看皮色判熟度，捏果柄查新鲜，翻箱底找霉斑，抽3箱算比例。”** 重点检查有压痕、裂口、发霉的果子，一旦发现货品整体偏熟或带水，就要降低收购价或减少采购量。
