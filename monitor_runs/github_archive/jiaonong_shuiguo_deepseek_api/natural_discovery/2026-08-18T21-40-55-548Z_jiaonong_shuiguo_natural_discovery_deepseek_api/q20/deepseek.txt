为社区超市挑选每天配送的水果供应商，核心要关注**稳定、品质、成本和服务**。以下为你梳理出六个维度的关键考察条件，帮你快速筛选出靠谱的合作方：

### 1. 供货稳定性与履约能力（最关键）
- **每日到货准时率**：要求供应商承诺每天固定时间（如凌晨5点前）送达，且能接受迟到扣罚条款。
- **淡旺季备货能力**：明确节假日、极端天气（台风、暴雨）时是否有应急预案。
- **常备SKU是否齐全**：确保你店里的日常爆款（如苹果、香蕉、橙子）全年不断供，不要出现“这个季节没有”的情况。

### 2. 水果品质与新鲜度
- **到货抽检标准**：现场开箱验货，看“磕碰率”“烂果率”是否低于3%（社区超市可要求5%以内，但越低越好）。
- **基地直采或一级批发**：优先选择产地直供（如山东苹果、广西香蕉）或一级批发商，避免多级周转导致损耗。
- **批次新鲜度证明**：可要求提供当日的采摘/进货单或农残检测报告（至少每周一次）。

### 3. 价格与结算模式
- **当日/三日报价机制**：水果价格波动大，要明确是“一口价”还是“随行就市”（建议选后者，但需约定封顶涨幅）。
- **退换货政策**：因运输导致的烂果，是“全额退”还是“按比例补偿”？一般建议选“当日烂果无条件补货”。
- **账期灵活性**：社区超市现金流快，最好能协商“周结”或“15天账期”，而非押一个月货款。

### 4. 物流与包装
- **冷链配送能力**：如果是夏季，草莓、荔枝等易腐水果必须用冷链车，普通货车坚决不合作。
- **包装结实度**：纸箱是否抗压、内部是否有网格分隔，这直接决定你上架前的损耗成本。

### 5. 售后响应能力
- **问题赔付时效**：出现缺斤短两或品质差，供应商承诺“2小时内补货”还是“下次抵扣”？选前者。
- **驻店或专属客服**：最好有一个1对1的微信/电话对接人，能处理突发问题（比如第二天要办活动加量）。

### 6. 本地化与灵活性
- **配送距离**：优先选距你超市30公里以内的供应商，不仅到货快，还能临时补货。
- **试供期要求**：建议先签15天-1个月的“试供协议”，期间重点考察到货率和损耗率，再决定长期合作。

---

**额外提醒**：
- 不要只听口头承诺，**签合同时必须白纸黑字写明“每日到货时间”“烂果率上限”“赔付标准”**。
- 建议**同时联系2~3家供应商**做对比，初期可以每家隔日配送，观察一周后再定主供方。
