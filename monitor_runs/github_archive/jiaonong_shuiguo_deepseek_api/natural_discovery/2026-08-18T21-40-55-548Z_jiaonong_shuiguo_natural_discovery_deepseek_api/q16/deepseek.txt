针对社区超市增加香蕉和苹果的采购选择，建议优先选择**稳定供应商**，理由如下：

**1. 香蕉的特殊性（核心原因）**
- **成熟度控制**：香蕉是典型的“呼吸跃变型”水果，采摘后继续成熟。稳定供应商（如大型批发市场的一级批发商或专业水果供应商）通常具备**催熟库**，能精准控制成熟度（如分批次供给7成熟、8成熟），避免到店后集中变黑、腐烂。本地批发市场多为散货，成熟度参差，损耗率高。
- **供货连续性**：香蕉需求稳定，但价格波动大。稳定供应商可签订短期合同，锁定供货价格区间，避免因台风、产地减产等导致断货或价格飞涨时，你被迫高价扫货。

**2. 苹果的储存与品质差异**
- 苹果保鲜期较长，但对储存条件有要求。本地批发市场可能将苹果与蔬菜混放，导致“串味”（苹果吸收洋葱、蒜味）或温度不恒定，影响脆度和口感。
- 稳定供应商（尤其产地直供型）通常有冷库，能保证全年供应不同品种（如红富士、嘎啦），且可提供分级标准（如按果径、糖度），减少你人工挑拣的成本。

**3. 成本与损耗的权衡**
- 虽然本地批发单价可能低5%-10%，但需自行承担：运输（油费+时间）、多次挑拣损耗（苹果碰伤、香蕉开裂）、以及因品质不稳定导致的顾客流失。
- 稳定供应商多为“送货上门+售后赔付”（如坏果包赔），对社区超市而言，**隐性成本更低**。

**4. 实际落地建议**
- **若社区超市日销量低于20公斤**：可先找当地批发市场，每次少进（20-30斤），测试周边居民偏好。
- **若日销量达到50公斤以上**：同时签约1家主供应商（负责香蕉）+ 1家备选批发商（应对临时促销），并协商“周结”或“月结”账期，减轻现金流压力。
- **关键测试指标**：试合作1个月，对比一周内损耗率（香蕉控制在5%以内，苹果2%以内）、顾客复购率。若损耗大，果断切换。

**风险提示**：警惕“超低价”供应商，可能以次充好（如用乙烯利催熟、发霉苹果混装）。签约前要求提供营业执照和食品经营许可证，并抽样检查果品克重和外观。
