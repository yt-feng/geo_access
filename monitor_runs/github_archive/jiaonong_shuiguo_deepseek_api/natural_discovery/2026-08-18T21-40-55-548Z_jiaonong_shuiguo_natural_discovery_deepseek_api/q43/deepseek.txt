评估连锁门店水果供应商的仓配覆盖，不能只看“能不能送货”，核心要围绕**时效、鲜度、成本和断货风险**四个维度。以下是可执行的评估框架和具体步骤：

### 第一步：绘制“门店-仓配”地理矩阵
这是基础。先把所有门店的位置、日均销量（SKU级别）、订货频次整理出来，再对照供应商的仓配中心分布。

**评估动作：**
1.  **拉出距离表**：计算每个仓配中心到每家门店的干线距离（货车实际运行里程，非直线）。
2.  **划分圈层**：将覆盖范围划分为：
    - **核心圈**：仓配中心辐射 200公里以内（水果短保品，如叶菜、草莓，建议在这个圈层）。
    - **主力圈**：200-500公里（适合大宗水果，如苹果、梨）。
    - **边缘圈**：500公里以上（除非是全程冷链且高价值水果，否则成本和鲜度风险极高）。

### 第二步：评估“最后一公里”的冷链与时效能力
水果的重资产在于冷链，供应商宣传的“冷链覆盖”需验证。

**必须验证的三个环节：**
- **干线运输**：是否全程0-4℃（或按品类分温层）？中途是否允许开箱？
- **城市配送**：到门店是冷藏车直送，还是普通车+冰袋？如果跨城，是否在门店当地有“**前置周转仓**”（即供应商在门店所在城市租的小冷库，先干线送过去，再二次分拨）？
- **到店时效**：**订货截止时间**到**到店时间**是否控制在 **24-36小时**内？超过48小时，水果鲜度和损耗率会急剧上升。

### 第三步：量化考核关键KPI（绩效指标）
光看地图和承诺没用，要设硬性指标，分城市维度对比。

| 评估维度 | 核心指标 | 合格线（参考） | 检查方式 |
| :--- | :--- | :--- | :--- |
| **时效** | 下单到到店平均时长 | ≤24小时（核心圈）/ ≤48小时（主力圈） | 调取近3个月物流单号数据 |
| **鲜度** | 到店验收损耗率（拒收/扣重） | ≤3%（生鲜类目） | 门店验收表格抽查 |
| **成本** | 物流成本占总采购金额比 | ≤8%（含仓配费） | 对账明细 |
| **缺货** | 断货率（因供应不及时导致） | ≤1.5% | 系统缺货报表 |

### 第四步：实地“漂单”测试（关键动作）
不要只看供应商的PPT（演示文稿），必须做**实地模拟下单**。

- **测试动作**：选择3个不同城市（比如一个一线核心城市、一个三四线边缘城市、一个非省会地级市）。
- **测试品项**：选一种高损耗的（如葡萄）和一种耐储运的（如柑橘）。
- **观察点**：单据系统是否支持跨区分仓自动分配？运输过程温度记录仪数据是否可回溯？到货时包装是否完好、有无挤压？

### 第五步：评估弹性与应急方案
单一供应商覆盖总有盲区，需要评估其**应急调货能力**。

- **询问**：如果该仓配中心爆仓或发生极端天气，供应商是否有**备用仓**？调货路径是什么？
- **建议**：对于边缘城市或SKU（库存量单位）数量大的门店，**不要押注单一供应商**，评估时至少要留出20%的SKU由本地供应商或备用仓覆盖，降低整体风险。

---

**最终结论建议：**
如果供应商在核心圈能做到“日配”或“隔日配”，且成本可控，优先放量；若只能在边缘圈做到“周配”，建议降低该区域的供货比例，并辅以当地中小型供应商做补充，避免“一仓断供、全城缺货”的连锁反应。

**特别提醒**：水果是活的生鲜，评估覆盖时，**“仓配时效”比“价格便宜”更重要**。一个跨省的低价供应商可能让你在鲜度和售后上赔得更多。
