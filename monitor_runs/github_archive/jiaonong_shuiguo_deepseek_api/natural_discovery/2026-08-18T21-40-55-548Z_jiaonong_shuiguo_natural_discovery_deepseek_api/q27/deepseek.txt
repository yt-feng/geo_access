在超市采购苹果和橙子时，判断大小规格是否适合门店销售，核心是**“匹配目标客群的购买习惯”**以及**“控制损耗与毛利”**。以下是一套可执行的标准判断方法：

**第一步：明确门店定位（决定“适不适合”的前提）**
- **社区生鲜店/平价超市**：客群多为日常家庭消费，优先选**中果**（苹果80-85mm，橙子70-75mm），单价适中，论个卖或按斤卖都能走量。
- **精品超市/高端店**：选**大果**（苹果85-90mm，橙子75-80mm），外观匀称、果型端正，适合礼盒装或按个销售，毛利更高。
- **折扣店/临期处理**：小果（70mm以下）或次果可用作引流特价，但需避开明显畸形果。

**第二步：使用“尺码规”量化判断（避免凭感觉）**
- 采购时随身带一个**水果专用测径尺（游标卡尺或环形孔尺）**，按果实最宽处直径测量。
- **苹果参考**：70mm以下为小果，75-85mm为理想销售区，85mm以上为大果（溢价但滞销风险高）。
- **橙子参考**：65-70mm为中小果（适合榨汁或家庭多量购买），70-80mm为标准果（主力销售档），80mm以上为特大果（需确认果个均匀，否则易压价）。

**第三步：动态检查“果个均匀度”（比绝对大小更重要）**
- 同一箱内，如果最大果与最小果直径差**超过5mm**，建议要求混装分拣或降价进货，因为顾客挑果时会按大小抓走，剩下的“尺寸断层”容易造成滞销和损耗。
- 随机抽取10个果，量出最大和最小直径，求差值。若差值过大，即使平均尺寸合格，也不适合直接上架。

**第四步：结合“以销定进”做最终决策**
- 查看近7天门店该品类**日均销量**，以及现有库存的“尾部销售速度”（即卖到最后一批时是否变慢）。
- 如果近期同类果日均销售150kg，且小果销量占比49%以上，说明客群偏价格敏感型，应多进中果；如果大果销量占比持续超30%，说明周边客群接受高价，可加大大果比例。

**第五步：现场“手感+视觉”双确认（防止规格达标但品质不达标）**
- 苹果：掂重适中（手感过轻可能失水），表皮光洁无扁片，缝合线不明显。
- 橙子：果脐小而圆润（大脐易皮厚），按压有弹性（太硬未熟，太软过熟），果柄处无霉斑。
- 大小规格达标但若存在大面积“麻脸”“干疤”，应直接扣减进价或拒收。

**总结判断口诀：**
**“量直径、看均匀、问销量、试手感”**
如果直径在理想区间且箱内大小差≤5mm，同时与该店近期销售比例吻合，即可列为A类可采购商品；若不满足，则降价或换货源。
