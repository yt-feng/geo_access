采购香蕉用于茶饮店或甜品时，熟度控制非常关键，因为香蕉的熟度直接决定风味、口感、出品稳定性以及损耗率。建议按 **“到货即用、分阶段使用”** 的原则来采购和管理。

以下是具体控制熟度的实操方案：

### 1. 根据用途分类采购
- **用于制作香蕉拿铁/奶昔（需要浓郁果香和顺滑口感）**：采购 **7-8分熟**（表皮变黄，带有少量绿斑或微褐点）。此时糖分高、淀粉转化充分，打出来的饮品最香甜，且不易氧化变黑。
- **用于制作香蕉松饼/蛋糕/布丁（需要甜度和软糯质地）**：采购 **8-9分熟**（表皮出现密集黑点，捏起来微软）。此时甜度达到巅峰，软烂易压泥。
- **用于制作冻酸奶/冰沙（需要Q弹口感）**：采购 **5-6分熟**（表皮黄绿色，捏起来较硬）。可保存时间更长，且冰沙中不易出水变糊。

**核心原则：** 
- 不要采购全青的香蕉（熟度<4分），因为大部分茶饮店没有催熟箱，自然催熟容易不均匀，且到货后至少需放置2-3天，备货周转压力大。
- 不要采购表皮全黑（熟度>9分）的香蕉，到店即烂，无法用于制作，损耗极高。

### 2. 到货验收时的“三看一捏”标准
- **看色泽**：整体呈亮黄色，允许有零星不明显斑点，但不能有大面积青绿色（过生）或发黑（过熟）。
- **看果柄**：果柄青绿色为新鲜，果柄发黑脱落说明已存放过久。
- **看表皮纹理**：棱角分明的（带棱）较生，棱角圆润饱满的甜度更佳。
- **捏手感**：手指轻捏果身，微微下陷约1-2毫米即合适；捏不动则生，一捏就塌则过熟。

### 3. 分批次到货策略
- **不建议一次性采购一周用量**。建议与供应商约定“每周到货2-3次”，每次采购量控制在2-3天用量内。
- 如果必须整箱采购，到货拆箱后**立即按熟度分拣**：
  - 硬黄果（6-7分熟）→ 常温阴凉处存放（垫报纸，不可密封塑料袋），做后续2-3天备用。
  - 软黄果（8-9分熟）→ 单独挑出，优先排产当天或次日使用，放进冷藏（但不要低于10℃，否则皮变黑但内部不熟，口感发硬）。

### 4. 日常操作中的熟度修正（应对不熟情况）
若到货偏生（整体偏绿）：
- 想加速成熟：与成熟苹果或猕猴桃一起放入纸箱（释放乙烯），常温密封催熟，一般12-24小时可见效。
- 若急需出餐：可剥皮切块，用少量糖浆或柠檬汁（抗氧化）微波叮20-30秒（微温即可，不可过熟），但仅限当日使用，不可复热。

### 5. 损耗与报损标准
- 熟度异常的香蕉应立即报损，**不要留在冰箱里等“变熟”**，因为低温会破坏细胞壁，导致返生和变黑。
- 建议在点单系统中设置“鲜香蕉当日保留期”，比如当日切片香蕉超过2小时未使用完，建议改打成奶昔或冷冻备用（冷冻后只适合做冰沙，不适合做热饮）。

### 小结
> 采购参考公式：**到货时为黄绿色微硬（约60%黄），存放1天后变全黄，第2-3天出现黑点，正好完成“用青-用黄-用黑点”的整个出餐阶段**。如果无法做到分批，宁可偏生不要偏熟，因为可以通过催熟救回，而熟过了只能报废。
