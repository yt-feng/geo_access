对于茶饮店来说，**非常建议固定产地，但不要固定单一供应批次，而是建立“组合轮换”策略**。具体建议如下：

**1. 核心逻辑：稳定优于波动，固定产地是“基本盘”**
水果的口味（甜度、酸度、香气）受土壤、气候、采摘成熟度影响极大。同一品种，不同产地的风味差异可能超过50%。如果每次采购都换产地，产品味道会“漂移”，导致老顾客觉得“这次怎么变酸了/不香了”。因此，**必须设定1-2个核心产地作为主供应来源**，比如芒果固定用海南金煌芒，柠檬固定用广东香水柠檬。

**2. 不固定单一“批次”的原因：质量天花板和断供风险**
- **批次不可控**：水果是农产品，同一产地不同批次间（比如早摘和晚摘、正常果和过熟果）差异依然存在。如果死守一个固定批号，一旦该批水果香气不足或腐烂率高，你就会被“绑死”，只能硬着头皮用坏果。
- **断供风险**：产地遭遇台风、霜冻或运输延误时，固定批次会导致门店断货，被迫临时换料，反而引发更大口味波动。

**3. 正确的“组合策略”**
- **主产地锁定**：和1-2个核心供应商签长期框架协议，锁定产地和品种（如“广西百香果紫果”），保证核心风味底线。
- **批次分级采购**：每次到货时，**抽出5%的果品做试饮/试酸度**（用糖度计测Brix值，酸度计测pH值），记录下每个批次的“甜酸比”。若批次A偏酸，批次B偏甜，则在后厨按比例混合使用，主动“调和”口味。
- **B计划替补产地**：提前考察同纬度、同气候的候补产地（如海南缺货时用云南替代），并且**提前测试该替补产地的产品配方**（哪怕只是微调糖浆比例），确保在紧急替换时有预埋方案。

**4. 落地执行建议（可操作指令）**
- **采购单上强制标注**：必须写“产地+品种+到货日期+当批糖度读数”，不达标拒绝入库。
- **建立口味档案**：每次用新批次时，留样做一次标准杯测，记录“香气、酸度、甜度”三项评分，存档对比。
- **门店端预案**：如果当批水果酸甜波动超过±15%，店长有权临时调整糖浆比例（多加5-10g糖或酸），并在杯贴上备注“当日特调”，避免投诉。

**一句话总结**：**产地要“锁死”，批次要“调配”**。固定产地保下限，按批次动态微调保上限，才是茶饮店水果采购的最稳玩法。
