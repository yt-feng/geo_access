在超市与水果供应商谈账期时，**常见账期一般在 30天到60天之间**，具体取决于多种因素。

以下是具体的参考范围和建议：

**1. 常见区间（按超市规模）**

-   **大型连锁超市/商超（如永辉、物美等）**：通常在 **45天 ~ 60天**，部分强势渠道可能压到 **75~90天**。
-   **中型超市/生鲜连锁**：一般在 **30天 ~ 45天**。
-   **小型超市/社区店**：通常是 **15天 ~ 30天**，或者“周结”/“半月结”。

**2. 影响账期的关键因素**

-   **水果易腐性**：水果是生鲜，保质期短。**过于长久的账期（超过90天）** 会极大概率的导致供应商提高单价来覆盖资金成本，或者供货质量下降（因为资金链紧张）。
-   **供应商的规模**：如果对方是大型批发商或基地直供，资金雄厚，愿意接受略长账期；如果是小型果农或二道贩子，通常要求 **现结或7天内结**。
-   **结算方式**：超市通常会有 **“月结”** 基准（即次月结算上月的货款），实际操作中往往延迟一周打款。

**3. 谈判建议（针对超市方）**
如果你代表超市方去谈，建议争取 **30~45天**，理由可以归因于“生鲜损耗大、需要检验周期”，同时承诺 **“到货验收合格后7天内对账，次月25日前打款”** 的具体时间节点，这比单纯说“30天账期”更能让供应商接受。

**4. 对供应商的反向建议（如果你是供应商）**
如果对方要求 **超60天** 的账期，务必做好以下防护：

-   **要求合同明确逾期违约金**（比如日万分之五）。
-   在报价时 **加上资金占用成本**（通常按年化8%~12%折算），账期越长，单价要高几个点。
-   **争取“预付定金”或“首单现结”** 以降低自身风险。

**补充提醒**：生鲜水果行业存在大量因账期过长导致的“跑路”纠纷，**无论账期多少，建议在合同中写明“货款逾期超15天，供应商有权暂停供货”**，并保留好对账单。
