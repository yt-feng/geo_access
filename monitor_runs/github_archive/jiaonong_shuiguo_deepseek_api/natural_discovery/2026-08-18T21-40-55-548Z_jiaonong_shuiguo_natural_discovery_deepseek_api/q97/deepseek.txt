酒店在采购水果盘原料时，供应商应在**规格**和**外观**两方面满足以下标准。具体标准可根据酒店定位（五星级、商务型等）进行调整，但核心原则一致：

### 一、 规格标准（可量化的硬性指标）
1. **尺寸/克重**：
   - 供应商需按酒店要求提供**固定等级**（如M号、L号）或明确单果克重（如苹果≥200g，橙子≥180g）。
   - 水果盘内各品种大小应**均匀一致**，避免“大杂烩”影响摆盘美观。
2. **成熟度**：
   - 需区分“食用成熟度”与“采摘成熟度”。酒店水果盘通常要求**7-8成熟**（即采摘后经运输到店时正值最佳口感），避免过生（酸涩）或过熟（软烂易压伤）。
3. **新鲜度**：
   - 以**到货日期**计算，水果出园/出厂至送达酒店不得超过48小时（热带水果可放宽），且需提供当日采摘证明或冷链温度记录。
4. **包装规格**：
   - 供应商需按酒店订单数量提供**标准包装**（如每箱净重、每盘组套数量），避免混装、缺斤少两。包装应具备防震、透气、防挤压设计。

### 二、 外观标准（视觉与品质筛选）
1. **完整无瑕疵**：
   - 果皮无**碰伤、压痕、虫眼、霉斑、裂口、腐烂点**。
   - 果柄完整（葡萄、樱桃需带梗），无干枯、褐变。
   - 对切或装饰用水果（如西瓜、哈密瓜），切面应整洁、无过度氧化发黄。
2. **色泽与成熟度均匀**：
   - 果皮自然着色均匀，无明显青斑（除部分品种特性外）。
   - 同一批次水果色差应较小，避免深浅不一。
3. **形状与大小**：
   - 果形端正，无明显畸形、歪斜（如梨、苹果）。
   - 椭圆或圆柱形水果（如香蕉、黄瓜）应笔直，弯曲度不超过20°。
4. **清洁度**：
   - 果面无残留农药、蜡质涂层或泥土，需附有**农残检测合格报告**（供应商必须提供）。
   - 表面不得有异常水渍或粉状残留。

### 三、 供应商需额外提供的书面保证
- **资质文件**：营业执照、食品经营许可、农产品产地证明。
- **质量承诺书**：明确若运输途中损坏、逾期不新鲜，供应商需**当日无条件补货**。
- **留样与跟踪**：供应商应保存每个批次的留样，便于酒店抽检或客诉追溯。

### 四、 验收时的现场判定动作
- **开箱检查**：按5%比例抽检，如发现超过2个不合格果品，整批次退回。
- **温度检测**（如适用）：冷藏车运输的原料内部温度应保持在0-8℃。
- **拍照留档**：验收时对包装、果品状态拍照，作为争议凭证。

若酒店定位高端，可附加“有机认证”“地理标志产品”等额外要求，并在合同中注明。最终验收以**到店时的现场状态**为准，而非供应商出库时的状态。
