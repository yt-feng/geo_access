在茶饮店旺季遇到菠萝用量突然变大，需要临时补货时，建议按以下步骤和话术与供应商沟通，既能保障稳定供应，又避免被坐地起价或断供：

**1. 先内部量化，再沟通**
- **精确估算缺口**：根据最近3天的日均消耗量、未来7天的预估销量（考虑周末和节假日），算出额外需要的菠萝数量（例如：平时每天50斤，现在需要100斤，缺口约350斤/周）。
- **明确品质标准**：明确你需要的菠萝成熟度（用于新鲜果肉还是熬酱）、去皮与否、尺寸规格（如A级果）以及是否需要切块预处理，以便谈判时口径一致。

**2. 电话或当面沟通，策略性谈判**
- **主动示好，确认合作基础**：开头先感谢长期合作，并说明“旺季来了，我们的销量增长很快，需要贵司支持”。
- **直接提出补货需求**：明确告知“预计未来一周需要额外供应XX斤，之后是否维持这个量要看客流，但至少需要本次应急”。
- **锁定价格与支付条款**：关键语句：“这个临时量希望能保持原合同价格，如果实在有运费或分拣成本增加，我们可以商量一个固定的临时单价（例如每斤加0.2元），但不能再高了。货款我们按老规矩（现结/周结）”。
- **约定到货时限**：明确要求“今天下单，明天早上必须送到，最迟不超过XX点，否则会影响出杯”。如果对方有困难，可以协商分批送达（如今天先送30%，明天送70%）。

**3. 书面确认，防扯皮**
- 无论电话里谈得多好，挂电话后立即用微信或邮件发送一条确认消息，包含：
  - **品名**：新鲜去皮菠萝 A级，XX规格
  - **数量**：总补货量XX斤，分X批（明确每批时间和数量）
  - **单价**：XX元/斤（含税/不含税）
  - **到货地址/时间**：XX门店，具体日期时间段
  - **质量标准**：无腐烂、无黑心，甜度不低于XX（如有明确标准）
- 收到对方“确认无误”的回复后，才算协议达成。

**4. 备好Plan B，作为谈判筹码**
- 如果供应商答应但拖延，可以明说：“如果你这边确实紧张，我先从隔壁档口调100斤应急，但这样我们的损耗会高，后续大单可能就要分流了。”
- 通常这话能促使供应商优先安排你的货。

**5. 补充建议（防患未然）**
- **锁定应急价**：在旺季前，最好在采购合同里增加“旺季临时补货条款”，规定“因我方需求增加，供应商需在24小时内响应，价格按原合同价的±5%浮动”。
- **多备1-2家备选供应商**：即使本次谈成，也要积极找备用货源，避免单一依赖。

**话术示例（简化版）：**
> “老板，这两天店里爆单了，菠萝用量翻倍。需要你帮忙救急，这个星期再给我加送300斤，要A级去皮的，每斤不多加价吧？我知道你忙，明天早上10点前能送到吧？辛苦你安排一下，这周销量稳定的话，后面我长期多订你家的量。你尽快回复我确认啊，我好安排库房。”

**核心原则**：**用长期订单换短期应急**，**先锁数量、再锁价格、最后锁时间**，并用文字留存证据。利益相关方，尽量提前1天提出，避免当天要货。
