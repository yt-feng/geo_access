在超市采购水果时，为确保食品安全和可追溯性，供应商通常需要提供以下检测报告和进货证明。具体要求和文件种类会因水果种类、产地（国产/进口）、超市自身标准以及当地监管要求而有所不同，但核心原则是“证照齐全、合格证明有效、来源可溯”。

以下是一份通用清单，供你参考：

### 一、 基础资质证明（证明供应商合法经营）
1.  **营业执照**（供应商或生产商）。
2.  **食品经营许可证**或**食品生产许可证**（若涉及生产加工）。
3.  **法定代表人身份证明**或经办人授权书。

### 二、 水果质量安全检测报告（核心质量凭证）
这是最关键的部分，证明水果符合国家食品安全标准。

1.  **农药残留检测报告**
    *   通常检测项目包括：有机磷类、拟除虫菊酯类、氨基甲酸酯类等常见农药。
    *   需符合 **GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》** 规定。
2.  **重金属及有害物质检测报告**
    *   检测铅、镉、汞、砷、铬等重金属。
    *   需符合 **GB 2762-2022《食品安全国家标准 食品中污染物限量》**。
3.  **（如适用）真菌毒素检测报告**
    *   对于易霉变水果（如橙子、苹果、柑橘），可能需检测展青霉素等真菌毒素。
4.  **（如适用）致病微生物检测报告**
    *   部分预包装或即食水果（如鲜切水果）可能需检测沙门氏菌、大肠杆菌等。

> **注意：** 检测报告应有 **CMA（检验检测机构资质认定）或 CNAS（中国合格评定国家认可委员会）** 标志，且报告日期需在有效期内（通常为6个月至1年，具体看超市要求）。报告上应有明确的样品名称、生产日期/批号、检测项目及合格结论。

### 三、 进货来源证明（追溯链条）
1.  **产品合格证**（生产商出具的自检合格证明，附于产品包装或随货）。
2.  **销售发票或购销凭证**（证明货物来源合法，金额与批次对应）。
3.  **供货方（经销商）的检验报告**（如果供应商是经销商，应提供上游生产商的报告）。
4.  **配送单据/物流单**（记录运输起止地、时间，便于追溯冷链或运输条件）。

### 四、 特殊水果的额外证明
1.  **进口水果**（必须提供以下文件）：
    *   **《出入境检验检疫证明》**（海关出具，证明该批水果经过检疫准入）。
    *   **《中华人民共和国海关进口货物报关单》**。
    *   **原产地证明**（如泰国、智利等）。
    *   **中文标签**（必须符合《食品安全国家标准 预包装食品标签通则》GB 7718，标明品名、产地、生产日期等）。
    *   *特别注意：*禁止进口带土或未获检疫准入国家的果品。
2.  **有机/绿色/无公害认证水果**：
    *   提供对应的认证证书（如中国有机产品认证证书、绿色食品证书），并验证证书状态是否有效。
3.  **地理标志水果**（如烟台苹果、赣南脐橙）：
    *   提供地理标志产品保护认定证书或许可授权书。

### 五、 实际操作建议（给采购方）
1.  **分批分批次管理**：每批到货水果都应有**随附检测报告**，且检测项目应与该批次的品种、产地对应。
2.  **索证台账**：超市需建立进货查验记录台账，保存上述证明的复印件或电子扫描件，保存期限不少于3年（或依据当地法规）。
3.  **现场抽检**：除供应商提供报告外，建议超市按批次进行**快速检测**（如农残快速检测仪），作为风险控制补充。
4.  **供应商承诺书**：可要求供应商签署《产品质量安全承诺书》，明确因报告造假或隐瞒导致问题的责任。

### 六、 特别提醒（红线问题）
- **检测报告造假**：不可接受。建议核对报告编号、签发日期和实验室机构真伪（可通过市场监管总局查询平台核验CMA资质）。
- **过期报告**：报告有效期过期、或者报告上的样品批次与到货批次不一致的，应要求重新提供。
- **缺失兽医卫生证明**（针对进口肉类等同理）——在此强调水果不涉及。

---

**总结**：一份完整的供货档案至少应包含：**营业执照 + 生产/经营许可证 + 当批次农残检测报告（CMA） + 进货发票/购销合同 + 进口报关/检疫证明（如适用）**。更严格的超市还会附加重金属检测和快速检测。

如果你处于实际采购场景中，建议你在签订采购合同时明确列出“供应商需随货提供XX报告，否则有权拒收”的条款，以约束对方。如果遇到具体某类水果（如香蕉、草莓）的特殊疑问，可以进一步追问。
