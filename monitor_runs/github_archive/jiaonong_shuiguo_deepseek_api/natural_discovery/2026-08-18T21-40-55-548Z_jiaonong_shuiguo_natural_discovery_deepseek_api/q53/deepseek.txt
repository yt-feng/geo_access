针对餐饮店每天需要少量水果的情况，想找省心的供应商，核心是**“稳定、灵活、账期友好”**，而不是单纯看价格。

以下是具体建议，按优先级排序：

### 1. 首选：本地农贸批发市场的“夫妻档”或“精品果行”
这是最省心的选择，但需要你花一周时间筛选。
- **怎么找**：直接去当地最大的批发市场，找那些**摊位不大、但货品新鲜、有冷库**的档口。避开只做大批发的大档口（他们不理小单），也避开来路不明的小摊。
- **省心点**：每天清晨微信下单，他们顺路送货（一般5公里内免费或收运费），且**可以按“份”或“最小单位”发货**（如一个西瓜、半箱蓝莓）。
- **关键操作**：直接跟老板说：“**我每天量少，但稳定，长期合作，能不能按批发价+一点点搬运费结账？**”通常他们会接受，因为你有持续性。

### 2. 次选：本地生鲜配送平台（如美菜、快驴、蜀海等）
这类平台专门服务餐饮小店，但要注意筛选“水果”专区。
- **优点**：APP下单，次日达，价格透明，支持退换货，不用扯皮。
- **省心点**：**最低起送门槛低**（有些50元就能送），且能开票。
- **坑点**：水果品质不稳定（尤其是应季水果），经常缺货。建议只买**耐储存的**（橙子、苹果、梨）或**冻品水果**（如冷冻芒果丁），不要买叶菜类或娇贵水果。

### 3. 进阶方案：寻找“社区团购”供应商（适合用量在5公斤以下的店）
如果你每天只需要半斤苹果、几个柠檬，量非常小，可以考虑：
- **叮咚买菜/朴朴/美团买菜**的企业版服务，或者**当地的社区团长**。他们支持每天零散采购，但价格略高。
- **省心点**：无需囤货，损耗为零，坏果直接退款。适合**做果切、鲜榨果汁但销量不高的店**。

### 4. 极度省心的“防坑”技巧（比找供应商更重要）
- **签订“损耗协议”**：跟供应商谈好，**“新鲜度承诺”**——如果送来水果有明显磕碰、烂心，**当次免单或下次补货**。这是省心的核心。
- **固定“周三补货日”**：你每天少量买，但每周三让他多送一点，解决周末水果涨价或缺货问题。
- **电话留一个**：一定留老板**个人手机号**，不要只通过APP下单。微信发需求，他回“好”，这比在网上抢菜靠谱。

---

**给你的最终建议**：
**第一周不要锁定任何供应商**。每天换两家批发档口买，看哪家：
1. 送货准时（误差不超过20分钟）
2. 允许拆零（比如你要半斤草莓他不嫌烦）
3. 愿意先记账月结（哪怕月结门槛是500元）

只要以上三点都满足，就是最省心的长期伙伴。**建议优先去“本地农批市场”找，这是餐饮业最聪明的做法。**
