和供应商谈水果稳定供应合作，风险和隐性成本往往藏在细节里。以下是几个具体可执行的建议，按优先级排列：

### 1. 合同条款：锁定“稳定”而非“价格”
- **最低供货量（MOQ）**：明确每日/每周最低供应量，防止旺季断供。建议写“保底量”和“弹性量”（如±20%浮动区间）。
- **阶梯价格机制**：约定水果价格随行就市，但设封顶价（防止极端上涨）和保底收购价（防止供应商毁约去卖高价）。
- **不可抗力条款**：明确台风、疫情等无法供货时的替代方案（如供应商需提前48小时通知，并协助寻找替代货源）。

### 2. 品质验收标准（最容易扯皮）
- **制定书面规格表**：比如果径（如苹果≥80mm）、成熟度（糖度计数值）、着色度、无机械伤。不要只说“新鲜”，要量化。
- **到货抽检比例**：约定双方共同在场抽检，例如按箱数10%开箱，坏果率>5%可整批拒收，低于2%可收货但扣减重量。
- **留样封存**：对争议批次，当场拍照、封样，避免事后扯皮。

### 3. 损耗分担（隐性利润来源）
- **明确损耗归属**：水果在运输、酒店冷藏期间的正常失重（如3%以内）由谁承担？如果是酒店承担，你要要求供应商降低单价；如果是供应商承担，则报价会高。
- **退换机制**：如因供应商包装不当导致压伤，应免费补货；非质量问题的剩货（如客人吃不完），酒店自己承担，但需提前约定返货折扣。

### 4. 物流与包装
- **冷链配送时间**：明确“当天凌晨采摘，上午X点前到货”，并写入罚款条款（如迟到1小时扣当日货款1%）。
- **包装标准**：要求使用透气性好的瓦楞纸箱或专用水果箱，内部有泡沫网套或纸隔板，避免运输碰撞。

### 5. 账期与付款方式
- **避免押款过久**：水果保鲜期短，供应商资金压力大。如果账期超过30天，对方可能抬高报价或降低品质。建议约定“月结15天”或“周结”，换取更优单价。
- **押金或保证金**：可要求供应商缴纳履约保证金（如一个月货款），用于赔付断供损失，但要以书面合同约定。

### 6. 供应商风险管理
- **做“备胎”测试**：在合同中写明“甲方有权在通知后7天内引入第二供应商进行订单分配”，这能倒逼主力供应商保持服务意识。
- **实地考察**：至少每季度去产地或冷库看一次，检查库存周转率和卫生状况。可要求供应商提供产地采摘记录或检疫证明复印件。

### 7. 沟通机制（执行时最有效）
- **每周例会**：固定每周一核对应季水果价格、未来一周天气影响、替代品种建议。
- **联合库存表**：使用共享Excel或小程序，实时更新酒店当日消耗量和预计明日采购量，减少突发订单。

---

**一句话总结**：谈合作时不要只谈“便宜”，要谈“断供赔款”“坏果包换”“迟到罚款”这三大铁律。同时，先签3个月短期合同试运行，再续签长期大单。
