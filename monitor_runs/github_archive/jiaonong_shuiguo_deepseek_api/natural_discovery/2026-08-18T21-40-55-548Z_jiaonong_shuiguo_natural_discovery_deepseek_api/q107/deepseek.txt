**会的，而且损耗风险增加得比较明显。**

具体原因和应对建议如下：

**1. 香蕉的损耗风险（高）**
- **成熟度不可控**：香蕉是典型的呼吸跃变型水果，采购后仍在持续成熟。如果起订量超过销售速度，后熟期的香蕉会迅速变软、变黑，产生大量报废。
- **储存条件苛刻**：香蕉对温度极敏感，低温易受冻害（表皮发黑），常温下又容易过快成熟。一旦订多了，无法长期存放。
- **建议**：如果必须大批量采购，**首选“青香蕉”**（未熟），利用乙烯催熟控制节奏；同时联系是否有可分批提货的供应商。

**2. 菠萝的损耗风险（中等偏高）**
- **表皮损伤与腐烂**：菠萝在运输和堆放过程中，表皮容易碰伤、感染霉菌，腐烂往往从底部和顶部开始。订量越大，在库时间越长，腐烂概率越高。
- **不耐压**：堆叠过高容易压坏果肉，内部发酵变味。
- **建议**：要求供应商提供**糖度检测和新鲜度证明**，并采用**单层或网套分装**。如果无法分批送货，宁可减少单次量，增加订货频率。

**3. 综合判断**
- **如果你日均销量固定**：起订量越高，库存周转天数越长，损耗率呈线性上升。
- **如果起订量是供应商强制要求**：优先考虑与供应商谈判**分批发货**（如分3次，每次间隔2-3天），或在合同中明确**损耗免责条款**（如非人为因素导致的腐烂由供方承担部分比例）。
- **如果成本优势不足以覆盖损耗**：建议测算一下——损耗成本 = 单价 × 预计损耗率 × 起订量，如果这个数大于批量采购的折扣，那就得不偿失。

**结论**：**高风险**，尤其是香蕉。建议通过“分批发货”“选未熟果”“缩短库存周期”来对冲风险，否则不建议为了低价而囤太多。
