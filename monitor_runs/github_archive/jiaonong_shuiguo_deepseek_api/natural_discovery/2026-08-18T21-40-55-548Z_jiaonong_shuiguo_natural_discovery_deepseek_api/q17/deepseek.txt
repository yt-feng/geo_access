社区超市做水果生意，核心矛盾就是**“货损”和“断货”**。要控制新鲜度和库存，不建议靠拍脑袋，需要一套“以销定采”的傻瓜式流程。以下是从实操角度给出的建议：

**第一步：把“新鲜度”变成硬指标（收货关）**
1. **定标准：** 进货时不要只看价格。要明确要求供应商提供“采后处理”等级（比如产地直发、冷库预冷）。收货时用**目测+手感**：叶菜看挺拔度，瓜果看表皮光泽，草莓/蓝莓看盒底有没有渗水。
2. **看批次：** 一定要看**生产日期（包装日期）**，而不是“到货日期”。宁可少进，也要进昨天或今天刚出库的货，而不是冷库里放了3天的“僵尸果”。
3. **设警戒线：** 对于香蕉、芒果、木瓜这类“后熟型”水果，要分成熟度进。比如按“1分熟、3分熟、6分熟”的比例进货，避免一车全是青的（卖不动）或全是黄的（当天烂）。

**第二步：用“ABC分类法”管库存（库存关）**
不要对所有水果一视同仁，要“区别对待”：
- **A类（高频易损耗）：** 香蕉、草莓、葡萄、叶菜类。**原则：** *勤进快销，一天一进或两天一进*，单次进货量控制在预计1.5天内卖完的量（最多不超过2天）。
- **B类（中频常备）：** 苹果、橙子、梨、桃子。**原则：** *可少量备货*，库存量控制在3天内卖完的量。这类水果耐放，但也要注意“吹风”和“翻堆”。
- **C类（低频大件/节日果）：** 榴莲、椰子、整箱礼盒。**原则：** *以销定采，先订货后进货*。不预售不进货，或只放1-2个陈列样品，接到订单再让供应商次日送货。

**第三步：用“时段折扣”代替“整箱烂掉”（动销关）**
1. **“一日三价”法：** 
   - **上午：** 按正常价，挑最好的卖。
   - **下午 3点-5点：** 将轻微发软、有微小瑕疵但不影响食用的水果，单独挑出来，立牌标明“特价果”，打8折或7折。
   - **晚上 7点后：** 将剩余水果打包成“盲盒”或“果切”，按成本价甚至略低于成本价卖（目的是回笼资金，换取明天进货的现金流）。
2. **“果切”是最后防线：** 只要水果没烂到出水，就可以削皮切块做成果切盒。这是解决库存最直接的办法，但**当天必须做，当天必须卖完**，否则坚决倒掉，不能过夜。

**第四步：用“数据”说话，别凭感觉（复盘关）**
每天打烊后，花10分钟记录三个数：
- **今日进货量** 与 **今日销量**。
- **今日损耗量**（（进货量-销量-次日剩余可售量）/进货量）。
- **滞销品名单**（哪些水果卖得慢）。
**设定红线：** 如果某类水果连续两天损耗超过15%，第三天真接取消该类水果的进货计划，直到找到替代品。

**特别提醒（避坑指南）：**
- **不要迷信“产地直采”：** 如果单次采购量不够大，产地直发往往物流时间更长，反而不如本地批发市场快。
- **冷柜不是万能的：** 很多水果（如香蕉、热带水果）怕冷，进冷柜反而会加速表皮变黑。要分清哪些必须冷藏（草莓、蓝莓、葡萄），哪些常温通风即可（苹果、橙子）。
- **和供应商谈“换货协议”：** 最好的进货方式是“卖不完，次日按6折退回”或“卖不完，供应商第二天折价补货”，这比你自己承担损耗强得多。

**执行总结：** 
- 每天进的水果，目标是在**48小时内**卖掉80%，剩下的20%在**72小时内**降价处理完毕。
- 如果某天货进多了，宁可在晚上8点打折甩卖，也不要留到第二天上午卖“旧货”——因为卖旧货会砸了新鲜招牌，导致客流流失，那是更大的损失。
