判断香蕉批发档口的**一手货源**是否稳定，核心要看**供应链的纵深**和**合作机制**，而不是单纯看报价。因为香蕉是农产品，受产区天气、运输（尤其海运/陆运周期）、催熟成本影响极大。

以下是**5个实操判断维度**，你可以直接去问对方或看对方的运作方式：

**1. 看“产地结构”而非“单一产地”（关键）**
- **问法**：“如果云南/老挝/缅甸（或你主要拿货的产区）下雨或者封关，你这边有备用产区吗？”
- **稳定表现**：真正一手货源的老板能明确说出“我们云南基地拿不到货时，海南、广西的货3天内能接上”，或者“我们有自己的种植基地”。
- **不稳定表现**：只会说“我货很多，你买就完了”，说不出产地切换逻辑，一旦产区台风或价格倒挂，立刻断供。

**2. 看“挂果周期”与“到货节奏”**
- **问法**：“你现在的货是几成熟的？到仓库后一般催熟几天？”
- **稳定一手**：会告诉你“现在是菲律宾进口（或海南本地），大概8成熟，离港口/产地1000公里内可以次日达”。
- **陷阱**：如果对方只卖“熟透的货”（因为熟透的容易烂，必须快出），说明他只是**二批**，从别的档口拿货，**不是一手**，无法控制到货时间。

**3. 看“账期与定金”的宽容度**
- **稳定供货商**：通常愿意给你**3-7天的账期**（或先付30%定金，货到验收后付尾款），因为他不愁卖，有底气。
- **不稳定供货商**：会要求“全款到账才发货”或“定金50%起”，因为他怕你跑路，也怕货砸手里，说明他自己现金流紧张或货源不稳定。

**4. 看“损耗率承诺”与“赔付条款”**
- **直接问**：“如果到货后，有5%以上的烂果或催熟过度，怎么处理？”
- **稳定方**：敢承诺“抽检不合格按比例赔付”，或者“下次进货抵扣”。
- **不稳定方**：会推诿“这是运输问题，我控制不了”，或者“你当天必须提走，烂了我不负责”。

**5. 看“车/柜”的到达规律性**
- **看对方朋友圈或档口记录**：是否**每周固定到货**（比如每周二、五有柜），还是“偶尔来一柜”。
- **稳定一手**：往往有固定的**冷链车/海运柜**排期，即使行情不好，他也会到货（因为产地合同必须执行）。
- **不稳定一手**：行情好时货多，行情跌时断供（因为他自己也是“投机性”采购）。

---

**如果时间有限，最直接的一招：**
> “我这边每天大概要800-1000箱，你能给我签个**周供合同**吗？如果连续两周断供，我尾款就不结了。”

**能签、敢签的，大概率稳定；含糊其辞、说“看行情再说”的，基本不稳定。**

**风险提示**：香蕉价格波动大（尤其节前节后），建议**先小额试单3次**（每次几十箱），记录到货时间、损耗率、口感均匀度，连续3次都OK再签长期合同。不要因为对方报低价就加大单量，低价往往对应的是“残次品”或“抢货先拉走，好坏随机”的货。
