选择供应商时，大家通常会关注价格、新鲜度和送货及时性，但容易忽视以下关键细节，这些恰恰是长期稳定的命脉：

1. **损耗率与次品处理机制**  
   供应商报的单价低，但如果损耗率高（如碰伤、腐烂、失水），实际成本反而更高。要问清楚：  
   - **退换货政策**：烂果能否按比例无条件退换？是当场赔付还是下次抵扣？  
   - **损耗承担**：运输途中破损由谁负责？到店后自然损耗（如榴莲开裂）是否能按比例折价？

2. **产地与采摘周期透明度**  
   供应商是否清楚告知每个水果的**具体产地**和**采收时间**？产地不同（如海南和越南的芒果）、采摘熟度（7成熟 vs 9成熟）直接影响货架期。如果供应商含糊其辞，可能是在混批（用低品质冒充高品质）。

3. **供应链的稳定性与备选货源**  
   - 当主产区遭遇极端天气（台风、暴雨）时，供应商是否有**B计划**（如切换备用产地）？  
   - 是否能保证**淡旺季供货速度**？比如春节前后，是否提前锁定库存？如果对方只有单一产地，一遇灾害就容易断供。

4. **冷藏链的“最后一公里”**  
   很多供应商有冷库，但装车、卸货、送货到店时是否全程冷链？如果你收货时水果温度不正常（如车在太阳下暴晒），意味着冷链断裂，这会造成隐性损耗。可要求供应商提供**到货温度记录**。

5. **账期与资金占用规则**  
   短期看报价，长期看账期。供应商是否支持**月结30天**或更长？如果要求**现款现货**，会占用你大量现金流。另外，是否接受**小批量多频次**送货（如每天送）？这能降低你的库存和损耗，但部分供应商嫌麻烦不愿配合。

6. **包装与标准化程度**  
   是否有**统一规格的净重包装**（如每箱10kg正负误差低于0.5%？）？如果每箱实际重量偏差大，你按箱计价就会吃亏。还要看**包装材料**是否防压防震（如网套、纸隔板），包装破损率高说明品控不严。

7. **售后响应速度与赔偿标准**  
   一旦出现品质问题（如整批柑橘发霉），供应商是否能**2小时内响应**并给出明确赔偿方案？如果对方售后流程繁琐、找各种理由推脱，长期合作你会非常被动。

8. **其他客户的真实口碑**  
   不要只看供应商自述，要**侧面打听**其合作客户（如学校食堂、高端餐厅）的反馈。重点问：**断供次数**、**缺斤少两情况**、**单品翻车频率**。如果对方不愿意提供老客户联系方式，要谨慎。

---

**行动建议**：  
正式合作前，先**小批量试单3-5次**，重点记录：每次损耗率、烂果赔付是否及时、送货准时率。同时要求供应商提供《供货保障协议》，明确损耗赔付比例（建议不低于5%）、应急预案（如48小时内补货）和违约金条款。

记住：**稳定 = 供应链韧性 + 可量化的售后规则**，而不是单纯看报价单上的那几毛钱差价。
