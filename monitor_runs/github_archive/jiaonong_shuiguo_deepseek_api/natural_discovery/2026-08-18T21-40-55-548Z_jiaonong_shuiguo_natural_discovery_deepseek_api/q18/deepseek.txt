在超市采购香蕉时，要避免买到太生或太熟，关键在于**看颜色、摸手感、看部位**。以下是可以直接照做的实用方法：

### 1. 明确“目标成熟度”对应的颜色
- **想当天/隔天吃**：选**整体黄色、带少量褐斑（芝麻点）** 的，这种最好吃，甜度最高。
- **想冷藏/存3-5天**：选**整体黄绿相间**，即顶部和中部有少量绿色、但捏起来略软，会自然熟。
- **必须避开**：整体绿得很均匀、捏起来硬邦邦的（通常没熟）；或整串黑斑严重、捏起来软烂出水（过熟）。

### 2. 用“手感法”确认，不要只靠看
- 轻轻捏香蕉中部和尾部（不要捏尖端，易受伤）。
- **太生**：捏起来像石头，没有弹性，按不动。
- **合适**：轻轻按有弹性，微微凹陷但能回弹，像按“熟透的梨”。
- **太熟**：按下去明显软塌、不回弹，甚至指尖有黏稠感。

### 3. 看“冠部”（香蕉柄连接处）
- 冠部颜色**鲜绿或浅黄** → 通常较生。
- 冠部**变黄、微开裂** → 适合当天吃。
- 冠部**变黑、发霉** → 过熟或保存不当，别拿。

### 4. 选“整串”时注意细节
- 避免拿**最顶部那根**（通常最熟）或**最底部那根**（通常最生）单独判断，看整串**大多数**香蕉的颜色。
- 如果有单根断裂、有外伤流汁的，不拿，容易提前腐败。

### 5. 辅助技巧（如果只能买整把）
- 如果买的是黄绿色偏生的，回家后**不要放冰箱**，放在常温通风处，1-2天会自然熟。
- 如果买回来发现太熟，立刻**剥皮冷冻**，做奶昔或烘焙用，避免浪费。

### 总结一句话：
**拿起香蕉，先看整体主色（绿多黄少=偏生，黄多绿少=正好，黑斑多=偏熟），再捏中段（硬=生，弹性=刚好，软塌=熟过头），最后看冠部是否发黑。** 这样基本不会踩雷。
