茶饮店用香蕉，核心不是“买最熟的”，而是**按用途分熟度、按批次分阶段采购**。香蕉熟度变化快，建议直接用“表皮颜色+手感”做验收标准，并把采购量控制在2～3天用量内。

**1. 先按用途定熟度**
- **做香蕉牛奶、奶昔、冰沙、果泥挂壁**：用**7～8分熟**，表皮黄色、略带少量褐色斑点，手捏有弹性但不软烂。香气够、甜度够，打碎后不易发黑发酸。
- **做香蕉果肉装饰、切片顶料**：用**6～7分熟**，全黄、基本无斑，果肉硬挺，切面不易塌。
- **做香蕉蛋糕、磅蛋糕、香蕉派馅、烤布蕾底**：用**8～9分熟**，黄皮带明显褐斑、手感偏软，甜度和香气最足，压泥更顺。
- **不建议饮品店大量用全褐发黑香蕉**：除非当天压泥并立即使用，否则氧化、发酵和酸败风险高。

**2. 验收标准**
- 拒绝：青硬、大面积黑斑、破皮流汁、有酒味/酸味、果柄发霉。
- 可收：同一批颜色接近，避免一箱里从全青到全黑混装。
- 手感：轻捏有回弹；若一捏就陷、表皮渗液，说明过熟。

**3. 采购与库存控制**
- **少量高频**：按日均用量×1.5～2天采购，夏天或高温天气按1～1.5天。
- **分批到货**：每天到一点，或一次到货后分“偏生、适熟、立即用”三档。
- **分阶段催熟**：偏青香蕉常温避光存放；适熟香蕉放阴凉通风处；已出褐斑的优先排产，必要时冷藏延缓但不要长期冷藏，冷藏后表皮发黑、风味下降。
- **先进先出**：每批贴到货日和熟度标签，先熟先用。

**4. 门店操作建议**
- 香蕉剥皮后极易氧化，饮品用香蕉建议**现切现打**，可加少量柠檬汁或维C护色。
- 过熟香蕉不要直接报废，可当天集中做烘焙馅料或香蕉泥，但必须冷藏并当日用完。
- 建立简单验收表：到货日期、数量、表皮等级、手感、处理方式，连续记录一周就能算出稳定采购量。

一句话：**饮品用7～8分熟，装饰用6～7分熟，烘焙馅用8～9分熟；采购按2天量、分批到货、贴标先进先出。**
