判断“哪个规格更容易出货”，不要凭感觉，按下面几步用自己最近的真实数据做筛选。

**1. 先定义“规格”**
菠萝常见分法要统一口径，否则数据不可比：
- 按重量：如 800g–1000g、1000g–1200g、1200g–1500g、1500g以上
- 按果径/等级：大果、中果、小果、精品果、统货
- 按成熟度/用途：鲜食零售、餐饮切果、加工
建议至少按“重量段+等级”组合统计，不要只看大小。

**2. 拉最近 2–4 周出货数据**
每个规格记录：
- 出货量（件/斤/箱）
- 出货频次（多少客户拿、多少天有单）
- 平均出货天数（从到货到卖完）
- 退货/损耗率
- 成交价与毛利
- 客户类型（商超、水果店、餐饮、二批、团购）

**3. 看四个核心指标排序**
优先出“周转快且不亏”的规格：
- **动销率**：某规格出货量÷到货量，越高越快
- **周转天数**：越短越容易出货
- **复购客户数**：拿过的客户里有多少再次拿，比一次性大单更可靠
- **损耗后毛利**：菠萝损耗高，必须扣掉坏果、削皮、退换后的毛利

简单判断：
- 动销率高、周转短、复购多、损耗低 → 主推规格
- 动销高但毛利低甚至倒挂 → 引流规格，控制量
- 动销低但毛利高 → 小众规格，只做预订或搭配
- 动销低、损耗高 → 尽快淘汰或改包装/改等级

**4. 做小批量测试，不要一次性压货**
选 2–3 个候选规格，各拿小批量，同一时间段、同一批客户测试 7–10 天：
- A 规格：比如 1000–1200g 中果
- B 规格：1200–1500g 大果
- C 规格：800–1000g 小果
记录每天出货和剩余，卖完即止。测试期不要混着推，避免客户替代选择干扰判断。

**5. 看客户结构决定主规格**
- 水果店/社区团购：中小果、按个卖、价格敏感，通常 800–1200g 更好走
- 商超/精品店：外观整齐、规格均匀的大中果更好陈列
- 餐饮/切果/果汁：更看出肉率和成本，大果或加工果可能更快
- 二批市场：价格和统货周转优先，规格不必过细

**6. 用简单打分表落地**
每个规格按 1–5 分打分：
- 动销速度 30%
- 周转天数 25%
- 损耗后毛利 25%
- 复购客户数 20%
总分最高的作为主推规格，次高的做搭配，最低的减量或停拿。

**结论**：更容易出货的规格，不是“最大”或“最便宜”，而是**在你现有客户结构下，动销率最高、周转最短、损耗后仍有毛利、复购客户最多的那个规格**。先用最近真实出货数据排序，再用 7–10 天小批量测试验证，避免凭经验压错规格。
