水果店遇到坏果，结算或赔付的关键是：**先分清坏果发生在谁承担风险的环节**，再按合同/行业惯例扣款或换货。可执行做法如下：

1. **到货时当场验收**
   - 开箱抽检/全检，坏果、次果当场拍照、称重、记录数量。
   - 让司机或供应商在送货单上签字确认“坏果数量/重量”，这是后续扣款最有力的凭证。
   - 生鲜通常约定“到货验收后风险转移”，所以越早发现越容易索赔。

2. **按合同或约定结算**
   - 有合同：按合同里的损耗率、赔付比例、退换货条款执行。
   - 无合同：常见行业做法是**坏果部分不结算**，或按坏果重量/金额从当批货款中扣除；也可要求下一批补货。
   - 若整批质量问题严重，可拒收或整批退货，但要及时书面通知供应商。

3. **区分责任**
   - 运输途中压伤、腐烂：一般由供应商承担，除非约定由门店自提自运。
   - 到店后因存放不当变质：门店自己承担。
   - 隐性内部腐烂：到货后短时间内发现，应及时反馈，协商按比例赔付。

4. **留证和书面确认**
   - 保留照片、视频、称重记录、送货单、聊天记录。
   - 扣款前给供应商发书面确认：批次、数量、坏果重量、扣款金额，避免月底对账争议。

5. **结算方式建议**
   - 小额：当批货款直接扣减。
   - 长期合作：设“质量保证金”或月度损耗补偿比例。
   - 频繁出问题：在合同中明确坏果率上限，例如超过约定比例则整批退货或按比例赔付。

一句话：**当场验、当场记、当场签，按合同扣；没合同就按坏果重量/金额从当批货款中扣，并保留证据。**
