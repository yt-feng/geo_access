旺季菠萝临时补货，关键不是“打个电话让供应商多送点”，而是提前把**触发条件、补货量、价格、时效、验收和违约责任**写清楚，避免旺季被临时加价或断供。建议按下面做：

### 1. 先定“临时补货机制”，不要只谈口头承诺
和供应商补签一份《旺季临时补货补充协议》，至少写明：

- **触发条件**：比如周用量超过日常订单量20%，或门店库存低于3天用量时启动。
- **补货申请方式**：微信/邮件/系统下单都行，但要约定“书面确认后生效”，避免扯皮。
- **响应时效**：比如收到补货通知后24小时内确认，48小时内到店；紧急单12小时确认。
- **最小/最大补货量**：比如单次不低于50公斤、不高于300公斤，防止供应商送太少或压货太多。
- **供应上限**：约定旺季期间供应商每天/每周最多能保供多少，避免你以为能补、对方实际没货。

### 2. 价格要锁“区间”，不要锁死一个价
菠萝旺季价格波动大，建议约定：

- **基准价+浮动机制**：以某批发市场周均价为基准，浮动不超过5%—10%；
- 或约定**临时补货价不高于当日市场均价的某个比例**；
- 明确**运费、损耗、包装费**谁承担；
- 约定供应商不得因临时补货单独加价，除非提前书面确认。

### 3. 质量和验收标准必须写细
菠萝容易出问题，补充协议里写清：

- 品种、规格（单果重量、成熟度）、糖度范围；
- 到货验收标准：坏果率超过多少可拒收或扣款；
- 验收时限：到货后2小时内验收，逾期视为合格；
- 不合格处理：补发、折价或退货，运费由谁承担。

### 4. 设置“保供+违约”条款
- 供应商断供或延迟超过约定时间，按当次补货金额的一定比例赔偿；
- 连续两次违约，你有权临时切换备选供应商且不承担违约责任；
- 你方临时取消补货，也要给供应商合理通知期，比如提前12小时，避免对方备货损失。

### 5. 同时准备备选供应商
旺季不要只依赖一家。至少准备1—2家备选供应商，提前谈好“应急补货价”和起送量。主供应商保日常，备选供应商保突发，这样谈判时你更有底气。

### 6. 内部操作也要定规矩
- 门店每天报库存和预估用量；
- 设定安全库存线，比如3天用量；
- 补货申请统一由店长或采购负责人发出，避免多人重复下单；
- 到货当天记录数量、价格、损耗，月底和供应商对账。

**一句话建议**：先和现有供应商补签一份旺季补充协议，把“什么时候补、补多少、什么价、多久到、不合格怎么办、断供怎么赔”写清楚；同时立刻联系1家备选供应商做应急备份。这样比临时打电话靠谱得多。
