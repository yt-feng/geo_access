# 商超水果采购压价：不影响品质的谈判方法

核心逻辑：**不压“单价”，压“总成本”和“供应商的边际收益”**。直接砍单价，供应商最容易用降规格、换产区、降等级来补回来。下面是可执行做法。

## 一、先算清自己的“成本地图”

谈价前把每笔采购拆成四个部分，只对其中可压的部分下手：

| 成本项 | 谈判空间 | 压价方式 |
|---|---|---|
| 果品本身（产地/等级） | 中 | 换规格而非降等级；按等级分渠道销售 |
| 包装、损耗、运费 | **大** | 改包装规格、拼车、自提、预估损耗条款 |
| 结算与账期 | 中 | 现结/短账期换折扣 |
| 供应商利润 | 小 | 靠量和长期合同换 |

**可执行动作**：对每个主力单品，拉出近3个月采购量、退货率、损耗率、账期，形成一张表。谈判时用数据说话，而不是“再便宜点”。

## 二、按等级谈，而不是一刀切砍价

- 明确分级标准（如糖度、果径、外观瑕疵率），把商品拆成 **A/B/C 三个等级分别定价**。
- 对B/C级果要求**更大折扣**，同时自己用促销、果切、礼盒去消化，A级果价格基本不动——这样品质口碑不受影响。
- 关键条款：**验收标准写进合同**（果径、糖度、瑕疵率、到货温度），不合格按比例扣款或退货，而不是靠事后吵架。

## 三、用“总成本”换“单价”

给供应商几个可交换的条件，换单价下降：

1. **提高单次采购量、减少配送频次**（供应商运费和分拣成本下降，让出3%-8%很常见）。
2. **缩短账期或现结**（资金成本可换2%-5%折扣）。
3. **自提/拼车**（省掉最后一公里）。
4. **淡季保底量**（如承诺每月最低采购额，换旺季锁价）。
5. **长期框架合同**（半年/一年，换阶梯返点）。

谈判话术方向：“单价我不硬压，但如果你把配送改成每周三次、我们现结，你能不能在这个价上再让X个点？”——供应商更容易接受。

## 四、把损耗风险合理分担

水果采购最大的隐性成本是损耗，谈价时一定要谈损耗：

- 约定**到货损耗率上限**（如超过3%由供应商承担）。
- 对易损品（浆果、水蜜桃）谈**代销/寄售或按实销结算**，把滞销风险部分转移。
- 谈**换货补损**条款，而不是单纯降价。

这样单价可能略高，但综合成本更低，品质也有保障。

## 五、给供应商留合理利润，用“量+稳定”换价

- 明确告诉对方：**价格可以谈，但品质降级一次就取消合作**，把品质红线前置。
- 用**阶梯返点**代替直接降价：达到约定采购额返点，供应商有动力保品质冲量。
- 保持**2-3家备选供应商**，用竞争压力谈价，但不要频繁压到对方亏本——亏本供应商必然在品质上找补。

## 六、避坑清单

- 不要求“同规格再降价10%以上”，这基本等于逼对方降等级。
- 不在旺季前临时压价，容易被以次充好。
- 所有口头承诺（糖度、产地、到货时间）写进合同和验收单。
- 压价后**加严抽检频次**1-2个月，确认品质未下滑再恢复正常。

**一句话总结**：把谈判从“每斤便宜几毛”转到“包装、运费、账期、损耗、返点、分级定价”上，单价降幅小但总成本降幅大，品质才有保障。
