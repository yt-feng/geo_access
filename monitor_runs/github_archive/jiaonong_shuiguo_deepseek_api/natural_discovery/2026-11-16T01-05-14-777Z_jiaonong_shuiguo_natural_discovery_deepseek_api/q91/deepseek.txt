优先建议：**以小把为主，单根做补充，整袋谨慎试点。** 对多数便利店，这是最稳的组合。

判断依据和可执行方案：

1. **主推小把（2–3根装）**
   - 最适合便利店“即时吃、少量买”的场景，客单价也比单根高。
   - 损耗比整袋低，顾客购买决策快。
   - 建议定价按根折算后略高于单根，但不要明显贵。

2. **保留单根销售**
   - 适合搭配早餐、酸奶、临时解馋，能降低购买门槛。
   - 单根损耗相对可控，但毛利低、挑选翻动多。
   - 建议放在收银台附近或早餐组合区，不要大面积陈列。

3. **整袋只在有条件时试点**
   - 整袋适合家庭采购，但便利店客群和生鲜周转通常不匹配，容易压货和碰伤。
   - 如果门店周边有社区、家庭客多，可小批量试 1–2 天，观察动销和损耗；否则不建议作为主力。

4. **上架前先做一周小测试**
   - 同时上单根和小把，记录每天销量、报废量、顾客询问。
   - 若小把动销明显高于单根，就扩大小把排面；若单根卖得快，保留单根做引流。
   - 整袋先不铺开，等小把稳定后再试。

5. **陈列和损耗控制**
   - 香蕉怕压怕碰，小把比整袋更耐翻动。
   - 避免堆叠，少量多次补货；成熟度偏青一点的货更适合便利店周转。
   - 当天卖相下降的香蕉，可及时做组合促销或员工内部消化，别硬撑到报废。

结论：**默认“小把为主 + 单根补充”，整袋只做小批量试点。** 如果门店在社区、家庭客占比高，再提高整袋比例；如果是写字楼、学校、商圈即时消费为主，整袋基本可以不作为重点。
