直接给你可落地的做法：**先保营业、再谈责任、补货条款写进采购合同/订货单，不要只靠口头。**

下面按“到货当下怎么处理”和“合同怎么约定”两块说。

## 一、到货当下的处理流程（避免断货）

1. **当场验货，不合格不入库**
   - 称重、看外观、闻气味、抽检切开；拍照/录像留存（含批次、车牌、送货单）。
   - 不合格部分**拒收并在送货单上注明数量、原因，双方签字**；不要先收下再扯皮。

2. **分级处理，别一刀切拒收**
   - 轻微瑕疵（可挑拣使用）：挑拣后按实际可用量结算，瑕疵部分折价或退。
   - 严重不合格（腐烂、异味、农残风险）：整批拒收。
   - 这样能保住一部分可用货，减少断档。

3. **启动“应急补货”条款**
   - 要求供应商**当日内/次日营业前**补足合格品；
   - 同时启用备用供应商或就近采购，**优先保证门店营业**，差价事后向责任方追偿。

4. **书面确认**
   - 用微信/邮件发《到货异常确认单》：批次、数量、问题、要求补货时间、补货数量，要求对方回复确认。这就是后续索赔依据。

## 二、合同/订货单里怎么约定（关键条款）

建议在采购合同或每次订货单中写明：

1. **验收标准**
   - 明确品种、规格（单果重量/直径）、成熟度、新鲜度、无腐烂/异味/病虫害；
   - 引用国家标准或双方封样，避免“看着不行”这种模糊表述。

2. **补货义务与时限**
   - 不合格品由供应商**免费补足**，补货到达时间约定为“**当日__点前/次日营业前**”；
   - 逾期未补，买方有权自行采购，**差价及因此产生的营业损失由供应商承担**（营业损失可约定固定金额或按日计算，便于执行）。

3. **退货与结算**
   - 不合格品拒收或退回，运费由供应商承担；
   - 该批次货款**待补货验收合格后结算**，或按合格数量结算。

4. **备用与替代**
   - 允许买方在供应商无法及时补货时**自行采购替代**，费用从应付货款中扣除或向供应商追偿。

5. **违约与频次管理**
   - 约定月度不合格率上限（如≤3%），超限可扣款、暂停下单或解除合同；
   - 连续两次补货仍不合格，买方有权终止合作。

6. **证据与对账**
   - 送货单须注明批次、数量、验收结果并双方签字；异常单作为结算和索赔依据。

## 三、操作要点

- **不要只约定“可以退换”**，必须写清**补货时限+逾期自购+差价承担**，否则影响营业时无法追责。
- **备用供应商常备1–2家**，这是不断货的根本保障。
- 补货条款放在**订货单背面或每次下单确认**里也有效，确保每批货都适用。

一句话：**验货留证、分级拒收、限时补货、逾期自购、差价可追、备用不断。**
