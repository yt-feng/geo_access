# 生鲜电商卖香蕉：压坏和变黑的防控方案

香蕉是生鲜里最难配送的单品之一，核心矛盾是：**太青不能吃，太熟一压就烂**。所以要分“选品—包装—履约—售后”四段来控制。

## 一、选品与催熟：从源头降低风险

1. **按配送半径定熟度**
   - 同城当日达：选**青黄交接（3~4号色，七八分熟）**，到手后常温1~2天转熟，抗压最好。
   - 次日达/跨城：必须选**偏青（2~3号色）**，宁青勿熟。
   - 切忌发全黄带芝麻点的香蕉，运输中极易压伤变黑。

2. **控制催熟程度**：供应商按“到货即食窗口”倒推催熟，不要按发货日催熟。可要求供应商提供色号，收货抽检。

3. **选耐运输品种**：优先果指粗、果皮厚的品种（如部分巴西蕉/威廉斯系列），少用皮薄易碰伤的品种。

## 二、包装：防压为主，防闷为辅

- **单根保护**：每根香蕉套**珍珠棉网套或气泡袋**，重点包住果指中段和果柄。
- **整把固定**：整把用软纸或珍珠棉包裹后，放入**带隔断的硬质纸箱/EPE箱**，箱内空隙用填充物塞满，防止晃动碰撞。
- **悬挂或架空**：条件允许时，箱内做“悬空托架”，让香蕉不直接受力于箱底。
- **不要密封闷死**：香蕉呼吸产乙烯，密封会加速变黑。箱体留透气孔，或用打孔膜，避免冷凝水。
- **防潮防冷凝**：箱内加吸水纸/干燥剂，冷链或温差大时尤其重要，冷凝水是变黑主因之一。
- **果柄朝上或侧放**，避免果指相互挤压；不要堆叠超过2层。

## 三、履约与温控

- **常温配送优先**：香蕉怕冷，**低于12℃会冷害发黑**。不要放冷藏车/冰袋直触，冬季北方要防冻。
- **夏季高温**：避免暴晒和车厢高温，可用隔热袋但不要加冰袋贴果。
- **轻拿轻放**：在分拣环节单独标识“易压品”，不与重物混装。
- **缩短在途时间**：香蕉优先安排最早班次配送，减少中转。

## 四、售后与预期管理

- 商品页明确标注“收到为青黄，常温放置1~2天转熟”，降低“到手不黄”的投诉。
- 制定**压伤/黑斑赔付标准**（如单根压伤超1/3拍照赔付），快速理赔减少纠纷。
- 收集破损数据，反向调整熟度和包装。

## 关键判断清单

| 场景 | 推荐熟度 | 包装重点 |
|---|---|---|
| 同城当日达 | 3~4号色 | 网套+隔断箱 |
| 次日达 | 2~3号色 | 气泡袋+硬箱+填充 |
| 夏季高温 | 偏青 | 透气+隔热，不加冰贴果 |
| 冬季低温 | 偏青 | 防冻，避免冷害 |

**一句话原则：宁青勿熟、单根防护、硬箱隔断、透气不闷、全程防低于12℃。**
