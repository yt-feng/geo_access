三者不是同一层级的问题：**食品安全是底线（一票否决），配送准时是保障（影响可用性），价格是优化项（在满足前两者基础上再谈）。**

具体判断顺序建议：

1. **食品安全优先**
   - 水果直接入口，食堂面向员工集中供餐，一旦农残、霉变、致病菌或来源不合规出问题，后果最大。
   - 采购时要看：供应商资质、产地/批次凭证、农残检测或承诺达标合格证、验收标准（新鲜度、腐烂率、异味）、留样和退换货机制。
   - 这一项不合格，价格再低、送得再快都不应合作。

2. **配送准时第二**
   - 水果有保鲜期，食堂供餐时间固定，晚到会直接影响当日供餐或造成临时替代。
   - 但要区分“准时”与“过度承诺”：关键看约定到货窗口、缺货/延误的替代方案和违约责任，而不是单纯比谁送得快。

3. **价格第三**
   - 在食品安全和配送稳定达标后，再比价格。
   - 建议比“综合到货价”，包括损耗率、退换货成本、账期和隐性配送费，而不是只看单价最低。

**可执行结论：**
- 先设食品安全准入条件，不合格直接淘汰；
- 再筛配送准时且稳定的供应商；
- 最后在合格供应商中比价、比账期、比损耗。
- 如果必须排一个优先级：**食品安全 ＞ 配送准时 ＞ 价格**。
