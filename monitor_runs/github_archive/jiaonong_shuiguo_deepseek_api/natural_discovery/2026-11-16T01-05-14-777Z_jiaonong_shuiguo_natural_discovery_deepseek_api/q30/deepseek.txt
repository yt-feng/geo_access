建议把“到货验收—留证—分级处理—时限—责任—结算扣款”写进采购合同或补充协议，不要只靠口头售后。可按下面约定：

1. **到货验收标准**
   - 明确品类、等级、规格、糖度/成熟度、单果重、颜色、瑕疵率上限（如腐烂、压伤、裂果、虫眼比例）。
   - 约定“可接受瑕疵”和“拒收标准”，例如腐烂果超过X%、整体不合格率超过Y%可整批拒收或部分拒收。
   - 约定验收时限：到货后2小时内或当日营业前完成抽检；逾期未提出异议视为数量验收通过，但不免除隐蔽质量问题责任。

2. **到货留证流程**
   - 收货时拍整车/整批、开箱、抽检、称重、瑕疵特写照片或视频，保留送货单、批次号、温度记录（如冷链）。
   - 双方在验收单上签字确认数量、抽检比例、不合格数量和暂定处理方式。

3. **分级售后处理**
   - 轻微瑕疵：折价接收，按不合格比例扣款。
   - 中度瑕疵：退货换货，供应商承担运费和损耗。
   - 严重腐烂/食品安全风险：整批拒收或销毁，供应商退款并承担相关费用。
   - 已上架后发现隐蔽问题：约定可追溯批次，按实际损失索赔。

4. **响应与处理时限**
   - 超市提出售后后，供应商应在2—4小时内响应，24小时内给出换货/补货/退款方案。
   - 换货补货到店时限明确，比如24—48小时内；逾期超市可自行处理并从货款中扣除损失。

5. **费用与责任**
   - 明确退换货运费、装卸费、销毁费、冷链损耗由谁承担。
   - 因不合格水果导致顾客投诉、赔偿或监管处罚的，约定供应商承担相应责任。
   - 约定扣款方式：从当批货款、保证金或下期结算中扣除。

6. **结算与保证金**
   - 可约定每批货款预留5%—10%作为质量保证金，验收后X天无质量问题再结清。
   - 月度汇总不合格率，超过约定阈值可调整供货资格或终止合作。

7. **争议处理**
   - 约定以双方共同抽检、照片视频、第三方检测或监控记录为依据。
   - 明确争议不影响超市对明显不合格批次先拒收、先保全证据。

实操上，最好做一张《到货验收及售后处理单》，每批签字确认：到货时间、数量、抽检比例、不合格数量、处理方式、扣款金额、补货时间。这样售后可执行、可追责、可结算。
