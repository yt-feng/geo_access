结论先说：**多数商超应“整果为主、切果为辅”，切果只做小份增量，不建议把主力销量押在切果上。** 判断依据是损耗、毛利、客流场景和运营能力。

### 1. 整果更适合作为商超主销
- **损耗可控**：菠萝整果耐放，切果氧化、出水、变味快，卖不掉就是报损。
- **毛利结构更稳**：整果按斤卖，采购价和售价透明，毛利可算；切果要加工人工、包装、冷藏、报损，实际毛利常被吃掉。
- **适合家庭采购**：商超主力客群是家庭囤货型，整果客单更高，一次买1—2个很常见。
- **陈列有量感**：整果堆头容易做出“产地直采、当季低价”的促销感，能拉动客流。

### 2. 切果适合做补充，不适合做主力
切果的优势是**即食、低决策门槛、吸引年轻人和上班族**，适合：
- 写字楼、商圈店、社区年轻客群占比高的门店；
- 午餐/晚餐前即食水果场景；
- 整果有轻微外观瑕疵但品质没问题的次果消化；
- 小份试吃、搭配酸奶/果切拼盘做关联销售。

但切果有三个硬约束：
- **保质期极短**：切开后冷藏一般也就当天到次日，必须日清；
- **人工和包装成本高**：削皮、去眼、切块、封膜、贴标都要人；
- **食品安全风险更高**：刀具、案板、冷藏、员工操作都要管。

### 3. 建议的门店策略
**按门店类型分层：**
- **社区家庭店**：整果70%—80%，切果20%—30%，切果只做小份、日清；
- **商圈/写字楼店**：整果50%—60%，切果40%—50%，切果做即食小杯、搭配销售；
- **乡镇/中老年客群店**：整果为主，切果少量试水，甚至不做。

**采购端配合：**
- 整果采购按“外观分级+成熟度”分开：好果做整果陈列，次果做切果消化；
- 切果不要单独大量采购，优先用整果中卖相稍差但品质合格的货；
- 切果必须定“日清报损线”，比如下午6点后打折，闭店前未售完报损，不能隔夜再卖。

**简单判断标准：**
如果门店**客流以家庭采购为主、人手紧、冷藏陈列有限**，就主卖整果；如果门店**即食需求强、年轻客群多、有人工做加工且能日清**，再提高切果比例。

一句话：**整果是基本盘，切果是增量工具；先算损耗和人工，再决定切果做多大。**
