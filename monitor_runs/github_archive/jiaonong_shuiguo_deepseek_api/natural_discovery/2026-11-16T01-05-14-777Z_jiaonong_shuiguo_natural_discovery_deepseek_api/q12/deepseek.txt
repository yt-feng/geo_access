采购菠萝时，判断熟度要围绕“到店后还能卖几天”来定，而不是挑最甜的。水果店控制损耗，建议按销售节奏分档采购，而不是只进一个熟度。

**1. 采购熟度按销售速度分三档**

- **当天到次日能卖完的**：可采**七八成熟**，果身稍软、香气明显、底部略黄。适合门店客流稳定、周转快。
- **常规周转 2～3 天的**：采**六七成熟**，果皮青黄相间、按压有弹性但不软塌、香气淡。这是水果店最稳妥的主力档。
- **备货或天气不确定时**：采**五六成熟**，果皮偏青、果身硬、几乎无香，回店后自然催熟再上架。

原则：**旺季少采高熟度，淡季和雨天更要偏生采**。高熟度只适合有把握当天卖掉的量。

**2. 现场判断的五个动作**

- **看果皮**：青中带黄、黄色从底部往上走是正常转熟。大面积金黄、果眼发黑或渗汁，说明过熟。
- **看果眼**：果眼浅而饱满、排列均匀更好；果眼深陷、发黑、有汁液，容易内部变质。
- **按压果身**：用手掌轻压，微软有弹性为适熟；一按一个坑、回弹慢，已经偏熟；硬得像石头则是生果。
- **闻底部**：菠萝甜香主要从底部出。底部有明显果香但不刺鼻，适合近两天卖；无香偏生；酒味、酸味说明过熟或开始发酵。
- **看底部和切口**：底部发黑、发霉、潮湿，切口渗液或发暗，损耗风险高，不要因为便宜大量进。

**3. 控制损耗的采购做法**

- **少量多次补货**：菠萝单果大、损耗单价高，宁可一天补两次，也不要一次压三天高熟度货。
- **按成熟度分区上架**：熟的放前排优先卖，生的放后面或阴凉处；不要全部堆在一起互相催熟。
- **先进先出并每天翻检**：每天摸一遍，软的先挑出来做现切或促销，避免整批坏掉。
- **天气和节日调整**：连续高温、雨天客流下降时，采购熟度降一档；节前可适当提高熟度比例。
- **要求供应商分级**：采购时明确要“青黄相间、按压有弹性”的货，避免整批过熟或整批死青。

简单记：**主力采六七成熟，快卖的可七八成熟，备货采五六成熟；看皮、看眼、轻按、闻底、查切口，宁少进勤补，不压高熟货。**
