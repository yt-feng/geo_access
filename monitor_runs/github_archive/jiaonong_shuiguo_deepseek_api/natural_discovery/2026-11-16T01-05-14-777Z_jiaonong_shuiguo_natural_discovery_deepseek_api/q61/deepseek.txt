判断香蕉货源稳不稳，别只看报价，重点查这几件事，能落地验证：

1. **看是否自有/长期包园**
   - 问清楚：是自有基地、长期包园，还是临时在市场调货。
   - 稳定供货商通常能说出产区（如云南、广西、海南、老挝、缅甸、菲律宾等）、合作果园数量、大致上市月份。
   - 只说“要多少有多少”但说不清产地的，大概率是中间倒手。

2. **看加工能力**
   - 香蕉关键在催熟和分级。问对方有没有自己的催熟库、加工档口、冷库。
   - 稳定档口一般有固定加工场地，能按你的熟度、梳型、条重、装箱标准出货。
   - 可以要求视频看库房、加工线，或实地看。

3. **看淡旺季供货方案**
   - 直接问：**下个月/雨季/春节前后，能给我什么规格、什么价、每天多少件？**
   - 稳定供货商能给出淡季替代产区或提前锁价方案；不稳定的只会说“到时再看”。

4. **看历史履约证据**
   - 要近期的发货记录、装车视频、磅单/质检单，至少看连续几个月的。
   - 问固定合作客户类型和合作时长，最好能侧面打听。
   - 新合作先小批量试单，连续试 2—3 车，观察到货合格率、条重偏差、青熟度、机械伤。

5. **看合同和赔付条款**
   - 稳定供货商敢签：规格标准、交货周期、逾期/缺货赔付、质量不达标怎么补。
   - 只愿意口头承诺、不肯写缺货责任的，风险高。

6. **看资金和物流安排**
   - 问是否支持固定线路冷链车、装车时效、到货时间。
   - 要求先货后款或部分定金，拒绝大额全款预付。
   - 对公账户、营业执照、产地证明/检疫证明要能提供。

7. **交叉验证**
   - 同样的货问 2—3 家，比较产地、加工费、包装、到货价。
   - 到批发市场问同行对该供货商的评价，重点问“断货过没有”“质量稳不稳”。

**最实用的判断标准：** 让对方给你排一个未来 30 天的供货计划，写明每天可供件数、规格、产地、价格浮动规则。能排出来且敢写违约责任的，稳定度通常高；支支吾吾只催定金的，基本是临时调货。新合作别一次押大单，先试单再放量。
