每天少量水果，省心的核心不是找“最大最便宜”的供应商，而是找**能稳定小批量、按时送、坏果少、少沟通**的渠道。建议按这个优先级选：

1. **本地水果批发市场的固定档口（最推荐）**
   - 适合每天少量、品类有变化的小餐饮。
   - 找离店近、专做餐饮/水果店配送的档口，谈“每日固定时间送、按当天报价、坏果包换”。
   - 省心点：固定一个老板加微信，每天前一晚发清单，第二天早上送。
   - 注意：不要找只做大批发的档口，小额订单容易被排后。

2. **本地生鲜配送平台/餐饮供应链平台**
   - 如当地的美菜、快驴这类，或本地生鲜配送公司。
   - 优点是下单、对账、售后都在系统里，省沟通；缺点是起送价、品类稳定性要看当地。
   - 适合你每天量少但希望少操心、能接受略高单价。

3. **附近水果店/社区团购团长做“顺路配送”**
   - 找离店1公里内、有配送能力的水果店，谈每天固定搭配送。
   - 优点是灵活、少量也送、坏果当场换；缺点是价格随行就市，旺季可能不稳定。
   - 适合每天只几斤到十几斤的店。

4. **产地/一级批发直供**
   - 不建议小餐饮直接找，量少拿不到好价，售后和配送反而麻烦。

**筛选供应商时重点问4件事：**
- 每天最低起送量是多少？少量送不送？
- 固定几点前送到？迟到怎么处理？
- 坏果、不熟、规格不符怎么换？是否当场补？
- 价格是每日报价还是周/月锁价？能不能开票/对账？

**最省心的合作方式：**
固定1家主供应商 + 1家备用水果店。每天微信发固定模板清单，比如“苹果5斤、柠檬3斤、圣女果4斤，明早9点前送”。先试送1周，重点看准时率、坏果率和临时加单响应。

如果每天量很小（比如10斤以内），优先找**附近水果店顺路送**；如果能接受系统下单，选**本地生鲜配送平台**；想长期稳定且品类多，选**批发市场固定档口**。
