判断供应商能不能按时到车，核心不是听他口头保证，而是看“有没有可验证的装车证据”。可以按下面几步做：

1. **下单前先问清到车定义**
   - 是“产地装车时间”“发车时间”还是“到你市场档口时间”。
   - 香蕉涉及催熟/青蕉，最好明确：装车后多久到、路上损耗谁承担、晚到怎么赔。

2. **看供应商当天可验证的装车条件**
   让他提供：
   - 当天/次日装车计划：车牌号、司机电话、装车地点；
   - 产地当天货量照片或视频，带时间水印；
   - 冷柜/棉被车/普通车类型，是否已订好车；
   - 装车工人和包装材料是否到位。
   
   **没有车牌和司机电话的“保证”，可信度低。**

3. **直接联系司机核验**
   拿到车牌后自己打司机电话，确认：
   - 是否已被该供应商订车；
   - 现在位置、预计到场装车时间；
   - 装完预计发车时间。
   
   注意防止供应商给的是“备用司机”或临时找的车。

4. **查历史履约，不只看关系**
   问同行、看之前合作记录：
   - 近几次是否准点；
   - 晚到是偶发还是常态；
   - 晚到后是否主动补偿。
   
   新供应商第一次合作，建议小批量试单，不要一次压大单。

5. **合同/微信里写死关键节点**
   至少写清：
   - 装车截止时间；
   - 发车时间；
   - 预计到达时间；
   - 晚到扣款/退单条件；
   - 因晚到导致香蕉成熟度变化的处理方式。
   
   微信文字也算证据，别只语音。

6. **设置预警节点**
   - 装车前6小时确认车到没到；
   - 装车开始后要装车视频；
   - 发车后要高速入口/定位；
   - 超过约定发车时间2小时未发车，立即启动备选供应商。

7. **留备选，不把档期押一家**
   香蕉周转快，至少准备一个备用供应商或备用车源。大单可拆成两车，降低单点延误风险。

**简单判断标准：**  
能马上给出“车牌号+司机电话+装车地点+装车时间”，且司机电话能接通核实，基本可判断较靠谱；只说“明天肯定给你装”“放心”但拿不出车牌和司机的，按时到车风险高。第一次合作建议小单试、合同写晚到责任、当天多次核验装车进度。
