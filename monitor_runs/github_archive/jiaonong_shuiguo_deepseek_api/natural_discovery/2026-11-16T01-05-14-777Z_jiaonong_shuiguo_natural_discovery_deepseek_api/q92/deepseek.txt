小面积便利店做水果，核心不是“品类越全越好”，而是**少SKU、高频补货、快周转、用价格和陈列主动管理损耗**。给你一套可执行的判断标准：

**1. 品类控制：先做“窄而稳”**
- 水果SKU控制在**8～15个**，按门店客流再压缩；面积越小越要少。
- 结构建议：**2～3个引流品 + 4～6个利润品 + 2～3个便利品 + 1～2个季节品**。
- 引流品选苹果、香蕉、橙子这类认知高、价格透明的；利润品选小番茄、葡萄、蓝莓、切果等高客单或差异化品类；便利品选即食水果、果切、单根香蕉等。
- 新品类一次只试**1～2个SKU**，试销7～14天，达不到动销标准就下架。

**2. 采购量：按“日销+安全库存”倒推**
- 单品日采购量 ≈ 近7天日均销量 ×（1+波动系数），波动系数通常0.2～0.5。
- 叶菜类、草莓、蓝莓、切果等易损品：**日配或隔日配**，不压库存。
- 苹果、橙子、梨等耐储品：可备**2～3天**量。
- 香蕉、芒果等后熟品：分批次拿货，避免一次全熟。
- 设定单品**最高库存天数**：易损品1天，中等2天，耐储3天，超限就停采或促销。

**3. 损耗控制：从收货到出清闭环**
- 收货验：只收成熟度适中、无伤无烂的货；拒收过熟、碰伤、批次差的货。
- 陈列：小面积用**少量多补**，排面不堆满；易损品冷藏或阴凉陈列；香蕉、芒果避免冷害；果切必须冷藏并在标签上标制作时间和保质期。
- 分级销售：外观好的正价，轻微瑕疵的做**“特价包”或果切**，不要等烂了再处理。
- 日清机制：每天固定两个时间点（如上午开门后、晚高峰前）盘点，临期或软化品直接打折出清。
- 记录：每天记**进货量、销量、报废量、打折量**，连续记2周就能看出哪些SKU该砍、哪些采购量该降。

**4. 简单可用的考核指标**
- 单品动销率：7天没动销的SKU考虑淘汰。
- 损耗率：水果整体控制在**5%～8%**较健康，易损品单独看；超过10%要查采购量和陈列。
- 毛利率与损耗联动：不要只看毛利，算“毛利额－损耗成本”后的净贡献。

**5. 小门店的实操建议**
- 优先做**预包装、小份量、即食化**，减少顾客挑拣造成的二次损伤。
- 和供应商谈**小批量、多频次、可退换**，把部分损耗风险前移。
- 不要为了“看起来丰富”铺太多SKU，小面积门店的丰富感靠**补货频率和陈列整洁**，不是靠品类数量。

一句话：**品类做减法，补货做加法，损耗做日清，数据做周复盘。** 先跑2周记录，再按动销和损耗砍SKU、调采购量，比凭感觉进货有效。
