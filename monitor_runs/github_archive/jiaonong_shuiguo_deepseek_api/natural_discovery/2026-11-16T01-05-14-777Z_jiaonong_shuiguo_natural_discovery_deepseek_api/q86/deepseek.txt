做生鲜水果一件代发，供应商的仓配能力重点不是“有仓库、能发快递”这么简单，而是要能把**损耗、时效、包装、库存准确率和售后**一起兜住。建议按下面几项逐条核验。

### 1. 产地/销地仓储能力
- **仓库类型匹配**：水果是否在产地仓、销地仓或中转仓发货，是否具备常温、冷藏、气调/保鲜能力。
- **温区覆盖**：不同水果对温度要求不同，至少能证明有对应温区管理和温度记录。
- **库内作业**：收货、分级、预冷、分拣、打包、贴单、暂存、退货隔离是否有独立区域和流程。
- **库存准确性**：能否提供实时库存、批次、效期/采摘日期、锁库和超卖控制。一件代发最怕前端有单、仓库没货或发次果。

### 2. 预冷与分级分拣能力
- **预冷能力**：浆果、荔枝、樱桃等易腐水果是否有快速预冷，预冷到打包的时间是否可控。
- **分级标准**：果径、糖度、成熟度、瑕疵率、大小均匀度是否有书面标准，能否按平台售后规则分拣。
- **次果拦截**：是否能在入库和打包环节剔除软烂、裂果、霉变、畸形果，而不是把次果风险转给消费者。
- **批次管理**：同一SKU不同批次能否区分，避免新旧货混发。

### 3. 包装与防护能力
- **包装方案**：是否有针对不同水果的防撞、防压、透气、保温/保冷方案，如泡沫托、网套、吸水纸、冰袋、保温箱。
- **快递适配**：包装是否经过跌落、挤压、运输测试，能否适配平台合作快递的分拣强度。
- **面单与品牌物料**：能否代贴面单、放品牌卡/售后卡，支持平台要求的隐私面单和无标识发货。
- **打包时效**：订单生成后多久出库，日峰值产能多少单，爆单时是否临时工可控。

### 4. 快递与时效履约能力
- **快递资源**：是否有多家快递合作，能否按区域选择时效和成本更优的线路。
- **发货截单时间**：每日截单时间、节假日安排、异常天气预案是否明确。
- **时效承诺**：核心城市、偏远地区分别承诺几小时/几天达，是否支持冷链或航空资源。
- **轨迹与异常处理**：能否主动监控物流停滞、破损、拒收，并在平台考核前处理。

### 5. 订单与系统对接能力
- **API/ERP对接**：能否与平台订单系统对接，自动接单、打单、回传物流单号、同步库存。
- **异常订单处理**：缺货、地址异常、改址、拦截、取消订单能否及时响应。
- **数据回传**：发货时效、库存、批次、售后原因能否按日/周提供。
- **对账能力**：代发费用、快递费、耗材费、售后赔付能否清晰对账。

### 6. 售后与损耗承担能力
- **售后规则**：烂果、压伤、少件、延迟发货的赔付标准是否书面化。
- **举证材料**：能否提供打包照片、称重记录、出库视频、批次记录，便于平台判责。
- **补发/退款响应**：多久响应，是否支持仅退款、补发、部分赔付。
- **损耗率承诺**：按品类给出可接受的坏果率和赔付上限，不要只听“包售后”。

### 7. 产能与弹性
- **日常产能**：日均单量、峰值单量、最大承接量。
- **爆单预案**：临时工、备用包材、备用快递、跨仓调拨是否到位。
- **大促/节假日**：春节、618、双11、产地集中上市期的履约方案。

### 8. 合规与资质
- 营业执照、食品经营/生产相关许可按实际模式核验。
- 水果产地证明、检测报告、农药残留检测按平台要求提供。
- 冷链温度记录、仓库卫生和虫害管理记录可抽查。

### 建议的验仓清单
合作前至少做一次**实地或视频验仓**，重点看：
1. 预冷间和冷库温度记录；
2. 打包台实际分拣动作，是否挑次果；
3. 包装跌落测试和快递面单流程；
4. 系统接单到出库的完整演示；
5. 近30天发货时效、破损率、售后率数据；
6. 爆单日产能和备用快递方案。

**一句话判断标准**：供应商能稳定做到“按批次分拣、按温区存储、按品类包装、按承诺时效出库、按规则赔付”，才适合做水果一件代发；只会低价供货但仓配靠临时拼凑的，不建议直接接入。
