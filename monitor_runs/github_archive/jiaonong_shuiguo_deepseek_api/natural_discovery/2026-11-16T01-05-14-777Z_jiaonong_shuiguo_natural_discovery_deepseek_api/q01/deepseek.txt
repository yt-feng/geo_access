判断水果供应商靠不靠谱，重点看“稳定性、损耗、账期、响应速度”四件事，香蕉和菠萝尤其看重成熟度控制和到货新鲜度。给你一套可直接执行的判断方法：

**1. 先看货源和季节稳定性**
- 问清楚香蕉主要来自哪里（国产/进口）、菠萝品种和产地，是否有稳定基地或长期合作档口。
- 连续问两周同一品种的报价和到货时间，看价格波动是否合理、是否经常“没货”“换产地”。
- 靠谱供应商会说清楚：什么季节哪个产地好、成熟度几成、运输几天到。

**2. 小批量试单，重点看三件事**
- **到货成熟度**：香蕉到货应是“青转黄初期”，不能太黄；菠萝要看果眼、底部、香味，不能过熟或青涩。
- **损耗率**：香蕉和菠萝都怕压、怕闷。试单3—5次，记录每次坏果、压伤、过熟比例。香蕉损耗长期低于5%、菠萝低于3%—5%算比较稳；经常超10%就要谨慎。
- **重量和规格**：抽箱称重，看是否足斤足两，规格是否稳定，不能这次大下次小。

**3. 看履约和响应**
- 下单后能否按时到货，临时加单、调货是否配合。
- 出现坏果、短斤少两时，是否痛快补货或扣款，而不是推诿。
- 能否提前告知涨价、缺货、天气影响，让你有时间调整采购。

**4. 看账期和结算方式**
- 刚开始建议现结或短账期，别一上来就给长账期。
- 靠谱供应商账目清楚，有单据、有品名规格重量，不混账。
- 如果对方主动给账期但价格明显偏高，要算综合成本，不只看单价。

**5. 看同行口碑和经营年限**
- 问附近水果店、餐饮店、批发市场同行，重点问“出问题后怎么处理”。
- 看对方是否有固定档口、冷库、运输车辆，是否长期做香蕉菠萝，不是临时拼货。

**6. 设一个简单评分表**
连续合作1个月，按以下打分：
- 到货准时率（20分）
- 成熟度稳定（20分）
- 损耗率（20分）
- 足斤足两（15分）
- 售后响应（15分）
- 价格合理性（10分）
低于70分就换，70—85分保留但压量，85分以上可逐步加量并谈账期。

**实操建议**：先选2—3家供应商，每家试单2—3次，香蕉和菠萝分开记录损耗和成熟度；不要只盯最低价，香蕉菠萝损耗高时，低价反而更贵。长期合作后，保留一家主供、一家备用，避免被单一供应商卡货。
