直接结论：**做茶饮店，选菠萝原料时“甜度”和“出汁率”不是二选一，而是要先看你的产品结构。多数茶饮店应优先保证“甜度稳定、风味够”，再要求“出汁率达标”；如果做鲜果茶、菠萝汁饮用量大，则出汁率权重明显上升。**

可执行判断如下：

1. **做鲜果茶、菠萝果肉茶**
   - **优先看甜度稳定和果肉品质**。
   - 甜度不够会导致每杯加糖量波动，风味不稳定；果肉发酸、纤维粗还会影响口感。
   - 出汁率只要达到正常水平即可，因为你主要用果肉，不是榨汁。

2. **做菠萝汁、菠萝冰茶、气泡菠萝饮**
   - **优先看出汁率**。
   - 出汁率低会直接推高单杯原料成本，也增加备料时间。
   - 但甜度仍需设最低标准，否则糖浆用量和口味稳定性会失控。

3. **做连锁或多店菜单**
   - **先定甜度标准，再定出汁率门槛**。
   - 甜度决定产品口味一致性，出汁率决定成本和出品效率。
   - 建议采购标准写成两项硬指标，而不是只写“新鲜香甜”。

4. **成本核算方法**
   - 用“每杯可用果肉/果汁成本”判断，不只看每斤采购价。
   - 公式：**单杯原料成本 = 采购单价 ÷ 每斤出汁率或可用果肉率 ÷ 每斤可做杯数对应的用量**
   - 甜度低但出汁率高的原料，可能因加糖和调整配方反而更贵。

5. **建议采购优先级**
   - 鲜果茶为主：**甜度与风味 ＞ 果肉率 ＞ 出汁率**
   - 果汁饮为主：**出汁率 ＞ 甜度稳定性 ＞ 采购价**
   - 综合菜单：**甜度稳定 + 出汁率达标 + 果肉率合格**三项同时设门槛。

一句话：**甜度决定口味下限和稳定性，出汁率决定成本和效率；茶饮店应先按产品用途定权重，再用“单杯可用成本”做最终选择。**
