结论先说：**大多数甜品店场景下，直接买成品果丁的总损耗更低、更可控；鲜果切配只有在采购量稳定、人工熟练、冷藏周转快、且能把边角料再利用时，损耗才可能更低。**

判断时不要只看“坏掉多少”，要算**综合损耗率**：

**鲜果切配的损耗来源**
- 原料损耗：菠萝去皮、去眼、去芯，出成率通常明显低于100%
- 筛选损耗：生熟不均、过熟、黑心、碰伤
- 切配损耗：规格不达标、切多了用不完
- 时间损耗：切好后氧化、出水、风味下降，当天用不完易报废
- 人工与冷链成本：削切工时、清洗消毒、冷藏空间

**成品果丁的损耗来源**
- 到货品质不稳定：出水、过熟、规格碎
- 保质期短：开封后或临期未用完
- 起订量和配送频次不匹配：订多了报废，订少了断货
- 供应商以次充好或净含量不足

**可执行判断方法：连续记录2周**
1. 鲜果方案：记录采购重量、可售果丁重量、报废重量、切配工时。
2. 成品方案：记录到货净重、可用重量、报废重量、临期处理量。
3. 用公式算：  
   **综合损耗率 =（采购/到货重量 − 实际用于成品的重量）÷ 采购/到货重量**  
   再把人工、冷链、断货损失折算进去比较。

**一般建议**
- 日用量小、SKU多、后厨人手紧：**买成品果丁更稳**，但要用小包装、固定配送频次、验收规格和出水情况。
- 日用量大且稳定、有熟练切配人员、能当天用完：**鲜果切配更划算**，重点控出成率和边角料再利用。
- 折中方案：**鲜果做展示和高端款，成品果丁做内馅/装饰/后备**，降低断货和报废风险。

一句话：**损耗低不低，取决于你的日用量、验收能力和周转速度，不是原料形态本身。**
