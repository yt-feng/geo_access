小批量试单的核心不是“先买一点试试”，而是用最低成本验证四件事：**货能不能稳定达标、价格和费用是否真实、交付是否可靠、出问题对方是否负责**。建议按下面设计。

## 1. 先定试单目标
第一次合作建议只验证，不追求毛利。试单要回答：
- 品质是否达到你下游客户能接受的标准
- 到货损耗率、规格合格率是否在可接受范围
- 报价是否含包装、装卸、短途运输等费用
- 约定时间内能否稳定到货
- 出现烂果、短斤少两、规格不符时，对方如何处理

## 2. 试单规模
不要按“整车”试，按**1～3天销量**或**一个最小起订量**试。  
经验上可控制在：
- 单品种：先试1～2个单品，不要一次铺很多SKU
- 数量：够覆盖你2～3个核心客户或1～2天正常销量
- 金额：控制在你可承受的完全损失范围内，避免因试单占用大量现金
- 频次：同一供应商至少连续试2～3批，不要只看第一批

## 3. 试单品种选择
优先选：
- 你销量稳定、容易判断品质的常规品
- 耐储运、损耗相对可控的品种
- 下游客户明确、能快速消化的品种

不要第一次就试：
- 高损耗、强季节性、价格波动大的稀缺品
- 你还没有明确买家的新品种
- 规格标准很难统一的散货

## 4. 合同或订单里必须写清
即使小批量，也要有书面订单或微信确认留痕，至少写清：
- 品种、产地、等级、规格、单果重量/个数、成熟度
- 单价、包装费、装卸费、运费、是否含税
- 交货时间、地点、验收时限
- 数量允许误差，比如±3%～5%
- 损耗和短斤少两的处理方式
- 品质不合格的退换、补货或扣款规则
- 付款方式：建议**先小比例定金，验收后付尾款**；第一次不要全款预付

## 5. 验收设计
到货后按固定流程验：
- 称重：抽3～5箱/件称重，核对净重
- 规格：随机抽检，记录不合格比例
- 品质：看成熟度、机械伤、腐烂、冻伤、病虫害
- 包装：是否挤压、潮湿、破损
- 拍照留证：到货开箱、称重、坏果、标签、车牌/物流单

建议设定明确红线，例如：
- 规格合格率低于90%要求补差或扣款
- 腐烂率超过3%～5%按比例扣款或退货
- 净重短缺超过约定误差按短缺金额扣款

具体比例可按品种和你下游标准调整，但必须在试单前写清。

## 6. 付款和风险控制
- 第一次合作不建议大额预付
- 可先做一单“现款现货、验收后付款”
- 保留对方营业执照、负责人身份证/手机号、收款账户信息
- 尽量公对公转账，备注品种和订单号
- 不要因为对方报价低就跳过验收

## 7. 试单后评估
每批试单记录：
- 实际到货率、规格合格率、损耗率
- 实际综合成本，不只看到货价
- 到货准时率
- 售后响应速度和处理结果
- 下游客户投诉情况

连续2～3批稳定后，再逐步放量。放量节奏建议：**试单量→3～5倍试单量→正常批量**，不要一次跳到大单。

## 8. 一个可执行模板
第一单可以这样设计：
- 单品：1～2个常规畅销品
- 数量：1～2天销量或最小起订量
- 金额：控制在可承受损失范围内
- 价格：要求报“到仓综合价”，列明所有费用
- 付款：小额定金+验收后尾款，或现款现货
- 验收：到货2小时内抽检称重、拍照，异常当天书面反馈
- 售后：明确坏果扣款、补货或退货规则
- 复购条件：连续2批合格率达标、售后及时，再谈放量和账期

最关键的是：**试单前把品质标准、费用构成、验收规则和售后责任写清楚，试单中留证据，试单后按数据决定是否放量。**
