商超会员日水果活动，供应商需要提前配合的准备，按时间顺序和品类特性拆开看，重点抓“货、价、质、陈列、履约”五件事。

**一、活动前7–10天：确认活动机制与备货计划**
- 与商超确认：会员日时间、活动单品/品类、促销价与让利分担比例、限量规则、线上线下是否同步、是否有堆头/端架/试吃位。
- 按商超给的预估销量做备货，水果要留损耗余量：叶菜类、浆果类、易软果（桃、杏、葡萄）备货系数通常高于耐储果（苹果、梨、柑橘）。具体系数按历史会员日动销和损耗率定，不要凭经验拍。
- 锁定货源和产地档期，确认活动期能连续供货，避免“首日爆量、次日断货”。

**二、活动前5–7天：价格与合同落定**
- 报价单、促销让利、费用承担（堆头费、试吃损耗、广告费）书面确认，避免活动当天扯皮。
- 确认结算价是否含税、含运费、含损耗补差；明确促销价执行区间和调价权限。
- 如做“会员专享价”，确认商超系统改价时间，供应商配合提供商品条码、规格、产地信息。

**三、活动前3–5天：品质标准与验收口径**
- 与商超质检/生鲜主管对齐验收标准：果径、糖度、成熟度、色泽、允许瑕疵率、包装规格。
- 明确“到店成熟度”：会员日走量快，可适当提高成熟度，但要按门店销售速度分批次到货，避免集中到店后熟过头。
- 约定不合格品处理方式：拒收、折价、换货的时限和责任人。

**四、活动前2–3天：到货与仓配安排**
- 确认配送频次和到店时间窗，会员日建议“活动前夜+活动当日早”两批到货，叶菜和浆果类尽量当日早到。
- 确认商超收货口人力、卸货预约、托盘/周转筐回收方式。
- 冷链品类确认全程温控和到店温度记录，避免路上捂坏。

**五、活动前1–2天：陈列与物料配合**
- 提供陈列建议和样品：堆头怎么码、端架怎么摆、哪些单品做组合装。
- 配合试吃：提供试吃果、切配标准、补货频次；试吃损耗谁承担提前写清。
- 提供价签信息、产地故事/卖点物料（如商超允许），以及导购/理货人员安排。

**六、活动当日：现场履约**
- 安排理货/导购驻店或巡店，重点盯：补货、挑拣残次、翻堆、试吃补台。
- 建立快速响应：断货2小时内能否补、品质投诉当场换货。
- 记录实际动销和损耗，作为结算和下次备货依据。

**七、活动后：复盘与结算**
- 48小时内完成对账：实际到货量、销量、退货/损耗、费用扣减。
- 复盘单品动销排名、断货单品、品质投诉，形成下次会员日备货清单。

**最容易出问题的三个点，建议重点盯：**
1. 只谈促销价没谈损耗承担，活动后对账扯皮；
2. 备货按平日量放大，叶菜浆果到店后卖不完烂在堆头；
3. 验收标准活动前没对齐，到店被拒收或折价，活动当天断档。
