连锁商超长期水果供应商招标，评分标准建议按“质量安全优先、供应稳定兜底、成本合理比较、服务与合规拉开差距”来设计。总分100分，可参考以下结构（按品类调整权重）：

**一、质量与食品安全 30–35分（权重最高）**
- 检测能力与报告：农残/重金属自检或第三方检测频次、报告可追溯性（10分）
- 认证与体系：GAP、ISO22000/HACCP、绿色/有机认证等（8分）
- 到货合格率承诺与历史数据：近12个月抽检合格率、损耗率（8分）
- 品控流程：产地预冷、分级包装、冷链温控记录（6–9分）
> 设置“否决项”：重大食品安全事故、虚假检测报告直接废标。

**二、供应保障与履约能力 20–25分**
- 产能/货源稳定性：自有基地或长期合作基地面积、单品年供应量（8分）
- 冷链与物流：冷藏车数量、产地仓/中转仓、到店时效（6分）
- 应急保供方案：灾情/旺季断供预案、替代产地（5分）
- 历史履约：近3年商超/大型渠道供货合同及履约评价（4–6分）

**三、价格与成本 20–25分**
- 报价合理性：不唯低价，设最高限价和成本构成说明（12分）
- 价格机制：是否接受随行就市调价、价格联动公式、锁价周期（6分）
- 账期与结算：接受商超账期、票据合规（4–7分）
> 建议价格分用“基准价法”而非最低价法，防止低价中标后降质。

**四、服务与运营配合 10–15分**
- 订单响应：下单到到货时长、最小起订量、拆零配送（5分）
- 售后：退换货、质量异议处理时限、损耗承担比例（5分）
- 促销与新品：配合档期促销、新品引进能力（3–5分）

**五、企业资质与合规 10分**
- 营业执照、食品经营/生产许可、种植/养殖资质（3分）
- 财务健康度、诉讼与失信记录（3分）
- 社保、环保、用工合规（2分）
- 可持续发展：农残减量、包装可回收等（2分）

**六、长期合作意愿 5–10分**
- 合同年限接受度、专属供应或优先供应承诺
- 联合品牌、产地直采、数字化对接（订单/库存系统）

**关键设置建议：**
1. **分品类差异化**：叶菜类提高冷链和到货时效权重；精品水果提高认证和分级标准权重；大宗单品提高价格和产能权重。
2. **先资格后评分**：资质、检测报告、食品安全承诺书作为资格预审，不占分但一票否决。
3. **样品盲测**：设置10–15分现场样品评分（外观、口感、规格一致性），评委独立打分。
4. **履约保证金与考核挂钩**：中标后按季度考核合格率、到货率，评分标准中明确“考核不合格扣款/退出机制”。
5. **防止围标**：要求提供基地证明、检测原始记录、近6个月流水，必要时实地考察并计入评分。

这样既能把食品安全和稳定供应放在首位，又能避免单纯低价竞争，适合长期供应商筛选。
