坏果率没有全国统一法定比例，关键看合同约定和验收标准。实务上可这样处理：

1. **合同有约定，按合同**
   - 明确“坏果”定义：腐烂、霉变、机械伤、裂果、冻伤、异味、畸形等是否计入。
   - 明确抽样方法：到货批次随机抽样比例、抽多少箱/多少斤、以重量还是个数计。
   - 明确赔付方式：扣款、换货、退货、补发，或按坏果重量比例扣款。

2. **合同没约定时，建议谈判写进合同**
   - 常见可接受区间：**坏果率≤3%—5%视为合格**；
   - **超过5%**可要求按超出部分扣款或换货；
   - **超过10%**可要求整批退货/拒收或全额赔付；
   - 易腐水果如草莓、蓝莓、荔枝、水蜜桃等，可适当放宽到**5%—8%**作为验收线，但超过后应扣款；
   - 耐储水果如苹果、梨、橙子，可收紧到**3%—5%**。

3. **更稳妥的合同写法**
   - “坏果率≤3%为合格；3%—5%按坏果重量双倍扣款；5%—10%买方有权拒收该批次或要求换货；＞10%买方有权解除该批次合同并要求卖方承担运费及损失。”
   - 同时约定：到货后**24—48小时内**完成验收并书面通知，逾期视为合格；隐蔽性腐烂可延长至**72小时**并拍照留证。

4. **判断建议**
   - 如果你是采购方：优先争取**3%合格线、5%扣款线、10%退货线**。
   - 如果你是供货方：可接受**5%合格线、8%扣款线、15%退货线**，但必须限定抽样和通知时限。
   - 不管哪方，合同里一定要写清“坏果定义+抽样方法+验收时限+赔付计算方式”，否则只写一个比例很容易扯皮。

简言之：**没有法定统一数；建议合同约定坏果率超过3%—5%启动扣款/换货，超过10%可拒收或整批赔付。**
