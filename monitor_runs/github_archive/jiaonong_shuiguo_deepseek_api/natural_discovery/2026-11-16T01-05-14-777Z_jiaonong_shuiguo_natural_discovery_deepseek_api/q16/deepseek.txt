这要看你的超市更怕“断货”还是更怕“损耗”，香蕉和苹果策略不同，建议分开选。

**香蕉：优先稳定供应商，不建议主要靠本地批发**
- 香蕉是后熟水果，批次品质波动大，催熟和温控要求高。
- 稳定供应商能提供相对一致的成熟度、固定到货周期和售后；本地批发适合做临时补货。
- 关键条件：到货成熟度可控（没黄透）、能按周固定配送、坏果可换。
- 操作上：主力用1家稳定供应商，本地批发只在周末或突发缺货时补。

**苹果：可以本地批发为主，但要有稳定备选**
- 苹果耐储、标准化程度高，本地批发更容易比价和看货。
- 本地批发适合小批量、多品种试销，减少压货。
- 但本地批发品质和供应不稳定，需固定1家稳定供应商作备选，防止旺季缺货或价格大幅波动。

**判断标准**
1. 香蕉日销量稳定、损耗承受力低 → 稳定供应商。
2. 苹果想先试品种、控制库存 → 本地批发为主。
3. 本地批发能稳定供货、账期和退换条件好 → 可扩大本地比例。
4. 本地批发价格虽低但损耗高、到货不稳 → 综合成本可能更高，选稳定供应商。

**最稳妥的组合**
香蕉：稳定供应商为主 + 本地批发补货。  
苹果：本地批发试销 + 稳定供应商兜底。  
先各试2–4周，记录到货合格率、损耗率、缺货次数和实际毛利，再调整比例。
