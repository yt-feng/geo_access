大型超市的水果供应商，核心能力可以拆成两条线：**食品安全合规与过程控制**、**物流与冷链履约**。下面按“必须具备 / 加分项”给出可执行清单。

## 一、食品安全能力（必须具备）

1. **主体资质与产品合规**
   - 营业执照、食品经营/生产相关许可齐全；种植/养殖端有产地证明或基地备案。
   - 每批次可提供**承诺达标合格证/检测报告**；农残检测项目覆盖超市验收标准。
   - 进口水果具备海关入境货物检验检疫证明、报关单等。

2. **农残与污染物控制**
   - 有供应商准入检测和**批次抽检**机制，能追溯检测报告到批次。
   - 对高风险品类（叶菜、草莓、葡萄等）加密检测；有超标召回和隔离流程。

3. **溯源体系**
   - 能做到**产地—批次—收货—门店**可追溯，至少保留进货台账、检测记录、发货记录。
   - 包装或周转箱有批次标识，支持超市扫码追溯。

4. **仓储与加工卫生**
   - 分拣、包装区域防虫防鼠、清洁消毒、人员健康证和更衣洗手制度。
   - 生熟/成品半成品分离，破损果、腐烂果隔离处理，避免交叉污染。

5. **冷链食品安全**
   - 不同水果按温区储存运输：一般冷藏0–8℃、部分热带水果10–15℃、冷冻品-18℃以下。
   - 冷藏车/冷库有**温度记录仪和异常报警**，能提供全程温度曲线。

6. **召回与客诉处理**
   - 有食品安全事件应急预案、批次召回流程、留样制度。
   - 能配合超市做供应商审核、飞行检查、第三方检测。

## 二、物流与履约能力（必须具备）

1. **冷链运输能力**
   - 自有或稳定合作的冷藏车、保温箱、冰袋方案；车辆有温控记录和消毒记录。
   - 能按超市要求做**多温区配送**，避免水果与冷冻品混装导致冻伤。

2. **仓储与分拣能力**
   - 具备常温/冷藏库、分拣线、称重贴标、按门店订单分货能力。
   - 有先进先出、临期预警、损耗登记和库存盘点机制。

3. **订单履约与时效**
   - 能支持超市的**日配/隔日配**节奏，有固定截单时间、装车时间和到店时间。
   - 节假日、促销高峰期有备用车辆和人员预案，履约率、准时率可考核。

4. **包装与运输防护**
   - 按品类使用透气箱、防压托盘、缓冲材料；易损果单独包装。
   - 运输中防挤压、防日晒、防雨淋，装卸有温度暴露时限控制。

5. **信息化与单据**
   - 能提供送货单、批次号、检测报告、温度记录；支持与超市系统对接订单和库存。
   - 有异常反馈机制：缺货、品质不合格、温度超标时能快速补货或换货。

6. **损耗与品质保障**
   - 有到货验收标准（糖度、硬度、外观、新鲜度），能承担验收不合格的退换货。
   - 有运输损耗率控制目标和理赔机制。

## 三、加分项（大型超市通常更看重）

- **基地直采或订单农业**，产地仓预冷能力；
- **第三方检测合作**和食品安全管理体系认证（如ISO 22000、HACCP）；
- **冷链可视化**：GPS+温度实时监控，异常自动预警；
- **应急保供能力**：极端天气、疫情、节假日保供预案；
- **可持续包装**和农产品质量等级分选能力。

## 四、超市审核时最常卡的点

1. 检测报告不能对应到具体批次；
2. 冷链温度记录缺失或断档；
3. 分拣区卫生和人员健康证不合规；
4. 高峰期准时率不达标；
5. 退货、召回流程只写在纸上，没有演练记录。

**一句话判断标准**：能证明“每一批水果从哪来、检测过什么、全程在什么温度下、出了问题多久能召回和补货”，才算具备大型超市供应商的基本资格。
