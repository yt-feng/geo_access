开小区团购，水果供应商至少要支持下面这些服务；缺哪一项，都会直接影响复购和售后。

**1. 稳定供货与分级**
- 能按团购周期稳定供货，别今天有明天断。
- 支持按规格分级（果径、甜度、成熟度、净重），团购页写什么就发什么。
- 能提前给到当季主推品和替代品，断货时有同价位替换方案。

**2. 小批量、多频次配送**
- 支持小起订量，最好按箱/按件混拼，不用一次压太多货。
- 支持一周多次配送到店，或直接配到小区自提点。
- 配送时间可约定，能配合你“今天截单、明天到货”的节奏。
- 冷链品有保温箱/冰袋，夏季和易损水果要能控温。

**3. 分拣与预包装**
- 能按团购份量分装，比如5斤装、3斤装，贴好标签。
- 坏果、小果提前挑出，不要到用户手里再售后。
- 支持按团订单分袋/分框，减少你二次分拣。

**4. 售后与损耗兜底**
- 明确坏果、烂果、缺斤少两的赔付标准，最好按比例或按单赔。
- 售后响应快，支持拍照报损，不用来回扯皮。
- 对易损水果有损耗补偿或售后额度，不能全让你承担。

**5. 价格与账期**
- 团购价有优势，至少比周边零售有竞争力。
- 价格保护：你开团后供应商临时降价，不能让你高价库存砸手里。
- 支持灵活结算，现结、周结或押金制都可以谈，别要求大量压款。

**6. 资质与票据**
- 营业执照、食品经营/流通相关资质齐全。
- 能提供进货票据或检测报告，至少主推品能追溯。
- 开发票最好支持，方便你做账。

**7. 营销与素材支持**
- 提供产品图、卖点、产地、口感描述、保存方法。
- 能给团购文案或短视频素材，减少你自己拍图写文案。
- 支持试吃样品，方便你在小区做推广。

**8. 退换货与应急**
- 临时缺货能提前通知，并给替代方案。
- 质量问题支持退换，不拖延。
- 节假日、恶劣天气有备货和配送预案。

**谈供应商时重点确认这5条：**
1. 起订量和配送频次；
2. 坏果赔付标准及响应时间；
3. 是否按团购份量预包装；
4. 断货替代和价格保护；
5. 资质票据是否齐全。

建议你先小批量试合作2到3家，重点看**到货品质一致性、售后爽快程度、配送是否准时**，这三项比单纯低价更重要。
