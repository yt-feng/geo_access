对便利店卖菠萝切块，这三项都重要，但优先级建议是：**保质期管理 > 包装 > 配送频次**。更准确地说，核心不是“只盯哪一个”，而是用**配送频次去支撑保质期，用包装去守住保质期**。

### 1. 保质期是第一优先级
菠萝切块属于鲜切水果，高风险点是微生物滋生、氧化变色、出水变味。便利店场景下，顾客对“新鲜”和“安全”的容忍度很低。
- 必须明确：**切块后冷藏保质期通常很短**，应按门店实际工艺和冷链条件设定，不能照搬长保包装水果。
- 要做：**批次标签、切配时间、到期时间、先进先出、临期下架**。
- 判断标准：如果做不到按小时/按天严格管控，先不要扩大销售。

### 2. 包装是第二优先级
包装直接影响氧化、失水、污染和展示效果。
- 建议用**食品级密封盒或覆膜托盘**，冷藏陈列，避免敞口。
- 包装要能标识：**切配日期/时间、保质期、储存条件**。
- 注意：包装不是越密封越好，完全闷湿可能加速霉变；要结合冷藏和周转速度。

### 3. 配送频次是支撑条件
配送频次影响原料新鲜度和门店库存周转，但不是唯一决定因素。
- 如果门店切配：关注**整果到店频次和库存周转**。
- 如果中央厨房配送切块：关注**冷链配送频次、到店温度、在店剩余保质期**。
- 判断标准：配送频次再高，如果门店陈列温度不稳、包装不当、过期不下架，仍然会出问题。

### 可执行建议
1. **先定保质期规则**：切配时间、冷藏温度、最长售卖时限、临期下架规则。
2. **再定包装标准**：密封、冷藏、标签齐全、避免挤压出水。
3. **用配送频次匹配销量**：少量高频配送，减少门店积压；中央厨房切块要保证到店后剩余售卖期充足。
4. **每日检查**：颜色、气味、出水、包装胀气、标签是否完整。
5. **销量小就降频或改整果现切**，不要为了陈列丰富压库存。

一句话：**保质期是底线，包装是保障，配送频次是周转手段；先管住时间和温度，再谈频次。**
