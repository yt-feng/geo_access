判断门店销售规格，建议用“可卖性+陈列效率+损耗”三个维度做快速验收，而不是只看单个果径。

**一、苹果**
1. **看果径分级**：用果径圈/卡尺抽检，按箱随机取20–30个测横径，记录最小、最大、集中在哪个区间。门店常见做法是设“主力规格”和“上下限”，超下限、超上限分开处理。
2. **看单果重**：同规格苹果单果重应相对稳定，轻的偏小或脱水，重的可能过大。
3. **看果形和着色**：大小合格但畸形、偏色、锈斑重的，不宜进正常陈列。
4. **看硬度与新鲜度**：轻压有弹性、无软塌；表皮发皱、果梗干枯的说明失水。
5. **看陈列匹配**：按门店货架和包装袋容量定——散装堆头适合中等偏大且整齐的；预包装要能装袋不挤伤；礼盒装要大小均匀。

**二、橙子**
1. **看横径和单果重**：同样抽检，重点看同一箱内大小是否整齐。橙子大小差异大，顾客挑拣和称重体验会差。
2. **看皮厚与手感**：轻捏有弹性、皮薄紧实为好；皮过厚、手感空软的规格偏大但可食率低。
3. **看瑕疵**：重点看日灼、风疤、油斑、裂口、霉变。大小合格但瑕疵多的，只能降级或做特价。
4. **看成熟度和汁水**：抽样切开或手掂，过轻可能干水；青果比例高的要评估是否适合即食销售。

**三、快速判定标准**
- **整齐度**：同箱80%以上落在门店设定的主力规格区间，才算适合正常陈列。
- **上下限控制**：小于下限的做特价/加工/员工购；大于上限的单独定高价或做礼盒，不要混堆。
- **损耗预估**：抽检中软伤、裂口、霉变比例超过可接受阈值，就要求换货或降级采购。
- **陈列效率**：能稳定堆叠、装袋、称重，顾客拿取不散乱，才算规格适合。
- **包装标注核对**：箱标规格、果径、等级与实物抽检一致，不一致就按实际验收并记录。

**建议落地做法**：采购前和门店约定“主力果径区间+单果重范围+允许瑕疵率”，到货抽检20–30个，记录合格率；合格率不达标的批次不进入正常陈列，先降级处理。这样比凭感觉看大小更可执行。
