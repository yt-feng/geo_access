烘焙、饮品、果切、团餐这几类餐饮客户对菠萝和香蕉的规格要求差别较大，建议按用途分档备货，先小批量试销再放量。

**菠萝**

餐饮客户主要用菠萝做果切、饮品、烘焙馅料和热菜。备货可按净重和成熟度分档：

- **小果**：单果净重约0.8–1.2斤，适合饮品店现切、单杯装饰，也可做整果售卖。
- **中果**：单果净重约1.5–2.5斤，走量最大，适合果切店、团餐、食堂。
- **大果**：单果净重约3斤以上，适合烘焙工厂、中央厨房出肉率优先的场景。

成熟度建议分两档：七成熟（青黄、耐放，适合档口周转和客户二次催熟）和九成熟（金黄、即食，适合饮品店和果切店当天用）。品种上可区分“香水菠萝/金钻”类小果（香气足、单价高）和普通大果（性价比、出肉多），但具体品种名以你当地实际货源为准，不要硬套。

**香蕉**

餐饮客户主要是饮品店、烘焙店、果切和酒店早餐。按催熟度和单根规格分：

- **规格**：单根约120–150g的中等果走量最稳；150–200g大果适合烘焙和酒店；100g以下小果适合饮品店单杯和儿童餐。
- **成熟度**：分3档——青蕉（客户自行催熟，耐运输）、黄熟（七至八成熟，2–3天内可用，适合大多数餐饮）、全熟/芝麻蕉（即食，适合饮品店和当天出品，但损耗高）。
- **包装**：整箱散装适合大客户；小把/单根分装适合饮品店和便利店型客户。

**给档口的实操建议**

1. 先按“菠萝中果+香蕉中等黄熟果”作为主推标准品，覆盖大多数餐饮客户。
2. 再各备一个差异化规格：菠萝小果（饮品/果切）、香蕉青蕉（有催熟能力的客户）。
3. 报价时按“净重/出肉率/成熟度”说清楚，餐饮客户最在意稳定性和损耗，不是单纯低价。
4. 首批每类控制在少量试销，记录客户复购和损耗后再定常备库存。

具体斤两可按你当地批发市场习惯和客户实际反馈微调，以上是通用分档逻辑。
