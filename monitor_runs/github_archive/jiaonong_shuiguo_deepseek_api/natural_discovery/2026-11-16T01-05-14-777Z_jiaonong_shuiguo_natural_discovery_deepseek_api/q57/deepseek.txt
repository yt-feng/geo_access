建议以中央厨房统一收货为主，门店只保留极少数例外。水果虽然易损耗，但连锁餐饮真正要控制的是品质一致性、损耗责任和结算效率，分开收货通常弊大于利。

判断框架如下：

1. **优先中央厨房统一收货的情况**
   - 水果用于门店现制饮品、果切、沙拉、甜品，且有统一配方和克重标准；
   - 门店数量多、分布在同一城市或可冷链配送半径内；
   - 供应商能按标准做分拣、成熟度分级和冷链运输；
   - 你希望统一议价、统一质检、统一损耗核算。

   做法：中央厨房收货时按“到货批次”抽检糖度、硬度、外观、温度、净重；按门店订单做越库或简单加工后配送；门店只做“到店验收”，不再与供应商直接结算。

2. **可以门店分开收货的例外**
   - 门店距离中央厨房远，二次配送会明显增加压伤和成熟度失控，比如跨城、配送超过数小时且无冷链；
   - 水果是整颗陈列型、需要按当日客流灵活补货，且单店销量足以独立成单；
   - 当地有成熟供应商可做到“门店直送+总部统一合同、统一价格、统一质检标准”。

   即便分开收货，也应坚持：总部签框架合同、统一定价和验收标准；门店只验数量、温度和外观；质量索赔归总部采购；供应商考核按门店投诉率汇总。

3. **不建议的做法**
   - 总部谈价、门店各自收货且各自结算：价格失控、责任不清；
   - 中央厨房收大货后无标准地二次分拣：损耗和成熟度问题会被放大；
   - 所有门店都直送但总部不做批次追溯：出现品质问题无法定位。

**可执行结论**：先算一笔账——单店日均水果用量、中央厨房到门店配送时长、冷链温控能力、二次分拣人工成本。若配送能在可控温时间内完成，选中央厨房统一收货；若配送半径过长导致损耗明显上升，则采用“总部统采统价+区域仓/中央厨房越库+门店直收”的混合模式，而不是完全放开门店分开收货。
