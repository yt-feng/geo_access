可以，但通常不是“默认全包”，而是按合作方式和促销档期谈。你可按下面判断和准备：

1. **供应商一般能提供的支持**
   - **陈列支持**：堆头/端架陈列方案、陈列道具、陈列架、包装箱、陈列图，部分供应商可派人到店理货、做陈列。
   - **海报/物料支持**：促销海报、价签、爆炸贴、吊旗、地贴、展架、试吃台围挡等；有的是供应商直接提供成品，有的是给设计稿由超市制作。
   - **试吃支持**：试吃品、试吃台、一次性用品、试吃人员、现场促销员；生鲜水果试吃还涉及切配、保鲜、卫生管理，需确认谁负责。
   - **价格/费用支持**：特价供货、促销折让、陈列费补贴、海报费分摊、试吃损耗补贴、临促人员费用等。

2. **能不能提供，关键看这些条件**
   - 促销档期和销量目标是否够大；
   - 是否签短期促销协议或年度框架协议；
   - 费用是供应商承担、超市承担还是按比例分摊；
   - 试吃人员由谁雇佣、谁办健康证、谁承担食品安全责任；
   - 物料是定制还是通用，制作周期是否来得及；
   - 门店是否允许供应商人员进场、进场手续和着装要求。

3. **建议你直接这样谈**
   - 先给供应商明确促销时间、门店、预估销量、陈列位置和海报档期；
   - 要求对方报“支持清单”：陈列道具、海报物料、试吃品数量、试吃人员、费用分摊；
   - 把支持内容写进促销协议或采购订单附件，避免口头承诺；
   - 试吃环节单独确认食品安全责任和损耗承担；
   - 对供应商支持做复盘：销量、损耗、物料使用率，决定下次是否继续给资源。

**结论：能谈，而且水果促销中供应商提供陈列、海报、试吃支持很常见；但你要把“谁出物、谁出人、谁出钱、谁担责”四项提前定清楚。**
