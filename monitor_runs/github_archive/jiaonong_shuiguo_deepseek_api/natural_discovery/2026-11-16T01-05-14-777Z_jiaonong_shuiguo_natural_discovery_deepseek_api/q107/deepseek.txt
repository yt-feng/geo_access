会，而且香蕉和菠萝的风险点不一样，要分开看。

**结论先说：起订量太高通常会增加损耗风险，尤其香蕉更明显；菠萝相对耐放，但高起订量也会放大资金占用和滞销风险。**

1. **香蕉：高起订量对损耗风险影响最大**
- 香蕉是呼吸跃变型水果，后熟快，对温度、乙烯、挤压敏感。
- 起订量高会导致到货集中、库容和催熟/分拣压力大，容易出现过熟、碰伤、黑斑。
- 若销售速度跟不上，损耗会从“个别坏果”迅速变成“整批集中变质”。
- 建议：按日销量×周转天数下单，起订量尽量贴近1—2个销售周期；优先小批量多频次。

2. **菠萝：相对耐放，但高起订量仍有风险**
- 菠萝整体耐储运性比香蕉好，但高起订量会带来库容占用、成熟度不均、长期存放后黑心/腐烂风险。
- 若一次性到货太多，后批次存放时间拉长，品质下降和滞销风险会上升。
- 建议：按周销量和库容设定上限，分批到货；关注成熟度和存放条件。

3. **判断是否“起订量太高”的可执行标准**
- 起订量对应的可售天数是否超过你的安全库存天数。香蕉建议更短，菠萝可略长。
- 到货后是否有足够冷库/阴凉库容、分拣能力和催熟管理能力。
- 历史损耗率是否随批量增大明显上升；若是，说明起订量已超过运营能力。
- 供应商是否允许拆分批次、混装或调整起订量。

4. **降低风险的做法**
- 和供应商谈“小批量多频次”或分批交付。
- 香蕉优先缩短在库时间，避免与乙烯释放源混放，减少挤压。
- 菠萝控制堆放高度和通风，先进先出。
- 用“销量预测+安全库存+损耗率”反推合理起订量，而不是只看单价优惠。

所以，**会增加损耗风险，香蕉尤其敏感；起订量应受销售速度、库容和周转能力约束，不宜只因为单价低而放大批量。**
