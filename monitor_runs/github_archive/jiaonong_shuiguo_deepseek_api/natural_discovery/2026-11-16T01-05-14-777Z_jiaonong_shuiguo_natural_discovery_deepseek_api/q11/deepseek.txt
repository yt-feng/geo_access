会有影响，但影响大小取决于你怎么卖、卖给谁、怎么定级。

**直接影响：**
- **外观一致性差**：同一箱大小差异明显，顾客挑拣时容易翻乱，损耗增加。
- **定价难统一**：大小混装，按同一价格卖，顾客会挑大的，小的剩下来；按大小分开卖又增加人工。
- **称重销售影响小一些**：如果按斤卖、不按根卖，大小差异对成交影响相对小；但礼盒、精品果切、团购标准装影响大。
- **熟度不一致时问题更大**：大小不同常伴随成熟速度不同，一箱里有的已软、有的还硬，销售期和损耗都会变差。

**可执行建议：**
1. **到货先分拣**：至少分大、中、小三级，或分“直接售卖”和“促销/加工”两档。
2. **分级定价**：大果做精品或礼盒，中果正常散卖，小果做促销、果切、奶昔原料或员工福利。
3. **散卖优先按斤**：避免按根统价导致顾客只挑大的。
4. **陈列时混放要控制比例**：不要一箱直接倒出来，先挑出明显偏小、偏青、有伤的。
5. **采购端要求供应商分级装箱**：同一箱规格尽量接近；如果价格便宜但混装严重，要把分拣人工和损耗算进成本再判断是否划算。
6. **看销售场景**：社区水果店散客对大小容忍度较高；礼盒、企业团购、线上标准份对一致性要求高，混装会明显影响复购和差评。

**判断标准：** 如果分拣后小果占比超过20%—30%，且小果只能降价处理，这箱香蕉的实际毛利会被明显拉低，采购时应压价或换供应商。
