超市采购水果时，建议按“供应商资质＋批次证明＋检测报告＋进货票据”四类材料核验。具体要求会因水果品类、地区监管和超市内控不同而有差异，以下是可执行清单：

**1. 供应商主体资质**
- 营业执照
- 食品经营许可证（或食品生产许可证，视经营形态）
- 供货商为种植合作社/农户直供时，至少留存身份证明、产地证明或合作协议
- 进口水果需额外有：海关入境货物检验检疫证明、报关单等

**2. 批次合格证明/检测报告**
- 承诺达标合格证：食用农产品常见，尤其产地直供；应能对应到品种、批次/产地
- 农药残留检测报告：优先索取与本次进货批次对应的报告；报告应有检测机构、检测项目、检测依据、结论、日期
- 若供应商无法提供批次报告，可要求其提供近期同品种检测报告，并配合超市抽检或快检
- 重点品类（如叶菜、草莓、葡萄、柑橘等高风险或易农残品类）建议提高抽检频次
- 进口水果：入境货物检验检疫证明应随批次留存

**3. 进货凭证**
- 送货单/销售单：写明品名、规格、数量、产地、生产日期或采摘日期、供应商名称、联系方式
- 发票或收据
- 进货台账：超市自身应记录进货日期、名称、规格、数量、生产日期/批号、供货者名称及联系方式、进货凭证编号
- 冷链水果还需温度记录或冷链运输证明

**4. 特殊情形**
- 地理标志、有机、绿色食品等宣称：需对应认证证书，并注意证书在有效期内、产品在认证范围内
- 预包装切果/鲜切水果：按预包装或即食农产品管理，需更完整的生产资质、检验报告和标签信息
- 散装水果：重点保留产地证明、合格证和进货票据，做到可追溯

**可判断的操作建议：**
- 首次合作：索要资质证照并核验有效期、经营范围。
- 每批进货：至少留存“合格证或检测报告＋送货单”，票货对应。
- 报告核对：看检测日期、批次/产地是否对应，检测项目是否覆盖常用农药，结论是否合格。
- 无法提供合格证明的，不建议直接收货；可先快检，合格后再收货并留存记录。
- 建立供应商档案和进货台账，保存期限按当地监管要求执行，通常不少于6个月至2年不等，建议按较长期限保存。
