# 减少坏果与口感不稳定的采购要点

线上水果最怕差评，核心是两件事：**坏果率**和**口感一致性**。采购端能做的比很多人想象的多，关键是把“凭经验收果”变成“按标准收货”。

## 一、先把标准定死，再谈采购

上线前按单品写“收货标准卡”，至少包含：

- **糖度（可溶性固形物）**：明确下限，如西瓜≥11°、芒果≥14°，用折光仪现场抽测，不是听供应商说。
- **硬度/成熟度**：按品种定几成熟采收。线上销售要考虑物流时间，通常选“硬熟采收、到手可食”，而不是收到就已经软熟。
- **果径/单果重**：分档收购，同一链接内规格差异过大会直接导致“大小不一”差评。
- **外观容忍度**：明确哪些瑕疵可收（轻微日灼、小斑点），哪些一票否决（裂口、霉点、软塌、机械伤）。
- **抽检比例**：每批至少抽3%–5%，大货按批次抽，不合格整批退或降级。

## 二、选供应商看“稳定性”，不是看“最好的一批”

- 优先选**有分级线、有冷库、有稳定基地**的供应商，而不是临时收散户货的中间商——散户货口感波动最大。
- 问清楚**同一品种的采收期**，避开“尾期果”（口感下降、易软烂）。
- 要求供应商提供**近几批的糖度记录和坏果率**，能持续给数据的才值得长期合作。
- 小批量试单：先发100–200单测真实到货坏果率和评价，再放量。

## 三、采购节奏与物流匹配

- **按销售速度采购**，宁可少备不要压货。水果在仓里每多放一天，坏果率和口感下降都在增加。
- 控制**采摘到发货的时长**，尤其是浆果、桃、荔枝等呼吸跃变型或易腐品类，超过48小时风险陡增。
- 采购时就把**包装和温控**算进去：易压伤的用蛋托/网套+硬箱，怕闷的留透气孔，夏季走冷链或加冰袋。很多“坏果”其实是包装和运输造成的，不是采购本身。

## 四、到货后做“二次把关”

- 入库快检：糖度抽测、软果挑出、按成熟度分开发货（熟的先发近的，硬的发远的）。
- 建立**批次追溯**：哪批货对应哪些订单，出现集中差评能立刻定位是采购批次问题还是物流问题。
- 对差评做归因：是“坏果”还是“不甜/酸/没味道”，前者查物流和包装，后者查采收成熟度和品种，别混为一谈。

## 五、一个务实建议

**不要追求“零坏果”，要追求“坏果可预期、可赔付”。** 采购标准+试单+批次追溯三件事做到位，坏果率能压到可控范围；同时把售后规则写清楚（坏果拍照即赔），差评率会明显低于只靠压价采购的同行。压价采购往往换来的是混级货和尾期果，短期省的钱远不够补差评的损失。
