判断供应商售后是否稳定，不要只听口头承诺，建议用“事前问清 + 小单试 + 异常场景演练 + 合同约束”四步核验。

**1. 事前把售后规则问成可量化条款**
重点问清楚并让对方书面确认：
- 报损响应时限：例如到货后几小时内受理、多久给处理方案。
- 责任判定：菠萝黑心/水烂、香蕉催熟不均/青硬/过熟，哪些算供应商责任，按到货批次还是抽检比例赔付。
- 赔付方式：补货、折价、退款还是下批抵扣，补货最晚多久到。
- 售后对接人：是否有固定对接人、备用联系人，微信群/电话/系统工单哪个留痕。
- 节假日和旺季是否照常响应，尤其是春节、夏季高温期。

**2. 用小单和异常单试响应**
先下1—2个小批量订单，并故意设置一次可验证的异常沟通：
- 到货后当天反馈一个轻微质量问题或包装问题，看对方多久回复、是否主动给方案。
- 要求对方在约定时间内补发或折价，记录实际完成时间。
- 观察是“销售个人在扛”还是“公司有流程”。只靠一个业务员口头答应的，稳定性通常偏弱。

**3. 用真实场景做压力测试**
菠萝和香蕉售后高发点不同，要分别测：
- 菠萝：到货抽检黑心、水烂、机械伤，反馈后是否按比例赔。
- 香蕉：催熟后出现青硬不熟、催熟不均、过熟软烂，是否认账；是否愿意提供催熟建议或换货。
可要求供应商提供近3个月同类客户售后处理记录（脱敏即可），看平均响应时长和赔付兑现情况。

**4. 合同和日常管理留痕**
- 把响应时限、赔付标准、补货时限写进采购合同或年度框架协议。
- 所有售后走固定群或工单，保留照片、视频、批次号和沟通记录。
- 每月统计一次：投诉次数、平均首次响应时长、实际赔付完成率。连续两次超时或推诿的供应商，降级或替换。

**可执行的判断标准：**
首次响应≤2小时、给出方案≤24小时、补货≤48小时且能连续执行2—3次，才算售后响应较稳定。若每次都要催、责任总往采购方推、赔付靠“下次再说”，即使价格低也不建议作为主供。
