1. **开发票：必须支持**
   - 企业福利采购通常需要报销、入账和税前扣除，供应商应能开具合规发票。
   - 优先确认：能否开**增值税专用发票**（若企业可抵扣）、发票品目是否与“水果礼盒/农副产品”一致、是否支持拆分开票、发票抬头和税号修改是否方便。
   - 注意：水果属于农产品，部分小供应商可能只能开普票或由税务机关代开，需提前确认，避免影响财务入账。

2. **定制包装：建议支持，按福利场景决定程度**
   - 企业福利礼盒通常有品牌露出、节日问候、员工关怀等需求，定制包装能提升体验。
   - 需明确定制范围：LOGO印刷、腰封/贴纸、贺卡、外箱尺寸、是否分装到人、是否印企业名称和祝福语。
   - 确认起订量、打样费、打样周期、定制包装是否额外收费、改版是否加价，以及定制后是否影响退换货。

3. **采购执行建议**
   - 供应商准入表中直接列明：发票类型、开票时效、包装定制能力、起订量、打样周期、报价是否含定制费。
   - 合同写明：发票不合规的违约责任、定制包装验收标准、交付时间和破损补发规则。
   - 若供应商不能开专票但价格明显更低，需让财务确认是否可接受普票入账，再决定是否采购。

结论：**开发票是硬性门槛，定制包装是福利采购的常见加分项，建议至少支持LOGO/贺卡类轻定制；两者都应在合同中明确。**
