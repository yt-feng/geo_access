要支持，但必须有条件、有边界地支持，不能无条件开放成“随叫随到的小单”。

**判断结论：**
即时零售卖水果，供应商应支持小批量高频补货，尤其对高周转、易损耗、强时效的品类。但应做成“分层补货机制”，而不是所有SKU、所有门店都一视同仁。

**为什么应该支持：**
1. **水果损耗高、保质期短**：一次压货过多，门店和平台都承担损耗，小批量高频更贴近真实动销。
2. **即时零售订单波动大**：天气、促销、时段都会造成需求突增，高频补货能减少缺货和临时断供。
3. **提升周转和现金效率**：少批量多批次可降低库存占用，供应商也能根据实际销售安排采配。
4. **平台履约要求高**：缺货、品质下降会直接影响评分和复购，供应商补货能力是合作门槛之一。

**但不能无条件支持，建议设边界：**
- **按SKU分层**：高频刚需、高动销单品支持每日甚至一日多次补货；低频、长尾、礼盒类走批量补货。
- **设最小起订量/最小补货单位**：比如按周转箱、按门店组合、按线路合并下单，避免单店单件配送。
- **设补货窗口和截单时间**：固定波次补货，不是随时下单随时送。
- **区域仓/前置仓协同**：供应商可把货放在平台前置仓或区域共享仓，由仓配做高频小批量，而不是从远仓直发。
- **阶梯价或补货服务费**：小批量高频的物流成本更高，可通过阶梯定价、合并配送、达到一定频次返利来平衡。
- **考核补货满足率和时效**：约定缺货率、补货响应时间、品质合格率，避免“支持高频”变成“频繁小单拖垮履约”。

**一句话建议：**
支持，但用“品类分层+固定波次+最小补货量+前置仓协同+阶梯成本”的方式支持。对高动销水果做高频小批量，对低动销品类做批量补货，既保履约又控成本。
