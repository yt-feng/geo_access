如果只能选一个核心指标，应该优先关注**切果损耗**，而不是甜度、大小或外观。原因是超市卖菠萝的主要利润风险在损耗，不在单果看起来好不好。

具体判断顺序可以这样排：

1. **切果损耗优先**
   - 菠萝是去皮去眼损耗很高的水果，成品率低会直接吃掉毛利。
   - 重点关注：去皮去眼后出肉率、切果废弃比例、临期切果报损。
   - 可执行指标：每批抽切2—3个，记录“毛重→净果重”，算出肉率；出肉率明显偏低的批次要减少订货或改促销。

2. **甜度第二**
   - 甜度影响复购和试吃转化，但甜度不能靠外观完全判断，最好用糖度计抽测。
   - 可执行：到货抽测可食部分糖度，设一个门店最低可接受线；低于线的批次不主推，做试吃或加工成果切。

3. **外观第三**
   - 外观决定顾客第一眼购买意愿，但超市更应关注“可售外观”而不是漂亮。
   - 看：果眼深浅、表皮损伤、黑心风险、成熟度是否适合当天销售。
   - 外观好的高损耗品种不一定划算。

4. **大小最后**
   - 大小影响定价和顾客选择，但不如损耗关键。
   - 大果不一定出肉率高；小果单价低但人工成本高。应按目标客群定规格，比如家庭装偏中大果，即食果切偏中小果。

**结论：**
超市卖菠萝应把**切果损耗**作为第一经营指标，**甜度**作为复购指标，**外观**作为销售转化指标，**大小**作为陈列和定价指标。最实用的做法是：每批到货抽切测出肉率和糖度，用数据决定订货、定价和是否转果切。
