很重要。水果是典型的短保、高损耗品类，便利店销量不稳定时，供应商能否支持小批量试卖，直接决定你是在“用损耗换品类完整度”，还是在“用可控成本验证需求”。

你可以从四个维度判断这件事的重要性：

1. **降低试错成本**
   水果损耗高，首批进多了卖不动就是直接报损。小批量试卖能把损失控制在可承受范围内，尤其适合新品、新店、季节切换。

2. **提高补货灵活性**
   销量不稳定意味着订货量难预测。供应商若能小批量、多频次补货，你就能“少量多次”调整，而不是一次压货。

3. **验证真实需求**
   小批量试卖能快速看出哪些单品、规格、价格带动销好。没有小批量支持，你很难低成本试出结论，容易凭感觉订货。

4. **改善现金和货架效率**
   小批量降低库存占用和冷藏陈列压力，也减少临期处理的人力成本。

判断供应商是否“真的支持”，不要只听口头承诺，建议看这些可执行条件：

- **起订量**：按单品还是按整箱？能否混拼？
- **补货频率**：一周几次？临时加单是否接？
- **最小陈列单位**：是否接受小包装、少SKU试销？
- **损耗与退换**：临期、破损、滞销是否有分担机制？
- **试卖周期**：给多久观察期？期间价格和供货是否稳定？
- **结算方式**：小批量是否加价、是否影响账期？

如果供应商不能小批量试卖，你要么承担更高试错成本，要么只能放弃部分水果品类。对销量不稳定的便利店来说，**供应商的小批量试卖能力不是加分项，而是控制损耗和验证品类的基本能力**。谈判时可以把“首批小批量、两周动销复盘、达标再放量”写成明确合作条件。
