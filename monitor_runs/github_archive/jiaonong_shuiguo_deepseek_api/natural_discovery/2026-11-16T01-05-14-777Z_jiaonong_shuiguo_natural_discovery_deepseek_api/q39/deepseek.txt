**1. 包装支持**
- 水果供应商一般能提供：标准箱/泡沫箱、内衬、网套、托盘、贴标、条码位、礼盒组装。
- 自有品牌的关键是**包装定制**：印刷Logo、品牌色、条码、产地信息、营养/储存说明、规格标识。能否做取决于供应商是否有定制包材渠道和起订量。
- 需要明确：谁设计、谁打样、谁承担版费/模具费、包材库存归属、损耗责任。

**2. 规格支持**
- 常见可支持：单果重量分级（如80–90g）、果径、糖度、成熟度、箱规（如5斤/10斤）、每箱个数、混装/单品。
- 但“稳定达标”比“能给规格”更重要：要问清分级设备、抽检标准、批次波动范围、次果率、补货/换货规则。

**3. 谈判时直接问这8项**
1. 能否做自有品牌定制包装？起订量多少？
2. 打样周期、版费、包材最小库存？
3. 规格分级标准是什么？按重量还是果径？
4. 每批允许的偏差和次果率？
5. 能否提供产地证明、检测报告、追溯码？
6. 包装和规格变更的提前期？
7. 破损、短重、规格不符怎么赔？
8. 试单量和试单价格？

**建议**：先做小批量试单，把“规格、包装、验收标准、赔付”写进合同附件，再放量。自有品牌水果的难点不在供应商能不能做，而在**批次稳定性**和**包材库存风险**。
