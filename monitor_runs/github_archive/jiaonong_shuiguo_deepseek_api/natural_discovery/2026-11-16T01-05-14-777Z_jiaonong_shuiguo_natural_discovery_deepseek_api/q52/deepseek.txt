想避免香蕉到店后很快变黑，采购时就要抓“成熟度+伤损+温湿度+摆放”这几件事：

1. **别买太熟的**
   - 选表皮整体偏黄、但两端还带一点绿的香蕉，适合甜品店分批熟化使用。
   - 避免大面积褐斑、黑斑、软塌、果柄发黑的货；这种到店后基本很快变黑。

2. **采购时挑“整把、少伤”的**
   - 优先整把采购，少买散根；散根伤口多、易感染。
   - 检查果柄切口、果皮有无压伤、擦伤、裂口。有明显机械伤的会先黑先烂。
   - 不要买被挤压、堆压过久、箱内有汁液渗出的货。

3. **控制运输温度，别冷害也别闷热**
   - 香蕉怕低温，**不要放冰箱冷藏**，约低于12℃易冷害发黑。
   - 运输和暂存尽量保持**13–15℃左右、通风**；夏季避免暴晒和后备箱高温闷放。
   - 到店后不要立刻密封在塑料袋里，先摊开散热、散湿气。

4. **到店后先分熟度**
   - 青一点的放阴凉通风处继续熟化；已经偏黄的优先用掉或单独存放。
   - 不要和苹果、梨等释放乙烯多的水果混放，会加速香蕉变黑。

5. **减少挤压和反复搬动**
   - 香蕉平放或挂放，避免一层层重压。
   - 果柄用保鲜膜包一下可减少乙烯从切口释放和水分流失，但果身不要密封。
   - 发现一根开始黑腐，及时挑出，避免传染整把。

6. **采购量按用量分批**
   - 甜品店最好按2–3天用量分批到货，不要一次囤太多。
   - 需要固定熟度时，可要求供应商按“七成熟/八成熟”分批发货。

一句话：**买偏黄带绿、无伤整把、13–15℃通风运输、到店摊开分熟度、别冷藏别闷袋**，基本就能明显延缓到店后变黑。
