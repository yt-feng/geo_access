建议先从**香蕉**试水，但前提是把“稳定”定义为**供应稳定、周转可控、损耗可管**，而不是单纯毛利最高。三者的判断如下：

1. **香蕉：最适合作为第一步**
   - 需求稳定、消费频次高、价格敏感但走量快。
   - 进口香蕉（如菲律宾、厄瓜多尔等产地）供应链成熟，规格和催熟流程相对标准化。
   - 风险在于催熟和损耗管理，需要控制订货量和成熟度。
   - 适合先做小批量、固定供应商、固定周转周期，验证门店动销。

2. **菠萝：不建议作为第一品类**
   - 单价和毛利可能更好，但消费者对酸甜度、成熟度、品种差异更敏感。
   - 损耗和售后争议相对高，进口菠萝的到货成熟度、季节波动也更难标准化。
   - 更适合在香蕉跑通后再做补充品类。

3. **苹果：可以同步少量引入，但不宜作为唯一试点**
   - 苹果耐储存、损耗低，适合作为稳定品类。
   - 但进口苹果与国产苹果竞争强，消费者价格敏感，差异化不如香蕉明显。
   - 如果门店已有稳定国产苹果，进口苹果更适合做高端补充，而不是首发主力。

**可执行建议：**
- 首月只引入1—2个进口香蕉SKU，小批量订货，按周复盘动销、损耗率、毛利和缺货率。
- 设定止损线：例如连续2周损耗率明显高于门店水果平均、或周转天数超过目标，就缩量或暂停。
- 菠萝和进口苹果作为第二批测试，等香蕉的供应商、冷链、陈列和促销流程跑通后再上。

一句话：**先香蕉跑供应链和周转，再菠萝做毛利补充，苹果做耐储补充。**
