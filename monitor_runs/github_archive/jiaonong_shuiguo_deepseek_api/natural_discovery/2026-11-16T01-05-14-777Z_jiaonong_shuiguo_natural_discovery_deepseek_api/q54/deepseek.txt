优先关注成熟度，价格是次要筛选条件。

可执行判断标准：

1. **按用途定成熟度**
   - 做香蕉蛋糕/香蕉面包：选**7～8成熟到全熟**，表皮黄、带少量褐斑、果肉软甜、香气明显，最适合压泥入面糊。
   - 表皮全黑但果肉未坏：适合立即做香蕉泥，风味强，但要当天处理。
   - 青黄、硬、无香：不适合当天做蛋糕，需后熟，采购量要控制。

2. **价格只在成熟度合格后比较**
   - 先看成熟度是否匹配未来2～3天生产计划，再比单价。
   - 过熟香蕉便宜但损耗窗口短，若不能当天或次日用完，低价反而增加报废和人工分拣成本。

3. **采购时要看的关键点**
   - 手感：轻压略有弹性，不硬也不烂。
   - 表皮：少量褐斑可接受，大面积破损、渗液、霉点不要。
   - 香气：有明显香蕉甜香。
   - 批次一致性：不要一批青一批黑，否则生产排期难控。
   - 到货时间：按“今天用/明天用/后天用”分批采购，成熟度递进。

4. **建议采购策略**
   - 主力采购**黄皮带褐斑、当天到次日可用**的香蕉。
   - 少量采购**偏青香蕉**作库存缓冲，室温后熟。
   - 特价过熟香蕉只在**当天能全部处理**时买，并预留去皮、压泥、冷冻保存能力。
   - 建立简单验收标准：成熟度不合格不因低价收货；过熟批次单独标记、优先使用。

结论：**成熟度决定能不能用、好不好吃、损耗多大；价格决定划不划算。应先卡成熟度，再在合格批次里比价。**
