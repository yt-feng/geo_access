# 学校食堂水果供应商选择：可执行方案

## 一、先定“准入底线”，再比价格

学校食堂有食品安全责任，供应商筛选顺序应该是：**资质合规 → 供货稳定 → 价格合理 → 服务配合**，不要反过来先比价。

**必备资质（缺一不可）：**
- 营业执照、食品经营许可证（经营范围含食用农产品/预包装食品）
- 送货人员健康证
- 每批次农残检测报告（或供应商自检+定期第三方送检）
- 能开具正规发票、能签食品安全责任承诺书

**加分项：** 有学校/机关食堂供货案例、有冷链或保鲜运输能力、有固定分拣场地。

## 二、三类供应商的取舍

| 类型 | 优点 | 风险 | 适合场景 |
|---|---|---|---|
| 本地批发市场档口 | 价格低、品类全、灵活 | 资质参差、批次追溯弱 | 小规模、临时补货 |
| 产地/合作社直供 | 新鲜、价格有优势 | 品类单一、配送能力弱 | 香蕉、苹果等单品量大 |
| 专业食材配送公司 | 资质齐、可追溯、配送稳 | 价格略高、易形成依赖 | 主供应商首选 |

**建议：** 选1家主供应商（配送公司或合作社）+1—2家备选（批发档口/另一家配送），避免单一依赖，也保留比价空间。

## 三、香蕉、苹果、橙子分开定标准

常见水果的验收标准要写进合同，不能只写“新鲜”：

- **香蕉：** 成熟度7—8成（青黄转色）、无黑斑腐烂、果指饱满；按“把”或“斤”计价要明确，损耗率约定（如到货损耗≤5%）。
- **苹果：** 果径分级（如70—80mm）、无碰伤、无蜡感异常、硬度达标；按等级报价，避免“统货”混级。
- **橙子：** 糖度可抽检（如≥10°）、无青果、无烂果；注明品种和产地，防止以次充好。

**通用验收：** 每批抽检外观、气味、切果检查；记录到货时间、数量、批次、检测报告编号；不合格当场拒收并留证。

## 四、定价与结算机制

- **报价方式：** 要求按“周报价”或“随行就市+固定下浮率”报价，写清是否含税、含运费、含卸货。
- **比价：** 每月至少一次拿本地批发市场均价做对照，防止价格虚高。
- **结算：** 月结为主，预留5%—10%质保金，按季度或学期考核后支付。
- **调价：** 约定价格波动超过一定幅度（如10%）可协商调整，避免旺季随意涨价。

## 五、合同里必须写清的条款

1. 品名、规格、等级、单价、数量（或月度框架量）
2. 送货时间、地点、频次（如每周2—3次，早于食堂备餐时间）
3. 验收标准与拒收/退换货规则（如2小时内补货）
4. 食品安全责任：因供货问题导致食安事故的赔偿与追责
5. 检测报告随货或按批提供
6. 违约条款：缺货、迟送、以次充好的扣款或终止合作
7. 合同期限（建议一学期一签，考核合格可续）

## 六、落地步骤（可直接照做）

1. **发询价函：** 列明品类、规格、预估月量、资质要求、报价表格式。
2. **收资料初审：** 证照、检测能力、供货案例、配送车辆/人员。
3. **实地看：** 看分拣场地、仓储、保鲜条件，问追溯流程。
4. **小批量试供：** 试供2—4周，重点看准时率、损耗率、退换货响应。
5. **综合评分定标：** 资质30%、质量30%、价格25%、服务15%（可按校情调整）。
6. **签约+建档：** 建立供应商档案和每批验收台账，学期末考核。

## 七、几个容易踩的坑

- **只比单价不看损耗：** 低价统货烂果多，实际成本更高。
- **不约定规格等级：** 苹果大小混装、橙子品种替换，验收时扯皮。
- **检测报告“一证通用”：** 要求批批对应，至少定期第三方报告。
- **没有备选供应商：** 一家断供，食堂当天就缺水果。
- **验收不留痕：** 拍照、称重、签字记录，出现问题时才有依据。
