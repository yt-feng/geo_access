结论：**食堂采购水果，通常“按份/按标准份”最好管理；大宗、耐储存、品质稳定的水果可“按斤”；“按箱”只适合有明确规格、且验收能力强的情况，不建议作为主结算方式。**

可以按下面判断：

1. **按份结算最适合食堂日常管理**
   - 优点：份量固定、成本可预算、领用和售卖简单、盘点容易，适合直接面向就餐者的水果杯、果切、单人份水果。
   - 风险：必须把“一份多少克/多少块/什么品质”写进验收标准，否则供应商容易在单份重量和成熟度上缩水。
   - 适合：苹果、香蕉、橘子、圣女果、西瓜切块等标准化分发。

2. **按斤结算适合大宗采购和耐储存水果**
   - 优点：价格透明，便于比价，适合土豆式的大宗入库、后厨再加工。
   - 风险：称重、去皮、损耗、退换货争议多；食堂如果人手少，验斤和记账工作量较大。
   - 适合：整箱进货后再分发的苹果、梨、柑橘，或后厨统一切配的水果。
   - 管理要求：必须明确净重还是毛重、箱皮/筐重扣除、损耗率、退换标准。

3. **按箱结算管理最省事，但最容易吃规格亏**
   - 优点：下单、验收、结算快，适合包装规格稳定的品牌水果。
   - 风险：箱内大小、成熟度、坏果率不透明；不同批次“一箱多少斤”可能浮动；退换货责任难界定。
   - 适合：规格固定、供应商稳定、有抽检能力的包装水果。
   - 管理要求：合同里写清每箱净重区间、果径/等级、坏果率上限、抽检比例和扣款规则。

**推荐组合：**
- 对外售卖或分发：**按份结算**，定标准克重和品质。
- 后厨大宗入库：**按斤结算**，抓净重和损耗。
- 品牌包装水果：**按箱下单，但按净重+抽检结果结算**，不要只按箱一口价。

最核心的不是结算单位，而是**验收标准**：净重、等级、坏果率、损耗承担方、退换规则。没有这些，按斤、按箱、按份都会扯皮。
