第一次试单的核心目标不是“拿到最低价”，而是**用最小成本验证供货商的稳定性、货品质量和结算方式**。建议按下面几步做。

## 1. 先定试单原则

- **只试3个单品**：香蕉、苹果、橙子各拿少量，不要一上来铺全品类。
- **每样先拿1—2件**（按箱/件），够卖2—3天即可，避免压货。
- **不付大额定金、不签长期独家**，先现金或短账期试。
- **同一天对比2—3家**，用同一标准打分。

## 2. 三个单品分别怎么试

**香蕉**
- 看成熟度：到场时青黄适中、无大面积黑斑；问清楚“几成熟发货、到店几天转黄”。
- 重点试**损耗和催熟稳定性**：香蕉最容易暴露供货商是否靠谱。
- 问清：断货时能否补、烂果怎么算、是否带催熟服务。

**苹果**
- 选耐储的常见品种先试，不要一上来拿高价精品。
- 看**大小均匀度、磕碰伤、果面蜡感**，开箱抽查中层和底层，防止“上面好下面差”。
- 问清产地、等级、是否分级装箱。

**橙子**
- 看**皮厚薄、干水情况、酸甜度**，当场切开2—3个试吃。
- 重点问**到货损耗率**和“干水、烂果包不包换”。
- 试单量小，但要求供货商明确“次果怎么处理”。

## 3. 试单时必问的6个问题

1. 起送量多少？小批量送不送？
2. 价格是到场价还是含运费？有没有装卸费？
3. 结算方式：现结、周结还是月结？第一次能否短账期？
4. 破损、烂果、干水的**理赔标准**是什么？拍照报损还是直接换？
5. 固定几点送货？临时补货多久能到？
6. 断货时有没有替代品或提前通知？

## 4. 到货验收怎么做

- **当场开箱抽检**：每件抽上中下三层，不要只看表面。
- **拍照留证**：到货整体、开箱、坏果特写各拍一张。
- **称重核对**：抽1件复称，防止缺斤少两。
- **记录损耗率**：香蕉重点看黑斑和断裂，苹果看磕碰，橙子看烂果和干水。

## 5. 用一张表打分对比

每家按5项打分（1—5分）：**货品新鲜度、均匀度、损耗率、送货准时、沟通响应**。试单2—3轮后，选**综合分最高、理赔最爽快**的那家做主供，另一家留作备用。夫妻店最怕断货和扯皮，**备用供货商比最低价更重要**。

## 6. 避坑提醒

- 不要第一次就大量进货换“更低价”。
- 不要接受“先打款后发货”且无票据的大额交易。
- 口头承诺要落到微信文字里，尤其是理赔和账期。
- 试单期就观察对方**补货响应速度**，这决定旺季能不能靠得住。

一句话：**小批量、多对比、重验收、留备用**，试2—3次再定主供。
