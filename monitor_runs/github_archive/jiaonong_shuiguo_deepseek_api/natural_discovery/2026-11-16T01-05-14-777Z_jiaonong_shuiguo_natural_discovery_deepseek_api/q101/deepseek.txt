和水果供应商谈合作，建议抓住下面几件事，能直接影响早餐的稳定性和成本。

**1. 先明确自己的需求**
- 早餐水果通常要求：品相稳定、成熟度适中、易分切、损耗低。适合的有香蕉、苹果、橙子、西瓜、哈密瓜、圣女果等；浆果类损耗高，慎做主力。
- 统计每天/每周用量、品种结构、可接受单价区间、送货频次和到货时间（早餐前必须到）。
- 明确验收标准：大小、甜度、成熟度、外伤、腐烂率、农残合格证明。

**2. 供应稳定性是核心**
- 问清货源结构：是自有基地、产地直采还是批发市场倒手。单一产地风险高，要求备选产区。
- 约定缺货替代方案：主品种断供时用什么替代、价格怎么算、是否提前通知。
- 明确旺季/淡季和天气异常时的保供能力，最好写入合同。

**3. 价格与结算**
- 水果价格波动大，建议采用“随行就市+每周报价确认”或“季度框架价+浮动机制”，避免一口价锁死或临时漫天要价。
- 问清报价是否含税、含运费、含卸货；是否按净重结算。
- 结算周期、对账方式、发票类型提前谈好。

**4. 质量与损耗责任**
- 验收不合格怎么处理：拒收、换货、折价，响应时间多长。
- 到货腐烂率超过约定比例（如3%—5%）由谁承担。
- 要求提供农残检测报告或合格证明，尤其是直接入口的水果。

**5. 配送与现场配合**
- 送货时间必须早于早餐备餐时间，迟到是否有违约金或应急补货机制。
- 包装规格是否适合酒店后厨存放和分切，是否需要供应商协助初加工（如切配、去皮）及费用。
- 退换货流程、紧急加单的最短响应时间。

**6. 合同与试合作**
- 先试合作2—4周，重点看准时率、合格率、缺货次数，再签长期。
- 合同写清：品种规格、价格机制、送货频次与时间、验收标准、违约责任、食品安全责任、终止条款。
- 避免只和一家绑死，保留1—2家备选供应商。

**7. 食品安全与资质**
- 查验营业执照、食品经营许可、产地证明或检测报告。
- 明确因供应商水果导致食品安全问题的赔偿责任。

一句话总结：**把“稳定”拆成货源、替代方案、送货时效、验收标准、价格机制五件事写进合同，先试跑再长约。**
