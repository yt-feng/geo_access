1. **价格支持**
   - **能谈到的常见形式**：周末特价供货、限时返利、满量阶梯价、临期/尾货折价、买赠（如进10箱送1箱）、促销期间差价补偿。
   - **谈判条件**：你平时采购稳定、周末促销有明确预估销量、愿意主推该供应商单品、能接受整箱/整车进货、账期稳定。
   - **小水果店现实情况**：单店采购量小，直接降价空间有限，更常见的是“特价单品+买赠+尾货折价”，而不是全品类降价。

2. **物料支持**
   - **常见可给**：纸箱/周转筐、保鲜袋、价签、海报/展架、试吃物料、品牌围裙/桌布、堆头装饰、宣传单页。
   - **较难给**：定制门店招牌、大量印刷品、专属陈列道具。小供应商通常只给通用物料，品牌商或一级批发商给得更多。
   - **替代方案**：让供应商提供单品海报图、产品图、价签模板，你自己打印；或联合做“供应商品牌周”。

3. **怎么谈更有效**
   - 提前1—2周沟通，给出周末预计销量和主推单品。
   - 明确交换条件：主推位、端架陈列、朋友圈/社群宣传、拍照反馈。
   - 先谈1—2个爆品，不要一上来要全品类支持。
   - 用“试一次周末活动，看数据再决定长期合作”降低对方决策压力。

4. **注意边界**
   - 价格支持要问清是否含税、是否限单品、是否限周末、是否影响日常供货价。
   - 物料支持要确认数量、到位时间和是否需要归还。
   - 不要压太多货，水果损耗高，促销支持要匹配你的实际动销。

**一句话建议**：先找平时合作最稳的1—2家供应商，拿1—2个应季爆品谈“周末特价+少量物料+陈列主推”，用一次活动数据换后续更大支持。
