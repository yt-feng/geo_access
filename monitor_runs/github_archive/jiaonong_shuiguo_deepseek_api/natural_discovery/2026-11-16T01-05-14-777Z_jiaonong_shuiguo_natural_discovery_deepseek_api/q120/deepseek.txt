核心原则：**别用产地/品种术语开场，先用商家熟悉的“卖法、口感、用途、损耗”翻译，再给一个能直接下单的最小试单方案。**

供应商介绍时可按这个顺序说：

1. **先对应到商家已知品类**
   - “这个相当于菠萝里的‘凤梨口感款’，不用泡盐水，切开就能吃。”
   - “这个是香蕉里的‘小把装、适合便利店单根卖’的规格。”

2. **用三句话讲清楚**
   每介绍一个产品只说：
   - **吃起来怎么样**：甜度、酸度、软硬、有没有籽/纤维。
   - **怎么卖**：按根、按把、按盒、按斤；适合水果店、餐饮、便利店还是外卖果切。
   - **好不好操作**：要不要催熟、耐不耐放、损耗大不大、切开后能放多久。

3. **拿商家的货架和场景做对比**
   - “比你现在卖的普通香蕉更小把，适合前台单根卖，不容易一次买一大把吃不完。”
   - “这个适合做果切，不出水、颜色好看，外卖盒里不塌。”
   - “这个不适合散卖，适合餐饮后厨按箱用，出杯稳定。”

4. **少讲品种名，多讲“区别”**
   不要只说“这是某某品种”，要说：
   - 比普通款贵多少、为什么值；
   - 比普通款耐放几天；
   - 适合替代哪个现有产品；
   - 哪些客人会买。

5. **给最小试单，降低决策压力**
   最后直接说：
   - “先拿一箱试卖，按你店里一天卖多少算，大概能卖几天。”
   - “我给你配一张对比卡：普通款 vs 这款，怎么摆、怎么推荐、什么价合适。”
   - “卖不动我教你换场景，不急着压货。”

6. **让商家能判断下单的四个问题**
   供应商介绍完，最好能回答：
   - 我卖给谁？
   - 和现在货架上的货有什么区别？
   - 我怎么保存、损耗多少？
   - 最小拿多少、多久能卖完？

一句话模板：**“这个你可以当成××的升级/替代款，口感是××，适合××卖法，比普通款耐放/好操作在××，先拿最小箱试卖，卖几天就能看出要不要补。”**
