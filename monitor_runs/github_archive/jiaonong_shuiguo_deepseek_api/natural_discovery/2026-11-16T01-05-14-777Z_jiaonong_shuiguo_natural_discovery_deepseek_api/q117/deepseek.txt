先试卖多少，关键不是定一个固定数量，而是用“最小可判断销量 + 损耗可控”来试。给你一个可直接执行的判断框架：

**1. 先定试卖目标**
新品试卖要回答三件事：卖不卖得动、复购有没有、损耗能不能接受。所以试卖量应控制在 **3～7天能卖完**，而不是按供应商起订量硬压。

**2. 建议试卖量**
按门店/渠道类型给区间：

- **单店便利店/水果店**：单品先试 **10～20公斤**，或 **2～4箱**（按箱规折算），宁少勿多。
- **社区生鲜店/小型超市**：先试 **20～50公斤**，约 **3～5天销量**。
- **连锁门店**：先选 **2～3家代表性门店**试卖，每店 **10～20公斤**，不要全渠道铺开。
- **餐饮/果汁/团购大客户**：先按 **1～2次交付量**试，通常 **50～100公斤**，但必须约定可退换或分批提货。
- **高损耗、易熟软、保质期短的水果**（如草莓、蓝莓、熟芒果、水蜜桃）：再下调30%～50%，先 **1～2天销量**。
- **耐储水果**（苹果、橙子、梨）：可适当到 **5～7天销量**。

**3. 用公式算更稳**
试卖量 ≈ 同类水果日均销量 × 试卖天数 × 新品修正系数（新品尝鲜期一般0.5～0.8）。
例如同类日均卖10公斤，试3天，修正0.6，则先试 **18公斤** 左右。

**4. 必须同时谈好的条件**
- 小批量、分批发货，避免一次压库；
- 明确损耗承担和退换货比例；
- 先拿样品做糖度、硬度、外观、到货损耗抽检；
- 记录试卖期的日销量、损耗率、复购和顾客反馈，再决定补单。

**一句话建议：首次试卖以“3～5天能卖完、损耗金额可承受”为上限；单店通常先试10～30公斤或2～4箱，高损耗品再减半。** 如果供应商要求起订量明显高于这个数，优先谈分批提货或换小规格，而不是直接放大试卖量。
