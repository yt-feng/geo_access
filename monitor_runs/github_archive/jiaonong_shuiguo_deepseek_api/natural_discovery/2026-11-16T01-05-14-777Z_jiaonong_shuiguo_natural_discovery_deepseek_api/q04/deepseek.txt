采购香蕉时，把“熟度”和“到货时间”写成可验收的标准，比口头说“别太熟”有用得多。建议这样要求供应商：

1. **按颜色和硬度定熟度**
   - 常规门店销售：要求到货为**青黄转色期**，果身大部分黄、两端略显青绿，果肉按下去有弹性但不软塌。
   - 不要只看颜色，要求**手感硬挺、无软斑、无黑点、无裂口**。
   - 如果门店销量快、2—3天内能卖完，可适当要“黄一点”；销量慢就坚持“偏青一点”。
   - 明确拒收标准：大面积黑斑、果柄发黑、果身软陷、有酒味或酸味、整把发黄发软。

2. **按到货时间倒推采收熟度**
   - 要求供应商按**到店日期**发货，而不是按采摘日期随便发。
   - 夏季高温：优先要求**到店当天或前一天采收/发货**，熟度偏青，避免运输中催熟过快。
   - 冬季低温：可接受稍早采收，但到店仍应保持硬挺、无软斑。
   - 明确运输时长和温度：尽量**冷链或阴凉运输**，避免暴晒、闷热；到店时果温不能明显发热。

3. **写进采购单的验收条款**
   - “到货熟度：青黄转色，果身硬挺，允许轻微青绿，不允许大面积黄软和黑斑。”
   - “到货时间：按门店指定日期上午到店，运输时长不超过X小时，途中避免高温暴晒。”
   - “验收方式：每箱抽检颜色、硬度、黑斑、裂口、异味；不合格比例超过X%可拒收或换货。”
   - “批次标注：每箱标明采收/发货日期和预计最佳销售期。”

4. **采购节奏上少量多次**
   - 香蕉是呼吸跃变型水果，后熟快。与其一次进很多，不如**增加频次、减少单次批量**。
   - 先小批量试供应商的“到店熟度”，连续观察2—3批，再固定标准。
   - 到店后立即拆箱通风，别闷在塑料袋或纸箱里；按熟度分架，先卖黄的，青的放阴凉处后熟。

一句话：**要“青黄硬挺、按店日期到货、可抽检拒收”的香蕉，不要笼统说“不要太熟”。**
