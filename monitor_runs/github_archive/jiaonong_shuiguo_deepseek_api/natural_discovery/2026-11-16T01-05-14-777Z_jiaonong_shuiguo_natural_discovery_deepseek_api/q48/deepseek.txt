判断菠萝供应商能否稳定按规格送货，重点不是看样品，而是看“批次一致性”和“旺季履约能力”。建议按下面几步做，可直接落地：

1. **先定可验收的规格标准**
   不要只写“大果、新鲜”。至少明确：
   - 品种/产地范围；
   - 单果重量区间（如1.2–1.5kg）；
   - 成熟度（七成熟/八成熟，糖度范围）；
   - 果形、无黑心、无机械伤、冠芽保留要求；
   - 每批允许的不合格率（如≤3%）；
   - 包装方式、每箱净重、箱规、到货温度或冷链要求。
   标准越可量化，越能判断供应商是否“按规格”。

2. **要求提供连续批次的履约记录**
   让供应商提供近3个月的真实送货记录：批次号、单果重抽检、合格率、迟到次数、缺货补货记录。重点看**同一规格连续多批是否稳定**，而不是单次样品好。可要求其现有茶饮/水果客户中的同类供货案例，但不要只看客户名单，要看抽检记录。

3. **做“小批量试单+多批次抽检”**
   先下2–3个小批次，分别在不同周、不同天气或不同产地切换期送货。每批到货按标准抽检：
   - 每批随机抽30–50个果称重、看成熟度、切开查黑心；
   - 记录不合格率、重量标准差、到货时间偏差；
   - 连续3批合格率≥97%、重量区间达标、无集中性质量问题，再进入稳定供应。
   这比看工厂和样品更能判断稳定性。

4. **核查产地与季节供应能力**
   菠萝有明显产季和产区切换。要问清：
   - 自有基地/合作基地面积、日加工能力；
   - 当前产区切换时如何保证规格一致；
   - 旺季日供货上限、备用产区；
   - 遇到台风、暴雨、寒潮时的替代方案。
   如果供应商只有一个产区、一个季节货源，旺季断供风险高。

5. **看分选和冷链能力**
   稳定按规格送货，核心在采后分选。确认是否有重量分选线、人工分级标准、预冷/冷链车、到货温度记录。没有分选能力的供应商，很难长期稳定同一重量区间。

6. **在合同里写履约约束**
   明确：
   - 规格不合格的拒收/扣款规则；
   - 连续两批不合格的暂停供货或替换供应商；
   - 缺货提前通知时限和补货责任；
   - 旺季保供量、价格调整机制；
   - 每批随货提供产地证明、农残检测报告、发货批次号。
   有约束条款，供应商才会认真对待规格稳定。

7. **建立到货评分表**
   每批按“规格合格率、重量达标率、新鲜度、到货准时率、缺货率、异常响应”打分，连续4周看趋势。评分稳定在90分以上再放量；低于80分要求整改或缩量。

简单判断：**愿意让你抽检连续批次、能说清产区切换和旺季保供方案、合同接受不合格扣款的供应商，稳定性更可信；只靠样品和口头承诺的，不要直接放量。**
