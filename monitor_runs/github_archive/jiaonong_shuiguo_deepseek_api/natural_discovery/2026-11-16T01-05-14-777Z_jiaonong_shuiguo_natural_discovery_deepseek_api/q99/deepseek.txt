选下午茶水果供应商，核心看四件事：**稳定供货、批量分装、准时配送、损耗可赔**。按下面顺序筛，基本不会踩坑。

**1. 先定需求再找供应商**
- 人数、预算/人、配送时间（精确到半小时）、是否有忌口或过敏、是否需要洗切分装。
- 优先选**单一品类少、当季本地水果为主**的方案，批量配送最怕“品类多但每样量少”，分装和品控都难。

**2. 供应商类型怎么选**
- **本地水果批发商/档口**：价格低、适合大批量，但分装和配送要自己协调，适合有行政人手接货。
- **生鲜配送平台（B端）**：有企业下午茶套餐、可开发票、配送准时，价格中等，适合省心。
- **本地果园/合作社直供**：当季单品性价比高，但品类单一、配送范围有限。
- **连锁水果店企业团购**：服务好、可试吃，但批量价未必低，适合小批量高频。
建议：**20人以下选连锁团购或生鲜B端；50人以上选本地批发商+分装服务，或B端企业套餐比价。**

**3. 必须核验的硬指标**
- **配送能力**：是否自有冷链车、能否固定时段送达、迟到怎么赔。
- **分装能力**：能否按份装袋/装盒、是否洗切、有无独立包装。
- **品控与售后**：坏果率承诺（比如≤3%）、到货坏果是否补送或退款、拍照留证流程。
- **资质**：营业执照、食品经营许可证、开票能力。
- **试单**：先下**一次小批量试单**，看准时率、坏果率、分装质量，再签长期。

**4. 批量配送的避坑点**
- 别只比单价，算**含分装、配送、损耗后的实际成本**。
- 合同写明：送达时间、坏果赔付比例、临时加单/减单截止时间。
- 水果品类选**耐运输、不易压伤**的：苹果、橘子、香蕉、圣女果、提子；少选草莓、荔枝、水蜜桃等易损品，除非供应商有冷链且承诺赔付。
- 要求**到货拍照验收**，当场清点，坏果当场登记。

**5. 快速比价方法**
找3家：1家本地批发商、1家生鲜B端、1家连锁团购，用同一份清单（品类、数量、配送时间、分装要求）报价，重点对比**总价+坏果赔付+迟到赔付**，选中间价位且条款最全的。

一句话：**先试单、再签量；合同写清赔付；品类选耐运的。**
