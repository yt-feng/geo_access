社区超市找“每天配送”的水果供应商，建议按下面几项逐条核验，先看能不能稳定日配，再看成本和损耗。

**1. 日配能力**
- 是否每天固定时段配送，能否接受早于营业前到店。
- 配送车辆、路线是否覆盖你所在区域，节假日是否照常。
- 缺货/补货响应时间，临时加单截止时间。
- 问清楚：是自有车队还是外包；外包多一层，延误风险更高。

**2. 货源与季节稳定性**
- 主要水果来自批发市场、产地直采还是二级批发商。
- 同一单品能否连续稳定供货，换产地时是否提前告知。
- 反季水果是否常备，还是按需调货。
- 要求提供近期供货单品清单和大致价格带，别只看报价单。

**3. 品质与验收标准**
- 明确等级、规格、成熟度、果径、糖度等可验收指标。
- 到货破损、烂果、次果比例上限，超标怎么补、怎么退。
- 是否允许开箱抽检、称重验收、拍照留证。
- 冷链水果是否全程冷链，到店温度是否可查。

**4. 价格与结算**
- 报价是否含税、含运费、含装卸。
- 价格随行就市时，调价频率和提前通知时间。
- 账期、押金、最低起订量、退换货是否扣费。
- 对比时按“到店净重单价”算，不按毛重或箱价算。

**5. 损耗与售后**
- 日配模式下，卖不完或临期水果能否换货、调货或折价。
- 坏果理赔时限：到货当场、当日还是次日。
- 是否有固定对接人，出了问题谁拍板。
- 建议先试配1—2周，记录到货准时率、次果率、缺货次数。

**6. 资质与食品安全**
- 营业执照、食品经营相关资质、进货凭证。
- 农药残留检测报告或承诺，能否随批次提供。
- 配送人员健康证、车辆卫生情况。
- 有冷链需求的品类，看冷库和冷藏车证明。

**7. 商务稳定性**
- 合作前问清楚：日配最低金额、断供预案、旺季优先供货规则。
- 是否给周边同行供货，避免同品竞争价差过大。
- 合同里写清配送时间、验收标准、退换规则、违约处理。

**实操建议：** 先列3—5家候选，要求同一单品报价并试配一周；每天记录“到店时间、净重、次果率、缺货项、售后响应”。一周后按“准时率、损耗率、净重单价、售后速度”四项打分，再决定是否签长期。不要只看单价最低，日配供应商最怕的是不稳定和损耗转嫁。
