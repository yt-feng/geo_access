最应该先问**售后**，其次确认**配送**，最后再谈**价格**。

原因是团购团长卖水果，真正决定你能不能持续赚钱的不是进货价低几分钱，而是：

1. **售后决定你会不会亏钱、掉口碑**
   水果是非标品，坏果、烂果、缺斤少两、口感差几乎必然发生。你要先问清楚：
   - 坏果怎么赔？按个数、按比例还是整单补发？
   - 拍照报损的时限和标准是什么？
   - 是供应商承担还是团长先垫？
   - 多次售后会不会限制额度或取消合作？

2. **配送决定你能不能按时交付**
   水果有时效，配送晚一天，损耗和投诉都会上升。重点问：
   - 几点前下单、多久送到？
   - 送到团长自提点还是分拣到小区？
   - 破损、延迟、漏送谁负责？
   - 旺季能不能保证运力？

3. **价格要谈，但不该第一个问**
   价格最低的供应商，往往在售后和配送上省钱。你应该在售后和配送条款清楚后，再比较“综合到货成本”：
   - 报价是否含运费、包装、损耗；
   - 起订量和账期；
   - 坏果赔付后的实际成本。

**可执行的判断顺序：**
先让供应商书面写清售后赔付规则 → 再确认配送时效和责任 → 最后对比含损耗、运费后的综合价格。只给低价、不肯明确售后的供应商，不建议合作。
