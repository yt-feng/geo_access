核心思路：**不要按“买回来能放多久”采购，而要按“从到货到用完的窗口期”倒推采购量和成熟度，并用加工/分流兜底。**

可执行做法：

1. **按使用周期定量**
   - 统计食堂香蕉从到货到基本用完通常需要几天，按日均用量×到货间隔采购。
   - 香蕉属于后熟水果，建议**少量多次、缩短补货间隔**，比一次大批量更稳。
   - 设安全库存只覆盖1天左右，不囤“便宜货”。

2. **采购时明确成熟度**
   - 不要只写“香蕉”，在采购单中约定成熟度：如“到货时果皮以黄绿为主、少量黄斑，适合2—3天内用完”。
   - 要求供应商分批次供货，避免同一批全部同期成熟。
   - 到货验收时抽检：青绿比例、已出现黑斑比例、果柄状态，超熟比例高的拒收或折价。

3. **到货后做“成熟度分级”**
   - 青黄偏硬的：常温通风存放，优先留到后两天用。
   - 已全黄、少量芝麻斑的：当天/次日优先出餐。
   - 已大面积黑斑但果肉未坏的：立即转加工，不再陈列自取。

4. **用出餐方式调节消耗**
   - 熟香蕉优先用于香蕉牛奶、奶昔、香蕉粥、蒸糕、松饼、水果沙拉等加工品，消化速度快。
   - 设置“今日优先食用”标识或窗口推荐，减少学生挑拣导致剩果。
   - 避免把最熟的香蕉放在自取台最显眼处被反复翻拣。

5. **建立简单的每日巡检和预警**
   - 每天固定时间检查库存，按“青/黄/熟/过熟”四档记录数量。
   - 当“熟+过熟”库存超过当日预计用量时，第二天减少采购或改为加工菜单。
   - 连续记录2—4周后，就能得到本校食堂真实的香蕉周转天数，采购量会更准。

6. **合同和供应商协同**
   - 与供应商约定小批量、多频次配送；允许按实际用量调整次日订单。
   - 对长期合作供应商提出成熟度标准，把“到货即可用窗口”写进验收要求。

7. **兜底处理**
   - 对果肉未变质但外观差的香蕉，及时去皮冷冻，用于后续奶昔/烘焙，但要有明确标识和先进先出。
   - 已变质的不加工、不二次分发，按食堂食品安全制度处理。

一句话：**少量高频采购 + 约定到货成熟度 + 每日分级巡检 + 熟果转加工**，是避免香蕉熟过头浪费最直接的四件事。
