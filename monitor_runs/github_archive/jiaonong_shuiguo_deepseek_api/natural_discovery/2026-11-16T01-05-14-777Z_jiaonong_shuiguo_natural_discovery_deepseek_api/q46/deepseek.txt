直接给结论：**优先买鲜果，次选冷冻果丁/果丁，果泥只适合做特定产品；不要一上来全用果泥。**

### 怎么选
1. **鲜果：最推荐做主打的菠萝果茶**
   - 优点：香气、口感、果肉感最好，能做“鲜切、捣果、果块装饰”，顾客感知强。
   - 缺点：损耗高、削皮切配耗时、甜酸不稳定，需要定标准。
   - 适合：招牌菠萝茶、鲜果茶、带果肉的产品。

2. **果丁（尤其冷冻果丁）：适合稳定出杯和降损耗**
   - 优点：规格统一、开袋即用、损耗低、出品稳定，适合高峰期。
   - 缺点：香气和脆感通常不如鲜果，解冻后易出水。
   - 适合：连锁化、外卖多、销量大、想减少切配人力的门店。
   - 注意：选冷冻果丁要看是否加糖、是否带汁、解冻后状态。

3. **果泥：只适合做基底或风味补充**
   - 优点：稳定、方便、成本可控，适合做冰沙、果酱型、混合茶底。
   - 缺点：缺少果肉感，容易出现“香精感/酱感”，单独做鲜果茶卖点弱。
   - 适合：菠萝冰沙、菠萝气泡饮、复合果茶基底、季节限定中的风味补充。

### 最稳的采购组合
- **小店/单店主打鲜果**：鲜果为主，少量果泥做基底补充。
- **销量大/外卖多/人手紧**：鲜果做卖点款，冷冻果丁做常规款，果泥做冰沙或调味基底。
- **不建议**：全部用果泥还宣传“鲜果茶”，口感和信任感容易翻车。

### 采购前先做3个判断
1. **菜单里菠萝是“主角”还是“配角”**：主角用鲜果或果丁，配角可用果泥。
2. **日出杯量和人力**：切配扛不住就上冷冻果丁。
3. **是否强调“鲜切/果肉感”**：强调就保留鲜果，至少做装饰或部分添加。

**建议先小批量测试：鲜果、冷冻果丁、果泥各做同一款茶，盲测香气、果肉感、甜酸稳定性和成本，再定比例。**
