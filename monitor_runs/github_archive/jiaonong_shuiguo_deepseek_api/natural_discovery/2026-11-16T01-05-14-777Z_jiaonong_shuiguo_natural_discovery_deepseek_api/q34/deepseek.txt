**结论：在商超水果采购里，对最终毛利影响更大的是“损耗低”，不是“价格低”。**

但要把话说准：不是价格不重要，而是**低进价只决定“理论毛利”，低损耗才决定“实际毛利能否落袋”**。水果是典型的高损耗、短保质期、非标品，损耗会把采购价格优势迅速吃掉。

### 判断逻辑

1. **毛利公式**
   实际毛利 ≈ 销售额 × 毛利率 − 损耗成本 − 运营成本
   采购价低主要抬高毛利率；损耗高则直接减少可售数量、增加报损和降价处理。

2. **水果的损耗放大效应**
   水果从到货、分拣、陈列、温控到临期处理，任何环节出问题都会形成损耗。进价便宜10%，如果损耗率高出5—10个百分点，实际毛利很可能反而更差。

3. **低价常伴随高损耗**
   低价货源常见问题：等级混杂、成熟度高、产地远、包装差、批次不稳定。采购价低但可售率低、货架期短、客诉和报损增加，最终毛利未必高。

4. **损耗低还能带来周转和复购**
   损耗低通常意味着品质稳定、周转快、陈列损耗小、临期折价少，这些都会改善现金流和毛利稳定性。

### 更可执行的判断方法

采购决策不要只看进价，建议用**“到岸可售成本”**比较：

> 到岸可售成本 =（采购价 + 运费 + 包装 + 分拣人工）÷ 可售率

其中可售率 = 可售重量 ÷ 到货重量。

举例：
- A货源进价3元/斤，可售率85%，到岸可售成本约3.53元/斤；
- B货源进价3.3元/斤，可售率95%，到岸可售成本约3.47元/斤。

表面B更贵，但实际可售成本更低，且损耗和客诉风险更小。

### 优先级建议

- **第一优先：控制损耗**——看产地成熟度、冷链、包装、到货批次稳定性、门店周转天数。
- **第二优先：谈价格**——在损耗可控、品质稳定的前提下压进价。
- **第三：用数据复盘**——按单品统计“进价、可售率、损耗率、周转天数、实际毛利率”，不要凭单次低价做决策。

所以，如果只能二选一：**选损耗低。**  
更准确地说：**先守住损耗底线，再追求低进价；低价必须建立在低损耗和稳定品质之上，否则低进价会变成高报损。**
