生鲜水果坏果投诉的责任划分，建议按“先定场景、再看证据、最后定承担比例”处理。核心不是简单归责给顾客或商家，而是看坏果发生在哪一环节、是否可归责于某一方。

## 一、常见责任场景

1. **到货即发现明显腐烂、霉变、压烂**
   - 通常由商家/平台承担主要责任。
   - 理由：采摘、分选、包装、冷链、配送环节可能存在问题，顾客在签收时难以逐颗开箱验货。
   - 处理：拍照/视频留证，按坏果数量比例退款或补发。

2. **外包装明显破损、挤压变形导致坏果**
   - 配送方或平台承担主要责任。
   - 若商家包装明显不足（如无缓冲、无冰袋、箱体过软），商家也承担部分责任。
   - 处理：顾客签收时拍外箱和内部坏果，平台协调配送方与商家。

3. **签收后放置较久才投诉**
   - 需区分“到货即坏”和“储存不当”。
   - 若顾客未及时开箱、未按说明冷藏，扩大损失部分可能由顾客承担。
   - 商家仍应对到货时已存在的隐蔽坏果承担合理责任，但顾客需举证。

4. **个别坏果属于生鲜合理损耗**
   - 水果是非标品，少量轻微碰伤、成熟度差异通常不构成质量问题。
   - 若合同/页面承诺“坏果包赔”“坏果率超过X%赔付”，按承诺执行。
   - 无明确承诺时，按坏果比例、严重程度协商，不宜因一颗坏果要求整单赔偿。

5. **顾客自身原因导致**
   - 如拒绝及时签收、要求放快递柜暴晒、未按储存条件保存、人为损坏。
   - 该部分责任由顾客承担，但商家需有证据证明。

## 二、建议的责任划分原则

- **到货验收前发现的坏果**：商家/平台主责，配送造成的外损由配送方承担，商家可向配送方追偿。
- **包装不当与配送损坏叠加**：商家与配送方按过错分担，平台先行处理。
- **签收后因储存不当扩大损失**：顾客承担扩大部分。
- **少量轻微损耗**：双方合理分担或按售后规则补偿。
- **无法举证时**：平台一般倾向消费者，但商家可要求顾客提供开箱照、坏果照、时间记录。

## 三、可执行处理流程

1. 顾客在签收后尽快开箱，拍摄外箱、快递面单、坏果整体和细节。
2. 商家核对发货记录、分选记录、包装和冷链记录。
3. 平台按坏果比例给出补发、部分退款或全额退款方案。
4. 若争议大，保留照片、聊天记录、物流记录，向平台投诉或申请消费者协会调解。

## 四、给商家的风控建议

- 页面明确坏果赔付规则和签收验货时限。
- 易损水果加强缓冲包装、冰袋和防压设计。
- 要求顾客坏果与面单同框拍照，降低恶意索赔。
- 对高频投诉区域和配送线路做复盘。

**结论：** 到货即坏的坏果，原则上商家/平台承担主要责任；配送外损由配送方分担；签收后因顾客储存不当扩大的损失由顾客承担；少量合理损耗按约定或比例协商。关键是保留开箱证据和时效记录。
