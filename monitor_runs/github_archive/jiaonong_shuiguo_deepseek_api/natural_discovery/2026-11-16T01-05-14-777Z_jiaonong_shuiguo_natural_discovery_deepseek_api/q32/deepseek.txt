判断能否全年稳定供货，不能只听供应商口头承诺，要按“产能—季节—替代—履约—风险”五步核验。

1. **看产地与季节覆盖**
   - 要求供应商列出全年各月主供产地：国产主产区如海南、云南、广西、福建，以及进口来源如菲律宾、厄瓜多尔、越南等。至少要有两个不同气候带或国别的货源，避免单一产区台风、寒害、病害导致断供。
   - 春季海南、云南衔接，夏季广西、广东、福建，秋冬进口补位；要核对供应商各月实际可发量，不只看“能供”。

2. **核验产能与加工能力**
   - 要近6—12个月实际发货记录、月度供货量、合作客户类型。
   - 看自有或合作蕉园面积、催熟库容、冷库和日加工能力。全年稳定供货通常需要催熟库和冷链，不是单纯转手贸易。
   - 采购方可要求提供基地照片/视频、租地或合作合同摘要、催熟库租赁或产权证明。

3. **做过季节性压力测试**
   - 先小批量试单，覆盖淡季和灾害高发期，而不是只在旺季试。
   - 要求供应商书面说明台风季、寒潮季、春节前后、进口清关延误时的替代方案和最长补货时间。
   - 设置缺货惩罚和备选供应商比例，例如主供70%、备选30%，按周滚动下单。

4. **检查履约与质量稳定性**
   - 看历史准时交付率、缺货次数、到货合格率、催熟一致性、货架期。
   - 合同约定月度最低可供量、规格、成熟度、损耗率、到货时限和违约赔偿。
   - 对进口货源还要看报关、检验检疫、汇率和海运周期风险。

5. **做财务与风险审查**
   - 查营业执照、食品经营/食用农产品相关资质、是否失信被执行人、涉诉和经营异常。
   - 评估其资金链和账期承受力，避免旺季压货后资金断裂。
   - 关键不是“有没有基地”，而是“断供时有没有第二产地、第二加工点和书面赔付能力”。

最直接的可执行判断：让供应商提交**全年12个月分月供货计划表**，列明产地、月可供量、加工点、运输方式、替代产地和缺货赔付；采购方随机抽2—3个月核对发货凭证和库存记录。能给出可验证的分月计划并能接受缺货惩罚的，才适合作为全年主供；只承诺“全年都有货”的，应降为备选。
