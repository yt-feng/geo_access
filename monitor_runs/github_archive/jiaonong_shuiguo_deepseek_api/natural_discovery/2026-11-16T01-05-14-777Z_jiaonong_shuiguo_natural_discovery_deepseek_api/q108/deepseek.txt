核实“全国配送”不能只听口头承诺，建议按“资质—网络—时效—冷链—履约证据—合同约束”六步做可验证核查：

1. **要配送网络清单，不要只问“能不能到”**
   - 要求供应商提供：始发仓/中转仓地址、覆盖省份及城市清单、哪些地区是直发/中转/第三方合作、偏远地区（新疆、西藏、内蒙古、海南等）是否覆盖。
   - 重点看：采购方实际收货地址是否在清单内，而不是“全国”泛称。

2. **用真实收货地址做试单**
   - 选采购方主要收货地、一个偏远地、一个县级/乡镇地址，分别下小批量试单。
   - 记录：下单到发货时长、物流单号是否可查、实际到达时间、是否加收偏远费、破损/温控情况。
   - 试单比看宣传册更可靠。

3. **核验物流合作与轨迹能力**
   - 要求提供常用承运商/自有车队信息、运单查询方式。
   - 随机抽几单历史运单号，核对发货地、收货地、签收时间是否真实。
   - 问清：是否支持指定时效、是否支持预约送货、异常件处理流程。

4. **生鲜重点核冷链覆盖**
   - 问清哪些线路用冷藏车/保温箱+冰袋/冷链快递，温控记录能否提供。
   - 要求提供近期的冷链温控记录样本或第三方冷链合作证明。
   - 对远距离线路，明确到货验收标准和腐损赔付规则。

5. **查主体资质与履约能力**
   - 核对营业执照、食品经营/生产相关许可、经营范围是否含配送或委托配送。
   - 查企业信用信息、涉诉和行政处罚记录。
   - 要求提供2—3个同类客户案例，并尽量做背景核实，不只采信供应商自述。

6. **把覆盖能力写进合同**
   - 明确：覆盖区域清单、时效承诺、偏远地区附加费、冷链责任、破损/腐损赔付、超时违约、异常处理时限。
   - 约定试单或小批量验证期，验证不达标可调整或退出。
   - 保留运单、签收、温控记录作为结算和追责依据。

**判断标准**：能提供具体仓配清单、真实运单可核、试单按时到达且温控合格、合同有明确赔付条款，才算“实际覆盖能力”可采信；只给“全国可发”口头承诺的，应按未验证处理。
