建议按“先验资质、再要检测、最后留凭证”的顺序向供应商索取资料，重点是能对应到具体批次和品种。

1. **供应商与产地资质**
   - 营业执照、食品经营许可证（或备案信息）
   - 产地证明/供货证明；若是合作社或种植基地，索取基地名称和地址
   - 若供应商声称“绿色食品”“有机”等，索取对应有效认证证书，并核对认证范围是否包含该水果

2. **农残检测报告（最关键）**
   - 要求提供**与拟采购品种、批次/采收期对应**的农残检测报告，不接受只有“通用合格报告”
   - 报告应由具备资质的检测机构出具，关注：检测项目是否覆盖常见农残、检测依据、样品名称、抽样日期、报告编号、结论
   - 优先要**批次检测报告**；若供应商只有年度/季度报告，要求补充该批次的快检或委托检测记录
   - 对高风险品种（如草莓、葡萄、豇豆等）可要求更近期的检测或增加项目

3. **进货查验与追溯资料**
   - 随货提供送货单/销售凭证，注明品种、数量、产地、批次或采收日期
   - 索取供应商的进货查验记录或承诺书，明确农残超标时的退换货和责任承担
   - 保留供应商联系人、检测报告编号，便于抽检不合格时追溯

4. **合同/质量保证条款**
   - 在采购合同或质量协议中写明：每批随货提供合格证明或检测报告；超市有权抽检；农残超标时供应商承担退货、销毁、罚款及连带责任
   - 约定报告造假或不提供资料的违约责任

**判断标准**：资料要能“三对应”——对应品种、对应批次/采收期、对应检测项目。只有营业执照和一张模糊的年度报告，不足以应对抽检风险。到货后超市自身也应做快检或抽检留样，并保存进货台账和检测记录。
