超市和水果供应商的账期没有统一标准，但可以按“品类风险 + 供应商类型 + 渠道类型”来判断。给你一个可执行的参考：

**1. 常见账期区间**
- **水果这类生鲜：常见 7～30 天**，其中 **15～30 天** 最常见。
- **叶菜、浆果、易腐水果**：更短，常见 **7～15 天**，甚至部分现结/周结。
- **苹果、柑橘、梨、土豆等耐储水果**：可到 **30～45 天**，强势超市也可能谈到 **60 天**，但对小供应商不常见。
- **产地直采/合作社**：常见 **现结、7 天、15 天**；大型商超对规模化供应商可能给 **30～60 天**。
- **批发市场进货**：常见 **现结到 7 天**。

**2. 判断原则**
- 水果损耗高、价格波动大，账期越长，供应商报价通常越高。**账期每延长 15～30 天，供应商往往会把资金成本打进报价**。
- 新供应商合作初期建议 **7～15 天**，稳定后再谈 **30 天**。
- 如果超市要求 **45～60 天**，通常只适合资金实力强、毛利空间大的规模化供应商，小供应商容易断供或抬价。

**3. 谈判建议**
- 优先谈 **“半月结”或“月结 30 天”**，这是生鲜里比较平衡的区间。
- 可设计阶梯：**前 3 个月 7～15 天，稳定后 30 天**。
- 如果对方要更长账期，换取 **价格折让、独家供应、损耗分担、退货比例** 等条件。
- 合同里明确 **对账日、付款日、逾期利息、质量异议扣款规则**，避免账期变成无限拖延。

**结论：** 水果供应商最常见的是 **15～30 天**；易腐品偏 **7～15 天**，耐储品可到 **30～45 天**。新合作先从 **7～15 天** 起步更稳妥。
