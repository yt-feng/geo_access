优先谈 **账期**，但要用“账期换稳定采购量/换价格或服务条款”的方式谈，而不是单纯压账期。

判断逻辑：

1. **账期最值得先谈**
   - 水果损耗高、价格波动大、现金流压力大，账期直接决定你的资金占用和经营风险。
   - 长期合作下，账期是结构性条款，一旦定下来影响每一笔订单；配送和售后更多是执行层问题，可以后续逐步优化。
   - 账期谈成后，还能反向约束供应商重视配送和售后，因为你有未结货款作为履约杠杆。

2. **配送第二优先**
   - 水果非标、易损，配送时效和温控直接影响损耗率和客户投诉。
   - 但配送问题通常可以通过约定到货时间、验收标准、迟到/破损处理来补，属于“可操作、可考核”的条款，不必在第一轮谈判中作为核心交换条件。
   - 如果供应商配送能力明显不足，优先谈配送；否则先谈账期。

3. **售后最后谈，但要同步写清**
   - 售后条款（烂果率、短斤少两、退货补货时限）很重要，但它通常是“出了问题怎么赔”，不是合作能否成立的核心。
   - 售后容易谈成，因为供应商让一步成本可控；可以放在账期之后作为配套条款一并锁定。

建议谈判顺序和交换条件：

- **第一步：谈账期**。先明确你能给的稳定采购量/年度合作承诺，再要求账期从现结或短账期延长到合理区间（如月结30天等，按你行业实际定），同时约定逾期付款的后果。
- **第二步：用账期换配送标准**。比如要求固定时段送达、冷链/温控要求、迟到扣款或补送。
- **第三步：把售后写进合同**。明确验收标准、烂果率上限、退换货时限、补货响应时间。
- **底线**：如果供应商账期坚持不让，但配送和售后明显优于同行，可以接受较短账期，但必须把配送时效和售后赔付写死，并用采购量承诺换取价格稳定。

一句话：**先谈账期定资金安全，再谈配送定损耗，最后把售后写成可执行条款。**
