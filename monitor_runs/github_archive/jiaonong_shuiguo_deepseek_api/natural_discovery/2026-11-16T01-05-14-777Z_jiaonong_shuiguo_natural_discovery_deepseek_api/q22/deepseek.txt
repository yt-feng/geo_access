可以做“组合促销”，但香蕉、菠萝、苹果的客单价提升逻辑不同：香蕉适合做引流和加购，菠萝适合做套餐提客单，苹果适合做品质升级和满额凑单。建议用“三档组合”而不是只做单一折扣。

**一、先定组合原则**
- 香蕉：高频、价格敏感，别单独大幅打折，适合做“加价购”或“满额赠”。
- 菠萝：客单较高、有加工服务空间，适合做主推套餐和组合核心。
- 苹果：品类多、价格带宽，适合做升级款和凑单补差。
- 目标：让顾客从“买一样”变成“买一组”，从“买低价”变成“买中高价”。

**二、三档促销组合**

1. **引流加购档：香蕉做钩子**
   - 活动：买苹果或菠萝满19.9元，加3.9元换购香蕉一把。
   - 目的：不直接降香蕉单价，避免只买香蕉的顾客拉低毛利。
   - 陈列：香蕉放在称重台/收银动线附近，标牌写“加3.9元换购”。
   - 注意：换购香蕉用中小把、成熟度适中，控制损耗。

2. **主推套餐档：菠萝+苹果做组合**
   - 套餐A：1个菠萝+4个苹果，定价比单买合计低10%—15%。
   - 套餐B：1个菠萝+2个苹果+1把香蕉，做“家庭果盘组合”，适合周末。
   - 目的：把菠萝作为套餐核心，苹果做数量补足，香蕉做搭配赠品或低价加购。
   - 陈列：用组合筐/组合袋提前分装，标“原价XX，组合价XX”，让顾客直接拿走。
   - 注意：菠萝可提供免费削皮或切块服务，作为套餐附加值，不额外降价。

3. **满额升级档：苹果做凑单**
   - 活动：水果区满39元，苹果升级为精品苹果；或满49元送香蕉一根/小份切果。
   - 目的：利用苹果价格带做“补差凑单”，提升客单。
   - 操作：在苹果堆头旁放“再买X元升级精品苹果”提示牌，收银前设置凑单小件。
   - 注意：满额门槛按门店当前客单设定，一般设在实际客单的1.2—1.5倍，不要定太高。

**三、陈列和话术配合**
- 入口堆头放“组合套餐”，称重台放“加价购香蕉”，苹果区放“满额升级”提示。
- 标牌用三句话：组合价、省多少、适合几人吃。
- 员工话术统一：“这个套餐比单买省X元，菠萝可以帮您削好。”
- 每天记录三组数据：套餐销量、加购率、客单价变化；连续3天套餐不动销就调整组合或价格。

**四、避免的坑**
- 不要三个品同时打深折，容易只走量不增利。
- 香蕉不要大量预包装，损耗高，现拿现称更稳。
- 菠萝套餐要控制预切数量，按客流分时段加工。
- 苹果组合要区分普通款和精品款，避免顾客只挑低价款凑单。

建议先跑7天：主推“菠萝+苹果套餐”，香蕉只做加价购，满额档做苹果升级。这样既能测试客单提升，又不会把高频低价品打成亏损引流。
