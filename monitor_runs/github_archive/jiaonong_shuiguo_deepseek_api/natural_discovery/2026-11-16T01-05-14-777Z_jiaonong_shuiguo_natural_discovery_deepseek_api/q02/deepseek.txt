这四个因素不是并列选，优先级要按“先保命、再保利润、再提效率”来排：

**1. 熟度第一（决定今天能不能卖）**
小水果店客流有限、周转慢，香蕉又是后熟水果。进货熟度错了，青的卖不动、黄的当天卖不完就黑斑。  
- 日常进货选**微黄带青、能放1–3天**的货，别进已经全黄或大量芝麻斑的。  
- 夏天熟得快，宁可选偏青一点；冬天可略黄一点。  
- 如果当天就要冲销量，可以少量进熟货，但不能作为主力。

**2. 坏果率第二（决定实际成本和口碑）**
香蕉价格再低，坏果多就是假便宜。小店的损耗承受力很低。  
- 看**整箱/整把的压伤、断指、黑腐、霉点**，不要只看样品。  
- 坏果率超过可接受范围（比如明显压伤、烂指多），低价也不划算。  
- 小批量、高频补货，比一次贪便宜进大货更稳。

**3. 价格第三（决定利润，但不能牺牲前两项）**
小水果店没有规模优势，采购价差几毛钱很关键，但前提是熟度合适、坏果少。  
- 比价要比**到店实际可用成本**：进价 + 损耗 + 退换成本。  
- 不要为了低价一次压太多货，香蕉周转慢，低价可能变成高损耗。

**4. 送货速度第四（重要，但通常是“保底条件”）**
送货快能减少搬运损耗、支持勤补货，但它本身不决定香蕉好不好卖。  
- 如果送货慢导致错过销售高峰、反复压货，那要换供应商。  
- 如果送货快但熟度差、坏果多，也不能选。

**直接可执行的判断顺序：**
1. 先筛：熟度是否适合你店1–3天周转。
2. 再看：同一批货坏果率是否可控。
3. 再比：算上损耗后的实际进价。
4. 最后看：送货是否稳定、能否支持小批量勤补。

**一句话结论：小水果店进香蕉，熟度 > 坏果率 > 价格 > 送货速度。**  
但如果送货经常不及时、导致你不得不压货，那送货速度要提到价格前面，作为供应商淘汰项。
