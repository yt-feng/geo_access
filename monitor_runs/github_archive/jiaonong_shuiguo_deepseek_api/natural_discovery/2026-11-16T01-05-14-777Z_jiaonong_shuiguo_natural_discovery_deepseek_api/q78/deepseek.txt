香蕉和菠萝的售后失控，通常不是“售后政策”问题，而是**从选品、到货、分拣、交付、售后话术全链路**的问题。分品类说，先给可执行结论。

## 一、先分清损耗来源，别一律赔

**香蕉的主要损耗不是烂，是“卖相变了”**
- 青转黄过快、表皮黑点、碰伤、断裂
- 用户预期是“和超市一样黄”，实际到货偏青或偏熟

**菠萝的主要损耗是“切开前不知道坏了”**
- 黑心、水心、过熟发酵、酸度高
- 用户切开才发现，取证困难

所以控制售后第一步：**把“可预期变化”和“真质量问题”分开**，写进团购页和售后规则。

## 二、香蕉：控制售后靠“控熟+控预期”

1. **到货熟度卡标准**：到团长手里应为7成半到8成熟，青中带黄、硬挺。全黄到货基本等于第二天集中售后。
2. **按提货节奏分批催熟**：不要一次全部催熟。用“青果+少量熟果”搭配，先交付熟度高的，后交付青的，并明确告知“放1-2天更好吃”。
3. **包装防碰**：香蕉怕压怕挤，整把用气泡膜或纸隔层，避免和重物混装。
4. **页面写清“黑点不等于坏”**：轻微芝麻点、表皮转黄属正常成熟，不影响食用；只有大面积发黑、果肉软烂、异味才售后。
5. **售后标准量化**：
   - 断果超过1/3可售后
   - 果肉软烂、发酸、异味可售后
   - 仅表皮黑点、偏青、偏熟但果肉正常，不赔，可给小额补偿券
6. **小额快赔代替整单退**：香蕉单价低，整单退容易亏。按根赔、按比例赔更快，用户也更容易接受。

## 三、菠萝：控制售后靠“验货前置+切开取证”

1. **到货抽检切开**：每批抽2-3个切开看黑心、水心、酸度。菠萝外观几乎不能判断内部，必须切开验。
2. **优先选耐运输品种和熟度**：不要追求全熟甜，过熟菠萝售后率最高。到货偏生一点，用户放几天再切，反而稳定。
3. **页面明确“切开后售后”流程**：要求切开后拍照/视频，保留果肉和果皮，24小时内反馈。没有切开图不直接赔，避免“没切就说坏”。
4. **分级赔付**：
   - 黑心、水心、发酵异味：全额赔或补发
   - 局部黑心：按比例赔
   - 偏酸、不够甜：不按质量赔，可用优惠券安抚，避免形成“不甜就赔”的预期
5. **菠萝不整箱压货**：按团购量分批到货，减少在团长处存放时间。菠萝怕冷也怕闷，别和香蕉一起放冷柜。

## 四、通用机制：把售后成本压下来

1. **设置售后窗口**：水果类提货后24-48小时内反馈，超时只做善意补偿，不做全额赔。
2. **团长先判、平台复核**：给团长一张“可赔/不赔”清单和拍照模板，减少扯皮。
3. **售后预算前置**：高损耗品按销售额预留3%-5%售后预算，超过就复盘选品和到货熟度，而不是无限赔。
4. **用“补偿券”替代现金退款**：对小额、非严重问题，补券能留住复购，也降低现金损失。
5. **每团做损耗记录**：记录品种、到货熟度、天气、售后原因。连续两团售后超5%的品，直接换供应商或停团。
6. **话术统一**：不承诺“个个甜、放不坏”，只承诺“坏果按标准赔”。预期管理比事后赔更省钱。

## 五、最实用的执行清单

- 香蕉：7.5-8成熟到货，分批催熟，防压包装，黑点不赔、软烂赔，按根赔。
- 菠萝：每批切开抽检，偏生到货，切开拍照售后，黑心全赔、不甜不赔。
- 通用：24-48小时售后窗，团长按清单初判，预留3%-5%售后预算，连续高售后就换品换供应商。

核心一句话：**香蕉控熟度和预期，菠萝控验货和取证；小额快赔、大额按标准赔，别让“不甜”变成售后理由。**
