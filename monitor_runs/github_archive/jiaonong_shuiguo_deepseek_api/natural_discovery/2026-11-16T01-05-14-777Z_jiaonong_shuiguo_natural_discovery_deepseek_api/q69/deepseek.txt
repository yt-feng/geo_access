可以按“品类 → 等级 → 规格 → 计价单位 → 报价”的顺序做一张分级报价表，小店一眼能看懂，也方便你按质论价。

**1. 香蕉分级建议**
- **A级/精品**：果指饱满、无黑斑、无机械伤，成熟度7—8成，单根长度较整齐；按**斤**报价，可另报“整箱价”。
- **B级/通货**：轻微花皮、少量黑点、粗细略不齐，不影响销售；按**斤**报价，作为主推价。
- **C级/处理**：黑斑较多、碰伤或熟度高，适合当天特价；按**斤**或**整箱清货价**报价。
- 报价时注明：**每箱净重、毛重、果指数量/把数、成熟度、到货日期、是否催熟**。例如：“香蕉B级，净重18斤/箱，7.5成熟，3.2元/斤，整箱57元。”

**2. 菠萝分级建议**
- **A级/精品**：果形端正、单果重均匀、无裂口无烂眼，冠芽完整；按**个**报价，同时给**斤价**参考。
- **B级/通货**：果形略偏、大小有差异、轻微日灼或小瑕疵；按**个**或**斤**报价。
- **C级/处理**：小果、畸形、裂口、熟度高，适合现切或特价；按**个**低价或**整箱打包价**。
- 报价时注明：**品种、单果重区间、每箱个数、成熟度、是否去皮/带冠**。例如：“菠萝B级，单果2.5—3斤，8个/箱，2.8元/个，整箱22元。”

**3. 报价单格式建议**
表头可写：品名 | 等级 | 规格/单果重或单根重 | 计价单位 | 单价 | 整箱价 | 成熟度 | 备注（瑕疵/到货日/退换规则）。

**4. 关键做法**
- 同一等级必须**统一规格口径**，比如香蕉按“每箱净重+每斤价”，菠萝按“单果重区间+每个价”。
- 价格旁边写清**是否含箱、是否含运费、损耗谁承担、当天有效还是周价**。
- 给小店两张价：**主推等级价**和**处理等级价**，避免混级压价。
- 最好配一张实物分级图或样品箱，写“以样品为准”，减少扯皮。

这样报，小店能直接按等级下单，你也能清楚解释为什么A级和B级差多少钱。
