水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格”和“有没有货”，而是下面这些会直接影响损耗、复购和现金流的细节：

1. **同一批次内的稳定性，而不是只看样品**
   最容易忽视：供应商给你看的样品很好，但实际到货大小、成熟度、甜度、颜色不齐。
   建议：连续看3—5批货，记录“到货合格率、同级果比例、次果率”，不要用一次样品定供应商。

2. **成熟度和货架期的匹配**
   水果不是越熟越好。你要看供应商发货时的成熟度是否适合你的销售周期：当天卖、2—3天卖、还是可冷藏周转。
   最容易忽视：到货很漂亮，但只能放1天，第二天集中软烂，损耗反而更高。

3. **产地、分级和包装是否可追溯**
   要问清：产地具体到县/基地、采摘时间、分级标准、装箱规格、是否混级。
   最容易忽视：只谈“产地直发”，但没有稳定分级，导致同一箱里大小果混装，影响定价和复购。

4. **损耗责任和售后规则**
   长期合作一定要提前明确：烂果、压伤、短重、成熟度不符怎么赔，拍照时效、报损比例、补货还是扣款。
   最容易忽视：口头说“有问题找我”，真出问题时没有标准，最后自己承担损耗。

5. **冷链和运输细节**
   看供应商是否真能做到预冷、冷链车、温控记录、装卸规范。尤其浆果、荔枝、樱桃、葡萄等。
   最容易忽视：只问“是不是冷链”，不问“从采摘到装车多久、运输温度多少、到货温差多大”。

6. **供货节奏和淡旺季能力**
   长期稳定不只看旺季有没有货，更要看淡季、雨天、节日、产区减产时是否还能按约定供货。
   最容易忽视：供应商平时便宜，但节前优先供大客户，你的订单被延期或降级。

7. **结算方式和价格机制**
   要明确是随行就市、锁价、保底价还是代销；账期、押金、返利、运费谁承担。
   最容易忽视：低价背后是现款现货、不包运费、不包损耗，综合成本并不低。

8. **供应商的客户结构**
   他主要供商超、批发市场、社区团购还是餐饮？不同客户对分级和成熟度要求不同。
   最容易忽视：供应商主要做大流通，给你做精品店，分级和包装可能不匹配。

9. **异常处理速度**
   水果生意时间敏感，坏一批货能不能当天补、次日补，比赔偿金额更重要。
   建议：合作前试一次“小问题”，看对方响应速度和处理态度。

10. **是否过度依赖单一供应商**
    长期稳定不等于只找一个供应商。至少保持“主供+备用”结构，主供占60%—70%，备用能补急单。
    最容易忽视：主供一停，门店直接断货或被迫高价拿货。

可执行判断标准：
- 连续5批到货合格率是否稳定在你能接受的水平；
- 报损是否在约定范围内且售后响应及时；
- 同一规格是否长期稳定，不用每次重新定价；
- 旺季和异常天气下是否仍能按约供货；
- 综合成本是否包含运费、损耗、账期后的真实成本。

一句话：选水果供应商，重点看“稳定分级、成熟度匹配、损耗责任、冷链执行、异常补货能力”，而不是只看报价单。
