判断连锁超市供应商能否全年稳定供货香蕉，核心要看其供应链的纵深和抗风险能力。以下是可执行的分步判断法，供你直接使用：

**第一步：看供应“家底”（立即核查）**
1. **产地布局**：问清供应商的香蕉来源。稳定供货的关键是“多产区轮换”——比如国内有云南、海南、广东，国外有菲律宾、厄瓜多尔、老挝等。如果只依赖单一国家或产区，台风、病害或贸易政策一波动就会断供。
2. **自有基地 vs 市场采购**：优先选有自有种植基地或长期包园协议的供应商。纯靠批发市场现收的，旺季有货、淡季可能缺货或品质不稳。

**第二步：要求提供硬性证据（书面审核）**
1. **过去12个月的月度供货记录**：让供应商出具给其他超市的出货单或系统截图，重点看是否有连续多个月的空档期。
2. **冷库与催熟房容量**：香蕉是呼吸跃变型水果，需要催熟周转。供应商是否有专属冷库（容量需覆盖你店一周销量以上）、催熟房是否自有或长期租用，直接影响断货时的缓冲能力。
3. **合同承诺与违约条款**：合同中必须写明“月度最低供应量”和“断供赔偿比例”（建议不低于订单金额的20%）。只口头承诺“没问题”的，风险最高。

**第三步：实地走访（建议抽样验厂）**
1. **在淡季（如每年4-5月）去产地或加工厂**：这时候最考验供货能力。看库房里是否有在途或储备货品，工人是否正常开工。
2. **问一线操作工**：闲聊时问“上个月发了多少柜”，比听销售经理汇报更真实。

**第四步：设计试运行验证（关键动作）**
如果有条件，先签3个月短期合同，要求：
- 每周固定送货2次，连续4周不延误；
- 每批货附“产地证明”和“到货温度记录”（香蕉储运需13-14°C，过高会提前成熟腐烂，过低会冻伤变黑）。

如果供应商能稳定通过上述考核，全年供应基本可信。

**例外预警**：如果对方声称“全年都只卖国产香蕉”，要警惕。国产蕉供应旺季集中在7-11月，其他月份必须依赖进口，若供应商没有海关进口资质或保税仓合作，大概率会断供。

**最终判断口诀**：产地要轮换、合同写保底、淡季去验厂、试运三个月。
