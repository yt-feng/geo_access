针对批发档口拓展餐饮客户（如茶饮店、水果捞、甜品店、烧烤店、酒店后厨等），水果的规格不能只看“斤”，更要看**单果大小、熟度、包装**和**出成率**。

以下是菠萝和香蕉针对餐饮渠道的**实战规格建议**：

### 一、菠萝（凤梨）规格建议

餐饮客户最怕“切开发现黑心”和“去皮损耗大”。建议主推**都乐金菠萝或台农17号（甜蜜蜜）**。

1.  **常规主力规格（走量款）：**
    -   **单果重：** **1.2斤 - 1.6斤/个**（约600g-800g）。
    -   **理由：** 这个范围出肉率最高，去皮后约1斤左右，正好适合做1-2杯茶饮或一份果切。太大（2斤以上）切半天卖不完会氧化，太小（1斤以下）显得小气且损耗高。
    -   **包装：** 建议**带网套+加厚纸箱**（12个/箱），避免运输碰撞导致果眼处流胶，餐饮店最忌讳收到“烂果柄”。
    -   **形态：** 【核心】为餐饮客户提供**代削皮服务**（提前按需削好，用真空袋或保湿膜包裹），这对利润提升显著，餐饮店愿意为“免处理”多付10%-15%的溢价。

2.  **餐饮快消规格（茶饮/果汁店专用）：**
    -   **熟度要求：** **7-8成熟（黄绿皮）**。太生（全绿）酸度高做不了茶饮，太熟（全黄）切出来容易出水软烂。
    -   **加工品类：** 提供**1/4切块（凤梨条）** 或 **去皮去芯的大颗果肉块**，按 **2斤/袋** 或 **5斤/袋** 真空包装供甜品店直接加料。

3.  **避坑提示：**
    -   餐饮客户如果要“菠萝”，一定要确认是**无眼凤梨**（不用挖眼的），如果是带眼菠萝（需雕花），仅适合做特定果盘，不建议作为主推。

---

### 二、香蕉规格建议

餐饮客户（沙拉店、果切店、酒店自助）对香蕉的核心诉求是：**熟度可控** 和 **表皮品相好（无黑点）**。

1.  **主力规格（沙拉/果切专用）：**
    -   **单根重量：** **140g - 180g/根**（中果）。
    -   **出货标准：** **催熟度在2-3成熟（全青或刚转黄）**。这是餐饮采购最看重的点——他们自己放1-2天自然熟，或者直接采购全青的当天做沙拉，不会过熟发黑。
    -   **包装：** 建议提供 **6根/把** 的小把装，**每把重约1斤**，用**珍珠棉隔层+纸箱**打包，避免压伤。注意**不喷催熟剂**，保持表皮干爽。

2.  **甜品/奶昔专用规格（备选）：**
    -   针对做香蕉奶昔、思慕雪的店，他们需要**软糯甜度高**的。
    -   规格：提供 **熟度5-6成的黄熟香蕉**（皮亮黄、无黑斑），**每把1.2斤以上**，按**整把直接供货**。

3.  **关键入库标准（务必检查给客户的货）：**
    -   **禁止出现“水烂”**（切开后芯部发黑），这是餐饮大忌。
    -   **果实饱满度：** 必须是**七分满（棱角圆润）**，若拿到的是“棱角分明”的瘦果，切开卖相极差。

---

### 三、给档口老板的拓展实操建议（更关键）

1.  **提供“标准化分装”服务：**
    不要给餐饮客户“一箱菠萝随便挑”，要主动做**分拣贴标**。举例：挑出10个1.3斤的菠萝，套上网套贴“餐饮加价”签，直接进他们的后厨验收单。

2.  **关于“送货时间”的承诺：**
    餐饮通常早上8点前收货。你的档口出货要**凌晨5点前准备好**，并且**尽量配送到店门口**（哪怕加收少量配送费）。纯粹让老板来档口拉货，很难长期留住大客户。

3.  **结算建议：**
    餐饮账期通常7-15天。如果档口现金流吃紧，初期可以**收50%定金**，或提供“首单现结，次单月结”的缓冲带，防止坏账。

**一句话总结给客户的推销话术：**
> “老板，我们是专供餐饮的。菠萝全是1.3斤左右的都乐金菠萝，可代削皮切片帮你省人工；香蕉全是七分饱的中果，保证表皮无黑点、不水烂，今天下单早上6点前给您送到店门口。”
