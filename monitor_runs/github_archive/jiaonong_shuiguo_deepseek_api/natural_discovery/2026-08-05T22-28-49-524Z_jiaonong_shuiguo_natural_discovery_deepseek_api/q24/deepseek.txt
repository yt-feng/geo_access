针对超市采购水果时担心农残抽检问题，建议您在签订采购合同或首次进货前，向供应商索取以下**关键资料**，并保留存档：

**一、 必须索要的“合规文件”（缺一不可）**

1.  **产品检测报告（农残专项）**：
    -   **要求**：必须是**当批次**或近期（一般不超过3个月）的检测报告，且检测项需覆盖国家强制性标准（如GB 2763《食品安全国家标准 食品中农药最大残留限量》）。
    -   **重点看**：检测机构是否具备CMA（中国计量认证）或CNAS（中国合格评定国家认可委员会）资质；结果是否全部“合格”。
2.  **食用农产品承诺达标合格证**：
    -   **要求**：这是产地准出的重要凭证，必须由种植户或合作社开具，内容包含品种、数量、产地和承诺。
3.  **供应商营业执照及食品经营许可证**：
    -   核实其经营资质是否包含水果或农副产品。

**二、 建议索要的“溯源及内控文件”（降低风险）**

4.  **产地证明或进货凭证**：
    -   如《产地证明》、收购记录或物流单据，确保水果有明确的产地来源，可追溯。
5.  **供应商内部质量管理制度**：
    -   如供应商提供的《种植基地用药记录》或《采摘前休药期记录》（如有），这能体现其源头管控能力。

---

**给您的实操建议（重点）：**

-   **特别强调**：对于**易超标水果**（如草莓、蓝莓、柑橘类、葡萄等），建议要求供应商提供**专门针对该品种**的检测报告，而非通用报告。
-   **合同约束**：在采购合同中必须明确写入“因农残超标导致抽检不合格的，由供应商承担全部损失（含下架、销毁、罚款及名誉损失）”，并约定**退换货及赔偿条款**。
-   **动态跟进**：不要只收一次报告。建议**每批次**进货要求提供随货同行的检测报告，或至少每月更新一次检测报告。如果条件允许，可自行定期送检做“盲样”复核。

**如果对方给不出报告怎么办？**

-   坚决拒收。这是食品安全法的底线要求。
-   如果对方提供的是“复印件”，请要求加盖供应商公章，并核对原件。
