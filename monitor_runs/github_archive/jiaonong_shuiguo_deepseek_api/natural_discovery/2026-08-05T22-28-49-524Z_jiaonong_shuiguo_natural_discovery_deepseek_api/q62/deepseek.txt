判断一批香蕉的熟度和坏果风险，是批发商控制损耗和利润的关键。以下是一套**可立即上手**的实操判断流程，分为“未开箱”和“开箱验货”两个阶段。

**一、未开箱时的“看、闻、掂”判断**

1. **看外观（箱体）**：
   - **箱身是否潮湿或有水渍**：说明运输途中可能受挤压或冷库结露，内部易滋生霉菌（炭疽病）。
   - **箱体有无异味（酒精味、酸味）**：凑近箱缝闻，如果有明显的发酵酒精味，说明内部已有大量裂果或过熟果，风险极高。

2. **掂重量（估算水份）**：
   - **比较箱子重量**：如果箱子异常沉重，可能被淋水（增重但易烂）；如果异常轻，可能已风干脱水，果皮发黑。

**二、开箱验货的四个核心指标（重点）**

到达仓库后，按“**看把、看果、捏果、切果**”四步走：

1. **看“蕉把”（果柄）**：这是判断新鲜度的**第一信号**。
   - **深绿色、饱满** → 刚采摘不久，新鲜。
   - **发黑、干枯、断裂** → 储存时间长或受过冻害，果肉内耗大，熟度不均风险高。

2. **看“棱角”与“颜色”**：
   - **棱角分明** → 太生，可能难以催熟，或催熟后口感发涩。
   - **棱角圆润、颜色黄绿相间（黄中带绿）** → 这是**最佳收货标准**，适合批发后再催熟。
   - **全黄或出现黑点（芝麻点）** → 已经成熟或过熟，必须当天或次日售出，否则报废。

3. **捏“果身”**：
   - **硬如石头** → 过生。
   - **有弹性、按下去可回弹** → 合适。
   - **软塌、手捏有积水感** → 内部已变软腐烂，不能留。
   - **特别提示**：不要只捏顶部或底部，要捏**香蕉中段**，这个部位最能反映整体熟度。

4. **切“果肉”看心部**：
   - 随机切开1-2根香蕉的**中段**。
   - **果肉呈乳白色、中心无黑点** → 健康。
   - **中心有黑心或褐变色** → 受寒或内部病变，催熟后极易全批烂损。

**三、坏果风险预判（经验公式）**

| 迹象 | 风险等级 | 处理建议 |
|------|---------|---------|
| 箱内有大量“**裂果**”（果皮爆开） | 高（已产乙烯催熟整箱） | 立即拆箱分拣，裂果挑出，整箱降价或急售 |
| 果柄发霉（白霉/黑霉） | 中高（炭疽病） | 单独存放，尽快销售，避免传染相邻好果 |
| 果身有**黑色圆形凹陷斑**（蓟马咬伤） | 低（仅外观疤） | 不影响熟度，但影响卖相，需折扣处理 |
| 手感**发凉且僵硬**（冻伤） | 高（催熟后必黑） | 拒绝收货，或立即退货 |

**四、收货后的风险控制建议**

- 如果批货**偏生（棱角明显）**，不要急于催熟，放在 **13-14℃ 的阴凉通风处**自然后熟，切忌放冷库（会冻伤变黑）。
- 如果批货**偏熟（全黄）**，必须当天分拣，将**有斑点的香蕉**单独挑出，避免它们释放乙烯加速整柜成熟。
- **催熟技巧**：如果判断熟度在7-8成（黄中带微绿），可用**苹果或乙烯利**催熟，但必须在**20-25℃**下密闭24小时，避免温度过高导致“硬心”。

---

**最后提醒**：如果是陌生供货商，**务必先拆2-3箱抽检**，不要只检查顶部。很多果商用“上熟下生”或“上大下小”的方式混装，开箱时最好把箱底翻出来看看。
