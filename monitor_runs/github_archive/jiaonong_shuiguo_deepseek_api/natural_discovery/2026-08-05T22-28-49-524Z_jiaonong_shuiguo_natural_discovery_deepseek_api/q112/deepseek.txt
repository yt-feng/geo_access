在水果采购合同中，**坏果率（含腐烂、变质、严重损坏）的赔付标准没有法律强制数值**，主要靠双方协商约定。实操中，常见做法如下：

**1. 建议的合理赔付阈值（供参考）**
- **优质精品果/高端水果**：坏果率超过 **2%** 即可要求赔付（行业惯例通常≤1%）。
- **普通大货/产地直采**：坏果率超过 **5%** 应启动赔付（常规合格线通常在3%—5%）。
- **明显低质/库存果**：超过 **8%** 即可认定质量不合格，可要求全额退换或降价。

> 如果合同没有约定，一般司法实践倾向于**超过5%**作为“明显瑕疵”的参考线。

**2. 赔付计算方式（建议写入合同）**
- **按比例扣款**：例如，坏果率每超1%，扣减该批次货款总额的2%—3%。
- **退换货**：超过约定标准时，卖方应在3日内补发等量好果。
- **拒收**：现场验货时坏果率超过15%—20%，可直接拒收整批。

**3. 特别注意**
- 合同中必须明确“坏果”定义（如：果蒂发霉、流汁、严重软烂、机械伤超过单果面积1/3）。
- **需设定“产地损耗免责”**：运输自然挤压、轻微碰伤通常不计入赔付范围。
- 收货后**务必在24小时内开箱抽检并留存视频/照片**，超过期限可能丧失索赔权。

**行动建议**：  
如果合同尚未签订，请立即补充条款：“现场或到货24小时内，坏果率超过X%的，按每超出1%扣减总价款X%”。  
如果已签订且无约定，可依据《民法典》第582条主张“质量不符合约定”要求合理扣减价款，但举证难度较大。
