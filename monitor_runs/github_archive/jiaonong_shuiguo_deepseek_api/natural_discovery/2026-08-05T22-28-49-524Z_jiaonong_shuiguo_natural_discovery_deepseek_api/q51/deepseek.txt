对于茶饮店来说，**固定产地和供应批次（或可靠供应商的稳定供应）是必须的，且应作为采购的核心策略**。原因如下：

1. **口味稳定性是品牌生命线**
   - 水果（尤其是芒果、橙子、草莓、柠檬等）受产地气候、土壤、采摘成熟度影响极大。同一品种，山东的苹果和陕西的苹果味道不同；同一果园，今年和明年的甜度、酸度也可能有差异。
   - 如果客户今天喝到的招牌“杨枝甘露”偏酸，明天喝到的偏甜，他们会认为配方变了、品质不稳定，从而流失。

2. **降低“批次波动”风险**
   - 即使固定产地，采收季节、催熟方式、运输时间不同，风味也有差异。
   - **固定“供应批次”**意味着与供应商约定：按订单配送的同一批水果需来自同一果园、同一采收期、同一加工线。这样能确保在你消耗完该批次前，出品一致性高，也便于你根据批次特点微调配方（比如甜度略高时减少糖浆）。

3. **采购实操建议**
   - **首选产地直采协议**：与固定农场的供应商签长约，明确品种、成熟度标准（如糖度/Brix值、酸度区间）。
   - **设置“双产地备选”**：例如芒果主用海南产的，但为应对台风季断供，锁定越南或泰国产地的备用供应商。**但备用产地也要提前做口味盲测**，确保大致匹配。
   - **建立“批次验收标准”**：到货时检查果重、色泽、甜度仪器读数，留存样品。不符合标准的批次拒收或要求换货。
   - **预留安全库存**：当核心水果果季交替（如早季转晚季）时，提前囤够过渡期用量，避免青黄不接。

4. **如果无法完全固定**
   - 小本经营或季节水果（如荔枝、杨梅）无法全年固定，建议**因季更新菜单**，并主动告知客户“季节限定”风味差异，透明反而增加信任。

**结论**：能固定就固定，特别是招牌菜单用的高频水果。如果因成本或供量原因无法完全固定，至少要做到“同一批售完再换下一批”，并记录每批次的糖度/酸度数据，用于小范围微调配方（如加糖或加柠檬汁平衡），而不是让口味随机波动。
