社区超市经营水果，核心是**“以销定进，快进快出”**。要同时控制新鲜度和库存，不能靠猜，必须靠**数据+流程**。以下是可执行的操作方案：

### 一、 采购端：控制源头，少进勤补
1.  **按销量定采购量（7天滚动法）**：不要按周进货，按**未来3天**的预估销量进货（周末量加大30%）。例如：上周一卖50斤苹果，这周一就订50斤，宁可缺货也不多订。
2.  **分级采购**：将水果分为**引流款**（如香蕉、当季特价，毛利低但走量大）和**利润款**（如进口提子、精品礼盒，毛利高但易损耗）。引流款每日补货，利润款每周补2次。
3.  **签订“隔日换”协议**：与供应商谈**“48小时退换”**——如果早上进的水果当天没卖完，部分品种（如绿叶菜、草莓）可退回或换新，这是控制损耗最有效的合同条款。

### 二、 门店端：动态管理，先入先出
1.  **“先进先出”+“翻堆”制度**：上货时必须把旧货摆上面/前排，新货放下面/后排。**每天早、晚各翻一次堆**，把品相变差但还能卖的水果挑出做“特价处理区”，防止烂在货架底端。
2.  **分级降价“三段式”**：
    - 品相最佳：正常价。
    - 轻微发软/有斑点（未坏）：**当日下午4点**打8折。
    - 熟透/轻微碰伤：**晚间7点**打5折或按盆/袋卖（如“10元3斤”），**当晚必须清空，绝不过夜**。
3.  **高损耗水果“小包装/盘装”**：对草莓、蓝莓、樱桃等易损品，不整箱卖，拆分成小盒装（0.5斤/盒），减少顾客翻捡造成的二次损伤。

### 三、 库存端：可视化看板，每日清零
1.  **制作“每日水果库存看板”**（在白板或Excel表上）：
    - 列出所有果品，分三栏：**今日进货量 | 昨日剩余量 | 今日需处理量**。
    - 设定**安全库存警戒线**：单价高的（如榴莲）只备1-2个；大众果（如苹果梨）备2天量。
2.  **每日营业前10分钟“清点+定价”**：早上一开门先看昨晚剩余的数量。如果某果品库存**超过3天销量**，当天立即做“买一送一”或“满减”，而不是等坏了再处理。
3.  **“1+2”补货法**：每次补货只补**陈列量的1/3**。货架空了再补，而不是一次性堆满。堆得越满，下面的越容易压坏，且顾客会觉得不新鲜。

### 四、 特殊情况（季节性水果）应对
- **当季爆款（如西瓜、桃）**：采用**“预售+整箱”**模式——门口放一个切开的样品，顾客可预订整箱（当日到货当日提），减少现货库存。
- **极易变质果（如荔枝、山竹）**：**只订不存**，当天早市进，下午卖不完直接做**“空箱撤架”**处理，不硬扛到第二天。

### 五、 关键KPI指标（每周必看）
- **损耗率** = 处理/扔掉的成本 ÷ 总进货成本。**目标控制在5%以内**，超过8%需复盘采购量。
- **售罄率**：如果某果品经常下午就卖光，说明进少了，次日加量；如果晚上还有大量库存，说明进多了，次日减半。

### 六、 执行口诀（每天照做）
> **“早上看剩货，上午推新品，下午调价格，晚上必清空。”**
> 宁少卖十斤，不多压一斤。

**最终原则**：水果店赚钱靠的是**周转率**，不是利润率。压货亏的是本金+空间+顾客信任，**卖光比卖贵更重要**。如果连续一周某水果压货超过2天，立刻停采该品种，换引流新果。
