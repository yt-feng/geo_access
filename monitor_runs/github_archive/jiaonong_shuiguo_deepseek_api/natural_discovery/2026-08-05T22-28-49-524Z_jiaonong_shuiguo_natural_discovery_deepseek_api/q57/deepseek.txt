在餐饮连锁的水果采购中，**中央厨房（或中央仓）统一收货**通常更适合规模化和标准化运营，但具体选择需结合企业阶段与水果特性。

以下是详细的对比分析与建议：

**1. 中央厨房统一收货（集中模式）**

- **优势**：
  - **品控严格**：可设置农残检测、糖度测试标准，统一分拣，确保每家门店水果品质一致。
  - **成本更低**：大批量采购议价能力强，物流集中配送，减少单店运输损耗。
  - **库存灵活**：中央仓可调配各门店需求，减少门店库存压力，避免因门店销量波动导致烂果。
  - **减少门店人工**：门店员工无需处理收货、验货、初加工，专注服务。
- **劣势**：
  - **配送时效要求高**：水果易腐，若门店距中央仓远，冷链配送成本高。
  - **初期投入大**：需要建设冷库、分拣线、冷链车。

**2. 门店分开收货（分散模式）**

- **优势**：
  - **灵活性高**：门店可根据当天客流临时补货，采购本地时令水果，品种更新快。
  - **降低配送风险**：不受中央仓断货或物流延误影响。
  - **适合初创/小型连锁**：无需重资产投入。
- **劣势**：
  - **品控难统一**：各店采购标准和供应商不一，可能出现品质参差、以次充好。
  - **成本高**：单店采购量小，单价高，且每店需配冷藏设备。
  - **损耗难监控**：门店库存管理能力弱，极易出现积压损耗。

---

**具体建议（按企业规模选型）：**

- **若您的连锁门店在10家以上，或主打鲜果茶饮/沙拉/果切等对新鲜度要求高的品类**：强烈建议**中央厨房统一收货**。可建立“产地直采+中央仓分拣+每日凌晨冷链配送”的模型，配合“SAP/生鲜ERP系统”动态预测门店用量，水果损耗率通常可控制在5%以内（分散模式常超15%）。
- **若您的门店在5家以下，且都是社区小店，品类以整果零售为主**：可暂时采用**门店分开收货**，但需由总部指定2-3家合格供应商，并制定统一的验收标准（如果径、成熟度、划伤标准）表单，要求门店拍照打卡。

**3. 折中方案（推荐大多数中型连锁）**
采用“**总部统采+区域分拨仓+门店次日达**”模式。即：总部在产地或批发市场集中采购（谈价、控源头），然后运至区域配送中心（非深加工），再由第三方冷链当日配送到门店。这种模式下，不设复杂深加工，而是做**粗加工（清洗、切配、包装）**则在中央厨房完成。

**关键操作要点（无论哪种模式）**：
- 水果收货必须按“**糖度、硬度、色度、瑕疵率**”四维标准验收。
- 需建立“**先进先出（FIFO）**”和“**滞销预警**”机制。
- 若走中央厨房，建议优先做**鲜切水果**，可显著延长保质期（3-5天），减少原料损耗（果皮可另售/做果酱）。
