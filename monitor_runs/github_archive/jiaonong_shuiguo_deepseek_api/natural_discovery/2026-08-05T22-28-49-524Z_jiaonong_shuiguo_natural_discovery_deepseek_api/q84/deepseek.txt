针对家庭团购水果礼盒，建议以 **“耐放+营养+口感差异”** 为组合原则，优先保证水果新鲜度，同时兼顾老人小孩的接受度。

---

### 推荐组合方案（按家庭需求分档）

**方案一：实用日常型（性价比最高）**
- **苹果 4个 + 橙子 4个 + 香蕉 1把（约5-6根）**  
  - **理由**：苹果和橙子都比较耐放，常温可存一周左右；香蕉是家庭“刚需”，老人小孩都能吃，但香蕉熟得快，建议放在礼盒上部或单独说明“尽快食用”。
  - **搭配技巧**：苹果选红富士（脆甜），橙子选赣南脐橙（酸甜多汁），香蕉选国产大蕉/皇帝蕉（甜度高）。

**方案二：健康营养型（适合有孩子的家庭）**
- **苹果 3个 + 橙子 3个 + 菠萝 1个 + 香蕉 3-4根**  
  - **理由**：菠萝富含维生素C，但需要处理（削皮），可以提醒家庭“可切块泡盐水”；橙子和苹果补足维生素，香蕉补能量。
  - **注意点**：菠萝建议选已成熟（底部金黄）的，否则太酸；如果团购配送时间超过2天，建议菠萝单独用纸包裹防碰伤。

**方案三：精致送礼型（如果预算较高）**
- **苹果 6个（选大果）+ 橙子 4个 + 菠萝 1个**  
  - **理由**：全由耐放水果组成，摆盘好看，不需要急着吃；但缺少香蕉，口感稍单一，可以额外附赠一小袋盐（用于泡菠萝）。

---

### 关键建议（直接可执行）

1. **避免“香蕉+苹果”直接接触**：苹果会释放乙烯催熟香蕉，导致香蕉很快变黑。建议礼盒内用隔层或纸分开，或者把香蕉放在最上层。
2. **菠萝需要特殊处理**：新鲜菠萝外皮锋利，建议在礼盒内附赠一次性手套或削皮刀，并注明“建议削皮后泡淡盐水10分钟再吃”。
3. **重量和包装**：家庭装建议总净重控制在 **3-4公斤**（约6-8斤），这样大多数家庭2-3天能吃完，不会浪费；外盒用硬底纸箱或带通风孔的塑料筐，夏天（或气温>25℃）需加冰袋。
4. **团购话术**（可直接复制用到群公告）：  
   “本周团购：苹果补身、橙子润肺、香蕉润肠、菠萝开胃，一盒吃遍四季味！当天下单，次日达，坏果包赔。”

---

### 不推荐的组合
- ❌ 不要全部选软质水果（香蕉、芒果、草莓）——容易碰撞腐烂。
- ❌ 不要选太多菠萝（超过2个）——家庭处理麻烦，且易刺激口腔。
