生鲜平台做水果“一件代发”，对供应商的仓配能力要求比较高，核心要解决水果的 **“易损、短保、非标”** 三大痛点。具体需要具备以下能力：

---

### 一、 发运前：验收与分级能力
1. **产地/批次质检**：能对每批水果进行糖度、外观（大小/色泽）、农残抽检，并出具检测记录（或第三方报告）。
2. **分级标准化**：能按平台要求的规格（如5斤装、果径XXcm、瑕疵率≤X%）进行机器或人工分级，避免大小混装、熟度不均。

### 二、 打包仓内：保鲜与防损能力
1. **冷链暂存**：仓库具备**分温区冷库**（如苹果/梨0-4℃，芒果/香蕉12-15℃催熟区），至少有预冷设备（强制风冷或压差预冷），确保水果采摘后尽快降温，锁住新鲜度。
2. **特殊包装方案**：
   - 使用**珍珠棉网套/防震托盘/瓦楞纸分格**防挤压。
   - 需配备**保鲜袋+冰袋/吸水纸**（针对需要冷链的水果），对“怕冷”的热带水果（如榴莲、香蕉）需有通风透气包装及保温/防寒材料（冬季）。
   - 能提供**防撞外箱**，面单防水处理。

### 三、 订单履约与发货能力
1. **订单对接系统**：能与平台接口（API）或电子面单系统对接，实现订单审核、面单打印、物流单号回传自动化和实时化。
2. **日发货产能**：能应对平台大促或爆单（如日发货能力≥500单），具备分拣线或熟练打包团队，确保当日16:00前的订单当日发出。
3. **库存同步**：能实时维护平台库存，设置安全库存预警，避免超卖。

### 四、 物流与时效管理能力
1. **快递资源稳定**：与顺丰、京东、中通冷链或产地直发冷链车队有合作协议，能覆盖平台主要销售区域，并保证时效（如省内次日达，跨省2-3天）。
2. **物流追踪与客服**：能实时监控在途温度（若有温度记录仪）和物流异常（延误、破损），并有专职人员处理售后，及时向平台反馈物流单号异常。
3. **批次追溯**：能通过条码或二维码追溯到具体产地、采摘日期、仓内操作人，便于出现品质问题时快速定位并召回。

### 五、 售后处理能力（关键加分项）
1. **坏果包赔机制**：有明确的理赔标准（如坏果率≤5%不赔，5%-10%按比例赔付或退款），并能响应平台售后工单，快速（24-48小时内）完成退款或补发。
2. **残次品处理**：有独立的分拣区处理运输途中产生的压坏、腐烂果，避免混入大货。

---

### 判断优先级建议：
如果只能选一个核心能力，**必须具备“预冷+标准包装+稳定快递”**。这三项决定了到货时水果的“颜值和品质”，直接影响平台评分和复购率。

如果供应商只能做“散装拉走、常温发货”，这种通常无法直接匹配生鲜平台的一件代发需求，建议平台将其降级为“大宗产地直供”或者要求其先整改仓配方案。
