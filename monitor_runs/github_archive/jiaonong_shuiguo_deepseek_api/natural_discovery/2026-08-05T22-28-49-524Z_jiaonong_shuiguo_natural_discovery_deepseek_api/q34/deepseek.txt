在商超采购水果时，**损耗低通常比价格低更影响最终毛利**，尤其是在生鲜品类中。

**核心逻辑在于“毛利率”与“损耗率”的杠杆效应：**

- **损耗的“杀伤力”是加倍的**。假设采购价10元/斤，售价15元/斤，理论毛利率为33%（毛利5元）。如果损耗率是20%，意味着每斤实际可售部分只有0.8斤，实际成本被抬高到12.5元/斤（10÷0.8），此时毛利只剩2.5元，实际毛利率骤降至16.7%，接近腰斩。
- **价格低的让利空间是有限且单次的**。如果价格便宜5%，即采购价便宜0.5元/斤，在无损耗情况下，毛利从5元升至5.5元，提升10%。但若损耗率仅高出3-5个百分点，这些微薄的采购价优势会瞬间被损耗吞噬。

**更具体的决策建议：**

1. **先定损耗红线，再谈价格**。采购时优先评估供货商的新鲜度、成熟度、包装防护、冷链稳定性。同一水果，三天货架期的批次和七天货架期的批次，即使采购价贵10%，只要损耗率能降低5%以上，整体毛利反而更高。
2. **区分品类侧重**。高单价易损耗水果（如草莓、车厘子、蓝莓、荔枝）必须把损耗放在第一位，价格低5%不值一提；而耐储存的苹果、柑橘、瓜类，价格优势可以适度重视。
3. **用“可售成本”倒推采购价**。公式：**可接受的实际成本 = 售价 × (1 - 目标毛利率)**；而 **采购价 = 实际成本 × (1 - 预估损耗率)**。先确定损耗率，再反推能接受的采购价上限，避免只盯采购单价。
4. **考虑退换货条款**。如果供货商承诺包退坏果，损耗的影响会大幅下降，此时价格低的权重可以上升；反之无售后保底，谨慎采购低价货。

**一句话结论：** 在水果这种高周转、高易腐的生鲜里，**损耗率每高1%，对毛利的侵蚀通常远超采购价高1%的让利损失**。控制好损耗，才谈得上价格谈判。
