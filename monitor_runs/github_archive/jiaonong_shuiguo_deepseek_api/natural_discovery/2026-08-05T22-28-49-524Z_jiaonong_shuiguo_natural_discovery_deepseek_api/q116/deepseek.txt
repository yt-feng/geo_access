对于小商家采购水果，**现金结算**和**月结账期**各有不同的风险，核心在于现金流、信任成本和对供应商的议价能力。下面分别说明：

---

### 一、现金结算的风险
**核心风险：资金占用和品质保障缺失**

1. **资金链压力大**：一次性付清全款，如果水果在运输或销售过程中出现大量损耗（如撞伤、腐烂），这笔钱就打了水漂，无法退换或抵扣。
2. **供货商难托底**：部分小供应商在现金模式下“钱货两清”，对售后（如次果率、腐烂率）推诿，甚至可能出现“拿了钱就跑”的极端情况。
3. **容易被动压货**：现金客户有时会被要求“整箱起批”，但作为小商家，你可能卖不完，导致库存积压，水果保质期短，风险陡增。
4. **比价劣势**：现金采购通常是“一口价”，如果供应商觉得你非买不可，可能会报高价，你缺乏周转缓冲期去货比三家。

---

### 二、月结账期（赊账）的风险
**核心风险：账期坏账、关系绑定和隐性成本**

1. **坏账风险**：如果供应商经营不善或人品不佳，可能到月底不认账、少算账甚至跑路。小商家往往没有书面合同，维权成本高。
2. **隐性利息成本**：月结通常意味着供应商会把资金占用成本转嫁给你，水果单价可能比现金贵5%～10%，甚至要求“押一笔保证金”。
3. **限制换供应商**：为了稳住账期，你可能被要求“独家供货”，一旦货品质变差，你很难中途终止，否则要结清余款才脱身。
4. **过度依赖“先货后款”**：如果供货商突然要求结清现货，你手头又没有现金，就会断货，影响正常经营。

---

### 三、给你的实操建议（按风险从低到高）

| 采购方式 | 适用场景 | 风险等级 |
|---------|---------|---------|
| 现金+小额多次 | 新供应商、天气不好（易烂）时 | ⭐低 |
| 现金+当日验货 | 长期合作且品质稳定的本地果农 | ⭐低 |
| 周结（3~7天账期） | 中间商、有一定信任基础 | ⭐⭐中 |
| 月结+合同 | 大型批发市场、正规公司 | ⭐⭐⭐中高 |
| 纯月结无合同 | 熟人介绍但没书面协议 | ⭐⭐⭐⭐高 |

**关键原则：**
- **前期永远现金结算**，连续合作1个月以上且品质稳定，再切换成周结或半月结。
- **月结必须签简易合同**，注明品名、单价、数量、付款日、损耗赔付标准（如“腐烂超5%免单”）。
- **现金结算也要留凭证**，微信/支付宝转账备注“XX水果采购”，避免口头说不清。
- **每次采购前先看行情价**（如当地批发市场当天行情），避免被多收钱。

简单说：**水果易腐，现金风险在“钱”，月结风险在“账”**。小商家建议以“小额现金试货”起步，再逐步过渡到短账期，永远不要相信“先给货后补合同”这类口头承诺。
