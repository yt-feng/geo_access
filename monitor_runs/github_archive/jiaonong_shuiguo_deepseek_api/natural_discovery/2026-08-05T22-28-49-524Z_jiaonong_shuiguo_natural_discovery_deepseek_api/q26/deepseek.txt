针对社区超市想卖小包装香蕉，采购和经营时需特别注意**包装规格**和**损耗控制**。以下是核心实操建议：

### 一、 采购时：包装与选品标准
**1. 包装规格要“按人设计”**
- **分量控制**：小包装建议按 **500g-750g（约3-5根）** 一包，便于单人/小家庭一餐或两餐内吃完，避免剩余浪费。
- **捆扎方式**：优先选**果柄朝下、果实朝上**的托盘或网袋包装；避免用密封保鲜膜紧裹（会加速呼吸作用导致发霉），建议使用带透气孔的PE袋或浅盘+保鲜膜（留出缝隙）。
- **包装材质**：必须有**吸水垫或防潮纸**，防止冷凝水浸泡果柄引发霉变。

**2. 采购时的品质红线**
- **成熟度分级**：现场采购时，**要选“7-8成熟”**（果皮整体微黄、果柄带绿、捏起来有弹性不软烂）。全熟（通透黄）绝不能进小包装，因小包装周转慢，极易在2天内发黑。
- **损伤检查**：**挨个翻转检查**，拒绝有“跌青”（碰撞褐斑）、“果柄发黑”（炭疽病）、“裂口”的香蕉。一根烂会在袋内传染。
- **供应商要求**：让供应商提供**小包装专用分拣线**（人工挑选后按条装盒），并明确：**如果到店后24小时内出现超过5%黑斑，需无条件补货或退款**（写在采购合同里）。

---

### 二、 到店后：防损耗关键动作（比采购更重要）
**1. 到货即处理（黄金2小时）**
- 到货后**立刻拆开所有包装**，平铺在阴凉通风处散热30分钟（香蕉采摘后呼吸热巨大，闷在袋内会迅速腐烂）。
- 散热后，**用干布擦干果柄和果皮表面水汽**，再进行分装。

**2. 陈列与翻包纪律**
- **只拆2-3包面销**，其余冷藏在**13-14℃**的专用果菜柜（低于12℃会冻伤变黑，高于16℃会过快成熟）。**切忌放于冷库风口下**。
- **每日早、中、晚各翻动一次**，将有黑斑、软化的立即挑出，放入“临期特价篮”按5折处理，绝不能混入新包装。
- **“先进先出”**：旧货补在货架前排，新货补在后面，确保最快售出最熟的那一批。

**3. 损耗止损规则**
- 若某天才卖出1/3，**次日必须主动降价促销**（如买二送一），而不是等到变黑降价。
- 设定损耗警戒线：小包装香蕉**正常损耗率应控制在4%-6%以内**。若超过8%，立即调整采购量或批次大小。

---

### 三、 给你的额外建议
- **预售制**：每天上午根据前一日销售数据决定当天进货量，只进“刚刚够卖”的量，宁缺毋滥。
- **包装替代方案**：如果社区内老人多，建议同时准备**“单根散装”**（称重）搭配小包装，顾客可按需拿取，减少因包装强制捆束导致的浪费。

**执行优先级**：先解决“成熟度+到货散热”，这能消除70%的损耗；包装透气性次之。
