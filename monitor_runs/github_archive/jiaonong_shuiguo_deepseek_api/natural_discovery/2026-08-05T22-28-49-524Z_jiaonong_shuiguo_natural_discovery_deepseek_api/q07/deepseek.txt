针对水果店做礼盒，这四样水果的搭配核心是**“颜值、口感、寓意、应季”**。直接给方案，你按这个思路配：

---

### 一、销量最高的黄金搭配（推荐主推款）

**组合：苹果 + 橙子 + 香蕉 + 小番茄/葡萄（替代菠萝）**

- **原因**：苹果（平安）、橙子（心想事成/大吉大利）寓意好；香蕉是“蕉”通“招财”，且价格亲民、走量大；再搭配色彩鲜艳的小番茄或青提，整体视觉效果比菠萝好——**菠萝个头大、刺多且重，放在小礼盒里会挤压其他水果空间，显得杂乱**。
- **定价参考**：按当地行情，总重约3-4斤，卖68-88元，走“平安富贵”礼盒名。

---

### 二、如果坚持要放菠萝（夏季限定款）

**组合：小菠萝（凤梨）切块 + 橙子 + 苹果 + 蓝莓**

- **操作重点**：菠萝一定**去皮去芯切块**，装进透明盒或独立小盒，避免刺伤顾客，也显得高端。
- **售卖说辞**：“热带水果拼盘，酸甜开胃”，适合夏季。
- **注意事项**：菠萝水分大，不能和苹果、橙子同放封闭盒子（会催熟发软），建议菠萝单独隔层。

---

### 三、针对不同人群的差异化搭配

| 场景 | 具体组合 | 卖点 |
|------|----------|------|
| 探病/送长辈 | 苹果 + 橙子 + 香蕉（去掉菠萝） | 低敏、易消化、无硬质酸味 |
| 送孕妇/儿童 | 苹果 + 橙子 + 葡萄/软枣 | 干净、无籽、切片吃更方便 |
| 员工福利/公司团购 | 苹果2个 + 橙子2个 + 香蕉1把 + 小菠萝1个（切块） | 量大实惠，一箱搞定，单价可控 |

---

### 四、避坑建议（非常重要）

1. **菠萝不要和其他水果混装在一个盒子**：它释放的乙烯会催熟香蕉和苹果，导致软烂。要么切块单独放，要么干脆不装。
2. **香蕉一定要选未全熟带点青的**：全熟的香蕉在盒子里憋一天就发黑。
3. **礼盒最上层建议用橙子或苹果打底，香蕉放最下面**：因为香蕉怕压。
4. **标价策略**：不要只卖一种固定配比，推出“88元装（苹果+橙子）”“128元装（苹果+橙子+香蕉+菠萝切块）”等三档，让顾客有选择。

---

### 五、最终推荐动作

- **主推款**：苹果（2个） + 橙子（3个） + 香蕉（1小把） + 石榴/提子（10颗），售价按成本加价40%-50%。
- **备选款**：苹果 + 橙子 + 凤梨切块 + 樱桃，定价高30%，主打“尝鲜”。

记住：**菠萝建议作为附加单品单卖，而不是塞进主礼盒**。先做小份试卖，看顾客反馈再说。
