从损耗角度来看，**鲜果切配**通常比直接买成品果丁损耗更低，但前提是操作和管理得当。具体分析如下：

**1. 损耗构成差异**
- 鲜果切配：损耗主要来自菠萝皮、芯、两端切除（通常占整果重量约40%-55%），以及切配过程中的人为浪费。这部分损耗是“固定成本”，一旦操作规范，可控性强。
- 成品果丁：损耗主要来自供应商加工时的损耗（已内含在采购价中），以及到店后的保鲜期限制（开封后通常只能放1-2天）。如果销量波动，卖不完的果丁会直接变成报废损耗。

**2. 成本对比（以每日用果量为例）**
假设每日需要10kg净果丁：
- 鲜果切配：采购菠萝约需18~20kg（按出肉率50%-55%计算），菠萝采购价通常是果丁的1/4~1/3。虽然多出皮核成本，但总进货价更低。
- 成品果丁：采购价高（含加工、运输、包装成本），且如果当天用不完，剩余果丁按报废处理，损耗率可能达10%-20%（视销量波动）。

**3. 关键风险点**
- 鲜果切配的损耗是“显性”的（皮、芯），容易统计；但需要人工时成本，且切配速度影响出餐效率。
- 成品果丁的损耗是“隐性”的（保质期短、滞销报废），如果门店客流稳定、日销量大且能售罄，损耗率其实更低；反之，小批量门店更容易因卖不完产生报废。

**4. 给你的实操建议**
- **如果门店日销稳定、用果量大（日净果丁≥5kg）且有人手**：优先选鲜果切配。成本可控，且能按需现切，减少二次污染，品质更佳。
- **如果门店日销波动大、人手紧张或场地有限**：选成品果丁，但需做“两次小批量采购”（比如早、晚各订一次），避免囤货；同时设“最佳使用时间”标签，超时未售的果丁立即用于饮品或甜品（如菠萝酱、菠萝汁），减少浪费。
- **无论哪种方式**：建议记录一周的实际报废重量，算清“鲜果损耗率” vs “成品报废率+价差”，两周后就能得出自己门店的最优解。

总结：**同等销量下，鲜果切配的采购成本更低，损耗可控性更强；但成品果丁省人力、省时间。** 硬要二选一，如果贵店能做“当日净果丁全部售罄”，鲜果切配综合损耗更低；否则成品果丁反而更稳。
