第一次做夫妻店，试单的核心原则是：**“少进、勤进、品类聚焦、现金结算”**。千万不要贪多求全，也不要在陌生档口一上来就押大货。

以下是针对香蕉、苹果、橙子的具体试单策略：

**一、 香蕉（风险最高，最考验眼光）**
- **试单量**：**1-2箱**（约30-50斤）。香蕉是呼吸跃变型水果，熟得快，损耗大，夫妻店前期最容易在这里亏钱。
- **看货重点**：不要只看表面黄不黄，要看**“楞”**。棱角分明的是生果，圆润无楞的才是刚好能上架的。**不要拿全熟的（隔夜就黑）**，拿“七成熟”带点青头的，放店里捂两天刚好。
- **试单策略**：问老板要**“统货”**还是**“选货”**？试单阶段一定选选货，虽然贵一两毛钱，但省去你大量挑拣烂把的功夫。
- **关键动作**：当场掰开一根看果肉，**芯发黑坚决不要**。试卖2天，如果动销慢，立刻降价套现，别恋战。

**二、 苹果（最稳妥，但水最深）**
- **试单量**：**2-3箱**（不同品种各一箱）。苹果耐储存，试错成本低，是建立供货关系的“敲门砖”。
- **品种搭配**：第一天别只进一种。用**红富士（走量）** + **嘎啦/金帅（利润款）** 的组合。红富士看卖相，嘎啦看香气。
- **验货重点**：打开箱子翻**底层的**，很多档口表层好果，底层有“虎皮”（果皮褐变）或伤疤。摸表面，发涩的是新果，发滑发油的可能是陈果。
- **试单话术**：直接问：“老板，这批红富士是80#还是85#的？” 能准确报出果径的，基本是行家；含糊其辞的，换一家。

**三、 橙子（试单重点是“试水分”）**
- **试单量**：**1-2框**（或2-3袋）。橙子最怕“干水”和“酸”。
- **核心动作**：**现场切开吃**。不要吃档口切好摆盘里的，自己挑一个小的、一个大的，切开看皮厚，尝酸甜度。**如果老板不让试吃，直接走人**。
- **产地区分**：赣南脐橙果皮较粗糙，湖南橙子果皮光滑但偏酸。试单期不要迷信“产地标”，只相信嘴里的味道。
- **小技巧**：称一下箱子的**皮重**。有些不良档口箱子夹层灌水泥或用超厚湿纸皮压秤，试单时就要求“去皮过秤”或要求“毛重结算”。

---

**四、 试单“铁律”与黄金话术（必看）**

1.  **现金为王**：第一次**绝对不要赊账**。拿着现金去买，老板会把你当长期客户看，给的价格和货品都会更实在。主动说：“咱第一次合作，我先给现钱，靠谱的话下次我固定拿。”（这句话最管用）。
2.  **明确“售后规则”**：付款前当面问一句：“老板，这苹果里面如果翻出两个烂心的，我明早拿过来，您给不给换？” 试单就是测试售后。**同意“坏果包换”的，才是值得长期合作的供应商。**
3.  **建群留底**：加老板微信，拍照记录今天进的货（尤其是香蕉的青度、苹果的红度）。第二天卖不完拍照发给他看，**逼单再进下一批**时，他能给你调更好的货。

**五、 试单心理底线**
- 香蕉试单一次亏100块以内是“学费”，第二次还亏，就是“智商税”。
- 苹果、橙子试单**只要品质达标**，亏在盒装损耗上（表皮花斑），就不要轻易换供货商，因为换新档口重新磨合的成本更高。

**最后建议**：第一次试单，**不要凌晨去**（人少没人理你）。跟着其他拿货多的老手后面，看他们怎么翻货、怎么砍价，转悠半小时再出手。如果一家档口老板在你询问时**主动递烟或请吃水果**，说明他想做长线，这类老板优先合作。
