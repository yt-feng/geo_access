商超做会员日水果活动时，供应商的配合是活动成败的核心。为了确保活动有吸引力、不断货、且不会造成损耗，供应商建议从以下五个维度提前准备：

### 一、 商品与库存准备（核心）
1. **爆款特价定品**：提前与商超确认3-5款会员价水果（如榴莲、车厘子、西瓜、柑橘类），这些单品必须价格有绝对优势（建议低于市场价15%-20%，否则不足以触发会员购买冲动）。
2. **品质分级与分拣**：
   - **活动果**：确保无疤痕、无软果、大小均匀，因为会员日流量大，顾客会随手翻捡，品质差的果会引发大量投诉。
   - **备用果**：针对活动爆款，供应商需准备比预估销量多20%-30%的货源，存放在商超冷库或供应商前置仓，随时补货。
3. **定制化包装**：制作带商超LOGO和“会员专享”标识的专业果篮或预包装盒（如4粒装苹果、6粒装橙子），提高客单价，同时减少现场称重排队时间。

### 二、 物流与冷链保障
1. **分批配送与到货时间**：建议活动当天凌晨或前一日晚间到货，避免清晨高峰到货导致卸货拥堵，顾客无货可买。
2. **冷链温控**：严格监控配送车温度（香蕉11-13℃，草莓2-4℃），并携带**温度记录仪**，到店后与商超收货部共同验收，防止运输中捂坏或冻伤。
3. **应急补货机制**：明确紧急补货响应时间（通常要求4小时内送达），并预留一辆备用冷链车。

### 三、 现场人力和陈列支持（关键）
1. **派驻促销员**：每个爆款单品至少安排1名专职促销员（熟练切块试吃的），负责试吃推广、剥壳去皮（如榴莲、菠萝蜜）、现场吃不完的损耗处理。
2. **陈列道具协助**：根据商超堆头尺寸，提前制作“碰碰果”堆头围板、价格牌、跳跳卡，并准备**喷水保湿设备**（针对绿叶蔬菜类，但水果需注意避免水滴导致霉变）。
3. **试吃品供应**：准备带盖试吃盒、牙签、湿巾，试吃品切好后用保鲜膜覆盖，每半小时更换一次，确保看相好。

### 四、 数据与促销配合
1. **历史数据复盘**：提供过去三个月会员日各单品销量数据给商超采购，帮助精准预估本次订货量（尤其注意会员日一般销量是平日的3-5倍）。
2. **毛利核算清单**：提前制作一份“活动商品毛利表”，明确哪些果是引流亏损、哪些是利润果，方便商超营运决定是否加大扫码购或线上秒杀力度。
3. **线上下单支持**：如果商超有线上到家业务，供应商需提前分拣出小规格包装（如500g装），确保线上爆单时库存能及时锁定。

### 五、 风险预案与损耗控制
1. **雨天应急预案**：如果活动日遇雨天，需准备防雨棚车、已切好的水果预制盒（方便顾客快速拿走），并将堆头从外摆区移入室内。
2. **售后快速理赔**：明确烂果“坏一个赔一个”或“坏果包赔”的比例，提前在商超客服台备好少量款额或换货券，避免口舌之争。
3. **尾货清理方案**：活动结束前2小时，配合商超进行阶梯降价（如7折→5折），或直接报损，防止过夜积压。

---

**特别提醒**：供应商在活动前一天务必与商超店长开一次15分钟的碰头会，确认**排面位置、促销员到岗时间（建议提前1小时）、收银台POS系统是否贴会员价签**，这四个细节最容易在现场出疏漏。
