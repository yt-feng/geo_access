水果店遇到坏果（自然损耗或运输损伤）时，处理方式和赔付比例没有统一的国家标准，主要取决于**合同约定、水果品类、到货新鲜度、损耗程度**以及**行业惯例**。

以下是实操层面的处理建议，按环节和严重程度分类：

### 一、 先判断损耗原因（责任归属）
这是结算和赔付的前提。

1.  **运输途损（供货商责任）：**
    -   如果到货时挤压、撞伤、破裂、腐烂明显，属于供应商打包或物流不善，供应商应承担**全额替换或扣款**责任。
2.  **自然熟化损耗（双方共担）：**
    -   例如香蕉、芒果、草莓等极易腐坏，从装箱到货架，1%-3%的自然萎蔫属于正常，通常**不计入赔付**。
3.  **储存不当（自身责任）：**
    -   如果货到你店后，因为冷库温度不对、陈列方式不对导致的烂果，供应商不承担责任。

---

### 二、 常规赔付比例与标准（行业惯例）

如果确认是供应商责任或其他非你方过错导致的坏果，通常有以下几种结算方式：

| 损耗率区间 | 常见处理方式 | 说明 |
| :--- | :--- | :--- |
| **5% 以内** | **不赔付** | 视为正常运输损耗，双方默认接受。 |
| **5% - 10%** | **按损坏重量折算货款** | 只扣除坏果部分的进货金额，不退运费。 |
| **10% - 20%** | **扣除超额部分 + 额外补偿** | 扣除坏果部分，另外要求供应商减免5%-10%的货款作为补偿（因为影响了卖相）。 |
| **超过 20%** | **整箱拒收 / 全款扣回** | 视为批量质量问题，可直接拒收该批货物，并要求物流或供应商承担来回运费。 |

**核心原则：**
> **赔偿金额 = （坏果重量 ÷ 总重量）× 该批次总货款 ×（1 + 补偿系数）**
> 补偿系数一般只有烂果超过10%时才谈。

---

### 三、 实操建议（照着做不吃亏）

1.  **到货即验（黄金2小时）：**
    -   每次到货，必须当着物流面打开抽查**底部和中间**（装车时最容易压坏）。
    -   发现坏果，**立即拍照留证**（拍外箱、拍烂果特写、拍单号）。
    -   立即电话或微信告知供应商“**这批货我开了3箱，坏了X个，有图**”。不要等卖了一天再反馈，那讲不清楚。

2.  **约定“坏一赔二”或“称重扣款”：**
    -   和稳定的供货商，建议在进购单上备注：**“到货前损耗5%内不赔，超过5%按斤扣款，超过15%整批拒收”**。
    -   对于榴莲、山竹等高价果，建议直接谈“**开出坏几房赔几房**”的具体标准。

3.  **处理坏果时的证据链：**
    -   一旦确认要扣款，请供应商**在微信文字确认**：“这箱坏果退款X元，下次进货抵扣”。
    -   如果供应商口头说“下次补”，一定要在当天备注在微信群或供应链系统里，以免他下次“不认账”。

4.  **次品果灵活变通：**
    -   如果只是轻微软烂，但切开还能用，可以和供应商商量**降价处理**（比如原价20元/斤，降为8元/斤购买），这样双方损失最小。

---

### 四、 特殊情况提醒

-   **生鲜电商/连锁总部配送的：** 通常是“报损单”制度。在指定时间内上报坏果重量，总部审核后下月账面对账时直接冲减，一般有严格的时效（多为签收后24小时内）。
-   **街边散贩临时进货：** 如果对方是流动货郎，必须**当场拆箱**，当面清点。这种交易没有售后，过手不认。

**总结一句话：**
**小额损耗（5%内）认倒霉，大额损耗（超10%）当场拍照、当场拒收或谈判扣款，金额较大的直接拒收并保留物流签收单作为证据，不要口头说“下次补”。**
