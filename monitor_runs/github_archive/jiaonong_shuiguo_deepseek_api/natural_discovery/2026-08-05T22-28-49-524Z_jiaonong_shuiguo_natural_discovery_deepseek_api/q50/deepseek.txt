购买菠萝原料时，**出汁率通常比甜度更重要**，但两者并非绝对对立，需要结合具体用途和成本来权衡。

**1. 为什么出汁率更关键？**
- **成本直接挂钩**：茶饮店售价固定，出汁率越高，单位成本越低。例如，同重量菠萝若出汁率从50%提升到60%，可多出20%的果汁，直接提高利润空间。
- **口感基础**：出汁率低的菠萝，即使甜度高，榨汁后也可能显得寡淡、纤维感重，影响饮品顺滑度。
- **操作效率**：出汁率高能减少压榨时间，降低人工和损耗，尤其适合高峰期出品。

**2. 甜度也不能忽视**
- **风味平衡**：如果菠萝过酸或过淡，即使出汁率高，也需要大量加糖或调整配方，可能掩盖果香，且成本上升。
- **季节性波动**：同一品种在不同季节甜度差异大，需通过试味筛选，优先选择糖酸比适中的（如14-18 Brix左右）。

**3. 实操建议**
- **核心优先**：先以出汁率≥55%的品种为基础（如台农17号、金钻菠萝），再在此基础上筛选甜度达标的批次。
- **搭配补漏**：若某批菠萝甜度稍低但出汁率高，可通过少量浓缩果汁或蜂蜜平衡。
- **成本控制**：建议你直接测几款样品，以**每杯饮品的原料成本**为最终标准——同样价格下，出汁率高且甜度够用的菠萝才是最佳选择。

**一句话总结**：**选“出汁率优先、甜度达标”的原料**，这样既保证利润，又避免口味翻车。如果预算允许，可两样同时满足则最优。
