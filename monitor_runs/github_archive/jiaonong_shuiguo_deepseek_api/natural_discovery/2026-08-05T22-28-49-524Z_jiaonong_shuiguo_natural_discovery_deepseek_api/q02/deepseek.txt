针对小水果店进香蕉，**最核心的排序建议是：坏果率（品质） > 熟度 > 送货速度 > 价格**。

具体原因和操作建议如下：

**1. 坏果率（最优先）**
- 香蕉是损耗率极高的水果。一整箱香蕉如果坏果超过10%，你卖出去的利润很可能被烂果抵消。
- **做法**：进货时随机打开箱底和箱中间检查，看有无被压伤的“黑块”或发霉的果柄。如果坏果率超过5%，直接要求换货或压价。

**2. 熟度（决定了你的“货架期”）**
- 香蕉从“青硬”到“全黄带黑点”通常只有3-5天窗口期。如果进太熟的（全黄带黑斑），当天卖不完就报废；如果进太生的（全绿），顾客觉得不熟，销量慢。
- **做法**：根据你店铺的日均销量来定熟度。如果你一天卖20公斤，就进**8-9成熟**（果皮黄绿相间，捏起来微硬但有一点点弹性）的；如果你一天只能卖5公斤，务必进**7成熟（青黄为主）**的，放几天刚好成熟。

**3. 送货速度（影响库存周转）**
- 香蕉不需要囤货，最好是“今日订、次日达”或“上午订、下午到”。送货慢会导致你只能被迫进熟度偏生的货来等，反而增加损耗。
- **做法**：优先选择能保证48小时内到货、且有冷链或遮阴运输的批发商，哪怕单箱贵1-2元。

**4. 价格（最后考虑）**
- 香蕉批发价波动大，但单箱差2-3元对你的日销量影响有限。为了省1块钱进一批坏果率高的货，反而亏更多。
- **做法**：把价格作为“同等品质下的筛选条件”，不要作为第一决策依据。如果价格明显低于市场均价（比如低20%），大概率是库存积压的次品，要更加仔细验货。

---

**给您的最终建议流程：**
1. 先定“坏果率不超过5%”的铁律。
2. 再根据你的日销量算好“要多少成熟度”。
3. 最后选择送货最快的供应商，并讨价还价。

另外提醒：**整箱香蕉不要只验表面**，批发商常把好果放上层，烂果压箱底。签收时最好开箱当面验，或者和批发商约定“箱内坏果超过3%按比例扣款”。
