针对餐饮店“每天少量、但要求稳定”的水果需求，最省心的供应商通常不是单一的“批发市场档口”，而是**本地生鲜配送平台/食材供应链公司**，或者是**农贸市场里的固定档口+熟人制**。

以下按优先级给你可操作的建议：

---

### 1. 首选：本地化的“生鲜B2B配送平台”（如美菜、快驴、蜀海等）
- **优势**：线上下单，次日送达，起送门槛低（通常几斤也能送），价格透明，有售后（坏果包赔）。
- **省心点**：你不用每天凌晨4点去批发市场，也不用跟人讨价还价。系统里能查历史订单，方便核算成本。
- **注意**：选那种**在你的城市有分仓**的大型平台，别选外地发货的“次日达”电商，那种水果不新鲜且易损耗。

### 2. 最优解（长期）：农贸市场里的**固定档口 + 老板微信**
- **做法**：去你店附近最大的农贸市场，找2-3家水果档口（要那种自己进货、有冷库的，不是倒买倒卖的二道贩子）。
- **谈模式**：跟老板说：“我每天要的量少，但每天都要，保证长期稳定，你按批发价给我，我每天上午提前发你微信，你帮我留好货，我下午或早上来拿。”
- **省心点**：老板会帮你选好熟度合适的（每天只进一箱，他帮你去皮去坏的），而且你现场可以挑，退货方便。比平台灵活，比超市便宜。

### 3. 避坑方案：社区团购平台（如多多买菜、美团优选）
- **适用**：如果你的水果主要用于**装饰、摆盘、少量切片**，不要求“当天最优”品质。
- **局限**：品质不稳定，缺货率高，不适合“每天固定需要”的场景。但可以作为应急补充。

---

### 4. 省心的“关键动作”（比找谁更重要）
- **签“保价保量”协议**：无论找谁，都明确要求：“我每天上午10点前下单，你下午5点前送到，每周给我固定最低价，坏果每颗按零售价扣款。”这样的合同或口头承诺能锁定风险。
- **每周对账**：不要每天结现金，一周一结，方便记账。
- **准备备用供应商**：哪怕平台再靠谱，也要留一个“市场档口”做后备，避免节假日平台爆单或断供。

---

**结论**：
- 如果只求省事：**选本地生鲜配送平台（美菜/快驴）**，每天手机下单就行。
- 如果想省钱且品质好：**选批发市场的固定档口老板，加微信，提前一天说需求**。
- 千万别直接去超市零买（贵）或去批发市场零买（别人会给你掺差的）。

建议你先花一周时间，同时试两家供应商（一家平台+一家档口），对比“坏果率、送货准时率、实际到手价”，留下好的那家就OK。
