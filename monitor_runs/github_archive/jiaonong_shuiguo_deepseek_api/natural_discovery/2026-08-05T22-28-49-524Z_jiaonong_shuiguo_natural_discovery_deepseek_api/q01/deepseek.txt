开水果店判断香蕉和菠萝这类**大宗、易损耗、周转快**的供应商，核心要看“保底能力”和“赔付机制”，而不是只比价格。给你一套具体可执行的筛选和测试流程：

### 第一步：看硬性资质（排除皮包公司）
- **索要营业执照**（看经营范围是否含“鲜果批发/配送”）；
- **要求提供产地证明或检疫证明**（尤其是菠萝，很多来自海南/越南，要有进口检疫或产地溯源单）；
- 让供应商提供**冷库照片或仓库地址**，并实地或视频考察（香蕉需要催熟库，菠萝需要保鲜库，没有冷库的供应商千万别碰）。

### 第二步：测试“沟通和专业度”（最核心）
同一个问题问三家供应商：
- **问香蕉**：“我店里室温25度，你送来的香蕉一般到几成熟？我按这个成熟度应该放几天卖？”
- **问菠萝**：“你每天几点到货？菠萝磕碰的损耗率你包多少？”
- **看反应**：靠谱供应商会主动告诉你**催熟天数、到货成熟度、建议销售期**，甚至帮你规划单次进货量；不靠谱的只会说“保甜、包退”但说不清细节。

### 第三步：小批量试单（给双方止损机会）
- 第一次**只进2-3箱**，不要一次性压大货。
- 送货时重点检查：
  - **香蕉**：看果柄是否发黑、果皮有无大面积出水（挤压伤），捏一下香蕉是否过硬（太生）或太软（过熟）；
  - **菠萝**：看果眼是否发黑、底部有没有发霉，闻有没有酒味（发酵说明库存太久）。
- **拍照记录坏果数量**，当场和司机确认，并要求在送货单上注明“坏果比例”。

### 第四步：试探售后和结账周期
- 直接问：“如果这批菠萝切开有黑心，你补贴还是换货？怎么赔付？”
  - 靠谱供应商会说“签收当日有坏果拍照给业务员，按比例抵扣货款”；
  - 不靠谱的会说“卖出去就不管了”或“要你自己承担”。
- **结账周期**：初期最好选择“现结或周结”，不要盲目相信“月结更优惠”的承诺，避免资金被套牢。

### 第五步：长期合作前用“波动测试”
供货稳定不代表一定靠谱，反而要**在天气突变或节假日前后下单**（如台风、春节前一周）：
- 看他能否照常给货、涨价是否提前通知、缺货时是否主动推荐替代品（比如香蕉缺货时建议你进大蕉或恢复时间）。
- **靠谱供应商会提前告知风险**，而不是发货当天才说“没货了”。

### 关键提醒：
- **拒绝“包圆”全单**：有人给你超低价格但要求你一次进10箱以上，大概率是尾货或残次品，切勿贪便宜。
- **做“进销存台账”**：哪怕用最简单的Excel，记录每批进货量、价格、坏果数、实际售出天数，对比三个月就能看出哪家综合成本最低（价格+损耗+服务）。
- **备选供应商至少2家**：不要只依赖一家，以防断货或质量下滑时无路可退。
