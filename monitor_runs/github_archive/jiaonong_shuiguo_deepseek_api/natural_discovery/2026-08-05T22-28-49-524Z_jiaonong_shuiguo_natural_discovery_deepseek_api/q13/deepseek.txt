针对小水果店做附近小区团购，对水果供应商的要求核心是**多网点配送、小批量高频次补货、以及灵活退换货**。以下是供应商需要支持的关键服务清单，你可以直接按此标准去筛选合作方：

### 1. 履约与配送服务（核心）
-   **支持“多批次、少批量”发货**：团购往往是今天下单明天提货，或一周2-3次。供应商必须支持**小箱起订**，而不是一箱几十斤的大批发规格，否则小店备货压力大、损耗高。
-   **次日达或“今日订明日达”**：供应商要有稳定的冷链或常温车，最好能覆盖小区集中送货时间（如下午4点-6点前送达），方便业主下班取货。
-   **可拆分小区地址**：如果供应商是到店批发，你需要自己配车；如果供应商能按你的订单分拣打包好并送到你店里或指定小区提货点，那最好。重点是确认快递或物流是否支持**拼车/顺带配送**以降低运费。

### 2. 商品与品质服务
-   **稳定供货周期**：团购是预售制，供应商需能保证每周有固定的上新或补货清单，不能这周有下周没，否则社群活跃度会断。
-   **“标准化”分级**：供应商应提供**商品分级标准**（如精品果/普果），并且大小、甜度误差小。因为团购客户不挑货，一旦打开箱子发现品质不一，会产生大量客诉。
-   **损耗包赔政策**：这是最关键的！必须有明确的**“按比例折损”或“坏果包赔”条款**（例如：箱内坏果超过5%按斤补货，或直接退款）。供应商能否承诺“隔天坏果照样赔付”直接影响你的毛利率。

### 3. 售后与灵活结算
-   **快速退换货通道**：团购中经常有“客户拿回家切开发现烂心”的情况。供应商必须支持**次日补货**或**小额现金抵扣**，不能让你自己承担所有坏果损失。
-   **账期支持**：最好能谈**“周结”或“月结”**，而不是一手交钱一手交货。小水果店现金流有限，团购利润薄，月结能让你腾出资金去周转其他货品。
-   **提供“引流爆品”**：供应商应能配合你每月做1-2次低价引流品（如9.9元/3斤的耙耙柑），甚至可以亏本冲量，换取你持续从他这里拿货。

### 4. 增值服务（增强竞争力）
-   **提供原产地/检测证明**：在小程序或群里发宣传海报时，如果供应商能提供**产地视频、农残检测截图**，对提高小区业主信任度非常有帮助（特别是宝妈群体）。
-   **素材支持**：供应商若能提供现成的**产品图、卖点话术、食用禁忌**，可以帮你节省大量做社群内容的时间。

---

### 给你一个筛选供应商的“执行清单”：
1.  **首单测试**：先小批量订100斤试单，重点看**送达时的果温（是否冷链）、破损率、以及售后处理速度**。
2.  **谈保底政策**：直接问业务员：“如果小区团购滞销，我整箱退货，你们扣不扣钱？” 能接受无理由退货（或只扣运费）的，才是适合做团购的供应商。
3.  **锁定“次日达”爆品池**：要求供应商每周五发一份“下周特价单品表”，你据此提前在群里预告接龙。

**最后提醒**：如果本地批发市场距离近，反而比远距离的大仓更有优势，因为**短途运输能大幅降低损坏率**，且临时补货只需15分钟车程。谈判时，重点拿“卖不动的榴莲能整箱退吗”这类极端情况去试对方的底线，看对方是否愿意兜底。
