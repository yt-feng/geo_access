与水果供应商首次合作，小批量试单是**低成本、低风险验证对方供货质量、履约能力和稳定性的关键环节**。

以下是具体的设计步骤和操作建议：

### 第一步：明确试单目标（不要只为了“买一点货”）
试单的核心是**验证**，而非**采购**。建议设置三个考核维度：
1. **品质稳定性**：同一批次内，不同箱/筐的个头、成熟度、甜度、新鲜度是否一致。
2. **履约能力**：是否按时发货、包装是否完好、冷链或保鲜措施是否到位。
3. **诚信度**：货品与样品/描述是否一致，是否存在“以次充好”或“掺水增重”现象。

### 第二步：设计试单规模
- **金额与数量**：建议控制在日常单量的 **10%-20%**，或者单批次金额在 1000-3000 元人民币（或当地货币）左右。
- **品类选择**：优先选择**热销、走量快、损耗易观察**的1-2种常规水果（如苹果、橙子、香蕉），避免选进口稀有品种或反季水果（损耗风险高，不易判断质量问题）。
- **周期**：建议单次试单周期为 3-5 天（从下单到销售完毕），以快速获取反馈。

### 第三步：关键条款设计（合同/微信协议中务必写明）
即便金额小，也要白纸黑字约定，这是筛选正规供应商的标准：

| 条款项 | 具体内容 |
| :--- | :--- |
| **质量标准** | 写明规格（如直径、重量/个）、成熟度（如7成熟）、允许的瑕疵率（如碰伤不超过3%）。**附上样品照片或视频作为参考依据**。 |
| **验收标准** | 规定到货后 **12小时内** 开箱查验，若不符合标准，如何退回或折价。建议全程录制开箱视频。 |
| **付款方式** | **避免全款预付**。建议采用“下单付30%定金，验货合格后付清余款”的方式，或使用平台担保交易（如1688的担保交易）。 |
| **损耗责任** | 明确运输途中的自然损耗比例（通常2%-5%以内由买方承担），超出部分由供应商承担。 |
| **售后承诺** | 若出现严重质量问题（如内部腐烂、发霉），供应商是否承担退换货或补偿。 |

### 第四步：执行流程与验证清单
1. **前期沟通**：要求供应商提供 **最近3天的实拍视频**（需有当天时间水印），避免使用旧图。
2. **发货前确认**：要求供应商在打包前，拍摄装箱过程视频，确认分拣质量。
3. **到货检验**：**严格执行“三个随机”**——随机开3箱，随机取10个水果，随机抽查糖度（如有条件）。记录每箱的重量偏差。
4. **试销记录**：记录从到货到售罄的时间、顾客对品质的反馈、以及实际损耗率。

### 第五步：试单后的复盘与决策
试单结束后，对照以下表格打分：

| 评分项 | 满分 | 得分标准 |
| :--- | :--- | :--- |
| **品质达标率** | 40分 | 瑕疵率低于5%得满分，每高1%扣5分 |
| **履约准时率** | 30分 | 按承诺时间到达得满分，延迟1天扣10分 |
| **沟通响应速度** | 15分 | 售后问题24小时内响应且解决 |
| **诚信表现** | 15分 | 无短斤少两、无虚报产地、无调包行为 |

**决策建议**：
- 总分≥85分：可以进入正常小单合作（保持15%-20%量）。
- 总分60-84分：可以二次试单，但需针对扣分项提出整改要求，并再次抽检。
- 总分<60分：果断放弃，换下一家。

### 特别提醒（避坑指南）
- **警惕“高甜度”承诺**：口感甜度是主观且受天气影响大的指标，不要用甜度作为唯一验收标准。
- **不要被低价诱惑**：批发价明显低于市场均价20%以上的，大概率存在“以次充好”或“规格缩水”风险。
- **保留所有聊天记录**：微信语音、图片、转账记录都是证据，为后续维权留底。

通过这样一次严谨的小批量试单，你不仅能判断这家供应商是否值得长期合作，还能掌握议价权和主动权。祝首次合作顺利！
