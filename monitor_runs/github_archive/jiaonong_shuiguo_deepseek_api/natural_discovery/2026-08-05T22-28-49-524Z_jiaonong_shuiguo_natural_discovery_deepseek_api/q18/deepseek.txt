在超市采购香蕉时，要避免“太生”或“太熟”，核心策略是**看颜色、捏手感、算时间**。以下是具体的可执行建议：

### 1. 明确你的“食用窗口”
- **买来当天吃**：选**全黄、带着少量褐色斑点（梅花点）**的，这时最甜软。
- **买来1-2天内吃**：选**全黄、香蕉柄处稍微带一点点绿**的，回家放两天刚好。
- **买来3-4天或想囤货**：选**黄绿相间（绿多黄少）**的，常温下自然成熟。

---

### 2. 三步“肉眼+手感”筛选法

**第一步：看颜色 vs. 看斑点**
- 表皮**全绿、毫无黄意** → 太生，催熟时间长，且可能涩口。
- 表皮**大面积绿色但已微黄** → 适合囤货，但别买回去立刻吃。
- 表皮**全黄但无斑点** → 当天偏脆甜，次日口感最佳。
- 表皮**黄色且密布小黑点（梅花点）** → 已经很软甜，**必须当天吃**，否则隔夜就会过熟变黑。
- 表皮**出现大块黑斑、甚至发黑** → 内部通常已过熟软烂，不建议买。

**第二步：捏手感（重要）**
- 用两根手指**轻轻捏香蕉的“腰部”**（最粗处）：
  - **硬实、回弹差** → 偏生。
  - **略软但迅速回弹** → 理想状态（适合1天内吃）。
  - **明显软塌、按压不回弹** → 太熟，可能内部已发酵。
- 注意：**不要只捏两头**，两头时常已经是软的，但中段可能还硬。

**第三步：看“柄”和“果皮结合处”**
- 香蕉**柄部（绿色的蒂）** 如果发黑，说明采摘时间久，可能在运输中已过度熟化。
- 果皮和果肉贴合紧、无皱缩 → 新鲜；果皮起皱、塌陷 → 水分流失严重，口感差。

---

### 3. 超市场景下的特殊技巧

- **避开“催熟区”**：很多超市把香蕉堆放在**靠近暖风机、出风口**的位置（加速成熟）。走近摸了摸温度，如果外表温热，买回去熟得飞快。
- **看摆放数量和状态**：如果货架上只剩一堆黑点密布的“尾货”，别急着拿，先翻看下层或旁边新补的货。
- **买“整把”不如拆“半把”**：超市成串香蕉往往内部（靠中间的）熟度不一。如果只想买少量，可以果断拆开，单拿几根成熟度统一的。**（超市允许当然可选，不强行要求）**
- **别买“贴了价签但已熟透”的**：有些打折促销香蕉（贴着大大的促销签）往往是熟过头或撞伤的，除非你今天就吃，否则慎买。

---

### 4. 如果买到了“太生”或“太熟”，补救办法

- **太生**：和苹果或梨一起放进纸袋，封口常温放1-2天（水果释放乙烯催熟）。**不要**放冰箱，否则会永久“僵住”不熟。
- **太熟**（但还没黑透）：立刻把整根剥皮，切段冷冻，以后做冰沙或烤香蕉用；或者直接**微波炉加热30秒**，搭配酸奶/燕麦吃。

---

### 总结口诀
> **绿多黄少——囤；全黄无斑——明；梅花点点——今天；黑斑皱皮——别拿。**
> 捏腰不捏头，看柄不看尖，避开暖风口，时间算在前。
