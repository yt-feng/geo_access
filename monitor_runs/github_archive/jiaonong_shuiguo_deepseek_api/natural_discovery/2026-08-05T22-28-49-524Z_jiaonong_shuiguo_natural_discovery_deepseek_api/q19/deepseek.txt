在超市卖菠萝时，**切果损耗**是最需要优先关注的，其次是**甜度**，然后是**外观**和**大小**。这四个因素的重要性和具体操作建议如下：

**1. 切果损耗（最优先，直接影响毛利）**
- 为什么重要：整只菠萝的利润率很高，但切好的菠萝如果卖不掉，损耗极大（一天内会变色、发酸）。损耗是超市生鲜最大的隐形“利润杀手”。
- 具体做法：
  - **按需切果**：只在客流高峰时段（如傍晚）切少量试吃装或整盒装，高峰期后再根据销量补充。
  - **包装透明化**：切好的果肉必须用带盖透明盒真空或密封包装，并贴上**当日截止时间**标签（通常只保质24小时）。
  - **日清制度**：对切果在打烊前2小时进行**买一送一**或**特价清仓**，宁可薄利卖掉，绝不能隔夜。
  - **损耗率红线**：切果损耗率必须控制在**5%以下**（即卖100元切果，最多报废5元），超过则立刻减少切量。

**2. 甜度（影响复购和口碑）**
- 为什么重要：顾客买菠萝是为了吃，甜度直接决定会不会再次购买。
- 具体做法：
  - **进货验收**：不要只看外观，至少要抽样切开1-2只，用糖度计（或凭经验尝）确认糖度**不低于12度**（优质台湾菠萝通常14度以上）。
  - **宣传手段**：在货架旁放**试吃盒**，不是给顾客拿着整盒吃，而是**给试吃签或小牙签**，方便试吃后购买。
  - **成熟度分级**：如果同一批货有成熟度差异（表皮青黄不均），优先把**最熟的**（按压底部稍软）摆在靠近收银台或人流最大的位置，并贴“今日甜”标识。

**3. 外观（影响第一印象，但不是核心）**
- 为什么重要：外观不好看（疤多、刺长、变色）会直接劝退顾客，但**外观与甜度相关性不高**。
- 具体做法：
  - **淘汰标准**：丢弃严重裂口、发霉、黑斑或渗水（肉质已坏）的菠萝；轻微刮伤可降价处理。
  - **摆放技巧**：将表皮颜色**金黄、叶片鲜绿**的摆上层，外观一般的放底层，整体看起来整齐、饱满。
  - **不必完美**：不要因为外表有少量疤痕或刺多影响甜度而放弃进货，这对价格有利（这类菠萝往往更甜）。

**4. 大小（影响单价，权重最低）**
- 为什么重要：顾客对大小有偏好，但**大小不能决定甜度**（大果可能水分多、甜度低；小果也可能过酸）。
- 具体做法：
  - **分类定价**：按大小分大果（≥1.5kg）、中果（1-1.5kg）、小果（<1kg）三个价位，让顾客按预算选择，减少“大果太贵”的抱怨。
  - **进店建议**：如果你在采购端，优先进**中果为主（占60%）**，大果和小果各20%，中果是主流消费和切果首选规格。

---

**给你的执行清单（按优先级排序）：**
1. 每日设立“切果损耗警戒线”，超5%立即调低切量或改做果盘特价。
2. 进货必抽查甜度，不甜不发，哪怕外观再好。
3. 货架放试吃，用甜度征服顾客，而不是靠大小。
4. 外观只要没有烂点即可，重点陈列整齐、灯光打亮。

如果你现在正在店里，**优先处理切果损耗问题**，把临期切果清完库存再补新货。
