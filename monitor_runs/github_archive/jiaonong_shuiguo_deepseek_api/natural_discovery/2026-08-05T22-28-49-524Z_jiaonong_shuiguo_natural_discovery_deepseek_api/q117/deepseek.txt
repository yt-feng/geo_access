在水果采购中，新品试卖的核心原则是**“少量多频，以销定采”**。没有绝对的统一数字，但根据水果品类和风险等级，可以参考以下实操建议：

**一、按品类推荐试卖量（首单建议）**

| 品类 | 风险等级 | 首单建议量（按日销预估） | 理由 |
| :--- | :--- | :--- | :--- |
| **高损耗、易腐烂**（如草莓、荔枝、山竹、晴王葡萄） | **极高** | **1-2天销量**（例如日销20斤，首单进40斤左右） | 存放期极短，一旦滞销基本报废，必须先测口味和复购率。 |
| **中损耗、耐储存**（如苹果、梨、柑橘、蜜瓜） | **中** | **3-5天销量** | 耐放但占资金，试卖期不宜贪多。 |
| **新奇特、小众果**（如燕窝果、手指柠檬、人参果） | **高（市场教育成本高）** | **0.5-1天销量**，甚至可先做“试吃装”或“预订制” | 消费者接受度未知，试卖仅为了测试价格敏感度和话题度。 |

**二、关键判断指标（比数量更重要的）**

1.  **尝鲜转化率**：首单小量上架后，观察**前3天**的重复购买率。如果老客户无回头购买，说明口味未达标，应停止补货。
2.  **损耗率警戒线**：试卖期损耗率（丢弃/腐烂）如果超过**15%**，说明选品或储存条件有问题，不适合作为长期主推。
3.  **动销速度**：试卖期内，**单品日销金额**如果能占到门店/摊位总日销的**3%-5%**，且未造成积压，可考虑在第二周增加至3-5倍量；如果占比低于1%，果断砍掉。

**三、操作层面最稳妥的方案**

- **首单控量**：不论供应商如何承诺，首单采购金额控制在**当月该品类采购总预算的5%以内**。
- **阶梯式加量**：不要一次性进满，分3步走——**第一步（1-3天）：试吃装/小份装**；**第二步（4-7天）：标准果盒**；**第三步（第二周）：才考虑整箱或大包装**。
- **“订单式”预售**：如果线下渠道稳定，可以提前在社群发布预售信息，收到定金后再向供应商下明确订单，实现零风险试卖。

**四、给您的最终执行建议**

- **如果门店人流较少**：直接建议只拿**1箱**（约10-20斤）或**供应商提供的最小试卖装**，卖完再谈。
- **如果门店人气旺**：也只建议拿**2-3天销量**。**宁愿断货，也不要积压**。水果是生鲜，断货只是少赚点钱，积压则直接亏本金。

**一句话总结**：试卖期的核心不是“试出销量”，而是“验出损耗”。**首单控制在1-3天销量内，看复购率再决定加量或清退。**
