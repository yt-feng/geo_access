社区团购旺季爆单前锁定水果库存，核心是**“早沟通、给保障、建机制”**。以下是一套可落地的操作步骤：

---

### 第一步：提前1-2个月，与供应商签订“框架协议”或“意向订单”

不要等到旺季当天或前一周才沟通。提前锁定主要品类（如苹果、柑橘、香蕉、草莓等）的**月度预估量**，签订框架协议。协议里明确：

- 价格波动调节机制（如设3%-5%的浮动区间）
- 到货时间（允许±2小时误差）
- 最低供货量
- 验收标准（如糖度、大小、瑕疵率）

### 第二步：采用“阶梯式预付款”提高供应商积极性

给供应商预付款（通常货款的20%-30%），分三档：

- 提前30天打款：锁定**最低价**，享受优先配货权
- 提前15天打款：锁定**市场价9折**
- 提前7天打款：锁定**当时市价**

预付款越多，供应商越愿意优先保证你的货。风险控制：合同约定预付款可抵扣货款，若违约需双倍返还。

### 第三步：建立“产地直采+代采”双渠道

如果你直接对接产地合作社/果园：

- 提前支付定金（水果不需要全款锁定，一般5-10%定金即可）
- 或者一次性买断某块果园的产量（适合精品水果，如阳光玫瑰、水蜜桃）

如果通过批发市场代采：

- 与2-3个核心代采商签订长期协议，旺季时给高优先级（通常加价1-2%换取优先权）

### 第四步：设定“保量补差”条款

在合同中加入：

- 若供应量不足，供应商需以**更低折扣**补偿其他品类（如水果差额用干货/粮油补上）
- 若你方未达到最低采购量，需支付一定比例的违约金（反过来也约束你方）

### 第五步：建立每日滚动预测机制

旺季前3周，每天下午4点前，你和供应商共享次日预估销量（通过昨日实销+今日实时销量推算）。让供应商按此提前备货，甚至提前一天半夜到货，避免次日早高峰缺货。

### 第六步：冷库/冷链前置

如果量非常巨大，提前租用共享冷库（或与供应商共用），把水果提前囤在社区前置仓。这样即使供应商断货，你有3-5天缓冲库存。注意：热带水果（香蕉、芒果）不耐存，提前囤货需谨慎。

---

### 关键提醒（避坑指南）

- **不要口头要货，一定要落纸面**，旺季供应商会优先给有合同的客户
- **水果损耗要明确由谁承担**，建议旺季入库损耗你承担，出库后损耗供应商承担
- **预留10%-15%的备用供应商**，如果主供应商突然掉链子（例如产地暴雨），立即启用备用渠道

---

3. 约谈其中2家，敲定框架协议模板
4. 准备10%的备用资金用于旺季临时补货
