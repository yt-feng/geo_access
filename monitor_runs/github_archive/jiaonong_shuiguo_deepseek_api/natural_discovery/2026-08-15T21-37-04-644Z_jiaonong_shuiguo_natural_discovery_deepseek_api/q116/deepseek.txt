小商家采购水果时，**现金结算**和**月结账期**各有不同的风险，具体如下：

---

### 一、现金结算的风险
1. **资金占用压力大**  
   一次性支付全部货款，可能导致现金流紧张，尤其当采购量较大或水果价格波动时，后续进货或日常运营资金可能不足。

2. **售后维权困难**  
   现金交易往往没有书面合同或发票，若水果出现质量问题（如腐烂、缺斤少两），商家难以举证追责，只能自行承担损失。

3. **缺乏价格谈判筹码**  
   现金结算虽能获取“现金优惠价”，但若供应商坐地起价，商家很难要求延期付款或调整价格，容易陷入被动。

4. **账目管理麻烦**  
   大量现金收支容易出现记账遗漏或错误，增加财务核算难度，也容易产生员工挪用风险。

---

### 二、月结账期的风险
1. **信用风险（供应商跑路或赖账）**  
   若供应商经营不善或恶意拖欠，商家可能无法按时收到货或货款被长期压住，甚至血本无归。尤其对小商家而言，供应商若倒闭，追偿成本极高。

2. **隐性成本高**  
   月结通常意味着供应商会提高单价（相当于利息成本），且商家需承担资金被占用的时间成本。若水果行情波动大，账期越长，价格风险越大。

3. **对供应商依赖性强**  
   供应商一旦断供或涨价，商家因账期拖欠可能被迫接受不合理条件，丧失议价能力，影响正常经营。

4. **账目纠纷可能性**  
   月结需要频繁对账，若双方记录不一致（如退换货、折扣未记录），容易引发纠纷，且口头约定难获法律支持。

---

### 三、风险规避建议（可执行）
- **现金结算**：  
  1. 明确要求供应商提供**正规发票或收据**，并注明质量标准（如品种、甜度、破损率）。  
  2. 一次性采购量控制在合理区间，避免囤货过多。  
  3. 优先选择本地信誉好的供应商，并留存对方身份证或营业执照复印件。

- **月结账期**：  
  1. 签订**书面合同**，约定账期（如30天）、逾期利息、质量标准、违约责任。  
  2. 要求供应商提供**押金或担保**，或先小规模试合作2-3个月再扩大账期。  
  3. 每月固定时间**主动对账**，保留送货单、聊天记录等凭证。  
  4. 统计供应商的**历史履约记录**，避免与有拖欠前科的供应商长期月结。

---

### 四、结论
- 若商家资金充裕、采购频率低，**现金结算**更稳妥简单；  
- 若采购量大、需周转资金，**月结**可缓解现金流压力，但务必用合同和法律手段降低信用风险。  
- 折中方案：**首月现金，后续月结**，或“部分现金+部分月结”（如总货款的70%现金，30%月结），平衡风险与资金压力。
