茶饮店遇到水果到货不合格，处理不当确实容易影响营业。核心原则是**“以保障营业连续为首要目标，同时明确责任和补货时效”**。以下是一套可执行的约定方案和建议：

### 1. 合同/采购协议中需明确的“补货条款”
在与供应商签订合同时，务必写清楚以下四点，避免口头约定：

- **验收标准与时效**：约定具体到货时间（如：门店营业前2小时）和验收标准（如：甜度、外观、破损率≤X%）。
- **不合格认定与通知**：规定发现不合格后，**需在到货后1小时内**（或拆箱时）拍照/视频留证，并通过微信群或系统书面通知供应商。
- **补货责任**：明确**因供应商原因导致的不合格，供应商须**（建议写死）**：
  - **4小时内**送达合格品（同城供应商）；
  - **次日到货**（异地供应商），且需承担运费。
  - **违约责任**：若供应商无法按时补货，需赔偿门店当日该款饮品的预估损失（可约定固定金额或按前3日平均日销估算）。
- **替代方案权**：合同写明“若供应商无法在约定时效内补货，门店有权从第三方渠道紧急采购，差价由供应商承担”。

### 2. 当日紧急处理的“三线并行”操作流程
如果当天就遇到到货不合格，按以下优先级操作，不打断营业：

- **第一线（供应商）：** 立即电话通知供应商，要求其**当天内**紧急调货。明确告知“如果今天到不了，我就要从XX市场临时采购，差价你来补”。
- **第二线（临时采购）：** 马上联系附近的水果批发市场或本地菜市场，**先买够当天营业所需的量**（哪怕量少或品质稍差，先撑过中午高峰期）。同时保留采购小票。
- **第三线（菜单微调）：** 如果缺货的水果是低频原料（如某种进口莓果），可前台暂时**停售含该水果的1-2款饮品**，引导顾客点替代品，避免现场断货尴尬。

### 3. 长期预防策略（最关键）
- **建立“安全库存缓冲”**：对易损耗水果（如草莓、芒果）设置警戒线（如剩余量低于2天用量），提前3天下单，给供应商留出补货时间。
- **发展1-2家备选供应商**：不要把所有水果押在一家，平时就保持和另一家批发商的联系，遇到紧急情况能当天调货。
- **不合格品的“止损”利用**：轻微瑕疵（如个别压伤）可用来做员工餐、试饮或制作果酱、冷萃基底，减少浪费。

### 4. 话术参考（用于和供应商沟通）
> “王老板，今天到的这批柠檬有XX个明显软了，我拍照发你了。**我这边今天下午的订单已经排满了，最晚下午3点前你务必安排人送一箱合格的过来**，不然我下午就要断货了。这次运费你出，如果3点前到不了，我就自己从XX调货，差价直接在你货款里扣。你看行不行？”

### 检查清单：
- [ ] 合同中是否写明“4小时补货时效”和“差价承担方”？
- [ ] 是否有当天的备用供应商联系人电话？
- [ ] 门店是否有“暂停售HIGH”、“限时更换”的应急SOP？

**最后提醒**：补货条款写得越具体，供应商责任越清晰，营业风险越低。核心是**“时效”和“差价承担”**两点必须白纸黑字写清。
