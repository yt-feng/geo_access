为了帮您做出更划算的选择，我可以从**单位价格、出肉率、损耗率**三个维度帮您分析。以下是根据常见餐厅采购场景给出的具体建议：

### 1. 苹果（首选：规格差，价格优先）
- **选规格**：**75#-80#**（直径约7.5-8厘米）的苹果。
- **理由**：这个规格的苹果大小适中，一个正好拼一盘（切成6-8瓣），**损耗率最低**（果核占比小）。而90#以上的大果虽然单价可能略高，但单个重量大，实际出肉量差不多，性价比反而低。
- **省钱技巧**：如果餐厅不要求卖相完美，可以采购“**统货**”（大小混合），通常比精选果便宜15%-20%。

### 2. 橙子（最关键：看品种，别只看大小）
- **选规格**：**70#-75#**（中果），且**优先选赣南脐橙或血橙**（皮薄、籽少）。
- **关键点**：**不要买大果（80#以上）**！大果皮厚、纤维粗，切起来损耗大。中果皮薄肉厚，出肉率更高。
- **数据参考**：中果去皮去籽后出肉率约80%，大果只有70%左右。如果大果单价是2元/斤，中果2.2元/斤，实际核算下来**中果更划算**。

### 3. 菠萝（建议：现切整果，别买切好的）
- **选规格**：**3-4斤/个**的整果（带皮）。
- **理由**：餐厅现切损耗约25%（去头尾、削皮、去芯）。如果买超市切好的“黄金菠萝”，单价通常贵1倍以上，且无法把控新鲜度。
- **省钱技巧**：**选用“都乐金菠萝”**（不用泡盐水，甜度高），虽然单价略贵，但省了泡盐水的人工和额外调味成本，综合性价比高。**避免买“香水菠萝”**，酸度高，需要加糖水处理。

### 额外建议
1. **批量采购时**：苹果和橙子可以找批发市场“**晚间剩货**”（下午5点后），价格能再降30%，但需要当天用完。
2. **损耗控制**：苹果切后泡淡盐水防氧化，橙子切后冷藏可保存2小时，菠萝切后冷藏可隔夜（但口感会下降）。
3. **避免踩坑**：不要买“**染色橙**”（表面颜色不均匀）或“**硼砂苹果**”（摸起来过于光滑），这些可能影响食品安全。
