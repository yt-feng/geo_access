判断批发档口香蕉供货是否稳定的核心在于**四个维度**：规模、资质、历史信用和供应链可验证性。以下是实操判断标准：

### 1. 看“规模匹配度”（最直接）
- **看档口面积与库存**：一手货源通常有自己的仓库或冷库。如果档口只有几个周转箱，且货量时多时少，基本是“炒货”或二三级经销商，稳定性差。
- **问日常吞吐量**：直接问“你一天能出多少柜（集装箱）？”或“单次最大供应量是多少吨？”。一手供应商往往能明确报出单次发货量（如20吨/柜），如果对方含含糊糊，只说“要看情况”，那基本是拼单模式。

### 2. 看“产地与季节性应对”
- **明确产地链**：问“你的货主要来自哪里？是缅甸、老挝还是海南、广东、云南？” 稳定的一手货源通常有固定的产地基地或长期合作农场，且能提供产地证明或检疫合格单（入境货物检验检疫证明）。
- **应对淡旺季**：香蕉有季节性波动，问“你夏季和冬季的货源怎么保证？”稳定的供应商会提到“有反季节种植基地”或“多产区调配”。如果他们只能靠一个产区且无法应对气候风险，供应容易断裂。

### 3. 看“合同与结算习惯”
- **要求签合同或长期框架**：稳定货源通常接受“月结”或“按批次签合同”，并写明质量标准（如长斑率、催熟程度）。如果对方只接受现金现货、且拒绝任何书面承诺，风险很高。
- **试笔“小订单测试”**：先下一个小单（比如200件），要求对方按标准准时交付，并观察：
  - 到货时间是否准时（误差不超过1天）
  - 香蕉催熟度是否统一（看颜色M3-M5，表皮有伤疤但果肉无损）
  - 是否有断货、缺斤少两现象

### 4. 看“同行口碑与经营年限”
- **直接去周边档口问**：在批发市场里，同货类的其他档口最了解底细。直接问“某某档口的货稳不稳”，如果连续3个人都说好，可信度高。
- **查经营年限**：稳定供货商通常经营5年以上，且档口招牌、位置固定。如果刚开业几个月，或频繁搬家，建议谨慎。

### 5. 现场“突击检查”法
- **要求看运输单据**：要求看最近的产地收购单、物流发货单或船运提单（海运居多）。一手的通常有完整单据，而货源不稳的会借口“单据在车里/没带”。
- **看卸货是否整柜**：一手货源到货通常是整柜或整卡（整车）卸货，你如果看到对方在拆散拼装，说明不是一手。

---

**总结行动建议**：  
1. 先做一次**200件小单试探**，重点看准时性和质量稳定性。  
2. 要求提供**连续3个月的供货记录**（哪怕口头承诺，观察对方是否能编出具体日期、数量）。  
3. 保留对方**产地检疫证明**和**合同复印件**，如果后续断货，可向市场管理方或工商投诉。  

如果对方在这些点上都能清晰、快速应答且有书面凭证，通常就是稳定一手货源；反之，多半是临时倒手商，建议换人。
