可以的，**超市是可以向水果供应商申请陈列、海报和试吃支持的**，这在零售行业非常普遍，属于供应商的常规市场支持费用（通常叫**渠道费用**或**市场推广费**）。

具体能否获得以及获得多少，取决于以下几点：

1. **合作模式**：如果是经销（买断）模式，供应商一般会提供；如果是代销或联营，供应商支持力度可能稍弱。
2. **采购规模**：你的促销档期采购量越大，供应商越愿意投入资源。
3. **谈判筹码**：如果你同时经营多家供应商的同类水果，有竞争时更容易争取到支持。

**你可以这样去谈：**

- **陈列支持**：要求供应商提供**端头货架、堆头**（如地堆、促销车）以及**陈列道具**（如水果展示盒、价签卡、促销围挡），并负责摆放美观。
- **海报支持**：要求供应商提供**POP海报、爆炸贴、吊旗**，甚至承担海报制作费用（或提供设计稿印刷成品）。有的供应商还会提供**促销台卡、宣传单页**。
- **试吃支持**：要求供应商承担**试吃损耗成本**（即试吃消耗的水果不记账或补偿），并派**驻场促销员/试吃员**（供应商出人工费）。通常大型供应商（如佳沃、都乐、百果园合作商）都有专项资金。

**实操建议：**

- 不要只口头问，要**书面或邮件形式**将需求列出（如：档期7天、堆头2个、需要1名试吃员、海报50张）。
- 建议提出**阶梯式要求**：比如采购量达到X箱，就要求供应商全包（陈列+海报+试吃+人工）。
- 如果供应商推脱，你可以用**联合促销**话术：“我这边帮你做爆量促销，你提供资源，我们共同冲销量，对双方都有利。” 
- 注意确认**费用归属**：陈列费（进店费）、海报制作费、试吃损耗，明确是供应商承担还是超市报销，避免后续扯皮。

**结论**：可以争取，而且大概率能争取到一部分。重点在于你要**主动提、分项谈**，不要指望供应商主动全包。如果供应商拒绝，你也可以提出“以销量反扣”的方式让利交换。
