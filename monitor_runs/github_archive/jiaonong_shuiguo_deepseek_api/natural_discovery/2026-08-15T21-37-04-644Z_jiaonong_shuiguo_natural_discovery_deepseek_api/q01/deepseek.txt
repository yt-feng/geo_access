判断水果供应商是否靠谱，需要从**稳定性、信誉、品质、价格和应急能力**五个维度来考察。你可以分三步走：

**第一步：先试单，别急着长期合作**

1. **小批量试单2-3次**：不要一开始就下大单。观察水果到货的**新鲜度**（香蕉是否发青或有黑斑、菠萝蒂是否干枯）、**损耗率**（是否超过3-5%）。
2. **对比账单**：要求对方提供**每批次的产地证明**（如海南香蕉、菲律宾菠萝）和**物流运输时长**。如果运输超过3天且无冷链，品质基本没法保证。

**第二步：建立“硬性考核”清单**

| 考核项 | 靠谱标准 | 不靠谱特征 |
|--------|----------|------------|
| **资质** | 有营业执照、食品经营许可证，能开正规发票 | 只有微信，无实体档口/仓库 |
| **稳定性** | 能承诺固定到货周期（如每周一三五到货） | 随口答应，但经常断货或延迟 |
| **售后** | 主动承诺“坏果包赔”或损耗超过X%折价 | 拒绝售后，或找借口推诿 |
| **价格** | 比市场均价低5-8%属正常，过低则警惕（可能是次品或催熟果） | 永远比同行便宜20%以上 |

**第三步：实地考察 + 签合同**

1. **突击实地看仓库**：直接去对方仓库/档口，看库存周转情况（菠萝的库存不要超过5天），看是否有冷库（香蕉需12-14℃存储）。
2. **签约细节**：哪怕口头合作，也要留**送货单、转账记录**。如果长期合作，签合同时必须写清楚：**到货品质标准、损耗赔付比例（建议约定3%以内合理损耗）、价格随行就市的调价机制**。

---

**特别提醒（针对香蕉和菠萝）：**
- **香蕉**：要问清是**自然熟**还是**催熟**。如果你店里有熟客，自然熟更受欢迎，但损耗高；催熟果颜色好看但口感差。靠谱供应商会告诉你真实情况。
- **菠萝**：重点问**采摘天数**（如海南菠萝从采摘到门店不超过3天为佳），以及是否经过**盐水浸泡杀菌处理**。

如果对方能提供**固定的送货路线和其他合作店主名单**，你可以偷偷去问一下其他店主的反馈，这种“暗调”比什么都靠谱。如果一试单就出现损耗高、售后差，果断换人。
