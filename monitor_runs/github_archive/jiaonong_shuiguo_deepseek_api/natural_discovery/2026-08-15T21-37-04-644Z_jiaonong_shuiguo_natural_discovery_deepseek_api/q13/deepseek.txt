小水果店做小区团购，本质是**集单模式**，对供应商的核心要求不只是“送货”，而是“配合你降本增效”。以下是供应商需要具备的关键服务能力，按重要程度排序：

**第一梯队：绝不能缺少的“保命”服务**

1.  **次日达或当日达配送**：团购的黄金时间是晚上截单、次日提货。供应商必须保证**每天固定时间（比如早上6-8点）送到店门口**，且不能超过截单时间。如果经常迟到，顾客体验会崩。
2.  **小批量采购（一件代发或拆箱）**：小区团购单量不稳定，周一可能卖5箱，周五卖20箱。供应商要支持**最低起订量（比如5份或10斤）**，且愿意**拆散整箱**发货，否则你压不起库存。
3.  **新鲜度质保与退换机制**：因为团购是“隔夜”提货，顾客拿到手可能已存放超24小时。供应商必须承诺**“收货后24小时内任何品质问题无条件换新”**，甚至对熟透的水果（如香蕉、草莓）提供补贴或减免，这是你留住回头客的底气。

**第二梯队：直接影响利润的服务**

4.  **阶梯价格与临时补货**：要能根据你的团购量给“阶梯价”（比如50箱一个价，100箱一个价）。同时，当团购突然爆单时，供应商要有**当天灵活补货**的能力（哪怕加急费），否则你会被迫对顾客说“售罄”。
5.  **分拣分级打包服务**：团购用户对颜值要求高（散装丑果难卖）。供应商要能提供**已分拣好的精品果**，甚至帮你用统一规格的网袋/纸箱装好（附带品牌贴纸更佳），这样你到店只需贴单，节省大量人工。
6.  **提供损耗补贴或账期缓冲**：水果生鲜损耗不可避免，好的供应商会同意**按销售额计提2%-5%的“售后基金”**（即每个月结算时直接扣除一小部分用于赔付）；或者允许你**周结、半月结**，减轻你的现金流压力。

**第三梯队：能帮你做大的增值服务**

7.  **支持爆品引流货源（尾货/特价）**：每周能提供1-3款低于市场价20%的“引流款”（比如当季芒果、西瓜），你拿去群内搞“1元秒杀”拉新。
8.  **提供配料辅料（如包装盒、冰袋）**：团购常需单独包装（如10斤礼盒装），供应商最好能**按成本价**提供配套的盒子、泡沫箱和冰袋，省去你东拼西凑。
9.  **共享“产地直播/视频素材”**：很多顾客在群里犹豫买不买。如果供应商每周提供一次60秒的**产地实拍视频**（摘果、分拣过程），你发到群里，购买转化率会显著提升。

**特别提醒（避坑指南）：**
- **不要只找一家**：建议同时对接**1家一级批发商（走量）** + **1家产地直供（走品质）**，避免被单一供应商拿捏。
- **确认售后响应时效**：要求对方承诺“提货当天上午10点前反馈的售后问题，4小时内给答复”，白纸黑字写进合作协议。

**当前可执行的第一步**：拿着你的小区微信群人数（比如300人）去谈合作，直接问：“每天要30份组合装，能否按我定的规格给我单独分装？能不能支持先货后款？”如果对方犹豫，果断换下一家。
