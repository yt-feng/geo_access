针对香蕉这类呼吸跃变型水果（砍下来还会继续熟），核心策略是**“按需锁绿、动态催熟”**，而不是等它自然熟了再卖。跟采购（或供应商）沟通时，按以下几点提要求，能大幅减少损耗：

### 一、熟度要求（锁定“绿熟”级别）

1. **指定“货架期级别”**：要求供应商提供**3号色（全绿，或微黄仅尖部）** 的香蕉。测量标准是果皮颜色（绿→黄），全绿或刚转色的香蕉在常温下还能放3-5天。**绝不能要“黄熟”的货**——那种到店当天就会大片变黑。
2. **验收时抽检转色**：到货时随机开箱3-5箱，观察**果实棱角**。如果需要棱角饱满、边圆润的（那是后熟度偏高），会让它很快过熟；应该要求**棱角分明、果皮硬挺**，捏起来略硬但有弹性，不能有软腐。
3. **拒绝“爆籽”和“裂口”**：如果看到果柄处发黑、果皮有裂纹或小斑点，说明在运输途中已经过熟，这种货直接拒绝接受。

### 二、到货时间要求（倒排计划）

这个才是关键，鲜果损耗跟时间强相关：

1. **倒推催熟期**：香蕉从**绿熟到最佳食用期**（皮黄但果肉硬）在常温下约需 **3-5天**。所以跟采购下单时，要**明确“预计开卖日”**，并倒推**到货时间**：
   - 如果计划2天后开卖：要求供应商发**全绿果**，今天到货，店里自然放2天。
   - 如果计划第二天就开卖：要求供应商**提前在产地催熟至2-3号色**（绿黄相间），并**空运/冷链**确保当天到。
   - **严禁**要求“明天到货、明天就能卖”但又不让催熟——那必然到货时已经熟过头。

2. **错峰到货（分批次）**：不要一单进半吨。要求**每周2-3次小批量到货**，每次到货量以“未来3-4天销量”为上限。如果是一周一批，必须要求供应商**分成熟梯度发货**（比如第1天发全绿，第3天发转黄），自己按顺序上架。

3. **收货时限**：合同/口头协议里要求**“到货后2小时内必须开箱通风”**。如果供应商承诺“今天下午到”，就让对方务必下午到；晚上到会导致闷箱一晚，转熟加速。

### 三、到货时的操作要求（配合减损）

这些不算采购要求，但验收时同步执行：

- **开箱翻动**：到货后立即将所有香蕉**把柄朝上、果弯朝下**放置（避免压伤），并逐把检查有没有“软柄”（捏一下柄部，软的就是熟过头了）。
- **分温度区**：到货时如果手摸果身发热（超过25℃），必须**立即放入15-18℃的阴凉库**（不能直接上架），并打开箱盖透气。

### 四、采购话术模板（直接用）

您可以直接跟采购说：

> “这批香蕉我要**绿熟果（全绿、棱角分明）**，到货后我要在**X天内**上架售卖。如果你们不能保证到货后我能放3天以上，那就请**只发今天能到的货**，并确保**到货时果皮温度不超过22℃**。如果到货后发现是黄熟果或软果，这个批次我不接收，或扣款50%。”

**总结一句话**：**采购时买“绿不买黄”，到货时间“宁早一天勿晚半日”，批次“少量多次”**。这比单纯要求“熟一点好卖”更能控损。
