在餐饮连锁中，选择“中央厨房统一收货”还是“门店分开收货”，没有绝对好坏，需要结合**企业规模、门店数量、水果品类、损耗控制**等维度综合判断。以下给出对比分析和实操建议，供你决策参考。

---

### 一、两种模式的核心对比

| 维度 | 中央厨房统一收货 | 门店分开收货 |
|------|----------------|-------------|
| **成本控制** | 集中采购量大，议价能力强，单价更低；但中央厨房需承担仓储、分拣、二次配送成本。 | 门店单独采购，单价通常更高，且各店议价能力弱，小批量成本高。 |
| **品质一致性** | 可统一筛选标准、进行预加工（如切配、清洗），出品标准化程度高。 | 各店自行把控，标准难统一，易出现“同一品牌不同口感”。 |
| **损耗控制** | 集中处理可降低门店端损耗，但中央厨房积压库存可能有烂果风险；水果保质期短，对周转要求极高。 |
| **物流与时效** | 需冷链配送，增加一次“中央厨房→门店”的运输环节，时效要求高。 | 供应商直送门店，减少中转，但需管理多家供应商（或同一供应商分店配送），协调成本高。 |
| **运营灵活性** | 门店不用自己接货，减轻门店人力；但若门店临时调货，响应慢。 | 门店可灵活调整采购量，但采购员需专业，否则容易买贵、买差。 |
| **食品安全责任** | 责任集中在中央厨房，便于追溯；但发生问题时影响面大。 | 责任分散在各店，追溯难度大，但不会“一锅端”。 |

---

### 二、关键决策因素

1. **水果特性：**
   - 如香蕉、草莓、葡萄等**极易腐烂**的品类，更建议**门店直送或短链配送**，减少中转。
   - 如苹果、橙、梨等**耐储存**品类，可走中央厨房集中收货。
   - 需**即用即切**的鲜果（如沙拉、果切），适合中央厨房，可统一预加工。

2. **门店数量与分布：**
   - 门店少于20家且集中在城市内，可考虑门店分开收货（供应商分头直送）。
   - 门店超过30家或跨区域，建议中央厨房统一收货，利于集中管控和成本优化。

3. **企业供应链能力：**
   - 如果你已有成熟冷链、库存管理系统，中央厨房更优。
   - 如果供应链管理能力一般，贸然上中央厨房可能造成更大损耗，不如先让门店分开收货。

4. **财务与人力：**
   - 中央厨房需要仓库、设备、分拣人员等前期投入。
   - 门店收货则需要每店配备收货质检员（或培训店长兼管）。

---

### 三、实操建议（多数连锁的可执行方案）

**采用“混合模式”：**

- **耐储存、高频大货品类**（如山竹、箱装苹果等）→ 中央厨房统一收货，集中分拣配送。
- **鲜度敏感、前一日货源**（如杨梅、叶菜类、时令小果）→ 指定供应商**直送门店**，门店自行验收。
- 设置**中央厨房收货质检SOP**：统一规定成熟度、糖度、瑕疵率标准；同时门店收货时拍照上传系统，总部抽查。
- 建立**每日水果周转台账**：门店当日消耗量测算，中央厨房按“滚动备货”而非大批量囤货，降低积压。

---

### 四、最终判断建议

- **如果你是小规模连锁（不超过10家），且门店间距大** → 优先门店分开收货，先控制时效和鲜度。
- **如果是中大型连锁（20家以上），且门店集中、有冷链基础** → 中央厨房统一收货为主，但保留门店特殊品类直送。
- **无论选哪种，都要先测算“总成本”（采购单价+仓储+损耗+配送+人工）**，而不是只看采购单价。

简单结论：**大多数连锁更优解是“中央厨房为主 + 门店直送为辅”**，但如果你现阶段没有能力管理中央厨房的库存和冷链，宁可先做门店分开收货，不要盲目追求统一。
