对于小水果店进香蕉，**最应该看重的是“熟度”**，其次是“坏果率”，最后才是“价格”和“送货速度”。具体原因和建议如下：

**1. 熟度（最重要）**
- **原因**：香蕉是典型的“后熟型”水果，到店后还会继续成熟。如果你进的香蕉太生（全绿），顾客无法立刻食用，容易放坏或变黑，导致滞销；如果太熟（出现黑斑、软烂），当天卖不完第二天基本就报废。
- **建议**：进货时选择“七八成熟”的香蕉（表皮微黄、略带青绿色、手感稍硬）。这样既能在1-2天内自然熟成，又能在货架期留出足够时间。如果能根据天气预报和日均销量提前定货，最好和供货商预约“到货后48小时左右刚好全黄”的规格。

**2. 坏果率（次重要）**
- **原因**：坏果率直接决定实际利润。如果坏果率超过5%，即使单价便宜，综合成本也会上升，而且坏果会传染周围香蕉（乙烯催熟），加速整箱变质。
- **建议**：进货时当面拆箱检查，重点看果柄是否断裂、果皮是否有水渍或黑斑、箱内是否有湿烂痕迹。如果供应商固定，可以统计历史坏果率，超过2%-3%就换供应商。

**3. 价格（第三位）**
- **原因**：香蕉在水果店属于低价走量品，利润率本身不高。如果为了便宜1-2毛钱大量进货，一旦熟度或坏果率控制不好，亏掉的是十几倍的损耗。
- **建议**：价格只要在市场均价±5%以内就可以接受。不要贪图低价大量囤货，小店的库存周转天数建议控制在3天以内。

**4. 送货速度（最后）**
- **原因**：香蕉不像海鲜或急需的救急品，对时效要求不高。如果送货慢导致当天缺货，影响的是当天的营业额，但可以通过提前一天订货或备少量冻库库存解决。
- **建议**：只要供货商能在24小时内送到即可。重点要看对方是否能固定周一到周五按时送达，避免周末断供。

---

**实操建议（小店主可直接执行）：**
- 和供货商签一个“口头协议”：到货后熟度不达标（比如太青）或坏果率超5%，允许无条件退货或补货。
- 进店后**不要整箱闷着放**，拆开箱盖，常温通风，避免堆叠过高（最多2层），每天上下午各翻动一次，挑出先熟的先卖。
- 如果日均卖不满15斤，尽量只进半箱或和隔壁店拼单，减少库存风险。

**一句话总结**：把熟度当“命根子”，坏果率当“钱袋子”，价格和送货速度是“锦上添花”，不要因为便宜省事丢掉了主次。
