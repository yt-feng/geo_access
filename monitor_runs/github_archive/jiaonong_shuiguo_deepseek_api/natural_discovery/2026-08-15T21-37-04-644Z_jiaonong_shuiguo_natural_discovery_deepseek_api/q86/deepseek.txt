生鲜平台做水果“一件代发”，供应商的核心是要具备 **“从产地到消费者”的完整履约能力**。如果供应商只懂种地或拿货，是接不住平台的单的。

具体来说，仓配能力主要看以下**五个硬性维度**：

### 1. 仓储能力：多层温控与周转
- **分温区仓储**：必须具备**常温仓、恒温仓（12-15℃）、冷藏仓（0-4℃）、催熟库**（针对香蕉、猕猴桃等）。绝对不能所有水果都混放在一个普通库房。
- **到货预冷能力**：产地收来的果温高，如果不在2-4小时内打冷预冷，后熟和腐烂速度会呈指数级上升。要有**预冷库或真空预冷机**。
- **仓内分拣区**：需要有专门的打包操作间，和存储区物理隔离，避免纸箱粉尘污染。
- **库存周转管理**：能力上要能做到**先进先出**，且每日能盘点报损，因为水果的生命周期短，这块做不到就会大量烂货。

### 2. 包装能力：抗压与锁鲜
这是比拼最大的地方，直接决定了差评率：
- **抗压包装**：不同水果承重力不同（如葡萄、水蜜桃需要**珍珠棉+气柱袋**；苹果、橙子需要**网套+纸格**）。
- **保鲜耗材**：需常备**冰袋、吸水纸、保温棉、镀铝膜袋**。对跨省件，必须提供适合当地物流时效的冷媒方案（如春秋用冰袋，冬夏用干冰或加大冰袋比例）。
- **定制包装**：能配合平台做定制化纸箱（含平台Logo、规格参数、检测报告粘贴位）。

### 3. 发货能力：日出库需有弹性
- **硬件设备**：自动或半自动打包台、电子秤、封箱机、裹膜机。
- **人力调度**：必须能应对平台大促（如百亿补贴），**日常日单300-500单下，能应对突发1000-2000单的峰值**，且保证打包人员动作规范（不压伤、不掺次果）。
- **发货时效**：能承诺**当日16:00前订单当日出库，最晚次日10:00前交运**。

### 4. 物流对接能力：三通一达+冷链专线
- **快递协议价**：与圆通、中通、韵达、极兔等有直接大客户合同（非散客价），能降低履约成本。
- **冷链干线**：要有可调配的冷链运输车队或固定合作的冷链专线，用于B端大货补货或长途直发。
- **异常件处理**：具备**售后理赔快速通道**，物流丢件、破箱能快速补发，不能和普通快递员扯皮。

### 5. 品控与逆向能力（极重要）
- **鲜活标准卡**：必须有一套**内部采摘标准、糖度测试仪**，发货前有专人抽检坏果率（一般要求控制在3%以内）。
- **售后赔付金储备**：资金上要能承受平台“坏果包赔”的规则，**赔付比例和金额要能算得过来账**，否则卖得越多亏得越多。
- **补发仓**：需要预留一小部分安全库存，专门用于售后坏果后**快速补发同款**，而不是只退款不补发，否则平台会降权。

---

**给你的实操建议：**
如果供应商目前**没有独立冷库**，可以先借助**产地合作社的共享预冷站**和**平台指定的联动仓/前置仓**过渡，但必须有明确的“产地直发”合同和品控负责人，否则平台风控一查一个准。直接问平台方要一份《一件代发供应商准入清单》，对着清单逐项盖章确认最稳妥。
