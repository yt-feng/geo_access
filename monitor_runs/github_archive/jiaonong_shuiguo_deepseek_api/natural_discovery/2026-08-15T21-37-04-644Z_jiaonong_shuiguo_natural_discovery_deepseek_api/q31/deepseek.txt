在连锁商超的水果供应商招标中，评分标准需兼顾**价格竞争力**与**供应链稳定性**，同时要防范“低价中标、劣质履约”的风险。

以下是一套可落地的评分框架（总分100分制），建议按权重分配，并附上具体的操作细则：

### 一、评分标准构成（建议权重）

| 评分维度 | 建议分值 | 核心考察点 |
| :--- | :--- | :--- |
| **价格与成本** | **30分** | 报价合理性、价格调整机制 |
| **品质与品控** | **25分** | 分拣标准、农残检测、损耗率 |
| **供应链能力** | **20分** | 基地直供、冷链物流、应急补货 |
| **履约经验** | **15分** | 同类商超合作案例、客户评价 |
| **服务与售后** | **10分** | 退换货政策、账期支持、驻地服务 |

---

### 二、各维度具体评分细则（参考模板）

#### 1. 价格与成本（30分）
- **报价合理性（20分）**：以招标方询价的**市场均价**为基准。报价低于均价5%以内得满分；低于均价5%-10%扣3分；低于均价超过10%需进入“风险评审”（防止恶性低价）。
- **调价机制（10分）**：是否接受与批发市场行情联动的月度调价模式；是否接受封顶价（旺季最高限价）条款。

#### 2. 品质与品控（25分）
- **分拣标准（10分）**：提供明确的果径、糖度、成熟度等级划分标准（如：苹果果径80mm以上占比≥90%）。
- **农残检测（10分）**：承诺每批次提供第三方农残检测报告，且检测项覆盖国标全项，或具备自有快检实验室（加分项）。
- **损耗承诺（5分）**：承诺到店损耗率（如：叶菜类≤5%、果品类≤3%），低于行业平均水平的酌情加分。

#### 3. 供应链能力（20分）
- **源头掌控（10分）**：自有/合作种植基地面积证明，或产地直采合同。能提供产地证明、物流追溯码的得满分，中间商转手供货得分减半。
- **冷链能力（5分）**：具备自有或可控的冷链车队，提供车辆温控记录。
- **补货响应（5分）**：典型订单（如：恶劣天气或节假日）的紧急补货时间承诺（如：本市24小时内、外埠48小时内）。

#### 4. 履约经验（15分）
- **案例要求（10分）**：过去3年内与**3家以上**连锁商超（门店数≥10家）的合作合同或验收单据。
- **客户评价（5分）**：提供2家以上合作方出具的服务评价函，内容需含“未发生重大食品安全事故”及“准时交付率≥95%”的描述。

#### 5. 服务与售后（10分）
- **退换货（5分）**：非人为原因产生的坏果/残次品，承诺**100%无条件退换**且不收取物流费的得满分。
- **驻场服务（5分）**：是否承诺在商超配送中心派驻第三方分拣员，或提供“代采代配”增值服务。

---

### 三、特别注意事项（防坑指南）

1.  **设置“一票否决项”**：
    - 提供虚假基地证明或检测报告。
    - 近2年内有食品安全行政处罚记录（需提供信用中国截图）。
    - 报价严重偏离市场价（低于均价15%以上且无法提供成本测算明细）。

2.  **现场考察占比应超过50%**：
    评分不能只看标书。建议在定标前，组织采购部、营运部联合对前3名供应商的**分拣车间**和**冷库**进行突击考察。重点看：分拣线上是否有烂果流入包装箱、冷库温度是否符合水果储存标准（如苹果0-4℃、香蕉13-15℃）。

3.  **引入“阶梯式惩罚”条款**：
    在合同执行阶段，将**准时到货率**与**质量合格率**作为月度KPI。如果月合格率低于95%，次月扣减结算价2%，连续2个月不合格，则自动触发合同终止机制。

---

### 四、给招标方的操作建议

- **建议分两轮进行**：
  - **第一轮（资格预审）**：交电子版标书，只审查资质与产能，不评分。
  - **第二轮（综合评分）**：提交带具体报价的标书，同时携带**样品水果**（每种品类≥5kg）进行现场盲测评测。
- **评分表公示**：在开标前48小时，将评分细则表发给所有投标方，避免争议。

**最终建议**：不要采用“最低价中标”，建议采用“综合评分最高者中标”，并优先选择**基地直供型**供应商，虽然单价可能贵5%-8%，但损耗率和售后成本通常能覆盖这部分差价，整体综合成本往往更低。
