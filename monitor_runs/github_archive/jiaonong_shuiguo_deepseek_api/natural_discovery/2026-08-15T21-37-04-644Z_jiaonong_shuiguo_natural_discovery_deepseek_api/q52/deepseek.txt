针对甜品店采购香蕉后很快变黑的问题，核心在于**采购时的成熟度控制**和**到店后的储存管理**。以下是具体可执行的建议：

### 一、采购环节（源头控制）
1. **按用途分级采购**：
   - **用于当天制作**（如装饰、直接食用）：选择 **7-8成熟** 的香蕉（表皮微黄，略带青绿，手捏稍硬）。
   - **备货储存（未来2-3天）**：选择 **6-7成熟**（表皮青绿为主，手感结实）。
   - 若做香蕉泥、烘焙（加热会继续熟化），可稍熟一点，但不宜过熟。

2. **检查果柄与表皮**：果柄发黑、表皮出现黑斑（芝麻点）的说明成熟度过高，避免采购；表皮无裂痕、无挤压伤。

3. **避开“催熟环境”**：夏季运输车厢温度高，订货时要求供应商用带透气孔的纸箱，不要用密闭塑料膜包裹。

### 二、到店后处理（黄金1小时）
1. **立即拆箱散热**：香蕉在运输途中会积累乙烯气体，进店后**不要整箱堆放**，应平铺在阴凉处，散去箱内闷热湿气，避免捂熟。
2. **检查并分拣**：立即挑出有黑点、变软或破损的**单独存放**，优先使用。坏果会释放更多乙烯，加速周围香蕉成熟。

### 三、储存与摆放（关键步骤）
1. **温度控制**：香蕉的最佳存放温度为 **13~15℃**。如果店内室温超过25℃，应放入冷藏展示柜，但**不能低于12℃**，否则皮会变黑（冻伤）。
2. **悬挂或平铺**：
   - 有条件时**悬挂放置**（模拟树上状态），减少受压面，果汁不易淤积。
   - 若平铺，建议**拱面朝上**（让香蕉背脊朝上，接触台面的一面少），并定期翻转。
3. **隔绝乙烯源**：避免与苹果、梨、芒果、西红柿同放，它们会释放乙烯催熟香蕉。
4. **包裹果柄**：用保鲜膜或锡纸**包裹香蕉柄部**，能减少乙烯气体从柄部扩散到果实，可延缓变色约2-3天。

### 四、延长货架期的实用技巧
- **冰箱急冻法**：如果某批香蕉熟化过快，可剥皮切块后真空密封冷冻，用于甜品制作（如奶昔、冰淇淋），避免浪费。
- **表面处理**：若发现零星黑点，可在黑点处滴少量柠檬汁或白醋，可短暂延缓氧化，但效果有限，不建议作为主要手段。

### 五、每日检查制度
- **先进先出**：每天早班固定检查，将表皮开始出现小褐点的香蕉挑出，优先用于当日制作（比如烤香蕉、香蕉酱），确保新鲜品始终供应给顾客。

**总结口诀**：“买青不买黄，拆箱又分拣，挂起不压轴，包柄防催熟，冷藏限15度”。按此操作，香蕉到店后通常能保持3-5天外观良好。
