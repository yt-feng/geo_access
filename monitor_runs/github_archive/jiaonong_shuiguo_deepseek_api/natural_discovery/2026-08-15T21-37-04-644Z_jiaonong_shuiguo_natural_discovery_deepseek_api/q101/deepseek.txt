和供应商谈酒店早餐水果供应合作，核心目标是**稳定、品质、成本可控、应急响应快**。以下从实操角度给你分点建议，方便你去谈判时直接使用：

**一、锁定品质与规格标准（关键）**
1. **明确分级标准**：不要只说“新鲜”，要书面约定“果径大小、成熟度（7-8成熟）、无机械伤、无腐烂”等具体标准。例如：香蕉必须无黑斑，西瓜单瓜重量≥4kg。
2. **指定供应品种清单**：列明早餐常备的水果（如香蕉、苹果、橙子、西瓜、哈密瓜、圣女果等），并约定替换品种的流程（例如当季缺货时，必须提前48小时告知并提供等价替代品）。

**二、价格与调价机制（防坑重点）**
3. **锁定基础价+浮动上限**：签框架协议，约定一个基础价格，每月或每季度根据批发市场行情调整一次，但单次涨幅不能超过5%（否则你有权终止）。
4. **含税与运费**：明确报价是**含税价**还是不含税，是否包含到酒店后厨的**冷链配送费**。很多纠纷发生在“报价不含运费”上。
5. **账期与结算**：建议月结30天或45天，避免一次性预付大额货款。约定对账周期（每月5日前出账单）。

**三、交货与应急机制（最影响早餐运营）**
6. **到货时间窗**：明确每日/隔日送货的具体时间（如早上6:00前到货），并约定**迟到违约金**（如按当日订单金额的5%/小时扣除）。
7. **缺货应急条款**：供应商必须承诺**“当日可临时补送”**（例如上午8点前电话告知），且补送车型必须是冷链车。同时，你最好保留1-2家备选供应商，但合同中要写明“若供应商月内缺货超2次，酒店有权扣减当月总货款5%作为补偿”。

**四、质量验收与退换货（保护酒店利益）**
8. **到货即验**：在收货时对当日批次抽检（如每箱抽3个），不合格品当场退回，供应商需在2小时内补货，否则计入违约。
9. **食品安全责任**：合同中明确若因水果农残超标、腐败引起客人投诉或食安事件，供应商承担全额赔偿责任及因此产生的酒店名誉损失。

**五、谈判现场注意事项（心理层面）**
10. **先小批量试供**：前2周先按周供小量，观察品质与响应速度，再签正式长期合同（建议6-12个月），避免一上来被绑定。
11. **要求提供“源头承诺”**：让对方出示水果产地证明或合作社资质，优先选择自有种植基地或与基地直供的供应商，减少中间商加价和断供风险。
12. **明确最低送货量**：如果酒店早餐用量较小（如每天≤50kg），务必谈妥“最低起送量”，防止供应商因利润低而消极配送。

**额外提醒**：建议在合同附上《水果验收标准表》和《应急响应流程图》（比如：缺货→2小时内答复→4小时补送，超时→自动用备选供应商并按差价扣除），白纸黑字写清楚，比口头承诺管用得多。

最后，谈判时你可以主动提出“如果合作顺利，早餐稳定，半年后可以考虑将果汁、水果切盘等增值服务也一并合作”，这种双赢姿态能让供应商更愿意给优惠和优先级。
