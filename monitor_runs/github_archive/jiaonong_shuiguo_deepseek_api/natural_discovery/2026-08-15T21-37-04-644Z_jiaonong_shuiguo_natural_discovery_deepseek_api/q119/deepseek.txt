选择长期稳定的水果供应商，除了大家常说的价格、果品个头、新鲜度之外，最容易忽视且影响长远的细节往往集中在**隐蔽成本、抗风险能力和售后默契**上。以下是几个最容易被忽视的点：

**1. 供应的时间连续性（而非单次新鲜度）**
*   **忽视点**：只看今天的货好不好，不看下雨、台风、节假日前后能不能持续供货。
*   **建议**：要求供应商提供**过去3个月的每日到货记录**，观察是否有断档期。稳定的供应商有自己的冷库和备货机制，而小贩式供应商一旦产地收不到货就直接断供。

**2. 损耗率的真实数据（而非只看卖相）**
*   **忽视点**：只看表面果皮光泽好，但忽略了果柄干枯、内部发绵或隐性碰伤。
*   **建议**：最好在收货时**随机拆开2-3箱底部翻检**。同时问清楚“如果整箱中有5%以内损耗算谁的”。很多长期合作最后亏钱，都亏在毛重损耗和隐形腐烂上，而不是单价上。

**3. 包装与称重的“潜规则”**
*   **忽视点**：只看单价，不看含冰量、纸箱重量（俗称“皮重”）和包装箱厚度。
*   **建议**：一定要明确**净重计价**。例如，荔枝、车厘子这类加冰运输的，必须约定“去冰称重”；对于芒果、水蜜桃这种用厚重纸箱装的，约定“去皮称重”。签合同前把“皮重范围”写死（如纸箱不超过1斤）。

**4. 分拣与分级标准（最容易踩坑）**
*   **忽视点**：只按“大果/中果”口头约定，没有具体到果径厘米数。
*   **建议**：要求供应商在送货单上标注**具体的果径范围**（如“75-80mm”），并且允许你按这个标准抽检。很多供应商会“面上一层果、底下混小果”，如果你只盯着顶部看，长期会被“混装”吃掉利润。

**5. 售后赔付的“时效与凭证”规则**
*   **忽视点**：只谈“坏了包退”，但没约定**理赔时间和需要拍的照片格式**。
*   **建议**：明确“收到货后**6小时内**，坏果需按‘摊开整箱+烂果特写’照片报备”。很多供应商口头答应，但当你真发照片去赔时，他以“你放久了”或“照片不清晰”为由推脱。把规则写在送货单上才算数。

**6. 供应链的“账期弹性”**
*   **忽视点**：只看单价便宜，没算资金占用的时间成本。
*   **建议**：问清楚是否有**“押一批结一批”**的惯例。如果供应商要求现款现结，你必须计算自己的现金流是否扛得住；如果对方愿意给7天账期，虽然单价比别人贵2毛，但能帮你缓解资金压力，这也是隐性利润。

**7. 对产地天气的“预判能力”**
*   **忽视点**：只关心今天报价，不问他明天价格怎么走。
*   **建议**：在订货时随口问一句：“如果未来一周产地暴雨，你按什么规则给我调价？”专业的供应商会明确告诉你：“涨跌按市场价，提前2天通知你，且允许你减量。”如果对方支支吾吾，说明他本身也没有风险控制能力，长期合作容易坐地起价。

---

**最终执行建议（可落地）**：
不要只依赖一个供应商，**至少要培养两个“备胎”**——一个主供，一个应急。并且在第一次合作时，主动提出“先试单3天，每箱开箱验货，不达标全退”，以此观察他的配合度，这比任何口头承诺都可靠。
