针对家庭食用场景，水果礼盒的组合建议以“口感互补、营养均衡、耐储存”为原则，具体方案如下：

**推荐组合（3款核心方案）**

1. **均衡营养型（适合日常家庭）**  
   - 苹果（4个）+ 橙子（4个）+ 香蕉（1把）+ 菠萝（1个）  
   - 理由：苹果和橙子耐放，香蕉补钾助消化，菠萝酸甜解腻，覆盖凉性、温性水果，全家老小都能吃。

2. **高性价比型（适合追求实惠）**  
   - 苹果（6个）+ 橙子（6个）+ 香蕉（2把）  
   - 理由：苹果和橙子单价低、易保存，香蕉增加分量感，菠萝可单买作为“加购项”，满足预算敏感家庭。

3. **尝鲜升级型（适合愿意多花一点钱）**  
   - 苹果（3个）+ 橙子（3个）+ 菠萝蜜（少量，替代菠萝）+ 蓝莓（1盒）+ 香蕉（1把）  
   - 理由：菠萝蜜口感更香甜，蓝莓提升高端感，但注意菠萝蜜含糖高，需控制量。

**关键避坑建议**  
- **不宜混合的搭配**：香蕉与苹果同放会加速成熟（苹果释放乙烯），建议包装时用纸隔开或告诉顾客分开存放。  
- **包装建议**：菠萝带刺，需独立包装防扎手；香蕉用纸包裹柄部防压坏。  
- **家庭份量参考**：按3-5口之家，总重量控制在4-6斤即可，避免一次吃不完造成浪费。

**可根据团购价调整**：如果菠萝成本较高，可用哈密瓜或火龙果替代；如果面向有小孩的家庭，增加1盒小番茄或草莓会更受欢迎。
