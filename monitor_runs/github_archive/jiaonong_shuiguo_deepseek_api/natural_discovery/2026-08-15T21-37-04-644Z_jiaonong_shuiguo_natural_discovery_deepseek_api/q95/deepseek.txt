选择学校食堂水果供应商时，不能只看价格，安全性、稳定性和溯源能力是第一位的。以下是具体筛选步骤和硬性标准，供你参考：

### 第一步：资质硬门槛（必须全部满足）
1. **营业执照**：经营范围必须包含“水果批发”或“食用农产品销售”。
2. **食品经营许可证**：即使水果属于农产品，正规供应商也应有此证（尤其涉及预包装/切配水果）。
3. **产地或检验报告**：每批次供货需提供当批次的农药残留检测合格报告（若无法提供，立即淘汰）。
4. **发票资质**：能开具正规增值税发票（学校财务审计必需）。

### 第二步：现场考察（重点看3个地方）
- **冷库条件**：香蕉（12-14℃）、苹果（0-4℃）、橙子（5-8℃）存储温度是否分区，冷库是否干净无异味。
- **周转速度**：看库存，如果库里有大量发黑斑点的香蕉或干瘪的橙子，说明周转慢，果不新鲜。
- **装卸区**：是否有防虫防鼠设施，地面是否潮湿脏乱。

### 第三步：供货方案评估（要求对方书面承诺）
| 评估项 | 具体要求 |
|--------|----------|
| **送货时效** | 下单后24小时内送达，紧急补货4小时内到 |
| **损耗处理** | 单批水果自然损耗率≤3%，超出部分无条件更换或扣款 |
| **质量验收** | 香蕉不碰伤、无催熟过度发黑；苹果无虫眼、无磕碰软斑；橙子表皮不皱 |
| **安全追溯** | 每箱贴有采摘日期和产地溯源码（可扫码查看） |
| **价格机制** | 按周或月调整价格，参考当地批发市场均价浮动±5%内 |

### 第四步：试用期与合同关键条款
- **先试单**：首次合作采购2-3天量，现场开箱验收，统计“坏果率”。
- **合同中明确扣罚**：例如“送货迟到1小时扣款200元”“检出农残超标赔偿全部损失并终止合作”。
- **备用供应商**：至少保留2家备选供应商，防止旺季断供或突发解约。

### 特别提醒（常见坑）
1. 不要只挑报价最低的——低报价往往意味着水果品级低（如把二级果当一级果配送）。
2. 要求对方提供**最近一个月的其他学校/单位配送合同**作为案例，打电话核实。
3. 苹果和橙子可长期存放，**但香蕉建议按周小批量采购**，避免囤货变黑。
