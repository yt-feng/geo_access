在超市采购中，为了应对市场监管部门的农残抽检、保障食品安全并规避法律风险，建议你在签订供货合同或首批进货前，向供应商**书面索取并核验**以下核心资料：

**1. 法定证照（资质合规类）**
- **营业执照**（经营范围需包含“食品销售”或“新鲜水果”）。
- **食品经营许可证**（供应商销售环节必备；若为食用农产品销售，可提供备案证明）。
- **若为批发市场档口**，提供市场方出具的《食用农产品销售凭证》或“一票通”。

**2. 农残证明（核心检测类）**
- **当批次/同批次的农药残留检测报告**：
  - 优先索要**第三方权威机构（CMA/CNAS认证）**出具的检测报告，要求注明“敌敌畏、甲胺磷、氧乐果、克百威、毒死蜱”等常规高毒农药项目。
  - 若供应商提供的是快检报告，必须要求其加盖市场管理方或供应商鲜章，并注明采样日期、品种、合格结论。
- **食用农产品合格证**（“一证一报告”制度下，产地开具的合格证通常包含自检或承诺信息）。
- **产地证明**（如产地村委会、合作社或产地经销商出具的证明，证明水果来源地）。

**3. 专项承诺类**
- **无农药残留承诺书或质量保证书**：由供应商法定代表人签字并盖章，承诺当批次水果符合GB 2763-2021《食品安全国家标准 食品中农药最大残留限量》。
- **若为绿色/有机水果**：索要对应的认证证书复印件（绿标、有机标），且证书需在有效期内。

**4. 过程记录类（便于追溯）**
- **进货查验记录**（供应商自己采购时的源头记录，用于倒查）。
- **冷链运输交接单**（部分水果需冷链，需确认运输温度，防止变质引发变质性农残超标误判）。

---

**实操建议（直接可执行）：**

- **必须当场核验原件，并留存加盖公章的复印件**，注明“复印件与原件一致，仅限本次供货使用”。
- **索要上述资料的时间**：在首次谈判或下订单前索要，不要等到货后再要。若供应商拒绝提供或无法提供，建议直接终止合作。
- **关于快检报告的局限**：快检只能初步筛查，无法覆盖所有农残项。为最大限度规避抽检风险，**强烈建议每批次少量送检第三方**（如当地农检中心或SGS等），费用不高（一般几百元），但能从根本上堵住风险。
- **特别注意**：**进口水果**必须索要《中华人民共和国出入境检验检疫入境货物检验检疫证明》，该证明上有明确备注“农药残留检测合格”且需与海关放行批次号对应。

如果供应商无法提供检测报告，建议在该批次入库前，**坚决执行“先快检、后入库”**，用自己门店的快速检测设备（酶抑制率法）当场验证，检测合格后再收货并留档记录。
