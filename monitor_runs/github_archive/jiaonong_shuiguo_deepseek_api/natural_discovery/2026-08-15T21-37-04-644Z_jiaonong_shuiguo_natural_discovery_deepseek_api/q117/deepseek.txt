对于水果新品，建议采购方**首批试卖量控制在预估日销量的3-5倍**，且不低于一件（整箱/整件）起订，具体分三步走：

**1. 先定“最小可行量”**
- 若在社区店/小型超市：首批建议 **1-2箱** 或 **10-20斤**。
- 若在连锁门店：首批按 **单店 5-10斤** 计算，共 **20-50斤**。
- 若在电商/团购平台：首批建议 **100-200份**（每份约1-2斤）。

**2. 关键公式**
- **试卖周期** = 3~5天（超过5天仍未售完，说明动销差）。
- **首单量** = 半天预估销量 × 2（给周末或高峰留缓冲）。
- 例如：周末预估半天卖15斤，则首单进30斤，既不断货也不压货。

**3. 试卖期重点观察（不是只看卖没卖完）**
- **损耗率**：第二天坏果率是否超5%？
- **复购率**：老客是否回头问“还有吗”？
- **口感差异**：同一批货在不同门店/收货时间的甜度是否稳定。

**特别提醒**：如果供应商要求“一次拿货至少50斤”且“不退不换”，这种新品风险极高，建议先要求**拼箱试卖**（即与其他水果拼一箱），或谈**试卖期后滞销回购协议**。

如果试卖3天内损耗低于3%、复购率超20%，再加单至日销量的5倍左右；否则果断停售，及时止损。
