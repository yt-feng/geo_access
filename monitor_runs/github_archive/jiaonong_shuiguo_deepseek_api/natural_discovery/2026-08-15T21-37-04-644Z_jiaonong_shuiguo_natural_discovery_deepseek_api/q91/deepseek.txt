针对便利店上架香蕉，**建议优先选择“小把包装”（2-3根）**，其次是“单根独立包装”，**不建议选整袋装**。

具体原因和操作建议如下：

1. **消费场景匹配（最重要）**  
   便利店的核心客群是单身白领、学生、临时补充能量的人，往往是“即买即走”，一次性购买量小。  
   - **小把（2-3根）**：刚好是1-2天内的食用量，既避免了浪费，又比单根看起来更有“分量感”，客单价适中（通常定价在3-6元区间），复购率高。  
   - **单根**：适合作为早餐或应急水果，单价可以做得很低（比如2-3元），但毛利较低，且容易显得“过于寒酸”。  
   - **整袋（5根以上）**：重量大、单价高，不符合便利店的快速决策逻辑，容易滞销。而且香蕉成熟速度快，一旦整袋卖不动，损耗会成倍增加。

2. **损耗控制（便利店盈利关键）**  
   香蕉是后熟型水果，一旦成熟，货架期只有2-3天。  
   - 小把会减少“触碰挑拣”导致的机械损伤，且消费者一次拿走的数量少，剩余库存的压力小。  
   - 整袋装的香蕉往往在堆头中被人反复翻动，极易产生压痕、黑斑。

3. **视觉与陈列**  
   - 小把香蕉可以用**透明保鲜膜**或**有透气孔的塑料袋**封装，标签注明“当日鲜果”，放在收银台附近或冷藏柜上方的常温货架。  
   - 单根的建议放在小竹篮里，整齐摆放，但要注意防止顾客“只挑好看的”，导致剩下丑的积压。

4. **定价策略**  
   - 小把装建议按“把”定价（如3根装5元），不要按斤称重，能增加冲动消费。  
   - 如果同时提供单根，定价建议在2.5-3元，用来吸引极限预算的客户。

**最终建议**：以 **“3根小把装”为主力商品，配少量“单根”作为引流款**。同时每天上午补货（香蕉怕压不怕放），不要一次性上架过量的成熟香蕉。如果门店有冷藏风幕柜，可以放1-2天未全熟的香蕉，标注“可放2天，自然熟更甜”，减少折价损失。
