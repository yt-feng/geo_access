针对便利店面积小、品类控制难、损耗高的痛点，可以从**“少而精”**和**“周转快”**两个核心维度来管理。

以下是一套可落地的执行方案：

### 一、 品类控制：从“全”转向“精”

小面积便利店不适合卖整果（如大西瓜、整袋苹果），要卖**“即食型”和“应急型”**水果。

1.  **确定“黄金三品”**：
    -   **引流品（1-2款）**：选择当季最畅销、价格透明的单品（如夏季的西瓜/麒麟瓜、冬天的砂糖橘）。价格极低，甚至可以微亏，用来带动进店率。
    -   **利润品（2-3款）**：选择便于携带和储存的水果（如香蕉、苹果、梨、圣女果）。这是毛利的主要来源，品质必须过关。
    -   **冲动品（1-2款）**：选择颜值高、单颗售价低的水果（如蓝莓盒装、金桔、应季草莓小盒）。适合摆在收银台附近，激发随手单。

2.  **执行“1㎡极限选品法”**：
    -   **SKU数量控制**：门店水果SKU控制在 **8-12个** 以内。超过这个数，不仅陈列面积不够，而且会分散顾客注意力，增加损耗。
    -   **规格限制**：**只进小包装**。例如香蕉只进4-5根的小把，苹果只进2-3个装的小袋，坚决不拆散卖散称（除非有专门称重台），避免顾客翻动造成机械损伤。

3.  **按“动线”布局**：
    -   香蕉（易熟）放在**门口最外侧**，用于吸引顾客。
    -   苹果、梨（耐放）放在**中部货架**。
    -   草莓、蓝莓（娇贵）放在**收银台前**的冷风柜。

### 二、 损耗控制：源头与日常管控并重

小面积便利店的损耗控制，核心在于**“只卖一天的量”**。

1.  **采购端：采用“少进勤补”策略**
    -   **不要**为了拿批发价一次进一箱。与本地水果批发商或前置仓建立**“每日退换”**协议（次日达，当天坏果可换）。
    -   **晚上8点后**去批发市场拿尾货，价格常有惊喜，但仅限采购**耐储存**的品种（如梨、苹果）。
    -   如果门店没有专门冷柜，坚决不采购荔枝、杨梅等极度娇贵的水果。

2.  **门店端：推行“一日两翻”制度**
    -   **早班整理**：开门前将全部水果擦干水渍，翻动一遍，将底部压坏的挑出低价处理。
    -   **晚班复盘**：闭店前2小时，将表面有轻微瑕疵但未变质的水果**自行降价**（贴黄色特价标签），或者做成**果切拼盘**，在当晚卖完。**原则是：宁可在店里降价卖，也不放到第二天报损。**

3.  **体验端：**“即买即走”**减少人为损耗**
    -   在货架旁张贴**“请勿用力捏按”**的提示。
    -   销售过程中**不提供“先尝后买”**（便利店毛利低，试吃损耗大），改为**“买一盒，送一颗散装”**的形式，既防止浪费又促进复购。

### 三、 最容易忽略的“隐性损耗”与对策

-   **电费损耗**：水果冷风柜不要开最大档，设定在 **10°C-12°C** 即可（香蕉类反而不能放太冷），既能保鲜又省电。
-   **内包装损耗**：如果采购的是散装整箱，**必须拆除原有厚重纸箱**，换成轻便的塑料陈列盒。重的纸箱会压坏底层水果，且不美观。

### 四、 极简执行清单（每日）

| 时间段 | 动作 | 目的 |
| :--- | :--- | :--- |
| **09：00** | 到货验货：拒收病斑、软烂果 | 防止源头带损 |
| **12：00** | 巡场：挑出被顾客碰伤的次果 | 转至特价区 |
| **17：00** | 巡场：香蕉若发青则补货，发黄则促销 | 控制成熟度 |
| **20：00** | **特价清货**：所有非硬果全部现折价 | 当日必清 |

**最后的建议**：如果连续一周，某款水果的单日销量低于5份，**直接下架**。在小面积门店里，**“无损耗”比“有销量”更重要**——卖不动的就是损耗。
