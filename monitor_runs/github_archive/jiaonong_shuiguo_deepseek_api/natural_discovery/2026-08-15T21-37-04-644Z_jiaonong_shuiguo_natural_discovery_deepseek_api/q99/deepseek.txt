选择水果批量配送供应商，核心是**稳定、新鲜、性价比**。你可以从下面几个维度去筛选和谈判：

### 一、 优先考虑供应商类型
1. **本地大型农批市场**：价格最低，但品质波动大，需要自己去挑。
2. **专业水果配送公司**（专门做B端企业或餐饮的）：有冷链车，损耗率低，品控相对稳定，是最推荐的选择。
3. **线上生鲜平台**（如美菜、快驴等）：适合中小批量，下单方便，但品种可能受限，价格略高。

### 二、 考察硬性指标（重点）
- **配送时效**：必须要求**次日早晨**送达（最好9点前），否则水果不新鲜。
- **损耗包赔**：合同中要写明“当日损耗超过X%（如3%）部分免费补送或退款”，这是防止缺斤少两的关键。
- **换货机制**：如果员工投诉酸涩、坏果，供应商必须在**2小时内**响应补发。

### 三、 水果选品建议（根据公司偏好）
- **应季水果**（性价比最高）：如当下时令的西瓜、蜜瓜、桃子等。
- **耐放类**（减少损耗）：苹果、橙子、梨、柚子。
- **注意避开**：异地采摘的娇贵水果（如草莓、山竹），配送途中容易压坏，如果一定要吃，建议单独购买小包装。

### 四、 谈判与试单
- **先试单**：不要一次性下大单，先下 5-10 人份的试单，看包装（是否有防震网、独立盒装）和新鲜度。
- **谈账期**：一般可以谈成月结，避免预付全款。
- **合同要点**：明确写清“水果成熟度”和“具体甜度标准”（如：要求当日货架期不低于3天）。

### 五、 特别提醒（防坑）
- **警惕超低价**：低于市场价20%以上的，大概率是**果二次品**（分级时挑出的外表有疤但内部完好的），虽然能吃但观感差。
- **看皮不看肉**：现场验货时，一定要开箱检查底部，很多供应商上面放好果，下面垫坏果。
