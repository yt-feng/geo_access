第一次与水果供应商进行小批量试单，核心目标是**用最低的试错成本，验证供应商的货源稳定度、品质把控、履约能力和沟通响应**，而不是追求利润。

以下是一套完整的小批量试单设计方案，共分四步：

**第一步：试单前的“软验厂”（必做，免费）**
在真正下单前，先用2-3个问题筛选供应商，主要看其专业度和诚信：

- **索要资质与批号**：要求对方提供当季度的水果农残检测报告、进货单据（原产地证明）。若对方支支吾吾或只发一张模糊的网图，直接淘汰。
- **视频看货**：要求对方在**自然光下**，对**随机抽样的5-10个果**进行360度视频展示，并当场用卡尺测果径、用测糖仪测糖度。如果对方拒绝，说明其货源不稳定。

**第二步：订单量设计（控制在最小起订量的130%）**
不要按“箱”订，要按“客户需求”订。目的是为了测出真实的损耗率。

- **数量公式**：预估第一批次客户（比如5-10个老客户或社群）的7天消耗量 × **140%**。
- **品种策略**：不要只订1个单品。建议选择**2个畅销款+1个高毛利款**，每款不超过20-30斤。如果只订一项，无法测试供应商对不同品类果品的处理能力。
- **硬性要求**：明确要求供应商提供**“防撞气泡棉”+“独立果托”**包装，并拍照留底。如果到货后出现大量挤压破损，且包装不符合要求，这是供应商的履约责任。

**第三步：合同与付款的“防火墙”设计**
小批量的核心是**不让对方觉得你是小客户而轻视，也不让对方觉得你是大客户从而压死你**。

- **付款方式**：**坚决反对全款预付**。建议采用 **30%定金 + 70%尾款验货后付**。如果对方坚持要求100%全款，风险极高，建议放弃改用“一件代发”模式测试。
- **验收条款（写入合同或聊天记录）**：明确写明 **“货到24小时内，若出现软果、腐烂超过5%（按个数计），供应商需免费补发同等品质的货，或全额退款该批次”**。注意，这里要写“个数”，不要写“重量”，因为水果失水是正常的。
- **违约责任**：约定 **“若延迟发货超过12小时，按货款的3%/天扣款”**。这个条款主要是为了震慑，防止对方为了拼车发货而让水果在车里捂了几天。

**第四步：试单后的“三维评估表”**
这批货卖得怎么样不重要，重要的是给供应商打分。

| 维度 | 具体观察指标 | 合格线 |
| :--- | :--- | :--- |
| **货品硬指标** | 到货损耗率（破皮/压烂/过熟） | <3% |
| **货品软指标** | 果径是否达标、糖度是否达标、口感与描述是否一致 | 一致率>90% |
| **服务硬指标** | 发货时效（下单到发出）、物流跟踪单号是否准确 | 24小时内发出 |
| **售后硬指标** | 针对你反馈的1个小问题（如有个别软果），处理速度与态度 | 2小时内给出解决方案 |

**关于后续合作的关键决策：**
试单结束后，不要急着下大单。可以给供应商发送一份**《试单反馈单》**，列出你的评分和问题。如果第一单在品质和履约上都达标，那么第二单可以翻倍至50斤，并开始谈**阶梯价、账期（月结）以及退换货补充协议**。如果第一单出现任何一项硬指标不合格，原则上不建议继续合作，因为水果行业试单不合格，大概率是源头基地或分拣环节有系统性缺陷，靠催款或换货解决不了根本问题。

**特别注意（避坑提示）：**
- **不要问**“你们的水果甜不甜？”，而要问“这批果的入库日期是哪天？”——这是判断新旧库存的关键。
- **不要用**“多少钱一斤”来砍价，要用“我要10公斤，给我报个含泡沫箱和空运到付的落地价”——防止对方在包装和运费上玩猫腻。
