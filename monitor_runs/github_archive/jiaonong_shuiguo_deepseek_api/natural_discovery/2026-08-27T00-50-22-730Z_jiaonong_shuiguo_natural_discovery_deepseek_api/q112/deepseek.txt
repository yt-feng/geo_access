在水果采购合同中，“坏果率”的具体赔付阈值没有统一法定标准，完全由买卖双方协商确定。但根据行业惯例和常见风控做法，建议参考以下区间：

1. **常规基准线（较宽松）**  
   - 坏果率 **≤5%**：一般视为正常损耗，不赔付。  
   - 坏果率 **5%~10%**：超出部分按比例折算金额赔付（例如：8%坏果，赔付3%对应货款）。  

2. **对于高价值/易腐水果（如草莓、荔枝、车厘子）**  
   - 建议将基准线压至 **≤3%**，超过即触发赔付，且可约定“整箱全额赔付”或“降级处理”。  

3. **合同条款必须写清的三件事**  
   - **判定标准**：例如“坏果”定义（腐烂、压伤、发霉、碰伤面积超过1/3等）。  
   - **验收时间**：到货后 **24~48小时内** 书面提出异议，逾期视为接受。  
   - **赔付方式**：按原价退款、补发同等数量、或在货款中直接扣除，需明确计算基数（按整箱重量还是净果重量）。

- 如果对方合同未写明，先按 **5%** 作为谈判底线，争取写为“超过5%部分按货款1.2倍赔偿”以增加违约成本。  
- 若您是买方且无法谈判，至少保留到货时开箱视频、坏果照片和物流签收记录，作为后续争议证据。
