试卖新品的采购量，核心原则是：**“小批量、高频次、控损耗、测动销”**。

对于水果这类生鲜品类，建议的**首批试卖量**通常控制在**1-1.5天的预期销量**，或者**单店3-5箱（按标准件）**。具体可以按以下维度来定：

### 1. 精准测算公式（最稳）
**首次试卖量 = （店铺日均客流 × 该品类预估转化率）× 客单重量 / 单箱重量**

- **举例：** 如果门店日均客流500人，新品是某类柑橘，预估转化率3%（即15人会买），人均购买2斤，那就是30斤。若一箱20斤，**首批进1.5箱（即1.5天量）**最稳。

### 2. 按风险分档（简单粗暴）
- **高损耗水果（如草莓、荔枝、山竹、阳光玫瑰）：** 首批只进**0.5天销量**，甚至按“把/盒”进货，宁缺毋滥。因为损耗是最大成本。
- **常规水果（如苹果、梨、橙子）：** 可进货**1.5-2天销量**，因为耐存放，且补货容易。
- **进口高价水果（如A级车厘子、晴王）：** 首批只进**小规格礼盒**或**散装极限量**，通常不超过20盒，看复购再加大。

### 3. 合同保护（关键动作）
**不要一次性买断！** 必须在合同或口头协议中明确：
- **首批试卖期**（比如7天）
- **损耗共担机制**：如果试卖期损耗超过5%，供应商需承担部分或换货
- **尾货退货权**：未售完的按比例退回（一般生鲜惯例是允许退10-20%）

### 4. 观察指标（何时加量？）
不要只看“卖光了”就加量。要看三个数据：
- **复购率**：首次购买后的7天内，有没有回头客？（≥15%是可推的好品）
- **毛利贡献**：扣除损耗后，毛利率是否≥25%？
- **连带率**：买这个新品的人，有没有顺便买了别的水果？（好品能带旺整店）

### 5. 实操提醒
- **先上架，后宣传：** 先在显眼位置放3天，看自然动销率，再决定是否主推。
- **避免堆头：** 试卖期不要做大型堆头，用小货架或台面陈列，减少后期处理压力。
- **每日盘点：** 每天记录“进货量-售卖量-损耗量”，一旦损耗率超过15%，立即启动退换货流程或下架。

**一句话总结：** 首批按“1天销量”进货，签好试卖协议，用7天数据说话，好卖再加倍，不好卖立即退。这样既给供应商面子，又保住自己现金流。
