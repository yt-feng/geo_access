为公司下午茶批量采购水果，选择合适的供应商需要兼顾**价格、品质、配送稳定性**和**售后**。以下是一套可执行的筛选和评估方案：

---

### 第一步：明确你的核心需求（先定标准，再找供应商）

在联系供应商之前，先整理出这几项关键指标，写下来：

| 需求项 | 参考标准（建议） |
|--------|----------------|
| **配送频率** | 每周1次 / 每日1次（取决于公司规模和水果消耗速度） |
| **水果种类** | 固定几款常备果（如香蕉、苹果、橙子）+ 1~2款应季果（如车厘子、西瓜） |
| **份量/预算** | 按人头预算（例如每人15-25元/次），或按箱/按篮打包 |
| **验收要求** | 当日到货是否新鲜、有无坏果、是否支持临时补货 |

---

### 第二步：供应商渠道排查（优先本地，其次平台）

| 渠道类型 | 优点 | 风险 | 适用场景 |
|---------|------|------|---------|
| **本地水果批发市场**（如嘉兴水果市场、广州江南市场等） | 价格最低，可现场验货 | 需自提或找跑腿，缺机动性 | 公司附近有专人可自提 |
| **本地果蔬配送商/农贸公司**（社区团购供应链） | 可谈账期、可定制包装、配送稳定 | 需实地考察仓库卫生 | 中大型公司（30人以上） |
| **生鲜电商B端（如美菜、快驴进货、叮咚买菜企业版）** | 下单方便、有售后、可小批量 | 单价比批发贵10%-20%，品质波动 | 小公司、临时加购 |
| **水果品牌直供（如百果园企业购、盒马企业版）** | 品质统一、售后好 | 价格偏高，最小起订量可能较高 | 预算充足、追求品牌感 |

> **建议组合打法：** 日常用量大（每周两次+）用本地批发商，紧急补货用电商B端当日达。

---

### 第三步：供应商考察与验货清单（务必现场或发视频确认）

无论是线上还是线下，至少完成以下“三查”：

1. **查资质**：营业执照、食品经营许可证（看经营范围是否有鲜果）。
2. **查现场**（批发商）：仓库是否通风、有无果蝇/霉味；看他们库存周转速度（如果一个品种积压超过3天，说明卖不动，可能不新鲜）。
3. **查包装**：是否提供分装盒/果篮，还是整箱原装。原装箱损耗率通常更高（每箱大约损耗5%-15%），需要确认损耗承担方。

---

### 第四步：签订合同/合作协议时的关键条款

| 条款 | 描述 |
|------|------|
| **损耗标准** | 明确“坏果率”超过某个比例（如5%）如何赔付：换新果 or 按差价退款 |
| **配送时间** | 约定送达时间窗口（如上午10点前），超时按比例扣款 |
| **临时加单** | 提前几小时下单可次日必达（通常提前6小时） |
| **价格调整机制** | 水果价格波动大，签订月价锁价或按周调价，避免突然涨价 |
| **最低起送量** | 防止因公司人少被拒单，或被迫囤货 |

---

### 第五步：试运行建议（非常重要）

先不要直接签长约，建议先试运行**2-3次**：

- 第1次：测试配送准时率和果品完整度。
- 第2次：随机抽查果品甜度/成熟度（让行政同事盲吃评价）。
- 第3次：测试一次临时加单（模拟周五下午突然要求加购）。

试运行通过后，再签月度或季度合同。

---

### 一句话总结

> **首选本地有实体仓库的配送商（现场看货）+ 电商平台作为后备补货渠道，合同里白纸黑字写清损耗赔付和配送时限，先试3次再签约。**
