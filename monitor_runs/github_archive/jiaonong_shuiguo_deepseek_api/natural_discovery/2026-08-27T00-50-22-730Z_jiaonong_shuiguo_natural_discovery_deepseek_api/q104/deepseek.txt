单位采购水果时，如果到货品质不一致（例如大小、甜度、新鲜度参差不齐），验收和售后需要做到**留痕、分级、定责、速办**。以下是具体操作建议：

---

### 一、验收阶段（收货当天）

1. **拍照/录像留证（必须做）**
   - 开箱前先拍外包装、物流单号、封条。
   - 开箱后，将全部水果平铺，用手机横拍全景照，再对瑕疵果（压伤、腐烂、发霉、过软、变色）和正常果分别拍特写。
   - 视频记录开箱过程，从拆封到摊开，中间不要剪辑。

2. **当场抽检比例**
   - 建议按 **10%~20%** 的比例随机拆开品相较好的外层果箱，检查底部和中间是否掺次品（常见手法：上层好果、下层次果）。
   - 如果总箱数超过20箱，可抽检不少于5箱。

3. **明确分类与标准**
   - 按“合格果”“轻度瑕疵果（可食用但卖相差）”“严重问题果（腐烂、变质、不可食用）”三级分类。
   - 称重生果量，记录数量（例如总采购100斤，合格85斤，轻度10斤，严重5斤）。

4. **当场提出异议**
   - 在签收单上注明“已开箱检查，发现品质不一致”，不要直接签“完好”。
   - 如果属于明显供货商责任（如腐烂超过5%，或大量青涩不熟），**可拒收整批或部分退还**，并要求重新发货。

---

### 二、售后处理阶段（签收后24~48小时内）

1. **按“质”和“量”分开索赔**
   - 重量短缺：称总重量与送货单比对，短缺部分要求补发或退款。
   - 品质差异：按以下阶梯协商：
     - 轻微落差（个别果有斑点）：可要求8~9折结算，或下次采购抵扣。
     - 明显不合格（腐烂/不熟超过10%）：要求无条件换货或全额退款相应部分。
     - 严重不合格（超过20%或整箱变质）：整批拒收，并要求补偿人工分拣成本。

2. **提供证据链**
   - 将开箱照片、视频、抽检记录、合格/不合格的详细清单打包发给供应商。
   - 写明采购单号、到货日期、问题描述，以邮件或微信有记录的方式发送，避免口头沟通。

3. **设定处理时限**
   - 要求供应商在 **24小时内** 给出处理方案（换货/补发/退款/折扣）。
   - 若供应商拖延，可同步向采购平台（如单位食堂集采APP、团购平台）投诉并申请仲裁。

4. **如涉及长期供货合同**
   - 记录每一次到货品质等级，若多次（≥2次）出现明显不一致，可依据合同条款提出终止合作或降低采购价。

---

### 三、防止再发生的预防措施

| 问题点 | 措施 |
|--------|------|
| 供货商挑拣不严 | 下次采购在合同中注明“到货合格率≥95%，否则按比例扣款” |
| 运输挤压 | 要求供应商用分隔泡沫箱、气柱包装，禁用大袋散装 |
| 到货时间过长 | 锁定冷运（0~5℃），最迟48小时内送达 |
| 标准模糊 | 提前与供应商确认“大小等级（如直径≥6cm）”“成熟度（7~8成熟）”并写入订单备注 |

---

### 四、特殊情况提醒

- **如果是单位食堂大规模采购**，建议直接对接本地水果批发市场的供应商（可实地验货），不要跨省采购容易变形的草莓、荔枝等高损耗水果。
- **如果到货品质不一致但已有部分正常使用**，建议保留部分不合格实物，必要时可送市场监管部门质量检测（属于食品安全范畴的，如农药残留，需送检）。

最后，**字面留痕比口头承认更重要**，任何沟通（电话、微信群）后，都补一条文字确认：“关于今日到货XX箱XX水果，我方已记录问题如下，请迅速处理，如无异议视为认可。”这样售后纠纷会少很多。
