针对茶饮店采购菠萝，**首选是果丁**，其次是果泥/果酱，最后才是鲜果。具体选择取决于你的产品定位和出杯效率，以下是详细的对比和建议：

### 1. 为什么“鲜果”不适合茶饮店主力使用？
- **成本高且不稳定**：鲜菠萝去皮、去芯、去眼，损耗率高达40%-50%，且成熟度难以统一，口感时酸时甜。
- **处理耗时**：切丁、切片的效率极低，在高峰期严重拖慢出杯速度。
- **风味不稳定**：不同批次的菠萝甜度差异大，容易导致每杯果茶口味不一致，影响复购。

**适用场景**：仅建议作为**顶部装饰**（如一片新鲜菠萝片）或**短保质期的特调限定款**，不建议作为日常批量使用。

---

### 2. 果丁（冷冻/罐装）：**最推荐的首选**
- **优点**：
  - **口感真实**：保留了菠萝的纤维感和咀嚼感，咬下去有颗粒感，和果茶更搭。
  - **出杯快**：开袋即用，直接加入杯子或捣压，出杯效率高。
  - **口味稳定**：工厂标准化糖度处理，批次差异小。
  - **成本可控**：冷冻果丁损耗低，且价格通常低于同重量的鲜果处理成本。
- **选择要点**：
  - **形态**：建议选**1cm左右的小方丁**，太大影响吸管吸食，太小没口感。
  - **包装**：优先选**冷冻果丁**（-18℃保存），优于罐装果丁（罐装常有糖水味，且果肉偏软烂）。
  - **供货商**：找专门做餐饮定制的水果加工厂，避免买超市零售款（含防腐剂或过甜）。

---

### 3. 果泥（菠萝酱/冷冻果泥）：
- **优点**：
  - **风味极浓**：能快速带出菠萝香气，适合做“菠萝乳酸菌”“菠萝冰沙”等浓郁型饮品。
  - **无需处理**：直接怼进雪克杯或破壁机，零准备时间。
- **缺点**：
  - **口感单一**：如果整杯只用果泥，会缺乏咀嚼感，略显廉价。
  - **甜度难控**：市售果泥通常含较多糖浆或添加剂，需要精确控制糖浆比例，否则容易齁甜。

---

### 4. 终极搭配方案（运营角度最优解）：
**日常主力用“冷冻菠萝丁” + 少量“菠萝酱/果泥”调配糖水比例 + 顶部放“鲜菠萝片”装饰。**

- 果丁提供咀嚼感和果肉真实感；
- 果泥/果酱提供浓郁菠萝香气和稳定甜度（或调整酸度）；
- 鲜果片作为视觉卖点，提升产品价值感。

**注意事项**：
- 如果采购量大（月采购超10箱），直接找供应商谈**定制糖度**（例：白利度BX值14-16），避免过酸或过甜。
- 如果只做单一爆款（如“手打菠萝茶”），建议**冷冻果丁+手捣**，最能还原现切风味。

**总结一句话：别买鲜果做主力，买小颗粒冷冻果丁（配少量果酱调味）是最稳的选择。**
