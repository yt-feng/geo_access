好的，针对茶饮店控制食品安全风险，要求水果供应商提供以下核心证明和文件。这些文件不仅是合规的底线，也是建立可追溯供应链的基础。

建议你在与供应商合作前，**逐项核验**以下文件的齐全性和有效性，并**保留复印件或电子扫描件**存档备查：

### 一、 资质与主体资格证明（证明供应商合法经营）

1.  **营业执照**（必须）：确认经营范围包含“水果销售”或“食用农产品销售”，且营业执照在有效期内。
2.  **食品经营许可证**（或食品生产许可证）：对于供应商，可能是销售环节的经营许可；如果是直接分装的加工商，可能需要生产许可。注意查看许可证上的经营项目是否包含水果。

### 二、 产品溯源与质量证明（证明水果本身安全）

3.  **产品检验合格证明**：
    *   **农残快检报告**：供应商应提供当批次水果的农药残留快速检测合格报告。建议是**每批次**提供，或至少能提供对应批次的报告。
    *   **第三方检测报告（型式检验）**：建议要求供应商提供**最近一年内**由有资质的第三方检测机构出具的、涵盖重点项目（如农残、重金属、防腐剂等）的检测报告。
4.  **产地证明**（或上市凭证、食用农产品合格证）：用于证明水果的合法来源地。可以是一张合格证，上面标明产地、生产者信息。
5.  **供货凭证**（销货清单/送货单）：每一批送货都应附上，明确记录商品名称、数量、产地、供货日期、供应商签字等信息，这是**追溯**的关键凭证。

### 三、 运输与贮存证明（保障交付过程中不变质）

6.  **运输车辆相关记录**：
    *   **冷藏/保温车辆温控记录**（如适用）：如果是易腐水果或冷链运输，应要求供应商提供运输过程中的温度监控记录，证明全程冷链不脱冷。
    *   **车辆消毒记录**：确认运输车辆定期清洁消毒。
7.  **合格供应商名录**：你自己应建立一份合格供应商名录，将上述文件审核通过后归档，定期更新。

### 四、 风险承诺与责任文件（管理风险）

8.  **食品质量安全承诺书**：由供应商盖章签署，承诺其提供的产品符合食品安全标准，并明确相关责任条款。
9.  **质量保证协议**（长期合作时）：在采购合同中明确质量要求、验收标准、抽检不合格时的处理办法（如退换货、赔偿等）。

---

### 给你的执行建议（具体操作步骤）：

*   **第一步：** 建立供应商准入清单，要求新供应商提供上述1-4项文件。
*   **第二步：** 在每次下单或收货时，要求供应商随货提交**第5项（供货凭证）** 和**第3项（农残快检报告）**。
*   **第三步：** 在店内安排专人负责**进货查验**，逐一核对单据和产品外观（有无腐烂、异味、包装破损），做好查验记录（日期、品名、数量、温度、查验结果等）。
*   **第四步：** 冷藏水果收货时，**用红外测温枪测量中心温度**，确保符合贮存要求（通常建议≤10℃，具体依品种而定）。

**重要提醒**：不要依赖口头承诺，**所有的检查和记录都要书面化、签字化**，以便在发生食品安全事件时能迅速溯源并自我保护。如果你需要一份“验收记录表”的模板，或者对特定水果（如草莓、芒果）的特殊风险控制有疑问，可以继续提问。
