挑选超市的香蕉，关键是在“生熟”和“口感”之间找到平衡。这里给你一套实操性很强的避坑方法：

**第一步：看颜色（最直观）**

- **颜色偏绿、有棱角**：通常偏生。买回去常温放2-3天会熟，适合追求脆甜或需要储存的家庭。
- **颜色纯黄、有少量黑点**：这是最佳食用期，软糯香甜。当天吃选这种。
- **颜色深黄、黑点密集**：偏熟/过熟。如果当天不吃，千万别买，容易在1天内变质软烂。

**第二步：摸手感（关键技巧）**

- **轻捏香蕉中段**：如果**硬实、无弹性**，偏生；如果**软嫩但按下去能迅速回弹**，是最佳状态；如果**按下去凹陷且不回弹**，已经过熟，接近变质。
- **不要只捏两头**，两头通常都是软的。

**第三步：看梗部（防坑点）**

- **香蕉梗（头部）**：如果梗部是**青绿色且坚硬**，说明刚采摘不久，比较新鲜；如果**梗部发黑、干枯**，说明存放时间很久，内部可能已经开始变质，慎买。

**第四步：避开特殊组合**

- **同一串香蕉**如果一半青一半黄，说明可能催熟不均匀，买回去容易软硬不一。
- **价格便宜的“处理装”**（如散装打折蕉）通常是为了出清熟透库存，除非你当天吃，否则不建议买。

---

**到店后实操建议**（如果你有选择权）：

- **今天吃**：选**纯黄带少量黑点**、手感软弹的。
- **明天吃**：选**黄色带一点青**、手感稍硬的。
- **两天后吃**：选**全绿但果身饱满**的，放常温即可。

**最后提醒**：香蕉只要果皮上出现**大面积水渍状黑斑**，说明内部已发酵变质，一律不买。
