小商家采购水果时，**现金结算**和**月结账期**各有明显风险，具体如下：

---

### 现金结算的风险
1. **资金占用大**：立即支付现金，会占用大量流动资金，尤其水果是易损耗品，一旦滞销或变质，直接亏损。
2. **售后保障弱**：如果没有书面合同或收据，水果质量问题（如烂果、缺斤少两）难追溯，商家可能自担损失。
3. **供应链风险**：不熟悉的供应商若收钱后不发货或货不对板，很难追回款项，甚至存在诈骗风险。
4. **价格不透明**：部分供应商可能抬高现金价，小商家若不了解市场行情，容易多付成本。

---

### 月结账期的风险
1. **资金链压力**：月底一次性结清，若当月销售不佳或账期过长，可能面临集中付款压力，影响现金周转。
2. **供应商依赖**：一旦拖欠或延期，供应商可能断供、涨价，或限制采购量，影响正常进货。
3. **隐性利息成本**：部分供应商会把账期利息或手续费计入单价，实际成本可能高于现金价。
4. **纠纷风险**：若水果损耗、退换货未明确约定，月底对账时易产生争议，甚至影响合作关系。

---

### 小商家实用建议
- **小额试单**：首次合作尽量用现金小额采购，测试供应商信誉。
- **签书面合同**：无论现结还是月结，都要写清单价、数量、质量标准、损耗责任、付款期限。
- **设置账期上限**：月结尽量控制在30天内，避免长期挂账。
- **混用结算方式**：畅销品种用现金锁低价，普通品种走月结降低压力。
- **保留凭证**：现金要收据，月结按月对账单，并拍照留存。

如果您的月采购额不大，**建议优先现金结算**（风险可控），但务必先小额验证供应商；如果采购量大且信任度已建立，月结可缓解现金流，但一定要签合同。
