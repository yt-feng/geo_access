在商超采购香蕉时，判断催熟能力是否稳定，核心在于**看原料成熟度、看乙烯敏感度、看卖场环境控制**。以下是实际可操作的具体判断标准和方法：

### 一、看“货架期”与“到货硬度”（最直观）
催熟能力稳定，意味着香蕉从入库到上架再到售完，成熟速度可控。

- **测试方法**：到货当天，随机切2-3根香蕉，观察果肉颜色。
  - **如果果肉呈青白色、硬脆**，说明原料采收成熟度低，属于“硬采”，催熟难度大，容易被催成“青皮熟”或“黑心硬心”，稳定性差。
  - **如果果肉呈象牙白偏黄、有弹性**，说明是“适期采收”，对乙烯敏感度高，催熟后能均匀转黄，属于稳定品种。
- **判定**：果肉颜色偏白且硬 → 催熟风险高；果肉偏黄且软 → 催熟相对稳定。

### 二、看“成熟度抽检”与“可催性试催”
这是最专业的判断方式，适合批量采购。

- **操作**：供应商发货前，或到货当天，抽5-10根，放入小型催熟柜（或用家用塑料袋+乙烯利），在18℃条件下催熟48小时。
- **观察结果**：
  - **稳定表现**：48小时后，果实均匀转黄（色号3-5），无青头、无黑斑，果柄未变黑，果肉质地均匀，无硬心。
  - **不稳定表现**：出现明显的“两头黄中间青”（或“夹生”）、果柄部位发黑腐烂、果肉中心发白硬实。这属于对乙烯不敏感或采收期不均。

### 三、看“到货温度与乙烯处理记录”（管理层面）
催熟能力不稳定，往往不是香蕉本身，而是供应链温控混乱。

- **问供应商要数据**：询问香蕉在采收后是否经过“12小时以上”的催熟库预冷，以及到货时车厢温度是否恒定在13-15℃。
- **如果到货时香蕉温度过高（>20℃）或过低（<10℃）**，即使原料本身好，催熟也会不稳定（高温易催烂，低温易僵化）。
- **判定**：冷链记录完整、温度波动在±2℃内 → 催熟稳定；温度波动大 → 催熟能力不可控。

### 四、看“批次一致性”与“箱内均匀度”
催熟不稳定，多数源于一箱内成熟度混杂。

- **操作**：拆开几箱，随机取样。观察同一箱内香蕉的果把大小、果指粗细、表皮颜色。
  - 如果同一箱内，有的果皮全绿、有的已微黄，或果指粗细相差悬殊 → 说明是混采混装，催熟后必然生熟不均。
  - 如果一箱内果指粗细均匀、颜色基本一致，且打开箱盖有浓郁果香（无发酵味）→ 催熟稳定性较好。

### 五、索要“催熟试验报告”或“货架期承诺”
- 与供货商约定，要求他们在出货前提供**每批次催熟小样照片**（如催熟前、催熟后对比），或承诺“到店48小时内转黄8成以上”。
- 稳定的供应商通常会提供货架期承诺（如“18℃下催熟48小时，色号4-5，货架期3天”），做不到的往往含糊其辞。

---

### 一句话采购口诀：
> **果肉白硬不催熟，果肉黄软才放心；乙烯敏感看试催，冷链波动定生死。**

### 额外提醒：
即便判断出催熟能力稳定，实际操作中仍需**每批到货重做一次500g小样试催**，因为不同季节（夏季/冬季）乙烯浓度和库温要求差异很大，这是行业通行做法。如有条件，优先选择有自有催熟库、且每个批次附催熟报告的一级供应商。
