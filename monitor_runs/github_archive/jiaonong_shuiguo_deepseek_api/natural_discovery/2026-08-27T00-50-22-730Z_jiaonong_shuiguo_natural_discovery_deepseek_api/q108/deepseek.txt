采购方在收到“全国配送”的口头承诺后，不能仅凭信用或宣传就签约。**建议通过以下五个步骤进行结构化核实，并将结果落实到合同中：**

### 第一步：索要书面“服务范围与时效承诺书”
不要接受口头“全国都能送”。
要求供应商提供一份**盖章的《配送服务承诺函》**，里面必须明确列出：
*   **可配送区域**：精确到省、市、区/县，不要写“全国”或“偏远地区除外”，要写明“新疆、西藏、内蒙、青海、甘肃”等具体地区到底是送还是不送，时效是几天。
*   **最低起送量**：比如某区县需满100箱才发，或不足多少加收配送费。
*   **时效承诺**：例如“省会城市24小时，地级市48小时，县级市72小时”。

### 第二步：进行“盲测式”查件核实
**不要用同一个收件地址反复问客服**，客服的回答往往是话术。
你可以：
1.  随意抽取3个**非省会城市**的地址（比如：甘肃天水、黑龙江齐齐哈尔、云南曲靖）和一个**县级地址**（如：安徽临泉县）。
2.  要求供应商针对这几个具体地址，提供**过往1个月的签收记录**（打码客户隐私后提供物流单号）。
3.  **关键动作**：直接在快递公司官网或第三方物流平台（如快递100）输入单号，核对**真实的“揽收、中转、派送、签收”时间戳**。看这条链路是否顺畅，是否存在“在省会中转站滞留”的情况。

### 第三步：验证冷链与末端派送能力（如果涉及生鲜）
水果配送比普通电商更复杂。如果供应商说“全国配送”，你要确认：
*   **是快递配送还是专线物流？** 如果是走顺丰/京东这类快递，确认是否支持**生鲜专送**；如果是普通物流，很可能到县级市就是“自提”且无法保证新鲜度。
*   **异地仓覆盖情况**：要求对方拿出在**您的目标销售地**（如成都、武汉）是否有分仓或合作云仓的单据。若有分仓，跨省单的配送纠纷会少很多。

### 第四步：小额试单 + 实际周报
这是最有效的检验方式。
*   不要一上来就签大订单。**采购金额控制在1000元以内**，下两个小单，分别投向“华东二线城市”和“西部县级市”。
*   要求供应商提供这两个试单的**全程物流轨迹截图**，如果供应商拒绝配合或声称“运费自理”，说明其全国配送能力存疑。

### 第五步：签合同 + 设置兜底条款
即使前四步都通过了，也必须在采购合同的**违约责任**中明确写上：
> *“若乙方（供应商）承诺的可配送区域内，实际无法实现上门派送或需额外支付配送费，乙方应承担由此产生的全部实际损失，且甲方有权按单件货值的 **X%** 扣减该笔货款。”*

**简而言之：**
全国配送 ≠ 全国都便宜、全国都送到家门口。**核实核心要看“非中心城市的末端服务”**。最直接的办法是：**给一个县级市下单，然后看派送员是不是在您指定的楼下签收，以及水果是否完好。**
