处理生鲜电商水果到货后的坏果投诉，责任划分通常遵循**“谁交付谁负责”**和**“谁控制风险谁负责”**的原则。具体划分需要区分以下几种情况，建议你按以下步骤判断并操作：

**一、责任划分的三个核心环节**

1. **源头（发货方/商家）责任**：
   - 如果水果在发货前已存在瑕疵（如内部霉变、虫眼、过熟），无论外包是否完好，责任在商家。
   - 如果包装不符合防撞、防压、保鲜要求（例如装葡萄只用普通塑料袋），导致运输中损坏，责任同样在商家。

2. **运输（快递/物流）责任**：
   - 如果外包装有明显破损、压痕、浸水，导致内部水果挤压、腐烂，且商家包装合格，则责任在承运方（快递公司）。
   - **注意**：商家与快递是合同关系，**顾客通常直接找商家索赔**，商家再向快递追偿。顾客无需直接联系快递。

3. **验收（消费者）责任**：
   - 如果水果已签收，且**超24-48小时未开箱**（不同平台通常72小时为限），导致水果在常温下变质，且商家外包装无问题，则责任可能在消费者。
   - 如果消费者签收时发现外包装破损，但**未拍照拒收**或未及时联系商家，可能被视为“默认接受”，责任划分时对消费者不利。

**二、实际操作判断标准（建议你直接执行）**

- **你看包装和果子**：打开后先拍照（外包装、内物、单果特写）。如果外包装完好但果子坏，**99%是商家责任**，直接申请退款或补发。
- **看坏果比例**：通常电商平台规则是“坏果超过一定比例（如30%）全赔，不足则按比例赔付”。你只需按平台售后入口提交照片，**无需自行划分责任**。

**三、给顾客的具体行动建议**

1. **立即拍照取证**：包括快递面单、外包装六面、打开后的状态、坏果特写（要能露出果柄或伤疤）。
2. **在签收后24小时内联系客服**（越快越好），说明“XX水果到货有坏果”，并上传照片。
3. **不要主动提及“可能是快递责任”**：你只需陈述事实“到货坏了”，商家有义务处理。如果商家推诿，平台介入后通常判定商家赔偿。

**四、给商家的责任规避建议**

- 发货前做好**品控和加固包装**（如泡沫网套、吸湿纸）。
- 在面单或包装上提示“请当快递面开箱验货”。
- 售后时以“坏果率”而非“单果好坏”作为赔付标准，避免客户过度索赔。

**最终结论**：**在没有签收证据证明是运输损坏的情况下，默认由商家承担全部责任**（因为商家无法证明发货时是好的）。如果你作为消费者，只需保留好证据并申请售后；如果是商家角度，请主动承担责任并向快递索赔以降低损失。

如果涉及金额较大且涉及食品安全（如变味、发霉），建议联系平台官方客服介入。
