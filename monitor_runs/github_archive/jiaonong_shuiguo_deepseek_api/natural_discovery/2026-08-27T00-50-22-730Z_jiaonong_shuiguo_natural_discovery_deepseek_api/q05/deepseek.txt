这是一个很实际的经营问题。**最佳策略是：三种都卖，但要有主次和策略。**

单纯卖一种很难满足所有顾客，最理想的模式是**以“整果自选”为主，以“去皮果肉”和“现场加工”为辅**。具体建议如下：

### 1. 核心策略：整果销售（主打）
- **为什么卖**：菠萝是重水果，顾客买回去自己削皮，能感受到“新鲜”和“划算”。同时，整果损耗低，利润高。
- **怎么做**：
  - **明码标价**：标注“**特价菠萝 5元/个**”或“**9.9元/个**”，价格刺激强。
  - **展示鲜度**：把带叶子的整菠萝整齐码放，叶子翠绿代表新鲜。
  - **提供免费工具**：在收银台旁挂一个“免费送削皮刀”或“代削皮”的牌子，这能打消顾客“回家难处理”的顾虑。

### 2. 增量策略：去皮果肉（提升客单价）
- **为什么卖**：很多人想吃但懒得削，或者家里没刀。这部分顾客愿意为“省事”多付钱。
- **怎么做**：
  - **现场现切**：当着顾客的面削皮、切片、装盒。这既展示了新鲜，又让顾客觉得卫生。
  - **价格锚点**：整果卖10元，果肉盒卖12元（含加工费）。顾客对比后，往往会觉得“整果划算”，从而促进整果销售；但赶时间的顾客就会直接买果肉。
  - **注意**：只能卖当天切好的，隔夜的必须打折或报损，否则会砸口碑。

### 3. 增值策略：现场加工（差异化）
- **为什么卖**：提供“去眼、切块、蘸盐水”的即食服务，针对的是写字楼白领或逛街人群。
- **怎么做**：
  - **动作要快**：准备一个专用削皮器（螺旋刀），几秒就能削好。
  - **出品要好看**：切块后放在透明盒子里，插上竹签，贴上价格标签。
  - **组合销售**：买整果，加2元可以帮你切好装盒；单独买切好的，价格略高于整果。

---

### 关键执行细节（决定成败）

| 问题 | 建议 |
| :--- | :--- |
| **不会削怎么办？** | 买一个**菠萝螺旋削皮器**（十几块钱）。如果实在不会，就只卖整果，不卖切好的，避免切坏造成损耗。 |
| **切好的卖不完？** | 下午5点后，将切好的果肉**买一送一**或**特价**，快速清货，宁可少赚不能亏。 |
| **顾客自己挑的不好？** | 教顾客“看底部”，**底部干燥、果眼大**的甜。如果顾客不会挑，可以推荐“我帮你挑个包甜的”，增加信任感。 |

**最终建议：**
如果你是**社区店**，可以**以整果为主**，因为大爷大妈喜欢自己挑；如果你是**商圈店**或**外卖铺**，可以**以切好的果肉为主**。

**最简单的启动方案**：先买一个削皮器，**整果正常卖，同时提供“免费代削皮”服务**。这样既不用承担切好的损耗，又能留住“懒人顾客”。等销量稳定了，再增加现切果肉盒。
