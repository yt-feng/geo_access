针对水果店减少香蕉损耗，采购时的**核心思路**是：**不要采购全熟香蕉**，而是要求“**七八分熟**”（即半绿半黄或微黄带绿），并严格规定**到货时间和运输条件**。

以下是具体的采购要求建议：

### 一、 对熟度的硬性要求
1.  **明确颜色标准**：要求供应商提供的香蕉在到货时，果皮应为**黄中带绿**（绿皮比例约20%-30%），也就是“硬熟”状态。坚决拒绝全黄或果皮发黑的香蕉。
2.  **指定成熟度范围**：不要买“树上熟”的香蕉，要买“乙烯催熟”后未完全成熟的。要求供应商提供香蕉的“成熟度等级”（一般用1-7级表示），到货时要求在**3.5-4级**（即果皮变黄，但果肉仍硬）。
3.  **指定果指大小**：要求单根香蕉果指长度、粗细均匀，避免大小不一导致成熟时间不同。

### 二、 对到货时间的核心要求
1.  **分批次到货**：建议要求供应商**每天或隔天定时少量送货**，而不是一次送一周的量。这样可以避免库存积压，保证货架上的永远是“新熟”的。
2.  **明确“到货即售”时间窗**：要求到货时间在**早上开门前（如8:00前）**，确保当天上架的是最新鲜的香蕉。
3.  **禁止“隔夜货”**：在采购合同中明确要求，**不接受已在仓库存放超过24小时**的香蕉，或者到货时必须明确告知生产日期。

### 三、 对运输和储存的附加要求
1.  **冷链要求**：要求供应商使用**13℃-15℃的恒温运输车**（这是香蕉的最佳储运温度）。如果温度过高（超过20℃）会加速成熟，温度过低（低于10℃）会导致果皮发黑、果肉不熟。
2.  **通风与防压**：要求纸箱侧面必须有透气孔，且运输时**最大堆叠层数不超过6层**，防止底层被压坏。

### 四、 验收时的“一票否决”条款
在采购单上明确写上以下验收标准，不达标可拒收或要求换货：
- 果皮有**黑斑、擦伤、发霉**的。
- 果柄断裂或腐烂的。
- 触感**软烂**（说明过度成熟）。

### 五、 销售端配合（减少浪费的补充）
采购回来后，建议按**成熟度分层上架**：
- 将相对生一点的（带绿）放在货架**外层**，先卖。
- 将已经全黄的放在**里层或特价区**，优先促销。
- 切勿将全部香蕉堆在一起，避免相互催熟。

---

**一句话总结**：采购时要求“**七八分熟、分批到、冷链运、防压伤**”，验收时坚持“**带绿、硬挺、无黑斑**”，就能最大程度减少因过熟导致的损耗。
