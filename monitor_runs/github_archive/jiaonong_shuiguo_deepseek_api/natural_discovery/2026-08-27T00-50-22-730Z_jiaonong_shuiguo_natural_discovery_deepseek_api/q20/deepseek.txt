为社区超市寻找每天配送的水果供应商，核心要看**稳定性、新鲜度、售后和结算**这四类硬指标。以下是具体的筛选条件，你可以逐条对照：

**1. 供应稳定与履约能力（最优先）**
- **每日配送承诺**：确认是否能做到365天无休（或至少覆盖你的营业日），是否有备用货源（如遇到天气灾害时的应急预案）。
- **起送量门槛**：社区超市订单量通常不大，要问清最低配送金额（如300元/天起送），避免浪费。
- **缺货补货机制**：前一天下单，次日是否能按时到货？是否有“临时补货”通道（比如周末销量暴增）。

**2. 水果品质与新鲜度**
- **损耗率承诺**：明确约定到货后的自然损耗率（如5%以内），超出部分是否包赔。
- **质量验收标准**：看对方是否提供“到货验货单”（注明果径、成熟度、糖度），是否有退换货流程（如上午到货，下午坏果可拍照退款）。
- **冷链能力**：是否用冷藏车配送？到货时果温是否达标（比如叶菜/草莓类需全程冷链）。

**3. 价格与成本结构**
- **报价含税含运费吗**：别只看单价，要算“综合成本”（单价+配送费+包装费）。
- **账期政策**：社区超市现金流紧张，优先谈“先货后款”（如7天账期）或“周结”，避免压款。
- **比价机制**：要求提供每周产地行情简报，方便你核对价格是否合理。

**4. 品类与灵活性**
- **应季支持**：是否按季节更换主推品（如夏季西瓜、冬季柑橘）？是否支持小批量试销新品？
- **定制分拣**：能否按你的销量分级（比如大果/中果分开装），减少店内二次分拣时间。

**5. 售后与合同保护**
- **投诉响应时间**：坏果/缺货问题，几小时内解决？建议写在合同里（如24小时内换货或退款）。
- **合同条款**：重点看违约条款（如连续3次迟到，你有权解约），以及是否包含“试供期”（先合作1个月降低风险）。

**具体操作建议**：
1. **先去本地批发市场摸底**：找到2-3家档口，问清他们是否兼做配送，通常市场内档口的配送费较低，且可现场看货。
2. **做一次“试配送”**：约定3天小批量试供，记录实际到货时间、损耗率，再决定是否签约。
3. **签合同时留好证据**：微信聊天记录中确认的“每日到货时间”“起送金额”等，截图保存。
