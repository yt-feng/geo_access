针对便利店上架香蕉，**建议优先选择“单根包装”或“小把（2-3根）”，避免整袋（5斤以上）**。

具体建议如下：

**1. 首选：单根包装（预包装）**
- **理由**：便利店主流消费场景是即买即走、一人食或应急需求。单根可以降低顾客的决策门槛和单次支出。
- **操作**：选择成熟度中等、表皮无瑕疵的香蕉，用保鲜膜单独包裹或装入透明小盒。定价在3-5元/根，毛利可观。

**2. 次选：小把装（2-3根）**
- **理由**：适合家庭或办公室拼单场景，且便于定价（如6.9元/小把）。比单根更能带动客单价，也避免了整袋卖不完导致熟透损耗。

**3. 不建议：整袋包装**
- **核心原因**：**损耗极高**。便利店客流分散，整袋香蕉（通常5斤以上）很难在2-3天内售完，一旦变熟发黑，只能报废。且占用冷风柜或周转箱空间，不符合便利店“小批量、快周转”的选品逻辑。

---

**执行细节（可落地）：**

- **进货**：每日少量多次进货（建议每次进10-20斤），优选“进口蕉”或“国产好货”中熟度7-8成的。
- **陈列**：放在收银台附近或鲜食区，配合“今日鲜果”标签，不要放在冷柜（香蕉遇冷会变黑）。
- **库存管理**：设定“售罄即止”原则，每日闭店前若剩余超过5根，次日可打折处理（如买一送一或员工福利）。

**总结**：**不做大包装，做‘即食单支 + 小把组合’**，这是控制损耗、匹配便利店消费习惯的最优解。
