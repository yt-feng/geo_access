在超市水果采购到货后发现品相不好，处理流程是否顺畅，直接影响店铺口碑和成本。建议从**收货前端**、**拍照留证**、**退换规则**、**责任划定**四个环节进行约定，并写入采购合同或微信群公告。

以下是具体的操作流程约定建议：

**一、收货时：立即执行初检（黄金30分钟）**
- **约定动作**：到货后**30分钟内**，由店长或指定负责人开箱抽检。
- **约定标准**：提前书面列明“品相不好”的具体标准（如：破损率超过5%、软烂果超过3%、明显磕碰/斑点多于10%等），避免口头描述模糊。
- **操作方法**：对整批货拍照（含外箱标签、批次号），对问题果单独拍照（特写+全景）。

**二、争议处理：先留证据，后谈退款**
- **约定动作**：发现问题后，**禁止直接丢弃问题果**。将问题果单独存放并贴标签，保留原包装袋/箱。
- **沟通话术**：直接联系供货商时，发送照片+视频+收货时间截图，说明“按标准判定为XX问题”。
- **约定时效**：要求供货商在**2小时内**回复处理意见，超时视为默认接受退货/补货。

**三、售后方案分级（写在合同里）**
1. **轻微瑕疵**（不影响售卖，可打折）：按相应比例协商折扣，或要求下次进货时补送等值水果。
2. **严重腐烂/不可售卖**：约定**全额退货退款**，或由供货商承担运费补发新品。
3. **反复出现**（同批次连续3次）：约定**扣减货款**或**解除合作**条款。

**四、财务与账期联动**
- 重要一点：**不结清上月货款，不退本次**。约定结算周期内，如有售后未解决，暂缓支付该供应商货款，以此作为谈判筹码。

**五、特殊情况处理**
- 如果供货商不认账但金额较小（低于200元），建议以“下次抵扣”方式快速了结，避免纠缠。
- 如果是冷链水果（如草莓、蓝莓）出现化冻软烂，需立即检查运输温度记录（若有），并重点归因于物流而非品相。

---

**补充建议（可直接执行）**：
- 制作一张简单的《水果到货验收单》，包含：到货时间、重量、外包装完整度、抽检数量、问题照片链接、签字栏。每次进货都填写，避免扯皮。
- 首次合作时，先小批量试单（如20箱），不直接下大单，验证对方品控和售后响应速度。

如果供货商长期品相不佳，即使售后流程完善，也建议考虑更换供应商，因为损耗成本会在日常中持续吞噬利润。
