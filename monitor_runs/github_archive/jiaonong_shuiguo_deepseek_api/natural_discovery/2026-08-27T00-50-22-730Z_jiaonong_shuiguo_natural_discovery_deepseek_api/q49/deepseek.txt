**第一步：立即启动“紧急沟通”而非“下订单”**
- **沟通方式**：不要只在微信/APP里发个数量，建议**电话直接沟通**，说明是“旺季突增”，并确认供应商当前库存和产能。
- **关键话术**：“您好，我们最近菠萝杯量突然爆发，需要紧急补货。想确认您这边现在**可发库存**和**最快到货周期**（比如明天上午还是后天）？”

**第二步：拟定书面/口头补充协议要点**
临时补货建议双方确认以下具体条款（哪怕是微信文字留痕）：
1.  **数量与规格**：本次补货的具体斤数（建议按“箱”或“kg”明确），并注明**果径大小**（如：大果/中果）和**成熟度要求**（如：8成甜，避免过熟压坏）。
2.  **价格约定**：旺季价格可能上涨，需明确**本次到货单价**，并与日常价对比。如果是浮动价格，约定**涨价上限**（如：最高不超过日常价的15%）。
3.  **送货时间与费用**：明确**送达时间节点**（如：明天上午10点前），运费谁承担（急单一般建议自担运费或加急费，利于对方优先安排）。
4.  **损耗与退换**：约定因压伤、腐烂等原因的**损耗比例**（如超过3%部分由供应商赔付），以及到货后**48小时内**可提出质量异议。

**第三步：建立“阶梯式”应急备货机制**
不要一次性只谈这一单，要谈未来1-2周的节奏：
- **每周锁定量**：与供应商约定一个“保底周供货量”（如每周200kg），旺季按此执行。
- **临时追加窗口**：约定每天**下午3点前**确认第二天的补货量，双方默认响应时效（如2小时内确认），超时按原计划执行。

**第四步：预防性措施（关键）**
- **准备备选供应商**：即使已约定，也要告知供应商“如果这次周转不及时，我会联系备选商，希望您优先保证我的量”，形成良性压力。
- **按“1.5倍预估”补货**：下量时，按你当前日产量的**1.5倍**来下，因为菠萝损耗率较高（需去皮、去芯），且天气热熟得快。

**第五步：书面留痕（防扯皮）**
如果涉及金额较大（如单次超5000元），建议在微信或邮件里发送一条完整信息：
> “确认：今日补菠萝XXkg（大果，7成熟以上），单价X元/kg，合计X元。要求明早10点前送到XX店，到货开箱验收，超过3%坏果由贵方补损。运费实报。请回‘确认’视为双方同意。”
