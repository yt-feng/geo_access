为养老院或医院食堂采购水果，**合规性**和**稳定性**是核心，因为直接关系到老人/病人的饮食安全和机构的法律责任。

以下是一套实操性较强的判断标准和建议：

### 一、判断供应商的合规性（硬性门槛）

这一步是“一票否决”项，不达标直接淘汰。

1.  **查验三证一照（必备资质）**
    -   **营业执照**：经营范围必须包含“食用农产品销售”或“食品销售”。
    -   **食品经营许可证**：如果供应商是配送公司，必须有此证（注意看经营范围是否覆盖）。
    -   **法人身份证复印件**：留存备查。
    -   **农产品合格证明**：每批次水果必须能提供《食用农产品合格证》或供货方出具的质检报告。

2.  **查验人员健康证（配送员）**
    -   凡是接触水果的搬运工、司机，必须持有有效的健康证明（健康证）。

3.  **实地查看仓储环境（非常重要）**
    -   **不要只看办公室**，必须要求看其冷库或分拣车间。
    -   判断标准：是否有防鼠、防虫、防蝇设施？水果是否分类存放？腐烂变质的水果是否及时清理？（如果烂果和好果混放，说明合规意识差）。

4.  **索证索票与台账能力**
    -   有正规供应商能提供**进货凭证**（上游批发市场的单据）和**销货清单**。
    -   关键点：他能否按你的要求，每批次提供“一票通”（即食品销售统一票据）？这不仅是合规，更是你食堂台账追溯的源头。

---

### 二、判断供应商的稳定性（服务能力）

这一步决定你们是否“用得长久”和“不出乱子”。

1.  **看其上游资源是否足够深**
    -   问询：“你的水果来源是本地批发市场（如新发地）现买，还是基地直采？”
    -   **建议**：优先选择拥有**基地直采**或与大型种植基地有长期合同的供应商。他们抗价格波动和天气灾害的能力更强，不会因为下大雨就缺货。

2.  **看其配送体系（含应急能力）**
    -   **准时率测试**：试用期前两周，要求每天固定时间送达，测试其迟到率。
    -   **应急预案**：明确询问“如果明天早上6点因高速封路无法送达，怎么办？”合格的供应商应该有备用仓库或备用车辆方案。

3.  **看其质量分拣标准（分级能力）**
    -   好的供应商会按“特级、一级、二级”分级报价。
    -   测试方法：要求切开几个水果看内部品质（如西瓜熟度、木瓜是否软硬适中），看是否与报价等级相符。**杜绝以次充好**是稳定性的核心。

4.  **账期与付款方式**
    -   医院/养老院通常月度结账。若供应商要求“现款现货”，其资金链可能较紧，稳定性差。通常能接受30-45天账期的中等规模公司，相对稳定。

---

### 三、合同中的“实战”保护条款（规避风险）

不要只相信口头承诺，一定要落到合同里：

-   **“三天试供货期”条款**：正式合作前，要求试供3-5天，不合格则终止。
-   **“质量扣款机制”**：明确烂果率超过3%（或5%），超出部分按双倍扣罚或无偿换货。
-   **“溯源承诺书”**：要求供应商书面承诺，若因水果质量问题导致食品中毒或事故，承担全部法律责任。
-   **“断供违约金”**：明确未提前24小时通知而断供的，按货款的相应比例扣违约金，并有权启用备选供应商。

---

### 四、给采购负责人的三条“避坑”小贴士

1.  **不要只看价格低**：比市场价低10%以上的，风险极高，很可能混入次果或早采果（不熟）。
2.  **建立评估档案**：每月对供应商的“到货准时率、验收合格率、临时补货响应速度”进行打分，实行季度赛马机制（2-3家供应商轮流备选），避免被单一供应商拿捏。
3.  **现场收验货双签字**：食堂库管和厨师长（或护士长）必须双人签字验收，拍照留档，这是合规的最后一道防线。

---

**总结一句话**：合规看“证件和仓库”，稳定看“基地和应急”。**永远保留一家备选供应商**，比压榨现有供应商的利润更保险。
