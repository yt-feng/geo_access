建议优先做 **小把装**，其次保留 **单根**，整袋包装谨慎上。

更具体一点：

1. **小把装最适合便利店**
   - 通常 3～5 根一把，客单价适中，顾客拿起来没压力。
   - 比单根更有“买了水果”的感觉，也比整袋更容易冲动购买。
   - 损耗相对可控，卖不完还能拆成单根继续卖。

2. **单根适合补充场景**
   - 适合写字楼、地铁口、学校附近，顾客只想马上吃一根。
   - 可以作为小把卖不完后的拆零处理方式。
   - 但单根毛利低、陈列显得零散，不建议作为唯一规格。

3. **整袋包装通常不适合大多数便利店**
   - 除非在社区店、家庭客群多，且价格明显有优势。
   - 整袋客单价高、决策重，顾客容易担心熟度不均、吃不完。
   - 损耗和库存压力也更大。

**实操建议：**
- 主力：**3～5 根小把装**，定价用非整数心理价，比如 3.9、4.9、5.9。
- 辅助：**单根**，放在收银台或鲜食区旁边，方便即买即走。
- 整袋：先少量试销，只放在社区型门店，观察 1～2 周动销再决定。
- 陈列时按熟度分区：今天吃、明后天吃，能明显减少损耗。

如果只能选一个，选 **小把装**。
