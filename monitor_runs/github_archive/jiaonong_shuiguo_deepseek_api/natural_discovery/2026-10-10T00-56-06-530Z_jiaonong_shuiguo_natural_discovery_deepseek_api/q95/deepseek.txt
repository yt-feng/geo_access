选学校食堂水果供应商，核心不是“找最便宜的”，而是先定标准，再验资质，再小批量试供，最后用考核决定是否长期合作。可按下面步骤做。

**一、先明确食堂自己的采购标准**
1. 品类标准：香蕉、苹果、橙子分别定规格，比如苹果单果重量、橙子直径、香蕉成熟度。
2. 质量要求：无腐烂、无大面积碰伤、无异味、成熟度适合当天或次日食用。
3. 配送要求：到货时间、频次、临时加单响应时间、是否送货到库房。
4. 结算要求：账期、发票类型、对账方式、退换货规则。
5. 安全要求：农残检测报告、产地证明、营业执照、食品经营许可证等。

**二、供应商来源**
优先从这几类里找：
- 本地农产品批发市场里有固定档口、能做学校配送的商户。
- 本地水果种植合作社或基地，适合苹果、橙子等有稳定产区的品类。
- 有冷链或配送能力的水果供应链公司。
- 学校原有米面油、蔬菜供应商中，能顺带做水果且资质齐全的。
不建议只找流动摊贩或没有固定经营场所的个人。

**三、资质和现场核验**
重点查：
- 营业执照、食品经营许可证是否在有效期内。
- 是否有固定仓库、分拣场地、冷藏或保鲜条件。
- 是否能提供农残检测报告或承诺批批检测。
- 配送车辆是否清洁，是否与生鲜、化学品混装。
- 实际去看一次仓库和分拣现场，比只看资料更有效。

**四、比价不要只看单价**
让供应商按同一规格、同一质量、同一配送条件报价。比如：
- 苹果：80mm以上，无伤，箱装或散装。
- 橙子：直径70mm以上，酸甜适中，无干水。
- 香蕉：七成熟左右，到货后1—2天可食用。
比较时看“到货合格率”和“实际可食用率”，烂果、次果多，单价再低也不划算。

**五、小批量试供**
先让2—3家供应商各试供1—2周：
- 记录到货时间、数量误差、腐烂率、口感、退换货速度。
- 让食堂库管、厨师、甚至学生代表参与评价。
- 重点看早高峰前能不能按时到货，临时加单能不能补。

**六、合同和考核**
合同里写清：
- 品种、规格、单价、浮动机制。
- 质量标准、验收方式、不合格处理。
- 退换货时限、损耗承担。
- 食品安全责任、票据和结算方式。
考核建议按月或按季度：
- 到货合格率
- 配送准时率
- 退换货响应
- 价格稳定性
- 投诉情况
连续不达标就减少订单或更换。

**七、实际操作建议**
1. 先选2家主供应商+1家备选，避免单一依赖。
2. 香蕉、苹果、橙子可以分开找更专业的供应商，不一定一家全包。
3. 每次到货必须验收称重、抽检、拍照留痕。
4. 价格随行就市，但约定每周或每两周调价一次，避免天天扯价。
5. 对学校食堂来说，稳定、安全、可追溯比单纯低价更重要。

简单说：先定规格和质量标准，再查资质和现场，再小批量试供，最后用合格率、准时率、退换货和价格稳定性来定长期供应商。
