大型超市对水果供应商的要求，通常高于普通批发市场，核心可以分成**食品安全能力**和**物流交付能力**两块。下面按“必须具备”和“加分但常见门槛”来梳理。

## 一、食品安全能力

### 1. 合规资质
- 营业执照、食品经营许可证或食品生产许可证（按业务形态）
- 食用农产品合格证或产地证明
- 若涉及进口水果：入境货物检验检疫证明、海关报关资料
- 若做分装/预包装：相应生产许可和标签合规能力

### 2. 农残与污染物控制
- 有稳定的基地或合作果园，能追溯到大宗批次
- 每批次或按周期做农残快检/定量检测
- 能提供第三方检测报告，项目覆盖农药残留、重金属等
- 对高风险品类（如叶菜类、草莓、豇豆等）有加密检测机制

### 3. 追溯与批次管理
- 能做到“一批一码”或批次号管理
- 出现问题时，能快速定位到果园、采收日期、加工线和发货批次
- 有召回预案，能在数小时内下架、封存、追溯

### 4. 仓储与加工卫生
- 分选、包装场所符合食品卫生要求
- 有防虫、防鼠、防尘、温湿度控制
- 人员健康证、工服、洗手消毒流程
- 不与有毒有害物品混存

### 5. 体系与审计
大型超市通常还会看：
- ISO 22000、HACCP、GLOBALG.A.P.、BRCGS 等认证（不是每家都强制，但很加分）
- 能接受超市或其第三方机构的飞行检查
- 有不合格品处理、投诉处理、纠偏记录

## 二、物流能力

### 1. 冷链能力
水果供应商最核心的物流能力是冷链：
- 预冷：采后尽快降温，尤其是浆果、樱桃、荔枝等
- 冷藏运输：全程温控，不同品类不同温区
- 冷库存储：分温区、分品类存放，避免乙烯催熟和串味
- 温度记录：可提供全程温度曲线，异常可报警

### 2. 仓储与分拣
- 有水果专用仓库，通风、避光、防冻防热
- 能按超市订单做分拣、称重、贴标、组板
- 支持多门店、多波次配送
- 对易损果有防压、防震包装方案

### 3. 配送时效
- 能按超市要求做到日配、隔日配或定时达
- 有备用车辆和备用路线，能应对爆单、堵车、天气异常
- 能对接超市 DC（配送中心）或直送门店
- 到货准时率和订单满足率通常要有考核数据

### 4. 损耗控制
- 有采后商品化处理能力：分级、清洗、打蜡（如允许）、包装
- 能控制磕碰、失水、腐烂
- 对临期果有快速分流机制
- 能提供损耗率数据并持续改善

### 5. 信息化对接
- 能对接超市的订单系统、EDI 或供应商平台
- 能提供库存、在途、到货信息
- 有批次追溯和电子台账
- 出现质量异常时能快速提供数据

## 三、大型超市通常还会额外要求

- **供应稳定性**：不是有货就行，而是全年或产季内稳定供货
- **产地直采或基地直供**：减少中间环节，便于追溯和控价
- **食品安全责任险**：部分超市会要求
- **应急能力**：疫情、自然灾害、封路时的保供方案
- **财务与履约能力**：能接受账期、退换货、质量扣款
- **可持续与合规**：如农药使用规范、劳工合规、包装环保

## 四、最简判断标准

如果只问“必须有哪些”，可以压缩成 8 条：

1. 合法资质齐全  
2. 农残检测合格且可追溯  
3. 有批次管理和召回能力  
4. 有符合卫生要求的分选包装场所  
5. 有预冷和冷链运输能力  
6. 有水果专用仓储和分拣能力  
7. 能按超市时效稳定配送  
8. 能对接超市系统并控制损耗  

真正能进大型超市的供应商，通常不是“能拉到货”的贸易商，而是**有基地、有检测、有冷链、有追溯、能稳定交付**的供应链型供应商。
