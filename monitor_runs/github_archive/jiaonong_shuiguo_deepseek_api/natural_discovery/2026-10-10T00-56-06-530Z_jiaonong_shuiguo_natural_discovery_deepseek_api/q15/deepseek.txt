水果店遇到坏果，处理方式主要取决于**损耗发生在哪个环节**、**和供应商的事先约定**，以及**是否有证据**。下面按常见情形给你一套可执行做法。

## 一、先分清责任环节

| 环节 | 通常责任方 | 处理方式 |
|---|---|---|
| 到货验收时就发现坏 | 供应商 | 当场拒收或扣重，最稳妥 |
| 到货时好、存放几天后坏 | 多为门店 | 自己承担，除非能证明是货源问题 |
| 运输途中压伤、闷坏 | 看约定，常由供应商或承运方 | 拍照留证后找供应商协商 |
| 整批内在品质差（如切开黑心） | 供应商 | 凭证据要求补货/退款/折价 |
| 个别坏果混在好果里 | 按比例协商 | 常见是扣重或按比例折价 |

**核心原则：能当场验收的，绝不拖到事后。** 事后扯皮成本最高。

## 二、正常结算/赔付的几种方式

按行业习惯，一般是这几种，优先用前两种：

1. **扣重结算**：验收时把坏果挑出称重，按坏果重量从货款里扣掉。这是最常见、最不容易起争议的方式。
2. **折价结算**：整批货有轻微瑕疵但还能卖，双方谈一个折扣价（如按 8 折、9 折结算）。
3. **补货**：供应商下次送货时补上等量好果。
4. **退款**：坏得严重、无法销售的，按坏果数量退对应货款。
5. **换货/退货**：整批不合格时直接退回，运费责任按事先约定。

赔付金额一般就是**坏果的进货成本价**，而不是你的零售价。因为你的利润损失通常不被供应商认，除非合同里明确写了。

## 三、标准操作流程（建议固定成规矩）

1. **到货当场开箱抽检**，尤其是易坏的（草莓、葡萄、桃、荔枝等）。
2. **拍照/录像**：拍坏果、拍包装、拍批次、拍称重，最好带时间。
3. **当场挑拣、称重、记录**，让送货人签字确认数量。
4. **当天反馈供应商**，别拖，越拖越难认定。
5. **按约定方式结算**：扣重、折价或补货。
6. **保留记录**：形成台账，长期看哪家供应商坏果率高，直接影响续约。

## 四、关键点：事先约定比事后吵架有用

和供应商合作前，最好在口头或书面上说清楚：

- 验收标准：坏果率超过多少算不合格（如超过 5% 整批可退）。
- 验收时限：到货后多久内可提出异议（如当天、24 小时内）。
- 处理方式：优先扣重还是补货。
- 运费责任：退货时谁出运费。
- 易坏品单独约定：如草莓、樱桃等高损耗品，是否接受一定比例的自然损耗。

## 五、特殊情况

- **没有事先约定**：只能协商，通常按"坏果对应货款"扣减，双方各让一步。
- **供应商不认账**：靠到货照片、称重记录、送货单签字来谈；长期如此就换供应商。
- **整批内在质量问题**：如外表好但内部坏，需在合理时限内反馈，超出时限供应商可能不认。
- **你自己存放导致的坏**：一般自担，别去要求供应商赔，容易伤合作。

## 一句话总结

**能当场验收就当场扣重，扣重是最干净的结算方式；赔付一般只按进货成本价算，不按零售价；所有处理都靠事先约定 + 当场留证，事后追责很难。**
