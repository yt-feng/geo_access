要减少香蕉放坏，采购时要同时管住“熟度”和“到货节奏”，核心是让香蕉到店后还能卖几天，而不是到店即熟、隔天发黑。

**一、采购时怎么要求熟度**

按你计划卖完的速度来定：

- **想卖3～5天**：要求到货为 **青香蕉、微黄**，果皮整体偏绿，只有棱边略转黄，果肉硬。适合门店慢慢转色销售。
- **想卖1～3天**：要求到货为 **黄中带一点绿**，即“转色期”，果柄和果尖还带绿，没有黑点。
- **当天或次日就要卖**：可以要 **黄熟、无黑点** 的，但不要大量进，否则很快过熟。
- **不要收**：果皮大面积金黄、果柄发黑、果身有黑斑、按压发软、有酒味或酸味的香蕉。

可以让供货商按“几分熟”说，比如：
- 1～2分熟：全青，只适合长期催熟；
- 3～4分熟：青中带黄，适合门店放几天；
- 5～6分熟：黄中带绿，适合1～3天卖；
- 7分熟以上：黄熟，适合即时促销。

**二、采购时怎么要求到货时间**

- **不要一次到太多**，宁可 **少量多次**。比如每天或隔天到一次，每次按2～3天销量进。
- **要求到货时间避开高温时段**，最好 **早上开市前或傍晚** 到店，减少在车厢和店门口暴晒。
- **要求冷链或通风运输**。夏天尤其要问清是否用冷藏车，温度大概 **13～15℃** 比较合适；不能太低，香蕉怕冻，低于12℃容易冷害发黑。
- **要求产地或批发市场直发后尽快到店**，不要经过多次转运和长时间堆压。
- **要求到货时不要已经堆在常温下太久**，最好刚从冷库或阴凉处出来。

**三、和供货商可以这样约定**

可以直接提：
1. “我要3～4分熟，青中带黄，果柄绿，不能有黑点。”
2. “每次按我2～3天销量发，不要一次性压货。”
3. “夏天要冷藏车或阴凉车，早上到店，不能中午暴晒送到。”
4. “到货如果有黑斑、软果、酒味，我要退换。”
5. “先按小批量试，稳定后再加量。”

**四、到店后配套做法**

- 到店后先 **拆箱、通风、分把**，不要闷在箱里。
- 放在 **阴凉通风处**，避免空调直吹和暴晒。
- 不要和苹果、梨、番茄等释放乙烯多的水果放一起，会催熟香蕉。
- 按熟度分区：青的放里面，黄的放前面先卖。
- 夏天可放 **13～15℃** 冷库或冷柜，但不要低于12℃。
- 已经黄熟的可以 **冷藏展示**，但时间别太长，果皮可能变黑，果肉仍可卖。

**最简单的一句话：**
采购时要求“青中带黄、无黑点、果柄绿”，到货要求“少量多次、早上或傍晚到、夏天走冷链”，到店后通风分把、按熟度先卖黄的。这样香蕉放坏会明显减少。
