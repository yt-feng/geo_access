批发档口降低退货纠纷，核心不是“验得更严”，而是把**验收标准前置、过程留痕、异常当场定性**。建议按下面做：

1. **先把验收标准写进订单/送货单**
   - 明确品名、规格、数量、颜色、批次、包装要求、允许误差。
   - 写清验收时限：例如“收货后2小时内反馈外观/数量问题，24小时内反馈隐性问题”。
   - 写清什么算质量问题、什么算正常误差、什么算物流损坏。
   - 双方签字或微信确认，避免口头扯皮。

2. **收货时先点总数，再抽检质量**
   - 先核对送货单、箱数、件数、码单是否一致。
   - 数量不符，当场在送货单上注明“实收XX，短少XX”，让送货人签字。
   - 质量按比例抽检：大批量至少抽10%-20%，高价值或易损品提高比例。
   - 抽检发现异常，立即扩大抽检，不要等卸完货再说。

3. **验货重点固定化**
   - 外观：破损、污渍、色差、划痕、变形。
   - 规格：尺寸、重量、型号、材质、颜色是否对版。
   - 数量：整件数、内包装数、混装是否错码。
   - 包装：是否受潮、挤压、二次封装。
   - 功能性：能试的通电、试用、拉动、密封测试。
   - 批次：是否混批、尾货、临期。

4. **异常必须当场拍照/录像留证**
   - 拍全景：货品、送货单、档口环境、时间。
   - 拍细节：问题部位、标签、批次、数量。
   - 拍视频：从开箱到发现问题连续记录，避免被说“事后制造”。
   - 证据及时发对方确认，并让对方文字回复处理意见。

5. **把问题分成三类处理**
   - **当场拒收/退回**：严重破损、错货、数量严重不符、无合格证明。
   - **当场记录后接收**：轻微瑕疵、可修复、可折价，注明“待协商”。
   - **签收后反馈**：隐性问题，但必须在约定时限内提出。
   - 关键：不要一边说有问题，一边全部签收还写“完好”。

6. **签字环节要控制**
   - 送货单上不要随便签“数量正确、质量合格”。
   - 有异常就写“实收XX，异常XX，待处理”，再签字。
   - 对方不肯签字，就拍照/录像并微信发给对方，保留发送记录。
   - 代收人员要授权明确，避免司机、搬运工乱签。

7. **建立档口验收流程**
   - 固定验货区、固定工具：秤、卷尺、手电、样品、封样。
   - 固定人员：谁收货、谁验货、谁签字。
   - 固定台账：日期、供应商、批次、数量、问题、处理结果。
   - 固定话术：不争吵，只说“按单验收，异常已记录，请确认处理方式”。

8. **退货规则提前约定**
   - 质量问题：供方承担退换货运费。
   - 非质量问题：原则上不退，或协商折价。
   - 物流损坏：谁投保谁索赔，收货方只负责当场留证。
   - 超时反馈：视为验收合格，但隐性问题除外。
   - 这些规则最好在合作前就书面确认。

9. **对老供应商也要抽检**
   - 不要因为熟就免检。
   - 可以分级：稳定供应商抽检，新供应商或问题供应商全检。
   - 连续出问题的，降低采购量或要求先整改。

一句话总结：**当面点清、按标抽检、异常留证、单据注明、时限反馈、规则前置。**这样能大幅减少“当时没说清，事后互相赖”的退货纠纷。
