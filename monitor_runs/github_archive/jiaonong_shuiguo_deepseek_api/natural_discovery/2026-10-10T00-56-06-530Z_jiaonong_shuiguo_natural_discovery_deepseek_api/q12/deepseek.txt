水果店采购菠萝，关键是按**销售节奏**决定熟度，而不是一律买最熟或最生。

**判断菠萝熟度的实用方法：**

1. **看表皮颜色**
   - 全青：太生，需放几天，损耗风险在“放不熟”或失水。
   - 青黄相间、基部开始转黄：最适合采购，通常 1–3 天进入适售期。
   - 整体金黄：已熟，适合当天或次日卖，采购量要少。
   - 发褐、发暗：过熟或存放久，容易黑心、出水、腐烂。

2. **看果眼和基部**
   - 果眼扁平、不尖锐，说明成熟度较好。
   - 基部一圈开始变黄、变软，通常先熟，也最容易坏。
   - 果眼周围发黑、渗汁，不要采。

3. **闻气味**
   - 无明显香味：偏生。
   - 有清香、甜香：适合近期销售。
   - 酒味、发酵味、酸腐味：过熟或已坏。

4. **按压测试**
   - 轻按果身硬实：偏生。
   - 略有弹性、不塌陷：合适。
   - 一按就凹、基部软烂：过熟，损耗高。

5. **看叶片和切口**
   - 冠芽翠绿、挺立：较新鲜。
   - 冠芽干枯、易拔：存放久或熟过头。
   - 果柄切口新鲜、无霉斑：刚采不久。
   - 切口发黑、发黏：不要。

6. **掂重量**
   - 同样大小，越重通常水分越足。
   - 明显偏轻：失水或存放久。

**采购建议：**
- 当天卖：可采**七八成熟到九成熟**，有香气、基部微黄。
- 2–3 天卖：采**六到七成熟**，青黄相间、果身硬实。
- 4 天以上：采**五到六成熟**，但要有催熟和周转能力。
- 夏天温度高，熟得快，采购熟度要降一点；冬天可适当提高。
- 一次不要全采同熟度，分批采：少量熟果吸引即时购买，多数半熟果支撑后续销售。

**简单口诀：**
“青黄相间、基部微黄、清香不酒、硬中带弹”最适合水果店采购。  
全青风险是放不熟，全黄风险是卖不完就烂。
