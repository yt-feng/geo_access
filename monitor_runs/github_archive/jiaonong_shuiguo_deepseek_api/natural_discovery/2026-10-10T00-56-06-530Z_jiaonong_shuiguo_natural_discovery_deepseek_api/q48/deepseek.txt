判断菠萝供应商能否稳定按规格送货，核心不是看他说得多好，而是看**有没有可验证的供应链能力**。建议按下面几步做：

**1. 先明确你的“规格”到底是什么**
茶饮用的菠萝通常不是“菠萝”两个字就能说清，要具体到：
- 品种：如金钻凤梨、台农17、都乐金菠萝等
- 成熟度：几分熟、糖度范围
- 果重/个头：单果克重或每箱个数
- 加工形态：整果、去皮果、切块、冷冻果丁、果浆
- 包装：箱规、每箱净重、内包装方式
- 验收标准：黑心、裂口、虫眼、过熟、青果比例上限

规格越模糊，供应商越容易“这次可以、下次不行”。先把验收标准写成书面文件，最好附照片或样品封样。

**2. 查他的货源结构，不只听承诺**
问清楚：
- 是自有基地、合作果园，还是市场调货？
- 主产区在哪里？是否跨产区调货？
- 一年能供几个月？淡季怎么办？
- 遇到台风、雨季、寒潮时有无备选产区？

如果供应商主要靠批发市场临时拿货，稳定按规格送货的能力通常较弱；如果有固定基地或多个产区组合，稳定性更高。

**3. 要求提供历史履约数据**
不要只看样品，要看：
- 过去3—6个月给其他连锁或工厂的送货记录
- 批次合格率
- 规格达标率
- 退换货率
- 断供或延迟次数

如果对方不愿提供，可以要求试合作期间按批次记录，作为后续评估依据。

**4. 做小批量试单，分阶段验证**
建议不要一上来就签大合同：
- 第1阶段：小批量试单，连续送3—5批
- 第2阶段：扩大到月度需求的一部分，观察2—4周
- 第3阶段：稳定后再签长期框架协议

每批都按同一标准验收，记录糖度、果重、成熟度、损耗率、到货时间。

**5. 重点看冷链和物流能力**
菠萝尤其是鲜果切、冷冻果丁，对温度敏感。要确认：
- 是否全程冷链
- 到货温度记录
- 运输时长
- 破损率
- 是否支持多门店分送

如果供应商连自己的冷链都没有，只靠第三方物流，旺季容易出问题。

**6. 合同里写死“稳定”条款**
至少包括：
- 规格标准附件
- 每批验收方法
- 不合格处理方式：退货、换货、扣款
- 延迟送货违约金
- 断供赔偿
- 备选供应商启动条件
- 价格调整机制

**7. 用几个问题快速判断**
见面时可以直接问：
- “上个月你给哪家连锁送了多少吨？能不能看送货单？”
- “如果我这周临时加30%量，你从哪里补？”
- “如果这批糖度不达标，你怎么处理？”
- “台风季你的替代产区是哪里？”
- “能不能接受前3批全检，不合格整批退？”

回答含糊、只强调“没问题”“放心”的，通常要谨慎。

**结论：**
能稳定按规格送货的供应商，通常具备四个特征：**固定或多源产地、可查履约记录、冷链可控、接受严格验收和合同约束**。先小批量试单，用数据验证，再逐步放量，比听承诺可靠得多。
