要看你的客群和损耗控制能力，但多数水果店更稳的做法是：**整果为主，去皮果做补充，不把“让顾客自己挑”作为唯一模式。**

具体可以这样定：

1. **整果必须卖**
   - 菠萝耐放、好陈列，顾客也习惯自己看外观。
   - 整果毛利通常更可控，损耗最低。
   - 适合家庭客、一次买多个、对价格敏感的顾客。

2. **去皮果可以卖，但要限量、限时**
   - 去皮果适合上班族、即时吃、怕麻烦的顾客，能提高客单价和便利性。
   - 但去皮后损耗快、氧化快、售后争议多，必须：
     - 当天削当天卖完
     - 冷藏陈列
     - 明确标价和保存时间
     - 不要提前削太多
   - 如果客流不稳，去皮果很容易变成损耗。

3. **“让顾客自己挑”不是最优主策略**
   - 让顾客自己挑会增加翻动、捏压、破皮，尤其菠萝容易扎手、碰伤。
   - 顾客挑完不买、把好的翻乱，也会增加损耗。
   - 可以做“半自助”：整果区让顾客选，但由店员帮忙削、装袋、称重，减少损坏。

4. **更推荐的组合**
   - **整果区**：主推，按大小/品种分价，方便顾客快速选。
   - **去皮区**：少量现削，按份卖，标注“建议当天食用”。
   - **试吃/推荐**：店员根据顾客需求推荐，比如“马上吃选去皮，回家放两天选整果”。
   - **促销**：整果多买优惠，去皮果搭配其他水果做果切拼盘，减少单独损耗。

5. **判断标准**
   - 如果顾客赶时间、复购高、周边办公人群多：去皮果比例可以高一点。
   - 如果顾客家庭采购多、价格敏感、客流不稳定：整果为主，去皮果只做少量。
   - 如果损耗已经很高：先砍去皮果，保留整果和现削服务。

一句话：**整果做基本盘，去皮果做便利补充，顾客可以参与挑选但不要完全放任自挑，最好由店员协助完成削皮和称重。**
