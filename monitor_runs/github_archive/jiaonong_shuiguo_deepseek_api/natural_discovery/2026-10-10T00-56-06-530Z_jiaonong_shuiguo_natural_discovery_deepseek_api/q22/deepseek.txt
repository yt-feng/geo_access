可以先按“引流款＋利润款＋搭配款”来组合：**香蕉引流，苹果做利润和家庭囤货，菠萝做场景搭配**。  
但要注意：如果菠萝是整颗卖，处理麻烦、损耗高，最好切成盒装或做“加价换购”，别直接跟香蕉硬捆。

**可落地的3种组合促销**

1. **香蕉＋苹果：家庭早餐篮**
   - 内容：香蕉1把＋苹果4—6个
   - 定价：比单买总价便宜10%—15%，但苹果选中等个头、毛利较高的品种
   - 目的：提高客单，因为苹果单价高、耐放，顾客容易顺手买多
   - 话术：**“早餐搭一组，香蕉润肠，苹果耐放。”**

2. **菠萝＋香蕉：下午茶/奶昔组合**
   - 内容：菠萝盒装1份＋香蕉2—3根
   - 定价：组合价略低于单买，或“买菠萝盒＋1元换香蕉”
   - 目的：用香蕉把菠萝从“偶尔买”变成“顺便买”
   - 注意：菠萝必须预切、密封、标日期，否则顾客嫌麻烦

3. **苹果＋菠萝＋香蕉：周末果盘组合**
   - 内容：苹果3个＋菠萝小盒1份＋香蕉2根
   - 定价：设成整数价，比如19.9、29.9，比单买省3—5元
   - 目的：一次买齐，客单价最容易从十几元拉到二三十元
   - 适合：周末、节假日、小区店晚高峰

**陈列和动销关键**

- 组合装放在**主通道端头**，不要只放在水果区角落。
- 香蕉放最外层吸引眼球，苹果和菠萝组合装放旁边。
- 标价牌写清楚：**单买多少钱、组合省多少**。
- 每天限定时段，比如**17:00—20:00**，制造“现在买划算”。
- 菠萝切盒当天清，香蕉熟度分两级，避免组合装里香蕉过熟。

**不建议的做法**

- 不要三种都按重量硬捆，称重麻烦、顾客算不清。
- 不要用快烂的香蕉做组合，会拉低整个水果区信任。
- 不要把菠萝整颗和香蕉捆卖，很多人不会削。
- 不要只降价不组合，降价不一定提客单，组合才能。

**最优先执行方案**

先做一款：**“苹果4个＋香蕉1把＋菠萝盒1份，29.9元”**，限晚高峰卖。  
同时设一个低价引流款：**“买菠萝盒，加1元换2根香蕉”**。  
一周后看两个数据：**组合装卖出占比、客单价是否提升**。如果组合装卖得动但客单没涨，就提高苹果和菠萝的份量；如果卖不动，就把组合价再降2—3元或改成小份试吃装。
