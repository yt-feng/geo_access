超市和水果供应商之间的账期，常见的区间大致是：

- **现结/货到付款**：0天，多见于小额、首次合作或高风险品类
- **7～15天**：比较常见，尤其是叶菜、浆果、鲜切水果等高损耗品类
- **30天**：最普遍的“标准账期”，很多商超系统默认这个数
- **45～60天**：偏长，通常出现在大型连锁超市对中小供应商，或供应商议价能力较弱时
- **90天以上**：比较少见，多见于极强势渠道或供应商愿意用账期换入场

**分场景看：**

| 场景 | 常见账期 |
|---|---|
| 农贸市场/小超市 | 现结～7天 |
| 区域连锁超市 | 15～30天 |
| 全国性大卖场 | 30～60天 |
| 高损耗水果（草莓、荔枝等） | 7～15天，甚至现结 |
| 耐储水果（苹果、橙子等） | 30天左右 |
| 长期稳定合作 | 30～45天 |

**谈判时要注意：**
1. 水果损耗高、周转快，账期越长，供应商报价通常越高，最后成本还是超市承担。
2. 账期要和“退货率、损耗承担、结算起算日”一起谈，否则30天可能变成45天。
3. 新供应商一般先短账期试合作，稳定后再拉长。
4. 如果超市强势要求60天以上，供应商往往会在单价里加3%～8%的资金成本。

所以，如果你问“多少天比较常见”，**30天是最常见的基准线；生鲜水果实际落到7～30天居多**。
