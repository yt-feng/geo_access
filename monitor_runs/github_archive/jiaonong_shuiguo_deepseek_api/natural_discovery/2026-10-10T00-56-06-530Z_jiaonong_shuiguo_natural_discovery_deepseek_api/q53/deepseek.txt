如果餐饮店每天只需要少量水果，省心的核心不是找“最便宜”，而是找**稳定、可小批量、能按你要的规格和熟度送货、售后不扯皮**的供应商。可以优先考虑下面几类：

1. **本地水果批发市场里的固定档口**
   - 适合：每天用量不大，但希望品种能换、能挑。
   - 优点：价格通常比超市和生鲜平台低，可以当面看货，临时加量也方便。
   - 省心做法：固定找1-2家档口，谈好“每天几点前送到、少量起送、坏果包换”。不要每天临时换档口。

2. **专做餐饮配送的生鲜/水果配送商**
   - 适合：想要省事、开票、固定账期、每天定时送。
   - 优点：有配送体系，能按餐饮客户做小批量，售后相对规范。
   - 注意：起送价、配送费、是否可指定熟度、缺货替代规则要提前写清。

3. **本地果园或合作社直供**
   - 适合：你主用某几种水果，比如柠檬、橙子、苹果、西瓜等。
   - 优点：品质和价格可能更稳，适合做招牌饮品或果盘。
   - 缺点：品种单一，季节性明显，小量配送未必愿意接。
   - 省心做法：只把1-2个核心单品交给果园，其余用配送商补。

4. **社区团购/生鲜平台的企业采购**
   - 适合：用量很小、临时补货。
   - 优点：下单方便，起送门槛低。
   - 缺点：品质波动大，不适合每天依赖，尤其餐饮高峰期容易掉链子。

更省心的组合建议：

- **主供应商**：选1家本地餐饮水果配送商，负责每天基础用量。
- **备用供应商**：选1家批发市场档口，缺货、临时加量时补。
- **核心单品**：如果某款水果用量大，再找果园直供。

找供应商时重点问清这8件事：

1. 少量能不能送，起送量是多少？
2. 每天几点前能到，能不能固定时间？
3. 坏果、烂果、缺斤少两怎么赔？
4. 能不能按你要求的熟度送，比如香蕉要青一点、芒果要熟一点？
5. 缺货时是否提前说，能否换同等价位品种？
6. 价格是每天随行就市，还是每周/每月锁价？
7. 能不能开票，账期是现结还是月结？
8. 临时加单最晚几点前说？

最省心的判断标准：

- 连续送一周，迟到少；
- 坏果率低，有问题直接补；
- 不用你每天催单、比价、换人；
- 价格不是最低，但算上损耗和人工后总成本可控。

如果你们店每天水果量真的很少，比如只有几斤，最省心的通常不是找大供应商，而是：**本地批发市场固定档口 + 生鲜平台应急**。如果每天有稳定十几斤以上，再考虑专门餐饮配送商或果园直供。
