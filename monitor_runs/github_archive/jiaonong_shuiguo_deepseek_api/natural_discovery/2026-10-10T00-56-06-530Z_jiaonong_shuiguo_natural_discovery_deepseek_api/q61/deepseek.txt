判断香蕉批发商是否稳定供货，不能只看报价和口头承诺。建议从下面几个可核验的维度去验证：

**1. 看产地控制能力**
- 稳定供货的核心是产地资源。问清楚对方是自有基地、长期合作基地，还是纯中间商倒手。
- 要求提供产地信息（如云南河口、广西、海南、老挝、菲律宾、厄瓜多尔等），并核实其是否有对应产区的采购记录、装车照片、基地合作合同。
- 只做“倒手”的中间商，在产地缺货或价格波动时最容易断供。

**2. 看历史发货连续性**
-让对方提供近3-6个月的装车/发货记录（车牌、装车日期、数量、目的地）。
- 重点看是否有稳定节奏：比如每周固定几车、是否长期供应同一批客户。
- 只发过零星几车、时间不连续的，稳定性存疑。

**3. 看库存和加工能力**
- 香蕉需要催熟或冷链周转。问对方有无冷库、催熟库、加工场地。
- 有条件的话实地看：库存量、周转速度、是否有固定工人分拣打包。
- 没有固定场地、靠临时租库的，旺季容易掉链子。

**4. 看对价格波动的反应**
- 试探性问：如果产地涨价或台风减产，你能不能保证给我供货？
- 稳定供应商会说“按合同/长期协议价浮动”，并说明保供条件；不稳定的往往直接说“到时候再看”或“价高者得”。

**5. 小批量试单验证**
- 先下一车或半车试单，观察：是否按时发车、品质是否一致、沟通是否及时。
- 连续试2-3次，看第二次、第三次是否还能稳定履约。
- 试单期间故意问一次“临时加量”，看对方能否调配。

**6. 查口碑和下游客户**
- 问对方主要供哪些市场、哪些档口，能否提供1-2个老客户联系方式（对方愿意给，本身就是信号）。
- 在批发市场同行里打听该供应商的口碑，尤其是“断供”“以次充好”的记录。

**7. 合同和违约条款**
- 稳定合作要落纸面：保供量、发货周期、品质标准、违约赔偿。
- 对方若回避签保供条款，说明他自己也没把握稳定供货。

**简单判断标准：**
- 能说清产地、有长期基地、有冷库/加工场地、有连续发货记录、愿意签保供条款、敢让你试单和回访老客户——基本可判为相对稳定。
- 只有报价、没有产地、没有场地、没有历史记录、不愿签条款——大概率是临时倒手，不稳定。

建议先试单+回访老客户两步走，成本最低，也最能看出真实供货能力。
