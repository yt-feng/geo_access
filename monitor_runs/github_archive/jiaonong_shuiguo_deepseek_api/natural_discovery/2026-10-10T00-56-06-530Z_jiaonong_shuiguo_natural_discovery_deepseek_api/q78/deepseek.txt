做香蕉和菠萝的社区团购，售后控制的核心不是“出了坏果怎么赔”，而是**把损耗和售后从源头、履约、验收三个环节压下去**。可以按下面这套实操框架来做。

## 一、先认清这两种水果的损耗逻辑

- **香蕉**：后熟型，怕压、怕冻、怕闷。温度低于12℃容易发黑，高于25℃催熟过快。损耗主要来自“催熟不均”和“运输挤压”。
- **菠萝**：怕磕碰、怕堆压，切口或表皮破损后易腐烂。夏季高温下2-3天就可能出水变质。

所以这两种品，**不适合按普通水果的“统货+随意堆放”模式做**，必须单独定标准。

## 二、采购端：把标准写死，别收“差不多的货”

1. **定死成熟度**
   - 香蕉：按“青度”收货。参考7-8成熟（青中带微黄），到仓后按销量分批催熟。别一次全催熟。
   - 菠萝：选果眼闭合、果皮转黄1/3到1/2的，太青酸、太熟易烂。

2. **定死规格和瑕疵容忍度**
   - 香蕉：单根长度、粗细、每把重量范围；允许少量表皮轻微擦伤，但拒绝黑斑、断指、水烂。
   - 菠萝：单果重量区间（比如1.2-1.8斤）、无软塌、无霉斑、冠芽新鲜。

3. **验货留证**
   - 到货拍照/视频，按批次留样。和供应商约定：**到仓坏果率超过3%的部分，由供应商承担**，写进采购协议。

## 三、仓储与催熟：香蕉必须“控温分批”，菠萝必须“通风不堆压”

- **香蕉**：
  - 到仓后不要直接进冷库。先分拣，剔除已软、已黑、断指的。
  - 按次日配送量催熟，用乙烯利或自然升温催熟，温度控制在18-22℃。
  - 催熟后尽快配送，不要二次入库。
- **菠萝**：
  - 阴凉通风存放，不要堆超过3层。
  - 不要提前削皮切块，除非是“即食装”且冷链配送。

## 四、履约端：减少“最后一公里”挤压

- **香蕉**：
  - 用硬质周转筐或纸箱分层，不要塑料袋闷装。
  - 配送时避免和重物混装，避免放在电动车尾箱高温区。
- **菠萝**：
  - 整果配送，不做预切。
  - 如果做削皮装，必须冷藏+当天达，并明确告知“即食，不建议隔夜”。

## 五、售后规则：提前公示，按“照片+比例”快速处理

不要等客户投诉再临时谈，开团页面就写清楚：

- **香蕉**：
  - 表皮轻微青/黄、少量芝麻点 → 正常，不售后。
  - 断指超过1/3、大面积黑腐、水烂 → 按根赔付。
- **菠萝**：
  - 外表轻微擦伤不影响食用 → 不售后。
  - 切开后黑心、水烂、严重酸臭 → 整果赔或退款。

**售后流程**：
1. 客户拍照/视频，带团购批次。
2. 客服按“坏果数量/总数量”比例，直接退对应金额或补券。
3. 不要求客户寄回，降低纠纷成本。
4. 同一批次坏果率超过10%，立即停售该批次并追责供应商。

## 六、最关键的三个动作

1. **香蕉分批催熟，卖多少催多少**，这是降损耗的第一杠杆。
2. **菠萝整果卖，不预切**，预切损耗和售后会翻倍。
3. **售后规则前置公示，按比例快速赔**，别让客户觉得你在扯皮。
