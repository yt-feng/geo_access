判断香蕉供应商能否全年稳定供货，核心不是听他怎么说，而是看他的**货源结构、产地布局、硬件能力和历史履约记录**。可以按下面几步查：

**1. 先问清他的货源是“单一产地”还是“多产地组合”**
- 香蕉是热带作物，单一产区必然有淡旺季和气候风险。
- 能全年稳定供货的供应商，通常手里有多个产区轮换，比如国内海南、云南、广西，加进口的菲律宾、越南、厄瓜多尔、柬埔寨等。
- 关键问法：  
  “你全年12个月分别从哪些产区拿货？每个产区的供应月份、占比是多少？”  
  如果他说不清月份轮换，只讲“随时有货”，基本不可靠。

**2. 看他有没有催熟和仓储能力**
- 香蕉采购通常不是要树上熟，而是要青蕉，再由超市或供应商催熟。
- 稳定供应商一般有催熟库、冷库、加工场地，能控制到货成熟度和批次节奏。
- 如果他没有催熟能力，只做转手贸易，旺季可能没问题，淡季或价格波动时容易断供。

**3. 查他的历史履约记录**
- 让他提供过去12个月的供货记录，最好能对应到具体客户。
- 重点看：有没有连续供货、有没有单月断供、断供后怎么补货、补货周期多长。
- 可以要求提供近3个月的发货单、物流单、质检记录，交叉验证。

**4. 做小批量试单，跨淡旺季验证**
- 不要一上来就签全年大合同。
- 先按季度或月度试单，至少覆盖一个淡季和一个旺季。
- 试单时重点观察：
  - 到货时间是否稳定；
  - 单批次重量、成熟度、损耗率是否一致；
  - 临时加单能不能响应；
  - 出现质量问题时处理速度。

**5. 看物流和口岸能力**
- 进口香蕉依赖口岸通关、冷链运输。供应商如果有关口关系、稳定冷链车队或合作物流，抗风险能力更强。
- 问清楚：主要走哪个口岸、通关时间、冷链车数量、异常天气或节假日怎么保供。

**6. 合同里写清“保供条款”**
- 不要只写价格和数量，要写：
  - 全年分月供货计划；
  - 淡季最低供货量；
  - 断供违约金；
  - 替代产地或替代品种方案；
  - 质量不达标时的补货和扣款机制。

**简单判断标准：**
- 能说清12个月产地轮换的，加分；
- 有催熟库、冷库、稳定冷链的，加分；
- 有过去一年连续供货记录的，加分；
- 只靠一个产地、一个口岸、口头承诺的，风险高；
- 不肯试单、不肯写保供条款的，直接淘汰。

最稳的做法是：**先试单验证，再签带保供条款的季度或年度合同，同时保留一个备用供应商。**
