要避免香蕉到店后很快变黑，核心是控制 **成熟度、温度、乙烯和机械损伤**。采购时和到店后可以这样做：

1. **采购时选成熟度偏低的香蕉**
   - 优先选 **颜色偏绿、刚转黄** 的香蕉，不要选已经全黄、带黑点或果柄发黑的。
   - 如果甜品店当天或第二天就要用，可以选“黄中带一点绿”；如果要放 2–3 天，选更绿一些的。
   - 避免买已经软熟、有压伤、裂口、发霉的香蕉。

2. **减少机械损伤**
   - 搬运时轻拿轻放，不要堆压、摔碰。
   - 香蕉受挤压后，受伤部位会更快变黑腐烂。
   - 到店后尽量保留原包装或纸箱，不要直接倒成一堆。

3. **控制温度，但不要直接冷藏未熟香蕉**
   - 未完全成熟的香蕉：放在 **13–15℃、阴凉通风处** 比较合适。
   - 已经成熟、准备尽快使用的香蕉：可以放 **冷藏室**，但香蕉皮会变黑，果肉短期内仍可用。若在意卖相，不建议冷藏。
   - 不要放在空调出风口、暖气旁、烤箱边或阳光直射处。

4. **隔离乙烯，减少催熟**
   - 香蕉会释放乙烯，也会被乙烯催熟。
   - 不要和苹果、梨、猕猴桃、牛油果等一起放。
   - 可以用保鲜膜包住香蕉果柄，因为果柄是释放乙烯较多的部位。
   - 如果店里有多箱香蕉，尽量分开摆放，不要全部挤在一个密闭空间。

5. **保持通风，避免闷湿**
   - 纸箱可留通气孔，不要用塑料袋完全密封。
   - 湿度太高容易发霉，太干又会失水。阴凉通风即可。
   - 发现有一根开始发黑腐烂，立刻挑出，避免影响其他香蕉。

6. **按使用节奏分批采购**
   - 不要一次买太多。甜品店最好按 **1–2 天用量** 采购。
   - 如果必须多买，分成“马上用”和“后备用”两批，后备用选更绿的。
   - 到店后先用的放外面，后用的放阴凉处。

7. **到店后的简单处理**
   - 先检查，挑出坏果。
   - 果柄用保鲜膜包一下。
   - 放在阴凉通风货架上，避免叠压。
   - 每天翻看一次，先熟先用。

**最实用的采购标准：**
- 当天用：选黄中带绿、无黑点。
- 1–2 天用：选偏绿、刚开始转黄。
- 2–3 天用：选青绿、硬实、无损伤。

如果香蕉已经熟了但一时用不完，可以 **去皮后冷冻**，以后做奶昔、香蕉泥、烘焙馅料，不影响甜品使用。
