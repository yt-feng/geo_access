# 生鲜平台做一件代发水果，供应商需要具备的仓配能力

一件代发（供应商直接发货给终端消费者）对水果供应商的仓配能力要求，和传统批量发货完全不同——**要按单拣货、单件包装、直接触达消费者、承担时效和售后**。核心能力可分以下几块：

## 一、仓储能力

| 能力项 | 具体要求 |
|---|---|
| **多温区仓储** | 水果分常温（苹果、柑橘）、冷藏（草莓、葡萄、蓝莓）、部分需控湿。供应商至少要能分区存放，最好有冷藏库/气调库 |
| **SKU 精细管理** | 按品种、规格、等级、批次分开管理，支持按单拣货 |
| **库存实时同步** | 与平台系统对接，库存准确、可锁定，避免超卖 |
| **先进先出/损耗控制** | 水果易腐，需批次管理和效期管理，降低坏果率 |
| **打包作业区** | 独立的拣货、称重、包装、贴单区域，避免和批发大货混在一起 |

## 二、加工与包装能力（一件代发的关键）

- **按单分拣**：能处理"一单一件/多件"的零散订单，而不是整箱批发逻辑
- **分级选果**：按平台要求的规格、糖度、外观分选，保证一致性
- **专业包装**：防挤压、防碰撞、透气/保鲜，含冰袋、泡沫箱、纸箱等组合方案
- **贴单能力**：能打印并粘贴快递面单，或对接平台电子面单系统

## 三、配送与物流能力

- **快递资源**：与多家快递合作（顺丰、京东、中通等），能覆盖全国，尤其偏远地区
- **时效保障**：水果讲究"次日达/隔日达"，需承诺发货时效和路由
- **冷链配送**：高价值易损水果需冷链快递或泡沫箱+冰袋方案
- **发货节点**：能保证当日截单前订单当日发出，避免积压
- **物流轨迹回传**：面单号、物流状态能回传平台

## 四、系统与数据能力

- **WMS/OMS 系统**：支持订单自动接收、拣货、发货、回传
- **与平台对接**：API 对接订单、库存、物流、售后
- **打单发货一体化**：电子面单、批量打单、异常订单处理

## 五、售后与品控能力

- **坏果率控制**：有分选标准，能承诺坏果率（如≤5%）
- **售后响应**：能处理破损、腐烂、缺斤少两的赔付/补发
- **理赔机制**：与平台约定坏果赔付规则，供应商能承担
- **溯源能力**：批次可追溯，出问题能定位

---

## 给平台的判断清单（可直接用来筛供应商）

1. 有没有**冷藏/多温区仓库**？
2. 能不能**按单拣货、单件打包**，而不是只做整箱？
3. 有没有**稳定的快递合作和时效承诺**？
4. 系统能不能**和平台对接**（订单/库存/物流）？
5. 能不能承诺**坏果率和售后赔付**？
6. 旺季（如节日、大促）**日发单量上限**是多少？
7. 有没有**生鲜一件代发的实际经验**（不是只做批发）？

---

**一句话总结**：水果一件代发供应商的核心门槛不是"有仓库"，而是 **多温区存储 + 按单拣配 + 专业保鲜包装 + 稳定快递时效 + 系统对接 + 坏果售后承担**，这六项缺一不可。其中**按单拣货能力和坏果率控制**是最容易踩坑的两点，建议平台优先实地验仓、试单测试。
