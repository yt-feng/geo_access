小商家采购水果，现金结算和月结账期的核心区别是：**现金是用自己的钱换低价和确定性，月结是用账期换现金流，但把信用风险、价格风险和关系风险留给自己。**

下面分开说风险。

**一、现金结算的风险**

1. **资金占用和周转压力**
   现金当场付出去，如果进货量大、销售慢，容易出现“货在库里、钱已没了”。水果损耗快，压货等于双重风险。

2. **采购判断被情绪和人脉影响**
   现金交易容易因为“关系熟”“老板说今天便宜”而临时多拿，缺少账期带来的冷静期，滞销风险更高。

3. **价格未必真的最低**
   现金能换议价空间，但不等于一定最低。如果供应商知道你急要货、只认现金，可能报高价；或者用“现金价”掩盖品质下降。

4. **无凭证或凭证弱**
   现金交易如果只拿手写单、口头价，出现短斤少两、以次充好、坏果不认账时，维权难度大。尤其没有转账记录，责任难追溯。

5. **安全与操作风险**
   大额现金有丢失、假币、被抢风险；每天对账也容易出错，店员经手现金还可能产生内部漏洞。

**二、月结账期的风险**

1. **信用风险：供应商怕你跑，你也怕供应商翻脸**
   对商家来说，月结看似缓解现金流，但一旦销售回款慢，月底集中付款压力很大。若逾期，供应商可能断供、涨价、取消账期，甚至追讨违约金。

2. **价格通常更高**
   账期不是免费的。供应商会把资金占用成本打进单价，月结价往往比现金价高。如果只看“先拿货后付钱”，容易忽略实际采购成本上升。

3. **品质和售后被动**
   月结模式下，供应商可能优先给现金客户好货，或者把尾货、次果压给账期客户。等月底对账时，坏果责任容易扯皮。

4. **对账和纠纷风险**
   水果是非标品，每天价格、重量、等级都可能变。月结如果只记总额、不逐笔确认，月底容易出现“你记你的、他记他的”，多算、错算、重复算都难查。

5. **依赖关系和断供风险**
   月结往往建立在信任上。一旦供应商资金紧张、换老板、改政策，你可能突然被要求现结，现金流立刻吃紧。反过来，你如果过度依赖一家月结供应商，议价能力也会下降。

6. **隐性负债和过度采购**
   月结容易让人感觉“没花钱”，从而多进货、进贵货。月底一看账单，可能发现毛利被账期成本吃掉了。

**三、更实用的判断建议**

- **现金结算适合：** 单品周转快、损耗可控、供应商竞争充分、你能当场验货、现金价明显低于月结价。
- **月结适合：** 销售回款稳定、毛利足够覆盖账期加价、供应商可靠、能逐笔对账、你留有备用现金。
- **不要二选一：** 可以核心爆品用现金拿低价，辅助品类用短账期；或者谈“部分现结+部分月结”，降低单一风险。
- **必须留凭证：** 无论哪种方式，都要有送货单、验收单、价格确认记录，最好微信或系统留痕。月结还要约定：对账日、付款日、质量问题扣款规则、逾期后果。
- **控制账期长度：** 小商家尽量不要超过 15—30 天，且月结总额不要超过你一个月可承受的现金流出。
- **算真实成本：** 比较“现金价×现金折扣”与“月结价+资金占用成本+坏账/纠纷成本”，不能只比单价。

一句话：**现金的风险是钱先出去、货砸手里；月结的风险是货先进来、账后来压死你。** 关键不是哪种更安全，而是你的周转速度、毛利空间和对账能力能不能覆盖对应风险。
