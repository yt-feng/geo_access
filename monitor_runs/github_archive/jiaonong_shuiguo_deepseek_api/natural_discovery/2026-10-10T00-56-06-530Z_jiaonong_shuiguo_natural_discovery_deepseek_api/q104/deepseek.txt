单位采购水果到货品质不一致，验收和售后建议按下面这套流程处理，核心是：**先固定证据，再按合同/订单标准分级判定，最后按比例扣款、换货或补货**。

## 一、验收前先明确标准

验收能不能站住脚，取决于事前有没有写清楚。采购单或合同里最好明确：

1. **品种、规格**：如苹果直径80mm以上、单果重、几级果。
2. **成熟度**：如香蕉到货青度、猕猴桃硬熟可放软。
3. **外观标准**：允许的伤果、烂果、虫眼、畸形比例。
4. **新鲜度**：叶菜是否萎蔫、根茎是否发芽、果面是否皱缩。
5. **包装与温度**：冷链品种到货温度、箱规、净重。
6. **验收期限**：到货后几小时内验收，逾期是否视为合格。
7. **不合格处理**：扣款比例、换货时限、补货责任、运费承担。

如果没有书面标准，至少保留聊天记录、报价单、样品照片、供应商承诺，作为验收依据。

## 二、到货验收怎么做

### 1. 到场先看整体

- 拍照/录像：车牌、送货单、外包装、整批货状态。
- 核对送货单：品种、数量、规格、批次、到货时间。
- 冷链水果测中心温度，记录是否断链。

### 2. 抽样验收

不能只看表面，也不能全拆。建议：

- 按批次、箱号、供应商分层抽样。
- 大批量按 **5%—10%** 抽检，小批量至少抽3—5箱。
- 每箱随机取上、中、下三层。
- 对争议品种可全检或提高抽检比例。

### 3. 分级记录

把货分成：

- **合格品**：符合约定标准。
- **次品/降级品**：轻微瑕疵，可折价接收。
- **不合格品**：腐烂、变质、严重损伤、规格不符。

记录时要写清：

- 不合格类型；
- 数量/重量；
- 占比；
- 对应箱号、批次；
- 现场照片和视频。

### 4. 当场确认

让送货人、司机或供应商代表在场确认，并在验收单上签字。对方不签的，要在送货单上注明“存在品质争议，详见验收记录”，并拍照留证。

## 三、判定与处理方式

按不一致程度处理：

| 情况 | 处理建议 |
|---|---|
| 少量轻微瑕疵 | 折价接收，按次品比例扣款 |
| 部分规格不符 | 降级计价或退回不符部分 |
| 腐烂、变质、异味 | 拒收该批次或该部分，要求换货 |
| 整体品质明显低于约定 | 整批拒收或重新议价 |
| 影响食品安全 | 立即隔离，不得入库、不得分发 |

常见售后方式：

1. **换货**：供应商在约定时间内补送合格品。
2. **补货**：数量不足或损耗部分补齐。
3. **扣款**：按不合格比例扣减货款。
4. **退货退款**：严重不符时整批退回。
5. **索赔**：因品质问题造成额外损失，如活动延误、二次运输费，可按合同追偿。

## 四、售后沟通要点

联系供应商时，不要只说“质量不好”，要给出可执行信息：

- 订单号/送货单号；
- 到货时间；
- 抽检数量；
- 不合格比例；
- 具体问题照片；
- 要求：换货、补货、扣款还是退货；
- 期限：如24小时内答复，48小时内补送。

示例话术：

> 本次到货苹果共20箱，抽检5箱，其中2箱发现明显压伤和腐烂，不合格约18%。现场已拍照并让送货人确认。请于24小时内确认处理方案，48小时内补送合格果，否则按合同第X条扣减相应货款。

## 五、内部管理建议

1. **验收单标准化**：品种、数量、抽检数、不合格数、处理意见、双方签字。
2. **留样**：争议批次保留样品和照片，至少保存到结算完成。
3. **分开存放**：不合格品单独隔离，避免混入合格品。
4. **及时录入**：当天录入验收结果，避免事后扯皮。
5. **供应商评分**：多次品质不一致的，降低评分、减少订单或列入黑名单。

## 六、最简操作流程

到货 → 拍照留证 → 核对单据 → 抽样分级 → 当场确认 → 判定合格/折价/拒收 → 通知供应商 → 换货/补货/扣款 → 入库结算。

关键原则：**没有验收记录，售后很难主张；没有事前标准，验收很难判定。** 所以单位采购水果，最好在订单里就把规格、瑕疵允许比例、验收时限和售后方式写清楚。
