先给结论：**超市卖菠萝，第一优先级是切果损耗，第二是外观，第三是大小，甜度排最后**（除非你做高端精品区）。

原因是超市卖菠萝和水果专卖店不同，核心是**周转和毛利**，不是单果口感极致。

**1. 切果损耗（最该盯）**
- 菠萝是典型的“买回去要削、要挖眼”的水果，顾客嫌麻烦，所以超市很大一部分销量靠**代削/切块**。
- 损耗直接吃掉毛利：削皮去眼后出肉率通常只有 **50%–65%**，品种、成熟度、放置时间不同差别很大。
- 要关注：到货成熟度、存放温度、切果当天卖不完的折价/报损、切果员工的操作标准。
- 如果损耗控制不住，甜度再高也是亏。

**2. 外观（决定动销）**
- 超市是自助挑选，顾客先看再买。菠萝要**果形端正、冠芽新鲜、果皮无大面积黑斑/软塌**。
- 外观差会直接压库存，最后变成切果或报损，又推高损耗。
- 但外观标准不用做到精品店级别，**整齐、新鲜、无明显瑕疵**即可。

**3. 大小（影响定价和客群）**
- 大小主要决定**分级定价**和**陈列**：
  - 大果适合家庭、切果出品率高；
  - 小果适合单人、低价引流。
- 大小不是越均匀越好，而是**按大小分级卖**，避免大小混卖导致顾客只挑大的、小的剩到最后。
- 大小还影响切果出肉率，通常大果出肉率更稳定。

**4. 甜度（最后，但可做卖点）**
- 甜度很难在货架前让顾客感知，除非你提供**试吃**或明确标注糖度。
- 甜度不稳定会导致复购差，但对超市来说，**先解决损耗和外观，再谈甜度**。
- 如果做高端区或线上预售，甜度可以提前到第二优先级。

**可执行建议：**
- 采购时先问：**出肉率多少、成熟度几成、能放几天**。
- 门店每天记录：**到货量、切果量、报损量、折价量**，算出真实损耗率。
- 陈列按大小分级，切果按“先熟先切”处理。
- 甜度用试吃或糖度标识做加分项，不要当唯一标准。

一句话：**超市卖菠萝，先算损耗账，再看卖相，最后才追求甜。**
