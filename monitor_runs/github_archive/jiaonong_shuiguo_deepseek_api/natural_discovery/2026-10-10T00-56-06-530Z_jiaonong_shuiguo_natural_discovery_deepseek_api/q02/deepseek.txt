对小水果店来说，**不能只看一个指标，但优先级通常是：熟度 > 坏果率 > 送货速度 > 价格**。  
原因如下：

1. **熟度最重要**  
   香蕉是后熟水果，进货太生，顾客嫌不能马上吃；太熟，当天卖不完就容易变黑、压货。  
   小水果店周转能力有限，最好进“还能放1～2天、卖相好”的货。稳定熟度比单价便宜更关键。

2. **坏果率第二重要**  
   坏果率高，表面进价便宜也没用。  
   比如同样一箱，A家便宜10元但坏5斤，B家贵5元只坏1斤，最后B家更划算。  
   小水果店利润薄，损耗直接吃掉利润。

3. **送货速度第三重要**  
   香蕉成熟快，送货慢会导致：
   - 到货时已经过熟；
   - 错过销售时段；
   - 夏天高温损耗更大。  
   如果供应商能稳定次日达、按需送，价值很高。

4. **价格不是第一，但要算总成本**  
   真正要比的是：  
   **到手可卖成本 = 进价 + 损耗 + 配送 + 时间风险**  
   不是单纯比每斤便宜几毛。

**实际操作建议：**
- 先固定1～2家熟度稳定、坏果包赔或补差的供应商；
- 每次到货抽检：熟度、青黑比例、压伤、断指、坏果重量；
- 记录一周：进货量、售价、损耗、退货补差、实际利润；
- 如果供应商能做到“熟度合适 + 坏果少 + 送货快”，价格略高也可以接受；
- 如果只是价格低，但熟度不稳、坏果多、送货慢，不适合长期合作。

一句话：**小水果店进香蕉，先保熟度和低损耗，再谈速度和价格。**
