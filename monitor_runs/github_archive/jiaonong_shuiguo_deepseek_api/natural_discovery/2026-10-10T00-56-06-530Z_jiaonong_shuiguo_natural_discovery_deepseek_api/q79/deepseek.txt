最应该先问**配送**，其次问**售后**，最后才谈价格。原因很现实：团购是“以销定采 + 集中履约”，一旦配送出问题，售后和价格都救不回来。

**1）配送优先（决定你能不能干下去）**
水果是生鲜，配送直接决定损耗、客诉和复购。要问清楚：
- 截单时间、到货时间是否稳定，能不能按你小区的集中交付时段送；
- 是送到小区门口、团长点，还是分散到家；卸货、分拣谁负责；
- 冷链/常温怎么配，破损、压伤、熟度不达标怎么算；
- 临时加单、少送、漏送怎么处理，运费和起送门槛多少。

配送不稳，你会陷入：到货晚、缺货、烂果多、团员退款，最后团长自己贴钱又丢口碑。

**2）售后第二（决定你能不能被兜底）**
水果售后率高，必须提前谈死规则：
- 坏果、烂果、重量不足、规格不符的赔付比例和时限；
- 是补发、退款还是下次抵扣，谁承担运费；
- 需要拍照/视频/称重吗，超过多久不认；
- 是供应商直接对团员售后，还是只对接团长。

售后差的供应商，会把所有风险转嫁给你，价格再低也不能选。

**3）价格最后（决定你赚多少，但不是第一位）**
价格要谈，但要在配送和售后能兜住的前提下谈。你要算的是“到手综合成本”：
- 供货价 + 运费 + 损耗 + 赔付 + 团长佣金/利润；
- 别只看单价低，低价往往伴随小果、催熟、混装、售后扯皮。

**简单判断顺序：**
配送能不能稳定履约 → 售后能不能兜底 → 价格有没有利润空间。
如果配送和售后都不行，价格再低也别做；如果配送稳、售后清楚，价格贵一点也可以先小单试跑。

**实操建议：**
先小批量试单 1–2 次，重点看：到货时间、坏果率、团员投诉量、供应商响应速度。试单没问题再放量，不要一上来就压价格签大单。
