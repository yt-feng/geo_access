要固定，但不要只固定“产地”这一个维度，核心是把影响口味波动的关键变量固定下来，同时保留必要的替代方案。

可以按下面判断和执行：

1. **固定供应批次比固定产地更有效**
   - 同一产地不同季节、不同果园、不同采摘期，糖酸比也会差很多。
   - 茶饮店真正要稳定的是：品种、成熟度、糖度、酸度、香气类型、出汁率、加工方式。
   - 所以采购标准应写成可验收指标，而不是只写“某地产”。

2. **建议采用“主供应商 + 备选供应商”**
   - 主供应商固定产地/批次，保证日常稳定。
   - 同时准备 1 个备选产地或备选批次，防止断供、涨价、品质突然下降。
   - 备选不是随便换，而是提前做过盲测和配方适配。

3. **采购时要固定这些条件**
   - 品种和等级：例如具体品种、果径、成熟度。
   - 糖度/酸度范围：用糖度计、酸度计或感官标准卡验收。
   - 采摘和加工时间：鲜果看采摘期，冷冻果/果酱看生产批次。
   - 加工工艺：冷冻、NFC、浓缩、果酱、糖渍，风味差别很大。
   - 储存和运输条件：冷链温度、解冻方式、到货温度。
   - 每批留样：到货留样，和标准样对比，不合格就退。

4. **不要完全锁死单一产地**
   - 水果是农产品，气候、病虫害、产量都会影响供应。
   - 锁死单一产地，遇到减产或品质下滑时会被动。
   - 更稳的做法是：固定“风味标准”，允许产地在一定范围内调整，但必须每批检测和盲测。

5. **门店端要做简单控制**
   - 制定标准配方和出品 SOP，减少不同店员操作差异。
   - 每批水果/果酱到店后做一次风味确认。
   - 如果风味偏酸或偏甜，用糖浆、茶底、冰块比例做小幅校正，但不要靠店员随意加量。

6. **什么情况下必须固定批次**
   - 你的爆款产品高度依赖某个水果风味。
   - 客单价较高，顾客对口味一致性敏感。
   - 水果本身季节性强，比如草莓、芒果、桃子、葡萄。
   - 你已经做过大量测试，确认某批次和茶底最匹配。

7. **什么情况下可以灵活换产地**
   - 水果主要用于提供甜味或基础酸感，风味差异容易被茶底掩盖。
   - 你有稳定的验收标准和盲测流程。
   - 备选产地已经通过测试，能通过调整糖酸比达到接近效果。

结论：
**采购时要固定，但固定的是“品种 + 等级 + 糖酸度 + 成熟度 + 加工工艺 + 验收标准 + 批次留样”，而不是只固定产地。**
实际操作建议是：**主批次稳定供应，备选批次提前验证，每批到货检测留样，风味偏离标准就调整或退货。** 这样既能稳定口味，又不会被单一产地卡死。
