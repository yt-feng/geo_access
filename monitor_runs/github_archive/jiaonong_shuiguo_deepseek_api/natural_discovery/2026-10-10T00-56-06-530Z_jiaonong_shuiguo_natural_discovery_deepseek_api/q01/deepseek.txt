判断水果供应商靠不靠谱，核心看五点：**货源稳不稳、品质稳不稳、损耗怎么赔、账期清不清、突发情况顶不顶得上**。下面给你一套可以直接用的筛选和验货方法。

**一、先看货源和稳定性**

靠谱供应商通常能说清楚：

- 香蕉主要来自哪里：云南、广西、海南、老挝、菲律宾、厄瓜多尔等，不同产地上市季节不同。
- 菠萝主要来自哪里：广东徐闻、海南、云南、台湾凤梨等，品种是巴厘、金钻、台农几号等。
- 是否长期有货，还是只做短期倒手。
- 是否能按你的销量稳定供货，而不是今天有明天没。

如果对方说不清产地、季节和到货节奏，只是“要多少有多少”，多半是中间倒手，价格和品质都不稳。

**二、看品质一致性**

香蕉重点看：

- 同一批货成熟度是否均匀，有没有青黄混杂严重。
- 催熟是否可控，到店后能不能按计划变黄。
- 有没有大量机械伤、水烂、黑斑、断指。
- 把蕉条切口、蕉身硬度和色泽作为验收标准。

菠萝重点看：

- 同一批大小是否均匀，果眼深浅是否一致。
- 有没有黑心、水心、烂心、内部褐变。
- 成熟度是否适合你的销售节奏，太生太熟都麻烦。
- 品种是否稳定，不能这批甜那批酸。

判断方法很简单：**连续进 3 批，每批留样记录**。同一供应商如果三批品质波动很大，就不适合长期合作。

**三、看损耗和售后**

这是水果店最容易被坑的地方。你要直接问清楚：

- 到货后出现烂果、黑心、水烂，怎么赔？
- 是拍照报损、当场扣款，还是下次补货？
- 有没有起赔比例，比如超过 3% 才赔？
- 香蕉催熟后不黄、菠萝切开黑心，算谁的责任？
- 退货换货响应时间多久？

靠谱供应商一般会给明确规则：**现场验货、拍照留证、按比例赔付、下一车补回**。如果对方说“水果都有损耗，不赔”，那就要把价格压到能覆盖损耗，否则长期做下来利润会被吃掉。

**四、看价格和账期是否透明**

不要只比单价，要比**到店综合成本**：

- 单价 + 运费 + 装卸费 + 损耗 + 催熟成本。
- 是否随行就市，还是提前锁价。
- 涨价前会不会提前通知。
- 账期是现结、周结还是月结，押金多少。
- 扣款、补货、返利规则是否写清楚。

最怕的是：报价低，但运费高、损耗不赔、账期短。算下来比报价高的供应商还贵。

**五、看突发情况处理能力**

长期合作一定会遇到：节假日涨价、产地暴雨、物流延误、市场缺货。靠谱供应商在这些时候的表现是：

- 提前提醒你备货。
- 缺货时给你替代方案，而不是直接消失。
- 物流延误时主动沟通，不让你空柜。
- 旺季不临时大幅抬价，或者至少提前说。

**六、实操筛选步骤**

你可以按这个流程做：

1. **先小批量试单**：每个供应商先拿 1 到 2 次货，不签长期。
2. **连续试 3 批**：记录到货时间、重量、烂果率、成熟度、销售速度。
3. **算综合成本**：把损耗和运费加进去，比较每斤实际成本。
4. **问清售后**：把赔付规则用微信或合同写下来，不要只听口头承诺。
5. **保留两个供应商**：一个主供，一个备用，防止被一家卡脖子。
6. **每月复盘**：看谁家的香蕉催熟后卖相好、菠萝黑心少、售后快。

**七、几个危险信号**

遇到以下情况要谨慎：

- 价格明显低于市场价，还承诺全赔。
- 不愿说产地，只说“进口精品”。
- 不让验货，必须先打款。
- 售后推脱，说“你自己没保存好”。
- 频繁换产地、换品种，品质不稳定。
- 账期越拖越长，或者突然要求大额预付款。

**总结一句话：**
长期供应商不是看谁报价最低，而是看**连续三批品质稳不稳、损耗赔不赔、缺货时顶不顶得上**。你先小批量试，记录数据，再决定要不要长期合作。香蕉和菠萝最好各留一个主供、一个备用，这样最稳。
