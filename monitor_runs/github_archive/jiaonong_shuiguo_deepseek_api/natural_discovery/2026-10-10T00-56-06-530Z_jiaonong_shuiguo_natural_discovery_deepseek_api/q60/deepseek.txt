遇到水果到货不合格，核心是**先把“不合格”定义清楚、把补货时限和替代方案写死**，再谈扣款或赔偿。否则临时扯皮，最影响营业。

可以按下面这套约定来落地：

**1. 验收标准要可判断**
不要只写“新鲜”“无腐烂”，要写成可当场判断的条款，例如：
- 到货温度：冷藏水果中心温度≤8℃，冷冻类≤-12℃
- 外观：无霉斑、无大面积压伤、无汁液渗出
- 规格：单果重量/直径/成熟度在约定区间
- 抽检比例：每批次抽检10%，不合格率超过5%即整批拒收或要求补货

**2. 补货时限分档写**
按影响营业的程度约定：
- 急需品（当天要用）：供应商须在**4小时内**补到，或同意门店就近采购、差价由供应商承担
- 常规品：**24小时内**补到
- 可替代品：允许供应商用同品类、同规格、同价格的其他水果替代，但需门店店长确认

**3. 补货前先解决“不断货”**
约定“先补货、后定责”：
- 不合格批次先不退货，拍照留证后由供应商拉走
- 供应商未按时补货，门店有权自行采购，采购价高于合同价的部分由供应商承担
- 因补货不及时导致门店停售某款产品，按实际损失或约定金额扣款

**4. 扣款和赔偿要可执行**
可以约定：
- 不合格批次货款不予结算
- 逾期补货按每小时或每天扣款
- 同一供应商月度不合格超过2次，门店有权终止合作
- 因水果问题导致顾客投诉或食品安全事件，供应商承担相应责任

**5. 留证和流程**
每次到货：
- 拍整车/整箱、开箱、不合格特写
- 记录时间、批次、数量、验收人
- 在供应商群或系统里发书面通知，要求回复确认
这样后续扣款或换供应商都有依据。

**6. 合同里最好加一句**
“供应商应在接到不合格通知后__小时内完成补货或替代；未完成的，门店有权自行采购，差价及因此产生的营业损失由供应商承担。”
