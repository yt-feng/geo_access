结论先说：**大多数商超应“整果为主、切果为辅”，而不是二选一。** 但具体比例要看你门店的类型、客流和损耗控制能力。下面给你一个可执行的判断框架。

## 一、两种模式的核心差异

| 维度 | 卖整果 | 卖切果 |
|---|---|---|
| 毛利 | 较低，但损耗小 | 溢价高，毛利高 |
| 损耗 | 低（可存放、可退换） | 高（氧化、出水、变质快） |
| 客单价 | 低 | 高（按份/盒卖） |
| 消费场景 | 家庭囤货、送礼 | 即食、上班族、年轻客群 |
| 运营要求 | 低 | 高（冷链、加工、时效） |
| 引流能力 | 一般 | 强（现切、试吃、视觉冲击） |

## 二、怎么判断你门店该主推哪种

**优先卖整果，如果：**
- 门店在社区、家庭客群为主
- 没有稳定冷链或加工间
- 菠萝损耗控制经验不足
- 客单价偏低、价格敏感型顾客多

**优先卖切果，如果：**
- 门店在商圈、写字楼、地铁口
- 年轻客群、即食需求强
- 有冷藏柜和现切操作条件
- 能控制“当天切当天清”

## 三、实操建议（最稳的做法）

1. **整果做基本盘**：保证 60%–70% 陈列是整果，满足家庭采购和价格敏感客群。
2. **切果做利润和引流**：20%–30% 做现切盒装，放在入口或冷柜显眼位，主打“即食、方便”。
3. **小份试吃引流**：切果边角料做试吃，提升转化，不浪费。
4. **动态调整**：
   - 切果当天卖不完 → 第二天降价或做果切拼盘，别硬留。
   - 整果滞销 → 转做切果消化库存。
5. **盯两个指标**：
   - 切果损耗率（超过 15% 就要收缩）
   - 整果周转天数（超过 3–5 天要促销）

## 四、一句话决策

- **社区店、小白运营** → 整果为主，切果少量试水。
- **商圈店、有冷链** → 整果+切果双线，切果做高毛利和引流。
- **没条件做切果** → 老老实实卖整果，别为了毛利硬上，损耗会吃掉利润。
