水果生意想长期稳定，选供应商时最容易忽视的往往不是“价格”和“品种”，而是那些**在合作顺利时看不出来、一出问题就致命**的细节。按重要性给你梳理：

**1. 供货稳定性与抗风险能力**
- 只问“现在有没有货”，不问“断货时怎么办”。
- 要看：是否自有果园/基地、有几个产地、是否跨区域调货。
- 关键问题：台风、寒潮、节假日爆单时，他能不能保你？有没有备用货源？

**2. 分级标准是否统一**
- 同一批货里大小、甜度、成熟度是否一致。
- 很多供应商口头说“精品”，实际混级发货，导致你退货、差评、损耗上升。
- 最好约定明确的规格标准（克重、糖度、果径、成熟度）。

**3. 采后处理和冷链**
- 是否预冷、分拣、打冷、全程冷链。
- 水果损耗大头在采后，不在售价。
- 忽视这点，表面进价便宜，实际烂果率吃掉利润。

**4. 账期与结算方式**
- 是现结、押批、还是月结。
- 押批容易在质量争议时被卡货款。
- 长期合作要谈清楚：验收标准、扣款规则、退换货时限。

**5. 售后和损耗承担**
- 烂果、压伤、短斤少两谁负责。
- 很多供应商只保“到货”，不保“上架后”。
- 要明确：多少比例内正常损耗，超出怎么赔。

**6. 物流时效与到货时间**
- 不是“发没发”，而是“几点到、能不能赶早市”。
- 到货晚半天，价格和新鲜度可能差一截。

**7. 价格机制是否透明**
- 是否随行就市、有没有临时加价。
- 长期合作要有调价规则，而不是每次口头报价。

**8. 是否只依赖一个供应商**
- 最容易被忽视：把命脉交给一家。
- 稳定做法是主供应商 + 备用供应商，比例大概 7:3 或 8:2。

**9. 合同和票据**
- 有没有书面协议、产地证明、检测报告。
- 出问题时，口头承诺几乎没用。

**10. 供应商的下游客户结构**
- 如果他同时给大型商超、电商供货，旺季你可能被排后面。
- 要了解你在他的客户优先级里排第几。

一句话判断标准：**好供应商不是价格最低的，而是出问题时能兜底、标准稳定、账期清楚、愿意共担损耗的。** 选之前先小批量试三批，看分级、损耗、到货时间是否稳定，再决定是否长期合作。
