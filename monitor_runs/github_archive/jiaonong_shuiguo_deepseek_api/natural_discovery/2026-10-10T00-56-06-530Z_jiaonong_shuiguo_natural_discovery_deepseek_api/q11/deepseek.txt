会影响销售，但“大小不一样”本身不是致命问题，关键看**差多大、你怎么卖、卖给谁**。

**结论先说：**
- 如果只是轻微大小差异，正常，靠分级销售能消化。
- 如果大小差很明显，比如一根特别粗大、一根很细小，**会影响卖相、定价和顾客挑拣**，损耗和投诉会变多。
- 水果店采购香蕉，最怕的不是“有大小”，而是**同一箱里大小混乱、成熟度还不一致**，这会让顾客觉得你不专业、像尾货。

**具体影响：**
1. **卖相变差**  
   顾客买香蕉很多时候是看整体，一把蕉大小均匀，显得新鲜、品质稳定。大小乱，顾客会觉得是拼箱或次果。

2. **定价困难**  
   大的、小的如果混在一起，按同一价格卖，顾客会专挑大的，小的剩下；分开卖，又增加分拣人工。

3. **挑拣损耗增加**  
   顾客翻来翻去，容易把香蕉碰伤、掉把、断果，最后小的、伤的只能降价或报损。

4. **影响复购和口碑**  
   如果顾客买回去发现“上面大下面小”或者同一把蕉差很多，会觉得被坑，尤其做社区熟客生意时更伤。

5. **不一定全是坏事**  
   有些顾客专门买小香蕉，觉得一次吃一根刚好；也有顾客要大香蕉，觉得划算。大小差异如果稳定，反而可以做“大小果分级卖”。

**建议你这样做：**
- **采购时先定标准**：同一箱香蕉，单根粗细、长度不要差得太离谱，成熟度尽量一致。
- **到店后分级**：大果、中果、小果分开，按不同价格或不同用途卖。大的按斤卖，小的可以做促销装、儿童装。
- **混装要谨慎**：如果一定要混卖，尽量按“把”卖，不要散卖让顾客自己挑，减少翻拣。
- **看客户群**：社区店、水果摊对均匀度要求高；做果汁、烘焙、食堂供货，大小差异影响小很多。
- **算损耗账**：如果一箱里小果、次果比例超过你能接受的范围，比如超过两三成，就要考虑压价采购或换供应商。

**一句话：**
轻微大小差异可以靠分级销售解决；差异明显又混在一起卖，一定会影响销售。采购时宁可少赚一点，也要拿大小和成熟度相对均匀的货。
