超市水果到货后发现品相不好，售后流程要在采购/供货合同或订货单里提前写清楚，核心是：**验收标准、反馈时限、举证方式、处理方式、费用承担、责任边界**。可以按下面条款来约定。

## 一、先约定“品相不好”的判断标准

不要只写“品相好”“新鲜”，要量化，否则容易扯皮。建议写：

1. **外观标准**  
   - 无明显腐烂、霉变、虫蛀、异味；
   - 无明显压伤、裂口、冻伤、烫伤；
   - 果形、大小、颜色符合约定等级或样品；
   - 允许的瑕疵比例，例如：单项瑕疵率不超过 3%—5%，严重瑕疵不超过 1%。

2. **成熟度标准**  
   - 按品种约定，如“到货成熟度 7—8 成”“可即时销售或 1—2 天内可售”。

3. **规格标准**  
   - 单果重量/直径/个数/箱规；
   - 等级如特级、一级、二级；
   - 是否允许混级，混级比例多少。

4. **以样品或图片为准**  
   - 首次合作可封存样品，或双方确认标准图片；
   - 后续到货与样品/图片对比。

## 二、约定验收和反馈时限

水果易腐，时限要短、要明确。

建议约定：

1. **到货当场验收**  
   - 司机在场时，超市/收货方应在 **30—60 分钟内**完成抽检；
   - 抽检比例可约定：每批次抽 5%—10%，大货批次不少于若干箱。

2. **隐蔽瑕疵反馈时限**  
   - 外观问题：到货后 **2—4 小时内**反馈；
   - 开箱后内部腐烂、冻伤等：到货后 **12—24 小时内**反馈；
   - 超过时限未反馈，视为验收合格，但供应商故意隐瞒或存在重大质量问题的除外。

3. **反馈方式**  
   - 必须通过书面方式：微信、邮件、系统工单、书面通知均可；
   - 内容包含：批次号、到货时间、品种、数量、问题描述、照片/视频、抽检结果。

## 三、约定举证方式

水果售后最容易争议的是“是不是你存放不当导致的”。所以要约定：

1. **到货拍照/视频**  
   - 外包装、车牌/送货单、开箱过程、问题果品、抽检整体情况；
   - 照片要能看清批次、时间、数量。

2. **保留实物或样品**  
   - 争议批次保留部分问题样品，冷藏封存；
   - 双方可约定第三方检测，费用由责任方承担。

3. **送货单签收备注**  
   - 签收时备注“外观异常，待开箱细验”；
   - 不要直接签“完好无损”，否则后续维权困难。

## 四、约定处理方式

可按问题严重程度分档：

| 问题程度 | 处理方式 |
|---|---|
| 轻微瑕疵，不影响销售 | 折价接收，按比例扣款 |
| 部分不合格 | 退货、换货或补发 |
| 严重不合格，如腐烂、异味 | 整批拒收或退货退款 |
| 多次出现 | 扣保证金、暂停合作、终止合同 |

建议写明：

1. **退货/换货**  
   - 供应商应在收到通知后 **24—48 小时内**补发或换货；
   - 换货后仍不合格，超市有权拒收并要求退款。

2. **折价扣款**  
   - 按不合格数量 × 单价 × 折扣比例扣款；
   - 或按整批比例扣款，例如不合格率 10%，扣款 10%—20%。

3. **退款**  
   - 已付款的，供应商应在 **3—7 个工作日**内退回；
   - 未付款的，从货款中直接扣除。

4. **损失赔偿**  
   - 因质量问题导致超市无法销售、被顾客投诉、被监管处罚的，供应商承担相应损失；
   - 可约定违约金，如该批次货款的 10%—30%。

## 五、约定费用和责任承担

1. **运输费、装卸费**  
   - 因供应商质量问题退货的，来回运费由供应商承担；
   - 因超市验收不及时或存放不当导致的，由超市承担。

2. **损耗承担**  
   - 到货前损耗由供应商承担；
   - 到货验收合格后，因超市保管不当产生的损耗由超市承担。

3. **责任倒置情形**  
   - 超市未按约定温度、湿度存放；
   - 未在规定时限内反馈；
   - 已签收且无备注，事后才提出外观问题；
   - 这些情况下供应商可拒绝或减轻责任。

## 六、建议写进合同或订单的简洁条款模板

可以这样约定：

> 1. 水果到货后，买方应在司机在场时 60 分钟内完成抽检，抽检比例不低于 5%。外观、规格、成熟度以双方确认的样品/图片及本合同标准为准。  
> 2. 外观问题应在到货后 4 小时内书面反馈；内部腐烂、冻伤等隐蔽问题应在 24 小时内书面反馈，并提供照片、视频及保留样品。逾期未反馈视为验收合格。  
> 3. 经确认属卖方质量问题的，买方可选择折价接收、退货、换货或退款。轻微瑕疵按不合格数量折价扣款；严重腐烂、异味、霉变的，买方有权整批拒收。  
> 4. 因卖方质量问题产生的退换货运输费、装卸费、检测费由卖方承担；卖方应在收到通知后 48 小时内补发或退款，逾期按该批次货款的 0.5%/日支付违约金。  
> 5. 因买方未按约定条件存放、未及时验收或反馈导致的损失，卖方不承担责任。

## 七、实操建议

1. **不要口头约定**，至少用微信文字、订货单备注、合同附件确认。  
2. **每次到货都留证**：送货单、车牌、开箱视频、抽检照片。  
3. **设置验收责任人**，避免“谁都能签收、谁都不负责”。  
4. **首次合作压一批质保金**，或约定月结扣款机制。  
5. **问题频发就书面整改**，连续 2—3 次不合格可暂停供货。

总结一句话：  
**把“什么算品相不好、多久内反馈、怎么举证、怎么赔、谁出运费”写清楚，水果售后就不会全靠扯皮。**
