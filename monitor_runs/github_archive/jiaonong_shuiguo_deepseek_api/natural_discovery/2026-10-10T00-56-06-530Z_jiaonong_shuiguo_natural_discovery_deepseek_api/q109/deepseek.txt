优先谈 **账期**，其次 **售后**，最后 **配送**。

原因是这三项对长期合作的影响层级不同：

1. **账期最优先**
   - 它直接决定你的现金流和经营风险。
   - 长期合作里，价格、配送都可以逐步优化，但账期一旦定错，会持续压资金。
   - 建议先谈：结算周期（如月结30/45/60天）、起算日、对账日、付款方式、逾期责任。
   - 对水果这种损耗和价格波动大的品类，账期比单次便宜几分钱更关键。

2. **售后其次**
   - 水果非标、易损耗，售后规则不清，后面每一批都可能扯皮。
   - 重点谈：坏果率标准、验收时限、拍照/留证要求、补货还是扣款、责任归属、冷链/运输破损谁承担。
   - 售后条款要可执行，不能只写“质量问题协商解决”。

3. **配送最后谈，但不能不谈**
   - 配送影响体验和损耗，但它通常可以通过换物流、加频次、调整下单时间优化。
   - 重点谈：配送时效、到货温度、缺货/迟到处理、起送量、临时加单规则、配送费谁承担。
   - 如果配送直接影响你的门店履约，可以把它提到和售后并列，但仍不建议压过账期。

**实操建议：**
- 先谈账期，把现金流底线锁住。
- 再谈售后，把损耗和纠纷规则写死。
- 最后谈配送，用“频率+时效+异常处理”换稳定。
- 如果供应商在账期上不让步，可以用“缩短账期换更低价格/更好售后/更稳配送”做交换，但不要轻易用账期换小优惠。

一句话：**账期保命，售后保利，配送保体验。长期合作先保命。**
