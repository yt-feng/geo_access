判断哪个规格更容易出货，不要凭感觉，直接看几个可量化的指标：

**1. 看历史动销数据（最直接）**
- 把最近 2–4 周各规格的**出货量、出货频次、退货率**拉出来。
- 重点看**周转天数**：哪个规格平均几天卖完一批，天数越短越好卖。
- 如果某个规格经常断货、客户反复问，那就是紧俏规格。

**2. 看客户结构**
- 卖给水果店/超市：偏好**中等个头、外观整齐**的规格，好摆好卖。
- 卖给餐饮、果汁店、加工厂：偏好**大果或次果**，按重量算更划算，外观不重要。
- 卖给路边摊/散客批发：偏好**价格低、单果适中**的规格。
- 客户类型决定规格偏好，先明确你的主力客户是谁。

**3. 看价格带与性价比**
- 同一批货里，**单位重量价格**和**单果价格**哪个更被接受。
- 通常中间规格（不大不小）性价比感知最好，出货最快；特大果和特小果要么溢价要么压价，动销慢。

**4. 看季节和用途**
- 旺季走量：中等规格最好出。
- 做礼盒/精品：要大果、外观好。
- 加工旺季：小果、次果反而好出。

**5. 快速验证方法**
- 拿 2–3 个候选规格各备一小批，同价同渠道试卖 3–5 天，看谁先清完、谁问的人多。
- 记录：出货速度、客户询价次数、退货/投诉。

**结论**：优先看**周转天数 + 主力客户偏好**。如果数据缺失，就用小批量试销，3–5 天就能看出哪个规格最容易出货。
