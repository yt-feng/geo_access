想避免买到太生或太熟的香蕉，核心是按“计划吃的时间”挑成熟度，而不是只看黄不黄。

**到店怎么挑：**
- **想当天/1天内吃**：选通体黄色、带少量褐色糖斑的。糖斑说明已经熟到位，甜度高。
- **想2–3天内吃完**：选黄色为主、两端还略绿或柄部偏青的。回家放室温会继续熟。
- **想放4天以上**：选青黄相间、整体偏硬、没有黑斑的。越青放得越久。
- **不要买**：表皮发黑发软、柄部发霉、一按一个坑的，基本已经过熟或开始坏。

**现场判断技巧：**
- 轻捏中间：太硬=生；微软有弹性=刚好；很软=熟过头。
- 看柄部：柄部青绿说明刚摘不久，能再放；柄部发黑发软说明老了。
- 看棱角：棱角明显、圆润度低=偏生；棱角不明显、果身饱满=偏熟。
- 整串比单根更耐放，单根通常已经熟得比较快。

**买回家后怎么控熟：**
- 想加快熟：和苹果/香蕉放同一个纸袋，室温催熟。
- 想减慢熟：成熟后放冰箱冷藏。冷藏会让皮变黑，但果肉还能多撑几天。
- 已经熟透吃不完：剥皮切段冷冻，做奶昔或香蕉面包。

**最稳的买法：**
如果家里每天吃，买“黄中带一点青”的整串；如果只想买几根当天吃，就挑“黄带糖斑”的。不要一次全买同一种熟度。
