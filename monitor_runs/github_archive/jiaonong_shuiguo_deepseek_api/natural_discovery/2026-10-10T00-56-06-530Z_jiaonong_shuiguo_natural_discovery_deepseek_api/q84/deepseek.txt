做家庭水果礼盒，组合原则是：**好吃、耐放、颜色好看、成本别太高**。苹果、橙子、香蕉、菠萝里，最适合当“家庭装主力”的是苹果和橙子，香蕉负责香气和即食，菠萝负责撑场面和特色。

比较推荐这几种组合：

**1. 均衡实惠型：苹果 + 橙子 + 香蕉**
- 比例：苹果 40%、橙子 40%、香蕉 20%
- 适合：普通家庭日常吃、走量团购
- 优点：成本低、接受度高、颜色也好看
- 注意：香蕉容易熟，最好单独用袋装或加缓冲，别压在最底下

**2. 好看送礼型：苹果 + 橙子 + 菠萝**
- 比例：苹果 35%、橙子 35%、菠萝 30%
- 适合：节日团购、送长辈、家庭囤货
- 优点：耐放、体面、颜色金黄红橙很喜庆
- 注意：菠萝带皮重、占体积，礼盒要大一点，最好配开果器或说明

**3. 即食丰富型：苹果 + 橙子 + 香蕉 + 菠萝**
- 比例：苹果 30%、橙子 30%、香蕉 20%、菠萝 20%
- 适合：家庭人数多、想一次吃到多种水果
- 优点：层次丰富，有即食香蕉，也有耐放的苹果橙子
- 注意：香蕉和菠萝都怕压，包装要分层；菠萝最好选小果或已削皮盒装

**不太建议的组合：**
- 香蕉 + 菠萝为主：都怕压、成熟快，家庭团购损耗高
- 苹果 + 香蕉为主：颜色偏单调，橙子缺席会少一点清爽感
- 菠萝占比太高：重量大、处理麻烦，很多家庭嫌费事

**如果只选一个最稳的家庭团购方案：**
> **苹果 4 个 + 橙子 4 个 + 香蕉 1 把 + 小菠萝 1 个**
> 或按重量：苹果 1kg、橙子 1kg、香蕉 0.8kg、菠萝 1 个。

这个组合的好处是：苹果橙子耐放，香蕉当天就能吃，菠萝有节庆感；家庭收到后不会觉得全是便宜货，也不会因为熟得太快烂掉。

包装上建议：
- 苹果、橙子放底层
- 菠萝单独一侧
- 香蕉放最上层，最好用纸袋或气泡膜隔开
- 盒内加一张食用顺序卡：先吃香蕉，再吃菠萝，苹果橙子可存放

如果是做团购，还可以分两档：
- **实惠档**：苹果 + 橙子 + 香蕉
- **升级档**：苹果 + 橙子 + 菠萝，或四样全配

这样家庭客户更容易按预算选择。
