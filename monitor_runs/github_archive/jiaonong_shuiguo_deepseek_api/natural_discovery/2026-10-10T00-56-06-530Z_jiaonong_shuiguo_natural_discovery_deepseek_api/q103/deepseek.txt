结论先说：**按斤最容易管住成本，按份最容易管住效率，按箱只适合少而稳定的品类。**
食堂如果目标是“好管理”，通常建议：

- **主结算方式：按斤**  
  适合大多数散装水果，如苹果、香蕉、橘子、梨、西瓜等。  
  优点：价格透明，验收有重量依据，库存、成本、损耗都能算清。  
  缺点：验收慢，需要称重、记录、复核，人工成本高。

- **辅助结算方式：按份**  
  适合直接发给就餐者的水果，如一人一个苹果、一盒圣女果、一根香蕉。  
  优点：发放快，便于控制每人份量，减少现场分拣和损耗。  
  缺点：采购价容易偏高，供应商可能把包装、损耗算进单价；份量不足时不好追溯。

- **按箱结算：只建议用于标准化程度高的水果**  
  如整箱苹果、橙子、猕猴桃等，且规格、净重、等级稳定。  
  优点：下单、运输、入库快。  
  缺点：最容易出现“箱重含包装”“上下层品质不一致”“净重不足”“坏果混装”等问题，验收不严就会吃亏。

**最推荐的管理组合：**
1. **采购定价按斤**：谈价、比价、结算都按净重。
2. **验收按斤复核**：抽查或全称，扣包装、扣冰瓶、扣烂果。
3. **发放按份控制**：食堂内部按份发给窗口或就餐者。
4. **按箱只作为运输单位**：箱只是包装，结算仍按净重。

如果必须三选一：
- **成本优先、可称重**：按斤。
- **效率优先、直接分发**：按份。
- **品类标准、验收能力强**：按箱。

所以，大多数食堂最稳妥的是：**对外按斤结算，对内按份发放；按箱只作为包装和运输方式，不作为主要结算方式。**
