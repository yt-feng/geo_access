超市采购水果时，通常需要供应商提供以下几类检测报告或进货证明，具体取决于超市的内部审核要求和当地监管规定：

**一、主体资质类**
1. **营业执照**：供应商合法经营的基本证明。
2. **食品经营许可证**（或食品生产许可证）：销售食品的必备资质。
3. **若为进口水果**：还需提供进出口经营权相关资质。

**二、进货来源证明**
1. **供货凭证/采购合同**：证明水果来源合法、可追溯。
2. **产地证明**：部分超市要求提供，尤其对地理标志产品或特定产区水果。
3. **上游供应商资质**：如果供应商本身是二级批发商，需提供其上游的资质和进货凭证，形成完整追溯链。

**三、检测报告类**
1. **农药残留检测报告**：最核心的一项。可以是供应商自检报告，也可以是第三方检测机构出具的报告，通常要求近期（如半年内或每批次）有效。
2. **重金属检测报告**：针对铅、镉、汞、砷等指标，视水果种类和产地风险而定。
3. **食品添加剂/保鲜剂检测**：如防腐剂、打蜡剂等，部分超市会要求。
4. **微生物检测报告**：一般鲜果较少要求，但切果或预包装水果可能涉及。
5. **快速检测合格证明**：部分超市接受供应商提供的农残快检结果。

**四、批次相关证明**
1. **批次检测报告/合格证**：每批次到货对应一份，确保可追溯。
2. **入境货物检验检疫证明**：进口水果必须提供，由海关出具。

**五、其他可能要求的文件**
1. **承诺书/质量保证书**：供应商对产品质量安全的书面承诺。
2. **无公害/绿色/有机认证**：如超市定位高端或有机专区，会要求相应认证证书。
3. **追溯码或追溯凭证**：部分地区推行食用农产品追溯，需提供追溯信息。

**实操建议**
- 不同超市要求差异较大：大型连锁超市（如永辉、沃尔玛）审核较严，通常要求第三方检测报告；小型超市可能只要求营业执照和进货凭证。
- 建议供应商提前准备一份**资质文件包**，包含上述核心文件，并根据超市要求补充批次报告。
- 检测报告需注意**有效期**和**检测项目是否覆盖**超市要求的指标，避免因报告过期或项目不全被拒收。
- 若超市有线上供应商系统，通常需在系统中上传并维护这些文件的电子版。
