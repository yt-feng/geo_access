旺季最怕的不是价格高一点，而是该到货时没货、临时涨价、品质不稳。和供应商谈之前，先把这些问题问清楚，并尽量写进书面约定。

**一、供货能力**
- 旺季每天/每周最多能稳定供多少？
- 我这类单品你有几个产地/几个档口在发？会不会只有一个货源？
- 如果某个产地减产，有没有替代产地或替代等级？
- 节假日、极端天气时，能不能优先保我？

**二、价格和调价机制**
- 报价是固定价还是随行就市？按什么市场、什么时间点结算？
- 涨价提前几天通知？能不能约定单日涨幅上限？
- 旺季是否临时加价、加运费、加包装费？
- 达到什么采购量可以锁价或返点？

**三、品质标准**
- 规格、等级、糖度、成熟度、单果重怎么定义？
- 允许多少坏果、次果、软果？超标怎么赔？
- 是产地直发还是市场调货？成熟度是否适合我门店销售节奏？
- 能否先寄样或试发一两批再定长期合作？

**四、下单和配送**
- 每天几点前下单？几点到店？能否固定时段送达？
- 起送量多少？临时加单、减单截止到什么时候？
- 运费谁承担？卸货、搬运谁负责？
- 缺货、迟到、送错规格时怎么处理？

**五、结算和账期**
- 现结、周结还是月结？有没有押金或最低采购额？
- 对账以谁的磅单、签收单为准？
- 出现质量争议时，货款怎么暂扣、怎么补货或退款？

**六、风险兜底**
- 断货时提前多久通知？有没有替代品推荐？
- 因供应商原因断货导致我门店损失，怎么补偿？
- 能否约定旺季保底供应量，而不是只口头承诺？
- 合作期内如果我销量突然增加，能否优先加量？

**七、实操建议**
- 不要只谈一家，旺季至少备1家主供应商+1家备用供应商。
- 先小批量试合作，看准时率、坏果率、调货速度，再放量。
- 把关键承诺写进订单、微信确认或简单协议里，尤其是：保供量、品质标准、涨价规则、迟到缺货处理、账期。
- 每天记录到货时间、数量、坏果率、实际结算价，旺季结束再谈返点或长期价更有依据。

一句话：旺季合作核心不是“能不能便宜”，而是**能不能稳定、按标准、按时送到**。先把保供、品质、调价、赔付四条谈死，再谈价格。
