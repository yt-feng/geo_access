选批量配送的水果供应商，关键不是找“最便宜”，而是找**能稳定交付、损耗可控、售后可追责**的。可以按下面几步判断和筛选。

**1. 先明确自己的需求参数**
先定清楚这几项，再去问供应商，效率会高很多：
- **人数和份量**：按多少人、每人多少克/份，还是按整箱切果盘。
- **配送时间**：下午茶通常要求固定时间送到，比如 14:30 前，迟到会影响体验。
- **配送地点**：写字楼是否允许送货上楼、有无卸货区、是否要提前报备。
- **预算区间**：按人均 5 元、10 元、20 元，选品和供应商类型差别很大。
- **水果形式**：整果、切果、果切拼盘、独立包装，对供应商要求不同。
- **频次**：单次还是每周固定几次，频次越高越要签稳定供应。

**2. 优先看这几类供应商**
- **本地水果批发商/农批市场商户**：适合量大、预算有限，但配送和售后不稳定，最好找有固定配送能力的。
- **生鲜配送平台/企业团餐供应商**：适合公司批量采购，通常能开发票、固定时段配送，售后相对规范。
- **连锁水果店/品牌水果店**：适合中小批量、品质稳定，但单价偏高，大单可能需要提前预订。
- **专业果切/下午茶供应商**：适合直接要果切拼盘，省事，但要注意冷链和卫生资质。
- **企业福利/团购平台**：适合标准化套餐，价格透明，但灵活度低。

**3. 重点核验这几个硬指标**
- **是否有稳定货源**：问清楚主要水果来自哪里，是否当天采购，缺货时怎么替代。
- **配送能力**：自有车辆还是外包，能否固定时间送达，迟到怎么处理。
- **损耗和售后**：坏果、压伤、不熟、少送怎么赔，是否支持拍照后补送或退款。
- **资质和卫生**：尤其果切类，要看营业执照、食品经营许可证、冷链条件。
- **报价是否含税含运**：很多低价是不含运费、不含切配、不含包装的，要问总价。
- **结算方式**：月结、对公转账、发票类型，能不能开专票。

**4. 建议的筛选流程**
1. 先找 3—5 家本地供应商，要求按同一标准报价。
2. 让对方提供：品种、规格、单价、配送时间、售后规则、发票信息。
3. 先小批量试单一次，重点看准时率、新鲜度、包装、实际份量。
4. 试单没问题再签短期合作，比如先签 1 个月，稳定后再长期。
5. 保留每次配送和售后记录，方便后续换供应商或谈价。

**5. 避坑提醒**
- 不要只看单价低，要算**到货可食用部分**的成本。
- 不要选无法固定时间配送的，下午茶最怕迟到。
- 不要选售后模糊的，坏果不赔最后全是公司承担。
- 果切类不要选无冷链、无资质的，食品安全风险高。
- 大单不要只找一家，最好有备用供应商。

**简单判断标准：**
能固定时间送到、坏果能赔、报价含运含税、试单品质稳定，这四条满足，基本就可以作为批量配送供应商。
