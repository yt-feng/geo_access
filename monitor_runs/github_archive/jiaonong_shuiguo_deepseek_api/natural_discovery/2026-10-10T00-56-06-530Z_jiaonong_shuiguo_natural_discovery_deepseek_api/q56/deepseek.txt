茶饮店使用水果，核心要控三类风险：**农残/重金属等化学污染、腐烂霉变等生物污染、非法添加或来源不明**。供应商通常需要提供以下证明，按优先级和用途分：

**一、必备基础证照**
1. **营业执照**：经营范围应包含水果种植/销售/农产品购销等。
2. **食品经营许可证或食品生产许可证**：如果供应的是预包装果浆、冷冻果肉、果干等加工品，需要食品生产/经营许可；如果是鲜果初级农产品，通常按农产品管理，不一定需要食品经营许可，但要有合法经营资质。
3. **法定代表人/负责人身份证复印件**：用于建档和追溯。

**二、每批次必须随货提供的证明**
4. **农产品承诺达标合格证**：鲜果类供应商最核心的证明，承诺农药残留等符合标准。散装鲜果应有这个证或同等合格证明。
5. **出厂检验报告/产品质量检验报告**：加工类水果制品（冷冻果肉、果浆、罐头、果干）每批应有出厂检验报告。
6. **送货单/销售凭证**：品名、规格、数量、批次、日期、供应商信息，用于追溯。

**三、定期提供的检测证明**
7. **第三方检测报告**：农残、重金属、微生物等项目，鲜果一般要求一年内有效，高风险品类或新品可要求每批或每季度。
8. **农药残留检测报告**：重点看是否覆盖 GB 2763《食品中农药最大残留限量》中对应水果的常用农药。
9. **重金属及污染物检测报告**：铅、镉、砷、汞等，符合 GB 2762。
10. **微生物检测报告**：即食鲜切水果或冷冻果肉需要，看菌落总数、大肠菌群、沙门氏菌、金黄色葡萄球菌等。

**四、进口水果额外需要**
11. **海关入境货物检验检疫证明**。
12. **报关单/入境货物报关单**。
13. **中文标签**：预包装进口水果制品需有符合 GB 7718 的中文标签。

**五、辅助管理和风险控制文件**
14. **供货商质量保证协议/食品安全承诺书**：约定农残、添加剂、追溯、召回责任。
15. **产地证明或基地信息**：种植基地、合作社、采收记录，便于源头追溯。
16. **储存运输条件说明**：冷链温度记录、运输车辆卫生证明，尤其是冷冻果肉、鲜切水果。
17. **无非法添加承诺**：不得使用防腐剂、色素、甜味剂等超范围添加。

**实操建议：**
- 鲜果供应商：重点收 **营业执照 + 承诺达标合格证 + 每批送货单 + 定期农残检测报告**。
- 加工水果制品供应商：重点收 **营业执照 + 食品生产许可证 + 每批出厂检验报告 + 第三方型式检验报告**。
- 进口水果：再加 **入境货物检验检疫证明 + 报关单**。
- 建立 **一供应商一档案、一批次一记录**，检测报告过期前提前催新，送货单和检测报告按批次对应保存，至少保存至产品保质期满后6个月，没有明确保质期的保存2年以上。

如果供应商只能提供营业执照，不能提供合格证或检测报告，建议不要直接用于即食茶饮，至少要做进货快检或换供应商。
