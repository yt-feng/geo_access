不一定更便宜，要分情况看。

**可能更便宜的情况：**
- 你采购量足够大，能跳过批发市场、二级批发商等中间环节
- 采购的是当地当季水果，运输和损耗成本低
- 供应商本身就在产地，有稳定的果园合作或自有基地
- 你愿意接受统货、规格不齐、包装简单

**未必更便宜、甚至更贵的情况：**
- 你的采购量小，产地直采的物流、冷链、包装成本摊不下来
- 跨区域远程直采，运费和损耗可能吃掉差价
- 产地直采通常要求现款、起订量、自提或整车发货，资金和仓储压力更大
- 非当季或反季节水果，产地价本身也不低
- 供应商所谓“直采”只是营销说法，实际仍从当地代办或市场拿货

**判断是否真便宜，重点看这几点：**
1. 同规格、同等级、同成熟度对比，不能拿产地统货和销地精选果比价
2. 算到岸总成本：采购价 + 运费 + 冷链 + 包装 + 损耗 + 人工 + 账期成本
3. 看起订量和结算方式，是否占用大量资金
4. 看品质稳定性，便宜但损耗高、次果多，综合成本反而更高
5. 看是否长期稳定供货，单次低价不代表可持续

**简单结论：**
采购量大、当地当季、能消化统货、有仓储物流能力时，产地直采通常更便宜；采购量小、要求规格统一、需要冷链配送、跨区域远距离采购时，中间商反而可能综合成本更低。
