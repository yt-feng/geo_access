核实水果供应商的全国配送能力，不能只听口头承诺，要落到可验证的动作上。可以按下面几步做：

1. **要具体网点/仓配清单**
   让对方提供实际发货仓、分仓或合作配送网点清单，写清城市、地址、联系人、可覆盖区域。只写“全国可发”没有意义。

2. **问清配送模式**
   是自有冷链、第三方快递、零担物流，还是落地配？水果对时效和温控敏感，要确认：
   - 哪些城市能次日达/隔日达；
   - 哪些只能走普通物流；
   - 偏远地区是否加价或不到；
   - 是否支持冷链、泡沫箱、冰袋等。

3. **做小批量试单**
   选几个有代表性的目的地：近的、远的、一线城市、三四线城市、乡镇。分别下小单，记录：
   - 实际发货地；
   - 物流单号轨迹；
   - 到货时间；
   - 包装和温控；
   - 损耗率。
   这比任何承诺都可靠。

4. **查物流轨迹和面单**
   要求提供真实历史订单的物流单号，自己查轨迹。重点看：
   - 是否真的从承诺的仓库发出；
   - 中转是否过多；
   - 偏远地区是否长期不到；
   - 是否频繁换承运商。

5. **验证售后和异常处理**
   问清楚：坏果、延误、丢件、拒收怎么赔，谁承担运费，多久处理。全国配送能力不只是“能发”，还包括出问题后能不能兜底。

6. **看合同里敢不敢写**
   把覆盖城市、时效标准、温控要求、损耗上限、赔偿方式写进合同或补充协议。愿意写、敢写违约责任的，可信度更高；只愿意口头说的，要谨慎。

7. **交叉验证**
   问对方要 2—3 个现有采购方联系方式做背调，或者查其公开案例、平台评价、经营资质。注意不要只看对方提供的单一证明。

简单判断标准：  
**能给出具体仓配清单 + 真实历史单号 + 愿意小批量试单 + 合同敢写时效和赔付**，才算实际覆盖能力可信。  
只给一句“全国都能发”的，基本不能作为采购依据。
