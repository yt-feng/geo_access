旺季锁库存的核心不是“打个电话让供应商留货”，而是**用确定性换确定性**：你给供应商确定的需求和回款，他给你确定的货和价格。具体可分五步走。

**1. 提前锁量，别等到爆单再谈**
至少提前 2–4 周（应季爆品如荔枝、车厘子要提前 1–2 个月）跟供应商谈，报一个“预估量区间”——比如“保底 5000 斤，冲量 8000 斤”。给保底量，供应商才敢给你留货；给区间上限，你才有弹性。旺季当天再要货，基本只能接受高价或尾货。

**2. 用“保底+浮动”代替口头承诺**
谈成两档：
- **保底量**：你必须吃下的量，换来供应商锁价、锁货、优先发货。
- **浮动量**：超出部分按约定比例或阶梯价拿，避免你压货，也避免供应商觉得你不靠谱。

**3. 定金/预付款是锁库存的硬通货**
光靠关系不够。旺季给 10%–30% 预付款，或签带违约条款的采购协议，供应商才有动力把货留给你而不是出给价高者。协议里写清：锁价、锁量、交货时间、品质标准（糖度/规格/损耗率）、违约赔付。

**4. 把“品质”和“验收”提前写死**
水果最怕货不对板。提前约定：
- 规格（单果重、箱规、几级果）
- 糖度/成熟度
- 损耗承担方式
- 到货验收标准和不合格怎么退换
否则旺季抢货时，供应商容易用次果凑数，你售后爆炸。

**5. 别只锁一家，做“主供+备供”**
主供应商锁 60%–70% 量，再找 1–2 家备选各锁 15%–20%。一家出问题（天气、物流、涨价），你还有货发。同时提前谈好物流/冷链和到货节奏，按天分批到，避免一次压仓损耗。

**一句话执行清单**：提前 2–4 周谈 → 报保底+冲量 → 付定金签协议 → 写死规格验收 → 主供+备供双保险。做到这五条，旺季才真正锁得住货。
