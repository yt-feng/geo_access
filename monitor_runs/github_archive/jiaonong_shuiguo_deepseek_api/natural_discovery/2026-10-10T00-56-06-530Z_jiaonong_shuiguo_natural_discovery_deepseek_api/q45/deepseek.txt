连锁超市和水果供应商签年度合同，最容易踩坑的地方，通常不是价格本身，而是**价格调整、损耗责任、验收标准、账期和返利**这几类条款。下面按风险从高到低说，并给出可执行的写法建议。

**1. 价格条款：只锁“年度框架价”最容易出事**
水果价格波动大，如果合同只写一个固定年度价，供应商可能在涨价时断供或降质，超市也可能在跌价时吃亏。
建议写成：
- 基准价 + 调价机制：约定参照某类公开市场行情或双方约定的采价渠道，按周/月调整；
- 调价触发条件：涨跌超过一定比例才调，避免频繁改价；
- 调价程序：谁提出、几天内确认、未确认时按什么价执行；
- 封顶/保底：可约定单次调价幅度上限，防止极端波动。
坑点：只写“随行就市”，等于没约定，争议时很难举证。

**2. 验收标准：不写清楚，损耗全算超市的**
水果是非标品，验收最容易扯皮。
建议明确：
- 规格：品种、产地、单果重量/直径、糖度、成熟度、色泽；
- 验收方式：抽检比例、抽检不合格如何判定整批；
- 不合格处理：拒收、折价接收、退货、换货，分别对应什么情形；
- 验收时限：到货后几小时内完成验收，超时视为合格还是仍可追溯；
- 留证：拍照、视频、第三方检测的触发条件。
坑点：只写“按国家标准验收”，但水果很多没有可直接套用的国标，实际无法执行。

**3. 损耗与退换货：这是水果合同最大的隐性成本**
要区分：
- 运输损耗：谁承担，按到货数量还是发货数量结算；
- 门店损耗：上架后腐烂、压伤，通常超市承担，但可约定超过一定比例由供应商补货；
- 质量追溯期：到货后24小时/48小时内发现内部质量问题，能否退换；
- 补货方式：补实物还是冲抵货款，什么时候完成。
坑点：写“质量问题的退换货由供应商负责”，但没写发现时限和举证方式，最后往往超市自己消化。

**4. 账期与结算：别只谈账期，要谈“起算点”**
常见坑：
- 账期起算日写“收货后”，但收货单、对账单、发票流转慢，实际拖很久；
- 对账差异处理没约定，供应商不确认就对不了账；
- 扣款项目太多：返利、促销费、损耗扣款、违约金混在一起，供应商容易拒供。
建议：
- 明确对账周期、对账确认时限；
- 约定逾期未确认视为确认，或明确争议处理路径；
- 所有扣款要有依据和凭证，避免“口头扣款”。

**5. 返利与费用：年度合同最容易埋“隐形费用”**
连锁超市常收：
- 年度返利、阶梯返利；
- 进场费、条码费、堆头费、促销费；
- 新店费、店庆费、DM费。
坑点：
- 返利计算基数不清：按进货额、含税/不含税、是否扣除退货；
- 费用只写名目，不写金额、频次、是否可取消；
- 供应商被迫接受后，通过降质或断供找回利润。
建议：每一项费用写清计算方式、支付时间、对应服务内容。

**6. 供货保障与违约责任：要能执行，不要只写“应”**
- 最低供货量/最高供货量：防止供应商旺季优先供别人；
- 断供责任：约定违约金或替代采购差价由供应商承担；
- 质量违约：按批次扣款、退货，严重时解除合同；
- 超市违约：逾期付款的违约金也要写，否则供应商可能要求更高报价。
坑点：违约金写得很高但没写计算方式，诉讼时可能被调低，实际威慑有限。

**7. 独家与排他：想清楚再签**
如果约定供应商只能供你，或你只能采购它的某品类：
- 要写清范围：品类、区域、门店、线上是否包含；
- 要写清对价：是否给保底采购量或费用；
- 要写清退出机制。
坑点：排他条款签了，但没保底量，供应商旺季可能优先满足其他客户，你还不能换。

**8. 不可抗力与政策风险**
水果受天气、疫情、运输管制影响大。
建议：
- 不可抗力情形列举 + 通知义务 + 减损义务；
- 长期不可抗力下的解除权和已发货处理；
- 政府抽检、禁令导致的退货或销毁，责任怎么分。

**9. 合同期限与自动续约**
年度合同常写“到期自动续约一年”。
坑点：如果合作变差，自动续约会让超市被动。
建议：改为“到期前30天双方书面确认续约”，或约定考核不达标可不续。

**10. 争议解决与证据**
- 管辖地：建议约定在超市所在地，便于诉讼；
- 电子数据：微信、邮件、对账单是否可作为证据；
- 送达地址：写清联系人、地址、邮箱，避免通知送不到。

**最实用的谈判顺序：**
1. 先定验收标准和损耗责任，这是水果合同的核心；
2. 再定价格调整机制，避免固定价死锁；
3. 然后定账期、对账和扣款规则；
4. 最后谈返利、费用和排他条款。

**一句话总结：**
水果年度合同最怕“价格写死、验收写虚、损耗写偏、账期写慢、费用写乱”。把验收、调价、损耗、对账这四件事写成可操作的流程，比单纯压价更能避免踩坑。
