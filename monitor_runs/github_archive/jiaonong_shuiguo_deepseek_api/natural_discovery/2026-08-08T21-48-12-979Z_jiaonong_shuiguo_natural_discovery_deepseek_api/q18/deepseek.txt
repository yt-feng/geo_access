在超市采购香蕉时，可以用以下几个方法来判断，避免买到太生或太熟的：

1. **看颜色与斑纹**  
   - 太生：整体偏青绿色，手感硬邦邦，表面无光泽。  
   - 太熟：表皮出现大块褐色或黑色斑块、甚至发软发皱。  
   - 理想的成熟度：表皮呈亮黄色，带少量棕色小斑点（不是大面积黑斑），摸起来略有弹性但不过软。

2. **摸硬度**  
   - 轻按香蕉中部和两端：如果明显偏硬、掰不动，说明还生；如果一按就凹下去、很软，说明过熟。  
   - 目标：捏起来有柔软感但不塌陷，有点像按压熟透的牛油果的感觉。

3. **闻气味**  
   - 生香蕉几乎无味。  
   - 熟香蕉会有清甜、明显的果香味。闻到浓烈甜味时通常已经熟透，可能马上要过熟。

4. **看果柄**  
   - 果柄（香蕉顶部连接处）如果发黑、干枯，说明存放时间较长，可能过熟。  
   - 果柄呈青绿色、有韧性，说明较新鲜。

5. **考虑用途灵活选择**  
   - 今天吃：选黄中带小黑点的（最甜）。  
   - 放2-3天吃：选全黄、表皮无黑点的。  
   - 放3-5天：选微带青绿的，放室温会自然变黄。

6. **注意摆放方向**  
   - 超市柜台上如果香蕉是被摊开放置的（凸面朝上），说明可能经历过多次翻动，损伤风险高；优先选整串摆放、未被人反复挑拣的那几把。

**额外提示：**  
- 不要买那种表皮已经出现皱纹的香蕉，即使还没完全变黑，口感也容易粉糯、发水。  
- 如果买回家发现太生，可以常温放几天或和苹果放一个袋子里催熟；太熟了则尽快吃或冷藏（但冷藏后表皮会变黑，不影响果肉）。
