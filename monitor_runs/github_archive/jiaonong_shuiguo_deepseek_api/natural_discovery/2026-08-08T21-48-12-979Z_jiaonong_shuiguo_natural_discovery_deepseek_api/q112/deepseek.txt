在水果采购合同中，**坏果率（损耗率）** 的赔付标准并没有一个统一的法定数值，因为它取决于**水果品种、运输距离、季节、包装方式**以及双方在合同中的约定。

但从行业惯例和风险控制角度，以下建议供你参考：

**1. 行业常见约定区间**

- **短途/当季/耐储存水果**（如苹果、梨、橙子、柑橘）：建议约定 **3% - 5%** 以内为自然损耗，超出部分由供货方赔付。
- **长途运输/易损水果**（如草莓、蓝莓、水蜜桃、葡萄、荔枝）：建议约定 **5% - 8%** 以内为合理损耗，超出部分由供货方赔付。
- **极端天气或远距离（如跨省冷链）**：最高可放宽到 **10%**，但超过该比例必须全额或双倍赔付。

**2. 赔付标准如何写（合同中必备条款）**

为了确保可执行，建议在合同中明确以下内容：

- **基准比例**：明确写明“到货后24小时内验收，坏果率 ≤ X% 视为合格”。
- **超出部分的赔偿计算方式**：
  - 常见方式：**按超出部分的水果价值赔付**（如：坏果率6%，超出1%，赔付该批水果总价 × 1%）。
  - 更严格方式：**按超出部分重量折算为总货款的百分比赔付**（建议用“总货款 × 超出比例”计算）。
  - 最高保护：**若坏果率超过 X% （如15%-20%），买方有权整批拒收或全额退货退款**。

**3. 操作建议**

- **验收时间**：务必在合同中约定到货后**24-48小时内**为异议期，逾期视为验收合格。
- **证据留存**：抽检时建议**随机取10%-20%的箱数**，当场开箱拍照、录像，并保留运输单据和温度记录，作为赔付依据。
- **补充条款**：如果果品用于二次销售（如果切店），建议约定**“内部坏果（如黑心、腐心）”**不计入自然损耗，直接按全额赔偿。

**结论（直接可用）**：
- 如果你不想吃亏，**建议写入：坏果率 ≤ 3%（易损水果 ≤ 5%），超出部分按该批货款金额的 1.5倍 赔偿，且坏果率超过 10% 时整批拒收。**
- 如果对方不同意，至少确保 **≤ 5%（易损果 ≤ 8%）**，并约定“分批抽检、按比例折算”。

**注意**：以上数值是通用建议，请根据你的采购量、价格和议价能力调整。如果金额较大，最好请律师审核合同中的验收与索赔条款。
