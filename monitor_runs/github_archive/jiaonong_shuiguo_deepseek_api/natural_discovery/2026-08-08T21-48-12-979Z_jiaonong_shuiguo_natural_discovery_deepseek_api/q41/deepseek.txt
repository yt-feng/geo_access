商超采购香蕉时，判断催熟能力是否稳定，核心是**看基地、看批次、看硬件、看流程**。以下是操作性较强的判断步骤，建议培训采购员执行：

**一、 询问供应商“催熟档案”**
1.  **批次追溯**：要求供应商提供每一批香蕉的**采收日期、产地、到货温度**。稳定供应商通常能精确到“船运/车运天数+到仓温度”。
2.  **催熟参数**：直接询问其催熟库的**乙烯浓度（PPM）、温度曲线（如17-18℃）、湿度（85%-90%）**。如果对方含糊其辞或说“差不多”，大概率不稳定。

**二、 到货仓储“两查一测”**
1.  **查库房**：现场查看催熟库是否有**循环风机**、**温湿度记录仪**（是否有24小时曲线）、是否有**乙烯气罐/发生设备**。无硬件支撑的“自然放熟”一定不稳定。
2.  **测中心温度**：用探针温度计插入香蕉果肉中心，理想到货中心温度应在**13-15℃**。若高于18℃或低于10℃，后期催熟极易出现“外黄内硬”或“青皮不熟”。
3.  **查“青度”均匀性**：随机拆开2-3箱，看整箱蕉的**颜色是否一致**（青度色卡3-4级为主）。如果一箱里有全青的、有微黄的，说明分选不严，催熟后熟度会参差。

**三、 小批量“试催”测试（核心动作）**
采购前或首批到货后，**强制要求做1-2箱（约10-15kg）的平行测试**：
- 将同批香蕉分两份：一份按供应商建议的**乙烯浓度+温度**催熟；一份**不加乙烯**，仅常温储存。
- 48小时后观察：
  - 正常催熟：果皮由青转黄，**果柄处不发黑**，敲击有**“空鼓”感**（果肉与果皮分离）。
  - **稳定性判断**：如果加乙烯的48-72小时全部转黄且糖度高（糖度计测18-20 Brix），而不加乙烯的也在2-3天内自然转黄，说明该批次“后熟能力”强，催熟稳；如果加乙烯的熟了但肉质发硬、不甜，或出现**“绿皮熟烂”**（皮青但果肉软烂），则说明催熟能力极不稳定，直接拒收。

**四、 观察“哑果”与“回青”比例**
- 整体催熟完成后，随机开3-5箱，数**“哑果”**（没有香味、颜色发灰绿的果）数量，占比超过5%则不稳定。
- 上架后抽查：如果顾客反映**“买回家3天不熟”**或**“放一夜就全黑”**，说明该批次催熟剂残留或温度波动过大，立刻更换供应源。

**五、 关键话术（用于谈判）**
- “请提供您上个月同产地香蕉的催熟记录曲线，我们抽查一下合格率。”
- “这一批我们按您的方案试催24小时，如果中心温度超过15℃或出现黑心，这批货我们按退货运费你来承担。”

**最终底线**：如果供应商无法提供**实时温湿度数据**或**拒绝小批量试验**，无论价格多低，都不要长期采购。稳定的催熟能力 = 供应商愿意为温度/乙烯误差买单。
