可以的。超市做水果促销时，供应商通常可以提供多种形式的支持，具体取决于双方的合作条件和供应商的实力。

一般来说，供应商可以提供的支持包括：

1. **陈列支持**：提供端架、堆头、专区的优先使用权，或免费提供陈列道具（如展示架、水果托盘）和生动化装饰物料（如挂旗、价签卡）。
2. **海报与物料支持**：提供促销海报、跳跳卡、地贴、横幅、水果营养知识宣传册等宣传物料；部分供应商还会协助设计专属促销方案。
3. **试吃与互动支持**：派遣促销员现场制作试吃装，提供一次性试吃盒、牙签、消毒用品等，或组织“现切现尝”“水果汁现场榨取”等互动活动。

**建议与条件：**
- **提前沟通**：最好在档期开始前1-2周与供应商业务员或厂家经理确认支持内容，便于采购和备货。
- **明确费用与让利**：有些支持是免费的（尤其是新品推广或高毛利品种），有些可能需要扣点、广告费或销售保底。务必在合同或补充协议中写明。
- **验证供应商能力**：优先选择有成熟促销团队和丰富终端经验的水果供应商（如大型水果基地或品牌经销商），避免小商贩口头承诺后无法兑现。
- **试吃合规**：需确保试吃水果新鲜卫生，并符合商超当地的食安规定（如办理临时摊点许可等，视门店要求而定）。

如果供应商无法提供，超市也可以自行采购转台、打印简易海报，或与门店店长沟通申请总部促销资源，但效果和成本会略有差异。
