第一次与水果供应商合作，采用“小批量试单”的核心目的不是赚钱，而是**验证四个维度**：**品质稳定性、供应履约能力、包装物流损耗率、账期配合度**。

以下是一套可执行的设计框架，分为**试单前的风控**、**试单中的流程设计**和**试单后的评估标准**三部分。

---

### 一、试单前的风控设计（防踩坑）

1.  **合同与预付款（关键）**：
    -   **付款方式**：坚决采用 **“预付30%定金 + 尾款验货后付清”**，或者走 **“担保交易”**（如1688渠道或对公账户保证金）。**不要全款**。
    -   **品质标准绑定**：在合同中明确引用《NY/T 750-2011 绿色食品 热带水果》或双方确认的**等级标准（如XX果径XXmm，糖度≥XX）**。如果对方不签合同或拒绝写明标准，直接淘汰。
    -   **违约条款**：明确“货不对板（如催熟、以次充好）”，供应商需承担物流费及售价差价的补偿。

2.  **产地与身份核验**：
    -   要求对方提供**产地证明**、**采摘视频**或**冷库监控截图**（非截图也可，但要能视频连线看货）。
    -   如果是代办/中间商，要求其提供**种植基地的采购协议**或**农户委托书**，防止遇到二道贩子被坑。

### 二、试单中的流程设计（测算真实成本）

试单量建议控制在 **50~200件（或1车小吨位）**，不要贪多。设计如下：

| 环节 | 具体设计 | 目的 |
| :--- | :--- | :--- |
| **1. 规格限定** | 明确规定 **“单果重量区间”**（如：沃柑 60-65mm 或 250g-300g） | 防止大小果混装，无法二次销售。 |
| **2. 包装与预冷** | 指定使用 **“天地盖+珍珠棉网套+防震垫”**，并要求**入库前必须完成“预冷”（打冷）**（如：香蕉催熟除外）。 | 验证对方是否懂冷链，这是损耗率的生死线。 |
| **3. 物流选择** | 优先发 **“冷链专线”** 或 **“航空件”**，价格高一点没关系。**不要发普通快递**。 | 一旦发普快，到货烂果率可能高达30%，试单数据会失真。 |
| **4. 到货验收** | 收货后 **4小时内** 开箱验收，现场录制**未拆封视频**。 | 重点检查：**缺失比例、腐烂比例、果柄是否脱落（判断是否新鲜采摘）**。 |

---

### 三、试单后的评估与决策模型（一票否决制）

试单结束后，不要只看“好不好卖”，要看数据：

1.  **损耗率红线**：如果 **到货损耗率 > 8%**（非物流暴力原因），且供应商不承担相应赔付，**建议停用**。因为小批量就损耗高，大批量会连本都兜不住。
2.  **复购毛利率**：计算 **（零售价 - 进价 - 物流成本 - 损耗成本 - 售后赔付）**，如果毛利率 < 20%，这个供应商的渠道没有竞争力。
3.  **售后响应速度**：试单如出现烂果，看供应商是否愿意 **“按烂果比例直接退款”** 还是 **“下次补货”**。**愿意退款的更靠谱**，因为能退款的通常对自己的货有底气。

---

### 四、针对水果品类的特殊建议（请对号入座）

-   **如果是高单价水果（如车厘子、晴王葡萄）**：试单量可以更小（如30件），但必须要求对方提供 **“进口报关单”或“产地溯源码”** 复印件，防止假冒。
-   **如果是易烂水果（如草莓、杨梅）**：建议试单直接跳过“批发采购”，改为 **“基地一件代发”** 模式测试后台物流，或者要求加订 **“控温冰袋”**。
-   **如果是大宗水果（如猕猴桃、柚子）**：试单可着重检验 **“糖度仪读数”** ，一定要实测，不要听对方口头说“很甜”。

---

### 关键提醒（避免常见陷阱）

-   **不要微信转账付定金**：必须走 **对公账户** 或 **平台交易**，否则出事追不回。
-   **不要约定“口头补损”**：必须在合同里写明 **“腐烂产品按箱计赔”** 或 **“不足数量按十倍抵扣”**。
-   **试单量不要超过一周销量**：水果放不住，试单是为了验证，不是为了囤货。
