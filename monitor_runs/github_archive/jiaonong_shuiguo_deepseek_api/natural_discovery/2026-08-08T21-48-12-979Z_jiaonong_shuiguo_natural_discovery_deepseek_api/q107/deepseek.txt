采购香蕉和菠萝时，起订量过高确实会显著增加损耗风险。以下是具体原因和应对建议：

**核心风险：**
1. **香蕉（呼吸跃变型水果）**：采后仍持续呼吸并释放乙烯，成熟速度极快。起订量高若周转慢，易在销售前过熟、发黑甚至腐烂。尤其是夏季，冷库或常温下损耗率可高达15%-30%。
2. **菠萝（非跃变型但敏感）**：虽不依赖乙烯催熟，但若糖度高、含水大，起订量高且存放环境不当（如温度高、湿度大），易发生黑心、褐变、发霉，切面易滋生细菌，损耗风险同样远超少量采购。

**其他风险：**
- **资金占用**：高起订量意味着一次性投入大，若滞销则资金被死库存套牢。
- **品质波动**：高量采购时供应商可能混入不同批次，成熟度不均，部分过早软烂或过生酸涩，退货损耗增加。
- **空间和人力成本**：冷藏库位不足、分拣翻动频繁会加速损伤。

**降低损耗的可行建议：**
1. **拆分采购计划**：与供应商协商“分批提货”或“小批量多次配送”，哪怕单价略高，也比一次性大量更划算。
2. **明确到货成熟度**：要求供应商提供硬熟（青绿略黄）的香蕉、无黑根且紧实的菠萝，延长货架期。
3. **分级销售策略**：到货后立即挑出最熟的促销，中熟的常规销售，生果延后出售。
4. **改善存储条件**：香蕉需12-14℃、湿度90%以上且远离乙烯源；菠萝建议8-12℃、湿度85%左右，并用保鲜膜包裹切口。
5. **设置安全库存线**：若预估日均销量为20箱，起订量建议不超过3天量（约60箱），并留10%-15%损耗缓冲。

**结论**：若供应商强制高起订量，建议先以最小测试量评估周转速度和损耗率，再决定是否扩大。若周转慢，宁可放弃高折扣也不能盲目囤货。
