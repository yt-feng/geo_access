茶饮店在控制食品安全风险时，水果供应商需要提供一系列合规证明，以证明其产品来源合法、质量合格、可追溯。以下是最核心的证明文件清单，以及对应的判断要点：

**一、主体资质证明（证明供应商合法经营）**
1. **营业执照**：需为在有效期内的副本复印件或扫描件，经营范围应包含“水果销售”或“食用农产品销售”。
2. **食品经营许可证**（或食品流通许可证）：若供应商直接向茶饮店供货（非农户直供），需提供此证。

**二、产品质量证明（证明当批次水果安全）**
3. **食用农产品合格证**：承诺合格证或检测合格证，需注明品名、数量、产地、生产者信息及合格声明。这是目前食用农产品上市流通的关键文件。
4. **出厂检验报告/第三方检测报告**：
   - **农残检测报告**：重点查看是否检测有机磷类、氨基甲酸酯类等禁用/限用农药，结果需达标（GB 2763）。
   - **重金属检测报告**（部分高风险水果如草莓、杨梅等）：检测铅、镉、汞等指标。
   - **微生物指标**：对鲜切水果或需冷链的水果，应含菌落总数、大肠菌群等。
   - 报告有效期通常为3个月至半年，注意核对报告日期和水果批次是否对应。

**三、源头追溯证明（证明水果产地与流向清晰）**
5. **产地证明**：由产地农业农村部门或乡镇政府出具的产地证明，或供应商与产地合作社/农户的合作协议、进货凭证（含产地名称）。
6. **进货查验记录**：供应商应能提供其上游的进货台账、运输单据，形成完整追溯链。

**四、运输与储存条件证明（防止二次污染）**
7. **冷链运输记录或温度监控记录**（若为需冷藏水果）：如荔枝、蓝莓、切好的水果，需提供运输温度记录（一般要求0-4℃或按品种要求）。

---

**实战建议（给茶饮店管理者）：**

- **索证要“当场验”**：不要仅收复印件，应让供应商现场展示原件或电子证照，并用手机拍照存档。
- **批次对应原则**：每次进货时，让供应商提供**当批次**的检测报告，而不是拿旧报告充数。遇到异常可要求快检（现场用农残试纸抽检）。
- **合同约定责任**：在采购合同中明确“供应商承诺提供真实有效的证明文件，若因虚假证明导致食品安全事故，由供应商承担全部损失及法律责任”。
- **建立台账**：保存所有证明的电子或纸质版，并登记进货日期、品种、数量、供应商联系方式，保存期不少于2年（实际建议随查随调）。

**特别提醒**：如果茶饮店使用的是**鲜切水果、自制果酱**等自制加工品，除了供应商证明，自己还要建立加工过程的备案记录；若从农户个人（自产自销）直接采购，则需农户提供身份证复印件、自产证明（村委会开具），并尽量索要农产品合格证。
