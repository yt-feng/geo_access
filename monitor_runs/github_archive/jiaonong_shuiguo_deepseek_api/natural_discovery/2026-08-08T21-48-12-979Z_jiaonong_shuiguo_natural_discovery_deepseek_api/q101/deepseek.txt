与酒店早餐水果供应商洽谈合作，核心目标不只是“能供货”，更是要保证**稳定、安全、可追溯、以及成本可控**。以下是具体的注意事项和谈判建议：

### 1. 确定需求与质量分级（谈判前准备）
- **明确品类清单**：确定每天需要的水果种类（如常规苹果、香蕉、橙子，以及季节性西瓜、葡萄等），以及是否需要**切配果盘**（去皮、切块）还是整果。
- **制定质量规格**：明确果径大小、成熟度（如香蕉需七成熟）、是否有虫眼/疤痕、最远采摘时间（如超24小时拒收）。
- **预估波动量**：根据入住率和季节客流，给出每月/每周预估用量（如淡季每天X公斤，旺季每天Y公斤），让供应商报价有依据。

### 2. 合作模式的谈判要点
- **价格机制**：避免“一次定价一年不变”。应约定**月度或季度调价公式**（参考本地批发市场均价波动），且明确含税价、含运输费。
- **账期与结算**：酒店通常有30-60天账期，需与供应商明确结算周期，并要求提供合规发票（如农产品增值税发票）。
- **最低起送与最小订货量**：避免供应商因单量小而不送货，需约定“即使当日只订1箱也可配送”或“每周必须配送不少于3次”。

### 3. 供应稳定性与应急机制（重点）
- **备选供应商条款**：合同里写明“若因缺货导致无法按时交付，供应商需提前24小时书面通知，并协助调拨或推荐同等级别的替代品”，否则承担违约金（如按缺货金额的20%）。
- **极端天气应对**：要求供应商提供台风、暴雨等极端天气下的应急预案（如提前一天备货或异地调配）。
- **长期合同绑定**：谈判时可提出“如果连续6个月稳定供货且零投诉，则额外支付年度返利1%-2%”，换取供应商优先供货权。

### 4. 食品安全与合规（不可妥协）
- **资质审查**：要求供应商提供食品经营许可证、营业执照，水果来源需记录产地（如云南、海南等地）及**农药残留检测报告**（每月更新）。
- **批次追溯**：要求每批到货提供“到货单”，注明采摘日、农场、运输车辆牌照，以备市场监管检查。
- **到货验收标准**：最好请餐饮部厨师或采购一起参与验收，抽样开箱检查。若发现烂果超过规定比例（如小于3%），供应商需无条件补货。

### 5. 合同细节（防坑指南）
- **不可抗力条款**：明确因天气、疫情等不可抗力导致断供时，双方免责，但需启动后备方案。
- **退出机制**：约定试用期（如1个月），若质量不合格可随时终止合同；同时注明若酒店3次以上收到客诉，供应商需承担返换货费用。
- **保密义务**：部分供应商可能会透露给同行“酒店采购价”，需在协议中加入保密条款。

### 6. 谈判时的话术建议
- 开场话术示例：“我们酒店早餐对果盘要求较高，您那边如果能保证每日清晨6点前送达，且提供48小时紧急响应，我们可以考虑提高单价0.5元/公斤。”
- 不要只谈单价，应谈**综合成本**（比如损耗率、送货频率），例如：“您价格虽便宜0.2元，但需要每天送，运费成本高，抵销后不划算。”

### 7. 附加增值项（可争取）
- 免费提供**季节性新品试吃**（如国产樱桃、蓝莓等）。
- 提供**餐台摆盘建议**（供应商有时有专业水果切配指导）。

---

**重要提醒**：不要仅凭口头承诺就合作，所有协议必须书面化。建议首次合作签订3个月短合同，观察实际履约后再续签长期合同。如果酒店采购量较大（日均超50公斤），可考虑同时引入2家供应商竞争，但需控制主次关系，避免谁都不愿承担责任。
