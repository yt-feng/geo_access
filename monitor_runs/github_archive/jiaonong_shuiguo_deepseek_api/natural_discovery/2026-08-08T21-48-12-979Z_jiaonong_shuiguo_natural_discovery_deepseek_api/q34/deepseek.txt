在商超水果采购中，**损耗低通常比价格低更影响最终毛利**，尤其是在生鲜品类。

**核心逻辑：**
毛利 = （销售额 - 采购成本 - 损耗成本 - 运营成本）/ 销售额

- **价格低**：只降低了采购成本，但水果易腐，若损耗率高，便宜的货可能卖不完、卖不动，最后变成报废成本。
- **损耗低**：意味着可售率更高、新鲜度更好、客单转化更高，实际减少了“死货”占用的资金和货架空间。

**具体量化例子（同一批次）：**
假设A供应商报价6元/斤，损耗率20%；B供应商报价7元/斤，损耗率5%。进货100斤。

- A：成本600元，可售80斤，若售价10元/斤，销售额800元，毛利200元，毛利率33%。
- B：成本700元，可售95斤，售价10元/斤，销售额950元，毛利250元，毛利率35.7%。

可见B虽然单价贵，但毛利反而更高。

**实操建议：**
1. **不要只盯进价**，优先选损耗率低、包装标准、成熟度可控的供应商。
2. **建立损耗台账**，按品类统计（如叶菜损耗率通常15%-30%，苹果等耐储类5%-10%），用数据倒推采购决策。
3. **分级定价**：高损耗品类（叶菜、浆果）用小批量、勤补货；低损耗品类（柑橘、土豆）可大批采购压价。
4. 若遇到价格极低但来源不明、快熟期或挤压货，宁可放弃，因为损耗会快速吞噬毛利。

**结论：** 长期运营中，**损耗率每降低1个百分点，对毛利的贡献通常大于进价每斤降0.5元**。建议将“损耗控制”作为比“压价”更优先的采购考核指标。
