**结论：不一定，但通常有价格优势，只是“便宜”的背后需要仔细核算。**

产地直采（跳过中间商）确实能降低**采购单价**，但**综合成本**不一定最低。以下是判断是否更便宜的具体分析，以及你需要核验的3个关键点：

**1. 直采的优势（为什么可能便宜）**
- **减少差价**：传统供应链有产地代办、一级批发商、二级批发商等2-3层加价，每层加价约5%-15%。直采直接对接基地或果农，**采购价通常低10%-20%**。
- **损耗控制**：直采可现场验货、把控品质，避免到店后因质量问题大量剔除，**实际可销售成本**更低。

**2. 直采的隐藏成本（为什么可能不便宜）**
- **物流与包装**：产地直发需要承担整箱运输、冷链费用，如果采购量不足，单件物流成本可能高于城市批发市场的配送费。**建议让供应商提供“含税含运到店价”**。
- **库存与损耗**：直采通常要求整件起订，如果门店销量慢，积压库存导致的腐烂损耗（水果日损耗率约3%-5%）会吃掉价格优势。
- **服务成本**：批发商通常提供“送货上门+换货服务”，直采需要自己对接司机、协调到货时间，**时间成本和人力成本**也需计入。

**3. 判断是否更便宜的标准（可直接执行）**
- **对比总价**：要求该供应商报“产地直采到店价”（含运费、税、包装），再让你的常规供应商报“批发市场配送价”。**同等规格、同等成熟度**下，直采总价低于批发价10%以上，才值得切换。
- **测算损耗**：如果直采需要囤货超过3天销量，则按日损耗率计算可能增加的成本。例如：柑橘类日损耗约2%，你囤5天，损耗约10%，直接抵消溢价。
- **小批量试单**：首次合作只订1-2箱，实测到货品质、损耗率和实际到店时间，用数据验证。

**4. 例外情况**
- 如果供应商声称“产地直采”但**价格与批发市场持平甚至更高**，需警惕其是否只是贴牌宣传。可要求其提供产地收货凭证或果园合作合同。
- 对于**季节性、大宗品类**（如西瓜、苹果），直采优势明显；对于**小众或进口水果**（如某些热带水果），批发市场反而因批量集采更便宜。

**最终建议**：不要只看“直采”标签，直接拿报价单对比“到店综合成本”。第一次合作优先选择“可退货、付款周期灵活”的直采供应商，降低试错风险。
