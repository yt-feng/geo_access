在茶饮店旺季遇到菠萝用量激增，临时补货的核心在于**快速锁定货源+明确交易条件+规避质量风险**。以下是具体操作建议：

**一、立即沟通（30分钟内）**
1. **直接电话/微信语音**（不要只发文字），说明“紧急需求+预计周用量”，请供应商报**今日可调货量**和**最快到货时间**。
2. 明确告知“本周优先供应，后续旺季长期合作优先考虑你”，给供应商吃定心丸。

**二、明确关键条款（口头确认后补书面）**
| 条款 | 必须锁定内容 |
|------|------------|
| **价格** | 是否随市场价上浮？锁定本周单价（避免旺季坐地起价） |
| **到货时效** | 约定“下单后24小时内送达”或具体到半天 |
| **质量标准** | 糖度（如≥13%）、无碰伤、无烂心，到货抽检不合格比例（如≤5%）可拒收或按比例扣款 |
| **付款** | 先货后款（月结）或“预付款5%锁定货源”均可，押金金额写清楚 |

**三、合同/补充协议要点（避免扯皮）**
- 手机录音或微信文字记录：“本次为旺季临时调货，到货验收标准同原合同”
- 若原合同没有“旺季紧急供应”条款，建议补签**《临时补货确认单》**，写明品名、规格、数量、单价、到货日期、验收标准。
- **注意**：要求供应商提供“产地证明/农残检测报告”复印件，避免食品安全追溯问题。

**四、风险控制（预防断货）**
1. **不要只依赖一个供应商**：立即联系备用供应商（哪怕贵10-15%），作为应急后备。
2. **要求分批到货**：比如今天先送50%，明天再送50%，避免单次质量差导致全店断档。
3. **留好证据**：所有沟通截图、录音保存至旺季结束，万一纠纷可用。

**五、话术参考（可直接使用）**
> “王总，最近菠萝杯销量突然爆了，这周需要多供200斤，您明天中午前能送吗？如果行，我上午先转您2000定金锁定，到货验收合格按原价结，不合格我退您货，您看怎么安排？”

**关键提醒**：旺季临时补货，供应商可能会抬价或掺杂次果，**验收时务必开箱抽查**（底部和中间层），一旦发现以次充好，立即拍照留证并要求退货或折价。
