做社区团购水果，尤其是香蕉和菠萝这类**高损耗、易后熟**的品，关键不是“出事再赔”，而是**把损耗前置分流**。

给你一套从选品到售后的实操流程，分为四个核心环节：

**1. 源头与规格的“硬控制”**
- **香蕉：** 不要进全黄熟果。采购时要求**七成半黄、两成绿**的“黄绿条”或“微黄”果。到货后先放阴凉通风处，再按成熟度分批上架。建议卖“稍带青”的，跟用户明说“放两天更好吃”。
- **菠萝：** 生切菠萝损耗巨大，建议**只卖带皮整果**，且必须是**鲜绿冠**、底部干爽的。不要为了省事卖切好的，除非你次日能清完。

**2. 到货后的“分级分流”**
- 到货后立即开箱检查。
- **一级果（品相极佳）：** 做正价秒杀，限量。
- **二级果（轻微瑕疵/皮有斑点）：** 做“盲盒果”或“特价果”，文案写“外观不影响口感的福利果”。
- **卖不掉的风险果（过熟/软烂）：** 当晚直接转为“赠品”，买其他任意水果送半个香蕉或菠萝，用来引流，降低售后单。

**3. 售后标准的“精准锚定”**
- **香蕉：** 用户投诉“烂了”，不要看整把，拍图看**根部**。如果只是果皮发黑、果肉完好，定义为“熟过头”，**不赔**，但补偿0.5-1元优惠券；如果果肉发黑流水，**全额退款**。
- **菠萝：** 投诉“酸”或“不甜”，这是主观口感，**不赔**。但如果是切开发现内部发黑、霉变，**全额退+下次优惠**。
- **统一话术：** 售后不是“你赔我”，是“平台帮您分担损耗”。比如：“亲，这个果确实熟过了，我们全额退您，并且这张5元券您下次买苹果直接抵扣。”

**4. 售后的“情绪安抚”**
- 最核心的一点：**高损耗品不要承诺“不甜包退”**，要承诺“坏了包退”。把用户的预期从“口感”拉低到“品质”，这是关键。
- 遇到态度差的用户，直接退款+赠送小额券，不纠缠。**用一次小额赔付，换取该产品长期的口碑稳定，高损耗品最怕的是差评带来连带效营销。**

**止损底线：**
- 香蕉/菠萝的**售后率控制在3%以内**是正常。如果超过5%，不是售后问题，是你**进货成熟度或运输环节**出了问题，需要马上换供应商或改规格，靠售后补贴是补不平的。

简言之，你的核心动作是：**源头收生、到货分流、售后只赔烂不赔熟、用赠品消化积压。**
