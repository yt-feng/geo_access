在便利店销售菠萝切块时，**保质期、包装和配送频次都需要重点关注，三者环环相扣，缺一不可**。但如果非要按优先级排序，建议按以下顺序考虑：

**第一优先级：保质期（食品安全底线）**
- **核心原因**：鲜切水果极易滋生细菌，菠萝含糖高、水分大，切块后接触空气氧化快，常温下2小时菌落可能超标，4小时内必须冷藏（0-4℃）。
- **具体动作**：
  - 严格标注“生产时间+到期时间”，通常是**冷藏24小时内**（建议最好12小时内卖完）。
  - 超过2小时未售出的，必须从冷藏柜临时撤下废弃，不能二次回冷。
  - 如果当天卖不完，坚决报废，不要卖隔夜切块。

**第二优先级：包装（决定卖相和保质时长）**
- **核心原因**：塑料盒+保鲜膜是最低标准；如果是敞口或裸装，不仅暴露污染风险，还卖相差，顾客捏来捏去会被退货投诉。
- **具体要求**：
  - 使用**食品级PE/PP透明盒**，带密封盖或覆膜，防漏汁。
  - 可以加一张吸水垫（吸出果汁防变质）。
  - 包装上必须印/贴**“保质期至几点”**和**“冷藏保存”**提示。

**第三优先级：配送频次（影响新鲜度与损耗）**
- **核心原因**：配送频次过低，货架上的切块时间过长；频次过高，运费成本增加。
- **建议方案**：
  - 如果门店销量稳定，**最好每天分2次配送**（如上午开店前1次、中午1次），每次按门店预估半日销量供货。
  - 如果销量波动大，采用“**小批量、高频次、当天清空**”模式，宁少勿多。
  - 督导/摆台时定时检查冷柜温度（0-4℃），若温度异常立即下架。

---

**给你的操作性建议（可直接落地）：**

1. **每天开店核对**：检查货架上所有切块盒上的“到期时间”，优先销售最早生产的这批。
2. **店内冷藏柜设置提示卡**：写明“本柜商品需2小时内售出，超时请下架”。
3. **排班表单加一项**：每2小时由店员巡查一次，翻动检查有无变色、出水、异味。
4. **配送下单参考**：按前一日销量×1.2倍下单，若当日高温（超过30℃）建议减半量、加配送次数。

**一句话总结**：保质期是安全红线，包装是销售前提，配送频次是损耗平衡点。如果只能选两件事做好，优先做**保质期管理**和**包装规范**，配送频次可根据实际销量灵活调整。
