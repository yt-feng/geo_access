签订年度水果供应合同，超市方最容易在以下几个条款上踩坑。建议逐条核对，最好附上违约责任和退出机制：

### 1. 价格调整机制（最核心的坑）
- **风险点**：约定“全年固定价”或“随行就市”但未定义怎么调。
- **坑**：果品价格波动大（如极端天气、疫情），如果写“按市场价结算”，供应商可能以高价结算；如果写“固定价”，遇上行情下跌，供应商可能断供或降低品质。
- **建议**：明确调价触发条件（如产地批发价涨跌超10%时可协商调价），并约定调价依据（如参考权威平台发布价）和调价流程（需书面确认）。

### 2. 质量标准与验收标准
- **风险点**：合同只写“优质”“无腐烂”，实操中争议不断。
- **坑**：到货后大小、甜度、损伤率没有量化标准，供应商可能以“次果充好”，验收时扯皮；或者你拒收，但合同没写异议期，供应商说“你没在24小时内提出视为接收”。
- **建议**：在附件中明确规格（如单果重量、直径）、成熟度（糖度Brix值）、外观瑕疵容忍比例（如碰伤不超过X%）、农残标准（附检测报告）。约定验收时效（如到货后X小时内书面异议，超时视为默认合格）。

### 3. 送货与损耗责任
- **风险点**：约定“甲方自提”或“乙方送货”但未明确风险转移点。
- **坑**：仓库卸货前发现腐烂，若合同写“交付后风险转移”，可能归超市；若写“运输途中损耗由供应商承担”，供应商可能延长配送时间导致损耗增加。
- **建议**：明确风险转移节点（如“货到超市指定仓库验收合格后风险转移”），并约定损耗率上限（如整车损耗率≤3%，超出部分由供应商承担或折价）。

### 4. 结算周期与账期（资金占用坑）
- **风险点**：写“月结30天”但未约定对账流程和利息。
- **坑**：供应商以“账期太长”为由中途提价或断供；或者结算时因发票、对账单滞后，你被迫多付滞纳金。
- **建议**：明确对账日、开票日、付款日（如“次月10日前对账，20日前付款”），并约定逾期付款的违约金（如每日万分之五）。同时可约定“如遇供应质量问题，有权暂缓支付对应货款”。

### 5. 独家供应与最低采购量
- **风险点**：写“乙方为甲方独家供应商”但未限制乙方只能供你一家，或写了“年度保底采购量”但未约定弹性。
- **坑**：供应商同时供货给其他超市，货品分给别家更优质的；或者你自己季节性销量波动，全年保底量订高了，淡季也得吃进烂水果，订低了供应商压价。
- **建议**：独家条款要明确“乙方不得向甲方半径X公里内的竞争超市供货”；保底量可设为季度/月度弹性区间（如最低采购量不低于X吨，但可上下浮动20%）。

### 6. 违约责任与退出机制
- **风险点**：只写“违约方赔偿损失”但没有具体违约金，或没有单方解约权。
- **坑**：供应商连续三次质量不达标，你想解除合同，但合同没写解除条件，对方赖着不退押金；或者你经营调整想减少采购，被要求支付全年货款差额。
- **建议**：明确具体违约情形和违约金（如延迟交货按日罚款，质量不合格可拒收并要求换货或扣款），并写明“任何一方出现X次重大违约，另一方有权书面通知解约”。

### 7. 附带条款（常被忽视）
- **不可抗力**：明确哪些情况算（疫情、自然灾害），以及如何分担已采购库存损失。
- **知识产权与保密**：如果涉及包装定制或促销信息，防止供应商泄密。
- **争议解决**：约定仲裁或诉讼地（建议选超市所在地法院）。

**最后的防坑建议**：不要只靠文字合同，务必在签约前实地考察供应商的果园/仓库，并要求提供上一年度的第三方质检报告。合同里可加一句“乙方需投保农产品责任险”，降低极端风险。如果有法务，务必请法务逐条审核再签。
