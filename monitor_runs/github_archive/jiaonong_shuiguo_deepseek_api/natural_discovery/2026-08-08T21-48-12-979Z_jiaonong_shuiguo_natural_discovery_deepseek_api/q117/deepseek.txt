这是一个非常典型的零售/采购场景。供应商推新品时，**采购方最忌讳“一步到位”的大批量铺货**，重仓高风险。

**核心原则：先小批量试水，用数据说话，再决定是否放大。**

具体建议如下，按“稳妥策略”和“激进策略”分档：

### 1. 稳妥策略（推荐，90%的情况适用）
**建议试卖量：** 目标门店 **1-2周的预估销量**，或 **单店最小起订量（通常1-5箱）**。

-   **计算逻辑：** 假设你有10家门店，每家店每天能卖5份该新品（基于你历史类似品类的经验），试卖周期7天。则采购量 = `10家店 × 5份/天 × 7天 = 350份`。
-   **核心动作：**
    -   **谈“试销协议”**：务必和供应商白纸黑字约定，首批为“试销”，**周期内卖不动的可退换货**（这是关键谈判点，大部分供应商为了铺货会同意）。
    -   **选样本店**：不要全部铺，先选 **3-5家** 客流量大、且目标客群匹配（比如主打健康、或口味偏好度高的）的超级门店。

### 2. 保守策略（预算紧张 / 品类风险高）
**建议试卖量：** **最小陈列单位**（通常1-2箱）或 **单品不超过门店总SKU的5%**。

-   **适用场景：** 供应商是纯新品牌、包装没有吸引力、或者属于重口味/猎奇性产品（如异域水果）。
-   **核心逻辑：** 目标是“验证动销”，而不是“卖货”。只要这1箱能在3天内自然卖掉一半以上（非促销），就说明有潜力。

### 3. 激进策略（仅限爆品潜力 / 供应链极强）
**建议试卖量：** 按 **双周预估销量** 进货，但**必须配套满减或买赠活动**。

-   **前提条件：** 供应商提供免费试吃装，且你的门店有冷柜/堆头位置。
-   **注意：** 即使激进，也**绝对不要一次性下3个月的货**。

### 决策参考表（自检清单）

| 维度 | 判断标准 | 动作 |
| :--- | :--- | :--- |
| **供应商口碑** | 是头部大厂还是小厂？ | 大厂可多进一点，小厂压到最低量 |
| **保质期** | 是不是短保（如 < 7天）？ | 是短保，采购量除以3，并缩短试销期 |
| **毛利率** | 新品毛利率是否比老品高20%？ | 过低就少进，不值得占用排面 |
| **季节匹配** | 是否是当季水果？ | 不当季，只进1/4量试水 |
| **退换政策** | 卖不完能换老品或退钱吗？ | 不能退换，只进“能送人不亏”的量 |

### 关键风险提示
-   **缺货损失 vs 滞销损失**：试卖阶段，**宁可卖断货，也不要压库存**。新品卖断货了，你可以补单，还能给供应商制造“热销”的假象去争取更好的返利政策；一旦压货，资金占用和损耗（水果极易变质）就是纯亏损。
-   **数据复盘节点**：**第3天** 看复购（有没有回头客找指定），**第7天** 看动销率（销量/进货量）。低于30%动销率，直接清库存下架。

**最终建议：** 除非你非常看好，否则**首批进货量严格控制在“试产线产能”的5%以内**，也就是 **“够5家店卖5天”** 的量。这个量即使全军覆没，亏损额也在你可控范围内（通常建议控制在单店单日营业额的1%以内）。
