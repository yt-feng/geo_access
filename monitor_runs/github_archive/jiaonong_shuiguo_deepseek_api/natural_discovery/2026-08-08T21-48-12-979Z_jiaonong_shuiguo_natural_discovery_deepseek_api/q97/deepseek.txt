在酒店采购水果盘原料时，供应商应确保满足以下规格和外观标准，以保障出品质量与安全：

**一、规格标准**
1. **成熟度统一**：同一批次水果成熟度尽量一致（如按糖度、软硬度分级），避免出现生熟混装，影响口感一致性。
2. **大小均匀**：单个水果的尺寸/重量偏差控制在±10%以内（例如苹果直径7-8cm，橙子≥200g），有利于摆盘美观和成本核算。
3. **包装规格明确**：明确按箱/筐/袋采购，箱内排列整齐，标明净重、毛重、产地、采摘日期。
4. **分切件标准**（如酒店自行切或供应商预切）：  
   - 果切块大小一致（如3cm见方，误差±0.5cm）；  
   - 片状厚度均匀（如0.4-0.6cm）；  
   - 去核、去皮彻底，无残留果皮或籽。

**二、外观标准**
1. **无瑕疵**：无明显机械伤（压痕、割伤）、虫眼、病斑、霉变、冻伤或褐变（如有轻微碰伤，应在交接时书面标注并扣除）。
2. **色泽自然**：成熟果色均匀，无过度催熟发暗或异常艳色（如打蜡过厚、人工染色）。
3. **表面干燥**：无大量水珠凝结（防加速腐烂），果蒂部无发霉、干裂。
4. **形态完整**：果实无畸形、瘪缩、干皱；叶菜类（如装饰用薄荷）无黄叶、烂叶。
5. **清洁度**：表面无泥沙、农药残留痕迹（需提供农残检测报告或产地证明）。

**三、附加保障（建议写入合同）**
- 提供每批次合格证或检测报告（农残、重金属指标）。
- 到货温度控制（如冷链车运输，果温≤10℃）。
- 退换货条款：当日内发现不合格品，供应商无条件补货或退换。

酒店验收时可抽查（按箱数5-10%开箱检查），拍照留存，对不符合标准的部分按比例扣款或拒收。
