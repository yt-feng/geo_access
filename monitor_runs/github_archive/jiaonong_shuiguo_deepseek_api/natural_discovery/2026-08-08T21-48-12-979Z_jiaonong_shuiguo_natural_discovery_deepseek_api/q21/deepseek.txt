在超市采购水果时，供应商需要提供以下主要检测报告和进货证明，以保障食品安全和可追溯性：

1. **农产品合格证明 / 产地证明**  
   - 供应商需提供水果产地的农业部门或合作社出具的合格证明，或购货凭证，说明水果来源合法。

2. **农药残留检测报告**  
   - 需提供近期（一般为1-3个月内）由第三方检测机构（如SGS、华测等）出具的农药残留检测合格报告，确保符合国家限量标准。

3. **重金属及有害物质检测报告**  
   - 针对可能受土壤污染的水果（如苹果、柑橘等），需提供铅、镉、汞、砷等重金属检测报告。

4. **进货台账/购销凭证**  
   - 供应商应提供采购合同、送货单、发票等，确保每批次水果来源清晰，便于追溯。

5. **合格供应商资质**  
   - 需提供营业执照、食品经营许可证（或生产许可证），以及供应商信用记录。

6. **特殊水果的附加证明**（视情况）  
   - 进口水果：需提供海关报关单、入境货物检验检疫证明、原产地证明。
   - 有机水果：需提供有机认证证书。
   - 绿色食品或无公害认证：需提供相应证书。

---

**实用建议：**  
- 采购时要求供应商随货提供以上报告的**复印件或电子版**，并加盖公章；报告需在有效期内。  
- 超市自身应建立进货查验制度，抽检留样，并保存记录至少2年。  
- 若供应商无法提供核心检测报告（尤其是农残报告），建议拒绝采购，并考虑更换供应商。

如涉及具体地区，请以当地市场监管部门的最新要求为准。
