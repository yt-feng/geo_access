在超市与水果供应商之间，账期（即货款结算周期）是双方商业谈判的核心条款之一。常见的情况如下：

**1. 行业普遍惯例（常见区间）：**
- **15天至30天**：这是最常见、最主流的账期区间。尤其对于中小型超市或社区店，因采购量相对固定、现金流需求快，供应商通常愿意接受15天左右的账期。
- **30天至45天**：对于连锁超市、大型卖场，由于采购量大、供应链稳定，账期通常会拉长至30天甚至45天。
- **45天至60天**：部分大型连锁或外资超市（如山姆、盒马等）在强势地位下，账期可达60天左右，但这通常伴随更优的供货价格或独立品牌合作。

**2. 水果品类的特殊性（关键提醒）：**
水果是**易腐、高损耗、价格波动大**的商品，这与百货、包装食品有很大区别。因此，账期谈判需特别注意：
- **短账期倾向**：供应商对水果的账期普遍非常敏感。**15天以内**在实践中更常见，甚至很多供应商要求**7天至10天**，因为水果保质期短，一旦回款周期过长，供应商的现金流和损耗风险都会大幅上升。
- **避免过账期**：**极少有供应商愿意接受超过45天的账期**，除非超市承担了部分储存或损耗压力，或者供应商是大型基地直供、货量极大。

**3. 实操建议：**
- **首次合作**：优先谈 **7-15天**，给双方一个磨合期，降低供应商的戒备心。
- **合作成熟后**：可以尝试谈判延长至 **20-30天**，并以“增加订货量、减少退货率”作为交换条件。
- **特别警示**：**尽量避免超过60天**。水果供应商一旦预期回款太慢，很容易通过降低品控、混入次果或减少配送频率的方式找补成本，最终导致超市端损耗上升，得不偿失。

**总结：** 如果是最常见情况，**15天至30天**是最合理的谈判区间。具体天数取决于超市规模、采购量以及双方信任度，但**水果行业整体偏短账期**，建议以短账期起步，避免冒进。
