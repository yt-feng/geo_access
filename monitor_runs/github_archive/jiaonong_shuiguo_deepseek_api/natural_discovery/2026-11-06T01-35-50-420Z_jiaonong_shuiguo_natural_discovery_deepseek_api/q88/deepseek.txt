# 线上水果销售：采购端减少坏果与口感不稳定的可执行做法

核心思路：**把"口感"和"坏果"拆成可验收的指标，写进采购标准和供应商合同，用量化门槛替代"看着不错"**。

## 一、先定标准，再谈采购

1. **按品类定"可接受区间"而非单一等级**：糖度（如柑橘可溶性固形物≥11°Brix）、硬度、单果重区间、着色度、果径，每项给出下限和上限。口感不稳定往往不是"不够甜"，而是同一批货糖度跨度过大，所以**要同时控均值和控制波动幅度**。
2. **明确"坏果"定义**：腐烂、霉变、机械伤、虫眼、裂口、软塌分别计数，不要笼统说"次果"。定义越细，验收和索赔才有依据。
3. **定义"口感不稳定"的判定**：抽样测糖+试吃打分（如酸甜比、化渣度、香气），设合格率阈值，比如抽检合格率低于 90% 拒收或折价。

## 二、供应商与产地管理

- **优选有分级线的供应商**：能提供糖度分选、重量分选记录的，口感一致性天然更好；小散农户便宜但批次波动大，适合做低价引流品而非主推品。
- **锁定产区与采摘窗口**：同一品种不同海拔、不同成熟期口感差异大，合同中约定产区范围和采摘成熟度标准。
- **一主两备**：主供应商之外保留备选，避免单一产地遇雨、遇灾时被迫收次货。
- **要求提供批次信息**：采摘日期、产地、分级结果、农残检测，随货同行，便于追溯和评价差时定位问题批次。

## 三、采后与物流环节（坏果大头在这里）

- **采后预冷和冷链**：易腐品类（浆果、荔枝、桃）要求采摘后尽快预冷，运输全程温控，合同中写明温度区间和断链责任。
- **包装按品类设计**：单果网套/托盘防挤压，浆果用透气硬盒，避免"箱子好看但果子互相压"。
- **到货抽检制度化**：每批按比例开箱抽检，记录坏果率、糖度、软硬度，形成供应商评分档案，长期用数据淘汰不稳定供应商。
- **控制采购批量与周转**：线上订单波动大，宁可小批量高频补货，也别一次压大量库存导致尾货变坏果。

## 四、把风险前移到定价和承诺

- **按实测分级定价**：糖度/果径达标的走主推，边缘批次做特价或组合装，不要混装按统一标准卖——混装是差评高发点。
- **详情页写清口感区间和储存建议**，管理预期；对易损品类设置合理的售后规则，减少"口感不符预期"类差评。

## 五、最小可落地的起步动作

如果资源有限，先做三件事：**① 每品类一张验收卡（糖度、果径、坏果率阈值）；② 每批到货抽检并记录；③ 按供应商月度坏果率和差评归因打分，末位淘汰。** 这三步成本低，但能显著压缩坏果和口感波动。
