要固定，但不要只固定一个产地/一个批次。更稳妥的做法是：**固定“标准”和“主供+备供”结构，而不是把采购锁死在一个产地或一个批次上。**

可以这样落地：

1. **先固定原料标准，而不是先固定产地**
   - 对水果设定可验收指标：糖度、酸度、香气、出汁率、果肉状态、成熟度、农残检测、冷链温度、到货损耗率。
   - 例如柠檬可约定糖酸比范围、单果重量范围、表皮缺陷比例；草莓约定成熟度、软烂率、香气。产地只是来源，标准才是口味稳定的核心。

2. **固定“主产地/主批次+备选”**
   - 主供占60%—80%，备供占20%—40%，避免单一产地减产、涨价或风味突变时断供。
   - 同一产品尽量固定品种和加工形态，比如固定“某品种冷冻果浆/果茸”比固定“某地鲜果”更容易稳定口味。

3. **按批次做小样和留样**
   - 每批到货先做杯测/试饮，记录糖酸度、香气、色泽、出杯表现。
   - 留样对比上一批，设定可接受偏差；超差就调整配方、拼配或退货。
   - 对鲜果波动大的品类，优先用“鲜果+冷冻果浆/浓缩汁”组合做口味锚定。

4. **合同里写清楚波动处理机制**
   - 约定验收标准、抽检比例、退货条件、批次追溯。
   - 约定主供不能随意换品种/换产区；换批次需提前送样确认。
   - 价格随行就市可以谈，但风味标准不能跟着价格漂。

5. **门店端做配方弹性**
   - 给每款水果饮品设糖度/酸度微调区间和标准出杯SOP。
   - 高峰期用稳定形态原料打底，鲜果做风味增强，而不是完全依赖鲜果。

结论：**要固定产地和批次的“稳定性管理”，但采购策略上应固定标准、固定主供、保留备供、按批验收。** 只固定一个产地或一个批次，短期稳、长期风险大；完全不固定，则口味和成本都不可控。
