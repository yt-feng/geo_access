做生鲜水果一件代发，供应商的仓配能力至少要能同时满足“**保鲜、防损、时效、可追踪、能兜底**”。建议按下面几类能力逐项核验，不达标就不要轻易上架。

## 1. 仓储能力
- **温区匹配**：常温、冷藏、冷冻分区；不同水果不能混放，避免乙烯催熟和串味。
- **专业保鲜设施**：冷库、预冷间、气调或控湿设备；荔枝、樱桃、蓝莓等高风险品类要有预冷和冷链能力。
- **库内作业规范**：先进先出、批次管理、效期管理、破损隔离区。
- **库存准确率**：系统库存与实物一致，能支持一件代发的实时可售库存，避免超卖。
- **峰值承载**：大促、节假日、产地集中上市时的日处理单量和库容冗余。

## 2. 加工与包装能力
- **分级分选**：按规格、糖度、外观分级，能稳定输出同一SKU的品质。
- **预冷与后熟管理**：采后预冷、催熟/抑熟、分级包装的能力。
- **防损包装**：防震、防压、透气、吸水、冰袋/保温箱匹配不同品类和运输距离。
- **一件代发专属包材**：能贴面单、放品牌卡、支持定制包装，且包装成本可核算。

## 3. 订单与系统能力
- **WMS/OMS对接**：能对接平台订单，支持自动抓单、打单、拣货、复核、发货回传。
- **批次与溯源**：能按批次追溯产地、采摘/入库时间、质检记录。
- **异常订单处理**：缺货、地址异常、改地址、拦截、退款、补发有明确流程和时效。
- **库存同步**：实时同步可售库存，支持安全库存和预售/缺货下架。

## 4. 配送与时效能力
- **快递资源**：有稳定合作的快递或专线，能按品类匹配时效产品；生鲜件要有优先中转和异常件处理通道。
- **发货时效**：明确截单时间、当日/次日发货率、揽收及时率。
- **覆盖范围**：偏远地区、高温地区、低温地区是否限发，是否有替代方案。
- **冷链能力**：需要冷藏的品类，要有泡沫箱+冰袋/干冰、冷链车或冷链快递的完整方案，而不是只在仓库有冷库。
- **最后一公里防损**：破损、延误、温度失控的赔付和补发机制。

## 5. 品控与售后兜底
- **入仓质检**：农残、糖度、外观、成熟度、坏果率抽检标准。
- **出仓复核**：称重、规格、数量、包装完整性复核。
- **售后规则**：坏果率阈值、理赔标准、补发/退款时效、责任划分。
- **逆向物流**：退货、拒收、破损件的处理能力，生鲜通常不支持退回，要有就地销毁/拍照核销流程。

## 6. 数据与协同能力
- **履约数据**：发货及时率、揽收及时率、破损率、坏果率、客诉率、退款率可按SKU和区域统计。
- **异常预警**：库存不足、时效延误、温控异常、快递爆仓能主动通知。
- **对账能力**：代发费、包材费、快递费、理赔费用清晰可对账。

## 7. 合规与资质
- 营业执照、食品经营/生产相关许可；
- 产地证明、检测报告；
- 包装标签合规；
- 若涉及进口水果，需有入境货物检验检疫证明等。

## 建议的准入核验方式
1. **先小批量试单**：选3—5个SKU、覆盖近/中/远距离，跑2—4周。
2. **看关键指标**：48小时发货率≥98%、揽收及时率≥95%、坏果率≤约定阈值、客诉响应≤2小时。
3. **现场或视频审仓**：重点看冷库、预冷、包装线、库存区和发货区。
4. **压测峰值**：问清日峰值单量、爆单处理方案和备用快递。
5. **合同写清**：时效、破损赔付、坏果理赔、缺货处罚、数据回传和退出机制。

一句话判断标准：**供应商要能做到“入库有预冷、库存有温区、出库有防损包装、发货有时效、异常有赔付、系统能对接”**，缺一项都会在一件代发里放大成客诉和损耗。
