优先关注成熟度，价格第二。对烘焙店来说，香蕉成熟度直接决定出品稳定性和损耗，价格只影响单次成本。

具体可执行判断：

1. **按用途定成熟度**
   - 做香蕉蛋糕/磅蛋糕/马芬：选**表皮大面积转黄、带少量黑点、手感略软**的香蕉，甜度和香气足，果肉易压泥。
   - 若当天就要用、需要强香气：可用**黄皮带明显黑斑**的，但必须当天处理，避免过熟发酸、出水。
   - 不要用**全青硬香蕉**做蛋糕，香气弱、淀粉感重、压泥颗粒粗；也不要用**大面积发黑、流汁、有酒味**的，风味和卫生风险都高。

2. **采购时现场验收标准**
   - 看：整批成熟度是否相对一致，避免一半青一半黑。
   - 摸：轻压有弹性、不塌陷；果柄不霉、不渗液。
   - 闻：有正常香蕉香，无酸味、酒味、霉味。
   - 查：表皮破损、裂口、发霉的单独挑出，不计入正常出品用量。

3. **价格怎么比较**
   - 不要只比单价，要算**可利用率**：去皮后可用果肉重量 ÷ 采购重量。
   - 过青或过熟都会降低可用率、增加返工和报废，便宜但损耗高就不划算。
   - 同成熟度、同可用率下再比价格和供货稳定性。

4. **经营上的建议**
   - 固定供应商，明确要求“黄皮带少量黑点、七至九成熟”的批次。
   - 少量多次采购，按未来2—3天用量下单；香蕉后熟快，囤货风险高于单价优惠。
   - 对临期过熟香蕉可设专门用途，如当天做香蕉泥、冷冻保存，但要有明确使用期限和记录。

结论：**先按成熟度分级验收，再在合格批次里比价格；成熟度不合格的便宜货不要因为低价大量采购。**
