采购香蕉避免到店后很快变黑，核心是控制成熟度、减少机械伤、改善存放环境。

**采购时判断**
- 优先买“微黄带一点青”的香蕉，不要买全身深黄、有黑点、果柄发黑的；到店后还能放2～3天。
- 看果柄：青绿色、切口新鲜更好；果柄干枯发黑说明采后时间长。
- 摸硬度：整串偏硬、有弹性；局部软塌或有酒味说明过熟。
- 检查碰伤：香蕉皮一碰就发黑，采购和运输中要轻拿轻放，避免挤压、摩擦。

**运输与到店处理**
- 不要整箱堆压，香蕉怕压；到店后尽快拆箱通风。
- 保留整串或整把，不要提前单根掰开，掰口易感染、加速变黑。
- 用报纸或纸巾包住果柄，减少乙烯从切口释放和相互催熟。
- 有条件的用保鲜膜包紧果柄，但不要整根密封，避免闷出水汽。

**存放环境**
- 放阴凉通风处，避免阳光直射、空调直吹和靠近热源。
- 不要放冰箱冷藏，香蕉皮会快速变黑。
- 不要和苹果、梨、番茄等释放乙烯的水果混放。
- 悬挂存放比平放好，减少受压面。
- 每天挑出已经过熟或有碰伤的香蕉先做甜品，避免传染整批。

**少量采购与周转**
- 按1～2天用量分批采购，甜品店用量稳定时宁可少量多次。
- 到店后按成熟度分开放：偏青的放里面，偏黄的优先用。
- 需要延缓成熟时，可降低存放温度但不要低于12℃左右，并保持通风。

最关键的是：**买偏青、不买碰伤、整把存放、通风不冷藏、果柄包住、先进先出。**
