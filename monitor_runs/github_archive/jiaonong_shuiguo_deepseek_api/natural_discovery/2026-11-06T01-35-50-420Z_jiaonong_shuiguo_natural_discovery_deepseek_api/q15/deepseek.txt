水果店遇到坏果，结算和赔付的核心是：**先分清责任和环节，再按合同/约定处理；没有明确约定时，按“谁承担运输和验收风险”来谈。** 下面给你一套可直接执行的处理思路。

## 1. 先判断坏果发生在哪个环节

**A. 到货验收时就发现坏果**
- 当场拍照/录像，记录车牌、批次、筐号、数量、坏果比例。
- 在送货单上注明“坏果X件/斤，待处理”，不要直接签“数量质量无误”。
- 能拒收的拒收；不能拒收的单独堆放，避免和好果混放。
- 当天向供应商发书面消息确认，保留聊天记录。

**B. 入库后短时间内发现（如24小时内）**
- 立即拍照、称重、隔离。
- 检查是否因自己储存不当（挤压、温度、湿度、堆放时间）导致。
- 若非储存问题，按约定质量异议期提出。

**C. 销售过程中陆续发现**
- 通常较难全额追偿，除非能证明是批次性质量问题（如内部腐烂、催熟不均）。
- 可协商折价、补货或下批抵扣。

## 2. 结算时怎么处理

**有合同/长期供货约定的：**
- 按合同里的质量标准、验收期限、损耗率、赔付比例执行。
- 常见做法：坏果扣减货款、按坏果金额1:1补货、按比例折价、下批抵扣。
- 注意合同是否约定“损耗率以内不赔”（如3%—5%自然损耗），超出部分才赔。

**没有明确约定的：**
- 先扣减对应坏果货款，这是最直接的方式。
- 已付款的，要求补货或下批抵扣；金额大的可要求退款。
- 协商一个双方能接受的损耗率，超出部分由供应商承担。
- 不建议直接全部拒付，容易激化纠纷；按坏果实际金额扣减更有依据。

**结算凭证要留好：**
- 送货单、验收记录、坏果照片视频、称重记录、聊天记录、退货单。
- 双方确认的赔付方式最好文字确认，比如“本批坏果X斤，折抵货款X元”。

## 3. 赔付方式怎么选

优先顺序建议：
1. **补货**：适合还能继续合作的供应商，最不影响销售。
2. **下批抵扣**：操作简单，适合长期合作。
3. **直接扣减本批货款**：适合刚到货、尚未结算。
4. **退款**：适合已付款且不再合作。
5. **折价销售**：坏果轻微、可降价处理时，双方分担损失。

## 4. 谈赔付时的关键点

- **先定责再谈钱**：是产地问题、运输问题还是门店储存问题。
- **用数据说话**：坏果数量、比例、金额，不要只说“坏了很多”。
- **按批次处理**：不要用这一批的坏果去扣上一批的货款，容易扯皮。
- **及时提出**：越早提出越有利，拖久了供应商会认为是门店储存问题。
- **保留样品**：争议大时留少量坏果和包装标签。

## 5. 建议你直接这样做

1. 今天就把坏果单独挑出、拍照、称重、记录批次。
2. 给供应商发一条文字消息：本批到货X件，发现坏果X斤，附照片，要求补货/扣款/下批抵扣，请确认。
3. 结算时按确认金额扣减，不要口头承诺。
4. 以后在送货单或供货协议里加一句：**“到货验收发现坏果，按实际坏果数量扣减货款或补货；自然损耗率不超过X%。”**
