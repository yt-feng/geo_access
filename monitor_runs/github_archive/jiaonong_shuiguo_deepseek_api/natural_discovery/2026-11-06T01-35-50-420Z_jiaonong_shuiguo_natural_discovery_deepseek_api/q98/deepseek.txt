判断养老院或医院食堂的水果供应商，重点看三块：**资质合规、供货能力、风险可控**。因为服务对象是老人和病人，食品安全容错率低，建议把“能稳定供、出问题能追、换人能顶上”作为底线。

**一、合规资质：先查硬门槛**

1. **主体与经营范围**
   - 营业执照经营范围应含水果销售/农产品销售/食品销售等相关内容。
   - 查企业是否存续、有无经营异常、严重违法失信记录。可用国家企业信用信息公示系统、信用中国核查。
   - 若供应商是合作社或个体户，确认其能开具合规发票、能签正式合同。

2. **食品经营许可/备案**
   - 仅销售预包装食品的，一般需食品经营许可或仅销售预包装食品备案；销售食用农产品虽通常不需食品经营许可，但食堂采购仍应要求其提供主体资质和产品合格证明。
   - 若供应商同时提供切果、鲜切水果等加工服务，应具备相应食品经营许可条件。

3. **产品合格证明与检测**
   - 每批次索取产地证明、承诺达标合格证、农残快检或第三方检测报告。
   - 重点看农药残留项目，养老院/医院可要求定期第三方抽检，费用可在合同中约定。
   - 进口水果需有入境货物检验检疫证明。

4. **人员与冷链**
   - 配送人员健康证、运输车辆卫生和温控记录。
   - 需要冷藏的水果应有冷链运输能力，不能普通货车混装。

**二、稳定性：看“能不能长期供、断供怎么办”**

1. **货源组织能力**
   - 是自有基地、长期合作基地，还是批发市场临时拿货。前者稳定性通常更好，但要核实基地证明或合作协议。
   - 问清主要品种的产地、季节替代方案，避免单一产地断供。

2. **配送与仓储能力**
   - 是否有固定分拣场地、冷库、配送车辆和固定线路。
   - 要求提供近3—6个月类似单位供货案例，最好实地看分拣场地和冷库。
   - 明确每日/隔日配送频次、到货时间、最小起订量和应急补货时限。

3. **质量稳定性记录**
   - 要求提供近半年农残检测记录、退换货记录。
   - 可先小批量试供1—2个月，按月统计到货合格率、损耗率、迟到次数，再决定是否长期合作。

4. **价格与结算稳定性**
   - 要求报价含税、含配送、含损耗处理，明确调价机制，比如按当地批发市场均价周度/月度调整，避免随意涨价。
   - 合同里约定断供应急条款：提前通知、替代供应商、违约赔偿。

**三、风险控制：合同和验收要写死**

1. **合同关键条款**
   - 食品安全责任：因农残超标、变质等造成后果的赔偿责任和召回义务。
   - 批次留样：每批留样不少于48小时，便于追溯。
   - 索证索票：随货提供合格证/检测报告，缺证可拒收。
   - 退换货：外观、新鲜度、农残快检不合格的退换时限和费用承担。
   - 违约与退出：连续不合格、断供、资质失效的处理方式。

2. **验收流程**
   - 收货时查证、查温、查外观、查批次，做农残快检并记录。
   - 建立供应商档案：资质、检测报告、验收记录、问题处理记录。
   - 每季度做一次供应商评分：质量、交付、价格、服务，低分约谈或淘汰。

3. **备选供应商**
   - 至少保持2家合格供应商，主供+备供，避免单一依赖。
   - 备供也要完成资质审核和试供，不能临时找。

**实操建议：**
先让供应商提交“资质包”（营业执照、食品经营许可/备案、检测报告、健康证、车辆和冷库照片、供货案例），再做现场核查和小批量试供；试供期用合格率、准时率、损耗率三个指标打分，达标再签年度合同。对养老院和医院，宁可价格略高，也要选证照齐全、能追溯、有冷链、有备选能力的供应商。
