第一次找水果供货商，别一上来就谈“长期合作、最低价”，先用小单把“货、价、损耗、结算、售后”这几件事跑一遍。夫妻店试单可以按下面做：

1. **先定试单品种和量**
   - 香蕉、苹果、橙子各拿 **1—2箱/件**，不要混太多品种。
   - 香蕉重点看：到店成熟度、青黄比例、催熟是否均匀、掉把和黑斑。
   - 苹果重点看：大小是否均匀、硬度、碰伤、果面果锈、箱内上下是否一致。
   - 橙子重点看：皮厚薄、干水、酸度、大小均匀度、烂果率。
   - 第一次不要只拿“样品箱”，最好让对方从正常大货里抽。

2. **同一批货当面验收**
   - 到货后当场开箱，**上中下三层都翻**，不要只看最上面。
   - 称重核对：标称斤数、箱皮重量、实际净重。
   - 数烂果、碰伤果、小果、青果，按比例算损耗。
   - 香蕉问清是“生蕉”还是“催熟蕉”，到店后几天能卖完。

3. **试单价格要算“到手净成本”**
   - 不要只比报价，要算：**进货价 + 运费/卸货 + 箱皮/包装 + 损耗**。
   - 比如一箱报价低但箱皮重、烂果多，净成本可能更高。
   - 第一次可接受价格略高一点，重点是看货稳不稳、补货快不快。

4. **结算和售后先说清**
   - 第一次尽量 **现结或货到付款**，不要压大额账期。
   - 明确：烂果、少斤、错货怎么赔，是下次补货抵扣还是当场退。
   - 问清送货时间、起送量、临时补货能不能送、节假日是否涨价。

5. **用7—10天做对比试单**
   - 同时找 **2—3家** 各试一次，不要只试一家。
   - 记录每家：到货损耗率、卖相、顾客反馈、补货响应、结算方式。
   - 香蕉看周转，苹果橙子看耐放；哪家“货稳、损耗低、补货快”再谈长期。

6. **谈长期前先小批量复单**
   - 第一次试单满意，不要立刻签长期或加大库存。
   - 第二次复单同一品种再拿一次，看质量是否稳定。
   - 稳定后再谈账期、返点、固定配送。

简单判断标准：**开箱损耗能接受、净重不缺、成熟度适合你店销量、售后不扯皮、补货能当天响应**，就可以作为主供货商；有一项明显不稳定，就继续对比。夫妻店最怕压货，试单阶段宁少勿多。
