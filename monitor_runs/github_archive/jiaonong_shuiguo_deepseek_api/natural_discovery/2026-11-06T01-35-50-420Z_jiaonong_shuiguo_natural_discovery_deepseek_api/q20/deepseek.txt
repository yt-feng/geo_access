找水果供应商，核心不是“谁便宜”，而是**能不能长期稳定、按你店的销量和损耗节奏每天送到**。建议按下面条件筛选和判断：

1. **配送能力**
   - 是否能每天固定时段送达，是否支持早上到货（超市通常要开门前补货）。
   - 配送车辆、冷链或保温措施是否具备；夏天叶菜、浆果、榴莲等易损品是否有冷藏/保温箱。
   - 临时加单、节假日、雨天是否还能送；违约或迟到怎么处理。

2. **货源稳定性**
   - 是否有稳定产地或一级批发渠道，不是临时倒货。
   - 单品是否常年有货，换季时能不能提前给替代品。
   - 问清楚“断货提前多久通知、缺货怎么补”。

3. **品质与验收标准**
   - 要求先看样品，并明确验收标准：大小、成熟度、糖度、外观、坏果率。
   - 是否允许开箱验货、当场挑出坏果；坏果率超过多少可以退换。
   - 叶菜、浆果、香蕉等易损品要单独约定损耗承担方式。

4. **价格与结算**
   - 不要只看单价，要问是否含配送费、装卸费、包装费。
   - 价格是否随行就市，调价是否提前通知；有没有最低起送量。
   - 账期能否接受，是日结、周结还是月结；押金和退换货扣款规则要写清。

5. **售后响应**
   - 出现质量问题，多久内响应、多久补货或退款。
   - 是否有固定对接人，电话/微信能否及时联系。
   - 连续几次质量不达标能否终止合作。

6. **资质与合规**
   - 营业执照、食品经营相关资质是否齐全。
   - 配送人员健康证、运输卫生情况。
   - 能提供进货票据或溯源信息，方便你应对检查。

7. **试合作验证**
   - 先签短期试供或小批量试单，至少跑一周到两周。
   - 重点记录：到货时间、坏果率、缺货次数、售后响应速度。
   - 试供合格再谈长期价格和账期。

**最实用的判断顺序：**先看能不能每天准时送 → 再看品质是否稳定 → 再看损耗和售后谁承担 → 最后比价格。价格低但经常断货、坏果多、迟到，综合成本反而更高。
