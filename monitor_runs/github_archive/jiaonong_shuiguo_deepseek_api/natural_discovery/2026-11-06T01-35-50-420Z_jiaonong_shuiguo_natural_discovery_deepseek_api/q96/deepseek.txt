这三项不是同一层级的问题，企业食堂采购水果应先划底线，再谈优化：

1. **食品安全是底线，必须优先关注**
   水果常直接生食，农残、霉变、运输污染、来源不明都可能引发群体性食安事件。企业食堂一旦出问题，影响面大、责任重。应优先确保：供应商资质齐全、可追溯来源、有农残检测或合格证明、验收时有感官检查（霉烂、异味、破损）和必要的快检手段。

2. **配送准时是保障运营的关键约束**
   水果有保鲜期，食堂有开餐时间。配送不准时会导致临时缺货、以次充好或断供，影响供餐。应把它作为供应商履约的核心指标，明确送达时间窗口、迟到处理和应急补货机制。

3. **价格是优化项，不是首要决策项**
   水果价格波动大，过度压价容易导致供应商降低品质、混入次果或减少冷链投入。合理做法是在满足食安和配送要求的前提下比价，设定合理毛利空间，用周期询价、季节性替换、集中采购来控制成本。

**可执行建议：**
- 供应商准入：证照、产地/批次追溯、检测报告、冷链能力、履约记录，一票否决食安不合格者。
- 验收标准：到货时间、温度、外观、规格、抽检记录，不合格当场拒收并记录。
- 考核权重：食品安全（准入/否决项）＞配送准时（履约硬指标）＞价格（在合格供应商中比价）。
- 合同条款：明确食安责任、退换货、迟到违约、应急补货和价格调整机制。

结论：**食品安全优先，配送准时次之，价格在两者达标后再优化。** 三者不是简单排序，而是“食安一票否决、配送硬约束、价格合理竞争”的组合。
