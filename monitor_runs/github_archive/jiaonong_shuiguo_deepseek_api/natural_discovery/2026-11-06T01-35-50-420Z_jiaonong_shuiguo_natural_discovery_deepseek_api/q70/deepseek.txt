对批发商来说，坏果责任的核心是“把损耗从模糊风险变成可举证、可扣款、有时限的合同义务”。合同里建议这样写：

1. **明确合格标准**
   - 写清品种、等级、单果规格（如重量/横径）、糖度/成熟度区间、允许缺陷类型。
   - 用“坏果/烂果/霉变/机械伤/冻伤”分别定义，并约定计数口径：按个数还是按重量、是否含轻微瑕疵。
   - 约定抽样方法：到货后按批次随机抽几箱、每箱抽多少、以抽样坏果率推算整批，或全检。

2. **约定到货验收与异议期**
   - 货到后买方在合理时限内（如24—48小时，冷链货可缩短）验收并书面/拍照提异议。
   - 逾期未提异议视为验收合格，但隐蔽瑕疵（如内部霉变）可约定更长发现期。
   - 验收时双方在场或允许卖方视频复验；单方拍照+称重记录可作为初步证据。

3. **坏果率阶梯责任**
   - 设“自然损耗/免赔率”，如坏果率≤3%买方自担；3%—8%按坏果重量扣款；＞8%可拒收该批或要求换货。
   - 扣款公式写死：扣款=该批坏果重量×单价×系数，或直接按坏果重量从货款中扣除。
   - 超过约定上限（如10%）买方有权整批退货，运费/装卸费由卖方承担。

4. **责任主体与费用承担**
   - 明确运输方式、温控要求、装车责任方。若因冷链断链、野蛮装卸导致坏果，由责任方承担。
   - 约定退换货的运费、分拣费、仓储费、销毁费由谁出；因坏果导致买方对下游违约的，是否赔偿及上限。

5. **通知与举证流程**
   - 买方发现坏果后多少小时内通知卖方，附照片/视频、批次号、称重单、抽样记录。
   - 卖方多少小时内回复或到场复验；逾期视为认可买方记录。
   - 约定第三方检测机构（如当地质检/冷链协会）作为争议鉴定方，费用由责任方承担。

6. **货款结算与扣款权**
   - 明确买方有权直接从应付货款中扣除坏果赔款，无需另行诉讼。
   - 若已付全款，约定卖方在几日内补付或下批货款抵扣。

7. **免责与不可抗力**
   - 不可抗力导致的坏果可免责，但卖方需及时通知并提供证明；不可抗力不免除已发生的温控管理义务。

8. **争议解决**
   - 约定管辖法院或仲裁机构，优先选买方所在地，降低维权成本。

实操上，建议把“验收标准+抽样方法+异议时限+扣款公式”做成合同附件，比正文一句话更管用。同时保留每批到货的开箱视频、称重照片和温度记录，否则条款再细也难执行。
