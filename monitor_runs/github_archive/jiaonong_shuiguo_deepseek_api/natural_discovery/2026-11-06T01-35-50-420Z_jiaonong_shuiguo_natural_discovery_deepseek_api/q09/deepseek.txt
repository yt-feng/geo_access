旺季怕断货，和供应商谈之前，先把“能不能稳定供、断了怎么补、出了问题谁负责”这三件事问清楚。建议按下面几组问题提前列好，谈的时候逐条确认，最好落到书面或微信文字里。

**一、供货能力**
1. 旺季你每天/每周能稳定给我供多少量？最低保底量是多少？
2. 你现在主要供哪些品类？哪些品类旺季容易缺？
3. 你的货源是自有基地、产地直采还是批发市场调货？调货的话断货风险多大？
4. 旺季你同时供几家店？给我排第几优先级？
5. 如果我要临时加量，提前多久说能安排？最多能加多少？

**二、价格与结算**
6. 旺季价格怎么定？是锁价、随行就市还是阶梯价？
7. 锁价的话锁多久？超出部分怎么算？
8. 起订量多少？达不到起订量怎么处理？
9. 账期怎么谈？现结、周结还是月结？有没有押金？
10. 运费谁承担？送到店还是自提？

**三、品质与损耗**
11. 到货标准是什么？规格、成熟度、瑕疵率怎么约定？
12. 坏果、烂果、缺斤少两怎么赔？是补货、扣款还是退货？
13. 验收当场发现问题怎么处理？事后发现还认不认？
14. 有没有质检或产地证明？

**四、断货应急**
15. 你断货前会提前多久通知我？
16. 断货了你怎么补？有没有备用货源？
17. 因你断货导致我缺货，有没有补偿或违约责任？
18. 能不能给我留应急库存或优先调货通道？

**五、合作保障**
19. 能不能签书面供货协议？把保底量、价格机制、赔付写进去。
20. 合作初期能不能先小批量试供一两周，看稳定性再放量？
21. 有没有备用供应商推荐，或者你自己有第二货源？

**谈的时候记住三点：**
- **保底量写进协议**，口头承诺不算数；
- **断货赔付和补货时限要明确**，否则旺季只能干着急；
- **别把鸡蛋放一个篮子**，旺季至少备一家备用供应商，哪怕量小。

另外，谈之前先算清自己旺季的日均销量和峰值销量，带着具体数字去谈，比空口问“能不能供”更有底。
