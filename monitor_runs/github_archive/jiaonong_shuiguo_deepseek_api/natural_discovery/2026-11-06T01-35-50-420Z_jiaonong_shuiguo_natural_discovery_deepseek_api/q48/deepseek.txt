判断的核心不是“他说能不能”，而是“能不能把标准、产能、异常处理写进合同并留下验证痕迹”。建议按下面五步做，每一步都有可判断的通过标准。

**1. 先把规格定义到可验收**
- 明确品种/产区、单果重量区间、成熟度（如几成熟）、糖度范围、果径/果形、外观缺陷允许比例、农残检测标准、包装方式（箱规、单箱净重、内衬）、冷链或常温要求。
- 写清验收方法：抽检比例、糖度怎么测、缺陷怎么计数、不合格整批退还是按比例扣款。
- **通过标准**：供应商能逐条确认并书面报价，且愿意把这些写进合同附件；含糊说“都行”“看行情”的，先降级。

**2. 查真实产能和季节供应能力**
- 要求提供产地/合作果园/加工厂信息、日均加工或出货能力、当前服务客户类型和大致采购量、旺季最大日供量。
- 关键问一句：**“我们的日峰值需求占你该品类日出货量的多少？”** 超过30%就要警惕单一供应商依赖。
- **通过标准**：能给出可核验的产地和产能说明，且愿意接受突击或视频验厂；只给贸易商名片、说不清货源层级的，稳定性通常较差。

**3. 用小批量试单验证“按规格、按时间”**
- 先下2—4周试单，覆盖至少一个正常周和一个需求高峰周。
- 记录四项：到货准时率、规格合格率、单箱净重偏差、异常响应时间。
- **通过标准建议**：准时率≥95%，规格合格率≥95%，净重偏差在约定范围内，异常2小时内响应、24小时内给处理方案。达不到就不要直接放主供。

**4. 看异常处理和历史履约**
- 问三个具体场景：产地暴雨/涨价时怎么保供？规格不达标怎么补货或赔付？冷链断链怎么追溯？
- 要求提供近3个月同类客户供货记录或履约说明；注意不是要商业机密，而是看其是否有稳定客户和赔付意愿。
- **通过标准**：有书面保供方案、有赔付条款、有替代产地或备货机制；只会口头承诺“放心”的，不算通过。

**5. 合同里锁住稳定性和退出机制**
- 写清：规格附件、日/周最低保供量、价格调整触发条件、验收与退换货、违约金、质量事故赔付、账期。
- 设置双供应商：主供70%—80%，备供20%—30%，每季度按准时率和合格率重新分配份额。
- **通过标准**：合同能覆盖“规格—数量—时间—异常—赔付”五件事，且备供已试单合格。

一句话判断：**愿意把规格写细、接受试单考核、能说清产能来源、合同里敢写保供和赔付的供应商，才具备稳定按规格送货的基础；只靠样品和口头承诺的不算。**
