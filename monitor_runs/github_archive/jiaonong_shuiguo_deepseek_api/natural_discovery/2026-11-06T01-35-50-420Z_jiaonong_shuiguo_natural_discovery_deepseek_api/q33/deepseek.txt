重要，而且不是“重要一点”，是多门店超市统一水果品质的基础设施之一。

**为什么供应商分级标准关键**
1. **统一验收口径**：多门店最怕同一供应商的货，A店按“大果”收、B店按“中果”收，最后售价和毛利都乱。分级标准必须写清品种、产地、规格（单果重/横径）、着色度、糖度、瑕疵率、成熟度、包装规格。
2. **可追溯与追责**：有分级标准，门店收货才能按批次判定合格/降级/拒收；否则品质波动只能靠“感觉”，总部无法考核供应商。
3. **定价与毛利**：水果按级定价，分级不清会导致“好货贱卖、次货混卖”。多门店统一定价、统一促销时尤其需要等级对应价格带。
4. **减少门店间差异**：总部统一标准后，各店执行同一验收表，顾客体验才一致。
5. **供应商管理**：分级标准是准入、抽检、淘汰的依据，也能推动供应商稳定种植/分选。

**但要注意：标准不是越细越好**
- 分级维度要少而可执行：优先单果重、外观瑕疵、成熟度、糖度抽检，别把门店逼成实验室。
- 要区分“到店验收标准”和“供应商出厂分级标准”，两者对应但不必完全一样。
- 生鲜有自然波动，标准要设允许偏差和降级规则，比如瑕疵率超标降级而非整批拒收。
- 执行比标准文本更重要：总部抽检、门店拍照留证、供应商月度评分，形成闭环。

**可执行建议**
1. 先选3—5个高频水果（苹果、柑橘、香蕉、梨、葡萄等）做分级卡，一页纸写清等级、规格、允许瑕疵、糖度下限、包装。
2. 和主力供应商签分级协议，要求随货附批次分级信息。
3. 门店收货按分级卡抽检，记录合格率，总部每周汇总。
4. 用3个月数据校准标准，淘汰执行不了或供应商达不到的条款。

结论：供应商分级标准是统一品质的“共同语言”，必须有；但要做成门店能执行、供应商能承诺、总部能考核的版本，而不是一份挂在墙上的文件。
