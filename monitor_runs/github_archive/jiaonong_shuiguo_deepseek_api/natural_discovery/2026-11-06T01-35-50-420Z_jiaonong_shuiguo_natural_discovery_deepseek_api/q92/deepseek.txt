小店做水果，核心不是“品类多”，而是**少SKU、高周转、快止损**。建议按下面几条执行：

1. **先定品类结构：3+3+2**
   - 3个引流款：苹果、香蕉、橙子/柑橘这类耐放、认知高、复购稳的。
   - 3个利润款：当季高毛利水果，如葡萄、小番茄、芒果、猕猴桃，按季节轮换。
   - 2个尝鲜款：只做小份装、小批量，用来测试动销，卖不动就撤。
   - 总SKU控制在8–12个，不要超过15个。单品超过7天动销差就淘汰。

2. **采购按“少量多次”**
   - 叶菜类、浆果类、切果类：每天或隔天补，宁可缺货不压货。
   - 苹果、橙子、柚类：可2–3天一次，但单次量控制在预计销量的1.5倍以内。
   - 香蕉、芒果、猕猴桃等后熟水果：按“青熟搭配”采购，青果占一部分，避免到店即熟过头。
   - 新品首次采购只进1–2箱或1–2个小陈列面，卖3天再决定是否加量。

3. **用陈列面积倒推采购量**
   - 小店水果区若只有1–2组货架，每个单品最多给1–2个陈列位。
   - 单品日销量预估 = 过去7天同品类日均销量 × 1.2，采购不超过2天销量。
   - 畅销品可占60%采购额，利润款30%，尝鲜款10%。

4. **损耗控制抓四个动作**
   - **分级定价**：到店即分“正价、临期折扣、处理”三档，别等烂了才降。
   - **小份包装**：葡萄、小番茄、浆果做小盒装，降低挑选损耗和顾客翻捡。
   - **先进先出**：新货放后排，旧货前排；每天早晚两次翻检，挑出软伤果。
   - **日清机制**：闭店前1–2小时对易损品打折；次日仍卖不动的直接下架做果切或报损，不继续占排面。

5. **设几个硬指标**
   - 水果整体损耗率控制在**5%–8%**以内，叶菜浆果可放宽到10%，超过就砍品类或减采购量。
   - 单品动销率：7天内有5天能卖出视为可保留；连续3天零动销就减量或淘汰。
   - 库存周转：易损水果不超过2天库存，耐放水果不超过4天。

6. **供应商和补货**
   - 优先找本地批发市场或二级批发商，支持小批量、多频次补货。
   - 和供应商约定次品换货或补差，尤其浆果、葡萄这类易损品。
   - 每天记录“进货量、销量、报损量”，一周复盘一次，只保留动销前80%的品类。

一句话：**品类控制在10个左右，采购按2天销量走，易损品日清，连续3天卖不动就砍。** 小店水果赚的是周转和损耗差，不是品类齐全。
