判断“售后响应稳不稳定”，不要只听供应商口头承诺，建议用“先小单验证 + 明确响应条款 + 留痕考核”的方式落地。

**一、先把售后标准写清楚**
采购前在合同或订单备注里约定可考核的条款，例如：
- 到货品质不符、短装、烂损、催熟不均等问题的响应时限：如2小时内回复、24小时内给处理方案；
- 补货/换货/退款的处理时限和责任归属；
- 对接人、备用联系人、节假日值班方式；
- 售后凭证要求：到货拍照、抽检记录、异常单编号；
- 月度考核：响应超时次数、未解决率、重复问题率。

**二、小单试单，主动制造一次售后场景**
先下小批量订单，重点观察：
- 出现1—2次真实异常时，供应商是否按约定时间回复；
- 是否主动给方案，而不是反复推诿；
- 补货是否按时到店；
- 同一问题是否再次发生。

**三、用固定渠道留痕**
不要只靠电话或口头沟通。要求通过微信工作群、邮件或供应商系统提交异常单，保留时间戳。采购可每周统计：
- 平均首次响应时长；
- 24小时解决率；
- 补货及时率；
- 因售后问题导致的缺货/损耗金额。

**四、检查供应商的售后支撑能力**
可实地或视频看：
- 是否有专门售后/客服岗位，还是业务员兼管；
- 是否有备用货源和冷链/仓储能力；
- 对菠萝催熟、香蕉温控等常见问题是否有处理经验；
- 能否提供近期同类商超客户的售后记录（可要求脱敏案例，但不要轻信口头描述）。

**五、设置试用期和退出机制**
前1—2个月设为试用期，把售后响应纳入考核。连续出现“超时未回复”“补货不到位”“同一问题重复发生”，就降低采购份额或切换备用供应商。不要等大单出问题才验证。

**可执行建议：** 先列一张《售后响应考核表》，包含响应时限、解决时限、补换货及时率、异常次数四项；用一笔小单跑一遍完整售后流程，再决定是否放量。
