会，而且香蕉、菠萝这类生鲜对起订量特别敏感。结论先说：**起订量越高，损耗风险通常越大，尤其是香蕉；菠萝次之，但也明显受影响。** 关键不是“能不能订”，而是“订多少能在销售周期内消化掉”。

具体判断可以从这几项看：

1. **香蕉损耗风险最高**
   - 香蕉后熟快，催熟后销售窗口短，堆压、温度波动、表皮擦伤都会加速变黑。
   - 起订量高会带来：库存周转天数拉长、成熟度集中、只能降价处理或报损。
   - 如果门店日均销量不稳定，高起订量很容易造成“前半段不够卖、后半段集中熟过头”。

2. **菠萝损耗相对低，但仍有风险**
   - 菠萝耐储性比香蕉好，但高起订量会带来仓储占地、果心褐变、黑心、机械伤和尾部腐烂等问题。
   - 若销路以整果为主，周转慢时表皮失水、冠芽萎蔫，卖相下降；若做鲜切，切开后保质期更短，起订量高反而增加加工端压力。

3. **真正决定风险的是“周转天数”**
   建议用这个公式判断：
   **可接受起订量 ≈ 日均销量 × 安全周转天数**
   - 香蕉：安全周转天数通常要压得很短，按实际销售节奏控制在几天内更稳。
   - 菠萝：可略长，但也要看仓储条件和销售形式。
   如果供应商起订量明显高于这个值，损耗风险就会上升。

4. **还要看采购频次和补货能力**
   - 高起订量 + 低频补货 = 高风险。
   - 高起订量 + 快速分货/多门店调拨/促销消化 = 风险可控一些。
   - 如果供应商能拆批、混装、按成熟度分档供货，风险会下降。

5. **实操建议**
   - 优先谈**小批量多频次**，或香蕉、菠萝混装凑起订量。
   - 香蕉要求**分成熟度到货**，不要一次全到同一催熟档。
   - 对高起订量做**试单**：先按1—2周实际销量测周转，再决定是否放大。
   - 设置损耗预警线：比如香蕉到货后超过预定周转天数仍未售出，就提前促销或调拨。
   - 把“起订量”折算成“预计损耗成本”再比价，不要只看采购单价。

一句话：**起订量高本身不是问题，问题是它是否超过你的销售周转能力。香蕉要特别谨慎，菠萝可适度放宽，但都建议用小批量试单验证后再放量。**
