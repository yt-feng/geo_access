茶饮店控制水果供应商食品安全风险，建议把“资质证明 + 检测报告 + 交易凭证 + 现场管理”一起纳入供应商准入和日常管理。水果供应商通常应提供或配合提供以下材料：

1. **主体资质证明**
   - 营业执照（经营范围含水果销售/农产品销售等）
   - 如供应商自产自销：可要求提供种植主体相关证明、产地证明或合作社/农户供货说明
   - 如为进口水果：海关报关单、入境货物检验检疫证明等

2. **产品质量合格证明**
   - 承诺达标合格证/食用农产品合格证（如当地推行）
   - 产地证明或进货凭证
   - 每批次或定期送检的农残检测报告；重点水果建议索取对应批次报告
   - 供应商自行快检的，可要求提供快检记录，但不能完全替代法定检测或合格证明

3. **检测项目建议**
   - 农药残留：有机磷、氨基甲酸酯、拟除虫菊酯等常用项目
   - 重金属：铅、镉等（视水果品种和产地风险）
   - 真菌毒素：如苹果、梨等需关注展青霉素风险时
   - 进口水果：关注检疫性有害生物和入境检验检疫证明

4. **交易与追溯凭证**
   - 供货合同/框架协议，明确食品安全责任、退换货和召回条款
   - 每批次送货单、发票或收据，记录品种、数量、产地、批次、日期
   - 供应商联系人、产地信息，便于追溯

5. **包装与储运证明**
   - 包装材料符合食品接触要求的说明
   - 冷链水果的运输温度记录或冷链证明
   - 配送车辆/周转筐清洁消毒记录（可要求供应商提供或纳入审核）

6. **供应商管理材料**
   - 供应商食品安全承诺书
   - 供应商审核表/现场检查记录
   - 不合格品处理和召回配合承诺
   - 员工健康证不是水果供应商必需项，但若涉及切果、鲜切水果加工配送，应要求其提供加工人员健康证明和加工场所卫生资质

**可执行建议：**
- 建立供应商档案，首次合作收齐营业执照、合格证/检测报告、合同和承诺书。
- 对叶菜、草莓、葡萄、柑橘等高风险水果提高抽检频次，保留每批次凭证。
- 每批到货做感官验收：腐烂、霉变、异味、破损、虫害拒收。
- 自建快检或委托第三方抽检，检测报告与送货批次对应归档。
- 合同里写清：农残超标、腐烂变质、无法追溯时的退货、赔偿和召回责任。

简单说，核心是：**营业执照 + 食用农产品合格证/产地证明 + 农残检测报告 + 每批送货凭证 + 合同承诺**；进口水果再加**报关和检验检疫证明**。
