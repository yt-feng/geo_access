门店多、单店量小，关键不是找“最便宜的一级批发商”，而是找**能支撑多店小批量、高频补货、品质稳定、账期可控的供货模式**。建议按下面顺序选：

1. **区域配送型供应商/城市仓：优先**
   - 找本地或周边城市有分拣中心、能按门店订单分货、每天/隔天配送的供应商。
   - 适合你的点：多店合并采购形成总量，但由供应商拆分配到各店，单店不用压大批量。
   - 谈判重点：起送量、配送频次、分店分拣费、损耗赔付、缺货补货时效、账期。

2. **产地/一级批发市场“统采统配”**
   - 你公司统一从产地或大市场采购，再委托第三方分拣配送，或自建小中转仓。
   - 适合：水果品类相对集中、门店密度较高、你已有仓储或能租小仓。
   - 注意：单店量小，不适合每个店各自去批发市场采；必须集中采购、集中分拣。

3. **多供应商拼盘，不把鸡蛋放一个篮子**
   - 主力供应商做苹果、梨、柑橘等耐储大单品；本地供应商做叶菜类水果、应季鲜果；少量特色果走产地直发或一件代发。
   - 适合：单店销量不足以支撑单一供应商全品类，但可以按品类拆分。
   - 原则：大单品集中，小品类分散；鲜度要求高的本地化，耐储的跨区采购。

4. **联合采购/集采集配平台**
   - 如果门店分散且单店量小，可加入区域商超联盟、餐超集采平台，或与同区域非竞争门店拼单。
   - 适合：你自身采购量不足以拿到好价格，但多店合并后有一定议价权。
   - 注意：平台品质稳定性参差，要先小范围试单。

5. **产地直发/基地直采：谨慎作为补充**
   - 只适合耐储、标准化程度高、你能消化整批量的单品，比如苹果、柑橘、瓜类。
   - 单店量小、门店多，不建议全品类产地直发，否则分货和损耗压力大。

**不建议的模式：**
- 每个店各自找批发商：价格、品质、账期难统一。
- 纯一件代发做全品类：成本高、鲜度不可控、售后扯皮多。
- 只找一个大供应商包全部水果：单店量小议价弱，容易被压品级或断供。

**落地建议：**
先选1个城市仓供应商+1个本地补充供应商试跑1个月，考核四项：到店准时率、损耗率、缺货率、单店起送满足率。跑通后再扩品类、扩门店。合同里重点写清：按店分拣、坏果赔付、临期/品质不达标退换、节假日报备补货。
