找“少量、每天要、省心”的水果供应商，关键不是找最便宜的，而是找**稳定性高、起订量低、能固定时间送、售后不扯皮**的渠道。建议按以下优先级选：

**1. 首选：本地水果批发市场里做“配送档口”的商户**
- 适合日用量几十斤到一两百斤的餐饮店。
- 找那种本身给周边小店、水果店配货的档口，问清楚：能否每天固定时间送、最低起送量多少、坏果怎么补。
- 优点：价格比零售低，品类灵活，当天可调量。
- 省心要点：固定一个老板，长期合作，让他按你的菜单每天报1—2个替代品种，不要自己天天挑。

**2. 次选：本地生鲜配送平台/B2B食材配送商**
- 如当地的美菜、快驴、菜划算类平台，或区域生鲜配送公司。
- 优点：线上下单、有票据、准时、售后流程化。
- 缺点：起送金额和品类限制较多，小众水果不一定有。
- 适合：水果用量稳定、你不想每天沟通、重视对账和发票的店。

**3. 补充：周边水果店/社区团购团长做“固定日配”**
- 适合每天只要几斤到十几斤的小店。
- 和水果店谈长期价，约定每天上午送，坏果当场换。
- 优点：起订量最低、沟通最方便；缺点：价格略高、旺季可能先保零售。

**4. 不建议作为主渠道：大型电商/社区团购自提**
- 价格有优势，但品质波动大、到货时间不可控、售后麻烦，不适合餐饮每天出餐。

**签约/合作前必须确认这5件事：**
1. 最低起送量和每天截单时间；
2. 固定送达时间段，迟到怎么处理；
3. 坏果、缺斤少两的补货或扣款规则；
4. 是否含税、能否开票、结算周期；
5. 旺季或天气异常时能否保供，提前几天通知。

**最省心的组合建议：**
主供应商选**本地批发市场配送档口**，备选一家**生鲜B2B平台**。每天只让主供报“今日可送清单”，你按菜单选2—3种，避免临时缺货。先试合作1—2周，重点看准时率和坏果率，再决定是否长期固定。
