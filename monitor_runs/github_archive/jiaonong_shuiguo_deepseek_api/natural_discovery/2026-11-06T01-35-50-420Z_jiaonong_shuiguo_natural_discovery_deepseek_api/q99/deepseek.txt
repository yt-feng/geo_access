选择批量配送水果供应商时，建议按“先定需求，再验能力，最后小单试跑”的顺序判断，重点看以下几条：

1. **先明确采购参数**
   - 人数、预算/人、配送频次（每周几次）、配送时间窗；
   - 是否需要切果/果切、独立包装、摆盘、一次性餐具；
   - 公司是否有冷藏条件、前台能否代收；
   - 是否要求发票、对公付款、食品安全资质。

2. **供应商类型选择**
   - **本地水果批发商/配送商**：适合量大、价格敏感，但要确认能否按公司时间配送、是否做售后。
   - **生鲜平台企业购**：履约稳定、发票和售后规范，价格略高，适合行政省心。
   - **果切/下午茶套餐供应商**：适合直接摆台，注意果切食品安全和配送时效。
   - **周边水果店长期合作**：适合小批量高频，谈固定折扣和固定配送时段。

3. **重点核验能力**
   - 是否有营业执照、食品经营相关资质；果切供应商还要看操作间和冷链条件。
   - 是否能提供**到货时间承诺**和**坏果/少件赔付规则**。
   - 是否支持**按份/按盒标准化配送**，避免现场分拣耗时。
   - 是否有企业客户案例，能否接受先小批量试单。
   - 报价是否含配送费、包装费、切果费、税费，避免低价后加项。

4. **试单判断标准**
   - 连续试2—3次，记录：到货准时率、坏果率、重量/份数是否足、包装是否渗漏、售后响应时间。
   - 坏果率建议控制在可接受范围（例如5%以内，具体按品类谈），超出部分补送或退款。
   - 试单通过后再签月度/季度框架价，约定每周菜单和替换规则。

5. **合同或订单里写清楚**
   - 品类、规格、单份克重、数量、配送时间、验收标准；
   - 坏果赔付、临时加单/减单截止时间、发票类型；
   - 食品安全责任和异常处理联系人。

**实操建议**：同时找2—3家本地供应商，用同一份需求单报价，先各试单一次，再按“准时率、品质稳定、售后、价格”四项打分选定主供应商，保留一家备选。这样比只看单价更稳。
