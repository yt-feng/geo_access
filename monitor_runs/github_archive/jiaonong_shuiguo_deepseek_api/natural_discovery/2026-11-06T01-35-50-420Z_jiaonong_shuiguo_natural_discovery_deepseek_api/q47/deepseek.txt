采购香蕉做饮品/甜品，核心原则是**按用途分批采购、以“七成熟左右”为基准，到店后人为控熟**，不要一次全买同一熟度。

**1. 按用途定熟度**
- 饮品打泥/摇杯：选**七成熟**，皮黄带少量绿、捏着略硬但有弹性。太熟打泥易发黑、发酸、挂杯差；太生涩味重、甜度低。
- 甜品装饰/切片：选**七到八成熟**，外形完整、切面不易塌。
- 香蕉奶昔/冰沙若追求自然甜：可少量用**八成熟**，但必须当天用完，且要加酸（柠檬汁/酸奶）防氧化。
- 熟蕉泥做馅料：可用**八到九成熟**，但需控量、当天处理。

**2. 采购验收标准**
- 表皮：黄色为主，允许少量绿尖；无大面积黑斑、无裂口、无霉点。
- 手感：整串捏有弹性，不软塌、不流水。
- 果柄：新鲜不发黑；切口干爽。
- 批次：不要整批同一熟度，按“今天用/2天后用/4天后用”分三档下单。

**3. 到店控熟**
- 未熟蕉：常温阴凉通风存放，不要冷藏；可和苹果/梨同袋催熟，但每天检查。
- 七成熟：常温货架，避免堆压；按先进先出。
- 八成熟以上：立即冷藏或剥皮分装冷冻；冷藏会停熟但皮变黑，果肉仍可用，适合打泥。
- 已剥果肉：加柠檬汁/维C液防褐变，密封冷藏当天用完，或分装冷冻。

**4. 库存与损耗控制**
- 每日盘点熟度，把“快熟过头”的香蕉转到甜品/馅料/员工餐，不要等黑斑再处理。
- 饮品店建议**每次采购2—3天用量**，夏季缩短到1—2天；香蕉损耗高，宁可少量多次。
- 建立简单熟度标签：绿尖/全黄/糖斑三档，分别对应“明天用/今天用/立即处理”。

**5. 避坑**
- 不要买整箱已全黄带糖斑的香蕉做饮品，当天用不完就报废。
- 不要冷藏未熟香蕉，会停止成熟且皮黑。
- 不要用冷冻香蕉直接做装饰，解冻后塌软，只适合打泥。
- 香蕉泥饮品建议现打现卖，氧化变黑快，提前预制要加防褐变措施并限时使用。
