让供应商按“**商家能卖、能算、能判断**”的方式说，重点不是讲品种知识，而是讲清楚：**卖给谁、怎么卖、赚多少、风险多大、怎么进货**。

可以要求供应商按下面这个模板介绍，基本一听就能判断要不要下单：

1. **一句话定位**
   - “这是给水果店做中高端散客的，不是给奶茶店做原料的。”
   - “这个适合做试吃引流，不适合做礼盒。”
   - 先说使用场景，别先报品种名。

2. **对标商家熟悉的品类**
   - “它像菠萝一样好切，但比菠萝甜、不用泡盐水。”
   - “口感接近香蕉的软糯，但比香蕉耐放两天。”
   - “吃法像西瓜，切块卖；客单价能比普通苹果高。”
   - 用商家已知的菠萝、香蕉、苹果做参照，比讲“凤梨释迦”“指橙”更容易懂。

3. **说清楚卖给谁**
   - 家庭日常、小孩零食、办公室下午茶、水果礼盒、餐饮店原料、社区团购。
   - 同时说“不适合谁”，比如“不适合做低价促销，损耗扛不住”。

4. **直接算账**
   - 进货价、建议零售价、毛利空间。
   - 一斤能切几盒、一箱出多少份、损耗大概多少。
   - 例：“一箱10斤，进价60元，能分装20盒，每盒卖8元，不算损耗毛利100元。”
   - 商家最怕听“利润高”，要听“一箱到底赚多少”。

5. **讲操作难度**
   - 要不要催熟、能不能冷藏、切开后能放多久、好不好剥、好不好切。
   - “今天到货明天能卖”还是“要放三天”。
   - “切开两小时变色”这种风险必须提前说。

6. **给试销方案**
   - 先小批量试卖，不要一上来压大货。
   - “先拿一箱，搭配试吃，卖不动我告诉你原因。”
   - 供应商如果能给陈列建议、试吃话术、复购判断标准，商家更容易下单。

7. **用对比表收尾**
   供应商最后给一张简单对比：
   - 对标普通菠萝/香蕉：价格高多少、甜度如何、损耗如何、操作难度如何、适合什么店。
   - 一张纸能看懂，比讲十分钟品种故事有用。

**一句话总结：**  
让供应商少讲“这是什么品种”，多讲“**像什么、卖给谁、一箱赚多少、好不好操作、先拿多少试**”。商家听得懂、算得清、风险小，才容易下单。
