先按“证据 → 环节 → 规则”三步划分，不要一上来就认全责或全推给顾客。

**1. 先固定证据**
- 顾客：坏果照片/视频、开箱时间、外包装和面单、快递签收记录。
- 商家：发货前质检/装箱记录、冷链或常温包装方式、物流时效、同批次其他投诉。
- 关键判断：坏果是**签收时已存在**，还是**签收后因顾客存放不当**扩大。

**2. 按环节划责**
- **商家责任**：发货时已有腐烂、碰伤、未成熟/过熟、包装不足、未按温控要求发货、缺斤少两。一般由商家承担退款/补发/赔付。
- **物流责任**：运输延误、暴力分拣、冷链断链、外箱严重破损导致坏果。商家先对顾客负责，再依据合同向物流追偿；顾客一般不直接找物流。
- **顾客责任**：签收后长时间未取/未冷藏、超时开箱、人为挤压、未按提示存放导致变质。可减轻或免除商家责任，但商家需举证。
- **混合责任**：如商家包装一般 + 物流延误 + 顾客延迟取件，按过错程度和原因力比例分担，常见做法是协商部分退款或补发部分。

**3. 可执行的处理规则**
- 建立“坏果率”标准：如单箱坏果超过约定比例（常见 5%—10%，以商品页/平台规则为准）可整箱退补；低于比例按坏果数量部分赔付。
- 顾客需在签收后合理时间内（如 24 小时内，生鲜通常更短）反馈并提供照片；商家需在商品页明示售后时限和赔付标准。
- 商家不能以“生鲜不支持七天无理由”一概拒绝质量问题；顾客也不能无证据要求全额赔。
- 平台介入时，通常看：商品页承诺、签收时间、坏果照片、同批次记录、物流记录。

**结论**：核心是看坏果发生的时间点和原因。**发货前/运输中造成的，商家对顾客负责；签收后顾客保管不当造成的，顾客担责；双方都有过错的，按比例分担。** 商家对外先售后、再向物流追偿，是最稳妥的处理方式。
