结论：绝大多数餐饮连锁采购水果，优先**中央厨房统一收货**；只有“极短保鲜期+门店现切现用+配送半径大”的品类才考虑门店分开收货。可以按下面的判断标准直接落地。

**一、优先中央厨房统一收货的场景**
- 水果用于中央厨房统一加工：切配、榨汁、果酱、沙拉半成品、甜品装饰标准化。
- 品类相对耐储：苹果、橙子、柠檬、西瓜、哈密瓜、菠萝、冷冻果浆等。
- 门店数量多、单店用量小，需要合并订单拿价格和账期。
- 需要统一验收标准：糖度、规格、农残检测、批次追溯。
- 需要集中质检和退货，避免门店验收能力参差。

**好处**：采购议价强、品质标准统一、食安追溯集中、门店操作简化、损耗集中管理、供应商管理简单。

**二、考虑门店分开收货的场景**
- 极短保鲜期且不适合二次配送：草莓、蓝莓、树莓、鲜切果盒、熟度敏感水果。
- 门店现制饮品/甜品对熟度和新鲜度要求极高，中央厨房配送会增加压伤和时效风险。
- 中央厨房到门店配送半径大、冷链能力不足。
- 单店销量大，直送门店物流成本更低。

**风险**：验收标准不统一、门店收货人手不足、批次追溯分散、供应商对账复杂、退货扯皮多。

**三、推荐落地模式：集中采购+分级收货**
1. **耐储和加工类水果**：中央厨房统一收货、统一质检、统一分拣配送。
2. **极鲜短保类水果**：供应商直送门店，但必须执行总部统一验收标准、统一供应商、统一价格协议、统一拍照留证和批次追溯。
3. **设置验收门槛**：中央厨房配糖度计、农残快检、温控记录；门店只做外观、温度、数量复核。
4. **损耗归属清晰**：中央厨房收货后损耗归中央厨房/配送环节；门店直送收货前损耗归供应商，收货后归门店。
5. **先用小范围试点**：选3—5家门店和2—3个高频水果品类，对比3个月损耗率、客诉率、到店新鲜度和综合成本，再全面切换。

**一句话判断**：要标准化、要议价、要食安追溯，选中央厨房统一收货；要极致新鲜、配送会伤品质，才让门店分开收货，但采购权和验收标准仍应总部集中。
