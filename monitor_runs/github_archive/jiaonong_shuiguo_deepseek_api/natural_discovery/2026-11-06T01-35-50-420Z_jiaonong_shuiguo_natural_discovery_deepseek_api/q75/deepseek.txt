小批量试单的核心不是“先进点货卖卖看”，而是用最低成本验证四件事：**品质稳定性、供货履约、结算信用、损耗可控**。建议按下面设计。

## 一、先定试单目标
第一次合作不要追求低价和爆量，重点验证：
1. 到货品质是否与样品/承诺一致；
2. 交期是否准时、缺货时是否提前沟通；
3. 包装、规格、净重是否稳定；
4. 售后是否认账、处理是否及时；
5. 结算条件是否按约定执行。

## 二、试单规模怎么定
建议用“**单品类、小批量、短周期、多频次**”：
- **品类**：先选1—2个你熟悉、周转快、损耗相对可控的品种，不要一次上多个新品；
- **数量**：按你正常单次采购量的 **10%—20%**，或按 **3—5天销量** 备货；
- **频次**：连续试 **2—3次**，比一次大单更能看出稳定性；
- **金额**：控制在你可承受损失范围内，建议单次不超过日常采购预算的20%。

## 三、试单前必须确认的条款
合作前用文字确认，别只口头说：
- 品种、等级、规格、产地、净重、包装方式；
- 单价、是否含税含运费、卸货费谁承担；
- 交货时间、交货地点、迟到或缺货怎么处理；
- 验收标准：外观、成熟度、大小、瑕疵率、腐烂率上限；
- 破损/腐烂/短斤少两的赔付比例和时限；
- 结算方式：建议首次**货到验收合格后付款**，至少保留部分尾款；
- 退换货：哪些情况可退、运费谁出、多久内提出。

## 四、验收要做记录
每次到货当场做三件事：
1. **抽检**：随机开箱，记录规格、净重、瑕疵率、腐烂率；
2. **拍照留证**：整车、包装、开箱、问题品；
3. **填验收单**：到货时间、数量、合格率、扣款/退换结论，双方确认。

建议设一个简单底线，例如：腐烂率超过约定比例即扣款或退货；净重短缺超过约定误差即按实结算并记录。

## 五、用三次试单做判断
- **第1次**：看品质和交期是否达标；
- **第2次**：看稳定性，是否同一标准；
- **第3次**：故意给一个稍紧的交期或小增量，看响应能力。

三次都稳定，再逐步放量到正常采购的30%—50%，不要一次跳到全量。

## 六、付款和风险控制
- 首次合作优先 **现结或货到付款**，不建议预付大额；
- 不押太多库存，试单商品尽快周转；
- 保留样品和验收记录；
- 合同或订单里写清违约和赔付，哪怕是微信文字确认也要留存。

## 七、什么情况直接停止合作
出现以下情况建议不放大：
- 连续两次品质明显低于样品；
- 缺货不提前通知、交期随意；
- 短斤少两或包装规格不稳定；
- 售后推诿、不认验收记录；
- 要求大额预付但不愿给明确赔付条款。

**一句话方案：选1—2个熟悉品种，按3—5天销量下2—3次小单，货到验收付款，每次记录品质/交期/损耗，三次稳定后再逐步放量。**
