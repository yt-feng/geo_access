食堂采购香蕉要防“熟过头”，核心是**控制采购成熟度 + 分批到货 + 后熟管理 + 快速周转 + 次熟果再利用**，不要等香蕉全黄了才处理。

可直接执行的做法：

1. **采购时明确成熟度标准**
   - 要求供应商供“微黄或青黄”香蕉，不要全黄、带黑斑的。
   - 到货验收看：果皮青绿到浅黄、果柄完整、无大面积黑斑、无软塌、无酒味。
   - 合同里写清验收标准：黑斑面积超过多少、软化比例超过多少可拒收或折价。

2. **分批到货，不要一次囤太多**
   - 按食堂日均用量拆成每周2—3次到货。
   - 每次到货量控制在2—3天用量内，避免后熟集中爆发。
   - 节假日前后按实际就餐人数下调采购量。

3. **到货后按成熟度分级存放**
   - 青黄果：常温通风存放，可略催熟，放在阴凉处。
   - 浅黄果：优先发到窗口或早餐使用。
   - 全黄果：冷藏或尽快加工，不宜再常温久放。
   - 香蕉不宜低温久藏，冷藏后易表皮变黑，但果肉短时间可用；适合尽快做成香蕉粥、香蕉饼、奶昔、烘焙等。

4. **先进先出，设“熟度看板”**
   - 库房每天标注批次、到货日、成熟度。
   - 先熟先出，窗口优先消耗全黄果。
   - 每天下午检查一次，把次日会过熟的香蕉提前转到加工间。

5. **把“过熟香蕉”转成加工品**
   - 香蕉牛奶、香蕉燕麦粥、香蕉松饼、香蕉面包、香蕉派等。
   - 食堂可设“香蕉加工日”，把表皮有黑点但果肉未变质的香蕉及时消耗。
   - 注意：果肉发酸、有酒味、渗液、霉变的不得再用。

6. **用量与菜单联动**
   - 香蕉作为加餐或水果时，按实际就餐人数精确下单。
   - 连续多日有香蕉时，菜单里穿插香蕉加工品，平滑消耗。
   - 建立近7天用量记录，按趋势采购，不凭经验拍脑袋。

7. **供应商管理**
   - 要求供应商按约定成熟度分批配送。
   - 对频繁送全黄果的供应商扣分或调整订单。
   - 可协商“熟度不达标退换”条款。

最有效的组合是：**只进微黄果、2—3天量分批到、每天按成熟度分流、全黄果当天转加工**。这样能把熟过头浪费压到较低水平。
