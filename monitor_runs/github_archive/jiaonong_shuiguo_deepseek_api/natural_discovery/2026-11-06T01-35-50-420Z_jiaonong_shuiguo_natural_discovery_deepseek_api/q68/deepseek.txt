判断供应商能不能按时到车，核心不是听承诺，而是看“可验证的发车证据 + 风险兜底”。可按下面顺序做：

**1. 下单前先筛供应商**
- 优先选合作过、有稳定档口/基地的供应商，新供应商先小单试。
- 问清：香蕉是自有基地、代办收储还是市场调货。调货型供应商准时率通常更不稳定。
- 看历史记录：近1个月有没有因雨季、堵车、装工不足延迟；让他提供最近几车到货时间记录。

**2. 合同里把“到车”定义清楚**
- 写明具体到车日期、时间段、卸货地点，避免“大概几号”。
- 约定延迟违约金或补货责任，例如每延迟一天扣款、超过24小时可取消并索赔。
- 明确是“装车发运”还是“到达市场”，很多纠纷出在只承诺发车。

**3. 发车前要关键证据**
- 装车前：确认采摘/催熟进度、装车工人和车辆是否已定。
- 装车时：要求拍装车视频、车牌号、司机电话、装车单、过磅单。
- 发车后：要定位或高速通行记录；长途运输至少每半天更新一次位置。
- 到车前半天：确认司机是否已下高速、预计到达时间。

**4. 识别高风险信号**
出现以下情况要警惕：
- 反复说“明天一定装”但给不出车牌和装车时间；
- 报价明显低于市场，可能靠拖车或临时换货；
- 以“雨大、工人少、车难找”为由拖延，但没有替代方案；
- 不肯写违约条款，或只愿意口头保证。

**5. 做备份方案**
- 同一到货周期保留1家备选供应商，先问好档期。
- 对关键档口，可要求供应商预付部分延迟保证金，或你方留部分尾款到车后结。
- 销售端提前预留半天到一天缓冲，不要把促销档期卡在到车当天。

**一句话判断标准：** 能给出“车牌号+司机电话+装车视频/过磅单+明确到达时间”，且合同有延迟责任的，才基本可信；只给口头承诺的，按不能按时到车管理。
