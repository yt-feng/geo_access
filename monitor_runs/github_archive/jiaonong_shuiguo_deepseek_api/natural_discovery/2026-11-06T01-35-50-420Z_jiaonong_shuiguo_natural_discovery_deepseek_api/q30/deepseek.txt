超市水果到货品相不好，售后流程建议在采购合同或到货验收单里提前写清楚，核心是把“什么算品相不好、多久内提、怎么赔”三件事约定死。

**1. 验收标准和时限**
- 约定到货后开箱验收时限，例如“到货后2小时内完成抽检，24小时内提出书面异议”，超期视为验收合格。
- 明确品相标准：按品种写清楚果径、色泽、成熟度、机械伤、腐烂率、畸形果比例等，最好用“抽样比例”表达，如“抽检100箱，允许轻微机械伤不超过5%，腐烂果不超过1%”。
- 区分“轻微瑕疵可折价接收”和“严重不合格可拒收/退货”两档，避免全凭感觉扯皮。

**2. 异议提出方式**
- 要求书面或系统内提交：照片/视频、批次号、抽检数量、不合格数量、问题描述，缺一不可。
- 约定供应商响应时限，例如“收到异议后4小时内确认，24小时内给出处理方案”，逾期视为认可买方异议。

**3. 处理方式和赔付**
- 分档处理：轻微品相问题按比例折价；严重腐烂、变质、明显不符合约定标准的，拒收或退货，运费和损耗由供应商承担。
- 约定折价计算方式，例如“不合格部分按该批次单价的50%结算”或“按不合格数量直接扣款”，不要只写“协商处理”。
- 明确补货、换货的到货时限，以及逾期补货的违约责任。
- 腐烂类问题要约定是否包含后续扩大损失，例如到货后24小时内发现的腐烂由供应商承担，超过时限的由买方自担。

**4. 证据和结算挂钩**
- 验收照片、视频、抽检记录作为结算附件，未处理完的异议批次暂缓付款或按约定扣款。
- 约定争议解决方式，例如先按抽检结果处理，争议部分送第三方检测或按合同约定的计价规则处理。

**5. 写进合同的关键条款示例**
“乙方所供水果应符合附件《品相验收标准》。甲方应在到货后24小时内完成抽检并书面提出异议，逾期视为验收合格。抽检不合格率超过约定比例的，甲方有权拒收该批次或要求按不合格数量单价50%折价结算；腐烂、变质等严重不合格的，乙方应在24小时内补货或退货，费用由乙方承担。乙方逾期未响应异议的，视为认可甲方处理方案。”

一句话：**把验收时限、抽检比例、分档处理、赔付计算和证据留存写进合同，比事后协商更有效。**
