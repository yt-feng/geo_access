连锁商超选长期水果供应商，评分标准建议按“资格门槛+评分表”两层设计：先把硬性条件设为合格制，避免不合格供应商进入打分；再用百分制评分，权重向长期稳定性、食品安全和履约能力倾斜，而不是单纯比价格。

**一、先设资格门槛（不打分，合格/不合格）**
- 营业执照、食品经营许可证、种植/养殖基地证明或产地证明；
- 近2年无重大食品安全处罚、无严重失信记录；
- 具备冷链运输能力或稳定冷链合作方；
- 能提供农残检测报告、产地证明、可追溯凭证；
- 接受商超的质量标准、退货换货规则和账期；
- 具备一定的日供应量和应急补货能力。

**二、评分表建议（100分）**

| 维度 | 建议权重 | 评分要点 |
|---|---|---|
| 产品质量与食品安全 | 30分 | 农残检测合格率、抽检记录、分级标准执行、口感/外观稳定性、可追溯体系 |
| 供应稳定性与产能 | 20分 | 基地面积/合作果园数量、日均供应能力、旺季保供方案、灾情/减产应对预案 |
| 价格与成本 | 15-20分 | 报价竞争力、价格调整机制是否透明、是否接受锁价/浮动价、运费承担 |
| 冷链与物流履约 | 10-15分 | 冷链车辆/仓储、配送时效、损耗率承诺、缺货补货响应时间 |
| 质量事故与售后 | 10分 | 退换货响应、质量问题赔付标准、客诉处理时限 |
| 企业资质与行业经验 | 5-10分 | 同类商超供货经验、合作年限、荣誉/认证（GAP、绿色食品等） |
| 数字化与管理配合 | 5分 | 能否对接订单系统、提供批次追溯数据、配合商超抽检和审计 |
| 可持续与ESG（可选） | 0-5分 | 环保种植、用工合规、包装减量 |

**三、关键设置建议**
1. **价格权重不宜过高**，建议不超过20分。水果损耗和品质波动大，低价供应商往往履约风险高。
2. **把“可量化承诺”写进评分**，例如：损耗率≤3%、缺货响应≤4小时、农残抽检合格率100%、质量问题24小时内处理。
3. **设置否决项**：出现重大食品安全事故、提供虚假检测报告、连续缺货超过约定次数，直接取消资格。
4. **长期合同建议设“季度/年度复评”**，评分不与一次性招标绑定，而是和履约绩效挂钩，比如年度评分低于80分触发整改或退出。
5. **样品盲测可单独设分**，建议5-10分，由采购、品控、门店代表共同打分，避免只凭书面材料判断。

总体原则：**食品安全和供应稳定性合计不低于50分，价格控制在15-20分，履约与售后不低于10分**。这样既能选出长期稳定的供应商，也能避免招标变成单纯压价。
