# 单位采购水果的验收与售后处理

针对品质不一致的情况，核心思路是：**入库前先分层抽样、按标准分档定级，不达标的当场拒收或折价，并留好可追溯证据**。具体分三步：

## 一、验收环节（到货当场做）

**1. 先核数量与外观，再抽样开箱**
- 按送货单核对品种、规格、数量、产地、生产日期。
- 整批货按"上、中、下、边"分层抽样，抽检比例建议不低于 10%（大单可抽 5%–10%，小单至少每箱抽 2–3 个）。
- 每箱都要开，不能只看表层。

**2. 按约定标准逐项判定**
提前在采购合同/订单里写清验收标准，现场按项打分：
- **规格**：单果重量/直径是否在约定区间（如 80–85mm），大小果比例超多少算不合格。
- **新鲜度**：果皮、果蒂、色泽、硬度，有无萎蔫。
- **成熟度**：是否适合当次使用（食堂/招待用途对成熟度要求不同）。
- **损伤**：碰伤、压伤、裂口、霉变、虫蛀。
- **一致性**：同一批内大小、色泽、成熟度差异是否超出约定范围。

**3. 分档处理，当场定性**
- **合格**：正常签收。
- **轻微不符**（如部分偏小、个别压伤在约定容差内）：**折价接收**，在送货单上写明扣减数量和金额，双方签字。
- **明显不符**（霉变、严重压伤、规格大面积不达标、以次充好）：**拒收该批次或该部分**，拍照留证，写明拒收原因。

**4. 留证**
- 拍照/录像：整批、开箱、不合格品特写、称重显示。
- 验收单上注明抽样数量、不合格数量、处理结论，送货人签字确认。这是后续售后的唯一依据。

## 二、售后环节

**1. 当场或当日提出**
发现问题当天（最好收货后 2 小时内）书面（微信/邮件/售后单）通知供应商，附照片和验收记录，明确诉求：换货、补发、折价或退款。

**2. 按合同约定时限和方式处理**
- 生鲜类通常约定"到货 24 小时内可提出质量异议"，超时容易扯皮，务必在时限内提。
- 换货要约定补货时间，避免影响使用；不能及时补的，按折价或退款处理。

**3. 建立供应商考核**
- 记录每次不合格率、售后响应速度，累计超标（如月度不合格率 >5% 或同一问题重复出现）触发约谈、扣款或更换供应商。
- 把验收不合格率与结算挂钩，是最有效的约束手段。

## 三、事前要做的两件事（决定售后是否顺利）

1. **合同/订单写清验收标准**：规格区间、容差比例、不合格处理方式（折价系数、拒收条件）、质量异议时限、违约责任。没有标准，验收和售后都无据可依。
2. **约定抽样和判定方法**：抽检比例、判定规则（如"不合格率超过 5% 整批折价 10%"），避免现场各说各话。

**一句话原则**：验收时"分层抽样、逐箱开检、当场定性、签字留证"；售后"当日书面提出、按合同时限处理、结果计入供应商考核"。
