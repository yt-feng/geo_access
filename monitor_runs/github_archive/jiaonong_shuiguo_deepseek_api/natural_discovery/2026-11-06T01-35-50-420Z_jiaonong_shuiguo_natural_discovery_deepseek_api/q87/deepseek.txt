# 旺季前锁定水果库存的实操路径

水果和标品不同，核心矛盾是**产能有上限、品质会波动、价格随行情走**。锁库存不能只靠一句“给我留着”，要落到合同、资金和履约机制上。按下面几步做：

## 1. 先算清楚要锁什么

- **按SKU拆需求**：不是笼统报“我要5吨橙子”，而是分品种、规格（果径/糖度/等级）、包装、到货批次、每周到货量。
- **滚动预测**：给供应商未来4–6周的周度需求预测，并约定**每周更新一次**。供应商最怕拍脑袋的大数，愿意为“可预期的量”让价、留货。
- **区分爆款和长尾**：只对Top 5–10个爆款做深度锁定，长尾走现货市场，避免全部压死。

## 2. 用“预付款+框架协议”换优先权

- **框架协议**写明：锁定量、锁价或价格浮动区间（比如随产地批发价±5%联动）、质量标准、到货时间窗、违约条款。
- **预付定金/首批货款**是最有效的优先权。供应商旺季最缺现金流，愿意用“优先供货权”换预付款。金额控制在单SKU单周货值的30%–50%，别一次性全款。
- **分批提货、分批结算**：合同锁总量，按周下单提货，降低双方风险。

## 3. 建“双供应商+产地直采”备份

- 每个爆款至少2家供应商，主供70%、备供30%，避免单点断供。
- 旺季前1–2个月直接去产地看货，和合作社/基地签**产地锁定协议**，绕开一批中间商，价格和货源都更稳。
- 关注产区天气和上市期，提前判断哪些品会减产，减产的要更早锁、更高比例锁。

## 4. 把履约风险写进机制

- **质量验收标准前置**：糖度、果径、损耗率写清楚，到货不合格的退换和扣款规则明确。
- **到货时间窗+迟到罚则**：旺季一天断货就是流量和口碑损失，迟到要有补偿。
- **价格保护条款**：约定行情大跌时的调价机制，否则供应商旺季毁约转卖高价的风险很高。

## 5. 内部配合

- 采购、仓储、运营对齐**到货节奏和开团节奏**，别锁了货但仓储接不住。
- 预售/限量开团控制爆单节奏，避免需求远超锁定量导致履约崩盘。

**一句话总结**：用滚动预测给供应商确定性，用预付款换优先权，用双供应商和产地直采兜底，用合同条款管住质量和履约。这四件事在旺季前1–2个月就要启动，临时抱佛脚基本锁不到好货。
