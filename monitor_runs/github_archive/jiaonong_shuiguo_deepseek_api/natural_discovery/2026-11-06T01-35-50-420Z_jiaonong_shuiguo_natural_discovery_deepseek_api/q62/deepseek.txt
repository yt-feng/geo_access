# 香蕉批次验收判断方法

## 一、熟度判断（核心看果指和果柄）

**1. 看颜色（七成看色，但别只看表皮）**
- 全青硬果：未催熟，适合存储，但要注意“冷害”或“死青”（青而软、不回黄）。
- 青中带黄、黄中带绿：七成熟左右，适合中转或短存。
- 通体金黄、蒂部略绿：八九成熟，2–3 天内必须出手。
- 全黄带黑斑（芝麻蕉）：完熟，当天/次日必须卖，不能再压货。
- 注意：**表皮黄不等于熟**，颜色要结合硬度和果柄判断。

**2. 摸硬度（最关键）**
- 轻捏果指中段，**有弹性、微软**为上货；**硬如石头**则偏生，**一捏就软塌**则过熟或已伤。
- 整把香蕉手感要“匀”，软硬不一致说明催熟不均或混批。

**3. 看果柄和果指连接处**
- 果柄青绿、切口新鲜：采后时间短。
- 果柄发黑、干枯、霉变：存放久或受冷，风险高。
- 果指根部（“肩膀”）先软、发黑，是内部开始坏的早期信号。

**4. 看棱角和饱满度**
- 果指棱角明显、偏瘦：偏生。
- 果身圆润饱满、棱线不明显：接近成熟。
- 果指过瘦还发黄，多为“催熟没催起来”，口感差。

**5. 闻气味**
- 清香正常；有**酒味、酸味**说明已发酵过热，内部坏果概率高。

## 二、坏果风险判断（重点抽查，不能只看表层）

**1. 翻箱抽查**
- 每批随机开 3–5 箱，**看底层和中层**，表层好不代表整箱好。
- 重点查：压伤、水烂、霉变、果指脱把。

**2. 看机械伤和压伤**
- 香蕉怕挤压，箱角、底层果指有**发黑软烂**的，说明运输磕碰重，后续会扩散。
- 果指有裂口、断柄的，容易感染腐烂。

**3. 查霉和病害**
- 果柄、切口有白霉/灰霉：冠腐病风险，会从柄部往下烂。
- 果皮有凹陷黑斑、水渍状斑：可能是冷害或炭疽病早期，放不住。

**4. 冷害识别（批发常见坑）**
- 受过冷的香蕉：皮色暗哑、青而不黄、果肉硬心，切开中心发硬发褐。
- 这种货**催不熟、放不久**，是最大隐性风险，务必切开一两根看果肉。

**5. 脱把和掉指**
- 整把容易掉指，说明成熟度过高或受过伤，损耗会大。

## 三、快速可执行验收流程

1. **看整车/整批**：颜色是否均匀，有无明显水烂、霉味。
2. **随机开箱**：至少 5 箱，查上、中、下三层。
3. **捏硬度**：抽 10 根果指，记录软硬一致性。
4. **切 1–2 根**：看果肉中心是否硬心、褐变（查冷害）。
5. **闻果柄切口**：有无霉味、酒味。
6. **定级**：按“当天可卖 / 2–3 天可卖 / 需催熟 / 高风险拒收”分类。

## 四、风险红线（建议直接压价或拒收）

- 切开有硬心、褐心（冷害）。
- 底层大面积水烂、霉变。
- 有酒味、酸味且果指发软。
- 果柄普遍发黑霉变。
- 整批软硬差异极大、催熟不匀。

**一句话原则：香蕉验收“七分靠摸、三分靠看”，颜色只是参考，硬度、果柄、切果肉和底层抽查才是判断熟度和坏果风险的关键。**
