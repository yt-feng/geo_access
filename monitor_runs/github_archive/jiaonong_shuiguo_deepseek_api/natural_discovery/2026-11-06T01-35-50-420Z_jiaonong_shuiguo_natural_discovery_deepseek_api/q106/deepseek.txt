判断“合理波动”不能只看涨跌幅，要先把波动拆成可核验的结构。给你一套可直接落地的判断框架：

## 1. 先建立“价格基准线”
- **当日市场价**：以当地批发市场（如新发地、江桥、江南市场等）同品类、同等级、同规格的均价为基准，而非供应商单方报价。
- **历史同期价**：拉近3年同月同日价格，水果有强季节性，春节前、台风季、换季期的波动本身有规律。
- **产地收购价+物流+损耗**：让供应商拆分“产地价、运费、包装、损耗率、利润”，与产地行情（农业农村部批发价指数、产地代办报价）交叉验证。

## 2. 设定“合理波动区间”
按品类定阈值，而不是一刀切：
- **耐储品类**（苹果、梨、土豆类）：日波动超过3%~5%需说明原因。
- **易腐品类**（叶菜、草莓、荔枝）：日波动5%~10%属正常，超过10%要凭证。
- **强天气敏感品类**（台风、寒潮前后）：允许短时跳涨，但要看是否全市场同步。

关键判断：**同一天同一品类，多家供应商是否同向同幅变动**。全市场都涨是行情，只有一家涨是议价问题。

## 3. 要求“波动归因凭证”
报价变动时，让供应商给出可核验的依据，至少一项：
- 产地收购价截图/代办报价；
- 批发市场当日行情截图；
- 天气、交通、检疫等公开事件；
- 运费或包装成本变动单据。

无法归因的涨价，按原价或招标比价处理。

## 4. 用合同锁定规则
- 约定**调价触发条件**：如市场均价连续3日变动超X%才可调价；
- 约定**调价上限**：单次调价不超过X%，月度累计不超过Y%；
- 约定**比价机制**：采购方有权每周向2~3家供应商询价，取中位数作为结算参考；
- 约定**异常波动复核**：供应商需在调价前24小时书面说明。

## 5. 建数据看板做趋势判断
每天记录：品类、规格、报价、市场均价、价差率、调价原因。连续记录1~2个月后，就能看出该供应商的报价是“跟随市场”还是“单向试探”。重点看**价差率**（供应商报价/市场均价-1），价差率稳定说明报价合理，价差率忽高忽低说明在博弈。

## 一句话判断标准
**同品类、同规格、同日、多源比价，涨跌方向与市场一致、幅度在品类阈值内、且有可核验归因——就是合理波动；否则按异常报价处理，要求说明或换源比价。**
