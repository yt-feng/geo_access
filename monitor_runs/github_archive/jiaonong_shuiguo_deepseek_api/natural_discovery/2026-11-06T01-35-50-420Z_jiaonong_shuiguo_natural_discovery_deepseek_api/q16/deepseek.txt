社区超市增加香蕉和苹果，建议先别把“本地批发”和“稳定供应商”当成二选一，而是按品类和经营阶段分开定：

**1. 苹果：优先稳定供应商**
- 苹果相对耐储、周转压力小，但客户对大小、甜度、外观稳定性要求高。
- 稳定供应商更适合保证规格统一、持续供货和售后。
- 如果本地批发市场同一品种价格明显低、且你能每天或隔天补货，可作为补充渠道，但不要只靠临时批发。

**2. 香蕉：前期优先本地批发或短链路供货**
- 香蕉成熟快、损耗高，催熟和到货成熟度很关键。
- 社区店销量未稳定前，先少量、高频补货，优先选能控制成熟度、退换货方便的本地批发或本地短链路供应商。
- 等销量稳定后，再转为固定供应商，要求按成熟度分批到货。

**3. 实操决策标准**
- 看损耗：香蕉连续2周损耗超过10%—15%，说明供货成熟度或补货频率不合适。
- 看周转：苹果库存超过7—10天未明显动销，先缩SKU，不要加大进货。
- 看退换：坏果、青果、过熟果能否退换，比单价便宜几毛更重要。
- 看配送频率：香蕉最好每周2—3次小批量；苹果可每周1—2次。
- 看价格差：本地批发若只便宜5%以内，但品质和售后不稳定，选稳定供应商；若便宜10%以上且能高频补货，可本地为主。

**建议组合：**
- 苹果：稳定供应商为主，本地批发比价补充。
- 香蕉：先本地批发/短链路小批量试销，销量稳定后签稳定供应商并约定成熟度和退换标准。
- 两个品类都先做2—4周试销，记录日均销量、损耗率、退货率和毛利，再决定主渠道。

一句话：**苹果偏稳定供应商，香蕉偏本地短链路高频补货；先用小批量试销验证，再定长期主供应商。**
