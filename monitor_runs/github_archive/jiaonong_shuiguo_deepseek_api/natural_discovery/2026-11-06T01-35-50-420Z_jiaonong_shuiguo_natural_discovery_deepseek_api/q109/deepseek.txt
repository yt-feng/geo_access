优先谈**账期**，其次**售后**，最后**配送**。

理由很直接：账期直接决定你的现金流和资金占用，是长期合作里最容易变成“隐性成本”的条款；售后决定出问题时的损失由谁承担；配送在水果这种品类里虽然重要，但通常可以通过备选供应商、分仓、验收标准来部分对冲。

具体优先级和谈法：

1. **账期优先谈**
   - 先明确：结算周期（周结/半月结/月结）、起算点（收货验收后还是开票后）、付款方式、逾期是否有宽限。
   - 长期合作可以争取“月结30天”或“半月结”，但不要只看天数，要看**起算点**。收货后30天和开票后30天差别很大。
   - 如果供应商坚持短账期，可换条件：比如预付部分、货到付款换更低单价，或要求账期随合作月份逐步延长。

2. **售后第二谈**
   - 水果非标、易损耗，必须把售后写成可执行条款：到货验收标准、坏果率上限、拍照留证时限、补货/退款/折价方式、责任归属。
   - 重点谈**坏果率超过约定比例后的处理方式**，而不是只谈“包售后”。比如超过3%按实际坏果补货或折价，超过10%整批退换。
   - 售后条款谈清楚，能显著降低长期合作的扯皮成本。

3. **配送第三谈**
   - 谈配送频次、到货时间窗口、冷链/保鲜要求、临时加单响应时间、缺货替代方案。
   - 配送的核心不是“送不送”，而是**稳定性**和**异常处理**。如果配送不稳，可以用备选供应商或调整订货节奏来补，但账期和售后一旦没谈好，损失更直接。

一句话判断：**账期保现金流，售后保底线，配送保体验。长期合作先保现金流和底线，再优化体验。** 如果供应商在账期上完全不让步，可以用售后条款和配送稳定性作为交换条件，但不要把账期让成“无限期现结”却不换任何条件。
