通常**直接买成品果丁的“显性损耗”更低，但未必总成本更低**。判断关键是把损耗拆成可核算的几项来比。

**结论**
- 若你店销量稳定、后厨人手紧、菠萝鲜果品质不稳定：**买成品果丁，综合损耗通常更低**。
- 若你销量大、切配规范、能控温控时、鲜果采购价明显低：**鲜果切配可能更划算**，但要把人工和废弃算进去。

**对比框架**
1. **鲜果切配损耗**
   - 去皮、去眼、去芯、修边：菠萝可食率通常约50%–65%，品种和成熟度影响很大。
   - 切配后氧化出水、冷藏变味、当日未用完报废。
   - 人工切配时间、清洗消毒、刀具砧板占用。
   - 鲜果熟度不一致导致出品波动和返工。

2. **成品果丁损耗**
   - 到货规格不符、解冻/沥水损失、临期报废。
   - 供应商批次波动、冷链断链风险。
   - 开袋后未用完的氧化和污染风险。
   - 单价通常高于鲜果折合可食部分，但省人工、省后厨面积。

**可执行判断方法**
连续记录7–14天：
- 鲜果：进货重量、可食果丁重量、废弃重量、切配工时。
- 成品：到货重量、沥水后可用重量、报废重量、开袋后损耗。
- 计算：`实际可用成本 = 采购金额 ÷ 实际可用果丁重量`，再加上人工和报废成本。
- 同时看出品稳定性和食品安全风险。

**建议**
- 小批量、多品类、后厨空间小的甜品店：优先成品果丁，重点选冷链稳定、规格一致的供应商。
- 菠萝用量大且稳定：鲜果切配+标准化切配流程+当日冷藏时限管理，可能更省。
- 不要只比采购单价，要比**每公斤可用果丁的综合成本**。
