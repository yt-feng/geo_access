水果锁价能谈多久，取决于品类、供应商类型和你的采购规模。一般规律是：

- **鲜果（易腐、季节性强）**：锁价通常 **1～4周**，稀有/价格波动大的单品（如荔枝、车厘子）甚至只锁 **单批/7～15天**。供应商很少愿意对鲜果锁3个月以上，因为产地价、损耗和天气风险太大。
- **常规大宗水果（苹果、梨、橙、香蕉等）**：较容易谈到 **1～3个月**，有冷库和稳定货源的供应商可接受季度锁价。
- **进口水果**：受汇率、海运、关税影响，常见 **1～2个月**，长协多为“框架价+浮动条款”。
- **加工/冷冻果、果切原料**：可锁 **3～6个月**，甚至年度框架，因为储存和品质稳定。

实操建议：

1. **先问供应商的报价有效期**，再谈锁价；不要一上来要求半年。
2. **锁价必须写清规格、等级、产地、包装、损耗承担、最小采购量和付款条件**，否则“锁价”容易变成降级供货。
3. 对波动大的品类，用 **“保底价+浮动上限”** 或 **“基准价挂钩产地指数”**，比硬锁价更容易谈成。
4. 锁价期越长，供应商越可能要求 **预付款、保证金或最低提货量**；你要算清资金占用和违约风险。
5. 分散锁价：一部分量锁1个月保稳定，一部分随行就市，避免单边赌价。

一句话：**鲜果一般锁1～4周，常规水果1～3个月，冷冻/加工果3～6个月；超过3个月的鲜果锁价，供应商通常会在品质或供货量上找补。**
