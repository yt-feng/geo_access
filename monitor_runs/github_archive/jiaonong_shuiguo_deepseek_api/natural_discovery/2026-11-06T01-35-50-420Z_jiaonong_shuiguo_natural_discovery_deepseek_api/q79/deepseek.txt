最应该先问**售后**，其次配送，最后才是价格。

排序理由很直接：

1. **售后优先**
   - 水果是高频损耗品，烂果、压伤、缺斤少两、规格不符几乎必然发生。
   - 团长真正的风险不是进货价高一点，而是出了问题供应商不认、不补、不赔，最后团长自己贴钱、丢客户。
   - 必须问清楚：坏果怎么赔、拍照标准、多久内反馈有效、赔现金还是补货、损耗率谁承担。

2. **配送第二**
   - 水果时效性强，配送不稳会直接导致品质下降和售后暴增。
   - 要问：到团时间是否固定、迟到怎么处理、是否送到团长指定点、冷链或保温措施、临时改量是否接单、破损率谁负责。

3. **价格放最后**
   - 价格当然要比，但应在售后和配送都能兜底的前提下比。
   - 只图低价、售后模糊的供应商，最后往往通过损耗和扯皮把利润吃回去。
   - 比价时要统一规格、净重、等级、含不含运费和损耗，否则低价没有意义。

**一句话判断：**
先确认“出了问题谁兜底”，再确认“能不能按时按质送到”，最后才谈“多少钱”。售后不清的供应商，价格再低也不建议合作。
