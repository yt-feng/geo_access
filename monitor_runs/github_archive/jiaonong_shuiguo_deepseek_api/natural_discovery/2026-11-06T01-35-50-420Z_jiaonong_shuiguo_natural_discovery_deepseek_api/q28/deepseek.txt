建议先做**香蕉的“稳定进口替代”或苹果的“稳定进口补充”**，不建议把菠萝作为第一步。更可执行的选择是：**如果超市想要低门槛、快周转，先从香蕉切入；如果想要更长货架期、更稳的价格和供应，先从苹果切入。菠萝放在第二阶段测试。**

判断依据：

1. **香蕉**
   - 优点：消费频次高、周转快、顾客接受度高，适合做引流和稳定销量。
   - 风险：货架期短、对冷链和催熟/成熟度管理要求高，损耗控制不好会吃掉毛利。
   - 适合条件：门店有一定客流、能做每日动销管理，且能接受“稳定供应+成熟度分级”的操作复杂度。
   - 建议：不要一开始追求多产地，先锁定1个稳定产地/供应商，做单一SKU试销，重点看损耗率和日销。

2. **苹果**
   - 优点：货架期长、损耗相对低、价格带容易分层，适合做稳定毛利和长期陈列。
   - 风险：进口苹果与国产苹果竞争激烈，顾客价格敏感，差异化不足时容易卖不动。
   - 适合条件：超市有中高端客群，或能做出明确产地/品种/规格差异。
   - 建议：先选1—2个有明确卖点的进口品种做小批量陈列，不要一次性铺太多SKU。

3. **菠萝**
   - 优点：有差异化，适合做促销亮点。
   - 风险：成熟度、酸甜度、损耗和顾客处理便利性都更不稳定，进口菠萝还涉及季节和运输波动。
   - 建议：不作为首选稳定品，适合作为阶段性测试或促销品。

**可执行结论：**
- 想低风险起步：**先苹果**，因为货架期长、损耗低，最容易验证“进口水果是否有稳定需求”。
- 想快周转、做客流：**先香蕉**，但必须先把损耗和成熟度管理跑通。
- **菠萝暂缓**，等苹果或香蕉跑出稳定动销后再测试。

最稳妥的做法不是三选一压货，而是：**选一个主品小批量试销4周，记录日销、损耗率、毛利率、缺货率和顾客反馈；达到稳定动销后再扩品。**
