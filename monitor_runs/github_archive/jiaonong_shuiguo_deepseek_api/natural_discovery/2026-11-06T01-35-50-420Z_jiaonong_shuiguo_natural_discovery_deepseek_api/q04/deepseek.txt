采购香蕉时，直接把“熟度”和“到货时间”写成可验收的采购条件，最有效。

**1. 采购单上明确熟度等级**
不要只说“不要太熟”，建议按香蕉表皮颜色和手感写清楚：

- **建议采购熟度：3～4号色**
  - 1号：全绿
  - 2号：绿中带黄
  - 3号：黄绿相间、棱角明显
  - 4号：黄多绿少、微有棱角
  - 5号以上：全黄、开始出糖斑，适合当天卖，不适合囤
- **手感要求：果身硬挺、有弹性，不软塌，不粘手。**
- **果柄要求：青绿、不干枯；果指无大面积黑斑、无裂口、无机械伤。**
- **拒收标准：到货已出糖斑、果肉发软、果柄发黑、整箱有酒味或酸味。**

香蕉是呼吸跃变型水果，采后仍会继续成熟，所以店里想减少放坏，核心是**不要一次进太熟的货**。如果门店销量稳定，可把采购分成两档：

- **主销货：3.5～4号色**，到店后2～4天内卖完；
- **备货货：2.5～3号色**，用于周转，到店后自然转黄再上架。

**2. 到货时间要卡“转黄节点”**
采购时要求供应商：

- **到货时中心温度不要过高，运输不要闷箱；**
- **到货熟度不高于4号色，最好3～4号色；**
- **要求“按门店销售周期分批到货”**，比如每天或隔天到一次，而不是一周一次大量到货；
- **要求供应商提供催熟批次和催熟日期**，避免拿到已催熟多日、到店很快出斑的货；
- **尽量安排上午到货**，当天完成分拣、上架，避免在仓库闷一夜；
- **到货后立即开箱通风、分级**，不要整箱堆压。

**3. 合同/订货话术可以直接写**
可以这样要求供应商：

> “香蕉按3～4号色到货，果身硬挺、果柄青绿，无明显糖斑、无软果、无机械伤。到货时间控制在门店上架前1天内，分批到货，不接受一次大批量压货。到货超过4号色、已出糖斑或果肉发软的，按不合格拒收或折价处理。请随货注明催熟日期和批次。”

**4. 店内配套动作**
- 到货后按熟度分三区：青黄货、适卖货、即售货；
- 适卖货放常温通风处，不要提前进冷柜；
- 已黄熟的可冷藏延缓后熟，但表皮易变黑，适合短时周转；
- 每天挑出糖斑果做折扣或加工，避免传染整箱。

**一句话标准：采购要求“3～4号色、硬挺无斑、分批短周期到货、超熟拒收”，比单纯要求“晚点到”更能减少放坏。**
