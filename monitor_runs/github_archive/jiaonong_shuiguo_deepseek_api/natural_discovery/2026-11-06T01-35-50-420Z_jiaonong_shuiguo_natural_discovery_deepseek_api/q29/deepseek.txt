超市和水果供应商的账期没有统一标准，但按渠道和品类可以这样判断：

- **普通商超、区域连锁：30～60天最常见**，其中生鲜/水果常偏向 **30～45天**。
- **大型连锁商超、强势渠道：60～90天较常见**，部分甚至更长。
- **水果批发、产地直采、小供应商：7～30天更常见**，不少是现结、周结或半月结。
- **高端精品超市：30～60天**较常见，但对品质和损耗要求更高。

水果属于高损耗、短保鲜品类，谈判时要特别明确：

1. **账期起算日**：按收货日、对账日还是开票日。
2. **对账和开票周期**：避免账期名义30天、实际拖到45天以上。
3. **损耗和退换货扣款规则**：否则账期再短也可能被扣款拉长实际回款。
4. **促销、进场费、陈列费**是否从货款中扣。
5. **新供应商前期**：可先做 **15～30天**，稳定后再谈30～45天。

实操上，如果你是供应商，**30～45天是相对可接受且常见的谈判区间**；如果超市强势要求60天以上，应把价格、损耗承担和结算方式一起谈，不要只让账期。
