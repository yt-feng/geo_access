可以谈，但“锁价”要分层看：能锁的通常是短期价格或价格区间，很难让供应商长期无条件锁定单一低价。餐饮店做水果成本稳定，建议这样谈和做：

1. **先分清品类**
   - 苹果、梨、橙、香蕉等大宗水果：供应相对稳定，较适合谈1—3个月锁价或区间价。
   - 草莓、车厘子、荔枝、芒果等季节性强、波动大的水果：供应商一般不愿长锁，适合谈“保底量+浮动价+最高限价”。

2. **谈判时给供应商确定性**
   供应商愿意锁价，通常因为你给量、给账期确定性。可提出：
   - 月度/季度预估采购量；
   - 固定送货频次和规格标准；
   - 接受合理浮动机制，如“基准价+±5%—10%浮动”；
   - 约定品质标准、损耗赔付、缺货替代规则。

3. **锁价条款要写清楚**
   建议合同写明：
   - 锁价品类、规格、等级、含税/含运费；
   - 锁价期限；
   - 触发调价的条件（产地大涨大跌、极端天气、物流成本）；
   - 最高限价和最低采购量；
   - 质量不达标、缺货时的处理；
   - 对账周期和付款方式。

4. **不要只锁一家**
   可主供应商锁价+备用供应商比价，避免单一供应商锁价后降品质或断供。

5. **内部做成本稳定**
   菜单上减少对高波动水果的依赖，设定替代水果，按周比价；对季节性水果用“时令菜单+短期锁价”，比全年锁价更现实。

结论：**能谈，但更适合谈短期锁价、区间价、最高限价和量价绑定，而不是长期固定低价。**
